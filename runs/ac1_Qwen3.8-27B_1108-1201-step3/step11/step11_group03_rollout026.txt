**Alternative: Direct minimization with constraint qualification**

At the optimum, KKT conditions hold:
- There exist multipliers λ_k >= 0 for each constraint (a*a)_k <= t
- There exist multipliers μ_j >= 0 for each a_j >= 0
- There's a multiplier ν for sum(a) = 1
- Stationarity: 2 * sum_k λ_k * (Q_k a)_j + μ_j - ν = 0 for all j
- Complementary slackness: λ_k * ((a*a)_k - t) = 0, μ_j * a_j = 0

At the optimum, only a few λ_k are nonzero (active constraints). If we can identify the active set, we can solve the KKT system directly.

This is exactly what the active-set QCQP does. The key is to correctly identify the active set.

**My strategy for active set identification**:
1. Start with the current solution
2. Compute the convolution
3. Find all positions where (a*a)_k is within ε of the max
4. Solve the QCQP with those active constraints
5. Check the new solution: are there new positions that now exceed the threshold?
6. If yes, add them to the active set and repeat
7. If no, we've found the optimum (for that active set)

One more thought: the previous code uses the LP alternating method as the "main workhorse". This is because it's theoretically sound (converges for convex problems) and doesn't require a good solver. But it's slow.

My alternative: use the **direct subgradient method** on the simplex, which is simpler and can be faster:
- At each step, compute the subgradient (average of gradients at active positions)
- Take a step in the negative subgradient direction
- Project onto the simplex

The advantage of this over LP alternating is that it's simpler and doesn't require solving an LP at each step.

For the projection onto the simplex, there's an O(n log n) algorithm (sort-based).

Let me implement this:

```python
def project_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.where(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)
```

Let me now think about the step size. For convex optimization, the standard subgradient method has step size eta_t = c/sqrt(t) or eta_t = c/t. For better convergence, we can use the "averaged" subgradient method.

But actually, since the function is convex but not smooth, the best we can do is O(1/sqrt(t)) for the subgradient method, or O(1/t) for the averaged version. For n=1200 and a target precision of 1e-5, we might need ~1e10 iterations, which is way too many.

So the subgradient method alone won't be fast enough. We need a smarter approach.

**Better approach: Smoothing + accelerated method**

Use the LogSumExp smoothing: f_T(a) = T * log(sum_k exp((a*a)_k / T))

This is a smooth convex function that converges to f(a) = max_k (a*a)_k as T → 0.

The gradient is smooth, so we can use FISTA (accelerated gradient descent) with O(1/t^2) convergence, or L-BFGS for even faster convergence.

**FISTA for the smoothed problem**:
- f_T(a) = T * log(sum_k exp((a*a)_k / T))
- ∇f_T(a) = sum_k w_k * 2 * Q_k @ a, where w_k = exp((a*a)_k / T) / sum_j exp((a*a)_j / T)
- L (Lipschitz constant of gradient) can be estimated

  t ← t+1

This should converge fast.
