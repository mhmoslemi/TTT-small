`(w ⋆ a)[i] = sum_j u[2n-2-i-j] * a[j]`

Let `l = 2n-2-i`, then:
`= sum_j u[l-j] * a[j] = (u * a)[l]` (linear convolution)

So `(w ⋆ a)[i] = (u * a)[2n-2-i]` where `u = reverse(w)` and `*` is linear convolution.

This can be computed with a single FFT of size `>= 2*(2n-1)-1 = 4n-3`.

For `n = 1200`, that's an FFT of size 4096, which is very fast.

So the gradient computation is:
1. Compute `b = conv(a, a)` via FFT (size `2n-1` padded to power of 2)
2. Compute `w = softmax(T * b)`
3. Compute `u = reverse(w)`
4. Compute `v = conv(u, a)` via FFT (size `4n-3` padded to power of 2)
5. `grad[i] = 2 * v[2n-2-i]` (for `i = 0, ..., n-1`)

This is very efficient! Two FFTs per gradient evaluation.

Now let me think about the optimization algorithm:

**Nesterov Accelerated Gradient with projection onto simplex:**

The problem is: minimize `f_T(a)` subject to `a >= 0, sum(a) = 1`.

The projection onto the simplex `{a : a >= 0, sum(a) = 1}` has a closed-form solution (sort-based).

Nesterov's method:
- `y_k = a_k + (t_{k-1} - t_k) / t_{k+1} * (a_k - a_{k-1})` (Nesterov momentum)
- `a_{k+1} = Proj_simplex(y_k - eta_k * grad f(y_k))`

where `t_k = (1 + sqrt(1 + 4*t_{k-1}^2)) / 2` and `eta_k` is the step size.

For a smooth convex function with `L`-Lipschitz gradient, `eta = 1/L` gives `O(1/k^2)` convergence.

The Lipschitz constant of the gradient: `||grad f_T(a) - grad f_T(b)|| <= L * ||a - b||`.

For the LogSumExp smoothed max of quadratics, the Hessian is bounded. The Hessian of `f_T(a)` is:
`H = 2 * sum_k (T*w_k*b_k - w_k^2 * sum_m T*b_m) * C_k / sum_k exp(T*b_k)`

This is bounded by `2 * T * max_k ||C_k||` (roughly), and `||C_k|| <= 2` (since each row has at most 2 nonzeros of value 1, so the spectral norm is at most 2).

So `L ≈ 4*T` (rough upper bound). We could use `eta = 1/(4*T)` or just do a backtracking line search.

Actually, for practical purposes, I'll use a backtracking line search or an adaptive step size.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. FFT-based LogSumExp-smoothed Nesterov accelerated gradient with adaptive temperature
2. Exact-max projected subgradient for final polish
3. Multi-n exploration with interpolation
4. Structured and random initialized attempts
5._restart mechanism with perturbations toward second-highest peak

Key advantage over LP-based approach: gradient computed in O(n log n) via FFT,
enabling 100x+ more iterations in the same time budget.
"""

import numpy as np
import time
from scipy.fft import rfft, irfft


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def compute_gradient_fft(a, T):
    """
    Compute gradient of LogSumExp-smoothed max(conv(a,a)).
    grad[i] = 2 * sum_j w[i+j] * a[j] where w = softmax(T * conv(a,a))
    Computed via FFT: grad[i] = 2 * (reverse(w) * a)[2n-2-i]
    """
    n = len(a)
    b = fast_convolve(a)
    max_b = b.max()
    exp_b = np.exp(T * (b - max_b))
    w = exp_b / exp_b.sum()
    
    # reverse(w)
    u = w[::-1]
    
    # Linear convolution of u and a
    size_u = len(u)  # 2n-1
    size_a = n
    conv_size = size_u + size_a - 1  # 3n-2
    fft_size = 1 << (conv_size - 1).bit_length()
    U = rfft(u, fft_size)
    A = rfft(a, fft_size)
    v = irfft(U * A, fft_size)[:conv_size]
    
    # grad[i] = 2 * v[2n-2-i] for i=0,...,n-1
    idx = 2 * n - 2 - np.arange(n)
    grad = 2.0 * v[idx]
    
    # Objective value
    log_sum = max_b * T + np.log(exp_b.sum())
    obj = log_sum / T
    
    return obj, grad


def project_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)


def nesterov_logsumexp(a0, time_limit, T_start=10.0, T_end=0.1, 
                        n_stages=8, iters_per_stage=50000, seed=42):
    """
    Nesterov accelerated gradient on LogSumExp-smoothed objective.
    Operates on the simplex (sum=1, a>=0).
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
        s = 1.0
    a = a / s
    
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)
    
    # Temperature schedule
    T_schedule = np.geomspace(T_start, T_end, n_stages)
    iters_per_stage = max(100, iters_per_stage // n_stages)
    
    for stage, T in enumerate(T_schedule):
        if time.monotonic() - t0 > time_limit - 2:
            break
        
        a_prev = a.copy()
        t_val = 1.0
        stall = 0
        stall_threshold = iters_per_stage // 10
        
        for it in range(iters_per_stage):
            if time.monotonic() - t0 > time_limit - 1:
                break
            
            # Nesterov momentum
            if it > 0:
                t_next = (1.0 + np.sqrt(1.0 + 4.0 * t_val * t_val)) / 2.0
                momentum = (t_val - 1.0) / t_next
                y = a + momentum * (a - a_prev)
            else:
                y = a.copy()
            
            # Compute gradient at y
            obj_y, grad_y = compute_gradient_fft(y, T)
            
            # Backtracking line search for step size
            # Lipschitz estimate: L ~ 4*T*n (very rough)
            eta = 1.0 / (4.0 * T * max(1, n // 100))
            eta = max(eta, 1e-8)
            
            # Gradient step with projection
            z = y - eta * grad_y
            a_new = project_simplex(z)
            
            # Check improvement
            score_new = 2.0 * n * fast_convolve(a_new).max()
            if score_new > best_score * 1.5:
                # Something went wrong, reduce step
                eta *= 0.5
                z = y - eta * grad_y
                a_new = project_simplex(z)
            
            a_prev = a
            a = a_new
            
            # Update Nesterov counter
            t_val = (1.0 + np.sqrt(1.0 + 4.0 * t_val * t_val)) / 2.0
            
            # Track best
            if score_new < best_score:
                best_score = score_new
                best_a = a.copy()
                stall = 0
            else:
                stall += 1
            
            # Restart on stall
            if stall >= stall_threshold and T < 1.0:
                # Perturb toward reducing the second-highest peak
                b_cur = fast_convolve(a)
                sorted_idx = np.argsort(b_cur)[::-1]
                peak_idx = sorted_idx[0]
                js = max(0, peak_idx - n + 1)
                je = min(n - 1, peak_idx)
                idx = np.arange(js, je + 1)
                contribs = a[idx] * a[peak_idx - idx]
                n_reduce = max(2, len(idx) // 20)
                top_pos = idx[np.argsort(contribs)[::-1][:n_reduce]]
                a_trial = a.copy()
                for pos in top_pos:
                    a_trial[pos] *= 0.95
                a_trial = np.maximum(a_trial, 0)
                a_trial = a_trial / a_trial.sum()
                score_trial = 2.0 * n * fast_convolve(a_trial).max()
                if score_trial < best_score:
                    best_score = score_trial
                    best_a = a_trial.copy()
                a = a_trial
                a_prev = a.copy()
                t_val = 1.0
                stall = 0
                stall_threshold = min(stall_threshold * 2, iters_per_stage // 2)
        
        # Periodic status
        if (stage + 1) % 2 == 0:
            elapsed = time.monotonic() - t0
            print(f"    NLSE stage={stage+1}/{n_stages} T={T:.2f} ({elapsed:.0f}s): best={best_score:.8f}")
    
    return best_a, best_score


def exact_subgradient_polish(a0, time_limit, n_max_iters=500000, seed=42):
    """
    Projected subgradient method using the exact max (not smoothed).
    Uses adaptive step size and focus on active peaks.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
        s = 1.0
    a = a / s
    
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)
    
    eta = 0.1  # Initial step size
    decay = 0.9999
    no_improve = 0
    patience = 5000
    
    for it in range(n_max_iters):
        if time.monotonic() - t0 > time_limit:
            break
        
        b = fast_convolve(a)
        max_b = b.max()
        
        # Find active peaks (within 0.1% of max)
        threshold = max_b * 0.999
        active = np.where(b >= threshold)[0]
        
        # Subgradient: g[i] = (1/|S|) * sum_{k in S} 2*a[k-i]
        g = np.zeros(n)
        for k in active:
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            g[idx] += 2.0 * a[k - idx]
        g /= len(active)
        
        # Projected subgradient step
        z = a - eta * g
        a_new = project_simplex(z)
        
        score_new = 2.0 * n * fast_convolve(a_new).max()
        
        if score_new < best_score - 1e-12:
            best_score = score_new
            best_a = a_new.copy()
            no_improve = 0
            a = a_new
        else:
            a = a_new  # Still move (subgradient methods need this)
            no_improve += 1
        
        # Decay step size
        eta *= decay
        
        # Restart on long stall
        if no_improve >= patience:
            if eta < 1e-6:
                break
            # Perturb
            noise = rng.standard_normal(n) * 0.005
            a = a + noise
            a = np.maximum(a, 0)
            a = a / a.sum()
            eta = 0.05
            no_improve = 0
            patience = max(2000, patience // 2)
        
        if (it + 1) % 20000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    SubGrad iter={it+1} ({elapsed:.0f}s): best={best_score:.8f}, eta={eta:.2e}")
    
    return best_a, best_score


def coordinate_descent_polish(a0, time_limit, n_max_steps=200000):
    """
    Targeted coordinate descent: reduce top contributors to each peak,
    redistribute mass to non-contributing coordinates.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
        s = 1.0
    a = a / s
    
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    t0 = time.monotonic()
    stall = 0
    
    for step in range(n_max_steps):
        if time.monotonic() - t0 > time_limit:
            break
        
        b = fast_convolve(a)
        max_b = b.max()
        
        # Find all significant peaks
        threshold = max_b * 0.9995
        peaks = np.where(b >= threshold)[0]
        
        improved = False
        for peak_k in peaks[:5]:
            js = max(0, peak_k - n + 1)
            je = min(n - 1, peak_k)
            idx = np.arange(js, je + 1)
            contribs = a[idx] * a[peak_k - idx]
            
            # Find top contributor
            top_m = min(5, len(idx))
            top_positions = idx[np.argsort(contribs)[::-1][:top_m]]
            
            for pos in top_positions:
                if a[pos] < 1e-12:
                    continue
                # Try reducing this coordinate and redistributing
                for factor in [0.999, 0.995, 0.99, 0.98]:
                    a_trial = a.copy()
                    removed = a_trial[pos] * (1.0 - factor)
                    a_trial[pos] -= removed
                    # Redistribute to positions that DON'T contribute to this peak
                    mask = np.ones(n, dtype=bool)
                    mask[pos] = False
                    # Also exclude positions that contribute to nearby peaks
                    for p2 in peaks[:3]:
                        js2 = max(0, p2 - n + 1)
                        je2 = min(n - 1, p2)
                        mask[js2:je2+1] = False
                    # Keep some as targets
                    targets = np.where(mask & (a_trial > 1e-10))[0]
                    if len(targets) == 0:
                        targets = np.where(mask)[0]
                    if len(targets) == 0:
                        break
                    a_trial[targets] += removed / len(targets)
                    a_trial = np.maximum(a_trial, 0)
                    a_trial = a_trial / a_trial.sum()
                    score = 2.0 * n * fast_convolve(a_trial).max()
                    if score < best_score - 1e-14:
                        a = a_trial
                        best_score = score
                        best_a = a.copy()
                        improved = True
                        break
                if improved:
                    break
            if improved:
                break
        
        if not improved:
            stall += 1
            if stall > 1000:
                # Multi-coordinate simultaneous reduction
                peak_k = int(np.argmax(b))
                js = max(0, peak_k - n + 1)
                je = min(n - 1, peak_k)
                idx = np.arange(js, je + 1)
                contribs = a[idx] * a[peak_k - idx]
                top_positions = idx[np.argsort(contribs)[::-1][:3]]
                a_trial = a.copy()
                for pos in top_positions:
                    a_trial[pos] *= 0.998
                a_trial = a_trial / a_trial.sum()
                score = 2.0 * n * fast_convolve(a_trial).max()
                if score < best_score - 1e-14:
                    a = a_trial
                    best_score = score
                    best_a = a.copy()
                    stall = 0
                elif stall > 5000:
                    break
        else:
            stall = 0
        
        if (step + 1) % 50000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    CoordDesc {elapsed:.0f}s: score={best_score:.8f}")
    
    return best_a, best_score


def interpolate_sequence(f, new_n):
    """Interpolate sequence to new length, preserving normalization."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = (np.arange(old_n) + 0.5) / old_n
    new_x = (np.arange(new_n) + 0.5) / new_n
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp


def structured_init(n, rng):
    """Create structured initial sequence with various shapes."""
    choice = rng.integers(0, 8)
    x = np.linspace(0, 1, n)
    if choice == 0:
        a = np.sin(np.pi * x) ** 1.5
    elif choice == 1:
        a = np.cos(np.pi * (x - 0.5)) ** 2
    elif choice == 2:
        a = np.exp(-4 * (x - 0.5) ** 2 / 0.15)
    elif choice == 3:
        a = 1.0 + 0.5 * np.cos(2 * np.pi * x)
        a = np.maximum(a, 0)
    elif choice == 4:
        a = 1.0 + 0.3 * np.cos(4 * np.pi * x) + 0.2 * np.cos(6 * np.pi * x)
        a = np.maximum(a, 0)
    elif choice == 5:
        # Bimodal
        a = np.exp(-10 * (x - 0.3) ** 2) + np.exp(-10 * (x - 0.7) ** 2)
    elif choice == 6:
        # Triangular
        a = 1.0 - np.abs(2 * x - 1)
    else:
        # Flat top with tapered edges
        a = np.ones(n)
        taper = n // 10
        if taper > 0:
            fade = np.linspace(0, 1, taper)
            a[:taper] = fade
            a[-taper:] = fade[::-1]
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s

        )
        if score_try < best_score:
            best_score = score_try
            best_a = a_try.copy()
            print(f"    MultiStart sched={i}: improved to {best_score:.8f}")
    
    return best_a, best_score


def propose_candidate(seed=42, budget_s=1800.0):
    """
    Multi-phase optimization for minimizing 2*n*max(conv(a,a))/(sum(a))^2.
    Uses FFT-based gradient methods for fast convergence.
    """
    deadline = time.monotonic() + max(1.0, float(budget_s) - 15.0)
    rng = np.random.default_rng(seed)
    
    best_seq = None
    best_score = float('inf')
    
    # Load parent sequence
    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            parent = p / p.sum()
            p_score = 2.0 * len(parent) * fast_convolve(parent).max()
            print(f"Parent: n={len(parent)}, score={p_score:.8f}")
            best_seq = parent.copy()
            best_score = p_score
    except Exception:
        pass
    
    if parent is None:
        n_init = 1200
        best_seq = structured_init(n_init, rng)
        best_score = 2.0 * len(best_seq) * fast_convolve(best_seq).max()
        print(f"Default init: n={len(best_seq)}, score={best_score:.8f}")
    
    def try_update(a, label):
        nonlocal best_seq, best_score
        a = np.maximum(np.asarray(a, dtype=np.float64), 0)
        s = a.sum()
        if s < 0.01:
            return
        a = a / s
        sc = 2.0 * len(a) * fast_convolve(a).max()
        if np.isfinite(sc) and sc < best_score:
            best_score = sc
            best_seq = a.copy()
            print(f"  NEW BEST [{label}]: {sc:.8f} (n={len(a)})")
    
    n_parent = len(best_seq)
    
    # === Phase 1: Nesterov LogSumExp on parent (main workhorse) ===
    print(f"\n=== Phase 1: Nesterov LogSumExp (score={best_score:.8f}, n={n_parent}) ===")
    rem = deadline - time.monotonic()
    t_alloc = min(rem * 0.35, 600.0)
    if t_alloc > 30:
        print(f"  Budget: {t_alloc:.0f}s")
        a_opt, _ = multi_start_optimize(best_seq, t_alloc, seed=seed)
        try_update(a_opt, "NLSE_p1")
    
    # === Phase 2: Subgradient polish ===
    print(f"\n=== Phase 2: Subgradient Polish (score={best_score:.8f}) ===")
    rem = deadline - time.monotonic()
    t_alloc = min(rem * 0.15, 200.0)
    if t_alloc > 15:
        print(f"  Budget: {t_alloc:.0f}s")
        a_sg, _ = exact_subgradient_polish(best_seq, t_alloc, seed=seed)
        try_update(a_sg, "subgrad")
    
    # === Phase 3: Coordinate descent polish ===
    print(f"\n=== Phase 3: Coord Descent (score={best_score:.8f}) ===")
    rem = deadline - time.monotonic()
    t_alloc = min(rem * 0.15, 200.0)
    if t_alloc > 10:
        print(f"  Budget: {t_alloc:.0f}s")
        a_cd, _ = coordinate_descent_polish(best_seq, t_alloc)
        try_update(a_cd, "coorddesc")
    
    # === Phase 4: Multi-n exploration ===
    print(f"\n=== Phase 4: Multi-n Exploration (score={best_score:.8f}) ===")
    rem = deadline - time.monotonic()
    t_alloc = min(rem * 0.20, 300.0)
    if t_alloc > 30:
        n_best = len(best_seq)
        # Try nearby and different n values
        candidate_ns = []
        for delta in [-200, -100, 100, 200, 400]:
            nc = n_best + delta
            if 600 <= nc <= 5000:
                candidate_ns.append(nc)
        # Also try doubling and halving
        if 600 <= n_best * 2 <= 8000:
            candidate_ns.append(n_best * 2)
        if 600 <= n_best // 2 <= 5000:
            candidate_ns.append(n_best // 2)
        candidate_ns = sorted(set(candidate_ns))
        
        per_n = t_alloc / max(1, len(candidate_ns))
        print(f"  Trying n values: {candidate_ns}, ~{per_n:.0f}s each")
        
        for n_try in candidate_ns:
            if time.monotonic() > deadline - 15:
                break
            if n_try == len(best_seq):
                continue
            a_interp = interpolate_sequence(best_seq, n_try)
            t_sub = min(per_n * 1.5, deadline - time.monotonic() - 10)
            if t_sub < 15:
                continue
            print(f"  n={n_try}, budget={t_sub:.0f}s")
            a_sub, _ = nesterov_logsumexp(a_interp, t_sub, T_start=10.0, 
                                          T_end=0.3, n_stages=5,
                                          iters_per_stage=80000, seed=seed + n_try)
            try_update(a_sub, f"multi_n_{n_try}")
    
    # === Phase 5: Final Nesterov on best found ===
    print(f"\n=== Phase 5: Final Nesterov (score={best_score:.8f}) ===")
    rem = deadline - time.monotonic()
    t_alloc = min(rem * 0.25, 350.0)
    if t_alloc > 20:
        print(f"  Budget: {t_alloc:.0f}s")
        a_fin, _ = nesterov_logsumexp(best_seq, t_alloc, T_start=5.0,
                                      T_end=0.05, n_stages=8,
                                      iters_per_stage=200000, seed=seed + 999)
        try_update(a_fin, "final_nlse")
    
    # === Phase 6: Final subgradient polish ===
    print(f"\n=== Phase 6: Final Polish (score={best_score:.8f}) ===")
    rem = deadline - time.monotonic()
    t_alloc = min(rem * 0.10, 150.0)
    if t_alloc > 10:
        a_pol, _ = exact_subgradient_polish(best_seq, t_alloc, seed=seed + 777)
        try_update(a_pol, "final_polish")
    
    # Final verification
    if best_seq is not None:
        fs = 2.0 * len(best_seq) * fast_convolve(best_seq).max()
        if np.isfinite(fs):
            best_score = fs
        print(f"\nFINAL SCORE: {best_score:.8f} (n={len(best_seq)})")
    
    return [float(max(0.0, min(1000.0, x))) for x in best_seq]
