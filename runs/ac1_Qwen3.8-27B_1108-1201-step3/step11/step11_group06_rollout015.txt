**Frank-Wolfe (Conditional Gradient) approach:**

The problem: min_a f(a) = max_k a^T P_k a  s.t. a in Δ (simplex)

Frank-Wolfe:
- At current point a, compute gradient g = 2 * P_k* @ a (where k* is the argmax)
- Find s = argmin_{s in Δ} <g, s> = e_{argmin_i g[i]} (a vertex of the simplex)
- Update: a_new = (1-t) * a + t * s, where t = 2/(iter+2) (or line search)

This is very simple! Each iteration:
1. Compute conv(a,a) to find the peak k* (O(n log n) with FFT)
2. Compute gradient: g[i] = 2 * a[k*-i] (reversed and shifted a) (O(n))
3. Find min of g (O(n))
4. Update (O(n))

Total per iteration: O(n log n) dominated by FFT.

def frank_wolfe_nesterov(a0, time_limit, top_k=5):
    n = len(a0)
    a = a0.copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
        s = 1
    a = a / s  # normalize to sum=1
    
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    
    t0 = time.monotonic()
    x = a.copy()  # Nesterov's ghost point
    
    for t in range(1, 10_000_000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Compute convolution at ghost point
        b = fast_convolve(x)
        max_b = b.max()
        
        # Find top-k peaks with softmax weighting
        # Use log-sum-exp for smooth approximation
        T = max(1e-6, 1.0 / t)  # decreasing temperature
        log_weights = (b - max_b) / T
        log_weights -= log_weights.max()
        weights = np.exp(log_weights)
        w_sum = weights.sum()
        if w_sum < 1e-30:
            weights = np.zeros_like(b)
            weights[np.argmax(b)] = 1
            w_sum = 1
        weights /= w_sum
        
        # Compute weighted subgradient
        g = np.zeros(n)
        active = np.where(weights > 1e-15)[0]
        for k in active:
            wk = weights[k]
            # P_k @ x: (P_k @ x)[i] = x[k-i] if valid
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            g[idx] += wk * 2.0 * x[k - idx]
        
        # Frank-Wolfe: find min of g
        min_idx = np.argmin(g)
        e_min = np.zeros(n)
        e_min[min_idx] = 1.0
        
        # Step size
        gamma = 2.0 / (t + 2)
        
        # Update
        x = (1 - gamma) * x + gamma * e_min
        x = np.maximum(x, 0)
        sx = x.sum()
        if sx < 1e-15:
            x = a.copy()
        else:
            x = x / sx
        
        # Evaluate
        if t % 100 == 0 or t == 1:
            score = 2.0 * n * fast_convolve(x).max()
            if score < best_score:
                best_score = score
                best_a = x.copy()
            a = x.copy()
    
    return best_a, best_score

    a = a0 / a0.sum()

Or equivalently: max min_i (T^T @ lambda)[i]  s.t. sum(lambda) = 1, lambda >= 0.

This is a zero-sum game! The "row player" chooses a distribution lambda over the convolution indices, and the "column player" chooses a coordinate i. The payoff is T^T @ lambda [i] = sum_k lambda_k * T[k,i] = sum_k lambda_k * y[k-i] (if valid) = (y convolved with delta at position i, weighted by lambda).

Actually, (T^T @ lambda)[i] = sum_k lambda_k * T[k,i] = sum_k lambda_k * y[k-i] (where y[j] = 0 if j not in [0,n-1]).

This is the cross-correlation of y with the "measure" lambda, evaluated at position i.

So the dual is: find a distribution lambda over [0, 2n-2] that maximizes the minimum of the cross-correlation of y with lambda.

This is interesting! It means the LP is giving us a "worst case" distribution over the convolution peaks, and the dual is the "best case" distribution for the column player.

This doesn't immediately help with optimization, but it gives us a different perspective.

**Approach: Use the fact that the problem is a minimum of a maximum of quadratics, and apply the "outer approximation" method.**

The idea:
1. Start with the parent sequence
2. Compute conv(a, a) and identify the top M peaks (say M=50)
3. Solve: min t s.t. a^T P_k a <= t for k in top_M, sum(a)=1, a>=0
   - This is a quadratic programming problem with M quadratic constraints
   - For small M (say < 100), this can be solved with CVXPY
   - Or we can linearize: a^T P_k a <= t at the current point becomes 2*a^T P_k (a_new - a) + a^T P_k a <= t (first-order approximation)
   - This gives a linear program!
4. Get the new solution
5. Recompute conv, update top_M
6. Repeat

This is essentially a **linearized** or **cutting-plane** approach. Each iteration:
- Solve an LP with M constraints (fast if M is small)
- Update the active set

The advantage over the full LP is that we only need M constraints (M << 2n-1), making the LP much faster.

def fast_convolve(a):

    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)

def simplex_project(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    x = np.sort(v)[::-1]
    cssv = np.cumsum(x)
    rho = np.nonzero(x * np.arange(1, n + 1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def compute_weighted_gradient(y, n, peak_weights):
    """Compute weighted subgradient of max_k conv(y,y)[k]."""
    g = np.zeros(n)
    for w, k in zip(peak_weights[1], peak_weights[0]):
        if w < 1e-18:
            continue
        js = max(0, k - n + 1)
        je = min(n - 1, k)
        idx = np.arange(js, je + 1)
        g[idx] += w * 2.0 * y[k - idx]
    return g


def find_peak_weights(b, n_peaks=10, temperature=0.01):
    """Find top peaks and their softmax weights."""
    max_b = b.max()
    if max_b < 1e-30:
        idx = np.array([np.argmax(b)])
        weights = np.array([1.0])
        return idx, weights
    # Use top-k + softmax weighting
    k = min(n_peaks, len(b))
    top_idx = np.argpartition(b, -k)[-k:]
    top_vals = b[top_idx]
    # Softmax weighting
    shifted = (top_vals - top_vals.max()) / max(temperature, 1e-10)
    exp_vals = np.exp(shifted)
    weights = exp_vals / exp_vals.sum()
    return top_idx, weights
