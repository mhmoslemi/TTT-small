**Practical approach: Fast LP via cutting planes**

```python
def proj_simplex(z):
    """Project z onto {x >= 0, sum(x) = 1}."""
    n = len(z)
    # Binary search for tau
    lo, hi = z.min(), z.max()
    for _ in range(60):  # enough for double precision
        mid = (lo + hi) / 2
        s = np.maximum(z - mid, 0).sum()
        if s > 1:
            lo = mid
        else:
            hi = mid
    return np.maximum(z - (lo + hi) / 2, 0)
```

This is O(60 * n) = O(n) per projection, which is very fast.
