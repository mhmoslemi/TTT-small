**Proximal Gradient with Exact Subgradient and Nesterov Acceleration**

The key insight: since f(a) = max_k conv(a,a)[k] is the max of smooth convex functions, its subgradient is well-defined (as the convex hull of the gradients of the active functions). We can use:

1. Compute g = (1/|S|) * sum_{k in S} grad_k(a) where S is the set of (near-)max lags
2. Nesterov step: y_t = x_t + (t-2)/(t+1) * (x_t - x_{t-1})
3. Proximal step: x_{t+1} = prox_{eta_t}(y_t - eta_t * g_t)
   where prox is the mirror prox for the entropy loss: x_{t+1}[i] ∝ y_t[i] * exp(-eta_t * g_t[i])

The step size eta_t should be chosen based on the Lipschitz constant of the gradients. Since each grad_k is a linear map (a -> 2*T_k^T * a), its operator norm is at most 2*||a||_1 * 2 = 4 (roughly). But with the softmax weighting, it's smaller.

def nesterov_mirror_descent(a0, time_limit, top_k=100, beta=10.0, eta0=0.05, 
                              verbose=True, seed=42):
    """Nesterov-accelerated mirror descent with exact subgradient."""
    n = len(a0)
    a = norm1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)
    
    x = a.copy()
    x_prev = a.copy()
    stall = 0
    restart_every = 3000
    
    for t in range(1, 1000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Nesterov extrapolation
        beta_t = (t - 2.0) / (t + 1.0)
        if beta_t < 0:
            beta_t = 0
        y = x + beta_t * (x - x_prev)
        y = np.maximum(y, 1e-30)
        sy = y.sum()
        if sy < 1e-30:
            y = x.copy()
        else:
            y = y / sy
        
        # Compute subgradient
        g, M_curr = compute_subgrad(y, top_k=top_k, beta=beta)
        
        # Mirror descent step
        eta_t = eta0 / np.sqrt(t)
        log_y = np.log(y)
        log_new = log_y - eta_t * g
        log_new -= log_new.max()
        new = np.exp(log_new)
        new = np.maximum(new, 1e-30)
        sn = new.sum()
        if sn < 1e-30:
            new = y.copy()
        else:
            new = new / sn
        
        x_prev = x.copy()
        x = new
        
        M_new = fast_autocorr(x).max()
        if M_new < best_m - 1e-14:
            best_m = M_new
            best_a = x.copy()
            stall = 0
        else:
            stall += 1
        
        # Restart
        if stall > restart_every:
            stall = 0
            scale = max(0.01, 0.1 * (1 - stall / restart_every))
            pert = rng.normal(0, scale, n) * best_a
            x = best_a + pert
