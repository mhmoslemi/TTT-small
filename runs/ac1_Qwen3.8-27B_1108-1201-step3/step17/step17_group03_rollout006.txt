    print(f"\n=== Phase 1: LP-FW main (n={len(best_seq)}, t={t1:.0f}s) ===")
    a_out, m_out = lp_frank_wolfe_v2(norm_sum1(best_seq), t1, solver, verbose=True)
    best_seq, best_score = try_update(a_out, best_seq, best_score, t_global, "fw_main")
    
    # Phase 2: Coordinate descent polish (20% of time)
    remaining = time_budget - (time.monotonic() - t_global)
    t2 = remaining * 0.25
    print(f"\n=== Phase 2: Coord descent (n={len(best_seq)}, t={t2:.0f}s) ===")
    a_out, m_out = coord_descent_polish(norm_sum1(best_seq), t2, verbose=True)
    best_seq, best_score = try_update(a_out, best_seq, best_score, t_global, "cd_polish")
    
    # Phase 3: LP-FW tighter (10% of time)
    remaining = time_budget - (time.monotonic() - t_global)
    t3 = remaining * 0.2
    print(f"\n=== Phase 3: LP-FW tight (n={len(best_seq)}, t={t3:.0f}s) ===")
    a_out, m_out = lp_frank_wolfe_v2(norm_sum1(best_seq), t3, solver, verbose=True, top_K=500, margin_frac=1e-4)
    best_seq, best_score = try_update(a_out, best_seq, best_score, t_global, "fw_tight")
    
    # Phase 4: Try different length (10% of time)
    remaining = time_budget - (time.monotonic() - t_global)
    if remaining > 60:
        new_n = len(best_seq) + 200
        print(f"\n=== Phase 4: Extend to n={new_n} (t={remaining*0.4:.0f}s) ===")
        a_long = interpolate_sequence(best_seq, new_n)
        t4 = remaining * 0.4
        a_out, m_out = lp_frank_wolfe_v2(norm_sum1(a_long), t4, solver, verbose=False)
        best_seq, best_score = try_update(a_out, best_seq, best_score, t_global, f"n{new_n}")
        
        # Polish the new length
        remaining = time_budget - (time.monotonic() - t_global)
        if remaining > 30:
            a_out, m_out = coord_descent_polish(norm_sum1(best_seq), remaining * 0.5, verbose=False)
            best_seq, best_score = try_update(a_out, best_seq, best_score, t_global, "cd_n2")
    
    # Final validation
    if best_seq is not None:
        fs = evaluate_safe(best_seq)
        if np.isfinite(fs):
            best_score = fs
        total_time = time.monotonic() - t_global
        print(f"\nFINAL: score={best_score:.6f}, n={len(best_seq)}, time={total_time:.0f}s")
    else:
        best_seq = make_parametric(3600, 'sine')
        best_score = evaluate_safe(best_seq)
    
    return [float(x) for x in best_seq]

Now let me think about the LP Frank-Wolfe implementation more carefully.

The key LP at each iteration:
- Given current $a$ (normalized, sum=1), compute $ac = \text{convolve}(a, a)$ and $M = \max(ac)$.
- Select top-K constraints: those $k$ where $ac[k]$ is largest (tightest).
- Solve: max $\sum g_i$ s.t. $(a * g)[k] \leq M$ for selected k, $g_i \geq 0$.
  Here $(a * g)[k] = \sum_i a[i] g[k-i]$ (cross-correlation, which is linear in g).
- Take FW step: $a_{new} = (1-\alpha) a + \alpha g / \sum g$

The constraint matrix for the LP:
For each selected lag $k$, the constraint is:
$\sum_i a[i] \cdot g[k-i] \leq M$

where the sum is over valid $i$ (i.e., $0 \leq i < n$ and $0 \leq k-i < n$).

So for lag $k$, the coefficient of $g[j]$ in the constraint is $a[k-j]$ (if $0 \leq k-j < n$).

Let me write the constraint matrix:
$T[k_idx, j] = a[k - j]$ if $0 \leq k - j < n$, else 0.

This is a banded matrix (each row has at most min(k+1, n, 2n-1-k) non-zeros).

For the LP solve, I'll use cvxpy.

Let me also think about the coordinate descent approach:

For coordinate $i$, fix all other $a_j$ (j ≠ i) and find $a_i$ that minimizes $\max_k C_k$.

$C_k$ as a function of $a_i$:
$C_k = C_k^{(excl)} + a_i \cdot (a[k-i] + a[k-i] \text{ from the other side})$

Wait, let me be more careful. The convolution is:
$C_k = \sum_{j} a[j] a[k-j]$

If we isolate the terms involving $a_i$:
$C_k = \sum_{j \neq i} a[j] a[k-j] + a[i] a[k-i] + a[k-i] a[i]$ (if $i \neq k-i$)
$C_k = \sum_{j \neq i} a[j] a[k-j] + a[i]^2$ (if $i = k-i$, i.e., $k = 2i$)

Wait, more carefully:
$C_k = \sum_{j=0}^{n-1} a[j] a[k-j]$ (with the constraint $0 \leq k-j < n$)

The terms involving $a[i]$ are:
- When $j = i$: term is $a[i] \cdot a[k-i]$ (valid if $0 \leq k-i < n$)
- When $k-j = i$, i.e., $j = k-i$: term is $a[k-i] \cdot a[i]$ (valid if $0 \leq k-i < n$)

If $i \neq k-i$ (i.e., $k \neq 2i$): both terms are present, giving $2 a[i] a[k-i]$.
If $i = k-i$ (i.e., $k = 2i$): only one term, $a[i]^2$.

So $C_k(a) = C_k^{base} + a[i] \cdot s_k$ where:
- $s_k = 2 a[k-i]$ if $k \neq 2i$ and $0 \leq k-i < n$
- $s_k = a[i]$ if $k = 2i$ (this is quadratic in $a[i]$)
- $s_k = 0$ otherwise

Wait, this is getting complicated because of the quadratic term when $k = 2i$. Let me handle it differently.

$C_k = C_k^{base} + a[i] \cdot t_k + \delta_{k,2i} \cdot a[i]^2$

where $C_k^{base} = C_k$ with $a[i]$ set to 0, and $t_k = a[k-i]$ (if valid), and $\delta_{k,2i}$ is 1 if $k=2i$ else 0.

Actually, let me just compute it numerically. For a given coordinate $i$ and its value $v = a[i]$:
- Set $a[i] = v$
- Compute the full convolution
- Check the max

This is O(n) per evaluation (since we only need to update the convolution entries that involve coordinate $i$).

The entries of the convolution that involve $a[i]$ are:
$C_k$ for $k$ where $0 \leq k-i < n$ (i.e., $i \leq k \leq i + n - 1$) AND $0 \leq i < n$ (always true).

Wait, more precisely, $C_k$ involves $a[i]$ when:
- There exists $j$ such that $a[j] a[k-j]$ includes $a[i]$, i.e., $j = i$ or $k-j = i$.
- $j = i$: valid if $0 \leq i < n$ (always) and $0 \leq k-i < n$, i.e., $i \leq k \leq i+n-1$.
- $k-j = i$: valid if $0 \leq k-i < n$ and $0 \leq i < n$, same condition.

So the affected lags are $k \in [i, i+n-1]$ (clipped to $[0, 2n-2]$).

For each such $k$:
- Contribution from $a[i]$: if $k \neq 2i$, it's $2 \cdot a[i] \cdot a[k-i]$; if $k = 2i$, it's $a[i]^2$.

So if we write $C_k = B_k + a[i] \cdot T_k + \delta_{k,2i} a[i]^2$ where $B_k$ is the baseline (without $a[i]$) and $T_k = a[k-i]$ (for $k \in [i, i+n-1]$):

To find the optimal $a[i] = v$ that minimizes $\max_k (B_k + v \cdot T_k + \delta_{k,2i} v^2)$:

This is a 1D optimization problem. The function is the max of affine (or quadratic) functions of $v$, so it's convex in $v$. We can solve it with bisection or by finding the point where the maximum is minimized.

Actually, for the objective $\min_v \max_k f_k(v)$ where each $f_k$ is convex, the optimum is where the "active" constraints are balanced.

A simple approach: since $v \geq 0$ and we want to minimize the max, we can use a ternary search or bisection on the derivative.

But this might be overkill. A simpler approach: for each coordinate, try a few candidate values (current value ± small perturbations) and keep the best.

Actually, for the coordinate descent, here's a simpler approach:
1. For coordinate $i$, the current value is $a[i] = v_0$.
2. The "pressure" on coordinate $i$ is determined by the lags $k$ where $a[i]$ contributes significantly to $C_k$.
3. We want to reduce $a[i]$ if it's contributing to high $C_k$ values, and increase it if it's in a "low" region.

A practical approach:
- Compute the gradient of $\max_k C_k$ with respect to $a[i]$ (using the subgradient from the active lags).
- Do a small step in the negative gradient direction.
- Project back to the constraint set ($\sum a_i = 1, a_i \geq 0$).

But this is essentially what the AMD (accelerated mirror descent) approach already does.

Let me focus on making the LP Frank-Wolfe approach as effective as possible, since that's the main workhorse.

**Improved LP Frank-Wolfe:**

Key changes from the previous version:
1. Use a dynamic number of constraints: start with top-100, gradually increase to top-500.
2. Use a tighter margin: start with 1e-3 * M, decrease to 1e-5 * M.
3. Use a better step size: line search within [0, 1] to find the $\alpha$ that minimizes the objective.
4. Monitor for convergence and restart if stalled.

Let me also think about whether there's a fundamentally different approach that could work better.

**Alternative: Iterative water-filling**

The idea: we want to "flatten" the convolution. At each step:
1. Find the lag $k^*$ with the maximum convolution value.
2. Reduce the contribution to $C_{k^*}$ by adjusting the $a_i$ values that contribute to it.
3. The contribution of $a_i$ to $C_{k^*}$ is proportional to $a[k^*-i]$.
4. So we should reduce $a_i$ in proportion to $a[k^*-i]$ (for $i$ in the valid range).

This is similar to the "peak crushing" approach but more systematic.

Actually, I think the most effective approach is:
1. LP Frank-Wolfe as the main optimizer
2. A "smoothing" coordinate descent as the polisher
3. Trying a few different lengths

Let me now write the full code. I'll focus on making the LP Frank-Wolfe as efficient as possible.

For the LP, the constraint matrix $T$ has a special banded structure. Each row $k$ has non-zeros at positions $j$ where $0 \leq k - j < n$, i.e., $j \in [\max(0, k-n+1), \min(n-1, k)]$. The number of non-zeros in row $k$ is $\min(k+1, n) - \max(0, k-n+1) + 1 = \min(k+1, 2n-1-k, n)$.

For $k$ near the center ($k \approx n-1$), there are $n$ non-zeros. For $k$ near the edges, there are fewer.

For the LP with K constraints and n variables, the constraint matrix is K × n. For K=200-500 and n=3600, this is manageable.

Let me also think about solver choice. For this type of LP (maximize sum of variables subject to upper-bound constraints and non-negativity), the problem is well-structured. CLARABEL or PDLP should work well.

Actually, I realize I should also think about the problem from a different angle. The objective $J = 2n \max_k C_k$ (for normalized $a$) can be rewritten as:

$J = 2n \min_t \{ t : C_k \leq t \text{ for all } k, \sum a_i = 1, a_i \geq 0 \}$

This is a feasibility problem. We can binary search on $t$ and check feasibility. But the feasibility check is a non-convex QP (due to the quadratic $C_k$), so this doesn't directly help.

However, we can use the SCA (successive convex approximation) approach:
- At iterate $a^{(t)}$, linearize $C_k(a) \approx 2(B_k a^{(t)})^T a - C_k(a^{(t)})$
- Check if there exists $a$ such that the linearized constraints are satisfied with a smaller $t$
- This is an LP!

This is essentially the same as the Frank-Wolfe approach but formulated differently. The FW approach finds the best direction in the feasible set, while the SCA approach finds the best point in the linearized feasible set.

I think the FW approach is more stable and reliable. Let me stick with it.

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. LP Frank-Wolfe with adaptive constraint selection and line search
2. Coordinate descent polishing with subgradient-based updates
3. Multi-length exploration with interpolation
4. Frequency-domain perturbation for diversification
"""

import numpy as np
import time
import cvxpy as cp

_global_solver = None

def get_solver():
    global _global_solver
    if _global_solver is not None:
        return _global_solver
    for s in [cp.CLARABEL, cp.PDLP, cp.ECOS, cp.SCS]:
        try:
            x = cp.Variable(5, nonneg=True)
            prob = cp.Problem(cp.Minimize(cp.sum(x)), [cp.sum(x) == 1, x <= 0.4])
            prob.solve(solver=s, verbose=False)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                _global_solver = s
                print(f"  LP solver: {s}")
                return s
        except Exception:
            continue
    _global_solver = cp.ECOS
    print("  LP solver (fallback): ECOS")
    return _global_solver

def fast_autocorr(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(np.asarray(a, dtype=np.float64), fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def evaluate_safe(a):
    try:
        a_list = [float(x) for x in np.asarray(a, dtype=np.float64)]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')

def norm_sum1(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss

def make_parametric(n, family='sine'):
    if family == 'sine':
        x = np.linspace(0, 1, n)
        return norm_sum1(np.sin(np.pi * x) ** 2)
    elif family == 'cosine':
        x = np.linspace(0, 1, n)
        return norm_sum1(np.cos(np.pi * x / 2) ** 2)
    elif family == 'uniform':
        return np.ones(n) / n
    else:
        x = np.linspace(0, 1, n)
        return norm_sum1(np.sin(np.pi * x) ** 2)

def lp_frank_wolfe_v2(a0, time_limit, solver, verbose=True, top_K=300, margin_frac=2e-3):
    """
    LP-based Frank-Wolfe with adaptive constraints and line search.
    """
    n = len(a0)
    a = norm_sum1(a0)
    ac = fast_autocorr(a)
    M_curr = ac.max()
    best_a = a.copy()
    best_M = M_curr
    t0 = time.monotonic()
    
    # Adaptive parameters
    cur_top_K = top_K
    cur_margin = margin_frac
    
    for t in range(1, 500000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Re-compute if needed
        if t > 1:
            ac = fast_autocorr(a)
            M_curr = ac.max()
        
        if M_curr < 1e-18:
            break
        
        # Select constraints: top cur_top_K by value (tightest)
        k_sel = np.argsort(ac)[::-1][:cur_top_K]
        K = len(k_sel)
        
        # Build constraint matrix T (K x n)
        # T[row, j] = a[k_sel[row] - j] if 0 <= k_sel[row] - j < n
        T = np.zeros((K, n))
        for row, k in enumerate(k_sel):
            k_int = int(k)
            j_start = max(0, k_int - n + 1)
            j_end = min(n, k_int + 1)
            j_range = np.arange(j_start, j_end)
            T[row, j_range] = a[k_int - j_range]
        
        # Solve LP: max sum(g) s.t. T @ g <= M_curr, g >= 0
        g_var = cp.Variable(n, nonneg=True)
        constraints = [T @ g_var <= M_curr]
        prob = cp.Problem(cp.Maximize(cp.sum(g_var)), constraints)
        
        try:
            prob.solve(solver=solver, verbose=False)
        except Exception:
            continue
        
        if prob.status not in ('optimal', 'optimal_inaccurate'):
            continue
        
        g_val = np.maximum(np.asarray(g_var.value, dtype=np.float64), 0.0)
        g_sum = g_val.sum()
        if g_sum < 1e-15:
            g_val = a.copy()
            g_sum = 1.0
        g_dir = g_val / g_sum
        
        # Line search for step size
        best_alpha = 2.0 / (t + 2.0)
        best_trial_M = M_curr
        
        # Try a few alphas
        alphas_to_try = [best_alpha, best_alpha * 0.5, best_alpha * 2.0, 
                         best_alpha * 0.75, best_alpha * 1.5]
        # Add FW default
        for alpha_try in alphas_to_try:
            alpha_try = np.clip(alpha_try, 1e-6, 0.5)
            a_trial = (1.0 - alpha_try) * a + alpha_try * g_dir
            a_trial = np.maximum(a_trial, 0.0)
            s = a_trial.sum()
            if s < 1e-15:
                continue
            a_trial = a_trial / s
            M_trial = fast_autocorr(a_trial).max()
            if M_trial < best_trial_M:
                best_trial_M = M_trial
                best_alpha = alpha_try
        
        a_new = (1.0 - best_alpha) * a + best_alpha * g_dir
        a_new = np.maximum(a_new, 0.0)
        s = a_new.sum()
        if s < 1e-15:
            a_new = a.copy()
        else:
            a_new = a_new / s
        
        a = a_new
        M_new = fast_autocorr(a).max()
        
        if M_new < best_M - 1e-16:
            best_M = M_new
            best_a = a.copy()
            # Tighten margin on improvement
            cur_margin = max(cur_margin * 0.95, 1e-5)
            # Increase K gradually
            if t % 100 == 0:
                cur_top_K = min(cur_top_K + 10, 600)
        else:
            # No improvement - relax margin slightly
            cur_margin = min(cur_margin * 1.1, margin_frac)
        
        if verbose and t % 10 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_M
            print(f"    FW iter={t} ({elapsed:.0f}s): J={J:.6f}, K={cur_top_K}, M={best_M:.8f}")
    
    return best_a, best_M


def coord_descent_polish(a0, time_limit, verbose=True, rng_seed=42):
    """
    Coordinate descent with subgradient-based updates for polishing.
    """
    n = len(a0)
    a = norm_sum1(a0)
    ac = fast_autocorr(a)
    best_M = ac.max()
    best_a = a.copy()
    t0 = time.monotonic()
    rng = np.random.default_rng(rng_seed)
    
    stall = 0
    max_stall = 200
    
    while time.monotonic() - t0 < time_limit and stall < max_stall:
        ac = fast_autocorr(a)
        M_curr = ac.max()
        
        # Find top contributing lags
        top_lags = np.argsort(ac)[::-1][:20]
        
        # For each top lag, find the coordinate that contributes most
        improved = False
        for k in top_lags:
            k_int = int(k)
            i_start = max(0, k_int - n + 1)
            i_end = min(n, k_int + 1)
            idx = np.arange(i_start, i_end)
            contrib = a[idx] * a[k_int - idx]
            
            # Find the coordinate with the largest contribution
            max_li = int(np.argmax(contrib))
            src = int(idx[max_li])
            src_val = a[src]
            
            if src_val < 1e-12:
                continue
            
            # Try reducing this coordinate and redistributing
            for frac in [0.01, 0.03, 0.05, 0.1]:
                amt = src_val * frac
                if amt < 1e-14:
                    continue
                
                # Try moving to a random location
                best_trial_M = M_curr
                best_move = None
                
                for _ in range(50):
                    dst = int(rng.integers(n))
                    if dst == src:
                        continue
                    a_trial = a.copy()
                    a_trial[src] -= amt
                    a_trial[dst] += amt
                    a_trial = np.maximum(a_trial, 0.0)
                    s_t = a_trial.sum()
                    if s_t < 1e-15:
                        continue
                    a_trial = a_trial / s_t
                    M_trial = fast_autocorr(a_trial).max()
                    if M_trial < best_trial_M:
                        best_trial_M = M_trial
                        best_move = (src, dst, amt)
                
                if best_move is not None:
                    src_i, dst_i, amt_m = best_move
                    a[src_i] -= amt_m
                    a[dst_i] += amt_m
                    a = np.maximum(a, 0.0)
                    a = a / a.sum()
                    if M_trial < best_M:
                        best_M = M_trial
                        best_a = a.copy()
                        stall = 0
                        improved = True
                    break
        
        if not improved:
            # Random perturbation
            i = int(rng.integers(n))
            j = int(rng.integers(n))
            if i != j and a[i] > 1e-10:
                frac = rng.uniform(0.005, 0.03)
                amt = a[i] * frac
                a[i] -= amt
                a[j] += amt
                a = np.maximum(a, 0.0)
                a = a / a.sum()
                M_new = fast_autocorr(a).max()
                if M_new < best_M:
                    best_M = M_new
                    best_a = a.copy()
                    stall = 0
                else:
                    stall += 1
        
        if verbose and stall % 50 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_M
            print(f"    CD ({elapsed:.0f}s): J={J:.6f}, stall={stall}")
    
    return best_a, best_M


def freq_perturb(a, strength=0.01, rng=None):
    n = len(a)
    fft_size = 1 << (2 * n - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    phase = np.angle(A)
    mag = np.abs(A)
    phase_pert = phase + rng.normal(0, strength, len(phase))
    A_new = mag * np.exp(1j * phase_pert)
    a_new = np.fft.irfft(A_new, fft_size)[:n]
    a_new = np.maximum(a_new, 0.0)
    s = a_new.sum()
    if s < 1e-15:
        return a.copy()
    return a_new / s


def try_update(a, best_seq, best_score, t_global, label=""):
    if a is None:
        return best_seq, best_score
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 0.01:
        return best_seq, best_score
    a_norm = a / s
    sc = evaluate_safe(a_norm)
    if np.is
