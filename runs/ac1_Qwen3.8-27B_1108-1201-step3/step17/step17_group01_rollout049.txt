term2[j] = sum_m w[j-m] * a[m] = sum_m a[m] * w[j-m] = corr(a, w)[j] (by symmetry of real cross-correlation)

Actually wait: corr(a, w)[j] = sum_k a[k+j] * w[k] = sum_m a[m] * w[m-j]... no.

Let me be very explicit:
corr(x, y)[j] = sum_k x[k+j] * y[k]

corr(a, w)[j] = sum_k a[k+j] * w[k]

I want term2[j] = sum_m a[m] * w[j-m]

Let k = j-m, so m = j-k:
term2[j] = sum_k a[j-k] * w[k]

This is: sum_k w[k] * a[j-k] = (w * a)[j] (convolution!)

So term2[j] = conv(w, a)[j] (the j-th element of the linear convolution of w and a).

And term1[j] = corr(w, a)[j] = sum_k w[k+j] * a[k]

In terms of convolution: corr(w, a)[j] = sum_k w[k+j]*a[k]. If I define w_flipped[k] = w[2n-2-k], then:
corr(w, a)[j] = sum_k w[k+j]*a[k] = conv(w_flipped, a)[j + 2n - 2 - ... ]

This is getting confusing. Let me just use the direct FFT computation.

For the full (linear) cross-correlation of vectors x (length L1) and y (length L2):
corr[x,y][j] = sum_k x[k+j]*y[k] for j = -(L1-1), ..., L2-1

Using FFT: pad both to length >= L1+L2-1, then:
corr = IFFT(conj(FFT(y)) * FFT(x))

The result has the positive lags in the first part and negative lags in the second part.

Let me just implement it carefully and test.

Actually, for our purposes, let me simplify. The gradient computation can be done more simply:

g[j] = (1/T) * sum_{k=0}^{2n-2} w[k] * (a[k-j]*I(0<=k-j<n) + a[j-k]*I(0<=j-k<n))

For the first part: fix j, sum over k where 0 <= k-j < n, i.e., j <= k <= j+n-1 (and k <= 2n-2).
So k ranges from j to min(j+n-1, 2n-2).
Sum = sum_{k=j}^{min(j+n-1, 2n-2)} w[k] * a[k-j] = sum_{m=0}^{min(n-1, 2n-2-j)} w[j+m] * a[m]

For the second part: fix j, sum over k where 0 <= j-k < n, i.e., j-n+1 <= k <= j (and k >= 0).
So k ranges from max(0, j-n+1) to j.
Sum = sum_{k=max(0,j-n+1)}^{j} w[k] * a[j-k] = sum_{m=0}^{min(j, n-1)} w[j-m] * a[m]

So:
g[j] = (1/T) * (sum_{m=0}^{min(n-1, 2n-2-j)} w[j+m]*a[m] + sum_{m=0}^{min(j, n-1)} w[j-m]*a[m])

The first sum is a cross-correlation of w and a (with w shifted).
The second sum is a convolution of w and a.

Both can be computed via FFT.

Let me define:
- w has length 2n-1
- a has length n

For the first sum: S1[j] = sum_{m=0}^{n-1} w[j+m]*a[m] (with w[j+m] = 0 if j+m >= 2n-1)
This is the cross-correlation (w ⋆ a)[j] = sum_m w[j+m]*a[m]

For the second sum: S2[j] = sum_{m=0}^{n-1} w[j-m]*a[m] (with w[j-m] = 0 if j-m < 0 or j-m >= 2n-1)
This is the convolution (w * a)[j] = sum_m w[j-m]*a[m]

So g = (S1 + S2) / T

And:
S1 = cross-correlation of w and a = IFFT(conj(FFT(a)) * FFT(w)) (with proper zero-padding)
S2 = convolution of w and a = IFFT(FFT(w) * FFT(a)) (with proper zero-padding)

Both need zero-padding to length >= (2n-1) + n - 1 = 3n-2.

This is efficient! O(n log n) per gradient step.

Now, the algorithm becomes:
1. Start with initial a (normalized to sum=1, non-negative)
2. Compute gradient g of smooth_max(conv(a,a), T)
3. Update: a_new = a - eta * g, then project to a >= 0 and normalize
4. Decrease T over time (from large to small, making the approximation sharper)
5. Adapt eta via backtracking

This is a much smoother optimization than the subgradient method, and should give better results.

Let me also add:
- Periodic frequency-domain "smoothing" steps
- Multiple restarts
- Different T schedules

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Smooth-max gradient descent with annealed temperature (exponential softmax)
2. Frequency-domain spectrum flattening (iterative projection)
3. Subgradient method with softmax-weighted peaks
4. Multi-start with diverse initializations
5. Adaptive step size with backtracking line search
"""

import numpy as np
import time

def fast_autocorr(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(np.asarray(a, dtype=np.float64), fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def evaluate_safe(a):
    try:
        a_list = [float(x) for x in np.asarray(a, dtype=np.float64)]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')

def norm_sum1(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s

def smooth_max_gradient(a, T):
    """Compute gradient of (1/T)*sum_k exp(conv[k]/T) w.r.t. a.
    This approximates the subgradient of max(conv) as T -> 0."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    conv = np.fft.irfft(A * A, fft_size)[:size]
    
    # Softmax weights (shift for numerical stability)
    conv_shifted = conv - conv.max()
    w = np.exp(conv_shifted / T)
    
    # Need cross-correlation and convolution of w (length 2n-1) and a (length n)
    # Both need padding to >= 3n-2
    corr_size = 1 << (3 * n - 1).bit_length()
    A_pad = np.fft.rfft(a, corr_size)
    W_pad = np.fft.rfft(w, corr_size)
    
    # S1[j] = sum_m w[j+m]*a[m] = cross-correlation(w, a)[j], first n elements
    S1 = np.fft.irfft(np.conj(A_pad) * W_pad, corr_size)[:n]
    
    # S2[j] = sum_m w[j-m]*a[m] = convolution(w, a)[j], first n elements
    S2 = np.fft.irfft(W_pad * A_pad, corr_size)[:n]
    
    g = (S1 + S2) / T
    return g, conv.max()

def smooth_max_optimize(a0, time_limit, T_start=0.1, T_end=0.005, verbose=False):
    """Optimize using smooth-max gradient descent with annealed temperature."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    
    total_iters = 5000  # will be limited by time
    eta = 0.01  # initial step size
    
    for it in range(total_iters):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Anneal temperature
        progress = it / total_iters
        T = T_start * (T_end / T_start) ** progress
        
        # Compute gradient
        g, M_curr = smooth_max_gradient(a, T)
        
        # Normalize gradient (by its norm) for stable stepping
        g_norm = np.linalg.norm(g)
        if g_norm < 1e-15:
            break
        g = g / g_norm
        
        # Mirror descent step (exponential family)
        eta_t = eta * (1.0 / (1.0 + 0.1 * it / 100.0))
        log_a = np.log(np.maximum(a, 1e-15)) - eta_t * g
        a_new = np.exp(log_a - log_a.max())
        a_new = a_new / a_new.sum()
        
        # Evaluate
        M_new = fast_autocorr(a_new).max()
        if M_new < best_m:
            best_m = M_new
            best_a = a_new.copy()
            a = a_new
        else:
            # Backtrack: try smaller step
            accepted = False
            for frac in [0.5, 0.25, 0.1, 0.05]:
                a_try = a + frac * (a_new - a)
                a_try = np.maximum(a_try, 0.0)
                s_try = a_try.sum()
                if s_try < 1e-15:
                    break
                a_try = a_try / s_try
                M_try = fast_autocorr(a_try).max()
                if M_try < best_m:
                    best_m = M_try
                    best_a = a_try.copy()
                    a = a_try
                    accepted = True
                    break
            if not accepted:
                # Accept with damping regardless (to make progress)
                a = 0.5 * a + 0.5 * a_new
                a = norm_sum1(a)
            
        if verbose and it % 500 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print(f"    SmoothMax it={it} ({elapsed:.0f}s): J={J:.6f}, T={T:.4f}")
    
    return best_a, best_m

def subgradient_optimize_v2(a0, time_limit, verbose=False):
    """Improved subgradient method with softmax-weighted peaks and backtracking."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(42)
    
    eta = 0.1 / np.sqrt(n)
    stall = 0
    
    for it in range(100000):
        if time.monotonic() - t0 > time_limit:
            break
        
        ac = fast_autocorr(a)
        M_curr = ac.max()
        
        # Softmax-weighted subgradient
        ac_shifted = ac - ac.max()
        T_sg = 0.02 * M_curr  # temperature for softmax
        w = np.exp(ac_shifted / T_sg)
        w = w / w.sum()
        
        # Compute gradient: sum_k w[k] * d(conv[k])/da
        # d(conv[k])/da[j] = a[k-j] (if valid) + a[j-k] (if valid)
        # = corr(w, a)[j] + conv(w, a)[j] (as derived)
        size = 2 * n - 1
        corr_size = 1 << (3 * n - 1).bit_length()
        A_pad = np.fft.rfft(a, corr_size)
        W_pad = np.fft.rfft(w, corr_size)
        
        S1 = np.fft.irfft(np.conj(A_pad) * W_pad, corr_size)[:n]
        S2 = np.fft.irfft(W_pad * A_pad, corr_size)[:n]
        g = S1 + S2
        
        # Normalize
        g_norm = g.max()
        if g_norm < 1e-15:
            break
        g = g / g_norm
        
        # Mirror descent update
        log_a = np.log(np.maximum(a, 1e-15)) - eta * g
        a_new = np.exp(log_a - log_a.max())
        a_new = a_new / a_new.sum()
        
        M_new = fast_autocorr(a_new).max()
        if M_new < best_m:
            best_m = M_new
            best_a = a_new.copy()
            a = a_new
            stall = 0
            eta = min(eta * 1.05, 1.0)  # increase step slightly
        else:
            stall += 1
            eta *= 0.95  # decrease step
            # Damped acceptance
            a = 0.3 * a + 0.7 * a_new
            a = norm_sum1(a)
        
        # Periodic restart
        if stall > 500:
            pert = rng.normal(0, 0.01, n) * best_a
            a = best_a + pert
            a = norm_sum1(a)
            stall = 0
            eta = 0.1 / np.sqrt(n)
        
        if verbose and it % 200 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print(f"    SG-v2 it={it} ({elapsed:.0f}s): J={J:.6f}, eta={eta:.4f}")
    
    return best_a, best_m

def freq_flatten_v2(a0, time_limit, verbose=False):
    """Improved frequency-domain flattening with adaptive compression."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    
    fft_size = 1 << (2 * n - 1).bit_length()
    
    for it in range(10000):
        if time.monotonic() - t0 > time_limit:
            break
        
        A = np.fft.rfft(a, fft_size)
        P = np.abs(A) ** 2
        P_mean = P.mean()
        
        if P_mean < 1e-30:
            break
        
        # Adaptive compression: target is geometric mean
        ratio = P / P_mean
        # Compress: P_new = P_mean * ratio^alpha where alpha < 1
        alpha = 0.5 + 0.3 * (it / 10000.0)  # start at 0.5, go to 0.8
        
        P_new = P_mean * np.power(ratio, alpha)
        P_new = np.maximum(P_new, 1e-30)
        
        mag_new = np.sqrt(P_new)
        phase = np.angle(A)
        A_new = mag_new * np.exp(1j * phase)
        
        a_new = np.fft.irfft(A_new, fft_size)[:n]
        a_new = np.maximum(a_new, 0.0)
        s_new = a_new.sum()
        if s_new < 1e-15:
            continue
        a_new = a_new / s_new
        
        M_new = fast_autocorr(a_new).max()
        if M_new < best_m:
            best_m = M_new
            best_a = a_new.copy()
            a = a_new
        else:
            # Try different alpha
            alpha2 = alpha - 0.1
            if alpha2 > 0.1:
                P_new2 = P_mean * np.power(ratio, alpha2)
                P_new2 = np.maximum(P_new2, 1e-30)
                mag_new2 = np.sqrt(P_new2)
                A_new2 = mag_new2 * np.exp(1j * phase)
                a_new2 = np.fft.irfft(A_new2, fft_size)[:n]
                a_new2 = np.maximum(a_new2, 0.0)
                s_new2 = a_new2.sum()
                if s_new2 > 1e-15:
                    a_new2 = a_new2 / s_new2
                    M_new2 = fast_autocorr(a_new2).max()
                    if M_new2 < best_m:
                        best_m = M_new2
                        best_a = a_new2.copy()
                        a = a_new2
                    else:
                        a = norm_sum1(0.5 * a + 0.5 * a_new2)
                else:
                    a = norm_sum1(0.7 * a + 0.3 * a_new)
            else:
                a = norm_sum1(0.7 * a + 0.3 * a_new)
        
        if verbose and it % 500 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print(f"    FreqFlat it={it} ({elapsed:.0f}s): J={J:.6f}")
    
    return best_a, best_m

def mixed_optimize(a0, time_limit, verbose=False):
    """Combine smooth-max gradient with frequency flattening and subgradient."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()

    t_smooth = time_limit * 0.4
    a, m = smooth_max_optimize(a, t_smooth, T_start=0.1, T_end=0.01)
    if m < best_m:
        best_m = m
        best_a = a.copy()
    
    # Phase B: Frequency domain (20% of time)
    remaining = time_limit - (time.monotonic() - t0)
    if remaining > 5:
        t_freq = remaining * 0.4
        a, m = freq_flatten_v2(best_a, t_freq)
        if m < best_m:
            best_m = m
            best_a = a.copy()
    
    # Phase C: Subgradient v2 (25% of time)
    remaining = time_limit - (time.monotonic() - t0)
    if remaining > 5:
        a, m = subgradient_optimize_v2(best_a, remaining * 0.6)
        if m < best_m:
            best_m = m
            best_a = a.copy()
    
    # Phase D: Final smooth-max polish
    remaining = time_limit - (time.monotonic() - t0)
    if remaining > 5:
        a, m = smooth_max_optimize(best_a, remaining, T_start=0.05, T_end=0.005)
        if m < best_m:
            best_m = m
            best_a = a.copy()

def make_init_power_law(n, power, center=False):
    x = np.arange(1, n + 1, dtype=np.float64)
    if center:
        x = np.abs(x - (n + 1) / 2.0) + 1.0
        a = x ** (-power)
    else:
        a = x ** power
    return norm_sum1(a)

def make_init_cosine(n, mode=1):
    x = np.linspace(0, 1, n)
    a = np.cos(np.pi * mode * (x - 0.5)) ** 2
    a = np.maximum(a, 0.0)
    return norm_sum1(a)

def make_init_sinc(n, bandwidth=5.0):
    x = np.linspace(0, 1, n)
    t = (x - 0.5) * bandwidth
    a = np.sinc(t) ** 2
    a = np.maximum(a, 0.0)
    return norm_sum1(a)

def make_init_multihump(n, n_humps=3, spread=0.15):
    x = np.linspace(0, 1, n)
    a = np.zeros(n)
    for i in range(n_humps):
        center = (i + 1) / (n_humps + 1)
        a += np.exp(-((x - center) ** 2) / (2 * spread ** 2))
    a += 0.01
    return norm_sum1(a)

def make_init_smooth_random(n, seed=0, n_freq=8):
    rng = np.random.default_rng(seed)
    x = np.linspace(0, 1, n)
    a = np.ones(n) * 0.5
    for f in range(1, n_freq + 1):
        coeff = rng.normal(0, 0.15 / np.sqrt(f))
        phase = rng.uniform(0, 2 * np.pi)
        a += coeff * np.sin(2 * np.pi * f * x + phase)
    a = np.maximum(a, 0.001)
    return norm_sum1(a)

def interpolate_seq(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss

def coordinate_polish(a0, time_limit, verbose=False, rng_seed=42):
    """Targeted coordinate descent on the peak lags."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(rng_seed)
    
    stall = 0
    
    while time.monotonic() - t0 < time_limit and stall < 100:
        ac = fast_autocorr(a)
        M_curr = ac.max()
        top_k = np.argsort(ac)[::-1][:10]
        
        improved = False
        for k in top_k:
            if time.monotonic() - t0 > time_limit:
                break
            k_int = int(k)
            
            # Find the pair (i, j) with i+j = k_int that maximizes a[i]*a[j]
            i_start = max(0, k_int - n + 1)
            i_end = min(n - 1, k_int)
            if i_start > i_end:
                continue
            
            idx = np.arange(i_start, i_end + 1)
            pairs = a[idx] * a[k_int - idx]
            src = idx[np.argmax(pairs)]
            dst_partner = k_int - src
            
            if a[src] < 1e-12:
                continue
            
            # Try moving mass from src to a position that reduces the peak
            # Find position with lowest "contribution" to top peaks
            # Simple heuristic: try random positions
            for _ in range(5):
                dst = int(rng.integers(n))
                if dst == src or dst == dst_partner:
                    continue
                
                for frac in [0.05, 0.1, 0.2, 0.3]:
                    amt = a[src] * frac
                    a_trial = a.copy()
                    a_trial[src] -= amt
                    a_trial[dst] += amt
                    a_trial = np.maximum(a_trial, 0.0)
                    s_t = a_trial.sum()
                    if s_t < 1e-15:
                        continue
                    a_trial = a_trial / s_t
                    M_trial = fast_autocorr(a_trial).max()
                    if M_trial < best_m - 1e-16:
                        a = a_trial
                        best_m = M_trial
                        best_a = a.copy()
                        improved = True
                        stall = 0
                        break
                if improved:
                    break
        
        if not improved:
            stall += 1
            # Random perturbation
            i = int(rng.integers(n))
            j = int(rng.integers(n))
            if i != j and a[i] > 1e-10:
                frac = rng.uniform(0.01, 0.05)
                amt = a[i] * frac
                a[i] -= amt
                a[j] += amt
                a = np.maximum(a, 0.0)
                s_t = a.sum()
                if s_t > 1e-15:
                    a = a / s_t
                    M_new = fast_autocorr(a).max()
                    if M_new < best_m:
                        best_m = M_new
                        best_a = a.copy()
                        stall = 0
    
    return best_a, best_m
