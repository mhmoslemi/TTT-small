This is only possible if |F(m)|^2 is constant (all equal to N*S^2/(2n-1)... wait, sum of |F(m)|^2 = N * sum(a^2) by Parseval. And sum_k (a*a)_k = S^2. If (a*a)_k = S^2/(2n-1) for all k in [0,2n-2], then the sum is (2n-1)*S^2/(2n-1) = S^2. ✓

But for the periodic extension to be constant for ALL k (mod N), we need:
(1/N) sum_m |F(m)|^2 * exp(2πi*m*k/N) = S^2/(2n-1) for all k

This means |F(m)|^2 must be: |F(0)|^2 = N*S^2/(2n-1) and |F(m)|^2 = 0 for m != 0.

But |F(0)|^2 = S^2, and N*S^2/(2n-1) = S^2 only if N = 2n-1. So if N = 2n-1, we need |F(m)|^2 = S^2 for m=0 and 0 for m != 0. This means F is a delta at the origin, which means a is constant. And indeed, for constant a, (a*a)_k = (n-k)*c^2 for k=0,...,n-1 and (n+k)*c^2 for k=n,...,2n-2, which is NOT constant.

So the "ideal" flat autocorrelation is not achievable with a non-negative sequence of finite length. The best we can do is approximate it.

Let me think about this differently. For a constant sequence a_j = c, we get:
(a*a)_k = (n-|k|)*c^2 for 0 <= |k| < n
sum(a) = n*c

For a triangular sequence (a_j = c*(n-|j-(n-1)/2|)), the autocorrelation is more peaked.

For a "random" non-negative sequence, the autocorrelation has fluctuations of order c^2*sqrt(n) around the mean c^2*n/(2n-1)... roughly.

The key point is that we need the sequence to be "band-limited" in some sense to reduce the autocorrelation peaks. A sinc-like sequence (which is band-limited) would have a flatter autocorrelation.

But a sinc-like sequence has negative lobes, which violates the non-negativity constraint. So we need to find the best non-negative approximation to a band-limited signal.

**New approach: Constrained frequency-domain optimization**

1. Work in the frequency domain
2. The constraint a >= 0 becomes: IDFT(F) >= 0
3. The constraint sum(a) = 1 becomes: F(0) = 1 (real and positive, since a >= 0)
4. The objective is to minimize max_k (a*a)_k, which in the frequency domain is related to making |F|^2 as flat as possible

Algorithm:
1. Initialize F with a "flat" spectrum (|F(m)| = 1/sqrt(N) for all m, with appropriate DC)
2. Iterate:
   a. Compute a = IDFT(F)
   b. Project a onto the non-negative simplex (set negative entries to 0, renormalize)
   c. Compute F_new = DFT(a)
   d. Modify |F_new| to be flatter: |F_new|(m) = |F_new|(m) * (target/|F_new|(m))^alpha for m != 0
   e. Keep the phase of F_new
   f. Set F = F_new_modified
3. Repeat

**Approach: Minimize the log-sum-exp of autocorrelation values**

Instead of minimizing max_k (a*a)_k (which is non-smooth), minimize:
L(a) = (1/T) * log(sum_k exp(T * (a*a)_k / S^2))

As T -> infinity, this approaches max_k (a*a)_k / S^2. For moderate T, it's a smooth approximation that's easier to optimize.

The gradient of L(w.r.t. a) can be computed analytically:
∂L/∂a_j = (1/T) * (sum_k exp(T*(a*a)_k/S^2) * ∂(a*a)_k/∂a_j) / (sum_k exp(T*(a*a)_k/S^2))
        = sum_k p_k * ∂(a*a)_k/∂a_j / S^2

where p_k = exp(T*(a*a)_k/S^2) / sum_l exp(T*(a*a)_l/S^2)

This is a weighted average of the gradients of all autocorrelation values, weighted by a softmax. For large T, this concentrates on the maximum; for small T, it's more spread out.

Now, np.convolve for arrays of length n and 2n-1 will use FFT internally (numpy uses scipy's FFT for large enough arrays). For n=5000, this should be fast.

Actually, I realize I can compute this even more efficiently using the FFT directly:

```python
def compute_grad_fast(a, weights):
    n = len(a)
    w = weights[::-1]  # flip
    fft_size = 1 << (3*n - 2).bit_length()  # need at least 3n-2
    A = np.fft.rfft(a, fft_size)
    W = np.fft.rfft(w, fft_size)
    conv = np.fft.irfft(A * W, fft_size)[:3*n-2]
    return 2.0 * conv[2*n-2 : n-2 : -1]
```

This is O(n log n) which is great.

Now let me put together the full algorithm:

1. **Main optimization loop**: Use log-sum-exp subgradient with adaptive step size (Adam-like).
2. **Spectral equalization**: Periodically modify the spectrum to flatten it.
3. **Multi-length search**: Try a few different lengths.
4. **Smart restarts**: When stalled, perturb the sequence and restart.

Let me also think about the step size. For the log-sum-exp objective:
L(a) = (1/T) log(sum_k exp(T * ac[k] / S^2))

The Lipschitz constant of the gradient is roughly 2*T*max(a) (since each ac[k] is a quadratic form with eigenvalues of order max(a)).

For Adam, the step size is alpha / (sqrt(t) + eps) or a fixed alpha. Let me use a fixed alpha with decay.

Actually, for the normalized problem (sum(a) = 1), the components of a are at most 1 (and typically around 1/n for a uniform distribution). So the gradient magnitude is of order 2/n. A step size of about 1 should give reasonable progress.

Let me now write the complete code:

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Log-sum-exp subgradient with Adam optimizer
2. Periodic spectral equalization (frequency domain flattening)
3. Multi-length search with interpolation
4. Adaptive restarts with spectral diversification
5. Final coordinate descent polish
"""

import numpy as np
import time

def fast_autocorr(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(np.asarray(a, dtype=np.float64), fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def compute_grad_lse(a, ac, T):
    """Compute subgradient of (1/T)*log(sum exp(T*ac_k)) w.r.t. a."""
    n = len(a)
    ac_shifted = ac - ac.max()
    weights = np.exp(T * ac_shifted)
    w_sum = weights.sum()
    if w_sum < 1e-300:
        return np.ones(n) / n
    weights /= w_sum
    
    # grad[j] = 2 * sum_{l=0}^{n-1} a[l] * weights[l+j]
    w_flip = weights[::-1]
    conv = np.convolve(a, w_flip, mode='full')
    grad = 2.0 * conv[2*n-2 : n-2 : -1]
    return grad

def norm_nonneg(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s

def evaluate_safe(a):
    try:
        a_list = [float(x) for x in np.asarray(a, dtype=np.float64)]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss

def make_initializations(n, rng):
    """Generate diverse initializations."""
    inits = []
    labels = []
    
    # Sinc-like (band-limited)
    for bw in [3.0, 5.0, 8.0, 12.0]:
        x = np.linspace(0, 1, n)
        t = (x - 0.5) * bw
        a = np.sinc(t) ** 2
        a = np.maximum(a, 0.001)
        inits.append(norm_nonneg(a))
        labels.append(f"sinc_{bw}")
    
    # Power law
    for p in [0.3, 0.5, 1.0, 1.5]:
        x = np.arange(1, n+1, dtype=np.float64)
        a = x ** (-p)
        inits.append(norm_nonneg(a))
        labels.append(f"pow_{p}")
    
    # Cosine modes
    for mode in [1, 2, 3]:
        x = np.linspace(0, 1, n)
        a = np.cos(np.pi * mode * (x - 0.5)) ** 2
        a = np.maximum(a, 0.0)
        inits.append(norm_nonneg(a))
        labels.append(f"cos_{mode}")
    
    # Random smooth
    for seed in [1, 42, 123]:
        x = np.linspace(0, 1, n)
        a = np.ones(n) * 0.5
        for f in range(1, 15):
            coeff = rng.normal(0, 0.1 / np.sqrt(f))
            phase = rng.uniform(0, 2*np.pi)
            a += coeff * np.sin(2*np.pi*f*x + phase)
        a = np.maximum(a, 0.001)
        inits.append(norm_nonneg(a))
        labels.append(f"rand_{seed}")
    
    # Multi-hump
    for n_humps in [3, 5, 7]:
        x = np.linspace(0, 1, n)
        a = np.zeros(n)
        for i in range(n_humps):
            center = (i + 1) / (n_humps + 1)
            a += np.exp(-((x - center)**2) / (2 * 0.15**2))
        a += 0.01
        inits.append(norm_nonneg(a))
        labels.append(f"hump_{n_humps}")
    
    return inits, labels

def adam_lse_optimize(a0, time_limit, T_init=5.0, T_max=500.0, alpha=0.5, 
                       spectral_interval=500, verbose=False, rng_seed=42):
    """Adam optimizer with log-sum-exp subgradient and periodic spectral equalization."""
    n = len(a0)
    a = norm_nonneg(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    
    # Adam state
    m_v = np.zeros(n)
    v_v = np.zeros(n)
    t_step = 0
    
    # Adaptive T (temperature for softmax)
    T = T_init
    
    # Track progress for adaptive T
    prev_m = best_m
    
    while time.monotonic() - t0 < time_limit:
        t_step += 1
        
        # Adaptive T: increase T as we converge (more focused on the max)
        # But not too fast
        T = min(T_max, T * (1.0 + 0.001 * t_step))
        
        # Compute autocorrelation and subgradient
        ac = fast_autocorr(a)
        M_curr = ac.max()
        
        # Update best
        if M_curr < best_m - 1e-15:
            best_m = M_curr
            best_a = a.copy()
        
        # Compute log-sum-exp subgradient
        g = compute_grad_lse(a, ac, T)
        
        # Adam update
        beta1, beta2, eps = 0.9, 0.999, 1e-8
        alpha_t = alpha / (1.0 + 0.01 * t_step / 1000)
        
        m_v = beta1 * m_v + (1 - beta1) * g
        v_v = beta2 * v_v + (1 - beta2) * g**2
        m_hat = m_v / (1 - beta1**t_step)
        v_hat = v_v / (1 - beta2**t_step)
        
        # Update in log space (to maintain non-negativity)
        log_a = np.log(a + 1e-30) - alpha_t * m_hat / (np.sqrt(v_hat) + eps)
        max_log = log_a.max()
        a_new = np.exp(log_a - max_log)
        a_new = np.maximum(a_new, 1e-15)
        a_new = a_new / a_new.sum()
        
        # Periodic spectral equalization
        if t_step % spectral_interval == 0:
            fft_size = 1 << (2*n - 1).bit_length()
            A = np.fft.rfft(a_new, fft_size)
            P = np.abs(A)**2
            P_mean = P.mean()
            if P_mean > 1e-30:
                # Compress dynamic range
                eta = 0.3 + 0.3 * min(1.0, t_step / 5000)
                P_target = P_mean * (P / P_mean) ** (1.0 - eta)
                P_target = np.maximum(P_target, 1e-30)
                phase = np.angle(A)
                A_new = np.sqrt(P_target) * np.exp(1j * phase)
                a_spec = np.fft.irfft(A_new, fft_size)[:n]
                a_spec = np.maximum(a_spec, 0.0)
                a_spec_sum = a_spec.sum()
                if a_spec_sum > 1e-15:
                    a_spec = a_spec / a_spec_sum
                    M_spec = fast_autocorr(a_spec).max()
                    if M_spec < best_m:
                        best_m = M_spec
                        best_a = a_spec.copy()
                        a_new = a_spec
                    else:
                        a_new = 0.5 * a_new + 0.5 * a_spec
                        a_new = norm_nonneg(a_new)
        
        a = a_new
        
        if verbose and t_step % 500 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print(f"      Adam t={t_step} ({elapsed:.0f}s): J={J:.6f}, T={T:.1f}")
    
    return best_a, best_m

def spectral_equalize(a, eta=0.5, iters=100):
    """Iterative spectral flattening."""
    n = len(a)
    a_curr = a.copy()
    best_a = a_curr.copy()
    best_m = fast_autocorr(a_curr).max()
    
    for it in range(iters):
        fft_size = 1 << (2*n - 1).bit_length()
        A = np.fft.rfft(a_curr, fft_size)
        P = np.abs(A)**2
        P_mean = P.mean()
        if P_mean < 1e-30:
            break
        
        P_target = P_mean * (P / P_mean) ** (1.0 - eta)
        P_target = np.maximum(P_target, 1e-30)
        phase = np.angle(A)
        A_new = np.sqrt(P_target) * np.exp(1j * phase)
        a_new = np.fft.irfft(A_new, fft_size)[:n]
        a_new = np.maximum(a_new, 0.0)
        s = a_new.sum()
        if s < 1e-15:
            break
        a_new = a_new / s
        
        M_new = fast_autocorr(a_new).max()
        if M_new < best_m:
            best_m = M_new
            best_a = a_new.copy()
            a_curr = a_new
        else:
            a_curr = 0.7 * a_curr + 0.3 * a_new
            a_curr = norm_nonneg(a_curr)
    
    return best_a, best_m

def coordinate_polish(a0, time_limit, rng_seed=42):
    """Simple coordinate descent: move mass from high-contributing positions."""
    n = len(a0)
    a = norm_nonneg(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(rng_seed)
    
    stall = 0
    max_stall = 500
    
    while time.monotonic() - t0 < time_limit and stall < max_stall:
        ac = fast_autocorr(a)
        M_curr = ac.max()
        
        if M_curr < best_m - 1e-15:
            best_m = M_curr
            best_a = a.copy()
            stall = 0
        
        # Find the top contributing positions for the max peak
        k_max = int(np.argmax(ac))
        # For peak at k_max, the contributing pairs are (i, k_max-i)
        js = max(0, k_max - n + 1)
        je = min(n - 1, k_max)
        if js > je:
            stall += 1
            continue
        
        idx = np.arange(js, je + 1)
        pairs = [(i, k_max - i) for i in idx]
        contribs = np.array([a[i] * a[k_max - i] for i in idx])
        
        # Find the pair with max contribution
        max_idx = np.argmax(contribs)
        i_src = int(idx[max_idx])
        j_src = int(k_max - i_src)
        
        if i_src == j_src:
            # Only one element to modify
            if a[i_src] < 1e-12:
                stall += 1
                continue
            # Try reducing a[i_src]
            for frac in [0.01, 0.02, 0.05, 0.1]:
                amt = a[i_src] * frac
                a_trial = a.copy()
                a_trial[i_src] -= amt
                # Distribute to random positions
                dsts = rng.choice(n, size=min(5, n), replace=False)
                for dst in dsts:
                    a_trial[dst] += amt / len(dsts)
                a_trial = np.maximum(a_trial, 0)
                a_trial = a_trial / a_trial.sum()
                M_trial = fast_autocorr(a_trial).max()
                if M_trial < best_m - 1e-15:
                    a = a_trial
                    best_m = M_trial
                    best_a = a.copy()
                    stall = 0
                    break
        else:
            # Try moving mass from the larger of the two
            if a[i_src] >= a[j_src]:
                src = i_src
            else:
                src = j_src
            
            if a[src] < 1e-12:
                stall += 1
                continue
            
            # Find a good destination (low autocorrelation contribution)
            # Compute "cost" of each position
            costs = np.zeros(n)
            for k2 in np.argsort(ac)[::-1][:10]:
                k2i = int(k2)
                d = src - k2i
                if 0 <= d < n:
                    costs[src] += ac[k2i]
                d2 = k2i - src
                if 0 <= d2 < n:
                    costs[src] += ac[k2i]
            
            # Choose destination with low current value and low cost
            candidates = np.argsort(a)[:n//2]
            # Further filter by cost
            candidate_costs = np.array([sum(ac[max(0,k)-d:min(2*n-1, k-d+1)] for k in [0]) for d in candidates[:50]])
            # Simplified: just pick from low-value positions
            dst = candidates[rng.integers(min(20, len(candidates)))]
            
            if dst == src:
                dst = rng.integers(n)
                if dst == src:
                    stall += 1
                    continue
            
            for frac in [0.005, 0.01, 0.02, 0.05, 0.1]:
                amt = a[src] * frac
                a_trial = a.copy()
                a_trial[src] -= amt
                a_trial[dst] += amt
                a_trial = np.maximum(a_trial, 0)
                a_trial = a_trial / a_trial.sum()
                M_trial = fast_autocorr(a_trial).max()
                if M_trial < best_m - 1e-15:
                    a = a_trial
                    best_m = M_trial
                    best_a = a.copy()
                    stall = 0
                    break
        
        stall += 1 if M_curr >= best_m - 1e-15 else 0
    
    return best_a, best_m
