For optimization, we want to minimize f(a) subject to sum(a) = 1 and a >= 0.

This is a convex optimization problem! (f is convex as a pointwise max of linear functions in a... wait, no. conv(a,a)[k] = sum a[i]*a[k-i] is NOT linear in a. It's quadratic!)

So the problem is actually NON-convex. The function max_k sum_i a[i]*a[k-i] is not convex in a (it's a ratio of quadratic forms, or rather, the max of quadratic forms).

This explains why the LP-based Frank-Wolfe approach was used: they linearize the problem by fixing one side of the convolution.

In the LP approach: fix y (current iterate), and solve for g that minimizes max_k (y * g)[k] subject to g >= 0, sum(g) = 1. This is a linear program because (y*g)[k] = sum_i y[i]*g[k-i] is linear in g for fixed y.

Then update: a_new = (1-t)*a + t*g.

This is the classic Frank-Wolfe / conditional gradient approach for non-convex problems (it's actually a variant of the "alternating direction" or "block coordinate descent" where we linearize one variable at a time).

Let me think about improvements to this approach:

1. **Better LP formulation**: Instead of just minimizing the max, we could use a "soft" max (sum of exponentials) or an l_p norm to get a smoother objective.

2. **Multiple linearization points**: Instead of a single y, use an average of recent iterates.

3. **Adaptive step size**: Use backtracking line search.

4. **Better initialization**: Use a shape that's known to be good.

5. **Post-processing**: After the main optimization, do coordinate descent or local search.

6. **Different norm**: Instead of minimizing the max, minimize the l_p norm of the autocorrelation for p > 1, which might give a better maximum after optimization.

        # = sum_{k=j}^{n-1} w[k]*a[k-j]  (since k-j >= 0 means k >= j)
        # Let m = k-j: h[j] = sum_{m=0}^{n-1-j} w[m+j]*a[m]
        # This is the cross-correlation: h = np.correlate(w, a, mode='valid')? No...
        
        # Let me just use FFT:
        # h[j] = sum_k w[k] * a[k-j] (with a[m] = 0 for m outside [0,n-1])
        # Define W extended to length 2n-1 (same as convolution output)
        # h is the "anti-convolution" or "cross-correlation"
        # h[j] = sum_k w[k] * a[k-j]
        # If we define w_pad[2n-1-k] (reverse of w), then:
        # (w_reversed * a)[n-1+j] = sum_i w_reversed[i] * a[n-1+j-i]
        # = sum_i w[2n-1-1-i] * a[n-1+j-i]  ... this is getting complicated.
        
        # Simplest: just use the FFT of the product.
        # The gradient g[j] = 2 * sum_k w[k] * a[k-j] for valid k-j
        # Note that sum_k w[k] * a[k-j] is the cross-correlation of w and a at lag j.
        # Cross-correlation: (w ⋆ a)[j] = sum_k w[k] * conj(a[k-j])
        # For real: (w ⋆ a)[j] = sum_k w[k] * a[k-j]
        # In FFT: FFT(w ⋆ a) = conj(FFT(w)) * FFT(a)
        # So: g = 2 * ifft(conj(fft(w)) * fft(a))
        
        Wf2 = np.fft.rfft(w_padded, fs)  # w padded to length fs
        Yf2 = np.fft.rfft(a_padded, fs)
        g_full = np.fft.irfft(np.conj(Wf2) * Yf2, fs)
        # g_full has the cross-correlation, and we want the first n elements (lags 0 to n-1)
        # Actually, cross-correlation at lag j: sum_k w[k]*a[k-j]
        # The FFT gives us all lags from -(n-1) to n-1.
        # We want j = 0, 1, ..., n-1.
        # In the irfft output of length fs, the lag 0 is at position 0, lag 1 at position 1, etc.
        # But for negative lags, they wrap around.
        # Actually, for the product conj(Wf) * Yf:
        # ifft(conj(Wf)*Yf)[j] = (1/fs) * sum_k conj(W[k]) * Y[k] * exp(2πijk/fs)
        # = (1/fs) * sum_k conj(W[k]) * Y[k] * exp(2πijk/fs)
        # This is the cross-correlation: (w ⋆ y)[j] = sum_m w[m] * y[m-j]
        # So g_full[j] for j = 0, ..., n-1 gives us the cross-correlation at non-negative lags.
        
        g = 2.0 * g_full[:n]
        # But we also need to handle the fact that the cross-correlation is defined for all lags,
        # and some terms might be "missing" due to the finite length.
        # For our purpose, this should be fine as an approximation.
        
        # Mirror descent step
        eta = step_size / (np.sqrt(t) + 1)
        log_a = np.log(y) - eta * g
        log_a -= log_a.max
        a_new = np.exp(log_a)
        a_new = np.maximum(a_new, 1e-30)
