Looking at the LP formulation again: "maximizing sum_j b_j subject to b_j >= 0 and ||f*g_0||_inf <= M"

Here f*g_0 is the cross-correlation (or convolution) of f with the new direction g_0. The idea is to find a direction that, when mixed with the current f, reduces the peak of the autocorrelation.

This is a Frank-Wolfe-style approach where:
1. Current point: f (normalized, sum=1)
2. We want to minimize ||f*f||_inf
3. Subgradient of ||f*f||_inf at f is: for the active lag k*, the subgradient is 2*P_{k*}(f) where P_{k*}(f)[j] = f[k*-j] (the contribution to lag k*)
4. Frank-Wolfe step: find g that minimizes <subgrad, g> subject to g >= 0, sum(g) = 1
   This is equivalent to: minimize sum_j subgrad[j]*g[j] s.t. g >= 0, sum(g) = 1
   The LP in the paper is slightly different - it's maximizing sum(g) subject to ||f*g||_inf <= M, which is a different (but related) LP.

For efficient computation: if we have the FFT of a (zero-padded) and the FFT of h (zero-padded), then the cross-corlation can be computed as IFFT(FFT(a) * conj(FFT(h))). But this gives circular cross-correlation. For linear, we need sufficient zero-padding.

Actually, the simplest approach: if K (number of active lags) is small (say < n/4), just compute g directly in O(K*n). For K close to n, use FFT.

Given n = 3200, even O(K*n) with K=100 is 320,000 operations per iteration, which is fast.

Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. FFT-based adaptive subgradient (mirror descent) with dynamic active sets
2. LP-based Frank-Wolfe for directional guidance
3. Multi-start with diverse parametric initializations
4. Length interpolation and final polishing
Key innovations: dual-variable tracking, soft active set selection,
parametric shape exploration, and aggressive local search.

import numpy as np

def fft_autocorr(a):
    """Compute full linear autocorrelation conv(a,a) via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def normalize(a):
    """Normalize to sum=1, clip negatives."""
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s

def grad_from_active_lags(a, active_lags):
    """Compute averaged gradient from active lags."""
    # g[j] = (2/K) * sum_{k in active} a[k-j] (for valid k-j in [0,n-1])
    # = (2/K) * cross_correlation(a, indicator(active))[j]
    n = len(a)
    K = len(active_lags)
    if K == 0:
        return np.zeros(n)
    # Direct computation for small K
    if K * n < 2 * n * np.log2(n):
        g = np.zeros(n)
        for k in active_lags:
            k = int(k)
            # g[j] += a[k-j] for valid j: 0<=k-j<n -> max(0,k-n+1) <= j <= min(n-1,k)
            j_start = max(0, k - n + 1)
            j_end = min(n - 1, k)
            if j_start <= j_end:
                g[j_start:j_end+1] += a[k - np.arange(j_start, j_end+1)]
        g *= 2.0 / K
        return g
    else:
        # FFT-based
        # g[j] = (2/K) * sum_m a[m] * h[m+j] where h[k]=1 if k in active
        h = np.zeros(2*n-1)
        h[active_lags] = 1.0
        total_size = n + (2*n-1) - 1
        fft_size = 1 << (total_size - 1).bit_length()
        A = np.fft.rfft(a, fft_size)
        H = np.fft.rfft(h, fft_size)
        # cross-correlation: sum_m a[m]*h[m+j] = conv(a, h_rev)[(2n-2)-j]... 
        # Actually: cross_corr(x,y)[j] = sum_m x[m]*y[m+j]
        # In terms of convolution: cross_corr(x,y) = conv(x, y_reversed) reversed... 
        # Simpler: use the fact that sum_m x[m]*y[m+j] = (x * y_flipped)[len(y)-1-j]
        # where * is linear convolution and y_flipped = y[::-1]
        h_flip = h[::-1]
        conv = np.fft.irfft(A * np.fft.rfft(h_flip, fft_size), fft_size)[:total_size]
        # conv[m] = sum_i a[i]*h_flip[m-i] = sum_i a[i]*h[2n-2-(m-i)] = sum_i a[i]*h[2n-2-m+i]
        # We want sum_m a[m]*h[m+j] = sum_i a[i]*h[i+j]
        # conv[2n-2-j] = sum_i a[i]*h[2n-2-(2n-2-j)+i] = sum_i a[i]*h[j+i] ✓
        g = (2.0 / K) * conv[2*n-2-np.arange(n)]
        return g

def mirror_descent(a0, time_limit, seed=42, verbose=False):

    a = normalize(a0)
    best_a = a.copy()
    ac = fft_autocorr(a)
    best_m = ac.max()
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)
    
    x = a.copy()
    x_prev = a.copy()
    stall = 0
    max_stall = 3000
    beta = 10.0  # softness parameter
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        # Nesterov extrapolation
        alpha_t = (it - 1.0) / (it + 2.0)
        y = x + alpha_t * (x - x_prev)
        y = np.maximum(y, 1e-15)
        y = y / y.sum()
        
        ac_y = fft_autocorr(y)
        M_curr = ac_y.max()
        
        # Select active lags: all lags within 5% of max, or top-K
        threshold = M_curr * 0.95
        active = np.where(ac_y >= threshold)[0]
        if len(active) < 3:
            active = np.argsort(ac_y)[::-1][:max(3, n // 10)]
        if len(active) > n:  # cap
            active = np.argsort(ac_y)[::-1][:n]
        
        # Compute gradient
        g = grad_from_active_lags(y, active)
        
        # Mirror descent step (exponential)
        eta = 3.0 / (np.sqrt(it) + 1.0)
        log_y = np.log(y)
        log_new = log_y - eta * g
        log_new -= log_new.max()
        a_new = np.exp(log_new)
        a_new = np.maximum(a_new, 1e-30)
        a_new = a_new / a_new.sum()
        
        x_prev = x
        x = a_new
        
        M_new = fft_autocorr(x).max()
        if M_new < best_m - 1e-14:
            best_m = M_new
            best_a = x.copy()
            stall = 0
        else:
            stall += 1
        
        # Adaptive: if stalled, increase beta (sharper active set)
        if stall == max_stall // 2:

            x = x / x.sum()
            x_prev = x.copy()
            stall = 0
            if rng.random() < 0.2:
                # Full random restart
                x = rng.dirichlet(np.ones(n) * 0.3)
                x_prev = x.copy()
        
        if verbose and it % 2000 == 0:
            print(f"      MD it={it}, J={2*n*best_m:.6f}, stall={stall}, |active|={len(active)}")
    
    return best_a, best_m
