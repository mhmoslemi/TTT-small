So: `dc_k/da[j] = a[k-j]*I(j in S_k) + a[k-j]*I(k-j in S_k)`

But `j in S_k` means `0<=j<n` and `0<=k-j<n`.
And `k-j in S_k` means `0<=k-j<n` and `0<=j<n` (since `k-(k-j) = j`).

So both conditions are equivalent! `j in S_k` iff `0<=j<n` AND `0<=k-j<n`.

Therefore: `dc_k/da[j] = 2*a[k-j]*I(0<=k-j<n)` for `0<=j<n`.

Wait, that means the gradient is just `2 * (shifted a)`? Let me verify with a small example.

Take `a = [a0, a1, a2]`, n=3.
`c_0 = a0*a0` (only i=0 is valid since k-i=0-i must be >= 0, so i=0)
`c_1 = a0*a1 + a1*a0` (i=0: a0*a1, i=1: a1*a0)
`c_2 = a0*a2 + a1*a1 + a2*a0` (i=0: a0*a2, i=1: a1*a1, i=2: a2*a0)
`c_3 = a1*a2 + a2*a1` (i=1: a1*a2, i=2: a2*a1)
`c_4 = a2*a2` (i=2: a2*a2)

Now, `dc_1/da[0]`: j=0. `2*a[k-j]*I(0<=k-j<n)` = `2*a[1]*I(0<=1<3)` = `2*a1`. ✓ (c_1 has `a0*a1 + a1*a0`, derivative w.r.t. a0 is `a1 + a1 = 2a1`).

`dc_2/da[1]`: j=1. `2*a[2-1]*I(0<=2-1<3)` = `2*a[1]*I(0<=1<3)` = `2*a1`. ✓ (c_2 = a0*a2 + a1^2 + a2*a0, derivative w.r.t. a1 is `2*a1`).

`dc_2/da[0]`: j=0. `2*a[2]*I(0<=2<3)` = `2*a2`. ✓ (c_2 = a0*a2 + a1^2 + a2*a0, derivative w.r.t. a0 is `a2 + a2 = 2*a2`).

Great, so the formula is: `dc_k/da[j] = 2*a[k-j]` if `0 <= k-j < n`, else 0.

This means the gradient vector for peak k is: `2 * a[k-n+1 : k+1]` (padded with zeros to length n).

More precisely, for j = 0, ..., n-1:
`grad[j] = 2*a[k-j]` if `0 <= k-j <= n-1`, else 0.

So `grad[j] = 2*a[k-j]` for `j = max(0, k-n+1), ..., min(n-1, k)`, and 0 elsewhere.

This is just a reversed and shifted copy of `a`! Very efficient to compute.

Now, for the soft-max objective:
`f_beta(a) = (2n/beta) * log(sum_k exp(beta * c_k))`

`grad f_beta(a) = 2n * sum_k p_k * grad c_k`
where `p_k = exp(beta*c_k) / sum_j exp(beta*c_j)`

Since `grad c_k = 2 * shift(a, k)` (the 2 is a constant), we can factor it out:
`grad f_beta(a) = 4n * sum_k p_k * shift(a, k)`

Where `shift(a, k)[j] = a[k-j]` if `0 <= k-j < n`, else 0.

This is essentially a weighted sum of shifted copies of `a`, which can be computed efficiently!

In fact, `sum_k p_k * shift(a, k)` is a "convolution" of `a` with the probability distribution `p` (but in a specific way).

Let me think about how to compute this efficiently. If we have K active peaks (where p_k is significant), we just sum K shifted copies of a, which is O(K*n). For K up to a few hundred, this is fast for n up to 5000.

Alternatively, if we use all 2n-1 peaks, we can use FFT. But for the soft-max, only a few peaks have significant weight, so direct computation is fine.

def fast_autocorr(a):
    """Compute linear convolution a*a via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def evaluate_safe(a):
    try:

        return float(evaluate_sequence(a_list))
    except Exception:

def norm_sum1(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s


def simplex_project(v, target_sum=1.0):
    """Project v onto the simplex {x >= 0, sum(x) = target_sum}."""
    v = np.asarray(v, dtype=np.float64)
    n = len(v)
    if n == 0:
        return v
    # Sort-based algorithm
    u = np.sort(v)[::-1]
    cv = np.cumsum(u)
    idx = np.arange(1, n + 1, dtype=np.float64)
    cond = u * idx > (cv - target_sum)
    if not cond.any():
        return np.ones(n) * (target_sum / n)
    rho = np.where(cond)[0][-1]
    theta = (cv[rho] - target_sum) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def compute_soft_gradient(a, c, beta, top_k=100):
    """Compute gradient of soft-max approximation of max(c).
    
    Returns grad of (1/beta)*log(sum exp(beta*c_k)) w.r.t. a.
    = sum_k p_k * (2 * shifted_a_k) where p_k = softmax(beta*c_k)
    """
    n = len(a)
    n_c = len(c)
    k_use = min(top_k, n_c)
    
    # Get top-k peak indices
    top_idx = np.argsort(c)[::-1][:k_use]
    c_top = c[top_idx]
    
    # Softmax weights
    c_shifted = beta * (c_top - c_top.max())
    p = np.exp(c_shifted)
    p_sum = p.sum()
    if p_sum < 1e-30:
        p = np.ones(k_use) / k_use
    else:
        p = p / p_sum
    
    # Compute gradient
    grad = np.zeros(n)
    for ki in range(k_use):
        pk = p[ki]
        if pk < 1e-12:
            continue
        k = int(top_idx[ki])
        # grad[j] += 2*pk*a[k-j] for j where 0 <= k-j < n
        # i.e., j ranges from max(0, k-n+1) to min(n-1, k)
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        if j_start > j_end:
            continue
        j = np.arange(j_start, j_end + 1)
        grad[j] += 2.0 * pk * a[k - j]
    
    return grad


def softmax_gd(a0, time_limit, beta_init=80.0, beta_end=300.0,
               eta0=0.05, top_k=100, verbose=True, rng_seed=42):
    """Soft-max smoothed gradient descent with simplex projection."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(rng_seed)
    
    x = a.copy()
    x_prev = a.copy()
    beta = beta_init
    stall = 0
    
    for t in range(1, 20000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Nesterov
        if t > 1:
            mu = (t - 1.0) / (t + 1.5)
            y = x + mu * (x - x_prev)
        else:
            y = x.copy()
        y = np.maximum(y, 1e-30)
        sy = y.sum()
        y = y / sy
        
        # Gradient
        c = fast_autocorr(y)
        g = compute_soft_gradient(y, c, beta, top_k=top_k)
        
        # Step size
        eta = eta0 / (np.sqrt(t) + 1.0)
        
        # Update
        a_new = y - eta * g
        a_new = simplex_project(a_new)
        
        x_prev = x
        x = a_new
        
        # Track
        M = fast_autocorr(x).max()
        if M < best_m - 1e-16:
            best_m = M
            best_a = x.copy()
            stall = 0
        else:
            stall += 1
        
        # Adapt beta
        if stall > 1000:
            beta = min(beta * 1.05, beta_end)
        
        # Restart
        if stall > 5000:
            stall = 0
            noise = rng.normal(0, 0.03, n) * best_a
            x = best_a + noise
            x = np.maximum(x, 1e-10)
            x = x / x.sum()
            x_prev = x.copy()
            beta = max(beta_init, beta * 0.8)
        
        if verbose and t % 10000 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print(f"    SoftMaxGD t={t} ({elapsed:.0f}s): J={J:.6f} beta={beta:.0f} stall={stall}")
    
    return best_a, best_m
