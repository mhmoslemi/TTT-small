Let me think about the subgradient approach:

The objective is: score = 2n * max_k conv[k] / S^2

Let h(f) = max_k conv[k] (the peak of the convolution).
The subgradient of h at f is: (∂h/∂f)[i] = conv[k*][n-1-i] + conv[k*][i] for k* in the argmax set.

Wait, let me be more careful. conv[k] = sum_j f[j]*f[k-j]. So:
∂conv[k]/∂f[i] = f[k-i] + f[i-k] (if both indices are valid)

More precisely: ∂conv[k]/∂f[i] = (f[k-i] if 0<=k-i<n) + (f[i-k] if 0<=i-k<n)

The subgradient of h = max_k conv[k] is the average of the subgradients of the active constraints (those k where conv[k] = h).

So the subgradient of h is:
(∂h/∂f)[i] = (1/|A|) * sum_{k in A} [(f[k-i] if 0<=k-i<n else 0) + (f[i-k] if 0<=i-k<n else 0)]

where A = {k : conv[k] = max(conv)}.

To minimize h (which is what we want, since score is proportional to h when S is fixed), we take a step in the negative subgradient direction:
f_new = f - eta * ∂h/∂f + (correction to maintain sum = n)

But we also need f_new >= 0.

This is essentially a projected subgradient method.

For the score (which accounts for S), the gradient is more complex because S also depends on f. But since the problem is scale-invariant, we can fix S = n and just minimize h.

Let me code this up:

```python
def subgradient_step(f, eta, n_active=5):
    """One subgradient step to reduce the peak of the convolution."""
    conv = np.convolve(f, f)
    h = conv.max()
    # Get active indices (where conv is close to max)
    active = np.where(conv >= h - 1e-10 * h)[0]
    # Or just the top few
    if len(active) > n_active:
        top_k = np.argsort(conv)[-n_active:]
        active = top_k
    
    # Compute subgradient
    n = len(f)
    grad = np.zeros(n)
    for k in active:
        for i in range(n):
            # ∂conv[k]/∂f[i] = f[k-i] (if valid) + f[i-k] (if valid)
            val = 0
            if 0 <= k - i < n:
                val += f[k - i]
            if 0 <= i - k < n:
                val += f[i - k]
            grad[i] += val
    
    grad /= len(active)
    
    # Normalize gradient
    grad_norm = np.linalg.norm(grad)
    if grad_norm < 1e-15:
        return f
    
    # Step
    f_new = f - eta * grad / grad_norm
    
    # Project: clip to [0, inf] and renormalize to sum = n
    f_new = np.maximum(f_new, 0)
    s = f_new.sum()
    if s < 1e-10:
        return f
    f_new = f_new * (n / s)
    
    return f_new
```
