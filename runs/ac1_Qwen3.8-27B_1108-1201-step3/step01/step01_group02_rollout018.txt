```
        # min t s.t. 2 * sum_j a_{k-j} * a_j <= t + c_k for all k
        #            sum a_j = 1, a_j >= 0
        # Solve LP to get a_new
        a = (1-alpha) * a + alpha * a_new  # step size for stability
        a = project(a)  # ensure non-negativity and sum=1
    polish with local search
```

Let me also think about the step size alpha. If we use alpha=1 (full step), we might oscillate. A smaller alpha (e.g., 0.3-0.5) should be safer. We can also use adaptive step sizing.

Now, let me also think about the LP formulation more carefully. The LP is:

min t
s.t. for k = 0, ..., 2n-2:
        sum_{j: 0<=k-j<=n-1} 2*a_{k-j} * a_j <= t + c_k
     sum_{j=0}^{n-1} a_j = 1
     a_j >= 0 for all j

The coefficient matrix for the a_j variables in the k-th constraint is:
A[k, j] = 2 * a_{k-j} if 0 <= k-j <= n-1, else 0

And the right-hand side is t + c_k, which can be rewritten as:
sum_j (2*a_{k-j} - 1_{k has valid j}) * a_j <= c_k

Wait, let me rearrange:
2 * sum_j a_{k-j} * a_j - t <= c_k
sum_j (2*a_{k-j}) * a_j - t <= c_k

This has the variable t with coefficient -1 in each constraint. To put in standard LP form (Ax <= b):

For each k: sum_j (2*a_{k-j}) * a_j - t <= c_k

Plus: sum_j a_j = 1 (equality constraint)
And: a_j >= 0 (bound constraints)
And: t is free (or t >= 0, since c_k >= 0 implies t >= 0 at optimum).

So the LP in standard form (minimize t) is:
min t
s.t. sum_j (2*a_{k-j}) * a_j - t <= c_k for k=0,...,2n-2
     sum_j a_j = 1
     a_j >= 0
     t >= 0 (implicit from constraints)

In scipy's linprog format:
- c = [0, 0, ..., 0, 1] (minimize t, which is the last variable)
- A_ub[i, 0:n] = 2*a_{i-j} for j where 0<=i-j<=n-1, else 0
- A_ub[i, n] = -1 (coefficient of t)
