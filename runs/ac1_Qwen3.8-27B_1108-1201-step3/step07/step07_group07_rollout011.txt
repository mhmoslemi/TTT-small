Let me analyze the problem carefully.

We need to minimize: `2 * n * max_b / (sum_a)**2`

where `b_sequence = np.convolve(sequence, sequence)` (auto-convolution), `max_b = max(b_sequence)`, and `sum_a = sum(sequence)`.

The key insight is that if we normalize so that `sum_a = 1`, then we want to minimize `2 * n * max_b`, which is equivalent to minimizing `max_b` (the maximum of the auto-convolution).

The previous approach achieved 1.504889 with n=1152. The target is 1.5027.

Let me think about what could improve things:

1. **Different sequence lengths**: The objective scales as `2n * max_b / sum_a^2`. If we normalize `sum_a = 1`, it's `2n * max_b`. For a roughly flat sequence of length n with height 1/n, the auto-convolution at the peak is about n * (1/n)^2 = 1/n, so the objective would be `2n * 1/n = 2`. For a more concentrated sequence (like triangular), the peak of auto-convolution is lower relative to what you'd expect.

2. **The LP approach**: The state-of-the-art uses LP to find a direction that reduces the maximum convolution. The idea is: given current `f` with `max(conv(f,f)) = M`, solve for `g >= 0` maximizing `sum(g)` subject to `conv(f, g) <= M` element-wise. Then blend `f` with normalized `g`.

3. **Key improvement ideas**:
   - The LP approach is good but the constraint matrix construction is O(n * (2n-1)) which is expensive for large n.
   - We could use a smarter approach: instead of solving the full LP, use a subgradient method that directly targets the peaks.
   - We could try a "peak shaving" approach: identify which convolution bins are at the maximum, and reduce those specifically.

4. **Different algorithmic approach**: 
   - Instead of the LP + subgradient hybrid, try a **direct peak-shaving** approach:
     - Compute the auto-convolution
     - Identify the top K peaks
     - For each peak at position p, the convolution value is `sum_i a[i] * a[p-i]`
     - To reduce this, we want to reduce products `a[i] * a[p-i]` for the relevant pairs
     - This suggests reducing elements that contribute to multiple peaks simultaneously

5. **Another idea - spectral approach**:
   - The auto-convolution maximum is related to the L-infinity norm of the convolution
   - By Young's inequality or similar, there are relationships between L1, L2 norms
   - `||f*f||_inf <= ||f||_1 * ||f||_inf` but this is often loose
   - `||f*f||_inf <= ||f||_2^2` (by Cauchy-Schwarz on each bin)
   - The latter suggests that minimizing `||f||_2^2` subject to `||f||_1 = 1` gives the uniform distribution, which doesn't necessarily minimize the actual max

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using FFT-accelerated softmax subgradient
descent with Nesterov momentum, periodic LP-based refinement, multi-length exploration,
and diverse initialization strategies. Uses adaptive temperature for the softmax
approximation of the max operator to balance between exact peak tracking and smooth
gradient information.
"""

import numpy as np
from scipy.fft import rfft, irfft
from scipy.optimize import linprog
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT. Returns array of length 2n-1."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def softmax_subgradient_step(a, T):
    """
    Compute the gradient of the softmax-smoothed max of auto-convolution.
    Returns (grad, b, max_b) where grad has length n.
    Uses cross-correlation via FFT for O(n log n) complexity.
    """
    n = len(a)
    conv_len = 2 * n - 1
    fft_size = 1 << (3 * n - 2).bit_length()

    # Compute auto-convolution
    A = rfft(a, fft_size)
    b_full = irfft(A * A, fft_size)
    b = b_full[:conv_len]
    max_b = b.max()

    # Compute softmax weights (shifted for numerical stability)
    shifted = T * (b - max_b)
    # Clip to avoid underflow issues
    shifted = np.maximum(shifted, -50.0)
    w = np.exp(shifted)
    w_sum = w.sum()
    if w_sum < 1e-300:
        # Fallback: uniform weight on the max bin
        w = np.zeros(conv_len)
        w[np.argmax(b)] = 1.0
    else:
        w = w / w_sum

    # Compute gradient: grad[i] = sum_j w[j] * (a[j-i] + a[i-j])
    # This is 2 * cross_correlation(a, w) appropriately indexed
    # conv(a, w) gives (a*w)[k] = sum_j a[j]*w[k-j]
    # We need: grad[i] = sum_j w[j]*a[j-i] + sum_j w[j]*a[i-j]
    # First term: sum_j w[j]*a[j-i] = (w * a_flipped)... let's just use convolution
    # Actually: sum_j w[j]*a[j-i] for valid j,i. Let m=j-i: sum_m w[m+i]*a[m] = cross_corr
    # And sum_j w[j]*a[i-j] = (a * w)[i] (standard convolution)

    # Method: use the fact that for the auto-convolution derivative:
    # d(b[k])/d(a[i]) = a[k-i] + a[i-k] (with a[j]=0 outside [0,n-1])
    # grad[i] = sum_k w[k] * (a[k-i] + a[i-k])
    # = sum_k w[k]*a[k-i] + sum_k w[k]*a[i-k]
    # First sum: let m=k-i, = sum_m w[m+i]*a[m] = cross-correlation of w and a at lag i
    # Second sum: let m=k, = sum_m w[m]*a[i-m] = convolution (a*w)[i]

    # For the cross-correlation: cc[i] = sum_m a[m]*w[m+i]
    # This equals (a * w_rev_full)[N-1-i] where w_rev_full is w reversed and zero-padded
    # Simpler: use the FFT trick: cc = irfft(conj(A) * W)
    # where A = fft(a_padded), W = fft(w_padded), both padded to fft_size

    # Actually the simplest: just do the convolution
    # grad[i] = sum_k w[k] * a[k-i] + sum_k w[k] * a[i-k]
    # The second term is just (a * w)[i] (convolution of a and w, evaluated at i)
    # The first term: sum_k w[k] * a[k-i]. Let j = k-i: sum_j w[j+i] * a[j]
    # This is the cross-correlation (a ⋆ w)[i] = sum_j a[j] * w[j+i]
    # Cross-correlation via FFT: cc[i] = irfft(conj(FFT(a)) * FFT(w))[i]

    A_fft = rfft(a, fft_size)
    W_fft = rfft(w, fft_size)

    # First term: cross-correlation of a and w
    # cc[i] = sum_j a[j] * w[j+i] = irfft(conj(A_fft) * W_fft)[i]
    cc = irfft(np.conj(A_fft) * W_fft, fft_size)[:n]

    # Second term: convolution (a * w)[i] = irfft(A_fft * W_fft)[i]
    conv_aw = irfft(A_fft * W_fft, fft_size)[:n]

    grad = cc + conv_aw
    return grad, b, max_b


def project_simplex(v):
    """Euclidean projection onto {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho_vals = np.arange(1, n + 1)
    cond = u * rho_vals > (cssv - 1.0)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def eval_max_b(a):
    """Return max of auto-convolution for normalized sequence (sum=1)."""
    b = fast_convolve(a)
    return float(b.max())


def softmax_optimize(a0, time_limit, lr_init=0.003, momentum=0.9,
                     T_init=5.0, T_end=50.0, seed=42,
                     decel_factor=0.95, kick_size=0.005,
                     restart_after=2000):
    """
    FFT-accelerated softmax subgradient with Nesterov momentum.
    Optimizes max(conv(a,a)) subject to a>=0, sum(a)=1.
    T (temperature) is annealed from T_init to T_end for smoother gradients.
    """
    rng = np.random.default_rng(seed)
    t0 = time.monotonic()
    n = len(a0)
    a = a0.copy().astype(np.float64)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    v = np.zeros(n)
    best_a = a.copy()
    best_obj = eval_max_b(a)
    cur_lr = lr_init
    no_improve = 0
    it = 0
    total_iters = 0

    while time.monotonic() - t0 < time_limit:
        # Anneal temperature
        progress = min(1.0, (time.monotonic() - t0) / time_limit)
        T = T_init * (T_end / T_init) ** progress

        # Compute softmax gradient
        grad, b, max_b = softmax_subgradient_step(a, T)

        # Nesterov momentum step
        v = momentum * v - cur_lr * grad
        a_new = project_simplex(a + v)

        # Evaluate
        obj_new = eval_max_b(a_new)

        if obj_new < best_obj - 1e-14:
            best_obj = obj_new
            best_a = a_new.copy()
            no_improve = 0
        else:
            no_improve += 1

        a = a_new
        it += 1
        total_iters += 1

        # Adaptive strategy
        if no_improve >= restart_after:
            # Restart with perturbation
            a = project_simplex(best_a + rng.standard_normal(n) * kick_size)
            v = np.zeros(n)
            cur_lr = max(cur_lr * 0.5, lr_init * 0.1)
            no_improve = 0
            kick_size *= 0.8
        elif no_improve >= restart_after * 0.5:
            cur_lr *= decel_factor
        elif no_improve >= restart_after * 0.25:
            cur_lr *= 0.98

    return best_a, best_obj, total_iters


def top_k_subgradient_optimize(a0, time_limit, lr_init=0.005, momentum=0.92,
                               n_top=30, seed=42, threshold_frac=0.999,
                               restart_after=3000):
    """
    Subgradient with exact top-K peak selection (no softmax needed).
    Faster per iteration since no softmax computation.
    """
    rng = np.random.default_rng(seed)
    t0 = time.monotonic()
    n = len(a0)
    a = a0.copy().astype(np.float64)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    v = np.zeros(n)
    best_a = a.copy()
    best_obj = eval_max_b(a)
    cur_lr = lr_init
    no_improve = 0
    kick_size = 0.004
    it = 0
    total_iters = 0
    fft_size = 1 << (3 * n - 2).bit_length()

    while time.monotonic() - t0 < time_limit:
        # Compute convolution
        A = rfft(a, fft_size)
        b_full = irfft(A * A, fft_size)
        conv_len = 2 * n - 1
        b = b_full[:conv_len]
        b_max = b.max()

        # Select active peaks
        n_sel = min(n_top, conv_len)
        top_idx = np.argpartition(b, -n_sel)[-n_sel:]
        top_vals = b[top_idx]
        threshold = b_max * threshold_frac
        active_mask = top_vals >= threshold
        if not active_mask.any():
            active_mask[0] = True
        active_indices = top_idx[active_mask]

        # Build weight vector
        w = np.zeros(conv_len)
        w[active_indices] = 1.0 / len(active_indices)

        # Compute gradient via FFT
        W = rfft(w, fft_size)
        cc = irfft(np.conj(A) * W, fft_size)[:n]
        conv_aw = irfft(A * W, fft_size)[:n]
        grad = cc + conv_aw

        # Nesterov step
        v = momentum * v - cur_lr * grad
        a_new = project_simplex(a + v)

        # Evaluate
        obj_new = eval_max_b(a_new)
        if obj_new < best_obj - 1e-14:
            best_obj = obj_new
            best_a = a_new.copy()
            no_improve = 0
        else:
            no_improve += 1

        a = a_new
        it += 1
        total_iters += 1

        if no_improve >= restart_after:
            a = project_simplex(best_a + rng.standard_normal(n) * kick_size)
            v = np.zeros(n)
            cur_lr = max(cur_lr * 0.5, lr_init * 0.08)
            no_improve = 0
            kick_size *= 0.75
        elif no_improve >= restart_after // 2:
            cur_lr *= 0.95
        elif no_improve >= restart_after // 4:

def lp_refine(f, max_iters=20, time_limit=60.0, verbose=False):
    """
    LP-based refinement: solve max sum(g) s.t. conv(f,g) <= M, g >= 0.
    Blend with current f to reduce max convolution.
    Returns (best_a, best_max_b) where a is normalized to sum=1.
    """
    t0 = time.monotonic()
    n = len(f)
    a = f.copy().astype(np.float64)
    a = a / a.sum()

    best_a = a.copy()
    best_obj = eval_max_b(a)

    for iteration in range(max_iters):
        if time.monotonic() - t0 > time_limit:
            break

        M = fast_convolve(a).max()

        # Build LP constraint matrix (banded structure)
        num_constraints = 2 * n - 1
        A_mat = np.zeros((num_constraints, n))
        for k in range(num_constraints):
            lo = max(0, k - n + 1)
            hi = min(n - 1, k)
            A_mat[k, lo:hi + 1] = a[lo:hi + 1]

        b_lp = np.full(num_constraints, M)
        c = -np.ones(n)

        try:
            res = linprog(c, A_ub=A_mat, b_ub=b_lp,
                          bounds=[(0.0, None)] * n, method='highs')
            if not res.success:
                break

            g = res.x
            g_sum = g.sum()
            if g_sum < 1e-10:
                break

            g_norm = g / g_sum

            # Line search for blending
            best_t = 0.0
            best_blend_obj = best_obj
            t_candidates = [0.03, 0.05, 0.08, 0.1, 0.15, 0.2, 0.3, 0.4, 0.5]
            for t in t_candidates:
                blend = (1.0 - t) * best_a + t * g_norm
                blend = np.maximum(blend, 0.0)
                ss = blend.sum()
                if ss < 1e-10:
                    continue
                blend = blend / ss
                obj_blend = eval_max_b(blend)
                if obj_blend < best_blend_obj:
                    best_blend_obj = obj_blend
                    best_t = t

            if best_t > 0.0:
                a = (1.0 - best_t) * best_a + best_t * g_norm
                a = np.maximum(a, 0.0)
                a = a / a.sum()
                obj = eval_max_b(a)
                if obj < best_obj:
                    best_obj = obj
                    best_a = a.copy()
                    if verbose:
                        print(f"    LP iter {iteration}: t={best_t:.2f}, max_b={best_obj:.10f}")
                else:
                    a = best_a.copy()
            else:
                break

        except Exception:
            break

    return best_a, best_obj


def coordinate_descent(a0, time_limit, multipliers=None):
    """Coordinate descent on the simplex."""
    t0 = time.monotonic()
    n = len(a0)
    a = a0.copy().astype(np.float64)
    a = a / a.sum()
    best_a = a.copy()
    best_obj = eval_max_b(a)

    if multipliers is None:
        multipliers = np.array([0.3, 0.5, 0.7, 0.85, 0.95, 1.05, 1.15, 1.3, 1.5, 2.0, 3.0])

    improved_global = True
    while improved_global and time.monotonic() - t0 < time_limit:
        improved_global = False
        for j in range(n):
            if time.monotonic() - t0 > time_limit:
                return best_a, best_obj
            old_val = a[j]
            if old_val < 1e-15:
                continue
            denom = 1.0 - old_val
            if denom < 1e-12:
                continue

            best_j_obj = best_obj
            best_j_val = old_val

            for mult in multipliers:
                new_val = old_val * mult
                if new_val < 0.0 or new_val > 0.9999:
                    continue
                scale = (1.0 - new_val) / denom
                if scale < -0.01 or scale > 20.0:
                    continue
                a_tr = a.copy()
                a_tr[j] = new_val
                mask = np.ones(n, dtype=bool)
                mask[j] = False
                a_tr[mask] *= scale
                ss = a_tr.sum()
                if ss < 1e-15:
                    continue
                a_tr = a_tr / ss
                val = eval_max_b(a_tr)
                if val < best_j_obj - 1e-14:
                    best_j_obj = val
                    best_j_val = new_val

            if best_j_val != old_val:
                scale = (1.0 - best_j_val) / denom
                a[j] = best_j_val
                mask = np.ones(n, dtype=bool)
                mask[j] = False
                a[mask] *= scale
                a = a / a.sum()
                if best_j_obj < best_obj - 1e-14:
                    best_obj = best_j_obj
                    best_a = a.copy()
                    improved_global = True

    return best_a, best_obj


def make_gaussian_init(n, sigma=0.3):
    x = np.linspace(0, 1, n)
    a = np.exp(-0.5 * ((x - 0.5) / sigma) ** 2)
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def make_cosine_init(n):
    x = np.linspace(0, 1, n)
    a = 0.5 * (1.0 + np.cos(2.0 * np.pi * x))
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def make_tukey_init(n, r=0.5):
    a = np.ones(n)
    taper = max(1, int(r * n // 2))
    if taper < n:
        t = np.linspace(0, 1, taper)
        a[:taper] = 0.5 * (1.0 + np.cos(np.pi * (2.0 * t / r - 1.0)))
        a[-taper:] = a[:taper][::-1]
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def make_triangular_init(n):
    a = np.ones(n)
    half = n // 2
    a[:half] = np.linspace(0.05, 1.0, half)
    a[half:] = np.linspace(1.0, 0.05, n - half)
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def make_uniform_init(n):
    return np.ones(n) / n


def interpolate_sequence(f, new_n):
    """Interpolate normalized sequence to new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp /= ss
    else:
        f_interp = np.ones(new_n) / new_n
    return f_interp


def run_fast_optimize(a_init, time_limit, seed=42, verbose=False):
    """
    Run top-k subgradient optimization, then a lighter softmax pass,
    then LP refinement.
    """
    t0 = time.monotonic()
    n = len(a_init)
    a = a_init.copy().astype(np.float64)
    a = a / a.sum()
    best_a = a.copy()
    best_obj = eval_max_b(a)

    # Phase A: Top-K subgradient (fast, many iterations)
    t_alloc_a = time_limit * 0.5
    if t_alloc_a > 3:
        a_a, obj_a, iters_a = top_k_subgradient_optimize(
            a, time_limit=t_alloc_a,
            lr_init=0.004, momentum=0.92,
            n_top=max(20, n // 10), seed=seed,
            threshold_frac=0.999, restart_after=3000
        )
        if verbose:
            print(f"    TopK-SG: {iters_a} iters, max_b={obj_a:.10f}")
        if obj_a < best_obj:
            best_obj = obj_a
            best_a = a_a.copy()

    # Phase B: LP refinement
    rem = time_limit - (time.monotonic() - t0)
    if rem > 5:
        t_lp = min(rem * 0.4, 60.0)
        a_lp, obj_lp = lp_refine(best_a, max_iters=20, time_limit=t_lp, verbose=verbose)
        if obj_lp < best_obj:
            best_obj = obj_lp
            best_a = a_lp.copy()

    # Phase C: More top-K from LP result
    rem = time_limit - (time.monotonic() - t0)
    if rem > 5:
        a_c, obj_c, iters_c = top_k_subgradient_optimize(
            best_a, time_limit=min(rem, time_limit * 0.3),
            lr_init=0.002, momentum=0.94,
            n_top=max(30, n // 8), seed=seed + 7777,
            threshold_frac=0.999, restart_after=2000
        )
        if verbose:
            print(f"    TopK-SG2: {iters_c} iters, max_b={obj_c:.10f}")
        if obj_c < best_obj:
            best_obj = obj_c
            best_a = a_c.copy()

    # Phase D: Final LP
    rem = time_limit - (time.monotonic() - t0)
    if rem > 5:
        a_d, obj_d = lp_refine(best_a, max_iters=10, time_limit=min(rem, 30.0), verbose=verbose)
        if obj_d < best_obj:
            best_obj = obj_d
            best_a = a_d.copy()

    return best_a, best_obj


def propose_candidate(seed=42, budget_s=1800.0):
    """
    Multi-phase optimization for minimizing 2n*max(conv(a,a))/(sum(a))^2.
    Uses fast top-K subgradient, LP refinement, multi-length exploration,
    diverse initializations, and coordinate descent polish.
    """
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + max(1.0, budget_s - 30.0)

    best_seq = None
    best_score = float('inf')

    def update_best(a, label):
        nonlocal best_seq, best_score
        a = np.maximum(a, 0.0)
        s = a.sum()
        if s < 0.01:
            return
        a_norm = a / s
        score = float(evaluate_sequence(a_norm.tolist()))
        if np.isfinite(score) and score < best_score:
            best_score = score
            best_seq = a_norm.copy()
            print(f"  NEW BEST [{label}]: {score:.8f} (n={len(a)})")

    # Load parent
    parent = None
    parent_score = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            parent = p / p.sum()
            parent_score = float(evaluate_sequence(parent.tolist()))
            print(f"Parent loaded: n={len(parent)}, score={parent_score:.6f}")
            best_seq = parent.copy()
            best_score = parent_score
    except Exception:
        pass

    if parent is None:
        parent = make_cosine_init(1152)
        best_seq = parent.copy()
        best_score = float(evaluate_sequence(best_seq.tolist()))
        print(f"No parent, using cosine init n=1152, score={best_score:.6f}")

    n_parent = len(parent)

    # === Phase 1: Fast optimization on parent ===
    print(f"\n{'='*60}")
    print(f"Phase 1: Fast optimization on parent (n={n_parent})")
    print(f"{'='*60}")
    rem = deadline - time.monotonic() - 600
    if rem > 30:
        t_alloc = min(rem, 400.0)
        print(f"  t={t_alloc:.0f}s")
        a_opt, obj_opt = run_fast_optimize(parent, t_alloc, seed=seed, verbose=True)
        update_best(a_opt, "phase1_parent")

    # === Phase 2: Diverse initializations at parent length ===
    print(f"\n{'='*60}")
    print(f"Phase 2: Diverse Initializations (best={best_score:.6f})")
    print(f"{'='*60}")
    n_base = len(best_seq) if best_seq is not None else n_parent

    inits = {
        "gauss_0.2": make_gaussian_init(n_base, 0.2),
        "gauss_0.3": make_gaussian_init(n_base, 0.3),
        "cosine": make_cosine_init(n_base),
        "tukey_0.4": make_tukey_init(n_base, 0.4),
        "tukey_0.6": make_tukey_init(n_base, 0.6),
        "triangular": make_triangular_init(n_base),
        "uniform": make_uniform_init(n_base),
    }

    rem_total = deadline - time.monotonic() - 500
    if rem_total > 20:
        time_per_init = max(10.0, rem_total / len(inits))
        for name, init_a in inits.items():
            rem = deadline - time.monotonic() - 450
            if rem < 12:
                break
            t_alloc = min(time_per_init, rem * 0.3)
            if t_alloc < 8:
                continue
            print(f"  {name} (t={t_alloc:.0f}s)")
            a_div, obj_div = run_fast_optimize(
                init_a, t_alloc, seed=seed + hash(name) % 100000, verbose=False
            )
            update_best(a_div, f"div_{name}")

    # === Phase 3: Multi-length exploration ===
    print(f"\n{'='*60}")
    print(f"Phase 3: Multi-length Exploration (best={best_score:.6f})")
    print(f"{'='*60}")
    if best_seq is not None:
        target_lengths = []
        for factor in [0.75, 0.85, 1.15, 1.25, 1.5, 0.6, 1.4, 1.1]:
            tl = int(n_parent * factor)
            tl = max(256, min(4096, tl))
            if tl not in target_lengths:
                target_lengths.append(tl)
        target_lengths.sort(key=lambda x: abs(x - n_parent))

        for target_n in target_lengths[:5]:
            rem = deadline - time.monotonic() - 300
            if rem < 20:
                break

            f_interp = interpolate_sequence(best_seq, target_n)
            t_alloc = min(rem * 0.2, 50.0)
            if t_alloc < 10:
                continue
            print(f"  n={target_n}, t={t_alloc:.0f}s")
            a_len, obj_len = run_fast_optimize(
                f_interp, t_alloc, seed=seed + target_n, verbose=False
            )
            update_best(a_len, f"len_n{target_n}")

    # === Phase 4: Deep optimization on best ===
    print(f"\n{'='*60}")
    print(f"Phase 4: Deep Optimization (best={best_score:.6f})")
    print(f"{'='*60}")
    if best_seq is not None:
        n_best = len(best_seq)
        rem = deadline - time.monotonic() - 200
        if rem > 20:
            t_deep = min(rem, 200.0)
            print(f"  Deep: n={n_best}, t={t_deep:.0f}s")
            a_deep, obj_deep = run_fast_optimize(
                best_seq, t_deep, seed=seed + 99999, verbose=True
            )
            update_best(a_deep, "deep")

    # === Phase 5: Coordinate descent polish ===
    print(f"\n{'='*60}")
    print(f"Phase 5: Coordinate Descent Polish (best={best_score:.6f})")
    print(f"{'='*60}")
    if best_seq is not None:
        rem = deadline - time.monotonic() - 80
        if rem > 10:
            t_cd = min(rem, 60.0)
            n_cd = len(best_seq)
            print(f"  CD: n={n_cd}, t={t_cd:.0f}s")
            a_cd, obj_cd = coordinate_descent(best_seq, time_limit=t_cd)
            update_best(a_cd, "cd")

    # === Phase 6: Final micro-polish ===
    print(f"\n{'='*60}")
    print(f"Phase 6: Final Polish (best={best_score:.6f})")
    print(f"{'='*60}")
    if best_seq is not None:
        n_final = len(best_seq)
        rem = deadline - time.monotonic() - 30
        if rem > 8:
            # Quick LP
            t_lp = min(rem * 0.4, 25.0)
            a_lp_f, obj_lp_f = lp_refine(
                best_seq, max_iters=15, time_limit=t_lp, verbose=True
            )
            update_best(a_lp_f, "final_lp")

            # Quick subgradient
            rem = deadline - time.monotonic() - 15
            if rem > 5:
                a_sg_f, obj_sg_f, _ = top_k_subgradient_optimize(
                    best_seq, time_limit=min(rem, 20.0),
                    lr_init=0.001, momentum=0.95,
                    n_top=max(40, n_final // 5), seed=seed + 777777,
                    threshold_frac=0.9999, restart_after=1500
                )
                update_best(a_sg_f, "final_sg")

            # Tiny CD
            rem = deadline - time.monotonic() - 8
            if rem > 5:
                a_cd_f, obj_cd_f = coordinate_descent(
                    best_seq, time_limit=min(rem, 15.0),
                    multipliers=np.array([0.8, 0.9, 0.95, 1.05, 1.1, 1.2, 1.5])
                )
                update_best(a_cd_f, "final_cd")

    # Fallback
    if best_seq is None:
        best_seq = parent.copy()
        best_score = float(evaluate_sequence(best_seq.tolist()))

    # Final verification
    fs = float(evaluate_sequence(best_seq.tolist()))
    if np.isfinite(fs):
        best_score = fs
    else:
        best_seq = parent.copy()
        best_score = float(evaluate_sequence(best_seq.tolist()))

    print(f"\n{'='*60}")
    print(f"FINAL SCORE: {best_score:.8f} (n={len(best_seq)})")
    print(f"{'='*60}")

    return [float(x) for x in best_seq]
