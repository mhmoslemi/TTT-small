Wait, I need to be more careful. For k in 0..2n-2:
j ranges from max(0, k-n+1) to min(n-1, k).
The number of such j is min(n, k+1, 2n-1-k).

Total non-zeros = sum_{k=0}^{2n-2} min(n, k+1, 2n-1-k).

For k = 0 to n-1: min(n, k+1, 2n-1-k) = k+1 (since k+1 <= n and k+1 <= 2n-1-k for k <= n-1).
For k = n to 2n-2: min(n, k+1, 2n-1-k) = 2n-1-k (since 2n-1-k <= n and 2n-1-k <= k+1 for k >= n-1).

Total = sum_{k=0}^{n-1}(k+1) + sum_{k=n}^{2n-2}(2n-1-k)
= n(n+1)/2 + (n-1)n/2 = n^2.
