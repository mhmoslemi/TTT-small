import numpy as np
import time

def _convolve_fft(x):
    """Compute full convolution x*x using FFT."""
    n = len(x)
    size = 1
    while size < 2 * n - 1:
        size *= 2
    X = np.fft.rfft(x, size)
    result = np.fft.irfft(X * X, size)
    return result[:2 * n - 1]

def _compute_gradient(a, weights):
    """Compute gradient of weighted sum of convolution values.
    grad[i] = 2 * sum_k weights[k] * a[k-i] (valid indices only)
    """
    n = len(a)
    size = 1
    while size < 2 * n:
        size *= 2
    A = np.fft.rfft(a, size)
    W = np.fft.rfft(weights, size)
    # We want: sum_k weights[k] * a[k-i] for each i
    # This is: ifft(conj(FFT(weights)) * FFT(a))[:n]
    grad = 2.0 * np.fft.irfft(np.conj(W) * A, size)[:n].real
    return grad

def _softmax_weights(c, temperature):
    """Compute softmax weights over convolution values."""
    c_shifted = c / temperature
    c_shifted -= c_shifted.max()
    w = np.exp(c_shifted)
    w_sum = w.sum()
    if w_sum == 0 or not np.isfinite(w_sum):
        # Fallback: uniform over top few
        top_k = np.argsort(c)[-10:]
        w = np.zeros_like(c)
        w[top_k] = 1.0 / len(top_k)
    else:
        w /= w_sum
    return w

def _full_convolution(x):
    """Full convolution x*x via FFT."""
    n = len(x)

Or even simpler: **Fisher scoring / natural gradient:**

Since we're on the simplex {a >= 0, sum=1}, the natural gradient would be:
a_new[i] = a[i] * (1 - lr * (grad[i] - sum_j a[j]*grad[j])) / a[i] (for a[i] > 0)

This automatically maintains the simplex constraint.

Actually, let me think about this more carefully. The Fisher information matrix on the simplex is:
F[i,j] = delta(i,j)/a[i] - 1/a[i]/a[j] (approximately, for the Bernoulli/simplex model)

The natural gradient is F^{-1} * grad, which on the simplex simplifies to:
a[i] * (grad[i] - sum_j a[j]*grad[j])

... but this is for the case where we're maximizing a log-likelihood. For our problem, it's more like:
a_new[i] ∝ a[i] * exp(-lr * (grad[i] - mean_weighted(grad)))

This is the "exponential tilting" or "multiplicative weights" update.

Let me use this:
```
score[i] = grad[i] - sum_j a[j] * grad[j]  # center the gradient
a_new[i] = a[i] * exp(-lr * score[i])
a_new = max(a_new, 0) / sum(max(a_new, 0))
```

This is a multiplicative update that naturally stays on the simplex (after normalization).
