from scipy.sparse import csr_matrix

def solve_lp(a, M):
    """Solve LP: maximize sum(g) subject to (a*g)_k <= M for all k, g >= 0."""
    n = len(a)
    # Build constraint matrix A where A[k, j] = a[k-j] if valid
    # (a*g)_k = sum_j A[k,j] * g[j] <= M
    # Number of constraints: 2n-1
    # Number of variables: n

    cols = []
    vals = []
    
    for k in range(2*n - 1):
        for j in range(max(0, k-n+1), min(n, k+1)):

            cols.append(j)

**Simpler approach: Direct coordinate-wise optimization.**

Instead of solving a big LP, what if I optimize one element at a time?

For a given element $a_j$, the auto-convolution entries that involve $a_j$ are:
$(a*a)_k$ for $k = j, j+1, \ldots, j+n-1$ (and symmetrically).

Actually, $(a*a)_k$ involves $a_j$ when $k-j$ is a valid index into $a$, i.e., $0 \leq k-j \leq n-1$, so $k$ ranges from $j$ to $j+n-1$.

The contribution of $a_j$ to $(a*a)_k$ is $a_j \cdot a_{k-j}$.

If I increase $a_j$ by $\delta$, the change in $(a*a)_k$ is $\delta \cdot a_{k-j}$ (to first order).

The objective is $f = 2n \cdot \max_k (a*a)_k / S^2$. If the peak is at $k^*$, then the derivative of $f$ w.r.t. $a_j$ (to first order) is:
$\frac{\partial f}{\partial a_j} = 2n \cdot a_{k^*-j} / S^2 - 2 \cdot 2n \cdot \max(a*a) \cdot a_j / S^3$

(assuming the peak index doesn't change)

For a descent direction, I should decrease $a_j$ if $\frac{\partial f}{\partial a_j} > 0$ and increase it if $< 0$.

But this is just first-order information and might not be very effective.

Let me try a different tactic: **use the structure of the problem to design a smart initial guess**.

The optimal sequence should have the auto-convolution as flat as possible. For a non-negative sequence, this means:
- The sequence should be "spread out" (not concentrated).
- But not uniform (which gives score 2).
- The sequence should have some "anti-correlation" structure.

One idea: use a sequence that's high in the "middle" and low at the "edges." This would make the auto-convolution more concentrated in the center, which is... wait, that would INCREASE the peak.

Another idea: use a sequence with a "comb" pattern - alternating high and low values. This would spread out the auto-convolution.

Let me try: $a_i = 1 + \epsilon \cos(2\pi i / n)$ for some small $\epsilon$. This is a small perturbation of the uniform sequence.

The auto-convolution of a cosine-modulated uniform sequence... this is getting complicated. Let me just implement the LP approach and see.

Actually, here's another thought. The problem is scale-invariant, so I can fix $\sum a_i = n$ (mean = 1). Then the objective is $2 \cdot \max(a*a)$.

For the uniform sequence, $\max(a*a) = n$ (at the center). So the objective is $2n \cdot n / n^2 = 2$.

To get below 2, I need $\max(a*a) < n$ (with mean 1).

The sum of all auto-convolution entries is $(\sum a_i)^2 = n^2$. There are $2n-1$ entries. The average is $n^2/(2n-1) \approx n/2$.

So the peak must be at least $n/2$ (by the average). The uniform sequence has peak $n$, which is twice the average. To get closer to the lower bound, I need the auto-convolution to be more uniform.

This is exactly the problem of minimizing the peak of the auto-convolution, which is related to "optimal sequences" in coding theory.
