**Alternative: Use the "peak reduction" approach.**

The idea is: the peak of the autocorrelation is at k*. To reduce it, we need to reduce conv[k*] = sum_j a_j * a_{k*-j}. This is a sum of products. To reduce it, we should decrease the products that contribute most to this sum.

The gradient tells us exactly how to do this: decrease a_i in proportion to a_{k*-i} (for i in the valid range).

But we also need to maintain the sum constraint and non-negativity.

**Better approach: Block coordinate descent with exact line search.**

For each "block" of coordinates (say, all coordinates in the range where the gradient is non-zero), solve a small subproblem: minimize the objective over that block, keeping other coordinates fixed.

But the objective is non-convex, so even the subproblem is hard.

**Even better approach: Use the structure of the problem.**

The objective is `2n * M / S^2` where M = max_k conv[k].

If we can identify the "active" constraints (the k values where conv[k] is close to M), we can try to reduce all of them simultaneously.

This is similar to the "water-filling" or "projection" approach used in some signal processing applications.

**Let me try a different practical approach: projected subgradient with step-size schedule.**

The key insight is that the problem is (approximately) homogeneous of degree 0 (scale-invariant). So we should work in the "projected" space where sum(a) = 1 and a >= 0 (the simplex).

On the simplex, the objective is `2n * max_k conv[k]` (since S = 1). We want to minimize this.

The projection onto the simplex is: given a vector v, find the closest point on the simplex (sum = 1, all >= 0). This can be done in O(n log n) using a binary search on the threshold.

Algorithm:
1. Start with a on the simplex.
2. Compute conv, find k*.
3. Compute subgradient g (on the simplex, this is just the gradient of conv[k*] w.r.t. a, projected onto the tangent space of the simplex).
4. Take a step: a_new = a - η * g.
5. Project a_new onto the simplex.
6. Repeat.

The projection onto the simplex {a: sum(a) = 1, a >= 0} is:
- Find τ such that sum(max(a - τ, 0)) = 1.
- The projected point is max(a - τ, 0).

This is a standard result.
