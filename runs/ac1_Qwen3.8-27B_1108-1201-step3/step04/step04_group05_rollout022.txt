```python
def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)
```

In coordinate descent, we update one element at a time. For a given element `a[j]`, the objective as a function of `a[j]` (with all other elements fixed) is:

Alternatively, we can use the "cyclic coordinate descent" approach: at each step, pick a pair `(i, j)` and transfer mass from one to the other. The objective as a function of the transfer amount `δ` is:
`f(δ) = 2n * max_k c[k](δ) / 1` (since the sum is always 1).

This is a 1D optimization problem (piecewise quadratic), which we can solve exactly!

For a given pair `(i, j)` and the current `a`, the auto-correlation at lag `k` changes as:
`c[k](δ) = c[k](0) + δ * (partial c[k] / partial a[i]) + δ * (partial c[k] / partial a[j]) + δ^2 * (second order terms)`

The partial derivatives involve the values of `a` at shifted positions, so this is computable.

The max of a set of quadratic functions is a convex piecewise-quadratic function of `δ`. We can find its minimum by considering the breakpoints (where the argmax changes) and evaluating the quadratics between breakpoints.

This gives an exact 1D optimization at each step, which is very fast.

import time

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def compute_subgradient(a, c, top_k, temp):
    """Compute weighted subgradient for multi-peak targeting."""
    n = len(a)
    peaks = np.argpartition(c, -top_k)[-top_k:]
    pv = c[peaks]
    scaled = pv / temp
    scaled -= scaled.max()
    w = np.exp(scaled)
    ws = w.sum()
    if ws < 1e-15:
        w = np.zeros(len(peaks))
        w[np.argmax(pv)] = 1.0
    else:
        w /= ws
    
    sg = np.zeros(n)
    for i in range(len(peaks)):
        if w[i] < 1e-13:
            continue
        k = int(peaks[i])
        # Gradient of c[k] = sum_j a[j]*a[k-j] wrt a is 2*a[k-j] (reflected)
        # Specifically, dc[k]/da[i] = 2*a[k-i] (with a[m]=0 for invalid m)
        js = max(0, k - n + 1)
        je = min(n - 1, k)
        idx = np.arange(js, je + 1)
        sg[idx] += 2.0 * w[i] * a[k - idx]
