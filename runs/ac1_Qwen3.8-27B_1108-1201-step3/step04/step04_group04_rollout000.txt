Actually, for a practical implementation, I can just do a 1D line search for each coordinate. Since the function is the max of affine functions (approximately, ignoring the quadratic term at k=2i), the minimum is at a breakpoint or at 0.

The breakpoints occur where two different lags give the same convolution value. There are O(n) such breakpoints, so I can find all of them and check each.

But this might be too slow for n=768. Let me think of a simpler approach.

**Simpler coordinate descent**: For each coordinate `i`, try a few candidate values (e.g., current value ± small amounts, 0, and the value that would make the peak lag equal to the second-highest lag). This is O(1) per coordinate and O(n) per full sweep.

Let me code this up:

```python
def coordinate_descent_step(a, conv, n, i):
    """Find optimal a[i] given all other coordinates fixed."""
    v = a[i]
    a[i] = 0.0
    conv0 = fast_convolve(a)  # convolution with a[i] = 0
    
    # Now (a*a)[k] = conv0[k] + v*(a[k-i] + a[i-k]) + v^2*1(k=2i)
    # (with appropriate boundary handling)
    
    # Actually this is expensive (O(n) FFT per coordinate). Let me use a different approach.
    
    # Instead, compute the "response" of each lag to changes in a[i]:
    # d(conv[k])/d(a[i]) = a[k-i] + a[i-k] (for valid indices)
    # This is O(n) to compute.
    
    a[i] = v  # restore
    response = np.zeros(2*n-1)
    for k in range(2*n-1):
        ki = k - i
        if 0 <= ki < n:
            response[k] += a[ki]
        ik = i - k
        if 0 <= ik < n:
            response[k] += a[ik]
    
    # So conv[k] + delta * response[k] + delta^2 * 1(k=2i) is the new convolution
    # where delta = new_a[i] - v
    # We want to minimize max_k (conv[k] + delta * response[k] + delta^2 * 1(k=2i))
    # subject to v + delta >= 0
    
    # This is a 1D minimization of a max of affine (or quadratic) functions.
    # We can use bisection on the subgradient, or just try a grid.
    
    # For simplicity, let's try a few values:
    best_delta = 0.0
    best_val = conv.max()
    
    # The function is convex in delta (max of convex functions).
    # Find where subgradient changes sign.
    # At delta=0: subgradient = response[peak_idx] (approximately)
    # Try bisection
    
    delta_lo = -v  # a[i] can't be negative
    delta_hi = v * 0.5 + 1.0  # reasonable upper bound
    
    # Actually, let's just do a simple ternary search on a grid
    for delta in np.linspace(delta_lo, delta_hi, 20):
        if v + delta < 0:
            continue
        max_conv = np.max(conv + delta * response + delta**2 * (np.arange(2*n-1) == 2*i).astype(float))
        if max_conv < best_val:
            best_val = max_conv
            best_delta = delta
    
    return v + best_delta
```

This is O(n^2) per full sweep (n coordinates × O(n) response computation). For n=768, that's about 600K operations per sweep, which should be fast.

But wait, I'm computing the response for each coordinate separately, which is O(n) each. And I'm doing a grid search of 20 points. So per coordinate: O(n) for response + O(n) for grid search = O(n). Per full sweep: O(n^2). For n=768: ~600K ops per sweep. We can do many sweeps in the time budget.

Actually, there's a smarter way. The response vector for coordinate `i` is just a shifted and reflected version of `a`. Specifically:
`response_i[k] = a[k-i] + a[i-k]` (with 0 for out-of-bounds)

This is basically the auto-correlation of `a` with a delta at position `i`, which is just `a` shifted. So I can compute all responses efficiently using FFT or just by shifting.

But for simplicity, let me just do the direct computation. n=768 is small enough.

Let me now write the full solution:

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. LP-based direction finding with golden-section line search
2. Coordinate descent with response-based 1D optimization
3. Subgradient descent with active set
4. Simulated annealing for escaping local minima
5. Multi-length exploration
"""

import numpy as np
import time
from scipy.optimize import linprog


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def build_conv_matrix(a):
    """Build matrix C such that C @ g = a * g (full linear convolution)."""
    n = len(a)
    C = np.zeros((2 * n - 1, n))
    for j in range(n):
        C[j:j + n, j] = a
    return C


def obj(a, n):
    """Compute objective value (assuming sum(a) = 1)."""
    conv = fast_convolve(a)
    return 2.0 * n * conv.max()


def normalize(a):
    """Normalize to sum=1, non-negative."""
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s


def lp_direction(a, M, C=None):
    """Solve LP: max sum(g) s.t. C@g <= M, g >= 0."""
    n = len(a)
    if C is None:
        C = build_conv_matrix(a)
    c = -np.ones(n)
    b = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    try:
        result = linprog(c, A_ub=C, b_ub=b, bounds=bounds, method='highs',
                         options={'presolve': True})
        if result.success and result.x is not None:
            g = np.maximum(result.x, 0)
            gs = g.sum()
            if gs > 1e-10:
                return g, gs, True
    except Exception:
        pass
    return a.copy(), 1.0, False


def golden_section_search(a, direction, n, max_iter=40):
    """
    Golden section search for step size t.
    Minimize obj(normalize(a + t * direction)) over t in [0, 1].
    """
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    lo, hi = 0.0, 1.0
    
    c = hi - gr * (hi - lo)
    d = lo + gr * (hi - lo)
    
    a_c = normalize(a + c * direction)
    a_d = normalize(a + d * direction)
    f_c = obj(a_c, n)
    f_d = obj(a_d, n)
    
    for _ in range(max_iter):
        if hi - lo < 1e-12:
            break
        if f_c <= f_d:
            hi = d
            d = c
            f_d = f_c
            c = hi - gr * (hi - lo)
            a_c = normalize(a + c * direction)
            f_c = obj(a_c, n)
        else:
            lo = c
            c = d
            f_c = f_d
            d = lo + gr * (hi - lo)
            a_d = normalize(a + d * direction)
            f_d = obj(a_d, n)
    
    t = (lo + hi) / 2.0
    a_best = normalize(a + t * direction)
    return a_best, obj(a_best, n)


def lp_optimize(a0, time_limit, verbose=False):
    """LP-based iterative optimization."""
    a = normalize(a0.astype(np.float64).copy())
    n = len(a)
    conv = fast_convolve(a)
    M = conv.max()
    best_obj = 2.0 * n * M
    best_a = a.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    perturb_count = 0
    rng = np.random.default_rng(42)
    
    C = build_conv_matrix(a)
    
    while time.monotonic() - t0 < time_limit:
        # Check stagnation
        if no_improve > 50:
            # Perturb and restart
            scale = 0.002 + 0.003 * min(perturb_count, 10)
            noise = rng.standard_normal(n) * scale
            a = normalize(best_a + noise)
            conv = fast_convolve(a)
            M = conv.max()
            C = build_conv_matrix(a)
            no_improve = 0
            perturb_count += 1
            if perturb_count > 50:
                break
            continue
        
        # Solve LP
        g, g_sum, success = lp_direction(a, M * 1.00001, C)
        
        if not success or g_sum <= 1.0 + 1e-6:
            no_improve += 1
            continue
        
        # Direction
        d = g - a
        d_norm = np.linalg.norm(d)
        if d_norm < 1e-10:
            no_improve += 1
            continue
        
        # Golden section line search
        a_new, obj_new = golden_section_search(a, d, n, max_iter=25)
        
        if obj_new < best_obj - 1e-12:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new
            conv = fast_convolve(a)
            M = conv.max()
            C = build_conv_matrix(a)
            no_improve = 0
        else:
            no_improve += 1
        
        if verbose and (no_improve % 20 == 0):
            print(f"    LP: obj={best_obj:.8f}, no_improve={no_improve}, t={time.monotonic()-t0:.1f}s")
    
    return best_a, best_obj


def coordinate_descent(a0, time_limit):
    """
    Coordinate descent: for each coordinate, find optimal value
    using the response vector.
    """
    a = normalize(a0.astype(np.float64).copy())
    n = len(a)
    conv = fast_convolve(a)
    best_obj = 2.0 * n * conv.max()
    best_a = a.copy()
    
    t0 = time.monotonic()
    no_improve_passes = 0
    rng = np.random.default_rng(123)
    
    while time.monotonic() - t0 < time_limit:
        improved_this_pass = False
        
        for i in range(n):
            if time.monotonic() - t0 > time_limit - 0.1:
                break
            
            v = a[i]
            
            # Compute response: d(conv[k])/d(a[i]) = a[k-i] + a[i-k]
            response = np.zeros(2 * n - 1)
            for k in range(2 * n - 1):
                ki = k - i
                if 0 <= ki < n:
                    response[k] += a[ki]
                ik = i - k
                if 0 <= ik < n:
                    response[k] += a[ik]
            
            # Quadratic term at k=2i
            quad_mask = (np.arange(2 * n - 1) == 2 * i).astype(float)
            
            # Minimize max(conv + delta*response + delta^2*quad_mask)
            # subject to v + delta >= 0
            # Use ternary search on [−v, 0.5*v + 0.1*max(a)]
            delta_lo = -v
            delta_hi = 0.5 * max(v, 0.01)
            
            # Quick grid search
            best_delta = 0.0
            best_val = conv.max()
            
            # First try: set to 0
            val_0 = np.max(conv - v * response + v**2 * quad_mask)
            if val_0 < best_val - 1e-12:
                best_val = val_0
                best_delta = -v
            
            # Try a few values
            for delta in np.linspace(delta_lo, delta_hi, 10):
                if v + delta < -1e-15:
                    continue
                new_conv = conv + delta * response + delta**2 * quad_mask
                val = new_conv.max()
                if val < best_val - 1e-12:
                    best_val = val
                    best_delta = delta
            
            if best_delta != 0.0:
                a[i] = v + best_delta
                a[i] = max(0.0, a[i])
                # Recompute convolution
                conv = fast_convolve(a)
                cur_obj = 2.0 * n * conv.max()
                if cur_obj < best_obj - 1e-12:
                    best_obj = cur_obj
                    best_a = a.copy()
                    improved_this_pass = True
        
        if not improved_this_pass:
            no_improve_passes += 1
            if no_improve_passes > 5:
                # Perturb
                noise = rng.standard_normal(n) * 0.005
                a = normalize(best_a + noise)
                conv = fast_convolve(a)
                no_improve_passes = 0
            if no_improve_passes > 30:
                break
        else:
            no_improve_passes = 0
    
    return best_a, best_obj


def subgradient_descent(a0, time_limit, lr_init=0.01):
    """Subgradient descent on the peak autocorrelation."""
    a = normalize(a0.astype(np.float64).copy())
    n = len(a)
    conv = fast_convolve(a)
    best_obj = 2.0 * n * conv.max()
    best_a = a.copy()
    
    t0 = time.monotonic()
    lr = lr_init
    no_improve = 0
    rng = np.random.default_rng(99)
    
    while time.monotonic() - t0 < time_limit:
        conv = fast_convolve(a)
        M = conv.max()
        peak_idx = int(np.argmax(conv))
        
        # Subgradient of (a*a)[peak_idx] w.r.t. a
        grad = np.zeros(n)
        for m in range(n):
            ki = peak_idx - m
            if 0 <= ki < n:
                grad[m] += a[ki]
            ik = m - peak_idx
            if 0 <= ik < n:
                grad[m] += a[ik]
        
        # Make sum-preserving: subtract mean
        grad = grad - grad.mean()
        
        # Step
        a_new = a - lr * grad
        a_new = normalize(a_new)
        
        conv_new = fast_convolve(a_new)
        obj_new = 2.0 * n * conv_new.max()
        
        if obj_new < best_obj - 1e-12:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new
            no_improve = 0
        else:
            no_improve += 1
        
        # Adaptive learning rate
        lr *= 0.999
        if no_improve > 100:
            # Perturb
            noise = rng.standard_normal(n) * 0.003
            a = normalize(best_a + noise)
            no_improve = 0
            lr = lr_init * 0.5
            if lr < 1e-5:
                break
    
    return best_a, best_obj


def simulated_annealing(a0, time_limit, T_init=0.01, T_min=0.0001, cooling=0.999):
    """Simulated annealing for escaping local minima."""
    a = normalize(a0.astype(np.float64).copy())
    n = len(a)
    conv = fast_convolve(a)
    cur_obj = 2.0 * n * conv.max()
    best_obj = cur_obj
    best_a = a.copy()
    
    t0 = time.monotonic()
    T = T_init
    rng = np.random.default_rng(77)
    step_size = 0.01
    
    while time.monotonic() - t0 < time_limit and T > T_min:
        # Propose: change 1-3 random coordinates
        n_changes = rng.integers(1, 4)
        idxs = rng.integers(0, n, size=n_changes)
        deltas = rng.standard_normal(n_changes) * step_size
        
        a_try = a.copy()
        for idx, delta in zip(idxs, deltas):
            a_try[idx] = max(0.0, a_try[idx] + delta)
        a_try = normalize(a_try)
        
        conv_try = fast_convolve(a_try)
        obj_try = 2.0 * n * conv_try.max()
        
        delta_obj = obj_try - cur_obj
        if delta_obj < 0 or rng.random() < np.exp(-delta_obj / T):
            a = a_try
            cur_obj = obj_try
            if cur_obj < best_obj:
                best_obj = cur_obj
                best_a = a.copy()
        
        T *= cooling
        step_size *= 0.9999
    
    return best_a, best_obj
```

Wait, I realize there might be an issue with the coordinate descent. Computing the response vector for each coordinate is O(n), and we do this for all n coordinates, so it's O(n^2) per pass. For n=768, that's about 600K operations per pass. With the FFT for convolution, each pass is O(n log n + n^2) ≈ O(n^2). For 768, that's manageable.

But actually, I can optimize the response computation. The response for coordinate `i` is:
`response[k] = a[k-i] + a[i-k]` for valid indices.

This is just the sequence `a` reflected and shifted. I can compute it more efficiently:
- `a[k-i]` is `a` shifted right by `i` (with zeros for invalid positions)
- `a[i-k]` is `a` reversed and shifted

Actually, for a given `i`:
- `response[k] = a[k-i]` for `k >= i` and `k-i < n` (i.e., `i <= k <= i+n-1`)
- `response[k] += a[i-k]` for `k <= i` and `i-k < n` (i.e., `i-n+1 <= k <= i`)

So `response` is non-zero only in the range `[max(0, i-n+1), min(2n-2, i+n-1)]`.

For the grid search, I can avoid computing the full `new_conv` array by only checking the relevant lags. But this optimization might not be worth the complexity.
