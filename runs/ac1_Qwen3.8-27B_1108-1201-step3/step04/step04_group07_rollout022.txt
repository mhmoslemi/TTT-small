Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using Nesterov accelerated gradient
descent on a smoothed max objective with FFT-based gradient computation,

import numpy as np
import time
from scipy.optimize import linprog

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def compute_smoothed_max_grad(a, T):
    """Compute (gradient, smoothed_max_value) of T*log(sum(exp(b/T))) where b=conv(a,a)."""
    n = len(a)
    b = fast_convolve(a)
    b_s = b / T
    b_s -= b_s.max()
    w = np.exp(b_s)
    w_sum = w.sum()
    w = w / w_sum
    smoothed_val = T * np.log(w_sum)  # Note: this is T*log(sum exp(b/T)) but b_s was shifted
    # Actually: T*log(sum exp(b/T)) = T*log(exp(b.max()/T) * sum exp((b-b.max())/T))
    # = b.max() + T*log(w_sum)  [where w_sum = sum exp((b-b.max())/T)]
    smoothed_val = b.max() + T * np.log(w_sum)
    
    # Gradient: grad[i] = sum_k w[k] * 2*a[k-i] (for valid k-i)
    # = 2 * sum_{j=0}^{n-1} a[j] * w[i+j]
    g = np.zeros(n)
    for i in range(n):
        g[i] = 2.0 * np.dot(a, w[i:i+n])
    return g, smoothed_val

def build_conv_matrix(a):
    n = len(a)
    C = np.zeros((2 * n - 1, n))
    for i in range(n):
        C[i:i + n, i] = a
    return C

def solve_lp_direction(a, M, A_ub):
    n = len(a)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    result = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if result.success:
        g = result.x
        g_sum = g.sum()
        if g_sum > 1e-10:
            return g / g_sum, g_sum
    return a.copy(), 1.0

The Nesterov momentum update is:
- t_{k+1} = (1 + sqrt(1 + 4*t_k^2)) / 2
- y_k = x_k + (t_k - 1) / t_{k+1} * (x_k - x_{k-1})
- x_{k+1} = proj(y_k - alpha_k * grad(f)(y_k))

Where proj is the Euclidean projection onto the constraint set (simplex).

For the simplex {x >= 0, sum(x) = 1}, the projection is done by:
1. Compute y - alpha * grad
2. Find the largest t such that sum(max(y - alpha*grad - t, 0)) = 1
3. Return max(y - alpha*grad - t, 0)

Actually, for the scale-invariant problem, the "projection" onto the simplex is:
1. a_new = max(y - alpha*grad, 0)
2. a_new = a_new / sum(a_new)

This is not exactly the Euclidean projection, but it works well in practice for scale-invariant problems.

Actually, let me take a step back and think about what will actually work well in practice.

The key challenge is that the objective `max(b)` is non-smooth (piecewise linear in a). The smoothed max with temperature T approximates it. As T → 0, the smoothed max → true max, but the gradient becomes more concentrated on the peak.

For the gradient descent to work well:
1. T should be large enough that the gradient is informative (spreads over multiple peaks)
2. T should be small enough that the smoothed max is a good approximation of the true max
3. The step size should be small enough for convergence but large enough for speed

A good strategy:
- Start with T = 0.01 (or scale it with the peak value)
- Run gradient descent until convergence
- Decrease T by factor of 2
- Continue
- Stop when T is very small and no improvement

Let me also think about the **scale of the gradient**. If `a` is normalized to sum=1, then `max(a) ≈ 1/n` for a uniform distribution, but can be larger for peaked distributions. The convolution `b[k] ≈ max(a)^2 * n` at the peak (roughly). So the gradient components are `2 * sum_j a[j] * w[i+j] ≈ 2 * O(1/n) * O(1) = O(1/n)`.

The change in `b` from a step of size alpha in the gradient direction is approximately `alpha * ||grad||^2`. For the objective to decrease by a meaningful amount, we need `alpha * ||grad||^2 > current_obj - optimal_obj`.

Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using Nesterov accelerated multiplicative
gradient descent on a smoothed-max surrogate (log-sum-exp), with temperature
annealing, periodic LP polishing, and multi-length exploration.

import numpy as np
import time

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def compute_grad(a, T):
    """
    Compute gradient of T*log(sum_k exp(b[k]/T)) where b = conv(a,a).
    Returns (gradient array of length n, smoothed max value).
    """
    n = len(a)
    b = fast_convolve(a)
    b_scaled = b / T
    b_scaled -= b_scaled.max()
    w = np.exp(b_scaled)
    w_sum = w.sum()
    w = w / w_sum
    smoothed_val = b.max() + T * np.log(w_sum)
    
    # grad[i] = 2 * sum_{j=0}^{n-1} a[j] * w[i+j]
    g = np.zeros(n)
    for i in range(n):
        g[i] = 2.0 * np.dot(a, w[i:i+n])
    return g, smoothed_val


def multiplicative_step(a, grad, alpha):
    """One multiplicative update: a[i] <- a[i] * exp(-alpha * grad[i]), then normalize."""
    # For numerical stability

    a_new = a * np.exp(log_factor)
    a_new = np.maximum(a_new, 0.0)
    s = a_new.sum()
    if s > 1e-15:
        a_new = a_new / s
    else:
        a_new = a.copy()
