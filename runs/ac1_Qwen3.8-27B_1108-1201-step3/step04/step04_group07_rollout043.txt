from scipy.optimize import linprog

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def build_conv_matrix(a):
    n = len(a)
    # C[k, j] = a[k-j] if 0 <= k-j < n
    # This is a Toeplitz matrix
    cols = a[np.arange(n)]

    # i.e., k-n+1 <= j <= k
    C = np.zeros((2*n-1, n))
    for j in range(n):
        C[j:j+n, j] = a
    return C

def lp_direction(a, M):
    """Solve LP: max sum(g) s.t. conv(a,g) <= M, g >= 0"""
    n = len(a)

    A_ub = build_conv_matrix(a)
    b_ub = np.full(2*n-1, M)
    bounds = [(0, None)] * n
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success:
        g = res.x
        s = g.sum()
        if s > 1e-10:
            return g, s
    return None, 0

What about a sequence that's large at 1/3 and 2/3? Then n-1 - n/3 ≈ 2n/3, so the peaks pair with each other. Also bad.

What about a "flat-top" with slight variations? Or a sequence with a periodic structure?

Actually, let me think about this differently. We want to minimize `sum_j a_j * a_{n-1-j}` (approximately, since the center lag has the most terms) subject to `sum a_j = 1, a_j >= 0`.

By Cauchy-Schwarz: `sum_j a_j * a_{n-1-j} <= sqrt(sum a_j^2 * sum a_{n-1-j}^2) = sum a_j^2`.

So the center value is bounded above by `sum a_j^2`. To minimize the center, we want to minimize `sum a_j^2`, which is the uniform distribution.

But wait, the bound is tight when `a_j = a_{n-1-j}` for all j (i.e., when a is symmetric). For a symmetric sequence, the center value equals `sum a_j^2`.

For an asymmetric sequence, the center value can be less than `sum a_j^2`. In fact, if a is "anti-symmetric" (but we can't have negative values), the center value could be much smaller.

Hmm, but with non-negative values, the minimum of `sum_j a_j * a_{n-1-j}` subject to `sum a_j = 1` is... let's think.

If we put all mass at one point, say `a_0 = 1`, then `(a*a)_{n-1} = a_0 * a_{n-1} + ... + a_{n-1} * a_0 = 0` (since only `a_0` is non-zero and `a_{n-1} = 0`). But then `(a*a)_0 = a_0^2 = 1`, so the max is 1, and the objective is `2*n*1/1 = 2n`. Very bad.

The tension is: we want the center lag to be small, but other lags might be large.

For a uniform sequence, all lags k from 0 to 2n-2 have values `(n-|k-(n-1)|) * (1/n)^2` (triangle shape), with peak `1/n` at k=n-1. Objective = 2.

To do better than 2, we need a sequence where the peak of the autocorrelation (relative to `(sum a)^2/n`) is less than 1. In other words, `max_k (a*a)_k < (sum a)^2 / n`.

For uniform: `max_k (a*a)_k = 1/n = (sum a)^2 / n`. So the ratio is exactly 1, giving objective 2.

We need the ratio `n * max_k (a*a)_k / (sum a)^2` to be less than 1.

This is related to the "flatness" of the autocorrelation. We want the autocorrelation to be as flat as possible (no peaks).

For binary sequences (±1), the "ideal" autocorrelation is a delta function (peak at 0, zero elsewhere). But for non-negative sequences, we can't achieve this.

The best we can do with non-negative sequences is to make the autocorrelation as flat as possible. The "flatness" is limited by the fact that the sum of all autocorrelation values is `(sum a)^2 = 1` (when normalized), and there are 2n-1 values. The average is `1/(2n-1)`, and the peak must be at least the average.

For a perfectly flat autocorrelation: `max = 1/(2n-1)`, objective = `2n/(2n-1) ≈ 1`. So the theoretical minimum is close to 1 for large n.

But can we achieve a flat autocorrelation with non-negative values? This is related to "Sidon sequences" and "perfect autcorrelation sequences" (Barker, etc.), but those typically use complex or ±1 values.

For non-negative real sequences, the best we can do is related to "low autocorrelation" or "low peak-to-average power ratio (PAPR)" sequences.

OK so the problem is well-defined. Let me think about practical optimization.

The key insight is: we want to flatten the autocorrelation. The LP approach works because it finds a direction `g` such that `conv(a, g)` is bounded by the current peak M. If we can find such a `g` with `sum(g) > sum(a)`, then moving towards `g` flattens the autocorrelation.

Let me think about the coordinate-wise approach more carefully.

Given `a` with `a_i` fixed at all positions except i, the objective is:
`f(a_i) = 2*n*max_k (conv(a,a))_k / (sum a)^2`

where `sum a = S - a_i + a_i'` (where S is the original sum and a_i' is the new value).

The convolution values that depend on `a_i` are those at positions k where k-i is in [0, n-1], i.e., k in [i, i+n-1]. At such position k:
`(conv(a,a))_k = (conv(a,a))_k|_{a_i=0} + 2*a_i * a_{k-i}` (the cross terms)

Wait, more precisely:
`(conv(a,a))_k = sum_{j=0}^{n-1} a_j * a_{k-j}`

The terms involving `a_i` are:
- `j = i`: term is `a_i * a_{k-i}` (if `0 <= k-i < n`)
- `k-j = i`, i.e., `j = k-i`: term is `a_{k-i} * a_i` (if `0 <= k-i < n`, same condition)

So if `0 <= k-i < n`, the term `a_i * a_{k-i}` appears twice (once for j=i and once for j=k-i), unless i = k-i (i.e., k=2i), in which case it appears once as `a_i^2`.

So `(conv(a,a))_k = C_k + 2*a_i*a_{k-i}` for k in [i, i+n-1], k != 2i
`(conv(a,a))_k = C_k + a_i^2` for k = 2i (if 2i < 2n-1)
where `C_k` is the convolution value without the terms involving a_i.

This is a quadratic in a_i for k=2i and linear for other k. The max of these is a piecewise function. We can find the optimal a_i by checking the critical points.

This is a 1D non-convex optimization (the max of linear/quadratic functions), but it's tractable.

where k* is the position of the max.

This is what the subgradient method uses.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using LP-based optimization with
co

ordinate descent polishing, dual-guided perturbations, and adaptive constraint
tightening. Key improvements: tighter LP iterations, coordinate-wise refinement,
and exploitation of LP dual information for structured restarts.

import numpy as np
import time
from scipy.optimize import linprog


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def compute_obj(a):
    """Compute objective value and convolution."""
    n = len(a)
    conv = fast_convolve(a)
    s = a.sum()
    if s < 1e-15:
        return float('inf'), conv
    obj = 2.0 * n * conv.max() / (s * s)
    return obj, conv


def build_conv_matrix(a):
    """Build matrix C such that C @ g = conv(a, g)."""
    n = len(a)
    C = np.zeros((2 * n - 1, n))
    for j in range(n):
        C[j:j + n, j] = a
    return C


def solve_lp(a, M):
    """Solve LP: max sum(g) s.t. conv(a,g) <= M, g >= 0. Returns (g, sum_g, duals)."""
    n = len(a)
    c = -np.ones(n)
    A_ub = build_conv_matrix(a)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success:
        g = res.x
        s = g.sum()
        duals = res.ineqlin.marginals if hasattr(res.ineqlin, 'marginals') else None
        if s > 1e-10:
            return g, s, duals
    return None, 0.0, None


def line_search(a, d, obj_cur, n, max_evals=30):
    """Line search: find best t in [0, 1] for a + t*d (normalized)."""
    best_t = 0.0
    best_obj = obj_cur
    
    # Coarse scan
    for t in np.linspace(0.05, 1.0, 10):
        a_try = np.maximum(a + t * d, 0.0)
        s = a_try.sum()
        if s < 1e-15:
            continue
        a_try = a_try / s
        obj_try, _ = compute_obj(a_try)
        if obj_try < best_obj:
            best_obj = obj_try
            best_t = t
    
    # Refined scan around best
    if 0.05 < best_t < 0.95:
        for t in np.linspace(max(0.01, best_t - 0.1), min(0.99, best_t + 0.1), 10):
            a_try = np.maximum(a + t * d, 0.0)
            s = a_try.sum()
            if s < 1e-15:
                continue
            a_try = a_try / s
            obj_try, _ = compute_obj(a_try)
            if obj_try < best_obj:
                best_obj = obj_try
                best_t = t
    
    return best_t, best_obj


def coordinate_descent(a, n_passes=3, n=0):
    """Coordinate-wise descent: for each coordinate, optimize its value."""
    if n == 0:
        n = len(a)
    a = a.copy()
    
    for _ in range(n_passes):
        for i in range(n):
            # Current value
            ai = a[i]
            # Try a few candidate values
            best_val = ai
            best_obj, _ = compute_obj(a)
            
            # Candidates: current, 0, and a few multiplicative factors
            candidates = [0.0, ai * 0.5, ai * 0.8, ai * 1.2, ai * 2.0]
            # Also try values based on neighbors
            if i > 0:
                candidates.append(a[i-1])
            if i < n-1:
                candidates.append(a[i+1])
            
            for cv in candidates:
                if cv < 0:
                    cv = 0.0
                a[i] = cv
                s = a.sum()
                if s < 1e-15:
                    a[i] = ai
                    continue
                # We don't normalize here to keep the coordinate descent meaningful
                obj_try, _ = compute_obj(a)
                if obj_try < best_obj:
                    best_obj = obj_try
                    best_val = cv
            
            a[i] = best_val
    
    return a


def lp_optimize(a0, time_limit, verbose=False):
    """Main LP-based optimization loop."""
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    obj, conv = compute_obj(a)
    M = conv.max()
    best_obj = obj
    best_a = a.copy()
    
    t0 = time.monotonic()
    iteration = 0
    no_improve = 0
    max_no_improve = 100
    perturb_count = 0
    tightness = 0.9995
    
    while time.monotonic() - t0 < time_limit:
        M_lp = M * tightness
        g, s_g, duals = solve_lp(a, M_lp)
        
        if g is not None and s_g > 1.0 + 1e-6:
            d = g / s_g - a  # direction towards normalized g
            t_best, obj_best = line_search(a, d, best_obj, n)
            if obj_best < best_obj - 1e-14:
                a_new = a + t_best * d
                a_new = np.maximum(a_new, 0.0)
                s_new = a_new.sum()
                if s_new > 1e-15:
                    a = a_new / s_new
                obj, conv = compute_obj(a)
                M = conv.max()
                best_obj = obj
                best_a = a.copy()
                no_improve = 0
                tightness = max(0.999, tightness - 0.0001)
                if verbose and iteration % 20 == 0:
                    print(f"    LP iter {iteration}, obj={best_obj:.8f}, time={time.monotonic()-t0:.1f}s")
            else:
                no_improve += 1
        else:
            no_improve += 1
        
        iteration += 1
        
        if no_improve >= max_no_improve:
            # Dual-guided perturbation
            rng = np.random.default_rng(iteration * 13 + perturb_count * 7)
            if duals is not None:
                # Perturb more where duals are large (active constraints)
                # Map duals back to positions
                active = np.where(np.abs(duals) > np.max(np.abs(duals)) * 0.1)[0]
                if len(active) > 0:
                    noise = np.zeros(n)
                    for k in active[:50]:
                        j_start = max(0, k - n + 1)
                        j_end = min(n - 1, k)
                        noise[j_start:j_end+1] += rng.standard_normal(j_end - j_start + 1) * 0.003
                else:
                    noise = rng.standard_normal(n) * 0.003
            else:
                noise = rng.standard_normal(n) * 0.003
            
            a = best_a + noise
            a = np.maximum(a, 0.0)
            s = a.sum()
            if s > 1e-15:
                a = a / s
            obj, conv = compute_obj(a)
            M = conv.max()
            no_improve = 0
            perturb_count += 1
            max_no_improve = min(300, 100 + 30 * perturb_count)
            tightness = 1.001
            if perturb_count > 50:
                break
    
    return best_a, best_obj


def subgradient_polish(a0, time_limit, lr_init=0.005, momentum=0.95, top_k=80, temp=0.0001):
    """Subgradient descent with momentum."""
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    v = np.zeros(n)
    obj, conv = compute_obj(a)
    best_obj = obj
    best_a = a.copy()
    
    t0 = time.monotonic()
    lr = lr_init
    no_improve = 0
    step_count = 0
    
    while time.monotonic() - t0 < time_limit:
        # Compute subgradient
        top_k_actual = min(top_k, len(conv))
        peaks = np.argpartition(conv, -top_k_actual)[-top_k_actual:]
        peak_vals = conv[peaks]
        scaled = peak_vals / temp
        scaled -= scaled.max()
        w = np.exp(scaled)
        w_sum = w.sum()
        if w_sum < 1e-15:
            w = np.zeros(len(peaks))
            w[np.argmax(peak_vals)] = 1.0
        else:
            w /= w_sum
        
        sg = np.zeros(n)
        for idx in range(len(peaks)):
            if w[idx] < 1e-12:
                continue
            k = int(peaks[idx])
            j_start = max(0, k - n + 1)
            j_end = min(n - 1, k)
            jj = np.arange(j_start, j_end + 1)
            sg[jj] += w[idx] * 2.0 * a[k - jj]
        
        v = momentum * v - lr * sg
        a = np.maximum(a + v, 0.0)
        s = a.sum()
        if s > 1e-15:
            a = a / s
        else:
            a = best_a.copy()
            v = np.zeros(n)
        
        obj, conv = compute_obj(a)
        step_count += 1
        
        if obj < best_obj - 1e-14:
            best_obj = obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        if no_improve % 30 == 0:
            lr *= 0.995
            temp *= 1.005
        
        if no_improve >= 300:
            rng = np.random.default_rng(step_count * 3 + 7)
            noise = rng.standard_normal(n) * 0.002
            a = best_a + noise
            a = np.maximum(a, 0.0)
            s = a.sum()
            if s > 1e-15:
                a = a / s
            v = np.zeros(n)
            obj, conv = compute_obj(a)
            no_improve = 0
    
    return best_a, best_obj


def resample_sequence(seq, new_n):
    """Resample a sequence to a different length."""
    old_n = len(seq)
    if old_n == new_n:
        return seq.copy()
    x_old = np.linspace(0, 1, old_n)
    x_new = np.linspace(0, 1, new_n)
    new_seq = np.interp(x_new, x_old, seq)
    new_seq = np.maximum(new_seq, 0.0)
    s = new_seq.sum()
    if s > 1e-15:
        new_seq = new_seq / s
    return new_seq


def get_structured_inits(n, parent, rng):
    """Generate diverse structured initializations."""
    inits = {}
    x = np.arange(n, dtype=np.float64)
    
    if parent is not None:
        inits['parent'] = resample_sequence(parent, n)
    
    inits['uniform'] = np.ones(n) / n
    
    # Smooth variations
    for freq in [2, 3, 4, 6]:
        name = f'sine_{freq}'
        sig = 0.8 + 0.2 * np.sin(2 * np.pi * freq * x / n)
        inits[name] = sig / sig.sum()
    
    # Cosine window
    cw = np.cos(np.pi * (x - n/2) / n)**2 + 0.1
    inits['coswin'] = cw / cw.sum()
    
    # Random smooth
    rough = rng.standard_normal(n)
    # Smooth via FFT
    spec = np.fft.rfft(rough)
    freqs = np.fft.rfftfreq(n)
    spec[1:] *= np.exp(-5 * freqs[1:])
    smooth = np.fft.irfft(spec, n)
    inits['rand_smooth'] = np.maximum(smooth, 0) 
    inits['rand_smooth'] = inits['rand_smooth'] / inits['rand_smooth'].sum()
    
    return inits

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def compute_obj(a):
    n = len(a)
    conv = fast_convolve(a)
    s = a.sum()
    if s < 1e-15:
        return float('inf'), conv
    return 2.0 * n * conv.max() / (s * s), conv


def build_conv_matrix(a):
    n = len(a)
    C = np.zeros((2 * n - 1, n))
    for j in range(n):
        C[j:j + n, j] = a
    return C


def solve_lp(a, M):
    n = len(a)
    c = -np.ones(n)
    A_ub = build_conv_matrix(a)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success:
        g = res.x
        s = g.sum()
        duals = None
        try:
            duals = res.ineqlin.marginals
        except:
            pass
        if s > 1e-10:
            return g, s, duals
    return None, 0.0, None

    return out / s if s > 1e-15 else out

"""

import numpy as np

from scipy.optimize import linprog


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def compute_obj(a):
    """Compute objective value and convolution."""
    n = len(a)
    conv = fast_convolve(a)
    s = a.sum()
    if s < 1e-15:
        return float('inf'), conv
    return 2.0 * n * conv.max() / (s * s), conv


def build_conv_matrix(a):
    """Build matrix C such that C @ g = conv(a, g) (full linear convolution)."""
    n = len(a)
    C = np.zeros((2 * n - 1, n))
    for j in range(n):
        C[j:j + n, j] = a
    return C


def solve_lp(a, M):
    """Solve LP: max sum(g) s.t. conv(a,g) <= M elementwise, g >= 0.
    Returns (g, sum_g, duals) or (None, 0, None)."""
    n = len(a)
    c = -np.ones(n)
    A_ub = build_conv_matrix(a)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success:
        g = res.x
        s_g = g.sum()
        duals = None
        try:
            duals = res.ineqlin.marginals
        except Exception:
            pass
        if s_g > 1e-10:
            return g, s_g, duals
    return None, 0.0, None


def line_search(a, d, obj_cur, max_fine=12):

def sg_polish(a0, time_limit, lr=0.004, momentum=0.95, top_k=90, temp=0.00012):
    """Subgradient descent with momentum and adaptive learning rate."""
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)

    obj, conv = compute_obj(a)
    best_obj = obj

    t0 = time.monotonic()
    no_improve = 0
    steps = 0

    while time.monotonic() - t0 < time_limit:
        tk = min(top_k, len(conv))
        peaks = np.argpartition(conv, -tk)[-tk:]
        pv = conv[peaks]
        sc = pv / temp
        sc -= sc.max()
        w = np.exp(sc)
        ws = w.sum()
        if ws < 1e-15:
            w = np.zeros(len(peaks))
            w[np.argmax(pv)] = 1.0
        else:
            w /= ws

        sg = np.zeros(n)
        for idx in range(len(peaks)):
            if w[idx] < 1e-12:
                continue
            k = int(peaks[idx])
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            jj = np.arange(js, je + 1)
            sg[jj] += w[idx] * 2.0 * a[k - jj]

        v = momentum * v - lr * sg
        a = np.maximum(a + v, 0.0)
        s = a.sum()
        if s > 1e-15:
            a = a / s
        else:
            a = best_a.copy()
            v = np.zeros(n)

        obj, conv = compute_obj(a)
        steps += 1
        if obj < best_obj - 1e-14:
            best_obj = obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1

        if no_improve % 40 == 0:
            lr *= 0.995
            temp *= 1.004

        if no_improve >= 400:
            rng = np.random.default_rng(steps * 7 + 13)
            a = np.maximum(best_a + rng.standard_normal(n) * 0.002, 0.0)
            s = a.sum()
            if s > 1e-15:
                a = a / s
            v = np.zeros(n)
            obj, conv = compute_obj(a)
            no_improve = 0

    return best_a, best_obj


def resample_sequence(seq, new_n):
    """Resample a sequence to a different length via linear interpolation."""
    old_n = len(seq)
    if old_n == new_n:
        return seq.copy()
    x_old = np.linspace(0, 1, old_n)
    x_new = np.linspace(0, 1, new_n)
    new_seq = np.interp(x_new, x_old, seq)
    new_seq = np.maximum(new_seq, 0.0)
    s = new_seq.sum()
    if s > 1e-15:
        new_seq = new_seq / s
    return new_seq
