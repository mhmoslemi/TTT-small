```python
def project_simplex(a, S):
    """Project a onto {x >= 0, sum(x) = S}."""
    n = len(a)
    # Euclidean projection onto the probability simplex scaled by S
    # Find threshold tau such that sum(max(a - tau, 0)) = S
    sorted_a = np.sort(a)[::-1]
    cumulative = np.cumsum(sorted_a)
    rho = np.where(sorted_a * np.arange(1, n+1) > (cumulative - S))[0]
    if len(rho) == 0:
        return np.zeros(n)
    rho = rho[-1]
    tau = (cumulative[rho] - S) / (rho + 1)
    return np.maximum(a - tau, 0)
```

= a[k-m] (if 0 <= k-m < n) + a[k-m] (if 0 <= k-m < n)
= 2 * a[k-m] (if 0 <= k-m < n)
= 0 (otherwise)

So grad[m] = 2 * a[k-m] if 0 <= k-m < n, else 0.

For m in [0, n-1], k-m is in [0, n-1] iff k-n+1 <= m <= k.
So lo = max(0, k-n+1), hi = min(n, k+1) (exclusive upper bound).
For m in [lo, hi-1], grad[m] = 2*a[k-m].

When m = lo = k-n+1: k-m = n-1, so grad[lo] = 2*a[n-1]
When m = hi-1 = k (if k < n): k-m = 0, so grad[k] = 2*a[0]

So grad[lo:hi] = 2*a[k-lo : k-hi+1+1][::-1] = 2*a[k-lo : k-hi+2][::-1]

Let me verify: k-lo = k - max(0, k-n+1). If k >= n-1, k-lo = k-(k-n+1) = n-1. If k < n-1, k-lo = k.
k-hi+1 = k - min(n, k+1) + 1. If k+1 <= n, i.e., k < n, then k-hi+1 = k-(k+1)+1 = 0. If k >= n, k-hi+1 = k-n+1.

So the slice is a[k-hi+1 : k-lo+1][::-1], which gives a[k-m] for m from hi-1 down to lo.

Let me just verify with a small example:
a = [1, 2, 3], n=3, k=2.
(a*a)[2] = a[0]*a[2] + a[1]*a[1] + a[2]*a[0] = 3 + 4 + 3 = 10.
grad[0] = 2*a[2] = 6
grad[1] = 2*a[1] = 4
grad[2] = 2*a[0] = 2

Check: d/d(a[0]) (a*a)[2] = 2*a[2] = 6. (a*a)[2] = 2*a[0]*a[2] + a[1]^2, d/d(a[0]) = 2*a[2] = 6. ✓
d/d(a[1]) (a*a)[2] = 2*a[1] = 4. ✓
d/d(a[2]) (a*a)[2] = 2*a[0] = 2. ✓

Now, lo = max(0, 2-3+1) = 0, hi = min(3, 3) = 3.
grad[0:3] should be [6, 4, 2].
a[k-hi+1 : k-lo+1][::-1] = a[2-3+1 : 2-0+1][::-1] = a[0:3][::-1] = [3, 2, 1].
2 * [3, 2, 1] = [6, 4, 2]. ✓

Great, so the formula is:
lo = max(0, k - n + 1)
hi = min(n, k + 1)
grad[lo:hi] = 2 * a[k-hi+1 : k-lo+1][::-1]

Or equivalently:
grad[lo:hi] = 2 * a[max(0, k-n+1) : k-lo+1][::-1]

Wait, k-hi+1 = k - min(n, k+1) + 1.
If k < n: k - (k+1) + 1 = 0.
If k >= n: k - n + 1.
So k-hi+1 = max(0, k-n+1) = lo.

And k-lo+1 = k - max(0, k-n+1) + 1.
If k < n: k - 0 + 1 = k+1.
If k >= n: k - (k-n+1) + 1 = n.
So k-lo+1 = min(n, k+1) = hi.

So grad[lo:hi] = 2 * a[lo:hi][::-1].

That's even simpler! The gradient is just 2 times the reversed slice of a from index lo to hi-1.

Let me verify: a = [1, 2, 3], n=3, k=2.
lo = 0, hi = 3.
grad[0:3] = 2 * a[0:3][::-1] = 2 * [3, 2, 1] = [6, 4, 2]. ✓

Another: a = [1, 2, 3], n=3, k=1.
(a*a)[1] = a[0]*a[1] + a[1]*a[0] = 4.
grad[0] = 2*a[1] = 4, grad[1] = 2*a[0] = 2, grad[2] = 0.
lo = max(0, 1-3+1) = 0, hi = min(3, 2) = 2.
grad[0:2] = 2 * a[0:2][::-1] = 2 * [2, 1] = [4, 2]. ✓ (grad[2] remains 0)

So the formula is simply:
lo = max(0, k - n + 1)
hi = min(n, k + 1)
grad[lo:hi] = 2 * a[lo:hi][::-1]

This is very clean and efficient.

Now let me think about the overall algorithm more carefully.

**Multiplicative Weight Update:**
a_new[j] = a[j] * exp(-lr * grad_normalized[j])
Then normalize to sum = sqrt(2n) and clip at 0.

Where grad_normalized is the weighted subgradient, possibly normalized.

The advantage of multiplicative updates:
- Automatically maintains non-negativity
- Large gradient → big decrease
- Small gradient → small decrease
- Similar to "exponential weights" in online learning

**Additive update (projected gradient):**
a_new = project_simplex(a - lr * grad, sqrt(2n))

The advantage of additive updates:
- Can increase some coordinates (if they have small gradient)
- More flexible

I think a combination might work best: use multiplicative updates for the "bulk" and additive for "fine-tuning".

**Nesterov acceleration for subgradient:**
y_t = a_t + (t-1)/(t+2) * (a_t - a_{t-1})
a_{t+1} = project_simplex(y_t - lr_t * grad(y_t), sqrt(2n))

This should give O(1/T) rate instead of O(1/sqrt(T)) for the averaged iterates.

**Adaptive learning rate:**
lr_t = lr_0 / (1 + t * decay)
Or use "diminishing step" based on gradient norm.

Let me also think about what "special structure" the optimal solution might have.

For a sequence to have flat autocorrelation, it should be "spread out" in both time and frequency. This suggests:
- The sequence should not have large spikes (which would create high autocorrelation at lag 0)
- The sequence should not be too periodic (which would create high autocorrelation at the period lag)
- The sequence should be "chaotic" or "pseudo-random" looking

But it also needs to be non-negative, which constrains it to be in the positive orthant.

**Initialization ideas:**
1. The parent sequence (from height_sequence_1)
2. A "Spread spectrum" sequence: a[j] = |sum of a few shifted cosines| (ensures non-negativity)
3. A "chirp" sequence: a[j] = |cos(2*pi*(j^2/n))| (quadratic phase spread)
4. Random + optimize: start random, then optimize
5. Binary + smooth: start with a bit-reversal or similar pattern, then smooth

Let me now write the actual code:

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Fast smoothed subgradient descent with multiplicative weights
2. Nesterov-accelerated projected subgradient
3. LP best-response for refinement
4. Coordinate descent polish

Key insight: grad of (a*a)[k] w.r.t. a is 2*a[k-m] (reversed slice),
enabling O(n) gradient computation per peak.
"""

import numpy as np
import time
from scipy.fft import rfft, irfft

def fast_autocorr(a):
    """Compute full linear autocorrelation via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]

def project_simplex(a, S):
    """Euclidean projection onto {x >= 0, sum(x) = S}."""
    n = len(a)
    # Find tau such that sum(max(a - tau, 0)) = S
    # Binary search on tau
    lo_tau = a.min() - 1
    hi_tau = a.max() + 1
    
    # Use the O(n log n) algorithm
    sorted_a = np.sort(a)[::-1]
    cumulative = np.cumsum(sorted_a)
    # Find largest rho such that sorted_a[rho] > (cumulative[rho] - S) / (rho+1)
    # i.e., rho * sorted_a[rho] > cumulative[rho] - S
    vals = (cumulative - S) / np.arange(1, n + 1)
    valid = np.where(sorted_a > vals)[0]
    if len(valid) == 0:
        # All zero
        return np.full(n, S / n)
    rho = valid[-1]
    tau = (cumulative[rho] - S) / (rho + 1)
    result = np.maximum(a - tau, 0)
    # Fix numerical issues
    s = result.sum()
    if s < 1e-15:
        result = np.full(n, S / n)
    else:
        result *= S / s
    return result

def compute_grad_for_peaks(a, peak_indices, weights):
    """Compute weighted gradient sum for given peaks."""
    n = len(a)
    grad = np.zeros(n)
    for w, k in zip(weights, peak_indices):
        k = int(k)
        lo = max(0, k - n + 1)
        hi = min(n, k + 1)
        if lo < hi and w > 1e-10:
            grad[lo:hi] += 2.0 * w * a[lo:hi][::-1]
    return grad

def smoothed_subgradient_descent(a0, time_limit, verbose=False, seed=0):
    """Smoothed subgradient descent with soft-max weights and Nesterov acceleration."""
    rng = np.random.default_rng(seed)
    n = len(a0)
    S = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    a = project_simplex(a, S)
    
    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()
    
    # Parameters
    beta = 3.0  # Soft-max temperature (higher = more concentrated on max)
    top_k = 10  # Number of top peaks to consider
    lr0 = 0.5  # Initial learning rate
    lr_decay = 0.9999  # Decay factor per iteration
    use_nesterov = True
    
    y = a.copy()  # Nesterov momentum variable
    y_prev = a.copy()
    lr = lr0
    iter_count = 0
    no_improve = 0
    best_iter = 0
    
    while time.monotonic() - t0 < time_limit:
        # Check time more frequently
        if time.monotonic() - t0 > time_limit:
            break
        
        # Compute autocorrelation
        conv = fast_autocorr(y)
        M = conv.max()
        
        if M < best_score - 1e-12:
            best_score = M
            best_a = y.copy()
            no_improve = 0
            best_iter = iter_count
        else:
            no_improve += 1
        
        # Find top peaks
        n_peaks = min(top_k, len(conv))
        top_indices = np.argsort(conv)[-n_peaks:]
        
        # Soft-max weights
        peak_vals = conv[top_indices]
        logits = peak_vals * beta / max(M, 1e-10)
        logits -= logits.max()
        weights = np.exp(logits)
        weights /= weights.sum()
        
        # Compute gradient
        grad = compute_grad_for_peaks(y, top_indices, weights)
        
        # Normalize gradient
        gn = np.linalg.norm(grad)
        if gn < 1e-15:
            break
        grad_norm = grad / gn
        
        # Nesterov update
        if use_nesterov and iter_count > 0:
            momentum = (iter_count - 1.0) / (iter_count + 2.0)
            momentum = min(momentum, 0.95)
            y_new = y + momentum * (y - y_prev)
        else:
            y_new = y.copy()
        
        # Take step
        y_new = y_new - lr * grad_norm * S * 0.1
        y_new = project_simplex(y_new, S)
        
        y_prev = y
        y = y_new
        iter_count += 1
        lr *= lr_decay
        
        # Periodic re-initialization if stalled
        if no_improve > 200:
            y = best_a.copy()
            y_prev = best_a.copy()
            lr = lr0 * 0.5
            no_improve = 0
            # Add small random perturbation
            perturb = 0.01 * rng.standard_normal(n)
            y = project_simplex(y + perturb * S, S)
        
        if verbose and iter_count % 500 == 0:
            elapsed = time.monotonic() - t0
            print(f"    SSD iter={iter_count} ({elapsed:.0f}s): best={best_score:.10f}, lr={lr:.6f}")
    
    return best_a, best_score

def multiplicative_weight_descent(a0, time_limit, verbose=False, seed=0):
    """Multiplicative weight update for the subgradient problem."""
    rng = np.random.default_rng(seed)
    n = len(a0)
    S = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    a = project_simplex(a, S)
    # Add small epsilon to avoid log(0)
    a = a + 1e-10
    a = a / a.sum() * S
    
    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()
    
    beta = 5.0
    top_k = 8
    lr = 0.05
    iter_count = 0
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        conv = fast_autocorr(a)
        M = conv.max()
        
        if M < best_score - 1e-12:
            best_score = M
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        # Top peaks with soft-max
        n_peaks = min(top_k, len(conv))
        top_indices = np.argsort(conv)[-n_peaks:]
        peak_vals = conv[top_indices]
        logits = peak_vals * beta / max(M, 1e-10)
        logits -= logits.max()
        weights = np.exp(logits)
        weights /= weights.sum()
        
        # Gradient
        grad = compute_grad_for_peaks(a, top_indices, weights)
        
        # Multiplicative update
        # a_new[j] = a[j] * exp(-lr * grad[j] / max_grad)
        max_g = np.abs(grad).max()
        if max_g < 1e-15:
            break
        scale = lr / max_g
        a_new = a * np.exp(-scale * grad)
        
        # Project back to simplex
        a_new = project_simplex(a_new, S)
        a_new = np.maximum(a_new, 1e-10)
        a = a_new / a_new.sum() * S
        
        iter_count += 1
        lr *= 0.9995
        
        if no_improve > 300:
            a = best_a.copy() + 0.005 * S * rng.standard_normal(n)
            a = project_simplex(np.maximum(a, 0), S)
            no_improve = 0
            lr = 0.05
        
        if verbose and iter_count % 500 == 0:
            elapsed = time.monotonic() - t0
            print(f"    MWD iter={iter_count} ({elapsed:.0f}s): best={best_score:.10f}, lr={lr:.6f}")
    
    return best_a, best_score

def lp_best_response(a_fixed, M, active_set, solver):
    """Solve LP: max sum(b) s.t. (a_fixed * b)[k] <= M for k in active_set, b >= 0."""
    import cvxpy as cp
    n = len(a_fixed)
    k_indices = np.asarray(active_set)
    size = len(k_indices)
    
    T = np.zeros((size, n))
    for idx in range(size):
        k = int(k_indices[idx])
        lo = max(0, k - n + 1)
        hi = min(n, k + 1)
        if lo < hi:
            T[idx, lo:hi] = a_fixed[lo:hi][::-1]
    
    b_var = cp.Variable(n, nonneg=True)
    constraints = [T @ b_var <= M]
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        return None, None
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None, None
    b_val = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
    if b_val.sum() < 1e-15:
        return None, None
    duals = None
    try:
        dual_val = constraints[0].dual_value
        if dual_val is not None:
            duals = np.asarray(dual_val, dtype=np.float64)
    except Exception:
        pass
    return b_val, duals

def nesterov_lp_optimize(a0, time_limit, solver, verbose=False, seed=0):
    """Nesterov-accelerated LP best-response with progressive active-set tightening."""
    import cvxpy as cp
    rng = np.random.default_rng(seed)
    n = len(a0)
    S = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    a = project_simplex(a, S)
    
    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    
    y = a.copy()
    y_prev = a.copy()
    t0 = time.monotonic()
    active_set = None
    stall_count = 0
    n_iters = 0
    conv_size = 2 * n - 1
    
    for t in range(1, 10000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        conv_y = fast_autocorr(y)
        M_curr = conv_y.max()
        
        # Progressive active set
        if active_set is None or t % 30 == 0:
            progress = min(1.0, t / 500.0)
            tol = 0.1 * (1.0 - progress) + 0.01 * progress
            base_threshold = M_curr * (1.0 - tol)
            active_set = np.where(conv_y >= base_threshold)[0]
            n_top = max(5, n // 100)
            top_k = np.argsort(conv_y)[-n_top:]
            active_set = np.unique(np.concatenate([active_set, top_k]))
            if len(active_set) > int(1.2 * n):
                conv_at_active = conv_y[active_set]
                keep = np.argsort(conv_at_active)[-int(1.2 * n):]
                active_set = active_set[keep]
        
        b, duals = lp_best_response(y, M_curr, active_set, solver)
        
        if b is None:
            if t % 5 == 0:
                active_set = np.arange(conv_size)
                b, duals = lp_best_response(y, M_curr, active_set, solver)
            if b is None:
                continue
        
        b_sum = b.sum()
        if b_sum < 1e-15:
            continue
        g = b * S / b_sum
        n_iters += 1
        
        # Nesterov update
        alpha = 2.0 / (t + 2.0)
        y_new = (1.0 - alpha) * y + alpha * g
        y_new = np.maximum(y_new, 0.0)
        y_new = project_simplex(y_new, S)
        
        if t == 1:
            a_new = g.copy()
        else:
            momentum = min((t - 1.0) / (t + 2.0), 0.95)
            a_new = y_new + momentum * (y_new - y_prev)
            a_new = project_simplex(np.maximum(a_new, 0.0), S)
        
        y_prev = y
        y = y_new
        a = a_new
        
        score_y = fast_autocorr(y).max()
        if score_y < best_score:
            best_score = score_y
            best_a = y.copy()
            stall_count = 0
        else:
            stall_count += 1
        
        if stall_count > 50:
            y = best_a.copy()
            y_prev = best_a.copy()
            a = best_a.copy()
            active_set = None
            stall_count = 0
        
        if verbose and n_iters % 100 == 0:
            elapsed = time.monotonic() - t0
            print(f"    LP iter={n_iters} ({elapsed:.0f}s): best={best_score:.10f}")
    
    return best_a, best_score

def coordinate_descent_polish(a0, time_limit, verbose=False, seed=0):
    """Coordinate descent for final polish."""
    rng = np.random.default_rng(seed)
    n = len(a0)
    S = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    a = project_simplex(a, S)
    
    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()
    size = 2 * n - 1
    no_improve = 0
    
    for outer in range(50):
        if time.monotonic() - t0 > time_limit:
            break
        if no_improve > 3:
            break
        
        conv = fast_autocorr(a)
        improved = False
        order = rng.permutation(n)
        
        for j in order:
            if time.monotonic() - t0 > time_limit:
                break
            
            aj = a[j]
            if aj < 1e-10:
                # Try setting to small positive value
                candidates = [S / (10 * n), S / (5 * n)]
            else:
                # Try scaling
                candidates = [aj * f for f in [0.3, 0.6, 0.8, 1.2, 1.5, 2.0, 5.0]]
                candidates.append(0.0)
                candidates.append(S / n)
            
            best_x = aj
            best_obj = best_score + 1  # Current best
            
            for x in candidates:
                x = max(0.0, min(x, S * 0.5))
                if abs(x - aj) < 1e-12:
                    continue
                
                # Efficient update of autocorrelation
                new_conv = conv.copy()
                delta = x - aj
                lo = max(0, j)
                hi = min(size, j + n)
                new_conv[lo:hi] += 2.0 * delta * a[lo - j: hi - j]
                if 2 * j < size:
                    new_conv[2 * j] += delta * delta
                
                new_sum = a.sum() - aj + x
                if new_sum < 1e-15:
                    continue
                scale = S / new_sum
                new_max = new_conv.max() * scale * scale
                
                if new_max < best_obj:
                    best_obj = new_max
                    best_x = x
            
            if abs(best_x - aj) > 1e-12:
                a[j] = best_x
                a = a / a.sum() * S
                new_score = fast_autocorr(a).max()
                if new_score < best_score - 1e-13:
                    best_score = new_score
                    best_a = a.copy()
                    conv = fast_autocorr(a)
                    improved = True
                else:
                    a = best_a.copy()
                    conv = fast_autocorr(a)
        
        if not improved:
            no_improve += 1
    
    return best_a, best_score

def get_solver():
    import cvxpy as cp
    for s in [cp.CLARABEL, cp.PDLP, cp.SCS, cp.ECOS]:
        try:
            x = cp.Variable(4, nonneg=True)
            prob = cp.Problem(cp.Minimize(cp.sum(x)), [cp.sum(x) == 1, x <= 0.4])
            prob.solve(solver=s)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                return s
        except Exception:
            continue
    return cp.ECOS
```

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Fast smoothed subgradient descent with simplified gradient (reversed slice)
2. KKT-condition-based refinement (weighted autocorrelation constant on support)
3. Multiplicative weight updates
4. LP best-response with Nesterov acceleration
5. Coordinate descent polish
Key insight: d(a*a)[k]/da[m] = 2*a[k-m] (reversed slice), enabling O(n) per peak.
"""

import numpy as np
import time
from scipy.fft import rfft, irfft


def fast_autocorr(a):
    """Compute full linear autocorrelation via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def project_simplex(a, S):
    """Euclidean projection onto {x >= 0, sum(x) = S}."""
    n = len(a)
    if n == 0:
        return a
    sorted_a = np.sort(a)[::-1]
    cumulative = np.cumsum(sorted_a)
    vals = (cumulative - S) / np.arange(1, n + 1)
    valid = np.where(sorted_a > vals)[0]
    if len(valid) == 0:
        return np.full(n, S / n)
    rho = valid[-1]
    tau = (cumulative[rho] - S) / (rho + 1)
    result = np.maximum(a - tau, 0.0)
    s = result.sum()
    if s < 1e-15:
        result = np.full(n, S / n)
    else:
        result *= S / s
    return result


def compute_grad_peaks(a, peak_indices, weights):
    """Compute weighted gradient sum. grad[m] = 2*sum_k w_k * a[k-m] (reversed slice)."""
    n = len(a)
    grad = np.zeros(n)
    for idx in range(len(peak_indices)):
        w = weights[idx]
        if w < 1e-12:
            continue
        k = int(peak_indices[idx])
        lo = max(0, k - n + 1)
        hi = min(n, k + 1)
        if lo < hi:
            grad[lo:hi] += 2.0 * w * a[lo:hi][::-1]
    return grad


def get_top_weights(conv, M, beta, n_peaks):
    """Get soft-max weights over top peaks."""
    n_total = len(conv)
    n_peaks = min(n_peaks, n_total)
    top_indices = np.argsort(conv)[-n_peaks:]
    peak_vals = conv[top_indices]
    logits = peak_vals * beta / max(M, 1e-10)
    logits -= logits.max()
    weights = np.exp(logits)
    weights /= weights.sum()
    return top_indices, weights

def smoothed_subgradient(a0, time_limit, verbose=False, seed=0):

    y_prev = a.copy()

def kkt_refinement(a0, time_limit, verbose=False, seed=0):
    """
    KKT-based refinement: at optimum, weighted sum of reversed shifts is constant on support.
    We iterate: identify active peaks, solve for dual weights, compute violation, update.
    """
    rng = np.random.default_rng(seed)
    n = len(a0)
    S = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    a = project_simplex(a, S)

    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()
    lr = 0.1
    patience = 0
    max_patience = 300

    while time.monotonic() - t0 < time_limit:
        if patience > max_patience:
            break

        conv = fast_autocorr(a)
        M = conv.max()

        if M < best_score - 1e-13:
            best_score = M
            best_a = a.copy()
            patience = 0
        else:
            patience += 1

        # Identify active peaks (where conv is close to max)
        tol = 0.03
        active = np.where(conv >= M * (1.0 - tol))[0]
        if len(active) < 3:
            active = np.argsort(conv)[-max(3, n // 80):]
        if len(active) > 50:
            # Keep top 50
            active_vals = conv[active]
            keep = np.argsort(active_vals)[-50:]
            active = active[keep]

        # For KKT: we want sum_k lambda_k * 2*a[k-m] = const for m in support
        # This is a least-squares problem: A * lambda = c
        # Where A[m, k] = 2*a[k-m] (the gradient contribution of peak k at position m)
        support_thresh = 0.002 * a.max()
        support = np.where(a > support_thresh)[0]
        if len(support) < 2:
            break

        # Build matrix A (support x active)
        n_active = len(active)
        A_mat = np.zeros((len(support), n_active))
        for ki, k in enumerate(active):
            k = int(k)
            for si, m in enumerate(support):
                diff = k - m
                if 0 <= diff < n:
                    A_mat[si, ki] = 2.0 * a[diff]

        # Solve least squares: A * lambda ~= mu * 1
        # Normalize: minimize ||A*lambda - ones||^2
        try:
            lam, _, _, _ = np.linalg.lstsq(A_mat, np.ones(len(support)), rcond=None)
        except Exception:
            lam = np.ones(n_active) / n_active
        lam = np.maximum(lam, 0)
        if lam.sum() < 1e-15:
            lam = np.ones(n_active) / n_active
        lam = lam / lam.sum()

        # Compute the "violation": v[m] = sum_k lam_k * 2*a[k-m] for m in support
        # The variance of v on support should be 0 at optimum
        v = A_mat @ lam
        v_mean = v.mean()
        v_std = v.std()

        if v_std < 1e-8:
            patience += 10
            continue

        # Direction: reduce a where v is high, increase where v is low
        # Extended to full vector
        v_full = np.zeros(n)
        for ki, k in enumerate(active):
            k = int(k)
            lo = max(0, k - n + 1)
            hi = min(n, k + 1)
            if lo < hi:
                v_full[lo:hi] += 2.0 * lam[ki] * a[lo:hi][::-1]

        v_full[support] = (v_full[support] - v_mean) / max(v_std, 1e-10)

        a_new = a - lr * v_full
        a_new = project_simplex(a_new, S)

        new_score = fast_autocorr(a_new).max()
        if new_score < best_score - 1e-14:
            a = a_new
            best_score = new_score
            best_a = a_new.copy()
            patience = 0
            lr = min(lr * 1.01, 1.0)
        else:
            lr *= 0.97
            if lr < 1e-8:
                # Try perturbation
                a = best_a + 0.005 * S * rng.standard_normal(n)
                a = project_simplex(np.maximum(a, 0), S)
                lr = 0.1

        if verbose and patience % 200 == 0:
            elapsed = time.monotonic() - t0
            print(f"    KKT iter={patience} ({elapsed:.0f}s): best={best_score:.10f}, v_std={v_std:.6f}")

    return best_a, best_score

def lp_solve(a_fixed, M, active_set, solver):
    """Solve LP: max sum(b) s.t. (a_fixed * b)[k] <= M for k in active_set, b >= 0."""
    import cvxpy as cp
    n = len(a_fixed)
    k_indices = np.asarray(active_set)
    size = len(k_indices)

    T = np.zeros((size, n))
    for idx in range(size):
        k = int(k_indices[idx])
        lo = max(0, k - n + 1)
        hi = min(n, k + 1)
        if lo < hi:
            T[idx, lo:hi] = a_fixed[lo:hi][::-1]

    b_var = cp.Variable(n, nonneg=True)
    constraints = [T @ b_var <= M]
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        return None, None
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None, None
    b_val = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
    if b_val.sum() < 1e-15:
        return None, None
    duals = None
    try:
        dual_val = constraints[0].dual_value
        if dual_val is not None:
            duals = np.asarray(dual_val, dtype=np.float64)
    except Exception:
        pass
    return b_val, duals

                y = project_simplex(np.maximum(y, 0), S)

def coord_descent(a0, time_limit, verbose=False, seed=0):
    """Coordinate descent with efficient autocorrelation updates."""
    rng = np.random.default_rng(seed)
    n = len(a0)
    S = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    a = project_simplex(a, S)

    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()
    size = 2 * n - 1
    no_improve = 0

    for outer in range(100):
        if time.monotonic() - t0 > time_limit:
            break
        if no_improve > 4:
            break

        conv = fast_autocorr(a)
        improved = False
        order = rng.permutation(n)

        for j in order:
            if time.monotonic() - t0 > time_limit:
                break
            aj = a[j]
            if aj < 1e-10:
                candidates = [S / (20 * n), S / (10 * n), S / (5 * n)]
            else:
                candidates = [0.0, aj * 0.2, aj * 0.5, aj * 0.75, aj * 1.25, aj * 1.6, aj * 2.5, S / n]

            best_x = aj
            best_obj = conv.max()

            for x in candidates:
                x = max(0.0, min(x, S * 0.5))
                if abs(x - aj) < 1e-12:
                    continue
                new_conv = conv.copy()
                delta = x - aj
                lo = max(0, j)
                hi = min(size, j + n)
                new_conv[lo:hi] += 2.0 * delta * a[lo - j: hi - j]
                if 2 * j < size:
                    new_conv[2 * j] += delta * delta
                new_sum = a.sum() - aj + x
                if new_sum < 1e-15:
                    continue
                scale = S / new_sum
                new_max = new_conv.max() * scale * scale
                if new_max < best_obj:
                    best_obj = new_max
                    best_x = x

            if abs(best_x - aj) > 1e-12:
                a[j] = best_x
                a = a / a.sum() * S
                ns = fast_autocorr(a).max()
                if ns < best_score - 1e-13:
                    best_score = ns
                    best_a = a.copy()
                    conv = fast_autocorr(a)
                    improved = True
                else:
                    a = best_a.copy()
                    conv = fast_autocorr(a)

        if not improved:
            no_improve += 1
        else:
            no_improve = 0

        if verbose and (outer + 1) % 5 == 0:
            elapsed = time.monotonic() - t0
            print(f"    CD pass={outer+1} ({elapsed:.0f}s): best={best_score:.10f}")

    return best_a, best_score
