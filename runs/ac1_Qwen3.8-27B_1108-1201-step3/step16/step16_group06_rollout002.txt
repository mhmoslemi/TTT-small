Use the top-K peaks to compute a subgradient, and use Nesterov-accelerated gradient descent. This is O(n log n) per iteration vs O(n^2) or more for LP.

**Improvement 3: Solution polishing via local QP**

After the main optimization, solve a local QP: minimize max_k (c_k(a*) + grad_k(a*)^T (a - a*)) subject to a >= 0, sum(a) = 1, ||a - a*||_2 <= r. This is a convex problem that can give a small improvement.

**Improvement 4: Multi-start with diverse initializations**

Try different initial shapes:
- Uniform
- Semicircle: a[i] = sin(pi * (i+0.5)/n)
- Gaussian: a[i] = exp(-((i-n/2)/(n/4))^2)
- Raised cosine: a[i] = 0.5 * (1 + cos(2*pi*(i+0.5)/n))
- Triangular: a[i] = 1 - |2*(i+0.5)/n - 1|

**Improvement 5: Post-LP-FW refinement**

After LP-FW converges, do a "dual" approach:
- Identify the binding constraints (peaks at the maximum)
- Try to reduce those peaks while keeping others below the maximum
- Use small LPs or coordinate moves
