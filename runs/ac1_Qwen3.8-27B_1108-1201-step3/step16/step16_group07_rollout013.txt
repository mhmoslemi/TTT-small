Actually, I think the cleanest way is:
`sum_k w[k] * a[|k-j|]` = convolution of w with the "bilateral" extension of a.

Define a_bil of length L (L >= 2n-1 + 2*(n-1) = 4n-3) as:
a_bil[m] = a[m - (n-1)] for (n-1) <= m <= (n-1) + (n-1) = 2n-2 (the "forward" part)
a_bil[m] = a[(n-1) - m] for 0 <= m <= n-2 (the "backward" part)
a_bil[m] = 0 otherwise

Then: conv(w, a_bil)[j + (n-1)] = sum_k w[k] * a_bil[j+n-1-k]
For the term to be non-zero, we need 0 <= j+n-1-k <= 2n-2, i.e., j+n-1-(2n-2) <= k <= j+n-1, i.e., j-n+3 <= k <= j+n-1.
And a_bil[j+n-1-k] = a[j+n-1-k-(n-1)] = a[j-k] if j+n-1-k >= n-1, i.e., k <= j.
Or a_bil[j+n-1-k] = a[(n-1)-(j+n-1-k)] = a[k-j] if j+n-1-k < n-1, i.e., k > j.

So conv(w, a_bil)[j+n-1] = sum_{k<=j} w[k]*a[j-k] + sum_{k>j} w[k]*a[k-j] = sum_k w[k]*a[|k-j|] ✓ (with a[x]=0 for x<0 or x>=n)

But wait, a_bil as defined has a_bil[m] = a[m-(n-1)] for m in [n-1, 2n-2], which means the indices of a are 0 to n-1. And a_bil[m] = a[(n-1)-m] for m in [0, n-2], which means the indices of a are (n-1)-m ranging from n-1 down to 1.

So a_bil[0] = a[n-1], a_bil[1] = a[n-2], ..., a_bil[n-2] = a[1], a_bil[n-1] = a[0], a_bil[n] = a[1], ..., a_bil[2n-2] = a[n-1].

So a_bil = [a[n-1], a[n-2], ..., a[1], a[0], a[1], ..., a[n-1]] (length 2n-1).

And the result is: grad[j]/2 = conv(w, a_bil)[j+n-1] where the convolution is linear (full).

The length of the full convolution is (2n-1) + (2n-1) - 1 = 4n-3.
We want elements at positions j+n-1 for j in [0, n-1], i.e., positions n-1 to 2n-2.

So: `full_conv = np.convolve(w, a_bil)` (length 4n-3), and `grad = 2 * full_conv[n-1 : 2n-1]`.
