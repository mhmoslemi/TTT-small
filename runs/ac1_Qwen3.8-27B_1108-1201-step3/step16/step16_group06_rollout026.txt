Peak shaving:
1. Find the peak location k* (where conv(a,a) is maximized).
2. Compute the "gradient" of the peak with respect to a: d(conv(a,a))[k*]/da[i] = 2*a[k*-i] (for valid i).
3. Move a in the direction that reduces the peak: a[i] -= eta * gradient[i] (for the "source" positions) and redistribute to "sink" positions.

This is essentially subgradient descent on the function max_k (conv(a,a))[k].

The multiplicative weight update (or "exponential weights") is:
a_new[i] = a[i] * exp(-eta * grad[i]) / Z

where grad[i] = sum_{k in peaks} w_k * a[k-i] (the subgradient contribution).

This is similar to the "soft_subgradient_descent" in the previous code, but with a better initialization.

The number of constraints is 2n-1, and the number of variables is n. For n=3000, this is 5999 constraints and 3000 variables. The matrix T is (2n-1) x n with a special structure (it's like a Toeplitz matrix but with the values of y).
