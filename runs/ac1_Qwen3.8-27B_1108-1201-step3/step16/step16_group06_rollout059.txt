**Key insight: The LP `max sum(b) s.t. conv(y,b) <= M, b >= 0` has a simple structure.**

The LP is: max 1^T b s.t. A b <= M * 1, b >= 0, where A is (2n-1) x n Hankel.

**Exploiting the Hankel structure:**

The dual is: min M * 1^T u s.t. A^T u >= 1, u >= 0.

(A^T u)_j = sum_k A[k,j] * u[k] = sum_k y[k-j] * u[k] (where 0 <= k-j < n).

Let m = k-j, so k = j+m. Then (A^T u)_j = sum_{m=0}^{n-1} y[m] * u[j+m].

This is the cross-correlation of y and u at lag j! So the dual constraint is:
(y ⋆ u)[j] >= 1 for j = 0, ..., n-1, where ⋆ denotes cross-correlation.

And the dual objective is: min M * sum(u[k]) for k = 0, ..., 2n-2.

So the dual is: min M * ||u||_1 s.t. (y ⋆ u)[j] >= 1 for j = 0, ..., n-1, u >= 0.

This is a **minimum l1-norm problem with correlation constraints**. It's a convex problem and can be solved with First-Order methods.

But more importantly, the structure means we can use **FFT-based** methods to compute the correlation quickly, and potentially use a **projected gradient** or **ADMM** approach for the dual.

For the FW iteration, we need the primal solution b. By strong duality:
- LP_primal_value = LP_dual_value = M * sum(u*)
- The primal solution b* satisfies: b*_j > 0 ⟺ (A^T u*)_j = 1 (complementary slackness)

So b*_j > 0 only at the "active" constraints. The number of active constraints equals the number of non-zero u*_k.

In practice, the number of active constraints (and non-zero b entries) is much less than n (typically O(n^0.5) or less). So b is sparse!

This is great because:
1. We can solve the dual (which has 2n-1 variables) using a first-order method that exploits the correlation structure.
2. The primal solution b is sparse, so the FW direction is sparse.
