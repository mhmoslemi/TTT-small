**Algorithm: Projected subgradient/ascent method**

1. Start with a good initialization (parent sequence).
2. At each iteration:
   a. Compute the convolution c = conv(a, a).
   b. Find the active lags S = {k : c_k = max(c)} (or near-max).
   c. Compute the subgradient g = 2 * sum_{k in S} w_k * (P_k * a).
   d. Take a step in the negative direction: a_new = a - eta * g (projected to simplex {a >= 0, sum(a) = 1}).
   e. Use adaptive step size (backtracking or decreasing schedule).

The "projection to simplex" (a >= 0, sum(a) = 1) can be done efficiently.

But wait, this is a non-convex problem (max of quadratics), so subgradient descent won't necessarily converge to a global optimum. But it might work in practice.

**Alternative: Frank-Wolfe (Conditional Gradient) method**

The Frank-Wolfe method for minimizing F(a) over the simplex:
1. At current point a, compute the (sub)gradient g.
2. Solve the linear minimization: min_{v in simplex} g^T v. The solution is v = e_j where j = argmin_j g[j].
3. Update: a <- a + alpha*(v - a) for some alpha.

This is simple and efficient! The linear minimization over the simplex is just picking the coordinate with the most negative gradient.

But this is very myopic. A better version: solve min_{v in simplex} g^T v + (lambda/2)*||v - a||^2 (proximal variant), or use the standard FW with alpha = 2/(t+2).

Actually, for the standard FW method:
- alpha_t = 2/(t+2) (or 1/t for the variant)
- a_{t+1} = (1-alpha_t)*a_t + alpha_t*v_t where v_t = argmin_{v in simplex} <g_t, v>

Let me think about the subgradient computation more carefully for efficiency.

Given a of length n, and a lag k, the contribution to the gradient is:
g[j] += 2 * a[k-j] for j where 0 <= k-j < n, i.e., j in [max(0, k-n+1), min(k, n-1)]

So for each active lag k, I need to add `2*a[k-j]` to g[j] for j in a range. This is like a "smeared" version of a.

For efficiency, if I have many active lags, I can compute the gradient as:
g = 2 * sum_{k active} w_k * (a reversed and shifted by k)

This can be done with FFT or direct computation.

For a single lag k: the vector (P_k * a)[j] = a[k-j] if 0 <= k-j < n, else 0.
This is a[i] with i = k-j, so it's a "reversal and shift" of a.

If I precompute the reversal of a (a_rev[i] = a[n-1-i]), then:
(P_k * a)[j] = a[k-j] = a_rev[n-1-k+j]

So it's a shifted version of a_rev. For multiple lags, it's a weighted sum of shifted versions of a_rev.

This can be computed efficiently using FFT:
g/2 = sum_k w_k * shift(a_rev, n-1-k)

The FFT of a shifted signal is the FFT of the signal multiplied by a phase factor. So:
FFT(g/2) = FFT(a_rev) * sum_k w_k * exp(2πi(n-1-k)/N)

where N is the FFT size. This is O(N + K) where K is the number of active lags.

But for simplicity, I'll just do the direct computation for small K (top-k lags), which is O(n*K).

import numpy as np
import time

def fast_autocorr(a):
    """Compute full linear convolution a*a via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def softmax_subgradient(a, conv, top_k=50, beta=3.0):
    """Compute subgradient using top-k lags with softmax weighting."""
    n = len(a)
    k_max = min(top_k, len(conv))
    
    # Select top-k lags
    if len(conv) <= k_max:
        idx = np.arange(len(conv))
        vals = conv[idx].copy()
    else:
        # Partial sort for efficiency
        part = np.argpartition(conv, -k_max)[-k_max:]
        idx = np.sort(part)
        vals = conv[idx].copy()
    
    # Softmax weights
    vals = np.maximum(vals, 1e-30)
    log_w = beta * np.log(vals)
    log_w -= log_w.max()
    w = np.exp(log_w)
    w_sum = w.sum()
    if w_sum < 1e-30:
        w = np.ones_like(w) / len(w)
    else:
        w = w / w_sum
    
    # Compute gradient: g[j] = 2 * sum_k w_k * a[k-j] (valid indices)
    g = np.zeros(n)
    for wi, k in zip(w, idx):
        if wi < 1e-12:
            continue
        k_int = int(k)
        # j ranges from max(0, k-n+1) to min(k, n-1)
        j_start = max(0, k_int - n + 1)
        j_end = min(n, k_int + 1)
        if j_start >= j_end:
            continue
        # a[k_int - j] for j in [j_start, j_end)
        a_indices = k_int - np.arange(j_start, j_end)
        g[j_start:j_end] += 2.0 * wi * a[a_indices]
    
    return g

def frank_wolfe(a0, time_limit, top_k=80, beta=3.0, verbose=True):
    """Frank-Wolfe with softmax subgradient and Chebyshev step size."""
    n = len(a0)
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    t0 = time.monotonic()
    best_a = a.copy()
    best_conv = fast_autocorr(a)
    best_max = best_conv.max()
    
    for t in range(1, 10000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        conv = fast_autocorr(a)
        current_max = conv.max()
        
        if current_max < best_max:
            best_max = current_max
            best_a = a.copy()
        
        g = softmax_subgradient(a, conv, top_k=top_k, beta=beta)
        
        # FW: linear minimization over simplex -> pick coordinate with min gradient
        j = int(np.argmin(g))
        v = np.zeros(n)
        v[j] = 1.0
        
        # Chebyshev step size
        gv = g[j]
        ga = g @ a
        denom = (a - v) @ (a - v)
        if denom < 1e-30:
            break
        alpha = (ga - gv) / denom
        alpha = min(max(alpha, 0.0), 1.0)
        
        a_new = (1.0 - alpha) * a + alpha * v
        a_new = np.maximum(a_new, 0.0)
        s_new = a_new.sum()
        if s_new < 1e-15:
            a_new = a.copy()
        else:
            a_new = a_new / s_new
        
        a = a_new
        
        if verbose and t % 1000 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_max
            print(f"    FW t={t} ({elapsed:.1f}s): J={J:.6f}, max_conv={best_max:.8f}")
    
    return best_a, best_max

def mirror_descent(a0, time_limit, top_k=80, initial_lr=0.1, verbose=True):
    """Nesterov mirror descent with adaptive subgradient."""
    n = len(a0)
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    t0 = time.monotonic()
    best_a = a.copy()
    best_conv = fast_autocorr(a)
    best_max = best_conv.max()
    
    x = a.copy()
    x_prev = a.copy()
    lr = initial_lr
    stall = 0
    max_stall = 500
    
    for t in range(1, 10000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Nesterov momentum
        beta_t = (t - 0.5) / (t + 1.5)
        y = x + beta_t * (x - x_prev)
        y = np.maximum(y, 1e-15)
        y = y / y.sum()
        
        conv = fast_autocorr(y)
        g = softmax_subgradient(y, conv, top_k=top_k, beta=3.0)
        
        # Adaptive learning rate
        eta = lr / (np.sqrt(t) + 1.0)
        
        # Mirror descent update
        log_a = np.log(y) - eta * g
        log_a -= log_a.max()
        a_new = np.exp(log_a)
        a_new = np.maximum(a_new, 1e-30)
        a_new = a_new / a_new.sum()
        
        x_prev = x
        x = a_new
        
        m = fast_autocorr(x).max()
        if m < best_max - 1e-15:
            best_max = m
            best_a = x.copy()
            stall = 0
        else:
            stall += 1
        
        if stall > max_stall:
            # Reduce learning rate and reset
            lr *= 0.5
            stall = 0
            max_stall = max(100, max_stall // 2)
            # Also try perturbing
            if lr < 1e-4:
                break
        
        if verbose and t % 2000 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_max
            print(f"    MD t={t} ({elapsed:.1f}s): J={J:.6f}, lr={lr:.6f}")
    
    return best_a, best_max

def coordinate_polish(a0, time_limit, verbose=True):
    """Coordinate descent: for each coordinate, find optimal transfer to minimize max_conv."""
    n = len(a0)
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    t0 = time.monotonic()
    best_a = a.copy()
    best_conv = fast_autocorr(a)
    best_max = best_conv.max()
    rng = np.random.default_rng(42)
    
    stall = 0
    max_stall = 3
    
    while time.monotonic() - t0 < time_limit and stall < max_stall:
        improved = False
        coord_order = np.arange(n)
        rng.shuffle(coord_order)
        
        for i in coord_order:
            if time.monotonic() - t0 > time_limit:
                break
            if a[i] < 1e-12:
                continue
            
            # Try moving a small amount from i to several random targets
            n_targets = min(5, n)
            targets = rng.choice(n, size=n_targets, replace=False)
            
            best_trial = None
            best_trial_max = best_max
            
            for dst in targets:
                if dst == i:
                    continue
                for frac in [0.01, 0.05, 0.1, 0.2]:
                    amt = a[i] * frac
                    a_trial = a.copy()
                    a_trial[i] -= amt
                    a_trial[dst] += amt
                    a_trial = np.maximum(a_trial, 0.0)
                    s_t = a_trial.sum()
                    if s_t < 1e-15:
                        continue
                    a_trial = a_trial / s_t
                    m = fast_autocorr(a_trial).max()
                    if m < best_trial_max - 1e-14:
                        best_trial_max = m
                        best_trial = a_trial.copy()
            
            if best_trial is not None:
                a = best_trial
                best_max = best_trial_max
                best_a = a.copy()
                improved = True
        
        if improved:
            stall = 0
        else:
            stall += 1
    
    return best_a, best_max
