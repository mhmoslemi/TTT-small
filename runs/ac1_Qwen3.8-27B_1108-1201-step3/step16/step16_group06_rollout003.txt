The peak of this as a function of `alpha` is `max_k [(1-alpha)^2 * b[k] + 2*alpha*(1-alpha) * c[k] + alpha^2 * e[k]]`

where `b = conv(a,a)`, `c = conv(a,d)`, `e = conv(d,d)`.

This is a max of quadratic functions of `alpha`, which is a convex function of `alpha`. We can minimize it by ternary search or by checking the critical points.

This exact line search would give much faster convergence than the standard FW step size!

2. **Better LP oracle**: The LP `max sum(b) s.t. T @ b <= M, b >= 0` is good, but we could also try:

3. **Active set identification**: After convergence, identify which lags are at the maximum. The optimal solution should have all active lags at exactly the same value. We can then solve a smaller system.
