Now, for c in [0, n-1]:
b[n-1+c] = sum_{i=c}^{n-1} (i+1)(n+c-i)

This is a sum of (n-1-c+1) = n-c terms. Each term is (i+1)(n+c-i).

The function (i+1)(n+c-i) is a downward parabola in i, with maximum at i = (n+c-1)/2.

So the sum is maximized when the parabola's peak is within the summation range [c, n-1].

The peak of the parabola is at i* = (n+c-1)/2. This is in [c, n-1] when:
c <= (n+c-1)/2 <= n-1
2c <= n+c-1 => c <= n-1 ✓ (always true)
(n+c-1)/2 <= n-1 => n+c-1 <= 2n-2 => c <= n-1 ✓ (always true)

So the peak is always in the range. The sum is a "trapezoidal" approximation of the parabola integral.
