def project_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.argmax(1 - u * np.arange(1, n + 1) > cssv)
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)

For coordinate descent, I'll use a "sensitivity-guided" approach:
1. Compute c = a*a and find the peak
2. For the peak position k*, compute the sensitivity of c_{k*} to each a_i
3. Move mass from high-sensitivity positions to low-sensitivity positions
4. Use line search to find the best amount

Actually, let me think about a simpler but effective coordinate descent:

For each pair (i, j), consider moving a small amount from a_i to a_j. The effect on the objective can be computed analytically (approximately).

If we move amount δ from a_i to a_j:
- a_i' = a_i - δ, a_j' = a_j + δ
- (a'*a')_k = (a*a)_k + δ*(a_{k-i} - a_{k-j}) + δ^2*(terms involving i and j)
- For small δ, the linear term dominates

The change in the peak is approximately:
Δmax ≈ max_k [(a*a)_k + δ*(a_{k-i} - a_{k-j})] - max_k (a*a)_k

For the current peak k*, this is:
Δc_{k*} ≈ δ * (a_{k*-i} - a_{k*-j})

We want this to be negative, so we want a_{k*-j} > a_{k*-i}, i.e., the destination j should have a larger value at position k*-j than the source i has at position k*-i.

This is a good heuristic for choosing moves.

def project_simplex(v):
    """Euclidean projection onto probability simplex."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    ar = np.arange(1, n + 1)
    cond = 1.0 - u * ar > cssv
    if not cond.any():
        return v / v.sum()
    rho = np.argmax(~cond)
    if rho == 0 and not cond[0]:
        rho = np.max(np.where(cond))
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def smooth_grad(a, beta):
    """
    Compute smooth gradient of 2n*lse(beta, a*a) w.r.t. a.

    c = fast_conv(a)

    bc_max = bc.max()

    S = exp_bc.sum()
