If a is symmetric, `(a*a)[n-1] = sum a[j]^2 >= (sum)^2/n` by Cauchy-Schwarz.

But what if the maximum is NOT at the center? What if some other lag has a larger value?

For non-symmetric a, the maximum could be at any lag. The question is whether we can make ALL lags have value < (sum)^2/n.

Let's consider: `(sum a)^2 = sum_{j,k} a[j]*a[k] = sum_k (a*a)[k]`? No, that's not right either.

There are 2n-1 lags. So the AVERAGE value of (a*a)[k] over all lags is `(sum a)^2 / (2n-1)`.

For the score to be < 2: `max_conv < (sum a)^2 / n`.

OK so now I understand the problem better. Let me think about how to minimize the peak of the autocorrelation.

This is essentially the "ambiguity function minimization" problem, or the "low PSL (peak sidelobe level)" sequence design problem.

For continuous-valued non-negative sequences, the optimal solution should have the autocorrelation as flat as possible.

Key approaches:
1. **LP-based**: Alternate between fixing a and optimizing b (the "best response" for the opponent)
2. **Gradient-based**: Use the subgradient at the maximizing lag
3. **Frequency domain**: Work with the power spectrum

Let me think about the frequency domain approach more carefully.

For a sequence a of length n, define the DFT: `A[m] = sum_j a[j] * exp(-2*pi*i*j*m/n)` for m = 0, ..., n-1.

The circular autocorrelation is: `r[k] = sum_j a[j]*a[(j+k) mod n] = IDFT(|A|^2)[k]`.

For linear autocorrelation, it's different, but for sequences that are "zero-padded" or have most energy in the middle, the two are similar.

If we want the circular autocorrelation to be flat (all r[k] = (sum a)^2/n), we need |A[m]|^2 to be proportional to a delta function at m=0, i.e., |A[m]| = 0 for m != 0. This means a[j] is constant (uniform), which gives r[k] = (sum a)^2/n for all k. Wait, that's already flat!

For uniform a: A[m] = sum a * exp(-2*pi*i*j*m/n) = n*a * delta_{m,0} (for circular). So |A|^2 = n^2*a^2 * delta_{m,0}. And IDFT of this is n*a^2 for all k. And (sum a)^2/n = (n*a)^2/n = n*a^2. Yes, it's flat!

So the circular autocorrelation of a uniform sequence IS flat. But the LINEAR autocorrelation is a triangle: [a^2, 2a^2, 3a^2, ..., n*a^2, (n-1)*a^2, ..., a^2].

The difference is that linear convolution doesn't wrap around. So the peak is at the center.

To minimize the linear autocorrelation peak, we want to "spread out" the energy so that the center lag doesn't dominate.

One approach: make the sequence "anti-symmetric" in some sense, so that the center lag contributions cancel. But we can't use negative values.

Another approach: make the sequence have a specific shape that reduces the center correlation. For example, a "U-shaped" sequence (high at the ends, low in the middle) would have low center correlation.
