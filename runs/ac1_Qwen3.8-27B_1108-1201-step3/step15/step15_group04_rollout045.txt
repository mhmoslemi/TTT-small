R[k] = n(n+1)(2n+1)/6 - (n-k)(n-k+1)(2(n-k)+1)/6 for k = 0, ..., n-1

More precisely, for the linear convolution of [1, 2, ..., n] with itself:
Let's call it C[k] for k = 0, ..., 2n-2.

C[k] = sum_{i=max(0, k-n+1)}^{min(k, n-1)} (i+1)(k-i+1)

For k ≤ n-1:
C[k] = sum_{i=0}^{k} (i+1)(k-i+1)
= sum_{i=0}^{k} (i+1)(k+1-i)
= (k+1) * sum_{i=0}^{k}(i+1) - sum_{i=0}^{k}(i+1)^2
= (k+1) * (k+1)(k+2)/2 - (k+1)(k+2)(2k+3)/6
= (k+1)(k+2)[(k+2)/2 - (2k+3)/6]
= (k+1)(k+2)[(3k+6-2k-3)/6]
= (k+1)(k+2)(k+3)/6

For k ≥ n-1:
By symmetry of the convolution (conv of a sequence with itself is symmetric), C[k] = C[2n-2-k].
So for k = n-1+j, C[n-1+j] = C[n-1-j] = (n-j)(n-j+1)(n-j+2)/6.

So the maximum is at k = n-1:
C[n-1] = n(n+1)(n+2)/6
