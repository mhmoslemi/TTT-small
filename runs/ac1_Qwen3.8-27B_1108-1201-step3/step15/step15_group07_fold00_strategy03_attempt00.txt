Two-Peak Strategy • Optimized Placement  
The primary contribution is the use of two strategically placed peaks to prevent self-overlapping autocorrelation. The two peaks are positioned at indices (n-1)//2 and (n)//2 (mirror positions) to disrupt constructive interference. The bonus function returns float('inf') if the input is invalid, and the security checks ensure we never explore sequences outside the [0,1000]^domain.

# Fast initialization and optimization for minimal autocorrelation
import numpy as np

def evaluate_sequence(sequence):
    if not isinstance(sequence, list):
        return np.inf
    if not sequence:
        return np.inf
    for x in sequence:
        if isinstance(x, bool) or not isinstance(x, (int, float)):
            return np.inf
        if np.isnan(x) or np.isinf(x):
            return np.inf
    sequence = [float(x) for x in sequence]
    sequence = [max(0, x) for x in sequence]
    sequence = [min(1000.0, x) for x in sequence]
    n = len(sequence)
    b_sequence = np.convolve(sequence, sequence)
    max_b = np.amax(b_sequence)
    sum_a = np.sum(np.asarray(sequence))
    if sum_a < 0.01:
        return np.inf
    return float(2 * n * max_b / (sum_a ** 2))

    a[middle1] = total_sum / np.sqrt(n)
