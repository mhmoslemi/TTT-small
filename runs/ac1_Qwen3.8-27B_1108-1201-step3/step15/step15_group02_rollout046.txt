        P = np.abs(A) ** 2  # Power spectrum
        
        # Flatten the spectrum (excluding DC component)
        # Target: flat spectrum at level P[0] / fft_size or similar
        P_flat = P[0] / fft_size  # Target flat level (energy conservation)
        
        # Soft flattening: interpolate between current and flat
        # Use a temperature-like parameter that decreases over iterations
        frac = it / max(1, n_iter - 1)
        alpha = 0.3 + 0.7 * (1.0 - frac)  # Start with strong flattening, decrease
        
        P_new = P.copy()
        for k in range(1, fft_size // 2 + 1):
            P_new[k] = (1 - alpha) * P[k] + alpha * P_flat
        
        # Recover complex spectrum with modified magnitude, same phase
        with np.errstate(divide='ignore', invalid='ignore'):
            scale = np.sqrt(P_new / np.maximum(P, 1e-30))
        A_new = A * scale
        # Fix DC
        A_new[0] = A[0]  # Keep DC (sum) unchanged
        
        # Inverse FFT
        a_new = irfft(A_new, fft_size)[:n]
        
        # Project to non-negative
        a_new = np.maximum(a_new, 0.0)
        s_new = a_new.sum()
        if s_new < 1e-15:
            continue
        a_new = a_new * norm / s_new
        
        # Check improvement
        sc = fast_conv_self(a_new).max()
        if sc < best_score:
            best_score = sc
            best_a = a_new.copy()
        
        a = a_new
        
        if verbose and it % 500 == 0:
            elapsed = time.monotonic() - t0
            print(f"    Spectral it={it} ({elapsed:.0f}s): best={best_score:.8f}")
    
    return best_a, best_score

Wait, I realize there's an issue with the spectral shaping. The DC component `A[0] = sum(a)` is fixed (we normalize to `sqrt(2n)`). The other components we want to flatten. But the target flat level should be chosen so that the total energy is preserved.

Total energy = `sum(a^2) = (1/fft_size) * sum_k |A[k]|^2` (Parseval's theorem).

If we want `|A[k]|^2 = P_flat` for k >= 1, and `|A[0]|^2 = |A[0]|^2` (fixed), then:
`(1/fft_size) * (|A[0]|^2 + (fft_size/2 - 1) * P_flat + P_flat + ...) = sum(a^2)`

This is getting complicated. Let me just use a simpler approach: scale the non-DC components to have a target variance.

Actually, let me reconsider. The key insight is:

`max_k b[k]` where `b = conv(a,a)` is related to the peak of the inverse FFT of the power spectrum. Specifically:
- `b[k]` (for the circular version with zero-padding) = `IDFT(|A|^2)[k]`
- We want to minimize `max_k b[k]`
- This is equivalent to making `|A|^2` as flat as possible (since a flat spectrum gives a delta autocorrelation)

But we have the constraint that `a >= 0` and `sum(a) = fixed`.

The iterative algorithm:
1. Compute `A = FFT(a)`
2. Modify `|A|^2` to be flatter (objective)
3. `a' = IDFT(A_modified)`
4. Project: `a = max(a', 0)`, renormalize
5. Repeat

The challenge is in step 2: how to modify `|A|^2`. Simple approaches:
- Set `|A[k]| = c` for all k != 0 (too aggressive, might not converge)
- `|A[k]|_new = |A[k]|_old + α * (target - |A[k]|_old)` (gradient step)
- Use the actual peak-to-actual ratio as feedback

Let me use a more principled approach. The gradient of `max_k b[k]` with respect to `|A[k]|^2` is concentrated at the frequency components that create the peak. But this is hard to compute directly.

Simpler: use the "RCSP" (Random Complex Spectrum Phase) or "Optimal ECAI" algorithm from ultrafast optics.

Actually, let me try a different formulation. The "pressure" approach:

At each iteration:
1. Compute `b = conv(a, a)`
2. Find the peak position `k*` where `b[k*] = max(b)`
3. The peak `b[k*] = sum_i a[i]*a[k*-i]`. To reduce it, we want to reduce the contributions from the "problematic" pairs.
4. For each `i`, the contribution to the peak from position `i` is `a[i]*a[k*-i]`. The "pressure" on position `i` is proportional to `a[k*-i]` (if we're reducing `a[i]`).
5. Update: `a[i] = a[i] * (1 - η * a[k*-i] / a_max)` for positions that contribute to the peak.

This is similar to what the Vegas method does, but focused on the actual peak.

Let me try yet another approach that I think might be more effective:

**Iterated Projections (POCS-like)**

The problem is to find `a >= 0`, `sum(a) = c` that minimizes `max_k (a*a)[k]`.

This can be seen as a feasibility problem: find `a` in the intersection of:
- `C1 = {a : a >= 0, sum(a) = c}` (simplex)
- `C2 = {a : max_k (a*a)[k] <= t}` (sublevel set of the max-autocorrelation)

For a given t, we can use alternating projections:
1. Start with `a in C1`
2. Project onto C2: reduce the peaks of `conv(a,a)`
3. Project back onto C1: renormalize and clip
4. Repeat

The projection onto C2 is the hard part. One approximation: for the peak positions, reduce the contributing elements proportionally.

OK, I think I'm overcomplicating this. Let me focus on what's most likely to work given the time constraint:

1. **Improved LP method** with better active set management and more iterations
2. **Spectral shaping** as a new optimizer
3. **Better initializations** (exploiting structure)
4. **Population diversity** (multiple runs with different strategies)

def fast_conv_self(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]

def fast_conv_cross(a, b):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    B = rfft(b, fft_size)
    return irfft(A * B, fft_size)[:size]

def compute_score(a):

    S = a.sum()
    if S < 1e-15:
        return float('inf')
    n = len(a)
    max_b = fast_conv_self(a).max()
    return 2.0 * n * max_b / (S * S)

def get_solver():

def spectral_shaping(a0, time_limit, verbose=True):
    n = len(a0)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n)
    a = a * norm / s
    
    best_a = a.copy()
    best_score = fast_conv_self(a).max()
    t0 = time.monotonic()
    
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    n_freq = fft_size // 2 + 1
    
    # Annealing schedule for the flattening strength
    n_stages = 30
    alphas = np.geomspace(0.8, 0.01, n_stages)
    
    for si, alpha in enumerate(alphas):
        if time.monotonic() - t0 > time_limit:
            break
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 2:
            break
        n_steps = max(50, int(remaining * 20))
        
        for it in range(n_steps):
            if time.monotonic() - t0 > time_limit:
                break
            
            A = rfft(a, fft_size)
            P = np.abs(A) ** 2
            
            # Target: equal energy distribution across frequencies
            # DC is fixed, so we flatten the rest
            P_dc = P[0]
            P_rest_mean = (P.sum() - P_dc) / (n_freq - 1)
            
            # Flatten: move P_rest toward P_rest_mean
            P_new = P.copy()
            P_new[1:] = (1 - alpha) * P[1:] + alpha * P_rest_mean
            
            # Ensure non-negative
            P_new = np.maximum(P_new, 1e-15)
            
            # Recover A with same phase
            with np.errstate(divide='ignore', invalid='ignore'):
                ratio = np.sqrt(P_new / np.maximum(P, 1e-30))
            ratio = np.where(np.isfinite(ratio), ratio, 1.0)
            A_new = A * ratio
            A_new[0] = A[0]  # Preserve DC
            
            a_new = irfft(A_new, fft_size)[:n]
            a_new = np.maximum(a_new, 0.0)
            s_new = a_new.sum()
            if s_new < 1e-15:
                continue
            a_new = a_new * norm / s_new
            
            sc = fast_conv_self(a_new).max()
            if sc < best_score:
                best_score = sc
                best_a = a_new.copy()
            
            a = a_new
        
        if verbose and si % 5 == 0:
            print(f"    Spectral stage {si} alpha={alpha:.3f} ({time.monotonic()-t0:.0f}s): best={best_score:.8f}")
    
    return best_a, best_score

def lp_best_response(a, M, solver, active_set=None):
    n = len(a)
    b_var = cp.Variable(n, nonneg=True)
    
    if active_set is not None and 0 < len(active_set) < 2*n - 1:
        # Build constraint matrix for active set only
        T = np.zeros((len(active_set), n))
        for idx, k in enumerate(active_set):
            for i in range(n):
                j = k - i
                if 0 <= j < n:
                    T[idx, i] = a[j]
        constraints = [T @ b_var <= M]
    else:
        # Full constraint set
        size = 2 * n - 1
        T = np.zeros((size, n))
        for i in range(n):
            T[i:i+n, i] = a
        constraints = [T @ b_var <= M]
    
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        return None
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None
    val = np.asarray(b_var.value, dtype=np.float64)
    if val is None:
        return None
    return np.maximum(val, 0.0)

def lp_nesterov_optimize(a0, time_limit, solver, verbose=True):
    n = len(a0)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n)
    a = a * norm / s
    
    best_a = a.copy()
    best_score = fast_conv_self(a).max()
    t0 = time.monotonic()
    y = a.copy()
    size = 2 * n - 1
    
    for t in range(1, 100000):
        if time.monotonic() - t0 > time_limit:
            break
        
        conv_y = fast_conv_self(y)
        M = conv_y.max()
        if M < 1e-12:
            break
        
        # Adaptive threshold for active set
        threshold = M * (0.8 + 0.15 * (1 - min(1.0, t/200.0)))
        active_set = np.where(conv_y >= threshold)[0]
        
        if len(active_set) < 5:
            active_set = np.where(conv_y >= M * 0.5)[0]
        if len(active_set) > 1000:
            active_set = np.where(conv_y >= M * 0.95)[0]
            if len(active_set) < 5:
                active_set = None
        
        b = lp_best_response(y, M, solver, active_set)
        
        if b is None:
            b = lp_best_response(y, M, solver, None)
        
        if b is None:
            continue
        
        # Constraint verification and generation
        if active_set is not None:
            check = fast_conv_cross(y, b)
            violated = np.where(check > M * 1.001)[0]
            if len(violated) > 0:
                active_set = np.union1d(active_set, violated)
                b2 = lp_best_response(y, M, solver, active_set)
                if b2 is not None:
                    b = b2
        
        b_sum = b.sum()
        if b_sum < 1e-15:
            continue
        
        g = b * norm / b_sum
        
        # Nesterov update
        alpha = 2.0 / (t + 2.0)
        y_new = (1.0 - alpha) * y + alpha * g
        y_new = np.maximum(y_new, 0.0)
        s_y = y_new.sum()
        if s_y < 1e-15:
            y_new = y.copy()
        else:
            y_new = y_new * norm / s_y
        
        if t == 1:
            a_new = g.copy()
        else:
            momentum = (t - 1.0) / (t + 2.0)
            a_new = y_new + momentum * (y_new - y)
            a_new = np.maximum(a_new, 0.0)
            s_a = a_new.sum()
            if s_a < 1e-15:
                a_new = y_new.copy()
            else:
                a_new = a_new * norm / s_a
        
        y = y_new
        a = a_new
        
        sc = fast_conv_self(a).max()
        if sc < best_score:
            best_score = sc
            best_a = a.copy()
        
        if verbose and t % 50 == 0:
            print(f"    LP t={t} ({time.monotonic()-t0:.0f}s): best={best_score:.8f}")
    
    return best_a, best_score

def lse_adam_optimize(a0, time_limit, verbose=True):
    n = len(a0)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n)
    a = a * norm / s
    best_a = a.copy()
    best_score = fast_conv_self(a).max()
    t0 = time.monotonic()
    
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    
    m = np.zeros(n)
    v = np.zeros(n)
    beta1, beta2, eps = 0.9, 0.999, 1e-8
    t_adam = 0
    
    # More stages with finer temperature control
    n_stages = 30
    temps = np.geomspace(50.0, 0.01, n_stages)
    
    for si, T_val in enumerate(temps):
        if time.monotonic() - t0 > time_limit:
            break
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 3:
            break
        n_steps = max(40, min(300, int(remaining * 15)))
        lr = 0.3 / np.sqrt(n)
        
        for it in range(n_steps):
            if time.monotonic() - t0 > time_limit:
                break
            t_adam += 1
            
            conv = fast_conv_self(a)
            max_c = conv.max()
            if max_c < 1e-15:
                break
            
            # LSE-smoothed gradient
            shifted = (conv - max_c) / T_val
            shifted = np.maximum(shifted, -100.0)
            exp_c = np.exp(shifted)
            w = exp_c / (exp_c.sum() + 1e-30)
            
            W = rfft(w, fft_size)
            A = rfft(a, fft_size)
            
            grad = 2.0 * (irfft(np.conj(A) * W, fft_size)[:n] + irfft(A * W, fft_size)[:n])
            
            # Adam update
            m = beta1 * m + (1 - beta1) * grad
            v = beta2 * v + (1 - beta2) * grad * grad
            m_hat = m / (1 - beta1 ** t_adam)
            v_hat = v / (1 - beta2 ** t_adam)
            
            a_new = np.maximum(a - lr * m_hat / (np.sqrt(v_hat) + eps), 0.0)
            s_new = a_new.sum()
            if s_new < 1e-15:
                a_new = a.copy()
            else:
                a_new = a_new * norm / s_new
            
            a = a_new
            sc = fast_conv_self(a).max()
            if sc < best_score:
                best_score = sc
                best_a = a.copy()
        
        if verbose and si % 5 == 0:
            print(f"    Adam stage {si} T={T_val:.4f} ({time.monotonic()-t0:.0f}s): best={best_score:.8f}")
    
    return best_a, best_score
