**Radically different approach: Use the spectral representation**

The convolution c = a * a can be computed via FFT: C = |A|^2 where A = FFT(a).
So max(c) = max(IDFT(|A|^2)).

We want to minimize max(IDFT(|A|^2)) subject to a >= 0, sum(a) = 1.

In the frequency domain, a >= 0 means that the inverse DFT of A is non-negative. This is a complicated constraint in the frequency domain.

However, we can use the following approach:
1. Start with a good a
2. Compute A = FFT(a)
3. In the frequency domain, "shape" |A|^2 to be as flat as possible (since max(IDFT(|A|^2)) is small when |A|^2 is flat)
4. Convert back: a_new = IDFT(A_new)
5. Project a_new onto the non-negative orthant (and renormalize)

This is a "spectral shaping" approach. The idea is:
- If |A|^2 is perfectly flat, then c = IDFT(|A|^2) is a delta at lag 0, meaning max(c) is very small (just c[0] = 1/(2n-1) for the flat case).
- But |A|^2 flat means A has constant magnitude, which means a is a "chirp" or "Fourier basis" vector, which is generally complex and has both positive and negative parts.
- So we can't achieve perfect flatness, but we can get closer than with other approaches.

The algorithm:
1. Compute A = FFT(a) (zero-padded to length 2n-1 or more)
2. Compute |A|^2
3. "Flatten" |A|^2: A_new[m] = A[m] * sqrt(target_flatness / |A[m]|^2) for each frequency m
   (This makes |A_new|^2 more uniform)
4. a_new = real(IDFT(A_new))
5. Clip negative values: a_new = max(0, a_new)
6. Renormalize: a_new = a_new / sum(a_new)
7. Repeat

The "target_flatness" can be controlled by a parameter that determines how aggressively we flatten.

    fft_size = 1 << (2 * n - 1 - 1).bit_length()
    a = a0.astype(np.float64).copy()
    S = a.sum()
    a = a / S
    best_a = a.copy()
    best_cmax = fast_convolve(a).max()
    strength = strength_init
    stall = 0
    
    while time.monotonic() - t0 < time_limit:
        A = rfft(a, fft_size)
        power = A.real ** 2 + A.imag ** 2
        power = np.maximum(power, 1e-30)
        
        # Target power: blend between current and flat
        flat_power = 1.0 / fft_size
        target_power = (1.0 - strength) * power + strength * flat_power
        
        # Scale A to target power (preserve phase)
        scale = np.sqrt(target_power / power)
        A_new = A * scale
        
        # Inverse FFT
        a_raw = irfft(A_new, fft_size)[:n]
        
        # Project to non-negative, renormalize
        a_new = np.maximum(a_raw, 0.0)
        S_new = a_new.sum()
        if S_new < 0.001:
            # Too negative; reduce strength
            strength *= 0.9
            if strength < 0.001:
                strength = 0.001
                stall += 1
                if stall > 100:
                    break
            continue
        a_new = a_new / S_new
        
        c = fast_convolve(a_new)
        cmax = c.max()
        
        if cmax < best_cmax - 1e-15:
            best_cmax = cmax
            best_a = a_new.copy()
            stall = 0
            # Slowly reduce strength
            strength = max(0.005, strength * strength_decay)
        else:
            a = np.maximum(a, 0)  # revert
            stall += 1
            if stall > 200:
                # Try restart with different strength
                strength = min(0.5, max(0.01, strength * rng.uniform(0.5, 2.0)))
                stall = 0
                a = project_simplex(best_a + rng.standard_normal(n) * 0.001)
        
        a = a_new if cmax < best_cmax else a
    
    return best_a, best_cmax

# --- Subgradient with peak equalization ---

def subgrad_peak_eq(a0, time_limit, lr_init=0.003, momentum=0.9,
                    n_top=20, temp_init=0.001, seed=42):
    """
    Subgradient descent with focus on equalizing the top peaks.
    Uses Nesterov momentum and geometric peak weighting.
    """
    rng = np.random.default_rng(seed)
    t0 = time.monotonic()
    n = len(a0)
    a = a0.astype(np.float64).copy()
    a = a / a.sum()
    v = np.zeros(n)
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    lr = lr_init
    temp = temp_init
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        c = fast_convolve(a)
        cmax = c.max()
        
        # Geometric weighting on top peaks
        top_idx = np.argsort(c)[::-1][:n_top]
        top_vals = c[top_idx]
        # Weight: higher weight for higher peaks (geometric)
        base_ratio = 0.8
        w = np.zeros(len(c))
        base_val = top_vals[0]
        for i, k in enumerate(top_idx):
            w[k] = base_ratio ** i
        w /= w.sum()
        
        # Compute subgradient
        g = np.zeros(n)
        for k in top_idx:
            if w[k] < 1e-14:
                continue
            lo = max(0, k - n + 1)
            hi = min(n - 1, k)
            j_idx = np.arange(lo, hi + 1)
            g[j_idx] += w[k] * a[k - j_idx]
        
        # Nesterov step
        v = momentum * v - lr * g
        a_new = project_simplex(a + v)
        
        c_new = fast_convolve(a_new)
        obj_new = c_new.max()
        
        if obj_new < best_obj - 1e-15:
            best_obj = obj_new
            best_a = a_new.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        a = a_new
        
        # Adaptive adjustments
        if no_improve > 1000:
            a = project_simplex(best_a + rng.standard_normal(n) * 0.002)
            v = np.zeros(n)
            lr = max(lr * 0.7, lr_init * 0.1)
            no_improve = 0
        elif no_improve > 500:
            lr *= 0.95
    
    return best_a, best_obj
