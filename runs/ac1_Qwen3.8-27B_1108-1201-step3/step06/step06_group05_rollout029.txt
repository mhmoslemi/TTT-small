**KKT-based multiplicative update**:
At the optimum, the KKT conditions are:
- a_j >= 0, sum(a) = 1
- There exist q_k >= 0, sum(q) = 1, lambda > 0 such that:
  - For j with a_j > 0: 2 * sum_k q_k * a_{k-j} = lambda
  - For j with a_j = 0: 2 * sum_k q_k * a_{k-j} <= lambda
  - q_k > 0 implies (a*a)_k = max(a*a)

The idea is to iteratively:
1. Given a, compute c = a*a, find the peak set P
2. Set q_k = 1/|P| for k in P (or weight by excess)
3. Compute h_j = 2 * sum_k q_k * a_{k-j} (this should be constant at optimum)
4. Update: a_j <- a_j * (lambda / h_j)^eta for a_j > 0
   where lambda = mean(h_j over support of a)
5. Renormalize

This is a "multiplicative weight" update that equalizes h over the support.

Let me also think about **what the optimal shape looks like** for n=768.

From the KKT conditions, if the peak set is {k1, k2, ..., km}, then:
h_j = 2 * sum_{i=1}^{m} q_i * a_{k_i - j} = lambda for all j in support

This means h is a "superposition" of shifted copies of a, and it must be constant over the support.

If the peak set is just {n-1} (the center), then h_j = 2*a_{n-1-j} = lambda, which means a is constant. That gives the uniform solution (J=2).

If the peak set is {n-1, n-2, n, n-3, n+1, ...} (a range around the center), then h is a "blurred" version of a, and the condition that h is constant means a must be an "eigenfunction" of the blur.

This gives a system of linear equations:
For each j in support: sum_i q_i * a_{k_i - j} = lambda/2

This is an eigenvalue problem! The optimal a is the eigenvector (with eigenvalue lambda/2) of the matrix B where B[j, k] = sum_i q_i * delta_{k, k_i - j}.

But q itself depends on which positions are peaks, which depends on a... So it's a fixed point problem.

This suggests an iterative algorithm:
1. Start with a
2. Compute c = a*a, identify peaks
3. Set q proportional to (c_k - threshold) for peaks
4. Solve the eigenvalue problem: find a such that B*a = (lambda/2)*a
5. Update a, renormalize
6. Repeat

This is similar to the power iteration for finding the dominant eigenvector!

Let me formalize:
- Define the matrix B: B[j, k] = sum_{i: k_i is a peak} q_i * [k = k_i - j] (for valid indices)
- This is a "shift" matrix weighted by q
- We want a to be an eigenvector of B with the largest eigenvalue
- Power iteration: a_{new} = B * a, normalize

3. a_1 = B(q) * a_0, normalize

5. a_2 = B(q) * a_1, normalize
6. ...

This is like a "power iteration on a varying matrix." It might converge!

Let me think about whether this is well-defined. The matrix B(q) has the structure:
(B(q))_j = 2 * sum_k q_k * a_{k-j}

This is a convolution of q (padded) with a. So B(q) * a = 2 * (q * a) (appropriately truncated).

The power iteration a_{t+1} ∝ B(q_t) * a_t = 2 * (q_t * a_t) is essentially a "convolution with q" followed by normalization.

If q is concentrated at the center, B is an identity-like matrix, and the iteration doesn't change a much.
If q is spread out, B is a "blur," and the iteration smooths a.

"""
Multi-phase optimizer for minimizing 2*n*max(conv(a,a))/(sum(a))^2.
Uses smoothed gradient descent, power-iteration KKT refinement,
LP-based Frank-Wolfe, and coordinate descent.
"""

import numpy as np
from scipy.optimize import linprog
import time

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def compute_smoothed_grad(f, c, beta):
    n = len(f)
    scaled = beta * c
    scaled -= scaled.max()
    exp_scaled = np.exp(scaled)
    w = exp_scaled / exp_scaled.sum()
    w_rev = w[::-1].copy()
    conv_len = n + len(w_rev) - 1
    fft_size = 1 << (conv_len - 1).bit_length()
    F = np.fft.rfft(f, fft_size)
    W = np.fft.rfft(w_rev, fft_size)
    conv = np.fft.irfft(F * W, fft_size)[:conv_len]
    indices = np.arange(2 * n - 2, 2 * n - 2 - n, -1)
    g = 2.0 * conv[indices]
    return g

def power_iteration_kkt(f0, time_limit, verbose=False):
    """
    KKT-based power iteration.
    At each step:
    1. Compute auto-convolution
    2. Identify peak set
    3. Compute dual weights q
    4. Apply multiplicative update based on KKT conditions
    """
    f = np.maximum(f0.astype(np.float64), 0.0)
    f = f / f.sum()
    n = len(f)
    best_f = f.copy()
    best_obj = fast_convolve(f).max()
    t0 = time.monotonic()

    no_improve = 0
    it = 0
    while time.monotonic() - t0 < time_limit:
        it += 1
        c = fast_convolve(f)
        M = c.max()
        # Find peaks (top fraction or top K)
        K = max(10, n // 4)
        peak_idx = np.argpartition(c, -K)[-K:]
        # Weights proportional to excess above 95th percentile
        threshold = np.percentile(c, 90)
        excess = np.maximum(c - threshold, 0)
        if excess.sum() < 1e-15:
            break
        q_full = np.zeros(2 * n - 1)
        q_full[peak_idx] = excess[peak_idx]  # wait, this isn't right
        # Actually, let's weight all positions by excess
        q_full = np.maximum(c - threshold, 0)
        q_full = q_full / q_full.sum()
        # Compute h_j = 2 * sum_k q_k * a_{k-j}
        # This is 2 * cross-correlation of q and f
        q_rev = q_full[::-1]
        conv_len = n + len(q_rev) - 1
        fft_size = 1 << (conv_len - 1).bit_length()
        F = np.fft.rfft(f, fft_size)
        Q = np.fft.rfft(q_rev, fft_size)
        conv = np.fft.irfft(F * Q, fft_size)[:conv_len]
        indices = np.arange(2 * n - 2, 2 * n - 2 - n, -1)
        h = 2.0 * conv[indices]
        # KKT: h should be constant over support
        support = f > 1e-10
        if support.sum() < 2:
            break
        lambda_val = np.mean(h[support])
        # Multiplicative update: f_j *= (lambda / h_j)^eta
        ratio = np.ones(n)
        ratio[support] = (lambda_val / np.maximum(h[support], 1e-15)) ** eta
        f_new = f * ratio
        f_new = np.maximum(f_new, 0)
        f_new = f_new / f_new.sum()
        c_new = fast_convolve(f_new)
        obj_new = c_new.max()
        if obj_new < best_obj - 1e-13:
            best_obj = obj_new
            best_f = f_new.copy()
            f = f_new
            no_improve = 0
            eta = min(eta * 1.01, 0.5)
        else:
            no_improve += 1
            eta *= 0.97
        if verbose and it % 20 == 0:
            print(f"    PIT iter {it}: obj={c_new.max():.10f}, best={best_obj:.10f}")
        if no_improve > 150:
            break
        if eta < 0.01:
            break
    return best_f, best_obj

    res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success:
        return res.x
    return None
