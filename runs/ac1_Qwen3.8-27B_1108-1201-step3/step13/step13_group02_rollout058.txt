- Compute `grad f_T(a) = 2 * sum_k w_k * (Q_k @ a)` using FFT

The key insight is that `sum_k w_k * (Q_k @ a)` can be computed as a single convolution!

Specifically, `(Q_k @ a)_i = sum_j Q_k[i,j] * a[j]`. And `Q_k[i,j] = 1` if `j = k-i` (i.e., `i+j = k`), 0 otherwise (with appropriate bounds).

So `(Q_k @ a)_i = a[k-i]` (if `0 <= k-i < n`, else 0).

And `sum_k w_k * (Q_k @ a)_i = sum_k w_k * a[k-i]` (with bounds).

This is a convolution of `w` and `a` (reversed): `sum_k w_k * a[k-i] = (w * a_rev)[i+n-1]` where `a_rev = a[::-1]`.

Wait, let me be more careful. `(w * a_rev)[m] = sum_k w[k] * a_rev[m-k] = sum_k w[k] * a[n-1-(m-k)] = sum_k w[k] * a[n-1-m+k]`.

Setting `m = i + n - 1`: `(w * a_rev)[i+n-1] = sum_k w[k] * a[n-1-(i+n-1)+k] = sum_k w[k] * a[k-i]`.

Yes! So `sum_k w_k * (Q_k @ a)_i = (w * a_rev)[i+n-1]` (with appropriate handling of bounds).

But we need to be careful about the bounds. The full convolution `w * a_rev` has length `(2n-1) + n - 1 = 3n-2`. We take the middle `n` entries (from index `n-1` to `2n-2`).

This is exactly what the previous code's `compute_lse_gradient` function does.

So the FISTA-LSE approach is:
1. Compute `b = a*a` (autocorrelation) via FFT
2. Compute weights `w = softmax(b/T)`
3. Compute gradient `grad = 2 * (w * a_rev)[n-1:2n-1]` via FFT
4. FISTA update: `a_new = proj(a - step * grad)` where `proj` is projection onto the simplex

The step size for FISTA should be `1/L` where `L` is the Lipschitz constant of the gradient. For the LSE approximation, `L` depends on T and the eigenvalues of the `Q_k` matrices. A safe choice is `step = 1/(max_eig * n)` where `max_eig` is an upper bound on the maximum eigenvalue.

In practice, we can use a heuristic step size and adapt it based on whether the objective increases or decreases.

Let me also think about the projection onto the simplex `{a : sum(a) = c, a >= 0}`. This is a standard operation that can be done in O(n log n) time using the algorithm by Duchi et al. (2011). Or we can simply clip at 0 and renormalize (which is an approximation but works well in practice).

For simplicity, I'll use the "clip and renormalize" approach: `a_new = max(a - step*grad, 0)` then `a_new = a_new * c / sum(a_new)`.

OK let me write the final code now. I'll make it comprehensive but not overly complex.

Let me also think about one more improvement: **adaptive constraint selection for the LP**.

The LP is: max `sum(b)` s.t. `T @ b <= M`, `b >= 0`.

The number of constraints is `2n-1` (one for each lag). But many of these constraints are redundant (not active at the optimum). We can reduce the number of constraints by:
1. Solving the full LP
2. Identifying the active constraints (those with `T @ b ≈ M`)
3. Re-solving with only the active constraints
4. Verifying that the solution is feasible for the full problem
5. If not, add the violated constraints and go to step 3

This is the "constraint generation" approach. It should reduce the LP solve time significantly.

The previous code already does this (in `lp_best_response_reduced`), but I'll improve it by:
- Using a tighter tolerance for "active" constraints
- Limiting the number of constraint generation iterations
- Fallback to the full LP if the reduced LP gives an infeasible solution

Let me now write the complete code.

One more consideration: the time budget is 1800 seconds, but the function must return before that. So I need to be careful about timing and make sure to return a valid sequence before the time runs out.

I'll use a global timer and check it before each phase. If there's not enough time for a phase, I'll skip it.

Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Multi-start LP Nesterov with adaptive constraint reduction and warm-starting
2. FISTA with LSE smooth approximation for fast gradient-based polishing  
3. Multi-scale peak shaving with simulated annealing and constraint-aware perturbations
4. Adaptive multi-length exploration (1600-3000) with interpolation transfer
5. Diversification via structured random perturbations

_global_solver = None

        except Exception:

    return _global_solver

def fast_autocorr(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]

def evaluate_safe(a):
    try:
        a_list = [float(x) for x in np.asarray(a, dtype=np.float64)]

def build_conv_matrix(a, active_mask=None):
    n = len(a)
    if active_mask is None:
        active_mask = np.ones(2*n-1, dtype=bool)
    n_active = int(active_mask.sum())
    T = np.zeros((n_active, n))
    rows = np.where(active_mask)[0]
    for j in range(n):
        col_start = max(0, j)
        col_end = min(2*n-1, j+n)
        # T[k, j] = a[j] if k is in [j, j+n-1], else 0
        # Row k in T corresponds to lag rows[k]
        # T[row, j] = a[j] if j <= rows[row] <= j+n-1
        mask = (rows >= j) & (rows <= j + n - 1)
        T[mask, j] = a[j]
    return T, rows

def lp_best_response(a, M, solver, reduce_iters=5, verbose=False):
    n = len(a)
    b_var = cp.Variable(n, nonneg=True)
    
    # Build full constraint matrix
    n_lags = 2 * n - 1
    T_full = np.zeros((n_lags, n))
    for j in range(n):
        T_full[j:j+n, j] = a[j]
    
    # First solve with all constraints
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), [T_full @ b_var <= M])
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        return None
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None
    b_val = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
    
    if reduce_iters <= 0:
        s = b_val.sum()
        return b_val if s > 1e-15 else None
    
    # Constraint reduction
    for _ in range(reduce_iters):
        circ = T_full @ b_val
        tol = max(1e-10 * M, 1e-12)
        active = circ >= M - tol
        n_active = int(active.sum())
        
        if n_active >= n_lags - 10 or n_active < 30:
            break
        
        T_red = T_full[active, :].copy()
        prob = cp.Problem(cp.Maximize(cp.sum(b_var)), [T_red @ b_var <= M[active]])
        try:
            prob.solve(solver=solver, verbose=False)
        except Exception:
            break
        if prob.status not in ('optimal', 'optimal_inaccurate'):
            break
        b_new = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
        circ_new = T_full @ b_new
        if circ_new.max() <= M * (1 + 1e-6):
            b_val = b_new
        else:
            break
    
    s = b_val.sum()
    return b_val if s > 1e-15 else None

def nesterov_lp_optimize(a0, time_limit, solver, verbose=True, restart_every=300):
    n = len(a0)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s0 = a.sum()
    if s0 < 1e-15:
        a = np.ones(n) * norm / n
    else:
        a = a * norm / s0
    
    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()
    
    y = a.copy()
    t_iter = 0
    stall = 0
    
    while time.monotonic() - t0 < time_limit:
        M_curr = fast_autocorr(y).max()
        if M_curr < 1e-12:
            break
        
        b = lp_best_response(y, M_curr, solver, reduce_iters=4)
        if b is None:
            continue
        
        b_sum = b.sum()
        if b_sum < 1e-15:
            continue
        
        g = b * norm / b_sum
        t_iter += 1
        
        # Nesterov step
        alpha = 2.0 / (t_iter + 2.0)
        y_new = (1.0 - alpha) * y + alpha * g
        y_new = np.maximum(y_new, 0.0)
        s_y = y_new.sum()
        if s_y < 1e-15:
            y_new = y.copy()
        else:
            y_new = y_new * norm / s_y
        
        if t_iter == 1:
            a_new = g.copy()
        else:
            momentum = (t_iter - 1.0) / (t_iter + 2.0)
            a_new = y_new + momentum * (y_new - y)
            a_new = np.maximum(a_new, 0.0)
            s_a = a_new.sum()
            if s_a < 1e-15:
                a_new = y_new.copy()
            else:
                a_new = a_new * norm / s_a
        
        y = y_new
        a = a_new
        
        score_y = fast_autocorr(y).max()
        if score_y < best_score:
            best_score = score_y
            best_a = y.copy()
            stall = 0
        else:
            stall += 1
        
        score_a = fast_autocorr(a).max()
        if score_a < best_score:
            best_score = score_a
            best_a = a.copy()
            stall = 0
        
        if verbose and t_iter % 500 == 0:
            elapsed = time.monotonic() - t0
            print(f"    NLP iter={t_iter} ({elapsed:.0f}s): best={best_score:.8f}, stall={stall}")
        
        # Adaptive restart
        if stall > restart_every:
            rng = np.random.default_rng(t_iter * 13 + 7)
            perturb_scale = 0.03 * a.mean()
            y = np.maximum(y + rng.normal(0, perturb_scale, n), 0)
            s_y = y.sum()
            if s_y > 1e-15:
                y = y * norm / s_y
            a = np.maximum(a + rng.normal(0, perturb_scale, n), 0)
            s_a = a.sum()
            if s_a > 1e-15:
                a = a * norm / s_a
            stall = 0
            if verbose:
                print(f"    [Restart at iter {t_iter}, stall was {stall}]")
    
    return best_a, best_score

def compute_lse_gradient(a, w):
    n = len(a)
    a_rev = a[::-1]
    fft_size = 1 << (3 * n - 2).bit_length()
    W = rfft(w, fft_size)
    AR = rfft(a_rev, fft_size)
    conv = irfft(W * AR, fft_size)
    return 2.0 * conv[n - 1:2 * n - 1]

def fista_lse_optimize(a0, time_limit, verbose=True, T_factor_start=0.05, T_factor_end=0.001):
    n = len(a0)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s0 = a.sum()
    if s0 < 1e-15:
        a = np.ones(n) * norm / n
    else:
        a = a * norm / s0
    
    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()
    steps = 0
    
    # FISTA momentum
    y_fista = a.copy()
    t_fista = 1.0
    step_size = 0.5 / n  # Initial step size heuristic
    
    while time.monotonic() - t0 < time_limit:
        progress = min(1.0, (time.monotonic() - t0) / time_limit)
        T = best_score * T_factor_start * (T_factor_end / T_factor_start) ** progress
        
        b = fast_autocorr(y_fista)
        max_b = b.max()
        if max_b < 1e-15:
            break
        
        w = np.exp((b - max_b) / T)
        w_sum = w.sum()
        if w_sum < 1e-30:
            break
        w = w / w_sum
        
        grad = compute_lse_gradient(y_fista, w)
        
        a_new = y_fista - step_size * grad
        a_new = np.maximum(a_new, 0.0)
        s_new = a_new.sum()
        if s_new < 1e-15:
            a_new = y_fista.copy()
        else:
            a_new = a_new * norm / s_new
        
        # Check if step was good
        score_new = fast_autocorr(a_new).max()
        if score_new > best_score * 1.05:
            # Step too large, reduce
            step_size *= 0.8
            a_new = a.copy()  # Don't update
        else:
            step_size = min(step_size * 1.05, 2.0 / n)
        
        # FISTA momentum update
        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t_fista**2))
        theta = (t_fista - 1.0) / t_new
        y_fista = a_new + theta * (a_new - a)
        y_fista = np.maximum(y_fista, 0.0)
        s_yf = y_fista.sum()
        if s_yf > 1e-15:
            y_fista = y_fista * norm / s_yf
        
        a = a_new
        t_fista = t_new
        steps += 1
        
        if score_new < best_score:
            best_score = score_new
            best_a = a_new.copy()
        
        if verbose and steps % 500 == 0:
            elapsed = time.monotonic() - t0
            print(f"    FISTA-LSE step={steps} ({elapsed:.0f}s): T={T:.4f}, best={best_score:.8f}, step={step_size:.4f}")
    
    return best_a, best_score

def peak_shave_sa(a0, time_limit, seed=42, verbose=True):

        b = fast_autocorr(a)
