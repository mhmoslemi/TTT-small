We want to minimize: `2 * n * max(conv(a,a)) / (sum(a))^2`

where `conv(a,a)` is the full convolution of `a` with itself (autocorrelation), `n = len(a)`, and `a` is a non-negative sequence.

Key insights:
1. The score is scale-invariant (if we scale `a` by `c`, both numerator and denominator scale by `c^2`), so we can normalize `sum(a) = 1`.
2. With `sum(a) = 1`, the score is `2 * n * max_k (a*a)_k`.
3. The minimum possible value of `max_k (a*a)_k` when `sum(a) = 1` is related to the "flatness" of the autocorrelation.

For a uniform sequence `a_j = 1/n`, the autocorrelation is `(n - |k|)/n^2`, and `max_k = 1/n`, so the score is `2 * n * (1/n) = 2`.

For a "random" sequence with `sum(a) = 1` and `a_j ≈ 1/n`, the autocorrelation at lag 0 is `sum(a_j^2) ≈ 1/n` (by Chebyshev), and at other lags it's roughly `1/n^2 * n = 1/n` on average but with fluctuations. The score would be roughly `2n * (1/n) = 2` at best, but typically higher due to peaks.

The theoretical lower bound: If we could make the autocorrelation perfectly flat (like a perfect sequence / frequency-hopping sequence), then all `(a*a)_k` would be equal. The sum of all `(a*a)_k = (sum a)^2 = 1`. There are `2n-1` values, so each would be `1/(2n-1) ≈ 1/(2n)`. The score would be `2n * 1/(2n) = 1`. So the theoretical minimum is 1.

But for non-negative sequences, achieving a perfectly flat autocorrelation is very hard. The best known results for non-negative sequences are around 1.5.

**Algorithm 1: Multiplicative Weights + QP**
```
Initialize: a = parent_sequence (normalized to sum=1)
Initialize: w = uniform over lags (w_k = 1/(2n-1))

For iteration t = 1, 2, ...:
    1. Compute b = autocorr(a)
    2. Update w: w_k = w_k * exp(T * b_k) / sum_j w_j * exp(T * b_j)
    3. Build Q matrix: Q_{ij} = w_{i+j} (for i+j < 2n-1)
    4. Solve QP: min a^T Q a s.t. sum(a) = 1, a >= 0
    5. Update a (possibly with averaging for convergence guarantee)
    6. Check time, stop if exceeded

Return best a found
```

The temperature T controls how much we focus on the peak vs. the average. We can adapt T over time.

**Algorithm 2: Exponential Gradient (Mirror Descent)**
```
Initialize: a = parent_sequence (normalized to sum=1)
eta_0 = initial learning rate

For iteration t = 1, 2, ...:
    1. Compute b = autocorr(a)
    2. Compute softmax weights: w_k = exp(T*b_k) / sum exp(T*b_k)
    3. Compute gradient: g_j = 2 * sum_k w_k * a_{k-j} (valid k-j)
    4. Mirror descent update: a_j <- a_j * exp(-eta_t * g_j)
    5. Normalize: a = a / sum(a)
    6. Track best a by true score
```

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Exponential gradient (mirror descent) for fast initialization
2. Multiplicative weights + FISTA inner solve (primary optimizer, very fast)
3. Frank-Wolfe with line search (polish)
4. Coordinate descent with simulated annealing (final refinement)
Key innovation: exploits the structure Q_{ij}=w_{i+j} for O(n log n) matrix-vector products,
enabling thousands of MW iterations within the time budget.
"""

import numpy as np
import cvxpy as cp
import time
from scipy.fft import rfft, irfft


def fast_autocorr(a):
    """Full autocorrelation a*a using FFT. Returns array of length 2n-1."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]


def internal_score(a):
    """Compute 2*n*max_b assuming sum(a)≈1."""
    n = len(a)
    return 2.0 * n * fast_autocorr(a).max()


def evaluate_safe(arr):
    """Safely evaluate a sequence using the provided evaluate_sequence."""
    try:
        a_list = [float(max(0.0, min(1000.0, x))) for x in arr]
        sc = evaluate_sequence(a_list)
        return float(sc)
    except Exception:
        return float('inf')


def project_simplex(v, target_sum=1.0):
    """Project v onto {x: sum(x)=target_sum, x>=0}."""
    n = len(v)
    v = np.asarray(v, dtype=np.float64).copy()
    # Binary search on threshold
    v_sorted = np.sort(v)[::-1]
    cssv = np.cumsum(v_sorted)
    rho_candidates = np.nonzero(v_sorted * np.arange(1, n + 1) > (cssv - target_sum))[0]
    if len(rho_candidates) == 0:
        return np.full(n, target_sum / n)
    rho = rho_candidates[-1]
    theta = (cssv[rho] - target_sum) / (rho + 1.0)
    result = np.maximum(v - theta, 0)
    # Fix numerical issues
    diff = target_sum - result.sum()
    if abs(diff) > 1e-15:
        idx = np.argmax(result)
        result[idx] += diff
        result = np.maximum(result, 0)
        s = result.sum()
        if s > 0:
            result = result / s * target_sum
    return result


def qx_product(w, x):
    """
    Compute Q*x where Q_{ij} = w_{i+j}.
    Uses FFT for O(n log n) computation.
    w has length 2n-1, x has length n.
    Returns vector of length n.
    """
    n = len(x)
    fft_size = 1 << (3 * n - 2).bit_length()
    
    # x_rev[j] = x[n-1-j]
    x_rev = x[::-1].astype(np.float64)
    
    # Pad to fft_size
    X = rfft(x_rev, fft_size)
    W = rfft(w, fft_size)
    
    # d = IFFT(X * W)
    # d[m] = sum_j x_rev[j] * w[m-j] = sum_j x[n-1-j] * w[m-j]
    # Let k = n-1-j: d[m] = sum_k x[k] * w[m-n+1+k]
    # We want (Qx)_i = sum_k x[k] * w[i+k], so m-n+1 = i, m = i+n-1
    # (Qx)_i = d[i+n-1]
    d = irfft(X * W, fft_size)
    result = d[n-1 : 2*n-1]
    return result


def compute_grad(a, w):
    """
    Compute gradient of sum_k w_k * (a*a)_k w.r.t. a.
    grad_j = 2 * sum_k w_k * a_{k-j} = 2 * (Q*w_conv)... 
    Actually: grad_j = 2 * sum_{m=0}^{n-1} a_m * w_{m+j}
    This is the same as 2 * (Q^T @ a)... but Q is symmetric so 2*Q@a.
    Wait: Q_{ij} = w_{i+j}, so (Qa)_i = sum_j w_{i+j} a_j = sum_j a_j w_{i+j}
    And grad_i = 2 * sum_m a_m w_{m+i} = 2 * (Qa)_i (by symmetry of w_{i+j} = w_{j+i})
    So grad = 2 * Q @ a = 2 * qx_product(w, a)
    """
    n = len(a)
    return 2.0 * qx_product(w, a)


def softmax_weights(b, T):
    """Compute softmax weights with temperature T. b has length 2n-1."""
    Tb = T * b
    max_Tb = Tb.max()
    exp_Tb = np.exp(Tb - max_Tb)
    w = exp_Tb / exp_Tb.sum()
    return w


def mirror_descent(a0, time_limit, T=50.0, eta0=0.1, verbose=True):
    """
    Exponential gradient (mirror descent) for minimizing max_k (a*a)_k.
    Update: a_j <- a_j * exp(-eta * g_j), then normalize.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    best_score = internal_score(a)
    t0 = time.monotonic()
    t = 0
    stall = 0
    best_T = T
    
    while time.monotonic() - t0 < time_limit:
        t += 1
        b = fast_autocorr(a)
        w = softmax_weights(b, T)
        g = compute_grad(a, w)
        
        # Adaptive learning rate
        g_norm = np.max(g) - np.min(g)
        if g_norm < 1e-15:
            break
        eta = eta0 / (1.0 + 0.01 * t)
        
        # Mirror descent update
        log_a = np.log(np.maximum(a, 1e-30))
        log_a_new = log_a - eta * g
        # Clip for numerical stability
        log_a_new = np.clip(log_a_new, -50, 50)
        a_new = np.exp(log_a_new - log_a_new.max())
        s = a_new.sum()
        if s < 1e-15:
            break
        a_new = a_new / s
        
        score = internal_score(a_new)
        if score < best_score:
            if score < best_score - 1e-8:
                stall = 0
            else:
                stall += 1
            best_score = score
            best_a = a_new.copy()
        else:
            stall += 1
        
        a = a_new
        
        # Adapt temperature
        if t % 500 == 0:
            # Gradually increase T (focus more on peaks)
            T = min(T * 1.1, 500.0)
            # If stalled, restart with lower T
            if stall > 500:
                T = max(T * 0.5, 10.0)
                stall = 0
                # Back to best
                a = best_a.copy()
        
        if verbose and t % 1000 == 0:
            elapsed = time.monotonic() - t0
            print(f"      MD t={t} ({elapsed:.0f}s): best={best_score:.6f}, T={T:.1f}")
        
        if stall > 2000:
            break
    
    return best_a, best_score


def fista_qp_inner(w, a_init, n_inner=200, eta=None):
    """
    Solve min a^T Q a s.t. sum(a)=1, a>=0 using FISTA.
    Q_{ij} = w_{i+j}. Uses O(n log n) matrix-vector products.
    """
    n = len(a_init)
    
    # Estimate Lipschitz constant
    if eta is None:
        # Conservative estimate: L = 2 * ||Q||_2 <= 2 * max_i sum_j w_{i+j} = 2
        # But in practice, L is much smaller. Use power iteration to estimate.
        x = np.ones(n) / n
        for _ in range(10):
            Qx = qx_product(w, x)
            norm_Qx = np.linalg.norm(Qx)
            norm_x = np.linalg.norm(x)
            if norm_x < 1e-15:
                break
            x = Qx / norm_Qx
        L = 2.0 * norm_Qx / norm_x + 1e-6
        eta = 1.0 / L
    
    a = np.maximum(a_init.copy(), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    y = a.copy()
    a_prev = a.copy()
    
    for t in range(1, n_inner + 1):
        # Compute gradient at y
        grad_y = compute_grad(y, w)
        
        # Update a
        a_new = project_simplex(y - eta * grad_y)
        
        # FISTA momentum
        t_next = t + 1
        momentum = (t - 1) / (t_next + 1)
        y = a_new + momentum * (a_new - a)
        y = np.maximum(y, 0)  # Keep in domain
        s = y.sum()
        if s > 1e-15:
            y = y / s
        else:
            y = a_new.copy()
        
        a = a_new
        a_prev = y
    
    return a


def mw_fista_optimize(a0, time_limit, T_start=50.0, T_end=5.0, n_total=50000, verbose=True):
    """
    Multiplicative weights with FISTA inner solve.
    Very fast since inner solve is O(n log n * n_inner).
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    # Initialize w
    b0 = fast_autocorr(a)
    w = softmax_weights(b0, T_start)
    
    best_a = a.copy()
    best_score = internal_score(a)
    t0 = time.monotonic()
    
    # Time averaging
    avg_a = np.zeros(n)
    n_avg = 0
    stall = 0
    
    for t in range(1, n_total + 1):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Adaptive temperature
        progress = min(t / n_total, 1.0)
        T = T_start * (T_end / T_start) ** progress  # Geometric interpolation
        
        # Inner solve: min a^T Q a s.t. sum(a)=1, a>=0
        a_new = fista_qp_inner(w, a, n_inner=100)
        
        # Compute new autocorrelation
        b = fast_autocorr(a_new)
        
        # Update weights (multiplicative weights)
        log_w = np.log(np.maximum(w, 1e-30))
        log_w += T * b
        log_w -= log_w.max()
        w_new = np.exp(log_w)
        w_new /= w_new.sum()
        w = w_new
        
        # Check score
        score = internal_score(a_new)
        if score < best_score:
            if score < best_score - 1e-9:
                stall = 0
            best_score = score
            best_a = a_new.copy()
        else:
            stall += 1
        
        # Time average
        avg_a += a_new
        n_avg += 1
        if n_avg % 100 == 0 and n_avg >= 200:
            avg = avg_a / n_avg
            score_avg = internal_score(avg)
            if score_avg < best_score:
                best_score = score_avg
                best_a = avg.copy()
                stall = 0
        
        a = a_new
        
        if verbose and t % 500 == 0:
            elapsed = time.monotonic() - t0
            print(f"      MW-FISTA t={t} ({elapsed:.0f}s): best={best_score:.6f}, T={T:.1f}")
        
        if stall > 5000:
            # Try to unstick: add noise
            a = best_a + 0.01 * np.random.default_rng(t).standard_normal(n)
            a = project_simplex(a)
            stall = 0
    
    # Check time average one more time
    if n_avg > 0:
        avg = avg_a / n_avg
        score_avg = internal_score(avg)
        if score_avg < best_score:
            best_score = score_avg
            best_a = avg.copy()
    
    return best_a, best_score


def frank_wolfe_optimize(a0, time_limit, T=100.0, verbose=True):
    """
    Frank-Wolfe (conditional gradient) with line search.
    At each step: find vertex e_s with min gradient, then line search.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    best_score = internal_score(a)
    t0 = time.monotonic()
    t = 0
    stall = 0
    
    while time.monotonic() - t0 < time_limit:
        t += 1
        b = fast_autocorr(a)
        w = softmax_weights(b, T)
        g = compute_grad(a, w)
        
        # Find vertex with minimum gradient
        s_idx = np.argmin(g)
        e_s = np.zeros(n)
        e_s[s_idx] = 1.0
        
        # Line search: minimize f((1-gamma)*a + gamma*e_s) for gamma in [0,1]
        # Use a few candidate gammas
        best_gamma = 0.0
        best_trial_score = best_score
        
        # Standard FW step size: gamma = 2/(t+2)
        gamma_fw = 2.0 / (t + 2)
        
        candidates = [gamma_fw, 0.1, 0.2, 0.3, 0.5, 0.7, 0.9]
        candidates = [gamma for gamma in candidates if 0 < gamma < 1]
        
        for gamma in candidates:
            a_trial = (1.0 - gamma) * a + gamma * e_s
            score = internal_score(a_trial)
            if score < best_trial_score:
                best_trial_score = score
                best_gamma = gamma
        
        if best_gamma > 0:
            a = (1.0 - best_gamma) * a + best_gamma * e_s
            score = internal_score(a)
            if score < best_score:
                if score < best_score - 1e-10:
                    stall = 0
                best_score = score
                best_a = a.copy()
            else:
                stall += 1
        else:
            stall += 1
        
        if verbose and t % 5000 == 0:
            elapsed = time.monotonic() - t0
            print(f"      FW t={t} ({elapsed:.0f}s): best={best_score:.6f}")
        
        if stall > 20000:
            break
    
    return best_a, best_score


def coord_descent_anneal(a0, time_limit, seed=123, verbose=True):
    """
    Coordinate descent with simulated annealing.
    Moves mass from high-contributing positions to low-contributing ones.
    """
    n = len(a0)
    rng = np.random.default_rng(seed)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    best_score = internal_score(a)
    t0 = time.monotonic()
    t = 0
    temperature = 0.001
    stall = 0
    
    while time.monotonic() - t0 < time_limit:
        t += 1
        
        b = fast_autocorr(a)
        
        # Find peak lags
        peak_val = b.max()
        peak_lags = np.where(b > peak_val * 0.95)[0]
        
        if len(peak_lags) == 0:
            peak_lags = [np.argmax(b)]
        
        # Find positions most responsible for peaks
        # contrib[j] = sum over peak lags k of a[j] * a[k-j]
        contrib = np.zeros(n)
        for k in peak_lags[:20]:  # Limit to top 20 peaks
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            contrib[idx] += a[idx] * a[k - idx]
        
        # Choose source: position with high contribution and high value
        if contrib.max() > 0:
            src_weights = contrib * a
            src_weights = np.maximum(src_weights, 0)
            src_weights /= src_weights.sum()
            src = rng.choice(n, p=src_weights)
        else:
            src = int(rng.integers(n))
        
        # Choose destination: position with low contribution
        dst_weights = 1.0 / (contrib + peak_val * 0.01)
        dst_weights = np.maximum(dst_weights, 0)
        dst_weights[src] = 0  # Don't move to self
        dst_weights /= dst_weights.sum()
        dst = rng.choice(n, p=dst_weights)
        
        if src == dst or a[src] < 1e-12:
            continue
        
        # Try different amounts
        best_frac = 0
        best_trial_score = best_score
        for frac in [0.001, 0.005, 0.01, 0.02, 0.05, 0.1, 0.2]:
            amt = a[src] * frac
            if amt < 1e-15:
                continue
            a_trial = a.copy()
            a_trial[src] -= amt
            a_trial[dst] += amt
            if a_trial[src] < -1e-15:
                continue
            a_trial = np.maximum(a_trial, 0)
            a_trial /= a_trial.sum()
            score = internal_score(a_trial)
            
            # Simulated annealing: accept worse moves with probability exp(-delta/T)
            if score < best_trial_score:
                best_trial_score = score
                best_frac = frac
            
            if score - best_score < temperature:
                # Accept (MCMC style)
                if score < best_trial_score or rng.random() < np.exp(-(score - best_score) / max(temperature, 1e-10)):
                    a = a_trial
                    if score < best_score:
                        best_score = score
                        best_a = a.copy()
                        stall = 0
                    break
        
        if best_trial_score >= best_score and best_frac > 0:
            # Apply the best improvement found
            amt = a[src] * best_frac
            a_trial = a.copy()
            a_trial[src] -= amt
            a_trial[dst] += amt
            a_trial = np.maximum(a_trial, 0)
            a_trial /= a_trial.sum()
            a = a_trial
            score = internal_score(a)
            if score < best_score:
                best_score = score
                best_a = a.copy()
                stall = 0
            else:
                stall += 1
        else:
            stall += 1
        
        # Cool down
        temperature *= 0.9999
        temperature = max(temperature, 1e-6)
        
        if verbose and t % 10000 == 0:
            elapsed = time.monotonic() - t0
            print(f"      CD t={t} ({elapsed:.0f}s): best={best_score:.6f}, T={temperature:.6f}")
        
        if stall > 50000:
            break
    
    return best_a, best_score
