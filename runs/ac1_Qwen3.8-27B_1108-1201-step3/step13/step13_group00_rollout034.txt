Actually, one more thought: the full coordinate descent where we optimize a[i] for fixed other coordinates. The 1D problem is:

minimize max_k [base_k + lin_k * x + quad * x^2 * I(k=2i)]
over x in [0, x_max]

where base_k and lin_k are precomputed.

This is a convex 1D problem (max of convex functions). We can solve it efficiently:

1. Compute the "envelope" function E(x) = max_k [base_k + lin_k * x + (x^2 if k==2i)]
2. Find x that minimizes E(x)

Since E is convex and piecewise (linear + one quadratic), the minimum is at a "kink point" where two (or more) of the functions achieve the max, or at x=0.

The kink points are where base_k + lin_k * x = base_j + lin_j * x (for the linear parts) or base_k + lin_k * x = base_{2i} + x^2 (for the quadratic part).

For the linear parts: x = (base_j - base_k) / (lin_k - lin_j) (when lin_k != lin_j)
For the quadratic: solve base_k + lin_k * x = base_{2i} + x^2, which is a quadratic equation.

The number of kink points is O(n^2) in the worst case, but typically we only need to check the "upper envelope" which has O(n) breakpoints.

A simpler approach: since we only need the minimum of the max, and the function is convex, we can use binary search on the "level" t:
- Is there an x such that base_k + lin_k * x + (x^2 if k=2i) <= t for all k?
- This is equivalent to: for each k, x must satisfy:
  - If k != 2i: lin_k * x <= t - base_k, i.e., x <= (t - base_k) / lin_k (if lin_k > 0) or x >= (t - base_k) / lin_k (if lin_k < 0)
  - If k = 2i: x^2 + lin_k * x + base_k - t <= 0, i.e., x in [root1, root2] where roots are from the quadratic

So for a given t, the feasible set for x is an intersection of half-lines (and one interval from the quadratic). This is always an interval (possibly empty). We can binary search on t to find the minimum t.

This gives O(n log n * log(precision)) per coordinate update, which is very fast!

def optimize_single_coordinate(base, lin, quad_pos, quad_c, x_max):
    """
    Find x in [0, x_max] minimizing max_k (base[k] + lin[k]*x + (x^2 if k==quad_pos else 0))
    
    base[k] + lin[k]*x for all k (linear part)
    base[quad_pos] + x^2 for k = quad_pos (quadratic part, if quad_pos is valid)
    """
    size = len(base)
    
    def feasible(t):
        """Check if there exists x in [0, x_max] such that all constraints are satisfied."""
        # For each k != quad_pos: base[k] + lin[k]*x <= t
        #   If lin[k] > 0: x <= (t - base[k]) / lin[k]
        #   If lin[k] < 0: x >= (t - base[k]) / lin[k]
        #   If lin[k] == 0: need base[k] <= t
        x_lo = 0.0
        x_hi = x_max
        
        for k in range(size):
            if k == quad_pos:
                continue
            if base[k] > t:
                return False
            if lin[k] > 1e-15:
                x_hi = min(x_hi, (t - base[k]) / lin[k])
            elif lin[k] < -1e-15:
                x_lo = max(x_lo, (t - base[k]) / lin[k])
        
        # For k = quad_pos: base[quad_pos] + x^2 <= t (if quad_pos is valid)
        # i.e., x^2 <= t - base[quad_pos]
        if quad_pos is not None and quad_pos < size:
            if t < base[quad_pos]:
                # x^2 <= t - base[quad_pos] < 0, impossible unless x=0 and base[quad_pos] <= t
                # Wait, the quadratic term is x^2 (positive), so base[quad_pos] + x^2 <= t
                # means x^2 <= t - base[quad_pos], which requires t >= base[quad_pos]
                return t >= base[quad_pos] and 0 <= x_lo <= min(x_hi, np.sqrt(max(0, t - base[quad_pos]))
            # x in [0, sqrt(t - base[quad_pos])] intersects [x_lo, x_hi]
            quad_hi = np.sqrt(max(0.0, t - base[quad_pos]))
            x_hi = min(x_hi, quad_hi)
        
        return x_lo <= x_hi + 1e-12
    
    # Binary search on t
    # Lower bound: max(base[k] for k != quad_pos) and base[quad_pos] (if valid)
    t_lo = max(0, np.max(base))  # at x=0, max is max(base)
    # Upper bound: evaluate at x=0 and x=x_max
    t_hi = max(np.max(base), np.max(base + lin * x_max))
    if quad_pos is not None and quad_pos < size:
        t_hi = max(t_hi, base[quad_pos] + x_max * x_max)
    
    # Actually, t_lo should be the minimum possible value, which is at least:
    # The minimum of max_k (base[k] + lin[k]*x) over x >= 0 (ignoring the quadratic)
    # This is at least the "lower envelope" of the max of lines, which is >= min of the max at x=0
    # For a conservative lower bound: t_lo = max_k base[k] - max_k |lin[k]| * x_max
    # But let's just use t_lo = min(max(base), max(base + lin*x_max)) as a lower bound
    # Actually the true minimum is >= min_x max_k f_k(x) >= min(max at x=0, max at x=x_max)
    # No that's not right either.
    # Let me just use a wide range and binary search.
    t_lo = np.min(base)  # very loose lower bound
    t_hi = max(np.max(base + np.abs(lin) * x_max), base[quad_pos] + x_max*x_max if quad_pos is not None and quad_pos < size else 0)
    
    for _ in range(60):
        t_mid = (t_lo + t_hi) / 2
        if feasible(t_mid):
            t_hi = t_mid
        else:
            t_lo = t_mid
    
    # t_hi is the optimal value, now find the optimal x
    t_star = t_hi
    x_lo_final = 0.0
    x_hi_final = x_max
    for k in range(size):
        if k == quad_pos:
            continue
        if lin[k] > 1e-15:
            x_hi_final = min(x_hi_final, (t_star - base[k]) / lin[k])
        elif lin[k] < -1e-15:
            x_lo_final = max(x_lo_final, (t_star - base[k]) / lin[k])
    if quad_pos is not None and quad_pos < size:
        x_hi_final = min(x_hi_final, np.sqrt(max(0.0, t_star - base[quad_pos])))
    
    x_opt = (x_lo_final + x_hi_final) / 2
    return max(0, min(x_opt, x_max)), t_star

            shifted = np.clip(shifted, -500, 0)
            exp_vals = np.exp(shifted)
            w = exp_vals / exp_vals.sum()

            # Gradient: grad_i = 2 * sum_k w_k * a[k-i] (with a[m]=0 outside [0,n-1])
            # = 2 * cross_corr(w, a)[i] computed via FFT
            W = rfft(w, fft_size)
            A = rfft(a, fft_size)
            cross = irfft(W * np.conj(A), fft_size)
            grad = 2.0 * cross[:n]

            # Multiplicative update with learning rate
            eta = min(1.0, 2.0 * T / (n * max(1.0, grad.max())))
            log_a = np.log(np.maximum(a, 1e-300))
            log_a -= eta * grad
            log_a -= log_a.max()  # numerical stability
            a_new = np.exp(log_a)
            s_new = a_new.sum()
            if s_new < 1e-300:
                a_new = a.copy()
            else:
                a_new = a_new * norm / s_new

            conv_new = fast_conv(a_new)
            score = conv_new.max()
            if score < best_score - 1e-12:
                best_score = score
                best_a = a_new.copy()

            a = a_new

            if verbose and si == 0 and si % 3 == 0:
                elapsed = time.monotonic() - t0
                print(f"    MWU stage={si} T={T:.1f} ({elapsed:.0f}s): best={best_score:.8f}")

    return best_a, best_score


def lp_nesterov_optimize(a0, time_limit, verbose=True):
    """
    LP best-response with Nesterov acceleration.
    Finds b maximizing sum(b) s.t. conv(a,b) <= M, b >= 0.
    """
    import cvxpy as cp
    n = len(a0)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s0 = a.sum()
    if s0 < 1e-15:
        a = np.ones(n) * norm / n
    else:
        a = a * norm / s0

    best_a = a.copy()
    best_score = fast_conv(a).max()
    t0 = time.monotonic()
    size = 2 * n - 1

    solver_enum = get_solver_enum()
    b_var = None
    T_matrix = None

    y = a.copy()
    avg_a = np.zeros(n)
    n_avg = 0
    n_iters = 0

    for t in range(1, 100000):
        if time.monotonic() - t0 > time_limit:
            break

        M_curr = fast_conv(y).max()
        if M_curr < 1e-14:
            break

        # Build constraint matrix if needed
        if T_matrix is None:
            T_matrix = build_conv_matrix(y)

        # Constraint screening: only use active constraints
        conv_y = fast_conv(y)
        active = np.where(conv_y > M_curr * 0.7)[0]
        if len(active) < 5:
            active = np.where(conv_y > M_curr * 0.3)[0]
        if len(active) < size:
            T_active = T_matrix[active, :]
        else:
            T_active = T_matrix

        # Solve LP: max sum(b) s.t. T_active @ b <= M_curr, b >= 0
        if b_var is None or len(b_var.size if hasattr(b_var, 'size') else b_var.shape[0]) != n:
            b_var = cp.Variable(n, nonneg=True)

        constraints = [T_active @ b_var <= M_curr]
        prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)

        try:
            if solver_enum == cp.PDLP:
                prob.solve(solver=cp.PDLP, verbose=False)
            elif solver_enum == cp.MOSEK:
                prob.solve(solver=cp.MOSEK, verbose=False)
            elif solver_enum == cp.GUROBI:
                prob.solve(solver=cp.GUROBI, verbose=False)
            elif solver_enum == cp.CLARABEL:
                prob.solve(solver=cp.CLARABEL, verbose=False)
            else:
                prob.solve(solver=cp.ECOS, verbose=False)
        except Exception:
            try:
                prob.solve(solver=cp.ECOS, verbose=False)
            except Exception:
                continue

        if prob.status not in ('optimal', 'optimal_inaccurate'):
            continue

        b_val = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
        b_sum = b_val.sum()
        if b_sum < 1e-15:
            continue

        # Verify no constraint violation (if screened)
        if len(active) < size:
            full_conv_test = T_matrix @ b_val
            if np.any(full_conv_test > M_curr * (1 + 1e-5)):
                # Re-solve with all constraints
                constraints_full = [T_matrix @ b_var <= M_curr]
                prob_full = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints_full)
                try:
                    prob_full.solve(solver=cp.ECOS, verbose=False)
                except Exception:
                    continue
                if prob_full.status not in ('optimal', 'optimal_inaccurate'):
                    continue
                b_val = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
                b_sum = b_val.sum()
                if b_sum < 1e-15:
                    continue

        g = b_val * norm / b_sum
        n_iters += 1

        # Nesterov acceleration
        alpha = 2.0 / (t + 2.0)
        y_new = (1.0 - alpha) * y + alpha * g
        y_new = np.maximum(y_new, 0.0)
        s_y = y_new.sum()
        if s_y < 1e-15:
            y_new = y.copy()
        else:
            y_new = y_new * norm / s_y

        if t == 1:
            a_new = g.copy()
        else:
            momentum = (t - 1.0) / (t + 2.0)
            a_new = y_new + momentum * (y_new - y)
            a_new = np.maximum(a_new, 0.0)
            s_a = a_new.sum()
            if s_a < 1e-15:
                a_new = y_new.copy()
            else:
                a_new = a_new * norm / s_a

        a = a_new

        if score_y < best_score:
            best_score = score_y
            best_a = y.copy()
