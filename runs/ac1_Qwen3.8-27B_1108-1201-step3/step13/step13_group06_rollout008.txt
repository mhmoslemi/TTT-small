Actually, I realize I should think more carefully about the self-consistent field method. Let me derive it properly.

The problem: minimize `max_k c_k(a)` subject to `a >= 0, sum(a) = 1`.

The value function: `V(a) = max_k c_k(a)`.

The subdifferential: `∂V(a) = conv{∇c_k(a) : k in argmax_k c_k(a)}`.

So a subgradient is `g = sum_{k in S} λ_k ∇c_k(a)` where `S = argmax c_k`, `λ_k >= 0`, `sum λ_k = 1`.

The gradient of `c_k` w.r.t. `a` is `2 * shift_k(a)` where `shift_k(a)[j] = a[k-j]` (zero-padded).

So `g[j] = 2 * sum_{k in S} λ_k * a[k-j]`.

The self-consistent field is: find `λ` such that `g[j]` is constant (= some `c0`) for all `j` in the support of `a`. This is the KKT condition.

Given `λ`, the "force" on `a[j]` is `g[j]`. To minimize the max, we want to reduce `a[j]` where `g[j]` is large (since increasing `a[j]` would increase `c_k` for k in S).

The multiplicative update: `a[j] <- a[j] * exp(-η * g[j])` (then renormalize).

But actually, we want `g[j]` to be constant, not to minimize it. So the update should be:
`a[j] <- a[j] * (c0 / g[j])^η` where `c0 = mean(g[j])` on support.

This is equivalent to `a[j] <- a[j] * exp(η * (log(c0) - log(g[j])))` ≈ `a[j] * exp(-η * (g[j] - c0))` for small variations.

OK so my earlier formulation was correct. Let me now think about how to find good `λ`.

For a given active set S, the optimal `λ` minimizes the variance of `g = sum λ_k ∇c_k` on the support of `a`. This is:
minimize `Var(g[j])` over `j` in support
subject to `sum λ_k = 1, λ_k >= 0`

Where `g[j] = sum_k λ_k * 2*a[k-j]`.

Let `B[j,k] = 2*a[k-j]` (zero-padded). Then `g = B^T λ` (where B is n × |S|).

`Var(g) = (1/|J|) sum_{j in J} (g[j] - mean(g))^2` where J is the support.

This is a QP in λ: minimize `λ^T B_J^T (I - 11^T/|J|) B_J λ` subject to `sum λ = 1, λ >= 0`.

For |S| up to a few hundred, this QP is easily solvable.

1. Given a, find S (active peaks)
2. Given S, solve for optimal λ (or use uniform)
3. Given λ, update a (multiplicative)
4. Go to 1

This is a fixed-point iteration that should converge to a KKT point.

import numpy as np

from scipy.fft import rfft, irfft


def fast_autocorr(a):
    """Full convolution a*a using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]


def evaluate_safe(a):
    """Safely evaluate using the provided evaluate_sequence."""
    try:
        a_list = [float(max(0.0, min(1000.0, x))) for x in a]
        sc = evaluate_sequence(a_list)
        return float(sc)
    except Exception:
        return float('inf')


def compute_V_sliding(a, K_min, K_max):
    """
    Compute V[j] = (1/S) * sum_{k=K_min}^{K_max} a[k-j] (valid indices only)
    using prefix sums for O(n) computation.
    """
    n = len(a)
    S = K_max - K_min + 1
    prefix = np.concatenate([[0.0], np.cumsum(a)])
    j = np.arange(n)
    m_lo = np.maximum(K_min - j, 0)
    m_hi = np.minimum(K_max - j, n - 1)
    valid = m_lo <= m_hi
    V = np.zeros(n)
    V[valid] = (prefix[m_hi[valid] + 1] - prefix[m_lo[valid]]) / S
    return V


def self_consistent_field(a0, time_limit, eta_init=0.3, threshold_frac=0.05, 
                          scf_iters_per_update=10, seed=42):
    """
    Self-Consistent Field method: iteratively finds a and active set S
    such that the weighted autocorrelation gradient is flat on the support.
    """
    rng = np.random.default_rng(seed)
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()
    eta = eta_init
    stall = 0
    
    while time.monotonic() - t0 < time_limit - 2:
        c = fast_autocorr(a)
        c_max = c.max()
        
        # Find active range (contiguous peaks)
        threshold = c_max * (1.0 - threshold_frac)
        active = np.where(c >= threshold)[0]
        if len(active) == 0:
            active = np.array([n - 1])
        K_min = active[0]
        K_max = active[-1]
        
        # Compute V (sliding window average)
        V = compute_V_sliding(a, K_min, K_max)
        
        # Multiplicative update
        support = np.where(a > 1e-14)[0]
        if len(support) > 0:
            V_mean = V[support].mean()
            V_clipped = np.maximum(V, 1e-30)
            # a[j] *= (V_mean / V[j])^eta
            a_new = a * np.power(V_mean / V_clipped, eta)
            a_new = np.maximum(a_new, 0)
            sn = a_new.sum()
            if sn < 1e-15:
                # Fallback
                a_new = a.copy()
            else:
                a_new = a_new / sn
            
            score = 2.0 * n * fast_autocorr(a_new).max()
            if score < best_score * (1 - 1e-10):
                best_score = score
                best_a = a_new.copy()
                a = a_new
                stall = 0
            else:
                stall += 1
                if stall % 30 == 0:
                    eta *= 0.7
                if stall > 300:
                    # Perturbation and reset
                    a = best_a.copy()
                    noise = rng.normal(0, 0.02, n)
                    a = a * (1 + noise)
                    a = np.maximum(a, 0)
                    sn = a.sum()
                    if sn > 1e-10:
                        a = a / sn
                    stall = 0
                    eta = eta_init
        
        # Slowly decay eta
        eta = max(eta * 0.9995, eta_init * 0.1)
        
        if (int((time.monotonic() - t0) * 10) % 50) == 0:
            elapsed = time.monotonic() - t0
            if elapsed > 5:
                print(f"    SCF t={elapsed:.0f}s: best={best_score:.6f}, eta={eta:.4f}, S=[{K_min},{K_max}]")
    
    return best_a, best_score

def build_toeplitz(a_fixed):
    """Build (2n-1) x n matrix T where T@b = convolve(a_fixed, b)."""
    n = len(a_fixed)
    T = np.zeros((2 * n - 1, n))
    for j in range(n):
        T[j:j + n, j] = a_fixed
    return T


def find_solver():
    """Find a working LP solver."""
    for solver_name in [cp.CLARABEL, cp.SCS, cp.ECOS, cp.PDLP, cp.MOSEK, cp.GLPK]:
        try:

            prob = cp.Problem(cp.Minimize(cp.sum(x)), [cp.sum(x) == 1, x <= 0.5])
            prob.solve(solver=solver_name)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                return solver_name
        except Exception:

    return cp.ECOS


def solve_lp_best_response(y, T, solver, warm_b=None):
    """Solve LP: min M s.t. T@b <= M, sum(b)=1, b>=0."""
    n = len(y)
    if warm_b is not None and np.all(warm_b >= -1e-10) and warm_b.sum() > 1e-10:
        b_var = cp.Variable(n, nonneg=True, value=warm_b)
    else:
        b_var = cp.Variable(n, nonneg=True)
    M_var = cp.Variable(value=1.0 / n)
    constraints = [T @ b_var <= M_var, cp.sum(b_var) == 1]
    prob = cp.Problem(cp.Minimize(M_var), constraints)
    try:
        prob.solve(solver=solver)
    except Exception:
        pass
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        for alt in [cp.SCS, cp.ECOS, cp.CLARABEL, cp.PDLP]:
            if alt == solver:
                continue
            try:
                prob.solve(solver=alt)
                if prob.status in ('optimal', 'optimal_inaccurate'):
                    break
            except Exception:
                continue
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None, None
    b_val = np.asarray(b_var.value, dtype=np.float64)
    b_val = np.maximum(b_val, 0)
    s = b_val.sum()
    if s < 1e-15:
        return None, None
    b_val = b_val / s
    return b_val, float(M_var.value)

def peak_shaving(a0, time_limit, seed=42):
    """Systematic peak shaving with global peak verification."""
    n = len(a0)
    rng = np.random.default_rng(seed)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()
    stall = 0
    
    while time.monotonic() - t0 < time_limit - 2:
        b = fast_autocorr(a)
        bmax = b.max()
        threshold = bmax * 0.995
        top_peaks = np.where(b >= threshold)[0]
        if len(top_peaks) == 0:
            top_peaks = np.argsort(b)[::-1][:5]
        
        danger = np.zeros(n, dtype=bool)
        for k in top_peaks[:20]:
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            danger[js:je + 1] = True
        
        improved = False
        for k in top_peaks[:15]:
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            if len(idx) == 0:
                continue
            contrib = a[idx] * a[k - idx]
            if contrib.max() < 1e-15:
                continue
            src = idx[np.argmax(contrib)]
            
            safe = np.where(~danger)[0]
            safe = safe[safe != src]
            if len(safe) == 0:
                safe = np.where(np.arange(n) != src)[0]
            safe_sorted = safe[np.argsort(a[safe])]
            dst_pool = safe_sorted[:max(10, len(safe_sorted) // 3)]
            if len(dst_pool) == 0:
                continue
            
            found = False
            for dst in dst_pool[:12]:
                for frac in [0.002, 0.005, 0.01, 0.02, 0.04, 0.07, 0.10, 0.15]:
                    amt = a[src] * frac
                    if amt < 1e-15:
                        continue
                    a_trial = a.copy()
                    a_trial[src] -= amt
                    a_trial[dst] += amt
                    if a_trial[src] < -1e-12:
                        continue
                    a_trial = np.maximum(a_trial, 0)
                    st = a_trial.sum()
                    if st < 1e-12:
                        continue
                    a_trial = a_trial / st
                    new_max = fast_autocorr(a_trial).max()
                    if new_max < bmax * (1 - 1e-9):
                        a = a_trial
                        new_score = 2.0 * n * new_max
                        if new_score < best_score:
                            best_score = new_score
                            best_a = a.copy()
                        improved = True
                        found = True
                        stall = 0
                        break
                if found:
                    break
            if improved:
                break
        
        if not improved:
            stall += 1
            if stall % 15 == 0:
                n_pert = rng.integers(1, 6)
                a_trial = a.copy()
                for _ in range(n_pert):
                    i = rng.integers(n)
                    j = rng.integers(n)
                    if i != j and a_trial[i] > 1e-10:
                        frac = rng.uniform(0.001, 0.05)
                        amt = a_trial[i] * frac
                        a_trial[i] -= amt
                        a_trial[j] += amt
                a_trial = np.maximum(a_trial, 0)
                st = a_trial.sum()
                if st > 1e-10:
                    a_trial = a_trial / st
                    score = 2.0 * n * fast_autocorr(a_trial).max()
                    if score < best_score:
                        a = a_trial
                        best_score = score
                        best_a = a.copy()
                        stall = 0
            
            if stall > 300:
                break
    
    return best_a, best_score


def mirror_descent_refine(a0, time_limit, eta=0.01, seed=999):
    """Multiplicative weights refinement targeting top peaks."""
    n = len(a0)
    rng = np.random.default_rng(seed)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()
    stall = 0
    current_eta = eta
    
    while time.monotonic() - t0 < time_limit - 2:
        b = fast_autocorr(a)
        bmax = b.max()
        threshold = bmax * 0.99
        top_peaks = np.where(b >= threshold)[0]
        if len(top_peaks) == 0:
            top_peaks = np.argsort(b)[::-1][:5]
        
        importance = np.zeros(n)
        for k in top_peaks[:15]:
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            importance[idx] += a[k - idx]
        
        imax = importance.max()
        if imax > 1e-15:
            importance = importance / imax
        
        updates = 1.0 - current_eta * importance
        updates = np.maximum(updates, 0.01)
        updates = updates / updates.mean()
        a_new = a * updates
        a_new = np.maximum(a_new, 0)
        sn = a_new.sum()
        if sn < 1e-15:
            break
        a_new = a_new / sn
        
        score_new = 2.0 * n * fast_autocorr(a_new).max()
        if score_new < best_score:
            a = a_new
            best_score = score_new
            best_a = a.copy()
            stall = 0
        else:
            stall += 1
            if stall % 50 == 0:
                current_eta /= 2
                if current_eta < 1e-7:
                    current_eta = eta
                    a = best_a.copy()
                    noise = rng.normal(0, 0.01, n)
                    a = a * (1 + noise)
                    a = np.maximum(a, 0)
                    sn = a.sum()
                    if sn > 1e-10:
                        a = a / sn
            
            if stall > 500:
                break
    
    return best_a, best_score


def interpolate_sequence(f, new_n):
    """Interpolate a normalized sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp


def gradient_descent_smoothed(a0, time_limit, n_stages=20, topk_range=(5, 50), seed=123):
    """
    Gradient descent on smoothed max using LogSumExp, with adaptive topk.
    Uses the simple gradient structure: grad c_k = 2 * shifted a.
    """
    rng = np.random.default_rng(seed)
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()
    
    temps = np.geomspace(50.0, 0.5, n_stages)
    lrs = [0.005, 0.003, 0.002, 0.001, 0.0005]
    
    for si, T in enumerate(temps):
        if time.monotonic() - t0 > time_limit - 5:
            break
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 10:
            break
        
        lr = lrs[min(si // 4, len(lrs)-1)] * min(1.0, 100.0 / n)
        
        # Adam state
        m = np.zeros(n)
        v = np.zeros(n)
        t_adam = 0
        beta1, beta2, eps = 0.8, 0.999, 1e-8
        
        max_it = max(20, int(remaining * 0.8 * 3))
        
        for it in range(max_it):
            if time.monotonic() - t0 > time_limit - 3:
                break
            
            c = fast_autocorr(a)
            c_max = c.max()
            
            # Top-k lags
            k_use = max(5, min(len(c), int(n * 0.03)))
            top_idx = np.argsort(c)[::-1][:k_use]
            top_vals = c[top_idx]
            
            # LSE and gradient
            shifted = top_vals - top_vals.max()
            exp_shifted = np.exp(shifted)
            w = exp_shifted / exp_shifted.sum()
            lse = (top_vals.max() + np.log(exp_shifted.sum())) / T
            
            # Gradient: weighted sum of shifted a
            grad = np.zeros(n)
            for idx in range(k_use):
                K = top_idx[idx]
                wK = w[idx]
                js = max(0, K - n + 1)
                je = min(n - 1, K)
                if js <= je:
                    grad[js:je+1] += 2.0 * wK * a[K-je:js-1:-1]
            
            # Projected gradient step (simplex projection)
            t_adam += 1
            m = beta1 * m + (1 - beta1) * grad
            v = beta2 * v + (1 - beta2) * grad ** 2
            m_hat = m / (1 - beta1 ** t_adam)
            v_hat = v / (1 - beta2 ** t_adam)
            step = lr * m_hat / (np.sqrt(v_hat) + eps)
            
            a_new = a - step
            a_new = np.maximum(a_new, 0)
            sn = a_new.sum()
            if sn < 1e-15:
                a_new = a.copy()
            else:
                a_new = a_new / sn
            
            # Check every few iterations
            if (it + 1) % 5 == 0:
                score = 2.0 * n * fast_autocorr(a_new).max()
                if score < best_score:
                    best_score = score
                    best_a = a_new.copy()
                    a = a_new
                else:
                    a = a_new  # still accept for momentum
            
            # Occasional re-center
            if (it + 1) % 50 == 0:
                a = best_a + rng.normal(0, 0.005, n)
                a = np.maximum(a, 0)
                a = a / a.sum()
                m = np.zeros(n)
                v = np.zeros(n)
                t_adam = 0
        
        if (time.monotonic() - t0) % 30 < 1 or si == 0:
            elapsed = time.monotonic() - t0
            print(f"    GD stage {si}/{n_stages} (T={T:.1f}, {elapsed:.0f}s): best={best_score:.6f}")
    
    return best_a, best_score
