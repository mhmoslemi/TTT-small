**Fast coordinate descent with incremental updates:**

State: a (length n), conv (length 2n-1), current max M.

For a pair (i, j) with i ≠ j:

  where a[x] = 0 for x < 0 or x >= n
  q_k = 1 if k == 2i, +1 if k == 2j, -2 if k == i+j (these can overlap)

- We want to find delta in [0, a[i]] that minimizes max_k (conv[k] + Delta_k)

- Since Delta_k is linear in delta for most k (quadratic only at 3 positions), we can:
  1. Compute the "linear part" max: f_lin(delta) = max_k (conv[k] + 2*delta*s_k) where s_k = a[k-j] - a[k-i]
  2. The linear part is a piecewise-linear convex function of delta
  3. The full function is f(delta) = max(f_lin(delta), conv[2i] + 2*delta*s[2i] + delta^2, conv[2j] + 2*delta*s[2j] + delta^2, conv[i+j] + 2*delta*s[i+j] - 2*delta^2)
  4. Since f is convex, we can use ternary search on [0, a[i]]

- For efficiency, we can:
  - First check if delta=0 or delta=a[i] is optimal (boundary cases)
  - If not, use about 30-40 ternary search steps

**Alternative to LP: Use the "exponentiated gradient" method directly**

The LP best response is:
max sum(b) s.t. T b <= M, b >= 0

This is equivalent to:
min -sum(b) + sum_k [M b_k / 0] (indicator of T b <= M) + sum_i [b_i / 0] (indicator of b >= 0)

The exponentiated gradient (a.k.a. Fenchel duality) approach:
- Maintain log(b) as the variable
- At each step, take a subgradient step on the dual

The dual of the LP is:
min M * sum(y) s.t. T^T y >= 1, y >= 0

The exponentiated gradient for the dual:
- y_k = exp(log_y_k) (maintain log variables)
- Subgradient of dual objective w.r.t. y: M * 1 (constant)
- Constraint violation: (T^T y)_i - 1 <= 0 needed, so violation is max(0, 1 - (T^T y)_i)
- Update: log_y_k -= eta * (M + sum_i T_{k,i} * max(0, 1 - (T^T y)_i) * lambda_i)

import numpy as np
import time
from scipy.fft import rfft, irfft

def _next_pow2(m):
    return 1 << (m - 1).bit_length()

def _autocorr(a, L=None):
    """Compute full autocorrelation of a using FFT."""
    n = len(a)
    size = 2 * n - 1
    if L is None:
        L = _next_pow2(size)
    A = rfft(a, L)
    return irfft(A * A, L)[:size]

def _convolve(x, y, L=None):
    """Compute full convolution of x and y using FFT."""
    size = len(x) + len(y) - 1
    if L is None:
        L = _next_pow2(size)
    return irfft(rfft(x, L) * rfft(y, L), L)[:size]

def _cross_corr(x, y, L=None):
    """Compute cross-correlation: result[i] = sum_k x[k] * y[k+i] (linear)."""
    nx, ny = len(x), len(y)
    if L is None:
        L = _next_pow2(nx + ny - 1)
    X = rfft(x, L)
    Y = rfft(y, L)
    result = irfft(X * np.conj(Y), L)
    # result[i] for i=0..L-1 is circular cross-correlation
    # For linear cross-correlation, we need result[0:ny] (approximately)
    # Actually: result[i] = sum_k x[(k-i) mod L] * y[k]
    # Hmm, let me just use: result[i] = sum_k x[k] * y[(k+i) mod L]
    # For the linear version (i = 0, ..., nx-1): result[i] = sum_k x[k] * y[k+i] (valid k)
    return result[:ny]  # or result[:nx] depending on what we want

# Actually, let me just directly compute what I need:
# (T^T v)_i = sum_k a[k-i] * v[k] = sum_j a[j] * v[j+i]
# This is the cross-correlation of a and v at lag i (positive).
# Using: ifft(fft(a) * conj(fft(v)))[i] = sum_k a[(k-i) mod L] * v[k]
# For the linear version: = sum_j a[j] * v[j+i] (when j+i < len(v) and j < len(a))
# So I need L >= len(a) + len(v) - 1 for this to be correct.

def _twv(a, v, L):
    """Compute (T^T v)_i = sum_j a[j] * v[j+i] for i=0..n-1.
    L must be >= len(a) + len(v) - 1."""
    A = rfft(a, L)
    V = rfft(v, L)
    result = irfft(A * np.conj(V), L)
    return result[:len(a)]

def _lse_gradient(y, w, L):
    """Compute LSE gradient:
    grad_i = 2 * (sum_k w[k]*y[k+i] + sum_k w[k]*y[i-k])
    = 2 * (cross_wy[i] + conv_yw[i])
    where cross_wy[i] = sum_k w[k]*y[k+i] and conv_yw[i] = sum_k w[k]*y[i-k]
    """
    n = len(y)
    W = rfft(w, L)
    Y = rfft(y, L)
    # cross_wy[i] = sum_k w[k] * y[k+i] = IFFT(FFT(y) * conj(FFT(w)))[i]
    cross_wy = irfft(Y * np.conj(W), L)[:n]
    # conv_yw[i] = sum_k w[k] * y[i-k] = IFFT(FFT(w) * FFT(y))[i]
    conv_yw = irfft(W * Y, L)[:n]
    return 2.0 * (cross_wy + conv_yw)
