from scipy.fft import rfft, irfft


def _fast_autocorr(a):
    """Compute full convolution autocorrelation via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]


def _peak_gradient(a, k):
    """Compute gradient of c[k] = sum_t a[t]*a[k-t] w.r.t. a."""
    n = len(a)
    grad = np.zeros(n)
    # dc[k]/da[i] = 2*a[k-i] if 0 <= k-i < n
    valid = np.arange(n)
    ki = k - valid  # k - i for i in 0..n-1
    mask = (ki >= 0) & (ki < n)
    grad[mask] = 2.0 * a[ki[mask]]
    return grad


def _mirror_descent_step(a, grad, eta):
    """Exponential tilting step: a_new[i] = a[i] * exp(-eta * grad[i]) / Z"""
    # For numerical stability
    scaled = -eta * grad
    scaled -= scaled.max()  # shift for stability
    a_new = a * np.exp(scaled)
    s = a_new.sum()
    if s > 1e-30:
        a_new /= s
    else:
        a_new = a.copy()
    return a_new

Actually, let me think about it from the Fourier perspective. We have:
`c = ifft(|fft(a)|^2)` (with appropriate padding for linear convolution)

We want to minimize `max_k c[k]` subject to `sum a = 1, a >= 0`.

In the Fourier domain, `c[k]` is the inverse DFT of `|A[f]|^2` (the power spectrum). So we want the power spectrum to be as "flat" as possible (which makes `c` concentrated at one point) or... wait, we want `c` to be flat, which means the power spectrum should be concentrated.

Actually no. `c = ifft(|A|^2)` means that a flat `c` corresponds to a concentrated `|A|^2`, and a concentrated `c` (single peak) corresponds to a flat `|A|^2`.

We want `c` to be flat (all values equal), which means `|A|^2` should be concentrated at one frequency (DC). But `|A[0]|^2 = (sum a)^2 = 1` (for normalized), and we need `|A[f]|^2 = 0` for all `f != 0`. This means `A[f] = 0` for all `f != 0`, which means `a` is a delta function (concentrated at one point). But then `c` is also a delta function (concentrated), which has a large max.

So there's a tension: we can't make `c` perfectly flat. The best we can do is balance the peak of `c` against its spread.

This is essentially a time-frequency uncertainty principle problem. The minimum of `max_k c[k]` for `a >= 0, sum a = 1` is related to the "Beurling-Selberg" extremal problem.
