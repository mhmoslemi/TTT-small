Let me think about the multiplicative weight method more carefully.

The objective is to minimize `f(a) = max_k (a*a)[k]` subject to `sum(a) = 1, a >= 0`.

The subgradient of `f` at `a` (choosing the subgradient corresponding to the argmax) is:
`∇f(a) = 2 * a_shifted` where `a_shifted[j] = a[k* - j]` for `k* = argmax_k (a*a)[k]`.

More generally, if we average over the top `m` peaks:
`∇f(a) = (2/m) * sum_{i=1}^{m} a_shifted_{k_i}` where `a_shifted_k[j] = a[k-j]` (with zero padding).

The multiplicative weight update is:
`a_new[j] = a[j] * exp(-eta * ∇f(a)[j])`
`a_new = a_new / sum(a_new)`

This is equivalent to mirror descent with the negative entropy function `D(a) = sum a[j] log a[j]`.

The mirror descent theorem says: if `f` is `L`-Lipschitz (with respect to the dual norm of the regularization), then after `T` iterations, the gap to the optimum is `O(L^2 * T * D / ... )`. The exact rate depends on the constants.

For our problem, the "Lipschitz constant" of `f(a) = max_k (a*a)[k]` with respect to the `l1` norm is bounded by `2 * max_j |a[j]|` (roughly). Since `a[j] <= 1`, we have `L <= 2`.

The diameter of the simplex under the negative entropy is `log(n)`. So the rate is roughly `O(L^2 * log(n) / T) = O(4 * log(n) / T)`.

For `n = 1200`, `log(n) ≈ 7`. To get a gap of `0.001`, we need `T ≈ 4 * 7 / 0.001 = 28000` iterations. Each iteration requires an FFT (for the convolution) and an O(n) update. For `n = 1200`, each iteration takes about `O(n log n) ≈ 1200 * 11 ≈ 13000` operations. So 28000 iterations would take about `28000 * 13000 / 10^9 ≈ 0.4` seconds. Very fast!
