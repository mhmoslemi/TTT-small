One more thought: **Can we avoid the LP entirely?**

The best response `b*` satisfies the KKT conditions:
- `C(a) @ b* <= 1` (primal feasibility)
- `b* >= 0` (primal feasibility)
- `1 - C(a)^T @ lam = 0` for `b*_i > 0` (complementarity)
- `lam >= 0` (dual feasibility)
- `lam_k * (1 - (C(a) @ b*)_k) = 0` (complementarity)

So for the "active" coordinates (where `b*_i > 0`), we have:
`sum_k C[k,i] * lam_k = 1`

And for the "active" constraints (where `(C(a)@b*)_k = 1`), `lam_k > 0`.

This is a system of linear equations! If we know the active sets (which coordinates of b are positive, and which constraints are binding), we can solve it directly.

The active set of constraints is the set of lags where `conv(a,a)[k]` is near the max (these are the lags that will be binding). The active set of variables is the set of coordinates where `b*_i > 0` (typically all or most coordinates).

If all coordinates are active (b*_i > 0 for all i), then:
`C(a)^T @ lam = 1_n` (a system of n equations in 2n-1 unknowns lam_k)

With the constraint that `lam_k >= 0` and `lam_k = 0` for inactive k.

This is an underdetermined system (n equations, 2n-1 unknowns). We need an additional `n-1` equations to determine it, which come from the complementary slackness: `lam_k = 0` for inactive constraints.

If exactly `n` constraints are active (the most likely case for a non-degenerate solution), then we have `n` equations and `n` unknowns (the active lam_k's), which we can solve directly!

This is the **active set method** for the LP. It's essentially what the simplex method does, but if we can guess the active set correctly, we can solve it in one shot.

How to guess the active set: the active constraints are those where `conv(a,a)[k]` is closest to the max. Take the top n lags.

Let me implement this as an alternative to the full LP:

```python
def active_set_best_response(a, n_active=None):
    """Solve the LP using the active set method."""
    n = len(a)
    if n_active is None:
        n_active = n  # Assume n active constraints
    
    conv_aa = fast_convolve(a)
    max_val = conv_aa.max()
    
    # Select the top n_active lags
    active_lags = np.argpartition(conv_aa, -n_active)[-n_active:]
    active_lags.sort()
    
    # Build the system: C(a)^T @ lam = 1, restricted to active lags
    # C[k,j] = a[k-j] if 0 <= k-j < n else 0
    # (C^T)[j,k] = C[k,j] = a[k-j]
    # So (C^T @ lam)_j = sum_{k in active} a[k-j] * lam_k
    
    # This is a system of n equations in n_active unknowns
    # M @ lam = 1, where M[j,k] = a[k-j] for k in active_lags
    
    M = np.zeros((n, n_active))
    for idx, k in enumerate(active_lags):
        for j in range(max(0, k-n+1), min(n, k+1)):
            M[j, idx] = a[k-j]
    
    # Solve M @ lam = 1
    lam, residuals, rank, sv = np.linalg.lstsq(M, np.ones(n), rcond=None)
    lam = np.maximum(lam, 0)
    
    # Check dual feasibility
    # Compute C @ b where b = M^{-1} @ 1 (approximately)
    # Actually, b is determined by the KKT: C @ b <= 1, b >= 0, C^T @ lam = 1
    # If all b_i > 0, then C^T @ lam = 1 exactly, and b is determined by C @ b = 1 (for active constraints)
    # b = C_active^{-1} @ 1 (if C_active is square and invertible)
    
    # C_active: n_active x n matrix
    C_act = np.zeros((n_active, n))
    for idx, k in enumerate(active_lags):
        for j in range(max(0, k-n+1), min(n, k+1)):
            C_act[idx, j] = a[k-j]
    
    # We need to find b such that C_act @ b = 1 and b >= 0
    # This is n_active equations in n unknowns (underdetermined if n_active < n, overdetermined if n_active > n)
    
    # Use the dual: lam is determined by C^T @ lam = 1 (n equations, n_active unknowns)
    # And b is determined by C @ b = 1 for active constraints, b >= 0 for all
    
    # If n_active = n: square system
    if n_active == n:
        b, res, rank, sv = np.linalg.lstsq(C_act, np.ones(n_active), rcond=None)
        b = np.maximum(b, 0)
        s = b.sum()
        if s > 1e-15:
            return b / s, 1.0 / s
    else:
        # Use least squares
        b, res, rank, sv = np.linalg.lstsq(C_act, np.ones(n_active), rcond=None)
        b = np.maximum(b, 0)
        s = b.sum()
        if s > 1e-15:
            return b / s, 1.0 / s
    
    return None, None
```

```python
def line_search_fp(a, b, conv_aa, conv_ab, conv_bb):
    """Find best t in [0,1] to minimize max(conv(a_t, a_t)) where a_t = (1-t)*a + t*b."""
    best_t = 0.0
    best_max = conv_aa.max()
    
    for t in np.linspace(0.05, 1.0, 20):
        conv_at = (1-t)**2 * conv_aa + 2*t*(1-t) * conv_ab + t**2 * conv_bb
        mx = conv_at.max()
        if mx < best_max:
            best_max = mx
            best_t = t
    
    # Refine with golden section
    if best_t > 0:
        lo = max(0, best_t - 0.05)
        hi = min(1, best_t + 0.05)
        # Golden section search
        gr = (np.sqrt(5) - 1) / 2
        c = hi - gr * (hi - lo)
        d = lo + gr * (hi - lo)
        fc = ((1-c)**2 * conv_aa + 2*c*(1-c)*conv_ab + c**2*conv_bb).max()
        fd = ((1-d)**2 * conv_aa + 2*d*(1-d)*conv_ab + d**2*conv_bb).max()
        for _ in range(20):
            if fc <= fd:
                hi = d; d = c; fd = fc
                c = hi - gr*(hi-lo)
                fc = ((1-c)**2*conv_aa + 2*c*(1-c)*conv_ab + c**2*conv_bb).max()
            else:
                lo = c; c = d; fc = fd
                d = lo + gr*(hi-lo)
                fd = ((1-d)**2*conv_aa + 2*d*(1-d)*conv_ab + d**2*conv_bb).max()
        best_t = (lo+hi)/2
    
    return best_t
```

    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def cross_convolve(a, b):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    B = rfft(b, fft_size)
    return irfft(A * B, fft_size)[:size]


def compute_score(a):
    n = len(a)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    conv = fast_convolve(a)
    return float(2.0 * n * conv.max() / (s * s))


def build_conv_matrix(a):
    n = len(a)
    C = np.zeros((2 * n - 1, n))
    for j in range(n):
        C[j:j + n, j] = a
    return C


def build_subsampled_conv_matrix(a, n_active):
    n = len(a)
    conv_aa = fast_convolve(a)
    total_lags = 2 * n - 1
    if n_active >= total_lags:
        return build_conv_matrix(a), None
    active_lags = np.argpartition(conv_aa, -n_active)[-n_active:]
    C = np.zeros((n_active, n))
    for idx, k in enumerate(active_lags):
        k = int(k)
        j_start = max(0, k - n + 1)
        j_end = min(n, k + 1)
        C[idx, j_start:j_end] = a[k - j_start:k - j_end + 1]
    return C, active_lags
