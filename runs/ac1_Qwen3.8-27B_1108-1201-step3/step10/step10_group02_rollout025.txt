```python
            _, grad = lse_obj_grad_z(z_inner, T)
            return grad

            res = minimize(fun=func, x0=z, jac=jac, method='L-BFGS-B',
                          options={'maxiter': maxiter, 'ftol': 1e-15,
                                   'gtol': 1e-12, 'maxfun': maxiter * 200,
                                   'disp': False})
            z = res.x
        except Exception as e:
            print(f"  L-BFGS error at T={T}: {e}")
            break
    
    return softmax(z)
```

Wait, I realize there's a subtlety. The LSE objective `F_T(a) = (1/T) * log(sum exp(T*b_k))` is always >= max(b_k), with equality as T → ∞. So minimizing F_T gives an upper bound on the true objective. As T increases, the upper bound tightens.

But actually, we want to MINIMIZE max(b_k), and F_T >= max(b_k). So minimizing F_T gives a sequence where max(b_k) <= F_T(a). The gap F_T(a) - max(b_k) → 0 as T → ∞.

So the strategy is: minimize F_T for increasing T, and the final sequence should have max(b_k) close to the minimum of F_T at large T.

Let me also think about whether the L-BFGS will converge well. The issue is that at large T, the LSE function is almost non-differentiable (it approaches the max function), and the gradient becomes very sparse (only the peak lag contributes). In this regime, L-BFGS might struggle.

An alternative for the final refinement is to use the "active set" approach: identify the peak lags and use a subgradient method (like mirror descent) on just those.
