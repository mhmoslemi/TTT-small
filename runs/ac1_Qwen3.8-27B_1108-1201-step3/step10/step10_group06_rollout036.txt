The objective g_τ(a) = τ * logsumexp(conv(a,a)/τ) is convex in a (since conv(a,a) is a quadratic form with PSD matrix, and logsumexp is convex and monotone). Wait, is conv(a,a) convex in a?

Wait, but c[k] = sum_i a[i]*a[k-i]. Is this a quadratic form with a PSD matrix?

c[k] = sum_{i,j: i+j=k} a[i]*a[j]. The matrix for this quadratic form has entries M[i,j] = 1/2 (δ_{i+j,k} + δ_{j+i,k}) = δ_{i+j,k} (since it's symmetric). So M is a symmetric matrix with M[i,j] = 1 if i+j=k, else 0. This is a permutation matrix (for a given k), which has eigenvalues ±1. So it's NOT PSD!

So c[k] is NOT convex in a. The overall objective max_k c[k] is not convex either.

Actually wait, let me reconsider. c[k] = sum_{i+j=k} a[i]*a[j]. If we write this as a quadratic form: a^T M a where M[i,j] = 1/2 * δ_{i+j,k} (the factor of 1/2 is to handle the symmetric case i=j). Actually:

We want this to equal c[k] = sum_{i+j=k} a[i] a[j].

The eigenvalues of M: M is a symmetric matrix. For k=n-1 (the center), M[i,j] = 1 if i+j=n-1, which means M is the "anti-identity" matrix (ones on the anti-diagonal). The eigenvalues of the anti-identity matrix are ±1. So M is indefinite.

This means the overall problem is non-convex, and we need to be careful with optimization.

However, the smoothed logsumexp objective is still a reasonable target, and gradient methods with appropriate step-sizes and restarts should work well.

Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:

3. Exact coordinate descent for polishing

import numpy as np
from scipy.fft import rfft, irfft
import time

def fast_convolve(a):
    """Compute full linear convolution a*a using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]

def compute_score(a):
    """Compute the objective value 2*n*max(conv)/(sum)^2."""
    n = len(a)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    conv = fast_convolve(a)
    return 2.0 * n * float(conv.max()) / (s * s)

def simplex_project(v):
    """Project v onto the probability simplex (non-negative, sum=1)."""
    n = len(v)
    if n == 1:
        return np.ones(1)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if cond.any():
        rho = np.nonzero(cond)[0][-1]
        theta = (cssv[rho] - 1.0) / (rho + 1.0)
        return np.maximum(v - theta, 0.0)
    return np.ones(n) / n

def compute_gradient_smoothing(a, p):
    """
    Compute grad[i] = 2 * sum_k p[k] * a[k-i] for valid k-i.
    Uses FFT for efficiency.
    """
    n = len(a)
    a_rev = a[::-1]
    # H[i] = (conv(p, a_rev))[n-1+i]
    total_len = len(p) + n - 1
    N = 1 << (total_len - 1).bit_length()
    P = rfft(p, N)
    Ar = rfft(a_rev, N)
    conv_pa = irfft(P * Ar, N)
    H = conv_pa[n-1 : n-1+n]
    return 2.0 * H

def smoothed_grad_descent(a0, time_limit, tau_init=None, verbose=False, label=""):
    """
    Gradient descent on the smoothed objective tau*logsumexp(conv/tau).
    Uses projected gradient with adaptive step size.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    conv = fast_convolve(a)
    max_c = float(conv.max())
    best_score = 2.0 * n * max_c
    best_a = a.copy()
    
    if tau_init is None:
        tau = max_c / 10.0
    else:
        tau = tau_init
    
    lr = 1.0
    t0 = time.monotonic()
    iters = 0
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        iters += 1
        conv = fast_convolve(a)
        max_c = float(conv.max())
        
        # Compute softmax probabilities (numerically stable)
        shifted = (conv - max_c) / tau
        # Clip to avoid underflow
        shifted = np.maximum(shifted, -50.0)
        p = np.exp(shifted)
        p_sum = p.sum()
        if p_sum < 1e-300:
            p = np.zeros(len(conv))
            p[np.argmax(conv)] = 1.0
        else:
            p = p / p_sum
        
        # Compute gradient
        grad = compute_gradient_smoothing(a, p)

            grad_proj[support] -= grad[support].mean()
        else:

            # Increase step size slightly

        else:
            no_improve += 1
            lr *= 0.8
            # Still update a for exploration

            if tau < max_c * 0.001:
