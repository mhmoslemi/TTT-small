**Coordinate descent details:**

Given a with sum(a) = 1, compute conv = a * a (full convolution, 2n-1 elements).

For coordinate i, I want to find x >= 0 that minimizes:
F(x) = max_k [(a*a_new)[k]]

where a_new is a with a_i = x, re-normalized so sum = 1.

Let S = 1 - a_i + x (new sum before normalization).
After normalization: a_new_j = a_j / S for j != i, a_new_i = x / S.

(a_new * a_new)[k] = (1/S²) * [conv[k] - delta_i[k]]

where delta_i[k] is the change in the unnormalized convolution when we replace a_i with x:
- If 0 <= k-i < n and k != 2i: delta_i[k] = 2*(x - a_i)*a_{k-i} → new value = conv[k] + 2*(x-a_i)*a_{k-i}
  Wait, I need to be careful. The convolution conv[k] was computed with the OLD a_i. When I change a_i to x:
  
  (a_new_unnorm * a_new_unnorm)[k] where a_new_unnorm has x at position i and old values elsewhere:
  = conv[k] - (old contribution of a_i) + (new contribution of x)
  
  Old contribution of a_i to conv[k]:
  - If 0 <= k-i < n: a_i * a_{k-i} + (if k-i != i) a_{k-i} * a_i = a_i * a_{k-i} * (1 + [k != 2i])
    Actually: if k-i is in [0,n-1] and k-i != i: two terms a_i*a_{k-i} and a_{k-i}*a_i = 2*a_i*a_{k-i}
    If k-i = i (k = 2i): one term a_i * a_i = a_i²
    If k-i not in [0,n-1]: zero
  
  New contribution of x:
  - If 0 <= k-i < n and k-i != i: 2*x*a_{k-i}
  - If k = 2i: x²
  - Otherwise: 0

So:
(a_new_unnorm * a_new_unnorm)[k] = conv[k] + new_contrib[k] - old_contrib[k]

where:
- If 0 <= k-i < n and k != 2i: new - old = 2*x*a_{k-i} - 2*a_i*a_{k-i} = 2*(x-a_i)*a_{k-i}
- If k = 2i: new - old = x² - a_i²
- Otherwise: 0

And the normalized value:
(a_new * a_new)[k] = [conv[k] + delta[k]] / S²

where S = 1 - a_i + x and delta[k] is as above.

So F(x) = max_k [conv[k] + delta[k]] / (1 - a_i + x)²

This is a 1D function of x >= 0. Let me analyze its properties:
- For k where delta[k] = 0: value = conv[k] / (1-a_i+x)², which is decreasing in x (since denominator increases)
- For k where delta[k] = 2*(x-a_i)*a_{k-i}: value = [conv[k] + 2*(x-a_i)*a_{k-i}] / (1-a_i+x)²
  This is a rational function. Its derivative can change sign.
- For k = 2i: value = [conv[2i] + x² - a_i²] / (1-a_i+x)²

The function F(x) is the max of these, so it's the max of a set of functions, each of which is... let's check if they're convex.

For the "no delta" case: f(x) = c / (d+x)² where d = 1-a_i > 0. This is convex in x (second derivative positive).

For the "linear delta" case: f(x) = [c + 2*(x-a_i)*a_{k-i}] / (d+x)²
= [2*a_{k-i}*x + (c - 2*a_i*a_{k-i})] / (d+x)²

Let's call this (mx + b) / (d+x)² where m = 2*a_{k-i}, b = c - 2*a_i*a_{k-i}, d = 1-a_i.

The first derivative: d/dx [(mx+b)/(d+x)²] = [m(d+x)² - (mx+b)*2(d+x)] / (d+x)⁴
= [m(d+x) - 2(mx+b)] / (d+x)³
= [md + mx - 2mx - 2b] / (d+x)³
= [md - mx - 2b] / (d+x)³

Setting to 0: md - mx - 2b = 0 → x = (md - 2b) / m = d - 2b/m

Second derivative (to check convexity): it's more complex, but the function might not be convex everywhere.

For the "quadratic delta" case (k=2i): f(x) = [c + x² - a_i²] / (d+x)² where c = conv[2i]
= [(x²-a_i²+c)/(d+x)²]

This is also a rational function that may not be convex.

So F(x) is the max of potentially non-convex functions. This means ternary search might not work reliably. However, in practice, the function is likely to be "mostly" convex (unimodal) over the range of interest.

A safer approach: **golden section search** on [0, x_max] with x_max = some reasonable upper bound (like 5 * max(a) or 2 * a_i). If the function is unimodal, golden section will find the minimum.

import numpy as np
import cvxpy as cp
import time
from scipy.fft import rfft, irfft


def fast_autocorr(a):
    """Full convolution a*a using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    conv = irfft(A * A, fft_size)[:size]
    conv = np.maximum(conv, 0.0)
    return conv


def evaluate_safe(a):
    """Safely evaluate using the provided evaluate_sequence."""
    try:
        a_list = [float(max(0.0, min(1000.0, x))) for x in a]
        sc = evaluate_sequence(a_list)
        return float(sc)
    except Exception:
        return float('inf')


def softmax_fn(z):
    """Numerically stable softmax."""
    z = z - z.max()
    e = np.exp(z)
    s = e.sum()
    if s < 1e-300:
        return np.ones(len(z)) / len(z)
    return e / s


def simplex_project(v):
    """Project v onto the probability simplex {x: sum(x)=1, x>=0}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)


def get_lp_solver():
    """Find a working LP solver."""
    for solver_name in [cp.ECOS, cp.SCS, cp.PDLP, cp.CLARABEL, cp.MOSEK, cp.GLPK]:
        try:
            x = cp.Variable(5, nonneg=True)
            prob = cp.Problem(cp.Minimize(cp.sum(x)), [cp.sum(x) == 1, x <= 0.5])
            prob.solve(solver=solver_name)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                return solver_name
        except Exception:
            continue
    return cp.ECOS


def build_conv_matrix(a_fixed):
    """Build (2n-1) x n matrix T where T@b = convolve(a_fixed, b)."""
    n = len(a_fixed)
    size = 2 * n - 1
    T = np.zeros((size, n))
    for j in range(n):
        T[j:j + n, j] = a_fixed
    return T


def solve_lp_best_response(a_fixed, solver):
    """Solve LP: min M s.t. conv(a_fixed, b) <= M, sum(b)=1, b>=0."""
    n = len(a_fixed)
    b_var = cp.Variable(n, nonneg=True)
    M_var = cp.Variable()
    T = build_conv_matrix(a_fixed)
    constraints = [T @ b_var <= M_var, cp.sum(b_var) == 1]
    prob = cp.Problem(cp.Minimize(M_var), constraints)
    try:
        prob.solve(solver=solver)
    except Exception:
        pass
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        for alt in [cp.ECOS, cp.SCS, cp.PDLP, cp.CLARABEL, cp.MOSEK, cp.GLPK]:
            if alt == solver:
                continue
            try:
                prob.solve(solver=alt)
                if prob.status in ('optimal', 'optimal_inaccurate'):
                    break
            except Exception:
                continue
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None, None
    b_val = np.asarray(b_var.value, dtype=np.float64)
    b_val = np.maximum(b_val, 0)
    s = b_val.sum()
    if s < 1e-15:
        return None, None
    b_val = b_val / s
    return b_val, float(M_var.value)

    y = a.copy()

    t0 = time.monotonic()

    med_buf = [None] * WINDOW_MED
    med_idx = 0

    stall_count = 0
    no_lp = 0

    for t in range(1, max_iters + 1):

            break

        if b_star is None:
            no_lp += 1
            if no_lp > 50:
                break
            continue
        no_lp = 0

        alpha_t = 2.0 / (t + 2.0)
        y_new = (1 - alpha_t) * y + alpha_t * b_star
        y_new = np.maximum(y_new, 0)
        y_sum = y_new.sum()
        if y_sum < 1e-15:
            y_new = b_star.copy()
        else:

        else:

        # Update running averages

        n_long += 1
        avg_med += a
        n_med += 1

        if med_buf[med_idx] is not None:
            avg_med -= med_buf[med_idx]

        med_idx = (med_idx + 1) % WINDOW_MED

        # Check multiple candidates

            if score_a < best_score:

def coord_descent(a0, time_limit, max_sweeps=50000):
    """
    Coordinate descent: for each coordinate, find the optimal value
    using golden section search on the 1D objective.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        return a0, float('inf')
    a = a / s

    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(12345)

    sweep = 0
    stall = 0

    while time.monotonic() - t0 < time_limit - 3 and sweep < max_sweeps:
        sweep += 1
        conv = fast_autocorr(a)
        improved_this_sweep = False
        max_per_sweep = n if (time_limit - (time.monotonic() - t0)) > 30 else int(n * (time_limit - (time.monotonic() - t0)) / 30 * 0.5)

        # Randomize coordinate order to avoid cyclical behavior
        order = np.arange(n)
        if sweep % 3 == 0:
            rng.shuffle(order)

        for i in order[:max_per_sweep]:
            if time.monotonic() - t0 > time_limit - 3:
                break

            ai_old = a[i]
            if ai_old < 1e-15 and conv[i + i] < best_score * 0.99:
                continue  # Skip very small coordinates that aren't critical

            # Golden section search on x in [0, x_max]
            x_max = max(5.0 * ai_old, 0.05)
            if ai_old < 1e-10:
                x_max = 0.05

            # Define objective function for coordinate i
            def obj_1d(x):
                """Compute max autocorrelation when a[i] = x (with renormalization)."""
                S = 1.0 - ai_old + x
                if S < 1e-15:
                    return 1e10
                # Modified convolution values
                # For k where 0 <= k-i < n and k != 2i: conv[k] + 2*(x-ai_old)*a[k-i]
                # For k = 2i: conv[2i] + x^2 - ai_old^2
                # For other k: conv[k]
                # All divided by S^2
                new_conv = conv.copy()
                k_min = max(0, 0)  # k-i >= 0 means k >= i
                k_max = min(2 * n - 2, i + n - 1)  # k-i < n means k < i+n
                if k_min <= k_max:
                    krange = np.arange(k_min, k_max + 1)
                    relevant = krange - i  # = k - i, range [0, n-1]
                    mask = (krange != 2 * i)
                    if mask.any():
                        new_conv[krange[mask]] += 2.0 * (x - ai_old) * a[relevant[mask]]
                if 2 * i < 2 * n - 1:
                    new_conv[2 * i] += x * x - ai_old * ai_old
                new_conv = new_conv / (S * S)
                new_conv = np.maximum(new_conv, 0)
                return new_conv.max()

            # Golden section search
            gr = (np.sqrt(5.0) - 1.0) / 2.0  # golden ratio ~0.618
            lo = 0.0
            hi = x_max
            c = hi - gr * (hi - lo)
            d = lo + gr * (hi - lo)
            fc = obj_1d(c)
            fd = obj_1d(d)

            for _ in range(30):
                if fc < fd:
                    hi = d
                    d = c
                    fd = fc
                    c = hi - gr * (hi - lo)
                    fc = obj_1d(c)
                else:
                    lo = c
                    c = d
                    fc = fd
                    d = lo + gr * (hi - lo)
                    fd = obj_1d(d)

            x_opt = (lo + hi) / 2.0
            # Also check endpoints
            f_lo = obj_1d(0.0)
            f_him = obj_1d(x_max)
            f_opt = obj_1d(x_opt)

            candidates = [(0.0, f_lo), (x_opt, f_opt), (x_max, f_him), (ai_old, conv.max())]
            best_x = min(candidates, key=lambda t: t[1])[0]

            if best_x >= 0 and f_opt < best_score * (1 - 1e-12):
                a[i] = best_x
                S = a.sum()
                if S > 1e-15:
                    a = a / S
                    new_score = 2.0 * n * fast_autocorr(a).max()
                    if new_score < best_score:
                        best_score = new_score
                        best_a = a.copy()
                        improved_this_sweep = True
                        stall = 0
            elif best_x >= 0:
                # Still update a to the best found (even if not improving global score)
                # This helps with local adjustments
                a[i] = best_x
                S = a.sum()
                if S > 1e-15:
                    a = a / S

        if not improved_this_sweep:
            stall += 1
            # Try a random perturbation to escape
            if stall > 20:
                n_pert = rng.integers(2, 6)
                a_trial = a.copy()
                for _ in range(n_pert):
                    i1 = rng.integers(n)
                    i2 = rng.integers(n)
                    if i1 != i2:
                        frac = rng.uniform(0.005, 0.05)
                        amt = a_trial[i1] * frac
                        a_trial[i1] -= amt
                        a_trial[i2] += amt
                a_trial = np.maximum(a_trial, 0)
                st = a_trial.sum()
                if st > 1e-10:
                    a_trial = a_trial / st
                    score_p = 2.0 * n * fast_autocorr(a_trial).max()
                    if score_p < best_score:
                        a = a_trial
                        best_score = score_p
                        best_a = a.copy()
                        stall = 0
                    elif rng.random() < 0.3:
                        a = a_trial
                stall = 0

            if stall > 50:
                break

        if sweep % 100 == 0:
            elapsed = time.monotonic() - t0
            print(f"      CD sweep {sweep} ({elapsed:.0f}s): best={best_score:.7f}")

    return best_a, best_score


def lse_grad_descent(a0, time_limit, T_start=150.0, T_end=0.5, n_stages=20, topk=15):
    """
    Multi-stage LogSumExp gradient descent with Adam.
    """
    n = len(a0)
    a_init = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a_init.sum()
    if s < 1e-15:
        a_init = np.ones(n) / n
    else:
        a_init = a_init / s

    z = np.log(np.maximum(a_init, 1e-30))
    t0 = time.monotonic()

    best_a = a_init.copy()
    best_score = 2.0 * n * fast_autocorr(a_init).max()

    temps = np.geomspace(T_start, T_end, n_stages)

    for si, stage_T in enumerate(temps):
        if time.monotonic() - t0 > time_limit - 5:
            break
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 10:
            break

        base_lr = 3e-3 * min(1.0, 100.0 / n)
        lr = base_lr * (0.75 ** si)

        m_z = np.zeros(n)
        v_z = np.zeros(n)
        t_adam = 0
        beta1, beta2, eps = 0.8, 0.999, 1e-8

        max_it = max(20, int(min(remaining, 100.0) * 4))

        for it in range(max_it):
            if time.monotonic() - t0 > time_limit - 3:
                break

            a = softmax_fn(z)
            conv = fast_autocorr(a)
            k_use = min(topk, len(conv))
            top_idx = np.argsort(conv)[::-1][:k_use]
            top_vals = conv[top_idx]

            Tc = stage_T * top_vals
            max_Tc = Tc.max()
            exp_Tc = np.exp(Tc - max_Tc)
            w = exp_Tc / exp_Tc.sum()

            # Gradient: grad_a[i] = 2 * sum_K w_K * a[K-i] for valid K-i
            grad_a = np.zeros(n)
            for idx in range(k_use):
                K = top_idx[idx]
                wK = w[idx]
                js = max(0, K - (n - 1))
                je = min(n - 1, K)
                if js <= je:
                    idx_range = np.arange(js, je + 1)
                    grad_a[idx_range] += 2.0 * wK * a[K - idx_range]

            S = np.dot(grad_a, a)
            grad_z = a * (grad_a - S)

            t_adam += 1
            m_z = beta1 * m_z + (1 - beta1) * grad_z
            v_z = beta2 * v_z + (1 - beta2) * grad_z ** 2
            m_hat = m_z / (1 - beta1 ** t_adam)
            v_hat = v_z / (1 - beta2 ** t_adam)
            z = z - lr * m_hat / (np.sqrt(v_hat) + eps)

            if (it + 1) % 10 == 0:
                a = softmax_fn(z)
                score = 2.0 * n * fast_autocorr(a).max()
                if score < best_score:
                    best_score = score
                    best_a = a.copy()

        a_stage = softmax_fn(z)
        score_stage = 2.0 * n * fast_autocorr(a_stage).max()
        if score_stage < best_score:
            best_score = score_stage
            best_a = a_stage.copy()

    return best_a, best_score


def peak_shaving(a0, time_limit, seed=42):
    """
    Multi-scale peak shaving: target the top peaks and move mass to reduce them.
    """
    n = len(a0)
    rng = np.random.default_rng(seed)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        return a0, float('inf')
    a = a / s
    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()
    stall = 0

    while time.monotonic() - t0 < time_limit - 3 and stall < 200:
        conv = fast_autocorr(a)
        bmax = conv.max()
        threshold = bmax * 0.997
        top_peaks = np.where(conv >= threshold)[0]
        if len(top_peaks) == 0:
            top_peaks = np.argsort(conv)[::-1][:10]
        top_peaks = top_peaks[:15]

        improved = False
        for k in top_peaks:
            if time.monotonic() - t0 > time_limit - 3:
                break

            js = max(0, k - (n - 1))
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            if len(idx) == 0:
                continue
            contrib = a[idx] * a[k - idx]
            max_contrib = contrib.max()
            if max_contrib < 1e-15:
                continue

            src = idx[np.argmax(contrib)]

            # Danger zone: positions that affect any top peak
            danger = np.zeros(n, dtype=bool)
            for k2 in top_peaks:
                js2 = max(0, k2 - (n - 1))
                je2 = min(n - 1, k2)
                danger[js2:je2 + 1] = True

            safe = np.where(~danger)[0]
            safe = safe[safe != src]
            if len(safe) == 0:
                safe = np.where(np.arange(n) != src)[0]

            safe_sorted = safe[np.argsort(a[safe])]
            dst_pool = safe_sorted[:max(5, len(safe_sorted) // 4)]
            if len(dst_pool) == 0:
                continue

            # Try multiple destinations and step sizes
            best_trial = None
            best_trial_score = best_score
            for dst in dst_pool[:5]:
                for frac in [0.002, 0.005, 0.01, 0.02, 0.04, 0.07]:
                    amt = a[src] * frac
                    if amt < 1e-15:
                        continue
                    a_trial = a.copy()
                    a_trial[src] -= amt
                    a_trial[dst] += amt
                    if a_trial[src] < 0:
                        continue
                    a_trial = a_trial / a_trial.sum()
                    score = 2.0 * n * fast_autocorr(a_trial).max()
                    if score < best_trial_score:
                        best_trial_score = score
                        best_trial = a_trial

            if best_trial is not None and best_trial_score < best_score - 1e-14:
                a = best_trial
                best_score = best_trial_score
                best_a = a.copy()
                improved = True
                stall = 0
                break

        if not improved:
            stall += 1
            # Random small perturbation
            n_pert = rng.integers(1, 4)
            a_trial = a.copy()
            for _ in range(n_pert):
                i = rng.integers(n)
                j = rng.integers(n)
                if i != j and a_trial[i] > 1e-10:
                    frac = rng.uniform(0.001, 0.03)
                    amt = a_trial[i] * frac
                    a_trial[i] -= amt
                    a_trial[j] += amt
            a_trial = np.maximum(a_trial, 0)
            st = a_trial.sum()
            if st > 1e-10:
                a_trial = a_trial / st
                score = 2.0 * n * fast_autocorr(a_trial).max()
                if score < best_score:
                    a = a_trial
                    best_score = score
                    best_a = a.copy()
                    stall = 0

    return best_a, best_score


def interpolate_sequence(f, new_n):
    """Interpolate a normalized sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp


def propose_candidate(seed=42, time_budget=1800.0):
    """
    Multi-phase optimization combining LP Nesterov, coordinate descent,
    LSE gradient descent, and peak shaving for final polish.
    """
    rng = np.random.default_rng(seed)
    t_start = time.monotonic()
    time_budget = min(float(time_budget) - 60.0, 1740.0)

    solver = get_lp_solver()
    print(f"Using LP solver: {solver}")
    print(f"Time budget: {time_budget:.0f}s")

    # Get parent sequence
    best_seq = None
    best_score = float('inf')
    parent = None

    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            parent = p / p.sum()
            p_score = evaluate_safe(parent)
            print(f"Parent: n={len(parent)}, score={p_score:.7f}")
            best_seq = parent.copy()
            best_score = p_score
    except Exception:
        pass

    def try_update(a, label):
        nonlocal best_seq, best_score
        if a is None:
            return
        a = np.maximum(np.asarray(a, dtype=np.float64), 0)
        s = a.sum()
        if s < 0.01:
            return
        a = a / s
        sc = evaluate_safe(a)
        if np.isfinite(sc) and sc < best_score:
            best_score = sc
            best_seq = a.copy()
            elapsed = time.monotonic() - t_start
            print(f"  *** NEW BEST [{label}]: {sc:.7f} (n={len(a)}, t={elapsed:.0f}s)")

    n_base = len(best_seq) if best_seq is not None else 1600

    if parent is None:
        n_base = 1600
        x = np.linspace(0, 1, n_base)
        best_seq = 0.5 + 0.3 * np.cos(np.pi * x) + 0.2 * np.cos(2 * np.pi * x)
        best_seq = np.maximum(best_seq, 0)
        best_seq = best_seq / best_seq.sum()
        best_score = evaluate_safe(best_seq)
        print(f"Default init: n={n_base}, score={best_score:.7f}")

    # === Phase 1: LP Nesterov at base length ===
    remaining = time_budget - (time.monotonic() - t_start)
    print(f"\n=== Phase 1: LP Nesterov n={n_base} ({remaining:.0f}s left) ===")
    t1 = min(remaining * 0.35, 600.0)
    if t1 > 50:
        a_out, _ = nesterov_lp_optimize(best_seq, t1, solver)
        try_update(a_out, f"lp_n{n_base}")

    # === Phase 2: Coordinate descent at base length ===
    remaining = time_budget - (time.monotonic() - t_start)
    print(f"\n=== Phase 2: Coord Descent n={n_base} ({remaining:.0f}s left) ===")
    t2 = min(remaining * 0.20, 300.0)
    if t2 > 30:
        a_out, _ = coord_descent(best_seq, t2)
        try_update(a_out, f"cd_n{n_base}")

    # === Phase 3: LSE gradient descent ===
    remaining = time_budget - (time.monotonic() - t_start)
    print(f"\n=== Phase 3: LSE GD n={n_base} ({remaining:.0f}s left) ===")
    t3 = min(remaining * 0.12, 150.0)
    if t3 > 20:
        a_out, _ = lse_grad_descent(best_seq, t3, T_start=100.0, T_end=0.5, n_stages=15, topk=12)
        try_update(a_out, f"lse_n{n_base}")

    # === Phase 4: LP Nesterov at slightly longer length ===
    remaining = time_budget - (time.monotonic() - t_start)
    if remaining > 100:
        n_long = n_base + 200
        print(f"\n=== Phase 4: LP Nesterov n={n_long} ({remaining:.0f}s left) ===")
        t4 = min(remaining * 0.25, 350.0)
        if t4 > 50:
            init_long = interpolate_sequence(best_seq, n_long)
            a_out, _ = nesterov_lp_optimize(init_long, t4, solver)
            try_update(a_out, f"lp_n{n_long}")

    # === Phase 5: Coordinate descent on best so far ===
    remaining = time_budget - (time.monotonic() - t_start)
    if remaining > 30:
        print(f"\n=== Phase 5: Coord Descent polish ({remaining:.0f}s left) ===")
        t5 = min(remaining * 0.20, 200.0)
        if t5 > 20:
            a_out, _ = coord_descent(best_seq, t5)
            try_update(a_out, "cd_polish")

    # === Phase 6: Peak shaving ===
    remaining = time_budget - (time.monotonic() - t_start)
    if remaining > 20:
        print(f"\n=== Phase 6: Peak shaving ({remaining:.0f}s left) ===")
        t6 = min(remaining * 0.15, 100.0)
        if t6 > 10:
            a_out, _ = peak_shaving(best_seq, t6, seed=789)
            try_update(a_out, "peak_shave")

    # === Phase 7: Final LSE polish ===
    remaining = time_budget - (time.monotonic() - t_start)
    if remaining > 15:
        t7 = min(remaining * 0.25, 80.0)
        if t7 > 10:
            print(f"\n=== Phase 7: Final LSE ({remaining:.0f}s left) ===")
            a_out, _ = lse_grad_descent(best_seq, t7, T_start=5.0, T_end=0.1, n_stages=8, topk=6)
            try_update(a_out, "final_lse")

    # === Phase 8: Final peak shave ===
    remaining = time_budget - (time.monotonic() - t_start)
    if remaining > 10:
        t8 = min(remaining * 0.5, 40.0)
        if t8 > 5:
            print(f"\n=== Phase 8: Final peak shave ({remaining:.0f}s left) ===")
            a_out, _ = peak_shaving(best_seq, t8, seed=101)
            try_update(a_out, "final_shave")

    # Final verification
    if best_seq is not None:
        fs = evaluate_safe(best_seq)
        if np.isfinite(fs):
            best_score = fs
        print(f"\nFINAL SCORE: {best_score:.7f} (n={len(best_seq)})")
    else:
        print("\nERROR: No valid sequence found!")
        return [1.0]

    return [float(x) for x in best_seq]
