Let me also think about the "plateau shaving" technique more carefully. If the first n values of the convolution are all equal to some value V, and the last n-1 values are less than V, then:
- The max is V, achieved at positions 0 through n-1.
- To reduce V, we need to find a perturbation d such that d(conv[k])/da · d < 0 for all k = 0, ..., n-1.

This is equivalent to finding a direction d in the null space of the constraint sum(d) = 0, a + d >= 0, such that the maximum of {d(conv[k])/da · d : k = 0, ..., n-1} is negative.

We can formulate this as an LP:
find d
minimize t
subject to: d(conv[k])/da · d <= t for all k = 0, ..., n-1
           sum(d) = 0
           a[i] + d[i] >= 0 for all i

If the optimal t < 0, we can take a step in the direction d.
