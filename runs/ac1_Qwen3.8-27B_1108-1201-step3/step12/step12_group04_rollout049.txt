One more idea: **use the power method / iterative projection**.

The best response LP can be seen as: find b in the simplex that minimizes max_k (T@b)[k]. This is equivalent to: find b in the simplex such that T@b is as "uniform" as possible (minimax).

An iterative algorithm:
1. Start with b = uniform
2. Compute c = T@b (cross-convolution)
3. Let M = max(c), S = {k: c[k] = M}
4. Compute g_i = (1/|S|) * sum_{k in S} T[k,i] (average of the active rows)
5. Update: b = proj_simplex(b - eta * g)
6. Repeat

This is the subgradient method for the LP. With a good step size, it converges. The advantage is that it's very fast per iteration (O(n) for the update, O(n log n) for the cross-convolution).
