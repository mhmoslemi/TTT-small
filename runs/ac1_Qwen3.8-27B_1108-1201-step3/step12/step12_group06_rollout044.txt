Let me check: `conv_k(a) = sum_j a[j] * a[k-j]`. This is a quadratic form `a^T Q_k a` where `Q_k` is a symmetric matrix. The max of quadratic forms is convex if all `Q_k` are positive semidefinite. Is `Q_k` PSD?

`(Q_k a)[i] = sum_j Q_k[i,j] * a[j]`. We have `conv_k = a^T Q_k a`. For this to be a proper quadratic form, `Q_k` should be such that `a^T Q_k a = sum_j a[j] * a[k-j]`.

Actually, `a^T Q_k a = sum_{i,j} a[i] Q_k[i,j] a[j]`. We want this to equal `sum_j a[j] * a[k-j]`. So `Q_k[i,j] = 1/2` if `i+j = k` or `j+i = k` (to make it symmetric), and 0 otherwise.

For example, if `k = n-1` (center), `Q_k[i,j] = 1/2` if `i+j = n-1`. This is a "reverse identity" matrix, which has eigenvalues ±1 (for the symmetric and antisymmetric parts). So it's NOT PSD.

Therefore, `conv_k(a)` is not a convex function of `a` (it's an indefinite quadratic form), and the problem is non-convex.

However, if we restrict to the constraint `a ≥ 0`, the situation might be different. For `a ≥ 0`, `conv_k(a) = sum_j a[j]*a[k-j] ≥ 0`. But the function is still not convex in `a` in general.
