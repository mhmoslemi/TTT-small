Let me also add a key insight: **the "mirror" property**. If the peak is at lag k*, the gradient is 2*a[k*-m] (reversed and shifted). This means the update direction is always a "mirror image" of the sequence. So:

- If we update a -= eta * grad, we're pulling a toward "anti-mirror" of itself
- If a is already "anti-mirror" (a[m] = -a[k*-m]), the gradient is negative everywhere and we'd increase all elements (which doesn't make sense with the constraint)

The key is to work with the **normalized** gradient: subtract the mean to maintain the sum constraint, then update.

Let me also think about **second-order effects**. The Hessian of conv(a,a)[k] w.r.t. a is:
H[m,m'] = delta(m, k-m') + delta(m', k-m) (which is a permutation matrix, specifically the "anti-diagonal" at position k)

So the Hessian is rank 2n (actually it's a permutation matrix with some zeros), which means the function is quadratic (not just locally). This means Newton's method should converge in one step! But the constraint a >= 0 and the max over k make it non-trivial.

Actually, for a fixed k, conv(a,a)[k] is a quadratic form: a^T P_k a where P_k is the permutation matrix. So minimizing max_k a^T P_k a subject to a >= 0, sum(a) = S is a problem of minimizing the maximum of quadratic forms.

This can be approached by **bisection on M**:
- Is there a feasible a with a^T P_k a <= M for all k, a >= 0, sum(a) = S?
- This is a feasibility problem with quadratic constraints → can be solved as a SOCP (second-order cone program) or semidefinite program!

Specifically: a^T P_k a <= M can be written as ||P_k^{1/2} a||^2 <= M (since P_k is a permutation, P_k^{1/2} = P_k). So it's ||P_k a||^2 <= M, which is a second-order cone constraint!

So the problem is:
minimize M
subject to: ||P_k a|| <= sqrt(M) for k = 0, ..., 2n-2
            a >= 0
            sum(a) = S

This is a **Second-Order Cone Program (SOCP)**! We can solve it with interior point methods (cvxpy with ECOS, MOSEK, etc.).

But wait, there are 2n-1 constraints, each of dimension n. For n=256, that's 511 constraints of dimension 256. This might be too large for a standard SOCP solver.

1. Start with a subset of active constraints (e.g., just the current peak)
2. Solve the SOCP
3. Check if other constraints are violated
4. Add violated constraints
5. Repeat

This is the ** cutting plane / column generation** method for SOCP.

```python
"""
Fast gradient-based optimization for minimizing normalized peak autocorrelation.
Key innovations vs previous LP-based approach:
1. Analytical subgradient (O(n log n) per step vs O(n^3) for LP)
2. Multi-peak tracking to flatten top-K correlated peaks
3. Symmetry-breaking perturbations to escape palindromic local minima
4. Frequency-domain structural mutations for diversity
5. Adaptive step size with backtracking
6. Multi-start with diverse structural templates
"""

import numpy as np
import time

def fft_convolve(a, b):
    n, m = len(a), len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:n + m - 1]

def local_score(a):
    a = np.clip(a, 0.0, 1000.0)
    n = len(a)
    if n == 0:
        return np.inf
    sum_a = np.sum(a)
    if sum_a < 0.01:
        return np.inf
    c = fft_convolve(a, a)
    return float(2.0 * n * np.max(c) / (sum_a ** 2))

def subgrad_at_peak(a, k_peak):
    """Compute subgradient of conv(a,a)[k_peak] w.r.t. a, centered."""
    n = len(a)
    grad = np.zeros(n)
    lo = max(0, k_peak - n + 1)
    hi = min(n - 1, k_peak)
    if lo <= hi:
        indices = np.arange(k_peak - hi, k_peak - lo + 1)
        grad[lo:hi+1] = 2.0 * a[indices]
    grad -= np.mean(grad)
    return grad

def multi_peak_gradient(a, K=3):
    """Combined gradient from top-K peaks with exponential weighting."""
    n = len(a)
    c = fft_convolve(a, a)
    top_K = np.argsort(c)[::-1][:K]
    peak_vals = c[top_K]
    # Weights: exponential decay from max
    max_val = peak_vals[0]
    weights = np.exp(-2.0 * (max_val - peak_vals) / (max_val + 1e-10))
    weights /= np.sum(weights)
    
    grad = np.zeros(n)
    for i, k in enumerate(top_K):
        grad += weights[i] * subgrad_at_peak(a, k)
    return grad

def fast_gradient_optimize(a_init, time_limit, rng, K=3, verbose=False):
    """
    Fast gradient-based optimization with adaptive step size.
    Uses subgradient of the peak convolution value.
    """
    a = np.clip(a_init, 1e-8, None).astype(np.float64)
    n = len(a)
    S = np.sqrt(2.0 * n)
    a = a * (S / np.sum(a))
    
    best_a = a.copy()
    best_score = local_score(a)
    t0 = time.monotonic()
    eta = 0.15
    eta_min = 0.005
    stagnant = 0
    iter_count = 0
    last_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        # Compute gradient
        if K == 1:
            c = fft_convolve(a, a)
            k_peak = int(np.argmax(c))
            grad = subgrad_at_peak(a, k_peak)
        else:
            grad = multi_peak_gradient(a, K)
        
        # Step
        a_new = a - eta * grad
        a_new = np.clip(a_new, 1e-8, None)
        sum_new = np.sum(a_new)
        if sum_new < 1e-10:
            eta = max(eta_min, eta * 0.5)
            continue
        a_new = a_new * (S / sum_new)
        
        score = local_score(a_new)
        iter_count += 1
        
        if score < best_score - 1e-10:
            best_score = score
            best_a = a_new.copy()
            stagnant = 0
            last_improve = iter_count
            # Slightly increase step
            eta = min(0.3, eta * 1.02)
        else:
            stagnant += 1
            # Accept with probability based on improvement
            if stagnant < 30:
                a = a_new
            elif score < best_score + 0.01:
                a = a_new
                eta = max(eta_min, eta * 0.9)
            else:
                # Restart step size and perturb
                eta = 0.1
                a = a + 0.03 * rng.standard_normal(n)
                a = np.clip(a, 1e-8, None)
                a = a * (S / np.sum(a))
                stagnant = 0
        
        if verbose and iter_count % 500 == 0:
            elapsed = time.monotonic() - t0
            print(f"  Grad iter={iter_count}, score={local_score(a):.6f}, best={best_score:.6f}, eta={eta:.4f}, t={elapsed:.0f}s")
    
    return best_a, best_score

def freq_structural_mutate(a, rng):
    """Apply a structural mutation in the frequency domain."""
    n = len(a)
    A = np.fft.rfft(a)
    freqs = len(A)
    
    # Choose a random frequency band to modify
    band_width = max(1, freqs // 10)
    start = rng.integers(0, freqs - band_width)
    end = start + band_width
    
    # Option 1: Scale a frequency band
    if rng.random() < 0.4:
        scale = rng.uniform(0.5, 1.5)
        A[start:end] *= scale
    # Option 2: Phase shift a band
    elif rng.random() < 0.7:
        phase = rng.normal(0, 0.3, size=end-start)
        A[start:end] *= np.exp(1j * phase)
    # Option 3: Add a sinc bump (raises a specific frequency)
    else:
        f0 = rng.integers(1, freqs-1)
        amp = rng.uniform(0.01, 0.1) * np.std(np.abs(A))
        for f in range(max(1, f0-3), min(freqs-1, f0+3)):
            if f < freqs:
                A[f] += amp
    
    a_new = np.fft.irfft(A, n)
    return np.clip(a_new, 1e-8, None)

def sa_polish(a_init, time_limit, rng, K=3):
    """Simulated annealing with diverse move types including gradient steps."""
    a = np.clip(a_init, 1e-8, None).astype(np.float64)
    n = len(a)
    S = np.sqrt(2.0 * n)
    a = a * (S / np.sum(a))
    
    best_a = a.copy()
    best_score = local_score(a)
    current_score = best_score
    t0 = time.monotonic()
    temperature = 0.002
    cooling = 0.9998
    iter_count = 0
    
    while time.monotonic() - t0 < time_limit:
        candidate = a.copy()
        r = rng.random()
        
        if r < 0.3:
            # Gradient step (small)
            grad = multi_peak_gradient(candidate, K)
            eta = rng.uniform(0.02, 0.1)
            candidate -= eta * grad
        elif r < 0.5:
            # Peak-targeted: reduce elements contributing to peak
            c = fft_convolve(candidate, candidate)
            k_peak = int(np.argmax(c))
            # Elements contributing to peak at k_peak
            contrib = np.zeros(n)
            lo = max(0, k_peak - n + 1)
            hi = min(n - 1, k_peak)
            if lo <= hi:
                indices = np.arange(k_peak - hi, k_peak - lo + 1)
                contrib[lo:hi+1] = candidate[indices]
            # Reduce top contributors
            top_k = max(2, n // 10)
            top_idx = np.argsort(contrib)[-top_k:]
            candidate[top_idx] *= np.exp(rng.normal(-0.04, 0.01, top_k))
            # Increase others slightly
            other = np.setdiff1d(np.arange(n), top_idx)
            if len(other) > 0:
                n_inc = min(5, len(other))
                inc_idx = rng.choice(other, n_inc, replace=False)
                candidate[inc_idx] *= np.exp(rng.normal(0.03, 0.01, n_inc))
        elif r < 0.65:
            # Segment perturbation
            width = max(1, int(rng.integers(1, max(2, n // 8))))
            start = int(rng.integers(0, n - width))
            candidate[start:start+width] *= np.exp(rng.normal(0, 0.03, width))
        elif r < 0.8:
            # Frequency-domain mutation
            candidate = freq_structural_mutate(candidate, rng)
        elif r < 0.9:
            # Shift + noise
            shift = int(rng.integers(-3, 4))
            candidate = np.roll(candidate, shift)
            candidate += rng.normal(0, 0.005, n)
        else:
            # Global noise
            candidate += rng.normal(0, 0.008, n)
        
        candidate = np.clip(candidate, 1e-8, None)
        cand_sum = np.sum(candidate)
        if cand_sum < 1e-10:
            continue
        candidate = candidate * (S / cand_sum)
        
        new_score = local_score(candidate)
        iter_count += 1
        
        if new_score < current_score:
            a = candidate
            current_score = new_score
            if new_score < best_score:
                best_score = new_score
                best_a = candidate.copy()
        elif rng.random() < np.exp(-(new_score - current_score) / max(temperature, 1e-12)):
            a = candidate
```

```python
import numpy as np

def fft_convolve(a, b):
    """Linear convolution via FFT."""
    n, m = len(a), len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:n + m - 1]


def local_score(a):
    """Compute score = 2*n*max(conv(a,a))/sum(a)^2."""
    a = np.clip(a, 0.0, 1000.0)
    n = len(a)
    if n == 0:
        return np.inf
    sum_a = np.sum(a)
    if sum_a < 0.01:
        return np.inf
    c = fft_convolve(a, a)
    return float(2.0 * n * np.max(c) / (sum_a ** 2))


def subgrad_at_peak(a, k_peak):
    """Compute centered subgradient of conv(a,a)[k_peak] w.r.t. a."""
    n = len(a)
    grad = np.zeros(n)
    lo = max(0, k_peak - n + 1)
    hi = min(n - 1, k_peak)
    if lo <= hi:
        indices = np.arange(k_peak - hi, k_peak - lo + 1)
        grad[lo:hi + 1] = 2.0 * a[indices]
    grad -= np.mean(grad)
    return grad


def multi_peak_gradient(a, K=3):
    """Combined gradient from top-K peaks with exponential weighting."""
    n = len(a)
    c = fft_convolve(a, a)
    top_K = np.argsort(c)[::-1][:K]
    peak_vals = c[top_K]
    max_val = peak_vals[0]
    spread = max_val * 0.05 + 1e-10
    weights = np.exp(-(max_val - peak_vals) / spread)
    weights /= np.sum(weights)
    grad = np.zeros(n)
    for i in range(K):
        grad += weights[i] * subgrad_at_peak(a, int(top_K[i]))
    return grad

    if len(provided) == n:
        return provided.copy().astype(np.float64)
    x_old = np.linspace(0, 1, len(provided))
    x_new = np.linspace(0, 1, n)
    return np.clip(np.interp(x_new, x_old, provided), 0.01, None)


def make_sinusoidal_init(n, rng):
    """Create a multi-frequency sinusoidal initialization."""
    t = np.arange(n, dtype=np.float64)
    a = np.ones(n)
    n_freqs = rng.integers(2, 5)
    for _ in range(n_freqs):
        f = float(rng.integers(1, max(2, n // 3)))
        amp = rng.uniform(0.08, 0.25)
        phase = rng.uniform(0, 2 * np.pi)
        a += amp * np.cos(2.0 * np.pi * f * t / n + phase)
    return np.clip(a, 0.01, None)


def make_smooth_noise_init(n, rng):
    """Generate a smooth random sequence via random Fourier features."""
    K = max(3, n // 10)
    max_f = n // 2 - 1
    freqs = rng.choice(np.arange(1, max(2, max_f)), size=min(K, max(1, max_f)), replace=False)
    phases = rng.uniform(0, 2 * np.pi, size=len(freqs))
    amps = rng.uniform(0.05, 0.3, size=len(freqs))
    t = np.arange(n, dtype=np.float64)
    a = np.ones(n)
    for f, p, amp in zip(freqs, phases, amps):
        a += amp * np.cos(2 * np.pi * f * t / n + p)
    return np.clip(a, 0.01, None)


def make_tilted_init(n, rng, base=None):
    """Create a sequence with deliberate asymmetry to break palindromic symmetry."""
    t = np.arange(n, dtype=np.float64)
    tilt = 0.3 * (t / n - 0.5)
    if base is not None:
        a = base * 0.6 + (1.0 + tilt) * 0.4
    else:
        a = 1.0 + tilt + 0.15 * np.cos(2 * np.pi * 3 * t / n + rng.uniform(0, 2 * np.pi))
    return np.clip(a, 0.01, None)


def make_bump_init(n, rng):
    """Create a sequence with a Gaussian bump (concentrated mass)."""
    t = np.arange(n, dtype=np.float64)
    center = n * rng.uniform(0.2, 0.8)
    width = n * rng.uniform(0.1, 0.3)
    a = 0.5 + 0.8 * np.exp(-0.5 * ((t - center) / width) ** 2)
    a += 0.05 * rng.standard_normal(n)
    return np.clip(a, 0.01, None)
```
