**Simpler approach: Smoothed objective with L-BFGS**

Use the smoothed maximum: `g_tau(a) = (1/tau) * log(sum_k exp(tau * conv(a,a)[k]))`

This is differentiable and approximates `max_k conv(a,a)[k]` as tau -> infinity. The objective is:
`f_tau(a) = 2*n * g_tau(a) / (sum a)^2`

I can minimize this using L-BFGS with the constraint `a >= 0` (using a barrier or log transformation).

The gradient of `g_tau(a)` w.r.t. `a[j]` is:
`dg/da[j] = (1/tau) * sum_k exp(tau*conv_k) * d(conv_k)/da[j] / sum_k exp(tau*conv_k)`
`= sum_k p_k * (a[k-j] + a[j-k])_valid`

where `p_k = exp(tau*conv_k) / sum_

exp(tau*conv_k)` are softmax weights.

This is a weighted sum of the "autocorrelation vectors" at each lag, weighted by the softmax probabilities.

I can also use a **penalty method**: minimize `g_tau(a) + mu * sum(max(0, a[j])^2)` with mu -> -infinity... no, that's wrong.

Better: use the **log-barrier** for the non-negativity constraint: minimize `f_tau(a) - sigma * sum(log(a[j]+eps))` for the barrier term.

Or even simpler: parameterize `a[j] = exp(b[j])` so that `a[j] > 0` automatically, and minimize `f_tau(exp(b))` over `b` unconstrained.

This is a clean approach! Let me implement it.

Actually, for the log parameterization, the gradient w.r.t. `b[j]` is:
`df/da[j] * da[j]/db[j] = df/da[j] * a[j]`
