We want to find a perturbation δ (of a) such that:
- b_i decreases for all i
- sum(δ) = 0 (to maintain normalization)
- a + δ >= 0

The linearized effect of δ on b[k] is:
Δb[k] ≈ 2 * sum_i δ[i] * a[k-i] (for the aperiodic convolution)

So we want: 2 * sum_i δ[i] * a[k_j - i] < 0 for all j.

This is a system of K inequalities. We can solve it as a feasibility LP or use a least-squares approach:
minimize ||A δ||^2 subject to A δ < 0, sum δ = 0, a + δ >= 0
where A is the K x n matrix with A[j, i] = a[k_j - i] (if valid).

Or more simply: minimize sum_j (A[j,:] · δ)^2 subject to constraints, which pushes all peaks down simultaneously.

This is essentially a multi-peak gradient step.

- j must satisfy 0 <= j < n and 0 <= j+k < 2n-1
- So j from max(0, -k) to min(n-1, 2n-2-k)

For 0 <= k <= n-1: j from 0 to n-1 (all valid since j+k <= n-1+n-1 = 2n-2 < 2n-1)
So (w ⊛ a)[k] = sum_{j=0}^{n-1} w[k+j] * a[j] for k = 0, ..., n-1.

This is exactly what we want for the gradient!

So: grad[i] = 2 * (w ⊛ a)[i] for i = 0, ..., n-1.

Using FFT with L >= 3n-2:
W = FFT(w, L), A = FFT(a, L)
corr = IFFT(conj(W) * A)
grad = 2 * corr[0:n]

**Spectral re-weighting idea:**
The convolution b = a * a can be computed in the frequency domain: B = |A|^2 (where A = FFT(a)).
If we want to flatten B (make all b[k] equal), we need |A|^2 to be flat, i.e., |A[k]| = constant for all k.

This is the "flat spectrum" or "white spectrum" condition. Sequences with flat power spectrum are called "CAZAC" (Constant Amplitude Zero Autocorrelation) sequences in the periodic case (like Zadoff-Chu sequences).

For the aperiodic case, we can't achieve perfect flatness, but we can get close.

**Algorithm: Iterative spectral flattening**
1. Compute A = FFT(a) (zero-padded)
2. Compute P = |A|^2
3. The desired spectrum is P_target = (sum P) / L (flat)
4. Update: A_new = A * (P_target / P)^β (with β in (0,1) for stability)
   Or: A_new = A * exp(β * (log(P_target) - log(P)))
5. a_new = IFFT(A_new).real
6. Project: a_new = max(a_new, 0), normalize
7. Iterate

This is similar to the Gerchberg-Saxton / error reduction algorithm used in Phase retrieval!

The key advantage is that it operates on the global structure of the sequence, not just local perturbations. It can make large structural changes in a single step.

Let me combine this with the gradient method:
- Alternate between spectral flattening steps and gradient steps
- The spectral steps make large global changes
- The gradient steps fine-tune

This combination might escape the local minimum that the pure gradient method is stuck in.

Let me also think about the constraint that a >= 0. The IFFT step might produce negative values, which we clip. This clipping is a "projection" that might Lose some of the spectral shaping benefit. To mitigate this:
- Use a "soft" clipping: a_new = a * sigmoid(γ * a_raw) / sum(a * sigmoid(γ * a_raw))
- Or use a "reflection" instead of clipping: a_new[i] = |a_raw[i]| (this preserves the magnitude)
- Or use a "water-filling" projection: distribute the mass from negative entries to positive entries proportionally

I think the simplest effective approach is:
1. Do the spectral update
2. Take the real part
3. Apply a soft threshold: a_new[i] = max(0, a_raw[i] - ε) + ε_min (with small ε, ε_min)
4. Normalize

Or even simpler: just clip at 0 and normalize. The gradient steps will fix any artifacts.

import numpy as np
import time

def compute_obj(a):
    n = len(a)
    c = np.convolve(a, a)
    max_c = float(c.max())
    S = float(a.sum())
    if S < 0.01:
        return float('inf')
    return float(2.0 * n * max_c / (S * S))

def normalize(a, target=None):
    if target is None:
        target = np.sqrt(2.0 * len(a))
    S = a.sum()
    if S < 1e-12:
        return a.copy()
    return a * (target / S)

def fft_gradient(a, taus, top_k=None):
    """
    Compute soft-max gradient using FFT.
    Supports multiple temperatures (returns gradient for each tau).
    """
    n = len(a)
    c = np.convolve(a, a)
    L = 2 * (2 * n - 1)  # FFT length for cross-correlation
    
    fft_a = np.fft.fft(a, n=L)
    
    grads = []
    for tau in taus:
        c_shifted = c - c.max()
        w = np.exp(tau * c_shifted)
        
        if top_k is not None:
            # Only use top-k peaks
            top_indices = np.argsort(c)[-top_k:]
            w_masked = np.zeros_like(w)
            w_masked[top_indices] = w[top_indices]
            w = w_masked
        
        w_sum = w.sum()
        if w_sum < 1e-300:
            w = np.zeros_like(c)
            w[np.argmax(c)] = 1.0
        else:
            w /= w_sum
        
        fft_w = np.fft.fft(w, n=L)
        corr = np.real(np.fft.ifft(np.conj(fft_w) * fft_a))
        grad = 2.0 * corr[:n]
        grads.append(grad)
    
    return grads, c

def spectral_flatten(a, beta=0.5):
    """
    One step of spectral flattening.
    Tries to make the power spectrum flat (which flattens the autocorrelation).
    """
    n = len(a)
    L = 1  # find next power of 2 >= 2n-1
    while L < 2*n - 1:
        L *= 2
    
    A = np.fft.fft(a, n=L)
    P = np.abs(A)**2
    P_mean = P.mean()
    
    # Log-domain update for stability
    P_safe = np.maximum(P, 1e-30)
    A_new = A * (P_mean / P_safe) ** beta
    
    a_new = np.real(np.fft.ifft(A_new))[:n]
    a_new = np.maximum(a_new, 0.0)
    
    S = a_new.sum()
    if S < 1e-12:
        return a.copy()
    a_new /= S
    a_new *= a.sum()  # preserve sum
    
    return a_new
