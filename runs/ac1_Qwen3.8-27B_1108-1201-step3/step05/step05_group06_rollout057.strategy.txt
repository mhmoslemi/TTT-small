The goal is to find a sequence of non-negative coefficients that minimizes the evaluation function:
cost = (2 * n * max(convolution)) / (sum_a ** 2)

- **Gradient Info from Original Objective**: Instead of smoothing the objective when computing directions, we calculate the gradient fixing the exact optimization metric.
- **Structured Search**: We alternate between coordinate-wise optimization and geometric expansion phases.

## 4. Hyperparameter Schedule

Important parameters to schedule:

1. **Temperature Factor**: Start at 0.5 slowly decrease to 0.01.
2. **Learning Rate**: Start high for initial adaptation then decrease.
3. **Sequence Length**: Begin at 512 for base optimization, extend to 768, 1024, 1500.
4. **Method Switches**: Start with Nelder-Mead then COBYLA then linear programming.
5. **Max Function Evals**: Start at 5000 and decrease as length increases.
6. **Max Iteration**: Initially 1000 and decrease as length increases.
7. **Time Allotment**: Base time grows with length until total time exhaust.

## 5. Validation and Return Contract

The final candidate sequence `a` must satisfy:

1. Non-negative elements with no >1000
2. Sum >=0.01

We compute objective_safe for the final candidate.

If the sequence has length 0, use a fallback geometric sequence.

The returned value is a list of floats with the same structure as the parent was.
