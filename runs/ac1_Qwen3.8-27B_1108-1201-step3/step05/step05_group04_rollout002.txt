1. Start with a flat convolution target: target[k] = (sum a)^2 / (2n-1) for all k.
2. At each iteration:
   a. Find the sequence a that best matches the target convolution (in least-squares sense).
   b. Update the target to be the actual convolution of the current a, but with the maximum "clipped" down.
3. This is like an alternating minimization approach.

Step (a) is a quadratic optimization: minimize `sum_k (a*a[k] - target[k])^2` subject to `sum a = S, a >= 0`. This is a QP!

Actually, this might be too slow for n=768.

**New idea: Use the structure of the problem more directly**

The key insight is that we're looking for a sequence with a "flat" autocorrelation. This is related to:
- Barker sequences (for binary sequences)
- Low-autocorrelation sequences
- "Flat-top" spectral windows

One approach: parameterize the sequence in the frequency domain. Let `A(f)` be the DFT of a. Then `|A(f)|^2` determines the autocorrelation (via the Wiener-Khinchin theorem, the autocorrelation is the IFT of `|A(f)|^2`).

Wait, that's for the circular autocorrelation. For the linear autocorrelation, it's slightly different but related.

If we work in the frequency domain:
- Let `A = FFT(a, L)` where L >= 2n-1 (zero-padded).
- The linear autocorrelation is `IFFT(|A|^2)` (circular, but since we zero-padded enough, it equals the linear autocorrelation in the first 2n-1 positions).

So we want `IFFT(|A|^2)` to be as flat as possible.

This means we want `|A|^2` to be as "spread out" as possible in the frequency domain... wait, that's the opposite. If `|A|^2` is constant, then `IFFT(|A|^2)` is a delta function (all energy at lag 0). We want the opposite: `|A|^2` should be such that its IFT is flat.

Actually, IFT of a constant is a delta (at position 0). IFT of a delta (at frequency 0) is a constant. So we want `|A|^2` to be concentrated at frequency 0? That would mean A is concentrated at frequency 0, which means a is a delta function. That's not what we want.

Let me reconsider. We want `c[k] = (a*a)[k]` to be approximately constant for k = 0, ..., 2n-2. The sum of all c[k] is `(sum a)^2`. So ideally `c[k] = (sum a)^2/(2n-1)` for all k.

In the frequency domain: `C = |A|^2` (where C is the DFT of c, A is the DFT of a, both with appropriate zero-padding).

We want `IFFT(C)[k] ≈ constant` for k = 0, ..., 2n-2.

`IFFT(C)[k] = (1/L) * sum_m C[m] * exp(2πi*m*k/L)`

For this to be constant, we need `C[m] = 0` for all m != 0, and `C[0] = L * constant`. But `C[0] = |A[0]|^2 = (sum a)^2`, so `constant = (sum a)^2/L`.

But `C[m] = |A[m]|^2 >= 0`, so `C[m] = 0` for m != 0 means `A[m] = 0` for m != 0, which means a is a constant sequence (all mass at DC). For a constant sequence, `a[i] = 1/n`, and the convolution is a triangle, not flat.

So the "flat autocorrelation" is not achievable by this simple frequency argument. The constraint is that a must be a sequence of length n (not arbitrary), which couples the frequency domain.

OK let me step back and think about what practical algorithmic improvements to make.

**My plan for the improved algorithm:**

1. **Start from the parent sequence** (n=768) as the primary starting point.

2. **Use a more aggressive subgradient method**:
   - Use exact active set (top-k positions at the maximum) rather than soft-max.
   - Use Nesterov acceleration (momentum).
   - Adaptive step size based on the Lyapunov function.

3. **Add a "deflation" step**: After identifying the active set, explicitly try to reduce the values at those positions by adjusting the sequence.

4. **Use a two-level optimization**:
   - Outer loop: adjust the overall shape (e.g., try different "profiles" like Gaussian, uniform, etc.)
   - Inner loop: fine-tune the sequence given the profile.

5. **Try the symmetric restriction**: Optimize over symmetric sequences only, which might give a better landscape.

6. **Frequency-domain initialization**: Use known low-autocorrelation sequence structures (like Zadoff-Chu sequences) as initializations.

7. **Better coordinate descent**: Instead of trying a few multipliers per coordinate, use the exact optimal value for each coordinate (solving a 1D optimization).

import numpy as np
import time

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    """Euclidean projection onto the probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def compute_subgradient_exact(f, w):
    """Compute exact subgradient using active set weights w (length 2n-1)."""
    n = len(f)
    # sg[j] = 2 * sum_k w[k] * f[k-j] (with f[i]=0 outside [0,n-1])
    # This is 2 * correlate(w, f, 'valid')
    return 2.0 * np.correlate(w, f, 'valid')

def nesterov_subgradient(f0, time_limit, top_k=50, lr_init=0.01, 
                          beta=0.9, verbose=False):
    """Nesterov-accelerated projected subgradient method."""
    f = f0.astype(np.float64).copy()
    s = f.sum()
    f = f / s
    n = len(f)
    
    # Nesterov momentum
    y = f.copy()  # Nesterov lookahead point
    v = np.zeros(n)  # momentum
    
    t = 0
    best_f = f.copy()
    best_obj = fast_convolve(f).max()
    
    # Adaptive step size
    step = lr_init
    S = 0.0  # for adaptive step size
    
    t0 = time.monotonic()
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        t += 1
        
        # Compute convolution at y (Nesterov point)
        conv = fast_convolve(y)
        max_conv = conv.max()
        
        # Identify active set (top-k positions)
        k = min(top_k, len(conv))
        top_idx = np.argpartition(conv, -k)[-k:]
        top_vals = conv[top_idx]
        
        # Soft weights on active set (geometric)
        w = np.zeros(len(conv))
        top_sorted = np.sort(top_vals)[::-1]
        # Use exponential weighting
        if top_sorted[0] > 0:
            temps = top_sorted / top_sorted[0]
            w_active = np.exp(temps - 1.0)  # relative weighting
            w_active /= w_active.sum()
            w[top_idx] = w_active
            # Sort to assign weights correctly
            order = np.argsort(top_vals)[::-1]
            w[top_idx] = w_active[order]
        else:
            w[top_idx] = 1.0 / k
        
        # Compute subgradient
        sg = compute_subgradient_exact(y, w)
        
        # Nesterov update
        v = beta * v - step * sg
        x_new = project_simplex(y + v * (1.0 / (t + 1)))
        
        # Actually, let's use the standard Nesterov scheme:
        # y_{t+1} = x_{t+1} + (t/(t+2)) * (x_{t+1} - x_t)
        # x_{t+1} = project(y_t - step * sg)
        
        # Simpler: use heavy ball / momentum
        v = beta * v - step * sg
        f_new = project_simplex(f + v)
        
        # Update Nesterov point
        gamma = (1.0 + np.sqrt(1.0 + 4.0 * t * t)) / 2.0
        y = f_new + (t / gamma) * (f_new - f)
        y = project_simplex(y)  # Keep y on simplex
        
        f = f_new
        
        # Adaptive step size
        step = lr_init / (1.0 + 0.01 * t)
        step = max(step, lr_init * 0.01)
        
        # Check improvement
        conv_f = fast_convolve(f)
        cur_obj = conv_f.max()
        
        if cur_obj < best_obj - 1e-14:
            best_obj = cur_obj
            best_f = f.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        # Restart if stuck
        if no_improve > 200:
            f = project_simplex(best_f + np.random.default_rng(t).standard_normal(n) * 0.005)
            y = f.copy()
            v = np.zeros(n)
            step = lr_init
            no_improve = 0
            t = 0
        
        if verbose and t % 100 == 0:
            print(f"    Nesterov t={t}: obj={best_obj:.10f}, step={step:.6f}")
    
    return best_f, best_obj

def frank_wolfe(f0, time_limit, top_k=30, max_iter=100000, verbose=False):
    """Frank-Wolfe (conditional gradient) with exact active set."""
    f = f0.astype(np.float64).copy()
    s = f.sum()
    f = f / s
    n = len(f)
    
    best_f = f.copy()
    best_obj = fast_convolve(f).max()
    
    t0 = time.monotonic()
    t = 0
    gamma = 2.0 / (t + 2.0)  # FW step size
    
    while time.monotonic() - t0 < time_limit and t < max_iter:
        t += 1
        
        conv = fast_convolve(f)
        max_conv = conv.max()
        
        # Active set
        k = min(top_k, len(conv))
        top_idx = np.argpartition(conv, -k)[-k:]
        
        # Uniform weights on active set
        w = np.zeros(len(conv))
        w[top_idx] = 1.0 / len(top_idx)
        
        sg = compute_subgradient_exact(f, w)
        
        # Linear oracle: find e_j that minimizes <sg, e_j> = sg[j]
        j_min = np.argmin(sg)
        
        # FW step
        gamma = 2.0 / (t + 2.0)
        f_new = (1.0 - gamma) * f + gamma * np.zeros(n)
        f_new[j_min] = gamma  # Wait, this isn't right
        # Actually: f_new = (1-gamma)*f + gamma*e_{j_min}
        f_new = (1.0 - gamma) * f
        f_new[j_min] += gamma
        
        # Check improvement
        conv_new = fast_convolve(f_new)
        if conv_new.max() < best_obj - 1e-15:
            best_obj = conv_new.max()
            best_f = f_new.copy()
        
        f = f_new
    
    return best_f, best_obj

def symmetric_subgradient(f0, time_limit, top_k=50, lr_init=0.008, 
                          verbose=False):
    """Subgradient method restricted to symmetric sequences."""
    n = len(f0)
    f = f0.astype(np.float64).copy()
    # Symmetrize
    f = (f + f[::-1]) / 2.0
    s = f.sum()
    f = f / s
    
    # Work with half the sequence
    half_n = (n + 1) // 2
    # For symmetric seq: a[i] = a[n-1-i]
    # Parameters: a[0], a[1], ..., a[half_n-1] (and if n even, a[half_n] = a[half_n-1]... wait)
    
    # Actually, let's just enforce symmetry after each step
    best_f = f.copy()
    best_obj = fast_convolve(f).max()
    
    t = 0
    step = lr_init
    t0 = time.monotonic()
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        t += 1
        
        # Ensure symmetry
        f = (f + f[::-1]) / 2.0
        f = project_simplex(f)
        
        conv = fast_convolve(f)
        max_conv = conv.max()
        
        k = min(top_k, len(conv))
        top_idx = np.argpartition(conv, -k)[-k:]
        
        w = np.zeros(len(conv))
        w[top_idx] = 1.0 / len(top_idx)
        
        sg = compute_subgradient_exact(f, w)
        # Symmetrize subgradient
        sg = (sg + sg[::-1]) / 2.0
        
        f_new = project_simplex(f - step * sg)
        f_new = (f_new + f_new[::-1]) / 2.0
        f_new = project_simplex(f_new)
        f = f_new
        
        step = lr_init / (1.0 + 0.005 * t)
        step = max(step, lr_init * 0.01)
        
        conv_f = fast_convolve(f)
        cur_obj = conv_f.max()
        
        if cur_obj < best_obj - 1e-14:
            best_obj = cur_obj
            best_f = f.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        if no_improve > 300:
            rng = np.random.default_rng(t * 7)
            f = project_simplex(best_f + rng.standard_normal(n) * 0.003)
            f = (f + f[::-1]) / 2.0
            f = project_simplex(f)
            step = lr_init
            no_improve = 0
            t = 0
    
    return best_f, best_obj

def adaptive_topk_subgradient(f0, time_limit, top_k_init=100, top_k_min=5,
                              lr_init=0.005, temp_init=0.01, temp_decay=0.999,
                              verbose=False):
    """Adaptive subgradient with dynamic top-k and temperature."""
    f = f0.astype(np.float64).copy()
    s = f.sum()
    f = f / s
    n = len(f)
    
    best_f = f.copy()
    best_obj = fast_convolve(f).max()
    
    t = 0
    step = lr_init
    temp = temp_init
    top_k = top_k_init
    t0 = time.monotonic()
    no_improve = 0
    
    # Momentum
    v = np.zeros(n)
    beta = 0.9
    
    while time.monotonic() - t0 < time_limit:
        t += 1
        
        conv = fast_convolve(f)
        max_conv = conv.max()
        mean_conv = conv.mean()
        
        # Adaptive top-k: include positions above mean + alpha * (max - mean)
        alpha = 0.5  # threshold parameter
        threshold = mean_conv + alpha * (max_conv - mean_conv)
        active = np.where(conv >= threshold)[0]
        if len(active) < top_k_min:
            active = np.argpartition(conv, -top_k_min)[-top_k_min:]
        if len(active) > top_k:
            active = np.argpartition(conv, -top_k)[-top_k:]
        
        # Soft-max weights on active set
        w = np.zeros(len(conv))
        active_vals = conv[active]
        shifted = (active_vals - active_vals.min()) / max(temp, 1e-10)
        w_active = np.exp(shifted)
        w_active /= w_active.sum()
        w[active] = w_active
        
        sg = compute_subgradient_exact(f, w)
        
        # Momentum update
        v = beta * v - step * sg
        f_new = project_simplex(f + v)
        f = f_new
        
        step = lr_init / (1.0 + 0.002 * t)
        step = max(step, lr_init * 0.01)
        temp = max(temp * temp_decay, 1e-5)
        
        conv_f = fast_convolve(f)
        cur_obj = conv_f.max()
        
        if cur_obj < best_obj - 1e-14:
            best_obj = cur_obj
            best_f = f.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        if no_improve > 200:
            rng = np.random.default_rng(t * 13 + 3)
            scale = 0.002 + 0.005 * min(no_improve // 100, 3)
            f = project_simplex(best_f + rng.standard_normal(n) * scale)
            v = np.zeros(n)
            step = lr_init
            temp = max(temp_init * 0.5, 0.003)
            no_improve = 0
            t = 0
    
    return best_f, best_obj

def make_zadoff_chu_like(n):
    """Create a Zadoff-Chu-like initialization (good flat autocorrelation property)."""
    # Zadoff-Chu: z[k] = exp(-j*pi*k*(k+1)/N) for N odd
    # We use the magnitude pattern as initialization
    N = n if n % 2 == 1 else n + 1
    k = np.arange(N)
    z = np.exp(-1j * np.pi * k * (k + 1) / N)
    # Use the real part (positive parts) as initialization
    a = np.abs(z[:n])
    a = np.maximum(a, 0.01)
    return a / a.sum()

def make_spread_init(n, rng):
    """Create a well-spread initialization."""
    # Sum of shifted Gaussians with random centers
    a = np.zeros(n)
    n_gauss = rng.integers(3, 8)
    for _ in range(n_gauss):
        c = rng.uniform(0, 1)
        s = rng.uniform(0.05, 0.3)
        amp = rng.uniform(0.5, 2.0)
        x = np.linspace(0, 1, n)
        a += amp * np.exp(-0.5 * ((x - c) / s) ** 2)
    a = np.maximum(a, 0.001)
    return a / a.sum()

def two_level_optimize(f0, time_limit, verbose=False):
    """Two-level: first optimize the "envelope", then fine-tune."""
    n = len(f0)
    f = f0.astype(np.float64).copy()
    s = f.sum()
    if s < 1e-15:
        f = np.ones(n) / n
    else:
        f = f / s
    
    best_f = f.copy()
    best_obj = fast_convolve(f).max()
    
    t0 = time.monotonic()
    
    # Level 1: Coarse optimization with large steps
    t_alloc1 = time_limit * 0.4
    f, obj1 = adaptive_topk_subgradient(f, time_limit=t_alloc1, 
                                          top_k_init=200, top_k_min=10,
                                          lr_init=0.01, temp_init=0.02,
                                          temp_decay=0.998, verbose=verbose)
    if obj1 < best_obj:
        best_obj = obj1
        best_f = f.copy()
    
    # Level 2: Fine optimization with small steps
    t_alloc2 = time_limit * 0.6
    rem = time_limit - (time.monotonic() - t0)
    f, obj2 = adaptive_topk_subgradient(best_f, time_limit=min(t_alloc2, rem),
                                          top_k_init=50, top_k_min=3,
                                          lr_init=0.003, temp_init=0.005,
                                          temp_decay=0.9995, verbose=verbose)
    if obj2 < best_obj:
        best_obj = obj2
        best_f = f.copy()
    
    return best_f, best_obj
