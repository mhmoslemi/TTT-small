Actually, let me think about this more carefully. The issue is that for a uniform sequence, the convolution is triangular, peaking at the center. To flatten it, we want to REDUCE the center peak. The center of the convolution (position n-1) is:

To reduce this, we could reduce the product a[j]*a[n-1-j] for the j's that contribute most. If the sequence is uniform, all products are equal, so we'd need to make the sequence non-uniform.

One approach: make a[j] large for small j and small for large j (or vice versa). This would make b[n-1] = sum a[j]*a[n-1-j] potentially smaller because the large values of a[j] would be multiplied by small values of a[n-1-j].

The key tradeoff: we want to minimize the MAX of all b[k]. So we want to balance the peak at center against the peaks at edges.

This is exactly what the LP-based approach does! Fix one sequence, find the best response for the other, iterate.

Minimizes 2*n*max(convolve(a,a))/(sum(a))^2 using FFT-based gradient descent in
log-space with adaptive log-sum-exp temperature, LP-based best response,

Key innovations: efficient FFT gradient computation in softmax parameterization,

import numpy as np

from scipy.fft import rfft, irfft


def fast_convolve(a):
    """Compute full linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]


def compute_score(a):
    """Compute the evaluation score 2*n*max_b/(sum_a)^2."""
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    s = np.sum(a)
    if s < 0.01:
        return float('inf')
    b = fast_convolve(a)
    return float(2.0 * n * b.max() / (s * s))


def softmax_stable(z):
    """Numerically stable softmax."""
    z_shift = z - z.max()
    e = np.exp(z_shift)
    s = e.sum()
    if s < 1e-300:
        return np.ones(len(z)) / len(z)
    return e / s


def log_of_a(a):
    """Convert probability vector to log-space."""
    return np.log(np.maximum(a, 1e-300))


def grad_logsumexp(a, w):
    """
    Compute gradient of log-sum-exp objective w.r.t. a.
    grad_a[i] = 2 * sum_j a[j] * w[i+j] (cross-correlation of a and w).
    """
    n = len(a)
    # w has length 2n-1
    # We need g[i] = sum_{j=0}^{n-1} a[j] * w[i+j] for i = 0,...,n-1
    # This is cross-correlation of a and w at lags 0, 1, ..., n-1
    fft_len = 1 << (3 * n - 1).bit_length()
    a_pad = np.concatenate([a, np.zeros(fft_len - n)])
    w_pad = np.concatenate([w, np.zeros(fft_len - len(w))])
    A = rfft(a_pad, fft_len)
    W = rfft(w_pad, fft_len)
    corr = irfft(np.conj(A) * W, fft_len)[:n]
    return 2.0 * corr
