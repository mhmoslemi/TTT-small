In the frequency domain: $|\hat{a}(\omega)|^2$ should be the DFT of a "flattened triangle." The DFT of a triangle is a "sinc^2" shape. So we want $|\hat{a}(\omega)| \propto |\text{sinc}(\omega)| \cdot (\text{correction})$.

This is essentially a "magnitude modification" problem in the frequency domain, similar to phase retrieval or spectral shaping.

**Algorithm: Iterative spectral shaping**

1. Start with $a$ (e.g., uniform).
2. Compute $\hat{a} = \text{FFT}(a, N)$ where $N \geq 2n-1$.
3. Compute $|\hat{a}|^2$ and its IDFT to get $c = a*a$.
4. Compute the target $c^{\text{target}}$ (e.g., a flattened version of $c$).
5. Compute $\hat{c}^{\text{target}} = \text{FFT}(c^{\text{target}})$.
6. Set new magnitude: $|\hat{a}_{\text{new}}| = \sqrt{|\hat{c}^{\text{target}}|}$.

At the optimum, there's a set of "active" convolution positions where $c_k = M$ (the max). For these positions, the KKT conditions give:
$$\sum_{k \in A} \lambda_k \frac{\partial c_k}{\partial a_i} + \mu = 0 \quad \forall i$$
where $\lambda_k \geq 0$ and $\mu$ is the Lagrange multiplier for the sum constraint.

This means: for all $i$, $\sum_{k \in A} \lambda_k a_{k-i} = \mu$ (constant).

This is a system of $n$ equations in $|A|$ unknowns $\lambda_k$ plus $\mu$. If $|A| = n$, we can solve for all $\lambda_k$ and $\mu$.

But this is a linear system, and the "solution" gives us the weights for the subgradient. We can use this to define a "smoother" objective:
$$\tilde{f}(a) = \sum_{k \in A} \lambda_k c_k$$
which is linear in $c$ and hence quadratic in $a$. Minimizing this (subject to $\sum a = 1, a \geq 0$) is a QP!
