Wait, I made an error in the gradient computation. Let me redo it.

`b_k = sum_j a_j * a_{k-j}` where j ranges over `[max(0, k-n+1), min(k, n-1)]`.

`db_k / da_i`: 
- If i is in the valid range for j AND k-i is in [0, n-1]:
  - The term `a_i * a_{k-i}` contributes: derivative is `a_{k-i}`
  - If k-i != i and k-i is also in the valid range for j:

- Otherwise: 0

So actually, for i in the valid range (where both i and k-i are in [0, n-1]), `db_k / da_i = 2 * a_{k-i}`.

This is what I had. Good.

`= (db_k/da_i) * a_i - a_i * sum_m (db_k/da_m) * a_m`

So `db_k / dz_i = 2*a_{k-i} * a_i - 2*a_i * b_k = 2*a_i * (a_{k-i} - b_k)` for i in valid range, 0 otherwise.

And the gradient of `f(z) = (2n/T) * logsumexp(T*b)` w.r.t. `z_i` is:

`= 4n * a_i * sum_k w_k * (a_{k-i} - b_k) * I(0<=k-i<=n-1)`

Let me define `S_i = sum_k w_k * a_{k-i} * I(0<=k-i<=n-1)` and `B = sum_k w_k * b_k`.

Then `grad_z_i = 4n * a_i * (S_i - B)`.

This is a clean formula! Let me verify:
- `S_i = sum_k w_k * a_{k-i}` where k-i is in [0, n-1], i.e., k is in [i, i+n-1].
- `B = sum_k w_k * b_k`.

So the gradient is: `grad_z = 4*n * a * (S - B)` where `S_i = sum_{k=i}^{i+n-1} w_k * a_{k-i}` (with appropriate bounds).

Actually, `S_i = corrélation of w and a at lag i` (approximately). We can compute this via FFT!

Let me formalize: `S_i = sum_{m=0}^{n-1} w_{i+m} * a_m` where we define `w_k = 0` for k outside [0, 2n-2].

This is a cross-correlation! `S = correlate(w, a)` (with appropriate mode).

So the gradient can be computed as:
1. Compute `b = convolve(a, a)` via FFT.
2. Compute `w = softmax(T*b)`.
3. Compute `S = correlate(w, a)` via FFT.
4. Compute `B = dot(w, b)`.
5. `grad_z = 4*n*a*(S - B)`.

This is O(n log n) per gradient evaluation! Much faster than the naive O(n^2) approach.

Let me also think about the function value:
`f(z) = (2n/T) * logsumexp(T*b) = (2n/T) * (T*max_b + log(sum(exp(T*(b - max_b)))))`
`= 2n * (max_b + (1/T)*log(sum(exp(T*(b - max_b)))))`

For large T, this approaches `2n * max_b` (the actual objective). For small T, it's smoother.

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using fast FFT-based L-BFGS
with multi-length exploration and aggressive temperature annealing.
Key innovations: O(n log n) gradient computation via FFT cross-correlation,
multi-length search, and adaptive L-BFGS with very low final temperatures.

import numpy as np
import time
from scipy.fft import rfft, irfft
from scipy.optimize import minimize


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]


def fast_cross_corr(w, a):
    """Compute S_i = sum_m w[i+m] * a[m] for i=0..n-1 (cross-correlation)."""
    n = len(a)
    # S_i = sum_{m=0}^{n-1} w_{i+m} * a_m
    # This is the cross-correlation of w and a at lag i.
    # Using FFT: S = ifft(conj(FFT(a)) * FFT(w)) ... no, let me think.
    # S_i = sum_m w_{i+m} * a_m = (w * a)[i] in a specific convolution sense.
    # Actually, S_i = sum_m a_m * w_{i+m}
    # Let's define: for the "valid" correlation, S_i = sum_{m=0}^{n-1} a_m * w_{i+m}
    # where w is of length 2n-1.
    # This is equivalent to: S = correlate(w, a, mode='valid') but with a being the "kernel".
    # Actually, S_i = sum_m a_m * w_{i+m} is the cross-correlation of a and w at lag -i... 
    # Let me just use a direct FFT approach.
    # S_i = sum_{m=0}^{n-1} a_m * w_{i+m}
    # Let w_padded = w (length 2n-1), a_padded = a (length n)
    # S_i = sum_m a_m * w_{i+m} = (a reversed correlates with w at lag i)
    # = convolve(a_reversed, w)[i + n - 1] ... let me just do it with a small loop or direct FFT.
    
    # Alternative: S_i = sum_m a_m * w_{i+m} where w has length 2n-1
    # = sum_m a_{n-1-m} * w_{i+n-1-m} (substituting m -> n-1-m)
    # This is the cross-correlation of a_reversed and w at lag (i + n - 1) ... 
    # 
    # Simplest: use np.correlate(w, a, mode='valid') ... but that might be slow for large n.
    # 
    # Let's use FFT: 
    # S_i = sum_{m=0}^{n-1} a_m * w_{i+m}
    # Let's define x = a (length n), y = w (length 2n-1)
    # S_i = sum_m x_m * y_{i+m}
    # This is the cross-correlation (x ⋆ y) at lag i, defined as:
    # (x ⋆ y)[i] = sum_m x_m * y[m+i]
    # In terms of convolution: (x ⋆ y)[i] = (x_r * y)[i] where x_r is reversed x
    # = conv(x_r, y)[i] (full convolution, index i)
    # Wait: conv(x_r, y)[k] = sum_j x_r[j] * y[k-j] = sum_j x[n-1-j] * y[k-j]
    # Let j' = n-1-j: = sum_{j'} x[j'] * y[k-n+1-j']
    # We want S_i = sum_m x[m] * y[i+m]
    # So we need k-n+1-j' = i+j', i.e., k = i + 2j' + n - 1. That doesn't work out simply.
    
    # Let me just use a different approach. 
    # S_i = sum_{m=0}^{n-1} a_m * w_{i+m}
    # Let's pad a to length 2n-1 (zeros after n), and compute:
    # Actually, the simplest FFT approach:
    # S = ifft(fft(a_padded) * fft(w_reversed_padded)) ... 
    
    # OK let me just think of it as a simple correlation.
    # S_i = <a, shift_i(w)> where shift_i(w)_m = w_{i+m}
    # Using FFT: S = ifft(conj(FFT(a_full)) .* FFT(w_full)) shifted appropriately.
    
    # Simplest correct approach: 
    # S_i = sum_m a_m * w_{i+m} for m=0..n-1
    # This is the "valid" cross-correlation of w with a (a is shorter).
    # In numpy: np.correlate(w, a, mode='valid') gives sum_m w[i+m]*a[m] for i=0..(len(w)-len(a))
    # = sum_m w[i+m]*a[m] for i=0..(2n-1-n) = i=0..n-1. 
    # That's exactly what we want!
    
    # But np.correlate might be O(n^2) for large arrays. Let's use FFT.
    size = 4 * n  # enough for full convolution
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    W = rfft(np.asarray(w, dtype=np.float64), fft_size)
    # np.correlate(w, a, 'valid')[i] = sum_m w[i+m]*a[m]
    # = full_convolution(w, a_flipped)[i + len(a) - 1]
    # a_flipped = a[::-1]
    A_flipped = rfft(a[::-1], fft_size)
    result = irfft(W * A_flipped, fft_size)
    return result[n-1:n-1+n]


def softmax_from_z(z):
    z_shifted = z - z.max()
    exp_z = np.exp(z_shifted)
    s = exp_z.sum()
    if s < 1e-300:
        return np.ones(len(z)) / len(z)
    return exp_z / s


def z_from_a(a):
    return np.log(np.maximum(a, 1e-300))


def lbgfs_optimize(a0, time_limit, T_start=100.0, T_end=0.05, n_stages=10, maxiter_per_stage=500):
    """L-BFGS with fast FFT-based gradient and LogSumExp smoothing."""
    n = len(a0)
    z = z_from_a(a0).copy()
    t0 = time.monotonic()
    
    def obj_and_grad(z, T_val):
        a = softmax_from_z(z)
        b = fast_convolve(a)
        Tb = T_val * b
        max_Tb = Tb.max()
        exp_Tb = np.exp(Tb - max_Tb)
        w = exp_Tb / exp_Tb.sum()
        log_sum_exp = max_Tb + np.log(exp_Tb.sum())
        f_val = (2.0 * n / T_val) * log_sum_exp
        
        # Fast gradient: grad_z = 4*n*a*(S - B) where S_i = sum_m w_{i+m}*a_m, B = w·b
        S = fast_cross_corr(w, a)
        B = np.dot(w, b)
        grad = 4.0 * n * a * (S - B)
        
        return f_val, grad
    
    temps = np.geomspace(T_start, T_end, n_stages)
    
    for stage_idx, stage_T in enumerate(temps):
        if time.monotonic() - t0 > time_limit:
            break
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 2:
            break
        
        def func(z):
            if time.monotonic() - t0 > time_limit:
                return 1e15
            val, _ = obj_and_grad(z, stage_T)
            return val
        
        def jac(z):
            if time.monotonic() - t0 > time_limit:
                return np.zeros_like(z)
            _, g = obj_and_grad(z, stage_T)
            return g
        
        try:
            res = minimize(
                fun=func, x0=z, jac=jac,
                method='L-BFGS-B',
                options={'maxiter': maxiter_per_stage, 'ftol': 1e-18, 'gtol': 1e-12,
                         'maxfun': maxiter_per_stage * 100, 'disp': False}
            )
            z = res.x
        except Exception:
            pass
        
        # Print progress
        a_curr = softmax_from_z(z)
        score = 2.0 * n * fast_convolve(a_curr).max()
        elapsed = time.monotonic() - t0
        print(f"      Stage {stage_idx+1}/{n_stages} (T={stage_T:.2f}): score={score:.6f} ({elapsed:.0f}s elapsed)")
    
    return softmax_from_z(z)


def peak_shave(a0, time_limit, n_steps=50000):
    """Iteratively reduce the peaks of the convolution."""
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    a = a / s
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    t0 = time.monotonic()
    
    for step in range(n_steps):
        if time.monotonic() - t0 > time_limit:
            break
        if time.monotonic() - t0 > time_limit - 5:
            break
            
        b = fast_convolve(a)
        # Find the peak (excluding boundaries which are inherently small)
        b_work = b.copy()
        if n > 2:
            b_work[:max(1, n//20)] = -np.inf
            b_work[-max(1, n//20):] = -np.inf
        peak_k = int(np.argmax(b_work))
        peak_val = b[peak_k]
        
        # Find top contributors to this peak
        js = max(0, peak_k - n + 1)
        je = min(n - 1, peak_k)
        idx = np.arange(js, je + 1)
        contribs = a[idx] * a[peak_k - idx]
        
        # Try reducing the top contributor
        top_ci = int(np.argmax(contribs))
        i = idx[top_ci]
        
        # Try a range of reduction factors
        improved = False
        for factor in [0.99, 0.98, 0.97, 0.95, 0.93, 0.90, 0.85]:
            new_val = a[i] * factor
            diff = a[i] - new_val
            if diff < 1e-16:
                continue
            a_trial = a.copy()
            a_trial[i] = new_val
            # Redistribute the difference
            mask = np.ones(n, dtype=bool)
            mask[i] = False
            others = a_trial[mask]
            others_sum = others.sum()
            if others_sum < 1e-15:
                continue
            a_trial[mask] = others + diff * others / others_sum
            a_trial = a_trial / a_trial.sum()
            score = 2.0 * n * fast_convolve(a_trial).max()
            if score < best_score - 1e-15:
                a = a_trial
                best_score = score
                best_a = a.copy()
                improved = True
                break
        
        if not improved:
            # Try pair reduction
            if len(contribs) >= 2:
                top2 = np.argsort(contribs)[::-1][:4]
                pair_improved = False
                for ci in top2:
                    i1 = idx[ci]
                    j1 = peak_k - i1
                    if i1 == j1 or j1 < 0 or j1 >= n:
                        continue
                    if a[i1] < 1e-14 or a[j1] < 1e-14:
                        continue
                    for f1 in [0.97, 0.95, 0.93]:
                        a_trial = a.copy()
                        a_trial[i1] *= f1
                        a_trial[j1] *= (2.0 - f1)  # Keep sum roughly the same
                        a_trial = np.maximum(a_trial, 0)
                        ss = a_trial.sum()
                        if ss < 1e-15:
                            continue
                        a_trial = a_trial / ss
                        score = 2.0 * n * fast_convolve(a_trial).max()
                        if score < best_score - 1e-15:
                            a = a_trial
                            best_score = score
                            best_a = a.copy()
                            pair_improved = True
                            improved = True
                            break
                    if improved:
                        break
            if not improved:
                break
    
    return best_a, best_score


def structured_init(n, seed=0):
    """Create structured initial sequence with good autocorrelation properties."""
    rng = np.random.default_rng(seed)
    x = np.linspace(0, 1, n)
    
    choice = rng.integers(0, 6)
    if choice == 0:
        # Gaussian
        a = np.exp(-4 * (x - 0.5)**2)
    elif choice == 1:
        # Raised cosine
        a = np.cos(np.pi * (x - 0.5))**2
    elif choice == 2:
        # Parabolic
        a = 1 - 4*(x-0.5)**2
        a = np.maximum(a, 0)
    elif choice == 3:
        # Blackman-like
        a = 0.42 + 0.5*np.cos(2*np.pi*x) + 0.08*np.cos(4*np.pi*x)
        a = np.maximum(a, 0)
    elif choice == 4:
        # Optimal: minimize peak of autocorrelation (use sin^2 with adjustment)
        a = np.sin(np.pi * x)**4
    else:
        # Sine with random phase
        phase = rng.uniform(0, 1)
        a = (0.5 + 0.5*np.cos(2*np.pi*(x - phase)))**2
    
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s


def interpolate_sequence(f, new_n):
    """Interpolate sequence to new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp


def evaluate_safe(a):

    except Exception:
```

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using fast FFT-based L-BFGS with
multi-length exploration, aggressive temperature annealing, and peak shaving.
Key innovations: O(n log n) gradient via FFT cross-correlation, multi-length
search for better theoretical bounds, and adaptive multi-phase optimization.
"""

import numpy as np
import time
from scipy.fft import rfft, irfft
from scipy.optimize import minimize


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]


def fast_cross_corr(w, a):
    """Compute S_i = sum_{m=0}^{n-1} a[m] * w[i+m] for i=0..n-1."""
    n = len(a)
    fft_size = 1 << (3 * n + 1).bit_length()
    a_rev = a[::-1].copy()
    A_rev = rfft(a_rev, fft_size)
    W = rfft(np.asarray(w, dtype=np.float64), fft_size)
    result = irfft(A_rev * W, fft_size)
    return result[n - 1: n - 1 + n]


def softmax_from_z(z):
    """Convert log-domain vector to probability vector."""
    z_shifted = z - z.max()
    exp_z = np.exp(z_shifted)
    s = exp_z.sum()
    if s < 1e-300:
        return np.ones(len(z)) / len(z)
    return exp_z / s


def z_from_a(a):
    """Convert probability vector to log-domain."""
    return np.log(np.maximum(a, 1e-300))


class LBGFSState:
    """State for L-BFGS optimization at a given temperature."""

    def __init__(self, n, T_val, t0, time_limit):
        self.n = n
        self.T = T_val
        self.t0 = t0
        self.time_limit = time_limit

    def func(self, z):
        if time.monotonic() - self.t0 > self.time_limit:
            return 1e15
        a = softmax_from_z(z)
        b = fast_convolve(a)
        Tb = self.T * b
        max_Tb = Tb.max()
        exp_Tb = np.exp(Tb - max_Tb)
        log_sum_exp = max_Tb + np.log(exp_Tb.sum())
        return (2.0 * self.n / self.T) * log_sum_exp

    def jac(self, z):
        if time.monotonic() - self.t0 > self.time_limit:
            return np.zeros_like(z)
        a = softmax_from_z(z)
        b = fast_convolve(a)
        Tb = self.T * b
        max_Tb = Tb.max()
        exp_Tb = np.exp(Tb - max_Tb)
        w = exp_Tb / exp_Tb.sum()
        S = fast_cross_corr(w, a)
        B = np.dot(w, b)
        return 4.0 * self.n * a * (S - B)


def lbgfs_optimize(a0, time_limit, T_start=100.0, T_end=0.05, n_stages=10, maxiter_per_stage=500):
    """L-BFGS with FFT-based gradient and geometric temperature annealing."""
    n = len(a0)
    z = z_from_a(a0).copy()
    t0 = time.monotonic()
    temps = np.geomspace(T_start, T_end, n_stages)

    for stage_idx, stage_T in enumerate(temps):
        if time.monotonic() - t0 > time_limit:
            break
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 2:
            break

        state = LBGFSState(n, float(stage_T), t0, time_limit)
        try:
            res = minimize(
                fun=state.func, x0=z, jac=state.jac,
                method='L-BFGS-B',
                options={'maxiter': maxiter_per_stage, 'ftol': 1e-18,
                         'gtol': 1e-12, 'maxfun': maxiter_per_stage * 100,
                         'disp': False}
            )
            z = res.x
        except Exception:
            pass

        a_curr = softmax_from_z(z)
        score = 2.0 * n * fast_convolve(a_curr).max()
        elapsed = time.monotonic() - t0
        print(f"      Stage {stage_idx + 1}/{n_stages} (T={stage_T:.2f}): score={score:.6f} ({elapsed:.0f}s)")

    return softmax_from_z(z)


def peak_shave(a0, time_limit, n_steps=50000):
    """Iteratively reduce peaks of the convolution via coordinate updates."""
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    a = a / s
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    t0 = time.monotonic()
    no_improve = 0

    for step in range(n_steps):
        if time.monotonic() - t0 > time_limit - 2:
            break

        b = fast_convolve(a)
        b_work = b.copy()
        margin = max(2, n // 30)
        b_work[:margin] = -np.inf
        b_work[-margin:] = -np.inf
        peak_k = int(np.argmax(b_work))
        peak_val = b[peak_k]

        js = max(0, peak_k - n + 1)
        je = min(n - 1, peak_k)
        idx = np.arange(js, je + 1)
        contribs = a[idx] * a[peak_k - idx]

        improved = False
        # Single coordinate reduction
        top_ci = int(np.argmax(contribs))
        i = idx[top_ci]
        for factor in [0.995, 0.99, 0.98, 0.97, 0.95, 0.93, 0.90, 0.85]:
            new_val = a[i] * factor
            diff = a[i] - new_val
            if diff < 1e-16:
                continue
            a_trial = a.copy()
            a_trial[i] = new_val
            mask = np.ones(n, dtype=bool)
            mask[i] = False
            others = a_trial[mask]
            others_sum = others.sum()
            if others_sum < 1e-15:
                continue
            a_trial[mask] = others + diff * others / others_sum
            ss = a_trial.sum()
            if ss < 1e-15:
                continue
            a_trial = a_trial / ss
            score = 2.0 * n * fast_convolve(a_trial).max()
            if score < best_score - 1e-15:
                a = a_trial
                best_score = score
                best_a = a.copy()
                improved = True
                break

        if not improved:
            # Pair reduction
            if len(contribs) >= 2:
                top_ci_arr = np.argsort(contribs)[::-1][:6]
                for ci in top_ci_arr:
                    i1 = idx[ci]
                    j1 = peak_k - i1
                    if i1 == j1 or j1 < 0 or j1 >= n:
                        continue
                    if a[i1] < 1e-14 or a[j1] < 1e-14:
                        continue
                    for f1 in [0.98, 0.96, 0.94, 0.92]:
                        a_trial = a.copy()
                        a_trial[i1] *= f1
                        a_trial[j1] *= (2.0 - f1)
                        a_trial = np.maximum(a_trial, 0)
                        ss = a_trial.sum()
                        if ss < 1e-15:
                            continue
                        a_trial = a_trial / ss
                        score = 2.0 * n * fast_convolve(a_trial).max()
                        if score < best_score - 1e-15:
                            a = a_trial
                            best_score = score
                            best_a = a.copy()
                            improved = True
                            break
                    if improved:
                        break

        if not improved:
            no_improve += 1
            if no_improve >= 200:
                break
        else:
            no_improve = 0

    return best_a, best_score


def structured_init(n, seed=0):
    """Create structured initial sequence."""
    rng = np.random.default_rng(seed)
    x = np.linspace(0, 1, n)
    choice = int(rng.integers(0, 6))
    if choice == 0:
        a = np.exp(-6.0 * (x - 0.5) ** 2)
    elif choice == 1:
        a = np.cos(np.pi * (x - 0.5)) ** 2
    elif choice == 2:
        a = np.sin(np.pi * x) ** 4
    elif choice == 3:
        a = 0.42 + 0.5 * np.cos(2 * np.pi * x) + 0.08 * np.cos(4 * np.pi * x)
        a = np.maximum(a, 0.001)
    elif choice == 4:
        phase = rng.uniform(0, 1)
        a = (0.5 + 0.5 * np.cos(2 * np.pi * (x - phase))) ** 3
    else:
        a = np.exp(-2.0 * x * (1 - x))
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s


def interpolate_sequence(f, new_n):
    """Interpolate sequence to new length preserving normalization."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp


def evaluate_safe(a):
    """Evaluate sequence safely."""
    try:
        a_list = [float(max(0.0, min(1000.0, x))) for x in a]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')


def score_of(a):
    """Compute the objective value for a normalized non-negative sequence."""
    n = len(a)
    b = fast_convolve(a)
    return 2.0 * n * b.max()
```
