2. Solve `min_v { g · v : v >= 0, sum(v) = 1 }` → optimal is `v = e_j` where `j = argmin(g)`
3. Update: `f = (1-t) * f + t * v` where `t` is chosen by line search or `t = 2/(k+2)`

This is simple and efficient! Each iteration is O(n log n) for the convolution + O(n) for the cross-correlation + O(n) for the update.

But Frank-Wolfe converges slowly (1/k rate). However, for our purposes (getting a good enough solution in limited time), it might be fine, especially with a smooth approximation.

def softmax(x):
    x = x - x.max()
    e = np.exp(x)
    return e / e.sum()

def soft_max(b, temp):
    b_scaled = b / temp
    b_scaled = b_scaled - b_scaled.max()
    return temp * np.log(np.sum(np.exp(b_scaled)))

def project_simplex(v, target_sum=1.0):
    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho_vals = np.arange(1, n + 1)
    cond = u * rho_vals > (cssv - target_sum)
    if not cond.any():
        return np.full(n, target_sum / n)
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - target_sum) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)
