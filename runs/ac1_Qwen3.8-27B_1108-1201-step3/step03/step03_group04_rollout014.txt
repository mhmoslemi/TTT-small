`= 2 * sum_k w_k * a[k-j]`

This is a weighted sum of shifted-and-reversed versions of a, with weights given by the softmax of the convolution!

This is actually a very clean gradient formula. Let me implement this.

For the constraint `sum(a) = 1, a >= 0`, I'll use projection onto the simplex.

Actually, let me use a penalty approach: minimize `f(a) + mu * (sum(a) - 1)^2` with `a >= 0`. Or use the simplex projection directly.

Let me go with: minimize `f_T(a)` subject to `a >= 0, sum(a) = 1`, using projected gradient with the softmax-smoothed max.

Algorithm:
```
a = initial (on simplex)
for t = 1, 2, ...:
    conv = fast_convolve(a)
    w = softmax(T * conv / max(conv))  # weights for each lag
    grad[j] = 2 * sum_k w[k] * a[k-j]  (for valid k-j)
    a = project_simplex(a - lr_t * grad)
    periodically recompute T (anneal)
```

The learning rate should decay, e.g., lr_t = c / sqrt(t) or lr_t = c / t.

Let me also think about the **LP oracle** approach more carefully. The LP oracle gives the Frank-Wolfe direction. The standard FW convergence rate is O(1/t), which means after T iterations, the gap is O(1/T). For a 1.5% improvement (from 1.507 to 1.5027), we might need many iterations.

Actually, the convergence rate of FW for minimizing a smooth convex function over a polytope is O(1/t). But our function is NOT convex (as I showed earlier, the Hessian of a^T P a is 2P which is indefinite). So FW might not converge to the global optimum.

However, the LP oracle still gives a useful direction: it finds the best "linear" improvement at each step. This is essentially the "linearized" FW, which works well in practice even for non-convex problems.

Let me combine both approaches:
1. Use LP-based FW for the main optimization (handles non-convexity well)
2. Use smoothed gradient for polishing (can escape certain local minima)
3. Use perturbations to explore different basins

"""
Minimize 2*n*max(conv(a,a))/(sum(a))^2 using a combination of:
1. LP-based Frank-Wolfe (primary driver)
2. Smoothed subgradient polishing (softmax of convolution peaks)
3. Multi-length scanning and diverse initializations
4. Perturbation-based restarts to escape local minima
"""

import numpy as np
import time
from scipy.optimize import linprog
from scipy.sparse import csr_matrix


def fast_convolve(a, b=None):
    """Linear convolution via FFT."""
    if b is None:
        b = a
    n = len(a)
    m = len(b)
    size = n + m - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    B = np.fft.rfft(b, fft_size)
    return np.fft.irfft(A * B, fft_size)[:size]


def build_conv_matrix(a):
    """Build sparse matrix A such that (A @ b)[k] = conv(a,b)[k]."""
    n = len(a)
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        for j in range(j_start, j_end + 1):
            rows.append(k)
            cols.append(j)
            vals.append(a[k - j])
    return csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))


def lp_oracle(a, M, time_limit=3.0):
    """Solve LP: max sum(b) s.t. conv(a,b) <= M, b >= 0."""
    n = len(a)
    A = build_conv_matrix(a)
    c_obj = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    res = linprog(c_obj, A_ub=A, b_ub=b_ub, method='highs', bounds=bounds,
                  options={'presolve': True, 'time_limit': time_limit})
    if res.success and res.x is not None:
        return np.maximum(res.x, 0.0)
    return None


def project_simplex(v):
    """Project v onto the probability simplex (sum=1, all >= 0)."""
    n = len(v)
    if v.sum() < 1e-15:
        return np.ones(n) / n
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)


def smooth_subgradient(a, T=30.0):
    """Compute smoothed subgradient of max(conv(a,a)) using softmax weighting."""
    n = len(a)
    conv = fast_convolve(a)
    # Softmax weights over convolution lags
    conv_shifted = conv - conv.max()
    w = np.exp(T * conv_shifted)
    total = w.sum()
    if total < 1e-30:
        w = np.zeros(len(conv))
        w[np.argmax(conv)] = 1.0
    else:
        w /= total
    
    # Gradient: grad[j] = 2 * sum_k w[k] * a[k-j] for valid k-j
    g = np.zeros(n)
    for k in range(len(conv)):
        if w[k] < 1e-12:
            continue
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        idx = np.arange(j_start, j_end + 1)
        g[idx] += 2.0 * w[k] * a[k - idx]
    return g


def fw_lp_optimize(a0, time_limit, verbose=False):
    """LP-based Frank-Wolfe with adaptive M and standard step size."""
    n = len(a0)
    a = np.maximum(a0.copy(), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    conv = fast_convolve(a)
    M = float(conv.max())
    best_obj = 2.0 * n * M
    best_a = a.copy()

    t0 = time.monotonic()
    it = 0
    stall = 0
    max_stall = 100
    gamma = 1.0  # step scaling

    while time.monotonic() - t0 < time_limit:
        # Solve LP oracle
        b = lp_oracle(a, M, time_limit=min(3.0, max(0.5, time_limit - (time.monotonic() - t0))))
        if b is None:
            break
        sb = b.sum()
        if sb < 1e-15:
            break
        b = b / sb

        # Standard FW step size: 2/(it+2), scaled by gamma
        t_step = gamma * 2.0 / (it + 2)
        t_step = min(t_step, 1.0)
        
        a_new = (1 - t_step) * a + t_step * b
        conv_new = fast_convolve(a_new)
        M_new = float(conv_new.max())
        
        if M_new < M - 1e-12:
            a = a_new
            M = M_new
            cur_obj = 2.0 * n * M
            if cur_obj < best_obj - 1e-14:
                best_obj = cur_obj
                best_a = a.copy()
            stall = 0
        else:
            # Try smaller step
            t_step2 = t_step * 0.5
            a_try = (1 - t_step2) * a + t_step2 * b
            conv_try = fast_convolve(a_try)
            M_try = float(conv_try.max())
            if M_try < M - 1e-14:
                a = a_try
                M = M_try
                cur_obj = 2.0 * n * M
                if cur_obj < best_obj - 1e-14:
                    best_obj = cur_obj
                    best_a = a.copy()
                stall = 0
            else:
                stall += 1
        
        # Stagnation handling
        if stall >= max_stall:
            # Perturb and reset
            rng = np.random.default_rng(it * 7919 + 13)
            noise = rng.standard_normal(n) * 0.002 * (1 + stall / max_stall)
            a = project_simplex(a + noise)
            conv = fast_convolve(a)
            M = float(conv.max())
            stall = 0
            max_stall = int(max_stall * 1.5)
            gamma = max(0.3, gamma * 0.8)
        
        # Gradually reduce gamma
        if it % 200 == 0 and it > 0:
            gamma = max(0.2, gamma * 0.9)

        it += 1
        if verbose and it % 500 == 0:
            elapsed = time.monotonic() - t0
            print(f"    FW it={it}, obj={best_obj:.6f}, M={M:.4e}, gamma={gamma:.2f}, elapsed={elapsed:.1f}s")

    return best_a, best_obj


def subgradient_optimize(a0, time_limit, T_init=20.0, lr_init=0.01, verbose=False):
    """Polish with smoothed subgradient on the simplex."""
    n = len(a0)
    a = np.maximum(a0.copy(), 0.0)
    a = a / a.sum()

    conv = fast_convolve(a)
    best_obj = 2.0 * n * conv.max()
    best_a = a.copy()

    T = T_init
    lr = lr_init
    v = np.zeros(n)  # momentum
    mu = 0.9  # momentum coefficient
    t0 = time.monotonic()
    it = 0

    while time.monotonic() - t0 < time_limit:
        g = smooth_subgradient(a, T)
        v = mu * v - lr * g
        a_new = project_simplex(a + v)
        a = a_new

        # Anneal T (increase for sharper peaks, but not too fast)
        T = min(T * 1.002, 200.0)
        lr *= 0.999

        conv = fast_convolve(a)
        cur_obj = 2.0 * n * conv.max()
        if cur_obj < best_obj - 1e-14:
            best_obj = cur_obj
            best_a = a.copy()

        it += 1
        if verbose and it % 2000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    SG it={it}, obj={best_obj:.6f}, T={T:.1f}, lr={lr:.4e}, elapsed={elapsed:.1f}s")

    return best_a, best_obj


def generate_inits(n, parent, rng):
    """Generate diverse initializations."""
    inits = {}
    
    # Uniform
    inits['uniform'] = np.ones(n) / n
    
    # Linear ramp
    r = np.arange(1, n + 1, dtype=np.float64)
    r /= r.sum()
    inits['ramp'] = r.copy()
    
    # Reverse ramp
    inits['ramp_rev'] = r[::-1].copy()
    
    # Quadratic ramp (more edge-concentrated)
    q = np.arange(1, n + 1, dtype=np.float64) ** 2
    q /= q.sum()
    inits['quad_ramp'] = q.copy()
    
    # Triangle
    x = np.arange(n, dtype=np.float64)
    tri = np.minimum(x + 1, n - x)
    tri /= tri.sum()
    inits['triangle'] = tri.copy()
    
    # Edge concentrated (first and last 20%)
    edge = max(1, n // 5)
    ec = np.zeros(n)
    ec[:edge] = 1.0
    ec[-edge:] = 1.0
    ec /= ec.sum()
    inits['edge'] = ec.copy()
    
    # Strong edge (first and last 10%)
    edge2 = max(1, n // 10)
    ec2 = np.zeros(n)
    ec2[:edge2] = 1.0
    ec2[-edge2:] = 1.0
    ec2 /= ec2.sum()
    inits['edge_strong'] = ec2.copy()
    
    # Gaussian
    g = np.exp(-0.5 * ((x - 0.5 * (n - 1)) / (0.4 * n)) ** 2)
    g /= g.sum()
    inits['gauss'] = g.copy()
    
    # Sine pattern
    sine = np.abs(np.sin(np.pi * x / n))
    sine /= sine.sum()
    inits['sine'] = sine.copy()
    
    # Random
    inits['random'] = rng.dirichlet(np.ones(n) * 0.3)
    
    # Spiky random
    spiky = rng.random(n)
    spiky[spiky < 0.7] = 0.0
    if spiky.sum() < 1e-10:
        spiky = rng.dirichlet(np.ones(n))
    else:
        spiky /= spiky.sum()
    inits['spiky'] = spiky.copy()
    
    # Alternating pattern (high-low-high-low)
    alt = np.ones(n)
    alt[1::2] = 0.3
    alt /= alt.sum()
    inits['alternating'] = alt.copy()
    
    # Parent
    if parent is not None and len(parent) > 0:
        if len(parent) == n:
            pp = np.maximum(parent, 0.0)
            ps = pp.sum()
            if ps > 1e-10:
                inits['parent'] = pp / ps
        else:
            pp = np.interp(np.linspace(0, 1, n),
                           np.linspace(0, 1, len(parent)),
                           np.maximum(parent, 0.0))
            ps = pp.sum()
            if ps > 1e-10:
                inits['parent_interp'] = pp / ps
    
    return inits

"""
Minimize 2*n*max(conv(a,a))/(sum(a))^2 using a hybrid of:
1. LP-based Frank-Wolfe (primary optimizer with exact linearization oracle)
2. Smoothed subgradient method (softmax-weighted gradient for polishing)
3. Multi-length scanning with diverse initializations
4. Adaptive perturbation restarts to escape local minima
Key improvements over previous: better step-size scheduling, softmax gradient
with annealed temperature, faster LP oracle usage, and smarter restart strategy.
"""

import numpy as np
import time
from scipy.optimize import linprog
from scipy.sparse import csr_matrix


def fast_convolve(a, b=None):
    """Linear convolution via FFT."""
    if b is None:
        b = a
    n = len(a)
    m = len(b)
    size = n + m - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    B = np.fft.rfft(b, fft_size)
    return np.fft.irfft(A * B, fft_size)[:size]


def build_conv_matrix(a):
    """Build sparse matrix A such that (A @ b)[k] = conv(a,b)[k]."""
    n = len(a)
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        for j in range(j_start, j_end + 1):
            rows.append(k)
            cols.append(j)
            vals.append(a[k - j])
    return csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))


def lp_oracle(a, M, time_limit=3.0):
    """Solve LP: max sum(b) s.t. conv(a,b) <= M, b >= 0."""
    n = len(a)
    A = build_conv_matrix(a)
    c_obj = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c_obj, A_ub=A, b_ub=b_ub, method='highs', bounds=bounds,
                      options={'presolve': True, 'time_limit': time_limit})
        if res.success and res.x is not None:
            return np.maximum(res.x, 0.0)
    except Exception:
        pass
    return None


def project_simplex(v):
    """Project v onto the probability simplex (sum=1, all >= 0)."""
    n = len(v)
    v = np.asarray(v, dtype=np.float64)
    if v.sum() < 1e-15:
        return np.ones(n) / n
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)


def smooth_subgradient(a, T=30.0):
    """Compute smoothed subgradient of max(conv(a,a)) using softmax weighting.
    
    grad[j] = 2 * sum_k w[k] * a[k-j] for valid k-j,
    where w[k] = softmax(T * (conv[k] - max_conv))[k]
    """
    n = len(a)
    conv = fast_convolve(a)
    conv_max = conv.max()
    conv_shifted = conv - conv_max
    w = np.exp(T * conv_shifted)
    total = w.sum()
    if total < 1e-30:
        w = np.zeros(len(conv))
        w[int(np.argmax(conv))] = 1.0
    else:
        w /= total

    g = np.zeros(n)
    for k in range(len(conv)):
        wk = w[k]
        if wk < 1e-10:
            continue
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        idx = np.arange(j_start, j_end + 1)
        g[idx] += 2.0 * wk * a[k - idx]
    return g


def fw_lp_optimize(a0, time_limit, verbose=False, verbose_every=300):
    """LP-based Frank-Wolfe with adaptive M and decaying step size."""
    n = len(a0)
    a = np.maximum(a0.copy(), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    conv = fast_convolve(a)
    M = float(conv.max())
    best_obj = 2.0 * n * M
    best_a = a.copy()

    t0 = time.monotonic()
    it = 0
    stall = 0
    max_stall = 80
    gamma = 1.0

    while time.monotonic() - t0 < time_limit:
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 1.0:
            break

        b = lp_oracle(a, M, time_limit=min(4.0, max(0.3, remaining * 0.1)))
        if b is None:
            break
        sb = b.sum()
        if sb < 1e-15:
            break
        b = b / sb

        # FW step size with decay
        t_step = gamma * 2.0 / (it + 2)
        t_step = min(t_step, 1.0)

        a_new = (1 - t_step) * a + t_step * b
        conv_new = fast_convolve(a_new)
        M_new = float(conv_new.max())

        if M_new < M - 1e-13:
            a = a_new
            M = M_new
            cur_obj = 2.0 * n * M
            if cur_obj < best_obj - 1e-14:
                best_obj = cur_obj
                best_a = a.copy()
            stall = 0
        else:
            # Try half step
            t_step2 = t_step * 0.4
            a_try = (1 - t_step2) * a + t_step2 * b
            conv_try = fast_convolve(a_try)
            M_try = float(conv_try.max())
            if M_try < M - 1e-13:
                a = a_try
                M = M_try
                cur_obj = 2.0 * n * M
                if cur_obj < best_obj - 1e-14:
                    best_obj = cur_obj
                    best_a = a.copy()
                stall = 0
            else:
                stall += 1

        # Stagnation handling: perturb along subgradient direction
        if stall >= max_stall:
            # Use subgradient direction for smarter perturbation
            sg = smooth_subgradient(a, T=10.0)
            rng = np.random.default_rng(it * 104729 + 7)
            noise = rng.standard_normal(n) * 0.001 * (1.0 + stall / max_stall)
            a = project_simplex(a - 0.01 * sg + noise)
            conv = fast_convolve(a)
            M = float(conv.max())
            stall = 0
            max_stall = int(max_stall * 1.4)
            gamma = max(0.2, gamma * 0.85)

        # Slowly decay gamma
        if it % 300 == 0 and it > 0:
            gamma = max(0.15, gamma * 0.88)

        it += 1
        if verbose and it % verbose_every == 0:
            elapsed = time.monotonic() - t0
            print(f"    FW it={it}, obj={best_obj:.6f}, M={M:.4e}, gamma={gamma:.3f}, elapsed={elapsed:.1f}s")

    return best_a, best_obj


def subgradient_optimize(a0, time_limit, T_init=15.0, lr_init=0.008, momentum=0.92, verbose=False, verbose_every=3000):
    """Polish with annealed smoothed subgradient on the simplex."""
    n = len(a0)
    a = np.maximum(a0.copy(), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    conv = fast_convolve(a)
    best_obj = 2.0 * n * conv.max()
    best_a = a.copy()

    T = T_init
    lr = lr_init
    v = np.zeros(n)
    t0 = time.monotonic()
    it = 0

    while time.monotonic() - t0 < time_limit:
        g = smooth_subgradient(a, T)
        v = momentum * v - lr * g
        a_new = project_simplex(a + v)
        a = a_new

        # Anneal temperature (sharpen peak focus over time)
        T = min(T * 1.001, 100.0)
        lr *= 0.9995

        conv = fast_convolve(a)
        cur_obj = 2.0 * n * conv.max()
        if cur_obj < best_obj - 1e-14:
            best_obj = cur_obj
            best_a = a.copy()

        it += 1
        if verbose and it % verbose_every == 0:
            elapsed = time.monotonic() - t0
            print(f"    SG it={it}, obj={best_obj:.6f}, T={T:.1f}, lr={lr:.4e}, elapsed={elapsed:.1f}s")

    return best_a, best_obj


def generate_inits(n, parent, rng):
    """Generate diverse initializations of length n."""
    inits = {}
    x = np.arange(n, dtype=np.float64)

    # Uniform
    inits['uniform'] = np.ones(n) / n

    # Linear ramp
    r = np.arange(1, n + 1, dtype=np.float64)
    r /= r.sum()
    inits['ramp'] = r.copy()
    inits['ramp_rev'] = r[::-1].copy()

    # Quadratic (more edge-heavy)
    q = (np.arange(1, n + 1, dtype=np.float64)) ** 2
    q /= q.sum()
    inits['quad_ramp'] = q.copy()

    # Triangle
    tri = np.minimum(x + 1, n - x)
    tri /= tri.sum()
    inits['triangle'] = tri.copy()

    # Edge concentrated (20%)
    edge = max(2, n // 5)
    ec = np.zeros(n)
    ec[:edge] = 1.0
    ec[-edge:] = 1.0
    ec /= ec.sum()
    inits['edge'] = ec.copy()

    # Strong edge (10%)
    edge2 = max(2, n // 10)
    ec2 = np.zeros(n)
    ec2[:edge2] = 1.0
    ec2[-edge2:] = 1.0
    ec2 /= ec2.sum()
    inits['edge_strong'] = ec2.copy()

    # Very strong edge (5%)
    edge3 = max(2, n // 20)
    ec3 = np.zeros(n)
    ec3[:edge3] = 1.0
    ec3[-edge3:] = 1.0
    ec3 /= ec3.sum()
    inits['edge_5'] = ec3.copy()

    # Gaussian center
    g = np.exp(-0.5 * ((x - 0.5 * (n - 1)) / (0.35 * n)) ** 2)
    g /= g.sum()
    inits['gauss'] = g.copy()

    # Sine envelope
    sine = np.abs(np.sin(np.pi * (x + 0.5) / n))
    sine /= sine.sum()
    inits['sine'] = sine.copy()

    # Alternating (high-low pattern)
    alt = np.ones(n)
    alt[1::2] = 0.2
    alt /= alt.sum()
    inits['alternating'] = alt.copy()

    # Random
    inits['random'] = rng.dirichlet(np.ones(n) * 0.4)

    # Spiky
    spiky = rng.random(n)
    spiky[spiky < 0.6] = 0.0
    if spiky.sum() < 1e-10:
        spiky = rng.dirichlet(np.ones(n))
    else:
        spiky /= spiky.sum()
    inits['spiky'] = spiky.copy()

    # Bimodal (two peaks)
    bim = np.exp(-0.5 * ((x - 0.25 * n) / (0.1 * n)) ** 2) + np.exp(-0.5 * ((x - 0.75 * n) / (0.1 * n)) ** 2)
    bim /= bim.sum()
    inits['bimodal'] = bim.copy()

    # Parent
    if parent is not None and len(parent) > 0:
        if len(parent) == n:
            pp = np.maximum(parent, 0.0)
            ps = pp.sum()
            if ps > 1e-10:
                inits['parent'] = pp / ps
        else:
            pp = np.interp(np.linspace(0, 1, n),
                           np.linspace(0, 1, len(parent)),
                           np.maximum(parent, 0.0))
            ps = pp.sum()
            if ps > 1e-10:
                inits['parent_interp'] = pp / ps

    return inits
