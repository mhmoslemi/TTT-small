- The update direction should decrease the objective while staying on the simplex.

For multiplicative updates (mirror descent with entropic mirror):
a_new[i] = a[i] * exp(-eta * h[i]) / Z

where h is the subgradient and Z is the normalizer.

For small eta, this approximates:
a_new[i] ≈ a[i] * (1 - eta * h[i]) / (1 - eta * sum_j a[j]*h[j])

= a[i] * (1 - eta * h[i]) / (1 - eta * h·a)

Since h·a = sum_j a[j] * h[j] = sum_j a[j] * 4n * (shifted_a)[j] = 4n * b[k*] (by definition of convolution!)

Wait: sum_j a[j] * (shifted_a)[j] where (shifted_a)[j] = a[k*-j] + a[j-k*].
= sum_j a[j]*a[k*-j] + sum_j a[j]*a[j-k*]
= b[k*] + b[k*] = 2*b[k*]

So h·a = 4n * 2 * b[k*] = 8n * b[k*]

And the normalizer Z = 1 - eta * h·a = 1 - 8n*eta*b[k*]

So: a_new[i] = a[i] * (1 - eta * 4n * (shifted_a)[i]) / (1 - 8n*eta*b[k*])

This is a closed-form update! And it's very efficient to compute (just shift a and scale).

Let me verify: at convergence, we want a_new = a, which means:
(1 - eta * 4n * (shifted_a)[i]) / (1 - 8n*eta*b[k*]) = 1
=> 1 - eta * 4n * (shifted_a)[i] = 1 - 8n*eta*b[k*]
=> (shifted_a)[i] = 2*b[k*] for all i

This means a[k*-i] + a[i-k*] = 2*b[k*] for all i, which is a system of linear equations.

OK so this is a well-defined optimization. Let me now think about the step size eta.

The constraint is that a_new ≥ 0, so we need:
1 - eta * 4n * (shifted_a)[i] ≥ 0 for all i
=> eta ≤ 1 / (4n * max_i (shifted_a)[i])

And for the normalizer to be positive:
1 - 8n*eta*b[k*] > 0
=> eta < 1 / (8n*b[k*])

The optimal eta minimizes the resulting objective. Since the update is a closed-form function of eta, we can do a 1D line search.

But actually, for Nesterov acceleration, we need to be more careful. Let me use a simpler approach first:

**Simple multiplicative gradient descent:**
1. Compute b = autocorr(a), k* = argmax b
2. Compute h[i] = 4n * (a[max(0,k*-i) if k*-i >= 0 else -1] + a[max(0,i-k*) if i-k* >= 0 else -1])
   Actually, h[i] = 4n * (a[k*-i] if 0 ≤ k*-i < n else 0 + a[i-k*] if 0 ≤ i-k* < n else 0)
3. a_new[i] = a[i] * (1 - eta * h[i]) / (1 - eta * sum_j a[j]*h[j])
4. Clip to non-negative, renormalize

**Nesterov version:**
Maintain y (the "lookahead" point) and x (the actual iterate).
1. Compute gradient at y
2. x_new = multiplicative_update(y, eta)
3. y_new = x_new + momentum * (x_new - x)
4. Clip and normalize

Actually, for multiplicative updates, Nesterov is a bit different. Let me use a simpler acceleration scheme.

Wait, this is O(n^2) per iteration because of the h computation loop. I need to vectorize it.

The h computation: h[i] = 4n * (y[k*-i] if 0 ≤ k*-i < n else 0 + y[i-k*] if 0 ≤ i-k* < n else 0)

This is: h[i] = 4n * (y_flipped[i] + y_shifted[i]) where:
- y_flipped[i] = y[k*-i] if 0 ≤ k*-i < n, i.e., i ranges from max(0, k*-n+1) to min(n-1, k*)
  Actually, y[k*-i] is valid when 0 ≤ k*-i < n, i.e., k*-n+1 ≤ i ≤ k*
- y_shifted[i] = y[i-k*] if 0 ≤ i-k* < n, i.e., i ranges from k* to k*+n-1

So:
h[i] = 4n * y[k*-i] for i ∈ [max(0,k*-n+1), min(n-1,k*)]  [first term]
h[i] = 4n * y[i-k*] for i ∈ [max(0,k*), min(n-1,k*+n-1)]  [second term]

This is O(n) and vectorized. 

Now, the full autocorrelation computation is O(n log n) via FFT. So per iteration, we have O(n log n) work.

For n = 1600, FFT takes about 1600 * 11 ≈ 17600 operations (roughly). The h computation is 1600 operations. So per iteration we do ~20000 operations, which means we can do millions of iterations in 1800 seconds.

But wait, the FFT is the bottleneck. For n=1600, fft_size = 4096 (next power of 2 ≥ 3199). A 4096-point FFT takes roughly 4096 * 12 = 49152 floating point operations. With NumPy's optimized FFT, this should take about 5-10 microseconds. So per iteration we can do about 100-200 microseconds, meaning about 5000-10000 iterations per second.

In 1800 seconds, we can do about 9-18 million iterations. That's plenty.

But will it converge fast enough? The convergence rate of gradient descent on a quadratic is O(1/(t * (L-μ))) where L is the smoothness constant and μ is the strong convexity. For Nesterov, it's O(1/(t^2 * (L-μ))).

The "quadratic" here is b[k*](a) = sum_i a[i]*a[k*-i], which is a quadratic form with matrix T_{k*} (the k*-th shift of the identity convolution). The eigenvalues of T_{k*} are... well, it's a banded matrix, so the condition number depends on the bandwidth.

Actually, since k* changes as we iterate, the effective quadratic changes, making convergence analysis harder. But in practice, Nesterov should still work well.

Let me also think about an alternative: since the gradient is a shifted copy of a, the update a - eta*g is a linear operation. We can think of it as:

a_new = (I - 4n*eta*S_{k*}) @ a

where S_{k*} is the shift operator that maps a to (a[k*-i] + a[i-k*])_i.

This is a linear iteration! If k* were fixed, we'd be iterating a linear map. The convergence would depend on the spectral radius of this map.

But k* changes, so it's not a simple linear iteration. However, if we track k* and it stabilizes, we get a linear iteration and can analyze convergence.

```python
"""
Minimizes 2*n*max(convolve(a,a))/(sum(a))^2 using:
1. Nesterov-accelerated multiplicative gradient descent (O(n log n) per iter)
2. Active-set tracking for efficient gradient computation
3. Pair coordinate descent for local polish
4. Multi-length interpolation and exploration
5. Perturbation-based restarts
"""

import numpy as np
import time
from scipy.fft import rfft, irfft


def fast_autocorr(a):
    """Compute full linear autocorrelation (convolve a with itself) via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]


def compute_subgradient(a, k_star):
    """Compute subgradient of max_k b[k] at k_star. O(n) vectorized."""
    n = len(a)
    h = np.zeros(n)
    # Term 1: a[k_star - i] for valid i
    lo1 = max(0, k_star - n + 1)
    hi1 = min(n, k_star + 1)
    if hi1 > lo1:
        h[lo1:hi1] += a[k_star - np.arange(lo1, hi1)]
    # Term 2: a[i - k_star] for valid i
    lo2 = max(0, k_star)
    hi2 = min(n, k_star + n)
    if hi2 > lo2:
        h[lo2:hi2] += a[np.arange(lo2, hi2) - k_star]
    return h


def nesterov_multiplicative_optimize(a0, time_limit, verbose=True, seed=0):
    """
    Nesterov-accelerated multiplicative gradient descent on the simplex.
    Minimizes max_k b[k] where b = convolve(a,a), subject to a >= 0, sum(a) = 1.
    """
    rng = np.random.default_rng(seed)
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    best_b = fast_autocorr(a)
    best_max = best_b.max()
    
    x = a.copy()  # Current iterate
    y = a.copy()  # Nesterov lookahead
    
    t0 = time.monotonic()
    t = 0
    no_improve = 0
    stall_limit = 500
    
    # Adaptive step size
    eta = 0.5  # Initial step size (will be adaptive)
    
    while time.monotonic() - t0 < time_limit:
        t += 1
        
        # Compute autocorrelation at lookahead point y
        b_y = fast_autocorr(y)
        k_star = int(np.argmax(b_y))
        
        # Compute subgradient at y
        h = compute_subgradient(y, k_star)
        
        # Adaptive step size: ensure factors stay positive
        max_h = h.max()
        if max_h < 1e-15:
            break
        eta_max = 0.9 / max_h  # Keep factors > 0.1
        eta = min(eta, eta_max * 0.8)
        
        # Multiplicative update from x
        factors = 1.0 - eta * h
        factors = np.maximum(factors, 0.0)
        Z = np.dot(x, factors)
        if Z < 1e-15:
            eta *= 0.5
            continue
        
        x_new = x * factors / Z
        
        # Nesterov extrapolation
        if t <= 1:
            y_new = x_new.copy()
        else:
            momentum = (t - 1.0) / (t + 1.0)  # Nesterov momentum
            # Cap momentum for stability
            momentum = min(momentum, 0.95)
            y_new = x_new + momentum * (x_new - x)
            y_new = np.maximum(y_new, 0.0)
            s_y = y_new.sum()
            if s_y < 1e-15:
                y_new = x_new.copy()
            else:
                y_new = y_new / s_y
        
        x = x_new
        y = y_new
        
        # Check improvement (every 10 iterations to save time)
        if t % 10 == 0 or t <= 5:
            b_x = fast_autocorr(x)
            max_x = b_x.max()
            if max_x < best_max:
                best_max = max_x
                best_a = x.copy()
                no_improve = 0
                # Increase eta slightly when improving
                eta = min(eta * 1.05, 0.8 / max_h if max_h > 0 else 0.5)
            else:
                no_improve += 1
                # Decrease eta when stalled
                eta *= 0.95
        
        # Restart if stalled
        if no_improve > stall_limit:
            y = best_a.copy()
            x = best_a.copy()
            eta = 0.5
            no_improve = 0
            if verbose and t % 10000 == 0:
                elapsed = time.monotonic() - t0
                print(f"    NM restart at t={t} ({elapsed:.0f}s), best={best_max:.10f}")
        
        if verbose and t % 10000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    NM t={t} ({elapsed:.0f}s): best={best_max:.10f}, eta={eta:.4f}")
    
    return best_a, best_max


def pair_coordinate_descent(a0, time_limit, rng, verbose=True):
    """Pair swap coordinate descent with line search on the simplex."""
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return a, float('inf')
    a = a / s
    
    conv = fast_autocorr(a)
    best_score = conv.max()
    best_a = a.copy()
    t0 = time.monotonic()
    
    no_improve_passes = 0
    
    while time.monotonic() - t0 < time_limit:
        pass_improved = False
        perm = rng.permutation(n)
        
        for idx in perm:
            if time.monotonic() - t0 > time_limit:
                    break
            i = idx
            ai = a[i]
            if ai < 1e-12:
                continue
            
            # Try moving mass from i to a random j
            j = int(rng.integers(n))
            if j == i:
                continue
            
            # Line search: try a few fractions of moving mass
            # Moving delta from i to j: a[i]-=delta, a[j]+=delta
            # Try: delta = alpha * ai for alpha in {0.1, 0.25, 0.5, 0.75, 0.9}
            best_delta = 0.0
            best_conv_max = conv.max()
            
            for alpha in [0.05, 0.1, 0.2, 0.3, 0.5, 0.7, 0.9]:
                delta = alpha * ai
                a[i] = ai - delta
                a[j] = a[j] + delta
                # Don't renormalize (sum is preserved)
                c = fast_autocorr(a)
                c_max = c.max()
                if c_max < best_conv_max - 1e-14:
                    best_conv_max = c_max
                    best_delta = delta
                a[j] = a[j] - delta
                a[i] = ai
            
            if best_delta > 0:
                a[i] -= best_delta
                a[j] += best_delta
                conv = fast_autocorr(a)
                if conv.max() < best_score - 1e-14:
                    best_score = conv.max()
                    best_a = a.copy()
                    pass_improved = True
        
        if not pass_improved:
            no_improve_passes += 1
            if no_improve_passes >= 5:
                break
        else:
            no_improve_passes = 0
        
        if verbose:
            elapsed = time.monotonic() - t0
            print(f"    PCD ({elapsed:.0f}s): best={best_score:.10f}")
    
    return best_a, best_score


def structured_init(n, rng):
    """Generate a structured initial sequence (sum=1)."""
    choice = rng.integers(0, 10)
    x = np.linspace(0.0, 1.0, n)
    if choice == 0:
        a = np.cos(np.pi * x / 2.0) ** 2
    elif choice == 1:
        a = np.sin(np.pi * x) ** 1.5
    elif choice == 2:
        a = 0.5 + 0.3 * np.cos(2 * np.pi * x) + 0.15 * np.cos(5 * np.pi * x)
    elif choice == 3:
        a = np.exp(-6.0 * (x - 0.3) ** 2) + 0.7 * np.exp(-6.0 * (x - 0.7) ** 2)
    elif choice == 4:
        a = (1.0 - np.abs(2.0 * x - 1.0)) ** 3
    elif choice == 5:
        a = 0.3 + 0.7 * np.sin(np.pi * x) ** 0.7
    elif choice == 6:
        a = 1.0 + 0.3 * np.cos(4 * np.pi * x) + 0.1 * np.cos(8 * np.pi * x)
    elif choice == 7:
        a = np.sin(np.pi * x) ** 0.5 * (1 + 0.2 * np.cos(6 * np.pi * x))
    elif choice == 8:
        # Symmetric smooth
        a = np.exp(-4 * (x - 0.5) ** 2) + 0.3 * np.exp(-8 * (x - 0.2) ** 2) + 0.3 * np.exp(-8 * (x - 0.8) ** 2)
    else:
        a = 1.0 / (1.0 + 5.0 * np.abs(x - 0.5))  # Lorentzian-like
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s


def interpolate_sequence(f, new_n):
    """Interpolate a sequence to a new length (preserving sum=1)."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss


def perturb_sequence(a, rng, scale=0.05):
    """Add multiplicative noise and renormalize (preserving sum=1)."""
    n = len(a)
    noise = 1.0 + scale * rng.standard_normal(n)
    noise = np.maximum(noise, 0.1)
    a_pert = a * noise
    s = a_pert.sum()
    if s < 1e-15:
        return a.copy()
    return a_pert / s


def evaluate_safe(a):
    """Call the authoritative evaluator."""
    try:
        a_list = [float(max(0, x)) for x in a]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')


def additive_nesterov_optimize(a0, time_limit, verbose=False, seed=0):
    """
    Nesterov-accelerated additive gradient descent with projection onto simplex.
    Faster than multiplicative version since projection is O(n log n).
    """
    rng = np.random.default_rng(seed)
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    best_b = fast_autocorr(a)
    best_max = best_b.max()
    
    x = a.copy()
    y = a.copy()
    
    t0 = time.monotonic()
    t = 0
    no_improve = 0
    
    # Step size (for the gradient of 2n * max b[k])
    # Gradient is 4n * h where h is the shifted a
    # So step = eta / (4n) effectively
    L = 4.0 * n  # Lipschitz constant (rough)
    eta = 1.0 / L  # Initial step size
    
    while time.monotonic() - t0 < time_limit:
        t += 1
        
        b_y = fast_autocorr(y)
        k_star = int(np.argmax(b_y))
        
        # Subgradient of 2n*max b[k] = 2n * 2 * h = 4n * h
        h = compute_subgradient(y, k_star)
        grad = 4.0 * n * h
        
        # Additive update with Nesterov
        # x_new = proj_simplex(y - eta * grad)
        v = y - eta * grad
        # Project onto {a >= 0, sum(a) = 1}
        # Binary search for tau such that sum(max(v - tau, 0)) = 1
        v_sorted = np.sort(v)[::-1]
        cssv = np.cumsum(v_sorted)
        rho = np.nonzero(v_sorted * np.arange(1, n + 1) > (cssv - 1))[0]
        if len(rho) > 0:
            rho = rho[-1]
            theta = (cssv[rho] - 1.0) / (rho + 1.0)
            x_new = np.maximum(v - theta, 0.0)
        else:
            x_new = np.ones(n) / n
        
        # Nesterov momentum
        if t <= 1:
            y_new = x_new.copy()
        else:
            momentum = min((t - 1.0) / (t + 1.0), 0.95)
            y_new = x_new + momentum * (x_new - x)
            # Project y_new onto simplex
            yn_sorted = np.sort(y_new)[::-1]
            css = np.cumsum(yn_sorted)
            rho2 = np.nonzero(yn_sorted * np.arange(1, n + 1) > (css - 1))[0]
            if len(rho2) > 0:
                rho2 = rho2[-1]
                theta2 = (css[rho2] - 1.0) / (rho2 + 1.0)
                y_new = np.maximum(y_new - theta2, 0.0)
            else:
                y_new = np.ones(n) / n
            
            # Ensure sum = 1
            s_yn = y_new.sum()
            if s_yn > 1e-15 and abs(s_yn - 1.0) > 1e-10:
                y_new = y_new / s_yn
        
        x = x_new
        y = y_new
        
        if t % 20 == 0 or t <= 5:
            b_x = fast_autocorr(x)
            max_x = b_x.max()
            if max_x < best_max:
                best_max = max_x
                best_a = x.copy()
                no_improve = 0
            else:
                no_improve += 1
                if no_improve % 100 == 0:
                    eta *= 0.9
        
        if no_improve > 2000:
            y = best_a.copy()
            x = best_a.copy()
            eta = 1.0 / (4.0 * n)
            no_improve = 0
        
        if verbose and t % 50000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    AN t={t} ({elapsed:.0f}s): best={best_max:.10f}")
    
    return best_a, best_max
```

Minimizes 2*n*max(convolve(a,a))/(sum(a))^2 using:
1. Nesterov-accelerated multiplicative gradient descent with hard subgradient (O(n log n)/iter)
2. Smoothed softmax gradient refinement (O(n^2)/iter)
3. Pair coordinate descent polish
4. Multi-length interpolation and perturbation restarts

import numpy as np
import time
from scipy.fft import rfft, irfft


def fast_autocorr(a):
    """Compute full linear autocorrelation convolve(a,a) via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]


def compute_subgradient(a, k_star):
    """O(n) subgradient of max_k b[k] at k_star. Returns h where grad = 4n*h."""
    n = len(a)
    h = np.zeros(n)
    lo1 = max(0, k_star - n + 1)
    hi1 = min(n, k_star + 1)
    if hi1 > lo1:
        h[lo1:hi1] += a[k_star - np.arange(lo1, hi1)]
    lo2 = max(0, k_star)
    hi2 = min(n, k_star + n)
    if hi2 > lo2:
        h[lo2:hi2] += a[np.arange(lo2, hi2) - k_star]
    return h

    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    best_b = fast_autocorr(a)
    best_max = best_b.max()
    
    x = a.copy()
    y = a.copy()
    
    t0 = time.monotonic()
    t = 0
    no_improve = 0
    eta = 1.0  # Will be scaled by 1/(4n)

        t += 1
        b_y = fast_autocorr(y)
        k_star = int(np.argmax(b_y))
        h = compute_subgradient(y, k_star)
        
        # Gradient of 2n*max b[k] is 4n*h, so effective step is eta/(4n)
        step = eta / (4.0 * n)
        max_h = h.max()
        if max_h > 1e-15:
            step = min(step, 0.9 / (4.0 * n * max_h))
        
        factors = 1.0 - step * (4.0 * n) * h
        factors = np.maximum(factors, 0.0)
        Z = np.dot(x, factors)
        if Z < 1e-15:
            step *= 0.5
            continue
        x_new = x * factors / Z
        
        if t <= 2:
            y_new = x_new.copy()
        else:
            mu = min((t - 1.0) / (t + 1.0), 0.95)
            y_new = x_new + mu * (x_new - x)
            y_new = np.maximum(y_new, 0.0)
            sy = y_new.sum()
            if sy > 1e-15:
                y_new = y_new / sy
            else:
                y_new = x_new.copy()
        
        x = x_new
        y = y_new
        
        if t % 5 == 0:
            bx = fast_autocorr(x)
            mx = bx.max()
            if mx < best_max:
                best_max = mx
                best_a = x.copy()
                no_improve = 0
            else:
                no_improve += 1
                if no_improve % 50 == 0:
                    eta *= 0.9
        
        if no_improve > 500:
            y = best_a.copy()
            x = best_a.copy()
            eta = 1.0
            no_improve = 0
        
        if verbose and t % 5000 == 0:
            print(f"    HS t={t} ({time.monotonic()-t0:.0f}s): best={best_max:.10f}")
    
    return best_a, best_max
