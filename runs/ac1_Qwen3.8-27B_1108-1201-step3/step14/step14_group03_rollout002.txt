Wait, let me reconsider. For k = n-1:
`(a*a)_{n-1} = sum_{j=0}^{n-1} a_j * a_{n-1-j}`

= 1 if j = m and l = n-1-m, or j = n-1-m and l = m
= 1 if j+l = n-1 (for the cross terms, counted twice)

Actually wait, I want to reconsider the local search one more time. The key insight for speed is:

When I move mass δ from position i to position j, the convolution changes as follows:
- For each k in [0, 2n-2]:
  - The change is: δ * (a_{k-j} - a_{k-i}) + δ * (a_{k-j} - a_{k-i}) [cross terms, if i≠j]
  - More precisely: the change in (a*a)_k is:
    - -δ * a_{k-i} (from the term where the first index is i)
    - -δ * a_{k-i} (from the term where the second index is i) [if k-i ≠ i]
    - +δ * a_{k-j} (from the term where the first index is j)  
    - +δ * a_{k-j} (from the term where the second index is j) [if k-j ≠ j]
    - Plus second-order terms: -δ^2 (if k = 2i), +δ^2 (if k = 2j), etc.

So the change Δ_k is:
- For k in [i, i+n-1] ∩ [j, j+n-1]: Δ_k = 2δ(a_{k-j} - a_{k-i}) + (quadratic terms)
- For k in [i, i+n-1] \ [j, j+n-1]: Δ_k = -2δ*a_{k-i}
- For k in [j, j+n-1] \ [i, i+n-1]: Δ_k = 2δ*a_{k-j}
- Otherwise: Δ_k = 0

The new max is: max(max of unaffected positions, max of affected positions with Δ applied).

If I precompute the "second max" (max excluding the peak), then:
- New max = max(second_max_unaffected, max over affected positions of (conv[k] + Δ_k))

This is O(n) to compute (just iterate over the affected range), which is much faster than O(n log n) FFT.

But I need to be careful about the "unaffected" max. If the peak is at an affected position, I need to recompute the max over all positions.
