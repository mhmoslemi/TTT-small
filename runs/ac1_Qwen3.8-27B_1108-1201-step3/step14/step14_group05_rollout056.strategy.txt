## Approach and Rational

The goal is to design a step function with minimized maximum autocorrelation relative to its norm. The previous code achieved an upper bound of approximately 1.504346, and the target is to beat this to reach 1.5027 or lower. My approach involves creating a novel hybrid optimization method combining both gradient-based and stochastic search strategies.

Key rationale:
1. Use a mathematical formulation that bridges continuous optimization and combinatorial search.
2. Leverage the fact that spending more adjustment time (~50 T) on high-quality solutions (those already close to the target) is more beneficial than randomly exploring.
3. Employ adaptive stoch2 for both greedy steps and global exploration.

This method will:
- Use a combination of"ATSolver"s (accelerated time steps) and stochastic optimization.
- Monitor adjustment costs and solutions' quality.
- Proceed in iterations that first explore with stochastic methods then escalate to smart optimizations.

## Mathematical Specification

We will solve the minimization problem:

Minimize: `score = 2 * n * max(convolve(a, a)) / (sum(a)) ** 2`

Subject to:
- `a_i >= 0` for each i
- `sum(a) >= 0.01`

Where `convolve(a, a)` is the linear convolution (mode="full") of the sequence a.

We formulate two variations of the problem:

1. **Normalized Formulation**: The ratio to minimize is equivalent to just minimizing `max(convolve(a, a))` when we set `sum(a) = sqrt(2*n)`. This removes the homogeneous dependence on scaling.

2. **Iterative Refinement with Score Projection**: Even better is to not fix n but search over a grid of possibilities. However, since our previous record was for n=1600, we will focus on this near-optimal length and use projection techniques.

def evaluate_sequence(sequence: list[float]) -> float:
    """Evaluates a sequence of coefficients with security checks.
    Returns np.inf if input is invalid."""
    n = len(sequence)
    if n < 2:  # degenerate case, sum might be zero?
        return np.inf
    
    # Convert to float array safely
    arr = np.asarray(sequence)
    if not arr.flags.writeable or not np.allclose(arr, arr.astype(float)):
        return np.inf
    
    T = np.zeros((2*n-1, n))
    for j in range(n):
        T[j:j+n, j] = arr

    # Convert to float and ensure non-negativity
    b_seq = T @ arr
    max_b = np.max(b_seq)
    
    sum_a = np.sum(arr)
    if sum_a < 0.01:  # invalid normalization
        return np.inf
        
    score = float(2 * n * max_b / (sum_a ** 2))
    return score
