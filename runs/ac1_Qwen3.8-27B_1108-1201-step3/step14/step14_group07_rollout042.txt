Now, for the LP, the key is speed. Let me think about the structure:

The LP is:
max 1'b
subject to: T @ b <= M * 1
             b >= 0

where T is the (2n-1) × n matrix with T[k,i] = a[max(0, k-i)] if |k-i| < n, else 0.

Wait, let me be more precise. The constraint is (f * b)_k <= M for all k.
(f * b)_k = Σ_i f[i] * b[k-i] (summing over valid i)
= Σ_i f[k-i] * b[i] (reindexing, summing over valid i where both k-i and i are in [0, n-1])

So T[k, i] = f[k-i] if 0 <= k-i <= n-1, else 0.
Equivalently: T[k, i] = f[k-i] if max(0, k-(n-1)) <= i <= min(n-1, k), else 0.

The sparsity pattern: for each row k, the nonzeros are in columns max(0, k-n+1) to min(n-1, k).
- For k < n-1: columns 0 to k (k+1 nonzeros)
- For k >= n-1: columns k-n+1 to n-1 (2n-1-k nonzeros)

Total nonzeros: Σ_{k=0}^{n-2} (k+1) + Σ_{k=n-1}^{2n-2} (2n-1-k) = n(n-1)/2 + n(n-1)/2 = n(n-1) ≈ n².

For n=1600: about 2.56 million nonzeros. That's manageable.

Let me think about a different approach entirely. What if instead of LP, I use a "water-filling" approach?

The best response problem is:
max 1'b subject to (f*b)_k <= M, b >= 0

This is a max-flow / max-closure type problem. The dual is:
min M * 1'y + 0'b' subject to T'y + b' >= 1, y >= 0, b' >= 0

Which simplifies to: min M * Σy_k subject to T'y >= 1, y >= 0
= min M * Σy_k subject to Σ_k T[k,i]*y_k >= 1 for all i, y >= 0

The dual variable y_k corresponds to the constraint (f*b)_k <= M. At the optimum, y_k > 0 only for binding constraints (where (f*b)_k = M).

So the primal solution b* is determined by which constraints are binding. This is the "active set" approach mentioned in the state of the art.

In practice, solving the LP gives us both the active set and the solution. The LP is the right tool.

Let me focus on making the overall algorithm more effective:

**Key insight for improvement**: The previous algorithm might be spending too much time on the LP formulation (building the dense matrix) rather than solving it. Let me precompute the sparsity structure and reuse it.

Also, I notice that the LP matrix T changes every iteration (because it depends on the current `a`). But the sparsity PATTERN is fixed. So I can precompute the row/col indices once and just update the values.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Fast LP best-response with precomputed sparsity + Nesterov acceleration
2. Adaptive step size with backtracking line search
3. Subgradient polishing (directly target the maximum autocorrelation peak)
4. Multi-length exploration
5. LSE smooth minimization with L-BFGS-B at low temperatures
6. Final fine-tuned coordinate descent
Key improvements: sparse LP with pattern reuse, subgradient method,
adaptive Nesterov, better time allocation, and multi-start.

import numpy as np
import cvxpy as cp
import time
from scipy.fft import rfft, irfft
from scipy.optimize import minimize as scipy_minimize
from scipy.sparse import lil_matrix, csr_matrix

_global_solver = None

def get_solver():

    if _global_solver is not None:
        return _global_solver
    for s in [cp.CLARABEL, cp.MOSEK, cp.ECOS, cp.SCS]:
        try:
            x = cp.Variable(10, nonneg=True)
            prob = cp.Problem(cp.Minimize(cp.sum(x)), [cp.sum(x) == 1])
            prob.solve(solver=s)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                _global_solver = s
                print(f"  LP solver: {s}")
                return s
        except Exception:

    _global_solver = cp.ECOS
    print("  LP solver (fallback): ECOS")
    return _global_solver


def fast_autocorr(a):

    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), n=fft_size)
    return irfft(A * A, fft_size)[:size]


def evaluate_safe(a):

def build_conv_matrix_sparse(n):
    """Build the sparsity pattern for the convolution constraint matrix.
    Returns row_indices, col_indices for the (2n-1) x n matrix T.
    T[k, i] = a[k-i] if 0 <= k-i <= n-1 (values filled in later).
    """
    rows = []
    cols = []
    for k in range(2 * n - 1):
        i_start = max(0, k - (n - 1))
        i_end = min(n - 1, k)
        for i in range(i_start, i_end + 1):
            rows.append(k)
            cols.append(i)
    return np.array(rows), np.array(cols)


def lp_best_response(a, M, solver, row_idx, col_idx):
    """Solve the LP: max sum(b) s.t. T@b <= M, b >= 0.
    T[k,i] = a[k-i] for valid (k,i).
    """
    n = len(a)
    size = 2 * n - 1
    b_var = cp.Variable(n, nonneg=True)
    
    # Build the matrix values
    vals = np.zeros(len(row_idx))
    for idx in range(len(row_idx)):
        k = row_idx[idx]
        i = col_idx[idx]
        vals[idx] = a[k - i]
    
    T = csr_matrix((vals, (row_idx, col_idx)), shape=(size, n))
    constraints = [T @ b_var <= M]
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        return None
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None
    b_val = np.asarray(b_var.value, dtype=np.float64)
    if b_val is None:
        return None
    b_val = np.maximum(b_val, 0.0)
    s = b_val.sum()
    if s < 1e-15:
        return None
    return b_val


def nesterov_lp_optimize(a0, time_limit, solver, verbose=False):
    """Nesterov-accelerated LP best-response iteration."""
    n = len(a0)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s0 = a.sum()
    if s0 < 1e-15:
        a = np.ones(n) * norm / n
    else:
        a = a * norm / s0

    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    
    # Precompute sparsity pattern
    row_idx, col_idx = build_conv_matrix_sparse(n)
    
    y = a.copy()
    t0 = time.monotonic()
    n_iters = 0
    no_improve = 0
    
    for t in range(1, 100000):
        if time.monotonic() - t0 > time_limit:
            break
        
        M_curr = fast_autocorr(y).max()
        if M_curr < 1e-12:
            break
        
        b = lp_best_response(y, M_curr, solver, row_idx, col_idx)
        if b is None:
            continue
        
        b_sum = b.sum()
        if b_sum < 1e-15:
            continue
        g = b * norm / b_sum
        n_iters += 1
        
        # Nesterov step with adaptive momentum
        alpha = 2.0 / (t + 2.0)
        y_new = (1.0 - alpha) * y + alpha * g
        y_new = np.maximum(y_new, 0.0)
        s_y = y_new.sum()
        if s_y < 1e-15:
            y_new = y.copy()
        else:
            y_new = y_new * norm / s_y
        
        if t == 1:
            a_new = g.copy()
        else:
            momentum = (t - 1.0) / (t + 2.0)
            a_new = y_new + momentum * (y_new - y)
            a_new = np.maximum(a_new, 0.0)
            s_a = a_new.sum()
            if s_a < 1e-15:
                a_new = y_new.copy()
            else:
                a_new = a_new * norm / s_a
        
        y = y_new
        a = a_new
        
        score_y = fast_autocorr(y).max()
        if score_y < best_score:
            best_score = score_y
            best_a = y.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        score_a = fast_autocorr(a).max()
        if score_a < best_score:
            best_score = score_a
            best_a = a.copy()
            no_improve = 0
        
        if no_improve > 200:
            if verbose:
                print(f"    Stalling at iter={n_iters}, best={best_score:.8f}")
            # Restart from best
            y = best_a.copy()
            a = best_a.copy()
            no_improve = 0
            if t > 5000:
                break
        
        if verbose and n_iters % 50 == 0:
            elapsed = time.monotonic() - t0
            print(f"    LP iter={n_iters} ({elapsed:.0f}s): best={best_score:.8f}")
    
    return best_a, best_score


def lse_objective_and_grad(a_flat, n, T_temp):

        return 1e10, np.zeros(n)

    max_b = b.max()
    if max_b < 1e-15:
        return 1e10, np.zeros(n)
    exp_vals = np.exp(T_temp * (b - max_b))
    lse = max_b + np.log(exp_vals.sum()) / T_temp
    obj = 2.0 * n * lse / (s * s)

def build_conv_sparsity(n):
    """Build sparsity pattern for the (2n-1) x n convolution constraint matrix."""
    rows = np.concatenate([np.arange(max(0, k - (n - 1)), min(n - 1, k) + 1) for k in range(2 * n - 1)])
    cols = np.concatenate([np.full(min(n - 1, k) + 1 - max(0, k - (n - 1)), k - i) for k in range(2 * n - 1) for i in range(max(0, k - (n - 1)), min(n - 1, k) + 1)])
    # Simpler: just build row and col indices
    row_list = []
    col_list = []
    for k in range(2 * n - 1):
        i_start = max(0, k - (n - 1))
        i_end = min(n - 1, k)
        for i in range(i_start, i_end + 1):
            row_list.append(k)
            col_list.append(i)
    return np.array(row_list, dtype=int), np.array(col_list, dtype=int)


def lp_best_response(a, M, solver, row_idx, col_idx):
    """Solve LP: max sum(b) s.t. T@b <= M, b >= 0."""
    n = len(a)
    size = 2 * n - 1
    b_var = cp.Variable(n, nonneg=True)
    vals = a[row_idx - col_idx]
    T = csr_matrix((vals, (row_idx, col_idx)), shape=(size, n))
    constraints = [T @ b_var <= M]
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        return None
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None
    b_val = np.asarray(b_var.value, dtype=np.float64)
    if b_val is None:
        return None
    b_val = np.maximum(b_val, 0.0)
    if b_val.sum() < 1e-15:
        return None
    return b_val


def nesterov_lp_optimize(a0, time_limit, solver, verbose=False):
    """Nesterov-accelerated LP best-response with adaptive restarts."""
    n = len(a0)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s0 = a.sum()
    if s0 < 1e-15:
        a = np.ones(n) * norm / n
    else:
        a = a * norm / s0

    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    row_idx, col_idx = build_conv_sparsity(n)
    y = a.copy()
    t0 = time.monotonic()
    n_iters = 0
    no_improve = 0
    best_score_history = []

    for t in range(1, 200000):
        if time.monotonic() - t0 > time_limit:
            break

        M_curr = fast_autocorr(y).max()
        if M_curr < 1e-12:
            break

        b = lp_best_response(y, M_curr, solver, row_idx, col_idx)
        if b is None:
            no_improve += 1
            if no_improve > 50:
                y = best_a.copy()
                no_improve = 0
            continue

        b_sum = b.sum()
        if b_sum < 1e-15:
            continue
        g = b * norm / b_sum
        n_iters += 1

        alpha = 2.0 / (t + 2.0)
        y_new = (1.0 - alpha) * y + alpha * g
        y_new = np.maximum(y_new, 0.0)
        s_y = y_new.sum()
        if s_y < 1e-15:
            y_new = y.copy()
        else:
            y_new = y_new * norm / s_y

        if t == 1:
            a_new = g.copy()
        else:
            momentum = (t -1.0) / (t + 2.0)
            a_new = y_new + momentum * (y_new - y)
            a_new = np.maximum(a_new, 0.0)
            s_a = a_new.sum()
            if s_a < 1e-15:
                a_new = y_new.copy()
            else:
                a_new = a_new * norm / s_a

        y = y_new
        a = a_new

        score_y = fast_autocorr(y).max()
        if score_y < best_score:
            best_score = score_y
            best_a = y.copy()
            no_improve = 0
            best_score_history.append(best_score)
        else:
            no_improve += 1

        score_a = fast_autocorr(a).max()
        if score_a < best_score:
            best_score = score_a
            best_a = a.copy()
            no_improve = 0
            best_score_history.append(best_score)

        # Adaptive restart
        if no_improve > 150:
            if verbose:
                print(f"    Restart at iter={n_iters}, best={best_score:.8f}")
            y = best_a.copy()
            a = best_a.copy()
            no_improve = 0
            t = 1  # Reset momentum
            if n_iters > 3000 and no_improve > 200:
                if verbose:
                    print(f"    Breaking after extended stall at iter={n_iters}")
                break

        if verbose and n_iters % 20 == 0:
            elapsed = time.monotonic() - t0
            print(f"    LP iter={n_iters} ({elapsed:.0f}s): best={best_score:.8f}")

    return best_a, best_score


def subgradient_polish(a0, time_limit, verbose=False):
    """Polish using subgradient of the max autocorrelation peak."""
    n = len(a0)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s0 = a.sum()
    if s0 < 1e-15:
        a = np.ones(n) * norm / n
    else:
        a = a * norm / s0

    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(42)
    step_size = 0.01
    patience = 0

    for it in range(50000):
        if time.monotonic() - t0 > time_limit:
            break

        b = fast_autocorr(a)
        max_b = b.max()

        # Find peaks (within 1% of max)
        threshold = max_b * 0.99
        peak_indices = np.where(b >= threshold)[0]
        n_peaks = len(peak_indices)
        if n_peaks == 0:
            break

        # Compute subgradient
        # grad[i] = (1/n_peaks) * sum_{k in peaks} (a[k-i] if 0<=k-i<n + a[i-k] if 0<=i-k<n)
        fft_sz = 1 << (3 * n - 2).bit_length()
        a_p = np.zeros(fft_sz)
        a_p[:n] = a
        w_p = np.zeros(fft_sz)
        w_p[peak_indices] = 1.0 / n_peaks

        A_f = rfft(a_p, fft_sz)
        W_f = rfft(w_p, fft_sz)

        # term1[i] = sum_k w[k] * a[k-i]
        term1 = irfft(np.conj(A_f) * W_f, fft_sz)[:n]
        # term2[i] = sum_k w[k] * a[i-k]
        term2 = irfft(A_f * np.conj(W_f), fft_sz)[:n]

        grad_conv = term1 + term2

        # Full objective gradient: d(2n*max_b/S^2)/da
        s = a.sum()
        # We want to move in direction that reduces max_b while keeping S fixed
        # Project gradient onto the constraint sum(a) = norm
        grad_obj = grad_conv - np.mean(grad_conv) * a / a.sum() * 0  # just use grad_conv direction
        # Actually: minimize 2n*max_b / S^2. Gradient = (2n/S^2)*grad_conv - 4n*max_b*a/S^3
        grad_full = (2.0 * n / (s * s)) * (grad_conv - 2.0 * max_b * a / s)

        # Normalize gradient
        g_norm = np.linalg.norm(grad_full)
        if g_norm < 1e-15:
            break
        grad_full = grad_full / g_norm

        # Line search
        best_step = step_size
        best_obj = max_b
        for trial_step in [step_size, step_size * 0.5, step_size * 0.2, step_size * 2.0]:
            a_trial = a - trial_step * grad_full * s / np.linalg.norm(a)
            a_trial = np.maximum(a_trial, 0.0)
            sa = a_trial.sum()
            if sa < 1e-10:
                continue
            a_trial = a_trial * norm / sa
            sc = fast_autocorr(a_trial).max()
            if sc < best_obj:
                best_obj = sc
                best_step = trial_step

        a_new = a - best_step * grad_full * s / (np.linalg.norm(a) + 1e-15)
        a_new = np.maximum(a_new, 0.0)
        sa = a_new.sum()
        if sa < 1e-10:
            a_new = a.copy()
        else:
            a_new = a_new * norm / sa

        score_new = fast_autocorr(a_new).max()
        if score_new < best_score - 1e-14:
            best_score = score_new
            best_a = a_new.copy()
            a = a_new
            patience = 0
            # Adaptive step: increase if making good progress
            step_size = min(step_size * 1.05, 0.05)
        else:
            patience += 1
            step_size *= 0.95
            if patience % 10 == 0:
                # Random perturbation to escape
                n_pert = max(1, n // 100)
                indices = rng.choice(n, size=n_pert, replace=False)
                a_trial = a.copy()
                a_trial[indices] *= rng.uniform(0.7, 1.3, n_pert)
                a_trial = np.maximum(a_trial, 0.0)
                st = a_trial.sum()
                if st > 1e-10:
                    a_trial = a_trial * norm / st
                    sc_trial = fast_autocorr(a_trial).max()
                    if sc_trial < best_score:
                        best_score = sc_trial
                        best_a = a_trial.copy()
                        a = a_trial

            if patience > 500:
                if verbose:
                    print(f"    Subgrad: stalled at score={best_score:.8f}")
                break

        if verbose and it % 100 == 0:
            elapsed = time.monotonic() - t0
            print(f"    Subgrad iter={it} ({elapsed:.0f}s): best={best_score:.8f}")

    return best_a, best_score


def lse_objective(x, n, T):
    """LSE smoothed objective."""
    a = np.maximum(x, 0.0)
    s = a.sum()
    if s < 1e-10:
        return 1e10
    b = fast_autocorr(a)
    max_b = b.max()
    if max_b < 1e-15:
        return 1e10
    exp_vals = np.exp(T * (b - max_b))
    lse = max_b + np.log(exp_vals.sum()) / T
    return 2.0 * n * lse / (s * s)


def lse_gradient(x, n, T):
    """Gradient of LSE smoothed objective."""
    a = np.maximum(x, 0.0)
    s = a.sum()
    if s < 1e-10:
        return np.zeros(n)
    b = fast_autocorr(a)
    max_b = b.max()
    if max_b < 1e-15:
        return np.zeros(n)
    exp_vals = np.exp(T * (b - max_b))
    w = exp_vals / exp_vals.sum()
    lse = max_b + np.log(exp_vals.sum()) / T

    # Gradient via FFT
    fft_sz = 1 << (3 * n - 2).bit_length()
    a_p = np.zeros(fft_sz)
    a_p[:n] = a
    w_p = np.zeros(fft_sz)
    w_p[:2 * n - 1] = w

    A_f = rfft(a_p, fft_sz)
    W_f = rfft(w_p, fft_sz)

    term1 = irfft(np.conj(A_f) * W_f, fft_sz)[:n]
    term2 = irfft(A_f * np.conj(W_f), fft_sz)[:n]
    grad_conv = (term1 + term2) / T

    obj_val = 2.0 * n * lse / (s * s)
    grad = (2.0 * n / (s * s)) * (grad_conv - 2.0 * lse * a / s)
    return grad


def lse_scipy_optimize(a0, time_limit, T_start=40.0, T_end=1.0, n_stages=6):
    """LSE-based optimization with L-BFGS-B."""
    n = len(a0)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s0 = a.sum()
    if s0 < 1e-15:
        a = np.ones(n) * norm / n
    else:
        a = a * norm / s0

    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()

    temps = np.geomspace(T_start, T_end, n_stages)
    for si, T in enumerate(temps):
        if time.monotonic() - t0 > time_limit:
            break
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 5:
            break
        stage_time = min(remaining / max(1, n_stages - si), 180.0)
        if stage_time < 5:
            break

        x0 = a.copy()

        def obj_func(x):
            return lse_objective(x, n, T)

        def grad_func(x):
            return lse_gradient(x, n, T)

        try:
            res = scipy_minimize(obj_func, x0, method='L-BFGS-B',
                                  jac=grad_func,
                                  bounds=[(0, None)] * n,
                                  options={'maxiter': 200, 'maxfun': 500,
                                           'ftol': 1e-12, 'gtol': 1e-10})
            if res.x is not None:
                a_cand = np.maximum(res.x, 0.0)
                sc = a_cand.sum()
                if sc > 1e-10:
                    a_cand = a_cand * norm / sc
                    score_c = fast_autocorr(a_cand).max()
                    if score_c < best_score:
                        best_score = score_c
                        best_a = a_cand.copy()
                        a = a_cand
        except Exception:
            pass

    return best_a, best_score


def coordinate_descent_polish(a0, time_limit, seed=42):
    """Targeted coordinate descent focusing on the worst peaks."""
    n = len(a0)
    rng = np.random.default_rng(seed)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s0 = a.sum()
    if s0 < 1e-15:
        a = np.ones(n) * norm / n
    else:
        a = a * norm / s0

    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()
    stall = 0

    while time.monotonic() - t0 < time_limit:
        b = fast_autocorr(a)
        top_peaks = np.argsort(b)[::-1][:8]
        improved = False

        for k_peak in top_peaks:
            js = max(0, k_peak - n + 1)
            je = min(n - 1, k_peak)
            idx = np.arange(js, je + 1)
            if len(idx) == 0:
                continue
            contrib = a[idx] * a[k_peak - idx]
            top_src = idx[np.argsort(contrib)[::-1][:4]]

            # Find good destinations (away from peaks)
            peak_mask = np.zeros(n, dtype=bool)
            for k2 in top_peaks[:4]:
                js2 = max(0, k2 - n + 1)
                je2 = min(n - 1, k2)
                peak_mask[js2:je2 + 1] = True
            candidates = np.where(~peak_mask)[0]
            if len(candidates) == 0:
                candidates = np.arange(n)
            candidates_sorted = candidates[np.argsort(a[candidates])][:3]

            for src in top_src:
                if a[src] < 1e-12:
                    continue
                for dst in candidates_sorted[:2]:
                    if dst == src:
                        continue
                    for frac in [0.02, 0.05, 0.1]:
                        amt = a[src] * frac
                        if amt < 1e-15:
                            continue
                        a_trial = a.copy()
                        a_trial[src] -= amt
                        a_trial[dst] += amt
                        if a_trial[src] < -1e-15:
                            continue
                        a_trial = np.maximum(a_trial, 0.0)
                        st = a_trial.sum()
                        if st < 1e-10:
                            continue
                        a_trial = a_trial * norm / st
                        score = fast_autocorr(a_trial).max()
                        if score < best_score - 1e-14:
                            a = a_trial
                            best_a = a_trial.copy()
                            best_score = score
                            stall = 0
                            improved = True
                            break
                    if improved:
                        break
                if improved:
                    break
            if improved:
                break

        if not improved:
            stall += 1
            if stall % 3 == 0:
                for _ in range(20):
                    i = rng.integers(n)
                    j = rng.integers(n)
                    if i == j or a[i] < 1e-12:
                        continue
                    frac = rng.uniform(0.02, 0.1)
                    amt = a[i] * frac
                    a_trial = a.copy()
                    a_trial[i] -= amt
                    a_trial[j] += amt
                    a_trial = np.maximum(a_trial, 0.0)
                    st = a_trial.sum()
                    if st < 1e-10:
                        continue
                    a_trial = a_trial * norm / st
                    score = fast_autocorr(a_trial).max()
                    if score < best_score - 1e-14:
                        a = a_trial
                        best_a = a_trial.copy()
                        best_score = score
                        stall = 0
                        improved = True
                        break
            if stall > 200:
                break

    return best_a, best_score


def interpolate_sequence(f, new_n):
    """Interpolate a sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n)
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n)
    return f_interp / ss


def structured_init(n, rng):
    """Generate a structured initial sequence."""
    choice = rng.integers(0, 6)
    if choice == 0:
        x = np.linspace(0.0, 1.0, n)
        a = np.sin(np.pi * x) ** 1.5
    elif choice == 1:
        x = np.linspace(0.0, 2.0 * np.pi, n)
        a = 0.5 + 0.3 * np.cos(2.0 * x) + 0.15 * np.cos(5.0 * x) + 0.05 * np.cos(9.0 * x)
    elif choice == 2:
        x = np.linspace(0.0, 1.0, n)
        a = np.exp(-4.0 * (x - 0.3) ** 2) + 0.7 * np.exp(-4.0 * (x - 0.7) ** 2)
    elif choice == 3:
        center = n // 2
        idx = np.arange(n) - center
        sigma = n / 4.0
        a = np.exp(-0.5 * (idx / sigma) ** 2)
    elif choice == 4:
        x = np.linspace(0.0, 1.0, n)
        a = 1.0 + 0.2 * np.sin(6.0 * np.pi * x)
    else:
        a = np.ones(n) / n
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s


def propose_candidate(seed=42, budget_s=1800.0):
    """Main search function."""
    rng = np.random.default_rng(seed)
    t_global = time.monotonic()
    time_budget = min(float(budget_s) - 30.0, 1770.0)

    solver = get_solver()
    print(f"Time budget: {time_budget:.0f}s")

    best_seq = None
    best_score = float('inf')

    # Load parent if available
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            parent = p / p.sum()
            p_score = evaluate_safe(parent)
            print(f"Parent: n={len(parent)}, score={p_score:.6f}")
            best_seq = parent.copy()
            best_score = p_score
    except Exception:
        parent = None

    def do_try_update(a, label):
        nonlocal best_seq, best_score
        if a is None:
            return
        a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
        s = a.sum()
        if s < 0.01:
            return
        a = a / s
        sc = evaluate_safe(a)
        if np.isfinite(sc) and sc < best_score:
            best_score = sc
            best_seq = a.copy()
            elapsed = time.monotonic() - t_global
            print(f"  *** NEW BEST [{label}]: {sc:.6f} (n={len(a)}, t={elapsed:.0f}s)")

    # Phase 0: Quick multi-length scan
    print("\n=== Phase 0: Multi-length scan ===")
    n_parent = len(best_seq) if best_seq is not None else 1600
    scan_lengths = sorted(set([max(800, n_parent - 200), n_parent, n_parent + 200, n_parent + 400]))
    scan_results = {}

    for i_scan, n_scan in enumerate(scan_lengths):
        if time.monotonic() - t_global > time_budget * 0.10:
            break
        remaining_scan = time_budget * 0.10 - (time.monotonic() - t_global)
        if remaining_scan < 10:
            break
        scan_time = min(remaining_scan / max(1, len(scan_lengths) - i_scan), 80.0)
        if scan_time < 8:
            break

        if best_seq is not None:
            init_seq = interpolate_sequence(best_seq, n_scan)
        else:
            init_seq = structured_init(n_scan, rng)

        a_norm = init_seq * np.sqrt(2.0 * n_scan) / init_seq.sum()
        a_out, sc_out = nesterov_lp_optimize(a_norm, scan_time, solver, verbose=False)
        scan_results[n_scan] = (a_out, sc_out)
        print(f"  n={n_scan}: score={sc_out:.8f} ({time.monotonic()-t_global:.0f}s)")

    if scan_results:
        best_scan_n = min(scan_results, key=lambda k: scan_results[k][1])
        do_try_update(scan_results[best_scan_n][0], f"scan_n{best_scan_n}")

    if best_seq is None:
        n_base = 1600
        best_seq = structured_init(n_base, rng)
        best_score = evaluate_safe(best_seq)
        print(f"Default init: n={n_base}, score={best_score:.6f}")
    else:
        n_base = len(best_seq)

    # Phase 1: Deep LP at base length (main workhorse - 40% of time)
    remaining = time_budget - (time.monotonic() - t_global)
    print(f"\n=== Phase 1: Deep LP n={n_base} (budget={remaining:.0f}s) ===")
    t1 = remaining * 0.35
    a_norm = best_seq * np.sqrt(2.0 * n_base) / best_seq.sum()
    a_out, _ = nesterov_lp_optimize(a_norm, t1, solver, verbose=True)
    do_try_update(a_out, f"lp_deep_n{n_base}")

    # Phase 2: Subgradient polish
    remaining = time_budget - (time.monotonic() - t_global)
    n_best = len(best_seq)
    print(f"\n=== Phase 2: Subgradient polish n={n_best} (budget={remaining:.0f}s) ===")
    t2 = min(remaining * 0.15, 180.0)
    if t2 > 15:
        a_norm = best_seq * np.sqrt(2.0 * n_best) / best_seq.sum()
        a_out, _ = subgradient_polish(a_norm, t2, verbose=True)
        do_try_update(a_out, f"subgrad_n{n_best}")

    # Phase 3: LSE polish
    remaining = time_budget - (time.monotonic() - t_global)
    n_best = len(best_seq)
    print(f"\n=== Phase 3: LSE scipy n={n_best} (budget={remaining:.0f}s) ===")
    t3 = min(remaining * 0.15, 200.0)
    if t3 > 15:
        a_norm = best_seq * np.sqrt(2.0 * n_best) / best_seq.sum()
        a_out, _ = lse_scipy_optimize(a_norm, t3, T_start=30.0, T_end=1.0, n_stages=5)
        do_try_update(a_out, f"lse_n{n_best}")

    # Phase 4: Try longer length with LP
    n_long = n_base + 300
    remaining = time_budget - (time.monotonic() - t_global)
    print(f"\n=== Phase 4: LP n={n_long} (budget={remaining:.0f}s) ===")
    t4 = min(remaining * 0.15, 200.0)
    if t4 > 20:
        init_long = interpolate_sequence(best_seq, n_long)
        a_norm = init_long * np.sqrt(2.0 * n_long) / init_long.sum()
        a_out, _ = nesterov_lp_optimize(a_norm, t4, solver, verbose=True)
        do_try_update(a_out, f"lp_long_n{n_long}")

    # Phase 5: Subgradient polish again
    remaining = time_budget - (time.monotonic() - t_global)
    n_best = len(best_seq)
    print(f"\n=== Phase 5: Subgrad round 2 n={n_best} (budget={remaining:.0f}s) ===")
    t5 = min(remaining * 0.15, 200.0)
    if t5 > 15:
        a_norm = best_seq * np.sqrt(2.0 * n_best) / best_seq.sum()
        a_out, _ = subgradient_polish(a_norm, t5, verbose=True)
        do_try_update(a_out, f"subgrad2_n{n_best}")

    # Phase 6: Coordinate descent polish
    remaining = time_budget - (time.monotonic() - t_global)
    n_best = len(best_seq)
    print(f"\n=== Phase 6: Coord descent n={n_best} (budget={remaining:.0f}s) ===")
    t6 = min(remaining * 0.20, 300.0)
    if t6 > 10:
        a_norm = best_seq * np.sqrt(2.0 * n_best) / best_seq.sum()
        a_out, _ = coordinate_descent_polish(a_norm, t6, seed=12345)
        do_try_update(a_out, "coord_polish")

    # Phase 7: Final LSE + subgradient
    remaining = time_budget - (time.monotonic() - t_global)
    n_best = len(best_seq)
    print(f"\n=== Phase 7: Final polish n={n_best} (budget={remaining:.0f}s) ===")
    t7 = remaining * 0.5
    if t7 > 10:
        a_norm = best_seq * np.sqrt(2.0 * n_best) / best_seq.sum()
        a_out, _ = lse_scipy_optimize(a_norm, t7 * 0.4, T_start=15.0, T_end=0.5, n_stages=4)
        do_try_update(a_out, "lse_final")
        remaining2 = time_budget - (time.monotonic() - t_global)
        if remaining2 > 10:
            a_norm = best_seq * np.sqrt(2.0 * len(best_seq)) / best_seq.sum()
            a_out, _ = coordinate_descent_polish(a_norm, remaining2, seed=99999)
            do_try_update(a_out, "coord_final")

    # Final evaluation
    if best_seq is not None:
        fs = evaluate_safe(best_seq)
        if np.isfinite(fs):
            best_score = fs
        print(f"\nFINAL: score={best_score:.6f}, n={len(best_seq)}, time={time.monotonic()-t_global:.0f}s")
    else:
        print("\nERROR: No valid sequence found!")
        return [1.0]

    return [float(x) for x in best_seq]
