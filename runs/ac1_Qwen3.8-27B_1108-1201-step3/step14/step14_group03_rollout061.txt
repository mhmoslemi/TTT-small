    # Cross-correlation via FFT

    W = rfft(w, fft_size)
    A_rev = a[::-1]
    A = rfft(A_rev, fft_size)
    conv = irfft(W * A, fft_size)
    cross = conv[n-1 : 2*n-1]
    grad = 2.0 * cross
    return grad, c

def smoothed_objective(a, epsilon):
    c = fast_autocorr(a)
    c_max = c.max()
    val = epsilon * np.log(np.sum(np.exp((c - c_max) / epsilon))) + c_max
    return val

- Column player chooses k in {0, ..., 2n-2}
- Payoff to row player: (conv(a,a))_k / (sum(a))^2 (which is homogeneous, so we can set sum(a)=1 and payoff is (conv(a,a))_k)

The row player's best response to a distribution q over columns:
min_a sum_k q_k * (conv(a,a))_k = min_a a^T (sum_k q_k T_k) a

This is a QP (quadratic program) with the constraint a >= 0, sum(a) = 1.

The QP: min a^T Q a s.t. a >= 0, 1^T a = 1, where Q = sum_k q_k T_k.

The KKT conditions: 2Qa = 1*λ + μ - ν where μ >= 0 (for a >= 0) and ν is the dual of the sum constraint.

If Q is positive definite, the solution is:
a = Q^{-1}(1*λ + μ) / (1^T Q^{-1}(1*λ + μ))

This is expensive to compute (Q is n×n = 1600×1600).

But wait - Q = sum_k q_k T_k where T_k is the Toeplitz matrix for lag k. The sum is a Toeplitz matrix! So Q is a Toeplitz matrix, and we can use FFT for matrix-vector products.

The QP can be solved using conjugate gradients or L-BFGS with FFT-based matrix-vector products. Each matvec is O(n log n).

This is actually a much better approach than the LP! Let me elaborate:

**Algorithm: Mirror Descent with QP Best Response**

1. Start with a distribution q over lags (initially uniform)
2. Solve the QP: min a^T Q q a s.t. a >= 0, sum(a) = 1
   - Where Q q is a Toeplitz matrix
   - Use projected gradient or FISTA with FFT-based matvec
   - This gives the best response a*
3. Update q: q_k ∝ q_k * (conv(a*, a*))_k (multiplicative weights)
4. Normalize a* to get the new iterate
5. Repeat

This is the "multiplicative weights" or "regret minimization" algorithm applied to the game. It converges to the Nash equilibrium at rate O(sqrt(log(K)/T)) where K = 2n-1 is the number of lags.

The key advantage: each QP solve uses FFT-based matvec, which is O(n log n) per iterator. With FISTA, we can solve the QP to high accuracy in ~sqrt(n) iterations (each O(n log n)), giving O(n^{1.5} log n) per QP solve.
