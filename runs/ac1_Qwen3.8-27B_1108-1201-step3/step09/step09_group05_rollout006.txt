1. **SPSA** for broad exploration (it's derivative-free and works well for non-convex problems)
2. **Multiple restarts** with different initializations
3. **L-BFGS polish** from the best SPSA result
4. **Coordinate descent** for final refinement
5. **Multi-length exploration**

Let me now write the actual code. I'll focus on making SPSA effective:

For SPSA:
- Parameterize in log-space: `a_i = exp(z_i) / sum(exp(z_j))` (softmax)
- Use the standard SPSA update: `z_{t+1} = z_t - γ_t * G_t * d_t`
  where `G_t = (f(z_t + c_t * d_t) - f(z_t - c_t * d_t)) / (2 * c_t)`
  and `d_t` is a random ±1 vector
- Step sizes: `γ_t = a/(b+t)^α`, `c_t = c/(b+t)^κ`
- Typical values: `a=0.1, b=10, α=0.6, c=0.1, κ=0.6`

But wait, the softmax parameterization means we're optimizing over an unbounded space (z can be anything), which is good for SPSA.

However, the objective in z-space is:
`f(z) = 2*n*max_k (softmax(z) * softmax(z))_k / (sum(softmax(z)))^2`

But `sum(softmax(z)) = 1` by definition, so:
`f(z) = 2*n*max_k (a*a)_k` where `a = softmax(z)`

This is fine.

One issue: the softmax can have numerical issues when z values are very different. We can handle this by subtracting the max from z before exponentiating.

Let me also think about the dimension. If n=960, we have 959 effective degrees of freedom (since the softmax is invariant to adding a constant to all z). SPSA works well in high dimensions, so this should be fine.

Actually, for SPSA in high dimensions, we typically don't need to worry about the curse of dimensionality as much as for other methods, because each step only requires 2 function evaluations regardless of dimension.

Let me estimate: in 300 seconds, if each evaluation takes ~1ms (FFT convolution for n=960), we can do about 150,000 evaluations, which is 75,000 SPSA steps. That should be enough for good exploration.

Let me now write the complete code:

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. SPSA (Simultaneous Perturbation Stochastic Approximation) for global exploration in log-space
2. Nesterov-accelerated subgradient method with exact subgradient
3. Adaptive L-BFGS with dynamic log-sum-exp temperature (very low final T)
4. Coordinate descent with golden section on peak-contributing coordinates
5. Multi-length exploration with interpolation
6. Multi-start with diverse initializations
"""

import numpy as np
import time
from scipy.fft import rfft, irfft
from scipy.optimize import minimize


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def norm_sequence(a):
    """Normalize to sum=1, non-negative."""
    a = np.maximum(a, 0).astype(np.float64)
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s


def softmax_from_z(z):
    """Convert log-domain z to probability vector."""
    z_shifted = z - z.max()
    exp_z = np.exp(z_shifted)
    s = exp_z.sum()
    if s < 1e-300:
        return np.ones(len(z)) / len(z)
    return exp_z / s


def z_from_a(a):
    """Convert probability vector to log-domain."""
    return np.log(np.maximum(a, 1e-300))


def objective_from_a(a):
    """Compute 2*n*max(conv(a,a)) assuming sum(a)=1."""
    n = len(a)
    b = fast_convolve(a)
    return 2.0 * n * b.max()


def evaluate_safe(a):
    """Evaluate sequence safely using the global evaluate_sequence."""
    try:
        a_list = [float(max(0.0, min(1000.0, x))) for x in a]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')


def sspa_optimize(z0, time_limit, rng, a_coef=0.1, b_coef=20, alpha=0.6, c_coef=0.05, kappa=0.6, n_max_iters=200000):
    """SPSA optimization in log-space with softmax parameterization."""
    n = len(z0)
    z = z0.copy()
    t0 = time.monotonic()
    best_z = z.copy()
    best_f = objective_from_a(softmax_from_z(z))
    
    for t in range(n_max_iters):
        if time.monotonic() - t0 > time_limit:
            break
        
        gamma = a_coef / (b_coef + t) ** alpha
        c = c_coef / (b_coef + t) ** kappa
        
        d = rng.choice([-1.0, 1.0], size=n)
        
        a_plus = softmax_from_z(z + c * d)
        a_minus = softmax_from_z(z - c * d)
        
        f_plus = objective_from_a(a_plus)
        f_minus = objective_from_a(a_minus)
        
        G = (f_plus - f_minus) / (2.0 * c)
        
        z = z - gamma * G * d
        z = z - z.max()  # Center to prevent overflow
        
        f = objective_from_a(softmax_from_z(z))
        if f < best_f:
            best_f = f
            best_z = z.copy()
        
        if t % 5000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    SPSA t={t}, f={best_f:.6f}, elapsed={elapsed:.0f}s")
    
    return best_z, best_f


def nestsov_subgrad_optimize(a0, time_limit, n_max_iters=100000):
    """Nesterov-accelerated subgradient method on the simplex."""
    n = len(a0)
    a = norm_sequence(a0)
    z = z_from_a(a)
    y = a.copy()  # Nesterov momentum point
    best_a = a.copy()
    best_f = objective_from_a(a)
    t0 = time.monotonic()
    
    # Nesterov parameters
    beta_prev = 1.0
    a_nest = 0.5  # step size coefficient
    
    for t in range(1, n_max_iters + 1):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Compute subgradient at y
        b = fast_convolve(y)
        k_star = int(np.argmax(b))
        
        # Gradient of b_{k_star} w.r.t. a
        g = np.zeros(n)
        js = max(0, k_star - n + 1)
        je = min(n - 1, k_star)
        for i in range(js, je + 1):
            g[i] = y[k_star - i]
        # Fix the diagonal term
        if 2 * k_star % 2 == 0:
            j_diag = k_star // 2
            if 0 <= j_diag < n and 2 * j_diag == k_star:
                g[j_diag] = 2.0 * y[j_diag]  # Actually this is already handled
        
        # Actually, let me recompute the gradient properly
        # (a*a)_k = sum_i a_i * a_{k-i}
        # d/d a_j = a_{k-j} + a_j * [2j = k]
        # Wait, let's think again.
        # (a*a)_k = sum_i a_i * a_{k-i}
        # If we differentiate w.r.t. a_j:
        # - Term where i = j: a_j * a_{k-j}, derivative is a_{k-j}
        # - Term where k-i = j, i.e., i = k-j: a_{k-j} * a_j, derivative is a_{k-j}
        # If j = k-j (i.e., 2j = k), these are the same term, so derivative is just a_j (not 2*a_j)
        # If j != k-j, derivative is 2 * a_{k-j}
        # Wait no. Let me be very careful.
        # (a*a)_k = sum_{i=0}^{n-1} a_i * a_{k-i} (where a_m = 0 if m < 0 or m >= n)
        # d(a*a)_k / da_j:
        #   = sum_i [d(a_i)/da_j * a_{k-i} + a_i * d(a_{k-i})/da_j]
        #   = sum_i [δ_{i,j} * a_{k-i} + a_i * δ_{k-i,j}]
        #   = a_{k-j} + a_{k-j}  (first sum: i=j gives a_{k-j}; second sum: k-i=j means i=k-j gives a_{k-j})
        #   = 2 * a_{k-j}  (if 0 <= k-j < n and j != k-j)
        #   = a_{k-j}  (if 2j = k, because both terms are the same)
        #   = 0  (if k-j < 0 or k-j >= n)
        
        g = np.zeros(n)
        if 0 <= k_star - 0 < n:  # j=0
            pass
        for j in range(n):
            kj = k_star - j
            if 0 <= kj < n:
                if 2 * j == k_star:
                    g[j] = y[kj]  # = y[j]
                else:
                    g[j] = 2.0 * y[kj]
        
        # Step size
        eta = a_nest / np.sqrt(t)
        
        # Nesterov update
        beta_curr = (1.0 + np.sqrt(1.0 + 4.0 * beta_prev ** 2)) / 2.0
        
        # Update y in log-space
        z_y = z_from_a(y)
        z_y_new = z_y - eta * g / np.maximum(y, 1e-15)
        y_new = softmax_from_z(z_y_new)
        
        # Update a
        a_new = ((1.0 - 1.0/beta_curr) * a + (1.0/beta_curr) * y_new)
        a_new = norm_sequence(a_new)
        
        # Also update the z for y
        z = z_from_a(y_new)
        y = y_new
        a = a_new
        beta_prev = beta_curr
        
        f = objective_from_a(a)
        if f < best_f:
            best_f = f
            best_a = a.copy()
        
        if t % 5000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    Subgrad t={t}, f={best_f:.6f}, eta={eta:.6f}, elapsed={elapsed:.0f}s")
    
    return best_a, best_f


def lbgfs_refine(a0, time_limit, T_start=50.0, T_end=0.01, maxiter=10000, n_stages=None):
    """L-BFGS with LogSumExp smoothing and geometric temperature annealing."""
    n = len(a0)
    z = z_from_a(a0).copy()
    t0 = time.monotonic()
    
    if n_stages is None:
        n_stages = 12
    
    temps = np.geomspace(T_start, T_end, n_stages)
    iters_per_stage = max(50, maxiter // n_stages)
    
    for stage_T in temps:
        if time.monotonic() - t0 > time_limit:
            break
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 5:
            break
        
        def func(z_in):
            a = softmax_from_z(z_in)
            b = fast_convolve(a)
            Tb = stage_T * b
            max_Tb = Tb.max()
            exp_Tb = np.exp(Tb - max_Tb)
            log_sum_exp = max_Tb + np.log(exp_Tb.sum())
            return (2.0 * n / stage_T) * log_sum_exp
        
        def jac(z_in):
            a = softmax_from_z(z_in)
            b = fast_convolve(a)
            Tb = stage_T * b
            max_Tb = Tb.max()
            exp_Tb = np.exp(Tb - max_Tb)
            w = exp_Tb / exp_Tb.sum()
            grad_a = np.zeros(n)
            for k in range(len(b)):
                if w[k] < 1e-15:
                    continue
                js = max(0, k - n + 1)
                je = min(n - 1, k)
                idx = np.arange(js, je + 1)
                # Gradient of (a*a)_k w.r.t. a
                gk = np.zeros(n)
                for j in range(js, je + 1):
                    kj = k - j
                    if 2 * j == k:
                        gk[j] = a[kj]
                    else:
                        gk[j] = 2.0 * a[kj]
                grad_a += w[k] * gk
            
            S = np.dot(grad_a, a)
            return a * (grad_a - S)
        
        try:
            res = minimize(
                fun=func,
                x0=z,
                jac=jac,
                method='L-BFGS-B',
                options={'maxiter': iters_per_stage, 'ftol': 1e-20, 'gtol': 1e-16,
                         'maxfun': iters_per_stage * 500, 'disp': False}
            )
            z = res.x
        except Exception:
            pass
    
    return softmax_from_z(z)


def coord_descent_golden(a0, time_limit, n_steps=50000):
    """Coordinate descent with golden section search on peak-contributing coordinates."""
    n = len(a0)
    a = norm_sequence(a0)
    best_a = a.copy()
    best_f = objective_from_a(a)
    t0 = time.monotonic()
    no_improve = 0
    golden_ratio = (np.sqrt(5.0) - 1.0) / 2.0
    
    # Build coordinate importance ordering
    b = fast_convolve(a)
    k_star = int(np.argmax(b))
    imp = np.zeros(n)
    js = max(0, k_star - n + 1)
    je = min(n - 1, k_star)
    for j in range(js, je + 1):
        imp[j] = a[k_star - j]
    coord_order = np.argsort(imp)[::-1]
    
    for step in range(n_steps):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Refresh importance every 100 steps
        if step % 100 == 0:
            b = fast_convolve(a)
            k_star = int(np.argmax(b))
            imp = np.zeros(n)
            js = max(0, k_star - n + 1)
            je = min(n - 1, k_star)
            for j in range(js, je + 1):
                imp[j] = a[k_star - j]
            coord_order = np.argsort(imp)[::-1]
        
        improved = False
        # Try top 20 coordinates
        for ci in range(min(20, n)):
            i = coord_order[ci]
            if a[i] < 1e-14:
                continue
            
            # Golden section search on a[i] in [0, a[i] * 2]
            # (we can increase or decrease a[i], with redistribution)
            lo = 0.0
            hi = a[i] * 2.5
            c = hi - golden_ratio * (hi - lo)
            d = lo + golden_ratio * (hi - lo)
            
            def obj_1d(val):
                a_trial = a.copy()
                a_trial[i] = val
                # Redistribute the difference proportionally to other elements
                diff = a[i] - val
                mask = np.ones(n, dtype=bool)
                mask[i] = False
                if a[mask].sum() > 1e-15:
                    a_trial[mask] = a[mask] + diff * a[mask] / a[mask].sum()
                a_trial = np.maximum(a_trial, 0)
                s = a_trial.sum()
                if s < 1e-15:
                    return float('inf')
                a_trial = a_trial / s
                return objective_from_a(a_trial)
            
            fc = obj_1d(c)
            fd = obj_1d(d)
            
            for _ in range(30):
                if fc < fd:
                    hi = d
                    d = c
                    fd = fc
                    c = hi - golden_ratio * (hi - lo)
                    fc = obj_1d(c)
                else:
                    lo = c
                    c = d
                    fc = fd
                    d = lo + golden_ratio * (hi - lo)
                    fd = obj_1d(d)
            
            best_val = c if fc < fd else d
            best_1d_f = min(fc, fd)
            
            if best_1d_f < best_f - 1e-12:
                a_trial = a.copy()
                a_trial[i] = best_val
                diff = a[i] - best_val
                mask = np.ones(n, dtype=bool)
                mask[i] = False
                if a[mask].sum() > 1e-15:
                    a_trial[mask] = a[mask] + diff * a[mask] / a[mask].sum()
                a = norm_sequence(a_trial)
                best_f = best_1d_f
                best_a = a.copy()
                improved = True
        
        if not improved:
            no_improve += 1
            if no_improve > 50:
                break
        else:
            no_improve = 0
    
    return best_a, best_f


def multi_peak_gradient_descent(a0, time_limit, n_steps=50000, K=5):
    """Gradient descent using weighted combination of top-K peak gradients."""
    n = len(a0)
    a = norm_sequence(a0)
    best_a = a.copy()
    best_f = objective_from_a(a)
    t0 = time.monotonic()
    lr = 0.01
    no_improve = 0
    
    for step in range(n_steps):
        if time.monotonic() - t0 > time_limit:
            break
        
        b = fast_convolve(a)
        # Get top K peak values
        top_k_indices = np.argsort(b)[::-1][:K]
        top_k_vals = b[top_k_indices]
        
        # Exponential weights (sharper = more focus on max)
        weights = np.exp(top_k_vals * 20.0)
        weights = weights / weights.sum()
        
        # Combined gradient
        grad = np.zeros(n)
        for ki, w in zip(top_k_indices, weights):
            k = int(ki)
            for j in range(n):
                kj = k - j
                if 0 <= kj < n:
                    if 2 * j == k:
                        grad[j] += w * a[kj]
                    else:
                        grad[j] += w * 2.0 * a[kj]
        
        # Project gradient onto tangent space of simplex
        grad = grad - np.dot(grad, a) * a  # Project to remove component along a
        
        # Update in log-space
        z = z_from_a(a)
        z = z - lr * grad / np.maximum(a, 1e-10)
        a_new = softmax_from_z(z)
        
        # Adaptive learning rate
        f_new = objective_from_a(a_new)
        if f_new < best_f:
            best_f = f_new
            best_a = a_new.copy()
            a = a_new
            no_improve = 0
            lr = min(lr * 1.05, 0.1)
        else:
            no_improve += 1
            lr *= 0.9
            if no_improve > 100:
                break
    
    return best_a, best_f


def structured_init(n, rng, mode=0):
    """Create structured initial sequence."""
    if mode == 0:
        x = np.linspace(0, np.pi, n)
        a = np.cos(x / 2) ** 2
    elif mode == 1:
        x = np.linspace(-1, 1, n)
        a = np.exp(-x ** 2 * 3)
    elif mode == 2:
        x = np.linspace(0, 1, n)
        a = np.sin(np.pi * x) ** 1.5
    elif mode == 3:
        x = np.linspace(0, 1, n)
        a = np.exp(-6 * x * (1 - x))
    elif mode == 4:
        a = 0.5 + 0.5 * np.cos(2 * np.pi * np.linspace(0, 1, n))
        a = a ** 2
    elif mode == 5:
        x = np.linspace(0, 1, n)
        a = np.exp(-x * (1 - x) * 8) * (1 + 0.3 * np.cos(4 * np.pi * x))
    elif mode == 6:
        # Raised cosine (Hann window)
        x = np.linspace(0, 1, n)
        a = 0.5 * (1 + np.cos(2 * np.pi * x))
    elif mode == 7:
        # Flat top with smooth edges
        x = np.linspace(0, 1, n)
        a = np.ones(n)
        edge = n // 8
        for i in range(edge):
            t = i / edge
            a[i] = 0.5 * (1 - np.cos(np.pi * t))
            a[n-1-i] = 0.5 * (1 - np.cos(np.pi * t))
    else:
        a = np.ones(n) * (1 + 0.1 * np.sin(2 * np.pi * rng.random() * 3 * np.linspace(0, 1, n)))
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s


def interpolate_sequence(f, new_n):
    """Interpolate sequence to new length preserving normalization."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    f_norm = f / f.sum()
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp
