Actually, all we need is for the maximum lag to be minimized. The other lags don't matter as long as they're below the maximum.

So the "active set" of lags (those achieving the maximum) is what matters. If we can identify the active set, we can optimize for just those.

**Cutting-plane approach:**
1. Evaluate C₅ and find the worst lag k*
2. Add a constraint: corr[k*] ≤ C₅_current (or minimize corr[k*] directly)
3. Repeat

This is like Kelley's cutting plane method adapted for this problem.

In practice, with SLSQP, we can do:
1. Find worst lag k₁
2. Minimize corr[k₁] subject to constraints
3. Find new worst lag k₂
4. Minimize max(corr[k₁], corr[k₂]) subject to constraints
5. Continue...

This could be effective because at each step, we're adding a new "active" constraint.
