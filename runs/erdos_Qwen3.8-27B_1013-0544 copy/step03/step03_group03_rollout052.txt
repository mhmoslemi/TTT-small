2. Identify the active lines at t=1 (those with A_k + c_k = max(A_k + c_k))
3. The minimum is between the active lines at 0 and 1

- At t=0, the right derivative is c_{k0} where k0 = argmax A_k
- If c_{k0} ≤ 0, the minimum is at t=0
- At t=1, the left derivative is c_{k1} where k1 = argmax(A_k + c_k)
- If c_{k1} ≥ 0, the minimum is at t=1
- Otherwise, the minimum is in the interior, and we can bisection on the subgradient

The subgradient at t is the set {c_k : A_k + c_k*t = g(t)}. The function is decreasing as long as the max subgradient is negative, and increasing as long as the min subgradient is positive.

        if 0 <= i-lag < n:

    A = corr - h[i]*c

    # g(0) = max(A), g(1) = max(A+c)
    
    # Check boundaries
    if c[np.argmax(A)] <= 0:
        return 0.0  # minimum at t=0
    if c[np.argmax(A+c)] >= 0:
        return 1.0  # minimum at t=1
    
    # Interior: bisection on subgradient
    a, b = 0.0, 1.0
    for _ in range(50):  # more than enough for double precision
        mid = (a+b)/2
        vals = A + mid*c
        max_val = vals.max()
        # Subgradient: active indices are those where vals[m] ≈ max_val
        active = c[vals >= max_val - 1e-15]
        if active.min() >= 0:
            a = mid
        elif active.max() <= 0:
            b = mid
        else:
            break
    
    return (a+b)/2

    shifted = np.clip(beta*(corr-m), -700, 700)

def smooth_max_grad(h, dx, beta):
    corr = np.correlate(h, 1.0-h, mode='full')

            if 0 <= i-lag < n:
                d -= h[i-lag]
            grad[i] += w[m] * d
    return grad * dx
