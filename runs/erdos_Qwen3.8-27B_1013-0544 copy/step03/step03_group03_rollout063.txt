```python
    """Find optimal value of h[i] given all other coordinates fixed."""
    t_old = h[i]
    
    # Compute B[lag] = d(corr[lag])/dh[i] for all lags
    # corr[full_idx] corresponds to lag = full_idx - (n-1)
    # full_idx ranges from 0 to 2n-2
    
    # For coordinate i:
    # B[lag] = (1-h[i+lag])*[0<=i+lag<n] - h[i-lag]*[0<=i-lag<n]
    
    # And A[lag] = corr[lag] - t_old * B[lag]

    corr = np.correlate(h, 1.0 - h, mode='full')

    # full_idx = lag + (n-1)

            b -= h[i - lag]

    A = corr - t_old * B
    
    # Now minimize f(t) = dx * max(A + B*t) + lam*(t - t_old) over t in [0,1]
    # This is convex PWL.
    
    # Compute f(0) and f(1)
    f0 = dx * np.max(A) + lam * (0 - t_old)
    f1 = dx * np.max(A + B) + lam * (1 - t_old)
    
    # Check slopes at boundaries
    # f'(0+) = dx * max{B[k] : k in argmax(A)} + lam
    # f'(1-) = dx * min{B[k] : k in argmax(A+B)} + lam
    # (For the right derivative at 0, we need the max B among active constraints)
    
    active0 = A == np.max(A)
    active1 = (A + B) == np.max(A + B)
    
    slope0_right = dx * B[active0].max() + lam  # right derivative at 0
    slope1_left = dx * B[active1].min() + lam   # left derivative at 1
    
    if slope0_right >= 0:
        return 0.0
    if slope1_left <= 0:
        return 1.0
    
    # Minimum is in the interior. Find where slope crosses zero.
    # The slope of f at t is dx*B[k*(t)] + lam where k*(t) is the unique maximizer.
    # At breakpoints, the subgradient contains values from both sides.
    
    # Find all breakpoints (intersections of pairs of lines)
    # This is O(m^2) where m = 2n-1
    # For n=210, m=419, so ~87000 breakpoints. That's a lot.
    
    # Better approach: find the upper envelope in O(m log m)
    # Then binary search on the envelope for where slope = -lam/dx
    
    # Actually, let me just do a simple ternary search since f is convex:
    # f is convex, so ternary search works but is O(log(1/eps)) evaluations
    # Each evaluation is O(m) = O(n)
    
    # Or even simpler: since f is convex PWL with at most m-1 breakpoints,
    # and the minimum is at a breakpoint (or where the slope is exactly 0),
    # we can find it by:
    
    # The slope of the upper envelope as a function of t is non-decreasing.
    # We want where it equals -lam/dx.
    # 
    # Let's use a different approach: parametric search.
    # For a given slope s, the line with that slope on the upper envelope
    # is the one that maximizes A[k] + (B[k]-s)*t + s*t - s*t
    # = the one that maximizes A[k] + (B[k]-s)*t
    # At t=0, this is A[k] - 0 = A[k]... no that's not right.
    
    # OK let me just use a practical approach:
    # Since f is convex, use bisection on the subgradient.
    # The subgradient at t is: dx * conv{B[k] : k active} + {lam}
    # f is decreasing at t if max{dx*B[k]+lam : k active} < 0
    # f is increasing at t if min{dx*B[k]+lam : k active} > 0
    # f has a minimum at t if min <= 0 <= max
    
    # Bisection:
    lo, hi = 0.0, 1.0
    for _ in range(50):  # 50 iterations gives precision ~ 1/2^50
        mid = (lo + hi) / 2
        vals = A + B * mid
        max_val = np.max(vals)
        active = (vals == max_val)
        subgrad_lo = dx * B[active].min() + lam
        subgrad_hi = dx * B[active].max() + lam
        if subgrad_lo > 0:
            hi = mid
        elif subgrad_hi < 0:
            lo = mid
        else:
            break  # Found the minimum
    
    return (lo + hi) / 2
```

```python
                if c5 < best_c5:
```
```python
                    best_h = h_new.copy()
                    best_c5 = c5
            except Exception:
                pass

    best_h = project_feasible(best_h, target_sum)
    best_c5 = compute_c5(best_h)
    return best_h, best_c5, len(best_h)
```
