lambda = -mean(grad_obj[free]) where free = {i : 0 < h[i] < 1}

Then the effective gradient is grad_obj + lambda, and we use L-BFGS-B with bounds [0,1].

- For consistency: lambda = -mean(grad_f[free])

So the effective gradient for L-BFGS-B is: grad_f + lambda * 1
And L-BFGS-B handles the bound constraints 0 <= h <= 1.

This should work well! The key insight is that by adding the Lagrange multiplier, we project the gradient onto the feasible direction (i.e., the direction that preserves the sum constraint to first order).

    dx = 2.0 / n

def project_h(h, target_sum):
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-13:
            break
        free = (h > 1e-12) & (h < 1.0 - 1e-12)
        if free.sum() == 0:
            h += diff / len(h)
        else:
            h[free] += diff / free.sum()
        h = np.clip(h, 0.0, 1.0)
    return h

def corr_gradient(h, top_idx):
    """Compute gradient of sum of corr[top_idx] w.r.t. h."""
    n = len(h)
    grad = np.zeros(n)
    for idx in top_idx:
        lag = int(idx) - (n - 1)
        if lag == 0:
            grad += (1.0 - 2.0 * h)
        elif 0 < lag < n:

            grad[m2:] -= h[:n - m2]
    return grad

    return val, grad
