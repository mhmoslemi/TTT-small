**Focal Coordinate Descent:**

The key insight: for a fixed set of "active" correlations (top-M), the objective as a function of a single coordinate h[j] is:
g(t) = smooth_max([A_p * t + B_p for p in active], beta) * dx

where A_p = ∂corr[p]/∂h[j] (a constant for fixed j and fixed other h values)
and B_p = corr[p] - A_p * h[j] (the current value minus the contribution of h[j])

This is a convex function of t (smooth max of affine functions is convex). So we can find the minimum using a bounded scalar minimizer.

The algorithm:
1. Compute corr, find top-M positions
2. For each j in 0..n-1:
   a. For each active position p: compute A_p = ∂corr[p]/∂h[j]
   b. Compute B_p = corr[p] - A_p * h[j]

   d. Update h[j]
3. Project to feasible set
4. Repeat

The margin parameter controls how far we allow h[j] to move. Starting with a small margin and increasing it could help.

    """Find min of max(A_p * t + B_p) for t in [0,1] exactly."""
    # Find all kink points in (0,1)
    kinks = [0.0, 1.0]

        for j in range(i+1, M):
            denom = A[i] - A[j]
            if abs(denom) > 1e-15:
                t_kink = (B[j] - B[i]) / denom
                if 0.0 < t_kink < 1.0:
                    kinks.append(t_kink)
    kinks = sorted(set(kinks))

    best_t = 0.0

    for t in kinks:
        vals = A * t + B
        v = np.max(vals)
        if v < best_val:
            best_val = v
            best_t = t
    
    return best_t
