But wait, m = max(c_j) depends on h too! When we change h, m changes. However, m is only differentiable where the max is unique, and at points where it's not unique, the subgradient includes the term from m.

Actually, in the standard log-sum-exp approximation, we use:
log-sum-exp(x) = max(x) + log(sum exp(x - max(x)))

The gradient of this with respect to x is:
softmax(x) = exp(x - max(x)) / sum(exp(x - max(x)))

And the chain rule gives:
d(log-sum-exp)/d(x_i) = softmax(x)_i

So d(obj)/d(h) = sum_j softmax_j * d(c_j)/dh

This is exactly what the code computes. The fact that m depends on h is handled correctly because the gradient of max(x) with respect to x_i is 1 if i is the argmax and 0 otherwise, and the gradient of log(sum exp(x - max(x))) has a corresponding term that cancels this. So the total gradient is just the softmax.

    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_h(h, target_sum):
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-14:
            break
        free = (h > 1e-12) & (h < 1.0 - 1e-12)
        if free.sum() == 0:
            free = np.ones(len(h), dtype=bool)
        h[free] += diff / free.sum()
        h = np.clip(h, 0.0, 1.0)
    return h

def smooth_max_grad(h, beta, top_k):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    idx = np.argsort(corr)[::-1][:top_k]
    m = corr[idx[0]]
    x = np.clip(beta * (corr[idx] - m), -200, 0)
    e = np.exp(x)
    se = e.sum()
    w = e / se
    obj = m + np.log(se) / beta
    grad = np.zeros(n)
    for t in range(top_k):
        wt = w[t]
        if wt < 1e-12:
            continue
        lag = int(idx[t]) - (n - 1)
        if lag == 0:
            grad += wt * (1.0 - 2.0 * h)
        elif lag > 0:
            grad[lag:] += wt * (1.0 - h[:-lag])
            grad[:n-lag] -= wt * h[lag:]
        else:
            m2 = -lag
            grad[:n-m2] += wt * (1.0 - h[m2:])
            grad[m2:] -= wt * h[:n-m2]
    return obj, grad
