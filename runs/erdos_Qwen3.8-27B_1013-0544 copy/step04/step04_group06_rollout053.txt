Let me think of a faster approach. Instead of recomputing the full correlation after each coordinate change, I can update it incrementally.

When we change h[i] from old to new (delta = new - old):
- For each lag k, the correlation changes by:
  delta * (1-h[i+k]) + delta * (1-h[i-k]... ) 
  
Actually, the correlation at lag k is:
corr[k] = sum_j h[j] * (1-h[j+k])

If we change h[i] by delta:
- The term j=i: delta * (1-h[i+k])
- The term j=i-k: h[i-k] changes... no, h[i-k] is fixed, but (1-h[i]) changes by -delta
  So the term j=i-k changes by: -h[i-k] * delta

So the change in corr[k] is: delta * (1-h[i+k]) - h[i-k] * delta = delta * (1 - h[i+k] - h[i-k])

Wait, that's only if both i+k and i-k are in range. Let me be more careful.

corr[k] = sum_j h[j] * (1-h[j+k]) for j such that both j and j+k are in [0,n-1].

This equals: sum_j h[j] - sum_j h[j]*h[j+k]

If h[i] changes by delta:
- In the first sum: delta (if i is in range)
- In the second sum: terms where j=i (giving h[i]*h[i+k], changes by delta*h[i+k]) and where j+k=i i.e. j=i-k (giving h[i-k]*h[i], changes by h[i-k]*delta)

So change in corr[k] = delta - delta*h[i+k] - h[i-k]*delta = delta*(1 - h[i+k] - h[i-k])

(with appropriate handling when i+k or i-k is out of range)

This is O(1) per lag! So updating the correlation after a coordinate change is O(2n) (for all lags).

Then computing the max is O(2n). Total per coordinate: O(n). For all n coordinates: O(n²). For n=480: about 230K per sweep. Very fast!

                candidate = 1.0 if old < 0.5 else 0.0

            # (with boundary handling)
            
            # Build the "gradient" vector: how corr changes with delta at each lag
            delta_grad = np.zeros(2*n - 1)  # for each lag

                ik = i + k

                if 0 <= ik2 < n:

                coef += 1.0  # +1 from the linear term
                delta_grad[k + n - 1] = coef

            # We want to choose delta to minimize max_k (corr[k] + delta*delta_grad[k])

            # (Each corr[k] + delta*delta_grad[k] is linear in delta)
            # So g is convex, and we can find its minimum on [-(old), 1-old]
            
            # Wait, delta = new - old, so new = old + delta, and new ∈ [0,1]
            # So delta ∈ [-old, 1-old]

            # 1. Find where the derivative changes sign
            # 2. The derivative is the sum of delta_grad[k] for active k's
            
            # Actually, for a max of linear functions, the minimum is where the
            # "slope" crosses zero. The slope of g at delta is:
            # subgradient = {convex hull of {delta_grad[k] : k is active at delta}}
            
            # Simple approach: ternary search or golden section on [-(old), 1-old]
            lo = -old

            new_val = np.clip(new_val, 0.0, 1.0)

Wait, there's a problem: I'm ignoring the sum constraint during the coordinate updates. The sum of h might drift away from n/2. I need to handle this.

Option 1: After each coordinate update, reproject. But this is expensive.
Option 2: Do the coordinate descent ignoring the sum constraint, then project at the end. But the projection might undo the improvements.
Option 3: Include the sum constraint in the 1D optimization: after choosing the optimal delta for coordinate i, adjust another coordinate to maintain the sum.

Actually, option 2 might work in practice: do many sweeps of coordinate descent (ignoring sum), then project, then check if the result is still good. If the projection hurts, we can do a few more sweeps.

But actually, the projection (shifting all values by a constant and clipping) might significantly change the correlations. Let me think...

A better approach: do the coordinate descent with the sum constraint built in. When we change h[i] by delta, we also need to change some other h[j] by -delta to maintain the sum. The simplest is to spread -delta equally across all other coordinates (a "global shift" of the other coordinates).

But this makes the 1D optimization more complex because all lags are affected.

Alternatively: use a "swap" approach. Instead of changing one coordinate, swap: decrease h[i] by delta and increase h[j] by delta for some j. This maintains the sum automatically.

The "swap" approach:
- Choose pair (i, j)
- Change: h[i] -= delta, h[j] += delta
- Effect on corr[k]:
  - From h[i]: -delta * (1 - h[i+k] - h[i-k]) = -delta * grad_i[k]
  - From h[j]: +delta * (1 - h[j+k] - h[j-k]) = +delta * grad_j[k]
  - Total: delta * (grad_j[k] - grad_i[k])

This is still linear in delta for each k! So the 1D optimization is the same (convex piecewise linear).

The challenge is choosing which pair (i,j) to use. A natural choice:
- i = coordinate with high h (wants to decrease)
- j = coordinate with low h (wants to increase)

Or: use the subgradient to identify which coordinates should increase/decrease.

But wait, the "correlation" values also scale with n. For a binary sequence with n/2 ones:
- At shift k, the correlation is approximately (number of overlapping positions) * (fraction of 1-0 pairs)
- The number of overlapping positions is n-|k|
- So corr[k] ≈ (n-|k|) * p where p is the 1-0 fraction
- C₅ ≈ max_k (n-|k|) * p * (2/n) ≈ 2p for small k

So C₅ is roughly independent of n for binary sequences! The improvement from higher n comes from being able to use non-binary values to fine-tune.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    dx = 2.0 / len(h)
    return float(np.max(np.correlate(h, 1.0 - h, mode="full")) * dx)

def project_sum(h, target):
    h = np.clip(h, 0.0, 1.0)
    lo, hi = -2.0, 2.0
    for _ in range(60):
        mid = (lo + hi) * 0.5
        if np.clip(h - mid, 0.0, 1.0).sum() > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) * 0.5, 0.0, 1.0)

def smooth_obj_grad(h, beta):
    """Smooth approximation of max correlation using log-sum-exp."""
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    m = np.max(corr)
    bc = np.clip(beta * (corr - m), -500, 500)
    e = np.exp(bc)
    se = e.sum()
    val = (m + np.log(se / len(corr)) / beta) * dx
    w = e / se
    g = np.zeros(n)
    nc = len(corr)
    for j in range(nc):
        if w[j] < 1e-12:
            continue
        lag = j - (n - 1)
        if lag == 0:
            g += w[j] * (1.0 - 2.0 * h)
        elif lag > 0:
            g[lag:] += w[j] * (1.0 - h[:-lag])
            g[:n - lag] -= w[j] * h[lag:]
        else:
            m2 = -lag
            g[:n - m2] += w[j] * (1.0 - h[m2:])
            g[m2:] -= w[j] * h[:n - m2]
    return val, g * dx

def slsqp(h_init, beta, maxiter=3000):
    n = len(h_init)
    target = n / 2.0
    bounds = [(0, 1)] * n
    
    res = minimize(
        lambda x: smooth_obj_grad(np.clip(x, 0, 1), beta)[0],
        h_init,
        jac=lambda x: smooth_obj_grad(np.clip(x, 0, 1), beta)[1],
        method='SLSQP', bounds=bounds,
        constraints=[{'type': 'eq', 'fun': lambda x: np.sum(x) - target,
                      'jac': lambda x: np.ones(n)}],
        options={'maxiter': maxiter, 'ftol': 1e-18}
    )
    return project_sum(res.x, target)

def subgrad_polish(h, n_active, max_iters, t0, budget):
    n = len(h)
    target = n / 2.0
    best = h.copy()
    best_c5 = compute_c5(best)
    no_imp = 0
    
    for it in range(max_iters):
        if budget - (time.time() - t0) < 3:
            break
        corr = np.correlate(best, 1.0 - best, mode="full")
        top = np.argsort(corr)[::-1][:n_active]
        g = np.zeros(n)
        for idx in top:
            lag = int(idx) - (n - 1)
            if lag == 0:
                g += (1.0 - 2.0 * best)
            elif lag > 0:
                g[lag:] += (1.0 - best[:-lag])
                g[:n - lag] -= best[lag:]
            else:
                m2 = -lag
                g[:n - m2] += (1.0 - best[m2:])
                g[m2:] -= best[:n - m2]
        gn = np.linalg.norm(g)
        if gn < 1e-14:
            break
        g /= gn
        improved = False
        for step in [0.05, 0.02, 0.01, 0.005, 0.002, 0.001, 0.0005, 0.0002]:
            ht = project_sum(best - step * g, target)
            c5t = compute_c5(ht)
            if c5t < best_c5 - 1e-15:
                best = ht
                best_c5 = c5t
                improved = True
                break
        if not improved:
            no_imp += 1
            if no_imp > 500 and it % 200 == 199:
                pert_size = max(0.005, 0.02 * (1 - it / max_iters))
                ht = project_sum(best + np.random.randn(n) * pert_size, target)
                c5t = compute_c5(ht)
                if c5t < best_c5:
                    best = ht
                    best_c5 = c5t
                    no_imp = 0
            if no_imp > 5000:
                break
        else:
            no_imp = 0
    return best, best_c5

def pair_swap_polish(h, n_pairs, t0, budget):
    """Coordinate descent via pair swaps."""
    n = len(h)
    target = n / 2.0
    dx = 2.0 / n
    best = h.copy()
    corr = np.correlate(best, 1.0 - best, mode="full")
    best_c5 = np.max(corr) * dx
    no_imp = 0
    
    for it in range(n_pairs):
        if budget - (time.time() - t0) < 3:
            break
        # Pick random pairs
        rng = np.random
        improved = False
        for _ in range(200):
            i = rng.randint(n)
            j = rng.randint(n)
            if i == j:
                continue
            old_i, old_j = best[i], best[j]
            # We swap: h[i] decreases by delta, h[j] increases by delta
            # delta in range such that both stay in [0,1]
            d_lo = -old_i  # h[i] + d_lo = 0
            d_hi = 1.0 - old_j  # h[j] + d_hi = 1
            # Also h[i] - delta >= 0 => delta <= old_i
            # And h[j] + delta <= 1 => delta <= 1 - old_j
            # And h[i] - delta <= 1 => delta >= old_i - 1
            # And h[j] + delta >= 0 => delta >= -old_j
            d_lo = max(d_lo, old_i - 1.0, -old_j)
            d_hi = min(d_hi, old_i, 1.0 - old_j)
            if d_hi <= d_lo:
                continue
            
            # Compute gradient of corr w.r.t. delta for this swap
            # corr[k] changes by: -delta * grad_i[k] + delta * grad_j[k] = delta * (grad_j[k] - grad_i[k])
            # where grad_x[k] = 1 - h[x+k] - h[x-k] (with boundary handling)
            
            # For efficiency, compute delta_grad for this specific pair
            # delta_grad[k] = grad_j[k] - grad_i[k]
            # Let's compute this for all k
            
            # Actually, let's just try a few delta values
            # The optimal delta minimizes max_k (corr[k] + delta * (grad_j[k] - grad_i[k]))
            # which is convex in delta
            
            # Quick ternary search
            lo, hi = d_lo, d_hi
            for _ in range(20):
                m1 = lo + (hi - lo) / 3.0
                m2 = hi - (hi - lo) / 3.0
                # Compute max corr at m1 and m2
                # Need to update corr: corr_new = corr + delta * delta_grad
                # delta_grad[k] for swap (i decrease, j increase):
                # For each lag k, the change is:
                #   -delta * (1 - h[i+k] - h[i-k]) + delta * (1 - h[j+k] - h[j-k])
                #   = delta * [(1 - h[j+k] - h[j-k]) - (1 - h[i+k] - h[i-k])]
                #   = delta * [h[i+k] + h[i-k] - h[j+k] - h[j-k]]
                
                # This is expensive to compute for all k. Let's just evaluate directly.
                # Alternative: just try delta=0 (no change) vs a few candidate deltas
                pass
            
            # Simpler: just try moving i down and j up by a small amount
            for delta in [0.01, 0.005, 0.002]:
                if old_i - delta < 0 or old_j + delta > 1:
                    continue
                best[i] = old_i - delta
                best[j] = old_j + delta
                c5t = compute_c5(best)
                if c5t < best_c5 - 1e-15:
                    best_c5 = c5t
                    improved = True
                    break
                else:
                    best[i] = old_i
                    best[j] = old_j
                    continue
        
        if not improved:
            no_imp += 1
            if no_imp > 100:
                break
        else:
            no_imp = 0
    
    best = project_sum(best, target)
    best_c5 = compute_c5(best)
    return best, best_c5
