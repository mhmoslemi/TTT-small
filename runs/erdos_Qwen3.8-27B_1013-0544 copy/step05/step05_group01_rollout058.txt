Actually, let me try yet another approach: **Use the fact that we're minimizing a max of smooth functions.** The problem is a DC (Difference of Convex) optimization or can be formulated as:
min t
s.t. c_k(h) ≤ t for all k
     sum(h)*dx = 1
     0 ≤ h ≤ 1

This is a nonlinear feasibility problem in (h, t). We can solve it with:
- Penalty methods: minimize t + μ*sum(max(0, c_k - t)²)
- Augmented Lagrangian

But SLSQP with the smooth max is already doing something similar. Let me focus on making the local search better.

**Key insight for local search**: The pair search is O(n²) per pass, which for n=250 is 31K pair evaluations. Each evaluation requires an O(n) correlation, so it's O(n³) per pass = 15.6M operations. That's fine per pass, but we need many passes.

A faster approach: **Evaluate the effect of a pair move analytically.**

If I change h[i] by +d and h[j] by -d, the change in C_s is:
ΔC_s = d * [(1-h[i+s]) - h[i-s] - (1-h[j+s]) + h[j-s]] * dx (with boundary handling)

Wait, more carefully:
C_s = sum_h h[h](1-h[h+s])*dx

Change in C_s from changing h[i] by Δh_i and h[j] by Δh_j:
ΔC_s = Δh_i * (1-h[i+s]) + h[i-s] * (-Δh_i) + Δh_j * (1-h[j+s]) + h[j-s] * (-Δh_j)

Wait, I need to be more careful. The term h[h](1-h[h+s]) involves h at positions h and h+s. If I change h[i] by Δ, it affects:
- The term where h = i: Δ*(1-h[i+s])
- The term where h+s = i, i.e., h = i-s: h[i-s]*(-Δ)

So the total change in C_s from changing h[i] by Δ is:
Δ*(1-h[i+s]) - h[i-s]*Δ = Δ*(1-h[i+s]-h[i-s])

And for changing both h[i] by d and h[j] by -d:
ΔC_s = d*(1-h[i+s]-h[i-s]) - d*(1-h[j+s]-h[j-s])
     = d*(h[j+s]+h[j-s]-h[i+s]-h[i-s])

So I can compute the change in C_s for any pair move in O(1) per shift s! And the new max is max(old_max, max of new C_s values). Actually, since we're changing by a small d, the new C_s ≈ old_C_s + ΔC_s, and the new max is approximately max_s (old_C_s + ΔC_s).

This is much faster! Instead of O(n) per pair evaluation (for the full correlation), I can do O(n) for all shifts but with a simple formula.

Wait, I still need to check all 2n-1 shifts to find the new max. So it's O(n) per pair, same as before. But the constant is much smaller (just additions and comparisons vs. a full correlation).

Actually, the full correlation is O(n) (it's a convolution of two length-n sequences, which can be done in O(n) for a single shift, and O(n²) for all shifts, but numpy.correlate does it in O(n²) or O(n log n) with FFT).

So the current approach is:
- O(n²) for the full correlation (or O(n log n) with FFT)
- Per pair evaluation: O(n²) or O(n log n)

With the analytical formula:
- Precompute h[i+s] and h[i-s] for all i, s: O(n²)
- Per pair evaluation: O(n) (just compute d*(h[j+s]+h[j-s]-h[i+s]-h[i-s]) for all s and find the max change)

This is a factor of n improvement per pair evaluation! For n=250, that's 250x faster.

OK the analytical approach is getting complicated with boundaries. Let me just stick with the direct computation but make the pair search smarter about which pairs to try.

**Smart pair selection**: Instead of trying all O(n²) pairs, try only pairs that are likely to help:
- Pairs where one is "high" (h[i] > 0.5) and the other is "low" (h[j] < 0.5)
- Pairs that are far apart (large separation)
- Pairs identified by the gradient (i has high positive gradient, j has high negative gradient)

Let me implement a gradient-guided pair search:

```python
def gradient_pair_search(h, n, deadline, deltas):
    """Pair search guided by gradient information."""
    h = h.copy()
    best_c = compute_c5(h, n)
    dx = 2.0 / n
    
    for d in deltas:
        if time.time() > deadline:
            break
        for _pass in range(300):
            if time.time() > deadline:
                break
            improved = False
            
            # Compute gradient of C5 (subgradient from max shift)
            c = np.correlate(h, 1 - h, mode='full') * dx
            max_idx = np.argmax(c)
            s = max_idx - (n - 1)
            g = np.zeros(n)
            if s >= 0:
                g[:n-s] += 1.0 - h[s:]
                g[s:] += -h[:n-s]
            else:
                t = -s
                g[t:] += 1.0 - h[:n-t]
                g[:n-t] += -h[t:]
            
            # Try to increase h where g is negative, decrease where g is positive
            # (since we want to decrease C_s, and dC_s/dh[i] = g[i]*dx)
            # Wait: we want to DECREASE C_s. The gradient g points in the direction of increase.
            # So we want to move h in the -g direction.
            # That means: decrease h where g > 0, increase h where g < 0.
            # A pair move: increase h[i] (where g[i] < 0) and decrease h[j] (where g[j] > 0)
            
            neg_idx = np.where(g < -0.01)[0]
            pos_idx = np.where(g > 0.01)[0]
            
            # Try top pairs
            neg_sorted = neg_idx[np.argsort(g[neg_idx])]  # most negative first
            pos_sorted = pos_idx[np.argsort(-g[pos_idx])]  # most positive first
            
            tried = 0
            for i in neg_sorted[:30]:
                for j in pos_sorted[:30]:
                    if tried > 500:
                        break
                    tried += 1
                    hi = h[i] + d
                    hj = h[j] - d
                    if 0.0 <= hi <= 1.0 and 0.0 <= hj <= 1.0:
                        h[i], h[j] = hi, hj
                        c_new = compute_c5(h, n)
                        if c_new < best_c - 1e-15:
                            best_c = c_new
                            improved = True
                        else:
                            h[i], h[j] = hi - d, hj + d
            if not improved:
                break
    return h, best_c
```

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = h.copy()
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def smooth_obj(x, n, alpha):
    dx = 2.0 / n
    c = np.correlate(x, 1 - x, mode='full') * dx
    m = c.max()
    shifted = alpha * (c - m)
    mx = shifted.max()
    if mx > 500:
        return float(m + (mx + np.log(np.sum(np.exp(shifted - mx)))) / alpha)
    return float(m + np.log(np.sum(np.exp(shifted))) / alpha)

def _sum_con(x, n):
    return float(np.sum(x) - n / 2.0)

def _sum_con_jac(x, n):
    return np.ones(n)

def slsqp(h, n, alpha, maxiter=5000):
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _sum_con, 'jac': _sum_con_jac, 'args': (n,)}]
    try:
        res = minimize(smooth_obj, h, args=(n, alpha), method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-16})
        return project_feasible(res.x, n)
    except Exception:
        return h.copy()

def _grad_shift(h, n, s):
    g = np.zeros(n)
    if s >= 0:
        g[:n-s] += 1.0 - h[s:]
        g[s:] += -h[:n-s]
    else:
        t = -s
        g[t:] += 1.0 - h[:n-t]
        g[:n-t] += -h[t:]
    return g

def gradient_guided_search(h, n, deadline, top_k=3, n_deltas=5):
    h = h.copy()
    best_c = compute_c5(h, n)
    dx = 2.0 / n
    deltas = [0.02, 0.01, 0.005, 0.002, 0.001]
    for d in deltas[:n_deltas]:
        if time.time() > deadline:
            break
        for _pass in range(100):
            if time.time() > deadline:
                break
            improved = False
            c = np.correlate(h, 1 - h, mode='full') * dx
            top_idx = np.argsort(c)[-top_k:]
            g = np.zeros(n)
            for k in top_idx:
                s = k - (n - 1)
                g += _grad_shift(h, n, s)
            g /= top_k
            neg = np.where(g < -0.005)[0]
            pos = np.where(g > 0.005)[0]
            if len(neg) == 0 or len(pos) == 0:
                break
            neg_sorted = neg[np.argsort(g[neg])][:25]
            pos_sorted = pos[np.argsort(-g[pos])][:25]
            for i in neg_sorted:
                if time.time() > deadline:
                    break
                for j in pos_sorted:
                    hi = h[i] + d
                    hj = h[j] - d
                    if 0.0 <= hi <= 1.0 and 0.0 <= hj <= 1.0:
                        h[i], h[j] = hi, hj
                        cn = compute_c5(h, n)
                        if cn < best_c - 1e-15:
                            best_c = cn
                            improved = True
                        else:
                            h[i], h[j] = hi - d, hj + d
            if not improved:
                break
    return h, best_c

def full_pair(h, n, deadline, deltas):
    h = h.copy()
    best_c = compute_c5(h, n)
    for d in deltas:
        if time.time() > deadline:
            break
        for _ in range(400):
            if time.time() > deadline:
                break
            improved = False
            for i in range(n):
                if time.time() > deadline:
                    break
                for j in range(i + 1, n):
                    hi = h[i] + d
                    hj = h[j] - d
                    if 0.0 <= hi <= 1.0 and 0.0 <= hj <= 1.0:
                        h[i], h[j] = hi, hj
                        c = compute_c5(h, n)
                        if c < best_c - 1e-15:
                            best_c = c
                            improved = True
                        else:
                            h[i], h[j] = hi - d, hj + d
                    hi2 = h[i] - d
                    hj2 = h[j] + d
                    if 0.0 <= hi2 <= 1.0 and 0.0 <= hj2 <= 1.0:
                        h[i], h[j] = hi2, hj2
                        c = compute_c5(h, n)
                        if c < best_c - 1e-15:
                            best_c = c
                            improved = True
            if not improved:
                break
    return h, best_c

def directed_lsqp(h, n, deadline, top_k=3, n_steps=1500):
    h = h.copy()
    best_c = compute_c5(h, n)
    dx = 2.0 / n
    for step in range(n_steps):
        if time.time() > deadline:
            break
        c = np.correlate(h, 1 - h, mode='full') * dx
        top_idx = np.argsort(c)[-top_k:]
        g = np.zeros(n)
        for k in top_idx:
            s = k - (n - 1)
            g += _grad_shift(h, n, s)
        g *= dx / top_k
        improved = False
        for lr in [0.001, 0.003, 0.005, 0.01, 0.02, 0.04]:
            h_try = project_feasible(h - lr * g, n)
            cn = compute_c5(h_try, n)
            if cn < best_c - 1e-14:
                h, best_c = h_try, cn
                improved = True
                break
        if not improved:
            g_r = g + 0.02 * np.random.randn(n)
            for lr in [0.005, 0.01, 0.03]:
                h_try = project_feasible(h - lr * g_r, n)
                cn = compute_c5(h_try, n)
                if cn < best_c - 1e-14:
                    h, best_c = h_try, cn
                    improved = True
                    break
    return h, best_c

def refine(h_in, n, deadline, rng):
    h = project_feasible(h_in.copy(), n)
    best_c = compute_c5(h, n)
    alphas = [5000, 50000, 500000, 5000000, 50000000]
    for a in alphas:
        if time.time() > deadline - 25:
            break
        ht = slsqp(h, n, a, maxiter=10000)
        c = compute_c5(ht, n)
        if c < best_c - 1e-14:
            h, best_c = ht, c
    if time.time() < deadline - 15:
        ht, ct = directed_lsqp(h, n, deadline - 15, top_k=3, n_steps=2000)
        if ct < best_c:
            h, best_c = ht, ct
    if time.time() < deadline - 10:
        ht, ct = gradient_guided_search(h, n, deadline - 10, top_k=3, n_deltas=5)
        if ct < best_c:
            h, best_c = ht, ct
    if time.time() < deadline - 3:
        ht, ct = full_pair(h, n, deadline - 1, [0.002, 0.001, 0.0005, 0.0002, 0.0001])
        if ct < best_c:
            h, best_c = ht, ct
    h = project_feasible(h, n)
    best_c = compute_c5(h, n)
    return h, best_c

    t0 = time.time()
```
