Let me also think about the 1D solver. The function f(t) = max_k (A_k + B_k * t) + mu * t is convex piecewise-linear. The minimum is at a kink or at the boundary.

A fast way to find the minimum:
1. Evaluate f(0) and f(1)
2. Find the subgradient at 0: S0 = {B_k + mu : A_k = f(0) - mu*0}
   Actually, the subgradient of max_k (A_k + B_k * t) at t=0 is the convex hull of {B_k : A_k = max(A)}.
   Adding mu * t, the subgradient at 0 is {B_k + mu : A_k = max(A)}.
   If min of this set > 0, the function is increasing at 0, so min is at t=0.
   If max of this set < 0, the function is decreasing at 0, so min is at t=1 (or at a kink).
3. If 0 is in the subgradient at t=0, the minimum is at t=0.
   If 0 is not in the subgradient at t=1, the minimum is at t=1.
4. Otherwise, use bisection.

For bisection: at each t, the subgradient is {B_k + mu : A_k + B_k*t = f(t) - mu*t}. If all elements are negative, go right; if all positive, go left; if 0 is in the set, we found the minimum.

In practice, for a piecewise-linear function, bisection will land exactly on a kink after O(log(n/ε)) steps.

        active = vals == m  # within tolerance

import numpy as np

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def solve_1d(A, B, mu):
    lo, hi = 0.0, 1.0
    for _ in range(100):
        mid = (lo + hi) * 0.5
        vals = A + B * mid
        m = vals.max()
        active = B[vals >= m - 1e-10] + mu
        if active.min() >= -1e-12:
            hi = mid
        else:
            lo = mid
    return (lo + hi) * 0.5

def fix_sum(h, n):
    target = n / 2.0
    for _ in range(500):
        h = np.clip(h, 0.0, 1.0)
        diff = h.sum() - target
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = h - diff * room / s
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + (-diff) * h / s
    return np.clip(h, 0.0, 1.0)

def coord_descent(h, n, max_sweeps=500, deadline=None, mu_init=0.0):

            s_range = np.arange(s_lo, s_hi + 1)
            B = (1.0 - h[i - s_range]) - h[i + s_range]
            A = c_full[s_range + (n - 1)] - old * B
            t_new = solve_1d(A, B, mu)
            delta = t_new - old
            if abs(delta) > 1e-14:
                h[i] = t_new
                c_full[s_range + (n - 1)] += delta * B

        h = fix_sum(h, n)
