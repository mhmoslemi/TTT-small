OK so the gradient formula is correct. Now let me think about the Frank-Wolfe algorithm.

**Frank-Wolfe (FW) Algorithm:**
1. Initialize h^0 (e.g., from CD)
2. For t = 0, 1, 2, ...:
   a. Compute g_t = ∇f(h^t)
   b. Solve: s_t = argmin_{s ∈ P} g_t^T s where P = {h: 0≤h≤1, sum(h)=n/2}
      (This is the linear oracle: sort g_t, set top to 0, bottom to 1, adjust middle)
   c. Compute step size γ_t (e.g., 2/(t+2) for vanilla FW, or line search)
   d. h^{t+1} = (1-γ_t) * h^t + γ_t * s_t
3. Return h^T

The convergence rate of vanilla FW is O(1/t), which is slow. But with:
- Strong Wolfe line search: O(1/t^2) (but requires additional work)
- Away-steps: empirically much faster
- Restarting: can help a lot

For our problem, the feasible set is a "slice of a hypercube" which is a polytope. The FW gap (f(h_t) - f(h*)) decreases at rate O(1/t), so to get a gap of 1e-5 we'd need about 1e5 iterations. That's too many.

However, if we use FW as a way to escape a local minimum (rather than to converge to the global optimum), we only need a few iterations. The key is that FW makes moves that are not available to pure coordinate descent.

**Better idea: Use FW for a few iterations, then go back to CD.**

Or even better: **Use the FW direction as a perturbation direction for CD.**

Algorithm:
1. Run CD to convergence
2. Compute FW direction s - h (where s = linear oracle solution)
3. Move a small amount in this direction: h_new = h + ε * (s - h), then project
4. Run CD from h_new
5. If improved, keep; otherwise try different ε

This is essentially a "metaheuristic" that uses FW to generate escape directions.

**Even better: Block coordinate descent with FW-style updates.**

Instead of updating one coordinate at a time, update a block of coordinates. The block update can be solved as a small QP or using FW within the block.

Hmm, the pair CD with random search is not very principled. Let me think of a better approach.

**Key insight for improvement**: The main limitation of the current CD is that it can't make moves that require two coordinates to change simultaneously. For example, if increasing h[p] helps one lag but hurts another, and decreasing h[q] would fix the hurt, the CD can't do this in one step (it would need to increase h[p], see the objective get worse, and then decrease h[q] to fix it, but the intermediate state is worse).

The solution is to use a **2D exact solve** for pairs. Given h[p] and h[q] as variables, the max over all lags of c[m] is a function of (h[p], h[q]). We want to minimize this over [0,1]^2 (with the sum constraint handled by projection later).

The function c[m](h[p], h[q]) is at most quadratic in each variable and bilinear. So the max of these quadratics is a convex function of (h[p], h[q])... wait, no. The max of convex functions is convex, and each c[m] as a function of (h[p], h[q]) is... let me check.

c[m] = const + a*h[p] + b*h[q] + c*h[p]*h[q] + d*h[p]^2 + e*h[q]^2

The Hessian is:
[[2d, c], [c, 2e]]

For this to be convex, we need 2d ≥ 0, 2e ≥ 0, and 4de ≥ c^2.

In our case, d = e = -1 (if the diagonal terms are present) or 0 (otherwise). And c = -1 (if p and q are paired at this lag) or 0.

If d = e = -1 and c = -1: Hessian = [[-2, -1], [-1, -2]], eigenvalues -3 and -1. Not convex (negative definite).
If d = e = -1 and c = 0: Hessian = [[-2, 0], [0, -2]]. Not convex.
If d = 0, e = 0, c = -1: Hessian = [[0, -1], [-1, 0]]. Eigenvalues 1 and -1. Not convex.

So the individual c[m] are NOT convex in (h[p], h[q]). This means the 2D subproblem is non-convex, and we can't solve it exactly with simple methods.

However, we can still use numerical optimization (scipy) or a grid search for the 2D subproblem.

**Alternative: Use the "smooth max" objective for the 2D subproblem.**

f(h[p], h[q]) = smooth_max over m of c[m](h[p], h[q])

This is smooth (with the log-sum-exp) and we can use scipy.optimize.minimize on it.

For n=700, evaluating f requires computing the affected lags (O(n) lags affected), and scipy.optimize.minimize will need maybe 10-50 evaluations. So each pair update costs O(n * 50) = O(35000). For 100 pairs per pass, that's 3.5M per pass. For 10 passes, 35M. That's fine.

But actually, we don't need to recompute the full correlate. We only need the lags that are affected by h[p] or h[q]. Those are at most 2n lags (the ones where p or q appears).

Actually, I realize there's a much simpler and potentially more effective approach:

**Simultaneous subgradient descent on the top lags.**

Instead of optimizing one coordinate at a time, do the following:
1. Compute c and identify the top K lags (where K=2 or 3)
2. Compute the "average" subgradient: g = (1/K) * Σ_{m ∈ top_K} ∇c[m]
3. Take a small projected step: h_new = project(h - η * g)
4. This reduces the top lags simultaneously

This is much simpler than pair optimization and can break the "conflict" that prevents CD from improving.

The step size η can be chosen by line search or set adaptively.

Let me implement this:

```python
def subgradient_polish(h, n, n_iter, deadline):
    """Polish using subgradient of the top lags"""
    h = h.copy()
    for i in range(n_iter):
        if time.time() > deadline:
            break
        c = np.correlate(h, 1.0 - h, mode='full')
        cur_max = c.max()
        
        # Top 3 lags
        top_k = 3
        top_indices = np.argsort(c)[-top_k:]
        threshold = c[top_indices[0]] * 0.99  # lags within 1% of max
        
        active = np.where(c >= threshold)[0]
        K = len(active)
        if K == 0:
            break
        
        # Compute average subgradient
        grad = np.zeros(n)
        for m_idx in active:
            k = m_idx - (n - 1)
            if k >= 0:
                grad[:n-k] += (1.0 - h[k:n])
                grad[k:] -= h[:n-k]
            else:
                grad[-k:] += (1.0 - h[:n+k])
                grad[:n+k] -= h[-k:]
        grad /= K
        
        # Step size (decreasing)
        eta = 0.1 / (1 + 0.1 * i)
        
        h_new = h - eta * grad
        h_new = project_feasible(h_new, n)
        
        c_new = np.correlate(h_new, 1.0 - h_new, mode='full')
        if c_new.max() < cur_max:
            h = h_new
        else:
            # Try smaller step
            h_new = h - eta * 0.1 * grad
            h_new = project_feasible(h_new, n)
            c_new = np.correlate(h_new, 1.0 - h_new, mode='full')
            if c_new.max() < cur_max:
                h = h_new
    
    return h, compute_c5(h, n)
```

def project_feasible(h, n):

        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h = np.clip(h + (diff / tot) * room, 0.0, 1.0)
        else:
            tot = h.sum()
            if tot < 1e-15:

def solve_coord(c, h, p, n):
    h0 = h[p]
    m_min = max(0, n - 1 - p)
    m_max = min(2 * n - 2, 2 * n - 2 - p)
    ms = np.arange(m_min, m_max + 1)
    jf = p + ms - (n - 1)
    jb = p - ms + (n - 1)
    vf = (jf >= 0) & (jf < n)
    vb = (jb >= 0) & (jb < n)
    a = np.zeros(len(ms))
    if np.any(vf):
        a[vf] += (1.0 - h[jf[vf]])
    if np.any(vb):
        a[vb] -= h[jb[vb]]
    c_base = c[ms]
    diag_idx = np.where(ms == (n - 1))[0]
    has_diag = len(diag_idx) > 0
    unaff = 0.0
    if m_min > 0:
        unaff = float(np.max(c[:m_min]))
    if m_max < 2 * n - 2:
        unaff = max(unaff, float(np.max(c[m_max + 1:])))
    cur_max = float(np.max(c))
    neg_mask = a < -1e-14
    pos_mask = a > 1e-14
    zero_mask = np.abs(a) <= 1e-14
    L_lo, L_hi = unaff, cur_max
    for _ in range(50):
        if L_hi - L_lo < 1e-14:
            break
        L = (L_lo + L_hi) / 2.0
        x_lo, x_hi = 0.0, 1.0
        feasible = True
        if np.any(zero_mask) and np.any(c_base[zero_mask] > L + 1e-14):
            feasible = False
        if feasible and np.any(neg_mask):
            x_lo = max(x_lo, float(np.max((L - c_base[neg_mask]) / a[neg_mask])))
        if feasible and np.any(pos_mask):
            x_hi = min(x_hi, float(np.min((L - c_base[pos_mask]) / a[pos_mask])))
        if x_lo > x_hi + 1e-12:
            feasible = False
        if feasible and has_diag:
            c_diag = c_base[diag_idx[0]]
            a_d = a[diag_idx[0]]
            disc = a_d * a_d + 4.0 * (c_diag - L)
            if disc >= 0:
                sq = np.sqrt(disc)
                r1 = (a_d - sq) / 2.0
                r2 = (a_d + sq) / 2.0
                if x_lo > h0 + r1 and x_hi < h0 + r2:
                    feasible = False
        if feasible:
            L_hi = L
        else:
            L_lo = L
    L = L_hi
    x_lo, x_hi = 0.0, 1.0
    if np.any(neg_mask):
        x_lo = max(x_lo, float(np.max((L - c_base[neg_mask]) / a[neg_mask])))
    if np.any(pos_mask):
        x_hi = min(x_hi, float(np.min((L - c_base[pos_mask]) / a[pos_mask])))
    x_lo = max(x_lo, 0.0)
    x_hi = min(x_hi, 1.0)
    if has_diag:
        c_diag = c_base[diag_idx[0]]
        a_d = a[diag_idx[0]]
        disc = a_d * a_d + 4.0 * (c_diag - L)
        if disc >= 0:
            sq = np.sqrt(disc)
            r1 = (a_d - sq) / 2.0
            r2 = (a_d + sq) / 2.0
            if x_lo <= h0 + r1:
                x_hi = min(x_hi, h0 + r1)
            elif x_hi >= h0 + r2:

            else:

    return float(np.clip((x_lo + x_hi) / 2.0, 0.0, 1.0))

def exact_cd(h, n, max_passes, deadline):
    h = h.copy()
    c = np.correlate(h, 1.0 - h, mode='full')
    for _ in range(max_passes):
        if time.time() > deadline:
            break
        improved = False
        for p in range(n):
            h0 = h[p]
            if h0 < 1e-13 or h0 > 1.0 - 1e-13:
                continue
            xn = solve_coord(c, h, p, n)
            if abs(xn - h0) > 1e-13:
                delta = xn - h0
                m_min = max(0, n - 1 - p)
                m_max = min(2 * n - 2, 2 * n - 2 - p)
                ms = np.arange(m_min, m_max + 1)
                jf = p + ms - (n - 1)
                jb = p - ms + (n - 1)
                vf = (jf >= 0) & (jf < n)
                vb = (jb >= 0) & (jb < n)
                a = np.zeros(len(ms))
                if np.any(vf):
                    a[vf] += (1.0 - h[jf[vf]])
                if np.any(vb):
                    a[vb] -= h[jb[vb]]
                c[ms] += delta * a
                diag_i = np.where(ms == (n - 1))[0]
                if len(diag_i) > 0:
                    c[ms[diag_i[0]]] -= delta * delta
                h[p] = xn
                improved = True
        if not improved:
            break
        h = project_feasible(h, n)
        if abs(h.sum() - n / 2.0) > 1e-10:
            c = np.correlate(h, 1.0 - h, mode='full')
    return h, compute_c5(h, n)

def subgradient_polish(h, n, n_iter, deadline):
    h = h.copy()
    for i in range(n_iter):
        if time.time() > deadline:
            break
        c = np.correlate(h, 1.0 - h, mode='full')
        cur_max = c.max()
        top_k = max(2, int(0.05 * len(c)))
        threshold = np.sort(c)[-top_k]
        active = np.where(c >= threshold)[0]
        K = len(active)
        if K == 0:
            break
        grad = np.zeros(n)
        for m_idx in active:
            k = m_idx - (n - 1)
            if k >= 0:
                grad[:n-k] += (1.0 - h[k:n])
                grad[k:] -= h[:n-k]
            else:
                grad[-k:] += (1.0 - h[:n+k])
                grad[:n+k] -= h[-k:]
        grad /= K
        eta = 0.05 / (1.0 + 0.05 * i)
        for shr in [1.0, 0.3, 0.1]:
            h_new = h - eta * shr * grad
            h_new = project_feasible(h_new, n)
            c_new = np.max(np.correlate(h_new, 1.0 - h_new, mode='full'))
            if c_new < cur_max:
                h = h_new
                cur_max = c_new
                break
    return h, compute_c5(h, n)

def fw_escape(h, n, deadline):
    h_cur = h.copy()
    best_c = compute_c5(h_cur, n)
    for alpha in [500, 2000, 10000]:
        if time.time() > deadline:
            break
        c = np.correlate(h_cur, 1.0 - h_cur, mode='full')
        m = c.max()
        shifted = alpha * (c - m)
        mx = shifted.max()
        w = np.exp(shifted - mx)
        w /= w.sum()
        grad = np.zeros(n)
        for m_idx in range(len(w)):
            if w[m_idx] < 1e-12:
                continue
            k = m_idx - (n - 1)
            if k >= 0:
                grad[:n-k] += w[m_idx] * (1.0 - h_cur[k:n])
                grad[k:] -= w[m_idx] * h_cur[:n-k]
            else:
                grad[-k:] += w[m_idx] * (1.0 - h_cur[:n+k])
                grad[:n+k] -= w[m_idx] * h_cur[-k:]
        grad *= (2.0 / n)
        order = np.argsort(grad)
        s = np.zeros(n)
        cumulative = 0.0
        target = n / 2.0
        for ii in range(n):
            idx = order[ii]
            if cumulative + 1.0 <= target + 1e-12:
                s[idx] = 1.0
                cumulative += 1.0
            else:
                s[idx] = target - cumulative
                break
        for gamma in [0.01, 0.03, 0.05, 0.1, 0.2, 0.4]:
            h_new = (1.0 - gamma) * h_cur + gamma * s
            h_new = project_feasible(h_new, n)
            c_new = compute_c5(h_new, n)
            if c_new < best_c:
                h_cur = h_new
                best_c = c_new
    return h_cur, best_c

def _pair_obj(x, n, p, q, h_ref, alpha):
    h_ref[p] = x[0]
    h_ref[q] = x[1]
    c = np.correlate(h_ref, 1.0 - h_ref, mode='full')
    m = c.max()
    shifted = alpha * (c - m)
    mx_v = shifted.max()
    lse = mx_v + np.log(np.sum(np.exp(shifted - mx_v)))
    return (m + lse / alpha) * (2.0 / n)

def targeted_pair_opt(h, n, deadline, rng):
    h = h.copy()
    best_c = compute_c5(h, n)
    c = np.correlate(h, 1.0 - h, mode='full')
    for alpha in [5000, 20000]:
        if time.time() > deadline:
            break
        m = c.max()
        shifted = alpha * (c - m)
        mx_v = shifted.max()
        w = np.exp(shifted - mx_v)
        w /= w.sum()
        grad = np.zeros(n)
        for m_idx in range(len(w)):
            if w[m_idx] < 1e-10:
                continue
            k = m_idx - (n - 1)
            if k >= 0:
                grad[:n-k] += w[m_idx] * (1.0 - h[k:n])
                grad[k:] -= w[m_idx] * h[:n-k]
            else:
                grad[-k:] += w[m_idx] * (1.0 - h[:n+k])
                grad[:n+k] -= w[m_idx] * h[-k:]
        top_coords = np.argsort(np.abs(grad))[-12:][::-1]
        top_coords = top_coords[(h[top_coords] > 0.01) & (h[top_coords] < 0.99)]
        h_ref = h.copy()
        for ii in range(len(top_coords)):
            for jj in range(ii + 1, len(top_coords)):
                if time.time() > deadline:
                    break
                p, q = top_coords[ii], top_coords[jj]
                x0 = np.array([h[p], h[q]])
                h_ref[:] = h
                try:
                    res = minimize(_pair_obj, x0, args=(n, p, q, h_ref, alpha * 10),
                                   method='Nelder-Mead',
                                   options={'maxiter': 200, 'xatol': 1e-9, 'fatol': 1e-12, 'adaptive': True})
                    new_vals = np.clip(res.x, 0.0, 1.0)
                    h[p], h[q] = new_vals
                    h = project_feasible(h, n)
                    c_new = compute_c5(h, n)
                    if c_new < best_c:
                        best_c = c_new
                    c = np.correlate(h, 1.0 - h, mode='full')
                except Exception:
                    h_ref[:] = h
                    h[p], h[q] = x0
    return h, best_c

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    rng = np.random.RandomState(seed)
    deadline = t0 + budget_s - 10
    try:
        h_best = np.array(initial_h_values, dtype=float).copy()
        n = len(h_best)
    except Exception:
        h_best = np.full(700, 0.5)
        n = 700
    h_best = project_feasible(h_best, n)
    best_c = compute_c5(h_best, n)

    # Phase 1: Exact CD
    h1, c1 = exact_cd(h_best, n, 300, deadline)
    if c1 < best_c:
        h_best, best_c = h1, c1

    # Phase 2: Subgradient polish to escape
    h2, c2 = subgradient_polish(h_best, n, 500, deadline)
    if c2 < best_c:
        h_best, best_c = h2, c2

    # Phase 3: CD after subgradient
    h3, c3 = exact_cd(h_best, n, 200, deadline)
    if c3 < best_c:
        h_best, best_c = h3, c1 if c1 < c3 else h3, c3

    # Phase 4: Targeted pair optimization
    h4, c4 = targeted_pair_opt(h_best, n, deadline, rng)
    if c4 < best_c:
        h_best, best_c = h4, c4

    # Phase 5: CD after pair opt
    h5, c5 = exact_cd(h_best, n, 300, deadline)
    if c5 < best_c:
        h_best, best_c = h5, c5

    # Phase 6: FW escape
    h6, c6 = fw_escape(h_best, n, deadline)
    if c6 < best_c:
        h_best, best_c = h6, c6

    # Phase 7: Another round of subgradient + CD
    h7, c7 = subgradient_polish(h_best, n, 300, deadline)
    if c7 < best_c:
        h_best, best_c = h7, c7
    h8, c8 = exact_cd(h_best, n, 200, deadline)
    if c8 < best_c:
        h_best, best_c = h8, c8

    # Phase 8: More pair optimization with new info
    h9, c9 = targeted_pair_opt(h_best, n, deadline, rng)
    if c9 < best_c:
        h_best, best_c = h9, c9
    h10, c10 = exact_cd(h_best, n, 200, deadline)
    if c10 < best_c:
        h_best, best_c = h10, c10

    # Phase 9: Restart with perturbation in subgradient direction
    for r in range(5):
        if time.time() > deadline - 60:
            break
        c = np.correlate(h_best, 1.0 - h_best, mode='full')
        cur_max = c.max()
        top_k = max(2, int(0.05 * len(c)))
        threshold = np.sort(c)[-top_k]
        active = np.where(c >= threshold)[0]
        grad = np.zeros(n)
        for m_idx in active:
            k = m_idx - (n - 1)
            if k >= 0:
                grad[:n-k] += (1.0 - h_best[k:n])
                grad[k:] -= h_best[:n-k]
            else:
                grad[-k:] += (1.0 - h_best[:n+k])
                grad[:n+k] -= h_best[-k:]
        grad /= len(active)
        for temp in [0.002, 0.005]:
            hp = project_feasible(h_best - temp * grad + rng.normal(0, temp * 0.5, n), n)
            ho, co = exact_cd(hp, n, 150, deadline)
            if co < best_c:
                h_best, best_c = ho, co

    # Phase 10: Final polish
    if time.time() < deadline - 5:
        hf, cf = exact_cd(h_best, n, 100, deadline)
        if cf < best_c:
            h_best, best_c = hf, cf

    h_best = project_feasible(h_best, len(h_best))
    best_c = compute_c5(h_best, len(h_best))
    return h_best, best_c, len(h_best)
