**Approach: Direct non-smooth optimization via cutting planes**

The problem is:
minimize t
subject to c_k(h) ≤ t for all k
0 ≤ h ≤ 1
Σh = n/2

This is a non-convex problem (because c_k is non-convex). But we can use a sequential approach:
1. Start with a feasible h
2. Compute c_k for all k
3. Identify the violated constraints (c_k > t for some k)
4. Linearize c_k at the current h
5. Solve the resulting LP (or QP)
6. Iterate

This is essentially the "method of outer approximations" or "feasibility pump" approach.

But the linearization of c_k is:
c_k(h + Δ) ≈ c_k(h) + ∇c_k(h)·Δ

So the constraint becomes:
c_k(h) + ∇c_k(h)·Δ ≤ t

This is linear in (Δ, t). The LP would be:
minimize t
subject to c_k(h) + ∇c_k(h)·Δ ≤ t for active k
0 ≤ h + Δ ≤ 1
Σ(h + Δ) = n/2

This is a linear program! We can solve it with scipy.linprog.

But the issue is that the linearization is only valid locally. We need to keep a trust region or use successive linearization.

Actually, for this problem, the linearization gives a lower bound on c_k (since c_k is... wait, is c_k convex or concave?

c_k(h) = Σ_i h[i]*(1-h[i+k])

t_{k+1} = (1 + sqrt(1+4*t_k^2))/2

This has O(1/k^2) convergence rate for smooth functions, which is better than the O(1/k) of vanilla gradient descent.
