For coordinate p, the objective as a function of d is:

Actually, it's:

This is the max of (at most 2) quadratic/linear functions. The minimum of max of linear functions can be found in O(n) by checking all pairwise intersections. But with the quadratic term, it's a bit more complex.

Actually, the diagonal term only affects one specific correlation index. So:
- For k ≠ diag: f_k(d) = c_k + d*a_k (linear)
- For k = diag: f_diag(d) = c_diag + d*a_diag - d² (quadratic)

The max of these is a piecewise function. The minimum occurs where:
- Two linear functions cross, OR
- The quadratic touches one of the linear functions, OR
- The quadratic's vertex is below all linear functions

This can be solved in O(n log n) time (sort the linear functions by slope, find the upper envelope, then check where the quadratic intersects).

The objective is C5 = (2/n) * max_k c_k where c_k = sum_i h[i] * (1-h[i+k]).

Note that c_k = c_{-k} (the correlation is symmetric). So we only need to consider k ≥ 0 (or equivalently, k from 0 to n-1 in the correlate output, which corresponds to shifts from -(n-1) to n-1).

The correlation at shift 0 is: c_{n-1} = sum_i h[i](1-h[i]) = n/2 - sum h[i]²

To minimize the maximum, we want all c_k to be as equal as possible (as low as possible).

The average of all c_k (over k = -(n-1) to (n-1)) is:
(1/(2n-1)) * sum_k c_k = (1/(2n-1)) * sum_k sum_i h[i](1-h[i+k])

Each h[i] appears in c_k for k = -(n-1) to (n-1) (with appropriate bounds on i+k). The number of k values for which h[i] appears is at most 2n-1 (for i in the middle) or fewer (near the edges).
