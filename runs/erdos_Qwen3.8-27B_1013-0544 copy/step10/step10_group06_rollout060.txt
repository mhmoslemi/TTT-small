The problem is: min_h t s.t. c_k(h) ≤ t ∀k, sum h = n/2, 0≤h≤1.

For the dual to be bounded below, we need sum λ = 1.
Then: min_t t(1-1) = 0, and:
g(λ,μ) = min_{0≤h≤1, sum h=n/2} [sum_k λ_k c_k(h) + μ sum h]
= min_{0≤h≤1, sum h=n/2} [sum_k λ_k c_k(h)]  (since μ sum h = μ n/2 is constant)

So the dual problem is: max_{λ ≥ 0, sum λ = 1} min_{h feasible} sum_k λ_k c_k(h)

This is a max-min problem. We can solve it with:
- Outer: dual ascent on λ (gradient = c_k(h*) - t, normalized)
- Inner: solve min_h sum_k λ_k c_k(h) subject to constraints (a QP)

The inner QP is:
min_h sum_k λ_k sum_i h[i+k](1-h[i])
= min_h sum_k λ_k sum_i h[i+k] - sum_k λ_k sum_i h[i+k]h[i]

The first term is linear in h, the second is quadratic (h^T Q h where Q has specific structure).
