One more thought: the `project` function I wrote might not be optimal. The projection onto the set {h : 0 ≤ h_i ≤ 1, sum(h) = target_sum} is a well-studied problem. The optimal projection can be found by solving:

minimize sum_i (h_i - h_i*)^2
subject to 0 ≤ h_i ≤ 1, sum(h_i) = target_sum

This is solved by the "water-filling" algorithm: find a threshold tau such that:
h_i = clip(h_i* - tau, 0, 1) and sum(h_i) = target_sum

The threshold tau can be found by bisection.
