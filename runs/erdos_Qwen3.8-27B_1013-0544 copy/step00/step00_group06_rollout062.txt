Given the coordinate-wise linearity of C₅ (when other coordinates are fixed), here's a powerful coordinate descent:

For coordinate j, with all other coordinates fixed:
C₅(t) = max_k (a_k * t + b_k) for t = h[j]

where a_k and b_k are computed from the other coordinates.

The minimum of C₅(t) over t ∈ [0,1] (ignoring the sum constraint) can be found by:
- If all a_k ≤ 0: min at t=1
- If all a_k ≥ 0: min at t=0
- Otherwise: the minimum is at a point where two of the lines a_k*t + b_k cross, and that crossing point minimizes the maximum.

Actually, the minimum of max_k (a_k*t + b_k) over t is a classic problem. It's the smallest t such that... no, it's the C_CUSTOM: we want to find t that minimizes the maximum of these linear functions.

This is equivalent to finding the smallest C such that a_k*t + b_k ≤ C for all k, which means t ≥ (C - b_k)/a_k for a_k > 0 and t ≤ (C - b_k)/a_k for a_k < 0.

So for a given C, t must be in [max_{k: a_k>0} (C-b_k)/a_k, min_{k: a_k<0} (C-b_k)/a_k].

The optimal C* is the smallest C such that this interval is non-empty (and intersects [0,1]).

This can be found by binary search on C, or by finding the upper envelope of the lines and finding its minimum.

def optimize_pair_fast(h, j, m):
    """Optimize h[j] and h[m] maintaining sum. Uses delta formula."""
    n = len(h)
    dx = 2.0 / n
    c = h[j] + h[m]
    t_lo = max(0.0, c - 1.0)
    t_hi = min(1.0, c)
    if t_hi - t_lo < 1e-14:
        return compute_c5(h)
    
    old_j = h[j]
    old_m = h[m]
    
    # Compute current correlation
    corr = np.correlate(h, 1.0 - h, mode='full')
    
    # Compute d[p] = change per unit change in t (for the linear part)
    # d[p] = h[m-k] - h[j-k] - h[j+k] - h[m+k] where k = p - (n-1)
    offsets = np.arange(2 * n - 1) - (n - 1)
    
    def safe_h(idx):
        if 0 <= idx < n:
            return h[idx]
        return 0.0
    
    # Vectorized:
    j_minus_k = j - offsets  # j - k for each k
    m_minus_k = m - offsets
    j_plus_k = j + offsets
    m_plus_k = m + offsets
    
    d = np.zeros(2 * n - 1)
    mask1 = (j_minus_k >= 0) & (j_minus_k < n)
    mask2 = (m_minus_k >= 0) & (m_minus_k < n)
    mask3 = (j_plus_k >= 0) & (j_plus_k < n)
    mask4 = (m_plus_k >= 0) & (m_plus_k < n)
    
    d[mask2] += h[m_minus_k[mask2]]
    d[mask1] -= h[j_minus_k[mask1]]
    d[mask3] -= h[j_plus_k[mask3]]
    d[mask4] -= h[m_plus_k[mask4]]
    
    # But wait, I need to handle the special cases where indices coincide with j or m.
    # The formula d[p] = (new_corr[p] - old_corr[p]) / (t - old_j) is only valid
    # when the change in corr[p] is linear in t.
    # Special cases:
    # - j - k = m: then h_new[j-k] = h_new[m] = c-t, so the term t*(1-h_new[j-k]) = t*(1-c+t) is quadratic
    # - m - k = j: then h_new[m-k] = h_new[j] = t, so the term (c-t)*(1-h_new[m-k]) = (c-t)*(1-t) is quadratic
    # - j + k = m: then h_new[j+k] = h_new[m] = c-t, so the term h_new[j+k]*(1-t) = (c-t)*(1-t) is quadratic
    # - m + k = j: then h_new[m+k] = h_new[j] = t, so the term h_new[m+k]*(1-(c-t)) = t*(t-c+1) is quadratic
    
    # In these cases, the delta formula gives the WRONG value.
    # For the purpose of finding the optimal t, this means our "linear" model is slightly off
    # at a few lags. But since we'll verify with the actual C5 at the end, this should be OK
    # for finding a good candidate t.

    #              = max_p (d[p] * t + (corr[p] - old_j * d[p])) * dx
    
    base = corr - old_j * d  # b[p]

    ng = 80

    c5g = np.max(vals, axis=1) * dx
    bi = int(np.argmin(c5g))
    best_t = tg[bi]
    
    # Refine
    if 0 < bi < ng - 1:
        step = (t_hi - t_lo) / (ng - 1)
        tf = np.linspace(tg[bi-1], tg[bi+1], 80)
        vals_f = d[None, :] * tf[:, None] + base[None, :]
        c5f = np.max(vals_f, axis=1) * dx
        best_t = tf[int(np.argmin(c5f))]
    
    # Apply and verify

    h[m] = c - best_t

        # The linear approximation led to a worse solution; revert
        h[j] = old_j
