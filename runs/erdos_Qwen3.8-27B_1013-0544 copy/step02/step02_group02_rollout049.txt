Let me also consider a different approach: **coordinate descent with exact line search**.

For a fixed pair (i, j), the objective as a function of δ (where h[i] += δ, h[j] -= δ) is:
max_m (c[m] + δ * D[m]) * dx

where D[m] = (1-h[i+m-nm1]) - h[i-m+nm1] - (1-h[j+m-nm1]) + h[j-m+nm1]

This is the maximum of a set of linear functions of δ, so it's a convex piecewise-linear function. The minimum occurs where the maximum is minimized, which can be found by:
- Binary search on δ (since the function is convex)
- Or by finding the intersection point of the two "active" constraints

For a pair (i,j), we want to find δ that minimizes max_m (c[m] + δ*D[m]).
This is a 1D convex optimization problem. We can solve it by:
1. Finding the range of valid δ: max(0-h[i], 0-h[j]-... ) to min(1-h[i], 1-h[j]-...)
   Actually: 0 ≤ h[i]+δ ≤ 1 and 0 ≤ h[j]-δ ≤ 1
   So: max(-h[i], h[j]-1) ≤ δ ≤ min(1-h[i], h[j])
   
2. Within this range, minimize f(δ) = max_m (c[m] + δ*D[m])
   This is the minimum of a max of linear functions, which is convex.
   We can use ternary search or binary search on the derivative.

The derivative (subgradient) at δ is D[m*] where m* = argmax_m (c[m] + δ*D[m]).
The minimum is where 0 is in the subdifferential, i.e., where the max is "flat" or where two constraints are active with opposite slopes.

We can binary search: if D[argmax] > 0, we need to decrease δ; if D[argmax] < 0, increase δ.

This gives an exact line search for each pair! And it's O(n log n) per pair (O(n) to evaluate f and its subgradient, O(log n) bisections... actually O(n) bisections with O(1) convergence since we're doing bisection on a 1D interval).

Wait, bisection on δ: we need about 50 iterations to get 10 decimal digits of precision. Each iteration is O(n) to find the argmax. So O(50n) = O(4000) per pair. With C(80,2) = 3160 pairs, that's 3160 * 4000 = 12.6 million operations per full sweep. That's about 1-2 seconds per sweep. We can do many sweeps!

This is a **cyclic coordinate descent** approach with exact line search on each 2D coordinate. This is likely much more effective than random SA for fine-tuning.

    c_cor = np.correlate(best_h, 1.0 - best_h, mode='full')
    h_cd = best_h.copy()
    for sweep in range(3000):
        if remaining() < 200:
            break
        h_cd, c_cor, imp = coord_descent_sweep(h_cd, c_cor, n, m_arr, nm1, rng)
        c5_now = float(np.max(c_cor) * (2.0 / n))
        if c5_now < best_c5 - 1e-15:
            best_c5 = c5_now
            best_h = h_cd.copy()
        if imp == 0 and sweep > 10:
            # Stuck, perturb
            h_cd = best_h + rng.normal(0, 0.02, size=n)
            h_cd = project_feasible(h_cd, n)
            c_cor = np.correlate(h_cd, 1.0 - h_cd, mode='full')

    # Phase 3: SA for global exploration
    if remaining() > 150:
        c_sa = np.correlate(best_h, 1.0 - best_h, mode='full')
        h_sa, c5_sa = fast_sa(best_h, c_sa, n, m_arr, nm1, t0, budget_s,
                             rng, 2000000, 0.05, 1e-8)
        if c5_sa < best_c5:
            best_h, best_c5 = h_sa, c5_sa

    # Phase 4: More coordinate descent after SA
    if remaining() > 100:
        c_cor = np.correlate(best_h, 1.0 - best_h, mode='full')
        h_cd = best_h.copy()
        for sweep in range(3000):
            if remaining() < 50:
                break
            h_cd, c_cor, imp = coord_descent_sweep(h_cd, c_cor, n, m_arr, nm1, rng)
            c5_now = float(np.max(c_cor) * (2.0 / n))
            if c5_now < best_c5 - 1e-15:
                best_c5 = c5_now
                best_h = h_cd.copy()
            if imp == 0 and sweep > 10:
                h_cd = best_h + rng.normal(0, 0.01, size=n)
                h_cd = project_feasible(h_cd, n)
                c_cor = np.correlate(h_cd, 1.0 - h_cd, mode='full')

    # Phase 5: SLSQP polish
    for alpha in [100000, 500000, 2000000]:
        if remaining() < 10:
            break
        ht = slsqp_optimize(best_h, n, alpha, 3000, 1e-18)
        c = compute_c5(ht, n)
        if c < best_c5 - 1e-15:
            best_h, best_c5 = ht, c

    # Phase 6: Final coordinate descent
    if remaining() > 10:
        c_cor = np.correlate(best_h, 1.0 - best_h, mode='full')
        h_cd = best_h.copy()
        for sweep in range(500):
            if remaining() < 5:
                break
            h_cd, c_cor, imp = coord_descent_sweep(h_cd, c_cor, n, m_arr, nm1, rng)
            c5_now = float(np.max(c_cor) * (2.0 / n))
            if c5_now < best_c5 - 1e-15:
                best_c5 = c5_now
                best_h = h_cd.copy()

    # Final validation
    best_h = project_feasible(best_h, n)
    best_c5 = compute_c5(best_h, n)
    return best_h, best_c5, n
