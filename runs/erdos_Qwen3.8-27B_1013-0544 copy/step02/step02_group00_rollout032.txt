def corr_grad_single(h, d):
    """Gradient of correlation at signed lag d."""
    n = len(h)
    g = np.zeros(n)
    if d >= 0:
        m = n - d
        if m > 0:
            g[d:] += 1.0 - h[:m]
            g[:m] -= h[d:]
    else:
        l = -d
        m = n - l
        if m > 0:
            g[:m] += 1.0 - h[l:]
            g[l:] -= h[:m]

    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")

One key improvement: **use the gradient of the soft-max directly** rather than the subgradient of the max. The soft-max gradient is smooth and well-defined everywhere.

grad of soft_max(corr, beta) with respect to h:
= (1/beta) * sum_k exp(beta*(corr_k - max)) / sum_j exp(beta*(corr_j - max)) * d(corr_k)/dh

This is a weighted sum of the correlation gradients, with weights proportional to exp(beta*(corr_k - max)).

For large beta, this concentrates on the maximum lag. For small beta, it's a uniform average.

This is actually what the SLSQP approach does implicitly, but we can do it explicitly without the optimizer overhead.
