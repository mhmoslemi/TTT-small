Let me also think about a **faster 1D solver**. Instead of a grid, I can use:
- The optimal t is where the derivative of the max changes sign
- d/dt max_k (b_k + a_k * t) = a_k* where k* = argmax
- So I want a_k* ≈ 0 (or at a boundary)
- Algorithm: start at t=0, find k*, if a_k* > 0 move left (can't, at boundary), if a_k* < 0 increase t until another line overtakes

This is essentially the "farm-to-market" algorithm for the 1D case. Let me implement it:

```
def solve_1d_maximize_neg(a, b):
    # min_t max_k (b_k + a_k * t) for t in [0,1]
    # Equivalent to: -max_k(-b_k - a_k*t) is maximized... no.
    # Just find t* minimizing f(t) = max_k (b_k + a_k * t)
    
    # f is convex piecewise linear
    # Optimum is at a point where two lines tie, or at boundary
    
    # Simple approach: enumerate all pairs, find intersections in [0,1], check each
    # But that's O(n^2) which is fine for n=799
    
    # Actually, simpler: use the fact that at optimum, either t=0, t=1,
    # or the subgradient contains 0, meaning there exist k1, k2 with
    # a_k1 < 0 < a_k2 and b_k1 + a_k1*t = b_k2 + a_k2*t
    
    # Even simpler: just do a few iterations of:
    # 1. Find k* = argmax(b + a*t)
    # 2. If a_k* <= 0: optimal (or at t=0 boundary)
    # 3. If a_k* > 0: increase t; find the smallest t where another line overtakes
    #    t_new = min over k with a_k < a_k* of (b_k - b_k*)/(a_k* - a_k)
    
    # Let me just use a grid for simplicity and speed
    T = np.linspace(0, 1, 101)
    vals = np.max(b + T[:,None]*a, axis=1)
    idx = np.argmin(vals)
    return T[idx]
```

```python
    # First factor: h[j] appears as the first element
    # Valid when 0 <= j+shift < n, shift = p-(n-1)

        p_end = 2 * n - j - 2  # inclusive
        # h[j+shift] = h[j + p - (n-1)] = h[p - (n-1-j)]
```

```python
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    """Project h to {0≤h≤1, sum(h)=n/2}."""
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(1000):
        diff = target - h.sum()
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            # Need to increase sum: add to elements not at 1
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h += diff / s * room
        else:
            # Need to decrease sum: subtract from elements not at 0
            s = h.sum()
            if s < 1e-14:
                break
            h += diff / s * h
    return np.clip(h, 0.0, 1.0)

def coord_descent(h, n, deadline, steps_per_sweep=1, verbose=False):
    """Fractional coordinate descent for minimizing max correlation."""
    h = h.copy()
    n_corr = 2 * n - 1
    corr = np.correlate(h, 1 - h, mode='full').astype(float)
    cur_max = corr.max()
    best_h = h.copy()
    best_max = cur_max
    
    shift = np.arange(-(n-1), n)
    
    n_sweeps = 0
    while time.time() < deadline:
        n_sweeps += 1
        for j in range(n):
            # Compute delta arrays for h[j] going to 0 and 1
            # Currently h[j] has value h_j
            h_j = h[j]
            
            # Compute the coefficient a_p and constant b_p
            # c_p = b_p + a_p * t where t = h[j]
            # a_p = (1 - h[j+shift]) * I[valid1] - h[j-shift] * I[valid2]
            # b_p = c_p - a_p * h_j
            
            valid1 = (j + shift >= 0) & (j + shift < n)
            valid2 = (j - shift >= 0) & (j - shift < n)
            
            a = np.zeros(n_corr)
            a[valid1] = 1.0 - h[j + shift[valid1]]
            a[valid2] -= h[j - shift[valid2]]
            
            b = corr - a * h_j
            
            # Solve min_t max_p (b_p + a_p * t) for t in [0,1]
            # Use a grid
            T = np.linspace(0, 1, 50)
            vals = np.max(b[None, :] + T[:, None] * a[None, :], axis=1)
            t_new = T[np.argmin(vals)]
            
            # Update
            delta = t_new - h_j
            if abs(delta) > 1e-15:
                h[j] = t_new
                corr += delta * a
                cur_max = corr.max()
        
        # Project back to feasible set
        h = project_feasible(h, n)
        corr = np.correlate(h, 1 - h, mode='full')
        cur_max = corr.max()
        
        if cur_max < best_max:
            best_max = cur_max
            best_h = h.copy()
    
    return best_h, best_max
```

Let me think about the 1D subproblem solver more carefully. I said I'd use a grid, but let me think if there's a faster exact method.

min_t max_k (b_k + a_k * t) for t ∈ [0,1]

The function f(t) = max_k (b_k + a_k * t) is convex and piecewise linear. Its minimum is at:
- t = 0, or
- t = 1, or
- A point where f is not differentiable (i.e., where two or more lines achieve the max)

At an interior minimum, there must be at least two lines tied for the max, one with positive slope and one with negative slope (or one with zero slope).

Algorithm to find the minimum:
1. Compute f(0) and f(1)
2. Find the active line at t=0: k0 = argmax(b_k)
3. If a_k0 ≤ 0: f is decreasing at t=0, so minimum is at t > 0
4. Find the smallest t > 0 where another line overtakes: t = min over k ≠ k0, a_k < a_k0 of (b_k - b_k0)/(a_k0 - a_k), clipped to [0,1]
5. At that t, check if it's the minimum or if we need to continue

This is essentially walking along the upper envelope. In the worst case, it visits all n lines, but in practice it's much fewer.

Actually, for our purposes, a grid of 50-100 points is more than sufficient. The error from grid discretization is O(1/G) which is negligible.

But there's a subtlety: during the sweep, I'm updating h[j] one by one, and the intermediate states may violate the sum constraint. That's OK because I only project at the end of the sweep. The coordinate descent between projections is finding a local minimum of the objective without the sum constraint (subject to box constraints).

Actually, this might lead to poor results because the sum can drift far from n/2 during a sweep, and the projection at the end might undo a lot of progress.

Better approach: incorporate the sum constraint into the 1D subproblem. Use a Lagrange multiplier λ:

min_t max_k (b_k + a_k*t) + λ*t  for t ∈ [0,1]

This is: min_t max_k (b_k + a_k*t) + λ*t

The function max_k (b_k + a_k*t) + λ*t is still convex in t (max of affine + affine = max of affine). So the 1D solver still works, just with an extra term.

Update rule for λ: after each sweep, if sum(h) > n/2, increase λ (penalize increasing h); if sum(h) < n/2, decrease λ.

λ ← λ + μ * (sum(h) - n/2)

This is the dual ascent method.
