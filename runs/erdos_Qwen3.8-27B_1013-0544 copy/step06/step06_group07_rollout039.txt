**Smart coordinate descent for the smooth problem:**
For each coordinate i, the objective as a function of h[i] (with all other coordinates fixed) is:
max_m (A[m] + h[i] * B[i,m])

where A[m] and B[i,m] = 1 - h[i+m] - h[i-m] (the coefficient of h[i] in corr[m]).

This is a convex piecewise-linear function of h[i]. Its minimum over [0,1] is at a breakpoint or at 0 or 1.

The breakpoints occur where two different lags m1, m2 give the same value:
A[m1] + h[i]*B[i,m1] = A[m2] + h[i]*B[i,m2]
h[i] = (A[m2] - A[m1]) / (B[i,m1] - B[i,m2])

So the minimum is at:
- h[i] = 0
- h[i] = 1
- h[i] = (A[m2] - A[m1]) / (B[i,m1] - B[i,m2]) for some pair (m1, m2), clipped to [0,1]

We can find the minimum by trying all pairs of lags, but that's O(n^2) per coordinate, O(n^3) total. For n=250, that's 15.6M - feasible but maybe slow.

Alternatively, since the function is convex, we can use a 1D minimization (ternary search or golden section) which is O(log(1/eps)) evaluations, each O(n). So O(n * log(1/eps)) per coordinate, O(n^2 * log(1/eps)) total. Much better!
