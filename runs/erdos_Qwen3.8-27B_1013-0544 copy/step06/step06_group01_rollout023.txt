- p = softmax(alpha * (c_scaled - max(c_scaled)))

Then df/dh[j] = sum_k p[k] * d(c_scaled[k])/dh[j]

So my gradient computation is correct: grad[j] = dx * (t1 - t2).

Now, for the project_h function, I need to make sure it's correct. The projection onto {0 ≤ h ≤ 1, sum(h) = target} is:
h* = argmin ||x - h*||^2 s.t. 0 ≤ h*_i ≤ 1, sum(h*) = target

By KKT conditions: h*_i = clip(x_i - lambda, 0, 1) for some lambda.
We find lambda by bisection: sum(clip(x_i - lambda, 0, 1)) = target.

As lambda increases, each clip(x_i - lambda, 0, 1) is non-increasing, so the sum is non-increasing. We can bisect on lambda.

The range of lambda: if lambda ≤ min(x_i) - 1, all h*_i = 1, sum = n.
If lambda ≥ max(x_i), all h*_i = 0, sum = 0.
We want sum = target = n/2, so lambda is between min(x_i) and max(x_i).

Actually more carefully: h*_i = clip(x_i - lambda, 0, 1).
- If x_i - lambda > 1, i.e., lambda < x_i - 1, then h*_i = 1.
- If x_i - lambda < 0, i.e., lambda > x_i, then h*_i = 0.
- Otherwise h*_i = x_i - lambda.

So for lambda < min(x) - 1: sum = n.
For lambda > max(x): sum = 0.
We want sum = n/2, so lambda ∈ (min(x) - 1, max(x)) which is a valid range for bisection.
