    c = np.correlate(h, 1.0 - h, mode='full')
    return float(c.max()) * dx

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(1000):
        diff = target - h.sum()

For K=1, p=2: (1-h[1])·[0≤1<3 → T] - h[3]·[0≤3<3 → F] = (1-h[1]) - 0 = (1-h[1]) ✓



Now let me also handle the diagonal (K=0) correction for the quadratic term:
C[0] = sum h[i](1-h[i])
When we change h[p] to h[p]+δ:
C[0]_new = C[0] + δ(1-2h[p]) - δ²

So in the objective f(δ) = max_K (C[K] + δ·a_K), for K=0 we need to subtract δ².

                a[p_lo2:p_hi2+1] += -h[p_lo2+K : p_hi2+K+1]
            
            grad += a
        grad /= len(active)
        
        # Update with momentum
        v = beta * v - lr * grad
        h_new = h + v
        h_new = project_feasible(h_new, n)
        
        # Check improvement
        c_new = compute_c5(h_new, n)
        if c_new < compute_c5(h, n) + 0.01:  # allow some increase
            h = h_new
        else:
            v *= 0.5  # reduce momentum on failure

When we flip h[i] from 1 to 0 and h[j] from 0 to 1:
- For each lag K, the change in C[K] can be computed
- We need to check if the new max is smaller than the current max

The change in C[K] = C[K]_new - C[K]_old:
- h[i]: 1→0, h[j]: 0→1
- C[K] = sum_n h[n+K](1-h[n])
- Change from h[i]: 
  - As n+K=i (n=i-K): term goes from 1*(1-h[i-K]) to 0*(1-h[i-K]), change = -(1-h[i-K])
  - As n=i: term goes from h[i+K]*1 to h[i+K]*0, change = -h[i+K]
  - Total from h[i]: -(1-h[i-K]) - h[i+K]
- Change from h[j]:
  - As n+K=j (n=j-K): term goes from 1*(1-h[j-K]) to 0*(1-h[j-K])... wait, h[j] goes from 0 to 1
  - As n+K=j: h[j](1-h[j-K]) goes from 0 to (1-h[j-K]), change = +(1-h[j-K])
  - As n=j: h[j+K](1-h[j]) goes from h[j+K]*1 to h[j+K]*0, change = -h[j+K]
  - Total from h[j]: +(1-h[j-K]) - h[j+K]

So total change in C[K] = -(1-h[i-K]) - h[i+K] + (1-h[j-K]) - h[j+K]
= (1-h[j-K] - 1 + h[i-K]) - (h[i+K] + h[j+K])
= h[i-K] - h[j-K] - h[i+K] - h[j+K]

(with boundary handling: h[x] = 0 if x < 0 or x >= n)

This is O(1) per K (just 4 lookups), so O(n) total per flip. Much better!
