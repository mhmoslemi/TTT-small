    # Simpler: just evaluate the objective at several points and find the best
    # But let's do it more carefully.
    
    # For the simple case (no redistribution), the change in c[m] is:
    # c[m] + delta * A[m] - delta^2 * D[m]
    # where A[m] and D[m] depend on the structure.
    
    # Let's compute A and D:
    # c[m] = sum_i h[i] * (1-h[i+m-n+1]) for valid i
    # h[p] appears when i=p (first factor) or i+m-n+1=p i.e. i=p-m+n-1 (second factor)
    
    m_idx = np.arange(0, 2*n-1)
    lags = m_idx - (n-1)  # actual lag values from -(n-1) to n-1
    
    A = np.zeros(2*n-1)
    D = np.zeros(2*n-1)
    
    for m in range(2*n-1):
        lag = lags[m]
        # First factor: h[p] = h[i] where i=p, need i+lag in [0,n): p+lag in [0,n)
        #   contribution to c[m]: (1-h[p+lag]) * delta
        if 0 <= p + lag < n:
            A[m] += (1.0 - h[p + lag])
        # Second factor: 1-h[p] = 1-h[j] where j=p, need i in [0,n) and i+lag=p, so i=p-lag
        #   contribution to c[m]: h[p-lag] * (-delta)
        if 0 <= p - lag < n:
            A[m] -= h[p - lag]
        # Diagonal: both factors involve h[p], i.e., i=p and i+lag=p, so lag=0
        if lag == 0:
            D[m] += 1.0
    
    # Now c[m](delta) = c[m] + delta*A[m] - delta^2*D[m]
    # We want to minimize max_m c[m](delta) over delta in [lo, hi]
    # This is a concave function (max of concave functions), so min is at endpoints.
    # BUT: with the sum constraint, we need redistribution.
    
    # For now, ignore redistribution (the projection will handle it):
    # Evaluate at a few points:
    best_delta = 0.0
    best_val = float(c.max())
    
    # Since it's concave, check endpoints:
    for d in [lo, hi]:
        c_new = c + d * A - d*d * D
        val = float(c_new.max())
        if val < best_val:
            best_val = val
            best_delta = d
    
    # Also check middle (in case the projection changes things):
    for d in [lo*0.5, hi*0.5, (lo+hi)*0.25, (lo+hi)*0.75]:
        c_new = c + d * A - d*d * D
        val = float(c_new.max())
        if val < best_val:
            best_val = val
            best_delta = d
    
    return best_delta, best_val

Let me think about the pairwise coordinate descent more carefully.

For a swap: h[p] → h[p] + δ, h[q] → h[q] - δ, where δ ∈ [max(-h[p], h[q]-1), min(1-h[p], h[q])].

The change in c[m]:
- Terms involving h[p]: δ * (1-h[p+lag]) - δ*h[p-lag] (as before)
- Terms involving h[q]: -δ * (1-h[q+lag]) + δ*h[q-lag]
- Diagonal terms: -δ²*D_p[m] + δ²*D_q[m] (where D_p is 1 only at lag 0)

So the total change for c[m] is:
δ * (A_p[m] - A_q[m]) + δ² * (D_q[m] - D_p[m])

where A_p, A_q are the linear coefficient vectors and D_p, D_q are the diagonal indicators.

Since D_p = D_q = e_0 (the unit vector at the k=0 position in the correlation), D_q - D_p = 0!

So the change in c[m] is LINEAR in δ: c[m] + δ * (A_p[m] - A_q[m])

The max of linear functions is a convex function! And we want to MINIMIZE it. The minimum of a convex function is where the subgradient contains 0, or at a boundary.

So for the swap move, the 1D subproblem is: minimize max_m (c[m] + δ * B[m]) over δ ∈ [δ_lo, δ_hi], where B = A_p - A_q.

This is a classic "minimize max of linear functions" problem. The minimum is at a point where at least two of the linear functions are equal and the slopes change sign, or at a boundary.

We can solve this exactly:
1. Sort the lines by their value at δ=0 (which is just c[m])
2. The upper envelope is determined by the lines in order of slope
3. Find the point where the upper envelope is minimized

Actually, a simpler approach: bisection on the subgradient. The subgradient of f(δ) = max_m (c[m] + δ*B[m]) at δ is the set {B[m] : m is active (c[m]+δ*B[m] = f(δ))}. We want to find δ where 0 is in the subgradient, i.e., there exist active m1, m2 with B[m1] < 0 < B[m2] (or B[m] = 0 for some active m).

Bisection:
- If all active B[m] > 0, increase δ (the max is increasing, so we need to go left... wait, no. If the active lines have positive slope, increasing δ increases f, so we should decrease δ.)
- If all active B[m] < 0, decrease δ.
- If 0 is in the subgradient (some active B > 0 and some active B < 0), we're at the minimum.

This gives an exact solution in O(log(1/ε) * n) time.

This is a key improvement! The pairwise coordinate descent with exact 1D line search is much more efficient than the grid search in the previous code.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full')
    return float(c.max()) * dx

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(300):
        diff = target - h.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def swap_line_search(h, p, q, n, c):
    """Find optimal delta for swap h[p]+=delta, h[q]-=delta."""
    hp, hq = h[p], h[q]
    d_lo = max(-hp, hq - 1.0)
    d_hi = min(1.0 - hp, hq)
    if d_lo >= d_hi - 1e-15:
        return 0.0
    
    # Compute B[m] = A_p[m] - A_q[m]
    # A_p[m]: change in c[m] per unit delta in h[p] (linear part)
    # For lag k (where k = m - (n-1)):
    #   h[p] in first factor: needs 0 <= p+k < n, contributes (1-h[p+k])
    #   h[p] in second factor: needs 0 <= p-k < n, contributes -h[p-k]
    
    lags = np.arange(-(n-1), n)  # shape (2n-1,)
    
    # For position p:
    valid_f_p = (p + lags >= 0) & (p + lags < n)
    valid_b_p = (p - lags >= 0) & (p - lags < n)
    A_p = np.zeros(2*n-1)
    A_p[valid_f_p] += (1.0 - h[p + lags[valid_f_p]])
    A_p[valid_b_p] -= h[p - lags[valid_b_p]]
    
    # For position q:
    valid_f_q = (q + lags >= 0) & (q + lags < n)
    valid_b_q = (q - lags >= 0) & (q - lags < n)
    A_q = np.zeros(2*n-1)
    A_q[valid_f_q] += (1.0 - h[q + lags[valid_f_q]])
    A_q[valid_b_q] -= h[q - lags[valid_b_q]]
    
    B = A_p - A_q
    
    # Minimize max_m (c[m] + delta * B[m]) over delta in [d_lo, d_hi]
    # Bisection on subgradient:
    lo, hi = d_lo, d_hi
    for _ in range(40):
        mid = (lo + hi) / 2
        vals = c + mid * B
        active_max = vals.max()
        active = vals >= active_max - 1e-14
        if np.any(active):
            min_slope = B[active].min()
            max_slope = B[active].max()
            if min_slope > 1e-14:
                # f increasing at mid, go left
                hi = mid
            elif max_slope < -1e-14:
                # f decreasing at mid, go right
                lo = mid
            else:
                # 0 in subgradient, found minimum
                break
    delta = (lo + hi) / 2
    return delta
