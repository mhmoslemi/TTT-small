So first sum j ranges from 0 to n-1.

First sum = sum_{j=0}^{n-1} w[p-j+n-1] * (1-h[j])

Second sum: let j = p+K, K = j-p. j ∈ [0, n-1] and K = j-p ∈ [-(n-1), n-1]:
j-p ≥ -(n-1) → j ≥ p-(n-1) = p-n+1 (always true for j≥0 when p≤n-1)
j-p ≤ n-1 → j ≤ p+n-1 (always true for j≤n-1)

So j ranges from 0 to n-1.

Second sum = sum_{j=0}^{n-1} w[j-p+n-1] * h[j]

Therefore:
df/dh[p] = dx * [sum_{j=0}^{n-1} w[p-j+n-1] * (1-h[j]) - sum_{j=0}^{n-1} w[j-p+n-1] * h[j]]
