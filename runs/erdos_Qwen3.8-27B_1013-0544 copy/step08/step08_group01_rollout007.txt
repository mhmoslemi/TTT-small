1. Compute all overlaps O(k)
2. Let t = max_k O(k)
3. For a few iterations:
   a. Compute the "excess" for each k: e(k) = max(0, O(k) - t_target) where t_target is slightly below current max
   b. Compute the gradient of each O(k) with respect to h
   c. Take a step in the direction -sum_k e(k) * grad_k / sum_k e(k)
   d. Project onto feasible set
   e. If max decreased, update t_target
   f. Else, reduce step size

This is essentially a projected subgradient method with a smart choice of which gradients to use.

Let me implement this properly. The gradient of O(k) with respect to h[i] is:
∂O(k)/∂h[i] = (1 - h[i+k-(n-1)]) - h[i-k+(n-1)] (when both indices are valid)

More precisely:
∂O(k)/∂h[i] = sum over terms where h[i] appears:
- h[i] appears as the first factor in O(k) when i is in [0,n-1] and 0 <= i+k-(n-1) < n: contributes (1-h[i+k-(n-1)])
- h[i] appears as the second factor (inside 1-h[.]) when 0 <= i-k+(n-1) < n: contributes -h[i-k+(n-1)]

So: ∂O(k)/∂h[i] = [(1-h[i+k-(n-1)]) * I(0<=i+k-(n-1)<n)] - [h[i-k+(n-1)] * I(0<=i-k+(n-1)<n)]

For the multi-gradient step:
direction = -sum_{k in active} w_k * grad_O(k)
where w_k = (O(k) - t_target)^+ / sum_j (O(j) - t_target)^+

This is a weighted average of the gradients of the active constraints.

def grad_overlap(h, n, k):
    """Gradient of O(k) = sum_i h[i]*(1-h[i+k-(n-1)]) wrt h."""
    g = np.zeros(n)
    jf = k - (n - 1)
    lo = max(0, -jf)
    hi = min(n, n - jf)
    if lo < hi:
        g[lo:hi] += (1.0 - h[lo + jf:hi + jf])
    jb = (n - 1) - k
    lo2 = max(0, -jb)
    hi2 = min(n, n - jb)
    if lo2 < hi2:
        g[lo2:hi2] -= h[lo2 + jb:hi2 + jb]
    return g

    h_flip = project_feasible(1.0 - best_h, len(best_h))
    c_flip = compute_c5(h_flip, len(best_h))
    if c_flip < best_c:
        best_h, best_c = h_flip, c_flip

    best_h = project_feasible(best_h, len(best_h))
    best_c = compute_c5(best_h, len(best_h))
    return best_h, best_c, len(best_h)
