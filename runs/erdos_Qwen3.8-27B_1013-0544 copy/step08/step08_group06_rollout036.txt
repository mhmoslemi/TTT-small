I need to be smarter. For a two-interval function, I can compute the correlation analytically!

For h = 1_{[a, a+ℓ₁]} + 1_{[b, b+ℓ₂]}:
The correlation at shift k (in continuous terms) is:
∫₀² h(x)(1-h(x+k)) dx

Let S = [a, a+ℓ₁] ∪ [b, b+ℓ₂] (the support of h).
h(x)(1-h(x+k)) = 1_{S}(x) * 1_{S^c}(x+k) = 1_{S}(x) * 1_{(S-k)^c}(x)

So the integral is |S \ (S-k)| = |S| - |S ∩ (S-k)| = 1 - |S ∩ (S-k)|

And |S ∩ (S-k)| is the cross-correlation of the indicator of S with itself, which for a union of two intervals can be computed as:
|I₁ ∩ (I₁-k)| + |I₁ ∩ (I₂-k)| + |I₂ ∩ (I₁-k)| + |I₂ ∩ (I₂-k)|

where I₁ = [a, a+ℓ₁] and I₂ = [b, b+ℓ₂].

Each term |I_j ∩ (I_l - k)| is the length of the intersection of two intervals, which is:
max(0, min(end_j, end_l - k) - max(start_j, start_l - k))

So for a two-interval function, I can compute the continuous C₅ in O(1) per shift k (since there are only 4 terms per k). Then I just need to find the max over k, which is a 1D optimization.

Actually, the function |S ∩ (S-k)| is piecewise linear in k (since it's a sum of max(0, min(...)-max(...)) terms, each of which is piecewise linear). So the maximum of 1 - |S∩(S-k)| is at one of the "break points" or at the boundaries.

The break points occur where the endpoints of S and S-k coincide:
a, a+ℓ₁, b, b+ℓ₂, a+k, a+ℓ₁+k, b+k, b+ℓ₂+k (for various k)

So the break points in k are: 0, ℓ₁, ℓ₂, b-a, b-a+ℓ₁, b+ℓ₂-a, b+ℓ₂-a+ℓ₁, etc.

There are O(1) break points, so I can evaluate C₅ at all of them to find the maximum.

This gives me an O(1) evaluation of C₅ for a two-interval function! Then I can do a fine grid search in 3D.

    # S = [a, a+l1] ∪ [b, b+l2]
    # C5 = max_k (1 - |S ∩ (S-k)|) where the intersection is computed on [0,2]
    # Actually, we need: max_k ∫₀² h(x)(1-h(x+k))dx
    # = max_k (|S ∩ [0,2]| - |S ∩ (S-k) ∩ [0,2]|)
    # But S ⊂ [0,2], so |S ∩ [0,2]| = 1 (by constraint)
    # And S ∩ (S-k) ∩ [0,2] = (S ∩ (S-k)) since S ⊂ [0,2]
    # Wait, (S-k) might extend outside [0,2], but S ∩ (S-k) is still within [0,2] since S ⊂ [0,2]
    
    # |S ∩ (S-k)| = |I₁ ∩ (I₁-k)| + |I₁ ∩ (I₂-k)| + |I₂ ∩ (I₁-k)| + |I₂ ∩ (I₂-k)|
    # where I₁ = [a, a+l1], I₂ = [b, b+l2]
    
    # For a given k, |I ∩ (J-k)| = max(0, min(I[1], J[1]-k) - max(I[0], J[0]-k))
    
    # The function f(k) = |S ∩ (S-k)| is piecewise linear in k
    # Break points: where any endpoint of I equals any endpoint of J-k
    # I₁ = [a, a+l1], I₁-k = [a-k, a+l1-k]
    # Break points for |I₁ ∩ (I₁-k)|: k = 0, k = l1 (when a+l1-k = a, i.e., k = l1)
    # For |I₁ ∩ (I₂-k)|: a = b-k, a = b+l2-k, a+l1 = b-k, a+l1 = b+l2-k
    #   k = b-a, k = b-a+l2, k = b-a-l1, k = b-a+l2-l1

    breakpoints.add(a - b)

            hi = min(i1e, j1e - k)
            return max(0, hi - lo)

                   interval_overlap(b, b+l2, a, a+l1, k) +
                   interval_overlap(b, b+l2, b, b+l2, k))

        if val > max_val:

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def two_interval_c5(a, l1, b):
    """Compute continuous C5 for h = 1_[a,a+l1] + 1_[b,b+1-l1]."""
    l2 = 1.0 - l1
    # Must have b + l2 <= 2 and a + l1 <= b
    if b + l2 > 2 + 1e-10 or a + l1 > b + 1e-10 or a < -1e-10 or l1 < -1e-10 or l2 < -1e-10:
        return 1.0  # infeasible
    
    def int_overlap(s1, e1, s2, e2, k):
        # |I1 ∩ (I2 - k)| where I1=[s1,e1], I2=[s2,e2]
        lo = max(s1, s2 - k)
        hi = min(e1, e2 - k)
        return max(0.0, hi - lo)
    
    # Break points in k
    k_set = {0.0, l1, l2, 2.0, -2.0}
    for da in (a, a + l1):
        for db in (b, b + l2):
            k_set.add(db - da)
    k_candidates = sorted(k for k in k_set if -2.0 <= k <= 2.0)
    # Add midpoints
    for i in range(len(k_candidates) - 1):
        k_candidates.append((k_candidates[i] + k_candidates[i+1]) / 2)
    
    max_val = 0.0
    for k in k_candidates:
        ov = (int_overlap(a, a+l1, a, a+l1, k) +
              int_overlap(a, a+l1, b, b+l2, k) +
              int_overlap(b, b+l2, a, a+l1, k) +
              int_overlap(b, b+l2, b, b+l2, k))
        val = 1.0 - ov
        if val > max_val:
            max_val = val
    return max_val

    """Grid search for best two-interval solution."""
    best_c = 1.0

        if diff > 0:
            room = 1.0 - h
            tot = room.sum()

            if tot < 1e-15:

    lo = max(s1, s2 - k)
    hi = min(e1, e2 - k)
    return max(0.0, hi - lo)

def two_int_c5(a, l1, b):
    l2 = 1.0 - l1
    if a < -1e-9 or l1 < 0 or l2 < 0 or b + l2 > 2 + 1e-9 or a + l1 > b + 1e-9:
