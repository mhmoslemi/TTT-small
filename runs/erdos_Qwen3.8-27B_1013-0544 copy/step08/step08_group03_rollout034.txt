Actually, let me try a different approach entirely. What about **Frank-Wolfe** (conditional gradient)?

The problem: min f(h) = max_k c[k](h) subject to h in P = {h : 0<=h<=1, sum(h)=n/2}

Frank-Wolfe iteration:
1. Find s = argmin_{v in P} <g, v> where g is subgradient of f at h
2. h_new = (1-t)*h + t*s for some step size t

Step 1 is easy: s[i] = 0 if g[i] > 0, s[i] = 1 if g[i] < 0, and we need sum(s) = n/2, so we set the top n/2 coordinates (by -g[i]) to 1 and the rest to 0.

This gives a "bang-bang" direction. The step size can be chosen by line search.

The advantage: each Frank-Wolfe step is O(n log n) (sorting). The disadvantage: Frank-Wolfe converges slowly (O(1/t)) for non-strongly-convex problems.

But combined with CD, it might work well: FW provides global guidance, CD provides local refinement.

```python
def fw_step(h, n, c_full, alpha=0.1):
    """One Frank-Wolfe step."""
    mx = float(c_full.max())
    tol = max(1e-6, 0.01 * mx)
    active = np.where(c_full >= mx - tol)[0]
    
    # Subgradient: average gradient over active set
    g = np.zeros(n)
    # For each active k, compute grad c_full[k] wrt h
    # c_full[k] = sum_i h[i+k] * (1-h[i]) (with appropriate index range)
    # This is: np.correlate(h, 1-h, 'full')[k]
    # 
    # d/dh[j] of c_full[k]:
    # h[j] appears in c_full[k] as:
    #   - as h[i+k] where i = j-k (if 0 <= j-k < n): contributes (1-h[j-k])
    #   - as (1-h[i]) where i = j: contributes -h[j+k] (if 0 <= j+k < n)
    # So d c_full[k]/dh[j] = (1-h[j-k]) * I(0<=j-k<n) - h[j+k] * I(0<=j+k<n)
    
    for k in active:
        # k is the index into the full correlation array (0 to 2n-2)
        # The lag is k - (n-1)
        lag = k - (n - 1)
        # h[j] as h[i+k] where i = j - lag = j - k + (n-1)
        # Valid if 0 <= j - lag < n, i.e., lag <= j < lag + n
        # h[j] as (1-h[i]) where i = j
        # Valid if 0 <= j < n (always) and 0 <= j + lag < n, i.e., -lag <= j < n - lag
        
        # Contribution 1: (1-h[j-lag]) for j in [max(0,lag), min(n-1, lag+n-1)]
        # Contribution 2: -h[j+lag] for j in [max(0,-lag), min(n-1, n-1-lag)]
        
        lo1 = max(0, lag)
        hi1 = min(n-1, lag + n - 1)
        if lo1 <= hi1:
            g[lo1:hi1+1] += 1.0 - h[lo1-lag:hi1-lag+1]
        
        lo2 = max(0, -lag)
        hi2 = min(n-1, n-1-lag)
        if lo2 <= hi2:
            g[lo2:hi2+1] -= h[lo2+lag:hi2+lag+1]
    
    g /= len(active)
    
    # FW: find s in P minimizing <g, s>
    # s[i] = 1 for the n/2 smallest g[i], 0 otherwise
    order = np.argsort(g)
    s = np.zeros(n)
    s[order[:n//2]] = 1.0
    
    # Line search for step size
    best_t = alpha
    best_obj = float('inf')
    for t in [alpha, alpha*0.5, alpha*0.25, alpha*0.1]:
        h_new = (1-t)*h + t*s
        h_new = project_feasible(h_new, n)
        c_new = np.correlate(h_new, 1.0-h_new, mode='full')
        obj = float(c_new.max())
        if obj < best_obj:
            best_obj = obj
            best_t = t
    
    return (1-best_t)*h + best_t*s
```
