def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)

The problem is:
min_h max_m c[m](h) * dx
s.t. 0 ≤ h ≤ 1, sum(h) = n/2

where c(h) = correlate(h, 1-h, 'full').

This is a min-max problem. We can use the von Neumann minimax theorem or a dual approach.

The dual: max_λ min_h sum_m λ[m] * c[m](h) * dx
s.t. λ ≥ 0, sum λ = 1, 0 ≤ h ≤ 1, sum(h) = n/2

The inner problem is: min_h sum_m λ[m] * c[m](h) * dx s.t. constraints.

Since c[m](h) = sum_i h[i]*(1-h[i+m-n+1]), the objective is:
sum_i [h[i]*(1-h[i]) * λ[n-1] + sum_{m≠n-1} λ[m] * h[i]*(1-h[i+m-n+1])]

This is a quadratic in h! Specifically, it's a sum of terms of the form h[i]*(1-h[j]) which is bilinear.

So the dual inner problem is:
min_h Q(h) = sum_{i,j} A[i,j] * h[i] * h[j] + linear terms
s.t. 0 ≤ h ≤ 1, sum(h) = n/2

where A is a symmetric matrix (since h[i]*(1-h[j]) = h[i] - h[i]*h[j]).

Wait: h[i]*(1-h[j]) = h[i] - h[i]*h[j]. So the objective is:
sum_m λ[m] * sum_i (h[i] - h[i]*h[i+m-n+1]) * dx
= (sum_m λ[m]) * (sum_i h[i]) * dx - (sum_m λ[m] * sum_i h[i]*h[i+m-n+1]) * dx
= (sum_i h[i]) * dx - (sum_m λ[m] * sum_i h[i]*h[i+m-n+1]) * dx
= 1 - dx * h^T B h

where B[i,j] = sum_m λ[m] * 1_{j = i+m-n+1} = λ[j-i+n-1] (if 0 ≤ j-i+n-1 ≤ 2n-2)

So B is a Toeplitz matrix! And the inner problem is:
max_h dx * h^T B h - 1  (equivalently, max h^T B h)
s.t. 0 ≤ h ≤ 1, sum(h) = n/2

This is a quadratic program with a Toeplitz matrix! This is much more structured than the original problem.

For fixed λ, we can solve this QP. Then we use subgradient/Lambda iteration to update λ to maximize the inner value (which equals the max correlation by von Neumann).

This is essentially the multiplicative weights / column generation approach for the max.

The key advantage: for a given λ, the QP has a Toeplitz structure that can be exploited (e.g., via conjugate gradient with FFT for the matrix-vector product).

import numpy as np
from scipy.optimize import minimize

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h = np.minimum(1.0, h + diff / tot * room)
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h = np.maximum(0.0, h + diff / tot * h)
    return np.clip(h, 0.0, 1.0)

def coord_descent(h, n, max_passes=500, deadline=None, seed=0):
    rng = np.random.RandomState(seed)
    h = h.copy()

    for it in range(max_passes):

                continue

            ps = p + s
            pm = p - s
            a = np.zeros(2 * n - 1)
            v1 = (ps >= 0) & (ps < n)
            v2 = (pm >= 0) & (pm < n)
            a[v1] += (1.0 - h[ps[v1]])
            a[v2] -= h[pm[v2]]
            b = c - a * h0
            lo, hi = 0.0, 1.0
            for _ in range(42):
                mid = (lo + hi) * 0.5
                vals = a * mid + b
                vals[n - 1] = c[n - 1] - h0 * (1 - h0) + mid * (1 - mid)
                eps = (hi - lo) * 0.4
                vals_r = a * (mid + eps) + b

def fista_smooth(h, n, alpha, n_iter=2000, deadline=None):
    x = h.copy()
    z = x.copy()

    L = 5.0
    for it in range(n_iter):

        w /= w.sum()
        u = 1.0 - z
        grad = np.zeros(n)
        for p in range(n):
            lo = max(0, n - 1 - p)
            hi = min(2 * n - 2, 2 * n - 2 - p)
            if lo <= hi:
                grad[p] += np.dot(w[lo:hi + 1], u[n - 1 - p:2 * n - 1 - p + 1])
            lo2 = max(0, p)
            hi2 = min(2 * n - 2, p + n - 1)
            if lo2 <= hi2:
                g[p - hi2 - (n - 1):p - lo2 - (n - 1) + 1] += 0  # placeholder

        y = z - (1.0 / L) * (dx * grad)
