**Practical approach: Enhanced coordinate descent with exact 1D solution**

For each coordinate p, I'll:
1. Compute the affected k values and their coefficients (A[k] for linear, and the quadratic for k=n-1)
2. Find the top M "competitive" k values (those with c[k] + A[k]*d_max close to the current max, where d_max = 1-h[p])
3. Find all intersection points among these M lines and the quadratic
4. Evaluate the max at each intersection point and at boundaries
5. Take the best d

This should be O(M²) per coordinate, with M ≈ 20-50, giving ~2500 evaluations per coordinate. For n=700 coordinates, that's ~1.75M per pass. At ~100ns per evaluation, that's ~0.175s per pass. Very fast!

Actually wait, I realize there's an even simpler approach that's likely to work well:

**Since the 1D problem is "max of lines + one concave parabola", the minimum is at a point where two of these curves intersect (or at the boundary, or at the parabola vertex).**

The key insight: the upper envelope of {M lines + 1 parabola} has O(M) vertices (breakpoints). We can find them by:
1. Computing the upper envelope (like the convex hull but for the upper side)
2. The minimum of the envelope is at one of its local minima, which are at the breakpoints

For M lines, the upper envelope can be computed in O(M log M) time using a divide-and-conquer or a sweep. But for M ≤ 50, just checking all O(M²) intersections is fine.

    n = len(h)
    h0 = h[p]
    if h0 <= 1e-15 or h0 >= 1.0 - 1e-15:
        return 0.0
    
    d_lo, d_hi = -h0, 1.0 - h0
    
    # Compute unaffected max
    m_lo = max(0, n - 1 - p)
    m_hi = min(2 * n - 2, n - 1 + p)
    ms = np.arange(m_lo, m_hi + 1)
    
    # Affine coefficients
    jf = p + ms - (n - 1)
    jb = p - ms + (n - 1)
    A = np.zeros(len(ms))
    valid_f = (jf >= 0) & (jf < n)
    valid_b = (jb >= 0) & (jb < n)
    A[valid_f] += (1.0 - h[jf[valid_f]])
    A[valid_b] -= h[jb[valid_b]]
    
    # For k = n-1 (the diagonal), the formula is different (quadratic)
    diag_pos = np.where(ms == (n - 1))[0]

    diag_idx = int(diag_pos[0]) if has_diag else -1
    
    c_aff = c[ms]

    unaff_max = 0.0
    if m_lo > 0:

    if m_hi < 2 * n - 2:

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def compute_correlation(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h = np.clip(h + (diff / tot) * room, 0.0, 1.0)
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h = np.clip(h + (diff / tot) * h, 0.0, 1.0)
    return h

def eval_at_d(c_aff, A, d, diag_idx, has_diag):

    jb = p - ms + (n - 1)
    A = np.zeros(len(ms))

                h[p] = h0 + d_opt
                improved = True

def smooth_obj(x, n, alpha):
    c = np.correlate(x, 1.0 - x, mode='full')
    m = c.max()
    shifted = alpha * (c - m)
    mx = shifted.max()
    lse = mx + np.log(np.sum(np.exp(shifted - mx)))
    return (m + lse / alpha) * (2.0 / n)

def _sum_eq(x, n):
    return x.sum() - n / 2.0

def _sum_eq_jac(x, n):
    return np.ones(n)

    best_h = h.copy()
    best_c = compute_c5(h, n)
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _sum_eq, 'jac': _sum_eq_jac, 'args': (n,)}]
    for alpha in alphas:
        try:
            res = minimize(smooth_obj, best_h, args=(n, alpha), method='SLSQP',
                           bounds=bounds, constraints=cons,
                           options={'maxiter': maxiter_each, 'ftol': 1e-18})
            new_h = project_feasible(res.x, n)
            new_c = compute_c5(new_h, n)
            if new_c < best_c:
                best_h, best_c = new_h, new_c
        except Exception:
            pass
    return best_h, best_c
