Actually for our problem, the overlap for shift k is:

= |{x ∈ A : x+k ∉ A}| (for k > 0)

So we want to minimize max_k |{x ∈ A : x+k ∉ A}|.

This is the "one-sided discrepancy" or the number of "edges" in the directed graph from A to complement, maximized over all shifts.

For a set A of measure 1 in [0,2], the minimum possible maximum one-sided discrepancy is related to the structure of A.

If A is an interval of length 1, say [0,1], then for shift k:
|{x ∈ [0,1] : x+k ∉ [0,1]}| = |{x ∈ [0,1] : x+k > 1 or x+k < 0}| = min(k, 1) for k ∈ [0,1] (x+k > 1 when x > 1-k)

So the max is 1 (at k=1), giving C₅ = 1*2/2 = 1... wait no.

Actually for continuous case: ∫₀² 1_[0,1](x) * 1_[0,1](x+k)^c dx

For k ∈ (0,1): x ∈ [0,1] and x+k ∉ [0,1] means x+k > 1, so x > 1-k. The integral is ∫_{1-k}^1 dx = k.
For k ∈ (1,2): x ∈ [0,1] and x+k ∉ [0,1] means x+k > 1 (always since x≥0, k>1) or x+k < 0 (impossible). So the integral is ∫₀^1 dx = 1.
For k ∈ (-1, 0): by symmetry, same as positive.
For k ∈ (-2, -1): integral = 1.

So max is 1, giving C₅ = 1*2 = 2. That's terrible.

We need a much more structured set. The goal is to have |{x ∈ A : x+k ∉ A}| small for ALL k simultaneously.

This is related to the "tiling" or "difference set" problem. If A is a "difference set" in the sense that every element of the group can be written as a difference of elements of A in exactly the same number of ways, then the discrepancy is constant.

In the continuous case on [0,2] (which is a circle of circumference 2 if we identify 0 and 2), we want A ⊂ [0,2) of measure 1 such that the "one-sided difference" is as uniform as possible.

If A is a "perfect" set where every shift k gives the same overlap, then the overlap would be:

So the average overlap is 1/2 (dividing by 2 for the range of k). If it's constant, each overlap is 1/2.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(300):
        diff = target - h.sum()
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h = np.clip(h + (diff / tot) * room, 0.0, 1.0)
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h = np.clip(h + (diff / tot) * h, 0.0, 1.0)
    return h

def smooth_obj(x, n, alpha, pen):
    c = np.correlate(x, 1.0 - x, mode='full')
    m = c.max()
    shifted = alpha * (c - m)
    mx = shifted.max()
    lse = mx + np.log(np.sum(np.exp(shifted - mx)))
    base = (m + lse / alpha) * (2.0 / n)
    s = x.sum() - n / 2.0
    return base + pen * s * s

def _sq(x, n):
    return x.sum() - n / 2.0

def _sq_j(x, n):
    return np.ones(n)

def slsqp(h, n, alphas, maxiter, deadline):
    best_h = h.copy()
    best_c = compute_c5(h, n)
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _sq, 'jac': _sq_j, 'args': (n,)}]
    for a in alphas:
        if time.time() > deadline:
            break
        for pen in [0.0, 1.0]:
            try:
                res = minimize(smooth_obj, best_h, args=(n, a, pen), method='SLSQP',
                               bounds=bounds, constraints=cons if pen == 0 else [],
                               options={'maxiter': maxiter, 'ftol': 1e-18})
                nh = project_feasible(res.x, n)
                nc = compute_c5(nh, n)
                if nc < best_c:

            except Exception:

def coord_descent(h, n, max_passes, deadline, gs_iters=55):
    h = h.copy()
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    for _ in range(max_passes):
        if time.time() > deadline:
            break
        c = np.correlate(h, 1.0 - h, mode='full')
        improved = False
        order = list(range(n))
        for p in order:
            if time.time() > deadline:
                break
            h0 = h[p]
            if h0 <= 1e-12 or h0 >= 1.0 - 1e-12:
                continue
            k_lo = max(0, n - 1 - p)
            k_hi = min(2 * n - 2, 2 * n - 2 - p)
            ks = np.arange(k_lo, k_hi + 1)
            lags = ks - (n - 1)
            fp = p + lags
            fb = p - lags
            vf = (fp >= 0) & (fp < n)
            vb = (fb >= 0) & (fb < n)
            a = np.zeros(len(ks))
            a[vf] += (1.0 - h[fp[vf]])
            a[vb] -= h[fb[vb]]
            c_aff = c[ks]
            unaff = 0.0
            if k_lo > 0:
                unaff = max(unaff, float(c[:k_lo].max()))
            if k_hi < 2 * n - 2:
                unaff = max(unaff, float(c[k_hi + 1:].max()))
            d_lo, d_hi = -h0, 1.0 - h0
            d1 = d_hi - gr * (d_hi - d_lo)
            d2 = d_lo + gr * (d_hi - d_lo)
            f1 = max(float(np.max(c_aff + d1 * a)), unaff)
            f2 = max(float(np.max(c_aff + d2 * a)), unaff)
            for _ in range(gs_iters):
                if d_hi - d_lo < 1e-15:
                    break
                if f1 < f2:
                    d_hi, d2, f2 = d2, d1, f1
                    d1 = d_hi - gr * (d_hi - d_lo)
                    f1 = max(float(np.max(c_aff + d1 * a)), unaff)
                else:
                    d_lo, d1, f1 = d1, d2, f2
                    d2 = d_lo + gr * (d_hi - d_lo)
                    f2 = max(float(np.max(c_aff + d2 * a)), unaff)

def active_set_descent(h, n, max_iter, deadline, top_m=30):
    h = h.copy()
    best_h = h.copy()
    best_c = compute_c5(h, n)
    dx_val = 2.0 / n
    ss = 0.005
    for it in range(max_iter):
        if time.time() > deadline:
            break
        c = np.correlate(h, 1.0 - h, mode='full') * dx_val
        m = c.max()
        top = np.argsort(c)[-top_m:]
        sg = np.zeros(n)
        for k in top:
            lag = k - (n - 1)
            if lag >= 0:
                ln = n - lag
                sg[lag:] += (1.0 - h[:ln])
                sg[:ln] -= h[lag:]
            else:
                L = -lag
                ln = n - L
                sg[:ln] += (1.0 - h[L:])
                sg[L:] -= h[:ln]
        sg /= top_m
        h_try = project_feasible(h - ss * sg, n)
        c_try = compute_c5(h_try, n)
        if c_try < best_c - 1e-15:
            best_c = c_try
            best_h = h_try.copy()
            h = h_try
            ss = min(ss * 1.05, 0.02)
        else:
            ss *= 0.6
            if ss < 1e-7:
                break
    return best_h, best_c
