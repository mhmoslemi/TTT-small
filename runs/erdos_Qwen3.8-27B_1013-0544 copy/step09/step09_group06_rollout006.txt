Let me also think about whether there's a structural insight I'm missing.

For the Erdős problem, the optimal h is expected to be a "digital" function (taking values 0 or 1 almost everywhere). The constraint ∫h = 1 over [0,2] means h=1 on a set of measure 1 and h=0 on a set of measure 1.

If h is exactly 0/1, then c_k = ∫ h(x)(1-h(x+k)) dx = measure of {x : h(x)=1, h(x+k)=0}.

This is the "disagreement" between h and its shift by k. We want to minimize the maximum disagreement over all shifts k.

This is related to the concept of "perfect difference sets" or "Bose-Chowla sequences" in combinatorics!

For a periodic version: if h is periodic with period P, and h=1 on a subset S of {0,...,P-1} with |S|=P/2, then c_k = |{x ∈ S : x+k ∉ S}| = |S| - |S ∩ (S-k)| = P/2 - |S ∩ (S-k)|.

We want to maximize min_k |S ∩ (S-k)|, which is related to the autocorrelation of the indicator function of S.

This connection suggests that the optimal h might have a structure related to difference sets or Boolean functions with low autocorrelation peaks.

But for the non-periodic case on [0,2], the boundary effects matter.

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def build_M(b, n):
    M = np.zeros((2*n-1, n))
    for k in range(2*n-1):
        d = k - (n-1)
        lo = max(0, -d)
        hi = min(n, n-d)
        if lo < hi:
            M[k, lo:hi] = b[lo+d:hi+d]
    return M

def lp_step(h, n, deadline):
    b = 1.0 - h
    M = build_M(b, n)
    h_var = cp.Variable(n)
    t_var = cp.Variable()
    constraints = [h_var >= 0, h_var <= 1, cp.sum(h_var) == n/2.0,
                   M @ h_var <= t_var]
    prob = cp.Problem(cp.Minimize(t_var), constraints)
    try:
        prob.solve(solver=cp.CBC, max_time=20, verbose=False)
    except:
        return h
    if h_var.value is None:
        return h
    new_h = np.clip(np.array(h_var.value).flatten(), 0, 1)

def solve_1d_minimax(c_peak, a_coeff, diag_idx, unaff_max, lo, hi):
    T = len(c_peak)
    candidates = [lo, hi]
    for i in range(T):
        for j in range(i+1, T):
            if i == diag_idx or j == diag_idx:
                continue
            da = a_coeff[i] - a_coeff[j]
            if abs(da) > 1e-15:
                d = (c_peak[j] - c_peak[i]) / da
                if lo <= d <= hi:
                    candidates.append(d)
    if diag_idx is not None:
        for i in range(T):
            if i == diag_idx:
                continue
            B = -(a_coeff[diag_idx] - a_coeff[i])
            C = -(c_peak[diag_idx] - c_peak[i])
            disc = B*B - 4.0*C
            if disc >= 0:
                sq = np.sqrt(disc)
                d1 = (-B+sq)/2.0
                d2 = (-B-sq)/2.0
                if lo <= d1 <= hi:
                    candidates.append(d1)
                if lo <= d2 <= hi:
                    candidates.append(d2)
