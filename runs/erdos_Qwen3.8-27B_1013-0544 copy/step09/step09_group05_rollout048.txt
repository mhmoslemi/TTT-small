This is related to the "minimum peak sidelobe" problem in signal processing! The goal is to design a sequence with minimum peak autocorrelation sidelobe.

Known results:
- For binary sequences (0/1), the minimum peak sidelobe is related to Barker codes
- For real-valued sequences, we can do better
- The "CAZAC" (Constant Amplitude Zero Autocorrelation) sequences have zero sidelobes but constant amplitude, which doesn't help here

The key insight: we want a sequence whose autocorrelation is as flat as possible (ideally zero for all non-zero lags). This is the "perfect autocorrelation" problem.

For a continuous function, a function with flat power spectrum (white noise) has flat autocorrelation, but it won't satisfy our constraints.

For a periodic function, the autocorrelation at lag k is:
R(k) = integral h(x)h(x+k) dx

If h has Fourier series h(x) = sum a_m e^{i*pi*m*x}, then:
R(k) = sum |a_m|^2 e^{i*pi*m*k} (for the periodic case)

Wait, that's for the circular autocorrelation. For our case with h on [0,2], it's a bit different.

Anyway, the point is: we want h to have a "flat" autocorrelation profile. Functions with band-limited spectra (low-pass filtered noise) tend to have smoother autocorrelations.

def cd_pass(h, n, rng, order):
    c = np.correlate(h, 1.0 - h, mode='full')
    improved = False
    for p in order:
        h0 = h[p]

            continue
        x_new = solve_coord(c, h, p, n)
        if abs(x_new - h0) > 1e-13:
            h[p] = x_new
            improved = True
    return improved

def coord_descent(h, n, max_passes, deadline, rng, random=True):
    h = h.copy()
    for i in range(max_passes):
        if time.time() > deadline:
            break
        order = rng.permutation(n) if random else range(n)
        if not cd_pass(h, n, rng, order):
            break
        h = project_feasible(h, n)
    return h, compute_c5(h, n)

def smooth_obj(x, n, alpha):
    c = np.correlate(x, 1.0 - x, mode='full')
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    lse = mx + np.log(np.sum(np.exp(sh - mx)))
    return (m + lse / alpha) * (2.0 / n)

    return x.sum() - n / 2.0

    return np.ones(n)

def slsqp(h, n, alphas, maxiter, deadline):

            nh = project_feasible(res.x, n)
            nc = compute_c5(nh, n)

    n = len(best_h)
    if time.time() < deadline - 5:
        ho, co = coord_descent(best_h, n, 500, deadline - 1, rng, random=False)
        if co < best_c:
            best_h, best_c = ho, co

    best_h = project_feasible(best_h, len(best_h))
    best_c = compute_c5(best_h, len(best_h))
    return best_h, best_c, len(best_h)
