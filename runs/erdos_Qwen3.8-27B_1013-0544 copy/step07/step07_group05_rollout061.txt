Actually, let me think about this differently. For a single pair (i,j), the objective as a function of δ is:
f(δ) = max_k (c_k + δ * s_k)

where s_k = dc_k/dδ. This is the maximum of n linear functions, which is a convex piecewise-linear function of δ. The minimum is at a point where two lines cross (or at a boundary).

To find the minimum:
1. Compute s_k for all k (O(n) work)
2. The feasible range of δ is [δ_lo, δ_hi] where h[i]+δ ∈ [0,1] and h[j]-δ ∈ [0,1]
3. Find the minimum of max_k (c_k + δ*s_k) over δ ∈ [δ_lo, δ_hi]

Since it's piecewise linear and convex, the minimum is where the subgradient contains 0, i.e., where there exist k1, k2 with s_{k1} < 0 < s_{k2} and c_{k1} + δ*s_{k1} = c_{k2} + δ*s_{k2} = max.

This can be found by:
- Sorting the lines by slope
- Using a linear-time algorithm for the lower envelope (upper hull in this case)

But for n=400, a simpler approach works:
- Evaluate f(δ) at δ_lo and δ_hi
- The minimum of a convex piecewise-linear function on an interval is at a breakpoint
- Breakpoints occur where c_k + δ*s_k = c_l + δ*s_l for some k ≠ l
- δ_break = (c_l - c_k) / (s_k - s_l) for s_k ≠ s_l

There are O(n²) breakpoints, but most will be outside [δ_lo, δ_hi]. In practice, we can just do a ternary search or bisection on the piecewise-linear function.

Actually, the simplest approach for a convex piecewise-linear function on an interval:
1. Compute f(δ_lo) and f(δ_hi)
2. If f is decreasing at δ_lo (i.e., the active max has negative slope), binary search for where the slope crosses 0
3. If f is increasing at δ_hi, the minimum is at δ_lo
4. Otherwise, the minimum is at δ_hi

More precisely:
- At δ_lo, the active set is the set of k achieving the max. If all active k have s_k ≥ 0, the minimum is at δ_lo. If all have s_k ≤ 0, we need to go higher.
- We can binary search: at each point, compute the max and the slopes of the active k. If all active slopes > 0, go left. If all < 0, go right. If mixed, we're at the minimum (approximately).

This takes O(n * log(1/ε)) per pair, which is very fast.

def erdos_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def project_box_sum(x, target):
    x = np.asarray(x, dtype=float)
    n = x.size
    lo = float(np.min(x)) - 1.0
    hi = float(np.max(x)) + 1.0
    for _ in range(100):
        mid = 0.5 * (lo + hi)
        y = np.clip(x - mid, 0.0, 1.0)
        if float(y.sum()) > target:
            lo = mid
        else:
            hi = mid
    y = np.clip(x - 0.5 * (lo + hi), 0.0, 1.0)
    diff = float(target - y.sum())
    if abs(diff) > 1e-14:
        mask = (y > 1e-12) & (y < 1.0 - 1e-12)
        cnt = int(np.count_nonzero(mask))
        if cnt > 0:
            y[mask] += diff / cnt
        else:
            y += diff / n
        y = np.clip(y, 0.0, 1.0)
    return y

def softmax_vals(c, beta):
    maxc = float(np.max(c))
    z = beta * (c - maxc)
    np.clip(z, -745.0, 0.0, out=z)
    ew = np.exp(z)
    ws = float(ew.sum())
    f = maxc + np.log(ws) / beta
    if ws <= 1e-300:
        w = np.zeros_like(c)
        w[int(np.argmax(c))] = 1.0
    else:
        w = ew / ws
    return f, w

def compute_grad(h, w, n, dx):
    mid = n - 1
    w_pos = np.zeros(n)
    w_neg = np.zeros(n)
    w_pos[1:] = w[mid + 1:]
    w_neg[1:] = w[:mid][::-1]
    s = w_pos + w_neg
    pref_p = np.cumsum(w_pos)
    pref_n = np.cumsum(w_neg)
    idx = np.arange(n)
    consts = pref_p + pref_n[n - 1 - idx]
    kern = np.zeros(2 * n - 1)
    kern[mid + 1:] = s[1:]
    kern[:mid][::-1] = s[1:]
    neigh = np.convolve(h, kern, mode='full')[mid:mid + n]
    return (w[mid] * (1.0 - 2.0 * h) + consts - neigh) * dx

    betas = [50, 200, 800, 3000, 10000, 40000, 150000, 500000, 2000000]
    iters = [100, 90, 80, 70, 60, 50, 40, 30, 20]
    for beta, mx in zip(betas, iters):
        if time.time() > end1:
            break
        cand = run_lbfgs(best_h, beta, mx, deadline)
        c = erdos_c5(cand, n)
        if c < best_c - 1e-15:
            best_h = cand
            best_c = c

    # Phase 2: Try higher resolution (15% time)
    end2 = t0 + 0.68 * (deadline - t0)
    for nh in [800, 600]:
        if time.time() > end2 or nh == best_n:
            continue
        hh = resample(best_h, best_n, nh)
        for beta in [3000, 30000, 150000]:
            if time.time() > end2:
                break
            cand = run_lbfgs(hh, beta, 45, deadline)
            c = erdos_c5(cand, nh)
            if c < best_c - 5e-6:
                best_h = cand
                best_n = nh
                best_c = c
                break

    # Phase 3: Fast pair polishing (25% time)
    end3 = deadline - 12.0
    if best_n <= 1000:
        best_h, best_c = pair_polish_fast(best_h, best_n, end3, seed)

    # Phase 4: Final L-BFGS + pair polish
    if time.time() < deadline - 8.0:
        cand = run_lbfgs(best_h, 5000000, 25, deadline)
        c = erdos_c5(cand, best_n)
        if c < best_c - 1e-15:
            best_h = cand
            best_c = c
    if time.time() < deadline - 4.0:
        best_h, best_c = pair_polish_fast(best_h, best_n, deadline - 2.0, seed + 7)

    # Phase 5: Small perturbations
    rng = np.random.RandomState(seed + 31)
    for sig in [0.005, 0.02]:
        if time.time() > deadline - 3.0:
            break
        hh = project_box_sum(best_h + sig * rng.randn(best_n), 0.5 * best_n)
        cand = run_lbfgs(hh, 500000, 20, deadline)
        c = erdos_c5(cand, best_n)
        if c < best_c - 1e-15:
            best_h = cand
            best_c = c
            cand, c = pair_polish_fast(cand, best_n, deadline - 1.0, seed + 53)
            if c < best_c - 1e-15:
                best_h = cand
                best_c = c

    best_h = project_box_sum(best_h, 0.5 * best_n)
    best_c = erdos_c5(best_h, best_n)
    return best_h, best_c, int(best_n)
