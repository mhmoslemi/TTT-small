    target = n / 2.0
    h = h.copy()
    # Binary search for lambda
    lo, hi = -1.0, 2.0

For binary sequences, this is a well-studied problem in combinatorial design. The optimal binary sequence would be one where the cross-correlation between the set and its complement is as flat as possible.

**Key idea: Use a combinatorial construction as a starting point, then refine with continuous values.**

Some combinatorial constructions:
1. **Bose-Chowla construction**: Uses finite fields to construct difference sets
2. **Mian-Chowla sequences**: Greedy construction of sequences with distinct differences
3. **Golay sequences**: Complementary pairs with flat autocorrelation

For our problem, we want a set S ⊂ {0,...,n-1} of size n/2 such that for every shift k, the number of elements s ∈ S such that s-k ∉ S (or equivalently, the cross-correlation S with S^c) is minimized.

This is exactly the "what is the minimum maximum cross-correlation" problem.

Let me think about what the optimal value should be. For a random binary sequence with n/2 ones:
- Expected c[k] for k≠0: E[c[k]] ≈ (n/2)·(1/2) = n/4 (for large n, ignoring boundary effects)
- More precisely: for shift k, there are n-|k| valid pairs, and each has probability 1/2 of being (0,1) (for random independent bits). So E[c[k]] ≈ (n-|k|)/4.
- The max over k of c[k] would be around n/4 + O(√n) by concentration.

So C₅ ≈ (n/4) · dx = (n/4) · (2/n) = 1/2 for random. But we know we can do better (0.38 < 0.5).

The improvement comes from the structure: by carefully choosing which positions are 1, we can make the cross-correlation more uniform (and thus the max smaller).

    """Compute cross-correlation of a and b (same as np.correlate(b, a, 'full'))."""
    # a has length n, b has length 2n-1

import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.clip(h - mid, 0.0, 1.0).sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    lam = (lo + hi) / 2.0
    h_proj = np.clip(h - lam, 0.0, 1.0)
    diff = target - h_proj.sum()
    if abs(diff) > 1e-10:
        interior = (h_proj > 1e-12) & (h_proj < 1 - 1e-12)
        if interior.sum() > 0:
            h_proj[interior] += diff / interior.sum()
            np.clip(h_proj, 0.0, 1.0, out=h_proj)
    return h_proj
