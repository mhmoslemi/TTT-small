OK, the pure Python approach is too slow. Let me vectorize the inner loop.

For a fixed i (zero position), I want to find the best j (one position) to swap with. The change in correlation for swap (i, j) is:

Δcorr[p] = (1-h[i-s_p])_valid - (1-h[j-s_p])_valid + h[j+s_p]_valid - h[i+s_p]_valid

where s_p = p - (n-1) ranges from -(n-1) to (n-1).

Let me define:
- For fixed i: A[p] = (1-h[i-s_p])_valid - h[i+s_p]_valid (this is the contribution from i)
- For fixed j: B[p] = -(1-h[j-s_p])_valid + h[j+s_p]_valid (this is the contribution from j)

Then Δcorr[p] = A[p] + B[p]

And the new max is max(corr + A + B).

For fixed i, A is fixed. We want to find j that minimizes max(corr + A + B(j)).

This is still hard to vectorize over j because of the max. But we can approximate:
- The new max is approximately corr_max + max(A + B(j)) at the position where corr is currently max.
- Or we can just compute the new max for each j.

Actually, for n=400, the correlation array has 799 elements. For each of the 200 zeros, we try 200 ones, each requiring a vector operation of length 799. That's 200*200*799 = 32M operations per sweep. In numpy, each vector op of length 799 is fast (maybe 1-2 μs), so 40000 ops * 2μs = 80ms per sweep. With 500 sweeps, that's 40 seconds. But the issue is that the B computation above uses the current h_b, but after we change h_b[i] and h_b[j], the B computation for future iterations needs to use the updated values. Wait, there's a subtlety. When computing B for position j, I use h_b values. But at the time of computation, h_b[j] = 1 (it's still a 1). After the swap, h_b[j] = 0. So the B computation correctly uses the pre-swap values. Good.

But wait, when I compute A for position i, I use h_b[i] = 0 (pre-swap). After swap, h_b[i] = 1. The A computation is:
A[p] = (1-h[i-s]) - h[i+s] (with validity)

This doesn't involve h[i] itself directly (only h at other positions), so it's correct.

Actually wait, there IS a case where it involves h[i] or h[j]. If i-s[p] = i for some p, that means s[p] = 0, i.e., p = n-1. Then A[n-1] includes (1-h[i]) = 1 (pre-swap). Similarly for B: if j-s[p] = j, then s[p]=0, p=n-1. B[n-1] includes -(1-h[j]) = -0 = 0 (pre-swap, h[j]=1). After swap, it would be -(1-h[j]) = -1. But again, we recompute.

So the algorithm is: use pre-swap values to decide the best swap, then recompute corr after applying it. This is correct.

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(300):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h += diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h += diff / s * h
    return np.clip(h, 0.0, 1.0)

def to_binary(h, n):
    sorted_h = np.sort(h)[::-1]
    # Take top n/2
    h_b = np.zeros(n)
    idx = np.argsort(h)[::-1][:n//2]
    h_b[idx] = 1.0
    return h_b

def golden_init(n, seed=0):
    """Initialize using golden ratio spacing."""
    phi = (1 + np.sqrt(5)) / 2
    rng = np.random.RandomState(seed)
    h_b = np.zeros(n)
    # Use a Beatty-like sequence
    offset = rng.rand() * n
    positions = np.floor((np.arange(n//2) * phi + offset)).astype(int) % n
    positions = positions[np.argsort(positions)]
    # Handle duplicates
    used = set()
    count = 0
    for p in positions:
        while p in used:
            p = (p + 1) % n
        h_b[p] = 1.0
        used.add(p)
        count += 1
    # Fill remaining if needed
    if count < n//2:
        remaining = np.where(h_b == 0)[0]
        for p in remaining[:n//2 - count]:
            h_b[p] = 1.0
    return h_b

def random_init(n, seed=0):
    rng = np.random.RandomState(seed)
    h_b = np.zeros(n)
    idx = rng.choice(n, size=n//2, replace=False)
    h_b[idx] = 1.0
    return h_b

def binary_local_search(h_b, n, deadline, max_sweeps=500, sa_temp=0.0, seed=42):
    dx = 2.0 / n
    corr = np.correlate(h_b, 1.0 - h_b, mode='full').astype(float)
    cur_c = float(corr.max())
    best_h = h_b.copy()
    best_c = cur_c
    ones = np.where(h_b == 1)[0].tolist()
    zeros = np.where(h_b == 0)[0].tolist()
    rng = np.random.RandomState(seed)
    s_arr = np.arange(-(n-1), n)  # length 2n-1
    npoints = 2*n - 1
    
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        improved = False
        zeros_shuffled = zeros[:]
        rng.shuffle(zeros_shuffled)
        
        for i in zeros_shuffled:
            if time.time() > deadline:
                break
            j_candidates = [j for j in ones if j != i]
            if len(j_candidates) == 0:
                continue
            j_arr = np.array(j_candidates)
            
            # Compute B for all j at once: shape (num_j, npoints)
            jm = j_arr[:, None] - s_arr[None, :]
            jp = j_arr[:, None] + s_arr[None, :]
            B = np.zeros((len(j_arr), npoints))
            m1 = (jm >= 0) & (jm < n)
            B[m1] -= (1.0 - h_b[np.clip(jm, 0, n-1)[m1]])
            m2 = (jp >= 0) & (jp < n)
            B[m2] += h_b[np.clip(jp, 0, n-1)[m2]]
            
            # A for position i
            im = i - s_arr
            ip = i + s_arr
            A = np.zeros(npoints)
            m1 = (im >= 0) & (im < n)
            A[m1] = 1.0 - h_b[im[m1]]
            m2 = (ip >= 0) & (ip < n)
            A[m2] -= h_b[ip[m2]]
            
            base = corr + A
            new_maxes = (base[None, :] + B).max(axis=1)
            best_idx = int(np.argmin(new_maxes))
            best_val = new_maxes[best_idx]
            
            # SA: accept if better, or with probability exp(-(best_val - cur_c)/T) if worse
            accept = False
            if best_val < cur_c - 1e-12:
                accept = True
            elif sa_temp > 0 and best_val > cur_c:
                if rng.rand() < np.exp(-(best_val - cur_c) / sa_temp):
                    accept = True
            
            if accept:
                j = j_arr[best_idx]
                h_b[i] = 1.0
                h_b[j] = 0.0
                corr = np.correlate(h_b, 1.0 - h_b, mode='full').astype(float)
                cur_c = float(corr.max())
                ones.remove(j)
                ones.append(i)
                zeros.remove(i)
                zeros.append(j)
                improved = True
                if cur_c < best_c:
                    best_c = cur_c
                    best_h = h_b.copy()
        
        if not improved:
            break
    
    return best_h, best_c * dx

def slsqp_optimize(h, n, alpha, maxiter, ftol):
    dx = 2.0 / n
    def obj(x):
        c = np.correlate(x, 1.0 - x, mode='full') * dx
        m = c.max()
        shifted = alpha * (c - m)
        sm = shifted.max()
        logsum = sm + np.log(np.exp(shifted - sm).sum())
        return m + logsum / alpha
    def cons_fun(x):
        return x.sum() - n / 2.0
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cons_fun}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': maxiter, 'ftol': ftol})
        return project_feasible(res.x, n)
    except Exception:
        return h

def subgrad_optimize(h, n, deadline, max_iters=30000, top_k=3, lr_base=0.08):
    best_h = h.copy()
    best_c = compute_c5(h, n)
    dx = 2.0 / n
    momentum = np.zeros(n)
    beta = 0.9
    t = 0
    stall = 0
    stall_limit = 3000
    for it in range(max_iters):
        if time.time() > deadline:
            break
        t += 1
        c = np.correlate(h, 1 - h, mode='full') * dx
        cur_c = float(c.max())
        if cur_c < best_c:
            best_c = cur_c
            best_h = h.copy()
            stall = 0
        else:
            stall += 1
        if stall > stall_limit:
            h = best_h + 0.01 * np.random.RandomState(t).randn(n)
            h = project_feasible(h, n)
            momentum = np.zeros(n)
            stall = 0
        top_idx = np.argsort(c)[::-1][:top_k]
        # Compute subgradient
        grad = np.zeros(n)
        for idx in top_idx:
            k = int(idx) - (n - 1)
            if k >= 0:
                if k == 0:
                    grad[:] += 1.0 - 2.0 * h
                else:
                    grad[k:] += (1.0 - h[:n - k])
                    grad[:n - k] -= h[k:]
            else:
                kk = -k
                if kk == 0:
                    grad[:] += 1.0 - 2.0 * h
                else:
                    grad[:n - kk] += (1.0 - h[kk:])
                    grad[kk:] -= h[:n - kk]
        grad = dx * grad / top_k
        momentum = beta * momentum + (1 - beta) * grad
        step = (lr_base / (np.abs(momentum) + 0.1)) * momentum
        h_new = project_feasible(h - step, n)
        c_check = np.correlate(h_new, 1 - h_new, mode='full') * dx
        if c_check.max() < cur_c + 0.01:
            h = h_new
    return best_h, best_c

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    total = budget_s - 5
    dl = t0 + total
    rng = np.random.RandomState(seed)
    
    # Get initial values
    try:
        h0 = np.array(initial_h_values, dtype=float).copy()
        n = len(h0)

    p1 = min(t0 + 120, dl - 300)
    h = best_h.copy()

        c = compute_c5(h, n)
```

```python
                zeros = list(np.where(h_b == 0)[0])
                corr = np.correlate(h_b, 1.0 - h_b, mode='full').astype(float)
                cur_c = float(ccorr.max()) if False else float(corr.max())
            stall = 0
    return best_h, best_c * dx

def slsqp_optimize(h, n, alpha, maxiter, ftol):
    dx = 2.0 / n
    def obj(x):
        c = np.correlate(x, 1.0 - x, mode='full') * dx
        m = c.max()
        shifted = alpha * (c - m)
        sm = shifted.max()
        logsum = sm + np.log(np.exp(shifted - sm).sum())
        return m + logsum / alpha
    def cons_fun(x):
        return x.sum() - n / 2.0
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cons_fun}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': maxiter, 'ftol': ftol})
        return project_feasible(res.x, n)
    except Exception:
        return h

def subgrad_optimize(h, n, deadline, max_iters=20000, top_k=3, lr_base=0.08):
    best_h = h.copy()
    best_c = compute_c5(h, n)
    dx = 2.0 / n
    momentum = np.zeros(n)
    beta = 0.9
    stall = 0
    stall_limit = 3000
    for it in range(max_iters):
        if time.time() > deadline:
            break
        c = np.correlate(h, 1 - h, mode='full') * dx
        cur_c = float(c.max())
        if cur_c < best_c:
            best_c = cur_c
            best_h = h.copy()
            stall = 0
        else:
            stall += 1
        if stall > stall_limit:
            h = best_h + 0.01 * np.random.RandomState(it).randn(n)
            h = project_feasible(h, n)
            momentum = np.zeros(n)
            stall = 0
        top_idx = np.argsort(c)[::-1][:top_k]
        grad = np.zeros(n)
        for idx in top_idx:
            k = int(idx) - (n - 1)
            if k >= 0:
                if k == 0:
                    grad[:] += 1.0 - 2.0 * h
                else:
                    grad[k:] += (1.0 - h[:n - k])
                    grad[:n - k] -= h[k:]
            else:
                kk = -k
                grad[:n - kk] += (1.0 - h[kk:])
                grad[kk:] -= h[:n - kk]
        grad = dx * grad / top_k
        momentum = beta * momentum + (1 - beta) * grad
        step = (lr_base / (np.abs(momentum) + 0.1)) * momentum
        h_new = project_feasible(h - step, n)
        c_check = np.correlate(h_new, 1 - h_new, mode='full') * dx
        if c_check.max() < cur_c + 0.01:
            h = h_new
    return best_h, best_c

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    total = budget_s - 5
    dl = t0 + total
    rng = np.random.RandomState(seed)
    try:
        h0 = np.array(initial_h_values, dtype=float).copy()
        n = len(h0)
    except Exception:
        n = 400
        h0 = np.full(n, 0.5)
    best_h = project_feasible(h0, n)
    best_c = compute_c5(best_h, n)
    # Phase 1: SLSQP continuous optimization
    p1 = min(t0 + 100, dl - 400)
    h = best_h.copy()
    for alpha in [50000, 500000, 5000000]:
        if time.time() > p1:
            break
        h = slsqp_optimize(h, n, alpha, 1500, 1e-15)
        c = compute_c5(h, n)
        if c < best_c:
            best_c, best_h = c, h.copy()
    # Phase 2: Primary binary local search
    p2 = min(t0 + 550, dl - 200)
    h_b = to_binary(best_h, n)
    hb, cb = binary_local_search(h_b, n, p2, max_sweeps=3000, sa_temp=0.0, seed=seed)
    if cb < best_c:
        best_c, best_h = cb, hb.copy()
    # Phase 3: Multi-restart with SA
    p3 = min(t0 + 850, dl - 80)
    starts = [best_h.copy()]
    starts.append(golden_init(n, seed + 1))
    starts.append(random_init(n, seed + 2))
    h_pert = best_h + 0.15 * rng.randn(n)
    h_pert = project_feasible(h_pert, n)
    starts.append(to_binary(h_pert, n))
    h_pert2 = best_h + 0.3 * rng.randn(n)
    h_pert2 = project_feasible(h_pert2, n)
    starts.append(to_binary(h_pert2, n))
    for si, start in enumerate(starts):
        if time.time() > p3 - 30:
            break
        sp = min(time.time() + 80, p3)
        hb, cb = binary_local_search(start, n, sp, max_sweeps=800, sa_temp=0.8, seed=seed + 10 + si)
        if cb < best_c:
            best_c, best_h = cb, hb.copy()
    # Phase 4: Subgradient on continuous then re-binarize
    p4 = min(t0 + 980, dl - 40)
    h_cont = best_h.copy().astype(float)
    if np.all((h_cont == 0) | (h_cont == 1)):
        h_cont = h_cont + 0.02 * rng.randn(n)
        h_cont = project_feasible(h_cont, n)
    hs, cs = subgrad_optimize(h_cont, n, p4, max_iters=15000, top_k=5, lr_base=0.05)
    if cs < best_c:
        best_c, best_h = cs, hs.copy()
    h_b2 = to_binary(hs, n)
    hb, cb = binary_local_search(h_b2, n, dl - 15, max_sweeps=1000, sa_temp=0.0, seed=seed + 100)
    if cb < best_c:
        best_c, best_h = cb, hb.copy()
    # Phase 5: Final binary polish
    if time.time() < dl - 5:
        hb, cb = binary_local_search(best_h, n, dl - 1, max_sweeps=1000, sa_temp=0.0, seed=seed + 200)
        if cb < best_c:
            best_c, best_h = cb, hb.copy()
    best_h = np.clip(best_h, 0, 1)
    if not np.all((best_h == 0) | (best_h == 1)):
        best_h = project_feasible(best_h, n)
    best_c = compute_c5(best_h, n)
    return best_h, best_c, n
```
