def solve_1d_subproblem(c, p, h_p, n, A, B_diag):
    """Find optimal delta for position p.
    c: current correlation vector
    p: position
    h_p: current value at position p
    n: length
    A: array of coefficients for each affected lag (A[m_index])
    B_diag: coefficient for diagonal lag
    Returns optimal delta.
    """
    # c[m](delta) = c[m] + delta * A[m] for non-diagonal
    # c[diag](delta) = c[diag] + delta * B_diag - delta^2 for diagonal
    # Minimize max over all m of c[m](delta)
    
    # Candidate points:
    # 1. Boundaries: delta = -h_p, delta = 1-h_p
    # 2. Intersections of quadratic with each line
    # 3. Vertex of quadratic: delta_v = B_diag / 2
    
    candidates = [-h_p, 1.0 - h_p]
    
    # Vertex of quadratic (if quadratic is the max there)
    delta_v = B_diag / 2.0
    if -h_p < delta_v < 1.0 - h_p:
        candidates.append(delta_v)
    
    # Intersections: c_diag + delta*B_diag - delta^2 = c[m] + delta*A[m]
    # -delta^2 + delta*(B_diag - A[m]) + (c_diag - c[m]) = 0
    # delta^2 - delta*(B_diag - A[m]) - (c_diag - c[m]) = 0
    # delta = [(B_diag - A[m]) ± sqrt((B_diag - A[m])^2 + 4*(c_diag - c[m]))] / 2
    
    c_diag = c[n-1]  # diagonal lag
    disc = (B_diag - A)**2 + 4.0 * (c_diag - c)
    valid = disc >= 0
    if np.any(valid):
        sqrt_disc = np.sqrt(disc[valid])
        d1 = ((B_diag - A[valid]) + sqrt_disc) / 2.0
        d2 = ((B_diag - A[valid]) - sqrt_disc) / 2.0
        for d in np.concatenate([d1, d2]):

    # two lines are equal, but we already capture the important cases via
    # the quadratic intersections.
    
    best_val = np.inf

One more thought: the log-sum-exp with very large alpha (like 1,000,000) can have numerical issues. When alpha is large, `shifted = alpha * (c - m)` has values in [-alpha*max_c, 0], and `exp(shifted - mx)` underflows for most terms. This means the log-sum-exp essentially becomes the max, which is what we want, but the gradient becomes discontinuous. SLSQP might struggle with this.

A better approach: use a "hard max" approximation for high alpha. Instead of log-sum-exp, use:
f(h) = m + (1/alpha) * sum_{k: c_k > m - 1/alpha} (c_k - m)

This is the "mean of the top values" which is smoother than log-sum-exp at high alpha.

    c = np.correlate(x, 1.0 - x, mode='full')
    m = float(c.max())
    excess = np.maximum(c - m, 0.0)
    return (m + np.sum(excess**2) / (2.0 * alpha)) * (2.0 / n)

    return x.sum() - n / 2.0
