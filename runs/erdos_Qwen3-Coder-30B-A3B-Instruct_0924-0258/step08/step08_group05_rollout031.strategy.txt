### Approach and rationale

The strategy utilizes **Simulated Annealing (SA)** to escape local minima in the optimization of the Erdős minimum overlap problem. Unlike the prior gradient descent approach that may be confined by local optima, SA enables exploration of the solution space by accepting worse solutions probabilistically, especially at higher temperatures. This is particularly effective for the non-convex objective, which poses challenges for traditional gradient-based methods.

The approach maintains the sum constraint **sum(h) = n_points/2** by performing perturbations that swap values between pairs of indices, ensuring feasibility throughout the search. This is achieved by adjusting two elements at a time, adding a small Δ to one and subtracting the same Δ from another, while respecting the bounds **[0, 1]**. The combination of constrained perturbations and probabilistic acceptance shines in exploring dichotomous configurations, effectively seeking a binary-like solution without violating continuous value constraints.

### Mathematical specification

#### Variables
- `h[i]`: Step function values, `i ∈ {0, ..., n_points - 1}`.
- `C`: Objective function to minimize, representing the maximum overlap.

#### Problem Constraints
1. **Sum Constraint**:
   \[
   \sum_{i=0}^{n_points - 1} h[i] = \frac{n_points}{2}
   \]
2. **Bounds**:
   \[
   0 \leq h[i] \leq 1 \quad \forall i
   \]

#### Energy (Objective) Function
The energy represents the maximum overlap across all shifts:
\[
C = \max_{k} \left( \sum_{i=0}^{n_points - 1 - |k|} h[i](1 - h[i + k]) \times dx \right), \quad dx = \frac{2}{n_points}
\]

### Implementation procedure

1. **Initialization**:
   - Use `initial_h_values` if available. Otherwise, construct `h` with `n_points/2` ones (binary) if even, or with one element as 0.5 if odd.
   - Ensure `sum(h) = n_points / 2`.

2. **Energy Calculation**:
   - Compute the energy as described in the problem statement, returning the maximum overlap across all shifts.

3. **Temperature Setup**:
   - Initialize temperature `T` using the variance of the initial energy or set as a fraction (e.g., 10%).
   - Define a cooling schedule (e.g., geometric cooling: `T *= 0.99` each iteration).

4. **Simulated Annealing Loop**:
   - For each iteration until budget or convergence:
     - Generate a new candidate `h'` by swapping Δ between two indices.
     - Compute new energy `E'`.

   - Adjust `h[i] += Δ` and `h[j] -= Δ`.

6. **Termination Check**:
   - Stop early if the temperature falls below a threshold (e.g., 1e-3) or if no improvement occurs for N iterations.
