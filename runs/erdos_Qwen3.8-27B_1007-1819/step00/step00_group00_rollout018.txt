Let me look up the actual definition. For numpy:
`np.correlate(a, v, mode='full')`:
The result is c[k] = sum_n a[n+k] * conj(v[n])

For real arrays: c[k] = sum_n a[n+k] * v[n]
where k ranges from -(len(v)-1) to (len(a)-1), and the sum is over valid n.

For len(a) = len(v) = n:
k ranges from -(n-1) to (n-1), total 2n-1 values.
c[k] = sum_{n: 0≤n≤n-1, 0≤n+k≤n-1} a[n+k] * v[n]

In numpy's output, the index is k + (n-1), so output index j = k + (n-1), j ranges 0 to 2n-2.

So:
- j = n-1: k=0, c[0] = sum a[n]*v[n] (zero lag)
- j > n-1: k = j-(n-1) > 0, c[k] = sum_{n=0}^{n-1-k} a[n+k]*v[n]
- j < n-1: k = j-(n-1) < 0, c[k] = sum_{n=-k}^{n-1} a[n+k]*v[n] = sum_{m=0}^{n-1-k'} a[m]*v[m-k'] where k'=-k

For our problem: a = h, v = 1-h.
c[k] = sum h[n+k]*(1-h[n]) for valid n.

For k > 0: c[k] = sum_{n=0}^{n-1-k} h[n+k]*(1-h[n])
This counts the number of positions n where h[n+k]=1 and h[n]=0 (for 0-1 h).

For k < 0: c[k] = sum_{n=-k}^{n-1} h[n+k]*(1-h[n])
Let m = n+k (so m ranges from 0 to n-1-k' where k'=-k):
c[k] = sum_{m=0}^{n-1-k'} h[m]*(1-h[m+k'])
This counts positions m where h[m]=1 and h[m+k']=0.

So c[k] for k>0 and c[-k] for k>0 are related but not identical (they measure different things: 1s landing on 0s vs 0s landing on 1s).

For 0-1 with sum n/2: c[k] + c[-k] = sum_{overlap} h[n+k] + h[n] - h[n]*h[n+k]... no that's not right either.

Actually, c[k] = #{n: h[n+k]=1, h[n]=0} and c[-k] = #{n: h[n]=1, h[n+k]=0} for the overlapping range.

c[k] + c[-k] = #{n in overlap where h[n+k] ≠ h[n]} (the "boundary" count).
