The integral ∫₀² h(x)(1-h(x+k)) dx represents the "overlap" of h with the complement of shifted h. We want this to be small for all k.

One idea: if h is periodic with period 1 (so h(x) = h(x+1)), then the only "interesting" shifts are k ∈ [0,1]. With h(x) = h(x+1), we have ∫₀² h(x)(1-h(x+k)) dx for k ∈ [0,1].

Another idea: if h(x) = 1/2 for all x, then ∫₀² (1/2)(1/2) dx = 1/2. But C5 = 1/2 which is way too large.

The key is to make h vary so that h(x) and 1-h(x+k) don't overlap much.

For the binary case: h is 0 or 1. Then h(x)(1-h(x+k)) is 1 where h(x)=1 and h(x+k)=0. The integral is the measure of {x : h(x)=1, h(x+k)=0}. We want this small for all k.

For k=0: always 0.
For k near 0: the set {x : h(x)=1, h(x+k)=0} is small if h doesn't have sharp transitions.
For k = 1 (half period): depends on the structure.

I think the optimal structure for the binary case with period 2 would be something like a "golden ratio" type arrangement where 1s and 0s are as evenly spaced as possible.

- This is a 1D convex minimization
- Can solve via bisection on the derivative, or by finding all intersection points

import numpy as np

import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * dx

def logsumexp_max(h, n, t):
    corr = np.correlate(h, 1.0 - h, mode='full')
    m = np.max(corr)
    if t < 1:
        t = 1
    return (m + np.log(np.sum(np.exp(t * (corr - m)))) / t) * (2.0 / n)

def repair(h, n):
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    diff = target - h.sum()
    # Distribute correction to entries not at boundary
    mask = (h > 1e-4) & (h < 1.0 - 1e-4)
    if mask.sum() > 0:
        per = diff / mask.sum()
        h[mask] = np.clip(h[mask] + per, 0, 1)
        # Still not exact, do a second pass
        diff2 = target - h.sum()
        h += diff2 / n
        h = np.clip(h, 0, 1)
    else:
        h += diff / n
        h = np.clip(h, 0, 1)
    return h

def coord_descent(h, n, sweeps=50):
    h = h.copy()
    corr_all = np.correlate(h, 1.0 - h, mode='full')  # shape (2n-1,)
    for _ in range(sweeps):
        changed = False
        for i in range(n):
            # For coordinate i, c[lag] is linear in h[i]
            # c[k] = sum_j h[j+k]*(1-h[j]), k goes from -(n-1) to (n-1)
            # In np.correlate(h, 1-h, 'full'), index corresponds to lag
            # Let's just compute the slope for each lag
            # h[i] appears in:
            #   as h[j+k] when j+k=i, i.e., j=i-k: term h[i]*(1-h[i-k])
            #   as 1-h[j] when j=i: term h[i+k]*(1-h[i])
            # slope of c[k] w.r.t. h[i]:
            #   from first: (1-h[i-k]) if 0<=i-k<n
            #   from second: -h[i+k] if 0<=i+k<n
            #   total: (1-h[i-k])*[valid] - h[i+k]*[valid]
            
            sl = np.zeros(2*n-1)  # slope for each lag
            # lag k in np.correlate 'full': index offset
            # np.correlate(h, v, 'full')[m] where m goes from 0 to 2n-2
            # corresponds to lag = m - (n-1)
            # c[lag] = sum_{j} h[j+lag] * v[j] where valid indices used
            # with v = 1-h
            
            # For element i of h to appear as h[j+lag]:
            #   j+lag = i → j = i-lag
            #   valid: 0 <= i-lag < n and 0 <= i-lag < n
            #   contribution: (1-h[i-lag])
            # For element i to appear in (1-h[j]):
            #   j = i
            #   valid: 0 <= i < n (always true) and 0 <= i+lag < n
            #   contribution: -h[i+lag] (since d/dh_i [h[i+lag]*(1-h[i])] = -h[i+lag])
            
            for k in range(2*n-1):
                lag = k - (n-1)  # actual lag
                s = 0.0
                j1 = i - lag
                if 0 <= j1 < n:
                    s += (1.0 - h[j1])
                j2 = i + lag
                if 0 <= j2 < n:
                    s -= h[j2]
                sl[k] = s
            
            # base[k] = c[k] - sl[k] * h[i]
            base = corr_all - sl * h[i]
            
            # Now minimize max_k (base[k] + sl[k] * t) over t in [0,1]
            # This is 1D convex minimization
            # Use bisection/ternary
            def f(t):
                vals = base + sl * t
                return np.max(vals)
            
            # Ternary search on [0, 1]
            a, b = 0.0, 1.0
            for _ in range(50):
                m1 = a + (b-a)/3
                m2 = b - (b-a)/3
                if f(m1) < f(m2):
                    b = m2
                else:
                    a = m1
            t_opt = (a + b) / 2
            
            # Check boundaries
            f0 = f(0.0)
            f1 = f(1.0)
            if f0 < f(t_opt):
                t_opt = 0.0
            elif f1 < f(t_opt):
                t_opt = 1.0
            
            if abs(t_opt - h[i]) > 1e-8:
                h[i] = t_opt
                corr_all = np.correlate(h, 1.0 - h, mode='full')
                changed = True
        if not changed:
            break
    return h

def local_search(h, n, rng, iters=10000):
    best = h.copy()
    best_c5 = compute_c5(best)
    target = n / 2.0
    for _ in range(iters):
        h_t = best.copy()
        k = rng.randint(1, 4)
        idx = rng.choice(n, size=k, replace=False)
        for ii in idx:

        h_t = np.clip(h_t, 0, 1)
        diff = target - h_t.sum()
        h_t += diff / n
        h_t = np.clip(h_t, 0, 1)
        c5 = compute_c5(h_t)
        if c5 < best_c5 - 1e-10:
            best = h_t
            best_c5 = c5
    return best, best_c5

    corr = np.correlate(h, 1.0 - h, mode='full')
    m = np.max(corr)

    return (m + np.log(s) / t) * (2.0 / n)

    h = h.copy()
