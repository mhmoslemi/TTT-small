Actually, I can simplify. Note that:

- valid2: max(0,k-n+1)≤k-i≤min(n-1,k) ⟺ 0≤k-i<n AND 0≤k-(k-i)<n ⟺ 0≤k-i<n AND 0≤i<n

So valid1 and valid2 are the same condition: 0≤i<n AND 0≤k-i<n (both i and k-i are in [0,n-1]).

So: ∂corr[k]/∂h[i] = (1-2*h[k-i]) * [0≤i<n AND 0≤k-i<n]

Since i is always in [0,n-1] (it's an index), this simplifies to:
∂corr[k]/∂h[i] = (1-2*h[k-i]) * [0≤k-i<n]

This is valid when j+i ≤ 2n-2 (length of w is 2n-1, indices 0 to 2n-2). Since j≤n-1 and i≤n-1, j+i≤2n-2. ✓

∇f[i] = dx * Σ_{j=0}^{n-1} w[i+j] * (1-2*h[j])

This is like a cross-correlation of w with (1-2*h), computed only for lags 0 to n-1.

                ki = k_star - i
                if 0 <= ki < n:
                    sg[i] = (1.0 - 2.0 * h_curr[ki]) * dx
            h_curr -= lr * sg
            h_curr = project_feasible(h_curr, n_pts)
            c5_t = compute_c5(h_curr)
            if c5_t < best_c5 - 1e-12:
                best_c5 = c5_t
                best_h = h_curr.copy()
                lr = min(lr * 1.1, 0.01)
            else:
                h_curr = best_h.copy()
                lr *= 0.7
                if lr < 1e-5:
                    break

    best_h = project_feasible(best_h, best_n)
    best_c5 = compute_c5(best_h)
    return best_h, best_c5, best_n
