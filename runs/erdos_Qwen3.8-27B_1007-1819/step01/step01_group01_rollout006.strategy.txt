   - Adaptive filter optimization: We adapt the filter coefficients based on local signal properties rather than using fixed optimization methods.

These changes address the main bottleneck in the current approach: it's too likely to get stuck in local optima. Pyramid analysis helps escape these trapped states by exploiting differences at multiple scales, while adaptive filtering creates solutions sensitive to the current signal structure.
