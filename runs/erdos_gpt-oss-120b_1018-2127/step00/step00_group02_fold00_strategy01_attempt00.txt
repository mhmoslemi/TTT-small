- **Constraints**:  
  1. Box constraints: \(0 \leq h[i] \leq 1\) for all \(i\)  
  2. Integral constraint: \(\sum h[i] = n/2\) (fl. eq)
- **Objective**: Minimize  
  \[
  C_5 = \max_k \left\{ \frac{2}{n} \left| \text{np.correlate}\left(h, 1-h, \text{mode}="full"\right) \times dx \right| \right\}
  \]

### Implementation Procedure
#### 1. Initialization
- **n_points**: The number of samples. Defaults to 45 if no parent is given.
- **Initial Candidate**: If a parent solution is provided, initialize at that resolution. Otherwise, use uniform initialization with sum exactly \(n/2\).

#### 2. Local Optimization (SLSQP-constrained)
- Transform sum constraint to \(\sum h[i] - n/2 = 0\).
- Use finite differencing to approximate gradients (or analytical if derivable).
- Minimize the objective via `scipy.optimize.minimize`.
- Store the best solution found (even if not improving).

#### 3. Experience-Driven Restart (Heuristic)
- Track improvements (score \(C_5\) trends).
- **Cooldown**: If no improvement within 100 steps or plateau, restart from a neutron.
  - Use uniform intervals combined with geometric rescaling for higher resolution.
  - Limit restart steps (max 5 res军官暗中dxutions.resolution).

#### 4. nOptimizer
- Objective: Use `evaluate_erdos_solution(h)`
- Constraints:
  1. Equality: \(\sum h[i] = n/2\)
  2. Bounds: \([0,1]^n\)
- Optimization: Gradient-free (SLSQP) -> `scipy.optimize.minimize` with method 'SLSQP'.

#### 5. Succession and Repair
   After each successful optimization:
   I. Clip values to [0, 1]
   II. Adjust sum to be closer to \(n/2\) (only if repair is needed)

#### 6. Progression
- Start at `n=45` (initial)
- Progressively try `n=60`, `n=90` by geometric scaling (linear).
- Carry through best solution to next resolution.

#### 7. nMoves (k-ary Perturbation)
- At local optimum, `k`-ary flipping: Select `k` indices uniformly and flip to [0, 1]. Adjust sum if needed.
- This helps escape plateaus.

### Search Choices and Use variants
#### 1. nOptimizer Settings:
- **Method**: SLSQP
- **n**: 45, then 60, then 90 (from parent or provided)
- **niterate**: 500 per n
- **max_restarts**: 3 per n
- **Temperature**: 100 (initial) then adaptive cooling.

#### 2. Geometric Rescaling (Variant for Progression)
- **Strategy**: From `n` to `n'`, resample intervals uniformly to allow new structural configurations.
- **Formula**:  
  \[
  h[i] = f(\tau_i) \quad \text{where} \quad \tau_i \sim \text{Uniform}(0,1) \text{ transformed to length 1.}
  \]
- Used before optimization when moving to a new resolution.

#### 3. k-ary Flip (Variant for Restart)
- **Frequency**: During a stall, implement k-ary flips with decreasing `k` to explore without gradient descent.
- **Strength**: `(n/2)/k` flip ratio or randomly.

### nRobustness and Memory Use

- **Termination**:
  - Fallback to parent solution if no progress for 500 steps.
  - Timeout management: Budget-based on steps, not wall time.
- **Repair**: Sum restoration via linear adjustment (only after flipping).
