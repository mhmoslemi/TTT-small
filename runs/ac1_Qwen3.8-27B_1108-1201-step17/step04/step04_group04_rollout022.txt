`c[k] = sum_j a[j] * a[k-j]`

The terms are: for each j, the product is `a[j] * a[k-j]`.

When we differentiate w.r.t. `a[i]`:
- The term `a[j] * a[k-j]` gets a contribution from `da[j]/da[i] * a[k-j]` when `j = i`, giving `a[k-i]`.
- It also gets a contribution from `a[j] * da[k-j]/da[i]` when `k-j = i`, i.e., `j = k-i`, giving `a[k-i]`.
- If `j = i = k-j` (i.e., `k = 2i`), both contributions come from the same term, giving `2*a[i]`.

So: `dc[k]/da[i] = a[k-i] + a[k-i] = 2*a[k-i]` when `0 <= k-i < n` (which ensures both indices are valid).

But we also need `0 <= i < n` for the gradient to be defined. Since we're computing `grad[i]` for `i` in [0, n-1], that's automatically satisfied.

So: `grad[i] = 2 * sum_k w[k] * a[k-i]` where the sum is over k such that `0 <= k-i < n` (i.e., `i <= k <= i+n-1`).

This can be written as: `grad = 2 * cross_correlate(w, a)` where `w` is defined on the full convolution index range [0, 2n-2].

In practice, for the top-k peaks approach, `w` is non-zero only at k peak positions, so the computation is efficient.

Let me now think about the LP more carefully.

The LP I want to solve:
```
minimize:    t
subject to:  (a*g)[k] <= t  for k = 0, ..., 2n-2
             sum(g) = 1
             g >= 0
```

This finds the unit-sum non-negative `g` that minimizes the peak of `a*g`.

In standard LP form:
```
minimize:    t
subject to:  C @ g - t <= 0  (2n-1 constraints)
             sum(g) = 1  (1 constraint)
             g >= 0
             t >= 0 (implicit, since a >= 0 and g >= 0 implies a*g >= 0)
```

Where `C` is the `(2n-1) x n` matrix such that `C @ g = a * g` (full convolution).

Now, after finding `g`, we update `a <- a + t_step * (g - a) / sum(g - a)` or something like that... Actually, the standard approach is:

1. Find `g` from LP (unit sum, non-negative, minimizes peak of `a*g`).
2. Direction: `d = g - a` (both have sum 1, so d has sum 0).
3. Line search: find `t` that minimizes `objective(a + t*d)` subject to `a + t*d >= 0`.

The maximum useful `t` is `t_max = min over i where d[i]<0 of (-a[i]/d[i])`.

Let me also think about a different approach: **direct peak reduction via subgradient**.

At each step:
1. Compute `c = a*a`.
2. Find the argmax `k*`.
3. The subgradient of `max(c)` at `a` is `2 * a[k* - i]` (the gradient of `c[k*]`).
4. Take a step in the negative subgradient direction: `a <- a - lr * grad`.
5. Project onto `a >= 0`.

This is basically gradient descent on the (nonsmooth) function `max(a*a)`. It should work but might be slow.

The soft version (log-sum-exp) smooths this and gives better convergence.

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Soft gradient descent with adaptive temperature and Nesterov momentum
2. LP-based direction finding with line search
3. Coordinate descent polishing
4. Multi-restart strategy with length exploration
"""

import numpy as np
import time
from scipy.optimize import linprog


def fast_convolve(a):
    """Full linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def obj_value(a):
    """Compute objective value (assumes a is normalized to sum=1)."""
    n = len(a)
    c = fast_convolve(a)
    return 2.0 * n * c.max()


def soft_grad(a, temp, top_k=50):
    """
    Compute soft gradient of max(a*a) using log-sum-exp smoothing.
    Returns (gradient, convolution).
    """
    n = len(a)
    c = fast_convolve(a)
    peaks = np.argpartition(c, -top_k)[-top_k:]
    peak_vals = c[peaks].copy()
    scaled = peak_vals / temp
    scaled -= scaled.max()
    w = np.exp(scaled)
    w_sum = w.sum()
    if w_sum < 1e-300:
        w = np.zeros(len(peaks))
        w[int(np.argmax(peak_vals))] = 1.0
    else:
        w /= w_sum
    
    grad = np.zeros(n)
    for idx in range(len(peaks)):
        if w[idx] < 1e-15:
            continue
        k = int(peaks[idx])
        i_start = max(0, k - n + 1)
        i_end = min(n - 1, k)
        if i_start > i_end:
            continue
        idxs = np.arange(i_start, i_end + 1)
        grad[idxs] += 2.0 * w[idx] * a[k - idxs]
    return grad, c


def build_conv_matrix(a):
    """Build matrix C where C @ g = full_convolve(a, g)."""
    n = len(a)
    C = np.zeros((2 * n - 1, n))
    for j in range(n):
        C[j:j + n, j] = a
    return C


def lp_find_direction(a, C=None):
    """
    Find g >= 0, sum(g)=1, minimizing max(a*g).
    Returns (g, peak_value, success).
    """
    n = len(a)
    if C is None:
        C = build_conv_matrix(a)
    
    # minimize t s.t. C@g - t <= 0, sum(g) = 1, g >= 0, t >= 0
    c_obj = np.concatenate([np.zeros(n), [1.0]])
    A_ub = np.hstack([C, -np.ones((2 * n - 1, 1))])
    b_ub = np.zeros(2 * n - 1)
    A_eq = np.array([np.concatenate([np.ones(n), [0.0]])])
    b_eq = np.array([1.0])
    bounds = [(0, None)] * n + [(0, None)]
    
    try:
        result = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                         bounds=bounds, method='highs',
                         options={'presolve': True})
        if result.success:
            g = result.x[:n]
            g = np.maximum(g, 0)
            g_sum = g.sum()
            if g_sum > 1e-10:
                g = g / g_sum
            peak = result.x[n]
            return g, peak, True
    except Exception:
        pass
    return a.copy(), None, False


def line_search(a, d, max_iter=30):
    """
    Find best step size t for a + t*d that minimizes objective.
    d should have sum 0 (so normalization is automatic).
    Returns (best_t, best_a, best_obj).
    """
    n = len(a)
    a0 = a.copy()
    obj0 = obj_value(a0)
    
    # Max valid step
    neg_mask = d < -1e-15
    if np.any(neg_mask):
        t_max = np.min(a0[neg_mask] / (-d[neg_mask]))
    else:
        t_max = 1.0
    t_max = min(t_max * 0.99, 1.0)
    
    best_t = 0.0
    best_a = a0.copy()
    best_obj = obj0
    
    # Try logarithmically spaced steps
    if t_max > 1e-8:
        ts = np.concatenate([
            np.geomspace(t_max, 1e-4, 15),
            [t_max * 0.95, t_max * 0.9, t_max * 0.7, t_max * 0.5, t_max * 0.3]
        ])
        ts = np.sort(np.unique(ts))[::-1]  # descending
        
        # Actually, let's try a few specific values
        ts = np.array([t_max, t_max*0.8, t_max*0.6, t_max*0.4, t_max*0.2,
                       0.5, 0.3, 0.2, 0.1, 0.05, 0.01])
        ts = ts[ts <= t_max]
        ts = ts[ts > 1e-6]
        
        for t in ts:
            a_try = a0 + t * d
            if np.any(a_try < -1e-12):
                continue
            a_try = np.maximum(a_try, 0)
            s = a_try.sum()
            if s < 1e-10:
                continue
            a_try = a_try / s  # renormalize (sum should be ~1 already)
            obj_try = obj_value(a_try)
            if obj_try < best_obj:
                best_obj = obj_try
                best_t = t
                best_a = a_try.copy()
    
    return best_t, best_a, best_obj


def gradient_optimize(a0, time_limit, lr_init=0.01, momentum=0.9,
                      top_k=50, temp_init=0.001, temp_end=0.0001):
    """
    Nesterov-accelerated soft gradient descent.
    """
    a = np.maximum(a0.astype(np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    v = np.zeros(n)
    best_obj = obj_value(a)
    best_a = a.copy()
    
    t0 = time.monotonic()
    lr = lr_init
    temp = temp_init
    mom = momentum
    no_improve = 0
    total_steps = 0
    
    while time.monotonic() - t0 < time_limit:
        # Nesterov lookahead
        y = a + mom * v
        y = np.maximum(y, 0.0)
        sy = y.sum()
        if sy > 1e-15:
            y = y / sy
        
        grad, c = soft_grad(y, temp, top_k=top_k)
        
        # Gradient step
        v = mom * v - lr * grad
        a_new = a + v
        a_new = np.maximum(a_new, 0.0)
        sn = a_new.sum()
        if sn > 1e-15:
            a = a_new / sn
        else:
            a = best_a.copy()
            v = np.zeros(n)
            continue
        
        total_steps += 1
        cur_obj = obj_value(a)
        
        if cur_obj < best_obj - 1e-12:
            best_obj = cur_obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        # Adaptive updates
        progress = (time.monotonic() - t0) / time_limit
        # Anneal temperature
        temp = temp_init * (temp_end / temp_init) ** progress
        lr *= 0.999
        mom = min(0.97, mom + 0.0001)
        
        if no_improve >= 300:
            # Restart with perturbation
            rng = np.random.default_rng(int(time.monotonic() * 1000))
            noise = rng.standard_normal(n) * 0.002
            a = best_a + noise
            a = np.maximum(a, 0)
            s = a.sum()
            if s > 1e-15:
                a = a / s
            else:
                a = best_a.copy()
            v = np.zeros(n)
            no_improve = 0
    
    return best_a, best_obj


def lp_optimize(a0, time_limit, verbose=False):
    """
    LP-based iterative optimization.
    At each step: find g minimizing peak(a*g) with sum(g)=1, g>=0.
    Then line search along direction g - a.
    """
    a = np.maximum(a0.astype(np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    C = build_conv_matrix(a)
    best_obj = obj_value(a)
    best_a = a.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    max_no_improve = 50
    perturb_count = 0
    iteration = 0
    
    while time.monotonic() - t0 < time_limit:
        iteration += 1
        
        # Recompute C periodically (it changes as a changes)
        if iteration % 5 == 1:
            C = build_conv_matrix(a)
        
        # Find LP direction
        g, peak_val, success = lp_find_direction(a, C)
        
        if not success:
            no_improve += 1
        else:
            # Direction: d = g - a (sum is 0)
            d = g - a
            t_best, a_try, obj_try = line_search(a, d)
            
            if t_best > 1e-6 and obj_try < best_obj - 1e-13:
                a = a_try
                best_obj = obj_try
                best_a = a.copy()
                no_improve = 0
            else:
                no_improve += 1
        
        if verbose and iteration % 10 == 0:
            print(f"    LP iter {iteration}, obj={best_obj:.8f}, t={time.monotonic()-t0:.1f}s")
        
        # Handle stagnation
        if no_improve >= max_no_improve:
            rng = np.random.default_rng(iteration * 31 + 17 + perturb_count * 1000)
            scale = 0.001 + 0.003 * min(perturb_count, 10)
            noise = rng.standard_normal(n) * scale
            a = best_a + noise
            a = np.maximum(a, 0)
            s = a.sum()
            if s > 1e-15:
                a = a / s
            else:
                a = best_a.copy()
            no_improve = 0
            perturb_count += 1
            max_no_improve = min(200, 50 + 25 * perturb_count)
            
            if perturb_count > 50:
                break
        
        # Periodic gradient polish
        if no_improve >= 20 and no_improve < max_no_improve:
            a_g, obj_g = gradient_optimize(best_a, time_limit=3.0,
                                            lr_init=0.005, top_k=60,
                                            temp_init=0.0005)
            if obj_g < best_obj:
                best_obj = obj_g
                best_a = a_g.copy()
                a = a_g.copy()
                no_improve = 5  # reset partially
    
    return best_a, best_obj


def coordinate_descent(a0, time_limit):
    """
    Random coordinate descent: try small adjustments to pairs of elements.
    """
    a = np.maximum(a0.astype(np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        return a, obj_value(a)
    a = a / s
    n = len(a)
    
    best_obj = obj_value(a)
    best_a = a.copy()
    
    t0 = time.monotonic()
    rng = np.random.default_rng(99999)
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        # Try batch of random coordinate pairs
        n_trials = max(100, min(50000, int(2000000 / n)))
        
        for _ in range(n_trials):
            if time.monotonic() - t0 > time_limit - 0.1:
                break
            
            i = rng.integers(0, n)
            j = rng.integers(0, n)
            if i == j:
                continue
            
            # Try moving mass from i to j
            delta = 0.005 * a[i]
            if delta < 1e-10:
                continue
            
            a_try = a.copy()
            a_try[i] -= delta
            a_try[j] += delta
            if a_try[i] < 0:
                a_try[0] += a_try[i]  # redistribute
                a_try[i] = 0
            
            conv_try = fast_convolve(a_try)
            obj_try = 2.0 * n * conv_try.max()
            
            if obj_try < best_obj - 1e-12:
                a = a_try
                s = a.sum()
                a = a / s
                best_obj = obj_try
                best_a = a.copy()
                no_improve = 0
            else:
                no_improve += 1
        
        if no_improve > n_trials * 5:
            break
    
    return best_a, best_obj


def generate_inits(n, parent, rng):
    """Generate diverse initializations for length n."""
    inits = {}
    x = np.arange(n, dtype=np.float64)
    
    inits['uniform'] = np.ones(n) / n
    inits['random'] = rng.dirichlet(np.ones(n) * 0.5)
    
    # Sine
    s1 = np.sin(np.pi * x / n) ** 2 + 0.01
    inits['sine1'] = s1 / s1.sum()
    
    s2 = np.sin(2 * np.pi * x / n) ** 2 + 0.01
    inits['sine2'] = s2 / s2.sum()
    
    # Bimodal
    edge = max(1, n // 4)
    bi = np.zeros(n)
    bi[:edge] = 1.0
    bi[-edge:] = 1.0
    inits['bimodal'] = bi / bi.sum()
    
    # From parent
    if parent is not None and len(parent) > 0:
        p = np.maximum(parent, 0).astype(np.float64)
        ps = p.sum()
        if ps > 1e-10 and np.isfinite(p).all():
            if len(p) == n:
                inits['parent'] = p / ps
            else:
                pp = np.interp(np.linspace(0, 1, n),
                               np.linspace(0, 1, len(p)), p / ps)
                pp = np.maximum(pp, 0)
                pps = pp.sum()
                if pps > 1e-10:
                    inits['parent_interp'] = pp / pps
    
    return inits
```

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Soft gradient descent with adaptive temperature (Nesterov momentum)
2. LP-based direction finding (minimize peak of cross-convolution) with line search
3. Peak-shaving coordinate adjustments
4. Multi-phase alternating optimization with restarts
"""

import numpy as np
import time
from scipy.optimize import linprog


def fast_convolve(a):
    """Full linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def obj_value(a):
    """Compute 2n * max(a*a) assuming sum(a) = 1."""
    n = len(a)
    c = fast_convolve(a)
    return 2.0 * n * c.max()


def soft_grad(a, temp, top_k=50):
    """
    Compute soft gradient of max(a*a) using log-sum-exp smoothing over top-k peaks.
    Returns (gradient, full_convolution).
    """
    n = len(a)
    c = fast_convolve(a)
    peaks = np.argpartition(c, -top_k)[-top_k:]
    peak_vals = c[peaks].copy()
    scaled = peak_vals / temp
    scaled -= scaled.max()
    w = np.exp(scaled)
    w_sum = w.sum()
    if w_sum < 1e-300:
        w = np.zeros(len(peaks))
        w[int(np.argmax(peak_vals))] = 1.0
    else:
        w /= w_sum

    grad = np.zeros(n)
    for idx in range(len(peaks)):
        if w[idx] < 1e-15:
            continue
        k = int(peaks[idx])
        i_start = max(0, k - n + 1)
        i_end = min(n - 1, k)
        if i_start > i_end:
            continue
        idxs = np.arange(i_start, i_end + 1)
        grad[idxs] += 2.0 * w[idx] * a[k - idxs]
    return grad, c


def build_conv_matrix(a):
    """Build matrix C where C @ g = full_convolve(a, g)."""
    n = len(a)
    C = np.zeros((2 * n - 1, n))
    for j in range(n):
        C[j:j + n, j] = a
    return C


def lp_find_direction(a, C=None):
    """
    Find g >= 0, sum(g)=1, minimizing max_k (a*g)[k].
    Returns (g, peak_value, success).
    """
    n = len(a)
    if C is None:
        C = build_conv_matrix(a)

    c_obj = np.concatenate([np.zeros(n), [1.0]])
    A_ub = np.hstack([C, -np.ones((2 * n - 1, 1))])
    b_ub = np.zeros(2 * n - 1)
    A_eq = np.array([np.concatenate([np.ones(n), [0.0]])])
    b_eq = np.array([1.0])
    bounds = [(0, None)] * n + [(0, None)]

    try:
        result = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                         bounds=bounds, method='highs',
                         options={'presolve': True, 'dual_feasibility_tolerance': 1e-9})
        if result.success:
            g = np.maximum(result.x[:n], 0.0)
            g_sum = g.sum()
            if g_sum > 1e-10:
                g = g / g_sum
            peak = result.x[n]
            return g, peak, True
    except Exception:
        pass
    return a.copy(), None, False


def line_search(a, d):
    """
    Find best step t for a + t*d (d has sum ~0).
    Returns (best_t, best_a, best_obj).
    """
    n = len(a)
    obj0 = obj_value(a)

    neg_mask = d < -1e-15
    if np.any(neg_mask):
        t_max = np.min(a[neg_mask] / (-d[neg_mask]))
    else:
        t_max = 1.0
    t_max = min(t_max * 0.999, 1.0)

    if t_max < 1e-8:
        return 0.0, a.copy(), obj0

    best_t = 0.0
    best_a = a.copy()
    best_obj = obj0

    candidates = [t_max, t_max * 0.9, t_max * 0.75, t_max * 0.5,
                  t_max * 0.3, t_max * 0.15,
                  0.5, 0.3, 0.2, 0.1, 0.05, 0.02, 0.005]
    candidates = [t for t in candidates if t <= t_max and t > 1e-6]
    candidates = sorted(set(candidates), reverse=True)

    for t in candidates:
        a_try = a + t * d
        if np.any(a_try < -1e-12):
            continue
        a_try = np.maximum(a_try, 0.0)
        s = a_try.sum()
        if s < 1e-10:
            continue
        a_try = a_try / s
        obj_try = obj_value(a_try)
        if obj_try < best_obj - 1e-14:
            best_obj = obj_try
            best_t = t
            best_a = a_try.copy()

    return best_t, best_a, best_obj


def gradient_optimize(a0, time_limit, lr_init=0.01, momentum=0.92,
                      top_k=50, temp_init=0.001, temp_end=0.00005):
    """Nesterov-accelerated soft gradient descent with adaptive parameters."""
    a = np.maximum(a0.astype(np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)

    v = np.zeros(n)
    best_obj = obj_value(a)
    best_a = a.copy()

    t0 = time.monotonic()
    lr = lr_init
    temp = temp_init
    mom = momentum
    no_improve = 0

    while time.monotonic() - t0 < time_limit:
        y = a + mom * v
        y = np.maximum(y, 0.0)
        sy = y.sum()
        if sy > 1e-15:
            y = y / sy

        grad, c = soft_grad(y, temp, top_k=top_k)

        v = mom * v - lr * grad
        a_new = a + v
        a_new = np.maximum(a_new, 0.0)
        sn = a_new.sum()
        if sn > 1e-15:
            a = a_new / sn
        else:
            a = best_a.copy()
            v = np.zeros(n)
            continue

        cur_obj = obj_value(a)
        if cur_obj < best_obj - 1e-13:
            best_obj = cur_obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1

        progress = min(1.0, (time.monotonic() - t0) / time_limit)
        temp = temp_init * (temp_end / temp_init) ** progress
        lr *= 0.998
        mom = min(0.97, mom + 0.0001)

        if no_improve >= 400:
            rng = np.random.default_rng(int(time.monotonic() * 10000))
            noise = rng.standard_normal(n) * 0.002
            a = best_a + noise
            a = np.maximum(a, 0)
            s = a.sum()
            if s > 1e-15:
                a = a / s
            else:
                a = best_a.copy()
            v = np.zeros(n)
            no_improve = 0

    return best_a, best_obj


def lp_optimize(a0, time_limit, verbose=False):
    """
    LP-based iterative optimization with adaptive step sizing and restarts.
    """
    a = np.maximum(a0.astype(np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)

    C = build_conv_matrix(a)
    best_obj = obj_value(a)
    best_a = a.copy()

    t0 = time.monotonic()
    no_improve = 0
    max_no_improve = 60
    perturb_count = 0
    iteration = 0
    lp_fail_streak = 0

    while time.monotonic() - t0 < time_limit:
        iteration += 1
        C = build_conv_matrix(a)

        g, peak_val, success = lp_find_direction(a, C)

        if success:
            d = g - a
            t_best, a_try, obj_try = line_search(a, d)

            if t_best > 1e-6 and obj_try < best_obj - 1e-13:
                a = a_try
                best_obj = obj_try
                best_a = a.copy()
                no_improve = 0
                lp_fail_streak = 0
            else:
                no_improve += 1
                lp_fail_streak += 1
        else:
            no_improve += 1
            lp_fail_streak += 1

        if verbose and iteration % 20 == 0:
            print(f"    LP iter {iteration}, obj={best_obj:.8f}, t={time.monotonic()-t0:.1f}s, no_imp={no_improve}")

        if no_improve >= max_no_improve:
            rng = np.random.default_rng(iteration * 31 + 17 + perturb_count * 7919)
            scale = 0.0008 + 0.002 * min(perturb_count, 12)
            noise = rng.standard_normal(n) * scale
            a = best_a + noise
            a = np.maximum(a, 0)
            s = a.sum()
            if s > 1e-15:
                a = a / s
            else:
                a = best_a.copy()
            no_improve = 0
            perturb_count += 1
            max_no_improve = min(250, 60 + 30 * perturb_count)
            lp_fail_streak = 0

            if perturb_count > 60:
                break

        # Periodic gradient polish when LP stalls
        if lp_fail_streak >= 15 and lp_fail_streak % 15 == 0:
            t_rem = time_limit - (time.monotonic() - t0)
            t_grad = min(5.0, t_rem * 0.1)
            if t_grad > 1:
                a_g, obj_g = gradient_optimize(best_a, time_limit=t_grad,
                                                lr_init=0.004, top_k=80,
                                                temp_init=0.0003, temp_end=0.00005)
                if obj_g < best_obj:
                    best_obj = obj_g
                    best_a = a_g.copy()
                    a = a_g.copy()
                lp_fail_streak = 0

    return best_a, best_obj


def peak_shaving(a0, time_limit):
    """
    Identify peaks in auto-convolution and try to reduce them
    by redistributing mass from contributing elements.
    """
    a = np.maximum(a0.astype(np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        return a, obj_value(a)
    a = a / s
    n = len(a)

    best_obj = obj_value(a)
    best_a = a.copy()
    c = fast_convolve(a)
    peak = c.max()

    t0 = time.monotonic()
    rng = np.random.default_rng(424242)
    no_improve = 0

    while time.monotonic() - t0 < time_limit:
        c = fast_convolve(a)
        peak_idx = int(np.argmax(c))
        peak_val = c[peak_idx]

        # Find elements contributing most to this peak
        # c[peak_idx] = sum_j a[j] * a[peak_idx - j]
        j_start = max(0, peak_idx - n + 1)
        j_end = min(n - 1, peak_idx)
        if j_start > j_end:
            break

        # Compute contributions
        js = np.arange(j_start, j_end + 1)
        contributions = a[js] * a[peak_idx - js]

        # Find the element with largest contribution
        max_contrib_idx = js[np.argmax(contributions)]
        partner_idx = peak_idx - max_contrib_idx

        # Try reducing the larger of the two and putting mass elsewhere
        if a[max_contrib_idx] >= a[partner_idx]:
            donor = max_contrib_idx
            partner = partner_idx
        else:
            donor = partner_idx
            partner = max_contrib_idx

        base_frac = a[donor]
        for frac in [0.05, 0.02, 0.01, 0.005, 0.002]:
            delta = base_frac * frac
            if delta < 1e-12:
                break

            # Try several target positions (avoid positions near partner)
            targets = []
            for _ in range(20):
                tgt = rng.integers(0, n)
                if abs(tgt - partner) > n // 4 and tgt != donor:
                    targets.append(tgt)
            if not targets:
                targets = [rng.integers(0, n)]

            for tgt in targets[:5]:
                a_try = a.copy()
                a_try[donor] -= delta
                a_try[tgt] += delta
                if a_try[donor] < 0:
                    continue
                s_try = a_try.sum()
                if s_try < 1e-10:
                    continue
                c_try = fast_convolve(a_try)
                obj_try = 2.0 * n * c_try.max()
                if obj_try < best_obj - 1e-13:
                    a = a_try
                    best_obj = obj_try
                    best_a = a.copy()
                    no_improve = 0
                    break
            else:
                no_improve += 5

        if no_improve > 200:
            # Add small perturbation
            noise = rng.standard_normal(n) * 0.001
            a = best_a + noise
            a = np.maximum(a, 0)
            s = a.sum()
            if s > 1e-15:
                a = a / s
            else:
                a = best_a.copy()
                break
            no_improve = 0

    return best_a, best_obj


def coordinate_descent(a0, time_limit):
    """Random coordinate descent: try adjusting pairs of elements."""
    a = np.maximum(a0.astype(np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        return a, obj_value(a)
    a = a / s
    n = len(a)

    best_obj = obj_value(a)
    best_a = a.copy()

    t0 = time.monotonic()
    rng = np.random.default_rng(77777)
    no_improve = 0

    while time.monotonic() - t0 < time_limit:
        n_trials = max(200, min(100000, int(3000000 / n)))

        for _ in range(n_trials):
            if time.monotonic() - t0 > time_limit - 0.1:
                break

            i = rng.integers(0, n)
            j = rng.integers(0, n)
            if i == j:
                continue

            delta = 0.003 * a[i]
            if delta < 1e-12:
                continue

            a_try = a.copy()
            a_try[i] -= delta
            a_try[j] += delta
            if a_try[i] < 0:
                a_try[0] += a_try[i]
                a_try[i] = 0

            c_try = fast_convolve(a_try)
            obj_try = 2.0 * n * c_try.max()

            if obj_try < best_obj - 1e-13:
                a = a_try
                s = a.sum()
                a = a / s
                best_obj = obj_try
                best_a = a.copy()
                no_improve = 0
            else:
                no_improve += 1

        if no_improve > n_trials * 3:
            break

    return best_a, best_obj


def generate_inits(n, parent, rng):
    """Generate diverse initializations for length n."""
    inits = {}
    x = np.arange(n, dtype=np.float64)

    inits['uniform'] = np.ones(n) / n
    inits['random'] = rng.dirichlet(np.ones(n) * 0.5)

    s1 = np.sin(np.pi * x / n) ** 2 + 0.01
    inits['sine1'] = s1 / s1.sum()

    s2 = np.sin(2 * np.pi * x / n) ** 2 + 0.01
    inits['sine2'] = s2 / s2.sum()

    edge = max(1, n // 4)
    bi = np.zeros(n)
    bi[:edge] = 1.0
    bi[-edge:] = 1.0
    inits['bimodal'] = bi / bi.sum()

    if parent is not None and len(parent) > 0:
        p = np.maximum(parent, 0).astype(np.float64)
        ps = p.sum()
        if ps > 1e-10 and np.isfinite(p).all():
            if len(p) == n:
                inits['parent'] = p / ps
            else:
                pp = np.interp(np.linspace(0, 1, n),
                               np.linspace(0, 1, len(p)), p / ps)
                pp = np.maximum(pp, 0)
                pps = pp.sum()
                if pps > 1e-10:
                    inits['parent_interp'] = pp / pps

    return inits


def propose_candidate(seed=42, budget_s=1800, **kwargs):
    """
    Main entry point: multi-phase hybrid optimization.
    Phase 1: Gradient warm-up on parent sequence
    Phase 2: LP deep optimization (bulk of time)
    Phase 3: Alternating gradient + LP with peak shaving
    Phase 4: Fine-tuning and final polish
    """
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + max(1.0, float(budget_s) - 30.0)

    best_sequence = None
    best_score = float('inf')

    # Load parent
    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            parent = p
            parent_score = float(evaluate_sequence(p.tolist()))
            if np.isfinite(parent_score):
                best_score = parent_score
                best_sequence = p.copy()
            print(f"Parent loaded: n={len(p)}, score={parent_score:.8f}")
    except Exception as e:
        print(f"No parent: {e}")

    # ============================================================
    # Phase 1: Gradient warm-up (150s)
    # ============================================================
    print("\n=== Phase 1: Gradient Warm-up ===")
    t_start = time.monotonic()
    p1_limit = 150.0

    if parent is not None:
        n = len(parent)
        a0 = parent.copy()
        a0 = np.maximum(a0, 0)
        a0 = a0 / a0.sum()

        configs = [
            {'lr_init': 0.006, 'momentum': 0.93, 'top_k': 60, 'temp_init': 0.0005, 'temp_end': 0.00002},
            {'lr_init': 0.004, 'momentum': 0.95, 'top_k': 100, 'temp_init': 0.0002, 'temp_end': 0.00001},
            {'lr_init': 0.010, 'momentum': 0.90, 'top_k': 30, 'temp_init': 0.001, 'temp_end': 0.00005},
        ]

        for ci, cfg in enumerate(configs):
            t_rem = deadline - time.monotonic() - (p1_limit - (time.monotonic() - t_start))
            t_alloc = min(t_rem, 50.0)
            if t_alloc < 5:
                break

            print(f"  Grad {ci} (n={n}), t={t_alloc:.0f}s")
            a_opt, obj = gradient_optimize(a0, time_limit=t_alloc, **cfg)
            score = float(evaluate_sequence(a_opt.tolist()))
            if np.isfinite(score):
                if score < best_score:
                    best_score = score
                    best_sequence = a_opt.copy()
                    print(f"  Grad {ci}: {score:.8f} *NEW BEST*")
                else:
                    print(f"  Grad {ci}: {score:.8f}")
                a0 = a_opt.copy()
                a0 = np.maximum(a0, 0)
                a0 = a0 / a0.sum()

    print(f"Phase 1 done ({time.monotonic()-t_start:.0f}s). Best: {best_score:.8f}")

    # ============================================================
    # Phase 2: LP Deep Optimization (bulk of time, ~1100s)
    # ============================================================
    print("\n=== Phase 2: LP Deep Optimization ===")
    t_start2 = time.monotonic()

    if best_sequence is not None:
        p2_limit = 1100.0
        n_lp_runs = 4
        t_per_lp = p2_limit / n_lp_runs

        for ci in range(n_lp_runs):
            t_rem = deadline - time.monotonic() - 250.0
            t_alloc = min(t_per_lp, t_rem)
            if t_alloc < 30:
                break

            if ci == 0:
                a0 = best_sequence.copy()
                a0 = np.maximum(a0, 0)
                a0 = a0 / a0.sum()
            else:
                scale = 0.0005 * ci
                noise = rng.standard_normal(len(best_sequence)) * scale
                a0 = np.maximum(best_sequence + noise, 0)
                s = a0.sum()
                a0 = a0 / s if s > 1e-10 else best_sequence.copy()

            print(f"  LP run {ci}/{n_lp_runs}, t={t_alloc:.0f}s")
            a_opt, obj = lp_optimize(a0, time_limit=t_alloc, verbose=True)
            score = float(evaluate_sequence(a_opt.tolist()))
            if np.isfinite(score):
                if score < best_score:
                    best_score = score
                    best_sequence = a_opt.copy()
                    print(f"  LP {ci}: {score:.8f} *NEW BEST*")
                else:
                    print(f"  LP {ci}: {score:.8f}")

    print(f"Phase 2 done ({time.monotonic()-t_start2:.0f}s). Best: {best_score:.8f}")

    # ============================================================
    # Phase 3: Alternating gradient + LP + peak shaving (250s)
    # ============================================================
    print("\n=== Phase 3: Alternating Optimization ===")
    t_start3 = time.monotonic()

    if best_sequence is not None:
        p3_limit = 250.0
        n_rounds = 5
        t_per_round = p3_limit / n_rounds

        for ri in range(n_rounds):
            t_rem = deadline - time.monotonic() - 100.0
            t_round = min(t_per_round, t_rem)
            if t_round < 15:
                break

            # Gradient step
            t_g = t_round * 0.4
            if t_g > 3:
                a_g, obj_g = gradient_optimize(best_sequence, time_limit=t_g,
                                               lr_init=0.003, momentum=0.95,
                                               top_k=80, temp_init=0.0002,
                                               temp_end=0.00002)
                score_g = float(evaluate_sequence(a_g.tolist()))
                if np.isfinite(score_g) and score_g < best_score:
                    best_score = score_g
                    best_sequence = a_g.copy()

            # LP step
            t_l = t_round * 0.4
            if t_l > 5:
                a_l, obj_l = lp_optimize(best_sequence, time_limit=t_l)
                score_l = float(evaluate_sequence(a_l.tolist()))
                if np.isfinite(score_l) and score_l < best_score:
                    best_score = score_l
                    best_sequence = a_l.copy()
                    print(f"  Round {ri} LP: {score_l:.8f} *NEW BEST*")

            # Peak shaving
            t_p = t_round * 0.2
            if t_p > 3:
                a_p, obj_p = peak_shaving(best_sequence, time_limit=t_p)
                score_p = float(evaluate_sequence(a_p.tolist()))
                if np.isfinite(score_p) and score_p < best_score:
                    best_score = score_p
                    best_sequence = a_p.copy()
                    print(f"  Round {ri} PeakShave: {score_p:.8f} *NEW BEST*")

    print(f"Phase 3 done ({time.monotonic()-t_start3:.0f}s). Best: {best_score:.8f}")

    # ============================================================
    # Phase 4: Fine-tuning (remaining time)
    # ============================================================
    print("\n=== Phase 4: Fine-tuning ===")
    t_start4 = time.monotonic()

    if best_sequence is not None:
        remaining = deadline - time.monotonic() - 15.0

        # Final gradient
        t_g = min(remaining * 0.3, 60.0)
        if t_g > 5:
            a_opt, obj = gradient_optimize(best_sequence, time_limit=t_g,
                                           lr_init=0.002, momentum=0.96,
                                           top_k=100, temp_init=0.0001,
                                           temp_end=0.00001)
            score = float(evaluate_sequence(a_opt.tolist()))
            if np.isfinite(score) and score < best_score:
                best_score = score
                best_sequence = a_opt.copy()
                print(f"  Final Grad: {score:.8f} *NEW BEST*")

        # Coordinate descent
        remaining = deadline - time.monotonic() - 15.0
        t_cd = min(remaining * 0.3, 40.0)
        if t_cd > 5:
            a_opt, obj = coordinate_descent(best_sequence, time_limit=t_cd)
            score = float(evaluate_sequence(a_opt.tolist()))
            if np.isfinite(score) and score < best_score:
                best_score = score
                best_sequence = a_opt.copy()
                print(f"  CoordDesc: {score:.8f} *NEW BEST*")

        # Final LP micro-polish
        remaining = deadline - time.monotonic() - 10.0
        if remaining > 10:
            a_opt, obj = lp_optimize(best_sequence, time_limit=remaining * 0.8)
            score = float(evaluate_sequence(a_opt.tolist()))
            if np.isfinite(score) and score < best_score:
                best_score = score
                best_sequence = a_opt.copy()
                print(f"  Final LP: {score:.8f} *NEW BEST*")

    print(f"Phase 4 done ({time.monotonic()-t_start4:.0f}s). Best: {best_score:.8f}")

    # Fallback
    if best_sequence is None:
        best_sequence = np.ones(256) / 256

    # Final validation
    best_sequence = np.asarray(best_sequence, dtype=np.float64)
    best_sequence = np.maximum(best_sequence, 0.0)
    final_score = float(evaluate_sequence(best_sequence.tolist()))
    if np.isfinite(final_score):
        best_score = final_score

    print(f"\nFINAL: score={best_score:.8f}, n={len(best_sequence)}")
    return [float(x) for x in best_sequence]
```
