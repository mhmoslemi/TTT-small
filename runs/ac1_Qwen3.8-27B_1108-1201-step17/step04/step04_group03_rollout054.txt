More precisely: ∂(a*a)[k]/∂a[i] = 2*a[k-i] if 0 <= k-i <= n-1, else 0. (And when k-i = i, it's still 2*a[i] since d/dx(x^2) = 2x.)

So the gradient of the smoothed max is:
∇F(a)[i] = 2 * sum_k p_k * a[k-i] (for valid k-i)
= 2 * (p * a)[i] (with appropriate boundary handling)

where p is the softmax vector and * denotes the linear convolution (or cross-correlation).

This is great! The gradient is 2 * (p * a) where p is the softmax of the auto-convolution values. This is smooth and computable via FFT.

So we can use a smooth optimization method (like gradient descent with acceleration, or L-BFGS) on this smoothed objective!

**Algorithm: Smoothed max optimization**

1. Start with initial sequence a (normalized to sum=1, a >= 0).
2. Compute z = a * a (auto-convolution).
3. Compute p = softmax(τ * z) for some temperature τ.
4. Compute gradient: g = 2 * (p * a) (cross-correlation, via FFT).
5. Project gradient onto tangent space of simplex: g_proj = g - mean(g) (or g - (sum(g)/n) * 1).
   Actually, the tangent space of {a >= 0, sum(a) = 1} at a point a (with a[i] > 0 for all i) is {v : sum(v) = 0}.
   So the projected gradient is g - (sum(g)/n) * 1.
6. Take a step: a_new = a - lr * g_proj.
7. Project back to simplex: a_new = project_simplex(a_new).
8. Update τ (anneal it).
9. Repeat.

The key parameter is τ (temperature). Small τ → smoother → easier to optimize but less accurate. Large τ → sharper → more accurate but harder to optimize.

We can start with small τ and gradually increase it (simulated annealing style).

This approach has several advantages over the previous code:
1. **Smooth gradients**: No need for LP or subgradients.
2. **FFT-based**: The gradient computation is O(n log n) via FFT.
3. **Easy to accelerate**: Can use Nesterov acceleration, Adam, etc.
4. **Handles multiple peaks naturally**: The softmax automatically weights all peaks.

Let me also think about the constraint a >= 0. The simplex projection handles this, but it might cause issues near the boundary. An alternative is to parameterize a = softmax(b) / sum(softmax(b)) = softmax(b) (since softmax already sums to 1). Then we optimize over b ∈ R^n without constraints.

With the softmax parameterization:
a[i] = exp(b[i]) / sum_j exp(b[j])

∂a[i]/∂b[k] = a[i] * (δ_{ik} - a[k])

The gradient with respect to b is:
∂F/∂b[k] = sum_i (∂F/∂a[i]) * (∂a[i]/∂b[k])
= sum_i g[i] * a[i] * (δ_{ik} - a[k])
= g[k] * a[k] - a[k] * sum_i g[i] * a[i]
= a[k] * (g[k] - sum_i g[i] * a[i])

This is the "mirror descent" gradient. The update b_new = b - lr * a[k] * (g[k] - <g, a>) naturally maintains the probability structure.

Actually, this is equivalent to the multiplicative weight update: a_new[i] ∝ a[i] * exp(-lr * g[i]) (approximately, for small lr).

So the smoothed max + softmax parameterization gives us a principled multiplicative weight method!
