Actually, for coordinate descent, I can compute the derivatives directly:

For a given i, the function I want to minimize is:
`f(x) = max_k (conv(a,a)[k](x))` where `conv(a,a)[k](x)` is the k-th element of the convolution when `a[i] = x`.

I can write `conv(a,a)[k](x) = conv_base[k] + L_k * x + Q_k * x^2` where:
- `conv_base[k]` = the k-th element of `conv(a', a')` where `a' = a` but `a'[i] = 0`
- `L_k = a[k-i] + a[k-i]` = `2*a[k-i]` if `k-i` is valid and `k != 2i`; or `a[k-i]` if only one term... 

Wait, I need to be more careful. When `a'[i] = 0`:
`conv(a', a')[k] = sum_j a'[j] * a'[k-j]` (no terms involving index i)

When we set `a[i] = x`:
`conv(a,a)[k] = conv(a',a')[k] + (terms involving a[i])`

The terms involving `a[i]` in `conv(a,a)[k]`:
- `a[i] * a[k-i]` (when j=i, if k-i is valid)
- `a[k-i] * a[i]` (when k-j=i, i.e., j=k-i, if k-i is valid)

If `k-i = i` (i.e., `k = 2i`): these are the same term, so it's `a[i]^2 = x^2`.
If `k-i != i` and both valid: `2 * x * a[k-i]`.
If only one is valid (say k-i is valid but i is not... wait, i is always valid since 0 <= i <= n-1).

So:
- If `0 <= k-i <= n-1` and `k != 2i`: contribution is `2 * x * a[k-i]`
- If `k = 2i` (so `0 <= i <= n-1` automatically): contribution is `x^2`
- Otherwise: contribution is 0

So `conv(a,a)[k](x) = conv_base[k] + L_k * x + Q_k * x^2` where:
- `Q_k = 1` if `k = 2i`, else `0`
- `L_k = 2*a[k-i]` if `0 <= k-i <= n-1` and `k != 2i`, else `0`
- `conv_base[k] = conv(a',a')[k]` where `a'` has `a'[i] = 0`

Now I want to find `x >= 0` that minimizes `max_k (conv_base[k] + L_k * x + Q_k * x^2)`.

- Bisection on the derivative
- scipy.optimize.minimize_scalar with bounds [0, upper]
- Or just a grid + refinement

Alternative: I can compute the full convolution once, and for each i, compute the "base" convolution by subtracting the contribution of `a[i]`:
`conv_base[k] = conv_full[k] - L_k * a[i] - Q_k * a[i]^2`

where `L_k` and `Q_k` are as defined above. This avoids the FFT recomputation!

So the algorithm is:
1. Compute `conv_full = fast_convolve(a)` (one FFT)
2. For each i:
   a. Compute `conv_base[k] = conv_full[k] - 2*a[k-i]*a[i]` (for valid k-i, k!=2i) minus `a[i]^2` (for k=2i)
   b. Define `L_k` and `Q_k`
   c. Find optimal x by 1D minimization of `max_k (conv_base[k] + L_k*x + Q_k*x^2)`
   d. Update `a[i] = x`
   e. Update `conv_full` incrementally (add back the new contributions)

Step (e) is important for efficiency. When we change `a[i]` from old to new:
`conv_full[k] += (new - old) * (2*a[k-i])` for `k != 2i`
`conv_full[k] += (new^2 - old^2)` for `k = 2i`

This is O(n) per coordinate update, so one pass is O(n^2). For n=768, that's ~600K operations. Very fast!

`a^T Q_k a` is convex iff Q_k is positive semidefinite. The matrix Q_k for the k-th autocorrelation lag has entries (Q_k)_{ij} = 1 if j-i = k or j-i = -k (with appropriate bounds), 0 otherwise. This is a "shifted identity" type matrix, which has eigenvalues on the unit circle. So it's NOT positive semidefinite in general.

Therefore, the problem is non-convex, and coordinate descent doesn't have convergence guarantees. But it might still work in practice.

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def get_obj(a):
    n = len(a)
    s = np.sum(a)
    if s < 1e-15:
        return float('inf'), None
    conv = fast_convolve(a)
    return 2.0 * n * conv.max() / (s*s), conv

def build_conv_matrix(a, k_indices):
    """Build convolution matrix rows for specified k indices.
    Row k: C[k,:] @ g = conv(a, g)[k]
    """
    n = len(a)
    C = np.zeros((len(k_indices), n))
    for idx, k in enumerate(k_indices):
        j_lo = max(0, k - n + 1)
        j_hi = min(n - 1, k)
        for j in range(j_lo, j_hi + 1):
            C[idx, j] = a[k - j]
    return C

def active_set_lp(a, conv, n, gap_frac=0.95, max_constraints=200):
    """Solve LP with only active constraints."""
    M = conv.max()
    # Find active constraints
    threshold = M * gap_frac
    active_k = np.where(conv >= threshold)[0]
    if len(active_k) > max_constraints:
        # Keep only the top max_constraints
        active_k = np.argsort(conv[active_k])[::-1][:max_constraints]
        active_k = active_k[np.argsort(active_k)]  # re-sort by k
    if len(active_k) < 5:
        active_k = np.argpartition(conv, -min(20, len(conv)))[-min(20, len(conv)):]
    
    C = build_conv_matrix(a, active_k)
    
    # LP: max sum(g) s.t. C@g <= M, g >= 0
    c = -np.ones(n)
    b_ub = np.full(C.shape[0], M)
    bounds = [(0.0, None)] * n
    result = linprog(c, A_ub=C, b_ub=b_ub, bounds=bounds, method='highs')
    
    if result.success and result.x is not None:
        g = result.x
        g_sum = g.sum()
        if g_sum > 1e-15:
            return g, g_sum, result
    return None, 0, None

    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def get_obj(a):
    """Compute 2n * max(conv(a,a)) / (sum(a))^2 and return (objective, convolution)."""
    n = len(a)
    s = np.sum(a)
    if s < 1e-15:
        return float('inf'), None
    conv = fast_convolve(a)
    return 2.0 * n * conv.max() / (s * s), conv


def build_conv_matrix_rows(a, k_indices):
    """Build convolution matrix rows for specified lag indices.
    Row k gives coefficients such that row_k @ g = conv(a, g)[k].
    """
    n = len(a)
    C = np.zeros((len(k_indices), n))
    for idx, k in enumerate(k_indices):
        j_lo = max(0, k - n + 1)
        j_hi = min(n - 1, k)
        if j_lo <= j_hi:
            j_range = np.arange(j_lo, j_hi + 1)
            C[idx, j_range] = a[k - j_range]
    return C

    Returns (g, g_sum) or (None, 0).
