# Approach and Rationale
The objective is to minimize `2 * n * max(convolve(a, a, mode='full')) / (sum(a))^2`. The previous program achieved `1.505835` using a multi-phase search. Our approach combines an improved initialization with a two-phase simplex optimization and stochastic gradient descent with length adjustment. 

1. **Initialization**: Start with diverse initializations including uniform, Gaussian, cosine, and edge-based forms across multiple lengths (128, 256, 384, 512, 768, 1024).
2. **Phase 1**: Use a Frank-Wolfe variant with adaptive step sizes to find a balance between simplex and dual directions.
3. **Phase 2**: Implement a constrained stochastic gradient method focusing on promising directions while maintaining non-negativity and adjusting length periodically.

The bottleneck addressed is premature convergence and inefficiency. Our method uses higher learning rates and coordinate-wise addressing to handle sparsity better.

# Mathematical Specification
- **Representation**: Probability simplex (sum = 1, elements >=0).
- **Objective**: `f(a) = 2 * n * max(auto_convolve(a))`
- **Constraints**: Non-negativity and probability simplex properties.
- **Gradient**: 
  For a candidate `a`, the auto-convolution `F = auto_convolve(a)` and maximum `M = max(F)` give gradient components `g[k] += a[M_index - k]` for each trailing peak near `M`.

# Implementation Procedure

1. **Initialization**:
   - Generate initial solutions using sample-based generators (uniform, Gaussian, cosine) and simplex-safe variants.

2. **Frank-Wolfe Phase (Phase 1)**:
   - Set a base candidate and solve a linearized version of the problem using a mixed simplex/dual strategy.

3. **Constrained Stochastic Gradient (CSG) Phase (Phase 2)**:
   - Use momentum and adaptive length adjustment to optimize the solution. Specifically, we use a short vector to note divergence directions and project frequently.

4. **Fallback**:
   - Return the best candidate found even if the CSG phase doesn't complete.

5. **Optimization**:
   - Use scientific libraries (`numpy`, `scipy.optimize`) for linear algebra.
