where `b = convolve(a, a)` and `sum_a = sum(a)`.

This is invariant to scaling: if I multiply `a` by c, then `b` is multiplied by c², and `sum_a` is multiplied by c, so the ratio `max_b / sum_a²` stays the same.

So I can work with any scaling. Let me normalize to `sum(half) = 1` (so `sum(full) = 2`). Then:

Now let me think about the LP more carefully.

Given a palindromic `f` (normalized to sum=1), I want to find a palindromic `g` that maximizes `sum(g)` subject to:
- `conv(f, g)[k] <= M` for all k = 0, ..., 2n-2
- `g >= 0`

where `M = max(conv(f, f))` (the current max convolution value).

With palindromic constraint on g, I have n/2 free variables (the first half of g).

The constraint `conv(f, g)[k] <= M` can be written as:
`sum_j f[j] * g[k-j] <= M`

Since g is palindromic, `g[j] = g[n-1-j]`. So I can express `g[k-j]` in terms of the first half of g.

For a given k and j:
- If `0 <= k-j < n/2`: `g[k-j] = g_half[k-j]`
- If `n/2 <= k-j <= n-1`: `g[k-j] = g_half[n-1-(k-j)]`

So each constraint is linear in `g_half`.

Let me write this out more carefully for the LP.

Let n be even, n = 2m. The palindromic sequence is determined by `h = [h_0, h_1, ..., h_{m-1}]` where the full sequence is `[h_0, h_1, ..., h_{m-1}, h_{m-1}, ..., h_1, h_0]`.

For the LP, the variable is `h` (m variables). The constraint for convolution position k is:
`sum_{j=0}^{n-1} f[j] * g[k-j] <= M` (sum over valid j where 0 <= k-j < n)

Now `g[k-j]` depends on whether `k-j < m` or `k-j >= m`:
- If `0 <= k-j < m`: `g[k-j] = h[k-j]`
- If `m <= k-j < 2m`: `g[k-j] = h[2m-1-(k-j)] = h[n-1-k+j]`

So the constraint becomes a linear inequality in h.

Let me code this up properly.

Actually, for efficiency, let me precompute the constraint matrix for each k.

For a fixed k, the coefficient of `h[i]` in the constraint is:
`sum over j such that g[k-j] = h[i] of f[j]`

`g[k-j] = h[i]` when:
- `k-j = i` (i.e., `j = k-i`) and `0 <= i < m`, OR
- `k-j = n-1-i` (i.e., `j = k-n+1+i`) and `m <= n-1-i < n` (i.e., `0 <= i < m`)

So the coefficient of `h[i]` is:
`f[k-i] * [0 <= k-i < n] + f[k-n+1+i] * [0 <= k-n+1+i < n]`

where `[P]` is 1 if condition P holds, 0 otherwise.

Let me verify: for k=0, the constraint is `f[0]*g[0] <= M`. 
- `g[0] = h[0]`. 
- Coefficient of h[0]: f[0-0] * [0<=0<n] + f[0-n+1+0] * [0<=0-n+1<n] = f[0] + f[1-n] * [0 <= 1-n < n]. For n>1, 1-n < 0, so the second term is 0. Coefficient = f[0]. ✓

For k=1, the constraint is `f[0]*g[1] + f[1]*g[0] <= M`.
- Coefficient of h[0]: f[1-0]*[0<=1<n] + f[1-n+1+0]*[0<=1-n+1<n] = f[1] + f[2-n]*[0<=2-n<n] = f[1] (for n>2).
- Coefficient of h[1]: f[1-1]*[0<=0<n] + f[1-n+1+1]*[0<=1-n+1+1<n] = f[0] + f[3-n]*[0<=3-n<n] = f[0].
So constraint is `f[1]*h[0] + f[0]*h[1] <= M`. ✓

Great, so the LP constraint matrix A has entries:
`A[k, i] = f[k-i] * [0 <= k-i < n] + f[k-n+1+i] * [0 <= k-n+1+i < n]`

for k = 0, ..., 2n-2 and i = 0, ..., m-1.

This is a (2n-1) × m matrix. For n=384, m=192: it's a 767 × 192 matrix. Very manageable!

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using palindromic symmetry exploitation.
Key innovations:
1. Exploit palindromic symmetry to halve LP dimension
2. Frank-Wolfe with LP oracle on reduced space
3. Multiplicative weight (mirror descent) polish
4. Multi-length exploration
"""

import numpy as np
from scipy.optimize import linprog
import time


def expand_palindromic(half):
    """Expand a half-sequence to full palindromic sequence."""
    return np.concatenate([half, half[::-1]])


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def fast_convolve_cross(f, g):
    """Linear cross-convolution f * g via FFT."""
    n = len(f)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    F = np.fft.rfft(f, fft_size)
    G = np.fft.rfft(g, fft_size)
    return np.fft.irfft(F * G, fft_size)[:size]


def build_lp_matrix(f, n):
    """Build the LP constraint matrix for palindromic FW.
    f: palindromic sequence of length n
    Returns A (2n-1 x n/2) such that A @ h <= M for palindromic h.
    """
    m = n // 2
    A = np.zeros((2 * n - 1, m))
    # f is the full palindromic sequence
    for k in range(2 * n - 1):
        for i in range(m):
            # Coefficient of h[i] in conv[f, g][k]
            coeff = 0.0
            # g[k-j] = h[i] when k-j = i (j = k-i)
            j1 = k - i
            if 0 <= j1 < n:
                coeff += f[j1]
            # g[k-j] = h[i] when k-j = n-1-i (j = k-n+1+i)
            j2 = k - n + 1 + i
            if 0 <= j2 < n:
                coeff += f[j2]
            A[k, i] = coeff
    return A


def fw_palindromic(f_half, time_limit, verbose=False):
    """Frank-Wolfe with LP oracle on palindromic half-sequences."""
    n_full = 2 * len(f_half)
    m = len(f_half)
    f = expand_palindromic(f_half).copy()
    s = f.sum()
    if s < 1e-15:
        f = np.ones(n_full) / n_full
        f_half = f[:m].copy()
    else:
        f = f / s
        f_half = f[:m].copy()
    
    conv = fast_convolve(f)
    M = conv.max()
    best_obj = M
    best_half = f_half.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    m_exp = 1.0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        
        # Build LP and solve
        A = build_lp_matrix(f, n_full)
        c = -np.ones(m)  # minimize -sum(h) = maximize sum(h)
        b_ub = np.full(2 * n_full - 1, M * m_exp)
        bounds = [(0, None)] * m
        
        res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
        
        if not res.success:
            m_exp *= 1.2
            if m_exp > 5.0:
                m_exp = 1.0
                continue
            continue
        
        g_half = res.x

        g_half = g_full[:m].copy()

            continue

        best_alpha = 0.0
        best_val = M
        
        for alpha in [0.01, 0.02, 0.05, 0.1, 0.15, 0.2, 0.3, 0.5, 0.7, 1.0]:

            h_new = np.maximum(h_new, 0)
            h_sum = h_new.sum()
            if h_sum < 1e-15:
                continue

                h_new = (1 - mid) * f_half + mid * g_half

                full_new = expand_palindromic(h_new)
                fs = full_new.sum()

                    best_alpha = mid

            f_half = (1 - best_alpha) * f_half + best_alpha * g_half

            f = expand_palindromic(f_half)

def project_simplex(v):
    """Euclidean projection onto the simplex {x>=0, sum(x)=1}."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def mirror_descent_pal(f_half, time_limit, lr_init=0.02, top_k=10, temp_init=0.0003):
    """Mirror descent on palindromic half-sequences."""
    m = len(f_half)
    n_full = 2 * m
    f = expand_palindromic(f_half).copy()
    f = f / f.sum()
    f_half = f[:m].copy()
    
    conv = fast_convolve(f)
    best_obj = conv.max()
    best_half = f_half.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    cur_lr = lr_init
    cur_temp = temp_init
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        f = expand_palindromic(f_half)
        f = f / f.sum()
        conv = fast_convolve(f)
        M = conv.max()
        
        # Get gradient w.r.t. full sequence
        # grad[k-j] gets contribution 2*f[j]*w[k] for each peak k
        # But we only need the half-gradient
        top_k_eff = top_k
        if top_k_eff >= len(conv):
            peaks = np.arange(len(conv))
        else:
            peaks = np.argpartition(conv, -top_k_eff)[-top_k_eff:]
        
        pv = conv[peaks]
        scaled = pv / cur_temp
        scaled -= scaled.max()
        w = np.exp(scaled)
        ws = w.sum()
        if ws < 1e-15:
            w = np.zeros(len(peaks))
            w[np.argmax(pv)] = 1.0
        else:
            w /= ws
        
        # Compute gradient for full sequence
        grad_full = np.zeros(n_full)
        for i in range(len(peaks)):
            if w[i] < 1e-14:
                continue
            k = int(peaks[i])
            js = max(0, k - n_full + 1)
            je = min(n_full - 1, k)
            idx = np.arange(js, je + 1)
            grad_full[idx] += 2.0 * w[i] * f[k - idx]
        
        # Project to half (by symmetry, grad_full[j] and grad_full[n-1-j] contribute to same h[i])
        grad_half = (grad_full[:m] + grad_full[n_full-1:m-1:-1]) / 2.0
        
        # Multiplicative update
        f_half = f_half * np.exp(-cur_lr * grad_half)
        f_half = np.maximum(f_half, 1e-25)
        f_half = f_half / f_half.sum()
        
        f = expand_palindromic(f_half)
        f = f / f.sum()
        conv = fast_convolve(f)
        obj = conv.max()
        
        if obj < best_obj - 1e-15:
            best_obj = obj
            best_half = f_half.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        cur_lr *= 0.9995
        cur_temp *= 1.003
        
        if no_improve > 200:
            rng = np.random.default_rng(int(time.monotonic() * 100000))
            f_half = best_half * np.exp(rng.standard_normal(m) * 0.003)
            f_half = f_half / f_half.sum()
            cur_lr = max(lr_init * 0.5, 0.005)
            cur_temp = temp_init * 2.0
            no_improve = 0
    
    return best_half, best_obj


def subgradient_pal(f_half, time_limit, lr=0.002, mom=0.90, top_k=20):
    """Subgradient method on palindromic half-sequences."""
    m = len(f_half)
    n_full = 2 * m
    f = expand_palindromic(f_half).copy()
    f = f / f.sum()
    f_half = f[:m].copy()
    
    v = np.zeros(m)
    conv = fast_convolve(f)
    best_obj = conv.max()
    best_half = f_half.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    cur_lr = lr
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        f = expand_palindromic(f_half)
        f = f / f.sum()
        conv = fast_convolve(f)
        M = conv.max()
        
        if top_k >= len(conv):
            peaks = np.arange(len(conv))
        else:
            peaks = np.argpartition(conv, -top_k)[-top_k:]
        
        pv = conv[peaks]
        order = np.argsort(pv)[::-1]
        weights = np.zeros(len(peaks))
        for rank, idx in enumerate(order):
            weights[idx] = 1.0 / (rank + 1) ** 1.5
        weights /= weights.sum()
        
        grad_full = np.zeros(n_full)
        for i in range(len(peaks)):
            if weights[i] < 1e-14:
                continue
            k = int(peaks[i])
            js = max(0, k - n_full + 1)
            je = min(n_full - 1, k)
            idx = np.arange(js, je + 1)
            grad_full[idx] += 2.0 * weights[i] * f[k - idx]
        
        grad_half = (grad_full[:m] + grad_full[n_full-1:m-1:-1]) / 2.0
        
        v = mom * v - cur_lr * grad_half
        f_half = np.maximum(f_half + v, 0)
        f_half = f_half / f_half.sum()
        
        f = expand_palindromic(f_half)
        f = f / f.sum()
        conv = fast_convolve(f)
        obj = conv.max()
        
        if obj < best_obj - 1e-15:
            best_obj = obj
            best_half = f_half.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        cur_lr *= 0.9997
        
        if no_improve > 200:
            rng = np.random.default_rng(int(time.monotonic() * 100000))
            scale = 0.001 + 0.002 * min(1.0, no_improve / 500.0)
            f_half = np.maximum(best_half + rng.standard_normal(m) * scale, 1e-10)
            f_half = f_half / f_half.sum()
            v = np.zeros(m)
            cur_lr = max(lr * 0.7, 0.0005)
            no_improve = 0
    
    return best_half, best_obj


def get_score_from_half(half):

def make_palindromic(seq):
    """Make a sequence palindromic by averaging with its reverse."""
    n = len(seq)
    m = n // 2
    if n % 2 == 0:
        half = (seq[:m] + seq[n-1:m-1:-1]) / 2.0
    else:
        m = (n + 1) // 2
        half = (seq[:m] + seq[n-1:m-1:-1]) / 2.0
    half = np.maximum(half, 0)
    s = half.sum()
    if s < 1e-15:
        half = np.ones(len(half)) / len(half)
    else:
        half = half / s
    return half

Minimizes 2*n*max(conv(a,a))/(sum(a))^2 by exploiting palindromic symmetry.
Uses Frank-Wolfe with LP oracle on the reduced (half) space, combined with
mirror descent and subgradient polish. Explores multiple sequence lengths.

import numpy as np
from scipy.optimize import linprog
import time


def expand_palindromic(half):
    """Expand half-sequence to full palindromic: [h, h[::-1]]."""
    return np.concatenate([half, half[::-1]])


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Projection onto probability simplex."""
    n = len(v)
    if n <= 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using palindromic symmetry.
Algorithm:
1. Frank-Wolfe with LP oracle on palindromic half-sequences (fast due to reduced dimension)
2. Mirror descent / multiplicative weight polish
3. Subgradient method for final refinement
4. Multi-length exploration to find best n
"""

import numpy as np
from scipy.optimize import linprog
import time


def expand_palindromic(half):
    return np.concatenate([half, half[::-1]])


def fast_convolve(a):
    n = len(a)
    if n == 0:
        return np.array([])
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    n = len(v)
    if n <= 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def build_lp_matrix(f, n):
    """Build LP matrix for palindromic FW. f is full palindromic, n = len(f)."""
    m = n // 2
    A = np.zeros((2 * n - 1, m))
    for k in range(2 * n - 1):
        # First term: f[k-i]
        s1 = max(0, k - n + 1)
        e1 = min(m - 1, k)
        if s1 <= e1:
            idx = np.arange(s1, e1 + 1)
            A[k, idx] += f[k - idx]
        # Second term: f[k-n+1+i]
        s2 = max(0, n - 1 - k)
        e2 = min(m - 1, 2 * n - 2 - k)
        if s2 <= e2:
            idx = np.arange(s2, e2 + 1)
            A[k, idx] += f[k - n + 1 + idx]
    return A


def eval_half(half):
    """Evaluate objective from palindromic half (full sum normalized to 1)."""
    full = expand_palindromic(half)
    s = full.sum()
    if s < 1e-15:
        return 0.0
    full = full / s
    n = len(full)
    conv = fast_convolve(full)
    return 2.0 * n * conv.max()
