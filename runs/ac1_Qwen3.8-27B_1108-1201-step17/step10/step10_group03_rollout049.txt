Let me think about the multiplicative weight method more carefully:

The idea is:
- We want to minimize f(a) = max_k (a*a)[k] subject to a ≥ 0, sum(a) = 1
- At each step, compute the gradient g = ∇f(a) (or a subgradient if f is not differentiable)
- Update: a_new[j] = a[j] * exp(-η * g[j]) / Z (where Z normalizes)
- This is the multiplicative weight / Winnow update

For the max function, the subgradient at the active peak k* is:
g[j] = 2 * a[k*-j] (where a[k*-j] = 0 if k*-j is out of range)

For multiple active peaks, we average the subgradients:
g[j] = (1/|S|) * sum_{k in S} 2 * a[k-j]

The multiplicative update then becomes:
a_new[j] = a[j] * exp(-η * g[j]) / Z

This is equivalent to:
a_new[j] = a[j] / (1 + η * g[j]) (using the first-order approximation exp(-x) ≈ 1/(1+x))

Or more precisely:
a_new[j] = a[j] * (1 - η * g[j]) / (1 - η * sum_j a[j] * g[j]) (to maintain sum = 1)

The key advantage of the multiplicative update is that it naturally maintains non-negativity (as long as η * g[j] < 1 for all j).

Let me also think about the step size η. A good choice is:
η = c / ||g||_∞ (where c is a constant, typically 1 or 2)

Or adaptively: η = c * (f(a) - f_lower_bound) / ||g||^2 (where f_lower_bound is a known lower bound).

For this problem, a lower bound on f(a) = max_k (a*a)[k] is:
f(a) ≥ (sum(a))^2 / (2n-1) = 1/(2n-1) (by the pigeonhole principle / average value)

So a lower bound on the objective 2n * f(a) is 2n/(2n-1) ≈ 1.

The gap between the current objective and this lower bound gives us a natural measure of progress.

def fast_convolve(a):
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]

def build_conv_matrix(a):
    n = len(a)
    size = 2 * n - 1
    T = np.zeros((size, n))
    for j in range(n):
        T[j:j+n, j] = a
    return T

def local_eval(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    n = len(a)
    b = fast_convolve(a)
    return float(2.0 * n * b.max() / (s * s))

def normalize(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s

def get_lp_solver():
    for solver_name in [cp.ECOS, cp.SCS, cp.CLARABEL, cp.PDLP]:
        try:
            x = cp.Variable(3, nonneg=True)
            prob = cp.Problem(cp.Minimize(cp.sum(x)), [cp.sum(x) == 1])
            prob.solve(solver=solver_name)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                return solver_name
        except Exception:
            continue
    return cp.ECOS

def solve_best_response(fixed_a, solver):
    """Given fixed_a (sum=1), find b >= 0, sum(b)=1 minimizing max_k conv(fixed_a, b)[k]."""
    n = len(fixed_a)
    b_var = cp.Variable(n, nonneg=True)
    M_var = cp.Variable()
    T = build_conv_matrix(fixed_a)
    constraints = [T @ b_var <= M_var, cp.sum(b_var) == 1]
    prob = cp.Problem(cp.Minimize(M_var), constraints)
    try:
        prob.solve(solver=solver)
        if prob.status in ('optimal', 'optimal_inaccurate'):
            b_val = np.asarray(b_var.value, dtype=np.float64)
            b_val = np.maximum(b_val, 0)
            s = b_val.sum()
            if s > 1e-15:
                return b_val / s
    except Exception:
        pass
    for alt in [cp.ECOS, cp.SCS, cp.CLARABEL, cp.PDLP]:
        if alt == solver:
            continue
        try:
            prob.solve(solver=alt)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                b_val = np.asarray(b_var.value, dtype=np.float64)
                b_val = np.maximum(b_val, 0)
                s = b_val.sum()
                if s > 1e-15:

        except Exception:

    return None

def bidi_lp(a0, time_limit, solver, max_iters=100000):
    """Bidirectional LP alternation with Nesterov averaging."""
    n = len(a0)
    a = normalize(a0)
    b = a.copy()
    y_a = a.copy()
    y_b = b.copy()
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    t0 = time.monotonic()
    prev_best = best_score
    stall = 0
    rng = np.random.default_rng(12345)
    
    for it in range(max_iters):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Solve for best b given y_a
        b_new = solve_best_response(y_a, solver)
        if b_new is not None:
            alpha = 2.0 / (it + 2)
            y_b = (1.0 - alpha) * y_b + alpha * b_new
            y_b = normalize(y_b)
            b = ((it + 1) * b + (alpha * (it + 2)) * b_new) / (it + 1 + alpha * (it + 2))
            b = normalize(b)
        
        # Solve for best a given y_b
        a_new = solve_best_response(y_b, solver)
        if a_new is not None:
            alpha = 2.0 / (it + 3)
            y_a = (1.0 - alpha) * y_a + alpha * a_new
            y_a = normalize(y_a)
            a = ((it + 1) * a + (alpha * (it + 3)) * a_new) / (it + 1 + alpha * (it + 3))
            a = normalize(a)
        
        # Track best
        sc_a = 2.0 * n * fast_convolve(a).max()
        sc_b = 2.0 * n * fast_convolve(b).max()
        if sc_a < best_score:
            best_score = sc_a
            best_a = a.copy()
        if sc_b < best_score:
            best_score = sc_b
            best_a = b.copy()
        
        if (it + 1) % 100 == 0:
            if best_score < prev_best - 1e-10:
                stall = 0
            else:
                stall += 1
            prev_best = best_score
            
            if stall >= 5:
                noise = 0.03 / math.sqrt(stall)
                y_a = y_a + rng.standard_normal(n) * noise
                y_a = normalize(y_a)
                y_b = y_b + rng.standard_normal(n) * noise
                y_b = normalize(y_b)
                stall = 0
    
    return best_a, best_score

def multiplicative_weight(a0, time_limit, max_iters=50000):
    n = len(a0)
    a = normalize(a0)
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    t0 = time.monotonic()
    eta = 0.1
    no_improve = 0
    
    for it in range(max_iters):
        if time.monotonic() - t0 > time_limit:
            break
        
        b = fast_convolve(a)
        M = b.max()
        
        # Identify active peaks (within 0.5% of max)
        threshold = M * 0.995
        active = np.where(b >= threshold)[0]
        if len(active) == 0:
            active = np.array([int(np.argmax(b))])
        
        # Compute subgradient (average over active peaks)
        g = np.zeros(n)
        for k in active:
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            g[idx] += 2.0 * a[k - idx]
        g /= len(active)
        
        # Multiplicative update
        g_max = g.max()
        if g_max < 1e-15:
            break
        eta = min(eta, 0.5 / g_max)  # Safety: ensure a*(1-eta*g) > 0
        a_trial = a * (1.0 - eta * g)
        a_trial = np.maximum(a_trial, 0)
        s = a_trial.sum()
        if s < 1e-15:
            a_trial = a.copy()
        else:
            a_trial = a_trial / s
        
        sc = 2.0 * n * fast_convolve(a_trial).max()
        if sc < best_score - 1e-14:
            best_score = sc
            best_a = a_trial.copy()
            a = a_trial
            no_improve = 0
            eta = min(eta * 1.005, 0.5)
        else:
            no_improve += 1
            if no_improve >= 50:
                eta *= 0.9
                no_improve = 0
        
        # Safety: reset eta if it gets too small
        if eta < 1e-6:
            eta = 0.01
            no_improve = 0
    
    return best_a, best_score

            z = res.x

For the active-set refinement, here's the idea:

def active_set_refine(a0, time_limit, solver, max_rounds=2000):
    n = len(a0)
    a = normalize(a0)
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    t0 = time.monotonic()
    
    for rnd in range(max_rounds):
        if time.monotonic() - t0 > time_limit:
            break
        
        b = fast_convolve(a)
        M = b.max()
        
        # Active set: peaks within 1% of max
        threshold = M * 0.99
        active = np.where(b >= threshold)[0]
        if len(active) == 0:
            active = np.array([int(np.argmax(b))])
        m_active = len(active)
        
        # Build gradient matrix G: G[i, j] = 2 * a[active[i] - j] (if valid)
        G = np.zeros((m_active, n))
        for i, k in enumerate(active):
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            G[i, idx] = 2.0 * a[k - idx]
        
        # LP: minimize t s.t. G @ delta <= t - b[active] (for linearized constraint)
        # Actually: b[k] + G[i] @ delta <= t, sum(delta) = 0, a + delta >= 0
        # Substituting t: we want to minimize the max linearized value
        # Equivalent to: minimize t s.t. G @ delta - t*1 <= -b[active], sum(delta)=0, a+delta>=0
        
        delta_var = cp.Variable(n)
        t_var = cp.Variable()
        
        constraints = [
            cp.sum(delta_var) == 0,
            a + delta_var >= 0,
            G @ delta_var <= t_var * np.ones(m_active) - b[active],
        ]
        
        prob = cp.Problem(cp.Minimize(t_var), constraints)
        try:
            prob.solve(solver=solver)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                delta_val = np.asarray(delta_var.value, dtype=np.float64)
                a_trial = a + 0.5 * delta_val  # Damped step
                a_trial = np.maximum(a_trial, 0)
                s = a_trial.sum()
                if s > 1e-15:
                    a_trial = a_trial / s
                    sc = 2.0 * n * fast_convolve(a_trial).max()
                    if sc < best_score - 1e-14:
                        best_score = sc
                        best_a = a_trial.copy()
                        a = a_trial
        except Exception:
            pass
    
    return best_a, best_score

Let me also think about the n exploration more carefully. The objective is 2n * max_b / (sum_a)^2. If I increase n by a factor of λ, and scale the sequence accordingly (a_new[j] = a[old_index] / λ to maintain sum = 1), then:
- max_b changes (roughly stays the same if the peak is at lag 0, or decreases if the peak shifts)
- 2n increases by λ
- So the objective increases by roughly λ * (max_b_new / max_b_old)

For the uniform sequence, max_b = 1/n, so the objective is 2n * (1/n) = 2 regardless of n. For a non-uniform sequence, increasing n generally increases the objective (because 2n grows while max_b doesn't shrink proportionally).

But wait, if we interpolate the sequence to a longer length, the peak of the convolution might decrease (because the energy is spread over more elements). Let's see:

If a has n elements and sum = 1, then (a*a)[0] = sum(a_j^2) ≥ 1/n (by Cauchy-Schwarz, equality when uniform).

If we interpolate to 2n elements (by inserting zeros between elements), the new sequence a_new has 2n elements, sum = 1, and (a_new * a_new)[0] = sum(a_new_j^2) = sum(a_j^2) (same energy). So the peak at lag 0 doesn't change, but 2n doubles, so the objective doubles. Bad.

If we interpolate by linear interpolation (not inserting zeros), the new sequence is "smoother" and (a_new * a_new)[0] = sum(a_new_j^2) < sum(a_j^2) (the energy decreases because the values are spread out). But 2n still increases.

The net effect depends on the specific sequence. For a well-optimized sequence, the peak might be dominated by a few specific lags, and interpolating might not help much.
