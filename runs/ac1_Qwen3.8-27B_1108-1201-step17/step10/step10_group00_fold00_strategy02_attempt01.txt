<strategy-section>
1. Approach and rationale
We introduce a multi-length greedy optimization algorithm that explores different sequence lengths simultaneously in a loosely coupled parallel schedule. Unlike previous methods that used expensive, dense LPs or gradient-based solvers, this approach uses local, smart moves with active-set tracking to reduce the convolution maximum while maintaining non-negativity. The greedy algorithm finds moves where only items near the active peaks in current solution space are updated, which we show is surprisingly effective. Key improvements include:
   - Explicit dimension-respecting updates (zero outside the sequence)
   - Maximum-convex-combination nearest neighbor moves
   - Move insertion based on extreme value heuristic
   - Multiple-length updates across solver steps

The goal is to find a sequence structure with:
   Sum(a) ≥ 0.01 (avoiding trivial solutions)
   Each a_i ∈ [0, 1000] (per security constraint)
   Convolve(a,a): the full linear autocorrelation
   Objective: 2*n*max_conv / (sum(a))^2

<strategy-section>
2. Mathematical specification
The optimization occurs in two spaces:
   - Physical space: Vector a of nonnegative floats
   - Gradient space: Log-softmax space z

Variables:
   n: Length parameter (dimension)
   a: Sequence vector (must be normalized)
   z: Internal state variables (satisfaction of multiple constraints)

Constraints for physical space:
   a_i ∈ [0, 1000] for all i
   ∑ a_i ≥ 0.01

Objective function:
   f(a) = 2*n*max_k(conv(a,a)[k]) / (∑ a_i)^2

Extreme value heuristic:
   s = sum(a)
   For each peak index k0:
       Decide move only if conv(a,a)[k0] - conv(a,a)[k0+1] > 7 * s   (strong gradient requirement)
       Otherwise, track last few peaks that convolve strongly

This allows us to restrict expensive updates only to active indices.
