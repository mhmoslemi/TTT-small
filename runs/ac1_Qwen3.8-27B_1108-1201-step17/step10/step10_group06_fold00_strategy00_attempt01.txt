3. Projecting changes onto the feasible space preserved by the defensive clipping
4. Combining with a beam search strategy to explore multiple promising areas

The central idea is to minimize the worst-case position in the convolution using gradient information. We'll use the fact that the objective is scale-invariant (after normalization and clipping) to focus solely on the efficient vector. The nonnegativity of coefficients effectively makes this a convex optimization problem in a log-space or other space free of constraints.

### Mathematical Specification

We want to minimize:
```
O(a) = 2 * n * max_k(conv_k) / (sum(a))^2
```
over α ∈ ℝⁿ with sum(a) ≥ 0.01.

Define:
```
n = len(a)
conv_k = sum_i a_i * a_{k+i}   , but note this is for circular convolution
```
Actually, we should use linear convolution (mode = "full"):
```
conv_k = sum_{i=0}^{min(k, n+k-len(a)-1)} a_i * a_{k-i}   for the full convolution solution, but that's guaranteed by the evaluator
```

The optimization is performed by computing the gradient only at the active constraints (conv_k = max_k conv_k). For each active constraint, the directional derivative in direction d is proportional to the number of ways d influences that convolution element proportionally.
