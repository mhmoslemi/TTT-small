The autocorrelation `r[k] = sum_i a[i] * a[i+k]` (with appropriate bounds) is the cepstrum of the power spectrum. To minimize `max r[k]`, we want to minimize the peak of the cepstrum.

In the frequency domain, `|A(f)|^2 = sum_k r[k] * exp(-2πi*k*f/n)` (approximately, for circular convolution).

To make `r[k]` flat, we want `|A(f)|^2` to be concentrated at f=0 (DC). But `|A(0)|^2 = (sum a)^2 = 1`, so all the "energy" is at DC. The other frequency components should be as small as possible.

Wait, that's not right either. Let me use the correct relationship.

For a finite sequence `a` of length n, the DFT is `A[m] = sum_{k=0}^{n-1} a[k] * exp(-2πi*m*k/n)`.

The circular autocorrelation is `r_circ[k] = sum_i a[i] * a[(i+k) mod n] = IFFT(|A|^2)[k]`.

The linear autocorrelation is different (it's the full convolution), but for large n, they're approximately related.

To minimize the peak of the linear autocorrelation, we want the circular autocorrelation to be as flat as possible (except at k=0). This means `|A[m]|^2` should be as flat as possible for m ≠ 0.

But `|A[0]|^2 = (sum a)^2 = 1` (fixed), and `sum_m |A[m]|^2 = n * sum_k a[k]^2` (by Parseval). So the "energy" in the non-DC components is `n * sum a[k]^2 - 1`.

To minimize the peak of the autocorrelation, we want this energy to be spread evenly across the n-1 non-DC components. This means `|A[m]|^2 = (n * sum a[k]^2 - 1) / (n-1)` for m ≠ 0.

This is equivalent to making `a` have a "white" power spectrum (except at DC). The sequence that achieves this is a "causal" version of a random sequence with the right power spectrum.

In practice, we can approximate this by:
1. Start with `a` (e.g., uniform).
2. Compute `A = FFT(a)`.
3. Set `|A[0]| = 1` (fixed).
4. For m ≠ 0, set `|A[m]| = target_value` (e.g., the current mean of |A[m]| for m ≠ 0).
5. Keep the phase of A.
6. `a_new = IFFT(A_new)`.
7. Project to non-negative simplex.
8. Repeat.

This is essentially a "spectral equalization" approach.

But there's a problem: the non-negativity constraint is hard to satisfy. After the IFFT, the values might be negative. Projecting to non-negative (clipping at 0) changes the spectrum again.

This is where POCS (Projection Onto Convex Sets) comes in:
- Set 1: Sequences with the desired power spectrum (non-convex, but we can project by modifying the FFT magnitude).
- Set 2: Non-negative sequences with sum 1 (convex, the simplex).

We alternate projections between these two sets.

import numpy as np
from scipy.fft import rfft, irfft
import time

def fast_convolve(a):
    """Compute full linear convolution using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]

def simplex_project(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if cond.any():
        rho = np.nonzero(cond)[0][-1]
        theta = (cssv[rho] - 1.0) / (rho + 1.0)
        return np.maximum(v - theta, 0.0)
    else:
        return np.ones(n) / n

def convolve_ab(a, b):
    """Compute convolution of a and b using FFT."""
    n = len(a)
    m = len(b)
    size = n + m - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    B = rfft(b, fft_size)
    return irfft(A * B, fft_size)[:size]

def spectral_shaping(a0, time_limit, alpha=0.5, n_iters=None, label=""):
    """
    POCS-based spectral shaping to flatten the autocorrelation.
    Alternates between:
    - Flattening the power spectrum (in frequency domain)
    - Projecting to non-negative simplex (in time domain)
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    conv = fast_convolve(a)
    M = float(conv.max())
    best_a = a.copy()
    best_score = 2.0 * n * M
    t0 = time.monotonic()
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        if n_iters is not None and it >= n_iters:
            break
        it += 1
        
        # Step 1: FFT
        fft_size = 1 << (2 * n - 1).bit_length()
        A = rfft(a, fft_size)
        
        # Step 2: Compress the power spectrum
        # Keep DC fixed, compress the rest
        A_orig = A.copy()
        magnitude = np.abs(A)
        phase = np.angle(A)
        
        # Power spectrum
        P = magnitude ** 2
        P_non_dc = P[1:]
        P_dc = P[0]
        
        # Compress: P_new = P^alpha (reduces dynamic range)
        P_non_dc_new = P_non_dc ** alpha
        P_new = np.concatenate([[P_dc], P_non_dc_new])
        
        # But we need to preserve the total "energy" in some sense
        # Actually, let's just rescale to maintain the DC component
        # The DC component is (sum a)^2 = 1, so |A[0]| = 1
        # For the other components, we want them to be as equal as possible
        
        # Alternative: set all non-DC magnitudes to the geometric mean
        non_dc_mags = magnitude[1:]
        non_dc_mags_new = non_dc_mags ** alpha
        # Rescale to maintain same total non-DC energy
        total_orig = np.sum(non_dc_mags ** 2)
        total_new = np.sum(non_dc_mags_new ** 2)
        if total_new > 1e-30:
            non_dc_mags_new *= np.sqrt(total_orig / total_new)
        
        magnitude[1:] = non_dc_mags_new
        A_new = magnitude * np.exp(1j * phase)
        
        # Step 3: IFFT
        a_new = irfft(A_new, fft_size)[:n]
        
        # Step 4: Project to non-negative simplex
        a_new = np.maximum(a_new, 0.0)
        s_new = a_new.sum()
        if s_new < 1e-15:
            a_new = simplex_project(a_new + 1e-10)
        else:
            a_new = a_new / s_new
        
        # Evaluate
        conv_new = fast_convolve(a_new)
        M_new = float(conv_new.max())
        score = 2.0 * n * M_new
        
        if score < best_score - 1e-15:
            best_score = score
            best_a = a_new.copy()
        
        a = a_new
        
        if it % 100 == 0:
            elapsed = time.monotonic() - t0
            print(f"    SpecShape {label} it={it} ({elapsed:.0f}s): best={best_score:.6f}, M={M_new:.8f}")
    
    return best_a, best_score, it

def peak_targeted_descent(a0, time_limit, label=""):
    """
    Iteratively target the highest peaks in the autocorrelation and
    redistribute mass from high-pressure to low-pressure positions.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    conv = fast_convolve(a)
    M = float(conv.max())
    best_a = a.copy()
    best_score = 2.0 * n * M
    t0 = time.monotonic()
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        
        # Find the top peaks
        top_k = min(5, 2 * n - 1)
        peak_indices = np.argsort(conv)[::-1][:top_k]
        
        # Compute pressure at each position
        # pressure[i] = sum over peak lags k of a[i]*a[i+k] + a[i]*a[i-k]
        pressure = np.zeros(n)
        for k in peak_indices:
            for i in range(max(0, int(k) - n + 1), min(n, int(k) + 1)):
                j = int(k) - i
                if 0 <= j < n:
                    pressure[i] += a[i] * a[j]
        
        p_max = pressure.max()
        if p_max < 1e-20:
            break
        
        # Normalize pressure
        pressure = pressure / p_max
        
        # Create update direction: reduce high-pressure, increase low-pressure
        # Use a soft update
        eta = 0.1  # Step size
        a_update = a * (1.0 - eta * pressure)
        # Redistribute: add proportional to (1 - pressure) for positions with mass
        redistribute = (1.0 - pressure) * (a > 1e-10)
        r_sum = redistribute.sum()
        if r_sum > 1e-15:
            a_update += eta * a.sum() * redistribute / r_sum
        
        a_new = np.maximum(a_update, 0.0)
        s_new = a_new.sum()
        if s_new < 1e-15:
            break
        a_new = a_new / s_new
        
        conv_new = fast_convolve(a_new)
        M_new = float(conv_new.max())
        score = 2.0 * n * M_new
        
        if score < best_score - 1e-15:
            best_score = score
            best_a = a_new.copy()
            a = a_new
            conv = conv_new
            M = M_new
        else:
            # Reduce step size
            eta *= 0.9
            if eta < 1e-6:
                break
    
    return best_a, best_score, it

def get_lp_solver():
    import cvxpy as cp
    for solver_name in [cp.GUROBI, cp.MOSEK, cp.PDLP, cp.SCS, cp.ECOS]:
        try:
            x = cp.Variable(3, nonneg=True)
            prob = cp.Problem(cp.Minimize(cp.sum(x)), [cp.sum(x) == 1])
            prob.solve(solver=solver_name)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                return solver_name
        except Exception:
            continue
    return cp.ECOS

def build_conv_matrix(a):
    """Build the matrix T such that T @ b = convolve(a, b)."""
    n = len(a)
    T = np.zeros((2 * n - 1, n))
    for j in range(n):
        T[j:j + n, j] = a
    return T
