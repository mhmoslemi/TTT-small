- Subject to: `conv(a, a)[k] <= M` for all k
- `sum(a) = 1`
- `a >= 0`

But this is a NONLINEAR constraint (quadratic in a)! The constraint `a^T T_k a <= M` is quadratic, not linear.

So we can't directly solve this as an LP. We need to use the alternating approach: fix one variable, optimize the other.

The alternating approach:
1. Fix `a`, find `b` that minimizes `max_k (T_a @ b)[k]` where `T_a` is the "a-convolution" matrix. This IS an LP.
2. Fix `b`, find `a` that minimizes `max_k (T_b @ a)[k]`. This IS an LP.

But this finds a fixed point of the map `a -> best_response(a) -> best_response(best_response(a)) -> ...`, which is NOT the same as minimizing `max(conv(a,a))`.

However, if we start with `a = b` and alternate, we're effectively doing:
1. Given current `a`, find `a_new` that minimizes `max_k conv(a, a_new)[k]` (LP)
2. Given current `a_new`, find `a_newer` that minimizes `max_k conv(a_new, a_newer)[k]` (LP)
3. ...

This is the "best response" iteration, which converges to a Nash equilibrium of the 2-player game where both players choose the same sequence. The Nash equilibrium is NOT necessarily the minimizer of `max(conv(a,a))`.

But in practice, it often gets close to the optimum, especially if we average the iterates.

Alternatively, we can use the "mirror descent" or "gradient" approach directly on `a`, treating `max(conv(a,a))` as the objective (with logsumexp smoothing).
