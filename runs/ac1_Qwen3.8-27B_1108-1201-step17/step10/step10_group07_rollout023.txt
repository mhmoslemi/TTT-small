**Key insight for improvement**: The LP alternating minimizes a relaxed problem. The gap between the relaxed and original problems gives us a lower bound on how much we can improve by "pushing" a towards its best response.

Let me now think about a concrete improvement strategy:

2. **At the converged point, do a "self-consistency" check**: compute the best response b* to a. If b* is close to a, we're at a fixed point. If not, there's room for improvement.
3. **Use the gap to guide the optimization**: If b* differs from a, move a towards b* but also check the actual objective (not just the relaxed one).
4. **Use second-order information**: The Hessian of the objective at a is related to the convolution matrix. We can use Newton-like steps.

**Newton step idea**:
The objective is f(a) = max_k b_k where b = T(a)a. At a local minimum, the active set (k values where b_k = max) determines the optimization.

If we know the active set K, we can minimize:

This is still non-convex (bilinear), but we can linearize:

This is an LP! We can solve it to get the direction d, then do a line search.

This is essentially a cutting-plane / active-set method. Let me implement this.

Now let me think about the coordinate descent more carefully.

In the coordinate descent, for each coordinate i, we want to find the best value of a[i] (keeping others fixed) that minimizes the max of the convolution.

The convolution values affected by changing a[i] are:
b[k] for k in [i, min(i+n-1, 2n-2)]
b[k] = b[k]_old + 2*delta*a[k-i] + delta^2 (if k=2i)

Where delta = a[i]_new - a[i]_old.

For a given i, the affected b values are quadratic functions of delta. The max of these quadratics (and the unaffected b values) is what we want to minimize.

This is a 1D optimization problem: min_delta max(m1, m2, ..., mq(delta), unaff_max)
where mq(delta) = b[q]_old + 2*delta*a[q-i] + delta^2 (for k=q=2i) or b[q]_old + 2*delta*a[q-i] (for k≠2i).

The optimal delta can be found by bisection or by analyzing the piecewise-quadratic function.

For efficiency, we can:
1. Sort the affected b values.
2. Find the "critical" delta where the max changes which k is the peak.
3. At each critical region, the max is a specific quadratic, and we can find its minimum.

This is O(n log n) per coordinate, which for n=1024 gives O(n^2 log n) per sweep. That's about 10^7 * 10 = 10^8 operations per sweep, which might be too slow.

The previous code uses a simpler approach: try a few candidate deltas and pick the best. This is O(1) per coordinate (times the number of candidates), making a sweep O(n * candidates). Much faster.

**Key improvement for coordinate descent**: Instead of fixed ratios, use the current b values to determine good candidate deltas.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Active-set LP with line search (primary, replaces full LP alternating)
2. Mirror descent with log-sum-exp smoothing (diversification)
3. Targeted coordinate descent with smart candidate generation (polishing)
4. Spectral peak shaving (escape from local minima)
5. Multi-n exploration (try different sequence lengths)

import numpy as np
from scipy.fft import rfft, irfft
import time
import cvxpy as cp


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def convolve_ab(a, b):
    """Linear convolution of a and b via FFT."""
    n_a = len(a)
    n_b = len(b)
    size = n_a + n_b - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    B = rfft(b, fft_size)
    return irfft(A * B, fft_size)[:size]


def score_of(a):
    """Compute 2*n*max(conv)/(sum)^2 quickly (assumes sum=1)."""
    n = len(a)
    s = a.sum()
    if s < 1e-15:
        return float('inf')
    conv = fast_convolve(a)
    return float(2.0 * n * conv.max() / (s * s))


def simplex_project(v):
    """Project vector v onto the simplex {x >= 0, sum(x)=1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.arange(1, n + 1)
    cond = u * rho > (cssv - 1)
    if np.any(cond):
        k = int(np.nonzero(cond)[0][-1])
        theta = (cssv[k] - 1.0) / (k + 1.0)
        return np.maximum(v - theta, 0.0)
    return np.ones(n) / n


def find_lp_solver():
    """Find the fastest working LP solver."""
    cached = getattr(find_lp_solver, '_cached', None)
    if cached is not None:
        return cached
    for solver_name in [cp.CLARABEL, cp.PDLP, cp.ECOS, cp.SCS]:
        try:
            x = cp.Variable(10, nonneg=True)
            prob = cp.Problem(cp.Minimize(cp.sum(x)), [cp.sum(x) == 1])
            prob.solve(solver=solver_name)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                find_lp_solver._cached = solver_name
                return solver_name
        except Exception:
            continue
    find_lp_solver._cached = cp.ECOS
    return cp.ECOS


def normalize(a):
    """Normalize a to sum to 1, clip negatives."""
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s


def build_active_matrix(a, K):
    """Build matrix where row k of result = the gradient row for b_k."""
    n = len(a)
    mat = np.zeros((len(K), n))
    for idx, k in enumerate(K):
        k = int(k)
        i_start = max(0, k - n + 1)
        i_end = min(n - 1, k)
        if i_end >= i_start:
            # row[i] = a[k-i] for i in [i_start, i_end]
            # When i = i_start: a[k - i_start]
            # When i = i_end: a[k - i_end]
            mat[idx, i_start:i_end + 1] = a[k - i_end:k - i_start + 1][::-1]
    return mat


def active_set_lp(a, K, solver):
    """
    Solve the active-set LP to find a descent direction d.
    min t s.t. b_k + 2*(C_a d)_k <= t for k in K, sum(d)=0, d >= -a
    Returns (d, t_val) or (None, inf) on failure.
    """
    n = len(a)
    b = fast_convolve(a)
    
    if len(K) == 0:
        return None, float('inf')
    
    mat = build_active_matrix(a, K)  # shape (|K|, n), mat[idx, i] = a[K[idx]-i] if valid
    b_K = b[list(K)]
    
    d = cp.Variable(n)
    t = cp.Variable()
    
    constraints = [
        cp.sum(d) == 0,
        d >= -a,
        mat @ d <= (t - b_K) / 2.0
    ]
    
    prob = cp.Problem(cp.Minimize(t), constraints)
    try:
        prob.solve(solver=solver)
    except Exception:
        try:
            prob.solve(solver=cp.ECOS)
        except Exception:
            return None, float('inf')
    
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None, float('inf')
    
    d_val = np.asarray(d.value, dtype=np.float64)
    if d_val is None or not np.all(np.isfinite(d_val)):
        return None, float('inf')
    
    t_val = float(t.value) if t.value is not None else float('inf')
    return d_val, t_val


def line_search_conv(a, d):
    """
    Find optimal alpha in [0, 1] minimizing max(conv(a + alpha*d, a + alpha*d)).
    Uses the fact that conv(a+ad, a+ad) = b + 2*alpha*ad + alpha^2*dd.
    """
    n = len(a)
    b = fast_convolve(a)
    ad = convolve_ab(a, d)
    dd = fast_convolve(d)
    
    def obj(alpha):
        return float((b + 2.0 * alpha * ad + alpha * alpha * dd).max())
    
    # Golden section search
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    lo, hi = 0.0, 1.0
    c = hi - gr * (hi - lo)
    dpt = lo + gr * (hi - lo)
    fc = obj(c)
    fd = obj(dpt)
    
    for _ in range(40):
        if hi - lo < 1e-10:
            break
        if fc < fd:
            hi = dpt
            dpt = c
            fd = fc
            c = hi - gr * (hi - lo)
            fc = obj(c)
        else:
            lo = c
            c = dpt
            fc = fd
            dpt = lo + gr * (hi - lo)
            fd = obj(dpt)
    
    alpha = (lo + hi) / 2.0
    return alpha, obj(alpha)


def active_set_descent(a0, time_limit, solver, verbose=True):
    """
    Active-set LP + line search descent.
    """
    n = len(a0)
    a = normalize(a0.astype(np.float64).copy())
    best_a = a.copy()
    conv = fast_convolve(a)
    best_score = float(2.0 * n * conv.max())
    t0 = time.monotonic()
    it = 0
    stagnation = 0
    eps = 1e-6  # active set tolerance
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 1.0:
            break
        
        if it % 100 == 0 and verbose:
            print(f"    AS it={it} ({time.monotonic()-t0:.0f}s): best={best_score:.8f}")
        
        # Current objective
        M = float(conv.max())
        cur_score = 2.0 * n * M
        
        if cur_score < best_score - 1e-14:
            best_score = cur_score
            best_a = a.copy()
            stagnation = 0
        else:
            stagnation += 1
        
        if stagnation > 50:
            # Perturb and reset
            noise = np.random.standard_normal(n) * 0.01 / np.sqrt(n)
            a = normalize(a + noise)
            conv = fast_convolve(a)
            stagnation = 0
            continue
        
        # Identify active set
        threshold = M - eps
        K = np.where(conv >= threshold)[0]
        if len(K) > 30:
            # Keep only the top 30
            K = np.argpartition(conv, -30)[-30:]
        
        # Solve active-set LP
        d, t_lp = active_set_lp(a, K, solver)
        if d is None:
            # Fallback: use full LP best response
            d, t_lp = full_lp_best_response_dir(a, solver)
            if d is None:
                break
        
        # Check if direction is meaningful
        d_norm = np.linalg.norm(d)
        if d_norm < 1e-12:
            # At a fixed point (for the linearized problem)
            # Try a random perturbation
            noise = np.random.standard_normal(n) * 0.005 / np.sqrt(n)
            a = normalize(a + noise)
            conv = fast_convolve(a)
            continue
        
        # Line search
        alpha, new_obj = line_search_conv(a, d)
        
        # Check if the step actually improves the true objective
        a_new = a + alpha * d
        a_new = normalize(a_new)
        new_conv = fast_convolve(a_new)
        new_score = 2.0 * n * float(new_conv.max())
        
        if new_score < best_score * (1.0 + 1e-10):
            a = a_new
            conv = new_conv
        
        # Every 20 iterations, do a "refresh" with full LP
        if it % 20 == 0:
            d_full, _ = full_lp_best_response_dir(a, solver)
            if d_full is not None:
                alpha_f, _ = line_search_conv(a, d_full)
                a_f = normalize(a + alpha_f * d_full)
                conv_f = fast_convolve(a_f)
                score_f = 2.0 * n * float(conv_f.max())
                if score_f < best_score:
                    a = a_f
                    conv = conv_f
                    best_score = score_f
                    best_a = a.copy()
    
    return best_a, best_score

def full_lp_best_response_dir(a, solver):
    """
    Solve full LP: min M s.t. conv(a, b) <= M, sum(b)=1, b>=0.
    Return (b - a, M) as the direction.
    """
    n = len(a)
    # Build full convolution matrix
    T = np.zeros((2 * n - 1, n))
    for j in range(n):
        T[j:j + n, j] = a
    
    b_var = cp.Variable(n, nonneg=True)
    M_var = cp.Variable()
    ones = np.ones(2 * n - 1)
    constraints = [
        T @ b_var <= M_var * ones,
        cp.sum(b_var) == 1
    ]
    prob = cp.Problem(cp.Minimize(M_var), constraints)
    try:
        prob.solve(solver=solver)
    except Exception:
        try:
            prob.solve(solver=cp.ECOS)
        except Exception:
            return None, float('inf')
    
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None, float('inf')
    
    b_val = np.asarray(b_var.value, dtype=np.float64)
    b_val = np.maximum(b_val, 0.0)
    s = b_val.sum()
    if s < 1e-15:
        return None, float('inf')
    b_val = b_val / s
    M_val = float(M_var.value) if M_var.value is not None else float('inf')
    return b_val - a, M_val

def smoothed_mirror_descent(a0, time_limit, T_init=5.0, T_max=500.0, verbose=True):
    """
    Mirror descent on the simplex with log-sum-exp smoothing.
    """
    n = len(a0)
    a = normalize(a0.astype(np.float64).copy())
    best_a = a.copy()
    best_score = float(2.0 * n * fast_convolve(a).max())
    t0 = time.monotonic()
    it = 0
    T_cur = T_init
    eta = 1.0  # step size (log-scale)
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit:
            break
        
        if it % 100 == 0 and verbose:
            elapsed = time.monotonic() - t0
            cur_sc = 2.0 * n * fast_convolve(a).max()
            print(f"    MD it={it} ({elapsed:.0f}s): best={best_score:.8f} T={T_cur:.1f}")
        
        # Compute smoothed gradient
        conv = fast_convolve(a)
        M = conv.max()
        
        # Softmax weights over peaks
        T_eff = max(T_cur, 1.0)
        # Use only top peaks for efficiency
        K = min(50, 2 * n - 1)
        if K < 2 * n - 1:
            peaks = np.argpartition(conv, -K)[-K:]
            pv = conv[peaks]
        else:
            peaks = np.arange(2 * n - 1)
            pv = conv.copy()
        
        w_peaks = np.exp(T_eff * (pv - pv.max()))
        w_peaks = w_peaks / w_peaks.sum()
        
        # Gradient: g[i] = sum_k w_k * 2*a[k-i]
        g = np.zeros(n)
        for idx in range(len(peaks)):
            if w_peaks[idx] < 1e-14:
                continue
            k = int(peaks[idx])
            i_start = max(0, k - n + 1)
            i_end = min(n - 1, k)
            g[i_start:i_end + 1] += w_peaks[idx] * 2.0 * a[k - i_end:k - i_start + 1][::-1]
        
        # Mirror descent update (multiplicative)
        # a_new[i] ∝ a[i] * exp(-eta * g[i])
        log_a = np.log(a + 1e-30)
        log_a_new = log_a - eta * g
        a_new = np.exp(log_a_new - log_a_new.max())
        a_new = a_new / a_new.sum()
        
        # Check improvement
        sc = 2.0 * n * float(fast_convolve(a_new).max())
        if sc < best_score:
            best_score = sc
            best_a = a_new.copy()
            a = a_new
            # Increase temperature
            T_cur = min(T_cur * 1.5, T_max)
        else:
            # Step was bad, reduce eta
            eta *= 0.8
            if eta < 1e-6:
                # Reset with perturbation
                noise = np.random.standard_normal(n) * 0.01 / np.sqrt(n)
                a = normalize(a + noise)
                eta = 1.0 / np.sqrt(n)
    
    return best_a, best_score

def targeted_coord_descent(a0, time_limit, verbose=True):
    """
    Coordinate descent with smart candidate generation.
    For each coordinate, generates candidates based on the current peaks.
    """
    n = len(a0)
    a = normalize(a0.astype(np.float64).copy())
    conv = fast_convolve(a)
    M = float(conv.max())
    best_a = a.copy()
    best_score = 2.0 * n * M
    t0 = time.monotonic()
    sweeps = 0
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        sweeps += 1
        improved = False
        
        if sweeps % 20 == 0 and verbose:
            elapsed = time.monotonic() - t0
            print(f"    tCD sweep={sweeps} ({elapsed:.0f}s): best={best_score:.8f}")
        
        for i in range(n):
            if a[i] < 1e-14:
                continue
            
            k_start = i
            k_end = min(i + n - 1, 2 * n - 2)
            affected_len = k_end - k_start + 1
            
            # Unaffected max
            unaff_max = -1e30
            if k_start > 0:
                unaff_max = max(unaff_max, float(conv[:k_start].max()))
            if k_end < 2 * n - 2:
                unaff_max = max(unaff_max, float(conv[k_end + 1:].max()))
            
            a_shifted = a[k_start - i:k_end - i + 1]
            conv_aff = conv[k_start:k_end + 1]
            
            # Generate candidates
            candidates = [0.0]  # no change
            
            # Based on current a[i]
            candidates.append(-a[i] * 0.5)
            candidates.append(-a[i] * 0.2)
            candidates.append(a[i] * 0.2)
            candidates.append(a[i] * 0.5)
            
            # Based on peaks: find delta that would bring a peak to M
            # b[k] + 2*delta*a[k-i] = M => delta = (M - b[k]) / (2*a[k-i])
            for k_offset in range(affected_len):
                k = k_start + k_offset
                ak_i = a_shifted[k_offset]
                if ak_i < 1e-14:
                    continue
                if conv_aff[k_offset] > M * 0.8:  # near peak
                    delta = (M - conv_aff[k_offset]) / (2.0 * ak_i)
                    if -a[i] * 2 < delta < a[i] * 2:  # reasonable range
                        candidates.append(delta)
            
            # Also try to set a[i] to match neighbors
            if i > 0:
                candidates.append(a[i-1] - a[i])
            if i < n - 1:
                candidates.append(a[i+1] - a[i])
            
            best_delta = 0.0
            best_new_M = M
            
            for delta in candidates:
                new_val = a[i] + delta
                if new_val < -1e-14:
                    continue
                
                new_aff = conv_aff + 2.0 *
