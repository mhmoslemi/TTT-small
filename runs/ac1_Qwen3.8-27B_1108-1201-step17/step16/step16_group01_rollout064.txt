The weighted subgradient approach: For a normalized a (sum=1), let ac = fast_autocorr(a). The objective (with sum=1) is J = 2n*max(ac). To minimize max(ac), a natural subgradient direction is derived from the lags that are large.

g[i] = sum_k w_k * d(ac[k])/da[i] where w_k are weights (e.g., based on ac[k] being near max).

d(ac[k])/da[i]: ac[k] = sum_{j} a[j]*a[k-j] (valid). For fixed i:
- contribution as a[i] (the "first" factor): a[k-i] if valid
- contribution as a[k-i] (the "second" factor, when the index in the sum equals k-i): a[i] if (k-i) valid and maps back
Actually ac[k] = sum_{j: j in [0,n), k-j in [0,n)} a[j]*a[k-j]. d/da[i]:
- term where j=i: a[k-i] if valid
- term where k-j=i i.e. j=k-i: a[k-i]=a[i]... wait the product is a[j]*a[k-j]. When j = k-i, product = a[k-i]*a[i]. d/da[i] of that = a[k-i].
So both terms give: d/da[i] ac[k] = a[k-i] (if j=i valid) + a[k-i]... no.

Let me carefully use matrix form. ac[k] = a^T B_k a where (B_k) is the matrix. Actually ac[k] = sum_j a[j] a[k-j]. This equals a^T P_k a where (P_k)_{j, k-j} = 1 (and symmetric version). Since each product a[j]a[k-j] with j != k-j appears... in the double representation.

Simpler: ac[k] = sum_j a[j] * a[k-j]. Think of it as sum over pairs. Let me define for each i, the partial derivative:
d/da[i] sum_j a[j] a[k-j].
The sum has terms T_j = a[j]*a[k-j] for j in range j0..j1.
d/da[i] T_j:
- if j == i: derivative = a[k-i]
- if k-j == i i.e. j = k-i: derivative = a[i]  (since T_{k-i} = a[k-i]*a[i], d/da[i] = a[k-i])
So contribution to d/da[i] from index j: 
   a[k-i]  (from T_i, when i in [j0,j1])
   a[k-i]  (from T_{k-i}, when k-i in [j0,j1])
Both equal a[k-i]! Wait the second one: T_{k-i} = a[k-i]*a[i]. d/da[i] = a[k-i]. Yes same value.
So d/da[i] ac[k] = a[k-i] * (number of times i appears, counting j=i and j=k-i).
- If i in [j0,j1] and (k-i) in [j0,j1] and i != k-i: contributes 2*a[k-i]
- If i in [j0,j1] and i == k-i (k=2i): T_i = a[i]^2, d/da[i] = 2*[a[i]] = 2*a[i]. But also does j=k-i double count? j=k-i=i same term. So just 2*a[i].
- If i in [j0,j1] but k-i out of [j0,j1] (or vice versa, impossible by symmetry of valid range?): Actually [j0,j1] for the sum is [max(0,k-n+1), min(k,n-1)]. k-i in this range is equivalent to i in [k-(min(k,n-1)), k-max(0,k-n+1)] = [max(0, k-n+1), min(k,n-1)] same range! So j=i valid iff j=k-i valid. So they always come in pairs (or the same).
Thus: d/da[i] ac[k] = 0 if i not in valid range; else 2*a[k-i] (when i != k-i) or 2*a[i] (when k=2i, same thing since a[k-i]=a[i]).
