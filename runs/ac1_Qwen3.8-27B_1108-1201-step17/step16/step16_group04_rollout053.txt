- Let P_k = exp(Beta * C_k) / sum(exp(Beta * C_j))
- Then grad[i] = sum_k P_k * (a[k-i] + a[i-k]) (with range checks)

The last step is a weighted sum of shifted versions of a, which can be done with a single convolution:
grad = conv(P_weighted, a) + conv(P_weighted_reversed, a)

where P_weighted has P_k at position k.

This is O(n log n) per gradient evaluation!

Then we can use:
- Nesterov-accelerated gradient descent
- L-BFGS
- Adam

Another idea: **_randomized coordinate descent with exact line search on pairs of coordinates._

For a pair (i,j), we can optimize the 2D problem:
minimize max_k conv(a',a')[k] subject to a'[i] + a'[j] = a[i] + a[j], a'[i], a'[j] >= 0

where a' differs from a only at positions i and j.

This is a 1D problem (one parameter: the amount to move from i to j). The objective is a piecewise quadratic function of this parameter, so we can find the exact minimizer.

    A = np.fft.rfft(np.asarray(a, dtype=np.float64), fft_size)

def solve_lp_dir(y, M, lags):
    """
    Solve LP: max sum(b) s.t. (y*b)[k] <= M for k in lags, b >= 0.
    Returns normalized direction or None.
    """
    try:
        import cvxpy as cp
    except ImportError:
        return None
    
    n = len(y)
    b_var = cp.Variable(n, nonneg=True)
    constraints = [cp.sum(b_var) >= 1e-10]  # Feasibility
    
    for k in lags:
        k_int = int(k)
        j_start = max(0, k_int - n + 1)
        j_end = min(n - 1, k_int)
        if j_start > j_end:
            continue
        j_idx = np.arange(j_start, j_end + 1)
        y_coeff = y[k_int - j_idx]
        constraints.append(cp.multiply(y_coeff, b_var[j_idx]).sum() <= M)
    
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)
    
    # Try multiple solvers
    for solver in [cp.CLARABEL, cp.ECOS, cp.SCS]:
        try:
            prob.solve(solver=solver, verbose=False)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                break
        except Exception:
            continue
    
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None
    
    b_val = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
    b_sum = b_val.sum()
    if b_sum < 1e-15:
        return None
    return b_val / b_sum
