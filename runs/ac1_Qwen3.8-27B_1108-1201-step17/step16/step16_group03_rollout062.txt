    """Compute smoothed objective: tau * log(sum(exp(c_k/tau))) over top-k peaks."""
    c = fast_conv(a)
    if top_k is not None and top_k < len(c):
        idx = np.argsort(c)[::-1][:top_k]
        vals = c[idx]
    else:
        vals = c
    vals = np.maximum(vals, 1e-30)
    log_sums = np.log(vals / tau)
    m = log_sums.max()
    return tau * (m + np.log(np.exp(log_sums - m).sum()))

    vals = np.maximum(vals, 1e-30)
    log_w = vals / tau
    m = log_w.max()
    w = np.exp(log_w - m)
    w = w / w.sum()
    
    grad = np.zeros(n)
    for wi, k in zip(w, idx):

        i_start = max(0, k_int - n + 1)

        for i in range(i_start, i_end):

Let me think more carefully about the smoothed mirror descent.

The objective is $F_\tau(a) = \tau \log \sum_k \exp(c_k / \tau)$ where $c = a * a$.

The gradient is $\nabla F_\tau(a)_i = 2 \sum_k p_k \cdot a_{k-i}$ where $p_k = \exp(c_k/\tau) / \sum_l \exp(c_l/\tau)$.

The mirror descent update (multiplicative) is:
$a_i^{new} = a_i \cdot \exp(-\eta \nabla_i F_\tau) / Z$

where $Z$ is a normalization constant.

With Nesterov momentum:
$y = x + \beta_t (x - x_{prev})$
$x_{new} = y \cdot \exp(-\eta \nabla F_\tau(y)) / Z$

The step size $\eta$ should be related to the Lipschitz constant of the gradient. For the log-sum-exp, the gradient is a convex combination of the individual peak gradients, each of which has $\ell_1$ norm $\leq 2 \sum a = 2$. So the gradient is "Lipschitz" in the $\ell_1$ sense with constant 2.

In the mirror descent framework, the step size is related to the "dual" Lipschitz constant. For the entropy mirror (multiplicative update), the step size should satisfy $\eta \leq 1/L$ where $L$ is the Lipschitz constant in the dual norm.

But in practice, we can just use a fixed step size or a decaying one and rely on the normalization to keep things stable.
