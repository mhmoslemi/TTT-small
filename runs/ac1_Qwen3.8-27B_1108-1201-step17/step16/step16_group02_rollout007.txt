The max of c is minimized when |A|^2 is as flat as possible (equi-ripple in the frequency domain). This is related to the construction of "flat-top" spectra or "low-autocorrelation" sequences.

For the LINEAR autocorrelation, we have:
b[k] = c[k] - (wrap-around terms) for the "interior" lags

For large n, if the sequence decays at the edges (a[0] and a[n-1] are small), the linear and circular autocorrelations are approximately equal in the interior.

So one approach:
1. Design a sequence with flat circular autocorrelation (using frequency domain methods)
2. Ensure the edges are small (to make linear ≈ circular)
3. Fine-tune in the time domain

For flat circular autocorrelation, we want |A[k]|^2 to be approximately constant. This means |A[k]| ≈ sqrt(n) for all k (since sum |A[k]|^2 = n * sum a[i]^2 by Parseval, and if a is normalized to sum=1, then sum a[i]^2 >= 1/n, so sum |A[k]|^2 >= n/n = 1, giving |A[k]|^2 >= 1/n on average).

Actually, if sum a[i] = 1, then A[0] = 1 (the DC component). So |A[0]|^2 = 1, which is much larger than 1/n for large n. This means the circular autocorrelation at lag 0 is c[0] = sum a[i]^2 >= 1/n, and the "excess" at DC means we can't make the spectrum perfectly flat.

The best we can do in the frequency domain is:
|A[0]|^2 = 1 (fixed by the sum constraint)
|A[k]|^2 = (n-1)/n * (1/n) for k=1,...,n-1 (flat elsewhere)

Wait, that doesn't work because sum |A[k]|^2 = n * sum a[i]^2 >= n/n = 1 (by Parseval + Cauchy-Schwarz).

So we need sum |A[k]|^2 >= 1, with |A[0]|^2 = 1. This means |A[k]|^2 = 0 for k=1,...,n-1 would give sum = 1, which corresponds to a uniform sequence. But then c[0] = 1/n (minimum possible) and c[k] = 0 for k != 0, which gives max c = 1/n.

But for the LINEAR autocorrelation, the uniform sequence gives a triangular shape with max 1/n at the center.

So the circular and linear approaches give different results. For the linear case, we need to think differently.

Let me go back to a more practical approach. I'll combine several ideas:

2. **Use a combination of techniques**:
   a. A new "spectral balancing" initialization to explore different regions

   c. A "peak reduction" coordinate descent that specifically targets the highest lags
   d. A final LP-based polish

The key improvement I want to make over the previous solution:

- **Multi-start**: Try several different initializations and keep the best.
- **Adaptive n**: Try different sequence lengths and see which gives the best score.

Actually, let me reconsider the problem from scratch. The score is:
score = 2 * n * max_b / S^2

where S = sum(a), max_b = max(conv(a,a)).

Key question: what's the best n to use?

For a given "shape" (normalized sequence with sum=1), the score is 2n * max_b. If we can make the shape have max_b = C/n (i.e., the autocorrelation decays like 1/n), then the score is 2C, independent of n.

The best achievable C depends on the shape. For uniform, C=1 (score=2). For the previous solution, C ≈ 0.752 (score ≈ 1.504).

So increasing n doesn't help if the shape is fixed. We need to find a better shape.

The average of b is 1/(2n-1) ≈ 1/(2n). So max_b = C/n means max_b/avg_b ≈ 2C. For C=0.752, this ratio is about 1.5.

With more elements, we can potentially make this ratio closer to 1 (perfectly flat), giving a lower score.

def fast_autocorr(a):
    """Compute linear autocorrelation (full convolution of a with itself) using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    ac = np.fft.irfft(A * A, fft_size)[:size]
    # Small numerical cleanup
    ac = np.maximum(ac, 0.0)
    return ac

def get_score(a):
    """Compute the score 2*n*max_b/S^2 for array a."""
    a = np.asarray(a, dtype=np.float64)
    a = np.maximum(a, 0.0)
    S = a.sum()
    if S < 1e-15:
        return float('inf')
    ac = fast_autocorr(a)
    return 2.0 * len(a) * ac.max() / (S * S)

def norm_sum1(a):

    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s

def interpolate_to_length(a, new_n):
    """Interpolate a sequence to a new length, preserving the shape."""
    old_n = len(a)
    if old_n == new_n:
        return a.copy()
    s = a.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    fn = a / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    fn_interp = np.interp(new_x, old_x, fn)
    fn_interp = np.maximum(fn_interp, 0.0)
    ss = fn_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return fn_interp / ss

def compute_sharpened_subgradient(a, ac, top_p=0.05, beta=3.0):
    """
    Compute a sharpened subgradient focusing on the top p fraction of lags.
    Uses a power-law weighting within the top set.
    """
    n = len(a)
    n_lags = len(ac)
    
    # Find threshold for top-p lags
    sorted_ac = np.sort(ac)[::-1]
    n_top = max(3, int(top_p * n_lags))
    n_top = min(n_top, n_lags)
    threshold = sorted_ac[n_top - 1]
    
    # Select top lags
    top_mask = ac >= threshold * 0.999
    top_idx = np.where(top_mask)[0]
    
    if len(top_idx) == 0:
        top_idx = np.array([np.argmax(ac)])
    
    # Power-law weighting within the top set
    top_vals = ac[top_idx]
    min_val = top_vals.min()
    range_val = top_vals.max() - min_val
    if range_val < 1e-15:
        w = np.ones(len(top_idx)) / len(top_idx)
    else:
        # Normalize to [0, 1] and apply power
        w = ((top_vals - min_val) / range_val) ** beta
        w_sum = w.sum()
        if w_sum < 1e-15:
            w = np.ones(len(top_idx)) / len(top_idx)
        else:
            w = w / w_sum
    
    # Compute subgradient
    grad = np.zeros(n)
    for wi, k in zip(w, top_idx):
        k_int = int(k)
        i_start = max(0, k_int - n + 1)
        i_end = min(n, k_int + 1)
        if i_start >= i_end:
            continue
        idx = np.arange(i_start, i_end)
        j_idx = k_int - idx
        grad[idx] += 2.0 * wi * a[j_idx]
    
    return grad

def peak_shave_step(a, ac, n_shave=3, frac=0.005):
    """
    Directly reduce the peak by moving mass from positions contributing most
    to the top lags to positions contributing least.
    """
    n = len(a)
    a = a.copy()
    
    # Find top n_shave lags
    top_lags = np.argsort(ac)[::-1][:n_shave]
    
    for k in top_lags:
        k_int = int(k)
        # Find contributing positions
        i_start = max(0, k_int - n + 1)
        i_end = min(n, k_int + 1)
        if i_start >= i_end:
            continue
        
        idx = np.arange(i_start, i_end)
        j_idx = k_int - idx
        
        # Positions with high a[idx] * a[j_idx] contribute most
        contrib = a[idx] * a[j_idx]
        
        # Move mass from high-contributing to low-contributing positions
        # (within the pair for this lag)
        max_contrib = contrib.max()
        min_contrib = contrib.min()
        
        if max_contrib < 1e-15:
            continue
        
        # Find the position with highest contribution
        max_pos = np.argmax(contrib)
        min_pos = np.argmin(contrib)
        
        src = idx[max_pos]
        dst = idx[min_pos]
        
        if src == dst:
            continue
        
        # Move a small fraction
        amt = a[src] * frac
        if amt < 1e-18:
            continue
        
        a[src] -= amt
        a[dst] += amt
        a = np.maximum(a, 0.0)
        s = a.sum()
        if s > 1e-15:
            a = a / s
    
    return a

def nesterov_sharpened(a0, time_limit, initial_beta=3.0, final_beta=8.0,
                        top_p_init=0.08, top_p_final=0.02, c0=3.0,
                        verbose=True):
    """
    Nesterov accelerated mirror descent with adaptive sharpened subgradient.
    The key innovation is the adaptive focus on top lags with increasing sharpness.
    """
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(777)
    
    x = a.copy()
    x_prev = a.copy()
    gamma = c0
    stall_count = 0
    max_stall = 2000
    
    for t in range(1, 5000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Adaptive parameters
        frac = min(1.0, t / 3000.0)
        beta = initial_beta + (final_beta - initial_beta) * frac
        top_p = top_p_init + (top_p_final - top_p_init) * frac
        
        # Nesterov extrapolation
        beta_t = (t - 1.0) / (t + 2.0)
        y = x + beta_t * (x - x_prev)
        y = np.maximum(y, 1e-15)
        sy = y.sum()
        if sy < 1e-15:
            y = x.copy()
        else:
            y = y / sy
        
        ac = fast_autocorr(y)
        
        # Compute sharpened subgradient
        g = compute_sharpened_subgradient(y, ac, top_p=top_p, beta=beta)
        
        # Mirror descent step
        eta = gamma / (np.sqrt(t) + 1.0)
        log_a = np.log(y) - eta * g
        max_log = log_a.max()
        a_new = np.exp(log_a - max_log)
        a_new = np.maximum(a_new, 1e-30)
        s_new = a_new.sum()
        if s_new < 1e-15:
            a_new = y.copy()
        else:
            a_new = a_new / s_new
        
        x_prev = x
        x = a_new
        
        # Check improvement
        M_new = fast_autocorr(x).max()
        if M_new < best_m - 1e-15:
            best_m = M_new
            best_a = x.copy()
            stall_count = 0
        else:
            stall_count += 1
        
        # Periodic restart with perturbation
        if stall_count > max_stall:
            stall_count = 0
            max_stall = max(500, max_stall // 2)
            pert = rng.normal(0, 0.003, n)
            x_r = best_a * (1 + pert)
            x_r = np.maximum(x_r, 1e-10)
            x_r = x_r / x_r.sum()
            x = x_r
            x_prev = x_r
            gamma = max(1.0, gamma * 0.7)
        
        # Periodic peak shaving
        if t % 100 == 0:
            ac_x = fast_autocorr(x)
            x_shaved = peak_shave_step(x, ac_x, n_shave=2, frac=0.003)
            m_shaved = fast_autocorr(x_shaved).max()
            if m_shaved < best_m:
                best_m = m_shaved
                best_a = x_shaved.copy()
                x = x_shaved.copy()
                x_prev = x_shaved.copy()
        
        if verbose and t % 2000 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print(f"    NSD t={t} ({elapsed:.1f}s): J={J:.6f}, beta={beta:.1f}, stall={stall_count}")
    
    return best_a, best_m

def coordinate_descent_improved(a0, time_limit, verbose=True, rng_seed=42):

        ac = fast_autocorr(a)

        top_lags = np.argsort(ac)[::-1][:5]

                j_idx = k_int - idx
                sensitivity[idx] += a[j_idx]
        
        # Sort by sensitivity (process high-sensitivity coords first)
        order = np.argsort(sensitivity)[::-1]

            if best_move is not None:

                a = np.maximum(a, 0.0)
                a = a / a.sum()
                best_m = best_delta_m

                # Recompute sensitivity periodically

def lp_polish(a0, time_limit, solver, verbose=True):
    """
    LP-based Frank-Wolfe polish: solve convex relaxation at each step.
    Maximize sum(b) subject to b >= 0, T_k @ b <= M for active lags k.
    """
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    
    y = a.copy()
    
    for t in range(1, 2000):
        if time.monotonic() - t0 > time_limit:
            break
        
        ac = fast_autocorr(y)
        M_curr = ac.max()
        
        # Select active lags (within 2% of max)
        threshold = M_curr * 0.98
        active_lags = np.where(ac >= threshold)[0]
        if len(active_lags) > 100:
            active_lags = np.argsort(ac)[::-1][:100]
        
        # Build constraint matrix
        b_var = cp.Variable(n, nonneg=True)
        T = np.zeros((len(active_lags), n))
        for row_idx, k in enumerate(active_lags):
            k_int = int(k)
            i_start = max(0, k_int - n + 1)
            i_end = min(n, k_int + 1)
            if i_start < i_end:
                cols = np.arange(i_start, i_end)
                T[row_idx, cols] = y[k_int - cols]
        
        constraints = [T @ b_var <= M_curr, cp.sum(b_var) == 1]
        prob = cp.Problem(cp.Maximize(cp.sum(y * b_var)), constraints)
        
        try:
            prob.solve(solver=solver, verbose=False)
        except Exception:
            continue
        
        if prob.status not in ('optimal', 'optimal_inaccurate'):
            continue
        
        b_val = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
        b_sum = b_val.sum()
        if b_sum < 1e-15:
            continue
        g_dir = b_val / b_sum
        
        # Frank-Wolfe step
        alpha = 2.0 / (t + 2.0)
        y_new = (1.0 - alpha) * y + alpha * g_dir
        y_new = np.maximum(y_new, 0.0)
        sy = y_new.sum()
        if sy < 1e-15:
            y_new = y.copy()
        else:
            y_new = y_new / sy
        
        y = y_new
        
        # Check
        m_new = fast_autocorr(y).max()
        if m_new < best_m:
            best_m = m_new
            best_a = y.copy()
        
        if verbose and t % 20 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print(f"    LP iter={t} ({elapsed:.1f}s): J={J:.6f}, active={len(active_lags)}")
    
    return best_a, best_m

def get_solver():
    for s in [cp.CLARABEL, cp.PDLP, cp.ECOS, cp.SCS]:
        try:
            x = cp.Variable(5, nonneg=True)
            prob = cp.Problem(cp.Minimize(cp.sum(x)), [cp.sum(x) == 1])
            prob.solve(solver=s)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                print(f"  Using solver: {s}")
                return s
        except Exception:
            continue
    print("  Fallback solver: ECOS")
    return cp.ECOS
