So grad = 2*(cross_corr_wa + cross_corr_aw) = 2*([0,3,2] + [0,0,0]) = [0,6,4]. ✓

Great, the formula works. Note that in general, `cross_corr_aw[m] = cross_corr_wa[-m]` (by symmetry of the autocorrelation structure), so `grad[m] = 2*(cross_corr_wa[m] + cross_corr_wa[-m])`. But since we only compute m >= 0, we just add both terms as computed.

Now, the key question: will using the full gradient (all lags weighted by softmax) be better than the previous "top-k" approximation? I believe yes, because:
1. The top-k approximation might miss important lags that are currently just below the peak but could become the peak after a small perturbation.
2. The full gradient gives a more accurate descent direction.

The computational cost is O(n log n) per gradient evaluation (one FFT-based autocorrelation + one FFT-based cross-correlation), which is very fast for n=2400.

Now, for the optimizer: I'll use L-BFGS-B from scipy. It handles box constraints (0 <= a[j] <= some upper bound) and is a quasi-Newton method that should converge faster than APG near the optimum.

The objective function for L-BFGS-B:
`J(a) = (1/beta) * log(sum_k exp(beta * ac[k]))` where `ac = autocorr(a)`

This is smooth and its gradient is as computed above. We also need to normalize: `sum(a) = 1` (or we can work on the simplex by parameterizing with `a = softmax(z)`).

Actually, for L-BFGS-B, it's easier to work with the constraint `sum(a) = 1` as an equality constraint, but L-BFGS-B only handles inequality constraints. So either:
1. Work in the simplex directly (project after each step) - but L-BFGS-B doesn't do projections
2. Use the parameterization `a = exp(z) / sum(exp(z))` (softmax) - this is smooth and automatically satisfies the constraint
3. Work with the constraint `sum(a) >= 1` and `a >= 0`, and normalize at the end

Option 2 is the cleanest. Let's use `a = softmax(z)` where `z` is the free variable. Then the objective becomes:
`J(z) = (1/beta) * log(sum_k exp(beta * autocorr(softmax(z))[k]))`

The gradient with respect to z: `∂J/∂z = (∂J/∂a) * (∂a/∂z) = (∂J/∂a) * diag(a) - a * (∂J/∂a)·a`
(where `∂a/∂z` is the Jacobian of softmax: `diag(a) - a*a^T`)

Actually, it's simpler: since `J` is a function of `a` only (not of the absolute scale), and `a = softmax(z)` is scale-invariant (shifting all z by a constant doesn't change a), we can just compute:
`∂J/∂z[i] = a[i] * sum_j (∂J/∂a[j]) * (δ_ij - a[j])`
`= a[i] * (∂J/∂a[i] - sum_j a[j] * ∂J/∂a[j])`

Or equivalently, if `g = ∂J/∂a`, then `∂J/∂z = a * (g - dot(a, g))`.

This is the standard "softmax gradient trick."

Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Parametric family search for diverse initializations
2. Nesterov-accelerated projected gradient with FULL FFT-based gradient
3. L-BFGS-B on softmax parameterization for local polish
4. Peak-aware coordinate descent for final refinement
5. Multi-length exploration

import numpy as np
from scipy.optimize import minimize
import time

# ============ Core Computation ============

def fast_autocorr(a):
    """Full linear autocorrelation via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a.astype(np.float64), fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def compute_full_gradient(a, beta):
    """
    Compute gradient of (1/beta)*log(sum exp(beta*ac[k])) w.r.t. a.
    Uses full FFT-based cross-correlation (no top-k approximation).
    Returns (gradient array of length n, autocorrelation array of length 2n-1).
    """
    n = len(a)
    ac = fast_autocorr(a)
    max_ac = ac.max()
    shifted = ac - max_ac
    exp_vals = np.exp(beta * shifted)
    w_sum = exp_vals.sum()
    if w_sum < 1e-300:
        w = np.zeros_like(ac)
        w[np.argmax(ac)] = 1.0
    else:
        w = exp_vals / w_sum
    
    # grad[m] = 2 * sum_k w[k] * (a[k-m] + a[m-k]) with bounds [0,n)
    # = 2 * (cross_corr_wa[m] + cross_corr_aw[m])
    # where cross_corr_wa[m] = sum_j w[j+m]*a[j]
    # and cross_corr_aw[m] = sum_j a[j+m]*w[j]
    
    fft_size = 1 << (3 * n - 1).bit_length()
    Fa = np.fft.rfft(a, fft_size)
    Fw = np.fft.rfft(w, fft_size)
    
    cross_corr_wa = np.fft.irfft(Fw * np.conj(Fa), fft_size)[:n]
    cross_corr_aw = np.fft.irfft(Fa * np.conj(Fw), fft_size)[:n]
    
    grad = 2.0 * (cross_corr_wa + cross_corr_aw)
    return grad, ac

def project_simplex(v):
    """Project vector onto {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def normalize_nonneg(a):
    """Clip to non-negative and normalize to sum=1."""
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s

# ============ Objective ============

def objective_value(a):
    """Compute the actual objective: 2*n*max_b/(sum_a)^2."""
    a = np.asarray(a, dtype=np.float64)
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-10:
        return float('inf')
    ac = fast_autocorr(a)
    return 2.0 * len(a) * ac.max() / (s * s)

def apg_full_gradient(a0, time_limit, beta_start=30.0, beta_end=5.0,
                      c0=2.0, verbose=True, seed=42, restart_patience=2000):
    """
    Nesterov-accelerated projected gradient with FULL FFT-based gradient.
    Optimizes on the simplex {a >= 0, sum(a) = 1}.
    """
    n = len(a0)
    a = normalize_nonneg(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)
    
    x = a.copy()
    x_prev = a.copy()
    stall = 0
    max_stall = restart_patience
    
    for t in range(1, 10000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Adaptive beta
        frac = min(1.0, t / 30000.0)
        cur_beta = beta_start + (beta_end - beta_start) * frac
        
        # Nesterov extrapolation
        beta_t = (t - 1.0) / (t + 1.5)
        y = x + beta_t * (x - x_prev)
        y = project_simplex(y)
        
        # Full gradient
        g, _ = compute_full_gradient(y, cur_beta)
        
        # Lipschitz estimate (use norm-based)
        eta = c0 / (np.linalg.norm(g) + 1e-15)
        # Cap step size
        eta = min(eta, 1.0 / np.sqrt(t + 1.0))
        
        # Projected gradient step
        x_new = project_simplex(y - eta * g)
        
        x_prev = x
        x = x_new
        
        # Evaluate
        M_new = fast_autocorr(x).max()
        if M_new < best_m - 1e-15:
            best_m = M_new
            best_a = x.copy()
            stall = 0
        else:
            stall += 1
        
        # Periodic restart
        if stall > max_stall:
            stall = 0
            max_stall = int(max_stall * 1.4)
            noise = rng.normal(0, 0.003, n) * best_a
            x_re = np.maximum(best_a + noise, 1e-12)
            x_re = x_re / x_re.sum()
            x = x_re
            x_prev = x_re
            if verbose:
                elapsed = time.monotonic() - t0
                J = 2.0 * n * best_m
                print(f"      APG restart t={t} ({elapsed:.0f}s): J={J:.6f}")
        
        if verbose and t % 5000 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print(f"      APG t={t} ({elapsed:.0f}s): J={J:.6f}, beta={cur_beta:.1f}")
    
    return best_a, best_m

def coordinate_polish(a0, time_limit, verbose=True, seed=123):
    """
    Peak-aware coordinate descent.
    Moves mass from high-peak-contribution coordinates to low-impact ones.

    a = normalize_nonneg(a0)
    best_a = a.copy()

    stall = 0
    max_stall = 50

        ac = fast_autocorr(a)
        M_curr = ac.max()
        
        # Find top peak lags
        top_k = min(30, len(ac))

        # Compute peak contribution for each coordinate
        peak_contrib = np.zeros(n)
        for k in peak_lags[:15]:
            k_int = int(k)
            i_start = max(0, k_int - n + 1)
            i_end = min(n, k_int + 1)
            if i_start >= i_end:
                continue
            idx = np.arange(i_start, i_end)
            j_idx = k_int - idx
            weights = ac[k_int] / (ac[peak_lags[:15]].sum() + 1e-30)
            peak_contrib[idx] += weights * (a[idx] * (1.0 + a[j_idx]))

        sources = np.argsort(peak_contrib)[::-1][:20]

                d2 = j - k_int
                impact = 0.0
                if 0 <= d1 < n:
                    impact += a[d1]
                if 0 <= d2 < n:
                    impact += a[d2]
                dest_score[j] += impact * (ac[k_int] / (ac[peak_lags[:10]].sum() + 1e-30))
        
        destinations = np.argsort(dest_score)[:30]
        
        improved = False
        for src in sources:
            if a[src] < 1e-10:
                continue
            for dst in destinations:
                if dst == src:
                    continue
                # Try moving small amount
                for frac in [0.01, 0.02, 0.05, 0.1]:
                    amt = a[src] * frac
                    if amt < 1e-15:
                        break
                    a_trial = a.copy()
                    a_trial[src] -= amt
                    a_trial[dst] += amt
                    a_trial = np.maximum(a_trial, 0.0)
                    s_t
