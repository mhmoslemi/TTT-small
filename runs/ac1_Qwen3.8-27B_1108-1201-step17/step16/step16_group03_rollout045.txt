But we also have the constraint that conv[0] = a[0]^2 and conv[2n-2] = a[n-1]^2. If a[0] = 0 (as in the ramp), then conv[0] = 0, which is fine.

The constraint is that a >= 0 and the convolution is determined by a. The question is: what's the minimum possible max of conv(a,a) given sum(a) = 1 and a >= 0?

This is a hard optimization problem. But I suspect the linear ramp is close to optimal.
