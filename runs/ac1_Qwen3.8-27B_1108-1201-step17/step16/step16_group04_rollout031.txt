Let me now think about potential issues and improvements:

**Issue 1: The softmax weights w can become very peaked (concentrating on 1-2 lags)**

- Solution: Keep β moderate, or use a "top-K" truncation of the softmax

**Issue 2: The multiplicative weights update can cause some entries to underflow**
- a_new[j] = a[j] * exp(-eta * grad[j]) / Z
- If grad[j] is large and positive, a_new[j] can underflow to 0
- Solution: Use log-space computation, or clip the gradient

**Issue 3: Nesterov extrapolation can push into infeasible region (negative values)**
- Solution: Clip to non-negative before normalization

**Issue 4: The objective has many local minima**
- Solution: Multiple restarts with different random perturbations

For the "ideal" case where (a*a)[k] = c for all k, we'd need:

So A(x) = sqrt(c) * sqrt((1-x^{2n-1})/(1-x))

This is not a polynomial in general (the square root of a polynomial is not a polynomial). So perfect flatness is impossible.

However, we can get close by choosing a that approximates this. The "best" a would be one where A(x)^2 is as close to flat as possible.

One approach: choose A(x) to be a polynomial whose square is approximately flat. This is related to the theory of "flat polynomials" or "Borwein-Erdelyi" type results.

For practical purposes, the spectral equalization approach (iteratively correcting the DFT) is a good heuristic. It's equivalent to trying to make |A(e^{iω})|^2 flat, which by Parseval's relation is related to making the autocorrelation flat, which is related to making the convolution flat.

Actually, I realize there's a key difference:
- |A(e^{iω})|^2 flat ⟹ periodic autocorrelation is flat ⟹ aperiodic autocorrelation is approximately flat (for large n with good windowing)
- (a*a) flat ⟹ a different condition

The relationship between the full convolution and the power spectrum is:
(a*a)[k] = (1/2π) ∫ A(e^{iω})^2 e^{-ikω} dω (for the appropriate range)

Wait, that's for the periodic (circular) case. For the linear case, it's more complex.

Actually, for the linear convolution:
(a*a)[k] = coefficient of x^k in A(x)^2

And the power spectrum is |A(e^{iω})|^2 = A(e^{iω}) * conj(A(e^{iω}))

These are different! The convolution uses A(x)^2 (not A(x) * conj(A(x))), so it's related to the "auto-power spectrum" in a different sense.

For real a, A(x)^2 at x = e^{iω} gives A(e^{iω})^2, which is different from |A(e^{iω})|^2 = A(e^{iω}) * A(e^{-iω}).

So spectral equalization (flattening |A(e^{iω})|^2) is NOT the same as flattening A(x)^2. They're related but different objectives.

This means the spectral equalization initialization might not be optimal. A better initialization might directly target the flatness of A(x)^2.

How to directly target A(x)^2? We can do:
- Compute A(x)^2 (the polynomial square)
- Find the coefficients (which are just the convolution values)
- Iteratively adjust a to make these coefficients more uniform

This is essentially what the main optimization does, but as an initialization step, we could do a few iterations of:
1. Compute c = a * a (the convolution)
2. Target: c_target = mean(c) * ones (or some other target)
3. Update: a_new = a * (some correction based on c vs c_target)

But this is basically the same as the main optimization with a specific step size. So let's not overthink the initialization and just use spectral equalization + a few iterations of the main method.

**Another idea: Use the structure of the problem to find a good "shape" for a.**

From the analysis, we want A(x)^2 to be flat. One way to think about this is:
- A(x) should have roots that are "spread out" on the unit circle (in a sense)
- But A(x) has real non-negative coefficients, so its roots come in conjugate pairs and are constrained

For a sequence with non-negative coefficients, A(x) > 0 for x > 0. The roots of A(x) are in the complex plane, and A(x)^2 will have double roots at the same locations.

The "flattest" A(x)^2 would have its roots arranged to minimize the peak of the polynomial. This is related to the theory of "Leja points" or "Fekete points."

But this is getting too theoretical. Let me focus on the practical algorithm.

**My final algorithm plan:**

1. **Fast gradient computation** using the FFT-based method I derived above.

2. **Smoothed mirror descent with Nesterov acceleration**:
   - f_β(a) = (1/β) log(Σ_k exp(β * c[k])) where c = a*a
   - Gradient: ∇f_β = (1/β) * Σ_k w_k * grad_k where w = softmax(β*c)
   - Update: a_new = a * exp(-η * ∇f_β(y)) where y is the Nesterov extrapolation
   - Normalize a_new to sum to 1

3. **Adaptive temperature**: Start with β=3, increase to β=20 over the course of optimization.

4. **Adaptive step size**: Use backtracking or a fixed schedule η_t = c/sqrt(t).

5. **Periodic restarts**: If no improvement for X iterations, perturb the current best.

6. **Coordinate descent polish**: At the end, do targeted coordinate moves on the exact objective.

7. **Length exploration**: Try a few different sequence lengths.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. FFT-based fast gradient computation for the smoothed max-of-convolution objective
2. Nesterov-accelerated mirror descent (multiplicative weights) with adaptive temperature
3. Spectral equalization initialization
4. Coordinate descent polish on the exact objective
5. Multi-length exploration
"""

import numpy as np
import time

def fast_conv(a):
    """Compute full linear convolution a*a via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a.astype(np.float64), fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def fast_gradient(a, w):
    """
    Compute gradient of smoothed max of convolution.
    a: length n
    w: length 2n-1 (softmax weights)
    Returns: gradient of length n
    """
    n = len(a)
    conv_len = 3 * n - 2
    fft_size = 1 << (conv_len - 1).bit_length()
    
    A = np.fft.rfft(a, fft_size)
    W = np.fft.rfft(w, fft_size)
    W_rev = np.fft.rfft(w[::-1], fft_size)
    
    conv_aw = np.fft.irfft(A * W, fft_size)
    conv_aw_rev = np.fft.irfft(A * W_rev, fft_size)
    
    # conv[j] = (a*w)[j] for j=0,...,n-1
    conv_part = conv_aw[:n]
    # corr[j] = (a*flip(w))[2n-2-j] for j=0,...,n-1
    corr_part = conv_aw_rev[n-1:2*n-1][::-1].copy()
    
    return conv_part + corr_part

def normalize(a):
    """Normalize to sum=1, non-negative."""
    a = np.maximum(a.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s

def spectral_equalize(a, n_iter=30, eps=1e-8):
    """Flatten power spectrum via iterative DFT correction."""
    a = normalize(a).copy()
    n = len(a)
    for _ in range(n_iter):
        A = np.fft.fft(a)
        P = A.real**2 + A.imag**2
        C = 1.0 / np.sqrt(P + eps)
        A_new = A * C
        a_new = np.real(np.fft.ifft(A_new))
        a_new = np.maximum(a_new, 0.0)
        s = a_new.sum()
        if s < 1e-15:
            break
        a_new = a_new / s
        a = 0.5 * a + 0.5 * a_new
    return normalize(a)

def smoothed_mirror_descent(a0, time_limit, beta_start=3.0, beta_end=30.0, 
                             c0=2.0, restart_every=5000, verbose=True):
    """
    Nesterov-accelerated mirror descent on smoothed max of convolution.
    """
    n = len(a0)
    a = normalize(a0)
    best_a = a.copy()
    best_c = fast_conv(a)
    best_peak = best_c.max()
    t0 = time.monotonic()
    rng = np.random.default_rng(123)
    
    x = a.copy()
    x_prev = a.copy()
    stall = 0
    n_total = 2 * n - 1
    
    for t in range(1, 10000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Adaptive temperature
        frac = min(1.0, t / 50000.0)
        beta = beta_start + (beta_end - beta_start) * frac
        
        # Nesterov extrapolation
        if t > 1:
            mu = (t - 1.0) / (t + 1.5)
            y = x + mu * (x - x_prev)
        else:
            y = x.copy()
        y = np.maximum(y, 1e-15)
        sy = y.sum()
        if sy < 1e-15:
            y = x.copy()
        else:
            y = y / sy
        
        # Compute convolution and gradient
        c = fast_conv(y)
        peak = c.max()
        
        # Check improvement
        if peak < best_peak:
            best_peak = peak
            best_a = y.copy()
            best_c = c.copy()
            stall = 0
        else:
            stall += 1
        
        # Softmax weights
        beta_c = beta * c
        beta_c -= beta_c.max()  # numerical stability
        w = np.exp(beta_c)
        w /= w.sum()
        
        # Gradient
        grad = fast_gradient(y, w)
        
        # Step size
        eta = c0 / (np.sqrt(t) + 1.0)
        
        # Mirror descent update (multiplicative weights)
        # a_new = y * exp(-eta * grad) / Z
        log_ratio = -eta * grad
        log_ratio -= log_ratio.max()  # stability
        ratio = np.exp(log_ratio)
        a_new = y * ratio
        a_new = np.maximum(a_new, 1e-30)
        s_new = a_new.sum()
        if s_new < 1e-15:
            a_new = y.copy()
        else:
            a_new = a_new / s_new
        
        x_prev = y
        x = a_new
        
        # Periodic restart
        if stall > restart_every:
            stall = 0
            # Perturb from best
            noise = rng.normal(0, 0.01, n)
            x_new = best_a * (1.0 + noise)
            x_new = np.maximum(x_new, 1e-10)
            x_new = x_new / x_new.sum()
            x = x_new
            x_prev = x_new
        
        if verbose and t % 1000 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_peak
            print(f"    SMD t={t} ({elapsed:.1f}s): J={J:.6f}, beta={beta:.1f}, peak={best_peak:.8f}")
    
    return best_a, best_peak

def coordinate_polish(a0, time_limit, verbose=True, rng_seed=42):
    """Coordinate descent on the exact (unsmoothed) objective."""
    n = len(a0)
    a = normalize(a0)
    best_a = a.copy()
    c = fast_conv(a)
    best_peak = c.max()
    t0 = time.monotonic()
    rng = np.random.default_rng(rng_seed)
    
    stall = 0
    max_stall = 200
    
    while time.monotonic() - t0 < time_limit and stall < max_stall:
        c = fast_conv(a)
        peak = c.max()
        peak_idx = np.argmax(c)
        
        improved = False
        
        # Target the peak: find which pairs contribute most to c[peak_idx]
        k = peak_idx
        # c[k] = sum_i a[i]*a[k-i]
        # Find the pair (i, k-i) with largest product
        i_start = max(0, k - n + 1)
        i_end = min(n - 1, k)
        if i_start <= i_end:
            idx = np.arange(i_start, i_end + 1)
            pairs = a[idx] * a[k - idx]
            max_pair = np.argmax(pairs)
            src = idx[max_pair]
            dst_orig = k - src
            
            # Try moving mass from src to a random other location
            for trial in range(50):
                dst = int(rng.integers(n))
                if dst == src:
                    continue
                for frac in [0.001, 0.005, 0.01, 0.05, 0.1]:
                    amt = a[src] * frac
                    if amt < 1e-15:
                        continue
                    a_trial = a.copy()
                    a_trial[src] -= amt
                    a_trial[dst] += amt
                    a_trial = np.maximum(a_trial, 0.0)
                    s_t = a_trial.sum()
                    if s_t < 1e-15:
                        continue
                    a_trial = a_trial / s_t
                    c_trial = fast_conv(a_trial)
                    if c_trial.max() < best_peak - 1e-15:
                        a = a_trial
                        best_peak = c_trial.max()
                        best_a = a.copy()
                        improved = True
                        stall = 0
                        break
                if improved:
                    break
        
        if not improved:
            stall += 1
            # Random perturbation
            i = int(rng.integers(n))
            j = int(rng.integers(n))
            if i != j and a[i] > 1e-10:
                frac = rng.uniform(0.001, 0.02)
                amt = a[i] * frac
                a[i] -= amt
                a[j] += amt
                a = np.maximum(a, 0.0)
                s_t = a.sum()
                if s_t > 1e-15:
                    a = a / s_t
                    c_trial = fast_conv(a)
                    if c_trial.max() < best_peak:
                        best_peak = c_trial.max()
                        best_a = a.copy()
                        stall = 0
                    else:
                        a[i] += amt
                        a[j] -= amt
                        a = np.maximum(a, 0.0)
                        a = a / max(a.sum(), 1e-15)
    
    if verbose:
        elapsed = time.monotonic() - t0
        J = 2.0 * n * best_peak
        print(f"    Coord ({elapsed:.1f}s): J={J:.6f}")
    
    return best_a, best_peak
