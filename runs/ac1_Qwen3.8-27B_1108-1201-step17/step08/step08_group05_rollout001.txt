**Idea: "Frequency domain" optimization**
The condition that (a*a)[k] is small for all k is equivalent to saying that the polynomial P(x) = sum a[j] x^j has P(x)*P(x) with small coefficients.

In the frequency domain, P(e^{iθ}) * P(e^{iθ}) = |P(e^{iθ})|^2 if P has real coefficients... wait, no. P(e^{iθ}) * P(e^{iθ}) is not |P(e^{iθ})|^2. We have |P(e^{iθ})|^2 = P(e^{iθ}) * conjugate(P(e^{iθ})) = P(e^{iθ}) * P(e^{-iθ}).

But P(x)^2 = P(x) * P(x), which is different from P(x) * P(1/x).

The coefficients of P(x)^2 are (a*a)[k] = sum_j a[j] * a[k-j].
The coefficients of P(x) * P(1/x) are the autocorrelation: sum_j a[j] * a[j+k].

So we're minimizing the peak of P(x)^2, not |P(e^{iθ})|^2.

This means the frequency domain approach is:
- P(x)^2 = sum_k (a*a)[k] x^k
- We want all coefficients of P(x)^2 to be small
- This is equivalent to P(x)^2 being "flat" (close to a constant)
- But P(x)^2 is a polynomial of degree 2(n-1), and its "flatness" is measured by its coefficients

This is a different problem from making |P(e^{iθ})|^2 flat. The former is about the polynomial P(x)^2 having small coefficients, while the latter is about the magnitude of P on the unit circle being constant.

For P(x)^2 to have all coefficients equal to c, we'd need P(x)^2 = c * (1 + x + ... + x^{2n-2}) / (number of terms)... this doesn't work in general.

The best we can do is make P(x)^2 as "flat" as possible, which means the coefficients should all be close to (sum of coefficients of P(x)^2) / (2n-1) = 1/(2n-1).

This is a polynomial approximation problem: find P(x) = sum a[j] x^j with a[j] >= 0, sum a[j] = 1, such that P(x)^2 is as close as possible to the constant 1/(2n-1) (in the sense of minimizing the maximum deviation of its coefficients from 1/(2n-1)).

This is still a hard non-convex problem, but it gives us a good intuition: we want P(x) to be "asymmetric" in a way that P(x)^2 has flat coefficients.

            else:
                lo = m1
            if hi - lo < 1e-6:
                break
        best_t = (lo + hi) / 2.0
        trial = (1-best_t)*f + best_t*direction
        trial = np.maximum(trial, 0)
        s = trial.sum()
        if s > 1e-10:
            trial = trial/s
            best_s = 2.0*n*fast_convolve(trial).max()
    
    return best_t, best_s

def subgradient_polish(f, time_limit, n_top=50, lr_init=0.002):
    t0 = time.monotonic()
    n = len(f)
    f = f.copy()
    best_f = f.copy()
    best_score = 2.0 * n * fast_convolve(f).max()
    v = np.zeros(n)
    lr = lr_init
    stuck = 0
    rng = np.random.default_rng(12345)
    
    while time.monotonic() - t0 < time_limit:
        batch = 200
        step = 0
        for _ in range(batch):
            if time.monotonic() - t0 > time_limit:
                break
            step += 1
            b = fast_convolve(f)
            
            # Top-k weighted subgradient
            if n_top < len(b):
                top_idx = np.argpartition(b, -n_top)[-n_top:]
            else:
                top_idx = np.arange(len(b))
            
            # Weighted: give more weight to higher peaks
            bv = b[top_idx]
            w = bv / bv.sum()
            
            g = np.zeros(n)
            for idx_i, k in enumerate(top_idx):
                if w[idx_i] < 1e-12:
                    continue
                lo = max(0, k - n + 1)
                hi = min(n - 1, k)
                j = np.arange(lo, hi + 1)
                g[j] += w[idx_i] * f[k - j]
            
            v = 0.9 * v - lr * g
            f_new = project_simplex(f + v)
            
            # Check for improvement
            sc = 2.0 * n * fast_convolve(f_new).max()
            if sc < best_score - 1e-14:
                best_score = sc
                best_f = f_new.copy()
                stuck = 0
            f = f_new
        
        # Adaptive learning rate
        if stuck > 0:
            lr *= 0.9
            if lr < 1e-6:
                # Restart
                f = project_simplex(best_f + rng.standard_normal(n) * 0.001)
                v = np.zeros(n)
                lr = lr_init * 0.5
                stuck = 0
        else:
            lr = min(lr * 1.02, 0.005)
        
        if step % 500 == 0:
            stuck = 1 if best_score >= 2.0 * n * fast_convolve(f).max() - 1e-14 else 0
            if stuck > 10:
                break
    
    return best_f, best_score / (2.0 * n)  # Return max_b, not score

def coordinate_descent_polish(f, time_limit, n_sweeps=50):
    """Coordinate descent: optimize one coordinate at a time."""
    t0 = time.monotonic()
    n = len(f)
    f = f.copy()
    best_f = f.copy()
    best_score = 2.0 * n * fast_convolve(f).max()
    
    for sweep in range(n_sweeps):
        if time.monotonic() - t0 > time_limit:
            break
        improved = False
        for j in range(n):
            if time.monotonic() - t0 > time_limit:
                break
            # Try different values for f[j]
            current_val = f[j]
            if current_val < 1e-12:
                continue
            
            # Bisection to find optimal f[j]
            # The peak as a function of f[j] is the max of:
            # - Linear terms: c_k + f[j] * f[k-j] (for k != 2j, k-j in [0,n-1])
            # - Quadratic term: f[j]^2 + c_2j (for k = 2j)
            
            # Compute the "base" convolution (without position j)
            f_no_j = f.copy()
            f_no_j[j] = 0.0
            b_base = fast_convolve(f_no_j)
            
            # For a given value x = f[j], the convolution is:
            # b[k] = b_base[k] + x * f[k-j] (for k-j in [0,n-1] and k-j != j)
            #        + x * f[j-j] + x * f[k-j] ... 
            # Actually, let me just compute it directly for a few candidates
            
            best_x = current_val
            best_peak = fast_convolve(f).max()
            
            # Try a few candidates
            candidates = [current_val, current_val * 0.5, current_val * 1.5,
                         current_val * 0.1, current_val * 0.8, current_val * 1.2]
            for x in candidates:
                f[j] = x
                # Renormalize
                s = f.sum()
                if s < 1e-10:
                    f[j] = current_val
                    continue
                f = f / s
                peak = fast_convolve(f).max()
                if peak < best_peak:
                    best_peak = peak
                    best_x = x
            
            if best_x != current_val:
                f[j] = best_x
                f = f / f.sum()
                improved = True
            
            sc = 2.0 * n * fast_convolve(f).max()
            if sc < best_score:
                best_score = sc
                best_f = f.copy()
        
        if not improved:
            break
    
    return best_f, best_score / (2.0 * n)
