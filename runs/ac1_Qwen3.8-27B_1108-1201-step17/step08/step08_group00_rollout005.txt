**Projective Subgradient Method with Adaptive Step Size:**

1. Maintain a in the probability simplex
2. Compute c = conv(a,a), find active set A
3. Compute subgradient g (w.r.t. a)
4. Project g onto the face of the simplex defined by the active variables
5. Take a step: a_new = a - eta * g_projected
6. Project back to simplex
7. Adaptive step size: eta = alpha / sqrt(t)

This is essentially what mirror descent does, but with Euclidean projection instead of Bregman projection. The Bregman (entropy) projection might be better for this problem because we want to keep all values positive.

Actually, I think the best approach is a combination:
1. Use the LP alternating method (which is very effective) but with improvements:
   - Warm start the LP
   - Use a more aggressive learning rate
   - Add regularization to the LP to prevent degeneracy
2. Then polish with L-BFGS

Let me look at the previous code more carefully to see where improvements can be made.

The previous code's `nesterov_lp_refine` function:
- Solves LP: min M s.t. T(a) @ b <= M, sum(b) = 1, b >= 0
- Uses Nesterov acceleration: y = (1-alpha)*y + alpha*b, a = running average
- alpha = 2/(it+2)

Potential issues:
1. The LP might not be solved precisely (especially for large n)
2. Nesterov with alpha = 2/(it+2) might be too aggressive or too slow
3. The "stall detection" with noise injection might destroy progress

Improvements:
1. Use a line search on the mixing parameter t in f_new = (1-t)*f + t*g
2. Solve the LP more carefully (use CGAL or verify the solution)
3. Use a better acceleration scheme (e.g., FISTA with restart)
4. Add a "shrinkage" step: after each LP solve, check if the solution is "close enough" to the current iterate

Let me also think about a completely different approach:

**Direct Optimization via Semidefinite Programming (SDP):**

The problem min max_k a^T Q_k a s.t. a >= 0, sum(a) = 1 can be relaxed to:
min t s.t. a^T Q_k a <= t for all k, a >= 0, sum(a) = 1

This is a sequence of QCPs (quatically constrained programs). Not directly an SDP, but we could use a barrier method.

Alternatively, we can use the following trick:
Let x = a ⊗ a (the Kronecker product / outer product, as a vector). Then a^T Q_k a = <Q_k, x> (Frobenius inner product). The constraint is that x is the outer product of a, which is a rank-1 PSD constraint.

This gives an SDP relaxation, but it's very large (n^2 variables) and probably not practical for n=960.

Let me stick with the practical approach. Here's my final plan:

1. **Multi-start with diverse initializations** (10% time): Try 5-10 different symmetric initializations, run 50 LP iterations on each, keep the best.

2. **Main LP alternating with improvements** (45% time):
   - Warm start from Phase 1
   - Use FISTA acceleration with adaptive restart
   - Periodically verify with direct evaluation
   - If stalled, try a "jump" (large perturbation + re-optimize)

3. **L-BFGS LogSumExp polish** (25% time):
   - Multi-stage temperature annealing
   - On the symmetric half-vector
   - Very aggressive final stages (T down to 0.1)

4. **Multi-length + final polish** (20% time):
   - Try n=1024 (interpolate from best, run LP + L-BFGS)
   - Final peak shaving on the best found

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using symmetry-exploiting
FISTA-accelerated LP alternating optimization, LogSumExp L-BFGS
polish with multi-stage annealing, diverse multi-start, and
adaptive multi-length exploration.
Key innovations: symmetry constraint halves search space, FISTA
with adaptive restart avoids Nesterov overshoot, and the
multi-stage L-BFGS uses very low temperatures for final precision.

import numpy as np
import cvxpy as cp
import time
from scipy.fft import rfft, irfft
from scipy.optimize import minimize


def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]


def score_from_conv(a):
    n = len(a)
    c = fast_convolve(a)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    return 2.0 * n * c.max() / (s * s)


def symmetrize(a):
    return (a + a[::-1]) / 2.0


def make_symmetric_full(half, n):
    """Create full symmetric sequence from half vector of length ceil(n/2)."""
    m = len(half)
    if n % 2 == 0:
        # n = 2m, full = [half[0], ..., half[m-1], half[m-1], half[m-2], ..., half[0]]
        return np.concatenate([half, half[::-1]])
    else:
        # n = 2m-1, full = [half[0], ..., half[m-1], half[m-2], ..., half[0]]
        return np.concatenate([half, half[-2::-1]])


def extract_half(a, n):
    """Extract half vector from symmetric sequence of length n."""
    if n % 2 == 0:
        m = n // 2
        return a[:m].copy()
    else:
        m = (n + 1) // 2
        return a[:m].copy()


def build_conv_matrix(a):
    n = len(a)
    size = 2 * n - 1
    T = np.zeros((size, n))
    for j in range(n):
        T[j:j + n, j] = a
    return T


_lp_solver = None

def get_solver():
    global _lp_solver
    if _lp_solver is not None:
        return _lp_solver
    for name in [cp.ECOS, cp.SCS, cp.PDLP, cp.CLARABEL]:
        try:
            x = cp.Variable(2, nonneg=True)
            p = cp.Problem(cp.Minimize(cp.sum(x)), [cp.sum(x) == 1])
            p.solve(solver=name)
            if p.status in ('optimal', 'optimal_inaccurate'):
                _lp_solver = name
                return name
        except Exception:
            continue
    _lp_solver = cp.ECOS
    return _lp_solver


def solve_lp(a_fixed, solver):
    """Solve: min M s.t. conv(a_fixed, b) <= M*ones, sum(b)=1, b>=0."""
    n = len(a_fixed)
    b = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    T = build_conv_matrix(a_fixed)
    cons = [T @ b <= M, cp.sum(b) == 1]
    prob = cp.Problem(cp.Minimize(M), cons)
    try:
        prob.solve(solver=solver)
    except Exception:
        pass
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        for alt in [cp.ECOS, cp.SCS, cp.PDLP]:
            if alt == solver:
                continue
            try:
                prob.solve(solver=alt)
                if prob.status in ('optimal', 'optimal_inaccurate'):
                    break
            except Exception:
                continue
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None, None
    bv = np.asarray(b.value, dtype=np.float64)
    bv = np.maximum(bv, 0)
    s = bv.sum()
    if s < 1e-15:
        return None, None
    bv /= s
    return bv, float(M.value)


def lp_alternate_fista(a0, t_limit, solver, max_iters=50000):
    """FISTA-accelerated LP alternating with symmetry and adaptive restart."""
    n = len(a0)
    a = symmetrize(np.maximum(a0, 0)).astype(np.float64)
    s = a.sum()
    if s < 1e-15:
        return a0, float('inf')
    a /= s
    
    best_a = a.copy()
    best_score = score_from_conv(a)
    y = a.copy()  # accelerated iterate
    x_prev = a.copy()
    t_val = 1.0
    
    t0 = time.monotonic()
    stall = 0
    prev_best = best_score
    
    for it in range(max_iters):
        if time.monotonic() - t0 > t_limit:
            break
        
        b_new, M_val = solve_lp(y, solver)
        if b_new is None:
            continue
        b_new = symmetrize(b_new)
        sb = b_new.sum()
        if sb < 1e-15:
            continue
        b_new /= sb
        
        # FISTA update
        t_new = (1 + np.sqrt(1 + 4 * t_val * t_val)) / 2
        y_new = b_new + ((t_val - 1) / t_new) * (b_new - x_prev)
        y_new = symmetrize(np.maximum(y_new, 0))
        sy = y_new.sum()
        if sy < 1e-15:
            y_new = b_new.copy()
        else:
            y_new /= sy
        
        x_prev = a.copy()
        a = y_new.copy()
        t_val = t_new
        
        sc = score_from_conv(a)
        if sc < best_score:
            best_score = sc
            best_a = a.copy()
            stall = 0
        else:
            stall += 1
        
        # Adaptive restart: if no improvement for a while, reset momentum
        if stall > 50:
            a = b_new.copy()
            y = a.copy()
            t_val = 1.0
            stall = 0
        
        if (it + 1) % 2000 == 0:
            el = time.monotonic() - t0
            print(f"    FISTA-LP it={it+1} ({el:.0f}s): score={best_score:.6f}")
    
    return best_a, best_score


def lbgfs_refine(a0, t_limit, T_start=100.0, T_end=0.1, maxiter=8000):
    """L-BFGS with LogSumExp smoothing, multi-stage annealing, symmetry."""
    n = len(a0)
    a = symmetrize(np.maximum(a0, 0)).astype(np.float64)
    a /= a.sum()
    
    # Work with log-domain of the full sequence
    z = np.log(np.maximum(a, 1e-300)).copy()
    t0 = time.monotonic()
    
    def make_obj(T_val):
        def obj(z_val):
            if time.monotonic() - t0 > t_limit:
                return 1e15
            a_val = np.exp(z_val - z_val.max())
            a_val /= a_val.sum()
            a_val = symmetrize(a_val)
            a_val /= a_val.sum()
            c = fast_convolve(a_val)
            Tb = T_val * c
            mx = Tb.max()
            return (2.0 * n / T_val) * (mx + np.log(np.sum(np.exp(Tb - mx))))
        return obj
    
    def make_grad(T_val):
        def grad(z_val):
            if time.monotonic() - t0 > t_limit:
                return np.zeros_like(z_val)
            a_val = np.exp(z_val - z_val.max())
            a_val /= a_val.sum()
            a_val = symmetrize(a_val)
            a_val /= a_val.sum()
            c = fast_convolve(a_val)
            Tb = T_val * c
            mx = Tb.max()
            w = np.exp(Tb - mx)
            w /= w.sum()
            # Gradient w.r.t. a
            grad_a = np.zeros(n)
            for k in range(len(c)):
                if w[k] < 1e-14:
                    continue
                js = max(0, k - n + 1)
                je = min(n - 1, k)
                idx = np.arange(js, je + 1)
                grad_a[idx] += 2.0 * w[k] * a_val[k - idx]
            # Symmetrize gradient
            grad_a = symmetrize(grad_a)
            # Gradient w.r.t. z (softmax Jacobian)
            S = np.dot(grad_a, a_val)
            return a_val * (grad_a - S)
        return grad
    
    n_stages = 8
    temps = np.geomspace(T_start, T_end, n_stages)
    iters_per = max(30, maxiter // n_stages)
    
    for T_s in temps:
        if time.monotonic() - t0 > t_limit:
            break
        rem = t_limit - (time.monotonic() - t0)
        if rem < 3:
            break
        try:
            res = minimize(fun=make_obj(T_s), x0=z, jac=make_grad(T_s),
                          method='L-BFGS-B',
                          options={'maxiter': iters_per, 'ftol': 1e-18,
                                   'gtol': 1e-14, 'maxfun': iters_per * 50})
            z = res.x
        except Exception:
            pass
    
    a_out = np.exp(z - z.max())
    a_out /= a_out.sum()
    a_out = symmetrize(a_out)
    a_out /= a_out.sum()
    return a_out


def subgradient_descent(a0, t_limit, n_steps=200000):
    """Mirror descent (exponentiated gradient) with adaptive step size."""
    n = len(a0)
    a = symmetrize(np.maximum(a0, 0)).astype(np.float64)
    a /= a.sum()
    z = np.log(np.maximum(a, 1e-300))
    best_a = a.copy()
    best_score = score_from_conv(a)
    t0 = time.monotonic()
    lr = 0.05
    no_imp = 0
    
    for step in range(n_steps):
        if time.monotonic() - t0 > t_limit:
            break
        
        c = fast_convolve(a)
        c_max = c.max()
        # Active set: peaks within 2% of max
        thresh = c_max - 0.02 * c_max
        active = np.where(c >= thresh)[0]
        
        g = np.zeros(n)
        for k in active:
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            g[idx] += 2.0 * a[k - idx]
        g /= len(active)
        g = symmetrize(g)
        
        z -= lr * g
        a_new = np.exp(z - z.max())
        a_new /= a_new.sum()
        a_new = symmetrize(a_new)
        a_new /= a_new.sum()
        
        sc = score_from_conv(a_new)
        if sc < best_score - 1e-15:
            best_score = sc
            best_a = a_new.copy()
            a = a_new
            no_imp = 0
        else:
            no_imp += 1
            # Revert
            z = np.log(np.maximum(a, 1e-300))
        
        if no_imp >= 50:
            lr *= 0.8
            no_imp = 0
        lr = max(lr / (1 + step * 0.0001), 1e-9)
        
        if step % 50000 == 0:
            el = time.monotonic() - t0
            print(f"    SubGrad {el:.0f}s: score={best_score:.6f} lr={lr:.6f}")
    
    return best_a, best_score


def diverse_init(n, rng, idx):
    """Generate diverse symmetric initializations."""
    m = (n + 1) // 2
    if idx == 0:
        x = np.linspace(0, np.pi, m)
        h = np.cos(x / 2) ** 2
    elif idx == 1:
        x = np.linspace(-1, 1, m)
        h = np.exp(-x ** 2 * 3)
    elif idx == 2:
        x = np.linspace(0, 1, m)
        h = np.sin(np.pi * x) ** 2
    elif idx == 3:
        x = np.linspace(0, 1, m)
        h = np.exp(-3 * x * (1 - x))
    elif idx == 4:
        # Rectified Zadoff-Chu-like
        root = rng.integers(1, n)
        x = np.arange(m)
        h = np.abs(np.exp(1j * np.pi * root * x * (x + 1) / n))
        h = np.maximum(h, 0)
    elif idx == 5:
        # Random with smoothing
        h = rng.random(m)
        h = np.convolve(h, np.ones(5)/5, mode='same')
        h = np.maximum(h, 0)
    elif idx == 6:
        # Bimodal
        x = np.linspace(0, 1, m)
        h = np.exp(-((x-0.3)**2)*20) + np.exp(-((x-0.7)**2)*20)
    else:
        h = rng.random(m)
    
    h = np.maximum(h, 0)
    full = make_symmetric_full(h, n)
    full = np.maximum(full, 0)
    s = full.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return full / s

def interpolate_to_length(a, new_n):
    """Interpolate a sequence to a new length, preserving symmetry."""
    old_n = len(a)
    if old_n == new_n:
        return a.copy()
    a_sym = symmetrize(a)
    a_norm = a_sym / a_sym.sum()
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    new_a = np.interp(new_x, old_x, a_norm)
    new_a = np.maximum(new_a, 0)
    new_a = symmetrize(new_a)
    s = new_a.sum()
    if s > 1e-15:
        new_a /= s
    else:
        new_a = np.ones(new_n) / new_n
    return new_a
