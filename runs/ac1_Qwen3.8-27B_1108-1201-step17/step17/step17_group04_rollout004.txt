= 2(n+d)(-d) / (n+d)^4
= -2d / (n+d)^3

So the objective is decreasing in d (for d > 0) in this regime! We want d as large as possible, up to the point where the peak switches from center to k=2p.

The switch happens when d^2 = |(n-1)-2p|, i.e., d = sqrt(|(n-1)-2p|).

At this point: max(c) = n + 2*sqrt(|(n-1)-2p|).
s = n + sqrt(|(n-1)-2p|).
Objective = 2n * (n + 2*sqrt(|(n-1)-2p|)) / (n + sqrt(|(n-1)-2p|))^2.

Let m = |(n-1)-2p|. The most asymmetric p gives m = n-1 (p=0 or p=n-1).
Then d = sqrt(n-1).
Objective = 2n(n + 2*sqrt(n-1)) / (n + sqrt(n-1))^2.

For large n: ≈ 2n(n + 2*sqrt(n)) / (n + sqrt(n))^2 ≈ 2n*n / n^2 = 2. Hmm, that approaches 2 from below?

Let me expand: (n + sqrt(n))^2 = n^2 + 2n*sqrt(n) + n.
n + 2*sqrt(n) = n + 2*sqrt(n).
2n(n + 2*sqrt(n)) / (n^2 + 2n*sqrt(n) + n)
= 2n^2(1 + 2/sqrt(n)) / (n^2(1 + 2/sqrt(n) + 1/n))
= 2(1 + 2/sqrt(n)) / (1 + 2/sqrt(n) + 1/n)
≈ 2(1 + 2/sqrt(n)) / (1 + 2/sqrt(n)) = 2.

So it approaches 2 from below but very slowly. Not very useful for large n.

Let me try the other case: the peak is at k=2p (when d^2 > |(n-1)-2p|).
max(c) = c_u[2p] + 2d + d^2.
s = n + d.
Objective = 2n(c_u[2p] + 2d + d^2) / (n+d)^2.

For this to be less than 2: 2n(c_u[2p] + 2d + d^2) < 2(n+d)^2
n(c_u[2p] + 2d + d^2) < (n+d)^2 = n^2 + 2nd + d^2
n*c_u[2p] + 2nd + nd^2 < n^2 + 2nd + d^2
n*c_u[2p] + nd^2 - d^2 < n^2
n*c_u[2p] + d^2(n-1) < n^2
d^2(n-1) < n^2 - n*c_u[2p] = n(n - c_u[2p])
d^2 < n(n-c_u[2p])/(n-1) ≈ n - c_u[2p] for large n.

But we're in the regime d^2 > |(n-1)-2p| = n - c_u[2p] (approximately). So the condition d^2 < n - c_u[2p] contradicts d^2 > n - c_u[2p].

This means in the regime where the peak is at k=2p, the objective is always > 2! So we can't beat 2 with a single bump.
