I think the issue is that the subgradient of the MAX is not the right thing to use directly. The max function is not differentiable when multiple lags are tied, and even when it is differentiable, the subgradient might not point in the "useful" direction for this non-convex problem.

The real issue is: for the linear ramp, the peak is at the center, and the subgradient says "decrease the left side and increase the right side" (to reduce the center peak). But this actually increases the peak at a different lag!

Let me verify. If we make the distribution more concentrated at the right (larger $i$), then $(a*a)_k$ for $k$ near the right end will increase. Specifically, $(a*a)_{2n-2}$ (the rightmost) would increase because it's $a_{n-1}^2$.

So the subgradient descent is trying to reduce the center peak by making the distribution more asymmetric, but this creates new peaks at the edges. The net effect might be to increase the max.

This is a fundamental issue with using subgradient methods for this non-convex problem. The "convex" subgradient at the current point doesn't account for the non-convexity.

**Solution**: We need a different approach. Some options:

1. **Direct optimization without subgradients**: Use a method that directly evaluates the objective and takes steps based on the actual change, not the linear approximation.

2. **Penalized approach**: Instead of $\max_k (a*a)_k$, use a smooth approximation like $\text{softmax}(conv / \tau)$ for small $\tau$. This gives a differentiable objective, and gradient descent should work better.

3. **Coordinate descent with actual evaluation**: At each step, try moving mass from position $i$ to position $j$, and accept if the actual $J$ decreases. This is exact but slow.

4. **Hybrid approach**: Use the subgradient method for the "shape" but periodically check and correct for edge effects.

I think option 2 (softmax smoothing) is the most promising. Let me develop this.

The smooth objective: $f_\tau(a) = \tau \log \sum_k \exp((a*a)_k / \tau)$

This is smooth, and its gradient is:
$\nabla f_\tau(i) = \frac{\sum_k \exp((a*a)_k/\tau) \cdot 2a_{k-i}}{\sum_k \exp((a*a)_k/\tau)}$ (for valid $k-i$)

This is a weighted average of the shifted $a$'s, with weights proportional to $\exp((a*a)_k/\tau)$. For small $\tau$, this concentrates on the max lag, recovering the subgradient. For larger $\tau$, it averages over all lags, giving a smoother direction.

The advantage of using the soft objective is that the gradient accounts for ALL lags, not just the max one. This means the step direction considers the potential to create new peaks.

    """Compute gradient of tau * log(sum(exp(conv_k / tau)))."""
    n = len(a)
    conv = fast_conv(a)
    # For numerical stability
    conv_shifted = conv - conv.max()
    exp_vals = np.exp(conv_shifted / tau)
    weights = exp_vals / exp_vals.sum()
    
    # Gradient: weighted average of 2*a_{k-j} for each lag k
    g = np.zeros(n)
    for k in range(len(conv)):
