The GS (Gerchberg-Saxton) approach:
1. FFT(a) -> A (complex)
2. Modify |A| to be more flat: |A|_new = |A| * (|A|_target / |A|)^alpha where |A|_target is the "flat" target
3. IFFT(A_new) -> a_new
4. Enforce a_new >= 0 (clip)
5. Repeat

The "flat target" for |A|: if we want |A|^2 to be flat (which would give a flat circular autocorrelation), then |A|_target = mean(|A|) for all frequencies.

But we're looking at LINEAR convolution, not circular. The relationship is:
- If we zero-pad a to length L >= 2n-1, then the circular autocorrelation of the zero-padded sequence equals the linear autocorrelation.
- So in the frequency domain, |FFT(a_zero_padded)|^2 gives the DFT of the linear autocorrelation.

For the linear convolution to be flat, we want |A(f)|^2 to be flat (where A is the DFT of the zero-padded a). So the target is |A(f)| = constant for all f.

The GS algorithm would:
1. Zero-pad a to length L
2. Compute A = FFT(a_padded)
3. Set |A|_target = mean(|A|) (or some flat target)
4. Update: A_new = A * (|A|_target / |A|)^alpha (partial update, alpha in (0,1])
5. a_new = IFFT(A_new)
6. Clip to [0, L) and take first n elements
7. Enforce non-negativity and normalize

The key parameter is alpha (the "relaxation factor"). Small alpha gives gradual updates, large alpha gives more aggressive flattening.

import numpy as np

def fast_conv(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def simp_proj(v):
    """Project onto probability simplex."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.max(np.where(u * np.arange(1, n+1) > (cssv - 1))[0]) if np.any(u * np.arange(1, n+1) > (cssv - 1)) else 0
    if rho == 0:
        return np.ones(n) / n
    theta = (cssv[rho] - 1) / (rho + 1)
    return np.maximum(v - theta, 0)

def compute_pnorm_grad(a, c, p):
    """Compute gradient of sum(c^p) w.r.t. a using FFT. Returns unnormalized gradient."""
    n = len(a)
    v = np.maximum(c, 0.0) ** (p - 1)
    L = 1 << (3 * n - 1).bit_length()
    rev_a = a[::-1]
    fa = np.fft.rfft(rev_a, L)
    fv = np.fft.rfft(v, L)
    conv_res = np.fft.irfft(fa * fv, L)
    return 2.0 * p * conv_res[n-1:n-1+n]
