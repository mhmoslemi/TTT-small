## Mathematical Specification

We represent a non-negative sequence `a` of length `n` with elements constrained to `x_i ≤ 1000`. We wish to minimize:

```
J(a) = 2*n*max(conv(a,a)) / (sum(a))^2
```

We transform the problem by fixing the modulus across the sequence, so we can search at different levels of granularity:

1. Step 1: Analytical derivation, inversion and normalization
2. Step 2: Parametric optimization on rotated objective space
3. Step 3: Coordinated optimization with soft gradient cuts

The sequence is generated by composing multiple sinusoidal and exponential bumps, normalized to any modulus.

## Implementation Procedure

We assume the initial provided candidate `height_sequence_1` (if available) is of moderate length (approx 250). If not, we provide a fallback sequence of 250 points with Gaussian centers.

1. **Initial Setup**
   - If 'height_sequence_1' exists in global scope, use it as starting candidate
   - If not, initialize with fallback sequence of length 250

2. **Main Optimization Loop (300 seconds maximum)**
   - Project candidate to new sequence of length n=250, then transformed sequence (phase shift and regularization)
   - Calculate initially masked penalty function based on previous candidate score
   - Iterate over moduli and gradients with automatic validation against original scoring

3. **Sequence Length Adaptation**
   - Subdivide long sequences (above 150 points) into multiple segments
   - Apply coordinate-wise optimization to each segment independently
   - Combine optimally scored segments keeping modulus fixed

4. **Gradient-based Optimization**
   - For each transformation (rotation, phase shift) calculate finite difference gradients
   - Use stabilized gradient descent with moment smoothing controls
   - Protect against numerical instabilities by validating all extreme estimates

5. **Fallback if Improvements Fail**
   - If no significant improvement found, recompute using sampled realizations

All candidate sequences are normalized and evaluated through the provided `evaluate_sequence` function with analytical finite differences and penalty masking to avoid outlier evaluations.

## Search Choices and Variations

Default parameterization:
- Start length: 250 points
- Subdivision: 3 segments per initial candidate
- Modulus range: [0.3, 1.0] for most optimization runs
- Bump count: 5-8 bumps per segment

Interactive variations:
- If penalty score `> 2.0`, employ more aggressive subdivision
- If run time > 100 seconds, switch to accelerated gradient descent mode
- If optimization stalls, inject regularly perturbed populations of candidate sequences

## Compute Budget and Robustness

We estimate the evaluation time for a sequence of length n:
- FFT evaluation: O(n*log(n)) per transformation
- 250-length sequences: ~1.5 seconds evaluation including gradient and autocorrelation check
- 5000-length sequences: several minutes evaluation

We allocate:
- 90 seconds for the main optimization with active candidates
- 45 seconds for exploratory runs on different moduli
- 30 seconds for candidate validation against final objective metrics
- 5 seconds for fallback and recovery steps

The algorithm handles:
- Start-up with automatic candidate fallback system
- Out-of-memory issues through adaptive resolution projection
- Long run durations by segment braking and hierarchical optimization

We have safeguarded against any invalid evaluations by limiting all sequences to required domain and modulus constraints.

## Validation and Return Contract

We ensure all returned sequences `a` satisfy:
1. `a[i] ≥ 0` for all i
2. `sum(a) ≥ 0.01`
3. `all(a[i] ≤ 1000)`

We re-evaluate every candidate using the provided scoring function before maximizing the moduli. The final return is the minimal score obtained.

        if isinstance(x, bool) or not isinstance(x, (int, float)):
            return np.inf
        if np.isnan(x) or np.isinf(x):

    sequence = [float(x) for x in a_list]
    sequence = list(map(float, sequence))
    sequence = [max(0, x) for x in sequence]  # Apply non-negativity protection
    sequence = list(map(float, sequence))
    sequence = [min(1000.0, x) for x in sequence]  # Ensure values don't exceed 1000
    sequence = [max(0, x) for x in sequence]  # Protect against negative numbers
    n_val = float(sum(sequence))
    if n_val < 0.01:

    n_arr = np.array(sequence)

def norm_sum1(seq):

    if n_s < 1e-15:

        fall_back = [1.0 / len(seq)] * len(seq)
