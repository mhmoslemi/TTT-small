- a[k-j]*a[j] (from m=k-j, if k-j != j)

So b[k] depends on a[i] and a[j] through:
b[k] ∝ a[i]*a[k-i] + a[j]*a[k-j] + (cross terms if i = k-j or j = k-i)

This is a quadratic in a[i] (since a[j] = c - a[i]):
b[k] = Q_k * a[i]^2 + L_k * a[i] + C_k

where Q_k, L_k, C_k depend on the other elements of a.

We want to find a[i] that minimizes max_k b[k]. This is a 1D min-max problem, which can be solved by bisection or by finding the point where the maximum is minimized.

Actually, for each k, b[k] is a quadratic in a[i] (with coefficient Q_k >= 0 since it involves products). The max of quadratics is convex, so we can find the minimum by ternary search or golden section search.

This is a good approach for the final polish. Let me implement it.
