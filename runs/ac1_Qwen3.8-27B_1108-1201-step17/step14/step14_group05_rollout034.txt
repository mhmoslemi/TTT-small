def lp_solve(a, M, active_idx, solver):
    """Solve LP: max sum(b) s.t. T[active] @ b <= M[active], b >= 0."""
    n = len(a)
    b_var = cp.Variable(n, nonneg=True)
    
    # Build constraint rows
    constraints = []
    for k in active_idx:
        # T[k, :] = a[k-j] for j where 0 <= k-j < n
        js = max(0, k - n + 1)
        je = min(n - 1, k)
        if js > je:
            continue
        row = np.zeros(n)
        row[js:je+1] = a[k - np.arange(js, je+1)]
        constraints.append(row @ b_var <= M[k])
    
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)
    try:
        prob.solve(solver=solver, verbose=False)
    except:
        return None
    if b_var.value is None:
        return None
    return np.maximum(b_var.value, 0.0)

        grad = 2.0 * conv[2*n-2 - np.arange(n)]
        grad -= np.mean(grad)  # Project onto tangent of sum constraint
        
        steps += 1
        m = beta1 * m + (1 - beta1) * grad
        v = beta2 * v + (1 - beta2) * grad**2
        m_hat = m / (1 - beta1**steps)
        v_hat = v / (1 - beta2**steps)
        a_new = a - lr * m_hat / (np.sqrt(v_hat) + 1e-8)
        a_new = np.maximum(a_new, 0.0)

Actually, I just realized something. The Fessler-Parks method is designed for the problem:
min f(y) = max_k (T @ y)_k / sum(y)

where f is a ratio of a linear function to another linear function. The standard Nesterov acceleration works well for this because f is a "self-concordant" barrier-like function.

But our problem is slightly different: we're minimizing `max(conv(a,a))` where `conv(a,a)` is **quadratic** in `a`, not linear. The LP best-response linearizes this by fixing one argument of the convolution.

So the iteration is:
1. Given `y`, compute `M = max(conv(y,y))`
2. Solve LP: max `sum(b)` s.t. `conv(y, b) <= M`, `b >= 0`
3. The solution `g` minimizes `conv(y, ·)` in some sense
4. Update `y ← (1-t)y + t*g`

This is like a block coordinate descent where we optimize one "block" (the sequence) at a time, using an LP to optimize the other "block" (the convolution partner). The Nesterov acceleration is applied to the outer loop.

The convergence rate is limited by the condition number of the problem, which depends on the sequence structure. For well-conditioned problems, it converges fast; for ill-conditioned ones, it's slow.
