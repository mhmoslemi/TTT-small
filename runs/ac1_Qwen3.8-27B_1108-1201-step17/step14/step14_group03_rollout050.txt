Then we can use gradient descent (no LP needed!). The gradient of $\text{logsumexp}((a*a)/T)$ with respect to $a_i$ is:
$\frac{1}{T} \cdot \frac{\sum_k \exp((a*a)_k/T) \cdot \partial(a*a)_k/\partial a_i}{\sum_k \exp((a*a)_k/T)}$

And $\partial(a*a)_k / \partial a_i = a_{k-i} + a_i \cdot \delta_{k,2i}$ (the shift matrix plus the diagonal correction).

So the gradient is: $\frac{2}{T} \sum_k w_k (a_{k-i} + a_i \delta_{k,2i})$ where $w_k = \exp((a*a)_k/T) / \sum \exp((a*a)_j/T)$.

This is like a weighted average of the "shifted" versions of $a$, where the weights are concentrated near the max of the convolution.

This is essentially the LSE polish in the previous code! But we can make it much more efficient:
- Use FFT to compute the convolution
- Use FFT to compute the gradient (it's a correlation, which is a convolution with the reversed array)

The gradient computation: $\nabla_i = 2 \sum_k w_k a_{k-i}$ (ignoring the diagonal term for now).

This is a cross-correlation of $w$ and $a$, which can be computed in $O(n \log n)$ using FFT!

So the full LSE gradient descent step is:
1. Compute $\text{conv} = a * a$ via FFT: $O(n \log n)$
2. Compute $w_k = \exp(\text{conv}_k / T) / \sum \exp(\text{conv}_j / T)$: $O(n)$
3. Compute gradient via FFT correlation: $O(n \log n)$
4. Take a step: $a \leftarrow a - \eta \cdot \text{grad}$, clip to non-negative, renormalize: $O(n)$

Total per step: $O(n \log n)$. For $n = 1600$, that's about $1600 \times 11 \approx 17600$ operations. We can do millions of steps in a few seconds!

Let me now think about the LP with constraint screening in more detail.

**LP with constraint screening:**

At each Nesterov iteration:
1. Compute $M = \max(y*y)$
2. Solve LP: $\max \sum b_j$ s.t. $(y*b)_k \le M$ for $k$ in active set, $b_j \ge 0$
3. Update active set: include constraints where $(y*b_{\text{prev}})_k > M - \epsilon M$ (i.e., near-binding)
4. Nesterov update

The active set typically has $O(n)$ constraints (maybe 10-50% of all constraints), so the LP is smaller by a factor of 2-10.

For a bigger speedup, we can be more aggressive: only include constraints where $(y*b_{\text{prev}})_k > M - 0.01 M$. This might give only 5-20 active constraints.

But there's a risk: if we exclude a constraint that should be active, the LP solution might violate it. To handle this:
- After solving the LP, check if any excluded constraint is violated
- If so, add it to the active set and re-solve
- Repeat until no constraint is violated

This is a "lazy constraint" approach, similar to what's used in cutting-plane methods.

For the Nesterov acceleration, the standard schedule is:
- $y^{(t)} = (1 - \alpha_t) y^{(t-1)} + \alpha_t g^{(t)}$ where $\alpha_t = 2/(t+2)$
- $a^{(t)} = y^{(t)} + \frac{t-1}{t+2}(y^{(t)} - y^{(t-1)})$ (extrapolation)
- Evaluate at both $y^{(t)}$ and $a^{(t)}$

The convergence rate is $O(1/t)$ for the Nesterov method, which means after $T$ iterations, the error is $O(1/T)$.

For our problem, we want $\max(a*a)$ to be close to the optimal value. The Nesterov method guarantees that the duality gap decreases as $O(1/t)$.

                break
            
            # Compute gradient
            conv = fast_autocorr(a)
            max_conv = conv.max()
            if max_conv < 1e-15:
                break
            
            w = np.exp((conv - max_conv) / T)
            w_sum = w.sum()
            if w_sum < 1e-15:
                break
            w = w / w_sum
            
            # Gradient: grad[m] = 2 * sum_j w[m+j] * a[j]
            # Using FFT
            size = 2 * n - 1
            grad_fft_size = 1 << (3 * n - 3).bit_length()
            w_rev = w[::-1]
            W = rfft(w_rev, grad_fft_size)
            A2 = rfft(a, grad_fft_size)
            conv_wa = irfft(W * A2, grad_fft_size)
            grad = 2.0 * conv_wa[n-1:2*n-1][::-1] / T
            
            # Step size (adaptive)
            grad_norm = np.linalg.norm(grad)
            if grad_norm < 1e-15:
                break
            step = 1.0 / grad_norm  # normalize gradient to unit step
            
            # Try a few step sizes with backtracking
            best_step_val = step
            best_new_score = float('inf')
            for factor in [1.0, 0.5, 0.25, 0.1, 0.05]:
                s_try = step * factor
                a_new = a - s_try * grad
                a_new = np.maximum(a_new, 0.0)
                s = a_new.sum()
                if s < 1e-15:
                    continue
                a_new = a_new * norm / s
                sc = fast_autocorr(a_new).max()
                if sc < best_new_score:
                    best_new_score = sc
                    best_step_val = s_try
                if sc < conv.max() - 1e-10:
                    break
            
            a = a - best_step_val * grad
            a = np.maximum(a, 0.0)
            s = a.sum()
            if s < 1e-15:
                break
            a = a * norm / s
            
            sc = fast_autocorr(a).max()
            if sc < best_score:
                best_score = sc
                best_a = a.copy()
        
        if verbose and (si % 3 == 0 or si == n_stages - 1):
            elapsed = time.monotonic() - t0
            print(f"    LSE stage {si}/{n_stages} T={T:.3f} ({elapsed:.0f}s): best={best_score:.8f}")
    
    return best_a, best_score

def build_sparse_conv_matrix(a, active_k):
    """Build the constraint matrix rows for active constraints only."""
    n = len(a)
    size = 2 * n - 1
    T = np.zeros((len(active_k), n))
    for ii, k in enumerate(active_k):
        for j in range(n):
            i = k - j
            if 0 <= i < n:
                T[ii, j] = a[i]
    return T

def lp_best_response_screened(a, M, active_k, solver):
    """Solve LP with only active constraints."""
    n = len(a)
    b_var = cp.Variable(n, nonneg=True)
    T = build_sparse_conv_matrix(a, active_k)
    constraints = [T @ b_var <= M]
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        return None, active_k
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None, active_k
    b_val = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
    if b_val.sum() < 1e-15:
        return None, active_k
    
    # Update active set: find constraints that are near-binding
    size = 2*n - 1
    yb = np.zeros(size)
    for k in range(size):
        for j in range(n):
            i = k - j
            if 0 <= i < n:
                yb[k] += a[i] * b_val[j]
    
    # New active set: constraints within 2% of M
    new_active = set()
    for k in range(size):
        if yb[k] > M * 0.98:
            new_active.add(k)
    # Always keep some constraints
    if len(new_active) < 10:
        top_k = np.argsort(yb)[-20:]
        new_active.update(top_k.tolist())
    
    return b_val, sorted(new_active)
