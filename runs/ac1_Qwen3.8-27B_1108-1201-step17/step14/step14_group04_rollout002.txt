Let me think more carefully about the LP approach and how to improve it.

The minimax algorithm is:
- Start with a (normalized to sum = √(2n))
- M = max(conv(a, a))
- Solve LP: max sum(b) s.t. b >= 0, conv(a, b)_k <= M for all k
- The LP gives us b*. Note that conv(a, b*) sums to sum(a)*sum(b) = √(2n)*sum(b), and each entry is <= M, so sum(b) <= (2n-1)*M / √(2n) = √(2n)*M.
- Actually, the constraint is (2n-1) entries each <= M, so sum over all entries of conv(a,b) = sum(a)*sum(b) <= (2n-1)*M.
- So sum(b) <= (2n-1)*M / sum(a).
- Rescale b to have sum = √(2n): g = b * √(2n) / sum(b)
- Update: a <- (1-alpha)*a + alpha*g

The key insight is that at the optimum, this should converge to a point where the LP is "tight" in some sense.

**Improvement idea: Use the dual of the LP**
The dual of:
max sum(b) s.t. T @ b <= M, b >= 0

is:
min M * sum(y) s.t. T^T @ y >= 1, y >= 0

where T is the Toeplitz matrix. The dual variables y give us a "weighting" of the constraints.

At the optimum, complementary slackness tells us that y_k > 0 only where (T@b)_k = M (active constraints).

**Another idea: Use the subgradient of the max function**
The gradient of max(conv(a,a)) with respect to a can be computed via the FFT. If we know which lag gives the max, we can compute the gradient efficiently.

def fast_autocorr(a):
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def project_simplex(v, target_sum=1.0):
    v = np.maximum(np.asarray(v, dtype=np.float64), 0.0)
    s = v.sum()
    if s < 1e-15:
        n = len(v)
        return np.ones(n) * target_sum / n
    return target_sum * v / s


def lse_grad(y, T):
    n = len(y)
    ac = fast_autocorr(y)
    ac_max = ac.max()
    if ac_max < 1e-15:
        return np.zeros(n)
    shifted = (ac - ac_max) / T
    shifted = np.clip(shifted, -60.0, 60.0)
    exp_s = np.exp(shifted)
    w = exp_s / exp_s.sum()
    N = 1 << (3 * n - 2).bit_length()
    W = rfft(w, N)
    Y_rev = rfft(y[::-1], N)
    cross = irfft(W * Y_rev, N)
    grad = 2.0 * cross[n - 1: n - 1 + n]
    return grad

def lp_best_response(a, M, solver):
    n = len(a)
    b_var = cp.Variable(n, nonneg=True)
    T_mat = np.zeros((2 * n - 1, n))
    for j in range(n):
        T_mat[j:j + n, j] = a
    constraints = [T_mat @ b_var <= M]
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        return None
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None
    b_val = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
    if b_val.sum() < 1e-15:
        return None
    return b_val

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss
