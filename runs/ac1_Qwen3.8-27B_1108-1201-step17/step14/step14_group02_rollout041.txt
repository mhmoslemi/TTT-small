`new_conv[k] = conv[k] - δ*a[k-i] - δ*a[i-k] + δ*a[k-j] + δ*a[j-k]` (with appropriate zero-padding)

Wait, that's still not right. Let me expand:
`new_conv[k] = sum_l new_a[l] * new_a[k-l]`

The terms that change are those involving a[i] or a[j]:
- Terms with a[i]: a[i]*a[k-i] and a[k-i]*a[i] (if i ≠ k-i)
- After change: (a[i]-δ)*a[k-i] + a[k-i]*(a[i]-δ) = 2a[i]a[k-i] - 2δ*a[k-i] (if i ≠ k-i)
  Or: (a[i]-δ)^2 = a[i]^2 - 2δ*a[i] + δ^2 (if i = k-i)

This is getting complicated. Let me just use the formula:
`delta_conv[k] ≈ -δ*(a[k-i] + a[i-k]) + δ*(a[k-j] + a[j-k])` (ignoring the δ^2 term)

where all a[·] are zero outside [0, n-1].

So the change in the maximum is approximately:
`max_k (conv[k] + delta_conv[k]) - max_k conv[k]`

We want this to be negative (reduce the peak). The peak is at some set of lags S (where conv[k] ≈ max). For those lags:
`delta_conv[k] = δ * ((a[k-j] + a[j-k]) - (a[k-i] + a[i-k]))` for k in S

We want this to be negative for all k in S (or at least for the k with the largest conv[k]).

So we want: `(a[k-j] + a[j-k]) < (a[k-i] + a[i-k])` for all k in S.

This means: pick i such that the sequence values at positions related to i are LARGE (at the peak lags), and j such that values at positions related to j are SMALL.

**Algorithm:**
1. Find the active set S = {k : conv[k] > max_b * (1 - ε)} for small ε.
2. For each i (source), compute the "peak sensitivity": `sens_i = max_{k in S} (a[k-i] + a[i-k])` (zero-padded).
3. For each j (target), compute: `sens_j = max_{k in S} (a[k-j] + a[j-k])`.
4. Pick i with largest sens_i (among those with a[i] > 0) and j with smallest sens_j.
5. Move mass from i to j with an optimal step size.

The optimal step size δ* can be found by bisection or by solving for the point where the new max equals the old max.

This is O(n * |S|) per pair (i, j), and we try O(n^2) pairs. For n=1600 and |S| ≈ 10-50, this is about 1600 * 30 = 48000 per i, times 1600 j's = 77 million. That's too slow for each coordinate descent step.

- Precompute the "sensitivity vector" for each position: `sens[k, j] = a[k-j] + a[j-k]` (zero-padded). This is a (2n-1) x n matrix.
- Then `sens_i = max over k in S of sens[k, i]` and `sens_j = max over k in S of sens[k, j]`.
- This can be computed as: `sens_max = np.max(sens[np.ix_(S_indices, range(n))], axis=0)` - a vector of length n.
- Then pick i = argmax(sens_max) (among a[i] > 0) and j = argmin(sens_max).

Computing the sens matrix is O(n^2) which is fine. Then finding the best i, j is O(n).

For the step size: after picking (i, j), we want the largest δ such that:
`conv[k] + δ * (sens[k,j] - sens[k,i]) <= max_b` for all k.

This gives: `δ <= (max_b - conv[k]) / (sens[k,j] - sens[k,i])` for all k where `sens[k,j] - sens[k,i] > 0`.

So `δ* = min over k where denom > 0 of (max_b - conv[k]) / denom`.

Also `δ <= a[i]` (can't go negative).

This is O(n) to compute.

1. Compute sens matrix: O(n^2) [can be cached if a doesn't change much]

        # Find active set
        threshold = M_curr * 0.95
        active = np.where(ac >= threshold)[0]
        if len(active) == 0:
            active = np.where(ac >= M_curr * 0.99)[0]
        
        # Compute sensitivity for each position
        # sens[p] = max_{k in active} (a[k-p] + a[p-k]) with zero-padding
        sens = np.zeros(n)
        for k in active:
            ki = int(k)
            for p in range(n):
                val = 0.0
                d1 = ki - p
                if 0 <= d1 < n:
                    val += a[d1]
                d2 = p - ki
                if 0 <= d2 < n:
                    val += a[d2]
                sens[p] = max(sens[p], val)
        
        # Find source: position with highest sensitivity and non-zero mass
        source_candidates = np.where(a > 1e-10)[0]
        if len(source_candidates) == 0:
            break
        src = source_candidates[np.argmax(sens[source_candidates])]
        
        # Find target: position with lowest sensitivity
        tgt = np.argmin(sens)
        
        if src == tgt:
            # Random perturbation
            i = rng.integers(n)
            j = rng.integers(n)
            while j == i:
                j = rng.integers(n)
            if a[i] < 1e-10:
                src, tgt = i, j
            else:
                src, tgt = j, i
            sens_t = sens[src]
            sens_s = sens[tgt]
            if sens_s <= sens_t:
                src, tgt = tgt, src
        
        # Compute optimal step size
        # delta_conv[k] = delta * (sens_vector[k,tgt] - sens_vector[k,src])
        # We need: ac[k] + delta * delta_sens[k] <= M_curr for all k
        # => delta <= (M_curr - ac[k]) / delta_sens[k] where delta_sens[k] > 0
        
        max_delta = a[src] * 0.9  # Don't use all mass
        for k in range(2*n-1):
            ki = int(k)
            d1_t = ki - tgt
            d2_t = tgt - ki
            d1_s = ki - src
            d2_s = src - ki
            
            val_t = 0.0
            if 0 <= d1_t < n:
                val_t += a[d1_t]
            if 0 <= d2_t < n:
                val_t += a[d2_t]
            
            val_s = 0.0
            if 0 <= d1_s < n:
                val_s += a[d1_s]
            if 0 <= d2_s < n:
                val_s += a[d2_s]
            
            delta_sens = val_t - val_s
            if delta_sens > 1e-15:
                delta_max_k = (M_curr - ac[k]) / delta_sens + 1e-10
                if delta_max_k < max_delta:
                    max_delta = delta_max_k
        
        max_delta = max(0, min(max_delta, a[src] * 0.9))
        
        if max_delta < 1e-15:
            stall_count += 1
            # Random perturbation
            i = rng.integers(n)
            j = rng.integers(n)
            if i != j and a[i] > 1e-10:
                frac = rng.uniform(0.001, 0.01)
                amt = a[i] * frac
                a[i] -= amt
                a[j] += amt
                a = np.maximum(a, 0)
                a = a / a.sum()
            continue
        
        # Try the step
        a[src] -= max_delta
        a[tgt] += max_delta
        a = np.maximum(a, 0)
        a = a / a.sum()
        
        M_new = fast_autocorr(a).max()
        if M_new < best_m - 1e-15:
            best_m = M_new
            best_a = a.copy()
            stall_count = 0
        else:
            # Revert
            a[tgt] -= max_delta
            a[src] += max_delta
            a = np.maximum(a, 0)
            a = a / a.sum()
            stall_count += 1
    
    if verbose:
        elapsed = time.monotonic() - t0
        J = 2.0 * n * best_m
