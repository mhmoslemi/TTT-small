Let me also think about the soft-max gradient more carefully.

The soft-max of the convolution is:
M_T = (1/T) * log(sum_k exp(T * c[k]))

where c = a*a. As T → ∞, M_T → max(c).

The gradient of M_T with respect to a[i] is:
dM_T/da[i] = (1/T) * sum_k [T * exp(T*c[k]) / sum_j exp(T*c[j])] * dc[k]/da[i]
= sum_k [exp(T*c[k]) / sum_j exp(T*c[j])] * dc[k]/da[i]
= sum_k w[k] * dc[k]/da[i]

where w[k] = exp(T*c[k]) / sum_j exp(T*c[j]) is a softmax weight.

And dc[k]/da[i] = 2*a[k-i] if 0 <= k-i < n, else 0.

So:
dM_T/da[i] = 2 * sum_{k: 0<=k-i<n} w[k] * a[k-i]
= 2 * sum_{j=0}^{n-1} w[i+j] * a[j]  (letting j = k-i)

Wait, k-i ranges from 0 to n-1, so k ranges from i to i+n-1. But k also ranges from 0 to 2n-2. So:
dM_T/da[i] = 2 * sum_{j=0}^{n-1} w[i+j] * a[j]

where we interpret w[k] = 0 if k < 0 or k >= 2n-1.

This is a convolution of w with a! So:
dM_T/da = 2 * (w * a)  (where w is zero-padded to length 2n-1, and we take the first n elements of the convolution)

Wait, let me be more careful. The full convolution w*a has length (2n-1) + n - 1 = 3n-2. We want the elements at positions i, i+1, ..., i+n-1 for each i = 0, ..., n-1.

Actually, let me just define:
grad[i] = 2 * sum_{j=0}^{n-1} w[i+j] * a[j] for i = 0, ..., n-1

This can be computed as:
- Create an array W of length 3n-2 (or 3n-1 to be safe) with W[i+j] = w[i+j] for valid i+j
- Actually, it's easier to just compute it as a cross-correlation

Let me think of it differently. Define the "extended" weight vector W of length 3n-2:
W[k] = w[k] for 0 <= k <= 2n-2, W[k] = 0 otherwise.

Then grad[i] = 2 * sum_{j=0}^{n-1} W[i+j] * a[j] = 2 * (W * a)[i] (where * denotes cross-correlation, or equivalently convolution with a flipped)

Actually, (W * a)[i] = sum_j W[i+j] * a[j] is the cross-correlation of W and a at lag i.

In numpy, this is `np.correlate(W, a, mode='valid')` which gives n elements.

Or we can compute it using FFT:
- FFT of W (padded to length >= 3n-2)
- FFT of a (padded to same length)
- IFFT of (FFT(W) * conj(FFT(a)))
- Take the first n elements

This gives the gradient in O(n log n).

Then the full gradient of the objective F(a) = 2n * M_T / S^2 is:
∇F = (2n/S^2) * ∇M_T - (4n*M_T/S^3) * 1

where 1 is the all-ones vector (since dS/da[i] = 1 for all i).

Wait, let me redo this. F(a) = 2n * M_T(a) / S(a)^2.

dF/da[i] = 2n * (1/S^2) * dM_T/da[i] - 2n * M_T * (2/S^3) * dS/da[i]
= 2n/S^2 * dM_T/da[i] - 4n*M_T/S^3

So the gradient is:
grad_F[i] = 2n/S^2 * dM_T/da[i] - 4n*M_T/S^3

And dM_T/da[i] = 2 * sum_{j=0}^{n-1} w[i+j] * a[j] (as computed above).

For the optimization, we want to minimize F subject to a >= 0. We can use projected gradient descent:
a_new = max(0, a - lr * grad_F)
Then normalize: a_new = a_new * sqrt(2n) / sum(a_new)

But wait, the normalization changes the objective. Let me think about this more carefully.

The objective F(a) = 2n * max(a*a) / (sum a)^2 is scale-invariant. So we can fix the scale (e.g., sum a = sqrt(2n)) and just minimize max(a*a) (or the soft-max version).

If we fix sum a = sqrt(2n), then we're minimizing M_T(a) subject to sum a = sqrt(2n) and a >= 0.

The Lagrangian is: L = M_T(a) - λ * (sum a - sqrt(2n)) - μ^T a (for the non-negativity constraints)

The KKT conditions give: ∇M_T(a) - λ * 1 - μ = 0, where μ >= 0 and μ[i] * a[i] = 0.

For the unconstrained case (all a[i] > 0): λ = mean(∇M_T(a)), and the update is:
a_new = a - lr * (∇M_T(a) - mean(∇M_T(a)))
Then project onto a >= 0 and sum a = sqrt(2n).

This is like a "centered" gradient step.

def fast_autocorr(a):
    """Compute self-convolution using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]

def flat_sequence(n):
    """
    Generate the 'flat convolution' sequence via recursion.
    (a*a)[k] = C for k = 0, ..., n-1.
    Returns the sequence (may have negative values).
    """
    C = 1.0
    a = np.zeros(n)
    a[0] = np.sqrt(C)
    for k in range(1, n):
        # (a*a)[k] = 2*a[0]*a[k] + sum_{j=1}^{k-1} a[j]*a[k-j] = C
        s = 0.0
        for j in range(1, k):
            s += a[j] * a[k-j]
        a[k] = (C - s) / (2.0 * a[0])
    return a


def flat_sequence_fast(n):
    """
    Generate the 'flat convolution' sequence efficiently using FFT-based convolution.
    """
    C = 1.0
    a = np.zeros(n)
    a[0] = np.sqrt(C)
    
    # We need to compute sum_{j=1}^{k-1} a[j]*a[k-j] for each k
    # This is the (k-1)th element of a*a minus the terms involving a[0] and a[k]
    # Actually, let's just use the direct O(n^2) approach since n is at most a few thousand
    
    for k in range(1, n):
        s = np.dot(a[1:k], a[k-1:0:-1])  # sum_{j=1}^{k-1} a[j]*a[k-j]
        a[k] = (C - s) / (2.0 * a[0])
    
    return a


def softmax_gradient(c, T):
    """
    Compute softmax weights for the convolution.
    Returns w[k] = exp(T*c[k]) / sum exp(T*c[j])
    """
    c_shifted = c - c.max()  # numerical stability
    exp_c = np.exp(T * c_shifted)
    w = exp_c / exp_c.sum()
    return w

def grad_step(a, T, lr):
    """
    One gradient step on the soft-max objective.
    a is normalized to sum = sqrt(2n).
    Returns updated a.
    """

    c = fast_autocorr(a)
    w = softmax_gradient(c, T)
    
    # Gradient of M_T w.r.t. a
    dM = compute_grad_M(a, w, n)
    
    # For the constrained problem (sum a = sqrt(2n), a >= 0):
    # The effective gradient (projected onto the constraint) is:
    # grad_eff = dM - mean(dM)  (centering for the sum constraint)
    # Then: a_new = max(0, a - lr * grad_eff)
    # Then normalize: a_new = a_new * sqrt(2n) / sum(a_new)
    
    S = np.sqrt(2.0 * n)
    grad_eff = dM - dM.mean()
    
    a_new = a - lr * grad_eff
    a_new = np.maximum(a_new, 0.0)
    s = a_new.sum()
    if s < 1e-15:
        return a.copy()
    a_new = a_new * S / s
    
    return a_new
