    # f(t') = max_k (conv[k] + delta_k(t'))
    # where delta_k(t') = 2*(t'-old)*a[k-i] for k != 2i (valid k)
    #                        t'^2 - old^2 for k = 2i

    k_lo = i
    k_hi = min(2*n-1, i+n)
    indices = np.arange(k_lo, k_hi)
    j_indices = indices - i  # = 0 to k_hi-k_lo-1
    
    # Affine slopes: 2*a[j_indices]
    # Affine intercepts: conv[indices] - 2*old*a[j_indices]
    slopes = 2 * a[j_indices]
    intercepts = conv[indices] - 2 * old_val * a[j_indices]
    
    # Quadratic: t'^2 + (conv[2i] - old^2) at k=2i (if in range)
    has_quad = (2*i >= k_lo) and (2*i < k_hi)
    if has_quad:
        quad_const = conv[2*i] - old_val**2
    
    # Minimize max(slopes*t' + intercepts, t'^2 + quad_const) over t' >= 0
    # Binary search approach
    lo = 0.0
    hi = max(5.0 * old_val, slopes.max() + 1.0)  # upper bound
    
    for _ in range(30):
        mid = (lo + hi) / 2
        # Compute f(mid) and subgradient
        vals = slopes * mid + intercepts
        if has_quad:
            quad_val = mid**2 + quad_const
            all_vals = np.append(vals, quad_val)
        else:
            all_vals = vals
        mx = all_vals.max()
        
        # Subgradient: slope of the max function
        if has_quad and (mid**2 + quad_const) >= mx - 1e-10:
            # Quadratic is active (or tied)
            subgrad = 2 * mid
            # But also check if any affine is tied

            else:

        if subgrad > 0:
            hi = mid
        elif subgrad < 0:
            lo = mid
        else:
            break

Let me also consider: can we avoid the LP entirely and use a first-order method? The subgradient of the objective J(a) = 2n*max_k conv(a,a)[k] / (sum a)^2 with respect to a is:

Let b = conv(a,a) and M = max_k b[k]. Let S = sum(a).
J = 2n*M/S^2

dJ/da[i] = 2n * (dM/da[i])/S^2 - 2n*M * 2/S^3

dM/da[i] = sum of d(b[k])/da[i] over active k (where b[k] = M)
d(b[k])/da[i] = a[k-i] + a[k-i] (if k-i ≠ i) or 2*a[i] (if k-i = i)
Wait, b[k] = sum_j a[j]*a[k-j].
d(b[k])/da[i] = a[k-i] (if 0 ≤ k-i < n, from the term j=i) + a[k-i] (if 0 ≤ k-i < n, from the term j=k-i, i.e., k-j=i)
= 2*a[k-i] (if k ≠ 2i and 0 ≤ k-i < n)
= 2*a[i] (if k = 2i)

So the subgradient is:
∂J/∂a[i] = (2n/S^2) * sum_{k: b[k]=M, 0≤k-i<n} (2*a[k-i] * [k≠2i] + 2*a[i] * [k=2i]) - (4n*M/S^3)

This is a valid subgradient, and we can use it in a subgradient method or a smoothed approximation.

But the subgradient method is slow to converge. The LP-Nesterov approach is better because it uses the full convex structure.

    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]
