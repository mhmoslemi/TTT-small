Let me try a different approach: **direct coordinate descent on the peak**.

Algorithm:
1. Start with a good initialization (ramp, or the provided sequence)
2. Compute the convolution and find the peak lag(s)
3. For each coordinate a[j], compute the optimal value that minimizes the peak
4. Repeat

For step 3, fixing all coordinates except a[j], the convolution at lag k becomes:
c[k] = a[j]*a[k-j] + (c[k] - a[j]*a[k-j]) if k-j is valid
     = a[j]*a[k-j] + rest_k

where rest_k is the contribution from all other pairs. So c[k] is linear in a[j].

The peak is max_k c[k]. We want to choose a[j] >= 0 to minimize max_k c[k].

This is a 1D problem: minimize max_k (a_k * a[j] + b_k) over a[j] >= 0, where a_k = a[k-j] (if valid) and b_k = c[k] - a[k-j]*a[j].

The optimal a[j] is found by the point where the increasing and decreasing constraints balance. This can be solved in O(n) per coordinate.

This is similar to the approach in "minimax" optimization.

Let me code this up:

```python
def coordinate_descent_peak(f, max_iter=1000):
    n = len(f)
    f = f.copy()
    for it in range(max_iter):
        improved = False
        for j in range(n):
            # Compute current convolution contribution
            c = np.convolve(f, f)
            # For coordinate j, c[k] = f[j]*f[k-j] + rest
            # We want to minimize max c[k] by adjusting f[j]
            
            # Rest of c[k] (without f[j]'s contribution)
            rest = c.copy()
            for k in range(max(0, j - (n-1)), min(2*n-2, j + (n-1)) + 1):
                i = k - j
                if 0 <= i < n:
                    rest[k] -= f[j] * f[i]
            
            # Coefficient of f[j] in c[k]
            coeff = np.zeros(2*n-1)
            for k in range(max(0, j - (n-1)), min(2*n-2, j + (n-1)) + 1):
                i = k - j
                if 0 <= i < n:
                    coeff[k] = f[i]
            
            # We want: min_x max_k (coeff[k]*x + rest[k]) subject to x >= 0
            # At the optimum, the max is minimized
            # The function max_k (coeff[k]*x + rest[k]) is convex in x
            # Find x where the minimum is achieved
            
            # If all coeff[k] == 0, x doesn't matter
            if np.all(coeff == 0):
                continue
            
            # Binary search or direct computation
            # The subgradient at x is: weighted average of coeff at active constraints
            # At optimum, 0 is in the subgradient of max_k(coeff[k]*x + rest[k])
            
            # Simple approach: try several candidate x values
            # The optimum x* satisfies: max_k(coeff[k]*x* + rest[k]) is minimized
            # This happens where the "upper envelope" is minimized
            
            # For efficiency, let's use the fact that the optimum is where
            # the maximum of {coeff[k]*x + rest[k]} is flat
            # i.e., there exist k1, k2 with coeff[k1] != coeff[k2] such that
            # coeff[k1]*x + rest[k1] = coeff[k2]*x + rest[k2] = max
            
            # Or the optimum is at x = 0 (boundary)
            
            # Let's use a simple bisection on the subgradient
            # g(x) = max_k(coeff[k] - coeff_min) ... hmm this is getting complicated
            
            # Simpler: just do a line search
            # Try x = 0, and x values that make different k's tie
            candidates = [0.0, f[j]]  # keep current, and try 0
            # Add candidates where pairs of active constraints tie
            active_k = np.where(coeff > 0)[0]
            if len(active_k) > 1:
                # The optimum is where two (or more) constraints are active and equal
                # For efficiency, just do a few bisection steps
                lo, hi = 0.0, f[j] * 3
                # Evaluate score at several points
                for _ in range(20):
                    mid = (lo + hi) / 2
                    # Compute max at mid
                    vals = coeff * mid + rest
                    max_val = np.max(vals)
                    # Subgradient: average of coeff at active set
                    active = np.isclose(vals, max_val, atol=1e-10)
                    subgrad = np.mean(coeff[active])
                    if subgrad > 0:
                        lo = mid
                    else:
                        hi = mid
                x_star = (lo + hi) / 2
                candidates.append(x_star)
            
            # Choose the best candidate
            best_x = f[j]
            best_max = np.max(c)
            for x_cand in candidates:
                f[j] = max(0, x_cand)
                c_new = rest + coeff * f[j]
                m = np.max(c_new)
                if m < best_max:
                    best_max = m
                    best_x = f[j]
            f[j] = best_x
            if f[j] != f[j]:  # This won't trigger, just for logic
                pass
            improved = True
        
        if not improved:
            break
    return f
```

- If j is in the range [max(0,k-n+1), min(n-1,k)], then a[j] appears as the first factor in the term i=j, giving a[k-j].
- If k-j is in the range [max(0,k-n+1), min(n-1,k)], then a[j] appears as the second factor in the term i=k-j, giving a[k-j].

So ∂c[k]/∂a[j] = a[k-j] * 1[j in range] + a[j] * 1[k-j in range]

If both j and k-j are in the valid range (which they are when 0 <= k-j < n and 0 <= j < n):
= a[k-j] + a[j]

If j = k-j (k = 2j), then it's actually just 2*a[j] (since it's the same term counted twice). But the formula gives a[j] + a[j] = 2a[j], which is correct.

So the subgradient of the peak at coordinate j is:
g[j] = (1/|A|) * sum_{k in A} (a[k-j] + a[j]) * 1[0 <= k-j < n]

This is a valid subgradient. We can use this for subgradient descent.

```python
Multi-strategy optimization for minimizing peak autocorrelation of
non-negative sequences. Uses LP with reduced constraints, analytic
subgradient descent, coordinate descent, and multi-start across lengths.

import numpy as np
import time
from scipy.optimize import linprog
from scipy.fft import rfft, irfft


def fft_convolve(a, b):
    """Full linear convolution via FFT."""
    n, m = len(a), len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    return irfft(rfft(a, size) * rfft(b, size), size)[:n + m - 1]


def score_fast(a):
    """Compute score = 2*n*max(conv(a,a))/(sum(a))^2."""
    a = np.asarray(a, dtype=np.float64)
    a = np.clip(a, 0.0, 1000.0)
    n = len(a)
    S = float(np.sum(a))
    if S < 0.01:
        return np.inf
    c = fft_convolve(a, a)
    return float(2.0 * n * np.max(c) / (S * S))


def build_A_sparse(f, top_k=None):
    """Build constraint matrix (reduced to top_k constraints if specified)."""
    n = len(f)
    c = fft_convolve(f, f)
    if top_k is not None and top_k < 2 * n - 1:
        idx = np.argsort(c)[-top_k:]
    else:
        idx = np.arange(2 * n - 1)
    
    A = np.zeros((len(idx), n), dtype=np.float64)
    for row, k in enumerate(idx):
        ki = int(k)
        lo = max(0, ki - (n - 1))
        hi = min(n - 1, ki)
        for j in range(lo, hi + 1):
            A[row, j] = f[ki - j]
    return A


def solve_lp_reduced(f, M, top_k=30, timeout=3.0):
    """Solve LP with only top_k most active constraints."""
    n = len(f)
    A = build_A_sparse(f, top_k)
    c_obj = -np.ones(n)
    b_ub = np.full(A.shape[0], M)
    try:
        res = linprog(c_obj, A_ub=A, b_ub=b_ub,
                      bounds=[(0, None)] * n,
                      method='highs',
                      options={'time_limit': timeout, 'presolve': True})
        if res.success:
            return res.x
    except Exception:
        pass
    return None


def peak_shave(f, n_steps=1000, verbose=False):
    """Iteratively reduce the peak by adjusting coordinates."""
    n = len(f)
    f = f.astype(np.float64).copy()
    best_f = f.copy()
    best_score = score_fast(f)
    
    for it in range(n_steps):
        c = fft_convolve(f, f)
        M = np.max(c)
        peak_lags = np.where(c >= 0.95 * M)[0]
        
        # For each peak lag, find the coordinates that contribute most
        for k in peak_lags:
            ki = int(k)
            # Contributions: f[j] * f[ki-j] for valid j
            lo = max(0, ki - (n - 1))
            hi = min(n - 1, ki)
            contribs = np.array([f[j] * f[ki - j] for j in range(lo, hi + 1)])
            
            # Reduce the top contributors
            top_count = max(2, len(contribs) // 5)
            top_idx_local = np.argsort(contribs)[-top_count:]
            
            for tl in top_idx_local:
                j = lo + int(tl)
                # Reduce f[j] slightly
                f[j] *= 0.95
                # Increase non-contributing coordinates
                # (coordinates that don't appear in any peak lag)
        
        # Renormalize
        S = np.sum(f)
        if S < 1e-10:
            break
        f = f / S
        
        if it % 100 == 0:
            s = score_fast(f)
            if s < best_score:
                best_score = s
                best_f = f.copy()
    
    return best_f, best_score
```

Let me check: c[k] = sum_j a[j]*a[k-j]. The matrix B_k has B_k[j,i] = 1 if j+i = k, 0 otherwise. This is a symmetric matrix. Is it PSD?

For B_k to be PSD, we need a^T B_k a >= 0 for all a. But a^T B_k a = sum_j a[j]*a[k-j]. For a non-negative vector a, this is always >= 0. But for a general vector a, it might not be.

Example: n=2, k=1. B_1 = [[0, 1], [1, 0]]. This has eigenvalues 1 and -1. So it's NOT PSD.

So max_k c[k] is NOT convex in general. This means we can't use standard convex optimization.

However, for our problem (a >= 0), the situation is different. On the domain a >= 0, c[k] = sum_j a[j]*a[k-j] >= 0 for all k, and the function is well-behaved.

OK let me just go with a practical approach. Here's my final plan:

1. Multiple initializations at multiple lengths
2. LP optimization with reduced constraints (most effective)
3. Subgradient polish
4. A simple "peak reduction" heuristic

"""
Multi-start LP + subgradient optimization for minimizing peak
self-convolution of non-negative sequences.
"""

import numpy as np
import time
from scipy.optimize import linprog
from scipy.fft import rfft, irfft


def fft_convolve(a, b):
    n, m = len(a), len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    return irfft(rfft(a, size) * rfft(b, size), size)[:n + m - 1]


def score_fast(a):
    a = np.asarray(a, dtype=np.float64)
    a = np.clip(a, 0.0, 1000.0)
    n = len(a)
    S = float(np.sum(a))
    if S < 0.01:
        return np.inf
    c = fft_convolve(a, a)
    return float(2.0 * n * np.max(c) / (S * S))


def make_init(n, init_type, rng):
    t = np.arange(n, dtype=np.float64)
    if init_type == 'ramp_up':
        a = t + 1.0
    elif init_type == 'ramp_down':
        a = n - t
    elif init_type == 'v_shape':
        a = np.abs(t - (n-1)/2.0) + 1.0
    elif init_type == 'hann':
        a = 0.5 * (1.0 + np.cos(2.0 * np.pi * t / max(1, n - 1)))
    elif init_type == 'triangle':
        a = 1.0 - np.abs(2.0 * t / max(1, n - 1) - 1.0)
    elif init_type == 'sin':
        a = 0.5 + 0.5 * np.sin(np.pi * t / max(1, n - 1))
    elif init_type == 'quad':
        a = ((t / max(1, n - 1)) ** 2) + 0.1
    elif init_type == 'sqrt':
        a = np.sqrt(t / max(1, n - 1)) + 0.1
    elif init_type == 'exp':
        a = np.exp(t / max(1, n - 1))
    else:
        a = np.ones(n)
    a += 0.05 * rng.standard_normal(n)
    return np.clip(a, 0.01, None)


def solve_lp_reduced(f, M, top_k, timeout):
    n = len(f)
    c = fft_convolve(f, f)
    if top_k < 2 * n - 1:
        idx = np.argsort(c)[-top_k:]
    else:
        idx = np.arange(2 * n - 1)
    
    A = np.zeros((len(idx), n), dtype=np.float64)
    for row_i, k in enumerate(idx):
        ki = int(k)
        lo = max(0, ki - (n - 1))
        hi = min(n - 1, ki)
        for j in range(lo, hi + 1):
            A[row_i, j] = f[ki - j]
    
    c_obj = -np.ones(n)
    b_ub = np.full(len(idx), M)
    try:
        res = linprog(c_obj, A_ub=A, b_ub=b_ub,
                      bounds=[(0, None)] * n,
                      method='highs',
                      options={'time_limit': timeout, 'presolve': True})
        if res.success:
            return res.x
    except Exception:
        pass
    return None

def subgrad_optimize(f_init, time_limit, lr=0.002, beta=0.92):

        g = np.zeros(n)

            ki = int(k)
            lo = max(0, ki - (n - 1))

    t0 = time.monotonic()

        S = float(np.sum(f))
        
        # Find peak lags
        peak_lags = np.where(c >= 0.9 * M)[0]
        
        # For each peak lag, identify contributing coordinates
        for k in peak_lags[:5]:  # Limit to top 5 peak lags
            ki = int(k)
            lo = max(0, ki - (n - 1))
            hi = min(n - 1, ki)
            valid_j = np.arange(lo, hi + 1)
            contribs = np.array([f[j] * f[ki - j] for j in valid_j])
            
            # Reduce top contributors
            n_reduce = max(2, len(valid_j) // 8)
            top_local = np.argsort(contribs)[-n_reduce:]
            
            for tl in top_local:
                j = int(valid_j[tl])
                factor = 1.0 - 0.02 - 0.02 * rng.random()
                f[j] = max(0.01, f[j] * factor)
            
            # Increase non-contributing coordinates (helps maintain sum and spread mass)
            non_contrib = np.setdiff1d(np.arange(n), valid_j)
            if len(non_contrib) > 0:
                n_incr = max(2, len(non_contrib) // 10)
                incr_idx = rng.choice(non_contrib, size=n_incr, replace=False)

            best_score = s
            best_f = f.copy()
    
    return best_f, best_score
