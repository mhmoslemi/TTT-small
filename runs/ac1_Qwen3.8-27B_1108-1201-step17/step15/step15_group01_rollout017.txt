dB/dm = (2m+3)/2
dC/dm = d/dm [(m+1)(m+2)(2m+3)/6] = [(2m+3)(m+2) + (m+1)(2m+3)*2 + (m+1)(m+2)*2]/6
= [(m+2)(2m+3) + 2(m+1)(2m+3) + 2(m+1)(m+2)]/6
= (m+2)[(2m+3) + 2(m+1)]/6 + 2(m+1)(m+2)/6
= (m+2)(4m+5)/6 + (m+1)(m+2)/3
= (m+2)[(4m+5) + 2(m+1)]/6
= (m+2)(6m+7)/6

B = (m+1)(m+2)/2

df/dm = n(n+1)/2 - (2m+3)(n+m+2)/2 - (m+1)(m+2)/2 + (m+2)(6m+7)/6

For large n, the dominant terms are:
n^2/2 - m*n - m^2 - ... + lower order terms

Setting to 0: n^2/2 ≈ m*n + m^2
For large n: m ≈ n/2 (roughly)

So the maximum of (a*a)[k] for k >= n-1 is at approximately k = n + n/2 = 3n/2.
