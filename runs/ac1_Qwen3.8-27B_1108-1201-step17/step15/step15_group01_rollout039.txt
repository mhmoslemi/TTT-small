`= 2 * a[j-i]`

(With the convention that `a[m] = 0` if `m < 0` or `m >= n`.)

`g[i] = 2 * a[j* - i]` for `i = 0, ..., n-1` (with `a[m] = 0` for `m` out of range).

This is just a reflected and flipped version of `a`! Specifically, `g[i] = 2 * a[j* - i]`.

So the subgradient optimization step would be:
1. Compute `c = a * a` (convolution)
2. Find `j* = argmax c`
3. Compute `g[i] = 2 * a[j* - i]` (flipped and shifted)
4. Project `a - step * g` onto the feasible set

The feasible set is `{a : a >= 0, sum(a) = sqrt(2n)}` (after normalization). The projection onto this set is the simplex projection.

This is essentially what the LP best-response does, but using the subgradient instead of the LP solution. def subgradient_nesterov(a0, time_limit, verbose=True):
    """Subgradient Nesterov method using top-k active constraints."""
    n = len(a0)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s0 = a.sum()
    if s0 < 1e-15:
        a = np.ones(n) * norm / n
    else:
        a = a * norm / s0

    best_a = a.copy()
    best_score = fast_conv(a).max()
    y = a.copy()
    t0 = time.monotonic()
    k = 20  # number of active constraints to use
    
    for t in range(1, 100000):
        if time.monotonic() - t0 > time_limit:
            break
        
        conv_y = fast_conv(y)
        M = conv_y.max()
        
        # Find top-k active constraints
        top_k = np.argsort(conv_y)[::-1][:k]
        
        # Subgradient: average of 2*y[j*-i] for active j*
        # The subgradient of max_j conv[y][j] at the max is 2*y[j*-i]
        # Using average of top-k for smoothness
        g = np.zeros(n)
        for j_star in top_k:
            # g[i] += 2 * y[j_star - i] if 0 <= j_star - i < n
            lo = max(0, j_star - n + 1)
            hi = min(n, j_star + 1)
            for i in range(lo, hi):
                g[i] += 2.0 * y[j_star - i]
        g /= k  # average
        
        # Normalize the direction
        g_norm = g.sum()
        if g_norm < 1e-15:
            break
        g = g * norm / g_norm
        
        # Nesterov update
        alpha = 2.0 / (t + 2.0)
        y_new = (1.0 - alpha) * y + alpha * g
        y_new = np.maximum(y_new, 0.0)
        s_y = y_new.sum()
        y_new = y_new * norm / s_y
        
        momentum = (t - 1.0) / (t + 2.0) if t > 1 else 0.0
        a_new = y_new + momentum * (y_new - y)
        a_new = np.maximum(a_new, 0.0)
        s_a = a_new.sum()
        a_new = a_new * norm / s_a
        
        y = y_new
        a = a_new
        
        score = fast_conv(a).max()
        if score < best_score:
            best_score = score

Let me also think about whether the Nesterov momentum is correct. The standard Nesterov accelerated gradient method is:

```
t_k = (1 + sqrt(1 + 4*t_{k-1}^2)) / 2
x_{k+1} = x_k + (t_{k-1} - 1) / t_{k+1} * (x_k - x_{k-1})
y_{k+1} = x_{k+1} - grad step
```

But in the game-theoretic setting, the update is different. The_ODE viewpoint suggests:
```
y_{k+1} = (1 - 2/(t+2)) * y_k + 2/(t+2) * g_k
x_{k+1} = y_{k+1} + (t-1)/(t+2) * (y_{k+1} - y_k)
```

This is what the previous code uses, and it's a valid Nesterov-type acceleration. The convergence rate is O(1/t) for the gap.

One potential issue: the "best response" `g_k` is not the true gradient of a convex function (it's the solution of an LP). So the convergence guarantees of standard Nesterov don't directly apply. But empirically, it works well.

Let me also consider: what if we use a **damped** Nesterov (reduce the momentum when close to convergence)? This might help with the last bit of improvement.

```
mu = min((t-1)/(t+2), max_mu)
```

Where `max_mu` is like 0.9. This prevents oscillations when close to the optimum.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Full-constraint LP best-response with Nesterov acceleration (primary)
2. Smooth log-sum-exp gradient optimization (secondary)
3. Coordinate descent polishing
4. Multi-length exploration with interpolation
Key improvements over prior: full LP (all 2n-1 constraints) for accurate
best-response, damped momentum, adaptive temperature schedule, and
structured coordinate descent for final polishing.
"""

import numpy as np
import cvxpy as cp
import time
from scipy.fft import rfft, irfft


def fast_conv(a):
    """Compute self-convolution a*a using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]


def project_simplex(v, S):
    """Project v onto {x >= 0, sum(x) = S}."""
    n = len(v)
    if n == 0:
        return v
    v_sorted = np.sort(v)[::-1]
    css = np.cumsum(v_sorted)
    rho = np.where(v_sorted * np.arange(1, n + 1) > (css - S))[0]
    if len(rho) == 0:
        return np.zeros(n)
    rho = rho[-1]
    theta = (css[rho] - S) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def build_T(a):
    """Build convolution matrix T: (T@b)[j] = sum_i a[j-i]*b[i]."""
    n = len(a)
    size = 2 * n - 1
    T = np.zeros((size, n))
    for i in range(n):
        T[i:i + n, i] = a
    return T


def evaluate_safe(a):
    """Safely evaluate a sequence."""
    try:
        a_list = [float(x) for x in a]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')


def get_best_solver():
    """Find the best available LP solver."""
    for s in [cp.Clarabel, cp.MOSEK, cp.ECOS, cp.SCS]:
        try:
            x = cp.Variable(5, nonneg=True)
            prob = cp.Problem(cp.Minimize(cp.sum(x)), [cp.sum(x) == 1])
            prob.solve(solver=s)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                print(f"  LP solver: {s}")
                return s
        except Exception:
            pass
    print("  LP solver: SCS (fallback)")
    return cp.SCS


def solve_lp_full(T, M, n, solver):
    """Solve LP: max sum(b) s.t. T@b <= M, b >= 0."""
    b_var = cp.Variable(n, nonneg=True)
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), [T @ b_var <= M])
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        return None
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None
    b = np.asarray(b_var.value, dtype=np.float64)
    b = np.maximum(b, 0.0)
    if b.sum() < 1e-15:
        return None
    return b


def nesterov_lp_full(a0, time_budget, solver, verbose=True):
    """Nesterov-accelerated LP best-response with ALL constraints."""
    n = len(a0)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) * norm / n
    else:
        a = a * norm / s

    best_a = a.copy()
    best_m = fast_conv(a).max()
    y = a.copy()
    t_start = time.monotonic()
    it = 0
    fail = 0
    avg_a = np.zeros(n)
    n_avg = 0

    while time.monotonic() - t_start < time_budget:
        it += 1
        cv = fast_conv(y)
        M = cv.max()
        if M < 1e-14:
            break

        T = build_T(y)
        b = solve_lp_full(T, M, n, solver)
        if b is None:
            fail += 1
            if fail > 300:
                break
            continue
        fail = 0

        g = b * norm / b.sum()

        # Nesterov update with damping
        alpha = 2.0 / (it + 2.0)
        y_new = (1.0 - alpha) * y + alpha * g
        y_new = np.maximum(y_new, 0.0)
        sy = y_new.sum()
        if sy > 1e-15:
            y_new *= norm / sy

        if it == 1:
            a_new = g.copy()
        else:
            # Damped momentum: cap at 0.95 to avoid oscillation
            mu = min((it - 1.0) / (it + 2.0), 0.95)
            a_new = y_new + mu * (y_new - y)
            a_new = np.maximum(a_new, 0.0)
            sa = a_new.sum()
            if sa > 1e-15:
                a_new *= norm / sa
            else:
                a_new = y_new.copy()

        y = y_new
        a = a_new

        m_y = fast_conv(y).max()
        if m_y < best_m:
            best_m = m_y
            best_a = y.copy()
        m_a = fast_conv(a).max()
        if m_a < best_m:
            best_m = m_a
            best_a = a.copy()

        # Running average (can smooth out oscillations)
        avg_a += a
        n_avg += 1
        if n_avg % 200 == 0:
            avg_check = avg_a / n_avg
            sa_avg = avg_check.sum()
            if sa_avg > 1e-15:
                avg_check = avg_check * norm / sa_avg
                m_avg = fast_conv(avg_check).max()
                if m_avg < best_m:
                    best_m = m_avg
                    best_a = avg_check.copy()

        if verbose and it % 50 == 0:
            elapsed = time.monotonic() - t_start
            print(f"  LP-Nest(it={it}, t={elapsed:.0f}s): max_conv={best_m:.8f}, score_est={2*n*best_m/norm**2:.6f}")

    return best_a, best_m

    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) * norm / n
    else:
        a = a * norm / s

    best_a = a.copy()
    best_m = fast_conv(a).max()
    y = a.copy()
    t_start = time.monotonic()
    it = 0
    fail = 0

        M = cv.max()
        if M < 1e-14:
            break

        T = build_T(y)
        # Use top fraction of constraints

        top_idx = np.argsort(cv)[::-1][:n_cons]

        b_var = cp.Variable(n, nonneg=True)
        prob = cp.Problem(cp.Maximize(cp.sum(b_var)), [T[top_idx] @ b_var <= M])
        try:

        except Exception:
            fail += 1
            if fail > 200:
                break
            continue
        if prob.status not in ('optimal', 'optimal_inaccurate'):
            fail += 1
            if fail > 200:
                break
            continue

        b = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
        if b.sum() < 1e-15:
            fail += 1
            if fail > 200:
                break
            continue
        fail = 0

        g = b * norm / b.sum()
        alpha = 2.0 / (it + 2.0)

        if verbose and it % 100 == 0:

def smooth_optimize(a0, time_budget, verbose=True):
    """Smooth log-sum-exp gradient optimization with adaptive temperature."""
    n = len(a0)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) * norm / n
    else:
        a = a * norm / s

    best_a = a.copy()
    best_m = fast_conv(a).max()
    t_start = time.monotonic()
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()

    # Adaptive temperature schedule
    temps = [20.0, 10.0, 5.0, 2.5, 1.0, 0.5, 0.25, 0.1, 0.05, 0.02, 0.01, 0.005, 0.002, 0.001]

    for T_t in temps:
        if time.monotonic() - t_start > time_budget:
            break
        rem = time_budget - (time.monotonic() - t_start)
        if rem < 0.3:
            break
        n_steps = max(30, min(300, int(rem * 4)))

        for step in range(n_steps):
            if time.monotonic() - t_start > time_budget:
                break

            cv = fast_conv(a)
            c_max = cv.max()
            scaled = (cv - c_max) / T_t
            scaled = np.clip(scaled, -80, 80)
            exp_c = np.exp(scaled)
            w = exp_c / exp_c.sum()

            # Gradient: d/d a[i] of log-sum-exp = sum_k w[k] * d(conv[k])/d(a[i])
            # d(conv[k])/d(a[i]) = 2*a[k-i] (with bounds)
            # So grad[i] = 2 * sum_k w[k] * a[k-i]
            # = 2 * (cross_correlation of w and a)[i]
            W = rfft(w, fft_size)
            A = rfft(a, fft_size)
            cross = irfft(np.conj(W) * A, fft_size)[:n]
            grad = 2.0 * cross

            # Adaptive step size with backtracking
            step_size = norm / (2.0 * n * max(T_t, 0.01))
            for _bt in range(10):
                a_new = project_simplex(a - step_size * grad, norm)
                m_new = fast_conv(a_new).max()
                if m_new < best_m + 0.01 * T_t:
                    break
                step_size *= 0.5

            a = a_new
            m = fast_conv(a).max()
            if m < best_m:
                best_m = m
                best_a = a.copy()

        if verbose:
            elapsed = time.monotonic() - t_start
            print(f"  Smooth(T={T_t:.3f}, t={elapsed:.0f}s): max_conv={best_m:.8f}")

    return best_a, best_m


def coord_descent(a0, time_budget, rng, verbose=True):
    """Coordinate descent: move mass between positions to reduce max convolution."""
    n = len(a0)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return a, float('inf')
    a = a * norm / s

    best_a = a.copy()
    best_m = fast_conv(a).max()
    t_start = time.monotonic()
    stuck = 0
    offsets = [1, 2, 3, 5, 8, 13, 21]
    fracs = [0.5, 0.25]

    while time.monotonic() - t_start < time_budget:
        if stuck >= 4:
            break
        pass_improved = False
        perm = rng.permutation(n)

        for i in perm:
            if time.monotonic() - t_start > time_budget:
                break
            if a[i] < 1e-13 * norm:
                continue

            orig = a.copy()
            found = False
            for frac in fracs:
                if found:
                    break
                d = orig[i] * frac
                if d < 1e-15:
                    continue
                for off in offsets:
                    if found:
                        break
                    for j in [(i + off) % n, (i - off) % n]:
                        if j == i:
                            continue
                        a_test = orig.copy()
                        a_test[i] = orig[i] - d
                        a_test[j] = orig[j] + d
                        if a_test[i] < -1e-15:
                            continue
                        a_test = a_test * norm / a_test.sum()
                        m = fast_conv(a_test).max()
                        if m < best_m - 1e-14:
                            a = a_test.copy()
                            best_m = m
                            best_a = a.copy()
                            pass_improved = True
                            found = True
                            break

        stuck = 0 if pass_improved else stuck + 1
        if verbose:
            elapsed = time.monotonic() - t_start
            print(f"  CD(t={elapsed:.0f}s): max_conv={best_m:.8f}")

    return best_a, best_m


def interpolate_to_length(a, new_n):
    """Interpolate a sequence to a different length, preserving normalization."""
    old_n = len(a)
    if old_n == new_n:
        return a.copy()
    s = a.sum()
    if s < 1e-15:
        return np.ones(new_n) * (np.sqrt(2.0 * new_n) / new_n)
    a_norm = a / s
    old_x = np.linspace(0.0, 1.0, old_n, endpoint=False)
    new_x = np.linspace(0.0, 1.0, new_n, endpoint=False)
    a_interp = np.interp(new_x, old_x, a_norm)
    a_interp = np.maximum(a_interp, 0.0)
    ss = a_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) * (np.sqrt(2.0 * new_n) / new_n)
    return a_interp * np.sqrt(2.0 * new_n) / ss
