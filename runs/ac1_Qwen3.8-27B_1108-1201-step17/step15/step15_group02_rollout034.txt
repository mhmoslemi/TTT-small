One approach: use the fact that the problem is equivalent to finding a vector `a` such that `B_k a <= M` for all k, where `B_k` is the symmetric matrix for the k-th convolution lag. This is a system of quadratic inequalities.

Another thought: what if the optimal sequence has a specific parametric form? Like `a[i] = f(i/n)` for some smooth function f? Then the self-convolution would be approximately `n * (f * f)(k/n)` (a scaled version of the continuous convolution), and we'd want `f * f` to be as flat as possible.

For a continuous function f on [0,1], the self-convolution `(f*f)(t) = ∫ f(s) f(t-s) ds` (with appropriate integration limits). We want this to be as flat as possible.

If f is the indicator of [0,1], then f*f is the triangular function, which peaks at t=1.
If f is a "hat" function (tent), then f*f is a "parabolic" function.
If f is a Gaussian, then f*f is a wider Gaussian.

None of these give a flat convolution. To get a flat convolution, we'd need f to be "as random as possible" while being non-negative.

Actually, for a periodic function, the convolution is related to the autocorrelation in the frequency domain. A flat time-domain autocorrelation corresponds to a flat frequency-domain power spectrum. For a non-negative function, this is related to the "allpass" filter concept.
