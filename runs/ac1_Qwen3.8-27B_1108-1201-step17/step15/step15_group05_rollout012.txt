For a geometric sequence a_i = r^i (i=0,...,n-1) with 0 < r < 1:
conv[k] = sum_{i=max(0,k-n+1)}^{min(k,n-1)} r^i * r^{k-i} = r^k * (min(k,n-1) - max(0,k-n+1) + 1)

For 0 <= k <= n-1: conv[k] = (k+1) * r^k
For n <= k <= 2n-2: conv[k] = (2n-1-k) * r^k

The first part (k+1)*r^k is maximized at k ≈ 1/(1-r) (for large n, ignoring the boundary at k=n-1).
The value at the peak: approximately (1/(1-r)) * r^{1/(1-r)} = (1/(1-r)) * e^{-1/(1-r) * (1-r)/(1+r)}... 

Actually, (k+1)*r^k is maximized when d/dk [(k+1)r^k] = 0:
r^k + (k+1)r^k * ln(r) = 0
1 + (k+1) ln(r) = 0
k+1 = -1/ln(r) = 1/(-ln(r))

For r close to 1, -ln(r) ≈ 1-r, so k+1 ≈ 1/(1-r).
Peak value ≈ (1/(1-r)) * e^{-1/(1-r) * (-ln r)}...
