```python
    """Build the convolution matrix A where (A @ b)[k] = conv(a,b)[k]."""
    n = len(a)

    # A[k, j] = a[k-j] if 0 <= k-j < n, else 0
    k_vals = np.arange(2*n-1)[:, None]

    A = np.where(valid, a[diff_clipped], 0.0)

def project_simplex(v):
    """Project v onto the simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]

    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
```

**Approach: Iterative Peak Shaving with Momentum**

1. Compute c = conv(a, a)
2. Find the top-K peaks in c
3. For each peak at position k, compute the "contribution vector" v_k where v_k[j] = a[k-j] (valid indices)
4. The "pressure" on a_j is the weighted sum of v_k[j] over all peaks k
5. Update: a_j ← a_j * exp(-lr * pressure_j)
6. Renormalize
7. Repeat

This is similar to the multiplicative weights / exponentiated gradient method. It's always positive and naturally handles the non-negativity constraint.

Let me implement this:

```python
def exp_gradient_step(a, lr, top_k=10):
    c = np.convolve(a, a)
    max_c = c.max()
    # Find top-k peaks
    top_positions = np.argsort(c)[::-1][:top_k]
    
    # Compute pressure
    n = len(a)
    pressure = np.zeros(n)
    for k in top_positions:
        weight = c[k] - max_c * 0.5  # weight peaks more heavily
        if weight <= 0:
            weight = max_c * 0.1
        valid_j = np.arange(max(0, k - n + 1), min(n, k + 1))
        pressure[valid_j] += weight * a[k - valid_j]
    
    a_new = a * np.exp(-lr * pressure / pressure.max())
    a_new = np.maximum(a_new, 1e-10)
    a_new = a_new / a_new.sum()
    return a_new
```

Actually, for the convolution, the peak is at the center of the convolution (position n-1), and the value there is sum(a_i^2). To reduce this, we want to SPREAD the mass, not concentrate it. So a flat or U-shaped distribution is better.

But we also need to consider the off-center peaks. A U-shaped distribution (high at edges, low in center) might have lower off-center peaks.

a_i = 1 + cos(2*pi*i/n) (for i = 0, ..., n-1)
This is high at i=0 and i=n/2, low at i=n/4 and i=3n/4.

Or: a_i = 1 - 0.5*cos(2*pi*i/n) (high at i=0, low at i=n/2).

These break the left-right symmetry and might lead to better convolution profiles.
