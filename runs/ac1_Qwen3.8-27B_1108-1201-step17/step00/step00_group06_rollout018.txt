min d^T y
s.t. A^T y >= c
     y >= 0

The dual has 2n-1 variables and n constraints. The constraint A^T y >= c means:
sum_k A[k,j] * y[k] >= 1 for each j

A[k,j] = f[k-j] if 0 <= k-j < n, else 0.

So the j-th dual constraint is:
sum_k f[k-j] * y[k] >= 1 (for valid k, j)
= sum_i f[i] * y[i+j] >= 1 (substituting i = k-j)
= (f * y)[j] >= 1 (where y is extended with zeros)

So the dual is:
min sum_k M * y[k] = M * sum(y)
s.t. (f * y)[j] >= 1 for j = 0, ..., n-1
     y >= 0

This is equivalent to:
min sum(y)
s.t. (f * y)[j] >= 1 for j = 0, ..., n-1
     y >= 0

(We absorbed M into the objective since it's a constant.)

= sum(b) - (y^T A) b + M * sum(y) + z^T b
= b^T (1 - A^T y + z) + M * sum(y)

The dual has 2n-1 variables and n constraints. The constraint matrix for the dual is again a convolution matrix, but now it's n x (2n-1).

This is a feasibility/optimization problem with 2n-1 variables and n inequality constraints.

By strong duality, the optimal value of the primal (max sum(b)) equals the optimal value of the dual (min M * sum(y)).

**The problem with subgradient method:**
The subgradient method converges to a local minimum of M(a). Since the uniform sequence is a local minimum with M = 1/n (when sum=1), the subgradient method might converge to the uniform sequence if started close to it.

To avoid this, I need to:
1. Start from a sequence far from uniform
2. Use a large enough step size to "jump over" the barrier
3. Use multiple restarts

**What does the landscape look like?**
- Uniform sequence: local min, score = 2
- Global min: score ≈ 1.00009 (for large n)
- There must be a "saddle" or "barrier" between them

The barrier height is probably not too high (since the target 1.5027 is achievable), so a large step size or a good initialization should overcome it.
