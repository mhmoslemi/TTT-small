Key insight I haven't fully exploited: the problem is equivalent to finding a non-negative sequence whose self-convolution is as flat as possible. This is a well-studied problem in signal processing.

One powerful technique is the "iterative projection" method (also known as the POCS - Projection Onto Convex Sets algorithm):
1. Start with a random (or given) non-negative sequence a.
2. Compute b = conv(a, a).
3. Replace b with min(b, M) where M = max(b) (or better, replace with the "flattened" version).
4. Find the new a such that conv(a, a) = flattened_b. This is a non-convex feasibility problem.

A simpler version:
1. Compute b = conv(a, a).
2. Flatten b: b_flat = (1 - alpha) * b + alpha * mean(b) for some alpha in (0,1).
3. Find a_new such that conv(a_new, a_new) ≈ b_flat. This can be done by taking the "square root" in the frequency domain: a_new = IFFT(sqrt(FFT(b_flat))).
4. Take the real part and clip to non-negative.
5. Repeat.

This is the Gerchberg-Saxton algorithm (or its variant for this problem)! It's used in phase retrieval and should work well here.

Let me implement this:

```python
def gs_iteration(a, alpha=0.5):
    """One Gerchberg-Saxton iteration for flattening the convolution."""
    n = len(a)

    # So FFT(a) = sqrt(FFT(b_target))
```

Wait, there's an issue. The FFT of conv(a, a) is not exactly FFT(a)^2 due to the finite length. We need to zero-pad properly.

If a has length n, and we zero-pad to length N >= 2n-1, then:
FFT(N)(conv(a, a)) = FFT(N)(a) * FFT(N)(a) (pointwise product)

This is because the zero-padding makes it a "linear" convolution in the time domain, which corresponds to pointwise multiplication in the frequency domain.

So the algorithm is:
1. Zero-pad a to length N >= 2n-1.
2. Compute A = FFT(N)(a_padded).
3. Compute B = A * A (pointwise). This is the FFT of the zero-padded convolution.
4. The first 2n-1 elements of IFFT(N)(B) are conv(a, a).
5. To "flatten": modify B to be flatter in the time domain.
6. Take square root: A_new = sqrt(B_modified).
7. a_new = IFFT(N)(A_new)[:n].

The key question is: how to modify B to make the time-domain signal flatter?

One approach: In the time domain, flatten b by taking min(b, M) where M is some threshold. Then go back to frequency domain.

But this is exactly what the Gerchberg-Saxton algorithm does:
- Amplitude constraint in time domain: b should be as flat as possible (or at most M).
- Phase constraint in frequency domain: A should be such that IFFT(A) is non-negative (i.e., A = |A|, the phase is 0).

The GS iteration alternates between:
1. Time domain: enforce that b (the convolution) is flat (or has bounded peak).
2. Frequency domain: enforce that a (the inverse FFT of sqrt(B)) is non-negative.

Let me implement this more carefully:

```python
def gs_step(a, peak_limit=None, alpha=0.0):
    """One GS iteration.
    
    args:
        a: current sequence (length n)
        peak_limit: if set, clip the convolution to this value
        alpha: flattening parameter (0 = no flattening, 1 = completely flat)
    """
    n = len(a)
    N = 2 * n - 1
    N_fft = 1 << (N - 1).bit_length()  # Next power of 2
    
    # Forward FFT
    A = np.fft.rfft(a, N_fft)
    B = A * A  # Power spectrum (this is FFT of conv(a,a) zero-padded to N_fft)
    
    # Inverse FFT to get convolution
    b = np.fft.irfft(B, N_fft)[:N]  # Length 2n-1
    
    # Modify b: flatten or clip
    if peak_limit is not None:
        b = np.minimum(b, peak_limit)
    if alpha > 0:
        b = (1 - alpha) * b + alpha * np.mean(b)
    
    # Ensure b is non-negative (it should be, but numerical errors)
    b = np.maximum(b, 0)
    
    # Forward FFT again
    B_new = np.fft.rfft(b, N_fft)
    
    # Take square root (this is the "amplitude" constraint in freq domain)
    # B_new should be non-negative if b is a valid convolution of a real signal with itself
    # But after modification, it might have negative values
    A_new = np.sqrt(np.maximum(B_new, 0))
    
    # Inverse FFT
    a_new = np.fft.irfft(A_new, N_fft)[:n]
    
    # Enforce non-negativity
    a_new = np.maximum(a_new, 0)
    
    # Renormalize
    S = a_new.sum()
    if S > 0:
        a_new = a_new / S
    else:
        a_new = np.ones(n) / n
    
    return a_new
```

Wait, I'm concerned that the GS batch might not be efficient enough. Let me check: each GS step does 3 FFTs of size ~16384. With numpy, an FFT of size 16384 takes about 50-100 microseconds. So 3 FFTs ≈ 150-300 microseconds per step. For 500 steps per batch, that's 75-150 ms per batch. Plus the evaluate_sequence call which takes ~30ms. So total ~100-200ms per batch.

In 1800 seconds, that's about 9000-18000 batches, or 4.5M-9M GS steps. That's a lot!

But wait, I should also consider the overhead of the Python loop in _gs_batch. Each iteration of the loop has some Python overhead (~1-5 microseconds). For 500 iterations, that's 0.5-2.5 ms. Negligible compared to the FFT time.

OK so the GS approach should be fast enough. Let me also add a "simulated annealing" component: occasionally accept a worse solution to escape local minima.

Actually, let me reconsider the GS parameters. The key question is: what clip level should I use?

If I set clip = max_b (the current maximum), the GS iteration does nothing (the clip doesn't change b). I need to set clip < max_b to make progress.

But if I set clip too low, the "flattened" b might not be a valid convolution of any non-negative sequence, and the GS algorithm might oscillate or converge to a bad solution.

A good strategy: set clip to a fraction of the current max, say 0.99 * max_b. This ensures the algorithm always makes progress (the peak is reduced by at least 1%) but doesn't over-constrain.

Let me also add a "momentum" to the GS: instead of fully replacing a with the new iterate, use a = (1-t)*a_old + t*a_new for some t in (0,1]. This can help with convergence.

import numpy as np
import time

def _gs_step(a, clip, alpha, damping=1.0):
    """
    Single GS iteration with damping.
    
    Parameters:
        a: input array (length n, non-negative, sum=1)
        clip: max allowed value of conv(a,a) (or None for no clip)
        alpha: flattening parameter (0 to 1)
        damping: mixing parameter (1.0 = full update, <1 = damped)
    """
    n = len(a)
    N = 2 * n - 1
    Nf = 1 << (N - 1).bit_length()
    
    # Time domain: compute convolution
    A = np.fft.rfft(a, Nf)
    B = A * A
    b = np.fft.irfft(B, Nf)[:N]
    
    # Modify b
    if clip is not None:
        np.minimum(b, clip, out=b)
    if alpha > 0:
        flat = b.sum() / N
        b *= (1.0 - alpha)
        b += alpha * flat
    np.maximum(b, 0.0, out=b)
    
    # Frequency domain: square root
    B2 = np.fft.rfft(b, Nf)
    np.maximum(B2, 0.0, out=B2)
    A2 = np.sqrt(B2)
    a_new = np.fft.irfft(A2, Nf)[:n]
    
    # Non-negativity
    np.maximum(a_new, 0.0, out=a_new)
    
    # Damping
    if damping < 1.0:
        a_new = damping * a_new + (1.0 - damping) * a
    
    # Normalize
    s = a_new.sum()
    if s > 1e-10:
        a_new /= s
    else:
        a_new = np.ones(n) / n
    
    return a_new
