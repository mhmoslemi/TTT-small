```python
    # The delta means l = j+i (mod L). Since L > n + max(l), no wraparound.
    # = sum_j a[j] u[j+i]
    # ✓
    
    result = np.fft.irfft(np.conj(A) * U, L)
    return 2 * result[:n]
```

Wait, I need to be careful. The FFT length L should be at least n + len(u) - 1 to avoid circular wraparound. If u has length 2n-1, then L >= n + 2n-1-1 = 3n-2. So L = 4n (or next power of 2 above 3n) is safe.

For n = 5582, L = 22328, next power of 2 = 32768. FFT of size 32768 is very fast (~0.1ms).
