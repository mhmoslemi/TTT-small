**Idea: Use the fact that the constraint matrix T is a "Toeplitz-like" matrix**

The matrix T has T[k,i] = a[k-i] if 0 <= k-i < n, else 0. This is NOT exactly Toeplitz (it's a "hankel" or "convolution" matrix), but it has a special structure that can be exploited.

Specifically, T @ b = full_convolution(a, b) (first 2n-1 elements). So computing T @ b is O(n log n) via FFT.

The LP best response: max sum(b) s.t. T @ b <= M, b >= 0.

We can solve this with:
1. Interior point method (O(n^3) worst case, but often faster in practice)
2. Simplex method (exponential worst case, but good in practice)
3. Approximate methods (multiplicative weights, cutting plane)

For n=1600, cvxpy with a good solver should handle this in ~50-200ms.

The issue is that in the Nesterov scheme, we need to solve this LP at each iteration, and we need O(n) or O(n^2) iterations for good convergence.

**Alternative: Use a "lazy" LP**

Instead of solving the LP to optimality at each iteration, solve it approximately (e.g., with a few steps of multiplicative weights on the dual). This gives an approximate best response, which is sufficient for the Nesterov scheme.

**Let me design the new algorithm:**

= conv[k] + delta * sum_m (-1[m=i] + 1[m=j]) * a[k-m] + delta * sum_m a[m] * (-1[k-m=i] + 1[k-m=j]) + O(delta^2)
= conv[k] + delta * (-a[k-i] + a[k-j] + a[i-k] + a[j-k]) + O(delta^2)
= conv[k] + delta * (a[k-j] + a[j-k] - a[k-i] - a[i-k]) + O(delta^2)

Where a[x] = 0 if x is out of [0, n-1].

So the first-order change in conv[k] is:
deltaconv[k] = delta * (a[k-j] + a[j-k] - a[k-i] - a[i-k])

Let g_{ij}[k] = a[k-j] + a[j-k] - a[k-i] - a[i-k]

Then conv'[k] ≈ conv[k] + delta * g_{ij}[k]

We want to find delta in [0, a[i]] that minimizes max_k (conv[k] + delta * g_{ij}[k]).

This is a 1D optimization problem! We can solve it with binary search or by finding the intersection points.

The function f(delta) = max_k (conv[k] + delta * g_{ij}[k]) is a convex piecewise-linear function of delta (each term conv[k] + delta * g_{ij}[k] is linear in delta, and max of linear functions is convex piecewise-linear).

We can find the minimum by:
1. Evaluating f at delta = 0 and delta = a[i]
2. If f(a[i]) < f(0), the minimum is at delta = a[i] or somewhere in between
3. Binary search for the minimum

For the binary search, evaluating f(delta) takes O(n) (compute all 2n-1 values and take max). Binary search takes O(log(a[i]/eps)) evaluations.

For n=1600, each evaluation is O(n) = O(1600). Binary search takes ~20 evaluations. So each pair takes ~32000 operations. For O(n^2) pairs, that's ~1600^2 * 32000 = 8 * 10^10 operations. Way too slow!

We need to be smarter. Options:
1. Only try a subset of pairs (e.g., top 100 donors x top 100 recipients = 10000 pairs)
2. Use a fast approximation for the optimal delta (e.g., first-order: delta* = argmin of the linear approximation)
3. Use FFT to compute the max faster

Actually, for the first-order approximation:
f(delta) ≈ max_k (conv[k] + delta * g_{ij}[k])

The minimum of this piecewise-linear function is at a "kink" where two terms are equal and both are the maximum. We can find it by:
- Computing the slope at delta=0: this is g_{ij}[k_max] where k_max = argmax(conv)
- If slope < 0, increase delta; if slope > 0, decrease (can't, since delta >= 0)
- Find the delta where the slope changes sign

A simpler approach: just evaluate f at delta=0 and delta=a[i], and if f(a[i]) < f(0), try delta = a[i]/2, etc. (ternary search with a few iterations).

Or even simpler: use a grid of 10-20 delta values and pick the best.

**For the "top donors x top recipients" approach:**
- Compute g_i (subgradient) for all i
- Sort: top_D donors (highest g_i), top_R recipients (lowest g_i)
- Try all D*R pairs
- For each pair, evaluate f at 10 delta values
- Total: D*R*10*O(n) = 100*100*10*1600 = 1.6*10^7 per pass

That's feasible! In numpy, this should take maybe 0.1-1 seconds per pass.

def fast_autocorr(a):
    """Compute full autocorrelation using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a.astype(np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]

def build_conv_matrix(a):
    """Build the convolution matrix T where (T @ b) = full_conv(a, b)."""
    n = len(a)
    size = 2 * n - 1
    T = np.zeros((size, n))
    for j in range(n):
        T[j:j+n, j] = a
    return T

def lp_best_response(a, M, solver):
    """Solve the LP: max sum(b) s.t. T@a_conv b <= M, b >= 0."""
    n = len(a)
    size = 2 * n - 1
    b_var = cp.Variable(n, nonneg=True)
    T = build_conv_matrix(a)
    constraints = [T @ b_var <= M]
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)

        prob.solve(solver=solver, verbose=False)

        return None
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None
    b_val = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
    return b_val

def build_conv_matrix(a):
    n = len(a)
    size = 2 * n - 1
    T = np.zeros((size, n))
    for j in range(n):

def lp_best_response_full(a, M, solver):

def systematic_pair_cd(a0, time_limit, verbose=True):
    """
    Systematic pair coordinate descent with precomputed shift vectors.
    Key: precompute F[m,k]=a[k-m] and G[m,k]=a[m-k] for fast g_ij computation.
    Update in O(n) after each successful move.
    """
    n = len(a0)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return a, float('inf')
    a = a * norm / s

    size = 2 * n - 1
    conv = fast_autocorr(a)
    best_score = conv.max()
    best_a = a.copy()
    t0 = time.monotonic()

    # Precompute F and G
    F = np.zeros((n, size))
    G = np.zeros((n, size))

    def update_FG(a):
        F[:, :] = 0.0
        G[:, :] = 0.0
        for m in range(n):
            F[m, m:m + n] = a
        a_rev = a[::-1]
        for m in range(n):
            start = n - 1 - m
            G[m, start:start + n] = a_rev

    update_FG(a)

    def update_FG_partial(i, delta_i, j, delta_j):
        """Update F and G after a[i]+=delta_i and a[j]+=delta_j in O(n)."""
        # F[m, m+i] = a[i], valid for m=0..n-1-i
        for m in range(n - i):
            F[m, m + i] += delta_i
        # G[m, m-i] = a[i], valid for m=i..i+n-1
        for m in range(i, i + n):
            G[m, m - i] += delta_i
        # Same for j
        for m in range(n - j):
            F[m, m + j] += delta_j
        for m in range(j, j + n):
            G[m, m - j] += delta_j

    n_passes = 0
    no_improve = 0
    D = min(60, max(20, n // 25))
    R = min(60, max(20, n // 25))
    total_moves = 0

    while time.monotonic() - t0 < time_limit:
        n_passes += 1
        pass_improved = False
        moves_this_pass = 0

        k_star = int(np.argmax(conv))
        subgrad = 2.0 * (F[:, k_star] + G[:, k_star])

        order = np.argsort(subgrad)
        donors = order[n - D:]
        recipients = order[:R]

        for i in donors:
            if time.monotonic() - t0 > time_limit:
                break
            a_i = a[i]
            if a_i < norm * 1e-7:
                continue

            for j in recipients:
                if i == j or j == i:
                    continue
                if a[j] >= a_i and subgrad[j] >= subgrad[i]:
                    continue

                g_ij = F[j] + G[j] - F[i] - G[i]

                # Find best delta
                best_d = 0.0
                best_val = conv[k_star]
                a_i_val = a[i]
                n_eval = 10
                step = a_i_val / n_eval
                for d_idx in range(1, n_eval + 1):
                    d = d_idx * step
                    new_peak = (conv + d * g_ij).max()
                    if new_peak < best_val - 1e-12:
                        best_val = new_peak
                        best_d = d

                if best_d > 1e-12 * a_i_val:
                    a[i] -= best_d
                    a[j] += best_d
                    a = np.maximum(a, 0.0)
                    s_a = a.sum()
                    if s_a < 1e-15:
                        a[i] += best_d
                        a[j] -= best_d
                        continue
                    a = a * norm / s_a
                    conv = fast_autocorr(a)
                    cur = conv.max()
                    if cur < best_score - 1e-12:
                        best_score = cur
                        best_a = a.copy()
                        pass_improved = True
                        no_improve = 0
                        moves_this_pass += 1
                        total_moves += 1
                        update_FG_partial(i, -best_d, j, best_d)
                    else:
                        a[j] -= best_d
                        a[i] += best_d
                        a = a * norm / a.sum()
                        conv = fast_autocorr(a)
                        update_FG_partial(i, best_d, j, -best_d)

        if verbose and n_passes % 10 == 0:
            elapsed = time.monotonic() - t0
            print(f"    SPCD pass={n_passes} ({elapsed:.0f}s): best={best_score:.8f}, total_moves={total_moves}")

        if not pass_improved:
            no_improve += 1
            if no_improve >= 8:
                break
        else:
            no_improve = 0

    return best_a, best_score

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n)
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n)
    return f_interp / ss
