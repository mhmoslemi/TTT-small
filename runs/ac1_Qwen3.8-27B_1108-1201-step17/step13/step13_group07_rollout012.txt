def peak_equalization(a, n_peaks=5, n_iter=10000):
    n = len(a)
    a = a / a.sum()
    best_a = a.copy()
    best_score = internal_score(a)
    
    for it in range(n_iter):
        b = fast_autocorr(a)
        top_idx = np.argsort(b)[::-1][:n_peaks]
        top_vals = b[top_idx]
        
        # If all top peaks are nearly equal, we're at a local optimum
        if top_vals[0] - top_vals[-1] < 1e-10:
            break
        
        # Try to reduce the maximum peak
        # The gradient of b_k with respect to a_j is 2*a[k-j] (for valid k-j)
        # So to reduce b_{k_max}, we should reduce a_j where a[k_max - j] is large
        # But we need to add that mass somewhere that doesn't increase other peaks
        
        k_max = top_idx[0]
        # Gradient of b_{k_max} w.r.t. a_j: a[k_max - j] (for 0 <= k_max - j < n)
        js = max(0, k_max - n + 1)
        je = min(n - 1, k_max)
        grad = np.zeros(n)
        grad[js:je+1] = 2 * a[k_max - np.arange(js, je+1)]
        
        # Find the position with the largest gradient contribution
        j_max = js + np.argmax(a[k_max - np.arange(js, je+1)] * a[np.arange(js, je+1)])
        
        # Find a destination: position with small contribution to all top peaks
        dest_score = np.zeros(n)
        for k2 in top_idx:
            js2 = max(0, k2 - n + 1)
            je2 = min(n - 1, k2)
            dest_score[js2:je2+1] += a[k2 - np.arange(js2, je2+1)]
        
        # Prefer destinations not involved in any top peak
        candidates = np.argsort(dest_score)[:n//4]
        j_min = candidates[np.random.randint(len(candidates))]
        
        # Try a small transfer
        for frac in [0.001, 0.005, 0.01, 0.02, 0.05]:
            amt = a[j_max] * frac
            if amt < 1e-15:
                continue
            a_new = a.copy()
            a_new[j_max] -= amt
            a_new[j_min] += amt
            if a_new[j_max] < 0:
                continue
            a_new /= a_new.sum()
            sc = internal_score(a_new)
            if sc < best_score:
                best_score = sc
                best_a = a_new.copy()
                a = a_new
                break
    
    return best_a, best_score

But a[k-j] ≠ a[j-k] in general (they're different indices). So the formula is:
∂(a*a)_k / ∂a_j = 2 * a[k-j] if j ≠ k-j and both in range
                    = 2 * a[j] if j = k-j (which means k-j = j, same thing)
                    = 0 if either j or k-j is out of range

Wait, when j = k-j, k-j = j, so 2*a[k-j] = 2*a[j]. So the formula is simply:
∂(a*a)_k / ∂a_j = 2 * a[k-j] if 0 <= k-j < n and 0 <= j < n
                    = 0 otherwise

And we don't need the special case! Because when k-j = j, a[k-j] = a[j], and the formula gives 2*a[j], which is correct.
