# Approach and Rationale
The goal is to find a sequence of non-negative heights for a step function that minimizes the spectral distortion metric:  
`min (2*n*max(convolve(a,a)) / (sum(a))^2`  

We propose a gradient-annealed perturbation method inspired by simulated annealing but using gradient information to guide large-scale changes. This approach will help escape local minima while preserving a good solution state.  

Instead of relying solely on specific local search directions, we'll use projection from high-isosum to low-isosum states with large step sizes, similar to annealed importance sampling. The high-isosum states help in finding diverse patterns, while low-isosum states ensure the solution remains in a reasonable domain.  

The method should be efficient with adaptation to failure modes when gradient calculation issues occur. We need to balance search and evaluation times, and handle cases where only a low-quality parent sequence is available.  

# Mathematical Specification
Defin the following:  
- **Hypercube Domain**: The optimal sequence will be found in a space where sequences have exactly `n` non-zero elements.  
- **Iso-Sum Level**: Instead of fixing the sum, we'll work with level sets where the sum is maintained above `ε_sum=0.01`.  

Within this space, define:  
- **Convex Hull Maximization**: The function `internal_score` estimates the scoring metric `2*n*max(convolve(a,a)) / (sum(a))^2` but handles cross-term simplification via FFT.  
- **Gradient Information**: `compute_lse_grad_a` uses LogSumExp regularization to approximate gradients for the convolution score.  
- **Update Policy**: We'll use Poisson disk sampling to choose which iso-sum level to project to, ensuring a roughly uniform exploration.
