- This is equivalent to finding the smallest C such that conv_k + delta * g_k <= C for all k.
- For delta > 0: we need delta <= (C - conv_k) / g_k for all k with g_k > 0, and delta >= (C - conv_k) / g_k for all k with g_k < 0.
- The optimal C is the minimum over delta of max_k (conv_k + delta * g_k).

This is a 1D convex optimization problem (the max of linear functions is convex). We can solve it by:
- Binary search on C: for a given C, check if there exists delta in [0, a_i] such that conv_k + delta * g_k <= C for all k.
  - For each k: if g_k > 0, need delta <= (C - conv_k) / g_k. If g_k < 0, need delta >= (C - conv_k) / g_k. If g_k = 0, need conv_k <= C.
  - So the feasible range for delta is [max_{g_k<0} (C-conv_k)/g_k, min_{g_k>0} (C-conv_k)/g_k] intersected with [0, a_i].
  - If this range is non-empty, C is feasible.

- The optimal C* is the minimum feasible C, found by binary search.

This takes O(n) per feasibility check, and O(n log(n/eps)) for the binary search. For each pair (i,j), this is O(n log n).

For a full sweep of all pairs, that's O(n^3 log n) which is too slow.

def fast_autocorr(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]


def compute_shift(a, i, size):
    """Compute h^i_k = a_{k-i} for k in [0, size-1], zero outside [0,n-1]."""
    n = len(a)
    h = np.zeros(size)
    # k-i in [0, n-1] means k in [i, i+n-1]
    lo = i
    hi = min(size, i + n)
    if hi > lo:
        h[lo:hi] = a[:hi-lo]
    return h


def lp_best_response(a, M, solver):
    n = len(a)
    size = 2 * n - 1
    b_var = cp.Variable(n, nonneg=True)
    # Build constraints: (a * b)_k <= M for all k
    # (a * b)_k = sum_i a_i * b_{k-i}
    # This is a Toeplitz-like matrix times b
    # For efficiency, use the structure:
    # constraint k: sum_{i: 0<=k-i<n} a_i * b_{k-i} <= M
    # Let j = k-i: sum_{j: 0<=j<n, 0<=k-j<n} a_{k-j} * b_j <= M
    
    # Build the matrix T where T[k, j] = a_{k-j} if 0 <= k-j < n, else 0
    T = np.zeros((size, n))
    for j in range(n):
        T[j:j+n, j] = a
    constraints = [T @ b_var <= M]
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        return None
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None
    b_val = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
    if b_val.sum() < 1e-15:
        return None
    return b_val
