`∇f(a) = 2*Q*a`, so `∇f(a)^T(s-a) = 2*(Qa)^T(s-a)`.

`(s-a)^T Q (s-a)` is a scalar.

`(s-a)^T Q (s-a) = (e_{i*}-a)^T Q (e_{i*}-a) = Q[i*,i*] - 2*(Qa)[i*] + a^T Q a`.

So `eta* = (a^T Q a - (Qa)[i*]) / (Q[i*,i*,] - 2*(Qa)[i*] + a^T Q a)`.

All of these can be computed in `O(n)` or `O(n log n)`:

- `Q[i*,i*] = w[2*i*]` if `2*i* <= 2n-2`, else 0.

**Structural insight**: The optimal sequence should have a "smooth" profile. If we think of `a` as a function on the real line (scaled to `[0,1]`), the autocorrelation being flat means the Fourier transform has constant magnitude - i.e., `a` is a "flat spectrum" signal. For a real, non-negative signal, this is related to minimum-energy signals with flat spectrum, which are related to prolate spheroidal wave functions... but that's for a different constraint.

For our problem, the key trade-off is:
- `conv(a,a)[0] = a[0]^2` (small if `a[0]` is small)
- `conv(a,a)[n-1] = sum_j a[j]*a[n-1-j]` (the "middle" term, which is large if `a` is concentrated in the middle)
- `conv(a,a)[2n-2] = a[n-1]^2` (small if `a[n-1]` is small)

So the peaks are likely at `k = 0`, `k = n-1` (middle), and `k = 2n-2`. To minimize the max, we want all of these to be similar.

For a uniform `a`, `conv(a,a)[k] = (n-|k-(n-1)|)/n^2` (triangular), so the peak is at `k = n-1` with value `1/n`. The objective is `2n * 1/n = 2`.

For a "U-shaped" `a` (large at the ends, small in the middle), the peak at `k = n-1` would be reduced, but the peaks at `k = 0` and `k = 2n-2` would increase. There's an optimal shape that balances these.

**Multiplicative weights update:**
`a[i] <- a[i] * exp(-eta * grad[i])`
Then normalize to sum = 1.

This naturally stays non-negative. The step size `eta` controls the aggressiveness.

For the gradient `grad[i] = 2 * (Qa)[i]` (where `Q` depends on the current weights `w`):
- If `grad[i]` is large, `a[i]` decreases (reducing the contribution to peaks).
- If `grad[i]` is small, `a[i]` increases.

This is essentially a "mirror descent" on the simplex with the entropy regularizer.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Frank-Wolfe method with LSE-smoothed subgradient and exact line search
2. Multiplicative weights (mirror descent) as diversification
3. Multi-length exploration with interpolation
4. Adaptive temperature annealing
5. Post-optimization peak shaving
"""

import numpy as np
import time
from scipy.fft import rfft, irfft

def fast_autocorr(a):
    """Compute full autocorrelation (convolution) of a with itself using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]

def evaluate_safe(a):
    """Safely evaluate the sequence."""
    try:
        a_list = [float(x) for x in a]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')

def compute_Qa(a, w):
    """Compute Qa where Q[i,j] = w[i+j].
    Qa[i] = sum_j w[i+j] * a[j]
    """
    n = len(a)
    w_rev = w[::-1].copy()
    size = (2*n - 1) + n - 1  # = 3n - 2
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    WR = rfft(w_rev, fft_size)
    conv_aw = irfft(A * WR, fft_size)
    # Qa[i] = conv_aw[2n-2-i] for i = 0, ..., n-1
    Qa = conv_aw[n-1:2*n-1][::-1]
    return Qa

def fw_lse_optimize(a0, time_limit, verbose=True):
    """Frank-Wolfe with LSE-smoothed gradient and exact line search."""
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()
    iter_count = 0
    
    while time.monotonic() - t0 < time_limit:
        elapsed = time.monotonic() - t0
        progress = min(elapsed / time_limit, 1.0)
        
        # Temperature schedule: high to low
        # Start at ~10x the score, end at ~0.01x
        T = best_score * (10.0 * (1.0 - progress) + 0.01)
        
        b = fast_autocorr(a)
        b_max = b.max()
        
        # Softmax weights
        b_scaled = b / T
        b_scaled -= b_scaled.max()
        w = np.exp(b_scaled)
        w_sum = w.sum()
        if w_sum < 1e-30:
            break
        w = w / w_sum
        
        # Compute gradient (2 * Qa where Q[i,j] = w[i+j])
        Qa = compute_Qa(a, w)
        grad = 2.0 * Qa
        
        # Frank-Wolfe step
        i_star = np.argmin(grad)
        s_vec = np.zeros(n)
        s_vec[i_star] = 1.0
        d = s_vec - a
        
        # Exact line search for f(a + eta*d) = a^T Q a
        fa = np.dot(w, b)  # = a^T Q a
        Qa_i = Qa[i_star]
        Qii = w[2*i_star] if 2*i_star < 2*n-1 else 0.0
        
        num = fa - Qa_i
        den = Qii - 2*Qa_i + fa
        
        if den > 1e-30:
            eta = np.clip(num / den, 0.0, 1.0)
        else:
            eta = 1.0 / (iter_count + 1)
        
        a = a + eta * d
        
        iter_count += 1
        
        # Periodic check
        if iter_count % 50 == 0:
            score = fast_autocorr(a).max()
            if score < best_score:
                best_score = score
                best_a = a.copy()
        
        if verbose and iter_count % 100000 == 0:
            print(f"    FW iter={iter_count} ({elapsed:.0f}s): T={T:.6f}, best={best_score:.8f}")
    
    # Final check
    score = fast_autocorr(a).max()
    if score < best_score:
        best_score = score
        best_a = a.copy()
    
    return best_a, best_score

def multiplicative_weights_optimize(a0, time_limit, verbose=True):
    """Mirror descent (multiplicative weights) on the simplex."""
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()
    iter_count = 0
    
    while time.monotonic() - t0 < time_limit:
        elapsed = time.monotonic() - t0
        progress = min(elapsed / time_limit, 1.0)
        
        T = best_score * (5.0 * (1.0 - progress) + 0.01)
        
        b = fast_autocorr(a)
        b_max = b.max()
        
        # Softmax weights
        b_scaled = b / T
        b_scaled -= b_scaled.max()
        w = np.exp(b_scaled)
        w_sum = w.sum()
        if w_sum < 1e-30:
            break
        w = w / w_sum
        
        # Gradient
        Qa = compute_Qa(a, w)
        grad = 2.0 * Qa
        
        # Multiplicative update
        eta = 0.1 / (1.0 + iter_count * 0.001)
        a = a * np.exp(-eta * grad + eta * grad.min())  # shift for numerical stability
        s = a.sum()
        if s < 1e-15:
            break
        a = a / s
        
        iter_count += 1
        
        if iter_count % 50 == 0:
            score = fast_autocorr(a).max()
            if score < best_score:
                best_score = score
                best_a = a.copy()
        
        if verbose and iter_count % 100000 == 0:
            print(f"    MW iter={iter_count} ({elapsed:.0f}s): T={T:.6f}, best={best_score:.8f}")
    
    score = fast_autocorr(a).max()
    if score < best_score:
        best_score = score
        best_a = a.copy()
    
    return best_a, best_score

def peak_shave_fine(a0, time_limit, seed=42, verbose=True):
    """Fine peak shaving with small perturbations."""
    n = len(a0)
    rng = np.random.default_rng(seed)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        return a, fast_autocorr(a).max()
    a = a / s
    
    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()
    n_trial = 0
    
    T = best_score * 0.05
    T_end = best_score * 0.001
    
    while time.monotonic() - t0 < time_limit:
        progress = min((time.monotonic() - t0) / time_limit, 1.0)
        T = T * (T_end / T ** 1) ** (progress * 0.5)  # slow annealing
        T = max(T, T_end)
        
        b = fast_autocorr(a)
        k_max = np.argmax(b)
        
        # Find the main contributor to the peak
        js = max(0, k_max - n + 1)
        je = min(n - 1, k_max)
        idx = np.arange(js, je + 1)
        if len(idx) == 0:
            continue
        
        contrib = a[idx] * a[k_max - idx]
        src = idx[np.argmax(contrib)]
        
        # Try small transfer to random destination
        dst = rng.integers(n)
        frac = rng.uniform(0.001, 0.02)
        amt = a[src] * frac
        
        a_trial = a.copy()
        a_trial[src] -= amt
        a_trial[dst] += amt
        a_trial = np.maximum(a_trial, 0)
        s_t = a_trial.sum()
        if s_t < 1e-15:
            continue
        a_trial = a_trial / s_t
        
        score = fast_autocorr(a_trial).max()
        n_trial += 1
        
        if score < best_score:
            best_score = score
            best_a = a_trial.copy()
            a = a_trial
        elif rng.random() < np.exp(-(score - best_score) / max(T, 1e-10)):
            a = a_trial
        
        if verbose and n_trial % 100000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    PeakShave trial={n_trial} ({elapsed:.0f}s): best={best_score:.8f}")
    
    return best_a, best_score

def interpolate_sequence(f, new_n):
    """Interpolate a sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n)
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n)
    return f_interp / ss
