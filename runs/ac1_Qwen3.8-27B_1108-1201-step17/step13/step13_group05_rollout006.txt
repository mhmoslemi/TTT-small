    c = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)

    if s < 1e-15:

    else:
        a = a * c / s
    
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    
    # Nesterov momentum
    y = a.copy()  # momentum point
    t = 1
    
    while time.monotonic() - t0 < time_limit:
        # Compute subgradient at y
        ac = fast_autocorr(y)
        M = ac.max()
        
        # Top-K lags with exponential weighting
        top_idx = np.argsort(ac)[::-1][:K]
        w = ac[top_idx].copy()
        w = np.maximum(w, 0)
        w = w ** beta
        w_sum = w.sum()
        if w_sum < 1e-30:
            w = np.ones(K) / K
        else:
            w = w / w_sum
        
        g = np.zeros(n)
        for wi, k in zip(w, top_idx):
            i_start = max(0, int(k) - n + 1)
            i_end = min(n, int(k) + 1)
            idx = np.arange(i_start, i_end)
            g[idx] += 2.0 * wi * y[int(k) - idx]
        
        # Frank-Wolfe step
        # "Towards" direction: min of g
        i_min = np.argmin(g)
        # "Away" direction: max of g among active (a_i > 0) positions
        active = a > 1e-12

            i_max = np.argmax(g_active)

        a_towards = a.copy()
        a_towards[i_min] += gamma
        a_towards[i_min] = max(a_towards[i_min], 0)
        s_t = a_towards.sum()

Let me think about it differently. We want to minimize `max_k conv(a,a)[k]` subject to `sum a = S` and `a >= 0`.

By the constraint `sum_k conv(a,a)[k] = S^2`, we have `max_k conv(a,a)[k] >= S^2/(2n-1)`.

But can we achieve this? Only if `conv(a,a)[k] = S^2/(2n-1)` for all k, which means the convolution is constant. This is a "perfect" sequence.

For non-negative sequences, is a constant convolution possible? Let's see:
- `conv(a,a)[0] = a[0]^2 = S^2/(2n-1)` → `a[0] = S/sqrt(2n-1)`
- `conv(a,a)[2n-2] = a[n-1]^2 = S^2/(2n-1)` → `a[n-1] = S/sqrt(2n-1)`
- `conv(a,a)[1] = a[0]*a[1] + a[1]*a[0] = 2*a[0]*a[1] = S^2/(2n-1)`
  → `a[1] = S/(2*sqrt(2n-1))`

But then `a[0] + a[1] + ... + a[n-1] = S` must hold. With `a[0] = S/sqrt(2n-1)` and `a[1] = S/(2*sqrt(2n-1))`, we already have `a[0] + a[1] = S/sqrt(2n-1) * 1.5`. For this to be <= S, we need `1.5/sqrt(2n-1) <= 1`, i.e., `2n-1 >= 2.25`, i.e., `n >= 2`. So for n >= 2, it's possible in principle.

But the constraint is much more complex. For a constant convolution, we need:
`sum_{i} a[i]*a[k-i] = C` for all k, where C = S^2/(2n-1).

This is a system of quadratic equations. For n=2:
- a[0]^2 = C
- 2*a[0]*a[1] = C
- a[1]^2 = C

From the first and third: a[0] = a[1] = sqrt(C). Then 2*C = C, which means C = 0. Contradiction (unless S=0).

So for n=2, a constant convolution is impossible with non-negative a.

For n=3:
- a[0]^2 = C
- 2*a[0]*a[1] = C
- 2*a[0]*a[2] + a[1]^2 = C
- 2*a[1]*a[2] = C
- a[2]^2 = C

From 1 and 5: a[0] = a[2] = sqrt(C).
From 2: a[1] = C/(2*sqrt(C)) = sqrt(C)/2.
From 4: 2*(sqrt(C)/2)*sqrt(C) = C. ✓
From 3: 2*sqrt(C)*sqrt(C) + C/4 = 2C + C/4 = 9C/4 ≠ C (unless C=0). ✗

So for n=3, it's also impossible.

In general, for non-negative sequences, a perfectly flat convolution is impossible (for small n). But as n grows, we might be able to get closer.
