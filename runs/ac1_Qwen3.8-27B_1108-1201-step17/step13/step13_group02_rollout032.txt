For k-j ≠ j (i.e., k ≠ 2j): the terms a[j]*a[k-j] (at i=j) and a[k-j]*a[j] (at i=k-j) are two separate terms. Each has derivative a[k-j] w.r.t. a[j]. So total is 2*a[k-j].

So in all cases: d(conv[k])/da[j] = 2*a[k-j] if 0 <= k-j < n, else 0.

Wait, but that's only if both i=j and i=k-j are in range [0, n). If k-j is out of range, then only one of the terms exists.

Actually, let me reconsider. conv[k] = sum_{i=max(0,k-n+1)}^{min(n-1,k)} a[i]*a[k-i].

If we differentiate w.r.t. a[j]:
- The term a[i]*a[k-i] depends on a[j] if either i=j or k-i=j.
- If i=j: the term is a[j]*a[k-j]. Derivative w.r.t. a[j] is a[k-j] (if k-j ≠ j) or 2*a[j] (if k-j = j).
- If k-i=j, i.e., i=k-j: the term is a[k-j]*a[j]. Derivative w.r.t. a[j] is a[k-j] (if k-j ≠ j) or 0 additional (if k-j = j, since it's the same term).

So:
- If 0 <= j < n and 0 <= k-j < n and k ≠ 2j: derivative = a[k-j] + a[k-j] = 2*a[k-j]
- If 0 <= j < n and k-j = j (i.e., k = 2j): derivative = 2*a[j]
- If 0 <= j < n but k-j out of [0, n): derivative = 0
- If j out of [0, n): doesn't exist

So in all valid cases: d(conv[k])/da[j] = 2*a[k-j] (where we interpret a[k-j] as the value at position k-j, which equals a[j] when k=2j).

Great, so the subgradient of max(conv) w.r.t. a is:
`grad[j] = sum_{k in argmax(conv)} 2*a[k-j]` (where k-j is in [0, n))

This is very efficient to compute! For each peak position k, we add 2*a[k-j] to grad[j].

If there are multiple peaks (or we use LSE smoothing to approximate the max), we can sum over all positions with weights.

This gives us an O(n * n_peaks) gradient computation (or O(n * (2n-1)) in the worst case with LSE weights on all positions, but that's O(n^2) which is fine for n up to a few thousand).

Actually, with LSE weights w[k] on each position k:
`grad[j] = sum_k w[k] * 2*a[k-j]` (for valid k-j)

This is a convolution! `grad = 2 * (w * a_reversed)` (with appropriate indexing). So we can compute it in O(n log n) using FFT.

This is the key insight for fast gradient computation.

Now let me think about the overall algorithm:

1. **Initialization**: Try several different initializations:
   - U-shaped: a[i] ∝ 1/sqrt((i+1)(n-1-i+1))
   - Random: a[i] = |N(0,1)|
   - Sine: a[i] = sin^2(pi*i/(n-1))
   - The parent sequence (if available)

2. **Optimization loop**:
   - Compute convolution (FFT)
   - Compute LSE weights
   - Compute gradient (FFT)
   - Take gradient step with adaptive step size
   - Project to non-negative, renormalize
   - Track best

3. **Peak shaving** (when gradient descent stalls):
   - Find the top few peaks
   - Identify contributing elements
   - Move mass from peak-contributing to non-peak-contributing elements

4. **Length exploration**:
   - Try different lengths
   - Interpolate optimal solution from one length to another

5. **Restart strategy**:
   - If no improvement for a while, perturb the current solution
   - Or restart from a different initialization

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. FFT-based LSE gradient descent with adaptive temperature annealing
2. Multi-peak shaving with mass redistribution
3. Diverse initialization strategies (U-shaped, random, structured)
4. Adaptive length exploration with interpolation
5. Simulated annealing for escape from local minima
"""

import numpy as np
import time
from scipy.fft import rfft, irfft

def fast_autocorr(a):
    """Compute full convolution of a with itself using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a.astype(np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]

def eval_obj(a):
    """Compute the objective function directly (fast, no function call overhead)."""
    n = len(a)
    if a.sum() < 0.01:
        return float('inf')
    conv = fast_autocorr(a)
    return 2.0 * n * conv.max() / (a.sum() ** 2)

def normalized_eval(a):
    """Evaluate with normalization to sum=1 (equivalent up to scale)."""
    n = len(a)
    s = a.sum()
    if s < 1e-15:
        return float('inf')
    p = a / s
    conv = fast_autocorr(p)
    return 2.0 * n * conv.max()

def lse_gradient(a, temp):
    """Compute gradient of LSE approximation of max(conv(a,a)).
    Returns gradient w.r.t. a (length n).
    """
    n = len(a)
    conv = fast_autocorr(a)
    max_c = conv.max()
    # LSE weights
    w = np.exp((conv - max_c) / temp)
    w_sum = w.sum()
    if w_sum < 1e-30:
        return np.zeros(n), max_c
    w = w / w_sum
    
    # grad[j] = sum_k w[k] * 2*a[k-j] for valid k-j in [0, n)
    # This is 2 * (w * a_rev)[j + n - 1] where * is full convolution
    # Actually: grad[j] = 2 * sum_{k: 0<=k-j<n} w[k] * a[k-j]
    # Let m = k-j, then k = j+m, so grad[j] = 2 * sum_{m=0}^{n-1} w[j+m] * a[m] (for j+m < 2n-1)
    # This is the cross-correlation of w and a, which equals the convolution of w and a_reversed.
    
    a_rev = a[::-1]
    # conv(w, a_rev) has length (2n-1) + n - 1 = 3n - 2
    # We want positions [n-1, 2n-2] of this convolution
    fft_size = 1 << (3 * n - 2).bit_length()
    W = rfft(w, fft_size)
    AR = rfft(a_rev, fft_size)
    cross = irfft(W * AR, fft_size)
    grad = 2.0 * cross[n-1:2*n-1]
    return grad, max_c

def lse_laplace_gradient(a, temp):
    """Alternative: use softmax (Laplace approximation to max) for gradient."""
    n = len(a)
    conv = fast_autocorr(a)
    max_c = conv.max()
    
    # Softmax weights (equivalent to LSE with temperature)
    shifted = conv - max_c
    w = np.exp(shifted / temp)
    w_sum = w.sum()
    if w_sum < 1e-30:
        return np.zeros(n), max_c
    w = w / w_sum
    
    a_rev = a[::-1]
    fft_size = 1 << (3 * n - 2).bit_length()
    W = rfft(w, fft_size)
    AR = rfft(a_rev, fft_size)
    cross = irfft(W * AR, fft_size)
    grad = 2.0 * cross[n-1:2*n-1]
    return grad, max_c

def gradient_descent_cycle(a, time_limit, temp_start=None, temp_end=None, verbose=True):
    """Run LSE gradient descent with annealing."""
    n = len(a)
    a = a.astype(np.float64).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
        s = 1.0
    else:
        a = a / s  # normalize to sum 1
    
    best_a = a.copy()
    best_score = normalized_eval(a)
    t0 = time.monotonic()
    
    if temp_start is None:
        conv = fast_autocorr(a)
        temp_start = max(conv.max() * 0.1, 1e-4)
    if temp_end is None:
        temp_end = max(conv.max() * 0.001, 1e-6)
    
    steps = 0
    stale_count = 0
    
    while time.monotonic() - t0 < time_limit:
        elapsed_frac = min(1.0, (time.monotonic() - t0) / time_limit)
        # Exponential annealing
        temp = temp_start * (temp_end / temp_start) ** (elapsed_frac ** 0.7)
        
        conv = fast_autocorr(a)
        max_c = conv.max()
        
        # Compute LSE gradient
        shifted = conv - max_c
        # Clip to avoid underflow
        shifted = np.maximum(shifted, -temp * 50)
        w = np.exp(shifted / temp)
        w_sum = w.sum()
        if w_sum < 1e-30:
            break
        w = w / w_sum
        
        # Gradient via FFT
        a_rev = a[::-1]
        fft_size = 1 << (3 * n - 2).bit_length()
        W = rfft(w, fft_size)
        AR = rfft(a_rev, fft_size)
        cross = irfft(W * AR, fft_size)
        grad = 2.0 * cross[n-1:2*n-1]
        
        # Adaptive step size: use line search-lite (backtracking)
        # Start with a step based on gradient norm
        gnorm = np.linalg.norm(grad) / n
        if gnorm < 1e-15:
            break
            
        step = 0.1 / (temp + 1e-10)
        # Cap step to avoid large jumps
        step = min(step, 1.0 / n)
        
        improved = False
        for _ in range(10):
            a_new = a - step * grad
            a_new = np.maximum(a_new, 0.0)
            s_new = a_new.sum()
            if s_new < 1e-15:
                break
            a_new = a_new / s_new
            score = normalized_eval(a_new)
            if score < max_c + temp:  # approximate improvement check
                a = a_new
                improved = True
                break
            step *= 0.5
        
        if not improved:
            # Just take a small step regardless
            a_new = a - 0.001 * grad / (gnorm + 1e-15)
            a_new = np.maximum(a_new, 0.0)
            s_new = a_new.sum()
            if s_new > 1e-15:
                a = a_new / s_new
        
        steps += 1
        
        if steps % 50 == 0:
            score = normalized_eval(a)
            if score < best_score:
                best_score = score
                best_a = a.copy()
                stale_count = 0
            else:
                stale_count += 1
                
            if verbose and steps % 200 == 0:
                elapsed = time.monotonic() - t0
                print(f"      GD step={steps} ({elapsed:.0f}s): temp={temp:.6f}, score={best_score:.8f}, stale={stale_count}")
        
        # Restart if very stale
        if stale_count > 40:
            rng = np.random.default_rng(steps * 13 + 7)
            noise = rng.normal(0, 0.01 / np.sqrt(n), n)
            a = a + noise
            a = np.maximum(a, 0)
            s = a.sum()
            if s > 1e-15:
                a = a / s
            stale_count = 0
    
    return best_a, best_score

def peak_shave(a, time_limit, seed=42, verbose=True):
    """Peak shaving: find peaks and redistribute mass."""
    n = len(a)
    rng = np.random.default_rng(seed)
    a = a.astype(np.float64).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    best_score = normalized_eval(a)
    t0 = time.monotonic()
    
    T_start = max(0.1, best_score * 0.02)
    T_end = best_score * 0.001
    n_improve = 0
    n_stall = 0
    
    while time.monotonic() - t0 < time_limit:
        elapsed_frac = min(1.0, (time.monotonic() - t0) / time_limit)
        T = T_start * (T_end / T_start) ** elapsed_frac
        
        conv = fast_autocorr(a)
        # Find top peaks
        n_peaks = min(5, 2 * n - 1)
        top_k = np.argsort(conv)[::-1][:n_peaks]
        
        improved = False
        for k in top_k:
            # Find which indices contribute to this peak
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            contrib = a[idx] * a[k - idx]
            
            if contrib.max() < 1e-18:
                continue
            
            src = idx[np.argmax(contrib)]
            
            # Find good destinations (not contributing to top peaks)
            peak_mask = np.zeros(n, dtype=bool)
            for k2 in top_k:
                js2 = max(0, k2 - n + 1)
                je2 = min(n - 1, k2)
                peak_mask[js2:je2 + 1] = True
            
            non_peak = np.where(~peak_mask)[0]
            if len(non_peak) == 0:
                non_peak = np.where(np.arange(n) != src)[0]
            
            # Try moving mass to a random non-peak destination
            n_dest = min(3, len(non_peak))
            dst_candidates = non_peak[rng.choice(len(non_peak), n_dest, replace=False)]
            
            for dst in dst_candidates:
                # Try different fractions
                for frac in [0.03, 0.07, 0.15, 0.3]:
                    amt = a[src] * frac
                    if amt < 1e-18:
                        continue
                    a_trial = a.copy()
                    a_trial[src] -= amt
                    a_trial[dst] += amt
                    a_trial = np.maximum(a_trial, 0)
                    s_t = a_trial.sum()
                    if s_t < 1e-15:
                        continue
                    a_trial = a_trial / s_t
                    score = normalized_eval(a_trial)
                    
                    if score < best_score:
                        a = a_trial
                        best_score = score
                        best_a = a.copy()
                        improved = True
                        n_improve += 1
                        break
                    elif rng.random() < np.exp(-(score - best_score) / max(T, 1e-10)):
                        a = a_trial
                        improved = True
                        break
                if improved:
                    break
            
            if improved:
                break
        
        if not improved:
            n_stall += 1
            # Random pair swap
            i = rng.integers(n)
            j = rng.integers(n)
            if i != j and a[i] > 1e-10:
                frac = rng.uniform(0.05, 0.2)
                amt = a[i] * frac
                a_trial = a.copy()
                a_trial[i] -= amt
                a_trial[j] += amt
                a_trial = np.maximum(a_trial, 0)
                s_t = a_trial.sum()
                if s_t > 1e-15:
                    a_trial = a_trial / s_t
                    score = normalized_eval(a_trial)
                    if score < best_score:
                        a = a_trial
                        best_score = score
                        best_a = a.copy()
                        n_improve += 1
                    elif rng.random() < np.exp(-(score - best_score) / max(T, 1e-10)):
                        a = a_trial
            
            if n_stall > 100:
                # Larger perturbation
                n_pert = max(5, n // 20)
                idx_pert = rng.choice(n, n_pert, replace=False)
                a_trial = a.copy()
                for idx in idx_pert:
                    amt = a[idx] * rng.uniform(0.1, 0.5)
                    j = rng.integers(n)
                    a_trial[idx] -= amt
                    a_trial[j] += amt
                a_trial = np.maximum(a_trial, 0)
                s_t = a_trial.sum()
                if s_t > 1e-15:
                    a_trial = a_trial / s_t
                    score = normalized_eval(a_trial)
                    if score < best_score * 1.02:
                        a = a_trial
                        if score < best_score:
                            best_score = score
                            best_a = a.copy()
                n_stall = 0
        
        if verbose and n_improve % 500 == 0 and n_improve > 0:
            elapsed = time.monotonic() - t0
            print(f"      PeakShave improve={n_improve} ({elapsed:.0f}s): best={best_score:.8f}")
    
    return best_a, best_score

def interpolate_seq(f, new_n):
    """Interpolate sequence to new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    p = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    p_interp = np.interp(new_x, old_x, p)
    p_interp = np.maximum(p_interp, 0.0)
    ss = p_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return p_interp / ss

def make_u_shaped(n, alpha=2.0):
    """Create a U-shaped (edge-concentrated) initial sequence."""
    x = np.arange(n, dtype=np.float64)
    center = (n - 1) / 2.0
    # U-shaped: high at edges, low at center
    p = 1.0 / (1 + alpha * (1 - np.abs(x - center) / center) ** 2)
    # Actually let's make it more U-shaped
    p = (np.abs(x - center) / center) ** alpha + 0.1
    p = np.maximum(p, 0)
    s = p.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return p / s

def make_random_seq(n, seed=0):
    """Random initialization."""
    rng = np.random.default_rng(seed)
    p = rng.uniform(0, 1, n)
    s = p.sum()
    return p / s

def make_sine_seq(n):
    """Sine-shaped initialization."""
    x = np.linspace(0, 1, n)
    p = np.sin(np.pi * x)
    p = np.maximum(p, 0)
    s = p.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return p / s

def make_arcosine_seq(n):
    """Arccosine (Wigner semi-circle) shaped initialization."""
    x = np.linspace(-1, 1, n)
    p = np.sqrt(1 - x**2)
    p = np.maximum(p, 0)
    s = p.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return p / s

def make_edge_conc_seq(n, power=0.5):
    """Edge-concentrated: p[i] proportional to distance from center raised to power."""
    x = np.arange(n, dtype=np.float64)
    center = (n - 1) / 2.0
    p = (np.abs(x - center) / center) ** power
    p[0] = p[0] + 0.01  # avoid zero at exact center for odd n
    p = np.maximum(p, 0)
    s = p.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return p / s
