And s1[j] = sum_{i=0}^{n-1} w[i+j] * a[i]

So grad[j] = sum_{i=0}^{n-1} (w[i+j] + w[2n-2-j+i]) * a[i]

This is a weighted sum where the weight for a[i] is `w[i+j] + w[2n-2-j+i]`.

Now, I can compute this as a matrix-vector product, but that's O(n^2). For n=1600, that's 2.5M operations per gradient evaluation, which is fine (about 1-2 ms).

Actually, let me think about this differently. The matrix M where M[j,i] = w[i+j] + w[2n-2-j+i] is a symmetric Toeplitz-like matrix (it's the sum of two Toeplitz matrices). I can compute the matrix-vector product using FFT in O(n log n).

The first part M1[j,i] = w[i+j] is a Toeplitz matrix (depends only on i+j). The second part M2[j,i] = w[2n-2-j+i] = w[(2n-2) + (i-j)] is also a Toeplitz matrix (depends on i-j, with a shift).

For a Toeplitz matrix T where T[j,i] = t[i+j], the product (T*v)[j] = sum_i t[i+j] * v[i] is the cross-correlation of t and v (with appropriate indexing). This can be computed via FFT.

Specifically: (T*v)[j] = sum_i t[i+j] * v[i] for j = 0, ..., n-1.

Let me define the full vector t of length 2n-1 (t[k] = w[k] for k = 0, ..., 2n-2).
Then (T*v)[j] = sum_{i=0}^{n-1} t[i+j] * v[i].

This is the "reverse" cross-correlation: it's like correlating t with v but with a different indexing.

Actually, let me just define:
- c[j] = sum_{i=0}^{n-1} t[i+j] * v[i] for j = 0, ..., n-2 (so i+j ranges from j to n-1+j, which is within [0, 2n-3] for j <= n-2)

This is a "sliding inner product" of v with shifted versions of t. It can be computed as:
- Reverse v: vr[i] = v[n-1-i]
- c[j] = <v, t[j:j+n]>
- This is the cross-correlation at a specific set of lags.

Using FFT: Let V = rfft(v, N) and T = rfft(t, N) with N >= 3n-2.
The convolution (v * t)[k] = sum_i v[i] * t[k-i].
So (v * t)[j + (n-1)] = sum_i v[i] * t[j + n - 1 - i].

Hmm, this gives t[j+n-1-i] not t[i+j]. Let me try convolution of vr and t:
(vr * t)[k] = sum_i vr[i] * t[k-i] = sum_i v[n-1-i] * t[k-i]
Let m = n-1-i: = sum_m v[m] * t[k-n+1+m]
So (vr * t)[j + n - 1] = sum_m v[m] * t[m + j] = c[j]. ✓

So c = (vr * t)[n-1 : 2n-2] (a slice of the convolution).

Similarly for the second part: M2[j,i] = w[(2n-2) + (i-j)] = w[2n-2+i-j].
Let t2[k] = w[k] and define (T2*v)[j] = sum_i t2[2n-2+i-j] * v[i].
Let m = i-j: sum_m t2[2n-2+m] * v[m+j].

This is like a cross-correlation again. Let me define:
d[j] = sum_i w[2n-2+i-j] * v[i] for j = 0, ..., n-1.
Let m = i-j: d[j] = sum_m w[2n-2+m] * v[m+j].

This is the cross-correlation of (reversed and shifted w) with v.

Alternatively, since w is symmetric: w[2n-2+i-j] = w[j-i].
So d[j] = sum_i w[j-i] * v[i] = (w ⋆ v)[j] (standard cross-correlation of w and v).

And (w ⋆ v)[j] = sum_k w[k] * v[k-j] (with zero-padding).

This is exactly the cross-correlation computed via FFT: ifft(rfft(w) * conj(rfft(v)))!

So:
- s1[j] = c[j] = (vr * t)[j + n - 1] where vr = v reversed, t = w
- s2[j] = d[j] = (w ⋆ v)[j] = ifft(rfft(w) * conj(rfft(v)))[j]

And grad = s1 + s2.
