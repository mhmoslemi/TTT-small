where T_k is the matrix for the k-th convolution (T_k is symmetric since (a*a)_k = (a*a)_{-k}... wait, for the full convolution this isn't symmetric in the way I'm thinking).

Actually, (a*a)_k = sum_j a_j a_{k-j} (with a_i = 0 for i outside [0,n-1]). This is a quadratic form: a^T Q_k a where Q_k has Q_k[j, k-j] = 1/2 and Q_k[k-j, j] = 1/2 (for valid indices), and Q_k[j,j] = 1 if k=0.

Wait, for k=0: (a*a)_0 = sum_j a_j^2 = a^T I a.
For k>0: (a*a)_k = sum_j a_j a_{j+k} (where j+k < n). This is a^T Q_k a where Q_k[j, j+k] = 1 and Q_k[j+k, j] = 1... no, that gives 2*sum a_j a_{j+k}.

Let me be more careful. (a*a)_k = sum_j a_j * a_{k-j} for 0 <= j < n and 0 <= k-j < n.

For k=0: sum_j a_j * a_j = sum a_j^2.
For k>0: sum_{j=k-n+1}^{k} a_j * a_{k-j} (with a_i = 0 for i outside [0,n-1]).
  = sum_{j=max(0,k-n+1)}^{min(n-1,k)} a_j * a_{k-j}

This equals a^T Q_k a where Q_k is the matrix with (Q_k)_{i,j} = 1 if i+j=k (i.e., j = k-i), and 0 otherwise. But since we're summing a_i * a_j where j = k-i, and the matrix should be symmetric, we need:

(a*a)_k = sum_i sum_j (Q_k)_{i,j} a_i a_j

where (Q_k)_{i,j} = 1 if j = k-i and 0 <= k-i < n, else 0.

But this isn't symmetric in general (for k ≠ 0). To make it a proper quadratic form, we use the symmetrized version:
(Q_k)_{i,j} = 1/2 if j = k-i, 0 <= k-i < n, i ≠ j
(Q_k)_{i,j} = 1 if i = j and 2i = k (i.e., k is even and i = k/2)

This gives (a*a)_k = a^T Q_k a.

For the zero-sum game formulation:
V = min_{a in Delta} max_{p in Delta_{2n-1}} sum_k p_k a^T Q_k a = min_a max_p a^T (sum_k p_k Q_k) a

The inner max is over p, and the outer min is over a. By von Neumann's minimax theorem (since the game is bilinear... wait, it's not bilinear, it's a game where both players affect the same quadratic form).

Hmm, this is actually a "quadratic game" not a bilinear game, so the standard minimax theorem doesn't directly apply. The Nesterov LP approach in the previous code works differently - it's solving the LP which gives the best response of one player given the other's strategy.

Let me just stick with the LP-based approach but make it more efficient.

Key efficiency improvement: Instead of solving the LP from scratch each time, we can:
1. Use the previous solution as a warm start
2. Reduce the number of iterations (the LP doesn't need to be solved to full precision)
3. Use a faster solver

Another idea: Instead of the full LP, use a "best response" approximation. The best response b* to a given a is the solution to:
min_b max_k (a*b)_k s.t. sum(b) = 1, b >= 0

This LP has a special structure. The optimal b* will have at most n-1 non-zero components (by Carathéodory's theorem in the appropriate form). In practice, it often has even fewer.

For the Nesterov method, we don't need the exact best response - an approximate one is fine. We can solve the LP to moderate precision (tolerance 1e-4 or even 1e-3) and still get good convergence.

Let me write the final code now. I'll focus on:
1. Fast LP with moderate precision
2. Nesterov with time-averaged iterate
3. Aggressive peak shaving
4. Multi-length exploration

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Multi-alpha spectral shaping for initialization
2. Nesterov-accelerated LP best-response with warm-starting (primary)
3. Adaptive subgradient with top-K peak targeting
4. Aggressive multi-strategy peak shaving
5. Multi-length exploration with interpolation

import numpy as np
import time
from scipy.fft import rfft, irfft
import cvxpy as cp


def fast_autocorr(a):
    """Full auto-convolution a*a using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]


def evaluate_safe(arr):
    """Safely evaluate a sequence."""
    try:
        a_list = [float(max(0.0, min(1000.0, x))) for x in arr]
        sc = evaluate_sequence(a_list)
        return float(sc)
    except Exception:
        return float('inf')


def internal_score(a):
    """Compute 2*n*max_b assuming sum(a)=1."""
    n = len(a)
    return 2.0 * n * fast_autocorr(a).max()


def softmax_fn(z):
    """Numerically stable softmax."""
    z = z - z.max()
    e = np.exp(z)
    s = e.sum()
    if s < 1e-300:
        return np.ones(len(z)) / len(z)
    return e / s


def project_simplex(v, target_sum=1.0):
    """Project v onto {x: sum(x)=target_sum, x>=0}."""
    n = len(v)
    v = np.asarray(v, dtype=np.float64)
    if np.all(v >= 0) and abs(v.sum() - target_sum) < 1e-12:
        return v.copy()
    v_sorted = np.sort(v)[::-1]
    cssv = np.cumsum(v_sorted)
    rho = np.nonzero(v_sorted * np.arange(1, n + 1) > (cssv - target_sum))[0]
    if len(rho) == 0:
        return np.full(n, target_sum / n)
    rho = rho[-1]
    theta = (cssv[rho] - target_sum) / (rho + 1.0)
    result = np.maximum(v - theta, 0)
    diff = target_sum - result.sum()
    if abs(diff) > 1e-15:
        idx = np.argmax(result)
        result[idx] += diff
        result = np.maximum(result, 0)
        ss = result.sum()
        if ss > 0:
            result = result / ss * target_sum
    return result


def spectral_shaping(a, n_iter=400, alpha=0.3):
    """Iteratively flatten power spectrum to reduce autocorrelation peaks."""
    n = len(a)
    a = np.maximum(np.asarray(a, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    a = a / s
    fft_size = 1 << (2 * n - 1).bit_length()

    best_a = a.copy()
    best_score = internal_score(a)

    for i in range(n_iter):
        A = rfft(a, fft_size)
        B = np.abs(A) ** 2

        non_dc = B[1:]
        log_non_dc = np.log(non_dc + 1e-30)
        target = np.exp(np.mean(log_non_dc))

        scale = np.ones(len(A))
        ratio = target / (B[1:] + 1e-30)
        ratio = np.clip(ratio, 0.01, 100.0)
        scale[1:] = np.power(ratio, alpha / 2.0)

        A_new = A * scale
        a_new = irfft(A_new, fft_size)[:n]
        a_new = np.maximum(a_new, 0)
        ss = a_new.sum()
        if ss < 1e-15:
            break
        a_new = a_new / ss

        score = internal_score(a_new)
        if score < best_score:
            best_score = score
            best_a = a_new.copy()
        a = a_new

    return best_a


def build_conv_matrix(a_fixed):
    """Build (2n-1) x n matrix T where T[k,j] = a[k-j] if 0<=k-j<n else 0."""
    n = len(a_fixed)
    T = np.zeros((2 * n - 1, n))
    for j in range(n):
        T[j:j + n, j] = a_fixed
    return T


def get_lp_solver():
    """Find a working LP solver."""
    for solver_name in [cp.CLARABEL, cp.ECOS, cp.SCS, cp.PDLP]:
        try:
            x = cp.Variable(5, nonneg=True)
            prob = cp.Problem(cp.Minimize(cp.sum(x)), [cp.sum(x) == 1, x <= 0.5])
            prob.solve(solver=solver_name)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                return solver_name
        except Exception:
            continue
    return cp.ECOS


def solve_lp_fast(a_fixed, T, solver, prev_b=None, max_iter=100):
    """Solve LP: min M s.t. T@b <= M, sum(b)=1, b>=0. With warm start."""
    n = len(a_fixed)
    b_var = cp.Variable(n, nonneg=True)
    M_var = cp.Variable()
    constraints = [T @ b_var <= M_var, cp.sum(b_var) == 1]
    obj = cp.Minimize(M_var)
    prob = cp.Problem(obj, constraints)
    
    try:
        prob.solve(solver=solver, max_iter=max_iter)
    except Exception:
        pass
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        for alt in [cp.ECOS, cp.SCS, cp.PDLP, cp.CLARABEL]:
            if alt == solver:
                continue
            try:
                prob.solve(solver=alt, max_iter=150)
                if prob.status in ('optimal', 'optimal_inaccurate'):
                    break
            except Exception:
                continue
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None, None
    b_val = np.asarray(b_var.value, dtype=np.float64)
    b_val = np.maximum(b_val, 0)
    s = b_val.sum()
    if s < 1e-15:
        return None, None
    b_val = b_val / s
    return b_val, float(M_var.value)


def nesterov_lp(a0, time_limit, solver, verbose=True):
    """Nesterov-accelerated LP best-response for zero-sum game."""
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    y = a.copy()

    best_a = a.copy()
    best_score = internal_score(a)
    t0 = time.monotonic()

    avg_a = a.copy()
    n_avg = 1

    for t in range(1, 20000):
        if time.monotonic() - t0 > time_limit:
            break

        # Solve LP for best response to y
        T = build_conv_matrix(y)
        b_star, M_val = solve_lp_fast(y, T, solver, max_iter=80)
        if b_star is None:
            # Fallback: use uniform
            b_star = np.ones(n) / n

        alpha_t = 2.0 / (t + 2.0)
        y_new = (1 - alpha_t) * y + alpha_t * b_star
        y_new = np.maximum(y_new, 0)
        ss = y_new.sum()
        if ss < 1e-15:
            y_new = y.copy()
        else:
            y_new = y_new / ss

        if t == 1:
            a_new = b_star.copy()
        else:
            momentum = (t - 1.0) / (t + 2.0)
            a_new = y_new + momentum * (y_new - y)
            a_new = project_simplex(a_new)

        y = y_new
        a = a_new

        # Time-averaged iterate
        avg_a = (avg_a * (n_avg - 1) + a) / n_avg
        n_avg += 1

        # Check scores (every few iterations to save time)
        if t % 5 == 0 or t < 20:
            score_a = internal_score(a)
            if score_a < best_score:
                best_score = score_a
                best_a = a.copy()
            score_y = internal_score(y)
            if score_y < best_score:
                best_score = score_y
                best_a = y.copy()
            if t % 50 == 0:
                score_avg = internal_score(avg_a)
                if score_avg < best_score:
                    best_score = score_avg
                    best_a = avg_a.copy()

        if verbose and t % 100 == 0:
            elapsed = time.monotonic() - t0
            print(f"      NL t={t} ({elapsed:.0f}s): best={best_score:.6f}, LP_M={M_val:.8f}")

    # Final check of time-averaged
    score_avg = internal_score(avg_a)
    if score_avg < best_score:
        best_score = score_avg
        best_a = avg_a.copy()

    return best_a, best_score


def subgradient_optimize(a0, time_limit, verbose=True):
    """Subgradient optimization with adaptive top-K peak targeting."""
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    best_a = a.copy()
    best_score = internal_score(a)
    t0 = time.monotonic()

    v = np.zeros(n)
    beta = 0.85
    base_lr = 0.05
    t = 0

    while time.monotonic() - t0 < time_limit:
        t += 1
        b = fast_autocorr(a)

        # Adaptive temperature for peak weighting
        progress = min(1.0, t / max(1, int(time_limit * 30)))
        T_smooth = 1.0 + 200.0 * (1.0 - progress) ** 2
        Tb = T_smooth * b
        max_Tb = Tb.max()
        exp_Tb = np.exp(Tb - max_Tb)
        w = exp_Tb / exp_Tb.sum()

        # Compute gradient via FFT
        conv_len = n + (2 * n - 1) - 1
        fft_size = 1 << (conv_len - 1).bit_length()
        A_rev = rfft(a[::-1].copy(), fft_size)
        W = rfft(w, fft_size)
        conv = irfft(A_rev * W, fft_size)
        grad = 2.0 * conv[n - 1:n - 1 + n]

        # Adaptive learning rate
        lr_t = base_lr / (1 + 0.005 * t)

        # Nesterov momentum
        v = beta * v + (1 - beta) * grad
        a_new = a - lr_t * v
        a_new = project_simplex(a_new)

        score = internal_score(a_new)
        if score < best_score:
            best_score = score
            best_a = a_new.copy()
        a = a_new

        if verbose and t % 500 == 0:
            elapsed = time.monotonic() - t0
            print(f"      SubGrad t={t} ({elapsed:.0f}s): best={best_score:.6f}")

    return best_a, best_score


def peak_shaving(a0, time_limit, seed=123):
    """Aggressive peak shaving with multiple strategies."""
    n = len(a0)
    rng = np.random.default_rng(seed)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    best_a = a.copy()
    best_score = internal_score(a)
    t0 = time.monotonic()
    stall = 0

    while time.monotonic() - t0 < time_limit:
        b = fast_autocorr(a)
        top_k = np.argsort(b)[::-1][:15]

        improved = False
        # Strategy 1: Move mass from peak contributors to low-peak areas
        for k in top_k[:8]:
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            if len(idx) == 0:
                continue
            contrib = a[idx] * a[k - idx]

            # Find the biggest contributor
            src = idx[np.argmax(contrib)]

            # Find target: low autocorrelation contribution
            target_score = np.zeros(n)
            for k2 in top_k[:5]:
                js2 = max(0, k2 - n + 1)
                je2 = min(n - 1, k2)
                idx2 = np.arange(js2, je2 + 1)
                for j in idx2:
                    target_score[j] += 1

            # Candidates: positions not contributing much to peaks
            candidates = np.where(target_score < 3)[0]
            if len(candidates) == 0:
                candidates = np.arange(n)
            # Prefer low-value positions
            candidates_sorted = candidates[np.argsort(a[candidates])]
            dst = candidates_sorted[rng.integers(0, max(1, len(candidates_sorted) // 4))]

            if src == dst:
                continue

            # Try multiple transfer amounts
            for frac in [0.001, 0.003, 0.005, 0.01, 0.02, 0.03, 0.05]:
                amt = a[src] * frac
                if amt < 1e-15 or a[src] - amt < 0:
                    continue
                a_trial = a.copy()
                a_trial[src] -= amt
                a_trial[dst] += amt
                a_trial = a_trial / a_trial.sum()
                score = internal_score(a_trial)
                if score < best_score - 1e-14:
                    a = a_trial
                    best_score = score
                    best_a = a.copy()
                    improved = True
                    stall = 0
                    break
            if improved:
                break

        # Strategy 2: Swap between two positions
        if not improved and stall < 200:
            i = rng.integers(n)
            j = rng.integers(n)
            if i != j:
                a_trial = a.copy()
                a_trial[i], a_trial[j] = a[j], a[i]
                score = internal_score(a_trial)
                if score < best_score:
                    a = a_trial
                    best_score = score
                    best_a = a.copy()
                    stall = 0

        # Strategy 3: Small random perturbation
        if not improved:
            i = rng.integers(n)
            j = rng.integers(n)
            if i != j and a[i] > 1e-10:
                frac = rng.uniform(0.002, 0.03)
                amt = a[i] * frac
                a_trial = a.copy()
                a_trial[i] -= amt
                a_trial[j] += amt
                a_trial = a_trial / a_trial.sum()
                score = internal_score(a_trial)
                if score < best_score:
                    a = a_trial
                    best_score = score
                    best_a = a.copy()
                    stall = 0

        if not improved:
            stall += 1
            if stall > 1000:
                break

    return best_a, best_score


def interpolate_sequence(f, new_n):
    """Interpolate a normalized sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp


def lse_smoothed_optimize(a0, time_limit, T_start=50.0, T_end=0.05, n_stages=20, lr=0.005):
    """LogSumExp-smoothed optimization with Adam optimizer."""
    n = len(a0)
    a_init = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a_init.sum()
    if s < 1e-15:
        a_init = np.ones(n) / n
    else:
        a_init = a_init / s
    z = np.log(np.maximum(a_init, 1e-30))
    t0 = time.monotonic()

    temps = np.geomspace(T_start, T_end, n_stages)
    best_a = a_init.copy()
    best_score = internal_score(a_init)

    m = np.zeros(n)
    v = np.zeros(n)
    beta1, beta2, eps = 0.9, 0.999, 1e-8
    t_adam = 0

    for si, stage_T in enumerate(temps):
        if time.monotonic() - t0 > time_limit:
            break
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 2:
            break

        iters = max(20, min(150, int(remaining * 50 / max(1, n_stages - si))))

        for it in range(iters):
            if time.monotonic() - t0 > time_limit:
                break

            a = softmax_fn(z)
            b = fast_autocorr(a)
            Tb = stage_T * b
            max_Tb = Tb.max()
            exp_Tb = np.exp(Tb - max_Tb)
            w = exp_Tb / exp_Tb.sum()

            # Gradient
            conv_len = n + (2 * n - 1) - 1
            fft_size = 1 << (conv_len - 1).bit_length()
            A_rev = rfft(a[::-1].copy(), fft_size)
            W = rfft(w, fft_size)
            conv = irfft(A_rev * W, fft_size)
            grad_a = 2.0 * conv[n - 1:n - 1 + n]

            # Project gradient to simplex tangent
            S = np.dot(grad_a, a)
            grad_z = a * (grad_a - S)

            t_adam += 1
            m = beta1 * m + (1 - beta1) * grad_z
            v = beta2 * v + (1 - beta2) * grad_z ** 2
            m_hat = m / (1 - beta1 ** t_adam)
            v_hat = v / (1 - beta2 ** t_adam)

            lr_t = lr / np.sqrt(1 + 0.01 * it)
            z = z - lr_t * m_hat / (np.sqrt(v_hat) + eps)

            if it % 25 == 0:
                a_check = softmax_fn(z)
                score = internal_score(a_check)
                if score < best_score:
                    best_score = score
                    best_a = a_check.copy()

        a = softmax_fn(z)
        score = internal_score(a)
        if score < best_score:
            best_score = score
            best_a = a.copy()

        if si % 5 == 0:
            elapsed = time.monotonic() - t0
            print(f"      LSE stage {si}/{n_stages} (T={stage_T:.3f}, {elapsed:.0f}s): best={best_score:.6f}")

    return best_a, best_score
