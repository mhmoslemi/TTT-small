**LSE Gradient Descent:**
- Objective: f(a) = (1/T) * log(sum_k exp(T * c[k])) where c = conv(a,a)
- Gradient: grad[i] = 2 * sum_j a[j] * w[j+i] where w[k] = exp(T*c[k]) / sum_l exp(T*c[l])
- Constraint: a >= 0, sum(a) = S (fixed)

Algorithm:
1. Compute c = conv(a, a) (via FFT, O(n log n))
2. Compute w = softmax(T * c) (O(n))
3. Compute grad = 2 * cross_corr(a, w) (via FFT, O(n log n))
4. Update: a_new = a - step * grad
5. Project: a_new = max(a_new, 0), then normalize to sum S
6. Repeat

The step size is crucial. Since the gradient of the LSE is bounded (|grad[i]| <= 2 for normalized w and a), a reasonable step size is O(1/n) or so.
