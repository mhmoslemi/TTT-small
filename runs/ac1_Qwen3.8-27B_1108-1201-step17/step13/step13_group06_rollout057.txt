Let me also think about the coordinate descent more carefully. In coordinate descent for this problem:
- At each step, pick a coordinate i.
- Determine the best value for a[i] given all other coordinates fixed.
- The objective is max_k C[k], and C[k] changes when a[i] changes.
- C[k] depends on a[i] if i is in the range [max(0, k-n+1), min(k, n-1)].
- For a given i, the set of k values that depend on a[i] is k in [i, i+n-2] (since a[i] contributes to C[k] when k-i is in [0, n-1], i.e., k in [i, i+n-1], but also a[k-i] must exist, so k-i in [0, n-1], meaning k in [i, i+n-1], and k <= 2n-2).

Actually, C[k] = sum_j a[j] * a[k-j]. The term a[i] appears when j=i (so k-i = a[k-i] must exist, i.e., k-i in [0,n-1], so k in [i, i+n-1]) or when k-j=i, i.e., j=k-i (so a[i] = a[k-j] and a[j] = a[k-i] must exist, i.e., k-i in [0,n-1], same condition).

So changing a[i] affects C[k] for k in [i, i+n-1] (intersected with [0, 2n-2]).

For the coordinate descent, the best value of a[i] given the constraint a >= 0, sum(a) = 1:
- We want to minimize max_k C[k]
- C[k] is linear in a[i] for k in the affected range (since C[k] = a[i] * (sum of other terms) + (terms not involving a[i]))
- Wait, C[k] = sum_j a[j]*a[k-j]. If we fix all a[j] for j != i, then:
  - C[k] = a[i] * a[k-i] + a[k-i] * a[i] + (sum over j != i, k-j != i of a[j]*a[k-j])
  - Wait, that's not right. Let me be more careful.
  - C[k] = sum_j a[j] * a[k-j]
  - The terms involving a[i] are: j=i gives a[i]*a[k-i], and j=k-i gives a[k-i]*a[i] (if k-i != i)
  - If k = 2i, then j=i and j=k-i are the same term, so it's a[i]^2.
  - Otherwise, C[k] = 2*a[i]*a[k-i] + (sum over j != i, j != k-i of a[j]*a[k-j])

So for a fixed i, C[k] is linear in a[i] (unless k = 2i, in which case it's quadratic).

This means the coordinate descent can be done efficiently:
- For coordinate i, the affected C[k] values are for k in [i, i+n-1] (valid range).
- For each such k, C[k] = c_k * a[i] + d_k (linear in a[i], except k=2i where it's c_k * a[i]^2 + d_k).
- We want to find a[i] >= 0 that minimizes max_k C[k], subject to the sum constraint.
- The sum constraint: if we change a[i] by δ, we need to compensate elsewhere. But in coordinate descent, we typically fix the sum by adjusting another coordinate or by re-normalizing.

Actually, for simplicity, let's do: fix all coordinates except a[i], find the optimal a[i] >= 0 (ignoring the sum constraint for now), then re-normalize. The re-normalization changes the objective, so it's not exact, but it's a good heuristic.

For the unconstrained optimal a[i]:
- We want min_{x >= 0} max_{k in affected} (c_k * x + d_k)
- This is a 1D convex optimization (min of max of linear functions is convex)
- The optimal x is where the "active" constraints intersect.
- Can be solved by bisection or by finding the intersection of the top two lines.

This is doable in O(n) time per coordinate step (since there are at most n affected k values).

    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    y = a.copy()
    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()

    # Initialize active set
    C = fast_autocorr(y)
    active_k = np.argsort(C)[::-1][:n_constr]

    warm_b = None
    stall_count = 0

    for t in range(1, 500000):
        if time.monotonic() - t0 > time_limit - 0.5:
            break

        b_star, M_val = solve_lp_active(y, active_k, warm_b)
        if b_star is None:
            warm_b = None
            # Shrink active set
            active_k = active_k[:max(10, len(active_k) // 2)]
            continue
        warm_b = b_star

        # Nesterov update
        alpha_t = 2.0 / (t + 2.0)
        y_new = (1.0 - alpha_t) * y + alpha_t * b_star
        y_new = np.maximum(y_new, 0)
        y_sum = y_new.sum()
        if y_sum < 1e-15:
            y_new = b_star.copy()
        else:
            y_new = y_new / y_sum

        if t == 1:
            a_new = b_star.copy()
        else:
            momentum = (t - 1.0) / (t + 2.0)
            a_new = y_new + momentum * (y_new - y)
            a_new = np.maximum(a_new, 0)
            s_new = a_new.sum()
            if s_new < 1e-15:
                a_new = y_new.copy()
            else:
                a_new = a_new / s_new

        y = y_new
        a = a_new

        # Evaluate and update best
        score_a = 2.0 * n * fast_autocorr(a).max()
        if score_a < best_score:
            best_score = score_a
            best_a = a.copy()
            stall_count = 0
        else:
            stall_count += 1

        score_y = 2.0 * n * fast_autocorr(y).max()
        if score_y < best_score:
            best_score = score_y
            best_a = y.copy()
            stall_count = 0

        # Update active set periodically
        if t % update_interval == 0:
            C = fast_autocorr(y)
            # Mix of top peaks and spread-out peaks
            n_top = n_constr * 2 // 3
            n_spread = n_constr - n_top
            top = np.argsort(C)[::-1][:n_top]
            # Spread: evenly spaced positions weighted by C value
            all_positions = np.arange(2 * n - 1)
            spread_mask = np.random.random(2 * n - 1) < (2 * n - 1) / max(n_spread * 3, 1)
            spread_candidates = all_positions[spread_mask]
            if len(spread_candidates) > n_spread:
                spread_candidates = spread_candidates[np.argsort(C[spread_candidates])[::-1][:n_spread]]
            active_k = np.unique(np.concatenate([top, spread_candidates]))[:n_constr]

        # Restart if stalled
        if stall_count > 300 and t > 100:
            a = best_a.copy()
            y = best_a.copy()
            active_k = np.argsort(fast_autocorr(y))[::-1][:n_constr]
            warm_b = None
            stall_count = 0

        if t % 5000 == 0:
            elapsed = time.monotonic() - t0
            print(f"      NC t={t} ({elapsed:.0f}s): best={best_score:.8f}, M={M_val:.8f}")

    return best_a, best_score


def ifta_refine(a0, time_limit, n_inner=20):
    """
    IFTA-style refinement using cyclic autocorrelation.
    Reduces peaks by adjusting in a combined time/frequency domain.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()

    # Target M starts at current cyclic max, decreases over time
    R_cyc = cyclic_autocorr(a)
    M_target = R_cyc.max() * 0.98
    gamma = 0.005

    while time.monotonic() - t0 < time_limit - 1:
        for _ in range(n_inner):
            if time.monotonic() - t0 > time_limit - 1:
                break
            # Compute gradient from top cyclic peaks
            A = rfft(a, n)
            R = irfft(A * A, n).real

            # Find peaks above target
            peak_idx = np.where(R > M_target)[0]
            if len(peak_idx) == 0:
                peak_idx = np.argsort(R)[::-1][:5]

            # Compute gradient contribution from top peaks
            n_peaks = min(15, len(peak_idx))
            peak_idx = peak_idx[np.argsort(R[peak_idx])[::-1][:n_peaks]]

            grad = np.zeros(n)
            for k in peak_idx:
                if R[k] > M_target * 0.99:
                    grad += np.roll(a, k)
            grad /= max(1, n_peaks)

            # Update
            a_new = a - gamma * grad
            a_new = np.maximum(a_new, 0)
            sn = a_new.sum()
            if sn < 1e-15:
                break
            a_new = a_new / sn
            a = a_new

        # Check exact score
        score = 2.0 * n * fast_autocorr(a).max()
        if score < best_score:
            best_score = score
            best_a = a.copy()

        # Adapt parameters
        R_cyc = cyclic_autocorr(a)
        R_max = R_cyc.max()
        if R_max > M_target:
            M_target = R_max * 0.995
        else:
            M_target = R_max * 0.99
        gamma = max(0.001, gamma * 0.999)

    return best_a, best_score


def informed_peak_shave(a0, time_limit, seed=42):
    """
    Peak shaving with multi-peak awareness and smart destination selection.
    """
    n = len(a0)
    rng = np.random.default_rng(seed)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()
    stall = 0

    while time.monotonic() - t0 < time_limit - 1:
        C = fast_autocorr(a)
        C_max = C.max()

        # Find all significant peaks (within 2% of max)
        threshold = C_max * 0.98
        peaks = np.where(C >= threshold)[0]
        if len(peaks) == 0:
            peaks = np.argsort(C)[::-1][:3]
        peaks = peaks[np.argsort(C[peaks])[::-1][:20]]

        # Compute danger map: which positions a[i] contribute to peaks
        danger = np.zeros(n)
        for k in peaks:
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            danger[idx] += a[idx] * a[k - idx]

        # Find the most dangerous source position
        src_candidates = np.argsort(danger)[::-1][:20]

        # Find safe destinations (low danger, low current value)
        safe_score = a + 0.1 * danger
        dst_candidates = np.argsort(safe_score)[:30]
        dst_candidates = dst_candidates[dst_candidates != src_candidates[0]]

        improved = False
        for src in src_candidates[:10]:
            if a[src] < 1e-10:
                continue
            for dst in dst_candidates[:15]:
                if dst == src:
                    continue
                for frac in [0.003, 0.008, 0.015, 0.03, 0.05, 0.08]:
                    amt = a[src] * frac
                    if amt < 1e-12:
                        continue
                    a_trial = a.copy()
                    a_trial[src] -= amt
                    a_trial[dst] += amt
                    if a_trial[src] < -1e-12:
                        continue
                    a_trial = np.maximum(a_trial, 0)
                    st = a_trial.sum()
                    if st < 1e-12:
                        continue
                    a_trial /= st
                    new_max = fast_autocorr(a_trial).max()
                    if new_max < C_max * (1.0 - 1e-9):
                        a = a_trial
                        new_score = 2.0 * n * new_max
                        if new_score < best_score:
                            best_score = new_score
                            best_a = a.copy()
                        improved = True
                        stall = 0
                        break
                if improved:
                    break
            if improved:
                break

        if not improved:
            stall += 1
            # Random perturbation
            if stall % 20 == 0:
                n_pert = rng.integers(1, 6)
                a_trial = a.copy()
                for _ in range(n_pert):
                    i = rng.integers(n)
                    j = rng.integers(n)
                    if i != j and a_trial[i] > 1e-8:
                        frac = rng.uniform(0.002, 0.04)
                        amt = a_trial[i] * frac
                        a_trial[i] -= amt
                        a_trial[j] += amt
                a_trial = np.maximum(a_trial, 0)
                st = a_trial.sum()
                if st > 1e-10:
                    a_trial /= st
                    score = 2.0 * n * fast_autocorr(a_trial).max()
                    if score < best_score:
                        a = a_trial
                        best_score = score
                        best_a = a.copy()
                        stall = 0

            if stall > 300:
                break

    return best_a, best_score


def coord_perturb(a0, time_limit, seed=123):
    """
    Informed coordinate perturbation: try reducing high-contribution
    coordinates and redistributing to low-contribution ones.
    """
    n = len(a0)
    rng = np.random.default_rng(seed)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()

    iteration = 0
    while time.monotonic() - t0 < time_limit - 1:
        iteration += 1
        C = fast_autocorr(a)
        C_max = C.max()

        # Find the global peak
        k_peak = C.argmax()
        js = max(0, k_peak - n + 1)
        je = min(n - 1, k_peak)
        idx = np.arange(js, je + 1)
        contrib = a[idx] * a[k_peak - idx]

        # Top contributors to the peak
        top_contrib = np.argsort(contrib)[::-1][:10]
        src_set = idx[top_contrib]

        # Find positions that DON'T contribute to the top 5 peaks
        top5_peaks = np.argsort(C)[::-1][:5]
        no_contrib = np.ones(n, dtype=bool)
        for k in top5_peaks:
            js2 = max(0, k - n + 1)
            je2 = min(n - 1, k)
            no_contrib[js2:je2 + 1] = False

        # Safe destinations: don't contribute to top peaks, low value
        safe_mask = no_contrib.copy()
        safe_positions = np.where(safe_mask)[0]
        if len(safe_positions) < 5:
            safe_positions = np.where(a < np.median(a))[0]

        improved = False
        for src in src_set[:5]:
            if a[src] < 1e-10:
                continue
            n_try = min(10, len(safe_positions))
            dsts = safe_positions[np.argsort(a[safe_positions])[:n_try]]
            for dst in dsts:
                for frac in [0.005, 0.01, 0.02, 0.04]:
                    amt = a[src] * frac
                    a_trial = a.copy()
                    a_trial[src] -= amt
                    a_trial[dst] += amt
                    a_trial = np.maximum(a_trial, 0)
                    st = a_trial.sum()
                    if st < 1e-12:
                        continue
                    a_trial /= st
                    nm = fast_autocorr(a_trial).max()
                    if nm < C_max * (1 - 1e-10):
                        a = a_trial
                        ns = 2.0 * n * nm
                        if ns < best_score:
                            best_score = ns
                            best_a = a.copy()
                        improved = True
                        break
                if improved:
                    break
            if improved:
                break

        if not improved:
            # Try random pairs
            for _ in range(20):
                i = rng.integers(n)
                j = rng.integers(n)
                if i == j or a[i] < 1e-8:
                    continue
                frac = rng.uniform(0.001, 0.02)
                amt = a[i] * frac
                a_trial = a.copy()
                a_trial[i] -= amt
                a_trial[j] += amt
                a_trial = np.maximum(a_trial, 0)
                st = a_trial.sum()
                if st < 1e-12:
                    continue
                a_trial /= st
                nm = fast_autocorr(a_trial).max()
                if nm < C_max * (1 - 1e-10):
                    a = a_trial
                    ns = 2.0 * n * nm
                    if ns < best_score:
                        best_score = ns
                        best_a = a.copy()
                    improved = True
                    break

            if not improved and iteration % 500 == 0:
                # Restart from best with noise
                a = best_a.copy()
                noise = rng.normal(0, 0.005, n)
                a = a * (1 + noise)
                a = np.maximum(a, 0)
                s2 = a.sum()
                if s2 > 1e-10:
                    a /= s2

    return best_a, best_score


def interpolate_sequence(f, new_n):
    """Interpolate a normalized sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp /= ss
    return f_interp


def propose_candidate(seed=42, time_budget=1800.0):
    """
    Multi-phase optimization:
    Phase 1: Fast Nesterov CG (main workhorse, ~55% time)
    Phase 2: IFTA frequency refinement (~15% time)
    Phase 3: Informed peak shaving (~15% time)
    Phase 4: Coordinate perturbation (~10% time)
    Phase 5: Try different length + quick Nesterov (~5% time)
    """
    t_global = time.monotonic()
    time_budget = min(float(time_budget) - 60.0, 1740.0)
    rng = np.random.default_rng(seed)

    # Get parent
    best_seq = None
    best_score = float('inf')

    parent = get_parent_sequence()
    if parent is not None:
        n_base = len(parent)
        best_seq = parent.copy()
        best_score = evaluate_safe(parent)
        print(f"Parent: n={n_base}, score={best_score:.8f}")
    else:
        n_base = 1600
        x = np.linspace(0, np.pi, n_base)
        best_seq = np.cos(x / 2) ** 2
        best_seq = best_seq / best_seq.sum()
        best_score = evaluate_safe(best_seq)
        print(f"Default init: n={n_base}, score={best_score:.8f}")

    def try_update(a, label):
        nonlocal best_seq, best_score
        if a is None:
            return
        a = np.maximum(np.asarray(a, dtype=np.float64), 0)
        s = a.sum()
        if s < 0.01:
            return
        a = a / s
        sc = evaluate_safe(a)
        if np.isfinite(sc) and sc < best_score:
            best_score = sc
            best_seq = a.copy()
            elapsed = time.monotonic() - t_global
            print(f"  *** NEW BEST [{label}]: {sc:.8f} (n={len(a)}, t={elapsed:.0f}s)")

    # === Phase 1: Fast Nesterov with constraint generation ===
    remaining = time_budget - (time.monotonic() - t_global)
    t1 = min(remaining * 0.55, 900.0)
    print(f"\n=== Phase 1: Nesterov CG n={n_base}, budget={t1:.0f}s ===")
    if t1 > 30:
        a_out, s_out = nesterov_cg(best_seq, t1, n_constr=80, update_interval=5)
        try_update(a_out, f"nc_n{n_base}")

    # === Phase 1b: Another Nesterov run with different params ===
    remaining = time_budget - (time.monotonic() - t_global)
    t1b = min(remaining * 0.15, 200.0)
    print(f"=== Phase 1b: Nesterov CG (120 constr) budget={t1b:.0f}s ===")
    if t1b > 30:
        a_out, s_out = nesterov_cg(best_seq, t1b, n_constr=120, update_interval=3)
        try_update(a_out, f"nc120_n{n_base}")

    # === Phase 2: IFTA refinement ===
    remaining = time_budget - (time.monotonic() - t_global)
    t2 = min(remaining * 0.15, 200.0)
    print(f"=== Phase 2: IFTA n={n_base}, budget={t2:.0f}s ===")
    if t2 > 15:
        a_out, s_out = ifta_refine(best_seq, t2, n_inner=15)
        try_update(a_out, f"ifta_n{n_base}")

    # === Phase 3: Informed peak shaving ===
    remaining = time_budget - (time.monotonic() - t_global)
    t3 = min(remaining * 0.15, 200.0)
    print(f"=== Phase 3: Peak shaving n={n_base}, budget={t3:.0f}s ===")
    if t3 > 10:
        a_out, s_out = informed_peak_shave(best_seq, t3, seed=777)
        try_update(a_out, f"ps_n{n_base}")

    # === Phase 4: Coordinate perturbation ===
    remaining = time_budget - (time.monotonic() - t_global)
    t4 = min(remaining * 0.10, 120.0)
    print(f"=== Phase 4: Coord perturb n={n_base}, budget={t4:.0f}s ===")
    if t4 > 10:
        a_out, s_out = coord_perturb(best_seq, t4, seed=456)
        try_update(a_out, f"cp_n{n_base}")

    # === Phase 5: Try different length ===
    remaining = time_budget - (time.monotonic() - t_global)
    if remaining > 60:
        n_alt = n_base + 100
        t5 = min(remaining * 0.4, 200.0)
        print(f"=== Phase 5: Nesterov n={n_alt}, budget={t5:.0f}s ===")
        if t5 > 30:
            init_alt = interpolate_sequence(best_seq, n_alt)
            a_out, s_out = nesterov_cg(init_alt, t5, n_constr=80, update_interval=5)
            try_update(a_out, f"nc_n{n_alt}")

    # === Phase 6: Final peak shave ===
    remaining = time_budget - (time.monotonic() - t_global)
    if remaining > 20:
        t6 = min(remaining * 0.5, 100.0)
        print(f"=== Phase 6: Final peak shave, budget={t6:.0f}s ===")
        if t6 > 10:
            a_out, s_out = informed_peak_shave(best_seq, t6, seed=999)
            try_update(a_out, "ps_final")

    # === Phase 7: Final IFTA polish ===
    remaining = time_budget - (time.monotonic() - t_global)
    if remaining > 15:
        t7 = min(remaining * 0.5, 60.0)
        print(f"=== Phase 7: Final IFTA, budget={t7:.0f}s ===")
        if t7 > 10:
            a_out, s_out = ifta_refine(best_seq, t7, n_inner=30)
            try_update(a_out, "ifta_final")

    # Final verification
    if best_seq is not None:
        fs = evaluate_safe(best_seq)
        if np.isfinite(fs):
            best_score = fs
        print(f"\nFINAL: score={best_score:.8f}, n={len(best_seq)}, time={time.monotonic()-t_global:.0f}s")
    else:
        print("\nERROR: No valid sequence!")
        return [1.0]

    return [float(x) for x in best_seq]
