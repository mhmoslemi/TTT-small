**Interior Point Method for the specific structure:**

The LP is:
min M
s.t. sum_k max(0, (a*b)_k - M) = 0  [complementarity]
     sum b = 1
     b >= 0

This can be viewed as a min-max problem:
min_b max_k (a*b)_k  s.t. sum b = 1, b >= 0

The KKT conditions are:
1. sum b = 1, b >= 0
2. There exists a distribution q over k such that:
   - (a*b)_k ≤ M for all k
   - q_k > 0 only if (a*b)_k = M
   - sum_k q_k * a_{k-j} = λ for all j with b_j > 0 (stationarity)
   - sum_k q_k * a_{k-j} ≥ λ for all j (for b_j = 0 case)

The stationarity condition is: (q * a)_j = λ for all j with b_j > 0.

This means: find q (distribution over lags) and λ such that:
- (q * a)_j ≈ λ for all j (approximately, since q is a distribution and a is fixed)
- max_k (a*b)_k is minimized where b is concentrated on the j where (q*a)_j = λ

This gives an alternating minimization:
1. Given b, update q: q_k ∝ exp(η * (a*b)_k) (or concentrate on peaks)
2. Given q, update b: b_j ∝ exp(-η' * max(0, (q*a)_j - λ)) or b_j = 1/|{j: (q*a)_j = λ}|

Actually, for the inner problem (given q):

where (B q)[j,m] = q_{j+m}. The gradient is 2 * B q @ b. At optimum, the active constraints give:
2 * (B q @ b)_j = λ for j with b_j > 0.

So b is concentrated on the set {j: (B q @ b)_j is minimal}. This is a bit circular.

Let me just use a simpler approach: **Frank-Wolfe (conditional gradient) method**.

- f(b) = max_k (a*b)_k
