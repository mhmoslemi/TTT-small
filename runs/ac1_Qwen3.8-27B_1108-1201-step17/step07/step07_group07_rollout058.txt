Let me now think about the log-sum-exp gradient more carefully.

Let f(a) = (1/beta) * log(sum_{k=0}^{2n-2} exp(beta * conv(a,a)_k))

The gradient:
∂f/∂a[m] = (1/beta) * sum_k exp(beta * conv_k) * (∂conv_k/∂a[m]) / sum_k exp(beta * conv_k)
= sum_k p_k * (∂conv_k/∂a[m])

where p_k = exp(beta * conv_k) / sum_j exp(beta * conv_j) (softmax weights)

And ∂conv_k/∂a[m] = 2*a[k-m] if 0 <= k-m < n, else 0.

So ∂f/∂a[m] = 2 * sum_{k: 0<=k-m<n} p_k * a[k-m]
= 2 * a^T * (P shifted to position m)
= 2 * (P_conv * a)[m]

where P_conv is a "blurred" version of the peak weights.

Actually, let me write it differently. Let w_k = p_k (the softmax weights on the convolution values). Then:
∂f/∂a[m] = 2 * sum_{k=m}^{m+n-1} w_k * a[k-m]  (where w_k = 0 for k < 0 or k >= 2n-1)

This is a weighted sum of a[0], a[1], ..., a[n-1] with weights 2*w_m, 2*w_{m+1}, ..., 2*w_{m+n-1}.

This can be computed via convolution: g = 2 * convolve(w, a) (with appropriate truncation).

Or using FFT: g = IFFT(FFT(w_zero_padded) * FFT(a_zero_padded))[:n]

This is the same FFT trick used before, just with different weights w (softmax instead of uniform on active peaks).

The advantage of log-sum-exp is that:
1. It's smooth (C∞)
2. The weights p_k concentrate on the top peaks (for large beta), giving a well-defined gradient
3. We can use accelerated methods (Nesterov, L-BFGS)

- Use backtracking line search to ensure decrease
- Adaptive beta: start small (smooth), increase over time (sharper, converging to true max)

This should be significantly faster than the raw subgradient method.

Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Log-sum-exp smoothed projected gradient with Nesterov acceleration
2. Intensive LP-based peak reduction with adaptive M
3. FFT-accelerated subgradient for global progress
4. Pair-wise coordinate descent for final polish
5. Multi-length exploration

import numpy as np
from scipy.fft import rfft, irfft
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Project onto probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho_vals = np.arange(1, n + 1)
    cond = u * rho_vals > (cssv - 1.0)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def eval_max_b(a):
    """Return max of auto-convolution for sequence a (assumed sum=1)."""
    b = fast_convolve(a)
    return float(b.max())


def lse_projected_gradient(a0, time_limit, beta_init=50.0, beta_final=500.0,

    Log-sum-exp smoothed projected gradient with Nesterov acceleration.
    Minimizes smooth approximation of max(conv(a,a)) on the simplex.

    t0 = time.monotonic()
    n = len(a0)
    a = a0.copy().astype(np.float64)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    v = np.zeros(n)
    best_a = a.copy()
    best_obj = eval_max_b(a)
    cur_lr = lr_init
    no_improve = 0
    
    # FFT size for computing gradient

    # This is a correlation, computable via FFT
    fft_size = 1 << (3 * n - 2).bit_length()
    
    while time.monotonic() - t0 < time_limit:
        # Compute convolution
        b = fast_convolve(a)
        b_max = b.max()

        b_shifted = b - b_max  # Now max is 0
        exp_b = np.exp(beta_init * b_shifted)
        w = exp_b / exp_b.sum()

        # This is the cross-correlation of w and a, truncated to length n
        # corr[m] = sum_k w[k] * a[k-m] = (w * reverse(a))[m + n - 1]
        # Or: use FFT

        W = rfft(w, fft_size)
        # The correlation sum_k w[k]*a[k-m] = sum_k w[k]*a[(k-m) mod ...]

        # Then g[m] = 2 * sum_j h[m+j] * a[j] = 2 * (h reversed * a)[m]... 
        # 
        # Actually, g[m] = 2 * sum_j a[j] * w[m+j] for j=0..n-1 where m+j < 2n-1
        # This is the cross-correlation of a and w at lag m
        # = sum_j a[j] * w[m+j]
        #
        # In terms of convolution: if we define w_rev[k] = w[2n-2-k], then
        # (a * w_rev)[m + 2n-2] = sum_j a[j] * w_rev[m+2n-2-j] = sum_j a[j] * w[j-m]
        # That gives sum_j a[j]*w[j-m], not what we want.

        # Then IFFT(conj(A_full) * W_full)[m] = sum_j conj(a[j]) * w[m+j] (circular)
        # For real: = sum_j a[j] * w[m+j] (with circular wrap-around)
        # If fft_size >= 3n-2, there's no wrap-around issue for m < n.

        a_new = project_simplex(a + v)

        obj_new = eval_max_b(a_new)
        if obj_new < best_obj - 1e-14:

            best_a = a_new.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        a = a_new

            cur_lr = max(cur_lr * 0.5, lr_init * 0.01)
            no_improve = 0
        elif no_improve >= 2500:
            cur_lr *= 0.95
        elif no_improve >= 1000:
            cur_lr *= 0.98
        
        # Increase beta over time (sharpen the approximation)
        beta_init *= 1.001
    
    return best_a, best_obj
