```python
def compute_grad(a, w, n):
    """Compute gradient of weighted sum of convolution values.
    
    grad[i] = 2 * sum_j a[j] * w[j+i] (with w zero-padded)
    = 2 * cross_correlation(a, w)[i]
    """
    # Need FFT size >= n + len(w) - 1 = n + (2n-1) - 1 = 3n - 2
    fft_size = 1 << (3 * n - 2).bit_length()
    A = fft(a, fft_size)
    W = fft(w, fft_size)
    corr = ifft(A * np.conj(W)).real[:n]
    return 2.0 * corr
```

def multiplicative_descent(a, time_limit, T_init=0.1, T_final=0.001, 
                           eta_init=0.1, eta_min=0.001, seed=42):
    """
    Multiplicative gradient descent to minimize 2n*max(conv(a,a))/(sum(a))^2.
    
    Uses soft-max weighted gradient with multiplicative (exponential) updates.
    """
    rng = np.random.default_rng(seed)
    n = len(a)
    a = np.maximum(a.copy(), 1e-30)
    a = a / a.sum()
    
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    n_ = len(a)
    
    t0 = time.monotonic()
    no_improve = 0
    max_no_improve = 500  # iterations without improvement before restart
    
    eta = eta_init
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        elapsed_frac = (time.monotonic() - t0) / time_limit
        T = T_init * (T_final / T_init) ** elapsed_frac
        
        # Compute convolution
        b = fast_convolve(a)
        max_b = b.max()
        score = 2.0 * n * max_b  # since sum(a) = 1
        
        # Track best
        if score < best_score - 1e-12:
            best_score = score
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        # Restart if stuck
        if no_improve > max_no_improve:
            a = best_a + rng.standard_normal(n) * 0.01
            a = np.maximum(a, 1e-10)
            a = a / a.sum()
            no_improve = 0
            eta = max(eta_min, eta * 0.5)
            continue
        
        # Compute weights (soft-max)
        w = np.exp(b / T - max_b / T)
        w = w / w.sum()
        
        # Compute gradient
        grad = compute_grad(a, w, n)
        
        # Multiplicative update
        # a_new[i] = a[i] * exp(-eta * grad[i] / max(grad))
        grad_max = grad.max()
        if grad_max < 1e-30:
            grad_max = 1.0
        a = a * np.exp(-eta * grad / grad_max)
        a = np.maximum(a, 1e-30)
        a = a / a.sum()
        
        # Adaptive eta: decrease slowly
        eta = max(eta_min, eta * 0.9995)
    
    return best_a, best_score

**Key differentiator: Spectral domain approach**

The GS (Gerchberg-Saxton) approach works in the frequency domain. Here's how I'd adapt it:

1. We want the autocorrelation b to be "flat" (all values close to the mean)
2. In the frequency domain, flat b corresponds to concentrated |A(f)|^2 (peaky power spectrum)
3. So we want to make the power spectrum of a as concentrated as possible (at low frequencies)

GS iteration:
1. Start with a (time domain)
2. Compute A = FFT(a_padded) (pad to length >= 2n-1)
3. Compute |A|^2
4. Modify |A|^2 to be more concentrated: 
   - Option A: Keep only the lowest P frequency bins (set others to 0)
   - Option B: Multiply by a Gaussian window in frequency: |A_new|^2 = |A|^2 * exp(-f^2 / (2*sigma^2))
   - Option C: Soft threshold: |A_new|^2[f] = |A[f]|^2 * max(0, 1 - |A[f]|^2 / T) (not sure this helps)
5. Keep phase: A_new = sqrt(|A_new|^2) * exp(i * angle(A))
6. a_new = IFFT(A_new)
7. Enforce non-negativity: a_new = max(a_new, 0)
8. Renormalize: a_new /= sum(a_new)
9. Repeat

Option B is the most flexible. The parameter sigma controls how concentrated the spectrum should be. Small sigma → very concentrated → smooth time-domain signal. Large sigma → less concentrated → less smooth.

For our problem, we want the time-domain signal to be "smooth" (not too spiky) so that its autocorrelation is flat. A Gaussian window in frequency with appropriate sigma should help.

But there's a subtlety: We don't want the signal to be TOO smooth (like
a constant), because a uniform signal gives score = 2. We want it to be "moderately smooth" with some variation.

Actually, I think the GS approach might not directly help here. The issue is that we're trying to minimize the MAX of the autocorrelation, not make it perfectly flat. The GS approach would try to make it perfectly flat, which would give a constant signal (score = 2).
