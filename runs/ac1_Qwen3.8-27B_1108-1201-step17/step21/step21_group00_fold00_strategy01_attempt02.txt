### Approach and Rationale
The evaluation function is:
\[
\text{score} = \frac{2n \cdot \max(\text{convolve}(a, a))}{(\sum a)^2}
\]
for a non-negative sequence `a` with each element bounded between 0 and 1000.

**Key Insights:**
1. **Arithmetic Progression Structure:** Using sequences derived from arithmetic progressions (AP) between sorted elements often reduces the objective value significantly.
2. **Capped Optimization:** Capping values at 1000 introduces a deviation that can lead to better minimization potential.
3. **Template-Based Search:** Sequences with alternating increasing and decreasing segments (templates) can be optimized systematically.

**Proposed Strategy:**
1. **Base Template Optimization (ap3_optim):** Develop a template sequence with three distinct phases (starting, middle, ending) that help structure the AP segments.
2. **Constrained Optimization (uneven_sum):** Use Nelder-Mead simplex method to optimize within the [0, 1000] bound constraints, accepting sequences that yield finite scores.
3.painless simplification: Focus the search on sequences derived from these templates.

### Mathematical Specification
Define the optimization boundary for the primary search:
- **Bounds:** Each element is in [0, 1000]
- **Normalization:** Maintain sum ≥ 0.01 initially for direct evaluation
- **Objective:** Minimize the evaluation score via template-based optimization
