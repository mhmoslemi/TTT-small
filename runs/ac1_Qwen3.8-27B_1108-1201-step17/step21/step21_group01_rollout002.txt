= sum_{i=max(0,k-n+1)}^{min(n-1,k)} y[i] * g[k-i]

Let j = k-i, so i = k-j:
= sum_{j=max(0,k-n+1)}^{min(n-1,k)} y[k-j] * g[j]

So the coefficient of g[j] in C(y,g)[k] is y[k-j] if k-j is in [0,n-1], else 0.

For the LP:
A[k, j] = y[k-j] if 0 ≤ k-j ≤ n-1, else 0
(For k = 0, 1, ..., 2n-2 and j = 0, 1, ..., n-1)

This is a Toeplitz-like matrix (each row is a shifted version of y).

For efficiency, I'll build this as a sparse matrix.

def fast_autocorr(a):
    """Compute full linear convolution a*a using FFT."""
    n = len(a)
    size = 2*n - 1
    fsize = 1 << (size-1).bit_length()
    A = np.fft.rfft(a, fsize)
    return np.fft.irfft(A*A, fsize)[:size]

def fast_cross(a, b):
    """Compute full linear convolution a*b using FFT."""
    n, m = len(a), len(b)
    size = n + m - 1
    fsize = 1 << (size-1).bit_length()
    A = np.fft.rfft(a, fsize)
    B = np.fft.rfft(b, fsize)
    return np.fft.irfft(A*B, fsize)[:size]
