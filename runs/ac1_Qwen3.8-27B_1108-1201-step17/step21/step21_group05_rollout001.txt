Actually, let me think about one more thing: the "pressure equalization" idea from the previous code. The idea is to compute the "pressure" at each position (how much it contributes to the peak lags) and then adjust the sequence to equalize the pressure. This is similar to the "water-filling" approach in information theory.

The pressure at position i is:
p[i] = sum_{k in top_lags} w_k * a[k-i] (where the sum is over valid k-i)

If p[i] is high, position i is contributing a lot to the peaks, so we should reduce a[i].
If p[i] is low, position i is not contributing much, so we can increase a[i].

The update is: a[i] *= exp(-lr * (p[i] - mean(p)))

This is essentially the same as mirror descent with a specific subgradient. The difference is in how the weights w_k are chosen.

In the previous code, w_k = top_vals[k]^2 (quadratic weighting). This emphasizes the largest peaks more. Alternatively, we could use:
- w_k = top_vals[k] (linear)
- w_k = 1 (uniform)
- w_k = top_vals[k]^p for various p

I think the quadratic weighting is reasonable, but we could also try a mixture.

import time
from scipy.ndimage import gaussian_filter1d

    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()

    return np.fft.irfft(A * A, fft_size)[:size]

    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a, dtype=np.float64) / len(a)
    return a / s

    n = len(a)
    return 2.0 * n * fast_conv(a).max()

        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')

def compute_subgradient(a, top_idx, top_vals, k_sel):
    n = len(a)
    s = np.zeros(n, dtype=np.float64)
    for ii in range(k_sel):
        ki = int(top_idx[ii])
        w = top_vals[ii] / top_vals[0] if top_vals[0] > 0 else 1.0/k_sel
        j_start = max(0, ki - n + 1)
        j_end = min(n, ki + 1)
        if j_start < j_end:
            indices = np.arange(j_start, j_end)
            s[indices] += 2.0 * w * a[ki - indices]
    return s
