- Or: `||(ac/||ac||)_p||_p * ||ac||_inf` for p > 1 (Lp norm)
- Or: `max(ac) + (1/T) * sum_k (ac_k - max(ac))_+` (a smooth-ish approximation)

The simplest: use the **power-sum approximation**:
`PS(ac, p) = (1/m) * sum(ac_k^p)` where m = 2n-1 and p is large (like 50-100).

For p > max(ac) * m (or something), this approximates the max. Actually, for p -> infinity, `(1/m * sum ac_k^p)^(1/p) -> max(ac_k)`.

The gradient of `PS(ac, p)` w.r.t. `a` is:
`grad[j] = p * sum_k (ac_k)^(p-1) * d(ac_k)/da[j]`
`= p * sum_k (ac_k)^(p-1) * (a[k-j] + a[j-k])` (with boundary conditions)

This can be computed via FFT in O(n log n).

Then we can use Adam optimizer with projection onto the simplex.

**Adam + Projected Gradient with Lp-norm objective**:

1. Initialize a from parent (normalized to sum=1).
2. For each step:
   a. Compute ac = convolve(a, a)
   b. Compute target = (1/m) * sum(ac^p) (or (1/m) * sum(ac^p))^(1/p)
   c. Compute grad = p * corr(ac^(p-1), a) (the correlation can be done via FFT)
   d. Adam update: a <- a - lr * grad (with Adam momentum)
   e. Project onto simplex: a <- project_simplex(a)
3. Periodically evaluate true objective.

The Lp-norm approach is:
- Objective: `J_p(a) = (1/m) * sum_k ac_k[a]^p` (or its p-th root)
- This is smooth for p >= 1 (when ac_k > 0, which holds for a >= 0)
- Gradient is computable in O(n log n)
- We can use any convex/non-convex optimizer

But wait - is `J_p` convex in a (restricted to simplex)? Not necessarily, for the same reason as above.

However, in practice, Adam or L-BFGS can still find good local minima even for non-convex objectives.
