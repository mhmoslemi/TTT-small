One key optimization: in the LP-FW, after finding the direction g and doing the line search, I should check which NEW constraints are violated (i.e., the convolution of the new point exceeds M at lags not in the active set). This helps the active set grow to include all important constraints.

Another optimization: instead of recomputing the full autocorrelation at every line search evaluation, I can use the FFT of both a and g to compute the convolution of their convex combination more efficiently:
conv((1-α)*a + α*g) = (1-α)^2 * conv(a) + 2*α*(1-α) * cross(a,g) + α^2 * conv(g)

Where cross(a,g) = convolve(a, g). I can precompute FFT of a and g, and the cross is just ifft(FFT(a)*FFT(g)).

This saves one FFT per line search evaluation!

```python
def conv_from_fft(FA, Fg, alpha, conv_a, conv_g, fft_size):
    """Compute conv of (1-alpha)*a + alpha*g from precomputed FFTs."""
    # conv = (1-a)^2 * conv_a + 2*a*(1-a) * cross + a^2 * conv_g
    cross = np.fft.irfft(FA * Fg, fft_size)
    factor1 = (1.0 - alpha) ** 2
    factor2 = 2.0 * alpha * (1.0 - alpha)
    factor3 = alpha ** 2
    return factor1 * conv_a + factor2 * cross + factor3 * conv_g
```

Wait, this isn't quite right because the convolution is bilinear, not the square of a linear combination. Let me reconsider.

If h = (1-α)*a + α*g, then:
conv(h, h) = conv((1-α)a + αg, (1-α)a + αg)
= (1-α)^2 conv(a,a) + 2α(1-α) conv(a,g) + α^2 conv(g,g)

Yes! This is correct because convolution is bilinear. And I can compute conv(a,g) from the precomputed FFTs:
conv(a,g) = ifft(FFT(a) * FFT(g))

So I only need to compute the cross-convolution once, and then each line search evaluation is just a linear combination.

This is a significant speedup for the line search! Let me implement this.

```python
def build_lp_matrix(a, lags, n):
    K = len(lags)
    if K == 0:
        return np.zeros((0, n))
    # Use sparse construction
    coeffs = np.zeros((K, n), dtype=np.float64)
    for jj in range(K):
        k = int(lags[jj])
        i_start = max(0, k - n + 1)
        i_end = min(n, k + 1)
        if i_start < i_end:
            idx = np.arange(i_start, i_end)
            coeffs[jj, idx] = a[k - idx]
    return coeffs

def lp_direction(a, active_set, solver):
    n = len(a)
    clist = sorted(active_set)
    K = len(clist)
    if K == 0:
        return None
    # Cap active set
    if K > 500:
        ac = fast_autocorr(a)
        M = ac.max()
        margins = np.array([M - ac[k] for k in clist])
        keep = np.argsort(margins)[:500]
        clist = [clist[i] for i in keep]
        K = 500
    coeffs = build_lp_matrix(a, clist, n)
    g_var = cp.Variable(n, nonneg=True)
    M_var = cp.Variable()

            gs = g_val.sum()

    except Exception:
        pass
```
