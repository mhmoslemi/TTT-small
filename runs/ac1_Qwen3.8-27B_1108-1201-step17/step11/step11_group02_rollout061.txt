4. The condition for peak equalization is that we should reduce `a` in directions that increase the lower peaks and decrease `a` in directions that increase the higher peaks

This is a subgradient of the "excess peak" function, which is a proxy for the max.

Now, the FTRL/mirror descent update would be:
`log(a_new) = log(a) - eta * grad`
`a_new = exp(log(a_new) - max(log(a_new)))`
`a_new = a_new / sum(a_new)`

This is the multiplicative weight update.

Let me think about the step size. The gradient magnitude depends on the scale of `a`. Since we normalize `sum(a) = 1`, the values of `a` are of order `1/n`. The peaks of `b` are of order `1/n` (for uniform) to `1/n^2 * n = 1/n` (worst case). Actually for `sum(a)=1`, `b[k] = sum_i a[i]*a[k-i] <= (max a)^2 * n` but also `b[k] <= (sum a)^2 / n = 1/n` by Cauchy-Schwarz... no that's not right.

Actually, `b[n-1] = sum_i a[i]^2 <= (sum a)^2 = 1` (trivially). And by Cauchy-Schwarz, `b[n-1] >= 1/n` (when all a[i] = 1/n).

So the peaks are in the range [1/n, 1] for normalized a. The excess is of similar magnitude.

The gradient `grad[i] = -sum_k excess_k * a[k-i]` has magnitude roughly `m * (excess_scale) * (1/n)` where `excess_scale ~ 1/n`. So `|grad| ~ m/n^2`.

For the multiplicative update to be effective, we need `eta * |grad|` to be of order 1 for the coordinates that need the most change. So `eta ~ n^2/m`.

For n=1200, m=5: `eta ~ 288000`. That's a huge step size! This makes sense because the values of `a` are small (~1/1200) and we need to move them by a meaningful amount.

Actually, let me reconsider. The multiplicative update is:
`a_new[i] = a[i] * exp(-eta * grad[i])`

If `a[i] ~ 1/n` and `grad[i] ~ 1/n^2`, then `eta * grad[i] ~ eta/n^2`. For this to be O(1), we need `eta ~ n^2`.

But we also need `eta * grad[i]` to not be too large (or the exp will overflow/underflow). So we should normalize the gradient.

Let me normalize: `grad_norm = grad / (max(|grad|) + eps)` then use a moderate eta.

```python
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Diverse parametric initialization at multiple n values
2. Peak-equalization FTRL (multiplicative weight updates)
3. p-norm L-BFGSFor smooth optimization
4. LP-free alternating (using subgradient approximation of best response)
5. Coordinate descent final polish

import numpy as np
import time
from scipy.fft import rfft, irfft
from scipy.optimize import minimize

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]

def compute_score(a):
    """Compute the objective value."""
    a = np.maximum(np.asarray(a, dtype=np.float64), 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    n = len(a)
    b = fast_convolve(a)
    return float(2.0 * n * b.max() / (s * s))

def peak_equalization_subgrad(a, m=5):
    """
    Compute subgradient of sum of top-m peaks of conv(a,a).
    This approximates the LP best-response direction without solving the LP.
    """
    n = len(a)
    b = fast_convolve(a)
    top_indices = np.argsort(b)[::-1][:m]
    top_values = b[top_indices]
    mean_top = top_values.mean()
    weights = top_values - mean_top + 1e-15  # positive weights for above-mean peaks
    
    grad = np.zeros(n)
    for ii, k in enumerate(top_indices):
        w = weights[ii]
        if w < 1e-15:
            continue
        js = max(0, k - n + 1)
        je = min(n - 1, k)
        idx = np.arange(js, je + 1)
        grad[idx] += w * a[k - idx]
    
    return grad

def ftrl_multiplicative(a0, time_limit, eta0=1.0, m_peaks=5, decay=0.9995):
    """
    FTRL with entropic mirror (multiplicative weight updates) 
    guided by peak-equalization subgradient.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    a = a / s
    best_a = a.copy()
    best_score = compute_score(a)
    t0 = time.monotonic()
    eta = eta0
    no_improve = 0
    
    for it in range(5000000):
        if time.monotonic() - t0 > time_limit:

        grad_max = np.max(np.abs(grad))
        if grad_max < 1e-15:

        grad_norm = grad / grad_max
        
        # Multiplicative update (mirror descent with entropic regularizer)
        log_a = np.log(np.maximum(a, 1e-300))
        log_a_new = log_a - eta * grad_norm
        # Shift for numerical stability

            a_new_sum = 1.0

    return best_a, best_score
```

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using a novel combination of:
1. Diverse parametric initialization
2. Peak-equalization FTRL (multiplicative weight updates with momentum)
3. p-norm L-BFGS (FFT-accelerated gradients)
4. LP-free best-response approximation
5. Coordinate descent final polish
Key innovations: peak-equalization subgradient, momentum-augmented FTRL,
multi-stage p-norm smoothing.
"""

import numpy as np
import time
from scipy.fft import rfft, irfft
from scipy.optimize import minimize

def fast_convolve(a):
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]

def compute_score(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    n = len(a)
    b = fast_convolve(a)
    return float(2.0 * n * b.max() / (s * s))

def fast_convolve_cross(a, b):
    """Linear cross-convolution a * b via FFT."""
    n_a = len(a)
    n_b = len(b)
    size = n_a + n_b - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    B = rfft(b, fft_size)
    return irfft(A * B, fft_size)[:size]

def pnorm_obj_grad(a, p):
    """
    Compute p-norm smoothed objective and gradient.
    Objective: 2n * ||conv(a,a)||_p (a assumed normalized to sum=1)
    Gradient: vector of length n.
    """
    n = len(a)
    b = fast_convolve(a)
    # b is always non-negative
    b_clipped = np.maximum(b, 1e-300)
    bp1 = b_clipped ** (p - 1)
    
    # cross-correlation: c[i] = sum_j a[j] * bp1[i+j]
    # = conv(a_rev, bp1)[n-1 : 2n-2]
    a_rev = a[::-1]
    fft_size = 1 << (3 * n - 1).bit_length()
    A_rev = rfft(a_rev, fft_size)
    BP = rfft(bp1, fft_size)
    conv_full = irfft(A_rev * BP, fft_size)
    c = conv_full[n - 1:2 * n - 1]
    
    # ||b||_p = (sum b^p)^(1/p)
    obj_b = np.sum(b_clipped ** p) ** (1.0 / p)
    
    # Objective: 2n * ||b||_p
    obj = 2.0 * n * obj_b
    
    # Gradient: d(2n * ||b||_p) / d a[i] = 2n * (1/p) * ||b||_p^(1-p) * p * c[i]
    # = 2n * ||b||_p^(1-p) * c[i]
    if obj_b < 1e-300:
        grad = np.zeros(n)
    else:
        grad = 2.0 * n * (obj_b ** (1 - p)) * c
    
    return obj, grad

def pnorm_lbgfs(a0, time_limit, p_stages=None):
    """Multi-stage L-BFGS on p-norm smoothed objective."""
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    a = a / s
    t0 = time.monotonic()
    
    if p_stages is None:
        p_stages = [5, 10, 20, 40, 80, 160, 320]
    
    best_a = a.copy()
    best_score = compute_score(a)
    
    for p in p_stages:
        if time.monotonic() - t0 > time_limit - 10:
            break
        
        elapsed_stage = time.monotonic() - t0
        remaining = time_limit - elapsed_stage
        maxiter = min(500, max(50, int(remaining / 0.5)))
        
        def func(z):
            a_t = np.maximum(z, 0)
            st = a_t.sum()
            if st < 1e-15:
                return 1e15
            a_t = a_t / st
            obj, _ = pnorm_obj_grad(a_t, p)
            sc = compute_score(a_t)
            if sc < best_score:
                nonlocal best_score, best_a
                best_score = sc
                best_a = a_t.copy()
            return obj
        
        def jac(z):
            a_t = np.maximum(z, 0)
            st = a_t.sum()
            if st < 1e-15:
                return np.zeros_like(z)
            a_t = a_t / st
            _, grad = pnorm_obj_grad(a_t, p)
            return grad
        
        try:
            res = minimize(fun=func, x0=a, jac=jac, method='L-BFGS-B',
                           options={'maxiter': maxiter, 'ftol': 1e-18,
                                    'gtol': 1e-14, 'maxfun': maxiter * 100,
                                    'disp': False})
            a = np.maximum(res.x, 0)
            sa = a.sum()
            if sa > 1e-15:
                a = a / sa
        except Exception as e:
            print(f"    L-BFGS p={p} error: {e}")
        
        elapsed = time.monotonic() - t0
        sc = compute_score(a)
        print(f"    p-norm L-BFGS p={p} ({elapsed:.0f}s): score={sc:.8f}, best={best_score:.8f}")
    
    return best_a, best_score

def ftrl_peakeq(a0, time_limit, eta0=0.5, m_peaks=5, momentum_beta=0.9):
    """
    FTRL with peak-equalization subgradient and momentum.
    Uses multiplicative weight updates (entropic mirror).
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    a = a / s
    best_a = a.copy()
    best_score = compute_score(a)
    t0 = time.monotonic()
    eta = eta0
    m = np.zeros(n)  # momentum
    beta = momentum_beta
    no_improve = 0
    rng = np.random.default_rng(42)
    
    for it in range(10000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Compute peak-equalization subgradient
        b = fast_convolve(a)
        top_indices = np.argsort(b)[::-1][:m_peaks]
        top_values = b[top_indices]
        mean_top = top_values.mean()
        
        grad = np.zeros(n)
        for ii, k in enumerate(top_indices):
            w = top_values[ii] - mean_top
            if w < 1e-15:
                continue
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            grad[idx] += w * a[k - idx]
        
        grad_max = np.max(np.abs(grad))
        if grad_max < 1e-15:
            break
        
        grad_norm = grad / grad_max
        
        # Momentum update
        m = beta * m + (1 - beta) * grad_norm
        
        # Multiplicative update
        log_a = np.log(np.maximum(a, 1e-300))
        log_a_new = log_a - eta * m
        log_a_new -= log_a_new.max()  # stability
        a_new = np.exp(log_a_new)
        a_new = np.maximum(a_new, 0)
        a_new_sum = a_new.sum()
        if a_new_sum < 1e-15:
            a_new = a.copy()
            a_new_sum = 1.0
        a_new = a_new / a_new_sum
        
        score = compute_score(a_new)
        if score < best_score - 1e-13:
            best_score = score
            best_a = a_new.copy()
            no_improve = 0
            eta = min(eta * 1.02, 5.0)
        else:
            no_improve += 1
            if no_improve > 200:
                eta *= 0.85
                # Add small noise
                noise = rng.standard_normal(n) * (0.002 / np.sqrt(n))
                a_new = a_new + noise
                a_new = np.maximum(a_new, 0)
                a_new = a_new / a_new.sum()
                no_improve = 0
        
        a = a_new
        
        if (it + 1) % 20000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    FTRL-PEQ iter={it+1} ({elapsed:.0f}s): score={best_score:.8f}, eta={eta:.4f}")
    
    return best_a, best_score

def coordinate_descent(a0, time_limit, n_steps=500000):
    """Coordinate descent focusing on peak-contributing elements."""
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    a = a / s
    best_a = a.copy()
    best_score = compute_score(a)
    t0 = time.monotonic()
    stall = 0
    
    for step in range(n_steps):
        if time.monotonic() - t0 > time_limit:
            break
        
        b = fast_convolve(a)
        max_b = b.max()
        threshold = max_b * (1 - 1e-4)
        peaks = np.where(b >= threshold)[0]
        
        improved = False
        for peak_k in peaks[:5]:
            if improved:
                break
            js = max(0, peak_k - n + 1)
            je = min(n - 1, peak_k)
            idx = np.arange(js, je + 1)
            contribs = a[idx] * a[peak_k - idx]
            top_m = min(10, len(idx))
            top_positions = idx[np.argsort(contribs)[::-1][:top_m]]
            
            for pos in top_positions:
                if a[pos] < 1e-12:
                    continue
                for factor in [0.9995, 0.999, 0.998, 0.997, 0.995, 0.993, 0.99]:
                    a_trial = a.copy()
                    a_trial[pos] *= factor
                    diff = a[pos] - a_trial[pos]
                    if diff < 1e-16:
                        continue
                    mask = np.ones(n, dtype=bool)
                    mask[pos] = False
                    others = a_trial[mask]
                    others_sum = others.sum()
                    if others_sum < 1e-15:
                        break
                    a_trial[mask] = others + diff * others / others_sum
                    score = compute_score(a_trial)
                    if score < best_score - 1e-14:
                        a = a_trial
                        best_score = score
                        best_a = a.copy()
                        improved = True
                        break
                if improved:
                    break
        
        if not improved:
            stall += 1
            if stall > 100:
                # Simultaneous reduction
                peak_k = int(np.argmax(b))
                js = max(0, peak_k - n + 1)
                je = min(n - 1, peak_k)
                idx = np.arange(js, je + 1)
                contribs = a[idx] * a[peak_k - idx]
                top_positions = idx[np.argsort(contribs)[::-1][:6]]
                a_trial = a.copy()
                for pos in top_positions:
                    if a_trial[pos] > 1e-12:
                        a_trial[pos] *= 0.999
                a_trial = np.maximum(a_trial, 0)
                a_trial = a_trial / a_trial.sum()
                score = compute_score(a_trial)
                if score < best_score - 1e-14:
                    a = a_trial
                    best_score = score
                    best_a = a.copy()
                stall = 0
            if stall > 5000:
                break
        else:
            stall = 0
        
        if (step + 1) % 50000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    CoordDesc {elapsed:.0f}s: score={best_score:.8f}")
    
    return best_a, best_score

def structured_init(n, rng):
    """Create structured initial sequence."""
    choice = rng.integers(0, 8)
    x = np.linspace(0, 1, n)
    if choice == 0:
        a = np.cos(np.pi * x / 2) ** 2
    elif choice == 1:
        a = np.sin(np.pi * x) ** 1.5
    elif choice == 2:
        a = np.exp(-3 * x * (1 - x))
    elif choice == 3:
        a = 0.5 + 0.3 * np.cos(2 * np.pi * 2 * x)
        a = np.maximum(a, 0)
    elif choice == 4:
        a = np.exp(-2.0 * (x - 0.5) ** 2 / 0.2)
    elif choice == 5:
        a = np.exp(-8 * (x - 0.3) ** 2) + np.exp(-8 * (x - 0.7) ** 2)
    elif choice == 6:
        # Tukey (tapered cosine)
        r = 0.5
        a = np.ones(n)
        m = int(r * n / 2)
        if m > 0:
            t = np.linspace(0, np.pi, m)
            taper = 0.5 + 0.5 * np.cos(t)
            a[:m] = taper
            a[-m:] = taper[::-1]
    else:
        # Flat-top with smooth edges
        a = np.ones(n)
        m = max(5, n // 20)
        t = np.linspace(0, np.pi / 2, m)
        taper = 1 - 0.3 * np.sin(t) ** 2
        a[:m] = taper
        a[-m:] = taper[::-1]
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s

def interpolate_sequence(f, new_n):
    """Interpolate sequence to new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp

def best_response_approx(a_fixed, n_peaks=10):
    """
    Approximate the LP best response without solving the LP.
    The best response b minimizes max(conv(a, b)) subject to b>=0, sum(b)=1.
    At the optimum, the active peaks are equalized.
    We approximate by: b_i ∝ 1 / (sum of peak sensitivities at i)
    """
    n = len(a_fixed)
    b_conv_a = fast_convolve(a_fixed)  # This is conv(a, a) but we need conv(a, 1) = sum...
    # Actually, conv(a, b)[k] = sum_i a[i] * b[k-i]
    # To minimize max_k conv(a,b)[k], the best b should "avoid" the positions
    # that contribute most to the peaks.
    
    # Alternative: the LP dual says the optimal value is:
    # min_b max_k sum_i a[i]*b[k-i] s.t. b>=0, sum(b)=1
    # = min_b max_k (a * b)[k]
    # The dual is: max sum_k lambda_k s.t. sum_k lambda_k * a[k-i] <= 1 for all i, lambda >= 0
    # At the optimum, complementary slackness: b[i] > 0 => sum_k lambda_k * a[k-i] = 1
    
    # A simple heuristic: b[i] ∝ 1 / (effective_exposure[i])
```

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Multi-start FTRL with peak-equalization subgradient (momentum-augmented multiplicative weights)
2. Multi-stage p-norm L-BFGS (FFT-accelerated gradients, p from 5 to 500)
3. Multi-resolution exploration (n=1200 to 3000)
4. Coordinate descent final polish
Key innovations: peak-equalization subgradient avoids LP solving, momentum FTRL for
faster convergence, p-norm L-BFGS for precise local optimization, and diverse
parametric initialization to escape local minima.
"""

import numpy as np
import time
from scipy.fft import rfft, irfft
from scipy.optimize import minimize

# Global state for L-BFGS callbacks (avoids closures)
_lbgfs_state = {}


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def compute_score(a):
    """Compute the objective value (scale-invariant)."""
    a = np.maximum(np.asarray(a, dtype=np.float64), 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    n = len(a)
    b = fast_convolve(a)
    return float(2.0 * n * b.max() / (s * s))


def pnorm_obj_grad(a, p):
    """
    Compute p-norm smoothed objective and gradient.
    Objective: 2n * ||conv(a,a)||_p (a assumed normalized to sum=1)
    Returns (obj, grad) where grad has length n.
    """
    n = len(a)
    b = fast_convolve(a)
    b_safe = np.maximum(b, 1e-300)
    bp1 = b_safe ** (p - 1)

    # c[i] = sum_j a[j] * b[i+j]^(p-1) = conv(a_rev, bp1)[n-1 : 2n-2]
    a_rev = a[::-1]
    fft_size = 1 << (3 * n - 1).bit_length()
    A_rev = rfft(a_rev, fft_size)
    BP = rfft(bp1, fft_size)
    conv_full = irfft(A_rev * BP, fft_size)
    c = conv_full[n - 1:2 * n - 1]

    obj_b = np.sum(b_safe ** p) ** (1.0 / p)
    obj = 2.0 * n * obj_b

    if obj_b < 1e-300:
        grad = np.zeros(n)
    else:
        grad = 2.0 * n * (obj_b ** (1 - p)) * c

    return obj, grad


def _lbgfs_func(z):
    """L-BFGS objective callback."""
    if time.monotonic() > _lbgfs_state['deadline']:
        return 1e15
    a_t = np.maximum(z, 0)
    st = a_t.sum()
    if st < 1e-15:
        return 1e15
    a_t = a_t / st
    obj, _ = pnorm_obj_grad(a_t, _lbgfs_state['p'])
    sc = compute_score(a_t)
    if sc < _lbgfs_state['best_score']:
        _lbgfs_state['best_score'] = sc
        _lbgfs_state['best_a'] = a_t.copy()
    return obj


def _lbgfs_jac(z):
    """L-BFGS gradient callback."""
    if time.monotonic() > _lbgfs_state['deadline']:
        return np.zeros_like(z)
    a_t = np.maximum(z, 0)
    st = a_t.sum()
    if st < 1e-15:
        return np.zeros_like(z)
    a_t = a_t / st
    _, grad = pnorm_obj_grad(a_t, _lbgfs_state['p'])
    return grad


def pnorm_lbgfs_run(a0, time_limit, p_stages=None):
    """Multi-stage L-BFGS on p-norm smoothed objective."""
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    a = a / s
    t0 = time.monotonic()

    if p_stages is None:
        p_stages = [5, 10, 20, 50, 100, 200, 400]

    best_a = a.copy()
    best_score = compute_score(a)

    for p in p_stages:
        if time.monotonic() - t0 > time_limit - 10:
            break
        remaining = time_limit - (time.monotonic() - t0)
        maxiter = min(300, max(30, int(remaining / 1.0)))

        _lbgfs_state['p'] = p
        _lbgfs_state['best_score'] = best_score
        _lbgfs_state['best_a'] = best_a.copy()
        _lbgfs_state['deadline'] = time.monotonic() + min(remaining, time_limit - (time.monotonic() - t0)) - 2

        try:
            res = minimize(fun=_lbgfs_func, x0=a, jac=_lbgfs_jac, method='L-BFGS-B',
                           options={'maxiter': maxiter, 'ftol': 1e-18,
                                    'gtol': 1e-14, 'maxfun': maxiter * 200,
                                    'disp': False})
            a = np.maximum(res.x, 0)
            sa = a.sum()
            if sa > 1e-15:
                a = a / sa
        except Exception:
            pass

        if _lbgfs_state['best_score'] < best_score:
            best_score = _lbgfs_state['best_score']
            best_a = _lbgfs_state['best_a'].copy()

        elapsed = time.monotonic() - t0
        sc = compute_score(a)
        print(f"    p-LBFGS p={p} ({elapsed:.0f}s): score={sc:.8f}, best={best_score:.8f}")

    return best_a, best_score


def ftrl_peakeq(a0, time_limit, eta0=0.3, m_peaks=5, momentum_beta=0.9):
    """
    FTRL with peak-equalization subgradient and momentum.
    Uses multiplicative weight updates (entropic mirror).
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    a = a / s
    best_a = a.copy()
    best_score = compute_score(a)
    t0 = time.monotonic()
    eta = eta0
    m_vec = np.zeros(n)
    beta = momentum_beta
    no_improve = 0
    rng = np.random.default_rng(12345)

    for it in range(20000000):
        if time.monotonic() - t0 > time_limit:
            break

        # Compute peak-equalization subgradient
        b = fast_convolve(a)
        top_indices = np.argsort(b)[::-1][:m_peaks]
        top_values = b[top_indices]
        mean_top = top_values.mean()

        grad = np.zeros(n)
        for ii, k in enumerate(top_indices):
            w = top_values[ii] - mean_top
            if w < 1e-15:
                continue
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            grad[idx] += w * a[k - idx]

        grad_max = np.max(np.abs(grad))
        if grad_max < 1e-15:
            break

        grad_norm = grad / grad_max

        # Momentum update
        m_vec = beta * m_vec + (1.0 - beta) * grad_norm

        # Multiplicative update (entropic mirror descent)
        log_a = np.log(np.maximum(a, 1e-300))
        log_a_new = log_a - eta * m_vec
        log_a_new -= log_a_new.max()
        a_new = np.exp(log_a_new)
        a_new = np.maximum(a_new, 0)
        a_new_sum = a_new.sum()
        if a_new_sum < 1e-15:
            a_new = a.copy()
            a_new_sum = 1.0
        a_new = a_new / a_new_sum

        score = compute_score(a_new)
        if score < best_score - 1e-13:
            best_score = score
            best_a = a_new.copy()
            no_improve = 0
            eta = min(eta * 1.01, 5.0)
        else:
            no_improve += 1
            if no_improve > 300:
                eta *= 0.8
                noise = rng.standard_normal(n) * (0.003 / np.sqrt(n))
                a_new = a_new + noise
                a_new = np.maximum(a_new, 0)
                a_new = a_new / a_new.sum()
                no_improve = 0

        a = a_new

        if (it + 1) % 50000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    FTRL-PEQ iter={it+1} ({elapsed:.0f}s): score={best_score:.8f}, eta={eta:.4f}")

    return best_a, best_score

def coordinate_descent(a0, time_limit, n_steps=500000):
    """Coordinate descent focusing on peak-contributing elements."""
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    a = a / s
    best_a = a.copy()
    best_score = compute_score(a)
    t0 = time.monotonic()
    stall = 0

    for step in range(n_steps):
        if time.monotonic() - t0 > time_limit:
            break

        b = fast_convolve(a)
        max_b = b.max()
        threshold = max_b * (1.0 - 1e-4)
        peaks = np.where(b >= threshold)[0]

        improved = False
        for peak_k in peaks[:3]:
            if improved:
                break
            js = max(0, peak_k - n + 1)
            je = min(n - 1, peak_k)
            idx = np.arange(js, je + 1)
            contribs = a[idx] * a[peak_k - idx]
            top_m = min(8, len(idx))
            top_positions = idx[np.argsort(contribs)[::-1][:top_m]]

            for pos in top_positions:
                if a[pos] < 1e-12:
                    continue
                for factor in [0.9995, 0.999, 0.998, 0.997, 0.995, 0.993, 0.99]:
                    a_trial = a.copy()
                    a_trial[pos] *= factor
                    diff = a[pos] - a_trial[pos]
                    if diff < 1e-16:
                        continue
                    mask = np.ones(n, dtype=bool)
                    mask[pos] = False
                    others = a_trial[mask]
                    others_sum = others.sum()
                    if others_sum < 1e-15:
                        break
                    a_trial[mask] = others + diff * others / others_sum
                    score = compute_score(a_trial)
                    if score < best_score - 1e-14:
                        a = a_trial
                        best_score = score
                        best_a = a.copy()
                        improved = True
                        break
                if improved:
                    break

        if not improved:
            stall += 1
            if stall > 200:
                peak_k = int(np.argmax(b))
                js = max(0, peak_k - n + 1)
                je = min(n - 1, peak_k)
                idx = np.arange(js, je + 1)
                contribs = a[idx] * a[peak_k - idx]
                top_positions = idx[np.argsort(contribs)[::-1][:6]]
                a_trial = a.copy()
                for pos in top_positions:
                    if a_trial[pos] > 1e-12:
                        a_trial[pos] *= 0.999
                a_trial = np.maximum(a_trial, 0)
                a_trial = a_trial / a_trial.sum()
                score = compute_score(a_trial)
                if score < best_score - 1e-14:
                    a = a_trial
                    best_score = score
                    best_a = a.copy()
                stall = 0
            if stall > 5000:
                break
        else:
            stall = 0

        if (step + 1) % 50000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    CoordDesc {elapsed:.0f}s: score={best_score:.8f}")

    return best_a, best_score


def structured_init(n, rng):
    """Create diverse structured initial sequence."""
    choice = rng.integers(0, 10)
    x = np.linspace(0, 1, n)
    if choice == 0:
        a = np.cos(np.pi * x / 2) ** 2
    elif choice == 1:
        a = np.sin(np.pi * x) ** 1.5
    elif choice == 2:
        a = np.exp(-3.0 * x * (1.0 - x))
    elif choice == 3:
        a = 0.5 + 0.3 * np.cos(2.0 * np.pi * 2.0 * x)
        a = np.maximum(a, 0)
    elif choice == 4:
        a = np.exp(-2.0 * (x - 0.5) ** 2 / 0.2)
    elif choice == 5:
        a = np.exp(-8.0 * (x - 0.3) ** 2) + np.exp(-8.0 * (x - 0.7) ** 2)
    elif choice == 6:
        r = 0.5
        a = np.ones(n)
        m = max(1, int(r * n / 2))
        t = np.linspace(0, np.pi, m)
        taper = 0.5 + 0.5 * np.cos(t)
        a[:m] = taper
        a[-m:] = taper[::-1]
    elif choice == 7:
        a = np.ones(n)
        m = max(5, n // 20)
        t = np.linspace(0, np.pi / 2, m)
        taper = 1.0 - 0.3 * np.sin(t) ** 2
        a[:m] = taper
        a[-m:] = taper[::-1]
    elif choice == 8:
        # Raised cosine with different exponent
        a = (0.5 + 0.5 * np.cos(2.0 * np.pi * x)) ** 0.7
    else:
        # Slightly asymmetric
        a = np.exp(-4.0 * (x - 0.45) ** 2 / 0.25)
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s


def interpolate_sequence(f, new_n):
    """Interpolate sequence to new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp


def propose_candidate(seed=42, budget_s=1800.0):
    """
    Multi-phase optimization for minimizing 2*n*max(conv(a,a))/(sum(a))^2.
    Uses FTRL with peak-equalization, p-norm L-BFGS, multi-n exploration,
    and coordinate descent.
    """
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + max(1.0, float(budget_s) - 25.0)

    best_seq = None
    best_score = float('inf')

    # Try to load parent sequence
    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            parent = p / p.sum()
            p_score = compute_score(parent)
            print(f"Parent: n={len(parent)}, score={p_score:.8f}")
            best_seq = parent.copy()
            best_score = p_score
    except Exception:
        pass

    if parent is None:
        n_init = 1200
        best_seq = structured_init(n_init, rng)
        best_score = compute_score(best_seq)
        print(f"Default init: n={len(best_seq)}, score={best_score:.8f}")

    def try_update(a, label):
        nonlocal best_seq, best_score
        a = np.maximum(np.asarray(a, dtype=np.float64), 0)
        s = a.sum()
        if s < 0.01:
            return
        a = a / s
        sc = compute_score(a)
        if np.isfinite(sc) and sc < best_score:
            best_score = sc
            best_seq = a.copy()
            print(f"  NEW BEST [{label}]: {sc:.8f} (n={len(a)})")

    # === Phase 1: Multi-start FTRL with Peak Equalization ===
    print(f"\n=== Phase 1: FTRL-PEQ Multi-Start (best={best_score:.8f}) ===")
    rem = deadline - time.monotonic()
    n_starts = 3
    t_per_start = min(rem * 0.35 / n_starts, 300.0)
    if t_per_start > 30:
        print(f"  {n_starts} starts, {t_per_start:.0f}s each")
        # Start 1: parent sequence (or default)
        a1, _ = ftrl_peakeq(best_seq, t_per_start, eta0=0.3, m_peaks=5)
        try_update(a1, "FTRL_1")

        # Start 2: fresh structured init
        rem2 = deadline - time.monotonic()
        if rem2 > 30:
            n_cur = len(best_seq)
            a_init2 = structured_init(n_cur, rng)
            a2, _ = ftrl_peakeq(a_init2, min(t_per_start, rem2 - 5), eta0=0.5, m_peaks=7)
            try_update(a2, "FTRL_2")

        # Start 3: random perturbation of best
        rem3 = deadline - time.monotonic()
        if rem3 > 30:
            noise = rng.standard_normal(len(best_seq)) * (0.05 / np.sqrt(len(best_seq)))
            a_init3 = best_seq + noise
            a_init3 = np.maximum(a_init3, 0)
            a_init3 = a_init3 / a_init3.sum()
            a3, _ = ftrl_peakeq_multi_peak(a_init3, min(t_per_start, rem3 - 5), eta0=0.2)
            try_update(a3, "FTRL_3")

    # === Phase 2: p-norm L-BFGS refinement ===
    print(f"\n=== Phase 2: p-norm L-BFGS (best={best_score:.8f}) ===")
    rem = deadline - time.monotonic()
    t_alloc = min(rem * 0.25, 400.0)
    if t_alloc > 20:
        print(f"  Budget: {t_alloc:.0f}s")
        a_lb, _ = pnorm_lbgfs_run(best_seq, t_alloc)
        try_update(a_lb, "pLBFGS")

    # === Phase 3: Multi-n Exploration ===
    print(f"\n=== Phase 3: Multi-n Exploration (best={best_score:.8f}) ===")
    rem = deadline - time.monotonic()
    t_alloc = min(rem * 0.20, 300.0)
    if t_alloc > 40:
        n_best = len(best_seq)
        candidate_ns = []
        for n_try in [n_best + 400, n_best + 800, max(800, n_best // 2)]:
            if n_try != n_best and 400 <= n_try <= 5000:
                candidate_ns.append(n_try)
        if candidate_ns:
            per_n = t_alloc / max(1, len(candidate_ns))
            print(f"  Trying n values: {candidate_ns}, {per_n:.0f}s each")
            for n_try in candidate_ns:
                rem_n = deadline - time.monotonic()
                if rem_n < 20:
                    break
                t_sub = min(per_n, rem_n - 5)
                if t_sub < 15:
                    continue
                a_interp = interpolate_sequence(best_seq, n_try)
                print(f"  n={n_try}, budget={t_sub:.0f}s")
                a_sub, _ = ftrl_peakeq(a_interp, t_sub * 0.6, eta0=0.3, m_peaks=5)
                try_update(a_sub, f"multi_n_FTRL_{n_try}")
                rem_n2 = deadline - time.monotonic()
                if rem_n2 > 20:
                    a_sub2, _ = pnorm_lbgfs_run(a_sub, min(t_sub * 0.4, rem_n2 - 5))
                    try_update(a_sub2, f"multi_n_LB_{n_try}")

    # === Phase 4: Second round FTRL (longer) on best ===
    print(f"\n=== Phase 4: Deep FTRL (best={best_score:.8f}) ===")
    rem = deadline - time.monotonic()
    t_alloc = min(rem * 0.20, 300.0)
    if t_alloc > 30:
        print(f"  Budget: {t_alloc:.0f}s")
        a_deep, _ = ftrl_peakeq_multi_peak(best_seq, t_alloc, eta0=0.15)
        try_update(a_deep, "deep_FTRL")

    # === Phase 5: p-norm L-BFGS final polish ===
    print(f"\n=== Phase 5: Final p-LBFGS (best={best_score:.8f}) ===")
    rem = deadline - time.monotonic()
    t_alloc = min(rem * 0.15, 200.0)
    if t_alloc > 15:
        print(f"  Budget: {t_alloc:.0f}s")
        p_stages_final = [20, 50, 100, 200, 500]
        a_fin, _ = pnorm_lbgfs_run(best_seq, t_alloc, p_stages=p_stages_final)
        try_update(a_fin, "final_pLBFGS")

    # === Phase 6: Coordinate descent polish ===
    print(f"\n=== Phase 6: Coord Descent (best={best_score:.8f}) ===")
    rem = deadline - time.monotonic()
    t_alloc = min(rem * 0.15, 200.0)
    if t_alloc > 10:
        a_cd, _ = coordinate_descent(best_seq, t_alloc, n_steps=300000)
        try_update(a_cd, "coord_desc")

    # === Phase 7: Final quick FTRL + verify ===
    print(f"\n=== Phase 7: Final FTRL (best={best_score:.8f}) ===")
    rem = deadline - time.monotonic()
    t_alloc = min(rem * 0.05, 60.0)
    if t_alloc > 5:
        a_last, _ = ftrl_peakeq(best_seq, t_alloc, eta0=0.1, m_peaks=5)
        try_update(a_last, "final_FTRL")

    # Final verification
    if best_seq is not None:
        fs = compute_score(best_seq)
        if np.isfinite(fs):
            best_score = fs
        print(f"\nFINAL SCORE: {best_score:.8f} (n={len(best_seq)})")

    return [float(max(0.0, min(1000.0, x))) for x in best_seq]
```
