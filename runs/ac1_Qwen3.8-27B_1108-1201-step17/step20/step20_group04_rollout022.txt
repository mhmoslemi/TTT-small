However, we can use the fact that `(sum a)^2 = 1^T X 1 = 1`. So we add the constraint `1^T X 1 = 1`.

The relaxed problem:
- Minimize T
- Subject to: `tr(A_k * X) <= T` for all k
- `1^T X 1 = 1`
- `X >= 0` (PSD)

This is an SDP! We can solve it with cvxpy. The solution `X*` might not be rank-1, but we can extract a rank-1 approximation.

For n up to a few thousand, this SDP has `n^2` variables and `2n-1 + 1` constraints, which is too large for most solvers. But for small n (say 100-500), it might work and give us a good starting point.

Actually, for n = 6700, this is way too large. But we could use it for a smaller n to get insight, then interpolate up.

**Idea 6: Iterative Linearization (like the LP approach but with quadratic constraints)**

The previous SOTA uses LP: maximize `sum(b)` subject to `f * b <= M` elementwise and `b >= 0`. This is a valid approach because the constraints are linear in `b` (they're quadratic in `f` but linear in `b`).

Wait, actually re-reading: "maximizing sum_j b_j subject to b_j >= 0 and ||f*g_0||_inf <= M". So `f` is fixed (the current sequence) and we're finding the best `g_0` that keeps the cross-correlation `f*g_0` bounded.

This is clever: we're finding the best "direction" to move that doesn't increase the cross-correlation beyond the current max. Then we take a step in that direction.

Let me implement a similar approach but with some modifications:
1. Use the cross-correlation bound `||f*g||_inf <= M` (linear in g)
2. Add a quadratic term to encourage reducing the current peak specifically
3. Use a different objective (not just maximize sum, but minimize the expected peak)

**Idea 7: "Deflation" approach**

Inspired by eigenvalue deflation: 
1. Find the current maximum peak position k*.
2. The constraint `b[k*] <= T` is the binding one.
3. Write `b[k*] = a^T A_{k*} a`. The "eigenvector" of `A_{k*}` corresponding to the largest eigenvalue gives the direction that most increases `b[k*]`.
4. Project the current `a` onto the "null space" of this direction (reduce the component along the "bad" eigenvector).
5. Repeat.

But `A_k` is not PSD in general, so "eigenvectors" are tricky.

**Idea 8: Primal-dual / multiplicative weights**

Use a multiplicative weights update: `a[j] <- a[j] * exp(-eta * grad[j])` where `grad[j]` is the subgradient of the max autocorrelation. This is similar to the Mirror Descent approach with the entropy regularizer, which naturally maintains non-negativity.

The mirror descent update for minimizing `f(a) = max_k b[k]` with the simplex constraint:
- Subgradient: `g[j] = sum_{k in argmax} 2*a[k-j]` (the subgradient of the max at j)
- Update: `a[j] <- a[j] * (1 - eta * g[j])` (approximately, for small eta)
- Or more precisely: `a[j] <- a[j] * exp(-eta * g[j]) / Z` where Z normalizes.

This is essentially the "exponential weights" or "Hedge" algorithm applied to our problem.

Mirror Descent with entropy (exponential family):
- Maintain `w[j]` (log-weights), `a[j] = exp(w[j]) / sum(exp(w))`
- Subgradient of `f(a) = max_k b[k]`: pick the argmax k*, then `g[j] = 2*sum_{k=k*} a[k*-j]` (with appropriate indexing)
- Update: `w[j] <- w[j] - eta * g[j]`
- Renormalize

This is equivalent to multiplicative weights: `a[j] <- a[j] * (1 - eta * g[j])` (for small eta).

The advantage is that it naturally keeps `a >= 0` and can be very fast.

For the smoothed version, we can use the softmax weights `p[k] = exp(beta * b[k]) / sum exp(beta * b)` and the gradient `g[j] = (2/beta) * sum_k p[k] * a[k-j]`.

- Then take a mirror descent step from y.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Multiple diverse parametric initializations
2. Accelerated mirror descent (exponential family) - different from previous projected gradient

import numpy as np
import time

def fast_autocorr(a):
    """Compute full linear convolution of a with itself using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(np.asarray(a, dtype=np.float64), fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def evaluate_safe(a):
    try:
        a_list = [float(x) for x in np.asarray(a, dtype=np.float64)]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')

def norm_sum1(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s

def simplex_project(z):
    """Project onto probability simplex {x >= 0, sum(x) = 1}."""
    n = len(z)
    if n == 0:
        return z
    u = np.sort(z)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    rho = np.nonzero(cond)[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(z - theta, 0.0)

def softmax_project(w, temp=1.0):
    """Exponential family normalization: a[j] = exp(w[j]/temp) / sum(exp)."""
    w_shifted = w - w.max()
    exp_w = np.exp(w_shifted / temp)
    s = exp_w.sum()
    if s < 1e-300:
        return np.ones(len(w)) / len(w)
    return exp_w / s

def convolve_p_with_a(p, a):
    """Compute conv(p, a) where p has length 2n-1 and a has length n.
    Returns the 'correlation' sum_k p[k]*a[k-j] for j=0..n-1."""
    n = len(a)
    fft_size = 1 << (2 * n - 1).bit_length()
    P = np.fft.rfft(p, fft_size)
    a_rev = a[::-1]
    A = np.fft.rfft(a_rev, fft_size)
    Conv = np.fft.irfft(P * A, fft_size)
    return Conv[n - 1:2 * n - 1]

def compute_grad_mirror(a, beta, top_k=None):
    """Compute gradient for mirror descent on smoothed max autocorrelation."""
    n = len(a)
    c = fast_autocorr(a)
    if top_k is not None and top_k < len(c):
        idx = np.argsort(c)[::-1][:top_k]
        c_use = np.zeros(len(c))
        c_use[idx] = c[idx]
        c_max = c[idx].max()
    else:
        c_use = c
        c_max = c.max()
    shifted = beta * (c_use - c_max)
    shifted = np.clip(shifted, -300, 300)
    exp_vals = np.exp(shifted)
    total = exp_vals.sum()
    if total < 1e-300:
        p = np.zeros_like(c_use)
        p[np.argmax(c)] = 1.0
    else:
        p = exp_vals / total
    # grad[j] = (2/beta) * sum_k p[k] * a[k-j]
    # = (2/beta) * convolve_p_with_a(p, a)[j]
    grad = (2.0 / beta) * convolve_p_with_a(p, a)
    return grad, p, c

def mirror_descent_opt(a0, time_limit, beta_start=20.0, beta_end=2000.0,
                       beta_growth=1.005, eta_base=0.8, top_k_ratio=0.02,
                       restart_every=3000, verbose=True, seed=42):
    """Accelerated mirror descent with exponential family."""
    n = len(a0)
    a = norm_sum1(a0)
    # Work in log-space
    w = np.log(np.maximum(a, 1e-15))
    w_prev = w.copy()
    best_a = a.copy()
    best_c = fast_autocorr(a)
    best_max_b = best_c.max()
    t0 = time.monotonic()
    beta = beta_start
    t_nest = 1.0
    stall = 0
    rng = np.random.default_rng(seed)
    top_k = max(10, int(n * top_k_ratio))
    
    for t in range(1, 10000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Nesterov extrapolation
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t_nest * t_nest)) / 2.0
        theta = (t_nest - 1.0) / t_new
        w_y = w + theta * (w - w_prev)
        # Convert back to probability
        y = softmax_project(w_y, temp=max(1.0, beta * 0.1))
        
        # Compute gradient
        grad, p, c = compute_grad_mirror(y, beta, top_k)
        
        # Mirror descent step: w <- w - eta * grad
        eta = eta_base / max(1.0, np.abs(grad).max() * beta * 0.5)
        eta = min(eta, 0.5)
        w_new = w - eta * grad
        
        # Clamp to prevent overflow
        w_new = np.clip(w_new, -50, 50)
        
        # Convert to probability
        x_new = softmax_project(w_new, temp=1.0)
        
        # Check improvement
        b_new = fast_autocorr(x_new)
        max_new = b_new.max()
        if max_new < best_max_b - 1e-15:
            best_max_b = max_new
            best_a = x_new.copy()
            stall = 0
        else:
            stall += 1
        
        w_prev = w
        w = w_new
        t_nest = t_new
        
        if t % 50 == 0:
            beta = min(beta * beta_growth, beta_end)
        
        if stall > restart_every:
            stall = 0
            t_nest = 1.0
            # Restart with perturbation
            noise_scale = 0.05 / (1.0 + 0.1 * (t // restart_every))
            rand = rng.normal(0, 1, n)
            a_r = best_a + noise_scale * rand * best_a
            a_r = np.maximum(a_r, 1e-10)
            a_r = a_r / a_r.sum()
            w = np.log(a_r)
            # Re-normalize in log space
            w = w - w.min()
            w = w - np.log(np.exp(w).sum())
            w_prev = w.copy()
            beta = max(beta * 0.5, 10.0)
            if verbose:
                elapsed = time.monotonic() - t0
                J = 2.0 * n * best_max_b
                print("    MD restart t=" + str(t) + " (" + str(round(elapsed, 1)) + "s): J=" + repr(round(J, 6)))
        
        if verbose and t % 2000 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_max_b
            print("    MD t=" + str(t) + " (" + str(round(elapsed, 1)) + "s): J=" + repr(round(J, 6)) + ", beta=" + str(round(beta, 1)))
    
    return best_a, best_max_b

def lp_direction(a, M, time_limit=5.0, verbose=False):
    """Solve LP to find best direction g that keeps f*g <= M and maximizes progress.
    Returns the direction g (normalized to sum=1)."""
    n = len(a)
    try:
        import cvxpy as cp
        g = cp.Variable(n, nonneg=True)
        # Cross-correlation f * g bounded by M
        # (f*g)[k] = sum_i a[i]*g[k-i] <= M for all k
        # This is linear in g!
        # We can express as: for each k, a_inner = sum over valid i of a[i]*g[k-i] <= M
        # Using cvxpy: cp.sum(a * g_shifted) for appropriate shifts
        # Actually, let's use the matrix form: B @ g <= M where B[k,j] = a[k-j] (0 if out of range)
        # B is a (2n-1) x n matrix
        # B[k,j] = a[k-j] if 0 <= k-j < n, else 0
        # This means (B@j) is the j-th column, which is a shifted version of a
        
        # For efficiency, since n might be large, let's only include the most binding constraints
        # Find current peaks
        c = fast_autocorr(a)
        # Get top constraints
        n_constraints = min(n, 100)
        top_constraint_idx = np.argsort(c)[::-1][:n_constraints]
        
        # Build sparse constraint matrix
        # B[k,j] = a[k-j] if valid
        # For a given k: j ranges from max(0, k-n+1) to min(k, n-1)
        # g[j] coefficient is a[k-j]
        
        # Build as dense for small n, sparse for large
        if n <= 5000:
            B = np.zeros((len(top_constraint_idx), n))
            for ci, k in enumerate(top_constraint_idx):
                ki = int(k)
                j_start = max(0, ki - n + 1)
                j_end = min(n - 1, ki)
                if j_start <= j_end:
                    B[ci, j_start:j_end+1] = a[ki - np.arange(j_start, j_end + 1)]
            
            constraints = [B @ g <= M * np.ones(len(top_constraint_idx))]
            constraints.append(cp.sum(g) == 1)
            
            # Objective: minimize the increase in the current max peak
            # Or maximize sum of "good" components
            # Let's minimize the weighted sum of top peaks after update
            # a_new = (1-t)*a + t*g, so b_new[k] ≈ b[k] + t*(2*a*g - a*a)*[k] for small t
            # To minimize b_new at the top peak k*: minimize (a*g)[k*]
            # (a*g)[k*] = sum_j a[k*-j]*g[j] = B_top @ g (for k = top peak)
            k_star = int(top_constraint_idx[0])
            j_start = max(0, k_star - n + 1)
            j_end = min(n - 1, k_star)
            obj_vec = np.zeros(n)
            if j_start <= j_end:
                obj_vec[j_start:j_end+1] = a[k_star - np.arange(j_start, j_end + 1)]
            
            prob = cp.Problem(cp.Minimize(obj_vec @ g), constraints)
            
            # Try solvers
            for solver in [cp.CLARABEL, cp.PDLP, cp.SCS, cp.ECOS]:
                try:
                    prob.solve(solver=solver, verbose=False)
                    if prob.status in ('optimal', 'optimal_inaccurate'):
                        g_val = np.asarray(g.value, dtype=np.float64)
                        g_val = np.maximum(g_val, 0)
                        s = g_val.sum()
                        if s > 1e-10:
                            g_val = g_val / s
                            return g_val
                        break
                except Exception:
                    continue
        
        return None
    except Exception:
        return None

def peak_deflation(a0, time_limit, verbose=True, seed=77):
    """Targeted local search: deflation of top peaks via pairwise mass moves."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)
    no_improve = 0
    max_no_improve = 5000
    
    while time.monotonic() - t0 < time_limit and no_improve < max_no_improve:
        c = fast_autocorr(a)
        if c.max() < best_m - 1e-15:
            best_m = c.max()
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        # Find top peaks
        n_top = min(20, len(c))
        top_idx = np.argsort(c)[::-1][:n_top]
        
        improved = False
        
        for k in top_idx[:8]:
            if improved:
                break
            k_int = int(k)
            i_start = max(0, k_int - n + 1)
            i_end = min(n - 1, k_int)
            if i_start > i_end:
                continue
            
            idx = np.arange(i_start, i_end + 1)
            products = a[idx] * a[k_int - idx]
            prod_max = products.max()
            if prod_max < 1e-20:
                continue
            
            # Top contributing pairs
            n_pairs = min(5, len(idx))
            top_pairs = np.argsort(products)[::-1][:n_pairs]
            
            for pi in top_pairs:
                if improved:
                    break
                src_i = int(idx[pi])
                partner = k_int - src_i
                if partner < 0 or partner >= n or partner == src_i:
                    continue
                if a[src_i] < 1e-14 and a[partner] < 1e-14:
                    continue
                
                # Try to reduce the larger of the pair
                larger_i = src_i if a[src_i] >= a[partner] else partner
                if a[larger_i] < 1e-14:
                    continue
                
                # Compute "danger" at each position: how much would putting mass there
                # increase the total peak value
                # danger[j] = sum_{k in top_peaks} 2*a[k-j] (effect on peak from adding mass at j)
                danger = np.zeros(n)
                for k2 in top_idx[:10]:
                    k2i = int(k2)
                    # Effect of a[j] on b[k2]: derivative is 2*a[k2-j] (if valid)
                    j_lo = max(0, k2i - n + 1)
                    j_hi = min(n - 1, k2i)
                    if j_lo <= j_hi:
                        danger[j_lo:j_hi+1] += 2.0 * a[k2i - np.arange(j_lo, j_hi + 1)]
                
                # Find positions with low danger
                # Exclude positions near the source
                danger[larger_i] = np.inf
                n_try = min(20, n // 5)
                low_danger = np.argsort(danger)[:n_try]
                
                for dst in low_danger:
                    dst_int = int(dst)
                    if dst_int == larger_i or danger[dst_int] == np.inf:
                        continue
                    for frac in [0.002, 0.005, 0.01, 0.02, 0.05]:
                        amt = a[larger_i] * frac
                        if amt < 1e-16:
                            continue
                        a_trial = a.copy()
                        a_trial[larger_i] -= amt
                        a_trial[dst_int] += amt
                        a_trial = np.maximum(a_trial, 0.0)
                        s_t = a_trial.sum()
                        if s_t < 1e-15:
                            continue
                        a_trial = a_trial / s_t
                        M_trial = fast_autocorr(a_trial).max()
                        if M_trial < best_m - 1e-16:
                            a = a_trial
                            best_m = M_trial
                            best_a = a.copy()
                            improved = True
                            break
                    if improved:
                        break
            
        if not improved and no_improve > 200:
            # Random exploration
            for _ in range(20):
                i = int(rng.integers(n))
                j = int(rng.integers(n))
                if i != j and a[i] > 1e-10:
                    frac = rng.uniform(0.001, 0.03)
                    amt = a[i] * frac
                    a[i] -= amt
                    a[j] += amt
                    a = np.maximum(a, 0.0)
                    s_t = a.sum()
                    if s_t > 1e-15:
                        a = a / s_t
                        M_new = fast_autocorr(a).max()
                        if M_new < best_m:
                            best_m = M_new
                            best_a = a.copy()
                            improved = True
                            no_improve = 0
                            break
        
        if verbose and no_improve % 2000 == 0 and no_improve > 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print("    PeakDef (" + str(round(elapsed, 1)) + "s): J=" + repr(round(J, 6)) + " stall=" + str(no_improve))
    
    return best_a, best_m

def lp_based_refine(a0, time_limit, verbose=True, seed=99):
    """Use LP direction finding to guide updates."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)
    
    while time.monotonic() - t0 < time_limit:
        c = fast_autocorr(a)
        if c.max() < best_m - 1e-15:
            best_m = c.max()
            best_a = a.copy()
        
        # Get LP direction
        g = lp_direction(a, best_m * 1.001, time_limit=3.0)
        if g is not None:
            # Take a step toward g
            for t_frac in [0.1, 0.2, 0.3, 0.5]:
                a_trial = (1.0 - t_frac) * a + t_frac * g
                a_trial = np.maximum(a_trial, 0.0)
                s_t = a_trial.sum()
                if s_t < 1e-15:
                    continue
                a_trial = a_trial / s_t
                M_trial = fast_autocorr(a_trial).max()
                if M_trial < best_m:
                    a = a_trial
                    best_m = M_trial
                    best_a = a.copy()
                    break
        else:
            # Fallback: random perturbation
            if time.monotonic() - t0 > 10:
                break
        
        if verbose and (time.monotonic() - t0) % 30 < 1:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print("    LPRefine (" + str(round(elapsed, 1)) + "s): J=" + repr(round(J, 6)))
    
    return best_a, best_m

def coordinate_descent_polish(a0, time_limit, verbose=True, seed=123):
    """Fine-grained coordinate descent: adjust individual positions to reduce peaks."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)
    stall = 0
    max_stall = 1000
    
    while time.monotonic() - t0 < time_limit and stall < max_stall:
        c = fast_autocorr(a)
        threshold = np.percentile(c, 98)
        peak_positions = np.where(c > threshold)[0]
        if len(peak_positions) == 0:
            peak_positions = np.argsort(c)[::-1][:10]
        
        improved = False
        
        for k in peak_positions[:15]:
            if improved and (time.monotonic() - t0 > time_limit):
                break
            k_int = int(k)
            i_start = max(0, k_int - n + 1)
            i_end = min(n - 1, k_int)
            if i_start > i_end:
                continue
            idx = np.arange(i_start, i_end + 1)
            products = a[idx] * a[k_int - idx]
            
            # Try reducing top 3 products
            n_pairs = min(5, len(idx))
            top_pairs = np.argsort(products)[::-1][:n_pairs]
            
            for pi in top_pairs:
                if improved:
                    break
                src_i = int(idx[pi])
                partner = k_int - src_i
                if partner < 0 or partner >= n or partner == src_i:
                    continue
                if a[src_i] < 1e-15 and a[partner] < 1e-15:
                    continue
                
                larger_i = src_i if a[src_i] >= a[partner] else partner
                if a[larger_i] < 1e-15:
                    continue
                
                # Try moving small amount to random positions
                for _ in range(5):
                    dst = int(rng.integers(n))
                    if dst == larger_i:
                        continue
