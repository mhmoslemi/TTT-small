where c is the gradient of the objective at the current point. For our case, the "objective" is max_k conv_k(a), and the gradient at a is... hmm, it's not straightforward because it's non-smooth.

Actually, in the standard FW for non-smooth objectives:
- At point a, compute subgradient G of f(a) = max_k conv_k(a)
- f(a) = max_k c_k where c_k = conv_k(a)
- Subgradient: G = sum_{k active} lambda_k * grad_k where lambda_k ≥ 0, sum lambda_k = 1
  and grad_k[i] = a[k-i] (for the k-th convolution term)
- The FW step: minimize G^T g over the simplex {g ≥ 0, sum g = 1}
  This gives: g = e_j where j = argmin_i G[i] (a vertex of the simplex)
  
Wait, that gives a vertex! That's the standard FW step. But that might be too aggressive (jumping to a vertex).

The improved FW (or "lazy" FW) instead solves:
min G^T g s.t. A g ≤ b, g ≥ 0, sum g = 1
where A g ≤ b represents the linearized constraints.

In our case:
- G = sum_{k in active_top} (1/|active|) * a[k - :]* (the subgradient)
- Constraints: for each k in active_set, conv_k(g) ≤ M where M = max conv_k(a)
  But conv_k(g) = sum_i g[i] * a[k-i] is LINEAR in g!
  
So the LP is:

s.t. sum_i g[i] * a[k-i] ≤ M for k in active_set

def fast_autocorr(a):
    """Compute linear autocorrelation via FFT."""
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def simplex_project(z):
    """Project z onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(z)
    if n == 0:
        return z
    u = np.sort(z)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(z - theta, 0.0)


def normalize(a):
    """Normalize to probability simplex."""
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s


def interp_seq(f, new_n):
    """Interpolate sequence to new length, preserving normalization."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    f = normalize(f)
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    out = np.interp(new_x, old_x, f)
    return normalize(out)
