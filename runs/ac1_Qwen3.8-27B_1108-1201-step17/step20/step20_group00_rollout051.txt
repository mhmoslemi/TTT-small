So the subgradient of f(a) = max_k c[k] at a is:
∇f(a)[i] = 2 * sum_{k in active} λ_k * a[k-i] (for valid k-i)

where the active set is {k : c[k] = max} and λ is any probability distribution over the active set (for the subgradient of max).

For the Frank-Wolfe method, we want to minimize ⟨∇f(a), g - a⟩ over g in the feasible set (simplex). Since ⟨∇f(a), a⟩ is constant, this is equivalent to minimizing ⟨∇f(a), g⟩ = sum_i 2 * (sum_k λ_k * a[k-i]) * g[i].

If we use the "worst-case" subgradient (λ_k uniform over active peaks), then:
⟨∇f(a), g⟩ = (2/|active|) * sum_k sum_i a[k-i] * g[i] = (2/|active|) * sum_k c_cross[k]

where c_cross[k] = sum_i a[k-i] * g[i] = (a * g)[k] (with appropriate indexing for the full convolution).

So we want to minimize max_k (a*g)[k] over g in the simplex, which is exactly the LP in the previous code!
