Let me also consider: what if we DON'T keep the phase, but instead use a "flat" phase (i.e., all ones)? That would give a symmetric `a_new`, which we know is suboptimal.

What if we use the phase from the PREVIOUS iteration but add a small perturbation? This is like a "phase diversification" strategy.

Actually, I think the best approach is:
1. Start with a non-symmetric initial sequence
2. Use FDR iterations with phase preservation
3. The phase will naturally evolve to maintain the asymmetry

Let me also think about the target `T`. We want to decrease `T` over time:
- Start with `T = max(c) + epsilon` (slightly above current max)
- Gradually decrease `T`
- If the algorithm can't reach `T` (i.e., the max stays above `T`), decrease the rate of decrease

This is similar to the "successive over-relaxation" approach.

**Additional idea: Combine FDR with the LP approach**

Instead of a pure FDR iteration, I can:
1. Run a few FDR iterations to get a good structure
2. Then use the LP to find the optimal direction
3. Blend and repeat

But the LP might be too slow. Let me estimate: for n=6700, the LP has 6700 variables and ~13400 constraints. With a good solver, this might take 1-10 seconds per call. Over 1800 seconds, I could do maybe 100-500 LP iterations. That's not bad.

Actually, let me reconsider the LP. The constraint `(f*g)[k] <= M` for all k means:
`sum_i f[i] * g[k-i] <= M` for k = 0, ..., 2n-2

The matrix `A` has entries `A[k,j] = f[k-j]` (with `f[x] = 0` for x outside [0,n-1]). This is a Toeplitz-like matrix.

For the LP, I can use cvxpy with the constraint `A @ g <= M`. The matrix A is (2n-1) x n, which is about 13399 x 6700 ≈ 90M entries. That's large but should be manageable.

Actually, I realize I can make the LP much smaller by only including the top K peak constraints. If I only constrain the top 50 peaks, I get a 50-constraint LP, which is very fast.

**Revised LP approach:**
```
maximize: sum(g)
subject to: g >= 0
            (f*g)[k] <= M for k in top_K_peaks
```

This has only K constraints (plus non-negativity), so it's very fast!

Let me now write the complete implementation:

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. FDR (Frequency Domain Relaxed) iterations for fast structural optimization
2. LP-guided direction finding with top-K peak constraints
3. Nesterov accelerated gradient with log-sum-exp smoothing
4. Targeted peak surgery for final polish
5. Multi-length exploration
"""

import numpy as np
import time

def fast_autocorr(a):
    """Compute full linear convolution of a with itself using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(np.asarray(a, dtype=np.float64), fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def evaluate_safe(a):
    try:
        a_list = [float(x) for x in np.asarray(a, dtype=np.float64)]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')

def norm_sum1(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s

def simplex_project(z):
    """Project onto probability simplex {x >= 0, sum(x) = 1}."""
    n = len(z)
    u = np.sort(z)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    rho = np.nonzero(cond)[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(z - theta, 0.0)

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss

def fdr_iteration(a, T, keep_phase=True):
    """One FDR iteration for reducing max autocorrelation."""
    n = len(a)
    L = 2 * n - 1
    
    A = np.fft.rfft(a, L)
    c = np.fft.irfft(A * A, L)
    c = np.maximum(c, 0)
    
    # Threshold
    c[c > T] = T
    
    # Ensure valid spectrum
    C = np.fft.rfft(c, L)
    C_real = np.real(C)  # should be real since c is symmetric
    C_mag = np.maximum(C_real, 0)
    
    # New A magnitude
    A_new_mag = np.sqrt(C_mag)
    
    if keep_phase:
        # Preserve phase
        A_abs = np.abs(A)
        phase = A / (A_abs + 1e-30)  # unit phasor
        A_new = A_new_mag.astype(np.complex128) * phase
    else:
        A_new = A_new_mag.astype(np.complex128)
    
    a_new = np.fft.irfft(A_new, L)[:n]
    a_new = np.maximum(a_new, 0)
    s = a_new.sum()
    if s > 1e-15:
        a_new = a_new / s
    else:
        a_new = a.copy()
    
    return a_new

def fdr_optimize(a0, time_limit, T_start=None, T_end=None, n_iters_max=50000,
                 verbose=True, seed=1):
    """FDR-based optimization with adaptive target."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_max = fast_autocorr(a).max()
    t0 = time.monotonic()
    
    if T_start is None:
        T_start = best_max * 1.01
    if T_end is None:
        T_end = best_max * 0.95
    
    T = T_start
    decay = (T_end / T_start) ** (1.0 / max(1, n_iters_max))
    
    for it in range(n_iters_max):
        if time.monotonic() - t0 > time_limit:
            break
        
        a = fdr_iteration(a, T, keep_phase=True)
        
        c = fast_autocorr(a)
        cur_max = c.max()
        
        if cur_max < best_max - 1e-15:
            best_max = cur_max
            best_a = a.copy()
        
        # Adaptive T: if stuck, reduce decay rate
        if it % 100 == 0:
            T = max(T_end, T * decay ** 100)
        
        if verbose and it % 5000 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_max
            print("  FDR it=" + str(it) + " (" + str(round(elapsed, 1)) + "s): J=" + repr(round(J, 6)) + ", T=" + str(round(T, 8)))
    
    return best_a, best_max

def lp_direction(f, M, K=30, solver=None):
    """Solve LP to find direction g that maximizes sum(g) subject to f*g <= M."""
    try:
        import cvxpy as cp
    except:
        return None
    
    n = len(f)
    c = fast_autocorr(f)
    # Get top K peak positions
    top_K = np.argsort(c)[::-1][:K]
    
    g = cp.Variable(n, nonneg=True)
    
    # Build the convolution matrix A where A[k,j] = f[k-j] (valid entries)
    # For efficiency, only use top K constraints
    constraints = [cp.sum(g) <= 10]  # slack constraint to prevent unboundedness
    
    f_arr = np.asarray(f, dtype=np.float64)
    for k in top_K:
        k_int = int(k)
        i_start = max(0, k_int - n + 1)
        i_end = min(n - 1, k_int)
        if i_start > i_end:
            continue
        idx = np.arange(i_start, i_end + 1)
        # (f*g)[k] = sum_{i=i_start}^{i_end} f[i] * g[k-i]
        # = sum_{j=0}^{n-1} f[k-j] * g[j] (where f[k-j] is 0 if k-j outside [0,n-1])
        # Coefficient for g[j] is f[k-j] (if valid)
        coeffs = np.zeros(n)
        for j in range(n):
            k_minus_j = k_int - j
            if 0 <= k_minus_j < n:
                coeffs[j] = f_arr[k_minus_j]
        constraints.append(coeffs @ g <= M)
    
    prob = cp.Problem(cp.Maximize(cp.sum(g)), constraints)
    
    try:
        if solver is not None:
            prob.solve(solver=solver, verbose=False)
        else:
            prob.solve(verbose=False)
    except:
        return None
    
    if prob.status in ('optimal', 'optimal_inaccurate') and g.value is not None:
        g_val = np.maximum(g.value, 0)
        s = g_val.sum()
        if s > 1e-15:
            return g_val / s
    return None

def lp_guided_iterate(a0, time_limit, K=20, blend=0.3, verbose=True, solver=None):
    """LP-guided iteration: find direction via LP, blend, repeat."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_max = fast_autocorr(a).max()
    t0 = time.monotonic()
    
    for it in range(10000):
        if time.monotonic() - t0 > time_limit:
            break
        
        M = fast_autocorr(a).max()
        g = lp_direction(a, M, K=K, solver=solver)
        
        if g is not None:
            a_new = (1 - blend) * a + blend * g
            a_new = np.maximum(a_new, 0)
            s = a_new.sum()
            if s > 1e-15:
                a_new = a_new / s
                new_max = fast_autocorr(a_new).max()
                if new_max < best_max:
                    best_max = new_max
                    best_a = a_new.copy()
                a = a_new
        
        if verbose and it % 10 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_max
            print("  LP-iter " + str(it) + " (" + str(round(elapsed, 1)) + "s): J=" + repr(round(J, 6)))
    
    return best_a, best_max

def nesterov_opt(a0, time_limit, beta_start=30.0, beta_end=2000.0,
                 beta_growth=1.006, eta_base=0.6, top_k_ratio=0.02,
                 restart_every=2000, verbose=True, seed=42):
    """Nesterov accelerated projected gradient with log-sum-exp."""
    n = len(a0)
    x = norm_sum1(a0)
    x_prev = x.copy()
    best_a = x.copy()
    best_max_b = fast_autocorr(x).max()
    t0 = time.monotonic()
    beta = beta_start
    t_nest = 1.0
    stall = 0
    rng = np.random.default_rng(seed)
    top_k = max(10, int(n * top_k_ratio))
    
    for t in range(1, 10000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t_nest * t_nest)) / 2.0
        theta = (t_nest - 1.0) / t_new
        y = x + theta * (x - x_prev)
        y = np.maximum(y, 1e-15)
        s_y = y.sum()
        if s_y < 1e-15:
            y = x.copy()
        else:
            y = y / s_y
        
        # Compute gradient of smoothed max
        c = fast_autocorr(y)
        if top_k < len(c):
            idx = np.argsort(c)[::-1][:top_k]
            c_use = np.zeros(len(c))
            c_use[idx] = c[idx]
            c_max = c[idx].max()
        else:
            c_use = c
            c_max = c.max()
        
        shifted = beta * (c_use - c_max)
        shifted = np.clip(shifted, -300, 300)
        exp_vals = np.exp(shifted)
        total = exp_vals.sum()
        if total < 1e-300:
            p = np.zeros_like(c_use)
            p[np.argmax(c)] = 1.0
        else:
            p = exp_vals / total
        
        # Gradient computation via FFT
        fft_size = 1 << (2 * n - 1).bit_length()
        P = np.fft.rfft(p, fft_size)
        y_rev = y[::-1]
        Y_rev = np.fft.rfft(y_rev, fft_size)
        Conv = np.fft.irfft(P * Y_rev, fft_size)
        grad = (2.0 / beta) * Conv[n - 1:2 * n - 1]
        
        eta = eta_base / max(1.0, beta * p.max() * 2.0)
        eta = min(eta, 0.1)
        
        z = y - eta * grad
        x_new = simplex_project(z)
        
        b_new = fast_autocorr(x_new)
        max_new = b_new.max()
        if max_new < best_max_b - 1e-15:
            best_max_b = max_new
            best_a = x_new.copy()
            stall = 0
        else:
            stall += 1
        
        x_prev = x
        x = x_new
        t_nest = t_new
        
        if t % 50 == 0:
            beta = min(beta * beta_growth, beta_end)
        
        if stall > restart_every:
            stall = 0
            t_nest = 1.0
            noise_scale = 0.03 / (1.0 + 0.05 * (t // restart_every))
            anti = (np.arange(n) - (n - 1) / 2.0) / n
            anti -= anti.mean()
            rand = rng.normal(0, 1, n)
            pert = noise_scale * (0.5 * anti + 0.5 * rand) * best_a
            x_r = best_a + pert
            x_r = np.maximum(x_r, 1e-10)
            x_r = x_r / x_r.sum()
            x = x_r
            x_prev = x_r.copy()
            beta = max(beta * 0.6, 10.0)
        
        if verbose and t % 5000 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_max_b
            print("  Nest t=" + str(t) + " (" + str(round(elapsed, 1)) + "s): J=" + repr(round(J, 6)) + ", beta=" + str(round(beta, 1)))
    
    return best_a, best_max_b

def peak_surgery(a0, time_limit, verbose=True, seed=77):
    """Targeted local search for reducing specific peaks."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit and no_improve < 5000:
        c = fast_autocorr(a)
        c_max = c.max()
        if c_max < best_m - 1e-15:
            best_m = c_max
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        n_top = min(20, len(c))
        top_idx = np.argsort(c)[::-1][:n_top]
        
        improved = False
        
        for k in top_idx[:10]:
            if improved:
                break
            k_int = int(k)
            i_start = max(0, k_int - n + 1)
            i_end = min(n - 1, k_int)
            if i_start > i_end:
                continue
            
            idx = np.arange(i_start, i_end + 1)
            products = a[idx] * a[k_int - idx]
            if products.max() < 1e-20:
                continue
            
            src_i = int(idx[np.argmax(products)])
            partner = k_int - src_i
            if partner < 0 or partner >= n:
                continue
            
            if a[src_i] >= a[partner]:
                reduce_i = src_i
            else:
                reduce_i = partner
            
            if a[reduce_i] < 1e-14:
                continue
            
            # Find low-pressure destination
            pressure = np.zeros(n)
            for k2 in top_idx[:8]:
                k2i = int(k2)
                s2 = max(0, k2i - n + 1)
                e2 = min(n - 1, k2i)
                if s2 <= e2:
                    idx2 = np.arange(s2, e2 + 1)
                    pressure[idx2] += a[k2i - idx2]
                    pressure[k2i - idx2] += a[idx2]
            
            candidates = np.where(pressure < pressure.mean())[0]
            if len(candidates) < 50:
                candidates = np.arange(n)
            candidates = candidates[candidates != reduce_i]
            
            if len(candidates) == 0:
                continue
            
            n_try = min(5, len(candidates))
            try_dsts = candidates[np.argsort(pressure[candidates])[:n_try]]
            
            for dst in try_dsts:
                dst_int = int(dst)
                for frac in [0.01, 0.02, 0.03, 0.05]:
                    amt = a[reduce_i] * frac
                    if amt < 1e-15:
                        continue
                    a_trial = a.copy()
                    a_trial[reduce_i] -= amt
                    a_trial[dst_int] += amt
                    a_trial = np.maximum(a_trial, 0)
                    s_t = a_trial.sum()
                    if s_t < 1e-15:
                        continue
                    a_trial = a_trial / s_t
                    M_trial = fast_autocorr(a_trial).max()
                    if M_trial < best_m - 1e-16:
                        a = a_trial
                        best_m = M_trial
                        best_a = a.copy()
                        improved = True
                        break
                if improved:
                    break
        
        if not improved:
            if no_improve > 500:
                for _ in range(20):
                    i = int(rng.integers(n))
                    j = int(rng.integers(n))
                    if i != j and a[i] > 1e-10:
                        frac = rng.uniform(0.002, 0.05)
                        amt = a[i] * frac
                        a[i] -= amt
                        a[j] += amt
                        a = np.maximum(a, 0)
                        s_t = a.sum()
                        if s_t > 1e-15:
                            a = a / s_t
                            M_new = fast_autocorr(a).max()
                            if M_new < best_m:
                                best_m = M_new
                                best_a = a.copy()
                                improved = True
                                no_improve = 0
                                break
        
        if verbose and no_improve % 2000 == 0 and no_improve > 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print("  PeakSurgery (" + str(round(elapsed, 1)) + "s): J=" + repr(round(J, 6)) + " stall=" + str(no_improve))
    
    return best_a, best_m
