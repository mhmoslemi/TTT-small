For small delta, the first-order change dominates:
b'[k] ≈ b[k] + 2*delta*(a[k-j] - a[k-i])

where a[t] is 0 if t < 0 or t >= n.

This is very useful! For a given pair (i, j), the change in the max is determined by:
max_k (b[k] + 2*delta*(a[k-j] - a[k-i]))

We want to find delta > 0 that minimizes this. This is a 1D problem!

For a fixed (i, j), define c[k] = a[k-j] - a[k-i] (with a[t]=0 for invalid t).
Then b'[k] ≈ b[k] + 2*delta*c[k].

We want to minimize max_k (b[k] + 2*delta*c[k]).

The optimal delta is where the "active" constraints (those achieving the max) are balanced. Specifically, if the current max is M and is achieved at indices S = {k : b[k] = M}, then we want:
M + 2*delta*c[k] <= M for all k (to not increase the max)
But we also want to decrease M, so we need some k in S to have c[k] < 0.

The optimal delta is:
delta* = min over k with c[k] > 0 of (M - b[k]) / (2*c[k])
         (capped by the constraint that a[i] - delta >= 0, so delta <= a[i])

Wait, we also need a[i] - delta >= 0, so delta <= a[i].

And we want to choose (i, j) and delta to minimize the new max.

This gives us an efficient local search:
1. Compute b = autocorr(a)
2. Find the top peaks: S = {k : b[k] >= M - epsilon} (M = max(b))
3. For each i contributing to peaks in S, and for each candidate j:
   - Compute c[k] = a[k-j] - a[k-i] for relevant k
   - Find optimal delta
   - Evaluate new max
4. Apply the best move

The key efficiency gain is that we can evaluate the new max in O(|S|) time instead of O(n) (since we only care about the top peaks and their neighbors).

Actually, we need to be more careful. A move might reduce the top peaks but create new peaks elsewhere. So we need to check all k, not just the current top ones.

But for small delta, only k near the current peaks can change significantly. So we can limit the check to k within some range of the current peaks.

Let me implement this more carefully:

For a move (i, j, delta):

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)

                partner = k_int - src
                if partner < 0 or partner >= n:
                    continue
                if a[src] < 1e-14:
                    continue

                # Compute "pressure" at each position from all peaks
                dest_candidates = []
                for ds in range(n):
                    if ds == src:
                        continue

                    # First-order: new_b[k] ≈ b[k] + 2*delta*(a[k-ds] - a[k-src])
                    # We want this to reduce the peak at k_int

                    val_at_src = a[k_int - src] if 0 <= k_int - src < n else 0.0
                    val_at_ds = a[k_int - ds] if 0 <= k_int - ds < n else 0.0
                    if val_at_ds < val_at_src * 0.8:
                        # Check it won't create a new peak elsewhere
                        dest_candidates.append(ds)

                            pressure[pk_i - ii] += a[ii]

        # Simpler: pad both to size 4n, compute via FFT
        fft_len = 1 << (4 * n - 1).bit_length()
        Y = np.fft.rfft(y, fft_len)
        P = np.fft.rfft(p, fft_len)
        # We want grad[i] = (2/beta) * sum_k p[k] * y[k-i] for 0<=i<n
        # = (2/beta) * (sum_k p[k] * y[k-i])
        # Let's define q = p (length 2n-1, zero-padded to fft_len)
        # And y (length n, zero-padded to fft_len)
        # We need: for each i in [0,n-1], sum_{k} p[k] * y[k-i] where y[j]=0 for j<0 or j>=n
        # = sum_{k=i}^{i+n-1} p[k] * y[k-i]  (since y[m] nonzero for m in [0,n-1])
        # = sum_{m=0}^{n-1} p[m+i] * y[m]
        # This is the cross-correlation: (p ⊛ y)[i] where (p ⊛ y)[i] = sum_m p[m+i]*y[m]
        # In FFT terms: cross_corr = IFFT(FFT(p) * conj(FFT(y)))... 
        # Actually: cross_corr[i] = sum_m p[m+i]*y[m] = (flip(p) * y)[len(p)-1-i]... 
        # Let me just compute it directly for the top_k peaks (which is fast)

        grad = np.zeros(n)
        for k_i in idx_top:
            k_int = int(k_i)
            i_start = max(0, k_int - n + 1)
            i_end = min(n - 1, k_int)
            if i_start <= i_end:
                idx = np.arange(i_start, i_end + 1)
                grad[idx] += p[k_int] * 2.0 * y[k_int - idx]

        grad /= beta

        # Step size (decreasing)
        eta = 1.0 / (np.sqrt(t) * (np.linalg.norm(grad) + 1e-10))
        eta = min(eta, 0.03)
        eta = max(eta, 1e-8)

        # Update
        x_prev = x.copy()
        x_new = y - eta * grad
        x_new = simplex_project(x_new, 1.0)
        x = x_new

        # Check improvement
        b_new = fast_autocorr(x)
        m_new = b_new.max()
        if m_new < best_m - 1e-15:
            best_m = m_new
            best_a = x.copy()
            stall = 0
        else:
            stall += 1

        # Adaptive beta
        if t % 30 == 0:
            beta = min(beta * beta_growth, beta_end)

        # Periodic restart
        if stall > 800:
            stall = 0
            noise = 0.015 / (1.0 + 0.1 * (t // 800))
            pert = rng.normal(0, noise, n) * best_a
            x_r = best_a + pert
            x_r = np.maximum(x_r, 1e-14)
            x_r /= x_r.sum()
            m_r = fast_autocorr(x_r).max()
            if m_r < best_m:
                best_m = m_r
                best_a = x_r.copy()
            x = x_r
            x_prev = x_r.copy()
            beta = max(beta * 0.5, 5.0)
            if verbose:
                elapsed = time.monotonic() - t0
                J = 2.0 * n * best_m
                print("    Nesterov restart t=" + str(t) + " (" + str(round(elapsed, 1)) + "s): J=" + repr(J))

        if verbose and t % 500 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print("    Nesterov t=" + str(t) + " (" + str(round(elapsed, 1)) + "s): J=" + repr(J) + " beta=" + str(round(beta, 1)))

    return best_a, best_m

def lp_refine(a0, time_limit, solver, verbose=True):
    """LP-based Frank-Wolfe with active set and warm starting."""
    n = len(a0)
    if solver is None:
        return a0.copy(), fast_autocorr(a0).max()

    a = norm_sum1(a0)
    best_a = a.copy()
    b = fast_autocorr(a)
    best_m = b.max()
    t0 = time.monotonic()
    no_improve = 0
    t = 0
    active_set = set(int(k) for k in np.argsort(b)[::-1][:min(1500, 2 * n - 1)])

    while time.monotonic() - t0 < time_limit and no_improve < 200:
        t += 1
        b = fast_autocorr(a)
        M_curr = b.max()

        if M_curr < best_m - 1e-14:
            best_m = M_curr
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1

        # Update active set
        constraint_list = sorted(active_set)
        if len(constraint_list) > 2000:
            margins = np.array([M_curr - b[k] for k in constraint_list if 0 <= k < len(b)])
            valid_list = [k for k in constraint_list if 0 <= k < len(b)]
            if len(valid_list) > 0:
                keep = np.argsort(margins)[:1800]
                active_set = set(int(valid_list[i]) for i in keep)

        # Add violated constraints
        violations = np.where(b > M_curr + 1e-8)[0]
        if len(violations) > 0:
            top_v = violations[np.argsort(b[violations])[::-1][:20]]
            for k in top_v:
                active_set.add(int(k))

        constraint_list = sorted(active_set)
        K = len(constraint_list)
        if K == 0 or K > 3000:
            break

        # Build constraint matrix: A[j, i] = a[k_j - i] if valid
        # Constraint: sum_i A[j,i] * g[i] <= M for each j
        coeffs = np.zeros((K, n))
        for jj, k in enumerate(constraint_list):
            k_int = int(k)
            i_start = max(0, k_int - n + 1)
            i_end = min(n - 1, k_int)
            if i_start <= i_end:
                idx = np.arange(i_start, i_end + 1)
                coeffs[jj, idx] = a[k_int - idx]

        g_var = cp.Variable(n, nonneg=True)
        M_var = cp.Variable()
        constraints = [cp.sum(g_var) == 1, coeffs @ g_var <= M_var]
        prob = cp.Problem(cp.Minimize(M_var), constraints)

        try:
            prob.solve(solver=solver, verbose=False)
        except Exception:
            continue

        if prob.status not in ('optimal', 'optimal_inaccurate'):
            continue

        g_val = np.maximum(np.asarray(g_var.value, dtype=np.float64), 0.0)
        g_sum = g_val.sum()
        if g_sum < 1e-15:
            continue
        g_dir = g_val / g_sum

        # Check for violations in the full convolution
        size = 2 * n - 1
        fft_size = 1 << (size - 1).bit_length()
        Af = np.fft.rfft(a, fft_size)
        Gf = np.fft.rfft(g_dir, fft_size)
        conv_ag = np.fft.irfft(Af * Gf, fft_size)[:size]

        new_violations = np.where(conv_ag > M_curr + 5e-4)[0]
        if len(new_violations) > 0:
            top_nv = new_violations[np.argsort(conv_ag[new_violations])[::-1][:30]]
            for k in top_nv:
                active_set.add(int(k))

        # Line search
        alphas = [2.0 / (t + 2.0), 1.0 / (t + 1), 0.1, 0.05, 0.02]
        best_alpha = 2.0 / (t + 2.0)
        best_trial_M = M_curr
        for alpha in alphas:
            trial = (1.0 - alpha) * a + alpha * g_dir
            trial = np.maximum(trial, 0.0)
            st = trial.sum()
            if st < 1e-15:
                continue
            trial /= st
            M_trial = fast_autocorr(trial).max()
            if M_trial < best_trial_M:
                best_trial_M = M_trial
                best_alpha = alpha

        a_new = (1.0 - best_alpha) * a + best_alpha * g_dir
        a_new = np.maximum(a_new, 0.0)
        st = a_new.sum()
        if st > 1e-15:
            a_new /= st
        a = a_new

        if verbose and t % 50 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print("    LP iter=" + str(t) + " (" + str(round(elapsed, 1)) + "s): J=" + repr(J) + " |S|=" + str(len(active_set)))

    return best_a, best_m

def coord_descent(a0, time_limit, verbose=True):
    """Coordinate descent: optimize one coordinate at a time."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    b = fast_autocorr(a)
    best_m = b.max()
    t0 = time.monotonic()
    rng = np.random.default_rng(99)

    # Precompute which positions matter for top peaks
    while time.monotonic() - t0 < time_limit:
        b = fast_autocorr(a)
        M = b.max()
        if M < best_m - 1e-15:
            best_m = M
            best_a = a.copy()

        # Pick a random coordinate to optimize
        # Bias towards coordinates involved in top peaks
        top_peaks = np.argsort(b)[::-1][:15]
        involved = set()
        for k_i in top_peaks[:8]:
            k_int = int(k_i)
            i_start = max(0, k_int - n + 1)
            i_end = min(n - 1, k_int)
            if i_start <= i_end:
                for i in range(i_start, i_end + 1, max(1, (i_end - i_start) // 10)):
                    involved.add(i)
                for i in range(i_start, i_end + 1, max(1, (i_end - i_start) // 10)):
                    partner = k_int - i
                    if 0 <= partner < n:
                        involved.add(partner)

        if len(involved) > 0:
            i = list(involved)[rng.integers(len(involved))]
        else:
            i = rng.integers(n)

        # Optimize coordinate i: try several values
        a_i = a[i]
        # The optimal a[i] balances the constraints
        # Try: current value, scaled up, scaled down, and a few intermediate
        candidates = [a_i * 0.5, a_i * 0.7, a_i * 0.85, a_i, a_i * 1.15, a_i * 1.3, a_i * 1.5, a_i * 2.0]
        # Add: redistribute the mass to the position with lowest autocorrelation contribution
        if a_i > 1e-10:
            # Where would this mass go most safely?
            b_without_i = b - 2.0 * a_i * np.concatenate([a[max(0, -i):n-i if n-i>0 else 0], np.zeros(max(0, i))]) if i < n else b
            # Simplified: just try moving to a few random positions
            for frac in [0.3, 0.5, 0.7]:
                amt = a_i * frac
                j = rng.integers(n)
                if j != i:
                    a_trial = a.copy()
                    a_trial[i] -= amt
                    a_trial[j] += amt
                    a_trial = np.maximum(a_trial, 0.0)
                    st = a_trial.sum()
                    if st > 1e-15:
                        a_trial /= st
                        m_trial = fast_autocorr(a_trial).max()
                        if m_trial < best_m - 1e-15:
                            a = a_trial
                            best_m = m_trial
                            best_a = a.copy()
                            break

        if verbose and best_a is not None and t0 > 0:
            pass  # Keep it quiet

    return best_a, best_m

def propose_candidate(budget_s=1800.0):
    """Main search: iterative local search + Nesterov subgradient + LP refinement."""
    t_global = time.monotonic()
    time_budget = min(float(budget_s) - 45.0, 1740.0)

    solver = get_solver()
    print("Time budget: " + repr(time_budget) + "s, solver: " + str(solver))

    best_seq = None
    best_score = float('inf')

    # Load parent
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            parent = p.copy()
            p_score = evaluate_safe(parent)
            if np.isfinite(p_score):
                best_seq = norm_sum1(parent)
                best_score = p_score
                print("Parent: n=" + str(len(parent)) + ", score=" + repr(p_score))
    except Exception:
        parent = None

    if best_seq is None:
        n_base = 6700
        x = np.linspace(0, 1, n_base)
        a_raw = (x + 0.01) ** 1.0 * (1.0 - x + 0.01) ** 1.0
        best_seq = norm_sum1(a_raw)
        best_score = evaluate_safe(best_seq)
        print("Default init: n=" + str(len(best_seq)) + ", score=" + repr(best_score))

    n0 = len(best_seq)

    # Main iterative loop: alternate between methods
    phase_times = [
        ("local", 0.15),
        ("nesterov", 0.30),
        ("local", 0.10),
        ("lp", 0.20),
        ("nesterov", 0.15),
        ("local", 0.05),
        ("lp", 0.05),
    ]

    for phase_name, frac in phase_times:
        remaining = time_budget - (time.monotonic() - t_global)
        if remaining < 20:
            break
        t_phase = min(remaining * frac, remaining * 0.4)
        n_best = len(best_seq)
        elapsed = time.monotonic() - t_global

        if phase_name == "local":
            print("\n=== Local Search (n=" + str(n_best) + ", t=" + str(round(elapsed, 1)) + "s) ===")
            a_out, _ = local_search(best_seq, t_phase, top_k=30, verbose=True)
            best_seq, best_score = try_update(best_seq, best_score, a_out, "local", t_global)

        elif phase_name == "nesterov":
            print("\n=== Nesterov (n=" + str(n_best) + ", t=" + str(round(elapsed, 1)) + "s) ===")
            a_out, _ = nesterov_subgrad(best_seq, t_phase, beta_start=8.0, beta_end=400.0,
                                        beta_growth=1.01, verbose=True)
            best_seq, best_score = try_update(best_seq, best_score, a_out, "nesterov", t_global)

        elif phase_name == "lp":
            print("\n=== LP (n=" + str(n_best) + ", t=" + str(round(elapsed, 1)) + "s) ===")
            if solver is not None and n_best <= 8000:
                a_out, _ = lp_refine(best_seq, t_phase, solver, verbose=True)
                best_seq, best_score = try_update(best_seq, best_score, a_out, "lp", t_global)

    # Try nearby n values
    remaining = time_budget - (time.monotonic() - t_global)
    n_best = len(best_seq)
    nearby = []
    for dn in [-300, 300, -600, 600, -900, 900]:
        nl = n_best + dn
        if 4000 < nl <= 9000 and nl != n_best and nl not in nearby:
            nearby.append(nl)

    for new_n in nearby[:3]:
        remaining = time_budget - (time.monotonic() - t_global)
        if remaining < 60:
            break
        print("\n=== n=" + str(new_n) + " (t=" + str(round(time.monotonic() - t_global, 1)) + "s) ===")
        a_interp = interpolate_sequence(best_seq, new_n)
        best_seq, best_score = try_update(best_seq, best_score, a_interp, "interp_n" + str(new_n), t_global)

        remaining = time_budget - (time.monotonic() - t_global)
        if remaining > 40:
            a_out, _ = local_search(np.asarray(best_seq), min(remaining * 0.3, 80.0), top_k=25, verbose=False)
            best_seq, best_score = try_update(best_seq, best_score, a_out, "local_n" + str(new_n), t_global)

        remaining = time_budget - (time.monotonic() - t_global)
        if remaining > 40:
            a_out, _ = nesterov_subgrad(np.asarray(best_seq), min(remaining * 0.4, 100.0),
                                        beta_start=10.0, beta_end=300.0, beta_growth=1.01, verbose=False)
            best_seq, best_score = try_update(best_seq, best_score, a_out, "nest_n" + str(new_n), t_global)

    # Final polish on best
    remaining = time_budget - (time.monotonic() - t_global)
    n_best = len(best_seq)
    if remaining > 30:
        print("\n=== Final Polish (n=" + str(n_best) + ") ===")
        t_fp = min(remaining * 0.5, 60.0)
        if t_fp > 15:
            a_out, _ = local_search(best_seq, t_fp, top_k=20, verbose=True)
            best_seq, best_score = try_update(best_seq, best_score, a_out, "final_local", t_global)

        remaining = time_budget - (time.monotonic() - t_global)
        if remaining > 20 and solver is not None and n_best <= 8000:
            t_fl = min(remaining * 0.6, 50.0)
            if t_fl > 10:
                a_out, _ = lp_refine(best_seq, t_fl, solver, verbose=True)
                best_seq, best_score = try_update(best_seq, best_score, a_out, "final_lp", t_global)

    # Validation
    if best_seq is not None:
        fs = evaluate_safe(best_seq)
        if np.isfinite(fs):
            best_score = fs
        elapsed = time.monotonic() - t_global
        print("\nFINAL: score=" + repr(best_score) + ", n=" + str(len(best_seq)) + ", time=" + str(round(elapsed, 1)) + "s")
    else:
        print("\nERROR: No valid sequence!")
        n_fb = 6700
        x = np.linspace(0, 1, n_fb)
        a_raw = (x + 0.01) ** 1.0 * (1.0 - x + 0.01) ** 1.0
        best_seq = norm_sum1(a_raw)
        best_score = evaluate_safe(best_seq)

    return [float(x) for x in np.asarray(best_seq, dtype=np.float64)]
