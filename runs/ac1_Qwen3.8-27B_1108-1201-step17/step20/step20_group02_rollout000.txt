The question is: does c increase with n? For very large n, the sequence can be smoother, and the auto-convolution can be flatter.

Actually, I recall that for the problem of minimizing the peak-to-average power ratio (PAPR) of a sequence, longer sequences can achieve lower PAPR. Similarly here.

Let me think about a specific construction. Consider:
a_i = 1 + ε * cos(2π i / p) + δ * cos(2π i / q) + ...

where p, q are chosen to create "cancellations" in the auto-convolution peak.

The auto-convolution of cos(2πi/p) with itself:
sum_i cos(2πi/p) * cos(2π(i+k)/p) = (1/2) sum_i [cos(2πk/p) + cos(2π(2i+k)/p)]
≈ (n/2) cos(2πk/p) (for large n, the second term averages out)

So adding a cosine modulation creates a deterministic pattern in the auto-convolution that can be designed to have lower peak.

This is related to "gradient echo" or "pulse shaping" in NMR/MRI.

Let me try a specific approach:
- Base: a_i = 1 (uniform)
- Add: a_i = 1 + ε * f(i/n) where f is chosen to reduce the peak

The perturbation to the auto-convolution is approximately:
δc[k] ≈ 2 * sum_i f(i/n) * a[(i+k)/n] * ε + ε^2 * sum_i f(i/n) * f((i+k)/n)

For small ε, the first-order effect is:
δc[k] ≈ 2ε * sum_i f(i) * f((i+k)/n) (if a is close to uniform)

Wait, this isn't quite right. Let me be more careful.

a_i = c * (1 + ε * f(i/(n-1)))
sum a_i = c * n * (1 + ε * mean(f))

For the auto-convolution:
c[k] = sum_{i+j=k} a_i * a_j = c^2 * sum_{i+j=k} (1+εf_i)(1+εf_j)
≈ c^2 * (sum_{i+j=k} 1 + ε * sum_{i+j=k}(f_i + f_j) + ε^2 * sum_{i+j=k} f_i * f_j)

The zeroth-order term gives the triangular shape (uniform auto-conv).
The first-order term: ε * (sum_{i+j=k} f_i + sum_{i+j=k} f_j) = ε * 2 * sum_{i} f[i] (where the sum is over valid i for lag k).
The second-order term: ε^2 * sum_i f[i]*f[i+k] (auto-corr of f at lag k).

To reduce the peak (at k=n-1), we want:
- First-order: sum_i f[i] should be negative (reduce the peak)
- But this also reduces the sum of a, which affects the denominator.

Actually, since the objective is scale-invariant, we can normalize. Let's just work with sum a = 1.

a_i = (1 + ε f_i) / (n + ε sum f)

The auto-conv at lag k:
c[k] = (1/(n+εS_f)^2) * (tri_k + ε * 2 * (f * 1)_k + ε^2 * (f*f)_k)

where tri_k is the number of valid pairs (n-|k-(n-1)| for the triangular part), and (f*g)_k is the cross-conv.

For k = n-1 (the peak):
tri_{n-1} = n
(f*1)_{n-1} = sum_i f_i = S_f
(f*f)_{n-1} = sum_i f_i * f_{n-1-i}

So c[n-1] ≈ (n + 2ε S_f + ε^2 sum f_i f_{n-1-i}) / (n+ε S_f)^2

For small ε: ≈ (n + 2ε S_f) / (n^2 + 2nε S_f) ≈ 1/n * (1 + 2ε S_f/n) / (1 + 2ε S_f/n) ≈ 1/n

Hmm, so to first order, the peak doesn't change! The effect is second-order.

This makes sense: for a uniform base, any first-order perturbation that's roughly "global" doesn't change the peak much. We need a perturbation that's "local" around the peak region.

1. Uses a better parametric initialization (try many shapes)
2. Uses an improved LP-FW with better active set management
3. Uses a frequency-domain projection method as an alternative optimizer
4. Does very careful coordinate descent at the end
5. Tries multiple n values

def fast_conv(a):
    """FFT-based auto-convolution."""
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def obj_val(a):
    """Compute 2*n*max(conv)/(sum)^2."""
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    c = fast_conv(a)
    return 2.0 * n * c.max() / (s * s)


def norm_sum1(a):
    """Clip to non-negative and normalize to sum=1."""
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s


def evaluate_safe(a):
    try:

def interp_seq(f, new_n):
    """Interpolate sequence to new length, preserving shape."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_new = np.interp(new_x, old_x, f_norm)
    f_new = np.maximum(f_new, 0.0)
    ss = f_new.sum()
    return f_new / ss if ss > 1e-15 else np.ones(new_n) / new_n


def make_shape(name, n):
    """Generate parametric shapes for initialization."""
    x = np.linspace(0, 1, n)
    if name == 'uniform':
        return np.ones(n)
    elif name == 'sin':
        return np.sin(np.pi * x)
    elif name == 'sin2':
        return np.sin(np.pi * x) ** 2
    elif name == 'cos_taper':
        return 0.5 * (1 + np.cos(2 * np.pi * (x - 0.5)))
    elif name == 'gauss':
        return np.exp(-((x - 0.5) ** 2) / (2 * 0.2 ** 2))
    elif name == 'tri':
        return np.maximum(0, 1 - np.abs(2 * x - 1))
    elif name == 'cos_p1_5':
        return (0.5 * (1 + np.cos(2 * np.pi * (x - 0.5)))) ** 1.5
    elif name == 'cos_p0_7':
        return (0.5 * (1 + np.cos(2 * np.pi * (x - 0.5)))) ** 0.7
    elif name == 'sin_p0_5':
        return np.sin(np.pi * x) ** 0.5
    elif name == 'sin_p2':
        return np.sin(np.pi * x) ** 2
    elif name == 'poly3':
        # Cubic taper: smooth at edges
        t = np.clip(x * 4 - 1, 0, 1)  # 0 to 1 over [0.25, 0.75]
        return np.maximum(0.01, np.sin(np.pi * t) ** 2)
    elif name == 'flat_taper':
        # Flat middle, tapered edges
        t = np.abs(x - 0.5)
        return np.where(t < 0.3, 1.0, np.maximum(0.01, 1.0 - (t - 0.3) / 0.2))
    else:
        return np.ones(n)


def parametric_init(n):
    """Try many parametric shapes and return the best."""
    shapes = ['uniform', 'sin', 'sin2', 'cos_taper', 'gauss', 'tri',
              'cos_p1_5', 'cos_p0_7', 'sin_p0_5', 'sin_p2', 'poly3', 'flat_taper']
    best_a = None
    best_j = float('inf')
    for name in shapes:
        a = norm_sum1(make_shape(name, n))
        j = obj_val(a)
        if j < best_j:
            best_j = j
            best_a = a.copy()
    return best_a, best_j


def build_lp_matrix(y, k_list, n):
    """Build constraint matrix for LP: (y*g)[k] <= M for k in k_list."""
    K = len(k_list)
    A = np.zeros((K, n))
    for jj in range(K):
        k = int(k_list[jj])
        i_lo = max(0, k - n + 1)
        i_hi = min(n, k + 1)
        if i_lo < i_hi:
            idx = np.arange(i_lo, i_hi)
            A[jj, idx] = y[k - idx]
    return A


def lp_fw_optimize(a0, time_limit, solver, init_K=500, max_K=4000,
                   add_per_iter=50, verbose=True):
    """LP-Frank-Wolfe optimization."""
    n = len(a0)
    y = norm_sum1(a0)
    best_a = y.copy()
    c = fast_conv(y)
    best_m = c.max()
    t0 = time.monotonic()
    
    active_set = sorted(np.argsort(c)[::-1][:init_K].tolist())
    no_improve = 0
    max_no_improve = 600
    stag = 0
    iters = 0
    
    while time.monotonic() - t0 < time_limit:
        if no_improve > max_no_improve:
            if stag > 5:
                if verbose:
                    print("    LP-FW: stopping (persistent stagnation)")
                break
            # Perturb active set
            c_curr = fast_conv(y)
            n_pert = max(50, len(active_set) // 6)
            keep = list(np.random.default_rng(stag).choice(
                len(active_set), size=len(active_set) - n_pert, replace=False))
            new_top = np.argsort(c_curr)[::-1][:n_pert * 3]
            new_set = set(active_set[i] for i in keep)
            for k in new_top:
                new_set.add(int(k))
            active_set = sorted(new_set)[:max_K]
            no_improve = 0
            stag += 1
            continue
        
        iters += 1
        c = fast_conv(y)
        M_curr = c.max()
        
        if M_curr < best_m - 1e-14:
            best_m = M_curr
            best_a = y.copy()
            no_improve = 0
            stag = 0
        else:
            no_improve += 1
        
        # Trim active set
        if len(active_set) > max_K:
            margins = np.array([M_curr - c[k] for k in active_set])
            keep_idx = np.argsort(margins)[:int(max_K * 0.6)]
            base = [active_set[i] for i in keep_idx]
            viol = np.where(c > M_curr - 1e-8)[0]
            for v in viol[:80]:
                base.append(int(v))
            active_set = sorted(set(base))[:max_K]
        
        K = min(len(active_set), max_K)
        active_subset = active_set[:K]
        if K == 0:
            break
        
        A_mat = build_lp_matrix(y, active_subset, n)
        
        g_var = cp.Variable(n, nonneg=True)
        M_var = cp.Variable()
        constraints = [cp.sum(g_var) == 1, A_mat @ g_var <= M_var]
        prob = cp.Problem(cp.Minimize(M_var), constraints)
        
        try:
            prob.solve(solver=solver, verbose=False)
        except Exception:
            active_set = active_set[:max(100, K // 3)]
            continue
        
        if prob.status not in ('optimal', 'optimal_inaccurate'):
            continue
        
        g_val = np.maximum(np.asarray(g_var.value, dtype=np.float64), 0.0)
        g_sum = g_val.sum()
        if g_sum < 1e-15:
            continue
        g_dir = g_val / g_sum
        
        # Add violations to active set
        fft_s = 1 << (2 * n - 1 - 1).bit_length()
        Yf = np.fft.rfft(y, fft_s)
        Gf = np.fft.rfft(g_dir, fft_s)
        conv_ys = np.fft.irfft(Yf * Gf, fft_s)[:2 * n - 1]
        viol_all = np.where(conv_ys > M_curr + 1e-10)[0]
        if len(viol_all) > 0:
            viol_amt = conv_ys[viol_all] - M_curr
            top_v = viol_all[np.argsort(viol_amt)[::-1][:add_per_iter]]
            new_set = set(active_set)
            for k in top_v:
                new_set.add(int(k))
            active_set = sorted(new_set)[:max_K]
        
        # Line search
        best_alpha = 1.0 / (iters + 2.0)
        best_trial_m = fast_conv(y).max()
        
        for alpha in [1.0, 0.8, 0.6, 0.4, 0.25, 0.1,
                      max(0.05, 2.0/(iters+2)), max(0.02, 1.0/(iters+1))]:
            trial = (1 - alpha) * y + alpha * g_dir
            trial = np.maximum(trial, 0.0)
            s_t = trial.sum()
            if s_t < 1e-15:
                continue
            trial = trial / s_t
            m_t = fast_conv(trial).max()
            if m_t < best_trial_m:
                best_trial_m = m_t
                best_alpha = alpha
        
        if iters <= 3:
            y = g_dir.copy()
        else:
            y = (1 - best_alpha) * y + best_alpha * g_dir
            y = np.maximum(y, 0.0)
            s_y = y.sum()
            if s_y < 1e-15:
                y = best_a.copy()
            else:
                y = y / s_y
        
        if verbose and iters % 200 == 0:
            el = time.monotonic() - t0
            print("    LP-FW it=" + str(iters) + " (" + str(round(el,1)) + "s): J=" +
                  repr(2.0*n*best_m) + " |S|=" + str(len(active_set)))
    
    el = time.monotonic() - t0
    if verbose:
        print("    LP-FW done (" + str(round(el,1)) + "s): J=" + repr(2.0*n*best_m) + " it=" + str(iters))
    return best_a, best_m


def freq_project_optimize(a0, time_limit, n_steps=5000, verbose=False):
    """
    Frequency-domain projection: iteratively flatten the auto-convolution
    while maintaining non-negativity.
    
    Algorithm:
    1. Compute auto-conv c = a*a
    2. Compute "target" c_target = mean(c) (flat)
    3. In frequency domain, compute the gradient of max(c) w.r.t. a
    4. Update a in a way that reduces the peak
    """
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    c = fast_conv(a)
    best_m = c.max()
    t0 = time.monotonic()
    rng = np.random.default_rng(7)
    
    alpha0 = 0.3
    alpha_decay = 0.9995
    alpha = alpha0
    stall = 0
    
    for step in range(n_steps):
        if time.monotonic() - t0 > time_limit:
            break
        if stall > 2000:
            break
        
        c = fast_conv(a)
        M = c.max()
        
        if M < best_m - 1e-14:
            best_m = M
            best_a = a.copy()
            stall = 0
        else:
            stall += 1
        
        # Find all near-peak lags
        threshold = M - 0.05 * (M - c.min())
        near_peaks = np.where(c > threshold)[0]
        
        # Compute subgradient for the max
        k_max = int(np.argmax(c))
        grad = np.zeros(n)
        i_lo = max(0, k_max - n + 1)
        i_hi = min(n, k_max + 1)
        if i_lo < i_hi:
            idx = np.arange(i_lo, i_hi)
            grad[idx] = a[k_max - idx]
        
        # Also add gradient from other near-peaks (with smaller weight)
        for k2 in near_peaks[:10]:
            if k2 == k_max:
                continue
            weight = 0.3 * (c[k2] / M)
            i_lo2 = max(0, k2 - n + 1)
            i_hi2 = min(n, k2 + 1)
            if i_lo2 < i_hi2:
                idx2 = np.arange(i_lo2, i_hi2)
                grad[idx2] += weight * a[k2 - idx2]
        
        # Gradient step with projection
        a_new = a - alpha * grad
        a_new = np.maximum(a_new, 0.0)
        s_new = a_new.sum()
        if s_new < 1e-15:
            a = best_a.copy()
            alpha *= 0.5
            continue
        a_new = a_new / s_new
        
        # Check if it improved
        m_new = fast_conv(a_new).max()
        if m_new < M:
            a = a_new
            alpha = min(alpha * 1.01, alpha0)  # slight increase if improving
        else:
            # Rejected, reduce step
            alpha *= 0.7
            # Try a smaller step
            a_try = a - alpha * grad
            a_try = np.maximum(a_try, 0.0)
            s_try = a_try.sum()
            if s_try > 1e-15:
                a_try = a_try / s_try
                m_try = fast_conv(a_try).max()
                if m_try < M:
                    a = a_try
                else:
                    # Add random perturbation
                    noise = rng.normal(0, 0.005, n) * a
                    a_p = a + noise
                    a_p = np.maximum(a_p, 1e-15)
                    s_p = a_p.sum()
                    if s_p > 1e-15:
                        a = a_p / s_p
                    else:
                        a = best_a.copy()
        
        # Periodic restart
        if stall > 500 and stall % 500 == 0:
            a = best_a.copy() * 0.7 + norm_sum1(rng.dirichlet(np.ones(n))) * 0.3
            v = a.copy()  # keep v for reference
            a = norm_sum1(a)
            alpha = alpha0 * 0.5
        
        if verbose and step % 500 == 0:
            el = time.monotonic() - t0
            print("    FreqProj step=" + str(step) + " (" + str(round(el,1)) + "s): J=" +
                  repr(2.0*n*best_m))
    
    return best_a, best_m


def coord_descent(a0, time_limit, verbose=False):
    """Multi-scale coordinate descent with peak-aware transfers."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    c = fast_conv(a)
    best_m = c.max()
    t0 = time.monotonic()
    rng = np.random.default_rng(42)
    stall = 0
    
    for epoch in range(200):
        if time.monotonic() - t0 > time_limit or stall > 800:
            break
        
        c = fast_conv(a)
        n_top = min(20, len(c))
        top_k = np.argsort(c)[::-1][:n_top]
        
        epoch_improved = False
        
        for k in top_k[:12]:
            if time.monotonic() - t0 > time_limit:
                break
            k = int(k)
            i_lo = max(0, k - n + 1)
            i_hi = min(n - 1, k)
            if i_lo > i_hi:
                continue
            idx = np.arange(i_lo, i_hi + 1)
            contrib = a[idx] * a[k - idx]
            if contrib.max() < 1e-20:
                continue
            
            src = int(idx[np.argmax(contrib)])
            src_val = a[src]
            if src_val < 1e-12:
                continue
            
            # Score destinations by their impact on top peaks
            scores = np.zeros(n)
            for k2 in top_k[:8]:
                k2 = int(k2)
                s2 = max(0, k2 - n + 1)
                e2 = min(n - 1, k2)
                if s2 <= e2:
                    idx2 = np.arange(s2, e2 + 1)
                    scores[idx2] += a[k2 - idx2]
            
            # Prefer destinations with low score
            sorted_dst = np.argsort(scores)
            
            # Try multiple fraction sizes
            found = False
            for frac in [0.001, 0.003, 0.008, 0.02, 0.05, 0.1]:
                for pos in sorted_dst[:30]:
                    dst = int(pos)
                    if dst == src:
                        continue
                    amt = src_val * frac
                    if amt < 1e-15:
                        continue
                    a_try = a.copy()
                    a_try[src] -= amt
                    a_try[dst] += amt
                    a_try = np.maximum(a_try, 0.0)
                    s_t = a_try.sum()
                    if s_t < 1e-15:
                        continue
                    a_try = a_try / s_t
                    m_t = fast_conv(a_try).max()
                    if m_t
