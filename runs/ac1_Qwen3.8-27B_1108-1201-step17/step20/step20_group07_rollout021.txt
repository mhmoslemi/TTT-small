3. Compute the "pressure" at each position: `p[i] = sum_{k in S} a[k-i]` (with appropriate bounds).
4. Set `g` to be a point mass at the position with minimum pressure.
5. Take a step towards `g`.

But this is essentially what the peak shaving is already doing! So the Frank-Wolfe approach doesn't add much.

The LP-Frank-Wolfe (which the previous code uses) is different: instead of a point mass, it finds the best `g` in the simplex that satisfies the linearized constraints. This allows for a more nuanced direction.

**Idea: Use a "repulsion" model**

Think of each position `i` as having "mass" `a[i]`. The autocorrelation `b[k]` measures the "interaction" between positions `i` and `k-i`. We want to minimize the maximum interaction.

The key insight is that `b[k] = sum_i a[i] * a[k-i]`. For large `k` (near `n-1`), this is like an "inner product" of `a` with a shifted-and-reversed version of itself. For `k = n-1`, it's `sum_i a[i] * a[n-1-i]`, which is the "flip autocorrelation."
