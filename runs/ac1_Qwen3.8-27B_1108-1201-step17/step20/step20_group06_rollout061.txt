The non-negativity constraint in the time domain becomes a complicated constraint in the frequency domain, so this approach has issues. However, we can use it as a relaxation: optimize in the frequency domain (allowing negative time-domain values), then project back to non-negative.

This is essentially what the spectral refinement does, so let me not go that route.

Another improvement: **use the structure of the gradient more effectively**. The gradient of `b[k]` is essentially `2 * shift(a, k)` (with boundary corrections). So the subgradient of `max_k b[k]` is `2 * shift(a, k*)` for the active lag `k*`. This means the descent direction is "shift the sequence" (in a sense). We can exploit this by:

Actually, let me reconsider the problem from scratch. The score is:
```
score = 2 * n * max(convolve(a, a)) / sum(a)^2
```

Since the score is scale-invariant, let `s = sum(a)` and normalize to `a' = a/s` so that `sum(a') = 1`. Then:
```
score = 2 * n * max(convolve(a', a')) * s^2 / s^2 = 2 * n * max(convolve(a', a'))
```

Wait no. `convolve(c*a, c*a) = c^2 * convolve(a, a)`. And `sum(c*a) = c * sum(a)`. So:
```
score(c*a) = 2 * n * max(c^2 * convolve(a,a)) / (c * sum(a))^2
           = 2 * n * c^2 * max(convolve(a,a)) / c^2 * sum(a)^2
           = 2 * n * max(convolve(a,a)) / sum(a)^2
```

Yes, scale-invariant. So we can normalize `sum(a) = 1` and minimize `2 * n * max(convolve(a, a))`.

For the normalized problem: minimize `max_k b[k]` subject to `a >= 0`, `sum(a) = 1`.

The minimum possible value of `max_k b[k]` is at least `1/n` (from the central lag for symmetric sequences), and for non-symmetric sequences it can be lower (since the central lag can be lower, but other lags might compensate).

The theoretical minimum (over all non-negative sequences with sum=1) of `max_k b[k]` is... hmm, this is a hard problem in general.

For the score to be 1.5, we need `max_k b[k] = 1.5/(2n) = 0.75/n`.

For n=6700, `0.75/6700 ≈ 1.119e-4`. The uniform gives `1/6700 ≈ 1.493e-4`. So we need the max autocorrelation to be about 75% of the uniform value.

This is a significant reduction! The sequence must be quite non-uniform.

Let me think about what kind of sequence achieves this. If `max_k b[k] = 0.75/n` and `sum a = 1`, then:
- `b[0] = a[0]^2 <= 0.75/n` → `a[0] <= sqrt(0.75/n)`
- `b[n-1] = sum_j a[j]*a[n-1-j] <= 0.75/n`
- But `sum_j a[j]^2 >= 1/n` (Cauchy-Schwarz)
- So `sum_j a[j]*a[n-1-j] < sum_j a[j]^2`, meaning the sequence is NOT symmetric

The asymmetry must be such that `a[j]` and `a[n-1-j]` are "anti-correlated" in some sense.

A simple model: `a[j] = (1+epsilon*f(j))/n` where `f` is antisymmetric (`f(n-1-j) = -f(j)`). Then:
- `sum a[j]*a[n-1-j] = sum (1+eps*f(j))(1-eps*f(j))/n^2 = sum (1-eps^2*f(j)^2)/n^2 ≈ 1/n - eps^2*sum(f^2)/n`
- So the central lag is reduced by `eps^2 * sum(f^2) / n`

But we also need to check other lags. For lag k near 0:
- `b[k] = sum_j a[j]*a[k-j]`
- For small k, this is approximately `sum_j (1+eps*f(j))^2 / n^2` (since the overlap is large)
- `≈ (1 + 2*eps*sum(f)/n + eps^2*sum(f^2)/n) / n`
- If `sum(f) = 0` (which it is for antisymmetric f), this is `≈ (1 + eps^2*sum(f^2)/n) / n`
- This is HIGHER than 1/n!

So making the sequence antisymmetric reduces the central lag but increases the edge lags! The max would then be at the edges.

This suggests the optimal solution is a balance: the sequence should be shaped so that ALL lags are approximately equal to some value M, and M is minimized.

This is like a "flat autocorrelation" problem, similar to Barker sequences or Zadoff-Chu sequences!

For sequences with flat autocorrelation, all `b[k] ≈ constant`. The constraint is `a >= 0` and `sum(a) = 1`.

The "flat" value would be approximately `sum(a^2)/n` if the autocorrelation were perfectly flat (which it can't be exactly, since `b[n-1] = sum a[j]*a[n-1-j]` and `b[0] = a[0]^2` must differ).

So the problem is: find a non-negative sequence with sum 1 that has as flat an autocorrelation as possible.

This is reminiscent of the "minimum peak sidelobe" problem in radar/communications, but with the non-negativity constraint.

**New approach: Iterative flattening**

1. Start with a sequence (e.g., uniform or from parent)
2. Compute the autocorrelation `b`
3. Identify the peaks (lags where `b[k] > M`)
4. Adjust the sequence to reduce those peaks while not increasing others
5. Repeat

This is essentially what the LP-FW does, but let me think of a more direct approach.

**Direct approach: "Water-filling" in the autocorrelation domain**

At each step:
1. Compute `b = autocorr(a)`
2. Let `M = max(b)`, `k* = argmax(b)`
3. The gradient of `b[k*]` is `2 * shift(a, k*)` (approximately)
4. We want to reduce `b[k*]` without increasing other `b[k]`
5. The direction that reduces `b[k*]` most while keeping others bounded is the LP-FW direction

Alternatively, a simpler heuristic:
4'. Move mass from positions where `a[i] * a[k*-i]` is large to positions where it's small
5'. This reduces `b[k*]` directly

Let me think about this more carefully. `b[k*] = sum_j a[j] * a[k*-j]`. To reduce this, we can:
- Reduce `a[j]` for j where `a[j] * a[k*-j]` is large
- Move that mass to positions where it doesn't contribute to `b[k*]`

But moving mass to a new position `j'` will affect OTHER lags `b[k]` where `j'` is in the overlap range.

This is exactly the LP-FW approach: find the best direction to move mass.

def fast_autocorr(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def evaluate_safe(a):
    try:
        a_list = [max(0.0, float(x)) for x in np.asarray(a, dtype=np.float64)]
        if not a_list or sum(a_list) < 0.01:
            return float('inf')
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')

def norm_sum1(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s

def simplex_project(z):
    n = len(z)
    u = np.sort(z)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    rho = np.nonzero(cond)[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(z - theta, 0.0)

def grad_autocorr_at_k(a, k):
    """Gradient of b[k] = sum_j a[j]*a[k-j] with respect to a."""
    n = len(a)
    grad = np.zeros(n)
    if k < n:
        lo, hi = 0, k
    else:
        lo, hi = k - n + 1, n - 1
    if lo > hi:
        return grad
    idx = np.arange(lo, hi + 1)
    grad[idx] = 2.0 * a[k - idx]
    if k % 2 == 0:
        mid = k // 2
        if lo <= mid <= hi:
            grad[mid] -= a[mid]
    return grad

def compute_smoothed_obj_and_grad(a, beta, active_lags=None):
    """
    Compute smoothed objective (log-sum-exp approximation to max) and its gradient.
    If active_lags is given, only use those lags.
    """
    n = len(a)
    b = fast_autocorr(a)
    size = 2 * n - 1
    
    if active_lags is not None and len(active_lags) > 0:
        b_use = b[active_lags]
    else:
        b_use = b
    
    b_max = b_use.max()
    shifted = beta * (b_use - b_max)
    shifted = np.clip(shifted, -500, 0)
    exp_vals = np.exp(shifted)
    s = exp_vals.sum()
    if s < 1e-300:
        p = np.ones(len(b_use)) / len(b_use)
    else:
        p = exp_vals / s
    
    # Gradient: sum_k p[k] * grad_b_k
    grad = np.zeros(n)
    if active_lags is not None:
        lags = np.array(active_lags)
    else:
        lags = np.arange(size)
    
    for i, k in enumerate(lags):
        if p[i] > 1e-10:
            grad += p[i] * grad_autocorr_at_k(a, int(k))
    
    obj = b_max + np.log(s) / beta
    return obj, grad, b

def fista_softmax(a0, time_limit, beta_start=50, beta_end=5000,
                   beta_growth=1.005, verbose=True, seed=42):
    """FISTA with softmax smoothing and temperature annealing."""
    n = len(a0)
    x = norm_sum1(a0)
    best_a = x.copy()
    best_m = fast_autocorr(x).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)
    
    beta = beta_start
    t_fist = 1.0
    x_prev = x.copy()
    eta = 0.8 / (fast_autocorr(x).max() * 2.0 + 1e-10)
    eta = min(eta, 1.0)
    stall = 0
    active_lags = None
    
    for t in range(1, 50000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Nesterov momentum
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t_fist * t_fist)) / 2.0
        theta = (t_fist - 1.0) / t_new
        y = x + theta * (x - x_prev)
        y = np.maximum(y, 1e-15)
        s_y = y.sum()
        if s_y < 1e-15:
            y = x.copy()
        else:
            y = y / s_y
        
        # Update active set: lags within 1/beta of the max
        b_y = fast_autocorr(y)
        b_max = b_y.max()
        threshold = b_max - 2.0 / beta
        active_lags = list(np.where(b_y > threshold)[0])
        if len(active_lags) > 200:
            active_lags = list(np.argsort(b_y)[::-1][:200])
        
        # Compute smoothed gradient
        obj, grad, _ = compute_smoothed_obj_and_grad(y, beta, active_lags)
        gnorm = np.linalg.norm(grad)
        
        if gnorm < 1e-15:
            x_new = simplex_project(y - 1e-10 * grad)
        else:
            # Backtracking
            eta_trial = eta
            for _ in range(8):
                z = y - eta_trial * grad
                x_new = simplex_project(z)
                b_new = fast_autocorr(x_new)
                max_new = b_new.max()
                if max_new <= b_max + eta_trial * gnorm * gnorm / 2.0 + 1e-15:
                    break
                eta_trial *= 0.5
            x_new = simplex_project(y - eta_trial * grad)
            eta = eta_trial
        
        max_new = fast_autocorr(x_new).max()
        if max_new < best_m - 1e-16:
            best_m = max_new
            best_a = x_new.copy()
            stall = 0
            eta = min(eta * 1.05, 2.0)
        else:
            stall += 1
        
        x_prev = x
        x = x_new
        t_fist = t_new
        
        # Anneal beta
        if t % 30 == 0:
            beta = min(beta * beta_growth, beta_end)
        
        # Restart if stalled
        if stall > 800:
            stall = 0
            t_fist = 1.0
            # Perturb
            noise = rng.normal(0, 0.01, n) * best_a
            x_r = best_a + noise
            x_r = np.maximum(x_r, 1e-10)
            x_r = x_r / x_r.sum()
            x = x_r
            x_prev = x_r.copy()
            beta = max(beta * 0.5, beta_start)
            eta = 0.8 / (fast_autocorr(x).max() * 2.0 + 1e-10)
        
        if verbose and t % 2000 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print("  FISTA t=" + str(t) + " (" + str(round(elapsed, 1)) + "s): J=" + repr(round(J, 6)) + " beta=" + str(int(beta)) + " |A|=" + str(len(active_lags)))
    
    return best_a, best_m

def subgradient_polytope(a0, time_limit, verbose=True, seed=99):
    """
    Subgradient method with active set tracking.
    Directly minimizes max_k b[k] using exact subgradients.
    """
    n = len(a0)
    x = norm_sum1(a0)
    best_a = x.copy()
    best_m = fast_autocorr(x).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)
    
    eta = 1.0 / (best_m * 4.0 + 1e-10)
    eta = min(eta, 0.5)
    avg_grad = np.zeros(n)
    avg_window = 50
    stall = 0
    
    for t in range(1, 50000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        b = fast_autocorr(x)
        b_max = b.max()
        
        if b_max < best_m - 1e-16:
            best_m = b_max
            best_a = x.copy()
            stall = 0
        
        # Find active set: lags within eps of max
        eps = 1e-6
        active = np.where(b > b_max - eps)[0]
        if len(active) == 0:
            active = np.array([np.argmax(b)])
        if len(active) > 50:
            active = np.argsort(b)[::-1][:50]
        
        # Average subgradient
        grad = np.zeros(n)
        for k in active:
            grad += grad_autocorr_at_k(x, int(k))
        grad /= len(active)
        
        # Averaged gradient (Polyak averaging)
        avg_grad = (avg_grad * min(t, avg_window) + grad) / min(t + 1, avg_window + 1)
        
        # Step size: eta_t = c / sqrt(t)
        eta_t = 0.5 / np.sqrt(t + 1.0)
        eta_t = min(eta_t, 1.0)
        
        # Take step using averaged gradient for stability
        z = x - eta_t * grad
        x_new = simplex_project(z)
        
        # Also try with averaged gradient
        z_avg = x - 0.5 * eta_t * avg_grad
        x_avg = simplex_project(z_avg)
        
        # Pick the better
        m1 = fast_autocorr(x_new).max()
        m2 = fast_autocorr(x_avg).max()
        if m2 < m1:
            x_new = x_avg
        
        x = x_new
        stall += 1
        
        # Periodic restart with larger perturbation
        if stall > 2000:
            stall = 0
            noise = rng.normal(0, 0.02, n) * best_a
            x_r = best_a + noise
            x_r = np.maximum(x_r, 1e-10)
            x_r = x_r / x_r.sum()
            x = x_r
        
        if verbose and t % 2000 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print("  SG t=" + str(t) + " (" + str(round(elapsed, 1)) + "s): J=" + repr(round(J, 6)) + " |A|=" + str(len(active)))
    
    return best_a, best_m

def lp_fw_improved(a0, time_limit, solver, verbose=True):
    """Improved LP-Frank-Wolfe."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    
    y = a.copy()
    active_set = set(int(k) for k in np.argsort(fast_autocorr(y))[::-1][:300])
    no_improve = 0
    
    for t in range(1, 1000000):
        if time.monotonic() - t0 > time_limit:
            break
        if no_improve > 500:
            break
        
        ac = fast_autocorr(y)
        M_curr = ac.max()
        
        if M_curr < best_m - 1e-16:
            best_m = M_curr
            best_a = y.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        # Update active set
        threshold = M_curr - 1e-5
        viol = np.where(ac > threshold)[0]
        for k in viol[:50]:
            active_set.add(int(k))
        
        # Limit active set size
        if len(active_set) > 1500:
            ac_vals = np.array([ac[k] for k in active_set])
            keep = np.argsort(ac_vals)[::-1][:1500]
            active_set = set(int(list(active_set)[i]) for i in keep)
        
        constraint_list = sorted(active_set)
        K = len(constraint_list)
        if K == 0:
            break
        
        # Build constraint matrix
        coeffs = np.zeros((K, n))
        for jj, k in enumerate(constraint_list):
            k_int = int(k)
            i_start = max(0, k_int - n + 1)
            i_end = min(n, k_int + 1)
            if i_start < i_end:
                idx = np.arange(i_start, i_end)
                coeffs[jj, idx] = y[k_int - idx]
        
        g_var = cp.Variable(n, nonneg=True)
        M_var = cp.Variable()
        constraints = [cp.sum(g_var) == 1, coeffs @ g_var <= M_var]
        prob = cp.Problem(cp.Minimize(M_var), constraints)
        
        try:
            prob.solve(solver=solver, verbose=False)
        except Exception:
            if len(active_set) > 200:
                active_set = set(int(k) for k in np.argsort(ac)[::-1][:200])
            continue
        
        if prob.status not in ('optimal', 'optimal_inaccurate'):
            continue
        
        g_val = np.maximum(np.asarray(g_var.value, dtype=np.float64), 0.0)
        g_sum = g_val.sum()
        if g_sum < 1e-15:
            continue
        g_dir = g_val / g_sum
        
        # Add violated constraints
        size = 2 * n - 1
        fft_size = 1 << (size - 1).bit_length()
        Yf = np.fft.rfft(y, fft_size)
        Gf = np.fft.rfft(g_dir, fft_size)
        conv_ys = np.fft.irfft(Yf * Gf, fft_size)[:size]
        
        violations = np.where(conv_ys > M_curr + 1e-7)[0]
        for k in violations[:20]:
            active_set.add(int(k))
        
        # Line search
        best_alpha = 2.0 / (t + 2.0)
        best_M = M_curr
        for alpha in [best_alpha, 0.1, 0.05, 0.2, 0.3, 0.5]:
            trial = (1.0 - alpha) * y + alpha * g_dir
            trial = np.maximum(trial, 0.0)
            s_t = trial.sum()
            if s_t < 1e-15:
                continue
            trial = trial / s_t
            M_trial = fast_autocorr(trial).max()
            if M_trial < best_M:
                best_M = M_trial
                best_alpha = alpha
        
        y = (1.0 - best_alpha) * y + best_alpha * g_dir
        y = np.maximum(y, 0.0)
        s_y = y.sum()
        if s_y > 1e-15:
            y = y / s_y
        else:
            y = a.copy()
        
        if verbose and t % 100 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print("  LP-FW it=" + str(t) + " (" + str(round(elapsed, 1)) + "s): J=" + repr(round(J, 6)) + " |S|=" + str(len(active_set)))
    
    return best_a, best_m

def generate_inits(n, seed=0):
    """Generate diverse initializations."""
    rng = np.random.default_rng(seed)
    inits = []
    x = np.linspace(0, 1, n)
    
    # 1. Sine^2
    inits.append(np.sin(np.pi * x) ** 2)
    # 2. Asymmetric bump (peak at 1/3)
    inits.append(np.exp(-10 * (x - 1.0/3.0) ** 2))
    # 3. Asymmetric bump (peak at 2/3)
    inits.append(np.exp(-10 * (x - 2.0/3.0) ** 2))
    # 4. Linear ramp
    inits.append(x)
    # 5. Inverse linear
    inits.append(1.0 - x)
    # 6. Product of sines
    inits.append(np.sin(np.pi * x) * np.sin(2 * np.pi * x) ** 2 + 0.1)
    # 7. Quadratic
    inits.append(1.0 - (2*x - 1)**2)
    # 8. Random (Dirichlet)
    inits.append(rng.dirichlet(np.ones(n) * 0.5))
    # 9. Two bumps
    inits.append(np.exp(-15*(x-0.25)**2) + np.exp(-15*(x-0.75)**2))
    
    return [norm_sum1(s) for s in inits]

def get_solver():
    for s in [cp.CLARABEL, cp.PDLP, cp.ECOS, cp.SCS]:
        try:

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)

def fast_autocorr(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(np.asarray(a, dtype=np.float64), fft_size)

def evaluate_safe(a):

def norm_sum1(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()

        return np.ones_like(a, dtype=np.float64) / len(a)

def simplex_project(z):
    n = len(z)
    if n == 1:
        return np.array([max(0.0, z[0])])
    u = np.sort(z)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    rho = np.nonzero(cond)[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(z - theta, 0.0)

def grad_autocorr_at_k(a, k):
    n = len(a)
    grad = np.zeros(n)
    if k < n:
        lo, hi = 0, k
    else:
        lo, hi = k - n + 1, n - 1
    if lo > hi:
        return grad
    idx = np.arange(lo, hi + 1)
    grad[idx] = 2.0 * a[k - idx]
    if k % 2 == 0:
        mid = k // 2
        if lo <= mid <= hi:
            grad[mid] -= a[mid]
    return grad

def compute_smoothed_grad(a, beta, active_lags=None, top_k=200):
    n = len(a)
    b = fast_autocorr(a)
    size = 2 * n - 1
    if active_lags is not None and len(active_lags) > 0:
        lags = np.array(sorted(set(active_lags).intersection(set(range(size)))))
        if len(lags) == 0:
            lags = np.argsort(b)[::-1][:top_k]
    else:
        lags = np.argsort(b)[::-1][:top_k]
    b_use = b[lags]
    b_max = b_use.max()
    shifted = beta * (b_use - b_max)
    shifted = np.clip(shifted, -500, 0)
    exp_vals = np.exp(shifted)
    s = exp_vals.sum()
    if s < 1e-300:
        p = np.ones(len(lags)) / len(lags)
    else:
        p = exp_vals / s
    grad = np.zeros(n)
    for i, k in enumerate(lags):
        if p[i] > 1e-8:
            grad += p[i] * grad_autocorr_at_k(a, int(k))
    obj = b_max + np.log(max(s, 1e-300)) / beta
    return obj, grad, b

def lp_fw_v3(a0, time_limit, solver, initial_K=300, max_K=2000, verbose=True):

    no_improve = 0

    for t in range(1, 1000000):
        if time.monotonic() - t0 > time_limit:
            break
        if no_improve > 400:
            break
        ac = fast_autocorr(y)
        M_curr = ac.max()
        if M_curr < best_m - 1e-15:
            best_m = M_curr
            best_a = y.copy()
            no_improve = 0
        else:
            no_improve += 1
        # Active set update with hysteresis
        thresh_add = M_curr - 1e-6
        thresh_rem = best_m - 1e-5
        for k in np.where(ac > thresh_add)[0][:30]:
            active_set.add(int(k))
        if len(active_set) > max_K // 2:
            to_remove = [k for k in active_set if ac[k] < thresh_rem]
            for k in to_remove:
                active_set.discard(k)
        if len(active_set) > max_K:
            ac_vals = np.array([ac[k] for k in active_set])
            keep = np.argsort(ac_vals)[::-1][:max_K]
            active_set = set(int(list(active_set)[i]) for i in keep)
        constraint_list = sorted(active_set)
        K = len(constraint_list)
        if K == 0:
            break
        coeffs = np.zeros((K, n))
        for jj, k in enumerate(constraint_list):
            k_int = int(k)
            i_start = max(0, k_int - n + 1)
            i_end = min(n, k_int + 1)
            if i_start < i_end:
                idx = np.arange(i_start, i_end)
                coeffs[jj, idx] = y[k_int - idx]
        g_var = cp.Variable(n, nonneg=True)
        M_var = cp.Variable()
        constraints = [cp.sum(g_var) == 1, coeffs @ g_var <= M_var]
        prob = cp.Problem(cp.Minimize(M_var), constraints)
        try:
            prob.solve(solver=solver, verbose=False)
        except Exception:
            if len(active_set) > initial_K // 2:
                active_set = set(int(k) for k in np.argsort(ac)[::-1][:initial_K // 2])
            continue
        if prob.status not in ('optimal', 'optimal_inaccurate'):
            continue
        g_val = np.maximum(np.asarray(g_var.value, dtype=np.float64), 0.0)
        g_sum = g_val.sum()
        if g_sum < 1e-15:
            continue
        g_dir = g_val / g_sum
        size = 2 * n - 1
        fft_size = 1 << (size - 1).bit_length()
        Yf = np.fft.rfft(y, fft_size)
        Gf = np.fft.rfft(g_dir, fft_size)
        conv_ys = np.fft.irfft(Yf * Gf, fft_size)[:size]
        violations = np.where(conv_ys > M_curr + 5e-7)[0]
        for k in violations[:15]:
            active_set.add(int(k))
        best_alpha = 2.0 / (t + 2.0)
        best_M = M_curr
        for alpha in [best_alpha, 0.05, 0.1, 0.2, 0.3]:
            alpha = min(alpha, 1.0)
            trial = (1.0 - alpha) * y + alpha * g_dir
            trial = np.maximum(trial, 0.0)
            s_t = trial.sum()
            if s_t < 1e-15:
                continue
            trial = trial / s_t
            M_trial = fast_autocorr(trial).max()
            if M_trial < best_M:
                best_M = M_trial
                best_alpha = alpha
        y = (1.0 - best_alpha) * y + best_alpha * g_dir
        y = np.maximum(y, 0.0)
        s_y = y.sum()
        if s_y > 1e-15:
            y = y / s_y
        else:
            y = a.copy()
        if verbose and t % 80 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print("    LP-FW it=" + str(t) + " (" + str(round(elapsed, 1)) + "s): J=" + repr(round(J, 6)) + " |S|=" + str(len(active_set)))
    return best_a, best_m

def generate_inits(n, seed=0):
    rng = np.random.default_rng(seed)
    x = np.linspace(0, 1, n)
    inits = []
    inits.append(np.sin(np.pi * x) ** 2)
    inits.append(np.exp(-8 * (x - 0.3) ** 2))
    inits.append(np.exp(-8 * (x - 0.7) ** 2))
    inits.append(1.0 - np.abs(2 * x - 1))
    inits.append(x)
    inits.append(1.0 - x)
    inits.append(np.exp(-8 * (x - 0.25) ** 2) + np.exp(-8 * (x - 0.75) ** 2))
    inits.append(np.sin(np.pi * x) * (0.5 + 0.5 * np.sin(2 * np.pi * x)))
    inits.append(rng.dirichlet(np.ones(n) * 0.5))
    return [norm_sum1(s) for s in inits]

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss
