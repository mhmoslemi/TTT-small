Hmm, this is getting complicated. Let me simplify.

For the self-convolution C = conv(a, a), we have:
C[k] = sum_i a[i] * a[k-i] (with valid indices)

The gradient dC[k]/da[j]:
- a[j] appears in C[k] when i=j (giving a[k-j]) and when k-i=j i.e. i=k-j (giving a[k-j])
- If j and k-j are different and both valid: dC[k]/da[j] = 2*a[k-j]
- If j = k-j (j = k/2): dC[k]/da[j] = a[j] (only one term)
- If only one of j or k-j is in valid range: dC[k]/da[j] = a[k-j]

But "valid" for C[k] means: 0 ≤ i < n and 0 ≤ k-i < n, i.e., max(0, k-n+1) ≤ i ≤ min(n-1, k).

For the Lp objective: f = (sum_k C[k]^p)^(1/p)
df/da[j] = (1/p) * (sum C^p)^(1/p-1) * sum_k p*C[k]^(p-1) * dC[k]/da[j]
          = (sum C^p)^(1/p-1) * sum_k C[k]^(p-1) * dC[k]/da[j]

Let me define wt[k] = C[k]^(p-1) / (sum C^p)^(1-1/p)

Then df/da[j] = sum_k wt[k] * dC[k]/da[j]

For the hard max (p=∞), wt is a delta at argmax.

For efficiency, I'll only include the top contributing k's.

Actually, let me think about this differently. The key issue with the previous approach (LP-Frank-Wolfe) is that the LP subproblem is expensive. What if I just use a simple iterative method?

**Iterative water-filling / power iteration approach:**
1. Start with a
2. Compute conv = a * a
3. Find the peak lag k*
4. Reduce a[j] for j that contribute most to C(k*)
5. Redistribute the mass to positions that contribute least to all peaks
6. Repeat

This is essentially what coordinate descent does, but done in a more structured way.

**Spectral flattening approach:**
The convolution C = IFFT(|FFT(a)|²). To minimize max(C), we want |FFT(a)|² to be as flat as possible (since a flat spectrum gives a delta in time domain, which has max = mean).

But we need a ≥ 0, so we can't freely set the spectrum. However, we can iteratively:
1. Compute A = FFT(a)
2. Modify |A| to be flatter: |A|_new = |A|^α for α < 1 (this flattens)
3. Recompute: a_new = IFFT(|A|_new * exp(i*phase(A)))
4. Project: a_new = max(a_new, 0), normalize
5. Repeat

This is like the Gerchberg-Saxton algorithm but for autocorrelation minimization.

Let me combine multiple approaches:
1. Spectral flattening for global optimization
2. Lp gradient descent for medium-scale
3. Coordinate descent for fine-tuning
4. Try multiple n values

Let me also think about what n values to try. The objective is 2n*max_conv. For larger n, the "density" of convolution values is higher, which might allow lower peaks. But the search space is also larger.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:

def fast_convolve(a):
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def spectral_flatten(a0, time_limit, alpha_start=0.95, alpha_end=0.7, verbose=True):
    """Iterative spectrum flattening to reduce autocorrelation peaks."""
    a = norm_sum1(a0)
    n = len(a)
    best_a = a.copy()
    best_obj = 2.0 * n * fast_convolve(a).max()
    t0 = time.monotonic()
    fft_size = 1 << (2 * n - 2).bit_length()
    
    it = 0
    while time.monotonic() - t0 < time_limit:
        it += 1
        frac = min(1.0, it / max(1, int(time_limit / 0.1)))
        alpha = alpha_start + (alpha_end - alpha_start) * frac
        
        # Compute FFT
        A = np.fft.rfft(a, fft_size)
        mag = np.abs(A)
        phase = np.angle(A)
        
        # Flatten magnitude
        mag_flat = mag ** alpha
        # Preserve DC component
        mag_flat[0] = mag[0]
        
        # Reconstruct
        A_new = mag_flat * np.exp(1j * phase)
        a_new = np.fft.irfft(A_new, fft_size)[:n]
        
        # Project to non-negative, normalize
        a_new = np.maximum(a_new, 0.0)
        s = a_new.sum()
        if s < 1e-15:
            a = best_a.copy()
            continue
        a_new /= s
        
        # Check improvement
        obj = 2.0 * n * fast_convolve(a_new).max()
        if obj < best_obj:
            best_obj = obj
            best_a = a_new.copy()
        
        # Always take the step (projection ensures feasibility)
        a = a_new
        
        if verbose and it % 200 == 0:
            print(f"    Spectral it={it} alpha={alpha:.3f} obj={best_obj:.6f} (t={time.monotonic()-t0:.1f}s)")
    
    return best_a, best_obj

def lp_mirror_descent(a0, time_limit, p_steps=None, verbose=True):

    a = norm_sum1(a0)
    n = len(a)
    best_a = a.copy()
    best_obj = 2.0 * n * fast_convolve(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(7)
    
    if p_steps is None:
        p_steps = [4, 8, 16, 32, 64, 128, 256, 512]
    
    total_budget = time_limit
    per_p = total_budget / len(p_steps)
    
    for p_i, p in enumerate(p_steps):
        p_time = min(per_p, time_limit - (time.monotonic() - t0))
        if p_time < 1:
            break
        t_phase = time.monotonic()
        
        iters_this_p = int(p_time / 0.05)  # estimate max iterations
        for it in range(max(10, iters_this_p)):
            if time.monotonic() - t_phase > p_time:
                break
            
            conv = fast_convolve(a)
            obj = 2.0 * n * conv.max()
            if obj < best_obj:
                best_obj = obj
                best_a = a.copy()
            
            # Compute Lp gradient
            # wt[k] ∝ conv[k]^(p-1)
            log_wt = (p - 1) * np.log(np.maximum(conv, 1e-30))
            log_wt -= log_wt.max()
            wt = np.exp(log_wt)
            wt_sum = wt.sum()
            if wt_sum > 0:
                wt /= wt_sum
            else:
                break
            
            # Gradient: grad[j] = sum_k wt[k] * dC[k]/da[j]
            grad = np.zeros(n)
            # Use top k's only for efficiency
            n_top = min(300, 2 * n - 1)
            top_k = np.argsort(wt)[::-1][:n_top]
            
            for k_int in top_k:
                k_int = int(k_int)
                w = wt[k_int]
                if w < 1e-14:
                    break
                i_lo = max(0, k_int - n + 1)
                i_hi = min(n - 1, k_int)
                if i_lo > i_hi:
                    continue
                idx = np.arange(i_lo, i_hi + 1)
                vals = a[k_int - idx]
                grad[idx] += w * vals
                idx2 = k_int - idx
                valid = (idx2 >= 0) & (idx2 < n)
                if np.any(valid):
                    # Avoid double counting when idx == idx2 (i.e., 2*idx == k_int)
                    # For self-conv, dC[k]/da[j] = a[k-j] + a[j-k] (with bounds)
                    # But since conv is of a with itself, a[j-k] = a[k-j-k+... ]
                    # Actually let me just add it and accept the factor of 2
                    np.add.at(grad, idx2[valid], w * vals[valid])
            
            # Multiplicative weights update
            # eta adapts with iteration
            eta = 2.0 / (np.sqrt(it + 1) + 1.0) * (1.0 / max(1, p / 64.0))
            a_new = a * np.exp(-eta * grad / max(grad.max(), 1e-15))
            a_new = np.maximum(a_new, 1e-30)
            s = a_new.sum()
            if s > 1e-15:
                a_new /= s
                a = a_new
            else:
                a = best_a.copy()
            
            # Occasional random perturbation
            if it % 200 == 100:
                noise = rng.normal(0, 0.01, n)
                a = a + noise * a
                a = np.maximum(a, 1e-30)
                s = a.sum()
                if s > 1e-15:
                    a /= s
        
        if verbose:
            print(f"    LP p={p}: obj={best_obj:.6f} (t={time.monotonic()-t0:.1f}s)")

def subgradient_descent(a0, time_limit, verbose=True):
    """Hard-max subgradient with adaptive step and random exploration."""
    a = norm_sum1(a0)
    n = len(a)
    best_a = a.copy()
    best_obj = 2.0 * n * fast_convolve(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(99)
    
    eta = 0.05
    stall = 0
    momentum = 0.5
    vel = np.zeros(n)
    
    for it in range(100000):
        if time.monotonic() - t0 > time_limit:
            break
        if stall > 5000:
            break
        
        conv = fast_convolve(a)
        obj = 2.0 * n * conv.max()
        if obj < best_obj - 1e-12:
            best_obj = obj
            best_a = a.copy()
            stall = 0
        else:
            stall += 1
        
        # Subgradient at the peak
        k_star = int(np.argmax(conv))
        grad = np.zeros(n)
        i_lo = max(0, k_star - n + 1)
        i_hi = min(n - 1, k_star)
        idx = np.arange(i_lo, i_hi + 1)
        vals = a[k_star - idx]
        grad[idx] = vals  # first factor
        idx2 = k_star - idx
        valid = (idx2 >= 0) & (idx2 < n)
        # Second factor (avoid double count at center)
        for j in range(len(idx)):
            j_abs = idx[j]
            j2 = k_star - j_abs
            if 0 <= j2 < n:
                if j2 != j_abs:
                    grad[j2] += vals[j]
                else:
                    # Already counted
                    pass
        
        # Normalize gradient
        gmax = grad.max()
        if gmax > 1e-15:
            grad /= gmax
        
        # Add small random perturbation
        grad += 0.01 * rng.standard_normal(n) * a
        
        # Update with momentum
        vel = momentum * vel - eta * grad
        a_new = a + vel
        a_new = np.maximum(a_new, 1e-30)
        s = a_new.sum()
        if s > 1e-15:
            a_new /= s
            a = a_new
        else:
            a = best_a.copy()
        
        # Adaptive eta
        eta = 0.05 / (1.0 + it / 500.0)
        
        # Restart with perturbation if stuck
        if stall > 1000 and stall % 500 == 0:
            a = best_a + 0.05 * rng.standard_normal(n)
            a = np.maximum(a, 1e-10)
            s = a.sum()
            if s > 1e-15:
                a /= s
            vel = np.zeros(n)
    
    return best_a, best_obj

def coordinate_polish(a0, time_limit, verbose=True):
    """Fine-grained coordinate descent: transfer mass from peak contributors to off-peak positions."""
    a = norm_sum1(a0)
    n = len(a)
    best_a = a.copy()
    best_obj = 2.0 * n * fast_convolve(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(123)
    stall = 0
    
    while time.monotonic() - t0 < time_limit and stall < 3000:
        conv = fast_convolve(a)
        obj = 2.0 * n * conv.max()
        if obj < best_obj:
            best_obj = obj
            best_a = a.copy()
        
        # Find top peak lag
        k_star = int(np.argmax(conv))
        
        # Find the position that contributes most to this peak
        i_lo = max(0, k_star - n + 1)
        i_hi = min(n - 1, k_star)
        idx = np.arange(i_lo, i_hi + 1)
        contrib = a[idx] * a[k_star - idx]
        
        if contrib.max() < 1e-20:
            stall += 1
            continue
        
        src = int(idx[np.argmax(contrib)])
        
        # Find destination: position that minimizes contribution to all top peaks
        n_top_peaks = min(20, 2 * n - 1)
        top_peaks = np.argsort(conv)[::-1][:n_top_peaks]
        
        scores = np.zeros(n)
        for k_p in top_peaks:
            k_p = int(k_p)
            lo = max(0, k_p - n + 1)
            hi = min(n - 1, k_p)
            for j in range(lo, hi + 1):
                scores[j] += a[k_p - j]
        
        # Prefer positions with low score
        candidates = np.where(scores < scores.mean())[0]
        if len(candidates) < 10:
            candidates = np.arange(n)
        
        dst = int(candidates[np.argmin(scores[candidates])])
        if dst == src:
            dst = int(rng.integers(n))
            if dst == src:
                dst = (dst + 1) % n
        
        # Try a few fractions
        found = False
        for frac in [0.01, 0.02, 0.05, 0.1, 0.2]:
            amt = a[src] * frac
            if amt < 1e-15:
                continue
            a_trial = a.copy()
            a_trial[src] -= amt
            a_trial[dst] += amt
            a_trial = np.maximum(a_trial, 0.0)
            s = a_trial.sum()
            if s < 1e-15:
                continue
            a_trial /= s
            obj_trial = 2.0 * n * fast_convolve(a_trial).max()
            if obj_trial < obj - 1e-14:
                a = a_trial
                best_obj = obj_trial
                best_a = a.copy()
                stall = 0
                found = True
                break
        
        if not found:
            # Try random transfer
            j = int(rng.integers(n))
            if j != src:
                amt = a[src] * rng.uniform(0.005, 0.05)
                a[src] -= amt
                a[j] += amt
                a = np.maximum(a, 0.0)
                s = a.sum()
                if s > 1e-15:
                    a /= s
                    obj_new = 2.0 * n * fast_convolve(a).max()
                    if obj_new < best_obj:
                        best_obj = obj_new
                        best_a = a.copy()
                        stall = 0
            stall += 1
        
        if verbose and stall % 500 == 0:
            print(f"    Coord obj={best_obj:.6f} stall={stall} (t={time.monotonic()-t0:.1f}s)")
    
    return best_a, best_obj

def interpolate_seq(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss
