For the spectral equalization:

```
def spectral_equalization(a, n_iter=100, gamma=2.0):
    n = len(a)
    N = 1 << (2*n-1).bit_length()
    a = a.copy()
    for it in range(n_iter):
        A = np.fft.rfft(a, N)
        P = np.abs(A)**2
        # Flatten: raise to power < 1
        P_flat = P ** (1.0/gamma)
        # Get new a
        a_new = np.fft.irfft(P_flat * np.exp(1j * np.angle(A)), N)[:n]
        a_new = np.maximum(a_new, 0)
        s = a_new.sum()
        if s < 1e-15:
            break
        a = a_new / s
    return a
```

Wait, there's an issue. `np.angle(A)` for a real FFT gives angles in [-pi, pi]. And `P_flat * exp(1j*angle(A))` should give a valid spectrum. But the resulting `a_new` might have significant negative parts, and after clipping, the spectral shape is destroyed.

A better approach might be to use a "soft" version:
```
a_new = a + alpha * (a_trial - a)
```
where `a_trial = IFFT(|A|^gamma * exp(1j*angle(A)))[:n]` and alpha is a small step size.

Or even better: use the gradient of the "flatness" objective w.r.t. the power spectrum, and backpropagate to a.

Actually, let me think about this more carefully. The objective is `max_k c[k]` where `c = IFFT(|FFT(a)|^2)`. 

In the frequency domain, `C = |A|^2` and `c = IFFT(C)`. We want to minimize `max(c)`.

The gradient of `max(c)` w.r.t. `C` is a delta at the argmax position (in the time domain). So:
`d max(c) / d C[m] = IFFT(delta_{argmax})[m] = exp(2*pi*i*argmax*m/N) / N`

And `d C[m] / d a[j]` is more complex (it's `i * (2*A[m] * conj(d A[m] / d a[j]))` type thing).

This is getting too complicated analytically. Let me just use the time-domain gradient that I already have.

Let me focus on what might actually improve the score:

1. **The previous code already has good infrastructure**. The main improvements should be:
   - Better hyperparameters for Nesterov
   - A different local search strategy
   - Trying different lengths more aggressively
   - A spectral preprocessing step

2. **Key observation from the previous code**: The Nesterov method with top_k smoothing is the main workhorse. The peak surgery and pairwise CD are for final polish. The bottleneck is probably getting stuck in local optima.

3. **New idea**: Instead of just shifting mass from one position to another (as in peak surgery), try a "spread" operation: take mass from a hot position and spread it evenly across many cold positions. This is more likely to reduce the peak without creating new ones.

4. **Another new idea**: "Annealed restarts" - when stuck, don't just add random noise. Instead, interpolate between the current best and a random feasible point (like uniform), then re-optimize.

Let me now write the final code. I'll keep the overall structure similar to the previous code (since it's well-designed) but make targeted improvements:

1. Add a spectral equalization pre-processing step
2. Improve the Nesterov method with:
   - Adaptive top_k (increase as we get closer to convergence)
   - Better step size schedule
   - Periodic "spectral nudges" (small spectral equalization steps)
3. Improve peak surgery with "spread" moves
4. Add a "random restart + quick Nesterov" phase
5. More aggressive multi-length exploration

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Spectral equalization preprocessing (flatten power spectrum)
2. Nesterov accelerated projected gradient on log-sum-exp smoothed objective
3. Spread-based peak surgery (redistribute mass to multiple cold positions)
4. Adaptive top-k smoothing and periodic spectral nudges
5. Multi-length exploration with diverse initializations
6. Annealed random restarts for escaping local optima
7. Fine-grained pairwise coordinate descent for final polish
"""

import numpy as np
import time

def fast_autocorr(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(np.asarray(a, dtype=np.float64), fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def evaluate_safe(a):
    try:
        a_list = [float(x) for x in np.asarray(a, dtype=np.float64)]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')

def norm_sum1(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s

def simplex_project(z):
    n = len(z)
    if n == 0:
        return z
    u = np.sort(z)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    rho = np.nonzero(cond)[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(z - theta, 0.0)

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss

def spectral_equalize(a, n_iter=50, gamma=1.5, step=0.5):
    """Flatten the power spectrum to reduce autocorrelation peaks."""
    n = len(a)
    a = np.asarray(a, dtype=np.float64).copy()
    N = 1 << (2 * n - 1).bit_length()
    for it in range(n_iter):
        A = np.fft.rfft(a, N)
        P = np.abs(A) ** 2
        # Compress dynamic range
        P_flat = P ** (1.0 / gamma)
        # Reconstruct with original phase
        phase = np.angle(A)
        A_new = P_flat * np.exp(1j * phase)
        a_trial = np.fft.irfft(A_new, N)[:n]
        # Soft update: blend with original to maintain non-negativity
        a_trial = np.maximum(a_trial, 0.0)
        s = a_trial.sum()
        if s < 1e-15:
            break
        a_trial = a_trial / s
        # Blend to avoid discontinuities
        a = (1 - step) * a + step * a_trial
        a = np.maximum(a, 1e-15)
        a = a / a.sum()
    return a

def compute_smoothed_grad(y, beta, top_k=None):
    n = len(y)
    c = fast_autocorr(y)
    if top_k is not None and top_k < len(c):
        idx = np.argsort(c)[::-1][:top_k]
        c_use = np.zeros(len(c))
        c_use[idx] = c[idx]
        c_max = c[idx].max()
    else:
        c_use = c
        c_max = c.max()
    shifted = beta * (c_use - c_max)
    shifted = np.clip(shifted, -300, 300)
    exp_vals = np.exp(shifted)
    total = exp_vals.sum()
    if total < 1e-300:
        p = np.zeros_like(c_use)
        p[np.argmax(c)] = 1.0
    else:
        p = exp_vals / total
    fft_size = 1 << (2 * n - 1).bit_length()
    A = np.fft.rfft(y, fft_size)
    P = np.fft.rfft(p, fft_size)
    a_rev = y[::-1]
    Conv = np.fft.irfft(P * np.fft.rfft(a_rev, fft_size), fft_size)
    grad = (2.0 / beta) * Conv[n - 1:2 * n - 1]
    return grad, p, c

def nesterov_opt(a0, time_limit, beta_start=30.0, beta_end=2000.0,
                 beta_growth=1.006, eta_base=0.6, top_k_ratio=0.02,
                 restart_every=2000, verbose=True, seed=42,
                 spectral_nudge_every=5000, spectral_gamma=2.0):
    n = len(a0)
    x = norm_sum1(a0)
    x_prev = x.copy()
    best_a = x.copy()
    best_max_b = fast_autocorr(x).max()
    t0 = time.monotonic()
    beta = beta_start
    t_nest = 1.0
    stall = 0
    rng = np.random.default_rng(seed)
    top_k = max(10, int(n * top_k_ratio))

    for t in range(1, 10000000):
        if time.monotonic() - t0 > time_limit:
            break

        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t_nest * t_nest)) / 2.0
        theta = (t_nest - 1.0) / t_new
        y = x + theta * (x - x_prev)
        y = np.maximum(y, 1e-15)
        s_y = y.sum()
        if s_y < 1e-15:
            y = x.copy()
        else:
            y = y / s_y

        # Adaptively increase top_k over time (focus more on the max)
        progress = min(1.0, t / 20000.0)
        top_k_current = max(5, int(n * top_k_ratio * (1.0 - 0.5 * progress)))

        grad, p, c = compute_smoothed_grad(y, beta, top_k_current)

        eta = eta_base / max(1.0, beta * p.max() * 2.0)
        eta = min(eta, 0.1)

        z = y - eta * grad
        x_new = simplex_project(z)

        # Periodic spectral nudge
        if t > 0 and t % spectral_nudge_every == 0:
            x_new = spectral_equalize(x_new, n_iter=5, gamma=spectral_gamma, step=0.3)

        b_new = fast_autocorr(x_new)
        max_new = b_new.max()
        if max_new < best_max_b - 1e-15:
            best_max_b = max_new
            best_a = x_new.copy()
            stall = 0
        else:
            stall += 1

        x_prev = x
        x = x_new
        t_nest = t_new

        if t % 50 == 0:
            beta = min(beta * beta_growth, beta_end)

        if stall > restart_every:
            stall = 0
            t_nest = 1.0
            noise_scale = 0.03 / (1.0 + 0.05 * (t // restart_every))
            anti = (np.arange(n) - (n - 1) / 2.0) / n
            anti -= anti.mean()
            rand = rng.normal(0, 1, n)
            pert = noise_scale * (0.5 * anti + 0.5 * rand) * best_a
            x_r = best_a + pert
            x_r = np.maximum(x_r, 1e-10)
            x_r = x_r / x_r.sum()
            x = x_r
            x_prev = x_r.copy()
            beta = max(beta * 0.6, 10.0)
            if verbose:
                elapsed = time.monotonic() - t0
                J = 2.0 * n * best_max_b
                print("    Nest restart t=" + str(t) + " (" + str(round(elapsed, 1)) + "s): J=" + repr(round(J, 6)))

        if verbose and t % 5000 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_max_b
            print("    Nest t=" + str(t) + " (" + str(round(elapsed, 1)) + "s): J=" + repr(round(J, 6)) + ", beta=" + str(round(beta, 1)))

    return best_a, best_max_b

def spread_peak_surgery(a0, time_limit, verbose=True, seed=77):
    """Peak surgery with spread moves: redistribute mass to multiple cold positions."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)
    no_improve = 0
    max_no_improve = 5000

    while time.monotonic() - t0 < time_limit and no_improve < max_no_improve:
        c = fast_autocorr(a)
        c_max = c.max()
        if c_max < best_m - 1e-15:
            best_m = c_max
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1

        n_top = min(20, len(c))
        top_idx = np.argsort(c)[::-1][:n_top]

        # Compute pressure map
        pressure = np.zeros(n)
        for k2 in top_idx[:10]:
            k2i = int(k2)
            s2 = max(0, k2i - n + 1)
            e2 = min(n - 1, k2i)
            if s2 <= e2:
                idx2 = np.arange(s2, e2 + 1)
                pressure[idx2] += a[k2i - idx2]
                pressure[k2i - idx2] += a[idx2]

        # Find cold positions (low pressure)
        cold_mask = pressure < np.percentile(pressure, 20)
        cold_positions = np.where(cold_mask)[0]
        if len(cold_positions) < 10:
            cold_positions = np.where(pressure == pressure.min())[0]

        improved = False

        for k in top_idx[:10]:
            if improved:
                break
            k_int = int(k)
            i_start = max(0, k_int - n + 1)
            i_end = min(n - 1, k_int)
            if i_start > i_end:
                continue

            idx = np.arange(i_start, i_end + 1)
            products = a[idx] * a[k_int - idx]
            if products.max() < 1e-20:
                continue

            # Top contributing pairs
            n_pairs = min(5, len(idx))
            top_pairs = np.argsort(products)[::-1][:n_pairs]

            for pi in top_pairs:
                if improved:
                    break
                src_i = int(idx[pi])
                partner = k_int - src_i
                if partner < 0 or partner >= n:
                    continue

                # Try reducing the larger of the pair
                if a[src_i] >= a[partner]:
                    reduce_i = src_i
                else:
                    reduce_i = partner
                if a[reduce_i] < 1e-14:
                    continue

                # Spread move: move mass to multiple cold positions
                n_spread = min(5, len(cold_positions))
                spread_dsts = cold_positions[rng.choice(len(cold_positions), size=n_spread, replace=False)]

                for dst in spread_dsts:
                    dst_int = int(dst)
                    if dst_int == reduce_i:
                        continue
                    for frac in [0.003, 0.005, 0.01, 0.02]:
                        amt = a[reduce_i] * frac
                        if amt < 1e-15:
                            continue
                        a_trial = a.copy()
                        a_trial[reduce_i] -= amt
                        a_trial[dst_int] += amt
                        a_trial = np.maximum(a_trial, 0.0)
                        s_t = a_trial.sum()
                        if s_t < 1e-15:
                            continue
                        a_trial = a_trial / s_t
                        M_trial = fast_autocorr(a_trial).max()
                        if M_trial < best_m - 1e-16:
                            a = a_trial
                            best_m = M_trial
                            best_a = a.copy()
                            improved = True
                            break
                    if improved:
                        break

        if not improved:
            if no_improve > 1000:
                # Random exploration
                for _ in range(20):
                    i = int(rng.integers(n))
                    j = int(rng.integers(n))
                    if i != j and a[i] > 1e-10:
                        frac = rng.uniform(0.001, 0.03)
                        amt = a[i] * frac
                        a[i] -= amt
                        a[j] += amt
                        a = np.maximum(a, 0.0)
                        s_t = a.sum()
                        if s_t > 1e-15:
                            a = a / s_t
                            M_new = fast_autocorr(a).max()
                            if M_new < best_m:
                                best_m = M_new
                                best_a = a.copy()
                                improved = True
                                no_improve = 0
                                break

        if verbose and no_improve % 2000 == 0 and no_improve > 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print("    SpreadPS (" + str(round(elapsed, 1)) + "s): J=" + repr(round(J, 6)) + " stall=" + str(no_improve))

    return best_a, best_m

def pairwise_cd(a0, time_limit, verbose=True, seed=123):
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)
    stall = 0

    while time.monotonic() - t0 < time_limit and stall < 800:
        c = fast_autocorr(a)
        threshold = np.percentile(c, 95)
        peak_positions = np.where(c > threshold)[0]
        if len(peak_positions) == 0:
            peak_positions = np.argsort(c)[::-1][:20]

        improved = False

        for k in peak_positions[:15]:
            if improved:
                break
            k_int = int(k)
            i_start = max(0, k_int - n + 1)
            i_end = min(n - 1, k_int)
            if i_start > i_end:
                continue
            idx = np.arange(i_start, i_end + 1)
            products = a[idx] * a[k_int - idx]
            top_pairs = np.argsort(products)[::-1][:3]
            for pi in top_pairs:
                if improved:
                    break
                src_i = int(idx[pi])
                partner = k_int - src_i
                if partner < 0 or partner >= n or partner == src_i:
                    continue
                if a[src_i] < 1e-14 and a[partner] < 1e-14:
                    continue
                larger_i = src_i if a[src_i] >= a[partner] else partner
                if a[larger_i] < 1e-14:
                    continue
                for frac in [0.001, 0.002, 0.005]:
                    if improved:
                        break
                    amt = a[larger_i] * frac
                    if amt < 1e-18:
                        continue
                    for _ in range(5):
                        dst = int(rng.integers(n))
                        if dst == larger_i:
                            continue
                        a_trial = a.copy()
                        a_trial[larger_i] -= amt
                        a_trial[dst] += amt
                        a_trial = np.maximum(a_trial, 0.0)
                        s_t = a_trial.sum()
                        if s_t < 1e-15:
                            continue
                        a_trial = a_trial / s_t
                        M_trial = fast_autocorr(a_trial).max()
                        if M_trial < best_m - 1e-17:
                            a = a_trial
                            best_m = M_trial
                            best_a = a.copy()
                            improved = True
                            stall = 0
                            break

        if not improved:
            stall += 1

        if verbose and stall % 500 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print("    PairCD (" + str(round(elapsed, 1)) + "s): J=" + repr(round(J, 6)) + " stall=" + str(stall))

    return best_a, best_m

def try_update(best_seq, best_score, a, label, t_global):
    if a is None:
        return best_seq, best_score
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 0.01:
        return best_seq, best_score
    a_norm = a / s
    sc = evaluate_safe(a_norm)
    if np.isfinite(sc) and sc < best_score:
        best_score = sc
        best_seq = a_norm.copy()
        elapsed = time.monotonic() - t_global
        print("  *** NEW BEST [" + label + "]: " + str(sc) + " (n=" + str(len(a_norm)) + ", t=" + str(round(elapsed, 1)) + "s)")
    return best_seq, best_score
