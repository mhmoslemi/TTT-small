The "flattest" autocorrelation for a non-negative function would be one that's constant on [0,2] (the support of the linear autocorrelation). This gives `(f*f)(x) = 1/2` for x in [0,2].

The Fourier transform of a constant on [0,2] is a sinc-like function. So we want `|F(f)|^2` to be proportional to a sinc-like function. This means `F(f)` should be proportional to the square root of a sinc, which is not a standard function.

In practice, the optimal discrete sequence will be a smooth bump with specific shape determined by the equalization condition.

**Key insight for improvement**: Instead of just doing LP-FW (which is a first-order method), we could use a second-order method (like Newton's method) on the active constraints. At the optimum, the active constraints should all be tight (equal to M), and we can solve the KKT conditions.

The KKT conditions for:
```
minimize max_k c[k] = M
subject to sum(a) = 1, a >= 0
```

At the optimum (assuming a > 0 for all i):
- `sum(a) = 1`
- `c[k] = M` for all k in the active set S (the set of k where c[k] = max)
- The gradient of `c[k]` w.r.t. `a[i]` is `a[k-i] + a[i-k]` (with appropriate bounds), and the KKT condition is that the sum of multipliers times gradients equals a constant (from the sum constraint).

This gives a system of equations that we can solve iteratively.

**Newton-type approach:**
1. Identify the active set S (indices where c[k] is close to max).
2. Solve the system: c[k] = M for k in S, sum(a) = 1.
3. This is a system of |S| + 1 equations in n + 1 unknowns (a[0],...,a[n-1], M).
4. If |S| = n-1, we have n equations in n+1 unknowns, so we need the non-negativity constraints to determine the solution.
5. Use Newton's method to solve this system.

This could be much faster than LP-FW since it's a second-order method.
