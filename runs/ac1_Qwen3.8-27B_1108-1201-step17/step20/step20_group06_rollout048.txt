**Strategy: Iterative Water-Filling with Exact Peak Identification**

The key idea: The maximum of the convolution is determined by a small number of "active" peaks. We can:

3. The optimal solution (for fixed active set) is found by solving a QP:

4. Update the active set based on violations

But solving the QP at each iteration is expensive. Instead, I can use:

**Projected Subgradient with Exact Subgradient:**
- At each step, compute conv(a,a)
- Find the set S of indices where conv = max (or close to max)
- The subgradient is the average of the gradients at those indices
- Take a step in the negative subgradient direction
- Project onto the simplex

If k-i ≠ i but 0≤k-i<n: the terms are a[i]*a[k-i] (p=i) and a[k-i]*a[i] (q=i), derivative = a[k-i] + a[k-i] = 2*a[k-i].

So: d(conv(k))/da[i] = 2*a[k-i] if 0≤k-i<n, else 0.

This is simple! The gradient at peak index k is the vector g_i = 2*a[k-i] (for valid i).

For the max of multiple peaks, the subgradient is a convex combination of these gradients.

    5. Project: a_new = simplex_project(a_new)
    6. Update momentum (Nesterov)
    7. Check improvement

def simplex_project(z):
    n = len(z)
    u = np.sort(z)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    rho = np.nonzero(cond)[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(z - theta, 0.0)

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss

def try_update(best_seq, best_score, a, label, t_global):
    if a is None:
        return best_seq, best_score
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 0.01:
        return best_seq, best_score
    a_norm = a / s
    sc = evaluate_safe(a_norm)
    if np.isfinite(sc) and sc < best_score:
        best_score = sc
        best_seq = a_norm.copy()
        elapsed = time.monotonic() - t_global
        print(f"  *** NEW BEST [{label}]: {sc:.6f} (n={len(a)}, t={elapsed:.1f}s)")
    return best_seq, best_score
