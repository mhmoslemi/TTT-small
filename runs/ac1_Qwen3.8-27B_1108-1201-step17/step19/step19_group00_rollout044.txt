AH! I was confusing autocorrelation with convolution! 

The autocorrelation is: (a ⋆ a)(k) = sum_i a[i]*a[i+k] (for k >= 0)
The convolution is: (a * a)(k) = sum_i a[i]*a[k-i]

These are different! The convolution at lag k involves a[i] and a[k-i], while the autocorrelation at lag k involves a[i] and a[i+k].

Now I understand the problem better. We want to minimize the maximum of the full convolution, which for non-negative a can occur at various lags.

For the uniform sequence a[i] = c, the convolution is [c^2, 2c^2, 3c^2, ..., nc^2, ..., 2c^2, c^2], with max = n*c^2 at k=n-1.
J = 2*n*(n*c^2) / (n*c)^2 = 2*n^2*c^2 / (n^2*c^2) = 2.

So uniform gives J = 2, and we need to do better (get below 2).

To get below 2, we need the convolution to be more "flat" - i.e., avoid having a large peak. This means we want a sequence whose autocorrelation (in the convolution sense) is as flat as possible.

This is related to the theory of "Barker sequences" and "low autocorrelation sequences", but with the constraint that a >= 0.

For the convolution (not autocorrelation), the "peak" at k=n-1 is sum_i a[i]*a[n-1-i]. If a is symmetric (a[i] = a[n-1-i]), this becomes sum_i a[i]^2. If a is "anti-symmetric" in some sense (mass at opposite ends), this could be smaller.

Let me think about what gives J < 2.

J = 2*n*max_conv / (sum_a)^2

For J < 2: max_conv / (sum_a)^2 < 1/n, i.e., max_conv < (sum_a)^2 / n.

If sum_a = 1: max_conv < 1/n.

For uniform a[i] = 1/n: max_conv = n*(1/n)^2 = 1/n. So J = 2 exactly.

To get J < 2, we need max_conv < 1/n (with sum_a = 1).
