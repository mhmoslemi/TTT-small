   - Project gradient onto the tangent space of the simplex
   - Use backtracking line search
   - This should be more stable than the previous multiplicative updates
3. **Phase 2: Active set refinement**
   - Identify the top K autocorrelation lags
   - For each, compute the exact gradient
   - Use a weighted combination
4. **Phase 3: Coordinate descent with exact line search**
   - For each coordinate, find the optimal value given all others fixed
   - This is a 1D problem that can be solved exactly
5. **Phase 4: Length exploration**
   - Try a few nearby lengths
   - Interpolate and re-optimize
6. **Phase 5: Final polishing**
   - Very small steps, many iterations

For the coordinate descent step: if we fix all a[i] except a[j], then:
- `sum(a) = 1` means a[j] = 1 - sum_{i≠j} a[i] (but this over-constrains)
- Actually, in coordinate descent on the simplex, we fix a[j] and optimize, then renormalize.
- Or: we pick two coordinates i and j, and transfer mass between them: a[i] += δ, a[j] -= δ (keeping sum constant)
- Then optimize over δ.

For the "two-coordinate" update: the objective as a function of δ is:
`f(δ) = max_k (r_k + δ * ∂r_k/∂a_i - δ * ∂r_k/∂a_j)`

This is the max of linear functions of δ, so it's a piecewise-linear convex function. We can minimize it by finding the point where the "left" and "right" slopes cross.

Actually, `r_k` is quadratic in a, so as a function of δ (with only two coordinates changing), it's quadratic in δ. So `f(δ) = max_k (quadratic in δ)` is the max of quadratics, which is convex but not piecewise linear.

We can still do a line search over δ: try several values and pick the best.

Let me now write the code. I'll focus on making it efficient and effective.

Key improvements over the previous approach:
1. **Additive gradient descent with line search** instead of multiplicative updates (less prone to numerical issues)
2. **Better gradient computation** using the full gradient (not just top-K soft-max)
3. **Exact coordinate search** for pairs of coordinates
4. **Adaptive active set** that grows over time
5. **Multiple diverse restarts** with different perturbation strategies
6. **Smoother learning rate schedule**

Let me also consider the problem size. The parent has n=5200. The FFT for autocorrelation of size 5200 requires an FFT of size ~16384, which is very fast. So we can afford many iterations.

Let me estimate: each iteration of gradient descent requires:
- One FFT (O(n log n)) for autocorrelation
- Gradient computation (O(n * K) where K is the number of active lags)
- Line search (a few extra FFTs)

For n=5200, one FFT takes about 1ms. So we can do about 1000 iterations per second. In 1800 seconds, we can do about 1.8 million iterations. That's plenty.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Additive projected gradient descent with backtracking line search
2. Adaptive soft-max active set for subgradient computation
3. Pair coordinate descent with exact 1D minimization
4. Multi-restart strategy with diverse perturbations
5. Length exploration via interpolation
"""

import numpy as np
import time


def fast_autocorr(a):
    """Compute full autocorrelation via FFT. Returns array of length 2n-1."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size, fft_size)[:size]


def score_from_ac(a):
    """Compute score: 2*n*max(ac) for unit-sum sequence."""
    n = len(a)
    ac = fast_autocorr(a)
    return 2.0 * n * ac.max()


def compute_subgradient(a, ac, top_k, beta):
    """
    Compute subgradient of max_k ac[k] using soft-max weighting.
    ac[k] = sum_j a[j]*a[k-j]
    d(ac[k])/d(a[i]) = a[k-i] + a[i] (wait, let me be careful)
    
    Actually: ac[k] = sum_j a[j] * a[k-j] (summing over valid j)
    d(ac[k])/d(a[i]) = sum_j [d(a[j])/d(a[i]) * a[k-j] + a[j] * d(a[k-j])/d(a[i])]
    = a[k-i] + a[i]  (first term: j=i gives a[k-i]; second term: k-j=i gives j=k-i, so a[k-i])
    
    Wait, let me redo this. ac[k] = sum_{j: 0<=j<n, 0<=k-j<n} a[j] * a[k-j]
    
    d(ac[k])/d(a[i]) = sum_{j: valid} [δ_{j,i} * a[k-j] + a[j] * δ_{k-j,i}]
    = a[k-i] (if k-i is in [0,n-1]) + a[k-i] (if k-i is in [0,n-1])
    = 2 * a[k-i] (if 0 <= k-i < n)
    
    Wait no. Let me be more careful.
    
    ac[k] = sum_j a[j] * a[k-j]
    
    The terms are: for each j in the valid range, we have a[j] * a[k-j].
    
    d/d(a[i]) of a[j] * a[k-j] = δ(j,i) * a[k-j] + a[j] * δ(k-j, i)
    
    Summing over j:
    = a[k-i] (from the first part, when j=i, provided k-i is valid)
    + a[k-i] (from the second part, when k-j=i, i.e., j=k-i, provided k-i is valid)
    
    So d(ac[k])/d(a[i]) = 2 * a[k-i] if 0 <= k-i < n, else 0.
    
    Wait, that's only if i ≠ k-i (i.e., 2i ≠ k). If 2i = k, then the term a[i]*a[i] appears only once in the sum, so:
    d/d(a[i]) of a[i]*a[i] = 2*a[i]
    
    So in all cases: d(ac[k])/d(a[i]) = 2*a[k-i] if 0 <= k-i < n.
    
    This makes sense because ac[k] is a homogeneous quadratic, and by Euler's theorem for homogeneous functions, a·grad(ac[k]) = 2*ac[k].
    """
    n = len(a)
    k_alarm = min(top_k, len(ac))
    top_idx = np.argsort(ac)[::-1][:k_alarm]
    top_vals = ac[top_idx]
    
    # Soft-max weights
    max_v = top_vals.max()
    expo = beta * (top_vals - max_v)
    expo = np.clip(expo, -50, 50)
    weights = np.exp(expo)
    w_sum = weights.sum()
    if w_sum < 1e-30:
        weights = np.ones(k_alarm) / k_alarm
    else:
        weights = weights / w_sum
    
    # Compute subgradient
    grad = np.zeros(n)
    for w, k in zip(weights, top_idx):
        k_int = int(k)
        # d(ac[k])/d(a[i]) = 2*a[k-i] for valid i
        # Valid i: 0 <= i < n and 0 <= k-i < n
        # So i goes from max(0, k-n+1) to min(n-1, k)
        i_lo = max(0, k_int - n + 1)
        i_hi = min(n, k_int + 1)  # exclusive upper bound
        if i_lo >= i_hi:
            continue
        idx = np.arange(i_lo, i_hi)
        j_idx = k_int - idx  # k - i for each i
        # All j_idx are valid by construction
        grad[idx] += 2.0 * w * a[j_idx]
    
    return grad


def project_onto_simplex_tangent(grad, a):
    """
    Project gradient onto the tangent space of the simplex at point a.
    The tangent space is {v : sum(v) = 0 and v[i] >= 0 where a[i] = 0}.
    For now, we just enforce sum(v) = 0 and clip negative components where a=0.
    """
    n = len(a)
    v = grad.copy()
    # Zero out components where a is at the boundary
    mask = a > 1e-30
    v[~mask] = 0
    # Project onto sum=0
    v_sum = v.sum()
    v -= v_sum / mask.sum() if mask.sum() > 0 else 0
    return v


def projected_gradient_descent(a0, time_limit, lr_init=0.01, beta_init=3.0, 
                                 top_k_init=20, verbose=True, rng_seed=42):
    """
    Projected gradient descent on the simplex with backtracking line search.
    """
    n = len(a0)
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    ac = fast_autocorr(a)
    best_m = ac.max()
    best_score = 2.0 * n * best_m
    t0 = time.monotonic()
    rng = np.random.default_rng(rng_seed)
    
    lr = lr_init
    beta = beta_init
    top_k = top_k_init
    stall = 0
    stall_threshold = 5000
    
    for t in range(1, 500000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        ac = fast_autocorr(a)
        m_curr = ac.max()
        
        # Check improvement
        if m_curr < best_m - 1e-13:
            best_m = m_curr
            best_a = a.copy()
            best_score = 2.0 * n * best_m
            stall = 0
        else:
            stall += 1
        
        if stall > stall_threshold:
            # Restart
            pert = best_a * (1.0 + rng.normal(0, 0.02, n))
            pert = np.maximum(pert, 0.0)
            ps = pert.sum()
            if ps > 1e-15:
                a = pert / ps
            else:
                a = best_a.copy()
            stall = 0
            lr = max(lr * 0.7, 1e-6)
            beta = max(beta - 0.3, 1.0)
            if verbose:
                print(f"      PGD restart t={t} ({time.monotonic()-t0:.0f}s): score={best_score:.6f}")
            continue
        
        # Compute subgradient
        grad = compute_subgradient(a, ac, top_k, beta)
        
        # Project onto tangent space
        v = project_onto_simplex_tangent(grad, a)
        
        # Backtracking line search
        alpha = lr
        best_trial_m = m_curr
        best_trial_a = a.copy()
        
        for ls in range(20):
            a_trial = a - alpha * v
            a_trial = np.maximum(a_trial, 0.0)
            ts = a_trial.sum()
            if ts < 1e-15:
                alpha *= 0.5
                continue
            a_trial = a_trial / ts
            m_trial = fast_autocorr(a_trial).max()
            if m_trial < m_curr - 1e-14:
                best_trial_m = m_trial
                best_trial_a = a_trial.copy()
                break
            alpha *= 0.5
            if alpha < 1e-12:
                break
        
        if best_trial_m < m_curr:
            a = best_trial_a
        else:
            # No improvement; take a tiny random step
            a = a + rng.normal(0, 1e-6, n)
            a = np.maximum(a, 0.0)
            a = a / a.sum()
        
        # Adaptive parameters
        if t % 2000 == 0:
            top_k = min(top_k + 3, 100)
            lr *= 0.95
        
    if verbose:
        print(f"    PGD done ({time.monotonic()-t0:.0f}s): score={best_score:.6f}")
    return best_a, best_score


def pair_coord_descent(a0, time_limit, verbose=True, rng_seed=77):
    """
    Pair coordinate descent: for pairs (i,j), optimize the transfer δ.
    """
    n = len(a0)
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    ac = fast_autocorr(a)
    best_m = ac.max()
    best_score = 2.0 * n * best_m
    t0 = time.monotonic()
    rng = np.random.default_rng(rng_seed)
    stall = 0
    
    # Precompute which pairs to try
    # Focus on high-value positions (they contribute more to the autocorrelation peaks)
    sorted_idx = np.argsort(-a)  # descending
    
    while time.monotonic() - t0 < time_limit:
        ac = fast_autocorr(a)
        m_curr = ac.max()
        
        if m_curr < best_m - 1e-14:
            best_m = m_curr
            best_a = a.copy()
            best_score = 2.0 * n * best_m
            stall = 0
        else:
            stall += 1
            if stall > 20000:
                # Random perturbation
                a = best_a * (1.0 + rng.normal(0, 0.01, n))
                a = np.maximum(a, 0.0)
                a = a / a.sum()
                stall = 0
                continue
        
        # Get top lags
        n_top = min(20, 2 * n - 1)
        top_lags = np.argsort(ac)[::-1][:n_top]
        
        improved = False
        
        # Try pairs: source from high-value, dest from low-impact
        n_pairs_tried = 0
        max_pairs = 200
        
        for trial in range(max_pairs):
            if time.monotonic() - t0 > time_limit or n_pairs_tried > max_pairs:
                break
            
            # Choose source: prefer high-value positions that contribute to peaks
            if trial < 50:
                src = int(sorted_idx[int(rng.integers(min(100, n)))])
            else:
                src = int(rng.integers(n))
            
            if a[src] < 1e-12:
                continue
            
            # Compute impact score for destinations
            dst = int(rng.integers(n))
            if dst == src or a[dst] >= 0.9 * a[src]:
                continue
            
            # Try several transfer fractions
            n_pairs_tried += 1
            a_src = a[src]
            
            for frac in [0.01, 0.03, 0.05, 0.1, 0.2, 0.5]:
                amt = a_src * frac
                if amt < 1e-15:
                    continue
                a_trial = a.copy()
                a_trial[src] -= amt
                a_trial[dst] += amt
                if a_trial[src] < 0 or a_trial[dst] < 0:
                    continue
                m_trial = fast_autocorr(a_trial).max()
                if m_trial < best_m - 1e-15:
                    a = a_trial
                    best_m = m_trial
                    best_a = a.copy()
                    best_score = 2.0 * n * best_m
                    improved = True
                    break
        
        if not improved and stall > 0:
            pass  # Continue with random exploration
    
    if verbose:
        print(f"    Pair CD done ({time.monotonic()-t0:.0f}s): score={best_score:.6f}")
    return best_a, best_score

def interpolate_sequence(f, new_n):
    """Interpolate a normalized sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    x_old = np.linspace(0.0, 1.0, old_n)
    x_new = np.linspace(0.0, 1.0, new_n)
    f_int = np.interp(x_new, x_old, f_norm)
    f_int = np.maximum(f_int, 0.0)
    ss = f_int.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_int / ss


def norm_sum1(a):
    """Clip to non-negative and normalize to sum 1."""
    a = np.maximum(a.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s


def momentum_pgd(a0, time_limit, lr_init=0.05, beta_init=4.0,
                  top_k_init=30, momentum_init=0.9, verbose=True, rng_seed=42):
    """
    Momentum projected gradient descent with adaptive learning rate.
    Uses Nesterov acceleration and backtracking line search.
    """
    n = len(a0)
    a = norm_sum1(a0)
    v = np.zeros(n)  # momentum velocity
    
    best_a = a.copy()
    ac = fast_autocorr(a)
    best_m = ac.max()
    best_score = 2.0 * n * best_m
    t0 = time.monotonic()
    rng = np.random.default_rng(rng_seed)
    
    lr = lr_init
    beta = beta_init
    top_k = top_k_init
    momentum = momentum_init
    stall = 0
    stall_threshold = 8000
    
    for t in range(1, 500000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Nesterov lookahead
        a_nest = a + momentum * v
        a_nest = norm_sum1(a_nest)
        
        ac = fast_autocorr(a_nest)
        m_nest = ac.max()
        
        # Compute subgradient at Nesterov point
        grad = compute_subgradient(a_nest, ac, top_k, beta)
        
        # Project to tangent space
        mask = a_nest > 1e-30
        v_new = grad.copy()
        v_new[~mask] = 0
        n_active = mask.sum()
        if n_active > 1:
            v_new[mask] -= v_new[mask].mean()
        
        # Update momentum
        v = momentum * v + (1 - momentum) * v_new
        
        # Backtracking line search
        alpha = lr
        a_curr = a
        m_curr = fast_autocorr(a_curr).max()
        best_trial_m = m_curr
        best_trial_a = a_curr.copy()
        best_trial_v = v.copy()
        
        for ls in range(15):
            a_trial = a_curr - alpha * v
            a_trial = np.maximum(a_trial, 0.0)
            ts = a_trial.sum()
            if ts < 1e-15:
                alpha *= 0.5
                continue
            a_trial = a_trial / ts
            m_trial = fast_autocorr(a_trial).max()
            if m_trial < m_curr - 1e-14:
                best_trial_m = m_trial
                best_trial_a = a_trial.copy()
                best_trial_v = v.copy()
                break
            alpha *= 0.5
            if alpha < lr * 1e-6:
                break
        
        if best_trial_m < m_curr:
            a = best_trial_a
        else:
            # Stuck: random perturbation
            a = a + rng.normal(0, 1e-5, n)
            a = norm_sum1(a)
            v = np.zeros(n)
        
        # Check improvement
        if best_trial_m < best_m - 1e-13:
            best_m = best_trial_m
            best_a = a.copy()
            best_score = 2.0 * n * best_m
            stall = 0
        else:
            stall += 1
        
        if stall > stall_threshold:
            stall = 0
            # Diverse restart
            method = int(rng.integers(3))
            if method == 0:
                a = best_a * (1.0 + rng.normal(0, 0.03, n))
            elif method == 1:
                # Smooth perturbation
                noise = rng.normal(0, 1, n)
                # Low-pass filter the noise
                from scipy.ndimage import gaussian_filter1d
                noise = gaussian_filter1d(noise, sigma=10)
                a = best_a * (1.0 + 0.05 * noise / (np.abs(noise).max() + 1e-10))
            else:
                # Bump perturbation
                c = float(rng.uniform(0.2, 0.8))
                sig = float(rng.uniform(0.05, 0.2))
                x = np.linspace(0, 1, n)
                bump = np.exp(-((x - c)**2) / (2 * sig**2))
                a = norm_sum1(best_a + 0.1 * bump)
            a = norm_sum1(a)
            v = np.zeros(n)
            lr = max(lr * 0.8, 1e-5)
            beta = max(beta - 0.5, 1.5)
            if verbose:
                print(f"      Momentum PGD restart t={t} ({time.monotonic()-t0:.0f}s): score={best_score:.6f}")
        
        # Adaptive learning rate: decrease slowly
        if t % 5000 == 0:
            lr *= 0.98
            top_k = min(top_k + 2, 80)
    
    if verbose:
        print(f"    Momentum PGD done ({time.monotonic()-t0:.0f}s): score={best_score:.6f}")
    return best_a, best_score


def spectral_optimize(a0, time_limit, verbose=False):
    """
    Spectral domain optimization: flatten the power spectrum.
    In the frequency domain, the autocorrelation is |A(f)|^2 (for circular conv).
    We want to minimize the peak of the autocorrelation, which corresponds to
    making |A(f)|^2 as flat as possible.
    
    Strategy: iteratively reduce the magnitude at frequency bins where
    the corresponding time-domain autocorrelation peak is largest.
    """
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    ac = fast_autocorr(a)
    best_m = ac.max()
    best_score = 2.0 * n * best_m
    t0 = time.monotonic()
    rng = np.random.default_rng(123)
    
    fft_size = 1 << (2 * n - 2).bit_length()
    lr = 0.1
    stall = 0
    
    for t in range(1, 5000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        A = np.fft.rfft(a, fft_size)
        # The linear autocorrelation peak is related to the circular one
        # For large fft_size relative to n, they're similar
        P = np.abs(A)**2
        
        # We want to reduce the peak of the autocorrelation
        # The peak autocorrelation is related to the max of ifft(|A|^2 * something)
        # Actually, let's just use a heuristic: reduce the variance of P
        P_mean = P.mean()
        P_std = P.std() + 1e-30
        
        # Gradient in frequency domain: push toward flat spectrum
        # Reduce high-power bins, increase low-power bins
        P_dev = (P - P_mean) / P_std
        # Apply in log domain for magnitude
        mag = np.abs(A)
        phase = np.angle(A)
        
        # Scale magnitudes: reduce where P is high, increase where P is low
        scale = np.exp(-lr * P_dev / (1.0 + t * 0.001))
        scale = np.clip(scale, 0.5, 2.0)
        
        mag_new = mag * scale
        A_new = mag_new * np.exp(1j * phase)
        
        a_new = np.fft.irfft(A_new, fft_size)[:n]
        a_new = norm_sum1(a_new)
        
        m_new = fast_autocorr(a_new).max()
        if m_new < best_m - 1e-13:
            best_m = m_new
            best_a = a_new.copy()
            best_score = 2.0 * n * best_m
            a = a_new
            stall = 0
        else:
            stall += 1
            if stall > 2000:
                a = best_a * (1.0 + rng.normal(0, 0.02, n))
                a = norm_sum1(a)
                stall = 0
                lr *= 0.9
                if lr < 0.01:
                    break
    
    if verbose:
        print(f"    Spectral done ({time.monotonic()-t0:.0f}s): score={best_score:.6f}")
    return best_a, best_score


def soip_optimize(a0, time_limit, verbose=True, rng_seed=42):
    """
    SOIP (Sequential Overlap-Independent Perturbation) optimization.
    Key idea: instead of computing the full gradient at each step, 
    we identify the critical autocorrelation lags and directly compute
    the "pressure" they exert on each coordinate. Then we redistribute
    mass from high-pressure to low-pressure coordinates.
    
    This is more targeted than full gradient descent.
    """
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    ac = fast_autocorr(a)
    best_m = ac.max()
    best_score = 2.0 * n * best_m
    t0 = time.monotonic()
    rng = np.random.default_rng(rng_seed)
    
    stall = 0
    stall_threshold = 3000
    top_k = 20
    beta = 4.0
    lr = 0.02
    
    for t in range(1, 5000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        ac = fast_autocorr(a)
        m_curr = ac.max()
        
        if m_curr < best_m - 1e-13:
            best_m = m_curr
            best_a = a.copy()
            best_score = 2.0 * n * best_m
            stall = 0
        else:
            stall += 1
        
        if stall > stall_threshold:
            # Restart with perturbation
            a = best_a * (1.0 + rng.normal(0, 0.02, n))
            a = norm_sum1(a)
            stall = 0
            top_k = min(top_k + 5, 80)
            beta = max(beta - 0.3, 1.5)
            lr *= 0.85
            if verbose:
                print(f"      SOIP restart t={t} ({time.monotonic()-t0:.0f}s): score={best_score:.6f}")
            continue
        
        # Compute pressure at each position
        # Pressure[i] = sum_k w_k * a[k-i] (for active lags k)
        # This is essentially the subgradient without the factor of 2
        pressure = np.zeros(n)
        k_alarm = min(top_k, len(ac))
        top_idx = np.argsort(ac)[::-1][:k_alarm]
        top_vals = ac[top_idx]
        
        max_v = top_vals.max()
        expo = beta * (top_vals - max_v)
        expo = np.clip(expo, -50, 50)
        weights = np.exp(expo)
        w_sum = weights.sum()
        if w_sum < 1e-30:
            weights = np.ones(k_alarm) / k_alarm
        else:
            weights = weights / w_sum
        
        for w, k in zip(weights, top_idx):
            k_int = int(k)
            i_lo = max(0, k_int - n + 1)
            i_hi = min(n, k_int + 1)
            if i_lo >= i_hi:
                continue
            idx = np.arange(i_lo, i_hi)
            j_idx = k_int - idx
            pressure[idx] += w * a[j_idx]
        
        # Normalize pressure
        p_mean = pressure.mean()
        p_std = pressure.std() + 1e-30
        p_norm = (pressure - p_mean) / p_std
        
        # Move mass from high-pressure to low-pressure
        # Use a gentle, distributed update
        a_new = a * np.exp(-lr * p_norm)
        a_new = norm_sum1(a_new)
        
        # Check if this helped
        m_new = fast_autocorr(a_new).max()
        if m_new < m_curr - 1e-14:
            a = a_new
        else:
            # Try half step
            a_half = norm_sum1(a * np.exp(-0.5 * lr * p_norm))
            m_half = fast_autocorr(a_half).max()
            if m_half < m_curr - 1e-14:
                a = a_half
            else:
                # Tiny step or random
                a = a + rng.normal(0, 1e-6, n)
                a = norm_sum1(a)
        
        if t % 5000 == 0:
            lr *= 0.97
            top_k = min(top_k + 2, 100)
    
    if verbose:
        print(f"    SOIP done ({time.monotonic()-t0:.0f}s): score={best_score:.6f}")
    return best_a, best_score
