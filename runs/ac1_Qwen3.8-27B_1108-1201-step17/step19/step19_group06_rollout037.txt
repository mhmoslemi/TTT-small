```python
def fast_autocorr(a):
    """Compute full linear convolution a*a via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]
```

```python
    A_target = np.fft.rfft(target)
    target_mag = np.abs(A_target)
    
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    it = 0
    relaxation = 0.3
    
    while time.monotonic() - t0 < time_limit:
        A = np.fft.rfft(a, P)
        mag = np.abs(A)
        phase = np.angle(A)
        
        # Relax the magnitude toward target
        new_mag = (1-relaxation) * mag + relaxation * target_mag
        new_mag = np.maximum(new_mag, 1e-30)
        
        A_new = new_mag * np.exp(1j * phase)
        a_new = np.fft.irfft(A_new, P)[:n]
        a_new = norm_nonneg(a_new)
        
        m_new = fast_autocorr(a_new).max()
        if m_new < best_m:
            best_m = m_new
            best_a = a_new.copy()
        
        a = a_new
        it += 1
        
        # Adaptive relaxation
        if it % 100 == 0:
            relaxation = max(0.1, relaxation * 0.99)
    
    if verbose:
        print(f"  POCS: {it} iters, best_m={best_m:.8f}, score={2*n*best_m:.6f}")
    return best_a, best_m
```

Now, one issue with this approach: the phase is preserved from the current iterate, which might trap us in a local minimum. To avoid this, we can:
1. Add random phase perturbations occasionally
2. Use multiple restarts with different initial phases
3. Use a "hard" projection (set magnitude exactly to target) every few iterations

For a "bathtub" shape (low at edges, high in middle), the center peak is reduced but the "shoulders" of the convolution might increase. The optimal shape balances these effects.

Let me try to think about this more carefully with a continuous approximation.

In the continuous limit, let `f(t)` be a non-negative function on [0,1] with ∫f = 1. The "autocorrelation" is:
`R(τ) = ∫_0^{1-|τ|} f(t) f(t+|τ|) dt` for |τ| <= 1, and 0 for |τ| > 1.

We want to minimize `max_τ R(τ)`.

The constraint `∫_{-1}^1 R(τ) dτ = (∫_0^1 f(t)dt)^2 = 1` gives `max R >= 1/2`.

Can we achieve `R(τ) = 1/2`? At τ=0: `∫_0^1 f^2 = 1/2`. At τ→1: `∫_0^ε f(t)f(t+1-δ)dt → 0` for any fixed ε < 1. So R(τ) → 0 as τ → 1. This means R can't be constant 1/2 everywhere.

The minimum of max(R) is achieved when R(τ) decreases "gradually" from its peak. The optimal shape of R is determined by the constraint that R is the autocorrelation of a non-negative function.

This is a hard problem in general, but numerically we can approach it.
