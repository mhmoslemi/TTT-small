Let me think about the smooth gradient more carefully.

The objective (with sum(a)=1) is: J(a) = 2n * max_k c[a]_k

The soft approximation: J_β(a) = 2n * (1/β) * log(Σ_k exp(β * c[a]_k))
But this sum is over 2n-1 terms, which is expensive.

Better: use only the top K terms:
J_Kβ(a) = 2n * (1/β) * log(Σ_{k∈topK} exp(β * c[a]_k))

The gradient:
∂J_Kβ/∂a_i = (2n * 2 / β) * Σ_{k∈topK} w_k * (∂c_k/∂a_i)
= (4n/β) * Σ_{k∈topK} w_k * a[k-i] (for valid k-i)

where w_k = exp(β*c_k) / Σ_{j∈topK} exp(β*c_j)

This is computed as a weighted sum of shifted copies of a, which can be done efficiently.

Actually, for the top K peaks, we can compute the gradient directly:
grad_i = (4n/β) * Σ_{k∈topK} w_k * a[k-i] (where a[j]=0 for j∉[0,n-1])

This is like a weighted convolution of a with a "kernel" that has weights w_k at positions k.

For efficiency, if K is small (say 50-100), we can just loop over the top K peaks.

Let me also think about the update rule. On the simplex {a: a≥0, Σa=1}:
- Euclidean projection: a_new = Proj_simplex(a - η*grad)
- Mirror descent (entropy): a_new_i ∝ a_i * exp(-η*grad_i)

The mirror descent with entropy is better for the simplex because it handles the non-negativity constraint naturally (the exponential is always positive).

The update: a_new_i ∝ a_i * exp(-η * grad_i)

This is the "exponential weighting" update, which is equivalent to multiplicative weights.

a_{t+1,i} ∝ a_t,i * exp(-η * v_t,i)
a_{t+1} = a_{t+1} / Σa_{t+1}

def soft_peak_mirror_descend(a0, time_limit, beta0=3.0, beta_max=50.0, top_k0=20, 
                              top_k_max=100, lr0=0.5, momentum=0.8, verbose=True):
    """Adaptive soft-peak mirror descent with momentum."""
    n = len(a0)
    a = normalize(a0)
    best_a = a.copy()
    best_obj = objective(a)
    t0 = time.monotonic()
    rng = np.random.default_rng(123)
    
    beta = beta0
    top_k = top_k0
    lr = lr0
    mu = momentum
    
    v = np.zeros(n)  # momentum
    c = 0  # counter
    
    stall = 0
    max_stall = 3000
    
    while time.monotonic() - t0 < time_limit:
        # Adaptive parameters
        progress = min(1.0, c / 10000.0)
        beta = beta0 + (beta_max - beta0) * progress
        top_k = int(top_k0 + (top_k_max - top_k0) * progress)
        lr = lr0 / (1.0 + 0.01 * c)
        
        # Compute gradient
        c_prev = fast_conv(a)
        grad = soft_peak_grad(a, beta, top_k)
        
        # Momentum update
        v = mu * v + (1.0 - mu) * grad
        v_mean = v.mean()
        v_centered = v - v_mean  # Center the gradient to preserve sum
        
        # Mirror descent update (exponential weighting)
        log_a = np.log(np.maximum(a, 1e-30)) - lr * v_centered
        max_log = log_a.max()
        a_new = np.exp(log_a - max_log)
        a_new = a_new / a_new.sum()
        
        a = a_new
        c += 1
        
        # Evaluate
        if c % 10 == 0 or c < 5:
            obj = objective(a)
            if obj < best_obj - 1e-15:
                best_obj = obj
                best_a = a.copy()
                stall = 0
            else:
                stall += 10
        
        # Reheating
        if stall > max_stall:
            stall = 0
            # Fourier-based perturbation
            noise_freq = rng.integers(1, n//2)
            noise_phase = rng.uniform(0, 2*np.pi)
            pert = 0.05 * np.cos(2*np.pi*noise_freq*np.arange(n)/n + noise_phase)
            a = best_a + pert * best_a
            a = np.maximum(a, 1e-10)
            a = a / a.sum()
            v = np.zeros(n)
            # Reset progress
            beta = beta0
            top_k = top_k0
            lr = lr0
            if verbose and c % 10000 == 0:
                print("    SSD: reheat at iter " + str(c) + ", obj=" + repr(objective(best_a)))
    
    if verbose:
        print("  SSD done: obj=" + repr(objective(best_a)) + ", iters=" + str(c))
    
    return best_a, best_obj
