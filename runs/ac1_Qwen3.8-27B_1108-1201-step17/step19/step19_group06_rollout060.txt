For d = n-2: Q[i,j] = 1 if i+j = n-2. This is a sub-diagonal of J_n.
For d < n-1: Q_d has 1s on "sub-anti-diagonals."
For d > n-1: similar on the other side.

The eigenvalues of J_n (the exchange matrix) are 1 (with multiplicity ceil(n/2)) and -1 (with multiplicity floor(n/2)). So it's indefinite for n >= 2.

For the sub-anti-diagonal matrices, the eigenvalues are more complex.

```python
def solve_lp(a, M, max_time=5.0):
    """
    Solve: max sum(g) s.t. (a*g)[k] <= M for all k, g >= 0
    where (a*g) is the linear convolution of a and g.
    """
    n = len(a)
    # Build the Hankel matrix H where H[k, j] = a[k-j] if 0 <= k-j < n else 0
    # H has shape (2n-1, n)
    from scipy.sparse import lil_matrix, csc_matrix
    
    H = lil_matrix((2*n-1, n))
    for k in range(2*n-1):
        for j in range(n):
            idx = k - j
            if 0 <= idx < n:
                H[k, j] = a[idx]
    H = H.tocsc()
    
    # LP: max 1^T g s.t. H g <= M*1, g >= 0
    c = -np.ones(n)  # minimize -sum(g)
    A_ub = H
    b_ub = np.full(2*n-1, M)
    bounds = [(0, None)] * n
    
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    
    if res.success:
        return np.maximum(res.x, 0)
    return None
```

    cols_parts = []

        j_hi = min(n - 1, k)

            js = np.arange(j_lo, j_hi + 1, dtype=np.int32)
