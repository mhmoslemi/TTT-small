**Gradient-based approach on the "flatness" objective:**

The objective is `J = 2n * max(b) / S^2` where `b = conv(a,a)`.

The subgradient with respect to `a_i` at the peak location k* is:
`∂max(b)/∂a_i = 2 * a_{k*-i}` (with appropriate bounds on the index)

**Better approach: Direct optimization of the peak**

Fix the peak location k*. Then minimize `b_{k*}` subject to `S = 1` and `a_i >= 0`.

`b_{k*} = sum_i a_i * a_{k*-i}` (with valid indices).

This is a quadratic function of a. Minimizing a quadratic subject to linear constraints (sum = 1, a >= 0) is a QP!

But the peak location might not be fixed. We could:
1. Assume peak at center (k* = n-1).
2. Solve the QP.
3. Check if the peak is actually at the center.
4. If not, repeat with the new peak location.

For peak at center: `b_{n-1} = sum_{i=0}^{n-1} a_i * a_{n-1-i}`.

This is `a^T R a` where `R` is the "reverse" matrix (anti-identity).

We want to minimize `a^T R a` subject to `sum a = 1` and `a >= 0`.

By Cauchy-Schwarz, `a^T R a = sum a_i * a_{n-1-i} >= 0`. The minimum is 0, achieved when `a_i * a_{n-1-i} = 0` for all i.

But if the peak is at the center and `b_{n-1} = 0`, then we need to check other lags.

If `a_i * a_{n-1-i} = 0` for all i, then for each pair (i, n-1-i), at least one is 0. This means we can only fill either the first half or the second half (or one element of each pair).

The issue is that while the center lag is 0, other lags have large values.

def gradient_descent(a0, time_limit, temp_frac=0.05, lr0=1.0, verbose=False, rng_seed=42):
    """Smoothed gradient descent on the simplex to minimize max(conv(a,a))."""
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return a0, np.inf
    a = a / s
    
    best_a = a.copy()
    b = fast_conv(a)
    best_obj = b.max()  # We're minimizing max(conv) for normalized a
    t0 = time.monotonic()
    rng = np.random.default_rng(rng_seed)
    stall = 0
    
    for it in range(500000):
        if time.monotonic() - t0 > time_limit:
            break
        
        b = fast_conv(a)
        b_max = b.max()
        
        # Softmax weights
        temp = temp_frac * b_max
        if temp < 1e-15:
            temp = 1e-15
        w = np.exp((b - b_max) / temp)
        w_sum = w.sum()
        if w_sum < 1e-15:
            break
        w = w / w_sum
        
        # Gradient
        grad = compute_grad_fft(a, w)
        
        # Adaptive learning rate
        lr = lr0 / (1 + it * 0.01)
        
        # Try step
        a_new = a - lr * grad
        a_new = np.maximum(a_new, 0.0)
        s_new = a_new.sum()
        if s_new < 1e-15:
            a_new = a.copy()
            s_new = 1.0
        a_new = a_new / s_new
        
        obj_new = fast_conv(a_new).max()
        
        if obj_new < best_obj - 1e-15:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new
            stall = 0
        else:
            # Backtrack
            found = False
            for factor in [0.5, 0.25, 0.1, 0.05, 0.01]:
                a_try = a - lr * factor * grad
                a_try = np.maximum(a_try, 0.0)
                s_t = a_try.sum()
                if s_t < 1e-15:
                    continue
                a_try = a_try / s_t
                obj_t = fast_conv(a_try).max()
                if obj_t < best_obj - 1e-14:
                    best_obj = obj_t
                    best_a = a_try.copy()
                    a = a_try
                    stall = 0
                    found = True
                    break
            
            if not found:
                stall += 1
                if stall > 500:
                    # Restart with perturbation
                    pert = rng.normal(0, 0.01, n) * a
                    a = a + pert
                    a = np.maximum(a, 0.0)
                    a = a / a.sum()
                    stall = 0
        
        if verbose and it % 5000 == 0:
            print(f"    GD it={it} ({time.monotonic()-t0:.0f}s): max_conv={best_obj:.8f}, J={2*n*best_obj:.6f}")
