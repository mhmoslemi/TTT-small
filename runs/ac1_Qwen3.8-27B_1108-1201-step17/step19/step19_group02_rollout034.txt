Actually, I just realized something important. Let me re-examine the LP subproblem in the Frank-Wolfe method.

The objective is $f(a) = \max_k (a*a)_k$ (with $\sum a = 1, a \geq 0$).

The Frank-Wolfe method solves: $\min_{g \in \Delta} \nabla f(a)^T g$ (the linearized subproblem).

But $f(a) = \max_k (a*a)_k$ is not differentiable in general. The subgradient at $a$ is:
$\nabla f(a) = 2 \cdot P(a)$ where $P(a)_j = \sum_{k \in A} a_{k-j} \cdot \mathbf{1}[0 \leq k-j < n]$ and $A$ is the set of active lags (where $R(k) = \max R$).

If only one lag $k^*$ is active, then $\nabla f(a)_j = 2a_{k^*-j}$ (the reversed sequence).

The linearized subproblem is: $\min_g 2 \sum_j a_{k^*-j} g_j$ subject to $\sum g = 1, g \geq 0$.

This is minimized by putting all mass on the index $j$ that minimizes $a_{k^*-j}$, i.e., $j = k^* - \arg\max_i a_i$.

For the linear ramp with $k^* = n-1$: $a_{n-1-j}$ is minimized at $j = n-1$ (where $a_0$ is smallest). So $g = e_{n-1}$ (all mass at the last position).

The update would be $a \leftarrow (1-t)a + t \cdot e_{n-1}$, which makes the last element larger and all others smaller. This would INCREASE the peak (since $a_{n-1}^2 = R(2n-2)$ would grow).

So the naive Frank-Wolfe method with a single active lag would move AWAY from the ramp! This is because the subgradient is not a good approximation of the true "descent direction" when the max is achieved at a single point.

The issue is that $f(a) = \max_k R(k)$ is only locally linearized by the active set. If we use a larger active set (multiple lags near the peak), the LP subproblem becomes more meaningful and the descent direction is better.

This is exactly what the previous program does with its "active set" management: it keeps multiple lags in the constraint set and solves a more constrained LP.

So the approach should be:
1. Use LP-FW with a large active set (all lags where $R(k) > (1-\epsilon) M$).
2. This gives a better descent direction.
3. Use a small step size to avoid overshooting.
