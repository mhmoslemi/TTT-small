That's terrible! The issue is that for binary sequences, the sum is small relative to n, so the objective is bad.

The key tradeoff: 
- Uniform sequence: sum = n, max C = n, objective = 2.
- Binary sequence with k ones: sum = k, max C ≈ k, objective ≈ 2n*k/k^2 = 2n/k.

For the objective to be < 2, we need k > n, which is impossible for binary sequences.

So binary sequences can't beat 2. We need sequences with values spread between 0 and some maximum.
