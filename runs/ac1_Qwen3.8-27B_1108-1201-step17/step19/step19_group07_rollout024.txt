where g is the gradient of the objective with respect to the natural parameters. For the softmax, the natural parameter is theta, and the gradient of f(softmax(theta)) with respect to theta is:

d f / d theta_i = sum_j (d f / d a_j) * (d a_j / d theta_i)

                  = g_i * a_i - a_i * sum_j g_j * a_j
                  = a_i * (g_i - <g, a>)

        y_new = (1.0 - alpha) * y + alpha * g_dir
        y_new = np.maximum(y_new, 0.0)

            print(f"    LP-FW iter={iter_count} ({elapsed:.0f}s): J={J:.6f}, |S|={len(constraint_set)}")
    
    return best_a, best_m

    """Compute linear convolution of a and b using FFT."""
    n = len(a)

    size = n + m - 1

```python
def smoothed_subgradient(a, c, k_star, beta, top_k=50):
    """Compute a smoothed subgradient using top-k lags with exponential weight."""
    n = len(a)
    top_idx = np.argsort(c)[::-1][:top_k]
    weights = np.exp(beta * (c[top_idx] - c[top_idx[0]]))
    weights /= weights.sum()
    
    g = np.zeros(n)
    for w, k in zip(weights, top_idx):
        j = np.arange(n)
        idx = int(k) - j
        valid = (idx >= 0) & (idx < n)
        g[valid] += w * 2.0 * a[idx[valid]]
    return g
```
