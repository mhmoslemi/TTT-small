$J = 2 \cdot 2 \cdot 1/2 / (1)^2 = 2$.

If $a_0 = 1, a_1 = 0$: $c = (1, 0, 0)$, $\max = 1$.
$J = 2 \cdot 2 \cdot 1 / 1 = 4$.

Let me redo the analysis. For the uniform sequence, the peak is at lag $n-1$ with value $nc^2 = n(\sum a/n)^2 = (\sum a)^2/n$.

$J = 2n \cdot (\sum a)^2/n / (\sum a)^2 = 2$.

But we can do better by making the convolution more flat. The ideal is a constant convolution, which would give $J = 2n/(2n-1) \approx 1$.

So the question is: how flat can we make the linear convolution of a non-negative sequence with itself?

This is now a well-posed optimization problem! And the answer is NOT bounded below by 2.

Let me think about what sequences give flat convolutions. A sequence whose convolution with itself is constant is called a "perfect autocorrelation sequence" or is related to "complementary sequences" (Golay sequences).

For real non-negative sequences, this is more restrictive. Let me think...

If $a*a = c$ (constant) for all $k = 0, \ldots, 2n-2$, then taking the DFT:
$A(f)^2 = c \cdot (2n-1) \cdot \delta(f)$ (a delta at zero frequency)

This means $A(f) = 0$ for $f \neq 0$, so $a$ must be constant. But we showed constant gives a triangle, not a rectangle. Contradiction!

Wait, I think I'm confusing the DFT of the zero-padded sequence with the DFT of the periodic extension. Let me be more careful.

If we zero-pad $a$ to length $N \geq 2n-1$ and compute the circular convolution, it equals the linear convolution. The DFT of the circular convolution is the product of the DFTs.

So if $A(f) = \text{DFT}_N(a)$, then $\text{DFT}_N(a*a) = A(f)^2$.

For $a*a$ to be constant (equal to $c$ at every position), we need $A(f)^2 = c \cdot N \cdot \delta(f)$, i.e., $A(0) = \sqrt{cN}$ and $A(f) = 0$ for $f \neq 0$.

This means $a$ is constant (all elements equal to $\sqrt{cN}/N$). But then $a*a$ is a triangle, not a constant. The issue is that the "constant" constraint can only be satisfied if $N$ is large enough, but the DFT constraint forces $a$ to be constant, which doesn't give a constant convolution.

I think the resolution is that a constant linear convolution is impossible for a finite non-zero sequence. The best we can do is approximate it.
