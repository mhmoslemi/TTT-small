Wait, there's an issue. The subgradient of max(c) at a is NOT just the gradient of c[k*] at a. It's the gradient of the active constraint. For max of functions, the subdifferential is the convex hull of the gradients of the active functions.

So if the unique max is at k*, the subgradient IS grad c[k*]/grad a = 2*a shifted by k*.

But if there are multiple tied maxima, the subgradient is any convex combination.

In practice, for non-symmetric a, the max is usually unique (or nearly so), so using the single-peak gradient is fine.

The issue is: the subgradient points in the direction that INCREASES c[k*]. We want to DECREASE max(c), so we go in the -subgradient direction.

But -subgradient of max(c) is not the same as -gradient of c[k*]. The subgradient of max(c) at a is grad c[k*] (the gradient of the active function). The direction of steepest decrease of max(c) is -grad c[k*] (approximately, for the active constraint).

One more thought: the LP-FW in the previous code solved:

Wait, that's not right. The convolution (1-alpha)*y + alpha*g with itself is NOT linear in g. It's quadratic!

The previous code's LP is:
c[g][k] = sum_j g[j]*y[k-j] <= M

This is the "semi-convolution": g convolved with the FIXED y. This is linear in g. The FW principle says: if we're at y and move towards g, the new point is (1-alpha)*y + alpha*g. The change in c[k] to first order in alpha is:
alpha * (sum_j g[j]*y[k-j] + sum_j y[j]*g[k-j]) - alpha^2 * sum_j y[j]*y[k-j]

To first order: alpha * (c[g][k] + c[g_rev][k]) where c[g][k] = sum_j g[j]*y[k-j].

For the LP, the previous code uses: coeffs @ g <= M where row k of coeffs has coeffs[k,j] = y[k-j] (for valid j). This gives c[g][k] = sum_j g[j]*y[k-j].

But the actual change involves both c[g][k] AND c[g_rev][k] = sum_j g[k-j]*y[j] = sum_j g[j]*y[k-j] (by substitution). Wait, these are the same!

c[g][k] = sum_j g[j]*y[k-j]
c[y][g; k] = sum_j y[j]*g[k-j] = sum_j' g[j']*y[k-j'] (substituting j'=k-j) = c[g][k]

So they ARE the same! The first-order change in c[k] is 2*alpha*c[g][k] (minus the alpha^2 term).

So the LP constraint c[g][k] <= M/2 (to first order) is valid for controlling the change.

But the previous code uses c[g][k] <= M (not M/2). This is because the LP is finding a DIRECTION, not the exact step. The line search then handles the actual step size. So the constraint should be c[g][k] <= current M, meaning "the new c[k] at alpha=1 would be <= M". This is a valid FW constraint.

def fast_conv(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(np.asarray(a, dtype=np.float64), fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def eval_safe(a):
    try:
        a_list = [float(x) for x in np.asarray(a, dtype=np.float64)]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')

def norm1(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s

def simplex_proj(z):
    n = len(z)
    if n == 0:
        return z
    u = np.sort(z)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    rho = np.nonzero(cond)[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(z - theta, 0.0)

def interp_seq(a, new_n):
    old_n = len(a)
    if old_n == new_n:
        return a.copy()
    s = a.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    fn = a / s
    ox = np.linspace(0.0, 1.0, old_n)
    nx = np.linspace(0.0, 1.0, new_n)
    fi = np.interp(nx, ox, fn)
    fi = np.maximum(fi, 0.0)
    ss = fi.sum()
    if ss < 1e-15:
        fi = np.ones(new_n) / new_n
    else:
        fi = fi / ss
    return fi

def subgrad_nest(a0, time_limit, verbose=True, restart_every=1500):
    """Exact subgradient Nesterov: gradient of max-conv is 2*a shifted by peak lag."""
    n = len(a0)
    x = norm1(a0)
    x_prev = x.copy()
    best_a = x.copy()
    best_m = fast_conv(x).max()
    t0 = time.monotonic()
    t_nest = 1.0
    stall = 0
    rng = np.random.default_rng(42)

    for t in range(1, 100000000):
        if time.monotonic() - t0 > time_limit:
            break

        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t_nest * t_nest)) / 2.0
        theta = (t_nest - 1.0) / t_new
        y = x + theta * (x - x_prev)
        y = np.maximum(y, 1e-15)
        s_y = y.sum()
        if s_y < 1e-15:
            y = x.copy()
        else:
            y = y / s_y

        c = fast_conv(y)
        max_c = c.max()
        # Find peak (or top few for averaging)
        idx = int(np.argmax(c))
        # Check for near-ties
        thresh = max_c * 0.9999
        peaks = np.where(c >= thresh)[0]
        if len(peaks) > 5:
            peaks = np.argsort(c[peaks])[::-1][:5] + peaks[np.argsort(c[peaks])[::-1][:5]]
            peaks = peaks[:5]

        # Subgradient: average of 2*y[k-m] over active peaks
        g = np.zeros(n)
        for kp in peaks[:3]:
            kp = int(kp)
            lo = max(0, kp - n + 1)
            hi = min(n - 1, kp)
            if lo <= hi:
                idx_g = np.arange(lo, hi + 1)
                g[idx_g] += 2.0 * y[kp - idx_g]
        if len(peaks) > 1:
            g /= min(len(peaks), 3)

        # Adaptive step size
        g_sq = np.dot(g, g)
        if g_sq < 1e-20:
            eta = 1.0 / n
        else:
            eta = 1.0 / (np.sqrt(g_sq) * 0.5)
            eta = min(eta, 2.0 / (n * 0.02 * (1.0 + t * 0.0001)))
            eta = max(eta, 1e-8)

        z = y - eta * g
        x_new = simplex_proj(z)

        c_new = fast_conv(x_new)
        max_new = c_new.max()
        if max_new < best_m - 1e-16:
            best_m = max_new
            best_a = x_new.copy()
            stall = 0
        else:
            stall += 1

        x_prev = x
        x = x_new
        t_nest = t_new

        if stall > restart_every:
            stall = 0
            t_nest = 1.0
            noise = 0.015 / (1.0 + 0.05 * (t // restart_every))
            pert = rng.normal(0, noise, n) * best_a
            x_r = best_a + pert
            x_r = np.maximum(x_r, 1e-10)
            x_r = x_r / x_r.sum()
            x = x_r
            x_prev = x_r.copy()

        if verbose and t % 1000 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print("  SubGrad t=" + str(t) + " (" + str(round(elapsed, 1)) + "s): J=" + repr(J) + " peak_k=" + str(idx))

    return best_a, best_m

def lp_fw(v0, time_limit, solver, init_K=800, max_K=5000, verbose=True):
    """LP Frank-Wolfe with aggressive active set and full line search."""
    n = len(v0)
    y = norm1(v0)
    best_a = y.copy()
    best_m = fast_conv(y).max()
    t0 = time.monotonic()

    ac_y = fast_conv(y)
    active_set = set(int(k) for k in np.argsort(ac_y)[::-1][:init_K])
    no_improve = 0
    max_no_improve = 800

    for t in range(1, 5000000):
        if time.monotonic() - t0 > time_limit:
            break
        if no_improve > max_no_improve:
            if verbose:
                print("    LP-FW converged iter " + str(t))
            break

        ac = fast_conv(y)
        M_curr = ac.max()

        if M_curr < best_m - 1e-16:
            best_m = M_curr
            best_a = y.copy()
            no_improve = 0
        else:
            no_improve += 1

        # Update active set: top K by margin
        cs = sorted(active_set)
        if len(cs) > max_K:
            margins = np.array([M_curr - ac[k] for k in cs])
            keep = np.argsort(margins)[:max_K]
            active_set = set(int(cs[i]) for i in keep)
            cs = sorted(active_set)

        # Add new violators
        viol = np.where(ac > M_curr * 0.995)[0]
        for k in viol[:50]:
            active_set.add(int(k))
        cs = sorted(active_set)
        K = len(cs)
        if K == 0:
            break

        # Build constraint: row k is y[k-j] for valid j
        coeffs = np.zeros((K, n))
        for jj, k in enumerate(cs):
            ki = int(k)
            i_lo = max(0, ki - n + 1)
            i_hi = min(n, ki + 1)
            if i_lo < i_hi:
                idx = np.arange(i_lo, i_hi)
                coeffs[jj, idx] = y[ki - idx]

        g_var = cp.Variable(n, nonneg=True)
        M_var = cp.Variable()
        cons = [cp.sum(g_var) == 1, coeffs @ g_var <= M_var]
        prob = cp.Problem(cp.Minimize(M_var), cons)

        try:
            prob.solve(solver=solver, verbose=False)
        except Exception:
            if len(active_set) > init_K // 2:
                active_set = set(int(k) for k in np.argsort(ac)[::-1][:init_K // 2])
            continue

        if prob.status not in ('optimal', 'optimal_inaccurate'):
            continue

        g_val = np.maximum(np.asarray(g_var.value, dtype=np.float64), 0.0)
        gs = g_val.sum()
        if gs < 1e-15:
            continue
        g_dir = g_val / gs

        # Line search: try many alphas including 1.0
        alphas = [1.0, 0.9, 0.7, 2.0 / (t + 2.0), 1.0 / (t + 1), 0.3, 0.1]
        alphas = [max(0.01, min(1.0, a)) for a in alphas]
        alphas = list(set(alphas))

        best_alpha = 2.0 / (t + 2.0)
        best_trial_M = fast_conv((1 - best_alpha) * y + best_alpha * g_dir).max()

        for alpha in alphas:
            if alpha == best_alpha:
                continue
            trial = (1.0 - alpha) * y + alpha * g_dir
            trial = np.maximum(trial, 0.0)
            st = trial.sum()
            if st < 1e-15:
                continue
            trial = trial / st
            Mt = fast_conv(trial).max()
            if Mt < best_trial_M:
                best_trial_M = Mt
                best_alpha = alpha

        y_new = (1.0 - best_alpha) * y + best_alpha * g_dir
        y_new = np.maximum(y_new, 0.0)
        sy = y_new.sum()
        if sy < 1e-15:
            y_new = y.copy()
        else:
            y_new = y_new / sy
        y = y_new

        if verbose and t % 100 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print("    LP-FW iter=" + str(t) + " (" + str(round(elapsed, 1)) + "s): J=" + repr(J) + " |S|=" + str(len(active_set)))

    return best_a, best_m

def pair_swap(v0, time_limit, verbose=True):
    """Targeted pair-move: reduce peak by moving mass from peak contributors to safe spots."""
    n = len(v0)
    a = norm1(v0)
    best_a = a.copy()
    best_m = fast_conv(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(77)
    stall = 0
    max_stall = 500

    while time.monotonic() - t0 < time_limit and stall < max_stall:
        c = fast_conv(a)
        max_c = c.max()
        k_star = int(np.argmax(c))

        # Find top contributing pair for c[k_star]
        j_lo = max(0, k_star - n + 1)
        j_hi = min(n - 1, k_star)
        if j_lo > j_hi:
            stall += 1
            continue
        js = np.arange(j_lo, j_hi + 1)
        contribs = a[js] * a[k_star - js]
        max_c_idx = js[np.argmax(contribs)]
        partner = k_star - max_c_idx

        # Compute "safety" of each position: how much it contributes to top peaks
        top_peaks = np.argsort(c)[::-1][:15]
        pressure = np.zeros(n)
        for kp in top_peaks:
            kp = int(kp)
            pl = max(0, kp - n + 1)
            ph = min(n - 1, kp)
            if pl <= ph:
                ps = np.arange(pl, ph + 1)
                pressure[ps] += a[kp - ps]
                pressure[kp - ps] += a[ps]

        # Find safe destination (low pressure, not in top peak region)
        in_peak = np.zeros(n, dtype=bool)
        for kp in top_peaks[:8]:
            kp = int(kp)
            pl = max(0, kp - n + 1)
            ph = min(n - 1, kp)
            in_peak[pl:ph + 1] = True

        safe = np.where(~in_peak)[0]
        if len(safe) < 10:
            safe = np.arange(n)
        safe_pressure = pressure[safe]
        # Exclude the source indices
        safe_mask = np.ones(len(safe), dtype=bool)
        if int(max_c_idx) in safe:
            safe_mask[safe == int(max_c_idx)] = False
        if int(partner) in safe:
            safe_mask[safe == int(partner)] = False
        safe = safe[safe_mask]
        if len(safe) == 0:
            safe = np.arange(n)

        dst = int(safe[np.argmin(safe_pressure)])

        # Try moving fraction of the smaller element
        src = int(max_c_idx)
        src_val = a[src]
        if src_val < 1e-12:
            src = int(partner)
            src_val = a[src]
        if src_val < 1e-12:
            stall += 1
            continue

        found = False
        for frac in [0.02, 0.05, 0.1, 0.2, 0.4]:
            amt = src_val * frac
            if amt < 1e-15:
                continue
            a_t = a.copy()
            a_t[src] -= amt
            a_t[dst] += amt
            a_t = np.maximum(a_t, 0.0)
            st = a_t.sum()
            if st < 1e-15:
                continue
            a_t = a_t / st
            Mt = fast_conv(a_t).max()
            if Mt < best_m - 1e-16:
                a = a_t
                best_m = Mt
                best_a = a.copy()
                stall = 0
                found = True
                break

        if not found:
            # Try random move
            j = int(rng.integers(n))
            i = int(rng.integers(n))
            if i != j and a[i] > 1e-10:
                amt = a[i] * rng.uniform(0.01, 0.05)
                a[i] -= amt
                a[j] += amt
                a = np.maximum(a, 0.0)
                st = a.sum()
                if st > 1e-15:
                    a = a / st
                    Mt = fast_conv(a).max()
                    if Mt < best_m:
                        best_m = Mt
                        best_a = a.copy()
                        stall = 0
                        found = True
        if not found:
            stall += 1

        if verbose and stall % 200 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print("    PairSwap (" + str(round(elapsed, 1)) + "s): J=" + repr(J) + " stall=" + str(stall))

    return best_a, best_m

        print("  Trying n=" + str(nn) + ", time=" + str(round(remaining, 1)) + "s")

        t_s = min(per_n_time * 0.6, remaining * 0.5)
        if t_s > 15:
            a_out, _ = subgrad_nest(a_long, t_s, verbose=False)
            sc = eval_safe(a_out)
            if np.isfinite(sc) and sc < best_score:
                best_score = sc
                best_seq = a_out.copy()
                print("    NEW BEST n=" + str(nn) + " J=" + repr(sc))

        remaining = remaining - (time.monotonic() - t0)
        if remaining > 20 and nn <= 7500:
            t_lp = min(per_n_time * 0.4, remaining * 0.4)
            if t_lp > 10:
                a_out2, _ = lp_fw(a_out, t_lp, solver, init_K=500, max_K=3000, verbose=False)
                sc2 = eval_safe(a_out2)
                if np.isfinite(sc2) and sc2 < best_score:
                    best_score = sc2
                    best_seq = a_out2.copy()
                    print("    NEW BEST n=" + str(nn) + " J=" + repr(sc2))

    return best_seq, best_score

def propose_candidate(budget_s=1800.0):
    """Main search combining subgradient Nesterov, LP-FW, and pair-swap."""
    t_global = time.monotonic()
    time_budget = min(float(budget_s) - 60.0, 1740.0)
    solver = get_solver()
    print("Budget: " + str(round(time_budget, 1)) + "s")

    best_seq = None
    best_score = float('inf')

    # Load parent
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            parent_n = p.copy()
            ps = eval_safe(parent_n)
            if np.isfinite(ps):
                best_seq = norm1(parent_n)
                best_score = ps
                print("Parent: n=" + str(len(p)) + " score=" + repr(ps))
    except Exception:
        pass

    if best_seq is None:
        n_fb = 6000
        x = np.linspace(0, 1, n_fb)
        best_seq = norm1(np.sin(np.pi * x) ** 2)
        best_score = eval_safe(best_seq)
        print("Default init n=" + str(n_fb) + " score=" + repr(best_score))

    n_cur = len(best_seq)

    # Phase 1: Subgradient Nesterov (main optimizer - fast iterations)
    remaining = time_budget - (time.monotonic() - t_global)
    print("\n=== Phase 1: SubGrad Nesterov n=" + str(n_cur) + " ===")
    t1 = min(remaining * 0.30, 500.0)
    if t1 > 30:
        a_out, _ = subgrad_nest(best_seq, t1, verbose=True, restart_every=1200)
        sc = eval_safe(a_out)
        if np.isfinite(sc) and sc < best_score:
            best_score = sc
            best_seq = a_out.copy()
            print("  Best after P1: J=" + repr(best_score))

    # Phase 2: LP-FW (handles hard-to-reduce peaks)
    remaining = time_budget - (time.monotonic() - t_global)
    n_cur = len(best_seq)
    print("\n=== Phase 2: LP-FW n=" + str(n_cur) + " ===")
    t2 = min(remaining * 0.25, 400.0)

        sc = eval_safe(a_out)

            best_score = sc
            best_seq = a_out.copy()
            print("  Best after P2: J=" + repr(best_score))

    # Phase 3: Pair-swap coordinate descent
    remaining = time_budget - (time.monotonic() - t_global)
    n_cur = len(best_seq)
    print("\n=== Phase 3: PairSwap n=" + str(n_cur) + " ===")
    t3 = min(remaining * 0.12, 200.0)
    if t3 > 15:
        a_out, _ = pair_swap(best_seq, t3, verbose=True)
        sc = eval_safe(a_out)
        if np.isfinite(sc) and sc < best_score:
            best_score = sc
            best_seq = a_out.copy()
            print("  Best after P3: J=" + repr(best_score))

    # Phase 4: Another round of SubGrad (refined starting point)
    remaining = time_budget - (time.monotonic() - t_global)
    n_cur = len(best_seq)
    print("\n=== Phase 4: SubGrad round 2 n=" + str(n_cur) + " ===")
    t4 = min(remaining * 0.18, 300.0)
    if t4 > 20:
        a_out, _ = subgrad_nest(best_seq, t4, verbose=True, restart_every=800)
        sc = eval_safe(a_out)
        if np.isfinite(sc) and sc < best_score:
            best_score = sc
            best_seq = a_out.copy()
            print("  Best after P4: J=" + repr(best_score))

    # Phase 5: Multi-n exploration

    print("\n=== Phase 5: Multi-n exploration ===")
    if remaining > 60:

    # Phase 6: Final LP-FW polish on best
    remaining = time_budget - (time.monotonic() - t_global)

            best_score = sc
            best_seq = a_out.copy()
            print("  Best after P6: J=" + repr(best_score))

    # Phase 7: Final pair-swap polish
    remaining = time_budget - (time.monotonic() - t_global)
    n_cur = len(best_seq)

        if np.isfinite(fs):
            best_score = fs

    else:

        best_seq = norm1(np.sin(np.pi * x) ** 2)
        best_score = eval_safe(best_seq)
        print("ERROR fallback")

    return [float(x) for x in np.asarray(best_seq, dtype=np.float64)]
