Let me also think about the LP approach more carefully.

Given current a (normalized, sum=1), let M = max(c) where c = a*a.
The active set is A = {k : c[k] ≥ M - ε} for some small ε.

We want to find a direction d such that:
- (a + t*d) ≥ 0 for small t > 0
- sum(a + t*d) = 1 (so sum(d) = 0)
- max((a+td)*(a+td)) < M for small t

To first order in t:
(a+td)*(a+td) ≈ a*a + 2t*(d*a)
So we need (d*a)[k] < 0 for k in A (to reduce the peaks).

But d can be negative (we're moving in the simplex, so d has both positive and negative components). The constraint (a+td) ≥ 0 means d[i] ≥ -a[i]/t for all i.

The LP (for the positive part of d, say d = d+ - d- where d+, d- ≥ 0):
minimize max_k (d*a)[k] (or equivalently, find d that minimizes the maximum increase)
subject to:
  sum(d) = 0
  d[i] ≥ -a[i]/t for all i

This is a min-max LP. Alternatively, we can write it as:
minimize M'
subject to:
  (d*a)[k] ≤ M' for all k
  sum(d) = 0
  d[i] ≥ -a[i]/t for all i

This is a linear program! The variables are d[0], ..., d[n-1] and M'. The constraints are (2n-1) + 1 + n = 3n (approximately).

def coordinate_descent_fast(a0, time_limit, verbose=False, rng_seed=42):

    best_a = a.copy()

    t0 = time.monotonic()

    stall = 0
    
    while time.monotonic() - t0 < time_limit and stall < 200:
        conv = fast_autocorr(a)
        k_max = int(np.argmax(conv))
        
        # Find the pair (i, k_max-i) with maximum contribution
        j_lo = max(0, k_max - n + 1)
        j_hi = min(n - 1, k_max)
        if j_lo > j_hi:
            stall += 1
            continue
        
        idx = np.arange(j_lo, j_hi + 1)
        contrib = a[idx] * a[k_max - idx]
        src = idx[np.argmax(contrib)]
        
        if a[src] < 1e-14:
            stall += 1
            continue
        
        # Find destination: minimize increase in max conv
        # Cost of increasing a[dst]: how much it adds to peak positions
        top_ks = np.argpartition(conv, -20)[-20:]
        costs = np.zeros(n)
        for k2 in top_ks:

            lo2 = max(0, k2i - n + 1)
            hi2 = min(n - 1, k2i)
            if lo2 <= hi2:
                valid = np.arange(lo2, hi2 + 1)
                costs[valid] += a[k2i - valid]
        
        sorted_idx = np.argsort(costs + 0.01 * a)
        dst = sorted_idx[0]
        if dst == src:
            dst = sorted_idx[1] if len(sorted_idx) > 1 else int(rng.integers(n))
        
        moved = False
        for frac in [0.02, 0.05, 0.1, 0.2, 0.3]:
            amt = a[src] * frac
            if amt < 1e-15:
                continue
            a_trial = a.copy()
            a_trial[src] -= amt
            a_trial[dst] += amt
            a_trial = np.maximum(a_trial, 0.0)
            s_t = a_trial.sum()
            if s_t < 1e-15:
                continue
            a_trial = a_trial / s_t
            M_t = fast_autocorr(a_trial).max()

                a = a_trial
                best_j = J_t
                best_a = a.copy()
                moved = True
                stall = 0
                break
        
        if not moved:
            stall += 1
            # Random perturbation to escape local min
            i = int(rng.integers(n))
            j = int(rng.integers(n))
            if i != j and a[i] > 1e-10:
                amt = a[i] * rng.uniform(0.01, 0.05)

                a[j] += amt

                a = a / a.sum()
                M_new = fast_autocorr(a).max()
                J_new = 2 * n * M_new
                if J_new < best_j:
                    best_j = J_new
                    best_a = a.copy()
                    stall = 0
    
    return best_a, best_j
