c[2(n-1)-k] = sum_i a[(n-1)-i] * a[2(n-1)-k-(n-1)-i] = sum_i a[n-1-i] * a[n-1-k+i]

And c[k] = sum_j a[j] * a[k-j]
Let i = (n-1)-j:
c[k] = sum_i a[n-1-i] * a[k-(n-1)-i] = sum_i a[n-1-i] * a[k-n+1-i]

For these to be equal: a[n-1-k+i] = a[k-n+1-i] for all valid i.
n-1-k+i = k-n+1-i → 2i = 2k-2n+2 → i = k-n+1.

This is only true for a specific i, not for all i. So in general, c[k] ≠ c[2(n-1)-k].

BUT, the full convolution of a with a reversed copy of a WOULD be symmetric. The full convolution of a with itself (autocorrelation in signal processing) is:
(r_a)[m] = sum_j a[j] * a[j+m] (for the "correlation" convention)

This is different from the convolution! The convolution (a*a)[k] = sum_j a[j] * a[k-j] is NOT the same as the correlation.

In numpy, np.convolve(a, a) gives the convolution, not the correlation. The autocorrelation would be np.correlate(a, a, 'full').

So for np.convolve(a, a), the result is NOT symmetric for non-symmetric a!
