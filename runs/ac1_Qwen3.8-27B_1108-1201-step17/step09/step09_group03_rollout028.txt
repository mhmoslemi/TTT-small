For the coordinate descent, the key insight is:

When we change `a[i]` by `delta` (and renormalize), the convolution in the range `[i, i+n-1]` changes. The new value at position `k` in this range is approximately:
`conv_new[k] = conv[k] + 2*delta*a[k-i] + delta^2*(a[i] if k==2i else 0)`

(ignoring the normalization effect, which is small for small delta)

The new max is `max(conv_max_outside, max(conv_new[k] for k in [i, i+n-1]))`.

For line search, we want to find `delta` that minimizes this new max. Since the affected entries are quadratic in `delta` (at one point) and linear elsewhere, the new max is a piecewise function that we can optimize.

A practical approach: for each coordinate, compute the "bottleneck" - the delta at which the new max is minimized. This happens when the maximum of the affected entries equals the maximum of the unaffected entries, or when two affected entries cross.

For efficiency, I'll use a simplified line search:
1. Compute the current max and the "second max" (the max of the unaffected region).
2. For the affected region, find the delta that minimizes the max of the affected entries.
3. The optimal delta is where the affected max equals the unaffected max (if that's achievable), or where the affected max is minimized.

This is essentially a 1D optimization problem for each coordinate.

                delta = base * (factor - 1.0)
                new_val = a[i] + delta
                if new_val < -1e-14:
                    continue
                new_val = max(new_val, 0.0)
                actual_delta = new_val - a[i]
                if abs(actual_delta) < 1e-16:
                    continue

                new_affected = conv[k_start:k_end + 1].copy() + 2.0 * actual_delta * a_shifted
                if 2 * i >= k_start and 2 * i <= k_end:
                    idx = 2 * i - k_start
                    new_affected[idx] = conv[2 * i] + 2.0 * actual_delta * a[i] + actual_delta * actual_delta

                new_M_cand = max(unaff_max, float(new_affected.max()))
                if new_M_cand < best_new_M - 1e-16:
                    best_new_M = new_M_cand
                    best_delta = actual_delta

            if best_delta != 0.0:
                a[i] = max(a[i] + best_delta, 0.0)
                changes = 2.0 * best_delta * a_shifted.copy()
                if 2 * i >= k_start and 2 * i <= k_end:
                    idx = 2 * i - k_start
                    changes[idx] = 2.0 * best_delta * (a[i] - best_delta) + best_delta * best_delta
                conv[k_start:k_end + 1] += changes

                # Update prefix/suffix max (invalidate affected region)
                M = max(unaff_max, float(conv[k_start:k_end + 1].max()))
                prefix_max[k_start + 1:] = np.maximum.accumulate(
                    np.concatenate([[prefix_max[k_start]], conv[k_start:size_conv]])
                )
                suffix_max[:k_end + 1] = np.maximum.accumulate(
                    np.flip(np.concatenate([conv[0:k_end + 1], [suffix_max[k_end + 1]]]))
                )[::-1]

                cur_score = 2.0 * n * M
                if cur_score < best_score:
                    best_score = cur_score
                    best_a = a.copy()
                improved = True

        if not improved:
            no_improve += 1
            if no_improve > 20:
                break
        else:
            no_improve = 0

        if verbose and sweep % 20 == 0:
            elapsed = time.monotonic() - t0
            print(f"    Polish sweep={sweep} ({elapsed:.0f}s): score={best_score:.6f}")

    return best_a, best_score


def paired_cd(a_init, time_limit, verbose=True):
    """
    Paired coordinate descent: simultaneously increase a[i] and decrease a[j].
    This preserves the sum exactly without renormalization.
    """
    n = len(a_init)
    a = normalize(a_init.copy().astype(np.float64))
    conv = fast_convolve(a)
    M = float(conv.max())
    best_score = 2.0 * n * M
    best_a = a.copy()
    t0 = time.monotonic()
    sweep = 0
    no_improve = 0
    rng = np.random.default_rng(123)

    size_conv = 2 * n - 1
    prefix_max = np.zeros(size_conv + 1)
    prefix_max[0] = -np.inf
    for i in range(size_conv):
        prefix_max[i + 1] = max(prefix_max[i], conv[i])
    suffix_max = np.zeros(size_conv + 1)
    suffix_max[size_conv] = -np.inf
    for i in range(size_conv - 1, -1, -1):
        suffix_max[i] = max(suffix_max[i + 1], conv[i])

    while time.monotonic() - t0 < time_limit:
        sweep += 1
        improved = False

        n_pairs = min(5000, n * 5)

                break

            i = int(rng.integers(0, n))
            j = int(rng.integers(0, n))

                continue

                else:
