Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:

2. Flat-spectrum initialization with random phases

4. Frequency-domain basin hopping

6. Multi-length exploration

import numpy as np
from scipy.fft import rfft, irfft
import time

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]

def simplex_project(v):
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if cond.any():
        rho = np.nonzero(cond)[0][-1]
        theta = (cssv[rho] - 1.0) / (rho + 1.0)
        return np.maximum(v - theta, 0.0)
    return np.ones(n) / n

def init_flat_spectrum(n, rng):
    n_fft = 1 << (n - 1).bit_length()
    n_freq = n_fft // 2 + 1
    phases = rng.uniform(0, 2.0 * np.pi, n_freq)
    amps = rng.uniform(0.8, 1.2, n_freq)
    spectrum = amps * np.exp(1j * phases)
    a = irfft(spectrum, n_fft)
    a = np.abs(a[:n])
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-10:
        return np.ones(n) / n
    return a / s

def init_cosine(n, rng):
    t = np.arange(n, dtype=np.float64)
    center = (n - 1) / 2.0
    width = n * rng.uniform(0.2, 0.6)
    a = np.exp(-0.5 * ((t - center) / width) ** 2)
    s = a.sum()
    return a / s if s > 1e-10 else np.ones(n) / n

def interpolate_seq(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    return f_interp / ss if ss > 1e-15 else np.ones(new_n) / new_n

**Semi-smooth Newton method for the max**: At each iteration, identify the active set (lags where `C[k]` is close to the max), and solve the resulting linear system exactly. This is essentially what the LP does, but using a Newton method instead.

Specifically, if the active set is `S` (lags where `C[k] ≈ max`), then we want to find `da` such that:
- `C[k] + sum_j ∂C[k]/∂a[j] * da[j] = C[max]` for all `k in S` (all active lags are equalized)
- `sum_j da[j] = 0` (preserve normalization)
- `a + da >= 0` (non-negativity)

This is a linear system in `da`. If we can solve it, we get a Newton step that equalizes the active peaks.

This is essentially the **active set method** for the `L_∞` minimization problem.

```python
def semi_smooth_newton(a, n_active=5, max_iter=100):
    n = len(a)
    a = a.copy() / a.sum()
    
    for _ in range(max_iter):
        conv = fast_convolve(a)
        max_val = conv.max()
        
        # Find active set (lags within tolerance of max)
        tol = 0.01 * max_val
        active = np.where(conv >= max_val - tol)[0]
        
        if len(active) == 0:
            break
        
        # Build linear system:
        # For each active lag k: sum_j 2*a[k-j] * da[j] = max_val - conv[k]
        # Plus: sum_j da[j] = 0
        # Plus: a[j] + da[j] >= 0 (handled by clipping)
        
        m = len(active)
        # System: [J | 1] [da; lambda] = [b; 0]
        # where J[k,j] = 2*a[k-j] (if valid), b[k] = max_val - conv[k]
        
        J = np.zeros((m, n))
        b = np.zeros(m)
        for i, k in enumerate(active):
            b[i] = max_val - conv[k]
            for j in range(n):
                kj = int(k) - j
                if 0 <= kj < n:
                    J[i, j] = 2.0 * a[kj]
        
        # Add normalization constraint
        A = np.vstack([J, np.ones(n)])
        rhs = np.concatenate([b, [0.0]])
        
        # Solve least squares
        try:
            da, _, _, _ = np.linalg.lstsq(A, rhs, rcond=None)
        except:
            break
        
        # Line search
        best_t = 0
        best_score = 2.0 * n * max_val
        for t in [1.0, 0.5, 0.25, 0.1, 0.05, 0.01]:
            a_new = np.maximum(a + t * da, 0)
            s = a_new.sum()
            if s < 0.01:
                continue
            a_new = a_new / s
            conv_new = fast_convolve(a_new)
            score_new = 2.0 * n * float(conv_new.max())
            if score_new < best_score:
                best_score = score_new
                best_t = t
        
        if best_t == 0:
            break
        
        a = np.maximum(a + best_t * da, 0)
        a = a / a.sum()
    
    return a
```

def simplex_project(v):
    """Project onto probability simplex."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if cond.any():
        rho = np.nonzero(cond)[0][-1]
        theta = (cssv[rho] - 1.0) / (rho + 1.0)
        return np.maximum(v - theta, 0.0)
    return np.ones(n) / n

            d = c

            fc = fd
            d = lo + gr * (hi - lo)

Let me write the semi-smooth Newton more carefully:

The key idea: at each iteration, identify the set of "active" lags (those where `C[k]` is within some tolerance of the maximum). Then solve a linear system to equalize these active lags while preserving normalization.

The linear system:
For active lag `k`: `sum_j ∂C[k]/∂a[j] * da[j] = target - C[k]`
where `target = max(C[k] for k in active_set)`

Plus: `sum_j da[j] = 0`

This gives `(m+1)` equations in `n` unknowns (where `m` is the size of the active set). If `m+1 <= n`, we can solve the least squares system.

After solving, we do a line search to ensure the score decreases.

The trick is choosing the active set tolerance. Too tight and we have a poorly determined system; too loose and we over-constrain.

Let me also think about the **mirror descent** (multiplicative update) approach more carefully.

The update `a <- a * exp(-lr * grad) / Z` is equivalent to:
`log(a_new[i]) = log(a[i]) - lr * grad[i] - log(Z)`

This is a gradient step in the "log" parameterization. The advantage is that it automatically handles the non-negativity constraint.

The gradient in the log parameterization is different from the gradient in the linear parameterization. If we parameterize `a[i] = exp(theta[i]) / Z(theta)`, then the gradient with respect to `theta` is different.

Actually, for the mirror descent with negative entropy, the update is:
`a_new = argmin_{a in simplex} <grad, a> + KL(a || a_old)`

where `KL(a||b) = sum a[i] log(a[i]/b[i])`. The solution is:
`a_new[i] = a_old[i] * exp(-grad[i]) / Z`

This is exactly the multiplicative update. The gradient `grad` is the gradient of the objective with respect to `a` (in the linear parameterization).

So the algorithm is:
1. Compute `grad = ∇f(a)` (gradient of the smooth objective)
2. Update: `a_new[i] = a[i] * exp(-lr * grad[i]) / Z`

This is simple and effective. Let me use this.

Now, for the gradient computation, I'll use the log-sum-exp smooth approximation:
`f_t(a) = 2n * t * log(sum_k exp(C[k]/t))`

`∇f_t(a)[i] = 2n * sum_k w_k * ∂C[k]/∂a[i]`

`= 4n * sum_j w[i+j] * a[j]` (substituting `j = k-i`)

This is the cross-correlation of `w` and `a`, which I can compute via FFT.

def newton_step(a, active_tol=0.05, max_active=20):
    """
    Semi-smooth Newton step for L-infinity minimization.
    Identifies active peaks and solves linear system to equalize them.
    """
    n = len(a)
    conv = fast_convolve(a)
    max_val = float(conv.max())
    
    # Find active set
    tol = active_tol * max_val
    active = np.where(conv >= max_val - tol)[0]
    
    # Limit active set size
    if len(active) > max_active:
        idx = np.argsort(conv[active])[-max_active:]
        active = active[idx]
    
    m = len(active)
    if m == 0:
        return a, max_val
    
    # Build system: J @ da + lambda * 1 = b
    # J[i, j] = sum_k active[k=i] * dC[k]/da[j]
    # = 2 * sum over active k: a[k-j] * 1[0<=k-j<n]
    
    # Actually, for each active lag k_i, the constraint is:
    # sum_j 2*a[k_i - j] * da[j] = max_val - conv[k_i]
    
    # Build J matrix (m x n)
    J = np.zeros((m, n))
    b = np.zeros(m)
    for i, k in enumerate(active):
