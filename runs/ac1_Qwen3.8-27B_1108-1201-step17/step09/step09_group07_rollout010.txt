For uniform: max_k (a*a)_k = S^2/n, score = 2n * S^2/n / S^2 = 2.

To get below 2, we need max_k (a*a)_k < S^2/n.

The sum of all convolution values is S^2: sum_k (a*a)_k = (sum a)^2 = S^2.

There are 2n-1 convolution values. So the average is S^2/(2n-1).

For uniform, the max is S^2/n, and S^2/n > S^2/(2n-1) for n > 1, so the max is above average.

To get max < S^2/n, we need the convolution to be more "flat" than uniform. But uniform already gives a triangular convolution [1, 2, ..., n, n-1, ..., 1] (for unit values), which is quite peaked at the center.
