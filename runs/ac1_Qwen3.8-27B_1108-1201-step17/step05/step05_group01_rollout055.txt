Alternative: Use the "Board" algorithm (iterative projection) to find a non-negative sequence with flat autocorrelation:
1. Start with a random sequence.
2. Project onto the set of non-negative sequences (clip at 0).
3. Project onto the set of sequences with flat power spectrum (in frequency domain, set |A(f)| = constant).
4. Repeat.

This is like the Gerchberg-Saxton algorithm but for non-negative sequences.

```python
def iterative_flat_spectrum(n, rng, iters=100):
    """Iterative projection: non-negative + flat power spectrum."""
    a = rng.standard_normal(n)
    target_power = 1.0 / n  # target |A(f)|^2 for flat spectrum
    
    for _ in range(iters):
        # Project onto non-negative
        a = np.maximum(a, 0)
        s = a.sum()
        if s < 1e-15:
            a = rng.standard_normal(n)
            a = np.maximum(a, 0)
            s = a.sum()
        a = a / s
        
        # Project onto flat power spectrum
        fft_size = 1 << (2 * n - 2).bit_length()
        A = rfft(a, fft_size)
        mag = np.abs(A)
        # Set magnitude to constant
        target_mag = np.sqrt(fft_size * target_power)  # or some normalization
        phase = np.angle(A)
        A_new = target_mag * np.exp(1j * phase)
        # Ensure A[0] is real and positive (DC component)
        A_new[0] = np.abs(A_new[0])
        if fft_size % 2 == 0:
            A_new[-1] = np.abs(A_new[-1])
        a = irfft(A_new, fft_size)[:n]
        a = np.maximum(a, 0)
    
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s
```
