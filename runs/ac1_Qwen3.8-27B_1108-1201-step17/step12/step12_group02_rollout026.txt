The product (j+1)(k-j+1) as a function of j is a concave quadratic, maximized at j = (k-2)/2 (the vertex).

If (k-2)/2 is within [k-n+1, n-1], the max is at j = (k-2)/2.
Otherwise, it's at the nearest boundary.

For k = n: j ranges from 1 to n-1. Vertex at (n-2)/2. For n >= 2, (n-2)/2 >= 0 and < n-1, so the max is at the vertex.

The max value of b[k] for k > n-1:
b[k] = sum_{j=k-n+1}^{n-1} (j+1)(k-j+1)

This is a sum of a concave function, so the sum is maximized when the range of summation is widest AND the function values are largest. Both conditions point to k being as large as possible (near 2n-2), but the function values decrease as k increases (the range shrinks).
