Actually, for large p, sum_{i=1}^n i^p ≈ n^p * sum_{j=0}^{n-1} (1-j/n)^p ≈ n^p * ∫_0^1 (1-x)^p dx = n^p/(p+1).

So the formula sum ≈ n^{p+1}/(p+1) is actually valid for all p (it's the integral approximation).

Edge = n^{2p}.
sum^2 ≈ n^{2p+2}/(p+1)^2.
Objective (edge-dominates) = 2n * n^{2p} * (p+1)^2/n^{2p+2} = 2*(p+1)^2/n.

So for n=1600, p=100: objective ≈ 2*101^2/1600 = 2*10201/1600 ≈ 12.75.
For n=1600, p=5: objective ≈ 2*36/1600 = 0.045.
For n=1600, p=10: objective ≈ 2*121/1600 = 0.151.

Wait, so the objective in the edge-dominates regime INCREASES with p! That makes sense: higher p means more concentration, which means the edge value (a[n-1]^2) becomes a larger fraction of the total sum squared.

So the best strategy in the edge-dominates regime is to use the SMALLEST p that still gives edge dominance.

The boundary between center-dominates and edge-dominates is:
n * B(p+1,p+1) = 1.

For n=1600:
p=4: 1600/630 = 2.54 > 1 (center dominates)
p=5: 1600 * B(6,6) = 1600 * 5!5!/11! = 1600 * 14400/39916800 = 1600 * 0.000361 = 0.578 < 1 (edge dominates)

So the boundary is between p=4 and p=5. At the boundary, both center and edge are equal, and the objective is:
= 2n * center / sum^2 = 2n * n^{2p+1} * B(p+1,p+1) / (n^{p+1}/(p+1))^2
= 2 * (p+1)^2 * B(p+1,p+1)

At the boundary, B(p+1,p+1) = 1/n, so objective = 2*(p+1)^2/n.

For the boundary between p=4 and p=5 (interpolating): the objective at the exact boundary is 2*(p+1)^2/n where n*B(p+1,p+1)=1.

For p=4 (center dominates): objective = 2*25/630 = 50/630 ≈ 0.0794.
For p=5 (edge dominates): objective = 2*36/1600 = 0.045.

So p=5 (edge dominates) gives a better objective than p=4 (center dominates)!

What about p=6 (more edge-dominated)?
B(7,7) = 6!6!/13! = 518400/6227020800 ≈ 8.33e-5.
n*B(7,7) = 1600*8.33e-5 = 0.133 < 1. Edge dominates.
Objective = 2*49/1600 = 0.06125.

So p=6 gives 0.06125, worse than p=5's 0.045.

The minimum in the edge-dominates regime is at the smallest p that gives edge dominance. For n=1600, that's p=5 (since p=4 gives center dominance).

Actually, we can do better by using a non-integer p. The optimal p is the one where n*B(p+1,p+1) = 1 (the boundary), because:
- Below the boundary (smaller p): center dominates, objective = 2*(p+1)^2*B(p+1,p+1), which decreases with p in this regime.
- At the boundary: objective = 2*(p+1)^2/n.
- Above the boundary (larger p): edge dominates, objective = 2*(p+1)^2/n, which increases with p.

So the optimal is at the boundary! We need to find p* such that n*B(p*+1, p*+1) = 1.

For n=1600: B(p+1,p+1) = 1/1600.

Using the approximation B(p+1,p+1) ≈ 4^(-p-1) * sqrt(pi*(p+1)) for large p:
4^(-p-1) * sqrt(pi*(p+1)) = 1/1600
4^{p+1} = 1600*sqrt(pi*(p+1))

For p=5: 4^6 = 4096, 1600*sqrt(6*pi) ≈ 1600*4.34 ≈ 6944. 4096 < 6944, so B is larger than 1/1600. Center dominates (consistent with our earlier calc).

For p=5.5: 4^6.5 = 4^6 * 2 = 8192, 1600*sqrt(6.5*pi) ≈ 1600*4.51 ≈ 7216. 8192 > 7216, so B < 1/1600. Edge dominates.
