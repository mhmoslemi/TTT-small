**Spectral approach**: In the frequency domain, `conv(a,a)` has DFT `A(ω)^2` (where `A(ω)` is the DFT of `a`). We want `max_k (a*a)[k]` to be small, which means we want the inverse DFT of `A(ω)^2` to be flat. This is related to the "flat spectrum" problem.

If `A(ω)^2` is constant (flat spectrum), then the inverse DFT would be a delta function (all energy at one point), which is the opposite of what we want. We want the inverse DFT to be flat, which means `A(ω)^2` should be a delta function... but that's impossible for a time-domain signal.

Actually, I think the right way to think about it is:
- We want `c_k = (a*a)[k]` to be as flat as possible
- `DFT(c) = A(ω)^2`
- If `c` is flat, then `DFT(c)` is a delta at ω=0
- So we want `A(ω)^2 ≈ delta(ω)`
- But `A(0) = sum(a) = 1` (normalized), so `A(0)^2 = 1`
- And `A(ω)^2` for ω ≠ 0 should be small
- This means we want `A(ω)` to be concentrated at ω=0, which means `a` should be spread out (broad in time domain)

But `a` is already constrained to have length `n`, so it can't be arbitrarily spread out. The best we can do is make `a` as "flat" as possible (which gives a triangular convolution) or use a window function that reduces the convolution peaks.

def fast_autocorr(a):
    """Full convolution a*a using FFT."""
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def compute_grad_soft(a, temperature):
    """Compute gradient of soft-max of convolution values."""
    n = len(a)
    c = fast_autocorr(a)
    c_max = c.max()
    # Soft-max weights
    if temperature < 1e-10:
        # Hard max: only active at argmax
        weights = np.zeros(len(c))
        weights[np.argmax(c)] = 1.0
    else:
        weights = np.exp((c - c_max) / temperature)
        weights = weights / weights.sum()
    
    # grad[j] = 2 * sum_k weights[k] * a[k-j] (for valid k-j)
    grad = np.zeros(n)
    active = np.where(weights > 1e-12)[0]
    for k in active:
        js = max(0, k - n + 1)
        je = min(n - 1, k)
        if js > je:
            continue
        idx = np.arange(js, je + 1)
        other = k - idx
        grad[idx] += 2.0 * weights[k] * a[other]
    return grad, c.max()

def optimize_adam(a0, time_limit, lr=0.01, temperature_start=0.1, temperature_end=0.001):
    """Adam-based optimization with temperature annealing."""
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    a = a / s

    while time.monotonic() - t0 < time_limit:

        v_hat = v / (1 - 0.999**t)
        
        a_new = a - lr * m_hat / (np.sqrt(v_hat) + 1e-8)

def nesterov_lp_optimize(a0, time_limit, solver, verbose=True):
    """
    Nesterov-accelerated LP best-response with adaptive schedule.
    """
    n = len(a0)

            y_new = y.copy()

        if t == 1:

            a_s = a_new.sum()

        a = a_new

        c = fast_autocorr(a)

        if score_a < best_score:
            best_score = score_a

def solve_lp_best_response(a_fixed, solver):
    """Solve LP: min M s.t. T(a)@b <= M, sum(b)=1, b>=0."""
    n = len(a_fixed)
    b_var = cp.Variable(n, nonneg=True)
    M_var = cp.Variable()
    T = build_conv_matrix(a_fixed)
    constraints = [T @ b_var <= M_var, cp.sum(b_var) == 1]
    prob = cp.Problem(cp.Minimize(M_var), constraints)
    try:
        prob.solve(solver=solver)
    except Exception:
        pass
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        for alt in [cp.ECOS, cp.SCS, cp.PDLP, cp.CLARABEL]:
            if alt == solver:
                continue
            try:
                prob.solve(solver=alt)
                if prob.status in ('optimal', 'optimal_inaccurate'):
                    break
            except Exception:
                continue
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None, None
    b_val = np.asarray(b_var.value, dtype=np.float64)
    b_val = np.maximum(b_val, 0)
    s = b_val.sum()
    if s < 1e-15:
        return None, None
    b_val = b_val / s
    return b_val, float(M_var.value)


def build_conv_matrix(a_fixed):
    """Build convolution matrix."""
    n = len(a_fixed)
    T = np.zeros((2 * n - 1, n))
    for j in range(n):
        T[j:j + n, j] = a_fixed
    return T


def get_lp_solver():
    """Find a working LP solver."""
    for solver_name in [cp.ECOS, cp.SCS, cp.PDLP, cp.CLARABEL]:
        try:
            x = cp.Variable(5, nonneg=True)
            prob = cp.Problem(cp.Minimize(cp.sum(x)), [cp.sum(x) == 1, x <= 0.5])
            prob.solve(solver=solver_name)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                return solver_name
        except Exception:

    return cp.ECOS


def peak_shaving_subgrad(a0, time_limit, n_iters=10000, seed=42):
    """
    Peak shaving using subgradient method with restarts.
    At each step, identify the peak and move mass away from it.
    """
    n = len(a0)
    rng = np.random.default_rng(seed)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    a = a / s
    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()
    stall = 0
    
    lr = 0.1  # Initial learning rate
    
    for it in range(n_iters):
        if time.monotonic() - t0 > time_limit:
            break
        if it % 100 == 0:
            lr = max(0.001, 0.1 * (0.995 ** it))
        
        c = fast_autocorr(a)
        max_c = c.max()
        peak_idx = np.argmax(c)
        
        # Subgradient of max at peak: 2*a shifted
        grad = np.zeros(n)
        k = peak_idx
        js = max(0, k - n + 1)
        je = min(n - 1, k)
        idx = np.arange(js, je + 1)
        other = k - idx
        grad[idx] = 2.0 * a[other]
        
        # Also add a small regularization to keep distribution
        grad += 0.001 * a
        
        # Subgradient step
        a_new = a - lr * grad
        a_new = np.maximum(a_new, 0)
        s_new = a_new.sum()
        if s_new < 1e-15:
            a_new = a.copy()
            s_new = 1.0
        a_new = a_new / s_new
        
        score = 2.0 * n * fast_autocorr(a_new).max()
        if score < best_score:
            best_score = score
            best_a = a_new.copy()
            a = a_new
            stall = 0
        else:
            # Try a smaller step
            for frac in [0.5, 0.2, 0.1]:
                a_try = a - lr * frac * grad
                a_try = np.maximum(a_try, 0)
                s_try = a_try.sum()
                if s_try < 1e-15:
                    continue
                a_try = a_try / s_try
                sc_try = 2.0 * n * fast_autocorr(a_try).max()
                if sc_try < best_score:
                    best_score = sc_try
                    best_a = a_try.copy()
                    a = a_try
                    stall = 0
                    break
            else:
                stall += 1
                # Random perturbation
                if stall % 20 == 0:
                    pert = rng.random(n) * 0.01
                    a_try = a + pert
                    a_try = np.maximum(a_try, 0)
                    a_try = a_try / a_try.sum()
                    sc_try = 2.0 * n * fast_autocorr(a_try).max()
                    if sc_try < best_score:
                        best_score = sc_try
                        best_a = a_try.copy()
                        a = a_try
                        stall = 0
        
        if stall > 2000:
            break
    
    return best_a, best_score


def coordinate_ascent_refine(a0, time_limit, seed=123):
    """
    Coordinate-wise refinement: try moving mass between pairs of coordinates.
    Focus on reducing the peak of the convolution.
    """
    n = len(a0)
    rng = np.random.default_rng(seed)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    a = a / s
    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()
    stall = 0
    
    while time.monotonic() - t0 < time_limit:
        c = fast_autocorr(a)
        max_c = c.max()
        peak_idx = np.argmax(c)
        
        # Identify coordinates that contribute to the peak
        js = max(0, peak_idx - n + 1)
        je = min(n - 1, peak_idx)
        peak_coords = np.arange(js, je + 1)
        
        # For each peak coordinate, try moving mass to a non-peak coordinate
        improved = False
        for src in peak_coords:
            other_coord = peak_idx - src
            # Find target: coordinate far from peak
            dist = np.abs(np.arange(n) - peak_coords[0]) + np.abs(np.arange(n) - other_coord)
            targets = np.argsort(dist)[::-1][:20]
            
            for dst in targets:
                if dst in peak_coords or dst == other_coord:
                    continue
                for frac in [0.001, 0.005, 0.01, 0.02]:
                    amt = a[src] * frac
                    if amt < 1e-15:
                        break
                    a_try = a.copy()
                    a_try[src] -= amt
                    a_try[dst] += amt
                    if a_try[src] < -1e-12:
                        break
                    a_try = np.maximum(a_try, 0)
                    a_try = a_try / a_try.sum()
                    sc = 2.0 * n * fast_autocorr(a_try).max()
                    if sc < best_score:
                        best_score = sc
                        best_a = a_try.copy()
                        a = a_try
                        improved = True
                        break
                if improved:
                    break
            if improved:
                break
        
        if not improved:
            stall += 1
            if stall > 500:
                break
    
    return best_a, best_score


def generate_initialization(n, method='cosine'):
    """Generate diverse initializations."""
    if method == 'cosine':
        x = np.linspace(0, np.pi, n)
        a = np.cos(x / 2) ** 2
    elif method == 'gaussian':
        x = np.linspace(-3, 3, n)
        a = np.exp(-x**2)
    elif method == 'triangle':
        x = np.linspace(0, 1, n)
        a = np.maximum(0, 1 - np.abs(2*x - 1))
    elif method == 'exponential':
        x = np.linspace(0, 1, n)
        a = np.exp(-5*x)
    elif method == 'bimodal':
        x = np.linspace(-3, 3, n)
        a = np.exp(-(x-1)**2) + np.exp(-(x+1)**2)
    elif method == 'flat':
        a = np.ones(n)
    elif method == 'random':
        a = np.random.random(n)
    else:
        x = np.linspace(0, np.pi, n)
        a = np.cos(x / 2) ** 2
    
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    return a


def qp_active_set_refinement(a0, time_limit, n_active=30):

        a_new = np.asarray(a_var.value, dtype=np.float64)

def interpolate_sequence(f, new_n):
    """Interpolate a normalized sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp

Actually, let me reconsider the whole approach. The key insight is:

The objective is `2n * max_k c_k / S^2` where `c = a*a` (full convolution) and `S = sum(a)`.

By normalization invariance, we can set `S = 1` and minimize `2n * max_k c_k`.

The constraint is `sum_k c_k = S^2 = 1`, so the average of `c_k` is `1/(2n-1)`.

The question is: what is the minimum possible value of `max_k c_k` subject to `c = a*a` for some non-negative `a` with `sum(a) = 1`?

This is a constrained optimization problem. The LP Nesterov approach solves a saddle-point problem that is dual to this.

Let me think about what else could help:

1. **Use the fact that the problem is invariant under translation**: Shifting `a` doesn't change the set of convolution values, just their indices. So we can WLOG assume the peak is at a particular index.

2. **Use the fact that `c_0 = a[0]^2`**: The first element of the convolution is always a non-negative square. Similarly, `c_{2n-2} = a[n-1]^2`. So to minimize the max, we want `a[0]` and `a[n-1]` to be small.

3. **The "effective" problem**: If we set `a[0] = a[n-1] = 0`, the problem becomes easier because we eliminate two "free" peaks.

Actually, point 3 is interesting. If the first and last elements are zero, then `c_0 = 0` and `c_{2n-2} = 0`. This could help if the peaks are at the edges.

But typically, for a well-distributed sequence, the peak is near the center, not at the edges. So this might not help much.

Let me think about another approach: **iterative reweighting**.

**Iterative Reweighting Algorithm:**
1. Start with `a^(0)`
2. Compute `c^(t) = a^(t) * a^(t)`
3. Compute weights `w_k = 1 / (1 + c_k^(t) / eps)` for small `eps` (penalize large convolution values)
4. Solve: minimize `sum_k w_k * c_k` subject to `sum(a) = 1`, `a >= 0`

5. Update `a^(t+1) = argmin`
6. Repeat
