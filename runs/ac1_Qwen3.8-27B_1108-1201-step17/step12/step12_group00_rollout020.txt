Let me analyze this problem carefully:

We want to minimize `2 * n * max(conv(a, a)) / (sum(a))^2` for a non-negative sequence `a` of length `n`.

Key observations:
1. The objective is scale-invariant: if we multiply `a` by `c`, both the numerator (max of convolution scales by `c^2`) and denominator (`(sum(a))^2` scales by `c^2`) scale the same way. So we can normalize `sum(a) = 1` without loss of generality.

2. With `sum(a) = 1`, the objective becomes `2 * n * max(conv(a, a))`.

3. The minimum possible value of `max(conv(a,a))` when `sum(a) = 1` is related to the uniform distribution. If `a_i = 1/n` for all `i`, then `conv(a,a)_k = sum_i a_i * a_{k-i}`. For the middle lag (k ≈ n-1), this is approximately `n * (1/n)^2 = 1/n`. So `max(conv) ≈ 1/n` and the objective is `2 * n * 1/n = 2`. Wait, that's not right either.

Let me be more careful. If `a_i = 1/n` for all `i`, then:
- `conv(a,a)_k = sum_{i} a_i * a_{k-i}` where the sum is over valid indices.
- For k = n-1 (the center): `conv(a,a)_{n-1} = sum_{i=0}^{n-1} (1/n)(1/n) = n * (1/n)^2 = 1/n`
- For k = 0: `conv(a,a)_0 = (1/n)(1/n) = 1/n^2`
- So max is `1/n` at the center.
- Objective = `2 * n * (1/n) / 1^2 = 2`.

But the target is 1.5027, so we need to do better than uniform.

The problem is related to finding sequences with minimal peak autocorrelation - similar to the Sidon set / optimal Golay complementary sequence problem but for non-negative sequences.

The key insight from the LP approach: At each iteration, we fix `a` and find the best `b` such that `conv(a, b) <= M` elementwise. This is the "best response" in a game-theoretic sense. Then we mix or replace.

The Nesterov acceleration applied to this best-response iteration is what's driving the previous solution. The previous solution achieved 1.504353 with n=1600.

Let me think about what could improve this:

1. **Longer sequences**: The objective has a factor of `2n` in the numerator. For longer sequences, we can spread the energy more, potentially reducing the peak convolution. But the LP gets more expensive with larger n.

2. **Better initialization**: Instead of structured inits, we could use the parent sequence and perturb it, or use random inits from different families.

3. **Different optimization strategies**:
   - The LP best-response is exact but slow. For larger n, we could use approximate methods.
   - We could use a projected gradient approach on the smoothed objective (LogSumExp).
   - We could use coordinate descent with exact line search.
   - We could use a "mirror descent" approach with entropy regularization.

4. **Key mathematical insight**: The problem is equivalent to finding a probability distribution on {0, ..., n-1} that minimizes the maximum of its auto-convolution. This is related to the problem of finding "flat" sequences in signal processing.

5. **Another approach**: Instead of the LP best-response, we could directly minimize the LogSumExp approximation of the max using gradient methods. The gradient of LSE(conv(a,a)) w.r.t. a_i can be computed efficiently using FFT.

Let me think about the LSE gradient approach more carefully:

Let `f(a) = log(sum_k exp(T * conv(a,a)_k))` where T is a temperature parameter.

`conv(a,a)_k = sum_i a_i * a_{k-i}` (with appropriate bounds)

`df/da_i = 2 * sum_k (T * exp(T * conv_k) / sum_j exp(T * conv_j)) * (a_{k-i} + a_{i-k})`

This can be computed via FFT if we define the weighted convolution properly.

Actually, let me think about this differently. The gradient of `max_k conv(a,a)_k` (subgradient) at the maximizing index k* is:
- `d/da_i [conv(a,a)_{k*}] = a_{k*-i} + a_{i-k*}` (where these are zero if out of bounds)

For the LSE surrogate:
- `grad_i = 2 * sum_k w_k * (a_{k-i} + a_{i-k})` where `w_k = exp(T*conv_k) / sum_j exp(T*conv_j)`

This is a weighted sum of "shifted" versions of `a`, which can be computed via FFT!

Specifically, if we define `w = [w_0, ..., w_{2n-2}]` and compute the correlation of `a` with `w`, we get the gradient.

Now, the full algorithm:

1. Start with a normalized sequence (sum = 1 or sum = sqrt(2n)).
2. Compute gradient of LSE(conv(a,a)) with temperature T.
3. Take a gradient step: a_new = a - step_size * grad
4. Project to non-negative: a_new = max(a_new, 0)
5. Renormalize.
6. Anneal T from high to low.
7. Periodically try the LP best-response for exact improvement.

The key advantage of this approach over the LP is that it's O(n log n) per step (vs O(n^2) or worse for the LP), so we can do many more iterations, especially for larger n.

Let me also think about the "mirror descent" / "exponentiated gradient" approach:
- Maintain a "dual variable" U (same shape as a).
- At each step: a_i ∝ exp(-U_i / T) (or similar).
- Update U_i += learning_rate * grad_i.
- This naturally keeps a_i > 0 and can be seen as optimizing over the probability simplex with entropy regularization.

This might be better for this problem because:
1. It naturally handles the non-negativity constraint.
2. The "temperature" annealing is built in.
3. It can converge to very sparse solutions if desired.

Let me combine both approaches:

def mirror_descent_lse(a0, time_limit, T_start=100, T_end=1, n_stages=20):
    n = len(a0)
    a = np.maximum(a0, 1e-15).astype(np.float64)
    s = a.sum()
    a = a / s  # normalize to sum = 1
    
    log_a = np.log(a)
    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()
    
    for stage in range(n_stages):
        T = T_start * (T_end / T_start) ** (stage / max(1, n_stages - 1))
        eta = 1.0 / (T * n)  # learning rate
        n_inner = max(50, int(10000 / (1 + stage)))
        
        for it in range(n_inner):
            if time.monotonic() - t0 > time_limit:
                break
            
            # Compute LSE gradient
            b = fast_autocorr(a)
            max_b = b.max()
            w = np.exp(T * (b - max_b))
            w /= w.sum()
            
            # Compute gradient using FFT
            grad = compute_lse_grad(a, w, n)
            
            # Mirror descent update
            log_a -= eta * grad
            # Clip to avoid underflow
            log_a = np.clip(log_a, -50, 50)
            a_new = np.exp(log_a - log_a.max())
            s_new = a_new.sum()
            a_new /= s_new
            a = a_new
            
            score = fast_autocorr(a).max()
            if score < best_score:
                best_score = score
                best_a = a.copy()
        
        if time.monotonic() - t0 > time_limit:
            break
    
    return best_a, best_score

import numpy as np
import time
from scipy.fft import rfft, irfft

def fast_autocorr(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]

def lse_gradient(a, w):
    """Compute gradient of LSE(conv(a,a)) given weights w on the convolution lags."""
    n = len(a)
    # w has length 2n-1
    fft_size = 1 << (3 * n - 1).bit_length()
    A = rfft(a, fft_size)
    W = rfft(w, fft_size)
    
    # corr: ifft(conj(A) * W) gives cross-correlation
    # corr[i] = sum_j a[j] * w[j-i] for valid linear range
    corr = irfft(np.conj(A) * W, fft_size)
    
    # conv: ifft(A * W) gives convolution
    # conv[i] = sum_j a[j] * w[i-j] for valid linear range
    conv = irfft(A * W, fft_size)
    
    # g1[i] = sum_k w[k] * a[k-i]
    # For i=0: corr[0]
    # For i>0: corr[fft_size - i]
    g1 = np.zeros(n)
    g1[0] = corr[0]
    if n > 1:
        g1[1:] = corr[fft_size - 1 : fft_size - n : -1]
    
    # g2[i] = sum_k w[k] * a[i-k] = conv[i]
    g2 = conv[:n]
    
    return g1 + g2

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. LSE (LogSumExp) gradient with mirror descent (exponentiated gradient) and temperature annealing
2. FFT-based O(n log n) gradient computation for the convex objective
3. LP best-response with Nesterov acceleration as a periodic corrector
4. Multi-length exploration (n=1600, 2000, 2400)
5. Coordinate descent peak shaving for final polish
Key insight: mirror descent on the simplex avoids projection artifacts,
and the FFT-based gradient allows many more iterations than the LP approach.
"""

import numpy as np
import cvxpy as cp
import time
from scipy.fft import rfft, irfft

_global_solver = None


def get_solver():
    global _global_solver
    if _global_solver is not None:
        return _global_solver
    for s in [cp.PDLP, cp.CLARABEL, cp.ECOS, cp.SCS]:
        try:
            x = cp.Variable(4, nonneg=True)
            prob = cp.Problem(cp.Minimize(cp.sum(x)), [cp.sum(x) == 1, x <= 0.4])
            prob.solve(solver=s)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                _global_solver = s
                print(f"  LP solver: {s}")
                return s
        except Exception:
            continue
    _global_solver = cp.ECOS
    print(f"  LP solver (fallback): ECOS")
    return _global_solver


def fast_autocorr(a):
    """Compute full autocorrelation of a using FFT. Returns array of length 2n-1."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]


def evaluate_safe(a):
    try:
        a_list = [float(x) for x in a]
        sc = evaluate_sequence(a_list)
        return float(sc)
    except Exception:
        return float('inf')


def compute_lse_grad(a, w):
    """
    Compute gradient of LSE(conv(a,a)) w.r.t. a.
    w: weights on convolution lags (length 2n-1), summing to 1.
    Returns gradient of length n.
    grad[i] = sum_k w[k] * (a[k-i] + a[i-k]) for valid indices.
    """
    n = len(a)
    fft_size = 1 << (3 * n - 1).bit_length()
    A = rfft(a, fft_size)
    W = rfft(w, fft_size)

    # Cross-correlation: corr[lag] = sum_j a[j] * w[j-lag]
    corr = irfft(np.conj(A) * W, fft_size)
    # Convolution: conv[i] = sum_j a[j] * w[i-j]
    conv = irfft(A * W, fft_size)

    # g1[i] = sum_k w[k] * a[k-i] = corr at negative lag -i
    g1 = np.zeros(n)
    g1[0] = corr[0]
    if n > 1:
        g1[1:] = corr[fft_size - 1: fft_size - n: -1]

    # g2[i] = sum_k w[k] * a[i-k] = conv[i]
    g2 = conv[:n]

    return g1 + g2


def lse_mirror_descent(a0, time_limit, T_start=1.0, T_end=500.0, n_stages=30, verbose=True):
    """
    LSE-based mirror descent (exponentiated gradient) with temperature annealing.
    Minimizes max_k conv(a,a)_k for a on the probability simplex.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 1e-15)
    s = a.sum()
    a = a / s

    log_a = np.log(a).copy()
    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()
    total_iters = 0

    for stage in range(n_stages):
        if time.monotonic() - t0 > time_limit:
            break

        # Anneal temperature: increase T to sharpen the LSE toward max
        frac = stage / max(1, n_stages - 1)
        T = T_start * (T_end / T_start) ** frac

        # Learning rate: smaller for larger T (sharper objective needs smaller steps)
        eta = 1.0 / (T * 2.0 * np.log(n + 1))
        # Also adapt based on gradient magnitude
        n_inner = max(100, int(20000 / (1.0 + 0.5 * stage)))

        stage_start = time.monotonic()
        for it in range(n_inner):
            if time.monotonic() - t0 > time_limit:
                break

            b = fast_autocorr(a)
            max_b = b.max()
            # Compute LSE weights
            scaled = T * (b - max_b)
            scaled = np.clip(scaled, -700, 700)
            exp_scaled = np.exp(scaled)
            w = exp_scaled / exp_scaled.sum()

            # Compute gradient
            grad = compute_lse_grad(a, w)

            # Mirror descent: update in log-space
            log_a -= eta * grad
            # Numerical stability
            log_a_max = log_a.max()
            if np.isfinite(log_a_max):
                log_a_shifted = log_a - log_a_max
                log_a_shifted = np.clip(log_a_shifted, -50, 50)
                a_new = np.exp(log_a_shifted)
                s_new = a_new.sum()
                if s_new > 1e-15:
                    a = a_new / s_new
                    log_a = log_a_shifted  # Keep shifted for stability

            total_iters += 1
            if total_iters % 200 == 0:
                score = fast_autocorr(a).max()
                if score < best_score:
                    best_score = score
                    best_a = a.copy()

        # End of stage: evaluate
        score = fast_autocorr(a).max()
        if score < best_score:
            best_score = score
            best_a = a.copy()

        if verbose and (stage % 5 == 0 or stage == n_stages - 1):
            elapsed = time.monotonic() - t0
            print(f"    LSE-MD stage={stage}/{n_stages} T={T:.1f} eta={eta:.2e} "
                  f"score={best_score:.8f} elapsed={elapsed:.0f}s")

    return best_a, best_score


def build_conv_matrix(a):
    """Build the convolution matrix T such that (T @ b) = conv(a, b)."""
    n = len(a)
    T = np.zeros((2 * n - 1, n))
    for j in range(n):
        T[j:j + n, j] = a
    return T


def lp_best_response(a, M, solver):
    """Solve LP: maximize sum(b) s.t. T@b <= M, b >= 0."""
    n = len(a)
    b_var = cp.Variable(n, nonneg=True)
    T = build_conv_matrix(a)
    constraints = [T @ b_var <= M]
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        return None
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None
    b_val = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
    s = b_val.sum()
    if s < 1e-15:
        return None
    return b_val


def nesterov_lp_optimize(a0, time_limit, solver, verbose=True):
    """Nesterov-accelerated LP best-response iteration."""
    n = len(a0)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s0 = a.sum()
    if s0 < 1e-15:
        a = np.ones(n) * norm / n
    else:
        a = a * norm / s0

    best_a = a.copy()
    best_score = fast_autocorr(a).max()

    y = a.copy()
    avg_a = np.zeros(n)
    n_avg = 0
    t0 = time.monotonic()
    n_iters = 0

    for t in range(1, 500000):
        if time.monotonic() - t0 > time_limit:
            break

        M_curr = fast_autocorr(y).max()
        if M_curr < 1e-12:
            break

        b = lp_best_response(y, M_curr, solver)
        if b is None:
            continue

        b_sum = b.sum()
        if b_sum < 1e-15:
            continue
        g = b * norm / b_sum
        n_iters += 1

        alpha = 2.0 / (t + 2.0)
        y_new = (1.0 - alpha) * y + alpha * g
        y_new = np.maximum(y_new, 0.0)
        s_y = y_new.sum()
        if s_y < 1e-15:
            y_new = y.copy()
        else:
            y_new = y_new * norm / s_y

        if t == 1:
            a_new = g.copy()
        else:
            momentum = (t - 1.0) / (t + 2.0)
            a_new = y_new + momentum * (y_new - y)
            a_new = np.maximum(a_new, 0.0)
            s_a = a_new.sum()
            if s_a < 1e-15:
                a_new = y_new.copy()
            else:
                a_new = a_new * norm / s_a

        y = y_new
        a = a_new

        score_y = fast_autocorr(y).max()
        if score_y < best_score:
            best_score = score_y
            best_a = y.copy()

        score_a = fast_autocorr(a).max()
        if score_a < best_score:
            best_score = score_a
            best_a = a.copy()

        avg_a += a
        n_avg += 1
        if n_avg % 50 == 0:
            avg_check = avg_a / n_avg
            s_avg = avg_check.sum()
            if s_avg > 1e-15:
                avg_check = avg_check * norm / s_avg
                score_avg = fast_autocorr(avg_check).max()
                if score_avg < best_score:
                    best_score = score_avg
                    best_a = avg_check.copy()

        if verbose and n_iters % 200 == 0:
            elapsed = time.monotonic() - t0
            print(f"    NLP iter={n_iters} ({elapsed:.0f}s): best={best_score:.8f}")

    return best_a, best_score


def gradient_nesterov(a0, time_limit, T_start=5.0, T_end=300.0, n_stages=15, verbose=True):
    """
    Nesterov-accelerated projected gradient on LSE objective.
    Alternates with subgradient Frank-Wolfe for better convergence.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 1e-15)
    s = a.sum()
    a = a / s

    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()

    y = a.copy()  # Nesterov lookahead
    x_prev = a.copy()

    for stage in range(n_stages):
        if time.monotonic() - t0 > time_limit:
            break
        frac = stage / max(1, n_stages - 1)
        T = T_start * (T_end / T_start) ** frac
        eta = 1.0 / (T * np.log(n + 2))
        n_inner = max(200, int(50000 / (1.0 + stage)))

        for it in range(n_inner):
            if time.monotonic() - t0 > time_limit:
                break

            b = fast_autocorr(y)
            max_b = b.max()
            scaled = T * (b - max_b)
            scaled = np.clip(scaled, -700, 700)
            exp_s = np.exp(scaled)
            w = exp_s / exp_s.sum()

            grad = compute_lse_grad(y, w)

            # Gradient step with projection
            x_new = y - eta * grad
            x_new = np.maximum(x_new, 0.0)
            s_new = x_new.sum()
            if s_new < 1e-15:
                x_new = y.copy()
            else:
                x_new = x_new / s_new

            # Nesterov update for y
            if it == 0:
                y = x_new
            else:
                momentum = (np.sqrt(1.0 + 4.0 * it * it) - 1.0) / (2.0 * it + 2.0)
                y = x_new + momentum * (x_new - x_prev)
                y = np.maximum(y, 0.0)
                s_y = y.sum()
                if s_y < 1e-15:
                    y = x_new.copy()
                else:
                    y = y / s_y

            x_prev = x_new

            if it % 100 == 0:
                score = fast_autocorr(x_new).max()
                if score < best_score:
                    best_score = score
                    best_a = x_new.copy()

                score_y = fast_autocorr(y).max()
                if score_y < best_score:
                    best_score = score_y
                    best_a = y.copy()

        score = fast_autocorr(y).max()
        if score < best_score:
            best_score = score
            best_a = y.copy()

        if verbose and (stage % 3 == 0 or stage == n_stages - 1):
            elapsed = time.monotonic() - t0
            print(f"    GradNest stage={stage} T={T:.1f} score={best_score:.8f} t={elapsed:.0f}s")

    return best_a, best_score


def peak_shave_cd(a0, time_limit, seed=42, verbose=False):
    """
    Coordinate descent based peak shaving.
    Identifies the max convolution peak and redistributes mass
    from high-contributing positions to low-contributing ones.
    """
    n = len(a0)
    rng = np.random.default_rng(seed)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
        s = 1.0
    a = a / s

    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()
    stall = 0

    while time.monotonic() - t0 < time_limit:
        b = fast_autocorr(a)
        k_star = int(np.argmax(b))
        M = b[k_star]

        # Find positions contributing to the peak
        js = max(0, k_star - n + 1)
        je = min(n - 1, k_star)
        idx = np.arange(js, je + 1)
        contrib = a[idx] * a[k_star - idx]
        total_contrib = contrib.sum()
        if total_contrib < 1e-15:
            break

        # Source: position with highest contribution to this peak
        src_local = idx[np.argmax(contrib)]

        # Destination: position with low contribution to ALL top peaks
        top_k = np.argsort(b)[::-1][:5]
        peak_mask = np.zeros(n, dtype=bool)
        for k2 in top_k:
            js2 = max(0, k2 - n + 1)
            je2 = min(n - 1, k2)
            peak_mask[js2:je2 + 1] = True

        candidates = np.where(~peak_mask)[0]
        if len(candidates) == 0:
            candidates = np.where(np.arange(n) != src_local)[0]

        # Pick destination with lowest value among candidates
        dst = candidates[np.argmin(a[candidates])]

        if a[src_local] < 1e-12:
            stall += 1
            if stall > 500:
                break
            # Random perturbation
            i = rng.integers(n)
            j = rng.integers(n)
            if i != j and a[i] > 1e-10:
                amt = a[i] * rng.uniform(0.005, 0.02)
                a_trial = a.copy()
                a_trial[i] -= amt
                a_trial[j] += amt
                s_t = a_trial.sum()
                if s_t > 1e-15:
                    a_trial = a_trial / s_t
                    score = fast_autocorr(a_trial).max()
                    if score < best_score:
                        a = a_trial
                        best_score = score
                        best_a = a.copy()
                        stall = 0
            continue

        # Try different transfer fractions
        improved = False
        for frac in [0.001, 0.003, 0.01, 0.03, 0.1]:
            amt = a[src_local] * frac
            if amt < 1e-15:
                continue
            a_trial = a.copy()
            a_trial[src_local] -= amt
            a_trial[dst] += amt
            if a_trial[src_local] < 0:
                continue
            s_t = a_trial.sum()
            if s_t < 1e-15:
                continue
            a_trial = a_trial / s_t
            score = fast_autocorr(a_trial).max()
            if score < best_score - 1e-12:
                a = a_trial
                best_score = score
                best_a = a.copy()
                improved = True
                stall = 0
                break

        if not improved:
            stall += 1
            # Try multiple destinations
            tried = 0
            while tried < 20 and not improved:
                dst2 = rng.integers(n)
                if dst2 == src_local:
                    tried += 1
                    continue
                for frac in [0.005, 0.02, 0.05]:
                    amt = a[src_local] * frac
                    if amt < 1e-15:
                        break
                    a_trial = a.copy()
                    a_trial[src_local] -= amt
                    a_trial[dst2] += amt
                    if a_trial[src_local] < 0:
                        break
                    s_t = a_trial.sum()
                    if s_t < 1e-15:
                        break
                    a_trial = a_trial / s_t
                    score = fast_autocorr(a_trial).max()
                    if score < best_score - 1e-12:
                        a = a_trial
                        best_score = score
                        best_a = a.copy()
                        improved = True
                        stall = 0
                        break
                tried += 1

            if stall > 1000:
                break

    return best_a, best_score


def interpolate_sequence(f, new_n):
    """Interpolate a normalized sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss


def structured_init(n, rng):
    """Generate a structured initial sequence."""
    choice = rng.integers(0, 6)
    x = np.linspace(0.0, 1.0, n)
    if choice == 0:
        a = np.cos(np.pi * x / 2.0) ** 2
    elif choice == 1:
        a = np.sin(np.pi * x) ** 1.5
    elif choice == 2:
        a = 0.5 + 0.3 * np.cos(2 * np.pi * 2 * x) + 0.15 * np.cos(2 * np.pi * 5 * x)
    elif choice == 3:
        a = np.exp(-8.0 * (x - 0.3) ** 2) + 0.7 * np.exp(-8.0 * (x - 0.7) ** 2)
    elif choice == 4:
        a = (1.0 - np.abs(2.0 * x - 1.0)) ** 1.5
    else:
        # Quadratic residues inspired
        a = np.ones(n)
        primes = [2, 3, 5, 7, 11, 13]
        for p in primes:
            mask = (np.arange(n) % p == 0) | (np.arange(n) % p == 1)
            a[mask] += 0.3
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s
