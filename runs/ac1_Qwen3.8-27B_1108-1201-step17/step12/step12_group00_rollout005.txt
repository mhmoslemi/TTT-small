Second term: set k-j = i, i.e., j = k-i. Then we get a_{k-i} * [0 <= k-i <= n-1]. This is a[k-i] if k-i is in range.

So both terms give the same value: a[k-i] * [0 <= k-i < n].

Therefore: ∂(a*a)_k / ∂a_i = 2 * a[k-i] * [0 <= k-i < n]

Wait, that seems too simple. Let me verify with a small example.

a = [a0, a1, a2], n=3
(a*a)_1 = a0*a1 + a1*a0 = 2*a0*a1
∂/∂a0 = 2*a1 = 2*a[1] = 2*a[1-0] ✓ (k-i = 1-0 = 1, in range)
∂/∂a1 = 2*a0 = 2*a[0] = 2*a[1-1] ✓ (k-i = 1-1 = 0, in range)
∂/∂a2 = 0 (k-i = 1-2 = -1, out of range) ✓

(a*a)_2 = a0*a2 + a1*a1 + a2*a0 = 2*a0*a2 + a1^2
∂/∂a0 = 2*a2 = 2*a[2] = 2*a[2-0] ✓
∂/∂a1 = 2*a1 = 2*a[1] = 2*a[2-1] ✓
∂/∂a2 = 2*a0 = 2*a[0] = 2*a[2-2] ✓

Great, so the formula is: ∂(a*a)_k / ∂a_i = 2 * a[k-i] if 0 <= k-i < n, else 0.

This is very simple! The subgradient of max_k (a*a)_k at point a, when the max is achieved at k*, is:
grad[i] = 2 * a[k*-i] if 0 <= k*-i < n, else 0

This is just a (reversed and shifted) copy of a, multiplied by 2!

So the subgradient is O(n) to compute. 

For the FW method:
- Step 1: Compute b = autocorr(a) (O(n log n) via FFT)
- Step 2: k* = argmax(b)
- Step 3: grad[i] = 2*a[k*-i] if 0 <= k*-i < n, else 0 (O(n))
- Step 4: v = sum(a) * e[argmin(grad)] (O(n))
- Step 5: Nesterov update (O(n))

Total per iteration: O(n log n) dominated by FFT.

For n=1600, each iteration should take ~10-50 microseconds. So in 1800 seconds, we can do ~30,000,000 iterations. That's way more than enough.

But wait, the issue is that FW with a single subgradient direction (using just k*) might not converge well. The max function is not differentiable at points where multiple k values achieve the maximum. Using just one k* can lead to oscillation.

**Better: Use the full subdifferential**

The subdifferential of f(a) = max_k (a*a)_k at point a is:
∂f(a) = conv{grad_{k} : k in argmax_k (a*a)_k}

where grad_k[i] = 2*a[k-i] if 0 <= k-i < n, else 0.

For a "generic" point, only one k achieves the max, so the subdifferential is a single point. But near the optimum, multiple k values might be close to the max.

**Practical approach**: Use a softmax-weighted average of subgradients over the top few k values:
- Let S = {top L values of b} with weights w_k = exp(b[k]/T) / sum exp(b[k']/T)
- grad = sum_{k in S} w_k * grad_k

This gives a smoother optimization direction.

**Even better: Use the LP direction**

The LP best-response gives the optimal direction in the sense of maximizing the sum while keeping the autocorrelation bounded. This is much better than the FW vertex direction.

Phase 1 (fast, 60% time): Nesterov FW with softmax subgradient
- Many fast iterations
- Update best every 100 steps

Phase 2 (medium, 25% time): Nesterov LP best-response
- Slower but more effective
- Use the best from Phase 1 as starting point

Phase 3 (polish, 10% time): Alternating LP + FW
- Short LP steps interleaved with FW steps

Phase 4 (exploration, 5% time): Try n=1800 or n=2000
- Interpolate best to new length, do a few FW iterations

def fast_autocorr(a):
    """Compute full autocorrelation using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]

def subgradient_single(a, k):
    """Compute subgradient of (a*a)_k w.r.t. a. Result is 2*a[k-i] for valid i."""
    n = len(a)
    grad = np.zeros(n)
    # grad[i] = 2*a[k-i] if 0 <= k-i < n
    # i ranges from max(0, k-n+1) to min(n-1, k)
    i_start = max(0, k - n + 1)
    i_end = min(n - 1, k)
    if i_start <= i_end:
        idx = np.arange(i_start, i_end + 1)
        grad[idx] = 2.0 * a[k - idx]
    return grad


def softmax_subgradient(a, b, top_L=5, temperature=0.1):
    """Compute softmax-weighted subgradient over top L peaks."""
    n = len(a)
    # Find top L peaks
    indices = np.argsort(b)[::-1][:top_L]
    vals = b[indices]
    # Softmax weights
    vals_norm = vals - vals.max()
    w = np.exp(vals_norm / temperature)
    w /= w.sum()
    
    grad = np.zeros(n)
    for i, k in enumerate(indices):
        grad += w[i] * subgradient_single(a, k)
    return grad


def nesterov_fw(a0, time_limit, top_L=5, temperature=0.1, verbose=True):
    """Nesterov-accelerated Frank-Wolfe with softmax subgradient."""
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s  # Normalize to sum = 1
    
    best_a = a.copy()
    best_score = fast_autocorr(a).max() * 2 * n  # J value (times 1 since sum=1)
    
    y = a.copy()
    v = a.copy()  # Nesterov velocity
    t0 = time.monotonic()
    n_iters = 0
    best_iter = 0
    
    for t in range(1, 100000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Compute autocorrelation of y
        b = fast_autocorr(y)
        max_b = b.max()
        
        # Compute subgradient
        grad = softmax_subgradient(y, b, top_L=top_L, temperature=temperature)
        
        # FW step: v = e[argmin(grad)] (the vertex minimizing <grad, v> on simplex)
        i_min = int(np.argmin(grad))
        e = np.zeros(n)
        e[i_min] = 1.0
        
        # Nesterov update
        alpha = 2.0 / (t + 2.0)
        y_new = (1.0 - alpha) * y + alpha * e
        y_new = np.maximum(y_new, 0.0)
        s_new = y_new.sum()
        if s_new < 1e-15:
            y_new = y.copy()
        else:
            y_new = y_new / s_new
        
        # Nesterov momentum
        if t == 1:
            v_new = e.copy()
        else:
            beta = (t - 1.0) / (t + 2.0)
            v_new = y_new + beta * (y_new - y)
            v_new = np.maximum(v_new, 0.0)
            s_v = v_new.sum()
            if s_v < 1e-15:
                v_new = y_new.copy()
            else:
                v_new = v_new / s_v
        
        y = y_new
        v = v_new
        n_iters += 1
        
        # Check both y and v
        score_y = fast_autocorr(y).max()
        if score_y < best_score:
            best_score = score_y
            best_a = y.copy()
            best_iter = n_iters
        
        score_v = fast_autocorr(v).max()
        if score_v < best_score:
            best_score = score_v
            best_a = v.copy()
            best_iter = n_iters
        
        if verbose and n_iters % 10000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    NFW it={n_iters} ({elapsed:.0f}s): best_J={2*n*best_score:.8f}")
    
    return best_a, 2 * n * best_score


def build_conv_matrix(a):
    """Build the convolution matrix T where (T @ b)[k] = (a*b)_k."""
    n = len(a)
    T = np.zeros((2 * n - 1, n))
    for j in range(n):
        T[j:j + n, j] = a
    return T


def lp_best_response(a, M, solver):
    """Solve LP: max sum(b) s.t. T @ b <= M, b >= 0."""
    n = len(a)
    b_var = cp.Variable(n, nonneg=True)
    T = build_conv_matrix(a)
    constraints = [T @ b_var <= M]
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        return None
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None
    b_val = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
    if b_val.sum() < 1e-15:
        return None
    return b_val / b_val.sum()

def mirror_descent(a0, time_limit, eta0=0.1, verbose=True):
    """Mirror descent (multiplicative weights) for the softmax-smoothed objective."""
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()
    
    for t in range(1, 100000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        b = fast_autocorr(a)
        grad = softmax_subgradient(a, b, top_L=5, temperature=0.05)
        
        # Multiplicative update
        eta = eta0 / (1.0 + t * 0.01)
        a = a * np.exp(-eta * grad / grad.max())
        a = np.maximum(a, 1e-30)
        s = a.sum()
        if s < 1e-15:
            a = np.ones(n) / n
        else:
            a = a / s
        
        score = fast_autocorr(a).max()
        if score < best_score:
            best_score = score
            best_a = a.copy()
        
        if verbose and t % 10000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    MD it={t} ({elapsed:.0f}s): best_J={2*n*best_score:.8f}")
    
    return best_a, 2 * n * best_score


def peak_shave(a, time_limit, seed=42):
    """Spectral peak shaving: move mass from peak-contributing to non-contributing positions."""
    n = len(a)
    rng = np.random.default_rng(seed)
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / a.sum()
    
    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    t0 = time.monotonic()
    stall = 0
    
    while time.monotonic() - t0 < time_limit:
        b = fast_autocorr(a)
        top_k = np.argsort(b)[::-1][:5]
        
        improved = False
        for k in top_k:
            # Find which (i, k-i) pairs contribute most to b[k]
            i_start = max(0, k - n + 1)
            i_end = min(n - 1, k)
            idx = np.arange(i_start, i_end + 1)
            contrib = a[idx] * a[k - idx]
            
            # Source: position with max contribution
            src_i = idx[np.argmax(contrib)]
            src_j = k - src_i  # The other position in the pair
            
            # Destination: position with low contribution to ALL top peaks
            peak_involvement = np.zeros(n)
            for k2 in top_k:
                i2_start = max(0, k2 - n + 1)
                i2_end = min(n - 1, k2)
                idx2 = np.arange(i2_start, i2_end + 1)
                peak_involvement[idx2] += a[idx2] * a[k2 - idx2]
            
            # Pick destination with lowest involvement and not src
            peak_involvement[src_i] = np.inf
            peak_involvement[src_j] = np.inf
            candidates = np.argsort(peak_involvement)[:n // 10]
            
            if len(candidates) == 0:
                candidates = np.array([0])
            
            for frac in [0.001, 0.005, 0.01, 0.02, 0.05]:
                dst = candidates[rng.integers(len(candidates))]
                if dst == src_i or dst == src_j:
                    continue
                amt = a[src_i] * frac
                if amt < 1e-20:
                    continue
                a_trial = a.copy()
                a_trial[src_i] -= amt
                a_trial[dst] += amt
                if a_trial[src_i] < 0:
                    continue
                a_trial = a_trial / a_trial.sum()
                score = fast_autocorr(a_trial).max()
                if score < best_score:
                    a = a_trial
                    best_score = score
                    best_a = a.copy()
                    improved = True
                    stall = 0
                    break
            if improved:
                break
        
        if not improved:
            # Random perturbation
            i = rng.integers(n)
            j = rng.integers(n)
            if i != j and a[i] > 1e-10:
                frac = rng.uniform(0.01, 0.05)
                amt = a[i] * frac
                a_trial = a.copy()
                a_trial[i] -= amt
                a_trial[j] += amt
                if a_trial[i] >= 0:
                    a_trial = a_trial / a_trial.sum()
                    score = fast_autocorr(a_trial).max()
                    if score < best_score:
                        a = a_trial
                        best_score = score
                        best_a = a.copy()
                        stall = 0
            
            stall += 1
            if stall > 500:
                break
    
    return best_a, 2 * n * best_score


def interpolate_to_length(a, new_n):
    """Interpolate sequence to new length."""
    old_n = len(a)
    if old_n == new_n:
        return a.copy()
    s = a.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    a_norm = a / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    a_interp = np.interp(new_x, old_x, a_norm)
    a_interp = np.maximum(a_interp, 0.0)
    s_new = a_interp.sum()
    if s_new < 1e-15:
        return np.ones(new_n) / new_n
    return a_interp / s_new
