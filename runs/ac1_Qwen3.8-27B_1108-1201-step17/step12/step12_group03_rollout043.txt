   So the max is about 1.5x the average. We need to bring it closer to average.

4. "Flatten" operation: for each peak k that's above target, reduce the contributing pairs.
   This is like a water-filling algorithm.

**Approach II: Use the duality**

The problem min max_k c_k(a) s.t. sum(a)=1, a>=0 has a Lagrangian dual. The dual variables correspond to the peaks. At the optimum, only the active peaks have non-zero dual variables.

The dual problem is:
max sum_k lambda_k - (1/4) * ||sum_k lambda_k * grad_k||^2 (approximately)
s.t. lambda_k >= 0

This is getting complicated. Let me just focus on practical algorithms.

**My plan:**

1. Start from parent sequence
2. **Main optimization: Smoothed subgradient descent with Nesterov momentum**
   - Use softmax smoothing: f_beta(a) = (1/beta) * log(sum_k exp(beta * c_k(a)))
   - Gradient: g_i = (1/beta) * sum_k [exp(beta*c_k) / sum_j exp(beta*c_j)] * 2*a[k-i] (if valid)
   - Nesterov momentum + simplex projection
   - Adapt beta: start small (smooth), increase over time (sharper)
   
3. **Mirror descent phase** (multiplicative weights)
   - Better for the non-negativity constraint
   - Use the same smoothed gradient
   
4. **Active set QP** (improved version)
   - Use more active constraints
   - Use a proper QP solver
   - Multiple iterations with active set updates
   
5. **Coordinate descent with line search**
   - For each coordinate, find the optimal value given others
   - Use the structure that changing a_i only affects peaks k in range [i, i+n-1]

6. **Multi-length exploration**
   - Try slightly different lengths
   - Interpolate and re-optimize

7. **Simulated annealing / random restarts**
   - Occasionally perturb the sequence
   - Accept if improvement in a smoothed objective

Let me now code this up. I'll focus on making the algorithms efficient and well-tuned.

Key efficiency considerations:
- Use FFT for computing convolutions (already in the parent code)
- For the gradient, we need to compute weighted shifts of a, which can be done efficiently
- For the QP, keep the active set small

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Smoothed subgradient descent with Nesterov momentum and adaptive beta
2. Mirror descent (multiplicative weights) with peak-weighted gradient
3. Active set QP refinement with iterative constraint updates
4. Coordinate descent with exact line search on the convolution peaks
5. Multi-scale (coarsen-refine) exploration
6. Simulated annealing for escaping local minima
"""

import numpy as np
import cvxpy as cp
import time
from scipy.fft import rfft, irfft


def fast_autocorr(a):
    """Full linear convolution a*a using FFT. Returns array of length 2n-1."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), n=fft_size)
    return irfft(A * A, n=fft_size)[:size]


def evaluate_safe(a):
    """Safely evaluate using the global evaluate_sequence."""
    try:
        a_list = [float(max(0.0, min(1000.0, x))) for x in a]
        sc = evaluate_sequence(a_list)
        return float(sc)
    except Exception:
        return float('inf')


def project_simplex(v):
    """Project vector v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)


def fast_gradient(a, peaks, weights):
    """
    Compute the gradient of sum_k w_k * c_k(a) where c_k = (a*a)_k.
    Gradient w.r.t. a[i] = 2 * sum_k w_k * a[k-i] (if 0 <= k-i < n).
    Efficient computation using the structure.
    """
    n = len(a)
    grad = np.zeros(n)
    for k, w in zip(peaks, weights):
        # grad[i] += 2*w*a[k-i] for valid i
        # k-i in [0, n-1] means i in [k-n+1, k] intersect [0, n-1]
        i_start = max(0, k - n + 1)
        i_end = min(n - 1, k)
        if i_start <= i_end:
            # a[k-i] for i in [i_start, i_end]
            # k-i ranges from k-i_start to k-i_end
            idx = np.arange(k - i_end, k - i_start + 1)
            grad[i_start:i_end+1] += 2 * w * a[idx]
    return grad


def fast_gradient_smoothed(a, beta, n_top):
    """
    Compute gradient of the smoothed objective (1/beta)*log(sum_k exp(beta*c_k)).
    Use only top n_top peaks for efficiency.
    """
    n = len(a)
    c = fast_autocorr(a)
    max_c = c.max()
    # Softmax weights (only for top peaks to save time)
    c_shifted = c - max_c
    exp_c = np.exp(c_shifted * beta)
    total = exp_c.sum()
    if total < 1e-300:
        weights = np.ones(len(c)) / len(c)
    else:
        weights = exp_c / total
    
    # Use top peaks
    top_idx = np.argsort(c)[::-1][:n_top]
    top_w = weights[top_idx]
    top_w = top_w / top_w.sum()  # renormalize
    
    return fast_gradient(a, top_idx, top_w)


def smoothed_subgradient_nesterov(a0, time_limit, beta_start=50, beta_end=500, n_top=50, verbose=True):
    """
    Smoothed subgradient descent with Nesterov momentum.
    Minimize f_beta(a) = (1/beta)*log(sum_k exp(beta * c_k(a))) on the simplex.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    a = a / s
    
    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    
    t0 = time.monotonic()
    t_iter = 0
    prev_a = a.copy()
    y = a.copy()
    
    # Nesterov parameters
    L = 4.0 * n  # Rough Lipschitz constant estimate
    eta0 = 1.0 / L
    
    for t in range(1, 100000):
        if time.monotonic() - t0 > time_limit:
            break
        t_iter = t
        
        # Adaptive beta: increase over time
        frac = min(1.0, t / 5000)
        beta = beta_start * (beta_end / beta_start) ** frac
        
        # Nesterov extrapolation
        momentum = (t - 1.0) / (t + 2.0)
        y = a + momentum * (a - prev_a)
        y = np.maximum(y, 0)
        y_s = y.sum()
        if y_s < 1e-15:
            y = a.copy()
        else:
            y = y / y_s
        
        # Compute smoothed gradient at y
        grad = fast_gradient_smoothed(y, beta, n_top)
        
        # Step size: eta = 1/(L*t) or adaptive
        eta = eta0 / (1 + t * 0.01)
        
        # Gradient step
        a_new = y - eta * grad
        a_new = project_simplex(a_new)
        
        prev_a = a
        a = a_new
        
        # Evaluate
        score = 2.0 * n * fast_autocorr(a).max()
        if score < best_score:
            best_score = score
            best_a = a.copy()
        
        if verbose and t % 200 == 0:
            elapsed = time.monotonic() - t0
            print(f"    SSGD t={t} ({elapsed:.0f}s): beta={beta:.0f}, score={score:.6f}, best={best_score:.6f}")
    
    return best_a, best_score


def mirror_descent_v2(a0, time_limit, lr_start=0.5, lr_end=0.01, n_top=30, beta=10, verbose=True):
    """
    Mirror descent (multiplicative weights) with smoothed peak weighting.
    a_new[i] ∝ a[i] * exp(-lr * grad[i])
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    a = a / s
    
    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    
    t0 = time.monotonic()
    stall = 0
    max_stall = 2000
    
    for it in range(50000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Learning rate: decay
        lr = lr_start * (lr_end / lr_start) ** (it / 10000)
        
        # Compute smoothed gradient
        c = fast_autocorr(a)
        max_c = c.max()
        
        # Softmax weights for top peaks
        top_idx = np.argsort(c)[::-1][:n_top]
        top_c = c[top_idx]
        w = np.exp((top_c - max_c) * beta)
        w = w / w.sum()
        
        grad = fast_gradient(a, top_idx, w)
        
        # Mirror descent step
        log_a = np.log(np.maximum(a, 1e-30))
        log_a_new = log_a - lr * grad
        log_a_new -= log_a_new.max()
        a_new = np.exp(log_a_new)
        a_new_s = a_new.sum()
        if a_new_s < 1e-30:
            a_new = a.copy()
            a_new_s = 1.0
        a_new = a_new / a_new_s
        
        # Score
        score = 2.0 * n * fast_autocorr(a_new).max()
        if score < best_score:
            best_score = score
            best_a = a_new.copy()
            stall = 0
        else:
            stall += 1
        
        a = a_new
        
        if verbose and it % 500 == 0:
            elapsed = time.monotonic() - t0
            print(f"    MD2 it={it} ({elapsed:.0f}s): score={score:.6f}, best={best_score:.6f}")
        
        if stall > max_stall:
            # Reset with perturbation
            a = best_a + 0.01 * np.random.default_rng(it).normal(size=n)
            a = np.maximum(a, 0)
            a = a / a.sum()
            stall = 0
    
    return best_a, best_score


def active_set_qp_v2(a0, time_limit, n_active_max=50, n_rounds=30, verbose=True):
    """
    Active set QP: iteratively identify active constraints and solve QP.
    min M s.t. (a*a)_k <= M for active k, sum(a)=1, a>=0
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    a = a / s
    
    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()
    
    for round_num in range(n_rounds):
        if time.monotonic() - t0 > time_limit:
            break
        
        c = fast_autocorr(a)
        max_c = c.max()
        
        # Active set: peaks within 1% of max (up to n_active_max)
        threshold = max_c * 0.99
        active = np.where(c >= threshold)[0]
        if len(active) > n_active_max:
            active = np.argsort(c)[::-1][:n_active_max]
        
        # Build and solve QP
        a_var = cp.Variable(n, nonneg=True)
        M_var = cp.Variable()
        constraints = [cp.sum(a_var) == 1, M_var >= 0]
        
        for k in active:
            i_start = max(0, k - n + 1)
            i_end = min(n - 1, k)
            if i_start > i_end:
                continue
            idx = np.arange(i_start, i_end + 1)
            other = k - idx
            q_expr = cp.sum(a_var[idx] * a_var[other])
            constraints.append(q_expr <= M_var)
        
        prob = cp.Problem(cp.Minimize(M_var), constraints)
        
        solved = False
        for solver in [cp.CLARABEL, cp.ECOS, cp.SCS]:
            try:
                prob.solve(solver=solver, max_iter=20000)
                if prob.status in ('optimal', 'optimal_inaccurate'):
                    solved = True
                    break
            except Exception:
                continue
        
        if not solved:
            if round_num > 5:
                break
            continue
        
        a_new = np.asarray(a_var.value, dtype=np.float64)
        a_new = np.maximum(a_new, 0)
        a_new_s = a_new.sum()
        if a_new_s < 1e-15:
            break
        a_new = a_new / a_new_s
        
        score = 2.0 * n * fast_autocorr(a_new).max()
        
        if score < best_score:
            best_score = score
            best_a = a_new.copy()
            a = a_new
            if verbose:
                print(f"    QP round {round_num}: improved to {best_score:.6f} (M={M_var.value:.8f})")
        else:
            # Try mixing
            improved = False
            for frac in [0.2, 0.5, 0.8]:
                a_mix = (1 - frac) * a + frac * a_new
                a_mix = np.maximum(a_mix, 0)
                a_mix_s = a_mix.sum()
                if a_mix_s < 1e-15:
                    continue
                a_mix = a_mix / a_mix_s
                score_mix = 2.0 * n * fast_autocorr(a_mix).max()
                if score_mix < best_score:
                    best_score = score_mix
                    best_a = a_mix.copy()
                    a = a_mix
                    improved = True
                    if verbose:
                        print(f"    QP mix {frac}: improved to {best_score:.6f}")
                    break
            
            if not improved and round_num > 5:
                break
            if not improved:
                # Widen active set
                n_active_max = min(n_active_max * 2, 100)
    
    return best_a, best_score


def coordinate_descent_v2(a0, time_limit, n_sweeps=100, verbose=True):
    """
    Coordinate descent: for each coordinate i, find optimal value
    that minimizes the max peak, given all other coordinates fixed.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    a = a / s
    
    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()
    
    # Precompute: for each coordinate i, which peaks k does it affect?
    # a[i] affects c[k] for k in [i, i+n-1] (since c[k] involves a[j]*a[k-j]
    # and a[i] appears when j=i or k-j=i)
    
    for sweep in range(n_sweeps):
        if time.monotonic() - t0 > time_limit:
            break
        
        c = fast_autocorr(a)
        max_c = c.max()
        
        # Process coordinates in order of their "importance" (contribution to max peak)
        # For simplicity, just sweep in order
        improved = False
        for i in range(n):
            if time.monotonic() - t0 > time_limit:
                break
            
            # Current value
            a_old = a[i]
            if a_old < 1e-15:
                continue
            
            # Try different values for a[i]
            # The peaks affected are k in [max(0, i), min(2n-2, i+n-1)]
            # Actually, a[i] appears in c[k] when k-i in [0,n-1], i.e., k in [i, i+n-1]
            # AND when i in [0,n-1] (always true) and k-i in [0,n-1]
            # So k ranges from i to i+n-1, clipped to [0, 2n-2]
            k_start = i
            k_end = min(2 * n - 2, i + n - 1)
            
            # Binary search for optimal a[i]
            # When we increase a[i], some peaks increase and some might decrease
            # (actually all affected peaks increase since a[i] > 0 and all other a[j] >= 0)
            # So the max peak is monotonically increasing in a[i] (for affected peaks)
            # But non-affected peaks stay the same
            # So there's a tradeoff: reducing a[i] reduces affected peaks but increases others
            # (because we need to maintain sum=1, so other coordinates increase)
            
            # Simple approach: try reducing a[i] by small amounts
            best_val = a_old
            best_local_score = max_c
            
            for frac in [0.5, 0.7, 0.8, 0.9, 0.95, 1.1, 1.3, 1.5]:
                new_val = a_old * frac
                if new_val < 0 or new_val > 1.0:
                    continue
                # Redistribute the difference to other coordinates proportionally
                diff = a_old - new_val
                others_mask = np.ones(n, dtype=bool)
                others_mask[i] = False
                others_sum = a[others_mask].sum()
                if others_sum < 1e-15:
                    continue
                a_trial = a.copy()
                a_trial[i] = new_val
                a_trial[others_mask] += diff * a[others_mask] / others_sum
                a_trial = np.maximum(a_trial, 0)
                a_trial_s = a_trial.sum()
                if abs(a_trial_s - 1.0) > 1e-10:
                    a_trial = a_trial / a_trial_s
                
                c_trial = fast_autocorr(a_trial)
                score = 2.0 * n * c_trial.max()
                if score < best_local_score - 1e-12:
                    best_local_score = score
                    best_val = new_val
                    a = a_trial
                    max_c = c_trial.max()
                    improved = True
            
            if best_local_score < best_score:
                best_score = best_local_score
                best_a = a.copy()
        
        if not improved and sweep > 5:
            # Try random coordinate perturbations
            rng = np.random.default_rng(sweep)
            for _ in range(20):
                i = rng.integers(0, n)
                frac = rng.uniform(0.3, 1.5)
                new_val = a[i] * frac
                if new_val < 0 or new_val > 1.0:
                    continue
                diff = a[i] - new_val
                others_mask = np.ones(n, dtype=bool)
                others_mask[i] = False
                others_sum = a[others_mask].sum()
                if others_sum < 1e-15:
                    continue
                a_trial = a.copy()
                a_trial[i] = new_val
                a_trial[others_mask] += diff * a[others_mask] / others_sum
                a_trial = np.maximum(a_trial, 0)
                a_trial = a_trial / a_trial.sum()
                score = 2.0 * n * fast_autocorr(a_trial).max()
                if score < best_score - 1e-12:
                    a = a_trial
                    best_score = score
                    best_a = a.copy()
                    improved = True
    
    return best_a, best_score


def multisccale_optimize(a0, time_limit, verbose=True):
    """
    Multi-scale: coarsen, optimize, interpolate back.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    a = a / s
    
    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()
    
    # Try several coarsening factors
    for factor in [2, 4, 3]:
        if time.monotonic() - t0 > time_limit:
            break
        
        n_coarse = n // factor
        if n_coarse < 50:
            continue
        
        # Coarsen by averaging blocks
        a_coarse = np.zeros(n_coarse)
        for j in range(n_coarse):
            a_coarse[j] = a[j*factor:(j+1)*factor].sum()
        a_coarse = a_coarse / a_coarse.sum()
        
        # Optimize the coarse sequence
        t_coarse = min(30, (time_limit - (time.monotonic() - t0)) * 0.3)
        if t_coarse < 5:
            continue
        
        a_c_out, sc_c = smoothed_subgradient_nesterov(a_coarse, t_coarse, 
                                                       beta_start=10, beta_end=100, n_top=20, verbose=False)
        
        # Interpolate back
        a_fine = np.zeros(n)
        for j in range(n_coarse):
            a_fine[j*factor:(j+1)*factor] = a_c_out[j] / factor
        a_fine = a_fine / a_fine.sum()
        
        score = 2.0 * n * fast_autocorr(a_fine).max()
        if score < best_score:
            best_score = score
            best_a = a_fine.copy()
            if verbose:
                print(f"    Multi-scale (factor={factor}): improved to {best_score:.6f}")
        
        # Also try mixing coarse-optimized with original
        for mix in [0.3, 0.5, 0.7]:
            a_mix = (1 - mix) * a + mix * a_fine
            a_mix = np.maximum(a_mix, 0)
            a_mix = a_mix / a_mix.sum()
            score_mix = 2.0 * n * fast_autocorr(a_mix).max()
            if score_mix < best_score:
                best_score = score_mix
                best_a = a_mix.copy()
                if verbose:
                    print(f"    Multi-scale mix {mix}: improved to {best_score:.6f}")
    
    return best_a, best_score


def simulated_annealing(a0, time_limit, n_restarts=10, verbose=True):
    """
    Simulated annealing: perturb the sequence and accept/reject based on score.
    """
    n = len(a0)
    rng = np.random.default_rng(42)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    a = a / s
    
    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()
    
    T = 0.1  # Initial "temperature"
    T_min = 0.001
    
    for it in range(5000):
        if time.monotonic() - t0 > time_limit:
            break
        
        T = max(T_min, T * 0.999)
        
        # Propose a perturbation
        n_perturb = rng.integers(1, max(2, n // 100))
        indices = rng.choice(n, size=n_perturb, replace=False)
        a_trial = a.copy()
        for idx in indices:
            frac = rng.uniform(0.5, 1.5)
            a_trial[idx] *= frac
        a_trial = np.maximum(a_trial, 0)
        a_trial_s = a_trial.sum()
        if a_trial_s < 1e-10:
            continue
        a_trial = a_trial / a_trial_s
        
        score = 2.0 * n * fast_autocorr(a_trial).max()
        
        # Accept if better or with probability exp(-(score - current)/T)
        current_score = 2.0 * n * fast_autocorr(a).max()
        if score < current_score:
            a = a_trial
            if score < best_score:
                best_score = score
                best_a = a.copy()
        else:
            delta = score - current_score
            if delta < 1e-10:
                a = a_trial
            else:
                prob = np.exp(-delta / T)
                if rng.uniform() < prob:
                    a = a_trial
        
        if verbose and it % 500 == 0:
            elapsed = time.monotonic() - t0
            print(f"    SA it={it} ({elapsed:.0f}s): T={T:.4f}, score={current_score:.6f}, best={best_score:.6f}")
    
    return best_a, best_score
```

```python
def fast_autocorr(a):

def project_simplex(v):
    """Project vector v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)


def fast_conv_gradient(a, peaks, weights):
    """
    Compute gradient of sum_k w_k * (a*a)_k w.r.t. a.
    grad[i] = 2 * sum_k w_k * a[k-i] for valid k-i in [0,n-1].
    """
    n = len(a)
    grad = np.zeros(n)
    for k, w in zip(peaks, weights):
        i_start = max(0, k - n + 1)
        i_end = min(n - 1, k)
        if i_start > i_end:
            continue
        idx = np.arange(k - i_end, k - i_start + 1)
        grad[i_start:i_end + 1] += 2 * w * a[idx]
    return grad

        momentum = (t - 1.0) / (t + 2.0)
        y = a + momentum * (a - prev_a)
        y = np.maximum(y, 0)

        # Gradient step + projection
        a_new = project_simplex(y - eta * grad)

        prev_a = a
        a = a_new

        score = 2.0 * n * fast_autocorr(a).max()
        if score < best_score:
            best_score = score
            best_a = a.copy()

        if verbose and t % 300 == 0:
            elapsed = time.monotonic() - t0
            print(f"    SSG t={t} ({elapsed:.0f}s): beta={beta:.0f}, score={score:.6f}, best={best_score:.6f}")

    return best_a, best_score


def mirror_descent_optimize(a0, time_limit, lr_start=0.3, lr_end=0.005,
                             n_top=25, peak_beta=8.0, verbose=True):
    """
    Mirror descent (multiplicative weights) with peak-weighted gradient.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    a = a / s

    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()
    stall = 0
    max_stall = 3000
    rng = np.random.default_rng(123)

    for it in range(80000):
        if time.monotonic() - t0 > time_limit:
            break

        lr = lr_start * (lr_end / lr_start) ** (it / max(1, int(time_limit * 5)))

        c = fast_autocorr(a)
        max_c = c.max()
        top_idx = np.argsort(c)[::-1][:n_top]
        top_c = c[top_idx]
        w = np.exp((top_c - max_c) * peak_beta)
        w = w / w.sum()

        grad = fast_conv_gradient(a, top_idx, w)

        # Mirror descent step
        log_a = np.log(np.maximum(a, 1e-30))
        log_a_new = log_a - lr * grad
        log_a_new -= log_a_new.max()
        a_new = np.exp(log_a_new)
        a_new_s = a_new.sum()
        if a_new_s < 1e-30:
            a_new = a.copy()
            a_new_s = 1.0
        a_new = a_new / a_new_s

        score = 2.0 * n * fast_autocorr(a_new).max()
        if score < best_score:
            best_score = score
            best_a = a_new.copy()
            stall = 0
        else:
            stall += 1

        a = a_new

        if stall > max_stall:
            # Perturb and restart
            a = best_a + 0.005 * rng.normal(size=n)
            a = np.maximum(a, 0)
            a = a / a.sum()
            stall = 0

        if verbose and it % 500 == 0:
            elapsed = time.monotonic() - t0
            print(f"    MD it={it} ({elapsed:.0f}s): score={score:.6f}, best={best_score:.6f}")

    return best_a, best_score


def qp_refinement(a0, time_limit, n_active_start=20, max_active=60,
                   n_rounds=50, verbose=True):
    """
    Active-set QP refinement with iterative constraint updates and mixing.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    a = a / s

    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()
    n_active = n_active_start

    for rnd in range(n_rounds):
        if time.monotonic() - t0 > time_limit:
            break

        c = fast_autocorr(a)
        max_c = c.max()

        # Active set: top peaks (up to n_active)
        # Include all peaks within 0.5% of max, capped at n_active
        threshold = max_c * 0.995
        active_all = np.where(c >= threshold)[0]
        if len(active_all) > n_active:
            active = np.argsort(c)[::-1][:n_active]
        else:
            active = active_all

        if len(active) == 0:
            break

        # Build QP
        a_var = cp.Variable(n, nonneg=True)
        M_var = cp.Variable()
        constraints = [cp.sum(a_var) == 1, M_var >= 0]

        for k in active:
            i_start = max(0, k - n + 1)
            i_end = min(n - 1, k)
            if i_start > i_end:
                continue
            idx = np.arange(i_start, i_end + 1)
            other = k - idx
            q_expr = cp.sum(a_var[idx] * a_var[other])
            constraints.append(q_expr <= M_var)

        prob = cp.Problem(cp.Minimize(M_var), constraints)
        solved = False
        for solver in [cp.CLARABEL, cp.ECOS, cp.SCS]:
            try:
                prob.solve(solver=solver, max_iter=30000)
                if prob.status in ('optimal', 'optimal_inaccurate'):
                    solved = True
                    break
            except Exception:
                continue

        if not solved:
            if rnd > 5:
                break
            continue

        a_qp = np.asarray(a_var.value, dtype=np.float64)
        a_qp = np.maximum(a_qp, 0)
        a_qp_s = a_qp.sum()
        if a_qp_s < 1e-15:
            break
        a_qp = a_qp / a_qp_s

        # Try direct and mixed updates
        best_local = best_score
        best_local_a = best_a

        score_direct = 2.0 * n * fast_autocorr(a_qp).max()
        if score_direct < best_local:
            best_local = score_direct
            best_local_a = a_qp.copy()

        for frac in [0.1, 0.2, 0.3, 0.5, 0.7, 0.9]:
            a_mix = (1 - frac) * a + frac * a_qp
            a_mix = np.maximum(a_mix, 0)
            a_mix_s = a_mix.sum()
            if a_mix_s < 1e-15:
                continue
            a_mix = a_mix / a_mix_s
            score_mix = 2.0 * n * fast_autocorr(a_mix).max()
            if score_mix < best_local:
                best_local = score_mix
                best_local_a = a_mix.copy()

        if best_local < best_score:
            best_score = best_local
            best_a = best_local_a.copy()
            a = best_local_a.copy()
            if verbose:
                print(f"    QP rnd={rnd}: score={best_score:.6f} (active={len(active)}, M={M_var.value:.6f})")
        else:
            # No improvement - widen active set or stop
            n_active = min(n_active + 5, max_active)
            if rnd > 10:
                break

    return best_a, best_score


def coord_descent_subgrad(a0, time_limit, n_sweeps=80, verbose=True):
    """
    Coordinate descent with subgradient-based updates.
    For each coordinate, take a subgradient step and project.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    a = a / s

    best_a = a.copy()
    best_score = 2.0 * n * fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(777)

    for sweep in range(n_sweeps):
        if time.monotonic() - t0 > time_limit:
            break

        c = fast_autocorr(a)
        max_c = c.max()
        improved = False

        # Focus on coordinates that contribute to top peaks
        top_peaks = np.argsort(c)[::-1][:15]
        # Find coordinates that appear in top peaks
        important_coords = set()
        for k in top_peaks:
            i_start = max(0, k - n + 1)
            i_end = min(n - 1, k)
            for i in range(i_start, i_end + 1, max(1, (i_end - i_start) // 20)):
                important_coords.add(i)

        # Process important coordinates first, then a random sample
        coords = list(important_coords)
        remaining_coords = list(set(range(n)) - set(coords))
        rng.shuffle(remaining_coords)
        coords += remaining_coords[:min(100, len(remaining_coords))]
        rng.shuffle(coords)

        for i in coords:
            if time.monotonic() - t0 > time_limit:
                break

            a_old = a[i]
            if a_old < 1e-12:
                continue

            # Try several scales
            best_val = a_old
            best_local = 2.0 * n * max_c

            for frac in [0.3, 0.5, 0.7, 0.85, 1.15, 1.3, 1.5, 2.0]:
                new_val = a_old * frac
                if new_val < 0 or new_val > 0.5:
                    continue
                diff = a_old - new_val
                if abs(diff) < 1e-15:
                    continue
                others_sum = 1.0 - a_old
                if others_sum < 1e-10:
                    continue
                a_trial = a.copy()
                a_trial[i] = new_val
                spread = diff / others_sum
                a_trial[:] += spread
                a_trial[i] = new_val  # fix the coordinate
                a_trial = np.maximum(a_trial, 0)
                a_trial_s = a_trial.sum()
                if a_trial_s < 1e-10:
                    continue
                a_trial = a_trial / a_trial_s

                c_trial = fast_autocorr(a_trial)
                score = 2.0 * n * c_trial.max()
                if score < best_local - 1e-14:
                    best_local = score
                    best_val = new_val
                    a = a_trial.copy()
                    max_c = c_trial.max()
                    improved = True

            if best_local < best_score:
                best_score = best_local
                best_a = a.copy()

        if not improved and sweep > 5:
            # Random perturbations
            for _ in range(30):
                i = rng.integers(0, n)
                frac = rng.uniform(0.4, 2.0)
                new_val = a[i] * frac
                if new_val < 0 or new_val > 0.5:
                    continue
                diff = a[i] - new_val
                others_sum = 1.0 - a[i]
                if others_sum < 1e-10:
                    continue
                a_trial = a.copy()
                a_trial[i] = new_val
                spread = diff / others_sum
                a_trial[:] += spread
                a_trial[i] = new_val
                a_trial = np.maximum(a_trial, 0)
                a_trial = a_trial / a_trial.sum()
                score = 2.0 * n * fast_autocorr(a_trial).max()
                if score < best_score - 1e-14:
                    a = a_trial
                    best_score = score
                    best_a = a.copy()
                    improved = True

            if not improved and sweep > 20:
                break

    return best_a, best_score


def interpolate_seq(f, new_n):
    """Interpolate a normalized sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp


def propose_candidate(seed=42, budget_s=1800.0):
    """
    Main search: multi-phase optimization combining LP Nesterov, smoothed
    subgradient, QP refinement, coordinate descent, and multi-length exploration.
    """
    t_global = time.monotonic()
    time_budget = min(float(budget_s) - 120.0, 1680.0)

    solver = get_lp_solver()
    print(f"Using LP solver: {solver}")
    print(f"Time budget: {time_budget:.0f}s")

    # Get parent or initialize
    best_seq = None
    best_score = float('inf')

    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            p = p / p.sum()
            p_score = evaluate_safe(p)
            best_seq = p
            best_score = p_score
            print(f"Parent: n={len(p)}, score={p_score:.6f}")
    except Exception:
        pass

    n_base = len(best_seq) if best_seq is not None else 1600

    if best_seq is None:
        n_base = 1600
        # Cosine initialization (emphasizes edges)
        x = np.linspace(0, np.pi, n_base)
        best_seq = np.cos(x / 2) ** 2
        best_seq = best_seq / best_seq.sum()
        best_score = evaluate_safe(best_seq)
        print(f"Init: n={n_base}, score={best_score:.6f}")

    def try_update(a, label):
        nonlocal best_seq, best_score
        if a is None:
            return
        a = np.maximum(np.asarray(a, dtype=np.float64), 0)
        s = a.sum()
        if s < 0.01:
            return
        sc = evaluate_safe(a)
        if np.isfinite(sc) and sc < best_score:
            best_score = sc
            best_seq = a.copy()
            elapsed = time.monotonic() - t_global
            print(f"  *** NEW BEST [{label}]: {sc:.6f} (n={len(a)}, t={elapsed:.0f}s)")

    # Phase 1: LP Nesterov (primary optimizer) - 35% of time
    remaining = time_budget - (time.monotonic() - t_global)
    t1 = min(remaining * 0.35, 550.0)
    if t1 > 60:
        print(f"\n=== Phase 1: LP Nesterov at n={n_base} (t={t1:.0f}s) ===")
        a_out, sc_out, iters = lp_nesterov_optimize(best_seq, t1, solver)
        print(f"  LPN done: {iters} iters, score={sc_out:.6f}")
        try_update(a_out, f"lpn_n{n_base}")

    # Phase 2: Smoothed subgradient - 15% of time
    remaining = time_budget - (time.monotonic() - t_global)
    t2 = min(remaining * 0.15, 200.0)
    if t2 > 30:
        print(f"\n=== Phase 2: Smoothed Subgradient (t={t2:.0f}s) ===")
        a_out, sc_out = smoothed_subgrad_optimize(
            best_seq, t2, beta_start=15, beta_end=400, n_top=40)
        print(f"  SSG done: score={sc_out:.6f}")
        try_update(a_out, "ssg")

    # Phase 3: Mirror descent - 10% of time
    remaining = time_budget - (time.monotonic() - t_global)
    t3 = min(remaining * 0.10, 150.0)
    if t3 > 20:
        print(f"\n=== Phase 3: Mirror Descent (t={t3:.0f}s) ===")
        a_out, sc_out = mirror_descent_optimize(
            best_seq, t3, lr_start=0.2, lr_end=0.003, n_top=20, peak_beta=6.0)
        print(f"  MD done: score={sc_out:.6f}")
        try_update(a_out, "mirror")

    # Phase 4: QP refinement - 15% of time
    remaining = time_budget - (time.monotonic() - t_global)
    t4 = min(remaining * 0.15, 200.0)
    if t4 > 20:
        print(f"\n=== Phase 4: QP Refinement (t={t4:.0f}s) ===")
        a_out, sc_out = qp_refinement(
            best_seq, t4, n_active_start=25, max_active=60, n_rounds=40)
        print(f"  QP done: score={sc_out:.6f}")
        try_update(a_out, "qp")

    # Phase 5: Coordinate descent - 10% of time
    remaining = time_budget - (time.monotonic() - t_global)
    t5 = min(remaining * 0.10, 150.0)
    if t5 > 15:
        print(f"\n=== Phase 5: Coordinate Descent (t={t5:.0f}s) ===")
        a_out, sc_out = coord_descent_subgrad(best_seq, t5, n_sweeps=60)
        print(f"  CD done: score={sc_out:.6f}")
        try_update(a_out, "coord")

    # Phase 6: Multi-length exploration - 10% of time
    for n_try in [n_base + 100, n_base - 100, n_base + 200]:
        if n_try < 300:
            continue
        remaining = time_budget - (time.monotonic() - t_global)
        if remaining < 80:
            break
        print(f"\n=== Phase 6: Try n={n_try} (remaining={remaining:.0f}s) ===")
        t6 = min(remaining * 0.25, 150.0)
        if t6 < 40:
            continue
        init_try = interpolate_seq(best_seq, n_try)
        a_out, sc_out, _ = lp_nesterov_optimize(init_try, t6, solver, verbose=False)
        print(f"  LP at n={n_try}: score={sc_out:.6f}")
        try_update(a_out, f"lpn_n{n_try}")

        # Quick QP on result
        remaining = time_budget - (time.monotonic() - t_global)
        if remaining > 40:
            t_q = min(remaining * 0.15, 60.0)
            if t_q > 15:
                a_q, sc_q = qp_refinement(a_out, t_q, n_active_start=20, max_active=50, n_rounds=20)
                try_update(a_q, f"qp_n{n_try}")

    # Phase 7: Final polish - remaining time
    remaining = time_budget - (time.monotonic() - t_global)
    if remaining > 20:
        print(f"\n=== Phase 7: Final Polish (remaining={remaining:.0f}s) ===")
        # QP
        t7a = min(remaining * 0.4, 80.0)
        if t7a > 10:
            a_out, sc_out = qp_refinement(
                best_seq, t7a, n_active_start=20, max_active=50, n_rounds=25)
            try_update(a_out, "final_qp")

        # Coordinate descent
        remaining = time_budget - (time.monotonic() - t_global)
        t7b = min(remaining * 0.4, 60.0)
        if t7b > 10:
            a_out, sc_out = coord_descent_subgrad(best_seq, t7b, n_sweeps=40)
            try_update(a_out, "final_coord")

        # One more short LP round
        remaining = time_budget - (time.monotonic() - t_global)
        t7c = min(remaining * 0.5, 80.0)
        if t7c > 30:
            a_out, sc_out, _ = lp_nesterov_optimize(best_seq, t7c, solver, verbose=False)
            try_update(a_out, "final_lp")

    # Final verification
    if best_seq is not None:
        fs = evaluate_safe(best_seq)
        if np.isfinite(fs):
            best_score = fs
        print(f"\nFINAL SCORE: {best_score:.6f} (n={len(best_seq)})")
    else:
        print("ERROR: No valid sequence found!")
        return [1.0]

    return [float(x) for x in best_seq]
```
