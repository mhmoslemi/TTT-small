The key helper function:
```python
def max_conv_with_coord(a, i, x, n):
    """Compute max of conv(a,a) with a[i] replaced by x, in O(n)."""
    # conv(a,a)(k) = sum_j a_j * a_{k-j}
    # With a[i] replaced by x:
    # For each k, the change is:
    #   old contribution of a[i]: a[i]*a[k-i] (if valid)
    #   new contribution: x*a[k-i] (if k-i valid)
    #   old contribution of a[k-i] (if k-i != i): a[k-i]*a[i]
    #   new contribution: a[k-i]*x
    # So delta = (x - a[i]) * (a[k-i] + a[k-i]) if k-i != i
    #          = (x-a[i])*a[k-i] + (x-a[i])*a[i] + (x-a[i])^2 if k-i == i
    #          = x^2 - a[i]^2 if k-i == i (since a[k-i] = a[i])
    
    # Let's just compute it directly in O(n) per evaluation
    b = np.zeros(2*n-1)
    ai = a[i]
    for k in range(2*n-1):
        s = 0.0
        js = max(0, k - (n-1))
        je = min(n-1, k)
        for j in range(js, je+1):
            if j == i:
                aj = x
            else:
                aj = a[j]
            kj = k - j
            if kj == i:
                bkj = x
            else:
                bkj = a[kj]
            s += aj * bkj
        b[k] = s
    return b.max()
```

                break
            
            a_i = a[i]
            # Search range for x
            lo = 0.0
            hi = max(a_i * 3, 1e-6) if a_i > 1e-12 else 1.0/n

            for _ in range(35):
                m1 = lo + (hi - lo) / 3.0
                m2 = hi - (hi - lo) / 3.0
                f1 = max_conv_after_change(b, a, i, m1, n)
                f2 = max_conv_after_change(b, a, i, m2, n)
                if f1 < f2:
                    hi = m2
                else:
                    lo = m1

                delta = x_opt - a_i
                k_start = i
                k_end = min(i + n - 1, 2*n - 2)
                j_vals = np.arange(k_end - k_start + 1)

                if 0 <= 2*i <= 2*n-2:
                    b[2*i] += delta * delta
                a[i] = x_opt
                improved = True
        
        # End of sweep: normalize and check score
        s = a.sum()
        if s > 1e-15:
            # The autocorrelation scales as 1/s^2 after normalization
            # b_new = b / s^2

            if score < best_score:

                best_a = a.copy()
            # Normalize

            b = b / (s * s)

            elapsed = time.monotonic() - t0

Let me also add one more technique: **the "anti-peak" direction**.

At any point, the gradient of the max autocorrelation (or its LSE approximation) gives a direction of steepest increase. The "anti-gradient" (negated gradient) gives a direction of steepest decrease. We can take a step in this direction (with projection onto the simplex) to make a big improvement in one shot, rather than many small coordinate updates.

This is essentially the subgradient method:
1. Compute `g = ∂max(conv(a,a))/∂a` (the subgradient).
2. Take a step: `a_new = a - η * g`.
3. Project onto the simplex: `a_new = project_simplex(a_new)`.
