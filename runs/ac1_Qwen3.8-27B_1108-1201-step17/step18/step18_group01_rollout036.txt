**Optimal control / variational approach:**

We want to minimize max_k c[k] subject to a >= 0, sum(a) = 1.

This is equivalent to: find the smallest M such that there exists a >= 0, sum(a) = 1, with c[k] <= M for all k.

The constraints c[k] <= M for all k are:

These are quadratic constraints (bilinear in a). The problem is non-convex.

However, we can use a "bisection on M" approach:
- For a given M, check if there exists a >= 0, sum(a) = 1, with c[k] <= M for all k.
- This is a feasibility problem with quadratic constraints.

One approach: use SDP relaxation. The constraint sum_i a[i]*a[k-i] <= M can be written as a quadratic form. But with 5200 variables, an SDP would be intractable.

Another approach: **iterative constraint satisfaction**.
1. Start with a feasible a (e.g., the ramp)
2. Compute c = conv(a,a)
3. Find the "most violated" constraint: k* = argmax c[k]
4. Modify a to reduce c[k*] while keeping other c[k] from increasing too much
5. Iterate

This is essentially what the MGD approach does, but I want to do it more effectively.

**Key improvement idea: "Anti-peak" updates**

For a given peak at lag k*, the contribution is c[k*] = sum_i a[i]*a[k*-i]. The "hottest" pairs are those where a[i]*a[k*-i] is largest. To reduce c[k*], we should:
- Reduce a[i] for the i values where a[i]*a[k*-i] is large
- OR reduce a[k*-i] for those i values
- But we need to add the mass somewhere that doesn't increase other c[k] values

The best place to add mass is where it contributes minimally to all c[k] values. This is like finding a "cold spot" in the sequence.

**Algorithm: "Hot-cold" transfer**
1. Compute c = conv(a,a)
2. Find hot spots: positions i where a[i] is involved in many high c[k] values
3. Find cold spots: positions j where a[j] is involved in minimally in high c[k] values
4. Transfer mass from hot to cold spots
5. Repeat

2. Compute weights: w_j = c[k_j]^p / sum_l c[k_l]^p (for some p > 0)
3. Gradient: grad[i] = sum_j w_j * d(c[k_j])/da[i] = sum_j w_j * 2*a[k_j - i] (for valid i)

1. **Momentum**: maintain a running average of the gradient
2. **Adaptive step size**: backtracking line search
3. **Better weight function**: use c[k]^p with p > 1 to focus more on the peaks
4. **Annealing**: start with large k (many lags) and small p (smooth), then reduce k and increase p

def mgd_momentum(a0, time_limit, top_k_start, top_k_end, p_start, p_end, eta0, verbose=True):
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_val = fast_autocorr(a).max()
    t0 = time.monotonic()
    
    eta = eta0
    momentum_v = np.zeros(n)
    beta = 0.9  # momentum coefficient
    patience = 0
    max_patience = 500
    iters = 0
    
    while time.monotonic() - t0 < time_limit:
        # Progress parameter: 0 at start, 1 at end
        progress = min(1.0, iters / (time_limit / 0.001))  # rough estimate
        # Or use time-based:
        elapsed = time.monotonic() - t0
        progress = min(1.0, elapsed / time_limit)
        
        top_k = int(top_k_start + (top_k_end - top_k_start) * progress)
        top_k = max(5, top_k)
        p = p_start + (p_end - p_start) * progress
        
        c = fast_autocorr(a)
        M = c.max()
        
        if M < best_val - 1e-15:
            best_val = M
            best_a = a.copy()
            patience = 0
        else:
            patience += 1
        
        if patience > max_patience:
            break
        
        # Top-k selection
        k_max = min(top_k, len(c))
        top_idx = np.argsort(c)[::-1][:k_max]
        top_vals = np.maximum(c[top_idx], 1e-30)
        w = top_vals ** p
        w_sum = w.sum()
        if w_sum < 1e-30:
            w = np.ones(k_max) / k_max
        else:
            w = w / w_sum
        
        # Gradient
        grad = np.zeros(n)
        for wi, k in zip(w, top_idx):
            ki = int(k)
            # d(c[ki])/da[i] = 2*a[ki-i] for valid i (0 <= ki-i < n)
            i_start = max(0, ki - n + 1)
            i_end = min(n, ki + 1)
            if i_start < i_end:
                idx = np.arange(i_start, i_end)
                grad[idx] += 2.0 * wi * a[ki - idx]
        
        # Momentum
        momentum_v = beta * momentum_v + (1 - beta) * grad
        # Center the gradient (remove mean to stay on simplex)
        momentum_v -= momentum_v.mean()
        
        # Step size
        gmax = np.abs(momentum_v).max()
        if gmax < 1e-15:
            break
        momentum_v = momentum_v / gmax
        
        # Backtracking line search
        a_trial = a * np.exp(-eta * momentum_v)
        a_trial = np.maximum(a_trial, 0.0)
        s = a_trial.sum()
        if s < 1e-15:
            break
        a_trial = a_trial / s
        
        M_trial = fast_autocorr(a_trial).max()
        
        # Accept if improvement, else reduce step size
        if M_trial <= M + 1e-12:
            a = a_trial
            eta = min(eta * 1.01, 0.1)  # slowly increase
        else:
            # Try smaller step
            for _ in range(10):
                eta *= 0.5
                a_trial = a * np.exp(-eta * momentum_v)
                a_trial = np.maximum(a_trial, 0.0)
                s = a_trial.sum()
                if s < 1e-15:
                    break
                a_trial = a_trial / s
                M_trial = fast_autocorr(a_trial).max()
                if M_trial <= M + 1e-12:
                    a = a_trial
                    break
            else:
                # None worked, try very small step
                eta = 0.001
                a_trial = a * np.exp(-eta * momentum_v)
                a_trial = np.maximum(a_trial, 0.0)
                a_trial = a_trial / a_trial.sum()
                a = a_trial
        
        iters += 1
        if verbose and iters % 200 == 0:
            J = 2.0 * n * best_val
            print(f"  MGD+ iter={iters} ({elapsed:.0f}s): J={J:.6f}, eta={eta:.5f}, tk={top_k}, p={p:.1f}")
    
    J = 2.0 * n * best_val
    if verbose:
        print(f"  MGD+ done: J={J:.6f}, iters={iters}")
    return best_a

def fast_autocorr(a):
    """Compute linear autocorrelation via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(np.asarray(a, dtype=np.float64), fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def norm_sum1(a):
    """Normalize to non-negative, sum=1."""
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s


def evaluate_safe(a):
    """Safely call evaluate_sequence."""
    try:
        a_arr = np.asarray(a, dtype=np.float64)
        a_list = [float(x) for x in a_arr]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')


def interpolate_sequence(f, new_n):
    """Interpolate a normalized sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss


def mgd_momentum(a0, time_limit, top_k_start=60, top_k_end=15,
                 p_start=1.0, p_end=3.0, eta0=0.05, beta=0.85,
                 verbose=True):
    """
    Multiplicative Gradient Descent with momentum and annealing.
    Anneals top_k (many->few) and weight power (smooth->peaked).
    """
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_val = fast_autocorr(a).max()
    t0 = time.monotonic()

    eta = eta0
    momentum_v = np.zeros(n)
    patience = 0
    max_patience = 600
    iters = 0
    stall_count = 0

    while time.monotonic() - t0 < time_limit:
        elapsed = time.monotonic() - t0
        progress = min(1.0, elapsed / time_limit)

        top_k = max(5, int(top_k_start + (top_k_end - top_k_start) * progress))
        p = p_start + (p_end - p_start) * progress

        c = fast_autocorr(a)
        M = c.max()

        if M < best_val - 1e-15:
            best_val = M
            best_a = a.copy()
            patience = 0
            stall_count = 0
        else:
            patience += 1

        if patience > max_patience:
            # Reset with perturbation
            rng = np.random.default_rng(iters)
            a = a * np.exp(rng.normal(0, 0.01, n))
            a = np.maximum(a, 0.0)
            a = a / a.sum()
            patience = 0
            eta = max(eta, 0.02)
            momentum_v = np.zeros(n)
            stall_count += 1
            if stall_count > 5:
                break
            continue

        k_max = min(top_k, len(c))
        top_idx = np.argsort(c)[::-1][:k_max]
        top_vals = np.maximum(c[top_idx], 1e-30)
        w = top_vals ** p
        w_sum = w.sum()
        if w_sum < 1e-30:
            w = np.ones(k_max) / k_max
        else:
            w = w / w_sum

        grad = np.zeros(n)
        for wi, k in zip(w, top_idx):
            ki = int(k)
            i_start = max(0, ki - n + 1)
            i_end = min(n, ki + 1)
            if i_start < i_end:
                idx = np.arange(i_start, i_end)
                grad[idx] += 2.0 * wi * a[ki - idx]

        momentum_v = beta * momentum_v + (1.0 - beta) * grad
        momentum_v -= momentum_v.mean()

        gmax = np.abs(momentum_v).max()
        if gmax < 1e-15:
            break
        momentum_v = momentum_v / gmax

        # Backtracking line search
        accepted = False
        eta_trial = eta
        for _ in range(12):
            a_trial = a * np.exp(-eta_trial * momentum_v)
            a_trial = np.maximum(a_trial, 0.0)
            s = a_trial.sum()
            if s < 1e-15:
                break
            a_trial = a_trial / s
            M_trial = fast_autocorr(a_trial).max()
            if M_trial <= M + 1e-10:
                a = a_trial
                accepted = True
                break
            eta_trial *= 0.5
        if not accepted:
            eta = max(0.001, eta * 0.5)
            continue
        else:
            eta = min(eta * 1.02, 0.15)

        iters += 1
        if verbose and iters % 300 == 0:
            J = 2.0 * n * best_val
            print(f"    MGD+ iter={iters} ({elapsed:.0f}s): J={J:.6f}, eta={eta:.5f}, tk={top_k}, p={p:.1f}")

    J = 2.0 * n * best_val
    if verbose:
        print(f"    MGD+ done ({time.monotonic()-t0:.0f}s): J={J:.6f}, iters={iters}")
    return best_a


def anneal_local_search(a0, time_limit, verbose=True):
    """
    Simulated annealing local search with pair-exchange and block moves.
    Uses a temperature schedule to escape local optima.
    """
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_val = fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(42)

    T_init = 0.001
    T_end = 1e-6
    iters = 0

    while time.monotonic() - t0 < time_limit:
        elapsed = time.monotonic() - t0
        progress = min(1.0, elapsed / time_limit)
        T = T_init * (T_end / T_init) ** progress

        c = fast_autocorr(a)
        M = c.max()

        if M < best_val - 1e-15:
            best_val = M
            best_a = a.copy()

        # Choose move type
        move_type = rng.integers(0, 4)

        if move_type == 0:
            # Pair exchange: move mass from i to j
            # Choose i from "hot" positions, j from "cold"
            top_lags = np.argsort(c)[::-1][:8]
            hot = np.zeros(n)
            for k in top_lags:
                ki = int(k)
                js = max(0, ki - n + 1)
                je = min(n - 1, ki)
                if js <= je:
                    idx = np.arange(js, je + 1)
                    hot[idx] += a[ki - idx]
            hot += 1e-10
            # Cold positions: low hot score
            cold_idx = np.argsort(hot)[:n // 4]
            hot_idx = np.argsort(hot)[::-1][:n // 4]
            i = int(hot_idx[rng.integers(len(hot_idx))])
            j = int(cold_idx[rng.integers(len(cold_idx))])
            if i == j or a[i] < 1e-12:
                continue
            frac = rng.uniform(0.01, 0.08)
            amt = a[i] * frac
            a_trial = a.copy()
            a_trial[i] -= amt
            a_trial[j] += amt
            a_trial = np.maximum(a_trial, 0.0)
            a_trial = a_trial / a_trial.sum()

        elif move_type == 1:
            # Block swap: swap two blocks
            bs = int(rng.integers(5, max(6, n // 200)))
            i = int(rng.integers(0, max(1, n - 2 * bs + 1)))
            j = int(rng.integers(0, max(1, n - 2 * bs + 1)))
            if abs(i - j) < bs:
                continue
            a_trial = a.copy()
            a_trial[i:i+bs], a_trial[j:j+bs] = a_trial[j:j+bs].copy(), a_trial[i:i+bs].copy()

        elif move_type == 2:
            # Smooth perturbation: multiply by exp(noise)
            noise = rng.normal(0, 0.02, n)
            a_trial = a * np.exp(noise)
            a_trial = np.maximum(a_trial, 0.0)
            a_trial = a_trial / a_trial.sum()

        else:
            # Triple move: i loses, j and k gain
            top_lags = np.argsort(c)[::-1][:5]
            hot = np.zeros(n)
            for k in top_lags:
                ki = int(k)
                js = max(0, ki - n + 1)
                je = min(n - 1, ki)
                if js <= je:
                    idx = np.arange(js, je + 1)
                    hot[idx] += a[ki - idx]
            i = int(np.argmax(hot * a))
            if a[i] < 1e-10:
                continue
            j = int(rng.integers(n))
            k = int(rng.integers(n))
            if j == i or k == i or j == k:
                continue
            frac = rng.uniform(0.01, 0.05)
            amt = a[i] * frac
            a_trial = a.copy()
            a_trial[i] -= amt
            a_trial[j] += amt * 0.5
            a_trial[k] += amt * 0.5
            a_trial = np.maximum(a_trial, 0.0)
            a_trial = a_trial / a_trial.sum()

        M_trial = fast_autocorr(a_trial).max()
        delta = M_trial - M
        # Metropolis criterion
        if delta < 0 or rng.random() < np.exp(-delta / max(T, 1e-15)):
            a = a_trial

        iters += 1
        if verbose and iters % 500 == 0:
            J = 2.0 * n * best_val
            print(f"    Anneal iter={iters} ({elapsed:.0f}s): J={J:.6f}, T={T:.2e}")

    J = 2.0 * n * best_val
    if verbose:
        print(f"    Anneal done ({time.monotonic()-t0:.0f}s): J={J:.6f}")
    return best_a


def coord_polish(a0, time_limit, verbose=True):
    """
    Coordinate descent: systematically try moving mass from each position.
    """
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_val = fast_autocorr(a).max()
    t0 = time.monotonic()
    iters = 0

    while time.monotonic() - t0 < time_limit:
        c = fast_autocorr(a)
        M = c.max()
        improved = False

        # Focus on top peaks
        top_k = np.argsort(c)[::-1][:10]

        for k in top_k:
            if time.monotonic() - t0 > time_limit:
                break
            ki = int(k)
            js = max(0, ki - n + 1)
            je = min(n - 1, ki)
            if js > je:
                continue
            idx = np.arange(js, je + 1)
            contrib = a[idx] * a[ki - idx]
            if contrib.max() < 1e-20:
                continue
            src = idx[np.argmax(contrib)]
            src_val = a[src]
            if src_val < 1e-12:
                continue

            # Find best destination: minimize impact on autocorrelation
            # Score each position by its contribution to top peaks
            peak_impact = np.zeros(n)
            for k2 in top_k[:6]:
                k2i = int(k2)
                s2 = max(0, k2i - n + 1)
                e2 = min(n - 1, k2i)
                if s2 <= e2:
                    idx2 = np.arange(s2, e2 + 1)
                    peak_impact[idx2] += a[k2i - idx2]
                    peak_impact[k2i - idx2] += a[idx2]

            # Exclude positions already in peak regions
            in_peak = np.zeros(n, dtype=bool)
            for k2 in top_k[:6]:
                k2i = int(k2)
                s2 = max(0, k2i - n + 1)
                e2 = min(n - 1, k2i)
                if s2 <= e2:
                    in_peak[s2:e2+1] = True

            candidates = np.where(~in_peak)[0]
            if len(candidates) == 0:
                candidates = np.arange(n)
            dst = candidates[np.argmin(peak_impact[candidates])]
            if dst == src:
                continue

            for frac in [0.01, 0.02, 0.04, 0.08]:
                amt = src_val * frac
                a_trial = a.copy()
                a_trial[src] -= amt
                a_trial[dst] += amt
                a_trial = np.maximum(a_trial, 0.0)
                s_t = a_trial.sum()
                if s_t < 1e-15:
                    break
                a_trial = a_trial / s_t
                M_trial = fast_autocorr(a_trial).max()
                if M_trial < best_val - 1e-16:
                    a = a_trial
                    best_val = M_trial
                    best_a = a.copy()
                    improved = True
                    break

        if not improved:
            # Try random moves
            for _ in range(5):
                i = int(np.random.randint(n))
                j = int(np.random.randint(n))
                if i != j and a[i] > 1e-10:
                    frac = np.random.uniform(0.005, 0.03)
                    amt = a[i] * frac
                    a_trial = a.copy()
                    a_trial[i] -= amt
                    a_trial[j] += amt
                    a_trial = np.maximum(a_trial, 0.0)
                    a_trial = a_trial / a_trial.sum()
                    M_trial = fast_autocorr(a_trial).max()
                    if M_trial < best_val:
                        a = a_trial
                        best_val = M_trial
                        best_a = a.copy()
                        improved = True
                        break

        iters += 1
        if not improved and iters % 50 == 0:
            break

        if verbose and iters % 20 == 0:
            J = 2.0 * n * best_val
            print(f"    Coord iter={iters} ({time.monotonic()-t0:.0f}s): J={J:.6f}")

    J = 2.0 * n * best_val
    if verbose:
        print(f"    Coord done ({time.monotonic()-t0:.0f}s): J={J:.6f}")
    return best_a
