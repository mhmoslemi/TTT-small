Let me also think about the peak shaving more carefully. The idea is:
1. Compute b = conv(a, a).
2. Find the top P peaks (e.g., P=20).
3. For each peak at lag k, the "energy" is b[k] = sum_i a[i]*a[k-i].
4. To reduce b[k], we want to decrease the products a[i]*a[k-i] for the pairs (i, k-i) that contribute most.
5. We can do this by:
   a. Reducing a at positions that appear in many top peaks.
   b. Moving mass to positions that don't appear in any top peak.
6. The challenge is to do this without increasing other peaks.

A simple peak shaving step:
- For the worst peak at lag k*, find the position i* that maximizes a[i*]*a[k*-i*].
- Reduce a[i*] by a small amount.
- Add the mass to a position j* that minimizes the increase in all top peaks.
- Check if the overall max_b decreased.

This is O(n*P) per step, which is fast enough.

def fast_autocorr(a):

def norm_sum1(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s

def lse_smoothing_value(ac, tau):
    """Compute LSE approximation of max(ac)."""
    ac_scaled = ac / tau
    ac_scaled = ac_scaled - ac_scaled.max()
    return tau * np.log(np.sum(np.exp(ac_scaled)))

def lse_gradient(a, ac, tau):
    """Gradient of LSE(ac, tau) w.r.t. a."""
    n = len(a)
    ac_scaled = ac / tau
    ac_scaled = ac_scaled - ac_scaled.max()
    p = np.exp(ac_scaled)
    p = p / p.sum()
    
    # grad[i] = 2 * sum_j p[i+j] * a[j] (approximately)
    a_flip = a[::-1]
    size = len(ac)
    fft_size = 1 << (size - 1).bit_length()
    Af = np.fft.rfft(a_flip, fft_size)
    Pf = np.fft.rfft(p, fft_size)
    conv_full = np.fft.irfft(Af * Pf, fft_size)
    grad = 2.0 * conv_full[n-1:n-1+n]
    return np.maximum(grad, 0.0)

def simplex_project(v):
    """Project v onto the probability simplex {x >= 0, sum x = 1}."""
    n = len(v)
    if v.sum() <= 1:
        # Already in the simplex (if all non-negative)
        v = np.maximum(v, 0)
        s = v.sum()
        if s > 1e-15:
            return v / s
        return np.ones(n) / n
    # Standard projection
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.where(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1)
    return np.maximum(v - theta, 0)
