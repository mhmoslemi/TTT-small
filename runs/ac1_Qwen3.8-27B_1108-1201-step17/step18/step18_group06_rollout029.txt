Let me be careful about the gradient computation. The objective is:
J(a) = 2n * max_k c[k] / (sum a)^2

where c[k] = sum_j a[j] a[k-j].

If we normalize sum(a) = 1 (which is WLOG due to scale invariance), then:
J(a) = 2n * max_k c[k]

And we want to minimize max_k c[k] subject to a >= 0, sum(a) = 1.

The subgradient of max_k c[k] with respect to a[i] is:
d max_k c[k] / d a[i] = sum_{k: c[k] = max} (dc[k]/da[i])

where dc[k]/da[i] = sum of a[k-i] + a[i-k]... wait, let me be more careful.

c[k] = sum_j a[j] a[k-j]
dc[k]/da[i] = a[k-i] (from the first factor, when j=i) + a[i-k] (from the second factor, when k-j=i, i.e., j=k-i)

Wait, but we need to be careful about the range of j. c[k] = sum_{j: 0<=j<=n-1, 0<=k-j<=n-1} a[j] a[k-j].

dc[k]/da[i] = a[k-i] (if 0<=k-i<=n-1) + a[i-k] (if 0<=i-k<=n-1, i.e., k<=i<=k+n-1)

But since i is in [0, n-1] and k is in [0, 2n-2]:
- a[k-i] is valid when 0 <= k-i <= n-1, i.e., k-n+1 <= i <= k
- a[i-k] is valid when 0 <= i-k <= n-1, i.e., k <= i <= k+n-1

So dc[k]/da[i] = [0<=k-i<=n-1] * a[k-i] + [0<=i-k<=n-1] * a[i-k]

Note that [0<=k-i<=n-1] and [0<=i-k<=n-1] are not mutually exclusive (they overlap when k-i=0, i.e., i=k, but only if k is in [0,n-1]).

When i=k (and k in [0,n-1]): dc[k]/da[k] = a[0] + a[0] = 2a[0].
When i != k: at most one of the two terms is non-zero.

For the subgradient of max: if multiple k's achieve the maximum, we can average or use softmax weighting.

Let me code this up efficiently. For a given set of "active" lags (those with c[k] close to the max), the gradient is:

grad[i] = sum_{k in active} w_k * (dc[k]/da[i])
       = sum_{k in active} w_k * ([0<=k-i<=n-1]*a[k-i] + [0<=i-k<=n-1]*a[i-k])

For each active lag k, the contribution to grad[i] is:
- a[k-i] for i in [max(0, k-n+1), min(n-1, k)]
- a[i-k] for i in [max(0, k), min(n-1, k+n-1)]

Since k is in [0, 2n-2]:
- First term: i from max(0, k-n+1) to min(n-1, k), value a[k-i]
- Second term: i from max(0, k) to min(n-1, k+n-1), value a[i-k]

For k in [0, n-1]:
- First term: i from 0 to k, value a[k-i] (which is a reversed copy of a[0..k])
- Second term: i from k to n-1, value a[i-k] (which is a copy of a[0..n-1-k])

For k in [n, 2n-2]:
- First term: i from k-n+1 to n-1, value a[k-i] (which is a[k-n+1..n-1] reversed... wait)
  a[k-i] for i from k-n+1 to n-1: k-i goes from n-1 down to k-(n-1) = k-n+1. So it's a[k-n+1], a[k-n+2], ..., a[n-1].
- Second term: i from k to min(n-1, k+n-1) = n-1 (since k <= 2n-2, k+n-1 >= n-1). So i from k to n-1, value a[i-k] = a[0], a[1], ..., a[n-1-k].

This is all O(n) per active lag, and with K active lags, the total is O(K*n). With FFT, computing the autocorrelation is O(n log n). So each gradient step is O(K*n + n log n).

"""
Minimizes 2*n*max(convolve(a,a))/(sum(a))^2 using:
1. Parametric shape search (power law, exponential, two-phase) to find good init
2. Key insight: linear ramp (a[j]=j+1) gives J≈4/3, far better than sub-linear
3. Nesterov mirror descent with proper convolution gradient
4. Peak-shaving: directly target the argmax lag to reduce it
5. Multi-length exploration and final polishing

import numpy as np
import time


def fast_autocorr(a):
    """Compute full linear convolution a*a via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a.astype(np.float64), fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def eval_J(a):
    """Compute the objective J = 2*n*max_b/(sum_a)^2 directly."""
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    ac = fast_autocorr(a)
    return float(2.0 * n * ac.max() / (s * s))


def norm_sum1(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s


def make_power_law(n, p):
    x = np.arange(1, n + 1, dtype=np.float64)
    return x ** p


def make_exp_ramp(n, rate):
    x = np.linspace(0, 1, n)
    return np.exp(rate * x)


def make_two_phase(n, frac, alpha):
    x = np.linspace(0, 1, n)
    a = np.ones(n)
    mask = x > frac
    a[mask] = 1.0 + alpha * (x[mask] - frac) / max(1 - frac, 1e-10)
    return a


def make_sin_ramp(n):
    x = np.linspace(0.5, n + 0.5, n)
    return np.sin(np.pi * x / (n + 1))


def compute_conv_grad(a, ac, active_lags):
    """
    Compute gradient of sum_{k in active} w_k * c[k] wrt a.
    c[k] = sum_j a[j]*a[k-j], dc[k]/da[i] = a[k-i] + a[i-k] (when valid).
    """
    n = len(a)
    grad = np.zeros(n)
    for k in active_lags:
        ki = int(k)
        # First term: a[k-i] for i in [max(0,ki-n+1), min(n-1,ki)]
        lo1 = max(0, ki - n + 1)
        hi1 = min(n - 1, ki)
        if lo1 <= hi1:
            idx = np.arange(lo1, hi1 + 1)
            grad[idx] += a[ki - idx]
        # Second term: a[i-k] for i in [max(0,ki), min(n-1,ki+n-1)]
        lo2 = max(0, ki)
        hi2 = min(n - 1, ki + n - 1)
        if lo2 <= hi2:
            idx = np.arange(lo2, hi2 + 1)
            grad[idx] += a[idx - ki]
    return grad


def grad_optimize(a0, time_limit, top_k=30, c0=3.0, restart_every=3000,
                  verbose=False, rng_seed=42):
    """Nesterov mirror descent minimizing max autocorrelation peak."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.time()
    rng = np.random.default_rng(rng_seed)

    x = a.copy()
    x_prev = a.copy()
    stale = 0
    restart_count = 0

    for t in range(1, 50000000):
        if time.time() - t0 > time_limit:
            break

        beta = (t - 1.0) / (t + 2.0)
        y = x + beta * (x - x_prev)
        y = np.maximum(y, 1e-15)
        sy = y.sum()
        if sy < 1e-15:
            y = x.copy()
        else:
            y = y / sy

        ac = fast_autocorr(y)
        M = ac.max()

        # Find active lags (top k or those within 1% of max)
        threshold = M * 0.999
        active = np.where(ac >= threshold)[0]
        if len(active) > top_k:
            active = np.argsort(ac)[::-1][:top_k]

        # Use softmax weighting
        ac_act = ac[active]
        log_ac = np.log(np.maximum(ac_act, 1e-30))
        w = np.exp(log_ac - log_ac.max())
        w = w / w.sum()

        # Compute weighted gradient
        grad = np.zeros(n)
        for ii, ki in enumerate(active):
            w_i = w[ii]
            if w_i < 1e-12:
                continue
            ki = int(ki)
            lo1 = max(0, ki - n + 1)
            hi1 = min(n - 1, ki)
            if lo1 <= hi1:
                idx = np.arange(lo1, hi1 + 1)
                grad[idx] += 2.0 * w_i * y[ki - idx]
            lo2 = max(0, ki)
            hi2 = min(n - 1, ki + n - 1)
            if lo2 <= hi2:
                idx = np.arange(lo2, hi2 + 1)
                grad[idx] += 2.0 * w_i * y[idx - ki]

        eta = c0 / (np.sqrt(t) + 1.0)
        log_a = np.log(y) - eta * grad
        log_a -= log_a.max()
        a_new = np.exp(log_a)
        a_new = np.maximum(a_new, 1e-30)
        s_new = a_new.sum()
        if s_new < 1e-15:
            a_new = y.copy()
        else:
            a_new = a_new / s_new

        x_prev = x
        x = a_new

        M_x = fast_autocorr(x).max()
        if M_x < best_m - 1e-14:
            best_m = M_x
            best_a = x.copy()
            stale = 0
        else:
            stale += 1

        if stale > restart_every:
            stale = 0
            restart_count += 1
            strength = min(0.2, 0.03 + 0.02 * min(restart_count, 5))
            pert = rng.normal(0, strength, n) * best_a
            x_r = best_a + pert
            x_r = np.maximum(x_r, 1e-10)
            x_r = x_r / x_r.sum()
            x = x_r
            x_prev = x_r.copy()
            if verbose:
                elapsed = time.time() - t0
                print(f"      restart {restart_count} at t={t} ({elapsed:.0f}s): J={2*n*best_m:.6f}")

    return best_a, best_m


def peak_shave(a0, time_limit, verbose=False, rng_seed=0):
    """Directly shave the peak by reducing contributions to argmax lag."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.time()
    rng = np.random.default_rng(rng_seed)
    stall = 0

    while time.time() - t0 < time_limit and stall < 300:
        ac = fast_autocorr(a)
        M = ac.max()
        k_max = int(np.argmax(ac))

        # Find all positions contributing to lag k_max
        lo = max(0, k_max - n + 1)
        hi = min(n - 1, k_max)
        if lo > hi:
            stall += 1
            break

        idx = np.arange(lo, hi + 1)
        # Contributions: a[i]*a[k_max-i] + a[k_max-i]*a[i] (but these are the same pair)
        # Actually c[k] = sum_j a[j]*a[k-j], so each j contributes a[j]*a[k-j]
        contrib = a[idx] * a[k_max - idx]
        total = contrib.sum()

        if total < 1e-20:
            stall += 1
            break

        # Find the position with the largest contribution
        src_pos = idx[np.argmax(contrib)]

        # Try moving mass from src_pos to a position that doesn't contribute to top lags
        # Find positions with low "cost" (not in top lags)
        top_lags = np.argsort(ac)[::-1][:15]
        cost = np.zeros(n)
        for kl in top_lags:
            kli = int(kl)
            l1 = max(0, kli - n + 1)
            h1 = min(n - 1, kli)
            if l1 <= h1:
                cost[l1:h1+1] += 1
            l2 = max(0, kli)
            h2 = min(n - 1, kli + n - 1)
            if l2 <= h2:
                cost[l2:h2+1] += 1

        # Find best destination: low cost, not src
        cost[src_pos] = 1e10
        dst_pos = int(np.argmin(cost))

        # Try different fractions
        improved = False
        for frac in [0.01, 0.02, 0.04, 0.08, 0.15, 0.25]:
            amt = a[src_pos] * frac
            if amt < 1e-15:
                continue
            a_trial = a.copy()
            a_trial[src_pos] -= amt
            a_trial[dst_pos] += amt
            a_trial = np.maximum(a_trial, 0.0)
            st = a_trial.sum()
            if st < 1e-15:
                continue
            a_trial = a_trial / st
            M_trial = fast_autocorr(a_trial).max()
            if M_trial < best_m - 1e-15:
                a = a_trial
                best_m = M_trial
                best_a = a.copy()
                improved = True
                stall = 0
                break

        if not improved:
            # Try random perturbation
            i = int(rng.integers(n))
            j = int(rng.integers(n))
            if i != j and a[i] > 1e-12:
                frac = rng.uniform(0.005, 0.05)
                amt = a[i] * frac
                a[i] -= amt
                a[j] += amt
                a = np.maximum(a, 0.0)
                a = a / a.sum()
                M_new = fast_autocorr(a).max()
                if M_new < best_m:
                    best_m = M_new
                    best_a = a.copy()
                    stall = 0
            stall += 1

        if verbose and stall % 50 == 0:
            elapsed = time.time() - t0
            print(f"      peak_shave stall={stall} ({elapsed:.0f}s): J={2*n*best_m:.6f}")

    return best_a, best_m


def interpolate_to_length(a, new_n):
    """Interpolate sequence to new length, preserving sum=1."""
    old_n = len(a)
    if old_n == new_n:
        return a.copy()
    s = a.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    a_norm = a / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, a_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss

        s_out = eval_J(a_out)
        if s_out < best_score:
            best_score = s_out
            best_seq = a_out.copy()
            print(f"  Alt grad: J={s_out:.6f}")

    # Final validation
    remaining = time_budget - (time.time() - t_global)
    final_score = eval_J(best_seq)
    if final_score < best_score:
        best_score = final_score

    print(f"\n{'='*50}")
    print(f"FINAL: J={best_score:.6f}, n={len(best_seq)}, time={time.time()-t_global:.0f}s")
    print(f"{'='*50}")

    # Ensure valid output
    best_seq = np.clip(best_seq, 0.0, 1000.0)
    if best_seq.sum() < 0.01:
        best_seq = make_power_law(5000, 1.0)
        best_seq = norm_sum1(best_seq)

    return [float(x) for x in best_seq]
