= ((1-t)² + 2t(1-t))*M + t²*max(b*b)
= (1-t)(1-t+2t)*M + t²*max(b*b)
= (1-t)(1+t)*M + t²*max(b*b)
= (1-t²)*M + t²*max(b*b)

So if max(b*b) < M, then f_new*f_new < M for all t in (0,1). And the LP is designed to find b that minimizes the "worst" (b*b) while keeping (f*b) bounded.

But the LP doesn't directly minimize max(b*b). It minimizes -sum(b) (maximizes sum(b)) subject to (f*b) <= M.

The intuition: a b with large sum that has bounded cross-correlation with f is a "spread out" sequence that doesn't correlate strongly with f. Such a b should also have low autocorrelation.

Let me also think about the computational cost more carefully.

For n=4200:
- Building the sparse matrix: O(n²) = 17.6M operations → ~1 second
- Solving LP with HiGHS: probably 10-60 seconds
- Full convolution (FFT): O(n log n) → ~0.01 seconds
- Line search (a few FFTs): ~0.1 seconds

Total per LP iteration: ~15-70 seconds.
In 900 seconds: ~15-60 iterations.

That's reasonable.

But wait, I should also consider that the LP might not improve the sequence at each step. The LP finds the best b given the constraint (f*b) <= M, but the actual improvement in max(f*f) depends on the line search.

def fast_conv(a, b=None):
    """Full linear convolution using FFT."""
    if b is None:
        b = a
    a = np.asarray(a, dtype=np.float64)
    b = np.asarray(b, dtype=np.float64)
    n = len(a)
    m = len(b)
    size = n + m - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    B = np.fft.rfft(b, fft_size)
    return np.fft.irfft(A * B, fft_size)[:size]

    return a / s

def make_two_phase(n, frac=0.6, alpha=0.3):
    x = np.linspace(0, 1, n)
    a = np.ones(n, dtype=np.float64)
    mask = x > frac

def lp_direction(f, M):
    """Solve LP: max sum(b) s.t. (f*b)[k] <= M for all k, b >= 0.
    Returns normalized b (sum=1) or None on failure."""
    n = len(f)
    num_c = 2 * n - 1
    
    # Build sparse constraint matrix
    # A[k, j] = f[i] where k = i + j, i in [0, n-1]
    # For each j (column), it appears in rows k = i+j for i in [0, n-1]
    
    rows = []
    cols = []
    vals = []
    
    for j in range(n):
        for i in range(n):
            k = i + j
            if f[i] > 1e-18:
                rows.append(k)
                cols.append(j)
                vals.append(f[i])
    
    A = csc_matrix((vals, (rows, cols)), shape=(num_c, n))
    
    c_obj = -np.ones(n)
    b_ub = np.full(num_c, M)
    bounds = [(0, None)] * n
    
    res = linprog(c_obj, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
    
    if res.success and res.x is not None:
        b = np.maximum(res.x, 0)
        sb = b.sum()
        if sb > 1e-15:
            return b / sb
    return None

            if m_new < M - 1e-12:
