## Approach and Rationale
We'll implement a multi-phase genetic algorithm (GA) with local optimizations to systematically search for a sequence with a lower score than the parent. The core idea is:

1. **Initial Population**: Create diverse initial sequences using several initialization methods (flat, cosine, bowl, dual peak, ramp, sinc) to avoid local minima.

2. **Multi-Objective Gaits**: Importantly, we'll use multiple evaluation gaits (FTRL, DE, spectral) within the GA framework:

   - **FTRL Optimization** (`ftrl_optimize`): Handles non-negative, probability-constrained optimization
   - **Differential Evolution** (`differential_evolution`): Efficient exploration of sequence space
   - **Spectral Optimization** (`spectral_optimize`): Manages Fourier-space quality control

3. **Elitism Principle**: Maintain the best solutions from each generation to avoid losing promising candidates.

4. **Local Polish**: Apply local optimization to top candidates using a "polishing pipeline":

   - Spectral smoothing (frequency-domain)
   - Coordinate descent refinement
   - Additional FTRL polish
   - Extreme hill climbing via small variations

This approach systematically explores different sequence representations and optimization methods, ensuring we test various hypotheses to potentially beat the parent's upper bound while accounting for the problem's time budget and resource constraints.

## Mathematical Specification
The algorithm searches for a sequence `a = (a_0, ..., a_{n-1})` of length n (typically 4000) that minimizes:

```python
score = 2 * n * max(convolve(a, a)) / (sum(a) ** 2)
```

- Handle sequences of variable length
- Ensure all sequences are non-negative with sum > 0.01
