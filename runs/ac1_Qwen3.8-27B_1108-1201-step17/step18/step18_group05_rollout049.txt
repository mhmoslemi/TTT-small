where grad_c[k] is the gradient of c[k] w.r.t. a.

The gradient of c[k] = sum_j a[j] a[k-j] w.r.t. a[i] is:
- a[k-i] if 0 <= k-i < n
- + a[i-k] if 0 <= i-k < n
- (both terms if both conditions hold)

So M @ a can be computed in O(n log n) using convolution!

This means I can use L-BFGS or CG to solve the QP without explicitly forming M.

But wait, the QP also has the constraint sum(a) = 1 and a >= 0. This makes it a constrained optimization. I can use cvxpy with a matrix-free approach... but cvxpy doesn't support matrix-free Hessian.

Alternative: Use an **augmented Lagrangian** approach:
- Minimize a^T M a + μ/2 * (sum(a) - 1)^2 + penalty for a < 0
- Use gradient descent / L-BFGS on this
- The gradient is: 2*M@a + μ*(sum(a)-1)*1 - penalty_grad
- M@a can be computed via convolution in O(n log n)

This is feasible! Let me implement this.

Actually, even simpler: since we're on the simplex (sum a = 1, a >= 0), we can parameterize a as softmax of some variable, or use the simplex projection trick.

Let me simplify: use projected gradient descent on the simplex.
- Gradient of f(a) = a^T M a is 2*M@a (or M@a + a*M^T, but M is symmetric so it's 2*M@a)
- Projected step: a_new = project_simplex(a - eta * 2*M@a)
- M@a computed via convolution

But this is similar to what the smoothed gradient method already does! The difference is:
- Smoothed gradient: uses a soft approximation of the max (temperature-based)
- QP-boosting: uses a weighted sum with explicit weights that are updated

The QP-boosting should converge faster because the weights adapt to the actual peaks.

Let me also think about the spectral shaping more carefully:

**Spectral Shaping Algorithm**:
1. Zero-pad a to length N = 2n (or next power of 2)
2. Compute A = FFT(a_padded)
3. Compute |A|^2
4. The autocorrelation is c = IFFT(|A|^2) (real part, take relevant portion)
5. We want to reduce the peak of c
6. In the frequency domain, a peak in c at lag k corresponds to a modulation of |A|^2 at frequency k/N
7. To "flatten" c, we want to "flatten" |A|^2 in a certain sense
8. Algorithm: 
   - Compute the "excess" of c: excess[k] = max(0, c[k] - threshold)
   - The corresponding frequency-domain modification is: delta_P = FFT(excess_padded)
   - Update: |A|^2_new = |A|^2 - alpha * |delta_P|^2 (or some related operation)
   - Take A_new = sqrt(|A|^2_new) * exp(i * angle(A))
   - a_new = real(IFFT(A_new))[:n]
   - Project: a_new = max(a_new, 0), normalize

This is getting complicated. Let me simplify to a more practical approach:

**Simplified Spectral Shaping**:
1. Compute A = FFT(a, N=2n)
2. Compute c = IFFT(|A|^2)[:2n-1] (real part)
3. Identify peaks: k_peak = argmax(c)
4. Apply a "notch" to the power spectrum at the frequency corresponding to k_peak:
   - The frequency is f* = k_peak / (2n) (and its negative)
   - Notch: P_new[k] = P[k] * (1 - depth * exp(-(k - k_peak)^2 / width^2))
     (in the DFT bin index)
   - Wait, this doesn't quite make sense dimensionally.
   
   Let me think again. The power spectrum P[m] = |A[m]|^2 for m = 0,...,2n-1.
   The autocorrelation c[k] = (1/(2n)) * sum_m P[m] * exp(2πimk/(2n))
   
   To reduce c[k_peak], we want to reduce the contribution at frequency m = k_peak (and m = 2n-k_peak).
   
   So: P_new[m] = P[m] - alpha * P[m] * Sinc(m - k_peak)
   where Sinc is a narrow peak at m = k_peak.
   
   Actually, more precisely: c[k] is the DFT of P. To reduce c at lag k*, we subtract from P the DFT of a "bump" at lag k*.
   
   Bump in time domain: b[k] = exp(-(k-k*)^2 / (2σ^2)) for k near k*
   DFT of bump: B[m] = sum_k b[k] exp(-2πimk/(2n))
   
   Update: P_new = P - alpha * |B|^2 / (2n) ... this is getting too complicated.

Let me just use a simpler approach: **iterative peak shaving in the time domain via frequency-domain filtering**.

**Simple Spectral Shaping**:
1. A = FFT(a, N=2*n)
2. Apply a filter H to A: A_new = A * H
   - H should be chosen to reduce the peak of the autocorrelation
   - A "brickwall" filter that removes the frequency components responsible for the peak
   - Or a simple low-pass/high-pass filter
3. a_new = real(IFFT(A_new))[:n]
4. a_new = max(a_new, 0), normalize

The choice of H is the key. Let me try:
- H = 1 - beta * cos(2π * k_peak * m / N)
  This creates a notch at the frequency corresponding to the peak lag.

Actually, I think the most effective simple approach is:
- Compute the autocorrelation
- Find the peak lag k*
- The "fourier component" at lag k* in the autocorrelation corresponds to frequencies k*/N and (N-k*)/N in the power spectrum
- Reduce the power spectrum at those frequencies
- This is equivalent to applying a notch filter

```python
def spectral_shaping_step(a, alpha=0.1, sigma=2.0):
    n = len(a)
    N = 2 * n  # or next power of 2
    A = np.fft.rfft(a, N)
    P = A.real**2 + A.imag**2  # power spectrum (real, non-negative)
    
    # Compute autocorrelation
    c = np.fft.irfft(A * A.conj(), N)[:2*n-1]
    # Wait, A * A.conj() = |A|^2, and irfft of that gives the autocorrelation
    # Actually for real signals: irfft(|A|^2) gives the circular autocorrelation
    # But we need to be careful about normalization
    
    # Find peak
    k_peak = np.argmax(c)
    
    # Create notch in power spectrum
    # The peak at lag k_peak corresponds to DFT bins k_peak and N-k_peak
    m = np.arange(len(P))
    # Notch at m = k_peak (and by symmetry, the negative frequency is handled by rfft)
    notch = 1.0 - alpha * np.exp(-((m - k_peak)**2 + (m - (N - k_peak))**2) / (2 * sigma**2))
    # Wait, with rfft, N-k_peak might be out of range. Let's handle it differently.
    
    P_new = P * notch
    A_new = np.sqrt(P_new) * (A.real / np.maximum(np.abs(A), 1e-15) + 1j * A.imag / np.maximum(np.abs(A), 1e-15))
    # This preserves the phase
    
    a_new = np.fft.irfft(A_new, N)[:n]
    a_new = np.maximum(a_new, 0)
    s = a_new.sum()
