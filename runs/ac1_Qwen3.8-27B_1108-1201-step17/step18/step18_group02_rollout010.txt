def lse_grad(a, ac, tau):

    ac_s = ac / tau
    ac_s -= ac_s.max()

def pm_grad(a, ac, p_power):

    w = (ac / M) ** (p_power - 1)

    if w_sum < 1e-30:

def interpolate_seq(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    f_norm = f / f.sum()
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss

Actually, let me also add one more technique: **alternating projection between the "flat autocorrelation" constraint and the "non-negativity" constraint**.

The idea: 
1. Start with sequence a
2. Compute autocorrelation ac
3. The "ideal" autocorrelation would be flat: ac_ideal = sum(a^2)/(2n-1) at every lag
4. Compute the "correction" direction: for each lag k where ac[k] > ac_ideal, reduce the contribution
5. Project back to a >= 0

This is essentially a projected gradient step.

One more idea: **use the analytic gradient of the true max, not just the LSE approximation.**

When tau is very small, the LSE gradient is essentially the gradient of the max (only the argmax lags contribute). This means:
- At very small tau, we're doing a "steepest descent on the max" 
- The max might switch between different lags, causing discontinuities
- The LSE smoothing handles this, but at very small tau, it's essentially picking one lag

A better approach for the "hard" regime: use a **subgradient** of the max, which is the average of gradients at all lags achieving the max (or near-max). This is what the LSE with small tau does.

def fast_autocorr(a):

    size = 2 * n - 1

    A = np.fft.rfft(a, fft_size)
    ac = np.fft.irfft(A * A, fft_size)[:size]
    return ac


def lse_grad(a, ac, tau):
    n = len(a)
    ac_s = ac / tau
    ac_s -= ac_s.max()
    exp_v = np.exp(ac_s)
    p = exp_v / exp_v.sum()
