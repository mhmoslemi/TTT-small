The geometric sequence isn't the optimal shape. Let me think about what shape minimizes the peak.

Actually, I think the key is that we want the convolution to be as "flat" as possible. The convolution of a sequence with itself is related to the squared magnitude of its DFT. Specifically:

If A = DFT(a) (zero-padded to length ≥ 2n-1), then:
conv(a, a) = IDFT(|A|^2)

So minimizing the peak of conv(a,a) is equivalent to making |A|^2 as "spread out" as possible (flat spectrum).

But we have the non-negativity constraint a[i] ≥ 0, which means A[0] = sum a[i] = 1 (real and positive), and A is the DFT of a non-negative sequence.

The problem becomes: find a non-negative sequence a of length n with sum 1, such that the IDFT of |DFT(a)|^2 is as flat as possible (minimizes its peak).

This is related to the "minimum peak sidelobe" problem in radar/communications, but with the non-negativity constraint.

For complex sequences without the non-negativity constraint, there are well-known solutions (causal minimum-phase sequences, etc.). But the non-negativity constraint makes it harder.

One approach: start with a complex low-PEAK autocorrelation sequence, then project onto the non-negative orthant.

But I think the practical approach is what the previous code does: gradient-based optimization on the non-negative simplex.

Let me focus on making the optimization more effective:

1. **Key insight**: The peak of the convolution is typically NOT at k=0 (which is just a[0]^2) but at some intermediate lag. For symmetric sequences, it's at k=n-1. For asymmetric sequences, it can be elsewhere.

2. **Gradient**: The subgradient of max_k conv[k] w.r.t. a[j] is:
   For the lag k* where conv is maximized:
   d conv[k*]/da[j] = a[k*-j] (if 0 ≤ k*-j < n)
   
   This is O(n) to compute for one lag, or O(K*n) for K top lags.

3. **Update**: Multiplicative update a[j] *= exp(-eta * gradient[j]) keeps a[j] ≥ 0.

"""

import numpy as np
import time
import math


def fast_autocorr(a):
    """Compute linear convolution a*a via FFT (full mode, length 2n-1)."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(np.asarray(a, dtype=np.float64), fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def norm_sum1(a):
    """Normalize to non-negative, sum=1."""
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s


def evaluate_safe(a):
    """Safely call evaluate_sequence."""
    try:
        a_arr = np.asarray(a, dtype=np.float64)
        a_list = [float(x) for x in a_arr]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')


def compute_conv_gradient(a, top_lags, weights):
    """
    Compute weighted gradient: sum_l w_l * d conv[k_l]/da
    d conv[k]/da[j] = a[k-j] if 0 <= k-j < n
    """
    n = len(a)
    grad = np.zeros(n)
    for k, w in zip(top_lags, weights):
        ki = int(k)
        if ki < 0 or ki >= 2 * n - 1:
            continue
        j_lo = max(0, ki - n + 1)
        j_hi = min(n - 1, ki)
        if j_lo > j_hi:
            continue
        idx = np.arange(j_lo, j_hi + 1)
        a_idx = a[ki - idx]
        grad[idx] += w * a_idx
    return grad


def softmax_mgd(a0, time_limit, init_beta, max_beta, top_k, eta0, verbose=False):
    """
    Soft-max multiplicative gradient descent with beta annealing.
    Minimize (1/K) sum exp(beta * conv[k]) over top K lags.
    """
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_conv_max = fast_autocorr(a).max()
    t0 = time.monotonic()
    
    beta = init_beta
    eta = eta0
    patience = 0
    max_patience = 200
    iter_count = 0
    
    while time.monotonic() - t0 < time_limit:
        conv = fast_autocorr(a)
        K = min(top_k, len(conv))
        top_idx = np.argsort(conv)[::-1][:K]
        c_top = conv[top_idx]
        
        # Soft-max weights
        c_max = c_top.max()
        e = np.exp(beta * (c_top - c_max))
        w = e / e.sum()
        
        # Gradient
        grad = np.zeros(n)
        for ii, ki in enumerate(top_idx):
            ki_int = int(ki)
            wi = w[ii]
            j_lo = max(0, ki_int - n + 1)
            j_hi = min(n - 1, ki_int)
            if j_lo <= j_hi:
                idx = np.arange(j_lo, j_hi + 1)
                grad[idx] += wi * a[ki_int - idx]
        
        # Center the gradient
        grad = grad - grad.mean()
        gmax = np.abs(grad).max()
        if gmax < 1e-15:
            break
        grad = grad / gmax
        
        # Multiplicative update
        a_new = a * np.exp(-eta * grad)
        a_new = np.maximum(a_new, 0.0)
        s = a_new.sum()
        if s < 1e-15:
            break
        a_new = a_new / s
        
        conv_new = fast_autocorr(a_new)
        M_new = conv_new.max()
        
        if M_new < best_conv_max - 1e-15:
            best_conv_max = M_new
            best_a = a_new.copy()
            patience = 0
        else:
            patience += 1
        
        if M_new <= conv.max() + 1e-12:
            a = a_new
            eta *= 0.999
            # Anneal beta
            beta = min(beta * 1.01, max_beta)
        else:
            eta *= 0.5
            if eta < 0.001:
                eta = eta0 * 0.5
                patience = max(0, patience - 50)
        
        if patience > max_patience:
            break
        
        iter_count += 1
        if verbose and iter_count % 100 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_conv_max
            print(f"    SoftMGD iter={iter_count} ({elapsed:.0f}s): J={J:.6f}, beta={beta:.1f}, eta={eta:.5f}")
    
    if verbose:
        J = 2.0 * n * best_conv_max
        print(f"    SoftMGD done: J={J:.6f}, iters={iter_count}, beta={beta:.1f}")
    return best_a
