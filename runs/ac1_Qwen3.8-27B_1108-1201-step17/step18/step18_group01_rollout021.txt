    Uses softmax weighting over all lags.

    ac_max = ac.max()
    w = np.exp((ac - ac_max) / temperature)
    w = w / w.sum()

    return grad

By a counting argument: the sum takes values in {0, 1, ..., 2n-2}, which is 2n-1 values. The sum of all probabilities is 1. So the max is at least 1/(2n-1). This gives a lower bound of `f >= 2n/(2n-1) ≈ 1` for large n.

But this bound is not achievable because the support of the sum is constrained by the support of p. If p has support S (subset of {0,...,n-1}), then the sum has support S+S, and |S+S| can be at most 2n-1 but is often less.

For the full support (p[i] > 0 for all i), the sum has full support {0, ..., 2n-2} with 2n-1 values. The theoretical lower bound is 1/(2n-1), giving f >= 2n/(2n-1) ≈ 1.

But in practice, we probably can't achieve this bound. The best we can do is make the sum distribution as close to uniform as possible.

This perspective suggests that the optimal p should be designed so that its "sum distribution" is as close to uniform as possible. This is related to the concept of "difference sets" and "Sidon sets" in combinatorics, but in a continuous/soft sense.

One approach: use an iterative method to flatten the sum distribution. Start with some p, compute the sum distribution q = p*p, and adjust p to make q more uniform.

This is exactly what the MGD approach does! The subgradient at the peak positions tells us where to reduce mass, and the constraint sum(p) = 1 forces mass to go elsewhere.

OK so let me now think about concrete improvements to the algorithm:

1. **Polyak averaging**: In subgradient methods, the average of iterates often gives better results than the final iterate. I'll keep a running average.

2. **Nesterov acceleration**: Use momentum to speed up convergence.

3. **Adactive temperature for soft max**: Start with a low temperature (sharp, focusing on the top peak) and increase it over time (smoother, more informative gradient).

4. **Second phase with scipy**: After MGD converges, use a local optimizer.

5. **Multiple lengths**: Try n from 2000 to 8000 and keep the best.

6. **Better initialization**: Use the insight about sum distributions to create better initial guesses.

Let me also think about a completely different approach: **iterative proportional fitting** or **Sinkhorn-like iterations**.

Idea: We want p*p to be as close to uniform as possible. Define the target as u[k] = 1/(2n-1) for k = 0, ..., 2n-2. Then we want to find p such that p*p ≈ u.

This is a "deconvolution" problem. We can use iterative methods:
- Start with p_0
- Compute q = p*p
- Update p to reduce the discrepancy between q and u

One natural update: `p_new[i] = p[i] * (target / current)[i]` where the ratio is computed from the sum distribution. But this needs to be defined carefully.

Actually, the "ratio" approach from iterative deconvolution (like in medical imaging) would be:
`p_new[i] = p[i] * (sum_k u[k] * s_k(i) / q[k])`

where s_k(i) is the "sensitivity" of q[k] to p[i], which is p[k-i] (the contribution of p[i] to q[k]).

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using improved multiplicative gradient
descent with Nesterov momentum, Polyak averaging, adaptive peak selection,
and multi-length exploration.
"""

import numpy as np
import time
import math

def fast_autocorr(a):
    """Compute linear autocorrelation via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(np.asarray(a, dtype=np.float64), fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def norm_sum1(a):
    """Normalize to non-negative, sum=1."""
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s

def interpolate_sequence(f, new_n):
    """Interpolate a normalized sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss

def evaluate_safe(a):
    """Safely call evaluate_sequence."""
    try:
        a_arr = np.asarray(a, dtype=np.float64)
        a_list = [float(x) for x in a_arr]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')

def compute_gradient_topk(a, ac, top_k, temperature=1.0):
    """
    Compute gradient using top-k peaks with Gaussian weights.
    The weight for peak k is exp(-rank/temperature) where rank is 0-indexed.
    """
    n = len(a)
    k_max = min(top_k, len(ac))
    top_idx = np.argsort(ac)[::-1][:k_max]
    
    # Gaussian-like weights based on rank
    ranks = np.arange(k_max, dtype=np.float64)
    w = np.exp(-ranks / (k_max * temperature))
    w = w / w.sum()
    
    grad = np.zeros(n)
    for wi, k in zip(w, top_idx):
        ki = int(k)
        i_start = max(0, ki - n + 1)
        i_end = min(n, ki + 1)
        if i_start < i_end:
            idx = np.arange(i_start, i_end)
            grad[idx] += wi * a[ki - idx]
    
    return grad

def mgd_nesterov(a0, time_limit, top_k=50, eta0=0.05, momentum0=0.5, verbose=False):
    """
    MGD with Nesterov momentum and Polyak averaging.
    """
    n = len(a0)
    a = norm_sum1(a0)
    y = a.copy()  # Nesterov lookahead point
    avg_a = a.copy()  # Polyak average
    
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    
    t0 = time.monotonic()
    iter_count = 0
    momentum = momentum0
    
    # Step size: eta_t = eta0 / sqrt(1 + t * decay_rate)
    decay_rate = 0.1
    
    while time.monotonic() - t0 < time_limit:
        # Compute autocorrelation at the lookahead point
        ac = fast_autocorr(y)
        M = ac.max()
        
        # Update best
        if M < best_m - 1e-15:
            best_m = M
            best_a = y.copy()
        
        # Compute gradient at y
        eta_t = eta0 / math.sqrt(1.0 + iter_count * decay_rate)
        grad = compute_gradient_topk(y, ac, top_k, temperature=1.0)
        grad = grad - grad.mean()  # Project to sum-zero (tangent to simplex)
        
        gmax = np.abs(grad).max()
        if gmax < 1e-15:
            break
        grad = grad / gmax
        
        # MGD update: y_new = y * exp(-eta * grad), then normalize
        y_new = y * np.exp(-eta_t * grad)
        y_new = np.maximum(y_new, 0.0)
        s = y_new.sum()
        if s < 1e-15:
            break
        y_new = y_new / s
        
        # Nesterov: a_new = (1-momentum) * y_new + momentum * (y_new + (y_new - a))
        # Actually, standard Nesterov: y = a + momentum*(a - a_prev)
        # Let me use the standard formulation:
        # a_{t+1} = (1-mu) * g_t + mu * a_t, where g_t is the gradient step result
        # y_{t+1} = a_{t+1} + mu * (a_{t+1} - a_t)
        
        a_new = (1.0 - momentum) * y_new + momentum * a
        # Project to simplex
        a_new = np.maximum(a_new, 0.0)
        s2 = a_new.sum()
        if s2 < 1e-15:
            a_new = y_new
        else:
            a_new = a_new / s2
        
        # Nesterov lookahead
        y = a_new + momentum * (a_new - a)
        y = np.maximum(y, 0.0)
        s3 = y.sum()
        if s3 < 1e-15:
            y = a_new.copy()
        else:
            y = y / s3
        
        a = a_new
        
        # Polyak averaging
        avg_a = avg_a * (iter_count / (iter_count + 1.0)) + a_new / (iter_count + 1.0)
        
        # Decay momentum slightly
        momentum = max(0.3, momentum * 0.9999)
        
        iter_count += 1
        if verbose and iter_count % 200 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print(f"    MGD-N iter={iter_count} ({elapsed:.0f}s): J={J:.6f}, eta={eta_t:.5f}")
    
    # Also check the Polyak average
    avg_m = fast_autocorr(avg_a).max()
    if avg_m < best_m:
        best_m = avg_m
        best_a = avg_a.copy()
    
    elapsed = time.monotonic() - t0
    if verbose:
        J = 2.0 * n * best_m
        print(f"    MGD-N done ({elapsed:.0f}s): J={J:.6f}, iters={iter_count}")
    
    return best_a

def coord_polish_v2(a0, time_limit, verbose=False):
    """
    Improved coordinate descent: for each peak, identify the top contributing
    pair and try to redistribute mass.
    """
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(42)
    
    stall = 0
    max_stall = 200
    
    while time.monotonic() - t0 < time_limit and stall < max_stall:
        ac = fast_autocorr(a)
        M = ac.max()
        
        if M < best_m - 1e-15:
            best_m = M
            best_a = a.copy()
        
        n_top = min(8, len(ac))
        top_k = np.argsort(ac)[::-1][:n_top]
        improved = False
        
        for k in top_k:
            if time.monotonic() - t0 > time_limit:
                break
            k_int = int(k)
            js = max(0, k_int - n + 1)
            je = min(n - 1, k_int)
            if js > je:
                continue
            
            idx = np.arange(js, je + 1)
            contrib = a[idx] * a[k_int - idx]
            
            if contrib.max() < 1e-20:
                continue
            
            # Find the top contributing position
            src = idx[np.argmax(contrib)]
            src_val = a[src]
            if src_val < 1e-14:
                continue
            
            # Find a good destination: position that contributes least to any peak
            # Score each position by its total contribution to top peaks
            peak_contrib = np.zeros(n)
            for k2 in top_k:
                k2i = int(k2)
                s2 = max(0, k2i - n + 1)
                e2 = min(n - 1, k2i)
                if s2 <= e2:
                    idx2 = np.arange(s2, e2 + 1)
                    peak_contrib[idx2] += a[k2i - idx2]
            
            # Exclude positions that are in the current peak's neighborhood
            exclude = np.zeros(n, dtype=bool)
            exclude[js:je+1] = True
            
            candidates = np.where(~exclude)[0]
            if len(candidates) == 0:
                continue
            cand_scores = peak_contrib[candidates]
            dst = candidates[np.argmin(cand_scores)]
            
            if dst == src:
                continue
            
            # Try several transfer fractions
            for frac in [0.02, 0.05, 0.1, 0.2]:
                amt = src_val * frac
                a_trial = a.copy()
                a_trial[src] -= amt
                a_trial[dst] += amt
                a_trial = np.maximum(a_trial, 0.0)
                s_t = a_trial.sum()
                if s_t < 1e-15:
                    continue
                a_trial = a_trial / s_t
                M_trial = fast_autocorr(a_trial).max()
                if M_trial < M - 1e-14:
                    a = a_trial
                    M = M_trial
                    if M < best_m:
                        best_m = M
                        best_a = a.copy()
                    improved = True
                    break
        
        if not improved:
            stall += 1
            # Random perturbation to escape
            n_perturb = int(n * 0.05)
            idx_perturb = rng.choice(n, size=n_perturb, replace=False)
            a[idx_perturb] *= rng.uniform(0.5, 1.5, size=n_perturb)
            a = np.maximum(a, 0.0)
            s_t = a.sum()
            if s_t > 1e-15:
                a = a / s_t
                M_new = fast_autocorr(a).max()
                if M_new < best_m:
                    best_m = M_new
                    best_a = a.copy()
                    stall = 0
    
    if verbose:
        elapsed = time.monotonic() - t0
        J = 2.0 * n * best_m
        print(f"    CoordV2 done ({elapsed:.0f}s): J={J:.6f}")
    
    return best_a

2. Soft-max gradient using top-K peaks with exponential rank weights

import numpy as np
import time
import math


def fast_autocorr(a):
    """Compute linear autocorrelation via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(np.asarray(a, dtype=np.float64), fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def norm_sum1(a):
    """Normalize to non-negative, sum=1."""
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s


def interpolate_sequence(f, new_n):
    """Interpolate a normalized sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss

def compute_gradient_topk(a, ac, top_k, rank_temperature=1.0):
    """
    Compute subgradient using top-k peaks with exponential rank weights.
    Returns gradient of sum_k w_k * c[k] where w_k = exp(-rank/(K*tau)) / Z.
    """
    n = len(a)
    k_max = min(top_k, len(ac))
    top_idx = np.argsort(ac)[::-1][:k_max]

    ranks = np.arange(k_max, dtype=np.float64)
    w = np.exp(-ranks / (k_max * rank_temperature))
    w_sum = w.sum()
    if w_sum < 1e-30:
        w = np.ones(k_max) / k_max
    else:
        w = w / w_sum

    grad = np.zeros(n)
    for wi, k in zip(w, top_idx):
        ki = int(k)
        i_start = max(0, ki - n + 1)
        i_end = min(n, ki + 1)
        if i_start < i_end:
            idx = np.arange(i_start, i_end)
            grad[idx] += 2.0 * wi * a[ki - idx]

    return grad


def mgd_nesterov(a0, time_limit, top_k=80, eta0=0.05, momentum0=0.5,
                 rank_temp=1.0, verbose=False):
    """
    MGD with Nesterov momentum, Polyak averaging, and adaptive step size.
    """
    n = len(a0)
    a = norm_sum1(a0.copy())
    y = a.copy()  # Nesterov lookahead
    avg_a = a.copy()  # Polyak average

    best_a = a.copy()
    best_m = fast_autocorr(a).max()

    t0 = time.monotonic()
    iter_count = 0
    momentum = momentum0
    stagnation = 0
    max_stagnation = 500

    while time.monotonic() - t0 < time_limit and stagnation < max_stagnation:
        ac = fast_autocorr(y)
        M = ac.max()

        if M < best_m - 1e-14:
            best_m = M
            best_a = y.copy()
            stagnation = 0
        else:
            stagnation += 1

        eta_t = eta0 / math.sqrt(1.0 + 0.05 * iter_count)

        grad = compute_gradient_topk(y, ac, top_k, rank_temp)
        grad_mean = grad.mean()
        grad = grad - grad_mean

        gmax = np.abs(grad).max()
        if gmax < 1e-15:
            break
        grad = grad / gmax

        # MGD step from y
        y_new = y * np.exp(-eta_t * grad)
        y_new = np.maximum(y_new, 0.0)
        s = y_new.sum()
        if s < 1e-15:
            break
        y_new = y_new / s

        # Nesterov update
        a_new = (1.0 - momentum) * y_new + momentum * a
        a_new = np.maximum(a_new, 0.0)
        s2 = a_new.sum()
        if s2 < 1e-15:
            a_new = y_new.copy()
        else:
            a_new = a_new / s2

        # Lookahead
        y = a_new + momentum * (a_new - a)
        y = np.maximum(y, 0.0)
        s3 = y.sum()
        if s3 < 1e-15:
            y = a_new.copy()
        else:
            y = y / s3

        a = a_new

        # Polyak average
        avg_a = avg_a * (iter_count / (iter_count + 1.0)) + a_new / (iter_count + 1.0)

        # Slowly decay momentum
        momentum = max(0.3, momentum * 0.9998)

        iter_count += 1
        if verbose and iter_count % 500 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print(f"    MGD-N iter={iter_count} ({elapsed:.0f}s): J={J:.6f}")

    # Check Polyak average
    avg_m = fast_autocorr(avg_a).max()
    if avg_m < best_m:
        best_m = avg_m
        best_a = avg_a.copy()

    # Also check final a
    a_m = fast_autocorr(a).max()
    if a_m < best_m:
        best_m = a_m
        best_a = a.copy()

    if verbose:
        elapsed = time.monotonic() - t0
        J = 2.0 * n * best_m
        print(f"    MGD-N done ({elapsed:.0f}s): J={J:.6f}, iters={iter_count}")

    return best_a


def coord_polish(a0, time_limit, verbose=False):
    """
    Coordinate descent: move mass from peak-contributing positions to low-impact ones.
    """
    n = len(a0)
    a = norm_sum1(a0.copy())
    best_a = a.copy()
    best_m = fast_autocorr(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(123)

    stall = 0
    max_stall = 300

    while time.monotonic() - t0 < time_limit and stall < max_stall:
        ac = fast_autocorr(a)
        M = ac.max()

        if M < best_m - 1e-14:
            best_m = M
            best_a = a.copy()

        n_top = min(10, len(ac))
        top_k = np.argsort(ac)[::-1][:n_top]
        improved = False

        for k in top_k[:8]:
            if time.monotonic() - t0 > time_limit:
                break
            k_int = int(k)
            js = max(0, k_int - n + 1)
            je = min(n - 1, k_int)
            if js > je:
                continue

            idx = np.arange(js, je + 1)
            contrib = a[idx] * a[k_int - idx]

            if contrib.max() < 1e-20:
                continue

            src = idx[np.argmax(contrib)]
            src_val = a[src]
            if src_val < 1e-14:
                continue

            # Score positions by total peak contribution
            peak_contrib = np.zeros(n)
            for k2 in top_k[:8]:
                k2i = int(k2)
                s2 = max(0, k2i - n + 1)
                e2 = min(n - 1, k2i)
                if s2 <= e2:
                    idx2 = np.arange(s2, e2 + 1)
                    peak_contrib[idx2] += a[k2i - idx2]

            exclude = np.zeros(n, dtype=bool)
            exclude[js:je + 1] = True

            candidates = np.where(~exclude)[0]
            if len(candidates) == 0:
                candidates = np.arange(n)
            cand_scores = peak_contrib[candidates]
            dst = candidates[np.argmin(cand_scores)]

            if dst == src:
                continue

            for frac in [0.02, 0.05, 0.1, 0.15, 0.25]:
                amt = src_val * frac
                a_trial = a.copy()
                a_trial[src] -= amt
                a_trial[dst] += amt
                a_trial = np.maximum(a_trial, 0.0)
                s_t = a_trial.sum()
                if s_t < 1e-15:
                    continue
                a_trial = a_trial / s_t
                M_trial = fast_autocorr(a_trial).max()
                if M_trial < M - 1e-14:
                    a = a_trial
                    M = M_trial
                    if M < best_m:
                        best_m = M
                        best_a = a.copy()
                    improved = True
                    break

        if not improved:
            stall += 1
            # Random escape: perturb a random subset
            n_perturb = max(10, int(n * 0.03))
            idx_perturb = rng.choice(n, size=n_perturb, replace=False)
            multipliers = rng.uniform(0.6, 1.4, size=n_perturb)
            a[idx_perturb] *= multipliers
            a = np.maximum(a, 0.0)
            s_t = a.sum()
            if s_t > 1e-15:
                a = a / s_t
                M_new = fast_autocorr(a).max()
                if M_new < best_m:
                    best_m = M_new
                    best_a = a.copy()
                    stall = 0

    if verbose:
        elapsed = time.monotonic() - t0
        J = 2.0 * n * best_m
        print(f"    Coord done ({elapsed:.0f}s): J={J:.6f}")

    return best_a


def parametric_families(n):
    """Generate diverse parametric initializations including asymmetric shapes."""
    x = np.linspace(0, 1, n)
    i_arr = np.arange(n, dtype=np.float64)
    results = []

    # Sine-based with asymmetry
    for alpha in [0.5, 1.0, 1.5, 2.0, 3.0]:
        for shift in [0.0, 0.1, 0.2, -0.1, -0.2]:
            val = np.sin(np.pi * np.clip(x + shift, 0.01, 0.99)) ** alpha
            results.append(val)

    # Exponential-modulated sine
    for rate in [0.5, 1.0, 2.0, 3.0]:
        for side in [1, -1]:
            val = np.sin(np.pi * x) ** 2 * np.exp(rate * side * (x - 0.5))
            results.append(np.maximum(val, 0.001))

    # Power laws
    for p in [0.3, 0.5, 1.0, 2.0, 3.0]:
        results.append((i_arr + 1.0) ** p)
        results.append((n - i_arr).clip(1.0) ** p)

    # Gaussian bumps (off-center)
    for center in [0.3, 0.4, 0.5, 0.6, 0.7]:
        for sigma in [0.1, 0.15, 0.2, 0.3]:
            results.append(np.exp(-((x - center) ** 2) / (2.0 * sigma ** 2)))

    # Two-bump asymmetric
    for c1, c2, w1, w2 in [(0.3, 0.7, 1.0, 0.5), (0.3, 0.7, 0.5, 1.0),
                             (0.2, 0.8, 1.0, 0.7), (0.4, 0.6, 1.0, 0.3)]:
        val = w1 * np.exp(-((x - c1) ** 2) / 0.02) + w2 * np.exp(-((x - c2) ** 2) / 0.02)
        results.append(val)

    return results


def parametric_search(n, best_a, best_score, time_limit):
    """Try parametric families for better initialization."""
    t0 = time.monotonic()
    families = parametric_families(n)

    best_local = best_a.copy()
    best_local_score = best_score

    for fam in families:
        if time.monotonic() - t0 > time_limit:
            break
        fam_norm = norm_sum1(fam)
        ac = fast_autocorr(fam_norm)
        val = 2.0 * n * ac.max()
        if val < best_local_score:
            best_local_score = val
            best_local = fam_norm.copy()

    if best_local_score < best_score:
        print(f"  Parametric found: {best_local_score:.6f}")

    return best_local, best_local_score

    remaining = time_budget - (time.monotonic() - t_global)
    n_best = len(best_seq)
    print(f"\n=== Phase 5: Final MGD (n={n_best}) ===")
    if remaining > 25:
        t5 = min(remaining * 0.45, 250.0)
        if t5 > 15:
            a_out = mgd_nesterov(norm_sum1(best_seq), t5, top_k=120, eta0=0.01,
                                 momentum0=0.4, rank_temp=1.5, verbose=False)
            sc = evaluate_safe(a_out)
            if np.isfinite(sc) and sc < best_score:
                best_score = sc
                best_seq = a_out.copy()
                print(f"  *** NEW BEST final MGD: {sc:.6f}")

    # === Phase 6: Final coord ===
    remaining = time_budget - (time.monotonic() - t_global)
    if remaining > 15:
        t6 = min(remaining * 0.50, 150.0)
        if t6 > 10:
            a_out = coord_polish(norm_sum1(best_seq), t6, verbose=False)
            sc = evaluate_safe(a_out)
            if np.isfinite(sc) and sc < best_score:
                best_score = sc
                best_seq = a_out.copy()
                print(f"  *** NEW BEST final coord: {sc:.6f}")

    # Final validation
    if best_seq is not None:
        fs = evaluate_safe(best_seq)
        if np.isfinite(fs):
            best_score = fs
        elapsed = time.monotonic() - t_global
        print(f"\nFINAL: score={best_score:.6f}, n={len(best_seq)}, time={elapsed:.0f}s")
    else:
        n_fb = 5000
        x = np.linspace(0, 1, n_fb)
        best_seq = np.sin(np.pi * x) ** 2
        best_seq = norm_sum1(best_seq)
        best_score = evaluate_safe(best_seq)
        print(f"Fallback: score={best_score:.6f}")

    return [float(x) for x in best_seq]
