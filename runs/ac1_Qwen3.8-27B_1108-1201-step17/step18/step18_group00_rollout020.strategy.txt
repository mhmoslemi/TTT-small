We'll develop a search function that minimizes the evaluation function for a step function. The approach involves exploring parametric families to generate initial candidates, then using an optimization algorithm to refine them. The key idea is to find a sequence of non-negative heights that keeps the maximum autocorrelation low while maintaining a sufficient sum, all within an 1800-second time budget.

### Approach and Rationale
The central challenge is to minimize:
```
J = 2 * n * max(history) / (sum(sequence) ** 2)
```
with `history` being the autocorrelation (full convolution) of normalized step-function coefficients from the evaluated sequence.

We propose a mathematical program using mixed-integer linear programming (MILP) via the scip package, allowing us to avoid the numpy FFT-based convolution while keeping the candidate as a step function. Modern approximate approaches couldn't improve our score meaningfully, but sometimes classic formulations yield better results with sufficiently advanced hardware.

### Mathematical Formulaton
We represent a candidate sequence with n points as a set of parameters determining weights `w_i` between 0 and 1 (normalized non-negative floats) for the grid positions `x_i = i / n_max`. The autocorrelation convolution of the step function is:
```
A(d) = sum_{j=0}^{n_max-1} w_j * w_{j+d}   for each shift d (0 ≤ d < n_max)
```
Overall objective:
```
J = (2 * n_i * max_{d} A(d)) / S^2
```
where `n_i` is the candidate length and `S` is the sum (`≥ 0.01`). 

We define an objective function `evaluate_sequence(seq)` that computes J for the normalized sequence.

### Implementation Strategy
1. Generate candidates from grid positions and MILP variables mixed parametric families to leverage combinatorial structure
2. Use CVXPY to interface with the MILP solver (scip)
3. Evaluate solutions using the given metric and surrogates to avoid circular mode or complex FFTs
4. Maintain best candidate by exact evaluation

```python
    n = 500

def norm_sum1(seq):
    seq = np.asarray(seq, dtype=np.float64)
    if np.min(seq) < 0 or np.max(seq) > 1000:
        print("Normalizing...")
        s = np.sum(seq)
        if s < 1e-5:
            return np.ones_like(seq) / len(seq)
        seq = np.maximum(seq, 0.0)
        seq = np.minimum(seq, 1000.0)
        s = np.sum(seq)
        if s < 1e-5:
            return np.ones_like(seq) / len(seq)
        return seq / s
    return seq / np.sum(seq)

def evaluate_milp_objective(seq):
    #MLP-based representation of the autocorrelation
    n = len(seq)
    #Normalize to unit sum
    seq = norm_sum1(seq)
    #Compute autocorrelation
    ac = np.convolve(seq, seq, mode="full")[:n]
    #Find maximum value
    max_val = np.max(ac)
    #Calculate objective
    s_val = np.sum(seq)
    if s_val < 0.01:
        return float('inf')
    return float(2 * n * max_val / (s_val ** 2))
```
