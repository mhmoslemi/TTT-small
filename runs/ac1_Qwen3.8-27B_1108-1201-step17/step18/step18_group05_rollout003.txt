For J = 2n * max_b / (sum_a)² < 2, we need max_b < (sum_a)²/n.

The average b value is (sum_a)²/(2n-1) ≈ (sum_a)²/(2n). So we need max < about 2 * average. That's quite achievable!

The key is that for a "good" sequence, the convolution values are all close to each other, with the maximum not too far above the average.

For a uniform sequence, max/average = n/(n-1+1) * (2n-1)/n = (2n-1)/n ≈ 2. So max ≈ 2*average, giving J ≈ 2.

For a sequence where the convolution is more "flat" (less peaked), max/average < 2, giving J < 2.

So we need a sequence whose convolution is as flat as possible!

This is related to "low autocorrelation sequences" or "minimum peak-to-average ratio" (PAPR) sequences.

For complex sequences, there are well-known constructions (like Zadoff-Chu, m-sequences, etc.) that achieve very flat autocorrelation. But for non-negative real sequences, the constraints are much tighter.

For non-negative real sequences, the autocorrelation at lag 0 is sum(a_i²), and the autocorrelation at other lags is sum(a_i * a_{i+k}). The peak is typically at lag 0.

But wait - we're looking at LINEAR convolution, not circular autocorrelation. In linear convolution:
- c[0] = a[0]² (only one term)
- c[n-1] = sum a[i]*a[n-1-i] (n terms)
- c[2n-2] = a[n-1]² (only one term)

So the "peak" in linear convolution is typically at the center (k=n-1), not at the edges!

This is crucial. For non-negative a, the convolution c[k] grows from the edges toward the center (roughly), because more terms contribute to the sum.
