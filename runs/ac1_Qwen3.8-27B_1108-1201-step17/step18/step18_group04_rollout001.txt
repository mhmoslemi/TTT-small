def lp_direction(a, M, n_active=None, top_frac=0.1):
    """Find b >= 0 maximizing sum(b) subject to (a*b)[k] <= M for active k."""
    n = len(a)
    a = np.asarray(a, dtype=np.float64)
    conv = fast_conv(a)
    
    # Select active constraints
    if n_active is None:
        n_active = max(20, int(len(conv) * top_frac))
    top_indices = np.argsort(conv)[::-1][:n_active]
    
    # Build constraint matrix
    # For each active constraint k: sum_j c_{k,j} * b_j <= M
    # c_{k,j} = a[k-j] if 0 <= k-j < n, else 0
    m = len(top_indices)
    A_ub = lil_matrix((m, n), dtype=np.float64)
    for ii, k in enumerate(top_indices):
        k_i = int(k)
        lo = max(0, k_i - n + 1)
        hi = min(n - 1, k_i)
        for j in range(lo, hi + 1):
            A_ub[ii, j] = a[k_i - j]
    A_ub = A_ub.tocsr()
    b_ub = np.full(m, M)
    
    c = -np.ones(n)  # maximize sum(b) = minimize -sum(b)
    
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=[(0, None)] * n,
                  method='highs', options={'presolve': True})
    
    if res.success and res.x is not None:
        return res.x
    return None

**1. Alternating projections / Douglas-Rachford:**
Split the problem:

- Constraint 2: conv(a,a) <= M (non-convex, but for fixed M, we can project)

The projection onto {a: max conv(a,a) <= M} is hard, but we can approximate it.

**2. Bilevel optimization:**
Outer: minimize M
Inner: find a >= 0, sum=1, conv(a,a) <= M

The inner is a feasibility problem. We can binary-search on M.

For a given M, the feasibility problem is: find a >= 0, sum(a)=1, such that for all k, conv(a,a)[k] <= M.

This is a system of quadratic inequalities, which is non-convex. But we can use the LP relaxation (replace a[k-j]*a[j] by a[k-j]*M or similar).
