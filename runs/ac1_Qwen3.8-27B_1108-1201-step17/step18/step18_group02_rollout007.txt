Peak ≈ 1/n + C/√n for some constant C.
Objective ≈ 2n(1/n + C/√n) = 2 + 2C√n.

That's worse than uniform for large n! So random doesn't help.

For a "designed" sequence, we need to carefully control the convolution peaks.

Let me think about this problem as a "flattening" problem. We want to redistribute the mass of the sequence so that the convolution is as flat as possible.

The convolution at lag k is a "sliding dot product": b[k] = <a, shift_k(a)>.

For the uniform sequence, b[k] = (n-|k-n+1|)/n (triangular). To flatten this, we need to make the "energy" more uniformly distributed across lags.

One approach: use a sequence whose DFT has a specific structure. If A(ω) = |A(ω)| e^{iφ(ω)}, then:
b = ifft(linear_conv(a,a)) has DFT A(ω)² (padded).
|A(ω)²| = |A(ω)|².

For b to be flat, we need A(ω)² to have a "delta-like" structure in frequency, meaning A(ω) has a "sqrt-delta" structure. This is not physical.

Alternatively, for b to be flat, we need the IFFT of A(ω)² to be flat. This means A(ω)² should have a "concentrated" magnitude spectrum. Since |A(ω)²| = |A(ω)|², we need |A(ω)| to be concentrated.

|A(ω)| is concentrated means a is "broad" in the spatial domain (like a window function). But we already have a in [0, n-1], so it's already "broad."

I think the key insight is that for NON-NEGATIVE sequences, the auto-convolution peak is fundamentally limited. The best we can do is close to 2, and the discrete effects allow a small improvement.
