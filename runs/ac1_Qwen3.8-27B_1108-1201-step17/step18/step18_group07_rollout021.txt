For the spectral optimization, the key insight is that we should **adaptively choose which frequency bins to compress**. Instead of compressing all bins uniformly, we should focus on the bins that contribute most to the convolution peaks.

Here's a better spectral approach:

**Targeted spectral compression:**

1. Compute `c = conv(a,a)`.
2. Find the peak at position `k*`.
3. Compute `A = FFT(a)`.
4. For each frequency bin `f`, compute its contribution to `c[k*]`:
   `contrib(f) = |A[f]|^2 * cos(2π*f*k*/N + 2*angle(A[f]))`
5. For bins with positive contribution, reduce their magnitude.
6. For bins with negative contribution, keep or increase their magnitude.
7. Project back to non-negative.

This is more targeted than the previous "uniform compression" approach.

Let me implement this:

```python
def targeted_spectral_step(a, num_top_peaks=3, axtent=0.2):
    n = len(a)
    fft_size = 1 << (2*n - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    mag = np.abs(A)
    phase = np.angle(A)
    
    c = fast_conv(a)
    top_peaks = np.argsort(c)[::-1][:num_top_peaks]
    
    # For each top peak, compute frequency contributions
    # c[k] = (1/N) * sum_f A[f]^2 * exp(2πi*f*k/N)
    # The real part that contributes to c[k] is:
    # (1/N) * sum_f |A[f]|^2 * cos(2π*f*k/N + 2*angle(A[f]))
    
    mag_ratio = np.ones_like(mag)
    for k in top_peaks:
        k_int = int(k)
        # Compute contribution of each bin to c[k_int]
        freqs = np.arange(len(mag))
        angles = 2 * np.pi * freqs * k_int / fft_size + 2 * phase
        contrib = (mag ** 2) * np.cos(angles)
        
        # Reduce magnitude of bins with positive contribution
        positive_mask = contrib > 0
        if positive_mask.any():
            # Scale down positive contributors
            scale = 1.0 - axtent * (contrib[positive_mask] / (contrib.max() + 1e-30))
            scale = np.maximum(scale, 0.5)  # Don't reduce by more than 50%
            mag_ratio[positive_mask] *= scale
    
    mag_new = mag * mag_ratio
    A_new = mag_new * np.exp(1j * phase)
    a_new = np.fft.irfft(A_new, fft_size)[:n]
    a_new = np.maximum(a_new, 0.0)
    s = a_new.sum()
    if s < 1e-15:
        return a.copy()
    a_new = a_new / s
    
    # Blend
    return norm_simplex(0.7 * a + 0.3 * a_new)
```

Let me also consider using **scipy.optimize** for some of the local optimization steps. For example, we can use `scipy.optimize.minimize` with the L-BFGS-B method to optimize the objective directly (treating it as a smooth approximation using log-sum-exp).

The log-sum-exp approximation: `max_k c[k] ≈ (1/beta) * log(sum(exp(beta * c[k])))`. This is smooth and differentiable, so we can use gradient-based optimization.

The gradient of the log-sum-exp approximation:
`d/d a_i [log(sum_k exp(beta * c[k]))] = sum_k exp(beta * c[k]) * dc[k]/da_i / sum_k exp(beta * c[k])`

This is a weighted average of the subgradients, with weights proportional to `exp(beta * c[k])`. For large `beta`, this approximates the exact subgradient at the argmax.

Let me implement this:

```python
def logsumexp_objective(a, beta=100.0):
    """Smooth approximation of max(conv(a,a)) using log-sum-exp."""
    c = fast_conv(a)
    beta_c = beta * c
    max_bc = beta_c.max()
    return max_bc / beta + np.log(np.exp(beta_c - max_bc).sum()) / beta

def logsumexp_gradient(a, beta=100.0):
    """Gradient of the log-sum-exp approximation."""
    n = len(a)
    c = fast_conv(a)
    beta_c = beta * c
    max_bc = beta_c.max()
    w = np.exp(beta_c - max_bc)
    w = w / w.sum()
    
    grad = np.zeros(n)
    for wi, k in zip(w, range(len(c))):
        if wi < 1e-10:
            continue
        k_int = int(k)
        i_start = max(0, k_int - n + 1)
        i_end = min(n, k_int + 1)
        if i_start >= i_end:
            continue
        idx = np.arange(i_start, i_end)
        j_idx = k_int - idx
        grad[idx] += 2.0 * wi * a[j_idx]
    return grad
```

```python
    """Optimize using log-sum-exp smoothed objective with gradient descent."""
    n = len(a0)

    best_a = a.copy()

    t0 = time.monotonic()

        g = logsumexp_gradient(a, beta)

        eta = 1.0 / (np.sqrt(t + 1) + 1.0)
```
