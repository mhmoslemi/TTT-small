    # So: s1 = IFFT(FFT(p_padded) * conj(FFT(a_padded)))
    # And we take the first n values of s1.
    
    # For the second term:
    # s2_j = sum_i a[i] * p[j-i] = sum_i p[i] * a[j-i] (substituting)
    # = sum_i p[i] * a[(j-i)] 
    # Let m = j-i, so i = j-m. s2_j = sum_m p[j-m] * a[m]
    # = sum_m a[m] * p[j-m]
    # This is IFFT(conj(FFT(p_padded)) * FFT(a_padded))[j]
    # = IFFT(FFT(a_padded) * conj(FFT(p_padded)))[j]
    # Which is the cross-correlation in the other direction!
    
    # So: s2 = IFFT(FFT(a_padded) * conj(FFT(p_padded)))
    # And we take the first n values of s2.
    
    # Total gradient: grad = s1[:n] + s2[:n]
    
    s1 = np.fft.irfft(P * np.conj(A), N)[:n]
    s2 = np.fft.irfft(A * np.conj(P), N)[:n]
    
    return s1 + s2
