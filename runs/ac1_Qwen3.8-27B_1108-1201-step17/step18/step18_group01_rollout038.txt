Let me think about this more carefully. For a non-negative sequence of length n:

This is a quadratic optimization. The minimum is 0, achieved when for all i, either a[i]=0 or a[n-1-i]=0. This means a is supported on either the first half or the second half (but not both, except possibly at the middle if n is odd).

So concentrating the mass is bad because it creates a high peak at nearby lags.

The trade-off is:
- If mass is spread out, the center lag (n-1) has a high value
- If mass is concentrated, nearby lags have high values

The optimal is somewhere in between - we want to spread the mass just enough that no single lag dominates.

Let me think about this as an optimization problem. We want to minimize:
max_k sum_{i} a[i]*a[k-i]
subject to sum a[i] = 1, a[i] >= 0

By duality, the minimum value M* satisfies:
M* = min_a max_k conv(a,a)[k]

And the objective we want is 2n * M*.

For the lower bound, we have:
sum_k conv(a,a)[k] = (sum a[i])^2 = 1
There are 2n-1 lags, so M* >= 1/(2n-1).
Thus objective >= 2n/(2n-1).

Let me think about what shapes might work well. The key is to make conv(a,a) as flat as possible.

One approach: use a sequence that is approximately the square root of a "flat" spectrum. In the frequency domain, conv(a,a) corresponds to |A(f)|^2 where A is the DFT of a. If we want conv(a,a) to be flat, we want |A(f)|^2 to be flat, i.e., |A(f)| to be constant. This is the definition of a "flat-top" window in the frequency domain, which corresponds to a sinc-like function in the time domain. But we need a discrete, finite, non-negative sequence.

Let me think differently. If we pad a with zeros to length 2n-1 and take the DFT, the DFT of the padded conv(a,a) is |A_padded(f)|^2. So we want |A_padded(f)|^2 to be flat, meaning |A_padded(f)| is constant.

We want |A_padded(f)| to be constant for all f. This means a is a "flat spectrum" sequence of length n embedded in a length 2n-1 frame.

This is related to the concept of "low PAPR" (Peak-to-Average Power Ratio) sequences, but for the spectrum rather than the time domain.

In practice, we can't achieve perfectly flat spectrum with a non-negative sequence, but we can get close.

Let me think about a practical algorithm:

1. Initialize with a reasonable shape (e.g., sinusoidal, or the parent sequence)
2. Use gradient descent to minimize the peak of conv(a,a)
3. The gradient at the peak lag gives the direction to move

For the gradient computation:
If k* is the peak lag, the gradient of conv(a,a)[k*] with respect to a[j] is:
g[j] = a[k*-j] + a[j] (if 0 <= k*-j < n), else 0
(with the factor of 2 when k* = 2j)

We want to decrease a[j] where g[j] is large and increase a[j] where g[j] is small.

But we need to maintain sum(a) = 1, so we should move mass from high-gradient positions to low-gradient positions.

A simple approach:
- Compute g[j] for the peak lag
- For each pair (i, j) where g[i] > mean(g) and g[j] < mean(g), move a small amount from a[i] to a[j]
- Check if the peak decreased

This is essentially what the coordinate descent approach does, but let me make it more efficient.

Actually, the multiplicative gradient descent (MGD) approach is quite good for this kind of problem. The update is:
a[j] <- a[j] * exp(-eta * g[j])

where g is the (normalized) gradient. This automatically maintains a[j] > 0 and after renormalization, sum(a) = 1.

def lp_direction(f, M, max_time=120.0):
    """
    Solve LP: max sum(g) s.t. conv(f,g) <= M, g >= 0.
    Return the optimal g (or None if infeasible/too slow).
    """
    from scipy.optimize import linprog
    n = len(f)
    t0 = time.monotonic()

    # conv(f, g)[k] = sum_i f[i]*g[k-i] <= M for k = 0, ..., 2n-2
    # Variables: g[0], ..., g[n-1] (n variables)
    # Constraints: (2n-1) inequality constraints
    # Objective: maximize sum(g) => minimize -sum(g)

    c = -np.ones(n)  # minimize -sum(g)

    # Build constraint matrix A_ub: A_ub @ g <= M * ones(2n-1)
    # A_ub[k, j] = f[j] if 0 <= k-j < n, else 0
    # This is a banded matrix (banded with bandwidth n)
    # Build it efficiently using the structure

    A_ub = np.zeros((2 * n - 1, n))
    for j in range(n):
        # g[j] appears in conv[k] for k = j, j+1, ..., j+n-1
        k_start = j
        k_end = min(2 * n - 1, j + n)
        A_ub[k_start:k_end, j] = f[:k_end - j]

    b_ub = np.full(2 * n - 1, M)

    bounds = [(0, None) for _ in range(n)]

    # Try to solve
    try:
        result = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
        if result.success:
            g = result.x
            if g.sum() > 0:
                return g

def lp_iterate(a0, time_limit, max_lp_calls=5, verbose=False):
    """
    LP-based iteration: alternate between LP direction finding and updating.
    """
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_m = fast_conv(a).max()
    t0 = time.monotonic()

        if time.monotonic() - t0 > time_limit:

        ac = fast_conv(a)
        M = ac.max()
        improved = False
        top_lags = np.argsort(ac)[::-1][:8]

        for attempt in range(40):
            if time.monotonic() - t0 > time_limit:

            if attempt < 12 and len(top_lags) > 0:
                k_pick = int(top_lags[attempt % len(top_lags)])
                js = max(0, k_pick - n + 1)
                je = min(n - 1, k_pick)
                center = (js + je) // 2
                start = max(0, min(n - block_size, center - block_size // 2 + int(rng.integers(-block_size // 2, block_size // 2))))
            else:
                start = int(rng.integers(0, max(1, n - block_size + 1)))

            end = min(n, start + block_size)
            bs = end - start
            if bs < 2:
                continue

            block = a[start:end].copy()
            mean_block = block.mean() + 1e-8
            scale = rng.uniform(0.01, 0.05)
            pert = rng.normal(0, scale * mean_block, bs)
            new_block = np.maximum(block + pert, 0.0)

            a_temp = a.copy()
            a_temp[start:end] = new_block
            a_temp = np.maximum(a_temp, 0.0)
            s_t = a_temp.sum()
            if s_t < 1e-15:
                continue
            a_temp /= s_t
            M_temp = fast_conv(a_temp).max()

            if M_temp < M - 1e-14:
                a = a_temp
                M = M_temp
                if M < best_m:
                    best_m = M
                    best_a = a.copy()
                improved = True
                if attempt >= 25:
                    break

        if not improved:
            stall += 1

    if verbose:
        elapsed = time.monotonic() - t0
        print(f"    Block done ({elapsed:.0f}s): obj={2.0*n*best_m:.6f}")
    return best_a

    """Interpolate a normalized sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss

    best_seq = None
    best_score = float('inf')

    # Try to load parent sequence
    parent_loaded = False
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            p_norm = norm_sum1(p)
            p_score = evaluate_safe(p_norm)
            if np.isfinite(p_score):
                best_seq = p_norm
                best_score = p_score
                parent_loaded = True
                print(f"Parent: n={len(p)}, score={p_score:.6f}")
    except Exception:

    linear_ramp = make_linear_ramp(n_base)
