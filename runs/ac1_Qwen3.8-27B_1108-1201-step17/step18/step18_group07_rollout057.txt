- `b[j]` appears in the sum when `i = j` (giving `b[j] * b[k-j]`) and when `k-i = j`, i.e., `i = k-j` (giving `b[k-j] * b[j]`).
- If `j != k-j` (i.e., `2j != k`), these are two separate occurrences, so the derivative is `2*b[k-j]`.
- If `2j == k`, it's a single occurrence, so the derivative is `b[j]`.

For simplicity, I'll use `2*b[k-j]` for all valid j (the error at most one point is negligible for large n).

So: `grad[j] += 2 * w_k * b[k-j]` for all k (weighted by softmax weight `w_k`), where `j` ranges over valid values.

This can be vectorized: for each peak k, we add `2*w_k` times a shifted version of b to the gradient.

The shifted version: for peak at position k, the valid j range is `max(0, k-n+1)` to `min(n-1, k)`, and the contribution is `b[k-j]` for j in that range.

Note that `k-j` for j in `[max(0,k-n+1), min(n-1,k)]` ranges from `k-min(n-1,k)` to `k-max(0,k-n+1)`.

If `k < n-1`: j ranges from 0 to k, and k-j ranges from k to 0. So the contribution is `b[k], b[k-1], ..., b[0]` added to `grad[0], grad[1], ..., grad[k]`.

If `k >= n-1`: j ranges from k-n+1 to n-1, and k-j ranges from k-(n-1) to k-(k-n+1) = n-1. So the contribution is `b[k-n+1], b[k-n+2], ..., b[n-1]` added to `grad[k-n+1], grad[k-n+2], ..., grad[n-1]`.

This is essentially a cross-correlation! `grad = sum_k 2*w_k * cross_corr(b, delta_k)` which is equivalent to a weighted sum of reversed/shifted versions of b.

I can compute this efficiently using FFT:
`grad = 2 * IFFT(FFT(b) * FFT(weights_reversed))` where `weights_reversed` is constructed from the peak weights.

Actually, let me think about it differently. The subgradient is:
`grad = sum_k 2*w_k * shift_and_reverse(b, k)`

This is the cross-correlation of `b` with a "comb" signal that has weights `2*w_k` at positions k.

In the frequency domain: `FFT(grad) = FFT(b) * FFT(comb_reversed)` where `comb_reversed[k] = 2*w_k`.

def ftrl_optimize_v2(b0, time_limit, verbose=False):
    """Improved FTRL with FFT-based subgradient."""
    n = len(b0)
    b = norm_simplex(b0.copy())
    best_b = b.copy()
    best_m = fast_conv(b).max()
    t0 = time.monotonic()
    
    fft_size = 1 << (2*n - 1).bit_length()
    
    # Parameters
    eta0 = 1.0  # Initial step size
    gamma = 0.999  # Step size decay per iteration
    beta_init = 20.0  # Initial smoothing parameter
    beta_end = 100.0  # Final smoothing parameter
    top_k_init = 50
    top_k_end = 10
    total_iters = 500000
    
    for t in range(1, total_iters + 1):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Annealing
        progress = min(1.0, t / 200000.0)
        beta = beta_init + (beta_end - beta_init) * progress
        top_k = max(top_k_end, int(top_k_init + (top_k_end - top_k_init) * progress))
        eta = eta0 * (gamma ** t)  # Geometric decay
        
        # Compute auto-correlation
        c = fast_conv(b)
        M_curr = c.max()
        
        # Compute subgradient via FFT
        k_max = min(top_k, len(c))
        top_idx = np.argsort(c)[::-1][:k_max]
        top_vals = c[top_idx]
        
        max_v = top_vals[0]
        if max_v < 1e-30:
            w = np.ones(k_max) / k_max
        else:
            exponents = beta * (top_vals - max_v) / max_v
            exponents = np.clip(exponents, -50, 0)
            w = np.exp(exponents)
            w = w / w.sum()
        
        # Build weight vector
        w_vec = np.zeros(fft_size)
        for wi, k in zip(w, top_idx):
            if wi > 1e-15:
                w_vec[int(k)] = wi
        
        # FFT-based subgradient
        B = np.fft.rfft(b, fft_size)
        W = np.fft.rfft(w_vec, fft_size)
        grad = 2.0 * np.fft.irfft(np.conj(B) * W, fft_size)[:n]
        
        # Mirror descent step (exponential family / simplex)
        log_b = np.log(np.maximum(b, 1e-30)) - eta * grad
        max_log = log_b.max()
        b_new = np.exp(log_b - max_log)
        b_new = np.maximum(b_new, 1e-30)
        s = b_new.sum()
        if s < 1e-15:
            b_new = b.copy()
        else:
            b_new = b_new / s
        
        b = b_new
        
        # Track best
        c_new = fast_conv(b)
        M_new = c_new.max()
        if M_new < best_m:
            best_m = M_new
            best_b = b.copy()
        
        if verbose and t % 50000 == 0:
            elapsed = time.monotonic() - t0
            print(f"      t={t} ({elapsed:.0f}s): J={2*n*best_m:.6f}, M={best_m:.10f}, eta={eta:.6f}")
    
    return best_b, best_m
