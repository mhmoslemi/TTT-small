def coordinate_descent(polish_seq, time_budget):
    """Refine the sequence with local optimization"""
    seq = polish_seq.copy()
    n = len(seq)
    
    # Identify the highest autocorrelation positions
    ac = fast_autocorr(seq)
    top_k = 40
    top_indices = np.argsort(ac)[::-1][:top_k].tolist()
    
    best_seq = None
    best_score = float('inf')
    improvement_counter = 0
    
    # Local coordinate search
    for idx in top_indices:
        if time.time() - t0 > time_budget:
            break
            
        try:
            # Original coordinate
            x = seq[idx]
            
            # Calculate impulse response
            impulse = np.zeros(n)
            impulse[idx] = 1.0
            
            # Butter erosion vector
            eros = np.zeros(len(seq))
            eros[max(0, idx-n+1):min(idx+1, n)] = build_anticorrelation_vector(seq, idx)
            
            # Local optimization
            y = norm_sum1(seq)
            grad = (eros - y*ac[idx]) / (ac[idx]**2)   # focal gradient
            
            AM = ac[idx]   # peak autocorrelation
            alpha = min(max(0.01, (time.time()-t0)/60), 0.3)  # decrease as time progresses
            
            seq[idx] = x + AM*alpha*grad*random.uniform(-0.1, 0.1)
            
            # Renormalize if needed
            if not any(x < 1e-8 for x in seq):
                a_sum = ac.sum()
                if a_sum > 0.9:
                    seq = seq / seq.sum()
                    
                    # Evaluate and record best candidate
                    eval_val = 2*n*ac.max() / (a_sum)**2
                    if eval_val < best_score:
                        best_score = eval_val
                        best_seq = seq.copy()
                        
        except KeyboardInterrupt:
            # Graceful termination
            pass
            
    return best_seq, best_score

def propose_candidate(budget_s=1800):

This approach uses a combination of Hamiltonian Monte Carlo (HMC) for global exploration and coordinate descent for local optimization. The key steps are:

1. Initialization: Start from either the parent sequence or a random sequence
2.Hamiltonian Monte Carlo: This uses the autocorrelation as a potential function to guide the sampling. It helps explore meaningful regions of the sequence space that lower the evaluation function (J)
3.Coordinate Descent: This step refines selected coordinates using directional derivatives from the autocorrelation calculation
4.Validation: The best candidate is always verified against the original J calculation metric

The algorithm dynamically adjusts its sampling distribution based on the measured properties (autocorrelation pattern). Beneficial properties include:
- Reduces the chance of getting stuck in local minima
- Preserve non-negativity through explicit constraints
- Uses gradient information to bias search toward promising areas
- Maintains randomness in exploration while focusing on reductions of J
