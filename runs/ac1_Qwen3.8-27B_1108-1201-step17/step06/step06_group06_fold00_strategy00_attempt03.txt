   - **Parent-copied**: Make a default copy of the parent sequence.

3. **Gradient Estimation**:
   - At each point `j` in the sequence, estimate the gradient as the difference from the minimum value among all elements in the convolution that contributes to the peak.

4. **Intensive Optimization**:
   - Each candidate undergoes optimization using Adam (AdamSmoothOptimize) for up to 800 seconds.
   - Then does Ram-Frank-Wolfe refinements for up to 900 seconds.

5. **Peak Targeting**:
   - After Adam optimization, locate the peaks (indices where the convolution is largest) and use coordinate descent to suppress them,yes.

6. **Multi-Length Exploration**:
   - Start with the highest possible `n`, but conditionally use shorter lists to avoid memory issues.
   - The user can optionally provide a set of `n` values (or not), we default to `n=1200`.

7. **Adaptive Scaling**:
   - Ensure all sequences have a sum >=0.01. 
   - Optionally, scale to meet the original parent's normalization if required.

8. **Fallback**:
   - If no candidate improves, revert to the Bell Curve (steepest descent) optimized via Adam.
