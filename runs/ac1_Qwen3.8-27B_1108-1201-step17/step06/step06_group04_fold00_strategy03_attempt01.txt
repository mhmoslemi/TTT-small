## Approach and Rationale

We propose a two-phase optimization approach:
1. **Adaptive Length Exploration**: We start by initializing candidate sequences across a geometric progression of lengths derived from the parent sequence (if available). This allows us to escape local optima and find the globally optimal length.
2. **Adaptive Frank-Wolf Optimization**: For each length, we use a modified version of the Frank-Wolf algorithm that dynamically adjusts the dual gap expansion and leverages a trimmed peak gradient for acceleration.

The central idea is to **1)** use a triangular array representation to capture dependencies between consecutive time steps (gradient hinton) **2)** combine this with a barrier-like update strategy at local optima that minimizes the dual gap expansion aggresively. For sequences that stabilize, we revert to a standard Frank-Wolf optimization guided by expected descent metrics. 

To escape local minima, we introduce:
- **Directional sub-sampling**: When progress stalls, we randomly downsample the current length by up to 20% and restart the Frank-Wolf process.
- **Scaled momentum updates**: Allowing moderate shifts toward underrepresented time bins.
- **Peak sharpening via minus projection**: Aggressively pruning the dominant peak in the time index for dramatic reduction potential.

Limitations:
- Initial parent sequence is fixed to 768 lengths—this may restrict exploration but accelerates gradient-based exploitation.
- The negatives are set to zero, which might restrict optimized sequences from exploring truly hybrid solutions.

def fast_convolve(a):
    n = len(a)
    if n == 0:
        return np.zeros(0)
    size = 1 << (2*n-2).bit_length()
    a_pad = np.pad(a, (0, size-2*n+1), mode='constant')
    return np.fft.irfft(np.conj(np.fft.rfft(a_pad)[:n]) * np.fft.rfft(a_pad)[:n], size)

def obj_normalized(seq):
    n = len(seq)
    conv = fast_convolve(seq)
    return np.max(conv) / np.max(np.abs(seq))

def bounded_lpfw(a, weight_decay=0.03, tolerance=0.001):
    """Projected gradient descent using LP gaps and simplex filters."""
    n = len(a)
    s0 = a.sum()
    lam = 1 if s0 < 1 else np.interp(2, [0, s0*10], [0.9, 1.0])
    lam *= (1 - weight_decay)
    if tolerance < 0.0001:
        tolerance = 0.0001
    lam *= (1 + tolerance)
    a_kw = a - lam * np.gradient(a[:])
    a_kw[a_kw < 0] = 0
    a_kw[a_kw > 1000] = 1000
    return a_kw
