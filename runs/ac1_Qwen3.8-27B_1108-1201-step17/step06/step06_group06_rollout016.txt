**Another idea: Use the fact that the problem is equivalent to a "quadratic programming" problem**

min max_k (a*a)[k]
s.t. sum a_j = 1, a_j ≥ 0

This can be written as:
min t
s.t. (a*a)[k] ≤ t for all k
     sum a_j = 1
     a_j ≥ 0

This is a quadratic convex program (the constraints (a*a)[k] ≤ t are convex in a because (a*a)[k] = a^T Q_k a where Q_k is a symmetric matrix, and a^T Q_k a is convex when Q_k is PSD... wait, is Q_k PSD?)

(a*a)[k] = sum_j a_j * a_{k-j} = a^T Q_k a

where Q_k is the matrix with (Q_k)_{j,l} = 1 if j+l = k, else 0.

Q_k is a "permutation" matrix (specifically, a reversed identity shift). Its eigenvalues are on the unit circle (it's a symmetry matrix). It's not PSD in general.

Actually, Q_k is symmetric (since (Q_k)_{j,l} = (Q_k)_{l,j} when j+l = k). Its eigenvalues are ±1 (it's a reflection). So a^T Q_k a is NOT convex in general.

This means the problem is non-convex, and we can't use standard convex optimization.

However, for fixed a, the function a → (a*a)[k] is a quadratic form. The problem of minimizing the maximum of several quadratic forms subject to linear constraints is a "quatically constrained quadratic program" (QCQP), which is NP-hard in general.

So we need heuristics. The LP-FW approach works by fixing one variable and optimizing the other linearly, which is a valid approach for bilinear problems.

**Let me also consider a completely different approach: "Iterative reweighting"**

The idea is:
1. Start with a probability distribution p on {0, ..., 2n-2} (the lag space).
2. Given p, find a that minimizes a^T Q(p) a where Q(p) = sum_k p[k] Q_k.
3. Update p to put more weight on the lags where (a*a)[k] is large.

Step 2 is a quadratic minimization: min a^T Q(p) a s.t. sum a = 1, a ≥ 0. This is a QP (quadratic program) if Q(p) is PSD.

Is Q(p) PSD? Q(p) = sum_k p[k] Q_k where Q_k is the reflection matrix for lag k. The eigenvalues of Q_k are ±1. So Q(p) = sum_k p[k] Q_k is a symmetric matrix with eigenvalues in [-1, 1] (since each Q_k has eigenvalues ±1 and they're weighted by a probability distribution).

Actually, the eigenvalues of Q(p) are not simply in [-1,1] because the Q_k don't commute. But Q(p) is a symmetric matrix, and its eigenvalues are bounded by its spectral norm, which is ≤ sum_k p[k] * ||Q_k|| = 1 (since ||Q_k|| = 1 for each k).

So Q(p) is a symmetric matrix with spectral norm ≤ 1. It's not necessarily PSD, but it's "close" to PSD in some sense.

For the QP min a^T Q(p) a s.t. sum a = 1, a ≥ 0 to be convex, we need Q(p) to be PSD on the feasible set. This is not guaranteed, but in practice, for "smooth" p, Q(p) might be "mostly" PSD.

If Q(p) is not PSD, the QP is non-convex, and we can use a local solver.

Actually, let me reconsider. The matrix Q_k for lag k has (Q_k)_{j,l} = 1 if j+l=k, else 0. This is a "reverse shift" matrix. For k=0, Q_0 has only (0,0)=1. For k=1, Q_1 has (0,1)=(1,0)=1. Etc.

The matrix Q(p) = sum_k p[k] Q_k has (Q(p))_{j,l} = p[j+l] (if j+l < 2n-1, else 0).

So Q(p) is a "Hankel" matrix with entries p[j+l]. A Hankel matrix is PSD if and only if the sequence p is the autocorrelation of some sequence (by the Herglotz theorem / positive definiteness criterion). Since p is a probability distribution, it's not necessarily positive definite.

However, for "smooth" p (e.g., p[k] = C for all k, the uniform distribution), Q(p) is a Hankel matrix with constant entries, which is PSD (it's a sum of rank-1 matrices).

In practice, for the iterative reweighting approach, Q(p) will be "close" to PSD, and the QP will be "close" to convex. We can use a local QP solver or even projected gradient.

"""

import numpy as np
from scipy.optimize import linprog
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(0.0, v[0])])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def compute_smooth_grad(f, tau, top_k=None):
    """
    Compute gradient of smoothed max-convolution objective.
    If top_k is specified, use a "peak-weighted" version that emphasizes
    the top-k peaks with higher weight.
    """
    n = len(f)
    conv = fast_convolve(f)
    
    if top_k is not None and top_k < len(conv):
        # Weighted softmax: boost the top-k peaks
        sorted_idx = np.argsort(conv)[::-1]
        top_idx = sorted_idx[:top_k]
        # Create weights: top-k get weight 1, rest get weight 0.1
        w = np.ones(len(conv)) * 0.1
        w[top_idx] = 1.0
        scaled = conv / tau
        scaled -= scaled.max()
        w = w * np.exp(scaled)
        w /= w.sum()
    else:
        scaled = conv / tau
        scaled -= scaled.max()
        w = np.exp(scaled)
        w /= w.sum()
    
    # h[j] = sum_l w[l] * f[l-j] (cross-correlation)
    w_rev = w[::-1]
    total_len = n + len(w) - 1
    fft_size = 1 << (total_len - 1).bit_length()
    A = np.fft.rfft(f, fft_size)
    W = np.fft.rfft(w_rev, fft_size)
    conv_result = np.fft.irfft(A * W, fft_size)
    h = conv_result[n - 1:2 * n - 1][::-1]
    
    grad = (2.0 / tau) * h
    return grad, conv


def adam_optimize(f0, time_limit, tau_init=None, lr_init=0.003, top_k=None, verbose=False):
    """
    Adam optimization with adaptive temperature, learning rate, and restarts.
    """
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    n = len(f)
    if s < 1e-15:
        f = np.ones(n) / n
    else:
        f = f / s

    conv = fast_convolve(f)
    if tau_init is None:
        tau = 0.06 * conv.max()
    else:
        tau = tau_init

    m = np.zeros(n)
    v = np.zeros(n)
    beta1, beta2, eps = 0.9, 0.999, 1e-8
    lr = lr_init
    t = 0

    best_obj = conv.max()
    best_f = f.copy()
    no_improve = 0
    t0 = time.monotonic()
    
    # Track consecutive non-improvement for restart decisions
    restart_threshold = 80

    while time.monotonic() - t0 < time_limit:
        t += 1
        grad, conv = compute_smooth_grad(f, tau, top_k=top_k)
        M = conv.max()

        m = beta1 * m + (1 - beta1) * grad
        v = beta2 * v + (1 - beta2) * grad * grad
        m_hat = m / (1 - beta1 ** t)
        v_hat = v / (1 - beta2 ** t)

        f_new = f - lr * m_hat / (np.sqrt(v_hat) + eps)
        f_new = project_simplex(f_new)

        conv_new = fast_convolve(f_new)
        obj_new = conv_new.max()

        if obj_new < best_obj - 1e-15:
            best_obj = obj_new
            best_f = f_new.copy()
            no_improve = 0
        else:
            no_improve += 1

        f = f_new

        # Adaptive temperature: decrease slowly
        tau *= 0.9995
        if tau < 1e-8:
            tau = 1e-8

        # Adaptive learning rate
        if no_improve > 50:
            lr *= 0.92
        if no_improve > restart_threshold:
            # Restart with perturbation from best
            rng = np.random.default_rng(t * 37 + 13)
            noise_scale = 0.001 + 0.004 * min(no_improve / (restart_threshold * 2), 3.0)
            f = project_simplex(best_f + rng.standard_normal(n) * noise_scale)
            m = np.zeros(n)
            v = np.zeros(n)
            no_improve = 0
            lr = lr_init * (0.5 + 0.3 * np.random.random())
            tau = 0.04 * fast_convolve(f).max()
            restart_threshold = max(40, restart_threshold * 0.9)
            if verbose:
                print(f"    Restart at iter {t}: best_obj={2*n*best_obj:.8f}")

        if verbose and t % 200 == 0:
            print(f"    Adam iter {t}: obj={2*n*best_obj:.8f}, tau={tau:.2e}, lr={lr:.5f}, no_imp={no_improve}")

    return best_f, 2 * n * best_obj


def lp_fw_optimize(f0, time_limit, verbose=False, max_constraints=None):
    """
    LP-based Frank-Wolfe with constraint subsetting for speed.
    Only enforce the most violated constraints.
    """
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    n = len(f)
    if s < 1e-15:
        f = np.ones(n) / n
    else:
        f = f / s

    conv = fast_convolve(f)
    M = conv.max()
    best_obj = M
    best_f = f.copy()
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    m_exp = 1.0
    
    if max_constraints is None:
        max_constraints = min(2 * n - 1, 200)  # Use at most 200 constraints

    while time.monotonic() - t0 < time_limit:
        it += 1
        elapsed = time.monotonic() - t0

        # Select constraints: top peaks
        conv = fast_convolve(f)
        M = conv.max()
        peak_indices = np.argsort(conv)[::-1][:max_constraints]
        
        # Solve LP with only selected constraints
        g = _solve_lp_subset(f, M * m_exp, n, peak_indices)
        
        if g is None:
            m_exp *= 1.15
            if m_exp > 4.0:
                rng = np.random.default_rng(it * 23 + 5)
                f = project_simplex(best_f + rng.standard_normal(n) * 0.003)
                conv = fast_convolve(f)
                M = conv.max()
                m_exp = 1.0
            continue

        g_sum = g.sum()
        if g_sum < 1e-15:
            m_exp *= 1.1
            continue
        g = g / g_sum

        if np.max(np.abs(g - f)) < 1e-12:
            no_improve += 1
            if no_improve > 15:
                m_exp = min(m_exp * 1.1, 4.0)
            if no_improve > 60:
                rng = np.random.default_rng(it * 41 + 11)
                f = project_simplex(best_f + rng.standard_normal(n) * 0.002)
                conv = fast_convolve(f)
                M = conv.max()
                m_exp = 1.0
                no_improve = 0
            continue
        else:
            no_improve = 0

        # Line search
        best_alpha = 0.0
        best_val = M
        for alpha in [0.05, 0.1, 0.15, 0.2, 0.3, 0.5, 0.7, 1.0]:
            ft = np.maximum(f + alpha * (g - f), 0.0)
            st = ft.sum()
            if st < 1e-15:
                continue
            ft = ft / st
            val = fast_convolve(ft).max()
            if val < best_val:
                best_val = val
                best_alpha = alpha

        # Fine bisection
        if best_alpha > 0:
            lo = max(0.0, best_alpha - 0.05)
            hi = min(1.0, best_alpha + 0.05)
            for _ in range(8):
                mid = (lo + hi) / 2.0
                ft = np.maximum(f + mid * (g - f), 0.0)
                st = ft.sum()
                if st < 1e-15:
                    break
                ft = ft / st
                val = fast_convolve(ft).max()
                if val < best_val:
                    best_val = val
                    best_alpha = mid
                    lo = mid
                else:
                    hi = mid

        if best_alpha > 1e-10:
            f_new = np.maximum(f + best_alpha * (g - f), 0.0)
            f_new = f_new / f_new.sum()
            M_new = fast_convolve(f_new).max()
            f = f_new
            m_exp = 1.0

            if M_new < best_obj - 1e-14:
                best_obj = M_new
                best_f = f.copy()
                if verbose and it % 10 == 0:
                    print(f"    LP-FW iter {it}: obj={2*n*best_obj:.8f} (t={elapsed:.0f}s)")
        else:
            no_improve += 1

        if no_improve > 80:
            break

    return best_f, 2 * n * best_obj


def _solve_lp_subset(f, M, n, constraint_indices):
    """Solve LP: max sum(g) s.t. (f*g)[k] <= M for k in constraint_indices, g >= 0."""
    c = -np.ones(n)
    n_constraints = len(constraint_indices)
    A_ub = np.zeros((n_constraints, n))
    
    for i, k in enumerate(constraint_indices):
        k = int(k)
        js = max(0, k - n + 1)
        je = min(n - 1, k)
        if je < js:
            A_ub[i, :] = 0
        else:
            A_ub[i, js:je+1] = f[k - np.arange(js, je+1)]
    
    b_ub = np.full(n_constraints, M)
    bounds = [(0, None)] * n
    
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs',
                     options={'presolve': True, 'time_limit': 30})
        if res.success:
            return res.x
    except Exception:
        pass
    return None


def peak_equalize(f0, time_limit, verbose=False):
    """
    Peak equalization: iteratively identify the top peaks and redistribute
    mass to reduce the peak-to-second-peak ratio.
    """
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    n = len(f)
    if s < 1e-15:
        f = np.ones(n) / n
    else:
        f = f / s

    best_obj = fast_convolve(f).max()
    best_f = f.copy()
    t0 = time.monotonic()
    
    while time.monotonic() - t0 < time_limit:
        conv = fast_convolve(f)
        M = conv.max()
        
        # Get top 3 peaks
        top_idx = np.argsort(conv)[::-1][:3]
        peak_vals = conv[top_idx]
        
        # The "excess" is the amount by which the top peak exceeds the second
        excess = peak_vals[0] - peak_vals[1]

def interpolate_sequence(f, new_n):
    """Interpolate a normalized sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp /= ss
    return f_interp


def make_shape(n, shape_type, **params):
    """Generate various initial shapes."""
    if shape_type == 'asym_gauss':
        center = params.get('center', 0.35)
        sigma = params.get('sigma', 0.25)
        x = np.arange(n) - n * center
        a = np.exp(-0.5 * (x / (n * sigma)) ** 2)
    elif shape_type == 'bell':
        width = params.get('width', 0.5)
        x = np.arange(n) - n / 2.0
        half = n * width / 2.0
        t = np.clip(np.abs(x) / half, 0, 1.0)
        a = 1.0 - t ** 4
    elif shape_type == 'exp_decay':
        rate = params.get('rate', 0.4)
        a = np.exp(-np.arange(n) / (n * rate))
    elif shape_type == 'polynomial':
        alpha = params.get('alpha', 1.0)
        x = np.linspace(0, 1, n)
        a = x ** alpha * (1 - x) ** alpha
    elif shape_type == 'raised_cos':
        a = 0.5 * (1 + np.cos(2 * np.pi * np.arange(n) / n))
    elif shape_type == 'hamming':
        a = 0.54 + 0.46 * np.cos(2 * np.pi * np.arange(n) / n)
    elif shape_type == 'double_exp':
        center = params.get('center', 0.4)
        sigma = params.get('sigma', 0.2)
        x = np.arange(n) - n * center
        a = np.exp(-np.abs(x) / (n * sigma))
    else:
        a = np.ones(n)
    
    a = np.maximum(a, 0)
    s = a.sum()
    if s > 1e-15:
        a /= s
    return a
