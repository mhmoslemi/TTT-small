import time

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    """Euclidean projection onto the probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

    for T in T_values:

            a_local = a_local / a_local.sum()
            conv = fast_convolve(a_local)
            
            # Smoothed max: (1/T) * log(sum(exp(T * conv)))

            log_sum = np.log(np.sum(np.exp(vals)))
            f = (vals.max() + log_sum) / T  # This equals (1/T)*log(sum(exp(T*conv)))
            
            # Softmax weights

            return f, grad_w

Setting `n-1-k = -j`, i.e., `k = n-1+j`:
`conv[n-1+j] = sum_i p[i] * a[i-j]`

So `c[j] = conv[n-1+j]` for j = 0, ..., n-1.

Therefore: `c = conv[n-1 : 2*n-1]`.

The convolution `conv` has length `len(p) + len(a) - 1 = (2n-1) + n - 1 = 3n-2`.
We need indices `n-1` to `2n-2`, which are all within range since `3n-2 >= 2n-2` for n >= 0.

Great, this works! And it's O(n log n) instead of O(n^2).

3. **Coordinate descent**: For each coordinate i, optimize a[i] while keeping all others fixed. The objective as a function of a single coordinate is piecewise quadratic (max of quadratics), so we can find the optimum by evaluating at the breakpoints.

Actually, the coordinate descent idea is interesting. For a fixed a with a[i] = x, the convolution values are:
`conv[k] = (original conv[k] without a[i]) + 2*x*a[k-i] + x^2 * delta(k, 2i)` (approximately, ignoring boundary effects)

The max of these as a function of x is a piecewise quadratic function. We can find the minimum by checking all breakpoints (where two pieces of the max are equal) and the vertex of each piece.

This is O(n^2) per coordinate, O(n^3) for a full sweep. For n=1024, that's about 10^9, which is too slow.

A faster approach: for a given coordinate i, the gradient of the objective with respect to a[i] changes sign at the optimum. We can use bisection or golden section search on a[i].

Each function evaluation is O(n) (one convolution via FFT is O(n log n)). With 50 bisection iterations, that's 50 * n log n per coordinate, 50 * n^2 * log n for a full sweep. For n=1024, that's about 50 * 10^6 ≈ 5 * 10^7, which is fast.

But we need to be careful: changing a[i] also changes the sum, so we need to renormalize. This makes the optimization more complex.

Actually, since the objective is homogeneous, we can fix the sum to 1 and optimize the shape. When we change a[i], we renormalize. The renormalization factor is `1/(1 + delta/s)` where `delta` is the change in a[i] and `s` is the sum.
