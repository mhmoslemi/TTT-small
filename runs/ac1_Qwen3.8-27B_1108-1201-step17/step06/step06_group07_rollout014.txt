Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using LP-based iterative optimization
combined with fast gradient polishing and coordinate descent.

The LP-based approach finds the optimal direction to move at each step by solving:
  max sum(b) s.t. (f*b)_k <= M for all k, b >= 0
where M = max_k (f*f)_k. This gives a "best" direction that maximizes progress
while respecting the convolution bound.
"""

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def build_convolve_matrix(n):
    """Build sparse structure for the convolution matrix (2n-1) x n."""
    rows = []
    cols = []
    for k in range(2 * n - 1):
        js = max(0, k - n + 1)
        je = min(n - 1, k)
        for j in range(js, je + 1):
            rows.append(k)
            cols.append(j)
    return np.array(rows), np.array(cols)

def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.arange(1, n + 1)
    cond = u * rho > (cssv - 1.0)
    if not cond.any():
        return np.ones(n) / n
    rho_val = np.nonzero(cond)[0][-1]
    theta = (cssv[rho_val] - 1.0) / (rho_val + 1.0)
    return np.maximum(v - theta, 0.0)

def compute_conv_subgradient(a, weights, peak_indices):
    """Compute subgradient of weighted sum of convolution values."""
    n = len(a)
    g = np.zeros(n)
    for idx in range(len(peak_indices)):
        k = int(peak_indices[idx])
        w_k = weights[idx]

Let me also think about the LP more carefully. The LP is:
max $\mathbf{1}^T b$
s.t. $A b \le M \mathbf{1}$
     $b \ge 0$

where $A$ is the $(2n-1) \times n$ matrix with $A_{k,j} = f_{k-j}$ (if valid).

The dual is:
min $M \mathbf{1}^T y$
s.t. $A^T y \ge \mathbf{1}$
     $y \ge 0$

The dual has $2n-1$ variables and $n$ constraints. The dual constraint matrix $A^T$ is $n \times (2n-1)$.

By complementary slackness:
- If $b_j^* > 0$, then $(A^T y^*)_j = 1$
- If $y_k^* > 0$, then $(Ab^*)_k = M$

So the support of $b^*$ tells us which dual constraints are tight, and the support of $y^*$ tells us which primal constraints are tight.

At the optimal solution of the overall problem, we'd want:
- $b^* = f$ (i.e., $f$ is the LP solution when $M = \max(f*f)$)
- This happens when $\sum b^* = 1$ (same as $\sum f$)

In practice, we iterate:
1. Compute $M = \max(f*f)$
2. Solve LP to get $b^*$
3. If $\sum b^* \approx 1$, we're at (or near) a local optimum
4. Otherwise, move toward $b^*$ (rescaled to sum 1)

The step size matters. Too large a step might overshoot. Too small a step converges slowly.

I'll use a line search to find the best step size.

def fast_convolve(a):

    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def cross_convolve(a, b):
    """Linear cross-convolution via FFT."""
    n = len(a)
    m = len(b)
    size = n + m - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)

def project_simplex(v):
    """Euclidean projection onto the probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.arange(1, n + 1)
    cond = u * rho > (cssv - 1.0)
    if not cond.any():
        return np.ones(n) / n
    rho_val = np.nonzero(cond)[0][-1]
    theta = (cssv[rho_val] - 1.0) / (rho_val + 1.0)
    return np.maximum(v - theta, 0.0)
