Possibly we can combine heuristic with systematic improvement: use local search that moves multiple bits at once to reduce max shift.

Idea: Identify shift(s) that achieve maximal value; then try to reduce it by moving a 1 from positions that contribute heavily to that shift to a position that reduces it.

Implementation: compute overlap per shift: O(n^2) but can be calculated via correlation of h with f. For a given shift s, the contribution sum_i h_i * (1 - h_{i+s}) . This equals sum_i h_i - sum_i h_i * h_{i+s} for indices where i+s valid. Since sum_i h_i = n/2 (half). So max overlap for shift s is (n/2) - sum_{i} h_i * h_{i+s}. So reducing max overlap means increasing the inner product sum_{i} h_i * h_{i+s} for that shift, i.e., increasing overlap between h and its shift. That suggests aligning ones at shift s.

Thus we can target the shift(s) that have maximal overlap (largest C5). For those shifts, we can try to increase the product h_i * h_{i+s} by flipping bits accordingly.

A greedy move: pick shift s where overlap is maximum. Find pairs (i,j) where i is 1, j = i+s is 0 (so currently product 0 with contribution to overlap). Flipping them both (swap 1 from i to j) would increase product for that shift by 1 (decrease overlap by 1). But might affect other shifts.

Thus we can propose a swap that reduces the max shift: choose i where h_i=1 and h_{i+s}=0; choose j such that swapping i->0, i+s->1 (i.e., moving the 1 forward by s). This is a "move" that reduces overlap for shift s.

- Swap h[i] (1->0) with h[i+s] (0->1). That maintains total sum.

- Compute new C5 (or just re-evaluate). Accept if improved.

import time
import numpy as np

# ---------- basic utilities ----------
def compute_c5(h):
    """Return C5 bound for binary/float step function h."""
    n = h.shape[0]
    corr = np.correlate(h, 1.0 - h, mode='full')
    return corr.max() * (2.0 / n)

def random_binary_balanced(n, rng):
    """Binary vector of length n with exactly n/2 ones."""
    arr = np.zeros(n, dtype=float)
    ones = rng.choice(n, n // 2, replace=False)
    arr[ones] = 1.0
    return arr

def thue_morse(n):
    """Thue–Morse binary sequence (0/1) of length n."""
    return np.fromiter(((bin(i).count('1') & 1) for i in range(n)),
                       dtype=float, count=n)

def get_swap_candidate(h, s, rng):
    """Find i (h[i]=1) and j=i+s (h[j]=0) for given shift s.
    Returns (i,j) or (None,None) if none exists."""
    n = h.size
    if s >= 0:
        mask = (h[:n - s] == 1.0) & (h[s:] == 0.0)
        idxs = np.flatnonzero(mask)
        if idxs.size == 0:
            return None, None
        i = rng.choice(idxs)
        j = i + s
    else:
        t = -s
        mask = (h[t:] == 1.0) & (h[:n - t] == 0.0)
        idxs = np.flatnonzero(mask)
        if idxs.size == 0:
            return None, None
        i = rng.choice(idxs) + t
        j = i - t
    return i, j

# ---------- local search ----------
def local_search(h, max_iters, rng, start, budget_s):
    """Hill climbing / simulated annealing on binary h.
    Returns best vector found and its C5 bound."""
    n = h.size
    best_h = h.copy()
    best_score = compute_c5(h)
    cur_score = best_score

    for it in range(max_iters):
        # time guard
        if time.time() - start >= budget_s - 0.5:
            break

        # correlation to locate most offending shift
        corr = np.correlate(h, 1.0 - h, mode='full')
        max_corr = corr.max()
        idxes = np.flatnonzero(corr == max_corr)
        shift_idx = rng.choice(idxes)
        s = shift_idx - (n - 1)

        # try to fix that shift by moving a 1 forward/backward
        i, j = get_swap_candidate(h, s, rng)
        moved = False
        if i is not None:
            h[i], h[j] = 0.0, 1.0
            new_score = compute_c5(h)
            if new_score <= cur_score:
                cur_score = new_score
                moved = True
                if new_score < best_score:
                    best_score = new_score
                    best_h = h.copy()
            else:
                h[i], h[j] = 1.0, 0.0

        # occasional random swap to escape plateaus
        if not moved and rng.random() < 0.05:
            ones = np.flatnonzero(h == 1.0)
            zeros = np.flatnonzero(h == 0.0)
            if ones.size and zeros.size:
                i = rng.choice(ones)
                j = rng.choice(zeros)
                h[i], h[j] = 0.0, 1.0
                new_score = compute_c5(h)
                if new_score <= cur_score:
                    cur_score = new_score
                    if new_score < best_score:
                        best_score = new_score
                        best_h = h.copy()
                else:
                    h[i], h[j] = 1.0, 0.0

    return best_h, best_score

# ---------- main entry point ----------
def run(seed=42, budget_s=1100, **kwargs):

    start = time.time()

    best_h = None

    n_final = 512

        if sc_opt < best_score:
            best_score, best_h = sc_opt, h_opt.copy()

    # fallback
    if best_h is None:
