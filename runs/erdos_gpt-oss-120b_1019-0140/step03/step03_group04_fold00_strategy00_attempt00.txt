1. First perform a global search over a coarse grid using the Fast Fourier Transform (FFT) and selective pruning of non-promising regions
2. Then apply local optimization (gradient descent with momentum) to refine the champion candidate

This approach improves upon the previous method by:
- Using FFT to enable much finer grid resolution (1024 points) within time budget
- Identifying areas of high correlation and focusing optimization there
- Maintaining feasibility through sophisticated projection methods

Mathematical Specification
We represent h as a piecewise linear function interpolated from a grid.
The optimization domain is [0,2] with integral constraint sum(h) = 1024.

Key ingredients:
1. The objective is defined as:
   C_max = max_{shifts} ∫ h(x) · (1-h(x+shift)) dx
2. We must enforce:
   0 ≤ h(x) ≤ 1 ∀x
   ∫_{0}^{2} h(x) dx = 1

Implementation Procedure
1. Global pruning:
   - Initial coarse grid evaluation
   - Use Wigner function to estimate cross-correlation errors
   - Select promising regions based on minimal estimated overlap

2. Local refinement:
   - Start with interpolated candidate from pruned region
   - Perform projected gradient descent with adaptive momentum
   - Use integral-preserving projection scheme
