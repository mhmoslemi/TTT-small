# Erdős Minimum Overlap Problem Algorithm

## 1. Approach and Rationale

We address the Erdős minimum overlap problem through a geometrized optimization framework. Instead of treating the function h(x) as a continuous variable, we map it to the coefficients of a truncated Chebyshev series. This transformation converts the problem into a convex optimization task over coefficients.

Our method leverages the:

- Shift-invariance properties of Chebyshev polynomials under discrete convolutions
- Energy conservation under coefficient transformations
- Sum preservation via orthonormality properties
- Positivity constraints via Gram matrix shifts

The core bottleneck is handling the lower/upper bounds on function values. We resolve this through iterative projection operators applied to the coefficient space, ensuring both sum preservation and non-negativity.

This approach differs from previous methods by:

- Using a spectral representation for inherent function structure
- The orthonormal nature avoids basis-function collisions
- Local optimization focuses on energy redistribution, not brute-force searches
- Less is needed from expensive global searches

## 2. Mathematical Specification

### Variables
- n : Resolution (80-128)
- α : (M) Integral energy level
- θ : (N) Scale parameter (hopefully uniform)
- φ : Energy distribution shape

### Function
h(x) = T_n(2x-1) * exp(-|θ| * |x-0.5|) 
  + (1 - T_n(2x-1)) * exp(-|φ| * |x-0.5|) * β

### Constraints
- 0 ≤ h(x) ≤ 1 ∀ x
- ∫₀² h(x) dx = 0.5 * dx * n

### Objective
Minimize max_{k=±1,...,n-1} dx |∫₀² h(x)(1-h(x+k)) dx|

### Feasibility Sets
- Energy projection: erf(α) normalization
- Passivity enforcement: Soft-max transforms

### Solution Formulation
We solve:
  minimize h(x) ~ Xθ - projection to feasible set
subject to constraints via:
  h(x) = Φ(μ) * (integral-preserving matrix)

def project_energy_preserving(h, M):
    n = len(h)
    if abs(np.sum(h) - M) < 1e-5: return h
    adjustment = (M - np.sum(h)) / len(h)

def clip_nonnegative(h, tol=1e-5, softclip=True):
    if not softclip:
        return np.clip(h, tol, 1-tol)
    n = len(h)
    clipped = np.clip(h, tol, 1-tol)
    gradient = np.zeros(n)
    # Punish values outside [0,1] by Gaussian centers

    if np.any(where_out):
