1. Approach and Rationale
**Central Idea:** We use a Cross-Entropy Method (CEM) for global optimization to escape local optima.  
**Why it Might Help:**  
- CEM explores multiple directions with probabilistic moves, avoiding premature convergence issues of pure local search.  
- The search space is well-suited for probabilistic exploration due to periodicity constraints.  
- Efficiently balances exploration and exploitation through adaptive covariance updates.  

2. Mathematical Specification  
**Representation:**  
- `h` is a piecewise-constant function on a grid of 80 points.  
- Feasibility constraints: `0≤h[i]≤1` and `sum(h)=40`.  
**Objective:** Minimize `C5 = max_k dx * (np.correlate(h, 1-h, mode='full')).max()`.  
**Constraints Enforcement:**  
- `project_sum_and_bounds` adjusts values to enforce `0≤h[i]≤1` and `sum(h)=40`.  
- Uses clipping and iterative adjustments for feasibility.

    start_time = time.time()

    dx = 2.0 / n_points

    else:

    h0 = project_sum_and_bounds(h_base, target_sum)
    
    # CEM Parameters
    N_gen = 100  # Samples per iteration
    top_k = 10    # Number of top samples to keep
    alpha = 0.1  # Mix ratio
    max_iter = 50  # Maximum iterations
    
    # Initialize distribution
    mu = h0.copy()
    log_cov = -0.5 * np.ones(n_points)  # Log scale for covariance
    
    best_solution = h0.copy()
    best_c5 = compute_c5(best_solution)
    
    # Main loop
    for it in range(max_iter):
        if time.time() - start_time > budget_s:
            break
            
        # Check time remaining
        time_used = time.time() - start_time
        time_remaining = budget_s - time_used
        
        # Compute maximal iterations possible
        max_evals_this_iter = int(time_remaining / 1.0)  # Estimated time per eval
        N_this_iter = min(N_gen, max_evals_this_iter, 1e6)
        
        # Generate samples from distribution
        samples = np.exp(log_cov) * np.random.normal(size=(N_this_iter, n_points))
        samples += mu[:, np.newaxis]
        
        # Evaluate samples
        candidates = []
        for s in samples:
            clipped = np.clip(s, 0, 1)
            proj = project_sum_and_bounds(clipped, target_sum)
            c5_val = compute_c5(proj)
            candidates.append((c5_val, proj))
        
        # Sort candidates
        candidates.sort(key=lambda x: x[0])
        best_candidate = candidates[0][1]
        if compute_c5(best_candidate) < best_c5:
            best_c5 = compute_c5(best_candidate)
            best_solution = best_candidate
        
        # Update distribution if enough candidates
        if len(candidates) >= top_k:
            top = np.array([c[1] for c in candidates[:top_k]])
            new_mu = np.mean(top, axis=0)
            new_logcov = np.mean(np.log(np.var(top, axis=0)), axis=0) + np.log(alpha)
            
            # Update parameters
            mu[:] = new_mu
            log_cov[:] = new_logcov
        
        # Early exit if convergence
        if best_c5 < 0.38:
            break
    
    # Final cleanup
    best_solution = project_sum_and_bounds(best_solution, target_sum)
    compute_c5(best_solution)  # Final objective check
    return best_solution, best_c5, n_points
