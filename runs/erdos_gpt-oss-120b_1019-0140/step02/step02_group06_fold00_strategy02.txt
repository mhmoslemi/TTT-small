**1. Approach and Rationale**

The central idea is to replace the local gradient descent approach with a global **Genetic Algorithm (GA)** to discover better solutions. GAs excel at escaping local optima by maintaining a population of candidates and applying genetic operators (selection, crossover, mutation) to explore diverse regions of the search space. This addresses the original gradient descent's main bottleneck: dependence on initial conditions and inability to explore multiple promising regions simultaneously.

Key advantages of this approach include:
- **Population-based exploration**: Naturally handles multiple local optima
- **Probabilistic transition**: No gradient information required
- **Flexibility**: Crossover operations allow combining fragments of good solutions
- **Problem-specific customization**: Operators and representations are tailored to the step function problem

The GA formulation will:
- Maintain a population of feasible h(x) solutions
- Apply selection based on lower C5 values
- Use crossover between high-performing solutions
- Introduce targeted mutations to explore new regions
- Keep track of the global best solution found

This approach will potentially find better solutions despite the higher computational cost per evaluation (due to using the full correlation computation) since it explores more broadly.

**2. Mathematical Specification**

Representation:
- h(x) is represented as a piecewise constant function on a discrete grid
- Each candidate solution h ∈ ℝⁿ is a vector of 80 samples from [0, 1]
- Constraints: 0 ≤ h[i] ≤ 1 for all i, ∑h[i] = 80/2 = 40 (equivalent to ∫h dx = 1)

Objective Function:
- C5(h) = max_k ∫ h(x)(1−h(x+k))dx
- Computed using: dx * max_value_of_full_correlation(h, 1−h)

Feasibility:
- Enforced by projecting all candidates using `project_sum_and_bounds`
- Projection ensures: sum(h) = 40 and 0 ≤ h[i] ≤ 1

Operations:
- Selection: Tournament selection based on C5 values
- Crossover: Single-point crossover between parent vectors
- Mutation: Random walk around selected points with careful projection

def compute_c5(h, dx=None):
    if dx is None:
        dx = 2.0 / len(h)
    corr = np.correlate(h, 1 - h, mode='full')
    return dx * np.max(corr)

def project_sum_and_bounds(data, target, tolerance=1e-8, max_attempts=100):
    # First clip values to [0, 1]
    data = np.clip(data, 0.0, 1.0)
    
    # Compute current sum in terms of integral (without dx)
    current_sum = np.sum(data)
    diff = target - current_sum

    # If different below tolerance, return with adjustment
    if abs(diff) < tolerance:
        return data

    # Simple initial adjustment
    data += diff / len(data)
    data = np.clip(data, 0.0, 1.0)
    current_sum = np.sum(data)
    diff = target - current_sum

    # Check again:
    if abs(diff) < tolerance:
        return data

    # Iterate to enforce tolerance
    attempts = 0
    while abs(diff) >= tolerance and attempts < max_attempts:
        attempts += 1
        s = npr.rand(2)
        i1, i2 = int(s[0]*len(data)), int(s[1]*len(data))
        
        # Ensure adjustment maintains feasibility
        current_val1 = data[i1]
        current_val2 = data[i2]
        
        # Compute maximum allowed change before clipping
        max_inc1 = min(target/current_sum - 1/current_sum * current_val1, 1.0 - current_val1) if diff > 0 else 0
        max_dec1 = min(current_val1 * current_sum/np.sum(np.delete(data, i1))/1, current_val1) if diff < 0 else 0
        max_inc2 = min(target/current_sum - 1/current_sum * current_val2, 1.0 - current_val2) if diff > 0 else 0
        max_dec2 = min(current_val2 * current_sum/np.sum(np.delete(data, i2))/1, current_val2) if diff < 0 else 0
        
        # Apply constraint-aware adjustment
        if diff > 0:
            adj1 = np.minimum(max_inc1, diff)
            adj2 = np.minimum(max_inc2, diff - adj1)
            data[i1] += adj1
            data[i2] += adj2
        else:
            adj1 = np.minimum(max_dec1, -diff)
            adj2 = np.minimum(max_dec2, -diff - adj1)
            data[i1] -= adj1
            data[i2] -= adj2
        
        # Clip again
        data = np.clip(data, 0.0, 1.0)
        current_sum = np.sum(data)
        diff = target - current_sum

    return data
