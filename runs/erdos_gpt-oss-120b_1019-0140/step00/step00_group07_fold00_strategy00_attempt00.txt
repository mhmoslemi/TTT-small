## 2 Mathematical specification 

**Problem**: Binary sequence length n, with exactly n/2 ones (n even). Minimize \( C = \max_k \left| \sum_{i=0}^{n-1} h[i] \cdot (1 - h[(i+k) \mod n] \right| \)

**Representation**: 
- h ∈ {0,1}^n with weight n/2  
- Periodic circular shifts (k∈[0, n-1])  

**Constraints and objective**:
- Number of ones: \sum h[i] = n/2  
- No other constraints  
- Objective: leading minimum value of the periodic cross-correlation's maximum value  

**Feasibility**: Each candidate solution is a binary vector of length n with precisely n/2 ones. 

**Derivation**: The problem is to minimize the maximum correlation between a binary sequence and its bit-wise negated variant under circular shifts. This is a combinatorial optimization problem with a circular dependence that requires careful handling.

Consider a candidate h. The cross-correlation at lag k is defined as:

\[
r(k) = \sum_{i=0}^{n-1} h[i] \cdot (1 - h[(i+k) \mod n])
\]

## 1 Approach and rationale
The approach to find an improved upper bound for the Erdős minimum overlap problem constant C involves optimizing a periodic binary sequence with fixed density. We use a genetic-inspired search algorithm that particularly focuses on neighborhood optimization and local updates to efficiently explore the solution space. The core idea is to:

1. Start with a high-quality parent solution from the initial condition
2. Use a local search variant that considers small perturbations around each candidate
3. Maintain periodic boundary conditions in the circular cross-correlation calculation
4. Dynamically adapt search strategies based on the current optimization progress

The rationale behind this approach is that:
- The problem is combinatorial with a large search space (C(80,40) is enormous)
- Periodic binary sequences with fixed weight are difficult to optimize but show structural patterns
- Starting from a known good solution (the parent) allows focusing the search
- Local search methods are efficient for escape local minima
- The periodic cross-correlation creates a circular dependence that must be preserved

This differs from standard genetic algorithms which are expensive and may miss good solutions in large spaces. We focus on systematic examination of neighborhood operations and dynamic learning of effective operations as we explore.

### Important limitations of this approach:
1. Requires periodic boundary handling in the cross-correlation
2. The initial solution constrains the search space
3. Optimization is heuristically based on pattern discovery in the neighborhood
4. Performance depends heavily on the quality of the parent solution
5. May converge prematurely if stuck in a local minimum

The implemented method balances exploration and exploitation by focusing on small changes applied repeatedly, which is expected to be more effective than broad genetic operators for this type of structured problem.

## 2 Mathematical specification

The problem is defined to find a binary sequence \(h:\{0,...,n-1\} \to \{0,1\}\) with density \(w = n/2\) that minimizes the maximum circular cross-correlation:

\[
C_5 = \max_{k=0}^{n-1} \left| \sum_{i=0}^{n-1} h[i] \cdot (1 - h[i+k \mod n]) \right|
\]

with normalized value:

\[
\widehat{C_5} = C_5 \cdot \frac{2}{n}
\]

The search space is all such binary sequences. This formulation arises because:

1. The constraint \(\sum h[i] = n/2\) comes from the requirement that the integral is 1 over length 2 when discretized as \(\Delta x = 2/n\)
2. The operation \(1-h[i+k]\) captures the complement function when shifted by \(k\)
3. The circular correlation handles wrapping around the  \([0,2]\) interval properly

The fitness function is: 
\text{Minimize } f(h) = \widehat{C_5} = \frac{2}{n} \max_k \left| \sum_i h[i] (1-h[i+k]) \right|

The optimization is subject to:
1. Binary values (0 or 1)
2. Fixed weight (\(\sum h[i] = n/2\))

This problem can be re-formulated as a constraint optimization over a high-dimensional binary space. However, note that the circular nature creates a convolution-like structure that must be preserved.

### Objective equivalence:
The code's definition matches:

\[
f(h) = \frac{2}{n} \times \frac{1}{n} \left| \sum_j (h \times (1-h)[j] \right|
\]

But note the \(\widehat{C_5}\) definition normalizes by a factor \(2/n\):

finalscore = (1/dx) * max_outcome1 + (1/dx) * max_outcome2
dx = 2/80

When we compute the circular correlation and take its maximum, multiply by dx, we match the definition.
