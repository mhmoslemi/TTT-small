1. **Smooth transitions**: Gradually blend step changes into smoother variations to reduce peak overlap.

3. **Symmetric constructions**: Enforce additional symmetry (e.g., even symmetry) to control the correlation spectrum.

- \( 0 \le h(x) \le 1 \)  
- \( \int_0^2 h(x) dx = 1 \)  
- Discretization: \( \text{sum}(h) * dx = 1 \)  

### Search formulation:  
We model \( h \) as a vector of \( n \)-samples. The objective is the maximum correlation (adjusted by \( dx \)). We use:  
- **CVXPY** for smooth interpolation subproblems (quadratic penalties for deviations from constant steps)  
- **MOSEK** as solver for related QPs  
- **Simulated annealing** for discrete assignment problems  

---

## Implementation procedure  
### Input: `n_points`, `seed`, `initial_h_values` (if parent exists)  
**Steps:**  
1. **Parent validation**:  
   - Verify `initial_h_values` has length 70 and score ≤ current record.  
   - Ensure \( \sum(\text{initial\_h\_values}) * dx = 1 \).  

2. **Search setup**:  
   - Let \( dx = 2 / n_{\text{points}} \)  
   - Initialize \( h \) as:  
     - If parent exists: For \( n=70 \), use `initial_h_values`. Otherwise, random assignment.  
     - For higher \( n \): Interpolate (not resample, due to integral constraints)  

3. **Refinement phase (smooth optimization)**:  

   ```python
   def smooth_objective(h):  # Smoothed correlate score for CVX-opt-friendly  
       corr = np.correlate(h, 1-h, mode='full')  
       return dx * np.max(corr)  

   # Smooth constraint: Piecewise linear approximation for anti-correlation  
   # Use CVXPY to enforce negative correlation near max shifts  
   from cvxpy import Problem, Variable, Minimize, Constraint  
   h_smooth = Variable(n_points)  
   obj = Minimize(smooth_objective(h_smooth))  
   constraints = [0 <= h_smooth, h_smooth <= 1, sum(h_smooth)*dx == 1]  
   for i in range(n_points-1):  # Penalize sudden jumps  
       constraints.append( (h_smooth[i+1] - h_smooth[i])**2 <= (1-dx*(i/n_points))**2 )  
   prob = Problem(obj, constraints)  
   # Solve with MOSEK  
   prob.solve(solver=MOSEK)  
   ```  

4. **Evolutionary phase (mutation)**:  

   ```python
   from scipy.spatial import KDTree  
   
   def mutate(h, seed, mutation_rate=0.15):  
       prng = np.random.RandomState(seed)  
       rands = prng.random(size=len(h))  
       h_new = np.copy(h)  
       ids = np.where((rands < mutation_rate) & (h > 0.25) & (h < 0.75))[0]  
       if len(ids) == 0:  # Clone if no mutations  
           return h  
       # Insert notches at random positions  
       for i in ids:  
           if prng.rand() < 0.5:  
               h_new[i] *= 0.8  # Reduce h  
           else:  
               h_new[i] = 1.0 if h_new[i] < 0.7 else min(h_new[i] + 0.8, 1.0)  # Push up to 1  
               # Maintain total integral with minimal recalibration  
               found = None  
               for j in range(10):  # Find nearby index to adjust  
                   ij = ids[(i+j) % len(h)]  
                   if h_new[ij] < 0.5:  
                         h_new[ij] += (1 - h_new[ij]) * 0.2  
                         found = ij  
                         break  
               if found is None:  
                   # Recenter uniformly if no target  
                   h_new = h_new * n_points / np.sum(h_new)  
           # Renormalize minor changes  
           h_new = h_new / np.sum(h_new) * np.sum(h) * dx  
       return h_new  
   ```  

   5. **Ansemble comparison**:  
      - Maintain top-5 solutions from each mutation  
      - Recurse until \( |\text{improvement}| < 10^{-4} \) OR time > 90% budget  

   ```python
   pool = [initial_h_values] if parent else [random_sample()]  
   top_solutions = []  
   prune_threshold = 0.3810  # Start pruning above this C value  
   max_time = budget_s - 5  # Start overtime buffer  

   while time < budget_s:  
       for trial in range(min(5, ceil(budget_s/60))):  
           candidate = mutate(pool[0], seed + trial)  
           score = evaluate_erdos_solution(candidate)  
           if score < prune_threshold or (score improved top-5):  
               top_solutions.append(candidate)  
       time += time_per_trial  
   return min(top_solutions, by score)  
   ```  

6. **Conversion to step function**:  
   - For output, project `h_values` via \( \lfloor 0.6 \rfloor \) thresholding to ensure step structure:  
   ```python
   steps = np.sort(np.where(h_values >= 0.6)[0])  # Find placements of steps  
   n_steps = np.ceil(len(steps) / dx)  # Approximate expected steps  
   if n_steps > 15:  # Step limit heuristic  
       h_clean = build_optimal_placement_from_centers(steps)  # Noted above  
   else:  
       h_clean = stepwise_representation(h_values)  
   score_clean = evaluate_erdos_solution(h_clean)  
   return (h_clean, score_clean, n_points)
   ```

## Search choices and useful variations  
**Representation variations**:  
- **Stepwise**: Variable-length sequence of constant intervals  
- **Pulse-shape**: x-shaped motifs (useful for even lags)  
- **Smooth interpolations**: Saturating transitions to reduce abrupt correlations  

**Algorithm**:  
1. For smooth optimization: Cost function penalizes excessive peaks  
2. For mutation:  
   - Apply stochastic "hole" insertion (random removals)  
   - Trial compressions (constrict on/off durations)  
   - Coordinate accentuation (amplify minimal overlaps)  

**Final fallback**:  
If Mosek/MWEAK infeasible, use:
```python  
fall_back = np.copy(initial_h_values)  
fall_back[np.argsort(abs(x-coords))][:n_points//2] = 1.0  # Uniform rebalancing  
```

- **Gradient avoidance**: Mutation uses non-differentiable stochastic replacement
