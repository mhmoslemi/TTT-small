These are different sums. $(a*a)[n-1]$ pairs $a[0]$ with $a[n-1]$, $a[1]$ with $a[n-2]$, etc.
$(a*a)[n]$ pairs $a[1]$ with $a[n-1]$, $a[2]$ with $a[n-2]$, etc.

So they share some terms but not all. For example with n=4:
$(a*a)[3] = a[0]a[3] + a[1]a[2] + a[2]a[1] + a[3]a[0] = 2a[0]a[3] + 2a[1]a[2]$
$(a*a)[4] = a[1]a[3] + a[2]a[2] + a[3]a[1] = 2a[1]a[3] + a[2]^2$

These are clearly not ordered in general. So the max could be at any lag.

However, for the specific "energy" interpretation: $\sum_m (a*a)[m]^2 = \sum_m (a*a)[m] \cdot 1$... no that's not helpful.

Actually, $\sum_m (a*a)[m] = (\sum a_j)^2 = S^2$. And there are 2n-1 values. So the average value is $S^2/(2n-1)$. If all were equal, the max would be $S^2/(2n-1)$ and the score would be $2n \cdot S^2/(2n-1) / S^2 = 2n/(2n-1) \approx 1$.

So the theoretical minimum is $2n/(2n-1)$, achieved when all convolutions are equal (a "flat" convolution), which is related to difference sets and Singer sequences.

For our purposes, the target is 1.50274349. With n=5582, the theoretical minimum is $2 \cdot 5582/(2 \cdot 5582 - 1) = 11164/11163 \approx 1.0000896$. So 1.5027 is achievable in principle.

Now, the key question: what structure minimizes the max of the convolution for a non-negative sequence?

For the specific case of a "Barker-like" sequence but non-negative... this is related to the problem of minimizing the peak-to-average power ratio of the autocorrelation.

Actually, I realize that for a non-negative sequence, the problem is quite different from the complex Barker sequence problem. The constraint $a_i \geq 0$ is very restrictive.

Let me think about what the optimal solution looks like:
- We want $\max_m (a*a)[m]$ to be as small as possible (relative to $S^2$).
- Equivalently, we want the convolution to be as flat as possible.
- For a non-negative sequence, the "center" convolution $(a*a)[n-1]$ tends to be large because it has the most cross-terms.

One approach: make the sequence have a specific structure that makes the convolution flat. For example, if $a$ is an indicator function of a difference set, the convolution is nearly constant.

A (v, k, λ) difference set in a group of order v gives: $|A - A| = λ$ for $a \neq 0$, and the autocorrelation is constant at λ for all non-zero shifts (in the cyclic group). For a linear (non-cyclic) sequence, we can use Sidon sets or similar constructions.

But with n=5582 and needing non-negative values (not just 0/1), we have more flexibility.

Let me think about a practical optimization approach:

**Approach: Projected Gradient Descent with Smoothed Max**

Since the max is non-smooth, I'll use the log-sum-exp approximation:
$\max_i b_i \approx \frac{1}{\beta} \log \sum_i e^{\beta b_i}$ for large β.

The gradient of this smooth approximation is:
$\frac{\partial}{\partial a_j} \left(\frac{1}{\beta} \log \sum_i e^{\beta b_i}\right) = \sum_i \frac{e^{\beta b_i}}{\sum_k e^{\beta b_k}} \cdot \frac{\partial b_i}{\partial a_j}$

This is a weighted average of the individual gradients, with weights proportional to $e^{\beta b_i}$. As β → ∞, it concentrates on the max.

But computing this requires the full convolution spectrum, which is O(n log n) via FFT. That's fine.

Actually, for n=5582, even a direct convolve is fast (O(n^2) = 31 million operations, which is trivial for numpy). Let me just use np.convolve.

Let me estimate timing:
- np.convolve of two length-5582 arrays: ~1ms in numpy (it uses FFT internally for large arrays)
- Actually, for n=5582, 2n-1=11163, and numpy uses FFT-based convolution for large arrays. An FFT of size ~16382 takes ~0.5ms.
- So each iteration is maybe 2-5ms.
- In 1295 seconds, we can do ~250,000 iterations. That's plenty.
