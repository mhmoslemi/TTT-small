Given the current conv and the influence vector d_j, I want to find t >= 0 that minimizes:

For k = 2j: conv[2j] + u*d_j[2j] + u² = conv[2j] + 2a[j]*u + u² = (u + a[j])² + conv[2j] - a[j]² = t² + (conv[2j] - a[j]²)

So the objective is: max( max_{k≠2j}(conv[k] + u*d_j[k]), t² + rest_2j )
where rest_2j = conv[2j] - a[j]².

The first term is a convex piecewise-linear function of u (max of linear functions).
The second term is a convex quadratic in t (= u + a[j]).

The max of these is convex in u. To find the minimum, I can:
1. Find where the piecewise-linear part is minimized (ignoring the quadratic)
2. Check if the quadratic is the binding constraint
3. Use bisection on the "subgradient"

For a practical implementation, let me use a simple approach:
- Binary search on the optimal value M:
  - For a given M, find if there exists t >= 0 such that all constraints are satisfied
  - Constraint for k ≠ 2j: conv[k] + (t-a[j])*d_j[k] <= M
    - If d_j[k] > 0: t <= (M - conv[k]) / d_j[k] + a[j]
    - If d_j[k] < 0: t >= (M - conv[k]) / d_j[k] + a[j]
    - If d_j[k] = 0: need conv[k] <= M

  - Also: t >= 0

  Feasible if: max(0, all lower bounds) <= min(all upper bounds, sqrt(M - rest_2j))

- The minimum M is found by bisection.
