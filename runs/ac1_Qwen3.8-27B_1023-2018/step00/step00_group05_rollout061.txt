        sc = float(evaluate_sequence(f_try.tolist()))
        if np.isfinite(sc) and sc < best_score:
            best_f = f_try.copy()
            best_score = sc
            f = f_try.copy()
    
    # Phase 2: Subgradient iterations
    K = 5  # number of peaks to track
    lr = 0.1
    iters_per_phase2 = 0
    
    while time.monotonic() < deadline - 120:  # leave 120s for LP phase
        c = np.convolve(f, f)
        peak_idx = np.argpartition(c, -K)[-K:]
        peak_idx = peak_idx[np.argsort(c[peak_idx])[::-1]]
        
        # Subgradient
        sg = np.zeros(n)
        for k in peak_idx:
            k = int(k)
            lo = max(0, k - n + 1)
            hi = min(k, n - 1)
            if hi >= lo:
                sg[lo:hi+1] += f[k-hi:k-lo+1][::-1]
        
        f = f - lr * sg
        f = np.clip(f, 1e-10, 1000.0)
        s = f.sum()
        if s < 1e-10:
            f = best_f.copy()
            break
        f = f * n / s
        
        # Compute score (expensive but necessary)
        c_new = np.convolve(f, f)
        cur_score = 2.0 * n * c_new.max() / (f.sum()**2)
        
        if cur_score < best_score - 1e-12:
            best_f = f.copy()
            best_score = cur_score
        elif it % 1000 == 0 and best_score < 1.6:
            lr *= 0.9
        iters_per_phase2 += 1

Let me think about the geometry. The sinusoidal a[i] = 1 + A*sin(2πi/n) has:
- conv[n-1] ≈ n(1 - A²/2) (the center, which is the max)
- Other peaks are at most about n/2 + O(A²)
- Score ≈ 2(1 - A²/2)

For A = 1: score ≈ 2(1-0.5) = 1. But a[i] = 1 + sin(2πi/n) has minimum 0, so clip to 0. The actual score will be different from the approximation.

Let me try A = 1: a[i] = max(0, 1 + sin(2πi/n)). This is a "half-wave rectified" sinusoid. The values range from 0 to 2.

The sum is ≈ n * (1 + 0) = n (average of max(0, 1+sin) is 1, since sin has mean 0 and the rectification doesn't change the mean by much... actually it does. The mean of max(0, 1+sin(θ)) for θ uniform on [0, 2π] is:
(1/2π) ∫₀²π max(0, 1+sin θ) dθ = (1/2π) ∫_{-π/2}^{3π/2} (1+sin θ) dθ
= (1/2π)[θ - cosθ]_{-π/2}^{3π/2}
= (1/2π)[(3π/2 - 0) - (-π/2 - 0)]
= (1/2π)[3π/2 + π/2]
= (1/2π)(2π) = 1
