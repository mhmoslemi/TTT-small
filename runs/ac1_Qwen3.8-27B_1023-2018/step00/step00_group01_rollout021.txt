So L[i] = max(b[k]) for k ∈ [max(0,i), min(2n-2, i+n-1)].

For i=0: k ∈ [0, n-1], window size n
For i=n-1: k ∈ [n-1, 2n-2], window size n
For any i: the window is [i, i+n-1] (always within [0, 2n-2] since i ∈ [0,n-1] and i+n-1 ∈ [n-1, 2n-2]).

So L[i] = max(b[i : i+n]) (0-indexed, n elements). This is indeed a sliding window maximum with window size n over a sequence of length 2n-1, giving n output values.

This is standard and can be done with a monotone deque in O(n) time.
