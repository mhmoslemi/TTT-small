OK let me step back and think about what actually works for this problem.

The key challenge: minimize the peak of the autocorrelation of a non-negative sequence.

For non-negative sequences, the autocorrelation peak is at the "center" lag (k = n-1) where we get sum_i a_i * a_{n-1-i}. For a palindromic sequence, this equals sum a_i^2.

To minimize the peak, we want:
1. The sequence to be as "spread out" as possible (not concentrated)
2. The autocorrelation to be as flat as possible

One key insight: for non-negative sequences, the autocorrelation is always non-negative, and the "DC component" (sum) is fixed. The question is how to distribute the energy.

For a complex sequence, we can use FFT-based methods to flatten the spectrum. For real non-negative sequences, we're more limited.

Let me try a different approach: **iterative FFT-based deconvolution with non-negativity projection**.

1. Compute the "target" flat autocorrelation: c_target[k] = 1/(2n-1) for all k (if sum(a)=1)
2. Compute current c = conv(a, a)
3. Compute error: e = c - c_target
4. Update: a_new = a - eta * (a * e) [correlation, i.e., the "gradient"]
5. Project: a_new = max(a_new, 0), then normalize

Wait, step 4: the gradient of ||c - c_target||^2 with respect to a is:
2 * (a * (c - c_target)) (cross-correlation, or convolution with flipped error)

Actually, since c = a*a (auto-convolution), the gradient of sum_k (c_k - t_k)^2 with respect to a_j is:
2 * sum_k (c_k - t_k) * dc_k/da_j = 2 * sum_k (c_k - t_k) * (a_{k-j} + a_{k-j} if j≠k-j)

For simplicity (and since j=k-j only happens at one lag), let's approximate:
grad_j ≈ 4 * sum_k (c_k - t_k) * a_{k-j} (for j not at center)

This is essentially 4 * (a * e)[j + n - 1] where e = c - c_target.
