    size = 2 * n - 1  # minimum for linear conv

The score is `2n * C.max() / (sum a)²`. With sum a = n, this is `2 * C.max() / n`.

For the constant: C.max() = n, score = 2.
Lower bound: C.max() >= n/2, score >= 1.

We want score ≈ 1.5, so C.max() ≈ 0.75n.

The convolution C[k] for the constant is triangular: C[k] = min(k+1, 2n-1-k). The values range from 1 (at the edges) to n (at the center).

To reduce the peak from n to 0.75n, we need to "shave" the center by 25%. This means redistributing mass from the center of the convolution to the edges.

The center of the convolution (k = n-1) gets contributions from ALL pairs (j, n-1-j). The edges (k=0) only get a[0]².

One way to reduce the center: make the sequence have a "dip" in the middle. If a[j] is smaller for j near n/2, then the center of the convolution (which involves pairs straddling the middle) will be reduced.

For example: a[j] = 1 + alpha * (-1)^j (alternating). For alpha = 0.5:
- a alternates between 1.5 and 0.5.

- For k even: C[k] = (number of same-parity pairs) * 1.5*1.5 + (number of cross-parity pairs) * 0.5*1.5
