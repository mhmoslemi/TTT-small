1 ≤ (2n-1) * sum c_k²
sum c_k² ≥ 1/(2n-1)

And by Parseval (using DFT of the zero-padded convolution):
sum_k c_k² = (1/N) sum_freq |FFT(c)_freq|² where N is the DFT length.
FFT(c)_freq = |FFT(a)_freq|² (for the zero-padded case).
So sum_k c_k² = (1/N) sum_freq |FFT(a)_freq|⁴.

def fft_convolve(a):
    """Linear convolution via FFT."""
    n = len(a)
    size = 1
    while size < 2*n - 1:
        size *= 2
    fa = np.fft.rfft(a, n=size)
    c = np.fft.irfft(fa * fa, n=size)[:2*n-1]
    return c
