For the normalized problem (S = 1), AC1 = 2n * M where M = max_k b_k.

The subgradient of M with respect to f_j (when k* is the argmax):
$\frac{\partial M}{\partial f_j} = \frac{\partial b_{k^*}}{\partial f_j}$

And $\frac{\partial b_k}{\partial f_j} = 2 f_{k-j}$ (with $f_m = 0$ for $m \notin [0, n-1]$).

So $\frac{\partial M}{\partial f_j} = 2 f_{k^* - j}$ (with zero padding).

And $\frac{\partial AC1}{\partial f_j} = 2n \cdot 2 f_{k^* - j} = 4n f_{k^* - j}$.

For gradient descent: $f_j \leftarrow f_j - \eta \cdot 4n f_{k^* - j}$.

But we need to maintain $\sum f_j = 1$ (the normalization constraint). The projected gradient step is:
1. $f_j^{raw} = f_j - \eta \cdot 4n f_{k^* - j}$
2. Project onto $\{f \geq 0, \sum f = 1\}$.

The projection onto the non-negativity constraint is just clipping. The projection onto the simplex (sum = 1, non-negative) is the Euclidean projection, which can be done in O(n log n).

$f^{new} \leftarrow f^{new} / \sum f^{new}$

        if time.monotonic() > deadline - 10.0:
            break

    # Local search polish to fine-tune
    if time.monotonic() < deadline - 5.0:
        f_local = best.copy()
        # Scale to original range for local search (values in [0,1000])
        f_local = np.clip(f_local, 0, 1000.0)
        for _ in range(500):
            if time.monotonic() > deadline - 5.0:
                break
            width = max(2, n // 80)
            pos = rng.integers(0, max(1, n - width))
            f_local[pos:pos + width] *= np.exp(rng.normal(0.0, 0.04, width))
            f_local = np.clip(f_local, 0, 1000.0)
            if f_local.sum() < 0.01:
                continue
            score = evaluate_sequence(f_local.tolist())
            if np.isfinite(score) and score < best_score:
                best_score = score
                best = f_local.copy()

    # Final: ensure valid output
    out = [float(max(0.0, min(1000.0, x))) for x in best]
    final_score = evaluate_sequence(out)
    if not np.isfinite(final_score):
        out = [1.0] * n
        final_score = evaluate_sequence(out)

    return out
