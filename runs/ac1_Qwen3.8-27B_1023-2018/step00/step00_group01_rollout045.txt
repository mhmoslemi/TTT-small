Let me go back to the LP approach. For the constant sequence, the LP gives:
max sum g
s.t. g ≥ 0, prefix sums ≤ nc, suffix sums ≤ nc

The optimal extreme points are:
- g = [nc, 0, ..., 0] (all mass at start)
- g = [0, ..., 0, nc] (all mass at end)
- g = [nc/2, 0, ..., 0, nc/2] (split at both ends)
- g = [0, ..., nc, 0, ..., 0] (all mass in center) - wait, is this feasible?
