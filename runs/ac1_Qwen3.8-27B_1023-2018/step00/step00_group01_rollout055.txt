                best = a.copy()
                best_score = s_new

                accepted = True
                break
            elif s_new < fast_score(a):
                a = a_new
                accepted = True
                break

            base_step *= 0.5
            if base_step < 1e-15:

                s_noise = fast_score(a_noise)
                if s_noise < fast_score(a):
                    a = a_noise
                base_step = 0.1 * S / n

    final = evaluate_sequence(best.tolist())
    if not np.isfinite(final):
        best = np.ones(n, dtype=np.float64)

FISTA for minimizing $f(a) = \max_k (a*a)_k$ subject to $a \geq 0$, $\sum a = S$:

The "prox" step for the constraint $\{a \geq 0, \sum a = S\}$ is the Euclidean projection onto the simplex, which can be done in $O(n \log n)$ time.

FISTA:
1. $a^{k+1} = \text{Proj}(y^k - \alpha \nabla f(y^k))$
2. $t_{k+1} = (1 + \sqrt{1 + 4t_k^2))/2$
3. $y^{k+1} = a^{k+1} + (t_k - 1)/t_{k+1} \cdot (a^{k+1} - a^k$

Where $\text{Proj}$ is projection onto the simplex.

But $f(a) = \max_k (a*a)_k$ is not smooth, so I need to use the subgradient. FISTA works with subgradients (it becomes the "fast subgradient" method).

Actually, for a Lipschitz convex function, the fast subgradient method (Nesterov) gives $O(1/T)$ convergence. Since each $b_k(a)$ is a quadratic form, the max is piecewise quadratic and has bounded gradient on bounded sets.

The projection onto the simplex $\{a \geq 0, \sum a = S\}$:
Given $z \in \mathbb{R}^n$, find $a = \text{Proj}(z)$:
$a_i = \max(0, z_i - \tau)$ for some $\tau$ such that $\sum a_i = S$.

To find $\tau$: sort $z$ in decreasing order, then find the right threshold. This is $O(n \log n)$.

Actually, I realize I should also try a fundamentally different approach: **alternating minimization between the sequence and the "active" convolution entries**.

Idea:
1. Fix the set of $k$ where $b_k$ is at the max.
2. Minimize $\max_{k \in K} b_k$ over $a \geq 0, \sum a = S$.
3. Update $K$ based on the current $a$.

For a fixed active set $K = \{k_1, \ldots, k_m\}$, the problem is:
$$\min_a \max_{j} (a*a)_{k_j}$$

This is a convex problem (minimize the max of convex quadratics). It can be solved by bisection on $t$:
- Check: is there $a \geq 0, \sum a = S$ with $(a*a)_{k_j} \leq t$ for all $j$?
- This is a feasibility problem (quadratic constraints), solvable by SDP or by bisection.

But for $m$ constraints and $n$ variables, this is a QP feasibility problem. For small $m$ (say 2-5 active constraints), it's manageable.

Actually, the active set is typically small (1-3 values of $k$). So the problem is:
$$\min_a t \quad \text{s.t.} \quad (a*a)_{k_j} \leq t, \; a \geq 0, \; \sum a = S$$

This is a second-order cone program (SOCP) or QP. I could use scipy.optimize.minimize for this.

But for $n = 6121$, even a QP with 6121 variables and a few constraints might be slow.

Let me just go with the FISTA approach. It's simple, efficient, and should work well.

Let me also add a "smoothing" step: after FISTA converges, do a few steps of minimizing the smoothed max (using a softmax approximation):
$$\tilde{f}(a) = \frac{1}{\epsilon} \log \sum_k \exp(\epsilon b_k)$$

This is smooth and has a well-defined gradient:
$$\nabla_a \tilde{f}(a) = \sum_k p_k \nabla_a b_k$$

where $p_k = \exp(\epsilon b_k) / \sum_j \exp(\epsilon b_j)$.

The gradient $\nabla_a b_k$ is a "shifted and truncated" version of $a$, so computing $\sum_k p_k \nabla_a b_k$ requires combining shifted versions of $a$ weighted by $p_k$.

For $n = 6121$ and $2n-1 = 12241$ values of $k$, this is a sum of 12241 shifted copies of $a$, which is $O(n^2)$ naively. But we can use FFT:

$\nabla_a \tilde{f}(a)_i = \sum_k p_k a_{k-i}$ (with bounds check).

This is a convolution-like operation: $\sum_k p_k a_{k-i} = (p * a)(i)$ where $p$ is defined on $[0, 2n-2]$.

Wait, $(p * a)(i) = \sum_k p_k a_{i-k}$... let me be careful with indices.

$\nabla_a \tilde{f}(a)_i = \sum_k p_k \cdot \frac{\partial b_k}{\partial a_i}$

$\frac{\partial b_k}{\partial a_i} = a_{k-i}$ if $0 \leq k-i \leq n-1$, else 0.

So $\nabla_a \tilde{f}(a)_i = \sum_{k: 0 \leq k-i \leq n-1} p_k a_{k-i}$.

Let $j = k-i$. Then $k = i+j$, and the sum is over $j$ such that $0 \leq j \leq n-1$ and $0 \leq i+j \leq 2n-2$.

$\nabla_a \tilde{f}(a)_i = \sum_{j=\max(0,-i)}^{\min(n-1, 2n-2-i)} p_{i+j} a_j$.

This is like a "cross-correlation" of $p$ and $a$. It can be computed via FFT:
- Pad $p$ to length $4n$, compute FFT
- Pad $a$ to length $4n$, compute FFT
- Multiply, inverse FFT, extract the relevant part

The overall cost is $O(n \log n)$ per gradient evaluation.

With FISTA + smoothed max, the convergence is $O(1/T)$, and each iteration is $O(n \log n)$. For $n = 6121$, each iteration is about 100 μs. In 1300s, we can do about 10 million iterations. The $O(1/T)$ convergence means we need $T \sim 1/\epsilon$ iterations for precision $\epsilon$. For $\epsilon = 10^{-4}$, we need $T \sim 10^4$ iterations. Very feasible.
