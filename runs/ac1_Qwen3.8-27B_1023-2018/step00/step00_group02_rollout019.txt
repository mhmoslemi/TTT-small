If x^2 is max: AC1 = 4x^2/(x+1)^2. Minimize: d/dx [x^2/(x+1)^2] = 2x(x+1)^2 - x^2*2(x+1)/(x+1)^4 = 2x(x+1)-2x^2/(x+1)^2 = 2x/(x+1)^2. This is > 0 for x>0, so AC1 increases with x. Best is smallest x where x^2 >= 2x and x^2 >= 1, i.e., x>=2. at x=2: AC1=4*4/9=16/9. ✓

If 2x is max: AC1 = 8x/(x+1)^2. Minimize: d/dx [x/(x+1)^2] = (x+1)^2 - x*2(x+1)/(x+1)^4 = (x+1-2x)/(x+1)^3 = (1-x)/(x+1)^3. Min at x=1: AC1=8/4=2. At x=2: AC1=16/9. In between: at x=1.5: AC1=12/6.25=1.92.

If 1 is max (x<=1): AC1=4/(x+1)^2. Min at x=1: AC1=1. But x=1 gives [1,1] and AC1=2 (contradiction!). Let me recheck: a=[1,1], conv=[1,2,1], max=2, not 1. So 2x=2 > 1, so we're in the "2x is max" regime.

Let me think about what structure achieves AC1 ≈ 1.5 for large n.

If the peak of the convolution is at the center (k=n-1) and has value M, and the sequence is "asymmetric" (e.g., increasing), then M = sum_i a[i]*a[n-1-i].

If a[i] = i+1 (linearly increasing): a[i]*a[n-1-i] = (i+1)*(n-i). Sum over i: sum (i+1)(n-i) = n*sum(i+1) - sum(i+1)*i = n*n(n+1)/2 - ... this is complicated.

Actually, for a[i] = i+1, i=0..n-1:
sum a[i] = n(n+1)/2
(a*a)_{n-1} = sum_i (i+1)*(n-i) = sum_i [(i+1)*n - (i+1)*i] = n*sum(i+1) - sum(i^2+i)
= n*n(n+1)/2 - (n(n+1)(2n+1)/6 + n(n+1)/2)
= n^2(n+1)/2 - n(n+1)(2n+1)/6 - n(n+1)/2
= n(n+1)[n/2 - (2n+1)/6 - 1/2]
= n(n+1)[3n/6 - (2n+1)/6 - 3/6]
= n(n+1)(n-4)/6

AC1 = 2n * n(n+1)(n-4)/6 / (n(n+1)/2)^2 = 2n * n(n+1)(n-4)/6 / (n^2(n+1)^2/4)
= 2n * 4(n-4) / (6(n+1))
= 8n(n-4) / (6(n+1))
= 4n(n-4) / (3(n+1))
≈ 4n/3 for large n.

That's terrible (grows with n). So linear increase is bad.

What about a "bump" in the middle? a[i] = 1 for |i-n/2| < w, 0 otherwise (top-hat of width w centered in the middle).
Then the convolution peak is w^2 (at the center), sum = w.
AC1 = 2n * w^2 / w^2 = 2n. Terrible!

What about a "bump" at the edge? a[i] = 1 for i < w, 0 otherwise.
Conv peak: at k=w-1, value = w. sum = w.
AC1 = 2n * w / w^2 = 2n/w.
For w = n: AC1 = 2 (uniform). For w = n/2: AC1 = 4. Worse.
