Actually, let me think about this differently. The problem is:
minimize f(x) = max_k c_k(x) subject to sum(x) = 1, x >= 0

where c_k(x) = sum_i x_i * x_{k-i}.

This is a convex optimization problem? Let's check: c_k(x) = sum_i x_i * x_{k-i} is a quadratic form x^T Q_k x where Q_k is a symmetric matrix. Is Q_k positive semidefinite?

Q_k[j, i] = 1 if k - j = i (i.e., i = k - j) and 0 <= k-j < n, else 0.
So Q_k is a "reverse identity" type matrix (anti-diagonal). It's symmetric since Q_k[j,i] = 1 iff i = k-j iff j = k-i.

Is Q_k PSD? For k = n-1 (center): Q_{n-1}[j,i] = 1 if i = n-1-j. This is the "reversal" matrix. Its eigenvalues are 1 (with multiplicity ceil(n/2)) and -1 (with multiplicity floor(n/2)). So it's NOT PSD!

This means c_k(x) is NOT convex in general. The problem is non-convex.

However, for the center position k = n-1: c_{n-1}(x) = sum_i x_i * x_{n-1-i}. This is an inner product of x with its reversal. For x >= 0, by AM-GM, c_{n-1}(x) <= sum_i (x_i^2 + x_{n-1-i}^2)/2 = sum_i x_i^2. And c_{n-1}(x) >= 0.

So the problem is non-convex, and gradient methods might get stuck in local minima. The LP approach from the state of the art is better because it handles the non-convexity by linearizing.
