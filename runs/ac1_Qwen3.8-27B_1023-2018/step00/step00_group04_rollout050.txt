**Algorithm Plan:**

1. Generate several candidate initial shapes:
   - The parent (height_sequence_1)
   - Uniform
   - Quarter-sine / cosine
   - Linear ramp (increasing or decreasing)
   - Exponential decay
   - A "step" + smooth transition

2. For each, run an iterative refinement:
   - Compute score using the exact evaluator
   - Compute the autocorrelation
   - Compute the subgradient of the score
   - Take a projected subgradient step
   - Optionally: do a "smoothing" pass

3. Keep track of the best score seen
4. Return the best candidate

For the iterative refinement, the key operation is:
- Compute b = convolve(a, a) [O(n log n) with FFT]
- Find k* = argmax(b)
- Compute subgradient: for the active constraint at k*, the gradient is:
  grad[i] = a[k*-i] (if valid) + (a[i] if k*=2i)
  (this is ∂b_{k*}/∂a_i)
- But we also need to account for the 1/S² factor in the score.

Actually, since the score is scale-invariant, let me normalize a to sum=1 at each step. Then:
score = 2n * max_b (where b = convolve(a,a) and sum(a)=1)

∂score/∂a_i at the active lag k*:
= 2n * ∂b_{k*}/∂a_i - 2n * max_b * 2 * (∂sum(a)/∂a_i) / sum(a) ... 

Wait, if we don't fix sum(a), the score is:
score(a) = 2n * max_k b_k(a) / (sum a)²

∂score/∂a_i = 2n/S² * ∂max_b/∂a_i - 4n*max_b/S³

where S = sum(a).

At the active lag k*: ∂max_b/∂a_i = ∂b_{k*}/∂a_i = a_{k*-i} (for valid k*-i) [+ a_i if k*=2i]

So the subgradient is:
∂score/∂a_i = 2n/S² * a_{k*-i} - 4n*max_b/S³  (for valid k*-i)
∂score/∂a_i = -4n*max_b/S³  (for invalid k*-i, i.e., a_i doesn't contribute to b_{k*})

This means:
- Elements that contribute to the peak (a_{k*-i} is nonzero) should be reduced
- Elements that don't contribute to the peak should be increased (the -4n*max_b/S³ term is negative, so we increase a_i)
- But the reduction for contributing elements depends on a_{k*-i}

A simple update:
a_i ← a_i - lr * (2n/S² * a_{k*-i} - 4n*max_b/S³)
   = a_i - lr * 2n/S² * (a_{k*-i} - 2*max_b/S)

Since S ≈ 1 (normalized), this simplifies to:
a_i ← a_i - lr * 2n * (a_{k*-i} - 2*max_b)

For non-contributing elements (a_{k*-i} = 0):
a_i ← a_i - lr * 2n * (-2*max_b) = a_i + lr * 4n * max_b

So we're adding uniform mass to non-contributing elements and removing mass proportional to the "mirror" value from contributing elements.

After the update, clip to [0, ∞) and renormalize.

This is essentially a "move mass from the peak-contributing region to the non-contributing region" operation.

Let me also consider using multiple active lags (not just the max, but all lags above some threshold). This would give a smoother gradient.
