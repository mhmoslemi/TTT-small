Which can be computed via FFT in O(n log n).

As t → ∞, p concentrates on the max, and we recover the subgradient. For moderate t, we get a smoothed gradient that's easier to optimize.

**Algorithm:**
1. Start with a = parent (normalized to sum = 1)
2. For each iteration:
   a. Compute c = conv(a, a) via FFT
   b. Compute p = softmax(t * c) (with temperature t)
   c. Compute gradient g = 2 * cross_corr(p, a) via FFT
   d. Projected gradient step: a_new = proj(a - alpha * g)
   e. Adapt t (increase over time to sharpen)
   f. Update a = a_new
3. Periodically check the actual objective and update best

Let me think about the projected step more carefully:
a_new = argmin_x (1/2)||x - y||^2 subject to x >= 0, sum x = 1
where y = a - alpha * g

The solution is: x[j] = max(0, y[j] - lambda) for some lambda chosen so sum x = 1.

We can find lambda by bisection: O(n * log(1/epsilon)).

**Step size**: For the smoothed objective, we can use a larger step size. A good choice is:
alpha = 1 / (t * max_k |g[k]|) or alpha = c / sqrt(iteration)

Let me also think about **momentum** (Nesterov or simple momentum):

a_new = proj(a - alpha * v)

This can accelerate convergence.
