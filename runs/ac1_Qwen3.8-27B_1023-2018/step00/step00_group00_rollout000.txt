    For nonnegative a, the central autocorrelation is sum(a_i^2), and
    max(conv(a, a)) = sum(a_i^2).  Hence

        score = 2 * n * sum(a_i^2) / sum(a_i)^2 >= 2

    by Cauchy-Schwarz, with equality exactly for constant-height sequences.
    Return constant heights of the constructed length (or a safe fallback).
    """
    try:
        n = int(len(height_sequence_1))
    except Exception:
        n = 4806

    if n <= 0:
        n = 4806

    # The actual supplied construction has length 4806.  If a parent of some
    # unexpectedly large size were present, fall back to the known safe length
    # to keep memory use bounded.
    if n > 1_000_000:
        n = 4806

    candidate = [1.0] * n

    # Final authoritative validation; fall back to a minimal optimal sequence
    # if something unexpected happens.
    try:
        score = evaluate_sequence(candidate)
        if not (score < float("inf")):

    except Exception:
        pass
