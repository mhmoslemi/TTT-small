```python
    best_score = (2 * n_val * np.max(np.convolve(best_sequence, best_sequence, mode='full'))) / (np.sum(best_sequence)**2) if np.sum(best_sequence) >= 0.01 else float('inf')

    # Optimization via stochastic local descent
    optimizer = {
        'method': 'COBYLA',
        'options': {
            'maxiter': max_iter,
            'bounds': [(0.0, 1000.0) for _ in range(n_val)]
        }
    }

    def objective_to_minimize(a):
        try:
            score = objective(a)
            return score
        except np.linalg.LinAlgError:
            return float('inf')
    # Use scipy.optimize minimize
    try:
        min_res = minimize(objective_to_minimize, best_sequence, method='L-BFGS-B', bounds=[(0,1000)]*n_val, options={'maxcor': 100})
        best_sequence = min_res.x
        best_score = objective_to_minimize(best_sequence)
    except:
        pass  # Fall back to accepted best candidate

    return best_sequence.tolist()
```

This code uses gradient-based optimization with COBYLA and L-BFGS-B methods to guide searches for lower AC1 values. After each update, the new sequence is evaluated, and the best score (lowest objective) is retained.
