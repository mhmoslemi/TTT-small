For 0 <= k <= n-1: b[k] = sum_{i=0}^{k} ((i+1)/(n+1)) * ((k-i+1)/(n+1))
= 1/(n+1)² * sum_{i=0}^{k} (i+1)(k-i+1)

Actually, for the ramp a[i] = (i+1)/C where C = n+1:
b[k] = (1/C²) * sum_{valid i} (i+1)(k-i+1)

The sum (i+1)(k-i+1) = (k+2)sum(j) - sum(j²) for j=1 to k+1 = (k+2)(k+1)(k+2)/2 - (k+1)(k+2)(2k+3)/6 = (k+1)(k+2)(k+3)/6.

So for 0 <= k <= n-1: b[k] = (k+1)(k+2)(k+3)/(6C²)
For n <= k <= 2n-2: by symmetry of the ramp (reversed), b[k] = (2n-1-k+1)(2n-1-k+2)(2n-1-k+3)/(6C²) = (2n-k)(2n-k+1)(2n-k+2)/(6C²)

Wait, that's not quite right. Let me just compute b[n] directly.
b[n] = sum_{i=1}^{n-1} ((i+1)/C)((n-i+1)/C) = (1/C²) sum_{i=1}^{n-1} (i+1)(n-i+1)

Let j = i+1, j from 2 to n:

For large n: ≈ (1/C²)[(n+2)(n²/2) - n³/3] = (1/C²)[n³/2 + n³... ] hmm let me just compute the leading term.

C² = (n+1)² ≈ n².
