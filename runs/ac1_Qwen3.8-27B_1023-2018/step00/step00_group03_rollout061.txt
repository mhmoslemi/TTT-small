This is a nonconvex optimization problem (max of linear functions).

Key insight: The convolution `c[k]` is a quadratic form in `a`. Specifically:
`c[k] = sum_{i: max(0,k-n+1) <= i <= min(k,n-1)} a[i] * a[k-i]`

These are quadratic (bilinear) forms. The constraint is linear (sum = 1, a >= 0).

This is a nonconvex quadratic program. The feasible set is the simplex.
