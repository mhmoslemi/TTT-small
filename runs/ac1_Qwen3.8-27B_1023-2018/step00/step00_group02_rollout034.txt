    n = len(p)

    constraint_list = []  # list of (k,) indicating which convolution index is a constraint

        # Solve: max sum(g) s.t. g >= 0 and (p*g)[k] <= M for k in constraint_list
        # Using scipy linprog
        c = -np.ones(n)  # minimize -sum(g)
        A_ub = []

Let me think about what would make the gradient descent more effective.

The issue is that from a constant initialization, the "direction" to reduce the max is not obvious. The gradient points in a direction that reduces the smoothed max, but the actual max might not decrease monotonically.

One key insight: the projection onto the simplex changes the direction. After the gradient step, projecting onto the simplex can undo some of the progress.

Another approach: instead of projected gradient descent, use an "unconstrained" parameterization. For example, parameterize p = exp(w) / sum(exp(w)) (softmax parameterization), and optimize over w without constraints. This avoids the projection issue.

Let me try this:
- Parameterize p_i = exp(w_i) / sum_j exp(w_j)
- The constraint p >= 0, sum p = 1 is automatically satisfied
- Optimize over w (unconstrained)

The gradient with respect to w:
∂p_i/∂w_j = p_i * (δ_ij - p_j)

So ∂F/∂w_j = sum_i (∂F/∂p_i) * p_i * (δ_ij - p_j)
= p_j * (∂F/∂p_j - sum_i ∂F/∂p_i * p_i)

This is the "logit gradient" which is well-known in probability.

def _gradient_descent_logit(w, n, beta_init, lr_init, max_iters, deadline, rng, best_score):
    p = np.exp(w - w.max())  # For numerical stability
    p = p / p.sum()
    
    best_p = p.copy()
    best_sc = best_score
    
    beta = beta_init
    lr = lr_init
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        q = _fft_convolve(p, p)
        q_max = q.max()
        scaled = beta * (q - q_max)
        exp_q = np.exp(scaled)
        Z = exp_q.sum()
        softmax = exp_q / Z
        
        # Gradient w.r.t. p
        grad_p = 2.0 * np.correlate(softmax, p, 'full')[:n]
        
        # Convert to gradient w.r.t. w (logit parameterization)
        grad_w = p * (grad_p - grad_p @ p)
        
        # Step
        w -= lr * grad_w
        
        # Recompute p
        p = np.exp(w - w.max())
        p = p / p.sum()
        
        if it % 50 == 0:
            sc = _ac1_score(p, n)
            if sc < best_sc:
                best_sc = sc
                best_p = p.copy()
        
        if it % 500 == 0 and it > 0:
            lr *= 0.97
            beta = min(beta * 1.02, 300.0)
        
        if it % 2000 == 0 and it > 0:
            w += rng.normal(0, 0.1, n)
    
    sc = _ac1_score(p, n)
    if sc < best_sc:
        best_sc = sc
        best_p = p.copy()
    
    return best_p, best_sc
