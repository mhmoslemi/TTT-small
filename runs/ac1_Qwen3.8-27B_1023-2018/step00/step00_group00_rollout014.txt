**Better optimization: Use the fact that the problem is a minimax**

Minimize max_k c_k(a) subject to sum(a) = 1, a >= 0.

This is a convex problem if c_k(a) were convex in a. But c_k(a) = sum_i a_i * a_{k-i} is quadratic (not convex in general - it's a quadratic form that can be indefinite).

However, for the specific structure of the autocorrelation, each c_k is a sum of products of distinct pairs (except the "diagonal" terms where i = k-i, i.e., k even and i = k/2). The off-diagonal terms a_i * a_j (i ≠ j) make c_k a "bilinear" form, which is not convex.

So the problem is non-convex. Gradient methods with care should work though.

**Alternative: Direct minimization of the log-sum-exp**

Minimize log(sum_k exp(beta * c_k)) for large beta (approximates log(max_k c_k)).

d/d a_i log(sum_k exp(beta * c_k)) = beta * sum_k exp(beta*c_k) * d(c_k)/da_i / sum_k exp(beta*c_k)

= beta * sum_k p_k * d(c_k)/da_i

where p_k = exp(beta*c_k) / sum_j exp(beta*c_j) is a softmax over the autocorrelation values.

For large beta, p_k concentrates on the maximum lag(s), and this approaches the subgradient of the max.

The advantage is that it's smooth, so we can use Newton's method or L-BFGS.

But the second derivative involves d^2(c_k)/da_i da_j, which is the Hessian of c_k. For c_k = sum_i a_i a_{k-i}, the Hessian has:
H_k[i,j] = 1 if (j = k-i) or (i = k-j), i.e., if i + j = k or j + i = k... 

Actually, c_k = sum_i a_i a_{k-i}. The Hessian:
H_k[i,j] = dc_k / (da_i da_j)

For i ≠ j: H_k[i,j] = 1 if j = k-i (i.e., j = k-i) AND i = k-j (same condition). So H_k[i,j] = 1 if i + j = k, i ≠ j. And H_k[i,i] = 2 if 2i = k (i.e., i = k/2, k even).

So the Hessian of c_k is a permutation matrix (specifically, the anti-diagonal of an (n x n) matrix, restricted to valid indices). This is very sparse and structured.

The Hessian of the log-sum-exp is:
H = beta * sum_k p_k * H_k + beta^2 * (sum_k p_k * g_k)(sum_j p_j * g_j)^T

where g_k = gradient of c_k.

This is also structured (sum of sparse matrices + rank-1).

For practical purposes, L-BFGS with the log-sum-exp objective should work well.
