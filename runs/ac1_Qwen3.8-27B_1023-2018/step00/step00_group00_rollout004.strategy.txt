 We choose to use a two-level optimization framework that combines:

  Level 1: Active-set identification for the autocorrelation function (convolution) to reduce the dimensionality of the problem.
  Level 2: Euclidean gradient descent (or another first-order method) projected to the box constraints, but using an active-set strategy to focus the optimization on the most significant lags.

 Rational: The autocorrelation function (full convolution) of the sequence is a function of two variables (lags). The objective is dominated by the maximum of this autocorrelation. By identifying the lags that are active (where the convolution achieves its maximum) we can reduce the problem to optimizing only the lags that directly affect the maximum. However, the active set might change during optimization.

 However, note that the problem is non-convex and the active set might not be fixed. Therefore, we design a coordinate descent style algorithm that alternates between:

  1. Estimating the active set (the lags that contribute to the maximum of the autocorrelation) based on the current sequence.
  2. Optimizing the sequence coefficients in the active set, while keeping the others fixed, under the constraint that the active set must still be active (or nearly so) in the next iteration.
