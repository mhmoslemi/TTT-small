import numpy as np
import time

def project_simplex(v, s=1.0):
    """Project v onto the simplex {x >= 0, sum(x) = s}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    # Find rho: largest index where u[rho+1] > (cssv[rho+1] - s) / (rho+1)
    cond = u * np.arange(1, n+1) > (cssv - s)
    rho = np.nonzero(cond)[0][-1] if cond.any() else 0
    theta = (cssv[rho] - s) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

Let me think about what shape DOES work. The example [0.7, 0.3] (n=2) gave 1.96. The key was that a[0]^2 = 0.49 > 2*a[0]*a[1] = 0.42. So the peak was at the "self" term (a[0]^2) rather than the "cross" term.

For longer sequences, the analogous situation would be: a[0]^2 (or a[n-1]^2) is the peak, and it's smaller than (sum)^2/n.

(a[0])^2 < (sum)^2/n ⟺ a[0] < sum/sqrt(n)

For uniform: a[0] = 1/n, sum = 1, sum/sqrt(n) = 1/sqrt(n). Since 1/n < 1/sqrt(n) for n > 1, the condition holds.

But for uniform, the peak is actually at the center (conv[n-1] = 1/n), not at the edge (conv[0] = 1/n^2). So the peak is 1/n, not 1/n^2.

The trick is: we need ALL conv values to be below 1/n. The center value conv[n-1] = sum a[i]*a[n-1-i] must be < 1/n (for sum=1).

For a "slightly non-uniform" sequence, the center value will be close to 1/n, and the edge values will be much smaller. The question is: can we make the center value < 1/n while keeping all other values < 1/n?

For a monotonically increasing sequence a[0] < a[1] < ... < a[n-1]:
conv[n-1] = sum a[i]*a[n-1-i]

By the rearrangement inequality, this is the minimum possible value of sum a[i]*b[i] over all permutations b of a. The maximum is sum a[i]^2 (when b = a, same ordering).

So conv[n-1] ≤ sum a[i]^2, with equality when a is symmetric (a[i] = a[n-1-i]).

For a strictly increasing sequence, conv[n-1] < sum a[i]^2. And by Cauchy-Schwarz, sum a[i]^2 ≥ (sum a)^2/n = 1/n.

So we need: conv[n-1] < 1/n. This requires the sequence to be "sufficiently" non-symmetric.

Let me try: a[i] = (i+1)^p / sum((j+1)^p) for p > 0.
For p=1 (linear): a[i] = (i+1)/sum(j+1) = 2(i+1)/(n(n+1)).
sum a[i]^2 = 4/(n^2(n+1)^2) * sum(i+1)^2 = 4/(n^2(n+1)^2) * n(n+1)(2n+1)/6 = 4(2n+1)/(6n(n+1)) ≈ 4/(3n) for large n.
conv[n-1] = sum a[i]*a[n-i] = 4/(n^2(n+1)^2) * sum (i+1)(n-i) for i=0 to n-1
= 4/(n^2(n+1)^2) * [n*sum(i+1) - sum(i+1)*i]
= 4/(n^2(n+1)^2) * [n*n(n+1)/2 - n(n+1)(2n+1)/6]
= 4/(n^2(n+1)^2) * n(n+1)[n/2 - (2n+1)/6]
= 4/(n(n+1)) * (3n - 2n - 1)/6
= 4/(n(n+1)) * (n-1)/6
= 4(n-1)/(6n(n+1))
≈ 4/(6n) = 2/(3n) for large n.

So conv[n-1] ≈ 2/(3n) < 1/n.
