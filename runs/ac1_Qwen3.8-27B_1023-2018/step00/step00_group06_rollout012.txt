So the approach is:
1. Start with some f (e.g., uniform)
2. Set M = ||f*f||_inf (current value)
3. Solve LP: max sum(b) s.t. b >= 0, (f*b)[k] <= M for all k
4. Normalize: g = (sum(f)/sum(b)) * b (to maintain sum = 1)
5. Update: f <- (1-t)*f + t*g
6. Repeat

This is the "dual" approach. The idea is that if f is optimal, then the LP should return f itself (or something proportional to it), since you can't do better.

This is similar to the multiplicative weights / mirror descent approach, or the Frank-Wolfe method in a way.
