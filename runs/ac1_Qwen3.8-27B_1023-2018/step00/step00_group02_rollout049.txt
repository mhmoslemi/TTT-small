For $i \ge 0$ and $k \in [0, 2n-2]$: $k - i \in [-i, 2n-2]$. If $-i < 0$, then $(k-i) \mod N = k - i + N$. We need $x[k-i+N] = 0$ for the linear version. Since $x$ has support $[0, n-1]$ and $N \ge 3n-2$, we have $k - i + N \ge -i + N \ge N - (n-1) \ge 2n - 1 > n - 1$ (for $N \ge 3n-2$ and $i \le n-1$). So $x[k-i+N] = 0$. ✓

Similarly for $k-i > n-1$: $x[k-i] = 0$ in the linear version, and in the circular version, $x[k-i]$ is also 0 since $k-i < 2n-2 < N$ and $x$ is zero outside $[0, n-1]$. ✓

So the formula works. Let me proceed.

**Alternative: use the top-K active constraints directly**

Instead of softmax, use the top K values of $b[k]$ and average their gradients. This is closer to the true subgradient of $\max$.

active = np.argpartition(b, -K)[-K:]
grad = np.zeros(n)
for k in active:

    # x[k-hi], x[k-hi+1], ..., x[k-lo]
