- The denominator is $(\sum a_i)^2$

For a uniform sequence $a_i = c$, the autocorrelation at lag 0 is $nc^2$, and $\sum a_i = nc$, so:
$AC1 = \frac{2n \cdot nc^2}{(nc)^2} = \frac{2n}{n} = 2$

That's why the parent gets 2.0 (it's essentially uniform).

To get below 2, we need to reduce the peak autocorrelation relative to the mean. This means we want a sequence where the autocorrelation is as flat as possible (Wiener-Khinchin pairing).

The key insight: By Parseval's theorem, the autocorrelation $b_k = \sum_i a_i a_{i+k}$ has DFT $\hat{b}_k = |\hat{a}_k|^2$. So $\max_k b_k$ is related to the peak of the inverse DFT of $|\hat{a}|^2$.

To minimize $\max_k b_k$, we want $|\hat{a}_k|$ to be as flat as possible (white spectrum). This is like designing a sequence with flat autocorrelation.

Since $a_i \geq 0$, this is a constraint. The classic flat autocorrelation sequences (like Barker, Zadoff-Chu) are complex-valued. With the nonnegativity constraint, we need a different approach.

The objective is:
$$f(a) = \frac{2n \cdot M(b)}{S^2}$$
where $M(b) = \max_k b_k$ and $S = \sum a_i$.

For the active constraint at lag $k^*$ where $b_{k^*} = M(b)$:
$$\frac{\partial f}{\partial a_i} = \frac{2n}{S^2} \frac{\partial b_{k^*}}{\partial a_i} - \frac{4n M(b)}{S^3} \frac{\partial S}{\partial a_i}$$

$$\frac{\partial b_{k^*}}{\partial a_i} = a_{i+k^*} + a_{i-k^*}$$ (with boundary handling)
$$\frac{\partial S}{\partial a_i} = 1$$

So the gradient at the active lag is:
$$\nabla_i f = \frac{2n}{S^2}(a_{i+k^*} + a_{i-k^*}) - \frac{4n M(b)}{S^3}$$

This can be computed in $O(n)$ once we know the active lag!

This is like an "equalization" problem. At the optimum, all $c[k]$ should be equal (approximately), giving $c[k] = S^2/(2n-1)$ and $f = 2n/(2n-1) \approx 1 + 1/(2n-1)$.

But this is a necessary condition, not achievable for nonnegative sequences in general (it would require a specific sequence structure).

For the gradient approach: at the optimum, the gradient should be zero (or the gradient of the max should be zero for the active lags). This means:
$\frac{4n}{S^2} a[k^*-i] = \frac{4nC}{S^3}$ for all $i$ where $0 \leq k^*-i \leq n-1$

I.e., $a[k^*-i] = C/(nS)$ for all valid $i$.

Since $C = c[k^*] = \sum_j a[j]a[k^*-j] = \sum_j a[j](C/(nS))$ (at optimum) $= C/(nS) \cdot S = C/n$.

So at optimum: $C/n = C/(nS) \cdot S = C/n$. Consistent.
