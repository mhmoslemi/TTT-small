The minimum possible value of $\max_k q_k$ is $1/(2n-1)$ (achieved if $q$ is uniform), but this is not achievable for a sum distribution.

The constraint is that $q$ must be a valid sum distribution of a distribution on $\{0, ..., n-1\}$. The set of valid sum distributions is a convex set (the Minkowski sum of the probability simplex with itself), and we want to find the point in this set that minimizes the max coordinate.

This is a linear programming problem! We want to minimize $t$ subject to:
- $q_k \leq t$ for all $k$
- $q$ is in the Minkowski sum of the probability simplex
- $\sum q_k = 1$

The constraint "$q$ is in the Minkowski sum" can be written as: there exists $p \geq 0, \sum p_i = 1$ such that $q_k = \sum_i p_i p_{k-i}$.

This is a non-convex constraint (it's quadratic in $p$). So the overall problem is non-convex.

However, we can use the fact that for a fixed $t$, the question "is there a $p$ such that $\max_k q_k \leq t$" can be checked... well, it's still non-convex.

Let me just go with the numerical approach. I'll implement:
1. Projected gradient descent on the peak of the convolution.
2. Multiple restarts with different initializations.
3. A "deflation" technique: after finding a local minimum, perturb the solution in a direction that increases the already-small lags (to "flatten" the convolution).

Actually, here's a better idea. Instead of minimizing the max, I can minimize a smooth approximation:
$\phi_T(c) = \frac{1}{T} \log \sum_k \exp(T \cdot c_k)$

This is the "soft max" and converges to the hard max as $T \to \infty$. The gradient is:
$\nabla_x \phi_T(c) = \sum_k \frac{T \cdot c_k \cdot \exp(T \cdot c_k)}{\sum_j \exp(T \cdot c_j)} \nabla_x c_k = \sum_k w_k \nabla_x c_k$

where $w_k = T \cdot c_k \cdot \exp(T c_k) / \sum_j \exp(T c_j) = T \cdot \text{softmax}(Tc)_k$.

Wait, that's not quite right. Let me redo:
$\phi_T(c) = \frac{1}{T} \log \sum_k \exp(T c_k)$
$\frac{\partial \phi_T}{\partial c_k} = \exp(T c_k) / \sum_j \exp(T c_j) = \text{softmax}(Tc)_k$
$\nabla_x \phi_T = \sum_k \text{softmax}(Tc)_k \cdot \nabla_x c_k$

As $T \to \infty$, the softmax concentrates on the max, and we recover the hard max gradient.

For finite $T$, we get a smooth objective that's easier to optimize. We can start with small $T$ (smooth) and gradually increase $T$ (sharper).

import numpy as np
import time


def _project_simplex(v):
    """Project v onto the unit probability simplex {x >= 0, sum x = 1}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.arange(1, n + 1)
    cond = u * rho > (cssv - 1)
    if not np.any(cond):
        return np.ones(n) / n
    rho_val = rho[cond][-1]
    theta = (cssv[rho_val - 1] - 1) / rho_val
    return np.maximum(v - theta, 0)


def _make_soft_max_grad(x, c, T, fft_size, conv_size, n):
    """Compute gradient of the soft-max objective using FFT-based cross-correlation."""
    TC = T * c
    TC_max = TC.max()
    exp_TC = np.exp(TC - TC_max)
    W = exp_TC / exp_TC.sum()
    # g_j = 2 * sum_m W_{j+m} * x_m  (cross-correlation)
    XF = np.fft.rfft(x, fft_size)
    WF = np.fft.rfft(W, fft_size)
    g = np.fft.irfft(XF * WF, fft_size)[:n] * 2.0
    return g, W


def _full_conv(x, fft_size, conv_size):
    X = np.fft.rfft(x, fft_size)
    return np.fft.irfft(X * X, fft_size)[:conv_size]


def _optimize_single(x0, n, fft_size, conv_size, deadline, rng, T_init=5.0, T_max=100.0):
    """Run projected gradient descent with soft-max homotopy."""
    x = x0.copy()
    c = _full_conv(x, fft_size, conv_size)
    local_best_x = x.copy()
    local_best_peak = c.max()
    alpha = 0.02
    momentum = np.zeros_like(x)
    beta = 0.5
    T = T_init
    stalled = 0
    max_stall = 80
    It = 0

    while time.monotonic() < deadline:
        It += 1
        # Compute gradient
        g, W = _make_soft_max_grad(x, c, T, fft_size, conv_size, n)
        gn = np.linalg.norm(g)
        if gn < 1e-14:
            break
        g /= gn

        # Momentum update
        momentum = beta * momentum + alpha * g
        x_new = x - momentum
        x_new = _project_simplex(x_new)

        # Evaluate
        c_new = _full_conv(x_new, fft_size, conv_size)
        peak_new = c_new.max()

        if peak_new < local_best_peak:
            local_best_peak = peak_new
            local_best_x = x_new.copy()
            x = x_new
            c = c_new
            alpha = min(alpha * 1.02, 0.3)
            beta = min(beta * 1.005, 0.85)
            stalled = 0
            # Increase temperature periodically
            if It % 200 == 0:
                T = min(T * 1.25, T_max)
        else:
            alpha *= 0.85
            momentum *= 0.5
            stalled += 1
            if stalled > max_stall:
                # Perturb to escape local minimum
                x_new = x + 0.005 * rng.standard_normal(n)
                x_new = _project_simplex(x_new)
                c_new = _full_conv(x_new, fft_size, conv_size)
                x = x_new
                c = c_new
                momentum = np.zeros_like(x)
                alpha = 0.02
                T = max(T_init, T * 0.7)
                stalled = 0

    return local_best_x, 2.0 * n * local_best_peak
