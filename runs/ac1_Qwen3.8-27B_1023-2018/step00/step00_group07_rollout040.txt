The standard algorithm (Duchi et al., 2011) runs in O(n log n):
1. Sort x in decreasing order: x_(1) >= x_(2) >= ... >= x_(n)
2. Find the largest ρ such that sum_{i=1}^{ρ} (x_(i) - τ) > 0 where τ = (sum_{i=1}^{ρ} x_(i) - 1) / ρ
3
. Project: x_proj[i] = max(0, x[i] - τ)

Actually, a simpler approach for our case (since we always start close to the simplex) is:
1. Clip to nonnegative: x = max(0, x)
2. Normalize: x = x / sum(x)

This is an approximation of the exact projection but is much faster (O(n) vs O(n log n)). For our purposes, it should be fine.
