So for n=2, the minimum seems to be 2 (at uniform). Let me verify.
score = 4*max(x^2, 2xy, y^2)/(x+y)^2.
WLOG x >= y >= 0. Then max = max(x^2, 2xy). x^2 >= 2xy iff x >= 2y.
Case 1: x >= 2y. max = x^2. score = 4x^2/(x+y)^2. Minimized when y is as large as possible: y = x/2 (boundary). score = 4x^2/(3x/2)^2 = 4/(9/4) = 16/9 ≈ 1.78.
Case 2: x < 2y (i.e., x/y < 2). max = 2xy. score = 8xy/(x+y)^2. Let r = x/y. score = 8r/(r+1)^2. Maximized at r=1 (uniform): score = 8/4 = 2. Minimized at r→0 or r→2: at r=2, score = 16/9.

So for n=2, the minimum is 16/9 ≈ 1.78 at the boundary x/y = 2 (or y/x = 2).
