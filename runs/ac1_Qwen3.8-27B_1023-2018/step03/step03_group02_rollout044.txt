This is O(n log n) with FFT-based convolution.

Now let me think about the overall algorithm:

1. Start with parent (height_sequence_1)
2. Normalize to sum = 1
3. Iteratively:
   a. Compute soft-max objective and gradient
   b. Take a gradient step with line search
   c. Project onto {a >= 0, sum = 1}
   d. Or: use the LP projection (alternating)
4. Final polish with coordinate descent

Let me also think about the LP approach more carefully. The LP is:
max sum(g)
s.t. (f*g)_k <= M for all k = 0,...,2n-2
     g >= 0

The constraint matrix A has A[k,j] = f[(k-j) mod n]... no, A[k,j] = f[k-j] if 0 <= k-j < n, else 0.

This is a banded matrix! A[k,j] is nonzero only when 0 <= k-j < n, i.e., j <= k < j+n. So each row has at most n nonzeros, and each column has at most n nonzeros. The matrix is banded with bandwidth n on both sides.

For n=384, the matrix is 767 x 384, which is small enough to store densely.

Let me think about what M should be. If we normalize f to sum=1, then M = max(conv(f,f)). The LP finds the best g that can "fit" under this constraint.

Actually, I think a better approach might be:

1. Normalize a to sum = 1
2. Compute c = conv(a, a), M = max(c)
3. Solve the LP: max sum(g) s.t. conv(a, g)_k <= M, g >= 0
4. This gives a new g. Normalize g to sum = 1.
5. New a = (1-t)*a + t*g
6. Repeat

The key question is: does this converge to the global optimum? In general, no - it's a nonconvex problem and we're doing alternating minimization. But it should improve the score at each step (or at least not worsen it significantly).

Let me also consider: instead of the LP, I could use a QP:
min (1/2)*g'Tg + c'g
s.t. conv(a,g)_k <= M, g >= 0

where T encodes the quadratic cost. But this might be harder to solve.

Actually, the simplest and most effective approach might be:

1. Use the LP projection for the main optimization
2. Add a "flattening" step: after the LP, identify the top-k constraints (where conv is near M) and try to reduce them specifically
3. Use a multiplicative update: a_j *= exp(-eta * grad_j) / Z (like natural gradient)

Let me now write the actual code. I'll focus on:
- LP projection with the parent's approach but improved
- Soft-max gradient descent as an alternative
- Coordinate descent for polishing
- Multiple initializations
- Time management

Let me also consider: what if I try a different n? The score is 2n * max_conv / S^2. For a "good" sequence of length n, the score should be roughly constant (maybe slightly better for larger n due to the 2n/(2n-1) lower bound getting closer to 1).

But the LP cost grows with n, so there's a tradeoff. n=384 is fine.

import numpy as np
import time
import math
from scipy.fft import rfft, irfft, next_fast_len
from scipy.optimize import linprog

def _get_parent():
    try:
        h = globals()["height_sequence_1"]
        p = np.asarray(h, dtype=np.float64).ravel()
    except Exception:
        p = np.ones(384, dtype=np.float64)
    if p.size == 0:
        p = np.ones(384, dtype=np.float64)
    p = np.clip(p, 0.0, 1000.0)
    p = np.where(np.isfinite(p), p, 0.0)
    if p.size == 0:
        p = np.ones(384, dtype=np.float64)
    return p

def _conv_full(a):
    n = len(a)
    fsize = next_fast_len(2 * n - 1)
    F = rfft(a, fsize)
    c = irfft(F * F, fsize)[:2 * n - 1]
    np.maximum(c, 0.0, out=c)
    return c

def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 0.01:
        return math.inf
    b = _conv_full(a)
    m = float(b.max())
    if not math.isfinite(m) or m < 0:
        return math.inf
    return 2.0 * n * m / (s * s)

def _norm1(a):
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s

def _build_A(f, n):
    """Build constraint matrix for LP: A[k,j] = f[k-j] if 0<=k-j<n else 0"""
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        A[j:j+n, j] = f
    return A

def _lp_project(f, n, M, time_limit=15.0):
    """Solve LP: max sum(g) s.t. conv(f,g)_k <= M, g >= 0"""
    A = _build_A(f, n)
    c_obj = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    try:
        res = linprog(
            c_obj, A_ub=A, b_ub=b_ub,
            bounds=[(0, None)] * n,
            method="highs",
            options={"presolve": True, "time_limit": time_limit}
        )
    except Exception:
        return None
    if res.status not in (0, 3) or res.x is None:
        return None
    g = np.asarray(res.x, dtype=np.float64)
    gs = g.sum()
    if gs < 1e-12:
        return None
    return g / gs

def _softmax_step(a, beta, eta, n):
    """One step of gradient descent on soft-approx of max conv."""
    c = _conv_full(a)
    # Soft-max
    c_b = c * beta
    c_max = c_b.max()
    exp_c = np.exp(c_b - c_max)
    w = exp_c / exp_c.sum()  # softmax weights
    
    # Gradient: grad[j] = sum_i a[i] * w[i+j]
    a_rev = a[::-1]
    conv_res = np.convolve(a_rev, w, 'full')  # length n + (2n-1) - 1 = 3n-2
    grad = conv_res[n-1:n-1+n]
    
    # Gradient step
    a_new = a - eta * grad
    a_new = np.maximum(a_new, 0)
    a_new = _norm1(a_new)
    return a_new, grad, c

def _lp_optimize(f0, n, stop_time, seed, max_iter=200):

    f = np.clip(np.asarray(f0, dtype=np.float64).ravel()[:n].copy(), 0, None)

    b_current = _conv_full(f)
    M = float(b_current.max())
    
    t = 0.4

    t_max = 0.9
    stall = 0
    max_stall = 80
    iter_count = 0

            if stall > max_stall:

            continue
