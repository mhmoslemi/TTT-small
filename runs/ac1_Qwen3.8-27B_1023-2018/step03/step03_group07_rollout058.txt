One more consideration: I want to make sure the LP convergence is tight. The key question is: when does the LP best-response iteration converge to a local minimum?

The iteration is: $a_{t+1} = (1-\alpha) a_t + \alpha \cdot g_t^* / \sum g_t^*$ where $g_t^*$ is the LP optimum.

This is a Papaszpir-Penrose type fixed-point iteration. It converges when $a_t$ is a fixed point, i.e., when the LP optimum (normalized) equals $a_t$.

At a fixed point, $a^*$ is optimal for the LP with constraint level $M^* = \max(a^* * a^*)$. This means there's no $g \geq 0$ with $(a^* * g)[k] \leq M^*$ for all $k$ and $\sum g > \sum a^* = 1$.

By strong duality, this is equivalent to the existence of dual variables $\lambda_k \geq 0$ such that $\sum_k \lambda_k (a^*)[k-j] \geq 1$ for all $j$, with complementary slackness.

So the dual variables $\lambda_k$ give a "weighting" of the lags. If we can find such a $\lambda$, the primal $a^*$ is optimal.

This is the optimality condition. In practice, we check convergence by seeing if the LP solution matches the current point.

import numpy as np
import time
from scipy.optimize import linprog


def _score(a):
    a = np.asarray(a, dtype=np.float64)
    a = np.clip(a, 0.0, 1000.0)
    s = float(a.sum())
    if s < 0.01:
        return float('inf')
    c = np.convolve(a, a)
    return float(2.0 * a.size * np.max(c) / (s * s))


def _norm(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.full(a.size, 1.0 / a.size)
    return a / s


def _lp_optimize(a0, stop_time, seed=0):
    n = a0.size
    a = _norm(a0)
    m = 2 * n - 1

    K = np.arange(m)[:, None]
    J = np.arange(n)[None, :]
    IDX = K - J
    MASK = (IDX >= 0) & (IDX < n)
    CLIP = IDX.clip(0, n - 1)

    best_a = a.copy()
    best_M = float(np.max(np.convolve(a, a)))

    rng = np.random.default_rng(seed)
    stall = 0
    perturb = 0
    one_neg = -np.ones(n)
    bnds = [(0.0, None)] * n

    for _ in range(500000):
        if time.monotonic() >= stop_time:
            break

        conv = np.convolve(a, a)
        M = float(np.max(conv))

        if M < best_M - 1e-14:
            best_M = M
            best_a = a.copy()
            stall = 0
        else:
            stall += 1

        if stall > 350:
            if perturb > 35:
                break
            sc = min(0.04 + 0.01 * perturb, 0.25)
            a = a * np.exp(rng.normal(0, sc, n))
            a = _norm(a)
            stall = 0
            perturb += 1
            continue

        A = np.where(MASK, a[CLIP], 0.0)
        try:
            res = linprog(one_neg, A_ub=A,

        except Exception:

            g = np.maximum(res.x, 0.0)

                    bt, bv = 0.0, M
