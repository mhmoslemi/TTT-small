Actually, let me think about this differently. For the subgradient, I can compute it more efficiently:

grad[i] = sum_{k in active} 2*a[k-i] / |active| (where k-i is valid)

This can be computed as: grad = (2/|active|) * sum_{k in active} (a reversed and shifted by k)

Using the fact that for each active lag k, the contribution to grad is:
- For i from max(0, k-n+1) to min(n-1, k): grad[i] += 2*a[k-i]

This is equivalent to: grad = sum_{k in active} 2 * (cross-correlation of a with delta at k)

Or equivalently: if I define h_k[i] = a[k-i] (valid indices), then grad = sum_k 2*h_k / |active|.

For a single k, h_k is just a reversed and shifted version of a. So I can compute this as:

For active lags K = {k1, k2, ..., km}:
grad[i] = (2/m) * sum_{j=1}^{m} a[kj - i] (where kj - i is in [0, n-1])

This is like a weighted sum of shifted reversed copies of a. For small m (say < 20), this is O(n*m) which is fine.

    except Exception:

    if res.status != 0 or res.x is None:
        return None

def _coord_phase(f0, n, stop_time, seed):
    """Coordinate descent with 1-point and 2-point moves."""
    rng = np.random.default_rng(seed)
    f = np.clip(np.asarray(f0, dtype=np.float64).ravel().copy(), 0, None)
    f = f / f.sum()
    best_sc = _score(f)
    no_full_pass = 0
    multipliers = (0.5, 0.7, 0.85, 1.0, 1.15, 1.3, 1.5, 2.0, 0.1)

    while time.monotonic() < stop_time - 5.0:
        improved = False
        order = rng.permutation(n)
        for i in order:
            if time.monotonic() > stop_time - 5.0:
                return f, best_sc
            orig = f[i]
            for mlt in multipliers:
                f[i] = orig * mlt if orig > 1e-14 else (0.001 if mlt > 0 else 0.0)
                sc = _score(f)
                if sc < best_sc - 1e-14:
                    best_sc = sc
                    improved = True
                    orig = f[i]
            # Fine adjustment
            if orig > 1e-8:
                for frac in (0.95, 1.05, 0.9, 1.1):
                    f[i] = orig * frac
                    sc = _score(f)
                    if sc < best_sc - 1e-14:
                        best_sc = sc
                        improved = True
                        orig = f[i]
            f[i] = orig

        # 2-coord moves
        for _ in range(30):
            if time.monotonic() > stop_time - 5.0:
                return f, best_sc
            i, j = int(rng.integers(n)), int(rng.integers(n))
            if i == j:
                continue
            oi, oj = f[i], f[j]
            for mi in (0.6, 1.4, 2.0):
                for mj in (0.6, 1.4, 0.5):
                    f[i] = max(oi * mi, 1e-14) if oi > 1e-12 else 0.001
                    f[j] = max(oj * mj, 1e-14) if oj > 1e-12 else 0.001
                    sc = _score(f)
                    if sc < best_sc - 1e-14:
                        best_sc = sc
                        improved = True
            f[i], f[j] = oi, oj

        if not improved:
            no_full_pass += 1
            if no_full_pass >= 5:
                break
        else:
            no_full_pass = 0

    return f, best_sc

        lo = max(0, k_star - n + 1)
