def _coord_descent(f, stop_time, max_sweeps=100, seed=777):
    n = len(f)
    f = np.clip(f.astype(np.float64).copy(), 0, None)
    S = float(f.sum())
    if S < 0.01:
        return f, _score(f)
    conv = _conv_full(f)
    best_score = 2.0 * n * conv.max() / (S * S)
    rng = np.random.default_rng(seed)
    
    for sweep in range(max_sweeps):
        if time.monotonic() > stop_time - 10.0:
            break
        improved_any = False
        order = rng.permutation(n)
        
        for i in order:
            if time.monotonic() > stop_time - 10.0:
                break
            v = f[i]
            S_rest = S - v
            
            # Influence vector: infl[k] = contribution to conv[k] per unit change in f[i]
            # Δ(f*f)[k] = 2*delta*f[k-i] for k != 2i ((and valid range))
            #             2*delta*v + delta^2 for k = 2i
            infl = np.zeros(2 * n - 1)
            idx = np.arange(2 * n - 1) - i  # k - i
            valid = (idx >= 0) & (idx < n)
            infl[valid] = 2.0 * f[idx[valid]]
            # At k = 2i, the linear term is 2*v, which is already: 2*f[i] = 2*v. Good.
            # But we also need the quadratic term delta^2 at k=2i.
            
            # Search for optimal x
            x_max = max(10.0 * v + 1.0, 2.0)
            x_max = min(x_max, 500.0)
            
            # Coarse grid
            n_pts = 200
            x_grid = np.linspace(0.0, x_max, n_pts)
            best_x = v
            best_obj = best_score + 1e-10  # slightly above current to ensure we accept ties
            
            # Vectorized evaluation
            # For each x in x_grid:
            #   S_new = S_rest + x
            #   delta = x - v
            #   conv_new[k] = conv[k] + delta * infl[k] + (x==v ? 0 : (delta^2 if k==2i else 0))
            #   obj = 2*n*max(conv_new) / S_new^2
            
            deltas = x_grid - v
            S_news = S_rest + x_grid
            valid_S = S_news > 0.01
            
            if not valid_S.any():
                continue
            
            best_x = v
            best_obj = best_score
            
            # For efficiency, only evaluate a subset or vectorize
            x_ev = x_grid[valid_S]
            S_ev = S_news[valid_S]
            d_ev = deltas[valid_S]
            
            # conv_new = conv + d_ev[:, None] * infl[None, :] + quadratic correction
            # This is (n_pts x (2n-1)) which for n=384 is 200 x 767 = 153K. Fine.
            if 2 * i < 2 * n - 1:
                quad_term = d_ev**2
            else:
                quad_term = np.zeros_like(d_ev)
            
            # Vectorized: conv_new[j, k] = conv[k] + d_ev[j]*infl[k] + quad_term[j]*delta_{k,2i}
            conv_new = conv[None, :] + d_ev[:, None] * infl[None, :]
            if 2 * i < 2 * n - 1:
                conv_new[:, 2*i] += quad_term
            
            m_new = conv_new.max(axis=1)
            obj = 2.0 * n * m_new / (S_ev * S_ev)
            
            min_idx = int(np.argmin(obj))
            if obj[min_idx] < best_obj - 1e-13:
                best_obj = obj[min_idx]
                best_x = x_ev[min_idx]
            
            # Fine search around best
            if best_x != v:
                dw = x_max / n_pts
                x_fine = np.linspace(max(0, best_x - 5*dw), min(x_max, best_x + 5*dw), 100)
                S_fin = S_rest + x_fine
                v_fin = S_fin > 0.01
                if v_fin.any():
                    xf = x_fine[v_fin]
                    Sf = S_fin[v_fin]
                    df = xf - v
                    conv_fin = conv[None, :] + df[:, None] * infl[None, :]
                    if 2 * i < 2 * n - 1:
                        conv_fin[:, 2*i] += df**2
                    m_fin = conv_fin.max(axis=1)
                    obj_fin = 2.0 * n * m_fin / (Sf * Sf)
                    min_idx2 = int(np.argmin(obj_fin))
                    if obj_fin[min_idx2] < best_obj - 1e-13:
                        best_obj = obj_fin[min_idx2]
                        best_x = xf[min_idx2]
            
            # Accept
            if best_x != v and best_obj < best_score - 1e-14:
                w = best_x - v
                f[i] = best_x
                S += w
                conv += w * infl
                if 2 * i < 2 * n - 1:
                    conv[2*i] += w * w
                best_score = best_obj
                improved_any = True
        
        if not improved_any:
            break
    
    f = np.clip(f, 0, 1000)
    final_score = _score(f)
    return f, final_score

Let me also add a "spectral" initialization idea: try FFT-based constructions where the spectrum has specific properties.

For a sequence f with DFT F[k], the auto-convolution f*f has DFT |F[k]|^2. So max(f*f) = max of the inverse DFT of |F|^2. To minimize max(f*f), we want |F|^2 to be as "flat" as possible (in the time domain, its inverse should be flat). But |F|^2 being flat in frequency means |F| is constant, which means f is a delta (or impulse), which gives max(f*f) = 1 and sum(f) = 1, score = 2n. That's terrible.

Actually, we want the inverse DFT of |F|^2 to have low peak. The inverse DFT of |F|^2 is f*f. So we want f*f to be flat. This means |F|^2 should be "concentrated" in a way that its inverse is flat.

For a top-hat in frequency (|F| = 1 for |k| < K, 0 otherwise), the inverse is a sinc-like function, which has peaks. Not ideal.

For a Gaussian in frequency, the inverse is also Gaussian, which has a clear peak. 

The best "flat" convolution would come from a sequence whose autocorrelation is as flat as possible. This is related to "low autocorrelation" sequences in radar/signal processing. But we have the additional constraint that f >= 0.

For nonnegative sequences with flat autocorrelation, the optimal is related to the "circular" version of a Barker sequence or Zadoff-Chu sequence, but constrained to be nonnegative.

Let me also think about whether the LP is actually the best direction-finding method. An alternative is the "dual fitting" approach:

The dual of max 1'g s.t. B(f)g <= M, g >= 0 is:
min M * 1'a s.t. B(f)'a >= 1, a >= 0

The optimal dual solution a* tells us which constraints are active. The Lagrangian for the primal is:
L(g, a) = -1'g + a'(B(f)g - M*1)

At optimality: -1 + B(f)'a* = 0, i.e., B(f)'a* = 1.

This means: sum_k a*_k * f[|k-i|] = 1 for all i with g*_i > 0.

This is a system that determines the "support" of g*. The LP automatically finds this.

Alternatively, we could solve the dual directly (767 variables, 384 constraints) which might be faster. But HiGHS handles both fine.
