   So (a*a)_k = a^T B_k a where B_k is the "anti-diagonal" matrix for k.

   For the function to be convex, we need B_k >= 0 (positive semidefinite). The matrix B_k has 1s on the anti-diagonal j+l=k and 0s elsewhere. For k < n, this is a matrix with 1s on a single anti-diagonal, which has eigenvalues ±1 (for the even/odd parts). So it's NOT positive semidefinite in general.

   Therefore, (a*a)_k is NOT convex in a, and the max of non-convex functions is not convex. So we can't use standard convex optimization.

   However, the subgradient is still well-defined:
   ∂f/∂a_i (subgradient) = {2*a_{k-i} : k in active_set} (convex hull)
   
   where active_set = {k : (a*a)_k = max}.

   We can still do subgradient descent, but convergence will be slow and we'll need careful step size scheduling.

   Let me go back to the LP-based approach, which is more structured:

   - This finds a "direction" b that, when a small amount is added to a (after rescaling), keeps the autocorrelation bounded by M.
   - The idea is that b represents a "better" distribution that fits within the current autocorrelation envelope.

   This is essentially a Dinkelbach-type or projection method for non-convex problems.

   Let me also think about a potentially powerful technique: **Pairwise swap optimization**.

   Consider swapping mass between two positions i and j. If we decrease a_i by δ and increase a_j by δ (keeping sum constant), how does the max autocorrelation change?

   (a*a)_k changes by: -δ*a_{k-i} - δ*a_{k-i} + δ*a_{k-j} + δ*a_{k-j} = 2δ*(a_{k-j} - a_{k-i})
   
   (With appropriate boundary handling.)

   So the change in (a*a)_k is 2δ*(a_{k-j} - a_{k-i}).

   We want to choose δ > 0 (move mass from i to j) and find the maximum δ that doesn't increase the max autocorrelation. This gives a coordinate-descent-like method.

   For the optimal δ in a given direction (i,j):
   We need (a*a)_k + 2δ*(a_{k-j} - a_{k-i}) <= M_new for all k.
   If we're trying to maintain (a*a)_k <= M (current max), then:
   For k where a_{k-j} > a_{k-i}: (a*a)_k + 2δ*(a_{k-j} - a_{k-i}) <= M
   → δ <= (M - (a*a)_k) / (2*(a_{k-j} - a_{k-i}))
   
   And we also need a_i - δ >= 0, so δ <= a_i.

   The optimal δ is the minimum of all these upper bounds.

   This is a nice O(n^2) per step (or O(n) if we're clever about the active set) method.

    b = _conv_full(f)
    active = np.where(b >= M * (1 - 1e-10))[0]
    if len(active) == 0:
        active = np.where(b >= M * (1 - 1e-6))[0]
    if len(active) == 0:

            if 0 <= idx < n:

    if len(ind) == 0:

        return np.ones(n) / n
    tau = (f_new[ind[-1]] - 1) / (ind[-1] + 1)

    # Rescale to match original sum
    f_new = f_new * (f.sum() / max(f_new.sum(), 1e-10))

Let me also think about the "pairwise move" more carefully:

Current state: a, with max autocorrelation M.
Move: decrease a_i by δ, increase a_j by δ (sum preserved).
Effect on (a*a)_k:
  Δ(a*a)_k = -δ * a_{k-i} - δ * a_{k-i} + δ * a_{k-j} + δ * a_{k-j}
           = 2δ * (a_{k-j} - a_{k-i})
  (with a_{k-i} = 0 if k-i not in [0, n-1])

We need: (a*a)_k + 2δ*(a_{k-j} - a_{k-i}) <= M for all k (to not increase max).
For k where a_{k-j} > a_{k-i}: δ <= (M - (a*a)_k) / (2*(a_{k-j} - a_{k-i}))
Also: δ <= a_i (non-negativity)

The optimal δ is the minimum of all these bounds. If the optimal δ > 0, we make the move.

This is O(n) per candidate pair (i,j) if we precompute a*a. So checking all O(n^2) pairs is O(n^3) per sweep, which for n=384 is about 56M operations. That's feasible.

But actually, we can be smarter: only try moves that are likely to help. For example, move mass from positions with high "local autocorrelation contribution" to positions with low contribution.

import numpy as np
import time
import math
from scipy.fft import rfft, irfft, next_fast_len
from scipy.optimize import linprog


def _get_parent():
    try:
        h = globals()["height_sequence_1"]
        p = np.asarray(h, dtype=np.float64).ravel()
    except Exception:
        p = np.ones(384, dtype=np.float64)
    if p.size == 0:
        p = np.ones(384, dtype=np.float64)
    p = np.clip(p, 0.0, 1000.0)
    p = np.where(np.isfinite(p), p, 0.0)
    if p.size == 0:
        p = np.ones(384, dtype=np.float64)
    return p


def _conv_full(a):
    n = len(a)
    fsize = next_fast_len(2 * n - 1)
    F = rfft(a, fsize)
    c = irfft(F * F, fsize)[:2 * n - 1]
    np.maximum(c, 0.0, out=c)
    return c


def _score_fast(a):
    n = len(a)
    s = float(a.sum())
    if s < 0.01:
        return math.inf
    b = _conv_full(a)
    m = float(b.max())
    if not math.isfinite(m) or m < 0:
        return math.inf
    return 2.0 * n * m / (s * s)


def _build_A(f):
    n = len(f)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        A[j:j + n, j] = f
    return A


def _lp_direction(f, M, A, time_limit=10.0):
    n = len(f)
    c_obj = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    try:
        res = linprog(
            c_obj, A_ub=A, b_ub=b_ub,
            bounds=[(0, None)] * n,
            method="highs",
            options={"presolve": True, "time_limit": time_limit},
        )
    except Exception:
        return None
    if res.status not in (0, 3) or res.x is None:
        return None
    g = np.asarray(res.x, dtype=np.float64)
    g_sum = float(g.sum())
    if g_sum < 1e-12:
        return None
    return g / g_sum


def _lp_optimize(f0, n, stop_time, seed=42):

        f = f / f_sum

    best_f = f.copy()
    best_score = _score_fast(f)
    b = _conv_full(f)
    M = float(b.max())
    A = _build_A(f)

    stall = 0
    max_stall = 80
    iter_count = 0
    t = 0.3

    while time.monotonic() < stop_time - 5.0:
        g = _lp_direction(f, M, A, time_limit=10.0)

        if g is None:
            stall += 3
            if stall > max_stall:
                f = np.clip(f + rng.normal(0, 0.04, n), 0, None)
                fs = f.sum()
                if fs > 1e-10:
                    f = f / fs
                else:
                    f = best_f.copy()
                b = _conv_full(f)
                M = float(b.max())
                A = _build_A(f)
                stall = 0
                continue
            g = _lp_direction(f, M * 1.002, A, time_limit=5.0)
            if g is None:

                fs = f.sum()
                if fs > 1e-10:

                    f = best_f.copy()
                b = _conv_full(f)

        dist = float(np.linalg.norm(g - f))

                    elif strat == 1:
                        blk = n // 4

                        f = f2

def _pairwise_polish(f, n, stop_time, seed=123):
    """Polish using pairwise mass transfer moves."""
    rng = np.random.default_rng(seed)
    best = np.asarray(f, dtype=np.float64).copy()
    fs = best.sum()
    if fs < 1e-10:
        return best, math.inf
    best = best / fs
    best_sc = _score_fast(best)
    b = _conv_full(best)
    M = float(b.max())
    no_imp = 0
    max_no_imp = 12

    while time.monotonic() < stop_time - 3.0:
        improved = False
        n_pairs = 500
        for _ in range(n_pairs):
            if time.monotonic() > stop_time - 3.0:
                break
            i = int(rng.integers(n))
            j = int(rng.integers(n))
            if i == j:
                continue
            oi, oj = best[i], best[j]
            total = oi + oj
            if total < 1e-14:
                continue
            # Try several splits
            for ratio in (0.0, 0.15, 0.3, 0.5, 0.7, 0.85, 1.0):
                best[i] = ratio * total
                best[j] = (1.0 - ratio) * total
                sc = _score_fast(best)
                if sc < best_sc - 1e-15:
                    best_sc = sc
                    improved = True
            best[i], best[j] = oi, oj

        # Single coordinate adjustment
        for _ in range(100):
            if time.monotonic() > stop_time - 3.0:
                break
            i = int(rng.integers(n))
            orig = best[i]
            s_rest = best.sum() - orig
            if s_rest < 1e-10:
                continue
            for frac in (0.3, 0.5, 0.7, 1.0, 1.4, 2.0, 0.0):
                best[i] = orig * frac if orig > 1e-10 else frac / n
                sc = _score_fast(best)
                if sc < best_sc - 1e-15:
                    best_sc = sc
                    improved = True
            best[i] = orig

        if not improved:
            no_imp += 1
            if no_imp >= max_no_imp:
                break
        else:
            no_imp = 0

    return best, best_sc


def _subgrad_refine(f, n, stop_time, seed=777):
    """Subgradient-based refinement for the max autocorrelation."""
    rng = np.random.default_rng(seed)
    best = np.asarray(f, dtype=np.float64).copy()
    fs = best.sum()
    if fs < 1e-10:
        return best, math.inf
    best = best / fs
    best_sc = _score_fast(best)
    b = _conv_full(best)
    M = float(b.max())
    
    step_size = 0.05
    no_imp = 0
    max_no_imp = 50

    while time.monotonic() < stop_time - 3.0 and no_imp < max_no_imp:
        b = _conv_full(best)
        M = float(b.max())
        # Active set: lags where autocorrelation is near max
        threshold = M * (1.0 - 1e-4)
        active = np.where(b >= threshold)[0]
        if len(active) == 0:
            active = np.array([int(np.argmax(b))])

        # Compute subgradient: sg_i = (1/|A|) * sum_{k in A} 2*a_{k-i}
        sg = np.zeros(n)
        for k in active:
            # sg_i += 2*a_{k-i} for valid i
            k_lo = max(0, k - (n - 1))
            k_hi = min(n - 1, k)
            for i in range(k_lo, k_hi + 1):
                idx = k - i
                if 0 <= idx < n:
                    sg[i] += 2.0 * best[idx]
        sg /= len(active)

        # Take a step against the subgradient, project onto simplex
        f_new = best - step_size * sg
        f_new = npmaximum(f_new, 0)
        fs_new = f_new.sum()
        if fs_new < 1e-10:
            f_new = best
        else:
            f_new = f_new / fs_new

        sc = _score_fast(f_new)
        if sc < best_sc - 1e-14:
            best = f_new
            best_sc = sc
            no_imp = 0
            step_size = min(0.2, step_size * 1.1)
        else:
            no_imp += 1
            step_size = max(0.001, step_size * 0.7)

    return best, best_sc


def npmaximum(a, b):
    return np.maximum(a, b)
