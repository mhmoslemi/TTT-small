            else:

            if no_imp_count >= max_no_imp:

But actually, I realize the LP might not always make progress. The LP finds the g that maximizes sum(g) subject to f*g <= M. But if f is already "optimal" in some sense, the LP might return g ≈ f (up to normalization), and no improvement is possible.

Let me think about when the LP stops making progress:
- If f is such that for all g with f*g <= M, we have sum(g) <= sum(f), then the LP returns g ≈ f (normalized).
- This means f is a local optimum of the LP-based method.

Instead of the LP, I can:

Actually, let me think about this problem from a different angle. The objective is:

minimize max_k sum_i f_i * f_{k-i} / (sum f)^2

subject to f_i >= 0

This is a ratio of a convex function (max of quadratics) to a constant (since we normalize sum=1). So we're minimizing a convex function! Wait, is max_k (f*f)_k convex in f?

(f*f)_k = sum_i f_i * f_{k-i} is a quadratic form. Its Hessian with respect to f is:
H_ii = 2 (from the f_i^2 term when k-i=i, i.e., k=2i)
H_ij = 1 if j = k-i (and i ≠ k-i)

The Hessian is not necessarily positive semidefinite (it has off-diagonal entries). So (f*f)_k is not convex in general.

For example, (f*f)_0 = f_0^2 (convex)
(f*f)_1 = 2*f_0*f_1 (the Hessian is [[0,1],[1,0]] which is indefinite)

So the objective is NOT convex. That's why simple gradient descent might not work well, and why the LP approach (which finds a feasible direction) is useful.

OK so the problem is non-convex. The LP approach is a heuristic that works well in practice. Let me just make it work as well as possible.

    m = int(m)

    """Gradient-based refinement using subgradient of max convolution."""
    a = _norm(a0)
    n = a.size

        for k in hot:
            for m in range(n):

                if 0 <= km < n:
                    grad[m] += 2.0 * a[km]
        
        # Normalize gradient
        gn = np.linalg.norm(grad)
        if gn < 1e-15: break
        grad /= gn
        
        # Gradient descent step
        new_a = a - lr * grad
        new_a = np.clip(new_a, 0, None)
        s = new_a.sum()
        if s < 1e-12:
            lr *= 0.5
            continue
        new_a /= s
        sc = _sc(new_a)
        
        if sc < best_sc - 1e-15:
            best = new_a.copy()
            best_sc = sc
            a = new_a

            lr = min(lr * 1.05, 0.1)

                a = a / a.sum()
