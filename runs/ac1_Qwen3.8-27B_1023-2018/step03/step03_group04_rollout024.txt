To minimize the max, we want to "spread out" the auto-conv energy. The uniform sequence concentrates all energy at the center (k=n-1), giving M = 1/n (with S=1).

A better sequence would have some structure that makes the auto-conv more uniform across lags.

One idea: use a "spreading" sequence where consecutive elements are correlated in a way that the auto-conv is flat. This is related to Barker sequences and Zadoff-Chu sequences in communications.

But for continuous (real-valued) non-negative sequences, the design space is much larger.

The LP iteration essentially finds the optimal non-negative sequence that "responds" to the current convolution pattern. It's like a "natural selection" applied to the sequence.

Actually, I want to reconsider one thing. The LP direction method:

Given f (normalized to sum 1), find g = argmax sum(g) s.t. cross_conv(f, g) <= M, g >= 0.

Then update: f_new = (1-t)f + tg, renormalize.

The key question: does this converge? And to what?

This is related to the "convex envelope" method. If we think of the feasible set C(M) = {g : cross_conv(f, g) <= M, g >= 0}, the LP finds the point in C(M) with maximum "mass." The update moves f toward this point.

If f is already in C(M) (i.e., f is feasible), then the LP finds a g that's "as big as possible" while staying feasible. This g might be very different from f, leading to a large step.

If f is not in C(M) (i.e., f has some cross_conv values > M... wait, cross_conv(f, f) = auto_conv(f), so the max of cross_conv(f, f) is M by definition. So f IS feasible (barely, with the max constraint binding).

Hmm, actually the LP constraint is cross_conv(f, g) <= M, not auto_conv(f) <= M. So f might not be feasible for the LP (cross_conv(f, f) = auto_conv(f), and the max of auto_conv(f) is M, so the constraint is binding at the peak). f is on the boundary of the feasible set.

The LP finds the point in the feasible set with the largest "mass." If f is already this point, the LP returns f (or a scalar multiple), and the iteration stagnates.

In practice, the LP returns a g that's different from f, and the iteration makes progress. The iteration converges to a fixed point where the LP solution is proportional to the current f.

At the fixed point: f is proportional to the LP solution. The LP solution maximizes sum(g) subject to cross_conv(f, g) <= M, g >= 0. If f ∝ g*, then the constraint cross_conv(f, g*) = M is binding at exactly the peak auto-conv lag(s).

This is the KKT condition for the original problem (minimize max auto-conv subject to sum = 1, a >= 0). So the fixed point is a KKT point, which for this (non-convex) problem might not be a global optimum.

import numpy as np
import time
import math
from scipy.fft import rfft, irfft, next_fast_len
from scipy.optimize import linprog


def _get_parent():
    try:
        h = globals()["height_sequence_1"]
        p = np.asarray(h, dtype=np.float64).ravel()
    except Exception:
        p = np.ones(320, dtype=np.float64)
    if p.size == 0:
        p = np.ones(320, dtype=np.float64)
    p = np.clip(p, 0.0, 1000.0)
    p = np.where(np.isfinite(p), p, 0.0)
    if p.size == 0 or p.sum() < 0.01:
        p = np.ones(320, dtype=np.float64)
    return p


def _conv(a):
    n = len(a)
    fn = next_fast_len(2 * n - 1)
    F = rfft(a, fn)
    c = irfft(F * F, fn)[:2 * n - 1]
    np.maximum(c, 0.0, out=c)
    return c


def _score(a):
    n = len(a)
    S = float(a.sum())
    if S < 0.01:
        return math.inf
    M = float(_conv(a).max())
    if not math.isfinite(M):
        return math.inf
    return 2.0 * n * M / (S * S)


def _build_A(f):
    n = len(f)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        A[j:j + n, j] = f
    return A


def _lp_dir(f, M):
    n = len(f)
    if M < 1e-15:
        return None
    A = _build_A(f)
    c_obj = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    try:
        res = linprog(c_obj, A_ub=A, b_ub=b_ub,
                      bounds=[(0, None)] * n, method='highs',
                      options={"presolve": True,
                               "dual_feasibility_tolerance": 1e-10,
                               "primal_feasibility_tolerance": 1e-10})
    except Exception:
        return None
    if res.status != 0 or res.x is None:
        return None
    g = np.asarray(res.x, dtype=np.float64)
    s = float(g.sum())
    if s < 1e-12:
        return None
    return g / s


def _lp_optimize(f0, stop_time, rng):

    S = float(f.sum())

    best_f = f.copy()
    best_sc = _score(f)

    t = 0.3
    stall = 0
    max_stall = 80

    while time.monotonic() < stop_time - 3.0:
        conv = _conv(f)
        M = float(conv.max())

        g = _lp_dir(f, M)
        if g is None:
            stall += 5
            if stall > max_stall:
                break
            f = np.clip(f + rng.normal(0, 0.1, n), 0, None)
            S = f.sum()
            f = f / S if S > 1e-12 else best_f.copy()
            continue

        dist = float(np.linalg.norm(g - f))
        if dist < 1e-10:
            stall += 4
            if stall > max_stall:
                break
            f = np.clip(best_f + rng.normal(0, 0.04, n), 0, None)
            S = f.sum()
            f = f / S if S > 1e-12 else best_f.copy()

def _polish(f, stop_time, rng):
    n = len(f)
    best = np.clip(np.asarray(f, dtype=np.float64).ravel(), 0, None).copy()
    S = float(best.sum())
    if S < 1e-12:
        return best, math.inf
    best = best / S
    best_sc = _score(best)

    no_imp = 0
    max_no_imp = 20
    mults = [0.0, 0.15, 0.3, 0.5, 0.7, 0.85, 1.15, 1.3, 1.6, 2.2, 4.0]

    while time.monotonic() < stop_time - 3.0:
        improved = False

        order = rng.permutation(n)
        for i in order:
            if time.monotonic() > stop_time - 3.0:
                break
            orig = best[i]
            bv = orig
            bvs = best_sc
            for m in mults:
                nv = orig * m if orig > 1e-15 else (0.005 if m > 0 else 0.0)
                best[i] = nv
                s = float(best.sum())
                if s < 0.01:
                    best[i] = orig
                    continue
                sc = _score(best)
                if sc < bvs - 1e-14:
                    bv = nv
                    bvs = sc
            best[i] = bv
            if bvs < best_sc - 1e-14:
                best_sc = bvs
                improved = True

        n_2c = 200
        for _ in range(n_2c):
            if time.monotonic() > stop_time - 3.0:
                break
            i = int(rng.integers(n))
            j = int(rng.integers(n))
            if i == j:
                continue
            oi, oj = best[i], best[j]
            found = False
            for mi in [0.0, 0.4, 0.7, 1.0, 1.5, 2.5]:
                for mj in [0.0, 0.4, 0.7, 1.0, 1.5, 2.5]:
                    if mi == 1.0 and mj == 1.0:
                        continue
                    ni = oi * mi if oi > 1e-15 else (0.005 if mi > 0 else 0.0)
                    nj = oj * mj if oj > 1e-15 else (0.005 if mj > 0 else 0.0)
                    best[i], best[j] = ni, nj
                    s = float(best.sum())
                    if s < 0.01:
                        best[i], best[j] = oi, oj
                        continue
                    sc = _score(best)
                    if sc < best_sc - 1e-14:
                        best_sc = sc
                        improved = True
                        found = True
                        break
                if found:
                    break
            if not found:
                best[i], best[j] = oi, oj

        if not improved:
            no_imp += 1
            if no_imp >= max_no_imp:
                break
        else:
            no_imp = 0
