For coordinate descent: for each i, try changing a_i while keeping others fixed. The optimal a_i minimizes max_k (a*a)_k where only a_i changes.

When we change a_i from v to v', the convolution changes:
(a*a)'_k = (a*a)_k + v' * (sum of changes due to a_i)

Specifically:
(a*a)_k = sum_j a_j * a_{k-j}
Changing a_i from v to v' changes:
- Terms where j=i: a_i * a_{k-i} → v' * a_{k-i}, change = (v'-v) * a_{k-i}
- Terms where k-j=i (j=k-i): a_{k-i} * a_i → a_{k-i} * v', change = a_{k-i} * (v'-v)
- If i = k-i (k=2i): the term a_i^2 → v'^2, change = v'^2 - v^2 (counted once)

So: (a'n)_k = (a*a)_k + (v'-v) * [a_{k-i} + a_{k-i}] = (a*a)_k + 2(v'-v)*a_{k-i} (if k≠2i)
Or: (a*a)_k + (v'^2 - v^2) (if k=2i)

Wait, let me be more careful. When k=2i:
The term in the sum where j=i is a_i * a_{k-i} = a_i * a_i = v^2.
New term: v' * v' = v'^2.
Change: v'^2 - v^2.

But also, the term where j=k-i=i is the SAME term (since k-i=i when k=2i).
So we don't double count. The total change for k=2i is v'^2 - v^2.

For k ≠ 2i:
- j=i: a_i * a_{k-i} → v' * a_{k-i}, change = (v'-v) * a_{k-i}
- j=k-i: a_{k-i} * a_i → a_{k-i} * v', change = (v'-v) * a_{k-i}
- Total change: 2(v'-v) * a_{k-i} (if 0<=k-i<n)

So for coordinate i, the new max is:
max_k [b_k + delta_k(v')]

where delta_k(v') = 2(v'-v)*a_{k-i} for k≠2i (and 0<=k-i<n), or v'^2-v^2 for k=2i, or 0 otherwise.

To find the optimal v', we want to minimize max_k [b_k + delta_k(v')].

This is a 1D optimization in v'. We can solve it by:
- Binary search on the threshold: find the smallest M such that there exists v' >= 0 with b_k + delta_k(v') <= M for all k.

Actually, for a given v', the constraint b_k + delta_k(v') <= M is:
- For k≠2i, 0<=k-i<n: b_k + 2(v'-v)*a_{k-i} <= M → v' <= (M - b_k)/(2*a_{k-i}) + v (if a_{k-i}>0) or v' >= (M-b_k)/(2*a_{k-i}) + v (if a_{k-i}<0, but a_{k-i}>=0)
  Since a_{k-i} >= 0: v' <= (M - b_k)/(2*a_{k-i}) + v (upper bound on v')
- For k=2i: b_k + v'^2 - v^2 <= M → v'^2 <= M - b_k + v^2 → v' <= sqrt(M - b_k + v^2) (if M - b_k + v^2 >= 0)

So for a given M, v' must satisfy:
v' <= min over all k of the upper bounds
v' >= 0

The optimal M is the smallest M such that the upper bound is >= 0.

This can be solved by binary search on M. For each M, compute the upper bound on v' and check if it's >= 0.

This gives an exact 1D coordinate descent step!

from scipy.fft import rfft, irfft, next_fast_len
from scipy.optimize import linprog
import time
import math

def propose_candidate(seed=42, budget_s=1300, **kwargs):
    t0 = time.monotonic()
    budget = max(10.0, float(budget_s))
    deadline = t0 + budget - 12.0

    # --- Get and normalize parent ---
    try:
        parent = np.asarray(height_sequence_1, dtype=np.float64).ravel()
    except Exception:
        parent = np.ones(384, dtype=np.float64)
    n = len(parent)
    if n < 1:
        parent = np.ones(384, dtype=np.float64)
        n = 384
    parent = np.nan_to_num(parent, nan=0.0, posinf=1000.0, neginf=0.0)
    parent = np.clip(parent, 0.0, 1000.0)
    ps = parent.sum()
    if ps < 1e-10:
        parent = np.ones(n, dtype=np.float64)
        ps = float(n)
    a_init = parent / ps

    # --- Setup FFT and helpers ---
    L = next_fast_len(2 * n - 1)

    def conv(x):
        X = rfft(x, L)
        c = irfft(X * X, L)[:2 * n - 1]
        np.maximum(c, 0.0, out=c)
        return c

    def score(x):
        s = x.sum()
        if s < 0.01:
            return math.inf
        return 2.0 * n * conv(x).max() / (s * s)

    def proj(x):
        x = np.maximum(x, 0.0)
        s = x.sum()
        if s < 1e-18:
            return np.ones(n) / n
        return x / s

    best_a = a_init.copy()
    best_score = score(a_init)

    # --- LP-based optimization ---
    def lp_optimize(x0, stop_time, seed_v, max_stall=100):
        nonlocal best_a, best_score
        rng = np.random.default_rng(seed_v)
        x = x0.copy()
        local_best = x.copy()
        local_sc = score(x)
        stall = 0
        it = 0
        t_step = 0.35

        while time.monotonic() < stop_time - 1.5:
            it += 1
            b = conv(x)
            M = b.max()

            # Build LP matrix: A[k,j] = x[k-j] if 0<=k-j<n
            A = np.zeros((2 * n - 1, n), dtype=np.float64)
            for j in range(n):
                A[j:j + n, j] = x

            # Solve LP: max sum(g) s.t. A @ g <= M, g >= 0
            try:
                res = linprog(
                    -np.ones(n), A_ub=A, b_ub=np.full(2 * n - 1, M),
                    bounds=[(0, None)] * n, method='highs',
                    options={'time_limit': 4.0, 'presolve': True}
                )
            except Exception:
                res = None

            if res is None or res.status not in (0, 3) or res.x is None:
                stall += 4
                if stall >= max_stall:
                    break
                x = proj(x + rng.normal(0, 0.02 + 0.03 * stall / 30.0, n))
                local_sc = score(x)
                local_best = x.copy()
                continue

            g = res.x.astype(np.float64)
            gs = g.sum()
            if gs < 1e-12:
                stall += 4
                if stall >= max_stall:
                    break
                x = proj(x + rng.normal(0, 0.04, n))
                continue
            g /= gs

            dist = np.linalg.norm(g - x)
            if dist < 1e-9:
                stall += 3
                if stall >= max_stall:
                    break
                x = proj(x + rng.normal(0, 0.05, n))
                continue

            # Line search
            found = False
            for t in (t_step, 0.2, 0.1, 0.05, 0.02):
                x_new = proj((1.0 - t) * x + t * g)
                sc = score(x_new)
                if sc < local_sc - 1e-15:
                    x = x_new
                    local_best = x.copy()
                    local_sc = sc

                    stall = 0
                    found = True
                    if sc < best_score:

                        best_score = sc
                    break
            if not found:

                stall += 1
                if stall >= 40:

                    x = proj(x + rng.normal(0, 0.08, n))
                    local_sc = score(x)
                    local_best = x.copy()
                    t_step = 0.3
                    stall = 0
                elif stall >= 20:
                    x = proj(x + rng.normal(0, 0.03, n))

        return local_best, local_sc

    # --- Gradient-based smoothing optimization ---
    def grad_optimize(x0, stop_time, seed_v):
        nonlocal best_a, best_score
        rng = np.random.default_rng(seed_v)
        x = x0.copy()
        local_best = x.copy()
        local_sc = score(x)
        velocity = np.zeros(n)
        momentum = 0.85

        # Anneal tau from smooth to sharp
        n_steps = 300
        tau_vals = [0.05 * (0.001) ** (i / max(1, n_steps - 1)) for i in range(n_steps)]

        for step in range(n_steps):
            if time.monotonic() > stop_time - 1.5:
                break
            tau = tau_vals[step]

            b = conv(x)
            m = b.max()

            # Compute weights for smooth max
            if tau > 1e-12:
                scaled = (b - m) / tau
                # Clip for numerical stability
                scaled = np.clip(scaled, -50, 50)
                exp_b = np.exp(scaled)
                w = exp_b / exp_b.sum()
            else:
                w = np.zeros(len(b))
                w[b.argmax()] = 1.0

            # Gradient of smooth max: grad[i] = 2 * sum_k w[k] * a[k-i] (if 0<=k-i<n)
            # = 2 * sum_j a[j] * w[i+j]
            grad = np.zeros(n)
            for i in range(n):
                grad[i] = 2.0 * np.dot(x, w[i:i + n])

            # Gradient of score = 2n * smooth_max / S^2 (with S=1, just 2n * smooth_max)
            gnorm = np.linalg.norm(grad)
            if gnorm < 1e-15:
                break

            # Adam-like step
            scale = tau * 0.5 / gnorm
            velocity = momentum * velocity - scale * grad
            x_new = proj(x + velocity)

            sc = score(x_new)
            if sc < local_sc:
                x = x_new
                local_best = x.copy()
                local_sc = sc
                if sc < best_score:
                    best_a = x.copy()
                    best_score = sc
            else:
                # Halve the step
                x_try = proj(x - 0.5 * velocity)
                sc_try = score(x_try)
                if sc_try < local_sc:
                    x = x_try
                    local_best = x.copy()
                    local_sc = sc_try
                    if sc_try < best_score:
                        best_a = x.copy()
                        best_score = sc_try
                    velocity *= 0.5

        return local_best, local_sc

                #   delta_k = 2*v*a[k-i] if k!=2i, or v^2 if k==2i (for k in [0,2n-2])
                # Actually let's just try a few values directly

                best_v = orig
                best_v_sc = local_sc
                # Try multipliers and absolute values
                candidates = set()
                if orig > 1e-10:
                    for m in (0.3, 0.5, 0.7, 0.85, 1.0, 1.15, 1.3, 1.5, 2.0, 3.0):

                for v in candidates:

                    sc = score(x)

                        best_v_sc = sc

                x[i] = best_v
                if best_v_sc < local_sc - 1e-15:
                    local_sc = best_v_sc
                    improved = True
                    x = proj(x)
                    if local_sc < best_score:
                        best_a = x.copy()
                        best_score = local_sc
                    local_best = x.copy()

            if not improved:
                no_imp_rounds += 1
            else:
                no_imp_rounds = 0

        return local_best, local_sc

    # ==================== MAIN SEARCH ====================

    # Phase 1: LP optimization from parent (50% of time)
    p1_end = t0 + budget * 0.50
