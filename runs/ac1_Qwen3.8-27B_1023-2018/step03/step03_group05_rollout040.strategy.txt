<Approach_and_Rationale>
We propose a sparse optimization approach based on iterative reweighted least squares ($\ell_1$-minimization) to minimize the AC1 upper bound. Unlike the parent program's iteratively constrained approach, we directly optimize for both sparsity and low convolution maximum. The central idea is:
1. Model the bound minimization as an $\ell_1$-denoising problem penalizing large coefficients
2. Use a two-stage optimization:
   - First find a highly sparse candidate that minimizes the bound under sparsity constraints
   - Then refine the solution in a nonlinear programming framework
3. Ensure nonnegative coefficients throughout the process

We leverage the connection between sparse representations and bound minimization, as the AC1 bound is sensitive to spread-out coefficients magnitudes. This approach differs fundamentally from the parent's dense method by focusing first on extreme sparsity before refinement.

<Mathematical_Specification>
1. Representation: A real sequence $x=(x_0,...,x_{n-1})$ ($n=512$) with $\sum x_i = \sqrt{2n}$
2. Variables: $x_i \ge 0$ for all $i$
3. Objective: Minimize $\|x\|_{\ell_{1,\infty}}^{(dense)}$ where $\|x\|_{\ell_{1,\infty}}$ combines $\ell_1$-norm with max norm
4. Algorithm:
   - Stage 1: Iteratively Reweighted $\ell_1$-minimization
   - Stage 2: Nonlinear Programming refinement with gradient tracking
   - Both stages maintain nonnegativity constraints
   - Objective replacement: For evaluation we minimize $F(x) = \frac{2n \cdot \max(x*x)}{\left(\sum x_i\right)^2}$ split into two invariant parts
5. Formulation of $\ell_1$-minimization:
   \[\begin{aligned}\min_{x} & \|w_x\|_1 \\ subject~to & \sum_i x_i = \sqrt{2n},~\sum_i x_i^2 \le M^2, \\ & \sum_i |x_i - \hat{x}_i| \le \tau |S_i|\end{aligned}\]
6. Variables: $x \in \mathbb{R}^n$, $w_x \in \mathbb{R}^n$ (weighted $\ell_1$ vector)
7. Convolution: Used as $F(x) = \left( \sum x_i \right)^{-2} \cdot \max_{k} (x\ast x)_k$
8. Optimization: Employed ADMM for sparse updates and gradient descent with line-search for refinement

def _normalize_sum(seq, target_sum):
    if len(seq) == 0:
        return np.ones(1) / np.sqrt(2)
    arr = np.asarray(seq, dtype=np.float64)
    s = np.sum(arr)
    if s < 1e-12:
        return np.ones_like(arr) / np.sqrt(2)
    return arr * target_sum / s

def compute_convolution(seq):
    seq_arr = np.asarray(seq, dtype=np.float64) if type(seq) != np.ndarray else seq
    if len(seq_arr) == 0:
        return np.array([0.0])
    n = len(seq_arr)
    n_fft = next_fast_len(2 * n - 1)
    f = rfft(seq_arr, n_fft)
    conv = irfft(f * f, n_fft)
    return conv[:2*n - 1]
