Let me focus on making the LP optimization faster and more effective:

**Key improvement: Use the dual LP**

The primal LP is:
maximize sum(g)
subject to A @ g <= M * 1_{2n-1}
         g >= 0

where A is the (2n-1) x n convolution matrix.

The dual is:
minimize M * sum(y)
subject to A^T @ y >= 1_n
         y >= 0

If the dual is easier to solve, we can use it. But since HiGHS is fast, let's stick with the primal.

**Key improvement: Better line search**

Instead of trying 14 fixed steps, use a proper 1D optimization:
- First, find the best direction (LP)
- Then, optimize t in [0, 1] using golden section or a few evaluations

Actually, since the objective is 2n*max(conv(a,a))/(sum(a))^2 and this is a piecewise smooth function (smooth within each region where the argmax of the convolution is fixed), a simple approach might work:

1. Compute the current peak position k*
2. The objective in the neighborhood of a is: 2n * b[k*](t) / (s(t))^2 where b[k*](t) = ((1-t)*a + t*g)^T R_{k*} ((1-t)*a + t*g) and s(t) = (1-t)*sum(a) + t*sum(g)
3. Since we've normalized sum(g) = sum(a), s(t) = sum(a) is constant, and the objective is proportional to b[k*](t) which is a quadratic in t.
4. So the optimal t can be found analytically!

Wait, that's a great insight. If sum(g) = sum(a) = S, then for a_new = (1-t)*a + t*g:
- sum(a_new) = (1-t)*S + t*S = S (constant)
- b_new[k] = sum_i a_new[i]*a_new[k-i] = sum_i ((1-t)*a[i]+t*g[i]) * ((1-t)*a[k-i]+t*g[k-i])
  = (1-t)^2 * b[a][k] + t(1-t) * (b[a][k]... 

Wait, let me define cross terms:
conv(a,g)[k] = sum_i a[i]*g[k-i]
conv(g,a)[k] = conv(a,g)[k] (same since it's sum of products)

Actually conv(a,g) and conv(g,a) are the same (commutative).

So b_new[k] = (1-t)^2 * b_a[k] + 2t(1-t) * b_ag[k] + t^2 * b_g[k]

where b_a = conv(a,a), b_g = conv(g,g), b_ag = conv(a,g).

The objective is 2n * max_k b_new[k] / S^2.

If we assume the peak stays at k* (the current peak), then:
f(t) = 2n * b_new[k*](t) / S^2 = 2n * ((1-t)^2 * b_a[k*] + 2t(1-t) * b_ag[k*] + t^2 * b_g[k*]) / S^2

This is a quadratic in t: f(t) = At^2 + Bt + C where:
A = 2n * (b_g[k*] - 2*b_ag[k*] + b_a[k*]) / S^2
B = 2n * 2*(b_ag[k*] - b_a[k*]) / S^2
C = 2n * b_a[k*] / S^2

The minimum of this quadratic (if A > 0) is at t* = -B/(2A) = (b_a[k*] - b_ag[k*]) / (b_g[k*] - 2*b_ag[k*] + b_a[k*]).

But we need to check that the peak doesn't move to a different k. We can verify by computing the full conv(a_new, a_new) at t*.

This is a great speedup! Instead of 14 function evaluations for the line search, we just need:
1. Compute b_ag = conv(a, g) (one FFT)
2. Compute b_g = conv(g, g) (one FFT) - actually we might not need this if we just check the peak
3. Compute t* analytically
4. Verify by computing the full conv at t* (one FFT)
5. Adjust t if the peak moved

Actually, we also need to check that the new peak isn't somewhere else. But a good heuristic is:
- Compute t* from the current peak
- Clamp to [0, 1]
- Evaluate at t* and at a few nearby points
- Take the best

This reduces the line search from ~14 convolutions to ~2-3.

**Key improvement: subgradient polish**

After the LP phase, do a subgradient/gradient descent:
- Identify the active peaks (k where b[k] is within epsilon of max)
- Compute the gradient of max(b) w.r.t. a
- Take a step in the negative gradient direction
- Clip to non-negative
- This can fine-tune the solution

import time
import math
from scipy.fft import rfft, irfft, next_fast_len

    if n <= 512:
        return np.convolve(a, a, mode="full")

    F = rfft(a, fsize)
    c = irfft(F * F, fsize)[:2 * n - 1]
    np.maximum(c, 0.0, out=c)
    return c

def _conv_cross(a, b):
    n1, n2 = len(a), len(b)
    n = max(n1, n2)
    fsize = next_fast_len(n1 + n2 - 1)
    F = rfft(a, fsize)
    G = rfft(b, fsize)
    c = irfft(F * G, fsize)[:n1 + n2 - 1]
    return c

    s = float(a.sum())

    m = float(b.max())

        return math.inf
    return 2.0 * n * m / (s * s)

    f = np.clip(np.asarray(f0, dtype=np.float64).ravel(), 0, None).copy()

    f = f[:n]

    best_f = f.copy()
    best_score = _score(f)
    stall = 0
    max_stall = 100

    while time.monotonic() < stop_time - 3.0:
        b = _conv_full(f)
        M = float(b.max())
        if M < 1e-18:
            break

        g = _lp_direction(f, n, M, timeout=2.0)

def _subgradient_polish(a, stop_time, seed=0):
    """Polish using subgradient of max autocorrelation."""
    n = len(a)
    a = np.clip(np.asarray(a, dtype=np.float64).copy(), 0, None)
    # Normalize sum to 1
    s = a.sum()
    if s < 1e-10:
        return a, _score(a)
    a = a / s
    best_a = a.copy()
    best_sc = _score(a)
    rng = np.random.default_rng(seed)
    
    lr = 0.1
    no_imp = 0
    max_no_imp = 30
    
    while time.monotonic() < stop_time - 3.0:
        b = _conv_full(a)
        M = float(b.max())
        
        # Find active peaks (within 1% of max)
        active = np.where(b >= M * 0.99)[0]
        
        # Subgradient of max(b) w.r.t. a
        # ∂b[k]/∂a[j] = 2*a[k-j] (approximately, for valid k-j)
        sg = np.zeros(n)
        for k in active:
            for j in range(n):
                idx = k - j
                if 0 <= idx < n:
                    sg[j] += 2.0 * a[idx]
        
        # Normalize subgradient
        sg_norm = np.linalg.norm(sg)
        if sg_norm < 1e-15:
            break
        
        # Projected gradient step
        a_new = a - lr * sg / sg_norm
        a_new = np.clip(a_new, 0, None)
        s_new = a_new.sum()
        if s_new < 1e-10:
            lr *= 0.5
            continue
        a_new = a_new / s_new  # renormalize
        
        sc = _score(a_new)
        if sc < best_sc - 1e-14:
            a = a_new
            best_a = a.copy()
            best_sc = sc
            no_imp = 0
            lr = min(0.5, lr * 1.1)
        else:
            lr *= 0.7
            no_imp += 1
            if no_imp >= max_no_imp:
                break

def _coord_descent_polish(a, stop_time, seed=42):

            best_val = orig

import time
import math

from scipy.optimize import linprog


def _get_parent():
    try:
        h = globals()["height_sequence_1"]
        p = np.asarray(h, dtype=np.float64).ravel()

        p = np.ones(198, dtype=np.float64)
    return p


def _conv_full(a):
    n = len(a)
    if n <= 512:
        return np.convolve(a, a, mode="full")
    fsize = next_fast_len(2 * n - 1)
    F = rfft(a, fsize)
    c = irfft(F * F, fsize)[:2 * n - 1]
    np.maximum(c, 0.0, out=c)
    return c


def _conv_cross(a, b):
    n1, n2 = len(a), len(b)
    fsize = next_fast_len(n1 + n2 - 1)
    F = rfft(a, fsize)
    G = rfft(b, fsize)
    c = irfft(F * G, fsize)[:n1 + n2 - 1]
    return c


def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 0.01:
        return math.inf
    b = _conv_full(a)
    m = float(b.max())
    if not math.isfinite(m) or m < 0:
        return math.inf
    return 2.0 * n * m / (s * s)


def _build_A(f, n):
    A = np.zeros((2 * n - 1, n), dtype=np.float64)
    for j in range(n):
        A[j:j+n, j] = f
    return A


def _lp_direction(f, n, M, timeout=2.0):
    A = _build_A(f, n)
    c_vec = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c_vec, A_ub=A, b_ub=b_ub, bounds=bounds, method="highs",
                      options={"presolve": True, "time_limit": timeout})
    except Exception:
        return None
    if res.status != 0 or res.x is None:
        return None
    g = np.asarray(res.x, dtype=np.float64)
    g = np.clip(g, 0.0, 1000.0)
    if g.sum() < 1e-15:
        return None
    return g
