def _conv_fft(a):
    n = len(a)
    fsize = next_fast_len(2 * n - 1)
    F = rfft(a, fsize)
    c = irfft(F * F, fsize)[:2 * n - 1]
    return c

def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 0.01:
        return math.inf
    b = _conv_fft(a)
    m = float(b.max())
    if not math.isfinite(m):
        return math.inf
    return float(2.0 * n * m / (s * s))

def _build_A_sparse(f, n):

    for k in range(2*n-1):
        lo = max(0, k-n+1)
        hi = min(n, k+1)
        for j in range(lo, hi):
            if 0 <= k-j < n:
                A[k, j] = f[k-j]
    return A

    F = rfft(a, fsize)
    c = irfft(F * F, fsize)[: 2 * n - 1]

        return math.inf
    b = _conv_fft(a)
    m = float(b.max())
    if not math.isfinite(m):
        return math.inf
    return float(2.0 * n * m / (s * s))

    n = len(p)
    b = _conv_fft(p)
    return float(2.0 * n * b.max())

    for k in range(2 * n - 1):
        lo = max(0, k - n + 1)
        hi = min(n, k + 1)
        for j in range(lo, hi):
            A[k, j] = f[k - j]
    return A

def _lp_direction(f, n, M, time_limit=15.0):
    """Solve LP: max sum(g) s.t. conv(f,g) <= M, g >= 0. Return normalized g or None."""
    A = _build_A(f, n)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    try:
        res = linprog(
            c, A_ub=A, b_ub=b_ub,
            bounds=[(0.0, None)] * n,

            options={"presolve": True, "time_limit": time_limit},

    except Exception:
        return None
    if res.status != 0 or res.x is None:
        return None
    g = np.asarray(res.x, dtype=np.float64).copy()
    g = np.maximum(g, 0)
    gs = float(g.sum())
    if gs < 1e-14:
        return None
    return g / gs

Now for the main optimization loop. Let me think about the structure:

1. Normalize p to sum 1
2. Compute b, M
3. Solve LP to get direction g
4. Line search on (1-t)*p + t*g
5. Update p
6. Repeat

For the line search, I'll use a backtracking approach:
- Start with t = 0.5
- Evaluate score at t
- If better, try larger t (up to 1.0)
- If worse, try smaller t
- Golden section or bisection to find optimum

Actually, the score along the line should be unimodal (or nearly so) since we're moving towards the LP optimum. Let me use a simple 18-iteration bisection.

Let me also think about the subgradient step more carefully.

For p with sum=1, the objective is F(p) = 2n * max_k b_p[k].
The subgradient of max_k b_p[k] at p is:
g_sub[j] = sum_{k in K*} λ_k * 2 * p[k-j] * I(0 <= k-j < n)
where K* = {k : b_p[k] = max}, and λ is any probability distribution on K*.

For a "smoothed" version, use:
λ_k = exp(b_p[k] / τ) / sum_k' exp(b_p[k'] / τ) for small τ

Then the gradient step:
p_new = p - η * g_sub
project: p_new = max(0, p_new), renormalize to sum 1.

For n=384, computing g_sub:
g_sub[j] = 2 * sum_{k} λ_k * p[k-j] * I(0<=k-j<n)

This is like a "weighted correlation" of p with itself, where the weights are λ_k.

We can compute this efficiently:
g_sub = 2 * (weighted sum of reversed shifts of p)

For each k with λ_k > threshold:
  g_sub[j] += 2 * λ_k * p[k-j] for valid j

This is O(K*n) where K is the number of significant lags. For n=384, even K=384 gives 147K ops. Fast.

Alternatively, using FFT:
rev_p[j] = p[n-1-j]
For lag k, the contribution is λ_k * (rev_p shifted by (n-1-k), windowed to [0,n-1])

This can be done as: g_sub = 2 * IFFT(FFT(λ_in_freq) * FFT(rev_p))... but this is getting complicated. For n=384, direct computation is fine.
