**Alternative: Direct non-convex optimization**

The problem is: minimize $f(x) = \max_k (x*x)_k$ subject to $\sum x = 1$, $x \geq 0$.

This is a non-convex minimax problem. I could use:

- Custom projected gradient with Barzilai-Borwein step sizes
- Trust-region methods

The L-BFGS-B approach would be:
- Work in the space $x \geq 0$ (L-BFGS-B handles box constraints)
- The constraint $\sum x = 1$ can be handled by working with $n-1$ free variables and setting $x_{n-1} = 1 - \sum_{j<n-1} x_j$, or by re-normalizing.

Actually, re-normalizing breaks the step size selection in L-BFGS-B. A better approach: parameterize $x = \exp(y) / \sum \exp(y)$ (softmax parameterization). Then the problem becomes unconstrained in $y$, and we can use L-BFGS-B or BFGS.

But the softmax parameterization might be ill-conditioned for large $|y|$. Let me instead use: work with $x$ directly, use the smoothed objective, and after each gradient step, project onto the simplex $\{x \geq 0, \sum x = 1\}$.

The projection onto the simplex is: given $z$, find $x = \Pi_{\Delta}(z)$ where $\Delta = \{x \geq 0, \sum x = 1\}$. This is done by:
1. Sort $z$ in decreasing order.
2. Find $\tau$ such that $\sum_i \max(z_i - \tau, 0) = 1$.
3. $x_i = \max(z_i - \tau, 0)$.

This is O(n log n).

def simplex_project(z):
    """Project z onto the simplex {x >= 0, sum(x) = 1}."""
    n = z.size
    u = np.sort(z)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(z - theta, 0)

Wait, I need to be careful with the FFT correlation formula. Let me think...

The cross-correlation of $a$ and $b$ at lag $\tau$ is $\sum_n a(n+\tau) \overline{b(n)}$.

In terms of FFT: $\text{corr} = \text{IFFT}(\text{FFT}(a) \cdot \overline{\text{FFT}(b)})$.

We want: $grad_j = \sum_i x_i \cdot w_{i+j}$.

Let me define $a = w$ and $b = x$. Then the cross-correlation at lag $j$ is:
$\sum_i w_{i+j} \cdot x_i$ (with appropriate zero-padding).

This is exactly $grad_j$!

So: $grad = \text{IFFT}(\text{FFT}(w) \cdot \overline{\text{FFT}(x)})[:n]$ (with proper padding).

Actually, I need to be more careful. The standard relation is:
$\text{IFFT}(\text{FFT}(a) \cdot \text{conj}(\text{FFT}(b)))[k] = \sum_n a[n+k] \cdot \overline{b[n]}$

where the sum is over the periodic extension (in circular correlation). With sufficient zero-padding, this gives the linear cross-correlation.

So if I pad $w$ (length $2n-1$) and $x$ (length $n$) to length $N \geq (2n-1) + n - 1 = 3n - 2$:
$\text{IFFT}(\text{FFT}(w, N) \cdot \text{conj}(\text{FFT}(x, N)))[j] = \sum_i w[i+j] \cdot x[i]$

for $j = 0, 1, ..., n-1$ (the valid range for our problem).

Great, so I can compute the gradient in O(n log n) using FFT.

        idx = np.arange(1, n + 1)
        rho = np.nonzero(u * idx > (cssv - 1))[0]

            return np.full(n, 1.0 / n)
        r = rho[-1]
        theta = (cssv[r] - 1) / (r + 1.0)
        return np.maximum(z - theta, 0)

        Wf = fft(w, N)

            return None
