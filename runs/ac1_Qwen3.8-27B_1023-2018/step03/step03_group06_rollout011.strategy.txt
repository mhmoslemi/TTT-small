## Approach and Rationale

The central idea is to optimize the sequence by iteratively targeting the maximum value of the autocorrelation function (ACF) while maintaining a controlled total sum. Unlike previous approaches, this alternative method uses a combination of gradient-based optimization and dual-problem formulations. The algorithm works by:

2. Using gradient descent focused on reducing the maximum ACF value

4. Incorporating active constraint identification from linear programming to ensure feasible updates

This differs substantially from the parent program by decoupling the optimization into a more direct gradient-based approach for ACF maximization/minimization. The method is computationally efficient due to leveraging fast Fourier transform (FFT) for convolution calculations, and includes several protection mechanisms to ensure constraint compliance while improving numerical stability.

## Mathematical Specification

### Variables and Representation
- Sequence: Represented as real-valued vector $a = [a_0, a_1, ..., a_{n-1}$
- Convolution operation: Linear convolution mode (full) producing $2n-1$ points
- AC1 objective: $AC1(a)^2 = \frac{2n \cdot max_1 \text{conv}(a)}{(sum(a))^2$

### Objective Function
Minimize $AC1(a)$ = $\frac{2n \cdot \text{max}\_\text{conv}}{(sum(a))^2}$

Subject to:
- Non-negativity: $a_i \geq 0 \forall i$
- Upper bound: $a_i \leq 1000 \forall i$
- Lower bound on sum: $\sum_{i=0}^{n-1} a_i \geq 0.01$

### Convolution Calculation
The convolution is computed using the fast Fourier transform (FFT):

$\text{conv}(a)[k] = \sum_{j=0}^{k} a_j a_{k-j} \quad \text{for}\quad k = 0, 1, \ldots, 2n-2$

But practically computed via FFT:

$\text{FFT of conv}(a) = (\text{FFT}(a)) * (\text{FFT}(a))$

### Gradient Definition
The gradient of $AC1$ w.r.t $a_i$ is approximated using central differences, formally:

$\nabla_{a_i} AC1 \approx \frac{AC1(a + \epsilon \cdot e_i) - AC1(a - \epsilon \cdot e_i)}{2\epsilon}$

Where $e_i$ is a vector with 1 at position $i$ and 0 elsewhere.

### Dual-Problem Formulation
To handle the maximization component, we introduce an auxiliary variable $M$ and form the constrained optimization:

$\underset{a, M}{\min} AC1(a) \quad \text{s.t.} \quad M \geq \text{conv}(a)[k] \quad \forall k$

This is then linked to a linear program for auxiliary parameter estimation.
