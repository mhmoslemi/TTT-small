def _lp_direction(f, n, M, timeout=5.0):
    # Build constraint matrix: (f*g)_k <= M for k=0..2n-2
    # (f*g)_k = sum_{j=max(0,k-n+1)}^{min(k,n-1)} f_{k-j} * g_j
    # A[k, j] = f_{k-j} if 0 <= k-j < n, else 0
    A = np.zeros((2*n-1, n), dtype=np.float64)
    for j in range(n):
        A[j:j+n, j] = f
    c = -np.ones(n)  # minimize -sum(g) = maximize sum(g)
    b_ub = np.full(2*n-1, M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method="highs",
                      options={"time_limit": timeout})
    except Exception:
        return None
    if res.status != 0 or res.x is None:
        return None
    g = np.clip(res.x, 0.0, None)
    if g.sum() < 1e-15:
        return None
    return g

Hmm, the coordinate descent needs more care. Let me think about it differently.

For coordinate i, we want to find the best a_i value (given all other a_j fixed) that minimizes the score. Since the score is 2n * max_b / sum_a^2, and changing a_i affects:
- sum_a by delta
- b_k for k in [i, i+n-1] by 2*delta*a_{k-i} (or delta*a_{k-i} + delta^2 if k=2i)

The score as a function of a_i (with other a_j fixed) is:
S(x) = 2n * max(b_affected(x)) / (S_old + x - a_i)^2
where S_old = sum_a - a_i, and b_affected includes the changed entries.

This is a 1D function. We can evaluate it at several points and pick the best.

Let me implement this more carefully:
