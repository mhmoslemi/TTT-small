The objective is to minimize `F(a) = max_k (a*a)[k]` subject to `sum(a) = 1, a >= 0`.

At a current point `a_0`, the Frank-Wolfe (conditional gradient) method would:
1. Compute the gradient (or subgradient) of `F` at `a_0`.
2. Solve the linear minimization: `min_{g >= 0, sum(g)=1} <∇F(a_0), g>`.
3. Take a step toward `g`.

The subgradient at `a_0` (when max is at unique k*) is:
`[∇F(a_0)]_j = 2 * a_0[k* - j]` (for valid k*-j).

The linear minimization becomes:
`min_j sum_j g_j * 2 * a_0[k* - j]` s.t. `g >= 0, sum(g) = 1`.

This is simply: put all mass on the `j` that minimizes `2 * a_0[k* - j]`, i.e., put all mass on the position where `a_0[k* - j]` is smallest. So `g = e_j` where `j = argmin (k* - j) mapped to valid indices`... this gives a vertex of the simplex, which is just a basis vector. This is not very helpful for a smooth optimization.

The issue is that the Frank-Wolfe method with a non-convex objective can behave poorly. The LP approach in the previous program is a different (and arguably better) heuristic.

    # Build the (n x n) matrix M where M[j, i] = p[i+j] (0 if i+j >= 2n-1)
    # Then grad = 2 * (M @ a)

    # For j=0: M[0, :] = p[0:n]
    # For j=1: M[1, :] = p[1:n+1]
    # ...
    # For j=n-1: M[n-1, :] = p[n-1:2n-1] (last element might be 0 if 2n-2 > 2n-2, which it isn't)
    # Actually p has length 2n-1, so p[n-1 + n - 1] = p[2n-2] which is the last element.
    # So M[j, i] = p[i+j] for i+j <= 2n-2, which is always true since i <= n-1 and j <= n-1, so i+j <= 2n-2.
    # So M[j, i] = p[i+j] for all i, j in [0, n-1].
    
    # This is a "Hankel-like" matrix built from p.
    # We can build it as: M = the matrix where each row j is p[j:j+n].
    
    # For efficiency, let's use a Toeplitz matrix or direct construction.
    idx = np.arange(2 * n - 1)
    i_idx, j_idx = np.meshgrid(np.arange(n), np.arange(n), indexing='ij')
    p_idx = i_idx + j_idx  # p_idx[i, j] = i + j
    M = p[p_idx]  # M[i, j] = p[i+j]
    
    # Now grad[j] = 2 * sum_i M[j, i] * a[i] = 2 * (M.T @ a)[j]
    # Wait: M[j, i] = p[i+j], so (M @ a)[j] = sum_i M[j, i] * a[i] = sum_i p[i+j] * a[i]
    # That's exactly what we want!
    grad = 2.0 * (M @ a)
    return grad

    best_seq = parent.copy()
    best_score = _score_fast(best_seq)
    if not math.isfinite(best_score):
        best_seq = np.ones(n) / n
        best_score = 2.0
    
    # Phase 1: Main LP optimization (55%)
    p1_end = t0 + budget * 0.55
    try:
        res, sc = _lp_optimize(parent, n, p1_end - 10, seed)
        if sc < best_score:
            best_seq = res
            best_score = sc
    except Exception:
        pass
    
    if time.monotonic() > deadline - 30:
        return _finalize(best_seq)
    
    # Phase 2: Second LP with perturbation (20%)
    p2_end = t0 + budget * 0.75
    rng = np.random.default_rng(seed + 4242)
    perturbed = np.clip(best_seq * (1.0 + 0.04 * rng.standard_normal(n)), 0, None)
    perturbed = _normalize(perturbed)
    try:
        res2, sc2 = _lp_optimize(perturbed, n, p2_end - 5, seed + 7654)
        if sc2 < best_score:
            best_seq = res2
            best_score = sc2
    except Exception:
        pass
    
    if time.monotonic() > deadline - 20:
        return _finalize(best_seq)
    
    # Phase 3: Coordinate polish (15%)
    p3_end = t0 + budget * 0.90
    try:
        best_seq, best_score = _coord_polish(best_seq, n, p3_end - 3, seed + 1111)
    except Exception:
        pass
    
    if time.monotonic() > deadline - 12:
        return _finalize(best_seq)
    
    # Phase 4: Final polish
    try:
        best_seq, best_score = _coord_polish(best_seq, n, deadline - 5, seed + 9999)
    except Exception:
        pass
    
    return _finalize(best_seq)
