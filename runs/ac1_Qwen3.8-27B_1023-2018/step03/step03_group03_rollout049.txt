(a) Parameterize a as a simplex (sum=1) and work on the simplex.
(b) Use the scale invariance to normalize after each step.

Let me go with (b): at each gradient step, normalize a to have sum = n (or 1).

Actually, for L-BFGS to work well, I should have a proper objective function. Let me define:
- Objective: `minimize 2*n*max_k (a*a)[k]` subject to `sum(a) = n`, `a >= 0`.

Using the log-sum-exp smooth:
- `F(a) = 2*n * (1/beta) * log(sum_k exp(beta * (a*a)[k]))`
- Constraint: sum(a) = n (handled by normalization)
- Constraint: a >= 0 (handled by using a parameterization like a_i = exp(x_i) / sum_j exp(x_j) * n)

With the exponential parameterization, the map is smooth and automatically satisfies both constraints. The gradient would need chain rule.

This might be overkill. Let me think about a simpler approach.

**Simpler approach: Iterative LP + coordinate descent + random restarts**

1. Start with an asymmetric initialization.
2. Run the LP iteration for a while.
3. Do coordinate descent polish.
4. Add random perturbations and repeat.
5. Try different lengths.

The key improvement over the parent: better handling of the asymmetric structure and more aggressive polishing.

Let me also think about what the optimal asymmetric sequence looks like. If the sequence is "left-heavy" (more mass on the left), then the convolution peak might shift to the left, and the "center" (which would be the energy for a symmetric sequence) would be lower.

For example, if a is concentrated near index 0, then b[0] = a_0^2 is large, but b[n-1] = sum a_i * a_{n-1-i} would be small (since a_{n-1-i} is small for most i).

But b[0] = a_0^2 could be very large if a_0 is large. The trade-off is: concentrate mass to reduce the "center" peak, but this increases the "edge" peaks.

The optimal balance is where all peaks are equal (by the LP duality argument).

- Convolution: O(n^2) = O(149184) for direct, or O(n log n) for FFT.

import time
import math
from scipy.fft import rfft, irfft, next_fast_len
from scipy.optimize import linprog, minimize

    try:
        h = globals()["height_sequence_1"]
        p = np.asarray(h, dtype=np.float64).ravel()

    if p.size == 0:
        p = np.ones(384, dtype=np.float64)
    return p

    n = a.size
    if n <= 512:
        return np.convolve(a, a, mode="full")
    fsize = next_fast_len(2 * n - 1)
    F = rfft(a, fsize)
    c = irfft(F * F, fsize)[:2 * n - 1]
    np.maximum(c, 0.0, out=c)
    return c

def _score(a):
    n = a.size
    s = a.sum()
    if s < 0.01:
        return math.inf
    b = _conv_full(a)
    m = b.max()
    return 2.0 * n * m / (s * s)

def _build_conv_matrix(f, n):
    """Build the matrix A such that A @ g = f * g"""
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        A[j:j+n, j] = f
    return A

def _lp_direction(f, n, M, time_limit=5.0):
    """Find g maximizing sum(g) s.t. g>=0, f*g <= M"""
    A = _build_conv_matrix(f, n)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    try:
        res = linprog(c, A_ub=A, b_ub=b_ub, bounds=[(0, None)]*n,
                      method='highs', options={'presolve': True, 'time_limit': time_limit})
    except Exception:
        return None
    if res.status != 0 or res.x is None:
        return None
    g = np.asarray(res.x, dtype=np.float64)
    s = g.sum()
    if s < 1e-15:
        return None
    return g / s  # Normalize to sum = 1

def _lp_optimize(f0, n, stop_time, seed, max_iters=200):
    rng = np.random.default_rng(seed)
    f = np.clip(f0.copy(), 0, None)
    f = f / f.sum()  # Normalize to sum = 1
    
    best_f = f.copy()
    best_score = _score(f)
    
    t = 0.3
    stall = 0
    max_stall = 80
    
    for it in range(max_iters):
        if time.monotonic() > stop_time - 5.0:
            break
        
        b = _conv_full(f)
        M = b.max()
        
        g = _lp_direction(f, n, M, time_limit=4.0)
        if g is None:
            # Perturb
            f = np.clip(f + rng.normal(0, 0.05, n), 0, None)
            f = f / f.sum()
            stall += 5
            if stall > max_stall:
                break
            continue
        
        # Check if g is close to f
        if np.linalg.norm(g - f) < 1e-7:
            stall += 3
            if stall > max_stall:
                break
            f = np.clip(f + rng.normal(0, 0.05, n), 0, None)
            f = f / f.sum()
            continue
        
        # Line search
        improved = False
        for attempt in range(20):
            f_new = (1 - t) * f + t * g
            f_new = np.clip(f_new, 0, None)
            s_new = f_new.sum()
            if s_new < 1e-10:
                t *= 0.5
                continue
            f_new = f_new / s_new  # Renormalize
            sc = _score(f_new)
            if sc < best_score - 1e-14:
                f = f_new
                best_f = f.copy()
                best_score = sc
                improved = True
                t = min(0.7, t * 1.08)
                stall = 0
                break
            else:
                t *= 0.5
        
        if not improved:
            stall += 1
            if stall >= max_stall:
                f = np.clip(f + rng.normal(0, 0.08, n), 0, None)
                f = f / f.sum()
                t = 0.3
                stall = 0
    
    return best_f, best_score

So: b_new[k] = b_old[k] + d*a[k-i] + a[k-i]*d + (extra d^2 if k=2i)

Wait, but we need to be careful: when j=i, the term is a[i]*a[k-i]. When we change a[i] to a[i]+d, this becomes (a[i]+d)*a[k-i] = a[i]*a[k-i] + d*a[k-i].

And when k-j=i (i.e., j=k-i), the term is a[j]*a[k-j] = a[k-i]*a[i]. When a[i] changes, this becomes a[k-i]*(a[i]+d) = a[k-i]*a[i] + d*a[k-i].

Let me redo: b[k] = sum_j a[j] * a[k-j]. The terms that involve a[i] are:
- j=i: a[i]*a[k-i] (if 0 <= k-i < n)
- k-j=i (j=k-i): a[k-i]*a[i] (if 0 <= k-i < n)

These are the same term when k=2i (j=i=k-i). Otherwise they're different.

- If k=2i: (v+d)^2 - v^2 = 2vd + d^2 (from the single term a[i]*a[i])
- If k≠2i (but k-i is valid): 2d*a[k-i] (from the two terms, assuming k-i ≠ i)
- If k-i is not in [0, n-1]: no change

Wait, I need to be more careful. b[k] = sum_{j: 0<=j<n, 0<=k-j<n} a[j]*a[k-j].

The change in b[k] when a[i] increases by d:
- Contribution from j=i (if 0<=k-i<n): d * a[k-i]
- Contribution from k-j=i, i.e., j=k-i (if 0<=k-i<n and k-i≠i): a[k-i] * d
- If k=2i (so j=i=k-i): the single term a[i]*a[i] changes by 2vd + d^2

So:
- If 0 <= k-i < n and k ≠ 2i: change = 2*d*a[k-i]
