The first two terms are bounded by M * [(1-t)^2 + 2t(1-t)/S_g]. Since S_g > 1 (the LP maximizes sum, and f itself is feasible with sum 1, so S_g >= 1), this is <= M.

The third term t^2 * max(g_norm*g_norm) could push it above M. But for small t, it's negligible.

Let me also think about the coordinate descent more carefully. The 1D problem is:

Given f with f[i] = v, S = sum(f), b = f*f. Change f[i] to v+delta.
New S' = S + delta.
New b'[k] = b[k] + 2*delta*f[k-i] (for k-i in [0,n-1]) + delta^2 (for k=2i).

The new score is 2n * max(b') / (S')^2.

max(b') = max_k (b[k] + 2*delta*f[k-i]*1_{k-i in [0,n-1]} + delta^2*1_{k=2i})

This is a piecewise function of delta. For each k, the expression is:
- If k-i in [0,n-1] and k != 2i: b[k] + 2*delta*f[k-i] (linear in delta)
- If k=2i: b[2i] + 2*delta*f[i] + delta^2 (quadratic)
- Otherwise: b[k] (constant)

The max is the upper envelope of these pieces. We want to minimize this max / (S+delta)^2.

We can find the optimal delta by:
1. Computing all pieces
2. Finding the delta where the max is minimized (considering the denominator)

For the 1D search, we can use the fact that the objective is the max of convex functions divided by (S+delta)^2. The max of convex functions is convex. Dividing by (S+delta)^2 (which is decreasing for delta > -S) gives a function that may have a unique minimum.

In practice, a grid search followed by golden section refinement works well.

    # grad_k[i] = 2*f[k-i] if 0 <= k-i < n else 0
    n = len(f)
    sg = np.zeros(n)
    for k in Kstar:

    f_new = f - lr * (sg - sg.mean())
    f_new = np.maximum(f_new, 0)
    f_sum = f_new.sum()
    if f_sum < 1e-15:

    return f_new / f_sum

    """LP to find direction g maximizing sum(g) s.t. (f*g)<=M, g>=0."""
    n = len(f)
