Wait, I realize there's an issue with my gradient computation. Let me re-derive it.

b = np.convolve(a, a), so b[k] = sum_i a[i] * a[k-i] where 0<=i<n and 0<=k-i<n.

The gradient of b[k] w.r.t. a[j]:
- a[j] appears in b[k] when i=j: term a[j]*a[k-j], valid if 0<=k-j<n
- a[j] appears in b[k] when k-i=j, i.e., i=k-j: term a[k-j]*a[j], valid if 0<=k-j<n

If both are valid (which they are simultaneously since the conditions are the same: 0<=k-j<n):
grad[j] = a[k-j] + a[k-j] = 2*a[k-j]

If k-j is out of range [0,n-1], neither term exists, so grad[j] = 0.

So the gradient of b[k] w.r.t. a is: 2 * (a reversed, shifted by k), with zeros where the shift goes out of bounds.

More precisely: grad_bk[j] = 2*a[k-j] if 0 <= k-j < n, else 0.

This means grad_bk = 2 * (the portion of reversed_a that overlaps with the valid range for lag k).

If k < n: grad_bk[j] = 2*a[k-j] for j = 0,...,k (a[k], a[k-1], ..., a[0])
If k >= n: grad_bk[j] = 2*a[k-j] for j = k-n+1,...,n-1 (a[n-1], a[n-2], ..., a[k-n+1])

OK so my gradient computation above is correct.

        n = len(a)
        polish_deadline = deadline - 10
        for _ in range(500):
            if time.monotonic() > polish_deadline:
                break
            b = _conv_full(a)
            M = float(b.max())
            cs = _score_from_b(b, n, float(a.sum()))
            if cs < best_score:
                best_a = a.copy()
                best_score = cs

            active = np.where(b >= M * 0.999)[0]
            if len(active) == 0:
                active = np.array([int(np.argmax(b))])

            grad = np.zeros(n)
            for ki in active:
                src = int(ki) - np.arange(n)
                valid = (src >= 0) & (src < n)
                if valid.any():
                    grad[valid] += 2.0 * a[src[valid]]
            grad /= len(active)

            gnorm = float(np.linalg.norm(grad))
            if gnorm < 1e-15:
                break

            scale = 1.0 / (gnorm + 1e-15)
            moved = False
            for eta in [0.002, 0.005, 0.01, 0.02, 0.04]:
                cand = _project_simplex(a - eta * scale * grad)
                sc = _score_from_b(_conv_full(cand), n, float(cand.sum()))
                if sc < cs * (1 - 1e-10):
                    a = cand
                    moved = True
                    break
            if not moved:
                a = _project_simplex(a + rng.normal(0, 0.003, n))

    # Last chance: try a few random perturbations of best
    if time.monotonic() < deadline - 8:
        for _ in range(20):
            if time.monotonic() > deadline - 8:
                break
            cand = _project_simplex(best_a + rng.normal(0, 0.005, n))
            sc = _exact(cand)
            if np.isfinite(sc) and sc < best_score:
                best_a = cand
                best_score = sc

    # Validate and return
    final = np.asarray(best_a, dtype=np.float64).ravel()
    final = np.maximum(final, 0.0)
    final = np.minimum(final, 1000.0)
    fs = _exact(final)
    if not np.isfinite(fs):
        fallback = np.ones(512) / 512.0
        return [float(x) for x in fallback]

    # Ensure sum >= 0.01
    if final.sum() < 0.01:
        fallback = np.ones(512) / 512.0
        return [float(x) for x in fallback]

    return [float(x) for x in final]
