So if I naively sum both contributions, I get 2 * a_{k-m} = 2 * a_m, which is correct (the derivative of a_m^2 is 2a_m). Good.

But if m ≠ k-m (and both are valid):
- j = m: term a_m * a_{k-m}. Derivative: a_{k-m}.
- j = k-m: term a_{k-m} * a_m. Derivative: a_{k-m}.
Total: 2 * a_{k-m}. Correct!

So: `∂c_k / ∂a_m = 2 * a_{k-m}` if `0 <= k-m <= n-1` and `0 <= m <= n-1`, else 0.

Wait, I need to be more careful. If m is valid (0 <= m < n) but k-m is not valid (k-m < 0 or k-m >= n), then:
- j = m: a_{k-m} is out of range, so this term doesn't exist. Contribution: 0.
- j = k-m: but k-m is not in [0, n-1], so j = k-m is not a valid index. Contribution: 0.

So: `∂c_k / ∂a_m = 2 * a_{k-m}` if `0 <= k-m < n`, else 0.

This makes sense! The subgradient direction for lag k is: `d_m = 2 * a_{k-m}` (shifted and valid-indexed).

To minimize c_{k*}, we want to decrease a_m where d_m is large, i.e., where a_{k*-m} is large.

The projected step (maintaining sum=1):
`a_new = a - eta * (d - mean(d))`
`a_new = max(a_new, 0)`
`a_new = a_new / sum(a_new)`

For the LP best-response, the constraint matrix A has:
`A[k, m] = ∂c_k / ∂a_m / 2 = a_{k-m}` (using the factor of 2 absorbed)

Wait, in the LP: we want `convolve(a, g)_k <= M`. 
`convolve(a, g)_k = sum_j a_j * g_{k-j}`.

This is LINEAR in g (a is fixed). The constraint is `sum_j a_j * g_{k-j} <= M`.

So the matrix for the LP is: row k, column m: `A[k,m] = a_m` if k-m is in [0,n-1]... 

Wait, `convolve(a, g)_k = sum_j a_j * g_{k-j}`.

As a function of g: for each m, g_m appears when k-j = m, i.e., j = k-m. So:
`convolve(a, g)_k = sum_m a_{k-m} * g_m` (where a_{k-m} is defined only for valid k-m).

So `A[k, m] = a_{k-m}` if `0 <= k-m < n`, else 0.

This is the same as the subgradient direction (without the factor of 2)!

OK so the LP matrix and the subgradient are closely related. Good.

- It should be roughly unimodal (bell-shaped)
