5. Check if any other line is above at that point
6. If yes, the new active line is the one with the largest value at that point
7. Repeat until the active line's slope >= 0

This is the "walking on the upper envelope" approach. Each step moves to the next breakpoint, and there are at most n breakpoints in total. So it's O(n) per coordinate worst case, O(n²) total.

            if fn.sum() < 1e-10: continue

        hi_t = min(0.95, best_t + 0.1)
        gr = (math.sqrt(5)-1)/2
        c_t = hi_t - gr*(hi_t-lo_t)
        d_t = lo_t + gr*(hi_t-lo_t)
        fc, fd = _score(np.clip((1-c_t)*f+c_t*g,0,None)), _score(np.clip((1-d_t)*f+d_t*g,0,None))
        for _ in range(20):
            if hi_t - lo_t < 1e-7: break
            if fc <= fd:
                hi_t, d_t, fd = d_t, c_t, fc
                c_t = hi_t-gr*(hi_t-lo_t)
                fc = _score(np.clip((1-c_t)*f+c_t*g,0,None))
            else:

                d_t = lo_t+gr*(hi_t-lo_t)
                fd = _score(np.clip((1-d_t)*f+d_t*g,0,None))
        
        best_tv = (lo_t+hi_t)/2
        fn = np.clip((1-best_tv)*f + best_tv*g, 0, None)
        sc = _score(fn)
        if sc < best_sc - 1e-15:
            f, best_f, best_sc = fn, fn.copy(), sc
            M = float(_conv_full(f).max())
            stall = 0
        else:

            stall += 1
            if stall >= mx_stall:

                if s == 0: f = np.clip(f + rng.normal(0, 0.1, n), 0, None)
                elif s == 1:
                    b = n//4
                    f2 = f.copy()
                    f2[:b], f2[n-b:] = f[n-b:].copy(), f[:b].copy()
                    f = f2
                elif s == 2:

                fs = f.sum()
                f = f/fs if fs > 1e-10 else best_f.copy()
                M = float(_conv_full(f).max())
                stall = 0
    
    return best_f, best_sc

Wait, I want to double-check my understanding of the LP. The LP is:
max sum(g) s.t. A@g <= M*1, g >= 0

where A[k,j] = f[k-j] if 0 <= k-j < n, else 0.

The constraint (A@g)[k] = sum_j f[k-j] * g[j] = (f*g)[k] = conv(f,g)[k] <= M.

So the LP finds the "largest" g (in L1 norm) such that the cross-correlation of f and g doesn't exceed M.

When we form f_new = (1-t)*f + t*g, the self-correlation is:
conv(f_new, f_new) = (1-t)² conv(f,f) + 2t(1-t) conv(f,g) + t² conv(g,g)

We know conv(f,g) <= M = max conv(f,f). But we don't know conv(g,g). If conv(g,g) is small, then the new self-correlation will be reduced.

The LP doesn't directly control conv(g,g). That's a limitation of the approach. But empirically, it works well because the LP tends to find g that is "spread out" (high sum, low peak), which implies low self-correlation.

One improvement: we could add a constraint on conv(g,g) to the LP. But conv(g,g) is quadratic in g, so this would make the LP a QP. Let me consider this.

The QP would be:
max sum(g) s.t. A@g <= M*1, g^T Q_k g <= M for all k, g >= 0

where Q_k is the matrix for the k-th convolution lag. This is a convex QP (if Q_k is positive semidefinite). But is Q_k PSD?

Q_k[i,j] = 1 if i+j=k (or 2 if i=j and 2i=k), else 0.

This matrix is not PSD in general. For example, for k=1, Q_1 = [[0,1],[1,0]] which has eigenvalues 1 and -1. So the QP is nonconvex.

Alternative: use a penalty method. Add a penalty term for conv(g,g) > M to the LP objective. But this changes the problem.

I think the LP approach without the conv(g,g) constraint is good enough. The empirical results support this.
