So the problem is: minimize 2n * max_k (a*a)(k) / S^2 where (a*a) is the self-convolution (not autocorrelation).

This is a fundamentally different problem! The self-convolution (a*a)(k) = sum_j a[j] a[k-j] is symmetric (since a*a = a*a, the convolution is commutative), so (a*a)(k) = (a*a)(2n-2-k). The peak could be anywhere.

For a "flat" sequence a_j = c, (a*a)(k) = (n-|k-(n-1)|) * c^2 for k = 0, ..., 2n-2. The peak is at k = n-1: (a*a)(n-1) = n*c^2. S = n*c. Score = 2n * n*c^2 / (n*c)^2 = 2.
