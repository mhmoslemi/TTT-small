- Compute the linear convolution ar * w (length n + (2n-1) - 1 = 3n-2)

Let k = n-1-j: = sum_k a[k] * w[m-n+1+k]

We want g[i] = 2 * sum_k a[k] * w[i+k].

g[i] = 2 * (ar * w)[i + n - 1] for i = 0, ..., n-1.

So we need (ar * w)[n-1] through (ar * w)[2n-2], which is n values.

The full convolution ar * w has length n + (2n-1) - 1 = 3n - 2.

Using FFT with size >= 3n-2 (next_fast_len). For n=512, that's next_fast_len(1534) = 2048.

This is efficient.

Now, for the optimization algorithm:

1. Start from parent a (normalized to sum=1).
2. Compute c = convolve(a, a), M = max(c).
3. Soft-max weights: w[k] = exp((c[k] - M) / T) / sum(exp((c[j] - M) / T)), with T = alpha * M for small alpha (e.g., 0.01-0.05).
4. Compute gradient g[i] = 2 * sum_j a[j] * w[i+j] using FFT.
5. Line search: find step size eta that minimizes M(a - eta * g) projected onto simplex.
6. Update: a = project_simplex(a - eta * g).
7. Repeat.

The simplex projection: project onto {a >= 0, sum(a) = 1}.

For the line search, we can use a few candidate step sizes and pick the best.

Also, I should think about whether to use the `scipy.optimize.minimize` with a smooth approximation as an alternative to the manual gradient descent. The smooth approximation is:
f_T(a) = 2n * (M + T * log(sum(exp((c-M)/T))))

This is smooth and differentiable, so we could use scipy's gradient-based optimizers. But the constraint (simplex) makes it tricky. We'd need to parameterize a as exp(v) / sum(exp(v)) (log-barrier parameterization), which avoids the non-negativity constraint.

With the log parameterization: a[i] = exp(v[i]) / sum_j exp(v[j]) = softmax(v).

The objective in terms of v: f(v) = 2n * max_k convolve(softmax(v), softmax(v))[k].

This is a smooth function (for the soft-max approximation), and we can use gradient descent on v without any projection.

The gradient: df/dv[i] = df/da[i] * da[i]/dv[i].

da[i]/dv[i] = a[i] (1 if i not the max index, -a[j] if j is the max index)... actually:
da[i]/dv[i] = a[i](1 - a[i])
da[i]/dv[j] = -a[i]*a[j] for i != j

So df/dv = (I - a*a^T) @ (df/da) = df/da - a * (a^T @ df/da)

This is a nice correction that ensures the gradient is in the tangent space of the simplex.

Let me try this approach: optimize in log-space (v) using the gradient of the soft-max objective.
