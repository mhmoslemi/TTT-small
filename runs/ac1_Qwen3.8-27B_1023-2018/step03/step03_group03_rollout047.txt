M*(1-t)² + 2t(1-t)*M + t²*G < M
M*(1-2t+t²) + 2Mt-2t²M + t²G < M

t²(G - M) < 0

This requires G < M! So if max(g*g) < M, the update decreases the score. But we don't guarantee this from the LP.

Actually, the LP constraint is f*g <= M, not g*g <= M. So G could be > M.

Δscore ≈ 2n/M [max over k of (2t*(f*g)_k - 2t * M + ...)] + ...
