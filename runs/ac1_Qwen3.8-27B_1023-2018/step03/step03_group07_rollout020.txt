This is actually a well-studied problem related to "minimum peak distortion" or "flat autocorrelation" in signal processing.

For the two-bump structure [a]*p + [0]*q + [a]*p (with 2p + q = n):
The convolution will have:
- A triangular bump from the first cluster: max = p*a²
- A triangular bump from the second cluster: max = p*a²
- A cross-term bump in the middle: depends on overlap

If the two clusters don't overlap in the convolution (i.e., 2p-2 < q, or the gap is at least 2p-1), then the cross terms are zero and max(conv) = p*a².

def _simplex_proj(z):
    """Project z onto {x >= 0, sum(x) = 1}."""
    n = z.size
    u = np.sort(z)[::-1]
    cssv = np.cumsum(u)
    idx = np.arange(1, n + 1, dtype=np.float64)
    cond = u * idx > (cssv - 1.0)
    if not cond.any():
        return np.ones(n) / n
    rho = np.where(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(z - theta, 0.0)
