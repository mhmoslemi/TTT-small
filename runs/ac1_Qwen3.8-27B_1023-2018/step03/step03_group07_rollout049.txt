Actually, let me think about this problem from a different angle. The key quantity is:

`score = 2n * max_k(C[k]) / S²`

where `C = a*a` (full convolution) and `S = sum(a)`.

Since the score is scale-invariant, set `S = 1`. Then `score = 2n * max_k(C[k])`.

We want to minimize `max_k(C[k])` subject to `sum(a) = 1, a >= 0`.

The constraint at lag k is `sum_j a[j]*a[k-j] <= M` where the sum is over valid j. This is a quadratic constraint.

For a given M, the feasible set `{a >= 0 : sum(a) = 1, max_k C[k] <= M}` is not convex (because the quadratic constraints define non-convex sets in general, as I showed earlier).

However, we can use the LP relaxation: replace `a[j]*a[k-j]` with a linear constraint by fixing one of the two factors. This is the "alternating linearization" or "best response" approach.

The LP: `max sum(g) s.t. sum_j a[j]*g[k-j] <= M, g >= 0` is a relaxation.

The fixpoint of this alternating iteration is a KKT point of a related convex problem, not necessarily the original.

For the original problem, since it's a ratio of a piecewise-quadratic function to a quadratic function, we can use Dinkelbach's method or parameterized bisection.
