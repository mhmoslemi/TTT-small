This is a quasi-convex problem (for a fixed M, the constraint (a*a)[k] ≤ M is a set of quadratic inequalities, which is nonconvex). But the max makes it non-smooth.

An alternative formulation: minimize t subject to (a*a)[k] ≤ t for all k, sum(a)=1, a≥0. This is a QCQP (quadratically constrained quadratic program) which is NP-hard in general, but can be approximated.

The LSE smoothing converts it to a smooth nonconvex optimization, which L-BFGS can handle.

The coordinate descent is a first-order method that works well for this type of problem.

I think the best approach is to combine:
1. LSE + L-BFGS for the "coarse" optimization (gets us into the right basin)
2. Coordinate descent for the "fine" optimization (exploits the structure)
3. Periodic restarts/perturbations to escape local optima

Let me write the final code now.

One more thought: the evaluator uses `np.convolve` which does exact (up to floating point) convolution. The FFT-based convolution has small numerical errors. For the final evaluation, I should use the exact evaluator. But during optimization, FFT is fine.

Also, I should note that the evaluator clamps values to [0, 1000] and takes max(0, x). So negative values become 0, and values above 1000 become 1000. Since we're working with normalized sequences (sum=1), individual values are at most 1, so the clamping doesn't matter.

    L = 2 * n - 1
    size = next_fast_len(L)

    c = irfft(F * F, size)[:L]
    np.maximum(c, 0.0, out=c)

    u = np.asarray(u, dtype=np.float64)

    s = float(e.sum())
    if s <= 0 or not math.isfinite(s):

    return e / s

    Ltot = 2 * n - 1
    c = _conv_fft(p)
    S_total = 1.0
    cur_score = float(2.0 * n * c.max())
    best_score = cur_score
    best_p = p.copy()
    rng = np.random.default_rng(seed)
    sweep = 0
    flat = 0

    while sweep < max_sweeps and time.monotonic() < end_time - 2.0:
        improved = False
        order = rng.permutation(n)
        for idx_i in order:
            i = int(idx_i)
            if time.monotonic() > end_time - 0.8:
                break
            if S_total <= 1e-300:
                break
            if S_total > 1.3 or S_total < 0.7:
                inv = 1.0 / S_total
                p *= inv
                c *= inv * inv
                S_total = 1.0

            S = float(S_total)
            v = float(p[i])
            start_i = i
            end_i = min(i + n, Ltot)
            Ls = end_i - start_i
            if Ls <= 0:
                continue

            base = c[start_i:end_i].copy()
            infl = 2.0 * p[:Ls]

            max_const = 0.0
            if start_i > 0:
                ml = float(c[:start_i].max())
                if ml > max_const:
                    max_const = ml
            if end_i < Ltot:
                mr = float(c[end_i:].max())
                if mr > max_const:
                    max_const = mr

            avg = S / float(n)
            x_hi = max(22.0 * v, 70.0 * avg, 0.035 * S, 1e-12)
            x_hi = min(x_hi, 14.0 * S)
            if not math.isfinite(x_hi) or x_hi <= 0.0:
                x_hi = max(1e-8, avg)

            pts = np.linspace(0.0, x_hi, Gc + 1, dtype=np.float64)
            if 0.0 <= v <= x_hi:
                pts = np.unique(np.append(pts, v))

            diag = i - start_i

            def eval_xs(xs):
                xs = np.asarray(xs, dtype=np.float64).ravel()
                w = xs - v
                denom = S + w
                vals = np.full(xs.shape, math.inf, dtype=np.float64)
                valid = denom > 1e-15
                if not np.any(valid):
                    return vals
                aff = base[None, :] + w[:, None] * infl[None, :]
                dval = base[diag] + w * infl[diag] + w * w
                aff = np.maximum(aff, dval[:, None])
                aff = np.maximum(aff, max_const)
                dv = denom[valid]
                mv = aff[valid].max(axis=1)
                vals[valid] = (2.0 * n * mv) / (dv * dv)
                return vals

            vals = eval_xs(pts)
            if not np.any(np.isfinite(vals)):
                continue
            imin = int(np.argmin(vals))
            best_x = float(pts[imin])
            best_val = float(vals[imin])

            dw = x_hi / float(Gc)
            lo = max(0.0, best_x - 2.5 * dw)
            hi = min(x_hi, best_x + 2.5 * dw)
            if hi <= lo:
                hi = lo + 1e-12
            fine = np.linspace(lo, hi, Gf, dtype=np.float64)
            if 0.0 <= best_x <= x_hi:
                fine = np.unique(np.append(fine, best_x))
            vals2 = eval_xs(fine)
            if np.any(np.isfinite(vals2)):
                imin2 = int(np.argmin(vals2))
                vx2 = float(fine[imin2])
                vv2 = float(vals2[imin2])
                if vv2 < best_val:
                    best_x = vx2
                    best_val = vv2

            if math.isfinite(best_val) and best_val < cur_score - 1e-13 and 0.0 <= best_x <= 14.0 * S:
                w = best_x - v
                if abs(w) > 1e-15:
                    p[i] = best_x
                    S_total += w
                    c[start_i:end_i] += w * infl
                    di = 2 * i
                    if 0 <= di < Ltot:
                        c[di] += w * w
                    cur_score = best_val
                    improved = True

        S = float(S_total)
        if S > 1e-300 and math.isfinite(S):
            inv = 1.0 / S
            p *= inv
            c *= inv * inv
        else:
            break
        S_total = 1.0
        c = _conv_fft(p)
        np.maximum(c, 0.0, out=c)
        new_score = float(2.0 * n * c.max())
        if math.isfinite(new_score) and new_score < best_score - 1e-14:
            best_score = new_score
            best_p = p.copy()
        if consider is not None:
            try:
                consider(best_p)
            except Exception:
                pass

        if improved:
            flat = 0
        else:
            flat += 1
            if flat >= 4:
                if time.monotonic() < end_time - 6.0:
                    try:
                        p = p * np.exp(rng.normal(0.0, 0.02, n, dtype=np.float64))
                        p = np.maximum(p, 0.0)
                        ss = float(p.sum())
                        if ss > 0.0:
                            p /= ss
                        c = _conv_fft(p)
                        S_total = 1.0
                        cur_score = float(2.0 * n * c.max())
                        if math.isfinite(cur_score) and cur_score < best_score - 1e-13:
                            best_score = cur_score
                            best_p = p.copy()
                            if consider is not None:
                                consider(best_p)
                        flat = 0
                    except Exception:
                        break
                else:
                    break
        sweep += 1

    p = np.maximum(p, 0.0)
    ss = float(p.sum())
    if ss > 1e-300:
        p = p / ss
    try:
        c = _conv_fft(p)
        sc = float(2.0 * n * c.max())
    except Exception:
        sc = math.inf
    if math.isfinite(sc) and sc < best_score:
        best_score = sc
        best_p = p.copy()
    return best_p, best_score


def _lp_step(f, stop_time):
    n = int(f.size)
    if n < 50:
        return None
    M = float(_conv_fft(f).max())
    if M <= 0 or not math.isfinite(M):
        return None

    A = np.zeros((2 * n - 1, n), dtype=np.float64)
    for j in range(n):
        A[j:j + n, j] = f[j]

    try:
        import cvxpy as cp
        g = cp.Variable(n, nonneg=True)
        b = np.full(2 * n - 1, M, dtype=np.float64)
        constraints = [A @ g <= b]
        obj = cp.Maximize(cp.sum(g))
        prob = cp.Problem(obj, constraints)
        for slv in [cp.SCS, cp.ECOS, cp.CLIP]:
            try:
                prob.solve(solver=slv, verbose=False)
                break
            except Exception:
                continue
            if time.monotonic() > stop_time - 5:
                break
        if g.value is None:
            return None
        g_val = np.maximum(np.asarray(g.value, dtype=np.float64), 0.0)
        gv = float(g_val.sum())
        if gv < 1e-10 or not math.isfinite(gv):
            return None
        return g_val / gv
    except Exception:
        return None


def propose_candidate(seed=42, budget_s=1300, **kwargs):
    t0 = time.monotonic()
    budget = max(10.0, float(budget_s))
    hard = t0 + budget - 25.0
    if hard <= t0 + 3.0:
        hard = t0 + max(2.0, budget - 1.0)

    parent = _get_parent()
    best_arr = parent.copy()
    try:
        best_score = float(_score_exact_arr(best_arr))
    except Exception:
        best_score = math.inf

    if not math.isfinite(best_score) or best_arr.size == 0:
        best_arr = np.ones(64, dtype=np.float64)
        best_arr /= 64.0
        best_score = float(_score_exact_arr(best_arr))

    def consider(arr):
        nonlocal best_arr, best_score
        try:
            a = np.asarray(arr, dtype=np.float64).ravel()
            a = np.where(np.isfinite(a), a, 0.0)
            a = np.clip(a, 0.0, 1000.0)
            if a.size == 0:
                return
            s = float(a.sum())
            if s < 0.01:
                return
            sc = float(_score_exact_arr(a))
            if math.isfinite(sc) and sc < best_score - 5e-14:
                best_arr = a.copy()
                best_score = sc
        except Exception:
            pass

    n_par = int(best_arr.size)
    work = best_arr.copy()
    work = work / max(float(work.sum()), 1e-300)

    # Phase 1: LSE optimization
    p1_end = min(hard - 60.0, t0 + 0.30 * budget)
    if p1_end > time.monotonic() + 25.0 and n_par >= 64:
        try:
            p1 = _lse_optimize(work, p1_end, consider=consider)
            if p1 is not None and p1.size == n_par and np.all(np.isfinite(p1)):
                p1 = p1 / max(float(p1.sum()), 1e-300)
                consider(p1)
        except Exception:
            pass

    work = best_arr.copy()
    work = work / max(float(work.sum()), 1e-300)

    # Phase 2: Coordinate descent (main)
    p2_end = min(hard - 80.0, t0 + 0.52 * budget)
    if p2_end > time.monotonic() + 20.0:
        try:
            work, _ = _coord_polish(work, p2_end, max_sweeps=300000,
                                    seed=int(seed + 7777), consider=consider)
        except Exception:
            pass

    work = best_arr.copy()
    work = work / max(float(work.sum()), 1e-300)

    # Phase 3: LP direction blend
    lp_end = min(hard - 60.0, time.monotonic() + 45.0)
    if lp_end > time.monotonic() + 15.0 and np.all(np.isfinite(work)):
        g_dir = _lp_step(work, lp_end)
        if g_dir is not None and g_dir.size == n_par:
            for t_alpha in [0.30, 0.18, 0.10]:
                blended = (1.0 - t_alpha) * work + t_alpha * g_dir
                blended = np.maximum(blended, 0.0)
                bs = float(blended.sum())
                if bs > 0:
                    blended /= bs
                    consider(blended)

    work = best_arr.copy()
    work = work / max(float(work.sum()), 1e-300)

    # Phase 4: Fine LSE
    p4_end = min(hard - 50.0, time.monotonic() + 0.12 * budget)
    if p4_end > time.monotonic() + 20.0:
        try:
            p4 = _lse_optimize(work, p4_end, consider=consider)
            if p4 is not None and p4.size == n_par and np.all(np.isfinite(p4)):
                p4 = p4 / max(float(p4.sum()), 1e-300)
                consider(p4)
        except Exception:
            pass

    work = best_arr.copy()
    work = work / max(float(work.sum()), 1e-300)

    # Phase 5: More coordinate descent
    p5_end = min(hard - 30.0, t0 + budget - 35.0)
    if p5_end > time.monotonic() + 15.0:
        try:
            work, _ = _coord_polish(work, p5_end, max_sweeps=300000,
                                    seed=int(seed + 123456), consider=consider)
        except Exception:
            pass

    # Phase 6: Try resampled length if time permits
    rem = hard - 20.0 - time.monotonic()
    if rem > 150.0 and n_par >= 512:
        n2 = max(1024, min(2048, int(n_par * 0.75)))
        try:
            xp = (np.arange(n_par, dtype=np.float64) + 0.5) / float(n_par)
            fp = np.interp((np.arange(n2, dtype=np.float64) + 0.5) / float(n2),
                           xp, best_arr)
            p2 = np.maximum(fp, 0.0)
            p2s = float(p2.sum())
            if p2s > 0:
                p2 /= p2s
                consider(p2)
                if rem > 100.0:
                    p2_end = min(hard - 25.0, time.monotonic() + rem - 30.0)
                    if p2_end > time.monotonic() + 20.0:
                        p2, _ = _coord_polish(p2, p2_end, max_sweeps=100000,
                                              seed=int(seed + 424242), consider=consider)
        except Exception:
            pass

    # Final squeeze
    fin_end = min(hard - 15.0, t0 + budget - 10.0)
    if fin_end > time.monotonic() + 15.0:
        work = best_arr.copy()
        work = work / max(float(work.sum()), 1e-300)
        try:
            work, _ = _coord_polish(work, fin_end, max_sweeps=100000,
                                    seed=int(seed + 555555), consider=consider)
        except Exception:
            pass

    # Final validation and return
    try:
        out = np.asarray(best_arr, dtype=np.float64).ravel()
        out = np.where(np.isfinite(out), out, 0.0)
        out = np.clip(out, 0.0, 1000.0)
        if out.size == 0 or float(out.sum()) < 0.01:
            out = parent.copy()
            out = np.where(np.isfinite(out), out, 0.0)
            out = np.clip(out, 0.0, 1000.0)
            if out.size == 0 or float(out.sum()) < 0.01:
                out = np.full(64, 1.0 / 64.0, dtype=np.float64)
        ls = [float(x) for x in out]
        final_sc = float(evaluate_sequence(ls))
        if not math.isfinite(final_sc):
            ls = [float(x) for x in parent]
            final_sc = float(evaluate_sequence(ls))
            if not math.isfinite(final_sc):
                return [1.0]
        return ls
    except Exception:
        return [1.0]
