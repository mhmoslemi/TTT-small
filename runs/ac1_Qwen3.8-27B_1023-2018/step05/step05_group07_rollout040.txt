Now, for the line search: given $a$ and direction $g$, find $t \in [0,1]$ that minimizes $\max(((1-t)a + tg) * ((1-t)a + tg))$.

Note that $((1-t)a + tg) * ((1-t)a + tg) = (1-t)^2 (a*a) + 2t(1-t) (a*g) + t^2 (g*g)$.

So the max is $\max_k [(1-t)^2 c_k^{aa} + 2t(1-t) c_k^{ag} + t^2 c_k^{gg}]$.

This is the max of quadratic functions of $t$, each of which is convex in $t$ (since the coefficient of $t^2$ is $c_k^{gg} \geq 0$). The max of convex functions is convex, so we can use bisection or ternary search!

            # Gradient of smooth max: grad[j] = sum_k p[k] * 2*a[k-j]
            grad = np.zeros(n)
            for k in range(2*n-1):
                if p[k] < 1e-15:
                    continue
                jlo = max(0, k-n+1)
                jhi = min(n, k+1)
                for j in range(jlo, jhi):
                    grad[j] += 2.0 * p[k] * a[k-j]
            
            # Project: subtract mean (for sum=1 constraint)
            grad -= grad.mean()
            
            # Line search
            gnorm = np.linalg.norm(grad)
            if gnorm < 1e-15:
                break
            
            improved = False
            for lr_t in [lr, lr*0.5, lr*0.1, lr*0.01]:
                cand = a - lr_t * grad
                cand = np.maximum(cand, 1e-15)
                cand /= cand.sum()
                new_M = np.convolve(cand, cand).max()
                if new_M < M * (1 - 1e-12):
                    a = cand
                    improved = True
                    break
            
            if not improved:
                break
    
    return best_a
