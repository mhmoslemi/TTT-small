def _conv_self(a):
    n = a.size
    L = 2 * n - 1
    size = next_fast_len(L)
    F = rfft(a, size)
    c = irfft(F * F, size)[:L]
    return np.maximum(c, 0.0)

def _score(a):
    n = a.size
    s = float(a.sum())
    if s < 0.01:
        return math.inf
    c = _conv_self(a)
    m = float(c.max())
    return float(2.0 * n * m / (s * s))

  - Multiple linear functions of $\delta$ (for $k \neq 2i$)
  - One quadratic function of $\delta$ (for $k = 2i$)

  The minimum of a max of linear functions can be found by binary search or by solving a small LP.

  For the previous code's approach of grid search, it evaluates the max at many $\delta$ values. This works but is wasteful.

  A better approach: For the affected range, the new max as a function of $\delta$ is:
  $g(\delta) = \max(M_{unaffected}, \max_{k \in A, k \neq 2i} (c_k + 2\delta a_{k-i}), c_{2i} + 2\delta a_i + \delta^2)$

  where $A$ is the affected range and $M_{unaffected}$ is the max of unaffected values.

  To find $\min_\delta g(\delta)$, we can:
  1. Note that for $\delta \geq 0$, the linear terms increase, so the optimum is either at $\delta = 0$ or where the quadratic term dominates
  2. For $\delta < 0$, the linear terms decrease, so we want to make $\delta$ as negative as possible (until $a_i + \delta = 0$, i.e., $\delta = -a_i$)

  Actually, this is more subtle. The optimum could be at an interior point where two of the "active" constraints are equal.

  For efficiency, I'll use a binary search approach:
  - We want $g(\delta) \leq t$ for the smallest possible $t$
  - This means $c_k + 2\delta a_{k-i} \leq t$ for all $k \in A, k \neq 2i$, and $c_{2i} + 2\delta a_i + \delta^2 \leq t$
  - The first set of constraints gives: $\delta \leq (t - c_k)/(2a_{k-i})$ for $a_{k-i} > 0$, and $\delta \geq (t - c_k)/(2a_{k-i})$ for $a_{k-i} < 0$ (but $a \geq 0$, so $a_{k-i} \geq 0$)
  - Since $a \geq 0$, all linear constraints are upper bounds on $\delta$ (when $\delta > 0$) or always satisfied (when $\delta < 0$)

Wait, I realize there's an issue with my `_lse_objective` function. The cross-correlation computation needs to be correct. Let me verify:

I want $g[i] = \sum_k w_k \cdot p_{k-i}$ where $p_{k-i} = 0$ if $k-i < 0$ or $k-i \geq n$.

This is the cross-correlation of $p$ and $w$ at lag $i$:
$(p \star w)(i) = \sum_k p(k-i) \cdot w(k)$

Using FFT:
