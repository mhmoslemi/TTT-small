Actually, I realize there might be an even better approach. Let me think about the "subgradient" direction.

The score is `f(a) = 2n * max_j c_j / S²` where `c = a*a` and `S = sum(a)`.

The subgradient of `max_j c_j` w.r.t. `a` is:
`g_i = (1/|S|) * sum_{j in S} ∂c_j/∂a_i`

where S is the set of active lags (those achieving the max).

`∂c_j/∂a_i = 2*a_{j-i}` (as derived earlier, with a_k=0 outside [0,n-1])

So `g_i = (2/|S|) * sum_{j in S} a_{j-i}`

This gives a direction that, if we decrease a in the direction g, we reduce the max.

We can use this as a descent direction:
- Compute g (the subgradient)
- Find α > 0 that minimizes f(a - α*g) (or f(a - α*g) subject to a >= 0)
- Update a ← max(0, a - α*g)
- Renormalize to sum(a) = 1

This is a projected subgradient method. It's simple and should make steady progress.

Actually, a better approach is to use the "average" subgradient over a window (like in the LSE, but with a hard max instead of soft max):

`g_i = (2/|S|) * sum_{j in S} a_{j-i}`

where S = {j : c_j >= c_max - ε} for a small tolerance ε.

This is essentially what the LSE does with small T, but using a hard threshold instead of exponential weights.

The advantage of the hard max subgradient is that it's cheaper to compute (no exp, just threshold).

Let me combine these ideas:
1. Use LSE for the main optimization (smooth, good for L-BFGS)
2. Use hard-max subgradient for "spike" updates between LSE phases
3. Use coordinate descent for final polishing
