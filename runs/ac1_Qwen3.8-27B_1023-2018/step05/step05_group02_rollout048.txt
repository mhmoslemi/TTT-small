Actually, let me reconsider the coordinate descent. The key insight is:

Score = $2n \cdot \max_k c_k / S^2$

When we change $a_i$ by $\delta$, the score changes because:
1. Some $c_k$ values change (by $2\delta a_{k-i}$ or $2\delta a_i + \delta^2$)
2. $S$ changes by $\delta$

The score as a function of the new value $x = a_i + \delta$:
- $c_k' = c_k + 2(x-v) a_{k-i} + (x-v)^2 \mathbb{1}[k=2i]$ (for affected k)
- $S' = S + (x-v)$
- Score = $2n \cdot \max(\max_{affected} c_k', \max_{unaffected} c_k) / (S')^2$

This is a 1D optimization problem. The function is:
$$f(x) = \frac{2n \cdot \max(M_{const}, \max_k (c_k + 2(x-v) \cdot w_k + (x-v)^2 \cdot d_k))}{(S + x - v)^2}$$

where $w_k = a_{k-i}$ (for affected k), $d_k = \mathbb{1}[k=2i]$, and $M_{const} = \max$ over unaffected k.

This is a ratio of a convex piecewise-quadratic function to a convex quadratic. It's not convex in general, but for the range of x we care about, it should be unimodal or close to it.
