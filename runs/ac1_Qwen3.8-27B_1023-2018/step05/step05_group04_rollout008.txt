```python
def _lp_iterate(f, M, stop_time):
    """Solve the LP: max 1'b s.t. T_f b <= M*1, b >= 0."""
    n = f.size
    L = 2 * n - 1
    
    # Build sparse Toeplitz matrix
    rows = []
    cols = []
    vals = []
    for j in range(n):
        k_start = j  # k >= j (so k-j >= 0)
        k_end = min(L - 1, j + n - 1)  # k <= j+n-1 (so k-j < n)
        if k_start > k_end:
            continue
        ks = np.arange(k_start, k_end + 1)
        rows.extend(ks.tolist())
        cols.extend([j] * (k_end - k_start + 1))
        vals.extend(f[ks - j].tolist())
    
    T = csr_matrix((vals, (rows, cols)), shape=(L, n))
    
    c_obj = -np.ones(n)
    A_ub = T
    b_ub = np.full(L, M)
    bounds = [(0, None)] * n
    
    res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    
    if res.status == 0 and res.x is not None:
        b = np.maximum(res.x, 0.0)
        s = float(b.sum())
        if s > 1e-15:
            return b / s
    return None
```

Bisection: find the minimum value $v$ such that $\exists x \geq 0: \max_k (c_k + 2xd_k + e_k x^2) \leq v(S_{-i}+x)^2$.

The condition $c_k + 2xd_k + e_k x^2 \leq v(S_{-i}+x)^2$ for all $k$ is:
$c_k + 2xd_k + e_k x^2 \leq v(S_{-i}^2 + 2S_{-i}x + x^2)$
$\Rightarrow (e_k - v)x^2 + 2(d_k - vS_{-i})x + (c_k - vS_{-i}^2) \leq 0$

For each $k$, this is a quadratic in $x$ that must be $\leq 0$. The feasible set for $x$ is the intersection of all these constraints plus $x \geq 0$.

For a given $v$, we can check feasibility by finding if there exists $x \geq 0$ satisfying all $2n-1$ quadratic inequalities. Each inequality $(e_k - v)x^2 + 2(d_k - vS_{-i})x + (c_k - vS_{-i}^2) \leq 0$ gives a constraint on $x$ (either all $x$, or $x$ in an interval, or no solution).

If $e_k - v < 0$ (i.e., $v > e_k$): the quadratic opens downward, so it's $\leq 0$ outside a bounded interval. Constraint: $x \leq x_1$ or $x \geq x_2$.
If $e_k - v > 0$: the quadratic opens upward, so it's $\leq 0$ inside a bounded interval. Constraint: $x_1 \leq x \leq x_2$.
If $e_k - v = 0$: linear constraint.

Since $e_k \in \{0, 1\}$ and $v$ is the target score divided by $2n$ (very small, like 0.0002), we always have $v < e_k$ for $k = 2i$ (where $e_k = 1$). Wait, $v = M_{target}$ which is about 0.0002. For $k \neq 2i$: $e_k = 0$, so $e_k - v = -v < 0$ (opens downward, constraint is outside an interval).

So for $k = 2i$: $x$ must be in $[x_1, x_2]$ (bounded).
For $k \neq 2i$: $x$ must be outside $[x_1, x_2]$ (or all $x$ if discriminant < 0).
For all $k$: $x \geq 0$.

The intersection of all these constraints gives the feasible set for $x$. We can compute this by tracking the lower and upper bounds.
