def _lp_step(f, stop_time):
    """LP-based direction: maximize sum(g) s.t. f*g <= M, g >= 0."""
    n = int(f.size)
    if n < 10:
        return None
    M = float(_conv_self(f).max())
    if M <= 0 or not math.isfinite(M):
        return None

    # Only use LP for moderate sizes
    if n > 4096:
        return None

    A = np.zeros((2 * n - 1, n), dtype=np.float64)
    for j in range(n):
        A[j:j + n, j] = f[j]

    try:
        import cvxpy as cp
        g = cp.Variable(n, nonneg=True)
        b = np.full(2 * n - 1, M, dtype=np.float64)
        constraints = [A @ g <= b]
        obj = cp.Maximize(cp.sum(g))
        prob = cp.Problem(obj, constraints)
        for slv in [cp.SCS, cp.ECOS, cp.CLP]:
            try:
                prob.solve(solver=slv, verbose=False)
                break
            except Exception:
                continue
            if time.monotonic() > stop_time - 5:
                return None
        if g.value is None:
            return None
        g_val = np.maximum(np.asarray(g.value, dtype=np.float64), 0.0)
        gv = float(g_val.sum())
        if gv < 1e-10 or not math.isfinite(gv):
            return None
        return g_val / gv
    except Exception:
        return None

So d/d a_i [(a*a)_k] = 2 * a_{k-i} if 0 <= k-i < n, else 0.

But wait, if k-i = i (i.e., k = 2i), then both terms are a_i, so the derivative is 2 * a_i. Which is consistent with the formula 2 * a_{k-i} = 2 * a_i.

So the gradient of (a*a)_k with respect to a is: 2 * a flipped and shifted by k. Specifically, grad_k[i] = 2 * a[k-i] if 0 <= k-i < n.

For the max function, the subgradient at the maximizer k* is:
grad[i] = 2 * a[k*-i] if 0 <= k*-i < n, else 0.

This is just a flipped and shifted version of a! So the subgradient has the same "shape" as a, just reflected and shifted.

This means the subgradient descent step would be:
a_i -= step * 2 * a[k*-i] (for valid k*-i)
