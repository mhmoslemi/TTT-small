One key improvement: instead of a fixed grid + golden section, I can use a more efficient 1D optimizer. The function $f(\delta)$ is continuous and piecewise smooth. The breakpoints occur where two of the linear pieces of $L(\delta)$ cross. Between breakpoints, $f(\delta)$ is a ratio of a linear (or quadratic) function to a quadratic function, which has at most one critical point.

But finding all breakpoints is $O(n^2)$ in the worst case, which is too expensive per coordinate. The grid + golden section approach is $O(n \cdot G + n \cdot 22) = O(n \cdot 70)$ per coordinate, which is fine.

Let me estimate the total time for CD:
- Per coordinate: ~70 evaluations of the max over a window of $n$ elements
- Each max evaluation: O(n) in numpy, ~1-2 μs for n=3072
- Per coordinate: ~70 × 2μs = 140 μs
- Per sweep: 3072 × 140 μs ≈ 430 ms
- In 1000 seconds: ~2300 sweeps

That should be more than enough for convergence. The question is whether the optimization landscape is well-behaved.

Let me also think about the "kick" strategy. When CD stagnates, we can:
1. Add random perturbations to the sequence
2. Do a "water-filling" step: equalize the top few lag values
3. Randomly swap a pair of coordinates
4. Set some coordinates to 0 and redistribute their mass

I think the most effective kick is a small random multiplicative perturbation: $a_i \to a_i \cdot \exp(\epsilon_i)$ where $\epsilon_i \sim N(0, \sigma^2)$ for small $\sigma$. This is what the previous code does.

Let me now write the complete program.

Actually, let me reconsider the problem from a high level. The score is:
$J = 2n \cdot \max_k (a*a)_k / (\sum a)^2$

Since the score is scale-invariant, I can normalize $\sum a = 1$ and minimize $2n \cdot \max_k (a*a)_k$.

The key insight is that the max of the convolution is determined by a few "hot" lags. At the optimum, multiple lags should be near the maximum (otherwise we could redistribute mass to reduce the peak). This is similar to Chebyshev approximation or minimax optimization.

A good approach would be:
1. Identify the "active" lags (those near the max)
2. Use the KKT conditions to determine the optimal values

The KKT conditions for the problem:
$\min_a \max_k z_k$ subject to $a_i \geq 0$, $\sum a_i = 1$

At the optimum, there exist Lagrange multipliers $\lambda_k \geq 0$ for each $k$ with $\sum_k \lambda_k = 1$ (making it a convex combination), $\mu_i \geq 0$ for each $i$ (non-negativity), and $\nu$ (sum constraint) such that:

$\sum_k \lambda_k \frac{\partial z_k}{\partial a_i} + \mu_i = \nu$ for all $i$

$\mu_i a_i = 0$ for all $i$ (complementary slackness)

$\lambda_k (z_k - M^*) = 0$ for all $k$ (where $M^*$ is the optimal max)

This is a system of equations that's hard to solve directly, but it motivates the LSE approach (where $\lambda_k = w_k \propto \exp(z_k/T)$).

OK, I think the LSE + CD approach is sound. Let me just implement it well.

def _softmax(u):
    m = float(np.max(u))
    e = np.exp(u - m)
    s = float(e.sum())
    if not math.isfinite(s) or s <= 0:
        return np.full(u.shape, 1.0 / u.size)
    return e / s

def _lse_optimize(p, stop_time, consider=None):
    n = p.size
    p = np.maximum(np.asarray(p, dtype=np.float64), 0.0).copy()
    s = float(p.sum())
    if s < 1e-300:
        return p
    p = p / s
    u = np.log(np.maximum(p, 1e-30))
    u -= float(u.mean())
    
    conv_size = next_fast_len(2 * n - 1)
    conv_len = 2 * n - 1
    cross_size = next_fast_len(3 * n - 2)
    cross_len = 3 * n - 2
    
    def cfast(a):
        F = rfft(a, conv_size)
        c = irfft(F * F, conv_size)[:conv_len]
        return c
    
    def lse_func(uu, T):
        pp = _softmax(uu)
        c = cfast(pp)
        cmax = float(c.max())
        if not math.isfinite(cmax) or cmax <= 0:
            return 1e100, np.zeros_like(uu)
        T_eff = max(1e-300, T)
        scaled = (c - cmax) / T_eff
        exps = np.exp(scaled)
        sum_exp = float(exps.sum())
        if not math.isfinite(sum_exp) or sum_exp <= 0:
            w = np.zeros(c.size)
            w[int(np.argmax(c))] = 1.0
        else:
            w = exps / sum_exp
        
        # Cross-correlation: sum_m a_m w_{m+i}
        F = rfft(pp[::-1], cross_size)
        G = rfft(w, cross_size)
        cross = irfft(F * G, cross_size)[:cross_len]
        term1 = cross[n-1:2*n-1]
        
        # Windowed sum of w
        cumw = np.concatenate([[0.0], np.cumsum(w)])
        lo = np.arange(n, dtype=np.int64)
        hi = np.minimum(lo + n, 2*n - 1)
        term2 = pp * (cumw[hi] - cumw[lo])
        
        gdp = term1 + term2
        tdp = float(np.dot(pp, gdp))
        grad = pp * (gdp - tdp)
        grad = np.where(np.isfinite(grad), grad, 0.0)
        
        f = cmax + T_eff * float(np.log(sum_exp / c.size))
        return f, grad
    
    # Multi-stage temperature schedule
    c_init = cfast(p)
    cmax_init = float(c_init.max()) if c_init.size else 1.0
    
    best_p = p.copy()
    best_sc = _score_arr(p)
    
    T_stages = [0.1, 0.03, 0.01, 0.003, 0.001]
    
    start = time.monotonic()
    for T_frac in T_stages:
        now = time.monotonic()
        if now > stop_time - 5.0:
            break
        T = T_frac * cmax_init
        maxit = 60
        opts = {"maxiter": maxit, "gtol": 1e-13, "ftol": 1e-15, "maxls": 20, "maxdisp": 0}
        try:
            res = minimize(lse_func, u, args=(T,), method="L-BFGS-B", jac=True, options=opts)
            if res.x is not None and res.x.size == n and np.all(np.isfinite(res.x)):
                p_new = _softmax(res.x)
                p_new = np.maximum(p_new, 0.0)
                sc = _score_arr(p_new)
                if math.isfinite(sc) and sc < best_sc:
                    best_sc = sc
                    best_p = p_new.copy()
                    p = p_new
                    u = np.log(np.maximum(p, 1e-30))
                    u -= float(u.mean())
        except Exception:
            pass
        
        if consider:
            try:
                consider(best_p)
            except Exception:
                pass
    
    return best_p
