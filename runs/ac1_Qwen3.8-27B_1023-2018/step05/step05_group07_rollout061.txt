Actually, the LP dual is:
min M * sum(z) + 0 * w
s.t. A^T * z + w >= 0 (i.e., (A^T z)_j + w_j >= 0 for all j)

Since w_j >= 0 and (A^T z)_j can be negative, the constraint is w_j >= -(A^T z)_j, i.e., w_j >= max(0, -(A^T z)_j).

The dual objective is M * sum(z). At the optimum, by strong duality, this equals the primal objective sum(b*).

grad_j = sum_k z_k * A[k,j] = sum_k z_k * a[k-j] (when 0 <= k-j < n)

This is like a "weighted" autocorrelation gradient, where the weights are the dual variables.
