def _subgradient_step(x, eta):
    """Take one subgradient step to reduce max convolution."""
    n = len(x)
    c = np.convolve(x, x)
    M = c.max()
    active = np.where(c >= M * (1 - 1e-10))[0]
    
    # Compute subgradient
    g = np.zeros(n)
    for k in active:
        k = int(k)
        for i in range(n):
            di = k - i
            if 0 <= di < n:
                g[i] += x[di]
    g /= len(active)
    g *= 2.0
    
    # Zero-mean to maintain normalization
    g -= g.mean()
    
    # Step
    x_new = x - eta * g
    x_new = np.maximum(x_new, 0)
    s = x_new.sum()
    if s < 1e-15:
        return x, M
    x_new /= s
    return x_new, M

$\nabla F_\tau(x)_i = 2n \sum_k p_k \cdot \frac{\partial c_k}{\partial x_i}$

where $p_k = e^{c_k/\tau} / \sum_j e^{c_j/\tau}$.

And $\frac{\partial c_k}{\partial x_i} = 2x_{k-i}$ (if valid).

So $\nabla F_\tau(x)_i = 4n \sum_k p_k x_{k-i} \cdot \mathbf{1}[0 \leq k-i < n]$.

This is $O(n \cdot 2n) = O(n^2)$ per gradient evaluation, which is fine.

We can use `scipy.optimize.minimize` with L-BFGS-B, providing this gradient. The constraint is $x_i \geq 0$ and $\sum x_i = 1$ (handled by re-normalization after each step, or by adding the constraint explicitly).

Actually, L-BFGS-B handles box constraints $x_i \geq 0$ natively. The equality constraint $\sum x_i = 1$ is trickier. We can handle it by:
1. Optimizing on the simplex (using a parameterization that automatically satisfies the constraint).
2. Or re-normalizing after each step (which works but breaks the gradient).
3. Or using SLSQP which handles equality constraints.

For simplicity, let me use the re-normalization approach: after each L-BFGS step, clip to [0, ∞) and re-normalize. This is not exactly correct but works well in practice.

Alternatively, I can optimize on the "log" scale: let $x_i = e^{y_i} / \sum_j e^{y_j}$ (softmax parameterization). Then the constraint is automatically satisfied, and I optimize over $y \in \mathbb{R}^n$.

The gradient with respect to $y$ is:
$\frac{\partial F}{\partial y_i} = \sum_j \frac{\partial F}{\partial x_j} \frac{\partial x_j}{\partial y_i}$

$\frac{\partial x_j}{\partial y_i} = x_j (\delta_{ji} - x_i)$

So $\frac{\partial F}{\partial y_i} = \sum_j \frac{\partial F}{\partial x_j} x_j (\delta_{ji} - x_i) = x_i \frac{\partial F}{\partial x_i} - x_i \sum_j x_j \frac{\partial F}{\partial x_j}$

This is the "centered" gradient (zero-mean weighted by $x$).

This is elegant but adds complexity. Let me just use the simpler re-normalization approach for now.
