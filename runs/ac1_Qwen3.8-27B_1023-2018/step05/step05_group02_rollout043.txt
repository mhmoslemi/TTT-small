def lp_step(a, M, n_active=100):
    n = len(a)
    c = np.convolve(a, a)
    # Find active lags
    active = np.argsort(c)[-n_active:]
    # Build constraint matrix: T[k, i] = a[i] if 0 <= k-i <= n-1 else 0
    # T is (n_active x n)
    T = np.zeros((n_active, n))
    for idx, k in enumerate(active):
        i_start = max(0, k - n + 1)
        i_end = min(n - 1, k)
        T[idx, i_start:i_end+1] = a[i_start:i_end+1]
    # Solve: max sum(b) s.t. T @ b <= M, b >= 0
    # Or equivalently: min -sum(b) s.t. T @ b <= M, b >= 0
    from scipy.optimize import linprog
    c_obj = -np.ones(n)
    A_ub = T
    b_ub = np.full(n_active, M)
    bounds = [(0, None)] * n
    res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success:
        b = res.x
        b_sum = b.sum()
        if b_sum > 0:
            b = b / b_sum * a.sum()  # Rescale to match sum
        return b
    return a

When we change $p[i]$ from $v$ to $x$ (delta $= x - v$):
- $c[k]$ for $k$ in $[i, \min(i+n-1, L-1)]$ changes by $\delta \cdot 2 \cdot p[k-i]$ (using the OLD value of $p$)

- Old: $c[2i]$ includes the term $p[i] \cdot p[i] = v^2$
- New: $c[2i]$ includes the term $p[i] \cdot p[i] = x^2$
- Change: $x^2 - v^2 = (v+\delta)^2 - v^2 = 2v\delta + \delta^2$ ✓

And for $k \neq 2i$ (but $k-i$ valid):
- Old: $c[k]$ includes $p[i] \cdot p[k-i] = v \cdot p[k-i]$ AND $p[k-i] \cdot p[i] = p[k-i] \cdot v$ (two separate terms in the sum)

  $c[k] = \sum_j p[j] p[k-j]$
  The term $j = i$ gives $p[i] p[k-i] = v \cdot p[k-i]$
  The term $j = k-i$ gives $p[k-i] p[i] = p[k-i] \cdot v$
  These are the same product, but they're separate terms in the sum (unless $i = k-i$, i.e., $k = 2i$).
  
  So for $k \neq 2i$: both terms are present, total contribution is $2v \cdot p[k-i]$.
  After change: $2x \cdot p[k-i] = 2(v+\delta) p[k-i]$.
  Change: $2\delta \cdot p[k-i]$. ✓

For $k = 2i$: only one term ($j = i = k-i$), contribution is $v^2$, changes to $x^2$.
Change: $x^2 - v^2 = 2v\delta + \delta^2$. ✓

Great, so my formula is correct. The influence vector is:
- For $k$ in $[i, i+Ls-1]$ where $k \neq 2i$: $\Delta c[k] = 2\delta \cdot p[k-i]$
- For $k = 2i$ (if $2i < L$): $\Delta c[2i] = 2\delta \cdot p[i] + \delta^2 = 2\delta \cdot v + \delta^2$

And $p[k-i]$ here is the value BEFORE the update (which is the current value since we're only changing $p[i]$).

So the influence vector is:
```

```
where $j = k - i$ ranges from $0$ to $Ls-1$.

And the quadratic correction is: at position $j = i$ in the influence range (i.e., $k = 2i$), add $\delta^2$.

    K = 200  # Number of active constraints

    # Rescale b to have same sum as a
    b = b * (a_sum / b_sum)

**Multiplicative Weight Update (MWU) for the LP**:

  - Update: $b_i = b_i \cdot \exp(-\eta \sum_k w_k T[k,i])$
