For coordinate descent, the key operation is: for coordinate i, find the optimal value of a[i] given all other a[j] fixed.

The score is 2n * max(b) / S^2.

When we change a[i] from v to v+w:
- New S = S_old + w
- b[k] changes only for k in [i, i+n-1] (the lags affected by coordinate i)
- For k in [i, i+n-1]: b_new[k] = b_old[k] + 2w*a[k-i] + w^2*delta(k, 2i)
  where a[k-i] is the old value (since we're changing a[i], the cross terms are 2*a[i]*a[k-i] → 2*(a[i]+w)*a[k-i] = 2*a[i]*a[k-i] + 2w*a[k-i], and the self-term a[i]^2 → (a[i]+w)^2 = a[i]^2 + 2w*a[i] + w^2)
  
  Wait, let me be more careful. b[k] = sum_j a[j]*a[k-j].
  If we change a[i] to a[i]+w:
  - Terms where j=i: a[i]*a[k-i] → (a[i]+w)*a[k-i] = a[i]*a[k-i] + w*a[k-i]
  - Terms where k-j=i, i.e., j=k-i: a[k-i]*a[i] → a[k-i]*(a[i]+w) = a[k-i]*a[i] + w*a[k-i]
  
  But if i = k-i (i.e., k=2i), these are the same term, so:
  - a[i]*a[i] → (a[i]+w)^2 = a[i]^2 + 2w*a[i] + w^2
  
  So: b_new[k] = b_old[k] + 2*w*a[k-i] for k ≠ 2i, k in [i, i+n-1]
  b_new[2i] = b_old[2i] + 2*w*a[i] + w^2 (if 2i is in [i, i+n-1], which it is since i >= 0)
  
  But wait, for k ≠ 2i: the two terms (j=i and j=k-i) are distinct, so the total change is w*a[k-i] + w*a[k-i] = 2w*a[k-i].
  For k = 2i: the two terms coincide, so the change is 2w*a[i] + w^2.
  
  But a[k-i] when k=2i is a[i], so: 2w*a[i] + w^2. ✓
  And for k≠2i: 2w*a[k-i]. ✓

So the general formula is:
b_new[k] = b_old[k] + 2w*a[k-i] + w^2 * delta(k, 2i) for k in [i, i+n-1]

This is what the previous program uses. Good.
