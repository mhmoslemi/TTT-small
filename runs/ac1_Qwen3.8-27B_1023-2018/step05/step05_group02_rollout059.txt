def coord_descent(a, stop_time, seed):

    a = a / a.sum()
    S = 1.0  # normalized sum
    c = fft_conv(a)

    prefix_max = np.maximum.accumulate(c)
    suffix_max = np.maximum.accumulate(c[::-1])[::-1]

        if time.monotonic() > stop_time - 1.0:
            break
        
        # Update prefix/suffix max
        prefix_max = np.maximum.accumulate(c)
        suffix_max = np.maximum.accumulate(c[::-1])[::-1]
        
        improved = False
        order = rng.permutation(n)
        
        for i in order:
            if time.monotonic() > stop_time - 0.1:
                break
            
            # Affected range: [i, i+n-1]
            start = i
            end = min(i + n, 2*n - 1)
            Ls = end - start

            max_const = 0.0
            if start > 0:
                max_const = max(max_const, prefix_max[start-1])
            if end < 2*n - 1:
                max_const = max(max_const, suffix_max[end])
            
            # Influence vector: 2*a[0:Ls]
            infl = 2.0 * a[:Ls]
            
            # Current value
            v = a[i]
            
            # Search range
            x_lo = 0.0
            x_hi = max(10.0 * v, 0.02 * S, 1e-8)
            x_hi = min(x_hi, 5.0 * S)
            
            # Grid search
            pts = np.linspace(x_lo, x_hi, G+1)
            w = pts - v  # shape (G+1,)
            
            # New convolution values: base + w * infl
            base = c[start:end]  # shape (Ls,)
            new_vals = base[None, :] + w[:, None] * infl[None, :]  # shape (G+1, Ls)
            
            # Quadratic term for k=2i
            quad_pos = 2*i - start
            if 0 <= quad_pos < Ls:
                new_vals[:, quad_pos] += w**2
            
            new_maxes = np.maximum(new_vals.max(axis=1), max_const)
            
            # Score
            new_S = S + w
            valid = new_S > 1e-10
            scores_arr = np.full(G+1, np.inf)
            scores_arr[valid] = 2.0*n*new_maxes[valid] / (new_S[valid]**2)
            
            imin = np.argmin(scores_arr)
            best_x = pts[imin]
            best_sc = scores_arr[imin]

                a[i] = best_x

                if 0 <= 2*i < 2*n-1:
                    c[2*i] += (best_x - v)**2

            a /= S
            c /= S*S
            S = 1.0

Wait, there's an issue. The `c[start:end] += (best_x - v) * infl` update needs to be done incrementally. But `infl = 2.0 * a[:Ls]` uses the CURRENT a, which changes as we update coordinates within the same sweep. This is actually correct for a "synchronous" vs "asynchronous" update - in asynchronous (Gauss-Seidel) style, we use the latest values.

But there's a subtlety: when we update a[i], the influence vector for subsequent coordinates changes. Specifically, if we later update coordinate j, the influence vector for j includes a[i] (the updated value). Since we're computing infl = 2.0 * a[:Ls] each time (with the current a), this is correct.

However, the convolution update `c[start:end] += (best_x - v) * infl` assumes that the change in conv is (delta) * infl, where infl = 2*a. But if a changes during the sweep, the actual change in conv is more complex. Let me reconsider.

When we change a[i] from v to x:
- conv[k] changes by (x-v) * (a_old[k-i] + a_old[i]) for k != 2i (in the affected range)
- conv[2i] changes by (x-v)*(a_old[i] + a_old[i]) + (x-v)^2 = 2*(x-v)*a_old[i] + (x-v)^2

Wait, but a_old here should be the value of a at the time of the update (after previous coordinates in the sweep have been updated). Since we're doing Gauss-Seidel (updating in place), the influence vector 2*a (at the current state) is correct.

Actually no. The change in conv[k] when a[i] changes by delta is:
- For j=i term: delta * a[k-i] (current value of a[k-i])
- For k-j=i term (j=k-i): a[k-i] * delta (current value of a[k-i])
- If k=2i: the term a[i]*a[i] changes by 2*a[i]*delta + delta^2

So the linear part is delta * (a[k-i] + a[k-i]) = 2*delta*a[k-i] for k != 2i, and for k=2i it's 2*delta*a[i] + delta^2.

The influence vector is 2*a[:Ls] where a is the CURRENT state (after previous updates in the sweep). This is correct for Gauss-Seidel.

So the update is:
```
c[start:end] += delta * (2 * a[0:Ls])  # linear part
c[2*i] += delta^2  # quadratic correction (only if 2i is in range)
```

And the scoring uses the base + delta*infl + delta^2 (at quad position). This is what I had above. Good.

import numpy as np
import time
import math
from scipy.fft import rfft, irfft, next_fast_len
from scipy.optimize import minimize


def propose_candidate(seed=42, budget_s=1300, **kwargs):
    t0 = time.monotonic()
    budget = max(10.0, float(budget_s))
    hard_dl = t0 + budget - 25.0

    # --- Parent ---
    try:
        parent = np.asarray(globals()["height_sequence_1"], dtype=np.float64).ravel()

    n = parent.size

    csize = next_fast_len(cl)
    M_fft = next_fast_len(3 * n - 2)

    def fconv(a):
        F = rfft(a, csize)
        c = irfft(F * F, csize)[:cl]
        np.maximum(c, 0.0, out=c)
        return c

        s = a.sum()
        if s < 0.01:
            return math.inf
        c = fconv(a)
        return 2.0 * n * c.max() / (s * s)

    a = parent / parent.sum()
    best_a = a.copy()
    best_sc = sc(a)

    def update(a_new):
        nonlocal best_a, best_sc
        try:
            x = np.asarray(a_new, dtype=np.float64).ravel()
        except Exception:
            return
        if x.size != n:
            return
        x = np.where(np.isfinite(x), x, 0.0)
        x = np.clip(x, 0.0, 1000.0)
        s = x.sum()
        if s < 0.01:

        m = u.max()
        e = np.exp(u - m)
        s = e.sum()
        return e / s if s > 0 else np.full_like(u, 1.0 / n)

        shifted = np.clip(shifted, -400.0, 400.0)
