        #   In both cases it's a_{k-j} + a_j (since when j=k-j, this is 2*a_j)
        #   Valid when 0 <= k-j < n
        # So dc_k/da_j = (a_{k-j} + a_j) * [0 <= k-j < n]
        
        # But computing this for all j, k is O(n²). For n=3072, that's ~9.4M per gradient evaluation.
        # Let me use the FFT trick: the gradient is a cross-correlation.
        # sum_k w_k * (a_{k-j} + a_j) = (w * a)_j + a_j * sum(w_k) [for valid k]
        # Wait: sum_k w_k * a_{k-j} is the cross-correlation of w and a at lag j
        # sum_k w_k * a_j = a_j * sum_k w_k
        
        # Actually: dc_k/da_j = a_{k-j} + a_j for 0<=k-j<n
        # sum_k w_k * dc_k/da_j = sum_{k: 0<=k-j<n, 0<=k<conv_len} w_k * (a_{k-j} + a_j)
        # = sum_{k: 0<=k-j<n} w_k * a_{k-j} + a_j * sum_{k: 0<=k-j<n} w_k
        # = (w cross-correlate a) at lag j + a_j * (sum of w over valid k range)
        
        # The cross-correlation: sum_{k=0}^{conv_len-1} w_k * a_{k-j} where 0<=k-j<n
        # Let m = k-j, so m ranges from max(0, j-...) to min(n-1, ...)
        # Actually k ranges from j to j+n-1 (so that 0<=k-j<n), and also 0<=k<conv_len=2n-1
        # So k ranges from max(0,j) to min(j+n-1, 2n-2)
        # And m = k-j ranges from max(0,j)-j to min(j+n-1,2n-2)-j
        # = max(-j, 0) to min(n-1, 2n-2-j)
        # Since j is in [0, n-1]: max(-j,0) = 0, min(n-1, 2n-2-j) = n-1 (since 2n-2-j >= n-1 when j<=n-1)
        # So m ranges from 0 to n-1, i.e., we sum w_{j+m} * a_m for m=0..n-1
        # This is the correlation of w (shifted) with a.
        
        # Alternatively, I can compute it as:
        # grad_a[j] = sum_m a_m * w_{j+m} + a_j * sum_m w_{j+m}
        # where m=0..n-1 and j+m is a valid index in [0, 2n-2]

        # This is like a cross-correlation. I can compute it with FFT.
        # Let's define v = w (length 2n-1) and a (length n)
        # (a cross-corr w)[j] = sum_m a_m * w_{j+m}
        # This is the same as convolve(a, w)[2n-2-j] ... let me think.
        # convolve(a, w)[k] = sum_m a_m * w[k-m]
        # I want sum_m a_m * w[j+m] = sum_m a_m * w[j+m]
        # Let l = j+m, m = l-j: sum_{l=j}^{j+n-1} a_{l-j} * w[l]
        # = (a * w)[j+n-1] in the "flip a" convention
        # Actually: np.correlate(w, a, mode='full')[j + n - 1] ... this is getting complicated.
        
        # Let me just use a direct approach with the FFT:
        # Compute correlation(r)[j] = sum_{m=0}^{n-1} a[m] * w[j+m] for j=0..n-1
        # This is like: take w, and for each j, multiply a[m] by w[j+m] and sum
        # In terms of convolution: if I flip a, then (flip(a) * w)[n-1+j] = sum_m flip(a)[m] * w[n-1+j-m] = sum_m a[n-1-m] * w[j+1-m]
        # Hmm, this is getting confusing. Let me just do it directly.
        
        # For n=3072, the direct computation is:
        # For each j in 0..n-1: grad[j] = sum_{m=0}^{n-1} a[m] * (w[j+m] if j+m < 2n-1 else 0) + a[j] * sum_{m=0}^{n-1} (w[j+m] if j+m < 2n-1 else 0)
        # 
        # The first term is a matrix-vector product where the matrix M[j,m] = w[j+m] (truncated).
        # This matrix is a Hankel matrix. I can compute M*a using FFT by padding.
        #
        # Actually, let me think of it differently.
        # sum_m a[m] * w[j+m] = sum_m a[m] * w[j+m]
        # If I define b[k] = w[k] for k=0..2n-2 and 0 otherwise, then this is (a * b)_reversed... 
        # 
        # OK let me just use a simpler approach: compute the gradient using the fact that
        # the LSE objective is f(a) = log(sum_k exp((c_k - cmax)/T)) * T + cmax
        # and c = a * a (autocorrelation).
        # 
        # df/da_j = (1/T) * sum_k exp((c_k-cmax)/T) * dc_k/da_j / sum_k exp((c_k-cmax)/T)
        # = sum_k w_k * dc_k/da_j where w_k = exp((c_k-cmax)/T) / sum(exp(...))
        #
        # dc_k/da_j = a[k-j] + a[j] for 0<=k-j<n (and k-j >= 0, so k >= j)
        #            = a[k-j] + a[j] for 0<=j-k<n (and j >= k, but this is the same condition)
        # Wait, let me redo. c_k = sum_i a_i * a_{k-i} where 0<=i<n and 0<=k-i<n.
        # dc_k/da_j: j appears when i=j (need 0<=k-j<n) giving a_{k-j}, and when k-i=j i.e. i=k-j (need 0<=k-j<n) giving a_j.
        # So dc_k/da_j = a_{k-j} + a_j if 0<=k-j<n, else 0.
        # When j=k-j (k=2j): it's just one occurrence of a_j in the product a_j*a_j, so dc_k/da_j = 2*a_j.
        # But the formula a_{k-j} + a_j = a_j + a_j = 2*a_j, so it's consistent.
        
        # So: df/da_j = sum_{k=j}^{j+n-1} w_k * (a_{k-j} + a_j)
        #              = sum_{m=0}^{n-1} w_{j+m} * a_m + a_j * sum_{m=0}^{n-1} w_{j+m}
        # where w_k = 0 for k outside [0, 2n-2].
        
        # Let me define:
        # corr[j] = sum_{m=0}^{n-1} a[m] * w[j+m]  (this is a cross-correlation)
        # wsum[j] = sum_{m=0}^{n-1} w[j+m]  (this is a moving sum of w)
        # Then df/da_j = corr[j] + a[j] * wsum[j]
        
        # Computing corr: This is like a convolution. 
        # corr[j] = sum_m a[m] * w[j+m]
        # If I define a_flipped[m] = a[n-1-m], then:
        # corr[j] = sum_m a[n-1-m] * w[j+m] = (a_flipped * w)[j + n - 1] (linear convolution)
        # Because (a_flipped * w)[k] = sum_m a_flipped[m] * w[k-m] = sum_m a[n-1-m] * w[k-m]

        # For k = j+n-1: = sum_l a[l] * w[j+l]

        # Computing wsum:
        # wsum[j] = sum_{m=0}^{n-1} w[j+m]
        # This is a moving sum (sliding window) of w. I can compute it with cumsum.
        # wsum[j] = cumsum_w[j+n] - cumsum_w[j] (with cumsum_w[0]=0, cumsum_w[k]=w[0]+...+w[k-1])
        
        a_flipped = a[::-1]
        F_af = rfft(a_flipped, conv_size)
        F_w = rfft(w, conv_size)
        corr_full = irfft(F_af * F_w, conv_size)[:2*n-1]
        corr = corr_full[n-1:2*n-1]
        
        cumsum_w = np.zeros(2*n)
        np.cumsum(w, out=cumsum_w[1:])
        wsum = cumsum_w[n:2*n] - cumsum_w[:n]
        
        grad_a = corr + a * wsum
        grad_a /= T
        
        # Now convert to gradient w.r.t. u (log parameters)
        # a = softmax(u), so da_j/du_k = a_j * (delta_jk - a_k)
        # df/du_k = sum_j df/da_j * da_j/du_k = sum_j df/da_j * a_j * (delta_jk - a_k)
        #          = grad_a[k] * a[k] - a[k] * sum_j grad_a[j] * a[j]
        #          = a[k] * (grad_a[k] - dot(a, grad_a))
        
        t = float(np.dot(a, grad_a))
        grad_u = a * (grad_a - t)
        grad_u = np.where(np.isfinite(grad_u), grad_u, 0.0)
        
        return float(f), grad_u
