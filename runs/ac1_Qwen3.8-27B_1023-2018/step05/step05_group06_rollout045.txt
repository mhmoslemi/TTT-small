For the analytic solution, let me consider the case where a specific position k* in the window is the argmax:
f_k*(w) = 2n * (base[k*] + w*infl[k*] + w²*δ) / (S+w)²

where δ = 1 if k* == i (the diagonal), 0 otherwise.

The derivative:
f'_k*(w) = 2n * [S*infl[k*] + w*(2S*δ - infl[k*]) - 2*base[k*]] / (S+w)³

Setting to 0:
w* = (2*base[k*] - S*infl[k*]) / (2S*δ - infl[k*])

For δ=0: w* = (2*base[k*] - S*infl[k*]) / (-infl[k*]) = S*(infl[k*] - 2*base[k*]/S) / infl[k*]... 

Let me just compute it numerically. For each candidate position k* (top few by current c value), compute w*, check validity, and evaluate.

The validity conditions for k* being the argmax at w:
1. base[k*] + w*infl[k*] + w²*δ ≥ base[k] + w*infl[k] + w²*δ_k for all k
2. base[k*] + w*infl[k*] + w²*δ ≥ max_const
3. w ≥ -v
4. S + w > 0

Condition 2 gives: base[k*] + w*infl[k*] + w²*δ ≥ max_const
If δ=0: this is linear in w: w ≥ (max_const - base[k*]) / infl[k*] (if infl[k*] > 0)
If δ=1: this is quadratic: w² * 1 + w*infl[k*] + (base[k*] - max_const) ≥ 0

Condition 1 is harder to check. But in practice, the top few c values dominate, so checking the top 5-10 should suffice.

    # And try the boundaries
    candidates.append(max(w_lo, 0.0))  # don't change
    candidates.append(0.0)
    
    # Also try a few heuristic values
    # ...

    best_w = 0.0
