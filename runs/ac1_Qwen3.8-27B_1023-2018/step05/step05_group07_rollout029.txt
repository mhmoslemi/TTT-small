                      bounds=[(0, None)]*n, method='highs',

                               'primal_feasibility_tolerance': 1e-12})
        if res.status == 0 and res.x is not None:

  pac[i] = sum_{j=0}^{n-1} p[i+j] * a[j] (p[i+j] is valid for i+j <= 2n-2, i.e., j <= 2n-2-i, which is always true since j <= n-1 and 2n-2-i >= n-1 when i <= n-1)

So pac[i] = dot(p[i:i+n], a) for i in [0, n-1].

I can vectorize this as a matrix product:
Let B be the (n x n) matrix where B[i,j] = p[i+j]. Then pac = B @ a.

B[i,j] = p[i+j] for i in [0,n-1], j in [0,n-1].
This is a Hankel matrix! I can construct it:
B = p[0:2n-1] reshaped... actually:
B[i,j] = p[i+j]. The columns of B are:
B[:,0] = p[0:n]
B[:,1] = p[1:n+1]
...
B[:,n-1] = p[n-1:2n-1]

So B is a matrix where column j is p[j:j+n]. I can construct it as:
B = np.array([p[j:j+n] for j in range(n)]).T

Or more efficiently:
idx = np.arange(n)[:,None] + np.arange(n)[None,:]  # shape (n,n), B[i,j] = p[idx[i,j]]
B = p[idx]

For n=281, this is a 281x281 matrix, about 63K entries. Fine.

Then pac = B @ a.

        grad = (4.0 * n / (s*s)) * pac - (2.0 * n * lse / (s**3))

        # d(x/s)/dx_i = (s*delta_i - x_i)/s^2
        # So the true gradient of f(x/s) w.r.t. x is:
        # grad_true_i = sum_j grad_norm_j * d(x_j/s)/dx_i
        # = (grad_norm_i * s - sum_j grad_norm_j * x_j) / s^2
        # where grad_norm is the gradient w.r.t. the normalized variable
        # Actually this gets complicated. Let me just project.
        return score, np.maximum(grad, 0)  # crude projection
    
    # Actually, let me use a simpler approach: optimize in the "simplex" directly
    # Minimize f(x) = 2n * soft_max(conv(x,x)) / (sum x)^2 subject to x >= 0, sum x = 1
    
    def obj_simplex(x):
        # x is already on the simplex (sum=1, x>=0)
        c = np.convolve(x, x)
        bm = c.max()
        bc = beta * (c - bm)
        exp_bc = np.exp(bc)
        total = exp_bc.sum()
        lse = bm + np.log(total) / beta
        return 2.0 * n * lse
    
    # Use a parameterization: x = exp(y) / sum(exp(y))
    y0 = np.log(np.maximum(a0, 1e-10))
    
    def obj_y(y):
        x = np.exp(y - y.max())
        x /= x.sum()
        return obj_simplex(x)
    
    def obj_and_grad_y(y):
        x = np.exp(y - y.max())
        x /= x.sum()
        c = np.convolve(x, x)
        bm = c.max()
        bc = beta * (c - bm)
        exp_bc = np.exp(bc)
        total = exp_bc.sum()
        p = exp_bc / total
        lse = bm + np.log(total) / beta
        
        idx = np.arange(n)[:,None] + np.arange(n)[None,:]
        pac = p[idx] @ x
        
        # d(obj_simplex)/dx_i = 2n * dpac stuff
        # obj_simplex = 2n * lse where lse depends on x
        # d(lse)/dx_i = sum_k p_k * dc_k/dx_i = 2 * sum_k p_k * x[k-i] = 2*pac[i]
        dx_grad = 2.0 * n * 2.0 * pac  # d(obj_simplex)/dx_i
        
        # Chain rule for x(y) = softmax(y):
        # dx_i/dy_j = x_i*(delta_ij - x_j)
        # d(obj)/dy_j = sum_i dx_grad_i * x_i*(delta_ij - x_j)
        # = x_j * (dx_grad_j - sum_i dx_grad_i * x_i)
        sum_dgx = np.dot(dx_grad, x)
        dy_grad = x * (dx_grad - sum_dgx)
        
        return obj_simplex(x), dy_grad
    
    best_val = obj_simplex(a0)
    best_y = y0.copy()
    
    for attempt in range(5):
        if time.monotonic() > deadline:
            break
        try:
            res = minimize(obj_and_grad_y, y0 if attempt == 0 else best_y,
                          method='L-BFGS-B', options={'maxiter': 200, 'maxfun': 500})
            if res.fun < best_val:
                best_val = res.fun
                best_y = res.x.copy()
                y0 = res.x.copy()
        except Exception:
            break
    
    x_best = np.exp(best_y - best_y.max())
    x_best /= x_best.sum()
    x_best = np.maximum(x_best, 0)
    return x_best

score = 2n * max(c) / S^2 where c = conv(a,a), S = sum(a).

If S = 1: score = 2n * max(c).
So minimizing score is equivalent to minimizing max(c) subject to S=1, a>=0.

This is: min t s.t. c_k <= t for all k, sum(a)=1, a>=0.

The constraint c_k = sum_j a_j a_{k-j} <= t is a quadratic inequality. This is a QCQP with non-convex constraints (since the quadratic forms are not necessarily PSD).

However, there's a useful observation: if we define the "energy" E = sum_k c_k = S^2 = 1 (for S=1), then the "average" of c_k is 1/(2n-1). We want to minimize the maximum, which means making c as flat as possible.

The constraint sum_k c_k = 1 (which is automatically satisfied when S=1) means we can't make all c_k equal to their average AND have a feasible non-negative solution. The structure of c_k = sum_j a_j a_{k-j} imposes specific relationships.

4. **The "stuck" detection**: If the iteration doesn't improve for 30 consecutive steps, we perturb. This should prevent getting stuck in bad local optima.

5. **Length change**: Interpolating the parent to a different length and re-optimizing might find a better solution. The parent was presumably optimized at length 281, but a nearby length might have a slightly better score.

Let me also add one more idea: **try the "dual" LP**. The dual of:
max c'g s.t. A g <= M*1, g >= 0
is:
min M * sum(y) s.t. A'y >= c, y >= 0

The dual variables y_k correspond to the lags. At the optimum, y_k > 0 only for binding constraints (active lags). This gives us information about which lags are "important."

If all y_k are equal, the convolution is "flat" (all lags equally constrained). If some y_k are zero, those lags have slack (c_k < M).

I can use the dual solution to guide the optimization: focus on reducing the lags with large y_k.

But for now, let me keep it simple and just use the primal LP solution.

One more thought: **what about using the `cvt` or `convex` approach?** The problem min max(c_k) s.t. sum(a)=1, a>=0 is equivalent to:
min t s.t. a^T Q_k a <= t * (sum a)^2 for all k, sum a = 1, a >= 0

Wait, with sum(a)=1, it's just:
min t s.t. a^T Q_k a <= t for all k, sum a = 1, a >= 0

where (a^T Q_k a) = c_k = sum_j a_j a_{k-j}.

The matrix Q_k has Q_k[i,j] = 1 if i+j=k, else 0. This is a symmetric matrix but NOT positive semidefinite (it has both positive and negative eigenvalues for most k).

So this is a non-convex QCQP. We can't easily solve it with standard convex solvers.

However, we can use a **semidefinite relaxation**:
min t s.t. Tr(Q_k X) <= t for all k, sum_i X[i,i] = 1 (or sum_i sum_j X[i,j] = 1), X >= 0

where X = a a^T. This is an SDP! The relaxation is exact if the optimal X is rank-1.

For n=281, the SDP would be a 281x281 matrix variable with 561 linear constraints plus an PSD constraint. This is a large SDP (281*282/2 ≈ 39K variables). It might be solvable with MOSEK or SDPT3, but it's risky in terms of time.

Let me not pursue this and stick with the LP best-response method.

def _conv_mat(n, a):

    for k in range(2*n-1):
        jlo = max(0, k - n + 1)
        jhi = min(n, k + 1)

def _ls(a, g):
    """Line search: minimize max(conv)/sum^2 along (1-t)a + t*g."""
    n = a.size
    asq = a.sum()

    for t in np.linspace(0.02, 1.0, 15):

        s = c.sum()
        if s < 1e-12:

        if v < best_v:

    lo, hi = max(0.0, best_t - 0.05), min(1.0, best_t + 0.05)

        else:

def _smooth_polish(a0, deadline, beta=80.0):
    """Polish using smooth (soft-max) surrogate with L-BFGS-B in log-param space."""
    from scipy.optimize import minimize
    n = a0.size
    a = np.maximum(np.asarray(a0, dtype=np.float64), 1e-15).copy()
    a /= a.sum()
    y0 = np.log(a)

    def obj_grad(y):
        x = np.exp(y - y.max())
        x /= x.sum()
        c = np.convolve(x, x)
        bm = c.max()
        bc = beta * (c - bm)
        eb = np.exp(bc)
        total = eb.sum()
        p = eb / total
        lse = (bm + np.log(total)) / beta

        # pac[i] = sum_k p[k]*x[k-i] = row i of Hankel(p) dot x
        idx = np.arange(n)[:, None] + np.arange(n)[None, :]
        pac = p[idx] @ x

        obj = 2.0 * n * lse
        # d(obj)/dx_i = 4n * pac[i]
        # dx_i/dy_j = x_i*(delta_ij - x_j)
        # d(obj)/dy_j = x_j * (4n*pac_j - sum_i 4n*pac_i * x_i)
        s_pac = float(np.dot(pac, x))
        gy = x * 4.0 * n * (pac - s_pac)
        return obj, gy

    best_val = 2.0 * n * float(np.convolve(a, a).max())
    best_y = y0.copy()

    for attempt in range(8):
        if time.monotonic() > deadline:
            break
        try:
            res = minimize(obj_grad, y0 if attempt == 0 else best_y,
                           method='L-BFGS-B',
                           options={'maxiter': 300, 'maxfun': 800,
                                    'gtol': 1e-10})
            x_chk = np.exp(res.x - res.x.max())
            x_chk /= x_chk.sum()
            chk = float(np.convolve(x_chk, x_chk).max())
            if 2.0 * n * chk < best_val:
                best_val = 2.0 * n * chk
                best_y = res.x.copy()
                y0 = res.x.copy()
        except Exception:
            if attempt > 2:
                break

    if best_y is not None:
        x_best = np.exp(best_y - best_y.max())
        x_best = np.maximum(x_best, 0)
        x_best /= x_best.sum()
        return x_best
    return a0
