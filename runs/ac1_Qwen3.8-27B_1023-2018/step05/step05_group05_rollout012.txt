The LSE approach from the previous program minimizes:

This is a smooth upper bound on c_max = max(c). As T → 0, LSE → c_max.

The gradient of LSE_T(c) with respect to a[i] is:

where w[k] = exp((c[k]-c_max)/T) / sum(exp((c[k]-c_max)/T))

And dc[k]/da[i] = a[k-i] + a[k-i] (from both sides of the convolution) = 2*a[k-i] (when k-i is in range), plus a[i] if k=2i (diagonal).

= 2*a[k-i] (if 0 <= k-i < n)

Wait, that's not right either. Let me be very explicit.

c[k] = sum_{j} a[j] * a[k-j] where j ranges over all integers such that 0<=j<n and 0<=k-j<n, i.e., max(0, k-(n-1)) <= j <= min(k, n-1).

∂c[k]/∂a[i] = a[k-i] (if max(0,k-(n-1)) <= i <= min(k,n-1), from the a[j] factor)
              + a[k-i] (if max(0,k-(n-1)) <= k-i <= min(k,n-1), from the a[k-j] factor)

The first term exists iff 0<=i<n and 0<=k-i<n.
The second term exists iff 0<=k-i<n and 0<=i<n.

These are the same condition! So ∂c[k]/∂a[i] = 2*a[k-i] if 0<=k-i<n and 0<=i<n, else 0.

But when k-i = i (i.e., k=2i), both terms give a[i], so the total is 2*a[i] (not 3*a[i]). The two terms are a[k-i] = a[i] and a[k-i] = a[i], summing to 2*a[i].

So: ∂c[k]/∂a[i] = 2*a[k-i] if |k-i| < n, else 0.

And the gradient of the score:
score = 2n*max(c)/S^2

For the LSE approximation:

∂L/∂a[i] = (2n/S^2) * [sum_k w[k]*2*a[k-i]] - (2*2n*LSE_T(c)/S^3)*a[i]

    # We want sum_k w[k]*a[k-i]. Let j = k-i: sum_j w[j+i]*a[j]
    # This is xcorr at lag -i... or equivalently, xcorr[n-i] in circular correlation (for padded case).
    # Actually: xcorr[i] = sum_k a[k]*w[k-i]
    # We want y[i] = sum_k w[k]*a[k-i] = sum_k a[k]*w[k-i] (just renaming) = xcorr[i]!
    
    # Wait: sum_k w[k]*a[k-i]. Let m = k-i. Then k = m+i. sum_m w[m+i]*a[m].
    # And xcorr[i] = sum_k a[k]*w[k-i] = sum_k a[k]*w[k-i].
    # These are the same! sum_m w[m+i]*a[m] = sum_k a[k]*w[k-i] (just rename m to k and use w[m+i] = w[k] with k=m+i... no that doesn't work).
    
    # OK let me be super explicit. We want:
    # y[i] = sum_{k=0}^{2n-2} w[k] * a[k-i]  (where a[j]=0 for j<0 or j>=n)
    
    # The cross-correlation (a ⋆ w)[d] = sum_t a[t] * w[t+d]
    # (a ⋆ w)[d] = sum_t a[t] * w[t+d]

    # = (a ⋆ w)[i]

    # With zero-padding to avoid circular wraparound.

    # grad_a[i] = 2 * xcorr[i] where xcorr = ifft(fft(a, L) * conj(fft(w, L)))

    def compute_gradient(p_cur, w_cur, c_max, T):
        """Compute gradient of 2n*LSE(c)/S^2 w.r.t. p_cur."""
        L = cross_size
        F_a = rfft(np.append(p_cur, 0.0), L)  # length n, padded
        F_w = rfft(np.append(w_cur, 0.0), L)  # length 2n-1, padded
        xcorr = irfft(F_a * np.conj(F_w), L)[:n]
        # xcorr[i] = sum_t a[t]*w[t+i] = sum_k w[k]*a[k-i] (for our purposes)
        
        # Actually wait, I need to double-check the FFT cross-correlation formula.
        # ifft(fft(a) * conj(fft(b))) gives the circular cross-correlation:
        # xcorr[d] = sum_t a[t+d] * b[t] (with circular indexing)
        # OR xcorr[d] = sum_t a[t] * b[t-d]

        S = float(p_cur.sum())

        # = c_max + T*log(sum(exp((c-c_max)/T)) / (2n-1))

        # So sum(exp((c-c_max)/T)) = (2n-1) / w_sum_normalized... 
        # Actually w is normalized: sum(w) = 1

        # sum(exp((c-c_max)/T)) = L / (L * w Normalized)... 
        # Hmm, let me just compute LSE directly from c.
        
        base = 2.0 * n * LSE_val / (S*S)
        grad = 2.0 * 2.0 * n * xcorr / (S*S) - 2.0 * base * p_cur / S
        return base, grad
    
    # Stages: (temperature_fraction, weight)
    stages = [
        (0.1, 30),
        (0.05, 30),

                    return 1e100, np.zeros_like(u)

                exps = np.exp(scaled)

                    w[int(np.argmax(c))] = 1.0
                    LSE_v = cm
                else:

                    w = exps / sum_e

                # Center the gradient (invariance to adding constant to u)
                grad_u = grad_u - pp * float(np.dot(pp, grad_u)) / S
                return base, np.where(np.isfinite(grad_u), grad_u, 0.0)
            
            opts = {"maxiter": 50, "gtol": 1e-14, "ftol": 1e-18,

                    best_p = p_new.copy()
                    p = p_new.copy()
                    u = _init_u(p)
                    stale = 0
                    if consider:
                        try:
                            consider(p)
                        except:
                            pass
                else:
                    stale += 1
                    if stale >= 4:
                        break
            if getattr(res, "status", -1) == 0:
                break
    
    return best_p
