Let me think about n. The score is 2*n*max(conv(p,p)) where p is a probability vector. For a fixed "shape quality," smaller n might help because the convolution is shorter and the peak might be relatively lower.

Actually, let me think about this differently. For a probability vector p of length n, the "average" convolution value is sum_k conv(p,p)[k] / (2n-1) = (sum p)^2 / (2n-1) = 1/(2n-1) ≈ 1/(2n). The peak must be at least this average. So score >= 2n * 1/(2n) = 1. So the theoretical minimum is 1.

But Can we achieve close to 1? That would require the convolution to be perfectly flat, which means conv(p,p)[k] = 1/(2n-1) for all k. This is a very strong condition.

For a perfectly flat convolution, we'd need |FFT(p)|^2 to be constant, which means p has all Fourier coefficients of the same magnitude. This is related to "perfect sequences" or "Barker sequences" but for continuous non-negative values.

Actually, for linear convolution to be flat, we need the DFT of p (padded to length 2n-1) to have constant magnitude. This is possible in principle (it's related to "low autocorrelation" sequences).

The question is: how close can we get with non-negative coefficients?

For ±1 sequences (Barker, m-sequences), the peak sidelobe is O(sqrt(n)) relative to the peak. For non-negative sequences, the situation is different because we can't cancel.

I think the practical approach is:

            improved = False
            order = rng.permutation(n)

            for i in order:
                if time.monotonic() >= deadline:
                    break

                v = p[i]
                start = i
                Ls = n  # always n for valid i
                end = start + Ls

                base = c[start:end]
                infl = 2.0 * p  # infl[j] = 2*p[j], length n

                max_const = 0.0
                if start > 0:
                    mc = float(c[:start].max())
                    if mc > max_const:
                        max_const = mc
                if end < Ltot:
                    mc = float(c[end:].max())
                    if mc > max_const:
                        max_const = mc

                # Grid search for optimal delta
                dw_lo = -v
                dw_hi = max(5.0 * v, 4.0 / n)
                G = 32
                dws = np.linspace(dw_lo, dw_hi, G + 1)

                # Vectorized: aff[g, j] = base[j] + dws[g]*infl[j] + (dws[g]^2 if j==i else 0)
                aff = base[None, :] + dws[:, None] * infl[None, :]
                aff[:, i] += dws * dws
                np.maximum(aff, max_const, out=aff)
                mv = aff.max(axis=1)
                denoms = (1.0 + dws) ** 2
                invalid = dws <= -1.0 + 1e-10
                vals = np.full(G + 1, np.inf)
                valid = ~invalid
                vals[valid] = 2.0 * n * mv[valid] / denoms[valid]

                im = int(np.argmin(vals))
                bv = float(vals[im])
                bd = float(dws[im])

                # Golden section refinement
                if bv < cur_sc - 1e-13 and abs(bd) > 1e-15:
                    span = (dw_hi - dw_lo) / G
                    lo = max(dw_lo, bd - 3.0 * span)
                    hi = min(dw_hi, bd + 3.0 * span)
                    if hi > lo:
                        gr = (math.sqrt(5.0) - 1.0) / 2.0
                        a_, b_ = lo, hi
                        c_ = b_ - gr * (b_ - a_)
                        d_ = a_ + gr * (b_ - a_)

                        def obj_dw(dw):
                            den = 1.0 + dw
                            if den <= 1e-10:
                                return 1e100
                            nc = base + dw * infl
                            nc = nc.copy()
                            nc[i] += dw * dw
                            if nc[i] < 0:
                                nc[i] = 0.0
                            m = float(nc.max())
                            if m < max_const:
                                m = max_const
                            return 2.0 * n * m / (den * den)

                        fc_ = obj_dw(c_)
                        fd_ = obj_dw(d_)
                        for _ in range(30):
                            if fc_ < fd_:
                                b_ = d_
                                d_ = c_
                                fd_ = fc_
                                c_ = b_ - gr * (b_ - a_)
                                fc_ = obj_dw(c_)
                            else:
                                a_ = c_
                                c_ = d_
                                fc_ = fd_
                                d_ = a_ + gr * (b_ - a_)
                                fd_ = obj_dw(d_)

                        bd = (a_ + b_) / 2.0
                        bv = obj_dw(bd)

                if bv < cur_sc - 1e-13 and bd > -v + 1e-12 and 1.0 + bd > 1e-10:
                    p[i] += bd
                    c[start:end] += bd * infl
                    c[start + i] += bd * bd
                    c[start + i] = max(c[start + i], 0.0)
                    cur_sc = bv
                    improved = True

            # Renormalize
            s_new = p.sum()
            if s_new < 1e-30:
                break
            if abs(s_new - 1.0) > 1e-6:
                inv = 1.0 / s_new
                p *= inv
                c *= inv * inv
                cur_sc = 2.0 * n * float(c.max())
            else:
                cur_sc = 2.0 * n * float(c.max())

            # Periodic full recompute to correct drift
            if sweep % 8 == 7:
                c = conv_self(p)
                cur_sc = 2.0 * n * float(c.max())

            if improved:
                no_improve = 0
                if sweep % 10 == 0:
                    consider(p)
            else:
                no_improve += 1
                if no_improve >= 5:
                    if time.monotonic() < deadline - 20:
                        # Adapt perturbation size
                        pert_size = 0.01 + 0.01 * (sweep % 3)
                        p = p * np.exp(rng.normal(0.0, pert_size, n))
                        p = np.maximum(p, 1e-12)
                        p /= p.sum()
                        c = conv_self(p)
                        cur_sc = 2.0 * n * float(c.max())
                        no_improve = 0
                    else:
                        break

            sweep += 1

        p = np.maximum(p, 0.0)
        ss = p.sum()
        if ss > 1e-30:
            p /= ss
        c_f = conv_self(p)
        sc_f = 2.0 * n * float(c_f.max())
        return p, sc_f

    # Run main coordinate descent
    p_start = best_arr / best_arr.sum()
    cd_deadline = hard - 50.0
    if time.monotonic() < cd_deadline - 30:
        try:
            p_cd, sc_cd = coord_descent(p_start, cd_deadline, rng_seed=seed)
            if np.all(np.isfinite(p_cd)) and p_cd.sum() > 1e-10:
                consider(p_cd)
        except Exception:
            pass

    # Second round with different perturbation seed
    rem = hard - time.monotonic()
    if rem > 40:
        p_start2 = best_arr / best_arr.sum()
        try:
            p_cd2, _ = coord_descent(p_start2, hard - 8, rng_seed=seed + 7777)
            if np.all(np.isfinite(p_cd2)) and p_cd2.sum() > 1e-10:
                consider(p_cd2)
        except Exception:
            pass

    # Final validation
    try:
        a = np.asarray(best_arr, dtype=np.float64).ravel()
        a = np.clip(np.where(np.isfinite(a), a, 0.0), 0.0, 1000.0)
        if a.size == 0 or a.sum() < 0.01:
            a = np.ones(64)
        result = [float(x) for x in a]
        fs = float(evaluate_sequence(result))
        if not math.isfinite(fs):
            return [1.0]
        return result
    except Exception:
        return [1.0]
