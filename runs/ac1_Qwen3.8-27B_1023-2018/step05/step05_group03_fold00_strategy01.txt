We minimize the AC1 upper bound using projected gradient descent with FFT-based autocorrelation computation. The key innovation is:
- Using finite-difference gradients to handle the non-differentiable max operation
- Maintaining coefficient scaling for numerical stability
- Projecting gradients onto the feasible set (non-negative coefficients)

#### 2. Mathematical Specification

- **Constraints**:
