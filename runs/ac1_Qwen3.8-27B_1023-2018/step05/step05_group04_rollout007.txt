```python
import numpy as np
import time
import math
from scipy.fft import rfft, irfft, next_fast_len

def _get_parent():
    try:
        h = globals()["height_sequence_1"]
        p = np.asarray(h, dtype=np.float64).ravel()
    except Exception:
        p = np.ones(384, dtype=np.float64)
    if p.size == 0:
        p = np.ones(384, dtype=np.float64)
    p = np.where(np.isfinite(p), p, 0.0)
    p = np.clip(p, 0.0, 1000.0)
    if float(p.sum()) < 1e-12:
        p = np.ones(384, dtype=np.float64)
    return p

def _conv_self(a):
    n = a.size
    if n == 0:
        return np.zeros(0)
    L = 2 * n - 1
    size = next_fast_len(L)
    F = rfft(a, size)
    c = irfft(F * F, size)[:L]
    return np.asarray(c, dtype=np.float64)

def _score_arr(a):
    a = np.asarray(a, dtype=np.float64).ravel()
    n = a.size
    if n == 0:
        return float('inf')
    a = np.where(np.isfinite(a), a, 0.0)
    a = np.maximum(a, 0.0)
    s = float(a.sum())
    if s < 0.01:
        return float('inf')
    c = _conv_self(a)
    m = float(c.max())
    if not math.isfinite(m):
        return float('inf')
    return float(2.0 * n * m / (s * s))

def _softmax(u):
    m = float(np.max(u))
    e = np.exp(u - m, dtype=np.float64)
    s = float(e.sum())
    if not math.isfinite(s) or s <= 0:
        return np.full(u.shape, 1.0 / u.size, dtype=np.float64)
    return e / s
```

One key insight: in the CD, after a full sweep with no improvement, we're at a coordinate-wise local optimum. To escape, we need a non-local move. The "kick" (random perturbation) is one way, but it's quite random. A better approach:

**Directed kick**: Identify the lag k* where the maximum occurs. The convolution at k* is sum_i a[i]*a[i+k*]. To reduce this, we should reduce the product a[i]*a[i+k*] for the pairs that contribute most. This suggests:
- For the top-contributing pairs, either reduce a[i] or a[i+k*]
- Or, increase a at positions where the convolution is low (to spread out the mass)

This is essentially a gradient step in the space of the subgradient of the max.

Let me implement this as a "subgradient kick":
1. Find k* = argmax(conv)
2. Compute the subgradient: for each i, the subgradient contribution is a[i+k*] (if i+k* is valid) + a[i-k*] (if i-k* is valid)
3. Take a small step in the negative subgradient direction (in log-space)
4. Renormalize

This should be more directed than a random kick.
