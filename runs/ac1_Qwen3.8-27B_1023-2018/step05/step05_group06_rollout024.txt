**Improved Coordinate Descent:**

1. Start with parent sequence (normalized to sum=1)
2. Compute convolution c = convolve(p, p)
3. For each coordinate i (in random order):
   a. Determine the window [i, min(i+n-1, 2n-2)] that's affected
   b. Compute the influence vector: for j in window, Δb_j per unit w is 2*a_{j-i}
   c. Compute the "constant" max outside the window
   d. Find best w by grid search + golden section
   e. Update p[i], S, and c
4. After each sweep, renormalize
5. Periodically recompute c exactly to prevent drift

**Key improvement: Batched coordinate updates**

Instead of optimizing one coordinate at a time, we can optimize a small group of coordinates that don't overlap in their influence regions. Two coordinates i and j don't overlap if |i-j| >= n. Since we have n coordinates total, we can partition them into groups of roughly size 1 (since n coordinates each affect n positions, and there are 2n-1 total positions, almost any two coordinates overlap).

Actually, for coordinates i and j with |i-j| < n, their influence windows [i, i+n-1] and [j, j+n-1] overlap. So we can't easily batch them.

But we CAN do a simpler optimization: change two adjacent coordinates simultaneously. If i and i+1 are changed, the affected region is [i, i+n] (length n+1) instead of two separate regions of length n each. This is a minor improvement.

**Better idea: Block coordinate descent**

Partition the sequence into blocks of size B. For each block, solve the subproblem: given the values outside the block are fixed, find the optimal values inside the block.

For a block of size B, the subproblem is:
- Minimize 2n * max(b) subject to the constraint that only the B coordinates in the block can change
- The affected convolution region has size at most B + n (since the block spans B positions, and each affects n positions)
- This is a small optimization problem with B variables

We can solve this with a small QP or just coordinate descent within the block.

Actually, for B=2 or B=3, this is simple enough. Let me think about B=2:

If we change a[i] and a[i+1] by w1 and w2:
- Δb_j = 2*w1*a_{j-i} + 2*w2*a_{j-(i+1)} + w1^2*δ_{j,2i} + w2^2*δ_{j,2(i+1)} + 2*w1*w2*δ_{j,2i+1}

This is a 2D optimization problem. We can solve it with a small grid (say 20x20) followed by a few iterations of 2D golden section.

For B=3, it becomes a 3D problem, which gets harder.

Let me stick with B=1 (single coordinate) but add a B=2 refinement phase.

**Another key insight: The penalty structure**

The score is 2n * max(b_j) / (sum a)^2. The max is achieved at some lag k*. If we can identify which lag achieves the max, we can focus on reducing that specific lag.

For a given lag k, b_k = sum_i a_i * a_{i+k}. To reduce b_k, we want to reduce the "overlap" between a and its shifted version.

**Strategy: Focus on the active lags**

1. Find the lag k* that achieves max(b)
2. Focus optimization on coordinates that affect b_{k*}
3. Coordinate i affects b_{k*} if i <= k* <= i+n-1, i.e., i in [k*-n+1, k*]

This is a subset of coordinates. We can iterate: optimize those, recompute, find new k*, etc.

def _conv_self(a):
    """Compute autocorrelation using FFT."""
    n = len(a)
    L = 2 * n - 1
    size = next_fast_len(L)
    F = rfft(a, size)
    c = irfft(F * F, size)[:L]
    # Clip small negatives from FFT roundoff
    c = np.maximum(c, 0.0)
    return c

    m = float(c.max())
    return 2.0 * n * m / (S * S)
