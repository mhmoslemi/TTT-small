c[k] = sum_j a[j] * a[k-j] (sum over j where both a[j] and a[k-j] exist)

Wait, the second term: delta(k-j-i) means k-j=i, so j=k-i. The contribution is a[j] = a[k-i], valid if 0<=k-i<n and 0<=j<n = 0<=i<n.

So dc[k]/da[i] = 2*a[k-i] when 0<=k-i<n, else a[k-i] (if only one term is valid) or 0.

Hmm, actually both terms give a[k-i] when 0<=k-i<n. But wait:
- First term: j=i, contribution is a[k-i], valid when 0<=k-i<n (i.e., i<=k<i+n)
- Second term: j=k-i, contribution is a[k-i], valid when 0<=k-i<n (i.e., i<=k<i+n) AND 0<=k-i<n (same condition)

So actually both terms are valid under the same condition, giving dc[k]/da[i] = 2*a[k-i] for 0<=k-i<n.

But wait, that's when i != k-i, i.e., when 2i != k. When 2i = k (only possible when k is even and i = k/2):

- Second term: j=k-i=i, a[j] = a[i]
- Total: 2*a[i]

So it's always 2*a[k-i] when 0<=k-i<n. Good.

So: grad_i = 2n * (1/T) * sum_k w_k * 2*a[k-i] (for 0<=k-i<n)
= (4n/T) * sum_{k: 0<=k-i<n} w_k * a[k-i]
= (4n/T) * sum_{m: 0<=m<n, 0<=k=n... } 

Let's change variables: m = k-i, so k = m+i.
grad_i = (4n/T) * sum_{m=0}^{n-1} w_{m+i} * a[m] (where w_{m+i} is defined only if 0<=m+i<=2n-2)

This is a cross-correlation! grad_i = (4n/T) * (w_reversed * a)[i] where * is cross-correlation.

Or equivalently, grad = (4n/T) * ifft(fft(a) * conj(fft(w_extended)))

Let me think about this in terms of FFT:
- a has length n
- w has length 2n-1 (the softmax weights over the convolution)
- We want for each i: sum_{m=0}^{n-1} w[m+i] * a[m]

This is like a "sliding dot product" or "sliding cross-correlation". If we define:
v[m] = a[m] for m in [0, n-1], 0 otherwise (length 2n-1)
Then sum_{m=0}^{n-1} w[m+i] * a[m] = sum_m w[m+i] * v[m] = (w * v)[i] (cross-correlation)

Wait, that's not quite standard. Let me just define it as:
g[i] = sum_{m=0}^{n-1} w[m+i] * a[m]

This can be computed as:
- Create array W of length 2n-1 where W[k] = w[k]
- Create array A of length 2n-1 where A[m] = a[m] for m<n, 0 otherwise
- g = cross_correlation(W, A) where cross_corr(W, A)[i] = sum_m W[m+i]*A[m]

This is equivalent to: g[i] = conv(A, flip(W))[i + (2n-2)] ... hmm, getting complicated.

Actually, the simplest FFT approach:
g = ifft(fft(A_padded) * conj(fft(W_padded)))

Where A_padded and W_padded are zero-padded to the same length. But we need g[i] = sum_m W[m+i]*A[m], which is a cross-correlation.

Cross-correlation: (W ⊛ A)[i] = sum_m W[m+i]*A[m]
= ifft(conj(fft(W)) * fft(A))[i] (with appropriate padding)

Actually, the standard formula: corr(X, Y)[k] = sum_n X[n+k]*Y[n] = ifft(conj(FFT(X)) * FFT(Y))[k]

So g = ifft(conj(fft(W_pad)) * fft(A_pad))

g[0] = w0*a0 + w1*a1 (m=0: W[0]*A[0] + m=1: W[1]*A[1])
g[1] = w1*a0 + w2*a1 (m=0: W[1]*A[0] + m=1: W[2]*A[1])

Actually, since we're in log-space with a = softmax(u):
da_i/du_j = a_i * (delta_{ij} - a_j)

So dF/du_j = sum_i (dF/da_i) * a_i * (delta_{ij} - a_j)

Where dF/da_i = (4n/T) * sum_k w_k * a[k-i] (as computed above)

So the gradient in u-space is:
grad_u = a * (grad_a - dot(a, grad_a))

where grad_a is the gradient wrt a (the cross-correlation result).

This is the standard softmax gradient transformation.

import numpy as np
import time
import math
from scipy.fft import rfft, irfft, next_fast_len
from scipy.optimize import minimize

def _norm1(a):
    """Normalize to sum=1, clip to [0, inf]."""
    a = np.asarray(a, dtype=np.float64).ravel()
    a = np.where(np.isfinite(a), a, 0.0)
    a = np.maximum(a, 0.0)
    s = float(a.sum())
    if not math.isfinite(s) or s < 1e-300:
        return np.full(a.size, 1.0/a.size)
    return a / s

def _fft_conv(a):
    """FFT-based full convolution."""
    n = a.size
    L = 2*n - 1
    sz = next_fast_len(L)
    F = rfft(a, sz)
    c = irfft(F*F, sz)[:L]
    np.maximum(c, 0.0, out=c)
    return c

def _score_fast(a):
    """Compute 2n*max_b/sum^2 using FFT."""
    a = _norm1(a)
    if a.size == 0: return math.inf
    c = _fft_conv(a)
    m = float(c.max())
    return 2.0 * a.size * m

def _lse_objective(u, T, a_cache=None):
    """
    Log-sum-exp soft-max of convolution.
    Returns (value, gradient_u)
    """
    n = len(u)
    # softmax
    u = np.asarray(u, dtype=np.float64)
    umax = float(np.max(u))
    e = np.exp(u - umax)
    e = np.where(np.isfinite(e), e, 0.0)
    s = float(e.sum())
    if s <= 0: return 1e100, np.zeros(n)
    a = e / s
    
    # convolution
    L = 2*n - 1
    sz = next_fast_len(L)
    F = rfft(a, sz)
    c = irfft(F*F, sz)[:L]
    np.maximum(c, 0.0, out=c)
    
    cmax = float(c.max())
    scaled = (c - cmax) / T
    exps = np.exp(scaled)
    exps = np.where(np.isfinite(exps), exps, 0.0)
    sum_exp = float(exps.sum())
    if sum_exp <= 0:
        w = np.zeros(L); w[int(np.argmax(c))] = 1.0
    else:
        w = exps / sum_exp
    
    f = cmax + T * math.log(sum_exp / L)
    
    # Gradient wrt a: grad_a[i] = (4n/T) * sum_k w[k] * a[k-i] (for valid k-i)
    # This is a cross-correlation of w (length 2n-1) with a (length n)
    # grad_a[i] = sum_{m=0}^{n-1} w[m+i] * a[m]
    # Use FFT: pad a and w to size sz
    A_pad = np.zeros(sz); A_pad[:n] = a
    W_pad = np.zeros(sz); W_pad[:L] = w
    # cross-correlation: g[i] = sum_m W[m+i]*A[m]
    # = ifft(conj(fft(W)) * fft(A))
    grad_a = irfft(conj(rfft(W_pad, sz)) * rfft(A_pad, sz))[:n]
    grad_a = np.where(np.isfinite(grad_a), grad_a, 0.0)
    
    # score = 2n * (cmax + T*log(mean exp))
    # d(score)/da_i = 2n * (1/T) * sum_k w[k] * 2*a[k-i] = (4n/T) * grad_a[i]
    score_grad_a = (4.0 * n / T) * grad_a
    
    # Chain rule for softmax: d/du_j = a_j * (grad_a_j - sum_i a_i * grad_a_i)
    dot = float(np.dot(a, score_grad_a))
    grad_u = a * (score_grad_a - dot)
    grad_u = np.where(np.isfinite(grad_u), grad_u, 0.0)
    
    return 2.0 * n * f, grad_u

def _lse_optimize(a0, stop_time, T_frac=0.01):
    """Optimize using LSE + L-BFGS-B in log space."""
    a0 = _norm1(a0)
    n = a0.size
    u0 = np.log(np.maximum(a0, 1e-300)) - np.mean(np.log(np.maximum(a0, 1e-300)))
    
    best_a = a0.copy()
    best_sc = _score_fast(a0)
    
    c = _fft_conv(a0)
    cmax = float(c.max())
    
    # Temperature schedule: start high, end low
    temps = [0.05, 0.02, 0.01, 0.005, 0.002, 0.001, 0.0005]
    
    for T_frac_i in temps:
        if time.monotonic() > stop_time - 5: break
        T = T_frac_i * cmax
        T = max(1e-12, T)
        
        max_iter = 30
        # Run L-BFGS
        for _ in range(max_iter // 10 + 1):
            if time.monotonic() > stop_time - 5: break
            try:
                res = minimize(
                    _lse_objective, u0, args=(T,),
                    method='L-BFGS-B', jac=True,
                    options={'maxiter': 10, 'gtol': 1e-8, 'disp': False}
                )
                if res.x is not None and np.all(np.isfinite(res.x)):
                    u0 = res.x.copy()
            except:
                break
        
        # Convert back to a
        a_new = _norm1(np.exp(u0 - np.mean(u0)))
        sc_new = _score_fast(a_new)
        if sc_new < best_sc - 1e-12:
            best_a = a_new.copy()
            best_sc = sc_new
            a0 = a_new.copy()
            u0 = np.log(np.maximum(a0, 1e-300)) - np.mean(np.log(np.maximum(a0, 1e-300)))
            c = _fft_conv(a_new)
            cmax = float(c.max())
    
    return best_a, best_sc

def _coord_polish(a, stop_time, n_sweeps=100, seed=42):
    """Coordinate descent polish."""
    a = _norm1(a)
    n = a.size
    rng = np.random.default_rng(seed)
    best_a = a.copy()
    best_sc = _score_fast(a)
    
    c = _fft_conv(a)
    L = 2*n - 1
    s = 1.0  # sum is 1
    infl = 2.0 * a  # influence vector (derivative of conv wrt a_i, pre-multiplied)
    cur_sc = best_sc
    
    sweep = 0
    flat = 0
    
    while sweep < n_sweeps and time.monotonic() < stop_time - 2:
        improved = False
        order = rng.permutation(n)
        
        for pos in range(n):
            if time.monotonic() > stop_time - 0.5: break
            i = int(order[pos])
            v = float(a[i])
            
            # Compute new conv values if we change a[i]
            # c_new[k] = c[k] + d*a_infl[k-i] + d^2 (at k=2i)
            # where a_infl[m] = a[m] (for cross terms)

            # c_new[k] = c[k] + d * (a[k-i] + a[i-k]) + d^2 * delta(k-2i)
            # (with a[m]=0 for m outside [0,n-1])

            # Actually k ranges from 0 to 2n-2
            # a[k-i] is valid when 0 <= k-i <= n-1, i.e., i <= k <= i+n-1
            # a[i-k] is valid when 0 <= i-k <= n-1, i.e., i-(n-1) <= k <= i
            # Union: max(0, i-(n-1)) <= k <= min(2n-2, i+n-1)
            k_lo = max(0, i - (n-1))
            k_hi = min(L-1, i + n - 1)
            Ls = k_hi - k_lo + 1
            
            if Ls <= 0: continue
            
            # base = c[k_lo:k_hi+1]
            base = c[k_lo:k_hi+1].copy()
            
            # influence: for each offset m in [0, Ls-1], k = k_lo + m
            # delta_c[m] = a[k-m-i + i]... let me re-derive
            # c_new[k] - c[k] = d*(a[k-i] + a[i-k]) + d^2*delta(k, 2i)
            # For k in [k_lo, k_hi]:
            #   a[k-i]: valid when 0<=k-i<=n-1, value = a[k-i]
            #   a[i-k]: valid when 0<=i-k<=n-1, value = a[i-k]
            
            # Build influence vector of length Ls
            infl_vec = np.zeros(Ls)
            for m in range(Ls):
                k = k_lo + m
                # a[k-i]
                if 0 <= k-i < n:
                    infl_vec[m] += a[k-i]
                # a[i-k]
                if 0 <= i-k < n:
                    infl_vec[m] += a[i-k]
            
            # max outside the affected region
            max_const = 0.0
            if k_lo > 0:
                max_const = max(max_const, float(c[:k_lo].max()))
            if k_hi < L-1:
                max_const = max(max_const, float(c[k_hi+1:].max()))
            
            # Objective: 2n * max(max_const, base + d*infl_vec + d^2*delta) / (1+d)^2
            # where d = new_a[i] - v, and we re-normalize
            
            # Search for best new value of a[i]
            # Normalize a[i] to x, rest unchanged, then normalize
            # a_new[i] = x / (s - v + x) where s=1
            # Actually: a_new = a / s_new where s_new = 1 - v + x
            # c_new = c + d*(infl from a) + ... this gets complicated with normalization
            
            # Simpler: just try a range of values for a[i]
            # x ranges from 0 to some upper bound
            # After change, a_new = a.copy(); a_new[i] = x; a_new /= a_new.sum()
            # score = 2n * max(conv(a_new)) 
            # (since sum is 1 after normalization)
            
            # Brute force with FFT is too slow for each coordinate.
            # Use the incremental update:
            # a_new = a with a[i] changed to x, normalized
            # conv(a_new)[k] = conv(a)[k] / s_new^2 + terms involving x
            # This is getting complicated. Let me use a simpler approach:
            # Just try a few candidate values and recompute the score.
            
            # For efficiency, use the fact that:
            # a_new = a * (1/s_new) except a_new[i] = x/s_new where s_new = 1 - v + x
            # conv(a_new)[k] = conv(a)[k]/s_new^2 + (x/s_new - v/s_new^2) * (a[k-i]/s_new + a[i-k]/s_new) + ...
            # This is messy. Let me just do a few candidate values with full recompute.
            
            # Actually for n=3072, FFT conv takes ~0.1ms. So we can afford ~10000 per second.
            # Per coordinate, try ~10 values. That's 10 FFT convs per coordinate.
            # For 3072 coordinates, that's 30720 FFT convs per sweep.
            # At 10000/sec, that's 3 seconds per sweep. Too slow for many sweeps.
            # Need to be more selective.
            
            # Better approach: only try the top-k "most promising" coordinates per sweep
            # Based on which coordinates have the largest influence on the max conv values.
            
            # For now, let's do a simpler version: try 5 candidate values per coordinate
            # and only do a fraction of coordinates per sweep.
            
            # Actually, the previous program's approach of computing the score analytically
            # from the incremental update is much better. Let me implement that.
            
            # score(x) = 2n * max_k c_new(k) / (1 + x - v)^2
            # where c_new(k) = c[k] + (x-v)*(a[k-i] + a[i-k]) + (x-v)^2 * delta(k,2i)
            #   (before normalization)
            # After normalization by s_new = 1 + x - v:
            # conv(a_new)[k] = [c[k] + (x-v)*(a[k-i]+a[i-k]) + (x-v)^2*delta] / s_new^2
            
            # So score(x) = 2n * max_k [c[k] + (x-v)*infl_vec_offset + (x-v)^2*diag_offset] / (1+x-v)^2
            # where the max is over all k, and for k outside [k_lo, k_hi], the "infl" part is 0.
            
            # Let's define:
            # For k in [k_lo, k_hi]: new_c[k] = c[k] + d*infl_vec[k-k_lo] + d^2*delta(k,2i)
            # For k outside: new_c[k] = c[k]
            # max_new = max(max_const, max(new_c[k_lo:k_hi+1]))
            # score = 2n * max_new / (1+d)^2  where d = x-v
            
            def eval_x(d):
                """Evaluate score for a[i] -> a[i]+d (before normalization)."""
                aff = base + d * infl_vec
                if 2*i - k_lo >= 0 and 2*i - k_lo < Ls:
                    aff[2*i - k_lo] += d * d
                np.maximum(aff, max_const, out=aff)
                mv = float(aff.max())
                den = 1.0 + d
                if den <= 1e-30: return math.inf
                return 2.0 * n * mv / (den * den)
            
            # Try candidate d values
            # d ranges from -v (making a[i]=0) to some positive value
            # Let's try: 0, small positive, larger positive, negative
            # Use geometric spacing for positive, linear for negative
            d_candidates = [0.0]
            # Negative: down to -v
            if v > 1e-15:
                d_candidates.extend(np.geomspace(-v*0.99, -1e-12, 5).tolist())
            # Positive: up to max(10*v, 0.1/n)
            d_hi = max(10.0*v, 0.5/n)
            if d_hi > 1e-12:
                d_candidates.extend(np.geomspace(1e-12, d_hi, 8).tolist())
                d_candidates.extend(np.linspace(0, d_hi, 5).tolist())
            
            d_candidates = [d for d in d_candidates if 1.0 + d > 1e-10]
            if not d_candidates:
                d_candidates = [0.0]
            
            best_d = 0.0
            best_val = cur_sc
            for d in d_candidates:
                val = eval_x(d)
                if val < best_val:
                    best_val = val
                    best_d = d
            
            if best_val < cur_sc - 1e-12 and abs(best_d) > 1e-15:
                # Accept the move
                a[i] += best_d
                d = best_d
                # Update c
                for m in range(Ls):
                    k = k_lo + m
                    c[k] += d * infl_vec[m]
                di = 2*i - k_lo
                if 0 <= di < Ls:
                    c[k_lo + di] += d * d
                c = np.maximum(c, 0.0)
                s += best_d
                a /= s  # re-normalize
                c /= s * s
                c = np.maximum(c, 0.0)
                infl = 2.0 * a
                cur_sc = _score_fast(a)  # recompute to avoid drift
                improved = True
                if cur_sc < best_sc - 1e-12:
                    best_sc = cur_sc
                    best_a = a.copy()
        
        # End of sweep
        if improved:
            flat = 0
        else:
            flat += 1
            if flat >= 5:
                # Add noise to escape
                noise = rng.normal(0, 0.05, n)
                a = _norm1(a * np.exp(noise))
                c = _fft_conv(a)
                cur_sc = _score_fast(a)
                flat = 0
        
        sweep += 1
    
    return best_a, best_sc

def _explore(a, n_target, seed):
    """Generate diverse candidate shapes."""
    rng = np.random.default_rng(seed)
    candidates = []
    
    # Power transforms
    for q in (0.5, 0.7, 0.85, 1.15, 1.3, 1.5):
        x = np.arange(n_target) / n_target
        base = a * (1 + 0.5*q*np.sin(2*np.pi*(x + rng.random())))
        candidates.append(_norm1(np.maximum(base, 0)))
    
    # Shifted/warped versions
    for _ in range(5):
        shift = rng.uniform(-0.1, 0.1)
        x = np.linspace(0, 1, n_target)
        xw = (x + shift) % 1
        idx = (xw * n_target).astype(int) % n_target
        candidates.append(_norm1(a[idx]))
    
    # Smooth bumps
    for _ in range(3):
        center = rng.uniform(0.2, 0.8)
        width = rng.uniform(0.1, 0.4)
        bump = np.exp(-0.5*((x-center)/width)**2)
        base = a * (0.5 + 0.5*bump)
        candidates.append(_norm1(base))
    
    return candidates
