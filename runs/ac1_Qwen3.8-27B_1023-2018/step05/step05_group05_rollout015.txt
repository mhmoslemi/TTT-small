Now, for the grid search, I need to evaluate the score for many candidate values of w (or equivalently, v = p[i] + w). The score for a given w is:
score(w) = 2n * max_k c_new(k) / (S + w)^2

where c_new(k) = c(k) + 2w*p[k-i] (for k in affected range, k≠2i) + w^2 (at k=2i, in addition to the linear term).

Equivalently:
c_new(k) = c(k) + 2w*p[k-i] for k in [lo, hi], k ≠ 2i
c_new(2i) = c(2i) + 2w*p[i] + w^2
c_new(k) = c(k) for k outside [lo, hi]

For the grid search, I want to compute max_k c_new(k) for many w values. The max splits into:
1. max outside [lo, hi]: this is independent of w
2. max inside [lo, hi]: depends on w

For (2), I can compute it as a matrix operation:
c_affected = c[lo:hi+1]  # (length,)
new_affected = c_affected[None, :] + 2*w_grid[:, None] * p[:length][None, :]  # (G, length)
if has_diag:
    new_affected[:, diag_idx] += w_grid * w_grid  # (G,)
max_affected = new_affected.max(axis=1)  # (G,)

Then max_total = max(max_outside, max_affected)
score = 2n * max_total / (S + w_grid)^2

This is O(G * n) which for G=60, n=3072 is about 184K operations. Fast.

            final_sc = float(evaluate_sequence(ls))
            if not math.isfinite(final_sc):
