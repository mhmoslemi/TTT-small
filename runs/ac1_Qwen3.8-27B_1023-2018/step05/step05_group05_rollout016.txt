Given `a` (length n), `c = a * a` (linear convolution, length 2n-1).

Then `dF/dc_k = w_k`.

`c_k = sum_j a_j * a_{k-j}` (sum over valid j).

`dc_k/da_i = a_{k-i} + a_{k-i}` (two terms, as explained; for k=2i it's slightly different but we ignore)

So `dF/da_i = sum_k w_k * 2 * a_{k-i} = 2 * sum_k w_k * a_{k-i}`.

The sum `sum_k w_k * a_{k-i}` for k = 0..2n-2, where a_{k-i} is valid only when 0 ≤ k-i < n.

This is the cross-correlation of w (length 2n-1) with a (length n) at shift i:
`(w ⊛ a)(i) = sum_k w[k] * a[k-i]` (with a[j] = 0 for j < 0 or j ≥ n)

We want `a[k-i]`, so `n-1-m+k = k-i`, giving `m = n-1+i`.

And `dF/da = 2 * cross`.

                flat_count = 0
            else:
                flat_count += 1
                if flat_count >= 5:
                    # Perturb
                    p = p * np.exp(rng.normal(0, 0.03, n))
                    p = np.maximum(p, 0)
                    ss = p.sum()
                    if ss > 1e-10:
                        p /= ss
                    else:
                        p = np.ones(n)/n
                    c = full_conv(p)
                    cur_val = float(2*n*c.max())
                    flat_count = 0
            
            sweep += 1
        
        if best_cd_val < float(2*n*full_conv(p).max()):
            p = best_cd_p
    
    # Phase 3: Final LSE + brief CD
    final_end = deadline
    if time.monotonic() < final_end - 15:
        p = np.maximum(p, 0.0)
        p /= p.sum()
        cmax_f = float(full_conv(p).max())
        u = _p2u(p)
        for frac in [0.002, 0.0005, 0.0001]:
            T = frac * cmax_f
            if time.monotonic() > final_end - 10:
                break
            try:
                res = minimize(lse_val_grad, u, args=(T,), method='L-BFGS-B',
                              jac=True, options={'maxiter': 30, 'gtol': 1e-11,
                                                 'ftol': 1e-15, 'maxcor': 15,
                                                 'maxls': 15, 'disp': False})
                if res.x is not None and np.all(np.isfinite(res.x)):
                    p_new = _softmax(res.x)
                    u = res.x.copy()
                    p = p_new
            except:
                pass
        try_update(p * parent.sum())
    
    # Scale back to original scale for evaluation
    # Actually, the score is scale-invariant, so we can return any scaling
    # But let's keep the original scale
    out = best.copy()
    if out.size == 0 or out.sum() < 0.01:
        out = np.ones(64)
    final_sc = evaluate_sequence([float(x) for x in out])
    if not math.isfinite(final_sc):
        out = np.ones(64)
        final_sc = evaluate_sequence([float(x) for x in out])
    
    return [float(x) for x in out]
