where M(w) = max(max_{k in A} [c_k + w*d_k + w²*e_k], C)

Since e_k is 1 only at k=2j (if 2j < 2n-1), there's at most one quadratic term. The rest are linear in w.

The "effective max" M(w) is the upper envelope of:
- n linear functions: c_k + w*d_k for k in A, k ≠ 2j
- One quadratic: c_{2j} + w*d_{2j} + w² (if 2j in A)
- One constant: C

The minimum of f(w) = 2n*M(w)/(S+w)² over w >= -a_j.

For the linear part: if the max is achieved by a linear function c_k + w*d_k, then:
f(w) = 2n*(c_k + w*d_k)/(S+w)²
df/dw = 2n * [d_k*(S+w)² - (c_k + w*d_k)*2*(S+w)] / (S+w)⁴
= 2n * (S+w) * [d_k*(S+w) - 2*(c_k + w*d_k)] / (S+w)⁴
= 2n * [d_k*S + d_k*w - 2*c_k - 2*w*d_k] / (S+w)³
= 2n * [d_k*S - 2*c_k - w*d_k] / (S+w)³

Setting to zero: d_k*S - 2*c_k - w*d_k = 0 → w = S - 2*c_k/d_k (if d_k > 0)

For the quadratic part (k=2j):
f(w) = 2n*(c + w*d + w²)/(S+w)²
df/dw = 2n * [(d+2w)(S+w)² - (c+wd+w²)*2(S+w)] / (S+w)⁴
= 2n * [(d+2w)(S+w) - 2(c+wd+w²)] / (S+w)²
= 2n * [dS+dw+2wS+2w² - 2c-2wd-2w²] / (S+w)²
= 2n * [dS + 2wS - dw - 2c] / (S+w)²
= 2n * [d(S-w) + 2wS - 2c] / (S+w)²
= 2n * [dS - dw + 2wS - 2c] / (S+w)²

Setting to zero: dS - dw + 2wS - 2c = 0 → w(2S-d) = 2c - dS → w = (2c - dS)/(2S - d) (if 2S ≠ d)

So for each "active" linear or quadratic piece, I can compute the optimal w analytically. Then I just need to check which piece is active at that w and verify.
