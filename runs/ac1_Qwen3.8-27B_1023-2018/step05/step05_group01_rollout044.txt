If k-i ≠ i (i.e., k≠2i), these are two distinct terms.

  - If k ≠ 2i: delta_c = 2*(x-v)*a[k-i]
  - If k = 2i: delta_c = x^2 - v^2

And the affected range is k from max(0, i) to min(2n-2, i+n-1).

Actually, k-i ranges from 0 to n-1, so k ranges from i to i+n-1. Bounded by [0, 2n-2].
So affected range: k from i to min(i+n-1, 2n-2).

Wait, k-i >= 0 means k >= i. k-i < n means k < i+n. And k in [0, 2n-2].
So affected: k in [i, min(i+n-1, 2n-2)].

This is at most n elements.

For the optimization: given the current c and the affected range, I want to find x that minimizes:
score(x) = 2n * max(c_new) / (S + (x-v))^2

where c_new is computed from c_old by the updates above.

max(c_new) = max(
  max(c_new[k] for k in affected range),
  max(c_old[k] for k not in affected range)
)

The second term is a constant. Call it c_outside_max.

For k in affected range (k ≠ 2i): c_new[k] = c_old[k] + 2*(x-v)*a[k-i]
For k = 2i (if in range): c_new[2i] = c_old[2i] + x^2 - v^2

So max(c_new in affected) = max(
  max(c_old[k] + 2*(x-v)*a[k-i] for k in affected, k≠2i),
  c_old[2i] + x^2 - v^2 (if 2i in affected range)
)

This is the max of linear functions of (x-v) plus one quadratic. The upper envelope can be found, and then we minimize the ratio with (S+x-v)^2.

For a practical approach:
1. Compute the affected range and the coefficients
2. The function to minimize is piecewise: in each region where a particular k dominates the max, the score is a rational function of x
3. Find the optimum by checking the critical points

But this is complex. The grid approach (parent's method) is simpler and works well enough. Let me just make it faster.

Actually, let me think about a simpler but effective approach:

For each coordinate i:
1. Compute the "line" for the affected range: for each k in affected, c_new[k] is linear in x (except the diagonal which is quadratic)
2. The max of these lines (plus the constant outside max) determines the peak
3. The optimal x is where the peak is minimized, divided by (S+x-v)^2

A good heuristic: the optimal x is approximately where the peak is balanced between the "current peak" (outside or unaffected) and the "new contributions" in the affected range.

    c = irfft(F * F, size)[:L]

def _score_fft(a):
