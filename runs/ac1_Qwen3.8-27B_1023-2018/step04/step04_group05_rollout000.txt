This is a piecewise function of w. The `w^2` term is convex, and the linear terms are... well, each `b[k] + 2*(w-v)*a[k-i]` is linear in w with slope `2*a[k-i] >= 0`. So all the affected b[k] values are non-decreasing in w.

The max of non-decreasing functions is non-decreasing. So the new max is non-decreasing in w. This means the optimal w is as small as possible, i.e., w = 0!

Wait, that can't be right. If all b[k] are non-decreasing in w, then the min is at w = 0. But that would mean we should set every coordinate to 0, which gives sum_a = 0 and score = inf.

The issue is that we need to maintain `sum(a) >= 0.01` (or some normalization). But the score is scale-invariant, so we can normalize after.

Hmm, but if we set w = 0, we're removing mass from that coordinate. The score might decrease because we're reducing the max autocorrelation. But we also need to maintain some mass.

Actually wait, the score IS scale-invariant. So we should normalize after each step. The question is: given the current shape (relative values), what's the best value for coordinate i?

If we fix all other coordinates and vary a[i] = w, the score is:
`2n * max(b_new) / (sum_new)^2`

where `sum_new = sum_old - v + w` and `b_new` is computed as above.

This is NOT simply non-decreasing in w because of the denominator. Let me write it out:

Let `S = sum_old - v` (sum of all other coordinates).
Let `M0 = max_{k not in [i,i+n-1]} b[k]` (max of unchanged b values).
Let `c_k = 2*a[k-i]` for k in [i,i+n-1], k≠2i.
Let `d_k = b[k]` for those k.

Then:
`b_new[2i] = b[2i] + w^2 - v^2`
`b_new[k] = b[k] + c_k * w - c_k * v` for k in affected range, k≠2i.

`max_b_new = max(M0, b[2i] + w^2 - v^2, max_k (b[k] + c_k*w - c_k*v))`
`sum_new = S + w`

Score = `2n * max_b_new / (S + w)^2`

This is a 1D optimization problem in w. We can solve it with ternary search or by finding the critical points.

The function is a ratio of (piecewise) functions. The numerator is the max of:
- M0 (constant)
- b[2i] - v^2 + w^2 (convex quadratic)
- (b[k] - c_k*v) + c_k*w (linear, non-decreasing since c_k >= 0)

All non-decreasing in w (for w >= 0). The denominator (S+w)^2 is also increasing.

The score is `2n * f(w) / g(w)` where f is max of non-decreasing functions and g is increasing. The ratio could be non-monotonic.

For the 1D search, I'll use a grid + refinement approach:
1. Try w = 0 (set coordinate to 0)
2. Try w = v (keep current, score unchanged)
3. Try various fractions: 0.25v, 0.5v, 0.75v, 1.5v, 2v, 3v
4. Refine around the best

Actually, since the score is scale-invariant, setting w=0 and then renormalizing is equivalent to setting all other coordinates to their relative values and a[i] to 0. This might or might not improve things.

Let me think about the fastest approach:

For each coordinate i, we try several w values. For each w, we need:
1. The new max of b
2. The new sum

We can precompute:
- `b_other_max = max(b[k] for k not in [i, i+n-1])`
- For each affected k, the linear coefficient `c_k = 2*a[k-i]` and the intercept `d_k = b[k] - c_k * v` (for k ≠ 2i)
- For k = 2i: the quadratic term

Then for a given w:
- `b_new[2i] = d_2i + w^2` where `d_2i = b[2i] - v^2`
- `b_new[k] = d_k + c_k * w` for other affected k
- `max_b_new = max(b_other_max, b_new[2i], max_k b_new[k])`
- `sum_new = S + w`
- `score = 2n * max_b_new / sum_new^2`

The max of these piecewise-linear (and one quadratic) functions can be computed in O(affected_k) time.

For coordinate i, the affected k range has at most n values. So each w evaluation is O(n). With 13 w values, that's 13n per coordinate. For all n coordinates, 13n^2 ≈ 13 * 124K = 1.6M per round. Very fast!

Let me implement this:

```python
def _coord_descend_round(a, n, b):
    """One round of coordinate descent. Returns updated a and b."""
    S = a.sum()
    improved = False
    for i in range(n):
        v = a[i]
        S_other = S - v
        k_lo = i
        k_hi = min(2*n-2, i+n-1)
        
        # b_other_max: max of b[k] for k outside [k_lo, k_hi]
        b_other_max = 0.0
        if k_lo > 0:
            b_other_max = max(b_other_max, float(b[:k_lo].max()))
        if k_hi < 2*n-2:
            b_other_max = max(b_other_max, float(b[k_hi+1:].max()))
        
        # Precompute for affected k
        # For k != 2i: b_new[k] = (b[k] - 2*v*a[k-i]) + 2*a[k-i]*w = d_k + c_k*w
        # For k = 2i: b_new[k] = (b[k] - v^2) + w^2 = d_2i + w^2
        
        coeffs = []  # (c_k, d_k) for linear terms
        d_2i = None
        
        for k in range(k_lo, k_hi+1):
            ki = k - i
            if k == 2*i:
                d_2i = b[k] - v*v
            else:
                c_k = 2.0 * a[ki]
                d_k = b[k] - c_k * v
                coeffs.append((c_k, d_k))
        
        # Try candidate w values
        best_w = v
        best_sc = _score_from_parts(n, b_other_max, d_2i, coeffs, S_other, v)
        
        # Generate candidates
        if v > 1e-15:
            fracs = [0.0, 0.1, 0.25, 0.4, 0.6, 0.8, 1.25, 1.5, 2.0, 3.0]
            candidates = [f*v for f in fracs]
        else:
            candidates = [0.0, 0.01, 0.05, 0.1, 0.5]
        
        for w in candidates:
            if abs(w - v) < 1e-14:
                continue
            sc = _score_from_parts(n, b_other_max, d_2i, coeffs, S_other, w)
            if sc < best_sc - 1e-15:
                best_sc = sc
                best_w = w
        
        if abs(best_w - v) > 1e-14:
            # Update b and a
            for k in range(k_lo, k_hi+1):
                ki = k - i
                if k == 2*i:
                    b[k] = d_2i + best_w*best_w
                else:
                    b[k] += 2.0*(best_w - v)*a[ki]
            a[i] = best_w
            S = S_other + best_w
            improved = True
    
    return a, b, S, improved
```

And the score computation:
```python
def _score_from_parts(n, b_other_max, d_2i, coeffs, S_other, w):
    sum_new = S_other + w
    if sum_new < 0.01:
        return math.inf
    max_b = b_other_max
    if d_2i is not None:
        max_b = max(max_b, d_2i + w*w)
    for c_k, d_k in coeffs:
        val = d_k + c_k * w
        if val > max_b:
            max_b = val
    if max_b < 0:
        max_b = 0.0
    return 2.0 * n * max_b / (sum_new * sum_new)
```

This is O(n * affected_k) per round = O(n^2) per round. For n=352, that's ~124K * 10 (avg candidates) = 1.2M per round. Very fast!

Let me also add a subgradient method as an alternative to LP:

The subgradient of `max_k b_k` with respect to `a_j` is:
`sum_{k: b_k = max} ∂b_k/∂a_j`

`∂b_k/∂a_j = a[k-j]` (if k-j valid) + `a[j]` (if k-j ≠ j and k-j valid, from the other term) + `2a[j]` (if k = 2j).

Wait, more carefully:
`b_k = sum_m a[m] a[k-m]`
`∂b_k/∂a_j`:
- Term m=j: `a[k-j]` (if 0 <= k-j < n)
- Term k-m=j, i.e., m=k-j: `a[j]` (if 0 <= k-j < n and k-j ≠ j)
- If k-j = j (i.e., k=2j): the term is `a[j]^2`, derivative is `2a[j]`

So `∂b_k/∂a_j = a[k-j] + a[j]` (if k-j ≠ j and both valid) or `2a[j]` (if k=2j) or `a[k-j]` (if only one term valid) or 0.

This gives a subgradient direction. We can do projected gradient descent:
`a_new = project(a - lr * subgrad)`

where project onto {a >= 0, sum(a) = 1} (or just {a >= 0} since score is scale-invariant).

Actually, since the score is scale-invariant, we can work on the simplex {a >= 0, sum(a) = 1} and minimize `max_k b_k`.

Let me also think about the LP more carefully. The LP is:
max sum(g) s.t. (f*g)_k <= M for all k, g >= 0.

The constraint matrix A has A[k,j] = f[k-j] if 0 <= k-j < n, else 0.
This is a Toeplitz-like matrix. For n=352, it's 693 x 352 ≈ 244K entries. Solvable with HiGHS in a few seconds.

For larger n, this could be slow. Let's stick with n around 352-512.

```python
import numpy as np
import time
import math
from scipy.fft import rfft, irfft, next_fast_len
from scipy.optimize import linprog

def _get_parent():
    try:
        h = globals()["height_sequence_1"]
        p = np.asarray(h, dtype=np.float64).ravel()
    except Exception:
        p = np.ones(198, dtype=np.float64)
    if p.size == 0:
        p = np.ones(198, dtype=np.float64)
    p = np.clip(p, 0.0, 1000.0)
    p = np.where(np.isfinite(p), p, 0.0)
    if p.size == 0:
        p = np.ones(198, dtype=np.float64)
    return p

def _conv_full(a):
    n = len(a)
    if n <= 800:
        c = np.convolve(a, a, mode="full")
        np.maximum(c, 0.0, out=c)
        return c
    fsize = next_fast_len(2 * n - 1)
    F = rfft(a, fsize)
    c = irfft(F * F, fsize)[:2 * n - 1]
    np.maximum(c, 0.0, out=c)
    return c

def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 0.01:
        return math.inf
    b = _conv_full(a)
    m = float(b.max())
    if not math.isfinite(m) or m < 0:
        return math.inf
    return 2.0 * n * m / (s * s)

def _build_A(f, n):
    A = np.zeros((2 * n - 1, n), dtype=np.float64)
    for j in range(n):
        A[j:j + n, j] = f
    return A

def _lp_direction(f, n, M, timeout=6.0):
    if M <= 1e-18:
        return None
    A = _build_A(f, n)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M + 1e-15)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(
            c, A_ub=A, b_ub=b_ub, bounds=bounds, method="highs",
            options={"presolve": True, "time_limit": timeout}
        )
    except Exception:
        return None
    if res.status != 0 or res.x is None:
        return None
    g = np.asarray(res.x, dtype=np.float64)
    g = np.clip(g, 0.0, 1e6)
    if g.sum() < 1e-15:
        return None
    return g

def _lp_optimize(f0, n, stop_time, seed):
    rng = np.random.default_rng(seed)
    f = np.clip(np.asarray(f0, dtype=np.float64).ravel()[:n].copy(), 0, None)
    while f.size < n:
        f = np.concatenate([f, np.zeros(n - f.size)])
    f = f[:n]
    f_sum = float(f.sum())
    if f_sum < 1e-10:
        f = np.ones(n)
        f_sum = n

    target_sum = math.sqrt(2.0 * n)
    f = f / f_sum * target_sum

    best_f = f.copy()
    best_score = _score(f)

    t = 0.3
    t_min = 0.02
    t_max = 0.9
    stall = 0
    max_stall = 200
    conv_thresh = 1e-10
    iteration = 0

    while time.monotonic() < stop_time - 5.0:
        iteration += 1
        b = _conv_full(f)
        M = float(b.max())
        if M < 1e-18:
            break

        g = _lp_direction(f, n, M, timeout=5.0)
        if g is None:
            stall += 5
            if stall > max_stall:
                f = best_f + rng.normal(0, 0.05 * max(1.0, best_f.mean()), n)
                f = np.clip(f, 0, None)
                fs = f.sum()
                if fs > 1e-10:
                    f = f / fs * target_sum
                else:
                    f = best_f.copy()
                stall = 0
                max_stall += 100
                t = 0.3
            continue

        g_sum = float(g.sum())
        if g_sum < 1e-15:
            stall += 3
            continue
        g = g * (target_sum / g_sum)

        dist = float(np.linalg.norm(g - f)) / max(1.0, float(np.linalg.norm(f)))
        if dist < conv_thresh:
            stall += 3
            if stall > max_stall:
                f = best_f.copy()
                idx = rng.choice(n, size=min(15, n), replace=False)
                for k in idx:
                    f[k] = max(0.0, f[k] * rng.uniform(0.2, 3.0))
                fs = f.sum()
                if fs > 1e-10:
                    f = f / fs * target_sum
                stall = 0
                max_stall += 100
                t = 0.3
            continue

        improved = False
        candidates = sorted(
            {max(t_min, min(t_max, c)) for c in
             [t, t * 0.5, t * 0.75, t * 1.25, t * 1.5, 0.1, 0.3, 0.5, 0.7, 1.0]},
            reverse=True
        )
        for tc in candidates:
            f_new = (1.0 - tc) * f + tc * g
            f_new = np.clip(f_new, 0, None)
            fs_new = float(f_new.sum())
            if fs_new < 0.01:
                continue
            f_new = f_new / fs_new * target_sum
            sc = _score(f_new)
            if sc < best_score - 1e-12:
                f = f_new.copy()
                best_f = f.copy()
                best_score = sc
                improved = True
                t = min(t_max, tc * 1.2)
                stall = 0
                break

        if not improved:
            stall += 1
            t = max(t_min, t * 0.6)
            if stall >= max_stall:
                f = best_f.copy()
                strength = 0.1
                f += rng.normal(0, strength * max(1.0, best_f.mean()), n)
                f = np.clip(f, 0, None)
                fs = f.sum()
                if fs > 1e-10:
                    f = f / fs * target_sum
                else:
                    f = best_f.copy()
                stall = 0
                max_stall += 80
                t = 0.3

    return best_f, best_score

Now for the fast coordinate descent:

```python
def _score_parts(n, b_other_max, d_2i, c_arr, d_arr, S_other, w):
    """Compute score from precomputed parts for coordinate change."""
    sum_new = S_other + w
    if sum_new < 0.01:
        return math.inf
    max_b = b_other_max
    if d_2i is not None:
        vb = d_2i + w * w
        if vb > max_b:
            max_b = vb
    if len(c_arr) > 0:
        vals = d_arr + c_arr * w
        vm = float(vals.max())
        if vm > max_b:
            max_b = vm
    if max_b < 0:
        max_b = 0.0
    return 2.0 * n * max_b / (sum_new * sum_new)

def _coord_descend(a, n, stop_time, seed=0):
    """Fast coordinate descent using analytic deltas."""
    rng = np.random.default_rng(seed)
    a = np.clip(a.copy(), 0, None)
    S = float(a.sum())
    if S < 1e-10:
        return a, math.inf
    b = _conv_full(a)
    
    target_sum = math.sqrt(2.0 * n)
    a = a / S * target_sum
    S = target_sum
    b = _conv_full(a)
    
    best_sc = _score(a)
    best_a = a.copy()
    
    no_imp_rounds = 0
    max_no_imp = 30
    fracs = [0.0, 0.1, 0.2, 0.35, 0.5, 0.65, 0.8, 1.2, 1.5, 2.0, 3.0, 0.05, 0.9, 1.1]
    
    while time.monotonic() < stop_time - 5.0 and no_imp_rounds < max_no_imp:
        improved = False
        S = float(a.sum())
        b = _conv_full(a)
        
        order = rng.permutation(n)
        for i in order:
            if time.monotonic() > stop_time - 5.0:
                break
            v = a[i]
            S_other = S - v
            k_lo = i
            k_hi = min(2 * n - 2, i + n - 1)
            
            # b_other_max
            b_other_max = 0.0
            if k_lo > 0:
                b_other_max = max(b_other_max, float(b[:k_lo].max()))
            if k_hi < 2 * n - 2:
                b_other_max = max(b_other_max, float(b[k_hi + 1:].max()))
            
            # Precompute coefficients
            c_list = []
            d_list = []
            d_2i = None
            for k in range(k_lo, k_hi + 1):
                ki = k - i
                if k == 2 * i:
                    d_2i = b[k] - v * v
                else:
                    ck = 2.0 * a[ki]
                    dk = b[k] - ck * v
                    c_list.append(ck)
                    d_list.append(dk)
            
            c_arr = np.array(c_list) if c_list else np.array([])
            d_arr = np.array(d_list) if d_list else np.array([])
            
            best_w = v
            best_local_sc = _score_parts(n, b_other_max, d_2i, c_arr, d_arr, S_other, v)
            
            if v > 1e-15:
                candidates_w = [f * v for f in fracs]
            else:
                candidates_w = [0.0, 0.01, 0.05, 0.1, 0.5, 1.0]
            
            for w in candidates_w:
                if abs(w - v) < 1e-14:
                    continue
                w = max(0.0, w)
                sc = _score_parts(n, b_other_max, d_2i, c_arr, d_arr, S_other, w)
                if sc < best_local_sc - 1e-14:
                    best_local_sc = sc
                    best_w = w
            
            if abs(best_w - v) > 1e-14:
                # Update b in place
                for k in range(k_lo, k_hi + 1):
                    ki = k - i
                    if k == 2 * i:
                        b[k] = d_2i + best_w * best_w
                    else:
                        b[k] += 2.0 * (best_w - v) * a[ki]
                a[i] = best_w
                S
