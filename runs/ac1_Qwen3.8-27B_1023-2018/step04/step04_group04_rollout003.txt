Hmm, so it's not convex in the standard sense. The function (a*a)_k is not convex in a (it's a product of components). For example, (a*a)_1 = 2*a_0*a_1 is not convex.

Wait, actually, is it? (a*a)_k = sum_i a_i * a_{k-i}. For fixed k, this is a quadratic form in a. The Hessian of (a*a)_k with respect to a is:
H[j,l] = ∂²(a*a)_k/(∂a_j ∂a_l) = δ_{j+l,k} + δ_{j+l,k} = 2*δ_{j+l,k} (if j ≠ l)
or 2*δ_{j+l,k} if j = l and 2j = k.

Actually, (a*a)_k = sum_i a_i * a_{k-i}. This is a bilinear form: a^T Q_k a where Q_k has Q_k[i, k-i] = 1/2 and Q_k[k-i, i] = 1/2.

The Hessian is 2*Q_k, which has eigenvalues... Q_k is a permutation matrix (partial), so its eigenvalues are on the unit circle. The Hessian 2*Q_k is indefinite (has both positive and negative eigenvalues) unless k is such that Q_k is symmetric, which happens when k = 2j for some j.

So (a*a)_k is NOT convex in general. The max of non-convex functions is non-convex. So the problem is NON-CONVEX!

This explains why the LP-based approach in the parent works: at each iteration, given the current a, the function (a*a)_k is linear in g (the variable being optimized in the LP), so the LP is valid as a local approximation.

Actually, let me think about what pattern minimizes the max convolution. For a 0-1 sequence of length n with k ones:
- sum = k
- The convolution at lag m is the number of ways to write m as i+j where a_i = a_j = 1.
- We want to minimize max_m conv[m].

By Pigeonhole, sum_m conv[m] = k², and there are 2n-1 values of m, so the average conv value is k²/(2n-1) ≈ k²/(2n). The max is at least this average.

To minimize the max, we want the convolution to be as flat as possible. This is related to "flat functions" in additive combinatorics.

A random 0-1 sequence with density k/n will have conv[m] ≈ k²/n for most m, with fluctuations of order k^(3/2)/n^(1/2). For k = cn, the max conv ≈ c²n + O(cn^(1/2)), and the score ≈ 2n * c²n / (cn)² = 2. So random sequences don't help.

The key is to use STRUCTURED patterns. For example:

- Golomb rulers give minimal repetition of differences.

def _build_A(a, n):

    # This is a banded Toeplitz matrix
    A = np.zeros((2 * n - 1, n), dtype=np.float64)
    for j in range(n):
        A[j:j+n, j] = a
    return A

def _lp_directory(a, n, M, reg=0.0, timeout=5.0):

def _line_search(a, g, n, best_sc, max_evals=15):

    gs = g.sum()
