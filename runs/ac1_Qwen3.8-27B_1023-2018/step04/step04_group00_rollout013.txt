Actually, the issue is:
1. We have p with sum=1, conv c.
2. We change p[i] from v to x. New p has sum = 1 + (x-v).
3. New conv: affected entries change, unaffected don't.
4. But then we renormalize: p_new = p / (1+(x-v)).
5. Then conv_new = conv / (1+(x-v))^2 for ALL entries.
6. Score = 2*n * max(conv_new) = 2*n * max(conv) / (1+(x-v))^2

So the score computation in my grid is correct! I don't need to worry about the renormalization affecting the "unaffected" comparison because I'm computing the score after renormalization, which divides everything by (1+δ)^2.

Let me also think about the L-BFGS part. The issue with the "hard max" approach is that the gradient is only defined at the maximum. This can cause L-BFGS to get stuck. A better approach is to use a "soft max" - the log-sum-exp of the top few values, or a truncated log-sum-exp.

Actually, the previous program uses a log-sum-exp smoothing, which is better. Let me use that.

But the log-sum-exp over all 2n-1 values is expensive (O(n) per evaluation). For n=3072, that's 6143 values. With FFT being O(n log n), the log-sum-exp is comparable.

Alternative: use a "top-k" approach. Compute the top k values of the convolution, and use their log-sum-exp. This gives a smoother objective.

Actually, for the gradient, I can use:
- f = cmax + T * log(sum_i exp((c_i - cmax)/T) / (2n-1))
- df/dc_i = exp((c_i - cmax)/T) / sum_j exp((c_j - cmax)/T)
- df/dp = Jacobian(c) @ (df/dc)

The Jacobian of self-convolution is a Toeplitz matrix. For the cross-correlation approach:
- df/dp = 2 * circulant convolution of (df/dc) with p

This can be computed with FFT in O(n log n).

def _get_parent():

        h = globals()["height_sequence_1"]
        p = np.asarray(h, dtype=np.float64).ravel()
    except Exception:
        p = np.ones(384, dtype=np.float64)

def _conv_self(a):
    n = a.size
    L = 2 * n - 1
    size = next_fast_len(L)
    F = rfft(a, size)
    c = irfft(F * F, size)[:L]
    np.maximum(c, 0.0, out=c)
    return c


def _softmax(u):
    u = np.asarray(u, dtype=np.float64)
    m = float(u.max())
    z = u - m
    e = np.exp(z, dtype=np.float64)
    s = float(e.sum())
    if s < 1e-300 or not math.isfinite(s):
        return np.full(u.size, 1.0 / u.size, dtype=np.float64)
    return e / s


def _score_norm(p, c):
    n = p.size
    return float(2.0 * n * c.max())


def _score_full(a):
    a = np.asarray(a, dtype=np.float64).ravel()
    n = a.size
    if n == 0:
        return math.inf
    a = np.where(np.isfinite(a), a, 0.0)
    a = np.clip(a, 0.0, 1000.0)
    s = float(a.sum())
    if s < 0.01:
        return math.inf
    c = _conv_self(a)
    m = float(c.max())
    if not math.isfinite(m):
        return math.inf
    return float(2.0 * n * m / (s * s))
