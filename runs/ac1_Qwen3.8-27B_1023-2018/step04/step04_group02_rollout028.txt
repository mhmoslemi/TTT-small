Now for the parent with n=400, the score is 1.509. This is significantly below 2, confirming that the structure of the sequence matters a lot.

The key insight: we want to minimize the maximum of the full convolution, not just the center. The convolution has 2n-1 values, and we want them all to be as small and equal as possible (relative to the sum).

This is related to the "soap bubble" or "minimax" problem for convolutions.

Let me think about what the optimal structure looks like. For the score to be < 2, we need `max_b < s^2/n`. But `b[n-1] = sum a[i]*a[n-1-i]`. By C-S, `sum a[i]*a[n-1-i] <= ||a|| * ||a_rev|| = ||a||^2 = sum a[i]^2`. And `sum a[i]^2 >= s^2/n`. So we can't use C-S directly to bound `b[n-1]` from above in a useful way.

Actually, the trick is: if the sequence is "asymmetric" (not palindromic), then `b[n-1] = a · reverse(a)` can be much less than `||a||^2`. For example, if `a` is concentrated at one end, `a · reverse(a)` is small.

But then other convolution values might be large. The optimal balance is what we're searching for.

Key idea: The LP finds a direction `g` that maximizes `sum(g)` subject to `f*g <= M` and `g >= 0`. This is a valid subgradient direction for minimizing `max(f*f)` (or more precisely, for the problem of finding the "largest" sequence compatible with the current max level).

```python
def _smooth_objective_and_grad(a, tau):
    n = len(a)
    s = float(a.sum())
    if s < 0.01:
        return 1e10, np.zeros(n)
    b = _conv(a)
    # Numerically stable smax
    b_max = b.max()
    exp_b = np.exp((b - b_max) / tau)
    log_sum = tau * np.log(exp_b.sum()) + b_max
    w = exp_b / exp_b.sum()
    
    # Gradient of smax w.r.t. a
    # grad_smax[j] = sum_k w[k] * 2*a[k-j] (for valid k-j)
    # = full_conv[2n-2-j] where full_conv = convolve(2a, w[::-1], 'full')
    two_a = 2.0 * a
    full_conv = np.convolve(two_a, w[::-1], mode='full')
    grad_smax = full_conv[n-1:2*n-1][::-1]
    
    # Full objective gradient
    val = 2.0 * n * log_sum / (s * s)
    grad = 2.0 * n * (grad_smax * s - 2.0 * log_sum) / (s * s * s)
    
    return val, grad
```

Wait, I need to double-check this gradient formula. Let me verify:
- `f(a) = 2n * smax(b(a), tau) / s^2` where `s = sum(a)`
- `df/da_j = 2n * [d(smax)/da_j * s^2 - smax * 2s * 1] / s^4`
- `= 2n * [grad_smax_j * s^2 - 2*smax*s] / s^4`
- `= 2n * [grad_smax_j * s - 2*smax] / s^3`
