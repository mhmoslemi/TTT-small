**Approach: Iterative reweighted / water-filling**

The problem (after normalization) is:
$$\min_a \max_k (a*a)_k \quad \text{s.t.} \sum a = 1, a \geq 0$$

This is equivalent to:
$$\min_{a, M} M \quad \text{s.t.} (a*a)_k \leq M \forall k, \sum a = 1, a \geq 0$$

The KKT conditions at the optimum:
- For active constraints $(a*a)_k = M$: Lagrange multipliers $\lambda_k \geq 0$
- For inactive: $\lambda_k = 0$
- $\sum_k \lambda_k \frac{\partial (a*a)_k}{\partial a_m} + \mu - \nu_m = 0$ where $\mu$ is the multiplier for $\sum a = 1$ and $\nu_m$ for $a_m \geq 0$

The key insight: at the optimum, the weighted sum of gradients of active constraints should be constant (modulo the nonnegativity constraints).

**Algorithm: Active set method**
1. Start with current $a$, compute $M = \max(a*a)$, find active set $K = \{k : (a*a)_k \approx M\}$
2. Solve the system: find $a$ and $\lambda_k$ such that:
   - $(a*a)_k = M$ for $k \in K$
   - $\sum a = 1$
   - $\sum_{k \in K} \lambda_k \nabla_k (a*a) = \mathbf{1}$ (the gradient of the Lagrangian is constant)
   - $a \geq 0, \lambda \geq 0$
3. Update active set based on which constraints are violated
4. Iterate

            return float('inf')
        cand /= s
        return float(np.convolve(cand, cand).max())
    
    gr = (np.sqrt(5)-1)/2
    lo, hi = 0.0, 1.0
    c1 = hi - gr*(hi-lo)
    c2 = lo + gr*(hi-lo)

    best_t, best_f = c1, f1

            best_t, best_f = c1, f1
        if f2 < best_f:

def _conv_grad(a, k):
    """Gradient of (a*a)_k w.r.t. a."""
    n = len(a)
    grad = np.zeros(n)
    m = np.arange(n)
    km = k - m
    valid = (km >= 0) & (km < n)
    grad[valid] = a[km[valid]] + a[valid]
    return grad

But there's an issue: the gradient I'm computing is for $G_\epsilon(a) = 2nL/s^2$, which is NOT exactly the same as the log-sum-exp of the normalized convolution. Let me think...

Actually, for the purpose of optimization, what matters is that the gradient points in a direction that decreases the true objective $F(a) = 2n\max(a*a)/s^2$. For small $\epsilon$, $G_\epsilon$ is a good approximation of $F$, so its gradient should point in roughly the right direction.

The issue is that $G_\epsilon$ is not exactly scale-invariant (as I showed earlier), so the gradient has a component in the scale direction. But L-BFGS-B with box constraints $a \geq 0$ will naturally find a good scale, and I normalize at the end.

Actually, I realize I should just compute the gradient of the TRUE objective (not the log-sum-exp approximation) and use it. The true objective is $F(a) = 2n \max_k (a*a)_k / s^2$. Its subgradient at a point where constraint $k^*$ is active is:

$$\partial F(a)_m = \frac{2n}{s^2} (a_{k^*-m} + a_m) \cdot \mathbb{1}[0 \leq k^*-m < n] - \frac{4n (a*a)_{k^*}}{s^3}$$

This is what I had before. I can use this as a subgradient and implement a subgradient method (like Nesterov's) for the non-convex problem.

But actually, for L-BFGS-B, I need a smooth objective. The log-sum-exp is the standard way to get a smooth approximation. Let me just use it and not worry about the small scale-invariance error.
