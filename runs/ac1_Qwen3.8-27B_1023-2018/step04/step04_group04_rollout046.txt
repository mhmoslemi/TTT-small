The issue is that achieving a flat autocorrelation with real nonnegative sequences is very hard. The "flat" ideal requires:
- a[0]^2 = C (only one term)
- 2*a[0]*a[1] = C (two terms)
- 2*a[0]*a[2] + a[1]^2 = C (three terms)
- ...
- sum_{i=0}^{n-1} a[i]*a[n-1-i] = C (n terms)

For the first few:
a[0] = sqrt(C)
a[1] = C/(2*a[0]) = sqrt(C)/2
a[2] = (C - a[1]^2)/(2*a[0]) = (C - C/4)/(2*sqrt(C)) = 3C/(8*sqrt(C)) = 3*sqrt(C)/8

In general, a[k] = (C - sum_{i=1}^k a[i]*a[k-i]) / (2*a[0]) for k < n/2.

This is like the coefficients of a power series. Let's define A(x) = sum a[i] x^i. Then A(x)^2 = sum b[k] x^k, and we want b[k] = C for all k.

So A(x)^2 = C * sum_{k=0}^{2n-2} x^k = C * (1-x^{2n-1})/(1-x).

Thus A(x) = sqrt(C) * sqrt((1-x^{2n-1})/(1-x)).

For this to have nonnegative coefficients, we need the square root to have nonnegative coefficients. The function (1-x^{m})/(1-x) = 1 + x + x^2 + ... + x^{m-1} is a polynomial. Its square root... let's check.

For m=1: sqrt(1) = 1. Coeff: [1]. OK.
For m=2: sqrt(1+x) = 1 + x/2 - x^2/8 + ... not all positive!
For m=3: sqrt(1+x+x^2) = 1 + x/2 + x^2/8 - x^3/16 + ... mixed signs!

So the ideal "exactly flat" autocorrelation is NOT achievable with real nonnegative sequences (for n > 1). The square root of a polynomial with all positive coefficients does not generally have all positive coefficients.

This is the fundamental difficulty. The best we can do is approximate the flat autocorrelation while keeping all a[i] >= 0.

This is related to the theory of "flat-spot" sequences and "allpass" filters in signal processing.

Given this, the optimal sequence will have:
- Large a[0] and a[n-1] (boundary elements)
- Smaller interior elements
- The convolution will be "relatively flat" but with some peak at the edges

        F = rfft(a, fsize)

        if s < 0.005:
            return math.inf
        b = conv(a)
        m = float(b.max())
        if not math.isfinite(m):
            return math.inf
        return 2.0 * n * m / (s * s)

        a = np.clip(a, 0.0, None)
        s = a.sum()
        if s < 1e-15:
            return np.ones(n) / n
        return a / s

    A_buf = np.zeros((2 * n - 1, n), dtype=np.float64)

        A_buf.fill(0.0)
        for j in range(n):
            A_buf[j:j + n, j] = f_cur
        return A_buf

    def solve_lp(f_cur, M, timeout=2.0):
        A = fill_A(f_cur)
        c_obj = -np.ones(n)
        b_ub = np.full(2 * n - 1, M)
        try:

                          bounds=[(0.0, None)] * n,
                          options={'time_limit': timeout, 'presolve': True})
        except Exception:
            return None
        if res.status == 0 and res.x is not None:
            g = np.clip(res.x, 0, None)
            gs = g.sum()
            if gs > 1e-12:

        return None

        M = float(b.max())
        eps = max(1e-14, 1e-10 * M)
        active = np.flatnonzero(b >= M - eps)
        grad = np.zeros(n)
        for k in active:

            j_hi = min(k, n - 1)
            idx = k - np.arange(j_lo, j_hi + 1)
            grad[j_lo:j_hi + 1] += 2.0 * f_cur[idx]

        return grad, M
