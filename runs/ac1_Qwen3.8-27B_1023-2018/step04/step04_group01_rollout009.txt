Actually, let me think about this differently. The LP finds the best $g$ that keeps $f*g \leq M$. The idea is that $g$ "spreads out" the mass while keeping the convolution bounded. Then we interpolate toward $g$.

The convergence of this method depends on the "gap" between the current max and the LP's implied max. If the gap is small, the method converges.

```python
def _lp_step(f, M, n, time_limit=5.0):
    """One LP step: find g that maximizes sum(g) s.t. f*g <= M, g >= 0."""
    # Build constraint matrix
    A = np.zeros((2*n-1, n))
    for j in range(n):
        A[j:j+n, j] = f
    c_obj = -np.ones(n)
    b_ub = np.full(2*n-1, M)
    
    res = linprog(c_obj, A_ub=A, b_ub=b_ub,
                  bounds=[(0, None)]*n,
                  method='highs',
                  options={'time_limit': time_limit})
    
    if res.status != 0:
        return None
    return res.x
```

This builds a (2n-1) × n matrix. For n=400, that's 799×400 = 319,600 entries. The LP has 400 variables and 799 constraints. HiGHS should handle this in well under a second typically, but let's say 1-3 seconds.

Wait, I need to double-check the cross-correlation formula. For real signals:
$(a \star p)[i] = \sum_j a[j] p[j+i]$

Using DFT: $\text{DFT}(a \star p)[k] = \text{DFT}(a)[k] \cdot \overline{\text{DFT}(p)[k]} = A[k] \cdot \overline{P[k]}$

So $h1 = \text{IDFT}(A \cdot \overline{P})$, with zero-padding to length $N \geq n_a + n_p - 1$.

And $(p * a)[i] = \sum_j p[j] a[i-j]$, which is the standard convolution:
$h2 = \text{IDFT}(P \cdot A)$ with the same zero-padding.

So:
```python
N = next_fast_len(n + (2*n-1) - 1)  # = next_fast_len(3n - 2)
F_a = rfft(f, N)
F_p = rfft(p, N)
h1 = irfft(F_a * F_p.conjugate(), N)[:n]  # cross-correlation
h2 = irfft(F_p * F_a, N)[:n]  # convolution
grad_c = h1 + h2
```
