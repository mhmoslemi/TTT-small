Actually, for the ramp a[i]=i+1, the convolution is:
conv[k] = sum_{i=max(0,k-n+1)}^{min(k,n-1)} (i+1)(k-i+1)

For k < n: conv[k] = sum_{i=0}^{k} (i+1)(k-i+1)
This is a well-known sum: sum_{i=0}^{k} (i+1)(k+1-i)
Let m=k+1: sum_{i=1}^{m} i(m+1-i) = (m+1)sum(i) - sum(i²) = (m+1)m(m+1)/2 - m(m+1)(2m+1)/6
= m(m+1)[(m+1)/2 - (2m+1)/6] = m(m+1)(3m+3-2m-1)/6 = m(m+1)(m+2)/6

So for k < n: conv[k] = (k+1)(k+2)(k+3)/6

For k = n-1: conv = n(n+1)(n+2)/6

For k > n-1: the sum is truncated.
For k = n + j (j ≥ 0): conv[k] = sum_{i=j+1}^{n-1} (i+1)(k-i+1)
Let u = i-1, v = k-i, so u+v = k-1, u from j to n-2:
conv = sum_{u=j}^{n-2} (u+1)(k-j-u+1) = sum_{u=j}^{n-2} (u+1)(n-1-j-u+1) = sum_{u=j}^{n-2} (u+1)(n-j-u)
