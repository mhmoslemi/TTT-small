- `c[2i] + 2w*v + w^2`

The max of linear functions (in w) + one quadratic, all in the numerator, divided by (1+w)^2.

To find the minimum over w ≥ -v (and 1+w > 0, so w > -1):

Approach: The function is a ratio. Let's define g(w) = max(c_new[j]) and h(w) = (1+w)^2. We minimize g(w)/h(w).

At the optimum (if interior), either:
- Two or more constraints are active (the max is achieved by multiple j's, and their derivatives are equal)
- Or a single constraint is active and its derivative condition holds: g'(w)*h(w) - g(w)*h'(w) = 0

For a single active constraint j (linear in w): c[j] + 2w*p[j-i]
Derivative of (c[j]+2w*p[j-i])/(1+w)^2:
= [2*p[j-i]*(1+w)^2 - (c[j]+2w*p[j-i])*2(1+w)] / (1+w)^4
= [2*p[j-i]*(1+w) - 2*(c[j]+2w*p[j-i])] / (1+w)^3
= [2p[j-i] + 2w*p[j-i] - 2c[j] - 4w*p[j-i]] / (1+w)^3
= [2p[j-i] - 2c[j] - 2w*p[j-i]] / (1+w)^3
= [p[j-i] - c[j] - w*p[j-i]] / (1+w)^3

Setting to 0: p[j-i] - c[j] - w*p[j-i] = 0
=> w = (p[j-i] - c[j]) / p[j-i] = 1 - c[j]/p[j-i] (if p[j-i] > 0)

For the quadratic (j=2i): c[2i] + 2wv + w^2
Derivative of (c[2i]+2wv+w^2)/(1+w)^2:
= [(2v+2w)(1+w)^2 - (c[2i]+2wv+w^2)*2(1+w)] / (1+w)^4
= [(2v+2w)(1+w) - 2(c[2i]+2wv+w^2)] / (1+w)^3
= [2v+2w+2vw+2w^2 - 2c[2i]-4wv-2w^2] / (1+w)^3
= [2v + 2w + 2vw - 2c[2i] - 4wv] / (1+w)^3
= [2v - 2c[2i] + 2w - 2vw] / (1+w)^3
= [v - c[2i] + w(1-v)] / (1+w)^3

Setting to 0: w = (c[2i] - v) / (1-v) (if v < 1)

So the optimal w is either:
- At the boundary w = -v (i.e., p[i] = 0)
- At a candidate from one of the linear constraints: w_j = 1 - c[j]/p[j-i]
- At the candidate from the quadratic: w_q = (c[2i] - v) / (1-v)
- At a point where two constraints are "balanced" (their values are equal at the max)

The practical approach: 
1. Compute the current max and which j's are near the max.
2. Generate candidate w values from the formulas above for the top few j's.
3. Also include w=0 and w=-v (boundary).
4. Evaluate the score at each candidate and a few nearby points.
5. Pick the best.

def _lse_optimize(p, end_time, consider=None):
    n = p.size
    p = p / float(p.sum())
    
    conv_size = next_fast_len(2 * n - 1)
    cross_size = next_fast_len(3 * n - 2)
    conv_len = 2 * n - 1
    cross_len = 3 * n - 2
    
    def cfast(a):
        F = rfft(a, conv_size)
        c = irfft(F * F, conv_size)[:conv_len]
        np.maximum(c, 0.0, out=c)
        return c
    
    def xfast(pp, ww):
        F = rfft(pp[::-1], cross_size)
        G = rfft(ww, cross_size)
        c = irfft(F * G, cross_size)[:cross_len]
        q = c[n-1:2*n-1]
        np.maximum(q, 0.0, out=q)
        return q
    
    def softmax(u):
        m = float(np.max(u))
        e = np.exp(u - m)
        s = float(e.sum())
        if s < 1e-300:
            return np.full(n, 1.0/n)
        return e / s
    
    def p_to_u(pp):
        uu = np.log(np.maximum(pp, 1e-300))
        return uu - float(np.mean(uu))
    
    u = p_to_u(p)
    
    def lse_func(uu, T):
        pp = softmax(uu)
        c = cfast(pp)
        cmax = float(c.max())
        if not math.isfinite(cmax):
            return 1e100, np.zeros(n)
        if T <= 0:
            T = max(1e-300, 1e-4 * cmax)
        scaled = (c - cmax) / T
        exps = np.exp(scaled)
        sum_exp = float(exps.sum())
        if not math.isfinite(sum_exp) or sum_exp <= 0:
            w = np.zeros(c.size)
            w[int(np.argmax(c))] = 1.0
            f = cmax
        else:
            f = cmax + T * float(np.log(sum_exp / c.size))
            w = exps / sum_exp
        q = xfast(pp, w)
        gdp = 2.0 * q
        tdp = float(np.dot(pp, gdp))
        grad = pp * (gdp - tdp)
        grad = np.where(np.isfinite(grad), grad, 0.0)
        return float(f), grad
    
    stages = (
        (0.20, 0.15),
        (0.06, 0.20),
        (0.018, 0.25),
        (0.005, 0.25),
        (0.0015, 0.15),
    )
    
    start = time.monotonic()
    avail = float(end_time - start)
    if avail < 10:
        return p
    
    total_w = sum(wt for _, wt in stages)
    cum = 0
    for frac, wt in stages:
        now = time.monotonic()
        if now > end_time - 5:
            break
        cum += wt
        end_stage = min(end_time - 3, start + avail * (cum / total_w))
        if end_stage <= now + 2:
            continue

        cmax = float(c.max())
        T = max(1e-300, frac * cmax)
        
        maxit = 30
        opts = {"maxiter": maxit, "gtol": 1e-12, "ftol": 1e-15, "maxls": 20, "maxcor": 20, "maxdisp": 0, "disp": False}
        
        while time.monotonic() < end_stage - 2:
            try:
                res = minimize(lse_func, u, args=(T,), method="L-BFGS-B", jac=True, options=opts)
            except Exception:
                break
            if res.x is not None and np.all(np.isfinite(res.x)):
                u = np.asarray(res.x, dtype=np.float64)
                p_new = softmax(u)
                sc = _score(p_new)
                if math.isfinite(sc):
                    p = p_new / float(p_new.sum())
                    if consider:
                        consider(p)
            if getattr(res, "status", 1) == 0:
                break
    
    return p

                        cur_score = float(2.0 * n * c.max())
                        if cur_score < best_score_local:
                            best_score_local = cur_score
                            best_p_local = p.copy()
                        else:
                            p = best_p_local.copy()
                            c = _conv_fft(p)
                            cur_score = best_score_local
                    flat = 0
                else:
                    break
        
        sweep += 1
    
    # Final renormalize
    p = np.maximum(p, 0)
    ss = float(p.sum())
    if ss > 0:
        p /= ss
    
    if consider:
        consider(p)
