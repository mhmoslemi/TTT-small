目标是 minimize: $2n \cdot \max(\text{convolve}(a,a)) / (\sum a_i)^2$

其中 $a_i \geq 0$，$a_i \leq 1000$，$\sum a_i \geq 0.01$。

关键观察：
1. 这个函数关于 $a$ 的缩放是不变的（因为分子和分母都是2次齐次的）。所以我们可以在 $\sum a_i = 1$ 的简单模式下搜索，或者 $\sum a_i = \sqrt{2n}$ 等。
2. 实际上，如果我将 $a$ 替换为 $c \cdot a$，则 $\text{convolve}(ca, ca) = c^2 \text{convolve}(a,a)$，$\sum ca = c \sum a$，所以分数变为 $2n \cdot c^2 \max(\text{conv}) / (c^2 (\sum a)^2) = $ 原始分数。所以确实是缩放不变的。

3. 这意味着我们可以固定 $\sum a_i = 1$（或任何正数），然后 minimize $2n \cdot \max(\text{convolve}(a,a))$。

4. 由于 $\sum a_i = 1$ 且 $a_i \geq 0$，$\text{convolve}(a,a)$ 的第 $k$ 个元素是 $\sum_i a_i a_{k-i}$。特别地，$\sum_k (\text{convolve}(a,a))_k = (\sum a_i)^2 = 1$。

5. 所以 $\max(\text{convolve}(a,a)) \geq 1/(2n-1)$（因为总和为1，分布在 $2n-1$ 个位置）。

6. 因此下界是 $2n/(2n-1) \to 1$ 当 $n \to \infty$。

实际上，让我重新考虑。问题本质上是：在单纯形 $\{a \geq 0, \sum a = 1\}$ 上 minimize $\max_k (\text{convolve}(a,a))_k$。

这等价于 minimize $\|a * a\|_\infty$ subject to $a \geq 0$, $\|a\|_1 = 1$。

这是一个凸优化问题吗？$\|a*a\|_\infty = \max_k |a*a|_k$。由于 $a \geq 0$，$a*a \geq 0$，所以 $|a*a|_k = (a*a)_k$。但 $(a*a)_k$ 是关于 $a$ 的二次函数（不是线性的），所以 $\max_k (a*a)_k$ 不是凸函数。

实际上，$(a*a)_k = \sum_i a_i a_{k-i}$ 是 $a$ 的二次型，且由于 $a \geq 0$，它是凸的（Hessian 是半正定的？不一定...）

让我想：$(a*a)_k = \sum_{i+j=k} a_i a_j$。对于 $k$ 固定，这是 $a$ 的二次函数。其 Hessian 在 $a \geq 0$ 锥上... 

实际上 $\sum_{i+j=k} a_i a_j$ 的 Hessian 矩阵（关于 $a$）是：对于 $i,j$ 使得 $i+j=k$，$(H)_{ij} = (H)_{ji} = 1$（如果 $i \neq j$），$(H)_{ii} = 2$（如果 $2i=k$）。其他为 0。

这个 Hessian 矩阵是半正定的当且仅当... 嗯，对于 $k$ 固定，非零部分形成一个"带状"结构。让我具体看：

如果 $k$ 是偶数，$2i=k$ 有一个解 $i=k/2$，所以 $(H)_{k/2,k/2} = 2$，其他 $(H)_{ij} = 1$ 对于 $i+j=k, i \neq j$。

这形成一个完全图（在参与变量上），加上对角线额外 +1。这个矩阵是正定的（因为它是完全图的邻接矩阵 + 对角线）。

更具体地，如果参与变量是 $i_1, i_2, \ldots, i_m$（满足 $i_j + i_{m+1-j} = k$），那么 Hessian 的相应子矩阵是 $J + I$（$J$ 是全1矩阵），这是正定的。

所以每个 $(a*a)_k$ 在 $a \geq 0$ 上是凸的！因此 $\max_k (a*a)_k$ 也是凸的（凸函数的 max 是凸的）。

所以我们的问题是一个凸优化问题：
$$\min_a \max_k (a*a)_k \quad \text{s.t.} \quad a \geq 0, \sum a_i = 1$$

这可以通过凸优化求解！但变量有 $n$ 个，约束有 $2n-1$ 个（每个 convolution 位置一个不等式）。

引入辅助变量 $t$：
$$\min_{a,t} t \quad \text{s.t.} \quad (a*a)_k \leq t \;\forall k, \quad a \geq 0, \quad \sum a_i = 1$$

但 $(a*a)_k \leq t$ 是二次约束，不是线性的。所以这不是一个标准的二次规划。

但实际上，对于 $n \approx 400$，$\text{convolve}(a,a)$ 有 $2n-1 \approx 800$ 个分量，用 FFT 计算是 $O(n \log n)$。所以每步的计算量不大。

让我考虑 **Frank-Wolfe 算法**：

目标：minimize $f(a) = \max_k (a*a)_k$ s.t. $a \geq 0$, $\sum a = 1$。

Frank-Wolfe：
1. 计算 $f$ 在 $a$ 处的次梯度 $g \in \partial f(a)$。
2. 求解线性化子问题：$\min_{s \in \Delta} \langle g, s \rangle$，其中 $\Delta$ 是单纯形。
   最优解是 $s = e_j$ 其中 $j = \arg\min_i g_i$。
3. 更新：$a \leftarrow (1-\gamma) a + \gamma s$，其中 $\gamma \in [0,1]$。

这意味着每步我们只向一个顶点移动，即增加某个 $a_j$ 并减少其他分量。

但 $f(a) = \max_k (a*a)_k$ 的次梯度是什么？

$f(a) = \max_k h_k(a)$ 其中 $h_k(a) = \sum_{i+j=k} a_i a_j$。
$\nabla h_k(a) = 2 \cdot (a * \delta_k / 2)$... 

更具体地，$\partial (h_k)_i / \partial a_i = \sum_{j: i+j=k} a_j + \sum_{j: j+i=k} a_j$（但要小心对角项）。

实际上 $h_k(a) = \sum_{i=0}^{k} a_i a_{k-i}$（假设 $0 \leq k-i \leq n-1$）。
$\frac{\partial h_k}{\partial a_i} = a_{k-i} + a_{k-i}$（如果 $i \neq k-i$）或 $2a_i$（如果 $i = k-i$）。

等等，更准确：$h_k = \sum_{i: 0 \leq i \leq n-1, 0 \leq k-i \leq n-1} a_i a_{k-i}$。

$\frac{\partial h_k}{\partial a_m} = \sum_{i: i+m=k \text{ or } m+i=k} a_i$。

如果 $m + (k-m) = k$，所以 $i = k-m$ 是一个贡献，且 $m + i = k$ 意味着 $i = k-m$（同一个）。

等等，$h_k = \sum_i a_i a_{k-i}$。对 $a_m$ 求导：
$\frac{\partial h_k}{\partial a_m} = a_{k-m}$（来自 $i=m$ 项的导数）+ $a_{k-m}$（来自 $k-i=m$ 即 $i=k-m$ 项的导数）。

但如果 $m = k-m$（即 $2m=k$），这两项是同一个，所以 $\frac{\partial h_k}{\partial a_m} = 2a_m$。

否则 $\frac{\partial h_k}{\partial a_m} = 2a_{k-m}$（如果 $0 \leq k-m \leq n-1$），否则 0。

等等不对。让我重新来。

$h_k = \sum_{i=\max(0,k-n+1)}^{\min(k,n-1)} a_i a_{k-i}$

$\frac{\partial h_k}{\partial a_m}$：如果 $m$ 在求和范围内，那么 $a_m$ 出现在项 $a_m a_{k-m}$ 中。对 $a_m$ 求导得 $a_{k-m}$。

但如果 $k-m$ 也在求和范围内（即 $m' = k-m$ 也满足约束），那么 $a_m$ 还出现在项 $a_{k-m} a_m$ 中（即 $i = k-m$ 的项），对 $a_m$ 求导得 $a_{k-m}$。

所以：
- 如果 $m \neq k-m$（即 $2m \neq k$）且 $0 \leq k-m \leq n-1$：$\frac{\partial h_k}{\partial a_m} = 2a_{k-m}$
- 如果 $2m = k$：$\frac{\partial h_k}{\partial a_m} = 2a_m$
- 否则：0

注意 $2m = k$ 时 $k-m = m$，所以两种情况可以统一为：
$\frac{\partial h_k}{\partial a_m} = \begin{cases} 2a_{k-m} & \text{if } 0 \leq k-m \leq n-1 \\ 0 & \text{otherwise} \end{cases}$

当 $2m=k$ 时，$k-m=m$，所以 $2a_{k-m} = 2a_m$，一致。

所以 $\nabla h_k = 2 \cdot \text{reverse}(a)[\text{适当切片}]$... 

更准确地说，$(\nabla h_k)_m = 2 a_{k-m}$ if $0 \leq k-m \leq n-1$ else 0。

这等价于 $(\nabla h_k) = 2 \cdot (a \text{ 翻转后移位 k})$... 

实际上，如果定义 $\tilde{a} = (a_{n-1}, a_{n-2}, \ldots, a_0)$（$a$ 的翻转），那么 $(\nabla h_k)_m = 2\tilde{a}_{m-(k-(n-1))}$... 这变复杂了。

简单实现：对于 active set $\mathcal{A} = \{k : h_k(a) = \max\}$，次梯度是 $g = \frac{1}{|\mathcal{A}|}\sum_{k \in \mathcal{A}} \nabla h_k(a)$。

$(g)_m = \frac{2}{|\mathcal{A}|}\sum_{k \in \mathcal{A}} a_{k-m}$（如果 $0 \leq k-m \leq n-1$）。

这可以用 FFT 加速：对于每个 active $k$，$a_{k-m}$ 是 $a$ 翻转后偏移 $k$ 的版本。

或者，更直接地：
$g = \frac{2}{|\mathcal{A}|}\sum_{k \in \mathcal{A}} \text{flip\_shift}(a, k)$

其中 $\text{flip\_shift}(a, k)_m = a_{k-m}$ if valid else 0。

注意 $\text{flip\_shift}(a, k)$ 实际上是卷积 $a * \delta_{n-1}$ 然后移位... 不太对。

让我用更直接的方式：
$\text{flip\_shift}(a, k)_m = a_{k-m}$（if $0 \leq k-m \leq n-1$）

如果定义 $b = \text{flip}(a)$（即 $b_i = a_{n-1-i}$），那么 $a_{k-m} = b_{n-1-(k-m)} = b_{n-1-k+m}$。

所以 $\text{flip\_shift}(a, k)_m = b_{m + (n-1-k)}$（if valid index），即 $b$ 移位 $n-1-k$。

所以 $g = \frac{2}{|\mathcal{A}|}\sum_{k \in \mathcal{A}} \text{shift}(b, n-1-k)$

其中 $b = \text{flip}(a)$。

这可以用 FFT 或直接在循环中计算（如果 active set 不大的话）。

对于 Frank-Wolfe，每步：
1. 计算 $h = a * a$（FFT，$O(n \log n)$）
2. 找 active set
3. 计算次梯度 $g$（$O(|\mathcal{A}| \cdot n)$ 或 FFT）
4. 找 $\arg\min g_i$（$O(n)$）
5. 更新（$O(n)$）

总共每步 $O(n \log n + |\mathcal{A}| \cdot n)$。

对于 $n=414$，这很快。

Frank-Wolfe 的收敛率是 $O(1/t)$，要得到精度 $\epsilon$ 需要 $O(1/\epsilon)$ 步。对于从 2 降到 1.5，可能需要几百到几千步。每步几毫秒，所以总时间不会是问题。

- **自由步长（line search）**：每步做一维搜索找最优 $\gamma$。
- **加速版本**。

```python
import numpy as np
import time
import math
from scipy.fft import rfft, irfft, next_fast_len

def _fft_conv(a):
    """Compute a * a (full convolution) using FFT."""
    n = len(a)
    fsize = next_fast_len(2 * n - 1)
    F = rfft(a, fsize)
    c = irfft(F * F, fsize)[:2 * n - 1]
    np.maximum(c, 0.0, out=c)  # numerical safety
    return c

def _score(a):
    """Compute the AC1 score."""
    n = len(a)
    s = float(np.sum(a))
    if s < 0.01:
        return math.inf
    b = _fft_conv(a)
    m = float(np.max(b))
    return 2.0 * n * m / (s * s)

def _fw_step(a, gamma):
    """Frank-Wolfe step: move towards the best vertex."""
    n = len(a)
    b = _fft_conv(a)
    M = float(b.max())
    # Subgradient of max(a*a) at a
    # (grad h_k)_m = 2 * a_{k-m} if 0 <= k-m <= n-1
    # For active set, average the gradients
    eps = max(1e-14, 1e-10 * M)
    active = np.flatnonzero(b >= M - eps)
    
    g = np.zeros(n)
    for k in active:
        # (grad h_k)_m = 2 * a_{k-m} if 0 <= k-m <= n-1
        # i.e., m ranges from max(0, k-n+1) to min(k, n-1)
        # and the value is 2 * a_{k-m} = 2 * a_{k - m}
        lo = max(0, k - n + 1)
        hi = min(k, n - 1)
        for m in range(lo, hi + 1):
            g[m] += 2.0 * a[k - m]
    
    g /= len(active)
    
    # FW: find argmin of g (the linear minimization over simplex)
    j = int(np.argmin(g))
    
    # Line search
    best_gamma = gamma
    best_sc = _score(a)
    for try_g in [gamma, gamma*0.5, gamma*1.5, 0.05, 0.1, 0.2, 0.3, 0.5, 0.7, 0.9, 1.0]:
        try_g = min(1.0, max(0.001, try_g))
        a_try = (1 - try_g) * a + try_g * np.eye(n)[j]  # no, too expensive
        # Better: a_try = a.copy(); a_try -= try_g * a; a_try[j] += try_g
        # Actually: a_try = (1-try_g)*a + try_g*e_j
        a_try = a * (1 - try_g)
        a_try[j] += try_g
        sc = _score(a_try)
        if sc < best_sc:
            best_sc = sc
            best_gamma = try_g
    
    a_new = a * (1 - best_gamma)
    a_new[j] += best_gamma
    return a_new, best_sc
```

让我优化梯度计算。注意：
$g_m = \frac{2}{|\mathcal{A}|}\sum_{k \in \mathcal{A}} a_{k-m}$（if $0 \leq k-m \leq n-1$）

这等价于：对于翻转的 $a$（$b_i = a_{n-1-i}$），
$g_m = \frac{2}{|\mathcal{A}|}\sum_{k \in \mathcal{A}} b_{n-1-(k-m)} = \frac{2}{|\mathcal{A}|}\sum_{k \in \mathcal{A}} b_{m + (n-1-k)}$

令 $j_k = n-1-k$，则 $g_m = \frac{2}{|\mathcal{A}|}\sum_{k \in \mathcal{A}} b_{m + j_k}$

这是 $b$ 与 indicator of $\{j_k : k \in \mathcal{A}\}$ 的"cross-correlation"。可以用 FFT！

令 $c_j = 1$ if $j = n-1-k$ for some $k \in \mathcal{A}$, else 0。
则 $g_m = \frac{2}{|\mathcal{A}|} \sum_j c_j b_{m+j}$（适当处理边界）

这本质上是 $b$ 和 $c$ 的互相关。用 FFT：
$\text{correlation}(b, c)_m = \sum_j b_j c_{j+m}$

嗯，让我更仔细地定义。

$g_m = \frac{2}{|\mathcal{A}|} \sum_{k \in \mathcal{A}} a_{k-m}$（if $0 \leq k-m < n$）

令 $r = k - m$，则 $k = m + r$，$r$ 从... 当 $k$ 遍历 $\mathcal{A}$ 时，$r = k - m$。

所以 $g_m = \frac{2}{|\mathcal{A}|} \sum_{r: m+r \in \mathcal{A}} a_r$

这等价于：令 $d_k = 1$ if $k \in \mathcal{A}$ else 0。
$g_m = \frac{2}{|\mathcal{A}|} \sum_r a_r d_{m+r}$

这是 $a$ 和 $d$ 的 cross-correlation（非标准方向）。

用 FFT 计算 cross-correlation：
$\text{corr}(a, d)_m = \sum_r a_r d_{r+m}$

这等于 $\text{conv}(\text{flip}(a), d)_{n-1+m}$... 让我验证。

$\text{conv}(\text{flip}(a), d)_s = \sum_i \text{flip}(a)_i d_{s-i} = \sum_i a_{n-1-i} d_{s-i}$

令 $j = n-1-i$，$i = n-1-j$：
$= \sum_j a_j d_{s-n+1+j}$

设 $s = n-1+m$：
$= \sum_j a_j d_{m+j}$

正是我们要的！所以：
$g_m = \frac{2}{|\mathcal{A}|} \text{conv}(\text{flip}(a), d)_{n-1+m}$

其中 $d_k = 1$ if $k \in \mathcal{A}$ else 0。

用 FFT：
1. 计算 $d$ 的 FFT
2. 计算 $\text{flip}(a)$ 的 FFT
3. 相乘，IFFT
4. 取位置 $n-1+m$（$m = 0, \ldots, n-1$）

这是 $O(n \log n)$！

def _subgrad_from_active(a, active_set, M):
    """Compute subgradient of max(a*a) using active set, via FFT."""
    n = len(a)
    d = np.zeros(2 * n - 1)
    d[active_set] = 1.0
    flip_a = a[::-1].copy()
    
    fsize = next_fast_len(2 * n - 1 + (2 * n - 1) - 1)  # conv size of flip_a (len n) and d (len 2n-1)
    # Actually conv of two arrays of length n and 2n-1 has length n + 2n-1 - 1 = 3n-2
    fsize = next_fast_len(3 * n - 2)
    F_flip = rfft(flip_a, fsize)
    F_d = rfft(d, fsize)
    conv = irfft(F_flip * F_d, fsize)[:3 * n - 2]
    
    # conv[n-1+m] for m = 0, ..., n-1
    g = conv[n-1:n-1+n] * (2.0 / len(active_set))
    return g
```

import math

    F = rfft(a, fsize)
    c = irfft(F * F, fsize)[:2 * n - 1]
    np.maximum(c, 0.0, out=c)

def _project_simplex(v):
    """Project v onto the simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)

def _subgrad_maxconv(a):
    """Compute a subgradient of max(a*a) at a."""
    n = len(a)
    b = _fft_conv(a)
    M = float(b.max())
    eps = max(1e-14, 1e-10 * M)
    active = np.flatnonzero(b >= M - eps)
    
    n_active = len(active)
    d = np.zeros(2 * n - 1)
    d[active] = 1.0 / n_active
    flip_a = a[::-1].copy()
    
    # conv(flip_a, d) has length n + (2n-1) - 1 = 3n - 2
    fsize = next_fast_len(3 * n - 2)
    F1 = rfft(flip_a, fsize)
    F2 = rfft(d, fsize)
    conv = irfft(F1 * F2, fsize)[:3 * n - 2]
    
    # g_m = 2 * conv[n-1+m]
    g = 2.0 * conv[n - 1:n - 1 + n]
    return g, M, b

def _fw_optimize(a0, stop_time, verbose=False):
    """Frank-Wolfe optimization with line search."""
    n = len(a0)
    a = a0.copy()
    best_a = a.copy()
    best_sc = _score(a)
    gamma = 0.3
    
    for it in range(50000):
        if time.monotonic() > stop_time:
            break
        
        b = _fft_conv(a)
        M = float(b.max())
        eps = max(1e-14, 1e-10 * M)
        active = np.flatnonzero(b >= M - eps)
        
        # Compute subgradient
        n_active = len(active)
        d = np.zeros(2 * n - 1)
        d[active] = 1.0 / n_active
        flip_a = a[::-1].copy()
        fsize = next_fast_len(3 * n - 2)
        F1 = rfft(flip_a, fsize)
        F2 = rfft(d, fsize)
        conv = irfft(F1 * F2, fsize)[:3 * n - 2]
        g = 2.0 * conv[n - 1:n - 1 + n]
        
        # Find argmin of g
        j = int(np.argmin(g))
        
        # Check convergence
        if g[j] >= np.max(g) - 1e-10:
            break  # At (approximate) optimum
        
        # Line search
        best_gamma = 0.1
        best_sc_try = _score(a)
        for try_g in [gamma, gamma*0.5, gamma*1.5, 0.05, 0.1, 0.2, 0.3, 0.5, 0.7, 0.9]:
            try_g = min(1.0, max(0.001, try_g))
            a_try = a * (1 - try_g)
            a_try[j] += try_g
            sc = _score(a_try)
            if sc < best_sc_try:
                best_sc_try = sc
                best_gamma = try_g
        
        a = a * (1 - best_gamma)
        a[j] += best_gamma
        
        if best_sc_try < best_sc - 1e-12:
            best_sc = best_sc_try
            best_a = a.copy()
            gamma = min(0.95, best_gamma * 1.3)
        else:
            gamma = max(0.02, gamma * 0.6)
    
    return best_a, best_sc

def _sgd_optimize(a0, stop_time):
    """Projected subgradient descent."""
    n = len(a0)
    a = a0.copy()
    best_a = a.copy()
    best_sc = _score(a)
    lr = 0.1
    momentum = np.zeros(n)
    mu = 0.5
    
    for it in range(100000):
        if time.monotonic() > stop_time:
            break
        
        g, M, b = _subgrad_maxconv(a)
        # Normalize gradient for step size
        g_norm = np.linalg.norm(g)
        if g_norm < 1e-15:
            break
        
        # Subgradient of the objective (with sum=1 constraint handled by projection)
        # Actual objective: f(a) = max(a*a). Since we're on simplex, 
        # the subgradient w.r.t. a is just g (from the max part).
        # Step: a - lr * g, then project to simplex
        momentum = mu * momentum - lr * g / g_norm
        a_new = _project_simplex(a + momentum)
        
        sc = _score(a_new)
        if sc < best_sc - 1e-13:
            a = a_new
            best_a = a.copy()
            best_sc = sc
            lr = min(0.5, lr * 1.02)
        else:
            lr = max(0.001, lr * 0.95)
            a = _project_simplex(a - 0.5 * lr * g / g_norm)
    
    return best_a, best_sc

def _coord_descent(a0, stop_time, max_epochs=100):
    """Coordinate descent on the simplex."""
    n = len(a0)
    a = a0.copy()
    best_a = a.copy()
    best_sc = _score(a)
    rng = np.random.default_rng(12345)
    
    for epoch in range(max_epochs):
        if time.monotonic() > stop_time:
            break
        improved = False
        order = rng.permutation(n)
        for i in order:
            if time.monotonic() > stop_time:
                break
            orig = a[i]
            if orig < 1e-15:
                continue
            best_v = orig
            best_v_sc = best_sc
            for mult in [0.1, 0.3, 0.5, 0.7, 1.0, 1.3, 1.5, 2.0, 3.0, 0.0]:
                v = orig * mult if orig > 0 else 0
                # Keep sum = 1: redistribute (1-v) among other coordinates proportionally
                if v < 0 or v > 1:
                    continue
                a[i] = v
                # Redistribute remaining mass
                remaining = 1.0 - v
                others_sum = 1.0 - orig  # sum of other coordinates before change
                if others_sum < 1e-15:
                    a[i] = orig
                    continue
                # Scale others to sum to remaining
                mask = np.ones(n, dtype=bool)
                mask[i] = False
                a[mask] *= remaining / others_sum if others_sum > 0 else 0
                sc = _score(a)
                if sc < best_v_sc:
                    best_v_sc = sc
                    best_v = a.copy()
            if best_v_sc < best_sc - 1e-14:
                a = best_v.copy()
                best_sc = best_v_sc
                best_a = a.copy()
                improved = True
            else:
                a[i] = orig
                # Restore others
                remaining = 1.0
                mask = np.ones(n, dtype=bool)
                mask[i] = False
                # oops, need to save original a
                pass  # This is getting complicated; let me save a before the loop
    
    return best_a, best_sc

实际上，让我再想想 FW 的效率。FW 的 "argmin of g" 步骤意味着我们每次只增加一个坐标（向一个顶点移动）。对于 $n=414$，如果最优解的所有分量都为正（很可能），FW 需要很多步才能让所有分量都变成正的。

更好的 FW 变体：** sỹ** 或者用 "away-step FW"：
- 标准 FW：$a \leftarrow (1-\gamma)a + \gamma e_j$（向顶点 $e_j$ 移动）
- Away-step FW：$a \leftarrow (1-\gamma)a - \gamma e_k$（从已支撑的顶点 $e_k$ 离开），其中 $k = \arg\max_i a_i g_i$（在 $\text{supp}(a)$ 中）

Away-step FW 通常收敛更快。

但实现更复杂。让我先用标准 FW + 其他方法组合。

另一个想法：**直接求解 KKT 条件**

在最优解处，存在 $t$ 和 active set $\mathcal{A}$ 使得：
- $(a*a)_k = t$ for $k \in \mathcal{A}$
- $(a*a)_k \leq t$ for $k \notin \mathcal{A}$
- $a_i \geq 0$
- $\sum a_i = 1$
- KKT: 存在 $\lambda$（对 $\sum a = 1$ 的乘子）使得 $g_i = \lambda$ for $a_i > 0$，$g_i \geq \lambda$ for $a_i = 0$

其中 $g = \frac{1}{|\mathcal{A}|}\sum_{k \in \mathcal{A}} \nabla h_k(a)$。

这给出了一个非线性方程组。如果 active set 已知，可以用牛顿法求解。但 active set 不确定。

这变得很复杂。让我还是用迭代方法。

```python
import numpy as np
import time
import math
from scipy.fft import rfft, irfft, next_fast_len


def _fft_conv_sq(a):
    """Compute a*a (full linear convolution) efficiently."""
    n = len(a)
    fsize = next_fast_len(2 * n - 1)
    F = rfft(a, fsize)
    c = irfft(F * F, fsize)[:2 * n - 1]
    # Clamp small negatives from numerical error
    np.maximum(c, 0.0, out=c)
    return c


def _ac1_score(a, conv=None):
    """Compute AC1 score = 2n * max(a*a) / (sum(a))^2.
    If conv is precomputed, use it to save one FFT."""
    n = len(a)
    s = float(np.sum(a))
    if s < 1e-10:
        return float('inf')
    if conv is None:
        conv = _fft_conv_sq(a)
    m = float(np.max(conv))
    return 2.0 * n * m / (s * s)


def _subgrad(a, conv=None):
    """Return (g, M, conv) where g is a subgradient of max(a*a) at a.
    g is a vector of length n."""
    n = len(a)
    if conv is None:
        conv = _fft_conv_sq(a)
    M = float(np.max(conv))
    eps = max(1e-14, 1e-10 * M)
    active = np.flatnonzero(conv >= M - eps)
    n_act = len(active)
    
    # g_m = (2/n_act) * sum_{k in active} a_{k-m} (if 0 <= k-m < n)
    # = (2/n_act) * conv(flip(a), d)[n-1+m] where d[k]=1 if k in active
    d = np.zeros(2 * n - 1)
    d[active] = 1.0
    flip_a = a[::-1].copy()
    
    # conv of flip_a (len n) and d (len 2n-1) -> len n + 2n-1 - 1 = 3n-2
    fsize = next_fast_len(3 * n - 2)
    F1 = rfft(flip_a, fsize)
    F2 = rfft(d, fsize)
    conv_fd = irfft(F1 * F2, fsize)
    
    # conv_fd[n-1+m] for m = 0,...,n-1
    g = (2.0 / n_act) * conv_fd[n - 1:n - 1 + n]
    return g, M, conv


def _project_simplex(v):
    """Project onto {x >= 0, sum(x) = 1}."""
    n = len(v)
    if np.sum(v) <= 1.0 and np.all(v >= 0):
        # Already in simplex (or on boundary with sum < 1, which shouldn't happen)
        pass
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1.0)
    rho = np.max(np.nonzero(cond)[0]) if np.any(cond) else n - 1
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    proj = np.maximum(v - theta, 0.0)
    # Ensure exact sum = 1 (fix floating point)
    s = proj.sum()
    if s > 0:
        proj /= s
    return proj


def _fw_phase(a0, stop_time, max_iter=20000):
    """Frank-Wolfe with line search."""
    n = len(a0)
    a = a0.copy()
    best_a = a.copy()
    best_sc = _ac1_score(a)
    gamma = 0.3
    stagnation = 0
    
    for it in range(max_iter):
        if time.monotonic() > stop_time:
            break
        
        conv = _fft_conv_sq(a)
        M = float(np.max(conv))
        g, _, _ = _subgrad(a, conv)
        
        # FW direction: towards vertex with smallest g
        j = int(np.argmin(g))
        
        # Check if we're at (approximate) optimum: g_j >= max(g) - tol
        # This means the linear minimization gap is ~0
        gap = float(np.max(g) - g[j])
        if gap < 1e-10:
            break
        
        # Line search over gamma
        best_g = 0.1
        best_sc_ls = best_sc
        for try_g in [gamma, gamma * 0.5, gamma * 1.5, 0.05, 0.1, 0.2, 0.4, 0.6, 0.8]:
            try_g = min(1.0, max(0.001, try_g))
            a_try = a.copy()
            scale = 1.0 - try_g
            a_try *= scale
            a_try[j] += try_g
            sc = _ac1_score(a_try)
            if sc < best_sc_ls:
                best_sc_ls = sc
                best_g = try_g
        
        if best_sc_ls < best_sc - 1e-13:
            a = a.copy()
            a *= (1.0 - best_g)
            a[j] += best_g
            best_sc = best_sc_ls
            best_a = a.copy()
            gamma = min(0.9, best_g * 1.2)
            stagnation = 0
        else:
            gamma = max(0.01, gamma * 0.5)
            stagnation += 1
            if stagnation > 200:
                break
    
    return best_a, best_sc


def _sgd_phase(a0, stop_time, max_iter=50000):
    """Projected subgradient descent with momentum."""
    n = len(a0)
    a = a0.copy()
    best_a = a.copy()
    best_sc = _ac1_score(a)
    momentum = np.zeros(n)
    lr = 0.05
    mu = 0.7
    no_improve = 0
    
    for it in range(max_iter):
        if time.monotonic() > stop_time:
            break
        
        conv = _fft_conv_sq(a)
        g, M, _ = _subgrad(a, conv)
        gn = float(np.linalg.norm(g))
        if gn < 1e-15:
            break
        
        mg = momentum
        momentum = mu * momentum - lr * g / gn
        a_new = _project_simplex(a + momentum)
        
        sc = _ac1_score(a_new)
        if sc < best_sc - 1e-13:
            a = a_new
            best_a = a.copy()
            best_sc = sc
            lr = min(0.3, lr * 1.03)
            no_improve = 0
        else:
            no_improve += 1
            if no_improve > 100:
                lr = max(0.001, lr * 0.7)
            if no_improve > 1000:
                break
    
    return best_a, best_sc


def _coord_descent(a0, stop_time, seed=42, max_epochs=200):
    """Coordinate descent maintaining sum=1."""
    n = len(a0)
    a = a0.copy()
    best_a = a.copy()
    best_sc = _ac1_score(a)
    rng = np.random.default_rng(seed)
    no_epoch_improve = 0
    
    for epoch in range(max_epochs):
        if time.monotonic() > stop_time:
            break
        epoch_improved = False
        order = rng.permutation(n)
        for i in order:
            if time.monotonic() > stop_time:
                break
            orig = a[i]
            if orig < 1e-15:
                continue
            a_save = a.copy()
            others_sum = 1.0 - orig
            if others_sum < 1e-15:
                continue
            best_local = orig
            best_local_sc = best_sc
            for mult in [0.2, 0.5, 0.8, 1.2, 1.5, 2.0, 3.0, 0.05]:
                v = orig * mult
                if v < 0 or v > 0.9999:
                    continue
                a[i] = v
                rem = 1.0 - v
                mask = np.ones(n, dtype=bool)
                mask[i] = False
                a[mask] = a_save[mask] * (rem / others_sum)
                sc = _ac1_score(a)
                if sc < best_local_sc:
                    best_local_sc = sc
                    best_local = a.copy()
            if best_local_sc < best_sc - 1e-13:
                a = best_local.copy()
                best_sc = best_local_sc
                best_a = a.copy()
                epoch_improved = True
            else:
                a = a_save.copy()
        
        if epoch_improved:
            no_epoch_improve = 0
        else:
            no_epoch_improve += 1
            if no_epoch_improve >= 5:
                break
    
    return best_a, best_sc


def _get_parent():
    try:
        h = globals()["height_sequence_1"]
        p = np.asarray(h, dtype=np.float64).ravel()
    except Exception:
        p = np.ones(414, dtype=np.float64)
    if p.size == 0:
        p = np.ones(414, dtype=np.float64)
    p = np.clip(p, 0.0, 1000.0)
    p = np.where(np.isfinite(p), p, 0.0)
    if p.size == 0:
        p = np.ones(414, dtype=np.float64)
    return p


def propose_candidate(seed=42, budget_s=1300, **kwargs):

    best_score = _ac1_score(p_norm)  # Same as _ac1_score(parent) due to scale invariance

            if np.all(np.isfinite(a)) and np.all(a >= -1e-10) and a.sum() > 0.01:
                best_seq = np.clip(a, 0, 1000.0).copy()

```python
import numpy as np
import time
import math
from scipy.fft import rfft, irfft, next_fast_len


def _fft_conv(a):
    """Compute full linear convolution a*a via FFT."""
    n = len(a)
    fsize = next_fast_len(2 * n - 1)
    F = rfft(a, fsize)
    c = irfft(F * F, fsize)[:2 * n - 1]
    np.maximum(c, 0.0, out=c)
    return c


def _ac1_score(a):
    """Compute AC1 score = 2n * max(a*a) / (sum(a))^2."""
    n = len(a)
    s = float(np.sum(a))
    if s < 1e-10:
        return float('inf')
    b = _fft_conv(a)
    m = float(np.max(b))
    return 2.0 * n * m / (s * s)


def _subgrad(a, conv=None):
    """Return (g, M, conv): subgradient of max(a*a), its value, and convolution."""
    n = len(a)
    if conv is None:
        conv = _fft_conv(a)
    M = float(np.max(conv))
    eps = max(1e-14, 1e-10 * M)
    active = np.flatnonzero(conv >= M - eps)
    n_act = len(active)
    d = np.zeros(2 * n - 1)
    d[active] = 1.0
    flip_a = a[::-1].copy()
    fsize = next_fast_len(3 * n - 2)
    F1 = rfft(flip_a, fsize)
    F2 = rfft(d, fsize)
    conv_fd = irfft(F1 * F2, fsize)
    g = (2.0 / n_act) * conv_fd[n - 1:n - 1 + n]
    return g, M, conv


def _project_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1.0)
    if not np.any(cond):
        return np.ones(n) / n
    rho = int(np.max(np.nonzero(cond)[0]))
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    proj = np.maximum(v - theta, 0.0)
    s = proj.sum()
    if s > 1e-15:
        proj /= s
    else:
        proj = np.ones(n) / n
    return proj


def _fw_phase(a0, stop_time, max_iter=50000):
    """Frank-Wolfe with line search."""
    n = len(a0)
    a = a0.copy()
    best_a = a.copy()
    best_sc = _ac1_score(a)
    gamma = 0.25
    stall = 0

    for it in range(max_iter):
        if time.monotonic() > stop_time:
            break
        conv = _fft_conv(a)
        g, M, _ = _subgrad(a, conv)
        j = int(np.argmin(g))
        gap = float(np.max(g) - g[j])
        if gap < 1e-12:
            break
        best_g = gamma
        best_sc_ls = best_sc
        for tg in [gamma, gamma * 0.5, gamma * 1.5, 0.05, 0.1, 0.2, 0.4, 0.6, 0.85]:
            tg = min(1.0, max(0.001, tg))
            at = a * (1.0 - tg)
            at[j] += tg
            sc = _ac1_score(at)
            if sc < best_sc_ls:
                best_sc_ls = sc
                best_g = tg
        a = a * (1.0 - best_g)
        a[j] += best_g
