One more thought: the coordinate descent in the previous program was quite expensive (evaluating the full score for each multiplier). I can make it faster by only recomputing the convolution at the affected lags when changing one coordinate.

If we change $f_i$ by $\delta$:
- Only lags $k$ where $f_{k-i}$ appears in $(f*f)_k$ are affected
- $(f*f)_k$ depends on $f_i$ only through terms where $j=i$ (giving $f_i f_{k-i}$) or $k-j=i$ (giving $f_{k-i} f_i$)
- So $(f*f)_k$ changes by $\delta \cdot f_{k-i} + \delta \cdot f_{k-i} = 2\delta f_{k-i}$ for $0 \le k-i < n$
- Plus the "self" term: if $k-i = i$ (i.e., $k = 2i$), there's an additional $\delta^2$ term

Wait, more carefully:
$(f*f)_k = \sum_j f_j f_{k-j}$

If $f_i$ changes to $f_i + \delta$:
- Term $j=i$: was $f_i f_{k-i}$, now $(f_i+\delta) f_{k-i}$, change: $\delta f_{k-i}$
- Term $j=k-i$ (if different from $i$): was $f_{k-i} f_i$, now $f_{k-i}(f_i+\delta)$, change: $\delta f_{k-i}$
- If $k-i = i$ (i.e., $k=2i$): single term $f_i^2$, becomes $(f_i+\delta)^2$, change: $2f_i\delta + \delta^2$

So:
- If $k \neq 2i$: $\Delta (f*f)_k = 2\delta f_{k-i}$ (if $0 \le k-i < n$)
- If $k = 2i$: $\Delta (f*f)_k = 2f_i\delta + \delta^2$

The affected lags are $k \in [i, i+n-1]$ (where $k-i \in [0, n-1]$).

This means for a single coordinate change, I only need to update $n$ lags. For $n=352$, that's 352 additions per trial. Much faster than recomputing the full convolution.

- $j = k-i$ (if $k-i \neq i$): contributes $f_{k-i} \cdot t$

- For other $k$: $(f*f)_k = C_k$ (unchanged)

    for L in other_lengths:
        if time.monotonic() > phase3_end - 8.0:
            break
        stop_L = min(phase3_end - 5.0, time.monotonic() + time_per_len)
        init_L = np.interp(np.linspace(0, 1, L), np.linspace(0, 1, len(best_seq)), best_seq)
        try:
            res, sc = _gradient_optimize(init_L, L, stop_L - 5, seed + 50000 + L)
            if res is not None:
                _update_best(res, sc)
                if time.monotonic() < stop_L - 5.0:
                    res2, sc2 = _coord_polish(res, L, stop_L, seed + 60000 + L)
                    _update_best(res2, sc2)
        except Exception:
            pass

    # Phase 4: Aggressive coordinate descent polishing
    phase4_end = hard_deadline - 25.0
    if time.monotonic() < phase4_end - 20.0:
        try:
            res, sc = _coord_polish(best_seq, len(best_seq), min(phase4_end, t0 + budget * 0.85), seed=4242)
            _update_best(res, sc)
        except Exception:
            pass

    # Phase 5: Second polish with different seed
    if time.monotonic() < phase4_end - 15.0:
        try:
            res, sc = _coord_polish(best_seq, len(best_seq), phase4_end - 10, seed=88888)
            _update_best(res, sc)
        except Exception:
            pass

    # Phase 6: Final micro-polish (single coordinate golden section)
    if time.monotonic() < hard_deadline - 15.0:
        n_final = len(best_seq)
        S_target = math.sqrt(2.0 * n_final)
        f_fin = _project(best_seq.copy(), S_target)
        f_sc = float(_conv_full(f_fin).max())
        f_fin_score = 2.0 * n_final * f_sc / (S_target * S_target)
        rng_fin = np.random.default_rng(seed + 1)
        imp_count = 0
        for _ in range(5000):
            if time.monotonic() > hard_deadline - 15.0:
                break
            i = int(rng_fin.integers(n_final))
            orig = f_fin[i]
            for m in [0.0, 0.2, 0.5, 0.7, 1.3, 1.6, 2.5]:
                nv = orig * m if m > 0 else 0.0
                f_fin[i] = nv
                ns = f_fin.sum()
                if ns < 0.01:
                    f_fin[i] = orig
                    continue
                f_s = f_fin * (S_target / ns)
                M_v = float(_conv_full(f_s).max())
                s_v = 2.0 * n_final * M_v / (S_target * S_target)
                if s_v < f_fin_score - 1e-15:
                    f_fin = f_s.copy()
                    f_fin_score = s_v
                    imp_count += 1
                    break
            else:
                f_fin[i] = orig
            if imp_count > 100 and _ % 200 == 0:
                break
        _update_best(f_fin, f_fin_score)

    # Final validation with exact evaluator
    try:
        final_sc = float(evaluate_sequence([float(x) for x in best_seq]))
    except Exception:
        final_sc = math.inf

    if not math.isfinite(final_sc):
        # Fallback: try ones
        try:
            final_sc = float(evaluate_sequence([1.0] * 100))
        except Exception:
            final_sc = math.inf
        if not math.isfinite(final_sc):
            return [1.0]
        return [1.0] * 100

    best_score = final_sc

    # Ensure all values are finite, nonnegative, and within bounds
    result = []
    for x in best_seq:
        xv = float(x)
        if not math.isfinite(xv):
            xv = 0.0
        xv = max(0.0, min(1000.0, xv))
        result.append(xv)

    if len(result) == 0 or sum(result) < 0.01:
        result = [1.0]

    return result
