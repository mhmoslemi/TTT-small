    """Build the convolution matrix A where (A @ g)_k = (f*g)_k."""
    A = np.zeros((2 * n - 1, n), dtype=np.float64)
    for j in range(n):

        return None

Wait, for the uniform sequence, $(f*f)_k = (n-|k-(n-1)|)/n^2$, and the max is at $k = n-1$ with value $1/n = \sum f_j^2$. So all other terms are $\leq 1/n$, and the uniform sequence is feasible. Score = 2.

But we know we can do better than 2 (the parent gets 1.509). So the optimal sequence must be asymmetric!

For an asymmetric sequence, $(f*f)_0 = f_0^2$ can be small (if $f_0$ is small), while $(f*f)_{n-1} = \sum f_j f_{n-1-j}$ can also be made small by making the "anti-diagonal" products small.

This is the key insight: by making the sequence asymmetric, we can reduce the peak of the convolution below $1/n$ (in normalized sum=1 terms), leading to scores below 2.

So the optimal sequence is likely asymmetric, with the "mass" shifted to one side. This makes sense intuitively: if all the mass is on one side, the convolution doesn't have a large "overlap" in the middle.

Let me think about this more concretely. Suppose $f$ is concentrated in the first half:
$f = [c, c, \ldots, c, 0, \ldots, 0]$ where there are $m$ non-zero entries, each $= 1/m$, and $n - m$ zeros.

Then $(f*f)_k = (m-|k|)/m^2$ for $|k| < m$, and 0 otherwise.
Max is at $k=0$: value $= 1/m$.
$S = 1$, $n = n$.
Score = $2n/m$.

To minimize, we want $m$ as large as possible, so $m = n$ gives score 2 (the uniform case).

What if we use a tapered sequence in the first half?

Max is at $k=0$: $(f*f)_0 = w_0^2$.
