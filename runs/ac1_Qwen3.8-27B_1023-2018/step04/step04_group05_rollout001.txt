- For k = 2i (if in range): b[2i] + 2*delta*a[2i-i] + delta^2 = b[2i] + 2*delta*a[i] + delta^2

The new max is: max(max(b[outside]), max(b[inside] + 2*delta*a[inside-i]), b[2i] + 2*delta*a[i] + delta^2)

I can precompute max(b[outside]) = max of b at indices not in [i, i+n-1].

For the "inside" part, I need max of b[k] + 2*delta*a[k-i] for k in [i, min(i+n-1, 2n-2)], k != 2i.

This is a max of b[k] + 2*delta*a[k-i], which for a given delta is just a shifted/scaled version. I can compute this in O(n).

So the total cost of evaluating a candidate delta is O(n), and I don't need to modify b or a. This is cleaner.

```python
def _coord_eval(b, a, S, i, delta, n):
    """Compute new max conv value and score if a[i] -> a[i] + delta."""
    new_S = S + delta
    if new_S < 0.01:
        return math.inf, new_S
    
    lo = i
    hi = min(i + n, 2 * n - 1)
    
    # Unaffected max
    if lo > 0:
        unaff_left = float(b[:lo].max()) if lo > 0 else 0.0
    else:
        unaff_left = 0.0
    if hi < 2 * n - 1:
        unaff_right = float(b[hi:].max())
    else:
        unaff_right = 0.0
    unaff_max = max(unaff_left, unaff_right)
    
    # Affected: k in [lo, hi)
    k_arr = np.arange(lo, hi)
    ki_arr = k_arr - i  # in [0, n-1]
    
    # New values: b[k] + 2*delta*a[k-i]
    new_vals = b[lo:hi] + 2.0 * delta * a[ki_arr]
    
    # Correction for k = 2i
    if lo <= 2 * i < hi:
        idx_2i = 2 * i - lo
        new_vals[idx_2i] += delta * delta  # additional delta^2
    
    aff_max = float(new_vals.max())
    new_M = max(unaff_max, aff_max)
    new_score = 2.0 * n * new_M / (new_S * new_S)
    
    return new_score, new_M, new_S
```

This is O(n) per evaluation and doesn't modify anything.

```python
def _coord_descent(a, max_rounds=200, stop_time=None, seed=42):
    n = len(a)
    a = np.clip(a.copy(), 0, None)
    b = _conv(a).copy()
    S = float(a.sum())
    if S < 0.01:
        return a, math.inf
    rng = np.random.default_rng(seed)
    
    mults = [0.0, 0.05, 0.1, 0.2, 0.35, 0.5, 0.7, 0.85, 1.2, 1.5, 2.0, 3.0, 5.0]
    
    best_score = 2.0 * n * float(b.max()) / (S * S)
    
    for rnd in range(max_rounds):
        if stop_time and time.monotonic() > stop_time:
            break
        round_imp = 0
        order = rng.permutation(n)
        for i in order:
            old = a[i]
            best_delta = 0.0
            best_sc = best_score
            
            # Generate candidate deltas
            candidates = set()
            for m in mults:
                candidates.add(old * (m - 1.0))  # delta = new - old
            # Add some absolute-scale candidates
            scale = max(1e-3, S / n)
            for f in (-0.5, -0.2, -0.1, 0.1, 0.2, 0.5):
                candidates.add(f * scale)
            candidates.add(-old)  # set to 0
            
            for delta in candidates:
                nv = old + delta
                if nv < -1e-15:
                    continue
                nv = max(0.0, nv)
                delta = nv - old
                if abs(delta) < 1e-15:
                    continue
                sc, _, _ = _coord_eval(b, a, S, i, delta, n)
                if sc < best_sc - 1e-14:
                    best_sc = sc
                    best_delta = delta
            
            if best_delta != 0.0:
                # Apply update
                a[i] += best_delta
                S += best_delta
                # Update b
                lo = i
                hi = min(i + n, 2 * n - 1)
                k_arr = np.arange(lo, hi)
                ki_arr = k_arr - i
                b[lo:hi] += 2.0 * best_delta * a[ki_arr]
                # Wait, a[i] has been updated. For k-i == i, a[k-i] = a[i] is the NEW value.
                # But we want the OLD value. Let me correct.
                # Actually, for k-i != i, a[k-i] is unchanged, so it's correct.
                # For k-i == i (k = 2i), a[k-i] = a[i] = old + delta = new value.
                # The base update adds 2*delta*a_new[i] = 2*delta*(old + delta)
                # But correct increment is 2*delta*old + delta^2
                # Difference: 2*delta*old + delta^2 - 2*delta*(old + delta) = -delta^2
                if lo <= 2 * i < hi:
                    b[2 * i] -= best_delta * best_delta
                best_score = best_sc
                round_imp += 1
        
        if round_imp == 0:
            break
    
    return a, best_score
```
