- For `b_k`:
  - The terms involving `a[i]` in `b_k` are:
    - `a[i] * a[k-i]` (from j=i, valid when 0 ≤ k-i < n, i.e., i ≤ k ≤ i+n-1)
    - `a[k-i] * a[i]` (from j=k-i, valid when 0 ≤ k-i < n and k-i ≠ i)
  - If k = 2i: the term is `a[i]^2` (only one term since j=i=k-i)
  - If k ≠ 2i and i ≤ k ≤ i+n-1: the term is `2 * a[i] * a[k-i]`
  - Outside [i, i+n-1]: no terms involving `a[i]`

So:
- `b_k` for k in [i, min(2n-2, i+n-1)]:
  - If k == 2i: `b_k += new_val^2 - orig^2`
  - Else: `b_k += 2 * (new_val - orig) * a[k-i]`
- All other `b_k`: unchanged

The new max is `max(b.max(), max of unchanged b values)`. Since we're modifying a contiguous range of `b`, we need to recompute the max. For n=416, b has 831 elements, so `b.max()` is O(831) which is fast.
