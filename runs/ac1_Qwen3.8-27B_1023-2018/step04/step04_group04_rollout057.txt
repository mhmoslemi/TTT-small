```python
def _mw_step(f, eta):
    b = _fft_conv(f)
    M = b.max()
    eps = 1e-10 * M
    active = np.flatnonzero(b >= M - eps)
    
    # Gradient of max(f*g) w.r.t. g, averaged over active constraints
    # grad(i) = (1/|active|) * sum_{k in active} f_{k-i}
    grad = np.zeros(n)
    for k in active:
        i_lo = max(0, k - n + 1)
        i_hi = min(k, n - 1)
        idx = k - np.arange(i_lo, i_hi + 1)
        grad[i_lo:i_hi+1] += f[idx]
    grad /= len(active)
    
    # Multiplicative update
    g = f * exp(-eta * grad)
    g /= g.sum()
    return g
```

This is just 2 times the reversed-and-shifted f!

So the subgradient of h(f) = max_k (f*f)(k) is:
∇h(f) = (2/|A|) sum_{k in A} R_k(f)

where R_k(f)_j = f_{k-j} if 0 <= k-j < n, else 0.

This is easy to compute! For each active k, we add 2*f (reversed and shifted) to the gradient.

Now, the full objective is:
F(f) = 2n * h(f) / (sum(f))^2

The gradient of F is:
∇F(f) = 2n * [∇h(f) * (sum(f))^2 - h(f) * 2*(sum(f)) * 1] / (sum(f))^4
= 2n * [∇h(f) * sum(f) - 2*h(f)] / (sum(f))^3

But since we're projecting to the simplex (sum(f)=1), we can just use the projected gradient of h(f) (or equivalently, minimize h(f) on the simplex).

**Projected gradient method on the simplex:**

1. Normalize f to sum 1
2. Compute subgradient of h(f) = max(f*f)
3. Take a step: f' = f - eta * ∇h(f)
4. Project f' onto the simplex {x >= 0, sum(x) = 1}
5. Adaptive step size

This is O(n^2) per step (for the gradient) + O(n log n) for the projection. For n=414, this is very fast.

The simplex projection is: given z, find the closest point on {x >= 0, sum(x) = 1}. This is done by sorting z and finding the threshold.

A[k, j] = f[k-j] if 0 <= k-j < n, else 0

But (f*g)(k) = sum_j f[k-j] * g_j where f and g are both length-n sequences. The valid range of j for each k is j ∈ [max(0, k-n+1), min(k, n-1)].

def _fft_conv(a):
    n = len(a)
    fsize = next_fast_len(2 * n - 1)
    F = rfft(a, fsize)
    c = irfft(F * F, fsize)[:2 * n - 1]
    np.maximum(c, 0.0, out=c)
    return c


def _score(a):
    n = len(a)
    s = float(np.sum(a))
    if s < 0.01:
        return math.inf
    b = _fft_conv(a)
    m = float(b.max())
    if not math.isfinite(m):
        return math.inf
    return 2.0 * n * m / (s * s)


def _build_A(f, n):
    A = np.zeros((2 * n - 1, n), dtype=np.float64)
    for j in range(n):
        A[j:j + n, j] = f
    return A


def _lp_direction(f, n, M, timeout=3.0):
    A = _build_A(f, n)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds,
                      method='highs',
                      options={'presolve': True, 'time_limit': timeout})
    except Exception:
        return None
    if res.status != 0 or res.x is None:
        return None
    g = np.clip(np.asarray(res.x, dtype=np.float64), 0.0, None)
    if g.sum() < 1e-15:
        return None
    return g


def _project_simplex(z):
    n = len(z)
    u = np.sort(z)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not np.any(cond):
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(z - theta, 0.0)
