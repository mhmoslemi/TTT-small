If we define a'[j] = a[n-1-j] (reversed), then:
np.convolve(a, a')[k] = sum_j a[j]*a[n-1-(k-j)] = sum_j a[j]*a[n-1-k+j]

This is the cross-correlation, which for a⊛a (auto-correlation) is symmetric.

So the key point: np.convolve(a, a) is NOT symmetric in general. The maximum could be anywhere.

However, there's a relationship: np.convolve(a, a) = np.convolve(a_reversed, a_reversed) reversed. Let me check:
a = [1, 2, 3], a_rev = [3, 2, 1]
np.convolve(a_rev, a_rev) = [9, 12, 10, 4, 1]
Reversed: [1, 4, 10, 12, 9] = np.convolve(a, a). ✓

So if a is better, a_reversed is also better (same score). This gives us a symmetry to exploit: we can restrict to "half-symmetric" sequences or use the symmetry to reduce search space.

But for the LP, the constraint matrix changes with a, so we can't easily exploit this symmetry in the LP itself.

            try:
                res = linprog(-np.ones(nf), A_ub=Af,
                              b_ub=np.full(2 * nf - 1, Mf * (1 + 1e-12)),
                              bounds=[(0.0, None)] * nf, method='highs',
                              options={'time_limit': 5,
                                       'dual_feasibility_tolerance': 1e-14,
                                       'primal_feasibility_tolerance': 1e-14})
            except Exception:
                break
            if res.status != 0 or res.x is None:
                break
            gf = np.maximum(res.x, 0)
            gsf = gf.sum()
            if gsf < 1e-15:
                break
            gf /= gsf
            if float(np.max(np.abs(gf - af))) < 1e-14:
                break

            # Small step
            for t in [0.05, 0.1, 0.15, 0.2]:
                cand_f = np.maximum((1 - t) * af + t * gf, 0)
                csf = cand_f.sum()
                if csf < 1e-15:
                    continue
                cand_f /= csf
                vf = np.convolve(cand_f, cand_f).max()
                if vf < Mf * (1 - 1e-14):
                    af = cand_f
                    break

        final_sc = 2.0 * nf * np.convolve(af, af).max()
        if final_sc < best_score:
            best_score = final_sc
            best_a = af.copy()

    # === Final validation and return ===
    result_arr = np.clip(best_a, 0.0, 1000.0)
    result_list = [float(x) for x in result_arr]

    try:
        fs = float(evaluate_sequence(result_list))
        if not np.isfinite(fs):
            result_arr = np.ones(32)
            result_list = [1.0] * 32
    except Exception:
        result_arr = np.ones(32)
        result_list = [1.0] * 32

    return result_list
