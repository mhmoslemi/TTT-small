- x = current f[i]
- x values where the max switches between different k's
- x values where the derivative of T is zero

= 2n * [max_k'(...) * (S0+x) - 2 * max_k(...)] / (S0+x)^3

Setting to zero: max_k'(...) * (S0+x) = 2 * max_k(...)

This is the marginal condition. If the max is achieved by term k*, then:

            if sc < best_sc:

                best_x = x_try

            if ji == i:

            else:
