One more thought: the coordinate descent can be very effective for the final polishing. For each coordinate i:
- Fix all other f[j] for j ≠ i
- B[k] as a function of f[i] is: B[k](x) = B_rest[k] + 2x*f[k-i] (for k ≠ 2i) or B_rest[k] + 2x*f[i] + x^2 (for k = 2i)
- Score(x) = 2n * max_k B[k](x) / (S_rest + x)^2
- This is a 1D optimization problem

The max of piecewise quadratic functions divided by a quadratic is a non-trivial 1D function, but we can find its minimum by:
1. Evaluating on a grid
2. Refining with golden section search

Or more precisely, the function max_k B[k](x) / (S_rest + x)^2 is a ratio of a convex function (max of linears/quadratics) to a convex function, which is not necessarily convex. But for 1D, we can just do grid + refine.

Actually, B[k](x) = B_rest[k] + 2x*f[k-i] for k ≠ 2i is LINEAR in x.
B[2i](x) = B_rest[2i] + 2x*f[i] + x^2 is QUADRATIC in x.

So max_k B[k](x) is the max of (2n-2) linear functions and 1 quadratic function. This is a convex function of x.

The score is 2n * max_k B[k](x) / (S_rest + x)^2. The numerator is convex and the denominator is convex (and positive for x >= 0), so the ratio is not necessarily convex. But it is unimodal in practice (for the range of x we care about).

    r = idx[-1]
