Actually, let me reconsider the LP approach. The key issue is: after solving the LP and getting direction $g$, the mixture $(1-t)f + tg$ may not decrease the objective. The LP ensures $(f*g) \leq M$, but it doesn't ensure $(g*g) \leq M$ or $((1-t)f+tg)*((1-t)f+tg)) \leq M$.

For the mixture:
$((1-t)f+tg)*((1-t)f+tg))_k = (1-t)^2 (f*f)_k + 2t(1-t)(f*g)_k + t^2 (g*g)_k$

We know $(f*f)_k \leq M$ and $(f*g)_k \leq M$ (from the LP). For the mixture to have max $\leq M$, we need:
$(1-t)^2 M + 2t(1-t) M + t^2 (g*g)_k \leq M$
$(1-t+t^2) M + t^2 (g*g)_k \leq M$
$t^2 ((g*g)_k - M) \leq t^2 M$
$(g*g)_k \leq 2M$

So if $(g*g)_k \leq 2M$ for all $k$, the mixture has max $\leq M$ for any $t \in [0,1]$.

But we don't know if $(g*g)_k \leq 2M$. The LP only constrains $(f*g)_k$, not $(g*g)_k$.

So the improvement is not guaranteed. The line search handles this by checking the actual objective.

Let me now think about a **dual** approach. The dual of the LP is:
$\min M \sum_k y_k$

def _smoothed_grad(f, n, beta):
    """Compute gradient of smoothed objective: 2n * LSE(beta * (f*f)) / S^2."""
    b = _fft_conv(f)
    S = float(np.sum(f))
    # Log-sum-exp for numerical stability
    bm = b.max()
    bz = b - bm
    e = np.exp(bz * beta)
    LSE = bm + np.log(e.sum()) / beta
    # weights
    w = e / e.sum()
    # subgradient: weighted average of 2*T_k f
    grad = np.zeros(n)
    for k, wk in enumerate(w):
        if wk < 1e-14:
            continue
        klo = max(0, k - n + 1)
        khi = min(k, n - 1)
        if klo <= khi:
            idx = k - np.arange(klo, khi + 1)
            grad[klo:khi+1] += 2.0 * wk * f[idx]
    # Full gradient of F(f) = 2n * LSE / S^2
    # dF/df = 2n * (S^2 * grad_LSE - 2*LSE*S*1) / S^4
    #       = 2n * (S * grad_LSE - 2*LSE*1) / S^3
    F_sub = 2.0 * n * (S * grad - 2.0 * LSE * np.ones(n)) / (S ** 3)
    return F_sub

def _proj_grad_optimize(f0, n, stop_time, seed=42):

    f = np.maximum(f0, 0.0).astype(np.float64).copy()

    best_f = f.copy()
    best_sc = _score(f)

    beta = 50.0
    no_imp = 0

            break

        F_sub -= np.mean(F_sub)  # project out the all-ones direction

def _coord_descent(f0, stop_time, seed=42, max_sweeps=100):
    rng = np.random.default_rng(seed)
    f = np.maximum(f0, 0.0).astype(np.float64).copy()
    n = len(f)
    best_sc = _score(f)
    best_f = f.copy()
    
    for sweep in range(max_sweeps):
        if time.monotonic() > stop_time:
            break
        improved = False
        order = rng.permutation(n)
        for i in order:
            if time.monotonic() > stop_time:
                break
            orig = f[i]
            if orig < 1e-15:
                # Try setting to small positive
                candidates = [0.001, 0.01, 0.05]
            else:
                candidates = [0.0, orig*0.1, orig*0.3, orig*0.5, orig*0.7,
                             orig*1.3, orig*1.5, orig*2.0, orig*3.0]
            best_v = orig
            best_v_sc = best_sc
            for cv in candidates:
                f[i] = cv
                if f.sum() < 0.01:
                    f[i] = orig
                    continue
                sc = _score(f)
                if sc < best_v_sc:
                    best_v_sc = sc
                    best_v = cv
            f[i] = best_v
            if best_v_sc < best_sc - 1e-15:
                best_sc = best_v_sc
                best_f = f.copy()
                improved = True

For $k = 0$: $f_0^2 = M \Rightarrow f_0 = \sqrt{M}$
For $k = 1$: $2f_0 f_1 = M \Rightarrow f_1 = M/(2f_0) = \sqrt{M}/2$
For $k = 2$: $f_1^2 + 2f_0 f_2 = M \Rightarrow f_2 = (M - f_1^2)/(2f_0) = (M - M/4)/(2\sqrt{M}) = 3\sqrt{M}/8$

This recursive structure (if all $k$ were active) would determine $f$ completely. But not all $k$ are active - only the ones at the max.

If the active set is $\{k_1, k_2, \ldots, k_m\}$, we have $m$ quadratic equations in $n$ unknowns. For $m < n$, there's a family of solutions. We can find the one that minimizes $M$ (or equivalently, that makes the inactive $(f*f)_k$ as small as possible).

This is a system of quadratic equations, which can be solved by Newton's method.

Let me try this approach:
1. Identify the active set $A$ (where $(f*f)_k ≈ M$).
2. Set up the system: $(f*f)_{k_i} = M$ for $k_i \in A$, plus $\sum f = 1$.
3. Solve by Newton's method.
4. Check that $(f*f)_k ≤ M$ for all inactive $k$.
5. If not, add the most violated constraint to $A$ and repeat.

This is an active-set method for the quadratic constraints. It could be more efficient than the LP approach because it directly solves the system of equations.
