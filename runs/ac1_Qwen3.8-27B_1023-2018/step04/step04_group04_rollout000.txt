Let me think about the asymptotic behavior. For a "smooth" sequence a(x) = f(x/n) where f is a smooth function on [0,1]:
(a*a)_k ≈ n * ∫ f(t) f((t+k)/n - ... ) dt

Actually, for large n, (a*a)_k/n → ∫ f(x) f(x + k/n) dx (roughly).

The maximum of this autocorrelation is at k=0 (for nonnegative f), where it's ∫ f^2.

So max_b ≈ n * ∫ f^2, and (sum a)^2 ≈ n^2 * (∫ f)^2.
score ≈ 2n * n * ∫f^2 / (n^2 * (∫f)^2) = 2 * ∫f^2 / (∫f)^2.

This is the "thermodynamic" limit, and it equals 2 for f = 1 (uniform), and is > 2 for any other f (by Cauchy-Schwarz, ∫f^2 * ∫1 >= (∫f)^2, so ∫f^2/(∫f)^2 >= 1/n... wait, that's not right for continuous functions on [0,1]).

Actually, by Cauchy-Schwarz: (∫f)^2 <= ∫f^2 * ∫1 = ∫f^2 * 1 = ∫f^2. So ∫f^2/(∫f)^2 >= 1.
score >= 2 * 1 = 2.

Wait, that means in the continuous limit, the score is always >= 2?! But the discrete sequence achieves < 2!

The difference is the edge effects. In the discrete case, the autocorrelation at large lags has fewer terms, so the "effective" integral is smaller. The continuous limit doesn't capture the edge effects.

For a discrete sequence of length n, (a*a)_k has (k+1) terms for k < n and (2n-1-k) terms for k >= n. The "edge" lags have fewer terms, so the autocorrelation is naturally smaller there.

The key insight: for a sequence that is "concentrated" at one end (say, decreasing), the autocorrelation at the center lag (n-1) involves the product of the large values (at the start) with the small values (at the end), giving a smaller product than if the mass were evenly distributed.

But we also need to check that no other lag has a larger value. For a monotonically decreasing sequence, the peak might be at k=0 (where a_0^2 is large) or at some intermediate lag.

Let me also consider: can I formulate this as a SOCP or use a different solver? The problem min t s.t. (a*a)_k <= t, sum a = 1, a >= 0 is a QCQP. Each constraint (a*a)_k <= t is a quadratic constraint. This can be written as a rotated SOC constraint:
||[2*a_i; t - (a*i)^T a]|| <= t + (a*i)^T a (for each k)

Actually, (a*a)_k <= t can be written as: the quadratic form a^T Q_k a <= t where Q_k is a fixed matrix (the k-th shift matrix). This is not convex in general because Q_k may not be PSD.

Wait, Q_k for the autocorrelation: (a*a)_k = a^T Q_k a where Q_k has (Q_k)_{i,j} = 1 if i+j = k, i.e., Q_k is a permutation matrix (the anti-identity for k = n-1).

For k = n-1: Q_{n-1} is the anti-identity, and a^T Q_{n-1} a = sum a_i * a_{n-1-i}. This is NOT a convex quadratic form (the anti-identity matrix has eigenvalues ±1).

So the problem is non-convex in general. The LP relaxation approach is a practical way to handle this.
