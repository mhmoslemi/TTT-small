Actually, let me think about this problem from a different angle. The score is:

score = 2n * max_k b_k / S^2

where b_k = sum_j a_j * a_{k-j} (with zero-padding).

The maximum is typically at k = n-1 (the center) for symmetric-like sequences. Let's denote k* = argmax b_k.

For a small perturbation a -> a + ε*d (where d has zero sum to preserve S), the change in b_k is:
δb_k = 2 * sum_j a_j * d_{k-j} + O(ε^2)

So to decrease b_{k*}, we want d to be "anti-aligned" with a shifted by k*:
sum_j a_j * d_{k*-j} < 0

This means we want d_{k*-j} to be negative where a_j is large (and positive where a_j is small).

A simple "anti-peak" move:
- Find k* = argmax b_k
- For each j, set d_j = -a_{k*-j} (with zero-padding)
- Subtract a small multiple of d from a: a_j -= lr * a_{k*-j}
- Clip to non-negativity
- Renormalize

This is like a subgradient step for the max component.

def _subgrad_step(f, n, lr=0.01):
    b = _conv_full(f)
    kstar = int(np.argmax(b))
    # Gradient: d_j = f[kstar - j] (shifted)

    for j in range(n):
        k = kstar - j
        if 0 <= k < n:
            d[j] = f[k]
    f_new = np.clip(f - lr * d, 0, None)
    s = f_new.sum()
    if s > 1e-10:
        f_new /= s
    return f_new

def _conv(a):
    n = len(a)
    fs = next_fast_len(2*n - 1)
    F = rfft(a, fs)
    c = irfft(F*F, fs)[:2*n-1]
    np.maximum(c, 0, out=c)
    return c

def _sc(a):

    s = float(a.sum())

    m = float(_conv(a).max())
    if not math.isfinite(m): return math.inf
    return 2.0*n*m/(s*s)

    ti = np.where(b >= thr)[0]
    if len(ti) < 10:

    ks = ti.astype(np.int64)
    A = np.zeros((len(ks), n))
    ix = ks[:,None] - np.arange(n)[None,:]
    v = (ix >= 0) & (ix < n)
    A[v] = f[ix[v]]
    try:

    except:
        return None
    if r.status not in (0,3) or r.x is None: return None
    g = np.asarray(r.x, np.float64)
    gs = float(g.sum())
