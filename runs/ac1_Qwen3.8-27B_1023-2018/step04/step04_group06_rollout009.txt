2. For blend t: (1-t)*a + t*g convolved with itself = (1-t)^2 * b(a) + t(1-t) * b(a*g) + t^2 * b(g)
   where b(a*g) = convolve(a, g)

So I only need 3 convolutions total (b(a), b(g), b(a*g)) and then the line search is just evaluating a quadratic in t! This is a huge speedup.

Let me verify: ((1-t)*a + t*g) * ((1-t)*a + t*g)
= (1-t)^2 * (a*a) + (1-t)*t * (a*g) + t*(1-t) * (g*a) + t^2 * (g*g)
= (1-t)^2 * conv(a,a) + 2*t*(1-t) * conv(a,g) + t^2 * conv(g,g)

Yes! So the max over k of this expression is:
max_k [(1-t)^2 * (a*a)[k] + 2t(1-t) * (a*g)[k] + t^2 * (g*g)[k]]

This is the max of 2n-1 quadratic functions of t. It's a piecewise quadratic function. To find its minimum, I can:
1. Evaluate at a grid of t values (fast, just arithmetic on precomputed arrays)
2. Refine with golden section (each evaluation is O(2n))

With precomputed arrays, each line search evaluation is O(n) instead of O(n^2) for convolution. This is a massive speedup.

Let me implement this:

```python
def fast_line_search(a, g, c_aa, c_ag, c_gg):
    """
    Find t minimizing max_k [(1-t)^2*c_aa[k] + 2t(1-t)*c_ag[k] + t^2*c_gg[k]]
    where c_aa = conv(a,a), c_ag = conv(a,g), c_gg = conv(g,g)
    """
    n_c = len(c_aa)  # 2n-1
    
    def obj(t):
        return np.max((1-t)**2 * c_aa + 2*t*(1-t) * c_ag + t**2 * c_gg)
    
    # Coarse grid
    ts = np.linspace(0, 1, 31)
    vals = np.array([obj(t) for t in ts])
    best_t = ts[np.argmin(vals)]
    best_val = vals[np.argmin(vals)]
    
    # Golden section refinement
    lo = max(0, best_t - 0.03)
    hi = min(1, best_t + 0.03)
    for _ in range(40):
        if hi - lo < 1e-9:
            break
        m1 = lo + (hi-lo)/3
        m2 = hi - (hi-lo)/3
        if obj(m1) < obj(m2):
            hi = m2
        else:
            lo = m1
    
    best_t = (lo+hi)/2
    best_val = obj(best_t)
    return best_t, best_val
```

This is O(n) per evaluation and O(40*n) total for the fine search, vs O(40*n^2) for the naive approach. For n=281, this is about 11k operations vs 3.1M. Huge speedup.

With this, I can afford much finer line searches and more iterations overall.

        return A

            else:

        best_val = obj(best_t)

    def proj_grad_step(a, k_star, alpha):
        """One projected gradient step on max(a*a) at active lag k_star."""
        gl = a.size
        grad = np.zeros(gl)
        lo = max(0, k_star - gl + 1)

        s = grad.sum()
        if s < 1e-15:

            active = x_proj > 1e-12
            if np.all(np.abs(cand[active] - theta) < 1e-10) if r > 0 else True:

            if not r:
                break
            break
        return x_proj
