def _proj_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    # Sort v in descending order
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1)
    return np.maximum(v - theta, 0)

Now let me reconsider the optimization. The problem is:
minimize max_k c_k  s.t.  a >= 0, sum(a) = 1
where c_k = sum_i a[i]*a[k-i] (full convolution, k=0,...,2n-2)

And score = 2n * max_k c_k / 1 = 2n * max_k c_k.

The constraint sum(a)=1 is WLOG due to scale invariance.

Now, the FW / Nesterov approach I outlined should work. Let me also think about what structure the optimal solution might have.

For a perfectly flat autocorrelation, we'd need a "Barker-like" or "Golay-like" sequence, but with nonnegative entries. The constraint a >= 0 is very restrictive.

One family: a_i = 1 + δ*x_i where x_i ∈ {-1, 1} (Barker). Then a_i >= 0 requires 1 + δ*x_i >= 0, so |δ| <= 1. The autocorrelation would be (1+δ*x)*(1+δ*x) which has some structure.

Actually, for nonnegative sequences, a natural approach is to use a "flat-top" or "window" function with some perturbation to flatten the autocorrelation.

Let me think about the structure of the convolution matrix. For a sequence a of length n, the convolution c = a*a (full) can be written as:
c = T(a) * a where T(a) is a Toeplitz matrix with first column [a[0], a[1], ..., a[n-1]]^T and first row [a[0], 0, ..., 0].

Wait, that's not quite right. The full convolution of two length-n sequences is:
c_k = sum_i a[i]*b[k-i]

If we write b = a, then:
c = A(a) * a where A(a) is the (2n-1) x n matrix with A(a)[k,i] = a[k-i] if 0<=k-i<n, else 0.

This is the same as the "upper triangular" part of the Toeplitz matrix.

For the LP approach: fix a, find direction d (represented as g) such that:
a * g <= M (element-wise, for all k)
g >= 0
maximize sum(g)

This is the LP in the parent. The constraint a*g <= M is linear in g.

Now, let me think about a potentially better approach:

**Approach: Direct minimization of max_k c_k using a "semismooth Newton" or "bundle" method**

Since f(a) = max_k c_k is the max of smooth functions, its subgradient at a is:
∂f(a) = conv{∇c_k(a) : k ∈ K(a)}
where K(a) = {k : c_k(a) = max_j c_j(a)} is the active set.

If |K(a)| = 1 (single active lag), f is locally smooth and we can use Newton's method on that single quadratic.
If |K(a)| > 1, we need to handle the non-smoothness.

For the single-active-lag case: minimize c_{k*}(a) + penalty * sum(a) = 1.
c_{k*}(a) is a quadratic form: a^T T_{k*} a where T_{k*} is a symmetric (n x n) matrix (the Toeplitz matrix for lag k*).
The Hessian is 2*T_{k*}. If T_{k*} is positive definite, we can take a Newton step.

But T_{k*} might not be positive definite. Let me check: T_{k*} is the matrix such that c_{k*} = a^T T_{k*} a. For k*=n-1 (the "center"), T is the "reverse" (anti-diagonal) Toeplitz, which is a Hankel matrix. It might be indefinite.

1. **FW with line search**: Simple, effective for convex problems.
2. **Nesterov-accelerated subgradient**: Faster convergence.
3. **LP-based direction** (like parent) when available.
4. **Coordinate descent polish** at the end.
