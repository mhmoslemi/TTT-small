  - OR k-i = j, i.e., i = k-j is in the valid range: max(0, k-n+1) <= k-j <= min(n-1, k)
  
  If i = j is valid, the term is x[j] * x[k-j].
  If i = k-j is valid, the term is x[k-j] * x[j] = x[j] * x[k-j] (same!).
  
  If both i=j and i=k-j are valid (and j ≠ k-j, i.e., k ≠ 2j), then there are TWO terms, each x[j]*x[k-j].
  If j = k-j (k=2j), there's only ONE term: x[j]*x[j].
  
  So:
  - If k=2j and j is in the valid range: x[j] appears once, as x[j]^2. Change = v^2 - a^2.
  - If k≠2j and both i=j and i=k-j are valid: x[j] appears twice. Change = 2(v-a)*x[k-j].
  - If k≠2j and only one of i=j, i=k-j is valid: x[j] appears once. Change = (v-a)*x[k-j].
  
  But actually, i=j is valid iff max(0,k-n+1) <= j <= min(n-1,k), which simplifies to j <= k (since j < n) and j >= k-n+1 (i.e., k-j <= n-1).
  i=k-j is valid iff max(0,k-n+1) <= k-j <= min(n-1,k), which simplifies to k-j <= k (always) and k-j >= 0 (j <= k), and k-j <= n-1 (k-j < n), and k-j >= max(0,k-n+1) which is always true.
  
  So i=j is valid iff 0 <= j <= k AND k-j <= n-1, i.e., j <= k < j+n.
  i=k-j is valid iff 0 <= k-j <= k AND k-j >= k-n+1, i.e., j <= k and j >= k-n+1, i.e., k-n+1 <= j <= k.
  
  These are the same condition: max(0, k-n+1) <= j <= min(n-1, k).
  
  So when the condition holds:
  - If k = 2j: one term, x[j]^2. Change = v^2 - a^2.
  - If k ≠ 2j: two terms, 2*x[j]*x[k-j]. Change = 2*(v-a)*x[k-j].
  
  When the condition doesn't hold: no change.
  
  This means x[j] affects ac[k] for k in [j, j+n-1] (i.e., k from j to j+n-1). Plus by symmetry, ac[k] = ac[2n-2-k], but we're computing the full convolution so we need to handle each k separately.

Actually, for the coordinate descent, the score as a function of x_j (with all other coordinates fixed) is:
score(v) = 2n * max_k [ac_k + Δ_k(v)] / (S - x_j + v)^2

where Δ_k(v) is as I described above. The max is piecewise linear in v, and the denominator is (S' + (v-x_j))^2 where S' = S - x_j.

So score(v) = 2n * max_k [piecewise linear in v] / (S' + v - x_j)^2

This is a ratio of a piecewise-linear (convex) function to a quadratic function. It's not convex in general, but it's unimodal in the region where a single constraint is active.

For practical purposes, a golden section search over v ∈ [0, v_max] should work well, where v_max = max(2*x_j, 2*S/n) or some reasonable upper bound.

                    fc = fd

                    fd = sc_of(d)

                S_cur = S_base + v_opt

                best_x = x.copy()

                S_cur = S

    return best_x, best_sc
