We're at point a (normalized, sum=1). We want to find a direction d (also normalized, sum=1) such that the new point (1-t)*a + t*d has a lower score.

The LP: max sum(b) subject to (a*b)[k] <= M for all k, b >= 0.

The constraint (a*b)[k] <= M means: for each lag k, the "cross-correlation" of a with b at lag k is bounded by M.

Why does this help? If we move from a to d, the new self-convolution is:
((1-t)a + td) * ((1-t)a + td) = (1-t)²(a*a) + 2t(1-t)(a*d) + t²(d*d)

The (a*d) term is bounded by M (from the LP constraint). The (a*a) term has max = M (by definition). So the new max is bounded by:
(1-t)²*M + 2t(1-t)*M + t²*max(d*d) = M*(1-t)² + 2t(1-t)*M + t²*max(d*d)
= M*((1-t)² + 2t(1-t)) + t²*max(d*d)
= M*((1-t)(1-t+2t)) + t²*max(d*d)
= M*(1-t)(1+t) + t²*max(d*d)
= M*(1-t²) + t²*max(d*d)

So the new score is bounded by 2n * (M*(1-t²) + t²*max(d*d)).

If max(d*d) <= M (which is likely if d is a "good" direction), then the new score is <= 2n*M = current score. So the score doesn't increase.

But we want it to DECREASE. This happens when t > 0 and max(d*d) < M. The LP doesn't directly ensure that max(d*d) < M, but in practice, the direction d found by the LP tends to have a lower self-convolution peak.

The line search handles the actual improvement: it tries different t values and picks the best one.

    def _polish(a0, stop_time):
        """Gradient-based polishing using projected gradient on the simplex."""
        a = np.asarray(a0, dtype=np.float64).ravel().copy()
        a = np.maximum(a, 0.0)
        a /= a.sum()
        n = a.size
        loc = _sc(a)
        _upd(a)
        no_improve = 0

        while time.monotonic() < stop_time and no_improve < 50:
            conv = np.convolve(a, a)
            k_star = int(np.argmax(conv))

            # Gradient of max_k (a*a)[k] at k_star
            g = np.zeros(n)
            for j in range(n):
                idx = k_star - j
                if 0 <= idx < n:
                    g[j] = 2.0 * a[idx]

            # Try multiple step sizes with projected gradient
            improved = False
            for lr in (0.02, 0.01, 0.005, 0.002, 0.001):
                cand = a - lr * g
                # Project onto simplex {x >= 0, sum(x) = 1}
                cand = np.maximum(cand, 0.0)
                # Euclidean projection onto simplex
                u = np.sort(cand)[::-1]
                cssv = np.cumsum(u)
                rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1.0))[0]
                if len(rho) == 0:
                    continue
                rho = rho[-1]
                theta = (cssv[rho] - 1.0) / (rho + 1.0)
                cand = np.maximum(cand - theta, 0.0)
                cs = cand.sum()
                if cs < 1e-10:
                    continue
                cand /= cs
                s = _sc(cand)
                if s < loc * (1.0 - 1e-10):
                    a = cand
                    loc = s
                    _upd(a)
                    improved = True
                    break

            if not improved:
                no_improve += 1
                # Add small noise
                a = a + 0.01 * rng.standard_normal(n)
                a = np.maximum(a, 0.0)
                a /= a.sum()
                if _sc(a) < loc:
                    loc = _sc(a)
                    no_improve //= 2
                else:
                    a = a0.copy()
                    a = np.maximum(a, 0.0)
                    a /= a.sum()

        return a

    # === Main optimization schedule ===
    par_len = par.size if par is not None else 192
    avail = endTime - t0

    # Phase 1: Primary LP optimization at parent length (45% of time)
    p1_end = t0 + avail * 0.45
    if par is not None:
        _optimize(par, par_len, p1_end)
    else:
        _optimize(best[1], 192, p1_end)

    # Phase 2: Second LP pass at parent length with fresh perturbation (15%)
    p2_end = t0 + avail * 0.60
    if time.monotonic() < p2_end:
        a2 = best[1].copy()
        a2 = a2 * np.exp(0.1 * rng.standard_normal(a2.size))
        a2 = np.maximum(a2, 0.0)
        if a2.sum() > 0:
            a2 /= a2.sum()
        _optimize(a2, par_len, p2_end)

    # Phase 3: Try other lengths (15%)
    p3_end = t0 + avail * 0.75
    for nl in (128, 256, 160):
        if time.monotonic() >= p3_end:
            break
        _optimize(best[1], nl, p3_end - 5)

    # Phase 4: Gradient polish at best length (10%)
    p4_end = t0 + avail * 0.85
    if time.monotonic() < p4_end:
        _polish(best[1], p4_end)

    # Phase 5: Final LP polish (10%)
    if time.monotonic() < endTime - 5:
        _optimize(best[1], best[1].size, endTime - 5)

    # Final validation
    _upd(best[1])
    fin = best[1]
    v = evaluate_sequence([float(x) for x in fin])
    if not math.isfinite(v):
        return [1.0, 1.0]
    return [float(x) for x in fin]
