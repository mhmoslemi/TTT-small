Let me refine this further. The main issue with the LP method is that the line search picks the best t in a grid. A better approach:

After finding direction g, the new autocorrelation is:
(a*a)[k] where a = (1-t)f + tg
= (1-t)²(f*f)[k] + 2t(1-t)(f*g)[k] + t²(g*g)[k]

We know (f*f)[k] <= M and (f*g)[k] <= M (by LP constraint). So:
new_conv[k] <= (1-t)²M + 2t(1-t)M + t²(g*g)[k]
= M((1-t)² + 2t(1-t)) + t²(g*g)[k]
= M(1-t²) + t²(g*g)[k]
= M - t²(M - (g*g)[k])

So if (g*g)[k] < M for all k, the new convolution is bounded by M - t²(M - max(g*g)), which is less than M.

The actual peak is max_k [(1-t)²(f*f)[k] + 2t(1-t)(f*g)[k] + t²(g*g)[k]].

For the line search, I can compute this exactly for each t without doing a full convolution (just using the precomputed f*f, f*g, and g*g). But computing g*g is another convolution...

Actually, the three convolutions (f*f, f*g, g*g) can be computed in one FFT batch:
- FFT(f), FFT(g) → IFFT(|FFT(f)|²), IFFT(FFT(f)*FFT(g)), IFFT(|FFT(g)|²)

This is 3 IFFTs and 2 FFTs (or 1 FFT if we compute both F and G first). Very fast.

Then for any t, the new convolution is a quadratic in t:
new_conv[k] = A[k]*t² + B[k]*t + C[k]
where C = f*f, B = 2*(f*g), A = g*g

And we want to minimize max_k new_conv[k] over t ∈ [0,1].

This is a 1D optimization of a max of quadratics, which can be done with bisection or by finding the intersection points.

Let me implement this:

```python
# Compute FFTs once

G = rfft(g, fsize)

Bg = irfft(F*G, fsize)[:2*n-1]  # f*g (note: this is NOT symmetric)
A = irfft(G*G, fsize)[:2*n-1]  # g*g

# We want min_t max_k (A*k*t² + 2*Bg*k*t + C[k])

# The function is convex in t (max of convex functions).
# Use bisection on the derivative, or ternary search.

def obj(t):
    vals = A*t*t + 2*Bg*t + C
    return vals.max()

# Ternary search on [0, 1]

    m2 = hi - (hi-lo)/3

        hi = m2

        lo = m1
```

Let me also think about the active-set polishing more carefully.

At the LP fixed point (g ≈ f), the LP says: max sum(g) s.t. (f*g)[k] <= M, g >= 0 has optimum at g = f (normalized). This means f is a "self-dual" point: the maximum of (f*g) under the constraint (f*g) <= M is achieved by g = f itself.

This is related to the KKT conditions. At the optimum of the original problem:
- (f*f)[k] <= M for all k
- (f*f)[k] = M for k in S (active set)
- sum_k mu_k (f*f)[k] = mu_k M = ... 
- The gradient condition: sum_k mu_k * ∂(f*f)[k]/∂f[j] = lambda for all j
  i.e., sum_k mu_k * (f[j+k] + f[j-k]) = lambda for all j
- sum_k mu_k = 1
- sum_j f[j] = 1

The ∂(f*f)[k]/∂f[j] = f[j+k] + f[j-k] (with f[m]=0 outside [0,n-1]).

So the KKT system is:
(1) For each j: sum_{k in S} mu_k * (f[j+k] + f[j-k]) = lambda
(2) For each k in S: sum_j f[j]*f[j+k] = M (with appropriate bounds on j)
(3) sum_j f[j] = 1
(4) sum_{k in S} mu_k = 1
(5) f[j] >= 0, mu_k >= 0

This is a nonlinear system (equation 2 is bilinear in f). But if I fix mu, equation 1 gives a linear system in f. Then I check if equation 2 is satisfied.

Iterative scheme:
1. Start with current f, compute active set S = {k: (f*f)[k] > M - ε}
2. Solve for mu: minimize some objective subject to (1) and (4)
   Actually, (1) determines lambda and mu given f and S. 
   
   Rewrite (1): For each j, sum_k mu_k * T_k(f)[j] = lambda
   where T_k(f)[j] = f[j+k] + f[j-k].
   
   This is: (sum_k mu_k T_k) f = lambda * 1
   
   With sum(mu) = 1, the unknowns are mu (|S| variables) and lambda (1 variable).
   The equations are n (one per j). Plus sum(mu) = 1. Total: n+1 equations, |S|+1 unknowns.
   
   If |S| < n: underdetermined. We need additional conditions.
   If |S| = n: square system.
   If |S| > n: overdetermined.
   
   In practice, |S| might be large (many near-constraints). Let me handle this with least squares.

3. Given mu, solve (1) + (3) for f:
   (sum_k mu_k T_k) f = lambda * 1
   sum(f) = 1
   
   This is a linear system: [sum_k mu_k T_k | -1; 1' | 0] [f; lambda] = [0; 1]
   
   The matrix sum_k mu_k T_k is n×n. With n=192, this is small.

4. Check: (f*f)[k] for k in S should be ≈ M. If not, adjust S and repeat.

5. Check: f >= 0. If not, adjust (remove negative components from support).

This is essentially a Newton-like method on the KKT conditions. Let me implement it.
