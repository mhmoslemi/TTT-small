The rationale is that combinatorial approaches excel at finding globally optimal solutions for discrete structures, while gradient methods efficiently refine local minima. We address the mixed-integer nature of step-function coefficients by
        
1. Using mixed-integer linear programming (MILP) to prove lower-bounds for minimum AC1
2. Filling design gaps initially through gradient descent in continuous space
3. Utilizing combinatorial search to evaluate promising discrete configurations
4. Maintaining feasibility across different coefficient scales
5. Dynamically adjusting search intensity based on evaluation feedback

- Let C = maximum value across all linear convolution points (full operation) of a with itself
