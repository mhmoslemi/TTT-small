Wait, there's an important issue. The constraint A @ y <= M where A depends on a. When a changes, A changes, so we need to rebuild A and create a new LP each iteration. This overhead (creating the cvxpy problem) might be significant.

Alternative: Use scipy.optimize.linprog for the LP. It's faster for small problems and doesn't have the cvxpy overhead.

Let me use scipy.optimize.linprog:

```python
from scipy.optimize import linprog

def solve_lp_linprog(A, M, n):
    # max sum(y) s.t. A @ y <= M, y >= 0
    # linprog minimizes c @ x s.t. A_ub @ x <= b_ub, x >= lb
    c = -np.ones(n)  # minimize -sum(y)
    A_ub = A
    b_ub = np.full(2*n-1, M)
    bounds = [(0, None)] * n
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success:
        y = np.maximum(res.x, 0)
        s = y.sum()
        if s > 1e-12:
            return y / s
    return None

    return A
```

This creates a (2n-1, n) array of differences and then indexes. For n=192, that's a 383x192 = 73536 element array. Should take <1ms.

Actually, let me think about a different approach for the local search. The objective is f(a) = max_k conv[a,a][k]. The subgradient at a is:

For the "active set" K* = {k : conv[k] = M}, the subgradient is:

Let me also consider: what if we solve the LP and the solution g has sum(g) < 1? Then the "natural" step is to go towards g, but we want to maintain sum = 1. The LP as formulated maximizes sum(y) subject to constraints, so if the optimum has sum(y)* < 1 (after normalization), it means the constraints are very tight. If sum(y*) = 1, the LP constraint is feasible with full mass.

Actually, the LP is: max sum(y) s.t. A@y <= M, y >= 0. The objective value sum(y*) tells us how much "mass" we can put while keeping conv(a, y) <= M. If sum(y*) = 1, we can replace a with y entirely (full step). If sum(y*) < 1, we can only do a partial step.

Wait, but we normalize: g = y* / sum(y*). Then the step is a -> (1-t)*a + t*g. The question is what t to use.

If conv(a, g) <= M / sum(y*), then t=1 might work. But conv(a, (1-t)*a + t*g) is not simply (1-t)*conv(a,a) + t*conv(a,g) because conv is quadratic!

conv((1-t)*a + t*g, (1-t)*a + t*g) = (1-t)^2*conv(a,a) + 2t(1-t)*conv(a,g) + t^2*conv(g,g)

So even if conv(a,g) <= M, the t^2*conv(g,g) term might push it over. The line search handles this.

    _k_idx = np.arange(2 * n - 1)[:, None]
    _j_idx = np.arange(n)[None, :]
    _diff = _k_idx - _j_idx
    _valid = (_diff >= 0) & (_diff < n)
    _valid_rows, _valid_cols = np.where(_valid)
    _diff_vals = _diff[_valid].astype(np.int64)
    _num_valid = len(_valid_rows)

    def build_A(x):
        A = np.zeros((2 * n - 1, n), dtype=np.float64)
        A[_valid_rows, _valid_cols] = x[_diff_vals]
        return A

    def conv_self(x):
        F = rfft(x, fft_size)
        c = irfft(F * F, fft_size)[:2 * n - 1]
        np.maximum(c, 0.0, out=c)
        return c

    def solve_lp(A, M):
        c_obj = -np.ones(n)
        b_ub = np.full(2 * n - 1, M)
        bounds = [(0.0, None)] * n
        try:

                          options={'presolve': True, 'time_limit': 5.0})
            if res.success and res.x is not None:
                y = np.maximum(res.x, 0.0)
                s = y.sum()
                if s > 1e-12:
                    return y / s
        except Exception:
            pass
        return None

    def optimize_lp(a_start, dl):

        s = a.sum()
        if s < 1e-15:

                no_improve = 0
            else:

                a /= a.sum()
                no_improve = 0
                continue
            if no_improve > 1500 and iter_count > 200:
                break

            # Build A and solve LP
            A = build_A(a)
            g = solve_lp(A, M)

            if g is None:

                k_star = int(np.argmax(b))
                grad = np.zeros(n)
                for m in range(n):

                    if 0 <= j < n:
                        grad[m] = 2.0 * a[j]
                gn = np.linalg.norm(grad)
                if gn < 1e-15:

                g = np.maximum(a - 0.3 * grad / gn, 0.0)
                gs = g.sum()
                if gs < 1e-15:
