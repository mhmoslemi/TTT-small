The LP for n=192: the matrix A is 383×192. Building it takes O(n²) = ~37k operations. Solving the LP with 383 constraints and 192 variables should be fast (milliseconds with a good solver).

Let me think about the LP more carefully. The constraint is:
For each k in 0..2n-2: sum_j a[j] * g[k-j] ≤ M (where the sum is over valid j)

This is A@g ≤ M*ones, where A[k,j] = a[j] if 0≤k-j≤n-1, else 0. Wait, that's not right.

conv(a,g)[k] = sum_j a[j] * g[k-j] (where 0≤j<n and 0≤k-j<n)
= sum_j a[j] * g[k-j] for j in [max(0,k-n+1), min(n-1,k)]

So the constraint is: for each k, sum_{j in valid range for k} a[j] * g[k-j] ≤ M.

This is NOT simply A@g ≤ M where A has constant rows. It's:
For k=0: a[0]*g[0] ≤ M
For k=1: a[0]*g[1] + a[1]*g[0] ≤ M
...
For k=n-1: a[0]*g[n-1] + a[1]*g[n-2] + ... + a[n-1]*g[0] ≤ M
...
For k=2n-2: a[n-1]*g[n-1] ≤ M

So the constraint matrix has a "toeplitz-like" structure but the coefficients in each row are different (they come from a). Specifically, the k-th row of the constraint has entries a[n-1-k+j] * g[j] for valid j. Or equivalently, the constraint is:

conv(a,g)[k] ≤ M for all k.

To express this as a standard LP: let x = g (the variable). The constraint for row k is:
sum_j [a[k-j] if 0≤k-j<n] * g[j] ≤ M

So A[k,j] = a[k-j] if 0≤k-j<n, else 0. This is a valid matrix. For n=192, A is 383×192, which is small.

def _conv_self(a):
    """Compute self-convolution using FFT."""
    n = len(a)
    fsize = next_fast_len(2 * n - 1)
    F = rfft(a, fsize)
    c = irfft(F * F, fsize)[:2*n-1]
    np.maximum(c, 0.0, out=c)
    c[~np.isfinite(c)] = 0.0
    return c

def _conv_cross(a, b):
    """Compute cross-convolution a*b using FFT."""
    n = len(a)
    m = len(b)
    fsize = next_fast_len(n + m - 1)
    F = rfft(a, fsize)
    G = rfft(b, fsize)
    c = irfft(F * G, fsize)[:n+m-1]
    np.maximum(c, 0.0, out=c)
    c[~np.isfinite(c)] = 0.0
    return c

def _solve_lp(a, M):
    """Solve the LP: max sum(g) s.t. conv(a,g) <= M, g >= 0."""
    n = len(a)
    # Build constraint matrix: row k, col j = a[k-j] if 0<=k-j<n
    g = cp.Variable(n, nonneg=True)
    
    # Build A efficiently
    # A[k, j] = a[k-j] if 0 <= k-j < n, else 0
    # This is a "convolution matrix" with a in the rows
    A = np.zeros((2*n-1, n))
    for k in range(2*n-1):
        j_min = max(0, k-n+1)
        j_max = min(n-1, k)
        if j_min <= j_max:
            A[k, j_min:j_max+1] = a[k-j_max:k-j_min+1][::-1]
    
    constraints = [A @ g <= M]
    prob = cp.Problem(cp.Maximize(cp.sum(g)), constraints)
    
    for solver in [cp.GLOP, cp.GLPK, cp.CBC, cp.PDLP]:
        try:
            prob.solve(solver=solver, verbose=False)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                gv = g.value
                if gv is not None and np.isfinite(gv).all():
                    gv = np.maximum(gv, 0)
                    s = gv.sum()
                    if s > 1e-15:
                        return gv / s  # Normalize to sum=1
        except Exception:
            continue
    return None

    n = len(a_init)

    a = a / a.sum()

    no_improve = 0

            a = a / a.sum()
        else:
