Given current sequence a (length n), compute b = a ⊗ a (length 2n-1), M = max(b).

LP:
maximize Σ_j g_j
subject to: for all k (0 ≤ k ≤ 2n-2): Σ_j [a_{k-j} g_j : 0 ≤ k-j < n] ≤ M · margin
            g_j ≥ 0

The constraint matrix A has:
A[k, j] = a[k-j] if 0 ≤ k-j < n, else 0

And b_ub[k] = M · margin.

This is correct.

Now, the solution g* gives a direction. The convex combination a_new = (1-t)·a + t·g*/Σg* should reduce the peak.

Why? Because at the LP optimum, the constraints Σ_j a[k-j] g*_j ≤ M·margin are tight for the "active" k values. If margin = 1, the max of a⊗g is at most M. So moving from a toward g* (which has a⊗g* ≤ M) should reduce the overall peak, especially since a⊗a has peak M.

Actually, this isn't quite right. a⊗a has peak M, and a⊗g* has peak ≤ M (atmargin=1). But (a+g*)⊗(a+g*) = a⊗a + 2a⊗g* + g*⊗g*. The cross term a⊗g* is bounded, but g*⊗g* could be large.

For a small step t, (1-t)a + tg has autocorrelation:
(1-t)²(a⊗a) + 2t(1-t)(a⊗g) + t²(g⊗g)

The peak at small t is approximately:
(1-t)² M + 2t(1-t) max(a⊗g)

If max(a⊗g) ≤ M (from the LP), then the peak is ≤ (1-t)² M + 2t(1-t) M = M(1-t)(1-t+2t) = M(1-t)(1+t) = M(1-t²).

So the peak decreases by factor (1-t²), which for small t is approximately 1-2t. The sum changes by factor (1-t) + t·Σg/Σg = 1 (since g is normalized to sum 1... wait, I normalize g to sum 1 at the end).

Actually, if a has sum S_a and g has sum S_g = 1 (after normalization), then (1-t)a + tg has sum (1-t)S_a + t.

The score is 2n · max(autocorr) / sum². For small t:
autocorr_peak ≈ M(1-t²) (approximately)
sum ≈ S_a(1-t) + t

If S_a = 1 (normalized), sum ≈ 1. So score ≈ 2n M (1-t²).

This gives a guaranteed improvement of factor (1-t²) for small t. For t=0.1, that's about 2% improvement per step.

Over 100 LP steps, that's a cumulative improvement that could be significant. But in practice, the improvement per step decreases as we approach the optimum.
