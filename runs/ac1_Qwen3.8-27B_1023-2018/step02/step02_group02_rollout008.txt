If the peak is at a single position k* (which is typical for generic a):
g[j] = 2*a[(k*-j) mod ...] 

Hmm, this is getting complicated with boundaries. Let me just use a simpler approach: use the FFT to compute the gradient.

Actually, the gradient of b[k] w.r.t. a is:
∇_a b[k] = 2 * (a circularly shifted and reversed) but with boundary corrections for linear vs circular.

For the full linear convolution, a cleaner way:
Let b = convolve(a, a, 'full'). Then b has length 2n-1.
∂b[k]/∂a = 2 * flip_and_shift(a, k) where flip_and_shift means:
(∂b[k]/∂a)[j] = a[k-j] + a[k-j] = 2*a[k-j] for valid indices, with the 2j=k exception.

For the subgradient of f = max(b):
g = Σ_{k=argmax(b)} 2 * (a shifted by k)

This can be computed as: if the peak is at position k*, then g[j] ≈ 2*a[k*-j] (for 0≤k*-j<n).

This is essentially a cross-correlation of a with a delta at position k*.

For implementation, I can:
1. Compute b = ifft(fft(a, 2n-1)^2) to get the full convolution
2. Find k* = argmax(b)
3. Compute g[j] = 2*a[k*-j] for 0≤k*-j<n (extend with 0)
4. Do a projected gradient step

But for the case where multiple k achieve the max, I'd sum over all of them.

Actually, for a more robust approach, I'll use a "soft" max: replace max(b) with log-sum-exp of b/τ, which is smooth. Then:
∇_a f_soft = Σ_k softmax_k(b) * 2*a[k-: ] / τ

This gives a smooth approximation to the subgradient.

Wait, I realize the subgradient approach might be slow because each iteration requires computing the gradient (which involves a dot product for each j) and a line search (multiple convolutions). Let me think about the computational cost:
- n = 192
- Each convolution: O(N log N) where N = next_fast_len(383) ≈ 512
- Gradient computation: O(n^2) = O(37K)
- Line search: ~10 evaluations × convolution cost

So each iteration is roughly: 1 + 10 = 11 convolutions + 1 gradient computation.
At ~1μs per FFT of size 512, each convolution is ~5μs. So each iteration is ~100μs.
In 1300 seconds, we can do ~13 million iterations. That's more than enough.

But actually, the subgradient method converges slowly. Let me think of a better approach.

**Better approach: Use the LP-based direction finding but with a better line search and more aggressive iteration.**

The LP approach: given current a (normalized to sum=1), find g that maximizes sum(g) subject to:
- (a*g)[k] ≤ M for all k (where M = max of current convolution)
- g ≥ 0

Then blend: a_new = (1-t)*a + t*g_normalized.

The LP has 2n-1 constraints and n variables. For n=192, that's 383 constraints and 192 variables. This is a small LP that HiGHS can solve in <1ms.

The key improvement: after finding g, do a more careful line search (binary search or golden section) to find the optimal t.

Also, I should consider:
1. **Multiple peaks**: If the convolution has multiple peaks, the LP constraint at M might be too restrictive. I could use a slightly higher M to allow more flexibility.

2. **Iterative refinement**: After the LP step, do a few gradient steps to polish.

3. **Periodic structure**: Try to impose periodicity to reduce the effective problem size.

Let me also consider a different formulation. Since the score is scale-invariant, I'll keep sum(a) = 1. The objective becomes:
minimize max_k (a*a)[k]

This is a minimax quadratic problem, which is NP-hard in general but can be approximated.

For the LP approach, the constraint is `(a*g)[k] ≤ M` where M is the current peak. This is a linear constraint in g (since a is fixed). The LP is:
maximize: 1^T g
subject to: A @ g ≤ M * 1 (where A is the convolution matrix of a)
            g ≥ 0

The convolution matrix A has A[k,j] = a[k-j] if 0≤k-j<n, else 0.

For n=192, A is 383×192, which is small. The LP should be fast.

Let me think about the convergence of the LP iteration. Each LP step finds the direction g that maximizes the "spread" of the new convolution while keeping the peak at most M. This is like a multiplicative weights or mirror descent step.

The convergence rate of such methods is typically O(1/T) in the gap, so we might need many iterations. But with good line search, we should see significant improvement in the first 100-1000 iterations.

Let me also think about whether we can exploit the symmetry of the problem. The convolution (a*a)[k] is symmetric: (a*a)[k] = (a*a)[2n-2-k]. This is because (a*a)[k] = Σ a[j]*a[k-j] and (a*a)[2n-2-k] = Σ a[j]*a[2n-2-k-j]. Substituting j' = n-1-j: (a*a)[2n-2-k] = Σ a[n-1-j']*a[n-1-k+j'] = (a_reversed * a_reversed)[n-1-k]... hmm, this isn't quite right.

Actually, (a*a)[k] for linear convolution:
(a*a)[k] = Σ_{j=max(0,k-n+1)}^{min(k,n-1)} a[j]*a[k-j]

(a*a)[2n-2-k] = Σ_{j=max(0,2n-2-k-n+1)}^{min(2n-2-k,n-1)} a[j]*a[2n-2-k-j]
= Σ_{j=max(0,n-1-k)}^{min(2n-2-k,n-1)} a[j]*a[2n-2-k-j]

Let j' = n-1-j:
= Σ_{j'=min(n-1,k)}^{max(0,n-1-(2n-2-k))} a[n-1-j']*a[2n-2-k-n+1+j']
= Σ_{j'=max(0,k-n+1)}^{min(n-1,k)} a[n-1-j']*a[n-1-k+j']

Hmm, this is (a_reversed * a_reversed)[n-1-k]... this is getting confusing. Let me just verify numerically later. The key point is that the convolution of a sequence with itself is NOT necessarily symmetric (unlike autocorrelation).

Wait, actually it IS symmetric! (a*a)[k] = Σ a[j]*a[k-j]. Now (a*a)[2n-2-k] = Σ a[j]*a[2n-2-k-j]. Let m = n-1-j, so j = n-1-m:
= Σ a[n-1-m]*a[2n-2-k-n+1+m]
= Σ a[n-1-m]*a[n-1-k+m]

And (a*a)[k] = Σ a[j]*a[k-j]. Let m = j:
= Σ a[m]*a[k-m]

These are equal iff a[n-1-m]*a[n-1-k+m] summed over m equals a[m]*a[k-m] summed over m. This is true if a is symmetric (a[m] = a[n-1-m]), but not in general.

So the convolution is NOT symmetric in general. Only if a is palindromic.

OK so I won't exploit symmetry.

For a "PERFECT" sequence (all b[k] equal), the score would be 2n/(2n-1) ≈ 1. For a "GOOD" sequence (peak = 1.5 * average), the score would be 2n * 1.5 * (sum_a)^2/(2n-1) / (sum_a)^2 = 3n/(2n-1) ≈ 1.5.

So the target of 1.5027 corresponds to peak/average ≈ 1.5. This is achievable regardless of n (as long as n is large enough for the sequence to "spread out" the convolution).

import numpy as np
import time
import math
from scipy.fft import rfft, irfft, next_fast_len
from scipy.optimize import linprog

def propose_candidate(seed=42, budget_s=1300, **kwargs):
    t0 = time.monotonic()
    deadline = t0 + max(1.0, float(budget_s)) - 10.0
    
    # Get parent sequence
    try:
        parent = np.asarray(height_sequence_1, dtype=np.float64).ravel()
    except Exception:
        parent = None
    
    if parent is None or parent.size < 2 or not np.isfinite(parent).all():
        # Fallback: random initialization
        rng = np.random.default_rng(seed)
        parent = rng.random(192)
    
    parent = np.clip(parent, 0, 1000)
    n = int(parent.size)
    
    if parent.sum() < 0.01:
        parent = np.ones(n)
    
    # Normalize to sum = 1
    a = parent / parent.sum()
    
    # FFT size for convolution
    conv_len = 2 * n - 1
    N = next_fast_len(conv_len)
    
    def conv_full(x):
        X = rfft(x, N)
        c = irfft(X * X, N)[:conv_len]
        return np.maximum(c, 0)
    
    def score_of(x):
        s = x.sum()
        if s < 1e-12:
            return np.inf
        c = conv_full(x)
        return 2.0 * n * float(c.max()) / (s * s)
    
    best_a = a.copy()
    best_sc = score_of(a)
    
    # =========================================================
    # PHASE 1: LP-based descent
    # =========================================================
    def lp_direction(a_curr):
        """Find direction g maximizing sum(g) s.t. a_curr * g <= M, g >= 0."""
        c_curr = conv_full(a_curr)
        M = float(c_curr.max())
        if M < 1e-16:
            return None, M
        
        # Build constraint matrix: (A @ g)[k] = (a_curr * g)[k]
        # A[k,j] = a_curr[k-j] if 0 <= k-j < n, else 0
        # For efficiency, build as banded
        A = np.zeros((conv_len, n), dtype=np.float64)
        for j in range(n):
            A[j:j+n, j] = a_curr  # a_curr[k-j] for k=j,...,j+n-1, i.e., k-j=0,...,n-1
        
        c_obj = -np.ones(n)
        b_ub = np.full(conv_len, M)
        bounds = [(0, None)] * n
        
        try:
            res = linprog(c_obj, A_ub=A, b_ub=b_ub, bounds=bounds,
                         method='highs', options={'presolve': True, 'time_limit': 5.0})
        except Exception:
            return None, M
        
        if not res.success or res.x is None:
            return None, M
        
        g = np.maximum(res.x, 0)
        gs = g.sum()
        if gs < 1e-12:
            return None, M
        g /= gs
        
        # Check if g is essentially the same as a_curr
        if np.linalg.norm(g - a_curr, 1) < 1e-8:
            return None, M
        
        return g, M
    
    # LP iteration loop
    for it in range(5000):
        if time.monotonic() > deadline - 120:
            break
        
        g, M = lp_direction(a)
        if g is None:
            break
        
        # Line search: find best t in [0,1] for a_new = (1-t)*a + t*g
        best_t = 0.0
        best_m = 2*n*M  # current score (with sum=1)
        
        # Try golden section or just a grid
        for t in (1.0, 0.8, 0.6, 0.5, 0.4, 0.3, 0.2, 0.15, 0.1, 0.05, 0.03):
            h = (1-t)*a + t*g
            m_h = 2*n*float(conv_full(h).max())
            if m_h < best_m - 1e-14:
                best_m = m_h
                best_t = t
        
        if best_t > 0:
            a = (1-best_t)*a + best_t*g
            sc = 2*n*float(conv_full(a).max())
            if sc < best_sc - 1e-13:
                best_sc = sc
                best_a = a.copy()
    
    # =========================================================
    # PHASE 2: Smoothed subgradient descent
    # =========================================================
    if time.monotonic() < deadline - 60:
        a = best_a.copy()
        lr = 0.3
        stuck = 0
        rng = np.random.default_rng(seed)
        
        for it in range(30000):
            if time.monotonic() > deadline - 60:
                break
            if stuck > 500:
                break
            
            c = conv_full(a)
            M = float(c.max())
            sc = 2*n*M  # sum(a) = 1
            
            if sc < best_sc - 1e-13:
                best_sc = sc
                best_a = a.copy()
                stuck = 0
            
            # Softmax weights for smoothed max
            tau = max(1e-10, 0.01 * M + 1e-12)
            x = (c - M) / tau
            x = np.clip(x, -60, 60)
            w = np.exp(x)
            ws = w.sum()
            if ws < 1e-30:
                w = np.zeros_like(c)
                w[np.argmax(c)] = 1.0
            else:
                w /= ws
            
            # Gradient: g[j] = 2 * sum_{m=0}^{n-1} w[j+m] * a[m]
            # (cross-correlation of w with a, only positive lags)
            g = np.zeros(n)
            for j in range(n):
                g[j] = 2.0 * np.dot(w[j:j+n], a)
            
            # Project to tangent of simplex (sum(a)=1)
            g = g - g.mean()
            
            # Normalize step
            gn = np.linalg.norm(g)
            if gn < 1e-14:

                    a /= a.sum()
                continue

            improved = False
            for scale in (lr, lr*0.5, lr*0.25, lr*0.1, lr*0.05, lr*0.01):
                cand = a - scale * g / gn
                cand = np.maximum(cand, 0)
                cs = cand.sum()
                if cs < 1e-10:
                    scale *= 0.5
                    continue
                cand /= cs
                cand_sc = 2*n*float(conv_full(cand).max())
                if cand_sc < sc - 1e-14:
                    a = cand
                    sc = cand_sc
                    improved = True
                    break
            
            if improved:
                stuck = 0
                lr = min(lr * 1.01, 2.0)
            else:
                stuck += 1
                lr = max(0.01, lr * 0.9)
    
    # =========================================================
    # PHASE 3: Stochastic local search
    # =========================================================
    if time.monotonic() < deadline - 20:
        a = best_a.copy()
        sc = best_sc
        rng2 = np.random.default_rng(seed + 12345)
        sigma = 0.05

                break

            if r < 0.3:

                z = np.log(np.clip(a, 1e-12, None))
                z += rng2.normal(0, sigma, n)
                z -= z.max()
                cand = np.exp(z)
                cand /= cand.sum()
            elif r < 0.5:
                # Local window perturbation
                cand = a.copy()
                k = int(rng2.integers(0, n))
                w = max(1, n // 40)
                lo, hi = max(0, k-w), min(n, k+w)
                cand[lo:hi] *= np.exp(rng2.normal(0, 0.1))
                cand = np.maximum(cand, 0)
                cs = cand.sum()
                if cs > 1e-10:
                    cand /= cs
                else:
                    continue
            elif r < 0.7:
                # Pair exchange
                cand = a.copy()
                i1 = int(rng2.integers(0, n))
                i2 = int(rng2.integers(0, n))
                if i1 == i2:
                    continue
                amt = 0.01 * cand[0]
                cand[i1] += amt
                cand[i2] -= amt
                cand = np.maximum(cand, 0)
                cs = cand.sum()
                if cs > 1e-10:
                    cand /= cs
                else:
                    continue
            elif r < 0.85:
                # Periodic reshape
                period = int(rng2.integers(2, min(16, n//4)))
                if period < 2 or period > n:
                    continue
                avg = a[:n].reshape(-1, period).mean(axis=0)
                cand = np.tile(avg, n//period + 1)[:n]
                cand += rng2.normal(0, 0.01, n)
                cand = np.maximum(cand, 0)
                cs = cand.sum()
                if cs > 1e-10:
                    cand /= cs
                else:
                    continue
            else:
                # Blend with reversed
                cand = 0.9 * a + 0.1 * a[::-1]
                cand = np.maximum(cand, 0)
                cs = cand.sum()
                if cs > 1e-10:
                    cand /= cs
                else:
                    continue
            
            cand_sc = 2*n*float(conv_full(cand).max())
            if cand_sc < sc - 1e-13:
                a = cand.copy()
                sc = cand_sc
                if sc < best_sc - 1e-13:
                    best_sc = sc
                    best_a = a.copy()
                sigma = max(0.01, sigma * 0.98)
            else:
                sigma = min(0.3, sigma * 1.02)
    
    # =========================================================
    # Final validation
    # =========================================================
    best_a = np.clip(best_a, 0, 1000)
    if not np.isfinite(best_a).all() or best_a.sum() < 0.01:
        best_a
