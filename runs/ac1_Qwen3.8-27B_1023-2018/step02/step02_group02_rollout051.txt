Now, for the projected subgradient method on the simplex:
- We want to minimize `c_max(a) ≈ c[k*(a)]` (using subgradient at current argmax)
- Subject to `a >= 0`, `sum(a) = 1`
- Step: `a_new = proj_simplex(a - eta * v)`

The Euclidean projection onto the simplex `{x >= 0, sum(x) = 1}`:
Given `y = a - eta*v`, find `proj = max(y - nu, 0)` where `nu` is chosen so that `sum(max(y-nu, 0)) = 1`.

The standard algorithm:
1. Sort y in descending order: `y_(1) >= y_(2) >= ... >= y_(n)`
2. Find the largest `rho` such that `y_(rho) - (sum_{i=1}^{rho} y_(i) - 1)/rho > 0`
3. `nu = (sum_{i=1}^{rho} y_(i) - 1) / (rho+1)`
4. `proj = max(y - nu, 0)`

This is O(n log n).

        best_f = np.ones(n) / n

    final_list = [float(x) for x in best_f]
    try:
        fs = float(evaluate_sequence(final_list))
    except Exception:
        fs = float('inf')

    if not np.isfinite(fs):
        final_list = [1.0 / n] * n
        try:
            fs = float(evaluate_sequence(final_list))
        except Exception:
            pass
        if not np.isfinite(fs):
            return [1.0]

    return final_list
