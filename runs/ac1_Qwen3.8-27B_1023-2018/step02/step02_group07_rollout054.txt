max(f_new ⊛ f_new) = max_k [(1-t)^2 (f⊛f)_k + 2t(1-t)(f⊛g')_k + t^2 (g'⊛g')_k]

At the peak position k* where (f⊛f)_{k*} = M:
= (1-t)^2 * M + 2t(1-t) * (f⊛g')_{k*} + t^2 * (g'⊛g')_{k*}

We know (f⊛g')_{k*} <= M/sum(g) (from the LP constraint scaled).

If sum(g) is large (which it will be since we're maximizing sum), then (f⊛g')_{k*} << M, which is good.

For small t: change ≈ 2t(1-t)[(f⊛g')_{k*} - M] + t^2(g'⊛g')_{k*}
≈ 2t[(f⊛g')_{k*} - M] + t^2(g'⊛g')_{k*}

Since (f⊛g')_{k*} < M (strictly, unless g is proportional to f at that position), this is negative for small t. Good.

So the LP direction should decrease the peak. The question is how fast.

    a = np.asarray(a, dtype=np.float64)
    s = float(a.sum())
    if s < 1e-300:
        return np.ones_like(a) / a.size
    return a / s

def _conv(a, fs):
    F = rfft(a, fs)
    n = a.size
    return irfft(F * F, fs)[:2*n-1]

def _score_n(a, fs):
    """Score assuming sum(a)=1"""
    b = _conv(a, fs)
    m = float(b.max())
    if not np.isfinite(m) or m < 0:
        return math.inf
    return 2.0 * a.size * m

def _soft_grad(a, b, fs2, tau):
    """Compute soft-argmax gradient"""
    n = a.size
    p = np.exp(np.clip(b / tau, -80.0, 80.0))
    s = float(p.sum())
    if s < 1e-300:
        p = np.zeros_like(b)
        p[int(np.argmax(b))] = 1.0
    else:
        p = p / s

    g = irfft(rfft(ar, fs2) * rfft(p, fs2), fs2)
    g = g[n-1:2*n-1] * 2.0
    return g, p

    """Solve LP: max sum(g) s.t. (f*g)_k <= M, g >= 0"""

        hi = min(n - 1, k)
        for i in range(lo, hi + 1):
            A[k, k - i] = f[i]
    b_ub = np.full(2*n-1, M)
    bounds = [(0, None)] * n
    res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success:
        return res.x
    return None
