If j = k-j (i.e., j = k/2): one term a_j * a_j, contribution = 2 * eps * a_j = 2 * eps * a_{k-j}

So in all cases: ∂b_k / ∂a_j = 2 * a_{k-j} (with a_i = 0 for i < 0 or i >= n).

Great, so the gradient is clean.

Now, the subgradient of f(a) = max_k b_k is in the convex hull of {∇b_k : b_k = max_b}.
