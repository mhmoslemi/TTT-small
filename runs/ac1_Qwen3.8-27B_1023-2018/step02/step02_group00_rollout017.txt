```python
        for m in [0, 0.05, 0.1, 0.25, 0.5, 0.75, 1.0, 1.25, 1.5, 2.0, 3.0, 5.0]:
            test_vals.add(orig * m)
    else:
        test_vals.update([0, 0.001, 0.01, 0.05])
    
    best_v = orig
    best_sc = 2.0 * n * f_old_b.max() / (S * S)
    
    for v in test_vals:
        delta = v - orig
        if abs(delta) < 1e-15:
            continue
        
        # Updated convolution
        new_max = f_old_b.max()
        # We need to compute max of (f_old_b + delta_conv)
        # delta_conv is nonzero only at positions [j, j+n-1]
        
        # Affected positions
        lo = j
        hi = min(j + n, 2*n - 1)
        
        # b_updated[k] = b[k] + 2*delta*f[k-j] for k in [lo, hi)
        # plus delta^2 at k=2j
        
        # To find the max efficiently:
        # - Positions outside [lo, hi) and != 2j are unchanged
        # - Position 2j gets extra delta^2
        
        # The max of the updated array:
        # Unchanged max: max(b[k] for k not in [lo,hi) and k != 2j)
        # Changed max: max(b[k] + 2*delta*f[k-j] for k in [lo,hi))
        # Special: b[2j] + 2*delta*f[j] + delta^2
        
        # For simplicity, just compute the affected section:
        idx = np.arange(lo, hi)
        affected = f_old_b[idx] + 2 * delta * f[idx - j]
        if lo <= 2*j < hi:
            affected[2*j - lo] += delta * delta
        
        new_max = max(float(affected.max()), 
                      float(np.delete(f_old_b, idx).max()) if len(f_old_b) > len(idx) else 0)
        
        new_S = S + delta
        if new_S < 0.01:
            continue
        
        sc = 2.0 * n * new_max / (new_S * new_S)
        if sc < best_sc - 1e-14:
            best_sc = sc
            best_v = v
    
    return best_v, best_sc
```

Hmm, the np.delete in the inner loop is expensive. Let me restructure:

```python
# Pre-compute the max of the UNCHANGED portion
# The unchanged positions are [0, lo) and [hi, 2n-1]
unchanged_max = max(
    float(f_old_b[:lo].max()) if lo > 0 else 0,
    float(f_old_b[hi:].max()) if hi < len(f_old_b) else 0
)
```

This is O(n) per evaluation, but without the delete. Better.

Actually, for n=320, the convolution has 639 elements. Computing max() over a subset is very fast. The whole coordinate sweep for one j is:
- ~12 test values
- Each test: O(n) to compute affected section, O(1) for unchanged max
- Total: ~12 * O(n) = O(12n)

Per full pass over all n coordinates: O(n^2) evaluations of O(n) = O(n^3)?? No, that's O(12n * n) = O(12n^2) = 1.2M for n=320. At ~1ns per op, that's 1.2ms per pass. Very fast!

But wait, I also need to update f[j] and b after choosing the best value. The b update is O(n) per coordinate change. So the full pass is O(n^2) for the sweeps + O(n^2) for the b updates. Total O(n^2) per pass.

With 100 passes, total is O(100 * n^2) = 10M for n=320. Very fast!

The bottleneck is the initial convolution computation (O(n log n)) and the final score validation.
