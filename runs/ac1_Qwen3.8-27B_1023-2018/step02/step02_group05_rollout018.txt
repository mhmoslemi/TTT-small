Let me implement a robust subgradient method:
1. Compute g = convolve(a, a)
2. Find active set A = {k : g[k] >= M - eps*M}
3. Compute subgradient: for each k in A, grad_k[i] = a[k-i] (if valid) + a[i-k] (if valid) = (shifted a)
4. Average: s = (1/|A|) * sum_{k in A} grad_k
5. Update: a = a - eta * s (where eta is step size)
6. Project onto {a >= 0, sum(a) = 1} (clip and renormalize)
7. Reduce eta slowly

This is a simple but effective approach. The projection onto the simplex is:
- Clip: a = max(a, 0)
- Renormalize: a = a / sum(a)
(This is the Euclidean projection onto the nonnegative simplex.)
