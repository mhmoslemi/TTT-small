    A_ub[:, 1:] = np.where(mask, fixed[np.clip(d, 0, n-1)], 0.0)
    
    b_ub = np.zeros(m)
    
    # Equality: sum(x) = 1
    A_eq = np.zeros((1, n + 1))
    A_eq[0, 1:] = 1.0
    b_eq = [1.0]
    
    # Bounds: M free, x_j >= 0
    bounds = [(None, None)] + [(0, None)] * n

                      options={'time_limit': timeout,
                               'dual_feasibility_tolerance': 1e-10,
                               'primal_feasibility_tolerance': 1e-10})
    except Exception:
        return None, None
    
    if res.status != 0 or res.x is None:
        return None, None
    
    M = res.x[0]
    x = np.clip(res.x[1:], 0.0, None)
    if not np.isfinite(x).all() or x.sum() < 1e-15:
        return None, None
    x = x / x.sum()
    return x, M

This is a much more direct formulation! We're directly minimizing the peak of the convolution.

The alternating scheme would be:
1. Start with a = parent (normalized)
2. Fix a, solve LP for g: min max(a*g)
3. Fix g, solve LP for a': min max(g*a')
4. Update a ← a' (or blend)
5. Repeat

This should converge to a saddle point of the bilinear form (a,g) → max_k (a*g)_k.

Actually, this is even better than the previous approach because we're directly minimizing the objective rather than using a proxy.

Let me also add:
- Blending (a + g) / 2 after each LP solve to ensure we're moving
- More aggressive line search
- Periodic random perturbations
