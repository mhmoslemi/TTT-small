Now let me think about the LP more carefully. The LP is:
maximize sum(g)
subject to: (a*g)_k <= M for k = 0, ..., 2n-2

The constraint matrix A has A[k,j] = a[k-j] if 0 <= k-j < n, else 0.

After solving, we get g. Then we mix: a_new = (1-t)*a + t*g (normalized).

The key insight is that this LP gives a direction that, if followed, keeps the convolution bounded while increasing the sum. The mixing step is a line search.

Let me also add a **second-order correction**. After computing the LP direction g, instead of just linear mixing, I can do a quadratic line search in the direction g - a (or just g).
