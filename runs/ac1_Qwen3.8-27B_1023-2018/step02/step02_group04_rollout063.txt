Hmm, this is getting messy. Let me think of a cleaner way.

For `b = np.convolve(a, a)` with n elements each:
`b[m] = sum_{i=max(0, m-n+1)}^{min(m, n-1)} a[i] * a[m-i]`

`∂b[m]/∂a[j]`:
- If `j` is in `[max(0, m-n+1), min(m, n-1)]` (i.e., a[j] appears as first factor):
  contributes `a[m-j]`
- If `m-j` is in `[max(0, m-n+1), min(m, n-1)]` AND `m-j != j` (i.e., a[j] appears as second factor, different from first):
  contributes `a[m-j]`

So:
- Let `i1 = (max(0, m-n+1) <= j <= min(m, n-1))` — j valid as first index
- Let `i2 = (max(0, m-n+1) <= m-j <= min(m, n-1))` — (m-j) valid as index, i.e., `j` valid as second index
- If `i1 and i2 and j != m-j`: ∂b[m]/∂a[j] = 2*a[m-j]
- If `i1 and i2 and j == m-j`: ∂b[m]/∂a[j] = a[m-j] (since m-j = j, only one term)
- If `i1 xor i2`: ∂b[m]/∂a[j] = a[m-j] (where valid)
- If not i1 and not i2: 0

For the gradient computation, for a fixed j:
- m ranges such that either `j` is a valid first index or valid second index
- As first index: `max(0,m-n+1) <= j <= min(m,n-1)` → `j <= m <= j+n-1` AND `m >= 0` AND `m <= 2n-2`
  So m ∈ [j, min(j+n-1, 2n-2)]
- As second index: `max(0,m-n+1) <= m-j <= min(m,n-1)` → `m-j >= 0` → `m >= j`, and `m-j <= n-1` → `m <= j+n-1`, and `m-j <= m` (always true for j>=0), and `m >= m-n+1` → `n-1 >= 0` (always true)
  So m ∈ [j, j+n-1] ∩ [0, 2n-2]

Both give m ∈ [j, min(j+n-1, 2n-2)].

For such m:
- k = m - j, range [0, n-1]
- If m == 2j: ∂b[m]/∂a[j] = a[j]
- Else: ∂b[m]/∂a[j] = 2 * a[k] = 2 * a[m-j]

                    upd(a)
            sub = min(deadline - 5, time.monotonic() + 40)
            a = grad_ref(a, sub, 500, 50.0)
        return a

    def mkstarts(n, par, cnt=12):
        S = []
        x = np.linspace(0, 1, n)
        def add(a):
            a = np.clip(np.nan_to_num(a, nan=0.0, posinf=0.0, neginf=0.0), 0, None).astype(np.float64)
            if a.size == n and a.sum() > 1e-10:
                S.append(a)
        if par is not None:
            add(np.interp(x, np.linspace(0, 1, len(par)), par))
        add(np.ones(n))
        for cc in [-2, -1, -0.5, 0.5, 1, 2, 3]:
            add(np.exp(cc * (x - 0.5)))
        for k in range(1, 6):
            for amp in [0.2, 0.5, 0.8]:
                add(1 + amp * np.sin(2 * np.pi * k * x))
                add(1 - amp * np.sin(2 * np.pi * k * x + np.pi / 4))
        for _ in range(4):
            add(np.exp(0.3 * rng.standard_normal(n)))
        out = []
        for s in S:
            v = sc(s)
            if math.isfinite(v):
                out.append((v, s))
        out.sort(key=lambda t: t[0])
        return [s for _, s in out[:cnt]]

    # === Main search ===

    # Phase 1: Gradient at default length
    if time.monotonic() < dl - 700:
        starts = mkstarts(n_def, parent, 10)
        for s in starts[:3]:
            if time.monotonic() > dl - 700:
                break
            _ = grad_ref(s, min(dl - 700, time.monotonic() + 120), 3000)

    # Phase 2: LP + gradient alternating
    if time.monotonic() < dl - 400:
        _ = lp_grad_alt(best_arr, min(dl - 400, time.monotonic() + 250), 25)

    # Phase 3: More gradient from different starts
    if time.monotonic() < dl - 300:
        starts2 = mkstarts(n_def, best_arr, 10)
        for s in starts2[3:8]:
            if time.monotonic() > dl - 300:
                break
            _ = grad_ref(s, min(dl - 300, time.monotonic() + 60), 2000)

    # Phase 4: Other lengths
    for alt_n in sorted(set([max(16, n_def - 32), max(16, n_def + 32), 128, 256])):
        if time.monotonic() > dl - 150:
            break
        if alt_n == n_def:
            continue
        for s in mkstarts(alt_n, best_arr, 4)[:2]:
            if time.monotonic() > dl - 150:
                break
            _ = grad_ref(s, min(dl - 150, time.monotonic() + 60), 1500)

    # Phase 5: LP polish
    if time.monotonic() < dl - 40:
        _ = lp_ref(best_arr, min(dl - 40, time.monotonic() + 100), 60)

    # Phase 6: Final gradient
    if time.monotonic() < dl - 15:
        _ = grad_ref(best_arr, min(dl - 15, time.monotonic() + 30), 3000, 100.0)

    # Final validation
    upd(best_arr)
    fin = best_arr.copy()
    fin = np.nan_to_num(fin, nan=0.0, posinf=0.0, neginf=0.0)
    fin = np.clip(fin, 0.0, 1000.0)
    if fin.size < 1 or fin.sum() < 0.01:
        fin = np.ones(2)
    upd(fin)

    v = evaluate_sequence([float(x) for x in best_arr])
    if not math.isfinite(v):
        return [1.0, 1.0]
    return [float(x) for x in best_arr]
