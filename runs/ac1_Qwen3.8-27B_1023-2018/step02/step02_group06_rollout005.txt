   Actually, let me use a different parameterization to handle the constraints:
   - a_j = exp(z_j) / sum(exp(z_k)) (softmax parameterization)
   - Then a > 0 and sum(a) = 1 automatically.
   - Optimize over z ∈ R^n.
   
   The gradient w.r.t. z_j:
   ∂a_j/∂z_k = a_j * (δ_jk - a_k)
   
   So ∂F/∂z_k = sum_j ∂F/∂a_j * a_j * (δ_jk - a_k)
   = a_k * (∂F/∂a_k - sum_j ∂F/∂a_j * a_j)
   
   This is the "softmax gradient" trick.
   
   But the softmax parameterization can cause numerical issues when some a_j are very small (exp underflow). For n=192, this should be fine as long as we don't push the values too extreme.
   
   Alternatively, I'll just use the simplex projection approach (project a - alpha*grad onto the simplex).
   
   **Simplex projection**: Given x, find the closest point on {a >= 0, sum(a) = 1}.
   Algorithm: find τ such that sum(max(x_j - τ, 0)) = 1. Use bisection.
   
   ```python
   def simplex_project(x):
       n = len(x)
       u = np.sort(x)[::-1]  # descending
       cssv = np.cumsum(u)
       rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
       theta = (cssv[rho] - 1) / (rho + 1.0)
       return np.maximum(x - theta, 0)
   ```

   The LP approach: given a and M = max(conv(a,a)), find g that maximizes sum(g) subject to conv(a,g) <= M, g >= 0. Then rescale g to sum 1 and blend with a.
   
   This is essentially a "dual" of the primal problem. The LP is a good direction-finding step because it identifies the "bottleneck" constraints (the lags where conv(a,g) = M).
   
   The smooth max approach directly optimizes a smooth approximation to the objective. For large λ, it's close to the true max.
