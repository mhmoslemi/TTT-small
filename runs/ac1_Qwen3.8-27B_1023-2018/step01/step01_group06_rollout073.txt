Alternatively, I can use a "top-k" approximation: instead of softmax over all lags, use only the top k lags with uniform weights. This approximates the max better for small k.

Let me implement the top-k approach as an alternative:
```python
k_top = 50  # number of top lags
thresh = np.partition(c, conv_len - k_top)[conv_len - k_top]
p = np.where(c >= thresh, 1.0, 0.0)
p /= p.sum()
```

This gives a piecewise-constant "max approximation" that's closer to the true max than a uniform softmax.

I'll use this as the primary weight and the softmax as a refinement.

Actually, let me just use a high-temperature softmax (tau=100+) and manually renormalize. For a 8995-element vector, the softmax computation is fast.

Let me finalize the code now. I'll keep it clean and well-structured.
