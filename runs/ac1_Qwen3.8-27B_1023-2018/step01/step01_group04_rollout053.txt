We want: convolve(a, g)[k] <= M for all k = 0, ..., 2n-2.

convolve(a, g)[k] = sum_{j} a[j] * g[k-j] where both indices are in [0, n-1].

So for a fixed k:
convolve(a, g)[k] = sum_{j=max(0,k-n+1)}^{min(n-1,k)} a[j] * g[k-j]

As a function of g (the unknowns), this is:
sum_{j=max(0,k-n+1)}^{min(n-1,k)} a[j] * g[k-j]

Let me reparameterize: let i = k-j, so j = k-i.
= sum_{i=max(0,k-n+1)}^{min(n-1,k)} a[k-i] * g[i]

So A[k, i] = a[k-i] if 0 <= k-i < n and 0 <= i < n, else 0.
