def solve_lp_step(a, M):
    n = len(a)
    conv_len = 2*n - 1
    
    # Build constraint matrix A such that (A @ b)_k = sum_i a[i]*b[k-i]
    # Row k has nonzeros at columns i where 0 <= k-i < n, i.e., k-n+1 <= i <= k
    # And 0 <= i < n

Alternative approach: **Interior point on the dual**

The dual of the LP is:
Minimize M * sum_k y[k]
Subject to: (a * y)[j] >= 1 for all j = 0,...,n-1
y[k] >= 0 for all k = 0,...,2n-2

where `(a * y)[j] = sum_k a[k-j] * y[k]` (with a[m]=0 outside [0,n-1]).

This has 2n-1 = 8995 variables and n = 4498 constraints. Still large.

But we can solve it with a simple projected gradient or FISTA method:
- Objective: f(y) = M * sum(y)
- Constraint: (A^T y)[j] >= 1, y >= 0
- Where A is the (2n-1) x n convolution matrix

The gradient of the objective is M * 1 (a vector of M's).
The constraint violation at j is: 1 - (A^T y)[j].

We can use a penalty method: minimize `f(y) + (rho/2) * sum_j max(0, 1 - (A^T y)[j])^2` subject to `y >= 0`.

Or use a simple projected subgradient:
- `y_new = max(0, y - lr * M + mu * (A^T y - 1))` where mu is a penalty parameter.

This is O(n^2) per iteration (for the matrix-vector product), which is about 20M operations. Very fast!
