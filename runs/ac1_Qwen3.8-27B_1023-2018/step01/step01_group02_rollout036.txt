c[n-1] = sum_j a[j]*a[n-1-j]. This is NOT sum a[j]^2 unless a is palindromic!

Aha, so if a is not palindromic, c[n-1] < sum a[j]^2. This is how we can get below 2!

So the key insight is: **make the sequence non-palindromic** to reduce the center value of the convolution.

For example, if a = [1, 0, 0, ..., 0] (a delta), then c = [1, 0, 0, ..., 0, 0, ..., 0] (just a single 1 at position 0). The max is 1, and the score is 2n*1/1 = 2n. That's terrible.

If a = [0, ..., 0, 1] (delta at the end), then c = [0, ..., 0, 1] (single 1 at position 2n-2). Score = 2n. Also terrible.

If a = [1, 1, 1, ..., 1]/n (uniform), then c[n-1] = n*(1/n)^2 = 1/n. Score = 2n*(1/n)/1 = 2.

If a is "left-heavy" (e.g., a[j] = (n-j)/sum for j=0,...,n-1), then a[0] is large and a[n-1] is small. Then c[n-1] = sum a[j]*a[n-1-j] pairs large values with small values, reducing the center. But c[0] = a[0]^2 might be large.

So there's a trade-off: making the sequence non-palindromic reduces c[n-1] but might increase c[0] or c[2n-2].

The optimal solution balances these.

So the binding constraint is likely c[n-1] (the center), and the goal is to minimize it while keeping all other c[k] values below the same level.

This is essentially: minimize c[n-1] = sum a[j]*a[n-1-j] subject to c[k] <= c[n-1] for all k, sum a = 1, a >= 0.

def _softmax(z):
    z = np.asarray(z, dtype=np.float64)
    z = z - np.max(z)
    e = np.exp(z)
    s = e.sum()
    if s < 1e-300:
        return np.full(z.shape, 1.0/z.size)
    return e / s

def _logit(a):
    return np.log(np.maximum(a, 1e-30))

def _compute_score(a):
    """Fast score computation (assumes a is normalized, sum=1)."""
    n = len(a)
    c = np.convolve(a, a)
    return 2.0 * n * np.max(c)

def _soft_objective(z, beta, n):
    a = _softmax(z)
    c = np.convolve(a, a)
    S = a.sum()
    bc = beta * c
    mx = np.max(bc)
    LSE = mx + np.log(np.sum(np.exp(bc - mx)))
    val = 2.0 * n * LSE / (beta * S * S)
    return val

def _soft_gradient(z, beta, n):
    a = _softmax(z)
    c = np.convolve(a, a)
    S = a.sum()
    m = 2 * n - 1
    
    bc = beta * c
    mx = np.max(bc)
    p = np.exp(bc - mx)
    p_sum = p.sum()
    p = p / p_sum  # probabilities
    
    L = (mx + np.log(p_sum)) / beta  # logsumexp(beta*c) / beta
    
    # Compute cross[i] = sum_{j=0}^{n-1} a[j] * p[i+j] for i in [0, n-1]
    # Using FFT:
    Lfft = 1
    while Lfft < n + m - 1:  # need at least n + (2n-1) - 1 = 3n-2
        Lfft *= 2
    A = np.fft.rfft(a, Lfft)
    Q = np.fft.rfft(p[::-1], Lfft)
    conv = np.fft.irfft(A * Q, Lfft)
    # cross[i] = conv[n-1 + (m-1) - i] ... let me just use direct for safety
    # Actually let me use the formula: cross[i] = conv[m-1-i] where conv = a * p_rev
    # conv[k] = sum_j a[j]*p_rev[k-j] = sum_j a[j]*p[m-1-k+j]
    # cross[i] = sum_j a[j]*p[i+j] = conv[m-1-i]
    # m-1-i ranges from m-1 (i=0) to m-n (i=n-1)
    # m-1 = 2n-2, m-n = n-1
    cross = conv[n-1 : 2*n-1][::-1]  # conv[2n-2], conv[2n-3], ..., conv[n-1]
    
    # dL/da[i] = 2 * cross[i]
    # df/da[i] = 2n * (S * 2*cross[i] - 2L) / S^3 = 4n*(S*cross[i] - L) / S^3
    fda = 4.0 * n * (S * cross - L) / (S * S * S)
    
    # Convert to gradient w.r.t. z (softmax chain rule):
    # df/dz[i] = a[i] * (fda[i] - sum_j fda[j]*a[j])
    dot = np.dot(fda, a)
    fdz = a * (fda - dot)
    
    return fdz

def _subgradient_step(a, step_size, n):
    """One subgradient step on the true objective."""
    c = np.convolve(a, a)
    S = a.sum()
    k_star = np.argmax(c)
    m = 2 * n - 1
    
    # Subgradient of max_k c[k] w.r.t. a:
    # g[i] = 2 * a[k_star - i] for valid indices
    g = np.zeros(n)
    for i in range(n):
        j = k_star - i
        if 0 <= j < 2*n - 1:  # j should be in [0, 2n-2] for p, but for a it's [0, n-1]
            if 0 <= j < n:
                g[i] = 2.0 * a[j]
    
    # Full subgradient of J = 2n*max_c/S^2:
    # dJ/da[i] = 2n*(S*g[i] - 2*max_c) / S^3
    max_c = c[k_star]
    gJ = 2.0 * n * (S * g - 2.0 * max_c) / (S * S * S)
    
    # Take a step and project
    a_new = a - step_size * gJ
    a_new = np.maximum(a_new, 0)
    if a_new.sum() > 1e-30:
        a_new = a_new / a_new.sum()
    else:
        a_new = a.copy()
    
    return a_new

    """Local coordinate search."""
    best = a.copy()
    best_score = _compute_score(best)
    step = 0.01 / np.sqrt(n)
