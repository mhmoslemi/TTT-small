### Approach and rationale
**Central idea:**  
Minimize the AC1 upper bound (defined in the evaluator) by iteratively improving a candidate sequence using gradient-based optimization and constraint-handling. The AC1 bound is given by:
\[
\text{AC1} = \frac{2n \cdot \max\text{(full convolution)}}{\left(\sum a_i\right)^2}
\]
The goal is to minimize this bound. The method uses finite-difference gradient estimation to avoid expensive analytic gradient computation while balancing exploration and exploitation.

**Key bottleneck addressed:**  
Direct analytic gradient computation is infeasible for full convolutions. Finite-difference gradients approximate the gradient at reasonable cost by slightly perturbing each parameter. This allows using nested optimization to explore the high-dimensional space efficiently.

**Advantages:**  
- Flexible and concise for high-dimensional optimization.  
- No restrictive assumptions on sequence structure (e.g., step-function shape).  
- Automatic handling of implicit constraints (coefficients ∈ [0,1000]) via bounds.  

**Limitations:**  
- Finite-differences are computation-heavy (n evaluations per gradient).  
- Gradients become "noisy" as coefficients approach boundaries, limiting optimization depth.  

**Fallback strategy:**  
If time expires or no performance improvement, revert to the provided `height_sequence_1`.

---

### Mathematical specification
**Variables:**  
- \( a = (a_0, a_1, \dots, a_{n-1}) \): Sequence of nonnegative coefficients bounded by [0,1000].  
- \( n \): Sequence length.  

**Objective to minimize:**  
\[
f(a) = \text{AC1}(a) = \frac{2n \cdot \max\text{(full convolution)}}{\left(\sum a_i\right)^2}
\]
where full convolution is the linear convolution (2n-1 terms).  

**Gradient estimation (subgradient for max):**  
Def: Active set indices \( S \) are lags where the convolution is maximized.  
Gradient of \( g_i = \max_{k \in S} \left( \nabla_k (a * a)[k] \right) \)  
The analytic gradient component \( g_i \) aggregates contributions from neighboring active lags \( k \), considering:  
- **Term exposure:** Sum of active cross-correlation contributions.  
- **Interactions:** Lags where \( a_i \) appears as input \( (\nabla_k^+ ) \) or output \( (\nabla_k^- ) \).  

Gradient projection ensures enforced moves decrease the AC1 bound or maintain feasibility.

**Optimization variables:**  
- \( a_i \in [0,1000] \)

**Representation:**  
- Full-length array, scaled to maintain convergence.  
- Dynamic learning rate: Reduces as bound improves (stabilizes optimization later).

**Supporting calculations:**  
1. Full convolution computation (contaminates time budget).  
2. Gradient averaging over active constraining lags (for finite-differences).

#### 2. Gradient-estimating function  
```python
def get_gradient(candidate):
    """Finite-difference gradients along each index."""
    n_val = len(candidate)
    g = []
    current_val = objective(candidate)
    # Perturbation step (small)
    eps = 0.001 * min(candidate) if min(candidate) else 0.001
    for i in range(n_val):
        c_pert = candidate.copy()
        c_pert[i] += eps
        forward = objective(c_pert) - current_val
        
        c_pert = candidate.copy()
        c_pert[i] -= eps
        backward = current_val - objective(c_pert)
        
        grad = (forward + backward) / (2 * eps) if eps else 0.0
        g.append(grad)
    return g
```

def optimize_with_gradient(candidate, max_steps=500, patience=10):
    best_candidate = candidate.copy()
    best_value = objective(best_candidate)
    history = best_value
    learning_rate = 0.01
    steps_without_improvement = 0
    # Early stopping
    for step in range(max_steps):
        # Stop if improvement plateaus
        if steps_without_improvement >= patience:
            break
        current_val = objective(best_candidate)
        grad = get_gradient(best_candidate)
        
        # Project gradient (dampen, clip)
        grad = [min(max(g, -5), 5) for g in grad]
        learning_rate = max(0.0001, 0.01 * 0.92 ** step)
        new_candidate = best_candidate.copy()
        
        for i in range(len(new_candidate)):
            new_candidate[i] += learning_rate * grad[i]
            new_candidate[i] = max(0, min(new_candidate[i], 1000))
        
        # Evaluate new candidate
        new_val = objective(new_candidate)
        if new_val < best_value:
            best_value = new_val
            best_candidate = new_candidate.copy()
            steps_without_improvement = 0
        else:
            steps_without_improvement += 1
    return best_candidate
