import time

def _proj_simplex(v, s=1.0):
    """Project v onto {x >= 0, sum(x) = s}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cv - s))[0][-1]
    theta = (cv[rho] - s) / (rho + 1.0)

I want: grad[i] = (1/sw) * sum_k w[k] * a[k-i] * I(0 <= k-i < n) for i = 0..n-1.

(a ⋆ w)[i] = sum_j a[j] w[j+i]

(a * w_rev)[m] = sum_j a[j] w_rev[m-j] = sum_j a[j] w[2n-2-m+j]

I want (a ⋆ w)[i] = sum_j a[j] w[i+j].

So grad[i] = (a * w_rev)[2n-2-i] / sw.

The convolution (a * w_rev) has length n + (2n-1) - 1 = 3n - 2.
I need entries m = 2n-2, 2n-3, ..., n-1 (for i = 0, 1, ..., n-1).
That's entries [n-1, n, ..., 2n-2] in reverse order.

In numpy: c[n-1 : 2n-1][::-1] where c is the convolution.
