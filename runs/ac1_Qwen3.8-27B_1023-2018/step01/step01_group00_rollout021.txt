```python
            rk = r - k
            if 0 <= rk < n:
                g += a[rk]
            grad[r] += pk * g
    
    return grad, float(U)
```

This is O(n * |active|) per gradient call. For n=192 and |active|~20-50, that's ~4000-10000 inner loop iterations. In Python, that's maybe 1-3ms. Over 800s, we can do ~270,000-800,000 gradient evaluations. More than enough.

But I can vectorize the inner loop:

```python
    for k in active_idx:
        k = int(k)
        pk = float(p[k])
        lo = max(0, k - n + 1)
        hi = min(k, n - 1)
        if hi < lo:
            continue
        r = np.arange(lo, hi+1)
        kr = k - r  # indices for a[k-r]
        rk = r - k  # indices for a[r-k]
        g = np.zeros(hi - lo + 1, dtype=np.float64)
        mask1 = (kr >= 0) & (kr < n)
        mask2 = (rk >= 0) & (rk < n)
        g[mask1] += a[kr[mask1]]
        g[mask2] += a[rk[mask2]]
        grad[lo:hi+1] += pk * g
```

This reduces the inner Python loop to just the active idx loop (20-50 iterations) with vectorized numpy operations inside. Much faster.

Let me now write the complete program. I'll structure it as:

1. `_get_parent()` - retrieve parent sequence
2. `_conv(a)` - FFT-based convolution
3. `_softmax(z)` - softmax
4. `_grad_lse(a, b, tau)` - gradient of soft-LSE
5. `_optimize(n, init_a, seed, stop_time)` - main gradient optimization
6. `_polish(seq, stop_time)` - local refinement
7. `propose_candidate()` - main entry point

Let me also add a key improvement: instead of just using the single max position (or soft max), I'll use the top-K positions with equal weights. This gives a "multimodal" gradient that pushes down multiple peaks simultaneously.

Actually, the soft-LSE already handles this - as tau decreases, it concentrates on the argmax, and as tau increases, it spreads over multiple positions. The annealing schedule controls this.

Let me also add: periodic "peak flattening" moves where I explicitly try to reduce the gap between the top few convolution values.

Here's my final plan for the optimization:

Phase 1 (0-600s): Gradient descent on softmax parameterization
- Start from parent (or log of parent for z initialization)
- Adam optimizer
- Temperature annealing from high to low
- Periodic restart from best
- Check time every 100 iterations

Phase 2 (600-1100s): Local polish
- Small random perturbations (Gaussian, Laplace)
- Block multipliers
- Symmetry enforcement (try a -> (a + a[::-1])/2)
- Coordinate-wise adjustments

Phase 3 (1100-1295s): Final validation and return

- Time management (check deadline frequently)

- Using the exact evaluator for acceptance

One more thought: for the initialization z, I should use z = log(a_parent) - log(a_parent).mean() to start near the parent in log-space. This ensures the first candidate is close to the parent.

Let me also try a trick: since the score is scale-invariant, I can normalize a to have sum=1 at each step (this doesn't change the score but helps numerical stability). In the softmax parameterization, this is automatic.

Actually wait - in the softmax parameterization, a = softmax(z) automatically has sum=1. So the score becomes simply 2n * max(conv(softmax(z), softmax(z))). That's clean.

But the evaluator doesn't normalize! It uses the actual sum. However, since the score is:
2n * max_b / sum²

And if I scale a by c: max(conv(ca, ca)) = c² * max(conv(a,a)), sum(ca) = c * sum(a), score = 2n * c² * max_b / (c * sum)² = 2n * max_b / sum². Same score!

So I can freely normalize. Using softmax (sum=1) is fine.

```python
import numpy as np
import time
import math
from scipy.fft import rfft, irfft, next_fast_len


def _get_parent():
    try:
        h = globals()["height_sequence_1"]
        p = np.asarray(h, dtype=np.float64).ravel()
        p = np.clip(p, 0.0, 1000.0)
        if p.size == 0 or not np.isfinite(p).all() or p.sum() < 0.01:
            return np.ones(192, dtype=np.float64)
        return p
    except Exception:
        return np.ones(192, dtype=np.float64)


def _conv(a):
    n = a.size
    if n <= 1:
        return np.array([a[0] * a[0] if n == 1 else 0.0])
    fsize = next_fast_len(2 * n - 1)
    F = rfft(a, fsize)
    c = irfft(F * F, fsize)[:2 * n - 1]
    c = np.where(c < 0.0, 0.0, c)
    c = np.where(np.isfinite(c), c, 0.0)
    return c


def _softmax(z):
    z = z - z.max()
    e = np.exp(z)
    s = e.sum()
    if s <= 0 or not np.isfinite(s):
        return np.full(z.size, 1.0 / z.size, dtype=np.float64)
    return e / s


def _grad_lse(a, tau, n):
    """Gradient of soft-LSE(conv(a,a)) w.r.t. a. Returns (grad, lse_value)."""
    b = _conv(a)
    m = float(b.max())
    if not np.isfinite(m):
        m = 0.0
    x = (b - m) / tau
    e = np.exp(x)
    s = e.sum()
    if s <= 0 or not np.isfinite(s):
        p = np.zeros_like(b)
        p[int(np.argmax(b))] = 1.0
        U = m
    else:
        p = e / s
        U = m + tau * math.log(s)

    L = b.size
    thresh = max(1e-14, float(p.max()) * 1e-8)
    active = np.where(p > thresh)[0]
    if active.size == 0:
        active = np.array([int(np.argmax(p))])

    grad = np.zeros(n, dtype=np.float64)
    for k in active:
        k = int(k)
        pk = float(p[k])
        if pk <= 0:
            continue
        lo = max(0, k - n + 1)
        hi = min(k, n - 1)
        if hi < lo:
            continue
        r = np.arange(lo, hi + 1)
        kr = k - r
        rk = r - k
        g = np.zeros(hi - lo + 1, dtype=np.float64)
        mask1 = (kr >= 0) & (kr < n)
        mask2 = (rk >= 0) & (rk < n)
        if mask1.any():
            g[mask1] += a[kr[mask1]]
        if mask2.any():
            g[mask2] += a[rk[mask2]]
        grad[lo:hi + 1] += pk * g

    return grad, float(U)


def _exact_score(a):
    s = float(a.sum())
    if s < 0.01:
        return math.inf
    b = _conv(a)
    m = float(b.max())
    if not np.isfinite(m) or m < 0:
        return math.inf
    return 2.0 * a.size * m / (s * s)


def _optimize_main(parent, seed, stop_time, best_seq, best_score):
    """Main gradient-based optimization on parent-length sequence."""
    n = parent.size
    rng = np.random.default_rng(seed)
    fsize = next_fast_len(2 * n - 1)

    # Initialize from parent
    a0 = parent.copy()
    s0 = a0.sum()
    if s0 < 0.01:
        a0 = np.ones(n) / n
        s0 = 1.0
    a0 = a0 / s0  # normalize to sum=1

    z0 = np.log(a0 + 1e-30)
    z0 = z0 - z0.mean()

    best_a = a0.copy()
    best_sc = float(best_score)

    # Score with sum=1 normalization: 2n * max(conv)
    # For validation against evaluator, we use actual values

    tau0 = 0.08 * max(float(_conv(a0).max()), 1e-10)
    base_lr = 0.30

    for restart in range(60):
        if time.monotonic() > stop_time - 3.0:
            break

        if restart == 0:
            z = z0.copy()
        else:
            # Restart from best with perturbation
            z_best = np.log(best_a + 1e-30)
            z_best = z_best - z_best.mean()
            sigma = 0.3 * (1.0 - 0.7 * restart / 60.0)
            z = z_best + rng.normal(0.0, sigma, n)

        z = np.clip(z, -15.0, 15.0)
        a = _softmax(z)
        b = _conv(a)
        sc = 2.0 * n * float(b.max())  # with sum=1

        if np.isfinite(sc) and sc < 2.0 * n * float(best_seq.sum()) ** -2 * float(_conv(best_seq).max()):
            # Check against best
            pass

        m_opt = np.zeros(n, dtype=np.float64)
        v_opt = np.zeros(n, dtype=np.float64)
        t_count = 0
        lr = base_lr
        tau = tau0
        stuck = 0
        last_improve_t = time.monotonic()
        cur_sc = sc

        # Anneal tau
        tau_start = 0.06 * max(float(b.max()), 1e-10)
        n_inner = 0
        max_inner = 8000

        while time.monotonic() < stop_time - 5.0 and n_inner < max_inner:
            n_inner += 1

            if n_inner % 200 == 0:
                # Evaluate against global best
                trial = a * (best_seq.sum() / a.sum()) if a.sum() > 0 else a
                trial = np.clip(trial, 0, 1000)
                if trial.sum() < 0.01:
                    trial = np.ones(n) / n
                try:
                    es = float(evaluate_sequence([float(x) for x in trial]))
                except Exception:
                    es = math.inf
                if np.isfinite(es) and es < best_sc - 1e-10:
                    best_a = trial.copy()
                    best_sc = es
                    last_improve_t = time.monotonic()

            # Compute gradient
            b = _conv(a)
            bmax = float(b.max())
            cur_sc = 2.0 * n * bmax  # with sum=1

            if not np.isfinite(cur_sc):
                break

            # Anneal tau
            progress = min(1.0, n_inner / max(100, max_inner) * 2.0)
            tau = tau_start * (1.0 - 0.85 * progress) + 1e-8 * bmax

            grad_a, U = _grad_lse(a, tau, n)

            # Convert to gradient w.r.t. z: da_i/dz_j = a_i(δ_ij - a_j)
            # d(f)/dz_j = sum_i d(f)/da_i * da_i/dz_j
            # = d(f)/da_j * a_j - a_j * sum_i d(f)/da_i * a_i
            S = float(np.dot(grad_a, a))
            grad_z = a * (grad_a - S)

            if not np.isfinite(grad_z).all():
                grad_z = np.where(np.isfinite(grad_z), grad_z, 0.0)

            gnorm = float(np.max(np.abs(grad_z))) if grad_z.size else 0.0
            if not np.isfinite(gnorm) or gnorm < 1e-15:
                stuck += 1
                if stuck > 20:
                    break
                z += rng.normal(0.0, 0.5, n)
                z -= z.mean()
                a = _softmax(z)
                continue

            # Adam update
            t_count += 1
            m_opt = 0.9 * m_opt + 0.1 * grad_z
            v_opt = 0.999 * v_opt + 0.001 * (grad_z * grad_z)
            m_hat = m_opt / (1.0 - 0.9 ** t_count)
            v_hat = v_opt / (1.0 - 0.999 ** t_count)
            direction = m_hat / (np.sqrt(v_hat) + 1e-8)
            direction[~np.isfinite(direction)] = 0.0
            dn = float(np.max(np.abs(direction)))
            if not np.isfinite(dn) or dn <= 0:
                continue

            # Line search
            improved = False
            for factor in (1.0, 0.5, 0.25, 0.125, 0.0625):
                cand_z = z - lr * factor * direction
                cand_z -= cand_z.mean()
                cand_z = np.clip(cand_z, -15.0, 15.0)
                cand_z[~np.isfinite(cand_z)] = 0.0
                cand_a = _softmax(cand_z)
                cand_b = _conv(cand_a)
                cand_sc = 2.0 * n * float(cand_b.max())

                if np.isfinite(cand_sc) and cand_sc < cur_sc * (1.0 - 1e-10):
                    z = cand_z
                    a = cand_a
                    cur_sc = cand_sc
                    improved = True
                    break

            if improved:
                stuck = 0
            else:
                stuck += 1
                lr = max(1e-5, lr * 0.92)
                if stuck >= 40:
                    z = z + rng.normal(0.0, 0.4, n)
                    z -= z.mean()
                    z = np.clip(z, -15.0, 15.0)
                    a = _softmax(z)
                    m_opt = np.zeros(n, dtype=np.float64)
                    v_opt = np.zeros(n, dtype=np.float64)
                    t_count = 0
                    lr = base_lr
                    stuck = 0

        # After inner loop, evaluate best found
        try:
            es = float(evaluate_sequence([float(x) for x in a]))
        except Exception:
            es = math.inf
        if np.isfinite(es) and es < best_sc:
            best_a = a.copy()
            best_sc = es

    return best_a, best_sc


def _quick_optimize(n, seed, stop_time, parent):
    """Quick optimization at a different length."""
    rng = np.random.default_rng(seed)
    a = np.ones(n, dtype=np.float64) / n

    # Try to inherit from parent
    if parent.size > 0 and parent.size > 1:
        P = parent.size
        idx = np.round(np.linspace(0, P - 1, n)).astype(int)
        a = np.maximum(parent[idx], 1e-6)
        a = a / a.sum()

    z = np.log(a + 1e-30)
    z = z - z.mean()
    best_a = a.copy()
    best_sc = _exact_score(best_a)

    base_lr = 0.2
    tau = 0.05 * max(float(_conv(a).max()), 1e-10)
    lr = base_lr
    stuck = 0
    t_count = 0
    m_opt = np.zeros(n, dtype=np.float64)
    v_opt = np.zeros(n, dtype=np.float64)

    while time.monotonic() < stop_time - 3.0:
        b = _conv(a)
        bmax = float(b.max())
        if not np.isfinite(bmax):
            break
        cur_sc = 2.0 * n * bmax

        grad_a, U = _grad_lse(a, tau, n)
        if not np.isfinite(grad_a).all():
            break
        S = float(np.dot(grad_a, a))
        grad_z = a * (grad_a - S)
        grad_z[~np.isfinite(grad_z)] = 0.0
        gnorm = float(np.max(np.abs(grad_z)))
        if gnorm < 1e-15:
            stuck += 1
            if stuck > 30:
                break
            z += rng.normal(0.0, 0.3, n)
            z -= z.mean()
            a = _softmax(z)
            continue

        t_count += 1
        m_opt = 0.9 * m_opt + 0.1 * grad_z
        v_opt = 0.999 * v_opt + 0.001 * (grad_z * grad_z)
        m_hat = m_opt / (1.0 - 0.9 ** t_count)
        v_hat = v_opt / (1.0 - 0.999 ** t_count)
        direction = m_hat / (np.sqrt(v_hat) + 1e-8)
        direction[~np.isfinite(direction)] = 0.0

        improved = False
        for factor in (1.0, 0.5, 0.25):
            cand_z = z - lr * factor * direction
            cand_z -= cand_z.mean()
            cand_z = np.clip(cand_z, -15.0, 15.0)
            cand_a = _softmax(cand_z)
            cand_sc = 2.0 * n * float(_conv(cand_a).max())
            if np.isfinite(cand_sc) and cand_sc < cur_sc * (1.0 - 1e-10):
                z = cand_z
                a = cand_a
                cur_sc = cand_sc
                improved = True
                break

        if not improved:
            stuck += 1
            lr = max(1e-5, lr * 0.9)
            if stuck >= 30:
                break
        else:
            stuck = 0

        # Periodic anneal
        if t_count % 200 == 0:
            tau *= 0.85

    # Final evaluate
    try:
        es = float(evaluate_sequence([float(x) for x in a]))
    except Exception:
        es = math.inf
    if np.isfinite(es) and es < best_sc:
        best_a = a.copy()
        best_sc = es

    return best_a, best_sc


def _polish(seq, best_score, stop_time):
    """Local refinement with small perturbations."""
    a = np.asarray(seq, dtype=np.float64).ravel()
    n = a.size
    rng = np.random.default_rng(777)

    best = a.copy()
    bs = float(best_score)
    if not np.isfinite(bs):
        bs = _exact_score(best)

    sigma = 0.08
    stuck = 0

    while time.monotonic() < stop_time - 2.0:
        cur = best.copy()
        s = cur.sum()
        if s < 0.01:
            cur = np.ones(n) / n
            s = 1.0

        r = rng.random()
        if r < 0.35:
            # Gaussian in log space
            z = np.log(np.clip(cur, 1e-10, 1e10))
            z += rng.normal(0.0, sigma, n)
            z -= z.mean()
            cand = _softmax(z)
            # Scale back to match sum
            cand = cand * s
        elif r < 0.55:
            # Block multiplier
            cand = cur.copy()
            width = max(1, int(rng.integers(2, max(3, n // 20))))
            start = int(rng.integers(0, max(1, n - width)))
            cand[start:start + width] *= float(np.exp(rng.normal(0.0, 0.15)))
        elif r < 0.65:
            # Symmetrize
            cand = 0.5 * (cur + cur[::-1])
        elif r < 0.75:
            # Chirp perturbation
            i = np.arange(n, dtype=np.float64)
            freq = rng.uniform(0.5, 3.0)
            amp = sigma * 0.3
            cand = cur * (1.0 + amp * np.sin(2.0 * math.pi * freq * i / n + rng.uniform(0, 2 * math.pi)))
        elif r < 0.85:
            # Coordinate nudge
            cand = cur.copy()
            k = int(rng.integers(1, max(2, n // 3)))
            idx = rng.integers(0, n, size=k)
            cand[idx] *= np.exp(rng.normal(0.0, sigma * 0.5, size=k))
        else:
            # Interpolate with uniform
            t = rng.uniform(0.02, 0.08)
            cand = (1.0 - t) * cur + t * (s / n)

        cand = np.clip(cand, 0.0, 1000.0)
        cs = cand.sum()
        if cs < 0.01:
            continue

        # Fast score check
        fs = _exact_score(cand)
        if not np.isfinite(fs) or fs >= bs - 1e-10:
            stuck += 1
            if stuck % 30 == 0:
                sigma = min(0.5, sigma * 1.3)
            continue

        # Exact evaluation
        try:
            es = float(evaluate_sequence([float(x) for x in cand]))
        except Exception:
            es = math.inf

        if np.isfinite(es) and es < bs - 1e-9:
            best = cand.copy()
            bs = es
            stuck = 0
            sigma = max(0.03, sigma * 0.92)
        else:
            stuck += 1
            if stuck > 150:
                stuck = 0
                sigma = 0.15

    return best, bs


def propose_candidate(seed=42, budget_s=1300, **kwargs):
    t0 = time.monotonic()
    budget = max(0.0, float(budget_s))
    deadline = t0 + budget - 8.0  # 8s headroom

    parent = _get_parent()
    n_p = parent.size

    # Validate parent
    try:
        ps = float(evaluate_sequence([float(x) for x in np.clip(parent, 0, 1000)]))
    except Exception:
        ps = math.inf

    if np.isfinite(ps):
        best_seq = np.clip(parent, 0, 1000).astype(np.float64).copy()
        best_score = ps
    else:
        best_seq = np.ones(64, dtype=np.float64) / 64
        best_score = 2.0

    # Phase 1: Main optimization on parent length
    if n_p >= 4:
        phase1_stop = t0 + 0.55 * budget
        try:
            best_seq, best_score = _optimize_main(parent, int(seed), phase1_stop, best_seq, best_score)
        except Exception:
            pass

    # Phase 2: Try nearby lengths
    other_lengths = []
    for L in [n_p - 16, n_p + 16, n_p - 32, n_p + 32, n_p // 2, int(n_p * 1.5)]:
        if L >= 8 and L not in other_lengths:
            other_lengths.append(L)

    for L in other_lengths:
        if time.monotonic() > deadline - 40.0:
            break
        if best_score < 1.495:
            break
        alloc_stop = min(deadline - 20.0, time.monotonic() + 50.0)
        if alloc_stop - time.monotonic() < 5.0:
            continue
        try:
            seq, sc = _quick_optimize(L, int(seed) + L * 13 + 7, alloc_stop, parent)
            if np.isfinite(sc) and sc < best_score:
                best_seq = seq.copy()
                best_score = sc
        except Exception:
            pass

    # Phase 3: Polish the best candidate
    if time.monotonic() < deadline - 10.0:
        polish_stop = deadline - 6.0
        n_parch = max(100, int((polish_stop - time.monotonic()) / max(0.01, budget) * 100))
        try:
            best_seq, best_score = _polish(best_seq, best_score, polish_stop)
        except Exception:
            pass

    # Final exact validation
    try:
        final_score = float(evaluate_sequence([float(x) for x in best_seq]))
    except Exception:
        final_score = math.inf

    if not np.isfinite(final_score):
        # Ultimate fallback
        fb = np.ones(32, dtype=np.float64) / 32
        try:
            final_score = float(evaluate_sequence([float(x) for x in fb]))
        except Exception:
            return [1.0]
        best_seq = fb

    return [float(x) for x in best_seq]
```
