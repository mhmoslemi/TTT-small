**Let me try a different algorithm: Iterative Proportional Fitting**

Initialize `a` (normalized).
Repeat:
1. Compute `b = a * a`.
2. Compute target: `T = mean(b)` (or `T = max(b)` for the min-max problem).
3. For each lag `k`, the "deficit" is `T - b_k` (positive if below target).
4. Redistribute: increase `a_i` where it contributes to lags with deficit, decrease where it contributes to lags with surplus.
5. `a_i <- a_i * (1 + η * sum_k (T - b_k) * ∂b_k/∂a_i / mean)`
6. Clip, normalize, repeat.
