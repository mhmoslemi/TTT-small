The Hessian of b[n-1] with respect to a is 2*Q_{n-1} (if we write it as a^T Q a, the Hessian is Q + Q^T = 2Q since Q is symmetric). Q_{n-1} has 1s where i + j = n-1, i.e., it's the anti-identity matrix J. The eigenvalues of J are ±1. So the Hessian has eigenvalues ±2, and b[n-1] is indefinite (neither convex nor concave).

So the problem is genuinely non-convex. Gradient descent will find a local minimum. The question is whether the global minimum is unique or if there are many local minima.

Given that the parent already achieves 1.5378 and the target is 1.5027, we need to improve by about 2.3%. This suggests we're in a local minimum that's close to the global one, and we need a more careful optimization.

Let me implement a more sophisticated approach:

1. **L-SBRL (Line Search with Backtracking and Restarting Loop)**: Standard gradient descent with backtracking, restart every K iterations with a slightly perturbed direction.

2. **Adaptive smoothing**: Start with small tau (smooth approximation) and gradually increase to sharpen toward the true max.

3. **Momentum (Nesterov acceleration)**: Use momentum to speed up convergence.

4. **Multiple starting points**: Try the parent, a raised cosine, a Gaussian, and a "two-bump" shape.

Let me also consider: the problem has n=4806 variables. The gradient computation is O(n log n) via FFT. The main cost is the backtracking line search, which requires evaluating the objective (or a smoothed version) at each trial point.

For the smoothed objective F_tau(a) = (1/tau) * log(sum exp(tau*b[k])), we can compute it in O(n log n) (one convolution + log-sum-exp). The gradient is also O(n log n).

Per iteration: O(n log n) * (1 + number of backtracking trials). With 5 backtracking trials on average, that's about 6 * O(n log n) ≈ 6 * 2 * 16384 * 14 ≈ 2.75M floating point operations. At ~1 GFLOPS (single thread, numpy), that's ~3ms per iteration. In 1285s, we can do ~400,000 iterations.

That's way more than enough. The limiting factor will be convergence speed.
