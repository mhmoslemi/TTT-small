This is actually a well-studied problem. It's related to the "minimum peak factor" of the convolved signal.

Key insight: The self-convolution is (in the z-domain) the square of the polynomial A(z) = sum a_i z^i. The coefficient of z^k in A(z)^2 is conv[k].

So we want to find a nonnegative-coefficient polynomial A(z) of degree < n with A(1) = 1 that minimizes the maximum coefficient of A(z)^2.

This is related to "flat" polynomials and "Barker-like" sequences, but with the nonnegativity constraint.

For the nonnegative constraint, one approach is to think of it as a probability distribution and minimizing the maximum of the "addition table" of two independent draws from this distribution.

Let me think about what happens with a geometric (exponential) distribution.
a_i = c * r^i for i = 0, ..., n-1, where c = (1-r)/(1-r^n) and r in (0,1).

The convolution: conv[k] = sum_i a_i * a_{k-i} = c^2 * sum_i r^i * r^{k-i} = c^2 * (number of valid i) * r^k.

Wait, that's not quite right. Let me be more careful.
conv[k] = sum_{i: 0<=i<n, 0<=k-i<n} a_i * a_{k-i} = c^2 * sum_{i: max(0,k-n+1)<=i<=min(k,n-1)} r^{i + k-i} = c^2 * (number of valid i) * r^k.

So conv[k] = c^2 * r^k * (min(k,n-1) - max(0,k-n+1) + 1) for k = 0, ..., 2n-2.

The factor (min(k,n-1) - max(0,k-n+1) + 1) is the "triangular" weight: it goes 1, 2, 3, ..., n-1, n, n, n-1, ..., 3, 2, 1.

And r^k is monotonically decreasing (for r < 1).

So conv[k] is the product of an increasing-then-decreasing (triangular) function and a decreasing (exponential) function. The maximum will be at some point where these balance.

For r close to 1, the exponential is flat and the max is approximately at the center (like the uniform case), giving max ≈ c^2 * n = n/(1-r)^2 * (1-r)^2/(1-r^n)^2 = n/(1-r^n)^2 ≈ n/(nr)^2 = 1/n for r≈1.

For r < 1, the exponential tilt shifts the peak to the left. The question is whether this reduces the max.

**Approach 1: Direct optimization with subgradient methods**
The function f(a) = max_k conv(a,a)[k] is convex in a (it's the max of linear functions). So we're minimizing a convex function over a convex set. We can use projected subgradient descent or a more sophisticated method.

The subgradient of f at a (for the active set of argmax) is:
∂f/∂a_i = sum_{k in active} (conv(a,a)[k]'s derivative w.r.t. a_i)

For conv(a,a)[k] = sum_i a_i * a_{k-i}:
∂conv[k]/∂a_i = a_{k-i} + a_{k-i} (if both terms are valid, i.e., 0 <= i < n and 0 <= k-i < n)
= a_{k-i} + a_{2k-i}... no, that's not right.

Actually, conv(a,a)[k] = sum_{i: valid} a[i] * a[k-i].
∂conv[k]/∂a_j = a[k-j] (if k-j is valid) + a[j-k] (if j-k is valid, from the "other" term).

Wait, more carefully: conv(a,a)[k] = sum_i a[i]*a[k-i].
∂/∂a_j = sum_i [δ(i,j)*a[k-i] + a[i]*δ(k-i,j)]
= a[k-j] (if 0<=k-j<n) + a[j-k] (if 0<=j-k<n)

So ∂f/∂a_j = sum_{k in active} [a[k-j] * 1(0<=k-j<n) + a[j-k] * 1(0<=j-k<n)]

This is a valid subgradient. We can use this for subgradient descent with projection onto {a >= 0, sum(a) = 1}.

**Approach 2: The LP approach (Borodich et al. style)**
Given current a with M = max(conv(a,a)):
1. Find b >= 0 that maximizes sum(b) subject to conv(a,b)[k] <= M for all k.

    """Solve LP: max 1^T b s.t. conv(a,b) <= M, b >= 0"""
    # Build constraint matrix
    # A[k, j] = a[k-j] if 0 <= k-j < n
    A = np.zeros((2*n-1, n))
    for k in range(2*n-1):
        # j ranges from max(0, k-n+1) to min(k, n-1)
        j_start = max(0, k-n+1)
        j_end = min(k, n-1)
        for j in range(j_start, j_end+1):

    res = linprog(c, A_ub=A, b_ub=np.full(2*n-1, M), bounds=(0, None), method='highs')
    if res.success:

    # A[k, j] = a[k-j] if 0 <= k-j < n, else 0

import numpy as np
import time

try:
    from scipy.optimize import linprog
except Exception:
    linprog = None


def _normalize(a, n):
    a = np.asarray(a, dtype=np.float64)
    a = np.where(np.isfinite(a) & (a > 0), a, 0.0)
    s = float(a.sum())
    if s <= 0 or not np.isfinite(s):
        return np.ones(n, dtype=np.float64) / n
    a = a / s
    return np.clip(a, 0.0, 1000.0)


def _score(a):
    a = np.asarray(a, dtype=np.float64)
    n = a.size
    if n == 0:
        return float('inf')
    c = np.convolve(a, a)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    val = 2.0 * n * float(c.max()) / (s * s)
    return val if np.isfinite(val) else float('inf')


def _build_A(a, n):
    A = np.zeros((2 * n - 1, n), dtype=np.float64)
    for j in range(n):
        A[j:j + n, j] = a
    return A


def _lp_polar(a, n, M):
    if linprog is None:
        return None
    A = _build_A(a, n)
    c = -np.ones(n, dtype=np.float64)
    b_ub = np.full(2 * n - 1, M, dtype=np.float64)
    try:
        res = linprog(c, A_ub=A, b_ub=b_ub, bounds=(0.0, None), method='highs',
                      options={'presolve': True, 'time_limit': 20.0})
    except Exception:
        try:
            res = linprog(c, A_ub=A, b_ub=b_ub, bounds=(0.0, None), method='highs')
        except Exception:
            return None
    if res is None or not getattr(res, 'success', False):
        return None
    b = np.asarray(res.x, dtype=np.float64)
    b = np.where(np.isfinite(b) & (b > 0), b, 0.0)
    s = b.sum()
    if s <= 0 or not np.isfinite(s):
        return None
    return b / s


def _subgradient_step(a, n, step):
    c = np.convolve(a, a)
    M = float(c.max())
    if M <= 0 or not np.isfinite(M):
        return a, M
    # Find active lags (top 20% of near-max)
    threshold = 0.85 * M
    active = np.where(c >= threshold)[0]
    if active.size == 0:
        active = np.array([np.argmax(c)])
    # Cap active set for efficiency
    if active.size > 30:
        top_idx = np.argsort(c[active])[::-1][:30]
        active = active[top_idx]
    # Compute subgradient
    g = np.zeros(n, dtype=np.float64)
    for k in active:
        k = int(k)
        j_start = max(0, k - n + 1)
        j_end = min(k, n - 1)
        # g[j] += a[k-j] for j in [j_start, j_end]
        # a[k-j] for j=j_start..j_end = a[k-j_start : k-j_end+1] reversed
        seg = a[k - j_end : k - j_start + 1][::-1]
        g[j_start:j_end + 1] += seg
        # Also the "reflected" part: g[j] += a[j-k] for j in [k+1, k+n-1]
        j2_start = k + 1
        j2_end = min(k + n - 1, n - 1)
        if j2_start <= j2_end:
            # a[j2-k] for j2=j2_start..j2_end = a[1 : j2_end-k+1]
            seg2 = a[0 : j2_end - k + 1]
            g[j2_start:j2_end + 1] += seg2
    g /= float(active.size)
    # Projected update
    cand = a - step * g
    return _normalize(cand, n), M


def _geometric_init(n, r):
    if r <= 0 or r >= 1:
        return np.ones(n) / n
    a = r ** np.arange(n, dtype=np.float64)
    return _normalize(a, n)


def _power_init(n, p):
    a = (np.arange(n, dtype=np.float64) + 1) ** (-p)

def _two_sided_init(n, r):

    d = np.minimum(np.arange(n), n - 1 - np.arange(n))
