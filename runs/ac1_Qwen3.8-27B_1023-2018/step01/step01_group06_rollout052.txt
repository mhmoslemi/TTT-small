**Dual formulation**: 
Minimize M subject to C_a[k] <= M for all k, a >= 0, sum(a) = 1.

The Lagrangian: L = M + sum_k λ_k (C_a[k] - M) - μ(sum(a) - 1) - sum_j ν_j a_j

∂L/∂a[j] = sum_k λ_k * ∂C[k]/∂a[j] - μ = 0
∂L/∂M = 1 - sum_k λ_k = 0
∂L/∂λ_k = C_a[k] - M <= 0 (complementary slackness: λ_k * (C_a[k] - M) = 0)
∂L/∂ν_j = -a[j] <= 0 (complementary slackness: ν_j * a[j] = 0)

So the KKT conditions give:
- sum_k λ_k = 1
- λ_k >= 0, λ_k = 0 when C_a[k] < M
- sum_k λ_k * ∂C[k]/∂a[j] = μ for all j with a[j] > 0
- a[j] >= 0, a[j] = 0 when sum_k λ_k * ∂C[k]/∂a[j] > μ

This is like: find weights λ on the active lags such that the "load" on each a[j] is equal (for active j).

The multiplicative update is essentially an approximation of this: it adjusts a[j] to equalize the load, and the "active set" is the top lags.

A faster approach would be to directly solve for the equalization condition. At each step:
1. Identify active lags S (where C[k] ≈ M)
2. Solve for μ: sum_k in S: λ_k * ∂C[k]/∂a[j] = μ for all j
3. Update a[j] based on the ratio μ / load[j]

This is essentially what the LP does in one step (finding the best b given the active set).

Let me implement a "dual ascent" approach:
1. Start with λ = uniform over top-K lags
2. Compute load[j] = sum_k λ_k * ∂C[k]/∂a[j]
3. Update: a[j] = max(0, a[j] * μ / load[j]) where μ = sum(a) / sum(1/load[j]) (to maintain sum(a)=1)
4. Update λ: λ_k ∝ (C[k] - M)^+ (proportional to constraint violation)
5. Repeat

This is a discretized version of the KKT conditions and should converge faster than the parent's uniform-weight update.
