If I normalize so S = 1, then `score = 2n * max(b)` and `b = a * a` where `sum(a) = 1`.

The minimum possible score... Let me think. If `a` is uniform (all `1/n`), then `max(b) = n/n^2 = 1/n`, score = 2. 

To get below 2, we need `max(b) < 1/n`. This means the convolution must be "flatter" than the triangular convolution of the uniform sequence.

One way to think about it: the convolution `b_k = sum_i a_i a_{k-i}`. The sum of all `b_k` is `(sum a)^2 = 1`. If `b` were perfectly uniform over `2n-1` entries, each would be `1/(2n-1)`, and the score would be `2n/(2n-1) ≈ 1`. But the convolution of a non-negative sequence with itself is always "unimodal" (increases then decreases), so it can't be uniform.

The best we can do is make it as flat as possible in the middle. This is related to the theory of "flat" sequences or "Costas arrays" in a sense.

For the LP approach: given current `a` with `max(a*a) = M`, we find `g` that maximizes `sum(g)` subject to `a*g <= M` componentwise. This `g` is "dual" to `a` in some sense - it's the sequence that, when convolved with `a`, stays below the current peak. By blending `a` and `g`, we hope to reduce the peak of the new convolution.

I think the key insight is that the LP approach converges to a local optimum where `a` and `g` are "dual" - i.e., `a*a = g*g = M * (some flat pattern)`. At such a fixed point, the sequence is locally optimal for the LP-based method.

To escape such a local optimum, we need a different method (like subgradient or coordinate descent).
