```python
def _project_simplex(z):
    """Project z onto {x >= 0, sum(x) = 1}."""
    n = len(z)
    if n == 0:
        return z
    # Sort z in descending order
    u = np.sort(z)[::-1]
    cssv = np.cumsum(u)
    rho = np.max(np.where(u * np.arange(1, n+1) > (cssv - 1), np.arange(1, n+1), 0))
    if rho == 0:
        return np.ones(n) / n
    theta = (cssv[rho-1] - 1) / rho
    return np.maximum(z - theta, 0)
```

The projection of z onto {x ≥ 0, sum(x) = 1} is:
- Find τ such that x_i = max(z_i - τ, 0) and sum(x_i) = 1
- This is equivalent to finding τ such that sum(max(z_i - τ, 0)) = 1

The standard algorithm:
1. Sort z in descending order: z_(1) ≥ z_(2) ≥ ... ≥ z_(n)
2. For each ρ = 1, ..., n, compute τ_ρ = (sum_{i=1}^ρ z_(i) - 1) / ρ
3. The correct ρ* is the largest ρ such that z_(ρ) > τ_ρ
4. Then x_i = max(z_i - τ_ρ*, 0)

```python
def _project_simplex(z):
    """Project z onto {x >= 0, sum(x) = 1}."""
    n = z.size
    if n <= 1:
        v = np.clip(z, 0, 1).astype(np.float64)
        s = v.sum()

            v /= s
        else:
            v = np.ones(n, dtype=np.float64) / max(n, 1)
```
