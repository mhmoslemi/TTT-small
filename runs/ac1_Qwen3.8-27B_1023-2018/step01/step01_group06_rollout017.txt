Let me think about this more carefully. We want to minimize:
score = 2n * max_k conv_k / (sum a)²

where conv_k = (a*a)[k] = Σ_j a[j]*a[k-j] (valid indices only), a ≥ 0.

This is scale-invariant, so we can set sum(a) = 1.
Then score = 2n * max_k conv_k.

We want to minimize max_k conv_k subject to a ≥ 0, sum(a) = 1.

The constraint is: for all k, Σ_j a[j]*a[k-j] ≤ C (minimize C).

This is a nonlinear (quadratic) constraint. The feasible set is non-convex in general (though the constraint a ≥ 0, sum a = 1 is convex, the quadratic constraints define a non-convex region... actually wait, each constraint aᵀ T_k a ≤ C where T_k is a (symmetric) matrix. If T_k is PSD, the constraint is convex (superlevel set of a convex function is... no, sublevel set of convex is convex). 

Actually aᵀ T a ≤ C with T PSD is a convex constraint (it's an ellipsoid). So if all the T_k matrices are PSD, the feasible region is convex!

Let me check: (a*a)[k] = aᵀ T_k a where T_k is the "reflection" matrix shifted by k.

For k < n: T_k has (T_k)[i,j] = 1 if j-i = k or i-j = k... no, let me think.

(a*a)[k] = Σ_i a[i] * a[k-i]

Let j = k-i, so i + j = k.
(a*a)[k] = Σ_{i+j=k} a[i]*a[j]

This can be written as aᵀ M_k a where M_k is the matrix with M_k[i,j] = 1 if i+j = k, and 0 otherwise. Wait, that's not symmetric in the right way for a quadratic form.

Actually: aᵀ M a = Σ_{i,j} a[i] M[i,j] a[j]

For (a*a)[k] = Σ_i a[i] a[k-i], we need:
aᵀ M_k a = Σ_{i,j} M_k[i,j] a[i] a[j] = Σ_i a[i] a[k-i]

So M_k[i,j] = 1 if j = k-i, i.e., i+j = k.

M_k is an anti-diagonal matrix (ones on the k-th anti-diagonal). This matrix is symmetric! M_k[i,j] = 1 iff i+j=k, and M_k[j,i] = 1 iff j+i=k, same thing.

Is M_k PSD? M_k is a symmetric matrix with ones on one anti-diagonal. The eigenvalues... For a matrix with ones on the k-th anti-diagonal of an n×n matrix, the eigenvalues are 0 and ±1 (each with multiplicity roughly n/2). Actually, for the anti-diagonal identity matrix (k = n-1), the eigenvalues are all ±1. For other k, there are more zeros.

So M_k is NOT PSD in general (it has negative eigenvalues). Therefore the constraint (a*a)[k] ≤ C is NOT convex in general.

However! Since a ≥ 0, we're restricted to the non-negative orthant. On this orthant, aᵀ M_k a = Σ_{i+j=k} a[i]*a[j] ≥ 0 (since all a[i] ≥ 0). But the constraint is still non-convex because M_k has negative eigenvalues.

So the problem is a non-convex quadratic program. That explains why we need iterative methods.
