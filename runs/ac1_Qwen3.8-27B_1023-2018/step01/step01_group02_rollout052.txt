                prob.solve(solver=cp.PDLP)

        return None

    s = np.sum(g_val)
    if s < 1e-12:
        return None
    return g_val / s  # Normalize to sum 1

The intuition: f convolved with g should not exceed M (the current max autocorrelation of f). This means g is "compatible" with f's constraint. Maximizing sum(g) means we want the "largest" such g.

The LP would find a g that maximizes sum(g) subject to this, likely g = uniform as well.

For a non-uniform f, the constraint is more interesting and would guide g toward a better shape.
