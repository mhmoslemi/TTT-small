```python
def _conv_mat(a):
    n = len(a)
    nn = 2 * n - 1
    # For each (m, j) pair where 0 <= m < nn, 0 <= j < n, 0 <= m-j < n
    # A[m, j] = a[m-j]
    m_idx = np.repeat(np.arange(nn), n)
    j_idx = np.tile(np.arange(n), nn)
    a_idx = m_idx - j_idx
    valid = (a_idx >= 0) & (a_idx < n)
    m_idx = m_idx[valid]
    j_idx = j_idx[valid]
    a_idx = a_idx[valid]
    data = a[a_idx]
    nz = data > 1e-18
    m_idx = m_idx[nz]
    j_idx = j_idx[nz]
    data = data[nz]
    return sps.csr_matrix((data, (m_idx, j_idx)), shape=(nn, n))
```

X + Y = (a_0^2 + ... + a_{k-1}^2) + 2*(a_k^2 + ... + a_{n-1-k}^2) + (a_{n-k}^2 + ... + a_{n-1}^2)

This is <= 2*(a_0^2 + ... + a_{n-1}^2) = 2*c(0).

So c(k) <= (X+Y)/2 <= c(0). So c(k) <= c(0) for all k!

But in my example, a = [3,1,1], c(0) = 9 (at index 0 of the conv), and the center value is c at index n-1=2, which is 7. And c at index 1 is 6. So max is 9 at index 0.

c(0) in my notation (the "zero-lag" autocorrelation) corresponds to index n-1 in the convolution, which is 7. But conv[0] = a[0]^2 = 9, which is the "lag -(n-1)" or "lag n-1" value.

So the "zero-lag" in the autocorrelation sense is at the center of the convolution, but the max is at the edge (lag ±(n-1)), where it equals a[0]^2 or a[n-1]^2.

So the max of the convolution is max(a[0]^2, a[n-1]^2, c_center, ...), and it's NOT simply sum(a_i^2) in general.

OK so the problem is more complex than I thought. The max can be at the edges or the center.

For a "bump" sequence (high in the middle, low at the edges), the max is at the center = sum(a_i^2).
For a sequence with large values at the edges, the max is at the edges = max(a_0^2, a_{n-1}^2).

The parent sequence has score 1.522 < 2, which means max(conv) / sum(a)^2 < 1/n. For uniform, this ratio is exactly 1/n. So the parent must have a non-trivial structure where the max autocorrelation is below the uniform level.

This is possible if the sequence is designed so that:
- The center value (sum a_i^2) is not the max
- The edge values (a_0^2, a_{n-1}^2) are small
- The intermediate values are small
