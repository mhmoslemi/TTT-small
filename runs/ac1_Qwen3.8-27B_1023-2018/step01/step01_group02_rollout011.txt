This is getting complicated. Let me think about it from the optimization perspective.

The score is 2n * max(conv(a,a)) / (sum(a))².

Since it's scale-invariant, set sum(a) = 1. Then score = 2n * max(conv(a,a)).

We want to minimize max(conv(a,a)) subject to sum(a) = 1, a >= 0.

This is a convex optimization problem! min max_k conv_k(a,a) subject to sum a = 1, a >= 0.

conv_k(a,a) is a quadratic form in a (specifically, a^T C_k a where C_k is a circulant-like matrix). The max of convex functions is convex. So this is a convex problem.

The optimal solution would make all the convolution values as equal as possible (minimax). Actually, the max of quadratics subject to linear constraint... it's convex but not necessarily with a simple closed form.
