2. Once close, identify the active set (max indices)
3. Solve the smooth subproblem exactly for that active set

For step 3: if the max is at index k*, then we minimize c_{k*} = sum_{i: 0<=k*-i<n} a[i]*a[k*-i] subject to a>=0, sum(a)=1.

This is a quadratic programming problem! And for a single active constraint, it's particularly simple.

Actually, for the full problem:
minimize sum_i a[i]*a[k*-i] (the convolution at the max index)
subject to: sum_i a[i] = 1, a[i] >= 0

This is minimizing a quadratic form with a linear constraint and box constraints. The quadratic form is:
f(a) = a^T K a where K is a symmetric matrix with K[i,j] = 1 if i + j = k* (i.e., j = k*-i), 0 otherwise.

Wait, c_{k*} = sum_i a[i]*a[k*-i]. Let j = k*-i, so i = k*-j. The valid range is max(0, k*-(n-1)) <= i <= min(n-1, k*).

So c_{k*} = sum_{i: valid} a[i]*a[k*-i]

If k* < n: valid i is [0, k*], and k*-i is in [0, k*].
If k* >= n: valid i is [k*-(n-1), n-1], and k*-i is in [0, n-1].

The quadratic form: c_{k*} = a^T B a where B[i,j] = 1 if i+j = k*, 0 otherwise.
This is a "reverse-diagonal" matrix - it has 1s along the anti-diagonal at position k*.

                    if sc < best_sc:
                        best_sc = sc
                        best_a = a.copy()

        sc = eval_a(a)
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()
        return a

    # ---- Multi-start: try base + a few perturbations ----
    rng = np.random.default_rng(seed)
    candidates = [a.copy()]
    # Small random perturbation
    p1 = a * (1.0 + 0.05 * rng.standard_normal(n))
    p1 = np.maximum(p1, 0.0)
    p1 /= p1.sum()
    candidates.append(p1)
    # Slight sharpening (power > 1 in normalized space)
    p2 = a ** 1.3
    p2 /= p2.sum()
    candidates.append(p2)
    # Slight flattening
    p3 = a ** 0.8
    p3 /= p3.sum()
    candidates.append(p3)

    # Evaluate and pick the best start
    cands_scored = []
    for c in candidates:
        sc = eval_a(c)
        if np.isfinite(sc):
            cands_scored.append((sc, c))
            if sc < best_sc:
                best_sc = sc
                best_a = c.copy()
    cands_scored.sort(key=lambda x: x[0])

    remaining = max(10.0, deadline - time.monotonic())

    # ---- Phase 1: Broad search from top seeds ----
    if remaining > 30:
        per = 0.25 * remaining / max(1, min(3, len(cands_scored)))
        for i in range(min(3, len(cands_scored))):
            if time.monotonic() > deadline:
                break
            run_phase(cands_scored[i][1].copy(), per, 20.0, 80.0, 0.02, 0.004)

    # ---- Phase 2: Focused refinement on best ----
    remaining = max(10.0, deadline - time.monotonic())
    if remaining > 15:
        run_phase(best_a.copy(), 0.5 * remaining, 50.0, 250.0, 0.004, 0.0008, b1=0.92, b2=0.999)

    # ---- Phase 3: Ultra-fine polish (near-exact gradient) ----
    remaining = max(5.0, deadline - time.monotonic())
    if remaining > 10:
        run_phase(best_a.copy(), 0.6 * remaining, 150.0, 800.0, 0.0008, 0.0001, b1=0.93, b2=0.9995)

    # ---- Phase 4: Exact single-max gradient kicks ----
    if time.monotonic() < deadline - 3.0:
        a_cur = best_a.copy()
        fa = np.fft.rfft(a_cur, sizeC)
        c = np.fft.irfft(fa * fa, sizeC)[:2 * n - 1]
        cmax = float(c.max())
        max_idx = int(np.argmax(c))
        S = float(a_cur.sum())

        # Exact subgradient: d(c_{max_idx})/d(a_i) = 2*a[max_idx - i]
        lo = max(0, max_idx - (n - 1))
        hi = min(n - 1, max_idx)
        grad_exact = np.zeros(n, dtype=np.float64)
        idx = np.arange(lo, hi + 1)
        grad_exact[idx] = 2.0 * a_cur[max_idx - idx]
        # Full gradient of 2n*cmax/S^2
        grad_full = 2.0 * n * (S * grad_exact - 2.0 * cmax) / (S * S * S)

        for lr_k in [0.005, 0.002, 0.001, 0.0005, 0.0002]:
            a_try = a_cur - lr_k * grad_full
            a_try = np.maximum(a_try, 0.0)
            s_try = float(a_try.sum())
            if s_try < 1e-15:
                continue
            a_try /= s_try
            sc_try = eval_a(a_try)
            if sc_try < best_sc:
                best_sc = sc_try
                best_a = a_try.copy()
                a_cur = a_try.copy()

    # ---- Final multi-index exact subgradient (if multiple near-max) ----
    if time.monotonic() < deadline - 2.0:
        a_cur = best_a.copy()
        fa = np.fft.rfft(a_cur, sizeC)
        c = np.fft.irfft(fa * fa, sizeC)[:2 * n - 1]
        cmax = float(c.max())
        S = float(a_cur.sum())
        # Find all indices within 1% of max
        thresh = cmax * 0.99
        active = np.where(c >= thresh)[0]
        if len(active) >= 2:
            grad_avg = np.zeros(n, dtype=np.float64)
            for k in active:
                lo = max(0, k - (n - 1))
                hi = min(n - 1, k)
                idx = np.arange(lo, hi + 1)
                grad_avg[idx] += 2.0 * a_cur[k - idx]
            grad_avg /= len(active)
            grad_full = 2.0 * n * (S * grad_avg - 2.0 * cmax) / (S * S * S)
            for lr_k in [0.002, 0.001, 0.0005]:
                a_try = a_cur - lr_k * grad_full
                a_try = np.maximum(a_try, 0.0)
                s_try = float(a_try.sum())
                if s_try < 1e-15:
                    continue
                a_try /= s_try
                sc_try = eval_a(a_try)
                if sc_try < best_sc:
                    best_sc = sc_try
                    best_a = a_try.copy()
                    a_cur = a_try.copy()

    # ---- Final validation ----
    final_sc = eval_a(best_a)
    if not np.isfinite(final_sc):
        best_a = a0.copy()
        best_a = np.clip(best_a, 0, 1000)
        s = float(best_a.sum())
        if s > 0:
            best_a /= s
        else:
            best_a = np.ones(n) / n

    out = [float(x) for x in best_a]
    # Sanity check
    if not out or any(not np.isfinite(x) for x in out):
        out = [1.0 / n] * n
    return out
