```python
def build_conv_matrix(f, lags):
    """Build sparse matrix A where A[i, m] = f[lags[i] - m] if 0 <= lags[i]-m < n."""
    n = len(f)
    K = len(lags)
    rows = []
    cols = []
    vals = []
    for i, k in enumerate(lags):
        lo = max(0, k - n + 1)
        hi = min(n - 1, k)
        if lo <= hi:
            m = np.arange(lo, hi + 1)
            rows.extend([i] * (hi - lo + 1))
            cols.extend(m.tolist())
            vals.extend(f[k - m].tolist())
    A = csc_matrix((vals, (rows, cols)), shape=(K, n))
    return A
```

This is O(n * K) for the construction, which is fine for small K.
