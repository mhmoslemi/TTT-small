- The "game" is: minimize max_k sum_i a[i]*a[k-i]

subject to: A * g <= t * 1  (A is the convolution matrix with a)
           1^T * g = 1
           g >= 0
```

This can be reformulated as:
```
minimize 0 (or t)
subject to: A * g - t * 1 <= 0
           1^T * g = 1
           g >= 0

- Variables: (g_0, ..., g_{n-1}, t)
- Minimize: t → c = [0, 0, ..., 0, 1]
- Inequality constraints: A * g - t <= 0 → [A, -1] * [g; t] <= 0
- Equality constraint: 1^T g = 1 → [1, 0] * [g; t] = 1
- Bounds: g_i >= 0, t free
