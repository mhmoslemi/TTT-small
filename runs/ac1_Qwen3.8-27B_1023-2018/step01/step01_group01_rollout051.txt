For a uniform sequence, C[n-1] = sum(a_i^2) = n*(1/n)^2 = 1/n ≈ 1.436e-4. And the target is 1.079e-4 < 1.436e-4. So we need to reduce the "middle" of the autocorrelation below 1/n.

But C[n-1] = sum(a_i * a_{n-1-i}). For a uniform sequence, this is 1/n. To reduce it, we need the sequence to be "anti-symmetric" in some sense - high values on one side should correspond to low values on the other side.

For example, if a is decreasing: a = [1, 0.9, 0.8, ..., 0.1] (normalized), then C[n-1] = sum(a_i * a_{n-1-i}) would be larger (high*high + mid*mid + low*low). If a is "bimodal" (high at both ends, low in middle), C[n-1] might be smaller.

Actually, let's think: C[n-1] = sum(a_i * a_{n-1-i}). By rearrangement inequality, this is minimized when one sequence is reversed relative to the other. But since we're correlating a with its own reverse, we can't change the ordering independently.

However, if a is symmetric (a_i = a_{n-1-i}), then C[n-1] = sum(a_i^2). If a is antisymmetric (a_i = -a_{n-1-i}), C[n-1] = -sum(a_i^2), but we need nonnegative values, so this doesn't apply.

For nonnegative a, C[n-1] = sum(a_i * a_{n-1-i}) >= 0. To minimize this while keeping sum(a) = 1, we want the "high" values of a to be concentrated where a_{n-1-i} is "low". Since a_{n-1-i} is just a reversed, we want a to be "concentrated" on one side: e.g., a = [1, 0, 0, ..., 0] gives C[n-1] = 0 (but max(C) = 1 at C[0]).

The tradeoff: concentrating a on one side reduces C[n-1] but increases C[0] (or C[n-2] etc.).

The optimal solution spreads the energy so that all C[k] are approximately equal. This is the "flat autocorrelation" problem.
