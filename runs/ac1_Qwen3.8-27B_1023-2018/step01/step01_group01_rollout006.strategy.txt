### Approach and rationale
We are addressing the minimization of the AC1 upper bound:
```latex
\text{AC1} = \frac{2n \cdot \max(\text{full convolution})}{(\sum a_i)^2}
```
by implementing a projected gradient descent method. The gradient incorporates the active set (indices where the convolution achieves its maximum) to guide updates. This method:
1. Uses the parent sequence (`height_sequence_1`) as a starting point
2. Projects updates onto the constraints \(0 \leq a_i \leq 1000\) and \(\sum a_i = \sqrt{2n}\)
3. Takes advantage of Pypy's fast JIT compilation
4. Includes time monitoring to ensure we complete within the 1300-second budget

The key bottleneck addressed is the need to compute high-dimensional gradients efficiently. We estimate gradients using active set contributions, which leverages the structure of the convolution operation. The method is simple but effective due to:
- Using the authoritative evaluator for final validation
- Performing projected updates to preserve feasibility
- Decaying the learning rate as optimization progresses

Limitations include:
- Gradient estimation relies on multiple active convolution indices
- The projected gradient method may not find global minima
- Learning rate scheduling requires hyperparameter tuning

The gradient calculation uses analytic contributions from active indices, with the update step incorporating both the gradient direction and normalization constraint. This differs from finite-difference methods by leveraging the convolution's smoothness properties.

We assume the sequence length `n` is known (6962) and we use the provided initial sequence `height_sequence_1`.

### Mathematical specification
**Representation & variables:**
- Sequence `a = (a_0, a_1, ..., a_{n-1})` with dimensions (n,)
- Normalization: \(\sum a_i = \sqrt{2n}\)
- Bound constraints: \(0 \leq a_i \leq 1000\)

**Objective:**
Minimize \(\text{AC1}(a) = \frac{2n \cdot \max_k (a * a)[k]}{(\sum a_i)^2}\)

**Gradient calculation:**
Let \(C = \text{full convolution}(a, a)\), \(M = \max_k C_k\), and \(S = \sum a_i\)
For each \(i\):
```
term1 = (2n / S²) * Σ_{k in active_set} a_{k-i}
grad_i = term1 - (4n * M) / S³
```

**Constraints handling:**
- Bounds: Clip \(a_i\) to [0, 1000]
- Normalization: Project sequence to sum(\(=\sqrt{2n}\))

**Initialization:**
- Start with provided `height_sequence_1`, clipped to [0,1000] and normalized
- Fallback: Uniform random sequence normalized to \(\sqrt{2n}\) if parent unavailable
