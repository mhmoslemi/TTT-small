def _convolve_fft(a, n, fsize):

    c = irfft(F * F, fsize)[:2*n-1]

    F = rfft(a, fsize)
    c = irfft(F * F, fsize)[:2*n-1]
    np.maximum(c, 0, out=c)

        hi = min(j + n, 2*n - 1)
        if hi > lo:
            A[lo:hi, j] = f[:hi-lo]
    return A

    A = _build_conv_matrix(f, n)

    if res.success:
        return np.maximum(res.x, 0)
    return np.ones(n)/n

def _softmax(z):

For general nonnegative f of length n:
- sum_k (f*f)[k] = (sum f)² 
- (f*f)[n-1] = sum_i f[i] * f[n-1-i] (this is the "autocorrelation at lag 0" for the specific indexing)

For a palindromic f: (f*f)[n-1] = sum_i f[i]².

But for a NON-palindromic f: (f*f)[n-1] = sum_i f[i] * f[n-1-i] which is NOT the sum of squares!

By Cauchy-Schwarz: sum_i f[i] * f[n-1-i] <= sqrt(sum f[i]² * sum f[n-1-i]²) = sum f[i]².

So (f*f)[n-1] <= sum f[i]². The center of the convolution is at most the sum of squares.

But the max of the convolution could be at a different lag! For example, if f is very asymmetric, the peak might be off-center.
