active has length conv_len = 2n-1. a has length n.
np.correlate(active, a, 'valid') computes: for each valid shift, the inner product.
'valid' mode: the smaller array slides over the larger one.
Since active has length 2n-1 and a has length n, 'valid' gives output of length (2n-1) - n + 1 = n.

Output[j] = sum_{d=0}^{n-1} active[j+d] * a[d]

Let me verify this is the gradient. 
conv[k] = sum_{i} a[i] * a[k-i] (valid)
d(conv[k])/d(a[j]) = a[k-j] (if 0 <= k-j < n)

grad[j] = sum_{k in active} d(conv[k])/d(a[j]) = sum_{k in active} a[k-j] * 1[0 <= k-j < n]
        = sum_{k in active} a[k-j] * 1[0 <= k-j <= n-1]

Let d = k-j, so k = j+d:
grad[j] = sum_{d: 0<=d<=n-1, j+d < conv_len} a[d] * active[j+d]
