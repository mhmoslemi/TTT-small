Score = 2n·M/S² where M = max_k C(k), C(k) = conv(a,a)[k], S = sum(a).

If M is achieved at lag k* (unique):
∂Score/∂a_i = 2n/S² · [∂C(k*)/∂a_i - M/S]

∂C(k*)/∂a_i: C(k*) = sum_j a_j · a_{k*-j} (with bounds)
= sum over valid (j, k*-j) pairs of a_j · a_{k*-j}

For a given i, a_i appears in C(k*) when:
- j = i: contributes a_{k*-i}
- k*-j = i, i.e., j = k*-i: contributes a_i (same as first if k*-i = i)

So ∂C(k*)/∂a_i = a_{k*-i} + a_i (if k*-i ≠ i and both in range)
= 2·a_i (if k*-i = i)
= a_{k*-i} (if k*-i out of range)
etc.

This is the "cross-correlation" of a with the indicator of lag k*.

Let me define r_i = ∂C(k*)/∂a_i. Then:
∂Score/∂a_i = (2n/S²)·(r_i - M/S)

To minimize Score, we want to decrease a_i where r_i > M/S and increase where r_i < M/S.

This is a simple subgradient step. But the max can switch between lags, causing discontinuities.

import numpy as np
import time

def _score(a):
    """Compute the exact score."""
    a = np.asarray(a, dtype=np.float64)
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-12:
        return np.inf
    c = np.convolve(a, a)
    mx = c.max()
    return 2.0 * len(a) * mx / (s * s)

def _grad_score(a, c, beta=10000, top_k=5):
    """Compute gradient of score w.r.t. a using soft-max or top-k approximation."""
    n = len(a)
    s = a.sum()
    M = c.max()
    # Soft-max weights
    z = beta * (c - M)
    w = np.exp(z)
    w /= w.sum()
    # c_soft = sum(w * c) ≈ M (close when beta large)
    # ∂c_soft/∂a_i = sum_k w_k * ∂C(k)/∂a_i
    # But this is expensive. Instead, use:
    # ∂(logsumexp(beta*c))/∂a_i = sum_k (w_k) * beta * ∂C(k)/∂a_i
    
    # Simplified: use the top-k lags
    k_idx = np.argsort(c)[-top_k:]
    weights = c[k_idx].copy()
    weights = weights / weights.sum()
    
    # Gradient of M_approx = sum(w_k * C(k))
    # ∂M_approx/∂a_i = sum_k w_k * (a_{k-i} + a_i [if k!=2i])
    # = sum_k w_k * a_{k-i} + sum_k w_k * a_i (for k where k-i != i)
    # = (w * a_reversed_correlated)_i + a_i * sum(w_k for valid k)
    
    rho = np.zeros(n)
    for k in k_idx:
        wk = weights[np.searchsorted(k_idx, k)]
        for i in range(min(k+1, n)):
            j = k - i
            if 0 <= j < n:
                rho[i] += wk * a[j]
                if i != j:
                    rho[j] += wk * a[i]
    
    # Actually this is O(n * top_k) which is fine for n=127, top_k=5
    
    score = 2*n*M/(s*s)
    grad = (2*n/(s*s)) * (rho - M/s)
    return grad, score
