   - If j in S_k: the term i=j gives a[k-j]. Also, if j in S_k means k-j in S_k too (by symmetry of the constraint), so the term i=k-j gives a[j]. If j = k-j (k=2j), these are the same term, so we get 2*a[j].
   - If j not in S_k: no contribution.
   
   So: ∂b[k]/∂a[j] = 
     - 2*a[j] if j in S_k and k = 2j
     - a[k-j] + a[j] if j in S_k and k ≠ 2j
     - 0 if j not in S_k
   = a[k-j] + a[j] if max(0,k-n+1) <= j <= min(k,n-1) and k ≠ 2j

   But note: if k=2j and j in S_k, then a[k-j] = a[j], so a[k-j]+a[j] = 2*a[j]. So actually:
   ∂b[k]/∂a[j] = a[k-j] + a[j] if max(0,k-n+1) <= j <= min(k,n-1), else 0.
   
   Great, that's a clean formula. And it's symmetric: ∂b[k]/∂a[j] = a[j] + a[k-j].

def subgradient_step(a, active_set, step_size):
    n = len(a)
    grad = np.zeros(n)
    for k in active_set:
        lo = max(0, k - n + 1)
        hi = min(k, n - 1)
        for j in range(lo, hi + 1):
            grad[j] += a[j] + a[k - j]
    grad /= len(active_set)
    # Subtract mean to maintain sum(a) = 1
    grad -= np.mean(grad)
    # Step
    a_new = a - step_size * grad
    # Project onto simplex (a >= 0, sum(a) = 1)
    a_new = project_simplex(a_new)
    return a_new

Let me focus on making the LP approach as effective as possible:

**Key insight for the LP**: The LP solution g is the "dual" of f in some sense. The product f*g <= M means that g is "fit" within the "capacity" defined by f and M. The optimal g will have its mass concentrated where it can be placed without violating the constraints.

**Improvement: Use the LP solution structure**
At the LP optimum, some constraints are tight (f*g)[k] = M. These k values tell us where the "bottleneck" is. In the next iteration, we should focus on reducing those peaks.

**Improvement: Geometric mixing**
Instead of linear mixing (1-t)a + t*g, try:
- Power mean: a^alpha * g^(1-alpha) (element-wise, for alpha in [0,1])
- This can sometimes give better results for multiplicative structures

**Improvement: Multiple LP targets**
Instead of one M, solve multiple LPs with different M values:
- M_1 = 0.9 * max_b (aggressive, forces g to be very "spread out")
- M_2 = max_b (standard)
- M_3 = 1.1 * max_b (relaxed, allows g to concentrate more)

Mix the solutions from different M values.

**Improvement: Constraint tightening**
After getting g from LP, we can tighten: the new max of ((1-t)a + t*g) * ((1-t)a + t*g) should be lower. If it's not, we need a smaller t or a different direction.
