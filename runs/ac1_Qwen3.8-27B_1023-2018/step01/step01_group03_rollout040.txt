    Subcase 1b: i >= p (i from p to k-p). B*B.
  Case 2: i >= k-p+1 (and i <= k, i < n).
    a_{k-i} = A.
    a_i = B (since i >= k-p+1 >= p+1 > p). B*A.
    Count: k - (k-p+1) + 1 = p.
  
  So conv[k] = min(p, k-p+1)*A*B + max(0, k-2p+1)*B^2 + p*A*B.
  For k < 2p: not in this range.
  For k >= 2p: min(p, k-p+1) = p (since k-p+1 >= p+1 > p). And k-2p+1 >= 1.
  conv[k] = p*AB + (k-2p+1)*B^2 + p*AB = 2pAB + (k-2p+1)B^2.
  
  This is increasing in k! So for k from 2p to n-1: conv[k] goes from 2pAB + B^2 to 2pAB + (n-2p)B^2.

For k >= n:
conv[k] = sum_{i=k-n+1}^{n-1} a_i * a_{k-i}.
This is the "tail" of the convolution, decreasing.

So for p < n/2, the full picture is:
- k = 0 to p-1: conv[k] = (k+1)A^2, increasing to pA^2.
- k = p to 2p-1: conv[k] = (2p-k-1)A^2 + 2(k-p+1)AB, decreasing (if A > B).
  At k=p: (p-1)A^2 + 2AB. At k=2p-1: 2pAB.
  Is (p-1)A^2+2AB > pA^2? No: (p-1)A^2+2AB < pA^2 iff 2AB < A^2 iff A > 2B.
  So if A > 2B, the peak is at k=p-1 with value pA^2.
  If A <= 2B, the peak might be at k=p-1 or k=p.
  
- k = 2p to n-1: conv[k] = 2pAB + (k-2p+1)B^2, increasing.
  At k=2p: 2pAB + B^2. At k=n-1: 2pAB + (n-2p)B^2.
  Compare with conv[2p-1] = 2pAB: conv[2p] = 2pAB + B^2 > 2pAB. So it keeps increasing.
  At k=n-1: 2pAB + (n-2p)B^2.

So the candidates for max are:
1. k = p-1: pA^2
2. k = n-1: 2pAB + (n-2p)B^2

(And possibly k = p if A <= 2B, but let's focus on A > 2B case.)

For A > 2B: max = max(pA^2, 2pAB + (n-2p)B^2).

Set them equal: pA^2 = 2pAB + (n-2p)B^2 → pA^2 - 2pAB = (n-2p)B^2 → pA(A-2B) = (n-2p)B^2.

S = pA + (n-p)B. Score = 2n * max / S^2.

Let r = A/B. Then: p*r^2 = 2pr + n-2p → p(r^2-2r) = n-2p → p = (n-2p)(r^2-2r)/(r^2-2r) ... this is circular.

Let me just parameterize by r and p/n = α.
S = B(nα*r + n(1-α)) = Bn(αr + 1 - α) = Bn(1 + α(r-1)).
max = B^2 * max(p*r^2, 2pr+n-2p) = B^2 * max(αnr^2, n(2αr+1-2α)).
score = 2n * B^2 * max(...) / B^2*n^2*(1+α(r-1))^2 = 2 * max(αr^2, 2αr+1-2α) / (n*(1+α(r-1))^2).

Wait, that has a 1/n factor which would make the score go to 0 as n→∞. That can't be right.

Let me redo. n is fixed (512). p = αn. A = rB.
S = αn*rB + (1-α)nB = nB(αr + 1-α) = nB(1+α(r-1)).
max_conv = B^2 * max(αnr^2, n(2αr+1-2α)).
score = 2n * B^2 * n * max(αr^2, 2αr+1-2α) / (nB(1+α(r-1)))^2
= 2n * n * B^2 * max(...) / n^2 * B^2 * (1+α(r-1))^2
= 2 * max(αr^2, 2αr+1-2α) / (1+α(r-1))^2.

The n cancels! So for this structure, the score is independent of n (as long as p = αn and the structure scales).

score(α, r) = 2 * max(αr^2, 2αr+1-2α) / (1+α(r-1))^2.

We want to minimize this over α ∈ (0,1/2) (assuming p < n/2) and r > 2 (for the A > 2B regime).

Case 1: αr^2 >= 2αr+1-2α (i.e., the first peak dominates).
score = 2αr^2 / (1+α(r-1))^2.
Let f = αr^2 / (1+α(r-1))^2. Minimize 2f.
For fixed r: df/dα = 2r^2(1+α(r-1))^2 - 4r^2*α(r-1)(1+α(r-1)) / (1+α(r-1))^4
= 2r^2(1+α(r-1))[(1+α(r-1)) - 2α(r-1)] / (1+α(r-1))^4
= 2r^2[1+α(r-1)-2α(r-1)] / (1+α(r-1))^3
= 2r^2[1-α(r-1)] / (1+α(r-1))^3.
This is positive when α < 1/(r-1). So f increases in α for α < 1/(r-1).
Since α < 1/2 and r > 2, 1/(r-1) < 1, so the max of α in range is min(1/2, 1/(r-1)).
If 1/(r-1) < 1/2 (i.e., r > 3): f is increasing on [0, 1/2], so minimum at α→0.
As α→0: f → 0. But this means p→0, and the sequence is almost all B with a tiny spike of A.
score → 2*0/1 = 0? That can't be right.

Wait, as α→0, p→0 (but p must be at least 1). Let me keep p fixed and let n→∞.
If p=1: a = [A, B, B, ..., B]. S = A + (n-1)B. max_conv = A^2 (at k=0).
score = 2n*A^2/(A+(n-1)B)^2. For large n: ≈ 2n*A^2/(nB)^2 = 2A^2/(nB^2) → 0.

But this is a degenerate case (one spike). The evaluator requires sum >= 0.01, which is satisfied. But is this valid?

Let me check: a = [A, B, B, ..., B] with n=512. If A = 1000 (max allowed) and B = 1:
S = 1000 + 511 = 1511.
conv[0] = 1000000.
max_conv = 1000000 (at k=0).
conv[1] = 2*1000*1 = 2000.
conv[k] for k>=2: 2000 + (k-1) (for k < n-1, approximately).
So max is indeed 1000000.
score = 2*512*1000000/1511^2 = 1024000000/2283121 ≈ 448. Terrible!

The issue is that A is bounded by 1000. So we can't make A arbitrarily large.

But we can make B very small! If A = 1 and B = ε:
S = 1 + (n-1)ε ≈ 1.
conv[0] = 1.
conv[1] = 2ε.
max = 1.
score = 2n*1/1 = 2n = 1024. Terrible.

So a single spike is always bad. The [2,2,1,1] example works because the ratio A/B = 2 is moderate and p is a significant fraction of n.

Let me go back to the formula: score(α, r) = 2 * max(αr^2, 2αr+1-2α) / (1+α(r-1))^2.

For the case where both peaks are equal: αr^2 = 2αr+1-2α → α(r^2-2r+2) = 1 → α = 1/(r^2-2r+2) = 1/((r-1)^2+1).
Then score = 2 * αr^2 / (1+α(r-1))^2.
With α = 1/((r-1)^2+1):
1+α(r-1) = 1 + (r-1)/((r-1)^2+1) = ((r-1)^2+1+r-1)/((r-1)^2+1) = (r^2-2r+2+r-1)/((r-1)^2+1) = (r^2-r+1)/((r-1)^2+1).
So denominator^2 = (r^2-r+1)^2/((r-1)^2+1)^2.
Numerator: 2*r^2/((r-1)^2+1).
score = 2r^2/((r-1)^2+1) * ((r-1)^2+1)^2/(r^2-r+1)^2 = 2r^2((r-1)^2+1)/(r^2-r+1)^2.

Let me compute for r=2: 2*4*(1+1)/(4-2+1)^2 = 16/9 ≈ 1.78. (Matches our [2,2,1,1] example!)
For r=3: 2*9*(4+1)/(9-3+1)^2 = 90/36 = 2.5. Worse.
For r=2.5: 2*6.25*(2.25+1)/(6.25-2.5+1)^2 = 40.625/12.25 ≈ 3.32. Worse.

So r=2 is optimal in this regime! And the score is 16/9 ≈ 1.78.
