1. Approach and rationale

Use the exact discrete evaluator as the only final yardstick and construct a local, nonsmooth, active-set descent method, then escape local basins by feasibility-preserving perturbations and resolution transfers. The main change from standard smoothing/SLSQP plans is to avoid replacing the maximum by a smooth surrogate for the final local moves. Instead, for the constraints that actually attain the current maximum, construct a first-order descent direction for the real maximum using a small linear program over feasible infinitesimal transfers. The accepted step is chosen by evaluating the original correlation on the new finite vector.

The method has three parts:

1. Local descent on the exact maximum:
   - Identify active lags whose current value is within a tiny tolerance of the current maximum A.
   - Linearize only these active correlation functions.
   - Solve a small LP: find a sum-preserving transfer vector whose maximum linearized active increase is as negative as possible.
   - Explore the exact nonlinear line determined by this transfer vector and accept only points whose authoritative evaluator score is lower.

2. Pair-wise exact polishing:
   - A pair transfer preserves the mass identity exactly by removing one scalar amount from one sample and adding the same amount to another.
   - Candidate pair directions are chosen from average active-lag gradients where gradients pass an indexing sanity check, and from randomized feasible transfers otherwise.
   - Each proposed pair or vector direction is validated and its score recomputed exactly.

3. Basin hopping and resolution search:
   - Treat the supplied parent as a candidate but not as a local sink. Random perturbations, resampling to smaller or larger resolutions, and deterministic balanced fallback sequences are projected back to feasibility and locally polished.
   - The smallest feasible score observed is returned; ties are resolved by preferring smaller n, matching the task preference.

Justifications and limitations:

- Fact: Each update uses direction-preserving pair transfers or sum-preserving projected updates, so both box constraints and the equality constraint are handled jointly, not by sequential clipping and linear rescaling.
- Fact: Candidate acceptance is based on the exact vector score from finite-correlation computation; no claim of global optimality is made.
- Heuristic: Active-constraint LP directions are more likely than a smoothed maximum to improve the limiting lags, because they directly ask for movement that reduces the active set.
- Heuristic: Random perturbations and down/up sampling allow escape from parent local minima; failure may occur if the parent optimum lies in a narrow basin that perturbation and smaller resolutions do not reach. The plan therefore retains a valid parent and fallback candidates throughout.

2. Mathematical specification

Representation and exact objective

For a vector h of length n, samples represent a step function with mass target

    S_n = n / 2,  0 <= h_i <= 1 for every i,  sum_i h_i = S_n.

The sample spacing is dx = 2.0 / n. The authoritative evaluator score is

    Score(h) = max_k Corr_k(h),
    Corr = correlate(h, 1 - h, mode = "full") * dx,
    length(Corr) = 2n - 1.

For local direction construction, use an equivalent finite-diagonal representation. For an integer lag shift d from -(n-1) to n-1 define

    start(d) = max(0, -d)
    stop(d)  = min(n, n - d)
    Q_d(h) = dx * sum_{i=start(d)}^{stop(d)-1} h_i * (1 - h_{i+d}).

The collection {Q_d} indexes every valid ordered pair difference. Reversing the lag ordering can interchange which index maps to a given diagonal, but since the full evaluator includes both positive and negative lags and the max is over all diagonals, the derived maximum over this set is the same function up to lag-order permutation. For safety, include an internal discrepancy check comparing this custom maximum with the authoritative Score. If the discrepancy exceeds a tiny numerical tol, treat gradient-derived local search as unavailable and use feasibility-preserving random transfer/line methods only.

Gradient for a lag constraint

For use only when the internal check passes, define the gradient of Q_d with respect to h. For each d,

    G_d = gradient(Q_d)

with length n. For a scalar index p, include:

- Source terms: if p is a valid source, start(d) <= p < stop(d), the term containing h_p is h_p * (1 - h_{p+d}), so its differential contribution is

    dx * (1 - h_{p+d}).

- Target terms: if p is the lag target, i+d = p for a valid source i = p-d, the term is h_i * (1 - h_p), so its contribution is

    - dx * h_{p-d}.

In an implementation, the second part is added for source behavior p+lag_d = target p. Programmatic helpers can loop over the valid source indices and explicitly add:

    grad[source] += dx * (1 - h[target])
    grad[target] += - dx * h[source]

where target = source + d and only valid target indices are included.

Linear LP direction

Given current h with maximum T, compute all Q_d and identify active lags

    Active = {d: Q_d(h) >= T - eta_active}.

Use eta_active = max(1e-12, 1e-11 * max(1, T)). Limit the active set, for example rank by value and retain at most the 35 best active constraints (all if there are fewer), to keep LP dimensions small.

For each active d obtain G_d from the finite-diagonal formula. Build matrix rows

    a_d = G_d^T.

The direction LP variables are z in R^n and scalar tau. The LP is

    minimize tau
    subject to  a_d^T z <= tau     for all active d,
                sum_i z_i = 0,
                -1 <= z_i <= 1.

This LP is convex and solved as a true LP; it does not claim to solve the original nonconvex quadratic problem. It is used only to generate a candidate descent direction.

Sum-preserving line moves

For a direction z, solve any numeric sum residual of z by moving the residual from one coordinate to another within the existing bounds, or reject the direction if the residual cannot be repaired. The exact normalized update uses step alpha:

    H(alpha) = h + alpha * z.

The admissible maximum alpha is

    alpha_max = min over i with z_i > 0 of (1 - h_i) / z_i,
