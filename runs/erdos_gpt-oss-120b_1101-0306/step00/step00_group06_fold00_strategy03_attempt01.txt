1. Approach and rationale

1.1 Central independent algorithm: active-detour predicted-reduction line flow (APRL)

The program will return a finite vector `h in [0,1]^n` sampled on `[0,2]`, with `dx = 2/n` and `sum(h) = n/2`. It will be optimized against the exact evaluator metric

`C(h) = max(np.correlate(h, 1.0 - h, mode="full")) * dx`,

not a smoothed surrogate value, not circular correlation, and not an autocorrelation relaxation. Every accepted vector must pass numerical feasibility and exact reevaluation using the metric above.

The central heuristic is a first-order active-model generation followed by an exact one-dimensional feasible ray search. At any current feasible vector `h`, construct a condensed set of components that are close to the maximum. For those components compute gradients of their correlation terms. Generate candidate tangent directions by minimizing a small convex least-squares model that predicts reduction of the selected high components: the model tries for each selected component `j` to have `∇g_j(h) · d ≈ -a_j`, where `a_j > 0` is a requested mengembangkan-saved reduction in the same units as `C`. The unconstrained model solution gives a raw direction that approximately descends all active peaks simultaneously. The raw direction is then projected exactly into the feasible affine box of unit-step directions:

`D(h,tau) = { d : sum(d)=0, max(-h_i,-tau) <= d_i <= min(1-h_i,tau) }`.

This sign is internally managed simply by searching along `d` and `-d`. Since all the linear constraints are enforced by projection, not later clipping/rescaling, every unit step of `h+sd` for `s in [0,1]` remains exactly in the box and preserves the sum (up to a very small numerical tolerance handled by the repair routine). A deterministic range of candidates covering `[0,1]` plus a localized golden refinement is then evaluated using the real evaluator. The moved point is accepted if and only if both feasibility and exact preferential finite objective are valid and strictly improve the current point.

This avoids the main pitfall of an epigraph/state reformado optimization of optional max via a nonconvex concave minimization maxim. It differentiates from a surrogate smooth maximum because the line accepts only real ridge moves of the predicted active reductions and because the raw directional generation is not a soft-max polynomial optimization. It is not relying solely on explicit pairwise integer-like moves either. It uses the complete active-gradient model and projective feasibility while scoring exact components.
