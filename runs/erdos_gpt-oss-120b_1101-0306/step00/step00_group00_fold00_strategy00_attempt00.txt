2. Mathematical specification

`c5_exact(h) = max_{p=0,...,2n-2} dx * corr[p]`,

where

`corr = np.correlate(h, 1 - h, mode="full")`.

For this plan, define the correlation output shift index by

`off = n - 1`,

so output index `p = k + off` corresponds to integer lag `k = p - off`, with

`k in {-(n-1), ..., n-1}`.

The required maximum ranges over every output element, including both negative and positive lags. This avoids replacing the evaluator by autocorrelation or by `1 - minimum autocorrelation`; those formulas require shift-independent boundary cancellation that is not guaranteed here.

`s[p] = exp(corr_scaled[p] / tau) / sum_q exp(corr_scaled[q] / tau)`,
