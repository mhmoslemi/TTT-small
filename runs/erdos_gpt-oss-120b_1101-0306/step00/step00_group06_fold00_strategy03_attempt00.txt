1. Approach and rationale

1.1 Central idea
The returned object is a finite feasibility vector h in R^n satisfying
  0 <= h_i <= 1,
  sum_i h_i = n/2.
The authoritative score is
  C5(h) = max(np.correlate(h, 1.0 - h, mode="full") * dx), dx = 2/n,
which is a maximum over all 2n-1 finite-support lag correlations, including both lag signs and the zero lag. The task is to minimize this maximum over a nonconvex box-simplex.

The proposed primary method is to optimize a smooth log-sum-exp model of this finite maximum inside a manifold that already represents the feasible set. The manifold uses logistic variables plus one scalar bias chosen to enforce the discrete mass constraint exactly:
  h_i = sigmoid(z_i + alpha(z)),
with alpha(z) satisfying sum(h) = n/2. Because the logistic map automatically gives 0 < h_i < 1, every point produced directly by the Smooth solver is feasible except for numerical tolerance. The remaining additive gauge in z is removed by fixing one coordinate, so the unconstrained search dimension is n-1.

A bounded L-BFGS-B solver is then used in the reduced logit variables to minimize a smoothed log-sum-exp surrogate of the hard objective. The surrogate and its gradients are derived exactly from the finite-support correlation components. After every L-BFGS-B run, or inside its callback, the proposed h is repaired to the exact discrete feasible set, scored with the actual evaluator, and only exact C5 improvements are retained.

To handle the nonsmooth hard maximum, the final refinement uses exact feasible search directions derived from active correlation components. These directions are projected to zero-sum directions and optimized as line moves or coordinate-exchange edges; candidate steps are exact scored and accepted only when the real objective decreases.

1.2 Why this can improve the supplied parent construction
The supplied vector, if feasible, is a high-quality local point but is likely already tight for the projection/SLSQP or active edge patterns that emphasize coordinate pair movement. The logistic-simplex smooth solver explores the continuous interior in a different tangent space:
  - it moves many smoothing components simultaneously,
  - it searches a smooth approximation to the hard maximum, then cools the smoothing,
  - it repairs to the exact objective rather than depending on the surrogate value,
  - it can discover asymmetric or fractional configurations that simple pairwise projection may miss.
Multi-resolution continuation lets high-resolution configurations be transferred down to smaller systems; smaller dimensions specifically lower personal budgets and can represent score changes inline initialization to final evaluation.

1.3 Limitations
This is not a global optimizer. The exact problem includes products h_i*h_j and is therefore generally nonconvex. A smoothed objective or L-BFGS-B convergence suffix from the log-sum-exp formulation does not make the overall problem convex. The search is therefore explicitly local/multistart. A score strictly below 0.3808 is sought but not proven reachable by these methods. 1. Approach and rationale
-------------------------

1.1 Central method
The optimization is performed on the box-simplex
  F_n = {h in R^n : 0 <= h_i <= 1, sum(h_i) = n/2}.
The final accepted score is always the exact evaluator:
  C5(h) = max(np.correlate(h, 1.0 - h, mode="full") * dx), dx = 2.0/n.
The returned vector must be feasible for the exact dimension n = len(h).

The principal search engine is a smooth log-sum-exp model of the hard maximum, optimized inside a manifold parameterization that enforces both the input bounds and the equality constraint by construction. We use reduced logistic variables
  x in R^{n-1}, x_i in [-L,L],
and build
  full_z = [x_0, ..., x_{n-2}, 0].
For each x, a scalar bias alpha(x) is found by solving
  sum_i sigmoid(full_z_i + alpha(x)) = n/2.
Then
  h_i(x) = sigmoid(full_z_i + alpha(x)).
Since sigmoid always lies in (0,1) and alpha solves the discrete mass constraint, every point produced by the smooth solver is nearly feasible automatically. Fixing the last z coordinate removes the otherwise redundant additive gauge in z.

This is structurally different from direct constrained SLSQP or an exact coordinate-edge-only king method: the main search moves through many interior points in a smooth low-dimensional parameterization, and exact feasibility is restored later only when finalizing candidates and for robustness. All accepted improvements are judged by the exact discrete evaluator, not by the surrogate.

After each smooth cooling stage, and whenever the surrogate stalls, a hard active-point refinement is run on the exact objective. This estimates active gradient directions, forms zero-sum directions in the tangent hyperplane, feasible line-segments or coordinate-exchange segments, performs exact scalar line searches on those paths, and accepts only exact C5 decreases. This closes gaps caused by the smoothing surrogate, nonsmooth plateaus, and saturation.

Why it may improve the parent:
- The parent vector may be near a local optimum for the current representation but not tight in the composite maximum active set.
- Smooth logit-plus-sum-bias transitions explore simultaneous multi-coordinate interior changes rather than only coordinate exchange moves.
- Multiresolution continuation finds solutions at smaller dimensions, where compactness is preferred and exact comparisons can reveal resolution-dependent improvements.
- The score value surrounding 0.38 is close to the usual optimum, so local smoothing and exact finalization from a high-quality parent may gain a few gaps.

Limitations and assumptions:
- The original discrete problem contains products h_i h_j and is nonconvex. A manifold reformulation does not make it convex. L-BFGS-B on the surrogate is only a local method.
- The surrogate does not always align with hard maximum-list peaks. If accepted without exact evaluation, it could increase the real score. Therefore surrogate values never determine final acceptance.
- Z saturation maps probabilities near, but not exactly, binary values; exact box-simplex projection further adjusts candidates. Therefore final candidates may differ from logits.
- Branches may fail. When that happens, the retained valid best is returned. The method is explicitly local/multistart, and no global minimum is claimed.
