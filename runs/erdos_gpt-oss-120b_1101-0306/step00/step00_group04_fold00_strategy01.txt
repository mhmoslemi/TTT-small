1. Approach and rationale

1.1 Primary idea

The parent answer is already close to the desired upper bound, so the remaining work is essentially precision refinement on a tightly constrained, nonsmooth, bilinear feasibility surface. The central idea is to spend most of the budget on a new kind of low-dimensional exploration that never optimizes raw high-dimensional h-arrays and never uses a convex or semidefinite relaxation. Instead, every candidate is produced by an explicitly feasible parameterized map and is ranked by the exact evaluator objective. This makes the search resistant to infeasibility bias, clipping artifacts, and inactive-gradient stagnation.

The main high-dimensional surface has 70 or more variables, sum constraint  sum(h)=n/2, box constraints 0≤h≤1, and an objective that is the maximum over 2n-1 discrete correlations. A high-dimensional local optimizer can easily move across many inactive correlations, be dominated by smoothing bias, or be upset by tiny repairs. The proposed method instead maps a compact parameter vector directly to a feasible h vector using a centered divided-range deformation around the parent. Differential evolution and other black-box global methods evaluate this map using only the exact discrete correlation. After a promising low-dimensional point is found, the remaining budget is spent on an exact nullspace random-line refinement that directly looks for a smaller correlation maximum. The program never claims a global optimum of the original continuous or quadratic problem; it produces a valid upper bound if it can find one below the parent.

The method is materially different from a smoothed-SLSQP approach in four substantial ways:

1. The search variables are basis coefficients in a purposely feasible deformation family, not raw vector coordinates.
2. There is no smoothing surrogate used for actual candidate ranking: every accepted candidate is scored by the exact discrete objective max(np.correlate(h,1-h,'full'))*dx.
3. Feasibility is enforced inside the candidate generation map, followed by a deterministic exact repair for return, not by repeated unverified projection chains.
4. The local phase uses exact-score line searches along null and active-edge directions, rather than a decreasing-temperature smoothing optimizer.
