1. Approach and rationale
-------------------------

1.1 Central idea
The optimizer will operate directly on the discrete objective that the grading formula uses:

C5(h) = max(np.correlate(h, 1-h, mode="full") * dx), dx = 2/n.

It keeps vector h in the exact feasible set

F_n = {h in R^n : 0 <= h_i <= 1, sum_i h_i = n/2}

and evaluates every proposed move with the exact metric, never with a surrogate score. A surrogate is allowed only for ranking and directions, not for acceptance.

The primary search mechanism is an exact scalar minimization over feasible two-coordinate exchanges. For a pair (i,j), with h_i and h_j variable until one of the two becomes 0 or 1 while h_i + h_j stays constant, the full discrete objective becomes one scalar function

f_{i,j}(s) = C5(h(s)), h_i(s) = h_i + s, h_j(s) = h_j - s,

and s is a step in a compact interval. For every selected pair, we find a good, usually local but often global-enough, minimizer of f_{i,j}(s) using a robust hybrid of grid search and bounded one-dimensional optimization. Then the exact full vector score is re-evaluated. If it improves, the move is accepted; otherwise the vector is unchanged. This is more powerful than evaluating a handful of prechosen step lengths on an exchange direction because for each exchange, the best step over the valid interval is explicitly sought.

Several search routes are combined to escape one-dimensional pair stagnation:

- A feasible frontier/candidate population is maintained. The parent is the main seed if present. The frontier contains transformed, transferred, randomized, and optimized child vectors at several dimensions, chosen among reasonably small dimensions, because small returned arrays are preferred.
- Nearby dimensions around the parent are emphasized, but a set of transferred child resolutions is searched because the finite-support correlation objective is not invariant to the Riemann grid and changing n can make boundary terms better or worse.
- Vector transforms include length-preserving symmetries such as reversal and complement mixes, as well as resolution resampling and projection.
- A stochastic frontier works as a global layer: mixed parents, small random moves followed by exact projected projection, and slight randomized perturbations provide seeds for the exact pair optimizer.

This is materially different from making an epigraph/smoothed maximum nonlinear solve, from using a general multi-dimensional continuous optimizer as the primary solver, and from random coordinate jitter with fixed step lengths. Here the algorithm’s core move is an exact one-dimensional line optimization over the full evaluator on a feasible tangent segment of the box-simplex.

1.2 Why the method should help
- It preserves feasibility exactly and therefore avoids recurring failures with clipped/renormalized points and infinite correction/feasibility penalties.
- Pair exchange is a feasible tangent direction: increasing one coordinate and decreasing another preserves the sum n/2, while simultaneous line search handles its box constraints.
- Subproblem exact minimization can remove residual asymmetries that local component gradient or fixed-step coordinate descent might miss, because it must examine the entire feasible interval for that swap.
- Multi-resolution transfer matters because the reported metric is computed on a returned finite vector and the line search has truncation/boundary terms. A parent can hint at the right continuous basin in n=70, while another discretization n=50 or n=76 may have a better finite lag-phrase.
- Variations using mixes, binarized samples, and small Gaussian perturbations add breadth but always re-score exact target objective, hence there is no chance of trusting a wrong non-exact objective.

1.3 Limitations and explicit honesty about claims

1.1 Central method and why it is chosen
The returned object is a finite sample vector h in R^n that must satisfy the exact discrete feasibility requirements 0 <= h_i <= 1 and sum(h)*dx = 1, where dx = 2/n. The reported optimizer score is the exact maximum finite-support cross-correlation

computed over all 2n-1 full-correlation lags. This plan optimizes that exact function directly. It does not replace it by a circular autocorrelation, by 1 minus a minimum autocorrelation, by a convex epigraph, or by a surrogate score that is later trusted.

The kernel of the method is a feasible exact one-dimensional exchange: for any two coordinates i and j, define

h_i(s) = h_i + s,
h_j(s) = h_j - s,
h_k(s) = h_k for k not in {i,j}.

This preserves the sum exactly as a real move. The scalar admissible interval for s is the intersection of the two single-coordinate feasibility ranges:

s in [max(-h_i, h_j-1), min(1-h_i, h_j)].

For that pair, the exact objective becomes a scalar one-dimensional function

For each selected pair direction, we search this scalar function on its valid interval and accept only moves for which the full vector C5 actually decreases.
