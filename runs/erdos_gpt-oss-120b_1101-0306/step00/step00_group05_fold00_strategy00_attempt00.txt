1. Approach and rationale

Goal. Produce a sampled step function
`h ∈ [0,1]^n` with `sum(h) = n/2` minimizing

`C5 = max_k ∫ h(x)(1-h(x+k)) dx`.

In the supplied evaluator this is exactly

`score(h) = max(np.correlate(h, 1-h, mode="full")) * (2/n)`.

This is a finite linear correlation with compact support over all `2n-1` sampled lag values. Boundary terms are therefore intrinsic: for nonzero sampled shifts only a portion of the grid overlaps, and `sum(h)` over that partial interval is not generally the full integral. Do not replace this by `1 - min autocorrelation` or by circular convolution unless separately proved equivalent for the same lattice and boundaries. The plan therefore uses the direct evaluator everywhere.

Main sources of difficulty.

1. Nonconvexity. The objective is a maximum of bilinear terms in `h`, because each term contains `h_i(1-h_j)=h_i-h_i h_j`. Any epigraph formulation becomes nonconvex and can only be solved as a heuristic unless a separate convex/reduction theorem is provided. Hence SLSQP, line searches, and simulated annealing are accepted only as proposal mechanisms and all results are judged by the exact evaluator.

2. Coupled feasibility. Simple clipping plus scaling cannot satisfy both `0<=h<=1` and `sum(h)=n/2`. Use a joint exact/proximal projection to the box-and-sum feasible set, and generate candididual moves with exact sum-preserving two-coordinate transfers.

3. High sensitivity. At active lag points the objective is a max of piecewise smooth functions, so many one-coordinate directions can be flat or locally improving in different active lags. Use pairwise mass-transfer line searches, exact golden refinement, smoothed-max SLSQP multi-coordinate proposals, and stochastic transfer restarts to expose useful move patterns.

Primary method. Build a vector-best state, and in each time window perform

- an initial repair/evaluation of the supplied `initial_h_values` whenever available;
- exact feasible pairwise line improvement on all or randomly selected pair directions with adaptive local step sizes;
- limited smoothed-max SLSQP restarts, repaired and exact-scored;
- simulated annealing over feasible finite-support transfers;
- independent candidate generators and size-transfer seeds for neighboring sample counts.

The best feasible vector found by exact objective locations is retained at every step, with the repaired parent as a mandatory fallback. If `C5 <= 0.38079` is reached, search may terminate early; this leaves a margin below the target `0.3808`.

Hypotheses and limitations.

- The parent construction is a strong starting point but need not cover all local basins. Random and smoothed restarts increase probability of improvement but do not guarantee a global optimum.
- Smooth SLSQP may lower a surrogate more than the exact max; it only proposes a state. Only exact-scored repaired vectors may be stored or returned.
- Alternative resolutions can sometimes lower the measured score because discretization affects boundary terms. If evaluated as exact vectors at their own lengths and they are feasible, they are legitimate candidates; sizes are kept modest (< about 120) for speed.

2. Mathematical specification

2.1. Representation and exact objective

For candidate `h ∈ R^n`,

`dx = 2/n`,
`g = 1 - h`,
`c = np.correlate(h, g, mode="full")`,
`score(h) = max(c) * dx`.

The length is `2n-1`. Every lag sign is present. This formula exactly matches the required finite linear-correlation evaluator. Since `np.correlate` uses zero outside the overlap, no additional boundary manipulation is needed.

Feasibility set:

`F_n = { h ∈ R^n : 0 <= h_i <= 1 for all i, sum_i h_i = n/2 }`.

Numerical final tolerance:

`abs(sum(h)-n/2) <= 1e-10`,  
`min(h) >= -1e-9`,  
`max(h) <= 1 + 1e-9`.

For candidate storage, copy arrays, repair if needed, recompute `score` by the actual evaluator. Never accept a score from a surrogate or unprocessed optimization result.

2.2. Projection onto box and sum

Define

`m = n/2`.

For any vector `y`, projection onto the Euclidean set

`P(y) = argmin_z { 0.5 ||y-z||^2 : z_i ∈ [0,1], sum(z)=m }`

can be computed via water-filling. Define

`u(theta) = clip(y - theta, 0, 1)`.

`sum(u(theta))` is continuous and nonincreasing in `theta`. Search `theta` on an interval covering `min(y)-1` to `max(y)` using approximately 60 bisection iterations. Return `z = u(theta)`. Then add tiny conservation corrections under bounds if left drift exists:

- If `r = m - sum(z) > 0`, raise coordinates with room `1-z_i > 0` by shared amounts rotating up.
- If `r < 0`, reduce coordinates with room `z_i > 0` similarly.

This projection is feasible and numerically near the exact constraint.

2.3. Sum-preserving pairwise transfer

Given feasible `h`, an ordered pair `(p,q)`, and scalar `delta`, define

`h_i(delta) = h_i` for `i != p,q`,  
`h_p(delta) = h[p]+delta`,  
`h_q(delta) = h[q]-delta`.

The conceptual sum is unchanged. The allowed interval ensures bounds:

`lo = max(-h[p], h[q]-1)`,
`hi = min(1-h[p], h[q])`.

If `hi-lo` is below the jitter tolerance, skip. The segment contains `delta=0`. Exact objective along the segment is

`phi(delta) = score(h(delta))`.

This is generally nonconvex and piecewise smooth; this does not inhibit sampling and local golden refinement.

2.4. Smoothed-max objective for proposals

For temperatures `tau` chosen on an absolute scale:

`M = max(c)`,
`Phi_tau(h) = M + tau * log( sum(exp((c-M)/tau)) )`,

where `c` is already multiplied by `dx`. This is stable; subtracting `M` avoids overflow. As `tau -> 0` it approaches the exact maximum from above.

Use the following temperature list as default:

`tau = [5e-3, 1e-3, 3e-4, 8e-5]`.

Apply `SLSQP` or a reliable local nonlinear optimizer to `Phi_tau` with bounds `[0,1]` and equality constraint `sum(x)-n/2=0`. Use no closure in the program; make needed constraint/objective functions top-level. Both `Phi_tau` and correlation evaluation are top-level helpers.

2.5. Optimization philosophy for nonconvex subproblems

Only exact sparse opportunity can prove a better returned upper bound. A convex maximization/subproblem. State all feasibility proposals using CVXPY easier. Thus, all use is proposal-only. A proposal is accepted if after repair:

`score(proposal) < stored_global_score - 1e-13`

then it becomes global best. A proposal may be accepted as an optimization working state only if feasibility and finite numerical score survive and the exact value is not worse than current active working exact by more than the current smoothing tolerance. For pairwise line search the update may use the strict exact improvement condition:

`new_score <= current_score - 1e-13`.

2.6. Multi-coordinate SLSQP statement

For a fixed feasible start `x0` and vector length `n`:

Decision vector: `x ∈ R^n`, each coordinate corresponds to some sample.  
Objective: `f(x) = Phi_tau(h(x))`, where `h(x)=clip(x,0,1)` before score evaluation. Smoothistically values in feasible domain and gradient may be computed via finite differences by solver.  
Constraint: `e(x)=sum(x)-n/2=0`.  
Bounds: `x_i ∈ [0,1]`.

If the solver stops, project `xopt` using projection. Then exact evaluate. `Phi_tau` only explores. Making no convex subsolving measurement is required: `f` smooth nonconvex from the objective; accepted state is tested exactly.

2.7. Objective boundary notes

A vector of half ones returns zero lag contribution zero, but other correlations enforce nonzero `C5`. The exact metric returns nonnegative values. Validate that all correlation results are finite and that `0 <= min(c) <= max(c)` approximately within floating noise; do not rescale objective by hand.
