1. Approach and rationale

1.1. Goal and exact target

We will work with the discrete evaluator supplied by the task rather than any circular or autocorrelation surrogate. For a proposed sampled step function `h` with `n_points = n`, the score is

  `score(h) = max_{all full lags} np.correlate(h, 1 - h, mode="full") * (2.0 / n)`.

Any accepted candidate must also satisfy

  `0 <= h_i <= 1` for all `i`,

  `sum_i h_i = n/2` to numerical precision.

The returned bound is the exact score obtained by re-evaluating the returned array with the same formula. We want a feasible array whose exact score is at most `0.38079` to leave a margin below the quoted target `0.3808`; if that is not achieved, return the best feasible value found.

1.2. Central idea

The implementation will not assume that a convex or global solver can solve the full problem. The problem is bilinear in `h` and the objective is a maximum over many bilinear lag expressions. Therefore every proposal must be judged by the original finite-support correlation evaluator. The search is organized as a multilayer local-plus-global heuristic with exact acceptance only:

1. Start from the supplied parent construction when it is available. If it is absent, build feasible local and smooth fallback constructions algorithmically.

2. Around every promising feasible vector, use a first-order active-lag linear program to find a simultaneous transfer direction. The direction is required to reduce, in first order, all correlations that are currently part of, or extremely close to, the active maximum, while not abruptly raising any lower lag.

3. Test the direction by an exact golden-section/general sample line search over the physically feasible segment of the transfer. Store any vector whose actual evaluator score is strictly lower.

4. Independently run smooth-max surrogate descent with SLSQP on the same finite feasible family. The surrogate is only a proposal generator; each output is projected to feasible and accepted only if the exact score improves.

5. Smoothly rescale, transfer, and randomize between feasible basins. Do not select a sequence merely because it is short; compare scores only after the returned vector is rescaled and exactly evaluated.

The important difference from the earlier proposal is that the new primary moving engine is a mathematically constructed first-order direction selected by linear programming over all active lag constraints, followed by exact transfer-curve verification. It is not just random pairwise perturbation, SLSQP, or a simple convex relaxation. The LP step is a rigorous local certificate proposal mechanism for a decrease of the maximum of currently active constraints. However, the final acceptance condition remains exact, so no nonconvexity theorem is needed or implied. This biases search toward directions that prove, at the local linear level, that all currently limiting correlations can be lowered together, which is precisely the obstruction in a max-over-correlations problem.

1.3. Strengths and honest limitations

The LP-created direction is a strong local research tool because a strict decrease of the maximum for a sufficiently small step follows if the active rows are lowered and inactive rows are kept from increasing above their slack margin, provided the derivative approximations and second-order terms are not disastrous. The exact line search handles remaining nonlinear effects.

The method is heuristic in the global sense. It can find a better construction if one lies in or is reachable from the parent perturbation or virtual resampling basins. It makes no claim of global optimality. The returned value is nevertheless a fully certified upper bound because the returned array is explicitly feasible and its score is measured by the supplied formula.

  `r(h) = np.correlate(h, 1.0 - h, mode="full")`.

The exact objective is

The feasible set is

All proposals are repaired into `M` before exact evaluation. The repair mechanism is not a sequence of separate clipping followed by simple normalization because those operations do not jointly preserve both constraints. Section 2.2 gives a valid joint mechanism.

2.2. Exact joint feasibility projection

A vector `r * bfill` already satisfies both box and mass constraints. Use a water-filling projection with a final conservation search.

Given target vector `y` of length `n` and mass `m = n/2`, compute

  `z(theta) = clip(y - theta, 0, 1)`

for scalar `theta`. The function `g(theta) = sum(z(theta))` is continuous and nonincreasing. Search on bracket `[min(y)-1, max(y)+1]` for `theta` such that `g(theta) = m`. Use about 80 bisection iterations. Return

  `z = clip(y - theta.star, 0, 1)`.

Then compute residual `e = sum(z) - m`.

If `abs(e) < 1e-12`, return `z`. If not, perform a coordinate transfer under the bounds:

- If `e > 0`, reduce coordinates where `z_i > 0`, decrement by a small amount, preferably `e*0.5` into the coordinate with largest headroom `z_i`, and update residual.
- If `e < 0`, increase coordinates where `z_i < 1`, using headroom `1 - z_i`.
- Repeat until `abs(e) < 1e-12` or no coordinate has room. If no coordinate has room, return `None`.

This projects approximately to the Euclidean projection onto box-and-sum and, in any case, ensures an exact sum within tolerance after the second correction.
