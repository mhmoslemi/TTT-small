1. Approach and rationale

1.1 Central idea

The problem is to minimize a nonsmooth finite-support correlation objective
\[
C_5(h)=\max_{k\text{ (all 2n-1 discrete lags)}} \;\frac{2}{n}\,
\sum_{\text{valid overlap }i,j} h_i(1-h_j),
\]
over the feasible box
\[
0\le h_i\le 1,\qquad \sum_i h_i=\frac n2.
\]
The difficulty is boat both the box/equality constraints and the max. The max is nonsmooth, and each fixed-lag objective is a differentiable but nonconvex quadratic expression because of the \(h_i h_j\) terms.

I propose a materially different algorithm: use a smooth reparameterization that makes the box and sum constraints structurally automatic. The reparameterization is
\[
h_i(w,\lambda)=\sigma(w_i+\lambda),\qquad \sigma(t)=\frac{1}{1+e^{-t}},
\]
where \(\lambda\) is chosen, at every objective evaluation, to enforce
\[
\sum_i h_i(w,\lambda)=\frac n2
\]
using a one-dimensional monotone root solve. The decision variables are only the unconstrained parameters \(w\in\mathbb R^n\); \(\lambda\) is not a separate optimization variable but an internal feasibility coordinate. Then optimize a smooth exponential smoothing of the max:
\[
J_\alpha(h)=\frac{1}{\alpha}\log\sum_m e^{\alpha C_m(h)},\qquad
C_m(h)=\frac{2}{n}\sum_{\text{valid overlap }i,j}h_i(1-h_j).
\]
Adapt \(\alpha\) upward so that \(J_\alpha(h)\) approaches the true maximum \(C_5(h)\) while remaining smooth enough for gradient descent. After any candidate is accepted, convert it to an exactly feasible output using a safe clipped projection and evaluate it using the authoritative objective `np.correlate(h,1-h,'full')*dx`.

1.2 Why this can improve the supplied parent

This method addresses the core bottleneck directly and differently from explicit epigraph/LP/SLSQP strategies. Constraints are not handled as hard inequalities inside a constrained nonlinear solver. Instead, feasibility, including exact mass, is built into the signal representation via the internal shift \(\lambda\). Bounds are automatic (no clipping instability during optimization). Any nonconvexity is handled by local descent on a smooth approximation of the max, while the final accepted metric is always the original evaluator.

The parent construction is used as the first high-quality source point. New sources are produced by resampling the parent to nearby grid lengths, mild radial changes around half-intensity, small Gaussian perturbations, and a handful of deterministic initializations. For each source, the smooth logistic-pseudominimax optimizer tries to reduce the active-lag peak. Candidates are then accepted only after exact projection and exact rescore. This provides a direct search around the known record construction and several diverse basins without committing to a convex relaxation or surrogate acceptance.

1.3 Material distinction from previous plans

The earlier proposed plans used local epigraph formulation with explicit nonlinear objectives/constraints over \(h\). This plan:
- moves all bound and sum constraints into a logistic reparameterization,
- optimizes in unconstrained \(w\) space with exact internal mass coordinate \(\lambda\),
- minimizes smooth maximum-of-lags objective \(J_\alpha\), not an epigraph of exact max in the variables \(h\),
- uses hard exact projection and exact evaluator only for candidate acceptance and final output,
- includes an independent binary local-search layer mainly as a fallback improvement attempt, not as the primary formulation,
- treats each parent length as a transferable representation, not a fixed 45-point case.

1.4 Honest limitations

This is not a global optimizer. It does not prove that \(C_5\le 0.3808\). It is a deterministic iterative search using sufficient compute budget, diverse starts, exact evaluator acceptance, and time guarding. The objective values are accepted only when the actual task objective is evaluated exactly on a returned feasible vector. If the returned value falls at or below the target bound, it is a valid construction under the evaluation metric; otherwise the best verified construction is returned. No claim is made that the operator achieves the true discrete minimum or that DS confidence improvement is guaranteed.

2. Mathematical specification

2.1 Exact discrete objective and feasibility

For a length-\(n\) sequence \(h=(h_0,\dots,h_{n-1})\),
\[
dx=\frac{2}{n},\qquad T_n=\frac n2.
\]
The constraints are
\[
0\le h_i\le 1 \quad\text{for all }i,\qquad \sum_{i=0}^{n-1} h_i=T_n.
\]
The task evaluator is:
\[
C_5(h)=\max_{m=0,\dots,2n-2} \left(\frac{2}{n}\right)
\left[\texttt{np.correlate}(h,1-h,\text{'full'})_m\right].
\]
Use this exactly for candidate acceptance and final output. Oversimplified formulations such as \(1-\)minimum autocorrelation are not used.

2.2 Orientation matching \(\texttt{np.correlate}\)

Let \(N_h=n\). For full correlation index \(m\in\{0,\dots,2n-2\}\), the formula consistent with NumPy `correlate` (as can be checked on small examples) is:
\[
m=n-1-s,
\]
where \(s=j-i\) is the forward offset. Thus each lag \(s=-(n-1),\dots,n-1\) corresponds to index \(m=n-1-s\). The valid ordered pairs are
\[
\mathcal P_s=\{(i,j):j=i+s,\;0\le i,j\le n-1\},
\]
having \(n-|s|\) pairs. The raw correlation at full index \(m\) is
\[
R_m(h)=\sum_{(i,j)\in\mathcal P_{n-1-m}} h_i(1-h_j),
\]
and the C-scale lag value is
\[
C_m(h)=\frac{2}{n}R_m(h).
\]
To guard against formula ambiguity during implementation, include a small validation step: construct several short random \(h\) values, compute \(C_m\) via both `np.correlate` and the formula above, and require max discrepancy \(\le 10^{-8}\). If they fail, use exact evaluator for objective and numerical gradients for the affected gradient component (not for the entire update unless very slow). The description below assumes the orientation above; it is the orientation should be selected for gradient formulas and weighted-lag accumulation.

2.3 Smooth parametric representation with automatic sum

Given unconstrained vector \(w\in\mathbb R^n\), temporarily define shifted logistic components
