1. Approach and rationale

   The goal is to find a feasible discrete step vector h, with 0 <= h[i] <= 1 and sum_i h[i] = n/2, whose exact evaluator objective makes the pessimistic maximum overlap at least as small as the target. The evaluator is authoritative: it uses n_points cells on [0,2], dx = 2/n_points, and maximizes np.correlate(h, 1-h, mode="full") * dx over all 2*n_points-1 lags. Therefore the program must minimize this exact nonsmooth linear-correlation maximum. It must not replace the evaluator by an autocorrelation-only, half-range, circular, or interval-integral expression unless that expression has been proved to match the exact evaluator.

   The central algorithmic idea is a multi-start, multi-resolution, locally driven optimizer designed for this exact evaluator:
   - Use the supplied parent construction if available, validate it, and use it as a current champion.
   - Generate alternative constructions through algorithmic parent transfers, symmetries, projections, randomly balanced feasible points, low-dimensional smooth constructions, and perturbations.
   - Improve candidates by optimizing smooth surrogates for the maximum overlap. First optimize a log-sum-exp / smooth-max surrogate with multiple tightness parameters. Then use a threshold-pressure objective that penalizes correlations above a slightly lower target and tries to force the active peak below that target.
   - Store and return only candidates that pass exact discrete feasibility and exact evaluator validation. Do not infer deterministically from smooth surrogate values alone.

   This approach directly deals with the bottleneck: the objective is a finite maximization of bilinear terms and is nonconvex. A direct convex global optimizer is unavailable without a valid convex reformulation. Smooth surrogate minimization gives tractable differentiable subproblems, and threshold pressure offers a practical final descent mechanism when the maximum is flat or nearly saturated because multiple lag sets are simultaneously active.

   The search deliberately evaluates several n_values rather than only n=45, because if a better objective is attainable on a differently discretized balanced vector, the authoritative evaluator will confirm it. Larger resolutions can sometimes improve the true discrete maximum by allowing more precise support; smaller resolutions are preferred if they match or improve the objective because they are faster and more compact. Do not overseek variables larger than about 90; cost and memory remain harmless, but optimization mountains are not linear. Each solver micro-loop must include deadline guards, and the champion must survive every failure. Random candidate generation is orthogonal to a purely parent-based local search to reduce oblivion in one structural basin, but the resultant solution has no smeared topology without numerical evidence.

   This plan does not claim that the optimum has been located. It claims a well-calibrated construction/validator that returns a feasible exact objective at least as good as the supplied parent and significantly better whenever the surrogate/penalty+re-disines strategies improve exact score.
