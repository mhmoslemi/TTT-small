1. Approach and rationale

1.1 Central idea

Construct and accept candidate vectors using exact one-dimensional minimization along feasible mass-transfer directions. For any current feasible vector h, and any tangent direction p with sum(p)=0, the full correlation vector

    np.correlate(h_s, 1 - h_s, mode="full"),   h_s = h + s p

is exactly a quadratic polynomial in the scalar step s. This exact quadratic structure is exploited directly, without using a log-sum-exp surrogate, without finite-difference gradients, and without optimizing a nonconvex vector problem directly. Candidate movements are proposed by scanning exact 1-D search functions along a large set of pair-transfer directions, then a small set of global tangent directions, and finally by a constrained epigraph SQP/SLSQP polish. Every candidate is accepted only after re-evaluation with the original finite-support max-correlation objective. The returned bound is always computed by the evaluator formula itself.

1.2 Why this is materially different

The main novelty is mathematical, not cosmetic:

- The algorithm uses the exact bilinear correlation identity
  corr(h+s p, 1-h-s p) = corr(h,1-h) + s corr(p,1-h) - s corr(h,p) - s^2 corr(p,p).
  Thus the line search objective over all 2n-1 finite-support lags is not approximated by local expansion; it is a known quadratic envelope for that direction.
- The line search is carried out in the original evaluator's full-correlation convention. There is no separate lag-order derivation that might accidentally use a positive-loop lag definition. np.correlate defines the ordering directly through the matching correlation and coefficient construction.
- Feasibility is maintained via an explicit interval constraint using the same feasible box and preservation of sum. Pair moves are exact mass exchanges with sum(zero) and exact step interval. Similar joint directions are used for structured global tangent moves.
- The main procedure performs scans along all unordered coordinate pairs using the precomputed exact pair-quadratic coefficients. The accepted candidate uses exact evaluator scoring; the method never accepts based solely on approximate objective models.
- There is no assumption of global optimality. A parent is taken as a fallback, parent transformations may be tried, and final objectives are recomputed exactly before return.

1.3 Problems addressed

The main choices may have worsening and can be or may be optimal false if constrained, but it is preserved; scanning many directional possibilities. small evaluations and simple vectors do not bring benefit. Independent objective results will be recorded.

1.4 Facts versus heuristics

Facts established algebraically:

- For any feasible h and any zero-sum p, corr(h+s p, 1-h-s p) equals the quadratic  a + s b + s^2 q  where
  a = corr(h,1-h), b = corr(p,1-h) - corr(h,p), q = -corr(p,p).
- A direction p is exact feasible for a scalar s iff every coordinate satisfies
  0 <= h_i + s p_i <= 1
  and sum(h + s p) = n/2.
  Thus the exact feasible scalar interval is obtained by intersecting feasible intervals for each coordinate.
- Every pair transfer direction p=e_i-e_j is exact and corresponds to adding mass to coordinate i and removing the same amount from coordinate j. Considering every unordered pair covers both directions of that mass exchange because negative s represents the reverse direction.
- The final objective and feasibility validation are completely defined by the exact evaluator formula. Constraints 0<=h_i<=1 and sum(h)=n/2 are satisfied deterministically throughout transferring the vector.

2.1 Representation and exact objective

For a runtime vector length n:

- Feasible set:

- Define the full-evaluator correlation vector:

- Exact unmultiplied objective:
  M(h) = max_j C(h)_j.
- Exact normalized objective:

2.2 Exact scalar polynomial along any zero-sum direction

  h_s = h + s p.

  C(h_s) = a + s b + s^2 q.
