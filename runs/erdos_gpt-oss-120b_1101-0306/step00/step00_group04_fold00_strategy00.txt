1. Approach and rationale

1.1 Central idea  
The existing supplied parent is a good value of the objective at resolution n=70, but the desired additional improvement is tiny (roughly 5×10^-5) relative to reference levels near 0.38085. The practical bottleneck is not global combinatorial search but high-precision local movement on the constrained set
{h in [0,1]^n : sum_i h_i = n/2}
while respecting the nonsmooth minimax objective, including all linear finite-support correlations, both positive and negative shifts.

The primary method is therefore a constrained surrogate-gradient/multiscale smoothing refinement:
- Convert the exact nonsmooth objective f(h)=dx*max_lags overlap_lag(h) into a smooth upper-bound-like scalar surrogate using the softmax/log-sum-exp aggregator of all lag values.
- Optimize this surrogate with SLSQP under exact-box bounds and an exact linear sum equality constraint.
- Schedule the smoothing temperature from coarse to extremely fine so that the surrogate converges toward the true maximum, not a merely averaged-like objective.
- After every refined point evaluate the exact evaluator objective using max(np.correlate(h, 1-h, mode='full'))*dx and retain only candidates that improve the exact objective and satisfy feasibility.
- After gradient/local refinement, apply a deterministic active-set line polish and small block coordinate polish. These local moves evaluate the exact objective directly and can catch improvements that the smooth surrogate misses because of nonsmooth active-set switching.
- Spread the search over variations to escape local traps: parent perturbations, reversal, complement, shifts, resolution refinement, quantized starts, binary simulated annealing, and a low-dimensional parametric family optimized with differential evolution.

1.2 Why this is chosen over direct CVXPY  
The original objective is nonconvex because sums of products h_i h_{i+k} appear, and it is a minimax objective, so a single direct CVXPY solve that claims global optimality is inappropriate. SLSQP with a smooth surrogate is only a local candidate generator. A convex subproblem relaxation is not promising without a derivation preserving all finite-support boundary terms. Therefore use CVXPY only if a candidate proof lies in e.g. convex separable surrogate or cutting-plane LP subproblem as an advanced variant. The recommended generic implementation does not need CVXPY.

1.3 Accepted candidate rule  
Every proposed vector h is judged only by the authoritative objective
F_exact(np.asarray(h)) = max(np.correlate(h, 1-h, mode='full')) * (2/n),
