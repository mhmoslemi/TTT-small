If we normalize so that $\sum a_j = S$, then the score is $\frac{2n \max_k (a*a)_k}{S^2}$.

The minimum possible score: by the Cauchy-Schwarz inequality or similar, we know that for any sequence, $\max_k (a*a)_k \geq \frac{1}{2n-1} \sum_k (a*a)_k = \frac{1}{2n-1} (\sum a_j)^2$. So the score is at least $\frac{2n S^2}{(2n-1) S^2} = \frac{2n}{2n-1} \to 1$ as $n \to \infty$.

The key insight is: we want the self-convolution to be as flat as possible (ideally constant). The self-convolution $(a*a)_k$ has $2n-1$ entries, and we want them all to be as equal as possible.

For the uniform sequence, the convolution is a triangle (increasing then decreasing), with peak at the center. So we want to "flatten" the convolution.

**Revised approach:**

2. Minimize $f(a) = \max_k (a*a)_k$ on the standard simplex.
3. Use projected subgradient with Nesterov acceleration.

The subgradient of $f(a) = \max_k (a*a)_k$ at a point where the max is achieved at $k^*$ is:
$\nabla f(a) = 2 \cdot a[k^* - j : k^* - j + n]$ (reversed and padded)

More precisely, if the max is at $k^*$, then:
$\frac{\partial f}{\partial a_j} = 2 a_{k^* - j}$ (if $0 \leq k^* - j \leq n-1$)

If multiple lags achieve the max, we can use the average subgradient (which is a valid subgradient of the max).

**Nesterov accelerated projected subgradient:**

$$y_t = x_t + \frac{t-1}{t+2} (x_t - x_{t-1})$$
$$x_{t+1} = \Pi_\Delta (y_t - \eta_t \nabla f(y_t))$$

where $\Pi_\Delta$ is projection onto the simplex and $\eta_t$ is the step size.

For the standard simplex, the projection is:
$$\Pi_\Delta(v)_i = \max(v_i - \tau, 0)$$
where $\tau$ is chosen so that $\sum_i \max(v_i - \tau, 0) = 1$.

This can be computed in $O(n \log n)$ using sorting.

The step size for Nesterov subgradient is typically $\eta_t = C / \sqrt{t}$ where $C$ is a constant depending on the Lipschitz constant of the gradient and the diameter of the domain.

The Lipschitz constant of $\nabla f$ is bounded by $2 \max |a|$ (since $|\nabla f_j - \nabla f'_j| \leq 2 |a_{k-j} - a'_{k'-j}| \leq 2 \max |a|$). On the simplex, $\max |a| \leq 1$, so the Lipschitz constant is at most 2.

The diameter of the simplex is $\sqrt{2}$ (in the $\ell_2$ norm, the maximum distance between two points is $\sqrt{2}$).

So $C \approx 2 \cdot \sqrt{2} = 2\sqrt{2}$.

But in practice, we can tune this.

def project_simplex(v):
    """Project v onto the standard simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)

What about $a_j = c / j$ (harmonic)? Then $(a*a)_k = c^2 \sum_j \frac{1}{j(k-j)}$. For $k$ near $n/2$, this is approximately $c^2 \cdot \frac{2 \ln k}{k}$, which decreases with $k$. So the convolution is highest at small $k$, not at the center. This is the opposite of what we want.

For $k$ near $n/2$, this is $\approx c^2 k^3/6$, which grows like $k^3$. Still worse than uniform.

So polynomial shapes don't work well. The uniform sequence (constant) gives the best "flatness" among simple shapes, with the convolution being a triangle.

To do better than uniform, we need a more sophisticated shape. The key insight is that we want to reduce the center of the convolution while not increasing the edges too much.

One approach: use a "modulated" sequence. For example, $a_j = c \cdot (1 + \epsilon \cos(2\pi f j / n))$ for some frequency $f$ and small $\epsilon$. The convolution would be:
$(a*a)_k = c^2 \sum_j (1 + \epsilon \cos(2\pi f j/n))(1 + \epsilon \cos(2\pi f (k-j)/n))$
$= c^2 [S_k + \epsilon \sum_j \cos(2\pi f j/n) + \epsilon \sum_j \cos(2\pi f (k-j)/n) + \epsilon^2 \sum_j \cos(2\pi f j/n) \cos(2\pi f (k-j)/n)]$

where $S_k$ is the number of valid $j$'s. The second and third terms are small (they oscillate). The fourth term is:
$\sum_j \cos(2\pi f j/n) \cos(2\pi f (k-j)/n) = \frac{1}{2} \sum_j [\cos(2\pi f k/n) + \cos(2\pi f (2j-k)/n)]$

The first part is $S_k \cos(2\pi f k/n) / 2$. The second part oscillates and is approximately 0 for large $n$ (if $f$ is not a multiple of $n$).

So the convolution is approximately:
$(a*a)_k \approx c^2 [S_k (1 + \epsilon^2/2 \cos(2\pi f k/n))]$

This means the convolution still has the triangular shape $S_k$, but with a small modulation $\cos(2\pi f k/n)$ at frequency $f$. This doesn't fundamentally change the shape.

To really flatten the convolution, we need a more global change in the shape of $a$.

**Let me try a different approach: use the "water-filling" metaphor.**

Imagine the convolution as a "landscape" with peaks and valleys. We want to "flatten" it by "pouring water" (mass) from the peaks to the valleys. The "pouring" is done by adjusting $a_j$.

The key insight is that each $a_j$ contributes to the convolution at lags $k = j + m$ for all $m$ (where $a_m$ is non-zero). So changing $a_j$ affects a "window" of the convolution.

This is similar to the "heating" problem in image processing: we have a "temperature" field (the convolution) and we want to flatten it by adjusting "heat sources" (the $a_j$'s).

**Algorithm: Iterative "heat balancing"**

1. Start with uniform $a$.
2. Compute $c = a * a$.
3. For each $j$, compute the "contribution" of $a_j$ to the peak: $contrib_j = \sum_k \max(0, c_k - \bar{c}) \cdot \frac{\partial c_k}{\partial a_j} / c_k$ (or something like that).
4. Reduce $a_j$ for positions with high contribution, increase for positions with low contribution.
5. Repeat.

This is essentially what the multiplicative update does, but let me think about a more principled version.

**Principled approach: Proportional update based on convex duality**

The problem is: minimize $\max_k (a*a)_k$ subject to $a \geq 0, \sum a_j = 1$.

The Lagrangian is: $L(a, \lambda, \mu) = \max_k (a*a)_k + \mu(\sum a_j - 1) - \sum_j \nu_j a_j$

where $\lambda_k$ are the dual variables for the "implicit" constraints $(a*a)_k \leq M$ (after introducing $M$).

The dual problem is: maximize $\min_a L(a, \lambda, \mu)$ subject to $\lambda_k \geq 0$.

At the optimum, the KKT conditions give us the balance equation:
$2 \sum_m \lambda_{j+m} a_m = \mu + \nu_j$ for all $j$

where $\nu_j \geq 0$ and $\nu_j a_j = 0$ (complementary slackness).

For positions where $a_j > 0$: $2 \sum_m \lambda_{j+m} a_m = \mu$.
For positions where $a_j = 0$: $2 \sum_m \lambda_{j+m} a_m \leq \mu$.

So the "active" positions (where $a_j > 0$) have a constant "potential" $\mu$, and the "inactive" positions (where $a_j = 0$) have potential $\leq \mu$.

This is exactly the "water-filling" problem! The potential $h_j = 2 \sum_m \lambda_{j+m} a_m$ should be at most $\mu$ everywhere, and equal to $\mu$ where $a_j > 0$.

The multiplicative update tries to equalize $h_j$, which is a good approximation.

"""
Step function optimization combining mirror descent (LP-dual inspired),
L-BFGS on LSE-smoothed objective, and Nesterov-accelerated subgradient.
Uses adaptive soft active set, multi-length exploration, and local search.
"""

import numpy as np
from scipy.optimize import minimize
import time


def fast_conv(a):
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]


def compute_score(a):
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return np.inf
    return 2.0 * n * float(c.max()) / (S * S)


def normalize_to_sum1(a):
    S = a.sum()
    if S < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / S


def project_simplex(v):
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def lse_score_grad(a, beta):
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return 1e10, np.zeros(n)
    c_max = float(c.max())
    scaled = beta * (c - c_max)
    exp_s = np.exp(scaled)
    log_sum = np.log(exp_s.sum())
    L = c_max + log_sum / beta
    score = 2.0 * n * L / (S * S)
    p = exp_s / exp_s.sum()
    rev_a = a[::-1]
    M2 = 3 * n - 2
    M2f = 1 << (M2 - 1).bit_length()
    RA = np.fft.rfft(rev_a, M2f)
    P = np.fft.rfft(p, M2f)
    conv_res = np.fft.irfft(RA * P, M2f)
    g = 2.0 * conv_res[n - 1:2 * n - 1]
    S2 = S * S
    S3 = S2 * S
    grad = (2.0 * n) * (g / S2 - 2.0 * L * a / S3)
    return score, grad


def run_lbfgs(a0, beta, maxiter=5000, maxfun=100000, deadline=None):
    n = len(a0)
    a0 = np.clip(a0.astype(np.float64), 0.0, 1000.0).copy()
    if a0.sum() < 1e-6:
        a0[:] = 0.5
    bounds = [(0.0, 1000.0)] * n

    def obj(x, b):
        return lse_score_grad(x, b)

    options = {'ftol': 1e-15, 'gtol': 1e-13, 'maxiter': maxiter, 'maxfun': maxfun, 'maxls': 50}
    if deadline is not None:
        remaining = deadline - time.monotonic()
        if remaining < 2.0:
            sc, _ = lse_score_grad(a0, beta)
            return compute_score(a0), a0
        options['maxfun'] = min(maxfun, max(100, int(remaining * 150)))
        options['maxiter'] = min(maxiter, max(100, int(remaining * 40)))

    try:
        res = minimize(obj, a0, args=(beta,), method='L-BFGS-B', jac=True,
                       bounds=bounds, options=options)
        a_out = np.clip(res.x, 0.0, 1000.0)
    except Exception:
        a_out = a0
    return compute_score(a_out), a_out


def mirror_descent(a, n_iters, beta_schedule, alpha, deadline, label=""):
    """
    Mirror descent (multiplicative update) with soft active set.
    beta_schedule: list of beta values to use (cycled or one per iteration group)
    alpha: step size for the multiplicative update
    """
    n = len(a)
    a = normalize_to_sum1(a.astype(np.float64).copy())
    best_a = a.copy()
    best_sc = compute_score(a)
    M_fft = 1 << (3 * n - 2).bit_length()
    
    for it in range(n_iters):
        if deadline is not None and time.monotonic() > deadline:
            break
        
        c = fast_conv(a)
        M = float(c.max())
        if M < 1e-15:
            break
        
        # Soft active set
        beta = beta_schedule[min(it, len(beta_schedule) - 1)] if isinstance(beta_schedule, list) else beta_schedule
        exp_vals = np.exp(beta * (c - M))
        lambda_v = exp_vals / exp_vals.sum()
        
        # Compute h_j = 2 * sum_m lambda[j+m] * a[m]
        A = np.fft.rfft(a, M_fft)
        L = np.fft.rfft(lambda_v, M_fft)
        cross = np.fft.irfft(A * np.conj(L), M_fft)
        h = 2.0 * cross[:n]
        h = np.maximum(h, 1e-15)
        
        # Multiplicative update
        h_mean = h.mean()
        factor = (h_mean / h) ** alpha
        a = a * factor
        a = np.clip(a, 1e-15, 1000.0)
        a = normalize_to_sum1(a)
        
        sc = compute_score(a)
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()
    
    return best_sc, best_a


def nesterov_subgrad(a, n_iters, step_scale, deadline):
    """Nesterov accelerated projected subgradient on the simplex."""
    n = len(a)
    a = normalize_to_sum1(a.astype(np.float64).copy())
    a_prev = a.copy()
    best_a = a.copy()
    best_sc = compute_score(a)
    
    for it in range(n_iters):
        if deadline is not None and time.monotonic() > deadline:
            break
        
        # Nesterov momentum
        t = float(it + 1)
        momentum = (t - 1.0) / (t + 2.0)
        y = a + momentum * (a - a_prev)
        y = np.clip(y, 0.0, None)
        Sy = y.sum()
        if Sy < 1e-12:
            y = a.copy()
        else:
            y = y / Sy
        
        # Subgradient at y
        c_y = fast_conv(y)
        M_y = float(c_y.max())
        k_star = int(np.argmax(c_y))
        sg = np.zeros(n)
        j_start = max(0, k_star - n + 1)
        j_end = min(k_star, n - 1)
        if j_end >= j_start:
            sg[j_start:j_end + 1] = 2.0 * y[j_start:j_end + 1][::-1]
        
        # Polyak step size
        sc_y = 2.0 * n * M_y / (Sy * Sy)
        sc_lb = 2.0 * n / (2.0 * n - 1.0)
        step = (sc_y - sc_lb) / (float(sg @ sg) + 1e-30)
        step = min(step, 1.0)
        
        y_new = y - step * sg
        y_new = project_simplex(y_new)
        
        a_prev = a
        a = y_new
        
        sc = compute_score(a)
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()
    
    return best_sc, best_a
