(f*g)[k] = sum_j f[j] * g[k-j] where 0<=j<n and 0<=k-j<n.
So (f*g)[k] = sum_{j: max(0,k-n+1) <= j <= min(k,n-1)} f[j] * g[k-j]

Let m = k-j, so j = k-m. The constraint is:

Simplifying the bounds on m:
- k-m >= max(0, k-n+1) => m <= k - max(0, k-n+1) = min(k, n-1)
- k-m <= min(k, n-1) => m >= k - min(k, n-1) = max(0, k-n+1)

So: sum_{m=max(0,k-n+1)}^{min(k,n-1)} f[k-m] * g[m] <= M

This means: F[k, m] = f[k-m] if max(0,k-n+1) <= m <= min(k,n-1), else 0.
Or equivalently: F[k, m] = f[k-m] if 0 <= k-m < n, else 0.

def fast_conv(a):
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]

def compute_score(a):

    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return np.inf
    return 2.0 * n * float(np.max(c)) / (S * S)

def build_conv_matrix(a):
    """Build the convolution matrix F where (F @ g)[k] = (a*g)[k]."""
    n = len(a)
    # F[k, m] = a[k-m] if 0 <= k-m < n, else 0
    # k ranges from 0 to 2n-2, m ranges from 0 to n-1
    rows = []
    cols = []
    vals = []

        m_end = min(k, n - 1)
        for m in range(m_start, m_end + 1):
            rows.append(k)
            cols.append(m)
            vals.append(a[k - m])
    F = sp.csr_matrix((vals, (rows, cols)), shape=(2*n-1, n))
