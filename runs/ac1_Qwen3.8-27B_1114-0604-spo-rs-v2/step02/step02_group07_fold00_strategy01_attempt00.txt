## Approach and rationale
We now use an approach combining a genetic algorithm for global exploration and Adam optimization for local refinement. This is a fundamentally different strategy from the previous optimization-based method. The genetic algorithm generates diverse candidate sequences by mutating a pool of initial sequences found in the frequency domain, while the Adam optimizer further minimizes the score around promising candidates.

### Key rationale:
1. **Frequency domain initialization**: Start with sequences derived from the discrete Fourier transform that correspond to desired autocorrelation profiles.
2. **Two-phase optimization**: Use genetic algorithm for broad exploration and Adam for precise local minimization.
3. **Cross-stage adaptation**: Allow the best sequence from one phase to guide the initialization of the next phase.

### Bottlenecks addressed:
- The previous algorithm struggled to escape local minima due to its reliance on exact gradient information.
- This approach broadens the search space by using frequency-derived initial candidates and elitist mutations.

### Limitations:
- The fitness evaluation uses expensive FFT-based convolution via the authorative evaluator.
- Genetic algorithm parameters require manual tuning.

## Mathematical Specification
We seek to minimize the objective: `(2 * n * max(convolve(a, a))) / (sum(a))**2`

### Variables:
- `a` : real-valued ndarray of length `n`
- `f` : fitness function `f(a) = (2*n * max_convolution(a, mode="full")) / (sum(a))**2`
- `n` : fixed dimension from parent sequence or set to 2048 by default.

### Optimization formulation (Genetic Algorithm):
We treat each generation as a population of sequences, and select two parents to crossover and mutate using:
```
score = (2*n * max_conv) / (S)**2   [with S=sum(a)]
```
with `n` fixed to the length of the best candidate so far.

### GA Initialization:
We initialize the population by starting with samples from the frequency domain.

### Adam Optimization:
While converging from a candidate with the Adam opimizer, we incorporate two-level gradient blending and adaptive learning rates.
