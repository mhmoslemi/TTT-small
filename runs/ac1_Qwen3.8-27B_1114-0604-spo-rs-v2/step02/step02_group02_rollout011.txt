The gradient with respect to $f_j$ is:
$\frac{\partial L_\tau}{\partial f_j} = \sum_k p_k \frac{\partial (f*f)_k}{\partial f_j}$

where $p_k = \exp(\tau (f*f)_k) / \sum_l \exp(\tau (f*f)_l)$

$\nabla_j = \sum_k h_k (f_{k-j} + f_{j-k})$

This is a convolution of $h$ with $f$ (and its reverse)! So it can be computed with FFT.

Specifically:
$\sum_k h_k f_{k-j} = (h * f)_j$ (circular or linear, depending on setup)
$\sum_k h_k f_{j-k} = (h * f_{rev})_j$ where $f_{rev}$ is the reverse of $f$

So the gradient is $g_j = (h * f)_j + (h * f_{rev})_j$, which is 2 FFT operations.

This is very efficient! Each gradient evaluation costs one forward and one inverse FFT (or 2 FFTs total), which is $O(n \log n)$.
