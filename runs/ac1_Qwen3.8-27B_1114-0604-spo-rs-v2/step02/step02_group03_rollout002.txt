Let me think about what makes the score small:
- Score = `2 * n * max_k c_k / (sum a)^2` where `c = a * a` (linear convolution)
- If we normalize so that `sum(a) = S`, then score = `2 * n * max_k c_k / S^2`
- The "average" value of `c_k` is roughly `S^2 / (2n)` (since sum of all c_k = S^2 and there are 2n-1 terms)
- So the score is approximately `2n * (peak/avg) * (S^2/(2n)) / S^2 = peak/avg`
- Actually, score = `2n * max(c) / S^2` and `sum(c) = S^2`, so `avg(c) = S^2/(2n-1)`
- Score ≈ `(2n/(2n-1)) * max(c)/avg(c) ≈ peak-to-average ratio of autocorrelation`

So we want to minimize the peak-to-average ratio of the autocorrelation. This is the "crest factor" problem in signal processing!

Sequences with low crest factor in their autocorrelation are related to:
1. Barker codes (short sequences)
2. Zadoff-Chu sequences (complex)
3. m-sequences (for binary)
4. For real non-negative sequences, this is harder
