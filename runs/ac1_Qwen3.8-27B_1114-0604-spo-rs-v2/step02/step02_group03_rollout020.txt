The general principle: we want the convolution to be as "flat" as possible, i.e., as close to a constant as possible. This is like designing a "flat-top" convolution, which is the dual of the "flat-top" window design problem in signal processing.

In signal processing, flat-top windows (like the Nuttall window) are designed to have very low sidelobes in the frequency domain. Dually, we want a time-domain sequence whose self-convolution has a very flat peak.

This suggests using iterative algorithms from the window design literature, such as:
- Remez exchange algorithm (alternating between the time and frequency domains)
- Iterative reweighting

1. Start with a non-negative sequence f.
2. Compute c = f*f.
3. Find the set S of lags where c is close to its maximum (the "active set").
4. Solve for a new f that minimizes the maximum of c over the active set S, subject to f >= 0 and sum(f) = 1.
5. Iterate.

This is essentially what the previous code does with its "active set" gradient, but we could make it more explicit.

Alternatively, we can use the "alternating projection" approach:
1. Given a target convolution profile g (e.g., a flat profile), find the f that best matches f*f ≈ g (in some norm), subject to f >= 0.
2. Update g to the actual |f*f| profile (or a smoothed version).
3. Iterate.

But solving step 1 is a quadratic program (minimize ||f*f - g||^2 subject to f >= 0, sum(f) = 1), which is expensive for large n.

A more practical approach: use the gradient of the max with respect to f, which is:
grad_f[k] = 2 * sum_{i in S} f[i-k] (where S is the active set of lags)

This is a "filtered" version of f, and we can use it to guide the optimization.
