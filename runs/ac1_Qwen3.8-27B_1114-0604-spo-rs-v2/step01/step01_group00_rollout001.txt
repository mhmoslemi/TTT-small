Step function optimizer using coordinate descent with exact 1D sub-optimization.
Minimizes 2*n*max(f*f)/(sum f)^2 over non-negative sequences.

import numpy as np
from scipy.signal import fftconvolve
import time


def autocorr(f):
    """Compute linear autocorrelation (full convolution of f with itself)."""
    n = len(f)
    size = 1 << (2 * n - 1).bit_length()
    F = np.fft.rfft(f, size)
    return np.fft.irfft(F * F, size)[:2 * n - 1]


def eval_score(f):
    """Compute the objective value for a normalized sequence (sum=1)."""
    n = len(f)
    c = autocorr(f)
    return 2.0 * n * c.max()


def coord_descent(f, max_time, verbose=True):
    """Coordinate descent with 1D optimization."""
    f = f.astype(np.float64).copy()
    S = f.sum()
    f = f / S  # normalize to sum=1
    
    n = len(f)
    start_time = time.monotonic()
    
    best_score = eval_score(f)
    best_f = f.copy()
    
    grid_coarse = 50
    grid_fine = 200
    
    old_c = autocorr(f)
    
    pass_num = 0
    while time.monotonic() - start_time < max_time:
        pass_num += 1
        old_c = autocorr(f)
        any_improved = False
        
        for j in range(n):
            if time.monotonic() - start_time > max_time:
                break
            
            a = f[j]
            
            # Compute B, C, base for this coordinate
            # B[k] = 2*f[k-j] if 0<=k-j<n and k != 2j
            # C[k] = 1 if k == 2j
            # base[k] = old_c[k] - B[k]*a - C[k]*a^2
            
            idx = np.arange(2*n-1)
            mask_b = (idx >= j) & (idx < j + n) & (idx != 2*j)
            
            B = np.zeros(2*n-1)
            B[mask_b] = 2.0 * f[idx[mask_b] - j]
            C = np.zeros(2*n-1)
            if 2*j < 2*n - 1:
                C[2*j] = 1.0
            
            base = old_c - B * a - C * a * a
            
            # 1D optimization: minimize 2*n*max(base + B*x + C*x^2) / (1-a+x)^2
            # Coarse grid
            x_lo = 0.0
            x_hi = max(2.0 * a + 1.0/n, 1.0/n * 5)
            x_grid = np.linspace(x_lo, x_hi, grid_coarse)
            
            new_c = base[:, None] + B[:, None] * x_grid[None, :] + C[:, None] * (x_grid[None, :]**2)
            max_new = new_c.max(axis=0)
            denom = (1.0 - a + x_grid)**2
            with np.errstate(divide='ignore'):
                vals = 2.0 * n * max_new / denom
            vals[~np.isfinite(vals)] = np.inf
            
            best_i = np.argmin(vals)
            best_x = x_grid[best_i]
            best_val = vals[best_i]
            
            # Fine refinement around best_x
            if 0 < best_i < grid_coarse - 1:
                local_lo = x_grid[max(0, best_i - 2)]
                local_hi = x_grid[min(grid_coarse-1, best_i + 2)]
            else:
                local_lo = max(0, best_x * 0.5)
                local_hi = best_x * 1.5 + 1e-8
            
            x_fine = np.linspace(local_lo, local_hi, grid_fine)
            new_c_f = base[:, None] + B[:, None] * x_fine[None, :] + C[:, None] * (x_fine[None, :]**2)
            max_new_f = new_c_f.max(axis=0)

            with np.errstate(divide='ignore'):

**Key insight**: The problem is equivalent to minimizing the "peak sidelobe level" of the autocorrelation. In the radar/signal processing literature, there are well-known techniques for this:

1. **Cyclic descent**: Iteratively rotate phases (but we're constrained to be real and non-negative, so this doesn't directly apply)
2. **Parallel gradient descent**: Use the gradient of the peak to drive the optimization
3. **Penalty methods**: Add a large penalty for exceeding a threshold

Let me try a different tactic: **Bisection on the peak level**.

Algorithm:
1. Guess a peak level P
2. Check if there exists f >= 0 with sum(f) = 1 and (f*f)[k] <= P for all k
3. If yes, reduce P; if no, increase P
4. The minimum feasible P gives the optimal solution

Step 2 is a feasibility problem: find f >= 0, sum(f) = 1, (f*f)[k] <= P for all k = 0, ..., 2n-2.

This is a system of quadratic inequalities. In general, it's not a convex feasibility problem (quadratic constraints can be non-convex). However, for our specific structure:

(f*f)[k] = sum_i f[i]*f[k-i] <= P

This is a quadratic form: f^T A_k f <= P, where A_k is a specific matrix.

For k = n-1 (the middle): A_{n-1} has entries A_{n-1}[i,j] = 1 if i + j = n-1. This is a "reverse identity" matrix. The constraint f^T A_{n-1} f <= P becomes sum_i f[i]*f[n-1-i] <= P.

For k = 0: A_0 has only A_0[0,0] = 1. So f[0]^2 <= P.
