Let me also think about the "active set" method more carefully.

Given the current sequence p and the current convolution b = p*p:
- Active set S = {k : b_k >= max(b) - ε}
- We want to minimize the average of {b_k : k in S}
- This is: min_p (1/|S|) sum_{k in S} (p*p)_k subject to sum p = 1, p >= 0
- The gradient of (p*p)_k w.r.t. p_i is: 2*p_{k-i} (if 2i ≠ k) or p_{k-i} (if 2i = k)
  More precisely: d(p*p)_k / dp_i = p_{k-i} + p_{k-i} = 2p_{k-i} if i ≠ k-i, and p_{k-i} = p_{k/2} if 2i = k.
  Wait: (p*p)_k = sum_j p_j p_{k-j}. The terms involving p_i are:
  - j = i: p_i * p_{k-i}, derivative = p_{k-i}
  - k-j = i, i.e., j = k-i: p_{k-i} * p_i, derivative = p_{k-i}
  Total derivative = 2*p_{k-i} if i ≠ k-i, and p_{k-i} = p_{k/2} if 2i = k.
  
  So grad_k(i) = 2*p_{k-i} - p_{k-i} * δ_{2i,k} = p_{k-i} * (2 - δ_{2i,k})

- The gradient of the average is: (1/|S|) sum_{k in S} p_{k-i} * (2 - δ_{2i,k})

This can be computed efficiently using convolution:
sum_{k in S} p_{k-i} = (p * 1_S_rev)[i] where 1_S is the indicator of S (reversed appropriately)

Actually, let me define it more carefully.
sum_{k in S} p_{k-i} where 0 <= k-i < n
= sum_{k in S, max(0,i) <= k <= min(2n-2, i+n-1)} p_{k-i}

Let j = k-i:
= sum_{j: j >= 0, j < n, i+j in S} p_j

This is the cross-correlation of p with the indicator of S (shifted by i):
= sum_j p_j * 1_{i+j ∈ S}

This is (p ⊛ 1_S)(i) where ⊛ denotes cross-correlation in a specific sense.

We can compute this with FFT:
Let s be the indicator of S (length 2n-1). Let s_rev be s reversed (s_rev[k] = s[2n-2-k]).
Then sum_j p_j * s[i+j] = sum_j p_j * s_rev[2n-2-i-j]

This is (p * s_rev)[2n-2-i] where * is standard convolution.

So we can compute all values with one FFT-based convolution.

def _normalize(a, eps=1e-300):
    a = np.asarray(a, dtype=np.float64).copy()
    a = np.where(np.isfinite(a), a, 0.0)
    a = np.maximum(a, 0.0)
    s = float(a.sum())
    if not np.isfinite(s) or s <= 0.0:
        a.fill(1.0)
        s = float(a.sum())
    a /= s
    a = np.maximum(a, eps)
    a /= float(a.sum())
    return a


def _conv_self(a, L, m):
    f = np.fft.rfft(a, L)
    c = np.fft.irfft(f * f, L)[:m]
    c = np.ascontiguousarray(c)
    np.maximum(c, 0.0, out=c)
    return c


def _score_a(a, L, m, n):
    c = _conv_self(a, L, m)
    return float(2.0 * n * np.max(c))


def _analytical_init(n, rng):
    """Initialize with x^{-1/2} shape and variants."""
    inits = []
    j = np.arange(n, dtype=np.float64)
    
    # x^{-1/2} with midpoint: a_j ∝ 1/sqrt(j + 0.5)
    a = 1.0 / np.sqrt(j + 0.5)
    inits.append(_normalize(a))
    
    # x^{-1/2} with offset 1: a_j ∝ 1/sqrt(j + 1)
    a = 1.0 / np.sqrt(j + 1.0)
    inits.append(_normalize(a))
    
    # Slightly softer: a_j ∝ 1/(j + 1)^{0.45}
    a = 1.0 / (j + 1.0) ** 0.45
    inits.append(_normalize(a))
    
    # x^{-1/2} from the other end
    a = 1.0 / np.sqrt(n - 1.0 - j + 0.5)
    inits.append(_normalize(a))
    
    # x^{-0.4} (softer singularity)
    a = 1.0 / (j + 0.5) ** 0.4
    inits.append(_normalize(a))
    
    # x^{-0.5} with Gaussian smoothing
    a = 1.0 / np.sqrt(j + 0.5)
    k = 21
    kernel = np.exp(-0.5 * (np.arange(k) - k//2)**2 / (k//4.0))
    kernel /= kernel.sum()
    a = np.convolve(a, kernel, mode='same')
    inits.append(_normalize(a))
    
    # Random perturbation of x^{-1/2}
    base = 1.0 / np.sqrt(j + 0.5)
    noise = rng.normal(0, 0.1, n)
    noise = np.convolve(noise, np.ones(5)/5, mode='same')
    a = base * np.exp(noise)
    inits.append(_normalize(a))
    
    return inits


def _random_prior(n, rng):
    """Generate a random prior for diversity."""
    t = np.linspace(0.0, 1.0, n)
    z = rng.normal(0.0, 0.35)
    x = 2.0 * t - 1.0
    z += rng.normal(0.0, 0.5) * x
    z += rng.normal(0.0, 0.5) * (x*x - 1.0/3.0)
    
    kmax = int(rng.integers(2, 8))
    for k in range(1, kmax+1):
        amp = rng.uniform(0.05, 0.4) / max(1.0, math.sqrt(float(k)))
        ph = rng.uniform(0.0, 2.0*np.pi)
        z += amp * np.cos(2.0*np.pi*k*t + ph)
    
    noise = rng.normal(0.0, 0.15, n)
    if n > 5:
        noise = np.convolve(noise, np.ones(5, dtype=np.float64)/5.0, mode='same')
    z += noise
    
    p = np.exp(z - float(np.max(z)))
    p = np.maximum(p, 1e-300)
    return _normalize(p)
