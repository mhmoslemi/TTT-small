```python
def _build_A_fast(f):
    n = len(f)
    # For offset d, the entries are at (d+i, i) with value f[d], for i = 0, ..., n-1
    # Total n^2 entries
    # 
    # Let's build row by row:
    # Row k: entries at positions (k, j) where j = k-d for d = 0, ..., min(n-1, k) and j >= 0
    # i.e., j from max(0, k-n+1) to min(n-1, k)
    
    # Alternative: for each diagonal d, the column indices are 0, 1, ..., n-1
    # and row indices are d, d+1, ..., d+n-1
    
    # So:
    # For d = 0: rows = [0, 1, ..., n-1], cols = [0, 1, ..., n-1], vals = [f[0]]*n
    # For d = 1: rows = [1, 2, ..., n], cols = [0, 1, ..., n-1], vals = [f[1]]*n
    # ...
    
    rows_parts = []
    cols_parts = []
    vals_parts = []
    for d in range(n):
        rows_parts.append(np.arange(d, d+n))
        cols_parts.append(np.arange(n))
        vals_parts.append(np.full(n, f[d]))
    
    rows = np.concatenate(rows_parts)
    cols = np.concatenate(cols_parts)
    vals = np.concatenate(vals_parts)
    
    return sparse.coo_matrix((vals, (rows, cols)), shape=(2*n-1, n)).tocsr()
```

This is cleaner and avoids the diags function. The memory is O(n^2) for the concatenated arrays, which is 3 × n^2 × 8 bytes = 3 × 4096^2 × 8 ≈ 402MB for n=4096. That's too much!
