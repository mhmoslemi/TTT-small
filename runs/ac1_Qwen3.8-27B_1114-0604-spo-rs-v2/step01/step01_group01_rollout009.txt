For any non-negative sequence a of length n with sum S:
score = 2n * max_k (a*a)[k] / S^2

We know (a*a)[n-1] = sum_{j=0}^{n-1} a[j]*a[n-1-j]

And (a*a)[0] = a[0]^2, (a*a)[1] = 2a[0]*a[1], etc.

The minimum possible value of max_k (a*a)[k] / S^2 is what we want to find.

min_f max_t ∫ f(x)f(t-x) dx / (∫f)^2

def _next_pow2(x):
    x = int(max(1, x))
    L = 1
    while L < x:
        L <<= 1
    return L

def _conv_fft(a, b):
    nout = len(a) + len(b) - 1
