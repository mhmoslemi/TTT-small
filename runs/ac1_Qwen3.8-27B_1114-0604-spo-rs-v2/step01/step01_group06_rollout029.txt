Actually, I realize I should be more careful about the time budget. With n=16384, each FFT-based convolution takes about O(n log n) ≈ 16384 * 14 ≈ 230K operations. That's very fast (microseconds). The main cost is the Python overhead and memory access. Let me estimate: each gradient evaluation requires 2-3 FFTs (for c, for the gradient). At about 0.1ms per FFT, that's about 0.3ms per gradient step. In 2400 seconds, we can do about 8 million steps. That's more than enough.

    s_R = np.dot(a, R)
    grad_z = 2.0 * a * (R - s_R)

    # But our score has S = sum(a) in the denominator. Since we use softmax, S = 1 always.
    # So we're minimizing 2*n*max(c) with sum(a)=1, which is equivalent to the original
    # (by scale invariance).
    
    val = m + tau * np.log(se)  # the smooth max value (which is max(c) when tau->0)
    # Score = 2*n*val (since sum=1)
    
    return val, grad_z

            # Let's just use a heuristic
            step = 1.0 / (4.0 * n)

        s_new = x_new.sum()
        if s_new > 0:

        a_new = np.maximum(a_new, 0)
        s = a_new.sum()
        if s > 1e-12:
            a_new = a_new / s
        else:
            a_new = np.ones(n) / n
        
        a = a_new
        
        # Check improvement (every 100 steps)
        if t % 100 == 0:
            sc = _score(a)
            if sc < best_score:
                best_score = sc
                best_a = a.copy()

def _init(n):
    global _N, _NFFT
    _N = n

def _softmax(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -50, 50))
    s = e.sum()
    if s < 1e-300:
        return np.full_like(z, 1.0 / len(z))
    return e / s

    fa = np.fft.rfft(a, _NFFT)
    c = np.fft.irfft(fa * fa, _NFFT)[:2*_N-1].real
    return np.maximum(c, 0.0)

    s = a.sum()
