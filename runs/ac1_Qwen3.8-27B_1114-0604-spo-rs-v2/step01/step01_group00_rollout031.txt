Let me focus on a hybrid approach:
1. **Phase 1 (exploration, 50% of time)**: Run multiple mirror descent runs from diverse initializations. Keep the best.
2. **Phase 2 (exploitation, 30% of time)**: Run a more refined optimization from the best Phase 1 solution, using smaller steps and more iterations.
3. **Phase 3 (polish, 20% of time)**: Coordinate descent / local search on the best solution.

For diversity in Phase 1, I'll use:
- Power laws: $a_i \propto (n-i)^\alpha$ for $\alpha \in \{0.5, 1, 1.5, 2, 3, 4, 5\}$
- Exponential: $a_i \propto \exp(-\beta i)$ for $\beta \in \{0.001, 0.005, 0.01, 0.02, 0.05\}$
- Truncated power law: $a_i \propto (n-i)^\alpha$ for $i < n/2$, then $0$ (or smooth transition)
- The given sequence
- Random with structure: pick a random "shape" and smooth it

Let me also add an important new idea: **shape parameter sweep**. For each family of initializations, sweep the shape parameter and keep the best. This is a 1D optimization that can be done efficiently.

def _gradient(f, c, T):
    """Soft-max gradient of max(c) w.r.t. f."""
    n = len(f)
