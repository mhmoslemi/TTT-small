    # conj(FA)[m] = sum_i a[i] exp(2πimi/N)
    # FC[m] = sum_k c[k] exp(-2πimk/N)
    # product: sum_i sum_k a[i] c[k] exp(2πimi/N) exp(-2πimk/N)
    # = sum_i sum_k a[i] c[k] exp(-2πim(k-i)/N)
    # ifft gives: sum_m (product)[m] exp(2πimj/N)
    # = sum_i sum_k a[i] c[k] sum_m exp(-2πim(k-i)/N) exp(2πimj/N)
    # = sum_i sum_k a[i] c[k] * N * delta(k-i-j mod N)
    # = N * sum_i a[i] c[i+j] (when k = i+j, within valid range)
    
    # So ifft(conj(FA) * FC)[j] = N * sum_i a[i] c[i+j] (for j in valid range, assuming no wrap-around)
    # We need N >= n + (2n-1) - 1 = 3n-2 to avoid wrap-around.
    
    corr = np.fft.irfft(np.conj(FA) * FC, M2_fft)[:n]
    # corr[j] = M2_fft * sum_i a[i] * c[i+j] (but we need to check the scaling)
    # Actually numpy's ifft includes 1/N factor, so:
    # ifft(conj(FA)*FC)[j] = (1/N) * sum_m conj(FA[m])*FC[m]*exp(2πimj/N)
    # = (1/N) * N * sum_i a[i] * c[i+j] (from above, the N from the delta)
    # = sum_i a[i] * c[i+j]
    
    # Wait, N here is M2_fft. Let me just trust the formula:
    # ifft(conj(FFT(a)) * FFT(c))[j] = sum_i a[i] * c[i+j] (for circular correlation, but with sufficient zero-padding it's linear)
    
    grad_L = 2.0 * corr
    S2 = S * S
    S3 = S2 * S
    grad = 2.0 * n * (grad_L / S2 - 2.0 * L_val / S3)
    return score, grad

Let me re-derive more carefully:

We want: g[j] = sum_{k=0}^{2n-2} full_p[k] * (d conv[k]/da[j])
= sum_{k=0}^{2n-2} full_p[k] * 2*a[k-j] * 1(0 <= k-j < n)
= 2 * sum_{k=0}^{2n-2} full_p[k] * a[k-j] * 1(0 <= k-j < n)
= 2 * sum_{i=0}^{n-1} full_p[i+j] * a[i] (where i = k-j, and i+j < 2n-1)
= 2 * sum_{i=0}^{min(n-1, 2n-2-j)} a[i] * full_p[i+j]

This is the cross-correlation of a and full_p at lag j: (a ⋆ full_p)[j] = sum_i a[i] * full_p[i+j].

Using FFT: Let N >= n + (2n-1) - 1 = 3n-2.
Ifft(conj(Rfft(a, N)) * Rfft(full_p, N))[j] should give us the cross-correlation (up to scaling).

Actually, the standard formula for cross-correlation via FFT is:
(a ⋆ b)[j] = sum_i a[i] * b[i+j] = (1/N) * sum_m conj(A[m]) * B[m] * exp(2πimj/N)

where A = DFT(a) (padded to N), B = DFT(b) (padded to N).

But this gives a CIRCULAR cross-correlation. For it to be linear (no wrap-around), we need N >= len(a) + len(b) - 1 = n + (2n-1) - 1 = 3n-2.

So:
N = next_pow2(3n-2)
g[j] = 2 * ifft(conj(fft(a, N)) * fft(full_p, N))[j] for j = 0, ..., n-1
