This is a min-max problem. The von Neumann minimax theorem doesn't directly apply because the "max" is over a continuous set of lags and the "min" is over a non-convex function.

But we can use the following iterative scheme:
1. Start with a_0.
2. At each step, find k* = argmax (conv(a,a))_k.
3. Update a using the subgradient of (conv(a,a))_{k*}:
   a_{new} = a - eta * grad_{k*} (normalized to maintain sum = 1 and non-negativity)

This is essentially projected subgradient descent on the max. It's simple but slow.

A better version: use the "weighted" subgradient where the weights are concentrated on the top few lags.

Actually, the LP alternating method is a much better version of this. Let me stick with it.

def self_conv(a):
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]


def cross_conv(a, b):
    M = len(a) + len(b) - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    B = np.fft.rfft(b, M_fft)
    return np.fft.irfft(A * B, M_fft)[:M]

    S = float(a.sum())
    if S < 1e-12:

    c = self_conv(a)
    return 2.0 * n * float(c.max()) / (S * S)

    n = len(a)

    M_fft = 1 << (n_c - 1).bit_length()
    
    if x_init is not None:

    # Lipschitz constant estimate: beta * sum(a) * max(a) * n_c (rough)

        u = np.maximum(u, 0.0)
        x = x_new
        t_mom = t_new
    
    return x
