∂L/∂M: 2n/S^2 - sum_k λ_k = 0 → sum_k λ_k = 2n/S^2
∂L/∂a[j]: sum_k λ_k * 2*a[k-j] (with bounds) - μ_j = 0

So at the optimum, 2 * (λ * a_reversed)[j] = μ_j (proportional to the dual variable for a[j] ≥ 0).

This suggests that at the optimum, the "weighted sum" of the dual variables convolved with a gives a constant (where a > 0).

This is similar to the LP approach in the paper! The idea is:
- Find λ ≥ 0 such that (λ * a)[j] is constant for all j where a[j] > 0
- This is the "dual feasibility" condition

In practice, we can alternate between:
1. Given a, find the best λ (maximize sum λ_k subject to (λ*a)[j] ≤ C for all j where a[j]>0)
2. Given λ, find the best a (minimize 2n*M/S^2 subject to (a*a)[k] ≤ M, a ≥ 0)

This is a Frank-Wolfe / cutting-plane type approach.

**Strategy F: Iterative reweighting / EM-like approach**
1. Compute convolution c = a*a
2. Identify peak lag k*
3. "Reweight" the problem: instead of minimizing max(c), minimize sum_k w_k * c[k] where w_k is concentrated near k*
4. The optimal a for the reweighted problem can be found by solving a QP
5. Iterate

The key insight is that step 4 is a QP:
min 2n * sum_k w_k * a^T T_k a / S^2  s.t. a ≥ 0

If we fix S, this becomes:
min a^T (sum_k w_k T_k) a  s.t. a ≥ 0, sum(a) = S

This is a QP with a single linear constraint and box constraints. It can be solved efficiently!

The matrix Q = sum_k w_k T_k is a Toeplitz matrix (since each T_k is Toeplitz and w_k just scales them). So we can use FFT-based methods to multiply by Q.

This is essentially the SCA (Successive Convex Approximation) approach!

Let me develop this more concretely:

**SCA Algorithm:**
1. Initialize a (e.g., uniform or from parent)
2. Repeat:
   a. Compute c = a*a (linear convolution)
   b. Compute weights w_k = exp(β * (c[k] - max(c))) / sum(exp(β * (c[j] - max(c))))
      (These are softmax weights that concentrate on the peaks)
   c. Solve: min a^T Q a  s.t. a ≥ 0, sum(a) = 1
      where Q = sum_k w_k T_k (a Toeplitz matrix)
   d. Update a
3. The solution to step 2c can be found by:
   - Lagrangian: min a^T Q a - λ(sum(a) - 1) + sum_j μ_j * (-a_j)
   - KKT: 2Qa - λ*1 + μ = 0, with complementary slackness
   - Where a_j > 0: 2(Qa)_j = λ
   - Where a_j = 0: 2(Qa)_j ≥ λ

   This is like finding the "water level" λ such that the solution to the LSE or proximal problem gives the right support.

   Alternatively, for a fixed λ, the solution is:
   a_j = max(0, (λ*1 - (2Q - diag(2Q))a)_j / (2*Q_jj))
   
   This doesn't quite work because Q is not diagonal. But we can use iterative methods.

   Actually, the QP min a^T Q a s.t. a ≥ 0, sum(a) = 1 can be solved by:

```python
def fast_conv(a):
    """Linear self-convolution via FFT."""
    n = len(a)
    M = 2 * n - 1

    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]

def compute_score(a):
    """Compute 2n * max(conv) / S^2."""
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())

        # The score is still the full LSE, but the gradient focuses on top-k
        p = exp_shifted / exp_shifted.sum()
        # Zero out non-top-k weights
        p[~mask] = 0
        p = p / p.sum()  # Renormalize

    SCA step: solve min a^T Q a s.t. a >= 0, sum(a) = 1
    where Q is the Toeplitz matrix defined by the weighted autocorrelation.
    Uses projected gradient with backtracking line search.
    """

    a = normalize(a.copy())
    c = fast_conv(a)
    
    # Compute weights (softmax of convolution)
    c_max = c.max()

    w = w / w.sum()
    
    best_a = a.copy()
    best_obj = float(a @ toepmat_vec(w, a, n))  # a^T Q a

        Qa = toepmat_vec(w, a, n)
        
        # Projected gradient step
        grad = 2.0 * Qa
        # Line search
        step = 1.0 / (2.0 * np.max(w) * 2.0 * np.max(a) + 1e-10)
        step = min(step, 0.5)
        
        for ls in range(20):

            # Project onto {a >= 0, sum(a) = 1}
            a_new = np.maximum(a_new, 0.0)

                best_obj = obj_new
                best_a = a.copy()
                break
            step *= 0.5

            break
```

One more idea: **The "important set" approach from the paper**.

The paper describes solving:

This is an LP! For a fixed f and M, we want to find g ≥ 0 that maximizes sum(g) subject to (f*g)[k] ≤ M for all k.

The constraint (f*g)[k] = sum_j f[j] * g[k-j] ≤ M is linear in g (for fixed f).

So this is:

where F is the Toeplitz matrix with f.

This can be solved with an LP solver! And the solution gives a direction g - f (after normalization) to move in.

This is essentially a Frank-Wolfe step! The LP gives the "farthest point" in the feasible set from the current point, and we move toward it.

```python
def frank_wolfe_step(f, M, n):
    """
    Solve: max sum(g) s.t. (f*g)[k] <= M for all k, g >= 0.
    Returns the optimal g.
    """
    from scipy.optimize import linprog
    
    # Decision variables: g[0], ..., g[n-1]
    # Objective: max sum(g) → min -sum(g)
    c = -np.ones(n)
    
    # Constraints: (f*g)[k] <= M for k = 0, ..., 2n-2
    # (f*g)[k] = sum_j f[j] * g[k-j] (linear convolution)
    # For fixed k: sum_j f[j] * g[k-j] = sum_{j: 0<=k-j<=n-1} f[j] * g[k-j]
    # = sum_{m: max(0,k-n+1) <= m <= min(k, n-1)} f[k-m] * g[m]
    
    # So the constraint matrix A has:
    # A[k, m] = f[k-m] if 0 <= k-m <= n-1 and 0 <= m <= n-1, else 0
    
    A = np.zeros((2*n-1, n))
    for k in range(2*n-1):
        for m in range(n):
            idx = k - m
            if 0 <= idx <= n-1:
                A[k, m] = f[idx]
    
    bounds = [(0, None)] * n
    res = linprog(c, A_ub=A, b_ub=np.full(2*n-1, M), bounds=bounds, method='highs')
    
    if res.status == 0:
        return res.x
    else:
        return f  # Return current point if LP fails
```

Now, the Frank-Wolfe algorithm:
1. Start with a_0 (e.g., uniform)
2. At each iteration:
   a. Compute M = max(conv(a))
   b. Solve LP: max sum(g) s.t. (a*g) ≤ M, g ≥ 0 → get g
   c. Normalize: g = g / sum(g) (to maintain sum = 1)
   d. Update: a ← (1-t)*a + t*g where t = 2/(iter+2) (or line search)
3. Return best a found

"""
Advanced multi-method optimizer for minimizing 2n*max(conv(a,a))/S^2.
Combines: (1) top-k LSE annealing with L-BFGS-B, (2) Frank-Wolfe/LP steps,
(3) SCA-QP refinement, (4) Fienup spectral flattening, (5) multi-restart
with peak-targeted perturbations, and (6) n-adaptation.
"""

import numpy as np
from scipy.optimize import minimize
import time

def fast_conv(a):
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]

def compute_score(a):
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return np.inf
    return 2.0 * n * float(np.max(c)) / (S * S)

def normalize(a):
    a = np.maximum(a, 0.0)
    S = a.sum()
    if S < 1e-15:
        return a
    return a / S

def topk_lse_obj_grad(a, beta, k=10):
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return 1e10, np.zeros(n)
    
    c_max = float(c.max())
    shifted = beta * (c - c_max)
    shifted = np.clip(shifted, -500, 500)
    exp_shifted = np.exp(shifted)
    
    if k < len(c) and k > 0:
        # Only use top-k in the gradient
        top_idx = np.argpartition(exp_shifted, -k)[-k:]
        p = np.zeros_like(exp_shifted)
        p[top_idx] = exp_shifted[top_idx]
        p = p / p.sum()
    else:
        p = exp_shifted / exp_shifted.sum()
    
    log_sum = float(np.log(p.sum() * p.max() / p.max() * np.exp(beta * (c_max - c_max))))
    # Actually, let's just use the full LSE for the score but top-k for gradient
    L = c_max + float(np.log(np.exp(shifted).sum())) / beta
    
    # Gradient using top-k p
    a_rev = a[::-1]
    M3 = (2 * n - 1) + n - 1
    M3_fft = 1 << (M3 - 1).bit_length()
    PA = np.fft.rfft(p, M3_fft)
    RA = np.fft.rfft(a_rev, M3_fft)
    conv_res = np.fft.irfft(PA * RA, M3_fft)[:M3]
    grad_L = 2.0 * conv_res[n - 1:2 * n - 1]
    
    S2 = S * S
    S3 = S2 * S
    grad = (2.0 * n) * (grad_L / S2 - 2.0 * L / S3)
    
    score = (2.0 * n * L) / S2
    return score, grad

def lse_obj_grad(a, beta):
    """Standard LSE with full softmax."""
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return 1e10, np.zeros(n)
    
    c_max = float(c.max())
    shifted = beta * (c - c_max)
    shifted = np.clip(shifted, -500, 500)
    exp_shifted = np.exp(shifted)
    p = exp_shifted / exp_shifted.sum()
    L = c_max + float(np.log(exp_shifted.sum())) / beta
    
    a_rev = a[::-1]
    M3 = (2 * n - 1) + n - 1
    M3_fft = 1 << (M3 - 1).bit_length()
    PA = np.fft.rfft(p, M3_fft)
    RA = np.fft.rfft(a_rev, M3_fft)

    S2 = S * S
    S3 = S2 * S
    grad = (2.0 * n) * (grad_L / S2 - 2.0 * L / S3)

def run_lbfgs(a0, objective, maxiter=5000, maxfun=50000):
    n = len(a0)
    a0 = normalize(a0.copy())
    bounds = [(0.0, None)] * n
    try:

            objective, a0,

def fienup_flat(a, n_iters=300):
    n = len(a)
    a = normalize(a.copy())
    M_fft = 1 << (2 * n - 1).bit_length()
    best_a = a.copy()
    best_sc = compute_score(a)
    
    for it in range(n_iters):
        progress = it / max(1, n_iters)
        A = np.fft.rfft(a, M_fft)
        P = A.real ** 2 + A.imag ** 2
        P_mean = float(P.mean())
        
        alpha = 0.1 + 0.8 * progress
        P_target = np.full_like(P, P_mean)
        P_blend = (1.0 - alpha) * P + alpha * P_target
        P_blend = np.maximum(P_blend, 1e-30)
        
        ratio = np.sqrt(P_blend / np.maximum(P, 1e-30))
        A_new = A * ratio
        a_new = np.fft.irfft(A_new, M_fft)[:n]
        a_new = np.maximum(a_new, 0.0)
        S = a_new.sum()
        if S < 1e-12:
            break
        a_new = a_new / S
        a = a_new
        
        sc = compute_score(a)
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()
    
    return best_a

def frank_wolfe_step(f, M, n, n_constraints=50):
    """
    Frank-Wolfe: solve max sum(g) s.t. (f*g)[k] <= M for top constraints, g >= 0.
    """
    from scipy.optimize import linprog
    
    c_conv = fast_conv(f)  # This is f*f, but we need f*g constraints
    # Active constraints: where (f*f) is closest to M (i.e., the "hardest" constraints)
    # For the LP, we use: (f*g)[k] <= M for k where (f*f)[k] is large
    
    # Select top n_constraints lags
    top_idx = np.argsort(c_conv)[::-1][:n_constraints]
    
    A = np.zeros((n_constraints, n))
    for i, k in enumerate(top_idx):
        k = int(k)
        m_start = max(0, k - n + 1)
        m_end = min(k, n - 1)
        for m in range(m_start, m_end + 1):
            A[i, m] = f[k - m]
    
    c_obj = -np.ones(n)
    bounds = [(0, None)] * n
    b_ub = np.full(n_constraints, M)
    
    try:
        res = linprog(c_obj, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': 5})
        if res.status == 0:
            return res.x
    except Exception:
        pass
    
    return f  # Fallback: return current point

def frank_wolfe_iterate(a, n_iters=100, t_decay=0.99):
    """
    Frank-Wolfe iterations for minimizing max(conv(a)) subject to a >= 0, sum(a) = 1.
    """
    n = len(a)
    a = normalize(a.copy())
    best_a = a.copy()
    best_sc = compute_score(a)
    t = 1.0
    
    for it in range(n_iters):
        c = fast_conv(a)
        M = float(c.max())
        
        # Solve FW subproblem
        g = frank_wolfe_step(a, M, n, n_constraints=30)
        g = normalize(g)
        
        # Line search for step size
        best_t = t
        best_val = compute_score(a)
        for trial_t in [t, t*0.5, t*0.25, 0.9, 0.7, 0.5]:
            a_try = (1 - trial_t) * a + trial_t * g
            a_try = normalize(a_try)
            sc = compute_score(a_try)
            if sc < best_val:
                best_val = sc
                best_t = trial_t
        
        a = (1 - best_t) * a + best_t * g
        a = normalize(a)
        
        sc = compute_score(a)
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()
        
        t = max(0.01, t * t_decay)
    
    return best_a

def sca_qp(a, beta_w=100, n_inner=200):
    """
    SCA step: solve min a^T Q_w a s.t. a >= 0, then normalize.
    Q_w is defined by weights w = softmax(conv(a) * beta_w).
    Uses projected gradient with backtracking.
    """
    n = len(a)
    a = normalize(a.copy())
    c = fast_conv(a)
    
    c_max = c.max()
    w = np.exp(beta_w * (c - c_max))
    w = w / w.sum()
    
    def qa_vec(x):
        """Compute Q_w @ x using FFT."""
        # (Q_w x)[j] = sum_m x[m] * (w[j+m] + w[j-m]) with bounds
        # = (w * x)[j] + (x * w_flip)[n_w-1+j] where w_flip = w[::-1]
        n_w = len(w)  # 2n-1
        M1 = 1 << (n + n_w - 2 - 1).bit_length()
        X = np.fft.rfft(x, M1)
        W = np.fft.rfft(w, M1)
        Wf = np.fft.rfft(w[::-1], M1)
        
        term1 = np.fft.irfft(X * W, M1)[:n]
        term2 = np.fft.irfft(X * Wf, M1)[n_w-1:n_w-1+n]
        return term1 + term2
    
    def objective(x):
        """Compute x^T Q x = sum_k w[k] * (x*x)[k]."""
        cx = fast_conv(x)
        return float(np.dot(w, cx))
    
    # Projected gradient with backtracking
    best_a = a.copy()
    best_obj = objective(a)
    L = 1.0  # Lipschitz constant estimate
    
    for it in range(n_inner):
        grad = 2.0 * qa_vec(a)
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-14:
            break
        
        # Backtracking line search
        step = 1.0 / L
        a_new = a - step * grad
        a_new = np.maximum(a_new, 0.0)
        S = a_new.sum()
        if S < 1e-12:
            break
        a_new = a_new / S
        
        obj_new = objective(a_new)
        
        ls_count = 0
        while obj_new > best_obj * (1 + 1e-10) + 0.5 * step * step * L * step * grad_norm * grad_norm and ls_count < 30:
            step *= 0.5
            a_new = a - step * grad
            a_new = np.maximum(a_new, 0.0)
            S = a_new.sum()
            if S < 1e-12:
                a_new = a
                break
            a_new = a_new / S
            obj_new = objective(a_new)
            ls_count += 1
        
        a = a_new
        if obj_new < best_obj:
            best_obj = obj_new
            best_a = a.copy()
        
        # Update L
        if ls_count > 0:
            L *= 2
    
    return best_a

def peak_shave(a, n_iters=2000, top_k=5):
    """Subgradient peak shaving."""
    n = len(a)
    a = normalize(a.copy())
    best_a = a.copy()
    best_sc = compute_score(a)
    
    for it in range(n_iters):
        c = fast_conv(a)
        S = float(a.sum())
        M_val = float(c.max())
        sc = 2.0 * n * M_val / (S * S)
        
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()
        
        # Top-k subgradient
        top_idx = np.argsort(c)[::-1][:top_k]
        sg = np.zeros(n)
        for k in top_idx:
            k = int(k)
            j_start = max(0, k - n + 1)
            j_end = min(k, n - 1)
            if j_end >= j_start:
                sg[j_start:j_end+1] += a[j_start:j_end+1][::-1]
        
        # Step size
        step = 0.005 / (1 + it * 0.001)
        a = a - step * sg
        a = np.maximum(a, 0.0)
        S = a.sum()
        if S < 1e-12:
            break
        a = a / S
    
    return best_a

def interpolate_seq(a, new_n):
    if len(a) == new_n:
        return a.copy()
    x_old = np.linspace(0, 1, len(a))
    x_new = np.linspace(0, 1, new_n)
    return np.interp(x_new, x_old, a)
