So the target for `|A[k]|` is `|FFT_N(conv_target)[k]|^(1/2)`.

Let me compute this:
```python
N = next_power_of_2(2*n-1)
b_target = np.zeros(N)
b_target[:2*n-1] = 1.0
B = np.fft.rfft(b_target)
target_amp = np.sqrt(np.abs(B))
```

And in the Fienup iteration:
```python
amp = np.abs(A)
amp_new = amp * (target_amp / amp) ** alpha
A_new = amp_new * np.exp(1j * np.angle(A))
a_new = np.fft.irfft(A_new, N)[:n]
```

This should be a better target than flat amplitude!

Let me also think about the non-negativity handling. The previous approach uses:
- Hard clipping: `a = max(a, 0)`
- Sigmoid gating: `a = a * sigmoid(alpha * a)`

A better approach might be to use the "water-filling" or "reflection" method:
- After the inverse FFT, we get `a_new` which may have negative values.
- Instead of hard-clipping, we can add a constant to make the minimum zero: `a_new = a_new - min(a_new)`.
- Or use a soft threshold: `a_new = a_new * sigmoid(beta * a_new)` with large beta.

Actually, the hard clip + renormalization approach is fine for practical purposes. The sigmoid gating is more expensive and doesn't necessarily help.

Let me also consider: what if I use a **two-phase** approach:
1. Phase 1: Flatten the convolution using the correct target spectrum.
2. Phase 2: Fine-tune using direct time-domain optimization.

For Phase 2, I'll use a subgradient method that targets all significant peaks (not just the top-k).

**Another idea**: Use the **Bregman iteration** or **ADMM** approach:
- Introduce auxiliary variables `b_k = conv(a,a)[k]`
- Minimize `max(b_k)` subject to `b = conv(a,a)`, `a >= 0`
- Alternate: update `a` to minimize `max(b) + (rho/2)*||conv(a,a) - b||^2`, update `b` to project onto `b_k <= M`.

The projection onto `b_k <= M` is just `b_k = min(b_k, M)`. And the update for `a` is a quadratic minimization (since `||conv(a,a) - b||^2` is quartic in a, not quadratic... hmm, that doesn't work directly).

Actually, `||conv(a,a) - b||^2` is quartic in a, not quadratic. So ADMM doesn't directly apply.

Let me just go with the practical approach.

**Let me also think about sequence length.** The previous solution has length 6962. The score is `2n * max_b / S^2`. For a given "quality" of the sequence (how flat the convolution is), a longer sequence gives a lower score because of the `2n/(2n-1)` factor approaching 1. But a longer sequence is harder to optimize.

The theoretical lower bound for length n is `2n/(2n-1)`. For n=6962, this is ≈ 1.0000718. For n=10000, it's ≈ 1.0001. The difference is tiny, so the length isn't the main issue.

The main issue is how close we can get to the theoretical limit given the non-negativity constraint.

1. Correct target spectrum (sqrt of DFT of top-hat)
2. Multiple Fienup variants with different targets
3. Aggressive peak-directed descent
4. L-BFGS with log-sum-exp
5. Good time management

Here's my implementation:

```python
"""
Optimized step function construction using spectral shaping with correct target
spectrum (sqrt of DFT of top-hat), peak-directed subgradient descent with
all-significant-peaks, and L-BFGS polish with log-sum-exp smoothing.
Key improvements: (1) correct spectral target derived from desired flat convolution,
(2) subgradient method targeting all significant peaks simultaneously,
(3) better time allocation and adaptive step sizes.
"""
import numpy as np
from scipy.optimize import minimize
import time


def fast_conv(a):
    """Fast linear convolution via FFT."""
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]


def compute_score(a):
    """Compute the objective value."""
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return np.inf
    return 2.0 * n * float(np.max(c)) / (S * S)


def compute_target_spectrum(n, N):
    """
    Compute the target amplitude spectrum that would produce a flat convolution.
    If b_target is flat over [0, 2n-2], then FFT(b_target) = B, and we want
    A^2 ≈ B, so |A| ≈ |B|^(1/2).
    """
    b_target = np.zeros(N)
    b_target[:2*n-1] = 1.0
    B = np.fft.rfft(b_target)
    target = np.sqrt(np.abs(B))
    # Avoid zeros
    target = np.maximum(target, 1e-10)
    return target


def fienup_targeted(a, n_iters, alpha_start, alpha_end, target_amp, N):
    """
    Fienup iteration targeting a specific amplitude spectrum.
    """
    n = len(a)
    a = np.maximum(a.astype(np.float64), 0.0).copy()
    S = float(a.sum())
    if S < 1e-12:
        a = np.ones(n) / n
        S = 1.0
    a = a / S

    best_a = a.copy()
    best_sc = compute_score(a)

    for it in range(n_iters):
        progress = it / max(1, n_iters)
        alpha = alpha_start + (alpha_end - alpha_start) * progress

        A = np.fft.rfft(a, N)
        amp = np.sqrt(A.real ** 2 + A.imag ** 2)
        phase = np.angle(A)

        # Geometric interpolation toward target
        amp_safe = np.maximum(amp, 1e-20)
        amp_new = amp_safe * (target_amp / amp_safe) ** alpha

        A_new = amp_new * np.exp(1j * phase)
        a_new = np.fft.irfft(A_new, N)[:n]
        a_new = np.maximum(a_new, 0.0)

        S_new = float(a_new.sum())
        if S_new < 1e-12:
            break
        a_new = a_new / S_new
        a = a_new

        sc = compute_score(a)
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()

    return best_a


def fienup_flat(a, n_iters=300, alpha_start=0.05, alpha_end=0.85):
    """Standard Fienup with flat amplitude target (for comparison)."""
    n = len(a)
    a = np.maximum(a.astype(np.float64), 0.0).copy()
    S = float(a.sum())
    if S < 1e-12:
        a = np.ones(n) / n
    a = a / S

    N = 1 << (2 * n - 1).bit_length()
    best_a = a.copy()
    best_sc = compute_score(a)

    for it in range(n_iters):
        progress = it / max(1, n_iters)
        alpha = alpha_start + (alpha_end - alpha_start) * progress

        A = np.fft.rfft(a, N)
        amp = np.sqrt(A.real ** 2 + A.imag ** 2)
        phase = np.angle(A)

        if len(amp) > 1:
            C = np.median(amp[1:])
        else:
            C = amp[0]
        C = max(C, 1e-20)

        amp_safe = np.maximum(amp, 1e-20)
        amp_new = amp_safe * (C / amp_safe) ** alpha

        A_new = amp_new * np.exp(1j * phase)
        a_new = np.fft.irfft(A_new, N)[:n]
        a_new = np.maximum(a_new, 0.0)

        S_new = float(a_new.sum())
        if S_new < 1e-12:
            break
        a_new = a_new / S_new
        a = a_new

        sc = compute_score(a)
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()

    return best_a


def subgradient_descent(a, n_iters=5000, frac_peaks=0.1, step_init=0.01, decay=0.9999):
    """
    Subgradient descent targeting the top fraction of peaks simultaneously.
    Uses the subgradient of max(b) averaged over the top peaks.
    """
    n = len(a)
    a = np.maximum(a.astype(np.float64), 0.0).copy()
    S = float(a.sum())
    if S < 1e-12:
        return a
    a = a / S

    N = 1 << (2 * n - 1).bit_length()
    n_conv = 2 * n - 1
    n_targets = max(1, int(frac_peaks * n_conv))
    
    best_a = a.copy()
    best_sc = compute_score(a)
    step = step_init
    sc_lb = 2.0 * n / (2.0 * n - 1.0)

    for it in range(n_iters):
        A = np.fft.rfft(a, N)
        c = np.fft.irfft(A * A, N)[:n_conv]
        S = float(a.sum())
        M_val = float(c.max())
        sc = 2.0 * n * M_val / (S * S)

        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()

        # Find top peaks
        if n_targets >= n_conv:
            top_idx = np.arange(n_conv)
        else:
            top_idx = np.argpartition(c, -n_targets)[-n_targets:]
            # Only keep those that are actually significant
            threshold = c.max() * 0.8  # at least 80% of max
            top_idx = top_idx[c[top_idx] >= threshold]
            if len(top_idx) == 0:
                top_idx = np.array([np.argmax(c)])

        # Compute subgradient
        sg = np.zeros(n)
        for k in top_idx:
            k = int(k)
            js = max(0, k - n + 1)
            je = min(k, n - 1)
            if je >= js:
                sg[js:je + 1] += 2.0 * a[js:je + 1][::-1]

        # Normalize subgradient by number of targets
        sg /= len(top_idx)

        S2 = S * S
        S3 = S2 * S
        grad = (2.0 * n) * (sg / S2 - 2.0 * M_val / S3)

        gn = float(np.linalg.norm(grad))
        if gn < 1e-15:
            break

        # Adaptive step size
        step = min(step, max((sc - sc_lb) / (gn * gn + 1e-30), 1e-10))
        step = min(step, 0.02)

        a -= step * grad
        a = np.maximum(a, 0.0)
        S = a.sum()
        if S < 1e-12:
            break
        a = a / S
        step *= decay

    return best_a


def lse_objective_and_grad(x, beta):
    """LSE-smoothed objective with gradient."""
    n = len(x)
    M = 2 * n - 1
    N = 1 << (M - 1).bit_length()
    A = np.fft.rfft(x, N)
    c = np.fft.irfft(A * A, N)[:M]
    S = float(x.sum())
    if S < 1e-12:
        return 1e10, np.zeros(n)

    c_max = float(c.max())
    scaled = beta * (c - c_max)
    # Clip to avoid overflow
    scaled = np.clip(scaled, -500, 500)
    exp_scaled = np.exp(scaled)
    exp_sum = float(exp_scaled.sum())
    if exp_sum < 1e-30:
        return 1e10, np.zeros(n)

    L = c_max + float(np.log(exp_sum)) / beta
    score = 2.0 * n * L / (S * S)

    # Softmax weights
    p = exp_scaled / exp_sum

    # Gradient of L w.r.t. x
    # dL/dx_i = 2 * sum_k p_k * (dc_k/dx_i)
    # dc_k/dx_i = 2*a[k-i] (if k != 2i) or a[i] (if k = 2i)
    # Using convolution: conv(p, a_reversed)
    rev_x = x[::-1]
    M2 = M + n - 1  # length of conv(p, rev_x)
    M2_fft = 1 << (M2 - 1).bit_length()
    RX = np.fft.rfft(rev_x, M2_fft)
    PP = np.fft.rfft(p, M2_fft)
    conv_res = np.fft.irfft(RX * PP, M2_fft)[n - 1:2 * n - 1]
    g_L = 2.0 * conv_res

    S2 = S * S
    S3 = S2 * S
    grad = (2.0 * n) * (g_L / S2 - 2.0 * L / S3)
    return score, grad


def run_lbfgs(a0, beta, maxiter=5000, maxfun=100000):
    """Run L-BFGS-B on the LSE-smoothed objective."""
    n = len(a0)
    a0 = np.clip(a0.astype(np.float64), 0.0, 1000.0).copy()
    if a0.sum() < 1e-6:
        a0[:] = 0.5
    a0 = a0 / a0.sum()
    bounds = [(0.0, 1000.0)] * n
    res = minimize(
        lse_objective_and_grad, a0, args=(beta,),
        method='L-BFGS-B', jac=True, bounds=bounds,
        options={'ftol': 1e-18, 'gtol': 1e-14,
                 'maxiter': maxiter, 'maxfun': maxfun, 'maxls': 50}
    )
    a_out = np.clip(res.x, 0.0, 1000.0)
    if a_out.sum() < 1e-6:
        a_out = a0.copy()
    exact_sc = compute_score(a_out)
    return exact_sc, a_out


def multiplicative_descent(a, n_iters=3000, n_peaks=20, step=0.01):
    """
    Multiplicative update: a[i] *= (1 - step * pressure[i])
    where pressure[i] is based on how much a[i] contributes to peaks.
    """
    n = len(a)
    a = np.maximum(a.astype(np.float64), 0.0).copy()
    S = float(a.sum())
    if S < 1e-12:
        return a
    a = a / S

    N = 1 << (2 * n - 1).bit_length()
    n_conv = 2 * n - 1
    best_a = a.copy()
    best_sc = compute_score(a)

    for it in range(n_iters):
        A = np.fft.rfft(a, N)
        c = np.fft.irfft(A * A, N)[:n_conv]
        S = float(a.sum())
        M_val = float(c.max())
        sc = 2.0 * n * M_val / (S * S)

        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()

        # Find top peaks
        if n_peaks >= n_conv:
            top_idx = np.arange(n_conv)
        else:
            top_idx = np.argpartition(c, -n_peaks)[-n_peaks:]

        # Compute pressure: for each i, how much does a[i] contribute to peaks?
        pressure = np.zeros(n)
        for k in top_idx:
            k = int(k)
            js = max(0, k - n + 1)
            je = min(k, n - 1)
            if je >= js:
                pressure[js:je + 1] += a[js:je + 1][::-1]

        pressure /= len(top_idx)

        # Multiplicative update
        # a_new = a * (1 - step * pressure / mean(pressure))
        mean_p = pressure.mean()
        if mean_p > 1e-20:
            ratio = pressure / mean_p
            a = a * np.clip(1.0 - step * (ratio - 1.0), 0.01, 2.0)

        a = np.maximum(a, 0.0)
        S = a.sum()
        if S < 1e-12:
            break
        a = a / S

    return best_a


def proportional_fitting(a, n_iters=2000, step=0.05):
    """
    Iterative proportional fitting: adjust a to make conv(a,a) flat.
    a_new[i] = a[i] * (target / contribution[i])^step
    where contribution[i] = sum_k w[k] * a[k-i] for appropriate k.
    """
    n = len(a)
    a = np.maximum(a.astype(np.float64), 0.0).copy()
    S = float(a.sum())
    if S < 1e-12:
        return a
    a = a / S

    N = 1 << (2 * n - 1).bit_length()
    n_conv = 2 * n - 1
    best_a = a.copy()
    best_sc = compute_score(a)

    for it in range(n_iters):
        A = np.fft.rfft(a, N)
        c = np.fft.irfft(A * A, N)[:n_conv]
        S = float(a.sum())
        M_val = float(c.max())
        sc = 2.0 * n * M_val / (S * S)

        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()

        # Target: flat convolution
        target_val = float(c.sum()) / n_conv  # = S^2 / (2n-1)

        # Weight: proportional to how much each c[k] exceeds target
        w = np.maximum(c / target_val - 1.0, 0.0)  # excess over target
        w_sum = w.sum()
        if w_sum < 1e-20:
            break
        w = w / w_sum

        # Compute contribution of each a[i] to the excess
        # contribution[i] = sum_k w[k] * a[k-i] (where valid)
        # This is conv(w, a_reversed)
        rev_a = a[::-1]
        M2 = n_conv + n - 1
        M2_fft = 1 << (M2 - 1).bit_length()
        WA = np.fft.rfft(w, M2_fft)
        RA = np.fft.rfft(rev_a, M2_fft)
        contrib = np.fft.irfft(WA * RA, M2_fft)[n - 1:2 * n - 1]

        # Multiplicative update
        mean_c = contrib.mean()
        if mean_c < 1e-20:
            break
        ratio = contrib / mean_c
        a = a * ((1.0 / ratio) ** step)
        a = np.maximum(a, 0.0)
        S = a.sum()
        if S < 1e-12:
            break
        a = a / S

    return best_a


def build_initializations(n, rng, parent):
    """Generate diverse initializations."""
    inits = []
    x = np.arange(n, dtype=np.float64) / n

    inits.append(np.ones(n) * 0.5)
    inits.append(np.maximum(0.1 + 0.8 * np.abs(2.0 * x - 1.0), 0.01))
    inits.append(np.maximum(0.5 + 0.4 * np.cos(np.pi * x), 0.01))
    inits.append(np.exp(-3.0 * (2.0 * x - 1.0) ** 2) + 0.05)

    # Random smooth
    freqs = rng.integers(1, 10, size=5)
    phases = rng.uniform(0, 2 * np.pi, size=5)
    amps = rng.uniform(0.1, 0.5, size=5)
    sig = np.ones(n) * 0.5
    for f, ph, am in zip(freqs, phases, amps):
        sig += am * np.cos(2 * np.pi * f * x + ph)
    inits.append(np.maximum(sig, 0.01))

    # Cosine window
    inits.append(np.maximum(0.5 * (1 + np.cos(2 * np.pi * x)), 0.01))

    # Random with structure
    inits.append(np.maximum(0.5 + 0.3 * np.random.default_rng(123).standard_normal(n) * 0.1, 0.01))

    if parent is not None and len(parent) == n:
        inits.append(np.clip(parent.astype(np.float64), 0.0, 1000.0).copy())

    return inits
```

```python
def subgradient_descent(a, n_iters, frac_peaks, step_init, decay):
    """Subgradient descent targeting top fraction of peaks."""
    n = len(a)
    a = np.maximum(a.astype(np.float64), 0.0).copy()
    S = float(a.sum())
    if S < 1e-12:
        return a
    a = a / S

    N = 1 << (2 * n - 1).bit_length()
    n_conv = 2 * n - 1
    n_targets = max(2, int(frac_peaks * n_conv))

    best_a = a.copy()
    best_sc = compute_score(a)
    step = step_init
    sc_lb = 2.0 * n / (2.0 * n - 1.0)

    for it in range(n_iters):
        A = np.fft.rfft(a, N)
        c = np.fft.irfft(A * A, N)[:n_conv]
        S = float(a.sum())
        M_val = float(c.max())
        sc = 2.0 * n * M_val / (S * S)

        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()

        if n_targets >= n_conv:
            top_idx = np.arange(n_conv)
        else:
            top_idx = np.argpartition(c, -n_targets)[-n_targets:]
            threshold = c.max() * 0.7
            top_idx = top_idx[c[top_idx] >= threshold]
            if len(top_idx) == 0:
                top_idx = np.array([np.argmax(c)])

        sg = np.zeros(n)
        for k in top_idx:
            k = int(k)
            js = max(0, k - n + 1)
            je = min(k, n - 1)
            if je >= js:
                sg[js:je + 1] += 2.0 * a[js:je + 1][::-1]

        sg /= len(top_idx)

        S2 = S * S
        S3 = S2 * S
        grad = (2.0 * n) * (sg / S2 - 2.0 * M_val / S3)

        gn = float(np.linalg.norm(grad))
        if gn < 1e-15:
            break

        step = min(step, max((sc - sc_lb) / (gn * gn + 1e-30), 1e-10))
        step = min(step, 0.015)

        a -= step * grad
        a = np.maximum(a, 0.0)
        S = a.sum()
        if S < 1e-12:
            break
        a = a / S
        step *= decay

    return best_a


def proportional_fitting(a, n_iters, step):
    """
    Proportional fitting: adjust a to make conv(a,a) flat.
   a_new[i] = a[i] * (target/contribution[i])^step
    """
    n = len(a)
    a = np.maximum(a.astype(np.float64), 0.0).copy()
    S = float(a.sum())
    if S < 1e-12:
        return a
    a = a / S

    N = 1 << (2 * n - 1).bit_length()
    n_conv = 2 * n - 1
    best_a = a.copy()
    best_sc = compute_score(a)

    for it in range(n_iters):
        A = np.fft.rfft(a, N)
        c = np.fft.irfft(A * A, N)[:n_conv]
        S = float(a.sum())
        M_val = float(c.max())
        sc = 2.0 * n * M_val / (S * S)

        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()

        target_val = float(c.sum()) / n_conv
        if target_val < 1e-20:
            break

        # Weight: excess over target
        w = np.maximum(c / target_val - 1.0, 0.0)
        w_sum = w.sum()
        if w_sum < 1e-20:
            break
        w = w / w_sum

        # Contribution: cross-correlation of w and a
        # h[i] = sum_k w[k] * a[k-i]
        N_corr = 1 << (2 * max(n_conv, n) - 1).bit_length()
        W = np.fft.rfft(w, N_corr)
        AA = np.fft.rfft(a, N_corr)
        contrib = np.fft.irfft(W * np.conj(AA), N_corr)[:n]

        mean_c = contrib.mean()
        if mean_c < 1e-20:
            break
        ratio = np.maximum(contrib / mean_c, 1e-10)
        a = a * (1.0 / ratio) ** step
        a = np.maximum(a, 0.0)
        S = a.sum()
        if S < 1e-12:
            break
        a = a / S

    return best_a

    S = float(a.sum())

        return a
    a = a / S

    N = 1 << (2 * n - 1).bit_length()
    n_conv = 2 * n - 1
    best_a = a.copy()
    best_sc = compute_score(a)

    for it in range(n_iters):
        A = np.fft.rfft(a, N)
        c = np.fft.irfft(A * A, N)[:n_conv]
        S = float(a.sum())
        M_val = float(c.max())
        sc = 2.0 * n * M_val / (S * S)

        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()

        if n_peaks >= n_conv:
            top_idx = np.arange(n_conv)
        else:
            top_idx = np.argpartition(c, -n_peaks)[-n_peaks:]

        pressure = np.zeros(n)
        for k in top_idx:
            k = int(k)
            js = max(0, k - n + 1)
            je = min(k, n - 1)
            if je >= js:
                pressure[js:je + 1] += a[js:je + 1][::-1]

        pressure /= len(top_idx)
        mean_p = pressure.mean()
        if mean_p > 1e-20:
            ratio = pressure / mean_p
            a = a * np.clip(1.0 - step * (ratio - 1.0), 0.01, 2.0)

        a = np.maximum(a, 0.0)
        S = a.sum()
        if S < 1e-12:
            break
        a = a / S

    return best_a


def lse_objective_and_grad(x, beta):
    """LSE-smoothed objective with gradient."""
    n = len(x)
    M = 2 * n - 1
    N = 1 << (M - 1).bit_length()
    A = np.fft.rfft(x, N)
    c = np.fft.irfft(A * A, N)[:M]
    S = float(x.sum())
    if S < 1e-12:
        return 1e10, np.zeros(n)

    c_max = float(c.max())
    scaled = beta * (c - c_max)
    scaled = np.clip(scaled, -500, 500)
    exp_scaled = np.exp(scaled)
    exp_sum = float(exp_scaled.sum())
    if exp_sum < 1e-30:
        return 1e10, np.zeros(n)

    L = c_max + float(np.log(exp_sum)) / beta
    score = 2.0 * n * L / (S * S)

    p = exp_scaled / exp_sum

    # Gradient of L: g_L[i] = 2 * sum_k p[k] * a[k-i] (approx)
    N_corr = 1 << (2 * max(M, n) - 1).bit_length()
    P = np.fft.rfft(p, N_corr)
    XX = np.fft.rfft(x, N_corr)
    h = np.fft.irfft(P * np.conj(XX), N_corr)[:n]
    g_L = 2.0 * h

    S2 = S * S
    S3 = S2 * S
    grad = (2.0 * n) * (g_L / S2 - 2.0 * L / S3)
    return score, grad


def run_lbfgs(a0, beta, maxiter, maxfun):
    """Run L-BFGS-B on the LSE-smoothed objective."""
    n = len(a0)
    a0 = np.clip(a0.astype(np.float64), 0.0, 1000.0).copy()
    if a0.sum() < 1e-6:
        a0[:] = 0.5
    a0 = a0 / a0.sum()
    bounds = [(0.0, 1000.0)] * n

    def obj_and_grad(x):
        return lse_objective_and_grad(x, beta)

    res = minimize(
        obj_and_grad, a0,
        method='L-BFGS-B', jac=True, bounds=bounds,
        options={'ftol': 1e-18, 'gtol': 1e-14,
                 'maxiter': maxiter, 'maxfun': maxfun, 'maxls': 40}
    )
    a_out = np.clip(res.x, 0.0, 1000.0)
    if a_out.sum() < 1e-6:
        a_out = a0.copy()
    exact_sc = compute_score(a_out)
    return exact_sc, a_out


def build_initializations(n, rng, parent):
    """Generate diverse initializations."""
    inits = []
    x = np.arange(n, dtype=np.float64) / n

    inits.append(np.ones(n) * 0.5)
    inits.append(np.maximum(0.1 + 0.8 * np.abs(2.0 * x - 1.0), 0.01))
    inits.append(np.maximum(0.5 + 0.4 * np.cos(np.pi * x), 0.01))
    inits.append(np.exp(-3.0 * (2.0 * x - 1.0) ** 2) + 0.05)

    freqs = rng.integers(1, 10, size=5)
    phases = rng.uniform(0, 2 * np.pi, size=5)
    amps = rng.uniform(0.1, 0.5, size=5)
    sig = np.ones(n) * 0.5
    for f, ph, am in zip(freqs, phases, amps):
        sig += am * np.cos(2 * np.pi * f * x + ph)
    inits.append(np.maximum(sig, 0.01))

    inits.append(np.maximum(0.5 * (1 + np.cos(2 * np.pi * x)), 0.01))

    # Structured random
    rng2 = np.random.default_rng(777)
    inits.append(np.maximum(0.5 + 0.3 * rng2.standard_normal(n) * 0.15, 0.01))

    # Two-scale structure
    inits.append(np.maximum(0.3 + 0.4 * np.cos(2 * np.pi * x) + 0.2 * np.cos(6 * np.pi * x), 0.01))

    if parent is not None and len(parent) == n:
        inits.append(np.clip(parent.astype(np.float64), 0.0, 1000.0).copy())

    return inits


def propose_candidate(seed=42, budget_s=2400):
    """
    Main search: targeted spectral shaping + proportional fitting + subgradient + L-BFGS.
    """
    rng = np.random.default_rng(seed)
    t_start = time.monotonic()
    total_budget = float(budget_s)
    deadline = t_start + total_budget - 25.0

    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64).ravel()
        if p.size >= 64:
            parent = np.clip(p, 0.0, 1000.0)
    except Exception:
        pass

    best_score = np.inf
    best_a = np.ones(4096) * 0.5

    def update_best(sc, arr, label=""):
        nonlocal best_score, best_a
        if sc < best_score:
            best_score = sc
            best_a = np.clip(arr.copy(), 0.0, 1000.0)
            elapsed = time.monotonic() - t_start
            print(f"  [{label}] NEW BEST: {sc:.8f} (n={len(arr)}, t={elapsed:.0f}s)")
            return True
        return False

    n_work = len(parent) if parent is not None else 8192
    N = 1 << (2 * n_work - 1).bit_length()
    target_amp = compute_target_spectrum(n_work, N)

    print(f"Working length: {n_work}, N={N}")
    print(f"Parent available: {parent is not None}")

    if parent is not None:
        sc = compute_score(parent)
        update_best(sc, parent, "PARENT")

    # ============================================================
    # Phase 1: Targeted spectral shaping (35% time)
    # ============================================================
    phase1_end = t_start + 0.35 * (total_budget - 25.0)
    print(f"\n=== Phase 1: Targeted Spectral Shaping (t<={phase1_end - t_start:.0f}s) ===")

    inits = build_initializations(n_work, rng, parent)
    print(f"  {len(inits)} initializations")

    for i, a0 in enumerate(inits):
        if time.monotonic() > phase1_end:
            break
        sc0 = compute_score(a0)
        if i <= 3 or sc0 < 1.6:
            print(f"  Init {i}: score={sc0:.6f}")

        # Targeted Fienup (key method)
        a_t = fienup_targeted(a0, n_iters=500, alpha_start=0.02, alpha_end=0.9,
                              target_amp=target_amp, N=N)
        sc = compute_score(a_t)
        update_best(sc, a_t, f"TARGET i={i}")

        # Flat Fienup
        if time.monotonic() < phase1_end - 30:
            a_f = fienup_flat(a0, n_iters=300, alpha_start=0.05, alpha_end=0.85)
            sc = compute_score(a_f)
            update_best(sc, a_f, f"FLAT i={i}")

        # Elliptical
        if time.monotonic() < phase1_end - 30:
            a_e = fienup_ellip(a_t, n_iters=200, beta_start=1.0, beta_end=5.0)
            sc = compute_score(a_e)
            update_best(sc, a_e, f"ELLI i={i}")

        # Proportional fitting after targeted
        if time.monotonic() < phase1_end - 20:
            a_pf = proportional_fitting(a_t, n_iters=800, step=0.03)
            sc = compute_score(a_pf)
            update_best(sc, a_pf, f"PROPF i={i}")

    print(f"After Phase 1: best = {best_score:.8f}")

    # ============================================================
    # Phase 2: Time-domain refinement (25% time)
    # ============================================================
    phase2_end = t_start + 0.60 * (total_budget - 25.0)
    print(f"\n=== Phase 2: Time-Domain Refinement (t<={phase2_end - t_start:.0f}s) ===")

    # Subgradient with different fractions
    for frac in [0.02, 0.05, 0.1, 0.15]:
        if time.monotonic() > phase2_end - 30:
            break
        a_sg = subgradient_descent(best_a, n_iters=2500, frac_peaks=frac,
                                   step_init=0.008, decay=0.99995)
        sc = compute_score(a_sg)
        update_best(sc, a_sg, f"SG f={frac}")

    # Proportional fitting (longer)
    if time.monotonic() < phase2_end - 30:
        a_pf2 = proportional_fitting(best_a, n_iters=1500, step=0.02)
        sc = compute_score(a_pf2)
        update_best(sc, a_pf2, "PROPF2")

    # Multiplicative descent
    if time.monotonic() < phase2_end - 30:
        a_md = multiplicative_descent(best_a, n_iters=1500, n_peaks=30, step=0.003)
        sc = compute_score(a_md)
        update_best(sc, a_md, "MULT")

    # Another round of targeted Fienup from best
    if time.monotonic() < phase2_end - 20:
        a_t2 = fienup_targeted(best_a, n_iters=300, alpha_start=0.02, alpha_end=0.6,
                               target_amp=target_amp, N=N)
        sc = compute_score(a_t2)
        update_best(sc, a_t2, "TARGET2")

    print(f"After Phase 2: best = {best_score:.8f}")

    # ============================================================
    # Phase 3: L-BFGS (30% time)
    # ============================================================
    phase3_end = t_start + 0.90 * (total_budget - 25.0)
    print(f"\n=== Phase 3: L-BFGS (t<={phase3_end - t_start:.0f}s) ===")

    for beta in [100, 300, 1000, 3000, 10000]:
        if time.monotonic() > phase3_end - 45:
            break
        remaining = phase3_end - time.monotonic()
        if remaining < 60:
            break
        print(f"  beta={beta}, remaining={remaining:.0f}s")
        maxiter = min(4000, int(remaining * 15))
        sc, a_opt = run_lbfgs(best_a, beta, maxiter=maxiter, maxfun=maxiter * 15)
        update_best(sc, a_opt, f"LBFGS b={beta}")

    print(f"After Phase 3: best = {best_score:.8f}")

    # ============================================================
    # Phase 4: Final polish (remaining)
    # ============================================================
    print(f"\n=== Phase 4: Final Polish ===")

    if time.monotonic() < deadline - 150:
        a_f2 = fienup_targeted(best_a, n_iters=200, alpha_start=0.01, alpha_end=0.3,
                               target_amp=target_amp, N=N)
        sc = compute_score(a_f2)
        update_best(sc, a_f2, "FIN-TARGET")

    if time.monotonic() < deadline - 150:
        a_sg2 = subgradient_descent(best_a, n_iters=2000, frac_peaks=0.05,
                                    step_init=0.003, decay=0.99999)
        sc = compute_score(a_sg2)
        update_best(sc, a_sg2, "FIN-SG")

    if time.monotonic() < deadline - 80:
        sc, a_opt = run_lbfgs(best_a, 5000, maxiter=2000, maxfun=30000)
        update_best(sc, a_opt, "FIN-LBFGS")

    # Perturbation restarts
    if time.monotonic() < deadline - 30:
        for trial in range(4):
            if time.monotonic() > deadline - 10:
                break
            noise_level = 0.005 * (1 + trial)
            a_p = best_a * (1.0 + noise_level * rng.standard_normal(len(best_a)))
            a_p = np.maximum(a_p, 0.0)
            S = a_p.sum()
            if S < 1e-12:
                break
            a_p = a_p / S
            a_r = fienup_targeted(a_p, n_iters=100, alpha_start=0.03, alpha_end=0.4,
                                  target_amp=target_amp, N=N)
            sc = compute_score(a_r)
            if sc < best_score:
                update_best(sc, a_r, f"RESTART {trial}")
                a_r2 = subgradient_descent(a_r, n_iters=1000, frac_peaks=0.05,
                                           step_init=0.003, decay=0.99998)
                sc2 = compute_score(a_r2)
                update_best(sc2, a_r2, f"RESTART+SG {trial}")

    # Final proportional fitting
    if time.monotonic() < deadline - 10:
        a_final_pf = proportional_fitting(best_a, n_iters=500, step=0.01)
        sc = compute_score(a_final_pf)
        update_best(sc, a_final_pf, "FIN-PROPF")

    # Output
    out = [float(max(0.0, min(1000.0, x))) for x in best_a]
    if sum(out) < 0.01:
        out = [0.5] * 64

    verified = float(evaluate_sequence(out))
    elapsed = time.monotonic() - t_start
    print(f"\n{'=' * 60}")
    print(f"FINAL: internal={best_score:.8f}, verified={verified:.8f}")
    print(f"Length: {len(out)}, Time: {elapsed:.1f}s / {total_budget}s")
    print(f"{'=' * 60}")
    return out
```
