- Convolve a_r with q: (a_r * q)[k] = sum_d a_r[d] * q[k-d] = sum_d a[n-1-d] * q[k-d]
  Let d' = n-1-d: = sum_{d'} a[d'] * q[k-n+1+d']
  = sum_{d'} a[d'] * q[(k-n+1)+d']
  = r[k-n+1] (if 0 <= k-n+1 <= n-1)

So r[j] = (a_r * q)[j + n - 1].

The convolution a_r * q has length n + (2n-1) - 1 = 3n-2.
