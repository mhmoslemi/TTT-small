Let me think about this differently. For large n, what structure minimizes the peak of the self-convolution?

The key insight from the n=5 examples: a "smooth" sequence (close to constant) has a score close to 2, and the peak of C is at the center. The peak at the center is approximately (sum a)^2 / n (for a "flat" sequence). So score ≈ 2n * (sum a)^2/n / (sum a)^2 = 2.

To beat 2, we need the peak of C to be less than (sum a)^2 / n. This means we need C to be "flatter" than the triangular shape that a constant sequence produces.

For a constant sequence, C[k] = n-|k| (for |k| < n, normalized so a[j]=1). The max is n at k=0 (which is the center of the convolution, k=n-1 in 0-indexed). Wait, I need to be careful about indexing.

For a = [1, 1, ..., 1] (length n):

So C is a triangle with peak n at k = n-1.
Max = n. Sum = n. Score = 2n*n/n^2 = 2.

For the score to be less than 2, we need max C < n * (sum a)^2 / n^2 = (sum a)^2 / n (when a[j] = 1).

So we need the peak of C to be less than n (for unit-valued sequences). But the "footprint" of C is still 2n-1 lags. If C is perfectly flat (all values equal), each value would be (sum of all C values) / (2n-1).

What's the sum of all C values? sum_k C[k] = (sum_j a[j])^2. (This is because C = a*a, and the sum of a convolution equals the product of the sums.)

So if C were perfectly flat: C[k] = (sum a)^2 / (2n-1) for all k. Max = (sum a)^2 / (2n-1). Score = 2n * (sum a)^2/(2n-1) / (sum a)^2 = 2n/(2n-1) ≈ 1.

So the theoretical minimum (if C could be perfectly flat) is 2n/(2n-1) which approaches 1 for large n. But C can't be perfectly flat because C[0] = a[0]^2 and C[2n-2] = a[n-1]^2, which are single terms.

Actually, C[0] = a[0]^2 and C[2n-2] = a[n-1]^2. These are the "edges" of the convolution and can be made small by making a[0] and a[n-1] small. The "interior" values C[k] for 1 <= k <= 2n-2 are sums of products and can potentially be made more uniform.

So the strategy is:
1. Make the edges of a small (a[0] ≈ 0, a[n-1] ≈ 0) to reduce C[0] and C[2n-2].
2. Make the "body" of a oscillate to reduce the peak at the center.
3. The goal is to make C as flat as possible in the interior.

This is essentially the "minimum peak sidelobe" (MPSL) problem for the aperiodic autocorrelation, which is well-studied in radar/communications.

For non-negative sequences, the problem is more constrained (we can't use negative values to cancel sidelobes), but we can still use oscillations to reduce peaks.

    # = sum_{k: 0<=k-m<n} p[k]*a[k-m] + sum_{k: 0<=m-k<n} p[k]*a[m-k]
    # = sum_{j=0}^{n-1} p[m+j]*a[j] + sum_{j=0}^{n-1} p[m-j]*a[j]
    # (where in the second sum, j=0 gives p[m]*a[0] which is the k=m case)
    
    # = f1[m] + f2[m] where f1[m] = sum_j a[j]*p[m+j] and f2[m] = sum_j a[j]*p[m-j]
    
    # f1[m] = corr[m] (already computed)
    # f2[m] = sum_j a[j]*p[m-j]
    
    # To compute f2 via FFT:
    # f2[m] = sum_{j=0}^{n-1} a[j]*p[m-j]
    # Let's define the cross-correlation: (a ⊙ p)[m] = sum_j a[j]*p[m+j] = f1[m]
    # And the "reverse correlation": (a ⊙' p)[m] = sum_j a[j]*p[m-j] = f2[m]
    # Note: f2[m] = (flip(a) ⊙ p)[n-1-m]... let me verify.
    # (flip(a) ⊙ p)[n-1-m] = sum_j flip(a)[j]*p[n-1-m+j] = sum_j a[n-1-j]*p[n-1-m+j]
    # Let j' = n-1-j: = sum_{j'} a[j']*p[n-1-m+n-1-j'] = sum_{j'} a[j']*p[2n-2-m-j']
    # That's not quite f2[m].
    
    # Alternative: f2[m] = sum_j a[j]*p[m-j]. Let k = m-j, so j = m-k:
    # f2[m] = sum_k a[m-k]*p[k] (for valid indices: 0<=m-k<n and 0<=k<2n-1)
    # = sum_{k=max(0,m-n+1)}^{min(m, 2n-2)} a[m-k]*p[k]
    
    # This is the standard cross-correlation of a and p at lag m:
    # (a ⊛ p)[m] = sum_k a[m-k]*p[k]
    
    # So f2[m] = (a ⊛ p)[m] = the standard cross-correlation.
    
    # In FFT: cross-correlation of a and p is IFFT(conj(A) * P) where A and P are FFTs.
    # This gives (a ⊛ p)[m] = sum_k a[k]*p[k+m] = f1[m]!
    
    # Wait, I'm confusing myself. Let me use a concrete definition:
    # Cross-correlation: R_{ap}[τ] = sum_k a[k] * conj(p[k+τ])
    # For real signals: R_{ap}[τ] = sum_k a[k] * p[k+τ]
    
    # In FFT: R_{ap}[τ] = IFFT(conj(A) * P)[τ]
    
    # So IFFT(conj(A) * P)[τ] = sum_k a[k] * p[k+τ] = f1[τ] (with τ = m)
    
    # And IFFT(A * conj(P))[τ] = sum_k p[k] * a[k+τ] = sum_k a[k+τ] * p[k]
    # Let j = k+τ: = sum_j a[j] * p[j-τ] = f2[τ]

    # f2 = IFFT(FA * conj(FP)) -> gives sum_j a[j]*p[m-j] (the "backward" correlation)

    # And since p is symmetric (p[k] = p[2n-2-k]), f2[m] = f1[2n-2-m]...

    # The gradient of L = (1/beta)*log(sum_k exp(beta*C[k])) w.r.t. a is:
    # grad_L = (1/beta) * sum_k exp(beta*C[k]) / sum_k exp(beta*C[k]) * grad_Ck
    # = sum_k p[k] * grad_Ck
    # where p[k] = exp(beta*C[k]) / sum exp(beta*C[k])
    
    # And grad_Ck[m] = a[k-m]*1_{0<=k-m<n} + a[m-k]*1_{0<=m-k<n}
    
    # So grad_L[m] = sum_k p[k] * a[k-m]*1_{0<=k-m<n} + sum_k p[k] * a[m-k]*1_{0<=m-k<n}
    # = f1[m] + f2[m]  (as derived above)
    
    # For the self-convolution C = a*a, we have C[k] = C[2n-2-k], so p[k] = p[2n-2-k].
    # f2[m] = sum_j a[j]*p[m-j]. Substituting p[m-j] = p[2n-2-(m-j)] = p[2n-2-m+j]:
    # f2[m] = sum_j a[j]*p[2n-2-m+j] = f1[2n-2-m]
    
    # So grad_L[m] = f1[m] + f1[2n-2-m]
    
    # But f1[m] is only defined for m = 0, ..., n-1 (it's the first n values of the correlation).
    # f1[2n-2-m] would be for index 2n-2-m which could be up to 2n-2.
    # The full correlation f1 has length n + (2n-1) - 1 = 3n-2? No...
    # f1[m] = sum_{j=0}^{n-1} a[j]*p[m+j], where p has length 2n-1.
    # For this to be non-zero, we need m+j < 2n-1 for some j, i.e., m < 2n-1.
    # And m+j >= 0 for the valid j, i.e., m >= -(n-1), but m >= 0 from our range.
    # So f1[m] is defined for m = 0, 1, ..., 2n-2.
    
    # Therefore: grad_L[m] = f1[m] + f1[2n-2-m] for m = 0, ..., n-1.
    
    # This is much simpler! I just need to compute f1 (the full cross-correlation) and add
    # the symmetric part.
    
    # Let me recompute:
    M2 = 2 * n - 1
    M2_fft = 1 << (M2 - 1).bit_length()
    RA = np.fft.rfft(a, M2_fft)
    P_full = np.fft.rfft(p, M2_fft)
    # f1[m] = sum_j a[j]*p[m+j] = IFFT(conj(RA) * P_full)[m]
    f1 = np.fft.irfft(np.conj(RA) * P_full, M2_fft)
    # f1 is length M2_fft, but we only need f1[0] to f1[2n-2]
    f1 = f1[:M2]  # length 2n-1
    
    # grad_L[m] = f1[m] + f1[2n-2-m] for m = 0, ..., n-1
    grad_L = f1[:n] + f1[n-1::-1]  # f1[2n-2-m] for m=0..n-1 is f1[n-1], f1[n-2], ..., f1[0] reversed
    # Wait: 2n-2-m for m=0 gives 2n-2, for m=n-1 gives n-1.
    # f1[2n-2], f1[2n-3], ..., f1[n-1]
    # That's f1[n-1:2n-1][::-1] = f1[n-1::][::-1]
    
    grad_L = f1[:n] + f1[n-1:2*n-1][::-1]
    
    S2 = S * S
    S3 = S2 * S
    grad = 2.0 * n * (grad_L / S2 - 2.0 * L_val / S3)
    return score, grad
