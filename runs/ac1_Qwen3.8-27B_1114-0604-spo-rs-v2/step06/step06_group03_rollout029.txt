This is a shape optimization problem! And the optimal shape can be found by solving an infinite-dimensional optimization problem (or approximating it with a finite-dimensional one).

For the continuous problem, the convolution is:
(f*f)(t) = integral_0^1 f(s) * f(t-s) ds (with f=0 outside [0,1])

The domain of t is [0, 2] (since both s and t-s must be in [0,1]).

We want to minimize: 2 * max_{t in [0,2]} (f*f)(t) / (int_0^1 f)^2

subject to f >= 0 on [0,1].

By scaling invariance (if we replace f by cf, the ratio is unchanged), we can set int f = 1 WLOG.

So: minimize max_{t in [0,2]} (f*f)(t) subject to f >= 0, int f = 1.

The minimum possible value of max (f*f)(t) is at least 1/2 (by averaging: integral_0^2 (f*f)(t) dt = (int f)^2 = 1, over a domain of length 2, so the average is 1/2).

So the minimum score is at least 2*(1/2) = 1.

This confirms the theoretical lower bound of 1.

Now, what shape achieves this? We want (f*f)(t) to be as flat as possible (close to 1/2 everywhere).

The "ideal" solution would be f*f(t) = 1/2 for all t in [0,2]. Taking the Laplace/Fourier transform:
F(s)^2 = (1/2) * (1 - e^{-2s})/s (for the Laplace transform)

So F(s) = sqrt((1/2) * (1-e^{-2s})/s)

And f would be the inverse transform. This might not be non-negative, so the constraint f >= 0 will bind.
