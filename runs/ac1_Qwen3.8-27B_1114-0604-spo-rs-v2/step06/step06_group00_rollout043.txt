`g[j] = sum_{k in A, k>=j} a[k-j] * w_k + sum_{k in A, k<j} a[j-k] * w_k`

where `w_k` are the weights (for a single peak, w_k = 1 if k is the argmax, 0 otherwise).

At the KKT optimum, `g[j]` should be constant for all j with a[j] > 0.

This gives a system of equations that we can solve iteratively:
1. Compute the current peak lag(s).
2. Compute the subgradient.
3. Find the "optimal" distribution that equalizes the subgradient.
4. Move toward it.

**Idea 2: Mirror asymmetry exploitation**

Note that `conv[k] = conv[2n-2-k]` (the convolution is symmetric). So we only need to consider lags 0 to n-1.

Also, `conv[n-1] = sum_i a[i]*a[n-1-i]` is the "palindromic" correlation. If the sequence is symmetric (`a[i] = a[n-1-i]`), then `conv[n-1] = sum a[i]^2`, which is the energy. For a normalized sequence (sum=1), the energy is at least 1/n (by Cauchy-Schwarz), with equality for uniform. So for symmetric sequences, `conv[n-1] >= 1/n`, giving score >= 2.

This means **symmetric sequences cannot beat score 2**! We need **asymmetric** sequences.

This is a crucial insight. The previous program might have been wasting time on symmetric solutions.

**Idea 3: One-sided concentration**

So we need to balance: concentrate mass but spread it enough to avoid large edge correlations.
