**Algorithm: Active Set Power Iteration with KKT Verification**

1. Start from initial sequence a
2. Loop:
   a. Compute cv = a*a (self-convolution)
   b. Find max_cv = max(cv)
   c. Active set S = {k : cv[k] >= max_cv - epsilon} (or top-K lags)
   d. Run power iteration: repeatedly apply T_S, normalize, until convergence
   e. Check KKT: is T_S(a) approximately constant on {i : a[i] > 0}?
   f. If KKT satisfied (or improvement), accept new a
   g. If not, try different epsilon or K
3. Return best a found

The power iteration step is:
- a_new = T_S(a)
- a_new = max(a_new, 0) (clip to non-negative)
- a_new = a_new / sum(a_new) (normalize)
- Check convergence: ||a_new - a|| / ||a|| < tol

This is essentially the power iteration for the top eigenvector of T_S (restricted to non-negative vectors).

One more practical consideration: the power iteration convergence rate. The rate is determined by the ratio lambda_2 / lambda_1 (second eigenvalue to first). If this ratio is close to 1, convergence is slow.

For our T_S operator, the eigenvalues are related to the "smoothing" effect. If S = {0}, then T_S = 2I (in the bulk, away from boundaries), so all eigenvalues are 2 (degenerate). The power iteration doesn't help in this case.

If S = {0, 1, 2, ..., K} (a "band" of lags), then T_S is a "smoothing" operator (like a finite difference stencil), and the top eigenvalue corresponds to the "smoothest" mode (constant in the bulk). Lanczos for the top eigenvalue of a symmetric matrix A:
- v_0 = initial vector (normalized)
- For j = 1, 2, ...:
  - w_j = A v_{j-1}
  - alpha_j = v_{j-1}^T w_j
  - w_j = w_j - alpha_j v_{j-1} - beta_{j-1} v_{j-2}
  - beta_j = ||w_j||
  - v_j = w_j / beta_j
  - Check convergence: |r_j| / beta_j < tol where r_j is the residual

Each iteration costs one matrix-vector product (A v = T_S v), which is O(n * |S|) or O(n log n) with FFT.

For our problem, Lanczos should converge in O(sqrt(n)) iterations (for a matrix of size n with a well-separated top eigenvalue). For n=10000, that's about 100 iterations, each costing O(n log n) ≈ 140000 operations. Total: 14 million operations, which is very fast.

Let me use a simpler approach: **Chebyshev-accelerated power iteration**.

The idea: instead of just doing a = T_S(a), we apply a Chebyshev polynomial of T_S to accelerate convergence. The optimal polynomial is the Chebyshev polynomial that minimizes the maximum of |p(lambda)| over the spectrum of T_S (excluding the top eigenvalue).

For T_S with eigenvalues in [lambda_min, lambda_max] and top eigenvalue lambda_1, the optimal polynomial is:
p(x) = T_m((lambda_min + lambda_max - 2x) / (lambda_max - lambda_min)) / T_m((lambda_min + lambda_max - 2*lambda_1) / (lambda_max - lambda_min))

where T_m is the m-th Chebyshev polynomial.

    out = np.fft.irfft(A * A, N)[:M]
    return np.maximum(out, 0.0)


def compute_score(a):
    n = len(a)
    S = float(a.sum())
    if S < 1e-12:
        return np.inf
    cv = self_conv(a)
    return float(2.0 * n * cv.max() / (S * S))


def normalize(a):
    a = np.asarray(a, dtype=np.float64).ravel()
    a = np.maximum(a, 0.0)
    S = float(a.sum())
    if S < 1e-15:
        return np.ones(max(1, len(a))) / max(1, len(a))
    return a / S


def apply_T_S(a, S_list):
    n = len(a)
    result = np.zeros(n)
    for k in S_list:
        k = int(k)
        if k == 0:
            result += 2.0 * a
        elif k < n:
            result[:n - k] += a[k:]
            result[k:] += a[:n - k]
    result /= float(len(S_list))
    return result


def power_iter_converge(a, S_list, max_iter=5000, tol=1e-13):
    a = normalize(a.copy())
    if len(S_list) == 0:
        return a
    for _ in range(max_iter):
        a_new = apply_T_S(a, S_list)
        a_new = np.maximum(a_new, 0.0)
        S_sum = float(a_new.sum())
        if S_sum < 1e-15:
            break
        a_new /= S_sum
        diff = float(np.max(np.abs(a_new - a)))
        a = a_new
        if diff < tol:
            break
    return a


def active_set_solve(a_init, deadline=None, max_outer=300):
    a = normalize(a_init.copy())
    best_a = a.copy()
    best_sc = compute_score(a)
    n = len(a)

    for outer in range(max_outer):
        if deadline is not None and time.monotonic() > deadline:
            break

        cv = self_conv(a)
        max_cv = float(cv.max())
        if max_cv < 1e-15:
            break

        threshold = max_cv * 0.9995
        S_mask = cv >= threshold
        S_list = np.where(S_mask)[0].tolist()

        max_S = max(10, n // 200)
        if len(S_list) > max_S:
            S_list = np.argsort(cv)[-max_S:].tolist()

        if len(S_list) == 0:
            S_list = [int(np.argmax(cv))]

        a_new = power_iter_converge(a, S_list, max_iter=5000, tol=1e-13)

        sc = compute_score(a_new)
        if np.isfinite(sc) and sc < best_sc:
            best_sc = sc
            best_a = a_new.copy()

        cv_new = self_conv(a_new)
        max_new = float(cv_new.max())

        S_vals = cv_new[S_list]
        all_S_active = float(S_vals.min()) >= max_new * 0.999 if len(S_vals) > 0 else True

        if len(S_list) < 2 * n - 1:
            non_S_mask = np.ones(2 * n - 1, dtype=bool)
            non_S_mask[S_list] = False
            max_non_S = float(cv_new[non_S_mask].max()) if non_S_mask.any() else 0.0
            missing = max_non_S >= max_new * 0.999
        else:
            missing = False

        a = a_new
        if all_S_active and not missing:
            break

    return float(best_sc), best_a


def cross_corr_for_grad(a, w):
    n = len(a)
    Nc = next_pow2(2 * n)
    A_rev = np.fft.rfft(a[::-1], Nc)
    W = np.fft.rfft(w, Nc)
    full = np.fft.irfft(A_rev * W, Nc)[:2 * n - 1]
    return full[n - 1:2 * n - 1]


def lse_objective_and_grad(a, beta):
    n = len(a)
    S = float(a.sum())
    if S < 1e-8:
        return 1e10, np.zeros(n)

    cv = self_conv(a)
    d = cv * n / (S * S)
    dmax = float(d.max())
    if dmax <= 0:
        return 1e10, np.zeros(n)

    z = beta * (d - dmax)
    z = np.clip(z, -60.0, 60.0)
    e = np.exp(z)
    sum_e = float(e.sum())
    if sum_e <= 0 or not np.isfinite(sum_e):
        z = z - z.max()
        e = np.exp(z)
        sum_e = float(e.sum())
    if sum_e <= 0:
        return 1e10, np.zeros(n)
    w = e / sum_e

    L = dmax + np.log(sum_e) / beta
    LDS = float(np.dot(w, d))

    h = cross_corr_for_grad(a, w)

    grad = (4.0 * n * h) / (S * S)
    grad -= (4.0 * LDS) / S
    grad = np.nan_to_num(grad, nan=0.0, posinf=0.0, neginf=0.0)
    grad = np.clip(grad, -1e6, 1e6)
    return 2.0 * L, grad


def run_lse_optimize(a_init, beta, deadline, maxfun):
    a = normalize(a_init)
    n = len(a)

    def fun(x):
        sc, g = lse_objective_and_grad(x, beta)
        return sc, g

    bounds = [(0.0, 1e6)] * n
    opts = {
        "ftol": 1e-14,
        "gtol": 1e-10,
        "maxiter": max(50, maxfun // 2),
        "maxfun": int(maxfun),
        "maxls": 40,
    }

    try:
        res = minimize(fun, a, method="L-BFGS-B", jac=True,
                       bounds=bounds, options=opts)
        a_out = normalize(res.x) if res.x is not None else a
    except Exception:
        a_out = a

    if deadline is not None and time.monotonic() > deadline:
        return compute_score(a), a
    return compute_score(a_out), a_out


def resample_to_length(a, n_target):
    a = np.asarray(a, dtype=np.float64).ravel()
    m = len(a)
    if m == 0:
        return np.ones(n_target) / n_target
    if m == n_target:
        return a.copy()
    x_old = np.linspace(0.0, 1.0, m)
    x_new = np.linspace(0.0, 1.0, n_target)
    return np.interp(x_new, x_old, a).astype(np.float64)


def generate_inits(n, rng, parent):
    inits = []
    x = np.linspace(0.0, 1.0, n)

    def add(arr):
        arr = np.asarray(arr, dtype=np.float64).ravel()
        if len(arr) != n:
            arr = resample_to_length(arr, n)
        arr = np.maximum(arr, 0.0)
        if arr.sum() < 1e-10:
            arr = np.ones(n)
        inits.append(normalize(arr))

    if parent is not None and len(parent) > 0:
        pr = resample_to_length(parent, n)
        add(pr)
        add(pr[::-1])

    add(np.ones(n))

    for alpha in (0.3, 0.5, 0.8, 1.0, 1.5, 2.0, 3.0):
        add(1.0 + alpha * np.abs(2.0 * x - 1.0))

    for alpha in (0.3, 0.5, 1.0, 2.0):
        add(1.0 + alpha * (2.0 * x - 1.0) ** 2)

    for f in (1, 2, 3, 4, 6, 8):
        for alpha in (0.3, 0.6, 1.0, 1.5, 2.0):
            add(1.0 + alpha * np.cos(2.0 * np.pi * f * x))

    for f in (1, 2, 3, 4, 6):
        add(1.0 + 0.5 * np.sin(np.pi * f * x))
        add(1.0 + 0.5 * np.abs(np.sin(np.pi * f * x)))

    for width in (0.05, 0.1, 0.15, 0.2, 0.3):
        add(np.exp(-(((x - 0.5) / width) ** 2)))
        add(np.exp(-(((x - 0.25) / width) ** 2)) + np.exp(-(((x - 0.75) / width) ** 2)))

    for rate in (1.0, 2.0, 3.0, 5.0, 10.0):
        add(np.exp(-rate * x) + np.exp(-rate * (1.0 - x)))

    for p in (0.5, 1.0, 2.0, 4.0, 8.0):
        t = np.abs(2.0 * x - 1.0)
        add(1.0 - 0.5 * t ** p)

    # Random smooth
    Nf = next_pow2(n)
    for _ in range(8):
        freqs = np.fft.rfftfreq(Nf) * Nf
        power = 1.0 / ((np.abs(freqs) + 1.0) ** float(rng.uniform(1.0, 5.0)))
        power[0] = 0.0
        phase = rng.uniform(-np.pi, np.pi, size=len(power))
        spec = power * np.exp(1j * phase)
        noise = np.fft.irfft(spec, Nf)[:n]
        noise = noise - float(noise.mean())
        add(1.0 + float(rng.uniform(0.3, 1.5)) * noise)

    # Periodic-like structures
    for period in (4, 8, 16, 32, 64):
        base = np.array([1.0, 0.3, 0.7, 0.5, 0.9, 0.2, 0.8, 0.4,
                         1.0, 0.5, 0.3, 0.8, 0.6, 0.9, 0.4, 0.7,
                         1.0, 0.2, 0.8, 0.5, 0.3, 0.9, 0.4, 0.7,
                         1.0, 0.5, 0.8, 0.3, 0.6, 0.9, 0.2, 0.7,
                         0.5, 0.8, 0.3, 0.9, 0.4, 0.6, 0.7, 0.2,
                         1.0, 0.4, 0.8, 0.3, 0.9, 0.5, 0.2, 0.7,
                         0.6, 0.3, 0.9, 0.4, 0.7, 0.8, 0.2, 0.5,
                         1.0, 0.3, 0.7, 0.5, 0.9, 0.2, 0.8, 0.4])[:period]
        reps = n // period + 1
        periodic = np.tile(base, reps)[:n]
        add(periodic * (1.0 - 0.3 * np.abs(2.0 * x - 1.0)))

    return inits


def perturb_sequence(a, rng, strength=0.2):
    p = normalize(a)
    n = len(p)
    mode = int(rng.integers(0, 6))

    if mode == 0:
        q = p * np.exp(strength * rng.standard_normal(n))
    elif mode == 1:
        t = float(rng.uniform(0.05, 0.3))
        q = (1.0 - t) * p + t * (np.ones(n) / n)
    elif mode == 2:
        d = self_conv(p)
        dmax = float(d.max())
        if dmax > 1e-12:
            k = int(rng.integers(1, 6))
            top_idx = np.argsort(d)[-k:]
            w = np.zeros(len(d))
            w[top_idx] = 1.0 / k
            h = cross_corr_for_grad(p, w)
            hmax = float(np.max(h)) + 1e-15
            q = p * np.exp(-strength * h / hmax)
        else:
            q = p.copy()
    elif mode == 3:
        logp = np.log(p + 1e-300)
        noise = rng.standard_normal(n)
        k = min(31, max(3, int(n) // 200))
        if k % 2 == 0:
            k += 1
        if k >= 3 and k <= n:
            c = k // 2
            sig = max(1.0, c / 2.0)
            kern = np.exp(-((np.arange(k) - c) ** 2) / (2.0 * sig * sig))
            kern /= kern.sum()
            noise = np.convolve(noise, kern, mode="same")
        noise -= noise.mean()
        logp += strength * 0.5 * noise
        q = np.exp(logp - logp.max())
    elif mode == 4:
        x = np.linspace(0.0, 1.0, n)
        q = p * (1.0 + strength * 0.5 * np.cos(2 * np.pi * float(rng.integers(1, 10)) * x))
    else:
        k = max(3, int(rng.integers(3, max(5, n // 100))))
        if k % 2 == 0:
            k += 1
        k = min(k, n if n % 2 == 1 else n - 1)
        c = k // 2
        sig = max(1.0, c / 2.0)
        kern = np.exp(-((np.arange(k) - c) ** 2) / (2.0 * sig * sig))
        kern /= kern.sum()
        q = np.convolve(p, kern, mode="same")

    return normalize(np.maximum(q, 0.0))
