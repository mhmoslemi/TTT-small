At optimum: ∂L/∂a[i] = 0 for a[i] > 0
→ 4n * h[i] - mu = 0
→ h[i] = mu/(4n) = constant

So yes, at the optimum, h[i] = corr_pair(a, w)[i] should be constant for all i in the support of a.

This is different from h[i] ∝ a[i]. The "power iteration" insight I was using before was wrong (or at least, it was for a different formulation).

Let me reconsider. If h[i] should be constant, then the "target" is a flat vector. The multiplicative update should be:
a_new[i] ∝ a[i] * exp(-eta * (h[i] - mean(h)))

This pushes a down where h is above average and up where h is below average.

In log space: log(a_new) = log(a) - eta * (h - mean(h)) (then normalize)

This is more like a "flattening" operation on h.

Actually, let me think about it differently. The fixed point condition h[i] = const means:
sum_k w[k] * a[k-i] = const for all i

This is a linear equation in a. If we write it as a matrix equation: W * a = c * 1 (where W is a circulant-like matrix based on w), then a is an eigenvector of W (or the solution to a linear system).

So the optimal a is (approximately) the top eigenvector of the matrix W!

This is exactly what power iteration does: repeatedly multiply W by a vector and normalize.

But W is implicitly defined by w (the active set weights). So the algorithm is:
1. Choose active set weights w (based on current d)
2. Compute h = W * a = corr_pair(a, w)
3. Update: a_new = normalize(a_new = a * (1 + eta * (something based on h)))

The "something" should push a towards the eigenvector. If W * a should be proportional to 1 (constant), and currently it's h, then we want to modify a so that W * new_a is more constant.

One approach: new_a = a * h^(-1) (in log space: log(new_a) = log(a) - log(h))
This makes W * new_a = W * (a / h) which... doesn't simplify nicely.

Alternative: new_a = W * a = h (the power iteration step)
But this might not preserve non-negativity (though h is always non-negative since a and w are non-negative).

Actually, h = corr_pair(a, w) IS non-negative (it's a sum of products of non-negative numbers). So the power iteration step a ← h (normalized) is valid!

The fixed point of a ← normalize(W*a) is the top eigenvector of W, which is exactly what we want (h[i] = const means W*a = const, i.e., a is an eigenvector of W with eigenvalue = const).

So the algorithm is:
1. Compute d = n*conv(a,a)/S^2
2. Choose w (active set weights)
3. h = corr_pair(a, w) = W*a
4. a_new = normalize(max(h, eps))
5. Blend: a = (1-t)*a + t*a_new (or in log space)
6. Repeat

This is cleaner than what the previous code was doing! Let me implement this.

The key question is: what temperature/blend to use, and how to choose w.

For w, I'll use a combination of:
- Softmax: w ∝ exp(beta * (d - max(d))) for some beta (like the LSE weight)
- Or: w ∝ max(0, d - threshold)^power (excess-based)
- Or: top-k (hard)

I'll try several and use the one that gives the best improvement.

```python
"""
Search for non-negative sequence minimizing 2*n*max(conv(a,a))/sum(a)^2.
Uses: (1) LSE L-BFGS-B optimization, (2) power iteration with adaptive 
active set, (3) coordinate descent, (4) multi-length exploration.
Key insight: at optimum, corr_pair(a, w_active) should be constant on the
support of a, so the optimal a is (approximately) the top eigenvector of
the matrix defined by the active set weights.
"""

import numpy as np
import time
from scipy.optimize import minimize


def next_power_of_two(m):
    m = int(max(1, m))
    return 1 << (m - 1).bit_length()


def fast_self_conv(a):
    a = np.asarray(a, dtype=np.float64)
    n = int(a.size)
    if n == 0:
        return np.empty(0, dtype=np.float64)
    M = 2 * n - 1
    N = next_power_of_two(M)
    A = np.fft.rfft(a, N)
    out = np.fft.irfft(A * A, N)[:M]
    return np.maximum(out, 0.0)


def corr_pair(a, w):
    a = np.asarray(a, dtype=np.float64)
    w = np.asarray(w, dtype=np.float64)
    n = int(a.size)
    m = int(w.size)
    if n == 0 or m == 0:
        return np.empty(n, dtype=np.float64)
    M = n + m - 1
    N = next_power_of_two(M)
    A = np.fft.rfft(a[::-1], N)
    W = np.fft.rfft(w, N)
    full = np.fft.irfft(A * W, N)[:M]
    return full[n - 1:2 * n - 1]


def normalize_a(a, target=1.0):
    a = np.asarray(a, dtype=np.float64).ravel()
    if a.size == 0:
        return np.array([], dtype=np.float64)
    a = np.nan_to_num(a, nan=0.0, posinf=1e6, neginf=0.0)
    a = np.clip(a, 0.0, None)
    S = float(a.sum())
    if S < 1e-12:
        return np.full(a.size, float(target) / float(a.size), dtype=np.float64)
    return a * (float(target) / S)


def exact_score_a(a):
    n = len(a)
    S = float(np.sum(a))
    if S < 1e-12:
        return np.inf
    c = fast_self_conv(a)
    cmax = float(np.max(c))
    if cmax < 0.0:
        cmax = 0.0
    return float(2.0 * n * cmax / (S * S))


def resample_sequence(a, n):
    a = np.nan_to_num(np.asarray(a, dtype=np.float64).ravel(), nan=0.0, posinf=0.0, neginf=0.0)
    m = int(a.size)
    if m == 0:
        return np.ones(int(n), dtype=np.float64) / float(max(1, n))
    if m == int(n):
        return a.copy()
    x_old = np.linspace(0.0, 1.0, m)
    x_new = np.linspace(0.0, 1.0, int(n))
    return np.interp(x_new, x_old, a).astype(np.float64)


def d_from_a(a):
    n = len(a)
    S = float(np.sum(a))
    if S < 1e-12:
        return np.zeros(2 * n - 1, dtype=np.float64), S
    c = fast_self_conv(a)
    d = (float(n) * c) / (S * S)
    d = np.maximum(d, 0.0)
    return d, S


def lse_score_grad(a, beta):
    a = np.asarray(a, dtype=np.float64)
    n = int(a.size)
    S = float(a.sum())
    if S < 1e-8:
        return 1e10, np.zeros(n, dtype=np.float64)
    beta = float(beta)
    if not np.isfinite(beta) or beta <= 1e-6:
        beta = 100.0
    d, S = d_from_a(a)
    dmax = float(np.max(d))
    if not np.isfinite(dmax) or dmax <= 0.0:
        return 1e10, np.zeros(n, dtype=np.float64)
    z = beta * (d - dmax)
    z = np.clip(z, -50.0, 50.0)
    e = np.exp(z)
    sum_e = float(e.sum())
    if sum_e <= 0.0 or not np.isfinite(sum_e):
        e = np.exp(z - z.max())
        sum_e = float(e.sum())
        if sum_e <= 0.0:
            return 1e10, np.zeros(n, dtype=np.float64)
    w = e / sum_e
    L = dmax + np.log(sum_e) / beta
    LDS = float(np.dot(w, d))
    h = corr_pair(a, w)
    score = 2.0 * L + 1e-3 * (S - 1.0) ** 2
    grad = (4.0 * float(n) * h) / (S * S)
    grad -= (4.0 * LDS) / S
    grad += 2.0 * 1e-3 * (S - 1.0)
    grad = np.nan_to_num(grad, nan=0.0, posinf=0.0, neginf=0.0)
    grad = np.clip(grad, -1e6, 1e6)
    return float(score), grad


def fun_lse(a, beta):
    return lse_score_grad(a, float(beta))


def run_lbfgs(a0, beta, deadline, maxfun):
    a = normalize_a(a0)
    n = len(a)
    if deadline is not None:
        rem = float(deadline - time.monotonic())
        if rem < 5.0:
            return exact_score_a(a), a
    maxfun = max(64, int(maxfun))
    maxiter = max(50, maxfun // 2)
    bounds = [(0.0, 10.0)] * n
    opts = {
        "ftol": 1e-14,
        "gtol": 1e-11,
        "maxiter": int(maxiter),
        "maxfun": int(maxfun),
        "maxls": 50,
    }
    try:
        res = minimize(
            fun_lse, a, method="L-BFGS-B", jac=True,
            args=(float(beta),), bounds=bounds, options=opts
        )
    except Exception:
        return exact_score_a(a), a
    if getattr(res, "x", None) is not None:
        a_out = normalize_a(res.x)
    else:
        a_out = a
    sc = exact_score_a(a_out)
    if not np.isfinite(sc) or sc > 1e8:
        a_out = a
        sc = exact_score_a(a)
    return float(sc), a_out
```
