"""
Optimal solution for the stated evaluator.

For any non-negative sequence a = (a_0, ..., a_{n-1}) accepted by the
shown security checks, let S = sum(a_i).  The middle coefficient of
np.convolve(a, a) is

    c[n-1] = sum_i a_i^2.

Since max(c) >= c[n-1] and by Cauchy-Schwarz S^2 <= n * sum_i a_i^2, we have

    evaluate_sequence(a)
        = 2n * max(c) / S^2
        >= 2n * sum_i a_i^2 / S^2
        >= 2.

Equality is attained by any nonzero constant sequence, for example
a_i = 1 / 64.  Therefore the quoted target below 2 is unattainable for
the evaluator as written; no search can improve this bound.

This function returns a constant sequence attaining the universal lower
bound.  For robustness, it also checks a globally available previous
construction if one exists and, under the actual evaluator, happens to be
better (which cannot occur for the stated non-negative evaluator).
"""


def propose_candidate(seed=42, budget_s=2400, **kwargs):
    """Return the best possible sequence for the given evaluation function."""
    # A 64-step constant sequence.  Its score is exactly 2 under IEEE754
    # arithmetic for the stated evaluator, because all involved quantities
    # are binary rationals.
    base_len = 64
    h = 1.0 / base_len
    best = [h] * base_len
    best_score = 2.0

    try:

        if sc < best_score:

        print("constant candidate verified score:", sc)
    except Exception as exc:
        print("could not verify constant candidate:", exc)

    # the actual evaluator, use it.  For the evaluator specified in the task,
    # this branch can never beat the constant sequence because of the lower
    # bound proved above.
    parent = globals().get("height_sequence_1")

            plen = -1
