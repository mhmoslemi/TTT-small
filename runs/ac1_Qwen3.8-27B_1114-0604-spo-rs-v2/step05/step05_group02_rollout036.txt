```python
def multiplicative_updates(a, n_iters=5000, beta_start=100, beta_end=5000, eta_start=0.5, eta_end=0.01):
    n = len(a)
    N = 1 << (3*n-2-1).bit_length()  # FFT length
    a = np.maximum(a.astype(np.float64), 0).copy()
    S = a.sum()
    if S < 1e-12:
        return np.ones(n)/n
    a = a / S  # normalize to sum=1
    
    best_a = a.copy()
    best_score = compute_score(a)
    
    a_rev = np.zeros(N)
    
    for it in range(n_iters):
        progress = it / n_iters
        beta = beta_start + (beta_end - beta_start) * progress
        eta = eta_start + (eta_end - eta_start) * progress
        
        # Compute convolution
        c = fast_conv(a)  # length 2n-1
        
        # Compute LSE
        c_max = c.max()
        scaled = beta * (c - c_max)
        exp_scaled = np.exp(scaled)
        w = exp_scaled / exp_scaled.sum()
        L = c_max + np.log(exp_scaled.sum()) / beta
        
        # Compute score
        S = a.sum()
        score = 2*n*L/(S*S)
        if score < best_score:
            best_score = score
            best_a = a.copy()
        
        # Compute gradient
        a_rev = a[::-1]
        W = np.fft.rfft(w, N)
        AR = np.fft.rfft(a_rev, N)
        conv_grad = np.fft.irfft(W * AR, N)
        g = 2.0 * conv_grad[n-1:2*n-1]
        
        # Full gradient of score
        S2 = S*S
        S3 = S2*S
        grad = (2.0*n) * (g/S2 - 2.0*L/S3)
        
        # Multiplicative update
        # a_i *= exp(-eta * grad_i / max(|grad|))
        grad_max = np.max(np.abs(grad))
        if grad_max < 1e-15:
            break
        a = a * np.exp(-eta * grad / grad_max)
        a = np.maximum(a, 0)
        S = a.sum()
        if S < 1e-12:
            break
        a = a / S
    
    return best_a
```

Wait, I realize there's an issue with the multiplicative update and the gradient. The gradient includes the 1/S² and 1/S³ terms, which are the same for all i. In the multiplicative update, these constant terms just multiply all a_i by the same factor, which is then undone by normalization. So we can simplify:

The "effective" gradient for the multiplicative update (up to a constant shift that doesn't matter after normalization) is just g_i.

So the update becomes: a_i *= exp(-eta * g_i / max(g))

This is simpler and equivalent (after normalization).

Actually wait, that's not quite right. The multiplicative update a_i *= exp(-eta * h_i) followed by normalization is equivalent to:
a_i_new = a_i * exp(-eta * h_i) / sum_j a_j * exp(-eta * h_j)

If h_i = g_i + c (constant shift), then:
a_i * exp(-eta*(g_i+c)) / sum_j a_j * exp(-eta*(g_j+c))
= a_i * exp(-eta*g_i) * exp(-eta*c) / (sum_j a_j * exp(-eta*g_j) * exp(-eta*c))
= a_i * exp(-eta*g_i) / sum_j a_j * exp(-eta*g_j)

So the constant cancels! Great, so we can use just g for the multiplicative update.

But we should be careful: g_i can be large, so we should normalize: a_i *= exp(-eta * (g_i - g_mean) / g_range) or just a_i *= exp(-eta * g_i / g_max).
