One more idea: **spectrum targeting**. Instead of the standard Fienup (compress top of spectrum), we can target a specific spectral shape that minimizes the peak autocorrelation. 

For a given power spectrum P(f), the autocorrelation is the inverse FFT of P. To minimize the peak of the autocorrelation, we want P to be as "flat" as possible (Wiener-Khinchin). But due to the non-negativity constraint on a, we can't make P exactly flat.

A compromise: make P close to flat but with a small "DC offset" that helps with non-negativity. The idea is:
- Target: P_target(f) = 1 + epsilon * cos(2πf) (or some other low-frequency component)
- This biases the time-domain signal towards positive values

Actually, for a non-negative signal, the DC component (f=0) must be large enough. Specifically, a[0]+...+a[n-1] = P(0)^(1/2) (roughly). If we want the signal to be non-negative, we need the AC components to not be too large relative to DC.

So a good spectral target might be: P_target(f) = A + B * exp(-f^2/σ^2) where A is the DC level and B*exp(-f^2/σ^2) adds a low-frequency bump that ensures non-negativity.

```python
def subgradient_topk(a, n_iters=1000, top_k=10, step_init=0.02):
    """Subgradient descent on the exact (non-smooth) objective."""
    n = len(a)
    a = np.maximum(a.astype(np.float64), 0.0).copy()
    S = float(a.sum())
    if S < 1e-12:
        return np.ones(n) / n
    a = a / S

    step = step_init
    decay = 0.9995
    
    for it in range(n_iters):
        c = fast_conv(a)
        S = float(a.sum())
        if S < 1e-12:
            break
        M_val = float(c.max())
        sc = 2.0 * n * M_val / (S * S)
        
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()
        
        # Get top-k peaks
        if top_k >= len(c):
            top_idx = np.arange(len(c))
        else:
            top_idx = np.argsort(c)[::-1][:top_k]
        
        # Subgradient: average over top-k peaks
        sg = np.zeros(2 * n - 1)  # working in c-space, but we need gradient in a-space
        # Actually, let's compute the subgradient directly in a-space
        grad = np.zeros(n)
        for k in top_idx:
            k = int(k)
            # dc[k]/da[j] = 2*a[k-j] for 0 <= k-j < n
            j_start = max(0, k - n + 1)
            j_end = min(k, n - 1)
            if j_end >= j_start:
                # For j in [j_start, j_end], k-j is in [0, n-1]
                # dc[k]/da[j] = 2*a[k-j]
                # k-j ranges from k-j_start to k-j_end
                indices = k - np.arange(j_start, j_end + 1)
                grad[j_start:j_end+1] += 2.0 * a[indices]
        
        # Normalize by number of active peaks
        grad /= len(top_idx)
        
        # Full gradient of f = 2n*max/S^2: (2n/S^2)*grad_c - (2n*max/S^3)*2
        S2 = S * S
        S3 = S2 * S
        full_grad = (2.0 * n / S2) * grad - (4.0 * n * M_val / S3) * np.ones(n)
        
        gn = float(np.linalg.norm(full_grad))
        if gn < 1e-15:
            break
        
        # Adaptive step size
        sc_lb = 2.0 * n / (2.0 * n - 1.0)
        step = min(step, max((sc - sc_lb) / (gn * gn + 1e-30), 1e-12))
        step = min(step, 0.03)
        
        a -= step * full_grad
        a = np.clip(a, 0.0, 1000.0)
        S = a.sum()
        if S < 1e-12:
            break
        a = a / S
        step *= decay
    
    return best_a
```

```python
def topk_obj_grad(x, k):
    """Sum of top-k autocorrelation values, normalized."""
    n = len(x)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(x, M_fft)
    c = np.fft.irfft(A * A, M_fft)[:M]
    S = float(x.sum())
    if S < 1e-12:
        return 1e10, np.zeros(n)
    
    # Get top-k indices
    k = min(k, M)
    top_idx = np.argpartition(c, -k)[-k:]
    top_val = float(c[top_idx].sum())
    sc = 2.0 * n * top_val / (k * S * S)
    
    # Gradient: sum of gradients of top-k c values
    grad = np.zeros(n)
    for ki in top_idx:
        ki = int(ki)
        j_start = max(0, ki - n + 1)
        j_end = min(ki, n - 1)
        if j_end >= j_start:
            indices = ki - np.arange(j_start, j_end + 1)
            grad[j_start:j_end+1] += 2.0 * x[indices]
    
    # Gradient of full objective
    S2 = S * S
    S3 = S2 * S
    full_grad = (2.0 * n / (k * S2)) * grad - (2.0 * n * top_val / (k * S3)) * 2.0 * np.ones(n)
    
    return sc, full_grad
```
