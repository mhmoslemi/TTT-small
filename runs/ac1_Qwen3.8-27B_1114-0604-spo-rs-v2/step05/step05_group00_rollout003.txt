For example, a = [1, 0, 0, ..., 0, 1] (1 at both ends, 0 elsewhere), n large.
S = 2, S^2 = 4.
conv[n-1] = a[0]*a[n-1] + a[n-1]*a[0] = 2 (wait, no)
conv[n-1] = sum_j a[j]*a[n-1-j] = a[0]*a[n-1] + a[n-1]*a[0] = 1*1 + 1*1 = 2.
S^2/n = 4/n. For n > 4, S^2/n < 1 < 2 = conv[n-1]. So conv[n-1] > S^2/n here.

But what about a = [1, 1, 0, 0, ..., 0] (1 at positions 0 and 1)?
S = 2, S^2 = 4.
conv[n-1] = sum_j a[j]*a[n-1-j] = a[0]*a[n-1] + a[1]*a[n-2] = 0 + 0 = 0 (for n > 2).
S^2/n = 4/n. For n=4: S^2/n = 1. conv[3] = a[0]*a[3] + a[1]*a[2] + a[2]*a[1] + a[3]*a[0] = 0.
So conv[n-1] = 0 < S^2/n = 1!

So my "proof" was WRONG. conv[n-1] can be less than S^2/n.
