  - If k < n: `k - (k-n+1) <= 0`... let me just say it's valid if `0 <= k-j < n` AND `0 <= j < n`.

Actually, I think the issue is that when `i = j` AND `k-i = j` (i.e., `k = 2j`), the two terms are the same and we get `2*a[j]`. But in general, they're different terms.

Let me verify with a small example. `a = [a0, a1, a2]`, n=3.
`c[0] = a0*a0` → `dc[0]/da0 = 2*a0` ✓
`c[1] = a0*a1 + a1*a0 = 2*a0*a1` → `dc[1]/da0 = 2*a1`, `dc[1]/da1 = 2*a0` ✓
`c[2] = a0*a2 + a1*a1 + a2*a0 = 2*a0*a2 + a1^2` → `dc[2]/da0 = 2*a2`, `dc[2]/da1 = 2*a1`, `dc[2]/da2 = 2*a0` ✓

So indeed `dc[k]/da[j] = 2*a[k-j]` when `0 <= k-j < n` (i.e., k-j is a valid index), AND `0 <= j < n` (j is valid). Wait, but for c[1] with a=[a0,a1,a2]: `c[1] = a0*a1 + a1*a0 = 2*a0*a1`. `dc[1]/da0 = 2*a1`. And `2*a[k-j] = 2*a[1-0] = 2*a1` ✓.

But wait, what about `c[1]/da2`? `c[1] = a0*a1 + a1*a0`, no a2 appears. And `2*a[k-j] = 2*a[1-2] = 2*a[-1]` which is not valid. So the rule is: `dc[k]/da[j] = 2*a[k-j]` if `0 <= k-j < n`, else 0.

Wait, but that's not right either. Let me check `c[4]` for n=3: `c[4] = a2*a2`. `dc[4]/da2 = 2*a2`. And `2*a[4-2] = 2*a2` ✓.

What about `c[3]`? `c[3] = a1*a2 + a2*a1 = 2*a1*a2`. `dc[3]/da1 = 2*a2 = 2*a[3-1]` ✓. `dc[3]/da2 = 2*a1 = 2*a[3-2]` ✓.

Great, so the formula is: `dc[k]/da[j] = 2*a[k-j]` if `0 <= k-j <= n-1` and `0 <= j <= n-1`, else 0.

This is very clean! It means the gradient of `c[k]` with respect to `a` is `2 * a[k-::-1]` (padded with zeros) or more precisely, the vector `g[k]` where `g[k][j] = 2*a[k-j]` if `max(0,k-n+1) <= j <= min(k,n-1)`.

This can be computed very efficiently using the FFT! The gradient of `c[k]` with respect to `a` is essentially `2 * cross_correlation(a, e_k)` where `e_k` is the unit vector at position k.

Even better: for the LSE gradient, we need `sum_k p_k * 2*a[k-j]` for each j, which is `2 * convolve(a, p)[j]` (or some variant depending on indexing).

OK so the gradient computation is straightforward. Let me now focus on the optimization strategy.

   - Take a projected gradient step with backtracking line search
   - The step direction is `-g` (negative gradient of the max)

   - This directly attacks the peaks without any smoothing approximation

"""
Hybrid peak-chasing + spectral shaping optimizer for minimum autocorrelation sequences.
"""

import numpy as np
from scipy.optimize import minimize
import time

# --- Core computation functions ---

def fast_conv(a):
    """Linear self-convolution via FFT."""
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]

def compute_score(a):
    """Compute 2n * max(conv) / (sum)^2."""
    n = len(a)
    S = a.sum()
    if S < 1e-12:
        return np.inf
    c = fast_conv(a)
    return 2.0 * n * c.max() / (S * S)

def lse_obj_and_grad(a, beta):
    """LSE-smoothed objective and gradient for max(conv(a,a))."""
    n = len(a)
    c = fast_conv(a)
    S = a.sum()
    if S < 1e-12:
        return 1e10, np.zeros(n)
    c_max = c.max()
    shifted = beta * (c - c_max)
    exp_s = np.exp(shifted)
    log_sum = np.log(exp_s.sum())
    L = c_max + log_sum / beta
    p = exp_s / exp_s.sum()
    
    # Gradient: dL/da_j = 2 * sum_k p[k] * a[k-j] (valid k-j)
    # = 2 * (a * p_flipped)[something]
    # Using FFT: the gradient is 2 * ifft(fft(a) * fft(p_flipped)) at appropriate indices
    # Actually, it's related to the cross-correlation of a and p
    
    # More carefully: dL/da_j = 2 * sum_{k: 0<=k-j<n} p[k] * a[k-j]
    # Let m = k-j, then k = j+m, and we need 0 <= j+m < 2n-1 and 0 <= m < n
    # = 2 * sum_{m=0}^{n-1} a[m] * p[j+m]
    # This is the cross-correlation of a and p at lag j
    
    # Using FFT: cross_corr(a, p)[j] = sum_m a[m] * p[m+j]
    # = ifft(fft(a) * conj(fft(p))) ... not quite, let me use a different approach
    # 
    # sum_m a[m] * p[m+j] = (a * p_rev)[j + (len(p)-1)] ... 
    # Actually, let me just use the direct FFT approach:
    # DFT interpretation: if we define the "cross-correlation" as sum_m a[m] * p[m+j],
    # this is ifft(conj(fft(a)) * fft(p))[n-1-j] or something similar.
    # 
    # Let me just use the approach from the previous code:
    # d[i] = 2 * conv_res[2n-2-i] where conv_res = ifft(fft(a_pad) * fft(p_rev_pad))
    
    conv_len = 3 * n - 2  # Actually 2*(2n-1)-1 = 4n-3? No...
    # a has length n, p has length 2n-1
    # convolve(a, p) has length n + (2n-1) - 1 = 3n-1
    # But we only need the part where both are valid for the correlation
    # Let me just use a simpler approach:
    
    # d_j = 2 * sum_{m=0}^{n-1} a[m] * p[j+m]
    # This is the "non-circular cross-correlation" of a and p
    # = ifft(fft(a, M) * conj(fft(p, M)))[n-1-j] ... 
    # Hmm, let me just use the previous code's approach which I know works:
    
    M_fft = 1 << (3 * n - 1).bit_length()
    A_pad = np.zeros(M_fft)
    A_pad[:n] = a
    p_rev = np.zeros(M_fft)
    p_rev[:2*n-1] = p[::-1]
    conv_res = np.fft.irfft(np.fft.rfft(A_pad) * np.fft.rfft(p_rev))[:3*n-1]
    # d[j] = 2 * conv_res[2n-2-j] for j=0..n-1
    grad_L = 2.0 * conv_res[n-1:2*n-1][::-1]
    
    # Full score gradient: score = 2n*L/S^2
    # d(score)/da = 2n * (grad_L/S^2 - 2*L*1/(S^3) * 1)  [since dS/da_j = 1]
    S2 = S * S
    S3 = S2 * S
    score = 2.0 * n * L / S2
    grad = (2.0 * n) * (grad_L / S2 - 2.0 * L * np.ones(n) / S3)
    return score, grad

def peak_chase_subgradient(a, n_iters, top_k=5, lr_init=0.1, lr_decay=0.999, 
                            backtrack_factor=0.5, min_lr=1e-6):
    """
    Subgradient method targeting the top peaks directly.
    Uses backtracking line search for guaranteed descent.
    """
    n = len(a)
    a = np.maximum(a.astype(np.float64), 0.0).copy()
    S = a.sum()
    a = a / S
    
    best_a = a.copy()
    best_sc = compute_score(a)
    lr = lr_init
    
    for it in range(n_iters):
        c = fast_conv(a)
        S = a.sum()
        current_sc = 2.0 * n * c.max() / (S * S)
        
        if current_sc < best_sc:
            best_sc = current_sc
            best_a = a.copy()
        
        # Find top peaks
        peak_indices = np.argsort(c)[::-1][:top_k]
        peak_values = c[peak_indices]
        peak_mean = c.mean()
        
        # Weights: proportional to excess over mean
        excess = np.maximum(peak_values - peak_mean, 0)
        if excess.sum() < 1e-15:
            break
        weights = excess / excess.sum()
        
        # Compute weighted subgradient
        # d(c[k])/da[j] = 2*a[k-j] if 0 <= k-j < n
        grad = np.zeros(n)
        for idx, k in enumerate(peak_indices):
            k = int(k)
            j_start = max(0, k - n + 1)
            j_end = min(k, n - 1)
            if j_end >= j_start:
                grad[j_start:j_end+1] += 2.0 * weights[idx] * a[k - np.arange(j_start, j_end+1)]
        
        # Also subtract the "normalization gradient" (to maintain sum=1)
        # The normalization gradient is 2n*L/S^3 * ones, but since we're 
        # targeting the max directly, let's just normalize after the step
        
        # Try step with backtracking
        found = False
        for _ in range(10):
            a_new = a - lr * grad
            a_new = np.maximum(a_new, 0.0)
            S_new = a_new.sum()
            if S_new < 1e-12:
                lr *= backtrack_factor
                continue
            a_new = a_new / S_new
            new_sc = compute_score(a_new)
            if new_sc < current_sc:
                a = a_new
                found = True
                break
            lr *= backtrack_factor
        
        if not found:
            lr *= backtrack_factor
            if lr < min_lr:
                break
        
    return best_a

def fienup_adaptive(a, n_iters=500, mode='auto'):
    """
    Fienup with adaptive peak compression.
    Instead of a fixed threshold, adapts based on the peak structure.
    """
    n = len(a)
    a = np.maximum(a.astype(np.float64), 0.0).copy()
    S = a.sum()
    a = a / S
    
    M_fft = 1 << (2 * n - 1).bit_length()
    best_a = a.copy()
    best_sc = compute_score(a)
    
    for it in range(n_iters):
        t = it / max(1, n_iters - 1)
        
        A = np.fft.rfft(a, M_fft)
        P = A.real**2 + A.imag**2
        P_mean = P.mean()
        
        # Adaptive threshold: start high, end low
        thresh = 3.0 - 1.8 * t  # from 3.0 to 1.2
        clip_power = 0.3 + 0.5 * t  # from 0.3 to 0.8
        
        above = P > P_mean * thresh
        if above.any():
            scale = np.ones(len(P))
            # Compress: scale = (target/current)^clip_power
            target = P_mean * thresh
            scale[above] = (target / P[above]) ** clip_power
            scale[above] = np.maximum(scale[above], 0.1)
        
        A_new = A * scale.astype(complex)
        a_new = np.fft.irfft(A_new, M_fft)[:n]
        a_new = np.maximum(a_new, 0.0)
        S_new = a_new.sum()
        if S_new < 1e-12:
            break
        a_new = a_new / S_new
        
        sc = compute_score(a_new)
        if sc < best_sc:
            best_sc = sc
            best_a = a_new.copy()
        
        # Also try a softer version
        if it % 3 == 0:
            scale2 = np.ones(len(P))
            above2 = P > P_mean * max(thresh * 1.2, 1.1)
            if above2.any():
                scale2[above2] = (P_mean * max(thresh * 1.2, 1.1) / P[above2]) ** 0.3
                scale2[above2] = np.maximum(scale2[above2], 0.3)
            A_new2 = A * scale2.astype(complex)
            a_new2 = np.fft.irfft(A_new2, M_fft)[:n]
            a_new2 = np.maximum(a_new2, 0.0)
            S_new2 = a_new2.sum()
            if S_new2 > 1e-12:
                a_new2 = a_new2 / S_new2
                sc2 = compute_score(a_new2)
                if sc2 < best_sc:
                    best_sc = sc2
                    best_a = a_new2.copy()
                    a = a_new2  # continue from the better one
    
    return best_a

def nesterov_sharp_lse(a, max_time, beta_start=500.0, beta_end=50000.0,
                        lr_init=0.01, lr_decay=0.9995, mu=0.92):
    """Nesterov with very sharp LSE for final polishing."""
    n = len(a)
    a = np.maximum(a.astype(np.float64), 0.0).copy()
    S = a.sum()
    a = a / S
    
    best_a = a.copy()
    best_sc = compute_score(a)
    v = np.zeros(n)
    t_start = time.monotonic()
    beta = beta_start
    lr = lr_init
    it = 0
    
    while time.monotonic() - t_start < max_time:
        it += 1
        lr *= lr_decay
        beta = min(beta * 1.02, beta_end)
        
        # Nesterov lookahead
        a_look = a + mu * v
        a_look = np.maximum(a_look, 0.0)
        S_look = a_look.sum()
        if S_look < 1e-12:
            break
        a_look = a_look / S_look
        
        _, grad = lse_obj_and_grad(a_look, beta)
        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-15:
            break
        
        v = mu * v - lr * grad
        a = a + v
        a = np.maximum(a, 0.0)
        S = a.sum()
        if S < 1e-12:
            break
        a = a / S
        
        if it % 100 == 0:
            sc = compute_score(a)
            if sc < best_sc:
                best_sc = sc
                best_a = a.copy()
    
    sc = compute_score(a)
    if sc < best_sc:
        best_sc = sc
        best_a = a.copy()
    
    return best_a

def run_lbfgs_sharp(a0, beta, maxiter=5000, maxfun=50000):
    """L-BFGS-B with sharp LSE."""
    n = len(a0)
    a0 = np.clip(a0.astype(np.float64), 0.0, 1000.0).copy()
    S = a0.sum()
    if S < 1e-6:
        a0[:] = 0.5
    a0 = a0 / S
    bounds = [(0.0, 1000.0)] * n
    
    def objective(x):
        return lse_obj_and_grad(x, beta)
    
    res = minimize(objective, a0, method='L-BFGS-B', jac=True, bounds=bounds,
                   options={'ftol': 1e-20, 'gtol': 1e-12,
                            'maxiter': maxiter, 'maxfun': maxfun, 'maxls': 50})
    a_out = np.clip(res.x, 0.0, 1000.0)
    S_out = a_out.sum()
    if S_out < 1e-6:
        a_out = a0.copy()
    return compute_score(a_out), a_out

def targeted_coord_descent(a, n_sweeps=10, n_top_peaks=10, n_top_contrib=15):
    """Coordinate descent targeting top peak contributors."""
    n = len(a)
    a = np.maximum(a.astype(np.float64), 0.0).copy()
    S = a.sum()
    a = a / S
    best_a = a.copy()
    best_sc = compute_score(a)
    
    for sweep in range(n_sweeps):
        c = fast_conv(a)
        peak_indices = np.argsort(c)[::-1][:n_top_peaks]
        
        for k in peak_indices:
            k = int(k)
            j_start = max(0, k - n + 1)
            j_end = min(k, n - 1)
            if j_end < j_start:
                continue
            
            # Contributions: a[k-j] for j in [j_start, j_end]
            contrib = a[k - np.arange(j_start, j_end + 1)]
            top_local = np.argsort(contrib)[::-1][:n_top_contrib]
            
            for jl in top_local:
                j = int(j_start + jl)
                old_val = a[j]
                if old_val < 1e-10:
                    continue
                
                # Try reducing this element
                for factor in [0.7, 0.8, 0.9, 1.1, 1.15]:
                    a[j] = old_val * factor
                    S_tmp = a.sum()
                    if S_tmp < 1e-12:
                        a[j] = old_val
                        continue
                    a_sc = a / S_tmp
                    sc = compute_score(a_sc)
                    if sc < best_sc:
                        best_sc = sc
                        best_a = a_sc.copy()
                        a = a_sc
                        break
                else:
                    a[j] = old_val
    
    return best_a

def log_space_gradient_descent(a, max_time, lr_init=0.05, lr_decay=0.999, 
                                top_k=3, momentum=0.9):
    """
    Gradient descent in log space (multiplicative updates).
    a_i = exp(theta_i), optimal theta found by gradient descent.
    Handles zero elements by using softplus.
    """
    n = len(a)
    a = np.maximum(a.astype(np.float64), 1e-10).copy()
    S = a.sum()
    a = a / S
    
    # Convert to log space
    theta = np.log(a)
    
    best_a = a.copy()
    best_sc = compute_score(a)
    v = np.zeros(n)  # velocity in theta space
    lr = lr_init
    t_start = time.monotonic()
    it = 0
    
    while time.monotonic() - t_start < max_time:
        it += 1
        lr *= lr_decay
        
        a_current = np.exp(theta)
        a_current = a_current / a_current.sum()
        
        # Compute LSE gradient in a-space
        _, grad_a = lse_obj_and_grad(a_current, 200.0)
        
        # Convert to theta-space: d(score)/dtheta_j = a_j * d(score)/da_j 
        # (since da_j/dtheta_j = a_j)
        # But we also need to account for the normalization...
        # For softmax: da_i/dtheta_j = a_i(delta_ij - a_j)
        # For simple exp: da_i/dtheta_j = a_i * delta_ij
        # Let's use simple exp (no normalization in the gradient, handle it separately)
        grad_theta = a_current * grad_a
        
        # Nesterov momentum
        v = momentum * v - lr * grad_theta
        theta = theta + v
        
        # Clamp theta to avoid overflow
        theta = np.clip(theta, -50, 50)
        
        a_new = np.exp(theta)
        S_new = a_new.sum()
        if S_new < 1e-12:
            break
        a_new = a_new / S_new
        
        sc = compute_score(a_new)
        if sc < best_sc:
            best_sc = sc
            best_a = a_new.copy()
        else:
            # Undo if worse (simple rejection)
            theta = theta - v * (1 + momentum)
            v = v * momentum
    
    return best_a

def build_good_init(n, rng):
    """Build a good initialization."""
    # Symmetric raised cosine
    x = np.linspace(0, 1, n)
    a = 0.5 + 0.5 * np.cos(2 * np.pi * x)
    a = np.maximum(a, 0.01)
    return a / a.sum()

def upsample(a, new_n):
    """Upsample sequence."""
    old_n = len(a)
    if old_n == new_n:
        return a.copy()
    x_old = np.linspace(0, 1, old_n)
    x_new = np.linspace(0, 1, new_n)
    return np.interp(x_new, x_old, a)

import numpy as np

def fast_conv(a):
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]


def compute_score(a):
    n = len(a)
    S = float(a.sum())
    if S < 1e-12:
        return np.inf
    c = fast_conv(a)
    return 2.0 * n * float(np.max(c)) / (S * S)


def lse_obj_and_grad(a, beta):
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return 1e10, np.zeros(n)
    c_max = float(np.max(c))
    shifted = beta * (c - c_max)
    exp_s = np.exp(shifted)
    log_sum = float(np.log(np.sum(exp_s)))
    L = c_max + log_sum / beta
    p = exp_s / np.sum(exp_s)
    conv_len = 3 * n - 1
    M_fft = 1 << (conv_len - 1).bit_length()
    A_pad = np.zeros(M_fft)
    A_pad[:n] = a
    p_rev = np.zeros(M_fft)
    p_rev[:2 * n - 1] = p[::-1]
    Af = np.fft.rfft(A_pad)
    Pf = np.fft.rfft(p_rev)
    conv_res = np.fft.irfft(Af * Pf)[:conv_len]
    grad_L = 2.0 * conv_res[n - 1:2 * n - 1][::-1]
    S2 = S * S
    S3 = S2 * S
    score = 2.0 * n * L / S2
    grad = (2.0 * n) * (grad_L / S2 - 2.0 * L / S3)
