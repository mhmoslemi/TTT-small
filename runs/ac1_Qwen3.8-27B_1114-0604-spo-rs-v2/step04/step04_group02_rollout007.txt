    """Solve: max sum(b) s.t. f*b <= M, b >= 0"""
    from scipy.optimize import linprog
    # c = -ones (minimize negative sum)
    c = -np.ones(n)
    # A_ub * b <= b_ub where A_ub row k is the k-th row of the convolution matrix
    # (f * b)(k) = sum_i f_i * b_{k-i} for valid i
    # For row k: b_j appears with coefficient f_{k-j} if 0 <= k-j < n, i.e., k-n+1 <= j <= k

    # But scipy linprog can handle sparse matrices.

**POCS/SET approach:**

The idea:
1. We have sequence a of length n (non-negative)
2. We want to minimize max of linear self-convolution
3. Pad a to length N >= 2n-1 (use next power of 2)
4. Compute X = FFT(padded_a, N)
5. The linear convolution is IFFT(|X|^2, N)[:2n-1]
6. To reduce the peak, we want to reduce |X|^2 at bins corresponding to the peak
7. But |X|^2 = X * conj(X), so reducing |X|^2 means reducing |X|
8. Set a threshold T. For all bins where |X|^2 > T, scale X to have |X|^2 = T
9. IFFT to get new time-domain signal
10. Keep only the first n samples (the "support" of our sequence)
11. Project onto non-negativity: max(0, real_part)
12. Repeat

This is a form of the "successive projection" algorithm. It should converge to a sequence with bounded peak, though not necessarily the optimal one.

The threshold T should be chosen adaptively: start high and decrease over iterations.

Let me also think about a variant: instead of hard thresholding, use soft thresholding:
For each bin, if |X_k|^2 > T, replace with T * X_k / |X_k| (i.e., scale down to magnitude sqrt(T)).

This is more stable than hard thresholding.

def subgradient_nesterov(a, n_iters=5000, f_lb=1.5, verbose=False):
    """Nesterov-accelerated subgradient on the exact objective."""
    n = len(a)
    a = a.astype(np.float64).copy()
    S = a.sum()
    if S < 1e-12:
        return a
    a = a / S
    
    y = a.copy()
    t = 1.0
    best_a = a.copy()
    best_sc = compute_score(a)
    
    for it in range(n_iters):
        c = fast_conv(y)
        Sy = float(np.sum(y))
        k_star = int(np.argmax(c))
        Mak = float(c[k_star])
        sc = 2.0 * n * Mak / (Sy * Sy)
        if sc < best_sc:
            best_sc = sc
            best_a = y.copy()
        
        # Subgradient
        j_start = max(0, k_star - n + 1)
        j_end = min(k_star, n - 1)
        sg = np.zeros(n)
        if j_end >= j_start:
            idx = np.arange(j_start, j_end + 1)
            sg[idx] = y[k_star - idx]
        
        S2 = Sy * Sy
        S3 = S2 * Sy
        grad = (2.0 * n) * (sg / S2 - 2.0 * Mak / S3)
        
        gnorm = float(np.linalg.norm(grad))
        if gnorm < 1e-15:
            break
        
        step = (sc - f_lb) / (gnorm * gnorm + 1e-30)
        step = min(step, 0.2)
        
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t * t)) / 2.0
        theta = (t - 1.0) / t_new
        t = t_new
        
        y_new = y - step * grad
        a_new = y_new + theta * (y_new - a)
        a = np.clip(a_new, 0.0, 1000.0)
        Sa = a.sum()
        if Sa < 1e-12:
            break
        a = a / Sa
        y = a.copy()
    
    return best_a
