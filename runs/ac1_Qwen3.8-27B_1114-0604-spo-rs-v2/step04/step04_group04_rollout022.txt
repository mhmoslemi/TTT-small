For k=2i: new_conv[2i] = conv[2i] + (t-a_i)*(t+a_i) = (t-a_i)*(t+a_i) + a_i^2 = t^2 ✓

OK so the formula is:
new_conv[k] = conv[k] + delta * 2 * a[k-i] for k in [i, i+n-1], k ≠ 2i (and k-i in [0,n-1])
new_conv[2i] = conv[2i] + delta * (2*a_i + delta) where delta = t - a_i

And new_sum = S - a_i + t = S + delta.

So for coordinate descent, for each i:
1. Compute the "influence" vector: inf[k] = 2*a[k-i] for k in [i, i+n-1], k≠2i; inf[2i] = 2*a_i (will add delta^2 separately)
2. Try values of t (or delta) and compute f(t) = 2n * max_k (conv[k] + delta*inf[k] + delta^2*[k=2i]) / (S+delta)^2
3. Pick the best t

For step 2, I can use golden section search on t in [0, upper_bound].

The upper bound: t can't be too large or the sum gets too large relative to the conv peak. A reasonable upper bound is max(3*a_i, 3*S/n).

For efficiency, computing max_k of the modified conv takes O(n) per evaluation of f(t), and golden section needs ~30 evaluations, so O(30n) per coordinate, O(30n^2) per sweep. For n=8192, that's ~2 billion operations per sweep. Too slow.

Alternative: instead of golden section, just try a few candidate t values:
- t = 0 (set to zero)
- t = a_i * 0.5
- t = a_i * 1.5
- t = a_i + 0.1 * S/n
- t = a_i - 0.1 * S/n

This gives O(5n) per coordinate, O(5n^2) per sweep ≈ 335M for n=8192. About 0.3 seconds per sweep. Doable for ~10 sweeps.

Actually, even simpler: just use the "current" conv and compute the gradient of the (smooth) LSE objective w.r.t. a[i], then take a small step. This is essentially what L-BFGS does, but coordinate-wise.

I think for the coordinate descent, I'll use a simple approach:
- For each i, compute the gradient of the LSE-smoothed objective w.r.t. a[i]
- Take a step of size eta in the negative gradient direction
- Clip to [0, 1000]
- This is O(n) per coordinate (using the precomputed LSE weights), O(n^2) per sweep

Wait, the gradient of LSE w.r.t. a[i] requires the LSE weights p_k, and:
dL/d a[i] = 2 * sum_k p_k * C[k,i] = 2 * sum_k p_k * a[k-i] [valid]

Which is 2 * (p ⋆ a)[i] (cross-correlation at lag i). I can compute this for all i at once using FFT!

So one coordinate descent sweep is:
1. Compute c = self_conv(a) [O(n log n)]
2. Compute p = softmax(beta * (c - c_max)) [O(n)]
3. Compute grad = 2 * (p ⋆ a) [O(n log n) via FFT]
4. For each i: a[i] = max(0, a[i] - eta * grad[i]) [O(n)]

This is O(n log n) per sweep! Very efficient. I can do many sweeps.

But this is just gradient descent on the LSE objective, which is what L-BFGS already does (but more efficiently using curvature information). So coordinate descent won't be better than L-BFGS in general.

However, coordinate descent has the advantage of being able to handle the non-negativity constraint exactly (via projection), while L-BFGS-B handles it approximately.

Let me include it as a polish step after L-BFGS.

"""
Multi-phase optimizer for minimal peak autocorrelation of non-negative sequences.
Combines LP alternating, spectral shaping, LSE-smoothed L-BFGS, and coordinate descent.
"""

import numpy as np
from scipy.optimize import minimize
import time


def self_conv(a):
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]


def cross_conv(a, b):
    M = len(a) + len(b) - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    B = np.fft.rfft(b, M_fft)
    return np.fft.irfft(A * B, M_fft)[:M]


def compute_score(a):
    n = len(a)
    S = float(a.sum())
    if S < 1e-12:
        return np.inf
    c = self_conv(a)
    return 2.0 * n * float(c.max()) / (S * S)


def lse_score_and_grad(a, beta):
    """Compute LSE-smoothed score and full gradient."""
    n = len(a)
    c = self_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return 1e10, np.zeros(n)
    c_max = float(c.max())
    z = beta * (c - c_max)
    z_shift = z - z.max()
    exp_z = np.exp(z_shift)
    exp_sum = float(exp_z.sum())
    p = exp_z / exp_sum
    L_val = c_max + float(np.log(exp_sum)) / beta
    
    # Gradient of LSE w.r.t. a: 2 * cross_correlation(a, p) restricted to valid indices
    # (a ⋆ p)[j] = sum_k a[k] * p[k+j] for j = 0,...,n-1
    M2 = 3 * n - 2
    M2_fft = 1 << (M2 - 1).bit_length()
    A = np.fft.rfft(a, M2_fft)
    P = np.fft.rfft(p, M2_fft)
    cross = np.fft.irfft(np.conj(A) * P, M2_fft)[:n]
    grad_L = 2.0 * cross
    
    S2 = S * S
    S3 = S2 * S
    score = 2.0 * n * L_val / S2
    grad = 2.0 * n * (grad_L / S2 - 2.0 * L_val / S3)
    return score, grad


def spectral_shaping(a, n_iters=100, alpha=0.5):
    """Flatten |FFT(a)|^2 iteratively while maintaining non-negativity."""
    n = len(a)
    a = np.maximum(a.astype(np.float64).copy(), 0.0)
    S = float(a.sum())
    if S < 1e-12:
        return a
    a = a / S
    
    best_a = a.copy()
    best_sc = compute_score(a)
    
    M = 1 << (2 * n - 1).bit_length()
    
    for it in range(n_iters):
        a_pad = np.zeros(M, dtype=np.float64)
        a_pad[:n] = a
        A = np.fft.fft(a_pad)
        
        # Compute |A|^2 and flatten
        mag2 = np.abs(A) ** 2
        mag2_mean = float(mag2.mean())
        mag2_max = float(mag2.max())
        
        if mag2_max - mag2_mean < 1e-15:
            break
        
        # Target: make |A| proportional to (target_mag2)^{1/2}
        # Iterate: A_new = A / |A| * |A_target|
        # |A_target|^2 = mag2_mean (flat)
        # But we want to reduce peaks, not fully flatten (that would make a a delta)
        
        # Use a power law: |A_new| = |A| * (mag2_mean / mag2)^alpha
        # This reduces high |A| and increases low |A|
        with np.errstate(divide='ignore'):
            ratio = mag2_mean / (mag2 + 1e-30)
            factor = np.minimum(ratio, 10.0) ** (alpha * 0.5)
        
        A_new = A * factor
        a_new = np.fft.ifft(A_new).real[:n]
        a_new = np.maximum(a_new, 0.0)
        
        S_new = float(a_new.sum())
        if S_new < 1e-12:
            break
        a_new = a_new / S_new
        
        sc = compute_score(a_new)
        if sc < best_sc:
            best_sc = sc
            best_a = a_new.copy()
        a = a_new
    
    return best_a


def lp_alternating_v2(a, max_outer_iters=100, fista_iters=5000, t_start=0.3, t_min=0.03,
                      time_limit=None, warm_start_x=None):
    """
    LP-based alternating with improved FISTA sub-solver.
    """
    n = len(a)
    a = np.maximum(a.astype(np.float64).copy(), 0.0)
    S = float(a.sum())
    if S < 1e-12:
        a = np.ones(n) / n
    else:
        a = a / S
    
    best_a = a.copy()
    best_sc = compute_score(a)
    no_improve = 0
    x_warm = warm_start_x
    
    for outer in range(max_outer_iters):
        if time_limit is not None and time.monotonic() > time_limit:
            break
        
        M = float(self_conv(a).max())
        
        # Solve LP: max 1^T x s.t. conv(a,x) <= M, x >= 0
        # using FISTA on LSE-smoothed surrogate
        if x_warm is not None and len(x_warm) == n:
            x = x_warm.copy()
        else:
            x = np.ones(n) / n
        
        u = x.copy()
        t_mom = 1.0
        
        sum_a2 = float(np.sum(a * a)) + 1e-15
        beta_lp = 20.0  # fixed beta for LP smoothing
        
        for it in range(fista_iters):
            frac = min(1.0, it / (fista_iters * 0.2))
            beta = 5.0 + (beta_lp - 5.0) * frac
            
            c = cross_conv(a, x)
            z = beta * (c - M)
            z_max = float(z.max())
            exp_z = np.exp(z - z_max)
            exp_sum = float(exp_z.sum())
            if exp_sum < 1e-300:
                p = np.ones(len(c)) / len(c)
            else:
                p = exp_z / exp_sum
            
            # C^T p = cross_correlation(a, p)[:n]
            M2 = 3 * n - 2
            M2_fft = 1 << (M2 - 1).bit_length()
            A_fft = np.fft.rfft(a, M2_fft)
            P_fft = np.fft.rfft(p, M2_fft)
            ct_p = np.fft.irfft(np.conj(A_fft) * P_fft, M2_fft)[:n]
            
            grad = a * 0 + ct_p - 1.0  # gradient of -1^T x + LSE(beta*(Cx-M))
            # Actually: d/dx [LSE(beta*(Cx-M))] = C^T * softmax(beta*(Cx-M))
            # d/dx [-1^T x] = -1
            # Total grad = C^T p - 1
            
            L = beta * n * sum_a2 + 1e-10
            step = 1.0 / L
            
            v = u - step * grad
            x_new = np.maximum(v, 0.0)
            t_new = (1.0 + np.sqrt(1.0 + 4.0 * t_mom**2)) / 2.0
            u = x_new + (t_mom - 1.0) / t_new * (x_new - x)
            u = np.maximum(u, 0.0)
            x = x_new
            t_mom = t_new
        
        Sx = float(x.sum())
        if Sx < 1e-12:
            break
        x = x / Sx
        
        # Adaptive mixing
        t_mix = max(t_min, t_start * (1.0 - 0.5 * outer / max(1, max_outer_iters)))
        
        a_new = (1.0 - t_mix) * a + t_mix * x
        a_new = np.maximum(a_new, 0.0)
        S_new = float(a_new.sum())
        if S_new < 1e-12:
            break
        a_new = a_new / S_new
        
        sc = compute_score(a_new)
        if sc < best_sc:
            best_sc = sc
            best_a = a_new.copy()
            no_improve = 0
        else:
            no_improve += 1
            if no_improve >= 20:
                break
        
        a = a_new
        x_warm = x.copy()
    
    return best_a, best_sc, x_warm


def coord_descent_lse(a, beta=500, n_sweeps=50, eta_scale=1.0):
    """Coordinate descent using LSE gradient (computed in vector form)."""
    n = len(a)
    a = np.maximum(a.astype(np.float64).copy(), 0.0)
    S = float(a.sum())
    if S < 1e-12:
        return a
    a = a / S
    
    best_a = a.copy()
    best_sc = compute_score(a)
    
    for sweep in range(n_sweeps):
        sc, grad = lse_score_and_grad(a, beta)
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()
        
        # Adaptive step size
        gn = float(np.linalg.norm(grad))
        if gn < 1e-15:
            break
        eta = eta_scale * (sc - 1.0) / (gn * gn + 1e-20)
        eta = min(eta, 0.1)
        
        a = a - eta * grad
        a = np.clip(a, 0.0, 1000.0)
        S = float(a.sum())
        if S < 1e-12:
            break
        a = a / S
    
    return best_a


def run_lbfgs_lse(a0, beta, maxiter=10000, maxfun=200000):
    """Run L-BFGS-B on LSE-smoothed objective."""
    n = len(a0)
    a0 = np.clip(a0.astype(np.float64).copy(), 0.0, 1000.0)
    if a0.sum() < 1e-6:
        a0[:] = 0.5
    bounds = [(0.0, 1000.0)] * n
    
    def obj_and_grad(x):
        return lse_score_and_grad(x, beta)
    
    res = minimize(
        obj_and_grad, a0,
        method='L-BFGS-B', jac=True, bounds=bounds,
        options={'ftol': 1e-16, 'gtol': 1e-14,
                 'maxiter': maxiter, 'maxfun': maxfun, 'maxls': 50}
    )
    a_out = np.clip(res.x, 0.0, 1000.0)
    exact_sc = compute_score(a_out)
    return exact_sc, a_out


def error_reduction(a, n_iters=100, alpha=0.7):
    """Frequency-domain error reduction."""
    n = len(a)
    a = np.maximum(a.astype(np.float64).copy(), 0.0)
    S = float(a.sum())
    if S < 1e-12:
        return np.ones(n) / n
    a = a / S
    
    best_a = a.copy()
    best_sc = compute_score(a)
    M = 1 << (2 * n - 1).bit_length()
    
    for it in range(n_iters):
        a_pad = np.zeros(M, dtype=np.complex128)
        a_pad[:n] = a
        A = np.fft.fft(a_pad)
        conv = np.fft.ifft(A * A).real[:2 * n - 1]
        
        conv_mean = float(conv.mean())
        conv_max = float(conv.max())
        if conv_max - conv_mean < 1e-15:
            break
        
        thresh = conv_mean + (1.0 - alpha) * (conv_max - conv_mean)
        excess = np.maximum(conv - thresh, 0.0)
        if excess.max() < 1e-15:
            break
        
        conv_mod = conv.copy()
        conv_mod[:2*n-1] -= 0.8 * excess
        err = conv_mod[:2*n-1] - conv
        
        err_pad = np.zeros(M, dtype=np.complex128)
        err_pad[:2 * n - 1] = err
        err_spec = np.fft.fft(err_pad)
        
        with np.errstate(divide='ignore', invalid='ignore'):
            d = err_spec / (2.0 * A + 1e-15)
        d[np.abs(A) < 1e-8] = 0.0
        
        damp = 0.3 + 0.7 * min(1.0, it / (n_iters * 0.3))
        A_new = A + damp * d
        a_new = np.fft.ifft(A_new).real[:n]
        a_new = np.maximum(a_new, 0.0)
        if a_new.sum() < 1e-12:
            break
        a_new = a_new / a_new.sum()
        
        sc = compute_score(a_new)
        if sc < best_sc:
            best_sc = sc
            best_a = a_new.copy()
        a = a_new
    
    return best_a
