Multi-phase optimization for minimizing 2n*max(self-conv)/(sum)^2.
Uses DFT-domain initialization, continuation L-BFGS with LSE smoothing,
peak-equalization coordinate descent, and diverse restarts.
"""

import numpy as np
from scipy.optimize import minimize
import time
import math

def fast_conv(a):
    """Linear self-convolution via real FFT."""
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]

def compute_score(a):
    """Exact score: 2n * max(conv) / (sum)^2."""
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return np.inf
    return 2.0 * n * float(c.max()) / (S * S)

The main issue is that L-BFGS with LSE smoothing converges to a point where the LSE gradient is zero, which is close to (but not exactly) the true optimum (where the max is minimized). As beta increases, the LSE gets closer to the max, but the optimization becomes harder (more non-smooth).

A better approach might be:
1. Use a moderate beta for L-BFGS to get close to the optimum
2. Then switch to a "peak-equalization" method that directly targets the active set

For peak-equalization:
- Identify the top m peaks: k1, k2, ..., km where c[k_i] ≈ max(c)
- We want to make c[k1] = c[k2] = ... = c[km]
- The condition c[ki] = max means: sum_j a[j]*a[ki-j] = max for i=1..m
- We can set up a system: minimize sum_i (c[ki] - max)^2 (make all peaks equal to their average)
- This is a quadratic optimization problem in a (since c[ki] is quadratic in a)

Actually, a simpler approach: 
- At the current point, identify the argmax k*
- Compute the "peak reduction direction": the direction p that most reduces c[k*] without increasing other c[k] too much
- This is a linear programming problem: minimize p^T * grad_c[k*] subject to p^T * grad_c[k] <= 0 for other k, ||p||=1
- But this is expensive for large n

Simpler: Just use the negative subgradient of the max, which is -a[k*-m] (the sensitivity of the peak to a[m]). But this only uses one peak.

Even simpler and potentially very effective: Use the "top-m" weighted subgradient:
- Let k1, ..., km be the top m peaks
- Compute a weighted average of their gradients: grad = (1/m) * sum_i grad_c[ki]
- Take a step in the negative of this

This is similar to using a medium beta in the LSE, where the top m peaks get roughly equal weight.

"""
Multi-phase optimization for minimizing 2n*max(self-conv)/(sum)^2.
Key innovations: DFT-domain initialization, active-set LP for peak shaving,
and paired coordinate descent for fine-tuning.
"""

import numpy as np
from scipy.optimize import minimize
import time
import math

def fast_conv(a):
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]

def compute_score(a):
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return np.inf
    return 2.0 * n * float(c.max()) / (S * S)

def lse_score_grad(a, beta):
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return 1e10, np.zeros(n)
    c_max = float(c.max())
    scaled = beta * (c - c_max)
    exp_scaled = np.exp(scaled)
    log_sum = np.log(exp_scaled.sum())
    L = c_max + log_sum / beta
    score = 2.0 * n * L / (S * S)
    p = exp_scaled / exp_scaled.sum()
    rev_a = a[::-1]
    M2 = 3 * n - 2
    M2_fft = 1 << (M2 - 1).bit_length()
    RA = np.fft.rfft(rev_a, M2_fft)
    P = np.fft.rfft(p, M2_fft)
    conv_res = np.fft.irfft(RA * P, M2_fft)[n - 1:2*n - 1]
    g = 2.0 * conv_res
    S2 = S * S
    S3 = S2 * S
    grad = (2.0 * n) * (g / S2 - 2.0 * L / S3)
    return score, grad

def dft_init(n, rng, n_phases=100):

        # Make DC term real and positive
        A[0] = 1.0
        if M_fft % 2 == 0:
            A[-1] = 1.0

            best_score = sc
            best_a = a.copy()

    """Compute the LP direction for peak shaving."""
