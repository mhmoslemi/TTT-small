But in the DISCRETE case, we might be able to do better because the discrete convolution has a different structure!

Let me reconsider. In the discrete case:
c[k] = sum_j a[j] a[k-j] (with the convention that a[j] = 0 outside [0, n-1]).

c[0] = a[0]^2 (just one term!)
c[1] = a[0]a[1] + a[1]a[0]
c[n-1] = sum_{j=0}^{n-1} a[j] a[n-1-j] (n terms)
c[n] = sum_{j=1}^{n-1} a[j] a[n-j] (n-1 terms)
...
c[2n-2] = a[n-1]^2 (one term)

So c[0] = a[0]^2 and c[2n-2] = a[n-1]^2. These are single terms!

If a[0] = 0, then c[0] = 0. Similarly if a[n-1] = 0, then c[2n-2] = 0.

But if a[0] = 0, then a[1] should be large, and c[1] = 2a[0]a[1] = 0, c[2] = 2a[0]a[2] + a[1]^2 = a[1]^2, etc.

So setting a[0] = 0 shifts the "mass" to the interior, and the peak of the convolution shifts.
