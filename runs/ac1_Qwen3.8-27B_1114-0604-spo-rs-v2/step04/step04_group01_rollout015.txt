Let me think about what "different" approach to use. The strategy says "Convolution Feature-guided Optimization with Multilevel Scaling."

**Convolution Feature-guided:** The key idea is to look at the convolution pattern and use it to guide modifications. Specifically:
- If the convolution has a "bump" at lag k, it means there's a correlation between `a[i]` and `a[k-i]` for various i.
- We can identify which pairs (i, k-i) contribute most to the bump and reduce those products.
- This is more targeted than the "pressure" approach which uses a weighted sum.

**Multilevel Scaling:** Optimize at multiple resolutions:
- Level 0: n/4 elements (block averages of the final sequence)
- Level 1: n/2 elements
- Level 2: n elements (final)

At each level, fix the coarser structure and optimize the finer details.

In practice:
1. Start with the parent, average it in blocks to get a coarse sequence.
2. Optimize the coarse sequence (it's shorter, so optimization is faster).
3. "Upsample" the coarse solution back to full length.
4. Optimize the full-length sequence, starting from the upsampled coarse solution.
5. Iterate: re-coarsen, re-optimize coarse, re-upsample, re-optimize fine.

This is similar to multigrid methods in PDEs.

from scipy.optimize import minimize

def next_power_of_two(m):
    m = int(max(1, m))
    return 1 << (m - 1).bit_length()

def fast_self_conv(a):
    a = np.asarray(a, dtype=np.float64)
    n = int(a.size)
    M = 2 * n - 1
    N = next_power_of_two(M)
    A = np.fft.rfft(a, N)
    out = np.fft.irfft(A * A, N)[:M]
    return np.nan_to_num(out, nan=0.0, posinf=0.0, neginf=0.0)

def corr_pair(a, w):
    a = np.asarray(a, dtype=np.float64)
    w = np.asarray(w, dtype=np.float64)
    n = int(a.size)
    M = n + int(w.size) - 1
    N = next_power_of_two(M)
    A = np.fft.rfft(a[::-1], N)
    W = np.fft.rfft(w, N)
    full = np.fft.irfft(A * W, N)[:M]
    return full[n-1:2*n-1]

def normalize_a(a, target=1.0):
    a = np.asarray(a, dtype=np.float64).ravel()
    a = np.nan_to_num(a, nan=0.0, posinf=1e6, neginf=0.0)
    a = np.clip(a, 0.0, None)
    S = float(a.sum())
    if S < 1e-12:
        return np.full(a.size, target / float(a.size))
    a = a * (target / S)
    return a

    """LSE-smoothed objective and gradient."""
    n = len(a)
    S = float(a.sum())
    if S < 1e-8:
        return 1e10, np.zeros(n)
    
    c = fast_self_conv(a)
    d = c * n / (S * S)  # d[k] = n * conv[k] / S^2
    d = np.maximum(d, 0)
    
    dmax = float(np.max(d))
    z = beta * (d - dmax)
    e = np.exp(z)
    sum_e = float(e.sum())
    if sum_e <= 0 or not np.isfinite(sum_e):
        return 1e10, np.zeros(n)
    w = e / sum_e
    
    L = dmax + np.log(sum_e) / beta
    h = corr_pair(a, w)
    
    # Objective: 2*L + pen*(S-1)^2
    obj = 2.0 * L + pen * (S - 1.0) ** 2
    
    # Gradient
    LDS = float(np.dot(w, d))
    grad = (4.0 * n * h) / (S * S) - (4.0 * LDS) / S + 2.0 * pen * (S - 1.0)
    grad = np.nan_to_num(grad, nan=0.0, posinf=0.0, neginf=0.0)
    
    return obj, grad

    a = normalize_a(a0)

        a_out = normalize_a(res.x) if res.x is not None else a

        a_out = a

    """Average consecutive blocks."""
    n = len(a)
    nb = n // block_size
    a_trimmed = a[:nb * block_size]
    return a_trimmed.reshape(nb, block_size).mean(axis=1)

So yes, longer sequences should give better scores. The question is whether the optimization can find the good solution within the time budget.

Let me also think about the "spectral" approach. If we want `conv(a,a)` to be flat, we want `|FFT(a)|^2` to be "spread out" in a specific way. 

Actually, `conv(a,a) = IFFT(FFT(a) * FFT(a))` (with zero padding). If `FFT(a)` is real and non-negative (which it is when `a` is a "low-pass" shaped sequence), then `FFT(a)^2` is the spectrum, and we want its IFFT to be as flat as possible.

The IFFT of a flat spectrum is a delta (at lag 0). The IFFT of a concentrated spectrum is a spread-out signal. So we want a spectrum that's "in between" - not too flat, not too concentrated.

This is getting too theoretical. Let me just write practical code.

My final approach will be:

1. **Start from parent** (resampled to 8192).
2. **Multigrid-style optimization**:
   a. Coarsen to 1024, optimize (fast, few iterations).
   b. Upsample to 4096, optimize.
   c. Upsample to 8192, optimize.
   d. Repeat the cycle 2-3 times.
3. **LSE smoothing** with continuation at each level.
4. **Subgradient polish** at the finest level.
5. **Perturbation restarts** if time remains.

This multigrid approach is genuinely different from the previous code and should help with convergence.

Let me also add a "project to flat spectrum" step: 
- Compute FFT(a).
- Modify the spectrum to be flatter (e.g., clip the magnitude).
- IFFT back.
- Project onto non-negative cone.
- Renormalize.
This is inspired by iterative FFT-based methods in radar design.

Let me write the final code:

```python
"""
Multilevel (multigrid) optimization of non-negative sequences minimizing
2*n*max(conv(a,a))/sum(a)^2. Uses LSE smoothing with L-BFGS-B at multiple
resolutions, spectral projection steps, and exact subgradient polishing.
"""

import numpy as np
import time
from scipy.optimize import minimize

def next_power_of_two(m):
    m = int(max(1, m))
    return 1 << (m - 1).bit_length()

def fast_self_conv(a):
    a = np.asarray(a, dtype=np.float64)
    n = int(a.size)
    if n == 0:
        return np.empty(0, dtype=np.float64)
    M = 2 * n - 1
    N = next_power_of_two(M)
    A = np.fft.rfft(a, N)
    out = np.fft.irfft(A * A, N)[:M]
    return np.nan_to_num(out, nan=0.0, posinf=0.0, neginf=0.0)

def corr_pair(a, w):
    a = np.asarray(a, dtype=np.float64)
    w = np.asarray(w, dtype=np.float64)
    n = int(a.size)
    if n == 0 or w.size == 0:
        return np.empty(n, dtype=np.float64)
    M = n + int(w.size) - 1
    N = next_power_of_two(M)
    A = np.fft.rfft(a[::-1], N)
    W = np.fft.rfft(w, N)
    full = np.fft.irfft(A * W, N)[:M]
    return full[n - 1:2 * n - 1]

def normalize_a(a, target=1.0):
    a = np.asarray(a, dtype=np.float64).ravel()
    if a.size == 0:
        return np.array([])
    a = np.nan_to_num(a, nan=0.0, posinf=1e6, neginf=0.0)
    a = np.clip(a, 0.0, None)
    S = float(a.sum())
    if S < 1e-12:
        return np.full(a.size, target / float(a.size))
    return a * (target / S)

def resample_sequence(a, n):
    a = np.nan_to_num(np.asarray(a, dtype=np.float64).ravel(), nan=0.0, posinf=0.0, neginf=0.0)
    m = int(a.size)
    if m == 0:
        return np.ones(max(1, int(n)), dtype=np.float64) / max(1, int(n))
    n = int(n)
    if m == n:
        return a.copy()
    x_old = np.linspace(0.0, 1.0, m)
    x_new = np.linspace(0.0, 1.0, n)
    return np.interp(x_new, x_old, a).astype(np.float64)

def exact_score(a):
    n = len(a)
    S = float(np.sum(a))
    if S < 1e-12:
        return np.inf
    c = fast_self_conv(a)
    cmax = float(np.max(c))
    if cmax < 0:
        cmax = 0.0
    return float(2.0 * n * cmax / (S * S))

def lse_objective_grad(a, beta, pen):
    n = int(len(a))
    grad = np.zeros(n, dtype=np.float64)
    S = float(a.sum())
    if S < 1e-8:
        return 1e10, grad
    c = fast_self_conv(a)
    d = float(n) * c / (S * S)
    d = np.maximum(d, 0.0)
    dmax = float(np.max(d))
    if not np.isfinite(dmax) or dmax <= 0:
        return 2.0 * dmax + pen * (S-1)**2, grad
    z = beta * (d - dmax)
    # Clip z for numerical stability
    z = np.clip(z, -50.0, 50.0)
    e = np.exp(z)
    sum_e = float(e.sum())
    if sum_e <= 0 or not np.isfinite(sum_e):
        return 1e10, grad
    w = e / sum_e
    L = dmax + np.log(sum_e) / beta
    LDS = float(np.dot(w, d))
    h = corr_pair(a, w)
    obj = 2.0 * L + pen * (S - 1.0) ** 2
    grad = (4.0 * float(n) * h) / (S * S) - (4.0 * LDS) / S + 2.0 * pen * (S - 1.0)
    grad = np.nan_to_num(grad, nan=0.0, posinf=0.0, neginf=0.0)
    grad = np.clip(grad, -1e6, 1e6)
    return float(obj), grad

def run_lbfgs(a0, beta, pen, deadline, maxiter=200, maxfun=None):
    a = normalize_a(a0)
    n = len(a)
    if n == 0:
        return np.inf, a
    
    nfun_est = int(maxiter * 1.5) if maxfun is None else maxfun
    # Time check
    if deadline is not None:
        rem = float(deadline - time.monotonic())
        if rem < 3.0:
            return exact_score(a), a
        # Estimate: each eval ~ n*2 log(n) / 1e7 seconds (rough)
        est_per_eval = 0.005 * max(1.0, n / 4096.0)
        cap = int(rem * 0.85 / max(est_per_eval, 0.001))
        nfun_est = min(nfun_est, cap)
        if nfun_est < 20:
            return exact_score(a), a
    
    def fun(x):
        return lse_objective_grad(x, beta, pen)
    
    bounds = [(0.0, 5.0)] * n
    try:
        res = minimize(fun, a, method='L-BFGS-B', jac=True, bounds=bounds,
                      options={'maxiter': maxiter, 'maxfun': max(40, nfun_est),
                               'ftol': 1e-14, 'gtol': 1e-12, 'maxls': 40})
        a_out = normalize_a(res.x) if res.x is not None else a
    except Exception:
        a_out = a
    
    sc = exact_score(a_out)
    if not np.isfinite(sc):
        a_out = a
        sc = exact_score(a)
    return float(sc), a_out

def spectral_project(a, n_harmonics_clip=None):
    """
    Project the spectrum toward flatness, then project back to non-negative.
    This is inspired by iterative spectral methods in radar/filter design.
    """
    a = np.asarray(a, dtype=np.float64).ravel()
    n = int(a.size)
    N = next_power_of_two(2 * n - 1)
    A = np.fft.rfft(a, N)
    mag = np.abs(A)
    phase = np.angle(A)
    
    if n_harmonics_clip is not None and n_harmonics_clip > 1:
        # Keep only the first n_harmonics_clip frequency bins (low-pass)
        A_clipped = A.copy()
        A_clipped[n_harmonics_clip:] = 0
        a_lp = np.fft.irfft(A_clipped, N)[:n]
    else:
        a_lp = a
    
    return a_lp

def subgrad_polish(a, max_iters=50, deadline=None, k=8):
    """Exact subgradient method for the max-convolution objective."""
    a = normalize_a(a)
    best_a = a.copy()
    best_sc = exact_score(a)
    cur_sc = best_sc
    
    for it in range(int(max_iters)):
        if deadline is not None and time.monotonic() > float(deadline):
            break
        
        c = fast_self_conv(a)
        S = float(a.sum())
        n = len(a)
        d = float(n) * c / (S * S)
        dmax = float(np.max(d))
        
        if d.size == 0 or not np.isfinite(dmax) or dmax <= 0:
            break
        
        # Top-k lags
        m = len(d)
        k_eff = min(int(k), m)
        idx = np.argpartition(d, m - k_eff)[m - k_eff:]
        
        # Weights: softmax on top-k for smoother pressure
        top_vals = d[idx]
        z = 10.0 * (top_vals - top_vals.max())
        e = np.exp(np.clip(z, -30, 30))
        w_idx = e / float(e.sum())
        
        w = np.zeros(m, dtype=np.float64)
        w[idx] = w_idx
        
        h = corr_pair(a, w)
        hmax = float(np.max(h))
        if hmax < 1e-12:
            break
        
        # Try multiple step sizes
        improved = False
        for mult in [0.03, 0.08, 0.15, 0.3, 0.6, 1.2]:
            if deadline is not None and time.monotonic() > float(deadline):
                break
            eta = mult / hmax
            q = a * np.exp(-eta * h)
            q = np.clip(q, 0, None)
            qs = float(q.sum())
            if qs < 1e-12:
                continue
            q = q / qs
            sc = exact_score(q)
            if np.isfinite(sc) and sc < best_sc:
                best_sc = sc
                best_a = q.copy()
            if np.isfinite(sc) and sc < cur_sc:
                cur_sc = sc
                a = q.copy()
                improved = True
        
        if not improved:
            # Try expanding (increase elements that DON'T contribute to hot lags)
            h_min = float(np.min(h))
            for mult in [0.05, 0.1, 0.2]:
                if deadline is not None and time.monotonic() > float(deadline):
                    break
                eta = mult / max(hmax - h_min, 1e-12)
                q = a * np.exp(eta * (h - hmax))  # increase low-pressure elements
                q = np.clip(q, 0, None)
                qs = float(q.sum())
                if qs < 1e-12:
                    continue
                q = q / qs
                sc = exact_score(q)
                if np.isfinite(sc) and sc < best_sc:
                    best_sc = sc
                    best_a = q.copy()
                if np.isfinite(sc) and sc < cur_sc:
                    cur_sc = sc
                    a = q.copy()
                    improved = True
            if not improved:
                break
    
    return float(best_sc), best_a

def multigrid_cycle(a, deadline, rng, n_levels=3):
    """
    Multigrid: coarsen, optimize coarse, upsample, optimize fine.
    """
    n = len(a)
    current = normalize_a(a)
    best_a = current.copy()
    best_sc = exact_score(current)
    
    # Build multigrid levels
    levels = []
    n_curr = n
    for _ in range(n_levels):
        levels.append(n_curr)
        n_curr = max(64, n_curr // 4)
    levels.reverse()  # coarsest first
    
    for level_idx, n_level in enumerate(levels):
        if time.monotonic() > deadline - 30:
            break
        
        # If coarser than current, downsample
        if n_level < len(current):
            coarse = resample_sequence(current, n_level)
            coarse = normalize_a(coarse)
        elif n_level == len(current):
            coarse = current.copy()
        else:
            coarse = resample_sequence(current, n_level)
            coarse = normalize_a(coarse)
        
        # Optimize at this level
        betas = [50, 150, 400, 1000, 2000]
        if n_level <= 1024:
            betas = [50, 100, 300]
            maxit_factor = 1.5
        elif n_level <= 4096:
            betas = [80, 200, 500, 1000]
            maxit_factor = 1.0
        else:
            betas = [100, 300, 800, 2000]
            maxit_factor = 0.8
        
        for beta in betas:
            if time.monotonic() > deadline - 20:
                break
            sc, coarse2 = run_lbfgs(coarse, beta, 1e-3, deadline, 
                                     maxiter=int(200 * maxit_factor))
            if sc < exact_score(coarse):
                coarse = normalize_a(coarse2)
        
        # Check improvement at this level
        sc_check = exact_score(coarse)
        # Upsample to next level (or finest)
        if n_level < n:
            upsampled = resample_sequence(coarse, min(n, levels[level_idx + 1]) if level_idx + 1 < len(levels) else n)
            current = normalize_a(upsampled)
        else:
            current = normalize_a(coarse)
        
        sc_current = exact_score(current)
        if sc_current < best_sc:
            best_sc = sc_current
            best_a = current.copy()
    
    return float(best_sc), best_a

def perturb(a, rng, strength=None):
    """Perturb a sequence for diversification."""
    p = normalize_a(np.asarray(a, dtype=np.float64).ravel())
    n = len(p)
    if n == 0:
        return p
    if strength is None:
        strength = float(rng.uniform(0.1, 0.5))
    mode = int(rng.integers(0, 5))
    
    if mode == 0:
        q = p * np.exp(strength * rng.standard_normal(n))
    elif mode == 1:
        t = float(rng.uniform(0.05, 0.3))
        q = (1.0 - t) * p + t * (np.ones(n) / n)
    elif mode == 2:
        q = p[::-1].copy()
        q = q * np.exp(0.05 * rng.standard_normal(n))
    elif mode == 3:
        # Local smoothing
        k = int(rng.integers(3, min(21, n)))
        if k % 2 == 0:
            k += 1
        if k > n:
            k = n if n % 2 == 1 else max(3, n - 1)
        if k < 3:
            k = 3
        kern = np.ones(k) / k
        q = np.convolve(p, kern, mode='same')
    else:
        # Segment-wise scaling
        nseg = int(rng.integers(4, 16))
        seg = np.ones(n)
        for i in range(nseg):
            lo = int(i * n / nseg)
            hi = int((i + 1) * n / nseg)
            seg[lo:hi] = float(rng.uniform(0.5, 1.5))
        q
