This is a nice reduction! And for the correlation, a periodic function has a special structure.

Let me try this approach: optimize over a pattern of length p for various p values.

For p=8: 8 variables, sum = 4
For p=16: 16 variables, sum = 8
For p=24: 24 variables, sum = 12
For p=32: 32 variables, sum = 16

The QP for a pattern of length p is much smaller and can be solved exactly!

But wait, does the optimal solution actually have periodic structure? Maybe not exactly, but it might be close. Let me try it as a starting point and then use the full optimization to refine.

Actually, I think the most promising approach is:

1. **Use the dual/mirror descent to guide a projected gradient or L-BFGS optimization**
2. **Try different initial conditions including periodic patterns**
3. **Polish with coordinate descent**

Let me now write the code. I'll focus on making the dual-guided approach efficient and effective.

One more thought: instead of solving the full QP at each iteration of the dual method, I can use a few steps of projected gradient (warm-started from the previous solution) which should be fast enough.

Let me also think about the update of p. The multiplicative weight update is:
p_new[k] ∝ p[k] * exp(-eta * corr_h*[k])

where corr_h* is the correlation of the QP solution. But I want p to focus on the MAX correlations, so I should use:
p_new[k] ∝ p[k] * exp(eta * (corr_h*[k] - max_corr))

This way, p concentrates on the correlations that are at (or near) the maximum.

With eta → ∞, p concentrates entirely on the argmax correlations, and the QP becomes: min_h max_k corr[k] (approximately). But with finite eta, we get a smooth approximation.

I'll use a schedule where eta increases over time (or equivalently, the "temperature" decreases).

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_to_sum(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(200):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        mask = (h > 1e-14) & (h < 1.0 - 1e-14)
        if np.any(mask):
            h[mask] += diff / np.sum(mask)
        else:
            h += diff / len(h)
        h = np.clip(h, 0.0, 1.0)
    return h

def compute_Ah(p, h):
    n = len(h)
    result = np.zeros(n)
    for d in range(-(n-1), n):
        k = d + n - 1
        pk = p[k]
        if pk == 0:
            continue
        if d >= 0:
            result[d:] += pk * h[:n-d]
        else:
            result[:n+d] += pk * h[-d:]
    return result

def compute_L(p):
    n = (len(p) + 1) // 2
    prefix = np.concatenate([[0.0], np.cumsum(p)])
    L = np.zeros(n)
    for j in range(n):
        lo = max(0, j + 1)
        hi = min(2 * n - 1, j + n + 1)
        L[j] = prefix[hi] - prefix[lo]
    return L

def qp_projected_gradient(p, h_init, n, max_iter=300, step=0.35):
    h = h_init.copy()
    L = compute_L(p)
    p_r = p[::-1].copy()
    
    for it in range(max_iter):
        Ah = compute_Ah(p, h)
        Ath = compute_Ah(p_r, h)
        grad = L - Ah - Ath
        
        h_new = h - step * grad
        h_new = project_to_sum(h_new, n / 2.0)
        
        if np.max(np.abs(h_new - h)) < 1e-12:
            h = h_new
            break
        h = h_new
    
    return h

def pair_descent_sweep(h, corr, rng, n_cand=10):
    # Same as before
    n = len(h)
    nm1 = n - 1
    improved = False
    order = np.arange(n)
    rng.shuffle(order)
    for j in order:
        B_j = np.zeros(2 * n - 1)
        # Compute B_j: derivative of corr w.r.t. h[j]
        # corr[k] = sum_i h[i] * (1-h[i+(n-1-k)])
        # B_j[k] = (1-h[j+(n-1-k)]) * 1[valid] - h[j-(n-1-k)] * 1[valid]
        # First term: j+(n-1-k) in [0,n-1], i.e., n-1-j <= k <= n-1+j
        k_lo = max(0, n - 1 - j)
        k_hi = min(2 * n - 2, n - 1 + j)
        if k_lo <= k_hi:
            idx = np.arange(k_lo, k_hi + 1)
            B_j[idx] += (1.0 - h[j + n - 1 - idx])
        
        # Second term: j-(n-1-k) in [0,n-1], i.e., j <= k <= j+n-1
        k_lo2 = max(0, j)
        k_hi2 = min(2 * n - 2, j + n - 1)
        if k_lo2 <= k_hi2:
            idx = np.arange(k_lo2, k_hi2 + 1)
            B_j[idx] += -h[j + n - 1 - idx]
        
        best_val = np.max(corr)
        best_delta = 0.0
        best_D = None
        best_k = -1
        
        k_set = [(j + 1) % n, (j - 1 + n) % n, (j + n // 2) % n,
                 (j + n // 3) % n, (j + 2 * n // 3) % n]
        for _ in range(max(0, n_cand - 5)):
            k_set.append(rng.randint(n))
        
        seen = set()
        for k in k_set:
            if k == j or k in seen:
                continue
            seen.add(k)
            B_k = np.zeros(2 * n - 1)
            k_lo = max(0, n - 1 - k)
            k_hi = min(2 * n - 2, n - 1 + k)
            if k_lo <= k_hi:
                idx = np.arange(k_lo, k_hi + 1)
                B_k[idx] += (1.0 - h[k + n - 1 - idx])
            k_lo2 = max(0, k)
            k_hi2 = min(2 * n - 2, k + n - 1)
            if k_lo2 <= k_hi2:
                idx = np.arange(k_lo2, k_hi2 + 1)
                B_k[idx] += -h[k + n - 1 - idx]
            
            D = B_j - B_k
            delta_lo = max(-h[j], h[k] - 1.0)
            delta_hi = min(1.0 - h[j], h[k])
            if delta_hi - delta_lo < 1e-13:
                continue
            
            # 1D optimization: min max(corr + delta * D)
            # Grid + bisection
            t_grid = np.linspace(delta_lo, delta_hi, 16)
            vals = np.max(corr[None, :] + D[None, :] * t_grid[:, None], axis=1)
            best_idx = int(np.argmin(vals))
            if best_idx == 0:
                delta_opt = delta_lo
            elif best_idx == len(t_grid) - 1:
                delta_opt = delta_hi
            else:
                lo_r = t_grid[best_idx - 1]
                hi_r = t_grid[best_idx + 1]
                for _ in range(24):
                    mid = (lo_r + hi_r) * 0.5
                    if np.max(corr + D * mid) <= np.max(corr + D * lo_r):
                        lo_r = mid
                    else:
                        hi_r = mid
                delta_opt = (lo_r + hi_r) * 0.5
            
            val_opt = np.max(corr + D * delta_opt)
            if val_opt < best_val - 1e-13:
                best_val = val_opt
                best_delta = delta_opt
                best_D = D
                best_k = k
        
        if best_k >= 0 and abs(best_delta) > 1e-13:
            corr += best_delta * best_D
            h[j] += best_delta
            h[best_k] -= best_delta
            h[j] = np.clip(h[j], 0.0, 1.0)
            h[best_k] = np.clip(h[best_k], 0.0, 1.0)
            improved = True
    
    return h, corr, improved

def run(seed=42, budget_s=1300, **kwargs):
    t_start = time.time()
    rng = np.random.RandomState(seed)
    best_h = None
    best_c5 = float('inf')
    best_n = 0
    
    if 'initial_h_values' in globals() and initial_h_values is not None:
        try:
            best_h = np.array(initial_h_values, dtype=float).copy()
            best_n = len(best_h)
            best_h = project_to_sum(best_h, best_n / 2.0)
            best_c5 = compute_c5(best_h)
        except Exception:
            pass
    
    if best_h is None:
        best_n = 240
        best_h = np.full(best_n, 0.5)
        best_c5 = compute_c5(best_h)
    
    # Phase 1: Dual-guided optimization (50% budget)
    t_end1 = t_start + 0.50 * budget_s
    n = best_n
    h_work = best_h.copy()
    p = np.ones(2 * n - 1) / (2 * n - 1)
    
    for outer_it in range(200):
        if time.time() > t_end1:
            break
        
        # Solve QP
        h_qp = qp_projected_gradient(p, h_work, n, max_iter=200, step=0.35)
        c5_qp = compute_c5(h_qp)
        
        if c5_qp < best_c5:
            best_c5 = c5_qp
            best_h = h_qp.copy()
            best_n = n
        
        # Update p
        corr_qp = np.correlate(h_qp, 1.0 - h_qp, mode="full")
        # Sharpen p to focus on max correlations
        eta = 5.0 + 10.0 * outer_it / 50.0  # increasing concentration
        p *= np.exp(eta * (corr_qp - np.max(corr_qp)) / (np.max(corr_qp) + 1e-10))
        p /= np.sum(p)
        
        # Occasionally re-randomize p to avoid getting stuck
        if outer_it % 20 == 19:
            p = p ** 0.5
            p /= np.sum(p)
        
        h_work = h_qp
    
    # Phase 2: Coordinate descent polish (35% budget)
    t_end2 = t_start + 0.85 * budget_s
    h_work = best_h.copy()
    corr_work = np.correlate(h_work, 1.0 - h_work, mode="full")
    n_w = len(h_work)
    stall = 0
    
    while time.time() < t_end2:
        h_work, corr_work, imp = pair_descent_sweep(h_work, corr_work, rng, n_cand=12)
        c5_w = compute_c5(h_work)
        if c5_w < best_c5 - 1e-10:
            best_c5 = c5_w
            best_h = h_work.copy()
            best_n = n_w
            stall = 0
        else:
            stall += 1
        if stall > 300:
            h_work = project_to_sum(h_work + rng.uniform(-0.08, 0.08, n_w), n_w / 2.0)
            corr_work = np.correlate(h_work, 1.0 - h_work, mode="full")
            stall = 0
    
    # Phase 3: Multi-resolution + SLSQP (15% budget)
    t_end3 = t_start + budget_s - 10
    resolutions = [200, 280, 320]
    for n_tr in resolutions:
        if time.time() >= t_end3:
            break
        ts = n_tr / 2.0
        if abs(ts - round(ts)) > 1e-6:
            continue
        x_old = np.linspace(0, 2, best_n, endpoint=False)
        x_new = np.linspace(0, 2, n_tr, endpoint=False)
        h_tr = project_to_sum(np.interp(x_new, x_old, best_h, period=2.0), ts)
        corr_tr = np.correlate(h_tr, 1.0 - h_tr, mode="full")
        
        # Quick coordinate descent
        max_sweeps = 30
        for _ in range(max_sweeps):
            if time.time() >= t_end3:
                break
            h_tr, corr_tr, _ = pair_descent_sweep(h_tr, corr_tr, rng, n_cand=8)
        
        c5_tr = compute_c5(h_tr)
        if c5_tr < best_c5:
            best_c5 = c5_tr
            best_h = h_tr.copy()
            best_n = n_tr
    
    # Final polish
    h_fin = best_h.copy()
    n_fin = best_n
    corr_fin = np.correlate(h_fin, 1.0 - h_fin, mode="full")
    while time.time() < t_start + budget_s - 3:
        h_fin, corr_fin, _ = pair_descent_sweep(h_fin, corr_fin, rng, n_cand=10)
        c5_fin = compute_c5(h_fin)
        if c5_fin < best_c5:
            best_c5 = c5_fin
            best_h = h_fin.copy()
            best_n = n_fin
    
    best_h = project_to_sum(best_h, best_n / 2.0)
    best_h = np.clip(best_h, 0.0, 1.0)
    best_c5 = compute_c5(best_h)
    return (best_h, best_c5, best_n)
```

Wait, let me double-check. np.convolve(p, h, mode='full') has length (2n-1) + n - 1 = 3n-2. That's not what I want.

Actually, np.convolve(p, h, mode='full')[k] = sum_j p[j] * h[k-j] where 0≤j<len(p) and 0≤k-j<len(h).

I want (A*h)[i] = sum_j h[j] * p[i+n-1-j] where 0≤j<n and 0≤i+n-1-j<2n-1.

np.convolve(p, h, mode='full')[i+n-1] = sum_j p[j] * h[i+n-1-j] where 0≤j<2n-1 and 0≤i+n-1-j<n.

These are the same sum (just with j and the other variable swapped in the multiplication, which is commutative).

So (A*h)[i] = np.convolve(p, h, mode='full')[i+n-1] for i=0,...,n-1.

The full convolution has length (2n-1) + n - 1 = 3n-2. And I'm taking indices n-1 through 2n-2, which is valid (2n-2 < 3n-2 for n ≥ 2).

Let me verify with a small example. n=3, p = [p0, p1, p2, p3, p4], h = [h0, h1, h2].

(A*h)[0] = sum_j h[j] * p[0+3-1-j] = h[0]*p[2] + h[1]*p[1] + h[2]*p[0] (for valid indices)
= h[0]*p[2] + h[1]*p[1] + h[2]*p[0]

np.convolve(p, h, mode='full')[2] = sum_j p[j]*h[2-j] = p[0]*h[2] + p[1]*h[1] + p[2]*h[0]

These are the same! (p[0]*h[2] + p[1]*h[1] + p[2]*h[0]) ✓

(A*h)[1] = sum_j h[j] * p[1+2-j] = h[0]*p[3] + h[1]*p[2] + h[2]*p[1]
np.convolve(p, h, mode='full')[3] = p[0]*h[3] + p[1]*h[2] + p[2]*h[1] + p[3]*h[0]
But h[3] doesn't exist (h has indices 0,1,2), so = p[1]*h[2] + p[2]*h[1] + p[3]*h[0] ✓

(A*h)[2] = sum_j h[j] * p[2+2-j] = h[0]*p[4] + h[1]*p[3] + h[2]*p[2]
np.convolve(p, h, mode='full')[4] = p[1]*h[3] + p[2]*h[2] + p[3]*h[1] + p[4]*h[0]
= p[2]*h[2] + p[3]*h[1] + p[4]*h[0] ✓
