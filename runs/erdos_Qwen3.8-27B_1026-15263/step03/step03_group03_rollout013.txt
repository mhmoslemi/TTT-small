For 0-1 h: result[k] = |{i: h[i]=1, h[i+k-n+1]=0}| (count of 1→0 transitions at that lag).

Let me denote d = k - (n-1) (the "effective lag" from center). Then:
result[k] = sum_i h[i] * (1-h[i+d]) for valid i.

For d > 0 (k > n-1): valid i are 0 to n-1-d. So result = sum_{i=0}^{n-1-d} h[i]*(1-h[i+d]).
For d < 0 (k < n-1): valid i are -d to n-1. So result = sum_{i=-d}^{n-1} h[i]*(1-h[i+d]) = sum_{j=0}^{n-1+d} h[j+d]*(1-h[j]) by substitution.

For 0-1 h and d > 0: result[k] = |{i ∈ [0, n-1-d]: h[i]=1, h[i+d]=0}|.

The number of terms is n-d. In a "random" 0-1 function, this would be approximately (n-d)/4.

So C5 ≈ max_{d≠0} (n-|d|)/4 * 2/n ≈ 1/2 for large n (when d is small relative to n).

But we can do better! The key is to arrange the 1s and 0s so that for each lag d, the number of 1→0 transitions at that lag is minimized.

This is exactly the problem of minimizing the maximum autocorrelation "peak" (in the cross-correlation sense). It's related to "low autocorrelation sequences" (Barker sequences, Welch-bound sequences, etc.).

For a binary sequence of length n with n/2 ones, the minimum possible value of max_d |autocorrelation(d)| is bounded below by the Welch bound. But our problem is slightly different because we're looking at the "one-sided" cross-correlation (1→0 transitions), not the two-sided one.

0→1 at lag d: count of i where s[i]=0, s[i+d]=1
1→1 at lag d: count of i where s[i]=1, s[i+d]=1
0→0 at lag d: count of i where s[i]=0, s[i+d]=0

Note: (1→0) + (1→1) = number of i where s[i]=1 in the valid range = approximately n/2 (for d not too large)
(0→1) + (1→1) = number of i where s[i+d]=1 in the valid range = approximately n/2

Also: (1→0) - (0→1) = ... let's see.
(1→0) + (0→0) = n - d (total terms)
(1→1) + (0→1) = n - d

And (1→0) + (1→1) = (number of 1s in positions 0 to n-1-d) ≈ (n-d)/2
(0→1) + (1→1) = (number of 1s in positions d to n-1) ≈ (n-d)/2

So (1→0) - (0→1) = (number of 1s in 0..n-1-d) - (number of 1s in d..n-1)
= (number of 1s in 0..d-1) - (number of 1s in n-d..n-1)

This is related to the "boundary" of the sequence. For a "balanced" sequence, this is approximately 0, so (1→0) ≈ (0→1) ≈ (n-d)/4.

But we can do better by making (1→0) < (n-d)/4 for all d. This is the "aperiodic autocorrelation" problem!

The aperiodic autocorrelation of a sequence s at lag d is:
R(d) = sum_{i=0}^{n-1-d} (2s[i]-1)(2s[i+d]-1)

For a 0-1 sequence, let x[i] = 2s[i]-1 ∈ {-1, +1}. Then:
R(d) = sum_{i=0}^{n-1-d} x[i]x[i+d]

And: (1→0) at lag d = (number of i where s[i]=1, s[i+d]=0)

(1→0) means s[i]=1, s[i+d]=0, i.e., x[i]=1, x[i+d]=-1.
(1→0)_count = |{i: x[i]=1, x[i+d]=-1}| = (1/4) * sum_{i=0}^{n-1-d} (1+x[i])(1-x[i+d])

= (1/4) * sum (1 + x[i] - x[i+d] - x[i]x[i+d])
= (1/4) * [(n-d) + (sum x[i]) - (sum x[i+d]) - R(d)]

If the sequence is "balanced" (sum x[i] = 0), then:
(1→0)_count ≈ (n-d)/4 - R(d)/4 (approximately, ignoring boundary effects)

So to minimize (1→0)_count, we want to maximize R(d) for all d. But we can't maximize R(d) for all d simultaneously!

The sum of R(d) over all d is (sum x[i])^2 - (n-d) terms... actually:
sum_{d=1}^{n-1} R(d) = sum_{d=1}^{n-1} sum_{i=0}^{n-1-d} x[i]x[i+d]
= sum_{i<j} x[i]x[j] (over all pairs)
= (1/2)[(sum x[i])^2 - sum x[i]^2]
= (1/2)[0 - n] = -n/2 (for balanced sequence)

So the average R(d) over d=1,...,n-1 is -n/(2(n-1)) ≈ -1/2.

This means we can't make all R(d) positive. The best we can do is make them all close to -1/2, which gives (1→0)_count ≈ (n-d)/4 + 1/8 ≈ (n-d+0.5)/4.

    corr = np.correlate(h, 1.0 - h, mode="full")

        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-13:
            break

        if np.any(mask):
            h[mask] += diff / np.sum(mask)
        else:
            h += diff / len(h)
        h = np.clip(h, 0.0, 1.0)

def compute_B(h, j, n):
    nm1 = n - 1
    B = np.zeros(2 * n - 1)
    k_start = max(0, nm1 - j)
    k_end = min(2 * n - 2, 2 * nm1 - j)
    if k_start <= k_end:
        B[k_start:k_end + 1] += (1.0 - h[j - nm1 + np.arange(k_start, k_end + 1)])
    k_start2 = max(0, j)
    k_end2 = min(2 * n - 2, j + nm1)
    if k_start2 <= k_end2:
        B[k_start2:k_end2 + 1] += -h[j + nm1 - np.arange(k_start2, k_end2 + 1)]
    return B

def solve_1d_minmax(A, D, lo, hi):
    if hi - lo < 1e-14:
        return (lo + hi) * 0.5
    # Use a combination of grid search and bisection
    # First, coarse grid to bracket the minimum
    n_grid = 20
    t_grid = np.linspace(lo, hi, n_grid)
    vals = np.max(A[None, :] + D[None, :] * t_grid[:, None], axis=1)
    best_idx = int(np.argmin(vals))
    if best_idx == 0:
        return lo
    if best_idx == n_grid - 1:
        return hi
    lo_r = t_grid[best_idx - 1]
    hi_r = t_grid[best_idx + 1]
    # Bisection
    for _ in range(30):
        mid = (lo_r + hi_r) * 0.5
        f_mid = np.max(A + D * mid)
        f_lo = np.max(A + D * lo_r)
        f_hi = np.max(A + D * hi_r)
        if f_mid <= f_lo:
            lo_r = mid
        elif f_mid <= f_hi:
            hi_r = mid

            if f_lo <= f_hi:
                hi_r = mid
            else:
                lo_r = mid

            val_opt = np.max(corr + D * delta_opt)

                best_delta = delta_opt
                best_D = D
                best_k = k
            elif temperature > 0 and T_accept > 0:

                    best_delta = delta_opt

            h[j] += best_delta
            h[best_k] -= best_delta
            if h[j] < 0: h[j] = 0.0
            elif h[j] > 1: h[j] = 1.0
            if h[best_k] < 0: h[best_k] = 0.0
            elif h[best_k] > 1: h[best_k] = 1.0
            improved = True
            accepted += 1

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_to_sum(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(300):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-13:
            break
        mask = (h > 1e-12) & (h < 1.0 - 1e-12)
        if np.any(mask):
            h[mask] += diff / np.sum(mask)
        else:
            h += diff / len(h)
        h = np.clip(h, 0.0, 1.0)
    return h

def compute_B(h, j, n):
    nm1 = n - 1
    B = np.zeros(2 * n - 1)
    k_start = max(0, nm1 - j)
    k_end = min(2 * n - 2, 2 * nm1 - j)
    if k_start <= k_end:
        B[k_start:k_end + 1] += (1.0 - h[j - nm1 + np.arange(k_start, k_end + 1)])
    k_start2 = max(0, j)
    k_end2 = min(2 * n - 2, j + nm1)
    if k_start2 <= k_end2:
        B[k_start2:k_end2 + 1] += -h[j + nm1 - np.arange(k_start2, k_end2 + 1)]
    return B

def solve_1d_minmax(A, D, lo, hi):
    if hi - lo < 1e-14:
        return (lo + hi) * 0.5
    n_grid = 16
    t_grid = np.linspace(lo, hi, n_grid)
    vals = np.max(A[None, :] + D[None, :] * t_grid[:, None], axis=1)
    best_idx = int(np.argmin(vals))
    if best_idx == 0:
        return lo
    if best_idx == n_grid - 1:
        return hi
    lo_r = t_grid[best_idx - 1]
    hi_r = t_grid[best_idx + 1]
    for _ in range(28):
        mid = (lo_r + hi_r) * 0.5
        f_mid = np.max(A + D * mid)
        f_lo = np.max(A + D * lo_r)
        if f_mid <= f_lo:
            lo_r = mid
        else:
            hi_r = mid
    return (lo_r + hi_r) * 0.5

def pair_descent_sweep(h, corr, rng, n, n_cand=10, temperature=0.0):
    order = np.arange(n)
    rng.shuffle(order)
    improved = False
    n_accepted = 0
    for j in order:
        B_j = compute_B(h, j, n)
        current_max = np.max(corr)
        best_val = current_max
        best_delta = 0.0
        best_D = None
        best_k = -1
        # Build candidate set
        k_candidates = [(j + 1) % n, (j - 1 + n) % n, (j + n // 2) % n, (j + n//3) % n, (j + 2*n//3) % n]
        for _ in range(max(0, n_cand - len(k_candidates))):
            k_candidates.append(rng.randint(n))
        seen = set()
        for k in k_candidates:
            if k == j or k in seen:
                continue
            seen.add(k)
            B_k = compute_B(h, k, n)
            D = B_j - B_k
            delta_lo = max(-h[j], h[k] - 1.0)
            delta_hi = min(1.0 - h[j], h[k])
            if delta_hi - delta_lo < 1e-13:
                continue
            delta_opt = solve_1d_minmax(corr, D, delta_lo, delta_hi)
            val_opt = float(np.max(corr + D * delta_opt))
            if val_opt < best_val - 1e-13:
                best_val = val_opt
                best_delta = delta_opt
                best_D = D
                best_k = k
            elif temperature > 0.0:
                delta_c = (val_opt - current_max) / temperature
                if delta_c < 100.0 and rng.random() < np.exp(-delta_c):
                    best_val = val_opt
                    best_delta = delta_opt
                    best_D = D
                    best_k = k
        if best_k >= 0 and abs(best_delta) > 1e-13:
            corr += best_delta * best_D
            h[j] = np.clip(h[j] + best_delta, 0.0, 1.0)
            h[best_k] = np.clip(h[best_k] - best_delta, 0.0, 1.0)
            improved = True
            n_accepted += 1
    return h, corr, improved, n_accepted

def smooth_max_and_grad(h, alpha):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    m_val = float(np.max(corr))
    shifted = alpha * (corr - m_val)
    # Numerical stability
    exp_vals = np.exp(np.maximum(shifted, -500))
    w = exp_vals / np.sum(exp_vals)
    obj = m_val + np.log(np.sum(exp_vals)) / alpha
    # Gradient
    j_idx = np.arange(n)[:, None]  # (n, 1)
    m_idx = np.arange(2 * n - 1)[None, :]  # (1, 2n-1)
    # corr[k] = sum_i h[i] * (1-h[i+k-n+1])
    # d(corr[k])/dh[j] = (1-h[j+k-n+1]) if valid - h[j-k+n-1] if valid
    first_idx = j_idx + m_idx - (n - 1)  # (n, 2n-1): for each j,k, this is j+k-n+1
    second_idx = j_idx - m_idx + (n - 1)  # (n, 2n-1): for each j,k, this is j-k+n-1
    valid_f = (first_idx >= 0) & (first_idx < n)
    valid_s = (second_idx >= 0) & (second_idx < n)
    fc = np.clip(first_idx, 0, n - 1)
    sc = np.clip(second_idx, 0, n - 1)
    grad = np.sum(valid_f * (1.0 - h[fc]) * w[None, :] - valid_s * h[sc] * w[None, :], axis=1)
    return obj, grad

def slsqp_local(h0, n, target_sum, alpha, maxiter=500):
    def f(h):
        return smooth_max_and_grad(h, alpha)[0]
    def g(h):
        return smooth_max_and_grad(h, alpha)[1]
    cons = [{'type': 'eq', 'fun': lambda x: np.sum(x) - target_sum,
             'jac': lambda x: np.ones(n)}]
    bounds = [(0.0, 1.0)] * n
    try:
        res = minimize(f, h0.copy(), method='SLSQP', jac=g,
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-14})
        return project_to_sum(res.x, target_sum)
    except Exception:
        return project_to_sum(h0.copy(), target_sum)

    pert = amplitude * np.sin(mode * np.pi * x + phase)
    h_new = project_to_sum(h + pert, n / 2.0)
    return h_new
