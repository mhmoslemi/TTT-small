def coordinate_descent_incremental(h, corr, target_sum, n, max_iters, rng):
    """Coordinate descent with incremental correlation updates."""
    h = h.copy()
    corr = corr.copy()
    c5 = float(np.max(corr) * 2.0 / n)
    
    for it in range(max_iters):
        # Find the active lag
        m_star = int(np.argmax(corr))
        k_star = m_star - (n - 1)
        
        # Choose coordinate to update
        # Gradient at active lag for each coordinate:
        # grad[j] = 1 - h[(j+k_star)%n] - h[(j-k_star)%n]
        g = 1.0 - h[(np.arange(n) + k_star) % n] - h[(np.arange(n) - k_star) % n]
        
        # We want to decrease the max correlation
        # Increasing h[j] by δ changes corr[k] by δ * grad[j] (for all k)
        # To decrease corr[k_star], we want grad[j] < 0 (increase h[j]) or grad[j] > 0 (decrease h[j])
        
        # Best move: find j that most decreases corr[k_star] while maintaining constraints
        can_inc = h < 1.0 - 1e-10
        can_dec = h > 1e-10
        
        # If we increase h[j] by δ: corr[k_star] changes by δ * g[j]
        # We want this to be negative, so g[j] < 0
        # If we decrease h[j] by δ: corr[k_star] changes by -δ * g[j]
        # We want this to be negative, so g[j] > 0
        
        best_delta = 0
        best_j = -1
        best_dir = 0  # +1 for increase, -1 for decrease
        
        for j in range(n):
            if can_inc[j] and g[j] < best_delta:
                best_delta = g[j]
                best_j = j
                best_dir = 1
            if can_dec[j] and (-g[j]) < best_delta:
                best_delta = -g[j]
                best_j = j
                best_dir = -1
        
        if best_j < 0:
            break
        
        # Determine step size (simple: try a few fractions)
        max_move = min(1.0 - h[best_j] if best_dir == 1 else h[best_j], 1.0)
        
        # Try multiple step sizes
        best_c5 = c5
        best_step = 0

Actually, for coordinate descent, I can handle the sum constraint by always doing a "swap": increase one coordinate and decrease another by the same amount. This automatically preserves the sum.

**Swap-based coordinate descent:**
1. Find the active lag k*
2. Compute the gradient g[j] = 1 - h[(j+k*)%n] - h[(j-k*)%n]
3. Find a pair (j_inc, j_dec) such that increasing h[j_inc] and decreasing h[j_dec] both decrease the objective
4. The condition is: g[j_inc] < 0 (increasing h[j_inc] helps) and g[j_dec] > 0 (decreasing h[j_dec] helps)
5. Actually, we need the net effect on the max to be negative.

For the swap h[j_inc] += δ, h[j_dec] -= δ:
Δcorr[k] = δ * (grad_k[j_inc] - grad_k[j_dec]) = δ * ((1-h[(j_inc+k)%n] - h[(j_inc-k)%n]) - (1-h[(j_dec+k)%n] - h[(j_dec-k)%n]))
= δ * (h[(j_dec+k)%n] + h[(j_dec-k)%n] - h[(j_inc+k)%n] - h[(j_inc-k)%n])

To decrease corr[k*], we want this to be negative for k = k*:
h[(j_dec+k*)%n] + h[(j_dec-k*)%n] < h[(j_inc+k*)%n] + h[(j_inc-k*)%n]

This is the condition for a beneficial swap at the active lag.

But we also need to make sure the max doesn't increase at other lags. This is harder to check in O(n) without computing the full update.

For a practical approach, I'll:
1. Do the swap
2. Check if the max decreased (approximately, by checking a random subset of lags)
3. If not, revert
