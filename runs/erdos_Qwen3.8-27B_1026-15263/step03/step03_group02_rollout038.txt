More precisely: for fixed h[0],...,h[i-1],h[i+1],...,h[n-1], the function f(h[i]) = max_k corr_k is a convex piecewise-linear function of h[i]. Its minimum over h[i] ∈ [0,1] can be found by checking the breakpoints (where the active set of k changes).

But in practice, the breakpoints are determined by where two different corr_k functions cross, which depends on all the other variables. This is complex but tractable for 1D optimization.

A simpler approach: use subgradient projection.
- f(h) = max_k corr_k(h)
- Subgradient at h: pick the k* that achieves the max (or a weighted average of the top few), and the subgradient is ∂corr_{k*}/∂h (or the weighted average of the gradients).
- Take a step: h_new = h - α · (subgradient - mean(subgradient)·1) [the subtraction of the mean projects onto the sum constraint]
- Project to [0,1]^n
- Adjust to satisfy sum constraint exactly

This is essentially what the previous code does with SLSQP, but we can make it more efficient by:
1. Using the exact subgradient (not smoothed max)
2. Using a better step size rule
3. Using the fact that the subgradient is sparse (each corr_k only involves O(n) variables)
