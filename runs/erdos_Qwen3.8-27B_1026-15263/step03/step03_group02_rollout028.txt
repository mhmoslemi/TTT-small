What about a "balanced" pattern? If we want D(k) to be as uniform as possible for all k, we want a sequence whose autocorrelation is as flat as possible. This is the "low autocorrelation" problem.

For a binary sequence of length n with n/2 ones, the periodic autocorrelation R(k) = sum_i a[i]*a[i+k] (mod n). We want R(k) to be as constant as possible. The average value of R(k) over all k (including k=0) is (n/2)²/n = n/4. So we want R(k) ≈ n/4 for all k ≠ 0, and R(0) = n/2.

This is related to "difference sets" and "BIBDs" (balanced incomplete block designs). A (v, k, λ) difference set in Z/vZ gives a sequence with:
- R(0) = k
- R(k) = λ for all k ≠ 0

We need v = n, k = n/2, and λ should be as close to (n/2)²/n - 1 = n/4 - 1... wait let me recompute.

For a difference set with parameters (v, k, λ): |D| = k, and for each nonzero g, |{(d1,d2) ∈ D×D : d1-d2 = g}| = λ.

The autocorrelation: R(g) = |{d ∈ D : d+g ∈ D}| = |D ∩ (D-g)|.

For a difference set: R(0) = k, R(g) = λ for g ≠ 0.

We need: k(k-1) = λ(v-1) (standard difference set equation).

With v = n, k = n/2: (n/2)(n/2 - 1) = λ(n-1), so λ = (n/2)(n/2-1)/(n-1) = n(n-2)/(4(n-1)).

Let me try a different approach: **iterative improvement with lookahead**.

Algorithm:
1. Start with a binary sequence (from parent or random)
2. Compute D(k) for all k
3. Find the worst shift k*
4. For each position i where a[i]=0 and a[i+k*]=1:
   - Try swapping a[i] with a[j] for j ≠ i, i+k*
   - Count how many "bad" pairs are eliminated vs created
5. Execute the best swap
6. Repeat

This is essentially a steepest-descent method but with a combinatorial objective. The key is step 4: we need a fast way to evaluate the impact of a swap.

For a swap of positions p and q (where a[p]=1, a[q]=0):
- For each shift k: D(k) changes by the amount that position p and q contribute.
- Position p contributes to D(k) as:
  - As a[i+k] (the "1" side): contributes (1-a[i]) for i = p-k (if valid)
  - As a[i] (the "0" side after switch): contributes a[i+k] for i = p (if valid)

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_to_sum(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(2000):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-13:
            break
        mask = (h > 1e-12) & (h < 1.0 - 1e-12)
        if np.any(mask):
            h[mask] += diff / np.sum(mask)
        else:
            h += diff / len(h)
        h = np.clip(h, 0.0, 1.0)
    return h

def make_binary(h, n, target_sum, rng):
    h_bin = (h > 0.5).astype(float)
    n_ones = int(np.sum(h_bin))
    if n_ones > target_sum:
        excess = n_ones - target_sum
        ones_idx = np.where(h_bin == 1.0)[0]
        order = np.argsort(h[ones_idx])[:excess]
        h_bin[ones_idx[order]] = 0.0
    elif n_ones < target_sum:
        deficit = target_sum - n_ones
        zeros_idx = np.where(h_bin == 0.0)[0]
        order = np.argsort(-h[zeros_idx])[:deficit]
        h_bin[zeros_idx[order]] = 1.0
    return h_bin

def thue_morse(n, target_ones, rng):
    t = np.zeros(1, dtype=np.float64)
    while len(t) < n:
        t = np.concatenate([t, 1.0 - t])
    t = t[:n].copy()
    n_ones = int(np.sum(t))
    if n_ones > target_ones:
        excess = n_ones - target_ones
        ones_idx = np.where(t == 1.0)[0]
        perm = rng.permutation(len(ones_idx))
        t[ones_idx[perm[:excess]]] = 0.0
    elif n_ones < target_ones:
        deficit = target_ones - n_ones
        zeros_idx = np.where(t == 0.0)[0]
        perm = rng.permutation(len(zeros_idx))
        t[zeros_idx[perm[:deficit]]] = 1.0
    return t

            if found_improve:
