**Idea: Block descent**
Instead of moving h[j] up and h[k] down, take a block h[j:L] and try to find new values that minimize the objective. This is a small subproblem.

Actually, for the block case, if we fix all other h values and vary h[j:j+L], the objective is:
max_k corr[k] where corr[k] depends on h[j:j+L] linearly (since corr is bilinear in h, but if we fix one set of indices and vary the other, it's linear in the varied indices).

Wait, corr[k] = sum_i h[i] * (1-h[i-k+n-1]). If we vary h[j:j+L], then:
- For terms where i is in [j, j+L-1]: h[i] * (1-h[i-k+n-1]) varies with h[i]
- For terms where i-k+n-1 is in [j, j+L-1]: h[i] * (1-h[i-k+n-1]) varies with h[i-k+n-1]

So it's not simply linear in the block variables. It's quadratic (bilinear).

However, if L is small (say 2-4), we can solve the subproblem approximately.

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_to_sum(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        mask = (h > 1e-14) & (h < 1.0 - 1e-14)
        if np.any(mask):
            h[mask] += diff / np.sum(mask)
        else:
            h += diff / len(h)
        h = np.clip(h, 0.0, 1.0)
    return h

def compute_B(h, j, n):
    nm1 = n - 1
    B = np.zeros(2 * n - 1)
    k_start = max(0, nm1 - j)
    k_end = min(2 * n - 2, 2 * nm1 - j)
    if k_start <= k_end:
        B[k_start:k_end + 1] += (1.0 - h[j - nm1 + np.arange(k_start, k_end + 1)])
    k_start2 = max(0, j)
    k_end2 = min(2 * n - 2, j + nm1)
    if k_start2 <= k_end2:
        B[k_start2:k_end2 + 1] += -h[j + nm1 - np.arange(k_start2, k_end2 + 1)]
    return B

def solve_1d(A, D, lo, hi):
    """Minimize max(A + D*t) over t in [lo, hi]."""
    if hi - lo < 1e-14:
        return (lo + hi) * 0.5
    # Coarse grid
    n_grid = 20
    t_grid = np.linspace(lo, hi, n_grid)
    vals = np.max(A[None, :] + D[None, :] * t_grid[:, None], axis=1)
    best_idx = int(np.argmin(vals))
    if best_idx == 0:
        return lo
    if best_idx == n_grid - 1:
        return hi
    lo_r = t_grid[best_idx - 1]
    hi_r = t_grid[best_idx + 1]
    # Binary search refinement
    for _ in range(40):
        mid = (lo_r + hi_r) * 0.5
        if np.max(A + D * mid) <= np.max(A + D * lo_r):
            lo_r = mid
        else:
            hi_r = mid
    return (lo_r + hi_r) * 0.5
```

Instead of coordinate descent, use a full gradient method on f(h) = log-sum-exp(alpha * corr) / alpha.

The gradient is:
∂f/∂h[j] = sum_k w_k * (∂corr[k]/∂h[j])

where w_k = alpha * exp(alpha * corr[k]) / sum_k' exp(alpha * corr[k'])

And ∂corr[k]/∂h[j] can be computed efficiently:
corr[k] = sum_i h[i] * (1 - h[i-k+n-1])
∂corr[k]/∂h[j] = (1 - h[j-k+n-1]) * [valid] + (-h[j+k-n+1]) * [valid]

This is exactly B_j[k] (the compute_B function gives the change in corr when h[j] increases by 1).

So the gradient is: grad[j] = dot(w, B_j) for all j.

But computing B_j for all j is O(n * (2n-1)) = O(n²), and the dot product with w is O(2n) per j, so total O(n²). For n=240, that's about 57K operations, which is fast.

Actually, we can vectorize this more efficiently. Let me think...

corr[k] = sum_i h[i] * (1 - h[i-k+n-1])

∂corr[k]/∂h[j] = (1 - h[j-k+n-1]) * [0<=j-k+n-1<n] + (-h[j+k-n+1]) * [0<=j+k-n+1<n]

Let me define:
A1[j,k] = (1 - h[j-k+n-1]) * [0<=j-k+n-1<n]
A2[j,k] = -h[j+k-n+1] * [0<=j+k-n+1<n]

grad[j] = sum_k w[k] * (A1[j,k] + A2[j,k])

For A1: j-k+n-1 = i means k = j+n-1-i. So:
sum_k w[k] * A1[j,k] = sum_i w[j+n-1-i] * (1-h[i]) * [0<=i<n]

This is a correlation of w with (1-h), evaluated at position j!
= np.corrcoef-like operation... actually it's:
sum_i (1-h[i]) * w[j+n-1-i] = convolve(1-h, w)[j+n-1] (with appropriate indexing)

Similarly for A2: j+k-n+1 = i means k = i+n-1-j.
sum_k w[k] * A2[j,k] = sum_i w[i+n-1-j] * (-h[i]) * [0<=i<n]
= -sum_i h[i] * w[n-1-j+i]
= -convolution of h with w at position n-1-j

So grad[j] = convolve(1-h, w)[j+n-1] - convolve(h, w)[n-1-j]

Let me verify: convolve(a, b)[m] = sum_i a[i] * b[m-i] (linear convolution)

    obj = m_val + max_s / alpha + np.log(sum_e) / alpha
    # Add penalty for sum constraint
    obj += 1000.0 * (np.sum(x) - target_sum) ** 2
    return obj

def _lbfgs_grad(x, alpha, target_sum, n):
    corr = np.correlate(x, 1.0 - x, mode="full")
    m_val = np.max(corr)
    shifted = alpha * (corr - m_val)
    max_s = np.max(shifted)
    exp_v = np.exp(shifted - max_s)
    sum_e = np.sum(exp_v)
    w = alpha * exp_v / sum_e
    corr_1h_w = np.correlate(1.0 - x, w, mode="full")
    w_flip = w[::-1]
    corr_h_wf = np.correlate(x, w_flip, mode="full")
    nm1 = n - 1
    grad = corr_1h_w[nm1:nm1+n] - corr_h_wf[nm1:nm1+n]
    # Add gradient of penalty
    grad += 2000.0 * (np.sum(x) - target_sum)
    return grad

def compute_c5(h):

def project_to_sum(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break

            h += diff / len(h)
        h = np.clip(h, 0.0, 1.0)

def compute_B(h, j, n):
    nm1 = n - 1
    B = np.zeros(2 * n - 1)
    ks = max(0, nm1 - j)

    if ks2 <= ke2:

    return B
