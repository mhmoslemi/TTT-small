1. Accurately identify the critical lags
2. Move in the direction that reduces the maximum most efficiently

The direction that reduces the maximum most efficiently is the negative of the gradient of the active lags (normalized). This is the "Chebyshev direction" in minimax optimization.

**Chebyshev direction**: At each point, compute the gradients of all active lags. The Chebyshev direction is the direction d that minimizes max_k ∇f_kᵀ d, subject to ||d|| = 1. This is a convex optimization problem (minimize the max of linear functions).

In practice, we can approximate this with a weighted average: d = -Σ w_k ∇f_k / ||Σ w_k ∇f_k|| where w_k is proportional to exp(α * f_k) (softmax weights).

This is essentially what the smooth max gradient already gives us! So the projected gradient method with smooth max IS following the Chebyshev direction (approximately).

The issue is the step size. With a fixed or slowly-decaying step size, we might oscillate or converge slowly. We need a good line search or adaptive step size.

Check: h[3] appears as h[i+s] in the third term (i=2, i+s=3): derivative is (1-h[2]) = 0.3.
h[3] doesn't appear in any (1-h[i]) term (since i+s would be 4 which is out of range).
Total: 0.3 ✓

So the gradient formulas are:
For s ≥ 0:
∂c[k]/∂h[j] = (1-h[j-s]) * [s ≤ j ≤ n-1] - h[j+s] * [0 ≤ j ≤ n-1-s]

For s < 0 (t = -s):
∂c[k]/∂h[j] = (1-h[j+t]) * [0 ≤ j ≤ n-1-t] - h[j-t] * [t ≤ j ≤ n-1]

Now, for the total gradient (smooth max over active lags with weights w_k):
∇obj = Σ_k w_k * dx * ∂c[k]/∂h

Let me now write efficient code for this.

Actually, I realize I can vectorize this nicely. For each active lag with shift s:
- If s ≥ 0:
  - grad[s:n] += w*dx * (1 - h[0:n-s])  (first term: j from s to n-1, h[j-s] from h[0] to h[n-1-s])
  - grad[0:n-s] -= w*dx * h[s:n]  (second term: j from 0 to n-1-s, h[j+s] from h[s] to h[n-1])
- If s < 0 (t = -s):
  - grad[0:n-t] += w*dx * (1 - h[t:n])  (first term: j from 0 to n-1-t, h[j+t] from h[t] to h[n-1])
  - grad[t:n] -= w*dx * h[0:n-t]  (second term: j from t to n-1, h[j-t] from h[0] to h[n-1-t])

This is very efficient! Each active lag only requires two slice operations.

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_to_sum(h, target_sum):
    h = np.clip(h.astype(float).copy(), 0.0, 1.0)
    for _ in range(200):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-13:
            break
        mask = (h > 1e-12) & (h < 1.0 - 1e-12)
        if np.sum(mask) > 0:
            h[mask] += diff / np.sum(mask)
        else:
            break
        h = np.clip(h, 0.0, 1.0)
    return h

def get_correlation(h):
    return np.correlate(h, 1.0 - h, mode="full")

def active_gradient(h, corr, dx, m=30, alpha=100.0):
    """Compute smooth max objective and gradient using top m lags."""
    n = len(h)
    nc = len(corr)
    
    if m >= nc:
        idx_all = np.arange(nc)
    else:
        idx_all = np.argsort(corr)[-m:]
    
    vals = corr[idx_all]
    vals_shifted = vals - vals.max()
    exp_v = np.exp(alpha * vals_shifted)
    w = exp_v / np.sum(exp_v)
    obj = vals.max() + np.log(np.sum(exp_v)) / alpha
    
    grad = np.zeros(n)
    for ii in range(len(idx_all)):
        k = idx_all[ii]
        s = k - (n - 1)
        wi = w[ii] * dx
        
        if s >= 0:
            ns = n - s
            if ns > 0:
                grad[s:] += wi * (1.0 - h[:ns])
                grad[:ns] -= wi * h[s:]
        else:
            t = -s
            nt = n - t
            if nt > 0:
                grad[:nt] += wi * (1.0 - h[t:])
                grad[t:] -= wi * h[:nt]
    
    return obj, grad
