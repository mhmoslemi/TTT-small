Actually, computing the gradient of O_k for a specific lag k is straightforward:
O_k = Σ_i h[i]·(1-h[i+k]) (with periodic indexing)
∂O_k/∂h[i] = (1-h[(i+k) mod n]) + (-1)·h[i-k] (the second term comes from the fact that h[i] also appears in the term where i = j+k, i.e., h[j]·(1-h[j+k]) with j+k = i, so j = i-k)

Wait, more carefully:
O_k = Σ_j h[j]·(1-h[(j+k) mod n])

∂O_k/∂h[i]:
- h[i] appears in the first factor when j = i: contribution (1-h[(i+k) mod n])
- h[i] appears in the second factor when (j+k) mod n = i, i.e., j = (i-k) mod n: contribution h[(i-k) mod n]·(-1) = -h[(i-k) mod n]

So ∂O_k/∂h[i] = (1-h[(i+k) mod n]) - h[(i-k) mod n]

This is clean and O(n) per lag. For the max of, say, 3 active lags, the total gradient computation is O(3n) = O(n).

def subgradient_method(h, n, ts, n_iter, lr_init):
    h = h.copy()
    lr = lr_init
    obj_prev = compute_c5(h)
    for i in range(n_iter):
        corr_vals = np.correlate(h, 1-h, mode="full") * (2.0/n)
        max_val = np.max(corr_vals)
        # Find active lags (within tolerance of max)
        tol = 1e-4
        active_lags = np.where(corr_vals >= max_val - tol)[0] - (n-1)
        # Compute subgradient
        grad = np.zeros(n)
        for k in active_lags:
            idx_k = (np.arange(n) + k) % n
            idx_mk = (np.arange(n) - k) % n
            grad += (1 - h[idx_k]) - h[idx_mk]
        grad /= len(active_lags)
        # Step
        h_new = project_to_sum(h - lr * grad, ts)
        obj_new = compute_c5(h_new)
        if obj_new < obj_prev:
            h = h_new
            obj_prev = obj_new
            lr *= 1.01
        else:
            lr *= 0.9
        # Adaptive learning rate
        lr = max(1e-6, min(lr, 0.1))
    return h, obj_prev
```

Let me now think about the **directed pair exchange** approach more carefully.

At the optimum, most h_i are at 0 or 1 (by the complementarity condition of KKT). The "free" variables (0 < h_i < 1) are few. For these free variables, the KKT condition says:
Σ_{k∈Active} λ_k · ∂O_k/∂h_i + μ = 0

This means the "effective gradient" (weighted sum of active lag gradients) is constant over all free variables. If this isn't the case, we can improve by transferring mass from a free variable with higher effective gradient to one with lower.

**Directed pair exchange algorithm:**
1. Identify free variables: F = {i : 1e-4 < h_i < 1 - 1e-4}
2. For each i ∈ F, compute g_i = Σ_{k∈Active} λ_k · ∂O_k/∂h_i (using λ_k = 1 for simplicity, or solving for optimal λ)
3. Find pairs (i, j) with i, j ∈ F or (i ∈ F, j at boundary) such that transferring mass from i to j reduces C₅
4. Execute the best transfer

Actually, for a simpler version:
1. Compute the exact gradient of C₅ (using subgradient for the max)
2. For each pair (i, j) where h_i > 0.01 and h_j < 0.99:
   - Estimate ΔC₅ ≈ δ·(g_j - g_i) where g = subgradient and δ is the transfer amount
   - If g_j < g_i, transferring from i to j should decrease C₅
3. Execute the best transfer
4. Repeat

This is essentially a specialized projected gradient method. The key advantage over the previous random CD is that it's directed.

def subgradient_step(h, n, ts, active_lags, lr):
    """One subgradient step. active_lags is a list of L values (integers, can be negative)."""
    g = np.zeros(n)
    for L in active_lags:
        if L >= 0:
            # First factor: 0 <= i < n-L
            g[:n-L] += (1 - h[L:])  # h[i+L] for i in [0, n-L)
            # Second factor: L <= i < n
            g[L:] -= h[:n-L]  # h[i-L] for i in [L, n)
        else:
            m = -L
            # First factor: m <= i < n (i.e., -L <= i < n)
            g[m:] += (1 - h[:n-m])  # h[i+L] = h[i-m] for i in [m, n), h[i-m] for i-m in [0, n-m)
            # Second factor: 0 <= i < n-m
            g[:n-m] -= h[m:]  # h[i-L] = h[i+m] for i in [0, n-m), h[i+m] for i+m in [m, n)
    g /= len(active_lags)
    h_new = project_to_sum(h - lr * g, ts)
    return h_new
```
