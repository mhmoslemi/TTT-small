Actually, I realize the solve_1d function can be optimized. Instead of 60 evaluations, I can use the fact that we're minimizing a convex piecewise-linear function. The minimum occurs at a "kink" point, which is where two or more of the (A + D*t) values are tied for the maximum.

A faster approach: the minimum of max(A + D*t) over t ∈ [lo, hi] occurs at a point where the subgradient contains 0. The subgradient is the convex hull of {D[i] : A[i] + D[i]*t = max(A + D*t)}.

So I need to find t such that 0 is in the convex hull of {D[i] : i ∈ argmax(A + D*i)}. This is a 1D problem: I need min(D[i] for i in active) ≤ 0 ≤ max(D[i] for i in active).

This can be found by:
1. Sort the D values
2. For each possible active set (determined by the ordering of A + D*t), check if 0 is in the convex hull of the active D values
3. The active set changes at "breakpoints" where A[i] + D[i]*t = A[j] + D[j]*t

This is related to the "lower envelope" problem. But it's complex to implement efficiently.

A simpler approach: use the bisection method on the subgradient. The function f(t) = max_i (A[i] + D[i]*t) is convex. The subgradient at t is the convex hull of {D[i] : i ∈ argmax}. So:
- If all active D[i] > 0, the function is increasing at t, so the minimum is to the left
- If all active D[i] < 0, the function is decreasing at t, so the minimum is to the right
- Otherwise, t is optimal (or very close)

This gives a simple bisection on the sign of the subgradient:
```python
def solve_1d_fast(A, D, lo, hi):
    for _ in range(50):
        mid = (lo + hi) * 0.5
        f_mid = A + D * mid
        max_val = np.max(f_mid)
        active = np.where(f_mid >= max_val - 1e-12)[0]
        if len(active) == len(D):
            return mid
        min_D = D[active].min()
        max_D = D[active].max()
        if min_D > 0:
            hi = mid  # function increasing, go left
        elif max_D < 0:
            lo = mid  # function decreasing, go right
        else:
            return mid  # 0 in subgradient, optimal
    return (lo + hi) * 0.5
```

This is O(n) per iteration and 50 iterations, so O(n) total per pair. Much faster!

Let me verify: the function f(t) = max(A + D*t) is convex (max of linear functions). Its derivative (where it exists) is D[i*] where i* = argmax. The subgradient at t is conv({D[i] : A[i] + D[i]*t = f(t)}). 

For a convex function, the minimum is where 0 ∈ ∂f(t). Since f is piecewise linear with kinks at the breakpoints, the minimum is either at a kink or at a boundary.

The bisection works because:
- If min(D[active]) > 0: all active slopes are positive, so f is increasing at t, meaning the minimum is to the left. So we set hi = mid.
- If max(D[active]) < 0: all active slopes are negative, so f is decreasing at t, meaning the minimum is to the right. So we set lo = mid.
- Otherwise: 0 is in the subgradient, so t is a minimizer.

This should converge in O(log((hi-lo)/ε)) iterations. With 50 iterations and initial interval of at most 1, we get precision of about 10^{-15}.

This is much faster than the original solve_1d which did 60 evaluations of np.max on the full vector. Let me use this.

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_to_sum(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        mask = (h > 1e-12) & (h < 1.0 - 1e-12)
        if np.any(mask):
            h[mask] += diff / np.sum(mask)
        else:
            h += diff / len(h)
        h = np.clip(h, 0.0, 1.0)
    return h

def compute_all_B(h, n):
    nm1 = n - 1
    all_B = np.zeros((n, 2 * n - 1))
    one_minus_h = 1.0 - h
    neg_h_rev = -h[::-1].copy()
    for j in range(n):
        all_B[j, nm1 - j: 2 * n - 1 - j] += one_minus_h
        all_B[j, j:j + n] += neg_h_rev
    return all_B

def solve_1d_fast(A, D, lo, hi):
    if hi - lo < 1e-14:
        return (lo + hi) * 0.5
    f0_max = np.max(A)
    f_lo_max = np.max(A + D * lo)
    f_hi_max = np.max(A + D * hi)
    if f0_max <= f_lo_max + 1e-13:
        return lo
    if f0_max <= f_hi_max + 1e-13:
        return hi
    for _ in range(50):
        mid = (lo + hi) * 0.5
        f_mid = A + D * mid
        max_val = np.max(f_mid)
        active = np.where(f_mid >= max_val - 1e-10)[0]
        min_D = D[active].min()
        max_D = D[active].max()
        if min_D > 1e-15:
            hi = mid
        elif max_D < -1e-15:
            lo = mid
        else:
            return mid
    return (lo + hi) * 0.5

def full_pair_sweep(h, corr, all_B, n):
    n_improved = 0
    for j in range(n):
        B_j = all_B[j]
        best_val = np.max(corr)
        best_delta = 0.0
        best_k = -1
        for k in range(n):
            if k == j:
                continue
            D = B_j - all_B[k]
            delta_lo = max(-h[j], h[k] - 1.0)
            delta_hi = min(1.0 - h[j], h[k])
            if delta_hi - delta_lo < 1e-13:
                continue
            delta_opt = solve_1d_fast(corr, D, delta_lo, delta_hi)
            if abs(delta_opt) < 1e-13:
                continue
            val_opt = np.max(corr + D * delta_opt)
            if val_opt < best_val - 1e-12:
                best_val = val_opt
                best_delta = delta_opt
                best_k = k
        if best_k >= 0 and abs(best_delta) > 1e-12:
            D_best = B_j - all_B[best_k]
            corr += best_delta * D_best
            h[j] = np.clip(h[j] + best_delta, 0.0, 1.0)
            h[best_k] = np.clip(h[best_k] - best_delta, 0.0, 1.0)
            n_improved += 1
    return h, corr, n_improved

def subgradient_step(h, corr, n, active_frac=0.1, step_size=0.01):
    """Take a subgradient step to reduce the max correlation."""
    nm1 = n - 1
    max_val = np.max(corr)
    threshold = max_val - 0.01 * (max_val - np.min(corr))
    active = np.where(corr >= threshold)[0]
    if len(active) == 0:
        active = np.where(corr >= max_val - 1e-10)[0]
    
    # Compute subgradient
    # grad[j] = sum_{m in active} w_m * B_j[m]
    # where w_m are weights (uniform over active set)
    all_B = compute_all_B(h, n)
    grad = np.mean(all_B[:, active], axis=1)
    
    # Take step in negative gradient direction
    h_new = h - step_size * grad
    h_new = project_to_sum(h_new, n / 2.0)
    
    return h_new
```

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_to_sum(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        mask = (h > 1e-12) & (h < 1.0 - 1e-12)
        if np.any(mask):
            h[mask] += diff / np.sum(mask)
        else:
            h += diff / len(h)
        h = np.clip(h, 0.0, 1.0)
    return h

def compute_all_B(h, n):
    nm1 = n - 1
    all_B = np.zeros((n, 2 * n - 1))
    one_minus_h = 1.0 - h
    neg_h_rev = -h[::-1].copy()
    for j in range(n):
        all_B[j, nm1 - j: 2 * n - 1 - j] += one_minus_h
        all_B[j, j:j + n] += neg_h_rev
    return all_B

def solve_1d_fast(A, D, lo, hi):
    if hi - lo < 1e-14:
        return (lo + hi) * 0.5
    f0 = A
    f_lo = A + D * lo
    f_hi = A + D * hi
    max0 = np.max(f0)
    max_lo = np.max(f_lo)
    max_hi = np.max(f_hi)
    if max0 <= max_lo + 1e-13:
        return lo
    if max0 <= max_hi + 1e-13:
        return hi
    for _ in range(50):
        mid = (lo + hi) * 0.5
        f_mid = A + D * mid
        max_val = np.max(f_mid)
        active = np.where(f_mid >= max_val - 1e-10)[0]
        min_D = D[active].min()
        max_D = D[active].max()
        if min_D > 1e-15:
            hi = mid
        elif max_D < -1e-15:
            lo = mid
        else:
            return mid
    return (lo + hi) * 0.5

def full_pair_sweep(h, corr, all_B, n):
    n_improved = 0
    for j in range(n):
        B_j = all_B[j]
        best_val = np.max(corr)
        best_delta = 0.0
        best_k = -1
        for k in range(n):
            if k == j:
                continue
            D = B_j - all_B[k]
            delta_lo = max(-h[j], h[k] - 1.0)
            delta_hi = min(1.0 - h[j], h[k])
            if delta_hi - delta_lo < 1e-13:
                continue
            delta_opt = solve_1d_fast(corr, D, delta_lo, delta_hi)
            if abs(delta_opt) < 1e-13:
                continue
            val_opt = np.max(corr + D * delta_opt)
            if val_opt < best_val - 1e-12:
                best_val = val_opt
                best_delta = delta_opt
                best_k = k
        if best_k >= 0 and abs(best_delta) > 1e-12:
            D_best = B_j - all_B[best_k]
            corr += best_delta * D_best
            h[j] = np.clip(h[j] + best_delta, 0.0, 1.0)
            h[best_k] = np.clip(h[best_k] - best_delta, 0.0, 1.0)
            n_improved += 1
    return h, corr, n_improved

def subgradient_polish(h, n, max_iters=100):
    ts = n / 2.0
    corr = np.correlate(h, 1.0 - h, mode="full")
    v = np.zeros(n)
    beta = 0.9
    step = 0.02
    for it in range(max_iters):
        all_B = compute_all_B(h, n)
        max_val = np.max(corr)
        spread = max_val - np.min(corr)
        if spread < 1e-10:
            break
        threshold = max_val - 0.08 * spread
        active = np.where(corr >= threshold)[0]
        if len(active) == 0:
            active = np.where(corr >= max_val - 1e-10)[0]
        grad = np.mean(all_B[:, active], axis=1)
        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-14:
            break
        grad = grad / gnorm
        v = beta * v - step * grad
        h = project_to_sum(h - v, ts)
        corr = np.correlate(h, 1.0 - h, mode="full")
        step *= 0.97
    return h
```
