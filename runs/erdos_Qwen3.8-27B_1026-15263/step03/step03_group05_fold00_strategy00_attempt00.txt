## 2. Mathematical specification
**Representation**: h(x) is discretized into n-point samples, represented by binary vector h ∈ {0, 1}^{n}
**Variables**: Integer vector h, autocorrelation matrix C
**Objective**: Minimize C₅ = max_{k=[-n+1, n-1]} ∫h(x)(1-h(x+k))dx, computed via:
    dx = 2.0/n
    corr = np.correlate(h, 1-h, mode='full')
    C₅ = max(corr) * dx
**Constraints**: 
    - ∑h_i * dx = 1 → ∑h_i = n/2 (must hold exactly through bit-count enforcement)
    - 0 ≤ h_i ≤ 1 (handled by binary nature)

Binary optimization method (with surrogate):

    Minimize f(h) = max_k corr(h,1-h)
    Under: |h|_count = n/2 (exactly n/2 ones)
    |h|_count = n/2 is maintained by specialized bit-flips

**Algorithm**: Hill-climb with structured swaps (flipping bits in a coordinated manner across time-shifts), guided by autocorrelation landscape analysis

**Formulation**: Objective surrogate is directly the Erdős evaluation. Constraints require integer solution exactly.
