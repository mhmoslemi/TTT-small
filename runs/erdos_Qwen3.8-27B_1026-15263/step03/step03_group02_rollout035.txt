def project_to_sum(h, target_sum):

def swap_delta(h, i, j, n):
    """Compute the change in cross-correlation when swapping h[i] (0->1) and h[j] (1->0)."""
    # corr[m] = sum_k h[k] * (1-h[k-m+n-1]) for valid k-m+n-1

The bottleneck is the swap search. Let me think about how to speed it up.

For the greedy approach, I want to find the swap (i,j) that minimizes the new max correlation. The new max is:
new_max = max_m [corr[m] + Δcorr_{i,j}[m]]

Since corr[m] is known and Δcorr_{i,j}[m] ∈ {-1, 0, 1} for binary, the new max is in {max(corr)-1, max(corr), max(corr)+1}.

To find if new_max = max(corr)-1 is achievable, I check the conditions I described earlier.
If not, I try to find the swap that minimizes new_max (which will be max(corr) or max(corr)+1).

Let me implement a two-phase search:
Phase A: Try to find a swap that reduces max by 1
Phase B: If not found, find the swap that keeps max the same (minimizes the "spread")

For phase A, the conditions are:
- For all m in A: Δcorr[m] = -1
- For all m in B: Δcorr[m] ≤ 0

For phase B (keep max the same), the conditions are:
- For all m in A: Δcorr[m] ≤ 0
- For all m with corr[m] = max-1: Δcorr[m] ≤ 1 (always true since Δ ≤ 1)
- Actually, we need: for all m, corr[m] + Δcorr[m] ≤ max, i.e., Δcorr[m] ≤ max - corr[m]
  For m in A: Δcorr[m] ≤ 0 (i.e., Δcorr[m] ∈ {-1, 0})
  For m in B: Δcorr[m] ≤ 1 (always true)
  For m with corr[m] < max-1: no constraint

So for phase B, the condition is just: for all m in A, Δcorr[m] ≤ 0.
This means: for all m in A, v_i(m) ≤ v_j(m), i.e., (1-h[i-m+n-1])*valid_i ≤ (1-h[j-m+n-1])*valid_j.

This is less restrictive than phase A, so more swaps will satisfy it.

Among phase B swaps, I want to pick one that minimizes the new max. The new max for a phase B swap is:
new_max = max(max over m not in A of (corr[m] + Δcorr[m]), max over m in A of (corr[m] + Δcorr[m]))
= max(max over m not in A of (corr[m] + Δcorr[m]), max_val)  [since for m in A, corr[m]+Δ≤max_val]
= max(max_val, max over m not in A of (corr[m] + Δcorr[m]))

For m not in A with corr[m] = max-1 (i.e., m in B): corr[m] + Δcorr[m] ≤ max-1+1 = max. So these don't exceed max.
For m not in A with corr[m] < max-1: corr[m] + Δcorr[m] ≤ max-2+1 = max-1 < max.

So for any phase B swap, new_max = max_val (the max stays the same). The "quality" of the swap is determined by how many positions in A get Δcorr = -1 (reducing them) vs Δcorr = 0 (keeping them). More reductions means the max is "more fragile" and easier to reduce in a future step.

So among phase B swaps, I should pick the one that maximizes the number of positions in A where Δcorr = -1.

Let me implement this:

For a swap (i,j), the number of positions in A where Δcorr = -1 is:
count = |{m in A : v_i(m) = 0 and v_j(m) = 1}|

where v_i(m) = (1-h[i-m+n-1]) if valid, else 0
and v_j(m) = (1-h[j-m+n-1]) if valid, else 0

For phase A (reduce max by 1): we need count = |A| (all positions in A get Δ=-1) AND the B condition.
For phase B (keep max): we need all positions in A to have v_i(m) ≤ v_j(m). Among these, maximize count.

This gives us a scoring function for each candidate swap.

Let me now code this up efficiently. The key is to avoid the O(n² * |A|) loop. Can I vectorize?

For each j in ones (n/2 candidates), I can compute the vector v_j over all of A:
v_j_A[j] = [(1-h[j-m+n-1]) * valid(j, m) for m in A]

This is an array of shape (n/2, |A|). Computing it requires: for each j and each m in A, compute j-m+n-1 and check bounds. This is O(n * |A|) operations.

Similarly for each i in zeros: v_i_A[i] = [(1-h[i-m+n-1]) * valid(i, m) for m in A]

Then for each pair (i, j):
- count_A(i,j) = sum over m in A of [v_i_A[i,m] == 0 and v_j_A[j,m] == 1]
- For phase A: need count_A(i,j) == |A| AND B condition
- For phase B: need sum over m in A of [v_i_A[i,m] > v_j_A[j,m]] == 0, and maximize count_A

The B condition for phase A:
For all m in B: v_i_B(i,m) ≤ v_j_B(j,m)

I can compute v_i_B and v_j_B similarly.
