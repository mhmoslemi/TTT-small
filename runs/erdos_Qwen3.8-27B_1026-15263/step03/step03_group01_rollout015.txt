3. Update h in the direction that reduces the gap

Let me think about the active-set gradient more carefully. If I have m active lags, the objective is:
f(h) = sum_{j=1}^{m} w_j * O_{k_j}(h)

where w_j are weights (from multiplicative weights or uniform).

The gradient is:
∇f(h) = sum_{j=1}^{m} w_j * ∇O_{k_j}(h)

For a single lag k (≥ 0):
O_k = dx * sum_{i=0}^{n-1-k} h[i]*(1-h[i+k])
∇O_k[i] = dx * (1 - h[i+k]) for i in [0, n-1-k]
∇O_k[i] = dx * (-h[i-k]) for i in [k, n-1]
(both apply if k ≤ i ≤ n-1-k)

So for i in [k, n-1-k]: ∇O_k[i] = dx * (1 - h[i+k] - h[i-k])
For i in [0, k-1]: ∇O_k[i] = dx * (1 - h[i+k])
For i in [n-k, n-1]: ∇O_k[i] = dx * (-h[i-k])

This is O(n) to compute for a single lag. For m lags, it's O(mn). With m=20 and n=480, that's 9600 operations per gradient, which is very fast.

The Hessian for a single lag k:
H_k[i,i+k] = -dx (for i in [0, n-1-k])
H_k[i+k,i] = -dx (same)
All other entries are 0.

So H_k is a banded matrix with -dx on the k-th off-diagonals. The total Hessian is:
H = sum_j w_j * H_{k_j}

This is a sum of banded matrices, which is still relatively sparse. We could use this for a Newton step, but L-BFGS should work well enough.

Let me also think about a key structural observation:

The overlap O_k = dx * sum_{i=0}^{n-1-k} h[i]*(1-h[i+k])

For the maximum to be small, we need ALL O_k to be small. This means:
- For small k: the function shouldn't have adjacent values that are both high (or one high, one low in a way that maximizes the product)
- For large k: less constraint since the sum has fewer terms

Actually, O_k = dx * (partial_sum - cross_term) where:
partial_sum = sum_{i=0}^{n-1-k} h[i] (decreases as k increases)
cross_term = sum_{i=0}^{n-1-k} h[i]*h[i+k]

To minimize O_k, we want the cross_term to be large relative to the partial_sum. Since h[i] ≤ 1, the maximum cross_term for a given partial_sum is achieved when h[i+k] = 1 wherever h[i] is large. This suggests that h should have a "shifted self-similarity" property: h(x) should look like h(x+k) for the critical k values.

This is reminiscent of **almost-periodic** or **quasi-periodic** functions!

A function that is "almost periodic" with period k would have h[i+k] ≈ h[i], which maximizes the cross_term. But we need this for MULTIPLE k values simultaneously, which is the crux of the problem.

If h has period p (in the sense h(x) = h(x+p)), then for k = p, the cross_term = sum h[i]² and partial_sum = sum h[i] (over the truncated range), giving O_p ≈ dx * (sum h - sum h²) which is O_0-like.

This suggests that the optimal h might have a quasi-periodic structure with multiple "near-periods."

For a function on [0,2] (length 2), if it has near-period 1/3, then it's roughly 3 times "repeated." Let's try h with period 2/3 (3 repeats of a pattern of length 2/3).

With 3 repeats: h(x) = p(x mod 2/3) for some pattern p of length 2/3.
∫₀² h = 3 * ∫₀^{2/3} p = 1, so ∫₀^{2/3} p = 1/3.
Mean of p is (1/3)/(2/3) = 1/2.

For k = 2/3 (one period): h(x) = h(x+k) approximately, so cross_term ≈ sum h² and O_k ≈ O_0 = dx*(n/2 - sum h²).

For k = 1/3 (half period): h(x+1/3) is the "other half" of the pattern.

    O = compute_all_overlaps(h)
    center = n - 1
    O_half = O[center:]  # lags 0 to n-1, length n
    
    # Soft max value
    shifted = O_half / temperature
    shifted -= np.max(shifted)
    exp_vals = np.exp(shifted)
    w = exp_vals / np.sum(exp_vals)
    soft_max = np.max(O_half) + temperature * (np.log(np.sum(exp_vals)))  # Actually: max + T*log(sum(exp))
    # More precisely: soft_max = T * log(sum(exp(O/T)))
    # = T * log(sum(exp((O - max_O)/T)) * exp(max_O/T))
    # = max_O + T * log(sum(exp((O-max_O)/T)))
    # But we already computed shifted = O/T - max_O/T
    # So soft_max = max_O + T * log(sum(exp(shifted)))
    # Hmm, let me just use the weighted sum as the objective
    obj = float(np.dot(w, O_half))
    
    # Gradient: only for lags with significant weight
    sig_mask = w > 1e-6
    sig_idx = np.where(sig_mask)[0]
    
    grad = np.zeros(n)
    for k in sig_idx:
        wk = w[k]
        if k == 0:
            grad += wk * (1.0 - 2.0 * h)
        else:
            grad[:n-k] += wk * (1.0 - h[k:])
            grad[k:] += wk * (-h[:-k])
    
    return obj, grad

import numpy as np
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def compute_all_overlaps(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return corr * dx

def project_to_sum(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(300):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        mask = (h > 1e-12) & (h < 1.0 - 1e-12)
        if np.any(mask):
            h[mask] += diff / np.sum(mask)
        else:
            h += diff / len(h)
        h = np.clip(h, 0.0, 1.0)
    return h

def smooth_max_objective_and_grad(h, temperature):
    n = len(h)
    O = compute_all_overlaps(h)
    center = n - 1
    O_half = O[center:]
    shifted = O_half / temperature

            grad += wk * (1.0 - 2.0 * h)
        else:
            grad[:n-k] += wk * (1.0 - h[k:])
            grad[k:] += wk * (-h[:-k])
    return obj, grad

def hard_topm_objective_and_grad(h, m_top):
    n = len(h)
    O = compute_all_overlaps(h)
    center = n - 1
    O_half = O[center:]
    if m_top < n:
        top_idx = np.argpartition(O_half, -m_top)[-m_top:]
    else:
        top_idx = np.arange(n)
    active_O = O_half[top_idx]
    obj = float(np.sum(active_O))
    grad = np.zeros(n)
    for k in top_idx:
        if k == 0:
            grad += (1.0 - 2.0 * h)
        else:
            grad[:n-k] += (1.0 - h[k:])
            grad[k:] += (-h[:-k])
    return obj, grad

def projected_momentum_opt(h0, n, ts, temp_init=0.05, temp_min=0.001, n_iter=5000, lr_init=0.04, momentum=0.85, use_hard_top=False, m_top=30):
    h = h0.copy()
    v = np.zeros(n)
    lr = lr_init
    temp = temp_init
    best_c5 = compute_c5(h)
    best_h = h.copy()
    best_smooth = float('inf')
    stall = 0
    
    for it in range(n_iter):
        if use_hard_top:
            obj, grad = hard_topm_objective_and_grad(h, m_top)
        else:
            obj, grad = smooth_max_objective_and_grad(h, temp)
        
        if obj < best_smooth - 1e-12:
            best_smooth = obj
            stall = 0
        else:
            stall += 1
            if stall > 200:
                break
        
        v = momentum * v - lr * grad
        h_new = project_to_sum(h + v, ts)
        h = h_new
        
        c5_cur = compute_c5(h)
        if c5_cur < best_c5:
            best_c5 = c5_cur
            best_h = h.copy()

        lr = max(1e-8, lr * 0.9995)
    
    return best_h, best_c5

def freq_perturb(h, rng, n_harm, amp):
    n = len(h)
    mean_h = np.mean(h)
    H = np.fft.rfft(h - mean_h)
    upper = min(n_harm, n // 2 - 1)
    for k in range(1, upper + 1):
        H[k] += amp * complex(rng.randn(), rng.randn())
    h_new = np.fft.irfft(H, n=n) + mean_h
    return project_to_sum(h_new, n // 2.0)

def block_flip_perturb(h, rng, ts):
    n = len(h)
    h_new = h.copy()
    blk = rng.randint(10, max(15, n // 8))
    start = rng.randint(0, n - blk)
    h_new[start:start+blk] = 1.0 - h_new[start:start+blk]
    return project_to_sum(h_new, ts)

def multi_scale_perturb(h, rng, ts):
    n = len(h)
    scale = rng.choice([2, 3, 4, 5, 7])
    low = np.interp(np.arange(n, dtype=float), np.arange(n, dtype=float) / scale, 
                    np.interp(np.arange(n // scale), np.arange(n), h))
    high = h - low
    h_new = low + rng.uniform(0.5, 2.0) * high
    return project_to_sum(h_new, ts)

def make_block_start(n, n_blocks, ts):
    h = np.zeros(n)
    blk = n // (2 * n_blocks)
    for i in range(0, n, 2 * blk):
        h[i:min(i+blk, n)] = 1.0
    return project_to_sum(h, ts)

def make_sinusoidal_start(n, freq, phase, amp):
    x = np.linspace(0, 2, n, endpoint=False)
    h = 0.5 + amp * np.sin(np.pi * freq * x + phase)
    return project_to_sum(h, n / 2.0)

    x = np.linspace(0, 2, n, endpoint=False)

    h = 0.5 + 0.3 * h / (np.max(np.abs(h)) + 1e-10)
