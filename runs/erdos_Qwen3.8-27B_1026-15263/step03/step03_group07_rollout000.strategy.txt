$$0 \leq h(x) \leq 1, \quad \int_0^2 h(x)\,dx = 1$$

For discrete implementation with dx=2/n:
$$C_5 = \max_k \left[\left(\frac{2}{n}\right) \cdot \text{autocorrelation}(h,k) \right]$$

The algorithm uses:
- Discrete domain with n points uniformly spaced in [0,2]
- Stepwise coordinate updates with bitmask selection
- Stochastic gradient descent with adaptive learning rate
- Non-gradient-based binary push refinement
- Resolution-aware interpolation and feasibility restoration

The solution vector h is kept as a NumPy array of length n, values must satisfy:
$$\sum_i h[i] dx = 1$$
$$0 \leq h[i] \leq 1 \forall i$$
