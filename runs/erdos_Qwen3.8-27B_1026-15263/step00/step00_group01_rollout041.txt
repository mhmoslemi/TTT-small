Let me define the "shift" for lag k: s_k = n - 1 - k. Then:
f_k(h) = sum_i h[i] * (1-h[i+s_k]) where 0 <= i < n and 0 <= i+s_k < n.

The valid range of i: 0 <= i < n and -s_k <= i < n-s_k.
So i ranges from max(0, -s_k) to min(n-1, n-1-s_k) = min(n-1, n-1-s_k).

If s_k >= 0 (i.e., k <= n-1): i from 0 to n-1-s_k.
If s_k < 0 (i.e., k > n-1): i from -s_k to n-1.

Now, df_k/dh[m]:
h[m] appears in f_k in two ways:
1. As h[i] when i = m: contributes (1-h[m+s_k]) if m is in the valid range
2. As h[i+s_k] when i+s_k = m, i.e., i = m-s_k: contributes -h[m-s_k] if m-s_k is in the valid range

So:
df_k/dh[m] = (1-h[m+s_k]) * I(m in valid range as i) - h[m-s_k] * I(m-s_k in valid range as i)

Where "valid range as i" means: 0 <= i < n and 0 <= i+s_k < n.

For m as i (first term): valid if 0 <= m < n and 0 <= m+s_k < n.
For m-s_k as i (second term): valid if 0 <= m-s_k < n and 0 <= m-s_k+s_k = m < n.
  The second condition (0 <= m < n) is always true for our m.
  The first condition: 0 <= m-s_k < n, i.e., s_k <= m < n+s_k.

So:
df_k/dh[m] = (1-h[m+s_k]) * I(0<=m<n, 0<=m+s_k<n) - h[m-s_k] * I(0<=m-s_k<n)

With s_k = n-1-k:
df_k/dh[m] = (1-h[m+n-1-k]) * I(0<=m+n-1-k<n) - h[m-(n-1-k)] * I(0<=m-(n-1-k)<n)
= (1-h[m+n-1-k]) * I(k-n+1<=m<=k) - h[m-k+n-1] * I(k-n+1<=m-k+n-1<=k-1)

3. Then do a few iterations of the active-set method to polish

For the soft-max gradient:
L(h) = dx * (m + (1/β) * log(sum exp(β(c_k - m))))
where m = max(c_k) and c_k are the correlations.

dL/dh[j] = dx * (1/β) * sum_k β * exp(β(c_k - m)) * dc_k/dh[j] / sum_k exp(β(c_k - m))
= dx * sum_k softmax_k * dc_k/dh[j]
= dx * sum_k softmax_k * (delta_k * term1_j - delta_k * term2_j)

where softmax_k = exp(β(c_k - m)) / sum exp(β(c_k - m)) and the delta terms are from the individual lag gradients.

This is O(n^2) per gradient evaluation (n lags × n variables), which is about 47^2 ≈ 2200 operations. Very fast.

Actually, let me just use numerical gradients for simplicity. The SLSQP method will do forward differences, which is O(n) function evaluations per gradient. import time


def compute_c5(h, n):
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return dx * np.max(corr)


def repair_sum(h, n):
    h = h.copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(1000):
        deficit = target - np.sum(h)
        if abs(deficit) < 1e-15:
            break
        if deficit > 0:
            room = 1.0 - h
            total = room.sum()
            if total < 1e-15:
                break
            h += (deficit / total) * room
        else:
            mass = h.copy()
            total = mass.sum()
            if total < 1e-15:
                break
            h += (deficit / total) * mass
        h = np.clip(h, 0.0, 1.0)
    return h


def sum_constraint(x, n):
    return np.sum(x) - n / 2.0


def objective_direct(x, n):
    return compute_c5(x, n)


def objective_softmax(x, n, beta):
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode="full")
    m = np.max(corr)
    return dx * (m + np.log(np.sum(np.exp(beta * (corr - m)))) / beta)


def objective_lag(x, n, k):
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode="full")
    return dx * corr[k]


def lag_gradient(x, n, k):
    dx = 2.0 / n
    s = n - 1 - k
    grad = np.zeros(n)
    lo1 = max(0, -s)
    hi1 = min(n, n - s)
    if lo1 < hi1:
        grad[lo1:hi1] += dx * (1.0 - x[lo1 + s:hi1 + s])
    lo2 = max(0, s)
    hi2 = min(n, n + s)
    if lo2 < hi2:
        grad[lo2:hi2] += -dx * x[lo2 - s:hi2 - s]
    return grad


def make_lag_obj(n, k):
    def _obj(x):
        return objective_lag(x, n, k)
    return _obj


def make_lag_grad(n, k):
    def _grad(x):
        return lag_gradient(x, n, k)
    return _grad


def make_sum_con(n):
    def _con(x):
        return sum_constraint(x, n)
    return _con


def make_soft_obj(n, beta):
    def _obj(x):
        return objective_softmax(x, n, beta)
    return _obj


def make_direct_obj(n):
    def _obj(x):
        return objective_direct(x, n)
    return _obj
