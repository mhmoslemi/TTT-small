- Minimize `C_5 = max_{k=-69}^{69} (2/70) × np.correlate(h, 1-h, mode='full')[k]`

**Repair Function:**  
- `h_clipped ← np.clip(h, 0, 1)`  
- `scale_factor ← 35 / ∑h_clipped`  
- `h_scaled ← h_clipped * scale_factor`  
- Clip `h_scaled` again if needed and rebalance integral to 35.  

**Key Operations:**  
- Evaluate `C_5` via finite-grid integration.  
- Search is guided by local improvement: update one coordinate at a time.  

The repair function preserves the integral constraint while respecting bounds. Unlike clipping followed by simple scaling, this iterative approach handles scaling infeasibility by minimal resampling.

```python
def repair(h):
    h = np.clip(np.array(h), 0, 1)
    s = np.sum(h)
    if s <= 0:  # Handle minimal sum edge case
        h = np.ones_like(h) / len(h) * 35
        s = 35
    factor = 35.0 / s
    h = h * factor
    clipped_against = np.clip(h, 0, 1)
    s_against = np.sum(clipped_against)
    if s_against != s:  # Adjust if clipping occurred
        factor_against = 35.0 / s_against
        h = clipped_against * factor_against
    return h
```

def objective(h):
    h = repair(h)
    # Clip first for stability or safety
    h_val = np.clip(np.array(h), 0, 1)
    corr = np.correlate(h_val, 1 - h_val, mode='full')
    max_corr = np.max(corr)
    return (2.0 / 70.0) * max_corr  # Scale to integral representation
