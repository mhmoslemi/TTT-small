2. The max of the linear functions l(t) = max_k(base[k]+coeff[k]*t) is a convex piecewise linear function.
3. The overall function f(t) = max(g(t), l(t)) 

The minimum is where g(t) and l(t) are "balanced" or at a vertex of l(t) or at t=0/1.

Actually, I realize I should think about this differently. The coordinate descent I described minimizes max_k c_k, which is what we want. But we also need to maintain the constraint sum(h) = n/2.

Options:
1. After each coordinate update, check if sum(h) changed and adjust.
2. Use a Lagrange multiplier: minimize max_k c_k + λ*(sum(h)-n/2).
3. Do paired coordinate updates: increase h[i] by δ, decrease h[j] by δ.

I think option 2 is cleanest. The 1D subproblem becomes:
min_{t∈[0,1]} max_k c_k(t) + λ*(t - old_h[i])
= min_{t∈[0,1]} max_k (c_k(t) + λ*t - λ*old_h[i])
= min_{t∈[0,1]} max_k (c_k(t) + λ*t) + const

For the non-zero-lag terms (linear in t): c_k(t) + λ*t = (a_k+λ)*t + b_k, still linear.
For the zero-lag: t(1-t) + λ*t = (1+λ)*t - t², still quadratic.

So the structure is preserved. Good.

def compute_c5_from_h(h):
    n = len(h)
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - np.sum(h)
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-15
            if not np.any(mask):
                break
            step = min(diff / np.sum(mask), (1.0 - h[mask].max()) * 0.999)
            if step <= 0:
                break
            h[mask] += step
        else:
            mask = h > 1e-15
            if not np.any(mask):
                break
            step = min(-diff / np.sum(mask), h[mask].min() * 0.999)
            if step <= 0:
                break
            h[mask] -= step
    return np.clip(h, 0.0, 1.0)

def c5_of_h_with_i(h, i, t):
    """Compute C5 with h[i] replaced by t."""
    n = len(h)
    dx = 2.0/n
    old = h[i]
    h[i] = t
    c = np.correlate(h, 1.0-h, mode='full')
    result = np.max(c) * dx
    h[i] = old
    return result

def coord_descent_1d(preserved_h, i, n, lam):
    """Solve 1D subproblem for coordinate i with Lagrange multiplier lam."""
    dx = 2.0/n
    old = preserved_h[i]
    
    def obj(t):
        preserved_h[i] = t
        c = np.correlate(preserved_h, 1.0-preserved_h, mode='full')
        val = np.max(c) * dx + lam * (t - old)
        return val
    
    res = minimize_scalar(obj, bounds=(0.0, 1.0), method='bounded', options={'xatol': 1e-12})
    preserved_h[i] = old
    return res.x, res.fun
