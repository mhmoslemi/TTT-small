**Alternative: Min-max via dual variable**

The problem is: min_h max_k c_k(h) subject to h ∈ [0,1]^n, sum(h) = n/2.

This can be written as: min_h min_λ max_k (c_k(h) - λ_k) subject to λ_k ≥ 0, sum λ_k = 1.

Or equivalently (by minimax theorem, if the problem were convex):
max_λ min_h [Σ_k λ_k c_k(h)] subject to h ∈ [0,1]^n, sum(h) = n/2, λ ≥ 0, sum λ = 1.

But the problem isn't convex, so minimax doesn't directly apply. However, we can still use an "iterative reweighting" approach:
1. Start with uniform weights λ
2. Compute h* = argmin_h Σ_k λ_k c_k(h) (a weighted sum, which might be easier)
3. Update λ to focus on the maximizers
4. Repeat

The weighted sum Σ_k λ_k c_k(h) is:
Σ_k λ_k [Σᵢ h[i] - h[i]h[i+k]]
= (Σ_k λ_k) Σᵢ h[i] - Σ_k λ_k Σᵢ h[i]h[i+k]
= Σᵢ h[i] - Σᵢ h[i] Σ_k λ_k h[i+k]  (for the periodic case)
= Σᵢ h[i] (1 - (Λ * h)[i])  (where Λ is the weighting kernel)

This is a quadratic in h! Specifically:
f(h) = Σᵢ h[i] - Σᵢ Σ_k λ_k h[i]h[i+k]
= Σᵢ h[i] - h^T A h  (where A is a matrix determined by λ)

If A is positive semidefinite, then -h^T A h is concave, and the problem is maximizing a concave function minus a linear function, which is... not standard.

Actually, f(h) = 1^T h - h^T A h. The Hessian is -2A. If A is PSD, the Hessian is negative semidefinite, meaning f is concave. Maximizing a concave function over a convex set is a convex optimization problem!

So if we can find λ such that A(λ) is PSD, we can solve the inner problem efficiently.

For the correlation structure, A(λ) has entries A[i,j] = Σ_k λ_k 1{j = i+k} = λ_{j-i} (with appropriate wrapping). So A is a circulant matrix (for the periodic case) determined by the first row being λ.

A circulant matrix is PSD iff its eigenvalues (which are the DFT of the first row) are non-negative. So we need the DFT of λ to be non-negative, which means λ must be a valid autocorrelation sequence (by Bochner's theorem, up to normalization).

_g_alpha = 100.0
_g_n = 240

def compute_c5(h):
    dx = 2.0 / len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_to_sum(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(2000):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-15:
            break
        mask = (h > 1e-14) & (h < 1.0 - 1e-14)
        if np.any(mask):
            h[mask] += diff / np.sum(mask)
        else:
            h += diff / len(h)
        h = np.clip(h, 0.0, 1.0)
    return h

def _smooth_obj(h):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    m_val = np.max(corr)
    alpha = _g_alpha
    shifted = np.minimum(corr - m_val, 0.0)
    shifted = np.maximum(shifted, -50.0 / alpha)
    exp_vals = np.exp(alpha * shifted)
    return m_val + np.log(np.sum(exp_vals)) / alpha

def _smooth_grad(h):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    m_val = np.max(corr)
    alpha = _g_alpha
    shifted = np.minimum(corr - m_val, 0.0)
    shifted = np.maximum(shifted, -50.0 / alpha)
    exp_vals = np.exp(alpha * shifted)
    w = exp_vals / np.sum(exp_vals)
    
    # grad[k] = sum_j w[j] * [(1-h[k+m_j]) * 1{0<=k+m_j<n} - h[k-m_j] * 1{0<=k-m_j<n}]
    mags = np.arange(2*n-1) - (n-1)  # lag for each correlation index
    k = np.arange(n)[:, None]
    idx_pos = k + mags[None, :]  # k + m_j
    idx_neg = k - mags[None, :]  # k - m_j
    valid_pos = (idx_pos >= 0) & (idx_pos < n)
    valid_neg = (idx_neg >= 0) & (idx_neg < n)
    cp = np.clip(idx_pos, 0, n-1)
    cn = np.clip(idx_neg, 0, n-1)
    grad = np.sum(valid_pos * (1.0 - h[cp]) * w[None, :] - valid_neg * h[cn] * w[None, :], axis=1)
    return grad

def _sum_con_fun(h):
    return np.sum(h) - _g_n / 2.0

def _sum_con_jac(h):
    return np.ones(len(h))

    _g_alpha = alpha
    _g_n = n

    except Exception:

def slsqp_optimize(h, n, alpha, maxiter):

One key thing: the previous code uses SLSQP throughout, which is slow for large n. Switching to L-BFGS-B should allow more iterations and potentially better convergence.

Another key thing: the previous code's Phase 2 tries multiple resolutions but with limited alpha values. My version tries more alphas at higher resolutions.

Another idea: **iterative reweighting on the active constraints**. Instead of using a uniform smooth max, I can iteratively:
1. Compute the correlation values
2. Identify which lags have the highest correlation (the "active" constraints)
3. Focus the optimization on those constraints by adjusting the weights

This is similar to the "barrier method" or "augmented Lagrangian" approach.

Actually, here's another idea: **use the structure of the problem to do a 1D search**.

Notice that if we fix the "shape" of h (up to affine transformation), the problem reduces to choosing the right amplitude and offset. Specifically, if h(x) = a * g(x) + b where g is fixed, then:
- The constraint ∫h = 1 gives b = 1/2 - a * (∫g / 2)
- The constraint 0 ≤ h ≤ 1 determines the valid range of a
- The objective becomes a function of a alone

So for a fixed shape g, we can do a 1D optimization over a!

This is a powerful idea. Let me combine it with the optimization:
1. Optimize the "shape" (direction) of h using the smooth max

_g_alpha = 100.0
_g_n_pts = 240

def compute_c5(h):
    dx = 2.0 / len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_to_sum(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(3000):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-15:
            break
        mask = (h > 1e-14) & (h < 1.0 - 1e-14)
        if np.any(mask):
            h[mask] += diff / np.sum(mask)
        else:
            h += diff / len(h)
        h = np.clip(h, 0.0, 1.0)
    return h

def _smooth_obj(h):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    m_val = np.max(corr)
    alpha = _g_alpha
    shifted = np.minimum(corr - m_val, 0.0)
    shifted = np.maximum(shifted, -60.0 / alpha)
    exp_vals = np.exp(alpha * shifted)
    return m_val + np.log(np.sum(exp_vals)) / alpha

def _smooth_grad(h):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    m_val = np.max(corr)
    alpha = _g_alpha
    shifted = np.minimum(corr - m_val, 0.0)
    shifted = np.maximum(shifted, -60.0 / alpha)
    exp_vals = np.exp(alpha * shifted)
    w = exp_vals / np.sum(exp_vals)
    mags = np.arange(2 * n - 1) - (n - 1)
    k = np.arange(n)[:, None]
    idx_pos = k + mags[None, :]
    idx_neg = k - mags[None, :]
    valid_pos = (idx_pos >= 0) & (idx_pos < n)
    valid_neg = (idx_neg >= 0) & (idx_neg < n)
    cp = np.clip(idx_pos, 0, n - 1)
    cn = np.clip(idx_neg, 0, n - 1)
    grad = np.sum(valid_pos * (1.0 - h[cp]) * w[None, :] - valid_neg * h[cn] * w[None, :], axis=1)
    return grad

    return np.sum(h) - _g_n_pts / 2.0

    return np.ones(len(h))

    _g_alpha = alpha
    _g_n_pts = n
    try:
        res = minimize(_smooth_obj, h, method='L-BFGS-B', jac=_smooth_grad,
                       bounds=[(0.0, 1.0)] * n,
                       options={'maxiter': maxiter, 'ftol': 1e-18, 'gtol': 1e-12, 'maxls': 80})
        return project_to_sum(res.x, n / 2.0)
    except Exception:
        return project_to_sum(h, n / 2.0)

def slsqp_opt(h, n, alpha, maxiter):
    global _g_alpha, _g_n_pts
    _g_alpha = alpha
    _g_n_pts = n
    try:
        res = minimize(_smooth_obj, h, method='SLSQP', jac=_smooth_grad,
                       bounds=[(0.0, 1.0)] * n,
                       constraints=[{'type': 'eq', 'fun': _sum_con_fun, 'jac': _sum_con_jac}],
                       options={'maxiter': maxiter, 'ftol': 1e-16})
        return project_to_sum(res.x, n / 2.0)
    except Exception:
        return project_to_sum(h, n / 2.0)

def upsample_h(h_old, n_new):

    h_new = np.interp(x_new, x_old, h_old, period=2.0)
    return project_to_sum(h_new, n_new / 2.0)
