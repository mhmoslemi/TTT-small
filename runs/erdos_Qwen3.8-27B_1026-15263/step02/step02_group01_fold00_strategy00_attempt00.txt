- **Physical interpretation**: Directly penalizes function overlaps with itself at shifted positions  
- **Algorithm selection**: SLSQP (Slack-constrained Least Squares with Quadratic Programming) due to quadratic programming availability  
- **Representation transfer**: Linear interpolation for higher-resolution decoding  
- **Convex relaxations**: None applied due to non-convex displacement correlations  
- **Derivative handling**: Gradient computed from correlation derivatives via perturbation  
- **Solver name**: SLSQP; provides both feasibility (integral) convergence and objective (overlap) satisfaction  
- **Constraints**: Explicit box-constrained [0,1] and integral normalization via projection  
- **Fallback**: Valid interpolation of parent solution at resolutions <720  

3. Implementation procedure  
   - **Input**: Seed=42, budget=1300s  
   - **Resolutions**: Progressive doubling from parent's 360 to max 720, or interpolation from parent at 480/600/720  
   - **Initializations**:  
     1. Parent interpolation (if available)  
     2. Random initialization  
     3. Harmonic sine/maxima masking via different phases  
     4. Rectangular blocking clustered at intervals  
     5. Direct slice from parent via uniform shift  
   - **Optimization subprocesses**:  
     1. SLSQP w/ adaptive alpha values (100-2000) for both lower and higher resolutions  
     2. Projected gradient descent with momentum  
     3. Coordinate descent with directional perturbations  
     4. Basinhopping w/ cooling schedule of 500s cycle for 1000 steps  
   - **Arithmetic validation**:  
     - Sum(h_idx) = n/2.0 normalized via projection  
     - Overlap C₅_n computed via full correlation scaling by dx  
     - Self-overlap penalty defined through explicit 
       2D difference operator  
   - **Performance modeling**:  
     - Linear interpolation: O(n) time scaling  
     - SLSQP runs: 500 per initialization (5 per resolution)  
     - Basinhopping: ~500s amortized per resolution  

4. Search choices and variations  
   - **Primary initialization**: Hybrid of parent projection (α=0.7) and random perturbations (α=0.95)  
   - **Resolution progression**: Quadratic expansion (n = 360 * 2ᵏ) stopping at computational ceiling  
   - **Alpha annealing**: In SLSQP, begin with 200 and increase by factor 1.05 until saturated  
   - **Heuristic variants**:  
     1. Noisy sine phase (15% focus): Alternate harmonic drivers

   - **Time allocation**:

   - **Validation filtering**: Strip 5% baseline noise from correlation peaks  
   - **Fallback mechanism**: Return interpolated 360-point parent if any optimization cycle fails  
   - **Constraint satisfaction**: Meta-projection after optimization to ensure ∑h=1  

6. Validation and return contract  
   - **Feasibility tests**:
     1. h_idx must be in [0,1] (percentile check >99.9%)  
     2. Integral ∑h_idx == n/2 ± 1e-6 (double-sure random check)  
   - **Sanity check**:
     1. Baseline overlap minima (void regions) <0.005
     2. Single-point perturbations reverseable with projection  
     3. Gradient sign consistency at peaks  
   - **Objective calculation**: 
     C₅_n = max_lag np.max( 
         np.correlate(h_idx, 1-h_idx, mode='full') ) * (2/n)
   - **Output contract**:
     (h_values, C₅_bound, n_points) with n_points = final NS (180-720)  
     C₅_bound: Unambiguous improvement if <0.3808  
     Time-based termination: Scale evaluations if runtime exceeds 1200s  
     Primary performance metric: Cross-resolution scaling of objective penalty
