Now, for the swap-based local search:
Given current h, precompute G.
For a pair (i, j) and transfer δ from i to j:
h_new = h with h[i]-=δ, h[j]+=δ
New corr = corr + δ * (G[:, j] - G[:, i])
New C₅ = max(new_corr) * dx

We want to minimize this over δ ∈ [δ_min, δ_max].

Since new_corr is linear in δ, and we're taking the max, the result is a convex piecewise-linear function of δ. The minimum is at a breakpoint or endpoint.

For efficiency, I'll just sample a few δ values:
- δ = 0 (no change)
- δ = δ_min, δ_max (endpoints)
- A few quantiles of the feasible range
- The value where the derivative changes sign (if we can find it cheaply)

Actually, the simplest approach that's still efficient:
1. For pair (i,j), compute d = G[:, j] - G[:, i] (length 2n-1)
2. The function to minimize is f(δ) = max(corr + δ*d)
3. This is convex in δ
4. We can find the minimum by:
   a. Checking endpoints
   b. Finding δ* where 0 ∈ subgradient, i.e., where sum of w_k * d[k] = 0 for some convex combination of active k's
   c. A simpler approach: ternary search (since f is convex)

Ternary search on a convex piecewise-linear function: we just need about 20-30 evaluations to get high precision. Each evaluation is O(n) (a max over 2n-1 values). So 30 * 720 = 21600 operations per pair. For 1000 pairs, that's 21.6M operations. Very fast!

But actually, we can be even smarter. Since f(δ) = max_k(corr[k] + δ*d[k]), and it's convex, we can find the minimum by:
1. Computing the "left" and "right" slopes
2. The minimum is where the slope crosses 0

The slope from the left at δ is max(d[k] for k active from below) and from the right is min(d[k] for k active from above). At the minimum, the slope changes from negative to positive.

A practical approach: evaluate f at 50 points in [δ_min, δ_max], pick the best, then refine with a few more evaluations. This gives us the optimal δ for this pair to high accuracy.

    tm = np.array(seq[:n], dtype=float)
    starts.append(tm)
    
    h_blk = np.zeros(n)
    period = max(3, n // 40)
    for s in range(0, n, period * 2):
        h_blk[s:s + period] = 1.0
    starts.append(h_blk)
    
    h_tri = np.zeros(n)
    for s in range(0, n, period * 3):
        seg = min(period, n - s)
        h_tri[s:s + seg] = np.abs(1.0 - 2.0 * np.linspace(0, 1, seg))
    starts.append(h_tri)
    
    return starts

def run(seed=42, budget_s=1300, **kwargs):
    t_start = time.time()
    
    def time_left():
        return budget_s - (time.time() - t_start)
    
    rng = np.random.RandomState(seed)
    best_h = None
    best_c5 = float('inf')
    best_n = 0
    
    if 'initial_h_values' in globals() and initial_h_values is not None:
        try:
            best_h = np.array(initial_h_values, dtype=float)
            best_n = len(best_h)
            ts = best_n / 2.0
            best_h = project_to_sum(best_h, ts)
            best_c5 = compute_c5(best_h)
        except Exception:
            pass
    
    if best_h is None:
        best_n = 360
        best_h = np.full(360, 0.5)
        best_c5 = compute_c5(best_h)
    
    n_targets = [360, 420, 480]
    
    for n in n_targets:
        if time_left() < 180:
            break
        if n % 2 != 0:
            continue
        ts = n / 2.0
        if abs(ts - round(ts)) > 1e-9:
            continue
        
        starts = []
        if best_n == n and best_h is not None:
            starts.append(best_h.copy())
        elif best_h is not None:
            x_old = np.linspace(0, 2, best_n, endpoint=False)
            x_new = np.linspace(0, 2, n, endpoint=False)
            h_interp = np.interp(x_new, x_old, best_h)
            starts.append(project_to_sum(h_interp, ts))
        
        for hs in generate_structured_starts(n, rng):
            starts.append(project_to_sum(hs, ts))
        
        h_cur = None
        for h_start in starts:
            if time_left() < 60:
                break
            h_start = project_to_sum(h_start, ts)
            c5_s = compute_c5(h_start)
            if c5_s < best_c5:
                best_c5 = c5_s
                best_h = h_start.copy()
                best_n = n
            
            if h_cur is None or c5_s < compute_c5(h_cur) + 0.01:
                h_cur = h_start.copy()
        
        if h_cur is None:
            h_cur = starts[0].copy()
        
        for alpha in [30.0, 80.0, 200.0, 500.0]:
            if time_left() < 50:
                break
            maxiter = max(50, min(500, int(time_left() * 1.0)))
            h_opt = slsqp_optimize(h_cur, n, ts, alpha, maxiter)
            c5_opt = compute_c5(h_opt)
            if c5_opt < best_c5:
                best_c5 = c5_opt
                best_h = h_opt.copy()
                best_n = n
            h_cur = h_opt
        
        if time_left() > 120:
            n_iters = min(5000, int(time_left() * 2))
            h_pg, c5_pg = projected_gradient(h_cur, n, ts, 100.0, n_iters, 0.03)
            if c5_pg < best_c5:
                best_c5 = c5_pg
                best_h = h_pg.copy()
                best_n = n
            h_cur = h_pg
        
        if time_left() > 80:
            n_rounds = min(200, int(time_left() * 0.5))
            h_sw, c5_sw = swap_local_search(h_cur, n, ts, n_rounds, rng, pairs_per_round=1200)
            if c5_sw < best_c5:
                best_c5 = c5_sw
                best_h = h_sw.copy()
                best_n = n
            h_cur = h_sw
    
    if best_h is not None:
        n_f = best_n
        ts_f = n_f / 2.0
        
        for alpha in [500.0, 1000.0, 2000.0]:
            if time_left() < 25:
                break
            h_pol = slsqp_optimize(best_h, n_f, ts_f, alpha, 400)
            c5_pol = compute_c5(h_pol)
            if c5_pol < best_c5:
                best_c5 = c5_pol
                best_h = h_pol.copy()
        
        if time_left() > 50:
            n_rounds = min(300, int(time_left() * 0.6))
            h_sw, c5_sw = swap_local_search(best_h, n_f, ts_f, n_rounds, rng, pairs_per_round=2000)
            if c5_sw < best_c5:
                best_c5 = c5_sw
                best_h = h_sw.copy()
        
        if time_left() > 30:
            h_cd, c5_cd = coordinate_descent_binary(best_h, n_f, ts_f, 30, rng)
            if c5_cd < best_c5:
                best_c5 = c5_cd
                best_h = h_cd.copy()
        
        if time_left() > 20:
            n_rounds = min(200, int(time_left() * 0.5))
            h_sw2, c5_sw2 = swap_local_search(best_h, n_f, ts_f, n_rounds, rng, pairs_per_round=3000)
            if c5_sw2 < best_c5:
                best_c5 = c5_sw2
                best_h = h_sw2.copy()
        
        if time_left() > 15:
            n_iters = min(3000, int(time_left() * 1.5))
            h_pg, c5_pg = projected_gradient(best_h, n_f, ts_f, 200.0, n_iters, 0.01)
            if c5_pg < best_c5:
                best_c5 = c5_pg
                best_h = h_pg.copy()
    
    n_final = len(best_h)
    ts_final = n_final / 2.0
    best_h = project_to_sum(best_h, ts_final)
    best_h = np.clip(best_h, 0.0, 1.0)
    best_c5 = compute_c5(best_h)
    return (best_h, best_c5, n_final)
