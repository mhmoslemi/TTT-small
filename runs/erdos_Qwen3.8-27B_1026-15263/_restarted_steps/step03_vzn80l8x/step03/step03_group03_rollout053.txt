def block_descent_lp(h, j_block, corr, n, n_cand=5):
    # Solve LP to find best delta for the block
    m = len(j_block)
    # A = [B[j1]; B[j2]; ...; B[jm]] shape (2n-1, m)
    A = np.column_stack([compute_B(h, j, n) for j in j_block])
    
    # Objective: minimize t
    # s.t. corr[k] + A[k,:] @ delta <= t for all k
    #      0 <= h[j] + delta[j] <= 1 for all j in block
    
    # Using linprog:
    # c = [0,...,0, 1] (m+1 variables: delta_1,...,delta_m, t)
    # A_ub = [A, -I_{2n-1}] shape (2n-1, m+1), b_ub = corr - ... 
    # Wait: corr[k] + A[k] @ delta <= t means A[k] @ delta - t <= -corr[k]
    # So A_ub = [A, -1_column], b_ub = -corr
    # Plus: -h[j] <= delta[j] and delta[j] <= 1 - h[j]
    
    c = np.zeros(m + 1)
    c[m] = 1.0  # minimize t
    
    A_ub = np.zeros((2*n-1, m+1))
    A_ub[:, :m] = A
    A_ub[:, m] = -1.0
    b_ub = -corr
    
    # Bounds on delta:
    bounds = []
    for j in j_block:
        bounds.append((max(-h[j], -1.0), min(1.0 - h[j], 1.0)))
    bounds.append((None, None))  # t is unbounded
    
    from scipy.optimize import linprog
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success:
        delta = res.x[:m]
        for idx, j in enumerate(j_block):
            h[j] = np.clip(h[j] + delta[idx], 0, 1)
    return h

Hmm, but this is subject to the constraint that h is a step function on [0,2] with integral 1, which means exactly half the values are 1 (for binary case) or the average is 1/2.

For binary h with exactly n/2 ones, the autocorrelation at lag 0 is n/2 (the number of ones). At lag L, it's the number of positions where both h[i]=1 and h[i+L]=1.

So we want a binary sequence of length n with n/2 ones that maximizes the minimum autocorrelation at non-zero lags... wait, that doesn't sound right either. Let me reconsider.

full[n-1+L] = sum_valid h[a]*(1-h[a+L])

For binary h: this counts the number of positions where h[a]=1 and h[a+L]=0.

We want to minimize the maximum of this over all L. For L=0, it's the number of positions where h[a]=1 and h[a]=0, which is 0! Wait no:

full[n-1] = sum_i h[i]*(1-h[i]) which for binary h is 0.

Oh! So for binary h, the diagonal term is always 0. The interesting lags are L ≠ 0.

For L ≠ 0: full[n-1+L] = number of positions where h[a]=1 AND h[a+L]=0 (for L>0) or h[a+L]=1 AND h[a]=0 (for L<0, by symmetry it's the same).

Wait, for L > 0: full[n-1+L] = sum_{i=0}^{n-1-L} h[i]*(1-h[i+L])
= (number of i in [0, n-1-L] where h[i]=1) - (number of i in [0, n-1-L] where h[i]=1 and h[i+L]=1)

For L < 0, let L' = -L > 0: full[n-1-L'] = sum_{i=L'}^{n-1} h[i]*(1-h[i-L'])
= sum_{j=0}^{n-1-L'} h[j+L']*(1-h[j])
= (number of j in [0, n-1-L'] where h[j+L']=1) - (number of j where h[j]=1 and h[j+L']=1)

So by symmetry, full[n-1+L] = full[n-1-L] (the correlation is symmetric for real signals... actually it's the cross-correlation of h with 1-h, which is not necessarily symmetric).

Wait: full[n-1+L] = sum h[i](1-h[i+L]) and full[n-1-L] = sum h[i](1-h[i-L]) = sum h[i+L](1-h[i]).

These are different! full[n-1+L] counts "1 followed by 0" at distance L, while full[n-1-L] counts "0 followed by 1" at distance L. They're equal only if the sequence has a specific symmetry.

OK so the problem for binary h is:
minimize max(0, max_{L≠0} full[n-1+L] * dx)

Since full[n-1] = 0 for binary, we just need to minimize max_{L≠0} full[n-1+L].

full[n-1+L] = sum_{i=0}^{n-1-|L|} h[i] * (1-h[i+|L|]) (for L>0, with appropriate index)

This is the number of "1-to-0 transitions" at lag L.

For a balanced binary sequence (n/2 ones, n/2 zeros), the total number of 1-to-0 at all lags is related to the structure of the sequence.

The correlation in the spatial domain becomes a convolution in the frequency domain (by the convolution theorem). So:
full = fft(h) * conj(fft(1-h)) (with appropriate normalization)

This means the objective in the frequency domain is:
max_k |IFFT(FFT(h) * FFT(1-h))[k]| ... hmm, not quite. The max is in the spatial domain of the correlation, which corresponds to the max of the time-domain autocorrelation.

autocorrelation = IFFT(|FFT(h)|^2)

But our correlation is cross-correlation of h with (1-h), not autocorrelation.

cross_corr(h, 1-h) = IFFT(FFT(h) * conj(FFT(1-h)))

And FFT(1-h) = FFT(ones) - FFT(h) = (at DC: some value) - FFT(h)

So cross_corr(h, 1-h) = IFFT(FFT(h) * conj(FFT(ones) - conj(FFT(h))))
= IFFT(FFT(h) * conj(FFT(ones))) - IFFT(FFT(h) * conj(conj(FFT(h))))

= n*h - autocorrelation(h) (for the linear case, with appropriate handling)

import numpy as np

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_to_sum(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        mask = (h > 1e-14) & (h < 1.0 - 1e-14)
        if np.any(mask):
            h[mask] += diff / np.sum(mask)
        else:
            h += diff / len(h)
        h = np.clip(h, 0.0, 1.0)
    return h

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode="full")

def compute_B(h, j, n):
    nm1 = n - 1
    B = np.zeros(2 * n - 1)
    k1_lo = max(0, nm1 - j)
    k1_hi = min(2 * n - 2, 2 * nm1 - j)
    if k1_lo <= k1_hi:
        ks = np.arange(k1_lo, k1_hi + 1)
        B[k1_lo:k1_hi + 1] += (1.0 - h[j + ks - nm1])
    k2_lo = max(0, j - nm1)
    k2_hi = min(2 * n - 2, j + nm1)
    if k2_lo <= k2_hi:
        ks = np.arange(k2_lo, k2_hi + 1)
        B[k2_lo:k2_hi + 1] -= h[ks - j + nm1]
    return B

def solve_1d(corr, D, lo, hi):
    if hi - lo < 1e-14:
        return (lo + hi) * 0.5
    # Golden section search for min of max(corr + D*t)
    gr = (np.sqrt(5) - 1) / 2
    a, b = lo, hi
    c = b - gr * (b - a)
    d = a + gr * (b - a)
    fc = np.max(corr + D * c)
    fd = np.max(corr + D * d)
    for _ in range(60):
        if b - a < 1e-15:
            break
        if fc < fd:
            b = d
            d = c
            fd = fc
            c = b - gr * (b - a)
            fc = np.max(corr + D * c)
        else:
            a = c
            c = d
            fc = fd
            d = a + gr * (b - a)
            fd = np.max(corr + D * d)
    return (a + b) * 0.5

def pair_descent_sweep(h, corr, rng, n_cand=10, temp=0.0):
    n = len(h)
    order = np.arange(n)
    rng.shuffle(order)
    improved = False
    best_corr_max = np.max(corr)
    
    for j in order:
        B_j = compute_B(h, j, n)
        best_val = np.max(corr)
        best_delta = 0.0
        best_D = None
        best_k = -1
        
        k_set = [(j + 1) % n, (j - 1 + n) % n, (j + n // 2) % n, 
                 (j + n // 3) % n, (j + 2 * n // 3) % n]
        for _ in range(max(0, n_cand - 5)):
            k_set.append(rng.randint(n))
        
        seen = set()
        for k in k_set:
            if k == j or k in seen:
                continue
            seen.add(k)
            B_k = compute_B(h, k, n)
            D = B_j - B_k
            delta_lo = max(-h[j], h[k] - 1.0)
            delta_hi = min(1.0 - h[j], h[k])
            if delta_hi - delta_lo < 1e-13:
                continue
            delta_opt = solve_1d(corr, D, delta_lo, delta_hi)
            val_opt = np.max(corr + D * delta_opt)
            
            # SA acceptance
            if val_opt < best_val - 1e-13:
                best_val = val_opt
                best_delta = delta_opt
                best_D = D
                best_k = k
            elif temp > 0 and rng.rand() < np.exp((best_val - val_opt) / temp):
                # Accept worse move (rare)
                if val_opt < best_val:  # this is already handled
                    pass
                # Actually for SA, we'd accept the move even if it's worse
                # But let's only do this for the "best" candidate
                pass
        
        if best_k >= 0 and abs(best_delta) > 1e-13:
            corr += best_delta * best_D
            h[j] += best_delta
            h[best_k] -= best_delta
            h[j] = np.clip(h[j], 0.0, 1.0)
            h[best_k] = np.clip(h[best_k], 0.0, 1.0)
            improved = True
    
    return h, corr, improved

def smooth_max_grad(h, alpha):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    m_val = np.max(corr)
    exp_vals = np.exp(alpha * (corr - m_val))
    w = exp_vals / np.sum(exp_vals)
    
    # Gradient of smooth max w.r.t. h
    # d/dh[j] of corr[k] for each k, weighted by w[k]
    # Use the B matrix approach
    grad = np.zeros(n)
    for j in range(n):
        B_j = compute_B(h, j, n)
        grad[j] = np.dot(w, B_j)
    
    return np.dot(w, corr) + np.log(np.sum(exp_vals)) / alpha, grad

def nesterov_smooth_max(h0, n, target_sum, alpha, n_steps, lr_init=0.01):
    h = h0.copy()
    v = np.zeros(n)
    lr = lr_init
    
    for step in range(n_steps):
        if step % 50 == 0:
            lr *= 0.95
        # Smooth max gradient
        _, grad = smooth_max_grad(h, alpha)
        # Nesterov step
        v = 0.9 * v + grad
        h_new = h - lr * v
        h_new = project_to_sum(h_new, target_sum)
        
        # Check if improvement
        c5_new = compute_c5(h_new)
        c5_old = compute_c5(h)
        if c5_new < c5_old:
            h = h_new
        else:
            v = v * 0.5
    
    return h

    k1_hi = min(2 * n - 2, 2 * nm1 - j)

    k2_hi = min(2 * n - 2, j + nm1)

    a, b = lo, hi

        if np.max(corr + D * c) < np.max(corr + D * d):
            b = d
        else:

        best_val = np.max(corr)
        best_delta = 0.0
        best_D = None
        best_k = -1
        k_set = [(j + 1) % n, (j - 1 + n) % n, (j + n // 2) % n,
                 (j + n // 3) % n, (j + 2 * n // 3) % n]
        for _ in range(max(0, n_cand - 5)):
            k_set.append(rng.randint(n))
        seen = set()
        for k in k_set:
            if k == j or k in seen:
                continue
            seen.add(k)
            B_k = compute_B(h, k, n)

            if delta_hi - delta_lo < 1e-13:

                best_delta = delta_opt

def active_set_perturb(h, corr, rng, n_perturb=10):
    n = len(h)
    max_corr = np.max(corr)
    # Find indices of correlations near the maximum
    threshold = max_corr - 0.01 * max_corr
    active = np.where(corr >= threshold)[0]
    # For each active correlation, find the h indices involved
    involved = set()
    nm1 = n - 1

        if L >= 0:

            involved.update(range(L, n))
        else:
            involved.update(range(-L, n))
            involved.update(range(0, n + L))

    h = np.clip(h, 0.0, 1.0)

Let me also try a completely different approach: **treating it as a maximum flow / min cut problem**.

Actually, for binary h, the problem can be formulated as:
minimize max_L C_L
where C_L = sum_{i} h[i]*(1-h[i+L])

This is equivalent to:
minimize t
subject to: C_L <= t for all L
             sum h[i] = n/2
             h[i] in {0, 1}

For the continuous relaxation (h in [0,1]), this is a linear program! Because C_L = sum_i h[i] - sum_i h[i]*h[i+L] is NOT linear in h (it has the product term h[i]*h[i+L]).

So it's not an LP. But for BINARY h, C_L is linear in the sense that each term is either 0 or 1... no, it's still not linear because h[i]*(1-h[i+L]) is a product.

For binary h: h[i]*(1-h[i+L]) = h[i] - h[i]*h[i+L]. The term h[i]*h[i+L] is the AND of two binary variables, which can be linearized with an auxiliary variable x[i,L] = h[i]*h[i+L] and constraints x[i,L] <= h[i], x[i,L] <= h[i+L], x[i,L] >= h[i] + h[i+L] - 1, x[i,L] >= 0.

This gives an LP with O(n^2) auxiliary variables and O(n^3) constraints (for O(n) lags, each with O(n) terms). For n=240, that's about 57600 variables and ~27M constraints. That's too large for a standard LP solver.

But we can reduce: we only need the CONSTRAINTS for the active lags (those near the maximum). If we know which lags are active, we only need those constraints.

This suggests a **Benders decomposition** approach:
1. Solve the LP relaxation for a subset of constraints
2. Add violated constraints
3. Repeat

But this is complex to implement and might not be worth it.

def project_to_sum(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break

def compute_B(h, j, n):
    nm1 = n - 1
    B = np.zeros(2 * n - 1)
    k1_lo = max(0, nm1 - j)
    k1_hi = min(2 * n - 2, 2 * nm1 - j)
    if k1_lo <= k1_hi:
        ks = np.arange(k1_lo, k1_hi + 1)
        B[k1_lo:k1_hi + 1] += (1.0 - h[j + ks - nm1])
    k2_lo = max(0, j - nm1)
    k2_hi = min(2 * n - 2, j + nm1)
    if k2_lo <= k2_hi:
        ks = np.arange(k2_lo, k2_hi + 1)
        B[k2_lo:k2_hi + 1] -= h[ks - j + nm1]
    return B
