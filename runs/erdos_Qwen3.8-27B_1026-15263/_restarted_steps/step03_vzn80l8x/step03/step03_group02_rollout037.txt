```python
    idx_ik = i + k
```

For a permutation P of the positions (where P maps old 1-positions to new 1-positions), the new overlap[k] is:
new_overlap[k] = sum_m h_new[m](1-h_new[m+k])
= sum_{m ∈ P(A)} (1 - h_new[m+k])
where A is the original set of 1-positions.

This is harder to compute incrementally. Let me stick with single swaps for simplicity, and add block swaps as a separate move type.

Actually, for the purpose of this problem, I think single swaps + good sampling strategy will be sufficient. Let me code it up.

Here's my refined algorithm:

```python
        improved = False
        
        # Sample candidate swaps
        best_delta_max = 0
        best_i = -1
        best_j = -1
        
        n_ones = len(ones)
        n_zeros = len(zeros)
        
        for s in range(n_samples):

            j = zeros[rng.randint(n_zeros)]
            
            # Compute delta
            idx_ik = i + k_arr
            idx_ik_neg = i - k_arr
            idx_jk = j + k_arr
            idx_jk_neg = j - k_arr

            m = (idx_ik >= 0) & (idx_ik < n)
            d[m] += h[idx_ik[m]]
            m = (idx_ik_neg >= 0) & (idx_ik_neg < n)
            d[m] += h[idx_ik_neg[m]]
            m = (idx_jk >= 0) & (idx_jk < n)
            d[m] -= h[idx_jk[m]]
            m = (idx_jk_neg >= 0) & (idx_jk_neg < n)
            d[m] -= h[idx_jk_neg[m]]
            
            new_max = (overlaps + d).max()
            delta_max = new_max - c5
            
            if delta_max < best_delta_max:
                best_delta_max = delta_max
                best_i = i
                best_j = j
        
        if best_i < 0:
            break
        
        # Accept if improves or with SA probability
        if best_delta_max < 0 or (rng.uniform() < np.exp(-best_delta_max / T)):
            # Apply swap
            h[best_i], h[best_j] = h[best_j], h[best_i]
            overlaps += ... # need to recompute or update
            # Actually, let's just recompute overlaps after each accepted move
            overlaps = np.correlate(h, 1.0 - h, mode="full")
            c5 = overlaps.max()
            
            if c5 < best_c5 - 1e-12:
                best_c5 = c5
                best_h = h.copy()
                no_improve = 0
            else:
                no_improve += 1
            
            # Update ones and zeros
            if h[best_i] == 1.0:
                ones = np.where(h == 1.0)[0]
                zeros = np.where(h == 0.0)[0]
            else:
                # best_i was 1, now 0; best_j was 0, now 1
                # Update the arrays
                ones = np.where(h == 1.0)[0]
                zeros = np.where(h == 0.0)[0]
            
            improved = True
        else:
            no_improve += 1
        
        # Anneal
        T = max(0.1, T * 0.999)
        
        if no_improve > 20000:

            h = best_h.copy()
            overlaps = np.correlate(h, 1.0 - h, mode="full")
            c5 = overlaps.max()

                j = rng.randint(n)

            overlaps = np.correlate(h, 1.0 - h, mode="full")

            no_improve = 0
```

```python
    for _ in range(5000):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-13:
            break
        mask = (h > 1e-12) & (h < 1.0 - 1e-12)
        if np.any(mask):
            h[mask] += diff / np.sum(mask)
        else:
            h += diff / len(h)
        h = np.clip(h, 0.0, 1.0)

def make_binary(h, n, target_ones, rng):
```

Wait, there's an issue with the `overlaps + best_delta` update. The delta is computed based on the CURRENT h, so after applying the swap, the overlaps should be `overlaps + delta`. But if I'm using the updated overlaps in the next iteration, I need to make sure the delta computation is consistent.

Actually, the delta formula I derived assumes that the swap is applied to the current h. So:
new_overlaps = old_overlaps + delta(current_h, i, j)

This is correct as long as I recompute the delta based on the current h each time. Since I'm updating h after each accepted move, this should be fine.

But there's a numerical precision issue: after many updates, the `overlaps` array might drift from the true values due to floating point accumulation. I should periodically recompute:

Good. Let me also think about whether I should try different strategies:

1. **Greedy**: Always accept the best move (no SA)
2. **SA**: Accept worse moves with some probability
3. **Hybrid**: Greedy for a while, then SA if stuck

I think a hybrid approach works best: start with a low temperature (nearly greedy), and increase temperature when stuck.

Also, I should consider: what if I try to specifically target the shifts that are at the maximum? I can bias the sampling toward swaps that are likely to reduce those specific shifts.

For a shift k at the maximum, I want delta[k] < 0, i.e., h[i+k] + h[i-k] < h[j+k] + h[j-k].

So I can score each position p by:
score(p) = h[p+k1] + h[p-k1] + h[p+k2] + h[p-k2] + ... (for critical shifts k1, k2, ...)

Then I want to pick i (currently 1) with low score and j (currently 0) with high score.

Let me add this as a "guided" sampling strategy:

```python
def guided_sample(h, ones, zeros, critical_shifts, k_arr, n, n_samples, rng):
    # Score each position based on critical shifts
    # score(p) = sum over critical k of (h[p+k] + h[p-k])
    scores = np.zeros(n)
    for k in critical_shifts:
        k_actual = k - (n-1)  # Convert from correlation index to actual shift
        # h[p + k_actual] for valid p + k_actual
        idx = np.arange(n) + k_actual
        mask = (idx >= 0) & (idx < n)
        scores[mask] += h[idx[mask]]
        # h[p - k_actual]
        idx2 = np.arange(n) - k_actual
        mask2 = (idx2 >= 0) & (idx2 < n)
        scores[mask2] += h[idx2[mask2]]
    
    # For i (currently 1), we want LOW score
    # For j (currently 0), we want HIGH score
    # Sample i proportional to 1/(score_i + 1) and j proportional to score_j + 1
    ones_scores = 1.0 / (scores[ones] + 1.0)
    zeros_scores = scores[zeros] + 1.0
    ones_probs = ones_scores / ones_scores.sum()
    zeros_probs = zeros_scores / zeros_scores.sum()
    
    i_batch = ones[rng.choice(len(ones), size=n_samples, p=ones_probs)]
    j_batch = zeros[rng.choice(len(zeros), size=n_samples, p=zeros_probs)]
    return i_batch, j_batch
```

This should give better moves on average.

Now, let me also add a continuous optimization step. The idea is:
1. Find a good binary solution
2. Use it as initial guess for continuous optimization
3. The continuous optimizer might find a slightly better solution with fractional values

For the continuous optimization, I'll use a smoothed max approach with adaptive alpha:

```python
def smooth_max_overlaps(h, alpha):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    m_val = np.max(corr)
    # Log-sum-exp for numerical stability
    shifted = alpha * (corr - m_val)
    shifted = np.clip(shifted, -500, 0)
    exp_vals = np.exp(shifted)
```

```python
def smooth_max_and_grad(h, alpha):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    m_val = np.max(corr)
    shifted = np.clip(alpha * (corr - m_val), -500.0, 0.0)
    exp_vals = np.exp(shifted)
    w = exp_vals / np.sum(exp_vals)
    obj = m_val + np.log(np.sum(exp_vals)) / alpha
    
    # d(corr[k])/d(h[i]) where corr[k] = sum_m h[m](1-h[m+k])
    # = sum_m [ δ_{m,i}(1-h[m+k]) + h[m]δ_{m+k,i}(-1) ]
    # = (1-h[i+k]) - h[i-k] (for valid indices)
    
    # Vectorized: for each i and k, the contribution is w[k] * ((1-h[i+k]) - h[i-k])
    j_idx = np.arange(n)[:, None]  # (n, 1)
    k_idx = np.arange(2*n-1)[None, :]  # (1, 2n-1)
    
    # Shift value for k_idx: k_actual = k_idx - (n-1)
    k_actual = k_idx.astype(float) - (n - 1)
    
    # First part: (1-h[i+k]) for valid i+k
    first = j_idx + k_actual  # (n, 2n-1)
    valid_f = (first >= 0) & (first < n)
    fc = np.clip(first.astype(int), 0, n-1)
    cf = valid_f * (1.0 - h[fc]) * w[None, :]
    
    # Second part: -h[i-k] for valid i-k
    second = j_idx - k_actual  # (n, 2n-1)
    valid_s = (second >= 0) & (second < n)
    sc = np.clip(second.astype(int), 0, n-1)
    cs = valid_s * h[sc] * w[None, :]
    
    grad = np.sum(cf - cs, axis=1)
    return obj, grad
```

Actually, for the overlap to be low, we want the set of 1s to be "spread out" so that at any shift, the overlap with the complement is roughly uniform. This is related to "difference set" theory in combinatorics.

A (v, k, λ) difference set has the property that every non-zero difference occurs exactly λ times. If we had a perfect difference set, the overlaps would be perfectly uniform.

For our problem:
- v = n (or n-1 for the non-periodic case)
- k = n/2 (number of 1s)
- We want the "difference multiset" to be as uniform as possible

Perfect difference sets exist for v = 4λ+1 where v is a prime power (Singer difference sets). For example:
- v=7, k=3, λ=1: {0,1,3}
- v=13, k=4, λ=1: {0,1,3,9}
- v=21, k=5, λ=2: exists
- v=31, k=6, λ=1: {0,1,2,4,10,28} (or similar)

For n=240, we don't have a perfect difference set (240 is not of the form 4λ+1 with λ giving k=n/2=120). But we can look for near-optimal structures.

```python
import numpy as np

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_to_sum(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(5000):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-13:
            break
        mask = (h > 1e-12) & (h < 1.0 - 1e-12)
        if np.any(mask):
            h[mask] += diff / np.sum(mask)
        else:
            h += diff / len(h)
        h = np.clip(h, 0.0, 1.0)
    return h

def make_binary(h, n, target_ones, rng):
    h_bin = (h > 0.5).astype(float)
    n_ones = int(np.sum(h_bin))
    if n_ones == target_ones:
        return h_bin
    if n_ones > target_ones:
        excess = n_ones - target_ones
        ones_idx = np.where(h_bin == 1.0)[0]
        order = np.argsort(h[ones_idx])[:excess]
        h_bin[ones_idx[order]] = 0.0
    else:
        deficit = target_ones - n_ones
        zeros_idx = np.where(h_bin == 0.0)[0]
        order = np.argsort(-h[zeros_idx])[:deficit]
        h_bin[zeros_idx[order]] = 1.0
    return h_bin

def batch_evaluate_swaps(h, i_batch, j_batch, k_arr, n):
    idx_ik = i_batch[:, None] + k_arr[None, :]
    idx_ik_neg = i_batch[:, None] - k_arr[None, :]
    idx_jk = j_batch[:, None] + k_arr[None, :]
    idx_jk_neg = j_batch[:, None] - k_arr[None, :]
    
    h_ik = np.where((idx_ik >= 0) & (idx_ik < n), h[np.clip(idx_ik, 0, n-1)], 0.0)
    h_ik_neg = np.where((idx_ik_neg >= 0) & (idx_ik_neg < n), h[np.clip(idx_ik_neg, 0, n-1)], 0.0)
    h_jk = np.where((idx_jk >= 0) & (idx_jk < n), h[np.clip(idx_jk, 0, n-1)], 0.0)
    h_jk_neg = np.where((idx_jk_neg >= 0) & (idx_jk_neg < n), h[np.clip(idx_jk_neg, 0, n-1)], 0.0)
    
    return h_ik + h_ik_neg - h_jk - h_jk_neg

def sliding_window_scores(h, k_vals, n):
    """Compute score[p] = sum over k in k_vals of (h[p+k] + h[p-k]) for valid indices."""
    scores = np.zeros(n)
    for k_val in k_vals:
        idx = np.arange(n) + k_val
        mask = (idx >= 0) & (idx < n)
        scores[mask] += h[idx[mask]]
        idx2 = np.arange(n) - k_val
        mask2 = (idx2 >= 0) & (idx2 < n)
        scores[mask2] += h[idx2[mask2]]
    return scores

def guided_local_search(h, n, target_ones, t_end, rng):

    c5 = overlaps.max()

    best_h = h.copy()

    n_batch = 5000
    half_batch = n_batch // 2

    zeros = np.where(h == 0.0)[0]
    
    T = 0.3
    no_improve = 0
    iter_count = 0
    
    while time.time() < t_end:
        iter_count += 1
        
        # Find top critical shifts
        top_k = min(5, len(overlaps))
        top_idx = np.argpartition(overlaps, -top_k)[-top_k:]
        critical_k = top_idx - (n - 1)
        
        # Compute scores for guided sampling
        scores = sliding_window_scores(h, critical_k, n)
        
        # Guided sampling (50%) + random (50%)
        ones_scores = 1.0 / (scores[ones] + 1.0)
        zeros_scores = scores[zeros] + 1.0
        ones_probs = ones_scores / ones_scores.sum()
        zeros_probs = zeros_scores / zeros_probs.sum()
        
        i_guided = ones[rng.choice(len(ones), size=half_batch, p=ones_probs)]
        j_guided = zeros[rng.choice(len(zeros), size=half_batch, p=zeros_probs)]
        i_random = ones[rng.randint(len(ones), size=half_batch)]
        j_random = zeros[rng.randint(len(zeros), size=half_batch)]

def smooth_max_and_grad(h, alpha):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    m_val = np.max(corr)
    shifted = np.clip(alpha * (corr - m_val), -500.0, 0.0)
    exp_vals = np.exp(shifted)
    w = exp_vals / np.sum(exp_vals)
    obj = m_val + np.log(np.sum(exp_vals)) / alpha
    
    j_idx = np.arange(n)[:, None]

def slsqp_optimize(h0, n, target_sum, alpha, maxiter=500):
    def f(x):
        return smooth_max_and_grad(x, alpha)[0]
    def g(x):
        return smooth_max_and_grad(x, alpha)[1]
    cons = [{'type': 'eq', 'fun': lambda x: np.sum(x) - target_sum,
             'jac': lambda x: np.ones(n)}]
    bounds = [(0.0, 1.0)] * n
    try:
        res = minimize(f, h0.copy(), method='SLSQP', jac=g,
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-14})
        return project_to_sum(res.x, target_sum)
    except Exception:
        return project_to_sum(h0.copy(), target_sum)
```
