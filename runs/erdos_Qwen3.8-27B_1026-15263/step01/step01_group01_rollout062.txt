**Practical approach: Projected subgradient with momentum**

3. Find the active set (correlations near the max)

- It's much faster per iteration (O(n²) for correlations vs. expensive nonlinear optimization)

Let me try a different approach: **coordinate descent**. At each step, optimize one coordinate (one grid point) while keeping the others fixed. The optimal value of h[j] given all other h[i] can be found by minimizing the maximum overlap, which is a 1D problem (since we're only changing one variable).

For a fixed h[j], the overlap at shift k is:
corr[k] = ∑_i h[i](1-h[i+k]) 

If we change h[j] to h[j]+δ, the change in corr[k] is:
Δcorr[k] = δ * ∂corr[k]/∂h[j]

For the shift k where j appears:
- If j is in the "h" part: contribution is (1-h[j+k])*δ
- If j is in the "1-h" part: contribution is -h[j-k]*δ

So for each shift k, the change is linear in δ. The new maximum is:
max_k (corr[k] + δ * g_k(j))

where g_k(j) is the gradient of corr[k] with respect to h[j].

We want to choose δ to minimize this, subject to 0 ≤ h[j]+δ ≤ 1 and the sum constraint.

This is a 1D minimization of the max of linear functions, which can be solved analytically!

The function f(δ) = max_k (a_k + b_k * δ) where a_k = corr[k] and b_k = g_k(j) is a convex piecewise-linear function of δ. Its minimum occurs where the subgradient contains 0, i.e., where the positive and negative slopes balance.

This is equivalent to finding the point where the upper envelope of lines changes from having positive slope to negative slope. We can find this by:
1. For each k, compute the "breakpoint" δ_k where line k ceases to be the maximum
2. The optimum is at one of these breakpoints (or at the boundary δ = -h[j] or δ = 1-h[j])

But this is O(n) per coordinate update (to compute all the relevant shifts), and we have n coordinates, so a full pass is O(n²). For n=190, that's about 36,000 operations per pass, which is very fast.

    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(h, n):
