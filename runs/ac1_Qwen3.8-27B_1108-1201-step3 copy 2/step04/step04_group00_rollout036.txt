Let me also consider: what's the theoretical lower bound?

We know that (a*a)[n-1] = sum_j a[j]*a[n-1-j] >= 0.
And sum_k (a*a)[k] = (sum a)^2 = 1.
There are 2n-1 terms in the convolution.
So max_k (a*a)[k] >= 1/(2n-1).
Objective >= 2n/(2n-1) → 1 as n → ∞.

But this lower bound is not achievable for non-negative sequences. The actual minimum is higher.

For very large n, what's the best we can do? If we could make the convolution perfectly flat (= 1/(2n-1) at every point), we'd achieve the bound. But this requires |A(f)|^2 to be constant for all frequencies, which means A(f) is a "flat" spectrum. The inverse DFT of a flat spectrum is a delta function (or a sinc function in the continuous case), which is not non-negative everywhere.

So the constraint a >= 0 is the binding constraint. The best we can do is find the non-negative sequence whose auto-convolution is as flat as possible.

This is related to the theory of "minimum autocorrelation" sequences, but with the non-negativity constraint.

For binary sequences (a[j] ∈ {0,1}), the minimum peak autocorrelation is well-studied. For real non-negative sequences, it's a different problem.

Actually, let me think about a completely different approach: **direct optimization of the max via log-sum-exp smoothing**.

Define: `L(f, t) = (1/t) * log(sum_k exp(t * (a*a)[k]))`

As t → ∞, L → max_k (a*a)[k]. For finite t, L is smooth and we can use gradient descent.

The gradient of L with respect to a[m] is:
`dL/da[m] = (1/t) * sum_k exp(t*(a*a)[k]) * d(a*a)[k]/da[m] / sum_k exp(t*(a*a)[k])`
`= sum_k p_k * (a[k-m] + a[m-k])` (for valid indices)
where `p_k = exp(t*(a*a)[k]) / sum_j exp(t*(a*a)[j])`

This is exactly the subgradient method with softmax weights! The temperature t controls how peaked the weights are.

So the subgradient method is already the smooth approximation. The key is to start with a moderate t (smooth) and gradually decrease it (approach the true max).

Let me think about what else could help:

**Idea: Use the structure of the optimal solution.**

At the optimum, the constraint `max_k (a*a)[k] = M` should be active at multiple k values (by LP duality, the active constraints determine the solution). This suggests that at the optimum, several peaks of the convolution are at the same height M.

This motivates a "balancing" approach:
1. Identify the current peaks
2. Adjust a to equalize the peak heights
3. Reduce the overall peak level

**Idea: Use the LP dual.**

The LP in the FW step is:
max sum(g) s.t. (f*g)[k] <= M for all k, g >= 0

The dual is:
min M * sum(y) s.t. sum_k y_k * f[k-j] >= 1 for all j, y >= 0

The optimal dual variables y give us the "importance" of each constraint. We can use these to guide the subgradient method.

**Idea: Accelerated methods.**

Use FISTA (Fast Iterative Shrinkage-Thresholding Algorithm) or Nesterov acceleration on the smoothed problem.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
- Log-sum-exp smoothed subgradient with Nesterov momentum (main workhorse)
- LP-based Frank-Wolfe for polished direction finding
- Multi-start with diverse initializations and multi-length exploration
- Coordinate descent and adaptive peak-shaving for final refinement

import numpy as np
from scipy.optimize import linprog
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def convolve_ab(a, b):
    """Full linear convolution of a and b via FFT."""
    na = len(a)
    nb = len(b)
    size = na + nb - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    B = np.fft.rfft(b, fft_size)
    return np.fft.irfft(A * B, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex {x>=0, sum(x)=1}."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def normalize_f(f):
    """Clip to non-negative and normalize to sum 1."""
    f = np.maximum(f, 0.0)
    s = f.sum()
    if s < 1e-15:
        return np.ones(len(f)) / len(f)
    return f / s


def lse_subgradient(f0, time_limit, t_init=30.0, t_max=2000.0, lr_init=0.08,
                    lr_decay=0.9998, momentum=0.92, restart_patience=200,
                    smooth_schedule='linear'):
    """
    Log-sum-exp smoothed subgradient with Nesterov momentum and adaptive temperature.
    Uses FFT-based gradient computation for efficiency.
    """
    f = normalize_f(f0.astype(np.float64))
    n = len(f)

    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()

    t0 = time.monotonic()
    no_improve = 0
    cur_t = t_init
    cur_lr = lr_init
    v = np.zeros(n)
    it = 0

    while time.monotonic() - t0 < time_limit:
        # Softmax weights over the convolution peaks
        shifted = conv - conv.max()
        scaled = cur_t * shifted
        scaled = np.clip(scaled, -600, 0)
        w = np.exp(scaled)
        ws = w.sum()
        if ws < 1e-300:
            w = np.zeros(len(conv))
            w[np.argmax(conv)] = 1.0
        else:
            w = w / ws

        # Compute gradient: grad[m] = 2 * sum_j w[j+m] * a[j]
        # = 2 * conv(flip(a), w)[m + n - 1]
        flipped_a = a[::-1] if (a := f) else f[::-1]
        conv_fa_w = convolve_ab(f[::-1], w)
        grad = 2.0 * conv_fa_w[n - 1: n - 1 + n]

        # Nesterov momentum step
        v = momentum * v - cur_lr * grad
        f_new = project_simplex(f + v)

        conv = fast_convolve(f_new)
        cur_obj = conv.max()

        if cur_obj < best_obj - 1e-13:
            best_obj = cur_obj
            best_f = f_new.copy()
            no_improve = 0
        else:
            no_improve += 1

        f = f_new
        cur_lr *= lr_decay
        cur_t *= 1.008

        # Adaptively increase temperature to focus on peaks
        if cur_t > t_max:
            cur_t = t_max

        if no_improve > restart_patience:
            rng = np.random.default_rng(it * 7919 + 13)
            scale = 0.003 + 0.003 * min(no_improve // 500, 5)
            f = project_simplex(best_f + rng.standard_normal(n) * scale)
            v = np.zeros(n)
            conv = fast_convolve(f)
            cur_lr = max(lr_init * 0.4, 0.005)
            cur_t = max(t_init, cur_t * 0.3)
            no_improve = 0

        it += 1
        if it % 5000 == 0 and verbose := False:
            pass

    return best_f, best_obj


def lp_fw_optimize(f0, time_limit, verbose=False, m_explore=1.0):
    """LP-based Frank-Wolfe with adaptive constraint relaxation."""
    f = normalize_f(f0.astype(np.float64))
    n = len(f)

    conv = fast_convolve(f)
    M = conv.max()
    best_obj = M
    best_f = f.copy()

    t0 = time.monotonic()
    no_improve = 0
    it = 0
    m_exp = m_explore

    while time.monotonic() - t0 < time_limit:
        it += 1

        g = solve_lp_direction(f, M * m_exp, n)
        if g is None:
            m_exp *= 1.15
            if m_exp > 8.0:
                m_exp = 1.0
            continue

        g_sum = g.sum()
        if g_sum < 1e-15:
            break
        g = g / g_sum

        # Check convergence
        if np.max(np.abs(g - f)) < 1e-11:
            no_improve += 1
            if no_improve > 30:
                break
            m_exp = min(m_exp * 1.05, 5.0)
            continue

        # Line search
        best_alpha = 0.0
        best_val = M

        for alpha in [0.05, 0.1, 0.15, 0.2, 0.3, 0.5, 0.7, 1.0]:
            ft = f + alpha * (g - f)
            ft = np.maximum(ft, 0.0)
            st = ft.sum()
            if st < 1e-15:
                continue
            ft = ft / st
            val = fast_convolve(ft).max()
            if val < best_val:
                best_val = val
                best_alpha = alpha

        if best_alpha > 0:
            # Refine with binary search
            lo = max(0.0, best_alpha - 0.15)
            hi = min(1.0, best_alpha + 0.15)
            for _ in range(8):
                mid = (lo + hi) / 2.0
                ft = f + mid * (g - f)
                ft = np.maximum(ft, 0.0)
                st = ft.sum()
                if st < 1e-15:
                    break
                ft = ft / st
                val = fast_convolve(ft).max()
                if val < best_val:
                    best_val = val
                    best_alpha = mid
                    lo = mid
                else:
                    hi = mid

        if best_alpha > 1e-10:
            f_new = f + best_alpha * (g - f)
            f_new = np.maximum(f_new, 0.0)
            f_new = f_new / f_new.sum()
            conv = fast_convolve(f_new)
            M = conv.max()
            m_exp = 1.0
            f = f_new

            if M < best_obj - 1e-14:
                best_obj = M
                best_f = f.copy()
                no_improve = 0
                if verbose and it % 20 == 0:
                    print(f"    LP-FW iter {it}: obj={best_obj:.10f}")
            else:
                no_improve += 1
        else:
            no_improve += 1
            m_exp = min(m_exp * 1.1, 5.0)

        if no_improve > 50:
            rng = np.random.default_rng(it * 31 + 7)
            scale = 0.002 + 0.003 * min(no_improve // 100, 4)
            f = project_simplex(best_f + rng.standard_normal(n) * scale)
            conv = fast_convolve(f)
            M = conv.max()
            m_exp = 1.0
            no_improve = 0

    return best_f, best_obj


def solve_lp_direction(f, M, n):
    """Solve LP: max sum(g) s.t. (f*g)[k] <= M for all k, g >= 0."""
    c = -np.ones(n)
    A_ub = np.zeros((2 * n - 1, n))
    for j in range(n):
        A_ub[j:j + n, j] = f
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs',
                  options={'presolve': True, 'dual_obj_bound': -1e10})
    if res.success:
        return res.x
    return None


def coordinate_descent(f0, time_limit):
    """Coordinate descent with local search per coordinate."""
    f = normalize_f(f0.astype(np.float64))
    n = len(f)

    best_f = f.copy()
    best_obj = fast_convolve(f).max()
    t0 = time.monotonic()
    passes = 0

    while time.monotonic() - t0 < time_limit:
        passes += 1
        improved = False

        for j in range(n):
            if time.monotonic() - t0 > time_limit:
                break

            old_val = f[j]
            if old_val < 1e-12:
                continue

            conv = fast_convolve(f)
            cur_peak = conv.max()
            best_j_val = old_val
            best_j_obj = cur_peak

            multipliers = [0.3, 0.5, 0.7, 1.3, 1.6, 2.0, 3.0]
            for mult in multipliers:
                new_val = old_val * mult
                if new_val < 0 or new_val > 0.999:
                    continue
                denom = 1.0 - old_val
                if denom < 1e-10:
                    continue
                scale = (1.0 - new_val) / denom
                f_trial = f.copy()
                f_trial[j] = new_val
                mask = np.ones(n, dtype=bool)
                mask[j] = False
                f_trial[mask] *= scale
                f_trial = f_trial / f_trial.sum()

                val = fast_convolve(f_trial).max()
                if val < best_j_obj - 1e-15:
                    best_j_obj = val
                    best_j_val = new_val

            if best_j_val != old_val:
                denom = 1.0 - old_val
                if denom > 1e-10:
                    scale = (1.0 - best_j_val) / denom
                    f[j] = best_j_val
                    mask = np.ones(n, dtype=bool)
                    mask[j] = False
                    f[mask] *= scale
                    f = f / f.sum()

                if best_j_obj < best_obj - 1e-14:
                    best_obj = best_j_obj
                    best_f = f.copy()
                    improved = True

        if not improved and passes > 2:
            break

    return best_f, best_obj


def interpolate_sequence(f, new_n):
    """Interpolate a sequence to a new length using cubic-like interpolation."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    # Use spline-like interpolation: average of linear and smoothed
    f_linear = np.interp(new_x, old_x, f)
    # Smooth a bit
    kernel = np.array([0.1, 0.35, 0.8, 0.35, 0.1])
    f_smooth = np.convolve(f_linear, kernel / kernel.sum(), mode='same')
    f_interp = 0.5 * f_linear + 0.5 * f_smooth
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp /= ss
    return f_interp


def make_initialization(n, mode, rng):
    """Create diverse initializations."""
    if mode == 'uniform':
        return np.ones(n) / n
    elif mode == 'gaussian':
        x = np.arange(n)
        sigma = n / (2.5 + rng.random() * 3.0)
        a = np.exp(-0.5 * ((x - n / 2) / sigma) ** 2)
        a += rng.random() * 0.01
        return normalize_f(a)
    elif mode == 'exponential':
        x = np.arange(n)
        tau = n / (5.0 + rng.random() * 10.0)
        a = np.exp(-x / tau) + np.exp(-(n - 1 - x) / tau)
        return normalize_f(a)
    elif mode == 'bimodal':
        x = np.arange(n)
        s1 = n * (0.2 + rng.random() * 0.1)
        s2 = n * (0.7 + rng.random() * 0.1)
        w1 = 0.5 + rng.random() * 0.5
        a = w1 * np.exp(-0.5 * ((x - s1) / (n * 0.1)) ** 2) + \
            (1 - w1) * np.exp(-0.5 * ((x - s2) / (n * 0.1)) ** 2)
        a += rng.random() * 0.005
        return normalize_f(a)
    elif mode == 'random_smooth':
        a = rng.random(n)
        # Smooth it
        k = max(3, n // 50)
        kernel = np.ones(k) / k
        a = np.convolve(a, kernel, mode='same')
        return normalize_f(a)
    elif mode == 'cosine':
        x = np.arange(n)
        freq = 1.0 + rng.random() * 3.0
        a = 0.5 + 0.5 * np.cos(2 * np.pi * freq * x / n)
        a += rng.random() * 0.01
        return normalize_f(a)
    elif mode == 'parent_interp':
        return None  # Handled externally
    else:
        return np.ones(n) / n

            t_final = min(rem * 0.7, 100)
            a_opt, _ = lse_subgradient(best_seq, time_limit=t_final,
                                       t_init=100.0, t_max=3000.0,
                                       lr_init=0.03, lr_decay=0.9999,
                                       momentum=0.95, restart_patience=150)
            try_seq(a_opt, "lse_fine")

        # Very fine LSE
        rem = deadline - time.monotonic() - 15
        if rem > 8:
            a_opt, _ = lse_subgradient(best_seq, time_limit=min(rem, 40),
                                       t_init=500.0, t_max=5000.0,
                                       lr_init=0.01, lr_decay=0.99995,
                                       momentum=0.96, restart_patience=100)
            try_seq(a_opt, "lse_very_fine")

    # === Phase 7: Tiny perturbations around best ===
    print(f"\n=== Phase 7: Perturbations (best={best_score:.6f}) ===")
    if best_seq is not None:
        for _ in range(5):
            rem = deadline - time.monotonic() - 5
            if rem < 5:
                break
            n_b = len(best_seq)
            noise = rng.standard_normal(n_b) * 0.002
            f_pert = project_simplex(best_seq + noise)
            a_opt, _ = lse_subgradient(f_pert, time_limit=min(rem, 20),
                                       t_init=200.0, t_max=5000.0,
                                       lr_init=0.01, lr_decay=0.99995,
                                       momentum=0.95)
            try_seq(a_opt, "perturb")

    # Fallback
    if best_seq is None:
        best_seq = np.ones(384) / 384
        best_score = float(evaluate_sequence(best_seq.tolist()))

    # Final verification
    fs = float(evaluate_sequence(best_seq.tolist()))
    if np.isfinite(fs):
        best_score = fs

    print(f"\nFINAL SCORE: {best_score:.8f} (n={len(best_seq)})")
    return [float(x) for x in best_seq]
