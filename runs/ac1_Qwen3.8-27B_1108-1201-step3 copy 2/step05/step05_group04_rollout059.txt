One idea: **Riemannian optimization on the simplex**. The simplex is a Riemannian manifold (with the Euclidean metric restricted to the tangent space). We can use Riemannian gradient descent or conjugate gradient.

The Euclidean gradient of `max conv(k)` (at the argmax k*) is:
`g[j] = 2*a[k*-j]` (for j where k*-j is in [0,n-1]) or 0 otherwise (with the special case for k*=2j).

Wait, I derived earlier that for k* = n-1 (center), the gradient is `2*a[n-1-j]` for all j. Let me verify:
`conv(n-1) = sum_j a[j]*a[n-1-j]`.
`∂conv(n-1)/∂a[j] = a[n-1-j] + a[n-1-j] = 2*a[n-1-j]` (since the j-th term is a[j]*a[n-1-j] and the (n-1-j)-th term is a[n-1-j]*a[j], both contributing a[n-1-j]).

Wait, that's only if j != n-1-j. If j = n-1-j (i.e., 2j = n-1), then it's a single term a[j]^2, and the gradient is 2*a[j].

So for k* = n-1: `∇conv(n-1)[j] = 2*a[n-1-j]` for all j (including the special case where j = (n-1)/2, since 2*a[j] = 2*a[n-1-j] when j = n-1-j).

Great, so the gradient at the center is simply `2*flip(a)`.

For a general k*, the gradient is more complex (depends on which terms are in range). But we can compute it numerically if needed.

For the Riemannian approach, the tangent space at point a on the simplex is {v : sum(v) = 0}. The Riemannian gradient is the projection of the Euclidean gradient onto the tangent space:
`rgrad = g - mean(g) * 1` (subtract the component in the normal direction).

Then we take a step in the Riemannian gradient direction and re-project onto the simplex.

Let me think about the coordinate descent more carefully.

For coordinate j, given the current sequence a (normalized to sum 1) and convolution c = conv(a,a):

If we change a[j] from v to v', and rescale the rest to maintain sum = 1:
- a'[j] = v'
- a'[i] = a[i] * (1-v')/(1-v) for i != j

The new convolution c' can be computed efficiently:
c'[k] = c[k] * s^2 + terms involving a'[j]

where s = (1-v')/(1-v).

More precisely:
c[k] = sum_l a[l]*a[k-l]

Let's decompose:
c[k] = a[j]*a[k-j] + a[k-j]*a[j] + sum_{l != j, k-l != j} a[l]*a[k-l]
     (with the special case j = k-j handled properly)

Actually, let me just define:
- For l != j and k-l != j: the term is a[l]*a[k-l], and in c' it becomes s^2*a[l]*a[k-l].
- For l = j (and k-j != j): the term is a[j]*a[k-j], and in c' it becomes v'*s*a[k-j].
- For k-l = j (and l != j): the term is a[l]*a[j], and in c' it becomes s*a[l]*v'.
- For l = j and k-l = j (i.e., k = 2j): the term is a[j]^2, and in c' it becomes v'^2.

So:
c'[k] = s^2 * (c[k] - c_j(k)) + c'_j(k)

where c_j(k) is the part of c[k] involving a[j], and c'_j(k) is the corresponding part in c'[k].

c_j(k) = a[j]*a[k-j] (if j valid and k-j valid and j != k-j) + a[j]^2 (if k = 2j)
       = 2*a[j]*a[k-j] (if j != k/2 and both valid) or a[j]^2 (if k = 2j)

c'_j(k) = v'*s*a[k-j] (if j != k/2 and both valid) + v'^2 (if k = 2j)
        = 2*v'*s*a[k-j] (if j != k/2) or v'^2 (if k = 2j)

This is O(n) to compute for all k given v'. Then we can try several values of v' and pick the one that minimizes max(c').

For the line search, I'll try v' values in a range around v, like [0, 2v] (clipped to [0, 1]) with, say, 10-20 trial points.

The cost per coordinate is O(n log n) for the FFT (to compute the initial c) + O(n * n_trials) for the trials. """
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Subgradient optimization with adaptive temperature
2. Coordinate descent with analytic line search
3. Pair-swap local search
4. Multi-start with diverse initializations
"""

import numpy as np
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def compute_grad_at_peak(a, k_star):
    """Compute gradient of conv(k_star) w.r.t. a."""
    n = len(a)
    grad = np.zeros(n)
    for j in range(n):
        # conv(k_star) involves a[j] in terms where l=j or k_star-l=j
        # i.e., a[j]*a[k_star-j] and a[k_star-j]*a[j]
        k2 = k_star - j
        if 0 <= k2 < n:
            if k2 == j:
                grad[j] = 2.0 * a[j]
            else:
                grad[j] = 2.0 * a[k2]
    return grad


def subgradient_optimize(a0, time_limit, lr=0.005, temp_init=0.005,
                         temp_decay=0.9995, top_k=10, verbose=False):
    """Subgradient method with Adam and adaptive temperature."""
    a = a0.astype(np.float64).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a0)) / len(a0)
    else:
        a = a / s
    n = len(a)

    m = np.zeros(n)
    v = np.zeros(n)
    t = 0
    temp = temp_init
    cur_lr = lr

    conv = fast_convolve(a)
    best_obj = conv.max()
    best_a = a.copy()

    t0 = time.monotonic()
    no_improve = 0

    while time.monotonic() - t0 < time_limit:
        t += 1
        conv = fast_convolve(a)
        max_val = conv.max()
        
        # Weighted subgradient: use top-k peaks
        if top_k is not None and top_k < len(conv):
            # Get top-k indices
            top_idx = np.argpartition(conv, -top_k)[-top_k:]
            # Use inverse as weight (higher conv value = higher weight)
            weights = conv[top_idx]
            weights = weights / weights.sum()
            grad = np.zeros(n)
            for idx in top_idx:
                g = compute_grad_at_peak(a, idx)
                grad += weights[np.argmax(top_idx == idx)] * g
        else:
            # Hard subgradient at argmax
            k_star = np.argmax(conv)
            grad = compute_grad_at_peak(a, k_star)
            
        # Adam update
        m = 0.9 * m + 0.1 * grad
        v = 0.999 * v + 0.001 * grad * grad
        m_hat = m / (1 - 0.9**t)
        v_hat = v / (1 - 0.999**t)
        
        a_new = a - cur_lr * m_hat / (np.sqrt(v_hat) + 1e-8)
        a = project_simplex(a_new)

        temp = max(temp * temp_decay, 1e-8)
        cur_lr = max(lr * (0.9999**t), lr * 0.1)

        conv = fast_convolve(a)
        cur_obj = conv.max()

        if cur_obj < best_obj - 1e-14:
            best_obj = cur_obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1

        if no_improve > 200:
            rng = np.random.default_rng(t * 31 + 7)
            noise = 0.005 + 0.003 * min(no_improve // 100, 3)
            a = project_simplex(best_a + rng.standard_normal(n) * noise)
            m = np.zeros(n)
            v = np.zeros(n)
            t = 0
            cur_lr = lr
            no_improve = 0

    return best_a, best_obj


def coordinate_descent(a0, time_limit, n_trials=15, verbose=False):
    """Coordinate descent with analytic line search."""
    a = a0.astype(np.float64).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a0)) / len(a0)
    else:
        a = a / s
    n = len(a)

    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    t0 = time.monotonic()
    passes = 0
    no_improve_passes = 0

    while time.monotonic() - t0 < time_limit:
        passes += 1
        improved = False
        conv = fast_convolve(a)

        # Process coordinates in random order for diversity
        rng = np.random.default_rng(passes * 1000 + 42)
        order = rng.permutation(n)

        for j in order:
            if time.monotonic() - t0 > time_limit:
                    break
            old_val = a[j]
            if old_val < 1e-14:
                continue

            s_factor_base = 1.0 - old_val
            if s_factor_base < 1e-12:
                continue

            best_trial_obj = conv.max()
            best_trial_val = old_val

            # Try several values of new_val
            # Range: [max(0, old_val - 0.5*old_val), min(1, old_val + 0.5*old_val)]
            # Also try some extreme values
            low = max(0.0, old_val * 0.3)
            high = min(0.5, old_val * 2.0)
            trial_vals = np.linspace(low, high, n_trials)
            # Add old_val and 0
            trial_vals = np.unique(np.concatenate([trial_vals, [old_val, 0.0, high * 1.5]]))
            trial_vals = [tv for tv in trial_vals if 0 <= tv < 1.0]

            for new_val in trial_vals:
                if abs(new_val - old_val) < 1e-15:
                    continue
                s_factor = (1.0 - new_val) / s_factor_base
                if s_factor < 0 or s_factor > 10:
                    continue

                # Compute new convolution analytically
                # c'[k] = s^2 * (c[k] - c_j(k)) + c'_j(k)
                c_new = np.zeros(2*n - 1)
                # For each k, the part involving a[j]:
                # c_j(k) = 2*a[j]*a[k-j] if 0<=k-j<n and k-j!=j
                #         = a[j]^2 if k==2j
                # c'_j(k) = 2*new_val*s*a[k-j] if 0<=k-j<n and k-j!=j
                #          = new_val^2 if k==2j
                
                for k in range(2*n - 1):
                    k2 = k - j
                    if 0 <= k2 < n:
                        if k2 == j:
                            cj = old_val * old_val
                            cnew_j = new_val * new_val
                        else:
                            cj = 2.0 * old_val * a[k2]
                            cnew_j = 2.0 * new_val * s_factor * a[k2]
                        c_new[k] = s_factor * s_factor * (conv[k] - cj) + cnew_j
                    else:
                        c_new[k] = s_factor * s_factor * conv[k]

                obj = c_new.max()
                if obj < best_trial_obj - 1e-15:
                    best_trial_obj = obj
                    best_trial_val = new_val

            if best_trial_val != old_val:
                s_factor = (1.0 - best_trial_val) / s_factor_base
                a[j] = best_trial_val
                mask = np.ones(n, dtype=bool)
                mask[j] = False
                a[mask] *= s_factor
                a = a / a.sum()  # renormalize for numerical stability

                if best_trial_obj < best_obj - 1e-14:
                    best_obj = best_trial_obj
                    best_a = a.copy()
                    improved = True

        if not improved and no_improve_passes > 3:
            # Try a perturbation to escape local minimum
            rng = np.random.default_rng(passes * 7 + 3)
            a = project_simplex(best_a + rng.standard_normal(n) * 0.003)
            no_improve_passes = 0
        elif not improved:
            no_improve_passes += 1
        else:
            no_improve_passes = 0

    return best_a, best_obj

But actually, I can optimize further. Instead of doing a full FFT for each trial, I can use the analytical formula I derived earlier, which is O(n) per trial (just computing the change in conv):

For a given j and new_val, with s_factor = (1-new_val)/(1-old_val):
- The change in conv[k] is:
  - For k where 0 <= k-j < n and k-j != j: Δc[k] = s^2*conv[k] - conv[k] + 2*new_val*s*a[k-j] - 2*old_val*a[k-j]
    = (s^2 - 1)*conv[k] + 2*(new_val*s - old_val)*a[k-j]
  - For k = 2j: Δc[k] = (s^2 - 1)*conv[k] + new_val^2 - old_val^2
  - For k where k-j is out of range: Δc[k] = (s^2 - 1)*conv[k]

Wait, this isn't quite right because the "terms not involving j" in conv[k] are scaled by s^2, but the terms involving j are replaced.

Let me redefine. Let conv[k] = T_k + U_k where:
- U_k = part involving a[j] = 2*a[j]*a[k-j] (if valid and k-j != j) or a[j]^2 (if k=2j) or 0
- T_k = conv[k] - U_k (part NOT involving a[j])

Then c_new[k] = s^2 * T_k + U_new_k where:
- U_new_k = 2*new_val*s*a[k-j] (if valid and k-j != j) or new_val^2 (if k=2j) or 0

So c_new[k] = s^2 * (conv[k] - U_k) + U_new_k

This is O(n) to compute for all k (since we just need to compute U_k for all k, which is O(n)).

Let me implement this:

```python
def compute_conv_change(a, conv, j, new_val):
    """Compute new convolution after changing a[j] to new_val and rescaling rest."""
    n = len(a)
    old_val = a[j]
    s = (1.0 - new_val) / (1.0 - old_val)
    s2 = s * s
    
    c_new = s2 * conv.copy()
    
    # Subtract old U_k and add new U_new_k
    for k in range(2*n - 1):
        k2 = k - j
        if 0 <= k2 < n:
            if k2 == j:
                old_U = old_val * old_val
                new_U = new_val * new_val
            else:
                old_U = 2.0 * old_val * a[k2]
                new_U = 2.0 * new_val * s * a[k2]
            c_new[k] = s2 * (conv[k] - old_U) + new_U
    
    return c_new
```

This is O(n) per trial (the loop over k). With n_trials=20 and n=768, that's 20*1535 ≈ 30K operations per coordinate. For 768 coordinates: 768 * 30K ≈ 23M per pass. Very fast!

    old_val = a[j]
    s = (1.0 - new_val) / (1.0 - old_val)
    s2 = s * s
    
    c_new = s2 * conv

    # Valid when 0 <= k2 < n, i.e., j <= k <= j+n-1
    k_start = max(j, 0)
    k_end = min(j + n - 1, 2*n - 2)

        k2_indices = k_indices - j  # These are in [0, n-1]

        old_U = 2.0 * old_val * a[k2_indices]
