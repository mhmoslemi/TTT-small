The auto-convolution c = a * a has DFT: C = |A|^2 where A = DFT(a).
We want to minimize max(c) = max(IDFT(|A|^2)).

The constraint sum(a) = 1 means A[0] = n (or sqrt(n), depending on convention). Let's use numpy's convention: A[k] = sum_j a[j] * exp(-2πijk/n). Then A[0] = sum(a) = 1.

We want to minimize max(j) IDFT(|A|^2)[j]. The "flattest" |A|^2 would minimize the peak of IDFT. But |A|^2 is determined by |A|, and we can only change the phase of A (keeping |A| fixed) to change a while maintaining sum(a) = 1 and a real.

The POCS approach:
1. Start with a (non-negative, sum = 1)
2. A = FFT(a)
3. Modify |A| to be flatter (e.g., |A_new| = (|A|^p + eps)^(1/p) for some p < 1, or use soft clipping)
4. Keep the phase of A: A_new = |A_new| * exp(i*angle(A))
5. Ensure A_new[0] = 1 (DC component)
6. a_new = IFFT(A_new).real
7. Project a_new onto {a: a >= 0, sum(a) = 1}
8. Repeat

The "flattening" in step 3 is the key tuning parameter. Too much flattening makes the time-domain signal oscillatory (negative values), which then get clipped in the projection, losing information.

Let me think about what "flat" target to use. The ideal |A| would give the flattest possible |A|^2 in time domain. This is related to the "flat spectrum" problem.

For a sequence of length n, the "maximum entropy" spectrum (flat) would be |A[k]| = constant for all k. This would give a white noise time-domain signal, which has auto-conv ≈ delta. But a real, non-negative time-domain signal can't have a perfectly flat spectrum.

A practical target: |A_new[k]| = sqrt(|A[k]|^2 * alpha + (1-alpha) * mean(|A|^2)) for some alpha in (0,1). This interpolates between the current spectrum and the flat spectrum.

Or: |A_new[k]| = |A[k]|^beta for some beta < 1 (compression toward flat).

"""
Hybrid optimization: spectral POCS + fast subgradient + precise coordinate descent
with incremental O(n) auto-conv updates. Targets score < 1.5027.
"""

import numpy as np
import time

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def compute_score(a, c=None):
    n = len(a)
    s = a.sum()
    if s < 1e-15:
        return float('inf')
    if c is None:
        c = fast_convolve(a)
    return float(2.0 * n * c.max() / (s * s))

def project_simplex(v):
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def spectral_iteration(a, n_iters=100, compression=0.5, verbose=False):
    """POCS/GRAM-style spectral iteration."""
    a = a.copy().astype(float)
    a = project_simplex(a)
    best_a = a.copy()
    best_score = compute_score(a)
    
    for it in range(n_iters):
        A = np.fft.rfft(a)
        mag = np.abs(A)
        phase = np.angle(A)
        
        # Compress magnitude toward flat
        mean_mag = mag.mean()
        new_mag = mag ** compression  # compression < 1 flattens
        # Actually, let's use: new_mag = (mag^2 * alpha + (1-alpha)*mean_mag^2)^(1/2)
        # Or simply: new_mag = mag^compression where compression in (0,1)
        
        A_new = new_mag * np.exp(1j * phase)
        A_new[0] = a.sum()  # Preserve DC
        
        a_new = np.fft.irfft(A_new, len(a))
        a_new = project_simplex(a_new)
        
        sc = compute_score(a_new)
        if sc < best_score:
            best_score = sc
            best_a = a_new.copy()
        
        a = a_new
    
    return best_a, best_score

def subgradient_descent(a, t_limit, lr0=0.1, decay=0.999, top_k=20, verbose=False):
    """Fast subgradient with multiple peaks."""
    n = len(a)
    a = project_simplex(a.copy())
    c = fast_convolve(a)
    best_a = a.copy()
    best_score = compute_score(a, c)
    t0 = time.monotonic()
    step = 0
    lr = lr0
    
    while time.monotonic() - t0 < t_limit:
        step += 1
        k_actual = min(top_k, len(c))
        peaks = np.argpartition(c, -k_actual)[-k_actual:]
        pv = c[peaks]
        pmax, pmin = pv.max(), pv.min()
        temp = max(1e-10, pmax - pmin) * 0.3
        w = np.exp((pv - pmax) / temp)
        w /= w.sum()
        
        # Subgradient
        sg = np.zeros(n)
        for i in range(k_actual):
            if w[i] < 1e-12:
                continue
            k = int(peaks[i])
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            sg[idx] += 2.0 * w[i] * a[k - idx]
        
        # Multiplicative update
        a = np.maximum(a * np.exp(-lr * sg), 1e-18)
        a = project_simplex(a)
        
        c = fast_convolve(a)
        sc = compute_score(a, c)
        if sc < best_score:
            best_score = sc
            best_a = a.copy()
        
        lr *= decay
        if step % 10000 == 0:
            lr = max(lr, lr0 * 0.01)
    
    return best_a, best_score

Option 2: |A_new| = (|A|^2 + λ * mean(|A|^2))^(1/2)
- λ=0: no change  
- λ→∞: flat
- This adds a "noise floor" to the spectrum

Option 3: Soft thresholding: |A_new| = max(|A| - τ, 0) or |A_new| + τ
- Reduces peaks or raises valleys

Instead of trying random candidate values, I can compute the exact optimal v for coordinate j by solving:
minimize max_k (d[k] + v*W[k] + v^2*[k=2j]) / (sum_base + v)^2

Taking the derivative and setting to 0 gives a complex equation. But I can use the following observation:

The max is achieved at some k*. At the optimum, either:
- v = 0 (boundary)
- The derivative of the score w.r.t. v at the active peak is zero
- Two peaks are tied (the max switches)

For the active peak k*, the score is:
f(v) = 2n * (d[k*] + v*W[k*] + v^2*[k*=2j]) / (sum_base + v)^2

df/dv = 2n * [(W[k*] + 2v*[k*=2j])*(sum_base+v) - 2*(d[k*]+v*W[k*]+v^2*[k*=2j])] / (sum_base+v)^3

Setting df/dv = 0:
(W[k*] + 2v*δ) * (S+v) = 2*(d[k*] + v*W[k*] + v^2*δ)
where δ = [k*=2j], S = sum_base

Expanding:
W[k*]*S + W[k*]*v + 2v*δ*S + 2v^2*δ = 2*d[k*] + 2*v*W[k*] + 2*v^2*δ

W[k*]*S + W[k*]*v + 2v*δ*S + 2v^2*δ - 2*d[k*] - 2*v*W[k*] - 2*v^2*δ = 0

W[k*]*S - W[k*]*v + 2v*δ*S - 2*d[k*] = 0

v * (2δ*S - W[k*]) = 2*d[k*] - W[k*]*S

v = (2*d[k*] - W[k*]*S) / (2δ*S - W[k*])  (if denominator ≠ 0)

This gives the optimal v for a fixed active peak k*! I can compute this for the current argmax and also for nearby peaks.

def coord_descent_precise_fast(a, c, t_limit, verbose=False):
    n = len(a)
    a = a.copy()
    total = a.sum()
    c = c.copy()
    best_a = a.copy()
    best_score = compute_score(a, c)
    t0 = time.monotonic()
    rng = np.random.default_rng(42)
    pass_count = 0
    
    while time.monotonic() - t0 < t_limit:
        pass_count += 1
        improved = False
        order = rng.permutation(n)
        
        for j in order:
            if time.monotonic() - t0 > t_limit:
                break
            old = a[j]
            if old < 1e-14:
                continue
            
            # Compute W
            W = np.zeros(2*n - 1)
            k_lo = max(0, j)  # k-j >= 0 => k >= j
            k_hi = min(2*n-2, j + n - 1)  # k-j < n => k < j+n
            valid_ks = np.arange(k_lo, k_hi + 1)
            W[valid_ks] = 2.0 * a[valid_ks - j]
            # Fix the k=2j case: W[2j] should be 0 (handled separately)
            if 2*j < 2*n-1:
                W[2*j] = 0.0
            
            # Compute d
            d = c - old * W
            if 2*j < 2*n-1:
                d[2*j] -= old * old
            
            S = total - old  # sum of all other coordinates
            
            # Find top peaks in c
            top_k = min(5, len(c))
            peak_indices = np.argpartition(c, -top_k)[-top_k:]
            
            candidates = [0.0, old]
            for k_star in peak_indices:
                # Compute v_opt for this peak
                w_val = W[k_star]
                delta = 1.0 if k_star == 2*j else 0.0
                d_val = d[k_star]
                
                denom = 2*delta*S - w_val
                if abs(denom) < 1e-15:
                    continue
                v_opt = (2*d_val - w_val*S) / denom
                if v_opt > 0 and v_opt < 2*old + S:
                    candidates.append(v_opt)
            
            # Evaluate all candidates
            best_v = old
            best_sc = best_score
            for v in candidates:
                v = max(0.0, v)
                if abs(v - old) < 1e-14:
                    continue
                new_c = d + v * W
                if 2*j < len(c):
                    new_c[2*j] += v * v
                new_sum = S + v
                if new_sum < 1e-15:
                    continue
                sc = 2.0 * n * new_c.max() / (new_sum * new_sum)
                if sc < best_sc:
                    best_sc = sc
                    best_v = v
            
            if best_v != old:
                a[j] = best_v
                total = S + best_v
                c = d + best_v * W
                if 2*j < len(c):
                    c[2*j] += best_v * best_v
                if best_sc < best_score:
                    best_score = best_sc
                    best_a = a.copy()
                    improved = True
        
        if not improved:
            if pass_count > 3:
                break
            # Add small noise to escape
            a += rng.standard_normal(n) * 1e-5
            a = np.maximum(a, 0)
            a = a / a.sum()
            total = a.sum()
            c = fast_convolve(a)
    
    return best_a, best_score

"""
Hybrid optimization combining spectral POCS iterations, fast subgradient descent,
and precise coordinate descent with O(n) incremental auto-conv updates and
analytical 1D subproblem solutions. Multi-scale local search and diverse
initializations (geometric, trapezoidal, two-lobe, spectral-flat) with

import numpy as np
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def compute_score(a, c=None):
    """Compute 2*n*max_conv/sum^2."""
    n = len(a)
    s = a.sum()
    if s < 1e-15:
        return float('inf')
    if c is None:
        c = fast_convolve(a)
    return float(2.0 * n * c.max() / (s * s))


def project_simplex(v):
    """Euclidean projection onto probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def geometric_sequence(n, r):
    a = (1.0 - r) * r ** np.arange(n)
    s = a.sum()
    if s > 1e-15:
