   The LP condition (f*g)[k] <= M is a sufficient (but not necessary) condition for small t:
   - For active k: (f*g)[k] <= M = (f*f)[k], so Δ <= 0. ✓
   - For inactive k: (f*g)[k] <= M, and we need (f*f)[k] + 2t*(f*g)[k] <= M, i.e., 2t*(f*g)[k] <= M - (f*f)[k]. Since (f*g)[k] <= M, we need 2t*M <= M - (f*f)[k], i.e., (f*f)[k] <= M(1-2t). For t < (M - min(f*f))/(2M), this holds for all k.

   So for sufficiently small t, the LP condition ensures the peak doesn't increase. Good.

   So the algorithm is:
   1. Compute M = max(f*f)
   2. Solve LP: max sum(g) s.t. (f*g)[k] <= M for all k, g >= 0
   3. Let S = optimal value. If S <= 1 + eps, we're at a local optimum.
   4. g = g* / S (normalize to sum 1)
   5. f_new = (1-t)*f + t*g for small t (e.g., t = 0.1 or adaptive)
   6. f = f_new / sum(f_new) (renormalize)
