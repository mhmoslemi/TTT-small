- **Golden section coordinate descent** is much more precise
- **Adam optimizer** converges faster than the simple momentum approach
- **Active-set balancing** directly targets the structure of the optimum
- **More time spent on local search** with finer steps

Let me code this up properly.

Actually, for the golden section coordinate descent, let me think about how it works:
- Fix all coordinates except j
- We want to find a_j* that minimizes max(conv)
- The relationship: if we change a_j from v to v', we need to rescale the other coordinates to maintain sum=1
- Let s_other = 1 - v (sum of all other coordinates)
- If we change a_j to v', the others scale by (1-v')/s_other
- So the new sequence is: a'[j] = v', a'[i] = a[i] * (1-v')/s_other for i != j
- The conv of a' as a function of v' is a function we can evaluate and search over

This is a 1D optimization problem! We can use golden section search or even a fine grid.

The range of v' is [0, 1]. For each v', we compute conv(a') and track the max.

This is O(1) per evaluation (one FFT), and golden section needs ~30 evaluations per coordinate. For n=768, that's 768*30 = 23040 FFT evaluations per pass. Each FFT is O(n log n) ≈ 768*10 ≈ 8000 ops. So one pass is about 23040 * 8000 ≈ 184M ops. At ~100M ops/sec (numpy is faster), that's about 2 seconds per pass. So we can do many passes in 300 seconds.

Actually, numpy FFT is much faster than that. Let me estimate: for n=768, FFT should take about 50 microseconds. So 23040 evaluations * 50us = ~1.2 seconds per pass. We can do ~250 passes in 300 seconds. That's plenty.

Let me also add a "pair coordinate descent" where we optimize two coordinates simultaneously.

For the active-set balancing:
- Identify the top-m positions where conv is near max
- The idea is: at the optimum, these should all be equal (by complementary slackness)
- So we want to find adjustments that reduce the maximum while keeping these balanced
- One approach: compute the subgradient (average of subgradients at active points), take a step in the negative direction, project to simplex

This is essentially what the subgradient method does, but we can be more aggressive by:
- Using a larger step size (with backtracking)
- Focusing only on the active set
- Using a "balancing" heuristic: move mass from positions that contribute to the active conv values

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Smooth log-sum-exp optimization with Adam on the simplex
2. Golden-section coordinate descent (1D optimization per coordinate)
3. Active-set subgradient balancing
4. Randomized local search with multiple restarts
5. Multi-length exploration
"""

import numpy as np
import time

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v, target_sum=1.0):
    """Euclidean projection onto {x>=0, sum(x)=target_sum}."""
    n = len(v)
    if n == 0:
        return v.copy()
    if target_sum <= 0:
        return np.zeros(n)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = (u - (cssv - target_sum) / np.arange(1, n + 1)) > 0
    if not cond.any():
        return np.full(n, target_sum / n)
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - target_sum) / (rho + 1)
    return np.maximum(v - theta, 0.0)

def compute_smooth_grad(a, tau, top_k=200):
    """Compute gradient of log-sum-exp approximation of max(conv)."""
    n = len(a)
    conv = fast_convolve(a)
    k = min(top_k, len(conv))
    
    if k == len(conv):
        top_idx = np.arange(len(conv))
        top_vals = conv
    else:
        top_idx = np.argpartition(conv, -k)[-k:]
        top_vals = conv[top_idx]
    
    m = top_vals.max()
    w = np.exp(tau * (top_vals - m))
    ws = w.sum()
    if ws < 1e-300:
        w = np.zeros(k)
        w[np.argmax(top_vals)] = 1.0
    else:
        w /= ws
    
    grad = np.zeros(n)
    for idx in range(k):
        if w[idx] < 1e-18:
            continue
        ki = int(top_idx[idx])
        wi = w[idx]
        js = max(0, ki - n + 1)
        je = min(n - 1, ki)
        idx_arr = np.arange(js, je + 1)
        grad[idx_arr] += 2.0 * wi * a[ki - idx_arr]
    
    return grad, conv, top_idx, top_vals

def adam_step_simplex(a, grad, m, v, beta1, beta2, lr, t, eps=1e-8):
    """Adam step with simplex projection."""
    m = beta1 * m + (1 - beta1) * grad
    v = beta2 * v + (1 - beta2) * (grad ** 2)
    m_hat = m / (1 - beta1 ** t)
    v_hat = v / (1 - beta2 ** t)
    step = m_hat / (np.sqrt(v_hat) + eps)
    a_new = project_simplex(a - lr * step, 1.0)
    return a_new, m, v

def optimize_adam(a0, time_limit, tau_init=50, tau_max=500, top_k=200, verbose=False):
    """Adam optimization with smooth log-sum-exp objective on simplex."""
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a0)) / len(a0)
    else:
        a = a / s
    n = len(a)
    
    conv = fast_convolve(a)
    best_obj = conv.max()
    best_a = a.copy()
    
    m = np.zeros(n)
    v = np.zeros(n)
    beta1, beta2 = 0.8, 0.999
    lr = 0.01
    tau = tau_init
    t = 0
    t0 = time.monotonic()
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        t += 1
        grad, conv, _, _ = compute_smooth_grad(a, tau, top_k)
        
        # Center gradient
        grad = grad - grad.mean()
        
        a_new, m, v = adam_step_simplex(a, grad, m, v, beta1, beta2, lr, t)
        
        obj_new = fast_convolve(a_new).max()
        
        if obj_new < best_obj - 1e-12:
            best_obj = obj_new
            best_a = a_new.copy()
            no_improve = 0
            # Adaptive: decrease lr slightly on improvement
        else:
            no_improve += 1
        
        a = a_new
        
        # Adaptive tau and lr
        if no_improve > 200:
            tau = min(tau_max, tau * 1.02)
            lr = max(0.001, lr * 0.95)
            if no_improve > 500:
                # Restart with perturbation
                rng = np.random.default_rng(t)
                noise = rng.standard_normal(n) * 0.003
                a = project_simplex(best_a + noise, 1.0)
                m = np.zeros(n)
                v = np.zeros(n)
                no_improve = 0
                lr = 0.008
                tau = max(50, tau * 0.8)
        elif no_improve > 100:
            tau = min(tau_max, tau * 1.01)
        
        if verbose and t % 100 == 0:
            print(f"    Adam t={t}: obj={best_obj:.10f}, tau={tau:.1f}, lr={lr:.5f}, no_imp={no_improve}")
    
    return best_a, best_obj

def golden_section_coord_descent(a0, time_limit, n_iter_target=None, verbose=False):
    """Golden section coordinate descent for 1D optimization per coordinate."""
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a0)) / len(a0)
    else:
        a = a / s
    n = len(a)
    
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    t0 = time.monotonic()
    pass_count = 0
    golden_ratio = (np.sqrt(5) - 1) / 2  # ~0.618
    
    # Only optimize coordinates with non-negligible values
    support_threshold = 1e-10
    
    while time.monotonic() - t0 < time_limit:
        pass_count += 1
        improved = False
        
        for j in range(n):
            if time.monotonic() - t0 > time_limit:
                break
            
            old_val = a[j]
            if old_val < support_threshold:
                continue
            
            # 1D optimization: find best v_j given others are rescaled
            s_other = 1.0 - old_val
            if s_other < 1e-12:
                continue
            
            def obj_1d(vj):
                if vj < -1e-15 or vj > 1.0 + 1e-15:
                    return float('inf')
                vj = np.clip(vj, 0.0, 1.0)
                scale = (1.0 - vj) / s_other
                a_trial = a.copy()
                a_trial[j] = vj
                a_trial[j] = vj  # set to vj
                # Scale others
                mask = np.ones(n, dtype=bool)
                mask[j] = False
                a_trial[mask] *= scale
                obj = fast_convolve(a_trial).max()
                return obj
            
            # Golden section search in [0, 1]
            # But we can narrow the range: [old_val * 0.1, old_val * 2.0] clipped to [0,1]
            lo = max(0.0, old_val * 0.3)
            hi = min(1.0, old_val * 3.0)
            
            # Ensure the current point is in the interval
            if old_val < lo or old_val > hi:
                lo = max(0.0, old_val * 0.5)
                hi = min(1.0, old_val * 2.0)
            
            # Golden section
            gr = (np.sqrt(5) - 1) / 2
            c = hi - gr * (hi - lo)
            d = lo + gr * (hi - lo)
            fc = obj_1d(c)
            fd = obj_1d(d)
            
            for _ in range(40):
                if fc < fd:
                    hi = d
                    d = c
                    fd = fc
                    c = hi - gr * (hi - lo)
                    fc = obj_1d(c)
                else:
                    lo = c
                    c = d
                    fc = fd
                    d = lo + gr * (hi - lo)
                    fd = obj_1d(d)
            
            vj_best = (lo + hi) / 2
            obj_best = obj_1d(vj_best)
            
            # Compare with current
            if obj_best < best_obj - 1e-13:
                # Apply
                scale = (1.0 - vj_best) / s_other
                a[j] = vj_best
                mask = np.ones(n, dtype=bool)
                mask[j] = False
                a[mask] *= scale
                a = np.maximum(a, 0)
                a /= a.sum()  # numerical safety
                best_obj = obj_best
                best_a = a.copy()
                improved = True
        
        if verbose and pass_count % 5 == 0:
            elapsed = time.monotonic() - t0
            print(f"    CD pass {pass_count}: obj={best_obj:.10f} ({elapsed:.0f}s)")
        
        if not improved and pass_count > 3:
            break
    
    return best_a, best_obj

def pair_local_search(a0, time_limit, seed=42, n_trials_per_round=200):
    """Randomized pair-swap local search with adaptive transfer amounts."""
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a0)) / len(a0)
    else:
        a = a / s
    n = len(a)
    
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)
    
    support = np.where(a > 1e-6)[0]
    if len(support) == 0:
        support = np.arange(n)
    
    while time.monotonic() - t0 < time_limit:
        round_obj = best_obj
        for _ in range(n_trials_per_round):
            if time.monotonic() - t0 > time_limit:
                break
            
            idx = rng.integers(0, len(support), size=2)
            i, j = int(support[idx[0]]), int(support[idx[1]])
            if i == j:
                continue
            
            val_i, val_j = a[i], a[j]
            if val_i < 1e-8 or val_j < 1e-8:
                continue
            
            # Try several transfer amounts
            max_transfer = 0.4 * min(val_i, val_j)
            num_trials = 8
            fractions = rng.uniform(0.01, 1.0, num_trials)
            directions = rng.choice([-1, 1], num_trials)
            
            for frac, direction in zip(fractions, directions):
                transfer = direction * frac * max_transfer
                new_i = val_i + transfer
                new_j = val_j - transfer
                if new_i < -1e-15 or new_j < -1e-15:
                    continue
                new_i = max(0.0, new_i)
                new_j = max(0.0, new_j)
                
                a_trial = a.copy()
                a_trial[i] = new_i
                a_trial[j] = new_j
                a_trial /= a_trial.sum()
                
                val = fast_convolve(a_trial).max()
                if val < best_obj - 1e-14:
                    best_obj = val
                    best_a = a_trial.copy()
                    a = a_trial.copy()
                    round_obj = best_obj
        
        # Update support
        if best_obj < round_obj:
            support = np.where(a > 1e-6)[0]
            if len(support) == 0:
                support = np.arange(n)
    
    return best_a, best_obj

def active_set_balance(a0, time_limit, top_k=50, verbose=False):
    """Optimize by balancing the top-k convolution values."""
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a0)) / len(a0)
    else:
        a = a / s
    n = len(a)
    
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    t0 = time.monotonic()
    lr = 0.005
    tau = 100
    
    v = np.zeros(n)
    momentum = 0.85
    no_improve = 0
    iter_count = 0
    
    while time.monotonic() - t0 < time_limit:
        iter_count += 1
        conv = fast_convolve(a)
        k_actual = min(top_k, len(conv))
        top_idx = np.argpartition(conv, -k_actual)[-k_actual:]
        top_vals = conv[top_idx]
        
        m = top_vals.max()
        w = np.exp(tau * (top_vals - m))
        ws = w.sum()
        if ws < 1e-300:
            w = np.zeros(k_actual)
            w[np.argmax(top_vals)] = 1.0
        else:
            w /= ws
        
        # Also include some "second tier" with lower weight
        # to avoid getting stuck
        all_idx = np.argsort(conv)[::-1]
        tier2_start = k_actual
        tier2_end = min(2 * k_actual, len(conv))
        if tier2_end > tier2_start:
            tier2_idx = all_idx[tier2_start:tier2_end]
            tier2_vals = conv[tier2_idx]
            w2 = 0.1 * np.exp(tau * 0.5 * (tier2_vals - m))
            w2s = w2.sum()
            if w2s > 1e-300:
                w2 /= w2s
            else:
                w2 = np.zeros(len(tier2_idx))
        else:
            tier2_idx = np.array([])
            w2 = np.array([])
        
        # Compute gradient
        grad = np.zeros(n)
        for idx in range(k_actual):
            if w[idx] < 1e-15:
                continue
            ki = int(top_idx[idx])
            wi = w[idx]
            js = max(0, ki - n + 1)
            je = min(n - 1, ki)
            idx_arr = np.arange(js, je + 1)
            grad[idx_arr] += 2.0 * wi * a[ki - idx_arr]
        
        for idx in range(len(tier2_idx)):
            if w2[idx] < 1e-15:
                continue
            ki = int(tier2_idx[idx])
            wi = w2[idx]
            js = max(0, ki - n + 1)
            je = min(n - 1, ki)
            idx_arr = np.arange(js, je + 1)
            grad[idx_arr] += 2.0 * wi * a[ki - idx_arr]
        
        # Step
        grad_centered = grad - grad.mean()
        v = momentum * v - lr * grad_centered
        a_new = project_simplex(a + v, 1.0)
        
        obj_new = fast_convolve(a_new).max()
        
        if obj_new < best_obj - 1e-12:
            best_obj = obj_new
            best_a = a_new.copy()
            no_improve = 0
            # Decrease learning rate slightly
            lr = max(0.001, lr * 0.999)
        else:
            no_improve += 1
            if no_improve > 100:
                lr = max(0.001, lr * 0.9)
                momentum = min(0.95, momentum + 0.002)
        
        a = a_new
        
        if verbose and iter_count % 200 == 0:
            print(f"    ASB iter {iter_count}: obj={best_obj:.10f}")
    
    return best_a, best_obj

def interpolate_sequence(f, new_n):
    """Interpolate a normalized sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp /= ss
    return f_interp

def flat_spectrum_init(n, rng):
    """Generate non-negative sequence with approximately flat cyclic spectrum."""
    phases = rng.uniform(0, 2 * np.pi, n)
    A = np.zeros(n, dtype=complex)
    A[0] = np.sqrt(n)
    half = n // 2
    for k in range(1, half + 1):
        mag = 1.0
        A[k] = mag * np.exp(1j * phases[k])
        if k < n - k:
            A[n - k] = np.conj(A[k])
    if n % 2 == 0:
        A[n // 2] = 1.0
    a = np.fft.ifft(A).real
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-10:
        return np.ones(n) / n
    return a / s

import numpy as np

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v, target_sum=1.0):
    """Euclidean projection onto {x>=0, sum(x)=target_sum}."""
    n = len(v)
    if n == 0:
        return v.copy()
    if target_sum <= 0:
        return np.zeros(n)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = (u - (cssv - target_sum) / np.arange(1, n + 1)) > 0
    if not cond.any():
        return np.full(n, target_sum / n)
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - target_sum) / (rho + 1)
    return np.maximum(v - theta, 0.0)


def compute_smooth_grad(a, tau, top_k=200):
    """Compute gradient of log-sum-exp approximation of max(conv)."""
    n = len(a)
    conv = fast_convolve(a)
    k = min(top_k, len(conv))
    if k == len(conv):
        top_idx = np.arange(len(conv))
        top_vals = conv
    else:
        top_idx = np.argpartition(conv, -k)[-k:]
        top_vals = conv[top_idx]
    m = top_vals.max()
    w = np.exp(tau * (top_vals - m))
    ws = w.sum()
    if ws < 1e-300:
        w = np.zeros(k)
        w[np.argmax(top_vals)] = 1.0
    else:
        w /= ws
    grad = np.zeros(n)
    for idx in range(k):
        if w[idx] < 1e-18:
            continue
        ki = int(top_idx[idx])
        wi = w[idx]
        js = max(0, ki - n + 1)
        je = min(n - 1, ki)
        idx_arr = np.arange(js, je + 1)
        grad[idx_arr] += 2.0 * wi * a[ki - idx_arr]
    return grad, conv, top_idx, top_vals

def coord_obj(a, j, vj):
    """Evaluate objective for 1D coordinate optimization at coordinate j with value vj."""
    n = len(a)
    old_val = a[j]
    s_other = 1.0 - old_val
    if s_other < 1e-14:
        return float('inf')
    vj = max(0.0, min(1.0, vj))
    scale = (1.0 - vj) / s_other
    a_trial = a.copy()
    mask = np.ones(n, dtype=bool)
    mask[j] = False
    a_trial[mask] *= scale
    a_trial[j] = vj
    a_trial = np.maximum(a_trial, 0)
    ss = a_trial.sum()
    if ss < 1e-14:
        return float('inf')
    return fast_convolve(a_trial / ss).max()


def golden_section_cd(a0, time_limit, verbose=False):
    """Golden-section coordinate descent: precise 1D search per coordinate."""
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a0)) / len(a0)
    else:
        a = a / s
    n = len(a)
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    t0 = time.monotonic()
    pass_count = 0
    gr = (np.sqrt(5.0) - 1.0) / 2.0

    while time.monotonic() - t0 < time_limit:
        pass_count += 1
        improved = False
        for j in range(n):
            if time.monotonic() - t0 > time_limit:
                break
            old_val = a[j]
            if old_val < 1e-10:
                continue
            # Narrow search range around current value
            lo = max(0.0, old_val * 0.2)
            hi = min(1.0, old_val * 5.0)
            # Ensure current is in range
            if old_val < lo or old_val > hi:
                lo = max(0.0, old_val * 0.5)
                hi = min(1.0, old_val * 2.0)
            # Golden section
            c = hi - gr * (hi - lo)
            d = lo + gr * (hi - lo)
            fc = coord_obj(a, j, c)
            fd = coord_obj(a, j, d)
            for _ in range(35):
                if fc < fd:
                    hi = d
                    d = c
                    fd = fc
                    c = hi - gr * (hi - lo)
                    fc = coord_obj(a, j, c)
                else:
                    lo = c
                    c = d
                    fc = fd
                    d = lo + gr * (hi - lo)
                    fd = coord_obj(a, j, d)
            vj_best = (lo + hi) / 2.0
            obj_best = coord_obj(a, j, vj_best)
            if obj_best < best_obj - 1e-13:
                s_other = 1.0 - old_val
                scale = (1.0 - vj_best) / s_other
                a[j] = vj_best
                mask = np.ones(n, dtype=bool)
                mask[j] = False
                a[mask] *= scale
                a = np.maximum(a, 0)
                a /= a.sum()
                best_obj = obj_best
                best_a = a.copy()
                improved = True
        if verbose and pass_count % 3 == 0:
            elapsed = time.monotonic() - t0
            print(f"    GS-CD pass {pass_count}: obj={best_obj:.10f} ({elapsed:.0f}s)")
        if not improved and pass_count > 2:
            break

def pair_search(a0, time_limit, seed=42, trials_per_round=300):
    """Intensive randomized pair-swap local search."""
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()

    support = np.where(a > 1e-7)[0]
    if len(support) == 0:
        support = np.arange(n)
    round_count = 0
    while time.monotonic() - t0 < time_limit:
        round_count += 1
        round_best = best_obj
        for _ in range(trials_per_round):
            if time.monotonic() - t0 > time_limit:
                break
            idx = rng.integers(0, len(support), size=2)
            i, j = int(support[idx[0]]), int(support[idx[1]])
            if i == j:
                continue
            val_i, val_j = a[i], a[j]
            if val_i < 1e-8 or val_j < 1e-8:
                continue
            max_t = 0.5 * min(val_i, val_j)
            num_trials = 10
            fracs = rng.uniform(0.02, 1.0, num_trials)

                transfer = direction * frac * max_t
                new_i = val_i + transfer
                new_j = val_j - transfer
                if new_i < -1e-14 or new_j < -1e-14:

                if ss < 1e-14:

                a_trial /= ss

def interpolate_sequence(f, new_n):
    """Interpolate a normalized sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp /= ss
    return f_interp


def flat_spectrum_init(n, rng):
    """Generate non-negative sequence with flat cyclic spectrum."""
    phases = rng.uniform(0, 2 * np.pi, n)
    A = np.zeros(n, dtype=complex)
    A[0] = np.sqrt(n)
    half = n // 2
    for k in range(1, half + 1):
        A[k] = np.exp(1j * phases[k])
        if k < n - k:
            A[n - k] = np.conj(A[k])
    if n % 2 == 0:
        A[n // 2] = 1.0
    a = np.fft.ifft(A).real
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-10:
        return np.ones(n) / n
    return a / s

        for r in range(3):
            rem = deadline - time.monotonic() - 60
            if rem < 15:
                break
            t_alloc = min(t_per, rem)
            if r == 0:
                f_init = best_state['seq'].copy()
            elif r == 1:
                noise = rng.standard_normal(n_best) * 0.004
                f_init = project_simplex(best_state['seq'] + noise, 1.0)
            else:
                f_init = 0.6 * best_state['seq'] + 0.4 * best_state['seq'][::-1]
                f_init = project_simplex(f_init, 1.0)
            a_opt, obj = optimize_adam(f_init, time_limit=t_alloc * 0.5, tau_init=100, tau_max=500, top_k=150)
            try_evaluate(a_opt, best_state)
            rem = deadline - time.monotonic() - 40
            if rem > 10:
                a_opt, obj = golden_section_cd(best_state['seq'], time_limit=min(rem, 25))
                try_evaluate(a_opt, best_state)

    # === Phase 6: Multi-length exploration ===
    print(f"\n=== Phase 6: Multi-Length (best={best_state['score']:.6f}) ===")
    if best_state['seq'] is not None:
        n_best = len(best_state['seq'])
        candidates = [int(n_best * 0.8), int(n_best * 1.2), int(n_best * 1.5)]
        candidates = [cn for cn in candidates if cn != n_best and 256 <= cn <= 2500]
        for target_n in candidates[:2]:
            rem = deadline - time.monotonic() - 60
            if rem < 30:
                continue
            f_interp = interpolate_sequence(best_state['seq'], target_n)
            t_alloc = min(rem * 0.4, 70)
            print(f"  n={target_n}, t={t_alloc:.0f}s")
            a_opt, obj = optimize_adam(f_interp, time_limit=t_alloc, tau_init=80, tau_max=400, top_k=150)
            try_evaluate(a_opt, best_state)
            rem = deadline - time.monotonic() - 30
            if rem > 15:
                a_opt, obj = golden_section_cd(a_opt, time_limit=min(rem, 35))
                try_evaluate(a_opt, best_state)

    # === Phase 7: Final intensive polish ===
    print(f"\n=== Phase 7: Final Polish (best={best_state['score']:.6f}) ===")
    if best_state['seq'] is not None:
        rem = deadline - time.monotonic() - 20
        if rem > 15:
            t_final = min(rem * 0.6, 60)
            print(f"  Final CD t={t_final:.0f}s")
            a_opt, obj = golden_section_cd(best_state['seq'], time_limit=t_final)
            try_evaluate(a_opt, best_state)
        rem = deadline - time.monotonic() - 15
        if rem > 10:
            a_opt, obj = pair_search(best_state['seq'], time_limit=min(rem, 30), seed=seed + 100, trials_per_round=200)
            try_evaluate(a_opt, best_state)
        # One more short Adam pass
        rem = deadline - time.monotonic() - 10
        if rem > 10:
            a_opt, obj = optimize_adam(best_state['seq'], time_limit=min(rem, 20), tau_init=200, tau_max=600, top_k=100)
            try_evaluate(a_opt, best_state)

    # Fallback
    if best_state['seq'] is None:
        best_state['seq'] = np.ones(384) / 384
        best_state['score'] = float(evaluate_sequence(best_state['seq'].tolist()))

    # Final verification
    fs = float(evaluate_sequence(best_state['seq'].tolist()))
    if np.isfinite(fs):
        best_state['score'] = fs
    else:
        best_state['seq'] = np.ones(384) / 384
        best_state['score'] = float(evaluate_sequence(best_state['seq'].tolist()))

    print(f"\nFINAL SCORE: {best_state['score']:.6f} (n={len(best_state['seq'])})")
    return [float(x) for x in best_state['seq']]
