- Small delta: only the exact maximum k's, sharper but noisier

            g[j_range] += 2.0 * a[k - j_range]
        
        g /= active_mask.sum()  # average over active set
        
        # Line search
        best_eta = eta
        best_val = R_max
        for factor in [0.25, 0.5, 1.0, 2.0, 4.0]:
            eta_try = eta * factor
            a_try = a - eta_try * g
            # Project
            a_try = water_fill(a_try, S)
            if a_try is None:
                continue
            R_try = fast_autocorr(a_try)
            if R_try.max() < best_val:
                best_val = R_try.max()
                best_eta = eta_try
        
        a = a - best_eta * g
        a = water_fill(a, S)
        
        if a is None:
            break
        
        R = fast_autocorr(a)
        if R.max() < best_score:
            best_score = R.max()
            best_a = a.copy()
            patience = 0
        else:
            patience += 1
        
        if patience % 50 == 0:
            eta *= 0.9
    
    return best_a, best_score

Wait, the line search is O(5 * O(n log n)) per iteration due to the FFT. That's manageable.

But I realize there might be an issue: the subgradient of max of non-convex functions is not well-defined in the standard sense. The "subgradient" I'm computing is the average of the gradients of the active functions, which is a valid subgradient of the pointwise maximum (even for non-convex functions, the " Clarke subdifferential" or "generalized gradient" can be defined). Moving in the negative of this gradient should decrease the maximum (at least to first order).

Actually, for f(x) = max_i f_i(x), a subgradient at x (where the active set is I = {i: f_i(x) = f(x)}) is any convex combination of {∇f_i : i in I}. Moving in the negative subgradient direction decreases all active f_i's to first order (if the subgradient is chosen appropriately). Specifically, if we use the equal-weight average, then for each active i:
`f_i(x - eta * g) ≈ f_i(x) - eta * ∇f_i · g = f_i(x) - eta * (1/|I|) * sum_{j in I} ∇f_i · ∇f_j`

This is negative if the gradients of the active functions are not all orthogonal (which they generally aren't). So the step should decrease the max to first order.

OK, I think this approach is sound. Let me now think about how to combine it with the LP approach.

**Combined Algorithm:**

1. **LP Best Response** (main workhorse): Find the best non-negative b within the current M-ball. Move toward it with Nesterov acceleration.

2. **Subgradient Step** (periodic injection): Every K iterations, instead of an LP step, take a subgradient step. This provides a different direction that can help escape local minima.

3. **Perturbation + Re-optimize** (escape mechanism): When stuck (no improvement for P iterations), add noise and restart the optimization.

4. **Frequency Domain Post-processing**: After finding a good solution, try frequency-domain adjustments to further flatten the autocorrelation.

Let me also think about the frequency domain approach more carefully.

In the frequency domain, the autocorrelation peak is related to the spectral envelope. Specifically, the peak at lag 0 of the autocorrelation (which for our linear convolution is at the center, lag n-1) is related to the "energy" of the signal.

Actually, for our problem, the key quantity is `max_k conv(a,a)_k`. In the circular convolution case, this would be related to the peak of `|FFT(a)|^2`. For linear convolution, it's more complex, but for long sequences (n >> 1), the linear and circular autocorrelations are similar in the middle.

A frequency-domain approach would be:
1. Compute A = FFT(a, 2n-1) (zero-padded for linear convolution)
2. The autocorrelation is IFFT(|A|^2)
3. To reduce the peak of the autocorrelation, we want to flatten |A|^2
4. This is the "flat top" or "flat response" problem

The standard approach in radar/communications is:
- Iteratively adjust the phase of A to flatten |A|^2
- But we have a non-negativity constraint on a, which complicates things

For our problem, since a >= 0, the phase of A is constrained. We can't freely adjust the phase.

An alternative frequency-domain approach:
1. Compute the current autocorrelation R
2. Identify the peak lags
3. In the frequency domain, the autocorrelation peak at lag k is related to the DFT of |A|^2 at frequency k/(2n-1)
4. To reduce the peak at specific lags, we can modify |A|^2 to be more flat

"""

def fast_autocorr(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]

def water_fill(x, S):
    """Project x onto {y >= 0 : sum(y) = S}."""
    # Find lambda such that sum(max(0, x - lambda)) = S
    # Use bisection
    x_sorted = np.sort(x)[::-1]
    cumsum = np.cumsum(x_sorted)
    # lambda is in [min(x), max(x)]
    lo = np.min(x)
    hi = np.max(x)
    for _ in range(100):
        mid = (lo + hi) / 2
        s = np.sum(np.maximum(x - mid, 0))
        if s > S:
            lo = mid
        else:
            hi = mid
    lambda_val = (lo + hi) / 2
    result = np.maximum(x - lambda_val, 0)
    # Exact correction
    s = result.sum()
    if s > S and s > 0:
        result = result * S / s  # This isn't quite right for the water-filling
    # Actually, let's do it properly with the sorted approach
    n = len(x)
    for k in range(n, 0, -1):
        if k == 0:
            break
        lambda_candidate = (np.sum(x_sorted[:k]) - S) / k
        if lambda_candidate < x_sorted[k-1]:  # x_sorted[k-1] is the k-th largest
            break
    else:
        k = n
        lambda_candidate = 0
    # Hmm, this is getting complicated. Let me use a simpler approach.
    
    # Proper water-filling:
    # We want max(0, x - lambda) to sum to S.
    # Sort x in decreasing order: x[0] >= x[1] >= ... >= x[n-1]
    # The optimal lambda satisfies: for some k, x[0]-lambda + ... + x[k-1]-lambda = S
    # i.e., lambda = (sum(x[0:k]) - S) / k
    # and we need x[k-1] > lambda >= x[k] (or k = n)
    
    x_s = np.sort(x)[::-1]
    cumsum = np.concatenate([[0], np.cumsum(x_s)])
    # For each k, lambda_k = (cumsum[k] - S) / k
    lambdas = (cumsum[1:n+1] - S) / np.arange(1, n+1)
    # We need: x_s[k-1] > lambda_k >= x_s[k] (for k < n)
    # Or for k = n: lambda_n <= x_s[n-1]
    
    valid = np.zeros(n+1, dtype=bool)
    for k in range(1, n+1):
        lam = lambdas[k-1]
        if k < n:
            valid[k] = (x_s[k-1] > lam) and (lam >= x_s[k])
        else:
            valid[k] = (lam <= x_s[k-1])
    
    # Find the valid k
    valid_indices = np.where(valid)[0]
    if len(valid_indices) == 0:
        # Fallback: use bisection
        lo = np.min(x)
        hi = np.max(x)
        for _ in range(200):
            mid = (lo + hi) / 2
            s = np.sum(np.maximum(x - mid, 0))
            if s > S:
                lo = mid
            else:
                hi = mid
        lambda_val = (lo + hi) / 2
    else:
        k_valid = valid_indices[-1]  # largest valid k
        lambda_val = lambdas[k_valid - 1]
    
    result = np.maximum(x - lambda_val, 0)
    # Exact normalization (should be very close)
    s = result.sum()
    if s > 1e-15:
        result = result * S / s
    return result

def build_conv_matrix(a):
    n = len(a)
    size = 2 * n - 1
    T = np.zeros((size, n))
    for j in range(n):
        T[j:j+n, j] = a
    return T

def lp_best_response(a, M, solver):
    n = len(a)
    size = 2 * n - 1
    T = build_conv_matrix(a)
    b_var = cp.Variable(n, nonneg=True)
    constraints = [T @ b_var <= M]
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        return None
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None
    b_val = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
    s = b_val.sum()
    if s < 1e-15:
        return None
    return b_val

def compute_subgradient(a, R, top_frac=0.05):
    """Compute the average gradient of the top active lags."""
    n = len(a)
    size = len(R)
    n_active = max(1, int(size * top_frac))
    threshold = np.sort(R)[-n_active]
    active_k = np.where(R >= threshold)[0]
    
    g = np.zeros(n)
    for k in active_k:
        L = max(0, int(k) - n + 1)
        U = min(int(k), n - 1)
        if U >= L:
            j_range = np.arange(L, U + 1)
            g[j_range] += 2.0 * a[k - j_range]
    
    g /= len(active_k)
    return g

def subgradient_step(a, S, eta=0.01, top_frac=0.05):
    """Take one subgradient step and project."""
    R = fast_autocorr(a)
    g = compute_subgradient(a, R, top_frac)
    g_norm = np.linalg.norm(g)
    if g_norm < 1e-15:
        return a.copy()
    g = g / g_norm  # normalize
    
    a_try = a - eta * g
    a_try = water_fill(a_try, S)
    if a_try is None:
        return a.copy()
    return a_try

            R_sg = fast_autocorr(y_sg)

                    best_a = y.copy()
