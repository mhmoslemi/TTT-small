Actually, I realize I should also think about what makes this problem hard and what the optimal solution looks like.

The objective is 2n * max(c) / S^2 where c = conv(a,a).

For the optimal solution, we expect:
1. The convolution c should be as "flat" as possible (all c_k close to each other).
2. The sequence a should be "spread out" to avoid concentration.

The lower bound is 2n/(2n-1) ≈ 1, achieved when all c_k are equal to S^2/(2n-1).

For non-negative a, we can't achieve this exactly, but we can get close.

The previous result of 1.504 means max(c) = 1.504 * S^2 / (2n) ≈ 0.752 * S^2/n.
The ideal would be S^2/(2n-1) ≈ S^2/(2n), so we're at about 75% of the ideal.

To improve, we need to get closer to the ideal. This means making the convolution flatter.

One key insight: the "ends" of the convolution (c[0] = a[0]^2 and c[2n-2] = a[n-1]^2) are always small if the sequence spreads its mass. The "middle" of the convolution tends to have larger values. So the max is typically in the middle.

For the middle values, c[n-1] = sum_j a[j]*a[n-1-j]. If a is symmetric, this is sum_j a[j]^2, which is >= S^2/n by Cauchy-Schwarz. So for symmetric sequences, the objective is >= 2.

To get below 2, the sequence must be **asymmetric**! This is a key insight.

The optimal sequence should have its mass shifted to one side, so that the "anti-diagonal" products a[j]*a[n-1-j] are small.

But then the "diagonal" products (near the center of the convolution) will be large...

Actually wait, I need to reconsider. The center of the convolution is c[n-1] = sum_j a[j]*a[n-1-j]. If the sequence is concentrated near the left (small indices), then for most j, a[j] and a[n-1-j] are both small (since n-1-j is near the right where there's no mass). So c[n-1] would be small.

But then c[0] = a[0]^2 would be large (if a[0] is large), and c[k] for small k would be the autocorrelation of the concentrated part, which could be large.

So there's a trade-off: spread the mass to reduce the peaks anywhere in the convolution.

This is essentially the problem of designing a sequence with minimum peak-to-average ratio in its autocorrelation (for the linear autocorrelation).

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. L-BFGS with adaptive log-sum-exp smoothing (primary)
2. Nesterov mirror descent with softmax gradient (polishing)
3. Pair-exchange coordinate descent (final polish)
4. Multi-length exploration

import numpy as np
import time
from scipy.optimize import minimize

def fast_conv(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(np.asarray(a, dtype=np.float64), fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def evaluate_safe(a):
    try:
        a_list = [float(x) for x in a]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')

def norm_sum1(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s

def softmax(c, tau):
    c_shift = c - c.max()
    p = np.exp(c_shift / tau)
    s = p.sum()
    if s < 1e-300:
        return np.ones_like(c) / len(c)
    return p / s

def lse_value_and_grad(a, tau):
    """Compute log-sum-exp of conv(a,a) and gradient w.r.t. a."""
    n = len(a)
    c = fast_conv(a)
    c_max = c.max()
    exp_c = np.exp((c - c_max) / tau)
    p = exp_c / exp_c.sum()
    value = tau * (c_max / tau + np.log(exp_c.sum()))
    
    # Gradient: grad[i] = 2 * sum_{m=0}^{n-1} p[i+m] * a[m]
    # Using FFT: r[i] = convolve(p, a[::-1])[n-1+i]
    a_rev = a[::-1]
    fft_size = 1 << ((2*n-1 + n - 1) - 1).bit_length()
    P = np.fft.rfft(p, fft_size)
    AR = np.fft.rfft(a_rev, fft_size)
    r_full = np.fft.irfft(P * AR, fft_size)
    r = r_full[n-1 : n-1+n]
    grad = 2.0 * r
    return value, grad

def lse_obj_and_grad_x(x, tau):
    """Objective and gradient in log-space parameterization.
    a_i = exp(x_i) / sum(exp(x_j))
    """
    x_shift = x - x.max()
    a = np.exp(x_shift)
    a /= a.sum()
    value, grad_a = lse_value_and_grad(a, tau)
    # Gradient w.r.t. x: grad_x_j = a_j * (grad_a_j - sum_i grad_a_i * a_i)
    mean_g = np.dot(grad_a, a)
    grad_x = a * (grad_a - mean_g)
    return value, grad_x

def lbfgs_optimize(a0, time_limit, tau_init=None, verbose=True):
    """Optimize using L-BFGS with annealing log-sum-exp."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_score = evaluate_safe(a)
    t0 = time.monotonic()
    
    # Initial tau
    c0 = fast_conv(a)
    M0 = c0.max()
    if tau_init is None:
        tau_init = M0 / 3.0
    
    # Annealing schedule
    n_stages = 5
    taus = [tau_init * (0.5 ** i) for i in range(n_stages)]
    
    # Convert to log-space
    x = np.log(np.maximum(a, 1e-30))
    
    for stage, tau in enumerate(taus):
        if time.monotonic() - t0 > time_limit:
            break
        
        # L-BFGS in log-space
        result = minimize(
            lse_obj_and_grad_x, x, args=(tau,),
            method='L-BFGS-B',
            jac=True,
            options={'maxiter': 200, 'ftol': 1e-12, 'gtol': 1e-8}
        )
        
        x_new = result.x
        a_new = np.exp(x_new - x_new.max())
        a_new = a_new / a_new.sum()
        a_new = np.maximum(a_new, 0.0)
        a_new = a_new / a_new.sum()
        
        sc = evaluate_safe(a_new)
        if np.isfinite(sc) and sc < best_score:
            best_score = sc
            best_a = a_new.copy()
            x = x_new
            a = a_new
            if verbose:
                print(f"    LSE stage {stage} (tau={tau:.6f}): {sc:.6f}")
        else:
            if verbose:
                print(f"    LSE stage {stage} (tau={tau:.6f}): no improvement ({sc:.6f})")
    
    return best_a, best_score

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss

Looking at this problem, I need to minimize `2*n*max(conv(a,a))/(sum(a))^2` for non-negative sequences. The key insight is that the convolution center `c[n-1] = sum_j a[j]*a[n-1-j]` is NOT the same as the energy `sum a_j^2` unless the sequence is symmetric. This means asymmetric sequences can potentially achieve lower peaks.

My approach differs from the previous program by using:

2. **Mirror descent with true softmax gradient** (log-sum-exp based, not power-based)

1. L-BFGS with adaptive log-sum-exp smoothing and annealing (primary)
2. Mirror descent (multiplicative weights) with softmax gradient (polishing)
3. Vectorized pair-exchange with linearization (final polish)
4. Multi-length and multi-initialization exploration

import numpy as np

from scipy.optimize import minimize


def fast_conv(a):
    """Compute linear convolution using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(np.asarray(a, dtype=np.float64), fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def evaluate_safe(a):
    """Safely evaluate a sequence."""
    try:
        a_list = [float(x) for x in a]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')


def norm_sum1(a):
    """Normalize to non-negative, sum=1."""
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s


def softmax_weights(c, tau):
    """Compute softmax weights for convolution values."""
    c_shift = c - c.max()
    p = np.exp(c_shift / tau)
    s = p.sum()
    if s < 1e-300:
        return np.ones_like(c) / len(c)
    return p / s


def compute_gradient(a, p):
    """Compute gradient: grad[i] = 2 * sum_m p[i+m] * a[m].
    Uses FFT for efficiency.
    """
    n = len(a)
    a_rev = a[::-1]
    total_len = (2 * n - 1) + n - 1
    fft_size = 1 << (total_len - 1).bit_length()
    P = np.fft.rfft(p, fft_size)
    AR = np.fft.rfft(a_rev, fft_size)
    r_full = np.fft.irfft(P * AR, fft_size)
    r = r_full[n - 1: n - 1 + n]
    return 2.0 * r


def lse_value_and_grad_a(a, tau):
    """Compute log-sum-exp of conv(a,a) and gradient w.r.t. a."""
    n = len(a)
    c = fast_conv(a)
    c_max = c.max()
    exp_c = np.exp((c - c_max) / tau)
    p = exp_c / exp_c.sum()
    value = tau * (c_max / tau + np.log(exp_c.sum()))
    grad = compute_gradient(a, p)
    return value, grad


def lse_obj_and_grad_x(x, tau):
    """Objective and gradient in log-space parameterization for L-BFGS.
    a_i = exp(x_i) / sum(exp(x_j))
    """
    x_shift = x - x.max()
    a = np.exp(x_shift)
    a_sum = a.sum()
    if a_sum < 1e-300:
        return 1e10, np.zeros_like(x)
    a = a / a_sum
    value, grad_a = lse_value_and_grad_a(a, tau)
    mean_g = np.dot(grad_a, a)
    grad_x = a * (grad_a - mean_g)
    return value, grad_x


def lbfgs_optimize(a0, time_limit, tau_init=None, verbose=True):
    """Optimize using L-BFGS with annealing log-sum-exp."""
    n = len(a0)
    a = norm_sum1(a0)
    best_a = a.copy()
    best_score = evaluate_safe(a)
    t0 = time.monotonic()

    c0 = fast_conv(a)
    M0 = max(c0.max(), 1e-10)
    if tau_init is None:
        tau_init = M0 / 3.0

    # Annealing: decreasing temperature
    n_stages = 6
    taus = [tau_init * (0.55 ** i) for i in range(n_stages)]

    x = np.log(np.maximum(a, 1e-30))

    for stage, tau in enumerate(taus):
        if time.monotonic() - t0 > time_limit:
            break

        result = minimize(
            lse_obj_and_grad_x, x, args=(tau,),
            method='L-BFGS-B',
            jac=True,
            options={'maxiter': 300, 'ftol': 1e-14, 'gtol': 1e-10,
                     'maxfun': 500}
        )

        x_new = result.x
        a_new = np.exp(x_new - x_new.max())
        a_new = a_new / a_new.sum()
        a_new = np.maximum(a_new, 0.0)
        s = a_new.sum()
        if s > 1e-15:
            a_new = a_new / s

        sc = evaluate_safe(a_new)
        if np.isfinite(sc) and sc < best_score:

            x = x_new
            if verbose:
