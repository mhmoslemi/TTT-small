J(n, a) = 2n ∥a⊗a∥∞ / (Σaᵢ)²

Variables:
t: Hyperparameter controlling crossover probability
σ²: Entropy regularization parameter (0.2 ≤ σ² ≤ 0.5)
β: Float controlling exponent decay/sine scale (tested in [1.0, 2.5, 4.0])

Constraints:
All aᵢ ≥ 0 after clipping
Σaᵢ ≥ 0.01 after normalization

      M_val = max(conv)

      # Project onto constrained direction space
      proj_dir = project_constraints(deriv, M_val)
      # Perform Nesterov-style projected gradient descent
      for _ in range(max_iters):
          move = compute_move(seq, proj_dir)
          new_seq = seq + move
          # Ensure non-negativity and normalization
          new_seq = np.maximum(new_seq, 0)
          new_seq = new_seq / sum(new_seq) if sum(new_seq)>1e-10 else np.ones_like(new_seq) * 0.01
          new_conv = np.convolve(new_seq, new_seq, mode='full')
          new_M = max(new_conv)
          # Update if improvement is detected
          if new_M < M_val * 0.997:
              seq = new_seq
              conv = new_conv
              M_val = new_M
