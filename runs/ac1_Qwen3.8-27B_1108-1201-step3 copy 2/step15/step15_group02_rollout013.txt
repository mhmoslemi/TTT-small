But wait, what about non-power-law shapes? What about a shape that's specifically designed to equalize the convolution?

The ideal would be a sequence where conv(a,a)[k] is constant for all k. This is analogous to a "perfect" autocorrelation. For non-negative sequences, this is impossible (the edges have fewer terms), but we can try to make it as flat as possible.

If conv[k] = C for all k = 0, ..., 2n-2, then (2n-1)*C = 1, so C = 1/(2n-1).
But conv[0] = a[0]^2 = C, so a[0] = 1/sqrt(2n-1).
And conv[2n-2] = a[n-1]^2 = C, so a[n-1] = 1/sqrt(2n-1).
And conv[1] = 2*a[0]*a[1] = C, so a[1] = C/(2*a[0]) = 1/(2*sqrt(2n-1)).

This quickly leads to a contradiction (a[1] < a[0] but we need a to be non-negative and the pattern doesn't work). So a perfectly flat convolution is impossible for non-negative sequences.

However, we can try to make the convolution "as flat as possible" in the middle while keeping the edges small. This is essentially what the linear ramp does - it makes the middle values roughly flat (O(1/n)) while the edges are small (O(1/n^2)).
