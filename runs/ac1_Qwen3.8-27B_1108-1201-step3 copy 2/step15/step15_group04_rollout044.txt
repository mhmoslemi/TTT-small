a_new_i ∝ a_i * exp(-eta * (a_i - b*_i))

Or more simply, we can use the geometric mean:
a_new_i = a_i^(1-eta) * b*_i^eta

Which is equivalent to:
a_new_i ∝ a_i * (b*_i / a_i)^eta = a_i^(1-eta) * b*_i^eta

This is the "multiplicative" or "exponential" update.

With Nesterov acceleration:
y = (1-alpha) * y + alpha * g (in the mirror geometry: y_new = y^(1-alpha) * g^alpha)
x_new = (1-alpha) * x + alpha * y (in mirror: x_new = x^(1-alpha) * y^alpha)

Wait, Nesterov in mirror geometry is more complex. Let me just use the simple multiplicative update:

a_new = a * (b/a)^eta = a^(1-eta) * b^eta

This is the multiplicative weight update. It should work well for non-negative variables.

Let me also think about a key insight: **The optimal sequence should have a specific structure.**

For a sequence a with sum S, the average autocorrelation is S^2/(2n-1). The minimum possible max autocorrelation is at least the average. But we can do better than the average by making the autocorrelation more uniform.

The best sequences would have autocorrelation values that are as close to each other as possible (ideally all equal to S^2/(2n-1)). This is related to "perfect sequences" or "Golomb rulers" in signal processing.

For non-negative sequences, we can't achieve perfect equi-correlation (since the peak at lag 0 is always S... wait, no. (a*a)[0] = sum a_i^2, which by Cauchy-Schwarz is at least S^2/n. And the average is S^2/(2n-1). So the peak is at least (2n-1)/n * average ≈ 2 * average for large n.

So the best we can do is to make all non-peak autocorrelation values as close to each other as possible, and the peak at lag 0 will be at least (2n-1)/n times the average.

This suggests that the optimal sequence should have:
- (a*a)[0] ≈ S^2/n (achieved when all a_i are equal, i.e., a_i = S/n)
- (a*a)[k] ≈ S^2/(2n-1) for k ≠ 0

But wait, if all a_i are equal (= S/n), then (a*a)[k] = (n-|k|) * (S/n)^2 for |k| < n, which is a triangular shape, not flat. The max is at lag 0: n * (S/n)^2 = S^2/n.

So for the uniform sequence, the objective is 2n * S^2/n / S^2 = 2. That's worse than 1.5.

The optimal sequence should have a more complex structure that makes the autocorrelation flatter.
