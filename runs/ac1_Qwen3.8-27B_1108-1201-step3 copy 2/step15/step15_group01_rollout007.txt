    if n == 0:
        return v

Let me also think about the LP more carefully. The LP is:
max sum(b) s.t. T @ b <= M, b >= 0

where T is the (2n-1) x n convolution matrix. For n=1600, T has about 1600*3200 ≈ 5 million entries (but it's banded, so only about 1600*1600 = 2.56 million non-zeros).

Solving this LP with all constraints might be slow. The constraint generation approach (using only the top constraints) is a good idea for speed. But maybe we can be less aggressive about which constraints to include.

Actually, I realize there might be a better way to think about this. The LP best response is:
max sum(b) s.t. (a*b)_k <= M for all k, b >= 0

The dual of this is:
min M * sum(y_k) s.t. T^T @ y >= 1, y >= 0

where y_k are the dual variables for each constraint. The complementary slackness condition says y_k > 0 only for the active constraints (where (a*b)_k = M).

So the constraint generation approach is actually using the dual variables! The active set in the dual corresponds to the binding constraints in the primal. This is a valid approach.

But the issue is that we're using the active set from the CURRENT iterate (y), not from the optimal b. This is an approximation. A better approach would be to:
1. Solve the LP with a subset of constraints
2. Check if the optimal b violates any of the other constraints
3. If so, add the violated constraints and re-solve
4. Repeat until no violations

This is the "cutting plane" method. Let me implement this.

def project_simplex(v, S):
    n = len(v)
    if n == 0:
        return v.copy()
    v = np.asarray(v, dtype=np.float64)
    v_sorted = np.sort(v)[::-1]
    css = np.cumsum(v_sorted)
    rho = np.where(v_sorted * np.arange(1, n + 1) > (css - S))[0]
    if len(rho) == 0:
        return np.zeros(n)
    rho = rho[-1]
    theta = (css[rho] - S) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

                break
            continue
        
        stuck_count = 0
        b_sum = b.sum()
        if b_sum < 1e-15:
            continue
        g = b * norm / b_sum
        n_iters += 1
        
        # Nesterov update for y
        alpha = 2.0 / (t + 2.0)
        y_new = (1.0 - alpha) * y + alpha * g
        y_new = np.maximum(y_new, 0.0)
        s_y = y_new.sum()
        if s_y < 1e-15:
            y_new = y.copy()
        else:
            y_new = y_new * norm / s_y
        
        # EMA for tracking best
        ema_a = (1 - alpha_ema) * ema_a + alpha_ema * y_new
        s_ema = ema_a.sum()
        if s_ema > 1e-15:
            ema_check = ema_a * norm / s_ema
            score_ema = fast_conv(ema_check).max()
            if score_ema < best_score:
                best_score = score_ema
                best_a = ema_check.copy()
        
        # Also check y_new directly

            a = g.copy()

def smooth_adam(a0, time_limit, verbose=True):

    n = len(a0)

            # Gradient via cross-correlation
            size = 2 * n - 1
            fft_size = 1 << (size - 1).bit_length()
            W = rfft(w, fft_size)
            A = rfft(a, fft_size)
            cross = irfft(W * np.conj(A), fft_size)[:n]

            # ADAM
            t_step += 1

def interpolate_to_length(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) * (np.sqrt(2.0 * new_n) / new_n)
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n, endpoint=False)
    new_x = np.linspace(0.0, 1.0, new_n, endpoint=False)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) * (np.sqrt(2.0 * new_n) / new_n)
    return f_interp * np.sqrt(2.0 * new_n) / ss
