Let me also think about the spectral (Feintuch) method more carefully.

The Feintuch algorithm for low-autocorrelation sequence design:
1. Start with initial sequence a
2. Compute A(f) = FFT(a)
3. Compute the aperiodic autocorrelation: R(k) = IFFT(|A(f)|^2)
4. Identify the peak lag k* = argmax |R(k)|
5. For the peak, compute the "error" signal: e(f) = R(k*) * exp(-i 2π f k*/N) (the complex exponential corresponding to the peak)
6. Modify the spectrum: A_new(f) = A(f) - c * |A(f)|^2 * e(f) / |A(f)|^2 = A(f) - c * e(f)
   (where c is a step size)
   Actually, the standard Feintuch update is:
   A_new(f) = A(f) * (1 - c * e(f) / |A(f)|^2)
   But this can make A complex.
7. a_new = IFFT(A_new)
8. Project to non-negative: a_new = max(a_new, 0)
9. Renormalize
10. Iterate

The key issue is that the Feintuch method doesn't naturally respect the non-negativity constraint. The projection onto non-negativity can hurt performance.

A better approach might be to use the Feintuch method as a "suggestion" for the direction of improvement, and then use the LP to refine.

**Spectral shaping with non-negativity constraint:**

The autocorrelation R(k) = IFFT(|A(f)|^2). We want to minimize max_k R(k) subject to a >= 0 and sum(a) = S.

In the frequency domain, |A(f)|^2 determines the autocorrelation. If we could make |A(f)|^2 as flat as possible (white spectrum), the autocorrelation would be a delta function (R(0) = sum(a_i^2), R(k) = 0 for k > 0). But we can't make the spectrum perfectly flat while maintaining non-negativity.

A practical approach:
1. Compute A(f) = FFT(a)
2. |A(f)|^2 is the power spectrum
3. The autocorrelation is IFFT(|A(f)|^2)
4. To reduce the peak autocorrelation, we want to reduce the power at frequencies that contribute to the peak

The contribution of frequency f to R(k) is |A(f)|^2 * exp(i 2π f k / N). So to reduce R(k*), we want to reduce |A(f)|^2 at frequencies where exp(i 2π f k* / N) has the same phase as R(k*).

def nesterov_lp(a0, time_limit, solver, verbose=True, full_constraints=True, 
                 use_screening=False, screen_threshold=0.6, restart_interval=200):

    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    a = a * norm / s
    
    best_a = a.copy()
    best_score = fast_conv_self(a).max()
    t0 = time.monotonic()
    size = 2 * n - 1
    
    y = a.copy()  # Nesterov lookahead
    warm_b = a.copy()  # Warm start for LP
    no_improve = 0
    
    for t in range(1, 500000):
        if time.monotonic() - t0 > time_limit:
            break
        
        conv_y = fast_conv_self(y)
        M = conv_y.max()
        if M < 1e-12:
            break
        
        # Choose constraints
        if full_constraints and not use_screening:
            T = build_T(y)
            b = lp_best_response(y, M, solver, T, warm_b)
        else:
            active = np.where(conv_y > screen_threshold * M)[0]
            if len(active) < 30:
                active = np.arange(size)
            T_act = build_T(y)[active, :]
            b_var = cp.Variable(n, nonneg=True)
            b_var.value = warm_b
            prob = cp.Problem(cp.Maximize(cp.sum(b_var)), [T_act @ b_var <= M])
            try:
                prob.solve(solver=solver, verbose=False)
            except Exception:
                b = None
            if prob.status in ('optimal', 'optimal_inaccurate'):
                b = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
                # Verify
                if fast_conv_cross(y, b).max() > M * (1 + 1e-3):
                    T_full = build_T(y)
                    b = lp_best_response(y, M, solver, T_full, b)
            else:
                b = None
        
        if b is None:
            b = a.copy()  # Fallback: stay put
        
        b_sum = b.sum()
        if b_sum < 1e-15:
            b = a.copy()
            b_sum = a.sum()
        g = b * norm / b_sum
        warm_b = b.copy()
        
        # Nesterov update
        alpha = 2.0 / (t + 2.0)
        y_new = (1.0 - alpha) * y + alpha * g
        y_new = np.maximum(y_new, 0.0)
        s_y = y_new.sum()
        if s_y < 1e-15:
            y_new = y.copy()
        else:
            y_new = y_new * norm / s_y
        
        # Momentum step
        momentum = min(1.0, (t - 1.0) / (t + 2.0))
        a_new = y_new + momentum * (y_new - y)
        a_new = np.maximum(a_new, 0.0)
        s_a = a_new.sum()
        if s_a < 1e-15:
            a_new = y_new.copy()
        else:
            a_new = a_new * norm / s_a
        
        y = y_new
        a = a_new
        
        # Track best
        sc_y = fast_conv_self(y).max()
        if sc_y < best_score - 1e-10:
            best_score = sc_y
            best_a = y.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        sc_a = fast_conv_self(a).max()
        if sc_a < best_score - 1e-10:
            best_score = sc_a
            best_a = a.copy()
            no_improve = 0
        
        # Periodic perturbation to escape local optima
        if no_improve == restart_interval:

            n_perturb = max(10, n // 20)
            idx = rng_perturb.choice(n, size=n_perturb, replace=False)
            y[idx] *= (1.0 + 0.3 * rng_perturb.standard_normal(n_perturb))

            s_y = y.sum()

                a[idx_p] *= (1.0 + 0.2 * rng.standard_normal(n_perturb))

                s_new = a.sum()
                if s_new > 1e-15:
                    a = a * norm / s_new
        else:
            no_improve = 0
    
    return best_a, best_score
