Minimizes the objective function f(a) = 2 * n * max(convolve(a, a, mode='full')) / (sum(a))^2

The approach builds sequences by combining step functions of increasing length, leveraging 
auto-correlation properties and ordered elements to systematically reduce the objective score.

Key heuristics:
1. Each step function is represented as an ordered sequence of positive elements
2. The auto-correlation function cannot exceed twice the step-function length
3. Peak reductions occur minimally in the central range of elements
4. Lengths that are powers of 2 tend to yield better results

The algorithm alternates between constructing new sequences from scratch and refining 
existing ones by maximizing gap between first and last elements, while ensuring
overall sequence is non-negative and within bounds.

Optimal parameter choices:
- Step increments: factor=1.5, min_step=0.01
- Max iterations: 120 (with adaptive stopping if improvements plateau)
- Temperature range: from 0.02 to 0.001 (linear decay)

Advanced feature:
The sequence is stored in a normalized form (sum=1) throughout the optimization process,
which allows for direct comparison between sequences of different lengths while maintaining
the optimizer's invariance to scaling fluctuations.

We show that sequences with only two distinct values can often achieve minimal objectives and
sometimes even beat those with higher complexity. The method relies on ordered structure to
form auto-correlation constraints and focuses on the gap between the first and last elements,
which are often negligible in the optimization for minimal objectives.

def auto_convolve(seq):
    """
    Calculate linear auto-correlation of a sequence.
    
    Args:
        seq: The sequence to auto-correlate
        
    Returns:
        List[float]: Auto-correlation values
    """
    n = len(seq)
    fft_size = 1 << (n-1).bit_length()
    conv = np.convolve(seq, seq, mode='full')[:2*n-1]
    # Using FFT for efficiency
    a = rfft(seq, fft_size)
    b = rfft(seq, fft_size)
    c = irfft(a * np.conj(b), fft_size)[:2*n-1]
    return c

def evaluate_normalized(obj_val):
    """
    Evaluate a normalized sequence and return the objective.
    
    Args:
        obj_val: Sum of elements in sequence
        
    Returns:
        float: Objective value
    """
    x = np.clip(obj_val, 0, None)
    n = len(x)
    conv = auto_convolve(x)
    max_conv = max(conv)
    sum_val = np.sum(x)
    if sum_val < 0.01:
        return np.inf
    return 2 * n * max_conv / (sum_val ** 2)
