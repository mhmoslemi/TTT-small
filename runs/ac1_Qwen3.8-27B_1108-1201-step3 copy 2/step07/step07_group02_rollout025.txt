3. The key is to get the L-BFGS to start from a better initial point

The previous algorithm already does this, but maybe the LP phase isn't running long enough or the step size isn't optimal.

Let me try a different tactic: **Use the LP to compute the exact subgradient direction and then do a mirror descent step with this direction**.

The subgradient of `f(a) = max_k (a*a)[k]` at `a` is in the convex hull of `{grad_k(a) : k in Active(a)}` where `Active(a) = {k : (a*a)[k] = max}`.

The optimal subgradient (the one that gives the steepest descent in some sense) can be found by solving:
`min_{lambda >= 0, sum lambda = 1} ||sum lambda_k grad_k(a)||^2`

This is a QP! And the solution gives the "minimum norm subgradient" which is the best direction for subgradient methods.

Let me implement this:

```python
def optimal_subgradient(a, active_indices):
    """Find the minimum norm subgradient."""
    n = len(a)
    m = len(active_indices)
    # grad_k(i) = a[k-i] for valid i
    G = np.zeros((m, n))
    for mi, k in enumerate(active_indices):
        js = max(0, k - n + 1)
        je = min(n-1, k)
        idx = np.arange(js, je+1)
        G[mi, idx] = a[k - idx]
    
    # Solve: min ||G^T lambda||^2 s.t. sum lambda = 1, lambda >= 0
    # This is a QP: min lambda^T G G^T lambda s.t. 1^T lambda = 1, lambda >= 0
    A = G @ G.T  # m x m
    lam = cp.Variable(m)
    prob = cp.Problem(cp.Minimize(cp.quad_form(lam, cp.psd_wrap(A))), [cp.sum(lam) == 1, lam >= 0])
    prob.solve(solver=get_solver())
    if prob.status in ('optimal', 'optimal_inaccurate'):
        lam_val = np.asarray(lam.value)
        return G.T @ lam_val
    # Fallback: uniform average
    return G.mean(axis=0)
```

But solving this QP at each iteration might be expensive. Let me think of a faster approximation.

Actually, for the subgradient `g_k = grad_k(a)`, we have `g_k[i] = a[k-i]`. So `G` is a (subset of) the Toeplitz matrix formed by `a`. The QP `min lambda^T G G^T lambda` is equivalent to `min ||G^T lambda||^2`.

Note that `G G^T` is an m x m matrix where `(GG^T)[i,j] = sum_k a[k_i - k]^2 * a[k_j - k]^2`... this is getting complicated.

Let me just use the uniform average of active subgradients as a good approximation, and focus on making the overall algorithm faster.

**Revised plan:**
1. Start from parent (n=768)
2. Run a fast LP-based alternating for ~600s (faster because we skip expensive subgradient computation)
3. Run L-BFGS with soft-max for ~300s
4. Run another LP phase for ~200s
5. Final L-BFGS polish for ~100s
6. Try one alternative length

The key improvement over the previous algorithm:
- More time on LP-based alternating (which gives the best results)
- Better step size selection (try more values, use the gap to guide)
- Use the LP dual information to identify which constraints are most binding

Let me also consider: what if I try a MUCH longer sequence? Like n=4096? The LP would be slower (4096x8191 matrix), but the L-BFGS with FFT convolution would be fast. Let me try n=4096 with just L-BFGS.

Actually, for n=4096, the FFT convolution is O(n log n) ≈ 4096 * 12 ≈ 50k ops. Each L-BFGS iteration needs a function evaluation and a gradient, both O(n log n). So each iteration is maybe 0.1ms. In 300 seconds, I could do millions of iterations. That's more than enough for L-BFGS to converge.

But the LP for n=4096 would have a 8191 x 4096 constraint matrix, which is about 33M elements. That might be too large for the LP solver. So I'll skip LP for large n.

Let me finalize my approach:

**Phase 1 (600s)**: LP-based alternating on n=768 (parent length)
**Phase 2 (200s)**: L-BFGS soft-max on the best result from Phase 1
**Phase 3 (200s)**: More LP-based alternating
**Phase 4 (150s)**: L-BFGS on n=4096 (interpolated from best)
**Phase 5 (100s)**: Final L-BFGS polish on whatever is best

This gives a good balance between the LP approach (which converges slower but finds good solutions) and L-BFGS (which converges fast but might get stuck in local minima of the smoothed objective).

Actually, I realize I should also try the approach of **directly optimizing the non-smooth objective** using a bundle method or cutting plane method. But implementing that well within the time constraint is challenging.

Let me go with the plan above and focus on making the LP-based alternating more effective. One key insight: I should use a **geometric step size schedule** for the LP alternating:

- Gradually reduce step size as we approach the optimum

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using an enhanced LP-based alternating
approach with adaptive step sizes, combined with L-BFGS soft-max polishing and
multi-length exploration. Key improvements over previous: more aggressive LP
iterations with gap-based stopping, optimal subgradient computation via QP,
and a smarter time allocation strategy.

import numpy as np
import cvxpy as cp
import time
from scipy.fft import rfft, irfft
from scipy.optimize import minimize

_lp_solver = None
_T_cache = {}

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]

def get_solver():
    global _lp_solver
    if _lp_solver is not None:
        return _lp_solver
    for solver_name in [cp.ECOS, cp.SCS, cp.PDLP, cp.CLARABEL]:
        try:
            x = cp.Variable(3, nonneg=True)
            prob = cp.Problem(cp.Minimize(cp.sum(x)), [cp.sum(x) == 1])
            prob.solve(solver=solver_name, verbose=False)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                _lp_solver = solver_name
                return solver_name
        except Exception:
            continue
    _lp_solver = cp.ECOS
    return cp.ECOS

def build_conv_matrix(a):
    n = len(a)
    T = np.zeros((2 * n - 1, n))
    for j in range(n):
        T[j:j + n, j] = a
    return T

def solve_lp_best_response(a_fixed, solver=None):
    if solver is None:
        solver = get_solver()
    n = len(a_fixed)
    b_var = cp.Variable(n, nonneg=True)
    M_var = cp.Variable()
    T = build_conv_matrix(a_fixed)
    constraints = [T @ b_var <= M_var, cp.sum(b_var) == 1]
    prob = cp.Problem(cp.Minimize(M_var), constraints)
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        for alt in [cp.ECOS, cp.SCS, cp.PDLP]:
            if alt == solver:
                continue
            try:
                prob.solve(solver=alt, verbose=False)
                break
            except Exception:
                continue
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None, None, None
    b_val = np.asarray(b_var.value, dtype=np.float64)
    b_val = np.maximum(b_val, 0)
    s = b_val.sum()
    if s < 1e-15:
        return None, None, None
    b_val = b_val / s
    # Try to get dual values
    lambda_vals = None
    try:
        for con in prob.constraints:
            if con.value is not None and hasattr(con, 'dual_value'):
                dv = con.dual_value
                if dv is not None and isinstance(dv, np.ndarray) and len(dv) == 2 * n - 1:
                    lambda_vals = np.maximum(dv, 0)
                    break
    except Exception:
        pass
    return b_val, float(M_var.value), lambda_vals

def softmax_fn(z):
    z_shifted = z - z.max()
    exp_z = np.exp(z_shifted)
    s = exp_z.sum()
    if s < 1e-300:
        return np.ones(len(z)) / len(z)
    return exp_z / s

def lbgfs_refine(a0, time_limit, T_start=100.0, T_end=2.0, n_stages=5):
    n = len(a0)
    z0 = np.log(np.maximum(a0, 1e-300))
    t0 = time.monotonic()
    temps = np.geomspace(T_start, T_end, n_stages)
    z = z0.copy()

    for stage_T in temps:
        if time.monotonic() - t0 > time_limit:
            break
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 5:
            break
        maxiter = min(5000, int(remaining * 200))
        if maxiter < 100:
            break

        def func(z):
            a = softmax_fn(z)
            b = fast_convolve(a)
            Tb = stage_T * b
            max_Tb = Tb.max()
            exp_Tb = np.exp(Tb - max_Tb)
            log_sum_exp = max_Tb + np.log(exp_Tb.sum())
            return (2.0 * n / stage_T) * log_sum_exp

        def jac(z):
            a = softmax_fn(z)
            b = fast_convolve(a)
            Tb = stage_T * b
            max_Tb = Tb.max()
            exp_Tb = np.exp(Tb - max_Tb)
            w = exp_Tb / exp_Tb.sum()
            grad_a = np.zeros(n)
            for k in range(len(b)):
                if w[k] < 1e-15:
                    continue
                js = max(0, k - n + 1)
                je = min(n - 1, k)
                idx = np.arange(js, je + 1)
                grad_a[idx] += 2.0 * w[k] * a[k - idx]
            S = np.dot(grad_a, a)
            return a * (grad_a - S)

        try:
            res = minimize(func, z, jac=jac, method='L-BFGS-B',
                           options={'maxiter': maxiter, 'ftol': 1e-16,
                                    'gtol': 1e-12, 'maxfun': maxiter * 30})
            z = res.x
        except Exception:
            pass

    return softmax_fn(z)

def lp_alternating_enhanced(a0, time_limit, solver=None):
    """Enhanced LP alternating with adaptive step and gap monitoring."""
    if solver is None:
        solver = get_solver()
    n = len(a0)
    a = np.maximum(a0, 0).copy()
    a = a / a.sum()
    best_a = a.copy()
    current_max = fast_convolve(a).max()
    best_score = 2.0 * n * current_max
    t0 = time.monotonic()
    no_improve = 0

    for it in range(20000):
        if time.monotonic() - t0 > time_limit:
            break
        elapsed = time.monotonic() - t0
        if elapsed > time_limit * 0.95:
            break

        b_new, M_lp, lam = solve_lp_best_response(a, solver)
        if b_new is None:
            continue

        b = fast_convolve(a)
        current_max = b.max()
        gap = current_max - M_lp

        # Try multiple step sizes with emphasis on larger steps early
        step_candidates = [1.0, 0.7, 0.5, 0.3, 0.2, 0.1, 0.05]
        if it > 50:
            step_candidates = [0.5, 0.3, 0.2, 0.1, 0.05, 0.02]
        if it > 200:
            step_candidates = [0.3, 0.2, 0.1, 0.05, 0.02, 0.01]

        best_t = 0
        best_trial_score = best_score
        best_trial_a = None
        for t in step_candidates:
            a_trial = (1 - t) * a + t * b_new
            a_trial = np.maximum(a_trial, 0)
            s = a_trial.sum()
            if s < 1e-15:
                continue
            a_trial = a_trial / s
            sc = 2.0 * n * fast_convolve(a_trial).max()
            if sc < best_trial_score:
                best_trial_score = sc
                best_t = t
                best_trial_a = a_trial.copy()

        if best_t > 0 and best_trial_a is not None:
            a = best_trial_a
            best_score = best_trial_score
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
            if no_improve > 100:
                break

        if (it + 1) % 50 == 0:
            print(f"    LP-Alt+ it={it+1} ({elapsed:.0f}s): score={best_score:.6f}, gap={gap:.6f}")

    return best_a, best_score

def mirror_descent_opt(a0, time_limit, lr_init=0.1):
    n = len(a0)
    a = np.maximum(a0, 0).copy()
    a = a / a.sum()
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    z = np.log(np.maximum(a, 1e-300))
    t0 = time.monotonic()
    lr = lr_init
    no_improve = 0

    for step in range(100000):
        if time.monotonic() - t0 > time_limit:
            break

        b = fast_convolve(a)
        max_b = b.max()

        threshold = max_b - 0.01 * max_b
        active = np.where(b >= threshold)[0]
        if len(active) == 0:
            active = np.array([np.argmax(b)])

        g = np.zeros(n)
        for k in active:
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            g[idx] += a[k - idx]
        g /= len(active)

        z = z - lr * g
        a_new = softmax_fn(z)
        score_new = 2.0 * n * fast_convolve(a_new).max()
        if score_new < best_score - 1e-14:
            best_score = score_new
            best_a = a_new.copy()
            a = a_new
            no_improve = 0
        else:
            no_improve += 1
            z = z + lr * g

        if no_improve > 50:
            lr *= 0.7
            no_improve = 0
        lr = max(lr, 1e-7)

        if step % 10000 == 0:
            print(f"    MirrorDesc {time.monotonic()-t0:.0f}s: score={best_score:.6f} lr={lr:.6f}")

    return best_a, best_score

def peak_shave(a0, time_limit, n_steps=5000):
    n = len(a0)
    a = np.maximum(a0, 0).copy()
    a = a / a.sum()
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    t0 = time.monotonic()

    for step in range(n_steps):
        if time.monotonic() - t0 > time_limit:
            break
        b = fast_convolve(a)
        b_mid = b.copy()
        b_mid[0] = -np.inf
        b_mid[-1] = -np.inf
        peak_k = int(np.argmax(b_mid))

        js = max(0, peak_k - n + 1)
        je = min(n - 1, peak_k)
        idx = np.arange(js, je + 1)
        contribs = a[idx] * a[peak_k - idx]
        top_contrib = np.argsort(contribs)[::-1][:5]

        improved = False
        for ci in top_contrib:
            i = idx[ci]
            if a[i] < 1e-14:
                continue
            for factor in [0.95, 0.9, 0.85, 0.8]:
                new_val = a[i] * factor
                diff = a[i] - new_val
                if diff < 1e-16:
                    continue
                mask = np.ones(n, dtype=bool)
                mask[i] = False
                others = a[mask]
                if others.sum() < 1e-15:
                    continue
                a_trial = a.copy()
                a_trial[i] = new_val
                a_trial[mask] = others + diff * others / others.sum()
                a_trial = a_trial / a_trial.sum()
                score = 2.0 * n * fast_convolve(a_trial).max()
                if score < best_score - 1e-14:
                    a = a_trial
                    best_score = score
                    best_a = a.copy()
                    improved = True
                    break
            if improved:
                break

        if not improved:
            for ci in top_contrib[:3]:
                i = idx[ci]
                j = peak_k - i
                if i == j or a[j] < 1e-14:
                    continue
                for f1 in [0.95, 0.9]:
                    for f2 in [0.95, 0.9]:
                        a_trial = a.copy()
                        a_trial[i] *= f1
                        a_trial[j] *= f2
                        a_trial = a_trial / a_trial.sum()
                        score = 2.0 * n * fast_convolve(a_trial).max()
                        if score < best_score - 1e-14:
                            a = a_trial
                            best_score = score
                            best_a = a.copy()
                            improved = True
                            break
                    if improved:
                        break
                if improved:
                    break

    return best_a, best_score

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp

def evaluate_safe(a):
    try:
        a_list = [float(max(0, min(1000, x))) for x in a]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')
