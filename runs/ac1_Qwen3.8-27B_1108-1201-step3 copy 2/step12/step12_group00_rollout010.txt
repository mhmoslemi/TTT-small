**The connection to uncertainty intervals / Sidon sets:**

The problem of minimizing the peak of the autocorrelation is related to the "Bhattacharya bound" and "uncertainty" in signal processing. For a sequence of length n with energy E = sum(a^2), the minimum possible peak of the autocorrelation (over all phases, i.e., complex sequences) is bounded by:
max|c[k]| >= E / sqrt(2n-1) (for k ≠ 0)

But we're restricted to non-negative real sequences, which is a much more restrictive constraint.

For non-negative sequences, the peak at lag n-1 is sum(a^2) = E. And we need sum(a) = S (fixed). By Cauchy-Schwarz: E >= S^2/n. So the peak is at least S^2/n.

J = 2n * peak / S^2 >= 2n * S^2/n / S^2 = 2.

So with the non-negativity constraint, J >= 2 if the peak is at the center. But we can do better by making the peak NOT at the center!

Wait, if the peak is at a non-central lag, say lag 0, then c[0] = a[0]^2. For this to be the peak: a[0]^2 >= sum(a^2). This means a[0] >= a[i] for all i, and a[0]^2 >= sum a[i]^2. For non-negative a, this means a is "concentrated" at index 0.

If a = [1, 0, 0, ..., 0] (normalized to sum=1), then c = [1, 0, 0, ..., 0], peak = 1, J = 2n. That's terrible.

If a is uniform, peak = 1/n (at center), J = 2.

The optimal solution has the peak spread out, with no single lag having a disproportionately large value. The LP Nesterov approach finds such solutions.

I think the key insight for improvement is: **the LP Nesterov method converges to a local minimum, and the quality of this local minimum depends on the starting point and the number of iterations.** To get better results:
1. Start from a good initial point (the parent helps).
2. Run many iterations (need fast LP solves).
3. Use averaging (the average of the iterates often has a lower objective than any single iterate).
4. Try multiple starting points.
