        a_new = a - step * grad
        a_new = proj_simplex(a_new, 1.0)
        
        # Check convergence
        if np.max(np.abs(a_new - a)) < tol:
            a = a_new
            break
        
        a_old = a.copy()
        grad_prev = grad.copy()
        a = a_new
    
    return a

def nesterov_maximin(a0, time_limit, verbose=True):
    """
    Nesterov acceleration for the maximin formulation:
    min_{a in Delta} max_k (a*a)[k]
    
    Uses the dual: max_{p in Delta_k} min_{a in Delta} sum_k p_k (a*a)[k]
    
    The outer loop updates p (dual), the inner loop solves the QP (primal best response).
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    # Dual variable: distribution over lags
    num_lags = 2 * n - 1
    p = np.ones(num_lags) / num_lags
    
    best_a = a.copy()
    best_score = fast_autocorr(a).max()
    
    t0 = time.monotonic()
    y = p.copy()  # Nesterov momentum for dual
    
    for t in range(1, 1000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Solve the QP: min a^T Q(y) a s.t. a >= 0, 1^T a = 1
        a_br = qp_best_response(y, n, max_iters=100)
        
        # Compute the payoff vector: (a_br * a_br)[k] for all k
        payoff = fast_autocorr(a_br)  # length 2n-1
        
        # Update dual: Nesterov step
        alpha = 2.0 / (t + 2.0)
        
        # Gradient of the dual objective: the payoff vector (normalized)
        # max_p min_a ... the "gradient" for p is the current payoff
        p_new = (1.0 - alpha) * y + alpha * (payoff / payoff.sum())
        p_new = np.maximum(p_new, 0.0)
        p_new = p_new / p_new.sum()
        
        # Nesterov momentum update for y
        if t == 1:
            y_new = p_new
        else:
            momentum = (t - 1.0) / (t + 2.0)
            y_new = p_new + momentum * (p_new - y)
            y_new = np.maximum(y_new, 0.0)
            y_new = y_new / y_new.sum()
        
        y = y_new
        p = p_new
        
        # Evaluate current primal solution
        score = fast_autocorr(a_br).max()
        if score < best_score:
            best_score = score
            best_a = a_br.copy()
        
        # Also check the running average of a
        if t % 50 == 0:
            # The running average of the best responses is also a good approximation
            # (This is the "Mirro" or averaged output)
            pass
        
        if verbose and t % 200 == 0:
            elapsed = time.monotonic() - t0
            print(f"  MaxMin iter={t} ({elapsed:.0f}s): best={best_score:.8f}")
    
    return best_a, best_score

Hmm wait, I'm not sure the Nesterov on the dual is quite right. Let me reconsider.

The standard approach for zero-sum games is:
- Maintain iterates (a_t, p_t)
- a_{t+1} = best_response(p_t) [minimize sum_k p_t(k) (a*a)[k]]
- p_{t+1} = best_response(a_t) = delta_{argmax_k (a_t*a_t)[k]} [maximize (a*a)[k]]

The "best response" for p is just putting all mass on the maximizing k. But this is too aggressive. Instead, we use the "optimistic" or "Nesterov" variant:

- y_t = extrapolation of p_{t:t-1}
- a_{t+1} = best_response(y_t)
- p_{t+1} = f(p_t, a_{t+1}) where f is some update

Actually, the standard mirror descent for zero-sum games is:
- p_{t+1} = p_t * exp(-eta_t * grad_p) / Z
- where grad_p = (a_t * a_t) - value (the payoff vector)

And the "optimistic mirror descent" (OMD) or "Nesterov's method" uses:
- y_t = extrapolate(p)
- a_{t+1} = best_response(y_t)
- p_{t+1} = update(p_t, a_{t+1})

Let me use a simpler and more standard formulation. The key algorithm I want to implement is:

**Algorithm: OGD (Optimistic Gradient Descent) / Nesterov for zero-sum games**

State: a (primal), p (dual = distribution over lags), y (Nesterov momentum for p)

For t = 1, 2, ...:
  1. y = (1 + beta_t) * p - beta_t * p_{t-1}  [Nesterov extrapolation]
  2. a = argmin_{a in Delta} y^T (a*a)  [best response to y, solve QP]
  3. g = a*a  [payoff vector, this is the "gradient" for the dual]
  4. p = proj_Delta(p - eta_t * (g - g_{t-1}))  [optimistic dual update]
  
  Or simpler:
  4. p = proj_Delta(p + eta_t * g / sum(g))  [simple dual ascent]

The value estimate is the running average of the payoffs.

Actually, I think the cleanest formulation is:

For the zero-sum game with payoff matrix A[a,k] = (a*a)[k]:
- Primal: minimize max_k A[a,k] over a in Delta
- Dual: maximize min_a A[a,k] over p in Delta_k (where A[p,a] = sum_k p_k A[a,k])

Mirror descent / Follow-the-Regularized-Leader (FTRL):
- p_t = argmin_{p in Delta_k} <p, g_{t-1}> + (1/eta) D(p, p_{t-1})
  where g_{t-1} = A[a_{t-1}, :] (the payoff vector)
  and D is KL divergence (for mirror descent) or squared distance (for GD)

- a_t = argmin_{a in Delta} sum_k p_t[k] A[a, k]
  = argmin_{a in Delta} a^T Q(p_t) a

The "optimistic" variant uses g_{t-1} - g_{t-2} instead of g_{t-1} in the dual update, which gives faster convergence.
