Let me think differently. Define `w_ext` as `w[k]` for `k = 0, ..., 2n-2` (the full convolution length).

`grad_i = 2 * sum_{j=0}^{n-1} w_ext[j+i] * a[j]`

This is the cross-correlation of `w_ext` and `a` evaluated at shift `i`.

Cross-correlation: `(w_ext ⋆ a)[i] = sum_j w_ext[j+i] * a[j]`

This can be computed as: reverse `a`, convolve with `w_ext`, and extract.

`(w_ext ⋆ a)[i] = (w_ext * a_rev)[(n-1) + i + (len(w_ext)-1)]`... this is getting confusing.

Let me use a different approach. Define `b = a[::-1]` (reversed). Then:

`sum_j w_ext[j+i] * a[j] = sum_j w_ext[j+i] * b[n-1-j]`

Let `l = n-1-j`, so `j = n-1-l`:
`= sum_l w_ext[n-1-l+i] * b[l]`
`= sum_l b[l] * w_ext[i + n-1 - l]`

This is the convolution `(b * w_ext)[i + n-1]`.

So `grad_i = 2 * (b * w_ext)[i + n-1]` where `b = a[::-1]`.

OK so the gradient computation is O(n log n) via FFT. 

Now, the LSE approach:
- Temperature `T`: controls how peaked the weights are
- `w_k = exp(c_k / T) / sum_k exp(c_j / T)` (softmax of the convolution values)
- As `T -> 0`, `w` concentrates on the argmax
- As `T -> ∞`, `w` becomes uniform

The algorithm:
1. Start with some `a` (normalized to sum = 1)
2. For iterations:
   a. Compute `c = conv(a,a)`
   b. Compute `w = softmax(c/T)`
   c. Compute `grad = 2 * (a_rev * w)[n-1:n-1+n]`
   d. Update: `a = a - eta * grad`, project to `[0, ∞)`, renormalize to sum = 1
   e. Anneal `T`

The step size `eta` is crucial. Since the objective is `2n * max(c)`, and we're using the LSE surrogate, the Lipschitz constant of the gradient depends on the problem.

Let me think about the step size. The gradient `grad_i = 2 * sum_j w[j+i] * a[j]`. Since `w` is a probability distribution (sums to 1) and `a` sums to 1:
`|grad_i| <= 2 * max_j |a[j]|` (since `sum_j w[j+i] <= 1`)

Actually, `sum_j w[j+i]` could be up to 1 (if all the weight is at indices reachable from `i`). And `max_j |a[j]| <= 1`. So `|grad_i| <= 2`.

But more precisely, since `a >= 0` and `sum(a) = 1`, `max(a) <= 1`. And `sum_j w[j+i] * a[j] <= max(a) * sum_j w[j+i] <= max(a)`.

So the gradient is bounded by `2 * max(a)`.

For a safe step: `eta <= 1 / L` where `L` is the Lipschitz constant of the gradient. The Hessian of the LSE surrogate is complicated, but as a heuristic, `eta = 1 / (2 * max(a))` should be safe.

Let me also think about the "dual" of the LP. The LP is:
`max 1^T b` s.t. `C b <= M * 1`, `b >= 0`

where `C` is the `a`-convolution matrix (size `(2n-1) × n`).

The dual is:
`min M * 1^T y` s.t. `C^T y >= 1`, `y >= 0`

The complementary slackness conditions tell us:
- If `b_i > 0`, then `(C^T y)_i = 1` (the dual constraint is tight)
- If `(Cb)_k < M`, then `y_k = 0` (the primal constraint is not binding)

So the dual variables `y_k` are non-zero only at the "binding" lags. The number of non-zero dual variables equals the number of support points in the primal (by the fundamental theorem of LP).

This gives us a way to validate the LP solution: check that the number of active constraints matches the number of non-zero primal variables.

For the Nesterov iteration, the key parameter is the step size. The standard Nesterov method for convex optimization over a convex set uses:
- `y_t = (1 - alpha_t) x_t + alpha_t * x*` (where `x*` is the best response)
- `x_{t+1} = y_t + momentum * (y_t - x_t)`

But in our case, the "best response" is the LP solution, which is the projection of a certain direction onto the feasible set `{b : Cb <= M*1, b >= 0}`.

Actually, the LP best response IS the solution of the variational inequality:
`<b* - b, c> <= 0 for all b in feasible set`

where `c = C^T 1` (the gradient of the objective `sum(b)`)... no, that's not quite right either.

Let me think about this more carefully. The best response problem is:
`max_{b >= 0, Cb <= M*1} 1^T b`

This is equivalent to: find `b*` that maximizes `1^T b` subject to the constraints.

The Nesterov iteration is:
1. Solve LP: `b* = argmax_{b >= 0, Cb <= M*1} 1^T b`
2. Rescale: `g = b* * S / sum(b*)` where `S = sqrt(2n)`
3. Nesterov update: `y <- (1-alpha)*y + alpha*g`, `x <- y + momentum*(y - y_old)`

The convergence of this depends on the "diameter" of the feasible set and the strong convexity of the objective (which is not strongly convex here, so we get the standard `O(1/T²)` rate for Nesterov on convex functions).

"""

1. Fast LSE (log-sum-exp) gradient descent with temperature annealing
2. LP best response with Nesterov acceleration for final polish

import numpy as np
import cvxpy as cp
import time
from scipy.fft import rfft, irfft

_solver_global = None

def get_lp_solver():
    """Find the best available LP solver."""
    global _solver_global
    if _solver_global is not None:
        return _solver_global
    for s in [cp.PDLP, cp.CLARABEL, cp.ECOS]:
        try:
            x = cp.Variable(20, nonneg=True)
            prob = cp.Problem(cp.Minimize(cp.sum(x)), [cp.sum(x) == 1, x <= 0.5])
            prob.solve(solver=s, verbose=False)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                _solver_global = s
                print(f"  LP solver: {s}")
                return s
        except Exception:
            continue
    _solver_global = cp.ECOS
    print(f"  LP solver (fallback): ECOS")
    return _solver_global


def fast_conv(a):
    """Compute full linear convolution a*a using FFT."""
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def lse_gradient(a, w):
    """Compute gradient of sum_k w[k]*conv(a,a)[k] w.r.t. a.
    
    Parameters:
        a: array of length n (non-negative)
        w: array of length 2n-1 (LSE weights, sum to 1)
    
    Returns:
        grad: array of length n
    """
    n = len(a)
    # grad[i] = 2 * sum_j w[j+i] * a[j] for valid j
    # This is the cross-correlation (w ⋆ a)[i]
    # = (a_rev * w)[n-1+i] where * is linear convolution
    a_rev = a[::-1]
    fft_size = 1 << (3 * n - 3 - 1).bit_length()
    Ar = rfft(a_rev, fft_size)
    W = rfft(w, fft_size)
    cross = irfft(Ar * W, fft_size)
    # cross has length fft_size, we need indices n-1 to n-1+n-1
    grad = 2.0 * cross[n - 1: n - 1 + n]
    return grad


def lse_objective_score(a):
    """Compute the actual objective score for a."""
    n = len(a)
    c = fast_conv(a)
    s = a.sum()
    if s < 1e-15:
        return float('inf')
    return 2.0 * n * c.max() / (s * s)


def normalize_seq(a, target_sum):
    """Normalize a to have the given sum, maintaining non-negativity."""
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a)) * target_sum / len(a)
    return a * (target_sum / s)


def lse_gradient_descent(a0, time_limit, T_start=5.0, T_end=0.5, n_stages=15, verbose=True):
    """LSE gradient descent with temperature annealing."""
    n = len(a0)
    S = np.sqrt(2.0 * n)
    a = normalize_seq(np.asarray(a0, dtype=np.float64), S)
    
    best_a = a.copy()
    best_score = lse_objective_score(a)
    t0 = time.monotonic()
    
    if verbose:
        print(f"  LSE-GD start: score={best_score:.6f}")
    
    temps = np.geomspace(T_start, T_end, n_stages)
    
    for si, T in enumerate(temps):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Compute number of steps for this stage
        remaining = time_limit - (time.monotonic() - t0)
        n_stages_remaining = n_stages - si
        steps_per_stage = max(10, int(remaining * 5 / n_stages_remaining))
        steps_per_stage = min(steps_per_stage, 500)
        
        for it in range(steps_per_stage):
            if time.monotonic() - t0 > time_limit:
                break
            
            c = fast_conv(a)
            
            # LSE weights with temperature T
            # Scale c to avoid overflow
            c_scaled = c / T
            c_max = c_scaled.max()
            exp_c = np.exp(c_scaled - c_max)
            w = exp_c / exp_c.sum()
            
            # Gradient
            grad = lse_gradient(a, w)
            
            # Adaptive step size
            # The gradient magnitude gives a natural scale
            gnorm = np.linalg.norm(grad)
            if gnorm < 1e-15:
                break
            # Scale a to have unit sum for step size calculation
            a_unit = a / a.sum()
            max_a = a_unit.max()
            eta = 0.5 / max(max_a, 0.01) * (1.0 / (1.0 + 0.5 * it / steps_per_stage))
            # Clip step to not overshoot
            eta = min(eta, 0.5 / (gnorm + 1e-10))
            
            a_new = a - eta * grad
            a_new = np.maximum(a_new, 0.0)
            s = a_new.sum()
            if s < S * 0.1:
                a_new = a.copy()  # Don't overshoot
            else:
                a_new = a_new * S / s
            
            score = lse_objective_score(a_new)
            if score < best_score:
                best_score = score
                best_a = a_new.copy()
            
            a = a_new
        
        if verbose and (si % 3 == 0 or si == n_stages - 1):
            elapsed = time.monotonic() - t0
            print(f"  LSE-GD stage {si+1}/{n_stages} (T={T:.3f}) ({elapsed:.0f}s): score={best_score:.6f}")
    
    return best_a, best_score


def build_conv_matrix(a):
    """Build the (2n-1) x n convolution matrix for a."""
    n = len(a)
    T = np.zeros((2 * n - 1, n))
    for j in range(n):
        T[j:j + n, j] = a
    return T


def lp_best_response(a, M, solver):
    """Solve: max sum(b) s.t. conv(a,b) <= M, b >= 0."""
    n = len(a)
    b_var = cp.Variable(n, nonneg=True)
    T = build_conv_matrix(a)
    constraints = [T @ b_var <= M]
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        return None
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None
    b_val = np.asarray(b_var.value, dtype=np.float64)
    b_val = np.maximum(b_val, 0.0)
    if b_val.sum() < 1e-15:
        return None
    return b_val


def nesterov_lp(a0, time_limit, solver, verbose=True):
    """Nesterov-accelerated LP best response iteration."""
    n = len(a0)
    S = np.sqrt(2.0 * n)
    a = normalize_seq(np.asarray(a0, dtype=np.float64), S)
    
    best_a = a.copy()
    best_score = lse_objective_score(a)
    t0 = time.monotonic()
    
    y = a.copy()
    n_iters = 0
    
    if verbose:
        print(f"  NLP start: score={best_score:.6f}")
    
    for t in range(1, 50000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Compute current M from y
        c_y = fast_conv(y)
        M_curr = c_y.max()
        if M_curr < 1e-12:
            break
        
        # LP best response
        b = lp_best_response(y, M_curr, solver)
        if b is None:
            continue
        
        b_sum = b.sum()
        if b_sum < 1e-15:
            continue
        g = b * S / b_sum
        n_iters += 1
        
        # Nesterov update
        alpha = 2.0 / (t + 2.0)
        y_new = (1.0 - alpha) * y + alpha * g
        y_new = np.maximum(y_new, 0.0)
        s_y = y_new.sum()
        if s_y < S * 0.01:
            y_new = y.copy()
        else:
            y_new = y_new * S / s_y
        
        if t == 1:
            a_new = g.copy()
        else:
            momentum = (t - 1.0) / (t + 2.0)
            a_new = y_new + momentum * (y_new - y)
            a_new = np.maximum(a_new, 0.0)
            s_a = a_new.sum()
            if s_a < S * 0.01:
                a_new = y_new.copy()
            else:
                a_new = a_new * S / s_a
        
        y = y_new
        a = a_new
        
        # Check improvement
        score_a = lse_objective_score(a)
        if score_a < best_score:
            best_score = score_a
            best_a = a.copy()
        
        score_y = lse_objective_score(y)
        if score_y < best_score:
            best_score = score_y
            best_a = y.copy()
        
        if verbose and n_iters % 50 == 0:
            elapsed = time.monotonic() - t0
            print(f"  NLP iter={n_iters} ({elapsed:.0f}s): score={best_score:.6f}")
    
    return best_a, best_score


def interpolate_to_length(a, new_n):
    """Interpolate sequence a to have new_n elements, preserving sum."""
    old_n = len(a)
    if old_n == new_n:
        return a.copy()
    s = a.sum()
    if s < 1e-15:
        return np.ones(new_n)
    a_norm = a / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    a_interp = np.interp(new_x, old_x, a_norm)
    a_interp = np.maximum(a_interp, 0.0)
    ss = a_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n)
    return a_interp * s / ss


def structured_init(n, rng):
    """Create a structured initial sequence."""
    choice = rng.integers(0, 6)
    if choice == 0:
        # Smooth bump (cosine window)
        x = np.linspace(0.0, 1.0, n)
        a = np.cos(np.pi * x / 2.0) ** 2
    elif choice == 1:
        # Triangle-like
        x = np.linspace(0.0, 1.0, n)
        a = 1.0 - np.abs(2.0 * x - 1.0)
        a = a ** 2
    elif choice == 2:
        # Two bumps
        x = np.linspace(0.0, 1.0, n)
        a = np.exp(-20.0 * (x - 0.3) ** 2) + 0.7 * np.exp(-20.0 * (x - 0.7) ** 2)
    elif choice == 3:
        # Oscillatory
        x = np.linspace(0.0, 1.0, n)
        a = 0.5 + 0.3 * np.cos(2.0 * np.pi * 3.0 * x) + 0.1 * np.cos(2.0 * np.pi * 7.0 * x)
    elif choice == 4:
        # Fejer-like kernel
        x = np.linspace(0.0, 1.0, n)
        a = np.sin(np.pi * x) ** 1.5
    else:
        # Near uniform with small perturbation
        a = np.ones(n) + 0.05 * rng.normal(size=n)
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s


def peak_shave(a, time_limit, seed=42):
    """Local peak shaving: move mass from peak-contributing positions to low-peak positions."""
    n = len(a)
    S = np.sqrt(2.0 * n)
    rng = np.random.default_rng(seed)
    a = normalize_seq(np.asarray(a, dtype=np.float64), S)
    
    best_a = a.copy()
    best_score = lse_objective_score(a)
    t0 = time.monotonic()
    stall = 0
    
    while time.monotonic() - t0 < time_limit:
        c = fast_conv(a)
        # Top 5 peaks
        top_k = np.argsort(c)[::-1][:5]
        
        improved = False
        for k in top_k:
            # Identify positions contributing to this peak
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            contrib = a[idx] * a[k - idx]
            total_contrib = contrib.sum()
            if total_contrib < 1e-15:
                continue
            
            # Source: position with highest contribution
            src = idx[np.argmax(contrib)]
            
            # Destination: position that doesn't contribute much to any top peak
            peak_mask = np.zeros(n, dtype=bool)
            for k2 in top_k:
                js2 = max(0, k2 - n + 1)
                je2 = min(n - 1, k2)
                peak_mask[js2:je2 + 1] = True
            
            candidates = np.where(~peak_mask)[0]
            if len(candidates) == 0:
                candidates = np.where(np.arange(n) != src)[0]
            
            if len(candidates) == 0:
                continue
            
            # Pick from candidates with lowest current value
            cands_sorted = candidates[np.argsort(a[candidates])]
            dst = cands_sorted[rng.integers(min(len(cands_sorted), max(1, len(cands_sorted)//4)))]
            
            # Try different transfer fractions
            for frac in [0.001, 0.003, 0.01, 0.02, 0.05]:
                amt = a[src] * frac
                if amt < 1e-18:
                    continue
                a_trial = a.copy()
                a_trial[src] -= amt
                a_trial[dst] += amt
                if a_trial[src] < 0:
                    continue
                a_trial = normalize_seq(a_trial, S)
                score = lse_objective_score(a_trial)
                if score < best_score - 1e-12:
                    a = a_trial
                    best_score = score
                    best_a = a.copy()
                    improved = True
                    stall = 0
                    break
            
            if improved:
                break
        
        if not improved:
            stall += 1
            # Random perturbation
            i = rng.integers(n)
            j = rng.integers(n)
            if i != j and a[i] > S * 1e-6:
                amt = a[i] * rng.uniform(0.01, 0.05)
                a_trial = a.copy()
                a_trial[i] -= amt
                a_trial[j] += amt
                if a_trial[i] >= 0:
                    a_trial = normalize_seq(a_trial, S)
                    score = lse_objective_score(a_trial)
                    if score < best_score:
                        a = a_trial
                        best_score = score
                        best_a = a.copy()
                        stall = 0
            if stall > 200:
                break
    
    return best_a, best_score

Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Fast LSE (log-sum-exp) gradient descent with temperature annealing (O(n log n) per step)
2. LP best response with Nesterov acceleration for precise optimization
3. Multi-length exploration with interpolation transfer
4. Peak shaving local refinement
5. Dual-gap monitoring for convergence detection
Key: FFT-based gradient computation allows 10x more iterations than LP-only approaches.

import numpy as np
import cvxpy as cp
import time
from scipy.fft import rfft, irfft

_solver_global = None


def get_lp_solver():
    global _solver_global
    if _solver_global is not None:
        return _solver_global
    for s in [cp.PDLP, cp.CLARABEL, cp.ECOS]:
        try:
            x = cp.Variable(20, nonneg=True)
            prob = cp.Problem(cp.Minimize(cp.sum(x)), [cp.sum(x) == 1, x <= 0.5])
            prob.solve(solver=s, verbose=False)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                _solver_global = s
                print(f"  LP solver: {s}")
                return s
        except Exception:
            continue
    _solver_global = cp.ECOS
    print(f"  LP solver (fallback): ECOS")
    return _solver_global


def fast_conv(a):
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def lse_objective_score(a):
    n = len(a)
    c = fast_conv(a)
    s = a.sum()
    if s < 1e-15:
        return float('inf')
    return 2.0 * n * c.max() / (s * s)


def normalize_seq(a, target_sum):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a)) * target_sum / len(a)
    return a * (target_sum / s)


def compute_lse_grad(a, w):
    n = len(a)
    a_rev = a[::-1]
    total_len = 3 * n - 2
    fft_size = 1 << (total_len - 1).bit_length()
    Ar = rfft(a_rev, fft_size)
    W = rfft(w, fft_size)
    cross = irfft(Ar * W, fft_size)
    grad = 2.0 * cross[n - 1: n - 1 + n]
    return grad


def lse_gradient_descent(a0, time_limit, T_start, T_end, n_stages, verbose=True):
    n = len(a0)
    S = np.sqrt(2.0 * n)
    a = normalize_seq(np.asarray(a0, dtype=np.float64), S)
    best_a = a.copy()
    best_score = lse_objective_score(a)
    t0 = time.monotonic()

    if verbose:
        print(f"    LSE-GD start: score={best_score:.8f}")

    temps = np.geomspace(T_start, T_end, n_stages)

    for si, T in enumerate(temps):
        if time.monotonic() - t0 > time_limit:
            break

        remaining = time_limit - (time.monotonic() - t0)
        n_stages_left = max(1, n_stages - si)
        steps = max(5, int(remaining * 8.0 / n_stages_left))
        steps = min(steps, 2000)

        for it in range(steps):
            if time.monotonic() - t0 > time_limit:
                break

            c = fast_conv(a)
            c_scaled = c / (T * 10.0)
            c_max = c_scaled.max()
            exp_c = np.exp(c_scaled - c_max)
            w = exp_c / exp_c.sum()

            grad = compute_lse_grad(a, w)
            gnorm = np.linalg.norm(grad)
            if gnorm < 1e-14:
                break

            a_unit = a / a.sum()
            max_a = max(a_unit.max(), 0.01)
            eta = 0.8 / (max_a * max_a * n)
            eta = min(eta, 0.3 / (gnorm + 1e-12))

            a_new = a - eta * grad
            a_new = np.maximum(a_new, 0.0)
            s = a_new.sum()
            if s < S * 0.05:
                a_new = a * (1.0 - 0.01) + 0.01 * a
                a_new = np.maximum(a_new, 0.0)
                s = a_new.sum()
            a_new = a_new * S / s

            score = lse_objective_score(a_new)
            if score < best_score:
                best_score = score
                best_a = a_new.copy()
            a = a_new

        if verbose and (si % 3 == 0 or si == n_stages - 1):
            elapsed = time.monotonic() - t0
            print(f"    LSE stage {si+1}/{n_stages} (T={T:.3f}) t={elapsed:.0f}s: score={best_score:.8f}")

    return best_a, best_score


def build_conv_matrix(a):
    n = len(a)
    T = np.zeros((2 * n - 1, n))
    for j in range(n):
        T[j: j + n, j] = a
    return T


def lp_best_response(a, M, solver):
    n = len(a)
    b_var = cp.Variable(n, nonneg=True)
    T = build_conv_matrix(a)
    constraints = [T @ b_var <= M]
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        return None
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None
    b_val = np.asarray(b_var.value, dtype=np.float64)
    b_val = np.maximum(b_val, 0.0)
    if b_val.sum() < 1e-15:
        return None
    return b_val


def nesterov_lp(a0, time_limit, solver, verbose=True, restart_every=200):
    n = len(a0)
    S = np.sqrt(2.0 * n)
    a = normalize_seq(np.asarray(a0, dtype=np.float64), S)
    best_a = a.copy()
    best_score = lse_objective_score(a)
    t0 = time.monotonic()

    y = a.copy()
    n_iters = 0
    prev_score = best_score

    if verbose:
        print(f"    NLP start: score={best_score:.8f}")

    for t in range(1, 200000):
        if time.monotonic() - t0 > time_limit:
            break

        c_y = fast_conv(y)
        M_curr = c_y.max()
        if M_curr < 1e-14:
            break

        b = lp_best_response(y, M_curr, solver)
        if b is None:
            continue

        b_sum = b.sum()
        if b_sum < 1e-15:
            continue
        g = b * S / b_sum
        n_iters += 1

        alpha = 2.0 / (t + 2.0)
        y_new = (1.0 - alpha) * y + alpha * g
        y_new = np.maximum(y_new, 0.0)
        s_y = y_new.sum()
        if s_y < S * 0.01:
            y_new = y.copy()
        else:
            y_new = y_new * S / s_y

        if t == 1:
            a_new = g.copy()
        else:
            momentum = (t - 1.0) / (t + 2.0)
            a_new = y_new + momentum * (y_new - y)
            a_new = np.maximum(a_new, 0.0)
            s_a = a_new.sum()
            if s_a < S * 0.01:
                a_new = y_new.copy()
            else:
                a_new = a_new * S / s_a

        y = y_new
        a = a_new

        score_a = lse_objective_score(a)
        if score_a < best_score:
            best_score = score_a
            best_a = a.copy()

        score_y = lse_objective_score(y)
        if score_y < best_score:
            best_score = score_y
            best_a = y.copy()

        if verbose and n_iters % 25 == 0:
            elapsed = time.monotonic() - t0
            print(f"    NLP iter={n_iters} t={elapsed:.0f}s: score={best_score:.8f}")

        if t % restart_every == 0 and t > restart_every:
            cur_score = lse_objective_score(a)
            if cur_score > prev_score * (1.0 + 1e-4):
                y = best_a.copy()
                prev_score = best_score
                t = restart_every
            else:
                prev_score = best_score

    return best_a, best_score


def interpolate_to_length(a, new_n):
    old_n = len(a)
    if old_n == new_n:
        return a.copy()
    s = a.sum()
    if s < 1e-15:
        return np.ones(new_n)
    a_norm = a / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    a_interp = np.interp(new_x, old_x, a_norm)
    a_interp = np.maximum(a_interp, 0.0)
    ss = a_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n)
    return a_interp * s / ss


def structured_init(n, rng):
    choice = rng.integers(0, 6)
    if choice == 0:
        x = np.linspace(0.0, 1.0, n)
        a = np.cos(np.pi * x / 2.0) ** 2
    elif choice == 1:
        x = np.linspace(0.0, 1.0, n)
        a = (1.0 - np.abs(2.0 * x - 1.0)) ** 2
    elif choice == 2:
        x = np.linspace(0.0, 1.0, n)
        a = np.exp(-20.0 * (x - 0.3) ** 2) + 0.7 * np.exp(-20.0 * (x - 0.7) ** 2)
    elif choice == 3:
        x = np.linspace(0.0, 1.0, n)
        a = 0.5 + 0.3 * np.cos(2.0 * np.pi * 3.0 * x) + 0.1 * np.cos(2.0 * np.pi * 7.0 * x)
    elif choice == 4:
        x = np.linspace(0.0, 1.0, n)
        a = np.sin(np.pi * x) ** 1.5
    else:
        a = np.ones(n) + 0.05 * rng.normal(size=n)
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s


def peak_shave(a0, time_limit, seed):
    n = len(a0)
    S = np.sqrt(2.0 * n)
    rng = np.random.default_rng(seed)
    a = normalize_seq(np.asarray(a0, dtype=np.float64), S)
    best_a = a.copy()
    best_score = lse_objective_score(a)
    t0 = time.monotonic()
    stall = 0

    if verbose_peak_shave():
        print(f"    PeakShave start: score={best_score:.8f}")

    while time.monotonic() - t0 < time_limit:
        c = fast_conv(a)
        top_k = np.argsort(c)[::-1][:5]
        improved = False

        for k in top_k:
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            contrib = a[idx] * a[k - idx]
            if contrib.sum() < 1e-15:
                continue
            src = idx[np.argmax(contrib)]

            peak_mask = np.zeros(n, dtype=bool)
            for k2 in top_k:
                js2 = max(0, k2 - n + 1)
                je2 = min(n - 1, k2)
                peak_mask[js2: je2 + 1] = True

            candidates = np.where(~peak_mask)[0]
            if len(candidates) == 0:
                candidates = np.where(np.arange(n) != src)[0]
            if len(candidates) == 0:
                continue

            cands_sorted = candidates[np.argsort(a[candidates])]
            n_pick = max(1, len(cands_sorted) // 5)
            dst = cands_sorted[rng.integers(n_pick)]

            for frac in [0.001, 0.003, 0.01, 0.02, 0.04]:
                amt = a[src] * frac
                if amt < 1e-18:
                    continue
                a_trial = a.copy()
                a_trial[src] -= amt
                a_trial[dst] += amt
                if a_trial[src] < 0:
                    continue
                a_trial = normalize_seq(a_trial, S)
                score = lse_objective_score(a_trial)
                if score < best_score - 1e-14:
                    a = a_trial
                    best_score = score
                    best_a = a.copy()
                    improved = True
                    stall = 0
                    break
            if improved:
                break

        if not improved:
            stall += 1
            i = rng.integers(n)
            j = rng.integers(n)
            if i != j and a[i] > S * 1e-7:
                amt = a[i] * rng.uniform(0.005, 0.03)
                a_trial = a.copy()
                a_trial[i] -= amt
                a_trial[j] += amt
                if a_trial[i] >= 0:
                    a_trial = normalize_seq(a_trial, S)
                    score = lse_objective_score(a_trial)
                    if score < best_score:
                        a = a_trial
                        best_score = score
                        best_a = a.copy()
                        stall = 0
            if stall > 300:
                break

    return best_a, best_score


def verbose_peak_shave():
    return True


def update_best(state, a, label, t_global):
    if a is None:
        return
    a = np.asarray(a, dtype=np.float64)
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 0.01:
        return
    a_norm = a / s
    sc = lse_objective_score(a_norm)
    if np.isfinite(sc) and sc < state['best_score']:
        state['best_score'] = sc
        state['best_seq'] = a_norm.copy()
        elapsed = time.monotonic() - t_global
        print(f"  *** NEW BEST [{label}]: {sc:.8f} (n={len(a_norm)}, t={elapsed:.0f}s)")


def propose_candidate(seed=42, budget_s=1800.0):
    rng = np.random.default_rng(seed)
    t_global = time.monotonic()
    time_budget = min(float(budget_s) - 150.0, 1620.0)

    solver = get_lp_solver()
    print(f"Time budget: {time_budget:.0f}s")

    state = {'best_seq': None, 'best_score': float('inf')}

    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 0.01:
            parent = p
            p_norm = p / p.sum()
            p_score = lse_objective_score(p_norm)
            print(f"Parent: n={len(parent)}, score={p_score:.8f}")
            state['best_seq'] = p_norm.copy()
            state['best_score'] = p_score
    except Exception as e:
        print(f"  No parent: {e}")

    if parent is None:
        n_init = 1600
        state['best_seq'] = structured_init(n_init, rng)
        state['best_score'] = lse_objective_score(state['best_seq'])
        print(f"  Init: n={n_init}, score={state['best_score']:.8f}")

    n_base = len(state['best_seq'])

    # Phase 1: LSE gradient descent (fast, many iterations)
    remaining = time_budget - (time.monotonic() - t_global)
    t1 = min(remaining * 0.30, 450.0)
    print(f"\n=== Phase 1: LSE-GD n={n_base} (budget={t1:.0f}s) ===")
    if t1 > 20:
        a_out, _ = lse_gradient_descent(
            state['best_seq'], t1,
            T_start=2.0, T_end=0.2, n_stages=15, verbose=True
        )
        update_best(state, a_out, f"lse1_n{n_base}", t_global)

    # Phase 2: LP Nesterov at base length
    remaining = time_budget - (time.monotonic() - t_global)
    n_cur = len(state['best_seq'])
    t2 = min(remaining * 0.25, 350.0)
    print(f"\n=== Phase 2: LP-Nesterov n={n_cur} (budget={t2:.0f}s) ===")
    if t2 > 30:
        a_out, _ = nesterov_lp(state['best_seq'], t2, solver, verbose=True)
        update_best(state, a_out, f"lp_n{n_cur}", t_global)

    # Phase 3: Second LSE pass at (possibly updated) length
    remaining = time_budget - (time.monotonic() - t_global)
    n_cur = len(state['best_seq'])
    t3 = min(remaining * 0.15, 200.0)
    print(f"\n=== Phase 3: LSE-GD pass 2 n={n_cur} (budget={t3:.0f}s) ===")
    if t3 > 15:
        a_out, _ = lse_gradient_descent(
            state['best_seq'], t3,
            T_start=1.0, T_end=0.1, n_stages=10, verbose=True
        )
        update_best(state, a_out, f"lse2_n{n_cur}", t_global)

    # Phase 4: Try longer length
    n2 = n_cur + 400
    remaining = time_budget - (time.monotonic() - t_global)
    t4 = min(remaining * 0.15, 200.0)
    print(f"\n=== Phase 4: LSE-GD n={n2} (budget={t4:.0f}s) ===")
    if t4 > 20 and remaining > 120:
        init_long = interpolate_to_length(state['best_seq'], n2)
        a_out, _ = lse_gradient_descent(
            init_long, t4,
            T_start=1.5, T_end=0.2, n_stages=10, verbose=True
        )
        update_best(state, a_out, f"lse_n{n2}", t_global)

    # Phase 5: LP Nesterov at longer length
    remaining = time_budget - (time.monotonic() - t_global)
    n_cur = len(state['best_seq'])
    t5 = min(remaining * 0.12, 180.0)
    print(f"\n=== Phase 5: LP-Nesterov n={n_cur} (budget={t5:.0f}s) ===")
    if t5 > 30 and remaining > 60:
        a_out, _ = nesterov_lp(state['best_seq'], t5, solver, verbose=True)
        update_best(state, a_out, f"lp2_n{n_cur}", t_global)

    # Phase 6: Peak shaving
    remaining = time_budget - (time.monotonic() - t_global)
    t6 = min(remaining * 0.10, 120.0)
    print(f"\n=== Phase 6: Peak shaving (budget={t6:.0f}s) ===")
    if t6 > 10:
        a_out, _ = peak_shave(state['best_seq'], t6, seed=12345)
        update_best(state, a_out, "peak_shave", t_global)

    # Phase 7: Final LSE polish
    remaining = time_budget - (time.monotonic() - t_global)
    t7 = min(remaining * 0.18, 150.0)
    print(f"\n=== Phase 7: LSE polish (budget={t7:.0f}s) ===")
    if t7 > 10:
        a_out, _ = lse_gradient_descent(
            state['best_seq'], t7,
            T_start=0.3, T_end=0.05, n_stages=8, verbose=True
        )
        update_best(state, a_out, "lse_final", t_global)

    # Phase 8: Final peak shave
    remaining = time_budget - (time.monotonic() - t_global)
    if remaining > 15:
        t8 = min(remaining * 0.6, 80.0)
        if t8 > 5:
            print(f"\n=== Phase 8: Final peak shave (budget={t8:.0f}s) ===")
            a_out, _ = peak_shave(state['best_seq'], t8, seed=99999)
            update_best(state, a_out, "peak_shave_final", t_global)

    # Final check
    if state['best_seq'] is not None:
        fs = lse_objective_score(state['best_seq'])
        state['best_score'] = min(state['best_score'], fs)
        print(f"\nFINAL: score={state['best_score']:.8f}, n={len(state['best_seq'])}, "
              f"time={time.monotonic()-t_global:.0f}s")
    else:
        print("\nERROR: No valid sequence!")
        return [1.0]

    return [float(x) for x in state['best_seq']]
