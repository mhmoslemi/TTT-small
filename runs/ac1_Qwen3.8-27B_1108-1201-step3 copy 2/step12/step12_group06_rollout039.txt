def evaluate_safe(a):

def softmax(z):

    exp_z = np.exp(z_shifted)
    s = exp_z.sum()
    if s < 1e-300:
        return np.ones(len(z)) / len(z)
    return exp_z / s

def project_simplex(v):
    """Project onto probability simplex {x: x>=0, sum(x)=1}."""
    n = len(v)
    if v.sum() < 1e-15:
        return np.ones(n) / n
    # Algorithm from "Euclidean projection on the simplex"
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho_arr = np.where(u * np.arange(1, n+1) > (cssv - 1))[0]
    if len(rho_arr) == 0:
        return np.ones(n) / n
    rho = rho_arr[-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)

Now let me think about the Nesterov update. The standard FISTA for minimizing f(x) + indicator_C(x) (where C is the constraint set) is:

Given x_k, y_k:
1. (a_{k+1}, M_{k+1}) = prox_{eta_k * f}(y_k)  [for our case: project onto simplex with gradient step]
2. t_{k+1} = (1 + sqrt(1 + 4*t_k^2)) / 2
3. y_{k+1} = a_{k+1} + ((t_k - 1) / t_{k+1}) * (a_{k+1} - a_k)
4. Project y_{k+1} onto C (simplex)

For the subgradient case (non-smooth f), we use:
1. g = subgradient of f at y_k
2. a_{k+1} = project_simplex(y_k - eta_k * g)
3. (same as above for t and y updates)

The step size eta_k can be:
- Polyak: eta_k = (f(y_k) - f*) / ||g||^2 (with f* being a lower bound)
- Decreasing: eta_k = eta_0 / sqrt(k)

For non-smooth convex problems, the Polyak step with a known lower bound gives O(1/k) convergence (vs O(1/sqrt(k)) for the decreasing step). With Nesterov acceleration, we get O(1/k^2) for the function value.

        a_new = project_simplex(y - eta * g)
        
        # Nesterov momentum
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t * t)) / 2.0
        y_new = a_new + ((t - 1.0) / t_new) * (a_new - a_prev)
        y_new = project_simplex(y_new)
        
        a_prev = a
        a = a_new
        y = y_new
        t = t_new
        
        # Check score
        sc = 2.0 * n * fast_convolve(a).max()
        if sc < best_score:
            best_score = sc
            best_a = a.copy()
            stagnant_count = 0
        else:
            stagnant_count += 1
        
        # Restart if stagnant
        if stagnant_count > 5000:
            y = best_a.copy()
            a_prev = best_a.copy()
            t = 1.0
            stagnant_count = 0
            n_active_frac = min(1.0, n_active_frac * 1.05)
        
        if (it + 1) % 10000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    NSG iter={it+1} ({elapsed:.0f}s): cur={2*n*fast_convolve(a).max():.8f} best={best_score:.8f}")
    
    return best_a, best_score
```

Now let me also implement the LSE (LogSumExp) smoothing with L-BFGS, similar to the previous code but with some improvements.

For the LSE objective:
f_T(a) = (2n/T) * log(sum_k exp(T * (a*a)_k))

The gradient:
∂f_T/∂a_j = (2n/T) * (1/sum_k exp(T*b_k)) * sum_k T * exp(T*b_k) * 2*a_{k-j}
= (2n) * sum_k w_k * 2*a_{k-j}
where w_k = exp(T*b_k) / sum_l exp(T*b_l)

This is just a weighted subgradient! The weights w_k are the "soft" active set.

So the LSE gradient is: 4n * sum_k w_k * a_{k-j} (with the usual bounds).

This can also be computed via FFT: create a weight vector w_k, and compute the convolution as before.

Let me implement this:

```python
def lse_objective_and_grad(a, T):
    n = len(a)
    b = fast_convolve(a)
    Tb = T * b
    max_Tb = Tb.max()
    exp_Tb = np.exp(Tb - max_Tb)
    w = exp_Tb / exp_Tb.sum()
    obj = (2.0 * n / T) * (max_Tb + np.log(exp_Tb.sum()))
    
    # Gradient: 4n * sum_k w_k * a[k-j] (for each j)
    # This is 4n * conv(w, flip_a)[n-1+n-1 : ...]
    # Actually same as before but with w instead of indicator
    # g[j] = 4n * sum_k w[k] * a[k-j]
    
    # Use FFT
    fft_size = 1 << (3*n - 2 - 1).bit_length()
    W = rfft(w, fft_size)
    FA = rfft(a[::-1], fft_size)
    conv_result = irfft(W * FA, fft_size)
    g = 4.0 * n * conv_result[n-1:2*n-1]
    
    # Convert to simplex tangent space
    # For softmax parameterization:
    S = np.dot(g, a)
    grad_z = a * (g - S)
    
    return obj, g, grad_z
```

Wait, I need to be careful about the factor. Let me re-derive.

f_T(a) = (2n/T) * log(sum_k exp(T * (a*a)_k))

∂f_T/∂a_j = (2n/T) * [1 / sum_k exp(T*b_k)] * sum_k exp(T*b_k) * T * ∂(a*a)_k/∂a_j

= (2n/T) * [1 / Z] * sum_k exp(T*b_k) * T * 2*a_{k-j}

= 2n * [1/Z] * sum_k exp(T*b_k) * 2*a_{k-j}

= 4n * sum_k w_k * a_{k-j}

where w_k = exp(T*b_k) / Z.

Yes, that's correct.

Now, for the L-BFGS optimization, I need to work in a parameterization where the constraints are automatically satisfied. The softmax parameterization is natural:
a = softmax(z), where z is unconstrained.

The gradient in z-space:
∂f_T/∂z_j = sum_i (∂f_T/∂a_i) * (∂a_i/∂z_j)
= sum_i g_i * a_i * (delta_{ij} - a_j)
= g_j * a_j - a_j * sum_i g_i * a_i
= a_j * (g_j - sum_i g_i * a_i)

So grad_z = a * (g - dot(g, a)).

This is what I had before. Good.

Now, for L-BFGS, I'll use scipy.optimize.minimize with the BFGS/L-BFGS-B method. The objective and gradient in z-space are:

obj(z) = f_T(softmax(z))
grad(z) = softmax(z) * (g(softmax(z)) - dot(g(softmax(z)), softmax(z)))

This should work well with L-BFGS.

The score is 2*n*max_b. For a "good" sequence at length n, max_b ≈ C/n where C depends on the quality. The score is ≈ 2C. The advantage of longer n is that the optimization is easier (more degrees of freedom), so we can potentially get a lower C.

Actually, let me reconsider the active set strategy. Instead of using a fixed fraction (e.g., 95%), I'll use an adaptive strategy:
- Start with a small active set (just the max).
- Gradually expand to include more constraints as the optimization progresses.
- This gives a "coarse to fine" approach that's fast initially and precise later.

Here's my final code:

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Fast Nesterov-accelerated subgradient with adaptive active set and FFT-based gradients
2. LogSumExp-smoothed L-BFGS optimization  
3. Multi-length exploration (interpolation to different n values)
4. LP-based final polish
Key: FFT-based subgradient computation enables millions of iterations in 1800s.
"""

import numpy as np
from scipy.fft import rfft, irfft
from scipy.optimize import minimize
import cvxpy as cp
import time


def fast_convolve(a):
    """Fast linear convolution via FFT."""
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def evaluate_safe(a):
    """Safely call evaluate_sequence."""
    try:
        a_list = [float(max(0.0, min(1000.0, x))) for x in a]
        if len(a_list) == 0:
            return float('inf')
        s = sum(a_list)
        if s < 0.01:
            return float('inf')
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')


def softmax_fn(z):
    """Stable softmax."""
    z_shifted = z - z.max()
    exp_z = np.exp(z_shifted)
    s = exp_z.sum()
    if s < 1e-300:
        return np.ones(len(z)) / len(z)
    return exp_z / s


def project_simplex(v):
    """Project onto probability simplex."""
    n = len(v)
    if v.sum() < 1e-15:
        return np.ones(n) / n
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho_arr = np.where(u * np.arange(1, n + 1) > (cssv - 1))[0]
    if len(rho_arr) == 0:
        return np.ones(n) / n
    rho = rho_arr[-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)


def compute_gradient_direct(a, active_indices):
    """Compute subgradient g[j] = 2/|A| * sum_{k in A} a[k-j] directly."""
    n = len(a)
    g = np.zeros(n)
    for k in active_indices:
        j_lo = max(0, k - n + 1)
        j_hi = min(n - 1, k)
        idx = np.arange(j_lo, j_hi + 1)
        m_start = k - j_hi
        m_end = k - j_lo
        g[idx] += 2.0 * a[m_start:m_end + 1][::-1]
    g /= len(active_indices)
    return g


def compute_gradient_fft(a, weights):
    """
    Compute gradient g[j] = 2 * sum_k weights[k] * a[k-j] via FFT.
    weights should be of length 2n-1.
    """
    n = len(a)
    total_w = weights.sum()
    if total_w < 1e-30:
        return np.zeros(n)
    w = weights / total_w  # normalize
    flip_a = a[::-1]
    conv_len = len(w) + n - 1
    fft_size = 1 << (conv_len - 1).bit_length()
    W = rfft(w, fft_size)
    FA = rfft(flip_a, fft_size)
    conv_result = irfft(W * FA, fft_size)
    g = 2.0 * conv_result[n - 1:2 * n - 1]
    return g


def nesterov_sg(a_init, budget, verbose=True):
    """
    Nesterov-accelerated subgradient with adaptive active set.
    Minimizes 2n * max_k (a*a)_k subject to a in simplex.
    """
    n = len(a_init)
    a = np.maximum(np.asarray(a_init, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    a = a / s

    best_a = a.copy()
    b = fast_convolve(a)
    best_score = 2.0 * n * b.max()
    lower_bound = 2.0 * n / (2.0 * n - 1.0)

    y = a.copy()
    a_prev = a.copy()
    t = 1.0
    t0 = time.monotonic()

    # Adaptive active set parameter (fraction of max)
    active_frac = 0.85
    last_progress = 0
    stagnant = 0

    for it in range(50000000):
        if time.monotonic() - t0 > budget:
            break

        # Compute subgradient at y
        b_y = fast_convolve(y)
        max_b = b_y.max()
        threshold = max_b * active_frac
        active = np.where(b_y >= threshold)[0]
        if len(active) == 0:
            active = np.array([int(np.argmax(b_y))])

        if len(active) < 50:
            g = compute_gradient_direct(y, active)
        else:
            w = np.zeros(2 * n - 1)
            w[active] = 1.0
            g = compute_gradient_fft(y, w)

        # Step size (Polyak)
        cur_score = 2.0 * n * max_b
        gap = cur_score - lower_bound
        if gap < 1e-10:
            break

        # Project gradient to tangent space of simplex
        g_mean = g.mean()
        g_tan = g - g_mean
        g_tan_sq = np.dot(g_tan, g_tan)
        if g_tan_sq < 1e-30:
            break
        eta = gap / g_tan_sq
        eta = min(eta, 5.0)

        # Projected gradient step
        a_new = project_simplex(y - eta * g)

        # Nesterov momentum
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t * t)) / 2.0
        y_new = a_new + ((t - 1.0) / t_new) * (a_new - a_prev)
        y_new = project_simplex(y_new)

        a_prev = a
        a = a_new
        y = y_new
        t = t_new

        # Evaluate
        sc = 2.0 * n * fast_convolve(a).max()
        if sc < best_score - 1e-10:
            best_score = sc
            best_a = a.copy()
            stagnant = 0
        else:
            stagnant += 1

        # Adaptive: expand active set when stagnant
        if stagnant > 3000:
            active_frac = min(0.999, active_frac * 1.02)
            stagnant = 0

        # Restart if very stagnant
        if stagnant > 20000:
            y = best_a.copy()
            a_prev = best_a.copy()
            a = best_a.copy()
            t = 1.0
            stagnant = 0
            active_frac = 0.85

        if verbose and (it + 1) % 20000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    NSG iter={it+1} ({elapsed:.0f}s): best={best_score:.8f} active_frac={active_frac:.4f}")

    return best_a, best_score


def lse_smooth_lbfgs(a_init, budget, verbose=True):
    """
    LogSumExp-smoothed L-BFGS optimization.
    Minimizes (2n/T) * log(sum exp(T*(a*a)_k)) with decreasing T.
    """
    n = len(a_init)
    a = np.maximum(np.asarray(a_init, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    a = a / s

    z = np.log(np.maximum(a, 1e-300))
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    t0 = time.monotonic()

    T = 50.0
    T_min = 0.5
    n_stages = 20

    for stage in range(n_stages):
        if time.monotonic() - t0 > budget:
            break
        remaining = budget - (time.monotonic() - t0)
        if remaining < 5:
            break

        def func(z_val):
            a_val = softmax_fn(z_val)
            b_val = fast_convolve(a_val)
            Tb_val = T * b_val
            max_Tb = Tb_val.max()
            exp_Tb = np.exp(Tb_val - max_Tb)
            return (2.0 * n / T) * (max_Tb + np.log(exp_Tb.sum()))

        def jac(z_val):
            a_val = softmax_fn(z_val)
            b_val = fast_convolve(a_val)
            Tb_val = T * b_val
            max_Tb = Tb_val.max()
            exp_Tb = np.exp(Tb_val - max_Tb)
            w = exp_Tb / exp_Tb.sum()
            # g = 4n * sum_k w_k * a[k-j]
            g = compute_gradient_fft(a_val, w) * (2.0 * n)
            # Wait, let me recheck. 
            # f_T = (2n/T) * log(sum exp(T*b_k))
            # df_T/da_j = (2n/T) * (1/Z) * sum_k exp(T*b_k) * T * 2*a_{k-j}
            # = 4n * sum_k w_k * a_{k-j}
            # compute_gradient_fft returns 2 * sum_k w_k * a[k-j]
            # So g = 2 * compute_gradient_fft(a_val, w) * 2n / 2 = ...
            # Let me just use compute_gradient_fft which gives 2*sum_k w_k*a[k-j]
            # and multiply by 2n:
            # Actually compute_gradient_fft gives: 2 * sum_k (w[k]/total_w) * a[k-j]
            # I want: 4n * sum_k w_k * a[k-j] where w_k = exp(T*b_k)/Z
            # So I need: 4n * sum_k w_k * a[k-j] = 2n * compute_gradient_fft(a_val, w)
            # where compute_gradient_fft normalizes w internally.
            # Wait, compute_gradient_fft does: w = weights / weights.sum()
            # So it returns 2 * sum_k (w[k]/sum(w)) * a[k-j]
            # If I pass w = exp(T*b), it returns 2 * sum_k w_k/Z * a[k-j]
            # I want 4n * sum_k w_k/Z * a[k-j]
            # So: g = 2n * compute_gradient_fft(a_val, exp_Tb)
            
            g = 2.0 * n * compute_gradient_fft(a_val, exp_Tb)
            S = np.dot(g, a_val)
            grad_z = a_val * (g - S)
            return grad_z

        try:
            res = minimize(
                fun=func, x0=z, jac=jac, method='L-BFGS-B',
                options={'maxiter': 50, 'ftol': 1e-20, 'gtol': 1e-12,
                         'maxfun': 2000, 'disp': False}
            )
            z = res.x
            a_new = softmax_fn(z)
            sc = 2.0 * n * fast_convolve(a_new).max()

            if sc < best_score:
                best_score = sc
                best_a = a_new.copy()

            if verbose and (stage + 1) % 5 == 0:
                elapsed = time.monotonic() - t0
                print(f"    LSE stage={stage+1}/{n_stages} T={T:.1f} ({elapsed:.0f}s): score={sc:.8f} best={best_score:.8f}")

            # Decrease temperature
            T = max(T_min, T * 0.7)

        except Exception as e:
            if verbose:
                print(f"    LSE stage {stage} error: {e}")
            T = max(T_min, T * 0.85)

    return best_a, best_score
