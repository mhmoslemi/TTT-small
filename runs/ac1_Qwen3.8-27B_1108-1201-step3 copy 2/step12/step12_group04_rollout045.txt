**Approach: Alternating Minimization / Game Theory**

The objective can be written as:
`f(a) = 2n * max_k C_k(a) / (sum a)^2`

where `C_k(a) = (a*a)[k]`.

By scale invariance, fix `sum(a) = 1`:
`f(a) = 2n * max_k C_k(a)`

This is equivalent to the value of the zero-sum game:
- Player 1 chooses a (probability distribution on {0,...,n-1})
- Player 2 chooses k (a lag)
- Payoff is C_k(a) = (a*a)[k]

The value of this game is `min_a max_k C_k(a)`.

The LP best-response approach:
- Fix a, find best response k* (the k that maximizes C_k(a))
- Fix k*, find best response a* (minimize C_k*(a) subject to sum(a)=1, a>=0)

The second step is: minimize `sum_i a[i]*a[k*-i]` subject to `sum a = 1, a >= 0`.

This is a QP! And for specific k*, it might be convex:
- If k* = 0: minimize a[0]^2 → optimal is a[0] = 0 (if allowed), spread rest equally.
- If k* is large (near 2n-2): similar.
- If k* = n-1: minimize a . a_rev. This is non-convex in general.
