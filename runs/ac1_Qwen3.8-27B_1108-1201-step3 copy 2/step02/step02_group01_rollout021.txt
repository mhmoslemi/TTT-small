  - If both (i.e., `j = k-j`, i.e., `k = 2j`): contributes `delta^2`

`conv[k] = sum_i a[i] * a[k-i]` where `0 <= i < n` and `0 <= k-i < n`.

If we change `a[j]` to `a[j] + delta`:
- Terms where `i = j`: `a[j]*a[k-j]` becomes `(a[j]+delta)*a[k-j]`, change is `delta*a[k-j]`
- Terms where `k-i = j`, i.e., `i = k-j`: `a[k-j]*a[j]` becomes `a[k-j]*(a[j]+delta)`, change is `a[k-j]*delta`
- If `j = k-j` (i.e., `k = 2j`): the term `a[j]*a[j]` becomes `(a[j]+delta)^2`, change is `2*a[j]*delta + delta^2`. But we already counted `delta*a[j]` twice, so the total change is `2*delta*a[j] + delta^2`.

So for `k != 2j`: change in `conv[k]` = `2*delta*a[k-j]` (if `0 <= k-j < n`, else 0)
For `k = 2j`: change in `conv[k]` = `2*delta*a[j] + delta^2`

This is a quadratic in delta. To minimize the max of all `conv[k]`, we'd want to find the delta that minimizes the maximum. This is a 1D minimax problem, solvable by bisection.

Let me also think about the target spectrum more carefully. The ideal flat autocorrelation `c[k] = C` for all `k = 0, ..., 2n-2` has DFT:
`C[f] = C * sum_{k=0}^{2n-2} exp(-2πikf/N) = C * exp(-πi f (2n-2)/N) * sin(πf(2n-1)/N) / sin(πf/N)`

So `|C[f]| = C * |sin(πf(2n-1)/N) / sin(πf/N)|`

And `|A[f]|^2 = C[f]` (for real a), so `|A[f]| = sqrt(C) * sqrt(|sin(πf(2n-1)/N) / sin(πf/N)|)`

Note that at f where `sin(πf/N) = 0` (i.e., f is a multiple of N), the expression is 2n-1 (by L'Hôpital). At f=0, `|A[0]| = sqrt(C) * sqrt(2n-1)`.

But wait, `|A[0]| = sum a` (the DC component, which is positive for non-negative a). And `C = (sum a)^2 / (2n-1)`. So `|A[0]| = sum a = sqrt(C * (2n-1))`. That's consistent.

So the target magnitude is:
`|A_target[f]| = (sum a) * sqrt(|sin(πf(2n-1)/N) / sin(πf/N)|) / sqrt(2n-1)`

This is the magnitude of the DTFT of a rectangular window of length 2n-1, scaled appropriately.

For the IFT algorithm, I'll use this as the target.

"""
Hybrid optimization for minimizing peak autocorrelation of non-negative sequences.
Uses IFT (Gerchberg-Saxton) with Dirichlet-kernel target spectrum as the primary
method, combined with LP blending and coordinate descent for polishing.
"""

import numpy as np
import time
from scipy.optimize import linprog


def fft_convolve(a, b):
    """Compute linear convolution using FFT."""
    n = len(a)
    m = len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:n + m - 1]


def local_score(a):
    """Compute the score 2*n*max(conv(a,a))/sum(a)^2."""
    a = np.clip(a, 0.0, 1000.0)
    n = len(a)
    sum_a = np.sum(a)
    if sum_a < 0.01:
        return np.inf
    conv = fft_convolve(a, a)
    return float(2.0 * n * np.max(conv) / (sum_a ** 2))


def normalize_seq(a, S=None):
    """Normalize sequence to have a given sum."""
    if S is None:
        S = np.sqrt(2.0 * len(a))
    s = np.sum(a)
    if s < 1e-12:
        return a * S / len(a)
    return a * S / s


def ift_optimize(a, time_limit, target='dirichlet', verbose=True):
    """
    IFT (Gerchberg-Saxton) optimization with Dirichlet kernel target spectrum.
    """
    n = len(a)
    N = 1
    while N < 2 * n - 1:
        N <<= 1
    
    # Compute target magnitude spectrum
    f = np.arange(N, dtype=np.float64)
    # Dirichlict kernel magnitude: |sin(pi*f*(2n-1)/N) / sin(pi*f/N)|
    target_mag = np.ones(N)
    num = np.sin(np.pi * f * (2*n-1) / N)
    den = np.sin(np.pi * f / N)
    # Handle zeros in denominator
    mask = np.abs(den) < 1e-15
    target_mag[~mask] = np.abs(num[~mask] / den[~mask])
    target_mag[mask] = 2*n - 1
    
    # Normalize target so that the DC component matches
    # |A[0]| = sum(a), and target_mag[0] = 2n-1
    # So scale: target_mag *= sum(a) / (2n-1)
    # Actually, since the score is scale-invariant, we can just use the shape
    # and normalize at the end
    
    best_a = np.abs(a).copy()
    best_score = local_score(best_a)
    
    a_current = np.abs(a).copy()
    t0 = time.monotonic()
    
    # Add small random perturbation to break symmetry
    a_current += 1e-6 * np.random.default_rng(42).standard_normal(n)
    a_current = np.maximum(a_current, 0)
    
    for iteration in range(100000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # FFT
        a_padded = np.zeros(N)
        a_padded[:n] = a_current
        A = np.fft.fft(a_padded)
        
        # Enforce target magnitude
        mag = np.abs(A)
        mag[mag < 1e-30] = 1e-30  # Avoid division by zero
        phase = A / mag
        A_new = target_mag * phase
        
        # Keep DC component real and positive
        A_new[0] = np.abs(A[0])
        
        # For real output, enforce Hermitian symmetry
        # Actually, if we start with real input and maintain Hermitian symmetry,
        # the output will be real. Let's enforce it explicitly.
        for i in range(1, N // 2 + 1):
            A_new[N - i] = np.conj(A_new[i])
        
        # IFFT
        a_new = np.fft.ifft(A_new).real[:n]
        
        # Project: non-negative
        a_new = np.maximum(a_new, 0)
        
        # Check score
        score = local_score(a_new)
        if score < best_score:
            best_score = score
            best_a = a_new.copy()
            if verbose and (iteration % 1000 == 0 or score < 1.55):
                print(f"    IFT iter {iteration}: score={best_score:.6f}")
        
        a_current = a_new
    
    return best_a


def build_lp_matrix(a):
    """Build the convolution constraint matrix A where (A@g)[k] = conv(a,g)[k]."""
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for k in range(2 * n - 1):
        j_min = max(0, k - n + 1)
        j_max = min(k, n - 1)
        for j in range(j_min, j_max + 1):
            A[k, j] = a[k - j]
    return A


def lp_solve(a, M):
    """
    Solve LP: maximize sum(g) subject to conv(a,g)[k] <= M for all k, g >= 0.
    """
    n = len(a)
    A = build_lp_matrix(a)
    c = -np.ones(n)
    res = linprog(c, A_ub=A, b_ub=np.full(2*n-1, M),
                  bounds=[(0, None)] * n, method='highs')
    if res.status == 0:
        return res.x
    return np.zeros(n)


def lp_refine(a, time_limit, verbose=True):
    """LP-based iterative refinement."""
    n = len(a)
    S = np.sqrt(2.0 * n)
    a = normalize_seq(a, S)
    t0 = time.monotonic()
    best_a = a.copy()
    best_score = local_score(a)
    
    for iteration in range(10000):
        if time.monotonic() - t0 > time_limit:
            break
        
        conv_a = fft_convolve(a, a)
        M = np.max(conv_a)
        
        g = lp_solve(a, M)
        g_sum = np.sum(g)
        if g_sum < 1e-10:
            break
        
        c = normalize_seq(g, S)
        
        # Find best blend parameter
        best_t = 0.0
        for t_try in [0.5, 0.3, 0.2, 0.15, 0.1, 0.05, 0.03, 0.01]:
            b = (1 - t_try) * a + t_try * c
            b = np.maximum(b, 0)
            b = normalize_seq(b, S)
            if local_score(b) < best_score:
                best_t = t_try
                best_score = local_score(b)
                best_a = b.copy()
                a = b
                break
        
        if best_t == 0.0:
            break
    
    return best_a


def coordinate_descent(a, time_limit, verbose=True):
    """
    Coordinate descent: update one element at a time to minimize the peak.
    """
    n = len(a)
    a = np.abs(a).copy()
    t0 = time.monotonic()
    best_a = a.copy()
    best_score = local_score(a)
    rng = np.random.default_rng(42)
    
    # Precompute which conv[k] are affected by each coordinate
    # conv[k] involves a[j] if 0 <= k-j < n, i.e., j in [k-n+1, k] ∩ [0, n-1]
    
    for iteration in range(1000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Pick a coordinate (cyclic or random)
        if iteration % n == 0:
            idx = int(np.argmax(fft_convolve(a, a)))  # Focus on peak
            j = rng.integers(0, n)
        else:
            j = iteration % n
        
        # Binary search for optimal delta for coordinate j
        # Current value: a[j]
        # New value: a[j] + delta, where delta can be positive or negative
        # But a[j] + delta >= 0
        
        # The peak conv value as a function of delta is:
        # conv[k](delta) = conv[k]_current + 2*delta*a[k-j] + delta^2*[k=2j] (with bounds)
        # We want to minimize max_k conv[k](delta)
        
        # Simple approach: try a few delta values
        a_j = a[j]
        best_delta = 0.0
        best_peak = np.max(fft_convolve(a, a))

        for frac in [0.5, 0.3, 0.1, 0.01, -0.5, -0.3, -0.1, -0.01]:
            delta = frac * a_j if a_j > 0 else frac
            if a_j + delta < 0:
                continue
            a_test = a.copy()
            a_test[j] = a_j + delta
            peak = np.max(fft_convolve(a_test, a_test))
            if peak < best_peak:
                best_peak = peak
                best_delta = delta
        
        if best_delta != 0:
            a[j] += best_delta
            a[j] = max(a[j], 0)
            score = local_score(a)
            if score < best_score:
                best_score = score
                best_a = a.copy()
                if verbose and iteration % 10000 == 0:
                    print(f"    CD iter {iteration}: score={best_score:.6f}")
    
    return best_a


def random_perturb_search(a, time_limit, verbose=True):
    """
    Random perturbation search with simulated annealing.
    """
    n = len(a)
    a = np.abs(a).copy()
    t0 = time.monotonic()
    best_a = a.copy()
    best_score = local_score(a)

    temperature = 0.1
    step = 0
    
    while time.monotonic() - t0 < time_limit:
        # Random perturbation
        candidate = a.copy()
        n_perturb = max(3, n // 10)
        idx = rng.choice(n, size=n_perturb, replace=False)
        candidate[idx] *= np.exp(rng.normal(0, 0.1, size=n_perturb))

        temperature *= 0.999

    return best_a
