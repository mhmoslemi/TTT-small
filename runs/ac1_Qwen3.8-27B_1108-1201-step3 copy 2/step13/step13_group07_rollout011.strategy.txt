# Approach and Rationale

The central idea is to develop a population-based search algorithm that iteratively improves candidate sequences to minimize the objective function `(2*n*max(convolve(a,a))) / (sum(a))^2`. We approach this by using guided local search components inspired by the previous program, but with a focus on efficient exploration through a fixed-length population and adaptive gradient-based weight updates.

Critically, we **deselect** all periodic components (`sin`, `arctan`, `Gaussian`) as they can overshoot the global optimum and introduce local minima. Instead, we maintain only the original parent sequence `height_sequence_1` across all generations, ensuring **progress continuity** without resetting the state.

We implement a **balanced search strategy** with explicit steps for:
- **Global optimization**: using simplified and efficient adaptations of the previous program's best components
- **Local refinement**: applying a gradient-based mutation that shields against catastrophic resets
- **Convergence criteria**: monitoring improvement rates and execution time

This approach addresses the original task's requirement for lower attacks but ensures robust performance.

# Mathematical Specification

The sequences are normalized non-negative real vectors `a` of fixed length `n = 1600` (matching the parent sequence supplied via `height_sequence_1`). The optimization targets minimizing `score = (2*n*M) / S²`, where `M = max(a*a)` and `S = sum(a)`.

**Key Components**:
- **Convolution**: uses FFT for efficient computation of the full convolution of length `2*n-1`
- **Gradient Update**: computes via the LogSumExp (LSE) smoothed gradient from `compute_lse_grad_a`
- **Projection**: uses `project_simplex` to maintain normalization after weight adjustments

## Implementation Procedure

1. **Security Checks and Initial Setup**
   - Verify that the input is a valid sequence list
   - Reject if empty (n < 1) sequences if not provided

2. **Parent Initialization**
   - Read `height_sequence_1` if available (always used as base)
   - Convert to float and normalize (clip handles zeros if any)

3. **Optimization Loop**
   - **Primary Objective**: Minimize `2*n*M / S²` using Adam/gradient-based search
   - **Gradient Calculation**: Use `fast_autocorr` to compute convolution and apply LSE smoothing to handle non-differentiable max operation
   - **Weight Updates**: Adjust each weight `a[i]` with a multiplicative factor derived from gradient, following normalization to simplex
   - **Convergence**: Implement cooldown periods and maximum iteration limits

4. **Final Validation**
   - Re-evaluate the best candidate using the original `evaluate_sequence`
   - Return with normalization maintained

## Search Space Handling

- **Fixed Length**: n=1600 maintains stability and allows better local search
- **Population Size**: 1 weights optimized each generation
- **Gradient Sampling**: Tracks number of distinct max peaks to balance exploration vs. exploitation

This setup leverages the previous program's foundations but streamlines the search process for faster convergence.
