Hmm, but the step size selection is crucial. If it's too large, the method diverges; if too small, it converges slowly.

For the LSE function `f_T(a) = T * log(sum exp(conv[k]/T))`, the Hessian is:
`∇²f_T = (1/T) * sum_k p_k * ∇²conv[k] - (1/T²) * sum_{k,k'} p_k * p_{k'} * ∇conv[k] * ∇conv[k']^T`

where `p_k = exp(conv[k]/T) / sum_j exp(conv[j]/T)`.

The first term has operator norm at most `(1/T) * max_k ||∇²conv[k]|| = 1/T` (since each ∇²conv[k] has norm 1).

The second term is PSD and has operator norm at most `(1/T²) * max_k ||∇conv[k]||^2 = (1/T²) * (2*max(a))^2`.

So the overall Lipschitz constant is at most `1/T + 4*max(a)^2/T^2`.

For T = 0.1 and max(a) ≈ sqrt(2n)/n ≈ sqrt(2/n) ≈ 0.035 (for n=1600):
L ≈ 10 + 4*0.0012/0.01 ≈ 10 + 0.5 ≈ 10.5

For T = 20 and max(a) ≈ 0.035:
L ≈ 0.05 + 4*0.0012/400 ≈ 0.05

So the step size should be about 1/L. For low T, it's about 0.1. For high T, it's about 20.

But this is a very rough bound. In practice, the effective Lipschitz constant is much smaller because:
1. The Hessian of conv[k] is a permutation-like matrix with singular values 1, but when combined with the weights p_k, the effective norm is smaller.
2. The second term (which could be negative) actually makes the function more "flat" in some directions.

A practical approach is to use a backtracking line search or an adaptive step size.

Actually, for FISTA, a common approach is to use the step size from the previous temperature stage (it should be similar). Or use a line search.

Let me think of an alternative: work in the "simplex" (sum = 1, a >= 0) and use a mirror descent / exponentiated gradient approach.

**Mirror Descent / Exponentiated Gradient:**

In the simplex, the natural mirror map is the negative entropy: `D(x || y) = sum x[i] * log(x[i]/y[i]) - sum x[i] + sum y[i]`.

The mirror descent update is:
`x_new[i] = x[i] * exp(-eta * grad[i]) / sum_j x[j] * exp(-eta * grad[j])`

This automatically maintains non-negativity and the sum constraint.

The step size eta can be chosen based on the Lipschitz constant. For Lipschitz L, eta = 1/L works.
