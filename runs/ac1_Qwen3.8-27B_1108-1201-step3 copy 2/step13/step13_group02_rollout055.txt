Let me think about the peak shaving more carefully:

For a peak at lag `k`, the contribution of element `j` is `a[j] * a[k-j]` (if both indices are valid). To reduce the peak, we want to decrease the sum of these contributions.

If we decrease `a[j]` by `delta`, the peak at lag `k` decreases by `delta * a[k-j]`. But `a[j]` also contributes to other peaks. The total "damage" from decreasing `a[j]` is the sum of its contributions to all above-threshold peaks.

So the "cost" of decreasing `a[j]` is `sum_{k in peaks} a[j] * a[k-j]` (approximately), and the "benefit" is the reduction in the maximum peak.

A good heuristic: find the element `j` with the highest ratio of "damage to max peak" / "total damage to all peaks". This is like a degree-centrality measure.

But computing this exactly is O(n * n_peaks) per step, which might be too slow. A simpler heuristic:
- For each peak `k`, find the element `j` with the largest `a[j] * a[k-j]` (the "dominant contributor")
- Among all peaks, pick the dominant contributor that appears most frequently (or with the largest total contribution)
- Reduce that element and add the mass to a "safe" element (one that doesn't contribute to any peak)

This is O(n * n_peaks) to compute, which for `n = 1600` and maybe 10-20 peaks is about 16000-32000 operations, fast enough.

**Let me also think about the "safe" elements.** An element `j` is "safe" if it doesn't contribute to any above-threshold peak. That is, for all peaks `k`, either `k-j < 0`, `k-j >= n`, or `a[k-j]` is very small.

In practice, an element is safe if `a[j] * max_k a[k-j] < threshold` for all valid `k`.

```python
            a_new = np.maximum(a_new, 0)
            a_new = normalize(a_new) * norm

        a = a_new
        
        # Track best
        for candidate in [y, a]:
            score = fast_autocorr(candidate).max()
            if score < best_score:
                best_score = score
                best_a = candidate.copy()
    
    return best_a, best_score
```

```python
def fast_projection(a, M, n_iters=100):
    """Simple iterative projection onto the constraint set."""
    n = len(a)
    b = a.copy()
    for _ in range(n_iters):
        # Find the most violated constraint
        circ = np.convolve(a, b)
        k_max = np.argmax(circ)
        violation = circ[k_max] - M
        if violation <= 0:
            break
        # Find the element of b that contributes most to this constraint
        js = max(0, k_max - n + 1)
        je = min(n - 1, k_max)
        idx = np.arange(js, je + 1)
        contrib = a[k_max - idx] * b[idx]
        j_max = idx[np.argmax(contrib)]
        # Reduce b[j_max]
        reduction = violation / max(a[k_max - j_max], 1e-15)
        b[j_max] = max(0, b[j_max] - reduction)
    return b
```
