min c^T x where x = [b, M], c = [0,...,0, 1]
A_ub @ x <= b_ub:
  T @ b - M * 1 <= 0  →  [T, -1] @ x <= 0
A_eq @ x = b_eq:
  [1...1, 0] @ x = 1
bounds: [(0, None)] * n + [(None, None)]  (M is unbounded below, but the constraints will bound it)

For scipy's HiGHS solver (default in recent scipy), this should be fast.

Let me benchmark mentally: n=1600, the LP has 1601 variables and ~3200 constraints. HiGHS should solve this in <10ms. That's much faster than cvxpy's typical 50-200ms per solve.
