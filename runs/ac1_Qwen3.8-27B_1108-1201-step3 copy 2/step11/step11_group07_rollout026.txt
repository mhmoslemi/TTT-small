1. A is in the range of the DFT restricted to zero-padded sequences (linear constraint)
2. The first n elements of IFFT(A) are non-negative
3. sum of first n elements of IFFT(A) = 1

- Fix A, update the "target" |A|^2 to be flatter (while maintaining the linear constraint)
- Fix the target, update A to match it (while maintaining non-negativity)

This is similar to the "Gerchberg-Saxton" or "error reduction" algorithm used in phase retrieval, but adapted for our purpose.

**Spectral optimization algorithm:**
1. Start with a (normalized, non-negative)
2. Repeat:

```python
import numpy as np
import time
from scipy.fft import rfft, irfft
from scipy.optimize import minimize

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]

def lse_obj_grad(a, T):
    """LSE-smoothed objective and gradient for probability vector a."""
    n = len(a)
    c = fast_convolve(a)
    c_max = c.max()
    exp_c = np.exp((c - c_max) / T)
    lse = c_max + T * np.log(exp_c.sum())
    obj = 2.0 * n * lse
    
    w = exp_c / exp_c.sum()
    
    # Gradient: 2 * (w cross-corr a)
    N = 1 << (len(w) + n - 1).bit_length()
    W = rfft(w, N)
    A = rfft(a, N)
    R = irfft(W * np.conj(A), N)
    g = 2.0 * R[:n]
    
    return obj, g

def softmax_from_z(z):
    z_shifted = z - z.max()
    exp_z = np.exp(z_shifted)
    s = exp_z.sum()
    if s < 1e-300:
        return np.ones(len(z)) / len(z)
    return exp_z / s

def z_from_a(a):
    return np.log(np.maximum(a, 1e-300))

def evaluate_local(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    a = a / s
    n = len(a)
    b = fast_convolve(a)
    return float(2.0 * n * b.max() / 1.0)  # sum=1 after normalization

def normalize(a):
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s
```

**Spectral reshaping algorithm:**
