```python
def project_simplex(v, s=1.0):
    """Project v onto {x >= 0, sum(x) = s}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - s))[0][-1]
    theta = (cssv[rho] - s) / (rho + 1.0)
    return np.maximum(v - theta, 0)
```

This is a set of quadratic inequality constraints, which is generally non-convex. However, we can relax it to a SDP (semidefinite program) by introducing the matrix X = a a^T:
- X is PSD
- X[i,j] = a[i]*a[j] (rank-1 constraint, which we relax to just PSD)
- sum(i) X[i,i] <= lambda for each k (the quadratic constraints become linear in X)
- sum(i,j) X[i,j] = 1 (from (sum a)^2 = 1)

This SDP relaxation gives a lower bound on the optimal value. But it's probably too expensive for n=1200.
