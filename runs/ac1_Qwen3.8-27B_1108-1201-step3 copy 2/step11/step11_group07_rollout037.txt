For large n, the lower bound is 2n/(2n-1) ≈ 2 - 1/n. So for n=1200, the lower bound is about 1.0008. But achieving it requires all conv[k] to be equal, which is impossible for non-negative sequences (since conv[0] = a[0]^2 and conv[2n-2] = a[n-1]^2 must also be small).

The question is: what's the achievable bound for large n?

I think the key is to make a[0] and a[n-1] very small (so that conv[0] and conv[2n-2] are small), while keeping the interior values such that the convolution is flat.

If a[0] ≈ 0 and a[n-1] ≈ 0, then conv[0] ≈ 0 and conv[2n-2] ≈ 0. The "effective" sequence is concentrated in the interior, and its convolution will be approximately the convolution of a "bump" function.

For a "bump" function (like a Gaussian or raised cosine), the convolution is also a bump, peaked at the center. So max(conv) is at the center.

To flatten the convolution, we need the sequence to have a "flat spectrum" in the interior. This is the key insight.

So the algorithm should be:
1. Start with a sequence that's zero (or near zero) at the edges and has a flat spectrum in the interior.
2. Iteratively refine to flatten the convolution.

This is essentially the "flat spectrum" design problem, which can be attacked with:
- Gerchberg-Saxton / error reduction in the frequency domain
- Gradient-based optimization of the convolution peak
- Convex optimization (but the problem is non-convex due to the max)

Let me think about the Gerchberg-Saxton approach:
1. Start with some initial a (e.g., a raised cosine that's zero at the edges).
2. Compute FFT of a (padded to length N >= 2n-1).
3. In frequency domain, replace |A[k]| with sqrt(mean(|A|^2)) (flat magnitude), keep phase.
4. Inverse FFT.
5. Clip to [0, ∞) and zero out the first and last few elements.
6. Normalize.
7. Repeat.

This should converge to a sequence with a nearly flat power spectrum, which means a nearly flat autocorrelation (and thus nearly flat convolution).

But there's a subtlety: we want the LINEAR convolution to be flat, not the circular autocorrelation. If N = 2n-1, they're the same. If N > 2n-1, there's a "wrap-around" issue.
