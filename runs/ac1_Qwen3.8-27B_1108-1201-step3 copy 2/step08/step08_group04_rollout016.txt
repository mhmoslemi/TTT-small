`grad[j] = dot(w[j:j+n], a)` for `j = 0, ..., n-1`

This is exactly what `sliding_window_view(w, n) @ a` computes.

Now, can I compute this efficiently via FFT? The matrix `M[j, m] = w[j+m]` is a Toeplitz matrix (constant along anti-diagonals). Computing `M @ a` is equivalent to a cross-correlation.

In fact, `grad[j] = sum_m M[j,m] * a[m] = sum_m w[j+m] * a[m]`.

If I define `a_rev[m] = a[n-1-m]`, then:
`grad[j] = sum_m w[j+m] * a_rev[n-1-m]`

Let `p = n-1-m`, so `m = n-1-p`:
`grad[j] = sum_p w[j+n-1-p] * a_rev[p]`

This is `correlate(w, a_rev)[j+n-1]` where `correlate(x, y)[k] = sum_p x[p+k] * y[p]`.

Or equivalently, `conv(w, a_rev)[j+n-1]` if we define `conv` appropriately.

Actually, `sum_p w[j+n-1-p] * a_rev[p]` is the convolution of `w` and `a_rev` at index `j+n-1`:
`conv(w, a_rev)[k] = sum_p w[p] * a_rev[k-p]`

At `k = j+n-1`: `sum_p w[p] * a_rev[j+n-1-p]`
Let `q = j+n-1-p`, so `p = j+n-1-q`:
`= sum_q w[j+n-1-q] * a_rev[q]`

Yes! This matches. So `grad[j] = conv(w, a_rev)[j+n-1]`.

Now let me verify with the example:
`a = [1, 2, 3]`, `a_rev = [3, 2, 1]`
`w = [10, 20, 30, 40, 50]`

`conv(w, a_rev)[k] = sum_p w[p] * a_rev[k-p]`

`conv[2] = w[0]*a_rev[2] + w[1]*a_rev[1] + w[2]*a_rev[0] = 10*1 + 20*2 + 30*3 = 140` ✓
`conv[3] = w[0]*a_rev[3] + w[1]*a_rev[2] + w[2]*a_rev[1] + w[3]*a_rev[0]`
But `a_rev` has length 3, so `a_rev[3]` is out of bounds (= 0).
`= 0 + 20*1 + 30*2 + 40*3 = 20+60+120 = 200` ✓
`conv[4] = w[2]*a_rev[2] + w[3]*a_rev[1] + w[4]*a_rev[0] = 30*1 + 40*2 + 50*3 = 250` ✓

So the formula works: `grad = conv(w, a_rev)[n-1 : 2n-1]`

And we can compute the full convolution via FFT:
```python
def compute_grad(a, w):
    n = len(a)
    a_rev = a[::-1]
    fft_size = 1 << (len(w) + len(a_rev) - 1).bit_length()
    W = rfft(w, fft_size)
    A_rev = rfft(a_rev, fft_size)
    conv = irfft(W * A_rev, fft_size)
    return conv[n-1:2*n-1]
```

Let me verify the output length: `conv` has length `fft_size`, and we take indices `n-1` to `2n-2` inclusive, which is `n` elements. ✓

Now I have a clean, fast O(n log n) gradient computation. Let me put it all together.

Here's my complete algorithm plan:

1. **Fast auto-convolution** via FFT
2. **Fast gradient** via FFT (as derived above)
3. **Subgradient optimization** with:
   - Softmax smoothing (adaptive temperature)
   - Nesterov momentum
   - Projection onto simplex (or exponential mapping for mirror descent)
   - Adaptive step size (backtracking or diminishing)
4. **Coordinate descent polish**
5. **Multi-scale / multi-n exploration**
6. **Random restarts**

Let me also think about the mirror descent variant. Instead of Euclidean projection onto the simplex, I can use:
`a_i <- a_i * exp(-eta * grad_i) / sum_j a_j * exp(-eta * grad_j)`

This is the multiplicative weight update, which is the mirror descent step with the negative entropy as the regularizer. It naturally maintains non-negativity and can be more effective when the solution has many small entries.

I'll implement both and choose the better one adaptively.

"""
Optimized subgradient + mirror descent + coordinate descent for minimizing
2*n*max(convolve(a,a))/(sum(a))^2.

Key innovations over previous LP-based approach:
1. FFT-based gradient computation (O(n log n) per step vs LP solve)
2. Nesterov-accelerated subgradient with adaptive step size
3. Mirror descent (multiplicative weight updates) as alternative
4. Two-phase strategy: coarse optimization then fine polish
5. Multiple n values with transfer initialization
6. Coordinate descent with paired updates
"""

import numpy as np
from scipy.fft import rfft, irfft
import time


def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def softmax_weights(b, tau):
    """Compute softmax(b * tau) with numerical stability."""
    m = b.max()
    shifted = tau * (b - m)
    exp_s = np.exp(shifted)
    s = exp_s.sum()
    if s < 1e-300:
        w = np.zeros(len(b))
        w[np.argmax(b)] = 1.0
        return w
    return exp_s / s


def compute_grad(a, w):
    """Compute grad[j] = sum_m w[j+m] * a[m] for j=0..n-1 via FFT."""
    n = len(a)
    a_rev = a[::-1]
    total_len = len(w) + len(a_rev) - 1
    fft_size = 1 << (total_len - 1).bit_length()
    W = rfft(w, fft_size)
    A_rev = rfft(a_rev, fft_size)
    conv = irfft(W * A_rev, fft_size)
    return conv[n-1:2*n-1]


def project_simplex(v, target_sum=1.0):
    """Euclidean projection onto {x >= 0, sum(x) = target_sum}."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)]) * target_sum
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.arange(1, n + 1)
    cond = u * rho > (cssv - target_sum)
    if not cond.any():
        return np.full(n, target_sum / n)
    rho_val = np.nonzero(cond)[0][-1]
    theta = (cssv[rho_val] - target_sum) / (rho_val + 1.0)
    return np.maximum(v - theta, 0.0)


def mirror_descent_step(a, grad, eta):
    """Multiplicative weight update: a_i <- a_i * exp(-eta * grad_i), normalized."""
    log_a = np.log(np.maximum(a, 1e-300))
    log_a_new = log_a - eta * grad
    # Shift for numerical stability
    log_a_new -= log_a_new.max()
    a_new = np.exp(log_a_new)
    s = a_new.sum()
    if s < 1e-300:
        return a.copy()
    return a_new / s


def subgradient_optimize(a_init, time_limit, method='projected', tau_init=5.0,
                         tau_max=200.0, eta_init=0.05, momentum=0.7,
                         label="sg"):
    """
    Subgradient optimization with Nesterov momentum.
    method: 'projected' (Euclidean projection) or 'mirror' (multiplicative)
    """
    t0 = time.monotonic()
    n = len(a_init)
    a = a_init.copy()
    s = a.sum()
    if s > 1e-15:
        a = a / s
    
    # Nesterov state
    a_prev = a.copy()
    
    best_a = a.copy()
    b = fast_convolve(a)
    best_obj = b.max()
    no_improve = 0
    
    tau = tau_init
    eta = eta_init
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        b = fast_convolve(a)
        M = b.max()
        
        # Softmax weights
        w = softmax_weights(b, tau)
        
        # Gradient
        grad = compute_grad(a, w)
        # Normalize gradient (optional, for step size tuning)
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-30:
            break
        
        # Nesterov acceleration
        if it == 1:
            a_nest = a.copy()
        else:
            beta = (1.0 + np.sqrt(1.0 + 4.0 * (it-1)**2 * eta**2)) / (2.0 * eta)  # This is getting complicated
            # Simpler: use fixed momentum
            a_nest = a + momentum * (a - a_prev)
        
        # Clip to non-negative for gradient evaluation
        a_nest = np.maximum(a_nest, 0.0)
        s_nest = a_nest.sum()
        if s_nest > 1e-15:
            a_nest = a_nest / s_nest
            # Recompute gradient at Nesterov point
            b_nest = fast_convolve(a_nest)
            w_nest = softmax_weights(b_nest, tau)
            grad = compute_grad(a_nest, w_nest)
        
        # Update
        if method == 'mirror':
            a_new = mirror_descent_step(a, grad, eta)
        else:
            a_new = a - eta * grad
            a_new = project_simplex(a_new)
        
        a_prev = a.copy()
        a = a_new
        
        # Evaluate
        new_obj = fast_convolve(a).max()
        
        if new_obj < best_obj - 1e-15:
            best_obj = new_obj
            best_a = a.copy()
            no_improve = 0
            # Slightly increase step size
            eta = min(eta * 1.01, 0.5)
        else:
            no_improve += 1
            if no_improve % 20 == 0:
                eta *= 0.9
            if no_improve > 100:
                # Restart from best
                a = best_a + np.random.default_rng(it).standard_normal(n) * 0.001
                a = np.maximum(a, 0)
                a = a / a.sum()
                a_prev = a.copy()
                no_improve = 0
                eta = eta_init * 0.5
        
        # Adaptive tau: increase to sharpen (more "peaky" gradient)
        if it % 50 == 0:
            tau = min(tau * 1.05, tau_max)
        
        if it % 200 == 0:
            elapsed = time.monotonic() - t0
            score = 2.0 * n * best_obj
            print(f"    {label} it={it} obj={best_obj:.10f} score={score:.6f} "
                  f"tau={tau:.1f} eta={eta:.5f} t={elapsed:.0f}s")
    
    return best_a, 2.0 * n * best_obj


def coordinate_descent(f_init, time_limit, multipliers_factor=10):
    """Coordinate descent: for each coordinate, try multiple values."""
    t0 = time.monotonic()
    n = len(f_init)
    f = f_init.copy()
    best_obj = fast_convolve(f).max()
    best_score = 2.0 * n * best_obj
    best_f = f.copy()
    
    # Multipliers to try at each coordinate
    multipliers = np.array([0.3, 0.5, 0.7, 0.8, 1.0, 1.2, 1.5, 2.0, 3.0])
    
    no_pass = 0
    while time.monotonic() - t0 < time_limit and no_pass < 3:
        any_improved = False
        for j in range(0, n, max(1, n // 500)):  # Skip some for speed
            if time.monotonic() - t0 > time_limit:
                break
            if f[j] < 1e-15:
                continue
            
            best_j_val = f[j]
            best_j_obj = best_obj
            
            for mult in multipliers:
                factor = time.monotonic() - t0
                if factor > time_limit:
                    break
                new_val = f[j] * mult
                f_trial = f.copy()
                f_trial[j] = new_val
                s = f_trial.sum()
                if s < 1e-12:
                    continue
                f_trial = f_trial / s
                obj = fast_convolve(f_trial).max()
                if obj < best_j_obj - 1e-13:
                    best_j_obj = obj
                    best_j_val = new_val
            
            if best_j_val != f[j]:
                f[j] = best_j_val
                s = f.sum()
                f = f / s
                if best_j_obj < best_obj - 1e-13:
                    best_obj = best_j_obj
                    best_score = 2.0 * n * best_obj
                    best_f = f.copy()
                    any_improved = True
        
        if not any_improved:
            no_pass += 1
        else:
            no_pass = 0
    
    return best_f, best_score


def random_restart_search(a_init, time_limit, n_restarts=10, perturbation=0.01):
    """Try random perturbations around best point."""
    t0 = time.monotonic()
    n = len(a_init)
    best_a = a_init.copy()
    b = fast_convolve(best_a)
    best_obj = b.max()
    rng = np.random.default_rng(12345)
    
    per_restart = time_limit / n_restarts
    
    for r in range(n_restarts):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Perturb
        a = best_a + rng.standard_normal(n) * perturbation
        a = np.maximum(a, 0)
        a = a / a.sum()
        
        # Quick optimization (few iterations)
        a, score = subgradient_optimize(
            a, time_limit=per_restart, tau_init=20, tau_max=100,
            eta_init=0.02, momentum=0.5, label=f"rr{r}")
        
        if 2.0 * n * fast_convolve(a).max() < best_obj * 2.0 * n:
            obj = fast_convolve(a).max()
            if obj < best_obj:
                best_obj = obj
                best_a = a.copy()
    
    return best_a, 2.0 * n * best_obj
