    """Solve dual LP: min M * sum(y) s.t. C^T y >= 1, y >= 0
    Returns y (the constraint weights) and the optimal value."""
    n = len(f)
    # C is (2n-1) x n, C[k,j] = f[k-j] if valid
    # Dual: min M * sum(y_k) s.t. sum_k C[k,j] * y_k >= 1 for all j, y >= 0
    # C^T y >= 1 means: for each j, sum_k f[k-j] * y_k >= 1
    # This is equivalent to: (f_reversed * y)_j >= 1 for all j

The most promising local method is L-BFGS on the smoothed objective. The key is to choose the right temperature T. Too high and we're optimizing the wrong thing; too low and the function is too non-smooth.

For the original score `s = 2n * max(b_k) / S^2`, with S=1, we minimize `2n * max(b_k)`. The smoothed version is `2n * T * log(sum exp(b_k/T))`. The gap between the smoothed and exact is approximately `T * log(K)` where K is the number of "active" peaks. So for a gap of 0.001, we need `T * log(K) < 0.001`. If K ≈ 10 (10 active peaks), then T < 0.001/log(10) ≈ 0.0004. That's very small, meaning the smoothing is very tight and L-BFGS might struggle.

Alternative: use a "top-k" approximation. Instead of the full softmax, use a "top-k softmax" that only considers the k largest values. This makes the function more "linear" and easier to optimize.

Or: use the "exact" max but with a subgradient + momentum approach. The subgradient of `max(b_k)` at the active peak k* is `db_{k*}/da = [a_{k*-j}]_j`. With momentum, this should converge linearly.
