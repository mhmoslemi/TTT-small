    c_step = fast_conv(step)
    obj_step = softmax_from_c(c_step, T)

This is 2 FFTs per successful line search step (one for the initial c, one for each trial). With 10 max trials, that's up to 11 FFTs per gradient step. For n=2400, each FFT takes about 0.5ms, so 5.5ms per gradient step. That gives about 180 gradient steps per second. Over 1000 seconds, that's 180,000 steps. Should be plenty.

Actually, I can be smarter: instead of full backtracking, I can use a "fixed step with occasional line search" approach:
- Most of the time, use a fixed step size
- If the objective increases, do a few line search steps to recover

This is more efficient. Let me implement this.

Or even simpler: since the softmax objective is smooth and the step size can be tuned, I can use a fixed step size per T value and just run for a fixed number of iterations. If things diverge, reduce eta.
