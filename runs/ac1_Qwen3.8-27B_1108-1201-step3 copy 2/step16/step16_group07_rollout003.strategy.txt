# Approach and Rationale
The core idea is to use a combination of gradient-based optimization and coordinate-wise updates to find a sequence that minimizes the autocorrelation score. We build upon the original solution by:
1. Using dual-guided gradient optimization as the primary search method
2. Implementing active-set reduction to focus on influential subproblems only
3. Adding temperature scaling to balance exploration and exploitation
4. Maintaining multiple temporal representations for better gradient estimation
5. Using iterative reweighting based on dual variables to ensure convergence

The objective is the score: 2*n*max(conv(a))/ (sum(a))^2, where conv(a) is a full linear convolution and sum(a) is maintained at √(2n) through normalization. The solution will iteratively search for the best sequence by:
- Computing gradients using the subgradient method
- Leveraging dual variables to guide the search
- Maintaining a temperature parameter to control greediness
- Restricting updates to segments that will impact the maximum convolution

# Mathematical Specification
We represent the sequence `a` of length `n` as a vector of coefficients in [0, ∞) with the sum enforced to be exactly √(2n). 

The autocorrelation convolution is defined for indices 0 ≤ k ≤ 2n-2 as:
max_b = max_{0≤k≤2n-2} |a * a][k]|
score = (2n * max_b) / (sum_a)^2 = (2n * max_b) / (2n) = max_b   [denominator is always 2n because we normalize]

Note: The normalization factor is √(2n), so the sum in denominator is (√(2n))^2 = 2n.

The optimization approach uses:
- Subgradient computation for the L1 or L2 norm functions
- Stochastic selection of active segments based on gradient impact
- Cross-validation between unperturbed and perturbed candidates
