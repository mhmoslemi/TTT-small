```python
        # Actually: d/d(a[i]) sum_{i'+j'=k} a[i']*a[j'] = a[k-i] (if 0 <= k-i < n)
        # Because the derivative of a[i']*a[k-i'] w.r.t. a[i] is:
        #   if i' = i: a[k-i]
        #   if k-i' = i, i.e., i' = k-i: a[i]
        # So d(conv[k])/d(a[i]) = a[k-i] + (a[i] if i != k-i else 0)
        # Wait, that's for the case i ≠ k-i.
        # More carefully: conv[k] = sum_{i'=0}^{min(k,n-1)} a[i'] * a[k-i'] (with a[j]=0 for j outside [0,n-1])
        # d(conv[k])/d(a[i]) = sum of terms involving a[i]:
        #   Term where i' = i: a[k-i] (if 0 <= k-i < n)
        #   Term where k-i' = i, i.e., i' = k-i: a[i'] = a[k-i] (if 0 <= k-i < n and k-i != i)
        #   If i = k-i, i.e., 2i = k: only one term, derivative is a[i]
        # So: d(conv[k])/d(a[i]) = a[k-i] if 0 <= k-i < n, plus a[i] if 2i = k and 0 <= k-i < n and i != k-i
        # Simplified: d(conv[k])/d(a[i]) = a[k-i] * (1 + [2i == k]) for 0 <= k-i < n
        # Wait no. Let me be more careful.
        # conv[k] = sum_{i'=max(0,k-n+1)}^{min(k,n-1)} a[i'] * a[k-i']
        # d(conv[k])/d(a[i]) = a[k-i] (if k-i is in valid range for the second index)
        #                       + a[i] (if i is in valid range for the first index AND i != k-i)
        # Actually, the cleanest way: conv[k] is quadratic in a, specifically:
        # conv[k] = a^T B_k a where (B_k)_{i,j} = 1 if i+j=k (and i,j valid), else 0
        # Since B_k is symmetric (B_k[i,j] = 1 iff i+j=k, and j+i=k means B_k[j,i]=1),
        # d(conv[k])/d(a) = 2 * B_k * a
        # (B_k * a)[i] = sum_j B_k[i,j] * a[j] = a[k-i] (if 0 <= k-i < n, else 0)
        # So d(conv[k])/d(a[i]) = 2 * a[k-i] (if 0 <= k-i < n, else 0)
        # BUT WAIT - this is for the quadratic form a^T B a. Let me verify.
        # a^T B a = sum_{i,j} a[i] B[i,j] a[j] = sum_{i+j=k} a[i] a[j] = conv[k] ✓
        # d/d(a[i]) (a^T B a) = (B + B^T) a [i] = 2 B a [i] (since B is symmetric)
        # (Ba)[i] = sum_j B[i,j] a[j] = a[k-i] (if valid)
        # So d(conv[k])/d(a[i]) = 2 * a[k-i] (if 0 <= k-i < n, else 0)
        
        if 0 <= k_int - i and i < n:  # This should be done per i
            pass
    
    # Redo: for each top lag, add its gradient contribution
    for w, k_idx in zip(weights, top_idx):
        k_int = int(k_idx)
        for i in range(n):
            j = k_int - i
            if 0 <= j < n:
                grad[i] += 2.0 * w * a[j]
    
    return grad
```

Hmm, this is getting complicated and slow for n=2400. Let me think of a more efficient approach.

Actually, the gradient computation can be done efficiently using convolution:
- grad[i] = sum_k w_k * 2 * a[k-i] (for valid k-i)
- This is 2 * (w_reversed * a) where * denotes convolution and w_reversed is the weight sequence reversed

Let me reformulate:
grad = 2 * convolve(weights_padded, a) where weights_padded has w_k at position k

Actually, let's define:
w_ext = np.zeros(2*n-1)
w_ext[top_idx] = weights

Then grad[i] = 2 * sum_k w_ext[k] * a[k-i] (for valid k-i)
            = 2 * (w_ext flipped, convolved with a)[some_offset]

Hmm, this is getting complex. Let me just use the direct approach but vectorize it:

For each top lag k:
- The valid i values are: max(0, k-n+1) to min(n-1, k)
- For those i, a[k-i] gives the gradient contribution

So:
```python
grad = np.zeros(n)
for w, k_int in zip(weights, top_idx):
    i_start = max(0, k_int - n + 1)
    i_end = min(n, k_int + 1)
    idx = np.arange(i_start, i_end)
    j_idx = k_int - idx
    grad[idx] += 2.0 * w * a[j_idx]
```

This is O(n * top_k) per iteration, which for n=2400 and top_k=20 is about 48000 operations per lag - very fast.

OK let me design the full algorithm:

**Algorithm: Adaptive Peak-Flattening Optimizer**

1. Initialize from parent (or structured init)
2. Work in log-parameter space: θ, where a = softmax(θ)
3. Use Adam optimizer
4. Objective: smoothed max of top-K convolution lags
5. Periodically:
   - Try to equalize the top lags (add small bias to lags below the max)
   - Do local coordinate moves
   - Restart with perturbation if stuck

Let me also consider: since the improvement needed is small, maybe I should focus on:
1. A very careful local optimization around the parent
2. Trying different n values (the parent is n=2400)
3. Using the LP approach more aggressively (it's exact for the subproblem)

Actually, re-reading the previous code, it already tries multi-length exploration. Let me focus on making the core optimization better.

Key insight: The previous approach used mirror descent (multiplicative updates in log-space). I'll use Adam instead, which adapts per-coordinate learning rates. This should be more effective for the non-smooth objective.

Another key insight: Instead of just reducing the max, I should try to EQUALIZE the top peaks. At the optimum, all active constraints should be tight (by KKT conditions). So the optimal solution has several lags all at the same maximum value.

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using Adam-based optimization in log-space
with peak equalization heuristics and adaptive restarts.
"""
import numpy as np
import time

def fast_conv(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a.astype(np.float64), fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def norm_sum1(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s

def evaluate_safe(a):
    try:
        a_list = [float(x) for x in a]
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')

def compute_grad_topk(a, conv, top_k=30, beta=100.0):
    """Compute gradient of smoothed max of top-k lags."""
    n = len(a)
    actual_k = min(top_k, len(conv))
    top_idx = np.argpartition(conv, -actual_k)[-actual_k:]
    top_vals = conv[top_idx]
    max_val = top_vals.max()
    # Softmax weights (temperature-controlled)
    exp_vals = np.exp(beta * (top_vals - max_val))
    weights = exp_vals / exp_vals.sum()
    
    grad = np.zeros(n)
    for w, k_int in zip(weights, top_idx.astype(int)):
        i_start = max(0, k_int - n + 1)
        i_end = min(n, k_int + 1)
        if i_start >= i_end:
            continue
        idx = np.arange(i_start, i_end)
        j_idx = k_int - idx
        grad[idx] += 2.0 * w * a[j_idx]
    
    return grad, top_idx, weights, top_vals

def adam_step(theta, grad_theta, m, v, t, lr=0.01, beta1=0.9, beta2=0.999, eps=1e-8):
    """Adam optimizer step."""
    m = beta1 * m + (1 - beta1) * grad_theta
    v = beta2 * v + (1 - beta2) * grad_theta ** 2
    m_hat = m / (1 - beta1 ** t)
    v_hat = v / (1 - beta2 ** t)
    theta_new = theta - lr * m_hat / (np.sqrt(v_hat) + eps)
    return theta_new, m, v

def interpolate_seq(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss

def adam_optimize(a0, time_limit, top_k=30, beta_init=50.0, beta_end=500.0,
                  lr=0.02, verbose=True, rng_seed=42):
    """
    Adam-based optimization in log-space with increasing beta (sharpening).
    """
    n = len(a0)
    a = norm_sum1(a0)
    theta = np.log(np.maximum(a, 1e-30))
    # Center theta
    theta = theta - theta.mean()
    
    conv = fast_conv(a)
    best_a = a.copy()
    best_max = conv.max()
    t0 = time.monotonic()
    rng = np.random.default_rng(rng_seed)
    
    m = np.zeros(n)
    v = np.zeros(n)
    t = 0
    stall_count = 0
    max_stall = 2000
    
    while time.monotonic() - t0 < time_limit:
        t += 1
        progress = min((time.monotonic() - t0) / time_limit, 1.0)
        
        # Animate beta from beta_init to beta_end
        beta = beta_init + (beta_end - beta_init) * progress
        
        a = norm_sum1(np.exp(theta - theta.max()))
        conv = fast_conv(a)
        curr_max = conv.max()
        
        if curr_max < best_max - 1e-15:
            best_max = curr_max
            best_a = a.copy()
            stall_count = 0
        else:
            stall_count += 1
        
        # Compute gradient in a-space, then transform to theta-space
        grad_a, top_idx, weights, top_vals = compute_grad_topk(a, conv, top_k, beta)
        # da/d(theta[i]) = a[i] * (1 - a[i]) (for softmax)
        # But we're using a = exp(theta)/sum(exp(theta)) parameterization
        # d(a[i])/d(theta[j]) = a[i]*(delta_ij - a[j])
        # grad_theta[i] = sum_j grad_a[j] * d(a[j])/d(theta[i])
        #                = sum_j grad_a[j] * a[j]*(delta_ji - a[i])
        #                = grad_a[i]*a[i] - a[i]*sum_j grad_a[j]*a[j]
        grad_theta = grad_a * a - a * np.dot(grad_a, a)
        
        # Adam step
        lr_t = lr / (1 + 0.1 * np.sqrt(t / 1000))  # Slight decay
        theta, m, v = adam_step(theta, grad_theta, m, v, t, lr_t)
        
        # Restart if stuck
        if stall_count > max_stall:
            stall_count = 0
            # Perturb in theta-space
            noise = rng.normal(0, 0.01, n)
            theta = np.log(np.maximum(best_a, 1e-30)) - np.log(np.maximum(best_a, 1e-30)).mean() + noise
            m = np.zeros(n)
            v = np.zeros(n)
            # Slightly reduce beta for exploration
            if beta > beta_init * 2:
                beta = max(beta_init, beta * 0.8)
            if verbose:
                elapsed = time.monotonic() - t0
                J = 2.0 * n * best_max
                print(f"    Adam restart ({elapsed:.1f}s): J={J:.6f}, beta={beta:.1f}")
        
        if verbose and t % 500 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_max
            print(f"    Adam t={t} ({elapsed:.1f}s): J={J:.6f}, beta={beta:.1f}, stall={stall_count}")
    
    return best_a, best_max

def peak_equalization(a0, time_limit, verbose=True, rng_seed=7):
    """
    Try to equalize the top peaks by transferring mass between positions
    that affect different peak lags.
    """
    n = len(a0)
    a = norm_sum1(a0)
    conv = fast_conv(a)
    best_a = a.copy()
    best_max = conv.max()
    t0 = time.monotonic()
    rng = np.random.default_rng(rng_seed)
    
    stall = 0
    max_stall = 100
    
    while time.monotonic() - t0 < time_limit and stall < max_stall:
        conv = fast_conv(a)
        curr_max = conv.max()
        
        # Get top lags
        top_k = min(10, len(conv)-1)
        top_idx = np.argsort(conv)[::-1][:top_k]
        top_vals = conv[top_idx]
        
        # For each pair of top lags, try to reduce the higher one
        improved = False
        for i in range(min(len(top_idx), 8)):
            if time.monotonic() - t0 > time_limit:
                break
            k1 = int(top_idx[i])
            v1 = conv[k1]
            if v1 < best_max * 0.95:  # Only work on significant peaks
                continue
            
            for j in range(i+1, min(len(top_idx), 8)):
                k2 = int(top_idx[j])
                v2 = conv[k2]
                
                if v1 <= v2:
                    continue  # Already k1 <= k2
                
                # Find positions that contribute to k1 but not k2 (or vice versa)
                # Positions contributing to conv[k1]: i where 0 <= k1-i < n
                # Positions contributing to conv[k2]: i where 0 <= k2-i < n
                
                # Try to reduce contribution to k1 by moving mass from a position
                # that's important for k1 but not for k2
                i_start1 = max(0, k1 - n + 1)
                i_end1 = min(n, k1 + 1)
                i_start2 = max(0, k2 - n + 1)
                i_end2 = min(n, k2 + 1)
                
                # Positions in k1's range but not k2's
                exclusive1 = set(range(i_start1, i_end1)) - set(range(i_start2, i_end2))
                if len(exclusive1) == 0:
                    continue
                
                # Find the position in exclusive1 with highest a[i] * a[k1-i]
                best_pos = -1
                best_contrib = 0
                for pos in exclusive1:
                    contrib = a[pos] * a[k1 - pos]
                    if contrib > best_contrib:
                        best_contrib = contrib
                        best_pos = pos
                
                if best_pos < 0 or best_contrib < 1e-20:
                    continue
                
                # Try moving mass from best_pos to a random position
                for frac in [0.001, 0.003, 0.005, 0.01]:
                    amt = a[best_pos] * frac
                    if amt < 1e-20:
                        continue
                    dst = int(rng.integers(n))
                    if dst == best_pos:
                        continue
                    a_trial = a.copy()
                    a_trial[best_pos] -= amt
                    a_trial[dst] += amt
                    a_trial = np.maximum(a_trial, 0)
                    s = a_trial.sum()
                    if s < 1e-15:
                        continue
                    a_trial = a_trial / s
                    conv_trial = fast_conv(a_trial)
                    max_trial = conv_trial.max()
                    if max_trial < best_max - 1e-15:
                        a = a_trial
                        best_max = max_trial
                        best_a = a.copy()
                        improved = True
                        break
            
            if improved:
                stall = 0
                break
        
        if not improved:
            stall += 1
            # Larger perturbation
            n_perturb = max(5, n // 200)
            for _ in range(n_perturb):
                i = int(rng.integers(n))
                j = int(rng.integers(n))
                if i != j and a[i] > 1e-10:
                    frac = rng.uniform(0.005, 0.02)
                    amt = a[i] * frac
                    a[i] -= amt
                    a[j] += amt
                    a = np.maximum(a, 0)
                    if a.sum() > 1e-15:
                        a = a / a.sum()
                        max_new = fast_conv(a).max()
                        if max_new < best_max:
                            best_max = max_new
                            best_a = a.copy()
                            stall = 0
                            improved = True
                        else:
                            a[i] += amt
                            a[j] -= amt
                            a = np.maximum(a, 0)
                            if a.sum() > 1e-15:
                                a = a / a.sum()
        
        if verbose and stall % 30 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_max
            print(f"    PE ({elapsed:.1f}s): J={J:.6f}, stall={stall}")
    
    return best_a, best_max

def local_search(a0, time_limit, verbose=True, rng_seed=13):
    """
    Coordinate descent with smart move selection.
    Focus on positions that are "hot" (contribute to peak lags).
    """
    n = len(a0)
    a = norm_sum1(a0)
    conv = fast_conv(a)
    best_a = a.copy()
    best_max = conv.max()
    t0 = time.monotonic()
    rng = np.random.default_rng(rng_seed)
    
    stall = 0
    max_stall = 200
    
    while time.monotonic() - t0 < time_limit and stall < max_stall:
        conv = fast_conv(a)
        curr_max = conv.max()
        
        top_k = min(10, len(conv)-1)
        top_idx = np.argsort(conv)[::-1][:top_k]
        
        # Build "hot" set: positions involved in top lags
        hot = set()
        for k in top_idx:
            k_int = int(k)
            i_start = max(0, k_int - n + 1)
            i_end = min(n, k_int + 1)
            for i in range(i_start, i_end):
                hot.add(i)
                j = k_int - i
                if 0 <= j < n:
                    hot.add(j)
        
        # Try moves: reduce a hot position, increase a cold position
        hot_list = list(hot)
        cold_list = [i for i in range(n) if i not in hot]
        
        if len(cold_list) == 0:
            cold_list = list(range(n))
        
        rng.shuffle(hot_list)
        n_hot_try = min(len(hot_list), 20)
        
        improved = False
        for src in hot_list[:n_hot_try]:
            if time.monotonic() - t0 > time_limit:
                break
            if a[src] < 1e-12:
                continue
            
            # Pick a few cold destinations
            n_cold_try = min(len(cold_list), 10)
            cold_sample = rng.choice(cold_list, size=n_cold_try, replace=False) if len(cold_list) > n_cold_try else np.array(cold_list)
            
            for dst in cold_sample:
                if dst == src:
                    continue
                for frac in [0.001, 0.003, 0.01, 0.02]:
                    amt = a[src] * frac
                    if amt < 1e-15:
                        continue
                    a_trial = a.copy()
                    a_trial[src] -= amt
                    a_trial[dst] += amt
                    a_trial = np.maximum(a_trial, 0)
                    s = a_trial.sum()
                    if s < 1e-15:
                        continue
                    a_trial = a_trial / s
                    max_trial = fast_conv(a_trial).max()
                    if max_trial < best_max - 1e-15:
                        a = a_trial
                        best_max = max_trial
                        best_a = a.copy()
                        improved = True
                        break
                if improved:
                    break
            if improved:
                stall = 0
                break
        
        if not improved:
            stall += 1
            # Random escape
            i = int(rng.integers(n))
            j = int(rng.integers(n))
            if i != j and a[i] > 1e-10:
                amt = a[i] * rng.uniform(0.01, 0.05)
                a[i] -= amt
                a[j] += amt
                a = np.maximum(a, 0)
                if a.sum() > 1e-15:
                    a = a / a.sum()
                    max_new = fast_conv(a).max()
                    if max_new < best_max:
                        best_max = max_new
                        best_a = a.copy()
                        stall = 0
                    else:
                        a[i] += amt
                        a[j] -= amt
                        a = np.maximum(a, 0)
                        if a.sum() > 1e-15:
                            a = a / a.sum()
        
        if verbose and stall % 50 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_max
            print(f"    LS ({elapsed:.1f}s): J={J:.6f}, stall={stall}")
    
    return best_a, best_max
```

The key issue with my Adam approach: I'm working in log-space (theta), and the gradient transformation from a-space to theta-space involves the softmax Jacobian. This can be numerically unstable.

Alternative: work directly in a-space with projection. At each step:
1. Compute gradient in a-space
2. Take a step: a_new = a - lr * grad
3. Project: a_new = max(a_new, 0), then normalize to sum = 1

This is simpler and avoids the log-space issues. But it's less effective for maintaining non-negativity.

Actually, let me use a different approach: work in a-space with "entropy-regularized" steps. At each step:
1. Compute gradient g in a-space
2. Update: a_new[i] = a[i] * exp(-lr * g[i]) (mirror descent / multiplicative update)
3. Normalize: a_new = a_new / sum(a_new)
4. Clip: a_new = max(a_new, 0)
5. Re-normalize

This is the mirror descent approach but with a different step size schedule.

Key insight: The previous code used a FIXED step size schedule (eta = c / sqrt(t) * sqrt(n)). I can use ADAPTIVE step sizes based on the actual gradient magnitude and the improvement.

Let me also think about a completely different approach: **SQP (Sequential Quadratic Programming)**.

At each iteration:
1. Linearize the objective: max_k (conv + dconv/dk * delta) where delta is the step
2. Solve a QP: minimize t subject to dconv_k/dk * delta + conv_k - t ≤ 0 for all top k, sum(delta) = 0, a + delta ≥ 0
3. Take a step in the direction delta

This is essentially a linearized approach. For n=2400, the QP has 2400 variables + 1 (t) and about 10-50 constraints (top lags). This is very tractable!

Actually, this is very similar to the LP-based Frank-Wolfe approach in the previous code, but using QP instead of LP, and with a proper line search.

Let me think about this more carefully:

The problem is:
minimize max_k f_k(a) = max_k (a^T B_k a)
subject to a ≥ 0, sum(a) = 1

At the current point a, the active constraints are the top lags. Let S be the set of active lags.

The KKT conditions at the optimum (assuming all active constraints are binding):
- For each k in S: f_k(a*) = M*
- There exist multipliers λ_k ≥ 0 for k in S such that:
  2 * sum_{k in S} λ_k * B_k * a* + ν * 1 - μ = 0 (where ν is for sum constraint, μ for non-negativity)
  (complementary slackness: μ_i = 0 if a*_i > 0)

This suggests that at the optimum, the "effective gradient" (weighted sum of B_k * a for active k) should be constant across all positive components.

This gives us a direction for optimization: adjust a so that the effective gradient becomes more uniform.

Let me implement a QP-based approach:

```python
def qp_step(a, conv, top_k=10, solver='ECOS'):
    """
    Compute a QP step to reduce the max of top-k lags.
    """
    import cvxpy as cp
    
    n = len(a)
    actual_k = min(top_k, len(conv)-1)
    top_idx = np.argsort(conv)[::-1][:actual_k]
    
    # Variable: delta (change to a), with sum(delta) = 0, a + delta >= 0
    delta = cp.Variable(n)
    t = cp.Variable()
    
    constraints = [
        cp.sum(delta) == 0,
        a + delta >= 0
    ]
    
    # Linearize: f_k(a + delta) ≈ f_k(a) + 2*(B_k * a) @ delta
    # = conv[k] + 2 * sum_i (B_k * a)[i] * delta[i]
    # We want: conv[k] + 2*(B_k*a) @ delta <= t for all top k
    for k_int in top_idx:
        # d(f_k)/d(a)[i] = 2 * a[k-i] (if valid)
        grad_k = np.zeros(n)
        i_start = max(0, k_int - n + 1)
        i_end = min(n, k_int + 1)
        idx = np.arange(i_start, i_end)
        j_idx = k_int - idx
        grad_k[idx] = 2.0 * a[j_idx]
        
        constraints.append(conv[k_int] + grad_k @ delta <= t)
    
    # Objective: minimize t
    prob = cp.Problem(cp.Minimize(t), constraints)
    prob.solve(solver=solver, verbose=False)
    
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None
    
    delta_val = np.asarray(delta.value, dtype=np.float64)
    return delta_val
```

This QP has n+1 variables and about top_k + 2 constraints. For n=2400 and top_k=10, this is very fast to solve (well under 1 second with CLBABEL or ECOS).

The key advantage of this approach:
1. It's exact (not approximate like subgradient methods)
2. It directly targets the active constraints
3. It naturally handles the non-negativity constraint
4. It's a proper optimization step (not just a heuristic)
