def compute_subgradient_fft(a, w):
    """Compute g[j] = 2 * sum_m a[m] * w[j+m] using FFT."""
    n = len(a)
    # w has length 2n-1
    # We need: g[j] = 2 * sum_{m=0}^{n-1} a[m] * w[j+m] for j=0..n-1
    # (w[j+m] = 0 if j+m >= 2n-1)
    
    # Use the formula: g[j] = 2 * conv(w_flipped, a)[(2n-2) - j + (n-1)] ... 
    # Actually from our derivation: g[j] = 2 * full_conv[n-1 : 2n-1][::-1][j]
    # where full_conv = conv(w_flipped, a)
    
    w_flipped = w[::-1]  # length 2n-1
    # Linear convolution of w_flipped (len 2n-1) and a (len n): result length 3n-2
    fft_size = 1 << (3*n-1).bit_length()
    W = np.fft.rfft(w_flipped, fft_size)
    A = np.fft.rfft(a, fft_size)
    full_conv = np.fft.irfft(W * A, fft_size)[:3*n-2]
    
    # g[j] = 2 * full_conv[(2n-1)-1-j + ... ] 
    # From our verification: g[j] = full_conv[n-1 : 2n-1][::-1][j]
    # = full_conv[2n-2-j]
    g = 2.0 * full_conv[2*n-2 - np.arange(n)]
    return g

    """Compute H @ v where H[j,l] = w[j+l] (Hankel matrix)."""

For the CD, the key insight is: for a given coordinate i, the objective as a function of a[i] = x is:
max_k [C_k + d_k * x + e_k * x^2]

where C_k, d_k are precomputed (independent of x) and e_k is 0 or 1.

The breakpoints (where the argmax changes) are at:
C_i + d_i * x + e_i * x^2 = C_j + d_j * x + e_j * x^2
=> (d_i - d_j) * x + (e_i - e_j) * x^2 = C_j - C_i

This is a quadratic (or linear) equation in x, giving at most 2 breakpoints per pair (i,j).

With n=2400, there are O(n^2) pairs, giving O(n^2) breakpoints. This is too many to enumerate.

Instead, I'll use a "practical" approach:
1. At the current x = a[i], find the active set A = {k: f_k(x) is within ε of max}
2. The active set defines a "piece" of the max function
3. Within this piece, the objective is max_{k in A} [C_k + d_k * x + e_k * x^2]
4. Minimize this over x >= 0 (subject to the active set remaining valid)
5. The minimum is either at a breakpoint, at x=0, or at the minimum of one of the active quadratics

For step 4, if all e_k in the active set are 0 (no x^2 terms), the objective is max of linear functions, and the minimum is at a breakpoint (intersection of two lines).

If some e_k = 1 (x^2 terms present), it's more complex.

In practice, for most coordinates, the active set is small (a few lags), and the 1D optimization is fast.
