def lp_best_response(a_fixed, M, active_set, solver):
    n = len(a_fixed)
    k_indices = np.asarray(active_set)
    size = len(k_indices)
    
    T = np.zeros((size, n))
    for idx in range(size):
        k = int(k_indices[idx])
        lo = max(0, k - n + 1)
        hi = min(n, k + 1)
        if lo < hi:
            T[idx, lo:hi] = a_fixed[k - np.arange(lo, hi)]
    
    b_var = cp.Variable(n, nonneg=True)
    constraints = [T @ b_var <= M]
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        return None
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None
    b_val = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
    if b_val.sum() < 1e-15:
        return None
    return b_val

```python
delta = x - aj
a[j] = x
conv[j:j+n] += 2.0 * delta * a[0:n]
conv[2*j] -= delta * delta
```

This is O(n) per coordinate update.

Now, for the score computation: after changing a[j] to x, the sum becomes `norm + delta` (since we were at sum=norm). The normalized score is:
`max(conv_new) * (norm / (norm + delta))^2`

Where `conv_new` is the updated convolution (before renormalization).

Wait, I need to be more careful. The original sequence has sum = norm = sqrt(2n). After changing a[j] to x, the new sum is `norm - aj + x = norm + delta`.

To renormalize: multiply all entries by `norm / (norm + delta)`.
The convolution of the renormalized sequence is `(norm/(norm+delta))^2 * conv_new`.
The max of this is `(norm/(norm+delta))^2 * max(conv_new)`.

So the score is: `(norm/(norm+delta))^2 * max(conv_new)`.

And `max(conv_new) = max(max(conv_new affected), max(conv_new unaffected))`.

The unaffected part is `conv` at indices not in [j, j+n-1].
The affected part is `conv[j:j+n]` after the update.

So:
```python
M_unaffected = np.max(conv with [j:j+n] zeroed out)  # or pre-computed
M_affected = np.max(conv[j:j+n])  # after update
M_new = max(M_unaffected, M_affected)
score = (norm / (norm + delta))**2 * M_new
```

For efficiency, I can precompute `M_unaffected` for each j. But it changes as we update other coordinates. So I'll just compute it on the fly:
```python
M_unaffected = np.max(np.concatenate([conv[:j], conv[j+n:]])) if j > 0 or j+n < 2*n-1 else 0
```

This is O(n) per coordinate. With the update also being O(n), total per coordinate is O(n). For all n coordinates, one pass is O(n^2). For n=1600, that's 2.56M operations per pass. Very fast!

With the grid of 25-30 x values per coordinate, it's O(n^2 * G) per pass = 2.56M * 30 ≈ 77M per pass. Still fast (maybe 1-2 seconds per pass in Python due to overhead).
