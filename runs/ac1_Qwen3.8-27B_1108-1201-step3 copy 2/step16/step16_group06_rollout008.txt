The inner LP: max 1'b s.t. (y*b)[i] <= M, b >= 0

The multiplicative weights algorithm for this packing LP:

The standard MW algorithm for packing LPs works as follows:
- Primal: max 1'p s.t. Ap <= b, 0 <= p <= u
- Dual: min b'y s.t. A'y >= 1, y >= 0

For our case: A = T (the constraint matrix), b = M * 1, u is unbounded (or we can set u = 1).

The MW algorithm:
1. Initialize p = alpha * 1/n (for some alpha)
2. At each iteration:
   a. Compute Ap (constraint values)
   b. Find the most violated constraint: i* = argmax (Ap)_i / b_i
   c. Update: p_j *= (1 - eta * A[i*, j] / b_i*)
      (or a softer version: p_j *= exp(-eta * sum_i y_i * A[i,j]))
3. Return p / sum(p)

The soft version (using all constraints weighted by their violation) is better:
p_j *= exp(-eta * sum_i (Ap)_i/b_i * A[i,j])
      = exp(-eta * sum_i (y*b)[i]/M * y[j] * 1[j<=i<=j+n-1])

The sum can be computed efficiently:
sum_i (y*b)[i]/M * y[j] * 1[j<=i<=j+n-1]
= y[j]/M * sum_{i=j}^{j+n-1} (y*b)[i]

So we need: for each j, S_j = sum_{i=j}^{min(j+n-1, 2n-2)} (y*b)[i]

This is a sliding window sum! We can compute it in O(n) using cumsum.

    """
    Solve: max sum(b) s.t. (y*b)[i] <= M, b >= 0
    using multiplicative weights.
    Returns b normalized to sum 1.
    """
    n = len(y)
    b = np.ones(n) / n
    v = fast_conv(y, b)  # (y*b)[i], length 2n-1
    
    for t in range(n_iters):
        # Compute excess
        excess = np.maximum(v / M - 1.0, 0.0)
        if excess.max() < 1e-10:
            break
        
        # Compute S_j = sum_{i=j}^{min(j+n-1, 2n-2)} excess[i]
        # Using cumsum
        cum = np.zeros(len(excess) + 1)
        cum[1:] = np.cumsum(excess)
        S = np.zeros(n)
        for j in range(n):
            i_end = min(j + n, len(excess))
            S[j] = cum[i_end] - cum[j]
        
        # Update: b_j *= exp(-eta * y[j] * S[j] / M)
        # Wait, the constraint is (y*b)[i] <= M, and the coefficient of b_j in constraint i is y[j] if j<=i<=j+n-1.
        # So the "pressure" on b_j is: sum_i excess_i * y[j] * 1[j<=i<=j+n-1] = y[j] * S_j
        # Update: b_j *= exp(-eta * y[j] * S_j / M)
        
        log_update = -eta * y * S / M
        log_update = np.clip(log_update, -50, 0)
        b = b * np.exp(log_update)
        b = np.maximum(b, 1e-30)
        s = b.sum()
        b = b / s
        
        # Update v = y * b
        v = fast_conv(y, b)
    
    return b
