In radar/communications, this is the "minimum PSL sequence design" problem. For complex sequences, optimal PSK sequences are well-studied. For non-negative real sequences, it's less studied but related.

The key algorithms for sequence design are:

Let me think about an algorithm:

**Adaptive Magnitude Sequence Design (AMSD):**
1. Start with a random non-negative sequence (or the parent)
2. Compute autocorrelation c = a * a
3. Find the peak sidelobe: k* = argmax_{k≠0} c[k]
4. For each position j, compute the "sensitivity" of c[k*] to a[j]:
   dc[k*]/da[j] = 2*a[k*-j] (for valid j)
5. We want to decrease a[j] where it contributes a lot to c[k*], and increase a[j] where it contributes little
6. But we also need to keep other sidelobes low and keep (a*a)[0] reasonable

This is similar to what the previous code does, but let me think about how to make it more effective.

**Key improvement idea: Use a "weighted" PSL objective**

Instead of just minimizing the maximum sidelobe, minimize a weighted sum of the top few sidelobes. This gives a smoother optimization landscape and allows simultaneous reduction of multiple peaks.

Specifically: min sum_k w_k * c[k] where w_k = exp(beta * c[k]) / sum_m exp(beta * c[m]) (softmax weights).

As beta → ∞, this approaches min max_k c[k]. For finite beta, it's a smooth approximation that's easier to optimize.

The gradient of this objective w.r.t. a[j] is:
sum_k w_k * dc[k]/da[j] = sum_k w_k * 2*a[k-j] (for valid k,j)

This is a weighted sum of shifted versions of a, which can be computed efficiently.

**Algorithm:**
1. Initialize a (from parent or random)
2. Repeat:
   a. Compute c = a * a (via FFT)
   b. Compute softmax weights: w_k = softmax(beta * c[k])
   c. Compute gradient: g[j] = 2 * sum_k w_k * a[k-j] (via FFT cross-correlation)
   d. Update: a = a - eta * g (with projection to a >= 0 and sum = 1)
   e. Optionally: adjust beta (increase it over time)

The key advantage over the previous approach:
- The gradient is computed via FFT (O(n log n)) instead of explicit loops
- The softmax weights focus optimization on the most important peaks
- We can use Adam for adaptive step sizing

Let me also think about the "projection" step. After the gradient step, we need:
- a >= 0
- sum(a) = 1 (normalization)

For the sum constraint, we can just normalize at the end. For the non-negativity, we clip to 0.

But this can cause issues (mass concentration at a few points). A better approach is to use the softmax parameterization:
a[j] = exp(w[j]) / sum(exp(w))

Then the gradient w.r.t. w is:
dw[j] = g[j] * a[j] - a[j] * sum_k g[k] * a[k]
= a[j] * (g[j] - sum_l a[l]*g[l])

This automatically ensures a > 0 and sum(a) = 1.

"""

import numpy as np
import time
import cvxpy as cp

_global_solver = None


def get_solver():
    global _global_solver
    if _global_solver is not None:
        return _global_solver
    for s in [cp.CLARABEL, cp.ECOS, cp.PDLP, cp.SCS]:
        try:
            x = cp.Variable(4, nonneg=True)
            prob = cp.Problem(cp.Minimize(cp.sum(x)), [cp.sum(x) == 1, x <= 0.4])
            prob.solve(solver=s)
            if prob.status in ('optimal', 'optimal_inaccurate'):
                _global_solver = s
                print(f"  LP solver: {s}")
                return s
        except Exception:
            continue
    _global_solver = cp.ECOS
    print("  LP solver (fallback): ECOS")
    return _global_solver


def fast_conv(a):
    """Compute full linear convolution a*a via FFT."""
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def smooth_max_grad(a, beta):
    """
    Compute gradient of log-sum-exp(beta * (a*a)) w.r.t. a using FFT.
    Returns (grad, c, M) where c = a*a, M = max(c).
    """
    n = len(a)
    c = fast_conv(a)
    c_shifted = c - c.max()
    weights = np.exp(beta * c_shifted)
    w_sum = weights.sum()
    if w_sum < 1e-300:
        weights = np.zeros(len(c))
        weights[int(np.argmax(c))] = 1.0
    else:
        weights /= w_sum

    # grad[j] = 2 * sum_k weights[k] * a[k-j] = 2 * (weights cross-correlate a)[j]
    N = 1 << (2 * n - 1).bit_length()
    Wf = np.fft.rfft(weights, N)
    Af = np.fft.rfft(a, N)
    h = np.fft.irfft(np.conj(Wf) * Af, N)
    grad = 2.0 * h[:n]
    return grad, c, c.max()


def eval_score(a):
    """Compute the score directly (fast, no function call overhead)."""
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    c = fast_conv(a)
    return float(2.0 * n * c.max() / (s * s))


def normalize(a):
    """Ensure a >= 0 and sum(a) = 1."""
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / len(a)
    return a / s


def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss


def adam_logspace(a0, time_limit, beta_start=5.0, beta_end=80.0,
                  lr=0.05, seed=42, verbose=True, max_iters=500000):
    """
    Adam optimizer in log-space with adaptive smooth-max objective.
    Works with w = log(a), so a = softmax(w).
    """
    n = len(a0)
    a = normalize(np.asarray(a0, dtype=np.float64))
    # Avoid log(0): add small epsilon
    a_safe = np.maximum(a, 1e-10)
    a_safe = a_safe / a_safe.sum()
    w = np.log(a_safe)
    w -= w.max()  # center for numerical stability

    best_a = a.copy()
    best_score = eval_score(a)
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)

    # Adam state
    m = np.zeros(n)
    v = np.zeros(n)
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8

    stall = 0
    stall_patience = 2000
    total_iters = 0

    for t in range(1, max_iters + 1):
        if time.monotonic() - t0 > time_limit:
            break
        total_iters = t

        # Adaptive beta: ramp up from beta_start to beta_end
        progress = min(1.0, t / (max_iters * 0.7))
        current_beta = beta_start + (beta_end - beta_start) * progress

        # Compute gradient in a-space
        a_curr = np.exp(w - w.max())
        a_curr = a_curr / a_curr.sum()
        grad_a, c, M = smooth_max_grad(a_curr, current_beta)

        # Gradient in w-space: grad_w[j] = a[j] * (grad_a[j] - sum(a*grad_a))
        mean_grad = np.dot(a_curr, grad_a)
        grad_w = a_curr * (grad_a - mean_grad)

        # Adam update
        m = beta1 * m + (1 - beta1) * grad_w
        v = beta2 * v + (1 - beta2) * (grad_w ** 2)
        m_hat = m / (1 - beta1 ** t)
        v_hat = v / (1 - beta2 ** t)
        w -= lr * m_hat / (np.sqrt(v_hat) + eps)

        # Convert back to a-space
        a_new = np.exp(w - w.max())
        a_new = a_new / a_new.sum()

        # Check improvement
        s_new = eval_score(a_new)
        if s_new < best_score - 1e-10:
            best_score = s_new
            best_a = a_new.copy()
            stall = 0
        else:
            stall += 1

        # Periodic restart if stuck
        if stall > stall_patience:
            # Try a perturbation
            w_perturb = w + rng.normal(0, 0.01, n)
            a_perturb = np.exp(w_perturb - w_perturb.max())
            a_perturb = a_perturb / a_perturb.sum()
            s_perturb = eval_score(a_perturb)
            if s_perturb < best_score:
                best_score = s_perturb
                best_a = a_perturb.copy()
                w = w_perturb
                m = np.zeros(n)
                v = np.zeros(n)
            else:
                # Larger restart
                w_restart = np.log(np.maximum(best_a, 1e-10))
                w_restart -= w_restart.max()
                w = w_restart + rng.normal(0, 0.02, n)
                m = np.zeros(n)
                v = np.zeros(n)
            stall = 0

        if verbose and t % 5000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    Adam t={t} ({elapsed:.1f}s): score={best_score:.6f}, beta={current_beta:.1f}, stall={stall}")

    return best_a, best_score


def lp_direction(a, M):
    """
    Solve the LP: max sum(b) s.t. (a*b)[k] <= M for all k, b >= 0.
    Returns the optimal b (normalized) or None.
    """
    n = len(a)
    solver = get_solver()

    # Build constraint matrix T: T[k, j] = a[k-j] if 0 <= k-j < n
    T = np.zeros((2 * n - 1, n))
    for j in range(n):
        T[j:j + n, j] = a

    b_var = cp.Variable(n, nonneg=True)
    constraints = [T @ b_var <= M]
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        return None
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None

    b_val = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
    b_sum = b_val.sum()
    if b_sum < 1e-15:
        return None
    return b_val / b_sum


def lp_frank_wolfe(a0, time_limit, verbose=True, max_iters=200):
    """LP-based Frank-Wolfe with Nesterov acceleration."""
    n = len(a0)
    y = normalize(np.asarray(a0, dtype=np.float64))
    best_a = y.copy()
    best_score = eval_score(y)
    t0 = time.monotonic()

    x_mom = y.copy()

    for t in range(1, max_iters + 1):
        if time.monotonic() - t0 > time_limit:
            break

        c = fast_conv(y)
        M = c.max()
        if M < 1e-15:
            break

        b_dir = lp_direction(y, M)
        if b_dir is None:
            break

        # Line search
        best_alpha = 2.0 / (t + 2.0)
        best_trial_score = float('inf')
        for alpha in [best_alpha, 0.5, 0.4, 0.3, 0.2, 0.15, 0.1, 0.05]:
            trial = (1.0 - alpha) * y + alpha * b_dir
            trial = normalize(trial)
            sc = eval_score(trial)
            if sc < best_trial_score:
                best_trial_score = sc
                best_alpha = alpha

        y_new = (1.0 - best_alpha) * y + best_alpha * b_dir
        y_new = normalize(y_new)

        # Nesterov momentum
        if t == 1:
            x_new = y_new.copy()
        else:
            beta_t = (t - 1.0) / (t + 2.0)
            x_new = y_new + beta_t * (y_new - y)
            x_new = normalize(x_new)

        y = y_new
        x_mom = x_new

        sc_y = eval_score(y)
        if sc_y < best_score:
            best_score = sc_y
            best_a = y.copy()
        sc_x = eval_score(x_mom)
        if sc_x < best_score:
            best_score = sc_x
            best_a = x_mom.copy()

        if verbose and t % 5 == 0:
            elapsed = time.monotonic() - t0
            print(f"    LP-FW iter={t} ({elapsed:.1f}s): score={best_score:.6f}")

    return best_a, best_score


def coordinate_polish(a0, time_limit, verbose=True, seed=42):
    """Aggressive coordinate descent with multi-fraction moves."""
    n = len(a0)
    a = normalize(np.asarray(a0, dtype=np.float64))
    best_a = a.copy()
    best_score = eval_score(a)
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)

    stall = 0
    max_stall = 100
    fractions = [0.001, 0.002, 0.005, 0.01, 0.02, 0.05, 0.1, 0.2]

    while time.monotonic() - t0 < time_limit and stall < max_stall:
        c = fast_conv(a)
        M = c.max()
        # Find top peaks
        top_k = min(20, len(c))
        peak_indices = np.argsort(c)[::-1][:top_k]

        improved = False

        for k_idx in peak_indices[:10]:
            if time.monotonic() - t0 > time_limit:
                break
            k = int(k_idx)
            # Find positions contributing to this peak
            i_start = max(0, k - n + 1)
            i_end = min(n, k + 1)
            idx = np.arange(i_start, i_end)
            contrib = a[idx] * a[k - idx]
            total_contrib = contrib.sum()
            if total_contrib < 1e-20:
                continue

            # Source: position with highest contribution
            src = idx[np.argmax(contrib)]

            # Find best destination: position with low contribution to all top peaks
            in_peak_mask = np.zeros(n, dtype=bool)
            for k2 in peak_indices[:8]:
                s2 = max(0, int(k2) - n + 1)
                e2 = min(n, int(k2) + 1)
                in_peak_mask[s2:e2] = True

            # Score each potential destination
            dest_scores = np.zeros(n)
            for k2 in peak_indices[:5]:
                k2_int = int(k2)
                s2 = max(0, k2_int - n + 1)
                e2 = min(n, k2_int + 1)
                for j in range(s2, e2):
                    dest_scores[j] += a[j] * a[k2_int - j]

            # Prefer destinations outside peaks with low score
            candidates = np.argsort(dest_scores)[:min(500, n)]
            candidates = candidates[candidates != src]

            found = False
            for dst in candidates[:100]:
                if found:
                    break
                for frac in fractions:
                    amt = a[src] * frac
                    if amt < 1e-15:
                        continue
                    a_trial = a.copy()
                    a_trial[src] -= amt
                    a_trial[dst] += amt
                    a_trial = np.maximum(a_trial, 0.0)
                    st = a_trial.sum()
                    if st < 1e-15:
                        continue
                    a_trial = a_trial / st
                    sc = eval_score(a_trial)
                    if sc < best_score - 1e-12:
                        a = a_trial
                        best_score = sc
                        best_a = a.copy()
                        improved = True
                        found = True
                        break

        if not improved:
            stall += 1
            # Random perturbation to escape
            if stall > 20:
                i = int(rng.integers(n))
                j = int(rng.integers(n))
                if i != j and a[i] > 1e-8:
                    frac = rng.uniform(0.01, 0.05)
                    amt = a[i] * frac
                    a[i] -= amt
                    a[j] += amt
                    a = np.maximum(a, 0.0)
                    a = a / a.sum()
                    sc = eval_score(a)
                    if sc < best_score:
                        best_score = sc
                        best_a = a.copy()
                        stall = 0
                    else:
                        a[i] += amt
                        a[j] -= amt
                        a = a / a.sum()

        if verbose and stall % 10 == 0:
            elapsed = time.monotonic() - t0
            print(f"    Coord ({elapsed:.1f}s): score={best_score:.6f}, stall={stall}")

    return best_a, best_score


def fine_coordinate_polish(a0, time_limit, verbose=True, seed=99):
    """Very fine coordinate descent sweeping all source-peak pairs."""
    n = len(a0)
    a = normalize(np.asarray(a0, dtype=np.float64))
    best_a = a.copy()
    best_score = eval_score(a)
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)

    fractions = [0.0005, 0.001, 0.002, 0.003, 0.005, 0.008, 0.012, 0.02, 0.035, 0.06]
    sweep_count = 0

    while time.monotonic() - t0 < time_limit:
        c = fast_conv(a)
        M = c.max()
        top_peaks = np.argsort(c)[::-1][:min(15, len(c))]

        improved_this_sweep = False
        sweep_count += 1

        for k_idx in top_peaks[:8]:
            if time.monotonic() - t0 > time_limit:
                break
            k = int(k_idx)
            i_start = max(0, k - n + 1)
            i_end = min(n, k + 1)
            idx = np.arange(i_start, i_end)
            contrib = a[idx] * a[k - idx]
            max_contrib = contrib.max()
            if max_contrib < 1e-15:
                continue

            # Try moving from top contributors
            top_src = idx[np.argsort(contrib)[::-1]][:min(20, len(idx))]

            for src in top_src:
                if time.monotonic() - t0 > time_limit:
                    break
                # Try multiple destinations
                # Prefer positions far from all top peaks
                peak_mask = np.zeros(n, dtype=bool)
                for k2 in top_peaks[:6]:
                    s2 = max(0, int(k2) - n + 1)
                    e2 = min(n, int(k2) + 1)
                    peak_mask[s2:e2] = True

                # Score destinations
                if peak_mask.sum() < n:
                    non_peak = np.where(~peak_mask)[0]
                    # Also add some random peak positions
                    all_dst = np.concatenate([non_peak, rng.integers(0, n, size=min(50, n))])
                else:
                    all_dst = rng.integers(0, n, size=100)
                all_dst = np.unique(all_dst)
                all_dst = all_dst[all_dst != src]

                # Sort by a[dst] (prefer low-value destinations)
                all_dst = all_dst[np.argsort(a[all_dst])[:min(200, len(all_dst))]]

                for dst in all_dst[:80]:
                    for frac in fractions[:6]:
                        amt = a[src] * frac
                        if amt < 1e-15:
                            continue
                        a_trial = a.copy()
                        a_trial[src] -= amt
                        a_trial[dst] += amt
                        a_trial = np.maximum(a_trial, 0.0)
                        st = a_trial.sum()
                        if st < 1e-15:
                            continue
                        a_trial = a_trial / st
                        sc = eval_score(a_trial)
                        if sc < best_score - 1e-13:
                            a = a_trial
                            best_score = sc
                            best_a = a.copy()
                            improved_this_sweep = True

        if not improved_this_sweep and sweep_count > 5:
            # Try random swaps
            for _ in range(200):
                i = int(rng.integers(n))
                j = int(rng.integers(n))
                if i == j or a[i] < 1e-10:
                    continue
                for frac in [0.005, 0.01, 0.02]:
                    amt = a[i] * frac
                    a[i] -= amt
                    a[j] += amt
                    a = np.maximum(a, 0.0)
                    a = a / a.sum()
                    sc = eval_score(a)
                    if sc < best_score:
                        best_score = sc
                        best_a = a.copy()
                        improved_this_sweep = True
                        break
                    else:
                        a[i] += amt
                        a[j] -= amt
                        a = a / a.sum()
                if time.monotonic() - t0 > time_limit:
                    break

            if not improved_this_sweep:
                break

        if verbose and sweep_count % 5 == 0:
            elapsed = time.monotonic() - t0
            print(f"    FineCoord sweep={sweep_count} ({elapsed:.1f}s): score={best_score:.6f}")

    return best_a, best_score

    print(f"\n=== Phase 2: LP Frank-Wolfe n={len(best_seq)}, time={remaining:.0f}s ===")
    t2 = min(remaining * 0.25, 350.0)
    if t2 > 60:
        a_in = normalize(best_seq)
        a_out, sc = lp_frank_wolfe(a_in, t2, verbose=True, max_iters=100)
        try_update(a_out, f"lp_n{len(best_seq)}")

    # === Phase 3: Adam after LP (to recover from LP direction) ===
    remaining = time_budget - (time.monotonic() - t_global)
    print(f"\n=== Phase 3: Post-LP Adam n={len(best_seq)}, time={remaining:.0f}s ===")
    t3 = min(remaining * 0.15, 200.0)
    if t3 > 30:
        a_in = normalize(best_seq)
        a_out, sc = adam_logspace(a_in, t3, beta_start=30.0, beta_end=100.0,
                                  lr=0.01, seed=99, verbose=False)
        try_update(a_out, f"adam_postlp_n{len(best_seq)}")

    # === Phase 4: Coordinate descent ===
    remaining = time_budget - (time.monotonic() - t_global)
    print(f"\n=== Phase 4: Coord polish n={len(best_seq)}, time={remaining:.0f}s ===")
    t4 = min(remaining * 0.12, 150.0)
    if t4 > 20:
        a_in = normalize(best_seq)
        a_out, sc = coordinate_polish(a_in, t4, verbose=True, seed=42)
        try_update(a_out, f"coord_n{len(best_seq)}")

    # === Phase 5: Fine coordinate descent ===
    remaining = time_budget - (time.monotonic() - t_global)
    print(f"\n=== Phase 5: Fine coord n={len(best_seq)}, time={remaining:.0f}s ===")
    t5 = min(remaining * 0.2, 250.0)
    if t5 > 20:
        a_in = normalize(best_seq)
        a_out, sc = fine_coordinate_polish(a_in, t5, verbose=True, seed=314)
        try_update(a_out, f"finecoord_n{len(best_seq)}")

    # === Phase 6: Try different lengths ===
    remaining = time_budget - (time.monotonic() - t_global)
    n_best = len(best_seq)
    print(f"\n=== Phase 6: Length exploration, time={remaining:.0f}s ===")
    if remaining > 120:
        for delta in [200, -200, 400, -400]:
            n_try = n_best + delta
            if n_try < 500 or n_try > 5000:
                continue
            remaining = time_budget - (time.monotonic() - t_global)
            if remaining < 80:
                break
            a_long = interpolate_sequence(best_seq, n_try)
            # Quick Adam
            t6 = min(remaining * 0.25, 150.0)
            if t6 > 20:
                a_out, _ = adam_logspace(a_long, t6, beta_start=10.0, beta_end=50.0,
                                         lr=0.02, seed=55 + n_try % 100, verbose=False)
                try_update(a_out, f"adam_n{n_try}")
                # Quick coord
                remaining = time_budget - (time.monotonic() - t_global)
                t6b = min(remaining * 0.1, 60.0)
                if t6b > 10:
                    a_out2, _ = coordinate_polish(a_long, t6b, verbose=False, seed=77)
                    try_update(a_out2, f"coord_n{n_try}")

    # === Phase 7: Final LP if time permits ===
    remaining = time_budget - (time.monotonic() - t_global)
    n_best = len(best_seq)
    if n_best <= 3000 and remaining > 100:
        print(f"\n=== Phase 7: Final LP n={n_best}, time={remaining:.0f}s ===")
        t7 = min(remaining * 0.4, 200.0)
        if t7 > 50:
            a_in = normalize(best_seq)
            a_out, _ = lp_frank_wolfe(a_in, t7, verbose=True, max_iters=50)
            try_update(a_out, f"lp_final_n{n_best}")

    # === Phase 8: Final fine coordinate descent ===
    remaining = time_budget - (time.monotonic() - t_global)
    n_best = len(best_seq)
    print(f"\n=== Phase 8: Final fine coord n={n_best}, time={remaining:.0f}s ===")
    if remaining > 30:
        t8 = min(remaining * 0.7, 100.0)
        if t8 > 15:
            a_in = normalize(best_seq)
            a_out, _ = fine_coordinate_polish(a_in, t8, verbose=True, seed=271)
            try_update(a_out, f"finalcoord_n{n_best}")

    # Final validation
    if best_seq is not None:
        fs = eval_score(best_seq)
        if np.isfinite(fs):
            best_score = fs
        print(f"\nFINAL: score={best_score:.6f}, n={len(best_seq)}, time={time.monotonic()-t_global:.0f}s")
    else:
        print("\nERROR: No valid sequence!")
        return [1.0]

    return [float(x) for x in best_seq]
