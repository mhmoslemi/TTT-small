**Key realization: The problem is essentially a "flatten the convolution" problem. The most direct approach is to identify the peaks and work to reduce them.**

Let me think about a "peak reduction" algorithm:

1. Compute `C = conv(a, a)`
2. Find the top peak `k*` with value `C_{k*}`
3. The peak is `C_{k*} = sum_j a_j * a_{k*-j}`
4. The terms with the largest `a_j * a_{k*-j}` contribute the most
5. To reduce the peak, transfer mass from the "source" (the `j` with the largest contribution) to a "destination" that doesn't increase any other peak

This is essentially the coordinate descent approach, but more targeted.

**Let me think about the "destination" selection more carefully.**

If we transfer mass `δ` from `a_i` to `a_k`, the change in `C_m` is:
`ΔC_m = δ * (a_{m-k} - a_{m-i}) + δ^2 * (terms involving δ)`

For small `δ`, the change is approximately:
`ΔC_m ≈ δ * (a_{m-k} - a_{m-i})`

We want `ΔC_m <= 0` for all `m` (or at least for the top peaks).

This means we need `a_{m-k} <= a_{m-i}` for all top-peak `m`.

So the destination `k` should satisfy: for all top peaks `m`, `a_{m-k} <= a_{m-i}`.

This is a useful criterion for choosing the destination!

**Algorithm: Targeted Mass Transfer**

1. Compute `C = conv(a, a)`, find top `P` peaks

   b. Find a destination `d` such that `a_{k_s - d} <= a_{k_s - i}` for all top peaks `k_s`
   c. Transfer a small amount from `a_i` to `a_d`
   d. Verify that the peak decreased
3. Repeat

This is more principled than the previous coordinate descent.

**Let me also think about a "global" approach.**

Instead of moving one mass at a time, what if we solve for the optimal redistribution?

Given the current `a`, we want to find `a'` such that:
- `a' >= 0`, `sum(a') = 1`
- `max_k conv(a', a')_k` is minimized
- `a'` is close to `a` (to ensure small steps)

This is a non-convex problem, but we can approximate it by linearizing:
- `conv(a', a')_k ≈ conv(a, a)_k + 2 * sum_j (a'_j - a_j) * a_{k-j}` (first-order)
- Subject to `a' >= 0`, `sum(a') = 1`, `||a' - a|| <= ε`

This is an LP! And it's much smaller than the full LP because we only need to consider the top peaks.

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss

            T[pi, i_start:i_end] = a[k_int - np.arange(i_start, i_end)]
        
        b_var = cp.Variable(n, nonneg=True)
        constraints = [T @ b_var <= M_curr, cp.sum(b_var) == 1]
        prob = cp.Problem(cp.Maximize(cp.sum(b_var) * 0 + cp.sum(cp.log(b_var + 1e-30))), constraints)
        
        # Actually, let's use the standard Frank-Wolfe: maximize sum(b) subject to constraints
        # But sum(b) = 1 is already a constraint, so we need a different objective
        # Let's minimize the distance to current point
        prob = cp.Problem(cp.Minimize(cp.sum_squares(b_var - a)), constraints)
        try:
            prob.solve(solver=solver, verbose=False)
        except Exception:
            continue
        
        if prob.status not in ('optimal', 'optimal_inaccurate'):
            continue
        
        b_val = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
        b_sum = b_val.sum()
        if b_sum < 1e-15:
            continue
        direction = b_val / b_sum
        
        # Line search
        alphas = [0.5, 0.4, 0.3, 0.2, 0.1, 0.05, 0.01]
        best_alpha = alphas[0]
        best_eval = fast_conv((1 - best_alpha) * a + best_alpha * direction).max()
        
        for alpha in alphas[1:]:
            trial = (1.0 - alpha) * a + alpha * direction
            trial = np.maximum(trial, 0.0)
            st = trial.sum()
            if st < 1e-15:
                continue
            trial = trial / st
            trial_m = fast_conv(trial).max()
            if trial_m < best_eval:
                best_eval = trial_m
                best_alpha = alpha
        
        a_new = (1.0 - best_alpha) * a + best_alpha * direction
        a_new = np.maximum(a_new, 0.0)
        s = a_new.sum()
        if s < 1e-15:
            break
        a_new = a_new / s
        
        M_new = fast_conv(a_new).max()
        if M_new < best_m:
            best_m = M_new
            best_a = a_new.copy()
        a = a_new
        
        iter_count += 1
        if verbose and iter_count % 5 == 0:
            elapsed = time.monotonic() - t0
            J = 2.0 * n * best_m
            print(f"    LP it={iter_count} ({elapsed:.1f}s): J={J:.6f}")
    
    return best_a, best_m

def try_random_initializations(n, time_per_init, n_tries=10, seed=0):
    """Try several random structured initializations."""
    rng = np.random.default_rng(seed)
    best_a = None
    best_m = float('inf')
    
    for i in range(n_tries):
        if time_per_init * (i + 1) > time_per_init * n_tries:
            break
        
        # Different types of random initializations
        kind = i % 5
        if kind == 0:
            a = rng.uniform(0.5, 1.5, n)
        elif kind == 1:
            x = np.linspace(0, 1, n)
            a = 1.0 + 0.3 * np.cos(2 * np.pi * rng.integers(1, 10) * x) + rng.normal(0, 0.1, n)
        elif kind == 2:
            a = np.abs(rng.normal(0, 1, n))
        elif kind == 3:
            a = np.exp(rng.normal(0, 0.5, n))
        else:
            a = 1.0 / (1.0 + np.exp(rng.normal(0, 2, n)))
        
        a = np.maximum(a, 0.0)
        s = a.sum()
        if s < 1e-15:
            continue
        a = a / s
        m = fast_conv(a).max()
        if m < best_m:
            best_m = m
            best_a = a.copy()
    
    return best_a, best_m
