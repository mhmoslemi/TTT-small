Now, for the local search:
1. Maintain the current binary sequence and its convolution.
2. At each step, find a position i where flipping a bit would most reduce the max of the convolution.
3. Apply the flip if it improves the score.

To find the best flip efficiently:
- For each position i, compute the new max if we flip a[i].
- If a[i] = 1 and we flip to 0: c_new[k] = c[k] - 2*a[k-i] for k in [i, i+n-1]. The new max is max of c[k] - 2*a[k-i] in the affected range and max of c[k] in the unaffected range.
- If a[i] = 0 and we flip to 1: c_new[k] = c[k] + 2*a[k-i] for k in [i, i+n-1].

This is O(n) per candidate flip, and we check n positions, so O(n^2) per step. For n=5582, that's about 31 million operations per step, which might be too slow.

Optimization: We can precompute the current max and the second max, and only check flips that affect the current max position.

Alternative: Use a priority queue or track which positions have high convolution values, and only try flips that would reduce those.

**Algorithm: Iterative Peak Reduction**
1. Start with a random binary sequence of weight w.
2. Find the position k* where the convolution is maximized.
3. For each pair (i, j) with i+j = k* and a[i]=a[j]=1, try moving one of them to a different position.
4. Accept the move that most reduces the peak.
5. Repeat until convergence or time runs out.

Step 3 is the key. If k* is the peak, the pairs contributing to it are (i, k*-i) for i in the support. We want to move one element of such a pair to a position that doesn't create a new peak.

This is similar to the "peak-shaving" approach in signal processing.

- At each step, find the vertex (extreme point) of the simplex that minimizes the linearized objective.
- The linearized objective at step t is: ∇f(a_t) · (v - a_t) for v in the simplex.
- The vertex that minimizes this is: v = e_i where i = argmin_j ∇f(a_t)_j.
- But f = max_k c[k] is not differentiable. We use subgradient: ∇f(a_t) is in the subdifferential of max at a_t.

∂f(a) = {∇c_{k*}} = {the gradient of c_{k*} with respect to a}

∂c_{k*}/∂a[j] = a[k*-j] + a[j] (for valid k*-j, else a[k*-j] + 0)
