**Clean formulation:**

We work with unnormalized sequences. The score is `2*n*max(C)/(sum(a))^2`.

Coordinate descent:
- Current state: array `a` (not necessarily normalized), current `C = conv(a,a)`, current `S = sum(a)`, current `score = 2*n*max(C)/S^2`.
- For coordinate j, try new value x:
  - delta = x - a[j]
  - New sum: S' = S + delta
  - New C: C' = C + 2*delta*shifted_a where shifted_a[k] = a[k-j] (zero-padded to length 2n-1)
  - Correction at k=2j: C'[2j] += delta^2
  - New score: 2*n*max(C')/S'^2
- Pick the x that minimizes the new score.
- Update a[j] = x, C = C', S = S'.

This is clean and each evaluation is O(n) (creating the shifted array and computing the max).

For the candidate values of x, I'll use:
- x = 0
- x = a[j] * factor for factor in [0.1, 0.3, 0.5, 0.7, 1.0, 1.3, 1.7, 2.5, 4.0]
- A couple of random perturbations
