And c_{n-1} >= ... well, it can be 0 if a is supported entirely on one half.

By the rearrangement inequality, for a symmetric a, c_{n-1} = sum a_j^2 >= 1/n.
For non-symmetric a, c_{n-1} = <a, rev(a)> which can be less than sum a_j^2.

With sum a = sqrt(2): normalized objective = 2n * 1 / 2 = n. Bad.

a[j] = 1/m for j in {m/2, ..., 3m/2-1}, 0 otherwise (m < n)

So max c = 1/m, and objective = 2n/m. For m < n, this is > 2. Worse than uniform.

So uniform is actually optimal among "simple" shapes. To beat 2, we need a more sophisticated shape.

The key insight: we need the convolution to be FLAT, not just have a small peak. The uniform sequence gives a TRIANGULAR convolution (peaked in the middle). We need to modify it to flatten the triangle.

How? The triangle shape comes from the fact that the "overlap" between a and its shift is largest in the middle. To flatten, we need to make the sequence aperiodic in a specific way.

This is exactly the "Barker sequence" or "low autocorrelation sequence" problem! In communications, Barker sequences are binary sequences with low peak sidelobe levels in their autocorrelation.

For real-valued sequences, the optimal "flat autocorrelation" sequences are related to:
- Zadoff-Chu sequences (complex)
- Costas arrays (permutation-based)
- M-sequences (but these are binary)

For our problem (real, non-negative, auto-CONVOLUTION not auto-CORRELATION), the situation is different because we require non-negativity.

If we allowed complex sequences, we could achieve perfectly flat autocorrelation (Zadoff-Chu). But with the non-negativity constraint, we're limited.

Here's an important observation: if a is non-negative, then conv(a,a) is also non-negative (all entries >= 0). And the sum of all entries is (sum a)^2. So the average entry is (sum a)^2 / (2n-1).

The minimum possible max entry is at least the average: max >= (sum a)^2 / (2n-1).
This gives: objective >= 2n / (2n-1) ≈ 1 for large n.

But we also have the constraint that c_{n-1} = <a, rev(a)> >= 0, and for non-negative a, this is just a sum of non-negative terms. The only lower bound is 0 (if a and rev(a) have disjoint supports, which is impossible for a non-negative sequence of length n since they always overlap at the center).

Actually, for a non-negative sequence of length n, c_{n-1} = sum_j a_j * a_{n-1-j}. Since a_j >= 0 and a_{n-1-j} >= 0, we have c_{n-1} >= 0. The minimum is achieved when a_j * a_{n-1-j} = 0 for all j, which means a_j = 0 or a_{n-1-j} = 0 for all j. This is possible: a = [1, 0, ..., 0] has c_{n-1} = 0 (for n > 1). But then c_0 = 1 and the objective is 2n.

So there's a trade-off: making c_{n-1} small forces other c_k to be large.

The optimal solution balances all c_k to be as equal as possible. This is the "minimax" problem.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. L-BFGS-B in softmax parameterization with adaptive log-sum-exp smoothing
2. Peak-targeted pairwise coordinate descent
3. Multi-length interpolation and re-optimization
4. Multiplicative weights fine-tuning
"""

import numpy as np
from scipy.optimize import minimize, linprog
import time

def fast_conv(a):
    """Auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    """Project onto probability simplex."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def smooth_obj_and_grad(z, tau):
    """
    Objective and gradient in softmax space.
    z is the log-parameter, a = softmax(z).
    Returns (objective_value, gradient_wrt_z).
    """
    n = len(z)
    # Compute a = softmax(z)
    z_max = z.max()
    exp_z = np.exp(z - z_max)
    a = exp_z / exp_z.sum()
    
    # Compute convolution
    conv = fast_conv(a)
    
    # Compute log-sum-exp
    scaled = conv / tau
    scaled -= scaled.max()
    w = np.exp(scaled)
    w_sum = w.sum()
    obj = np.log(w_sum) + scaled.max() * tau  # This is tau * log(sum exp(conv/tau))
    # Actually the objective is the log-sum-exp itself:
    # F = log(sum exp(conv/tau))
    # But for optimization, we can just minimize F
    
    # Gradient of F w.r.t. a:
    # dF/da[i] = (2/tau) * h[i] where h[i] = sum_k w[k]/w_sum * a[k-i]
    # (using the fact that the convolution is symmetric in a specific way)
    
    w_norm = w / w_sum
    
    # h[i] = sum_{k} w_norm[k] * a[k-i] (with appropriate bounds)
    # This is a cross-correlation: h = convolve(a, w_norm_rev)
    w_rev = w_norm[::-1]
    total_len = n + len(w_rev) - 1
    fft_size = 1 << (total_len - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    W = np.fft.rfft(w_rev, fft_size)
    h = np.fft.irfft(A * W, fft_size)
    # h[i] = sum_{k=0}^{2n-2} w_norm[k] * a[k-i] (with a[j]=0 for j<0 or j>=n)
    # We need h for indices 0 to n-1:
    # h_full[i] for i=0,...,total_len-1
    # h[i] = sum_k w_rev[k-i] * a[k] ... let me be more careful
    
    # Actually: conv(a, w_rev)[m] = sum_j a[j] * w_rev[m-j]
    # w_rev[k] = w_norm[2n-2-k]
    # conv(a, w_rev)[m] = sum_j a[j] * w_norm[2n-2-(m-j)] = sum_j a[j] * w_norm[2n-2-m+j]
    
    # I want h[i] = sum_k w_norm[k] * a[k-i] (for valid indices)
    # = sum_k w_norm[k] * a[k-i]
    # Let l = k-i, so k = l+i:
    # h[i] = sum_l w_norm[l+i] * a[l]
    # This is the cross-correlation of a and w_norm at lag i.
    
    # Alternative: h = ifft(fft(a) * conj(fft(w_norm_padded)))
    # Or: h[i] = sum_l a[l] * w_norm[l+i]
    
    # Let me use a direct FFT approach:
    # h[i] = sum_l a[l] * w_norm[l+i] for i = 0, ..., 2n-2
    # This is the "cross-correlation" of a and w_norm.
    # cross_corr[i] = sum_l a[l] * w_norm[l+i]
    # = conv(a, w_norm_rev)[i + 2n - 2 - (n-1)] ... this is getting confusing.
    
    # Let me just think of it as:
    # Define B[j] = w_norm[j] for j = 0,...,2n-2
    # h[i] = sum_{l} a[l] * B[l+i]
    # This is the cross-correlation (a ⋆ B)[i] = sum_l a[l] * B[l+i]
    # In terms of convolution: (a ⋆ B)[i] = (a * B_flipped)[i + len(B) - 1]
    # where B_flipped[j] = B[len(B)-1-j]
    
    B_flip = w_norm[::-1]  # B_flip[j] = w_norm[2n-2-j]
    total_len2 = n + (2*n-1) - 1
    fft_size2 = 1 << (total_len2 - 1).bit_length()
    A2 = np.fft.rfft(a, fft_size2)
    B2 = np.fft.rfft(B_flip, fft_size2)
    conv_ab = np.fft.irfft(A2 * B2, fft_size2)[:total_len2]
    # conv_ab[m] = sum_j a[j] * B_flip[m-j] = sum_j a[j] * w_norm[2n-2-(m-j)]
    # = sum_j a[j] * w_norm[2n-2-m+j]
    # Let k = 2n-2-m+j, so j = k - (2n-2-m):
    # conv_ab[m] = sum_k a[k-(2n-2-m)] * w_norm[k]
    # We want h[i] = sum_l a[l] * w_norm[l+i]
    # Set k = l+i, l = k-i:
    # h[i] = sum_k a[k-i] * w_norm[k]
    # So h[i] = conv_ab[m] where 2n-2-m = -i, i.e., m = 2n-2+i
    # Wait: conv_ab[m] = sum_j a[j] * w_norm[2n-2-m+j]
    # Set 2n-2-m+j = l+i and j = l:
    # 2n-2-m+l = l+i → i = 2n-2-m → m = 2n-2-i
    # So h[i] = conv_ab[2n-2-i]
    
    h = conv_ab[2*n-2-n+1:2*n-2+1][::-1]  # h[0] to h[n-1]
    # h[i] = conv_ab[2n-2-i] for i = 0,...,n-1
    # conv_ab indices: 2n-2-0 = 2n-2, 2n-2-1, ..., 2n-2-(n-1) = n-1
    # So h = conv_ab[n-1:2n-1][::-1]
    
    h = conv_ab[n-1:2*n-1][::-1]
    
    grad_a = (2.0 / tau) * h
    
    # Convert to gradient w.r.t. z:
    # da[i]/dz[j] = a[i] * (delta[i,j] - a[j])
    # grad_z[j] = sum_i grad_a[i] * da[i]/dz[j]
    # = sum_i grad_a[i] * a[i] * (delta[i,j] - a[j])
    # = a[j] * grad_a[j] - a[j] * sum_i grad_a[i] * a[i]
    
    grad_z = a * grad_a - a * np.dot(grad_a, a)
    
    return obj, grad_z

def lbfgs_smooth(z_init, tau, max_iter=200, tol=1e-8):
    """Run L-BFGS-B on the smoothed objective in softmax space."""
    result = minimize(
        smooth_obj_and_grad,
        z_init,
        jac=True,
        method='L-BFGS-B',
        options={'maxiter': max_iter, 'gtol': tol, 'maxfun': 500}
    )
    return result.x, result.fun

def a_from_z(z):
    """Convert log-parameter to probability vector."""
    z_max = z.max()
    exp_z = np.exp(z - z_max)
    return exp_z / exp_z.sum()

def z_from_a(a):
    """Convert probability vector to log-parameter."""
    a_safe = np.maximum(a, 1e-30)
    return np.log(a_safe)

def peak_targeted_swap(a, n_swaps=100, verbose=False):
    """
    Try pairwise mass transfers to reduce the peak of the convolution.
    """
    n = len(a)
    a = np.maximum(a, 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        return a
    a = a / s
    
    best_obj = fast_conv(a).max()
    best_a = a.copy()
    it = 0
    
    while n_swaps > 0:
        conv = fast_conv(a)
        M = conv.max()
        if M < best_obj - 1e-12:
            best_obj = M
            best_a = a.copy()
        
        # Find the peak
        pk = int(np.argmax(conv))
        
        # Find the main contributor to the peak
        js = max(0, pk - n + 1)
        je = min(n - 1, pk)
        idx = np.arange(js, je + 1)
        products = a[idx] * a[pk - idx]
        j1 = int(idx[np.argmax(products)])
        j2 = pk - j1
        
        if j1 == j2:
            # Diagonal: reduce a[j1]
            for frac in [0.3, 0.5, 0.7]:
                trial = a.copy()
                trial[j1] *= (1 - frac)
                diff = a[j1] * frac
                # Redistribute to a random non-contributing position
                # Find positions that don't contribute to the top 3 peaks
                top_peaks = np.argsort(conv)[-3:]
                contrib = set()
                for tp in top_peaks:
                    ts = max(0, int(tp) - n + 1)
                    te = min(n - 1, int(tp))
                    for j in range(ts, te+1):
                        contrib.add(j)
                # Choose a position not in contrib
                available = [j for j in range(n) if j not in contrib and a[j] < best_a.max()]
                if available:
                    j_target = available[np.random.randint(len(available))]
                    trial[j_target] += diff
                    trial = np.maximum(trial, 0)
                    trial /= trial.sum()
                    obj = fast_conv(trial).max()
                    if obj < best_obj - 1e-14:
                        a = trial
                        break
        else:
            # Off-diagonal: reduce one of the two
            for frac in [0.3, 0.5, 0.7]:
                for j_reduce in [j1, j2]:
                    trial = a.copy()
                    diff = a[j_reduce] * frac
                    trial[j_reduce] -= diff
                    # Add to a position far from the peak
                    # Choose j_target such that j_target + j_reduce != pk and j_target + j_other != pk
                    j_other = j_reduce if j_reduce == j1 else j2
                    available = []
                    for j in range(n):
                        if j + j_reduce == pk or j + j_other == pk:
                            continue
                        available.append(j)
                    if available:
                        # Choose the position that would most reduce the peak
                        # (heuristic: add to a small element far from peak)
                        rng_choice = available[np.random.randint(len(available))]
                        trial[rng_choice] += diff
                        trial = np.maximum(trial, 0)
                        trial /= trial.sum()
                        obj = fast_conv(trial).max()
                        if obj < best_obj - 1e-14:
                            a = trial
                            break
                else:
                    continue
                break
        
        n_swaps -= 1
        if n_swaps % 200 == 0 and verbose:
            print(f"    Peak swap: obj={2*n*best_obj:.6f}")
    
    return best_a

def multiplicative_weights_opt(a_init, time_limit, verbose=False):
    """
    Multiplicative weights optimization in the simplex.
    """
    n = len(a_init)
    a = np.maximum(a_init, 0.0).copy()
    s = a.sum()
    a = a / s
    
    best_obj = fast_conv(a).max()
    best_a = a.copy()
    t0 = time.monotonic()
    it = 0
    
    # Initialize p (distribution over convolution positions)
    p = np.ones(2*n-1) / (2*n-1)
    
    lr = 0.1
    inner_lr = 0.05
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        
        # Inner: multiplicative weights step
        # grad[i] = 2 * sum_k p[k] * a[k-i] (the "virtual" gradient)
        p_rev = p[::-1]
        total_len = n + len(p_rev) - 1
        fft_size = 1 << (total_len - 1).bit_length()
        A = np.fft.rfft(a, fft_size)
        P = np.fft.rfft(p_rev, fft_size)
        h = np.fft.irfft(A * P, fft_size)
        grad = 2.0 * h[n-1:2*n-1][::-1]
        
        # Multiplicative update
        a = a * np.exp(-inner_lr * grad)
        a = np.maximum(a, 0)
        a = a / a.sum()
        
        conv = fast_conv(a)
        M = conv.max()
        
        if M < best_obj - 1e-12:
            best_obj = M
            best_a = a.copy()
            if verbose and it % 100 == 0:
                print(f"    MW iter {it}: obj={2*n*best_obj:.6f}")
        
        # Outer: update p
        tau_p = max(0.01 * M, 1e-10)
        scaled = conv / tau_p
        scaled -= scaled.max()
        w = np.exp(scaled)
        w = w / w.sum()
        p = (1 - lr) * p + lr * w
        p = p / p.sum()
        
        # Adapt lr
        if it % 200 == 0:
            lr = max(0.02, lr * 0.9)
            inner_lr = max(0.01, inner_lr * 0.95)
    
    return best_a, 2 * n * best_obj

def try_sequence(a, best_state):
    """Evaluate a sequence and update best state."""
    a = np.asarray(a, dtype=np.float64)
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-10:
        return
    a_norm = a / s
    score = float(evaluate_sequence(a_norm.tolist()))
    if np.isfinite(score) and score < best_state[0]:
        best_state[0] = score
        best_state[1] = a_norm.copy()
        print(f"  NEW BEST: {score:.6f} (n={len(a_norm)})")

def interpolate_seq(a, new_n):
    """Interpolate sequence to new length."""
    old_n = len(a)
    if old_n == new_n:
        return a.copy()
    old_x = np.linspace(0, 1, old_n + 1)
    new_x = np.linspace(0, 1, new_n + 1)
    a_pad = np.concatenate([a, [0]])  # Pad with 0 at end
    a_interp = np.interp(new_x, old_x, a_pad)
    a_interp = a_interp[:-1]  # Remove the last point
    a_interp = np.maximum(a_interp, 0)
    s = a_interp.sum()
    if s > 1e-15:
        a_interp /= s
    return a_interp

def lbfgs_phase(a_start, time_limit, tau_start=None, verbose=False):
    """
    L-BFGS optimization phase with adaptive temperature.
    """
    n = len(a_start)
    a = np.maximum(a_start, 0.0).copy()
    s = a.sum()
    a = a / s
    
    conv = fast_conv(a)
    if tau_start is None:
        tau = 0.05 * conv.max()
    else:
        tau = tau_start
    
    z = z_from_a(a)
    best_obj = conv.max()
    best_a = a.copy()
    t0 = time.monotonic()
    phase_count = 0
    
    while time.monotonic() - t0 < time_limit:
        phase_count += 1
        # Run L-BFGS for a limited time
        phase_time = min(60, time_limit - (time.monotonic() - t0))
        if phase_time < 5:
            break
        
        max_iter = max(20, int(200 * (50 / (n / 100))))
        
        # Track time by limiting iterations
        result = minimize(
            smooth_obj_and_grad,
            z,
            args=(tau,),
            jac=True,
            method='L-BFGS-B',
            options={'maxiter': max_iter, 'gtol': 1e-6, 'maxfun': 300}
        )
        
        z = result.x
        a_new = a_from_z(z)
        conv_new = fast_conv(a_new)
        M_new = conv_new.max()
        
        if M_new < best_obj - 1e-10:
            best_obj = M_new
            best_a = a_new.copy()
            if verbose:
                print(f"    L-BFGS phase {phase_count}: obj={2*n*best_obj:.8f}, tau={tau:.2e}")
        
        # Decrease temperature
        tau *= 0.85
        tau = max(tau, conv_new.max() * 0.001)
        
        # Check time
        elapsed = time.monotonic() - t0
        if verbose and phase_count % 5 == 0:
            print(f"    L-BFGS elapsed: {elapsed:.0f}s/{time_limit:.0f}s")
        
        # If improvement stalled, perturb
        if M_new > best_obj * 1.001:
            rng = np.random.default_rng(phase_count * 1009)
            noise = rng.standard_normal(n) * 0.005
            a_pert = project_simplex(a_new + noise)
            z = z_from_a(a_pert)
            tau = 0.03 * fast_conv(a_pert).max()
    
    return best_a, 2 * n * best_obj

def propose_candidate(seed=42, budget_s=1800):
    """
    Multi-phase optimization:
    1. Initialize from parent or diverse starting points
    2. L-BFGS smooth optimization with temperature annealing
    3. Multiplicative weights refinement
    4. Peak-targeted coordinate descent
    5. Multi-length exploration
    6. Final polish
    """

    total_budget = float(budget_s)
    deadline = time.monotonic() + total_budget - 30.0
    
    # Best state: [score, sequence]
    best_state = [float('inf'), None]
    
    def try_seq(a, label=""):
        nonlocal best_state
        a = np.asarray(a, dtype=np.float64)
        a = np.maximum(a, 0.0)
        s = a.sum()
        if s < 1e-10:
            return
        a_norm = a / s
        score = float(evaluate_sequence(a_norm.tolist()))
        if np.isfinite(score) and score < best_state[0]:
            best_state[0] = score
            best_state[1] = a_norm.copy()
            print(f"  NEW BEST [{label}]: {score:.6f} (n={len(a_norm)})")
    
    # === Phase 1: Initialization (30s) ===
    print("=== Phase 1: Initialization ===")
    t1_end = time.monotonic() + 30

    parent = None

        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            parent = p / p.sum()
            try_seq(parent, "parent")
    except Exception:
        pass
    
    if parent is None:
        n0 = 512
        parent = np.ones(n0) / n0
        try_seq(parent, "uniform")

        if time.monotonic() > t1_end:

        # Asymmetric Gaussian

        try_seq(a_gauss, f"gauss_{n_try}")

        t3_end = min(time.monotonic() + 300, deadline - 300)
        t3_budget = t3_end - time.monotonic()

            a_opt, obj = lbfgs_phase(best_state[1], time_limit=t3_budget,

    if np.isfinite(final_score):
        best_state[0] = final_score
    
    print(f"\nFINAL: score={best_state[0]:.6f}, n={len(best_state[1])}")
    return [float(x) for x in best_state[1]]
