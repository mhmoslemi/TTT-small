def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(0.0, v[0])])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def hankel_matvec(p, a):
    """Compute H(p) @ a where H(p)_{j,l} = p_{j+l}."""
    n = len(a)
    if n == 1:
        return np.array([p[0] * a[0]])
    strides = (p.strides[0], p.strides[0])
    windows = as_strided(p, shape=(n, n), strides=strides)
    return windows @ a

≈ (1/n^2) * n * int_0^1 f(x) f(1-x) dx  (Riemann sum, n terms each of width 1/n)
= (1/n) * int_0^1 f(x) f(1-x) dx

And ||a||_2^2 = sum_j a[j]^2 = (1/n^2) sum_j f(j/n)^2
≈ (1/n^2) * n * int_0^1 f(x)^2 dx
= (1/n) * int f^2

So conv[n-1] ≈ (1/n) * int f(x) f(1-x) dx
And ||a||_2^2 ≈ (1/n) * int f^2

By C-S: int f(x) f(1-x) dx <= sqrt(int f^2 * int f^2) = int f^2.
Equality iff f(x) = f(1-x) (symmetric).

So conv[n-1] <= ||a||_2^2, as expected.

Now, the maximum of conv:
conv[0] = a[0]^2 ≈ (f(0)/n)^2
conv[n-1] ≈ (1/n) * int f(x) f(1-x) dx
conv[k] for other k: similar scaling

The largest value is at k = n-1 (the center), with value ≈ (1/n) * int f(x) f(1-x) dx.

Objective = 2n * max(conv) ≈ 2n * (1/n) * int f(x) f(1-x) dx = 2 * int f(x) f(1-x) dx.

So in the continuous limit, the objective is 2 * int_0^1 f(x) f(1-x) dx.

And we can make this less than 2! For example, if f is concentrated near x=0:
f(x) = c * exp(-x/sigma) for small sigma.
int f(x) f(1-x) dx = c^2 * int exp(-x/sigma) exp(-(1-x)/sigma) dx
= c^2 * exp(-1/sigma) * int exp(0) dx (approximately, for small sigma)
= c^2 * exp(-1/sigma)

And c is chosen so int f = 1: c * sigma (1 - exp(-1/sigma)) ≈ c * sigma = 1, so c ≈ 1/sigma.
int f(x) f(1-x) dx ≈ (1/sigma^2) * exp(-1/sigma)

For small sigma, this is very small! So the objective ≈ 2 * (1/sigma^2) * exp(-1/sigma) → 0 as sigma → 0.

But wait, we also need to check conv[0] = a[0]^2 ≈ (f(0)/n)^2 = (c/n)^2 = (1/(sigma*n))^2.
For this to be less than the center value: (1/(sigma*n))^2 < (1/n) * (1/sigma^2) * exp(-1/sigma)
=> 1/(sigma^2 * n^2) < exp(-1/sigma) / (n * sigma^2)
=> 1/n < exp(-1/sigma)
=> n > exp(1/sigma)

So for very small sigma, the corner values dominate, and the max is at the corners, not the center.

The optimal balance is when conv[0] ≈ conv[n-1], i.e.:
(c/n)^2 ≈ (1/n) * int f(x) f(1-x) dx

For f(x) = c * exp(-x/sigma):
(c/n)^2 = (1/n) * (1/sigma^2) * exp(-1/sigma) * (approximately)
c^2/n^2 = exp(-1/sigma)/(n*sigma^2)
c^2 * sigma^2 = n * exp(-1/sigma)
(1/sigma^2) * sigma^2 = n * exp(-1/sigma)  [since c ≈ 1/sigma for small sigma]
1 = n * exp(-1/sigma)
exp(1/sigma) = n
1/sigma = ln(n)
sigma = 1/ln(n)

So the optimal sigma is about 1/ln(n). For n = 768, sigma ≈ 1/6.6 ≈ 0.15.
