For the QP `min a^T M a` subject to `sum(a) = 1, a >= 0`:

The projected gradient step is:
`a_new = Proj_simplex(a - eta * grad)`

where `grad = 2 * M * a` and `Proj_simplex` projects onto the probability simplex.

The projection onto the simplex can be done with the algorithm from Duchi et al. (2008):
```python
def proj_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([1.0])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.argmax(1 - u * np.arange(1, n + 1) < cssv)
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)
```

**Alternative: Use the KKT conditions**

The QP `min a^T M a` s.t. `sum(a) = 1, a >= 0` has KKT conditions:
- `2*M*a + lambda * 1 - mu = 0` (gradient of Lagrangian = 0)
- `mu[i] >= 0, mu[i]*a[i] = 0` (complementary slackness)
- `sum(a) = 1, a >= 0`

For the active set (where `a[i] > 0`): `2*(M*a)[i] + lambda = 0`, i.e., `(M*a)[i] = -lambda/2 = c` (constant).

So on the active set, `M*a` is constant. This means we can solve for `a` on the active set:
If the active set is S, then `(M_SS * a_S) + (M_S,rest * a_rest) = c * 1_S`

Since `a_rest = 0` (by definition of active set): `M_SS * a_S = c * 1_S`

And `sum_S a_S = 1`.

From `M_SS * a_S = c * 1_S`, we get `a_S = c * M_SS^{-1} * 1_S` (if M_SS is invertible).
Then `sum_S a_S = c * 1_S^T * M_SS^{-1} * 1_S = 1`, so `c = 1 / (1_S^T * M_SS^{-1} * 1_S)`.

This requires inverting an |S| x |S| matrix, which is feasible if |S| is not too large.

But finding the right active set is the hard part. We can use an iterative approach:
1. Start with all indices in the active set
2. Solve the restricted QP
3. If any a[i] < 0 for i in S, remove it from S
4. Repeat

This is the **active set method** for QPs.

```python
def inner_qp_solve(a, p, n_steps=20):
    """Minimize a^T M(p) a s.t. sum(a)=1, a>=0 using projected gradient."""
    n = len(a)
    a = a.copy()
    # Initial step size
    # The Hessian is 2*M, eigenvalues bounded by 2*max_eig(M)
    # We can estimate the step size from the norm of the gradient
    for step in range(n_steps):
        grad = compute_gf(a, p)  # = 2 * M * a
        if np.max(np.abs(grad)) < 1e-10:
            break
        # Backtracking line search
        eta = 1.0 / (np.max(np.abs(grad)) + 1e-10) * 0.5
        f_old = a @ grad  # a^T * 2Ma = 2 * a^T M a (proportional to objective)
        for _ in range(20):
            a_trial = a - eta * grad
            a_trial = proj_simplex(a_trial)
            f_trial = a_trial @ compute_gf(a_trial, p)
            if f_trial < f_old:
                break
            eta *= 0.5
        a = a_trial
    return a
```
