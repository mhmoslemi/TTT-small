The key insight is that we want a sequence where the auto-convolution is as "flat" as possible (minimizing the maximum). This is related to the concept of "convolution flattening" or finding sequences with minimal peak factor in their autocorrelation.

Let me think about the mathematical structure more carefully:

If a is a probability vector (sum = 1), then convolve(a,a) has sum = 1, and we're minimizing `2*n*max_k conv(a,a)[k]`.

The minimum possible value of `max_k conv(a,a)[k]` is at least `1/(2n-1)` (by averaging), so the lower bound on the objective is `2n/(2n-1) ≈ 1` for large n.

For a uniform distribution a_i = 1/n, the convolution is a triangle: conv[k] = (k+1)/n² for k < n, and (2n-1-k)/n² for k >= n. The max is 1/n (at k=n-1). So the objective is `2n * (1/n) = 2`.

So we need to go from 2 (uniform) to below 1.5. That's a significant improvement.

The key idea is to find distributions whose auto-convolution is flatter than a triangle. This is related to "Barker sequences" and "Golay sequences" in signal processing, but for continuous (not binary) sequences.

Let me think about specific approaches:

**Approach 1: Multiplicative weight updates (follow the regularized leader)**
- This is like an online learning approach where we treat the convolution peaks as "losses"
- At each step, we reduce weights (a_i) that contribute to the current maximum peaks
- This is similar to the "no-regret" approach in game theory

**Approach 2: Simulated annealing with structured moves**
- Randomly perturb the sequence
- Accept with probability based on improvement
- Use cooling schedule

**Approach 3: Direct optimization using the structure**
- The gradient of max(conv(a,a)) w.r.t. a_i involves the pairs (j, k-j) where conv[k] is at the max
- We can do subgradient descent with momentum

**Approach 4: Using FFT-based methods**
- Work in frequency domain
- The convolution in time domain is multiplication in frequency domain
- But max is not straightforward in frequency domain

Key improvements over the previous approach:
- Instead of coordinate descent one coordinate at a time, do simultaneous multiplicative updates
- Use a temperature schedule for simulated annealing
- Try to exploit the structure: if conv[k] is at the max, we want to reduce products a[i]*a[k-i] for all valid i
- Use momentum and adaptive step sizes

Let me also think about the "peak targeting" more carefully:

If M = conv[a,a][k*] is the maximum, then:
- We want to reduce a[i]*a[k*-i] for all i where both indices are valid
- But reducing a[i] also affects other convolution values
- The optimal move is to reduce a[i] in proportion to its "damage" to the peaks

The "damage" of a[i] to the peaks is: sum over all peak positions k where i is in range, of a[k-i] (weighted by how close conv[k] is to M).

This gives a natural multiplicative update:
  a[i] *= exp(-lr * damage[i])

where damage[i] = sum_k w_k * a[k-i] for peaks k where i is valid.

This is essentially what the Nesterov MD does, but let me make it more explicit and add simulated annealing.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Subgradient multiplicative updates with adaptive temperature (simulated annealing)
2. FFT-based fast convolution and peak damage computation
3. Momentum-accelerated updates with adaptive learning rate
4. Multi-length search with interpolation
5. Structured restarts based on peak analysis
"""

import numpy as np
from scipy.fft import rfft, irfft
import time

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]

def simplex_project(v):
    """Project vector v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if cond.any():
        rho = np.nonzero(cond)[0][-1]
        theta = (cssv[rho] - 1.0) / (rho + 1.0)
        return np.maximum(v - theta, 0.0)
    else:
        return np.ones(n) / n

def compute_peak_damage(a, conv, top_frac=0.1, temperature=1.0):
    """
    Compute the 'damage' of each coordinate a[i] to the convolution peaks.
    damage[i] = sum over peak positions k of w_k * a[|k-i|] (where valid)
    """
    n = len(a)
    M = conv.max()
    # Soft weighting: weights are exp(-conv[k] * temperature / M) inverted
    # Actually, we want high weight for positions near the max
    # Use: w_k = exp(beta * (conv[k] - M) / M) normalized
    beta = temperature
    scaled = beta * (conv - M) / (M + 1e-30)
    scaled = np.clip(scaled, -50, 0)
    weights = np.exp(scaled)
    Z = weights.sum()
    if Z < 1e-30:
        weights = np.zeros_like(conv)
        weights[conv.argmax()] = 1.0
        Z = 1.0
    weights = weights / Z
    
    damage = np.zeros(n)
    for k in range(len(conv)):
        w = weights[k]
        if w < 1e-12:
            continue
        i_start = max(0, k - n + 1)
        i_end = min(n - 1, k)
        # For each i in [i_start, i_end], a[i] contributes w * a[k-i] to damage[i]
        i_range = np.arange(i_start, i_end + 1)
        j_range = k - i_range
        damage[i_range] += w * a[j_range]
    
    return damage

def multiplicative_update_with_annealing(a0, time_limit, lr_init=0.01, beta_init=20.0, 
                                           cooling=0.999, min_temp=0.5, label=""):
    """
    Simulated annealing with multiplicative (mirror) updates.
    At each step:
    1. Compute peak damage
    2. Multiply a[i] by exp(-lr * damage[i])
    3. Project to simplex
    4. Accept/reject based on improvement (annealing)
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    conv = fast_convolve(a)
    best_a = a.copy()
    best_score = 2.0 * n * conv.max()
    
    t0 = time.monotonic()
    it = 0
    lr = lr_init
    beta = beta_init
    temperature = 1.0
    momentum = np.zeros(n)
    momentum_beta = 0.9
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        
        # Compute damage
        damage = compute_peak_damage(a, conv, temperature=beta)
        
        # Normalize damage for stable updates
        d_max = damage.max()
        if d_max < 1e-30:
            break
        damage_normalized = damage / d_max
        
        # Momentum
        momentum = momentum_beta * momentum + (1 - momentum_beta) * damage_normalized
        
        # Multiplicative update
        log_a = np.log(a + 1e-30)
        log_a -= lr * momentum
        a_new = np.exp(log_a - log_a.max())
        a_new = simplex_project(a_new)
        
        # Compute new score
        conv_new = fast_convolve(a_new)
        score_new = 2.0 * n * conv_new.max()
        
        # Annealing acceptance
        if score_new < best_score:
            a = a_new
            conv = conv_new
            best_score = score_new
            best_a = a.copy()
        else:
            # Accept with probability exp(-(score_new - best_score) * n / temperature)
            delta = (score_new - best_score) * n / max(temperature, 0.01)
            if delta < 50 and np.random.random() < np.exp(-delta):
                a = a_new
                conv = conv_new
        
        # Cool down
        temperature *= cooling
        if temperature < min_temp:
            temperature = min_temp
        
        # Adaptive learning rate
        if it % 200 == 0:
            lr *= 0.97
            beta *= 1.01
        
        if lr < 1e-10:
            break
        
    return best_a, best_score

def batch_multiplicative_update(a0, time_limit, batch_size=100, lr_init=0.005, 
                                  label=""):
    """
    More efficient version: process coordinates in batches,
    using a smarter damage computation.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    conv = fast_convolve(a)
    best_a = a.copy()
    best_score = 2.0 * n * conv.max()
    t0 = time.monotonic()
    it = 0
    lr = lr_init
    
    # Use a "top-k peaks" approach for efficiency
    k_peaks = max(10, n // 10)
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        
        # Find top k peaks
        top_idx = np.argpartition(conv, -k_peaks)[-k_peaks:]
        peak_vals = conv[top_idx]
        M = peak_vals.max()
        
        # Compute damage from top peaks only
        damage = np.zeros(n)
        for k in top_idx:
            w = (conv[k] / M) ** 4  # Sharpen the focus
            i_start = max(0, k - n + 1)
            i_end = min(n - 1, k)
            i_range = np.arange(i_start, i_end + 1)
            j_range = k - i_range
            damage[i_range] += w * a[j_range]
        
        d_max = damage.max()
        if d_max < 1e-30:
            break
        
        # Multiplicative update
        log_a = np.log(a + 1e-30)
        log_a -= lr * (damage / d_max)
        a_new = np.exp(log_a - log_a.max())
        a_new = simplex_project(a_new)
        
        conv_new = fast_convolve(a_new)
        score_new = 2.0 * n * conv_new.max()
        
        if score_new < best_score - 1e-15:
            best_score = score_new
            best_a = a_new.copy()
            a = a_new
            conv = conv_new
        elif score_new < best_score * (1 + 1.0 / max(it, 1)):
            # Accept slightly worse solutions early on (annealing)
            a = a_new
            conv = conv_new
        else:
            # Revert and reduce learning rate
            lr *= 0.95
        
        if it % 100 == 0:
            elapsed = time.monotonic() - t0
            print(f"    BMD {label} it={it} ({elapsed:.0f}s): best={best_score:.6f} cur={score_new:.6f} lr={lr:.6f}")
        
        if lr < 1e-12:
            break
    
    return best_a, best_score

def coordinate_descent_optimal(a0, time_limit, label=""):
    """
    Coordinate descent where for each coordinate, we find the OPTIMAL
    value that minimizes the maximum convolution, using binary search.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    conv = fast_convolve(a)
    M = float(conv.max())
    best_a = a.copy()
    best_score = 2.0 * n * M
    t0 = time.monotonic()
    sweeps = 0
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        sweeps += 1
        improved = False
        
        for i in range(n):
            if a[i] < 1e-15:
                continue
            
            k_start = i
            k_end = min(i + n - 1, 2 * n - 2)
            
            # Unaffected max
            unaff_max = -1e30
            if k_start > 0:
                unaff_max = max(unaff_max, float(conv[:k_start].max()))
            if k_end < 2 * n - 2:
                unaff_max = max(unaff_max, float(conv[k_end + 1:].max()))
            
            # For coordinate i, conv[k] for k in [k_start, k_end] changes:
            # conv[k] = conv[k] - 2*a[i]*a[k-i] + 2*new_val*a[k-i] + (new_val^2 - a[i]^2) if k==2i
            # = conv[k] + 2*(new_val - a[i])*a[k-i] + (new_val^2 - a[i]^2) [delta for k==2i]
            
            # We want to find new_val that minimizes max(conv[k] + 2*delta*a[k-i]) over affected k
            # where delta = new_val - a[i]
            
            # This is equivalent to: minimize max over k of (conv[k] + 2*delta*a[k-i])
            # subject to new_val = a[i] + delta >= 0
            
            # The optimal delta is where the max of the affected conv is minimized.
            # This is a 1D minimax problem.
            
            # For a given delta, the affected values are:
            #   conv[k] + 2*delta*a[k-i] for k != 2i (within range)
            #   conv[2i] + 2*delta*a[i] + delta^2 for k = 2i (within range)
            
            # Use binary search on delta to find where the "upper envelope" is minimized
            # Actually, let's just try a few values
                
            a_i = a[i]
            # The range of delta: from -a_i (to zero) to some positive value
            # For the minimax, the optimal is typically a small negative delta
            # (reducing a[i] to lower the peaks it contributes to)
            
            # Quick approach: try the delta that would make the max affected conv
            # equal to the unaff_max (if possible), or the delta that minimizes the max
            
            affected_conv = conv[k_start:k_end + 1].copy()
            # a[k-i] for k in [k_start, k_end] => a[0 : n] = a (shifted)
            a_shifted = a[k_start - i : k_end - i + 1]  # This is a[0:n] always
            
            # Try to find delta that minimizes max(affected_conv + 2*delta*a_shifted)
            # This is a linear minimax problem in 1D
            # The optimal is where two (or more) constraints are tight
            
            # Simpler: binary search for the smallest delta such that
            # max(affected_conv + 2*delta*a_shifted) is minimized
            
            # The function f(delta) = max_k (affected_conv[k] + 2*delta*a_shifted[k])
            # is convex in delta (max of linear functions)
            # So we can find the minimum via ternary search or by finding
            # where the subgradient changes sign
            
            # For efficiency, let's just try a grid of values
            best_delta = 0.0
            best_max_val = M
            
            # The relevant range of delta
            # If delta = -a_i, then new_val = 0
            # If delta > 0, we're increasing
            # Typically we want negative delta (reduce)
            
            deltas = np.concatenate([
                np.linspace(-a_i, 0, 10),
                np.linspace(0, a_i * 2, 5)
            ])
            
            for delta in deltas:
                new_val = a_i + delta
                if new_val < -1e-15:
                    continue
                new_affected = affected_conv + 2.0 * delta * a_shifted
                if 2 * i >= k_start and 2 * i <= k_end:
                    idx_2i = 2 * i - k_start
                    new_affected = new_affected.copy()
                    new_affected[idx_2i] = conv[2 * i] + 2.0 * delta * a_i + delta * delta
                new_max = max(unaff_max, float(new_affected.max()))
                if new_max < best_max_val - 1e-15:
                    best_max_val = new_max
                    best_delta = delta
            
            if best_delta != 0.0 and best_max_val < M - 1e-14:
                a[i] = max(a[i] + best_delta, 0.0)
                sum_a = a.sum()
                
                # Update conv
                delta = best_delta
                changes = 2.0 * delta * a_shifted
                if 2 * i >= k_start and 2 * i <= k_end:
                    idx_2i = 2 * i - k_start
                    changes = changes.copy()
                    # The change at position 2i is 2*delta*(a[i]-delta) + delta^2
                    # = 2*delta*a[i] - 2*delta^2 + delta^2 = 2*delta*a[i] - delta^2
                    # Wait, let me be more careful:
                    # conv[2i] = sum_j a[j]*a[2i-j]
                    # When we change a[i] to a[i]+delta:
                    # The term a[i]*a[i] becomes (a[i]+delta)^2 = a[i]^2 + 2*a[i]*delta + delta^2
                    # So the change is 2*a[i]*delta + delta^2
                    # But the general formula gives 2*delta*a[i] for the 2i position
                    # (since a[k-i] at k=2i is a[i])
                    # So we need to add delta^2 to the 2i position
                    changes[idx_2i] += delta * delta
                conv[k_start:k_end + 1] += changes
                M = max(unaff_max, float(conv[k_start:k_end + 1].max()))
                
                cur_score = 2.0 * n * M / (sum_a * sum_a)
                if cur_score < best_score - 1e-14:
                    best_score = cur_score
                    best_a = a.copy()
                improved = True
        
        if not improved:
            no_improve += 1
            if no_improve > 50:
                break
        else:
            no_improve = 0
        
        if sweeps % 50 == 0:
            elapsed = time.monotonic() - t0
            print(f"    CDO {label} sweep={sweeps} ({elapsed:.0f}s): best={best_score:.6f}")
    
    return best_a, best_score

def annealed_coordinate_descent(a0, time_limit, label="", 
                                  initial_temp=1.0, cooling=0.999):
    """
    Coordinate descent with simulated annealing acceptance.
    At each coordinate, try multiple deltas and accept the best,
    but also accept worse moves with some probability (annealing).
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    conv = fast_convolve(a)
    M = float(conv.max())
    best_a = a.copy()
    best_score = 2.0 * n * M
    t0 = time.monotonic()
    sweeps = 0
    temperature = initial_temp
    rng = np.random.default_rng(123)
    
    while time.monotonic() - t0 < time_limit:
        sweeps += 1
        improved = False
        
        for i in range(n):
            if a[i] < 1e-15:
                continue
            
            k_start = i
            k_end = min(i + n - 1, 2 * n - 2)
            
            unaff_max = -1e30
            if k_start > 0:
                unaff_max = max(unaff_max, float(conv[:k_start].max()))
            if k_end < 2 * n - 2:
                unaff_max = max(unaff_max, float(conv[k_end + 1:].max()))
            
            affected_conv = conv[k_start:k_end + 1]
            a_shifted = a[0:n]
            a_i = a[i]
            
            best_delta = 0.0
            best_new_max = M
            
            # Try various deltas (more aggressive than before)
            for factor in [0.5, 0.7, 0.8, 0.9, 0.95, 1.0, 1.05, 1.1, 1.2, 1.3, 1.5, 2.0]:
                delta = a_i * (factor - 1.0)
                new_val = a_i + delta
                if new_val < -1e-15 or new_val > 1.0:
                    continue
                
                new_affected = affected_conv + 2.0 * delta * a_shifted.copy()
                if 2 * i >= k_start and 2 * i <= k_end:
                    idx_2i = 2 * i - k_start
                    new_affected[idx_2i] = conv[2 * i] + 2.0 * delta * a_i + delta * delta
                
                new_max = max(unaff_max, float(new_affected.max()))
                
                # Annealing: accept if better, or with probability if worse
                if new_max < best_new_max:
                    best_new_max = new_max
                    best_delta = delta
            
            # Also try random perturbation
            random_delta = rng.standard_normal() * a_i * 0.3
            new_val = a_i + random_delta
            if 0 <= new_val <= 1.0:
                new_affected = affected_conv + 2.0 * random_delta * a_shifted.copy()
                if 2 * i >= k_start and 2 * i <= k_end:
                    idx_2i = 2 * i - k_start
                    new_affected[idx_2i] = conv[2 * i] + 2.0 * random_delta * a_i + random_delta * random_delta
                new_max = max(unaff_max, float(new_affected.max()))
                
                if new_max < best_new_max:
                    best_new_max = new_max
                    best_delta = random_delta
                elif temperature > 0.1:
                    delta_score = (new_max - best_new_max) * n / temperature
                    if delta_score < 30 and rng.random() < np.exp(-delta_score):
                        best_new_max = new_max
                        best_delta = random_delta
            
            if best_delta != 0.0 and best_new_max < M - 1e-15:
                a[i] = max(a[i] + best_delta, 0.0)
                sum_a = a.sum()
                
                changes = 2.0 * best_delta * a_shifted
                if 2 * i >= k_start and 2 * i <= k_end:
                    idx_2i = 2 * i - k_start
                    changes = changes.copy()
                    changes[idx_2i] = 2.0 * best_delta * (a[i] - best_delta) + best_delta * best_delta
                conv[k_start:k_end + 1] += changes
                M = max(unaff_max, float(conv[k_start:k_end + 1].max()))
                
                cur_score = 2.0 * n * M / (sum_a * sum_a)
                if cur_score < best_score - 1e-14:
                    best_score = cur_score
                    best_a = a.copy()
                improved = True
        
        temperature *= cooling
        
        if not improved and temperature < 0.5:
            # Restart temperature occasionally
            if sweeps % 200 == 0:
                temperature = 1.0
            else:
                continue
        
        if sweeps % 100 == 0:
            elapsed = time.monotonic() - t0
            print(f"    ACD {label} sweep={sweeps} ({elapsed:.0f}s): best={best_score:.6f} temp={temperature:.3f}")
    
    return best_a, best_score

def interpolate_seq(f, new_n):
    """Interpolate a sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp

def init_fourier(n, rng, n_modes=4):
    """Initialize using Fourier modes to create aperiodic-like structure."""
    t = np.arange(n)
    a = np.ones(n)
    for j in range(n_modes):
        freq = rng.uniform(1, n // 2)
        amp = rng.uniform(0.1, 0.5)
        phase = rng.uniform(0, 2 * np.pi)
        a += amp * np.cos(2 * np.pi * freq * t / n + phase)
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s

def init_bimodal(n, rng):
    """Bimodal initialization."""
    c1 = n * rng.uniform(0.15, 0.35)
    c2 = n * rng.uniform(0.65, 0.85)
    w1 = n * rng.uniform(0.05, 0.15)
    w2 = n * rng.uniform(0.05, 0.15)
    t = np.arange(n)
    a = np.exp(-0.5 * ((t - c1) / w1) ** 2) + np.exp(-0.5 * ((t - c2) / w2) ** 2)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s

def init_golden_ratio(n, rng):
    """Initialize based on golden ratio spacing (quasi-aperiodic)."""
    phi = (1 + np.sqrt(5)) / 2
    t = np.arange(n)
    # Use fractional parts of golden ratio multiples
    positions = (t * phi) % 1.0
    # Create a smooth function of positions
    a = 1.0 + 0.3 * np.sin(2 * np.pi * positions) + 0.2 * np.cos(4 * np.pi * positions)
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s

def check_and_update(a, best_seq, best_score, label=""):

"""

import numpy as np
from scipy.fft import rfft, irfft
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def simplex_project(v):
    """Project vector v onto the probability simplex."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if cond.any():
        rho = np.nonzero(cond)[0][-1]
        theta = (cssv[rho] - 1.0) / (rho + 1.0)
        return np.maximum(v - theta, 0.0)
    else:
        return np.ones(n) / n


def compute_smooth_gradient(a, conv, beta):
    """
    Compute the smooth gradient of log-sum-exp approximation of max(conv).
    grad[i] = sum_k w_k * (a[k-i] + a[2i-k]) with bounds.
    """
    n = len(a)
    M = conv.max()
    scaled = beta * (conv - M)
    scaled = np.clip(scaled, -60, 0)
    weights = np.exp(scaled)
    Z = weights.sum()
    if Z < 1e-30:
        weights = np.zeros_like(conv)
        weights[conv.argmax()] = 1.0
        Z = 1.0
    weights = weights / Z

    grad = np.zeros(n)
    # Only process significant weights for efficiency
    threshold = 1e-10
    active = weights > threshold
    for k in np.where(active)[0]:
        w = weights[k]
        i_start = max(0, k - n + 1)
        i_end = min(n - 1, k)
        i_range = np.arange(i_start, i_end + 1)
        j_range = k - i_range
        # Contribution: w * a[k-i] for the "forward" part
        grad[i_range] += w * a[j_range]
        # For the "backward" part: w * a[2i-k]
        # 2i-k is valid when 0 <= 2i-k < n, i.e., k/2 <= i < (k+n)/2
        i2_start = max(0, (k + 1) // 2) if k % 2 == 0 else max(0, k // 2 + 1)
        i2_start = max(i_start, (k) // 2)
        i2_end = min(n - 1, (k + n - 1) // 2)
        i2_end = min(i_end, (k + n - 1) // 2)
        if i2_start <= i2_end:
            i2_range = np.arange(i2_start, i2_end + 1)
            j2_range = 2 * i2_range - k
            valid = (j2_range >= 0) & (j2_range < n)
            if valid.any():
                grad[i2_range[valid]] += w * a[j2_range[valid]]

    return grad


def nesterov_mirror_descent(a0, time_limit, lr_init=0.01, beta_init=30.0, label=""):
    """
    Nesterov-accelerated mirror descent with smooth max approximation.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    y = a.copy()
    best_a = a.copy()
    conv = fast_convolve(a)
    best_score = 2.0 * n * conv.max()
    t0 = time.monotonic()
    it = 0
    lr = lr_init
    beta = beta_init
    no_improve = 0
    gamma = 1.0

    while time.monotonic() - t0 < time_limit:
        it += 1

        if it == 1:
            y = a.copy()
        else:
            y = (1.0 + gamma) * a - gamma * y

        y_proj = simplex_project(y)
        conv_y = fast_convolve(y_proj)

        # Smooth gradient
        grad = compute_smooth_gradient(y_proj, conv_y, beta)

        # Mirror descent update
        log_a = np.log(a + 1e-30)
        log_a -= lr * grad
        a_new = np.exp(log_a - log_a.max())
        a = simplex_project(a_new)

        # Evaluate
        conv = fast_convolve(a)
        score = 2.0 * n * conv.max()
        if score < best_score - 1e-14:
            best_score = score
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1

        # Adaptive params
        if no_improve > 200:
            lr *= 0.9
            beta *= 1.3
            no_improve = 0
            if lr < 1e-10:
                break
        elif it % 50 == 0:
            beta *= 1.02

        gamma = (1.0 + np.sqrt(1.0 + 4.0 * gamma * gamma)) / 2.0

    return best_a, best_score


def fast_coord_descent(a0, time_limit, label="", verbose=False):
    """
    Fast coordinate descent trying multiple delta values per coordinate.
    Only accepts improvements.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    conv = fast_convolve(a)
    M = float(conv.max())
    sum_a = 1.0
    best_a = a.copy()
    best_score = 2.0 * n * M
    t0 = time.monotonic()
    sweeps = 0
    no_improve = 0

    while time.monotonic() - t0 < time_limit:
        sweeps += 1
        improved = False

        for i in range(n):
            if a[i] < 1e-15:
                continue

            k_start = i
            k_end = min(i + n - 1, 2 * n - 2)

            unaff_max = -1e30
            if k_start > 0:
                unaff_max = max(unaff_max, float(conv[:k_start].max()))
            if k_end < 2 * n - 2:
                unaff_max = max(unaff_max, float(conv[k_end + 1:].max()))

            affected = conv[k_start:k_end + 1]
            a_shifted = a[0:n]
            a_i = a[i]

            best_delta = 0.0
            best_new_max = M

            # Try a range of deltas
            deltas = np.concatenate([
                np.array([-0.9, -0.7, -0.5, -0.3, -0.15, -0.05, -0.02, -0.01]),
                np.array([0.02, 0.05, 0.1, 0.2, 0.3, 0.5, 0.8, 1.0, 1.5, 2.0])
            ]) * a_i

            for delta in deltas:
                new_val = a_i + delta
                if new_val < -1e-15 or new_val > 1.0:
                    continue

                new_affected = affected + 2.0 * delta * a_shifted
                if 2 * i >= k_start and 2 * i <= k_end:
                    idx_2i = 2 * i - k_start
                    new_affected = new_affected.copy()
                    new_affected[idx_2i] = conv[2 * i] + 2.0 * delta * a_i + delta * delta
                else:
                    new_affected = new_affected.copy()

                new_max = max(unaff_max, float(new_affected.max()))
                if new_max < best_new_max - 1e-16:
                    best_new_max = new_max
                    best_delta = delta

            if best_delta != 0.0 and best_new_max < M - 1e-15:
                a[i] = max(a_i + best_delta, 0.0)
                sum_a = a.sum()

                changes = 2.0 * best_delta * a_shifted.copy()
                if 2 * i >= k_start and 2 * i <= k_end:
                    idx_2i = 2 * i - k_start
                    changes[idx_2i] = 2.0 * best_delta * (a_i) + best_delta * best_delta
                conv[k_start:k_end + 1] += changes
                M = max(unaff_max, float(conv[k_start:k_end + 1].max()))

                cur_score = 2.0 * n * M / (sum_a * sum_a)
                if cur_score < best_score - 1e-14:
                    best_score = cur_score
                    best_a = a.copy()
                improved = True

        if not improved:
            no_improve += 1
            if no_improve > 100:
                break
        else:
            no_improve = 0

        if verbose and sweeps % 20 == 0:
            elapsed = time.monotonic() - t0
            print(f"    FCD {label} sweep={sweeps} ({elapsed:.0f}s): best={best_score:.6f} M={M:.10f}")

    return best_a, best_score, sweeps


def annealed_cd(a0, time_limit, label="", initial_temp=2.0, cooling=0.9995, verbose=False):
    """
    Coordinate descent with simulated annealing.
    Accepts worse moves with probability based on temperature.
    """
    n = len(a0)
    rng = np.random.default_rng(int(hash(label) % 10000) + 42)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    conv = fast_convolve(a)
    M = float(conv.max())
    sum_a = 1.0
    best_a = a.copy()
    best_score = 2.0 * n * M
    t0 = time.monotonic()
    sweeps = 0
    temperature = initial_temp

    while time.monotonic() - t0 < time_limit:
        sweeps += 1
        improved = False

        for i in range(n):
            if a[i] < 1e-15:
                continue

            k_start = i
            k_end = min(i + n - 1, 2 * n - 2)

            unaff_max = -1e30
            if k_start > 0:
                unaff_max = max(unaff_max, float(conv[:k_start].max()))
            if k_end < 2 * n - 2:
                unaff_max = max(unaff_max, float(conv[k_end + 1:].max()))

            affected = conv[k_start:k_end + 1]
            a_shifted = a[0:n]
            a_i = a[i]

            best_delta = 0.0
            best_new_max = M

            # Deterministic candidates
            for factor in [0.5, 0.7, 0.85, 0.95, 1.05, 1.15, 1.3, 1.5, 2.0, 3.0]:
                delta = a_i * (factor - 1.0)
                new_val = a_i + delta
                if new_val < -1e-15 or new_val > 1.0:
                    continue

                new_affected = affected + 2.0 * delta * a_shifted.copy()
                if 2 * i >= k_start and 2 * i <= k_end:
                    idx_2i = 2 * i - k_start
                    new_affected[idx_2i] = conv[2 * i] + 2.0 * delta * a_i + delta * delta

                new_max = max(unaff_max, float(new_affected.max()))
                if new_max < best_new_max - 1e-16:
                    best_new_max = new_max
                    best_delta = delta

            # Random perturbation (annealing exploration)
            if temperature > 0.5:
                random_delta = rng.standard_normal() * a_i * 0.5
                new_val = a_i + random_delta
                if 0 <= new_val <= 1.0:
                    new_affected = affected + 2.0 * random_delta * a_shifted.copy()
                    if 2 * i >= k_start and 2 * i <= k_end:
                        idx_2i = 2 * i - k_start
                        new_affected[idx_2i] = conv[2 * i] + 2.0 * random_delta * a_i + random_delta * random_delta
                    new_max = max(unaff_max, float(new_affected.max()))

                    if new_max < best_new_max:
                        best_new_max = new_max
                        best_delta = random_delta
                    else:
                        # Annealing acceptance
                        delta_score = (new_max - best_new_max) * n / max(temperature, 0.1)
                        if delta_score < 40 and rng.random() < np.exp(-delta_score):
                            best_new_max = new_max
                            best_delta = random_delta

            if best_delta != 0.0:
                new_val = a_i + best_delta
                if new_val < 0 or new_val > 1.0:
                    continue

                a[i] = new_val
                sum_a = a.sum()

                changes = 2.0 * best_delta * a_shifted.copy()
                if 2 * i >= k_start and 2 * i <= k_end:
                    idx_2i = 2 * i - k_start
                    changes[idx_2i] = 2.0 * best_delta * a_i + best_delta * best_delta
                conv[k_start:k_end + 1] += changes
                M = max(unaff_max, float(conv[k_start:k_end + 1].max()))

                cur_score = 2.0 * n * M / (sum_a * sum_a)
                if cur_score < best_score - 1e-14:
                    best_score = cur_score
                    best_a = a.copy()
                improved = True

        temperature *= cooling

        if not improved and temperature < 0.3:
            if sweeps % 500 == 0:
                temperature = 1.0  # Reheat
            elif sweeps > 200 and not improved:
                # Try a larger reheat less frequently
                if rng.random() < 0.1:
                    temperature = 1.5

        if verbose and sweeps % 50 == 0:
            elapsed = time.monotonic() - t0
            print(f"    ACD {label} sweep={sweeps} ({elapsed:.0f}s): best={best_score:.6f} temp={temperature:.3f}")

    return best_a, best_score, sweeps


def multiplicative_annealing(a0, time_limit, label="", lr_init=0.01, beta_init=20.0):
    """
    Global multiplicative updates with annealing acceptance.
    Uses peak damage to compute update direction.
    """
    n = len(a0)
    rng = np.random.default_rng(777)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    conv = fast_convolve(a)
    best_a = a.copy()
    best_score = 2.0 * n * conv.max()
    t0 = time.monotonic()
    it = 0
    lr = lr_init
    beta = beta_init
    temperature = 1.0
    momentum = np.zeros(n)
    mom_beta = 0.8

    while time.monotonic() - t0 < time_limit:
        it += 1

        # Compute peak damage
        M = conv.max()
        k_peaks = max(5, n // 20)
        top_idx = np.argpartition(conv, -k_peaks)[-k_peaks:]

        damage = np.zeros(n)
        for k in top_idx:
            w = (conv[k] / M) ** 8  # Very sharp focus on top peaks
            i_start = max(0, k - n + 1)
            i_end = min(n - 1, k)
            i_range = np.arange(i_start, i_end + 1)
            j_range = k - i_range
            damage[i_range] += w * a[j_range]

        d_max = damage.max()
        if d_max < 1e-30:
            break
        damage_norm = damage / d_max

        # Momentum
        momentum = mom_beta * momentum + (1 - mom_beta) * damage_norm

        # Multiplicative update
        log_a = np.log(a + 1e-30)
        log_a -= lr * momentum
        a_new = np.exp(log_a - log_a.max())
        a_new = simplex_project(a_new)

        conv_new = fast_convolve(a_new)
        score_new = 2.0 * n * conv_new.max()

        if score_new < best_score:
            best_score = score_new
            best_a = a_new.copy()
            a = a_new
            conv = conv_new
        else:
            # Annealing acceptance
            delta = (score_new - best_score) * n / max(temperature, 0.05)
            if delta < 40 and rng.random() < np.exp(-delta):
                a = a_new
                conv = conv_new

        temperature *= 0.999
        if temperature < 0.1:
            temperature = 0.1

        if it % 100 == 0:
            lr *= 0.95
            beta *= 1.05

        if lr < 1e-12:
            break

    return best_a, best_score


def interpolate_seq(f, new_n):
    """Interpolate a sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp


def init_bimodal(n, rng):
    """Bimodal Gaussian initialization."""
    c1 = n * rng.uniform(0.15, 0.35)
    c2 = n * rng.uniform(0.65, 0.85)
    w1 = n * rng.uniform(0.05, 0.15)
    w2 = n * rng.uniform(0.05, 0.15)
    t = np.arange(n)
    a = np.exp(-0.5 * ((t - c1) / w1) ** 2) + np.exp(-0.5 * ((t - c2) / w2) ** 2)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s


def init_fourier(n, rng, n_modes=5):
    """Fourier series initialization."""
    t = np.arange(n)
    a = np.ones(n)
    for j in range(n_modes):
        freq = rng.uniform(1, n // 3)
        amp = rng.uniform(0.1, 0.5)
        phase = rng.uniform(0, 2 * np.pi)
        a += amp * np.cos(2 * np.pi * freq * t / n + phase)
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s


def init_tridiagonal(n, rng):
    """Initialize based on spreading mass to reduce convolution peaks."""
    # Start with uniform and apply a few rounds of "diffusion"
    a = np.ones(n) / n
    sigma = n * rng.uniform(0.1, 0.3)
    t = np.arange(n)
    # Apply a circular Gaussian smoothing
    kernel = np.exp(-0.5 * ((t - n // 2) / sigma) ** 2)
    kernel = kernel / kernel.sum()
    # Circular convolution
    from scipy.signal import fftconvolve
    a = fftconvolve(a, kernel, mode='same')
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s


def peak_targeted_perturb(a0, rng, strength=0.05):
    """Perturb by reducing high-convolution-contribution coordinates."""
    n = len(a0)
    a = a0.copy()
    conv = fast_convolve(a)
    M = conv.max()

    # Find peak positions
    peak_thresh = M * 0.9
    peak_positions = np.where(conv >= peak_thresh)[0]

    # Compute pressure
    pressure = np.zeros(n)
    for k in peak_positions:
        i_start = max(0, k - n + 1)
        i_end = min(n - 1, k)
        for i in range(i_start, i_end + 1):
            j = k - i
            product = a[i] * a[j]
            pressure[i] += product
            if j != i:
                pressure[j] += product * 0.5

    p_max = pressure.max()
    if p_max > 1e-20:
        pressure = pressure / p_max
        noise = rng.standard_normal(n)
        a_new = a * (1.0 - strength * pressure + 0.3 * strength * noise)
        a_new = np.maximum(a_new, 0)
        s = a_new.sum()
        if s > 1e-15:
            return a_new / s
    return a.copy()

        rem = deadline - time.monotonic() - 800
        if rem > 30:
            t_md = min(rem * 0.5, 200.0)
            print(f"  NMD n={len(best_seq)}, budget={t_md:.0f}s")
            a_md, s_md = nesterov_mirror_descent(best_seq, t_md, lr_init=0.01, beta_init=25.0, label="nmd1")
            best_seq, best_score = check_and_update(a_md, best_seq, best_score, "nmd_main")

            # Second round with different params
            rem = deadline - time.monotonic() - 700
            if rem > 20:
                a_md2, s_md2 = nesterov_mirror_descent(best_seq, min(rem * 0.4, 100.0),
                                                        lr_init=0.005, beta_init=50.0, label="nmd2")
                best_seq, best_score = check_and_update(a_md2, best_seq, best_score, "nmd_fast")

    # === Phase 3: Annealed CD ===
    print(f"\n=== Phase 3: Annealed CD (best={best_score:.6f}) ===")
    if best_seq is not None:
        current = best_seq.copy()
        for rnd in range(4):
            rem = deadline - time.monotonic() - 500
            if rem < 30:
                break
            t_alloc = min(rem * 0.3, 120.0)
            print(f"  ACD round {rnd+1}/4, n={len(current)}, budget={t_alloc:.0f}s, score={best_score:.6f}")
            a_opt, s_opt, _ = annealed_cd(current, t_alloc, label=f"acdr{rnd}",
                                           initial_temp=1.5 - 0.2 * rnd, cooling=0.9997, verbose=True)
            best_seq, best_score = check_and_update(a_opt, best_seq, best_score, f"acd_r{rnd}")

                # Perturb for exploration

            else:

    if best_seq is not None:
        rem = deadline - time.monotonic() - 300
        if rem > 30:
            t_ma = min(rem * 0.4, 120.0)
            print(f"  MA n={len(best_seq)}, budget={t_ma:.0f}s")
            a_ma, s_ma = multiplicative_annealing(best_seq, t_ma, label="ma1")
            best_seq, best_score = check_and_update(a_ma, best_seq, best_score, "ma_main")

            rem = deadline - time.monotonic() - 200
            if rem > 20:
                a_ma2, s_ma2 = multiplicative_annealing(best_seq, min(rem * 0.4, 80.0),
                                                         label="ma2", lr_init=0.02, beta_init=40.0)
                best_seq, best_score = check_and_update(a_ma2, best_seq, best_score, "ma_fast")

    # === Phase 5: Intensive CD Polishing ===
    print(f"\n=== Phase 5: Intensive CD (best={best_score:.6f}) ===")
    if best_seq is not None:
        rem = deadline - time.monotonic() - 150
        if rem > 30:
            t_cd = min(rem * 0.5, 150.0)
            print(f"  FCD polish n={len(best_seq)}, budget={t_cd:.0f}s")
            a_fine, s_fine, _ = fast_coord_descent(best_seq, t_cd, label="polish1", verbose=True)
            best_seq, best_score = check_and_update(a_fine, best_seq, best_score, "polish_1")

        rem = deadline - time.monotonic() - 80
        if rem > 20:
            a_f2, s_f2, _ = fast_coord_descent(best_seq, min(rem * 0.5, 60.0), label="polish2")
            best_seq, best_score = check_and_update(a_f2, best_seq, best_score, "polish_2")

    # === Phase 6: Multi-length exploration ===
    print(f"\n=== Phase 6: Multi-length (best={best_score:.6f}) ===")
    if best_seq is not None:
        n_best = len(best_seq)
        alt_lengths = sorted(set([n_best + 256, n_best + 512, n_best - 256, 2048, 1536, 1280]))
        alt_lengths = [x for x in alt_lengths if 512 <= x <= 4096]

        for alt_n in alt_lengths[:4]:
            rem = deadline - time.monotonic() - 50
            if rem < 25:
                break
            t_alt = min(rem * 0.4, 60.0)
            if t_alt < 10:
                break
            init_alt = interpolate_seq(best_seq, alt_n)
            a_alt, s_alt, _ = fast_coord_descent(init_alt
