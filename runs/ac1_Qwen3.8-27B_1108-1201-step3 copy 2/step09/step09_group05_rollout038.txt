Now let me think about the overall algorithm:

**Algorithm: Fast Mirror Descent + GS + L-BFGS polish**

Phase 1: Fast Mirror Descent (many iterations, O(n^2) per iter but fast constants)
- Start from parent
- Iteratively: compute b, compute soft weights w, compute gradient g, update in log-space
- Adaptive temperature (start high, decrease)
- Goal: get close to the optimum

Phase 2: Gerchberg-Saxton frequency domain method
- Start from Phase 1 result
- Iteratively: FFT, flatten spectrum (for m != 0), IFFT, project to non-negative
- This exploits the frequency domain structure

    return irfft(A * A, fft_size)[:size]

def fast_grad(a, w):
    n = len(a)
    N = 1 << (3 * n - 1).bit_length()
    W = rfft(w, N)
    Ar = rfft(a[::-1], N)
    conv = irfft(W * Ar, N)
    return 2.0 * conv[n-1:2*n-1]

def norm_sequence(a):
    a = np.maximum(a, 0).astype(np.float64)
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s
