This is a feasibility problem for a given M. We can binary search on M to find the minimum feasible value.

For a given M, the feasibility problem is:
Does there exist a >= 0, sum(a) = 1, such that (a*a)[k] <= M for all k?

This is a set of quadratic constraints, which is nonconvex. So binary search doesn't directly help.

However, we can use the LP relaxation:
For a given M, does there exist b >= 0 such that (a*b)[k] <= M for all k and sum(b) > 1?

If the answer is yes for all a with sum(a) = 1, then M is feasible. If there exists a with sum(a) = 1 such that the LP gives sum(b) <= 1 for all b with (a*b) <= M, then M is not feasible.

This is exactly the game-theoretic formulation. The value M* is the minimax value.

def local_search(a0, time_limit, seed=42):

                a = best_trial
                best_score = best_trial_score
                best_a = a.copy()

                stall = 0
                break

            # Random perturbation
