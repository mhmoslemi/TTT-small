Actually, one more important insight: the LP constraint matrix T has T[k,j] = a[j] if 0 <= k-j < n, else 0. This is a "sliding window" matrix. For the LP:
maximize sum(b) subject to T @ b <= M, b >= 0

The dual is:
minimize M * sum(lam) subject to T^T @ lam >= 1, lam >= 0

Where lam has length 2n-1. The dual has 2n-1 variables and n constraints. This might be easier to solve!

T^T @ lam >= 1 means: for each j, sum_k T[k,j] * lam[k] >= 1
T[k,j] = a[j] if 0 <= k-j < n
So: sum_{k=j}^{j+n-1} a[j] * lam[k] >= 1
i.e., a[j] * sum_{k=j}^{j+n-1} lam[k] >= 1
i.e., sum_{k=j}^{j+n-1} lam[k] >= 1/a[j] (for a[j] > 0)

So the dual is:
minimize M * sum(lam)
subject to sum_{k=j}^{j+n-1} lam[k] >= 1/a[j] for all j with a[j] > 0
and lam >= 0

This is a much simpler LP! The constraint matrix is a "moving sum" matrix, which is very structured. Each constraint is just a sum of consecutive elements of lam.

This can be solved very efficiently! In fact, the optimal solution to this LP has a known structure.

Let me think about this. The dual has variables lam_0, ..., lam_{2n-2} (length 2n-1) and constraints:
For j=0: lam_0 + lam_1 + ... + lam_{n-1} >= 1/a_0
For j=1: lam_1 + lam_2 + ... + lam_n >= 1/a_1
...
For j=n-1: lam_{n-1} + ... + lam_{2n-2} >= 1/a_{n-1}
And lam_k >= 0 for all k.

The objective is to minimize M * (lam_0 + lam_1 + ... + lam_{2n-2}).

By strong duality, the optimal value of the primal = optimal value of the dual.
