Let me also think about the optimization more carefully.

The objective is f(a) = max_k (a*a)_k, and we want to minimize it (with the constraint sum a_i = 1, a_i >= 0).

The subgradient of f at a is: for each peak index k*, the subgradient component at a_i is:
∂f/∂a_i = a_{k*-i} + a_{i-k*} (with appropriate bounds)

If there are multiple peak indices, we average the subgradients (or use a convex combination).

**Frank-Wolfe (Conditional Gradient) method**:
- At each step, compute the subgradient g
- Find the vertex v of the simplex (sum a_i = 1, a_i >= 0) that minimizes <g, v>
  - This is v = e_j where j = argmin_i g_i (put all mass on the component with smallest subgradient)
- Update: a ← (1-γ_t) a + γ_t v, where γ_t = 2/(t+2)

This is essentially what the previous `subgrad_fw` function does! But it uses the single peak index. If we use a soft-max or average over multiple peaks, it might be better.

**Multiplicative Weights Update (MWU)**:
- a_i ← a_i * exp(-η * g_i) / Z
- This is a smooth version that keeps all components positive

For the MWU, the update is:
a_i_new = a_i * exp(-η * g_i) / sum_j a_j * exp(-η * g_j)

where g_i is the subgradient component.

This is essentially the "exponential clearing" or "mirror descent" with the negative entropy potential.
