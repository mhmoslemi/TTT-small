Actually, the standard Nesterov acceleration for the best-response method is:
- alpha_t = 2/(t+2)
- a_{t+1} = (1 + beta_t) * y_{t+1} - beta_t * y_t where beta_t = (t-1)/(t+2)

Which simplifies to: a_{t+1} = y_{t+1} + beta_t * (y_{t+1} - y_t)

This is what the previous code does.

The key question is: how many iterations do we need? For the LP best-response with Nesterov, convergence is O(1/t^2) in terms of the gap to the optimum. To get a 0.1% improvement, we might need a few hundred iterations.

Each LP solve takes ~1-2 seconds, so 500 iterations would take 500-1000 seconds. This is tight but feasible.

To speed things up, I can:
1. Use constraint screening to reduce the LP size
2. Use a warm-start (try to pass the previous solution as a hint)
3. Stop early if the improvement is negligible

Let me also think about the **pair CD** more carefully. The previous code's pair CD is O(n^2) per pass (for each i, try multiple j's). For n=1600, that's 2.5 million pairs per pass, which is too slow.

Instead, I can:
1. For each i, only try a few j's (e.g., 5-10 random + a few structured choices)
2. Or, for each i, find the j that gives the most improvement (using a greedy heuristic)

Actually, the previous code tries about 13 j's per i (8 random + 5 structured), so it's about 13*n = 20800 evaluations per pass. Each evaluation involves computing the gain vector g[k] (O(n) work) and finding the optimal delta (O(n) work). So each pass is about 20800 * 3200 = 67 million operations. In Python with NumPy, this might take 30-60 seconds per pass. That's reasonable.

But wait, the previous code recomputes the full convolution at the start of each i iteration, which is wasteful. Let me optimize this.

Actually, looking at the previous code more carefully, it does compute `conv = fast_conv_self(a)` inside the inner loop, which is very wasteful. Let me fix this.

Here's my optimized pair CD:
```
For each pass:
    Compute conv = fast_conv_self(a) once
    For each i (in random order):
        For each candidate j:
            Compute g[k] = a[k-j] + a[j-k] - a[k-i] - a[i-k]  (O(n))
            Find optimal delta (O(n))
            If improvement, update a and conv
```

The key optimization is to update `conv` incrementally instead of recomputing it:
When we transfer delta from i to j:
conv_new[k] = conv_old[k] + delta * g[k] + delta^2 * h[k]

Since h[k] is sparse, this is O(n) to update.

OK, let me write the final code now. I'll make it as efficient as possible while keeping it clean.

One more thing: I should also try **single coordinate descent** where I optimize one coordinate at a time (choosing the best partner to transfer to). This is simpler and might be faster for the final polish.

Actually, for the final polish, the most effective approach is probably:
1. Compute the gradient of the max-convolution (using the subgradient: pick the argmax position)
2. Do a projected gradient step
3. Repeat

This is simple and effective for fine-tuning.

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. LP best-response with HiGHS + Nesterov acceleration + constraint screening
2. Efficient pair coordinate descent with incremental convolution updates
3. Multi-restart with different initializations and lengths
4. Gradient-based polish for final refinement
"""

import numpy as np
import time
from scipy.fft import rfft, irfft
from scipy.optimize import linprog

def fast_conv_self(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]

def fast_conv_cross(a, b):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    B = rfft(b, fft_size)
    return irfft(A * B, fft_size)[:size]

def eval_fn(a):
    try:
        a_list = [float(x) for x in np.asarray(a, dtype=np.float64)]
        sc = evaluate_sequence(a_list)
        return float(sc)
    except Exception:
        return float('inf')

def get_active_constraints(conv, M, threshold_frac=0.9):
    """Get indices where conv is close to M."""
    if threshold_frac >= 1.0:
        return np.where(conv >= M * 0.999)[0]
    return np.where(conv >= M * threshold_frac)[0]

def lp_best_response(a, M, active=None, time_limit=10.0):
    """Solve LP: max sum(b) s.t. conv(a,b) <= M, b >= 0."""
    n = len(a)
    size = 2 * n - 1
    
    if active is None or len(active) >= size:
        active = np.arange(size)
    
    # Build constraint matrix
    m = len(active)
    A_ub = np.zeros((m, n))
    for row, k in enumerate(active):
        lo = max(0, k - n + 1)
        hi = min(n, k + 1)
        if hi > lo:
            A_ub[row, lo:hi] = a[k - np.arange(lo, hi)]
    
    c = -np.ones(n)
    b_ub = np.full(m, M)
    
    t0 = time.monotonic()
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, 
                     bounds=[(0, None)] * n,
                     method='highs',
                     options={'time_limit': time_limit, 'presolve': True})
        if res.success:
            return np.maximum(res.x, 0.0)
    except Exception:
        pass
    
    # Try without presolve
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub,
                     bounds=[(0, None)] * n,
                     method='highs',
                     options={'time_limit': time_limit, 'presolve': False})
        if res.success:
            return np.maximum(res.x, 0.0)
    except Exception:
        pass
    
    return None

def nesterov_lp(a0, time_budget, verbose=True):
    """Nesterov-accelerated LP best-response iteration."""
    n = len(a0)
    target_sum = 1.0  # normalize to sum=1
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n)
    a = a / s  # normalize to sum 1
    
    best_a = a.copy()
    best_conv = fast_conv_self(a)
    best_max = best_conv.max()
    t0 = time.monotonic()
    
    y = a.copy()
    
    for t in range(1, 10000):
        if time.monotonic() - t0 > time_budget - 5:
            break
        
        # Compute M for current y
        conv_y = fast_conv_self(y)
        M = conv_y.max()
        if M < 1e-12:
            break
        
        # Screen constraints
        active = np.where(conv_y >= M * 0.85)[0]
        if len(active) < 10:
            active = np.where(conv_y >= M * 0.5)[0]
        
        # Solve LP
        b = lp_best_response(y, M, active)
        if b is None:
            # Try with more constraints
            active = np.where(conv_y >= M * 0.7)[0]
            b = lp_best_response(y, M, active)
        if b is None:
            b = lp_best_response(y, M, None)
        if b is None:
            continue
        
        b_sum = b.sum()
        if b_sum < 1e-15:
            continue
        g = b / b_sum * target_sum  # normalize to target_sum
        
        # Check if dropped constraints are violated
        if len(active) < 2 * n - 1:
            check = fast_conv_cross(y, g)
            violated = check > M * (1 + 1e-6)
            if violated.any():
                violated_idx = np.where(violated)[0]
                new_active = np.union1d(active, violated_idx)
                b2 = lp_best_response(y, M, new_active)
                if b2 is not None:
                    b = b2
                    b_sum = b.sum()
                    if b_sum > 1e-15:
                        g = b / b_sum * target_sum
        
        # Nesterov update
        alpha = 2.0 / (t + 2.0)
        y_new = (1.0 - alpha) * y + alpha * g
        y_new = np.maximum(y_new, 0.0)
        s_y = y_new.sum()
        if s_y < 1e-15:
            y_new = y.copy()
        else:
            y_new = y_new * target_sum / s_y
        
        if t == 1:
            a_new = g.copy()
        else:
            momentum = (t - 1.0) / (t + 2.0)
            a_new = y_new + momentum * (y_new - y)
            a_new = np.maximum(a_new, 0.0)
            s_a = a_new.sum()
            if s_a < 1e-15:
                a_new = y_new.copy()
            else:
                a_new = a_new * target_sum / s_a
        
        y = y_new
        a = a_new
        
        # Track best
        sc_y = fast_conv_self(y).max()
        if sc_y < best_max:
            best_max = sc_y
            best_a = y.copy()
        
        sc_a = fast_conv_self(a).max()
        if sc_a < best_max:
            best_max = sc_a
            best_a = a.copy()
        
        if verbose and t % 20 == 0:
            elapsed = time.monotonic() - t0
            print(f"    LP Nesterov t={t} ({elapsed:.0f}s): max_conv={best_max:.10f}")
    
    return best_a, best_max

def pair_cd(a0, time_budget, rng, verbose=True):
    """Pair coordinate descent with efficient updates."""
    n = len(a0)
    target_sum = 1.0
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return a, float('inf')
    a = a / s
    
    best_a = a.copy()
    conv = fast_conv_self(a)
    best_max = conv.max()
    t0 = time.monotonic()
    size = 2 * n - 1
    no_improve = 0
    
    while time.monotonic() - t0 < time_budget - 5:
        perm = rng.permutation(n)
        pass_improved = False
        
        for idx in range(n):
            if time.monotonic() - t0 > time_budget - 5:
                break
            i = perm[idx]
            ai = a[i]
            if ai < 1e-10:
                continue
            
            # Generate candidate j's
            j_candidates = set()
            # Random
            for _ in range(6):
                j_candidates.add(int(rng.integers(n)))
            # Structured: based on convolution peaks
            peak_idx = np.where(conv >= best_max * 0.95)[0]
            for pk in peak_idx[:3]:
                # Moving mass from i to j where j = pk - i or j = pk + i might help
                j1 = (pk - i) % n  # not quite right for linear conv
                j1 = pk - i
                if 0 <= j1 < n and j1 != i:
                    j_candidates.add(j1)
                j2 = pk + i
                if 0 <= j2 < n and j2 != i:
                    j_candidates.add(j2)
            
            j_candidates.discard(i)
            
            best_delta = 0.0
            best_score = best_max
            best_j = -1
            
            for j in j_candidates:
                aj = a[j]
                
                # Compute gain vector g[k]
                # g[k] = a[k-j] + a[j-k] - a[k-i] - a[i-k]
                g = np.zeros(size)
                
                # a[k-j]: valid for k in [j, j+n-1]
                lo = j
                hi = min(size, j + n)
                if hi > lo:
                    g[lo:hi] += a[:hi-lo]
                
                # a[j-k]: valid for k in [max(0, j-n+1), j]
                lo2 = max(0, j - n + 1)
                hi2 = j + 1
                if hi2 > lo2:
                    g[lo2:hi2] += a[j - np.arange(lo2, hi2)]
                
                # -a[k-i]: valid for k in [i, i+n-1]
                lo3 = i
                hi3 = min(size, i + n)
                if hi3 > lo3:
                    g[lo3:hi3] -= a[:hi3-lo3]
                
                # -a[i-k]: valid for k in [max(0, i-n+1), i]
                lo4 = max(0, i - n + 1)
                hi4 = i + 1
                if hi4 > lo4:
                    g[lo4:hi4] -= a[i - np.arange(lo4, hi4)]
                
                # Find optimal delta in [0, ai]
                # conv_new[k] = conv[k] + delta * g[k]
                # (ignoring second-order for speed; it's tiny)
                # f(delta) = max_k (conv[k] + delta * g[k])
                # This is piecewise linear in delta, convex.
                # Minimum is where the max of the "ramps" is minimized.
                
                # Quick method: sample a few points
                n_samples = 20
                deltas = np.linspace(0, ai, n_samples + 1)[1:]
                
                best_d = 0.0
                for d in deltas:
                    new_conv = conv + d * g
                    # Add second-order correction at key positions
                    if 2*i < size:
                        new_conv[2*i] += d*d - 2*ai*d  # (ai-d)^2 - ai^2 = -2ai*d + d^2
                    if 2*j < size:
                        new_conv[2*j] += d*d + 2*aj*d  # (aj+d)^2 - aj^2 = 2aj*d + d^2
                    v = new_conv.max()
                    if v < best_score:
                        best_score = v
                        best_d = d
                
                if best_d > 0 and best_score < best_max - 1e-13:
                    best_delta = best_d
                    best_j = j
            
            if best_j >= 0 and best_delta > 0:
                a[i] -= best_delta
                a[best_j] += best_delta
                a = a * target_sum / a.sum()
                
                # Update conv incrementally
                # conv_new = conv + best_delta * g + best_delta^2 * h
                # But it's easier to just recompute for correctness
                conv = fast_conv_self(a)
                cur_max = conv.max()
                
                if cur_max < best_max - 1e-13:
                    best_max = cur_max
                    best_a = a.copy()
                    pass_improved = True
        
        if not pass_improved:
            no_improve += 1
            if no_improve >= 3:
                break
            # Perturb
            n_perturb = max(10, n // 20)
            idx_perturb = rng.choice(n, size=n_perturb, replace=False)
            a[idx_perturb] *= (1.0 + 0.05 * rng.standard_normal(n_perturb))
            a = np.maximum(a, 0.0)
            a = a * target_sum / a.sum()
            conv = fast_conv_self(a)
            best_max = conv.max()
            best_a = a.copy()
        else:
            no_improve = 0
        
        if verbose:
            elapsed = time.monotonic() - t0
            print(f"    CD pass ({elapsed:.0f}s): max_conv={best_max:.10f}")
    
    return best_a, best_max

def lse_gradient_descent(a0, time_budget, verbose=True):
    """Log-sum-exp smoothed gradient descent."""
    n = len(a0)
    target_sum = 1.0
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n)
    a = a / s
    
    best_a = a.copy()
    best_max = fast_conv_self(a).max()
    t0 = time.monotonic()
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    
    # Adaptive temperature
    temperatures = np.geomspace(20.0, 0.5, 15)
    
    for T_val in temperatures:
        if time.monotonic() - t0 > time_budget - 5:
            break
        remaining = time_budget - (time.monotonic() - t0)
        n_steps = max(10, min(100, int(remaining * 10)))
        
        for it in range(n_steps):
            if time.monotonic() - t0 > time_budget - 5:
                break
            
            conv = fast_conv_self(a)
            max_c = conv.max()
            
            # Soft-max weights
            shifted = (conv - max_c) / T_val
            shifted = np.maximum(shifted, -50.0)
            exp_c = np.exp(shifted)
            w = exp_c / exp_c.sum()
            
            # Gradient computation
            A = rfft(a, fft_size)
            W = rfft(w, fft_size)
            
            # d(conv[a,a])/da_i = 2 * sum_k w[k] * (a[k-i] + a[i-k])
            # First term: sum_k w[k] * a[k-i]
            g1 = irfft(np.conj(A) * W, fft_size)[:n]
            # Second term: sum_k w[k] * a[i-k] = conv(a,w)[i]
            g2 = irfft(A * W, fft_size)[:n]
            
            grad = 2.0 * (g1 + g2)
            
            # Gradient step with normalization
            lr = 1.0 / (T_val * np.sqrt(n))
            a_new = a - lr * grad
            a_new = np.maximum(a_new, 0.0)
            s_new = a_new.sum()
            if s_new > 1e-15:
                a_new = a_new * target_sum / s_new
                sc = fast_conv_self(a_new).max()
                if sc < max_c:
                    a = a_new
                    if sc < best_max:
                        best_max = sc
                        best_a = a.copy()
                else:
                    # Halve step
                    a_new = a - lr * 0.5 * grad
                    a_new = np.maximum(a_new, 0.0)
                    s_new = a_new.sum()
                    if s_new > 1e-15:
                        a_new = a_new * target_sum / s_new
                        sc = fast_conv_self(a_new).max()
                        if sc < max_c:
                            a = a_new
                            if sc < best_max:
                                best_max = sc
                                best_a = a.copy()
            
            if verbose and it % 50 == 0:
                elapsed = time.monotonic() - t0
                print(f"    LSE T={T_val:.1f} step {it} ({elapsed:.0f}s): {best_max:.10f}")
    
    return best_a, best_max

def structured_init(n, rng):
    choice = rng.integers(0, 6)
    x = np.linspace(0.0, 1.0, n)
    if choice == 0:
        a = np.sin(np.pi * x) ** 2
    elif choice == 1:
        a = np.exp(-6.0 * (x - 0.25)**2) + np.exp(-6.0 * (x - 0.75)**2)
    elif choice == 2:
        a = 0.5 + 0.3 * np.cos(4 * np.pi * x) + 0.2 * np.cos(8 * np.pi * x)
    elif choice == 3:
        a = (1.0 - np.abs(2.0*x - 1.0)) ** 2
    elif choice == 4:
        a = np.sin(np.pi * x) ** 0.8
    else:
        a = 0.4 + 0.4 * np.sin(np.pi * x) + 0.2 * np.sin(2*np.pi*x)**2
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s

def interpolate_seq(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss
```

```python
def fast_conv_self(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def fast_conv_cross(a, b):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    B = rfft(b, fft_size)
    return irfft(A * B, fft_size)[:size]

def build_T_active(a, active):

def lp_best_response(a, M, active=None, time_limit=8.0):

    size = 2 * n - 1

        return np.ones(n) / n

    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub,

    except Exception:

    return None


def nesterov_lp(a0, time_budget, verbose=True):
    n = len(a0)
    target_sum = 1.0
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n)
    a = a / s
    best_a = a.copy()
    best_conv = fast_conv_self(a)
    best_max = best_conv.max()
    t0 = time.monotonic()
    y = a.copy()
    size = 2 * n - 1
    for t in range(1, 5000):
        if time.monotonic() - t0 > time_budget - 5:
            break
        conv_y = fast_conv_self(y)
        M = conv_y.max()
        if M < 1e-12:
            break
        # Progressive screening
        frac = 0.90 if t < 50 else 0.85
        active = np.where(conv_y >= M * frac)[0]
        if len(active) < 10:
            active = np.where(conv_y >= M * 0.5)[0]
        b = lp_best_response(y, M, active)
        if b is None:
            active2 = np.where(conv_y >= M * 0.6)[0]
            b = lp_best_response(y, M, active2)
        if b is None:
            b = lp_best_response(y, M, None, time_limit=5.0)
        if b is None:
            continue
        b_sum = b.sum()
        if b_sum < 1e-15:
            continue
        g = b / b_sum * target_sum
        # Check dropped constraints
        if len(active) < size:
            check = fast_conv_cross(y, g)
            if check.max() > M * (1 + 1e-5):
                violated = np.where(check > M)[0]
                new_active = np.union1d(active, violated)
                b2 = lp_best_response(y, M, new_active)
                if b2 is not None:
                    b = b2
                    b_sum = b.sum()
                    if b_sum > 1e-15:
                        g = b / b_sum * target_sum
        # Nesterov update
        alpha = 2.0 / (t + 2.0)
        y_new = (1.0 - alpha) * y + alpha * g
        y_new = np.maximum(y_new, 0.0)
        s_y = y_new.sum()
        if s_y < 1e-15:
            y_new = y.copy()
        else:
            y_new = y_new * target_sum / s_y
        if t == 1:
            a_new = g.copy()
        else:
            momentum = (t - 1.0) / (t + 2.0)
            a_new = y_new + momentum * (y_new - y)
            a_new = np.maximum(a_new, 0.0)
            s_a = a_new.sum()
            if s_a < 1e-15:
                a_new = y_new.copy()
            else:
                a_new = a_new * target_sum / s_a
        y = y_new
        a = a_new
        sc_y = fast_conv_self(y).max()
        if sc_y < best_max:
            best_max = sc_y
            best_a = y.copy()
        sc_a = fast_conv_self(a).max()
        if sc_a < best_max:
            best_max = sc_a
            best_a = a.copy()
        if verbose and t % 30 == 0:
            elapsed = time.monotonic() - t0
            print(f"    LP Nesterov t={t} ({elapsed:.0f}s): max_conv={best_max:.10f}")
    return best_a, best_max


def lse_gradient_descent(a0, time_budget, verbose=True):
    n = len(a0)
    target_sum = 1.0
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n)
    a = a / s
    best_a = a.copy()
    best_max = fast_conv_self(a).max()
    t0 = time.monotonic()
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    temperatures = np.geomspace(30.0, 0.5, 20)
    for T_val in temperatures:
        if time.monotonic() - t0 > time_budget - 5:
            break
        remaining = time_budget - (time.monotonic() - t0)
        n_steps = max(10, min(80, int(remaining * 8)))
        for it in range(n_steps):
            if time.monotonic() - t0 > time_budget - 5:
                break
            conv = fast_conv_self(a)
            max_c = conv.max()
            shifted = (conv - max_c) / T_val
            shifted = np.maximum(shifted, -50.0)
            exp_c = np.exp(shifted)
            w = exp_c / exp_c.sum()
            A = rfft(a, fft_size)
            W = rfft(w, fft_size)
            g1 = irfft(np.conj(A) * W, fft_size)[:n]
            g2 = irfft(A * W, fft_size)[:n]
            grad = 2.0 * (g1 + g2)
            lr = 0.5 / (T_val * np.sqrt(n))
            for trial in range(8):
                a_new = a - lr * grad
                a_new = np.maximum(a_new, 0.0)
                s_new = a_new.sum()
                if s_new > 1e-15:
                    a_new = a_new * target_sum / s_new
                    sc = fast_conv_self(a_new).max()
                    if sc <= max_c + 0.05 * T_val:
                        break
                lr *= 0.5
            a_new = a - lr * grad
            a_new = np.maximum(a_new, 0.0)
            s_new = a_new.sum()
            if s_new > 1e-15:
                a_new = a_new * target_sum / s_new
                a = a_new
                sc = fast_conv_self(a).max()
                if sc < best_max:
                    best_max = sc
                    best_a = a.copy()
            if verbose and it % 40 == 0:
                elapsed = time.monotonic() - t0
                print(f"    LSE T={T_val:.1f} step={it} ({elapsed:.0f}s): {best_max:.10f}")
    return best_a, best_max


def pair_cd(a0, time_budget, rng, verbose=True):

    target_sum = 1.0
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)

    t0 = time.monotonic()
    size = 2 * n - 1
    no_improve = 0
    while time.monotonic() - t0 < time_budget - 5:
        perm = rng.permutation(n)
        pass_improved = False
        cur_conv = conv.copy()
        cur_max = cur_conv.max()
        for idx in range(n):
            if time.monotonic() - t0 > time_budget - 5:
                break
            i = perm[idx]
            ai = a[i]
            if ai < 1e-10:
                continue
            j_candidates = set()
            for _ in range(5):
                j_candidates.add(int(rng.integers(n)))
            peak_threshold = cur_max * 0.93
            peak_lags = np.where(cur_conv >= peak_threshold)[0]
            for pk in peak_lags[:4]:
                j1 = pk - i
                if 0 <= j1 < n and j1 != i:
                    j_candidates.add(j1)
                j2 = pk + i
                if 0 <= j2 < n and j2 != i:
                    j_candidates.add(j2)
                j3 = (pk // 2) if pk % 2 == 0 else (pk + 1) // 2
                if 0 <= j3 < n and j3 != i:
                    j_candidates.add(j3)
            j_candidates.discard(i)
            best_delta = 0.0
            best_val = cur_max
            best_j = -1
            for j in j_candidates:
                aj = a[j]
                g = np.zeros(size)
                lo = j
                hi = min(size, j + n)

                    g[lo:hi] += a[:hi - lo]
                lo2 = max(0, j - n + 1)
                hi2 = j + 1
                if hi2 > lo2:

                lo3 = i

                    v = new_conv_val.max()

                        best_j = j
            if best_j >= 0 and best_delta > 1e-12:
                a[i] -= best_delta
                a[best_j] += best_delta

                cur_max = cur_conv.max()
        else:
            no_improve = 0
        if verbose:
            elapsed = time.monotonic() - t0

def structured_init(n, rng):
    choice = rng.integers(0, 8)
    x = np.linspace(0.0, 1.0, n)
    if choice == 0:
        a = np.sin(np.pi * x) ** 2
    elif choice == 1:
        a = np.exp(-6.0 * (x - 0.25) ** 2) + 0.8 * np.exp(-6.0 * (x - 0.75) ** 2)
    elif choice == 2:
        a = 0.5 + 0.3 * np.cos(4 * np.pi * x) + 0.2 * np.cos(8 * np.pi * x)
    elif choice == 3:
        a = (1.0 - np.abs(2.0 * x - 1.0)) ** 2
    elif choice == 4:
        a = np.sin(np.pi * x) ** 0.6
    elif choice == 5:
        a = 0.3 + 0.5 * np.sin(np.pi * x) + 0.2 * np.cos(2 * np.pi * x) ** 2
    elif choice == 6:
        a = np.exp(-4.0 * (x - 0.5) ** 2) + 0.3
    else:
        a = 1.0 - 0.4 * (np.cos(2 * np.pi * x) + 0.3 * np.cos(4 * np.pi * x))
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:

    return a / s


def interpolate_seq(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss

        a_out, _ = lse_gradient_descent(results['seq'], t1, verbose=False)
        try_update(a_out, f"lse_n{n_base}")

    # Phase 2: LP Nesterov (main)
    remaining = time_budget - (time.monotonic() - t_global)
    t2 = min(remaining * 0.30, 500.0)
    print(f"\n=== Phase 2: LP Nesterov n={len(results['seq'])} (budget={t2:.0f}s) ===")
    if t2 > 30:
        a_out, _ = nesterov_lp(results['seq'], t2, verbose=True)
        try_update(a_out, f"lp_n{len(results['seq'])}")

    # Phase 3: Pair CD
    remaining = time_budget - (time.monotonic() - t_global)
    t3 = min(remaining * 0.15, 250.0)
    print(f"\n=== Phase 3: Pair CD n={len(results['seq'])} (budget={t3:.0f}s) ===")
    if t3 > 20:
        a_out, _ = pair_cd(results['seq'], t3, rng, verbose=True)
        try_update(a_out, f"cd_n{len(results['seq'])}")

    # Phase 4: LP Nesterov round 2
    remaining = time_budget - (time.monotonic() - t_global)
    t4 = min(remaining * 0.20, 350.0)
    print(f"\n=== Phase 4: LP Nesterov round 2 (budget={t4:.0f}s) ===")
    if t4 > 30:
        a_out, _ = nesterov_lp(results['seq'], t4, verbose=True)
        try_update(a_out, f"lp2_n{len(results['seq'])}")

    # Phase 5: Try longer length
    remaining = time_budget - (time.monotonic() - t_global)
    n_long = n_base + 400
    if remaining > 100:
        t5 = min(remaining * 0.25, 250.0)
        print(f"\n=== Phase 5: Longer length n={n_long} (budget={t5:.0f}s) ===")
        init_long = interpolate_seq(results['seq'], n_long)
        a_out, _ = nesterov_lp(init_long, t5, verbose=False)
        try_update(a_out, f"lp_long_{n_long}")

    # Phase 6: CD on longer if improved
    remaining = time_budget - (time.monotonic() - t_global)
    if remaining > 50:
        t6 = min(remaining * 0.30, 150.0)
        print(f"\n=== Phase 6: CD polish (budget={t6:.0f}s) ===")
        a_out, _ = pair_cd(results['seq'], t6, rng, verbose=False)
        try_update(a_out, f"cd_polish")

    # Phase 7: Final LP
    remaining = time_budget - (time.monotonic() - t_global)
    if remaining > 40:
        t7 = min(remaining * 0.8, 200.0)
        print(f"\n=== Phase 7: Final LP (budget={t7:.0f}s) ===")
        a_out, _ = nesterov_lp(results['seq'], t7, verbose=False)
        try_update(a_out, f"lp_final")

    # Final evaluation
    if results['seq'] is not None:
        final_score = eval_fn(results['seq'])
        if np.isfinite(final_score):
            results['score'] = final_score
        print(f"\nFINAL: score={results['score']:.6f}, n={len(results['seq'])}, time={time.monotonic()-t_global:.0f}s")
    else:
        print("\nERROR: No valid sequence found!")
        return [1.0]

    return [float(x) for x in results['seq']]
```
