    if F is not None:

    return result

                grad_C = hankel_matvec(y, a, C)
                # Need grad_C + lambda >= 0

                # From KKT: 2 Q a + lambda * 1 + mu = 0

            else:

Let me also think about the Nesterov acceleration more carefully.

The standard approach for the LP best-response game:
- a_t is the current iterate
- b_t is the best response to a_t
- Update: a_{t+1} = (1 - alpha_t) * a_t + alpha_t * b_t

With Nesterov:
- y_t = a_t + beta_t * (a_t - a_{t-1}) (extrapolation)
- b_t = best_response(y_t)
- a_{t+1} = (1 - alpha_t) * y_t + alpha_t * b_t
- beta_t = (1 - sqrt(1 + alpha_t^2)) / alpha_t (or similar)

The convergence rate is O(1/t) for simple iteration and O(1/t^2) for Nesterov.

But in practice, for this problem, the convergence is often much better than 1/t even without Nesterov, because the problem has strong convexity in some directions.
