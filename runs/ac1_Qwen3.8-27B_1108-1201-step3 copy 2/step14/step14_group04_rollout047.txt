**Approach: Frank-Wolfe (conditional gradient)**

The problem min max_k (a*a)[k] s.t. a in Δ (probability simplex) can be attacked with Frank-Wolfe:
- At each iteration, compute the linearization of the objective at the current point
- Solve the linear subproblem (find the vertex of the simplex that most reduces the linearization)
- Take a step toward that vertex

The linearization of max_k (a*a)[k] at point a is:
L(b) = max_k (a*a)[k] + <∇_k (a*a), b - a> (where ∇_k is the gradient of the active (a*a)[k])

This is the max of linear functions, so the Frank-Wolfe linear subproblem is:
min_b max_k [M_k + <g_k, b>]
where M_k = (a*a)[k] and g_k = ∇(a*a)[k] at the current a.

This is still non-linear (max of linear functions). But if we use the smoothed version (log-sum-exp), the subproblem becomes:
min_b (1/T) log(sum_k exp(T(M_k + <g_k, b>)))

which is convex in b. The minimum over the simplex of a convex function can be found by... well, it's not trivial.

Actually, for Frank-Wolfe, the standard approach is to use the subgradient of the max function. The subgradient of max_k f_k(a) at a is conv{∇f_k(a) : k in K(a)} where K(a) is the set of active indices. A specific subgradient is ∇f_k(a) for any active k.

The Frank-Wolfe step then becomes:
min_{b in Δ} <s, b> where s is the chosen subgradient.

The solution is b = e_i where i = argmin_j s_j (the vertex of the simplex with the smallest component of s).

This is very efficient! Each iteration is O(n) for the gradient computation (using FFT) + O(n) for the simplex step.

def fast_autocorr(a):
    a = np.asarray(a, dtype=np.float64)
    n = len(a)

def project_simplex(v, target_sum=1.0):
    v = np.maximum(np.asarray(v, dtype=np.float64), 0.0)
    s = v.sum()
    if s < 1e-15:
        return np.ones(len(v)) * target_sum / len(v)
    return target_sum * v / s

def lse_grad(y, T):
    n = len(y)
    ac = fast_autocorr(y)
    ac_max = ac.max()
    if ac_max < 1e-15:
        return np.zeros(n)
    shifted = (ac - ac_max) / T
    shifted = np.clip(shifted, -60.0, 60.0)
    exp_s = np.exp(shifted)
    w = exp_s / exp_s.sum()
    N = 1 << (3 * n - 2).bit_length()
    W = rfft(w, N)
    Y_rev = rfft(y[::-1], N)
    cross = irfft(W * Y_rev, N)
    grad = 2.0 * cross[n - 1: n - 1 + n]
    return grad

    constraints = [T_mat @ b_var <= M]
    prob = cp.Problem(cp.Maximize(cp.sum(b_var)), constraints)
    try:
        prob.solve(solver=solver, verbose=False)
    except Exception:
        return None
    if prob.status not in ('optimal', 'optimal_inaccurate'):
        return None
    b_val = np.maximum(np.asarray(b_var.value, dtype=np.float64), 0.0)
    if b_val.sum() < 1e-15:

    return b_val

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n) / new_n
    return f_interp / ss
