If k = 2i: the change is delta * a[i] + a[i] * delta + delta^2 = 2*delta*a[i] + delta^2

Wait, that's not right. When r = i AND k-r = i (i.e., k = 2i), the term is a[i] * a[i] = a[i]^2. When a[i] changes to a[i]+delta, it becomes (a[i]+delta)^2 = a[i]^2 + 2*a[i]*delta + delta^2. So the change is 2*a[i]*delta + delta^2.

When k != 2i but k-i is valid: the term a[i]*a[k-i] becomes (a[i]+delta)*a[k-i] = a[i]*a[k-i] + delta*a[k-i]. And the term a[k-i]*a[i] (from r = k-i) becomes a[k-i]*(a[i]+delta) = a[k-i]*a[i] + delta*a[k-i]. Total change: 2*delta*a[k-i].

So the first-order change in c_k when a[i] += delta is:
- 2*delta*a[k-i] if 0 <= k-i < n and k != 2i
- 2*delta*a[i] + delta^2 if k = 2i
- 0 otherwise

For the swap a[i] += delta, a[j] -= delta:
First-order change in c_k: 2*delta*(a[k-i] + a[i-k] - a[k-j] - a[j-k]) (with appropriate bounds)
Second-order: delta^2*(delta_{k,2i} - delta_{k,2j})

To minimize the maximum, we want to find the delta that minimizes max_k (c_k + delta * g_k + delta^2 * h_k) where:
g_k = 2*(a[k-i] + a[i-k] - a[k-j] - a[j-k]) (with bounds, and the k=2i, k=2j special cases handled)
h_k = delta_{k,2i} - delta_{k,2j}

For small delta, the optimal delta is approximately:
delta* = min over k of (M - c_k) / g_k (for g_k > 0)
where M is the current max.

This gives an analytical step! We can compute this quickly.

When we swap delta from j to i:
- conv_new[k] = conv[k] + delta * g_k + delta^2 * h_k

Hmm wait, the Frank-Wolfe step (putting all mass at one point) is very aggressive and might not work well here because the problem is non-convex (bilinear). Let me think about this more carefully.

The issue is that the problem min max_k c_k(a) s.t. a >= 0, sum(a) = S is NOT convex in a (because c_k is bilinear). So Frank-Wolfe doesn't directly apply.

However, the previous approach (LP best-response) works because:
- For fixed a, the problem in b is convex (linear objective, linear constraints)
- The "descent direction" is b - a (or a convex combination)
- This is like a block coordinate descent on the non-convex problem

The key insight is that we're minimizing a function of two copies of a: F(a, b) = max_k (a*b)_k. We alternate:
1. Fix a, minimize F(a, b) over b (this is the LP)
2. Fix b, minimize F(a, b) over a (this is also an LP by symmetry)

Or more practically:
1. Fix a, find b that maximizes sum(b) s.t. (a*b)_k <= M (the LP)
2. Move a towards b (Nesterov step)

This is essentially the "best response" method for a non-convex game.

Let me think about whether there's a faster way to do step 1 without solving the full LP.

**Approximate LP via a few iterations of dual ascent:**

The LP dual: minimize M * sum(y) s.t. T^T y >= 1, y >= 0.

We can solve this with projected gradient:
y^{t+1} = max(0, y^t - eta * (M - T^T y^t)) 

Wait, that's not right. The dual is:
min M * 1^T y
s.t. T^T y >= 1
     y >= 0

This is a standard LP. The KKT conditions are:
- T^T y - 1 + z = 0 (z >= 0 is the dual of y >= 0)
- y >= 0, z >= 0, y_j * z_j = 0
- Complementary slackness for primal: b_k * (M - (Tb)_k) = 0

A simple approach: just use scipy's linprog or a few iterations of the simplex method.

Actually, for n = 1600, even a full LP solve with a good solver should take < 0.1 seconds. The previous code's bottleneck might be elsewhere (the active set management, the Nesterov restart logic, etc.).

Let me take a different approach: instead of trying to optimize the LP solver, let me focus on:
1. A cleaner implementation of the main algorithm
2. A much better coordinate descent for the final polish
3. Better initialization strategies

For the coordinate descent, the key improvement is to use the **exact** optimal step size for each pair swap, computed in O(n) time.

Here's the exact computation:
- Current conv has max value M at indices in the active set A.
- We want to find delta that minimizes max_k (conv[k] + delta * g[k] + delta^2 * h[k])
  where g[k] = 2*(y[k-i] - y[k-j]) (with bounds, 0 if out of range)
  and h[k] = 1 if k=2i, -1 if k=2j, 0 otherwise (small correction)
  
- The optimal delta is the smallest non-negative value such that conv[k] + delta*g[k] + delta^2*h[k] <= M for all k.
- For k with g[k] > 0: delta <= (M - conv[k]) / g[k] (ignoring h for a first approximation)
- So delta* = min( min_{k: g[k]>0} (M-conv[k])/g[k], min(a[i], a[j]) )

This is O(n) per pair, and we can do a full sweep in O(n^2) time.

For n = 1600, one full sweep over all pairs is O(n^2) = 2.5M operations, which takes ~1 second in Python (maybe 10 seconds with numpy overhead). We can do many sweeps.

But actually, we don't need all pairs. We can be smarter:
- For each i, find the j that gives the best improvement
- Or use a random subset of pairs per pass

    # When a[i] increases by d: the term a[i]*a[k-i] becomes (a[i]+d)*a[k-i] = a[i]*a[k-i] + d*a[k-i]
    # And if k-i = i (k=2i): a[i]^2 becomes (a[i]+d)^2 = a[i]^2 + 2*a[i]*d + d^2
    # So the d^2 term is: d^2 if k=2i, 0 otherwise.
    # Similarly for a[j] decreasing: -d^2 if k=2j, 0 otherwise.
    # Total second-order: d^2 * (1 if k=2i else 0 - 1 if k=2j else 0)
    #
    # First-order: d * (2*a[k-i] (if valid) - 2*a[k-j] (if valid))
    
    # For efficiency, compute only over the range where g is non-zero
    # g[k] is non-zero when 0<=k-i<n or 0<=k-j<n
    # k-i in [0,n-1] -> k in [i, i+n-1]
    # k-j in [0,n-1] -> k in [j, j+n-1]
    
    # For the optimal delta, we need:
    # For all k: conv[k] + d*g[k] + d^2*h[k] <= M
    # For k with g[k] > 0: d <= (M - conv[k]) / g[k] (approximately, ignoring h)
    # For k with g[k] < 0: no upper bound (the value decreases)
    # For k with g[k] = 0: need d^2 * h[k] <= M - conv[k], but h is 0 or +/-1, so this is usually not binding
    
    # Compute g over the relevant range
    k_lo = max(0, min(i, j))
    k_hi = min(size, max(i + n, j + n))
    
    g = np.zeros(k_hi - k_lo)
    # Contribution from +d at position i
    for k in range(max(i, k_lo), min(i + n, k_hi)):
        g[k - k_lo] += 2.0 * a[k - i]
    # Contribution from -d at position j
    for k in range(max(j, k_lo), min(j + n, k_hi)):
        g[k - k_lo] -= 2.0 * a[k - j]
    
    # Find the binding constraint
    delta_max = max_delta
    for k_offset in range(len(g)):
        k = k_offset + k_lo
        if g[k_offset] > 1e-12:
            limit = (M - conv[k]) / g[k_offset]
            if limit < delta_max:
                delta_max = limit
            if delta_max <= 0:
                break
    
    delta_max = max(0.0, min(delta_max, max_delta))
    
    # Use a fraction of the optimal step (damping)
    delta = 0.95 * delta_max
    
    # Verify
    if delta < 1e-12:
        return 0.0, M
    
    # Predict new max
    new_conv_estimate = conv + delta * np.concatenate([
        np.zeros(k_lo), g, np.zeros(size - k_hi)
    ])
    # Add second-order correction
    if 2 * i < size:
        new_conv_estimate[2 * i] += delta * delta
    if 2 * j < size:
        new_conv_estimate[2 * j] -= delta * delta
    
    new_M = max(M, new_conv_estimate.max())
    
    return delta, new_M

import numpy as np

def fast_autocorr(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]


def get_M(a):
    return fast_autocorr(a).max()


def get_score(a):
    n = len(a)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    conv = fast_autocorr(a)
    return 2.0 * n * conv.max() / (s * s)


def normalize(a, S):
    s = a.sum()
    if s < 1e-15:
        return np.full(len(a), S / len(a))
    return a * (S / s)


def compute_subgradient(a, conv, smooth_p=1.0):
    """Compute weighted subgradient of max_k conv_k.
    smooth_p=1 uses smooth max (all peaks weighted by conv value).
    smooth_p > 1 emphasizes the peak more.
    Returns gradient vector of length n.
    """
    n = len(a)
    size = 2 * n - 1
    M = conv.max()
    if M < 1e-15:
        return np.zeros(n)

    # Weight each lag by (conv[k]/M)^p
    # For p=1: weight = conv[k]/M (smooth max gradient)
    # For p->inf: weight -> indicator of argmax
    if smooth_p <= 1.0:
        weights = conv / M  # Smooth max: all lags weighted proportionally
    else:
        weights = np.power(conv / M, smooth_p)
        wsum = weights.sum()
        if wsum < 1e-15:
            return np.zeros(n)
        weights = weights / wsum

    # grad[j] = 2 * sum_k weights[k] * a[k-j] (for valid k-j in [0,n-1])

    # More precisely: grad[j] = 2 * sum_{k: 0<=k-j<n} weights[k] * a[k-j]
    # Let m = k-j: grad[j] = 2 * sum_{m=0}^{n-1} weights[m+j] * a[m]
    # This is the cross-correlation of weights and a at lag j.
    
    # Use direct computation (fast when n is moderate)
    grad = np.zeros(n)
    for k in range(size):
        if weights[k] < 1e-12:
            continue
        # For this k, valid j range: max(0, k-n+1) <= j <= min(n-1, k)
        lo = max(0, k - n + 1)
        hi = min(n, k + 1)
        if hi <= lo:

        # grad[j] += 2 * weights[k] * a[k-j] for j in [lo, hi-1]
        # When j goes from lo to hi-1, k-j goes from k-lo down to k-hi+1
        # a indices: k-hi+1 to k-lo (reversed)
        a_slice = a[k - hi + 1: k - lo + 1]
        grad[lo:hi] += 2.0 * weights[k] * a_slice[::-1]
    
    return grad

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n)
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n)
    return f_interp / ss

    Starts with smooth (p=1) and anneals to sharp (p->inf).
    """
    rng = np.random.default_rng(seed)
    n = len(a)
    S = np.sqrt(2.0 * n)
    a = normalize(np.maximum(a, 0.0), S)
    
    best_a = a.copy()
    best_M = get_M(a)
    t0 = time.monotonic()
    
    y = a.copy()
    x = a.copy()
    avg = np.zeros(n)
    count = 0
    stall = 0
    
    total_iters = 200000
    
    for t in range(1, 5000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Anneal p: start smooth, get sharp
        frac = min(t / total_iters, 1.0)
        p = 1.0 + 99.0 * frac ** 2  # p goes from 1 to 100
        
        conv_y = fast_autocorr(y)
        M_y = conv_y.max()
        
        # Compute subgradient with current p
        grad = compute_subgradient(y, conv_y, smooth_p=p)
        
        # Frank-Wolfe step
        alpha = 2.0 / (t + 2.0)
        i_min = np.argmin(grad)
        v = np.zeros(n)
        v[i_min] = S
        
        y_new = (1.0 - alpha) * y + alpha * v
        y_new = np.maximum(y_new, 0.0)
        y_new = normalize(y_new, S)
        
        if t == 1:
            x_new = v.copy()
        else:
            beta = min((t - 1.0) / (t + 2.0), 0.85)
            x_new = y_new + beta * (y_new - y)
            x_new = np.maximum(x_new, 0.0)
            x_new = normalize(x_new, S)
        
        y = y_new
        x = x_new
        
        M_x = get_M(x)
        if M_x < best_M - 1e-12:
            best_M = M_x
            best_a = x.copy()
            stall = 0
