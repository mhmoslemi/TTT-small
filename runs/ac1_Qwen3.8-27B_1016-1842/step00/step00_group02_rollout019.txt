The key constraint: f >= 0, sum f = 1. The objective: 2n * max_k (f*f)_k.

At the optimum, by KKT conditions (relaxing the max to a set of active constraints), we have:
- For active k (where (f*f)_k = M = max): the gradient of (f*f)_k is in the normal cone of the constraint set.
- For inactive k: (f*f)_k < M.

The gradient of (f*f)_k at f is: g_k[i] = 2*f[k-i] (for valid k-i) + correction.

The normal cone of {f >= 0, sum f = 1} at f is: {v : v_i >= 0 for i where f_i = 0, and v = lambda * 1 (constant) for i where f_i > 0}.

So at the optimum: for all active k, 2*f[k-i] (for i in support) = lambda (a constant).

This means: for all active k and all i in support: f[k-i] = lambda/2.

This is a very strong condition! It means that for each active lag k, the sequence f, when flipped and shifted by k, has constant value (lambda/2) on the support.

For a single active k: f is constant on {k-i : i in support} ∩ [0, n-1]. If the support is all of [0, n-1], then f is constant, which gives the uniform solution (objective 2).

For multiple active k's: f must be constant on the intersection of multiple shifted supports. This is more restrictive.

If two consecutive lags k and k+1 are active, then:
f[k-i] = c for all i in support, AND f[k+1-i] = c for all i in support.
This means f is constant on {k-i, k+1-i : i in support}. If support is all of [0,n-1], this means f is constant on two overlapping intervals, hence constant everywhere. → uniform.

So for the optimum to be non-uniform, we need the active set to be such that the constraints are not all simultaneously satisfiable with f constant. This happens when the shifted supports don't all overlap.

For example, if k* = 0 is active: f[0-i] = c for valid i, which means f[0] = c. (Only one constraint.)
If k* = 1 is active: f[1] * 2*f[0]... wait, (f*f)_1 = 2*f_0*f_1. Gradient: [2*f_1, 2*f_0, 0, ...].
If both k*=0 and k*=1 are active: f_0² = M AND 2*f_0*f_1 = M. So f_1 = f_0/2.
