Let me think about a better perturbation. Actually, the subgradient of the objective F(a) = 2n * max_k b[k] / S^2 is:

∇F(a)[i] = (2n/S^2) * Σ_{k∈K*} 2*a[k-i] - (4n*max_b/S^3) * a[i]

where K* is the set of argmax indices.

The first term is the "peak reduction" direction, and the second is the "sum normalization" term.

For a descent step: a ← a - η * ∇F(a), then project.

But the subgradient is only an approximation (subgradient, not gradient). Still, it gives a useful direction.

Let me simplify: the descent direction is:
d[i] = Σ_{k∈K*} 2*a[k-i] - (2*max_b/S) * a[i]

We want to decrease a where d[i] > 0 (large partner values) and the second term discourages large a[i] (to maintain sum).

Actually wait, I should double-check the sign. F = 2nM/S^2. We want to minimize F.
dF/da[i] = (2n/S^2)(dM/da[i]) - (2nM/S^3)(2a[i]) [since dS/da[i] = 1, d(1/S^2) = -2/S^3]
= (2n/S^2)(dM/da[i]) - (4nM/S^3) * a[i]

For descent: a ← a - η * dF/da
= a - η * (2n/S^2)(dM/da[i]) + η * (4nM/S^3) * a[i]

The first correction reduces a[i] where it contributes to the peak.
The second correction increases a[i] proportionally (to compensate for reduced sum).

But we need to be careful: if we increase a[i], it might increase the peak at other lags.

For a practical implementation, I'll use a simple approach:
1. Compute the subgradient direction
2. Take a small step in the descent direction
3. Project onto [0, 1000]
4. Check if the score actually decreased; if not, take a smaller step or revert
