- 0 otherwise

The full gradient of F = 2n*M/S^2 where M = conv(a,a)[k*] and S = sum(a):
∂F/∂a[j] = 2n * (∂M/∂a[j] * S^2 - M * 2S * 1) / S^4
= 2n * (∂M/∂a[j]) / S^2 - 4n * M / S^3

Where ∂M/∂a[j] = a[k*-j] (if valid) + a[k*-j] ... wait.

conv(a,a)[k] = sum_{i: 0<=i<n, 0<=k-i<n} a[i]*a[k-i]

∂/∂a[j] conv(a,a)[k] = sum_{i: 0<=i<n, 0<=k-i<n} [δ(i,j)*a[k-i] + a[i]*δ(k-i,j)]
= a[k-j] (if 0<=k-j<n) + a[k-j] (if 0<=k-j<n)
= 2*a[k-j] (if 0<=k-j<n, and j≠k-j)
= a[k-j] (if 0<=k-j<n and j=k-j, i.e., k=2j)

So: ∂M/∂a[j] = 2*a[k*-j] if k*-j is in [0,n-1] and k* ≠ 2j, else a[k*-j] if k*=2j and j is in [0,n-1], else 0.

∂F/∂a[j] = (2n/S^2) * g_j - (4nM/S^3)

The first term is a "convolution-like" operation (shifted copy of a), and the second is a constant. So the gradient can be computed in O(n).
