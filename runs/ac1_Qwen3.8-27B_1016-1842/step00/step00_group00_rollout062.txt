    fb = np.fft.rfft(b, N)
    return np.fft.irfft(fa * fb, N)[:n]

Actually, for the LP, the optimal solution has a special structure: it's the solution of a "water-filling" problem. Given the constraint that all "sliding inner products" with a are <= M, maximize the sum of g.

This is equivalent to: find g >= 0 maximizing 1^T g such that for all k, sum_j a[k-j]*g[j] <= M.

This is a packing LP. The dual is: minimize M * sum_k y_k + 0 * ... s.t. sum_k a[j-k]*y_k >= 1 for all j, y_k >= 0.

The dual is: min M * 1^T y s.t. (T_a^T y)_j >= 1, y >= 0.
(T_a^T y)_j = sum_k T_a[k,j]*y_k = sum_k a[k-j]*y_k = (conv(a, y))[j] (approximately, with appropriate indexing).

So the dual is: min M * sum(y) s.t. conv(a, y) >= 1 (element-wise), y >= 0.

This is a "uncovering" problem. The optimal y would be concentrated where a is small (to cover those positions efficiently).
