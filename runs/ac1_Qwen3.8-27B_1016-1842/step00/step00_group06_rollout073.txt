Specifically: r[j] = sum_{m=0}^{n-1} p[j+m] * a[m] = (p ⊛ a)[j] (cross-correlation of p and a at lag j).

Using FFT: r = ifft(conj(fft(p, L)) * fft(a, L)) where L >= len(p) + len(a) - 1 = (2n-1) + n - 1 = 3n-2.

And r[j] for j = 0, 1, ..., n-1 gives us the gradient (times 2).

Let me verify with a small example:
n=2, a = [a0, a1]. p = [p0, p1, p2] (length 3 = 2n-1).
b[0] = a0^2, b[1] = 2*a0*a1, b[2] = a1^2.

grad[0] = 2 * (p[0]*a[0] + p[1]*a[1]) = 2*p[0]*a0 + 2*p[1]*a1
Using the formula: sum_k p[k] * 2*a[k-0] = 2*(p[0]*a[0] + p[1]*a[1] + p[2]*a[2])
But a[2] = 0 (out of range), so = 2*(p[0]*a0 + p[1]*a1). ✓

grad[1] = 2 * (p[1]*a[0] + p[2]*a[1])
Using the formula: sum_k p[k] * 2*a[k-1] = 2*(p[1]*a[0] + p[2]*a[1] + p[0]*a[-1])
a[-1] = 0, so = 2*(p[1]*a0 + p[2]*a1). ✓

Great, the formula works.

Now, for the cross-correlation via FFT:
r[j] = sum_{m=0}^{n-1} p[j+m] * a[m]

Standard cross-correlation: (f ⊛ g)[j] = sum_n f[n+j] * conj(g[n])
For real signals: (f ⊛ g)[j] = sum_n f[n+j] * g[n]

So r[j] = (p ⊛ a)[j] where p is "f" and a is "g".

Using FFT (with zero-padding to length L >= 2n-1+n-1 = 3n-2):
(r) = ifft(conj(FFT(p, L)) * FFT(a, L))

The first n elements of r give us grad/2.

import numpy as np
import time

def _compute_grad(a, p, conv_L, grad_L, n):
    """Compute gradient of smoothed max autocorrelation."""
    P = np.fft.rfft(p, grad_L)
    A = np.fft.rfft(a, grad_L)
    cross = np.fft.irfft(np.conj(P) * A, grad_L)
    return 2.0 * cross[:n]

def _softmax_weights(b, tau):
    """Compute softmax weights for the logsumexp approximation."""
    b_max = b.max()
    if b_max < 1e-15:
        n_b = len(b)
        p = np.zeros(n_b)
        p[int(b.argmax())] = 1.0
        return p
    scaled = (b - b_max) / (tau * b_max)
    scaled = np.clip(scaled, -100, 0)
    p = np.exp(scaled)
    p_sum = p.sum()
    if p_sum < 1e-15:
        p = np.zeros(len(b))
        p[int(b.argmax())] = 1.0
    else:
        p /= p_sum
    return p
