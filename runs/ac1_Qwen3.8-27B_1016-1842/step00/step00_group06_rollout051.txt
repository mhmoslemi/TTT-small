A practical approach:

3. The gradient of the peak w.r.t. a[i] is a[k*-i] (for the term a[i]*a[k*-i] in the sum).
4. To reduce the peak, we want to reduce the contributions at the peak and increase the sum.
5. Since we want to minimize 2n*peak/sum^2, the effective gradient is:
   d(score)/da[i] = 2n * (d(peak)/da[i] * sum^2 - peak * 2*sum * da[i→sum]) / sum^4

   = 2n * (a[k*-i] * sum - 2*peak) / sum^3

If a[k*-i] * sum < 2*peak, increasing a[i] decreases the score (good).

This suggests: at the peak position k*, the pairs (i, k*-i) that contribute to the peak should have a[k*-i] * sum < 2*peak for us to increase a[i].

import time

def make_ramp(n):
    return np.arange(1, n+1, dtype=np.float64)

def evaluate_score(a):
    """Fast score computation (same as evaluate_sequence but on numpy array)."""
    n = len(a)
    a = np.maximum(a, 0)
    a = np.minimum(a, 1000.0)
    conv = np.convolve(a, a)

    sum_a = np.sum(a)
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a ** 2)

    deadline = time.monotonic() + max(0.0, float(budget_s) - 5.0)

    try:
        n = len(height_sequence_1)
        parent = np.clip(np.asarray(height_sequence_1, dtype=np.float64), 0, 1000)

        n = 256

    # Try ramp initialization
    ramp = make_ramp(n)
    ramp_score = evaluate_score(ramp)

    best = ramp.copy() if ramp_score < parent_score else parent.copy()
    best_score = min(ramp_score, parent_score)

        # Random block perturbation
