Actually, let me try a two-level step function. a = [h, 1, 1, ..., 1, h] for some h > 0. Or a = [1, 1, ..., 1, h, h, h] (step at some point).

For a step function: a[i] = 1 for i < k, a[i] = c for i >= k (0 <= c <= 1, to keep non-negative).
S = k + c(n-k).
b[n-1] = sum a[i]*a[n-1-i]. For i < k: a[i]=1, a[n-1-i] depends on n-1-i vs k.
