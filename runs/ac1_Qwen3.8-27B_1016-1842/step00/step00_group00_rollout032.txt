    # Column i has n nonzeros in rows i..i+n-1

After .tocsc(), the CSC format stores:
- indptr: for column i, the data starts at indptr[i] and has (indptr[i+1]-indptr[i]) entries.
- Since each column has exactly n entries and they're in order, indptr[i] = i*n and the data for column i is at positions i*n to (i+1)*n-1.
- The data values for column i should all be 1 (initially), and after update should all be a[i].

But wait, I need to make sure the CSC conversion preserves the column ordering. In COO format, the entries are:
(0,0), (1,0), (2,0), ..., (n-1,0), (1,1), (2,1), ..., (n,1), ..., (n-1, n-1), (n, n-1), ..., (2n-2, n-1)

When converting to CSC, scipy sorts by column first, then by row within each column. Since the entries are already in column order (all column 0 entries first, then column 1, etc.) and sorted by row within each column, the CSC conversion should preserve this order.

After conversion:
- Column 0: data[0:n] = 1, indices[0:n] = [0, 1, ..., n-1]
- Column 1: data[n:2n] = 1, indices[n:2n] = [1, 2, ..., n]
- ...
- Column i: data[i*n:(i+1)*n] = 1, indices[i*n:(i+1)*n] = [i, i+1, ..., i+n-1]

So `A.data = np.repeat(a, n)` correctly sets column i's data to a[i] repeated n times. ✓
