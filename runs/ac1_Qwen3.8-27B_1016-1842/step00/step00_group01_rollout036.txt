def fft_convolve_sq(a):
    """Compute full auto-convolution a*a using FFT. O(n log n)."""

    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2*n - 1]

    # Final polish: check exact

    if sc < best_score:

By LP duality (if we relax the quadratic constraint), the optimal solution distributes the "mass" so that the convolution is as flat as possible.

For a non-negative sequence, the convolution is always non-negative, and its sum is 1. So the minimum possible max is 1/(2n-1) (all entries equal), but this is only achievable if a is specifically structured.
