Actually, there's no general inequality that max_b >= sum_a²/n for linear convolution (unlike circular convolution where Parseval's identity gives sum |b_k|² >= |sum b_k|²/N).

Let me think about when max_b < sum_a²/n is possible.

sum_a²/n = (sum a_j)²/n. And b[0] = a[0]², b[n-1] = sum a_j a_{n-1-j}, etc.

For a very skewed distribution, like a = [0, 0, ..., 0, M, 0, ..., 0] (single spike), max_b = M², sum_a = M, sum_a²/n = M²/n. Score = 2n*M²/M² = 2n. Terrible.

For a = [M, 0, 0, ..., 0] (spike at start), conv = [M², 0, ..., 0]. max_b = M². Same issue.

For a = [M/2, M/2, 0, ..., 0], conv = [M²/4, M²/2, M²/4, 0, ...]. max_b = M²/2. sum_a = M. Score = 2n*M²/2/M² = n. Still terrible for large n.

The point is: concentrating mass increases the peak. Spreading it uniformly gives score 2. Can we do better than 2?
