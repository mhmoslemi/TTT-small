a[i] = 1 + δ[i], where sum δ = 0 (to keep sum = n), and δ[i] is small.

conv(n-1) = sum_i (1+δ[i])(1+δ[n-1-i]) = n + sum_i δ[i] + sum_i δ[n-1-i] + sum_i δ[i]δ[n-1-i]
= n + 0 + 0 + sum_i δ[i]δ[n-1-i]
= n + sum_i δ[i]δ[n-1-i].

To reduce conv(n-1), we need sum_i δ[i]δ[n-1-i] < 0. This means δ should be "anti-correlated" with its reverse.

For example, δ[i] = ε sin(2πi/n) (approximately 0 at i=0 and i=n, positive in first half, negative in second half... wait sin(2πi/n) is positive for i in (0, n/2) and negative for i in (n/2, n)).

sum_i δ[i] = ε sum sin(2πi/n) = 0. ✓
sum_i δ[i]δ[n-1-i] = ε² sum sin(2πi/n)sin(2π(n-1-i)/n)
= ε² sum sin(2πi/n)sin(2π(n-1-i)/n).

Now sin(2π(n-1-i)/n) = sin(2π - 2π(1+i)/n) = -sin(2π(1+i)/n).

So the sum = -ε² sum sin(2πi/n)sin(2π(1+i)/n)
= -(ε²/2) sum [cos(2πi/n - 2π(1+i)/n) - cos(2πi/n + 2π(1+i)/n)]
= -(ε²/2) sum [cos(-2π/n) - cos(2π(2i+1)/n)]
= -(ε²/2) sum [cos(2π/n) - cos(4πi/n + 2π/n)]
= -(ε²/2) [n·cos(2π/n) - sum cos(4πi/n + 2π/n)]

For n > 4, sum_i cos(4πi/n + 2π/n) = Re(e^{2πi/n} sum e^{4πii/n}) = 0 (geometric series ratio ≠ 1).

So sum_i δ[i]δ[n-1-i] = -(ε²/2) · n·cos(2π/n) ≈ -ε²n/2.
