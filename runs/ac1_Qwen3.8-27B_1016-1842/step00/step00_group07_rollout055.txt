- When k-i = j, i.e., i = k-j: term is a[k-j]*a[j], derivative w.r.t. a[j] is a[k-j] (if 0<=k-j<n)
- If j = k-j (i.e., k = 2j): these are the same term, derivative is 2*a[j] = 2*a[k-j]

Wait, that's not right. When i = j AND k-i = j (i.e., k = 2j), the term a[j]*a[j] appears only once in the sum, and its derivative w.r.t. a[j] is 2*a[j]. When k ≠ 2j, the terms a[j]*a[k-j] (i=j) and a[k-j]*a[j] (i=k-j) are distinct, and each contributes a[k-j] to the derivative, giving 2*a[k-j].

import time

def fft_convolve(a, b):
    """Compute linear convolution using FFT. O(n log n)."""
    n = len(a) + len(b) - 1
    size = 1
    while size < n:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:n]

def compute_score_local(a, c):
    """Compute score from array a and its self-convolution c."""
    sa = a.sum()
    if sa < 0.01:
        return float('inf')
    return 2.0 * len(a) * c.max() / (sa * sa)

def project_simplex(v, target=1.0):
    """Project v onto {x >= 0, sum(x) = target} via clip+rescale (approximate)."""
    v = np.clip(v, 0.0, None)
    s = v.sum()
    if s < 1e-300:
        n = len(v)
        return np.full(n, target / n)
    return v * (target / s)
