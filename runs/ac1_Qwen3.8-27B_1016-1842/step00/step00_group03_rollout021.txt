But we also need k-j to be in [0,n-1] for the first term.

So the subgradient vector (as a function of f, at point k* = argmax C) is:
g[j] = f[k*-j] (if 0 <= k*-j <= n-1) + f[j] (if k* = 2j)
= f[k*-j] * 1[0<=k*-j<n] + f[j] * δ(k*=2j)

This can be computed in O(n) time.

Now, for the optimization, I'll use a projected subgradient method:
1. Compute C = f*f, find k* = argmax
2. Compute subgradient g
3. Step: f_new = f - α*g
4. Project: f_new = max(f_new, 0), then rescale to sum = 1
5. Adaptive step size

But this is a subgradient method on a non-smooth function, so convergence is slow (O(1/√T)).

A better approach: use the LP dual / alternating method described in the problem. Or use a smooth approximation of the max (like log-sum-exp).

Let me try the log-sum-exp smoothing:
F_β(f) = (1/β) * log(sum_k exp(β*C[k]))

This is a smooth approximation of max(C), and its gradient is:
∂F_β/∂f[j] = (1/β) * sum_k (β*C[k])' * exp(β*C[k]) / sum_m exp(β*C[m])
= sum_k (∂C[k]/∂f[j]) * p[k]

where p[k] = exp(β*C[k]) / sum_m exp(β*C[m]) is a softmax over C.

So the gradient is a weighted sum of the individual ∂C[k]/∂f[j], weighted by the softmax probabilities.

For β large, this approaches the subgradient at the argmax. For β moderate, it's a smoothed version.

Computing this gradient in O(n) (or O(n log n) with FFT):
- Compute C = f*f via FFT: O(n log n)
- Compute p = softmax(β*C): O(n)
- Compute gradient: grad[j] = sum_k p[k] * (∂C[k]/∂f[j])

The tricky part is the last sum. ∂C[k]/∂f[j] = f[k-j] * 1[valid] + f[j]*δ(k=2j)

So grad[j] = sum_k p[k] * f[k-j] * 1[0<=k-j<n] + p[2j]*f[j]
= sum_{i=0}^{n-1} p[j+i]*f[i] (where i = k-j, so k = j+i)
  * 1[0<=j+i<2n-1] + p[2j]*f[j] (if 0 <= 2j < 2n-1)

The first term is a convolution: (p * f)[j] (linear convolution of p and f), evaluated at index j. But p has length 2n-1 and f has length n, so this convolution has length 3n-2. We only need indices 0 to n-1.

This can be computed via FFT in O(n log n)!
