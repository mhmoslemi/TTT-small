But we only have n terms, and the boundary conditions at k >= n matter. The full condition is:
- For k = 0 to 2n-2: sum_{i=max(0,k-n+1)}^{min(k,n-1)} a_i * a_{k-i} = m (constant)

For k < n: sum_{i=0}^{k} a_i * a_{k-i} = m (the "infinite" condition)
For k = n-1: sum_{i=0}^{n-1} a_i * a_{n-1-i} = m
For k >= n: sum_{i=k-n+1}^{n-1} a_i * a_{k-i} = m (the "tail" condition)

The "infinite" solution (a_k proportional to binomial(2k,k)/4^k) satisfies the first set but NOT the tail conditions. For the tail, we need the sequence to "drop off" appropriately.

For large n, the sequence a_k = a_0 * binomial(2k,k)/4^k decays like a_0 / sqrt(pi*k). So it's slowly decaying. For k near n-1, a_k ≈ a_0 / sqrt(pi*(n-1)).

The sum of the sequence: sum_{k=0}^{n-1} binomial(2k,k)/4^k ≈ sum_{k=0}^{∞} 1/sqrt(pi*k) which diverges! So for finite n, the sum is finite but the sequence doesn't decay fast enough.

This means for large n, the "all b_k equal" constraint is infeasible (the sequence would need to be very non-uniform, with a_0 >> a_{n-1}).
