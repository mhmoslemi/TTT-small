(x * x)[k] = sum_{i=0}^{n-1} x[i] * x[k-i] (with x[j]=0 for j<0 or j≥n).

The autocorrelation R[j] = sum_{i=0}^{n-1-j} x[i] * x[i+j] for j ≥ 0.

(x * x)[n-1+j] = sum_i x[i] * x[n-1+j-i]. Let i' = n-1-i: = sum_{i'} x[n-1-i'] * x[j+i']. So (x*x)[n-1+j] = sum_{i'} x[n-1-i'] * x[i'+j].

This is NOT the same as R[j] = sum_i x[i] x[i+j] unless x is symmetric.

OK so the self-convolution is a "cross-correlation" of x with itself, not the standard autocorrelation. For a symmetric sequence, they coincide.
