The problem is clear: concentrating the sequence makes the peak/sum² ratio worse. The uniform distribution (score 2) is actually quite good.

So how do we beat 2? We need a non-trivial structure where:
- The convolution peak is reduced relative to the sum.
- The sum is maintained.

The only way I can think of is to make the sequence "anti-correlated with itself at the peak lag." For non-negative sequences, this means making a_i small where a_{k-i} is large (for the peak k).

But if k = n-1 (center), then we need a_i small where a_{n-1-i} is large. This means the sequence should be "anti-palindromic": a_i + a_{n-1-i} = constant.

If a_i + a_{n-1-i} = 2/n (constant), then:
b_{n-1} = Σ a_i a_{n-1-i} = Σ a_i(2/n - a_i) = (2/n)Σa_i - Σa_i² = 2/n - Σa_i².

By Cauchy-Schwarz: Σa_i² ≥ (Σa_i)²/n = 1/n. So b_{n-1} ≤ 2/n - 1/n = 1/n.

The uniform has exactly b_{n-1} = 1/n (and it achieves the lower bound of Σa_i²). Any non-uniform anti-palindromic sequence has Σa_i² > 1/n, so b_{n-1} < 1/n!

But we need to check that other b_k don't exceed the original max.

For the anti-palindromic constraint a_i + a_{n-1-i} = 2/n:
a_i = 1/n + x_i where x_i = -x_{n-1-i} (anti-palindromic perturbation) and |x_i| ≤ 1/n.

b_k = Σ (1/n + x_i)(1/n + x_{k-i})
= (1/n²)·count_k + (1/n)·Σ(x_i + x_{k-i}) + Σ x_i x_{k-i}

where count_k is the number of valid i for lag k.

For k = n-1: count = n.
(1/n²)·n = 1/n.
(1/n)·Σ(x_i + x_{n-1-i}) = (1/n)·(Σx_i + Σx_{n-1-i}) = (1/n)·(0 + 0) = 0 (since x is zero-mean and anti-palindromic implies zero-mean).
Σ x_i x_{n-1-i} = -Σ x_i² (anti-palindromic).

So b_{n-1} = 1/n - Σx_i². This is < 1/n. ✓

For k = 0: b_0 = (1/n + x_0)². If |x_0| < 1/n, then b_0 < (2/n)² = 4/n². For n ≥ 5582, 4/n² << 1/n. So b_0 is not a problem.

For general k: b_k = (1/n²)·count_k + (1/n)·Σ_{i∈S_k}(x_i + x_{k-i}) + Σ_{i∈S_k} x_i x_{k-i}

where S_k = {i: 0 ≤ i < n, 0 ≤ k-i < n}.

|Σ_{i∈S_k} x_i x_{k-i}| ≤ Σ_{i∈S_k} |x_i||x_{k-i}| ≤ max|x|² · count_k ≤ (1/n)² · count_k.

And |Σ_{i∈S_k}(x_i + x_{k-i})| ≤ 2·count_k·(1/n) (crude bound).

So |b_k - (count_k)/n²| ≤ (1/n)·(2·count_k/n) + count_k/n² = 3·count_k/n².

And (count_k)/n² ≤ n/n² = 1/n.

So b_k ≤ 2/n (roughly). This is too loose. Let me think more carefully.

The key question: for the anti-palindromic perturbation, is b_{n-1} still the maximum? Or do other lags become the peak?

For a small perturbation (|x_i| << 1/n), the answer is: the center is still the peak (since count_k ≤ n, and the perturbation is small). So for small perturbations, we reduce the center peak without creating new peaks.

The reduction in the center peak is Σx_i². To maximize this, we want to maximize Σx_i² subject to |x_i| ≤ 1/n and x_i = -x_{n-1-i}.

Max Σx_i² = (n/2)·(1/n)² = 1/(2n) (when |x_i| = 1/n for all i).

Then b_{n-1} = 1/n - 1/(2n) = 1/(2n). And the score at the center would be 2n·(1/(2n)) = 1. But we need to check other peaks.
