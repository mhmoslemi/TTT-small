sum_j b[j]*b[k-j] = sum_j A[j,k-j]*b[j]*b[k-j].

For this to equal b^T A_k b:
A_k[j, k-j] = 1 and A_k[k-j, j] = 1 (by symmetry).
So A_k[j,l] = 1 if j+l = k, 0 otherwise (within bounds).

But then b^T A_k b = sum_{j+l=k} b[j]*b[l]. This counts each pair (j,l) with j≠l twice (once as (j,l) and once as (l,j)). And j=l=k/2 is counted once.

So b^T A_k b = 2*sum_{j<k-j} b[j]*b[k-j] + sum_{j=k-j} b[j]^2.

But sum_j b[j]*b[k-j] = sum_{j<k-j} b[j]*b[k-j] + sum_{j<k-j} b[k-j]*b[j] + sum_{j=k-j} b[j]^2
= 2*sum_{j<k-j} b[j]*b[k-j] + sum_{j=k-j} b[j]^2.

So b^T A_k b = sum_j b[j]*b[k-j]. ✓
