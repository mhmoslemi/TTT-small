For the subgradient step, I'll use:
- Compute conv = np.convolve(a, a) (O(n log n) via FFT for large n)
- Find the index k* of the maximum
- Subgradient: g[j] = 2*a[k*-j] for valid j (this is 2 * a[::-1] shifted)

Actually, a better approach: use the "log-sum-exp" gradient:
- z_k = conv[k] / tau (for some temperature tau)
- w_k = softmax(z) (but we can approximate with just the top T terms)
- g[j] = sum_{k in top T} w[k] * 2*a[k-j] (if valid)

This naturally gives a non-uniform gradient even from the uniform starting point.

```python
import numpy as np
import time

def subgradient_step(a, lr, tau, top_k=50):
    """One subgradient step to minimize max(conv(a,a)) subject to sum(a)=n."""
    n = len(a)
    conv = np.convolve(a, a)
    # Find top peaks
    # Use a soft approximation: weight by exp(conv[k]/tau)
    z = conv / tau
    z -= z.max()  # for numerical stability
    w = np.exp(z)
    w /= w.sum()
    # Compute weighted subgradient
    # g[j] = sum_k w[k] * 2*a[k-j] (if 0<=k-j<n)
    # This is 2 * (w * a) where * is cross-correlation
    # Specifically, g[j] = 2 * sum_k w[k] * a[k-j] for valid indices
    # = 2 * (w[::-1] * a)[something]... 
    # Actually: g[j] = 2 * sum_{k: 0<=k-j<n} w[k] * a[k-j]
    # Let m = k-j, so k = m+j: g[j] = 2 * sum_m w[m+j] * a[m] (for valid m+j)
    # This is 2 * (cross_correlation(w, a))[j]
    # = 2 * convolve(w, a[::-1])[j + n - 1]  (with appropriate offsets)
    
    # Simpler: just compute directly for the top few k
    idx = np.argsort(conv)[-top_k:]
    g = np.zeros(n)
    for k in idx:
        wk = w[k]
        if wk < 1e-10:
            continue
        # g[j] += 2*wk*a[k-j] for 0<=k-j<n, i.e., max(0,k-n+1) <= j <= min(k, n-1)
        j_start = max(0, k - n + 1)
        j_end = min(k, n - 1)
        if j_start <= j_end:
            g[j_start:j_end+1] += 2 * wk * a[k - j_end:k - j_start + 1]  # a[k-j] for j in [j_start, j_end]
    return a - lr * g
```
