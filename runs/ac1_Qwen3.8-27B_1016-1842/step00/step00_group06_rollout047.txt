$\tilde{\phi}(a) = \log \sum_k \exp(\tau \cdot (a*a)_k) / \tau$ (for large $\tau$, this approximates the max).

The gradient of $\tilde{\phi}$ is a weighted average of the subgradients at all peaks, weighted by $\exp(\tau \cdot (a*a)_k) / \sum_j \exp(\tau \cdot (a*a)_j)$.

This gives a smoother gradient and might converge faster. But it requires computing all $(a*a)_k$ values (which we already do via FFT) and the gradient is:
$g_i = \sum_k w_k \cdot a[k-i]$ where $w_k = \text{softmax}(\tau \cdot (a*a)_k)$.

This is a convolution of $w$ with $a$ (reversed)! So:
$g = w * a$ (proper convolution), which can be computed via FFT.

This is elegant: at each iteration, compute $c = a * a$ (FFT), compute $w = \text{softmax}(\tau c)$, compute $g = w * a$ (FFT), then do a gradient step.

Two FFT convolutions per iteration. Still fast.

But actually, for the max approximation with large $\tau$, the softmax weights are concentrated at the peak, so it's similar to the subgradient approach. For moderate $\tau$, it considers multiple peaks simultaneously, which might be better.

Let me implement this. With $\tau = 100$ (scaled appropriately), the softmax will weight the top few peaks.

Actually, the scale matters. If the convolution values are around $1/n \sim 0.0002$, then $\tau$ should be around $1/0.0002 = 5000$ for the softmax to be peaky. Let me use $\tau$ relative to the range of $c$.

Let me simplify: use $w_k = \exp((c_k - c_{\max}) / t)$ where $t$ is a temperature. For $t$ small, weight concentrates at peak. For $t$ large, uniform.

I'll use $t = 0.05 \cdot \text{range}(c)$ initially, and decrease it.
