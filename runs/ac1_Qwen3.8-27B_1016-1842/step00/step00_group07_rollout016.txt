import time

def fft_convolve(a):
    """Compute linear convolution of a with a using FFT."""
    n = len(a)
    size = 1 << (2*n - 1).bit_length()  # next power of 2
    F = np.fft.rfft(a, size)
    return np.fft.irfft(F * F, size)[:2*n-1]

def score_fast(a):
    """Fast score computation."""
    n = len(a)
    s = np.sum(a)
    if s < 0.01:
        return np.inf
    c = fft_convolve(a)
    return 2.0 * n * np.max(c) / (s * s)

- c[k] for k in the range [i_j, k + i_m] for each j.

This is complex. Let me think of a simpler approach.

**Gradient-based approach (subgradient):**
- The score is f(a) = 2n * max_k c[k] / S² where S = sum(a).
- This is piecewise smooth (the max is the active constraint).
- Subgradient of max_k c[k] with respect to a[i]: if k* is the argmax, then ∂c[k*]/∂a[i] = a[k*-i] (if 0 <= k*-i < n, else 0).
- Subgradient of S² with respect to a[i]: 2S.
- So subgradient of f: 2n * [a[k*-i]/S² - c[k*] * 2 / S³] for the active k*.

This gives a direction to move. We can do:
1. Compute c = conv(a,a), find k* = argmax(c).
2. Compute subgradient direction.
3. Take a small step in the negative subgradient direction.
4. Clip to [0, 1000].
5. Repeat.

The subgradient step:
f(a) = 2n * c[k*] / S²
∂f/∂a[i] = 2n * (a[k*-i]*S² - c[k*]*2*S) / S⁴ = 2n * (a[k*-i]*S - 2*c[k*]) / S³

For a step in direction -∂f/∂a:
new_a[i] = a[i] - η * 2n * (a[k*-i]*S - 2*c[k*]) / S³

Simplifying: new_a[i] = a[i] - η * 2n/S * (a[k*-i] - 2*c[k*]/S) / S

Let's define: excess[i] = a[k*-i] - 2*c[k*]/S (where a[j]=0 if j out of range).
new_a[i] = a[i] - η * (2n/S²) * excess[i]

If excess[i] > 0: a[i] is too large (it contributes to the peak) → decrease.
If excess[i] < 0: a[i] is too small → increase.

This makes sense! Elements that pair with the peak lag get decreased, others get increased.

But we need to be careful: this only handles the single active lag. In practice, multiple lags might be near the maximum. We can use a "soft max" or weight multiple lags.

**Improved: Use top-m active lags:**
Instead of just k*, use the top m lags where c[k] is largest, weighted by c[k].

**Practical algorithm:**
