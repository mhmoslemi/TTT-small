The key constraint is that c[0] = a[0]^2 and c[2n-2] = a[n-1]^2. Also, c[j] for j < n is determined by the first j+1 elements of a, and c[j] for j > n-1 is determined by the last 2n-1-j elements.

The minimum possible max, given that sum(c) = (sum a)^2 and c >= 0 and c has the convolution structure, is what we want.

1. Start with the parent sequence.
2. Compute the convolution, find the maximizing position j*.
3. Compute the gradient of the score w.r.t. each coordinate.
4. Take a step in the negative gradient direction (with projection to nonnegativity).
5. Repeat.
