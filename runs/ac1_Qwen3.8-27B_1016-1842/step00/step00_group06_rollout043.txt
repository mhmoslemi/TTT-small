```python
def convolve_fft(a):
    n = len(a)
    size = 2 * n - 1
    # Next power of 2 for FFT efficiency
    fft_size = 2 ** (size - 1).bit_length()
    fa = np.fft.rfft(a, fft_size)
    c = np.fft.irfft(fa * fa, fft_size)[:size]
    return c
```

This is O(n log n) per evaluation.
