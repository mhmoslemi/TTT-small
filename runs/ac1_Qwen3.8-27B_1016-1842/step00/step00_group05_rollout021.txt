The objective is $f(x) = 2n \max_k (x*x)_k / (\sum x)^2$.

Since it's scale-invariant, set $\sum x = n$ (or any fixed value). Then minimize $2n \max_k (x*x)_k / n^2 = 2 \max_k (x*x)_k / n$.

So we want to minimize $\max_k (x*x)_k$ subject to $\sum x = n$ and $x_i \geq 0$.

This is equivalent to: find $x \geq 0$, $\sum x = n$, that minimizes $\|x*x\|_\infty$.

This is related to the "low autocorrelation" problem but for non-negative sequences.

One approach: alternating minimization.

3. Update $x \leftarrow x + t d$.
