Actually, this is the dual ascent for the LP. Let me formalize:

LP dual: min $M \sum_k y_k$ s.t. $\sum_k y_k a_j \mathbf{1}[k-j \in [0,n-1]] \ge 1$ for all $j$, $y_k \ge 0$.

Let $W_j = \sum_{k=j}^{j+n-1} y_k$ (the windowed sum of $y$). The constraint is $a_j W_j \ge 1$, i.e., $W_j \ge 1/a_j$.

Dual ascent:
- Initialize $y_k = 1/(2n)$ for all $k$
- Repeat:
  - Find the most violated constraint: $j^* = \arg\min_j a_j W_j$
  - Increase $y$ in the window $[j^*, j^*+n-1]$ to fix the violation
  - Or use subgradient: $y_k \leftarrow y_k + \eta \cdot \mathbf{1}[k \in [j^*, j^*+n-1]] - \text{normalization}$

The primal solution is then: $b_j \propto 1/(a_j W_j)$ (by complementary slackness, $b_j > 0$ only where $a_j W_j = 1$).

This is $O(n)$ per iteration (for the windowed sum update) and we need $O(n)$ iterations for convergence. Total: $O(n^2)$ per LP solve. For $n = 5582$, that's 31M operations, which is comparable to one convolution.

```python
def lp_direction(a, M, n, iters=50):
    """Compute LP direction via a few steps of dual ascent."""
    # Dual variables y_k for k in [0, 2n-2]
    y = np.full(2*n-1, 1.0/(2*n-1))
    
    for _ in range(iters):
        # Compute W_j = sum_{k=j}^{j+n-1} y_k for j in [0, n-1]
        # (clip k to [0, 2n-2])
        cdf_y = np.concatenate([[0], np.cumsum(y)])
        W = np.zeros(n)
        for j in range(n):
            k_start = j
            k_end = min(j + n, 2*n-1)
            W[j] = cdf_y[k_end] - cdf_y[k_start]
        
        # Most violated constraint: min_j a_j * W_j
        violations = a * W
        j_star = np.argmin(violations)
        
        # Update y: increase in window [j_star, j_star+n-1]
        k_start = j_star
        k_end = min(j_star + n, 2*n-1)
        eta = 0.1 / (violations.min() + 1e-10)
        y[k_start:k_end] += eta
        
    # Primal direction: b_j ∝ 1/(a_j * W_j)
    b = 1.0 / (a * W + 1e-10)
    b = b / b.sum()
    return b
```
