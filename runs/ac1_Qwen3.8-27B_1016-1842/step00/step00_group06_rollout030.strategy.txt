        \item Full coordinate update using projected gradient: $x := \text{clip}_+ (x - \alpha_k g)$ \label{step:projected_update}
        \item Multi-start interpolation: $x_{\text{start}} = \text{sample\_start}(best)$ (random block perturbation)
        \item Alternate search along gradient and interpolate off-optimization plateaus
     \end{enumerate}
   Evaluate projected and perturbed candidates with exact evaluator.

4. **Search choices**:
   - $\epsilon_{\text{grad}} = 0.001 \times \operatorname{std}(x)$
   - $\xi = 0.1 \times \mathrm{IQR}(x)$
   - Step size determination: backtracking Armijo line search
   - Plateau detection: score monitoring over 3 steps
   - Multi-start probability: $p_{\text{multi}} = 0.2 + 0.8 e^{-\tau / 500}$

5. **Compute budget and robustness**:
   - Initial setup: 3 exact evaluations
   - Iterations: $50 \times 4$ per high-low $\xi$ sweep
   - Backup: 5 parareto-optimal oversampled candidates
   - Graceful degradation: $\epsilon_{\text{grad}}$ increases with iteration count

6. **Validation contract**:
   - Retains 3 best candidates via $\|x\|_1$ flow
   - Continuously evaluates proposed sequences with exact evaluator
   - Score: $f(x) = 2n \cdot \max(\operatorname{convolve}(x, mode="full")) / (\sum x_i)^2$
   - Fallback selection: sequence with $lowest\_f$
   - Bounding: clip to $[1e-10, 1000]$ before evaluation
</strategy>
