     Approximates \( \nabla_{\mathbf{a}} \text{AC1} \) by \( \nabla_{\mathbf{a}} \approx \frac{1}{\epsilon} \left( \text{AC1}(\mathbf{a} + \epsilon\mathbf{e}_i) - \text{AC1}(\mathbf{a}) \right) \) for random directions \( \mathbf{e}_i \), using two evaluations per dimension.  
   - **Gradient-Based Update:**  
     \( \mathbf{a} \leftarrow \mathbf{a} - \alpha \nabla_{\mathbf{a}} \text{AC1} - \beta \mathbf{a}_{\text{prev}} - \gamma \hat{\mathbf{b}} \),  
     where \( \hat{\mathbf{a}}_\text{{prev}} \) is the previous state, and \( \hat{\mathbf{b}} \) is a momentum term accounting for curvature.  

   **Jensen Lower Bound (Relative Performance):**  
   \( J(\mathbf{a}) \leq \text{AC1}(\mathbf{a}) \) for comparison, where \( J(\mathbf{a}) = C \cdot \frac{\left( \int \mathbf{a}(x) \, dx \right)^2}{\int \mathbf{a}(x)^2 \, dx} \) (computed efficiently).  

   **Fallback Configuration:** Sequence with coefficients averaged to \( \frac{0.01}{n} \) and clamped to (0,1000).  

   **Memory and Cost:**  
   - Each gradient estimation costs O(n²) evaluations, so gradient updates are batched (every 5 updates).  
   - Total evaluations bounded by solver's finite-difference calls.

3. **Implementation Procedure:**

   **Steps:**
   - (Parent Initialization): Load `height_sequence_1` and compute initial score.  
   - (Timer and Budget): Set `deadline = time.now() + budget_s` seconds.  
   - (Gradient Batch Unit)():  
     - For a batch of coefficients \( \Delta\mathbf{a} \), compute finite-difference gradients at current `best`.  
     - If unstable gradients, use random search estimates.  
     - Augment gradient with Jensen bound for stability.  
   - (Stochastic Mutation Unit)():  
     - With prob \( p_\text{{restart}} = \min(0.05, \frac{timer}{total-time}) \), perturb `best` by adding small random blocks.  
     - Otherwise, refine `best` using gradient descent (Adam-inspired).  
   - (UnaryTest Unit): After each mutation/stochastic step, evaluate new candidate.  
   - (Budget Enforcement):  
     - `evaluate_sequence` costs \( t_\text{{convolve}} \) seconds; track total cost.  
     - If `evaluate_sequence` fails (ineval), revert to fallback.  
   - (Termination): While current time < deadline:  
     - Budget = `deadline - current_time`.  
     - Generate k=3 candidate sequences via stochastic and Jacobian-informed mutation.  
     - Evaluate each and update `best` if score improves.  
   - Return `best`.
