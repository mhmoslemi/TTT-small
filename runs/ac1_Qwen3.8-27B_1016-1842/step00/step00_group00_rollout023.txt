Let me also think about whether there are structural insights. For the autocorrelation to be flat, we want a sequence whose Fourier transform has flat magnitude (like a "white" sequence). But for non-negative sequences, this is constrained: the DC component (sum) is fixed positive, and the magnitude is |FFT(a)[f]|.

The Wiener-Khinchin theorem says the autocorrelation's FFT is |FFT(a)|^2. So minimizing the peak of the autocorrelation (in time domain) is related to making |FFT(a)|^2 flat (in frequency domain).

For a non-negative sequence with fixed sum, the most "flat" |FFT(a)|^2 is achieved when a is as close to a "random" (but non-negative) sequence as possible. However, the DC bin is fixed at S^2, so the remaining bins should be as equal as possible.

This suggests that a good approach is:
1. Fix the sum S
2. Maximize the entropy of |FFT(a)|^2 (or minimize its variance)
3. Subject to a >= 0

This is a non-convex problem in general, but gradient-based methods can work.

import numpy as np
import time


def _fft_conv(a):
    n = a.size
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    A = np.fft.rfft(a, size)
    return np.fft.irfft(A * A, size)[:2 * n - 1]


def _score(a, conv):
    S = a.sum()
    if S < 0.01:
        return float('inf')
    return float(2.0 * a.size * conv.max() / (S * S))


def _grad(a, conv):
    n = a.size
    S = a.sum()
    M = conv.max()
    k = int(conv.argmax())
    S2 = S * S
    g = np.full(n, -4.0 * n * M / (S2 * S), dtype=np.float64)
    lo = max(0, k - n + 1)
    hi = min(n - 1, k)
    if lo <= hi:
        g[lo:hi + 1] += (4.0 * n / S2) * a[k - hi:k - lo + 1][::-1]
    return g
