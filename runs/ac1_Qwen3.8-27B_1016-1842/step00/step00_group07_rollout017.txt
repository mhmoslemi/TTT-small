OH WAIT. I think the issue is that in the discrete case, the score formula is 2n * max C(k) / S^2, and in the continuous limit, the "2n" factor has a different interpretation.

Let me redo the continuous limit more carefully.
Discrete: a_i, i=0..n-1, S = sum a_i, C(k) = sum_i a_i a_{k-i}.
Continuous: a(x), x in [0,1], S_c = integral a, C_c(τ) = integral a(x)a(x+τ)dx for autocorrelation.
For full convolution: (a*a)(t) = integral a(x)a(t-x)dx, t in [0,2].

The discrete score: 2n * max_k C_disc(k) / S_disc^2.
S_disc = sum a_i ≈ n * S_c (if a_i = a(i/n)).
C_disc(k) = sum a_i a_{k-i} ≈ n * (a*a)(k/n) (approximately, with the right scaling).

Actually: C_disc(k) = sum_{i} a(i/n) a((k-i)/n) ≈ n * integral a(x) a(k/n - x) dx = n * (a*a)(k/n).

So: score = 2n * n * max_t (a*a)(t) / (n * S_c)^2 = 2n^2 * max_t (a*a)(t) / (n^2 * S_c^2) = 2 * max_t (a*a)(t) / S_c^2.

For a(x) = x: 2 * (1/6) / (1/4) = 2/6*4 = 4/3. ✓
For a(x) = x^2: 2 * (1/30) / (1/9) = 2/30*9 = 18/30 = 3/5.
