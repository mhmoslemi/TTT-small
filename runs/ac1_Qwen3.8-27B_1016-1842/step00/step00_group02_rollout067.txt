Actually, let me reconsider the LP approach. The LP is:
max sum(g) subject to (f*g)[k] ≤ M for all k, g ≥ 0.

The constraint (f*g)[k] ≤ M can be written as: for each k, sum_j f[j]*g[k-j] ≤ M.

This is a linear program with n variables (g_0,...,g_{n-1}) and 2n-1 constraints plus n nonnegativity constraints. Total: 3n-1 constraints, n variables.

The constraint matrix A is (2n-1) × n where A[k,j] = f[j] if 0 ≤ k-j < n, else 0. This is a banded Toeplitz matrix with bandwidth n. The total number of nonzeros is sum_k min(n, k+1, 2n-1-k, n) ≈ n²/2.

For n=6962, that's about 24 million nonzeros. This is too many for a practical LP.

Alternative: Use a "matrix-free" approach. The constraint (f*g)[k] ≤ M can be evaluated in O(n) for a given k, or O(n log n) for all k using FFT. But an LP solver needs to evaluate the constraint matrix times a vector, which is O(n log n) using FFT.

Actually, A*g = convolve(f, g) (full convolution). And A^T * y where y is the dual variable: (A^T*y)[j] = sum_k y[k]*f[j] where 0 ≤ k-j < n = f[j] * (sum over valid k of y[k]) = f[j] * (y convolved with ones)[j]... 

Actually A^T * y: (A^T*y)[j] = sum_k A[k,j]*y[k] = sum_k f[j]*y[k] (where 0≤k-j<n) = f[j] * sum_{k=j}^{j+n-1} y[k] (clipped to valid range).

This can be computed with a prefix sum in O(n) for the sum part, then multiplied by f[j]. So A^T*y is O(n).

And A*x = convolve(f, x) which is O(n log n) via FFT.

So we can implement the LP in a matrix-free way! Each iteration of the LP solver needs:
- A*x: FFT convolution, O(n log n)
- A^T*y: prefix sum + multiply, O(n)
