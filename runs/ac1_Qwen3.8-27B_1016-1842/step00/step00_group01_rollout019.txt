This is a quadratic program (or SOCP). The constraint (a*a)[k] <= t is quadratic in a (it's a sum of products of pairs). This is a non-convex quadratic constraint in general (since a >= 0, the products are bilinear).

Wait, (a*a)[k] = sum_i a[i]*a[k-i]. For a >= 0, this is a sum of nonnegative terms, so the constraint (a*a)[k] <= t defines a non-convex region (it's the interior of an ellipsoid-like surface).

However, if we fix some of the variables and optimize over others, it becomes convex. This is the basis of the LP relaxation in the paper.

For the LP relaxation: Fix a, and find b that maximizes sum(b) subject to (a*b)[k] <= M, b >= 0. This IS convex (linear constraints). The matrix has a nice Toeplitz structure.

Actually, let me try a different approach entirely. What about using the "Frank-Wolfe" (mirror descent) method?

The problem: min f(a) = 2n * max_k (a*a)[k] / (sum a)^2, a >= 0, sum(a) >= 0.01.

By scale invariance, fix sum(a) = 1. Then: min g(a) = max_k (a*a)[k], a >= 0, sum(a) = 1.

This is a non-convex problem (the feasible set is convex, but g is not convex). However, g(a) = max_k h_k(a) where h_k(a) = (a*a)[k] is a quadratic form. Each h_k is not convex in general (it's bilinear).

- At current a, compute the subgradient of g at a: it's the "pressure" vector from the peak position(s).
- The linear minimization over the simplex {b: b>=0, sum(b)=1} of the subgradient gives a vertex (a unit vector e_j).
- Update: a ← (1-t)*a + t*e_j.

This is the "conditional gradient" method. But it's very slow (only picks one coordinate at a time).
