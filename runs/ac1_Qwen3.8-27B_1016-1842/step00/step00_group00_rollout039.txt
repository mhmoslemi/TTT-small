This is a convex problem. The subgradient method converges, but the rate is $O(1/\sqrt{T})$ for the function value. Starting from a score of 2 (uniform), after $T$ iterations, the score should be bounded by:

where $\alpha$ is the minimum step size. This is a very slow rate.

Alternative: Use the Frank-Wolfe (conditional gradient) method. At each iteration:
1. Compute the subgradient $g = \nabla \max_m (a*a)_m$ (or smoothed version).
2. Solve the linear minimization: $\min_{y \in \Delta} g^T y$ where $\Delta = \{y : y \geq 0, \sum y = 1\}$ (the simplex).
3. The solution is $y = e_j$ where $j = \arg\min g_j$ (a vertex of the simplex).
4. Update: $a \leftarrow (1-\gamma) a + \gamma y$ where $\gamma$ is the step size.

The linear minimization over the simplex is trivial: just pick the coordinate with the smallest gradient component. This is $O(n)$.

The Frank-Wolfe method also converges as $O(1/T)$, which is better than $O(1/\sqrt{T})$.

However, the Frank-Wolfe update $a \leftarrow (1-\gamma) a + \gamma e_j$ can only increase the mass at coordinate $j$ and decrease it everywhere else proportionally. This is a very limited update. For a problem where the optimal solution has a complex shape (not a single spike), Frank-Wolfe might be slow.

A better approach: use the "away steps" variant of Frank-Wolfe, or use the "pairwise" Frank-Wolfe where $y$ is a convex combination of two vertices.

Actually, here's another idea: since the problem is convex and the feasible set is a simplex, I can use mirror descent (which is equivalent to multiplicative weight updates / follow-the-regularized-leader).

Mirror descent with the negative entropy as the regularizer on the simplex:
$a_i^{(t+1)} \propto a_i^{(t)} \exp(-\eta g_i^{(t)})$

where $g_i^{(t)}$ is the subgradient component and $\eta$ is the step size.

This is equivalent to:
$a_i^{(t+1)} = \frac{a_i^{(t)} \exp(-\eta g_i^{(t)})}{\sum_j a_j^{(t)} \exp(-\eta g_j^{(t)})}$

This is a "multiplicative" update that maintains the simplex constraint automatically.

For our subgradient $g_i = 2\sum_j a_j w_{i+j}$, the update is:
$a_i \leftarrow a_i \exp(-\eta \cdot 2\sum_j a_j w_{i+j})$

This can be computed in $O(n)$ after computing the subgradient.

The mirror descent method has a convergence rate of $O(1/T)$ for the function value (for convex problems), which is better than the standard subgradient method.
