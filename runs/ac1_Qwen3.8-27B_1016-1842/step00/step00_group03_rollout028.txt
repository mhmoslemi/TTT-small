- Project: grad_proj = grad - mean(grad)
- Take a step: a -= step * grad_proj
- Clip and renormalize

The antisymmetric perturbation insight suggests that the method should naturally move toward antisymmetric shapes (relative to the center) to reduce the peak.

Let me now think about the optimal shape for large n. The target is AC1 ≈ 1.5, which means max_b/S^2 ≈ 1.5/(2n) ≈ 0.000296 for n=2535.

For a uniform sequence, max_b/S^2 = 1/n ≈ 0.000394. So we need to reduce by about 25%.

I think the optimal shape for large n is close to uniform but with a specific modulation. Let me think about what kind of modulation.

If a[i] = (1/n)(1 + A*cos(2π*k*i/n)) for small A and some frequency k:
The convolution will have the DC component plus sidebands at ±k. The peak will be at lag n-1 with value (1/n)(1 + A^2/2) (the cos^2 averages to 1/2). Other lags will have the cosine modulation. The max of the sidelobes is (1/n)(1 + A) (at the appropriate lag).

For the max to be less than 1/n, we need 1 + A < 1, i.e., A < 0. But A<0 just flips the phase. So a pure cosine modulation can't help.

What about a[i] = (1/n)(1 + A*sin(2π*k*i/n))?
Convolution: the sin term creates an antisymmetric component. b[n-1] = (1/n)(1 + A^2/2) (the cross terms vanish by orthogonality). The sidelobes at lag n-1±k have amplitude (1/n)(1 ± A/2). For A > 0: the max sidelobe is (1/n)(1+A/2) which is > 1/n. So this makes things worse for the sidelobes.

def _eval(a):
    """Quick evaluation matching the authoritative evaluator."""
    b = np.convolve(a, a)
    S = a.sum()
    if S < 0.01:
        return np.inf
    return float(2 * len(a) * b.max() / (S * S))

    best = a0.copy()
    best_score = float(evaluate_sequence(best.tolist()))

                best_score = s

    a = best.copy()
    step = 1.0 / n
    patience = 0
    L = 3  # number of top lags to consider
    
    while time.monotonic() < deadline:
        b = np.convolve(a, a)
        S = a.sum()
        
        # Find top L lags
        if L < len(b):
            top = np.argpartition(-b, L)[:L]
        else:
            top = [int(np.argmax(b))]

        grad = np.zeros(n)

            m = (src >= 0) & (src < n)
            grad[m] += a[src[m]]
        grad /= len(top)

        grad -= grad.mean()

        a_new = np.maximum(a_new, 0.0)

        best = best / bs * np.sqrt(2*n)  # doesn't matter, evaluator handles scaling
    # Actually, return as-is (sum-normalized to 1 is fine)
    return [float(x) for x in best]
