The key is to make (a*a)_{n-1} = sum a_j * a_{n-1-j} small. This is the "inner product" of a with its reverse. If a is "anti-correlated" with its reverse, this will be small. Cauchy-Schwarz: (sum a_j * b_j)^2 <= (sum a_j^2)(sum b_j^2). With b_j = a_{n-1-j}:
(sum a_j * a_{n-1-j})^2 <= (sum a_j^2)(sum a_{n-1-j}^2) = (sum a_j^2)^2

So sum a_j * a_{n-1-j} <= sum a_j^2. That's an upper bound, not lower.

For a lower bound: since a_j >= 0 and a_{n-1-j} >= 0, the sum is >= 0. And it can be made arbitrarily close to 0 if, say, a is concentrated in the first half and a_{n-1-j} (i.e., a reversed) is concentrated in the second half. But wait, a_{n-1-j} for j in the first half IS the second half of a. So if a is concentrated in the first half, then a_{n-1-j} for j in the first half is the second half of a, which has small values. So the overlap is small!

Example: a_j = 1 for j < n/2, 0 for j >= n/2.
(a*a)_{n-1} = sum_{j=0}^{n-1} a_j * a_{n-1-j}
For j < n/2: a_j = 1, a_{n-1-j} = a_{n-1-j}. Since j < n/2, n-1-j > n/2-1, so a_{n-1-j} = 0 (for n-1-j >= n/2).
For j >= n/2: a_j = 0.
So (a*a)_{n-1} = 0!

But the peak of the full convolution: for this "block" sequence, (a*a)_k for k < n/2-1 is k+1 (growing), peaks at k = n/2-1 with value n/2, then decreases.

Score = 2n * (n/2) / (n/2)^2 = 2n * n/2 / (n^2/4) = 2n * 2/n = 4.

That's worse than 2. The peak is at a lag where both a_j and a_{k-j} are 1 for many j.

So minimizing just (a*a)_{n-1} isn't enough; we need to minimize the GLOBAL peak.

def simplex_project(v, s):
    """Project v onto {x >= 0, sum(x) = s}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cv = np.cumsum(u)
    w = np.arange(1, n+1, dtype=np.float64)
    cond = (cv - s) / w < u
    if not np.any(cond):
        return np.full(n, s/n)
    rho = int(np.max(np.where(cond)[0])) + 1
    theta = (cv[rho-1] - s) / rho
    return np.maximum(v - theta, 0.0)
