1. Approach and rationale

1.1 Central idea

Build a hybrid nonsmooth optimizer that always validates every proposed solution with the exact evaluator

    C5(h) = dx * max( np.correlate(h, 1 - h, mode="full") ) ,  dx = 2 / n

and improves it by combining:

- A parent starting point with smooth surrogate local optimization (log-sum-exp / smoothed-max objective) in several equivalent variable representations.
- Exact active-set first-order descent using finite directional derivatives of exact correlation scores plus an LP-generated, sum-preserving direction.
- Pairwise exact stochastic annealing / random restarts in the same feasible slice to escape small local plateaus.
- Resolution-transfer constructs over nearby template lengths, always returning only arrays that have passed a joint feasibility repair and exact reevaluation.

The problem is small-dimensional (the supplied parent has n=47), so exact `np.correlate` evaluations are cheap. The bottleneck is not raw evaluation cost but the nonsmooth maximum over many lags. A single smooth surrogate can stall or become insensitive to the margin needed to lower the exact bound by ~5e-5. Therefore the plan uses a smooth surrogate only to move in basins of attraction; every accepted candidate is accepted only after exact recomputation of the authoritative objective on a feasible repaired vector.

No global optimality is claimed. The only claim is an upper bound: if returned h is displayed feasible by the repair/evaluation helper, then the returned `c5_bound` is an actual exact evaluator result.

1.2 Substantive differences from a purely surrogate or purely integer/packet strategy

The primary method is not an integer/dyadic packet simulation and not exclusive to one fixed dimension or one smooth-clipped gradient path. It is a continuous constrained funnel that:

- Handles the equality and box constraints jointly by a water-fill-like projection.
- Uses multiple representations:
  - Full variables with the linear sum constraint.
  - Reflection antisymmetry: h[2 - x] = 1 - h(x), which reduces dimension and enforces the mass constraint automatically.
  - Translation complement symmetry (for even lengths): h(x + 1 shifted by half the template) = 1 - h(x), also enforcing mass automatically.
- Uses active exact correlation lags rather than only random perturbation or surrogate soft details.
- Transfers candidates between nearby n values and optimizes them there too, because the exact filter discretization can make marginally different lengths attain a lower discrete maximum.
