    """Project x onto {0 <= x_i <= 1, sum(x) = target_sum} using water-filling."""
    n = len(x)

Let me think about the Nesterov-style minimax more carefully. The idea is:

We want to minimize max_d F_d(h). This can be reformulated as:
minimize t
subject to F_d(h) <= t for all d
0 <= h <= 1
sum(h) = n/2

Nesterov's approach uses a dual variable w (probability distribution on rows) and alternates:
1. Given w, minimize sum_d w_d * F_d(h) subject to constraints → get h*(w)
2. Update w: w_d ∝ w_d * exp(eta * F_d(h*(w))) (or similar)

Step 1 is a quadratic program (since F_d is quadratic in h). Actually it's a convex quadratic if we look at it carefully... no, it's not necessarily convex.

F_d = sum_{i in range} h[i] * (1-h[i-d]) = sum h[i] - sum h[i]*h[i-d]

The Hessian of F_d has diagonal entries -2dx (from -h[i]^2 when d=0, or from cross terms) and off-diagonal entries. It's not positive semi-definite in general, so the problem is nonconvex.

However, for a fixed w, the weighted sum sum w_d * F_d is still the same type of problem. So step 1 is nonconvex too.

In practice, we can use gradient descent or SLSQP for step 1.

            best_c5 = c5_try
            best_h = h_try.copy()
    
    # Phase 2: Projected gradient on initial grid
    if not _timed_out():
        alphas_pg = [50, 100, 200, 500]
        h_try, c5_try = _proj_grad(best_h, alphas_pg, n_iters=400)

    if not _timed_out():
        for eta in [0.3, 0.5, 1.0]:

                best_h = h_try.copy()

    grid_sizes = [36, 48, 60, 80, 100]

        # Transfer to new grid
        h_try = _coarse_fine_transfer(best_h, n_new)
        c5_try, _ = _c5_exact(h_try)

        # Projected gradient
        if not _timed_out():

            if c5_try3 < c5_try:

        if c5_try < best_c5:
            best_c5 = c5_try
            best_h = h_try.copy()
            best_n = n_new
    
    # Phase 5: Fine-tune on best grid
    if not _timed_out():
        n_best = len(best_h)
        for alpha in [100, 200, 500, 1000]:
            if _timed_out():

            h_try = _slsqp_optimize(best_h, alpha, maxiter=200)

            if c5_try < best_c5:
                best_c5 = c5_try
                best_h = h_try.copy()
    
    # Phase 6: Final projected gradient polish
    if not _timed_out():
        h_final, c5_final = _proj_grad(best_h, [200, 500, 1000], n_iters=300)
