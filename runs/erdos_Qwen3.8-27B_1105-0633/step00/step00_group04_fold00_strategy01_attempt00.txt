1. Approach and rationale

The evaluator is a finite-dimensional, nonconvex minimax problem over a box plus one equality constraint:
C(h) = (2/n) * max over 2n-1 finite-support lags of sum_{i,j=i+lag} h_i * (1-h_j).
The parent supplied by the environment is a feasible discrete construction with about 70 samples and should be retained as a fallback, not copied into the returned source as a hard-coded table.

The centralized idea is to move the search into a smooth unconstrained parameter space that can only produce feasible vectors. Instead of optimizing h_i directly under hard box constraints and an explicit equality (`sum(h)=n/2`), every candidate is generated by
h(c) = sigmoid(B c + theta(c))
where theta(c) is the unique scalar that makes the sigmoid sum equal n/2. This automatically satisfies 0<h_i<1 and sum(h)=n/2 (up to machine precision, followed by a final exact feasibility repair). The actual returned vector is always repaired and re-scored using the original `np.correlate` metric.

In the unconstrained parameter space, the exact max-of-raw-scores is replaced by a temperature-controlled exponential smoothing surrogate. L-BFGS is used on the smoothed surrogate with analytic gradients. The surrogate is only a search engine: every relevant visit is evaluated by the original discrete objective and accepted only if the exact score improves. This separation avoids relying on a claimed convex relaxation; products are not assumed convex. The method may find a better local/global minimum but makes no global-optimality claim.

This approach differs from plain box-constrained gradient descent or projection-repair methods because:
- The feasible set is embedded directly, so the optimizer never tries an invalid pair move and never oscillates between separate projection and clipping operators.
- The equality constraint is preserved to machine precision by a one-dimensional root solve (theta), not by doing independent clipping and rescaling.
- The surrogate soft-max is smooth and has analytic derivatives, allowing a large number of restarts within a fixed budget.
- Search diversity is introduced through smooth Fourier/random families, deterministic transforms, optional coarse-grid refinement, and pair moves performed only at exact-scalar scores.

The search consumes its budget as follows: validate the current parent, generate several transformed initial vectors, run global/reduced-basis smooth probes, run full-dimensional smooth probes, then run short exact-score pair-move polishes. All candidates are evaluated in the author's benchmark using actual `np.correlate`; the final output is the exact-score feasible probe, and the parent is always retained.
