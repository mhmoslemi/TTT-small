1. Approach and rationale

1.1 Central idea

The supplied parent is already a near-record local point in the nonconvex problem

minimize over h ∈ [0,1]^N : sum_i h_i = N/2  the quantity

C_N(h) = max_r  dx * corlate(h, 1-h, 'full')[r],

where dx = 2/N. The task is therefore primarily local polish plus disciplined diversified search. The proposed method is not a certified global optimizer; it is a robust proposal engine for the exact evaluator, designed to exploit the supplied parent while also introducing enough independent starting points, resolutions, smoothings, and direct feasible line searches to move into a lower exact objective level if one exists in the chosen neighborhood.

The primary computations are:

- Start from the supplied parent, if available, as the best valid fallback.
- Repair its value/legal constraints exactly, then re-evaluate it with the supplied evaluator.
- Generate a set of diversified feasible starts around the parent and from independent compact constructions.
- Optimize a smooth softmax or log-sum-exp surrogate of the maximum correlation objective using SLSQP with bounds 0 ≤ h ≤ 1 and the equality constraint sum h = N/2.
- Use the exact evaluator for every candidate after feasibility repair, and retain only candidates that are valid and strictly better in the exact objective.
- Apply an active-set direct line search on the exact objective to polish near-maximal correlation plateaus, because a smooth surrogate can over-penalize non-dominant lags and can miss flat exact improvements.
- Search at several discrete resolutions, largest not exceeding a practical threshold, using resampling to transfer best vectors between lengths. Prefer exact objective improvement; secondarily prefer smaller resolution when exact values tie or nearly tie.
- Return the smallest class of valid best vector found before the deadline.

1.2 Why this can improve the parent

The parent is likely close to a local optimum of the non-smooth exact objective. The exact objective is the maximum of many discrete convolutions/cross-correlations. At optimum many lag sums are nearly tied. There are two paths to improvement:

- small continuous moves that lower several active lags while preserving the integral;
- slight changes of active support, for example reducing a fractional entry that contributes to several high-overlap lags.

A softmax surrogate h_c(h) = (1/β) log Σ_r exp(β C_{N,r}) has smooth gradients and reduces the non-smooth max to an approximate objective. SLSQP can handle box constraints and equality exactly with these smooth gradients. However the exact final metric is non-smooth and product-bearing; therefore we re-check and improve candidates under the exact maximum. We also intentionally retain the parent unless a valid candidate with strictly smaller exact C_N is found.

1.3 Main bottleneck and how it is addressed

The main issue is a bilinear objective: terms are h_i (1-h_j). This nonconvexity is not treated as a CVXPY model. The nonconvexity is handled through:

- smooth surrogate decomposition: for fixed softmax weights, the scalarized surrogate has ordinary gradients we can compute;
- active-set line search on the exact objective;
- multistart and fragmentation between parents;
- exact evaluation for every accepted candidate.

1.4 Limitations and hypotheses

- Local methods are not guaranteed to discover a global minimum nor guaranteed to achieve exactly target bound ≤ 0.3808.
- SLSQP uses smooth surrogate and can converge to one local surrogate minimum. Exact values will sometimes be slightly higher than the surrogate optimum. We attempt direct line searches after each stage to reduce the discounted surrogate influence.
- High β causes severe nonsmoothness and neuron-like search; moderate β schedules run safer.
- Exactness is assumed computationally commensurate; if gradients are incorrectly matched to numpy correlation orientation a SLSQP run visibly performs poorly. The methodology includes an automatic orientation alignment test.
- Smaller n is desirable but an improved lower exact value may occur at a larger resolution; we allow bound improvement in exact evaluation, preferring smaller only when exact value has no material tradeoff.
