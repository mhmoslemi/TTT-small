1.1 Core idea

amento I optimize the discrete step function exactly as a feasible vector in the box\(\cap\)simplex. The central optimization motif is not a smooth max or a nonconvex relaxation on all entries. It is exact affine line minimization along feasible zero-sum directions using the exact evaluator algebra.

A feasible transfer is represented as
```
h_t = h + t*d,
sum(d) approximately 0 so that the integral constraint is preserved.
```
For pure mass exchange
```
d = 1_j - 1_i        (equivalently one step moves one unit from coordinate i to j)
```
the sum is exactly preserved and the box constraints correspond to a simple interval for t. Since the evaluator is a bilinear correlation, the entire finite-support row vector is exactly a quadratic in t along any line. This gives a self-validating, exact line search over a true feasible one-dimensional face of the polytope.

The main search is:

A. assemble diverse valid starts, including the supplied parent, its reverse, its complement, integer-rounded versions, and random feasible points.

B. repeat exact feasible line minimization along often-used directions:
  1. single-pair exchange directions `d = e_a - e_b`.
  2. zero-sum random perturbation directions, with post-line feasibility repair.

C. accept any candidate only by recomputing the authoritative maximum overlap. No surrogate score is upgraded without exact reevaluation.

This idea is materially different from smooth-max/long-sum-exp matrix optimization or indefinite relaxation proposals. The geometry is selected by constructing genuinely feasible mass-transfers, whose row functions can be found exactly and checked directly against `np.correlate`. Nonconvexity is handled by stochastic direction choice and multistart, not by pretending that a relaxed model is globally valid.

1. Approach and rationale

1.1 Central method

The returned object is treated as a discrete feasible vector  
\[
h\in[0,1]^n,\qquad \sum_i h_i = n/2,
\]
with
\[
C_5(h)=\max_{m=0}^{2n-2} dx\,[\mathrm{corr}(h,1-h)]_m, \qquad dx=2/n,
\]
evaluated exactly by the authoritative rule

```
max(np.correlate(h, 1 - h, mode="full") * dx)
```

The central optimization motif is exact feasible line search. We do not globally convexify, replace the evaluator by a circular transform, or accept a surrogate score as the returned score. Only the above evaluator is used for acceptance.

Consider a feasible direction \(d\) with approximately zero sum and scale \(t\) inside
\[
0\le h_i + t d_i \le 1.
\]
For pure mass exchange use
\[
d=e_a-e_b,
\]
which transfers one unit-size value from coordinate \(b\) to coordinate \(a\). This is a true zero-sum edge direction of the box intersected with the sum constraint. Along such a line the exact row vector has the polynomial identity

\[
\operatorname{corr}(h+t d,\,1-(h+t d))
=
\operatorname{corr}(h,1-h)
+t\bigl(\operatorname{corr}(d,1-h)-\operatorname{corr}(h,d)\bigr)
-t^2\operatorname{corr}(d,d).
\]

Thus, if

```
C[m] = dx * corr(h, 1-h)[m]
B[m] = dx * (corr(d, 1-h)[m] - corr(h, d)[m])
A[m] = -dx * corr(d, d)[m]
```

then the full exact finite-support row scores along the feasible line segment are exactly

\[
F_m(t)=C_m+B_m t+A_m t^2,
\]
and the objective value is
\[
\phi(t)=\max_m F_m(t).
\]

For pair-exchange directions, the feasible interval \([L,U]\) can be explicitly recast from the box constraints. The solver then finds a good or locally exact minimizer of \(\phi(t)\) on that interval from candidates derived from quadratic rows and bracket refinement. The transformed vector is only accepted after rebuilding `h_t` and recomputing the original \(\mathrm{np.correlate}\) formula and feasibility.

1.2 Why this can improve the supplied parent

The target improvement, `0.38085 -> 0.3808`, is tiny and may require exploiting a narrow feasible path not visible to fixed penalties or low-dimensional parameterizations. Exact line search can follow one- and two-active-row envelopes while staying feasible. It also gives high precision for a local edge movement because, for the edge used, internal quadratic row models reconstruct the evaluator algebraically, subject to floating-point roundoff only. The key mechanisms intended to help:

- if the initial parent is near a nonsmooth minimizer, an active mass transfer can reduce the strictly largest row via exact line minimization;
- pairs of complementary/complement directions can produce better trade-offs among all rows;
- if the supplied construction is degenerate or flat in many directions, randomized feasible starts and zero-sum directions can sample other basins;
- valid seed constructions retain the current parent as an exact fallback.

1.3 Distinguishations and limitations

The method provides true feasible directions not convex representations of the nonsmooth objective. It is a stochastic, multistart, local-search scheme. It does not prove global optimality or provide a rigorous lower bound. The internal row-polynomial line evaluation is exact for a chosen zero-sum direction in exact arithmetic, but not every possible multi-coordinate nonsmooth minimum is guaranteed to lie on the generated coordinates and random directions. All heuristics are only candidates. The final `C5` returned must be measured later from the original evaluator after final repair.
