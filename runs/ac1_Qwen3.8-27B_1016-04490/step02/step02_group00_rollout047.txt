Key realization: The score is scale-invariant, so I can normalize to any sum. The key is to minimize `max(conv(a,a))` given `sum(a) = 1` (or any fixed value).

For the gradient, the simplest correct approach:
1. Compute `b = conv(a, a)` (full, via FFT)
2. Find the max value `b_max` and the set of indices where `b[k] >= b_max - eps` (active set)
3. The subgradient of `b_max` w.r.t. `a[j]` is `sum_{k in active} (a[k-j] + a[j-k])` (valid indices only)
4. For the full score `2n*b_max/(sum a)^2`, the gradient w.r.t. `a[j]` is:

   = `2n/((sum a)^2) * (db_max/da[j] - 2*b_max/(sum a))`

Since we can fix `sum(a) = 1` (scale invariance), the gradient simplifies to `2n * db_max/da[j]` (and we project back to sum=1 after each step).
