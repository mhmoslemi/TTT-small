Now, for the LSE gradient:
- Compute weights: `w[k] = exp(conv[k]/T - 1) / sum(exp(conv[j]/T - 1))` for k in [0, 2n-2]

This gives us a smooth gradient that accounts for all peaks, not just the top m. This should help escape local minima where a few peaks dominate.

Let me also think about the step size. The objective is `f(a) = 2*n*max(conv(a,a))` (with sum(a)=1 constraint). Using LSE approximation: `f_T(a) = 2*n*T*log(sum(exp(conv[k]/T)))`.

def next_pow2(m):
    p = 1
    while p < m:
        p <<= 1

def fft_conv(a, fs):
    A = sfft.rfft(a, fs)
    out = sfft.irfft(A * A, fs).real[:2 * len(a) - 1]
    return np.maximum(out, 0.0)


def lse_weights_inplace(conv, T, out):
