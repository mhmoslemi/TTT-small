So `d q_k / d a_j = a_{k-j} + a_j` (when both indices are in [0, n-1]).

`grad_j = sum_k p_k * (a_{k-j} + a_j) = c_j + a_j * sum_k p_k = c_j + a_j`

where `c_j = sum_k p_k * a_{k-j}` (with out-of-bounds a values being 0).

So `grad = c + a` where `c = cross_correlation(p, a)`.

The objective is `f(a) = T * log(sum exp(b_k/T))` (smooth approximation to `max b_k`).
`df/da_j = sum_k p_k * db_k/da_j = sum_k p_k * (a_{k-j} + a_j) = c_j + a_j`.

So the gradient is `c + a` where `c_j = sum_{k=0}^{2n-2} p_k * a_{k-j}`.

This can be computed via FFT in O(n log n).

Now, for the optimization:
- We want to minimize `2n * max_b / S^2` where `S = sum a`.
- Since it's scale-invariant, fix `S = 1` (or `S = sqrt(2n)` as in the previous code).
- Minimize `max_b` subject to `a >= 0, sum a = 1`.

Using the smooth approximation, we minimize `f_T(a) = T * log(sum exp(b_k/T))` subject to `a >= 0, sum a = 1`.

We can use projected gradient descent or the mirror descent approach.

Actually, since the constraint is `sum a = 1, a >= 0`, we can parameterize with `a = exp(w) / sum(exp(w))` (softmax parameterization) to handle the simplex constraint. But this changes the geometry.

Alternatively, we can use the previous approach: gradient step + projection to the simplex (clip to [0, 1000] and rescale to sum = target).

def _next_pow2(m):
    p = 1
    while p < m:
        p <<= 1
    return p

def _compute_grad(a, T, N):
    """Compute gradient of smooth max approximation."""
    # b = conv(a, a) via FFT
    b = np.real(sfft.irfft(sfft.rfft(a, N) ** 2, N))[:2*len(a)-1]
    b = np.maximum(b, 0)  # ensure non-negative (numerical)
    
    # Softmax weights
    b_shifted = b - b.max()
    p = np.exp(b_shifted / T)
    p_sum = p.sum()
    if p_sum < 1e-300:
        p = np.zeros_like(b)
        p[(2*len(a)-1)//2] = 1.0
    else:
        p /= p_sum

    A = sfft.rfft(a, N)
    c = np.real(sfft.irfft(P * np.conj(A), N))[:len(a)]
