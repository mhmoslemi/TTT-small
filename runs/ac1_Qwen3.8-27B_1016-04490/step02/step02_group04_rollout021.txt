Actually, let me think about a different approach that might work better: **convex optimization via repeated projection**.

The problem: minimize max_j (a*a)[j] / (sum(a))^2, a >= 0.

Since it's scale-invariant, set sum(a) = 1 (or sqrt(2n)):
minimize max_j (a*a)[j] subject to sum(a) = S, a >= 0.

This is equivalent to: find the smallest M such that (a*a)[j] <= M for all j, sum(a) = S, a >= 0.

For fixed M, the feasible set is defined by quadratic constraints. We can use an iterative method:
1. Start with a in the feasible set (or near it)
2. Find the most violated constraint: j* = argmax (a*a)[j]
3. Project a onto the half-space {x : (x*x)[j*] <= M} while maintaining sum(x) = S, x >= 0
4. Repeat

The projection onto {x : (x*x)[j] <= M} is non-trivial (it's a quadratic constraint). But we can approximate it.
