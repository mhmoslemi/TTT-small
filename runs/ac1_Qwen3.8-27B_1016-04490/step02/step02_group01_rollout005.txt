= a[m-j] (from first term, if 0 <= m-j < n) + a[m-j] (from second term, where i = m-j, if 0 <= m-j < n)

Wait, second term: sum_i a[i] * δ(m-i, j) = a[m-j] if 0 <= m-j < n.

So ∂g_m/∂a[j] = 2 * a[m-j] if 0 <= m-j < n, else 0.

This is the same formula I had before. Good.

So the subgradient direction is: for the argmax lag k*, `g[j] = 2 * a[k*-j]` for valid j. This is essentially a reversed/shifted copy of a.

Now, the algorithm:
1. Normalize a to sum = S
2. Compute conv(a,a) via FFT
3. Find argmax lag k*
4. Compute subgradient g[j] = 2*a[k*-j] (reversed/shifted)
5. Project: g -= g.mean() (to prevent changing the sum)
6. Update: a -= step * g
7. Clip to [0, ∞)
8. Renormalize to sum = S
9. Repeat

For the step size, I'll use an adaptive scheme. Since we're on the constraint sum(a) = S after normalization, the effective step is in the direction of g - g.mean(). The norm of this direction is ||g - g.mean()||.

A good step size would be: `step = alpha / ||g - g.mean()||` where alpha is a small constant (like 0.1 * S / n or similar). Or just a fixed small step with annealing.

Let me also consider using **multiple active lags**. If the top K lags of conv(a,a) are all close to the max, averaging their subgradients gives a more stable direction.
