Let j = i-k: `G[k] = sum_{j: 0≤j≤n-1, 0≤j+k≤2n-2} p[j+k] * a[j]`
Since k ≥ 0 and j ≤ n-1, j+k ≤ n-1+k ≤ 2n-2 (for k ≤ n-1). So the condition is just 0≤j≤n-1.
`G[k] = sum_{j=0}^{n-1} a[j] * p[j+k]`

This is the cross-correlation of a and p at lag k: `(a ⊛ p)[k] = sum_j a[j] * p[j+k]`.

The FFT formula for cross-correlation: `ifft(FFT(a) * conj(FFT(p)))` gives `(a ⊛ p)[k] = sum_j a[j] * p[j+k]` (circular). With zero-padding ≥ n + (2n-1) - 1 = 3n-2, it gives the linear version.

So: `G[k] = real(ifft(rfft(a, cs) * conj(rfft(p, cs))))[k]` for k = 0, ..., n-1.

In my code: `corr = np.real(sfft.irfft(Xc * np.conj(P), cs))` where `Xc = sfft.rfft(x, cs)` and `P = sfft.rfft(p, cs)`.

This gives `corr[k] = sum_j x[j] * p[j+k]` for k = 0, ..., cs-1 (circular, but linear with padding).

So `g = 2.0 * corr[:n]` gives the gradient. ✓

def _np2(m):
    p = 1
    while p < m:
        p <<= 1
    return p

def _norm(x, target):
    s = x.sum()
    if s < 1e-10:
        return np.ones_like(x) * (target / x.size)
    x = x * (target / s)
    return np.clip(x, 0.0, 1000.0)

def _scf(x, fs):
    n = x.size
    X = sfft.rfft(x, fs)
    c = np.real(sfft.irfft(X * X, fs))[:2*n-1]
    s = x.sum()
    if s < 1e-10:
        return np.inf
    return 2.0 * n * c.max() / (s * s)
