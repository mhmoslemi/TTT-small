```python
def _subgrad_lag(x, m, n):
    g = np.zeros(n)
    # (a*a)[m] = sum_j a[j] * a[m-j] for valid j, m-j
    # grad w.r.t. a[j] = a[m-j] if 0 <= m-j < n
    lo = max(0, m - n + 1)
    hi = min(n - 1, m)
    j_range = np.arange(lo, hi + 1)
    g[j_range] = x[m - j_range]
    return g
```

1. Compute conv via FFT to find top positions (one FFT pair)
2. Pick a random position from top-k
3. Compute subgradient via indexing (O(n))
4. Take a step

```python
        # Perturbation
        if it % 5000 == 0:
            strength = 1e-3 * (1.0 - elapsed) + 1e-5
            x += strength * rng.standard_normal(n)
            x = _ps(x, ts)
        
        # Restart
        if noi > 6000:
            x = _ps(best + rng.normal(0, max(best.std(), 0.01)*0.04, n), ts)
            x = np.clip(x, 0, 1000)
            noi = 0
    
    fs2 = _sc(best)
    if not np.isfinite(fs2):
        return [float(ts/n)] * n
    return best.tolist()
```
