- Pad f to length N
- Compute ifft(FFT(w) * conj(FFT(f)))[:n]

So the gradient computation is:
```python
def compute_grad(f, w):
    """w has length L=2n-1, f has length n. Returns gradient of sum(w*c) w.r.t. f, length n."""
    n = len(f)
    L = 2*n - 1
    N2 = 1 << (3*n - 2 - 1).bit_length()  # >= 3n-2
    W = np.fft.rfft(w, N2)
    F = np.fft.rfft(f, N2)
    cc = np.real(np.fft.irfft(W * np.conj(F), N2))
    return 2.0 * cc[:n]
```
