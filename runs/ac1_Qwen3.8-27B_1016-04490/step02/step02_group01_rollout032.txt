**Alternative: Convex optimization via subgradient with cutting planes.**

The function `f(a) = max_k (a*a)[k]` is convex. At each iteration:
1. Evaluate `f(a)` and a subgradient `g = 2 * T_{k*} a` where `k* = argmax`
2. This gives a cutting plane: `f(y) >= f(a) + g^T (y - a)`
3. Minimize the piecewise linear lower bound subject to `a >= 0, sum(a) = S`
4. The minimizer of the LP is the next iterate

The cutting plane method converges but can be slow. However, with a good initial guess (the parent), it might converge quickly.

The LP at each step is:
```
min t
s.t. t >= f(a_i) + g_i^T (x - a_i) for i = 1, ..., m
     x >= 0
     sum(x) = S
```

This is an LP with O(m * n) variables and constraints. For m = 100 cuts and n = 4498, that's ~450,000 constraints. Too large for a general LP solver.

But I can use a simplified version: keep only the most recent K cuts (e.g., K = 20) and solve the resulting small LP. Or even simpler: use the Frank-Wolfe (conditional gradient) method.

**Frank-Wolfe method**:
- At each step, compute the subgradient `g` at the current point `x`
- Find `y = argmin g^T z` subject to `z >= 0, sum(z) = S`
  - This is: `y[i] = S` if `g[i] = min(g)`, else `y[i] = 0`
  - (The minimizer of a linear function over the simplex is a vertex)
- Update: `x_new = (1 - t) * x + t * y` for some `t in [0, 1]`
- The step `t` can be chosen via line search or the FW step size formula

This is very efficient! Each iteration requires:
1. Compute subgradient (FFT, ~1ms)
2. Find min of gradient (O(n))
3. Compute FW step (O(n))
4. Line search (few FFTs)

The FW step size is `t = min(1, 2/(k+2))` (for convex problems) or via line search.
