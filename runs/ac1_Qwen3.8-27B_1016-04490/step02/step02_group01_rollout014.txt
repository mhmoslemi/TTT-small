d/dx0 = 2*x2 ✓ (2*x[2-0] = 2*x2)
d/dx1 = 2*x1 ✓ (2*x[2-1] = 2*x1)
d/dx2 = 2*x0 ✓ (2*x[2-2] = 2*x0)

So the gradient of c[k] w.r.t. x is 2 * x shifted, where the shift is by k. Specifically:
(∇_x c[k])_i = 2 * x[k-i] if 0 <= k-i < n, else 0.

In frequency domain: FFT(∇_x c[k]) = 2 * FFT(x) * FFT(impulse shifted to create the right shift)

Actually, the vector (∇_x c[k])_i = 2*x[k-i]*[0<=k-i<n] is 2 times x reversed and shifted. Let me think of it as:
- x_reversed[i] = x[n-1-i]
- shift by (n-1-k): (shifted)[i] = x_reversed[i + n-1-k] = x[n-1-i-n+1+k] = x[k-i]

So ∇_x c[k] = 2 * shift(x_reversed, n-1-k).

Alternatively, in FFT: if we define y[i] = x[k-i] for i in [0,n-1] (with y[i]=0 if k-i not in [0,n-1]), then ∇_x c[k] = 2*y.

In FFT, y is a "time-reversed and shifted" version of x. The FFT of y relates to the FFT of x by a phase factor.

Actually, the simplest way to compute this in code:
- Compute c = ifft(FFT(x, fs)^2)[:2n-1] (autocorrelation)
- For the active peak at position k*: compute grad = 2 * x aligned at shift k*
  - This means: grad[i] = 2*x[k*-i] if 0<=k*-i<n, else 0
  - Equivalently: grad = 2 * x[k*-1::-1] if k*>=1, padded... this is getting complicated.

Actually, the cleanest way in FFT: 
- The cross-correlation of x with x at lag k* gives x[k*-i] for various i.
- cross_corr[k] = sum_j x[j+k]*x[j] (or similar convention)

Let me just use the FFT approach from the previous code. It computes:
```
P = sfft.rfft(p, cs)
Xc = sfft.rfft(x, cs)
g = 2.0 * np.real(sfft.irfft(P * np.conj(Xc), cs))[:n]
```

This computes 2 * cross_correlation(p, x) (using the conjugate in frequency for correlation vs convolution). If p is the impulse at k*, then cross_correlation(impulse_{k*}, x)[i] = x[k*-i] (with appropriate bounds). So g = 2*x[k*-i] which matches our gradient formula!

Great, so the gradient computation in the previous code is correct. The factor of 2 is correct for self-convolution.

Now, for the softmax approach: instead of the hard max, we use a weighted combination:
p = softmax(c/T) over the top K entries
g = 2 * cross_correlation(p, x)

This gives a smooth approximation to the subgradient of max(c).

1. **Normalization**: The previous code normalizes to sum = sqrt(2n). This is good because the score = 2n*max_b/sum^2 = 2n*max_b/(2n) = max_b when sum = sqrt(2n). So we're just minimizing max_b.

Actually, for the softmax over the top K entries, I can just do:
- Find the top K indices
- Compute softmax over those K values
- Place them in the right positions

    p = 1
    while p < m:

    c = np.real(sfft.irfft(X * X, fs))[:2*n-1]
    np.maximum(c, 0.0, out=c)

def geo_mean_softmax(c, T, K=48):
    # Softmax over top K values
