This is equivalent to: find the smallest M such that there exists a >= 0, sum(a) = 1, and c[k] <= M for all k.

This is a feasibility problem. We could binary search on M and check feasibility. The feasibility check is: does there exist a >= 0, sum(a) = 1, c[k] <= M for all k?

The constraints c[k] = sum_i a[i]*a[k-i] <= M are quadratic (non-convex in general). So this isn't a standard LP.

However, if we fix a (the current iterate), the LP relaxation mentioned in the problem is:
maximize sum(b) subject to conv(a, b)[k] <= M, b >= 0

This IS a linear program (linear in b, with a fixed). The optimal b tells us how to "grow" the sequence while staying within the M envelope.

    c = np.fft.irfft(A * A, fft_sz)
