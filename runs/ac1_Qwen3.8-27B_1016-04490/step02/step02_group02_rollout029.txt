Actually, let me reconsider the problem. The objective is:
`f(a) = 2n * max_k (a*a)[k] / (sum a)^2`

Since this is scale-invariant, fix `sum(a) = 1` and minimize `g(a) = 2n * max_k (a*a)[k]`.

The gradient of `g` at a point where only one `k*` is the max is:
`∇g(a)[i] = 2n * 2 * a_{k*-i}` (if valid)

This is a scaled, shifted, reversed copy of `a`. Moving in the negative gradient direction reduces `a` at positions where the "mirror" (with respect to `k*`) has high values.

For a peak at the center (`k* ≈ n-1`), this means reducing the center of `a`. For peaks at the edges, it means reducing the edges.

The key question is: what's the stationary point? At a stationary point, the gradient (subgradient) of the max should contain 0 in its convex hull, projected onto the tangent space of the simplex.

For a single peak at `k*`: the gradient is `2 * a_{k*-i}`. For this to be "flat" (proportional to 1, the constraint gradient), we'd need `a_{k*-i} = const` for all valid `i`, which means `a` is constant. But a constant `a` gives a triangular convolution, and the max is at the center. So the single-peak stationary point is the uniform distribution, which gives bound ≈ 2.

To do better, we need multiple peaks to be active simultaneously. The subgradient is a convex combination of the peak gradients, and we need 0 to be in the convex hull of these, projected.

For two peaks at `k1` and `k2`: the subgradient is `w * a_{k1-i} + (1-w) * a_{k2-i}`. For this to be flat, we need `a` to look the same shifted by `k1-k2`. This suggests a periodic structure in `a`.

def _np2(m):
    p = 1
    while p < m:

    A = sfft.rfft(a, fs)
    out = sfft.irfft(A * A, fs).real[: 2 * len(a) - 1]
    return np.maximum(out, 0.0)

def _tgrad(cv, a, m, w):

    idx = idx[ord_]
