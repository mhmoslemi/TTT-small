```python
def _subgrad_step(x, T, lr, momentum, beta, fft_size, corr_size, n):
    X = sfft.rfft(x, fft_size)
    conv = np.real(sfft.irfft(X * X, fft_size))[:2 * n - 1]
    conv = np.maximum(conv, 0.0)

    cmax = conv.max()
    logits = np.clip((conv - cmax) / T, -50.0, 0.0)
    p = np.exp(logits)
    ps = p.sum()
    p /= ps

    P = sfft.rfft(p, corr_size)
    Xc = sfft.rfft(x, corr_size)
    corr = np.real(sfft.irfft(P * np.conj(Xc), corr_size))
    g = 2.0 * corr[:n]
    g -= g.mean()
    gmax = np.abs(g).max()
    if gmax > 1e5:
        g *= 1e5 / gmax

    momentum[:] = beta * momentum + (1.0 - beta) * g
    x_new = x - lr * momentum
    x_new = np.clip(x_new, 0.0, 1000.0)
    return x_new, conv
```

The gradient computation:
1. Compute conv = FFT of x * FFT of x (gives full convolution, length 2n-1 after taking first 2n-1)
2. Softmax over conv to get p (length 2n-1)
3. Cross-correlation of p and x: corr = IFFT(FFT(p) * conj(FFT(x)))
