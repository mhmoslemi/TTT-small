(p ⋆ w)_i = sum_k w_k * p_{k-i} = sum_j w_{j+i} * p_j (let j=k-i)
This is the "cross-correlation" sum_j p_j * w_{j+i}.

From my FFT analysis:
- ifft(P*W)[i] = (p*w)[i] = sum_j p_j * w_{i-j} (for appropriate i, no aliasing)
- ifft(conj(P)*W)[i] = sum_j p_j * w_{j+i} (for appropriate i, no aliasing)

So:
- (p*w)[i] = ifft(P*W)[i] → use first n elements
- (p⋆w)[i] = ifft(conj(P)*W)[i] → use first n elements

And we need N >= n + (2n-1) - 1 = 3n-2 for no aliasing.

So the gradient is:
dF/dz = p * [n*(ifft(conj(P)*W)[:n] + ifft(P*W)[:n]) - <p, n*(ifft(conj(P)*W)[:n] + ifft(P*W)[:n])>]

This is O(N log N) = O(n log n).
