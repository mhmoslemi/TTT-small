The problem is: min max_k b[k] subject to x >= 0, sum x = 1 (WLOG by scale invariance).

This is equivalent to: min t subject to b[k] <= t for all k, x >= 0, sum x = 1.

This is a convex program! We can solve it with CVXPY... but the constraints b[k] <= t involve products of x variables (since b[k] = sum x[i]*x[k-i]), making it a QCQP (quadratically constrained QP) or SOCP.

Actually, b[k] = sum_i x[i]*x[k-i] is a quadratic form in x. Specifically, b[k] = x^T T_k x where T_k is a symmetric Toeplitz matrix. The constraint x^T T_k x <= t is a quadratic constraint, which can be written as an SOCP constraint (since T_k should be PSD for x >= 0... actually T_k might not be PSD in general).

For k = 0: b[0] = x[0]^2, which is PSD.
For general k: T_k has entries T_k[i,j] = 1 if i+j=k (with appropriate bounds). This is a Hankel-like matrix.

Actually, let me reconsider. b[k] = sum_i x[i]*x[k-i]. This is NOT a standard quadratic form x^T Q x unless we're careful about the indices.

For k = n-1: b[n-1] = sum_i x[i]*x[n-1-i] = x^T P x where P is the reversal matrix. P is symmetric and orthogonal, with eigenvalues +1 and -1. So it's NOT PSD in general.

So we can't easily use CVXPY. The non-convexity is what makes this a search problem.
