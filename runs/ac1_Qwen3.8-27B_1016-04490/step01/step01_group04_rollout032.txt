- The peak of the convolution is at some position k*. The contribution to c[k*] from position i is a[i] * a[k*-i].
- To reduce c[k*], we should either reduce a[i] or a[k*-i] (or both).
- But we need to maintain sum(a) = 1, so we move mass from {i, k*-i} to positions j where the contribution to ALL lags is small.

The "cold" positions are those j where sum_k w[k] * a[k-j] is small, i.e., where h[j] is small. These are positions that, if they had more mass, would contribute less to the peak.

So the strategy is:
1. Compute h[j] = sum_k w[k] * a[k-j] (the "response" at position j)
2. "Hot" positions: h[j] * a[j] is large (they contribute a lot to the peak)
3. "Cold" positions: h[j] is small (adding mass here adds little to the peak)
4. Move mass from hot to cold positions

    L = 1
    while L < m:
        L <<= 1
    return L

def _norm(a):
    a = np.maximum(a, 0.0)
    s = float(a.sum())
    if s < 1e-300:
        return np.ones(a.size, dtype=np.float64) / a.size
    return a / s

def _conv(a, ffac):
    af = np.fft.rfft(a, n=ffac)
    c = np.fft.irfft(af * af, n=ffac)
    return np.maximum(c[:2 * a.size - 1], 0.0)
