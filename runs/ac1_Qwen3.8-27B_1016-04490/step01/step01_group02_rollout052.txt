The key constraint for non-negative a: the conv(a,a) values must satisfy certain relationships. In particular:
- conv[0] = a[0]^2
- conv[2n-2] = a[n-1]^2
- conv[n-1] = sum_i a[i] a[n-1-i]
- sum_k conv[k] = (sum a)^2

For the score to be < 2, we need max_k conv[k] < (sum a)^2 / n.

For uniform: max = n * (1/n)^2 * n^2 = n * 1/n = 1 (if normalized to sum=1). (sum a)^2/n = 1/n. max = 1/n. So max = (sum a)^2/n, giving score = 2.

To get max < (sum a)^2/n, we need the conv peak to be below the "uniform" level. This requires the sequence to be non-uniform in a specific way.
