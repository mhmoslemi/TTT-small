Now, the optimization:
- We want to minimize `F(a, tau) = sum_k w[k]*b[k]` where `w = softmax(b/tau)`.
- This is a smoothed approximation to `max(b)`.
- We also have the constraint `sum(a) = 1, a >= 0`.

The projected gradient step:
`a_new = (a - lr * (grad - mean(grad)))` projected to `a >= 0, sum(a) = 1`.

Wait, the constraint is `sum(a) = 1`. The gradient of the constraint is `(1, 1, ..., 1)`. To project the gradient onto the tangent space of the constraint, we subtract the mean: `grad_tangent = grad - mean(grad) * ones`.

Then: `a_new = a - lr * grad_tangent`, projected to `a >= 0, sum(a) = 1`.

The projection to `a >= 0, sum(a) = 1` is:
1. `a_new = a_new - min(a_new, 0)` (clip negatives to 0)
2. If `sum(a_new) != 1`, rescale: `a_new = a_new / sum(a_new)`.

But this rescaling can re-introduce issues. A better approach:
1. Compute `a_raw = a - lr * grad_tangent`.
2. Project: find `a_proj >= 0, sum(a_proj) = 1` that minimizes `||a_proj - a_raw||^2`.
   This is done by finding a threshold `t` such that `a_proj[i] = max(0, a_raw[i] - t)` and `sum(a_proj) = 1`.

The threshold `t` can be found by binary search or by sorting.

But for simplicity, the "clip and rescale" approach works well in practice.

import time

def _grad_via_fft(a, w, n):
    L = 1
    while L < 3 * n:
        L <<= 1
    fw = np.fft.rfft(w, L)
    fa = np.fft.rfft(a, L)
    xc = np.fft.irfft(fw * fa.conj(), L)
    grad = np.empty(n, dtype=np.float64)
    grad[0] = 2.0 * xc[0]
    grad[1:] = 2.0 * xc[L-1:L-n:-1]
    return grad

def _project(a, target_sum=1.0):
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
