```python
    # Cross-correlation via FFT:
    # cross_corr[m] = sum_j a[j]*w[j+m] = ifft(fft(w)*conj(fft(a)))[m] (circular)
    # For linear: with zero-padding to N >= 3n-2, the linear cross-corr is in the output.
    # ifft(wf * conj(af))[m] = sum_k w[k]*a[(k-m) mod N] for circular
    # With zero-padding and N large enough, for m in [0, n-1]:
    # = sum_k w[k]*a[k-m] (where a[k-m]=0 if k-m<0 or k-m>=n)
    # = sum_{k=m}^{m+n-1} w[k]*a[k-m] (the valid range)
    # This is PART1[m]! (since w has support [0, 2n-2] and a has support [0, n-1])
    
    cc = np.fft.irfft(wf * np.conj(af), n=N)
    part1 = cc[:n]
    
    return part1 + part2
```

Wait, let me double-check the cross-correlation formula.

For linear cross-correlation: (a ⊛ w)[m] = sum_n a[n+m]*w[n] (one convention)
Or: (w ⋆ a)[m] = sum_n w[n]*a[n+m] (another convention)

What I want: PART1[m] = sum_j a[j]*w[j+m]

Using the FFT: ifft(FFT(w) * conj(FFT(a)))[m] = sum_k w[k] * a[(k-m) mod N]

With zero-padding (N >= (2n-1) + n - 1 = 3n-2), for m in [0, n-1]:
= sum_{k=0}^{2n-2} w[k] * a[(k-m)] (where a[x]=0 for x<0 or x>=n)
= sum_{k=m}^{m+n-1} w[k] * a[k-m] (only terms where a[k-m] is nonzero)
= sum_{j=0}^{n-1} w[j+m] * a[j]
= PART1[m] ✓

And for PART2[m] = sum_j a[j]*w[m-j]:
conv(a,w)[m] = sum_j a[j]*w[m-j] (for valid indices)
= ifft(FFT(a)*FFT(w))[m] (with zero-padding) ✓

Great, so my formula is correct.

Now let me think about the optimization strategy more carefully.

The key insight: the score is scale-invariant. So I can fix sum(a) = 1 and minimize 2n*max(conv(a,a)).

Gradient descent in log-space:
- x = log(a + eps) (to handle zeros)
- Objective: g(x) = 2n * max_k conv(exp(x), exp(x))[k] (with the constraint that a = exp(x) has sum 1... but that's complicated)

Actually, since the score is scale-invariant, I don't need the constraint. I can just minimize max(conv(a,a)) / sum(a)^2 directly, or equivalently fix sum and minimize max(conv).

Let me use the multiplicative update approach:
1. Compute grad[m] = d(max_conv)/da[m] (or smoothed version)
2. a[m] -= eta * grad[m] (projected to a >= 0)
3. Normalize: a = a / sum(a)

Or multiplicative:
1. a[m] *= exp(-eta * grad[m])
2. Normalize

The multiplicative version preserves non-negativity automatically.

For the step size, I'll use a simple adaptive scheme:
- Start with small eta
- If score decreases, increase eta
- If score increases, decrease eta

Let me also add:
- Periodic "restart" from different initializations
- Temperature annealing for the softmax weights
- A final polish phase with smaller steps

import numpy as np
import time

def npow2(m):
    L = 1
    while L < m:
        L <<= 1
    return L

def fft_conv_sq(a, flen):
    n = a.size
    af = np.fft.rfft(a, n=flen)
    return np.fft.irfft(af * af, n=flen)[:2*n-1]

def score_calc(a, flen):
    c = fft_conv_sq(a, flen)
    M = float(np.max(c))
    s = float(np.sum(a))
    if s < 1e-30:
        return np.inf, c, M
    return 2.0 * a.size * M / (s*s), c, M

def grad_smoothed(a, w, N):
    n = a.size
    af = np.fft.rfft(a, n=N)
    wf = np.fft.rfft(w, n=N)
    part2 = np.fft.irfft(af * wf, n=N)[:n]
    part1 = np.fft.irfft(wf * np.conj(af), n=N)[:n]
    return part1 + part2

def norm1(a):
    s = float(np.sum(a))
