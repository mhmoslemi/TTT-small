We can think of it as a "minimax" problem or equivalently, project the convolution onto the uniform distribution (in the L-infinity sense).

A good approach: 
1. Compute c = a*a.
2. Identify "hot spots" where c[m] > average = S^2/(2n-1).
3. For each hot spot, the gradient points in the direction of a[m-i] (reversed and shifted).
4. Move a in the direction opposite to the weighted gradient.
5. Renormalize.

The previous program does this. To improve:
- Use more peaks (32-64).
- Use a smoother weighting (not just top-k, but all peaks above some fraction of max).
- Add momentum.
- Use a better step size.

Let me also consider: since the problem is smooth (the max is piecewise smooth), we could use:
- Projected gradient with step size from Lipschitz constant estimate.
- Or a simpler: reduce step size when the score is decreasing, increase when stuck.

import numpy as np
import time

def _fft_conv(a, N):
    A = np.fft.rfft(a, N)
    return np.fft.irfft(A * A, N)

def _score_fft(a, n, N):
    S = a.sum()
    if S < 0.01:
        return float('inf')
    b = _fft_conv(a, N)
    return 2.0 * n * b.max() / (S * S)

def _grad_from_peaks(a, b, n, peak_frac=0.5, n_top=64):
    S = a.sum()
    mean_a = S / n
    bmax = b.max()
    # Use top peaks above threshold
    thresh = max(bmax * peak_frac, b.mean())
    mask = b >= thresh
    peaks = np.where(mask)[0]
    if len(peaks) == 0:
        return np.zeros(n)
    if len(peaks) > n_top:
        # Keep top n_top
        top_vals = np.partition(b[peaks], -n_top)[-n_top:]
        top_thresh = top_vals[0]
        peaks = peaks[b[peaks] >= top_thresh]
    pv = b[peaks]
    w = pv / pv.sum()
    grad = np.zeros(n)
    for i, ki in enumerate(peaks):
        ki = int(ki)
        lo = max(0, ki - n + 1)
        hi = min(n - 1, ki)
        if lo <= hi:
            seg = a[ki - hi: ki - lo + 1][::-1]
            grad[lo:hi + 1] += w[i] * (seg - mean_a)
    return grad
