Let me also consider: at very high beta, the log-sum-exp gradient becomes very concentrated on the argmax, and L-BFGS-B may struggle. In that case, a subgradient method on the true max might be more effective.

The subgradient of max_k conv_k(a) is conv(a,a) argued in the direction of the active set (where conv_k = max). The subgradient w.r.t. a is:
If S = {k : conv_k = max}, then a subgradient is (1/|S|) * sum_{k in S} 2 * (delta_shifted by k) * a

where "delta_shifted by k" means the vector that is a[k-j] at position j.

This is equivalent to: subgrad[j] = 2 * (1/|S|) * sum_{k in S} a[k-j] (for valid k-j).

This can be computed efficiently if |S| is small (which it typically is at the optimum).

Let me design a hybrid approach:
- Phase 1: L-BFGS-B on log-sum-exp with beta from 4 to 256 (smooth phase)
- Phase 2: L-BFGS-B on log-sum-exp with beta from 512 to 8192 (approaching max)
- Phase 3: Subgradient / active set method on the true max (sharp phase)

For Phase 3, I can implement:
- At each iteration, compute conv(a,a), find the max and the active set S
- Compute the subgradient
- Take a projected gradient step (project onto {a >= 0, sum(a) = 1})
- Adjust step size by backtracking

Actually, for the projected gradient step:
- Start with a (sum to 1, non-negative)
- Compute subgradient g
- New a = a - lr * g
- Project onto {a >= 0, sum(a) = 1}: 
  - Clip: a = max(a, 0)
  - Rescale: a = a / sum(a)

This is simple but may be slow. A better approach is to use the "mirror descent" or "softmax" update:
- z = log(a) (log-space)
- z -= lr * grad_z (where grad_z is the gradient in z-space)
- a = softmax(z)

In z-space, the gradient of f(a) = max_k conv_k(a) is:
grad_z[j] = a[j] * (grad_a[j] - sum(a * grad_a))

where grad_a is the subgradient in a-space.
