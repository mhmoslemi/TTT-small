def fft_convolve(a):
    n = a.size
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    b = np.fft.irfft(fa * fa, size)
    return b[:2 * n - 1]

def fast_score(a):
    s = a.sum()

where g has n elements (g[0], ..., g[n-1]) and k ranges from 0 to 2n-2.

The (k, i) entry of the constraint matrix is f[k-i] if 0 <= k-i <= n-1, else 0.

So row k has non-zeros at columns i where k-n+1 <= i <= k (intersected with [0, n-1]).

Row 0: column 0 (f[0])
Row 1: columns 0, 1 (f[1], f[0])
...
Row n-1: columns 0, ..., n-1 (f[n-1], ..., f[0])
Row n: columns 1, ..., n-1 (f[n-1], ..., f[1])
...
Row 2n-2: column n-1 (f[n-1])

Total non-zeros: sum of min(k+1, 2n-1-k, n) for k=0 to 2n-2.
For k=0 to n-1: k+1 non-zeros → sum = n(n+1)/2
For k=n to 2n-2: 2n-1-k non-zeros → sum = n(n-1)/2
