```python
def autocorr(a):
    n = len(a)
    f_len = 1
    while f_len < 2*n-1:
        f_len *= 2
    fa = np.fft.rfft(a, f_len)
    ca = np.fft.irfft(fa * fa, f_len)[:]
    return ca[:2*n-1]  # linear convolution
```

Wait, `np.convolve(a, a)` gives the full linear convolution of length $2n-1$. The FFT approach: zero-pad both to length $f_len \geq 2n-1$, FFT, multiply, IFFT, take first $2n-1$ values.

```python
def linear_conv(a, b):
    n = len(a) + len(b) - 1
    f_len = 1
    while f_len < n:
        f_len *= 2
    fa = np.fft.rfft(a, f_len)
    fb = np.fft.rfft(b, f_len)
    return np.fft.irfft(fa * fb, f_len)[:n]
```

For $a = b$, this is the autocorrelation.

For $n = 6121$, $f_len = 16384$. The rfft of length 16384 gives 8193 complex numbers. Multiplication is O(8193). IFFT is O(16384 log 16384) ≈ O(225K). This is very fast (~1-2ms).

For the subgradient:
```python
def subgrad(a, t):
    n = len(a)
    m = np.arange(n)
    idx = t - m
    mask = (idx >= 0) & (idx < n)
    g = np.zeros(n)
    g[mask] = 2 * a[idx[mask]]
    return g
```

This is O(n) and vectorized.
