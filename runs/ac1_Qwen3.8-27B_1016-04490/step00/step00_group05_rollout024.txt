Actually, A^T @ y where y is of length 2n-1:

This can be computed with a sliding window sum! W[j+1] = W[j] - y[j] (if j >= 0) + y[j+n] (if j+n <= 2n-2).

So the full iteration is:
1. A@g = convolve(a, g) [FFT, O(n log n)]
2. v = max(0, A@g - M) [O(n)]
3. (A^T@v)[j] = a[j] * sliding_window_sum(v, j) [O(n)]
4. grad = ones(n) - 2*(A^T@v) [O(n)]
5. g += alpha * grad; g = max(g, 0) [O(n)]

All steps are O(n log n)! This is very efficient.
