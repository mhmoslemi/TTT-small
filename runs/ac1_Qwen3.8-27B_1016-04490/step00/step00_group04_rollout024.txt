Let me think about what the optimal shape looks like. For a symmetric sequence with sum = 1:
- b_{n-1} = sum a_i^2
- b_0 = a_0^2
- b_k for k < n-1 involves fewer terms

If the sequence is "flat" (all a_i ≈ 1/n), then b_{n-1} ≈ n*(1/n)^2 = 1/n, and b_k ≈ (n-|k-(n-1)|)*(1/n)^2 for k near center.

The peak is b_{n-1} = 1/n, giving score = 2n*(1/n)/1 = 2.

To reduce the peak, we want to reduce b_{n-1} = sum a_i^2 while keeping sum a = 1. But by Cauchy-Schwarz, sum a_i^2 >= 1/n, so we CAN'T reduce it below 1/n!

Wait, that means for SYMMETRIC sequences, the minimum is exactly 2 (achieved by uniform)!

So the optimum must be ASYMMETRIC! The symmetry constraint forces sum a_i^2 >= 1/n, and b_{n-1} = sum a_i^2 for symmetric sequences.

For asymmetric sequences, b_{n-1} = sum a_i * a_{n-1-i}, which is NOT sum a_i^2. And this CAN be less than 1/n!

For example, a = [0, 0, ..., 0, 1, 0, ..., 0] (one element = 1 at position p, rest 0):
b_{n-1} = a_p * a_{n-1-p}. This is 1 if p = n-1-p (middle), 0 otherwise.
If p ≠ (n-1)/2, then b_{n-1} = 0!
But b_p = a_p^2 = 1 (if p is the position of the 1).
So max_b = 1, sum = 1, score = 2n. Terrible.

The issue is that concentrating mass creates a spike at that position.

The optimal tradeoff: spread the mass enough to avoid spikes, but arrange it so that b_{n-1} (the cross term) is small.
