3. Gradient of max_c w.r.t. a: for each active k, grad += 2 * a[k-i] (shifted). Average over active set.
4. Step: a = a - lr * grad
5. Project: a = max(0, a), then rescale to sum S
6. Repeat

The gradient of c[k] w.r.t. a[i] is 2*a[k-i] (as derived earlier). So for the active set, the aggregate gradient is:
grad[i] = 2 * (1/|A|) * sum_{k in A} a[k-i] (for valid k-i)

This is 2/|A| times the sum of a shifted by each active k. This can be computed in O(n*|A|) or with FFT in O(n log n).

For n=2535, even O(n*|A|) is fine if |A| is small (say < 100).
