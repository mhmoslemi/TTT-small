    n = len(x) + len(y) - 1
    L = 1
    while L < n:
        L <<= 1
    X = np.fft.rfft(x, L)
    Y = np.fft.rfft(y, L)
    return np.fft.irfft(X * Y, L, )[:n]

def compute_gradient(a, b, beta):
    """Compute gradient of sum exp(beta*b) w.r.t. a."""
    n = len(a)
    exp_b = np.exp(beta * (b - b.max()))
    # grad[j] = sum_m exp_b[m+j] * a[m] for m=0,...,n-1
    # = full_conv(a[::-1], exp_b)[n-1 : 2n-1]
    full_c = fft_convolve(a[::-1], exp_b)
    return full_c[n-1:2*n-1]

Actually, let me reconsider the whole approach. The problem is:
minimize max_k b_k subject to a >= 0, sum a = 1

where b = a * a (convolution).

An alternative: binary search on the target M. For a given M, check if there exists a >= 0, sum a = 1 with b_k <= M for all k.

This feasibility problem: a >= 0, sum a = 1, and (a*a)_k <= M for all k = 0,...,2n-2.

The constraints (a*a)_k <= M are quadratic. This is a feasibility problem with quadratic constraints. We can solve it with:
- Sequential Quadratic Programming (SQP)
- Penalty methods
- Interior point methods for QCs

But with n=4498 and 2n-1=8995 quadratic constraints, this is a large-scale problem.

Alternatively, we can use an交替 algorithm:
1. Start with current a
2. Compute b = a*a, find active constraints (where b_k is close to M)
3. For the active set A, solve a linearized subproblem: minimize max_{k in A} b_k subject to a >= 0, sum a = 1
4. Update M

The linearized subproblem at the current point:
minimize max_{k in A} [b_k + sum_j 2*a_{k-j} * (a_j - a_j^0)]
subject to a >= 0, sum a = 1

where a^0 is the current iterate. This is a linear program (minimize max of linear functions, with linear constraints).

But implementing this efficiently is complex. Let me stick with the gradient approach.

import numpy as np
import time

def fft_convolve(x, y):
    n = len(x) + len(y) - 1
    L = 1 << (n - 1).bit_length()
    X = np.fft.rfft(x, L)
    Y = np.fft.rfft(y, L)
    return np.fft.irfft(X * Y, L)[:n]
