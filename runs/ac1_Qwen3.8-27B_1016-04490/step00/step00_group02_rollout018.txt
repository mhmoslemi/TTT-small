The issue is that the landscape near the uniform point is very flat (the score is 2 + O(ε^2) for perturbations of size ε), so random perturbations are unlikely to find improvements in the limited number of evaluations.

I need a more directed search. Let me go back to the multiplicative weight approach but fix the fixed-point issue.

**Fixing the fixed point:**

The problem is that for the center peak, the gradient 2*a[n-1-i] is approximately constant (≈ 2/n) when a is uniform. So the multiplicative update `a *= exp(-eta * 2*a[n-1-i])` becomes `a *= exp(-2*eta/n)` (uniform scaling), which does nothing after renormalization.

Solution: Use the **deviation from the mean** in the update:
`a[i] *= exp(-eta * (grad[i] - grad_mean))`

For the center peak: grad[i] = 2*a[n-1-i], grad_mean ≈ 2/n.
Update: `a[i] *= exp(-eta * 2*(a[n-1-i] - 1/n))`

This zero-mean update will amplify deviations from uniform. If a[n-1-i] > 1/n, a[i] decreases; if a[n-1-i] < 1/n, a[i] increases. This pushes the sequence to become more asymmetric.

But wait, will this actually reduce the peak? Let's check:
- Center conv: sum a[i]*a[n-1-i]. After the update, a[i] and a[n-1-i] both get adjusted. If a[n-1-i] was above average, a[i] decreases (reducing the product). If a[n-1-i] was below average, a[i] increases (also reducing the product, since a[n-1-i] is small). So yes, the center conv decreases!

Great, this should work. Let me also handle multiple peaks:

For multiple peaks k1, k2, ..., the update is:
`a[i] *= exp(-eta * sum_k w_k * (a[k-i] - a[k-i]_mean))`

where the "mean" is the average of a[k-i] over all valid i for peak k.

Actually, let me simplify. For each peak k, the contribution to the gradient at position i is 2*a[k-i] (for i in V(k)). The average over i in V(k) is 2*mean_{i∈V(k)} a[k-i] ≈ 2*mean(a) (approximately, for the center peak where V(k) = all indices).

So the centered gradient for peak k: 2*(a[k-i] - mean(a)).

For multiple peaks, sum them up (weighted by their relative magnitude).
