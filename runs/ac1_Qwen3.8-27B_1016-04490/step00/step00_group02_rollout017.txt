OK so it really does seem like 2 is the minimum. Let me think about why.

Actually, I think I can prove it. For f >= 0, sum f = S:

sum_k (f*f)[k] = (sum f)^2 = S^2.

There are 2n-1 values of (f*f)[k]. So the average is S^2/(2n-1).

If max >= S^2/(2n-1), then score = 2n * max / S^2 >= 2n/(2n-1).

For large n, 2n/(2n-1) ≈ 1. So in principle, if we could make (f*f) perfectly flat, we'd get score ≈ 1.

But the issue is: can we make (f*f) flat for f >= 0?

(f*f)[0] = f[0]^2. For this to equal S^2/(2n-1), we need f[0] = S/sqrt(2n-1).
(f*f)[2n-2] = f[n-1]^2. Similarly f[n-1] = S/sqrt(2n-1).

And (f*f)[n-1] = sum_j f[j] f[n-1-j] = S^2/(2n-1).

The sum of all (f*f)[k] = S^2. If all are equal to S^2/(2n-1), the sum checks out.

The question is whether there exists f >= 0, sum f = S, such that (f*f)[k] = S^2/(2n-1) for all k.

This means F(x)^2 = c * (1 + x + x^2 + ... + x^{2n-2}) where c = S^2/(2n-1) and F(x) = sum f_j x^j.

So F(x) = S / sqrt(2n-1) * sqrt(1 + x + ... + x^{2n-2}).

But sqrt(1 + x + ... + x^{2n-2}) doesn't have a polynomial square root with nonnegative coefficients in general!

For n=2: 1+x+x^2. sqrt = ? Not a polynomial.
For n=1: 1. sqrt = 1. F(x) = 1. f = [1]. Works.

So for n > 1, we can't achieve a perfectly flat convolution. The question is how close we can get.

This is related to the "nonnegative polynomial square root" problem. The minimum possible max(f*f) / S^2 is some value between 1/(2n-1) (theoretical flat) and 1/n (uniform).
