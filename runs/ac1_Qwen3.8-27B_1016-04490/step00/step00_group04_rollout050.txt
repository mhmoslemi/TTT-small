Actually, let me try a different strategy that might be more effective:

**Dual approach / "temperature" method:**

Define F(f, T) = log(sum_k exp(c[k]/T)) (log-sum-exp of the autocorrelation).
As T → 0, this approaches log(max_k c[k]).
Minimizing F(f, T) over f (with sum(f)=1, f>=0) is a smooth convex problem.

The gradient of F with respect to f[i] is:
∂F/∂f[i] = (1/T) * sum_k exp(c[k]/T) * (dc[k]/df[i]) / sum_k exp(c[k]/T)
= sum_k w[k] * f[k-i] / T (valid indices)
where w[k] = exp(c[k]/T) / sum_k exp(c[k]/T) (softmax weights)

This is a smooth gradient (the "soft" subgradient I mentioned earlier). We can use gradient descent on this.

The nice thing: as T decreases, we converge to the true max. But for small T, the gradient is concentrated at the peak lag, and updates are slow.

Practical approach:
1. Start with T large (smooth objective).
2. Decrease T geometrically.
3. At each T, do a few gradient descent steps.
