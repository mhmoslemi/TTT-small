For the example [1,2,1,1,2], the sequence has a "bump" at positions 1 and 4. The products that would have been at the center are now split, reducing the maximum.

This is very much like the "minor interval" construction in harmonic analysis / finite geometry.

Now, for large n=4498, we need an efficient algorithm to find such sequences. Let me design the optimization:

1. Start from the parent (likely near-constant, giving score ≈ 2)
2. Use iterative optimization to reshape a to flatten C

The gradient-based approach should work:
- Compute C = conv(a,a)
- Find the peak(s)
- Compute the direction that reduces the peak: for peak at k*, the gradient is the "shifted" a
- Take a multiplicative step in that direction

import time

def compute_conv(a):
    """Compute linear convolution via FFT."""
    n = len(a)
    N = 1
    while N < 2*n - 1:
        N *= 2
    A = np.fft.rfft(a, N)
    C = np.fft.irfft(A * A, N)
    C = C[:2*n-1]

    return C

    best_score = float(evaluate_sequence(best.tolist()))

    patience = 0
    for it in range(1000000):
        if time.monotonic() > deadline:
            break
        
        C = compute_conv(a)
        max_C = C.max()
        score = 2.0 * n * max_C  # since sum(a)=1

            best_score = score
            best = a.copy()
            patience = 0

        k_star = C.argmax()
        # grad[i] = 2 * a[k_star - i] for valid i (0 <= k_star-i < n)

        grad[lo:hi] = 2.0 * a[k_star - hi + 1 : k_star - lo + 1]

        step = lr * grad / (n * max_C)  # normalize step
        a *= np.exp(-step)
        a = np.maximum(a, 0)
        s = a.sum()
        if s < 1e-15:
            a = np.ones(n) / n
            continue
        a /= s
        
        # Periodic perturbation to escape local minima
        if patience > 200:

            lr = min(1.0, lr * 1.5)

            a *= np.exp(rng.normal(0, 0.01, n))
            a = np.maximum(a, 0)
            s = a.sum()
            if s > 1e-15:
                a /= s
            patience = 0
        
        if patience > 2000:
            break
    
    # Final check with evaluate_sequence
    final_score = float(evaluate_sequence(best.tolist()))
    if not np.isfinite(final_score):
        return [1.0]
    
    return [float(x) for x in best]
