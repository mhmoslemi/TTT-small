1. Approach and rationale
We design a robust local search algorithm with multiple perturbation strategies to minimize the AC1 upper bound. The core idea is to generate diverse candidates by combining multiple low-rank update operations (Jacobian, gradient, and random blocks) and use the exact evaluator to select high-performing ones. This approach is justified because:
- The exact evaluator is the ground truth, and we must rely on it for scoring.
- The state-of-the-art baseline achieved an upper bound of 2.0, while we aim for 1.5.
- Local searches with perturbations in the early adoption phase have shown promise for complex optimization problems.

The approach limits evaluations to prevent excessive time consumption in convolution operations (O(n^2)) and ensures the program meets the time budget by adapting the number of perturbations based on remaining time.

2. Mathematical specification
The objective is to minimize the AC1 upper bound score:

score = (2 * n * max_c) / (sum_a ** 2)

where:
- n = sequence length
- a = input sequence
- c = full convolution of a with itself
- sum_a = sum of a

The algorithm maintains:
- Best candidate sequence and its score
- Remaining time budget
- Three perturbation types:
  1. Low-rank Jacobian updates
  2. Gradient updates
  3. Random block updates

Each iteration picks a perturbation type probabilistically based on remaining time, updates the sequence while enforcing bounds [0,1000], and evaluates the candidate. The descent estimation uses finite differences to approximate directional improvement.

3. Implementation procedure
- Initialization:
  • Copy parent sequence and evaluate initial score
  • Set best_score and best_sequence
  • Create a perturbation pool with probabilities inversely proportional to time remaining

- Iterations:
  • Sample perturbation type (weighted by time)
  • Apply perturbation:
    * Jacobian: Add a low-rank outer product (rank=5)
    * Gradient: Apply a small step nd-direction (direction chosen randomly)
    * Random block: Multiply block by random scalar
  • Clip sequence to [0,1000] and enforce normalization
  • Evaluate candidate using exact evaluator
  • Update best candidate if improvement is substantial (relative)

- Convergence:
  • Stop when remaining time is minimal (<5% of budget)
  • Return best_sequence

4. Search choices and useful variations
- Default configuration:
  - Perturbation probabilities:
    • Jacobian updates: 35% (conservative potential)
    • Gradient updates: 45% (fast exploration vs stability conflict)
    • Random block: 20% (exploration focus)
  - Step size for gradient updates: adaptive (controlled by √(time remaining))

- Defensiveness:
