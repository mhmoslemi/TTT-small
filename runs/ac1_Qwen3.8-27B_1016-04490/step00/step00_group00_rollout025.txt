```python
# Fix the midpoint if k* is even and k*/2 is in [lo, hi]
mid = k_star // 2
if k_star % 2 == 0 and lo <= mid <= hi:
    grad[mid] = 2 * a[mid]
```

Now the score is S = 2n * c[k*] / (sum a)^2.
∂S/∂a[i] = 2n * ∂c[k*]/∂a[i] / (sum a)^2 - 2*2n*c[k*]*a[i]/(sum a)^4
= 2n/(sum a)^4 * ((sum a)^2 * grad[i] - 2*c[k*]*a[i])

For gradient descent: a_new = a - lr * ∂S/∂a, clipped to [0, 1000].

But the issue is that k* can change as we iterate, making the gradient non-smooth. A simple approach:
- At each step, compute c, find k*, compute gradient, take a small step.
- The step should be small enough that k* doesn't change much.

Alternatively, use a "smoothing" approach: instead of just the max, use a soft maximum (log-sum-exp) over all k. But that changes the objective.

Let me just go with the simple approach: gradient on the current max, small steps, clip.

For the initial shape, let me think about what works:
- The parent is constant (score 2).
- We want to break the symmetry to reduce the max.
- A linear ramp or a "one-sided boost" might work.

From my n=4 analysis, the best was around [2.7, 1, 1, 1] shape (high at one edge, low elsewhere), giving score ~1.82.

For n=4806, I'd try:
- a[j] = 1 + alpha * j/(n-1) (linear ramp, high at right)
- a[j] = 1 + alpha * (j/(n-1))^2 (quadratic ramp)
- a[j] = 1 - alpha * sin(pi*j/(n-1)) (dip in the middle)
- a[j] = 1 + alpha * cos(2*pi*j/(n-1)) (one full cosine cycle)

Let me also think about the "wrapper" approach from the strategy:
- Start with a shape, then iteratively flatten the convolution.

Algorithm:
1. Try several initial shapes, pick the best.
2. Gradient descent to refine.
3. Return the best found.

Let me also consider: the score is 2n * max(c) / (sum a)^2. If I normalize sum a = 1, I minimize 2n * max(c). The constraint is a >= 0.

For a unit-sum sequence, the "average" value of c[k] is sum(c)/ (2n-1) = 1/(2n-1). So the minimum possible max is at least 1/(2n-1), giving a score of at least 2n/(2n-1) ≈ 1. But we can't achieve this (non-negative constraint).

The real question is: what's the best achievable score for n=4806?

I think the answer is somewhere between 1 and 2, and we need a good shape to get there.

```python
        """Compute (score, max_loc) using full convolution."""
        c = np.convolve(a, a)
        max_loc = int(np.argmax(c))
        max_b = c[max_loc]
        s = a.sum()
        if s < 0.01:
            return np.inf, 0
        return float(2.0 * n * max_b / (s * s)), max_loc
    
    # Generate parametric shapes and optimize over alpha
    t = np.arange(n, dtype=np.float64)
    t_norm = t / max(1, n - 1)
    
    shapes = {}
    shapes['linear'] = 1.0 + 0.0 * t_norm  # placeholder, will add alpha*t_norm
    shapes['quad'] = 1.0 + 0.0 * t_norm
    shapes['dip_sin'] = 1.0 - 0.0 * np.sin(np.pi * t_norm)
    shapes['cos'] = 1.0 + 0.0 * np.cos(2.0 * np.pi * t_norm)
    shapes['exp_ramp'] = 1.0 + 0.0 * t_norm
    shapes['asym_quad'] = 1.0 + 0.0 * (2.0 * t_norm - 1.0) ** 2
    
    # For each shape, sweep alpha
    base_shapes = [
        ('ramp_linear', lambda al: np.clip(1.0 + al * t_norm, 0, 1000)),
        ('ramp_quad', lambda al: np.clip(1.0 + al * t_norm**2, 0, 1000)),
        ('dip_sin', lambda al: np.clip(1.0 - al * np.sin(np.pi * t_norm), 0, 1000)),
        ('cos_full', lambda al: np.clip(1.0 + al * np.cos(2.0*np.pi*t_norm), 0, 1000)),
        ('both_ramp', lambda al: np.clip(1.0 + al*(t_norm - 0.5), 0, 1000)),
        ('edge_high', lambda al: np.clip(1.0 + al*(1-t_norm)**2, 0, 1000)),
        ('mid_dip', lambda al: np.clip(1.0 - al*(t_norm*(1-t_norm)), 0, 1000)),
    ]
    
    for name, gen in base_shapes:
        if time.monotonic() > deadline - 60:
            break
        # Sweep alpha from -1.5 to 5
        alphas = np.concatenate([
            np.linspace(-1.5, 0, 20, endpoint=False),
            np.linspace(0.01, 5, 50)
        ])
        for al in alphas:
            if time.monotonic() > deadline - 60:
                break
            a = gen(al)
            if a.max() <= 0:
                continue
            sc, loc = conv_max_score(a)
            if sc < best_score:
                best_score = sc
                best = a.copy()
    
    # Gradient refinement
    if time.monotonic() < deadline - 30:
        a = best.copy()
        lr = 0.001
        for it in range(100000):
            if time.monotonic() > deadline - 10:
                break
            c = np.convolve(a, a)
            k_star = int(np.argmax(c))
            max_b = c[k_star]
            s = a.sum()
            if s < 0.01:
                break
            sc = 2.0 * n * max_b / (s * s)
            
            # Gradient of score w.r.t. a
            lo = max(0, k_star - (n - 1))
            hi = min(n - 1, k_star)
            grad = np.zeros(n)
            idx = np.arange(lo, hi + 1)
            paired = k_star - idx
            grad[idx] = a[paired] + a[idx]
            mid = k_star // 2
            if k_star % 2 == 0 and lo <= mid <= hi:
                grad[mid] = 2.0 * a[mid]

            ds = (2.0 * n / (s**4)) * (s**2 * grad - 2.0 * max_b * a)
            
            # Gradient step with clipping
            a_new = a - lr * ds
            a_new = np.clip(a_new, 0.0, 1000.0)
            
            # Check improvement

            sc_new = 2.0 * n * np.max(c_new) / (a_new.sum()**2)
            if sc_new < sc:
                a = a_new
                # Reduce lr slightly
            else:
                lr *= 0.5
                if lr < 1e-10:
                    break
            
            if sc_new < best_score:
                best_score = sc_new
                best = a_new.copy()
    
    return [float(x) for x in best]
```
