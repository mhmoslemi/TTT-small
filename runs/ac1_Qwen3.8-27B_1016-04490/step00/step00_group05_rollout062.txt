c[k] = sum_{j} x[j] * x[k-j] (valid range)
∂c[k]/∂x[m] = 2 * x[k-m] if 0 <= k-m <= n-1, else 0 (as I derived above)

So subgradient of max_k c[k] w.r.t. x[m] = sum_{k: c[k]=M} 2*x[k-m] (for valid k-m)
= 2 * sum_k active[k] * x[k-m] (for valid k-m)

Let me substitute j = k-m: = 2 * sum_j active[j+m] * x[j] (for valid j+m in [0, 2n-2])

This is 2 * (active ⋆ x)[m] where (a ⋆ b)[m] = sum_j a[j+m] * b[j].

FFT: (a ⋆ b) = ifft(conj(FFT_a) * FFT_b) (for zero-padded sequences with N >= len(a)+len(b)-1)

For our case: a = active (length 2n-1), b = x (length n). Need N >= 2n-1+n-1 = 3n-2.

So nfft2 should be >= 3n-2, use next power of 2.

Now let me also think about whether to normalize or not during optimization. Since the objective is scale-invariant:
f(cx) = 2*n*max(c*cx*cx) / (sum cx)^2 = 2*n*c^2*max(x*x) / (c^2*sum(x))^2 = f(x)

So we can fix sum(x) = 1 (or any constant) and just minimize max(x*x).

    p = 1
    while p < m:
        p *= 2
    return p

def _convolve_self(x, nfft):
    X = np.fft.rfft(x, nfft)
    return np.fft.irfft(X * X, nfft)

def _grad_sub(x, active, nfft):

    FA = np.fft.rfft(active, nfft)
    FX = np.fft.rfft(x, nfft)
    corr = np.fft.irfft(np.conj(FA) * FX, nfft)
    return 2.0 * corr[:len(x)]
