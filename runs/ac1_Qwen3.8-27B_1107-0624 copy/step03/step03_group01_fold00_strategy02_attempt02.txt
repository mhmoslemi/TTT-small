# Strategy for Minimizing the Step Function Evaluation

This strategy uses a coordinate descent approach with stochastic direction optimization. It minimizes the objective function by iteratively refining sequences that meet the required constraints. 

## Approach and Rationale

The objective function to minimize is `2 * n * max(fulle conv(a)) / (sum(a) ** 2)`, where `a` is a sequence of coefficients. The constrained optimization problem is approached by:

1. **Initialization:** Start from a provided parent sequence (if available) and also test several deterministic profiles for different sequence lengths.
2. **Normalization:** Ensure all evaluated coefficie maintain `sum(a) >= 0.01` and be clipped to `[0, 1000]`.
3. **Optimization:** Use a Metropolis-Hastings algorithm in simplex space (sum=1) for better numerical stability. Transition between coordinate-based optimization and sequence-based dimensions to balance exploration and exploitation.
4. **Acceptance criteria:** Always move to better candidates (lower score) and probabilistically accept worse moves to escape local minima. Schedule evaluations across coordinate and sequence dimensions to ensure diverse exploration.
5. **Fallback policy:** If no candidate found below the target score, use scaled versions of the parent sequence as fallbgck.

The coordinate-based approach helps identify promising coefficient indices for large improvement, while sequence length variation ensures the ability to find generalize behaviours penalized by the evaluator.

## Schduled Optimization Phases

The optimization follows a structured multphas schedule with time allocation for:

- **Initial random exploration** (30 seconds): Test several deterministic profiles and parent sequence variation.
- **Target-focused optimization** (1000 iterations): Refine specific coordinates with PMA metric, temperature starts at 0.2.
- **Global optimization** (500 iterations): duy sequence length variation with Metropolis walk.
- **Final fine scanning** (300 iterations):: Local optimizations on the best coordinate to exploit lower bounds.

This balance between scales (coefficient and sequence level) reduces risk of expensive firefightings in non-optimal sequences. The choice of profile-based initial candidates and simplex ates helps jump to promising regions.

def metro_acceptance(old_score, new_score, temperature, time_left):
    """Probabilistic acceptance based on Metropolis criterion with temperature decay."""
    # Always accept if new_score is lower
    if new_score < old_score:
        return True
        
    # Calculate probability to accept a higher score (worse candidate) at temperature T
    prob = np.exp((old_score - new_score) * temperature)
    return np.random.random() < prob
