For each coordinate i, the optimal value of a[i] (given all other coordinates fixed) satisfies:

- If a[i] = 0: derivative >= 0

`2 * sum_k w[k] * a[k-i]` (with appropriate bounds) = `2 * grad[i]` (from our formula above)

But we also have the constraint sum(a) = 1, so the effective derivative is:
`2 * grad[i] - lambda` where lambda is the Lagrange multiplier.

At the optimum (KKT): `2 * grad[i] = lambda` for all i with a[i] > 0.

This means: at the optimum, the gradient is constant on the support of a! This is a very useful characterization.

So a coordinate descent step would be:
1. Compute grad = compute_conv_gradient(w, a)
2. Find lambda = mean(grad[i] for i in support(a))
3. For each i: if 2*grad[i] > lambda, set a[i] = 0 (or very small)

"""
Multi-scale Nesterov optimization with adaptive softmax for minimizing
2n*max(conv(a,a))/sum(a)^2. Uses FFT-based gradient computation, 
Nesterov momentum, harmonic initializations, and progressive refinement.
"""
import numpy as np
import time


def compute_score(a):
    a = np.asarray(a, dtype=np.float64).ravel()
    n = a.size
    if n == 0:
        return np.inf
    s = float(a.sum())
    if s < 0.01:
        return np.inf
    c = np.convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))


def next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def fft_convolve(a):
    n = a.size
    if n <= 64:
        return np.convolve(a, a)
    N = next_pow2(2 * n - 1)
    fa = np.fft.rfft(a, N)
    c = np.fft.irfft(fa * fa, N)[:2 * n - 1]
    c = np.maximum(c, 0.0)
    return c


def fft_conv_grad(w, a):
    """Gradient of sum_k w[k]*conv(a,a)[k] w.r.t. a."""
    n = len(a)
    N = next_pow2(3 * n)
    wa = np.fft.rfft(w, N)
    aa = np.fft.rfft(a, N)
    R = np.fft.irfft(np.conj(aa) * wa, N)
    grad = np.zeros(n)
    grad[0] = 2.0 * R[0]
    if n > 1:
        grad[1:] = R[1:n] + R[N-1:N-n:-1]
    return grad


def softmax_weights(c, beta):
    mval = float(c.max())
    if beta < 1e-14:
        w = np.zeros_like(c)
        mask = c >= mval - 1e-12
        cnt = int(np.count_nonzero(mask))
        if cnt == 0:
            w[int(np.argmax(c))] = 1.0
        else:
            w[mask] = 1.0 / cnt
        return w
    x = (c - mval) / beta
    x = np.clip(x, -70.0, 0.0)
    ex = np.exp(x)
    s = float(np.sum(ex))
    if s < 1e-300:
        ex = np.zeros_like(c)
        ex[int(np.argmax(c))] = 1.0
        s = 1.0
    return ex / s


def interpolate_profile(p0, n_new):
    p0 = np.asarray(p0, dtype=np.float64).ravel()
    n0 = p0.size
    if n0 == n_new:
        s = p0.sum()
        return p0 / s if s > 1e-10 else p0.copy()
    x0 = np.linspace(0.0, 1.0, n0)
    x1 = np.linspace(0.0, 1.0, n_new)
    result = np.interp(x1, x0, p0)
    s = result.sum()
    return result / s if s > 1e-10 else result


def make_ramp(n, slope=1.0, offset=0.1):
    t = np.linspace(0.0, 1.0, n)
    a = np.maximum(1.0 + slope * (0.5 - t) + offset * np.sin(np.pi * t), 1e-12)
    return a / a.sum()


def make_harmonic(n, modes=5, rng=None):
    if rng is None:
        rng = np.random.default_rng(0)
    t = np.linspace(0.0, 1.0, n)
    a = np.ones(n)
    for k in range(1, modes + 1):
        amp = rng.uniform(0.05, 0.3) / k
        phase = rng.uniform(0, 2 * np.pi)
        a = a + amp * np.cos(2 * np.pi * k * t + phase)
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def nesterov_optimize(a0, deadline, rng, lr=0.05, beta_init=0.1,
                       beta_decay=0.998, mu=0.9, restart_after=800):
    """
    Nesterov-accelerated logit-space optimization.
    Minimizes sum_k w_k * conv(a,a)[k] where w = softmax(beta * conv(a,a)).
    """
    a = np.asarray(a0, dtype=np.float64).ravel()
    n = a.size
    a = np.maximum(a, 1e-15)
    a = a / a.sum()

def nesterov_optimize_v2(a0, deadline, rng, lr=0.04, beta_init=0.12,

- corr(a,w) = IFFT(conj(FFT(a)) * FFT(w)) = irfft(conj(rfft(a)) * rfft(w))

For the correlation: corr(a,w)[j] = sum_m a[m] * w[m+j mod N] (circular)
For the convolution: conv(a,w)[j] = sum_m a[m] * w[m-j mod N] (circular)

So:
C1[j] = corr(a,w)[j] for j = 0..n-1 (no wraparound since m+j <= n-1+n-1 = 2n-2 < N)
C2[j] = conv(a,w)[j] for j = 0..n-1... 

Wait, conv(a,w)[j] = sum_m a[m] * w[(m-j) mod N]
For m-j >= 0: w[m-j]
For m-j < 0: w[m-j+N]

C2[j] = sum_{m=0}^{n-1} a[m] * w[j-m] (valid when 0 <= j-m <= 2n-2)

conv(a,w)[j] = sum_m a[m] * w[(m-j) mod N]
For m >= j: w[m-j] (valid if m-j <= 2n-2, which is true since m <= n-1, j >= 0)
For m < j: w[m-j+N] (this is 0 if m-j+N > 2n-2, i.e., if N > 2n-2+j-m)

Since N >= 3n and m-j >= -(n-1), we have m-j+N >= N-(n-1) >= 2n+1 > 2n-2. So w[m-j+N] = 0.

Thus conv(a,w)[j] = sum_{m=j}^{n-1} a[m] * w[m-j]

Let m' = m-j: = sum_{m'=0}^{n-1-j} a[m'+j] * w[m']

But C2[j] = sum_{m=0}^{j} a[m] * w[j-m] = sum_{m'=0}^{j} a[j-m'] * w[m'] (letting m'=j-m)

These are different! conv(a,w)[j] has a[m'+j] while C2[j] has a[j-m'].

So C2 is NOT simply the linear convolution of a and w.

Let me try: conv(a, w_flipped)[j] where w_flipped[k] = w[2n-2-k].

conv(a, w_flipped)[j] = sum_m a[m] * w_flipped[j-m] = sum_m a[m] * w[2n-2-(j-m)] = sum_m a[m] * w[2n-2-j+m]

For this to equal C2[j] = sum_m a[m] * w[j-m]:
We need 2n-2-j+m = j-m, i.e., 2n-2 = 2j-2m, which is not generally true.

Let me try another approach. C2[j] = sum_m a[m] * w[j-m].

Define w_rev[k] = w[-k mod (2n-1)]? No, that's circular.

Actually, let me just compute C2 differently.

C2[j] = sum_{m=0}^{min(j, n-1)} a[m] * w[j-m] (since w[j-m] = 0 if j-m > 2n-2, which is always fine)

This IS the linear convolution of a and w evaluated at position j!
conv_linear(a, w)[j] = sum_m a[m] * w[j-m] (where the sum is over all m where both are defined)

Yes! C2[j] = (a * w)[j] (linear convolution of a and w at position j).

And C1[j] = sum_m a[m] * w[m+j] = (a ⋆ w)[j] (cross-correlation).

Cross-correlation = convolution with the flipped second signal:
(a ⋆ w)[j] = (a * w_flipped)[-j] where w_flipped[k] = w[-k]

Or: (a ⋆ w)[j] = (w * a_flipped)[j] where a_flipped[k] = a[-k]

Actually, the standard identity is:
(a ⋆ b)[j] = sum_m a[m] * b[m+j] = (a * b~)[j] where b~[k] = b[-k]

In terms of FFT:
(a ⋆ b) = IFFT(conj(FFT(a)) * FFT(b)) (circular, with proper padding)
(a * b) = IFFT(FFT(a) * FFT(b)) (circular, with proper padding)

So my original approach was correct for C1 (cross-correlation), but I was wrong about C2.

C2[j] = (a * w)[j] = conv(a, w)[j]

So the correct gradient formula is:
grad[j] = C1[j] + C2[j] = corr(a,w)[j] + conv(a,w)[j]

Where:
corr(a,w) = irfft(conj(rfft(a,N)) * rfft(w,N), N)
conv(a,w) = irfft(rfft(a,N) * rfft(w,N), N)

And we take the first n entries of each (j = 0, ..., n-1).
