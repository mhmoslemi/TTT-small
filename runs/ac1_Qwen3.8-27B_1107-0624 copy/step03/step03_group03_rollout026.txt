Optimization of step function heights to minimize 2n*max(conv(a,a))/sum(a)^2.
Uses exponential weights (mirror descent) with spectral initialization and LP refinement.

import time
from scipy.optimize import linprog

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _fft_convolve(a):
    a = np.asarray(a, dtype=np.float64).ravel()
    n = a.size
    if n == 0:
        return np.array([])
    if n <= 64:
        return np.convolve(a, a)
    N = _next_pow2(2 * n - 1)
    fa = np.fft.rfft(a, N)
    c = np.fft.irfft(fa * fa, N)[:2 * n - 1]
    mn = float(c.min())
    if mn < 0.0:
        c = c - mn
    return c

def _score(a):
    a = np.asarray(a, dtype=np.float64).ravel()
    n = a.size
    s = float(a.sum())
    if s < 1e-10:
        return np.inf
    c = _fft_convolve(a)
    return float(2.0 * n * c.max() / (s * s))

def _score_norm(a):
    """Score for normalized (sum=1) sequence."""
    a = np.asarray(a, dtype=np.float64).ravel()
    n = a.size
    c = _fft_convolve(a)
    return float(2.0 * n * c.max())

def _gradient_conv(a, c, active_set):
    """Compute gradient of max(conv) w.r.t. a using active set of lags."""
    n = len(a)
    grad = np.zeros(n)
    for k in active_set:
        # d(conv)_k / d(a_i) = a_{k-i} if 0 <= k-i < n
        lo = max(0, k - n + 1)
        hi = min(n, k + 1)
        for i in range(lo, hi):
            j = k - i
            if 0 <= j < n:
                grad[i] += a[j]
    grad /= len(active_set)
    return grad

def _exp_weights_step(a, c, eta, epsilon=1e-8):
    """One step of exponential weights / mirror descent."""
    n = len(a)
    c_max = float(c.max())
    # Find active set (lags near the maximum)
    active = np.where(c >= c_max - epsilon)[0]
    if len(active) == 0:
        active = np.array([int(np.argmax(c))])
    
    grad = _gradient_conv(a, c, active)
    
    # Mirror descent: a_i <- exp(-eta * grad_i) / Z

    a_new = np.exp(log_a)

    if s < 1e-30:

Actually, let me think about this more carefully. If `a` has a flat magnitude spectrum `|A|_k = C` for all k, then:
`conv(a,a)_m = (1/N) sum_k A_k * A_k * exp(2*pi*i*k*m/N)`

Wait, for linear convolution: `FFT(conv(a,a)) = A * A` (where A is the DFT of zero-padded a).
So `conv(a,a)_m = (1/N) sum_k A_k^2 * exp(2*pi*i*k*m/N)`

If `|A_k| = C` for all k, then `A_k^2 = C^2 * exp(2*i*theta_k)` where `theta_k` is the phase.
`conv(a,a)_m = (C^2/N) * sum_k exp(2*i*theta_k) * exp(2*pi*i*k*m/N)`

This is the inverse DFT of `exp(2*i*theta_k)`. For this to be flat (all m give the same value), we need `exp(2*i*theta_k)` to be a constant (i.e., all theta_k equal). This means `A_k = C * exp(i*theta)` for all k, which gives `a_m = C * N * delta_{m,0} * exp(i*theta)` - a delta function!

So flat spectrum does NOT give flat convolution. The relationship is more complex.

What we actually want is for `A_k^2` to be "flat" in the sense that its inverse DFT is flat. This means `A_k^2 = C' * exp(2*pi*i*k*m_0/N)` for some m_0 (a shifted constant). This means `A_k = sqrt(C') * exp(pi*i*k*m_0/N) * exp(i*phi_k)` where `exp(2*i*phi_k)` must be constant... which again gives a delta.

So it's impossible to have both flat spectrum AND flat convolution for a length-n sequence. The best we can do is approximate.
