- Subgradient with Nesterov acceleration: O(1/eps^2) iterations
- Or a proximal gradient method

The subgradient of F at f is:
- k* = argmax conv(f,f)
- grad = 2 * P_k*(f) where P_k*(f) is the vector with (P_k*(f))_i = f[k*-i] (for valid k*-i)

Wait, I computed this before. The gradient of c_{k*} is: for each i, 2*f[k*-i] (when 0 <= k*-i < n).

So the subgradient of F is `2 * f_reversed_shifted` where the shift depends on k*.

This is very simple to compute! No FFT needed for the gradient.

With subgradient + Nesterov, we might be able to converge faster than the LP approach, at least for the initial phase.

But the issue with pure subgradient is that it only targets one peak, and the convergence rate for non-smooth objectives is only O(1/sqrt(T)).

Actually, you know what, let me try a completely different angle. Let me think about what sequences minimize the peak of autocorrelation.

For a sequence f with sum(f)=1, the convolution (f*f)_k = sum_j f_j * f_{k-j}.

If we think of f as a probability distribution on {0, 1, ..., n-1}, then (f*f) is the distribution of the sum of two independent random variables with that distribution. We want this sum distribution to be as flat as possible.

The sum of two iid random variables has variance = 2*Var(X). If X is uniform on {0,...,n-1}, Var(X) = (n-1)(n+1)/12 ≈ n^2/12, so Var(X+X) ≈ n^2/6. The range of X+X is [0, 2(n-1)], which has 2n-1 values. A "flat" distribution over 2n-1 values would have variance (2n-1)^2/12 ≈ n^2/3. But our actual variance is only n^2/6, which is less. This means the distribution can't be perfectly flat - it's too concentrated.

To make it flatter, we need X to have larger variance. The maximum variance for a variable on {0,...,n-1} is achieved by a "bimodal" distribution: mass at 0 and n-1. Then X+X has mass at {0, n-1, 2(n-1)}. That's even more concentrated!

What about a "U-shaped" distribution? f_0 = f_{n-1} = alpha, f_j = (1-2*alpha)/(n-2) for 1<=j<=n-2. Then X+X would have some mass at the extremes and some in the middle.

Actually, I think the key insight is that we want the convolution to be as flat as possible, which means we want f to be "anti-correlated" in some sense with itself.

Let me try a different approach: **iterative flattening of the convolution**.

Algorithm:
1. Start with f (e.g., uniform or U-shaped)
2. Compute c = conv(f, f)
3. We want c to be as flat as possible. Define error e_k = c_k - mean(c)
4. Adjust f to reduce the error: increase f at positions that "feed into" the low parts of c, decrease f at positions that "feed into" the high parts.

This is essentially what the LP does, but in a more direct way.

def _fft_convolve(a, b):

"""
LP-based iterative optimization for minimizing 2*n*max(conv(a,a))/sum(a)^2.
Uses linear programming to find optimal blend directions (following the SOTA
LP approach), combined with subgradient polishing, adaptive step sizing,
and multi-length escalation.

import numpy as np
from scipy.optimize import linprog
import time

# Helper functions (top-level, no closures)

def _fft_conv(a):
    """Full autocorrelation via FFT: conv(a, a)."""
    n = len(a)
    N = 1
    while N < 2*n - 1:
        N <<= 1
    fa = np.fft.rfft(a, N)
    c = np.fft.irfft(fa * fa, N)[:2*n-1]
    if c.min() < 0:
        c -= c.min()
    return c

def _score(f):
    """Score = 2*n*max(conv(f,f)) with sum(f)=1 assumed."""
    n = len(f)
    return 2.0 * n * float(_fft_conv(f).max())

def _build_A(f):
    """Build LP constraint matrix (2n-1) x n."""
    n = len(f)
    nr = 2*n - 1
    A = np.zeros((nr, n))
    for k in range(nr):
        lo = max(0, k - n + 1)
        hi = min(k + 1, n)
        A[k, lo:hi] = f[k - np.arange(lo, hi)]
    return A

def _solve_lp(f, M):
    """Solve LP: max sum(g) s.t. A@g <= M, g >= 0. Returns normalized g or None."""
    n = len(f)
    A = _build_A(f)
    b = np.full(2*n-1, M)
    c_obj = -np.ones(n)
    res = linprog(c_obj, A_ub=A, b_ub=b, bounds=[(0, None)]*n, method='highs',
                  options={'presolve': True})
    if res.status != 0 or res.x is None:
        return None
    g = res.x.copy()
    s = g.sum()
    if s < 1e-15:
        return None
    return g / s

    n = len(f)

    lo = max(0, ks - n + 1)

"""
LP-based iterative optimization for minimizing 2*n*max(conv(a,a))/sum(a)^2.
Uses linear programming to find optimal blend directions (following the SOTA
LP approach), combined with subgradient polishing, adaptive step sizing,
and multi-length escalation.
"""
import numpy as np
from scipy.optimize import linprog
import time


def _fft_conv(a):
    """Full autocorrelation via FFT: conv(a, a)."""
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    if n == 0:
        return np.array([])
    N = 1
    while N < 2 * n - 1:
        N <<= 1
    fa = np.fft.rfft(a, N)
    c = np.fft.irfft(fa * fa, N)[:2 * n - 1]
    mn = c.min()
    if mn < 0:
        c = c - mn
    return c


def _score(f):
    """Score = 2*n*max(conv(f,f)) assuming sum(f)=1."""
    n = len(f)
    if n == 0:
        return np.inf
    c = _fft_conv(f)
    if c.size == 0:
        return np.inf
    return 2.0 * n * float(c.max())


def _build_A(f):
    """Build LP constraint matrix (2n-1) x n. A[k,j] = f[k-j] if 0<=k-j<n."""
    n = len(f)
    nr = 2 * n - 1
    A = np.zeros((nr, n))
    for k in range(nr):
        lo = max(0, k - n + 1)
        hi = min(k + 1, n)
        if hi > lo:
            A[k, lo:hi] = f[k - np.arange(lo, hi)]
    return A


def _solve_lp(f, M):
    """Solve LP: max sum(g) s.t. A@g <= M, g >= 0. Returns normalized g or None."""
    n = len(f)
    A = _build_A(f)
    b = np.full(2 * n - 1, M)
    c_obj = -np.ones(n)
    try:
        res = linprog(c_obj, A_ub=A, b_ub=b, bounds=[(0, None)] * n,
                      method='highs', options={'presolve': True})
        if res.status != 0 or res.x is None:
            return None
        g = res.x.copy()
        s = g.sum()
        if s < 1e-15:
            return None
        return g / s
    except Exception:
        return None


def _subgrad_step(f, lr):
    """Subgradient step targeting the current max of conv(f,f)."""
    n = len(f)
    c = _fft_conv(f)
    ks = int(np.argmax(c))
    grad = np.zeros(n)
    lo = max(0, ks - n + 1)
    hi = min(ks + 1, n)
    if hi > lo:
        grad[lo:hi] = 2.0 * f[ks - np.arange(lo, hi)]
    f_new = np.maximum(f - lr * grad, 0.0)
    s = f_new.sum()
    if s < 1e-15:
        return f.copy()
    return f_new / s


def _multi_subgrad_step(f, lr, n_targets=3):
    """Multi-target subgradient step: attack top-n peaks simultaneously."""
    n = len(f)
    c = _fft_conv(f)
    top_idx = np.argsort(c)[::-1][:n_targets]
    grad = np.zeros(n)
    for ks in top_idx:
        lo = max(0, ks - n + 1)
        hi = min(ks + 1, n)
        if hi > lo:
            grad[lo:hi] += 2.0 * f[ks - np.arange(lo, hi)]
    f_new = np.maximum(f - lr * grad / n_targets, 0.0)
    s = f_new.sum()
    if s < 1e-15:
        return f.copy()
    return f_new / s


def _interp(f, n_new):
    """Interpolate profile to new length."""
    n = len(f)
    if n == n_new:
        return f.copy()
    x0 = np.linspace(0, 1, n)
    x1 = np.linspace(0, 1, n_new)
    out = np.interp(x1, x0, f)
    out = np.maximum(out, 0)
    s = out.sum()
    if s < 1e-15:
        return np.ones(n_new) / n_new
    return out / s


def _make_profile(n, kind='flat'):

    if best_f is not None:

        s = final.sum()
        if s > 0.01:
            final = final / s
        else:
            final = _make_profile(256, 'flat')

        # Verify with evaluate_sequence
        try:
            sc_eval = float(evaluate_sequence([float(x) for x in final]))
            if np.isfinite(sc_eval):
                print(f"evaluate_sequence score: {sc_eval:.10f}", flush=True)
                if sc_eval < best_sc:
                    best_sc = sc_eval
        except Exception as e:
            print(f"evaluate_sequence failed: {e}", flush=True)

        print(f"\nFINAL: score={best_sc:.10f}, n={len(final)}", flush=True)
        return [float(x) for x in final]

    # Fallback
    fb = _make_profile(256, 'flat')
    print(f"FALLBACK: n=256", flush=True)
    return [float(x) for x in fb]
