Actually, the minimum of max_k c[k] over the probability simplex is what we want to find. This is a well-studied problem in the context of "flat" autocorrelations.

For large n, I believe the optimal max(c) scales like O(log n / n) or O(1/n) (I'm not sure of the exact rate). If it's O(1/n), then the objective would be O(1), which is consistent with the target of ~1.5.

def project_simplex(v):
    """Project vector v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if v.sum() < 1e-15:
        return np.ones(n) / n
    # Standard simplex projection
    mu = np.sort(v)[::-1]
    cumulative = np.cumsum(mu)
    rho = np.arange(1, n+1)
    condition = mu - (cumulative - 1) / rho > 0
    if not condition.any():
        return np.ones(n) / n
    rho_star = np.max(rho[condition])
    theta = (cumulative[rho_star - 1] - 1) / rho_star
    return np.maximum(v - theta, 0)
