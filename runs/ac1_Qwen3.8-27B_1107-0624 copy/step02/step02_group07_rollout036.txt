Now, the coordinate descent step:
- Current: s, conv, total = sum(s).
- For coordinate j:
  - h = 2*s[0:min(n, 2n-1-j)] placed at positions [j, j+len-1].
  - Find d ≥ -s[j] that minimizes f(d) = 2n*max(conv + d*h)/(total+d)^2.
  - Update: s[j] += d, conv += d*h, total += d.

The line search: f(d) is the score after changing s[j] by d.

Note: f(d) → 0 as d → ∞ (as we discussed). So the minimum over d ≥ -s[j] is at d → ∞, giving f → 0. But in practice, after the next coordinate update, this will be "corrected." The issue is that we need to bound d.

A natural bound: d ≤ total (so the new s[j] ≤ total + s[j] ≤ 2*total, meaning s[j] becomes at most about as large as the sum of all others). This prevents any single element from dominating.

Actually, let me think about this more carefully. If we allow d to be very large, then after the update, s[j] is much larger than all other elements. The next coordinate updates will then try to increase the other elements. This creates an oscillation.

A better approach: limit d to [-s[j], s[j]] (so the new value is in [0, 2*s[j]]). This is a "damped" coordinate descent.

Or even better: use a fixed ratio. New s[j] = r * s[j] where r ∈ [0, 2]. So d = (r-1)*s[j], and we optimize over r ∈ [0, 2].

```python
def coordinate_descent_v2(s, n_sweeps=200, deadline=None, rng=None):
    n = len(s)
    s = s.copy().astype(np.float64)
    s = np.maximum(s, 1e-10)
    # Normalize
    s = s / s.sum()
    total = 1.0
    conv = np.convolve(s, s)
    best_score = 2.0 * n * conv.max()
    best_s = s.copy()
    
    for sweep in range(n_sweeps):
        if deadline and time.monotonic() > deadline:
            break
        
        for j in range(n):
            # Compute h
            hi = min(n, 2*n - 1 - j)
            h_len = hi
            # h is non-zero only at positions j to j+h_len-1
            # h[j+p] = 2*s[p] for p = 0, ..., h_len-1
            
            # f(d) = 2n * max(conv + d*h) / (total + d)^2
            # d = (r-1)*s[j], r in [0, 2]
            # So we optimize over r in [0, 2]
            
            sv = s[j]
            # Evaluate at several r values
            r_candidates = np.linspace(0, 2, 30)
            best_r = 1.0
            best_f = 2.0 * n * conv.max() / (total * total)
            
            for r in r_candidates:
                d = (r - 1.0) * sv
                new_total = total + d
                if new_total < 1e-10:
                    continue
                # max of conv + d*h
                # h is non-zero at positions j to j+h_len-1 with values 2*s[0:h_len]
                new_max = conv.max()  # Start with current max
                # Only positions j to j+h_len-1 change
                if j + h_len - 1 < 2*n - 1:
                    affected = conv[j:j+h_len] + d * 2.0 * s[0:h_len]
                    local_max = affected.max()
                    # The max of the whole thing is max of (unaffected max, local max)
                    # But computing unaffected max is expensive. 
                    # Instead, just compute the full max.
                    full_max = max(conv[:j].max() if j > 0 else 0,
                                   local_max,
                                   conv[j+h_len:].max() if j+h_len < 2*n-1 else 0)
                else:
                    full_max = conv.max()
                
                f_val = 2.0 * n * full_max / (new_total * new_total)
                if f_val < best_f:
                    best_f = f_val
                    best_r = r
            
            # Apply update
            d = (best_r - 1.0) * sv
            if abs(d) > 1e-15:
                h = np.zeros(2*n-1)
                h[j:j+h_len] = 2.0 * s[0:h_len]
                s[j] += d
                s[j] = max(s[j], 0.0)
                conv += d * h
                total += d
            
            # Track best
            cur_score = 2.0 * n * conv.max() / (total * total)
            if cur_score < best_score:
                best_score = cur_score
                best_s = s.copy()
    
    # Renormalize and return
    best_s = best_s / best_s.sum()
    return best_s, best_score
```

```python
def peak_shave(s, num_iters=100, alpha=0.1):
    """Directly reduce the peak of the convolution."""
    n = len(s)
    s = s.copy().astype(np.float64)
    s = np.maximum(s, 0.0)
    s = s / s.sum()
    
    for it in range(num_iters):
        conv = np.convolve(s, s)
        p = conv.argmax()
        
        # Compute influence of each s[j] on conv[p]
        # ∂conv[p]/∂s[j] = 2*s[p-j] if 0<=p-j<=n-1 else 0
        lo = max(0, p - n + 1)
        hi = min(n - 1, p)
        # s[j] affects conv[p] through 2*s[p-j] for j in [p-(n-1), p] ∩ [0, n-1]
        # Actually: ∂conv[p]/∂s[j] = 2*s[p-j] for 0≤p-j≤n-1
        # So j ranges from max(0, p-(n-1)) to min(n-1, p)
        
        influence = np.zeros(n)
        for j in range(lo, hi+1):
            influence[j] = 2.0 * s[p-j]
        
        max_inf = influence.max()
        if max_inf < 1e-15:
            break
        
        # Reduce s[j] proportionally to influence
        s = s - alpha * influence / max_inf
        s = np.maximum(s, 1e-10)
        s = s / s.sum()
    
    return s
```

This is O(n) per iteration (the influence computation can be vectorized). Very fast.
