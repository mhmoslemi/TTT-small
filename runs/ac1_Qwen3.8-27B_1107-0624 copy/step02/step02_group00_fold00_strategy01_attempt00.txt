### Hybrid Evolutionary and Gradient Optimization for Step Function

**1. Approach and Rationale:**

We combine an evolutionary strategy with a gradient-based optimizer to find a sequence that minimizes the provided evaluation function. The key idea is to start with a diverse initial population (integer sequences unlike the parent, uniform, linear, or cubic profiles) and then refine the best candidates using a gradient descent algorithm with stabilization through regularization. This approach leverages multiple restarts, early termination, and aggressive hyperparameter scheduling to improve performance and avoid local minima.

**2. Mathematical Specification:**

We represent the sequence as `a`, a vector of non-negative floats of length `n`. The objective function is defined as:

\[
f(a) = \frac{2 \cdot n \cdot \| \text{convolve}(a, a, \text{mode}='\\text{full}') \|_\\infty}{(\sum a)^2}
\]

Constraints:
- `a` must consist of non-negative float values.
- The evaluated sequence must meet the defence checks (no NaN/inf, no booleans, etc.)
- `sum(a)` must be at least 0.01 if not already normalized by the evaluator.

We use a coarse-grained model for rapid exploration: sequences as integer percentages summing to `n` (like a probability distribution). This simplifies initialization and diversity.

**3. Implementation Procedure:**

- **Initialization:**
  1. Generate a population of integer sequences (each element an integer percentage between 1 and 100) of length `n` (dynamically determine length based on dimensionality).
  2. If no suitable parent is available, use a uniform initialization (each element equals `100 / n`).
  3. If a parent exists, create interleaving variants to help escape local minima.

- **Core Update/Simulated Annealing:**
  1. For each candidate in the population, evaluate `f(a)` (coarse-grained risk-based score).
  2. Use a stochastic neighborhood search to find potentially better directions: uniformly perturb one element and repair the sum by adjusting others.
  3. After each update, check if acceptance fails due to `NaN/inf` or if sum reduces below 0.01. Reject such candidates.
  4. Maintain a fraction of original population to retain memory, or save the best candidate from each iteration to continue from there.

- **Search Choices and Usefulness of Variations:**
  1. The initial population should include sequences of different lengths (from 50 to 512, powers of two).
  2. Try at least 30 restarts (each restart: generate new population).
  3. Use temperature-based hyperparameter tuning (update frequency and mutation strength decay with iterations).
