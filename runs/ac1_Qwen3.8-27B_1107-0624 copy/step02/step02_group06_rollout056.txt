- If unique max at `k*`: `2*a_{k*-j}` (if `k* != 2j`) or `2*a_j` (if `k* = 2j`)
  Actually, more precisely: `∂c_{k*}/∂a_j = 2*a_{k*-j}` if `0 <= k*-j <= n-1` and `k* != 2j`, and `2*a_j` if `k* = 2j`.
  Wait, if `k* = 2j`, then `k*-j = j`, so `∂c_{k*}/∂a_j = 2*a_{k*-j} = 2*a_j`. Same formula!
  
  Actually, let me re-derive. `c_k = sum_i a_i * a_{k-i}`.
  `∂c_k/∂a_j`: The terms where `a_j` appears are:
  - `i = j`: `a_j * a_{k-j}`, derivative w.r.t. `a_j` is `a_{k-j}`
  - `k-i = j`, i.e., `i = k-j`: `a_{k-j} * a_j`, derivative is `a_{k-j}`
  - If `j = k-j` (i.e., `2j = k`), these are the same term, so derivative is `2*a_j` (from `a_j^2`).
  
  So: `∂c_k/∂a_j = a_{k-j} + a_{k-j} = 2*a_{k-j}` if `j != k-j`, and `2*a_j` if `2j = k`.
  In both cases: `∂c_k/∂a_j = 2*a_{k-j}` (where `a_{k-j} = a_j` when `k-j = j`).
  And `a_{k-j} = 0` if `k-j` is out of range.

So the subgradient is: for the active set `A = {k : c_k = max(c)}`, the subgradient component is:
`g_j = (1/|A|) * sum_{k in A} 2*a_{k-j}` (where `a_{k-j} = 0` if out of range).

The full subgradient of `F` w.r.t. `a_j` is:
`∂F/∂a_j = 2n * (g_j * S^2 - max(c) * 2*S) / S^4 = 2n * (g_j * S - 2*max(c)) / S^3`

For gradient descent, we want to move in the direction that decreases `F`. Since we want to minimize, we move in the negative gradient direction:
`a_j <- a_j - lr * ∂F/∂a_j`

But we need to maintain `a_j >= 0` and (optionally) `sum(a) = 1`.

If we maintain `sum(a) = 1`, we need to project back onto the simplex after each step. This is a standard operation.

Alternatively, we can work in the space of `a >= 0` without the normalization constraint (since the objective is scale-invariant). In that case, we just need `a_j >= 0`.

Actually, the objective IS scale-invariant: `F(ca) = 2n * max(c(ca,ca)) / (sum(ca))^2 = 2n * c^2 * max(c) / (c^2 * S^2) = 2n * max(c) / S^2 = F(a)`. So scaling doesn't matter.

For the gradient step, I'll normalize after each step to keep `sum(a) = 1`.

The gradient descent update:
1. Compute `g_j` for all `j` (the subgradient of `max(c)`).
2. Compute `F_grad_j = 2n * (g_j * S - 2*max(c)) / S^3`.
3. Update: `a_j <- max(0, a_j - lr * F_grad_j)`.
4. Normalize: `a = a / sum(a)`.

For the subgradient `g_j`:
`g_j = (2/|A|) * sum_{k in A} a_{k-j}` (with `a_{k-j} = 0` if out of range).

If `|A| = 1` (unique max at `k*`):
`g_j = 2 * a_{k*-j}` (zero if `k*-j` out of range).

This is a sparse vector! Only `n` entries are non-zero (those `j` where `0 <= k*-j <= n-1`, i.e., `j` in `[k*-n+1, k*]` intersected with `[0, n-1]`).

For multiple active `k` values, `g_j` is the average of the corresponding vectors.

This is very efficient to compute.

def next_pow2(n):
    """Next power of 2 >= n."""
    k = 1
    while k < n:
