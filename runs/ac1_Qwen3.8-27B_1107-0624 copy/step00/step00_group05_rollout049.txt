    n = len(a)
    acf = full_autocorr(a)
    max_b = np.max(acf)
    sum_a = np.sum(a)
    if sum_a < 0.01:
        return np.inf
    return float(2 * n * max_b / (sum_a ** 2))

2. Find the optimal $a_j$ that minimizes the max autocorrelation.
3. Move to the next element.
4. Repeat.

But this is O(n) per sweep and the max autocorrelation is expensive to evaluate.

**Alternative: Use the "water-filling" analogy.**

Think of it this way: we have $2n-1$ "bins" (the lags of the autocorrelation), and we want to fill them as evenly as possible. Each element $a_j$ contributes to multiple bins (specifically, bins $j$, $j+1$, ..., $j+n-1$ in some pattern). We want to find the $a_j$ values that level the bins.

This is similar to the "load balancing" problem and can be attacked with greedy methods.

**Practical algorithm: Iterated peak reduction with multi-lag awareness**

```
Initialize a (non-uniform)
Repeat until convergence or time runs out:
    Compute autocorrelation acf
    Sort lags by acf value (descending)
    For the top m lags (m = 5 or 10):
        For each such lag k:
            Compute "blame" vector: blame_j = a[k-j] for valid j
            Reduce a_j proportional to blame_j
    Normalize a to sum 1
    Clip to [0, 1000]
```

The "multi-lag" aspect is important because reducing one peak might create another.

Let me also think about a "spectral" approach. Since the autocorrelation is the inverse DFT of $|A(f)|^2$:

$\text{acf}(k) = \frac{1}{N} \sum_{\omega} |A(\omega)|^2 e^{2\pi i \omega k / N}$

(where $N$ is the FFT size).

To make the acf flat, we want $|A(\omega)|^2$ to be as "concentrated" at $\omega = 0$ as possible (since a flat acf corresponds to a delta-spectrum). But wait, that's the opposite: a flat acf corresponds to a concentrated spectrum.

Actually no. A constant acf (all lags equal) corresponds to a delta at frequency 0 in the spectrum. But a delta at frequency 0 means the sequence is constant (uniform), which gives a TRIANGULAR acf, not flat.

Let me get this right. The relationship is:
- $a$ is the sequence.
- $A(\omega) = \text{DFT}(a)$.
- $\text{acf}(k) = \text{IDFT}(|A(\omega)|^2)$.

So:
- If $|A(\omega)|^2$ is constant (flat spectrum), then $\text{acf}(k) = \text{delta}(k)$ (impulse at lag 0). This is a "perfect" autocorrelation.
- If $|A(\omega)|^2$ is concentrated at $\omega = 0$, then $\text{acf}(k)$ is approximately constant (flat). This corresponds to a nearly constant sequence.

Wait, that's not right either. Let me be more careful.

If $a$ is constant (all values equal to $c$), then $A(0) = nc$ and $A(\omega) = 0$ for $\omega \neq 0$. So $|A(\omega)|^2$ is a delta at 0. Then $\text{acf}(k) = c^2 \cdot (\text{number of overlapping terms})$, which is the triangular shape.

If $a$ is a random sequence (white noise), then $|A(\omega)|^2 \approx n \cdot \text{Var}(a)$ for all $\omega$ (approximately flat spectrum). Then $\text{acf}(k) \approx \text{Var}(a) \cdot 1$ for all $k$ (approximately flat/constant autocorrelation). But the actual values are small and positive (since $a \geq 0$).

Wait, for a random non-negative sequence, the autocorrelation at lag 0 is $\sum a_i^2$ (which is larger than the other lags), and at other lags it's approximately $\bar{a}^2$ where $\bar{a} = 1/n$ (if normalized to sum 1). So the peak is at lag 0 with value $\sum a_i^2 \approx n \cdot (1/n)^2 = 1/n$ (for a uniform random sequence).

Hmm, so for a random sequence, the peak is at lag 0 (the "DC" peak), not at the middle lag. This is different from the uniform case where the peak is at the middle lag.

So there are two regimes:
1. **Uniform-like**: peak at middle lag, value $\approx 1/n$. Score $\approx 2$.
2. **Random-like**: peak at lag 0, value $\approx \sum a_i^2$. For a random sequence with sum 1, $\sum a_i^2 \approx 1/n$ (by the "typical" value of $\sum a_i^2$ for a random distribution on the simplex). Score $\approx 2$.

So both give score 2! The question is whether there's a sweet spot in between.

Actually, for a random sequence, $\sum a_i^2$ can range from $1/n$ (uniform) to $1$ (one-hot). The "typical" value for a random point on the simplex is $1/n + 1/n = 2/n$ (I think). Let me compute: for $a_i = X_i / \sum X_j$ where $X_i \sim \text{Exp}(1)$, $E[a_i^2] = E[X_i^2 / (\sum X_j)^2]$. This is complex, but by symmetry, $\sum E[a_i^2] = E[\sum a_i^2] = E[(\sum X_i^2) / (\sum X_i)^2]$.

For large n, $\sum X_i \approx n$ and $\sum X_i^2 \approx n$, so $E[\sum a_i^2] \approx 1/n$. So the peak at lag 0 is about $1/n$, same as the uniform middle peak.

But the key difference is: for the uniform sequence, ALL the "energy" of the autocorrelation is in the middle (trapezoidal shape), while for a random sequence, the energy is spread out with a slight peak at lag 0.

For the random sequence, the max is $\max(\text{lag 0}, \text{middle}, \text{other peaks})$. The lag 0 value is $\sum a_i^2$, and the middle value is $\sum a_i a_{n-1-i}$.

For a random sequence, both are approximately $1/n$ (with some variance). The max of $2n-1$ values, each approximately $1/n$, would be slightly above $1/n$ due to the "max of many random variables" effect.

So a random sequence might have a score slightly above 2. The uniform sequence has score exactly 2. We need to find something in between that has score below 2.

The key insight: we need a sequence where:
- $\sum a_i^2$ is small (to reduce lag 0)
- $\sum a_i a_{n-1-i}$ is small (to reduce middle lag)
- All other lags are also small

This means we want the sequence to be "spread out" (reducing lag 0) AND "anti-symmetric" (reducing middle lag).

A sequence that is "spread out" but "anti-symmetric" around the center would be ideal. For example:
$a_i = f(i)$ where $f$ is a "broad" function (to spread out) and $f(i) \cdot f(n-1-i)$ is small on average (anti-symmetric).

One concrete example: $a_i = (1 + \cos(\pi i / n)) / \sum$ (a half-cosine, high at the center, zero at the edges). This is "spread out" (not concentrated) and "symmetric" (so the middle lag is large).

For anti-symmetry: $a_i = (1 + \cos(\pi(2i+1) / n)) / \sum$ or something that makes $a_i$ and $a_{n-1-i}$ oppositely valued.

Actually, for non-negative sequences, true anti-symmetry is impossible (we can't have $a_i = -a_{n-1-i}$). But we can have "soft" anti-symmetry: $a_i$ is large where $a_{n-1-i}$ is small.

A concrete example: $a_i = (i/n)^\alpha + (1 - i/n)^\alpha$ for some $\alpha > 0$. For $\alpha = 1$, this is a "V" shape (high at edges, low in middle). For $\alpha = 0.5$, it's more "U"-shaped.

For the V-shape ($\alpha = 1$, normalized):
- The sequence is high at the edges and low in the middle.
- The middle lag involves products of $a_i \cdot a_{n-1-i}$, which for the V-shape means: small values in the middle times small values in the middle (both small when $i$ is near $n/2$).
- Actually, for the V-shape, $a_i \approx i/n$ for $i < n/2$ and $a_{n-1-i} \approx (n-1-i)/n$ for $i < n/2$. So $a_i \cdot a_{n-1-i} \approx i(n-1-i)/n^2$, which is a parabola with max at $i \approx n/2$. So the middle lag is NOT small for the V-shape.

Hmm, let me try a different shape. What about $a_i = \sin^2(\pi i / n)$? This is zero at both ends and maximum in the middle. It's symmetric, so the middle lag is an inner product of the sequence with itself (which is large).

What about $a_i = \sin(\pi(i+1) / (n+1))$? This is like a discrete sine mode. It's positive, zero at the "ends" (in a loose sense), and has one peak in the middle. Still symmetric.

For anti-symmetry, I need something like: $a_i$ is a "bump" that is NOT centered. For example, $a_i = \exp(-((i-c)/\sigma)^2)$ for $c < n/2$. Then $a_i$ and $a_{n-1-i}$ are two bumps at different positions, and their product is small when the bumps don't overlap.

But then the lag-0 value $\sum a_i^2$ is concentrated (small support), which increases the peak.

This is the fundamental trade-off. Let me think about it more carefully.

**Key trade-off:**
- To reduce the middle lag: make $a$ "anti-symmetric" (high where the reverse is low).
- To reduce lag 0: make $a$ "spread out" (many small values).
- To reduce other lags: make $a$ have low "self-similarity" at all shifts.

These goals are in tension. The optimal solution balances them.

A sequence that is approximately a "shifted" version of a low-autocorrelation pattern. For example, take a good binary low-autocorrelation sequence (like an m-sequence or Golay code) and map it to non-negative values with a small offset.

"""
Step function optimization via FFT-accelerated subgradient descent with
smart initializations and multi-start strategy. Minimizes 2*n*max(autocorrelation)/sum^2.
Uses multiplicative weight updates, adaptive step sizes, and diverse starting
points to escape local minima.
"""

import numpy as np
import time


def _full_autocorr(a):
    """Compute full autocorrelation of a using FFT. O(n log n)."""
    n = len(a)
    size = 2 * n - 1
    f = np.fft.rfft(a, n=size)
    acf = np.fft.irfft(f * np.conj(f), n=size)
    return acf


def _fast_score(a):
    """Fast computation of the evaluation score using FFT."""
    n = len(a)
    acf = _full_autocorr(a)
    max_b = float(np.max(acf))
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)


def _subgradient_for_peak(a, k_star):
    """Compute subgradient of max autocorrelation at lag k_star."""
    n = len(a)
    g = np.zeros(n)
    lo = max(0, k_star - (n - 1))
    hi = min(n - 1, k_star)
    for j in range(lo, hi + 1):
        g[j] = 2.0 * a[k_star - j]
    return g


def _optimize_from_start(a_init, time_budget, rng, top_k=5, verbose=False):
    """
    Optimize from a given starting point using multiplicative subgradient descent.
    Returns (best_sequence, best_score).
    """
    n = len(a_init)
    a = a_init.copy().astype(np.float64)
    a = np.clip(a, 0.0, 1000.0)
    s = np.sum(a)
    if s < 1e-10:
        a = np.ones(n) / n
        s = 1.0
    a = a / s  # normalize to sum=1

    best_a = a.copy()
    best_score = _fast_score(a)

    deadline = time.monotonic() + time_budget
    eta = 0.15
    patience = 0
    max_patience = 150
    iter_count = 0
    last_log = time.monotonic()

    while time.monotonic() < deadline:
        acf = _full_autocorr(a)

        # Find top_k peaks
        if top_k >= 2 * n - 1:
            peaks = np.argsort(acf)[-1:]
        else:
            peaks = np.argpartition(acf, -top_k)[-top_k:]
        peaks = peaks[np.argsort(acf[peaks])[::-1]]  # sort descending

        # Compute combined subgradient with exponential weighting
        g = np.zeros(n)
        max_acf_val = acf[peaks[0]]
        for idx, k in enumerate(peaks):
            weight = np.exp(-0.5 * (acf[peaks[0]] - acf[k]) / (max_acf_val + 1e-15))
            lo = max(0, k - (n - 1))
            hi = min(n - 1, k)
            for j in range(lo, hi + 1):
                g[j] += weight * 2.0 * a[k - j]

        # Normalize gradient for stability
        g_max = np.max(g)
        if g_max < 1e-15:
            break
        g = g / g_max

        # Multiplicative update (always keeps a > 0)
        a = a * np.exp(-eta * g)
        a = np.clip(a, 0.0, 1000.0)
        s = np.sum(a)
        if s < 1e-10:
            a = best_a.copy()
            continue
        a = a / s

        score = _fast_score(a)
        if score < best_score:
            best_score = score
            best_a = a.copy()
            patience = 0
        else:
            patience += 1

        # Adaptive step size
        if patience > max_patience:
            eta = max(0.01, eta * 0.85)
            patience = 0
            if rng.random() < 0.15:
                # Perturb from best
                a = best_a * (1.0 + 0.05 * rng.standard_normal(n))
                a = np.clip(a, 0.0, None)
                s = np.sum(a)
                if s > 1e-10:
                    a = a / s
                else:
                    a = best_a.copy()
        elif patience > max_patience // 3:
            eta = max(0.01, eta * 0.97)

        iter_count += 1
        if verbose and time.monotonic() - last_log > 30:
            last_log = time.monotonic()
            print(f"    iter={iter_count}, score={best_score:.6f}, eta={eta:.4f}, time_left={deadline - time.monotonic():.0f}s")

    return best_a, best_score


def _make_initializations(n, rng, base_seq=None):
    """Generate diverse initializations. Returns list of arrays (each sums to 1)."""
    inits = []

    # 1. Uniform
    inits.append(np.ones(n) / n)

    # 2. From base sequence with perturbation
    if base_seq is not None and len(base_seq) == n:
        b = np.array(base_seq, dtype=np.float64)
        b = np.clip(b, 0, None)
        if np.sum(b) > 1e-10:
            inits.append(b / np.sum(b))
        # Perturbed base
        b2 = b * (1.0 + 0.3 * rng.standard_normal(n)) if np.sum(b) > 0 else np.ones(n)
        b2 = np.clip(b2, 0, None)
        if np.sum(b2) > 1e-10:
            inits.append(b2 / np.sum(b2))

    # 3. Exponential decay (various rates)
    for rate in [0.5, 2.0, 5.0]:
        x = np.arange(n, dtype=np.float64)
        a = np.exp(-rate * x / n)
        a = a / np.sum(a)
        inits.append(a.copy())

    # 4. Sine-based
    x = np.arange(n, dtype=np.float64)
    for freq in [1, 2, 3]:
        a = 1.0 + np.cos(2 * np.pi * freq * x / n)
        a = np.clip(a, 0.01, None)
        a = a / np.sum(a)
        inits.append(a.copy())

    # 5. V-shape (high at edges)
    x = np.arange(n, dtype=np.float64)
    a = np.abs(x - n / 2.0) / (n / 2.0) + 0.1
    a = a / np.sum(a)
    inits.append(a.copy())

    # 6. Inverted V / bump (high in middle)
    a = 1.0 - np.abs(x - n / 2.0) / (n / 2.0)
    a = np.clip(a, 0.01, None)
    a = a / np.sum(a)
    inits.append(a.copy())

    # 7. Random exponential
    a = rng.exponential(1.0, size=n)
    a = a / np.sum(a)
    inits.append(a.copy())

    # 8. Two-bump asymmetric
    c1 = int(n * rng.uniform(0.15, 0.35))
    c2 = int(n * rng.uniform(0.65, 0.85))
    sigma = n * 0.05
    a = np.exp(-((x - c1) / sigma) ** 2) + np.exp(-((x - c2) / sigma) ** 2)
    a = a / np.sum(a)
    inits.append(a.copy())

    # 9. Power-law
    for p in [0.5, 2.0]:
        a = (x + 1) ** p
        a = a / np.sum(a)
        inits.append(a.copy())

    # 10. Alternating (high-low pattern)
    a = np.ones(n)
    a[::2] = 1.0
    a[1::2] = 0.3
    a = a / np.sum(a)
    inits.append(a.copy())

    # 11. Random walk (smooth)
    a = np.cumsum(rng.standard_normal(n))
    a = np.clip(a, 0.01, None)
    a = a / np.sum(a)
    inits.append(a.copy())

    return inits
