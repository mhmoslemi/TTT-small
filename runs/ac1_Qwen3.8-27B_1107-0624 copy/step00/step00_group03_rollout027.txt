Let me try a different approach entirely: **direct optimization of the Score function using gradient-based methods**.

The Score function is:
Score(s) = 2n * max_k c[k] / (sum s)²

This is not differentiable (because of the max), but we can use subgradient methods or reparameterize.

Reparameterization: Use s = softmax(x) * S for some x and fixed S. Or use s = exp(x) (ensuring positivity) and optimize over x.

Actually, since the Score is homogeneous (Score(αs) = Score(s) for α > 0), we can fix the sum and optimize the shape:
- Fix sum(s) = 1 (or any positive constant).
- Minimize max_k c[k].
- Use s = exp(x) / sum(exp(x)) (softmax) to ensure positivity and fix the sum.

Then the objective is f(x) = max_k (c_k(exp(x)/sum(exp(x)))) which is a smooth function of x (the max of smooth functions is smooth almost everywhere).

We can use L-BFGS-B or Adam to optimize this.

But the dimension is n = 2535, which is large for L-BFGS. Each function evaluation requires computing the convolution (O(n²) for direct, or O(n log n) for FFT-based). For n = 2535, the direct convolution is about 6.4 million operations, which is fast.

With FFT: O(n log n) ≈ 2535 * 12 ≈ 30K operations. Very fast.

So we can do many function evaluations. Let's estimate: if each evaluation takes ~1ms (including the max over 2n-1 values), we can do ~100K evaluations in 100 seconds. With a good optimizer, this should give meaningful progress.

But wait, the landscape might have many local minima. Let me think about the structure.

The objective max_k c[k] is convex in s (it's the max of linear... no, quadratic functions). Actually, c[k] = sum_i s[i]s[k-i] is a quadratic form in s, which is NOT convex in general.

So the objective is NOT convex, and we might get stuck in local minima.

However, there's a useful property: the "valley" structure. The all-ones sequence is a local minimum (Score = 2), and there might be other local minima with lower Score.

To find a better local minimum, we need to "escape" the all-ones basin. This can be done by:
1. Large random jumps.
2. Following a "descent direction" that temporarily increases the objective (like simulated annealing).
3. Using a structured perturbation that's known to reduce the Score.

From my earlier analysis, the key is to make the "AC" component of the autocorrelation negative at the peak positions. This requires the sequence to have a specific structure (like being anti-palindromic or having negative autocorrelation at specific lags).

**New idea: Use a "chirp" sequence.**

A chirp is a signal whose frequency increases (or decreases) with time. In discrete form:
s[i] = exp(i * ω * i²) (complex chirp).

But we need real, non-negative values. We can use:
s[i] = 1 + cos(ω * i²) (a real chirp with DC offset).

This is non-negative if the amplitude of the cosine doesn't exceed 1, which it doesn't (it's 1 + cos, range [0, 2]).

Let me analyze the autocorrelation of this sequence.

For a complex chirp z[i] = exp(iαi²), the autocorrelation is:
R(τ) = sum z[i] z*[i+τ] = sum exp(iαi²) exp(-iα(i+τ)²)
     = sum exp(-iα(2iτ + τ²))
     = exp(-iατ²) * sum exp(-i2αiτ)
     = exp(-iατ²) * D(2ατ)

where D(θ) = sum_{i=0}^{n-1} exp(-iθi) is the Dirichlet kernel.

|D(θ)| = |sin(nθ/2)/sin(θ/2)|.

So |R(τ)| = |D(2ατ)| = |sin(nατ)/sin(ατ)|.

The peak of |R(τ)| is at τ = 0: |R(0)| = n.
The sidelobes have magnitude O(1/|sin(ατ)|) which can be as large as O(n) for some τ (when sin(ατ) is small).

For the "real" chirp s[i] = 1 + cos(αi²), the autocorrelation is:
c[k] = sum (1+cos(αi²))(1+cos(α(k-i)²))
     = n + sum cos(αi²) + sum cos(α(k-i)²) + sum cos(αi²)cos(α(k-i)²)
     ≈ n + 0 + 0 + 1/2 sum cos(α(i²+(k-i)²)) + 1/2 sum cos(α(i²-(k-i)²))

The last two terms are oscillatory and average out to small values for most k. So c[k] ≈ n for most k, and the peak is at k where the oscillatory terms add up constructively.

This suggests that the chirp doesn't help much (the peak is still ≈ n, giving Score ≈ 2).

I think the fundamental limit for non-negative sequences is Score ≈ 2, with only small improvements possible. The target of 1.5027 might be achievable with a very clever construction that I'm not seeing, or it might be a loose target.
