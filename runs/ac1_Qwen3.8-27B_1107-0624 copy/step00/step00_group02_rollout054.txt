```python
import numpy as np
from scipy.optimize import linprog

def solve_lp(a, M):
    """Find g that maximizes sum(g) subject to g >= 0 and conv(a,g) <= M."""
    n = len(a)
    # Variables: g[0], ..., g[n-1]
    # Objective: maximize sum(g) -> minimize -sum(g)
    c = -np.ones(n)
    
    # Constraints: for each k in 0..2n-2: sum_{i+j=k} a[i]*g[j] <= M
    # The coefficient of g[j] in constraint k is a[k-j] (if valid)
    # This is a convolution matrix
    
    # Build the constraint matrix A (2n-1 x n)
    A = np.zeros((2*n-1, n))
    for k in range(2*n-1):
        for j in range(n):
            i = k - j
            if 0 <= i < n:
                A[k, j] = a[i]
    
    b = np.full(2*n-1, M)
    
    # Bounds: g >= 0
    bounds = [(0, None)] * n
    
    result = linprog(c, A_ub=A, b_ub=b, bounds=bounds, method='highs')
    if result.success:
        return result.x
    return None
```

```python
def project_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if v.sum() <= 0:
        return np.ones(n) / n
    # Bisection for tau
    lo, hi = v.min() - 1, v.max() + 1
    for _ in range(100):
        tau = (lo + hi) / 2
        projected = np.maximum(v - tau, 0)
        s = projected.sum()
        if s > 1:
            lo = tau
        else:
            hi = tau
    return np.maximum(v - (lo + hi) / 2, 0)
```

This is essentially a subgradient method for the non-smooth objective (max of convex functions).

But wait, the objective J(a) = 2*n*max_k c[k] is the max of convex quadratic functions (each c[k] is a quadratic form in a, specifically c[k] = a^T (P_k) a where P_k is a permutation matrix). The max of convex functions is convex. So we're minimizing a convex function over the probability simplex!

Wait, is c[k] convex in a? c[k] = sum_{i+j=k} a[i]*a[j]. This is a quadratic form. The Hessian of c[k] with respect to a is... let's see. c[k] = a^T B_k a where B_k is a matrix where B_k[i,j] = 1 if i+j=k and i != j, and B_k[i,i] = 1 if 2i=k. Actually for i != j: the term a[i]*a[j] appears once (at position k=i+j), so the Hessian has 1 at positions (i,j) and (j,i). For i=j and 2i=k: the term is a[i]^2, Hessian has 2 at (i,i).

So B_k is a symmetric matrix with 0s and 1s (or 2s on diagonal). Is B_k positive semidefinite?

B_k is actually a permutation matrix (possibly with some zeros if k is out of range), which is symmetric. A symmetric permutation matrix represents a permutation that is its own inverse (an involution). The eigenvalues of such a matrix are +1 and -1. So B_k is NOT positive semidefinite in general!

For example, if n=3 and k=1: B_1 has B[0,1]=1, B[1,0]=1, rest 0. Eigenvalues: 1, -1, 0. Not PSD.

So c[k] is NOT convex in a, and the objective J(a) is not convex. The subgradient method won't work directly.

Wait, I need to be more careful. The evaluator computes:
`2 * n * max_b / (sum_a**2)`

If sum_a = S, and we scale a by factor c, then:
- max_b scales by c^2
- sum_a scales by c
- Objective: 2*n*(c^2*max_b)/(c^2*S^2) = same.

So it's indeed scale-invariant. We just need sum >= 0.01.
