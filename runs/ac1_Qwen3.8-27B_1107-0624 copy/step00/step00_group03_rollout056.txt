The function g_linear(t) is the max of linear functions of t, hence convex and piecewise linear.
g_quad(t) is convex (quadratic opening upward).
The max of convex functions is convex.
So the numerator h(t) = max(M_base, g_linear(t), g_quad(t)) is convex.

The denominator d(t) = (S - ai + t)^2 is convex and increasing for t > ai - S (which is always true for t >= 0 since S > ai).

The ratio h(t)/d(t) of a convex function to an increasing convex function is not necessarily unimodal. However, h(t) is non-decreasing for large t (since both g_linear and g_quad are increasing for t > 0), and d(t) is increasing. So for large t, the ratio approaches h(t)/d(t) which depends on the asymptotic behavior.

For large t: g_quad ~ t^2, d ~ t^2, so h/d ~ 1 (if g_quad dominates).
For small t: h ~ M_base (if M_base dominates), d ~ (S-ai)^2, so h/d ~ M_base/(S-ai)^2.

The minimum is somewhere in between. This suggests the function might be unimodal (decreasing then increasing), in which case ternary search would work.
