**Better approach: Use the structure of the problem**

Since the problem is scale-invariant, we can normalize $\sum a = 1$ and minimize $\max_k (a*a)[k]$.

Key insight: The full convolution has $2n-1$ terms that sum to 1. The minimum possible max is achieved when the convolution is as flat as possible, i.e., all terms are $\approx 1/(2n-1)$.

The constraint that $a \geq 0$ and $\sum a = 1$ means $a$ is a probability distribution. The convolution is the distribution of the sum of two independent random variables both distributed as $a$.

So we're asking: what probability distribution on $\{0, 1, ..., n-1\}$ minimizes the maximum probability of the sum of two independent copies?

This is a nice reformulation! We want a distribution $p$ on $\{0,...,n-1\}$ such that $p*p$ (the distribution of the sum) is as flat as possible.

The maximum of $p*p$ is at least $1/(2n-1)$ (since there are $2n-1$ possible sums, each with probability at most 1, and they sum to 1). This lower bound is achieved if and only if $p*p$ is uniform on $\{0,...,2n-2\}$.

Can $p*p$ be uniform? That would mean $p$ is a "difference set" or something similar. In the continuous analog, the uniform distribution on $[0,1]$ convolved with itself gives a triangular distribution on $[0,2]$, not uniform. So in the continuous case, the uniform doesn't give a flat convolution.

For the discrete case, we need $\sum_i p_i p_{k-i} = 1/(2n-1)$ for all $k = 0, ..., 2n-2$.

This is a system of $2n-1$ equations in $n$ unknowns (with the constraint $\sum p_i = 1$ and $p_i \geq 0$). For large $n$, this is overdetermined, so an exact solution likely doesn't exist. But we can find an approximate solution.

**Practical approach: Iterative proportional fitting or gradient-based optimization**

Let me think about a practical algorithm:

1. Start with some initial distribution $p$ (e.g., uniform, or the given sequence).
2. Compute the convolution $c = p*p$.
3. Compute the "flattening" target: we want $c$ to be as close to uniform as possible. 
4. Update $p$ to reduce the peaks in $c$.

One natural update: if $c_k > 1/(2n-1)$, we want to reduce the contributions to $c_k$. The contribution to $c_k$ comes from pairs $(i, k-i)$. We could reduce $p_i$ for those $i$ that contribute most to the peak.

This is similar to the "power iteration" or "multiplicative weights" approach.

**Algorithm: Iterative convolution flattening**

1. Normalize $p$ so $\sum p_i = 1$.
2. Compute $c = p*p$ (full convolution, length $2n-1$).
3. For each peak position $k$ where $c_k > \text{mean}(c)$, reduce the elements that contribute to it.
4. Specifically, for each $i$, compute the "excess contribution": how much $p_i$ contributes to positions where $c$ is above the target.
5. Update: $p_i \leftarrow p_i \cdot \exp(-\eta \cdot \text{excess}_i)$, then renormalize.

8. Renormalize.
9. Repeat.

- Time domain: non-negativity

def compute_convolution(a):
    """Compute full self-convolution using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    result = np.fft.irfft(A * A, fft_size)[:size]
    return np.maximum(0, result)

def objective_value(p):
    """Compute the objective value (assuming sum(p) = 1)."""
    c = compute_convolution(p)
    return 2 * len(p) * np.max(c)

def gs_iteration(p, alpha=0.5):
    """One Gerchberg-Saxton iteration."""
    n = len(p)
    size = 2 * n - 1
    N = 1 << (size - 1).bit_length()
    
    P = np.fft.rfft(p, N)
    target_mag = np.sqrt(np.sum(p**2))
    current_mag = np.abs(P)
    
    # Avoid log(0) issues
    current_mag = np.maximum(current_mag, 1e-300)
    new_mag = np.exp(alpha * np.log(current_mag) + (1-alpha) * np.log(target_mag))
    
    phase = np.angle(P)
    P_new = new_mag * (np.cos(phase) + 1j * np.sin(phase))
    
    p_new = np.fft.irfft(P_new, N)[:n]
    p_new = np.maximum(0, p_new)
    s = np.sum(p_new)
    if s < 1e-15:

def _convolve_self(a):
    """Full self-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1

    A = np.fft.rfft(a, fft_size)
    out = np.fft.irfft(A * A, fft_size)[:size]

def _gs_step(p, alpha):

    new_mag = np.exp(new_log_mag)
