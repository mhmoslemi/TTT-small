Let me think about this problem more carefully for large n.

The key quantity is `max(c) / (sum a)^2` where `c = convolve(a, a)` and `sum(c) = (sum a)^2`.

We want to spread the mass of `c` as evenly as possible. `c` has 2n-1 entries. A uniformly distributed `c` would have each entry equal to `(sum a)^2 / (2n-1)`, giving max/sum^2 = 1/(2n-1), and objective = 2n/(2n-1) ≈ 1.

But `c` is constrained: it's the autocorrelation-like convolution of a with itself. The shape of `c` is determined by `a`.

One approach: if `a` is a "spread out" sequence (like a top-hat or Gaussian), then `c` will be more peaked. If `a` has alternating high and low values, `c` might be flatter.

Actually, let me think about it from the perspective of the DFT. 

Let `A[k] = sum_j a[j] * exp(-2πijk/n)` be the DFT of a (zero-padded to length 2n-1 for the convolution).

Then `C[k] = A[k]^2` (in the DFT domain, with appropriate zero-padding).

`c = ifft(C)` has `sum(c) = C[0] = |A[0]|^2 = (sum a)^2`.

We want to minimize `max(c)`, which is equivalent to minimizing the peak of the inverse DFT of `A[k]^2`.

By the uncertainty principle, if `A[k]^2` is spread out in frequency, `c` will be concentrated in time (and vice versa).

For a constant sequence, `A[k]` is a delta at k=0, so `A[k]^2` is also a delta at k=0, and `c` is constant... wait no. If a is constant, A[0] = na and A[k≠0] = 0. So C[0] = (na)^2 and C[k≠0] = 0. Then c is constant = (na)^2/(2n-1) ≈ na^2/2. But we computed earlier that c is triangular for a constant sequence. The discrepancy is because we need to zero-pad to length 2n-1 for the linear convolution.

Let me be more careful. For linear convolution, we zero-pad a to length 2n-1, take DFT, square, and inverse DFT.

If a = [1, 1, ..., 1] (length n), zero-padded to [1, 1, ..., 1, 0, 0, ..., 0] (length 2n-1), the DFT is:
A[k] = sum_{j=0}^{n-1} exp(-2πijk/(2n-1)) = exp(-πi(n-1)k/(2n-1)) * sin(πnk/(2n-1)) / sin(πk/(2n-1))

This is a sinc-like function, not a delta. So C[k] = A[k]^2 is also sinc-like, and c = ifft(C) is the triangular sequence we expected.

OK so the problem is: find a non-negative sequence a of length n that minimizes the peak of its autocorrelation (in the linear convolution sense) relative to its sum squared.

This is related to the "sidelobe" problem in radar/signal processing.

For large n, one approach that might work:
- Use a sequence that is approximately a windowed sinusoid or a "chirp"
- The idea is that in the frequency domain, A[k]^2 should be as flat as possible

A sequence with flat power spectrum (like a CAZAC sequence) would have flat |A[k]|^2, but we need A[k]^2 to be flat, which means A[k] itself should be flat in magnitude AND have a quasinconstant phase. For real sequences, the phase is constrained.
