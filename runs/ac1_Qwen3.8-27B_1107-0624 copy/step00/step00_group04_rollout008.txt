import numpy as np
import time

def proj_simplex(v):
    """Project v onto the probability simplex."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)

def compute_conv(a):
    """Compute full linear convolution of a with itself."""
    return np.convolve(a, a)

def get_grad_conv(a, k):
    """Get gradient of conv(a,a)[k] w.r.t. a."""
    n = len(a)
    grad = np.zeros(n)
    i_start = max(0, k - n + 1)
    i_end = min(k, n - 1)
    j_start = k - i_end
    j_end = k - i_start
    grad[i_start:i_end+1] = 2.0 * a[j_start:j_end+1][::-1]
    return grad

def score_normalized(a):
    """Score for normalized sequence (sum=1)."""
    n = len(a)
    conv = compute_conv(a)
    return 2.0 * n * conv.max()

def optimize_from(a_init, budget_s, rng):
    """Run projected gradient descent from a_init."""
    a = a_init.copy().astype(np.float64)
    a = np.clip(a, 0, None)
    s = a.sum()
    if s < 1e-10:
        a = np.ones(len(a)) / len(a)
        s = 1.0
    a = a / s  # Normalize
    
    n = len(a)
    best_a = a.copy()
    best_score = score_normalized(a)
    
    deadline = time.monotonic() + budget_s
    lr = 0.1  # Learning rate
    patience = 0

    while time.monotonic() < deadline:

        k_star = np.argmax(conv)
        max_val = conv[k_star]

                grad += weight * get_grad_conv(a, k)

        a_new = proj_simplex(a_new)

                lr = min(1.0, lr * 1.1)
                patience = 0
        
        a = a_new

    return best_a, best_score

Actually, I just realized something important. Let me reconsider the problem.

We want to minimize `2n * max_k conv_k / S^2` where S = sum(a).

By Cauchy-Schwarz: S^2 = (sum a)^2 <= n * sum(a^2).

And max_k conv_k >= conv_{n-1} = sum_j a_j * a_{n-1-j}.

Also, max_k conv_k >= conv_0 = a_0^2 (and by symmetry, conv_{2n-2} = a_{n-1}^2).

But more usefully: max_k conv_k >= (1/(2n-1)) * sum_k conv_k = S^2 / (2n-1).

So the minimum score is at least 2n * S^2/(2n-1) / S^2 = 2n/(2n-1) ≈ 1.

And the question is how close to this bound we can get.

For the constraint to be tight, we need all conv_k to be equal to S^2/(2n-1). This means the convolution is a constant (a flat line). In the Fourier domain, this means the FFT of a is constant (all equal magnitude), which is achieved by a "chirp" or "Kasami" type sequence.

For real sequences, we can't achieve a perfectly flat convolution, but we can get close.

Let me think about what a "flat convolution" looks like. If conv(a,a)[k] = c for all k = 0, ..., 2n-2, then:
- sum_k conv_k = (2n-1)*c = S^2, so c = S^2/(2n-1).
- This is a "perfect autocorrelation" in a sense.

In the Z-transform domain: A(z)^2 = c * (1 + z + z^2 + ... + z^{2n-2}) = c * (z^{2n-1} - 1)/(z - 1).

So A(z) = sqrt(c * (z^{2n-1} - 1)/(z - 1)).

This doesn't have a nice closed form in general, but it suggests that sequences with "flat" power spectrum (in a certain sense) would be good.
