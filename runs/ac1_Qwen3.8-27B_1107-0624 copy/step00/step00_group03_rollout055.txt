This is the convolution of a with p, evaluated at specific positions:
(a * p)[j + n - 1] = sum_{l=0}^{n-1} a[l] * p[j + n - 1 - l]

That's not quite what I want. Let me try:
(a * p_reversed)[j] where p_reversed[i] = p[2n-2-i].
(a * p_rev)[j] = sum_l a[l] * p_rev[j-l] = sum_l a[l] * p[2n-2-j+l]

For j = 0: sum_l a[l] * p[2n-2+l] — this goes out of bounds.

I think the cleanest way is to just use scipy.signal.correlate:
R = np.correlate(p, a, mode='valid')
This gives R[j] = sum_i p[i+j] * a[i] for i = 0, ..., n-1, and j = 0, ..., (2n-1)-n = n-1.

So R has length n, and R[j] = sum_{i=0}^{n-1} p[i+j] * a[i].

But I want sum_{l=0}^{n-1} a[l] * p[j+l], which is the same as R[j]! (Just rename i to l.)

So sg = 2 * np.correlate(p, a, mode='valid').

Let me verify: np.correlate(p, a, mode='valid') has length max(2n-1, n) - min(2n-1, n) + 1 = (2n-1) - n + 1 = n. ✓

And the j-th element is sum_{i=0}^{n-1} p[i+j] * a[i]. ✓

So the gradient is: sg = 2 * np.correlate(p, a, mode='valid').

This can be computed in O(n log n) using FFT.

def optimize_sequence(a, num_steps=1000, T_start=1.0, T_end=10.0):
    """Minimize the soft max of the convolution using gradient descent."""

    best_a = a.copy()

        p = np.exp(Tc)
        p /= np.sum(p)
        
        # Compute gradient

        # We want to reduce the max of c. A good step size is related to the
        # current max and the gradient magnitude.
        step_size = 0.1 * np.mean(a) / (np.max(np.abs(sg)) + 1e-10)
        
        # Gradient step
        a_new = a - step_size * sg

Wait, there's an issue. The gradient of the soft max with respect to a is:
d/da[j] [(1/T) log sum_k exp(T*c[k])]
= (1/T) * sum_k T*exp(T*c[k]) * d(c[k])/da[j] / sum_k exp(T*c[k])
= sum_k p[k] * d(c[k])/da[j]
= sum_k p[k] * 2*a[k-j] (if 0<=k-j<n)

And I showed that this equals 2 * np.correlate(p, a, mode='valid')[j].

But wait, I need to double-check the sign. We want to MINIMIZE the soft max, so we go in the NEGATIVE gradient direction:
a_new = a - step_size * gradient

The gradient is positive (since p[k] >= 0 and a[k-j] >= 0), so we're decreasing a. This makes sense: we're reducing the elements that contribute most to the peak.

But we also need to maintain the sum (or at least keep it from going to zero). If we always decrease a, the sum will go to zero. So we need to either:
1. Normalize after each step (keep sum constant).
2. Only decrease some elements and increase others.
3. Use a centering step: subtract the mean of the gradient before updating.

Option 3 is like doing gradient descent on the objective with a sum constraint (using Lagrange multipliers). The Lagrangian is:
L(a, lambda) = soft_max(c(a)) + lambda * (sum(a) - S)
dL/da[j] = gradient[j] + lambda

To keep sum constant, we set lambda = -mean(gradient). So the update is:
a_new = a - step_size * (gradient - mean(gradient))

This preserves the sum (in expectation) and pushes mass from high-gradient elements to low-gradient elements.

    n = len(a)
