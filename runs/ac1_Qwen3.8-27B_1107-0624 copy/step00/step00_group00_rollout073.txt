        eta = 0.01  # learning rate
        a_new = a - eta * grad
        a_new = np.maximum(a_new, 0)
        a_new = a_new / np.sum(a_new)  # renormalize
        
        # Evaluate
        f_new = float(evaluate_sequence(a_new.tolist()))
        if np.isfinite(f_new) and f_new < best_f:
            best_a = a_new.copy()
            best_f = f_new
            a = a_new
        else:
            # Reduce step size
            eta *= 0.5
            a_new = a - eta * grad
            a_new = np.maximum(a_new, 0)
            a_new = a_new / np.sum(a_new)
            f_new = float(evaluate_sequence(a_new.tolist()))
            if np.isfinite(f_new) and f_new < best_f:
                best_a = a_new.copy()
                best_f = f_new
                a = a_new
            # else try smaller eta...
        
        # Occasionally increase beta (sharpen the max approximation)
        if iteration % 1000 == 0 and iteration > 0:
            beta = min(beta * 1.5, 10000.0)
    
    return best_a

Now, let me think about the optimization more carefully.

The objective is: minimize max(conv(a,a)) subject to a >= 0, sum(a) = 1.

This is a non-smooth, non-convex problem. The log-sum-exp smoothing gives us a smooth approximation:
L_beta(a) = (1/beta) * log(sum_k exp(beta * conv_k))

As beta → ∞, L_beta → max(conv). For finite beta, L_beta is a smooth upper bound on max(conv).

The gradient descent on L_beta with the constraint sum(a)=1 and a>=0:
- Projected gradient: a_new = max(0, a - eta * grad), then renormalize to sum=1.
- The grad is the gradient of L_beta (computed as above), minus the Lagrange multiplier for the sum constraint.

For the sum constraint, the Lagrange multiplier lambda satisfies:
sum_j a_j * dL/da_j = 0 (at the optimum, the directional derivative in the feasible direction is 0)

Actually, for equality constraint sum(a)=1, the KKT condition is:
dL/da_j = lambda (for all j with a_j > 0)

So lambda = the weighted average of dL/da_j over the support of a.

In practice, we can just subtract the mean of the gradient (over all j, or over the support) before the update.
