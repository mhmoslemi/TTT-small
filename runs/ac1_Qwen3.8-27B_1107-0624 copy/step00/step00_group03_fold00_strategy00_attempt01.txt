Sin embargo, el objetivo en la mayoría de las mutaciones se incrementa, lo que hace que la búsqueda quede atrapada en un mínimo local temprano y no mejore la secuencia. Para abordar este problema, consideremos utilizar un método de recocido simulado (simulated annealing) que permita mejorar también las soluciones peores con cierta probabilidad, evitando quedarse atrapado en un óptimo local.

 Pasos en la nueva estrategia:

 1. Inicializar la mejor solución con la secuencia del padre (si está disponible) o con un vector de unos (fallback).
 2. Enfriar alrededor de la suma de la secuencia, manteniendo siempre al menos el requisito de que la suma sea >= 0.01.
 3. Utilizar una temperatura que disminuya con el tiempo, permitiendo a las soluciones más peoras a medida que transcurre el tiempo.
 4. Realizar un número máximo de iteraciones (por ejemplo 3600) dentro del tiempo límite de 1800 segundos.

 La idea es que el recocido simulado no seleccione solo las soluciones mejores, sino que acepte las peores con una probabilidad que disminuye con la temperatura. Esto ayuda a escapar de los óptimos locales.

 Sin embargo, el problema de la evaluación es que es costoso calcular la convolución de cada secuencia candidata. Por lo tanto, necesitamos balancear entre la velocidad y la calidad de la búsqueda.

 - Un contador de iteraciones para limitar el número de candidatos generados.

 3. Definir un número máximo de evaluaciones (por ejemplo 3600) basado en el tiempo estimado por evaluación.

            reduction = int(len(current_seq) * keep_rates)
            seq = np.random.default_rng().choice(current_seq[:reduction], size=new_length, replace=True)
            
    # Ensure positivity (though normalization handles this)
    if np.random.random() < 0.25:
        # Sometimes invert randomly
        pos = np.random.randint(0, new_length)
        seq[:pos] *= -1
        
    return seq
    
def mutate_sequence(seq, mutation_type):
    """Mutate the sequence by:

        mutation_type 0: Block perturbation
        mutation_type 1: Add random noise to one element
        mutation_type 2: Swap two adjacent elements
        mutation_type 3: Absolute value adjustment
        mutation_type 4: Sigmoid transformation
        mutation_type 5: Warm restart
        mutation_type 6: Quantile transformation
    """
    n = len(seq)
    rng = np.random.default_rng()
    
    if mutation_type == 0 or mutation_type == 1 or mutation_type == 2 or mutation_type == 6:
        # Block perturbation with multiple methods
        width = np.clip(np.random.normal(0.15 * n, 0.05 * n), n//15, n//5)
        start = rng.integers(0, n - width + 1)
        block = seq[start:start+width]
        
        if mutation_type == 0:
            # Normal perturbation
            block = block * np.exp(rng.normal(0, 0.1, len(block)))
            
        elif mutation_type == 1:
            # Small perturbation
            block = block + rng.normal(0, 0.05 * block.std(), len(block))
            
        elif mutation_type == 2:
            # Make it more peaked
            block = block / block.std() * 0.2 + block
            block = -np.log(np.abs(block)) * 0.7
            
        elif mutation_type == 6:
            # Quantile adjustment
            q_redistribution = rng.choice([-1, 1], p=[0.25, 0.75])
            q_values = np.quantile(block, np.linspace(0,1,5))
            if q_redistribution == 1:
                new_block = np.random.default_rng().choice(q_values, size=len(block))
            else:
                # More uniform
                v_range = q_values[-1] - q_values[0]
                new_block = np.ones(len(block)) * q_values[0] + v_range * rng.random(len(block))
                
        seq[start:start+width] = block
        return seq
        
    # Other mutation types
    elif mutation_type == 3:
        # Absolute value
        factor = rng.uniform(0.9, 1.1)
        seq = np.abs(seq) * factor
        return seq
        
    elif mutation_type == 4:
        # Sigmoid transformation
        seq = 10 * np.log(1 + rng.exponential(1.2, len(seq)))
        return seq
        
    elif mutation_type == 5:
        # Warm restart
        # We'll rebuild the sequence as a separate warm start
        n_new = np.random.choice(list(range(100, n+1, 100)), p=[0.5, 0.3, 0.2] if n>32 else [0.9, 0.09, 0.01])
        seq = np.random.default_rng().normal(0, 0.1, n_new)
        seq = (-seq + np.abs(seq)) * np.random.choice([-1,1])  # Random sign structure
        return seq

def power_of_two_lengths(min_base, max_base, n_level, current_length):
    """Generate lengths that are powers of two near the current length"""
    # Generate base lengths (powers of two)
    base_lengths = [128, 256, 512, 1024, 2048, 4096]
    # Filter
    return [l for l in base_lengths if min_base <= l <= max_base and l >= (current_length//2)/4 and l <= current_length*4]

def mutational_restart(current_seq, n, temp_factor):
    """Perform a complete restart with a higher probability of improvement"""
    # Try multiple restart techniques
    restart_type = np.random.randint(0, 3)
    
    if restart_type == 0:
        # More uniform distribution
        return np.ones(n) * (1.0 / np.sqrt(n)) * np.exp(rng.normal(0, 0.01, n))
    elif restart_type == 1:
        # Step-function with zeros in the back half
        spikes = int(n * 0.1)
        returns = np.zeros(n)
        positions = rng.permutation(spikes)
        returns[position] = np.exp(rng.normal(0, 0.1, spikes))
        return np.concatenate([returns[:spikes//2], returns[spikes//2:]])
    else:
        # Bipolar sequence (may be effective)
        return np.exp(rng.normal(0, 0.1, n)) * np.random.choice([-1,1], size=n, replace=True)
