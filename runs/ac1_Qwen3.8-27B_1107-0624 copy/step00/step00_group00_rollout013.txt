def subgradient_step(p, K, lr):
    """Take a step to reduce max_{k in K} (p*p)[k]."""
    n = len(p)
    # Gradient of (p*p)[k] w.r.t. p[j] is p[k-j] + p[j-k] (with p[m]=0 for invalid m)
    # Average gradient over K
    grad = np.zeros(n)
    for k in K:
        for j in range(n):
            idx1 = k - j
            idx2 = j - k
            if 0 <= idx1 < n:
                grad[j] += p[idx1]
            if 0 <= idx2 < n:
                grad[j] += p[idx2]
    grad /= len(K)
    
    # Projected gradient descent on the simplex
    p_new = p - lr * grad
    # Project onto simplex
    p_new = project_simplex(p_new)
    return p_new

To fix this, I need to make the endpoints small. Let me try a **symmetric** ramp: $a[i] = i/(n/2)$ for $i < n/2$ and $a[i] = (n-1-i)/(n/2)$ for $i \geq n/2$ (tent/triangle shape).

Wait, that would make it peaked in the middle, which is the opposite of what we want.

Actually, let me reconsider. The problem with the linear ramp is that $a[n-1] = 1$, so $c[2n-2] = 1$. If I scale the sequence so that $a[n-1]$ is smaller, the peak at the edge decreases.

But the problem is scale-invariant, so I can't just scale. The SHAPE matters.

Let me try: $a[i] = (i+1)/(n+1)$ for $i = 0, ..., n-1$. Then $a[0] = 1/(n+1)$ and $a[n-1] = n/(n+1)$.

$c[2n-2] = a[n-1]^2 = n^2/(n+1)^2 \approx 1$ for large $n$. Still close to 1.

The fundamental issue: any sequence with a large element will have a large square at the corresponding edge of the convolution.

So to minimize the max, we need ALL elements to be small relative to the sum. This means the sequence should be "spread out" (like the uniform distribution).

But the uniform distribution gives $f = 2$. To beat 2, we need to exploit the structure of the convolution more carefully.

Let me go back to the subgradient approach. The key is:
- The uniform distribution has peak at the center: $c[n-1] = n/n^2 = 1/n$ (for $p = a/S$)
- All other values are smaller
- If we can reduce the center value while not increasing other values, we win

The subgradient at the center for the uniform distribution:
$g[j] = p[n-1-j] + p[j-(n-1)] = 1/n + 0 = 1/n$ (for all $j$, since $j-(n-1) < 0$ for all $j < n$)

Wait, that's not right. Let me recompute.

For $k = n-1$: $g_k[j] = p[n-1-j] + p[j-(n-1)]$

For $j = 0$: $g[0] = p[n-1] + p[-(n-1)] = 1/n + 0 = 1/n$
For $j = 1$: $g[1] = p[n-2] + p[1-(n-1)] = 1/n + 0 = 1/n$
...
For $j = n-1$: $g[n-1] = p[0] + p[n-1-(n-1)] = 1/n + 1/n = 2/n$

So the gradient is $[1/n, 1/n, ..., 1/n, 2/n]$ (the last element is double).

To reduce $(p*p)[n-1]$, we should decrease $p[n-1]$ and increase the other $p_i$'s. This makes the sequence less "bottom-heavy" (in the convolution sense).

If we do this, the center value decreases, but what happens to other lags?

At lag $k = 2n-2$: $c[2n-2] = p[n-1]^2$. If we decrease $p[n-1]$, this decreases. Good.
At lag $k = 2n-3$: $c[2n-3] = p[n-2]p[n-1] + p[n-1]p[n-2] = 2p[n-2]p[n-1]$. If we decrease $p[n-1]$, this decreases. Good.

So decreasing $p[n-1]$ and spreading the mass to other positions seems to help!

But we need to be careful: if we increase $p[j]$ for some $j$, the value at lag $k = j$ (or nearby) might increase.

Let me think about this more systematically. The subgradient method should handle this naturally: it takes a step in the negative gradient direction, which reduces the active constraint while accounting for the effect on other constraints.

Let me implement a proper subgradient/active-set method:

```python
def optimize_by_subgradient(p0, n, max_iters=10000, lr_init=0.01):
    p = p0.copy()
    lr = lr_init
    
    for it in range(max_iters):
        # Compute convolution
        c = np.convolve(p, p, mode='full')
        max_val = c.max()
        max_idx = np.where(c == max_val)[0]
        
        # If multiple active constraints, use the one with largest gradient
        # Or use the average
        K = list(max_idx)
        
        # Compute gradient of max c[k]
        # For each k in K, grad_k[j] = p[k-j] (if valid) + p[j-k] (if valid)
        grad = np.zeros(n)
        for k in K:
            # p[k-j] for j where 0 <= k-j < n, i.e., k-n+1 <= j <= k
            j_start = max(0, k - n + 1)
            j_end = min(k, n - 1)
            for j in range(j_start, j_end + 1):
                grad[j] += p[k - j]
            
            j_start = max(0, -k)  # j-k >= 0 => j >= k
            j_end = min(n - 1, n - 1 + k)  # j-k < n => j < n+k, always true
            # j-k is valid if 0 <= j-k < n, i.e., k <= j <= k+n-1
            j_start = max(k, 0)
            j_end = min(k + n - 1, n - 1)
            for j in range(j_start, j_end + 1):
                grad[j] += p[j - k]
        
        grad /= len(K)
        
        # Projected gradient step on the simplex
        p_new = p - lr * grad
        p_new = project_simplex(p_new)
        
        # Check improvement
        c_new = np.convolve(p_new, p_new, mode='full')
        if c_new.max() < max_val:
            p = p_new
        else:
            lr *= 0.5
            if lr < 1e-10:
                break
    
    return p
```

This is $O(|K| \cdot n)$ per iteration (for the gradient computation) plus $O(n \log n)$ (for the simplex projection). With $n = 4806$ and $|K|$ small, this should be fast.

But wait, I'm computing the full convolution at each iteration, which is $O(n^2)$. For $n = 4806$, that's about 23 million operations per convolution. With FFT, it's $O(n \log n) \approx 60000$ operations. Let me use FFT for the convolution.

Actually, `np.convolve` for 1D sequences of length $n$ is $O(n^2)$ in the naive implementation, but numpy might use a faster algorithm. Let me use FFT-based convolution for safety:

```python
def fast_convolve(a, b):
    n = len(a) + len(b) - 1
    size = 1 << (n - 1).bit_length()  # next power of 2
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:n]
```

For $n = 4806$, the FFT size would be 16384 (next power of 2 after 9611). This is fast.

import numpy as np
import time
import scipy.sparse as sp

def project_simplex(v):
    """Project vector v onto the probability simplex {x : sum(x)=1, x>=0}."""
    n = len(v)
    if n == 1:
        return np.array([max(0, v[0])])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)

def fast_auto_convolve(a):
    """Compute auto-convolution using FFT."""
    n = len(a)
    size = 1 << (2*n - 2).bit_length()
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2*n-1]

def compute_convolution(a):
    """Compute full auto-convolution."""
    n = len(a)
    return np.convolve(a, a, mode='full')

def subgradient_optimize(p, n, max_iters=5000, lr_init=0.005, tol=1e-10):
    """Minimize max_k (p*p)[k] using subgradient method on the simplex."""
    p = p.copy()
    p = project_simplex(p)
    lr = lr_init
    best_max = np.inf
    patience = 0
    
    for it in range(max_iters):
        c = np.convolve(p, p, mode='full')
        current_max = c.max()
        
        if current_max < best_max:
            best_max = current_max
            patience = 0
        else:
            patience += 1
        
        if patience > 500:
            break
        
        # Find active set (top few lags)
        top_k = 3  # use top 3 lags
        sorted_lags = np.argsort(c)[::-1][:top_k]
        # Only include those close to the max
        active = sorted_lags[c[sorted_lags] > current_max * 0.99]
        if len(active) == 0:
            active = sorted_lags[:1]
        
        # Compute gradient
        grad = np.zeros(n)
        for k in active:
            # grad_k[j] = p[k-j] (if 0<=k-j<n) + p[j-k] (if 0<=j-k<n)
            # First term: p[k-j] valid when max(0, k-n+1) <= j <= min(k, n-1)
            j_lo = max(0, k - n + 1)
            j_hi = min(k, n - 1)
            if j_lo <= j_hi:
                grad[j_lo:j_hi+1] += p[k - j_hi : k - j_lo + 1][::-1]
            
            # Second term: p[j-k] valid when max(0, k) <= j <= min(n-1, k+n-1)
            j_lo = max(0, k)  # j >= k for j-k >= 0
            j_hi = min(n - 1, k + n - 1)  # j-k <= n-1, always true since j <= n-1
            if j_lo <= j_hi:
                grad[j_lo:j_hi+1] += p[0:j_hi - j_lo + 1]
        
        grad /= len(active)
        
        # Projected gradient step
        p_new = p - lr * grad
        p_new = project_simplex(p_new)
        
        # Check if improvement
        c_new_max = np.convolve(p_new, p_new, mode='full').max()
        if c_new_max < current_max:
            p = p_new
        else:
            lr *= 0.7
            if lr < 1e-12:
                break
    
    return p, best_max

def lp_direction(a, M):
    """
    Solve LP: max sum(b) s.t. convolve(a, b) <= M, b >= 0.
    Returns the optimal b.
    """
    import cvxpy as cp
    
    n = len(a)
    b = cp.Variable(n, nonneg=True)
    
    # Build sparse matrix A where (A @ b)[k] = convolve(a, b)[k]
    # A[k, j] = a[k-j] if 0 <= k-j < n
    rows = []
    cols = []
    vals = []
    for k in range(2*n - 1):
        j_lo = max(0, k - n + 1)
        j_hi = min(k, n - 1)
        for j in range(j_lo, j_hi + 1):
            rows.append(k)
            cols.append(j)
            vals.append(a[k - j])
    
    A = sp.csr_matrix((vals, (rows, cols)), shape=(2*n-1, n))
    
    constraints = [A @ b <= M]
    objective = cp.Maximize(cp.sum(b))
    prob = cp.Problem(objective, constraints)
    
    for solver in [cp.CLARABEL, cp.ECOS, cp.SCS]:
        try:
            prob.solve(solver=solver)
            break
        except Exception:
            continue
    
    if b.value is not None:
        return np.asarray(b.value, dtype=np.float64).flatten()
    return None
