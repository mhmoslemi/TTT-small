Let me think about this from an information-theoretic perspective. We have n non-negative numbers that sum to S. The convolution has 2n-1 entries that sum to S². We want to minimize the maximum entry.

This is like a "load balancing" problem: we want to distribute S² units of "load" across 2n-1 "bins" as evenly as possible, subject to the constraint that the load is determined by the pairwise products of the sequence entries (with the structure of convolution).

The constraint is: conv[k] = sum_i a[i] * a[k-i] (with appropriate bounds).

This is a system of quadratic equations/inequalities. The problem is: minimize max_k conv[k] subject to a[i] ≥ 0 and sum a[i] = S (or we can normalize S=1 for simplicity).

This is a non-convex optimization problem (because of the quadratic terms and the max).

One approach: use the fact that for the uniform sequence, the answer is exactly 2. Any perturbation from uniform that reduces the peak at some lag must increase it at another lag (by the sum constraint). The question is whether there's a perturbation that reduces the overall maximum.

Let me parameterize: a[i] = 1 + ε*f[i], where sum f[i] = 0 and ||f||_∞ is small.

Then conv[k] = (n-|k-(n-1)|) + ε * g[k] + ε² * h[k], where g and h depend on f.

For the uniform sequence, conv[k] = n - |k-(n-1)| (triangular). The maximum is n at k=n-1.

If we perturb, the first-order change in the center is:
Δconv[n-1] = ε * sum_i f[i] * a[n-1-i] + a[i] * f[n-1-i] = 2ε * sum_i f[i] * 1 = 2ε * sum f[i] = 0.

So the center is unchanged to first order! The first-order changes are at other lags.

conv[k] for k ≠ n-1: the triangular value is c_k = n - |k-(n-1)|.
Δconv[k] = ε * sum_i (f[i]*a[k-i] + a[i]*f[k-i]) = 2ε * sum_i f[i] (for interior lags where all a's are 1).

Wait, that's not right either. Let me be more careful.

a[i] = 1 + ε*f[i].
conv[k] = sum_i (1+ε*f[i]) * (1+ε*f[k-i]) = sum_i [1 + ε*f[i] + ε*f[k-i] + ε²*f[i]*f[k-i]]

For k in the "full overlap" region (n-1 ≤ k ≤ n-1, i.e., just the center), this is:
= (number of terms) + ε * sum_i [f[i] + f[k-i]] + ε² * sum_i f[i]*f[k-i]

For the center k=n-1:
= n + ε * 2*sum_i f[i] + ε² * sum_i f[i]*f[n-1-i]
= n + 0 + ε² * sum_i f[i]*f[n-1-i]

So the center changes only at second order!

For k = n-1 + d (d ≠ 0):
The overlap region has n-|d| terms.
conv[k] = (n-|d|) + ε * sum_i [f[i] + f[k-i]] + O(ε²)

For k = n-1 + d, the valid i range is [d, n-1-d] (for d > 0).
sum_i f[i] = sum_{i=d}^{n-1-d} f[i]
sum_i f[k-i] = sum_i f[n-1+d-i] = sum_j f[j] where j = n-1+d-i, so j ranges from d to n-1-d (same range!).

So sum_i [f[i] + f[k-i]] = 2 * sum_{i=d}^{n-1-d} f[i].

Therefore, to first order:
conv[n-1+d] ≈ (n-|d|) + 2ε * sum_{i=d}^{n-1-|d|} f[i]

For a large d (say d = n-1, the edge), the sum is just f[0] (or f[n-1]).
For d = 1, the sum is sum_{i=1}^{n-2} f[i] = -f[0] - f[n-1] (since sum f = 0).

So the first-order perturbation at lag n-1+d is proportional to the "prefix sum" of f.

To minimize the maximum of the perturbed convolution, we want:
(n-d) + 2ε * P(d) ≤ M for all d, where P(d) = sum_{i=d}^{n-1-d} f[i] and M is the new maximum.

The original maximum was n (at d=0). The new maximum is approximately:
max over d of [(n-|d|) + 2ε * P(d)].

At d=0: n + ε² * Q (second order, so ≈ n for small ε).
At d≠0: (n-|d|) + 2ε * P(d).
