a_new[i] = a[i] - η * a[k*-i] (for valid indices)

This is like a "deconvolution" step. It reduces the values of a at positions that contribute to the peak.

Let me think about whether this makes sense. If the peak is at k* = n-1 (center), then:
grad[i] = a[n-1-i]

So we're reducing a[i] proportionally to a[n-1-i]. If a is symmetric, this means we're reducing all values equally, which would reduce the sum (but we project to maintain the sum).

If a is not symmetric (say, larger at the beginning), then a[n-1-i] is larger for small i, so we reduce the beginning more. This pushes mass from the beginning to the end, breaking the symmetry.

Over many iterations, this might converge to a symmetric solution (since the problem is symmetric under reversal).

Actually, I think there's a key issue: if the sequence is symmetric (palindromic), then the gradient at the peak k* = n-1 is a[n-1-i] = a[i], so the gradient is proportional to a itself. The gradient descent step would be a - η*a = (1-η)*a, which just scales down. After projection to maintain the sum, this does nothing!

So for symmetric sequences, the peak at the center is a "flat direction" - we can't make progress by reducing the center peak alone. We need to look at other peaks or use a different approach.

This suggests we should:
1. Break the symmetry initially (use a non-symmetric starting point)
2. Or, optimize over the non-symmetric degree of freedom
3. Or, use a different objective that accounts for all peaks simultaneously

Actually, let me reconsider. For a symmetric sequence, the peak at the center has gradient proportional to a. But there might be other local maxima in c that are not at the center. If we target those instead, we can make progress.

Alternatively, we can use a different approach: instead of gradient descent on max(c), we can use a "peeling" approach:
1. Find the peak position k*
2. Reduce a at positions that contribute to c[k*]
3. This will create new peaks elsewhere
4. Repeat

This is similar to the LP approach in the state of the art.

Let me also think about the problem from a different angle. What if we formulate it as:

minimize t
subject to: sum_i a_i * a_{k-i} ≤ t for all k
            sum(a) = S
            a_i ≥ 0

This is a non-convex QCQP (quadratically constrained quadratic program) because the constraints are quadratic. However, we can solve it using:
- Alternating direction method: alternate between fixing a and optimizing t (trivial: t = max(c)), and fixing t and optimizing a (linear constraints if we linearize the quadratics).
- Or, use the fact that for a given t, the feasible set {a : c[k] ≤ t ∀k, sum(a)=S, a≥0} can be checked by... well, it's still non-convex.

I think the most practical approach is:
1. Use projected gradient descent with the "all peaks" objective (not just the single max)
2. Use a smoothed max: f(a) = log(sum_k exp(β*c[k])) / β for large β (this is a smooth approximation of max(c))
3. The gradient of this smoothed function is: (1/β) * sum_k exp(β*c[k]) * grad(c[k]) / sum_k exp(β*c[k])
   = weighted average of gradients at all peaks, weighted by exp(β*c[k])

This is essentially a "soft" version of targeting all peaks simultaneously, which should avoid the symmetry issue.

import numpy as np
import time

def propose_candidate(seed=42, budget_s=1800, **kwargs):
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + budget_s - 5.0
    
    # Get initial sequence
    try:
        a_init = np.clip(np.asarray(height_sequence_1, dtype=np.float64), 0.0, 1000.0).copy()
    except:
        a_init = np.ones(256)
    n = len(a_init)
    
    # Generate multiple starting points
    starts = []
    # 1. Normalized initial
    s = a_init.sum()
    if s > 0.01:
        starts.append(a_init / s * np.sqrt(2*n))
    # 2. All ones
    starts.append(np.ones(n) * np.sqrt(2*n/n))
    # 3. Hann window
    w = 0.5 * (1 + np.cos(2*np.pi*np.arange(n)/(n-1)))
    starts.append(w / w.sum() * np.sqrt(2*n))
    # 4. Random
    starts.append(rng.random(n) / rng.random(n).sum() * np.sqrt(2*n))
    # 5. Anti-palindromic perturbation of all-ones
    f = np.arange(n) / (n-1) * 2 - 1  # linear ramp, anti-palindromic
    a5 = 1 + 0.5 * f
    a5 = np.maximum(a5, 0)
    starts.append(a5 / a5.sum() * np.sqrt(2*n))
    
    best_score = float('inf')
    best_a = None
    
    for start in starts:
        if time.monotonic() > deadline:
            break
        
        a = start.copy()
        S = np.sqrt(2*n)
        a = a / a.sum() * S
        
        # Optimize
        for it in range(50000):
            if time.monotonic() > deadline:
                break
            
            c = np.convolve(a, a)
            c_max = c.max()
            
            # Soft-max weights
            beta = 100.0
            shifted = c - c_max
            weights = np.exp(beta * shifted)
            w_sum = weights.sum()
            if w_sum < 1e-30:
                weights = np.zeros_like(c)
                weights[c == c_max] = 1.0 / (c == c_max).sum()
            else:
                weights /= w_sum
            
            # Gradient
            grad = np.convolve(a, weights[::-1])[n-1:2*n-1]
            
            # Step size (backtracking)
            eta = 0.01
            for _ in range(20):
                a_new = a - eta * grad
                a_new = project(a_new, S)
                c_new = np.convolve(a_new, a_new).max()
                if c_new < c_max:
                    break
                eta *= 0.5
            else:
                break
            
            a = a_new
            c_max = np.convolve(a, a).max()
            
            score = 2 * n * c_max / S**2
            if score < best_score:
                best_score = score
                best_a = a.copy()
    
    if best_a is None:
        best_a = starts[0]
    
    return [float(x) for x in best_a]

def project(b, S):
    """Project b onto {x >= 0, sum(x) = S}."""
    # Euclidean projection: x_i = max(0, b_i - lambda)
    # Find lambda such that sum(max(0, b_i - lambda)) = S
    # b_i - lambda > 0 iff b_i > lambda
    # So: sum_{b_i > lambda} (b_i - lambda) = S
    # Let m = number of b_i > lambda: sum_{b_i > lambda} b_i - m*lambda = S
    # lambda = (sum_{b_i > lambda} b_i - S) / m
    
    b_sorted = np.sort(b)[::-1]
    cumsum = np.cumsum(b_sorted)

One more thought: the problem has a lot of symmetry. The sequence a and its reverse a[::-1] give the same score. Also, any "shift" of the sequence (circularly) doesn't change the score (since we're using linear convolution, not circular). However, for the purpose of minimizing the max, the shift doesn't matter much because the max is the same.

Hybrid optimization for minimum peak autocorrelation non-negative sequences.
Uses smoothed-max (log-sum-exp) gradient descent with multiple restarts,
projected onto the non-negative simplex with fixed sum. Combines:
- Multiple diverse starting points (uniform, Hann, Hadamard-inspired, random)
- Adaptive softmax sharpness (annealing)
- Backtracking line search with periodic reheating
- Final polishing phase with very sharp focus on the dominant peak
"""


def _project(b, S):
    """Project vector b onto {x >= 0, sum(x) = S} via bisection."""
    n = len(b)
    if b.sum() < 1e-15:
        return np.full(n, S / n)
    lo = b.min() - 1.0
    hi = b.max() + 1.0
    for _ in range(60):
        mid = 0.5 * (lo + hi)
        if np.maximum(b - mid, 0.0).sum() > S:
            lo = mid
        else:
            hi = mid
    lam = 0.5 * (lo + hi)
    x = np.maximum(b - lam, 0.0)
    s = x.sum()
    if s > 1e-15:
        x *= S / s
    return x


def _compute_grad(a, weights, n):
    """Compute gradient of sum_k weights[k]*c[k] w.r.t. a, where c=convolve(a,a).
    grad[j] = 2 * sum_k weights[k] * a[k-j] (for valid indices)"""
    # sum_k weights[k] * a[k-j] = convolve(a, weights[::-1])[n-1:2n-1]
    raw = np.convolve(a, weights[::-1])[n - 1: 2 * n - 1]
    return 2.0 * raw


def _get_weights(c, beta):
    """Compute softmax weights for the smoothed max."""
    c_max = c.max()
    shifted = c - c_max
    shifted = np.clip(shifted, -50.0 / beta, 0.0)
    exp_vals = np.exp(beta * shifted)
    w_sum = exp_vals.sum()
    if w_sum < 1e-30:
        mask = (c >= c_max - 1e-10)
        weights = mask.astype(np.float64) / mask.sum()
    else:
        weights = exp_vals / w_sum
    return weights, c_max
