def solve_lp(a, M):
    """Solve: maximize sum(b) subject to conv(a,b)[k] <= M, b >= 0"""
    n = len(a)
    # Variables: b[0],...,b[n-1]
    # Objective: maximize sum(b) = minimize -sum(b)
    c = -np.ones(n)
    
    # Constraints: conv(a, b)[k] <= M for k = 0, ..., 2n-2
    # conv(a,b)[k] = sum_{i} a[i] * b[k-i]
    # For each k, the coefficient of b[j] in conv(a,b)[k] is a[k-j] (if valid)

            i = k - j
            if 0 <= i < n:

    b_ub = np.full(2*n-1, M)
    
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=[(0, None)]*n, method='highs')

    return None

The only way to improve is to change the SHAPE of the sequence to make the convolution flatter.

Currently, conv[0] = a[0]^2 = 1, which is the max. If we could reduce a[0] (and correspondingly increase other elements to maintain the "flatness" in the bulk), the max would decrease.

The problem is equivalent to: find a non-negative sequence a of length n that minimizes the "peak-to-mean ratio" of its self-convolution.

For our specific problem (minimizing the PEAK of the full convolution, not just the sidelobes), the optimal solution is related to the "eigenfunction" of the convolution operator with the "max" constraint.
