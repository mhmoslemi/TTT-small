Uses FFT for convolution, HiGHS LP solver for direction finding, and line search.

def compute_conv(p):
    """Compute linear convolution p*p using FFT."""
    n = len(p)
    size = 2 * n - 1
    f = np.fft.rfft(p, n=2 * size)
    conv = np.fft.irfft(f * f, n=2 * size)[:size]
    return np.maximum(conv, 0.0)

def score_from_conv(p, conv):
    """Compute score from precomputed convolution."""
    n = len(p)
    s = np.sum(p)
    if s < 1e-10:
        return np.inf
    return 2.0 * n * np.max(conv) / (s * s)

def build_lp_matrices(n):
    """Precompute sparse structure of the LP constraint matrix."""
    size = 2 * n - 1
    total_rows = size + n
    
    rows = []
    cols = []
    
    # Convolution constraints: row k has non-zeros at cols i where 0<=k-i<n
    for k in range(size):
        i_start = max(0, k - n + 1)
        i_end = min(n - 1, k)
        for i in range(i_start, i_end + 1):
            rows.append(k)
            cols.append(i)
        rows.append(k)
        cols.append(n)  # t variable
    
    # Non-negativity: -d[i] <= p[i]
    for i in range(n):
        rows.append(size + i)
        cols.append(i)

Hmm, the subgradient approach with the simple step size might not work well. Let me think about a better approach.

Actually, let me reconsider the whole problem. Let me think about what distributions give flat self-convolutions.

For a continuous distribution on [0, 1]:
- Uniform: self-convolution is triangular on [0, 2], peak = 1 at x=1.
- Arcsine (Beta(1/2, 1/2)): density f(x) = 1/(pi*sqrt(x*(1-x))). The self-convolution is... complex.
- Poisson-like: not bounded support.

For discrete distributions on {0, 1, ..., n-1}:
- The key is to make the sum distribution (sum of two independent copies) as flat as possible.

One approach from probability theory: if X is uniform on {0, ..., n-1}, then X+Y (Y another independent copy) is triangular. To make it flatter, we could use a distribution that's "more spread out" in some sense.

Actually, I recall that for the problem of minimizing the peak of the autocorrelation of a sequence, the optimal solutions for non-negative sequences are related to "Barker sequences" for small n and are thought to approach a Gaussian-like shape for large n. But I'm not sure about this.

Let me try a different approach: **directed local search**.

Instead of subgradient or LP, let me try:
1. Start from the uniform distribution.
2. At each step, pick a random position i and try to reduce it (moving mass to other positions).
3. Accept if the score improves.

This is a form of simulated annealing / local search.

More specifically:
1. Start with p = uniform.
2. Repeat:
   a. Pick a random position i (to reduce).
   b. Pick a random set of positions J (to increase).
   c. Move a small amount of mass from i to J.
   d. If the score improves, accept; otherwise, reject (or accept with small probability for diversity).

The challenge is evaluating the score after each move. Using FFT, each evaluation is O(n log n). With n=2000, that's about 22000 operations per evaluation. We can do maybe 100,000-1,000,000 evaluations in 1800s.

But the moves need to be smart to actually improve the score. Random moves are unlikely to help.

Let me think about what kind of moves are beneficial:
- If the peak is at position k in the convolution, we want to reduce the contribution to q[k].
- q[k] = sum_i p[i] * p[k-i].
- To reduce q[k], we should reduce p[i] for values of i where p[i] * p[k-i] is large.
- But reducing p[i] increases other q values (at positions i+j for various j).

A good heuristic: reduce p[i] where i is at a "peak" of the distribution AND also at a position that contributes to the convolution peak.

This is getting complicated. Let me just go with the LP approach, which is more principled.

def score_fn(p):
    n = len(p)
    s = p.sum()
    if s < 1e-10:
        return np.inf
    conv = compute_conv(p)
    return 2.0 * n * conv.max() / (s * s)

def precompute_lp_structure(n):
    size = 2 * n - 1
    total_rows = size + n
    row_data = []
    col_data = []
    p_idx = []  # for each non-zero, which element of p to use (-1 for constant)
    
    for k in range(size):
        i_start = max(0, k - n + 1)
        i_end = min(n - 1, k)
        for i in range(i_start, i_end + 1):
            row_data.append(k)
            col_data.append(i)
            p_idx.append(k - i)
        row_data.append(k)
        col_data.append(n)
        p_idx.append(-1)
    
    for i in range(n):
        row_data.append(size + i)
        col_data.append(i)
        p_idx.append(-2)  # -1 for these (value is always -1)
    
    return (np.array(row_data, dtype=np.int32),
            np.array(col_data, dtype=np.int32),
            np.array(p_idx, dtype=np.int32),
            total_rows)

    b_eq = np.zeros(1)

        c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
        method='highs',
        options={'presolve': True, 'time_limit': 60}
    )
    
    if not result.success:
        return None
    return result.x[:n]
