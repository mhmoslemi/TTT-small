The key insight is: we want to minimize max(a*a) / (sum a)^2. By scale invariance, we can set sum a = 1, and we want to minimize max(a*a).

By the Cauchy-Schwarz inequality, (sum a)^2 <= n * sum a^2, so sum a^2 >= 1/n. The minimum of sum a^2 is 1/n (achieved by uniform a_i = 1/n).

But we're minimizing the max of the autocorrelation, not the sum of squares. The relationship between the two is:
- sum of all (a*a)_k = (sum a)^2 = 1
- There are 2n-1 values
- So max(a*a) >= 1/(2n-1)
- And sum of (a*a)_k^2 = ... (Parseval's theorem relates this to sum a_i^4)

For a "random" sequence with a_i ~ Exp(1), normalized to sum 1:
- a_i ≈ 1/n (order)
- (a*a)_k for center k: ≈ n * (1/n)^2 = 1/n (approximately, but with fluctuations)
- max(a*a) ≈ 1/n + O(1/n * sqrt(log n / n))

def _score(conv, S, n):
    if S < 0.01:
        return 1e18
    return 2.0 * n * float(np.max(conv)) / (S * S)

def _pass(parent, conv, S, n, rng):
    """One randomized coordinate descent pass. Returns new S."""
    order = rng.permutation(n)
    for i in order:
        old = parent[i]
        Sp = S - old
        
        # Build candidates
        cands = [0.0]
        
        # Analytical from current max
        ks = int(np.argmax(conv))
        d = ks - i
        if 0 <= d < n:
            c = parent[d]
            if c > 1e-15:
                base = conv[ks] - old * c
                xa = Sp - 2.0 * base / c
                if xa > 0:
                    cands.append(xa)
                    if xa * 0.5 > 0:
                        cands.append(xa * 0.5)
        
        if old > 0:
            cands.append(old * 0.5)
            cands.append(old * 2.0)
            cands.append(max(0.0, old * float(np.exp(rng.normal(0.0, 0.5)))))
        else:
            # Try to activate
            mx = float(np.max(parent))
            if mx > 0:
                cands.append(mx * float(rng.random()))
        
        cur = _score(conv, S, n)
        bv = old
        bs = cur
        
        for nv in cands:
            nv = min(max(nv, 0.0), 1000.0)
            if abs(nv - old) < 1e-18:
                continue

            nS = S + dv
            if nS < 0.01:
                continue
            conv[i:i+n] += dv * parent
            ns = _score(conv, nS, n)
