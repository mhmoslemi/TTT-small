2. Set a[i] to the minimum of these upper bounds (or the current value if it's already below).

Let me also think about the "spectral equalization" step. In the frequency domain:
- `A = FFT(a, 4n)` (zero-pad to avoid circular convolution effects)
- `|A|^2` is the power spectrum (proportional to the DFT of the auto-convolution)

3. `a_new = real(IFFT(A * |A|_new / |A|))` (keep phase, change amplitude)
4. `a_new = max(0, a_new)`, normalize.

This is similar to the "alternating projections" between the set {x: |FFT(x)| is flat} and {x: x >= 0}.

def spectral_equalize(a, alpha=0.5):
    """Flatten the spectrum of a while preserving non-negativity."""
    n = len(a)
    N = 4 * n  # zero-pad
    A = np.fft.rfft(a, N)
    mag = np.abs(A)
    phase = np.exp(1j * np.angle(A))
    # Compress magnitude
    mag_new = mag ** alpha
    # Reconstruct
    A_new = mag_new * phase
    a_new = np.fft.irfft(A_new, N)[:n]
    a_new = np.maximum(a_new, 0)
    s = a_new.sum()
    if s > 1e-10:
        a_new /= s
    else:
        a_new = np.ones(n) / n
    return a_new
