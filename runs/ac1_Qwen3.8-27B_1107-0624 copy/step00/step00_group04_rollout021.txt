def _fft_convolve(f):
    n = len(f)
    size = 1
    while size < 2*n - 1:
        size <<= 1
    F = np.fft.rfft(f, size)
    return np.fft.irfft(F * F, size)[:2*n-1]

def _smoothed_objective_and_grad(f, tau):
    n = len(f)
    size = 1
    while size < 2*n - 1:
        size <<= 1
    F = np.fft.rfft(f, size)

The valid range of $i$ is $0 \leq i \leq n-1$, $j$ is $0 \leq j \leq n-1$, and we need $0 \leq i+j \leq 2n-2$ (length of $w$ is $2n-1$).

The circular version wraps: $\text{corr}[i] = \sum_{j=0}^{N-1} f[j] \cdot w[(i+j) \bmod N]$.

For this to equal the linear version, we need $(i+j) \bmod N = i+j$ for all valid $i, j$. The maximum $i+j$ is $(n-1)+(n-1) = 2n-2$. So we need $N > 2n-2$, i.e., $N \geq 2n-1$.

So $N \geq 2n-1 = 7617$, i.e., $N = 8192$ is sufficient!
