def minimize_peak_convolve(n, budget_s=1800, seed=42):
    import numpy as np
    import time
    
    rng = np.random.default_rng(seed)
    t0 = time.monotonic()
    deadline = t0 + budget_s - 5.0
    
    # Initialize
    a = np.ones(n) / np.sqrt(n)  # or some other initialization
    
    best_a = a.copy()
    best_obj = np.inf
    
    while time.monotonic() < deadline:
        # Compute convolution
        fft_size = 1
        while fft_size < 2*n-1:
            fft_size *= 2
        fa = np.fft.rfft(a, fft_size)
        conv = np.fft.irfft(fa*fa, fft_size)[:2*n-1]
        
        # Find active set (top m lags)
        m = min(10, 2*n-1)
        top_m = np.argpartition(conv, -m)[-m:]
        max_val = conv[top_m].max()
        active = top_m[conv[top_m] > 0.9 * max_val]
        
        # Compute gradient of sum of active lags
        grad = np.zeros(n)
        for k in active:
            # d/d a_i of (a*a)_k = 2 * a[k-i] (if valid)
            i_min = max(0, k-(n-1))
            i_max = min(n-1, k)
            for i in range(i_min, i_max+1):
                grad[i] += 2 * a[k-i]
        
        # Gradient step
        # Normalize gradient
        grad_norm = np.linalg.norm(grad)
        if grad_norm > 0:
            grad = grad / grad_norm
        
        # Backtracking line search
        step = 1.0
        cur_obj = max_val
        for _ in range(30):
            new_a = a - step * grad
            new_a = np.maximum(new_a, 0)
            new_a = new_a / new_a.sum()  # normalize to sum 1
            # Check if objective improved
            fa2 = np.fft.rfft(new_a, fft_size)
            conv2 = np.fft.irfft(fa2*fa2, fft_size)[:2*n-1]
            new_obj = conv2.max()
            if new_obj < cur_obj:
                a = new_a
                break
            step *= 0.5
        else:
            break  # couldn't improve
        
        # Update best
        cur_max = conv.max()
        if cur_max < best_obj:
            best_obj = cur_max
            best_a = a.copy()
    
    return best_a

$f(x) f(x-1/2) = \sin(\pi x) \sin(\pi(x-1/2)) = \sin(\pi x) \cos(\pi x) = \frac{1}{2} \sin(2\pi x)$.
$\int_0^1 \frac{1}{2} \sin(2\pi x) dx = 0$.
Quarter coefficient: 0!

$(a*a)_0 = a_0^2 = \sin^2(0) = 0$. (The edge is zero!)
$(a*a)_{2n-2} = 0$ similarly.

So for the sine shape: edges are 0, center is $n/2$, quarter is 0. What about other lags?

$(a*a)_k \approx n \int_0^1 f(x) f(x - k/n) dx = n \int_0^1 \sin(\pi x) \sin(\pi(x-k/n)) dx$.

Using $\sin A \sin B = \frac{1}{2}[\cos(A-B) - \cos(A+B)]$:
$= \frac{n}{2} \int_0^1 [\cos(\pi k/n) - \cos(2\pi x - \pi k/n)] dx$
$= \frac{n}{2} [\cos(\pi k/n) - \frac{\sin(2\pi - \pi k/n) - \sin(-\pi k/n)}{2\pi}]$
$= \frac{n}{2} [\cos(\pi k/n) - \frac{-\sin(\pi k/n) - \sin(\pi k/n)}{2\pi}]$ (for large $n$, the integral of cos over a full period is 0, but there are boundary effects)

Actually, for large $n$: $\int_0^1 \cos(2\pi x - \pi k/n) dx = \frac{\sin(2\pi - \pi k/n) - \sin(-\pi k/n)}{2\pi} = \frac{-\sin(\pi k/n) + \sin(\pi k/n)}{2\pi} = 0$.

So $(a*a)_k \approx \frac{n}{2} \cos(\pi k/n)$ for large $n$.

The max of $\cos(\pi k/n)$ is 1 (at $k=0$). But we said $(a*a)_0 = 0$! The issue is that the large-$n$ approximation breaks down at $k=0$ (and near the edges).

For $k$ not too close to 0 or $2n-2$: $(a*a)_k \approx \frac{n}{2} |\cos(\pi k/n)|$.

The max (away from edges) is $\frac{n}{2}$ (at $k = n/2$: $\cos(\pi/2) = 0$... wait, that's 0).
