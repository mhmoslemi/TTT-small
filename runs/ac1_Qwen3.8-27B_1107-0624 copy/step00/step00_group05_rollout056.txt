def project_onto_simplex(v, target_sum):
    """Project v onto {x >= 0, sum(x) = target_sum}."""
    # Use bisection on the threshold
    # We want sum(max(v - lambda, 0)) = target_sum
    lo = -np.max(v) - target_sum

Let me also think about the **spectral iteration** (Gerchberg-Saxton):

1. Compute X = FFT(a)
2. Modify |X| to be more flat: |X_new| = (|X|^p + C)^(1/p) for some p < 1 (this compresses the dynamic range)
   Or: |X_new| = |X| / (1 + |X|/C) (soft compression)
   Or simply: |X_new| = sqrt(|X|) (which makes it more flat if |X| varies a lot)
3. Phase remains the same: X_new = |X_new| * exp(i*angle(X))
4. a_new = IFFT(X_new)
5. Project a_new onto {a ≥ 0, sum = S}

This is a form of "spectral shaping" that tries to flatten the power spectrum, which in turn flattens the autocorrelation.

The key parameter is how aggressively we flatten |X|. Too aggressive and we lose information; too gentle and we make slow progress.

def project_onto_simplex(v, target_sum):
    """Project v onto {x >= 0, sum(x) = target_sum} using bisection."""
    if target_sum <= 0:
        return np.zeros_like(v)
    n = len(v)
    if v.sum() == 0:
        return np.full(n, target_sum / n)
    lo = -np.max(v)
    hi = np.max(v)
    for _ in range(100):
        mid = (lo + hi) / 2
        s = np.sum(np.maximum(v - mid, 0))
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    threshold = (lo + hi) / 2
    result = np.maximum(v - threshold, 0)
    # Fix any numerical issues
    diff = target_sum - result.sum()
    if abs(diff) > 1e-10:
        # Distribute the difference to non-zero elements
        mask = result > 0
        if mask.any():
            result[mask] += diff / mask.sum()
            result = np.maximum(result, 0)
    return result
