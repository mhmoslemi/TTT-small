    """Perform one LP-based refinement step."""
    n = len(f)

    # A[k, i] = f[i] if 0 <= k-i < n
    # We'll use the active-set approach

- A^T y >= 1 means: for each i, sum_k A[k,i] * y[k] >= 1, i.e., sum_k f * y[k] (at position i) >= 1
  Wait, A[k,i] = f[i] if 0 <= k-i < n. So A^T[i,k] = f[i] if 0 <= k-i < n.
  (A^T y)[i] = sum_k A^T[i,k] * y[k] = sum_k f[i] * y[k] * [0 <= k-i < n]
  = f[i] * sum_{k: i <= k < i+n} y[k]
  
  The constraint is: f[i] * sum_{k=i}^{i+n-1} y[k] >= 1 for all i.

Interesting! So the dual is:
min M * sum(y) s.t. f[i] * W[i] >= 1 for all i, y >= 0
where W[i] = sum_{k=i}^{i+n-1} y[k] is the "window sum" of y at position i.

This is a nice structure. The constraint says: for each position i, the window sum of y at that position must be at least 1/f[i].

So positions with large f[i] need small W[i], and positions with small f[i] need large W[i].

The dual variables y are non-negative, and we want to minimize their sum.

This is actually a covering problem! We want to find the minimum "total mass" y such that every window of length n has sum at least 1/f[i] (where i is the window center or start).

This can be solved greedily or with a water-filling approach.

The optimal y puts mass at positions where it covers the most constraints. Since each y[k] contributes to W[i] for i in [k-n+1, k] (i.e., the windows that include position k), we want to put y[k] at positions that cover the most "tight" constraints.

This gives a very efficient algorithm:
1. Initialize y = 0
2. Find the most violated constraint: i* = argmin(f[i] * W[i])
3. Increase y at the position k that most helps constraint i* (i.e., k in [i*-n+1, i*] or [i*, i*+n-1], whichever is most effective)
4. Repeat

This is essentially a subgradient method on the dual.

The complementary slackness condition tells us:
- If y[k] > 0, then the corresponding primal constraint (f*g)[k] = M (it's active)
- If (f*g)[k] < M, then y[k] = 0

So the optimal y has support only at the active constraints (where (f*g) = M).

1. Start with f
2. Solve the dual (iteratively) to find y
3. The support of y gives the active constraints
4. Solve the LP with only those constraints
5. Update f

def make_monotone(n, alpha=1.0, c=1.0):
    """Create a monotonically decreasing sequence."""
    idx = np.arange(n, dtype=np.float64)
    t = 1.0 - idx / max(1, n - 1)  # 1 at i=0, 0 at i=n-1
    f = 1.0 + c * (t ** alpha - 0.5)  # centered around 1
    return np.clip(f, 0.01, 1000.0)

def lp_step(f, n_constraints=30, time_limit=20):
    """LP-based refinement: find g that maximizes sum(g) 
    subject to (f*g)[k] <= M for selected constraints."""

    all_idx = np.unique(np.concatenate([peak_idx, edge_idx]))

    # Build constraint matrix A (shape: len(all_idx) x n)
