```python
            best_x = x_new.copy()
```

```python
def project_onto_simplex(v):
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)
```

```python
def lp_direction(f, M):
    """Find b that maximizes sum(b) s.t. b>=0, (f*b)_k <= M for all k."""
    n = len(f)
    # Variables: b_0, ..., b_{n-1}
    # Objective: maximize sum(b) → minimize -sum(b)
    c_obj = -np.ones(n)
    # Constraints: (f*b)_k <= M for k=0,...,2n-2
    # (f*b)_k = sum_i f_i * b_{k-i} (valid i)
    # This is a row of the convolution matrix
    A_rows = []
    b_vec = []
    for k in range(2*n-1):
        row = np.zeros(n)
        for i in range(n):
            j = k - i
            if 0 <= j < n:
                row[j] = f[i]
        A_rows.append(row)
        b_vec.append(M)
    A = np.array(A_rows)
    b_constraint = np.array(b_vec)
    # Non-negativity: b >= 0
    bounds = [(0, None)] * n
    res = linprog(c_obj, A_ub=A, b_ub=b_constraint, bounds=bounds, method='highs')
    if res.success:
        return res.x
    return None
```

Actually, here's a cleaner idea: **coordinate descent**.

At each step, pick a single coordinate i and optimize p_i (given all other p_j fixed) to reduce max(c). The optimal p_i can be found by solving a 1D optimization (the max of several quadratic functions of p_i).

The value c_k as a function of p_i (with other p_j fixed):

- j = k-i: p_{k-i} * p_i (if k-i is valid and k-i ≠ i)
- j = i = k-i (i.e., k = 2i): p_i^2

So:
If k ≠ 2i and k-i is valid: c_k = 2*p_i*p_{k-i} + (other terms) — linear in p_i
If k = 2i: c_k = p_i^2 + (other terms) — quadratic in p_i
If k-i is not valid: c_k = (terms not involving p_i) — constant in p_i

So for each k, c_k is either linear, quadratic, or constant in p_i. The max of these is a convex function of p_i (max of convex functions is convex, and linear/quadratic-convex functions are convex).
