Let me also consider a different algorithm: **the "iterative water-filling" approach**.

The idea: we want `c(m) = C` (constant) for all m. This means `sum_i f(i) f(m-i) = C` for all m. This is a system of (2n-1) quadratic equations in n unknowns. We can try to solve it iteratively.

For a given m, the constraint is `sum_i f(i) f(m-i) = C`. If we fix all f(j) for j ≠ i, this gives a quadratic equation in f(i):
- Terms involving f(i): f(i) appears as f(i)*f(m-i) (when the "first" index is i) and f(m-i)*f(i) (when the "second" index is i). These are the same term unless i = m-i.
- So the equation is: f(i)² * [i = m/2] + f(i) * f(m-i) * [i ≠ m/2 or i = m/2] + (other terms not involving f(i)) = C

This is getting complicated for a linear convolution with boundary effects. Let me stick with the multiplicative weight approach.

**Let me also think about a completely different approach: using the structure of the problem.**

The objective is `2n * max(f*f) / (sum f)²`. Since it's scale-invariant, set sum f = 1. Minimize `max(f*f)`.

The function `g(f) = max_k (f*f)(k)` is a homogeneous quadratic form (max of quadratic forms). We want to minimize it over the simplex {f >= 0, sum f = 1}.

One approach: **Frank-Wolfe / mirror descent**. The mirror map for the simplex is the exponential (KL divergence). Mirror descent with exponential map gives exactly the multiplicative weight update!

So the multiplicative weight update IS the mirror descent step. The learning rate should be `eta_t = 1/sqrt(t)` or similar.

def _fft_convolve(a, b):
    """Compute linear convolution of a and b using FFT."""
    n = len(a) + len(b) - 1
    L = 1
    while L < n:
        L *= 2
    A = np.fft.rfft(a, L)
    B = np.fft.rfft(b, L)
    return np.fft.irfft(A * B, L)[:n]

    """Compute linear autocorrelation (convolution with self) of f."""
    n = len(f)
    L = 1
    while L < 2*n - 1:

    F = np.fft.rfft(f, L)
    return np.fft.irfft(F * F, L)[:2*n-1]
