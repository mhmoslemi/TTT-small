Step-function search that minimizes  2*n*max(conv(a,a)) / (sum(a))**2 .

Key insight used here:

  - The infinite one-sided profile a_j = C(2j,j)/4^j  ==  coeff of (1-x)^(-1/2)

def _next_pow2(x):

    a = np.empty(n, dtype=np.float64)

    for j in range(1, n):
        a[j] = a[j - 1] * (2.0 * j - 1.0) / (2.0 * j)
    s = a.sum()
    return a / s

    a = _seed_binomial(n)

    return G
