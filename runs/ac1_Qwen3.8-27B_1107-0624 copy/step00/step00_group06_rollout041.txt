obj = 2n * max(c) / S^2

Since the objective is scale-invariant, I'll work with S = 1 (so a is a probability vector).
Then obj = 2n * max(c).

I want to minimize max(c) where c = conv(a, a) and a is a probability vector (sum=1, a≥0).

The minimum possible value of max(c) is at least 1/(2n-1) (since sum(c) = S^2 = 1, so max(c) ≥ 1/(2n-1)).
This gives obj ≥ 2n/(2n-1) ≈ 1. This is the theoretical lower bound.

The constant sequence gives max(c) = n*(1/n)^2 = 1/n, obj = 2.

So we're looking for a probability vector whose self-convolution peak is between 1/(2n) and 1/n.

For a "random" probability vector (a[j] ~ Exp(1)/n), the expected value of c[k] is about 1/n^2 * n = 1/n (for the center) or less for other k. The peak is slightly above 1/n due to fluctuations.

To get max(c) < 1/n, we need a structured sequence. The question is what structure.

Let me try a "two-level" sequence: a[j] = p/n for "on" positions and a[j] = q/n for "off" positions, where the "on" positions form some pattern.

If the "on" set has size m and the "off" set has size n-m:
Sum = (mp + (n-m)q)/n = 1, so mp + (n-m)q = n.

The convolution at lag 0: c[0] = a[0]^2 = (p/n)^2 or (q/n)^2 depending on position.
The convolution at the center: c[n-1] = Σ a[j]*a[n-1-j].

"""
Minimizes 2n*max(conv(a,a))/(sum(a))^2 using smoothed gradient descent with FFT.
Multiple restarts with different initializations and adaptive parameters.
"""

import numpy as np
import time
from scipy.fft import fft, ifft

def _convolution(a):
    """Full linear convolution of a with itself using FFT."""
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    return np.real(ifft(A * A, fsize))[:size]

def _cross_corr(a, p):
    """Compute g[i] = sum_j a[j] * p[i+j] for i=0..n-1 using FFT."""
    n = len(a)
    # p has length 2n-1
    N = 1 << (3 * n - 1).bit_length()
    A = fft(a, N)
    P = fft(p, N)
    return np.real(ifft(np.conj(A) * P, N))[:n]

def _evaluate(a):
    """Compute the objective value."""
    n = len(a)
    S = np.sum(a)
    if S < 0.01:
        return np.inf
    c = _convolution(a)
    return 2.0 * n * np.max(c) / (S * S)

def _sm_gradient_descent(a, n, deadline, rng, beta_start=10.0, beta_end=500.0, lr_start=0.1):
    """Run smoothed gradient descent from initialization a."""
    # State
    best_a = a.copy()
    best_score = _evaluate(a)
    m = np.zeros(n)  # Adam first moment
    v = np.zeros(n)  # Adam second moment
    t = 0
    beta = beta_start
    
    while time.monotonic() < deadline:
        t += 1
        # Normalize to sum=1
        S = np.sum(a)
        if S < 1e-10:
            a = np.ones(n) / n
            continue
        a = a / S
        
        # Compute convolution
        c = _convolution(a)
        c_max = np.max(c)
        
        # Softmax weights
        exp_c = np.exp(beta * (c - c_max))
        Z = np.sum(exp_c)
        p = exp_c / Z
        c_smooth = np.log(Z) / beta + c_max
        
        # Gradient: 2n * d(c_smooth)/da = 4n * cross_corr(a, p)
        g = _cross_corr(a, p)
        grad = 4.0 * n * g
        
        # Adam update
        beta1, beta2, eps = 0.9, 0.999, 1e-8
        lr = lr_start / (1.0 + 0.001 * t)
        m = beta1 * m + (1 - beta1) * grad
        v = beta2 * v + (1 - beta2) * grad * grad
        m_hat = m / (1 - beta1 ** t)
        v_hat = v / (1 - beta2 ** t)
        a = a - lr * m_hat / (np.sqrt(v_hat) + eps)
        
        # Project to non-negativity
        a = np.maximum(a, 0.0)
        
        # Renormalize
        S = np.sum(a)
        if S < 1e-10:
            a = np.ones(n) / n
            continue
        a = a / S
        
        # Evaluate
        score = 2.0 * n * c_max  # approximate (using c_max before update)
        # Better: recompute
        c_new = _convolution(a)
        score = 2.0 * n * np.max(c_new)
        
        if score < best_score:
            best_score = score
            best_a = a.copy()
            if t % 1000 == 0:
                print(f"  ({t}) score={best_score:.6f} beta={beta:.1f}")
        
        # Adapt beta
        if t % 500 == 0:
            beta = min(beta * 1.2, beta_end)
        
        # Periodic perturbation
        if t % 5000 == 0:
            n_pert = max(10, n // 10)
            idx = rng.integers(0, n, n_pert)
            a[idx] *= rng.uniform(0.5, 2.0, n_pert)
            a = np.maximum(a, 0)
            S = np.sum(a)
            if S > 1e-10:
                a = a / S
    
    return best_a, best_score
