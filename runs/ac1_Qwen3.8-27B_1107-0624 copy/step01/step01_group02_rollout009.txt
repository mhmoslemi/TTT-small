Actually, let me think about another key insight. The problem is:
minimize max_k c_k subject to a ≥ 0, sum(a) = 1

This is equivalent to:
minimize t subject to c_k ≤ t for all k, a ≥ 0, sum(a) = 1

This is a non-convex problem (because c_k = Σ a_i a_{k-i} is not convex in a). However, if we fix which constraints are active (which k values achieve the max), we get a quadratic constraint, which makes it a quadratically constrained quadratic program (QCQP).

Alternatively, we can use a bisection approach: for a given t, check if there exists a ≥ 0, sum(a) = 1, with c_k ≤ t for all k. This is still non-convex.

Let me just go with the smooth gradient approach. Here's my plan:

1. **Smoothed gradient descent with projection**:

   - Objective: F(a) = 2n * τ * log(Σ exp(c_k/τ))
   - Gradient: computed via FFT
   - Step: a_new = project(a - lr * grad)
   - Adaptive τ: start at τ = max(c)/10, decrease over time
   - Learning rate: backtracking line search

2. **Coordinate descent**:
   - For each coordinate i, find the optimal value of a_i given all others fixed.
   - This is a 1D optimization (quadratic in a_i for each constraint).

3. **Hybrid**: Use smooth gradient for bulk of the time, with occasional coordinate descent and random perturbations.

The projection onto the simplex {a ≥ 0, sum(a) = 1}:
```python
def project_to_simplex(v):
    """Project v onto the probability simplex."""
    n = len(v)
    # Find lambda such that sum(max(v_i - lambda, 0)) = 1
    # Sort v in descending order
    u = np.sort(v)[::-1]
    # Find the largest k such that 1 + u[k]/k > 0 (i.e., the support)
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n+1) + 1 > cssv
    rho = np.max(np.where(cond)[0]) + 1  # 1-indexed
    theta = (cssv[rho-1] - 1) / rho
    return np.maximum(v - theta, 0)
```

This is the standard algorithm from Duchi et al. (2008).
