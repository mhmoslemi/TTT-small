By Parseval: sum_k (conv p)(k)^2 = (sum p)^2 * sum_j p[j]^2... no that's not right.

Actually, for circular convolution: if c = circconv(p,p), then FFT(c) = |FFT(p)|^2.
So sum_k c[k]^2 = (1/N) sum_k |FFT(p)[k]|^4 (by Parseval applied to |FFT(p)|^2).

We want to minimize max_k c[k] (peak of autocorrelation). By the relationship between peak and energy, for a fixed energy, the minimum peak is achieved when the signal is as "spread out" as possible.

In the frequency domain, minimizing the peak of c (which is IFFT(|FFT(p)|^2)) is equivalent to making |FFT(p)|^2 as "spread out" as possible (low peak in time = spread in frequency... wait, that's the wrong direction).

If c[k] = IFFT(|P[k]|^2) where P = FFT(p), then we want c to be flat, which means |P[k]|^2 should be... well, if c is perfectly flat (c[k] = 1/N for all k), then |P[k]|^2 = N (constant). So we want |FFT(p)| to be constant!

A sequence with constant |FFT(p)| is called a "flat spectrum" sequence or "allpass" sequence. For real non-negative sequences, this is related to "Zadoff-Chu" sequences but those are complex.

For real non-negative sequences with flat spectrum, we'd need p to be a "flat top" in the frequency domain. This is achievable approximately with certain window functions.

But wait, we also need the LINEAR convolution to be flat, not just the circular one. The linear conv has 2n-1 points while circular has n points. The linear conv is related to the circular conv by zero-padding.

If we zero-pad p to length 2n and compute the circular conv of the zero-padded version, we get the linear conv. The FFT of the zero-padded p has 2n points, and we want |FFT_2n(p)|^2 to be flat.

But p has only n non-zero entries (the first n), so its 2n-FFT has specific structure. It's related to the DFT of p evaluated at more points (interpolation).

This frequency-domain perspective might give insights for initialization: start with a sequence whose DFT has a nearly flat magnitude.

For a real sequence p of length n, the n-point DFT is P[k] = sum_j p[j] * exp(-2πijk/n).
The 2n-point DFT (with zero-padding to 2n) is: P_2n[k] = sum_j p[j] * exp(-2πijk/(2n)).

For k = 0, 1, ..., 2n-1.

We want |P_2n[k]| to be approximately constant. Since p is real and non-negative, P_2n[0] = sum p = 1. So we want |P_2n[k]| ≈ 1/sqrt(2n) for all k.

This is a "flat-top" constraint in the frequency domain. It's related to the design of"frequency-domain equalizers" or "ultra-wideband" signals.

Given this insight, a good initialization might be: start with a random non-negative sequence, compute its 2n-FFT, and iteratively adjust to flatten the magnitude. This is similar to the Gerchberg-Saxton algorithm (or Fienup's error reduction).

Algorithm:
1. Start with random non-negative p, sum = 1.
2. Compute P_2n = FFT_2n(p).
3. Set |P_2n[k]| = 1/sqrt(2n) for all k (keep the phase).
4. p_new = IFFT_2n(P_2n with flattened magnitude). Take the first n entries.
5. Project onto non-negative, sum=1.
6. Repeat.

This is a spectral flattening algorithm! It might give a good starting point for the optimizer.

"""
Multi-strategy search for minimizing 2n*max(conv(p,p)) over non-negative sequences p.
Combines spectral flattening initialization, L-BFGS-B with adaptive log-sum-exp smoothing,
and peak-targeted subgradient polishing. Uses the previous best as a seed and employs
a coarse-to-fine multi-resolution strategy.
"""

import numpy as np
import time

try:
    from scipy.optimize import minimize
except Exception:
    minimize = None

N = 4096
_FFT_SELF = 1 << (2 * N - 2).bit_length()
_FFT_GRAD = 1 << (3 * N - 2).bit_length()
_X = (np.arange(N, dtype=np.float64) + 0.5) / float(N)

_best_score = float("inf")
_best_p = None
_best_z = None
_deadline = 0.0
_BOUNDS = [(-50.0, 50.0)] * (N - 1)


class SearchTimeout(Exception):
    pass


def _sanitized_z(x):
    x = np.asarray(x, dtype=np.float64)
    x = np.where(np.isfinite(x), x, 0.0)
    x = np.clip(x, -50.0, 50.0)
    return x


def _probs_from_z(z):
    z = _sanitized_z(z)
    m = max(0.0, float(np.max(z))) if z.size else 0.0
    expz = np.exp(z - m)
    exp0 = np.exp(-m)
    Z = exp0 + float(np.sum(expz))
    p = np.empty(N, dtype=np.float64)
    p[0] = exp0 / Z
    p[1:] = expz / Z
    return p


def _self_conv(p):
    f = np.fft.rfft(p, _FFT_SELF)
    c = np.fft.irfft(f * f, _FFT_SELF).real
    c = c[:2 * len(p) - 1]
    np.maximum(c, 0.0, out=c)
    return c


def _score_p(p):
    c = _self_conv(p)
    return 2.0 * float(len(p)) * float(np.max(c))


def _update_best(z, p, score):
    global _best_score, _best_p, _best_z
    if np.isfinite(score) and score < _best_score:
        _best_score = float(score)
        _best_p = np.array(p, copy=True)
        _best_z = np.array(z, copy=True) if z is not None else None


def _grad_p_from_weights(p, w):
    n = len(p)
    w_rev = w[::-1]
    fa = np.fft.rfft(p, _FFT_GRAD)
    fb = np.fft.rfft(w_rev, _FFT_GRAD)
    conv = np.fft.irfft(fa * fb, _FFT_GRAD).real
    # C[i] = conv[2n-2-i]
    idx = 2 * n - 2 - np.arange(n)
    C = conv[idx]
    return 2.0 * C


def _objective_and_grad(x, alpha):
    if time.monotonic() >= _deadline:
        raise SearchTimeout
    x = _sanitized_z(x)
    p = _probs_from_z(x)
    c = _self_conv(p)
    hard = 2.0 * float(N) * float(np.max(c))
    _update_best(x, p, hard)

    cmax = float(np.max(c))
    u = alpha * (c - cmax)
    e = np.exp(u)
    s = float(np.sum(e))
    if s <= 0.0 or not np.isfinite(s):
        J = cmax
        w = np.zeros_like(c)
        w[int(np.argmax(c))] = 1.0
    else:
        J = cmax + np.log(s) / alpha
        w = e / s

    gp = _grad_p_from_weights(p, w)
    sdot = float(np.dot(gp, p))
    gz = p[1:] * (gp[1:] - sdot)
    gz = np.where(np.isfinite(gz), gz, 0.0)
    gz = np.clip(gz, -1e8, 1e8)
    return float(J), gz


def _optimize_z(z0, alpha, max_fun, deadline):
    global _deadline
    if minimize is None:
        return
    _deadline = float(deadline)
    x0 = _sanitized_z(z0)
    max_fun = int(max(60, max_fun))
    max_iter = int(max(40, max_fun // 2))
    try:
        minimize(
            _objective_and_grad,
            x0,
            args=(float(alpha),),
            method="L-BFGS-B",
            jac=True,
            bounds=_BOUNDS,
            options={"maxfun": max_fun, "maxiter": max_iter,
                     "ftol": 1e-15, "gtol": 1e-10, "maxls": 20, "disp": False},
        )
    except SearchTimeout:
        return
    except Exception:
        return


def _density_to_z(f):
    f = np.asarray(f, dtype=np.float64)
    f = np.where(np.isfinite(f), f, 0.0)
    f = np.maximum(f, 1e-15)
    f = f / float(np.sum(f))
    logf = np.log(f)
    z = logf[1:] - logf[0]
    return np.clip(z, -50.0, 50.0)


def _spectral_flatten_init(rng, n_iters=200):
    """Flat-top spectrum initialization via Gerchberg-Saxton-like iteration."""
    p = np.ones(N)
    p *= rng.uniform(0.5, 2.0, N)
    p = np.maximum(p, 1e-10)
    p /= float(np.sum(p))

    fft_len = 2 * N
    target_mag = 1.0 / np.sqrt(float(fft_len))

    for _ in range(n_iters):
        P = np.fft.fft(p, fft_len)
        mag = np.abs(P)
        mag_new = target_mag * (0.5 + 0.5 * mag / max(1e-15, np.max(mag)))
        phase = P / np.maximum(mag, 1e-30)
        P_new = mag_new * phase
        p_new = np.real(np.fft.ifft(P_new))[:N]
        p_new = np.maximum(p_new, 1e-12)
        p_new /= float(np.sum(p_new))
        p = p_new
    return _density_to_z(p)


def _structured_candidates(rng):
    cands = []
    # Linear ramp
    for mult in (0.3, 0.5, 0.7, 1.0, 1.5, 2.0, 3.0):
        f = 1.0 + mult * _X
        cands.append(_density_to_z(f))
        f = 1.0 + mult * (1.0 - _X)
        cands.append(_density_to_z(f))
    # Exponential
    for beta in (0.5, 1.0, 2.0, 3.0, 5.0):
        f = np.exp(beta * _X)
        cands.append(_density_to_z(f))
        f = np.exp(-beta * _X)
        cands.append(_density_to_z(f))
    # Logistic S-curves
    for beta in (2.0, 4.0, 6.0, 8.0, 12.0):
        u = beta * (2.0 * _X - 1.0)
        f = 1.0 / (1.0 + np.exp(-u))
        cands.append(_density_to_z(f))
    # Polynomial
    t = _X - 0.5
    for deg in (2, 3, 5):
        f = 1.0 + 0.5 * np.abs(t) ** (2.0 / deg)
        cands.append(_density_to_z(f))
        f = 1.0 + 0.3 * t ** (deg - 1) if deg % 2 == 0 else 1.0 + 0.3 * t ** deg
        f = np.maximum(f, 1e-6)
        cands.append(_density_to_z(f))
    # Bimodal
    for center in (0.25, 0.35, 0.4, 0.6, 0.65, 0.75):
        for width in (0.05, 0.1, 0.15, 0.2):
            f = np.exp(-((_X - center) / width) ** 2) + np.exp(-((_X - (1-center)) / width) ** 2)
            cands.append(_density_to_z(f))
    # Spectral flattening
    for _ in range(4):
        cands.append(_spectral_flatten_init(rng, 150))
    # Random structured
    for _ in range(20):
        f = np.ones(N)
        for _q in range(3):
            c = rng.uniform(0.1, 0.9)
            w = rng.uniform(0.05, 0.3)
            a = rng.uniform(0.2, 1.0)
            f += a * np.exp(-((_X - c) / w) ** 2)
        f = np.maximum(f, 1e-8)
        cands.append(_density_to_z(f))
    return cands


def _polish_subgradient(z0, deadline, rng):
    """Peak-targeted subgradient method with adaptive step size."""
    z = _sanitized_z(z0)
    p = _probs_from_z(z)
    score = _score_p(p)
    _update_best(z, p, score)

    noise = 0.08
    fails = 0
    step_mult = 1.0

    while time.monotonic() < deadline:
        if time.monotonic() >= deadline:
            break
        c = _self_conv(p)
        cmax = float(np.max(c))

        # Use top-2 peaks for sharper direction
        topk = 2
        idx = np.argpartition(c, -topk)[-topk:]
        w = np.zeros_like(c)
        wv = c[idx] + 1e-15
        w[idx] = wv / float(np.sum(wv))

        gp = _grad_p_from_weights(p, w)
        sdot = float(np.dot(gp, p))
        gz = p[1:] * (gp[1:] - sdot)
        gnorm = float(np.linalg.norm(gz))

        accepted = False
        if gnorm > 1e-14:
            direction = gz / gnorm
            base_step = 0.5 * step_mult
            for frac in (1.0, 0.5, 0.25, 0.125, 0.0625):
                step = base_step * frac
                zt = z - step * direction
                zt = _sanitized_z(zt)
                pt = _probs_from_z(zt)
                st = _score_p(pt)
                if st < score - 1e-13:
                    z = zt
                    p = pt
                    score = st
                    _update_best(z, p, score)
                    accepted = True
                    step_mult = min(3.0, step_mult * 1.1)
                    break
            if not accepted:
                step_mult = max(0.1, step_mult * 0.7)

        # Random perturbation escape
        if not accepted:
            best_local_score = score
            best_local_z = z
            best_local_p = p
            for _ in range(5):
                zt = z + rng.normal(0.0, noise, N - 1)
                zt = _sanitized_z(zt)
                pt = _probs_from_z(zt)
                st = _score_p(pt)
                if st < best_local_score - 1e-13:
                    best_local_score = st
                    best_local_z = zt
                    best_local_p = pt
            if best_local_score < score - 1e-13:
                z = best_local_z
                p = best_local_p
                score = best_local_score
                _update_best(z, p, score)
                accepted = True
                noise = min(0.3, noise * 1.2)
            else:
                fails += 1
                noise = max(0.01, noise * 0.85)
                if fails > 200:
                    break
        else:
            fails = 0

        if _best_score < score - 1e-6:
            z = _sanitized_z(_best_z)
            p = _probs_from_z(z)
            score = _score_p(p)


def _choose_alpha(score):
