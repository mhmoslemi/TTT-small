# 1. Approach and rationale
This approach uses a physics-inspired particle swarm optimization (PSO) method combined with directed rounding and structured perturbations. Instead of relying purely on gradient information, we interpret the coefficients as a discrete representation of a function and search for solutions that reduce the Lipschitz constant of this function. The search prioritizes positions that contribute most significantly to the maximum convolution value (peak height), using this insight to guide coordinate-specific updates. In contrast to previous methods that optimized the smooth function J, we directly optimize the original objective which includes clamping to [1,1000] and ensures non-negativity through these constraints. This method is particularly effective when the neighbors form a quasi-sinusoidal pattern, which is common towards the maximum Lipschitz point.

# 2. Mathematical specification
The objective function is defined as:
    J(a) = 2 * n * max(convolve(a, a)) / (sum(a))^2

We define candidate positions based on their contribution to the convolution maximum. For each position i, compute the sensitivity s_i = ||convolve(a + noise_i, a + noise_i)|| - ||convolve(a, a)|| where noise_i is a targeted perturbation. This captures how much increasing or decreasing a_i affects the overall Lipschitz constant. The search algorithm then focuses on minimizing the maximum sensitivity across positions.
