```python
def convolution_equalization(a, target, n_iter=100, eta=0.01):
    """Iteratively equalize the convolution."""
    for _ in range(n_iter):
        C = convolve_fft(a)
        pressure = np.maximum(0, C - target)
        if np.max(pressure) < 1e-6:
            break
        # For each a[i], compute how much it contributes to over-pressure
        # dC[k]/da[i] = a[k-i] (for valid k-i)
        # So the "pressure gradient" for a[i] is sum_k pressure[k] * a[k-i]
        # This is a cross-correlation of pressure and a
        p = np.zeros(len(C))
        p[:len(pressure)] = pressure
        cross = cross_correlate(p, a)  # cross[i] = sum_k p[k]*a[k-i]
        a -= eta * cross / np.sum(a)
        a = np.maximum(a, 0)
    return a
```

sum_k p[k]*C[k] = sum_k p[k]*sum_i a[i]*a[k-i] = sum_i a[i]*sum_k p[k]*a[k-i] = sum_i a[i]*q[i]

This is still non-linear in a (product a[i]*q[i] where q depends on a). So there's no simple closed form.

However, if we fix q (from a previous iterate), the inner problem becomes:
min sum_i a[i]*q[i] s.t. sum a = S, a ≥ 0
This is solved by putting all mass on the index with minimum q[i]: a[i*] = S where q[i*] = min q.

This gives a "greedy" algorithm: alternate between (1) choosing p to maximize sum p[k]*C[k] (i.e., p = delta at argmax C) and (2) choosing a to minimize sum a[i]*q[i] (i.e., a = S * delta at argmin q). But this just bounces around and doesn't converge to a good solution.

def convolve_fft(a):
    n = len(a)
    size = 1
    while size < 2*n-1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    result = np.fft.irfft(fa*fa, size)

    return i**(-alpha) * (n+1-i)**(-alpha)

def exponential_profile(n, decay=0.5):
    return np.exp(-decay*np.arange(n)/n)
