def _make_flat_seed(n):
    """Create a seed that approximates a flat convolution."""
    # Start with the recursive formula for the "tail"
    f = np.ones(n) / n  # start uniform
    # Apply the "flat convolution" tail from both ends
    tail_len = min(n // 4, 64)
    for k in range(tail_len):
        # a[k] from flat constraint
        target = 1.0 / (2 * n - 1)
        # Solve for a[k] given a[0]..a[k-1]
        # (a*a)[k] = sum_{i=0}^{k} a[i]*a[k-i] = target
        # The term a[k]*a[0] is 2*a[k]*f[k] (for k>0) or a[0]^2 (for k=0)
        if k == 0:
            f[0] = np.sqrt(target)
        else:
            s = sum(f[i] * f[k-i] for i in range(k))
            f[k] = (target - s) / (2.0 * f[0])
            if f[k] < 0:
                f[k] = 0.0
        # Mirror from the right
        f[n-1-k] = f[k]
    # Fill the middle
    mid_start = tail_len
    mid_end = n - tail_len
    if mid_end > mid_start:
        remaining = 1.0 - f[:tail_len].sum() - f[n-tail_len:].sum()
        # Wait, the tails overlap if tail_len > n/2
        # For now, just set the middle to make sum = 1
        middle_sum = 1.0 - f[:tail_len].sum() - f[n-tail_len:].sum()
        if middle_sum < 0:
            middle_sum = 0
        f[mid_start:mid_end] = middle_sum / (mid_end - mid_start)
    f = np.maximum(f, 0)
    f = f / f.sum()
    return f

    n = len(f)
    f = np.maximum(f, 0)
    S = f.sum()
    f = f / S  # normalize to sum = 1

    best_M = _max_conv(f)

        if M < best_M:
            best_M = M
            best_f = f.copy()

        # Maximize: sum(g) = -min(-sum(g))

                      bounds=[(0, None)]*n, method='highs')

            break

        g_sum = g.sum()
        if g_sum <= 0:
            break

        t = 0.5
        f_new = (1 - t) * f + t * g

            # Tried a big step didn't work, try smaller
            t = 0.1

One more thought: the LP constraint matrix A has entries A[k,j] = f[k-j]. Since f >= 0, all entries of A are non-negative. This means the LP is a "packing" type problem. The dual would be:

minimize M * sum(y_k)
subject to: sum_k y_k * A[k,j] >= 1 for all j
y_k >= 0

The dual variables y_k have a nice interpretation: they are "weights" on the lags. The constraint says that for each position j, the total "pressure" from adjacent lags must be at least 1.

At the optimum, by complementary slackness:
- g[j] > 0 implies sum_k y_k * f[k-j] = 1 (all constraints that "touch" position j are tight)
- y_k > 0 implies (f*g)[k] = M (only lags at the max have positive weight)

This gives us a way to check convergence: if the set of active constraints (lags at max) is stable and the dual solution is unique, we've converged.
