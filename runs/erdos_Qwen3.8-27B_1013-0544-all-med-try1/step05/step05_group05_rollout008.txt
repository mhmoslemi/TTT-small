  Contribution was: h[i]*(1-h[i+ℓ]) = 1*(1-h[i+ℓ]) = 1-h[i+ℓ]
  After change: 0*(1-h[i+ℓ]) = 0
  So we subtract (1-h[i+ℓ]) from g_ℓ for ℓ in [-i, n-1-i]

- Terms where h[i] is the "second" factor: ℓ such that 0 ≤ i-ℓ < n, i.e., i-n+1 ≤ ℓ ≤ i
  Contribution was: h[i-ℓ]*(1-h[i]) = h[i-ℓ]*0 = 0
  After change: h[i-ℓ]*(1-0) = h[i-ℓ]
  So we add h[i-ℓ] to g_ℓ for ℓ in [i-n+1, i]

Changing h[j] from 0 to 1:
- Terms where h[j] is the "first" factor: ℓ in [-j, n-1-j]
  Contribution was: 0*(1-h[j+ℓ]) = 0
  After change: 1*(1-h[j+ℓ]) = 1-h[j+ℓ]
  So we add (1-h[j+ℓ]) to g_ℓ for ℓ in [-j, n-1-j]

- Terms where h[j] is the "second" factor: ℓ in [j-n+1, j]
  Contribution was: h[j-ℓ]*(1-0) = h[j-ℓ]
  After change: h[j-ℓ]*(1-1) = 0
  So we subtract h[j-ℓ] from g_ℓ for ℓ in [j-n+1, j]

Total change in g_ℓ for a swap (i: 1→0, j: 0→1):
Δg_ℓ = -(1-h[i+ℓ])*[ℓ∈[-i, n-1-i]] + h[i-ℓ]*[ℓ∈[i-n+1, i]] + (1-h[j+ℓ])*[ℓ∈[-j, n-1-j]] - h[j-ℓ]*[ℓ∈[j-n+1, j]]

This is a sum of at most 4 terms for each ℓ, and we can compute it for all ℓ in O(n) time.

So for each swap (i,j), we can compute Δg_ℓ for all ℓ in O(n). Then the new max is max_ℓ (g_ℓ + Δg_ℓ). Finding the new max takes O(n).

So one swap evaluation is O(n). A full sweep over all n²/4 ≈ 2500 swaps (for n=200) is O(n³) = 8 million. In practice with numpy, this should be fast.

But we can do better: we don't need to try all swaps. We can use a greedy approach:
1. Find the lag k* with maximum g
2. Try to reduce g_{k*} by swapping
3. For lag k*, the change is Δg_{k*} = -(1-h[i+k*])*[k*∈[-i,n-1-i]] + h[i-k*]*[k*∈[i-n+1,i]] + (1-h[j+k*])*[k*∈[-j,n-1-j]] - h[j-k*]*[k*∈[j-n+1,j]]

To reduce g_{k*}, we want Δg_{k*} < 0, i.e., we want to remove (1,0) pairs at lag k*.

For lag k* > 0: the (1,0) pairs are at positions (i, i+k*) where h[i]=1, h[i+k*]=0.
To remove one: either change h[i] from 1 to 0 (and change some h[j] from 0 to 1), or change h[i+k*] from 0 to 1 (and change some h[j] from 1 to 0).

Strategy: 
- Find a position i where h[i]=1 and h[i+k*]=0
- Change h[i] to 0 (removing this (1,0) pair)
- Find a position j where h[j]=0 and the change to h[j]=1 doesn't create too many new (1,0) pairs at the maximum lag

This is essentially what the local search does.

**Key optimization**: Instead of recomputing the full correlation for each swap, precompute the effect of each swap on the correlation vector.

For a binary sequence, swapping i (1→0) and j (0→1) changes g by:
Δg[ℓ] = -(1-h_b[i+ℓ])*[valid] + h_b[i-ℓ]*[valid] + (1-h_b[j+ℓ])*[valid] - h_b[j-ℓ]*[valid]

    if best_h is not None and time.time() < deadline - 20:
        h_cont = best_h.astype(float)
        # Light SLSQP

        if c_polished < best_c:
            best_c = c_polished
            best_h = h_polished
    
    # Ensure feasibility
    best_h = project_feasible(best_h, best_n)
    best_c = compute_c5(best_h, best_n)
    
    return best_h, best_c, best_n

import numpy as np

import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full') * dx))

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)

def make_binary(h, n):
    target = n // 2
    idx = np.argsort(-h)
    h_b = np.zeros(n)
    h_b[idx[:target]] = 1.0
    return h_b

def raw_max(h, n):
    return int(np.max(np.correlate(h, 1.0 - h, mode='full')))

def ls_binary(h, n, deadline, seed=0):

                    break

            h[i] = 1.0

        if not improved:
