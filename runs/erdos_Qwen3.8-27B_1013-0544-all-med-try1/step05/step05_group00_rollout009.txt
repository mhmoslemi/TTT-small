So for a given m, the total delta is the sum of the applicable cases.

Now, the key insight: for a fixed pair (a,b), which m values give non-zero delta?

- From n=a case: m ∈ [a-n+1, a] (where a-m is valid)
- From n=b case: m ∈ [b-n+1, b]
- From n=a+m case: m ∈ [-a, n-1-a]
- From n=b+m case: m ∈ [-b, n-1-b]

The union of these ranges is at most 4 intervals. For a typical (a,b) pair, the union covers most of the range [-(n-1), n-1].

So the delta is non-zero for O(n) values of m. This means we can't avoid O(n) work per swap.

    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14: break

            s = h.sum()
            if s < 1e-14: break
            h += diff / s * h

                # j term (h[j] changes 1->0): affects lags m where j-m is valid

                m_end = min(j, n-1)

                    vals = h[idx]
                    vals[idx == i] = 0.0

                    vals = h[idx]

                    vals[idx == i] = 0.0

                    ones.add(i)
                    zeros.discard(i)
                    zeros.add(j)
                    improved = True
                    break
            if improved:
                break
        if not improved:
            break
