  Similarly for h[j]: -(1-h[j+l])*dx + h[j-l]*dx.

So the general formula for c_k (coefficient of delta in g(k) for the swap h[i]+=delta, h[j]-=delta) is:

c_k = dx * [(1-h[i+l])*1_{0<=i+l<n} - h[i-l]*1_{0<=i-l<n} - (1-h[j+l])*1_{0<=j+l<n} + h[j-l]*1_{0<=j-l<n}]

where l = k-(n-1).

This is correct for all l including l=0. Let me verify with l=0:
c_k = dx * [(1-h[i]) - h[i] - (1-h[j]) + h[j]] = dx * [1-2h[i] - 1+2h[j]] = dx * 2*(h[j]-h[i])

And indeed, if h[i] > h[j], then c_k < 0 for the central lag, meaning increasing h[i] and decreasing h[j] will decrease g(0). That makes sense.

OK so the formula is correct. Now for the 1D optimization:

f(delta) = max_k (g[k] + delta * c[k])

I want to minimize this over delta in [dmin, dmax] where:
dmin = max(-h[i], h[j]-1) = max(-h[i], h[j]-1)
dmax = min(1-h[i], h[j])

Since f is convex (max of linear functions), I can use minimize_scalar with method='bounded'.

Let me code the 2-coordinate search:

```python
def two_coord_search(h, n, deadline, max_pairs=5000):
    dx = 2.0 / n
    best_c = compute_c5(h, n)
    g = np.correlate(h, 1 - h, mode='full') * dx
    
    # Identify promising pairs: i where h[i] is high, j where h[j] is low
    high_idx = np.where(h > 0.5)[0]
    low_idx = np.where(h < 0.5)[0]
    
    # Try pairs
    pairs_tried = 0
    n_high = len(high_idx)
    n_low = len(low_idx)
    
    for _ in range(max_pairs):
        if time.time() > deadline:
            break
        i = high_idx[np.random.randint(n_high)]  # Hmm, but we need reproducibility
        j = low_idx[np.random.randint(n_low)]
        if i == j:
            continue
        
        # Compute c
        lags = np.arange(-(n-1), n)  # l = k - (n-1) for k in 0..2n-2
        c = np.zeros(2*n-1)
        for k in range(2*n-1):
            l = k - (n-1)
            ck = 0.0
            if 0 <= i+l < n:
                ck += (1.0 - h[i+l])
            if 0 <= i-l < n:
                ck -= h[i-l]
            if 0 <= j+l < n:
                ck -= (1.0 - h[j+l])
            if 0 <= j-l < n:
                ck += h[j-l]
            c[k] = ck * dx
        
        dmin = max(-h[i], h[j] - 1.0)
        dmax = min(1.0 - h[i], h[j])
        if dmax - dmin < 1e-12:
            continue
        
        def f1d(delta):
            return np.max(g + delta * c)
        
        res = minimize_scalar(f1d, bounds=(dmin, dmax), method='bounded',
                            options={'maxiter': 50})
        if res.fun < best_c - 1e-12:
            h[i] += res.x
            h[j] -= res.x
            h = project_feasible(h, n)
            best_c = compute_c5(h, n)
            g = np.correlate(h, 1 - h, mode='full') * dx
            # Update high/low
            high_idx = np.where(h > 0.5)[0]
            low_idx = np.where(h < 0.5)[0]
            n_high = len(high_idx)
            n_low = len(low_idx)
            if n_high == 0 or n_low == 0:
                break
        pairs_tried += 1
    
    return h, best_c
```

Wait, but the inner loop over k (2n-1 = 499 iterations) for computing c is slow in pure Python. Let me vectorize it.

Actually, I can compute c more efficiently:
c[k] = dx * [(1-h[i+l]) - h[i-l] - (1-h[j+l]) + h[j-l]] (with valid indicators)

Let me define:
- term_i_plus[k] = (1-h[i+l])*1_{valid} for l = k-(n-1)
- term_i_minus[k] = h[i-l]*1_{valid} for l = k-(n-1)
- etc.

For term_i_plus: l = k-(n-1), so i+l = i+k-(n-1). This is valid when 0 <= i+k-(n-1) < n, i.e., n-1-i <= k <= n-1-i+n-1 = 2n-2-i.
So term_i_plus is nonzero for k in [max(0, n-1-i), min(2n-2, 2n-2-i)].

I can construct c as:
```python
def compute_swap_coeff(h, n, i, j):
    dx = 2.0 / n
    c = np.zeros(2*n-1)
    l = np.arange(-(n-1), n)  # lag offsets
    
    # (1-h[i+l]) for valid i+l
    mask_i_plus = (i + l >= 0) & (i + l < n)
    c[mask_i_plus] += (1.0 - h[i + l[mask_i_plus]])
    
    # -h[i-l] for valid i-l
    mask_i_minus = (i - l >= 0) & (i - l < n)
    c[mask_i_minus] -= h[i - l[mask_i_minus]]
    
    # -(1-h[j+l]) for valid j+l
    mask_j_plus = (j + l >= 0) & (j + l < n)
    c[mask_j_plus] -= (1.0 - h[j + l[mask_j_plus]])
    
    # +h[j-l] for valid j-l
    mask_j_minus = (j - l >= 0) & (j - l < n)
    c[mask_j_minus] += h[j - l[mask_j_minus]]
    
    c *= dx
    return c
```

This is fully vectorized and fast!

Now, for the minimize_scalar call, the function f1d(delta) = max(g + delta * c) is O(n) to evaluate. With 50 iterations of bounded golden section, that's 50 * O(n) ≈ 25K operations per pair. With a few thousand pairs, that's ~50M-150M operations. Should be doable in a few seconds.

Let me also think about whether there's a smarter way to do the 2-coordinate search. Instead of random pairs, I can:
- For each i with h[i] > 0.5, find the best j with h[j] < 0.5
- This is still O(n²) pairs, but I can be selective

Or even better: I can compute for each pair (i,j) the "potential improvement" without doing the full 1D optimization, and only do the 1D search for the most promising pairs.

The potential improvement for pair (i,j) is approximately:
If the current max is at lag k*, then the improvement is approximately:
delta * c_{k*} (if c_{k*} < 0, meaning the swap helps at the active lag)
where delta is the maximum feasible step.

So I can rank pairs by c_{k*} * feasible_delta and only optimize the top ones.

Let me implement this:

```python
def two_coord_search_v2(h, n, deadline, rng):
    dx = 2.0 / n
    best_c = compute_c5(h, n)
    g = np.correlate(h, 1 - h, mode='full') * dx
    k_star = int(np.argmax(g))
    
    high_idx = np.where(h > 0.3)[0]
    low_idx = np.where(h < 0.7)[0]
    
    # Compute c_{k_star} for all pairs efficiently
    # c_{k*} for swap (i,j) = dx * [(1-h[i+l*]) - h[i-l*] - (1-h[j+l*]) + h[j-l*]] (with indicators)
    # where l* = k_star - (n-1)
    l_star = k_star - (n - 1)
    
    # For each i: contrib_i = (1-h[i+l*])*1_{valid} - h[i-l*]*1_{valid}
    # For each j: contrib_j = -(1-h[j+l*])*1_{valid} + h[j-l*]*1_{valid}
    # c_{k*}(i,j) = dx * (contrib_i(i) + contrib_j(j))
    
    contrib_i = np.zeros(n)
    mask = (np.arange(n) + l_star >= 0) & (np.arange(n) + l_star < n)
    contrib_i[mask] += (1.0 - h[np.arange(n)[mask] + l_star])
    mask2 = (np.arange(n) - l_star >= 0) & (np.arange(n) - l_star < n)
    contrib_i[mask2] -= h[np.arange(n)[mask2] - l_star]
    
    contrib_j = np.zeros(n)
    mask = (np.arange(n) + l_star >= 0) & (np.arange(n) + l_star < n)
    contrib_j[mask] -= (1.0 - h[np.arange(n)[mask] + l_star])
    mask2 = (np.arange(n) - l_star >= 0) & (np.arange(n) - l_star < n)
    contrib_j[mask2] += h[np.arange(n)[mask2] - l_star]
    
    # c_{k*}(i,j) = dx * (contrib_i[i] + contrib_j[j])
    # We want this to be negative (to decrease g[k*])
    # Score for pair (i,j): c_{k*} * feasible_delta (more negative = better)
    
    # For each i, the best j is the one that minimizes c_{k*}(i,j) * delta_max
    # This is approximately: dx * (contrib_i[i] + min_j contrib_j[j]) * feasible_delta
    
    # Simplified: just try the most promising pairs
    # Score_i = contrib_i[i], Score_j = contrib_j[j]
    # c_{k*}(i,j) ≈ dx * (Score_i + Score_j)
    # Want Score_i + Score_j to be very negative
    
    n_high = len(high_idx)
    n_low = len(low_idx)
    
    # Sort by score
    high_scores = contrib_i[high_idx]
    low_scores = contrib_j[low_idx]
    high_order = np.argsort(high_scores)  # most negative first
    low_order = np.argsort(low_scores)
    
    best_c = compute_c5(h, n)
    improved = True
    while improved and time.time() < deadline:
        improved = False
        for _ in range(500):
            if time.time() > deadline:
                break
            # Pick a random pair from the top-scored
            hi = high_idx[high_order[np.random.randint(min(50, n_high))]]
            lo = low_idx[low_order[np.random.randint(min(50, n_low))]]
            if hi == lo:
                continue
            
            c_full = compute_swap_coeff(h, n, hi, lo)
            dmin = max(-h[hi], h[lo] - 1.0)
            dmax = min(1.0 - h[hi], h[lo])
            if dmax - dmin < 1e-12:
                continue
            
            # 1D optimization
            res = minimize_scalar(lambda d: np.max(g + d * c_full),
                                  bounds=(dmin, dmax), method='bounded',
                                  options={'maxiter': 30})
            if res.fun < best_c - 1e-12:
                h[hi] += res.x
                h[lo] -= res.x
                h = project_feasible(h, n)
                best_c = compute_c5(h, n)
                g = np.correlate(h, 1 - h, mode='full') * dx
                k_star = int(np.argmax(g))
                # Recompute scores
                l_star = k_star - (n - 1)
                idx = np.arange(n)
                contrib_i = np.zeros(n)
                mask = (idx + l_star >= 0) & (idx + l_star < n)
                contrib_i[mask] += (1.0 - h[idx[mask] + l_star])
                mask2 = (idx -
