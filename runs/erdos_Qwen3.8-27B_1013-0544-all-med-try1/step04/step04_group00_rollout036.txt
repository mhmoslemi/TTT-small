So the question is: which 0-position i and 1-position j give the best improvement?

For a specific lag L where c is max:
- We want to reduce the number of (i, i-L) pairs where h[i]=1, h[i-L]=0
- If we set h[i]=1 (was 0) and h[j]=0 (was 1):
  - We gain a 1 at i: this ADDS a 1-0 pair at (i, i-L) if h[i-L]=0, or removes one if h[i-L]=1
  - We lose a 1 at j: this REMOVES a 1-0 pair at (j, j-L) if h[j-L]=0, or adds one if h[j-L]=1

So the net change for lag L is:
Δ = (h[i-L]==0 ? +1 : -1) + (h[j-L]==0 ? -1 : +1)

To maximize the decrease (most negative Δ):
- We want h[i-L]=0 (so +1, bad) → actually we want h[i-L]=1 (so -1, good, it removes a pair)
- We want h[j-L]=0 (so -1, good, it removes a pair)

So the best swap for reducing lag L is:
- i: a 0-position where h[i-L]=1 (setting it to 1 will "fix" a 0-1 pair to 1-1)
- j: a 1-position where h[j-L]=0 (setting it to 0 will "fix" a 1-0 pair to 0-0)

If both exist, Δ = -1 + (-1) = -2 (reduces c by 2).

But we also need to check the effect on OTHER lags! This is where it gets tricky.

**Practical algorithm:**

1. Start with a binary solution (round the initial_h_values to binary)
2. Compute full correlation
3. For the top K lags (say K=10), for each:
   a. Find candidate (i,j) swaps that reduce this lag by 2
   b. For each candidate, compute the full new correlation (fast for n=250)
   c. Accept if the new max is lower
4. Repeat until no improvement
5. Also try single-lag improvements (Δ=-1) if no Δ=-2 available

This is O(K * n * n) per iteration in the worst case, but in practice much less.

Let me also add:
- **Continuous refinement**: After binary local search, use the binary solution as starting point for SLSQP
- **Multiple resolutions**: Try n=100, 150, 200, 250, 300
- **Random restarts**: Perturb the binary solution and re-run

Now let me also think about the continuous problem differently.

**Key insight**: The problem is equivalent to finding h that minimizes the L∞ norm of the "cross-correlation" of h with (1-h). This is related to the theory of "biperiodic" or "two-shift" problems.

Another approach: **Iterative water-filling / projection**

1. Start with h0 = 0.5 everywhere (sum = n*0.5 = n/2, feasible)
2. Compute g_k for all k
3. Find k* = argmax g_k
4. Adjust h to reduce g_k*: this is like a "push" in the direction that reduces g_k*
   - ∂g_k*/∂h[m] = dx * [(1-h[m-L*]) - h[m+L*]] (approximately, ignoring boundary effects)
   - So we decrease h where the gradient is positive and increase where negative
   - But we must maintain 0 ≤ h ≤ 1 and sum = n/2
5. Repeat

This is essentially what subgradient descent does, but the "projection" step can be done more carefully.

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def compute_all_g(h, n):

    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(100):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h += diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h += diff / s * h
    return np.clip(h, 0.0, 1.0)

    """Nesterov-accelerated projected subgradient method."""
    best_h = h.copy()
    best_c = compute_c5(h, n)
    y = h.copy()
    v = np.zeros(n)
    t_val = 1.0
    
    for it in range(max_iter):
        if time.time() > deadline:
            break
        # Nesterov step
        t_next = 1 + np.sqrt(1 + 4 * t_val * t_val) / 2
        beta = (t_val - 1) / t_next
        y = h + beta * (h - y)
        
        # Compute subgradient of max at y
        g = compute_all_g(y, n)
        m = g.max()
        p_max = int(np.argmax(g))
        L = p_max - (n - 1)
        
        # Gradient of g_k at y for the maximizer k
        dx = 2.0 / n
        grad = np.zeros(n)
        for i in range(n):
            # ∂g_k/∂h[i] = dx * [(1-y[i-L]) if i-L in range + (-y[i+L]) if i+L in range]
            contrib = 0.0
            il = i - L
            if 0 <= il < n:
                contrib += (1 - y[il])
            ipl = i + L
            if 0 <= ipl < n:
                contrib += (-y[ipl])
            grad[i] = dx * contrib

        step = 2.0 / (1 + t_next)  # Polyak-like
        h_new = y - step * grad

        c = compute_c5(h_new, n)
        if c < best_c:
            best_c = c
            best_h = h_new.copy()
        
        h = h_new
        t_val = t_next
    
    return best_h, best_c

Wait, I need to be more careful. g_k(x) = sum_i x[i] * (1-x[i-k]) * dx where the sum is over valid i (both i and i-k in [0,n)).

∂g_k/∂x[m]:
- If m appears as i in the sum: term is (1-x[m-k]) * dx (if m-k is valid)
- If m appears as i-k in the sum (i.e., i = m+k): term is x[m+k] * (-1) * dx (if m+k is valid)

So ∂g_k/∂x[m] = dx * [(1-x[m-k]) * I(0≤m-k<n) + (-x[m+k]) * I(0≤m+k<n)]

This is correct.

For the log-sum-exp term:
L(x) = (1/alpha) * log(sum_k exp(alpha * g_k(x) - alpha * M)) where M = max g_k
= (1/alpha) * log(sum_k exp(alpha * (g_k(x) - M)))

∂L/∂x[m] = (1/alpha) * sum_k exp(alpha*(g_k-M)) * alpha * ∂g_k/∂x[m] / sum_k exp(alpha*(g_k-M))
= sum_k w_k * ∂g_k/∂x[m] where w_k = exp(alpha*(g_k-M)) / sum_j exp(alpha*(g_j-M))

So the full gradient is:
∂f/∂x[m] = ∂g_{k*}/∂x[m] + sum_k w_k * ∂g_k/∂x[m]

where k* = argmax g_k.

This can be computed in O(n²) time (for each m, sum over k of w_k * grad_k[m]).

def slsqp_obj_grad(x, n, alpha):
    dx = 2.0 / n
    g = np.correlate(x, 1 - x, mode='full') * dx
    M = g.max()
    
    # Log-sum-exp weights
    shifted = alpha * (g - M)
    sm = shifted.max()
    weights = np.exp(shifted - sm)
    weights /= weights.sum()
    
    # Gradient of f = g_max + LSE/alpha
    num_lags = len(g)
    # For each lag k (0 to 2n-2), the actual shift is L = k - (n-1)
    # grad_k[m] = dx * [(1-x[m-L]) * I(0<=m-L<n) + (-x[m+L]) * I(0<=m+L<n)]
    
    grad = np.zeros(n)
    for k_idx in range(num_lags):
        w = weights[k_idx]
        if w < 1e-10:
            continue
        L = k_idx - (n - 1)
        # For each m:
        # Term 1: (1-x[m-L]) if 0 <= m-L < n
        # Term 2: -x[m+L] if 0 <= m+L < n
        for m in range(n):
            val = 0.0
            ml = m - L
            if 0 <= ml < n:
                val += (1 - x[ml])
            mpl = m + L
            if 0 <= mpl < n:
                val += (-x[mpl])
            grad[m] += w * dx * val
    
    # Add gradient of max (subgradient)
    k_star = int(np.argmax(g))
    L_star = k_star - (n - 1)
    for m in range(n):
        val = 0.0
        ml = m - L_star
        if 0 <= ml < n:
            val += (1 - x[ml])
        mpl = m + L_star

For a fixed L:

```python
def compute_grad_all_lags(x, n):
    """Compute grad_k[m] for all k and m. Returns array of shape (2n-1, n)."""
    dx = 2.0 / n
    num_lags = 2 * n - 1
    all_grads = np.zeros((num_lags, n))
    for k_idx in range(num_lags):
        L = k_idx - (n - 1)
        # Term 1: (1-x[m-L]) for valid m
        m_start1 = max(0, L)
        m_end1 = min(n, n + L)
        if m_end1 > m_start1:
            xs = m_start1 - L  # start index into x
            all_grads[k_idx, m_start1:m_end1] += (1 - x[xs:xs + (m_end1 - m_start1)])
        # Term 2: -x[m+L] for valid m
        m_start2 = max(0, -L)
        m_end2 = min(n, n - L)
        if m_end2 > m_start2:
            xs = m_start2 + L
            all_grads[k_idx, m_start2:m_end2] += (-x[xs:xs + (m_end2 - m_start2)])
    all_grads *= dx
    return all_grads
```

This is O(n²) total (n lags × O(n) per lag). For n=250, that's 62500 operations, very fast.

grad = all_grads.T @ weights  (shape (n,) = (n, 2n-1) @ (2n-1,))

                        break
                    hb[i], hb[j] = 1.0, 0.0
                    c_new = np.correlate(hb, 1 - hb, 'full') * dev
                    cm = c_new.max()
                    if cm < best_c - 1e-13:
                        best_c = cm
                        c = c_new
                        p_max = int(np.argmax(c))
                        ones.remove(j); ones.append(i)
                        zeros.remove(i); zeros.append(j)
                        found = True
                        break
                    else:
                        hb[i], hb[j] = 0.0, 1.0
                    tried += 1
                if found:
                    break
        if not found:
            improved = False
            for _ in range(100):
                if time.time() > deadline:
                    break
                i = zeros[rng.randint(len(zeros))]
                j = ones[rng.randint(len(ones))]
                hb[i], hb[j] = 1.0, 0.0
                c_new = np.correlate(hb, 1 - hb, 'full') * dev
                if c_new.max() < best_c - 1e-13:
                    best_c = c_new.max()
                    c = c_new
                    p_max = int(np.argmax(c))
                    ones.remove(j); ones.append(i)
                    zeros.remove(i); zeros.append(j)
                    improved = True
                else:
                    hb[i], hb[j] = 0.0, 1.0
            if not improved:
                break
    return hb, best_c

def nesterov_subgrad(h, n, deadline, max_iter=15000):
    best_h = h.copy()
    best_c = compute_c5(h, n)
    dx = 2.0 / n
    for it in range(max_iter):
        if time.time() > deadline:
            break
        g = np.correlate(h, 1 - h, 'full') * dx
        m = g.max()
        p_max = int(np.argmax(g))
        L = p_max - (n - 1)
        grad = np.zeros(n)
        for mi in range(n):
            v = 0.0
            ml = mi - L
            if 0 <= ml < n:
                v += (1.0 - h[ml])
            mpl = mi + L
            if 0 <= mpl < n:
                v += (-h[mpl])
            grad[mi] = dx * v
        ng = np.linalg.norm(grad)
        if ng < 1e-14:
            break
        for step in [2.0/ng, 1.0/ng, 0.5/ng, 0.25/ng, 0.1/ng, 0.05/ng]:
            h_new = project_feasible(h - step * grad, n)
            c = compute_c5(h_new, n)
            if c < m:
                h = h_new
                if c < best_c:
                    best_c = c
                    best_h = h.copy()
                break
        else:
            break
    return best_h, best_c

def slsqp_analytic(h, n, alpha, maxiter, deadline):
    dx = 2.0 / n
    num_lags = 2 * n - 1

    def fun_grad(x):
        g = np.correlate(x, 1 - x, 'full') * dx
        M = g.max()
        shifted = alpha * (g - M)
        sm = shifted.max()
        ew = np.exp(shifted - sm)
        ws = ew.sum()
        w = ew / ws
        obj = M + (sm + np.log(ws)) / alpha
        grad_lse = np.zeros(n)
        for ki in range(num_lags):
            wi = w[ki]
            if wi < 1e-12:
                continue
            L = ki - (n - 1)
            s1, e1 = max(0, L), min(n, L + n)
            if e1 > s1:
                grad_lse[s1:e1] += wi * (1.0 - x[s1-L:e1-L])
            s2, e2 = max(0, -L), min(n, n - L)
            if e2 > s2:
                grad_lse[s2:e2] += wi * (-x[s2+L:e2+L])
        grad_lse *= dx
        k_star = int(np.argmax(g))
        Ls = k_star - (n - 1)
        grad_max = np.zeros(n)
        s1, e1 = max(0, Ls), min(n, Ls + n)
        if e1 > s1:
            grad_max[s1:e1] = (1.0 - x[s1-Ls:e1-Ls])
        s2, e2 = max(0, -Ls), min(n, n - Ls)
        if e2 > s2:
            grad_max[s2:e2] += (-x[s2+Ls:e2+Ls])
        grad_max *= dx
        return obj, grad_lse + grad_max

    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x: x.sum() - n/2.0,
             'jac': lambda x: np.ones(n)}]
    try:
        res = minimize(fun_grad, h, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-14})
        return project_feasible(res.x, n)
    except Exception:
        return h

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    dl = t0 + budget_s - 3
    rng = np.random.RandomState(seed)

    try:
        h0 = np.array(initial_h_values, dtype=float).copy()
        n0 = len(h0)
    except Exception:
        n0 = 250
        h0 = np.full(n0, 0.5)

    best_h = h0.copy()
    best_c = compute_c5(best_h, n0)

    # Phase 1: Binary greedy from initial (25% budget)
    p1 = t0 + 0.25 * budget_s
    hb = to_binary(best_h, n0)
    hb, cb = binary_greedy(hb, n0, p1, 60000, seed)
    if cb < best_c:
        best_c = cb
        best_h = hb.copy()

    # Phase 2: SLSQP with analytical grads (30% budget)
    p2 = t0 + 0.55 * budget_s
    h = best_h.copy()
    for alpha in [200, 1000, 5000, 20000, 100000, 500000, 2000000]:
        if time.time() > p2 - 5:
            break
        h = slsqp_analytic(h, n0, alpha, 600, p2 - 5)
        c = compute_c5(h, n0)
        if c < best_c:
            best_c = c
            best_h = h.copy()

    # Phase 3: Nesterov subgradient (10% budget)
    p3 = t0 + 0.65 * budget_s
    hn, cn = nesterov_subgrad(best_h.copy(), n0, p3, 15000)
    if cn < best_c:
        best_c = cn
        best_h = hn.copy()

    # Phase 4: Alternate resolutions (25% budget)
    p4 = t0 + 0.90 * budget_s
    for nh in [150, 200, 300, 400]:
        if time.time() > p4 - 15:
            break
        if nh == n0:
            continue
        xo = np.linspace(0, 2, n0)
        xn = np.linspace(0, 2, nh)
        hh = project_feasible(np.interp(xn, xo, best_h), nh)
        hb2 = to_binary(hh, nh)
        hb2, cb2 = binary_greedy(hb2, nh, p4 - 15, 20000, seed + 1)
        h2 = slsqp_analytic(hb2, nh, 5000, 400, p4 - 15)
        c2 = compute_c5(h2, nh)
        if c2 < best_c:
            best_c = c2
            best_h = h2.copy()
            n0 = nh

    # Phase 5: Thue-Morse start + binary (5% budget)
    if time.time() < dl - 10:
        tm = thue_morse_h(n0)
        hb3, cb3 = binary_greedy(tm, n0, dl - 5, 20000, seed + 7)
        if cb3 < best_c:
            h3 = slsqp_analytic(hb3, n0, 10000, 300, dl - 5)
            c3 = compute_c5(h3, n0)
            if c3 < best_c:
                best_c = c3
                best_h = h3.copy()
            elif cb3 < best_c:
                best_c = cb3
                best_h = hb3.copy()

    # Final polish
    if time.time() < dl - 2:
        h = slsqp_analytic(best_h.copy(), n0, 5000000, 200, dl - 2)
        c = compute_c5(h, n0)
        if c < best_c:
            best_c = c
            best_h = h.copy()

    best_h = project_feasible(best_h, n0)
    best_c = compute_c5(best_h, n0)
    return best_h, best_c, n0
