**Revised algorithm:**

```python
def pair_descent(h, n, max_sweeps, deadline, rng):
    dx = 2.0 / n
    c0 = np.correlate(h, 1-h, mode='full')
    c5_best = float(np.max(c0) * dx)
    
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        improved = False
        # Try pairs in a random or cyclic order
        order = list(range(n))
        rng.shuffle(order)
        for idx_j in range(n):
            j = order[idx_j]
            if time.time() > deadline:
                break
            # Try a few random l's
            for _ in range(5):  # try 5 random partners
                l = rng.randint(n)
                if l == j:
                    continue
                
                # Compute V, W for this pair
                v = 1 - h
                cv_j = np.zeros(2*n-1)
                cv_j[j:j+n] = v[::-1]
                cv_l = np.zeros(2*n-1)
                cv_l[l:l+n] = v[::-1]
                ch_j = np.zeros(2*n-1)
                ch_j[n-1-j:n-1-j+n] = h
                ch_l = np.zeros(2*n-1)
                ch_l[n-1-l:n-1-l+n] = h
                V = (cv_j - cv_l) - (ch_j - ch_l)
                
                W = np.zeros(2*n-1)
                W[n-1] = 2
                W[j-l+n-1] -= 1
                W[l-j+n-1] -= 1
                
                # Valid range for d
                d_min = max(-h[j], h[l] - 1.0)
                d_max = min(1.0 - h[j], h[l])
                if d_max <= d_min:
                    continue
                
                # Ternary search for optimal d
                a, b = d_min, d_max
                for _ in range(50):
                    m1 = a + (b-a)/3
                    m2 = b - (b-a)/3
                    # c_new(d) = c0 + d*V - d^2*W
                    c_m1 = np.max(c0 + m1*V - m1*m1*W) * dx
                    c_m2 = np.max(c0 + m2*V - m2*m2*W) * dx
                    if c_m1 < c_m2:
                        b = m2
                    else:
                        a = m1
                d_opt = (a+b)/2
                
                # Check if this improves
                c_new = np.max(c0 + d_opt*V - d_opt*d_opt*W) * dx
                if c_new < c5_best - 1e-12:
                    # Apply the update
                    h[j] += d_opt
                    h[l] -= d_opt
                    c0 = c0 + d_opt*V - d_opt*d_opt*W
                    c5_best = c_new
                    improved = True
        
        if not improved:
            break
    
    return h, c5_best
```

This is still O(n) but avoids the zero-array creation.

This is O(n) with very little overhead.

Let me also think about the **W** computation. W is fixed for a given pair (j,l) and doesn't depend on h:
W[n-1] = 2
W[j-l+n-1] -= 1 (if 0 ≤ j-l+n-1 < 2n-1)
W[l-j+n-1] -= 1 (if 0 ≤ l-j+n-1 < 2n-1)

Note that j-l+n-1 = n-1+j-l and l-j+n-1 = n-1+l-j.

So W has at most 3 non-zero entries. I can represent it sparsely.

result = np.max(temp)
