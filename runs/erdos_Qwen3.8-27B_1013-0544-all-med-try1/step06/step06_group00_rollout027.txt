and B[j,k] = -1 if lag_k = 0, else 0 (from the quadratic term)

Wait, for lag ≠ 0: Δcorr[k] = dv * [(1-h[j+lag_k]) + h[j-lag_k]]
For lag = 0: Δcorr[k] = dv * (1 - v_old - v_new) = dv - (v_new² - v_old²)

So for lag ≠ 0, it's linear in dv. For lag = 0, it's quadratic.

If I precompute A[j, :] for each j, I can vectorize the coordinate descent.

def smooth_obj_and_grad(h, temp):

    dx = 2.0 / n
    corr = compute_corr(h)
    m = np.max(corr)
    # Log-sum-exp for stability
    shifted = corr - m
    log_sum = np.log(np.exp(temp * shifted).sum())
    obj = (m + log_sum / temp) * dx

    # = dx * (1/temp) * sum_k exp(temp*(corr_k - m)) / sum_k' exp(temp*(corr_k' - m)) * d(corr_k)/d(h_j)
    # Let w_k = exp(temp*(corr_k - m)) / sum(exp(temp*(corr_corr - m)))
    # Then grad_j = dx * (1/temp) * sum_k w_k * d(corr_k)/d(h_j)
    
    weights = np.exp(temp * shifted)
    weights /= weights.sum()

    # corr_k = sum_i h[i]*(1-h[i+lag_k]), lag_k = k-(n-1)
    # d(corr_k)/d(h_j) = (1-h[j+lag_k])*(j+lag_k valid) + h[j-lag_k]*(j-lag_k valid) [for lag≠0]
    #                    = (1-2*h[j]) [for lag=0]
    
    # Vectorized: for each lag, compute the gradient contribution
    # grad = sum_k weights[k] * d(corr_k)/d(h_j)
    
    # Let's compute this by iterating over unique lags
    # For a given lag L:
    #   Contribution to grad[j] = weights[k] * [(1-h[j+L])*(valid) + h[j-L]*(valid)]
    #   where k = n-1+L
    
    lags = np.arange(-(n-1), n)
    # weights indexed by lag: w_L = weights[n-1+L]
    w = weights  # already indexed the same way as lags
    
    grad = np.zeros(n)
    for L in range(-(n-1), n):
        wL = w[n-1+L]
        if wL < 1e-15:
            continue
        if L == 0:
            grad += wL * (1.0 - 2.0 * h)
        else:

            lo1 = max(0, -L)
            hi1 = min(n, n - L)
            grad[lo1:hi1] += wL * (1.0 - h[lo1+L:hi1+L])

            lo2 = max(0, L)
            hi2 = min(n, n + L)
            grad[lo2:hi2] += wL * h[lo2-L:hi2-L]
    
    grad *= dx / temp
    return obj, grad

            # For lag=0: delta = dv*(1-v_old-v_new)

            # For lag=0: A[lag=0] = 1 - 2*v_old (and there's a quadratic term -dv²)

            A = np.zeros(2*n-1)
            
            for L in range(-(n-1), n):
                k_idx = n - 1 + L
                if L == 0:
                    # Special case
                    continue
                ip = j + L
                im = j - L
                val = 0.0
                if 0 <= ip < n:
                    val += (1.0 - h[ip])
                if 0 <= im < n:
                    val += h[im]
                A[k_idx] = val

            # Let's use: delta_0 = dv - dv*(v_old + v_new) = dv*(1 - v_old - v_new)

            # corr_trial[k0] = corr[k0] + dvs[k] * (1 - v_old - trial_vals[k])
            
            # Vectorized computation of max

            corr_trial[:] = corr[np.newaxis, :]
            corr_trial += dvs[:, np.newaxis] * A[np.newaxis, :]
            # Fix the lag=0 entry
            corr_trial[:, k0] = corr[k0] + dvs * (1.0 - v_old - trial_vals)
            
            max_trial = np.max(corr_trial, axis=1)
            best_idx = np.argmin(max_trial)

                corr = corr_trial[best_idx].copy()
                # Update h[j] in A for future use (not needed since we recompute A each j)
                did_improve = True

        corr = compute_corr(h)
        c5 = np.max(corr) * dx
        
        if c5 < best_c5:
            best_c5 = c5
            best_h = h.copy()
        
        if not did_improve:
            break
    
    return best_h, best_c5

Actually, one more idea: **What if I use the fact that the problem has a specific structure?**

The correlation corr[k] = sum_i h[i]*(1-h[i+lag_k]) can be written as:
corr[k] = sum_i h[i] - sum_i h[i]*h[i+lag_k]

The first term is constant (= n/2) due to the constraint. So:
corr[k] = n/2 - sum_i h[i]*h[i+lag_k]

We want to minimize max_k corr[k] = n/2 - min_k sum_i h[i]*h[i+lag_k]

So we want to MAXIMIZE min_k autocorr_k where autocorr_k = sum_i h[i]*h[i+lag_k].

This is a "maximin" problem. The ideal would be to make all autocorr_k equal (flat autocorrelation), which is related to "low autocorrelation sequences" in radar/communications.

But we have the constraint 0 ≤ h ≤ 1 and sum(h) = n/2, which makes it different from the standard problem of finding binary sequences with low autocorrelation.

One approach: use the " flattening " idea. If I can make the autocorrelation as flat as possible (all lag values give the same autocorrelation), then the max overlap is minimized.

For a random function with mean 1/2 and values in [0,1]:
E[h[i]*(1-h[i+lag])] ≈ 1/4 (for lag ≠ 0) and E[h[i]*(1-h[i])] = E[h[i]] - E[h[i]²]

For h ~ Uniform[0,1]: E[h²] = 1/3, so E[h(1-h)] = 1/2 - 1/3 = 1/6.
For h ∈ {0, 1/2, 1} equally likely: E[h²] = (0 + 1/4 + 1)/3 = 5/12, E[h(1-h)] = 1/2 - 5/12 = 1/12.
