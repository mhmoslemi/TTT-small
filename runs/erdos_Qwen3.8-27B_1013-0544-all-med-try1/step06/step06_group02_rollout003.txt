1. Computing the subgradient at h[i]=0 and h[i]=1
2. If the subgradient at 0 is positive (all active gradients > 0), the optimum is at h[i]=0
3. If the subgradient at 1 is negative (all active gradients < 0), the optimum is at h[i]=1
4. Otherwise, the optimum is at a kink where two active functions cross

But with the sum constraint, we can't just set one coordinate independently. We need to maintain sum(h) = N/2.

One approach: "transfer" mass between coordinates. Pick two coordinates i and j, and transfer mass δ from i to j (h[i] -= δ, h[j] += δ). The sum is preserved. We can optimize over δ for each pair.

For a pair (i, j) and transfer δ:
- h[i] → h[i] - δ
- h[j] → h[j] + δ
- Constraint: 0 ≤ h[i]-δ and h[j]+δ ≤ 1, so δ ∈ [h[i]-1, min(h[i], 1-h[j])]

The objective as a function of δ is max_k (linear in δ), so it's convex in δ. We can find the minimum by checking:
- The endpoints
- The kink points (where two active lags cross)

For a specific lag k, the change in corr[k] when we transfer δ from i to j is:
- corr[k] changes by: -δ * coeff_k[i] + δ * coeff_k[j] = δ * (coeff_k[j] - coeff_k[i])
- where coeff_k[i] = d(corr[k])/d(h[i])

So for each lag k, the new value is corr[k] + δ * d_k where d_k = coeff_k[j] - coeff_k[i].

The objective is max_k (corr[k] + δ * d_k), which is a max of linear functions in δ.

To find the minimum:
1. Sort the d_k values
2. The max function changes its "active" lag at breakpoints δ* = (corr[a] - corr[b]) / (d_b - d_a)
3. The minimum is at one of these breakpoints or at the constraint boundaries

import numpy as np
import time

def project_feasible(v, N):
    target = N / 2.0
    lo, hi = -3.0, 3.0
    for _ in range(70):
        mid = (lo + hi) / 2.0
        if np.clip(v - mid, 0.0, 1.0).sum() > target:
            lo = mid
        else:
            hi = mid
    lam = (lo + hi) / 2.0
    h = np.clip(v - lam, 0.0, 1.0)
    diff = target - h.sum()
    if abs(diff) > 1e-10:
        mask = (h > 1e-12) & (h < 1.0 - 1e-12)
        if mask.sum() > 0:
            h[mask] += diff / mask.sum()
            h = np.clip(h, 0.0, 1.0)
    return h

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def c5_value(corr, N):
    return corr.max() * 2.0 / N

def grad_for_lag(h, lag, N):
    g = np.zeros(N)
    if lag >= 0:
        if lag < N:
            g[:N-lag] += 1.0 - h[lag:]
            g[lag:] -= h[:N-lag]
    else:
        m = -lag
        if m < N:
            g[m:] += 1.0 - h[:-m]
            g[:-m] -= h[m:]
    return g

def weighted_topk_gradient(h, corr, k, r=0.7):
    N = len(h)
    top_idx = np.argsort(corr)[-k:]
    weights = r ** np.arange(k)
    weights /= weights.sum()
    g = np.zeros(N)
    for w, j in zip(weights, top_idx):
        lag = j - (N - 1)
        g += w * grad_for_lag(h, lag, N)
    return g

def interpolate_h(h_src, n_dst):

    x_dst = np.arange(n_dst) / float(n_dst)
    h_dst = np.interp(x_dst, x_src, h_src)
    return project_feasible(h_dst, n_dst)
