For the continuous case, the objective is max_k ∑h[i](1-h[i+k])dx. If we set h[i] = 1/2 + ε_i where |ε_i| ≤ 1/2, then:
h[i](1-h[i+k]) = (1/2+ε_i)(1/2-ε_{i+k}) = 1/4 - ε_{i+k}/2 + ε_i/2 - ε_i ε_{i+k}

So f_k = ∑(1/4 - ε_{i+k}/2 + ε_i/2 - ε_i ε_{i+k})dx
= (n-k)/4 * dx - (dx/2)∑(ε_{i+k} - ε_i) - dx * ∑ε_i ε_{i+k}

The linear term ∑(ε_{i+k} - ε_i) telescopes partially... not exactly, because the sums are over different ranges. But roughly, if ε is "smooth" (slowly varying), this term is small.

The key term is -∑ε_i ε_{i+k}, which is the autocorrelation of ε. To minimize f_k, we want ∑ε_i ε_{i+k} to be large (positive autocorrelation). But we want this for ALL k simultaneously.

If ε is a sum of sinusoids at incommensurate frequencies, the autocorrelation is a sum of cosines at those frequencies, and the max over k can be kept low.

This suggests that a "blue noise" type pattern (high-frequency, low-autocorrelation) for ε would work well.

But wait, we want to MINIMIZE the max of f_k. The dominant term is (n-k)/4 * dx ≈ 1/2 for small k. The perturbation -dx * ∑ε_i ε_{i+k} can reduce this if the autocorrelation is positive.

So we want ε to have positive autocorrelation at all lags. This means ε should be "smooth" - like a low-pass filtered signal. But if ε is too smooth, it becomes a low-frequency sinusoid, which has high positive autocorrelation at some lags and negative at others.

The optimal ε would be one whose autocorrelation is as uniformly positive as possible. This is related to "totally positive" kernels.

Actually, I think the key insight is:
- The constant 1/4 * dx * (n-k) gives a baseline of ≈ 1/2 for all k
- We want to subtract as much as possible from this baseline
- The subtraction is dx * ∑ε_i ε_{i+k}
- We want this to be large and uniform across k

The maximum possible value of ∑ε_i ε_{i+k} (over all k) is bounded by the energy of ε. By Parseval, ∑_k |â(k)|² = ∑|ε_i|² (up to constants). So the autocorrelation at lag 0 is the energy, and the autocorrelation at other lags is bounded by the energy.

This suggests that the best we can do is reduce the baseline by roughly 1/4 (the energy of ε divided by n, times dx), giving C5 ≈ 1/2 - 1/4 = 1/4 = 0.25.

But achieving exactly 0.25 would require the autocorrelation of ε to be perfectly flat (constant) at all non-zero lags, which is the difference set condition. In practice, we can get close.

from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return np.max(corr) * dx

def project_feasible(h, target_sum):
    h = np.asarray(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        d = target_sum - h.sum()
        if abs(d) < 1e-12:
            break
        mask = (h > 1e-15) & (h < 1.0 - 1e-15)
        if mask.sum() == 0:
            break
        h[mask] += d / mask.sum()
        h = np.clip(h, 0.0, 1.0)
    return h

def smooth_max_obj(h, temp):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full") * dx
    m = np.max(corr)
    s = np.exp(temp * (corr - m))
    return m + np.log(s.sum()) / temp

def slsqp_optimize(h_start, temp, maxiter=500):

    dx = 2.0 / n
    ts = n / 2.0
    bnds = [(0.0, 1.0)] * n

        return smooth_max_obj(hv, temp)

             'jac': lambda x: np.ones(n)}]
    res = minimize(obj, h_start, method='SLSQP', bounds=bnds,

                c5 = best_c
                improved = True
            else:
                h[j] = orig
                h = project_feasible(h, ts)
        if not improved:

    return h, c5
