The key insight for optimization: the problem is to find h that minimizes the maximum "badness" over all shifts. This is a min-max problem, which can be solved by:
1. Introducing a variable t
2. Minimizing t subject to: for all k, ∫h(x)(1-h(x+k))dx ≤ t
3. Plus 0≤h≤1 and ∫h=1

This is a convex optimization problem! (The objective is linear in h for fixed k, and we're minimizing the max of linear functions, subject to linear constraints.)

Wait, is it convex? Let's check:
- Constraint: ∫h(x)(1-h(x+k))dx ≤ t
- This is ∫h(x)dx - ∫h(x)h(x+k)dx ≤ t
- ∫h(x)dx = 1 (fixed by constraint)
- So: 1 - ∫h(x)h(x+k)dx ≤ t, i.e., ∫h(x)h(x+k)dx ≥ 1-t
- The LHS is a quadratic form in h: h^T A_k h where A_k is a Toeplitz-like matrix
- Is this convex? The matrix A_k has A_k[i,j] = 1 if |i-j| = k (for the appropriate shift). This is not positive semidefinite in general.

So it's NOT convex in general. That's why it's hard.

However, if we think of it as: minimize t subject to h^T A_k h ≥ 1-t for all k, 0≤h≤1, sum(h)=n/2... the constraints h^T A_k h ≥ 1-t are non-convex (they're reverse-convex since we need the quadratic form to be ≥ a constant, and the quadratic form isn't convex).

            h_new[bstart:bstart+blen] += rng.normal(0, T * 2.0, size=blen)
        h_new = repair(h_new, n)

        c5_new = evaluate_c5(h_new)
        delta = c5_new - best_c5

        if delta < 0:
            best_h = h_new
            best_c5 = c5_new
            stall_count = 0
        elif T > T_min and rng.random() < np.exp(-delta / T):
            best_h = h_new
            stall_count += 1
        else:
            stall_count += 1

        T = max(T * cooling, T_min)

        # Periodic restart
        if stall_count > 500 and T < 0.001:
            T = 0.008
            stall_count = 0

    # Phase 4: Fine Nelder-Mead polish
    if elapsed() < budget_s * 0.90:
        try:
            res = minimize(nm_obj, best_h, method='Nelder-Mead',
                          options={'maxiter': 20000, 'xatol': 1e-10, 'fatol': 1e-12,
                                   'adaptive': True})
            h_try = repair(res.x, n)
            c5_try = evaluate_c5(h_try)
            if c5_try < best_c5:
                best_c5 = c5_try
                best_h = h_try
        except Exception:
            pass

    # Phase 5: Coordinate descent with adaptive steps
    steps = [0.001, -0.001, 0.002, -0.002, 0.005, -0.005,
             0.01, -0.01, 0.003, -0.003]
    cd_end = budget_s * 0.97
    no_improve = 0
    while elapsed() < cd_end:
        improved = False
        for idx in rng.permutation(n):
            if elapsed() > cd_end:
                break
            for step in steps:
                h_try = best_h.copy()
                h_try[idx] = np.clip(h_try[idx] + step, 0.0, 1.0)
                h_try = repair(h_try, n)
                c5_try = evaluate_c5(h_try)
                if c5_try < best_c5 - 1e-14:
                    best_h = h_try
                    best_c5 = c5_try
                    improved = True
                    break
        if not improved:
            no_improve += 1
            if no_improve >= 3:
                break
        else:
            no_improve = 0

    # Final validation
    best_h = repair(best_h, n)
    best_c5 = evaluate_c5(best_h)
    assert 0.0 <= best_c5 <= 2.0
    assert np.all(best_h >= -1e-15) and np.all(best_h <= 1.0 + 1e-15)
    assert abs(np.sum(best_h) - n / 2.0) < 1e-6

    return (best_h, best_c5, n)
