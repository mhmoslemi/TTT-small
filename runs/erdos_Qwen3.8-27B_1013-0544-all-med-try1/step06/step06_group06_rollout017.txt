For np.correlate(a, v, mode='full') where a has length n and v has length n:
The result has length 2n-1.
result[m] = Σ_k a[k] * v[k + m - (n-1)] for valid k

So with a = h, v = 1-h:
result[m] = Σ_k h[k] * (1-h[k + m - (n-1)])

Let offset = m - (n-1). Then:
result[m] = Σ_{k: 0≤k<n, 0≤k+offset<n} h[k] * (1-h[k+offset])

The derivative with respect to h[j]:
∂result[m]/∂h[j] = Σ_{k: valid} [δ_{k,j} * (1-h[k+offset]) + h[k] * (-δ_{k+offset,j})]
= (1-h[j+offset]) * I(0≤j<n, 0≤j+offset<n) + (-h[j-offset]) * I(0≤j-offset<n, 0≤j<n)
= (1-h[j+offset]) * I(0≤j+offset<n) - h[j-offset] * I(0≤j-offset<n)

(since 0≤j<n is always true for our j)

sg[j] = (dx/|A|) * Σ_{m∈A} [(1-h[j+off_m]) * I(valid) - h[j-off_m] * I(valid)]

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target_sum = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            mask = h < 1.0
            if not mask.any():
                break
            h[mask] += diff / mask.sum()
        else:
            mask = h > 0.0
            if not mask.any():
                break
            h[mask] += diff / mask.sum()
        h = np.clip(h, 0.0, 1.0)
    return h

def obj_lse(h, n, alpha):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full') * dx
    m = c.max()
    shifted = alpha * (c - m)
    mx = shifted.max()
    if mx > 500:
        return float(m + (mx + np.log(np.sum(np.exp(shifted - mx)))) / alpha)

                g += (1.0 - h[jp])
            if 0 <= jm < n:
                g -= h[jm]
            grad[j] += g
    grad *= dx / len(top_idx)
    return grad
