However, if we fix all variables except one, f_k becomes linear in that variable. This suggests **coordinate descent** might work well!

For coordinate i:

So f_k as a function of h[i] (with all other h fixed) is:
f_k(h[i]) = h[i] * (1 - h[i+k]) + (contribution from i-k if valid) * (1 - h[i]) + constants

= h[i] * (1 - h[i+k]) - h[i] * h[i-k] + constants (when i-k is valid)

= h[i] * [(1 - h[i+k]) - h[i-k]] + constants

This IS linear in h[i]! (The constants don't depend on h[i].)

So for a fixed k, f_k is linear in h[i]. And max_k f_k is the max of linear functions of h[i], which is convex in h[i].

This means coordinate descent (optimizing one coordinate at a time) will converge! And we can solve each 1D subproblem exactly.

For coordinate i, we want to minimize max_k f_k(h) subject to 0 ≤ h[i] ≤ 1 and the sum constraint.

The sum constraint complicates things: if we change h[i], we need to adjust another coordinate to maintain the sum. 

Alternative: use a Lagrange multiplier for the sum constraint. Then the 1D problem becomes:
minimize max_k f_k(h) + λ*h[i] subject to 0 ≤ h[i] ≤ 1

where λ is chosen so that the sum constraint is satisfied.

This is a 1D convex optimization problem (min of a convex function over [0,1]).

The function max_k f_k(h[i]) + λ*h[i] is piecewise linear (max of linear functions). We can find the minimum by:
1. Computing the breakpoints (where the active k changes)
2. Evaluating at each breakpoint and at 0 and 1
3. Taking the minimum

def project_feasible(v, N):
    target = N / 2.0
    lo, hi = -1.5, 1.5
    for _ in range(80):
        mid = (lo + hi) / 2.0
        if np.clip(v - mid, 0.0, 1.0).sum() > target:
            lo = mid
        else:
            hi = mid
    lam = (lo + hi) / 2.0
    h = np.clip(v - lam, 0.0, 1.0)
    diff = target - h.sum()
    if abs(diff) > 1e-12:
        mask = (h > 1e-10) & (h < 1.0 - 1e-10)
        if mask.sum() > 0:
            h[mask] += diff / mask.sum()
            h = np.clip(h, 0.0, 1.0)
    return h

def obj_and_corr(h):
    N = len(h)
    dx = 2.0 / N
    corr = np.correlate(h, 1.0 - h, mode='full')
    return corr.max() * dx, corr, dx

def grad_lag(h, n_lag):
    N = len(h)
    g = np.zeros(N)
    s1 = max(0, n_lag)
    e1 = min(N, N + n_lag)
    if s1 < e1:
        g[s1:e1] += 1.0 - h[s1 - n_lag:e1 - n_lag]
    s2 = max(0, -n_lag)
    e2 = min(N, N - n_lag)
    if s2 < e2:
        g[s2:e2] -= h[s2 + n_lag:e2 + n_lag]
    return g

def soft_grad(h, corr, dx, alpha):
    N = len(h)
    c = corr - corr.max()
    w = np.exp(alpha * c)
    wsum = w.sum()
    if wsum < 1e-300:
        k_star = np.argmax(corr)
        return grad_lag(h, k_star - (N - 1)) * dx
    w /= wsum
    g = np.zeros(N)
    for j in range(len(w)):
        if w[j] < 1e-6:
            continue
        g += w[j] * grad_lag(h, j - (N - 1))
    return g * dx

def interpolate_to_n(h_src, n_dst):
    x0 = np.arange(len(h_src)) / len(h_src)
    x1 = np.arange(n_dst) / n_dst
    h = np.interp(x1, x0, h_src)

    diff = target - h.sum()
    if abs(diff) > 1e-12:
        mask = (h > 1e-10) & (h < 1.0 - 1e-10)
        if mask.sum() > 0:
            h[mask] += diff / mask.sum()
            h = np.clip(h, 0.0, 1.0)

    N = len(h)
    dx = 2.0 / N
    corr = np.correlate(h, 1.0 - h, mode='full')
    return corr.max() * dx, corr, dx

def grad_lag(h, n_lag):
    N = len(h)
    g = np.zeros(N)
    s1 = max(0, n_lag)
    e1 = min(N, N + n_lag)
    if s1 < e1:
        g[s1:e1] += 1.0 - h[s1 - n_lag:e1 - n_lag]
    s2 = max(0, -n_lag)
    e2 = min(N, N - n_lag)
    if s2 < e2:
        g[s2:e2] -= h[s2 + n_lag:e2 + n_lag]
    return g

def soft_grad(h, corr, dx, alpha):
    N = len(h)
    c = corr - corr.max()
    w = np.exp(alpha * c)
    wsum = w.sum()
    if wsum < 1e-300:
        k_star = np.argmax(corr)
        return grad_lag(h, k_star - (N - 1)) * dx
    w /= wsum
    g = np.zeros(N)
    for j in range(len(w)):
        if w[j] < 1e-6:
            continue
        g += w[j] * grad_lag(h, j - (N - 1))
    return g * dx

    return project_feasible(h, n_dst)

        h_new = project_feasible(h - lr * g + rng.randn(N) * 0.01 * T, N)

            val = val_new
            corr = corr_new
            if val < best_val:
                best_val = val
                best_h = h.copy()
                try_update(best_h, best_val)
    
    try_update(best_h, best_val)
    return best_h, best_val

def block_perturb(h, N, rng, n_blocks=3, block_size_frac=0.1):

        shift = rng.randint(-block_size, block_size + 1)
        h_new[start:end] = np.roll(h[start:end], shift)
