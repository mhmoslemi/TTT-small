Actually, let me reconsider the problem structure. We have:
C₅ = max_k ∫₀² h(x)(1-h(x+k)) dx (where the integral is only over the valid range)

For k=0: ∫₀² h(x)(1-h(x)) dx = 1 - ∫h(x)² dx

To minimize this, we want to maximize ∫h². With h ∈ [0,1] and ∫h = 1, the maximum of ∫h² is achieved by making h as "spiky" as possible. In the discrete case with n points, this means making h as binary as possible (0 or 1).

For binary h with n/2 ones: ∫h² = n/2 · dx = 1, so lag 0 gives 0.
For binary h: lag k gives the number of (1,0) pairs at distance k, times dx.

So for binary h, C₅ = max_k (disagreement_k) · dx

This is a combinatorial optimization problem: find a binary sequence of length n with n/2 ones that minimizes the maximum disagreement over all non-zero lags.

This is related to the "minimum maximum autocorrelation" problem in binary sequence design.

For the continuous problem, the optimal solution is a "soft" version of this binary sequence. The softening allows for better equalization of the different lags.

So my strategy should be:
1. Find a good binary (or near-binary) sequence
2. Use it as a starting point for the continuous optimization
3. The continuous optimization will "smooth out" the solution to equalize the lags

import numpy as np
from scipy.optimize import minimize
import time


def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)


def smooth_max(x, beta):
    m = np.max(x)
    return m + np.log(np.sum(np.exp(beta * (x - m)))) / beta


def project_box_sum(h, target):
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        d = target - h.sum()
        if abs(d) < 1e-14:
            break
        m = (h > 0.0) & (h < 1.0)
        if m.sum() == 0:
            break
        h[m] += d / m.sum()
        h = np.clip(h, 0.0, 1.0)
    return h


def obj_func(h, n, ts, beta, lam, bpen):
    c = np.correlate(h, 1.0 - h, mode="full")
    o = smooth_max(c, beta) * (2.0 / n)
    o += lam * (h.sum() - ts) ** 2
    if bpen > 0:
        o += bpen * np.sum(h * (1.0 - h))
    return o


def obj_top2(h, n, ts, beta, lam):
    c = np.correlate(h, 1.0 - h, mode="full")
    sc = np.sort(c)[::-1]
    o = (sc[0] ** 2 + sc[1] ** 2) * (2.0 / n) ** 2
    o += smooth_max(c, beta) * (2.0 / n) * 0.1
    o += lam * (h.sum() - ts) ** 2
    return o


def binary_max_disagreement(seq, n):
    md = 0
    for k in range(1, n):
        m = n - k
        md = max(md, int(np.sum((seq[:m] == 1) & (seq[k:k + m] == 0))))
    return md


def greedy_binary(n, target_ones, n_iter):
    h = np.zeros(n)
    idx = np.random.choice(n, target_ones, replace=False)
    h[idx] = 1.0
    best = h.copy()
    best_d = binary_max_disagreement(best, n)
    for _ in range(n_iter):
        i1, i2 = np.random.choice(n, 2, replace=False)
        if h[i1] != h[i2]:
            h[i1], h[i2] = h[i2], h[i1]
            d = binary_max_disagreement(h, n)
            if d < best_d:
                best_d = d
                best = h.copy()
            else:
                h[i1], h[i2] = h[i2], h[i1]
    return best, best_d
