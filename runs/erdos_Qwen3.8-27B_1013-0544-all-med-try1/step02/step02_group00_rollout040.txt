Now for the 1D minimax: given current c_k values and gradient g_k for coordinate i:
We want to find t ∈ [0,1] minimizing max_k (c_k + (t - h[i]) * g_k).

Let's define a_k = c_k - h[i]*g_k and b_k = g_k. Then we want to minimize max_k (a_k + b_k * t) over t ∈ [0,1].

The function φ(t) = max_k (a_k + b_k*t) is convex and piecewise linear. Its minimum over [0,1] is at a point where the subgradient contains 0, or at a boundary.

The subgradient at t is the convex hull of {b_k : k ∈ Active(t)} where Active(t) = {k : a_k + b_k*t = φ(t)}.

0 ∈ ∂φ(t) iff there exist active k's with b_k ≤ 0 ≤ b_k (or b_k = 0 for some active k).

A practical approach:
1. Evaluate φ at t=0 and t=1
2. Find the active set at t=0. If all active b_k > 0, the minimum is at t=0. If all < 0, at t=1.
3. Otherwise, the minimum is at an interior point. Find it by:
   - Collect all pairs of active lines and find their intersection
   - Among intersections in [0,1], pick the one that minimizes φ

        h_r, c_r = coord_descent(h_p, time_fn)
        if c_r < best_c5:
            best, best_c5 = h_r, c_r
    return best, best_c5

def run(seed=42, budget_s=1100, **kwargs):
    np.random.seed(seed)
    t0 = time.time()

    def time_left():
        return budget_s - (time.time() - t0)

    if 'initial_h_values' in globals() and initial_h_values is not None:
        h_init = np.array(initial_h_values, dtype=float).copy()
    else:
        h_init = np.full(140, 0.5)

    best_h = h_init.copy()
    best_c5 = compute_c5(best_h)

    # Phase 1: SLSQP warm-up
    if time_left() > 120:
        h1, c1 = slsqp_optimize(best_h, 300, time_left)
        if c1 < best_c5:
            best_h, best_c5 = h1, c1

    # Phase 2: Main coordinate descent
    if time_left() > 60:
        h2, c2 = coord_descent(best_h, time_left)
        if c2 < best_c5:
            best_h, best_c5 = h2, c5 if False else c2

    # Phase 3: SLSQP at higher beta
    if time_left() > 40:
        h3, c3 = slsqp_optimize(best_h, 800, time_left)
        if c3 < best_c5:
            best_h, best_c5 = h3, c3

    # Phase 4: Multi-start with perturbation
    if time_left() > 40:
        h4, c4 = multi_start_cd(best_h, time_left, 40)
        if c4 < best_c5:
            best_h, best_c5 = h4, c4

    # Phase 5: Final CD polish
    if time_left() > 10:
        h5, c5 = coord_descent(best_h, time_left)
        if c5 < best_c5:
            best_h, best_c5 = h5, c5

    # Phase 6: Final SLSQP
    if time_left() > 10:
        h6, c6 = slsqp_optimize(best_h, 2000, time_left)
        if c6 < best_c5:
            best_h, best_c5 = h6, c6

    return best_h, best_c5, len(best_h)
