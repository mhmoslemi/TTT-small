For the pairwise local search:
- For a random pair (i, j), the sum s = h[i] + h[j] is fixed.
- We want to find t in [max(0,s-1), min(1,s)] that minimizes the max correlation.
- We can do this with a few steps of ternary search or just try a small grid.
- The key is: changing h[i] and h[j] only affects correlations at lags that involve i or j.
- Specifically, lag k is affected if i and i+k are both in range, or j and j+k are both in range.
- For a given i, the affected lags are k in [-(i), n-1-i] (i.e., all k such that i+k is in [0, n-1]).

For efficiency, I'll precompute which lags are affected by each coordinate, and only recompute those.

Actually, for n=70, computing the full correlation takes only ~70^2 = 4900 operations (since np.correlate is O(n^2) for full mode). A grid of 10 points for the 1D search means 10 * 4900 = 49000 operations per pair. With maybe 100 pairs per sweep, that's 5 million operations per sweep. Very fast!

So I can afford to do many sweeps of pairwise local search.

```python
import numpy as np
from scipy.optimize import minimize, Bounds
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def get_corr(h):
    return np.correlate(h, 1.0 - h, mode="full")

def smooth_max(x, beta):
    m = np.max(x)
    # For numerical stability
    shifted = beta * (x - m)
    # Clip to avoid overflow
    shifted = np.clip(shifted, -500, 500)
    return m + np.log(np.sum(np.exp(shifted))) / beta

def project_h(h, target_sum):
    h = np.clip(h, 0.0, 1.0)
    for _ in range(20):
        s = h.sum()
        diff = target_sum - s
        if abs(diff) < 1e-12:
            break
        h += diff / len(h)
        h = np.clip(h, 0.0, 1.0)
    return h

def pairwise_local_search(h, n_iter=500, n_grid=15, seed=0):
    """Local search by random pair updates."""
    rng = np.random.RandomState(seed)
    n = len(h)
    h = h.copy()
    
    for it in range(n_iter):
        i = rng.randint(n)
        j = rng.randint(n)
        if i == j:
            continue
        s = h[i] + h[j]
        lo = max(0.0, s - 1.0)
        hi = min(1.0, s)
        if hi - lo < 1e-10:
            continue
        
        # Try grid of t values for h[i] (h[j] = s - t)
        grid = np.linspace(lo, hi, n_grid)
        best_t = h[i]
        best_val = float('inf')
        
        old_hi, old_hj = h[i], h[j]
        for t in grid:
            h[i] = t
            h[j] = s - t
            corr = get_corr(h)
            val = np.max(corr)
            if val < best_val:
                best_val = val
                best_t = t
        h[i] = best_t
        h[j] = s - best_t
    
    return h
```

Wait, I have a subtle issue. The `pairwise_local_search` function doesn't maintain the sum constraint! When I change h[i] and h[j] such that h[i]+h[j] = s, the total sum is preserved. So it's fine.

But I also need to make sure the values stay in [0,1], which is handled by the lo/hi bounds.

Let me also think about whether I should try a different approach entirely. 

**Alternative: Use the fact that the problem is almost a quadratic program**

If we linearize around the current solution, the problem becomes:
minimize max_k (c_k + g_k · δ)
subject to 1·δ = 0, -h <= δ <= 1-h

where c_k are the current correlation values and g_k are the gradients.

This is a linear program! We can solve it with scipy's linprog or cvxpy.

The gradient of c_k with respect to h[i] is:
∂c_k/∂h[i] = (1-h[i+k])·[valid1] - h[i-k]·[valid2] (using the formula above)

Actually, let me just use numerical gradients for simplicity.

**LP-based approach:**
1. Compute current correlations c_k
2. Compute (numerical) gradients g_k for each k
3. Solve: minimize t subject to c_k + g_k·δ <= t, 1·δ = 0, -h[i] <= δ[i] <= 1-h[i]
4. Take a step in the direction δ
5. Repeat

This is essentially a cutting-plane / subgradient method with LP as the inner solver.

Let me implement this:

```python
def lp_step(h, n_points, target_sum):
    """One step of LP-based optimization."""
    from scipy.optimize import linprog
    n = n_points
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    # Number of lags
    m = 2*n - 1
    
    # Numerical gradients
    # grad[k, i] = ∂corr[k]/∂h[i]
    # Use central differences
    eps = 1e-7
    # This would be O(n * m * n) = O(n^2 * m) which is O(n^3) for full mode
    # For n=70, that's 70^3 = 343000, times the number of lags... 
    # Actually, for each i, we perturb h[i] and recompute corr, which is O(n^2) per i, total O(n^3)
    # 70^3 = 343000 operations. That's fine.
    
    # But we need gradients for all m = 2n-1 lags. 
    # Actually, we only need the top few lags (the ones near the max).
    top_lags = 10
    sorted_idx = np.argsort(corr)[::-1]
    active_lags = sorted_idx[:top_lags]
    
    # Compute gradient only for active lags
    # grad[i] for lag k: ∂corr[k]/∂h[i]
    # We can compute this analytically:
    # corr[k] = sum_n h[n+k] * (1-h[n]) for valid n
    # ∂corr[k]/∂h[i] = (1-h[i-k]) * [i-k valid] + (-h[i+k]) * [i+k valid, for the n=i term]
    # Wait, let me be more careful.
    # 
    # corr[k] = sum_{n: valid} h[n+k] * (1-h[n])
    # where valid means 0 <= n < n AND 0 <= n+k < n
    #
    # ∂corr[k]/∂h[i]:
    # h[i] appears when:
    # - n+k = i (i.e., n = i-k): valid if 0 <= i-k < n and 0 <= i < n
    #   contribution: (1-h[i-k])
    # - n = i: valid if 0 <= i < n and 0 <= i+k < n
    #   contribution: -h[i+k]
    
    # Let me compute the gradient for each active lag
    # grad_k[i] = (1-h[i-k]) * [0<=i-k<n] + (-h[i+k]) * [0<=i+k<n]
    # But we need to be careful: these are the two different terms.
    # If both conditions are satisfied, both contributions add up.
    
    # For the LP, we want to minimize t subject to:
    # corr[k] + grad_k · delta <= t for k in active_lags
    # sum(delta) = 0
    # -h[i] <= delta[i] <= 1-h[i]
    
    # Variables: delta[0..n-1], t
    # Total: n+1 variables
    
    # c vector for linprog (minimize c^T x):
    # We want to minimize t, so c = [0, 0, ..., 0, 1]
    # x = [delta_0, ..., delta_{n-1}, t]
    
    # Constraints:
    # For each active lag k: grad_k[0]*delta_0 + ... + grad_k[n-1]*delta_{n-1} - t <= -corr[k]
    # sum(delta) = 0 (equality)
    # delta[i] >= -h[i] → -delta[i] <= h[i]
    # delta[i] <= 1-h[i] → delta[i] <= 1-h[i]
    
    n_active = len(active_lags)
    
    # Build the constraint matrix
    # A_ub * x <= b_ub
    # Rows: n_active (corr constraints) + n (lower bounds: -delta[i] <= h[i]) + n (upper bounds: delta[i] <= 1-h[i])
    # A_eq * x = b_eq
    # Row: sum(delta) = 0
    
    A_ub = np.zeros((n_active + 2*n, n + 1))
    b_ub = np.zeros(n_active + 2*n)
    
    for idx, k in enumerate(active_lags):
        # grad_k
        i = np.arange(n)
        # (1-h[i-k]) * [0<=i-k<n]
        mask1 = (i - k >= 0) & (i - k < n)
        # (-h[i+k]) * [0<=i+k<n]
        mask2 = (i + k >= 0) & (i + k < n)
        grad_k = np.zeros(n)
        if k >= 0:
            # For lag k >= 0: corr[k] = sum_{n=0}^{n-1-k} h[n+k]*(1-h[n])
            # h[i] appears when n+k=i (n=i-k, valid if i>=k) → (1-h[i-k])
            # h[i] appears when n=i (valid if i+k<n) → -h[i+k]
            mask1 = (i >= k) & (i < n)  # i-k valid means i>=k
            mask2 = (i + k < n)  # i+k valid
            grad_k[mask1] += (1 - h[i[mask1] - k])
            grad_k[mask2] += (-h[i[mask2] + k])
        else:
            # For lag k < 0, let m = -k > 0
            # corr[k] = sum_{n=m}^{n-1} h[n-m]*(1-h[n]) = sum_{p=0}^{n-1-m} h[p]*(1-h[p+m])
            # h[i] appears when p=i (valid if i < n-m = n+k) → (1-h[i+m]) = (1-h[i-k])
            # h[i] appears when p+m=i (p=i-m=i+k, valid if i+k>=0) → -h[i+k]... 
            # wait let me redo.
            # corr[k] for k<0: c[k] = sum_n h[n+k]*(1-h[n]) where 0<=n<n and 0<=n+k<n
            # For k = -m: c[-m] = sum_n h[n-m]*(1-h[n]) where n>=m and n<m+n → n in [m, n-1]
            # h[i] appears when n-m=i (n=i+m) → valid if i+m < n, i.e., i < n-m = n+k (since k=-m)
            #   contribution: (1-h[i+m]) = (1-h[i-k]) since k=-m so -k=m
            # h[i] appears when n=i → valid if i>=m=-k, i.e., i>=-k
            #   contribution: -h[i]... no wait.
            # c[-m] = sum_{n=m}^{n-1} h[n-m]*(1-h[n])
            # ∂/∂h[i]: 
            #   n-m=i → n=i+m: valid if m <= i+m <= n-1, i.e., 0<=i<=n-1-m. Contribution: (1-h[i+m])
            #   n=i: valid if m<=i<=n-1. Contribution: -h[i-m]
            
            m = -k
            mask1 = (i >= 0) & (i < n - m)  # i+m < n
            mask2 = (i >= m)  # i >= m
            grad_k[mask1] += (1 - h[i[mask1] + m])
            grad_k[mask2] += (-h[i[mask2] - m])
        
        A_ub[idx, :n] = grad_k
        A_ub[idx, n] = -1  # -t
        b_ub[idx] = -corr[k]
    
    # Lower bounds: -delta[i] <= h[i]
    for i in range(n):
        A_ub[n_active + i, i] = -1
        b_ub[n_active + i] = h[i]
    
    # Upper bounds: delta[i] <= 1-h[i]
    for i in range(n):
        A_ub[n_active + n + i, i] = 1
        b_ub[n_active + n + i] = 1 - h[i]
    
    # Equality: sum(delta) = 0
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1
    b_eq = np.zeros(1)
    
    # Objective: minimize t
    c_obj = np.zeros(n + 1)
    c_obj[n] = 1
    
    # Bounds for x: delta[i] is free (handled by ub constraints), t is free
    # Actually, let t be free: t >= 0 (since corr values are non-negative)
    bounds_lp = [(None, None)] * n + [(0, None)]
    
    try:
        res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds_lp, method='highs')
        if res.status == 0:
            delta = res.x[:n]
            # Take a step
            alpha = 1.0  # Full step
            h_new = h + alpha * delta
            h_new = np.clip(h_new, 0, 1)
            # Fix sum
            h_new = project_h(h_new, target_sum)
            return h_new
    except:
        pass
    
    return h
```

```python
import numpy as np
from scipy.optimize import minimize, Bounds, linprog
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def get_corr(h):
    return np.correlate(h, 1.0 - h, mode="full")

def smooth_max(x, beta):
    m = np.max(x)
    shifted = np.clip(beta * (x - m), -500, 500)
    return m + np.log(np.sum(np.exp(shifted))) / beta

def project_h(h, target_sum):
    h = np.clip(h, 0.0, 1.0)
    for _ in range(30):
        s = h.sum()
        diff = target_sum - s
        if abs(diff) < 1e-13:
            break
        h += diff / len(h)
        h = np.clip(h, 0.0, 1.0)
    return h

def pairwise_local_search(h, n_iter, n_grid, rng):
    n = len(h)
    h = h.copy()
    best_val = np.max(get_corr(h))
    for it in range(n_iter):
        i = rng.randint(n)
        j = rng.randint(n)
        if i == j:
            continue
        s = h[i] + h[j]
        lo = max(0.0, s - 1.0)
        hi = min(1.0, s)
        if hi - lo < 1e-10:
            continue
        grid = np.linspace(lo, hi, n_grid)
        best_t = h[i]
        best_cv = best_val
        old_i, old_j = h[i], h[j]
        for t in grid:
            h[i] = t
            h[j] = s - t
            cv = np.max(get_corr(h))
            if cv < best_cv:
                best_cv = cv
                best_t = t
        h[i] = best_t
        h[j] = s - best_t
        if best_cv < best_val:
            best_val = best_cv
    return h

def lp_local_step(h, n_points, target_sum, n_active=8, max_steps=30):
    n = n_points
    h = h.copy()
    for step in range(max_steps):
        corr = get_corr(h)
        sorted_idx = np.argsort(corr)[::-1]
        active = sorted_idx[:n_active]
        m = len(active)
        A_ub = np.zeros((m + 2 * n, n + 1))
        b_ub = np.zeros(m + 2 * n)
        for idx, k_idx in enumerate(active):
            k = k_idx - (n - 1)
            grad = np.zeros(n)
            i_arr = np.arange(n)
            if k >= 0:
                m1 = (i_arr >= k) & (i_arr < n)
                m2 = (i_arr + k < n)
                if m1.any():
                    grad[m1] += (1.0 - h[i_arr[m1] - k])
                if m2.any():
                    grad[m2] += (-h[i_arr[m2] + k])
            else:
                mk = -k
                m1 = (i_arr < n - mk)
                m2 = (i_arr >= mk)
                if m1.any():
                    grad[m1] += (1.0 - h[i_arr[m1] + mk])
                if m2.any():
                    grad[m2] += (-h[i_arr[m2] - mk])
            A_ub[idx, :n] = grad
            A_ub[idx, n] = -1.0
            b_ub[idx] = -corr[k_idx]
        for i in range(n):
            A_ub[m + i, i] = -1.0
            b_ub[m + i] = h[i]
            A_ub[m + n + i, i] = 1.0
            b_ub[m + n + i] = 1.0 - h[i]
        A_eq = np.zeros((1, n + 1))
        A_eq[0, :n] = 1.0
        b_eq = np.zeros(1)
        c_obj = np.zeros(n + 1)
        c_obj[n] = 1.0
        bounds_lp = [(None, None)] * n + [(0, None)]
        try:
            res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                          bounds=bounds_lp, method='highs')
            if res.status == 0:
                delta = res.x[:n]
                h_new = h + 0.5 * delta
                h_new = np.clip(h_new, 0, 1)
                h_new = project_h(h_new, target_sum)
                if compute_c5(h_new) < compute_c5(h):
                    h = h_new
                else:
                    break
            else:
                break
        except Exception:
            break
    return h

def run(seed=42, budget_s=1100, **kwargs):
    np.random.seed(seed)
    start_time = time.time()

    h_parent = None
    if 'initial_h_values' in globals() and initial_h_values is not None:
        h_parent = np.array(initial_h_values, dtype=float).copy()

    best_h = None
    best_c5 = float('inf')
    best_n = 0

    n_candidates = [50, 60, 70, 80, 90]

    for n_points in n_candidates:
        if time.time() - start_time > budget_s - 80:
            break
        t0 = time.time()
        time_budget_n = min(160, (budget_s - 100) / max(1, len(n_candidates) - n_candidates.index(n_points)))
        target_sum = n_points / 2.0
        dx = 2.0 / n_points
        bounds = Bounds(np.zeros(n_points), np.ones(n_points))

        def _con_fun(x, ts=target_sum):
            return np.sum(x) - ts
        def _con_jac(x, n2=n_points):
            return np.ones(n2)
        constraints = [{'type': 'eq', 'fun': _con_fun, 'jac': _con_jac}]

        starts = []
        if h_parent is not None:
            if len(h_parent) == n_points:
                starts.append(h_parent.copy())
            else:
                xo = np.linspace(0, 2, len(h_parent), endpoint=False)
                xn = np.linspace(0, 2, n_points, endpoint=False)
                h_int = np.interp(xn, xo, h_parent, period=2.0)
                starts.append(project_h(h_int, target_sum))
        x = np.linspace(0, 2, n_points, endpoint=False)
        starts.append(project_h(0.5 + 0.25 * np.sin(np.pi * x) + 0.1 * np.sin(2 * np.pi * x), target_sum))
        starts.append(project_h(np.random.RandomState(seed + n_points).random(n_points), target_sum))

        curr_h = None
        curr_c5 = float('inf')

        for h0 in starts[:3]:

                    h_new = project_h(res.x, target_sum)

            # Phase 4: SLSQP fine polish
            if curr_h is not None and time.time() - t0 < time_budget_n * 0.98:

                    if time.time() - t0 > time_budget_n:

                                       options={'maxiter': 300, 'ftol': 1e-13})

                        if c5 < curr_c5:

                    except Exception:
                        pass

            # Phase 5: Final pairwise
            if curr_h is not None and time.time() - t0 < time_budget_n + 10:
                rng_pw2 = np.random.RandomState(seed * 13 + n_points)
                h0 = pairwise_local_search(curr_h, n_iter=150, n_grid=16, rng=rng_pw2)
                c5 = compute_c5(h0)
                if c5 < curr_c5:
                    curr_h, curr_c5 = h0.copy(), c5

        if curr_h is not None and curr_c5 < best_c5:

    # Final global polish

        ts = n_f / 2.0
        dx_f = 2.0 / n_f
        bounds_f = Bounds(np.zeros(n_f), np.ones(n_f))
```
