    v = 1.0 - h
    c = np.correlate(h, v, mode='full') * dx
    k_max = np.argmax(c)

        g = 0.0

        if 0 <= j + d < n:
            g -= h[j + d]
        grad[j] = g * dx

Actually, let me reconsider the whole approach. The problem is:
- Maximize min_d R(d) where R(d) = sum_i h[i]h[i-d] * dx
- Subject to 0 ≤ h ≤ 1, sum(h)*dx = 1

This is a max-min problem. A key observation: if we fix the value of the minimum, say R_min, then the problem becomes:
- Maximize R_min
- Subject to R(d) ≥ R_min for all d
- 0 ≤ h ≤ 1, sum(h)*dx = 1

For a fixed R_min, this is a feasibility problem (or we can maximize R_min). The constraints R(d) ≥ R_min are quadratic in h, so this is a quadratically constrained program (QCP). This is non-convex in general.

However, we can use a "peeling" approach:
1. Start with a feasible h
2. Find the worst shift d*
3. Try to increase R(d*) while maintaining R(d) ≥ R(d*) - epsilon for all other d
4. This is a local optimization step

This is essentially what the subgradient method does.

def _project(h, target_sum):
    """Project onto {0<=x<=1, sum(x)=target_sum}"""
    lo, hi = -2.0, 2.0

Actually, let me provide the analytical gradient for the smooth objective. This will be much faster.

The smooth objective is:
f(h) = max_c + (1/t) * log(sum_k exp(t*(c_k - max_c))) + 50*(sum(h) - target)^2

where c_k = (n/2 - R(k-d_0)) * dx (the k-th correlation value)

The gradient of the log-sum-exp part:
d/dh[j] of (1/t) * log(sum_k exp(t*c_k)) = sum_k p_k * dc_k/dh[j]

where p_k = exp(t*c_k) / sum_k exp(t*c_k) (softmax of t*c)

And dc_k/dh[j] = dx * [(1-h[j-d_k]) * 1{0≤j-d_k<n} - h[j+d_k] * 1{0≤j+d_k<n}]

where d_k = k - (n-1)

So the full gradient is:
