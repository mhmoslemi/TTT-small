So np.correlate(h, 1-h, mode="full") at index corresponding to lag τ gives:
sum_{n: 0≤n<n AND 0≤n+τ<n} h[n+τ] * (1-h[n])

For h = [1]*24 + [0]*24 (n=48):
- τ = 0: h[n]*(1-h[n]) = 0 for all n. c = 0.
- τ = 1: h[n+1]*(1-h[n]). Nonzero when h[n+1]=1 and h[n]=0, i.e., n≥24 and n+1≤23. Impossible. c = 0.
- τ = -1: h[n-1]*(1-h[n]). Nonzero when h[n-1]=1 and h[n]=0, i.e., n-1≤23 and n≥24. So n=24. c = 1.
- τ = -24: h[n-24]*(1-h[n]). h[n-24]=1 when n-24≤23, n≥24. So n from 24 to 47. c = 24.
- τ = 24: h[n+24]*(1-h[n]). h[n+24]=1 when n+24≤23, i.e., n≤-1. c = 0.

So max c = 24, C₅ = 2/48 * 24 = 1. Still bad.

Actually, let me think about this problem differently. The key insight is:

For 0/1 h with n/2 ones: c[τ] = n/2 - (autocorrelation at τ)

The autocorrelation at τ=0 is n/2 (number of ones).
The autocorrelation at other τ is the number of ones that overlap with the shifted ones.

To minimize max c[τ], we want the autocorrelation to be as high as possible at all nonzero shifts. The maximum possible autocorrelation at any shift is n/2 (perfect overlap), which would give c = 0.

But we can't have the autocorrelation be n/2 at ALL shifts simultaneously (unless h is periodic, which creates problems at non-period shifts).

The best case is when the autocorrelation is uniformly n/4 at all nonzero shifts (like a "aperiodic autocorrelation" or "balanced" sequence). Then c[τ] = n/2 - n/4 = n/4 for all τ ≠ 0, and c[0] = 0. So max c = n/4, C₅ = 2/n * n/4 = 1/2.

This is the "random" baseline. To beat 1/2, we need some shifts to have autocorrelation > n/4.

The continuous relaxation allows values between 0 and 1, which gives more flexibility. The optimal continuous solution can have C₅ < 1/2.
