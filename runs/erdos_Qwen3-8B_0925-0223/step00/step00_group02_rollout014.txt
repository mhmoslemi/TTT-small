```python
            j = i + k
            if 0 <= j < n_points:
                contrib = h[i] * (1 - h[j])
                # Determine maximum delta to reduce contrib
                delta = 0.01
                if contrib > 0:
                    max_possible = min(h[i], 1 - h[i]) * (1 - h[j]) / contrib
                    delta = max(-0.01, min(0.01, max_possible))
                h[i] += delta
                h[i] = np.clip(h[i], 0, 1)
        # Adjust sum constraint
        sum_h = np.sum(h)
        if abs(sum_h - n_points / 2) > 1e-5:
            delta_sum = (n_points / 2) - sum_h
            h[-1] += delta_sum
            h[-1] = np.clip(h[-1], 0, 1)
    return (best_h, best_c5, n_points)
```

However, the mapping of the cross-correlation index to the lag k is incorrect. 

The correct way to map the cross-correlation index to the lag k is:

For a cross-correlation array of length L = 2n_points -1, the lag k for index m is k = m - (n_points -1).

So for m from 0 to L-1, lag = m - (n_points - 1). 

For example, for n_points =45, L=89. Index 44 corresponds to lag 0. Index 45 is lag 1, index 43 is lag -1, etc. 

Thus, the line `k = max_overlap_idx - (n_points -1)` would give the actual lag. 

Now, for the lag k, the indices i where i + k is within the array are valid. 

But for negative k, the i's that are valid are those where i +k >=0, i.e., i >= -k. For positive k, i <= n_points -1 -k. 

Thus, during the contributions calculation, for each i, we need to check if j = i +k is in the array. 

But the code in the above draft tries to do that. 

However, in practice, for small n_points, it's manageable. 

But there's still the issue of how to adjust the delta. The code currently uses a fixed delta of 0.01, but the strategy suggests using a delta that is based on the contribution. 

In any case, the code must be optimized for the given budget. 

Considering all these points, here's the final code that implements the coordinate descent approach, with adjustments to the function values to reduce the maximum overlap, ensuring the constraints are maintained, and efficiently managing the iterations within the time budget.

```python
import numpy as np

def run(seed=42, budget_s=600, **kwargs):
    np.random.seed(seed)
    initial_h_values = np.load('initial_h_values.npy')
    n_points = len(initial_h_values)
    dx = 2.0 / n_points
    h = initial_h_values.copy()
    sum_h = np.sum(h)
    if abs(sum_h - n_points / 2) > 1e-6:
        h = h * (n_points / 2) / sum_h
    best_h = h.copy()
    best_c5 = float('inf')
    max_iterations = int(budget_s / 0.01)
    for _ in range(max_iterations):
        corr = np.correlate(h, 1 - h, mode="full")
        overlaps = corr * dx
        max_overlap = np.max(overlaps)
        if max_overlap < best_c5:
            best_h = h.copy()
            best_c5 = max_overlap
        max_overlap_idx = np.argmax(overlaps)
        k = max_overlap_idx - (n_points - 1)
        contributions = []
        for i in range(n_points):
            j = i + k
            if 0 <= j < n_points:
                contrib = h[i] * (1 - h[j])
                contributions.append((i, contrib))
        contributions.sort(key=lambda x: -x[1])
        top_indices = [i for i, _ in contributions[:5]]
        for i in top_indices:
            j = i + k
            if 0 <= j < n_points:
                contrib = h[i] * (1 - h[j])
                if contrib > 0:
                    max_possible = min(h[i], 1 - h[i]) * (1 - h[j]) / contrib
                    delta = max(-0.01, min(0.01, max_possible))
                else:
                    delta = 0
                h[i] += delta
                h[i] = np.clip(h[i], 0, 1)
        sum_h = np.sum(h)
        if abs(sum_h - n_points / 2) > 1e-5:
            h[-1] += (n_points / 2 - sum_h)
            h[-1] = np.clip(h[-1], 0, 1)
    return (best_h, best_c5, n_points)
```
