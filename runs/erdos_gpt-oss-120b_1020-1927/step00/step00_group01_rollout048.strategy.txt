1. Approach and rationale

Erdős Minimum OverlapProblem requires a step function $h(x)$ defined on $[0,2]$ with $\int h(x) \mathbf{dx} = 1$ and $0 \leq h(x) \leq 1$. The goal is to minimize: $\max_k \int h(x) (1-h(x+k)) \mathbf{dx}$.

Our optimization approach combines several techniques:
- **Problem discretization**: Represent $h(x)$ on a uniform grid of $n$ points with $\mathrm{dx} = 2/n$. The objective is evaluated using $\max(\text{np.correlate}(h, 1-h, \text{mode}="full") \times \mathrm{dx})$.
- **Gradient-based optimization**: Use gradient descent (with CVXPY's constraint handling) to minimize the maximum overlap. The gradient efficiently computes the sensitivity of the objective to changes in each $h_i$.
- **Multi-resolution search**: Test different grid sizes (n=47, 94, 188) to escape local minima. Start with parent grid and refine if better solutions appear outside the initial grid.
- **Iterative refinement**: From local solutions, perturb and optimize to potentially find globally superior solutions. This leverages the step-function representation's structure to escape flat regions.

Important limitations:

2. Mathematical specification
Define $n$ samples at uniform spacing $\mathrm{dx}=2/n$, so the integral constraint becomes $\sum h_i / (2/n) = 1 \rightarrow \sum h_i = n/2$.

Minimize $C_5 = (\text{np.correlate}(h, 1-h, \text{mode}="full")} \times \mathrm{dx})$.

The objective's gradient w.r.t. $h_j$ is:
$$\frac{\partial C_5}{\partial h_j} = dx \times \sum_{k=\text{argmax}} \left[ (1-h_{j+k}) \cdot \mathbb{I}_{\text{in bounds}}(j+k) - h_{j-k} \cdot \mathbb{I}_{\text{in bounds}}(j-k) \right]$$

Derivation: The correlation's maximum at lag $k$ involves shifts $j+k$ and $j-k$. Gradient terms reflect how changes in $h_j$ affect these specific points.

    dx_val = 2.0 / len(h)

def compute_gradient(h):
    n = len(h)
    dx_val = 2.0 / n
    corr = np.correlate(h, 1-h, mode='full')
    max_val = np.max(corr)
    argmax = np.flatnonzero(corr == max_val)

                term2 = -h[i - s]  # Derivative from cross-term at index i-s
            else:
                term2 = 0.0
            grad[i] += term1 + term2
    return dx_val * grad
