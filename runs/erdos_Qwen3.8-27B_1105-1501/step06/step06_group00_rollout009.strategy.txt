1. Approach and rationale

1.1 Central idea

The new primary algorithm is a multi-coordinate, smooth-max gradient line search using the exact discrete quadratic structure of the unnormalized lag-overlap vector. A starting vector h is feasible (`0 <= h_i <= 1`, sum = target). At each round, a bounded set of candidate displacement vectors d with roughly zero coordinate sum is generated. For each candidate d, all feasible steps `h + alpha*d` are explored. Along that line, every shifted correlation is an exact quadratic function of alpha. The objective is the maximum of many quadratic curves, so its one-dimensional optimum is sought using:

- formulaically found vertices of the most active quadratic curves;
- formulaic intersections of pairs of the most active quadratic curves;
- a coarse grid plus local refinement;
- exact recomputation after the selected step.

The method never relies on a computed upper envelope as an accepted objective. Candidate interventions are accepted only if the true discrete evaluator improves.

This is materially different from the previous LP/SA/binary paired-transfer approach. The old workflow moved single mass transfers and repaired infeasible continuous iterates, or used LP linearization. Here:

- feasible moves are generated by explicit multi-coordinate directions, not only two-coordinate problem transfers;
- there is no LP or trust-region linear program;
- the smooth gradient guides a dictionary of structured directions, including gradient, block-smooth, low-frequency, and selected pair directions;
- the core line search exactly solves (or densely samples and candidates on quadratic envelope topology) a 1D line on the original discrete objective;
- discrete sizes can be perturbed but the same exact object/formula is reused.

**1.2 Why this could improve the supplied parent**

The target gap is small (`~7e-5` in the scaled c5). Such levels are often in a flat plateau where a pair transfer has no strictly decreasing direction. A one-dimensional line with a smooth direction can change many neighbor probabilities simultaneously, softening or reducing multiple correlated high overlap constraints before one active pair relation completely saturates. The use of intersection/vertex envelope candidates helps find interior moves that maximize endpoints of a single coordinate do not discover.

The methodology is local/nonconvex and offers no global optimality. It can certainly fail to decrease the global optimum. However, by actively using all shifted correlations and exact objective verification, every accepted candidate has its objective proven with the task metric.
