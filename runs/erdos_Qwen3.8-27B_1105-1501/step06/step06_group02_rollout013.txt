But C_k * dx is already the overlap value for lag k. So L is a smooth approximation of max_k(C_k * dx).

If T is close to the target (say T = current_best - small_delta), then when all C_k*dx < T, the log-sum-exp is small (all exponentials are small). This effectively says "I'm doing well, don't worry." But when some C_k*dx > T, the log-sum-exp grows rapidly, pushing the optimizer to reduce those peaks.

This is a nice property. The target T acts like a threshold.

However, there's a subtlety: if T is too low, the objective becomes dominated by the absolute max and behaves like a hard max. If T is too high, the objective is flat. The sweet spot is T just slightly below the current best.

Let me also think about the log-sum-exp stability:

where z_k = (C_k * dx - T) / tau

This is stable.

= tau * sum_k softmax_k * (1/tau) * (dx) * ∂C_k/∂h_i
= dx * sum_k softmax_k * ∂C_k/∂h_i

Wait, that's simpler than I thought! The tau cancels out!

So the gradient doesn't depend on tau directly (only through the softmax weights). As tau → 0, the softmax concentrates on the max, and the gradient becomes the gradient of the max (which is subgradient). As tau → ∞, the softmax is uniform and the gradient is the average of all row gradients.

This is actually a well-known property of the log-sum-exp approximation.
