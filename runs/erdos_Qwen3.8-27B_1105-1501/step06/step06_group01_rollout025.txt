def _corr_array(h):

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo, hi = float(v.min()) - 2.0, float(v.max()) + 2.0
    for _ in range(70):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-10:

        cnt = int(np.sum(mask))
        if cnt > 0:

def _line_search_obj(h, d, dx, trust_radius):
    """Line search for max of quadratic along direction d."""
    n = len(h)
    S0 = np.correlate(h, 1.0 - h, mode='full') * dx

    C = np.correlate(d, d, mode='full') * dx

    # Actually corr(d,d) at lag 0 is sum d^2 >= 0, but other lags can be anything
    # So S0 + t*T - t^2*C is a quadratic in t for each component
    # We want to minimize max_q (S0[q] + t*T[q] - t^2*C[q])
    
    # Find feasible t range
    t_lo, t_hi = 0.0, trust_radius
    pos = d > 1e-15

        t_hi = min(t_hi, float(np.min(-h[neg] / d[neg])))
    if t_hi < 1e-14:

    # The function f(t) = max_q (S0[q] + t*T[q] - t^2*C[q]) is the max of concave quadratics
    # which is generally NOT concave. But on a restricted range it's often well-behaved.
    # Use grid + golden section.

    gr = (np.sqrt(5.0) - 1.0) / 2.0

    c2 = a + gr * (b - a)

       = [i>=L]*(1-h[i-L]) - [i<=n-1-L]*h[i+L]

For L = 0: B_0(i) = (1-h[i]) - h[i] = 1 - 2*h[i]
For L > 0: B_L(i) has a "shift" structure.

I can compute this vectorized:
```python
def _sensitivity_vec(h, n):
    B = np.zeros((n, 2*n-1))
    q_off = n - 1
    for L in range(-(n-1), n):
        q = L + q_off
        b = np.zeros(n)
        # Term 1: (1-h[i-L]) for 0 <= i-L < n
        if L >= 0:
            idx_src = np.arange(L, n)  # i values where i-L in [0, n-1]
            b[idx_src] += (1.0 - h[idx_src - L])
        else:
            idx_src = np.arange(0, n + L)  # L negative, i+|L| in [0, n-1] means i in [0, n-1-|L|]
            abs_L = -L
            idx_src = np.arange(0, n - abs_L)
            b[idx_src] += (1.0 - h[idx_src + abs_L])
        # Term 2: -h[i+L] for 0 <= i+L < n
        if L >= 0:
            idx_dst = np.arange(0, n - L)  # i values where i+L in [0, n-1]
            b[idx_dst] -= h[idx_dst + L]
        else:
            abs_L = -L
            idx_dst = np.arange(abs_L, n)
            b[idx_dst] -= h[idx_dst - abs_L]
        B[:, q] = b
    return B
```

This is O(n²) but vectorized in the inner loop. For n=122, that's 243 lags, each with O(n) work = ~30K operations total. Fast.

Actually wait, I realize I can compute this even more efficiently using correlation!

B_L(i) = (1-h[i-L])*[valid] - h[i+L]*[valid]

The first term, for valid i, is (1-h[i-L]). If I define g = 1-h, then the first term is g[i-L] for valid i. The cross-correlation of g with a delta at position i gives this.

Actually, let me just use the direct formula. For each lag L, B[:, L+q_off] is:
- First part: shifted (1-h) with appropriate masking
- Second part: -shifted h with appropriate masking

Let me just compute it directly with numpy:

```python
def _compute_B(h, n):
    """Compute sensitivity matrix B[i, q] where q = L + (n-1)."""
    q_off = n - 1
    B = np.zeros((n, 2*n-1))
    one_minus_h = 1.0 - h
    for L in range(-(n-1), n):
        q = L + q_off
        b = np.zeros(n)
        if L >= 0:
            # (1-h[i-L]) for i in [L, n-1]
            b[L:] += one_minus_h[:n-L]
            # -h[i+L] for i in [0, n-1-L]
            b[:n-L] -= h[L:]
        else:
            a = -L
            # (1-h[i+a]) for i in [0, n-1-a]
            b[:n-a] += one_minus_h[a:]
            # -h[i-a] for i in [a, n-1]
            b[a:] -= h[:n-a]
        B[:, q] = b
    return B
```

This is clean and O(n²) total. For n=122, that's 243 iterations of O(n) = ~30K flops. Very fast.

Now, the optimization:

For a pair (i, j), the change in active lag values when transferring δ from i to j:
ΔL_k = δ * (B[j, k] - B[i, k]) for active lag k

The new active lag values: corr_k + δ * (B[j,k] - B[i,k])

We want to minimize max over active lags. This is a 1D convex problem.

But we also need to make sure non-active lags don't exceed the new max. So the true objective is:
f(δ) = max( max_{k∈Active} [corr_k + δ*A_k], max_{k∉Active} corr_k )

The second term is constant (doesn't depend on δ), so:
f(δ) = max( g(δ), C_nonactive )

where g(δ) = max_{k∈Active} [corr_k + δ*A_k] and C_nonactive = max_{k∉Active} corr_k.

If C_nonactive >= min(g), then the constraint is just f(δ) <= current max, and we need g(δ) <= current max.

This is getting complex. Let me simplify: just use the full corr array and evaluate f(δ) = max_q [corr_q + δ * A_q] where A_q = B[j,q] - B[i,q].

Since A_q is computed for ALL lags (not just active ones), this is the exact objective. And it's the max of linear functions, so convex in δ. Golden section works.

The computation per pair is O(n) (compute A_q for all q, then evaluate the max). With ~n² pairs to try per iteration, one iteration is O(n³). For n=122, that's about 1.8M operations per iteration. At maybe 100 iterations, that's 180M operations. Should be fine within budget.

But actually, we don't need to try all n² pairs. We can be smarter:
- For the worst lag, the best move is to reduce h[i] where B[i, worst_q] is largest and increase h[j] where B[j, worst_q] is smallest.
- So sort by B[:, worst_q] and try the top few i's with the bottom few j's.

This reduces the search to O(K² * n) per iteration where K is the number of candidates.

Let me now write the complete algorithm:
