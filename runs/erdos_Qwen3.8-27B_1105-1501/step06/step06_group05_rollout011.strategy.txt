<strategy>
1. Approach and rationale

The chosen primary approach is a non-global, but deliberately diversified, continuous minimax optimizer based on active-lag weighted directions, exact one-dimensional line searches, exhaustive small-pair move scanning, population/basin reinitialization, and a final exact dyadic quantization. It is intended to move below the supplied parent solution by attacking the three bottlenecks that often limit the supplied style of local optimizer:

2. Mathematical specification

2.1 Exact evaluation and indexing

For a solution array `h` of length `n`, define:

- `dx = 2.0 / n`.
- The raw finite correlation array is `raw = np.correlate(h, 1.0 - h, mode="full")`, with length `2n - 1`.
- The returned objective bound is `c5_bound = float(np.max(raw)) * dx`.

For complete indexing by lag, let `lag = idx - (n - 1)`, `idx = 0, ..., 2n - 2`. The evaluator value is equivalent to:
```
raw[idx] = sum_{i = max(0, lag)}^{min(n - 1, n - 1 + lag)} h[i] * (1 - h[i - lag])
```
This is finite linear correlation, not circular correlation. The formula contains boundary terms and must be used as the mathematical basis for validation signs.

Scalar objective:
```
F(h) = max over lags { dx * raw[idx] }
```
We minimize `F(h)`.
