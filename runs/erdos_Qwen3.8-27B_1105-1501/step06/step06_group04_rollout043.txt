def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo, hi = float(v.min()) - 2.0, float(v.max()) + 2.0

Now let me think about the rolling window approach more carefully.

**Rolling Window Optimization:**
- Choose a window of W consecutive indices: [start, start+W-1]
- Fix all other coordinates
- The objective is the max over all lags d of c_d
- c_d depends on h only through the window coordinates (for the lags that interact with the window)
- We want to minimize max_d c_d by adjusting the W window coordinates, subject to 0 ≤ h ≤ 1 and sum of window = original sum

This is a non-convex problem in W variables. We can solve it with:
- Scipy minimize (Nelder-Mead or COBYLA for small W)
- A custom LP-based approach (similar to the main loop but for W variables)
- Exhaustive search for very small W

For W = 10-20, this is tractable with scipy minimize.

Actually, a better approach: since we're near a local optimum, the "active" lags are roughly known. We can solve:
min_t t
s.t. c_d(h_window) ≤ t for all active d
     0 ≤ h_window ≤ 1
     sum(h_window) = const

This is a QP (quadratic constraints) which is non-convex. But for small W, we can use scipy minimize.

Let me think about a simpler but effective approach:

**Projected Gradient Descent with Log-Sum-Exp:**

Use the smoothed objective:
f(h) = (1/β) * log(sum_k exp(β * c_k(h)))

This is smooth and differentiable. The gradient is:
∇f(h) = (1/β) * sum_k (β * exp(β*c_k)) / sum_j exp(β*c_j) * ∇c_k
= sum_k w_k * ∇c_k
where w_k = exp(β*c_k) / sum_j exp(β*c_j)

As β → ∞, this approaches the gradient of the max. For finite β, it's a smooth approximation.

We can use this with projected gradient descent (projecting onto {0≤h≤1, sum(h)=n/2}).

The projection is the `_project` function (which projects onto {0≤h≤1, sum(h)=target}).

Actually, the full projection onto {0≤h≤1, sum(h)=n/2} is what `_project` does.

def _logsumexp_smooth(h, beta):
    """Compute log-sum-exp smoothed max of correlation values."""
    n = len(h)
    dx = 2.0 / n
    scores = np.correlate(h, 1.0 - h, mode='full') * dx
    max_s = scores.max()
    shifted = beta * (scores - max_s)
    shifted = np.clip(shifted, -500, 500)
    return max_s + np.log(np.sum(np.exp(shifted))) / beta

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo, hi = float(v.min()) - 2.0, float(v.max()) + 2.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0

        mask = (x < 1.0) if res > 0 else (x > 0.0)

def _grad_matrix(h, lag_indices=None):
    n = len(h)
