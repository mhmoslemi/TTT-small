    """Find the minimum-norm subgradient of max_k q_k at h."""
    n = len(h)
    # Compute gradients of active q_k
    G = _corr_grads(h)[active_lags]  # shape (|S|, n)
    # Solve min ||G^T λ||² s.t. λ >= 0, sum(λ) = 1
    # This is equivalent to: min λ^T G G^T λ s.t. λ >= 0, 1^T λ = 1
    A = G @ G.T  # shape (|S|, |S|)
    # Solve the QP using scipy
    from scipy.optimize import minimize

    x0 = np.ones(m) / m
    res = minimize(lambda l: l @ A @ l, x0, 
                   constraints=[{'type': 'eq', 'fun': lambda l: l.sum() - 1}],
                   bounds=[(0,1)]*m, method='SLSQP')
    if res.success:
        lam = res.x
        direction = -(G.T @ lam)  # negative subgradient
        # Project to sum-zero
        direction -= direction.mean()
        return direction
    # Fallback: average gradient

q_s(h) = sum_{i=max(0,-s)}^{min(n-1, n-1-s)} h[i] * (1 - h[i+s])

Then:
q_s(h + td) = sum_i (h_i + t*d_i) * (1 - h_{i+s} - t*d_{i+s})
= sum_i h_i(1-h_{i+s}) + t*sum_i [d_i(1-h_{i+s}) - h_i*d_{i+s}] + t²*sum_i(-d_i*d_{i+s})

So:
a_s = q_s(h)
b_s = sum_i [d_i(1-h_{i+s}) - h_i*d_{i+s}]
c_s = -sum_i d_i*d_{i+s}

For b_s, I can compute it as:
b_s = sum_i d_i*1 - sum_i d_i*h_{i+s} - sum_i h_i*d_{i+s} + sum_i h_i*h_{i+s}... no that's wrong.

b_s = sum_i d_i*(1-h_{i+s}) - sum_i h_i*d_{i+s}

The first term is correlate(d, 1-h) at lag s (with appropriate convention).
The second term is correlate(h, d) at lag s.

Actually, let me think about it differently. Let u = 1-h. Then:
q_s = sum h[i] * u[i+s] (over valid range)
b_s = sum d[i] * u[i+s] - sum h[i] * d[i+s]

The first sum is the "cross-correlation" of d and u at lag s.
The second sum is the "cross-correlation" of h and d at lag s.

In numpy: np.correlate(d, u, 'full') gives the cross-correlation.
np.correlate(h, d, 'full') gives the cross-correlation.

So b (for all lags) = correlate(d, 1-h) - correlate(h, d), all times dx.

And c (for all lags) = -correlate(d, d, 'full'), all times dx.

This is very efficient! I can compute all b_s and c_s with just 3 correlate calls.

def _line_search_fast(h, d, corr_dx, t_max=0.5):
    """
    Exact line search along direction d (sum zero).
    corr_dx = max of correlate(h, 1-h, 'full') * dx (current C5 value)
    Returns (best_t, best_value)
    """
    n = len(h)
    dx = 2.0 / n
    
    # Feasible range
    t_lo = -t_max
    t_hi = t_max
    pos = d > 1e-14
    neg = d < -1e-14
    if np.any(pos):
        t_hi = min(t_hi, float(np.min((1.0 - h[pos]) / d[pos])))
    if np.any(neg):
        t_lo = max(t_lo, float(np.max((1.0 - h[neg]) / d[neg])))
    # Also for positive d, lower bound from h_i + t*d_i >= 0: t >= -h_i/d_i
    if np.any(pos):
        t_lo = max(t_lo, float(np.max(-h[pos] / d[pos])))
    # For negative d, upper bound from h_i + t*d_i <= 1: t <= (1-h_i)/d_i (negative, so no constraint from above)
    # Wait: if d_i < 0, then h_i + t*d_i <= 1 is t >= (1-h_i)/d_i. Since d_i < 0 and 1-h_i >= 0, (1-h_i)/d_i <= 0. So for t >= 0 this is auto-satisfied.
    # And h_i + t*d_i >= 0 gives t <= h_i/(-d_i) = -h_i/d_i > 0.
    if np.any(neg):
        t_hi = min(t_hi, float(np.min(-h[neg] / d[neg])))
    
    t_lo = max(t_lo, -t_max)
    t_hi = min(t_hi, t_max)
    
    if t_hi - t_lo < 1e-14:
        return 0.0, corr_dx
    
    # Compute b and c vectors for all lags
    u = 1.0 - h
    b_all = (np.correlate(d, u, 'full') - np.correlate(h, d, 'full')) * dx
    c_all = (-np.correlate(d, d, 'full')) * dx
    a_all = np.correlate(h, u, 'full') * dx  # current values
    
    # Evaluate on grid
    n_grid = 80
    grid = np.linspace(t_lo, t_hi, n_grid)
    # obj(t) = max_k (a_k + b_k*t + c_k*t²)
    # = max_k (a_k + t*b_k + t²*c_k)
    vals = a_all[None, :] + grid[:, None] * b_all[None, :] + (grid[:, None])**2 * c_all[None, :]
    obj = vals.max(axis=1)
    best_i = int(np.argmin(obj))
    best_t = grid[best_i]
    best_val = obj[best_i]
    
    # Golden section refinement
    if 0 < best_i < n_grid - 1:
        span = grid[1] - grid[0]
        a = max(t_lo, grid[best_i] - 2*span)
        b = min(t_hi, grid[best_i] + 2*span)
    else:
        a, b = t_lo, t_hi
    
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    c = b - gr * (b - a)
    dd = a + gr * (b - a)
    fc = float((a_all + c*b_all + c*c*c_all).max())
    fd = float((a_all + dd*b_all + dd*dd*c_all).max())
    for _ in range(60):
        if b - a < 1e-13:
            break
        if fc < fd:
            b = dd
            fd = fc
            dd = c
            c = b - gr * (b - a)
            fc = float((a_all + c*b_all + c*c*c_all).max())
        else:
            a = c
            fc = fd
            c = dd
            dd = a + gr * (b - a)
            fd = float((a_all + dd*b_all + dd*dd*c_all).max())
    
    mid = (a + b) / 2.0
    fm = float((a_all + mid*b_all + mid*mid*c_all).max())
    if fm < best_val:
        best_val, best_t = fm, mid
    
    return best_t, best_val

This is much more efficient because I compute all the a, b, c vectors once (3 correlate calls) and then the line search is just evaluating a polynomial on a grid.

Now for the direction finding. The minimum-norm subgradient approach:

Given the active set S (lags where q_k is close to the maximum), I want to find:
min ||G_S^T λ||² s.t. λ ≥ 0, 1^T λ = 1

where G_S[k] = ∇q_{s_k}(h) / dx (the gradient of q at h for lag s_k, divided by dx for convenience... actually let me keep it consistent).

Actually, let me define:
- corr_vals = correlate(h, 1-h, 'full') * dx (vector of length 2n-1)
- C5 = max(corr_vals)
- Active set S = {k : corr_vals[k] >= C5 * (1 - tol) or corr_vals[k] >= C5 - abs_tol}

For the subgradient:
- G[k] = gradient of q_k w.r.t. h (a row vector of length n)
- I want to find d = -G_S^T λ where λ minimizes ||G_S^T λ||² subject to λ ≥ 0, sum(λ) = 1

This gives the steepest descent direction for the max function at h.

To compute G_S efficiently, I can use the same correlate trick:
G[k] · d = b_k (the directional derivative in direction d for lag k)
But I need G_S as a matrix for the QP...

Actually, for the QP, I need A = G_S @ G_S.T, which has elements:
A[i,j] = G_S[i] · G_S[j] = sum_p G_S[i,p] * G_S[j,p]

This is the Gram matrix of the active gradients. For |S| up to ~30, this is a 30x30 matrix.

But computing G_S explicitly requires n*(2n-1) storage which for n=122 is about 29,000 entries - manageable.

Actually, I can compute G_S @ G_S.T more efficiently. Let me think...

G[k, i] = (1/dx) * ∂q_k/∂h_i where q_k = sum_j h_j*(1-h_{j+s_k})*dx

So G[k, i] = (1/dx) * [∂/∂h_i sum_j h_j*(1-h_{j+s_k})*dx]
= ∂/∂h_i sum_j h_j*(1-h_{j+s_k})
= (1-h_{i+s_k}) if i is in the "first" position range
  -h_{i-s_k} if i is in the "second" position range
  (sum of both if both apply)

This is just the structure I had before. Let me compute it directly.

- Or a custom projected gradient method

            G[idx, :m] += (-h[g:g+m])

                lam = np.maximum(lam, 0)
