2. Mathematical specification

2.1 Evaluation orientation, row identification, and objective

Input is a real vector `h[0:n - 1]` with current n and `dx = 2/n`. true score is:

`C5(h) = max(np.correlate(h, 1 - h, mode="full")) * (2/n)`.

2.1 Evaluation representation, exact objective, feasible measure

Let `h ∈ R^n`, with current sample number `n` and `dx = 2/n`.

The only correct objective score is

`c5(h) = max(np.correlate(h, 1-h, mode="full").flatten()) * dx`.

No circular convolution, Fourier-domain simplification, replacement autocorrelation identity, or omitted old endpoint overlaps may substitute for this objective. All `2n-1` outputs are full linear overlaps. Orientation must match NumPy.

Row indexing:

For output row index `i ∈ [0,2n-2]`, centered lag variable is defined as `d = i - (n-1)`.

The corresponding raw overlap row is:
- If `d >= 0`, `m = n - d`:
  `R_i = sum_{j=0}^{m-1} h[j] * (1 - h[j+d])`.
- If `d < 0`, let `q = -d` and `m = n - q`:
  `R_i = sum_{j=q}^{n-1} h[j] * (1 - h[j-q])`.

The objective accepts maximum over signed lags including lag zero.

Feasibility constraints are:
- `0 <= h[j] <= 1`
- `sum_j h[j] * dx = 1`

- `sum_j h[j] = n/2`.

2.2 Raw row gradients and matrix coefficients

- If `d >= 0`, with `m = n - d`:

`R0 = correlate(h, 1-h, mode="full")`
`T = correlate(d, 1-h, mode="full") - correlate(h, d, mode="full")`
`C = correlate(d, d, mode="full")`
