Actually, thinking more carefully about the gradient:

For lag s (centered), the row value is:
R_s = sum_{i=0}^{n-|s|-1} h[i+s] * (1-h[i])  (for s >= 0)

The gradient with respect to h[j]:
- If s >= 0:
  - h[j] appears in term h[j] * (1-h[j-s]) if j-s is valid → contributes (1-h[j-s])
  - h[j] appears in term h[j+s] * (1-h[j]) → contributes -h[j+s]
  - So ∂R_s/∂h[j] = (1-h[j-s])_valid - h[j+s]_valid

- If s < 0, let r = -s:
  - R_s = sum_{i=0}^{n-r-1} h[i] * (1-h[i+r])
  - h[j] appears as h[j] * (1-h[j+r]) → contributes (1-h[j+r])
  - h[j] appears as h[j-r] * (1-h[j]) → contributes -h[j-r]

Now for the LP approach, let me think about what makes this different from the gradient approach already in the code:

The gradient approach computes a weighted sum of active gradients and moves in the negative direction. The LP approach instead finds a direction that simultaneously reduces ALL active constraints, which is a LP program.

The key advantage: at a KKT point, the weighted gradient might be zero (or very small) because the active constraints are in conflict, but the LP might still find a direction that helps.

Wait, actually if the weighted gradient is zero, that's a signal that we're at a local minimum of the weighted sum, but not necessarily of the max. The LP would try to minimize the maximum increase, which is different.

Let me think about this differently. The problem is:
minimize max_s R_s(h)
subject to 0 <= h[i] <= 1, sum(h) = n/2

This is a nonconvex problem (R_s is not convex in h). But locally, we can linearize.

At a local minimum h*, for any feasible direction d:
- If d decreases R_s for all active s, great
- If d increases some active R_s but decreases others, the max might still decrease if the ones that increase aren't active

The LP approach:
minimize t
subject to: g_i @ d <= 0 for all active i (first-order decrease)
           sum(d) = 0
           -u[i] <= d[i] <= u[i]
           t is auxiliary

Wait, if we require g_i @ d <= 0 for ALL active i, that's too restrictive. We should allow some to increase slightly:
minimize max_i (g_i @ d)
subject to sum(d) = 0, box constraints

This is the standard minimax LP. The optimal value tells us the best we can do in first order. If it's negative, we have an improving direction.

Let me formalize:
minimize t
subject to: g_i @ d - t <= 0 for i in active_set
            sum(d) = 0
            -u[i] <= d[i] <= u[i] for all i

Variables: d[0..n-1], t
Constraints: M + 1 + 2n inequalities/equalities

For n=122, M~20: 245 variables + t = 245, about 265 constraints. Very fast LP.

I'll use scipy.optimize.linprog with method='highs' (default, fast).

Then after getting direction d, I do exact line search:
f(α) = max(R0 + α*(A-B) - α²*C) * dx
where A = correlate(d, 1-h, 'full'), B = correlate(h, d, 'full'), C = correlate(d, d, 'full')

This is a 1D nonconvex problem (envelope of quadratics), so I need to be careful. I'll use the golden section method with the full vector evaluation.

import numpy as np
import time
from scipy.optimize import linprog

def c5_exact(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo, hi = float(v.min()) - 2.0, float(v.max()) + 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-13:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _golden_pair(h, i, j, dx, S0):
    n = len(h)
    lo = -min(h[j], 1.0 - h[i])
    hi = min(h[i], 1.0 - h[j])
    if hi - lo < 1e-14:
        return 0.0, c5_exact(h)
    d = np.zeros(n)
    d[i] = -1.0
    d[j] = 1.0
    T = np.correlate(d, 1.0 - h, 'full') - np.correlate(h, d, 'full')
    C = np.correlate(d, d, 'full')
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    a, b = lo, hi
    c1 = b - gr * (b - a)
    c2 = a + gr * (b - a)
    f1 = float(np.max(S0 + c1 * T - c1 * c1 * C)) * dx
    f2 = float(np.max(S0 + c2 * T - c2 * c2 * C)) * dx
    for _ in range(40):
        if b - a < 1e-13:
            break
        if f1 < f2:
            b, c2, f2 = c2, c1, f1
            c1 = b - gr * (b - a)
            f1 = float(np.max(S0 + c1 * T - c1 * c1 * C)) * dx
        else:
            a, c1, f1 = c1, c2, f2
            c2 = a + gr * (b - a)
            f2 = float(np.max(S0 + c2 * T - c2 * c2 * C)) * dx
    opt = (a + b) / 2.0
    val = float(np.max(S0 + opt * T - opt * opt * C)) * dx
    f_lo = float(np.max(S0 + lo * T - lo * lo * C)) * dx
    f_hi = float(np.max(S0 + hi * T - hi * hi * C)) * dx
    if f_lo < val:
        opt, val = lo, f_lo
    if f_hi < val:
        opt, val = hi, f_hi
    return opt, val

def _compute_row_grads(h):
    """Compute gradients of ALL rows with respect to h. Returns array of shape (2n-1, n)."""
    n = len(h)
    grads = np.zeros((2 * n - 1, n))
    for k in range(2 * n - 1):
        d = k - (n - 1)
        m = n - abs(d)
        if m <= 0:
            continue
        if d >= 0:
            if d == 0:
                grads[k, :m] = 1.0 - 2.0 * h[:m]
            else:
                grads[k, :m] += (1.0 - h[d:d + m])
                grads[k, d:d + m] += -h[:m]
        else:
            g = -d
            if g == 0:
                grads[k, :] = 1.0 - 2.0 * h[:]
            else:
                grads[k, g:] += (1.0 - h[:m])
                grads[k, :m] += -h[g:g + m]
    return grads

def _lp_direction(h, n_active, step_size):
    """Solve LP to find a direction minimizing max gradient dot product on active rows."""
    n = len(h)
    dx = 2.0 / n
    S0 = np.correlate(h, 1.0 - h, mode='full')
    scores = S0 * dx
    max_score = float(np.max(scores))
    
    # Select active rows: those within some fraction of max
    threshold = max_score - 0.01 * max_score
    active_mask = scores >= threshold
    active_idx = np.where(active_mask)[0]
    
    # If too many, take top n_active
    if len(active_idx) > n_active:
        top_scores = scores[active_idx]
        order = np.argsort(-top_scores)[:n_active]
        active_idx = active_idx[order]
    
    if len(active_idx) == 0:
        return None
    
    # Compute gradients for active rows
    G = np.zeros((len(active_idx), n))
    for k, r in enumerate(active_idx):
        d = r - (n - 1)
        m = n - abs(d)
        if m <= 0:
            continue
        if d >= 0:
            if d == 0:
                G[k, :m] = 1.0 - 2.0 * h[:m]
            else:
                G[k, :m] += (1.0 - h[d:d + m])
                G[k, d:d + m] += -h[:m]
        else:
            g = -d
            if g == 0:
                G[k, :] = 1.0 - 2.0 * h[:]
            else:
                G[k, g:] += (1.0 - h[:m])
                G[k, :m] += -h[g:g + m]
    
    # Normalize gradients by n for numerical stability
    G = G / n
    
    # Build LP:
    # Variables: d[0..n-1], t  (total n+1 variables)
    # Objective: minimize t
    # Constraints:
    #   G @ d - t <= 0  (M constraints)
    #   sum(d) = 0  (1 equality)
    #   -u[i] <= d[i] <= u[i]  (2n constraints)
    #   sum(|d|) <= step_size  → use split: a+b <= step_size where d=a-b
    #     Actually, let's just use box + L1 via additional constraint
    #     sum(d) + 2*sum(max(-d,0)) <= step_size
    #     This requires split variables...
    
    # Simpler: just use box constraints and sum(d)=0, scale d afterward
    # Or use: -step_size/(2*sqrt(n)) <= d[i] <= step_size/(2*sqrt(n))
    # and sum(d) = 0
    
    # Actually, let's use split variables for L1 constraint
    # Variables: a[0..n-1], b[0..n-1], t  (2n+1 variables)
    # d = a - b
    # Objective: minimize t
    # Constraints:
    #   G@(a-b) - t <= 0  (M constraints)
    #   sum(a) - sum(b) = 0  (1 equality)
    #   a[i] >= 0, b[i] >= 0 (built into linprog)
    #   a[i] + b[i] <= u[i] (n constraints, ensures |d[i]| <= u[i])
    #   sum(a) + sum(b) <= step_size (1 constraint)
    
    M = len(active_idx)
    nvar = 2 * n + 1  # a, b, t
    
    # Objective: minimize t
    c_obj = np.zeros(nvar)
    c_obj[-1] = 1.0  # t is last variable
    
    # Inequality constraints: A_ub @ vars <= b_ub
    # G@(a-b) - t <= 0  →  G@a + (-G)@b - t <= 0
    A_ub_parts = []
    b_ub_parts = []
    
    # First M constraints: G@(a-b) - t <= 0
    A1 = np.zeros((M, nvar))
    A1[:, :n] = G       # G @ a
    A1[:, n:2*n] = -G   # -G @ b
    A1[:, -1] = -1.0    # -t
    A_ub_parts.append(A1)
    b_ub_parts.append(np.zeros(M))
    
    # a[i] + b[i] <= u[i] for each i
    u = np.minimum(h, 1.0 - h)  # max displacement at each coordinate
    A2 = np.zeros((n, nvar))
    for i in range(n):
        A2[i, i] = 1.0
        A2[i, n + i] = 1.0
    A_ub_parts.append(A2)
    b_ub_parts.append(u)
    
    # sum(a) + sum(b) <= step_size
    A3 = np.zeros((1, nvar))
    A3[0, :n] = 1.0
    A3[0, n:2*n] = 1.0
    A_ub_parts.append(A3)
    b_ub_parts.append(np.array([step_size]))
    
    A_ub = np.vstack(A_ub_parts)
    b_ub = np.concatenate(b_ub_parts)
    
    # Equality: sum(a) - sum(b) = 0
    A_eq = np.zeros((1, nvar))
    A_eq[0, :n] = 1.0
    A_eq[0, n:2*n] = -1.0
    b_eq = np.array([0.0])
    
    # Bounds: a >= 0, b >= 0, t unbounded below (or -inf)
    bounds = [(0, None)] * (2 * n) + [(None, None)]
    
    try:
        res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq, 
                      bounds=bounds, method='highs')
    except Exception:
        return None
    
    if res.status != 0:
        return None
    
    d = res.x[:n] - res.x[n:2*n]
    if np.max(np.abs(d)) < 1e-12:
        return None
    
    # Normalize direction
    norm_d = np.sum(np.abs(d))
    if norm_d < 1e-12:
        return None
    d = d / norm_d
    
    return d

def _exact_line_search(h, d, dx, S0, n_iter=50):
    """Exact 1D line search along direction d."""
    T = np.correlate(d, 1.0 - h, 'full') - np.correlate(h, d, 'full')
    C = np.correlate(d, d, 'full')
    
    # Find feasible range for alpha
    pos = d > 1e-10
    neg = d < -1e-10
    lo, hi = 0.0, 1.0
    if np.any(pos):
        hi = min(hi, float(np.min((1.0 - h[pos]) / d[pos])))
    if np.any(neg):
        lo = max(lo, float(np.max(h[neg] / d[neg])))
    
    if hi - lo < 1e-14:
        return 0.0, float(np.max(S0)) * dx
    
    # Also check if going negative helps (alpha < 0)
    # Actually let's search in [lo, hi]
    # But also try negative direction
    # Let's just do golden section on [lo, hi]
    
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    a, b = lo, hi
    c1 = b - gr * (b - a)
    c2 = a + gr * (b - a)
    f1 = float(np.max(S0 + c1 * T - c1 * c1 * C)) * dx
    f2 = float(np.max(S0 + c2 * T - c2 * c2 * C)) * dx
    
    for _ in range(n_iter):
        if b - a < 1e-12:
            break
        if f1 < f2:
            b, c2, f2 = c2, c1, f1
            c1 = b - gr * (b - a)
            f1 = float(np.max(S0 + c1 * T - c1 * c1 * C)) * dx
        else:
            a, c1, f1 = c1, c2, f2
            c2 = a + gr * (b - a)
            f2 = float(np.max(S0 + c2 * T - c2 * c2 * C)) * dx
    
    opt = (a + b) / 2.0
    val = float(np.max(S0 + opt * T - opt * opt * C)) * dx
    
    # Check endpoints
    f_lo = float(np.max(S0 + lo * T - lo * lo * C)) * dx
    f_hi = float(np.max(S0 + hi * T - hi * hi * C)) * dx
    if f_lo < val:
        opt, val = lo, f_lo
    if f_hi < val:
        opt, val = hi, f_hi
    
    return opt, val

def _gradient_polish(h, deadline, n_active=15):
    """LP-guided gradient polish."""
    n = len(h)
    target = n / 2.0
    dx = 2.0 / n
    cur_c5 = c5_exact(h)
    best_h = h.copy()
    best_c5 = cur_c5
    S0 = np.correlate(h, 1.0 - h, mode='full')
    stall = 0
    
    while time.time() < deadline and stall < 40:
        d = _lp_direction(h, n_active, 1.0)
        if d is None:
            break
        
        opt, val = _exact_line_search(h, d, dx, S0)
        
        if opt > 1e-10 and val < cur_c5 - 1e-14:
            h = h + opt * d
            h = project(h, target)
            cur_c5 = c5_exact(h)
            S0 = np.correlate(h, 1.0 - h, mode='full')
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            stall = 0
        else:
            stall += 1
    
    return best_h, best_c5

def _directed_pair_search(h, n_pairs, deadline):
    """Directed pair moves targeting active peaks."""
    n = len(h)
    target = n / 2.0
    dx = 2.0 / n
    cur_c5 = c5_exact(h)
    best_h = h.copy()
    best_c5 = cur_c5
    S0 = np.correlate(h, 1.0 - h, mode='full')
    stall = 0
    rng = np.random.default_rng(777)
    
    while time.time() < deadline and stall < 100:
        scores = S0 * dx
        max_score = float(np.max(scores))
        threshold = max_score - 0.005 * max_score
        active_idx = np.where(scores >= threshold)[0]
        if len(active_idx) == 0:
            active_idx = np.argsort(-scores)[:10]
        
        # Compute weighted gradient
        grads = np.zeros(n)
        for r in active_idx:
            d = r - (n - 1)
            m = n - abs(d)
            if m <= 0:
                continue
            if d >= 0:
                if d == 0:
                    grads[:m] += 1.0 - 2.0 * h[:m]
                else:
                    grads[:m] += (1.0 - h[d:d + m])
                    grads[d:d + m] += -h[:m]
            else:
                g = -d
                if g == 0:
                    grads[:] += 1.0 - 2.0 * h[:]
                else:
                    grads[g:] += (1.0 - h[:m])
                    grads[:m] += -h[g:g + m]
        
        donor_pool = np.argsort(-grads)[:n_pairs]
        recv_pool = np.argsort(grads)[:n_pairs]
        
        best_alpha = 0.0
        best_new_c5 = cur_c5
        best_pair = None
        found = False
        
        tried = set()
        for i in donor_pool:
            if time.time() > deadline:
                break
            for j in recv_pool:
                if i == j:
                    continue
                key = (min(i, j), max(i, j))
                if key in tried:
                    continue
                tried.add(key)
                alpha, new_c5 = _golden_pair(h, i, j, dx, S0)
                if alpha > 1e-10 and new_c5 < best_new_c5 - 1e-14:
                    best_new_c5 = new_c5
                    best_alpha = alpha
                    best_pair = (i, j)
                    found = True
        
        if found and best_new_c5 < cur_c5 - 1e-13:
            i, j = best_pair
            h[i] -= best_alpha
            h[j] += best_alpha
            h = project(h, target)
            cur_c5 = c5_exact(h)
            S0 = np.correlate(h, 1.0 - h, mode='full')
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            stall = 0
        else:
            stall += 1
            if stall > 20 and rng.random() < 0.3:
                idx = rng.integers(n, size=4)
                for idx_k in idx:
                    h[idx_k] += rng.uniform(-0.05, 0.05)
                h = project(h, target)
                cur_c5 = c5_exact(h)
                S0 = np.correlate(h, 1.0 - h, mode='full')
                stall = 0
    
    return best_h, best_c5

def _resample(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return project(h_new, n_new / 2.0)

def _sine_init(n, freq, phase):
    x = np.arange(n)
    h = 0.5 + 0.45 * np.sin(2 * np.pi * freq * x / n + phase)
    return project(h, n / 2.0)

def _random_pair_search(h, deadline, rng, T_init=0.003):
    """Random pair search with simulated annealing."""
    n = len(h)

    """Gradient of row k with respect to h."""
    n = len(h)
    d = k - (n - 1)
    m = n - abs(d)
    g = np.zeros(n)

        return g

def _lp_direction(h, n_active, frac, step_scale):

    n = len(h)

    if len(active_idx) > n_active:
        svals = scores_c[active_idx]
        order = np.argsort(-svals)[:n_active]
        active_idx = active_idx[order]
    if len(active_idx) == 0:
        return None

    # Build gradient matrix
    G = np.zeros((len(active_idx), n))
    for k, r in enumerate(active_idx):
        G[k] = _compute_row_grad(h, r) / n

    M = len(active_idx)
    nvar = 2 * n + 1
    c_obj = np.zeros(nvar)
    c_obj[-1] = 1.0

    # G@(a-b) - t <= 0
    A1 = np.zeros((M, nvar))

    A1[:, n:2*n] = -G
    A1[:, -1] = -1.0

    A2 = np.zeros((n, nvar))

        A2[i, i] = 1.0
        A2[i, n+i] = 1.0

    A3 = np.zeros((1, nvar))

    A_eq = np.zeros((1, nvar))
    A_eq[0, :n] = 1.0

def _gradient_direction(h, n_active, frac):
    """Weighted gradient direction (fallback if LP fails)."""
    n = len(h)
    S0 = np.correlate(h, 1.0 - h, mode='full')
    scores = S0
    max_s = float(np.max(scores))
    threshold = max_s - frac * max_s
    active_idx = np.where(scores >= threshold)[0]
    if len(active_idx) > n_active:
        sv = scores[active_idx]
        order = np.argsort(-sv)[:n_active]
        active_idx = active_idx[order]
    if len(active_idx) == 0:
        return None
    w = np.exp((scores[active_idx] - max_s) / (0.01 * max_s + 1e-15))
    w /= np.sum(w)
    g = np.zeros(n)
    for k, r in enumerate(active_idx):
        g += w[k] * _compute_row_grad(h, r)
    g -= np.mean(g)
    gn = np.linalg.norm(g)
    if gn < 1e-14:
        return None
    return -g / gn

    val = float(np.max(S0 + opt * T - opt * opt * C)) * dx
    f_lo = float(np.max(S0 + lo * T - lo * lo * C)) * dx
    f_hi = float(np.max(S0 + hi * T - hi * hi * C)) * dx
    if f_lo < val:
        opt, val = lo, f_lo
    if f_hi < val:
        opt, val = hi, f_hi
    return opt, val

def _combined_polish(h, deadline):
    """Interleave LP and gradient directions."""
    n = len(h)
    target = n / 2.0
    dx = 2.0 / n
    cur_c5 = c5_exact(h)
    best_h = h.copy()
    best_c5 = cur_c5
    S0 = np.correlate(h, 1.0 - h, mode='full')
    stall = 0
    use_lp = True

    while time.time() < deadline and stall < 80:
        if use_lp:
            d = _lp_direction(h, 15, 0.01, 1.0)
        else:
            d = _gradient_direction(h, 15, 0.01)

        if d is None:
            use_lp = not use_lp
            stall += 1
            continue

        if use_lp:
            opt, val = _line_search(h, d, dx, S0)
        else:
            opt, val = _grad_line_search(h, d, dx, S0)

        if abs(opt) > 1e-10 and val < cur_c5 - 1e-15:
            h = h + opt * d
            h = project(h, target)
            cur_c5 = c5_exact(h)
            S0 = np.correlate(h, 1.0 - h, mode='full')
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            stall = 0
            use_lp = not use_lp
        else:
            stall += 1
            use_lp = not use_lp
    return best_h, best_c5

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    rng = np.random.default_rng(seed)
    deadline = t0 + budget_s * 0.97

    try:
        h0 = np.array(initial_h_values, dtype=float)
        n0 = len(h0)
    except NameError:
        n0 = 122
        h0 = _sine_init(n0, 2, 0.5)

    h = project(h0, n0 / 2.0)
    best_h = h.copy()
    best_c5 = c5_exact(h)
    best_n = n0

    # Phase 1: Combined LP+gradient polish (35%)
    d1 = t0 + budget_s * 0.35
    h_p1, c5_p1 = _combined_polish(h, d1)
    if c5_p1 < best_c5:
        best_c5 = c5_p1
        best_h = h_p1.copy()

    # Phase 2: Directed pair search (20%)
    d2 = t0 + budget_s * 0.55
    h_p2, c5_p2 = _directed_pair_search(best_h, 25, d2)
    if c5_p2 < best_c5:
        best_c5 = c5_p2
        best_h = h_p2.copy()

    # Phase 3: Multi-resolution (20%)
    d3 = t0 + budget_s * 0.75
    tried_n = {best_n}
    for dn in [-4, 4, -6, 6, -2, 2, -8, 8, -10, 10]:
        if time.time() > d3:
            break
        n_try = best_n + dn
        if n_try < 20 or n_try > 250 or n_try % 2 != 0:
            continue
        if n_try in tried_n:
            continue
        tried_n.add(n_try)
        h_r = _resample(best_h, n_try)
        sub_dl = min(d3, time.time() + budget_s * 0.02)
        h_r, c5_r = _directed_pair_search(h_r, 15, sub_dl)
        if c5_r < best_c5:
            sub_dl2 = min(d3, time.time() + budget_s * 0.015)
            h_r, c5_r = _combined_polish(h_r, sub_dl2)
            if c5_r < best_c5:
                best_c5 = c5_r
                best_h = h_r.copy()
                best_n = n_try

    # Phase 4: Random SA diversification (10%)
    d4 = t0 + budget_s * 0.85
    h_p4, c5_p4 = _random_sa(best_h, d4, rng, T_init=0.002)
    if c5_p4 < best_c5:
        best_c5 = c5_p4
        best_h = h_p4.copy()

    # Phase 5: Final combined polish (12%)
    d5 = deadline
    h_p5, c5_p5 = _combined_polish(best_h, d5)
    if c5_p5 < best_c5:
        best_c5 = c5_p5
        best_h = h_p5.copy()

    # Final directed micro-adjust
    h_f1, c5_f1 = _directed_pair_search(best_h, 30, deadline)
    if c5_f1 < best_c5:
        best_c5 = c5_f1
        best_h = h_f1.copy()

    h_f2, c5_f2 = _combined_polish(best_h, deadline)
    if c5_f2 < best_c5:
        best_c5 = c5_f2
        best_h = h_f2.copy()

    # Ensure validity
    best_h = project(best_h, len(best_h) / 2.0)
    final_c5 = c5_exact(best_h)
    return best_h, final_c5, len(best_h)
