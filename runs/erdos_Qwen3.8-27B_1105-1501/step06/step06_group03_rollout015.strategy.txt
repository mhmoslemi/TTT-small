1. Approach and rationale

The supplied parent is already an excellent local point, so a direct re-run of the previous active-LP or pair-search machinery is unlikely to be enough. The bottleneck is not simply low-level speed but basin quality: the exact objective is the maximum over many finite-support cross-correlation terms, and any single local method quickly gets trapped by a small set of currently active overlaps. The proposed method is materially different in that it optimizes a smoothed overlap envelope by proximal/Frank–Wolge-like moves on the truncated sum simplex, while accepting moves only after exact evaluation of the supplied correlation objective. It does not try to solve a convex relaxation for a certified optimum; it uses the envelope only to generate candidate directions (soft-gradient, linear-oracle vertices, proximal water-filling steps, and mass-exchange coordinates), and it uses the authoritative evaluator to reject every bad move. This should generate more structurally diverse feasible points than repeated small LP/radius walks, while preserving validity.

Main premises and limitations:
1. The method remains local/stochastic. It is not a proof of optimality and cannot claim global optimality.
2. The smooth envelope is only a heuristic search bias. A candidate is accepted only if the true evaluator improves the maximum overlap.
3. It relaxes feasibility through a jointly safe truncated hyperplane projection. Since the feasible set is exactly `{h: 0 <= h_i <= 1, sum h_i = n/2}`, every returned vector is jointly feasible unless final numerical correction is explicitly applied and then re-evaluated.
4. If the method fails, the valid parent supplied via `initial_h_values` is retained and returned.

Primary method followed by coherent material additions:
1. **Main primary method**: population of feasible continuous vectors evolved using a smoothed log-sum-exp correlation envelope. Candidate moves are proximal water-filling steps, Frank–Wolge linear-oracle directions, and exact tangent gradient directions.
2. **Search rejection**: every direction receives a nonlinear line search over the exact full-support correlation model, giving an internal candidate alpha before feasibility repair. Acceptance requires exact improvement of the true objective after joint projection repair.
3. **Escapism**: adaptive randomized restarts, binary projection seeds, weighted pair/higher mass-exchange directions, resolution re-sampling, and global migration between population members.
4. **Strict global policy**: a valid parent fallback is always stored; the final returned objective is never worse than the verified parent unless another exact objective value has actually improved and then survived final exact validation.

2. Mathematical specification

2.1 Variables, exact evaluator, and feasible set

For `n = n_points` samples and `dx = 2.0/n`, variables are

`h_j ∈ [0,1], j=0,...,n-1`.

The constraint is

`Σ_j h_j = n/2`.

If `n` is even, the target sum is integer; if odd, it is half-integer. Every helper must use the same target `nu = n/2.0`.

The authoritative scalar evaluator must be computed exactly as:

`dx = 2.0/n`
`S_full = np.correlate(h, 1.0 - h, mode='full')`
`C5(h) = dx * max(S_full)`.

This assumes no circular wrap. There are `L = 2*n - 1` correlation terms. Define for output index `r=0,...,L-1` a signed lag

`k = r - (n-1)`, with `k ∈ [-(n-1), n-1]`.

To match NumPy's full correlation used by the evaluator, use scaled correlations

`q_k(h) = dx * Σ` over the finite overlap:

- For `k >= 0`:
  `q_k = dx * Σ_{i=0}^{n-k-1} h_{i+k} * (1 - h_i)`.

- For `k < 0`, let `d = -k >= 0`:
  `q_k = dx * Σ_{i=0}^{n-d-1} h_i * (1 - h_{i+d})`.

For `k=0`, this reduces to `dx Σ_i h_i(1-h_i)`. The positive-lag and negative-lag arrays need not be symmetric; the evaluator checks both.

2.2 Joint feasibility projection

For any array `z`, define `Project(z, nu)`:

1. If `nu <= 0`, return zeros.
2. If `nu >= n`, return ones.
3. Compute a scalar shift `theta` by bisection/inversion of
   `φ(t) = Σ_i clip(z_i - t, 0, 1)`.
   Bracket a very wide interval around `min(z)-2, max(z)+2`; 80 iterations gives a scalar `theta`.
4. Set `x_i = clip(z_i - theta, 0, 1)`.
5. Let `gap = nu - Σ_i x_i`.
   If `|gap| > 1e-11`, repair without leaving the box:
   - For `gap > 0`, add `gap / number_of_indices_with_x_i < 1` to those entries outside 1, iterating until the target or clipped.
   - For `gap < 0`, subtract from entries outside 0.
   Repeat up to 40 fallback passes; either the exact target in floating-point precision or exactly enough elements to adjust.

The resulting array must satisfy bounds and sum inside an absolute tolerance `<= 1e-10` (`1e-12` if achievable).

Because the constraint target `nu` is a scalar multiple of n, this is a joint mechanism. Naively clipping and then renormalizing is forbidden; it may violate bounds or sum.

2.3 Tangent directions and ray model

For any direction `p` with approximately `Σ_i p_i = 0`, proposed raw vectors are

`h(α) = h + α p`.

Exact pointwise feasibility along the ray requires the interval

`α_min = max_{i: p_i < 0} (-h_i/p_i)`
`α_max = min_{i: p_i > 0} ((1-h_i)/p_i)`.

If `|p_i| < 1e-14` ignore, boundary entries at zero or one naturally force `0` if needed. Cap with a trust interval `[-R,R]` after computing the safe interval.

Even if `Σ p` has floating residual, raw `h+αp` might not satisfy the target; acceptance always repairs and exactly re-evaluates. For the quadratic ray formula, excluding the sum constraint, the exact correlation along the raw ray satisfies:

`S_unscaled(α) = corr(h, 1-h, 'full') + α [corr(p, 1-h, 'full') - corr(h, p, 'full')] - α^2 corr(p, p, 'full')`.

Define arrays:
- `S0 = np.correlate(h, 1-h, 'full')`
- `L深厚 = np.correlate(p, 1-h, 'full') - np.correlate(h, p, 'full')`
- `Q = np.correlate(p, p, 'full')`

Then the scaled objective is

`F_raw(α) = max_r dx * (S0.rar + α Lσ(arr) - α^2 Q.rar)`.

This formula is independent of the feasibility projection and is used only to choose α for a raw candidate; final economics accepts projected exact candidates.

2.4 Differentiable correlation gradient

For generating smooth directions use exact gradients of `q_k` (scaled dx) but do not use the gradient to accept anything automatically. For selected row `r` (or lag `k`) and weight `w_r`:

If `k >= 0`:
Let `m=n-k`. For all `i=0,...,m-1`:
- add `dx * w_r` to `grad[i+k]` from the term `h_{i+k}(1-h_i)`
- add `-dx * w_r * h_{i+k}` to `grad[i]`.

Equivalently:
`grad[k:] += dx*w_r*(1 - h[:m])`
`grad[:m] -= dx*w_r*h[k:]`.

If `k < 0`, `d=-k`, `m=n-d`:
`grad[:m] += dx*w_r*(1 - h[d:d+m])`
`grad[d:] -= dx*w_r*h[:m]`.

The full gradient must include all boundary terms above; do not replace it by one interior periodic formula.

2.5 Smooth envelope and soft weights

The true minimax objective is:

`F(h) = max_k q_k(h)`, scaled `C5`.

Use log-sum-exp smoothing with weights oriented by current evaluated scaled correlations:

1. Compute scaled `S_arr` and accuracy `M=max(S_arr)`.
2. Choose at most `K` top indices by `S_arr`; implement `K = min(70, max(20, (2*n-1)//3))`, weighted result changes `n`.
3. Set temperature `β = soft_temp * C_cur` with default schedule, see section 4.
4. For all 2n terms conceptually weight `exp((S_arr-M)/β)`, but if subnormal discard small terms and renormalize from top `K`.
5. Let `g_soft = Σ_r λ_r ∇q_r(h)`.
6. Turn it into tangent direction by subtracting mean: `g_tau = g_soft - mean(g_soft)`.

The soft envelope is not equal to `C5`; no proof is claimed. The top constraints/forcing information guides direction, and exact candidate evaluation controls actual final outcome. Direction is heuristically intended to lower all likely maximal correlations.
