For fixed i and j, Δc[n-1+k] = A(i,k) - A(j,k) is a vector of length 2n-1 that can be computed in O(n) (actually O(n) since each A is nonzero for at most n lags).

The new correlation is c_new = c + Δ, and the new C₅ is (2/n) * max(c_new).

The key question is: can I quickly determine if max(c_new) < current_max?

If current_max is at lag k*, then I need to check if c_new[k*] < current_max (necessary but not sufficient). If c_new[k*] < current_max, I still need to check if any other lag exceeds current_max.

A fast approach: 
1. Compute Δ = A(i,k) - A(j,k) for all k (O(n))
2. Check if max(c + Δ) < current_max

   - Otherwise, need to check all k: max(c + Δ)

```python
def _project(v, target):
    # Water-filling projection to sum=target, 0<=x<=1
    n = len(v)
    lo, hi = float(v.min()) - 1.0, float(v.max()) + 1.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)

    if abs(res) > 1e-10:

        else:

        cnt = int(np.sum(mask))

            x[mask] += res / cnt
    return np.clip(x, 0.0, 1.0)

            T = 0.01
            stuck = 0
            best_stuck = 0
```

```python
def _compute_A(h, p):
    """Compute A(p, k) for all k, returns array of length 2n-1."""
    n = len(h)
    A = np.zeros(2*n-1)
    # First term: h[p+k] for valid k
    # k ranges from -p to n-1-p
    lo1 = max(0, p - (n-1))  # k >= -(n-1)
    hi1 = min(2*n-2, p + n-1)  # k <= n-1, so k+n-1 <= 2n-2
    # Actually, k ranges from -(n-1) to n-1, index in A is k+(n-1)
    # h[p+k] is valid when 0 <= p+k < n, i.e., -p <= k <= n-1-p
    # Index range: -p+(n-1) to n-1-p+(n-1) = 2n-2-p
    start1 = max(0, -p + (n-1))
    end1 = min(2*n-1, (n-1-p) + (n-1) + 1)
    if start1 < end1:
        A[start1:end1] += h[p : p + (end1 - start1)]
    
    # Second term: -(1-h[p-k]) for valid k
    # h[p-k] is valid when 0 <= p-k < n, i.e., p-(n-1) <= k <= p
    # Index range: p-(n-1)+(n-1) to p+(n-1) = p to p+n-1
    start2 = max(0, (p-(n-1)) + (n-1))  # = max(0, p)
    end2 = min(2*n-1, p + (n-1) + 1)
    if start2 < end2:
        # h[p-k] for k from (start2-(n-1)) to (end2-1-(n-1))
        # = h from p-(start2-(n-1)) to p-(end2-1-(n-1))
        # = h from p-start2+n-1 to p-end2+n
        h_slice_start = p - (start2 - (n-1))
        h_slice_end = p - (end2 - 1 - (n-1)) + 1
        A[start2:end2] -= (1.0 - h[h_slice_start:h_slice_end][::-1])
    
    return A
```

```python
    n = len(h)
    # A index m corresponds to k = m - (n-1)
    # A[m] = h[p+k] (if 0<=p+k<n) - (1-h[p-k]) (if 0<=p-k<n)
    # where k = m - (n-1)
    # p+k = p + m - (n-1), valid when 0 <= p+m-(n-1) < n
    # p-k = p - m + (n-1), valid when 0 <= p-m+(n-1) < n
    A = np.zeros(2*n-1)
    # First part: h[p+k] = h[p + m - (n-1)]
    # Valid m: 0 <= p+m-(n-1) < n => (n-1)-p <= m <= n-1+p
    m_lo = max(0, (n-1) - p)
    m_hi = min(2*n-1, n-1+p+1)
    if m_lo < m_hi:
        h_idx_lo = p + m_lo - (n-1)
        A[m_lo:m_hi] += h[h_idx_lo : h_idx_lo + (m_hi-m_lo)]
    # Second part: -(1-h[p-k]) = -(1-h[p-m+(n-1)])
    # Valid m: 0 <= p-m+(n-1) < n => p-n+1 <= m <= p+n-1
```
