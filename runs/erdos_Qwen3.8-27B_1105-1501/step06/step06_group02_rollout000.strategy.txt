1. Approach and rationale

1.1 Central new idea

The supplied parent construction was produced primarily by coordinate-wise pair transfers, Fourier-like initializations, and small active-row directional probes. Those methods reduce one or two currently high correlation rows at a time and therefore can stall in a flat minimax plateau, where several row values are nearly tied and the objective improvement must be made by moving mass simultaneously through a coordinated combination of many coordinates.

The proposed materially different approach is to optimize a **dimension-minimax soft epigraph formulation** over the full feasible vector `h`:

Find `h` satisfying

0 <= h_i <= 1,    sum_i h_i = n / 2,

and minimize the instantaneous soft maximum over all `2n - 1` linear-lag overlap values

  R_k(h) = sum_i h_i (1 - h_{i+d(k)})

for all centered lags `d(k) = 0, 1, -1, 2, -2, ..., +/- (n-1)`.

The actual accepted value remains exactly the evaluator purple:

  C5(h) = max_k R_k(h) * (2/n)

where `R` is generated by the evaluator-defined full noncircular linear correlation. The optimization variables are fixed by runtime inputs, and no circular simplification or autocorrelation identity replaces the finite-boundary linear overlap.

The new machinery consists of three interacting components:

- a global or semiglobal low-dimensional Fourier harmonic search, not to produce the final construction directly unless it unexpectedly is best, but to provide diverse feasible parent and coarser starting points;
- a soft-max epigraph local solver using `scipy.optimize.minimize` with an analytic gradient, targeting row levels below the current best and annealing the smoothing parameter through several temperature/pre-compression stages;
- an exact line-search intensifier using the exact quadratic expansion in any feasible direction, followed by the original evaluator.

This is not merely another greedy pair search or another preliminary initial perturbation. The core is **simultaneous all-lag peak equalization**: the smooth objective aggregates all active peaks into one differentiable surrogate, so a single BFGS or SLSQP step changes many coordinates according to a shared direction. Exact all-row evaluation determines whether the suggested move is accepted.

1.2 Why it can improve the parent

At a plateau such as `C5 ~= 0.38089`, the current objective may be dominated by several rows, not one. A greedy coordinate move changes a pair or four coordinates and often exchanges one peak for another. A smooth log-sum-exp objective, in contrast, gives simultaneous pressure from every row near the universal maximum. A differentiable approximation is still nonconvex; no global optimum is claimed. But a full-dimensional BFGS/SLSQP path is markedly richer and can escape one-dimensional pair moves. The exact line search and exact acceptance make every accepted candidate honest against the supplied evaluator.

The low-dimensional harmonic search is separately motivated: it can generate smooth anti-correlated steps with periodic or dashed structures not naturally present in a neighboring local path, and it exposes starting basins to the local soft-max solver. Also, a coarse grid can be a legitimate final candidate if its exact evaluator score is lower and it is smaller.

1.3 Limitations and status

The problem remains bilinear and nonconvex. Smooth methods, harmonic restrictions, target updates, and stochastic line search do not certify optimality or prove any new bound except through exact evaluation of the returned sample. If no valid candidate improves the parent, the parent is kept. Claims are heuristic, with all correctness based on independently recomputing the evaluator's `C5` after each candidate repair.

2. Mathematical specification

2.1 Representation and exact discrete objective

Let `n` be any even or runtime-created number of sampling points, with `dx = 2.0 / n`. Decisively:

- input vector `h = (h_0, ..., h_{n-1})`;
- input constraint is `sum_i h_i = n / 2`;
- the formal overlap vector is exactly

  R_raw = correlate(h, 1 - h, mode="full") * dx

- the accepted output is

  C5(h) = max(R_raw)

where `correlate(..., mode="full") * dx` must be done once for the returned candidate. `R_raw` has length `2n - 1`, with equal boundary truncations.

For implementation of gradients, define the centered index

  idx = 0, 1, ..., 2n-2
  d(idx) = idx - (n-1)

The orientation matched to NumPy's generic `correlate(a, b, mode="full")` is

  R_d = sum_{i: 0 <= i < n and 0 <= i + d < n} h_i * (1 - h_{i+d}).

This is the signed-lag convention in which a positive lag is `b` shifted right relative to `a`. For `n=2`, the returned full array under NumPy is approximately

  index 0: h_1 (1 - h_0)
  index 1: h_0 (1 - h_0) + h_1 (1 - h_1)
  index 2: h_0 (1 - h_1)

which corresponds to `d = -1, 0, +1`.

The physical domain index does not matter for row formulas: only vector order. Coordinate formulas for basis functions use physical midpoints solely for constructing starts, not for the evaluation.

2.2 Joint feasibility mechanism

The feasible set is the intersection of the box and sum hyperplane. Use a joint water-fill projection rather than repeated clip-then-rescale. Given any finite vector `v` and target `S = n/2`:

- If `S <= 0`, return zeros.
- If `S >= n`, return ones.
- Find a threshold `theta` such that

  sum_i clip(v_i - theta, 0, 1) = S.

  The function in `theta` is nonincreasing and continuous. Bisect `theta` for approximately sixty iterations over an interval known to bracket. Use an initial bracket from the minimum and maximum entries of `v`, with offsets large enough to cover the needed mass.

- After bisection, let `x = clip(v - theta, 0, 1)` and let `e = S - sum(x)`. If `|e| <= 1e-13`, return `x`. Otherwise distribute `e/n` only to coordinates strict inside `(0,1)`. If insufficient interior capacity exists, complete the one final restitution under monotone box-preserving limiting: choose interior indices and raise lower-saturation ones first if `e > 0`, choose high-saturation ones first if `e < 0`, then clamp any rounding overshoot proportional to exact capacity. Reapply bisection jointly if residual remains above `1e-9`.

At return, require `0 - 1e-9 <= h_i <= 1 + 1e-9` and `abs(sum(h) * dx - 1) <= 1e-9` after treating treated pair values only for correction; if the final formal evaluator array is returned, project again and re-evaluate with strict acceptance.

2.3 Exact directional line search identity

For a perturbation direction `p`, the exact unweighted rows satisfy

  R(alpha) =
      correlate(h, 1 - h, "full")
    + alpha * (correlate(p, 1 - h, "full") - correlate(h, p, "full"))
    - alpha^2 * correlate(p, p, "full").

Use raw `correlate` values without `dx`, then multiply the maximum by `dx` at the chosen alpha. Let

  A = correlate(p, 1-h, full)
  B = correlate(h, p, full)
  C = correlate(p, p, full)

so row envelope is

  q(alpha) = R0 + alpha * (A - B) - alpha^2 C.

If `p` is direction used in a line search, enforce its mean to be zero before the line search:

  p_i = p_i - sum(p) / n.

This preserves total sum prior to the slight final projection made feasible; after exact evaluation the candidate is projected jointly again.

The feasible alpha interval starting at zero for a candidate p is:

  high = min over i with p_i > 0 of (1 - h_i) / p_i;
  low  = max over i with p_i < 0 of -h_i / p_i, 0.

If the interval degenerates, do not attempt an alpha-line move. For positive alpha only, use `0` and `high`. For symmetric full line, include `low` and redplay `p` if needed.

Because `C_i` can have mixed signs, the maximum envelope is not guaranteed unimodal. Perform a bracket-then-local search: on interval `[0, high]`, evaluate thirty evenly spaced candidate alphas, locate the two lowest adjacent interval endpoints around the minimum, and execute thirty golden-section iterations in the bracketed subinterval. Always compare the endpoints of the full allowable interval exactly.
