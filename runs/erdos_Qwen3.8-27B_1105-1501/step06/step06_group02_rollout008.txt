The strategy is quite garbled in places, but the core idea is clear:

1. Use LP to generate multi-coordinate directions that lower multiple active (high) correlation rows simultaneously
2. Use exact line search along those directions
3. This is different from the previous approach which only used pair moves and gradient descent

Let me design a clean implementation:

Key ideas:
- LP direction finding: select top-K active rows, form a linear program that finds a zero-sum direction `p` (decomposed as `a - b` where `a, b >= 0`) that minimizes the predicted increase in those rows (or maximizes predicted decrease)
- Exact line search: once we have direction `p`, find optimal alpha via golden section on the exact objective
- Multiple strategies for selecting which rows to target
- Periodic resampling to different grid sizes
- Start from `initial_h_values` if available

Let me think about the LP formulation more carefully:

Given direction `p` (zero-sum, bounded by current h), the change in row `R_s` for small alpha is:
`R_s(alpha) ≈ R_s(0) + alpha * G_s`

where `G_s = sum of gradient contributions for row s` applied to `p`.

The gradient of row `s` with respect to `h_i` is:
- For `s >= 0`: `G_s = sum_{t=0}^{n-s-1} [(1-h[t])*p[t+s] - h[t+s]*p[t]]`
- For `s < 0`: let `r = -s`, `G_s = sum_{t=0}^{n-r-1} [(1-h[t+r])*p[t] - h[t]*p[t+r]]`

So `G_s = g_s · p` where `g_s` is the gradient vector for row `s`.

The LP: minimize `max_s (g_s · p)` over selected rows, subject to:
- `sum p = 0`
- `0 <= h_i + alpha_max * p_i <= 1` for some reasonable `alpha_max` (or just bound `|p_i| <= M` for some M)

Actually, let me simplify. The LP should find a direction that decreases the maximum over selected rows. 

Minimize `t`
subject to: for each selected row `s`: `g_s · p <= -t` (we want to decrease each by at least `t`)
`sum p = 0`
`p_i >= -(h_i / alpha_bound)` for alpha_bound some fixed step (like 1)
`p_i <= ((1-h_i) / alpha_bound)`

Actually, the scaling matters. Let me think of it differently.

We want to find `p` such that `sum p = 0`, `|p_i| <= 1` (normalized), and we minimize `max_{s in S} g_s · p`.

This is a standard LP:
Minimize `t`
subject to: `g_s · p <= t` for s in S
`sum p = 0`
`-1 <= p_i <= 1`

Or we can decompose `p = a - b` with `a, b >= 0`:
Minimize `t`
subject to: for each s: `g_s · (a - b) <= t`
`sum a - sum b = 0`
`a_i + b_i <= 1` (bounds the L1 norm per coordinate)
`a_i >= 0, b_i >= 0`

This gives us a direction. Then we do exact line search along it.

Let me also think about what makes this different from the previous approach:
- Previous: pair moves (2 coordinates), gradient descent (all coordinates but following a single gradient direction), 4-coordinate moves
- New: LP finds directions that simultaneously address multiple active constraints, which can be much more effective at reducing the max

Let me also add:
- Different sets of rows to target (top 5, top 10, top 20, etc.)
- Sometimes target the "wings" of the distribution (rows that are slightly below the max but close)
- Periodic restart with different random perturbations

For the LP solver, I'll use scipy.optimize.linprog which is available.

Let me also think about the exact line search more carefully. The objective along direction `p` is:
`f(alpha) = max_k (R0[k] + alpha * D[k] - alpha^2 * C[k]) * dx`

where `D = correlate(p, 1-h, 'full') - correlate(h, p, 'full')` and `C = correlate(p, p, 'full')`.

This is `max_k (a_k - b_k * alpha^2 + c_k * alpha)` which is a maximum of concave quadratic functions (each concave in alpha since `C[k] >= 0`). Wait, `C = correlate(p,p,'full')` - is this always non-negative? Yes! Because `C[k] = sum_i p[i]*p[i+k]` which is... actually no, this is the autocorrelation of p, which CAN be negative for some lags.

Hmm, so the individual curves `R0[k] + alpha*D[k] - alpha^2*C[k]` are not necessarily concave. So golden section search might not work perfectly. But in practice, for small steps it should be fine. Let me use a more robust approach: sample the interval densely first, then refine.

Actually, let me reconsider. For the line search, I'll use a combination:
1. Coarse grid search over the feasible interval for alpha
2. Then golden section on the best sub-interval

The feasible interval for alpha is determined by `0 <= h_i + alpha * p_i <= 1` for all i.

import numpy as np
import time
from scipy.optimize import linprog

def c5_exact(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo, hi = float(v.min()) - 2.0, float(v.max()) + 2.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-13:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def compute_gradients(h, row_indices):
    """Compute gradient vectors for specified correlation rows.
    row_indices are 0-based indices into the full correlation output (length 2n-1).
    Returns array of shape (len(row_indices), n).
    """
    n = len(h)
    grads = np.zeros((len(row_indices), n))
    for k_idx, k in enumerate(row_indices):
        d = k - (n - 1)  # centered lag
        m = n - abs(d)
        if m <= 0:
            continue
        if d >= 0:
            # R = sum_{i=0}^{m-1} h[i+d]*(1-h[i])
            # dR/dh[i+d] += (1-h[i]) for i=0..m-1
            # dR/dh[i] += -h[i+d] for i=0..m-1
            if d == 0:
                grads[k_idx, :m] = 1.0 - 2.0 * h[:m]
            else:
                grads[k_idx, d:d+m] += (1.0 - h[:m])
                grads[k_idx, :m] += -h[d:d+m]
        else:
            r = -d
            # R = sum_{i=0}^{m-1} h[i]*(1-h[i+r])
            # dR/dh[i] += (1-h[i+r])
            # dR/dh[i+r] += -h[i]
            grads[k_idx, :m] += (1.0 - h[r:r+m])
            grads[k_idx, r:r+m] += -h[:m]
    return grads

def exact_line_search(h, p, dx, S0):
    """Exact line search along direction p. Returns (optimal_alpha, optimal_c5)."""
    n = len(h)
    # Find feasible range for alpha
    pos = p > 1e-15
    neg = p < -1e-15
    hi = 1.0
    lo = -1.0
    if np.any(pos):
        hi = min(hi, float(np.min((1.0 - h[pos]) / p[pos])))
    if np.any(neg):
        lo = max(lo, float(np.max(h[neg] / (-p[neg]))))
    
    if hi - lo < 1e-14:
        return 0.0, float(np.max(S0) * dx)
    
    D = np.correlate(p, 1.0 - h, 'full') - np.correlate(h, p, 'full')
    C = np.correlate(p, p, 'full')
    
    # Coarse grid
    n_grid = 30
    alphas = np.linspace(lo, hi, n_grid)
    vals = np.array([float(np.max(S0 + a * D - a * a * C)) * dx for a in alphas])
    best_idx = int(np.argmin(vals))
    
    # Refine around best
    if best_idx == 0:
        a, b = lo, alphas[1]
    elif best_idx == n_grid - 1:
        a, b = alphas[-2], hi
    else:
        a, b = alphas[best_idx - 1], alphas[best_idx + 1]
    
    # Golden section on [a, b]
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    c1 = b - gr * (b - a)
    c2 = a + gr * (b - a)
    f1 = float(np.max(S0 + c1 * D - c1 * c1 * C)) * dx
    f2 = float(np.max(S0 + c2 * D - c2 * c2 * C)) * dx
    for _ in range(40):
        if b - a < 1e-13:
            break
        if f1 < f2:
            b, c2, f2 = c2, c1, f1
            c1 = b - gr * (b - a)
            f1 = float(np.max(S0 + c1 * D - c1 * c1 * C)) * dx
        else:
            a, c1, f1 = c1, c2, f2
            c2 = a + gr * (b - a)
            f2 = float(np.max(S0 + c2 * D - c2 * c2 * C)) * dx
    
    opt = (a + b) / 2.0
    val = float(np.max(S0 + opt * D - opt * opt * C)) * dx
    
    # Check endpoints
    f_lo = float(np.max(S0 + lo * D - lo * lo * C)) * dx
    f_hi = float(np.max(S0 + hi * D - hi * hi * C)) * dx
    if f_lo < val:
        opt, val = lo, f_lo
    if f_hi < val:
        opt, val = hi, f_hi
    
    return opt, val

def lp_direction(h, row_indices, n):
    """Find LP direction that minimizes max gradient over selected rows.
    Returns direction vector p (zero-sum) or None if LP infeasible."""
    grads = compute_gradients(h, row_indices)  # shape (M, n)
    M = len(row_indices)
    
    # Variables: a (n), b (n), t (1) -> total 2n+1
    # Minimize t
    # Subject to:
    #   grads[i] @ (a-b) <= t  for i = 0..M-1
    #   sum(a) - sum(b) = 0
    #   a_i + b_i <= 1  for all i
    #   a_i >= 0, b_i >= 0, t >= 0 (unbounded above is fine, but let's keep t free)
    
    # Actually, let me be more careful with the constraint types for linprog.
    # linprog minimizes c @ x subject to A_ub @ x <= b_ub, A_eq @ x == b_eq, bounds
    
    c = np.zeros(2 * n + 1)
    c[-1] = 1.0  # minimize t
    
    # Inequality constraints:
    # grads[i] @ a - grads[i] @ b - t <= 0  for each i
    A_ub = np.zeros((M + n, 2 * n + 1))
    b_ub = np.zeros(M + n)
    
    for i in range(M):
        A_ub[i, :n] = grads[i]
        A_ub[i, n:2*n] = -grads[i]
        A_ub[i, 2*n] = -1.0
        b_ub[i] = 0.0
    
    # a_i + b_i <= 1
    eye = np.eye(n)
    A_ub[M:M+n, :n] = eye
    A_ub[M:M+n, n:2*n] = eye
    b_ub[M:M+n] = 1.0
    
    # Equality: sum(a) - sum(b) = 0
    A_eq = np.zeros((1, 2 * n + 1))
    A_eq[0, :n] = 1.0
    A_eq[0, n:2*n] = -1.0
    b_eq = np.zeros(1)
    
    bounds = [(0, None)] * (2 * n) + [(None, None)]  # a, b >= 0, t free
    
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')
    
    if res.status != 0:
        return None
    
    a = res.x[:n]
    b = res.x[n:2*n]
    p = a - b
    
    # Check if direction is non-trivial
    if np.max(np.abs(p)) < 1e-10:
        return None
    
    return p

def lp_direction_multiple(h, target_sets, n):
    """Try LP with different sets of target rows. Return best direction."""
    n_rows = 2 * n - 1
    S0 = np.correlate(h, 1.0 - h, mode='full')
    scores = S0  # raw scores
    
    best_p = None
    best_obj = np.inf
    
    for k in target_sets:
        # Top-k rows
        top_idx = np.argsort(-scores)[:k]
        p = lp_direction(h, top_idx, n)
        if p is not None:
            # Evaluate the LP objective (predicted improvement)
            grads = compute_gradients(h, top_idx)
            obj = float(np.max(grads @ p))
            if obj < best_obj:
                best_obj = obj
                best_p = p
    
    return best_p

def resample(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return project(h_new, n_new / 2.0)

def _directed_pair_search(h, n_pairs, deadline):
    """Directed pair moves targeting active peaks."""
    n = len(h)
    target = n / 2.0
    dx = 2.0 / n
    cur_c5 = c5_exact(h)
    best_h = h.copy()
    best_c5 = cur_c5
    S0 = np.correlate(h, 1.0 - h, mode='full')
    stall = 0
    rng = np.random.default_rng(777)
    
    while time.time() < deadline and stall < 100:
        scores = S0 * dx
        max_score = float(np.max(scores))
        threshold = max_score - 0.003 * max_score
        active_idx = np.where(scores >= threshold)[0]
        if len(active_idx) == 0:
            active_idx = np.argsort(-scores)[:10]
        
        grads = compute_gradients(h, active_idx)
        weight = np.exp((scores[active_idx] - max_score) / (0.008 * max_score + 1e-15))
        weight /= float(np.sum(weight))
        wgrad = grads.T @ weight
        
        donor_pool = np.argsort(-wgrad)[:n_pairs]
        recv_pool = np.argsort(wgrad)[:n_pairs]
        
        best_alpha = 0.0
        best_new_c5 = cur_c5
        best_pair = None
        
        tried = set()
        for i in donor_pool:
            if time.time() > deadline:
                break
            for j in recv_pool:
                if i == j:
                    continue
                key = (min(int(i), int(j)), max(int(i), int(j)))
                if key in tried:
                    continue
                tried.add(key)
                
                d = np.zeros(n)
                d[int(i)] = -1.0
                d[int(j)] = 1.0
                alpha, new_c5 = exact_line_search(h, d, dx, S0)
                if abs(alpha) > 1e-10 and new_c5 < best_new_c5 - 1e-14:
                    best_new_c5 = new_c5
                    best_alpha = alpha
                    best_pair = (int(i), int(j))
        
        if best_pair is not None and best_new_c5 < cur_c5 - 1e-13:
            i, j = best_pair
            h[i] -= best_alpha
            h[j] += best_alpha
            h = project(h, target)
            cur_c5 = c5_exact(h)
            S0 = np.correlate(h, 1.0 - h, mode='full')
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            stall = 0
        else:
            stall += 1
            if stall > 30 and rng.random() < 0.4:
                idx = rng.integers(n, size=6)
                for idx_k in idx:
                    h[idx_k] += rng.uniform(-0.08, 0.08)
                h = project(h, target)
                cur_c5 = c5_exact(h)
                S0 = np.correlate(h, 1.0 - h, mode='full')
                stall = 0
    
    return best_h, best_c5

def lp_search(h, deadline, rng):
    """LP-based direction search."""
    n = len(h)
    target = n / 2.0
    dx = 2.0 / n
    cur_c5 = c5_exact(h)
    best_h = h.copy()
    best_c5 = cur_c5
    S0 = np.correlate(h, 1.0 - h, mode='full')
    stall = 0
    
    # Different target set sizes to try
    target_sets = [5, 8, 10, 12, 15, 20]
    
    while time.time() < deadline and stall < 60:
        S0 = np.correlate(h, 1.0 - h, mode='full')
        scores = S0 * dx
        cur_c5 = float(np.max(scores))
        
        # Select which target set to use
        k = target_sets[rng.integers(len(target_sets))]
        
        # Sometimes use "near-top" rows instead of exact top
        if rng.random() < 0.3:
            # Use rows in top-2k but not necessarily the very top
            top_2k = np.argsort(-scores)[:2*k]
            selected = rng.choice(top_2k, size=min(k, len(top_2k)), replace=False)
            p = lp_direction(h, selected, n)
        else:
            top_k = np.argsort(-scores)[:k]
            p = lp_direction(h, top_k, n)
        
        if p is None:
            stall += 1
            continue
        
        # Exact line search
        alpha, new_c5 = exact_line_search(h, p, dx, S0)
        
        if abs(alpha) > 1e-10 and new_c5 < cur_c5 - 1e-14:
            h = h + alpha * p
            h = project(h, target)
            cur_c5 = c5_exact(h)
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            stall = 0
        else:
            stall += 1
            if stall > 20:
                # Perturb
                idx = rng.integers(n, size=8)
                for idx_k in idx:
                    h[idx_k] += rng.uniform(-0.1, 0.1)
                h = project(h, target)
                stall = 0
    
    return best_h, best_c5

def random_pair_search(h, deadline, rng):
    """Random pair exploration with SA."""
    n = len(h)
    target = n / 2.0
    dx = 2.0 / n
    cur_c5 = c5_exact(h)
    best_h = h.copy()
    best_c5 = cur_c5
    S0 = np.correlate(h, 1.0 - h, mode='full')
    T = 0.002
    T_min = 0.0001
    patience = 0
    
    while time.time() < deadline:
        if patience > 3000:
            if T <= T_min:
                break
            T = T_min
            patience = 0
        
        i = int(rng.integers(n))
        j = int(rng.integers(n))
        if i == j:
            continue
        
        d = np.zeros(n)
        d[i] = -1.0
        d[j] = 1.0
        alpha, new_c5 = exact_line_search(h, d, dx, S0)
        
        if abs(alpha) > 1e-10:
            delta = new_c5 - cur_c5
            if delta < 0 or (T > T_min and rng.random() < np.exp(-delta / (T + 1e-15))):
                h[i] -= alpha
                h[j] += alpha
                h = project(h, target)
                cur_c5 = c5_exact(h)
                S0 = np.correlate(h, 1.0 - h, mode='full')
                if cur_c5 < best_c5:
                    best_c5 = cur_c5
                    best_h = h.copy()
                    patience = 0
                else:
                    patience += 1
        T = max(T_min, T * 0.9999)
    
    return best_h, best_c5

def gradient_polish(h, deadline):
    """Gradient-based polish."""
    n = len(h)
    target = n / 2.0
    dx = 2.0 / n
    cur_c5 = c5_exact(h)
    best_h = h.copy()
    best_c5 = cur_c5
    S0 = np.correlate(h, 1.0 - h, mode='full')
    stall = 0
    
    while time.time() < deadline and stall < 40:
        S0 = np.correlate(h, 1.0 - h, mode='full')
        scores = S0 * dx
        max_score = float(np.max(scores))
        threshold = max_score - 0.002 * max_score
        active_idx = np.where(scores >= threshold)[0]
        if len(active_idx) == 0:
            active_idx = np.argsort(-scores)[:8]
        
        grads = compute_gradients(h, active_idx)
        weight = np.exp((scores[active_idx] - max_score) / (0.004 * max_score + 1e-15))
        weight /= float(np.sum(weight))
        g = grads.T @ weight
        g -= np.mean(g)
        gn = np.linalg.norm(g)
        if gn < 1e-15:
            break
        
        d = -g / gn
        alpha, new_c5 = exact_line_search(h, d, dx, S0)
        
        if abs(alpha) > 1e-10 and new_c5 < cur_c5 - 1e-14:
            h = h + alpha * d
            h = project(h, target)
            cur_c5 = c5_exact(h)
            S0 = np.correlate(h, 1.0 - h, mode='full')
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            stall = 0
        else:
            stall += 1
    
    return best_h, best_c5

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    rng = np.random.default_rng(seed)
    deadline = t0 + budget_s * 0.97
    
    # Initialize
    try:
        h0 = np.array(initial_h_values, dtype=float)
        n0 = len(h0)
    except NameError:
        n0 = 122
        x = np.arange(n0)
        h0 = 0.5 + 0.45 * np.sin(2 * np.pi * 2 * x / n0 + 0.5)
    
    h = project(h0, n0 / 2.0)
    best_h = h.copy()
    best_c5 = c5_exact(h)
    best_n = n0
    
    # Phase 1: Directed pair search (25% time)
    d1 = t0 + budget_s * 0.25
    h_p1, c5_p1 = _directed_pair_search(h, 15, d1)
    if c5_p1 < best_c5:
        best_c5 = c5_p1
        best_h = h_p1.copy()
    
    # Phase 2: LP direction search (30% time) - the key new phase
    d2 = t0 + budget_s * 0.55
    h_p2, c5_p2 = lp_search(best_h, d2, rng)
    if c5_p2 < best_c5:
        best_c5 = c5_p2
        best_h = h_p2.copy()
    
    # Phase 3: Multi-resolution (15% time)
    d3 = t0 + budget_s * 0.70
    tried_n = {best_n}
    for dn in [-4, 4, -6, 6, -8, 8, -2, 2, -10, 10]:
        if time.time() > d3:
            break
        n_try = best_n + dn
        if n_try < 20 or n_try > 250 or n_try % 2 != 0:
            continue
        if n_try in tried_n:
            continue
        tried_n.add(n_try)
        h_r = resample(best_h, n_try)
        sub_dl = min(d3, time.time() + budget_s * 0.015)
        h_r, c5_r = _directed_pair_search(h_r, 12, sub_dl)
        if c5_r < best_c5:
            sub_dl2 = min(d3, time.time() + budget_s * 0.01)
            h_r, c5_r = lp_search(h_r, sub_dl2, rng)
            if c5_r < best_c5:
                best_c5 = c5_r
                best_h = h_r.copy()
                best_n = n_try
    
    # Phase 4: LP search again (10% time)
    d4 = t0 + budget_s * 0.80
    h_p4, c5_p4 = lp_search(best_h, d4, rng)
    if c5_p4 < best_c5:
        best_c5 = c5_p4
        best_h = h_p4.copy()
    
    # Phase 5: Gradient polish (8% time)
    d5 = t0 + budget_s * 0.88
    h_p5, c5_p5 = gradient_polish(best_h, d5)
    if c5_p5 < best_c5:
        best_c5 = c5_p5
        best_h = h_p5.copy()
    
    # Phase 6: Random pair (5% time)
    d6 = t0 + budget_s * 0.93

import numpy as np

def c5_exact(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo, hi = float(v.min()) - 2.0, float(v.max()) + 2.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-13:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def compute_gradients(h, row_indices):
    n = len(h)
    grads = np.zeros((len(row_indices), n))
    for k_idx, k in enumerate(row_indices):
        d = k - (n - 1)
        m = n - abs(d)
        if m <= 0:
            continue
        if d >= 0:
            if d == 0:
                grads[k_idx, :m] = 1.0 - 2.0 * h[:m]
            else:
                grads[k_idx, d:d+m] += (1.0 - h[:m])
                grads[k_idx, :m] += -h[d:d+m]
        else:
            r = -d
            grads[k_idx, :m] += (1.0 - h[r:r+m])
            grads[k_idx, r:r+m] += -h[:m]
    return grads

def exact_line_search(h, p, dx, S0):
    n = len(h)
    pos = p > 1e-15
    neg = p < -1e-15
    hi = 1.0
    lo = -1.0
    if np.any(pos):
        hi = min(hi, float(np.min((1.0 - h[pos]) / p[pos])))
    if np.any(neg):
        lo = max(lo, float(np.max(h[neg] / (-p[neg]))))
    if hi - lo < 1e-14:
        return 0.0, float(np.max(S0) * dx)
    D = np.correlate(p, 1.0 - h, 'full') - np.correlate(h, p, 'full')
    C = np.correlate(p, p, 'full')
    n_grid = 25
    alphas = np.linspace(lo, hi, n_grid)
    vals = np.array([float(np.max(S0 + a * D - a * a * C)) * dx for a in alphas])
    best_idx = int(np.argmin(vals))
    if best_idx == 0:
        a, b = lo, alphas[1]
    elif best_idx == n_grid - 1:
        a, b = alphas[-2], hi
    else:
        a, b = alphas[best_idx - 1], alphas[best_idx + 1]
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    c1 = b - gr * (b - a)
    c2 = a + gr * (b - a)
    f1 = float(np.max(S0 + c1 * D - c1 * c1 * C)) * dx
    f2 = float(np.max(S0 + c2 * D - c2 * c2 * C)) * dx
    for _ in range(45):
        if b - a < 1e-13:
            break
        if f1 < f2:
            b, c2, f2 = c2, c1, f1
            c1 = b - gr * (b - a)
            f1 = float(np.max(S0 + c1 * D - c1 * c1 * C)) * dx
        else:
            a, c1, f1 = c1, c2, f2
            c2 = a + gr * (b - a)
            f2 = float(np.max(S0 + c2 * D - c2 * c2 * C)) * dx
    opt = (a + b) / 2.0
    val = float(np.max(S0 + opt * D - opt * opt * C)) * dx
    f_lo = float(np.max(S0 + lo * D - lo * lo * C)) * dx
    f_hi = float(np.max(S0 + hi * D - hi * hi * C)) * dx
    if f_lo < val:
        opt, val = lo, f_lo
    if f_hi < val:
        opt, val = hi, f_hi
    return opt, val

def lp_direction(h, row_indices, n):
    grads = compute_gradients(h, row_indices)
    M = len(row_indices)
    c = np.zeros(2 * n + 1)
    c[-1] = 1.0
    A_ub = np.zeros((M + n, 2 * n + 1))
    b_ub = np.zeros(M + n)
    for i in range(M):
        A_ub[i, :n] = grads[i]
        A_ub[i, n:2*n] = -grads[i]
        A_ub[i, 2*n] = -1.0
    eye = np.eye(n)
    A_ub[M:M+n, :n] = eye
    A_ub[M:M+n, n:2*n] = eye
    b_ub[M:M+n] = 1.0
    A_eq = np.zeros((1, 2 * n + 1))
    A_eq[0, :n] = 1.0
    A_eq[0, n:2*n] = -1.0
    b_eq = np.zeros(1)
    bounds = [(0, None)] * (2 * n) + [(None, None)]
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': 5.0})
    except Exception:
        return None
    if res.status != 0:
        return None
    a = res.x[:n]
    b = res.x[n:2*n]
    p = a - b
    if np.max(np.abs(p)) < 1e-10:
        return None
    return p
