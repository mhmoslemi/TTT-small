1. Approach and rationale

1.1 Central method: exact feasible affine-slice descent for the max-over-lap-overlap objective

The proposed algorithm is a randomized coordinate and direction method whose fundamental move is never a heuristic line taken after a full suggested direction, nor a projected LP step, nor a simulated-annealing binary search on bit sequences. Its fundamental move is:

  (a) Choose a zero-sum direction A whose entries are mostly zero (small support), generated by one of several families of proposals: balanced pair moves, balanced triple moves, randomized small-support moves, zero-sum directions extracted/augmented from top active correlation constraints, and random balanced streams of larger coordinates.

  (b) The candidate h_t is:
       h_t = h_old + t A
     with
       A > 0 or A_i < 0 positions paired with others such that sum(A)=0,
       t chosen such that |t A_i| does not push any position or the overall residual outside the available feasible interval,
       after projection, sum(h_t)=target exactly up to floating tolerance.

  (c) For that one line, the exact correlation objective can be evaluated without re-correlating the whole vector at every t. If the old full unscaled correlation vector is S0 = corr(h_old, 1-h_old, full), and A is the exact tested direction, then for every scalar t (without clipping and with exactly equal line model algebra):

       C_t = corr(h_old + t A, 1-h_old - t A, full)
           = corr(h_old, 1-h_old, full)
             + t corr(A, 1-h_old, full)
             - t corr(h_old, A, full)
             - t^2 corr(A, A, full).

     Thus with:
       T = corr(A, 1-h_old, full) - corr(h_old, A, full)
       Q = -corr(A, A, full)
     the full predicted correlation vector is:
       P_t = S0 + t T + t^2 Q.

     The line objective used while choosing t is:
       c5_line(t) = dx * max(P_t), dx = 2/n.

     This is not a surrogate: for the exact line h_old+tA it coincides algebraically with the final evaluator expression, because the correlation operation is bilinear and operates on the same finite full arrays.

  (d) The allowed interval of t is found from box constraints, not guessing:
       For every nonzero coordinate slaking A_i:
         if A_i > 0:
           t >= -h_i/A_i and t <= (1-h_i)/A_i.
         if A_i < 0:
           t <= h_i/(-A_i) and t >= (1-h_i)/A_i.
       Intersect all intervals. Include t=0 is automatically valid as long as h_old is feasible. The engine may also restrict the interval to a larger but meaningful movement radius to avoid degenerately exploring far moves while consuming too much objective time, while it should keep at least a few positions of feasible coordinates permitting positive moves.

  (e) A line is optimized locally by evaluating a grid of K points, selected around the current interval. The observed smallest grid score and neighbouring intervals are used to run a golden-section refinement.

  (f) A candidate line effectively only becomes accepted only if the exact, independent evaluator with full re-correlation of transformed h says it truly improves the current objective. The predicted grid and golden values are used solely for selection and comparison; the current and accepted c-values are always exact values computed using the task metric.

  (g) After the optimising valid direction proposal yields an accepted update, h is projected with the strict feasibility scheme to remove tiny tolerance drift. The objective value used in subsequent decisions is recomputed exactly using the objective function, not cached.

The new objective-search character differs from the parent approach as follows: the previous method generated an LP-type direction to reduce an active set, then do a generic line search with trust/λ/radius; this method uses many diverse small one-line feasible trial proposals in the full simplex, testing whether exact coordinate redistribution reduces objective along that slice. The proposal search has:

- Structural control: exact support count and geometry of the direction (pair, adjacent, local group, active-constristic weight they extract from active correlatives mathematically or approximately).
- Random variety: random allocations, partially random weights, random inactive and saturated support interactions.
- Exact runtime scoring: the objective along the exact h-propose line, but also real exact final matching on actual proposed values through the evaluator.
- All proposals are accepted or rejected by evaluating the authoritative correlation metric without backpassing an LP/Trust tolerance.

This is a random field of one-dimensional exact cross-directions that emphasize highly constrained indices as much as coordinate pairings by exact partial coordinate transfers. It could make small progressive real steps across nonconvex boundaries missed by constrained LP local updates, while also keeping a deterministic fallback of original start.

1. Approach and rationale

1.1 Central idea

The proposed solver follows a fundamentally different route from the published previous parent program. That program repeatedly searches a globally generated LP direction, applies a line search, then uses curvature, balance, perturbations and multi-resolution. The new solver instead explores many **exact feasible one-dimensional affine slices** of the full simplex boundary `0 <= h <= 1, sum(h)=target`. Each trial proposal is an exact direction proposal:

\[
h(t) = h_{0} + t A,
\qquad \sum_i A_i = 0.
\]

The scalar \(t\) is selected by an exact objective prediction along the slice. For the current unscaled full correlation vector

\[
S_0 = \operatorname{corr}(h_0,1-h_0)
\]

and a complete direction vector \(A\), bilinearity of ordinary correlation gives

\[
S_t =
\operatorname{corr}(h_0 + tA,\,1-h_0 - tA)
= S_0 + tT + t^2 Q
\]

where

\[
T = \operatorname{corr}(A,1-h_0)-\operatorname{corr}(h_0,A),
\qquad
Q = -\operatorname{corr}(A,A)
\]

with full mode correlation and all arrays of length \(n\). The predicted scaled line objective is exactly

\[
f_{line}(t) = \left(\max_r S_t[r]\right)\,dx,
\qquad
dx = \frac{2}{n}.
\]

This is mathematically identical to the final evaluator for the affine candidate as long as \(h(t)\) remains within \([0,1]\) and preserves the mass constraint. Final acceptance, however, also re-evaluates the true candidate using the official formula \(\max(\operatorname{corr}(h,1-h))*dx\) and projects tiny numerical drift; this sets a non-negotiable guard against implementation drift.

The solver does not claim convexity, global optimality, or an LP quadratic relaxation. It is a structured stochastic exact-line descent method, enriched by:

- direct exhaustive or selective **balanced pair moves**, the most elementary exact mass-transfer feasible lines;
- localized **small-support balanced directions**;
- **top active constraint gradient directions**, assembled from the actual full-lag gradient pattern and converted to a zero-sum proposal direction;
- randomized small support directions;
- random strong and resample-based global proposer families;
- post-update feasibility repair with a bisection-plus-residual exact feasibility mechanism;
- active proposal of different finite resolution lengths by resampling and re-polishing;
- a fallback path that always preserves a valid parent-like candidate.

It is different because the previous method spent most effort generating a constrained LP/quadratic/curvature style full direction. This method empirically optimizes a huge stream of exact one-dimensional exact objective directions accepted only if the objective itself reduces. It combines exact line arithmetic with a rich variety of foundational proposal families, especially exact active-constraint slices for which earlier LP greed is less adaptive.
