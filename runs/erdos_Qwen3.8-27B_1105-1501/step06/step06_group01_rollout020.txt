The objective C(h) = max_q dx * correlate(h, 1-h)[:, q] is a piecewise-linear (in h) convex function. The feasible set is a polytope (box + one linear equality). So this is a convex optimization problem! The minimum of a convex function over a polytope occurs at... well, it's convex optimization, so we can use LP cutting planes.

Wait - is it actually convex? Let's see: for each q, the function f_q(h) = dx * correlate(h, 1-h)[:, q] is linear in h (since correlate(h, 1-h) = correlate(h,1) - correlate(h,h), and correlate(h,1) is linear in h, but correlate(h,h) is quadratic in h).

So f_q(h) = dx * (sum of h[i] over some range - sum of h[i]*h[j] over some range). This is NOT linear in h - it has quadratic terms. So the objective max_q f_q(h) is the max of concave functions, making it non-convex.

Wait, let me reconsider. correlate(h, 1-h) at lag k:
- For k >= 0: sum_{i=0}^{n-1-k} h[i] * (1-h[i+k]) = sum_{i=0}^{n-1-k} h[i] - sum_{i=0}^{n-1-k} h[i]*h[i+k]
- This is indeed bilinear (quadratic) in h.

So the problem is non-convex. The max of these bilinear functions is non-convex.

However, the previous approach of LP direction finding works because: at a fixed point h, the gradient of each f_q with respect to h gives a linear approximation, and the LP finds the best direction to reduce the maximum. This is essentially a subgradient/LP cutting plane approach for the non-convex problem.

For fixed b, the function g(a) = dx * correlate(a, b) is linear in a. So min_a max_q g(a) is a genuine LP. The key insight is:
- u_L = a* (minimize max correlation with b)

C(h) = max_q dx * sum_i h[i] * (1-h[i+q])

If I fix one factor, say (1-h[i+q]) = b[i+q], then:
dx * sum_i h[i] * b[i+q] is linear in h.

So for fixed b = 1-h, the LP min_h max_q dx * correlate(h, b) gives a direction that's optimal against the "current" complement. The bridge idea is:
- u_L = a* (LP solution minimizing max correlation with b)
- u_R = 1 - b* (LP solution for the dual problem)
- Both have sum n/2 (by construction)
- The line segment between them is feasible
- Evaluate C(h) along this segment

This is different from the previous approach because:

Let me also think about the specific structure of good solutions. The optimal h should have the property that h(x) and 1-h(x+k) have minimal overlap for all k. This suggests h should be "spread out" in a way that its shifts are "complementary."

For the binary case (h takes values 0 and 1), this is related to finding a subset S of {0,...,n-1} of size n/2 such that for all shifts k, |S ∩ (S+k)| is minimized. This is related to difference sets and Sidon sets.

Actually, for the binary case:
C(h) = max_k dx * (n/2 - |S ∩ (S+k)|) ... wait no.

If h is binary with exactly n/2 ones, then:
correlate(h, 1-h) at lag k = sum_i h[i] * (1-h[i+k])

For k = 0: sum_i h[i](1-h[i]) = 0 (since h is binary)
For k ≠ 0: this counts pairs (i, i+k) where h[i]=1 and h[i+k]=0.

If h has exactly n/2 ones and n/2 zeros, then for each k:
sum_i h[i](1-h[i+k]) + sum_i h[i]h[i+k] = sum_i h[i] = n/2 (for k where all indices are in range)

So correlate(h,1-h) at lag k = n/2 - correlate(h,h) at lag k.

To minimize max_k correlate(h,1-h), we want to maximize min_k correlate(h,h) for k≠0, subject to correlate(h,h) at k=0 being n/2.

This is related to autocorrelation minimization - finding a sequence with flat autocorrelation (excluding the peak). This is related to Barker sequences, m-sequences, etc.

For the non-binary case, we can intermediate values to further reduce the maximum overlap.

import numpy as np
from scipy.optimize import linprog
import time

def _project(v, target):
    """Project v onto [0,1]^n with sum = target."""
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo, hi = float(v.min()) - 2.0, float(v.max()) + 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-12:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _corr_vals(h):
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def _build_H(h, dx):
    """Build the Hessian-related matrix for the quadratic terms.
    For f_q(h) = dx * sum_i h[i]*(1-h[i+q]), the quadratic part is
    -dx * sum_i h[i]*h[i+q].
    The Hessian of f_q w.r.t. h is -dx * (E_q + E_q^T) where E_q is the shift matrix.
    """
    n = len(h)
    # For the line search, we need: f_q(h + t*d) = S_q + t*T_q + t^2*C_q
    # where S_q = f_q(h), T_q = gradient contribution, C_q = quadratic coefficient
    return None  # Not needed directly, computed in line search

def _line_search(h, d, dx, trust_radius):
    """Line search along h + t*d, finding t that minimizes max_q f_q(h+t*d)."""
    n = len(h)
    # f_q(h + t*d) = dx * sum_i (h[i]+t*d[i]) * (1 - h[i+q] - t*d[i+q])
    # = dx * sum_i h[i](1-h[i+q]) + t*dx*sum_i (d[i](1-h[i+q]) - h[i]d[i+q]) - t^2*dx*sum_i d[i]*d[i+q]
    # = S_q + t*T_q - t^2*C_q
    S0 = np.correlate(h, 1.0 - h, mode='full') * dx
    T = (np.correlate(d, 1.0 - h, mode='full') - np.correlate(h, d, mode='full')) * dx
    C = np.correlate(d, d, mode='full') * dx
    
    # Constrain t so h + t*d stays in [0,1]
    t_lo = -trust_radius
    t_hi = trust_radius
    pos = d > 1e-15
    neg = d < -1e-15
    if np.any(pos):
        t_lo = max(t_lo, float(np.min(-h[pos] / d[pos])))
        t_hi = min(t_hi, float(np.min((1.0 - h[pos]) / d[pos])))
    if np.any(neg):
        t_lo = max(t_lo, float(np.min((1.0 - h[neg]) / d[neg])))
        t_hi = min(t_hi, float(np.min(-h[neg] / d[neg])))
    
    if t_hi - t_lo < 1e-14:
        return 0.0, float(np.max(S0))
    
    # Golden section search on the piecewise-quadratic function
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    a, b = t_lo, t_hi
    c = b - gr * (b - a)
    dpt = a + gr * (b - a)
    f_c = float(np.max(S0 + c * T - c * c * C))
    f_d = float(np.max(S0 + dpt * T - dpt * dpt * C))
    
    for _ in range(60):
        if b - a < 1e-13:
            break
        if f_c < f_d:
            b, dpt, f_d = dpt, c, f_c
            c = b - gr * (b - a)
            f_c = float(np.max(S0 + c * T - c * c * C))
        else:
            a, c, f_c = c, dpt, f_d
            dpt = a + gr * (b - a)
            f_d = float(np.max(S0 + dpt * T - dpt * dpt * C))
    
    opt_t = (a + b) / 2.0
    opt_val = float(np.max(S0 + opt_t * T - opt_t * opt_t * C))
    return opt_t, opt_val

def _lp_minimax(h_fixed, dx, target):
    """Solve min_a max_q dx * correlate(a, h_fixed) s.t. sum(a)=target, 0<=a<=1.
    
    This is: min tau s.t. dx * correlate(a, h_fixed)[:, q] <= tau for all q
    """
    n = len(h_fixed)
    # corr(a, h_fixed) at lag q: for q >= n-1 (i.e., k = q-(n-1) >= 0):
    #   sum_{i=0}^{n-1-k} a[i] * h_fixed[i+k]
    # for q < n-1 (k < 0, d = n-1-q, k=-d):
    #   sum_{i=d}^{n-1} a[i] * h_fixed[i-d]
    
    # Build A matrix: A[q, i] = dx * (coefficient of a[i] in correlate(a, h_fixed)[:, q])
    A = np.zeros((2*n-1, n))
    for q in range(2*n-1):
        k = q - (n-1)
        if k >= 0:
            # corr[a, h_fixed][q] = sum_{i=0}^{n-1-k} a[i] * h_fixed[i+k]
            m = n - k
            A[q, :m] = dx * h_fixed[k:k+m]
        else:
            d_abs = -k
            # corr[a, h_fixed][q] = sum_{i=d_abs}^{n-1} a[i] * h_fixed[i-d_abs]
            m = n - d_abs
            A[q, d_abs:d_abs+m] = dx * h_fixed[:m]
    
    # LP: min tau
    # s.t. A @ a - tau <= 0  (2n-1 constraints)
    #      sum(a) = target
    #      0 <= a_i <= 1
    c = np.zeros(n + 1)
    c[-1] = 1.0  # minimize tau
    A_ub = np.hstack([A, -np.ones((2*n-1, 1))])
    b_ub = np.zeros(2*n-1)
    A_eq = np.zeros((1, n+1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([target])
    bounds = [(0.0, 1.0)] * n + [(0.0, None)]
    
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs')
        if res.success:
            return res.x[:n]
    except Exception:
        pass
    return None

def _relaxed_pair_step(h, dx, target, rng, deadline):
    """One iteration of the relaxed pair LP approach.
    
    1. Choose partner b (various modes)
    2. Solve LP: a* = argmin_a max_q dx*corr(a, b)
    3. Solve LP: b* = argmin_b max_q dx*corr(a*, b) [wait, this isn't quite right]
    
    Actually the symmetric problem: for fixed a, solve min_b max_q dx*corr(a, b).
    Then u_L = a*, u_R = 1 - b* (since sum(b*)=target, sum(1-b*)=n-target=target).
    Both u_L and u_R are feasible (by construction).
    Evaluaate C(h) along the segment.
    """
    n = len(h)
    result_h = h.copy()
    result_c5 = _exact_c5(h)
    
    for mode in range(4):
        if time.time() > deadline:
            break
        
        # Generate partner b
        if mode == 0:
            # b = 1-h (complement, most natural)
            b = 1.0 - h
        elif mode == 1:
            # Random balanced vector with some structure
            freq = rng.integers(1, 6)
            phase = rng.uniform(0, 2*np.pi)
            x = np.arange(n)
            b = 0.5 + 0.3*np.sin(2*np.pi*freq*x/n + phase) + rng.normal(0, 0.1, n)
            b = _project(b, target)
        elif mode == 2:
            # Smoothed random binary
            b_bin = np.zeros(n)
            idx = rng.permutation(n)
            b_bin[idx[:int(target)]] = 1.0
            # Smooth: convolution with small kernel
            kernel = np.array([0.2, 0.6, 0.2])
            b = np.convolve(b_bin, kernel, mode='same')
            b = _project(b, target)
        else:
            # b = h with noise
            b = h + rng.normal(0, 0.2, n)
            b = _project(b, target)
        
        b = _project(b, target)
        
        # Solve LP for a*
        a_star = _lp_minimax(b, dx, target)
        if a_star is None:
            continue
        a_star = _project(a_star, target)  # Ensure feasibility
        
        # Evaluate a_star directly
        c5_a = _exact_c5(a_star)
        if c5_a < result_c5:
            result_c5 = c5_a
            result_h = a_star.copy()
        
        # Solve LP for b* given a_star
        b_star = _lp_minimax(a_star, dx, target)
        if b_star is None:
            continue
        b_star = _project(b_star, target)
        
        # u_R = 1 - b_star
        u_R = 1.0 - b_star
        u_R = _project(u_R, target)
        
        c5_R = _exact_c5(u_R)
        if c5_R < result_c5:
            result_c5 = c5_R
            result_h = u_R.copy()
        
        # Search along segment u_L=a_star, u_R=1-b_star
        # h(alpha) = (1-alpha)*u_R + alpha*u_L
        # Both have sum = target, so any convex combo also has sum = target
        # Both in [0,1], so segment is in [0,1]^n
        for alpha in np.linspace(0, 1, 21):
            h_seg = (1-alpha)*u_R + alpha*a_star
            c5_seg = _exact_c5(h_seg)
            if c5_seg < result_c5:
                result_c5 = c5_seg
                result_h = h_seg.copy()
    
    return result_h, result_c5

def _smooth_logsumexp_optimize(h, deadline, tau_init=0.01, lr_init=0.003, max_iter=5000):
    """Optimize using log-sum-exp smooth approximation with adaptive parameters."""
    n = len(h)
    dx = 2.0 / n
    target = n / 2.0
    h = h.copy()
    best_h = h.copy()
    best_c5 = _exact_c5(h)
    tau = tau_init
    lr = lr_init
    patience = 0
    
    for it in range(max_iter):
        if time.time() > deadline:
            break
        
        S = _corr_vals(h)
        S_max = float(np.max(S))
        # Soft max weights
        w = np.exp((S - S_max) / tau)
        w_sum = float(np.sum(w))
        if w_sum < 1e-30:
            break
        w = w / w_sum
        
        # Gradient of sum_q w_q * f_q(h) where f_q(h) = dx * corr(h, 1-h)[:, q]
        # df_q/dh[i] = dx * (sum over j where (i,j) contributes to lag q of (1-h[j]) - h[i]*... )
        # Actually: f_q(h) = dx * sum_i h[i]*(1-h[i+q]) (for appropriate ranges)
        # df_q/dh[i] = dx * [(1-h[i+q]) - h[i] * (contribution from i being the second index)]
        
        # Easier: use the linear structure
        # f_q = dx * sum_i h[i] * b_q[i] where b_q[i] = 1-h[i+q] or 1-h[i-q]
        # df_q/dh = dx * (b_q - something) ... 
        # Let me just compute it directly using the correlation structure
        
        # f_q(h) for lag k = q-(n-1):
        # if k>=0: dx * sum_{i=0}^{n-1-k} h[i]*(1-h[i+k])
        # df/dh[i] = dx * [(1-h[i+k]) if i < n-k else 0] + dx * [-h[i-k] if i >= k else 0]
        #           = dx * E[(1-h[i+k]) * 1_{i<n-k}] - dx * E[h[i-k] * 1_{i>=k}]
        
        # More efficiently: gradient of f_q w.r.t. h = dx * (correlate(1-h, e_q_shift) + correlate(e_q_shift_neg, 1-h))
        # Actually let me just build the gradient matrix G where G[q,i] = df_q/dh[i]
        # and compute grad = G.T @ w
        
        # G[q, i] = df_q/dh[i]
        # For lag k=q-(n-1):
        #   f_q = dx * sum_{i: 0<=i<n-k, 0<=i+k<n} h[i]*(1-h[i+k])  [for k>=0]
        #   or f_q = dx * sum_{i: k<=i<n, 0<=i+k<n} h[i]*(1-h[i+k])  [for k<0, use i+k>=0]
        
        # Let me use a different approach: 
        # grad_q[i] = dx * (1-h[i+k]) for i in valid range where i is first index
        #            - dx * h[i-k] for i in valid range where i is second index (i.e., i-k >= 0 and i-k < n)
        
        # For efficiency, I'll build G for the active lags only
        # But with n~122, full G is (2n-1) x n ~ 243*122 ~ 30k entries, fine.
        
        # Let me use a vectorized approach:
        # For each lag k, the gradient contribution to h[i] is:
        #   +dx*(1-h[i+k]) if 0<=i<n and 0<=i+k<n (i is first factor)
        #   -dx*h[i-k] if 0<=i<n and 0<=i-k<n (i is second factor, i-k is first)
        
        # This can be written as: grad_h = dx * (convolve(1-h, something) - convolve(h, something))
        # But let me just build it directly for clarity.
        
        G = np.zeros((2*n-1, n))
        for q in range(2*n-1):
            k = q - (n-1)
            if k >= 0:
                m = n - k
                # f_q = dx * sum_{i=0}^{m-1} h[i]*(1-h[i+k])
                # d/dh[i] for i < m: dx*(1-h[i+k])
                # d/dh[i] for i >= k: -dx*h[i-k] (from term where i-k is the first index)
                G[q, :m] += dx * (1.0 - h[k:k+m])
                G[q, k:] += -dx * h[:m]
            else:
                d_abs = -k
                m = n - d_abs
                # f_q = dx * sum_{i=d_abs}^{n-1} h[i]*(1-h[i-d_abs])
                # d/dh[i] for i >= d_abs: dx*(1-h[i-d_abs])
                # d/dh[i] for i < m: -dx*h[i+d_abs] (from term where i+d_abs is the second index)
                G[q, d_abs:] += dx * (1.0 - h[:m])
                G[q, :m] += -dx * h[d_abs:]
        
        grad = G.T @ w
        h = h - lr * grad
        h = _project(h, target)
        
        cur_c5 = _exact_c5(h)
        if cur_c5 < best_c5:
            best_c5 = cur_c5
            best_h = h.copy()
            patience = 0
            lr = min(lr * 1.03, 0.02)
        else:
            patience += 1
            lr *= 0.92
            if patience % 50 == 0:
                tau *= 0.95
                lr = max(lr, 0.001)
            if patience > 300:
                break
    
    return best_h, best_c5

def _resample(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    if n_new < 4:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return _project(h_new, n_new / 2.0)

def _diverse_start(n, rng):
    """Generate diverse random initial conditions."""
    strategy = rng.integers(0, 6)
    x = np.arange(n)
    if strategy == 0:
        # Single frequency
        freq = rng.integers(1, 10)
        phase = rng.uniform(0, 2*np.pi)
        h = 0.5 + 0.4*np.sin(2*np.pi*freq*x/n + phase)
    elif strategy == 1:
        # Two frequencies
        f1, f2 = rng.integers(1, 6), rng.integers(2, 10)
        p1, p2 = rng.uniform(0, 2*np.pi), rng.uniform(0, 2*np.pi)
        h = 0.5 + 0.25*np.sin(2*np.pi*f1*x/n + p1) + 0.25*np.sin(2*np.pi*f2*x/n + p2)
    elif strategy == 2:
        # Block pattern
        n_blocks = rng.integers(2, 8)
        block_size = n // n_blocks
        h = np.zeros(n)
        for b in range(n_blocks):
            if rng.random() < 0.5:
                h[b*block_size:(b+1)*block_size] = 1.0
        h = h + rng.normal(0, 0.15, n)
    elif strategy == 3:
        # Sine with chirp
        freq = rng.uniform(2, 5)
        h = 0.5 + 0.4*np.sin(2*np.pi*freq*x/n + 0.5*np.pi*x**2/(n*n))
    elif strategy == 4:
        # Random smooth
        h = 0.5 + rng.normal(0, 0.2, n)
        kernel = np.array([0.1, 0.8, 0.1])
        h = np.convolve(h, kernel, mode='same')
    else:
        # Random binary smoothed
        h = (rng.random(n) < 0.5).astype(float)
        kernel = np.ones(5) / 5.0
        h = np.convolve(h, kernel, mode='same')
    
    h = _project(h, n / 2.0)
    return h
