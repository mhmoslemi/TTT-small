Actually, one more thought: the "smart pair" idea. How do I compute a good score for each index?

For index i, its contribution to the maximum correlation depends on:
- The value h[i] itself
- The values of h at positions that interact with i (i.e., i±k for active lags k)
- Whether h[i] is "helping" or "hurting" the active correlations

A simple score: For each active lag k, compute the "contribution" of index i to C_k. If h[i] is high and (1-h[i±k]) is high, then i is contributing a lot to C_k (bad). The score for index i is the sum (or max) of its contributions across active lags.

Indices with high scores are "bad" (contributing to high correlations) and should be decreased.
Indices with low scores are "good" and could be increased.

Wait, this isn't quite right. The "contribution" of h[i] to C_k is:
- If h[i] appears as the first factor: h[i] * (1-h[i-k]) → contribution is (1-h[i-k])
- If h[i] appears as the second factor: (1-h[i]) * h[i-k'] → the effect of h[i] is through (1-h[i]), so increasing h[i] decreases C_k by h[i-k']

So the "pressure" to decrease h[i] at lag k is:
- If h[i] is in the "first" position: (1-h[i-k]) (we want h[i] low when (1-h[i-k]) is high)
- If h[i] is in the "second" position: h[i+k] (we want h[i] high when h[i+k] is high, to make (1-h[i]) low)

Hmm, this is getting complicated. Let me just use the gradient approach, which is simpler and more principled.

The gradient of C_k with respect to h[i] is:
- If h[i] appears as h[a] in C_k = sum h[a]*(1-h[b]): ∂C_k/∂h[i] = (1-h[b]) where b = i-k
- If h[i] appears as h[b]: ∂C_k/∂h[i] = -h[a] where a = i+k

So the total gradient of C_k at index i is:
g_k[i] = (1-h[i-k]) * [i-k valid] - h[i+k] * [i+k valid]

And the "soft-max" gradient of F(h) is:
g[i] = sum_k w_k * g_k[i]

This is exactly what the previous code computes with `_row_grad` summed over active lags.

So for the "smart pair", I can compute the gradient and then:
- Find indices with the most negative gradient (decreasing h[i] helps the most) → candidates to decrease
- Find indices with the most positive gradient (increasing h[i] helps the most) → candidates to increase
- Pick a random pair from these sets

import numpy as np
import time


def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx


def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo = float(v.min()) - 2.0
    hi = float(v.max()) + 2.0
    for _ in range(70):
        mid = 0.5 * (lo + hi)
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = 0.5 * (lo + hi)
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    for _ in range(8):
        if abs(res) <= 1e-12:
            break
        if res > 0:
            mask = x < 1.0 - 1e-12
        else:
            mask = x > 1e-12
        cnt = int(np.sum(mask))
        if cnt == 0:
            break
        x[mask] += res / cnt
        x = np.clip(x, 0.0, 1.0)
        res = target - float(np.sum(x))
    return x


def _line_search(S0, T, Q, dx, L, U):
    if U - L < 1e-13:
        t = 0.5 * (L + U)
        return t, float(np.max(S0 + t * T - t * t * Q)) * dx
    nq = 80
    grid = np.linspace(L, U, nq)
    tv = grid[:, None]
    vals = S0[None, :] + tv * T[None, :] - (tv ** 2) * Q[None, :]
    obj = np.max(vals, axis=1) * dx
    i = int(np.argmin(obj))
    a = grid[max(i - 1, 0)]
    b = grid[min(i + 1, nq - 1)]
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    c1 = b - gr * (b - a)
    c2 = a + gr * (b - a)
    f1 = float(np.max(S0 + c1 * T - c1 * c1 * Q)) * dx
    f2 = float(np.max(S0 + c2 * T - c2 * c2 * Q)) * dx

        else:

            c2 = a + gr * (b - a)
            f2 = float(np.max(S0 + c2 * T - c2 * c2 * Q)) * dx

def _row_grad(h, k):
    n = len(h)
    g = np.zeros(n)
    if k >= 0:
        nn = np.arange(0, n - k)
    else:
        nn = np.arange(-k, n)
    a = nn + k
    b = nn
    g[b] += -h[a]
    g[a] += (1.0 - h[b])
    return g


def _soft_gradient(h, corr, k_active, tau):
    n = len(h)
    m = float(np.max(corr))
    w = np.exp((corr - m) / tau)
    idx = np.argsort(-corr)[:k_active]
    G = np.zeros(n)
    for r in idx:
        G += w[r] * _row_grad(h, r - (n - 1))
    return G


def _active_direction(h, corr, k_active, tau, rng):
    G = _soft_gradient(h, corr, k_active, tau)
    d = -G
    d -= d.mean()
    nrm = float(np.linalg.norm(d))
    if nrm < 1e-14:
        d = rng.standard_normal(len(h))
        d -= d.mean()
        nrm = float(np.linalg.norm(d))
    return d / nrm

    best_h = _project(best_h, len(best_h) / 2.0)
    final_f = _exact_c5(best_h)
    return best_h, final_f, len(best_h)
