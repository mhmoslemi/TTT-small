1. Approach and rationale

1.1 Central idea: a direct smooth-minimax nonlinear-programming engine

The supplied parent uses repeated constrained LP-like full directions, a surrogate quadratic line model, curvature/balance proposals, random/parent-multistart affine-pair moves, and resolution changes. The proposed replacement is a different primary machine: solve the smooth minimax problem directly with a log-sum-exp (LSE-softmax) surrogate for the maximum overlap, preserve the mass and box constraints algebraically as constraints in a constrained nonlinear solver, and keep only candidates that improve the original evaluator.

The exact problem is

C(h) = dx * max_r r(h), dx = 2/n, m = 2n - 1,
r(h) = correlation(h, 1 - h, mode="full").

The LSE surrogate is

f_beta(h) = (1/beta) * log sum_{r=0}^{m-1} exp(beta * r(h)).

For beta -> infinity, f_beta -> C(h). For finite beta, f_beta is smooth (as long as beta is finite) and has exact analytic gradients that combine every near-maximal overlap. The constrained nonlinear optimizer then solves

minimize f_beta(h)
subject to sum_i h_i = n/2, 0 <= h_i <= 1,

for an increasing ladder of beta values. This is mathematically meaningful: f_beta is not a convex relaxation of the exact max problem, nor is it claimed to be globally solvable by a globalizer. It is a nonconvex smooth surrogate. But it changes the bottleneck in a useful way. The previous LP/direction family tries to reduce only the currently top active overlaps, then falls back to ad-hoc curvature/balance directions. The LSE objective pulls all overlaps that are within about 1/beta of the maximum, forcing motion not merely along the top peak but along the entire active-overlap plateau. This can resolve hidden compatibility requirements among several active lags that a sparse top-only LP step cannot see.
