2. Compute the gradient matrix `G` (shape `(2n-1, n)`)
3. Solve an LP: minimize `t` subject to `G[i,:] @ v - t <= G[i,:] @ h - R[i]` for all rows, with `v_i` bounded in `[h_i - r, h_i + r]` and `sum(v) = n/2`

5. Do exact line search along `d` using the formula `R(alpha) = R0 + alpha*T - alpha^2*C`
6. Accept if exact evaluation shows improvement

Let me think about the implementation details:

**Computing G (gradient matrix):**
For row index `i` with `d = i - (n-1)`:
- If `d >= 0`, `m = n - d`:

  - `g[d:d+m] += -h[0:m]`
- If `d < 0`, `q = -d`, `m = n - q`:

  - `g[0:m] += -h[q:q+m]`

**LP Formulation:**
Variables: `[t, v_0, ..., v_{n-1}]` (total `n+1` variables)
- Objective: minimize `t` → `c = [1, 0, 0, ..., 0]`
- Inequality constraints: `G[i,:] @ v - t <= G[i,:] @ h - R[i]` for all i

  - `A_ub[j, 1:] = G[j, :]`

- Equality constraint: `sum(v) = n/2`

Now, the key question: will this actually improve the true objective? The true row values are:

The higher order terms for a bilinear function are actually not higher order - they're quadratic. Specifically:
`R_i(h + d) = R[i] + G[i,:] @ d - sum over the quadratic part`

`R_i(h) = sum_{j} h[j] * (1 - h[j+d_i])` (with appropriate limits)

`= sum_j h[j](1-h[j+d_i]) + eps * sum_j (d[j](1-h[j+d_i]) - h[j]*d[j+d_i]) - eps^2 * sum_j d[j]*d[j+d_i]`
`= R[i] + eps * G[i,:] @ d - eps^2 * C_i`

where `C_i = sum_j d[j] * d[j+d_i]` (with appropriate limits).

So the second-order term is `-eps^2 * C_i`. If `C_i > 0`, this is a decrease (good for minimizing max). If `C_i < 0`, this is an increase (bad).

The LP only sees the linear part. If the linear part decreases all rows equally, and the quadratic terms are favorable (negative), we get improvement. If some quadratic terms are positive (unfavorable), we might need to use a smaller step.

This is why we need the exact line search: we find the best alpha in [0, 1] that minimizes `max_i(R[i] + alpha*G[i,:]@d - alpha^2*C_i)`.

Using the matrix form:
`T = correlate(d, 1-h, 'full') - correlate(h, d, 'full')` which gives `T[i] = G[i,:] @ d`
`C = correlate(d, d, 'full')` which gives `C[i]`

So the objective at alpha is: `max(R0 + alpha*T - alpha^2*C) * dx`

This is a concave function of alpha (each row is concave in alpha due to the `-alpha^2*C_i` term when `C_i > 0`, but could be convex when `C_i < 0`). The max of concave functions is concave, so if all `C_i >= 0`, the objective is concave and we can use golden section. But if some `C_i < 0`, it's not necessarily concave.

In practice, for small steps (small r), `C_i` will be small and the quadratic term won't dominate, so the function will be approximately linear (concave) over the step. Golden section should still work well for finding a good minimum.

Actually wait - we want to MINIMIZE `max_i(R0[i] + alpha*T[i] - alpha^2*C[i])`. Each individual row `R0[i] + alpha*T[i] - alpha^2*C[i]` is concave in alpha if `C[i] >= 0` and convex if `C[i] < 0`. The max of a mix of concave and convex functions is not necessarily concave or convex.

But in practice, for the Erdős problem, most of the `C[i]` values will be positive (since d typically has both positive and negative entries, their product at nearby positions tends to be positive on average). So the function is likely nearly concave, and golden section will work.

import numpy as np
import time
from scipy.optimize import linprog

def _c5_exact(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _compute_G(h):
    n = len(h)
    G = np.zeros((2*n - 1, n))
    for i in range(2*n - 1):
        d = i - (n - 1)
        m = n - abs(d)
        if m <= 0:
            continue
        if d >= 0:
            G[i, :m] += 1.0 - h[d:d+m]
            G[i, d:d+m] += -h[:m]
        else:
            q = -d
            G[i, q:] += 1.0 - h[:m]
            G[i, :m] += -h[q:q+m]
    return G

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo = float(v.min()) - 2.0
    hi = float(v.max()) + 2.0
    for _ in range(70):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-12:
        if res > 0:
            mask = (x < 1.0) & (x > 0.0)
            if np.sum(mask) == 0:
                mask = x < 1.0
        else:
            mask = (x > 0.0) & (x < 1.0)
            if np.sum(mask) == 0:
                mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _line_search(R0, T, C, dx, lo, hi):
    """Find alpha in [lo, hi] that minimizes max(R0 + alpha*T - alpha^2*C) * dx"""
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    a, b = lo, hi
    c1 = b - gr * (b - a)
    c2 = a + gr * (b - a)
    f1 = float(np.max(R0 + c1 * T - c1 * c1 * C)) * dx
    f2 = float(np.max(R0 + c2 * T - c2 * c2 * C)) * dx
    for _ in range(50):
        if b - a < 1e-14:
            break
        if f1 < f2:
            b, c2, f2 = c2, c1, f1
            c1 = b - gr * (b - a)
            f1 = float(np.max(R0 + c1 * T - c1 * c1 * C)) * dx
        else:
            a, c1, f1 = c1, c2, f2
            c2 = a + gr * (b - a)
            f2 = float(np.max(R0 + c2 * T - c2 * c2 * C)) * dx
    opt = (a + b) / 2.0
    val = float(np.max(R0 + opt * T - opt * opt * C)) * dx
    # Check endpoints
    f0 = float(np.max(R0 + lo * T - lo * lo * C)) * dx
    f1e = float(np.max(R0 + hi * T - hi * hi * C)) * dx
    if f0 < val:
        opt, val = lo, f0
    if f1e < val:
        opt, val = hi, f1e
    return opt, val

def _sine_init(n, freq, phase):
    x = np.arange(n)
    h = 0.5 + 0.45 * np.sin(2 * np.pi * freq * x / n + phase)
    return _project(h, n / 2.0)

def _resample(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return _project(h_new, n_new / 2.0)

def _lp_trust_step(h, r, deadline):
    """One LP trust-region step. Returns (new_h, new_c5) or (None, None) if no improvement."""
    n = len(h)
    dx = 2.0 / n
    target = n / 2.0
    R0 = np.correlate(h, 1.0 - h, mode='full')
    cur_c5 = float(np.max(R0) * dx)
    G = _compute_G(h)
    
    # Build LP
    # Variables: [t, v_0, ..., v_{n-1}]
    c_obj = np.zeros(n + 1)
    c_obj[0] = 1.0
    
    A_ub = np.zeros((2*n - 1, n + 1))
    b_ub = np.zeros(2*n - 1)
    A_ub[:, 0] = -1.0
    A_ub[:, 1:] = G
    b_ub = G @ h - R0
    
    A_eq = np.zeros((1, n + 1))
    A_eq[0, 1:] = 1.0
    b_eq = np.array([target])
    
    # Bounds: t is free, v_i in [max(0, h_i - r), min(1, h_i + r)]
    v_lo = np.maximum(0.0, h - r)
    v_hi = np.minimum(1.0, h + r)
    bounds = [(-np.inf, np.inf)] + list(zip(v_lo, v_hi))
    
    try:
        result = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                         bounds=bounds, method='highs')
    except Exception:
        return None, None
    
    if not result.success:
        return None, None
    
    t_val = result.x[0]
    v = result.x[1:]
    d = v - h
    
    # Check if direction is meaningful
    if np.linalg.norm(d) < 1e-10:
        return None, None
    
    # Ensure d is exactly zero-sum (LP should give this, but numerical errors)
    d -= np.mean(d)
    
    # Line search
    T = np.correlate(d, 1.0 - h, mode='full') - np.correlate(h, d, mode='full')
    C = np.correlate(d, d, mode='full')
    
    # Feasible alpha range: h + alpha*d in [0, 1]
    lo_a = 0.0
    hi_a = 1.0
    pos = d > 1e-10
    neg = d < -1e-10
    if np.any(pos):
        hi_a = min(hi_a, float(np.min((1.0 - h[pos]) / d[pos])))
    if np.any(neg):
        lo_a = max(lo_a, float(np.max(h[neg] / d[neg])))
    # Since d = v - h and v is in [0,1], alpha=1 should be feasible
    # But numerically, clip
    hi_a = min(hi_a, 1.0)
    lo_a = max(lo_a, -1.0)
    
    if hi_a - lo_a < 1e-12:
        return None, None
    
    opt_a, opt_val = _line_search(R0, T, C, dx, lo_a, hi_a)
    
    if opt_a < 1e-10 or opt_val >= cur_c5 - 1e-13:
        return None, None
    
    new_h = h + opt_a * d
    new_h = _project(new_h, target)
    new_c5 = _c5_exact(new_h)
    
    if new_c5 < cur_c5 - 1e-13:
        return new_h, new_c5
    return None, None

        active_idx = np.where(scores >= threshold)[0]
        if len(active_idx) == 0:

        # Weighted gradient direction
        grads = np.zeros(n)
        for k in active_idx:
            d = k - (n - 1)
            m = n - abs(d)
            if d >= 0:
                grads[:m] += (1.0 - h[d:d+m])
                grads[d:d+m] += -h[:m]
            else:
                q = -d
                grads[q:] += (1.0 - h[:m])
                grads[:m] += -h[q:q+m]
        
        w = np.exp((scores[active_idx] - max_score) / (0.01 * max_score + 1e-15))
        w /= float(np.sum(w))

                    best_alpha = opt_a

            h = _project(h, target)

            if cur_c5 < best_c5:

                best_h = h.copy()

        else:

            if stall > 20 and rng.random() < 0.3:

                h = _project(h, target)
