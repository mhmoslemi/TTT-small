1. Approach and rationale

1.1 Central idea
The previous search was already close to the target, but it mixed an approximate trust-region direction, a projected feasible point, and an exact re-evaluation in a delicate way. The proposed improvement is to replace that particular transaction by an exact epigraph/trust-region/LP search in which every proposed path is feasible before it is measured, every line search uses the exact finite-support correlation objective, and every accepted point is re-validated in the original constraints.

The new primary method is a boxed continuation/active-set optimizer:

- Start at the validated parent, algorithmic low-discrepancy/binary/block starts, and resampled multi-resolution candidates.
- Optimize with directions generated by three complementary mechanisms:
  1. an exact linearizing LP on all or selected active correlation constraints,
  2. a gradient of a smoothed maximum objective (log-sum-expsylogit) using the exact correlation gradients,
  3. deterministic/localized random directions that respect the zero-sum, box constraints.
- For each candidate direction, choose the step by a one-dimensional exact global-optimal line search on the true correlation function (not just a model trust value), moving only points that remain in [0,1] and preserve the discrete sum exactly by construction.
- Maintain best candidates by exact acceptance only. If a projection or repair is required, accept only after exact re-evaluation.
- Supplement with low-level simulated annealing on binary/e-continuous map surfaces and a smoothed-max continuation using SLSQP/SQP methods on the continuous problem. These are secondary but help escape local maxima, especially near nonsmooth maximal-change breakpoints.
- Continue only useful resolutions while changing n within a moderate range, requiring objective comparison under the exact evaluator whenever resolution changes.

1.2 Bottleneck addressed
The parent-focused local methods could stall due local numerical degeneracies and because the product h_i h_j makes the geometry non-smooth. The key improvements are exact operation on a path that is already feasible while the search step takes place and exact global step searching, removing the main source of wasted moves where the projected value becomes good under one convention and bad under the evaluator. The new optimizer has a, that a direction accepted after projection is guaranteed feasible before the true objective is measured. The full exact line allows the non-smooth boundary between active correlation lags to be left by taking tiny, heavily tested, and multiplier denoted equality-directed moves in all directions. It may also leave local bases beyond simply active gradients.
