1. Approach and rationale

This plan replaces the parent’s smoothed-maximum/epigraph/SLSQP pipeline with a geometry-based, exact-direction minimizer for the discrete nonconvex problem.

The feasible set is the slice of the hypercube

- `0 <= h[i] <= 1` for all `i`
- `sum(h) = n/2`

The objective is not convex, but every accepted move is judged by the original evaluator. The key observation is that the objective can be written as a one-dimensional quadratic algebraic function along any feasible sum-zero line segment. Therefore, candidate directions can be generated from the exact local correlation geometry and locally optimized much more accurately than by scalar gradient descent or SLSQP. The central representation is not a smoothed max of a set of correlations, but the exact active correlation pattern.

The method has three complementary mechanisms:

First, use `DIRECTIONAL LINE SEARCH BASED ON THE EXACT CORRELATOR ORIGIN`, where any sum-zero direction admits an exact bracketed one-dimensional minimization of the true objective. This provides reliable local improvement even when individual candidate directions are weak.

Second, investigate the active correlation geometry through Frank-Wolfe-style and active-subgraph directions. The active correlation set defines a vector of coordinate derivatives; vertices of the feasible polytope are generated by ordering those derivatives and by combining the highest and lowest derivative positions. These directions are not claimed to be globally optimal for a convex or synchrony-related surrogate; they are heuristic directions accepted only through exact evaluation.

Third, use exact one-step pair LIPS partners and small block percentage pass integers, followed by multi-resolution pair пошаг candidate processing. Single-coordinate moves are too slow and too weak at normals; the paired mass-transfer unit can propagate the minor variation produced within any core maybe alsogo the last few digits.

This is materially different from the supplied previous program because it establishes A NULL new solver architecture, not just a different continuation of smoothing and epigraph actions:
- no minimization of smoothed max
- no SLSQP epigraph subproblems
- each direction, whether a vertex/FW candidate, paired direction, or block direction, is evaluated using the exact correlation along a one-dimensional affine transversal directly derived from underlying `np.correlate` convention
- large search effort is in coordinate pair derivative and active constraints deterministically derived from the exact correlation recurrence
- the search preserves cheap smaller and reduced dimensions as the core by moving candidates across multiple local resolutions.

This is intended as a powerful nonconvex local search mechanism capable of finding desired marginal improvements.

2. Mathematical specification

2.1 Discrete objective

For returned length `n` (`n` is even in all finished candidates unless the parent has odd length), and `dx = 2.0 / n`, input configuration is a one-dimensional float array `h`.

The authoritative evaluation is:

`C5(h) = dx * max_r np.correlate(h, 1.0 - h, mode="full")[r]`

The correlation length is `m = 2*n - 1`. This exact evaluator from numpy is used for:
- all saved candidate scores
- all final feasibility/score certification.

For completeness, replacing it with a periodic/circular objective, dropping lag terms, or replacing it by `1 - autocorrelation` is spoiled because boundary truncation is directly in `np.correlate($ mode="full")`.
