1. Approach and rationale

1.1 Central idea

The supplied construction is likely near a local plateau for one fixed discretization. The proposed plan improves it by applying a feasible-direction local-and-growing search whose elementary move is an exact two-coordinate mass transfer between two sample points. In one move, mass is added to one coordinate and subtracted from another; the total sum and the box constraints can be maintained exactly throughout the move by restricting the move size to a one-dimensional feasible interval. The exact objective along that direction is known analytically because it is a maximum of quadratic functions of the scalar along the direction. This makes exact search over the scalar possible without linear programming, simulated annealing, or post-move projection of arbitrary general nonlinear steps.

The direction is chosen from a smooth-max minimax signal. Instead of the max overlap itself, a soft maximum over all shifted overlap values is differentiated. This smooth objective has a vector gradient with respect to the entries of h. The smooth gradient indicates which coordinates currently contribute high overlap and should lose mass, and which coordinates can receive mass at lower continuation cost. Ordered pairs of high-gradient/source coordinates and low-gradient/sink coordinates are then tested exactly using a one-dimensional exact quadratic curve, not a linearized approximation.

The method is also resolution-aware. The supplied parent is embedded into neighboring resolutions and also run in binary form. Small down-sampling and up-sampling perturbations can break discretization lock-in. A resolution-polishing loop repeatedly maps the current best vector to nearby grid sizes and optimizes there, returning the global best over all resolutions. The objective is always evaluated by the original evaluator formula before acceptance; internal smooth and exact quadratic quantities only guide search.

1.2 Why this targets the previous bottleneck

The earlier parent already achieved near-median performance but did not fall below the current best record. The most likely bottleneck is not lack of merit in the general solution but the inability of coarse or generically sampled moves to remove tiny active overlap peaks. Exact pair-transfer moves give fine control over a single active coordinate pair, and the smooth-max gradient is specifically designed to target the highest shifted overlaps. The scalar step can be chosen with respect to the real overlap maximum, within the one-step feasible interval. The line search does not rely solely on the linear approximation; its quadratic expansion and exact acceptance are both centered on the true discrete overlap objective.

Using different resolutions is also important. A solution on n=180 may have many active but discretization-specific lag constraints. Resampling to neighboring even n values transforms the set of realized lags while preserving the overall h shape. This creates new local vertices and can uncover a lower-correlation discretization that interpolates upward into a better solution at another resolution.

1.3 What is justified versus heuristic

Justified mathematical facts:

- For any vector d with zero sum, if h_target = S = n/2 and h_new = h + alpha*d, then sum(h_new)=S. For pair directions d=e_i-e_j, choosing alpha in its interval automatically preserves all [0,1] constraints exactly in exact arithmetic.
- For smooth bounded discrete h, the exact shifted-overlap vector is bilinear in h and its complement. Because of bilinearity, along any linear feasible direction d the exact shifted overlap vector is a quadratic function of scalar alpha. For pair directions this quadratic has an explicit coefficient vector.
- The objective is a pointwise maximum over shifted raw values; applying a positive scaling dx preserves all maximizers.
- The maximum over one quintic lag set evaluated by the arbitrary offset convention same for correlate. The intrinsic discrete overlap values are the same max regardless of whether we internally store lag index upwards; reversal of lag vector does not change the maximum.

Heuristics:

- Smooth-max weights approximate the nonsmooth maximum. They select candidate directions; no candidate is accepted unless the exact objective improves.
- The one-step soft gradient is only gradient-based. It may misidentify some exact descent directions when the general maximum is flat or multiple nearby lags change dominance. Exact pair vector candidate set counters this.
- Pair-transfer only searches the first-order zero-sum lattice directions. This can converge to local minima and cannot certify a global optimum.

1.4 Coherent selection of main representation and operations

The main exact descent is not a global convex solver. It is an adaptive local method with several diversifications:

1. Exact pair-transfer line search along smooth-max-selected coordinate pairs.
2. Resolution-cycling over neighboring even n values.
3. Diverse array and reverse mapping parent transforms, deterministic and low-cost start generation, and short perturbations.
4. Global best acceptance at each update. If no improvement with one neighborhood, shrink the trusted scalar rank or strengthen smooth maximum (make it focus on the sharper active peaks). The routine returns a known valid parent/fallback.

This is materially different from LP/B茅台酒/SA-family routines. No LP relaxation or subproblem; no general simulated-annealed moves; no acceptance using surrogate objective; no arbitrary projection step after arbitrary general gradient steps. The accepted core update is preserved by interior feasible pair interval and exact reevaluation.
