= (1-h[j-k'])*[j-k' ≥ 0, i.e., j ≥ k'] + (-h[j+k'])*[j ≤ n-1-k']

For k = 0:
= (1-h[j]) * 1 + (-h[j]) * 1 = 1 - 2h[j]

This makes sense! At k=0, C[n-1] = ∑h[i](1-h[i]), and ∂C/∂h[j] = (1-h[j]) + h[j]*(-1) = 1-2h[j]. ✓

```python
    """Compute B[m] = dC[m]/dh[i] for all lags m."""
    n = len(h)
    center = n - 1
    B = np.zeros(2 * n - 1)
    # For each shift k = m - center:
    # dB[m]/dh[i] = (1-h[i+k])*[0<=i+k<n] + (-h[i-k])*[0<=i-k<n]
    for m in range(2 * n - 1):
        k = m - center
        val = 0.0
        ik = i + k
        if 0 <= ik < n:
            val += (1.0 - h[ik])
        ik2 = i - k
        if 0 <= ik2 < n:
            val += (-h[ik2])
        B[m] = val
    return B
```

```python
def _grad_for_coord_vec(h, i):
    n = len(h)
    B = np.zeros(2*n-1)
    # Positive shifts k = 0..n-1
    for k in range(n):
        # B[n-1+k]: h[i] is "first" at position i, "second" at position i-k
        # As "first": (1-h[i+k]) if i+k < n
        # As "second": -h[i-k] if i-k >= 0
        b = 0.0
        if i + k < n:
            b += 1.0 - h[i+k]
        if i - k >= 0:
            b += -h[i-k]
        B[n-1+k] += b
    # Negative shifts k = 1..n-1
    for k in range(1, n):
        # B[n-1-k]: h[i] is "first" at position i, "second" at position i+k
        b = 0.0
        if i - k >= 0:
            b += 1.0 - h[i-k]
        if i + k < n:
            b += -h[i+k]
        B[n-1-k] += b
    return B
```

This is O(n) per coordinate. For the 1D minimax, I need to evaluate f(t) = max_m (A[m] + B[m]*t) for several t values.

A[m] = C[m] - B[m] * h[i] (the current correlation minus the contribution of h[i])

Then f(t) = max_m (C[m] - B[m]*h[i] + B[m]*t) = max_m (C[m] + B[m]*(t - h[i]))

Let u = t - h[i]. Then f = max_m (C[m] + B[m]*u) and u ∈ [-h[i], 1-h[i]].

This is nice! The 1D problem is: minimize g(u) = max_m (C[m] + B[m]*u) over u ∈ [-h[i], 1-h[i]].

And g is convex PL in u. The minimum is at:
- u = 0 if the current point is optimal (subgradient contains 0)
- Some other u if we can reduce the max

The "descent direction" in u is: if the max is achieved by lines with positive slope at u=0, we should decrease u (i.e., decrease h[i]). If by lines with negative slope, increase u.

The optimal u* is where the "weighted" slope (considering only active lines) crosses zero.

For a simple implementation, I'll just do:
1. Compute B[m] for all m
2. Find the optimal u by ternary/golden search on g(u) = max_m(C[m] + B[m]*u)
3. Update h[i] = h[i] + u*

This is clean and exact (up to the numerical precision of the golden search).
