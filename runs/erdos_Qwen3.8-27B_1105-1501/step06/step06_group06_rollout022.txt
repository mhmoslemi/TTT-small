from scipy.optimize import minimize
import time

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo = float(v.min()) - 2.0
    hi = float(v.max()) + 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-12:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _line_search_exact(h, d, alpha_max):
    """Exact line search along direction d (sum d = 0)."""
    n = len(h)
    dx = 2.0 / n
    c0 = np.correlate(h, 1.0 - h, mode='full')
    L = np.correlate(d, 1.0 - h, mode='full') - np.correlate(h, d, mode='full')
    Q = -np.correlate(d, d, mode='full')
    
    # Feasible alpha interval
    pos = d > 1e-14
    neg = d < -1e-14
    alpha_lo = -alpha_max
    alpha_hi = alpha_max
    if np.any(pos):
        alpha_hi = min(alpha_hi, float(np.min((1.0 - h[pos]) / d[pos])))
    if np.any(neg):
        alpha_lo = max(alpha_lo, float(np.min(h[neg] / (-d[neg]))))
    
    if alpha_hi - alpha_lo < 1e-12:
        return 0.0, _exact_c5(h)
    
    # Grid search + golden section
    n_grid = 64
    grid = np.linspace(alpha_lo, alpha_hi, n_grid)
    vals = c0[None, :] + grid[:, None] * L[None, :] + grid[:, None]**2 * Q[None, :]
    obj = np.max(vals, axis=1) * dx
    best_i = int(np.argmin(obj))
    best_t = grid[best_i]
    best_val = obj[best_i]
    
    # Golden section refinement
    if 0 < best_i < n_grid - 1:
        a, b = grid[best_i-1], grid[best_i+1]
    else:
        a, b = alpha_lo, alpha_hi
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    fa = float(np.max(c0 + a*L + a*a*Q)) * dx
    fb = float(np.max(c0 + b*L + b*b*Q)) * dx
    for _ in range(50):

        fm1 = a + gr*(b-a)
        fm2 = b - gr*(b-a)
        fm1_val = float(np.max(c0 + fm1*L + fm1*fm1*Q)) * dx

    if mid_val < best_val:

def _soft_gradient(h, gamma):
    """Compute soft-max weighted gradient of C5."""
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    M = np.max(corr)
    # Soft-max weights
    exponents = gamma * (corr - M)
    # Clip to avoid underflow
    exponents = np.maximum(exponents, -50.0)
    w = np.exp(exponents)
    w /= w.sum()
    
    # Gradient: d(c_k)/d(h_i) for each lag k
    # c_k = sum_i h[i] * (1-h[i+k-(n-1)])
    # d(c_k)/d(h_i) = (1-h[i+k-(n-1)]) - h[i-k+(n-1)] (where valid)
    
    # Build the weighted gradient
    grad = np.zeros(n)
    for k in range(2*n-1):
        wk = w[k]
        if wk < 1e-15:
            continue
        s = k - (n-1)  # lag
        m = n - abs(s)
        if s >= 0:
            # c_k = sum_{i=0}^{n-1-s} h[i]*(1-h[i+s])
            # d/dh[i] = (1-h[i+s]) for i in [0, n-1-s]
            # d/dh[i+s] = -h[i] for i in [0, n-1-s], i.e., for j in [s, n-1]
            grad[:m] += wk * (1.0 - h[s:s+m])
            grad[s:s+m] -= wk * h[:m]
        else:
            g = -s
            # c_k = sum_{i=g}^{n-1} h[i]*(1-h[i-g])
            # d/dh[i] = (1-h[i-g]) for i in [g, n-1]
            # d/dh[i-g] = -h[i] for i in [g, n-1], i.e., for j in [0, n-1-g]
            grad[g:g+m] += wk * (1.0 - h[:m])
            grad[:m] -= wk * h[g:g+m]
    
    grad *= dx
    # Make sum-zero
    grad -= grad.mean()
    return grad

Since Q has only 3 non-zero entries, for most lags the function is linear in α. The maximum of a set of linear (and 3 quadratic) functions is a piecewise-linear (with 3 quadratic pieces) convex function of α. The minimum of this convex function can be found by:
1. Finding the k that is maximized at α=0 (the active lags)
2. For each active lag, finding the α that minimizes c0[k] + α*L[k] + α²*Q[k]
3. The overall minimum is at the point where the maximum switches

Actually, the minimum of the max of convex functions is not necessarily at a point where any single function is minimized. It's at the point where the "envelope" has its minimum, which typically occurs where two or more functions are equal.

But for practical purposes, the grid + golden section approach works well enough.

For the pairwise coordinate descent, the key question is: which pairs to try? Trying all n(n-1)/2 pairs is O(n²) per iteration, and for each pair we need to evaluate the line search (which involves computing L and the full objective along the line). 

For n=122, that's about 7300 pairs. If each evaluation takes about 10μs (which is optimistic in Python), that's 73ms per full sweep. We could do about 100 sweeps in the available time.

But computing L for each pair separately would be expensive. However, we can precompute the "contribution" of each coordinate to each lag, and then L for a pair (i,j) is just the difference of two precomputed vectors.

Let me define:
    G_k(i) = (1-h[i+k-(n-1)])_valid - h[i-k+(n-1)]_valid  (contribution of coordinate i to lag k)

Then L_{ij}[k] = G_k(i) - G_k(j).

If we precompute G as a matrix of shape (2n-1, n), then L_{ij} = G[:, i] - G[:, j], which is O(2n) to compute.

The total cost of a full sweep is O(n² * 2n) = O(n³) ≈ 122³ ≈ 1.8M operations. That's feasible.

But actually, for the line search, we need to evaluate:
    φ(α) = dx * max_k (c0[k] + α*(G_k(i) - G_k(j)) + α²*Q_k(i,j))

For a given pair (i,j), this is a scalar function of α that we need to minimize. The grid + golden section approach takes about 100 evaluations, each O(2n). So per pair: O(200n) ≈ 25000 operations. For all pairs: O(n² * 200n) = O(200n³) ≈ 370M operations. That's too slow.

We need to be smarter. Instead of trying all pairs, we should:
1. Identify the "active" lags (those near the maximum)
2. For each active lag, find the best pair that reduces it
3. Only try a few pairs per iteration

For a given active lag k, the change in c_k from pair (i,j) is:
    Δc_k = α*(G_k(i) - G_k(j)) + α²*Q_k(i,j)

To minimize c_k, we want G_k(i) - G_k(j) to be as negative as possible (for small α). So we want i with small G_k(i) and j with large G_k(j).

This suggests: for each active lag k, find the i minimizing G_k(i) and the j maximizing G_k(j), then try the pair (i,j).

But we also need to consider that reducing one lag might increase others. So we should try a few candidate pairs and use the full line search.

Let me design the algorithm:

```
For each iteration:
  1. Compute all correlations c[k]
  2. Find active lags: those with c[k] > max_c - tolerance
  3. For each active lag k:
     a. Compute G_k = the vector of contributions (length n)
     b. Find i* = argmin G_k and j* = argmax G_k
     c. Try pair (i*, j*) with line search
  4. Also try soft-gradient direction with line search
  5. Accept the best move
```

This is O(n * n_active) per iteration for the G_k computations, plus the line searches. If n_active is small (say 5-20), this is very fast.

Actually, let me try something simpler: a projected subgradient method with Nesterov acceleration.

The subgradient of max_k c_k * dx at point h is:
- If the max is unique at k*: ∇(dx * c_{k*})
- If the max is at k1, ..., km: any convex combination of ∇(dx * c_{kj}) for j=1,...,m

Using the soft-max as a smooth approximation gives a differentiable surrogate. The gradient of the soft-max surrogate is:
    ∇S_γ(h) = dx * sum_k p_k * ∇c_k

where p_k = exp(γ(c_k - M)) / sum_j exp(γ(c_j - M)).

As γ → ∞, this approaches the true subgradient. For finite γ, it's a smooth approximation.

The Nesterov accelerated gradient method:
    x_k = x_{k-1} + (α_k - 1) * (x_{k-1} - x_{k-2})
    y_k = x_k - β * ∇S(x_k)
    x_{k+1} = projection(y_k)

where α_k = 2/(k+2) and β is a step size.

But we also have the constraint sum(h) = n/2 and 0 <= h <= 1. The projection onto this set is _project.
