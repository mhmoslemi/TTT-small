So for j from 0 to n-1-g: G_s[j] += -h[j+g]

So:
For s >= 0:
  G_s[0:n-s] += (1 - h[s:n])
  G_s[s:n] += -h[0:n-s]
For s < 0 (g = -s):
  G_s[g:n] += (1 - h[0:n-g])
  G_s[0:n-g] += -h[g:n]

This is O(n) per shift, and we have O(n) shifts, so total O(n^2). Good.

Let me also think about a completely different approach: ** saddle point / Villani's twist**.

The minimax problem can be written as:
min_h max_k f_k(h)

By minimax duality (under some conditions), this equals:
max_{p in simplex} min_h sum_k p_k * f_k(h)

The inner minimization is a quadratic program (since each f_k is quadratic in h), and the outer maximization is over the simplex. We could use a dual ascent method:
1. Start with p = uniform
2. Solve the QP: min_h sum_k p_k * f_k(h) subject to constraints
3. Update p: p_k <- p_k * exp(eta * f_k(h*)) (multiplicative weights)
4. Repeat

This is the "multiplicative weights" or "exponential weights" approach to online convex optimization. It's guaranteed to converge, and the convergence rate is O(sqrt(log(K)/T)) where K is the number of constraints and T is the number of iterations.

For our problem, K = 2n-1 ≈ 243, so we'd need about log(243)/epsilon^2 ≈ 5.5/epsilon^2 iterations. For epsilon = 0.001, that's about 5.5 million iterations, which is too many. But the practical convergence is usually much faster.

Actually, the QP in step 2 is:
min_h sum_k p_k * [sum_i h[i](1-h[i+s_k])] * dx
subject to: sum(h) = n/2, 0 <= h <= 1

This is a concave maximization (or convex minimization of a concave function)... wait, no.

f_k(h) = sum_i h[i] * (1-h[i+s_k]) * dx = (sum_i h[i]) * dx - sum_i h[i]*h[i+s_k] * dx

So sum_k p_k * f_k(h) = (sum_i h[i]) * dx - sum_k p_k * sum_i h[i]*h[i+s_k] * dx

The first term is linear (and constant since sum(h) is fixed), so we're really minimizing:
sum_k p_k * sum_i h[i]*h[i+s_k] * dx

This is a quadratic form in h! Specifically:
h^T (sum_k p_k * Q_k) h * dx

where Q_k is the matrix with (Q_k)_{i,j} = 1 if j-i = s_k.

So the QP is:
min h^T A(p) h
subject to: 1^T h = n/2, 0 <= h <= 1

where A(p) = sum_k p_k * Q_k * dx.

This is a convex QP if A(p) is positive semidefinite. Is it? Q_k is a permutation-like matrix (it's the matrix for shift s_k), and its eigenvalues are on the unit circle. So A(p) is a sum of such matrices with nonnegative weights, which means its eigenvalues are |sum_k p_k * exp(i * theta_k)| where theta_k are the eigenphases. This is NOT necessarily positive semidefinite!

Actually, let me reconsider. Q_k has entries (Q_k)_{i,j} = 1 if j = i + s_k (with appropriate boundary handling). This is not a standard shift matrix because of the boundary. But even for a circulant shift, the eigenvalues are exp(i * 2*pi * s_k * m / n) for m=0,...,n-1. The sum of such with weights p_k has eigenvalues sum_k p_k * exp(i * 2*pi * s_k * m / n), which has magnitude at most 1 but is not necessarily positive.

So A(p) is NOT necessarily positive semidefinite, and the QP might be non-convex. This makes the approach harder.

However, in practice, for the optimal p (which is the dual variable at the minimax solution), the QP should be well-behaved. And we can use a general QP solver or even SLSQP to solve it.

import numpy as np
from scipy.optimize import minimize, linprog
import time


def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)


def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo = float(v.min()) - 2.0
    hi = float(v.max()) + 2.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-13:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x


def _corr_grads(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    G = np.zeros((2 * n - 1, n))
    for s in range(-(n - 1), n):
        k = n - 1 + s
        if s >= 0:
            G[k, :n - s] += (1.0 - h[s:n])
            G[k, s:n] += (-h[:n - s])
        else:
            g = -s
            G[k, g:n] += (1.0 - h[:n - g])
            G[k, :n - g] += (-h[g:n])
    G *= dx
    return corr, G


def _lse_optimize(h0, deadline):
    n = len(h0)
    target = n / 2.0
    h = h0.copy()
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    tau_seq = [5, 15, 40, 100, 250, 600, 1500, 4000, 10000]
    for tau in tau_seq:
        if time.time() > deadline:
            break
        lr = 0.8 / (tau + 1.0) * n * 0.1
        for it in range(80):
            if time.time() > deadline:
                break
            corr, G = _corr_grads(h)
            mc = float(np.max(corr))
            exp_c = np.exp(tau * (corr - mc))
            w = exp_c / np.sum(exp_c)
            grad = w @ G
            h_new = h - lr * grad
            h_new = _project(h_new, target)
            c5_new = _exact_c5(h_new)
            if c5_new < cur_c5 - 1e-15:
                h = h_new
                cur_c5 = c5_new
                if cur_c5 < best_c5:
                    best_c5 = cur_c5
                    best_h = h.copy()
                lr = min(lr * 1.03, 2.0 / (tau + 1.0) * n * 0.1)
            else:
                lr *= 0.6
                if lr < 1e-12:
                    break
    return best_h, best_c5


def _exact_line_search(h, d):
    n = len(h)
    dx = 2.0 / n
    s_lo = 0.0
    s_hi = 0.5
    pos = d > 1e-14
    neg = d < -1e-14
    if np.any(pos):
        s_hi = min(s_hi, float(np.min((1.0 - h[pos]) / d[pos])))
    if np.any(neg):
        s_lo = max(s_lo, -float(np.min(h[neg] / d[neg])))
    s_hi = min(s_hi, 0.5)
    if s_hi - s_lo < 1e-14:
        return 0.0, _exact_c5(h)
    grid = np.linspace(s_lo, s_hi, 32)
    best_s = s_lo
    best_val = _exact_c5(h + s_lo * d)
    for s in grid:
        hv = h + s * d
        v = _exact_c5(hv)
        if v < best_val:
            best_val = v
            best_s = s
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    a, b = s_lo, s_hi
    for _ in range(50):
        if b - a < 1e-12:
            break
        m1 = b - gr * (b - a)
        m2 = a + gr * (b - a)
        f1 = _exact_c5(h + m1 * d)
        f2 = _exact_c5(h + m2 * d)
        if f1 < f2:
            b = m2
        else:
            a = m1
    mid = (a + b) / 2.0
    fm = _exact_c5(h + mid * d)
    if fm < best_val:
        best_val = fm
        best_s = mid
    return best_s, best_val


def _active_descent(h0, deadline, max_iter=800):
    n = len(h0)
    target = n / 2.0
    h = h0.copy()
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    radius = 0.08
    stall = 0
    rng = np.random.default_rng(31415)

    for _ in range(max_iter):
        if time.time() > deadline:
            break
        if stall > 50:
            if radius > 0.03:
                radius = max(0.03, radius * 0.5)
            else:
                h = h + rng.normal(0, 0.02, n)
                h = _project(h, target)
                cur_c5 = _exact_c5(h)
                radius = 0.08
                stall = 0
                continue
            if stall > 100:
                break

        corr, G = _corr_grads(h)
        M = cur_c5
        eps = max(2e-5, M * 0.002)
        active = np.where(corr >= M - eps)[0]
        if len(active) == 0:
            active = np.argsort(-corr)[:10]
        elif len(active) > 50:
            top_order = np.argsort(-corr[active])
            active = active[top_order[:50]]

        G_act = G[active]
        c_vec = np.zeros(n + 1)
        c_vec[-1] = 1.0
        A_ub = np.zeros((len(active), n + 1))
        A_ub[:, :n] = G_act
        A_ub[:, n] = -1.0
        b_ub = -(corr[active] - M * 0.5)
        A_eq = np.zeros((1, n + 1))
        A_eq[0, :n] = 1.0
        bounds = [(max(-radius, -h[j]), min(radius, 1.0 - h[j])) for j in range(n)]
        bounds.append((-radius * 5, radius * 5))
        try:
            res = linprog(c_vec, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=[0.0],
                          bounds=bounds, method='highs')
            if res.success:
                d = res.x[:n]
            else:
                d = None
        except Exception:
            d = None

        if d is None or np.max(np.abs(d)) < 1e-14:
            grad_sum = G_act.sum(axis=0)
            grad_sum -= grad_sum.mean()
            d = -grad_sum
            dn = np.linalg.norm(d)
            if dn < 1e-12:
                stall += 10
                radius *= 0.7
                continue
            d = d / dn * radius

        alpha, new_c5 = _exact_line_search(h, d)
        if new_c5 < cur_c5 - 1e-14:
            h = h + alpha * d
            h = _project(h, target)
            cur_c5 = _exact_c5(h)
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            stall = 0
            if abs(alpha) > 0.4 * radius:
                radius = min(radius * 1.15, 0.3)
            else:
                radius = min(radius * 1.02, 0.25)
        else:
            stall += 1
            radius *= 0.7
            if radius < 1e-5:
                break

    return best_h, best_c5


def _slsqp_optimize(h0, deadline, max_outer=20):
    n = len(h0)
    dx = 2.0 / n
    target = n / 2.0
    h = h0.copy()
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5

    for outer in range(max_outer):
        if time.time() > deadline:
            break
        corr = np.correlate(h, 1.0 - h, mode='full') * dx
        M = float(np.max(corr))
        eps = max(3e-5, M * 0.003)
        active = np.where(corr >= M - eps)[0]
        if len(active) == 0:
            active = np.argsort(-corr)[:20]
        elif len(active) > 35:
            top_order = np.argsort(-corr[active])
            active = active[top_order[:35]]

        t_init = cur_c5 + 1e-5
        x0 = np.concatenate([h, [t_init]])

        def _obj(x):
            return x[n]

        def _obj_g(x):
            g = np.zeros(n + 1)
            g[n] = 1.0
            return g

        def _ineq(x):
            hx = x[:n]
            c = np.correlate(hx, 1.0 - hx, mode='full') * dx
            return x[n] - c[active]

        def _ineq_j(x):
            hx = x[:n]
            _, G = _corr_grads(hx)
            J = np.zeros((len(active), n + 1))
            J[:, :n] = -G[active, :]
            J[:, n] = 1.0
            return J

        def _eq(x):
            return np.sum(x[:n]) - target

        def _eq_j(x):
            g = np.zeros(n + 1)
            g[:n] = 1.0
            return g

        bounds = [(0.0, 1.0)] * n + [(0.0, 2.0)]
        cons = [
            {'type': 'ineq', 'fun': _ineq, 'jac': _ineq_j},
            {'type': 'eq', 'fun': _eq, 'jac': _eq_j},
        ]
        res = minimize(_obj, x0, method='SLSQP', jac=_obj_g,
                       bounds=bounds, constraints=cons,
                       options={'maxiter': 50, 'ftol': 1e-13})
        if res.success:
            h_new = _project(res.x[:n], target)
            c5_new = _exact_c5(h_new)
            if c5_new < cur_c5 - 1e-14:
                h = h_new
                cur_c5 = c5_new
                if cur_c5 < best_c5:
                    best_c5 = cur_c5
                    best_h = h.copy()
            else:
                break
        else:
            break

    return best_h, best_c5


def _resample(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return _project(h_new, n_new / 2.0)


def _smooth_perturb(h, rng, amount=0.01):
    n = len(h)
    noise = rng.normal(0, amount, n)
    noise -= noise.mean()
    h_new = h + noise
    return _project(h_new, n / 2.0)

def _structured_init(n, rng):
    h = np.zeros(n)
    pos = 0
    while pos < n:
        blen = max(1, int(rng.integers(2, max(3, n // 3 + 1))))
        if rng.random() < 0.5:
            h[pos:pos + blen] = 1.0
        pos += blen
    return _project(h, n / 2.0)
