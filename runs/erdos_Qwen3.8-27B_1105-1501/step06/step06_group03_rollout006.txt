Let me be careful about the line search. The key insight is that along a direction d, the objective is a max of quadratic functions. The minimum of this max over t is the "minimax" point on the line. This is a 1D problem that can be solved exactly (it's the smallest t such that all quadratic functions are ≤ some value, which is a bisection on the value).

Actually, for a max of quadratics, the optimal t can be found by:
1. Bisection on the objective value v: find smallest v such that there exists t with all q_r(t) ≤ v
2. For a given v, the feasible set of t is the intersection of intervals (one per quadratic), which is an interval (or empty)
3. So we can bisection on v, and for each v check feasibility

But this is more complex than golden section and might not be faster in practice. Let me stick with grid + golden section but use more grid points (like 128) and more golden section iterations.

Actually, there's an even better approach: since each q_r(t) is a downward-opening or upward-opening parabola (C_r = -∑d_i*d_{i+k} ≤ 0 for the standard correlation), the max of these is a convex function of t (max of concave functions... wait no).

C_r = -np.correlate(d, d, mode='full')[r] = -∑ d_i * d_{i - (r-(n-1))}

For r = n-1 (k=0): C = -∑d_i² < 0 (concave parabola)
For other r: C_r can be positive or negative depending on the autocorrelation of d.

If all C_r < 0, then each q_r(t) is a concave parabola, and their max is... not necessarily convex or concave. It's the envelope of concave parabolas.

If some C_r > 0, those are convex parabolas and the max could be even more complex.

In practice, for small steps (small trust region), the C_r terms are small and the problem is approximately linear, so golden section works well.

def _project(v, target):

    A_ub[:, :n] = G
    A_ub[:, n] = 1.0

    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0

def _soft_dir(h, S, n, theta):
    """Softmax-weighted gradient direction."""
    M = float(S.max())
    x = (S - M) / theta
    x -= x.max()  # numerical stability
    w = np.exp(x)
    w_sum = w.sum()
    if w_sum < 1e-300:
        return None
    w = w / w_sum
    top_k = min(40, 2 * n - 1)
    top_idx = np.argsort(-S)[:top_k]
    G = _grad_rows(h, top_idx, n)
    g = w[top_idx] @ G
    g -= g.mean()
    if np.abs(g).max() < 1e-14:
        return None
    return -g / np.abs(g).max()
