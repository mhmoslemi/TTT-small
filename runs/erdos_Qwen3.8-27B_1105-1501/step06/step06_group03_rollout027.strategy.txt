2.1 Representation and exact evaluator

Let n be the returned integer number of samples and dx = 2/n. The action vector h is h ∈ [0,1]^n. Run says the area constraints are

    0 ≤ h_i ≤ 1,   sum_i h_i = n/2.

An implementation must use this exact expression for all candidate acceptance and final evaluation. Do not replace it by a circular correlation or by a full-interval autocorrelation formula that ignores partial support at the ends.

Define the lag k = r - (n - 1). For r selected by the evaluator's correlation ordering, the exact sum used in the gradient is the common finite-support formula:

    k ≥ 0: q_r(h) = dx ∑_{i=0}^{n-k-1} h_i (1 - h_{i+k})

Both boundary-limited cases must be supported, including k = 0. A small numerical gradient verification should be included as a sanity test. The returned exact bound from final vector re-evaluation is always checked directly without using the formula.

The gradient of q_r with respect to h contains six cases in practical indexing:

- for k=0:
  ∂q_0/∂h_i = dx(1 - 2h_i)
- for 0 ≤ j < n-k when k>0, as first appearance of q_r:
  add dx(1 - h_{j+k})
- for k ≤ j < n when k>0, second appearance due to the term -h_{j-k}h_j:
  add -dx h_{j-k}
- for k<0 with d=-k and using the written reversed expression:
