3. The binary objective for a sequence with n/2 ones is:
   C = max_k dx * (number of pairs (i,j) with h[i]=1, h[j]=0, j-i=k)

For a binary swap (i: 1→0, j: 0→1), the change in the count at each lag can be computed in O(1) if we precompute the current counts.

Wait, actually the change at lag k is:
- If h[i]=1 and h[i-k]=0: the pair (i, i-k) contributes to lag k. Removing h[i]=1 removes this contribution. Change: -1.
- If h[i]=1 and h[i+k]=0: the pair (i+k, i) contributes to lag -k. Removing h[i]=1 removes this. Change: -1 at lag -k.
- Adding h[j]=1: if h[j-k]=0, adds 1 to lag k. If h[j+k]=0, adds 1 to lag -k.

So for a swap (i: 1→0, j: 0→1):
Δcount[k] = -[h[i-k]=0] + [h[j-k]=0] - [h[i+k]=0] + [h[j+k]=0] (with appropriate boundary handling and accounting for the fact that h[i] and h[j] change)

More precisely, after the swap:
- h[i] becomes 0, h[j] becomes 1
