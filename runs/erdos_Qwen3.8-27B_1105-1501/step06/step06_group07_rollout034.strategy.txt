<strategy>

1. Approach and rationale

1.1 Central idea

Use a constraint-free, smooth surrogate formulated in a transformed coordinate system, then certify and tighten every candidate with the original exact discrete objective.

The transformed coordinate system makes the simple-sum and box constraints automatic: if `u ∈ R^n` is the search variable, the actual feasible vector is

`h(u) = sigmoid(u + lambda(u))`

where `lambda(u)` is selected so that every component lies in `(0,1)` and

`sum_i h_i(u) = n/2`.

The smoothning surrogate is a logarithmic-sum-exp approximation to the exact maximum over all full linear-correlation lags:

`Phi_eps(u) = eps * log( sum_r exp( v_r(u) / eps ) )`

where `v_r(u)` is the exact evaluated correlation model value at lag `r`, but without replacing the evaluator. The full transformed objective is therefore just one smooth scalar; `lambda(u)` and the sigmoid chain rules are built into the gradient. During optimization many `u` values are checked by the genuine evaluator

`C5(h) = dx * max_r np.correlate(h, 1-h, mode='full')`.

Only candidates that satisfy box and sum constraints and whose exact evaluator value improves on the retained parent are accepted. This is a materially different optimizer from active-only min-max descent, epigraph SLQP methods, or exact-active full-pair local search. It uses curvature-aware quasi-Newton progress on a smooth problem over a manifold-equivalent parameterization of the entire feasible box, with exact original-metric acceptance.

1.2 Why it may improve the supplied parent

The parent is close to a high-dimensional local performance level, around 0.380891. At that distance, to get a meaningful step to 0.3808 the optimizer must exploit coordinated curvature across the entire feasible hypercube, not merely move along the current active maximum. A log-sum-exp smoothing of all lags, combined with L-BFGS, can acknowledge many correlated active constraints in one full gradient step and can move across multiple inactive lags that cooperative descent misses. The logistic transform preserves the exact sum constraint in the model used for the gradient. Thus the optimization no longer loses the constraint by ordinary clipping or subsequent projected repair after each inner step.

The inner smooth max still can illuminate nearly tied constraints; as epsilon decreases, it approaches the original objective. Multi-resolution resampling and random but parent-anchored perturbations increase the chance of changing the active-lag constellation.

1.3 Honest limitations

- The original problem is nonconvex because it contains products of nonnegative `h` values with those values shifted only within partial linear overlaps. A quasi-Newton or smooth max method has no global optimality claim.
- The transformed variables do not represent exact 0 or 1 limits; they represent extremely close values, according to `u` cutoffs. A final repair is necessary for returned output. Ideally, a returned solution can be interior differentiable; slack is acceptable because the evaluator only needs `[0,1]`.
- `eps` smoothing can mislead for a few internal seconds because it is always ≥ exact max and mutation space saturation can deteriorate to a subsurface subproblem. For this reason exact evaluation and strengthened smoothing/acceptance after every subphase are mandatory.
- The low dimension solution is coarser, not necessarily physically smaller or equal. The decision rule is the displayed exact discrete objective value; if about equal, shorter representation is ordered, because the task calls out sample shorter preference.
- A material final improvement is likely, but not guaranteed for every seed.

2. Mathematical specification

2.1 Exact objective and exact evaluation

Take all representations `h` as one-dimensional float arrays for `i = 0,...,n-1`. Set

`dx = 2.0 / n`

The exact task objective is always

`C5(h) = dx * max_r XR(h)_r`

where

`XR(h) = np.correlate(h, 1.0 - h, mode='full')`.
