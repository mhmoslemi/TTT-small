Actually, I realize I should think more carefully about what makes this problem hard and what specific techniques would help.

The objective is F(h) = max_k c_k(h) where c_k(h) = dx * sum_i h[i]*(1-h[i-k]).

At the optimum, multiple c_k's are likely equal (or close to equal). The optimizer needs to:
1. Identify which lags are "binding" (have c_k close to the max)
2. Find directions that reduce the binding lags while not increasing non-binding ones too much
3. Navigate the "valley" where the max is flat

The key challenge is that the objective is non-smooth (it's a max of smooth functions). The subgradient is not unique at points where multiple functions are simultaneously maximal.

A good strategy is:
- Use a soft approximation: F_τ(h) = τ * log(sum_k exp(c_k/τ)) (log-sum-exp)
- This is smooth and its gradient is a weighted average of the individual gradients
- As τ → 0, it converges to the true max

This is essentially what the softmax weighting does in the previous program. Let me use this more explicitly.

For the gradient of F_τ:
∇F_τ(h) = (1/τ) * sum_k exp(c_k/τ) * ∇c_k(h) / sum_k exp(c_k/τ)
= sum_k w_k * ∇c_k(h) where w_k = exp(c_k/τ) / sum_j exp(c_j/τ)

This is exactly the softmax-weighted gradient. Good.

Now, for the line search, I need to minimize F_τ along a direction. If I use the true max (not the soft approximation), the line search is:
min_t max_k (c_k + t*T_k - t²*Q_k)

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo = float(v.min()) - 2.0
    hi = float(v.max()) + 2.0
    for _ in range(80):
        mid = 0.5 * (lo + hi)
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = 0.5 * (lo + hi)
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    for _ in range(8):
        if abs(res) <= 1e-13:
            break
        if res > 0:
            mask = x < 1.0 - 1e-12
        else:
            mask = x > 1e-12
        cnt = int(np.sum(mask))
        if cnt == 0:
            break
        x[mask] += res / cnt
        x = np.clip(x, 0.0, 1.0)
        res = target - float(np.sum(x))
    return x

def _lag_grad(h, k, n):
    g = np.zeros(n)
    if k >= 0:
        idx = np.arange(k, n)
        g[idx] += (1.0 - h[idx - k])
        g[idx - k] += -h[idx]
    else:
        idx = np.arange(0, n + k)
        g[idx] += (1.0 - h[idx - k])
        g[idx - k] += -h[idx]
    return g
