Σ h[i+k](1-h[i]) ≈ (n-k) * P(h[i+k]=1, h[i]=0) = (n-k) * 0.5*0.5 = (n-k)/4

So max corr ≈ (n-1)/4 ≈ 62/4 = 15.5, giving C₅ ≈ 15.5 * 2/63 ≈ 0.492.

To get C₅ = 0.38, we need max corr ≈ 0.38 * 63/2 ≈ 12.0.

So we need a sequence where the maximum "anti-correlation" at any lag is about 12, compared to the random expectation of about 15.5. This means we need to reduce the peak by about 23% below random.

This is achievable with structured sequences. The key is to avoid having too many 1s followed by 0s (or vice versa) at any particular lag.
