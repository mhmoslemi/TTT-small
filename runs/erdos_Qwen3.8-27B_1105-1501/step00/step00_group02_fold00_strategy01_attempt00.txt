1. Approach and rationale

1.1 Goal and bottleneck

The task is to produce a feasible discrete step vector h of n samples over [0,2] that minimizes

C(h) = max_r dx * sum_{i in valid overlap(r)} h_i * (1 - h_{shifted_i})

with dx = 2/n, 0 <= h_i <= 1 and sum_i h_i = n/2. The master constraint is an average, not a discrete count, so odd n is allowed because fractional sums such as 23.5 for n=47 are feasible.

The main obstruction to improving the parent value 0.38085 by ordinary "project to feasible and pip random moves" methods is that the objective is a single max over many lags, the feasible set is the intersection of a box and a hyperplane, and naive projection plus scaling can break the active bound constraints or the average. Also, coordinate changes affect several correlation lags at once because a single coordinate appears as the first factor in rightward lags and as the second complemented factor in leftward lags. Therefore an effective improvement should:

- preserve feasibility by a joint mechanism that enforces both box bounds and the average exactly or to very tight numerical tolerance;
- propose moves that preserve the average structurally, not by repair after arbitrary changes;
- choose transfers along exact feasible one-dimensional lines and judge all candidates only by the original evaluator formula;
- use global restarts and a population to avoid the many local flat plateaus produced by the max of correlations;
- optionally test smaller or slightly enlarged grid resolutions, but never accept a different resolution until it is evaluated by the exact discrete formula and feasible on that same resolution.

1.2 Primary algorithm

The primary method is a hybrid deterministic-stochastic minimizer:

- Start from the supplied parent if feasible; otherwise use a compact safely generated fallback vector, preferably after local line improvements.
- Build a limited but diverse candidate set by:
  - direct derivative-guided source/sink coordinate pairs chosen from the largest lag constraints;
  - one- and two-coordinate exact transfer line searches that preserve sum(h) structurally;
  - simulated annealing in continuous feasible moves;
  - a small population of continuous crossover/mutation candidates;
  - optional resampling to different grid sizes c usually around 40 to 300, not thousands, to test resolution-transfer candidates.
- Store and return only vectors h that pass a feasibility and finite-objective check. All accepted improvements must reduce the original metric from the exact evaluator, not from a surrogate.

This approach departs from a uniform random projection/restart plan in a substantive way: it uses exact average-preserving pair-line searches as the core local mover, derivative-weighted active-lag transport proposals for choosing variable pairs, and explicit box-simplex projection with slack-based exact residual repair. The core line search operates directly on the discrete objective, while the global population and annealing only create feasible candidates that are then polished by the same exact line polish.

1.3 Limitations

The problem is nonconvex because objective terms are products h_i*(1-h_j). The proposed algorithm has no global optimality guarantee. The line step on each pair solves the exact one-dimensional problem locally only to a fine sampled and refined interval; the overall method is a computationally feasible heuristic. The returned value is a conservative upper bound only for the exact supplied discrete invalid, static discontinuous finite function representation. If multiple grid resolutions are tried, the best final value must be chosen after exact objective evaluation on its own returned n, because changing n changes both dx and boundary overlap counts.

2. Mathematical specification

2.1 Exact discrete objective

For an input h length n define

dx = 2.0 / n.

For each full correlation index r with 0 <= r <= 2n-2, define signed shift

d = r - (n-1).

Let the overlap set for shift d be

I(d) = { i : 0 <= i < n and 0 <= i+d < n }.

Then the overlap sum for index r is

F_r(h) = dx * sum_{i in I(d)} h_i * (1 - h_{i+d}).

The objective

C(h) = max_r F_r(h).

This matches

max(np.correlate(h, 1.0 - h, mode="full") * dx)

for the orientation np.correlate(a,b,'full')[r] = sum_i a_i * b_{i + r - (n - 1)}. If this sign convention is inverted in an implementation, the formula can be reversed to F_r = dx * sum h_{i+d}(1-h_i). Do not maybe use orange? confirm via direct original expression. The max occurs over both lag directions. Do not replace this by a simplified autocorrelation formula that drops boundaries or uses only positive shifts.

Feasibility:

0 <= h_i <= 1 for all i,
sum_i h_i = n/2 as a float equality up to a prescribed tight numerical tolerance.

The integral constraint is exactly

sum_i h_i * dx = (n/2)*(2/n) = 1.

2.2 Joint feasible representation and exact repair

Let target T = n/2. Approximate project raw feasible values from a vector z into the set

B_T = { y : 0 <= y_i <= 1, sum y_i = T }.

Define the monotone scalar function

g(t) = sum_i clip(z_i - t, 0, 1).

g(t) is nonincreasing in t. If g(min(z)-1) >= T >= g(max(z)), the projection solve

g(t) = T

by bisection on a bracket such as [min(z)-1-s, max(z)+s], where s is enough to account for target, and compute

y_i(t) = clip(z_i - t, 0, 1).

Because floating-point bisection may leave a tiny residual e = T - sum(y_i), fix it using the slack directions:

- If e > 0, choose variables y_i whose y_i + delta <= 1 relies to weight and still total residual so that no variable is below. Set them as min(delta,e).
- If e < 0, choose variables y_i whose y_i + delta_i and add -e into slots making total. Check slack to positive.
