The gradient of c_k (the correlation sum at shift k) w.r.t. h is:
  ∂c_k/∂h[j] = sum over terms where h[j] appears

c_k = sum_{i: 0≤i<n, 0≤i+k<n} h[i] * (1-h[i+k])

So h[j] appears in:
- The first factor when i = j (if j+k < n): contributes (1-h[j+k])
- The second factor when i+k = j, i.e., i = j-k (if j-k ≥ 0): contributes -h[j-k]

So: ∂c_k/∂h[j] = (1-h[j+k]) * [j+k < n] - h[j-k] * [j-k ≥ 0]

Where [condition] is 1 if condition is true, 0 otherwise.

The gradient of the objective J(h) = dx * max_k c_k is:
  ∇J(h) = dx * ∇c_{k*}(h) where k* is an argmax

But J is nonsmooth when multiple c_k are equal to the max. In that case, any convex combination of the gradients of the active terms is a subgradient.

For descent, we want to move in the direction -∇c_{k*} projected to the feasible set. The projection to the feasible set (sum constraint + box) is:

  d = (-∇c_{k*}) - mean(-∇c_{k*}) = -∇c_{k*} + mean(∇c_{k*})

Then we do a line search along d to find the best λ.
