For shift d (signed), the correlation at that shift is:
F_d = dx * sum_{i: 0<=i<n, 0<=i+d<n} h_i * (1 - h_{i+d})

∂F_d/∂h_m = dx * sum over all pairs (i, i+d) where m is one of the two:
- If m = i (first factor): dx * (1 - h_{i+d}) = dx * (1 - h_{m+d}) for valid i+d
- If m = i+d (second factor): -dx * h_i = -dx * h_{m-d} for valid i-d

So the gradient at coordinate m is:
G_m = sum_d dx * [(1 - h_{m+d}) * 1_{valid(m+d)} - h_{m-d} * 1_{valid(m-d)}]

where the sum is over all d where the pair is valid.

For a transfer y_p = x_p - t, y_q = x_q + t:
The change in F_d is approximately (G_p - G_q) * t for small t
But for exact: F_d(t) is quadratic in t for each d, because:
F_d(t) = dx * sum_{(i,j) in pairs_d} y_i * (1-y_j)

For a pair (i,j) where i=p, j=q: (x_p - t)(1 - x_q - t) = x_p(1-x_q) - (1-x_q)t - x_p*t + t²
= x_p(1-x_q) - [(1-x_q) + x_p]t + t²

For a pair where i=p, j≠q: (x_p-t)(1-x_j) = x_p(1-x_j) - (1-x_j)t
For a pair where i≠p, j=q: x_i(1-x_q-t) = x_i(1-x_q) - x_i*t
