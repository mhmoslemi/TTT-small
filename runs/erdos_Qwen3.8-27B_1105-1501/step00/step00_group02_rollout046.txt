G[t, j] = (1-h[j-t])*[0≤j-t<n] - h[j+t]*[0≤j+t<n]

So for a pair (j, j'), computing D[t] for all t takes O(n) time.

Let me write the full algorithm:

```python
def gradient_matrix(h):
    """Compute G[t, j] = d(correlation[t])/d(h[j]) for all t, j"""
    n = len(h)
    G = np.zeros((2*n-1, n))
    for k in range(2*n-1):
        t = k - (n-1)
        for j in range(n):
            val = 0.0
            if 0 <= j - t < n:
                val += (1.0 - h[j-t])
            if 0 <= j + t < n:
                val -= h[j+t]
            G[k, j] = val
    return G
```

This is O(n * 2n) = O(n^2) which is fine.

def local_search(h_init, dx, max_sweeps=50, seed=42):

        # Try pairs in random order

        for j, k in pairs:
            # D[t] = G[t,j] - G[t,k]
            D = G[:, j] - G[:, k]
            # f(δ) = max(corr + δ * D)
            # Feasible: δ ∈ [max(-h[j], h[k]-1), min(1-h[j], h[k])]
            lo = max(-h[j], h[k] - 1.0)
            hi = min(1.0 - h[j], h[k])
            if lo >= hi - 1e-10:
                continue

            # f is convex (max of linear functions)
            # Try golden section search
            a, b = lo, hi
            gr = (np.sqrt(5) - 1) / 2
            for _ in range(30):
                m1 = b - gr * (b - a)
                m2 = a + gr * (b - a)
                f1 = np.max(corr + m1 * D)
                f2 = np.max(corr + m2 * D)
                if f1 < f2:
                    b = m2
                else:
                    a = m1
                if b - a < 1e-10:
                    break
            delta = (a + b) / 2
            
            # Check if it improves
            new_corr_max = np.max(corr + delta * D)
            if new_corr_max * dx < best_c5 - 1e-10:
                h[j] += delta
                h[k] -= delta
                # Update correlation
                corr = corr + delta * D
                G[:, j] = gradient_matrix(h)[:, j]  # Need to recompute? No, G is linear in h...

                # After changing h[j] by delta:
                # G_new[t, j] = G[t, j] + delta * (delta(j-t, j)*... ) 
                # This is getting complicated. Let me just recompute G periodically.

            best_c5 = c5_check
            best_h = h.copy()

Wait, I realize there's an issue. When I change h[j] by delta, the gradient G changes too (since G depends on h). So I can't just update corr = corr + delta * D. The new gradient for the next pair will be different.

But for the purpose of the local search, this is OK - I'm doing a "greedy" approach where I make one move at a time and recompute the gradients. The golden section search gives me the optimal δ for the current state, and then I update.

The issue is that after updating h, the gradient G for the current pair (j,k) changes, but I've already used it. For the next pair, I'll use the old G which is slightly off. This is like Gauss-Seidel vs Jacobi - it should still converge, just maybe slower.

Actually, for correctness, I should recompute G after each move. But that's O(n^2) per move, and there are O(n^2) moves per sweep, so O(n^4) per sweep. For n=47, that's about 5 million per sweep. With 50 sweeps, that's 250 million operations. At ~100M ops/sec (conservative for numpy), that's about 2.5 seconds per 50 sweeps. Very manageable.

But actually, I don't need to recompute ALL of G. I only need to update the columns that are affected. When h[j] changes, only G[:, j-t] and G[:, j+t] are affected (for various t). Hmm, actually G[k, j'] depends on h[j'-t] and h[j'+t] for shift t = k-(n-1). So if h[j] changes, then G[k, j'] changes for all j' where j'-t = j or j'+t = j for some t. That's all j' (since t ranges over all values). So I need to recompute all of G.

Alternatively, I can just not precompute G and compute it on the fly for each pair. For a given pair (j, k), I need D[t] = G[t,j] - G[t,k] for all t. Computing G[t, j] for all t is O(n) (since for each t, it's O(1)). Same for G[t,k]. So O(n) per pair.

Total per sweep: O(n^3). For n=47: about 100K per sweep. With 100 sweeps: 10M. Very fast.

Let me rewrite:

```python
def compute_D(h, j, k):
    """Compute D[t] = G[t,j] - G[t,k] for all t"""
    n = len(h)
    D = np.zeros(2*n - 1)
    for idx in range(2*n - 1):
        t = idx - (n - 1)
        # G[t, j]
        gj = 0.0
        if 0 <= j - t < n:
            gj += (1.0 - h[j - t])
        if 0 <= j + t < n:
            gj -= h[j + t]
        # G[t, k]
        gk = 0.0
        if 0 <= k - t < n:
            gk += (1.0 - h[k - t])
        if 0 <= k + t < n:
            gk -= h[k + t]
        D[idx] = gj - gk
    return D
```

This is O(n) per pair. Good.

import numpy as np
import time

def compute_c5(h, dx):
    return np.max(np.correlate(h, 1.0 - h, mode="full") * dx)

def project_to_constraint(v, target_sum):
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.clip(v - mid, 0, 1).sum()
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(v - (lo + hi) / 2.0, 0, 1)

def get_subgradient(h, dx, tol=1e-3):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full") * dx
    max_val = corr.max()
    active = np.where(corr >= max_val - tol)[0]
    if len(active) == 0:
        return np.zeros(n), max_val
    grad = np.zeros(n)
    for idx in active:
        t = idx - (n - 1)
        if t >= 0:
            grad[t:] += (1.0 - h[:n-t])
            grad[:n-t] -= h[t:]
        else:
            grad[:n+t] += (1.0 - h[-t:])
            grad[-t:] -= h[:n+t]
    grad *= dx / len(active)
    return grad, max_val

def subgradient_descent(h_init, dx, time_limit=60, init_lr=0.05):
    h = h_init.astype(float).copy()
    n = len(h)
    target = n / 2.0
    best_c5 = compute_c5(h, dx)
    best_h = h.copy()
    lr = init_lr
    start = time.time()
    
    while time.time() - start < time_limit:
        grad, curr = get_subgradient(h, dx)
        if curr < best_c5:
            best_c5 = curr
            best_h = h.copy()
        
        step = project_to_constraint(h - lr * grad, target)
        new_c5 = compute_c5(step, dx)
        if new_c5 < curr:
            h = step
            lr = min(lr * 1.05, 0.3)
        else:
            step2 = project_to_constraint(h - lr * 0.5 * grad, target)
            if compute_c5(step2, dx) < curr:
                h = step2
            else:
                lr *= 0.5
            if lr < 1e-9:
                break
    
    return best_h, best_c5
