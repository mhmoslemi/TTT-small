                # corr[k] = sum_{m=0}^{n-1-j} h[m]*(1-h[m+j])
                # For index i:
                #   h[i] in first factor (h[m]) when m = i, valid if 0 <= i <= n-1-j
                #     coeff: (1 - h[i+j])
                #   h[i] in second factor (1-h[m+j]) when m+j = i, i.e., m = i-j, valid if j <= i <= n-1
                #     coeff: -h[i-j]
                idx1 = np.arange(0, n - j)
                S[k, idx1] += (1.0 - h[idx1 + j])
                idx2 = np.arange(j, n)
                S[k, idx2] += (-h[idx2 - j])
        return S
    
    S = compute_S(h)
    corr = np.correlate(h, 1.0 - h, mode="full").astype(np.float64)
    best_val = float(np.max(corr))
    
    while (time.time() - t0) < time_limit:
        any_improve = False
        for u in range(n):
            for v in range(n):
                if u == v:
                    continue
                d = S[:, u] - S[:, v]
                if np.allclose(d, 0):
                    continue
                
                # Find optimal alpha
                alpha_lo = max(-h[u], h[v] - 1.0)
                alpha_hi = min(1.0 - h[u], h[v])
                
                # Bisection
                lo, hi = alpha_lo, alpha_hi
                for _ in range(40):
                    mid = (lo + hi) / 2.0
                    vals = corr + mid * d
                    k_star = np.argmax(vals)
                    slope = d[k_star]
                    if slope < -1e-15:
                        lo = mid
                    elif slope > 1e-15:
                        hi = mid
                    else:
                        break
                alpha_star = (lo + hi) / 2.0
                
                # Check if improvement
                new_vals = corr + alpha_star * d
                new_max = float(np.max(new_vals))
                
                if new_max < best_val - 1e-12:
                    # Accept
                    h[u] += alpha_star
                    h[v] -= alpha_star
                    # Clamp to [0,1] for numerical safety
                    h[u] = np.clip(h[u], 0.0, 1.0)
                    h[v] = np.clip(h[v], 0.0, 1.0)
                    corr = corr + alpha_star * d
                    best_val = new_max
                    S = compute_S(h)  # Recompute sensitivities
                    any_improve = True
        if not any_improve:
            break
    
    return h, best_val * dx

Wait, there's a problem. When I update h[u] and h[v], the correlation changes by exactly alpha_star * d (as we showed). But the sensitivity matrix S changes because it depends on h. So I need to recompute S after each accepted move. That's O(n^2) = 4900 per accepted move. If I have many accepted moves, this adds up.

But actually, I can update S more efficiently. When h[u] changes by α and h[v] changes by -α:
- S[k, u] changes: the sensitivity of lag k to index u depends on h values at specific positions. Specifically, S[k, u] = f(h) where f involves h[u±shift] and h[u±j]. When h[u] changes, S[k, u] changes, AND S[k, w] changes for any w that has u in its "neighborhood" (i.e., w = u ± shift for some shift).

This is getting complicated. Let me just recompute S from scratch after each accepted move. For n=70, it's O(70^2) = 4900 operations, which is fast.

Each sweep might have 10-100 accepted moves, so I'm doing 600-20000 S recomputations, each O(4900) = 3M-100M total. That's fine.

Actually, let me reconsider. The bisection is 40 iterations, each doing:
- vals = corr + mid * d → O(139) numpy operation (fast, ~1μs)
- k_star = np.argmax(vals) → O(139) (~0.5μs)
- slope = d[k_star] → O(1)

So each bisection iteration is ~2-3μs. 40 iterations = ~100μs per pair. 4830 pairs = ~483ms per sweep. That's very reasonable.
