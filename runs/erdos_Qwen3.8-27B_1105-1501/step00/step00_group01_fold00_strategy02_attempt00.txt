1. Approach and rationale
1.1 Central idea
The supplied continuous objective is a finite-dimensional nonconvex minimax problem. Each component of the objective is a sum of bilinear terms h_i(1-h_{i+k}). A direct convex solver for the exact objective is not available because the bilinear terms destroy convexity, and pixel-by-pixel coordinate perturbation is too weak for the small gap from the supplied construction toward 0.3808.

The proposed method is a trust-region sequential linear programming method, followed by a smooth active-set polish. The exact candidate is always scored by the specified evaluator:
    C5(h) = max(np.correlate(h, 1-h, mode="full")) * (2/n).
Every proposal is accepted only if it is feasible and has a strictly better exact score. The search itself uses a linearized model of all lag constraints and solves a linear program in the variables h and one epigraph coordinate lambda. After each implementation solving step, the true score is recomputed from the final feasible vector. This preserves correctness: the optimizer is only a proof-free move generator; the archive and returned bound are determined by exact evaluation. This is materially different from previous approaches because the central update is a finite linear program over all lag directions, not random coordinate directions, pairwise line searches, or an isolated nonlinear \(LSQP\)+ restore program. It also naturally produces extreme feasible points, which are appropriate here because the feasible polytope has a cardinality hyperplane and product minimization favors boundary values.

1.2 Why this should move the optimum
At a feasible point h0, each lag component F_k(h) has computable directional derivatives. The subproblem
    minimize lambda subject to F_k(h0) + grad F_k(h0).(h-h0) <= lambda for every k,
    + equality sum(h)=n/2,
    + 0 <= h_i <= 1,
    + optional trust-region width,
is an exact linear program. Its optimum is a vertex of the local feasible box and often has many coordinates at 0 or 1, with at most one fractional coordinate after the equality sum is enforced. This gives global coordinated shifts inside a trust region, avoids local one-knot restrictions, and can move across neighboring vertices. The approximate linearization error is bilinear and is dealt with by exact evaluation and acceptance/rejection. Suspension controls prevent isolated directions from causing repeated bad assignments.

1.3 Portfolio of programs
Important qualifications and limitations:
- The formulation is only locally model-valid. Its linear epigraph problem is not a global relaxation for the nonconvex objective. No convexity or global optimum claim is made.
- Random acceptance of mildly worse moves is used only for exploration. The returned promise is only the exact best score among all accepted families at final return.
- Final equality and box constraints are imposed explicitly by feasibility restoration, plus a dyadic quantization routine. This avoids the usual invalid clip/search/rescale orbit.
- The parent construction is dynamically obtained from the supplied runtime global. There are no large temporary numeric parent mappings stored in the program.
