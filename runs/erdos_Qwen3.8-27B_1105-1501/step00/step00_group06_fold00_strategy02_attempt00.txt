## 1. Approach and rationale

### 1.1 Central idea

Work directly with the exact discrete objective, using an equivalent minimax reformulation:

- Inputs are a feasible array `h` of length `n`, with `dx = 2.0/n`, and mass constraint `sum(h) = n/2`.
- Define the raw, unscaled correlation vector
  `Q(h) = np.correlate(h, 1.0 - h, mode="full")`.
- The evaluator returns
  `C(h) = dx * max(Q(h))`.
- Because `dx` is a positive constant for a fixed length `n`, minimizing `C(h)` is exactly the same as minimizing the scalar raw value
  `R(h) = max_m Q_m(h)`.

The central optimization quantities are therefore the raw scalar upper-bound variables, always tested against the original evaluator. We construct feasible candidates with few artificial relaxations:

1. An explicit finite minimax formulation
   minimize `u` subject to
   `Q_m(h) - u <= 0` for a selected set of overlap constraints,
   `sum(h) = n/2`,
   `0 <= h_i <= 1`,
   possibly using a symmetric subrepresentation. This formulation uses exact `correlate`-consistent constraint values and exact analytic gradients of those constraints, and is solved locally by SciPy's `SLSQP`.

2. Active-sensitivity feasible transfer loops: from candidates that do not break the stored exact best, move mass along pair-transfer zero-sum directions found from the actual overlap-count gradients of currently most-dangerous constraints.

3. Exact acceptance of all proposals using `np.correlate` and the supplied formula. A surrogate never replaces final acceptance.

This is materially different from previously proposed generic line-search/random-direction ideas in that it uses the constraint itself as a genuine scalar variable and kernels and explores feasible movements caused by actual active-constraint sensitivities.
