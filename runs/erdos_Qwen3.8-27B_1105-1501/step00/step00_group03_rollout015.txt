Let me analyze this problem carefully:

1. We need to minimize C₅ = max_k ∫ h(x)(1-h(x+k)) dx over all step functions h: [0,2] → [0,1] with ∫₀² h(x) dx = 1.

2. In discrete form with n points and dx = 2/n:
   - 0 ≤ h[i] ≤ 1
   - sum(h) = n/2
   - C₅ = max(np.correlate(h, 1-h, mode="full")) * dx

3. Current record: C₅ ≤ 0.38085, target: 0.3808

The key insight is that for k=0, we have ∫ h(x)(1-h(x)) dx = ∫ h(x) dx - ∫ h(x)² dx = 1 - ∫ h(x)² dx. To minimize this, we want ∫ h(x)² dx to be as large as possible, meaning h should be as close to 0 or 1 as possible (binary-like).

But we also need to minimize the correlation at other lags. The correlation at lag k is:
∫ h(x)(1-h(x+k)) dx

This is tricky because making h binary helps k=0 but might hurt other lags.

1. Start from initial_h_values (n=45) if available
2. Generate diverse candidates
3. Use local optimization (gradient-based line search + SLSQP)
4. Return the best feasible solution

Let me think about the gradient of the objective. The objective is:
C₅(h) = max_k F_k(h) * dx

where F_k(h) = sum_i h[i] * (1 - h[i+k]) for valid i.

The gradient of F_k with respect to h[p] is:
- For each valid i where i = p: contributes (1 - h[i+k]) = (1 - h[p+k])
- For each valid i where i+k = p: contributes -h[i] = -h[p-k]

So dF_k/dh[p] = (1 - h[p+k]) - h[p-k] (where the terms are only included when the indices are valid).

For k=0: dF_0/dh[p] = (1-h[p]) + (-h[p]) = 1 - 2*h[p]

The overall gradient is dominated by the active (maximum) constraints.

For the SLSQP approach, I'll formulate:
- Minimize theta
- Subject to theta >= F_k(h) * dx for all k
- Subject to 0 <= h[i] <= 1
- Subject to sum(h) = n/2

def official_score(h):
    """Compute the exact C5 score for a feasible h."""
    n = len(h)
    if n == 0:
        return float('inf')
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(z, target_sum):
    """Project z onto {x: 0<=x_i<=1, sum(x)=target_sum}."""
    n = len(z)
    z = np.asarray(z, dtype=float)
    # Clip to [0,1]
    h = np.clip(z, 0.0, 1.0)
    # Adjust sum
    current_sum = np.sum(h)
    diff = target_sum - current_sum
    if abs(diff) < 1e-15:
        return h
    # Distribute adjustment
    if diff > 0:
        # Need to add mass: prefer entries with most room
        room = 1.0 - h
        room_order = np.argsort(-room)
        remaining = diff
        for idx in room_order:
            add = min(remaining, room[idx])
            if add > 0:
                h[idx] += add
                remaining -= add
            if remaining < 1e-15:
                break
    else:
        # Need to remove mass
        diff_abs = -diff
        floor_order = np.argsort(h)
        remaining = diff_abs
        for idx in floor_order:
            rem = min(remaining, h[idx])
            if rem > 0:
                h[idx] -= rem
                remaining -= rem
            if remaining < 1e-15:
                break
    return h

def compute_correlations(h):
    """Compute all correlation values F_k(h) (unscaled)."""
    n = len(h)
    kh = 1.0 - h
    return np.correlate(h, kh, mode="full")

def compute_active_gradients(h, active_indices, n):
    """Compute sum of gradients for active correlation rows."""
    n = len(h)
    grad = np.zeros(n)
    for k in active_indices:
        # F_k = sum_{i} h[i] * (1 - h[i+k]) where indices are valid
        # dF_k/dh[p] = (1 - h[p+k]) if p+k valid, minus h[p-k] if p-k valid
        for p in range(n):

            j = p + k
            if 0 <= j < n:
                g += (1.0 - h[j])
            j = p - k
            if 0 <= j < n:
                g -= h[j]
            grad[p] += g
    return grad

def slsqp_polish(h, max_iter=50):
    """Polish using SLSQP with the exact minimax formulation."""
    n = len(h)
    dx = 2.0 / n
    h = project_feasible(h.copy(), n / 2.0)
    
    # Initial theta
    corr = compute_correlations(h)
    theta_init = np.max(corr * dx) + 1e-4
    
    # Variables: [h_0, ..., h_{n-1}, theta]
    x0 = np.concatenate([h, [theta_init]])
    
    def objective(x):
        return x[-1]  # theta
    
    def objective_grad(x):
        g = np.zeros(n + 1)
        g[-1] = 1.0
        return g
    
    def constraints_func(x):
        h_var = x[:n]
        theta = x[-1]
        corr = np.correlate(h_var, 1.0 - h_var, mode="full")
        # Constraint: theta - corr[k]*dx >= 0 for all k
        return theta - corr * dx
    
    def constraints_jac(x):
        h_var = x[:n]
        n_c = 2 * n - 1
        J = np.zeros((n_c, n + 1))
        for k in range(n_c):
            lag = k - (n - 1)
            J[k, -1] = 1.0
            # Gradient of -(corr[k]*dx) w.r.t. h
            # corr[k] = sum_i h[i]*(1-h[i+lag]) for valid i
            for p in range(n):
                g = 0.0
                j = p + lag
                if 0 <= j < n:
                    g += (1.0 - h_var[j])
                j = p - lag
                if 0 <= j < n:
                    g -= h_var[j]
                J[k, p] = -dx * g
        return J
    
    bounds = [(0, 1)] * n + [(0, 2.0)]
    
    # Equality constraint: sum(h) = n/2
    def eq_constraint(x):
        return np.sum(x[:n]) - n / 2.0
    
    def eq_jac(x):
        J = np.zeros(n + 1)
        J[:n] = 1.0
        return J
    
    from scipy.optimize import NonlinearConstraint
    
    try:
        ineq = NonlinearConstraint(constraints_func, 0, np.inf, jac=constraints_jac)
        eq = NonlinearConstraint(eq_constraint, n / 2.0, n / 2.0, jac=eq_jac)
        
        result = minimize(objective, x0, method='SLSQP', jac=objective_grad,
                         bounds=bounds, constraints=[ineq, eq],
                         options={'maxiter': max_iter, 'ftol': 1e-10})
        
        if result.success or (result.x is not None and np.all(np.isfinite(result.x))):
            h_result = project_feasible(result.x[:n], n / 2.0)
            return h_result
    except Exception:
        pass
    
    return None
