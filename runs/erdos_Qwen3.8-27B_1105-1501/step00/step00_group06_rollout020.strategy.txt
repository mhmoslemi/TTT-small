1. Approach and rationale

1.1 Central idea

Treat the discrete problem as a nonsmooth finite-dimensional minimax problem over the feasible polytope

    P_n = { h ∈ R^n : 0 ≤ h_i ≤ 1, sum_i h_i = n/2 }.

The returned objective must be the exact evaluator

    J(h) = (2/n) * max_{ℓ ∈ Z_{2n-1}} correlate(h, 1-h)[ℓ],

not a smoothed surrogate, not an exact-periodic approximation, and not a relaxation-only value.

Because J is a maximum of smooth quadratic pieces, each active correlation constraint is locally quadratic along feasible directions. The proposed algorithm repeatedly moves through feasible affine lines

    h_λ = h + λ d,   sum(d)=0,

which automatically preserve the mass and box constraints on the exact λ interval. On each such line, the exact one-dimensional objective

    φ_d(λ) = J(h + λ d)

is minimized or sufficiently reduced only with exact feasible candidates. Directions are generated from:

1. active worst-overlap gradients,
2. pairwise transfer directions selected from coordinate subgradients,
3. low-dimensional zero-sum harmonic modes,
4. stochastic zero-sum directions,
5. locally thinned pair-perturbation “clusters”,
6. explicit boundary-pair and edge-tilt directions.

A monotone descent phase is used first so that the supplied current construction is not damaged. After that, a temperature-controlled feasible-line walker is allowed to accept slightly worse working solutions as long as every candidate is scored by the original evaluator and the best feasible objective seen so far is stored separately.

The significant difference from prior generic surrogate-and-projection plans is that the core primitive is the exact line search along a strictly feasible affine direction inside P_n. Feasibility is obtained from construction, not from clip-then-rescale or projection at the inner loop. The plane of action is the simplex-box polytope, and no maximum is replaced by a false log-sum or p-norm solver endpoint except possibly to choose tired directions after exact evaluation.

1.2 Why this can improve the parent

A high-resolution parent at n≈70 should already be near a nonsmooth local minimum. Improvements require actions that can move the vector across the simultaneous kinks where several overlap maxima equal the current value. Probabilistically selecting high-quality directions and scanning the exact one-dimensional penalty along them is natural because on a single direction J_λ is maximum of quadratics, whose local minima are often lower than the current value. If no line move in the chosen families gives an improvement, using the current worst-active gradient as a guide can find a common descent. Classic random pair-perturbation alone gets stuck because it adapts poorly to wild symmetry and boundary terms; the active-set gradient directions help limit naive subspace. Combining them gives stronger navigation.

The method pays off because the target improvement from 0.38085 to about 0.3808 is tiny but in the same neighborhood: such improvements usually require extremely careful feasible crossings of active constraints, not global random rebuilds.

1.3 Consistency with authoritative evaluator

The evaluator includes both shift signs and full-support finite correlation, i.e. finite interval, not circular correlation. For shift s = -(n-1),...,n-1, the corresponding correlation coefficient is

    c_s(h) = sum_i h_i (1 - h_{i-s})
              with terms defined only when both indices 0≤i<n and 0≤i-s<n.

The objective is (2/n) max_s c_s(h). The supplied evaluator uses indexes 0..2n−2 for s = -n+1,...,n-1 according to either shift order. Directional gradients need only to be consistent with one convention; He definitely uses fallback order only if verified but the algorithm availability uses exact objective for acceptance, so a small convention mistake delays rather than derails it.

1.4 Limitations

* No convex optimization wrapper can certify global optimality; the bilinear terms break convexity.
* Directional line searches are local or randomized; genuinely small objective values are a consequence of sufficient trials rather than an unclaimed guarantee.
* Evaluation of the nonconvex objective can be direction-dependent after nonmonotone accepted steps; a working solution may deteriorate while maximum seen remains improved.
* Under parent or suggested dimensions not supported, algorithm should still return baselines, perhaps one of round format, according to equivalents but compare against fallback best.
* A target of ≤ 0.3808 requires improving approximate root by ~2.5e−4, so it can genuinely fail within time, but actual known valid best has lower fallback.
