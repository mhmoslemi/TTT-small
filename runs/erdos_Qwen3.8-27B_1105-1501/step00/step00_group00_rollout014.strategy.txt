1. Approach and rationale

The task is to find a feasible discrete step-function vector h of effective sample count n for which the evaluator score

C5(h) = max_k dx * np.correlate(h, 1-h, 'full')[k], dx = 2/n,

is smaller than the supplied parent construction. The neighborhood of the current record is small, so the main bottleneck is not low-quantity time; it is that direct unconstrained descents often violate the joint equality and box constraints, and that the active set of moving overlap constraints changes suddenly. Therefore the plan builds every candidate directly in the feasible set by a proper projection to the 0/1 box plus half-mass equality constraint, uses exact local gradient information for the active lap overlap constraints, smooths the max only for coarse exploration, and then polishes the actual non-smooth meta-problem by small epigraph formulations. The returned objective is always rechecked with the exact lattice objective used by the evaluator. This is materially different from generic “save improved keys” suggestions: feasibility is enforced by one projection mechanism, the exact active constraints are generated without circularity, resolutions can be transferred preserving area, and all solvers are used only as local nonconvex minimizers with exact-value acceptance.

Main facts:

- The problem is nonconvex. No globally optimal result is claimed.
- The objective is finite-support cross-correlation with the complement. Both lag directions are distinct and included in the array of 2n-1 outputs. No circular correlation or minus-correlation relaxation replaces it.
- Constraints 0 <= h_i <= 1 and sum(h)=n/2 must be enforced together; clipping an array then separately resetting its mass may violate one constraint. Feasibility repair must be joint.
- Direct CVXPY is not used to formulate the original problem because the epigraph includes terms h_i(1-h_j), which are bilinear and neither convex nor concave. A solver named later is used only as a local NLP/LP-method helper with exact objective acceptance and no optimality claim.

Central method:

1. Obtain and preserve a valid parent if `initial_h_values` is present. Otherwise build a deterministic feasible 45-vector or a determined shape. This parent remains the fallback.
2. At the parent’s current sample count, create a diverse set of feasible starts from the parent, complement/reverse transforms, low-discrepancy binary patterns, sinusoidal patterns, and lightly perturbed versions of the parent.
3. Run a stage of smoothed maximum minimization on `h` only, using the exact finite-lag values and a selected temperature sequence. The smoothed objective is accepted only by the exact evaluator, not by its surrogate number.
4. For the best local candidates, run a repeated active-set epigraph polish. For a selected subset of overlap constraints, minimize an auxiliary t subject to `t - C_l(h) >= 0`. After each epigraph solve, regenerate constraints using the exact value vector, repair feasibility, and store the candidate only if its exact standard score is better.
5. Add cheap walk around local optima: local coordinate pair mass moves that keep mass exactly and keep the bounds preserved. These moves can find tiny improvements that a gradient-based solver misses because of clipping and non-smooth active ties.
6. If a better shape is obtained or discovered at another resolution, transfer the function to higher or lower sample counts via area interpolation, project to joint feasibility, compare exact scores, and let lower-resolution versions collapse or preserve that shape if they are competitive and less nte. Resolution transfer is used to improve discretization means and to compact function without uncontowered larger arrays unless dramatically lower.
