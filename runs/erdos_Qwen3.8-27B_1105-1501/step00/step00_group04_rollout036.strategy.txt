1. Approach and rationale

1.1 Central algorithm
The proposed solution is a pair-transfer simulated-annealing montage over the exact discrete minimax objective. At any sampled vector \(h\), the algorithm:

1. Evaluates the original overlap score exactly using the task evaluator convention.
2. Builds an active-gradient proposal mechanism from the currently maximal or near-maximal lag overlaps.
3. Generates a mass-preserving pair move of the form
   \[
   h_u \leftarrow h_u+\alpha,\qquad h_v \leftarrow h_v-\alpha,
   \]
   or the opposite direction, preserving both \(\sum_i h_i=n/2\) and \(0\le h_i\le1\) by interval constraints rather than clipping and rescaling.
4. Accepts the move by a Metropolis rule on the exact continuous objective \(C_5(h)\), not on a smooth surrogate or relaxed objective.
5. Periodically performs deterministic pair-line polishing on active coordinate pairs, with exact local scans, to extract small improvements that ordinary random descent directions can miss.
6. Maintains a historical global best feasible candidate and always returns the best candidate accepted under the exact task objective.

This is materially different from the earlier smooth-max/log-sum-exp plan and from the earlier mixed-integer model plan. The new primary mechanism is an exact-objective stochastic search in the pair-transfer tangent space of the feasible set. It does not require convex subproblems, binary MILP certificates, log-sum-exp smoothing, or a relaxation whose validity must be derived. It searches the original feasible set and original objective, accepting downhill moves unconditionally and uphill moves with cooled probability. It is aimed at escaping a narrow local basin near the supplied parent while preserving any locally known better candidate.

1.2 Why this could improve the parent
The parent is close to the current record and likely sits in a shallow, mostly flat local region. A deterministic smooth-affine gradient may become ineffective when only a few lags are active and many near-tie constraints move as a side effect. The proposed method addresses this by:

- exact acceptance: changes are judged by the same correlate evaluator as the response, so surrogate mismatch cannot cause false progress;
- active-gradient directed pair moves: local transfer directions concentrate mass movement away from coordinates that most increase the largest overlaps;
- annealing acceptance: briefly accepting uphill moves can allow the chain to cross small bumps and reach a different pair-transfer basin near the parent;
- periodic exact pair-line polishing: when \(h_u,h_v\) are changed together, the exact objective restricted to that line is sampled and refined, which helps resolve tiny improvements under the \(5\times10^{-5}\) C₅ gap;
- small population: parent, parent variations, and parent-linked restarts are searched together so that one objective plateau does not lock the optimization.

No global optimality claim is made. The parent might already be locally optimal under all small pair moves. The method is a feasible-coin discovery and local-transition engine and is intended to test whether the present parent can be pushed under \(0.3808\) or at least lowered slightly while retaining a valid bound.

1.3 Factual vs heuristic statements
Facts:

- The feasible set \(\{h\in[0,1]^n:\sum_i h_i=n/2\}\) is convex and pair transfers preserve mass and bounds by exact intervals.
- The exact objective is continuous and piecewise bilinear; the discrete products make the full minimax problem nonconvex.
- Active-lag gradients are genuine directional gradients of the selected linearized overlap functions.

Justified heuristics:

- Pair-transfer moves are geometrically natural because the mass constraint has dimension \(n-1\) and each local tangent can be generated by a pair transfer.
- Active near-maximum constraints dominate the local behavior of \(\max_k C_k\).
- LOW-temperature simulated annealing with exact evaluation can improve local mixing compared with deterministic projected gradient paths.

2.2 Feasible set operation for continuous target odd sizes

\[

At very low \(\lambda\), \(\psi_\lambda\) approaches \(\sum 1=n\); at very large \(\lambda\), \(\psi_\lambda\) approaches 0. For mathematical bracket, start with 
\[

\]
then bisect until root interval length is \(<10^{-11}\) or fixed 58 iterations. The projection is
\[

\]
Because bisection retains floating residual mass \(r=\tau-\sum_i z_i\), apply a continuous greedy min-change fix: 
- If \(r>0\), loop over indices in any fixed deterministic order, selecting indices with remaining slack \(1-z_i\), set \(z_i\leftarrow z_i+\min(r,1-z_i)\), decrease \(r\).
- If \(r<0\), select indices with surplus contribution \(z_i\), set \(z_i\leftarrow z_i+\max(r,-z_i)\).
The clipping plus sequential assignment always yields min and sum conditions jointly. It also never rescales after clipping. Finally clamp residual values to ten-digit bounds \(0,1\) if tiny overshoot.
