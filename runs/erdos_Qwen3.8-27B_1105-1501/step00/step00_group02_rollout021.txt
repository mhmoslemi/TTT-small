    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr)) * dx

def gradient_active_lag(h, k_lag):
    """Compute gradient of R[k] with respect to h, projected to sum=0 subspace"""
    n = len(h)
    # k_lag is the index in the "full" correlation output
    # The actual lag is k_lag - (n-1)
    k = k_lag - (n - 1)
    
    g = np.zeros(n)
    for j in range(n):
        val = 1.0
        # h[j+k] term
        jp = j + k
        if 0 <= jp < n:
            val -= h[jp]
        # h[j-k] term  
        jm = j - k
        if 0 <= jm < n:
            val -= h[jm]
        g[j] = val
    # Project to sum=0
    g -= g.mean()
    return g

def smooth_local_search(h, n, time_limit, rng):
    """Local search using smooth perturbations and coordinate moves"""
    best_h = h.copy()
    best_val = compute_c5(best_h)
    start = time.time()
    
    while time.time() - start < time_limit:
        # Compute current lags
        dx = 2.0 / n
        corr = np.correlate(best_h, 1.0 - best_h, mode="full")
        lags = corr * dx
        max_idx = np.argmax(lags)

        g = gradient_active_lag(best_h, max_idx)

Let me try a different approach: use scipy's minimize with a smooth approximation of the max.

The max function can be approximated by the log-sum-exp:
max(x) ≈ (1/β) * log(sum(exp(β*x)))

for large β. This gives a smooth approximation that we can optimize with gradient methods.

But the constraint sum(h) = n/2 and 0 ≤ h ≤ 1 makes it a constrained optimization. We can use scipy.optimize.minimize with bounds and equality constraint.

Actually, let me think about this more carefully. The objective is:
f(h) = max_k corr[k] * dx

where corr = np.correlate(h, 1-h, mode="full")

This is a piecewise-linear (actually piecewise-quadratic, since each corr[k] is bilinear in h) function.

For a fixed active set S (the set of k that achieve the max), the objective is:
f(h) = max_{k in S} corr[k] * dx

And the subgradient is:
∂f/∂h[i] = (dx / |S|) * sum_{k in S} ∂corr[k]/∂h[i]

The partial derivative ∂corr[k]/∂h[i] depends on the specific formula numpy uses.

Since I'm not 100% sure of the exact formula, let me just use numerical gradients.

For a feasible direction d (sum(d) = 0, and h + t*d in [0,1]^n for small t), the directional derivative is:
f'(h; d) = max_{k in S} (∂corr[k]/∂h · d) * dx

We can compute ∂corr[k]/∂h · d numerically by evaluating corr at h and h + eps*d.

1. A smooth local search (using the log-sum-exp approximation)
