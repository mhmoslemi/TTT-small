Actually, for a binary sequence of length n with k ones and n-k zeros, the cross-correlation at lag d is:
C(d) = #{i: h[i]=1, h[i+d]=0} for i in valid range

And C(-d) = #{i: h[i]=1, h[i-d]=0} = #{i: h[i]=0, h[i+d]=1}

Note that C(d) + C(-d) = #{i: h[i] ≠ h[i+d]} = number of transitions at distance d.

So C(d) + C(-d) is the total number of "mismatches" at lag d. To minimize max(C(d), C(-d)), we want C(d) ≈ C(-d) for all d, and we want the total mismatches to be small.

The minimum possible total mismatches is related to the "disagreement" of the sequence with its shifts. For a sequence with k ones and n-k zeros, the minimum number of disagreements at lag d is |k - (n-k)| type arguments... Actually it's more subtle.

For a binary sequence with k ones:

- Also C(d) = (number of 1s in first n-d positions) - A(d)
- And C(-d) = (number of 0s in first n-d positions) - A(d) = (n-d) - (number of 1s in first n-d) - (n-d) + A(d)...

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode="full")
    return np.max(corr) * dx

def compute_all_lags(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode="full")
    return corr * dx

def project_to_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0, 1)
    diff = target - np.sum(h)
    if abs(diff) < 1e-12:
        return h
    if diff > 0:
        room = 1.0 - h
        order = np.argsort(-room)
        remaining = diff
        for idx in order:
            if remaining <= 1e-15:
                break
            amt = min(room[idx], remaining)
            h[idx] += amt
            remaining -= amt
    else:
        room = h
        order = np.argsort(room)
        remaining = -diff
        for idx in order:
            if remaining <= 1e-15:
                break
            amt = min(room[idx], remaining)
            h[idx] -= amt
            remaining -= amt
    return h

    cooling = 0.99985
    min_temp = 1e-7
    stuck_count = 0
    
    while temperature > min_temp:
        if time.time() - start_time > time_limit:
            break

        move_type = rng.randint(8)

            h_trial[i] = 1.0 - h_trial[i]
        elif move_type == 1:

            j = rng.randint(n)
            h_trial[i] = 1.0 - h_trial[i]
            h_trial[j] = 1.0 - h_trial[j]
        elif move_type == 2:

            h_trial[i], h_trial[j] = h_trial[j], h_trial[i]
        elif move_type == 3:
