Let me think about this more carefully. When I change h[j] from old to v:
- The change in corr[k] (for shift s = n-1-k) is:

  - If j is valid as second factor (i=j-s in range): delta_second = -h[j-s] * (v - old) [if s≠0]
  - If s=0 and j valid: delta = v*(1-v) - old*(1-old)
  
  So delta_k = delta_first + delta_second (with appropriate conditions)

This is O(1) per k! So I can compute the new max in O(n) per candidate value.

```python
def eval_change(h, j, old_val, new_val, n):
    """Compute new max corr after changing h[j] from old_val to new_val (before projection).
    Assumes sum constraint is handled separately."""
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    new_corr = corr.copy()
    for k in range(2 * n - 1):
        s = n - 1 - k
        i_start = max(0, -s)
        i_end = min(n, n - s)  # exclusive
        delta = 0.0
        # First factor: h[j] appears as h[i] when i=j
        if i_start <= j < i_end:
            if s == 0:
                delta += new_val * (1 - new_val) - old_val * (1 - old_val)
            else:
                delta += (new_val - old_val) * (1 - h[j + s])
        # Second factor: h[j] appears as h[i+s] when i+s=j, i.e., i=j-s
        if s != 0 and i_start <= (j - s) < i_end:
            delta += -h[j - s] * (new_val - old_val)
        new_corr[k] += delta
    return np.max(new_corr) * dx
```

This is O(n) per candidate value (since we loop over 2n-1 shifts, each O(1)). For 24 candidates and n=42, that's 42 * 24 * 84 ≈ 85k per pass. Very fast!

def _resample(parent, new_n):
    """Area-preserving resampling from len(parent) to new_n."""
    old_n = len(parent)
    if old_n == new_n:
        return parent.copy()
    # Cumulative integral
    cum = np.cumsum(np.concatenate(([0.0], parent)))
    # New bin edges in old coordinate
    edges = np.linspace(0, 1, new_n + 1)
    old_edges = edges * old_n
    left = np.floor(old_edges).astype(int)
    left = np.clip(left, 0, old_n)
    right = np.minimum(left + 1, old_n)
    frac = old_edges - left
    cum_new = cum[left] * (1 - frac) + cum[right] * frac
    new_vals = np.diff(cum_new)
    return np.clip(new_vals, 0, 1)
