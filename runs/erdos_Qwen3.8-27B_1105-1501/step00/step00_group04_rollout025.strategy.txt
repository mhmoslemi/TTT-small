1. Approach and rationale

1.1 Central idea
The task is a discrete minimax problem over a vector constraint set, but the supplied parent is already close to the current best bound, so a full redesign or global search is not likely to succeed within the budget. The new approach is a local Sequential Linear Programming / active-set convex-quadratic method for the exact objective:

- At a feasible iterate h, compute the exact full overlap count vector returned by the authoritative evaluator convention, not a circular or continuous approximation.
- Select the lags that are at or near the current maximum. These are the active constraints that actually determine the present maximum.
- Approximate the bilinear overlap function associated with each active lag by its exact first-order linearization.
- Solve one small convex quadratic feasibility-reduction problem for a feasible direction u that attempts to move the current h along the feasible tangent space while lowering the linearized overlaps of all selected active lags.
- Apply an exact line search using the real evaluated objective and accept only exact objective improvements.

This is materially different from smoothly maximizing all lag scores with log-sum-exp, from simulated-annealing pair-transfer methods, and from solving a large integer feasibility certificate. The method uses only exact one-step linearizations of selected original overlap components, solves a genuinely convex subproblem over the original linear box-and-mass constraints, and never optimizes or accepts a surrogate final objective.

1.2 Why this could improve the supplied construction
The current record likely lies in a flat or narrow plateau. On such plateaus a smooth surrogate can spend effort reducing a large number of moderate lags whose gradients oppose each other, and annealing may accept uphill directions without generating a coherent feasible descent direction for the true maximal lags. An active-set linearization routine instead directly asks: can we move mass within the feasible box so that the exact first-order derivatives of the currently maximal overlaps all decrease? This concentrates search effort on the lags that are responsible for the present maximum and enables small but disciplined moves past local ties.

The method may or may not find the exact global optimum; no global optimality claim is made. It is a sound local construction method: every returned candidate is re-scored with the authoritative finite-support evaluator and must satisfy the stated constraints.

1.3 Distinction from previous plans
- No smooth-max or log-sum-exp whole-objective surrogate is optimized. Any smooth surrogate would be a heuristic; here the convex subproblem only contains exact linearized overlap constraints for selected maximal constraints.
- No annealing (`accept uphill by temperature`) is used for objective accuracy. Only exact objective decrease is accepted for continuation of the local iterate.
- No large global integer certificate or full MILP model is required. If the master candidate is binary finally, that is a discretization polish, not the central mechanism.
- The main computational engine is a sequence of small convex quadratic programs, each constrained to the exact linear constraint set `0 <= h <= 1` and total mass preservation, with exact line search against `np.correlate`.

1.4 Known limitations
- The original objective is nonconvex because the overlap elements contain bilinear terms. The linearized subproblem is convex only as a directional-first-order approximation; it is not guaranteed to reduce the exact objective for every step.
- The active set is local and discrete. A wrong active set can miss newly created peaks. The implementation mitigates this with tolerance-based active sets, top-lag selection, exact line search rejection, and increasing opposite active-size trials.
- It is a local method. The parent fallback and multi-seed candidate drawer prevent returning an invalid result, but do not prove global optimality or a target value.

2. Mathematical specification

2.1 Discrete vector and authoritative objective
Let h be a real vector of length n and dx = 2.0 / n. The authoritative discrete objective is:

C(h) = dx * max_k( corr(h, 1 - h, mode='full')[k] )

where the `np.correlate` call is direct finite-length linear correlation with q = 1-h. There are L = 2n - 1 correlation outputs. Because the evaluator's correlation itself may not be centered in intuitive order, the implementation must use this same evaluator for final scoring. For internal reasoning, define another unscaled `partial-shot score vector` `Y` of length L with the same values as `np.correlate(h, 1.0 - h, 'full')`, so that C(h) = max(Y) * dx. Use unscaled integers or real count values internally for numerical reason except that all exact returned bounds are computed by multiplying by dx and taking the maximum with the evaluator function.

2.2 Constraint set
For n samples, the exact constraints are:
- h_i ∈ [0,1] for each i = 0,...,n-1;
- sum_i h_i = n/2.

Do not enforce feasibility with clipping followed by scaling; this can violate bounds or mass. Use only the joint feasibility repair defined below and pair transfers or QP moves whose bounds and equality are implicit.

2.3 Unscaled overlap components and exact gradient formulas
Compute `Y = np.correlate(h, 1.0-h, 'full')`. Let center = n-1.

At center:
Y_center = sum_i h_i(1 - h_i)
lower_gradient_center_i = 1 - 2 h_i for each i.

For p < center, define d = center - p (positive lag). The evaluator component is:
Y_p = sum_{i=0}^{n-d-1} h_{i+d}(1 - h_i).
The exact derivative row with respect to h (unscaled by dx) is:
for i in 0,...,n-d-1, add -h_{i+d} to derivative at coordinate i;
for j in d,...,n-1, add 1-h_{j-d} to derivative at coordinate j.

For p > center, define d = p - center (positive lag). The evaluator component is:
Y_p = sum_{i=0}^{n-d-1} h_i(1 - h_{i+d}).
The exact derivative row is:
for i in 0,...,n-d-1, add 1-h_{i+d} to coordinate i;
for j in d,...,n-1, add -h_{j-d} to coordinate j.

Use gradient rows unscaled by dx. The dx factor is a positive scale multiplier and can be applied only at final objective evaluation.

2.4 Joint feasibility repair (exact mass/bounds projection with correction)
For any numeric flawed candidate y ∈ R^n, target tau = n/2.
1. Clip y to [0,1]; abort if all nonfinite; construct a simple uniform half-mass vector if necessary.
2. Solve equation phi(lambda) = sum_i clip(y_i - lambda, 0, 1) = tau by bisection.
   Bracket:
   lambda_lo = min(y)-1.0
   lambda_hi = max(y)
   At lo the clipped value is n; at hi it tends to 0, bracket contains tau for n>=0. If tau is invalid out of [0,n], repair returns the nearest feasible constant or random; this should not happen for normal n.
3. Set z_i = clip(y_i-lambda,0,1).
4. Apply exact small-mass final correction:
   r = tau - sum_i z_i, preferably `math.fsum`.
   If r > 0, iterate through entries in a fixed deterministic order or by largest-threshold slack and increase z_i up to 1 by successive min(r,1-z_i) until r is small or zero.
   If r < 0, iterate and decrease z_i up to -z_i.
5. Clip final z for tiny roundoff to [0,1].
This method restores feasibility jointly. If not finite after clear safe fallback (uniform 0.5 after repair) is used.

2.5 Active-set linearized convex subproblem
At current feasible h:
- Evaluate Y and exact objective F = max(Y)*dx. For active selection use `M = max(Y)` unscaled.
- Define tolerance `top_tol` as an unscaled count tolerance with scale relative to M or absolute lower floor.
- Select active lag indices A:
  A = the first `k` indices whose values satisfy Y[i] >= M - top_tol, or the largest `k` indices if that set has fewer than a minimum. k is selected from a small schedule, and a cap avoids too many constraints, e.g. maxactive <= 64 even for n near 100.
- For each p in A, compute row gradient `G_p` and unscaled `Y_p`.
- Define delta_p = M - Y_p. Since active page is within tolerance, delta_p is a small nonnegative gap.
- Define target decrease for row p:
  eta_p = max(eta_floor, eta_factor * trust_radius * ||G_p||_2)
  where trust_radius is the directional maneuver trust size for sum u^2-style norm, eta_floor around count units `1e-4` to `1e-3`, and eta_factor around 0.1 to 0.4. If `||G_p||` is below a row пыль gradient floor, skip the row.
- Convex QP variables:
  u ∈ R^n, slack e_p ≥ 0 for each selected row.
  Constraints:
    -h_i <= u_i <= 1-h_i for all i (h+u in bounds);
    sum_i u_i = 0 (mass preservation);
    G_p dot u <= delta_p - eta_p + e_p.
  Objective:
    minimize 0.5 * ||u||_2^2 + w_slack * sum_p e_p.
   Choose w_slack large relative to norm units, for example w_slack = 10 / max(trust_radius, 0.01). Solving first without slacks and then with slacks is suggested by adding optional `strict` flag. If `e` is zero for a solution, this has exact linear header satisfying every target. If zero due objective but the constraints can decrease jointly, soft side active sum helps due nonzero. Code must not claim exact objective decrease from convex solve; exact line line search remains the authority.

The QP is convex because it only has box linear constraints, one linear equality, affine inequality constraints on u, and convex quadratic objective. No product variable or relaxation is used beyond the linearization.

2.6 Exact line search and acceptance
Given proposal direction u from QP:
1. Zero the implicit trust direction: ensure sum approx 0. Direction if tiny/invalid; else bound compatibility: compute safe maximum scalar beta to full constraints using current h:
   for each coordinate if u_i>0: bmax = min(bmax,(1-h_i)/u_i,bmax)
   if u_i<0: bmax = min(bmax, h_i/(-u_i), bmax)
   always. If bmax <=0 stop. If u is exactly feasible within tolerance, bmax=1, otherwise use given earlier; use less than 1 for backtracking.
2. Evaluate exact full `Y` for h + alpha*u for selected alpha values: for example convex geometric `1,0.8,0.6,0.4,0.25,0.12,0.06,0.03,0.015,0.006,0.002` plus optional random uniform step `alpha*max,0.05`. If within-deterministic checknot exact grid simplest.
3. The lowest exact `C` may be current best; store every attempted and repaired exact permanent feasible candidate into a global history if it globally improves current global.
4. Make `h_prop = make_repair_y(h+alpha*u)` only to safeguard solver or numerical bound drift. Re-evaluate all constraints. If bounds fail or sum fails, discard.
5. Accept direction as a new active iterate only if its exact objective improves current F by a shrinking `accept_tol` (count_unit pref threshold between 1e-12 unscaled or `max(1e-11,relative_hard_score_tolerance)` final). Otherwise cannot shrink further. Later new candidate active best returned to global does not relieve how improvement must align local current.

Note: Because the true objective is continuous and only the first-order approximation is used, new peaks can prevent improvement; selected exact rejection can rescue good subproblem by causing active lists later to expand/narrow as in schedule.

1. Approach and rationale

1.1 Central idea
The proposed method is a local, exact-acceptance, active-set sequential quadratic/linear approximation for the discrete minimax overlap problem. At a feasible iterate h, the algorithm evaluates the true full finite-support overlap vector, identifies the lags that are at or near the current maximum, linearizes only those bilinear overlap components, and solves a small convex quadratic subproblem to obtain a feasible mass-preserving direction that lowers the linearized maximal lags. The direction is then tested by exact alternating evaluations using the true objective: `dx * max(np.correlate(h, 1-h, mode='full'))`. The iterate changes only when the exact objective truly improves.

This is a different primary mechanism from the prior smooth-log-sum-exp, mixed-integer exact certificate, or pair-transfer annealing plans. It does not optimize or accept a smooth surrogate objective, does not anneal uphill moves, and does not try to solve a global integer certificate. Its core search step is: use exact first-order information of the overlap components that are locally responsible for the current maximum, solve a linear/box-preserving convex approximation to find a coordinated descent direction, and accept only real evaluator incidents.

1.2 Why it may improve the parent construction
The parent is close to the target record. The objective surface is piecewise bilinear, and near a record value many overlaps may tie or nearly tie. These ties make it difficult to make progress by a generic gradient or gradient-like vector, because reducing one peak may increase another and moving in one variable-only tangent may not preserve feasibility or avoid boundary terms. An active-set quadratic subproblem directly asks whether a joint atomic move within [0,1] and sum mass can reduce the currently maximal set of overlap components. The exact line search then lets second-order behavior resolve the final choice. This can discover small coordinated improvements that simple active-gradients, pair annealings, or declining smoothing may miss. The exact acceptance test prevents surrogacy mistakes.

This plan does not claim global optimality. It processes supplied parent and random candidates locally and returns the lowest exact evaluated feasible vector encountered before the time limit.

1.3 Limitations and factual status
Factual:
- The exact objective is continuous and piecewise bilinear over the feasible set.
- Each overlap output component has the exact derivative formulas given below.
- The proposed subproblem, when generated with selected linearized overlap rows plus the feasible box constraints and a mass equality, is convex: it has linear constraints and a quadratic objective.
- Every returned returned/best candidate must pass exact feasibility and exact evaluator checks.

Heuristic:
- Linearizing only near-max overlap components can still be disadvantageous because second-order cross terms may reduce the maximum created elsewhere. This is mechanically compensated by exact line search, trust-size shrinking, active-set expansion across near ties, and rejection of false local linear improvement.
- A smaller, denser active set can be sensitive to active selection scheduling. A failure tower with increasing active counts and shrinking trust sizes reduces that risk.
- It is not a proof of global optimality or proof that C5 becomes below 0.3808. The final available proof validity is always obtained from the original evaluator.
