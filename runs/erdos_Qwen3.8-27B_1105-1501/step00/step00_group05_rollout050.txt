```python
def compute_slopes(h, i, j, N):
    """Compute g_k[i] - g_k[j] for all lags k, vectorized."""
    # For position p, the gradient across all lags:
    # g_k[p] = (1-h[p-k])*1[0≤p-k<N] - h[p+k]*1[0≤p+k<N]
    
    # First term for position p: h[p-k] for k in [p-(N-1), p] clipped to [-(N-1), N-1]
    # This is (1-h) shifted and masked
    
    def grad_all_lags(p):
        # Returns array of length 2N-1, index m corresponds to lag k=m-(N-1)
        g = np.zeros(2*N-1)
        # First term: (1-h[p-k]) for valid p-k
        # p-k in [0, N-1] means k in [p-(N-1), p]
        k_lo = max(p-(N-1), -(N-1))
        k_hi = min(p, N-1)
        if k_lo <= k_hi:
            m_lo = k_lo + (N-1)
            m_hi = k_hi + (N-1)
            # k ranges from k_lo to k_hi
            # p-k ranges from p-k_lo to p-k_hi
            idx = p - np.arange(k_lo, k_hi+1)
            g[m_lo:m_hi+1] += 1.0 - h[idx]
        
        # Second term: -h[p+k] for valid p+k
        # p+k in [0, N-1] means k in [-p, N-1-p]
        k_lo2 = max(-p, -(N-1))
        k_hi2 = min(N-1-p, N-1)
        if k_lo2 <= k_hi2:
            m_lo2 = k_lo2 + (N-1)
            m_hi2 = k_hi2 + (N-1)
            idx2 = p + np.arange(k_lo2, k_hi2+1)
            g[m_lo2:m_hi2+1] -= h[idx2]
        
        return g
    
    return grad_all_lags(i) - grad_all_lags(j)
```

This is O(N) per position, so O(N) total for the pair. With N^2 pairs, that's O(N^3) per full pass. For N=42, that's about 74k operations per pass. Very fast.
