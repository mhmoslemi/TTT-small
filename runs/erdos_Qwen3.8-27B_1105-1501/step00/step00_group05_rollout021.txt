Δf_k = Σ_m [δh[m]*(1-h[m-L_k]) + h[m]*(-δh[m-L_k])]
     = Σ_m δh[m]*(1-h[m-L_k]) - Σ_m h[m]*δh[m-L_k]
     = Σ_m δh[m]*(1-h[m-L_k]) - Σ_m h[m+L_k]*δh[m]  (reindexing)
     = Σ_m δh[m]*[(1-h[m-L_k]) - h[m+L_k]]

So Δf_k = δh · g_k where g_k[m] = (1-h[m-L_k]) - h[m+L_k] (with h[j]=0 for invalid j).

This is linear in δh! (For small perturbations, ignoring second-order terms.)

So the problem reduces to: find δh with sum(δh)=0, |δh| small, 0 ≤ h+δh ≤ 1, that minimizes max_{k∈A} (f_k + δh·g_k).

This is a linear programming problem (if we fix A)! We can solve it with scipy or even by hand for small |A|.

But the issue is that the linear approximation might not be accurate for the step sizes we need. And the active set might change as we move.

from scipy.optimize import linprog

def linprog_direction(h, active_indices):
    """Find the direction that reduces the max of active correlations."""
    n = len(h)
    
    # Compute gradients for active correlations
    # Correlation k (0 to 2n-2) has lag L = k - (n-1)
    # f_k = sum_m h[m] * (1-h[m-L])
    # df_k/dh[m] = (1-h[m-L]) - h[m+L] (with h[j]=0 for invalid j)
    
    grads = []
    for k in active_indices:
        L = k - (n - 1)
        g = np.zeros(n)
        for m in range(n):
            # Term 1: h[m]*(1-h[m-L]) → derivative wrt h[m] is (1-h[m-L])
            ml = m - L
            val1 = (1 - h[ml]) if 0 <= ml < n else 1.0  # if m-L is invalid, h[m-L]=0, so 1-h[m-L]=1
            # Term 2: h[m+L]*(1-h[m]) → derivative wrt h[m] is -h[m+L]
            mp = m + L
            val2 = h[mp] if 0 <= mp < n else 0.0
            g[m] = val1 - val2
        grads.append(g)
    
    grads = np.array(grads)  # shape: (|A|, n)
    
    # LP: minimize t
    # Variables: [δh[0], ..., δh[n-1], t]
    # c = [0, ..., 0, 1]
    c = np.zeros(n + 1)
    c[-1] = 1.0
    
    # Inequality constraints: A_ineq @ x ≤ b_ineq
    # For each k: sum_m δh[m]*g_k[m] - t ≤ 0
    A_ineq = np.zeros((len(active_indices), n + 1))
    for idx, k in enumerate(active_indices):
        A_ineq[idx, :n] = grads[idx]
        A_ineq[idx, n] = -1.0
    b_ineq = np.zeros(len(active_indices))
    
    # Box constraints on δh: already in bounds
    # sum(δh) = 0: equality constraint
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.zeros(1)
    
    # Bounds: -h[m] ≤ δh[m] ≤ 1-h[m], t ∈ [-inf, inf]
    bounds = [(-h[m], 1-h[m]) for m in range(n)] + [(-np.inf, np.inf)]
    
    res = linprog(c, A_ub=A_ineq, b_ub=b_ineq, A_eq=A_eq, b_eq=b_eq, 
                  bounds=bounds, method='highs')
    
    if res.success:
        dirn = res.x[:n]
        # Normalize
        norm = np.max(np.abs(dirn))
        if norm > 0:
            dirn /= norm
        return dirn
    return None
