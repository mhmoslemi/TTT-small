1. Approach and rationale

1.1 Central idea

The task is a finite-dimensional nonconvex minimax problem. For a discrete vector h of length n, the required official score is

    C(h) = dx * max_r np.correlate(h, 1-h, mode="full")[r],    dx = 2/n.

The constraint is

    0 <= h[i] <= 1,
    sum_i h[i] = n/2.

The proposed primary algorithm is not a generic smoothing-plus-SQP loop. It is a focused active-lag local optimizer built around the exact derivative structure of the correlations. The idea is:

- At a current feasible h, the true objective is controlled primarily by the largest few or many correlation bishop constraints.
- Around h, each correlation surface F_k(h) can be linearized.
- The largest correlations are pushed downward simultaneously by solving a small equality-constrained least-squares problem for a tangent direction that preserves the sum constraint exactly.
- A robust line search and a joint box-sum projection convert tentative moves into perfectly discrete feasible vectors.
- Exact official scoring, rather than the linearized model, decides every accepted move and the final returned vector.
- The search explores a diverse but small pool of analytically generated feasible seeds, including the supplied parent, shifted/complement-reflected parents, deterministic block/sine alternations, and balanced quantizations of random perturbations.

This approach targets the bottleneck that custom local or global black-box methods often encounter: the objective is dominated by several competing lag constraints, so moving all of them together in a tangent compatible with the sum constraint is more effective than moving along the maximum-subgradient gradient or only smoothing the maximum.

1.2 Why this can improve the parent or solve the task

For a tiny desired improvement, e.g. from about 0.38085 to 0.38080, move feasibility is delicate. A successful move must:

- reduce the active correlation lags,
- not push a subset of nonactive lags above the current maximum,
- maintain the sum exactly,
- respect 0 <= h <= 1.

The equality-constrained least-squares direction is explicit about the active correlation derivatives and preserves the sum exactly by being restricted to a sum-zero basis before projection. The projection is applied only at the outer feasible trajectory level, so the direction never violates the equality constraint in its raw form.

1.3 Honest limitations

The governing surface in each correlation lag includes negative bilinear products h_i h_j, so the exact feasible set {h:C(h)<=t} is nonconvex. The linearized least-squares subproblem is therefore only a local heuristic model, not a relaxation with a global certificate. Accepted moves are validated by the original evaluator only. No step or solver is claimed to produce a global optimum.

2. Mathematical specification

2.1 Exact official objective, necessary for acceptance

For any returned vector h of length n:

    dx = 2.0 / n
    corr = np.correlate(h, 1.0-h, mode="full")
    score = np.max(corr) * dx

Only this formula, not a manually indexed surrogate, determines acceptance and the returned bound. If this is finite and the harness convention treats nan/inf as invalid, it must be rejected.

2.2 Manual correlation values for gradients

Define for each integer lag k = -(n-1), ..., n-1:

    valid i satisfy 0 <= i < n and 0 <= i+k < n,
    i_start(k) = max(0, -k),
    i_end(k) = min(n, n-k)  # Python-exclusive end.

The unscaled correlation value for that lag is

    F_k(h) = sum_{i=i_start(k)}^{i_end(k)-1} h[i] * (1 - h[i+k]).

This is a sum of some, but not necessarily the same as, np.correlate's full output ordering. The ordered set of F_k for k=-n+1..n-1 is identical to the ordered set of np.correlate(h, 1-h, "full") up to a permutation, including both lag directions; take the max for validation.
