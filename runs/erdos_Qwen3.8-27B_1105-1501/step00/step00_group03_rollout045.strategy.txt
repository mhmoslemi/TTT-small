The problem is a finite-dimensional, nonconvex minimax problem on a constrained box/simplex:

\[
C_5(h)=\max_{r=0,\ldots,2n-2} dx\; \text{fullcorrelation}_{r}(h,1-h),
\qquad dx=2/n,\qquad \sum_i h_i=n/2,\qquad 0\le h_i\le 1.
\]

Each correlation constraint expands into linear plus negative bilinear products, for example terms of the form
\[
h_i(1-h_j)=h_i-h_i h_j,
\]
so the feasible set \(\{h:C_5(h)\le t\}\) is generally nonconvex. Direct global convex optimization is therefore not applicable, and a CVXPY formulation containing arbitrary bilinear terms cannot be declared a valid convex subproblem.

The proposed method therefore uses:

- **Uniform constraints and exact evaluation:** every candidate that is reported or selected as a warm start is scored by the supplied official metric \(\max(\text{np.correlate}(h,1-h,\text{full}))*2/n\), not by a relaxed surrogate or manual-only bound.
- **A smoothing ladder:** smoothly aggregate near-active lag constraints using exponential or softmax weights. This gives better local descent information than the nondifferentiable maximum when many lags are almost maximal.
- **A direct constrained local minimax optimizer:** after smoothing, solve an explicit minimax NLP using SLSQP over all lag inequalities with exact first-order gradient information.
- **Multistart, interpolation, and symmetry transforms:** a small set of reachable neighborhood starts and combinatorial-like transforms can move the search to a different basin that a single polish may not reach.
- **Conservative fallback:** the parent construction is always treated as a valid feasible benchmark whenever it is internally valid; failure of any local solve, perturbation, projection, or alternative resolution automatically falls back to the best feasible candidate seen so far.

The target gap from roughly \(0.38085\) to \(0.3808\) is tiny. To pursue it safely, the procedure combines acceptance only against the **actual evaluator objective**, allowable small absolute and relative tolerances, multi-start intensification, and a suite of basin changes. The plan cannot honestly claim a global optimum unless separate proof is obtained; the bound it returns is the best exact feasible result found.

1.2 What the pipeline fixes  
The pipeline addresses the primary bottlenecks:

- The smooth maximum gives gradients that distribute movement among several constraints that remain close to the maximum after smoothing.
- Direct minimax restricts the lower objective without explicitly enforcing a penalty target; it gradually raises slack and decreases the maximum.
- A projection treating box and sum constraints simultaneously prevents the common failure of “clip to [0,1]” followed by “rescale sum,” which can violate either constraint.
- Resolution and representation changes exercise different local geometry and can produce lower evaluated step functions.

1.3 Honest limitations  
SLSQP is only a local constrained nonlinear optimizer. The method offers only numerical evidence under the exact evaluator. No CVX/CVXOPT/nonconvex heuristic result is treated as a valid upper bound unless the candidate vector is reproduced through the final exact objective after feasibility rechecking.

2.2 Manual correlation vector for gradients  
Because an analytic Jacobian is useful, define a manual set of unscaled correlations corresponding to every relevant lag. This set may be permuted relative to `np.correlate`; at the level of the **max**, only the set matters.

Let \(k\in\{-n+1,-n+2,\ldots,n-1\}\) and put \(r=k+n-1\). For terms,

\[

over valid indices \(i\) satisfying \(0\le i<n\) and \(0\le i+k<n\).

Valid index range for fixed \(k\):

\[
\text{start}(k)=\max(0,-k),\qquad \text{end}(k)=\min(n,n-k).
\]

Then \(i\in[\text{start}(k),\text{end}(k))\). The returned unscaled array shape is \((2n-1)\).

A systematic orientation check is mandatory during debug sanity validation: the maximum of `manual_values(h)* dx` should agree with
\[

within numerical tolerance. If sorting is used for checking, sort both vectors and compare sets, because signs/order may be reversed; the evaluator itself includes all signs, so the maximum only has to agree.

2.3 Manual gradient  
Let \(M\) denote row matrix of \(F_k\). Using the formula above:

For a fixed lag \(k\) pair \(i\to j=i+k\), the contribution
\(F\) contains \(x_i(1-x_j)\). Its derivatives include:

- at column \(i\): \(1-x_j\);
- at column \(j\): \(-x_i\).

A single output column can also be the second member of another pair for a different first index on the same row, therefore accumulation is mathematically required. Build a dense matrix of size \((2n-1)\times n\) with additions using `np.add.at` or an equivalent accumulation, never assignment that overwrites valid accumulated components.

Equivalent direct formula: for row \(r\) corresponding to \(k\),

\[
\frac{\partial F_k}{\partial x_p}=\mathbf 1_{p\text{ valid first}}(1-x_{p+k})-\mathbf 1_{p-lag valid right}}x_{p-k}.
\]

For \(k=0\), pairs yield \(1-2h_p\), as derivatives of \(h_p(1-h_p)\).
