- h[i] appears as second factor if 0 ≤ i - lag < n, contributing h[i-lag] * (1-h[i])

So the coefficient of h[i] in corr[m] is:
- (1-h[i+lag]) if 0 ≤ i+lag < n (as first factor)
- -h[i-lag] if 0 ≤ i-lag < n (as second factor)
- 0 otherwise

And the constant term (with h[i] removed) is:
- corr[m] - h[i] * (coefficient)

Actually, the simplest way is:
corr[m] as a function of h[i] (with all other h fixed) is:
- If only first factor applies: h[i] * (1-h[i+lag]) + rest = linear in h[i]
- If only second factor applies: h[i-lag] * (1-h[i]) + rest = -h[i]*h[i-lag] + const = linear in h[i]
- If both apply: h[i]*(1-h[i+lag]) + h[i-lag]*(1-h[i]) + rest
  = h[i] - h[i]*h[i+lag] - h[i]*h[i-lag] + h[i-lag] + rest
  = h[i]*(1 - h[i+lag] - h[i-lag]) + const
  = linear in h[i]
- If lag = 0 (m = n-1): h[i]*(1-h[i]) + rest = -h[i]² + h[i] + rest = quadratic

So for lag ≠ 0, it's always linear in h[i]. For lag = 0, it's quadratic (concave).

The "both apply" case happens when 0 ≤ i+lag < n AND 0 ≤ i-lag < n, i.e., when |lag| ≤ min(i, n-1-i).

            h[idx] -= rem
            remaining -= rem
            if remaining < 1e-14:
                break
    return h

def coord_descent_step(h, i, n, dx, temp):
    h0 = h.copy()
    h0[i] = 0.0
    h1 = h.copy()
    h1[i] = 1.0
    c0 = np.correlate(h0, 1 - h0, mode='full') * dx
    c1 = np.correlate(h1, 1 - h1, mode='full') * dx
    a = c1 - c0
    b = c0
    def f_1d(t):
        vals = a * t + b
        mx = np.max(vals)
        return (mx + np.log(np.sum(np.exp(temp * (vals - mx)))) / temp)
    res = minimize_scalar(f_1d, bounds=(0.0, 1.0), method='bounded',
                         options={'xatol': 1e-10})
    return res.x

def coordinate_descent(h, n, dx, temp, max_sweeps=40):
    for sweep in range(max_sweeps):
        max_change = 0.0
        for i in range(n):
            new_val = coord_descent_step(h, i, n, dx, temp)
            max_change = max(max_change, abs(new_val - h[i]))
            h[i] = new_val
        if max_change < 1e-11:
            break
    return h
