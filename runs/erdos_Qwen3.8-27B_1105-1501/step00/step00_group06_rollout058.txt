For the binary problem, simulated annealing with swap moves can escape local minima. The key is:
1. Start from a good initial solution (parent binarized)
2. Make random swaps
3. Accept if it improves, or with probability exp(-Δ/T) if it worsens
4. Slowly decrease T

1. Start from parent
2. Binarize
