import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, dx):
    corr = np.correlate(h, 1 - h, mode='full')
    return np.max(corr) * dx

def project_onto_feasible(h, target_sum):
    """Project h onto {sum(x) = target_sum, 0 ≤ x ≤ 1}"""
    h = np.array(h, dtype=float)
    n = len(h)
    # Bisection on lambda: find lambda such that sum(clamp(h[i]-lambda, 0, 1)) = target_sum
    lo, hi = -3.0, 3.0
    for _ in range(80):
        mid = (lo + hi) / 2
        s = np.sum(np.clip(h - mid, 0.0, 1.0))
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def subgradient_c(h, k, n):
    """Subgradient of c_k(h) = sum_n h[n+k]*(1-h[n]) at point h.
    Using the convention from np.correlate: lag k means index m = k + (n-1)."""
    grad = np.zeros(n)
    # dc_k/dh[j] = (1-h[j-k]) * 1_{0≤j-k<n} - h[j+k] * 1_{0≤j+k<n}
    # First term: j-k must be in [0, n-1], so j in [k, k+n-1] intersect [0, n-1]
    if k >= 0:
        # j ranges from k to min(n-1, k+n-1) = n-1
        # j-k ranges from 0 to n-1-k
        for j in range(k, n):
            grad[j] += (1 - h[j-k])
    else:
        # j-k = j+|k|, must be in [0, n-1], so j in [-|k|+0, n-1-|k|] = [-(|k|), n-1-|k|]
        # intersect with [0, n-1]: j in [0, n-1-|k|]
        for j in range(0, n + k):  # n+k = n-|k|
            grad[j] += (1 - h[j-k])
    
    # Second term: j+k must be in [0, n-1], so j in [-k, n-1-k] intersect [0, n-1]
    if k >= 0:
        # j in [0, n-1-k]
        for j in range(0, n - k):
            grad[j] -= h[j+k]
    else:
        # j in [-k, n-1] = [|k|, n-1]
        for j in range(-k, n):
            grad[j] -= h[j+k]
    
    return grad

Actually, I realize I should also think about the "soft-max + L-BFGS-B" approach more carefully, because L-BFGS-B is much faster than SLSQP for this problem size.

The soft-max approximation:
f_β(h) = (1/β) * log(sum_k exp(β * c_k * dx))

As β → ∞, f_β → max_k c_k * dx.

The gradient:
∇f_β(h) = (sum_k exp(β * c_k * dx) * ∇c_k * dx) / (sum_k exp(β * c_k * dx))
= (sum_k w_k * ∇c_k) * dx where w_k = exp(β * c_k * dx) / sum_j exp(β * c_j * dx)

This is a weighted average of the subgradients, which is smooth. I can use L-BFGS-B on this.

But I need to handle the sum constraint. I can parameterize h = 0.5 * ones + u where sum(u) = 0, and use the null space.

Actually, for n=45, the null space of [1,1,...,1] has dimension 44. I can construct a basis:
B = [b_1, ..., b_44] where b_i is the vector with 1 at position i, -1 at position n-1, and 0 elsewhere (for i = 0, ..., n-2).

Then h = 0.5*ones + B @ z, and I need to ensure 0 ≤ h ≤ 1, i.e., -0.5 ≤ B @ z ≤ 0.5.

The bounds on z are not simple box constraints, so L-BFGS-B won't directly work. I could use a penalty method or just use SLSQP.
