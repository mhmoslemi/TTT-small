1. Approach and rationale

1.1 Central idea

The task is a finite-dimensional nonlinear minimax problem.  The planner constructs a discrete function h represented by a one-dimensional NumPy vector of length n and seeks to minimize

    C(h) = dx * max_r np.correlate(h, 1-h, mode="full")[r],   dx = 2/n,

subject to

    0 <= h_i <= 1,   sum_i h_i = n/2.

The proposed algorithm is based on two exact structural observations and one local optimization discipline.

First, the full finite-support objective includes all lag signs.  Invariance under the transformation

    T(h)_i = 1 - h_{n-1-i}

is immediate at the level of the complete lag set: a term corresponding to one lag is transformed into the reversed term corresponding to the opposite lag.  Therefore evaluating h or T(h) with np.correlate over all full lags gives the same maximum.

Second, the constraint sum(h)=n/2 can be made exact automatically if we restrict to the symmetric-complement subspace

    h_i = a_i,     h_{n-1-i} = 1 - a_i

with 0 <= a_i <= 1.  For odd n, the centre entry is fixed to 0.5.  Any value of the reduced vector a in [0,1] produces a perfectly feasible full vector, in real arithmetic, without clipping followed by sum rescaling.  This eliminates the equality constraint entirely and reduces the decision dimension from n to ceil(n/2), with only simple box bounds remaining.

Third, the main promotion mechanism is exact-score local descent.  The optimizer is not driven only by a smooth surrogate or by an unviewed linearized objective.  At each current symmetric vector a, the algorithm:

1. computes the exact original objective for candidate moves;
2. identifies active finite-support correlation constraints using exact correlation rows and gradients;
3. forms candidate directions by an active-constraint linearized least-squares model, negative active gradients, and several deterministic transformations;
4. performs an exact one-dimensional search along each direction in the symmetric box and accepts only exact improvements;
5. refines promising candidates with a direct minimax nonlinear program formulated only in reduced symmetric variables, using SLSQP and exact row gradients.

The algorithm explores this reduced symmetric family from many starting points: the supplied parent, symmetrized/interpolated parents, binary complement patterns, cosine and logistic patterns, random symmetric patterns, and offspring combinations.  All candidates are scored by the original evaluator.  The main limitation is that the problem remains bilinear and nonconvex, and symmetric reduction is not claimed to contain the global optimum.  Nevertheless it gives a strong local optimizer with exact feasibility, reduced coordinates, and a direct model for the largest constraints.

1.2 Why this addresses the computational bottleneck

The supplied parent is already near record quality.  Small improvements normally violate some nonactive lag constraints when attempting only a single descent direction.  The active-correlation tangent model is aimed at this bottleneck: several large constraints are linearized and exploited simultaneously through a least-squares direction.  Candidate moves are then checked exactly, so an inactive constraint cannot be accepted if it becomes larger.

The symmetric parameterization is the second key improvement.  Ordinary optimization must either add an equality constraint or use a joint projection after every update.  Here the equality is imposed automatically by the design.  The optimizer has half as many variables, no equality row Jacobian, and no post-update sum repair.  This improves numerical conditioning and makes closed-form gradients easy to verify.

1.3 Honest limitations and hypotheses

The exact local formulation uses bilinear objectives and is not convex.  A constrained local solve is accepted only if the original np.correlate score improves.  SLSQP should be regarded as a local polish, not a certificate of global optimality.  Symmetric-complement search is a heuristic restriction intended to contain excellent records, based on invariance and the observed use of complement-reflection in this class of problems; it is not invoked as a proven missing minimizer.  The raw supplied parent remains a valid fallback whenever it is feasible.  If the search remains nonempty, the program always returns a discrete feasible vector and a bound recomputed from that vector.
