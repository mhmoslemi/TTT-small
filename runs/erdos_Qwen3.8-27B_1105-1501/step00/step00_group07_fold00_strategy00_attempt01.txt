1. Approach and rationale

1.1 The optimization is intrinsically non-convex. The feasible set
{h_i: 0 <= h_i <= 1, sum h_i = n/2} is convex, but the objective
max_lag dx * sum_{overlapping i} h_i (1 - h_{i+lag}) contains products
h_i h_{i+lag}. Therefore no method that uses a convex relaxation, a
linearized proxy, or a projected gradient surrogate can be claimed to
produce a global optimum. The plan below is a local, multi-start,
meta-local search: every proposed descent direction comes from a
mathematically consistent surrogate gradient, but the only decision
rule that changes the returned construction is the exact evaluator
max(np.correlate(h, 1-h, mode="full") * dx). No surrogate acceptance is
ever used for the final bound, and no global-optimality claim is made.

1.2 The supplied parent construction is retained as an anchor. A local
search from the parent may already improve it slightly because the
record is a near-optimal point and the peak constraints are active. However,
local basins can be very nearby. Therefore the primary search must combine:

- deterministic/refined restarts from the parent and reverse-parent;

- short perturbations around the current best maximizers;

- simulated-annealing binary trials, optimized when the resolution is
  converted to an even number so that integer half-density is valid;

- low-temperature log-sum-exp smoothed descent and exact active-subgradient
  descent, both projected onto the box+sum feasible set;

- a small number of neighboring resolutions, checked only within the
  remaining time and with exact resampling. Each returned vector is checked
  with the exact discrete objective supplied by the evaluator.

1.3 The central improvement bottleneck is not evaluation cost; it is the
max-type objective. Many sub-descent mutations improve inactive lags but
do nothing to the current maximum, or reduce the current peak while
forcing another constraint to become the new maximum. The algorithm
therefore explicitly encourages spreading the maximum over multiple active
terms (smooth log-sum-exp with decreasing temperature) and then uses an
active-set subgradient that reduces the largest terms directly. Simulated
annealing supplies diversity because the smoother surrogate still has many
locally inactive peaks. The method is heuristic but internally consistent.

1.4 Important limitations:

- The returned vector is a feasible discrete approximation of a step
  function; it is not certified optimal.

- Resolution changes can change the discrete objective. A resampled
  larger-resolution vector is never accepted merely because it improves in
  continuous hint; it is re-evaluated exactly at the proposed resolution and
  only then compared.

- At odd n, the sum target n/2 is fractional, so exact binary half-density
  is invalid. Binary SA is run only on candidate even resolutions; continuous
  at odd parent n still uses projected fractional feasibility.

- Multistart and simulated annealing example schedules are chosen so the
  program remains in the 1100-s box; every inner routine checks the deadline.
  The function's only valid exit conditions are a stored feasible best object
  and a final exact re-evaluation.

2. Mathematical specification

2.1 Feasible discrete representation

Let n = n_points, dx = 2/n. Interpret h as sample values on the right-endpoint
pieces of [0, 2]: the i-th sample represents [i dx, (i+1) dx). Objective
evaluates exactly on these discrete values; no continuous reconstruction is
used for the score.

Constraints are:

(1) 0 <= h_i <= 1 for every i=0,...,n-1.

(2) sum(h) = n/2 exactly (or within numerical tolerance; final code will
    redistribute to satisfy this as closely as the stored float array allows).

The target mass/area is chosen with `target = n / 2`; sum(h)*dx = 1 follows
algebraically because dx = 2/n.

2.2 Exact objective

For all integer lags -(n-1),...,n-1,

C_k(h) = dx * sum_{all i where 0 <= i < n and 0 <= i+k < n}
                 h_i * (1 - h_{i+k}).

Then

C(h) = max_k C_k(h).

The evaluator uses
max(np.correlate(h, 1-h, mode="full"))*dx. Use that exact code for final
acceptance and evaluation. The following pairwise representation contains the
same set (possibly permuted by lag indexing):

For n >= 2, define:

A_0 = dx * sum_{i=0}^{n-1} h_i (1-h_i).

For p=1,...,n-1:

A_plus(p)  = dx * sum_{i=0}^{n-1-p} h_i (1 - h_{i+p}).

A_minus(p) = dx * sum_{i=0}^{n-1-p} h_{i+p} (1 - h_i).

Use the internal vector

A = [A_0, A_plus(1),...,A_plus(n-1), A_minus(1),...,A_minus(n-1)]

of length m = 1+2(n-1). Its maximum should equal the evaluator's objective up
to numerical differences and lag permutation. This internal vector is justified
because it is exactly the set of all directional overlap terms plus its
opposite direction plus lag zero. Before using it for optimization, perform a
sanity test for random feasible vectors: max(A) and evaluator max must agree
within approximately 1e-12. If they do, reverse or swap the plus/minus
blocks; a permutation do not change the maximum but can change the orientation
of derivative indexing in active descent.

2.3 Smooth max and differentiated surrogate

For tau > 0, let M = max(A). Define

Phi_tau(h) = M + tau * log(sum_j exp((A_j - M)/tau)).

The weights are

w_j = exp((A_j - M)/tau) / S,  S = sum_j exp((A_j-M)/tau),

so sum_j w_j = 1 and w_j are exponential network. Phi_tau >= max(A), and
tau -> 0 yields Phi_tau -> max(A). This is a smoothing of the primal objective
and is never used for the accepted numerical bound.

General vector form: For a weight vector w_j whose coordinates match A, the
gradient of weighted sum sum_j w_j A_j with respects to h is exactly

g = sum_j w_j grad A_j.

The total gradient of Phi_tau is obtained with w = softmax(A/tau). It is
feasible-compatible: if h is projected after the update, the equal mass
constraint remains feasible.

Explicit gradient formulas (valid in Python floating arithmetic):

Initialize g[j]=0 for j=0,...,n-1.

Central component weight w0:

g[j] += w0 * dx * (1 - 2 h[j]),  j=0,...,n-1.

Positive p, p=1,...,n-1, weight wp:

for j=0,...,n-1-p:

  g[j] += wp * dx * (1 - h[j+p])

  g[j+p] += wp * (-dx * h[j])

Negative p, weight wm:

for j=0,...,n-1-p:

  g[j] += wm * (-dx * h[j+p])

  g[j+p] += wm * dx * (1 - h[j])

Use vectorized shortest-range/J-index operations; no-by-element Python loops for
speed. When plus and minus blocks are permuted relative to the evaluator, the
softmax approximation gradient of the permuted objective is the same, providing a
permutation only required is a consistent A.

2.4 Exact active-subgradient direction

For producing a direct descent direction at the current best unknown C, choose
a top active set:

Let e(C)=max(C_rel * max(1e-3, C_C0), abs_tol). C_C0 is the largest component
