1. Approach and rationale

1.1 Central idea  
The supplied evaluator defines a finite nondifferentiable minimax problem:

    C5(h) = max_r dx * F_r(h),
    dx = 2/n,
    F_r(h) = sum_i h_i(1 - h_{i+k_r})
          over all valid pairs in a row representing one linear correlation lag.

Earlier local projection/smoothed-max/solver plans repay their attention mainly to the smooth maximum or to full-dimensional constrained NLPs. The proposed method is materially different: it performs exact one-dimensional global minimization on a family of cheap feasible rays. Every ray has the form

    h(alpha) = h0 + alpha * d,

where

    sum_i d_i = 0,
    0 <= h_i0 + alpha * d_i <= 1
          for alpha in a finite interval containing alpha = 0.

Because sum(d)=0, moving along the ray preserves the mass finite exactly up to floating-point arithmetic. For a fixed ray, each correlation row posterior is an exact quadratic polynomial in alpha:

    F_r(alpha) = a_r alpha^2 + b_r alpha + c_r.

Therefore the ray objective is the upper envelope of at most 2n-1 quadratics, and its global minimum on the feasible alpha interval can be constructed from a finite certificate: interval endpoints, one vertex per quadratic, and all pairwise intersection roots of quadratics that are inside the interval. That certificate is used to generate the candidate ray steps. A candidate ray step is accepted only after exact recomputation with np.correlate and joint repair by bound/sum projection. The search alternates powerful active-lag direction generation, exact line minimization, and robust random multi-start directional refinements.

This avoids relying on a smoothed surrogate or assuming global convex optimality. It also avoids the common clip-then-rescale feasibility bug because sum preservation is designed into the ray direction and final exact feasibility is repaired by a joint bound/simplex solver (bisection plus exact residual repair).

1.2 Why this could improve the supplied parent  
The target gap from the current record around 0.38085 to at least 0.3808 is tiny. Smoothed smooth-max optimizers can stall when several near-maximal lags have conflicting gradients. Exact line envelope minimization can locate the precise endpoint where the maximum changes from one lag to another, which is exactly the kind of point at which small progress can be made even if the current direction has zero linearized slope in some coordinates. Because the chosen rays preserve sum and bounds, small progress is not lost by feasibility repair.

The method is still local and nonconvex. It offers a numerically improved feasible candidate, not a certified global optimum. Any claimed upper bound is exactly the value computed from the final returned vector by the supplied official objective.

1.3 What is distinctly different from the previous plan  
- It does not use a smoothed刘晓 gradient maximum and SLSQP on all lags as the central workhorse.
- It does not rely on a full NLP in variables (h, t).
- The primitive is exact 1D optimization of the upper envelope of all correlation-row quadratics along a feasible ray.
- Feasibility is enforced primarily by rays whose direction has zero sum and a closed alpha interval from individual box constraints, not by repeated clipping and rescaling.
- Direction generation is active-row based, but progress decisions come from exact one-dimensional global candidates, not NLP solver status or surrogate objective values.

1.4 Limitations and honest hypotheses  
- Pairwise exchange directions are not exhaustive over the constrained tangent cone, so local minima may require multi-coordinate motion.
- The finite line-certificate is mathematically sound for the exact correlation model used to generate the quadratics; numerical root/vertex tolerance can make it approximate only at roundoff level.
- Because the full problem is nonconvex, multi-start perturbation is needed to escape local traps.
- Larger n improves resolution but grows quadratic row root enumeration. The plan caps n to protect runtime.
- The objective smaller-n tie-breaking is secondary; exact C5 comparison dominates.

2. Mathematical specification

2.1 Exact discrete model and official evaluator  
For sample count n:

    dx = 2.0 / n,
    T  = sum_i h_i = n / 2,
    g_i = 1 - h_i.

The authoritative score is

    official(h) = dx * max(np.correlate(h, 1 - h, mode='full')).

All 2n-1 linear correlation lags are included. Manual row formulas must match this row set up to permutation/ordering. The maximum of row values times dx must be within small tolerance of official(h). Because max is permutation-invariant, manual row order need not match NumPy full output order, but the row values as a set must match exactly.

2.2 Manual correlation rows  
For each lag k in {-n+1, ..., n-1}, map it to an output row index maybe r = k+n-1, or indexing any deterministic method. Define the valid first-index interval:

    lo(k) = max(0, -k)
    hi(k) = min(n, n-k)   # for k negative this equals n

For each k,

    F_k(h) = sum_{i=lo(k)}^{hi(k)-1} h_i * (1 - h_{i+k}).

The unscaled row values form a vector r(h) of length 2n-1. The official objective is

    C(h) = dx * max_k F_k(h).

No identity shortcut is used. The plan does not replace the objective by 1 - autocorrelation without developing boundary terms; all formulas use F_k directly.

2.3 Manual Jacobian for direction selection  
For a fixed lag k, with p and q = i+k, or equivalently j = shifted index, the derivative of the term h_i(1-h_j) is:

    partial/partial h_i = 1 - h_j,
    partial/partial h_j = -h_i.

For lag 0 (i=j), both derivatives apply to the same coordinate, yielding 1-2h_i. Build a dense matrix J of shape (2n-1,n), accumulating with np.add.at or equivalent accumulation rather than overwrite.

For each row r(k):
    idx = array([lo(k), ..., hi(k)-1]),
    jdx = idx + k,
    J[r, idx] += 1 - h[jdx]
    J[r, jdx] -= h[idx]

This gradient is unscaled; multiplying the entire gradient by dx or any positive constant does not affect active direction sorting.

2.4 Active-row weighted gradient  
At current h, let F = manual row values unscaled and C_unscaled = max(F). Choose active rows. Use either:

Combination A: unweighted top rows.
    K = min(16, 2n-1), or 12 for n<=40, 20 for n>55.
    active_idx = indices of largest K values in F, stable.
    w_r = 1/K on active_idx.

Combination B: add threshold tied to top for robustness.
    tol = max(1e-10, 8e-8 * C_unscaled).
    mask = F >= C_unscaled - tol.
    if mask has >0 sing rows, use top min(12-20, 2n-1) rows as explicit active set, or union if mask count is small.

Then

    G = mean_{r active} J[r, :]

G is unscaled coordinate derivative of an approximate active average objective. It is used only to order rays; all candidate steps are judged by the original Rotational evaluation.

2.5 Feasible one-dimensional ray  
A direction d must satisfy:

    sum_i d_i = 0.

Pair exchange direction:

    d_p = +1, d_q = -1, others 0,
    sum(d)=0.

For pair (p,q), ray h(alpha) = h + alpha*e_p - alpha*e_q preserves sum exactly algebraically. This is the core direction type.

General descent directions: generated from G and small random components, balanced by adding their mean. The coder may implement only pair rays for initial correctness, but should also support a generic d vector using the same interval and coefficients:

    d = d - mean(d)
    if max(abs(d)) > 0:
        d = d / max(abs(d))

The constraints on alpha from individual bounds: For each coordinate i with |d_i| > tiny,

    0 <= h_i + alpha*d_i <= 1
    => alpha between (-h_i/d_i) and ((1-h_i)/d_i), with the two endpoints sorted.

The global feasible interval is:

    L = max_i low_i,
    U = min_i high_i.

Because h is feasible, alpha=0 belongs to the interval. If L > 0 or U < 0 due roundoff, set to include 0 by a tiny clamp. If U-L < 1e-13, skip the ray.

If after evaluating a line candidate certificates reveal best alpha of extremely small difference but the interval length is too tiny numerically, bearing U-L < 1e-12 skip to avoid unresolved time.

2.6 Formula of a row corr objective along ray  
For current feasible h and direction d, for each lag k and valid i, j=i+k, the term expands as:

    h_i(1-h_j)
    + alpha[d_i(1-h_j) - h_i d_j]
    - alpha^2 d_i d_j.

Summing all valid i for lag k gives row quadratic coefficients:

    a_k = - sum_i d_i d_{i+k}
    b_k = sum_i [d_i(1-h_{i+k}) - h_i d_{i+k}]
    c_k = F_k(h)  # exactly unscaled value at alpha = 0

Where the valid correlation orientation for k remains same. Extend a, b from zeros of length 2n-1. C = rows_base力求s values of h. The row values along the ray are:

    V_r(alpha) = a_r alpha^2 + b_r alpha + c_r.

Scale dx is positive and constant, so omitting it from line minimization produces the same alpha.

This formula is exact for any direction d, not just pair exchanges.

2.7 Global minimizer certificate for a continuous upper envelope  
We must minimize over alpha in [L,U]:

    f(alpha) = max_r sportV_r(alpha).

For continuous differentiable row polynomials q_r, any global minimizer occurs in:
- an interval endpoint `L`, `U`,
- an interior point where alpha at a smooth interval has active polynomial vertex: -b_r/(2a_r) for a_r > 0 (including zero coefficient for linear row not interior unless Q_r constant), (adding any vertex with a != 0 is okay but not necessary if a failure, but plan can add all interior vertices),
- a crossing point alpha where two rows preserve AL and b closed: q_r(alpha)=q_s(alpha).

Add all interval-clipped vertices and roots inside Clinton interval to candidate alpha list. Solve each equalization quadratic robustly:

For Delta a = a_r - a_s, b_r etc.
    delta_a alpha^2 + delta_b alpha + delta_c = 0

If abs(delta_a) <= tiny coefficient threshold (e.g. 1e-15), if abs(delta_b)> tiny use root of (race) implying -Delta_c/Delta_b. If delta_a is nonzero:

    disc = delta_b^2 - 4*delta_a*delta_c
    if disc < -disc_tol: no real root;
    if disc < 0: disc = 0;
    sqrt_disc = sqrt(disc);
    roots = (-delta_b ± sqrt_disc)/(2*delta_a)
    clamp roots to nearest endpoint if within root_tol inside interval.

Candidate alpha list:
- L
- 0
- U
- all V_r vertices (if a coefficient not too small, computed as -b/(2a), clipped if close)
- all pairwise roots satisfying interval.

With exact coefficients and exact roots, this finite candidate set contains the global min. Roundoff tolerances require final official recomputation. Evaluate each candidate alpha efficiently by row-package:

    AMI = max_rows( a alpha^2 + b alpha + c )

The alpha at minimum candidate list becomes tentative line minimizer. It should be verified by exact row_vec/h and official_score. The returned line candidate objective is always official_score, not V_alpha.

Important: If the row coefficient formula mismatch may only degrade for discovering promising alpha because official score always accepts/refuses. Orientation/order cannot affect the maximum and final bound.

1. Approach and rationale

1.1 Central idea  
The exact objective is an upper envelope of only `2n-1` linear correlation row functions. For any feasible ray preserving the mass constraint exactly and never violating the `[0,1]` box as long as the ray parameter is inside a finite interval, each row function becomes exactly a quadratic polynomial in the ray parameter. The upper envelope of one-dimensional quadratics has a global minimizer on a closed interval, and that minimizer is attainable from a finite candidate list: endpoints, coordinate vertices, and all pairwise intersection roots of row quadratics inside the interval.

The algorithm therefore alternates between:
- a current feasible vector,
- a small portfolio of selected feasible zero-sum directions,
- exact one-dimensional quadratic-envelope global minimization along each chosen direction,
- strict acceptance only when the original official NumPy objective improves after exact feasibility repair.

The line local minimization is the key primitive, not a smoothed maximum or a full-dimensional constrained NLP.

1.2 What makes this materially different from the earlier plan  
- It does **not** use a smoothed exponential/log-sum-exp maximum as the main descent objective.
- It does **not** formulate a full-dimensional `theta + h` constrained minimax NLP solved by SLSQP or CVXPY.
- It does **not** rely on surrogate projected local solvers.
- The central accepted move is the exact global minimum of the true envelope along a bounded feasible line, found by enumerating a finite certificate of envelope minima.
- Exact feasibility is obtained primarily by choosing directions satisfying `sum(d) = 0`, not after the fact by clipping plus rescaling. Joint projection is retained as a repair/fallback only.
- Candidate progress is real progress under the original evaluator; the quadratic-envelope line optimization is used for candidate generation, not for final authority.

1.3 Why this can move the parent closer to the target  
The supplied parent is already close to a local upper-bound plateau. Large changes often increase the maximum, but small changes can lower the maximum only along very particular active-lag directions. Achieving such changes is often a question of locating a point where one correlation row stops being dominant and becomes tightly constrained by another row. Exact one-dimensional quadratic envelope minimization is designed to find exactly those switching and vertex points.

This method is local and nonconvex. It can find a better feasible construction, but it does not establish global optimality. The only returned bound is the value obtained after exact `np.correlate` evaluation.
