     The problem is a feasible, deterministic, nonconvex optimization over sample values `h[i] ∈ [0,1]` with exact integral sum `sum(h)=n_points/2`. There is no valid way to cancel boundary terms and reduce the task to a simple mean/circulant formula.

     The plan is to keep the exact objective vector in memory for every current sample sequence and perform randomized two-coordinate feasible moves. A full re-evaluation is used periodically for re-sync, and after any global block operation. The exact objective vector is updated using a derived formula for moving a positive amount between two indices, which costs `O(n)` rather than `O(n^2)`. The optimization stages are:

     - validate the provided parent construction if present, repair it numerically without changing dimensions when needed, and save it as the baseline;
     - generate related parents by rounding/partial deterministic normalization, by transferring to a small set of neighboring sample counts;
     - optimize those samples using simulated annealing implemented with exact paired moves; high-efficiency 0/1 swaps where possible and general fractional transfers for odd or nonbinary states;
     - retain only improvements on the evaluator-consistent score;
     - perform a brief continuous coordinate polish using the exact two-index update formula;
     - periodic complete re-correlation to remove drift from long vector updates;
     - final repair/projection of a candidate only if it is known valid from prefix saves, and return the best evaluated state.

     This method does not claim global optimality or convexity. It is a robust metaoptimizer and is designed to improve or at least preserve a supplied construction quickly, preserve feasibility exactly in accepted states, and evaluate final results with the authoritative task metric. The main computational gain is from exact incremental objective updates. The main robustness requirement is to never return an invalid projection-derived candidate for which the feasible score has not been confirmed from the same precise vector held during the search unless its final objective is re-evaluated and still fits the previous best (or the parent fallback). This allowed freedom while expressing a nonseeking simulation-centered method between large functional families.

     `F = np.correlate(h, G, mode="full")`, length `2n - 1`

     Accepted constraints at all times for a returned vector: finite; all `interval` `0 <= h[i] <= 1`; and `abs(sum(h) - n/2) <= 1e-9` or a comparably tight tolerance in W units. Direct internal accepted moves preserve sum and bounds analytically. A final micro repair should only produce candidates evaluated on the original objective; any projection means relation nor fails exact feasibility, and it is retained only for safe copy of prior valid basis.

     2.2 Exact two-coordinate move

     At a state `h`, with cached objective vector `F`, propose changing two distinct indices `p` and `q`:

     - `h[p]` will increase by `a > 0`, named `inc`
