The key new idea: **pair coordinate descent**. For each pair (i, j), find the optimal values of h[i] and h[j] given all other coordinates fixed. This is a 2-variable optimization that can be done exactly.

For a fixed pair (i,j) with all other h fixed, the objective is:
max_p [F_p(h) where h_i and h_j are variables]

Each F_p is linear in (h_i, h_j) (since F_p = sum_k h_k(1-h_{k+off}), and only terms involving index i or j depend on h_i or h_j).

Specifically, F_p = (terms not involving i or j) + c_i(p)*h_i + c_j(p)*h_j - (term with both i and j if they interact)

Wait, F_p = sum_k h_k * (1 - h_{k+off}). The terms involving h_i are:
- k=i: h_i * (1 - h_{i+off}) [if i+off is valid]
- k such that k+off = i, i.e., k = i-off: h_{i-off} * (1 - h_i) [if i-off is valid]

Similarly for h_j. And if j = i+off or j = i-off, there's a cross term.

So F_p is at most linear in each of h_i and h_j individually, and bilinear if they interact.

The constraint is: h_i + h_j = (original h_i + h_j), and 0 ≤ h_i, h_j ≤ 1.

So for each pair, we're minimizing the maximum of a set of linear (or bilinear) functions of (h_i, h_j) subject to a line constraint. This is a 1D problem (since h_i + h_j is fixed)!

Let t = h_i, then h_j = S - t where S = h_i + h_j.
The feasible range for t is [max(0, S-1), min(1, S)].

Each F_p becomes a function of t only (at most quadratic if i and j interact at that lag).
We want to minimize max_p f_p(t) over t in [t_min, t_max].

This is a 1D minimax problem! We can solve it by:
- Evaluating f_p(t) on a fine grid
- Or using bisection: find the smallest C such that f_p(t) ≤ C for all p, for some t in the feasible range.

The bisection approach: for a candidate C, check if there exists t such that f_p(t) ≤ C for all p. Each f_p(t) is at most quadratic, so f_p(t) ≤ C is a constraint that defines an interval (or union of intervals) for t. The intersection of all these intervals gives the feasible set for t at level C.

This is efficient! And it's exact (no approximation).
