1. Approach and rationale

The supplied parent is an already-polished continuous vector. The previous program mostly operates in a local continuous neighborhood with log-sum-exp smoothing, accelerated subgradient steps, and dense minimax solvers. That is a reasonable localizer, but it can get trapped in a plateau basin where the maximum lag changes only slightly, and it does not explore the combinatorial boundary structure of the problem.

This proposed approach makes a materially different first move: it searches an exactly balanced binary/integer subspace over finite dimensions where the objective is a counts-of-directed-pairs problem. For even n, a vector with only 0/1 entries and exactly n/2 ones is feasible with the exact required integral. Such discrete vectors are highly structured starting points for the continuous problem: they often sit near active maxima and impose hard pairwise correlation constraints. Instead of using them only as a random perturbation, the algorithm performs a dedicated discrete global-type search with simulated annealing, deterministic balanced sequences, and pairwise swaps preserving the cardinality exactly. The best binary/catadromous candidates are then either kept directly (for even n) or relaxed, interpolated, and polished by exact constrained active-set minimax solvers.

The other major difference is the local polish method. Instead of dense all-lag min-max feasibility or a broad smooth surrogate, the polish stage optimizes the exact minimax problem restricted to the currently active or near-active lags. This is a local nonlinear program where the decision vector is h and a scalar t, with exact sum h = n/2, 0 <= h <= 1, and only a small subset of constraints t - C_q(h) >= 0. It exploits the sparsity of the maximization constraints and avoids carrying dozens of inactive constraints into every solver iteration. If ignored constraints become active, the solver is re-solved with the refreshed active set, while all accepted steps are judged only by the exact evaluator.

This plan is not a global optimality algorithm. Its intended value is that:
- binary balanced search can leave continuous basins that smooth gradient methods cannot reach;
- active-set exact-polish can exploit the active constraint geometry more accurately than pure smoothing and averaging;
- all candidates are returned only after exact evaluation and joint feasibility repair, so the reported value is always a valid upper bound.

A conservative correct fallback is always available from initial_h_values. If the initial supplied vector fails sanity checks, a deterministic balanced continuous vector is generated by algorithmic rules; after final feasibility projection it is used as the last fallback.

2. Mathematical specification

2.1 Representation, feasibility, and exact objective

Let n be positive, dx = 2/n, and T = n/2. For a vector h in R^n, the discrete measure represented by midpoint samples h_i has integral h_i dx summed over [0, 2], so exact total integral 1 is equivalent to sum_i h_i = T.

The authoritative objective is

    U(h) = max_k [ dx * (np.correlate(h, 1.0 - h, mode='full'))[k] ].

It is the maximum over all 2n - 1 linear-correlation lags, including both finite-support directions. Internally auxiliary smooth solvers may use a manually constructed correlation vector, but any accepted candidate must be re-scored with the original evaluator and must satisfy bounds exactly.

2.2 Exact feasible projection

Projection must preserve both 0 <= h_i <= 1 and sum_i h_i = T exactly through a monotone one-dimensional parameter, not by clip-then-rescale. Given a real vector z of length n, solve for alpha in

    phi(alpha) = sum_{i=0}^{n-1} clip(z_i + alpha, 0, 1) - T

1. Initialize L = -2 - max(z) and U = 2 - min(z).
2. For 80 bisection iterations:

3. Set h = clip(z + 0.5 * (L + U), 0, 1).
4. Compute residual r = T - sum(h).
5. If |r| > 1e-14, repair along coordinates that can move in the required direction and are not already saturated. For r > 0 increase unsaturated coordinates. If coordinates all saturated forward is impossible, else some remain feasible by construction. The greedy repair chooses indices in deterministic order. A simple deterministic order is decreasing available headroom 1 - h_i for r > 0; for r < 0 choose decreasing excess h_i. Loop:
   amount = min(|r|, relevant residual capacity at index);

6. If residual remains above 1e-13 because of floating rounding, explicitly set one feasible index to satisfy h_i = T - sum_{j!=i} h_j, clipped to its bounds. The existence of capacity guarantees this is possible.

Return type: exact vector shape (n,). Float rounding errors can be kept at machine-precision scale; the returned final vector passes validation with an absolute tolerance of 1e-10.
