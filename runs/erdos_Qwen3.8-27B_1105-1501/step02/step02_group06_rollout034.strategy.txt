1. Approach and rationale

1.1 Central idea

The supplied parent construction is strong but appears to be trapped in a shallow local minimax region: the score is only slightly above the target, and conventional smooth-max or regularized QP steps move almost parallel to the current active-lag constraints. The new primary algorithm is a trust-region sequential linear minimax method applied to the exact discrete correlation objective. The essential changes are:

1. Work directly with the exact linear-correlation raw lag variables that match np.correlate(h, 1-h, mode="full"), not with circular autocorrelation, global autocorrelation, Fourier surrogates, or a black-box smoothed objective.
2. At each iterate, linearize a relevant set of raw lag constraints in the decision vector h, add an auxiliary minimax variable tau, preserve the exact box and integral constraints, and use a small trust region around the current feasible point. This gives a linear subproblem whose only role is to propose a tangent feasible direction.
3. The proposed vector is always projected back to exact feasibility and re-evaluated with the authoritative discrete score. No proposed score is accepted unless the original evaluator agrees and the candidate satisfies the constraints.
4. If the linear model stalls, the algorithm uses exact 1D line searches along structured tangent directions range of directions: active-gradient differences, coordinate-pair mass moves, Fourier-like smooth modes, and the anti-symmetric complement direction. Because the exact 1D objective is a maximum of quadratic or rational functions along a fixed linear ray, dense sampling plus local refinement can find small nonconvex descents that first-order linear linearization misses.
5. Multiple resolutions are tried by exactly transferring the best construction to nearby even grid sizes, repairing feasibility, and optimizing locally. This may reveal a construction with comparable or better step-function bound at a useful grid size without abusing the scorer.

The method differs from the previous approach by replacing the main search mechanism with exact tangent linear minimax LP proposals plus nonconvex line-search escape along structured directions. The previous method used regularized quadratic active-set steps and log-sum-exp smoothing. Here, the convex subproblem is a linear programming minimax proposal, and all global/nonconvex progress is driven by exact line exploration and exact revalidation.

1.2 Bottleneck addressed

At a near optimum, many lag functions are active or nearly active. A restricted top-active QP or smooth objective tends to keep moving on the same piecewise-linear or smooth envelope. A small improvement may require:

- moving near a saddle/first-order stationary point where no small linearized decrease exists for all lags, but a finite step changes which lags are active, lowering the envelope;
- exploiting curvature along a direction where multiple portions of the active envelope curve downward collectively;
- moving mass along a direction that comes from an inactive but sensitive gradient or an anti-symmetric arrangement mismatch;
- shifting grid resolution so that a parent continuous recipe can be represented with smaller discretization error.

The LP gives global feasible tangent pocket search inside the trust region. The line-search escape addresses non-smooth/curvature effects and active-set changes. The resolution framework exposes possible gains by changing discrete representation. The final answer always has the original discrete upper bound, not an assumed convex optimum.

1.3 Guarantees and limitations

Justified facts:

- The accepted upper bound is the exact score of the returned vector, with a small reported slack to cover numerical corrections. The returned vector is feasible according to the returned box and sum constraints.
- The objective exact formula and gradient formulas are aligned with np.correlate linear correlation and include both positive and negative shifts.
- The LP subproblem is a valid linear program in variables (h, tau) and is solved only to generate a candidate. It is not claimed to solve the original nonconvex problem.

Heuristics or hypotheses:

- The complete algorithm is not globally optimal for the discrete nonconvex problem.
- The line-search directions, resolution sweep, acceptance rules, and random perturbations are heuristic; they may improve some corners but may not always.
- The returned c5_bound is an upper bound on C5 because a concrete feasible construction is returned, not because the algorithm proves no lower construction exists.

2. Mathematical specification

2.1 Discrete representation and authoritative objective

Let the returned array be h with length n. Use even n only. Let dx = 2.0 / n and target_sum = n / 2. Constraints:

- 0 <= h_i <= 1 for all i.
- sum_i h_i = target_sum.

The authoritative score is:

C(h) = max_{p=0}^{2n-2} R_p(h) * dx,

where R_p is the raw np.correlate(h, 1-h, mode="full") entry p. This is ordinary finite-support linear correlation; it is not circular. Overlap windows at nonzero shift have length n - |shift| and partial sums must be retained.

For consistency with np.correlate, define the shift:

s(p) = n - 1 - p.

Then p=0 corresponds to s=n-1, p=1 corresponds to s=n-2, ..., p=n-1 to s=0, ..., p=2n-2 to s=-(n-1). For each p:

R_p(h) = sum over i such that 0 <= i < n and 0 <= i + s(p) < n of h_i * (1 - h_{i+s}).

The vector 1-h gives the complement, and both positive and negative gradients are included because s ranges over both signs.

The objective in the LP proposals is the unnormalized raw maximization tau over R_p. To compare candidates, multiply max raw by dx or use official_score directly. Do not normalize inside gradientsffret; raw scaling is done once by dx in scoring.

2.2 Exact lag gradients

For a chosen lag p with shift s = n-1-p, the raw derivative g_p satisfies:

g_p dot d is the first-order change of R_p at h in direction d.

For each valid pair (i,j)=(i,i+s), the term is h_i(1-h_j). The contribution to g_i is 1 - h_j, and the contribution to g_j is -h_i. Reusing a variable on both sides works for s=0 and gives 1 - 2h_i.

A vectorized implementation rule:

- For s >= 0:
  - Let m = n - s valid pairs. Source indices are 0..m-1 and target indices are s..n-1.
  - g[0:m] += 1 - h[s:n]
  - g[s:n] -= h[0:m]

- For s < 0:
  - Let a = -s so shift is -a. Valid source indices are a..n-1 and target indices are 0..n-a-1.
  - g[a:n] += 1 - h[0:n-a]
  - g[0:n-a] -= h[a:n]

For s=0, m=n; the two update statements on the same indices apply and produce g_i = 1 - 2h_i.

The exact score values are always computed by np.correlate for validation. Implement a small optional exact double-loop scorer over p and valid pairs for a length-4 or length-5 sanity construction to confirm that the gradient update slices correspond to coefficient signs and p ordering. This check should only test gradient consistency for a finite difference and not replace official scoring.

1. Approach and rationale

1.1 Central idea

The supplied parent construction is close to the requested target, but it is sit on or inside a narrow continuous discretization local plateau. The proposed method is materially different from the previous solver scheme: the main engine first generates candidate steps through a trust-region sequential linear minimax method. The exact objective from `np.correlate(h, 1.0 - h, mode="full") * (2.0 / n)` is expanded into raw lag functions in the same order used by the evaluator, and a selected subset of these lag functions is linearized at the current feasible point. A minimax variable is added to form a linear program whose proposal minimizes the tangent envelope while preserving the box and exact-sum constraints within a trust neighborhood. Because the underlying problem is nonconvex, this LP is used only as a search generator; if it becomes first-order blocked, exact 1D line searches on structured tangent rays seek finite-step descents through nonsmooth activity changes and curvature effects. Feasibilities of all proposals are rebuilt with a joint exact-sum/box repair, and acceptance always uses the authoritative evaluator. Multiple grid resolutions are explored with exact transfer and repair so that a parent construction can be sharpened on a better grid if one is available.

1.2 Why this may improve the supplied parent

A regularized active-set QP or smooth max often stalls when the active envelope is locally balanced: the allowed directions have approximately zero first-order effect on the active lags, and small changes leave the active set fixed. The proposed method attacks that directly.

- A linear envelope LP minimizes the only objective and is allowed to trade off one active lag gradient against another, which gives linear pocket directions that may not lie in the QP regularization cone.
- Finite-step exact line searches along tangent directions address the reality that the max of lag functions is nonsmooth, quadratic in a fixed ray, and active-set changes occur at breakpoint alpha values. A sampled lambda grid plus local refinement can discover movement past a local kink that a purely first-order linearized or smoothed method misses.
- Feasibly anti-symmetric transfer interpolates between `h` and `1.0 - reversed(h)`, which is a geometric transformation that sometimes gives independent structure not found by scaling individual coordinates.
- Resolution step refinement uses even-distance interpolation at cell centers, then exact repair, so it can shrink discrete representation error while retaining the supplied parent as the fallback bound.

1.3 Bottleneck addressed

The supplied parent is approximately 0.380984, and the goal is 0.3808. That gap is extremely small and likely requires changing marginal constraints, not lowering one currently obvious maximum. This plan targets all marginal/near-active envelopes, not just one smoothed aggregate. It preserves finite-support boundary terms: nonzero lags contain only n plus or minus shift overlapping terms, never a full integral. All calculation definitions include both positive and negative shifts explicitly; periodic or full autocorrelation substitutes are not used.

1.4 Limitations and status

- The original problem contains symbolic constraint formulas for UFE variable-dependent f_A=raw lag functions are quadratic; the bilinear problem is not convex. The LP template is only a nonconvex stochastic tangent LP.
- Convexity only exists in generated submodels used to propose movement; no global optimum is claimed.
- Every improvement is acknowledged only after exact original evaluator equality and exact feasibility repair.
- If local, ramps, resolution and smoothing never improve the parent, the parent is returned as the valid upper bound.
- The method is a practical optimizer at finite declared values. Resolution transfer may discover only an upper bound of another finite discretization when appropriate; output feasibility and score are certified for returned sample individuals. In a retained context, deliverability yields a self-proved feasible h with computed exact score, relative to its stringent statement returning smaller best n on exact ties.

1. Approach and rationale

1.1 Central idea

The algorithm will pursue the improvement directly on the evaluator’s exact discrete objective, not by treating the problem as periodic autocorrelation or by replacing the maximum overlap with a smoothed aggregate. At each feasible iterate it performs three distinct operations:

1. exact trust-region linear minimax proposal: select a set of active/near-active raw lag functions, linearize them at the current h, and solve a linear program in (h, tau). This gives a feasible tangent pocket in the trust region.
2. Exact candidate repair and evaluator revalidation: the proposed LP point is projected to satisfy 0 <= h[i] <= 1 and sum(h[i]) = n/2 simultaneously, then rejected or accepted with max(np.correlate(h, 1-h, mode="full")) * (2.0/n).
3. structured non-smooth line-search escape: when the linear model is first-order blocked, the algorithm probes a collection of tangent rays using dense one-dimensional sampling, local refinement, and full evaluator updates. Rays include active-gradient differences, coordinate pair exchanges, smooth periodic modes, and the anti-symmetric complement ray. These rays can cross active-set boundaries and exploit curvature of the max of many finite-support correlations.

This differs substantively from the previous regularized QP and log-sum-exp smoothing method. The primary continuous optimizer is a trust-region sequential linear minimax process, not SLSQP with smoothing, and the emphasis is on exact discrete lag gradients, exact line searches, and feasibility-preserving moves. Generating more candidate h vectors is secondary to enabling finite, feasible moves that change marginal active-lag constraints slightly while preserving the full discrete overlap.

1.2 Bottleneck addressed

The supplied parent construction is near 0.380984 and target 0.3808. This plan addresses that by explicitly computing each raw correlation derivative and asking the linear model for a tangent improvement of the whole max envelope under the exact sum constraint. If no first-order pocket exists, it randomly tests finite movements that may lower all near-maximal branch functions while raising ones that would otherwise become active afterward.
