1. Approach and rationale

1.1 Central idea

The proposed method is a resolution-adaptive, active-set regularized minimax search followed by exact global pooling. The central change relative to the previously supplied program is not a simple parameter tweak: the main local workhorse becomes a *regularized active-set nonlinear minimax solver* that is repeatedly re-anchored to active constraints by both the smooth log-sum-exp surrogate and the exact supplied evaluator. Pure log-sum-exp soft-max optimization tends to blur the geometry of the true maximum; full simultaneous maximization over all lags is expensive and suffers flat directions. The proposed method instead:

1. Starts a diverse family of feasible candidates over multiple resolutions, including the supplied parent, interpolated/processed variants, deterministic low-discrepancy balanced sequences, and regularized smooth perturbations.
2. Smoothly polishes candidates with log-sum-exp objectives only to move them toward the neighborhood of the active maximum, not as the final acceptance objective.
3. Repeatedly solves the exact minimax constraint problem only for currently active or near-active lags, with a small regularization/anchor term to avoid producing arbitrary feasible iterates with slightly lower smooth objective but acceptable true objective.
4. Always scores every candidate accepted for the pool or final answer with the authoritative full evaluator, preserving all send lags and the exact finite-overlap semantics.
5. Uses exact feasibility projection throughout, so every vector entering or leaving a solver is already in the feasible set unless acceptance later promotes it after exact projection and exact scoring.

This addresses the observed bottleneck: the supplied construction is already near a local minimum, and the remaining tiny improvement (from approximately 0.380954 toward 0.3808) likely lies in a carefully chosen lower-resolution discretization or in better handling of the few active lag constraints. The method is not a global optimizer and does not claim optimality, but it adds two practical mechanisms that are mathematically targeted for nonconvex finite max overlap problems: active-state local nonconvex programming with exact check, and exact resolution shifts that can realize functions not representable at the parent resolution.

1.2 Important assumptions and limitations

- The problem is globally nonconvex. The solvers are local or semilocal. Multiple starts and multidimensional restarts are therefore required, but they do not prove global optimality.
- “Smaller sequences are preferred” is interpreted only as a tie/barbarism score rule: never prefer a smaller dimension if it has worse exact C. Prefer smaller n only when C is equal within a tiny numerical tolerance, otherwise prefer lower C even with slight bigger n.
- A constrained direct minimax solution with only a subset of lags can have another lag not included become the new maximum after projection or solver termination. Hence direct solver output is never accepted based on its internal scalar t; it is always projected and rescored using the authoritative `np.correlate` objective.
- Log-sum-exp smooth objectives are surrogate relaxation mechanisms, not proofs of completion or global lower bounds. They can be unsafe if unweighted; candidate screening always uses the exact score.

2. Mathematical specification

2.1 Feasible vector and exact objective

For a candidate vector h of length n:

0 ≤ h[i] ≤ 1, and sum_i h[i] = n/2.

Let

dx = 2.0 / n.

The authoritative implementation risk-free evaluation is always computed by exactly the supplied rule:

score_exact(h) = max(np.correlate(h, 1.0 - h, mode="full")) * dx.

This includes all 2n − 1 lags and the exact boundary handling of a finite window. Do not replace this objective with any circular correlation, Fourier autocorrelation, or normalized complementary form.

2.2 Internal shifted finite-overlap terms for locals

For gradient, constraint, and smoothing stages it is helpful to compute terms indexed by a chosen internal shift convention. The exact numerical vector over terms is the same set whether the terminal order of np.correlate is reversed or shifted; final acceptance is always with `score_exact`.

For integer s from −(n−1) to n−1, define the real overlap length L_s = n − |s|. The shifted term is

F_s(h) = dx * Σ valid h[i] * (1 - h[i+s]),

where “valid” means 0 ≤ i < n and 0 ≤ i+s < n.

Implementation forms:

- If s ≥ 0: pair indices are i = 0,...,n−s−1, and the terms are h[0:n-s] * (1 - h[s:n]).
- If s < 0, let r = -s: pair indices are i = r,...,n−1, and the terms are h[r:n] * (1 - h[0:n-r]).
- For s = 0 the central term is F_0(h)=dx * Σ h[i]*(1-h[i]), equivalently dx * (n/2 - Σ h[i]^2). With exact sum constraint, minimizing the maximum also includes this central term.

Let F(h) be the full array of these F_s values. Use it only to form smooth proxies and local inequality constraints. After any candidate move, compute the actual accepted score with the official `score_exact(h)`.

2.3 Exact feasible projection

Clipping then normalizing can double dangerously violate sum or [0,1] constraints. Use a bisection-plus-repair projection returning exact feasible vector.

Input an arbitrary floating vector z with finite entries. Define P(z) = ∑ clip(z + a, 0, 1). P is nondecreasing in a.

1. Start with lo = −max(z) − 2, hi = −min(z) + 2 so the target integral q=n/2 lies between P(lo)=0 and P(hi)=n (or at least between two monotone bracketing values robustly bounded from zero to n).
2. Perform 70 bisection iterations, selecting m=(lo+hi)/2. If P(m) < q, set lo=m, else hi=m.
3. Take a = (lo+hi)/2 and v = clip(z+a, 0, 1).
4. Compute residual r = q - sum(v). If |r| ≤ 1e-12 accept.
5. If r > 0: fill capacity using all indices with `v[i] < 1`, preferably in deterministic index order; add min(r, 1-v[i]) to one by until r near machine precision. If r < 0: drain capacity using indices with `v[i] > 0`, subtract min(-r,v[i]) until residual zero.
6. Finally clip `[0,1]`; if residual still exceeds 1e-9, discard candidate or replace with known feasible fallback. This cannot fail for finite z after exact repair unless arithmetic is invalid.

F_s(h) = dx * sum_i h_i(1-h_i+s) within finite overlap window.
