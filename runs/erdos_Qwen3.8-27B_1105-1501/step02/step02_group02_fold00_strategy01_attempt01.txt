1. Approach and rationale

1.1 Central idea

The supplied parent is a continuous vector of length 57 with bound about 0.380954. A materially different search method is to convert the problem temporarily into an exact integer discrepancy problem on balanced binary strings of even length. For a binary vector x ∈ {0,1}^n with sum exactly n/2, the overlap objective multiplied by n/2 is an integer, and the full evaluator becomes

    C(x) = (2/n) max_{q=0}^{2n-2} F_q(x),
    F_q(x) = sum_{(i,j) in P_q} x_i(1 - x_j),

where P_q are the finite-support correlation pairs. This eliminates scaling and floating-point polishing noise and converts the task into looking for a balanced binary string whose all finite-support discord counts are small.

The primary algorithm is an exact incremental combinatorial search:

- represent a balanced binary string by current integer lag counts F_q;
- maintain per-variable pair incidence lists for first-coordinate and second-coordinate contributions;
- evaluate every candidate one-one ↔ one-zero swap in exact O(n) time;
- use partial optimal greedy descent, then iterated local search with exact local moves;
- generate many starting strings from the parent by exact balanced rounding, reflections, and algorithmic quasi-Sturmian or modular seeds;
- search several even lengths near the parent;
- retain the parent as a valid continuous fallback and optionally attempt a very short exact direct min-max polish at the end if integer/continuous improvement is still needed.

This is different from a smooth LSE/FISTA/SLSQP global pipeline because the dominant search space is the integer hypercube and exact incremental swap evaluation. It exploits the fact that a binary solution with an integer maximum 1 lower than an upper integer level can improve the final bound by roughly 2/n, which for n around 58–64 is about 0.030–0.034. Even if the final target requires only 0.0001 improvement, finding a good binary string and rounding it carefully can often move to a stronger basin.

1.2 Why it addresses the bottleneck

The previous record is close to a local continuous optimum. An incremental integer local search can move through equilibria that are not reachable by tiny smooth gradients because it makes exact combinatorial changes that are implicitly accepted during a round of greedy descent. It also naturally respects the feasibility constraint sum h = n/2 by exchanging one 1 with one 0. Exact updates make the search fast on small-length sequences, which are preferred by the evaluator.

This method does not claim a global optimum. It is a stochastic global-and-local combinatorial search combined with exact evaluation. If the integer search does not reach the target, it still provides strong starting points for continuous polishing and can be abandoned whenever time remains tight.

1.3 Facts versus hypotheses

Facts used by the design:
- For binary x with sum n/2 and n even, the feasibility sum is automatic and exact in float form as 0.0 and 1.0.
- The evaluator objective over binary x is a multiple of 2/n.
- A swap can be evaluated exactly using only contributions containing the swapped indices.
- The finite-support correlation includes both lag directions and boundary-truncated overlaps; no identity replacing it by a convolution or cyclic autocorrelation is valid unless specifically derived and equality-checked.

Heuristic hypotheses explored by the optional and sequence choices:
- Balanced length intervals around the parent are likely better because known good constructions are correlated with this scale;
- modular or Sturmian seeds can provide balanced strings with locally lower correlations;
- integer search followed by a very short continuous direct min-max solve can recover a slightly lower fractional bound if a strictly integer solution is too coarse.
None of these hypotheses may be presented as proven.

2. Mathematical specification

2.1 Representation and exact feasible set

For an integer n, dx = 2/n, target sum T = n/2.

The feasible set is:
    0 <= h[i] <= 1 for all i,
    sum_i h[i] = T exactly.

For binary candidates, n must be even. Let K = n//2. A binary candidate satisfies sum = K exactly and T=K.

Continuous candidates are generated only as final polish or fallback. The final vector returned may be binary or continuous; in all cases it must be checked using exact feasibility repair and evaluator scoring.

2.2 Exact discrete objective

Define zero-indexed length n and lag variable s ∈ {-(n-1), ..., n-1}. Use the standard theorem for the numpy full correlation c = correlate(a,b,'full'), where b = 1 - a:

    q = n - 1 + s,
    c[q] = sum_{i valid} a[i] * b[i - s],

where valid means 0 <= i < n and 0 <= i - s < n.

For binary x with b_j = 1 - x_j, write:

    raw[q] = sum_{i valid} x_i * (1 - x_{i - s}).

This is the integer overlap count underlying C.

Equivalent pair representation:

- If s >= 0, valid i = s, s+1, ..., n-1 and pair is (i, i-s).
- If s < 0, valid i = 0, 1, ..., n+s-1 and pair is (i, i-s).

The final bound is:

    C_assignment = dx * max(raw).

This maximum includes lag s=0 and both positive and negative lags. At s=0 for binary x, raw is 0 because x_i(1-x_i)=0. Boundary terms are automatic in the list lengths n-|s| and must be preserved.

If a pair-list objective is implemented, it must be validated against the actual evaluator for several deterministic integer vectors of the current n; this catches directional definitions. Final returned candidates are judged by actual `np.correlate(h,1-h,'full') * dx`, not the internal update.

2.3 One-one to one-zero swap and exact delta

Let x be balanced. Let a be a coordinate with x[a]=1 and b with x[b]=0. The candidate x' has x'[a]=0 and x'[b]=1, all other coordinates unchanged. The current exact raw vector is F.

Build the incidence lists for every coordinate p by scanning all s and valid pairs:

1. `first_pairs[p]` contains triples `(q, p, j)` for each term "p is first" with second coordinate j = p - s.
2. `second_pairs[p]` contains triples `(q, i, p)` for each term "p is second" with first coordinate i.

The exact new raw vector for swap (a,b) is obtained from a copy of F. Let translate:
- a_old=1, b_old=0,
- a_new=0, b_new=1,
- all other x values are the current values.

To avoid double counting, process role contributions with corrections for two possible duplicated pair terms:

For every pair where a is first, `(q,a,j)`:
- old term = 1 - x[j] because x[a] is 1 before swap.
- new term = 0 because x[a] becomes 0.
- delta is -(1 - x[j]).
- If j == b, the pair (a,b) is also present in the second-list for b. This is double counted most of the total pair effect. Add +1 once at q to correct the overlap.

For every pair where a is second, `(q,i,a)`:
- old term is x[i]*(1 - x[a]) = 0.
- new term is x'[i]*(1 - x'[a]) = x'[i].
- delta is + x'[i], with x'[i] = 1 if i == b, else x[i].

For every pair where b is first, `(q,b,j)`:
- old term = 0 because x[b]=0 before swap.
- new term = 1 - x'[j], with x'[j] = 0 if j == a, else x[j].
- delta is +(1 - x'[j]).
- If j == a, the pair (b,a) is also present in the second-list for a, so add -1 once at q to correct double counting.

For every pair where b is second, `(q,i,b)`:
- old term = x[i]*(1 - 0) = x[i].
- new term = 0 because x[b] becomes 1.
- delta is -x[i].

This formula gives the exact modified raw vector F' for the only swapped pair. The objective energy used during integer search is

    E(F) = max_q F[q]

and a secondary tie-breaking statistic can be

    S(F) = sum_q F[q].

A candidate is preferred by tuple `(E, S, current string seed)` in lexicographic minimization after full raw evaluation; however for acceptance use either E alone for greedy strict improvements or an acceptance rule described below. At every accept step, x, integer ones list, zeros list, and F are all updated consistently; do not preserve inconsistencies from attempted moves.

2.4 Continuous final score and fallback projection

Let `score_exact(h)` be the actual evaluator:
    n = len(h)
    dx = 2/n
    corr = np.correlate(h, 1-h, mode='full')*dx
    return max(corr).

Feasibility projection is necessary for continuous candidates. Define a clipped-shift projection based on target T=n/2:

Function `project(z)`:
1. Clean z: replace NaN with 0.5, +inf with 1.0, -inf with 0.0.
2. Find alpha such that g(alpha) = sum_i clip(z_i + alpha,0,1) equals T.
3. g is continuous nondecreasing. Bracket alpha on:
       lower = -2 - max(z)
       upper =  2 - min(z)
   Use 70 bisection iterations.
4. Set h = clip(z + candidate_alpha, 0, 1).
5. Let r = T - sum(h).
   If r > 0, add mass to non-saturated entries using an order; if r < 0, remove mass from entries above zero using an order. Complete the finite greedy correction until residual is zero or at most 1e-12 in value. If residual cannot be removed due non-finite or full bounds, fall back to the last known feasible best.
6. Re-check all bounds and sum exactly before returning.

Before returning continuous polish, evaluate `score_exact` after projection. Accept only if the score exactly improves by at least 1e-12, and keep it as best only if both feasibility and finite score hold.
