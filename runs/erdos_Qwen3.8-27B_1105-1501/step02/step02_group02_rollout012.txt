Now, for the coordinate descent, I need a more efficient way to compute the gradient at a specific coordinate. Instead of computing the full gradient for each lag, I can directly compute the contribution of h[p] to each lag's correlation.

For coordinate p and lag s:
- The derivative of corr_s w.r.t. h[p] is:
  - If s >= 0:
    - If s <= p <= n-1: +(1-h[p-s]) [p is the first factor]
    - If 0 <= p <= n-1-s (i.e., p+s <= n-1): -h[p+s] [p is the second factor]
  - If s < 0 (m = -s):
    - If 0 <= p <= n-1-m: +(1-h[p+m]) [p is the first factor]
    - If m <= p <= n-1: -h[p-m] [p is the second factor]

So for a given p, I can compute the derivative for each lag s in O(1) (just checking a few conditions).

For the coordinate descent step at coordinate p:
1. Identify all lags s where h[p] appears (derivative is non-zero)
2. For each such lag, compute corr_s and deriv_s
3. Find v that minimizes max_s (corr_s + deriv_s * (v - h[p])) * dx

Step 3 is a 1D convex optimization. The function f(v) = max_s (a_s + b_s * v) where a_s = corr_s * dx - deriv_s * dx * h[p] and b_s = deriv_s * dx.

The minimum of f(v) over v in [0,1] occurs at:
- v = 0
- v = 1
- Or at a breakpoint where two lines a_i + b_i * v = a_j + b_j * v

The breakpoints are at v = (a_i - a_j) / (b_j - b_i) for pairs with b_i != b_j.

I'll evaluate f at all breakpoints in [0,1] and at 0 and 1, and take the minimum.

For n=60, the number of lags where h[p] appears is at most about n (for p in the middle). But I only need the top-m lags (those closest to the max). So the number of breakpoints is O(m^2) which is small.

def _fista(h0, beta, n_iter, alpha=0.005, mu=0.85):
    n = len(h0)
    h_cur = h0.copy()
    y = h0.copy()
    h_avg = h0.copy()
    best_h = h0.copy()
    best_s = _score(h0)
    t = 1.0
    
    for it in range(n_iter):
        grad = _lse_grad(y, beta)
        # Compute step
        h_new = y - alpha * grad
        h_new = _project(h_new)
        # Nesterov extrapolation
        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t * t))
        y = h_new + ((t - 1.0) / t_new) * (h_new - h_cur)
        y = _project(y)
        # Averaging
        h_avg += (h_new - h_avg) / t_new
        t = t_new
        
        # Track best
        s_cur = _score(h_new)
        if s_cur < best_s:
            best_s = s_cur
            best_h = h_new.copy()
        
        if it % 500 == 0 and it > 0:
            ha = _project(h_avg)
            sa = _score(ha)
            if sa < best_s:
                best_s = sa
                best_h = ha.copy()

    s_cur = _score(h_new)
    if s_cur < best_s:

        best_h = h_new.copy()
    ha = _project(h_avg)
    sa = _score(ha)
    if sa < best_s:
        best_s = sa
        best_h = ha.copy()

        if p >= m:
            d += (-h[p - m])
    return d

def _coord_descent(h0, n_sweeps=20, m_active=15):
    h = h0.copy()
    n = len(h)
    dx = 2.0 / n
    for sweep in range(n_sweeps):
        cv = _corr_vec(h)
        top_k = np.argsort(cv)[::-1][:m_active]
        improved = False
        for p in range(n):
            vals = []
            slopes = []
            for k in top_k:
                s = k - (n - 1)
                d = _corr_s_der_at(h, s, p)
                if abs(d) > 1e-12:
                    c = _corr_s_val(h, s) * dx
                    vals.append(c)
                    slopes.append(d * dx)
            if len(vals) == 0:
                continue
            vals = np.array(vals)
            slopes = np.array(slopes)
            a = vals - slopes * h[p]
            b = slopes
            hp = h[p]
            best_v = hp
            best_f = _max_lin_at(a, b, hp)
            # Endpoints
            for vt in (0.0, 1.0):
                ft = _max_lin_at(a, b, vt)
                if ft < best_f - 1e-15:
                    best_f = ft
                    best_v = vt
            # Breakpoints
            m = len(a)
            for i in range(m):
                for j in range(i + 1, m):
                    db = b[i] - b[j]
                    if abs(db) > 1e-14:
                        vbp = (a[j] - a[i]) / db
                        if -1e-6 <= vbp <= 1.0 + 1e-6:
                            vbp = np.clip(vbp, 0.0, 1.0)
                            fbp = _max_lin_at(a, b, vbp)
                            if fbp < best_f - 1e-15:
                                best_f = fbp
                                best_v = vbp
            if abs(best_v - hp) > 1e-10:
                h[p] = best_v
                improved = True
        if not improved:
            break
    return _project(h)
