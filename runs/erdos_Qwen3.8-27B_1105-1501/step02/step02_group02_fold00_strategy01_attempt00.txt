1. Approach and rationale

1.1 Central idea

Use an exact, constraint-preserving pairwise descent scheme as the core optimizer. Each proposed coordinate move transfers a scalar amount of mass from one support bin to another:

update_by_pair(h, receiver r, donor d, delta):
    h_new[r] = h[r] + delta
    h_new[d] = h[d] - delta

This move by itself preserves the equality

sum_i h_new[i] = sum_i h[i],

but is strictly scroll-dependent-free relative to the pair because the width of every feasible movement is exactly known. The important mathematical property is that, for any chosen pair, every single lag term in the given overlap objective is convex as a function of delta along the feasible interval. Therefore the objective, being the maximum over these single-lag terms, is also convex along that single-pair slice. Consequently one can perform reliable one-dimensional descent in this slice using exact initial scoring evaluations, and then evaluate the resulting candidate by the original allowed objective.

The search will be different from previous approaches in that it does not primarily rely on upper bound approximation by smooth LSE or p-norm terms, automatic differentiation by a black-box smooth objective, or SLSQP/FISTA extrapolation. Instead it works directly with the exact discrete max depending on finite support, while still using continuous optimizer assist accelerators on feasible components, especially Jacobian/transition transformations and local super-functions. Use a global static pulse optimization strategy with more raw, inter-event, generative generation structures but embed maintenance classical instinct for `min_sum_pairing_filter`.

1.2 Why this addresses the bottleneck
