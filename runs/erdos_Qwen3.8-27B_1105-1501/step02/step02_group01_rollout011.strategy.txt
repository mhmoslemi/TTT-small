Central idea. The returned construction must always be scored by the exact evaluator
`C5 = max_k np.correlate(h, 1-h, mode="full") * dx`, so every improvement step must keep a rigorously feasible vector and re-evaluate with that exact objective. The real difficulty is that the local landscape is nonconvex and often only a small subset of lag constraints supports the maximum, while gradient flows that optimize a smoothed pointwise upper envelope can move away from the finite-support boundary terms and raise previously inactive lags. This plan uses a hybrid local/validation strategy:

1. Preserve the supplied parent as a rigorous fallback and use it as the highest-priority local seed.
2. Generate several full-resolution starting vectors that stay close to but different from the parent: interpolation/downsampling variants, binary push variants, Fourier/coarse-linear expansions, deterministic balanced masks, and random balanced masks.
3. Run a lower-dimensional coarse search using smooth transformations and interpolation/projection to full resolution. This is not claimed to be globally optimal; it is an escape mechanism that can find different basins without spending the full budget in high-dimensional local algorithms.
4. Polish every candidate with a progressive softmax/smoothing local search, then with an active-cut active-lag method: repeatedly solve smaller nonconvex NLPs involving only the currently tight or nearly tight lag constraints, optionally with an auxiliary maximum variable. Accept only if the exact full-length correlation score improves.
5. Include a conservative exact two-variable exchange/local line-search refinement to improve flat-optima where NLP solvers stall.
6. Give explicit bisection plus tail repair for joint feasibility of `0 <= h <= 1` and `sum(h) = n/2`. Every candidate, including solver outputs, is repaired before scoring and the best feasible candidate is retained.

Why this may improve the supplied parent. The supplied construction is already near a nonconvex plateau. A direct full-constraint minimax solver can stagnate or traverse long dense Jacobian computations. A lower-dimensional coarse-to-fine structure search can escape the current stuck parent without becoming a fully separate construction method, while active-lag cutting converges to the small set that actually defines the maximum and avoids optimizing all 2n-1 inactive quadratic branches. The final answer is still an exact evaluation of the resulting feasible vector; no claim of global optimality is made.

Bottlenecks addressed.
- Parent may be local optimum: multi-resolution and different starting constructions allow different shapes.
- Full minimax constraint systems are expensive and can include many irrelevant constraints: active-set cuts focus computational effort on the active boundary plateau and re-add inactive violators only after exact evaluation.
- The objective has boundary effects because each correlation lag has only an overlap interval of length `n-|d|`; the exact index conventions and gradient formulas below preserve these terms rather than replacing the objective with circular correlation or an unqualified autocorrelation surrogate.

Correlation convention.

`raw_corr = np.correlate(h, 1-h, mode="full")`.
Use an organization with offsets `d = -(n-1), ..., n-1`, mapped to array index:
`k = d + (n-1)`.

For a fixed offset `d`, define overlap range:
`start(d) = max(0, -d)`,  
`end(d) = min(n, n-d)`.
Then the exact raw correlation value for index `k` is:
`f(h,d) = sum_{j = start(d)}^{end(d)-1} h[j+d] * (1 - h[j])`.

`C5(h) = dx * max_{d=-(n-1)}^{n-1} f(h,d)`.

This convention includes:
- negative offsets (`d < 0`)
- zero offset (`d = 0`)
- positive offsets (`d > 0`).

It is finite-support linear correlation. Do not replace `f(h,d)` with circular autocorrelation `(correlation ignoring overlap length changes)`. It also includes the overlap mass/boundary terms because each term has exactly `n-|d|` pairs.
