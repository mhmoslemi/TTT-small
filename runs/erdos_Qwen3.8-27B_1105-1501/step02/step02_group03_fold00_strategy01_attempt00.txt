1.3 Why this can improve the parent

At a near-minimax point the correct improving direction must often reduce many near-maximal constraints simultaneously rather than only a broad soft-weighted set. The LP model does precisely a finite hyperplane separation data problem: every affine constraint can decide which way to move. If the local linear model admits a direction whose predicted maximum overlap is lower, the line search tests the exact nonlinear direction. Because the problem is nonconvex, acceptance is always based on official exact overlap, so whether the model improved or worsened cannot cause an invalid improvement.

1.4 Scope and limitations

This is not a global proof method and does not claim optimality of any reported sample construction. Most merits are heuristic but concrete:
- Linearizing a bilinear overlap row may be inaccurate far from h_r.
- The LP may move to a boundary extreme that has a small trust radius after line search.
- Exact line-search rejections are handled by shrinking trust radius and by restarting from other valid low-dimensional refinements.
- If the new method produces no better parent, the compact validated initial construction or an algorithmically generated fallback vector is returned.

Every returned conclusion is always the provided evaluator's value for an explicitly feasible representation, so it remains a mathematically valid upper bound for the requested discrete evaluation. No claim is made that the reported value is the continuous Erdős problem optimum.

2. Mathematical specification

2.1 Discrete representation and objective

Let the current representation have n samples over [0,2]. The sample width is

    dx = 2.0 / n.

The vector h ∈ R^n represents a piecewise constant value on sample cells. The required constraints are

    0 ≤ h_i ≤ 1,        i=0,...,n-1,
    sum_i h_i = n / 2.

The exact objective used by the evaluator is

    F(h) = max_p [ dx * c_p(h) ],

where

    c(h) = np.correlate(h, 1-h, mode="full")

and p ranges over the 2n-1 full correlation positions. This is the finite-support linear correlation objective, not a circular autocorrelation objective. Boundary truncation is important: a shift of magnitude d samples overlaps only n-d samples.

2.2 Canonical finite-shift formulas

For algorithmic construction, define physical offsets s from -(n-1) to n-1. For each offset s:

If s ≥ 0, D=s and L=n-D:

    V_s(h) = dx * sum_{i=0}^{L-1} h_i * (1-h_{i+D}).

The gauge is:

    ∂_{h_i} V_s = dx * (1-h_{i+D}),           i=0,...,L-1,
    ∂_{h_{i+D}} V_s = -dx * h_i,              i=0,...,L-1.

Vectorized:

    row[0:L] += dx * (1-h[D:n]);
    row[D:n] -= dx * h[0:L].

If s < 0, let D=-s and L=n-D:

    V_s(h) = dx * sum_{i=0}^{L-1} h_{i+D} * (1-h_i).

Derivative:

    ∂_{h_{i+D}} V_s = dx * (1-h_i),           i=0,...,L-1,
    ∂_{h_i} V_s = -dx * h_{i+D},              i=0,...,L-1.

Vectorized:

    row[D:n] += dx * (1-h[0:L]);
    row[0:L] -= dx * h[D:n].

For s=0 these formulae combine into diagonal entries

    dx * (1-2h_i)

and the value

    V_0 = dx * sum_i h_i(1-h_i).

The set {V_s: s in {-(n-1, n-1)} equals the official full-correlation objective. The previous program's major constraints were ordered consistently. The implementation should not rely on the abstract sign convention of np.correlate for theory; it only needs the equality of the objective it evaluates. Do this with a check using one small vector that includes a minimum exact gradient sanity. using random vector validation below.

2.3 Exact gradient validation

For any implementation, values_canonical(h) reshaped to (2n-1,n) must satisfy, for random admissible h and some direction d:

    (V(h+eps*d)-V(h))/eps_dot ↓ G[h]^T d to numerical tolerance.

Also, because np.correlate may permute signs depending on conventions, test the value multiset:

    sorted(values_canonical(h)) ≈ sorted(dx*np.correlate(h,1-h,"full").max()*dx)

using large absolute tolerance, e.g. 1e-12, for a few deterministic random seeds. If the multiset mismatch is too large after known value-joining, do not use canonical gradients in a hard LP solver. In that case stop the primary LP machinery and execute the fallback described later; the exact evaluator will continue to be used. Under the standard full-mode correlation this multiset should match, but specifying the check prevents silently optimizing the wrong permutation.
