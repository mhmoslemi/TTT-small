def make_feasible(z):
    # Bisection to find shift that makes sum = n/2
    n = len(z)
    target = n / 2.0
    z = np.asarray(z, dtype=float).copy()
    z = np.clip(z, 0.0, 1.0)
    lo, hi = -1.0, 1.0
    for _ in range(60):

        s = np.sum(np.clip(z + mid, 0.0, 1.0))
        if s < target:
            lo = mid
        else:
            hi = mid
    h = np.clip(z + (lo + hi) / 2.0, 0.0, 1.0)

    if abs(residual) > 1e-12:
        if residual > 0:
            order = np.argsort(1.0 - h)
        else:

                if add <= 1e-15:

                h[idx] += add
                residual -= add
            else:

                if sub <= 1e-15:
                    continue
                h[idx] -= sub
                residual += sub
            if abs(residual) < 1e-14:
                break
    return np.clip(h, 0.0, 1.0)

def overlap_values(h):
    """Compute all overlap values (the values inside the max)."""
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def lse_value_grad(h, beta):
    """Compute value and gradient of log-sum-exp objective."""
    n = len(h)
    dx = 2.0 / n
    vals = overlap_values(h)  # shape (2n-1,)
    shifted = beta * vals
    m = shifted.max()
    exps = np.exp(shifted - m)
    total = exps.sum()
    w = exps / total  # softmax weights
    value = (m + np.log(total)) / beta
    
    # Compute gradient using vectorized approach
    grad = np.zeros(n)
    # Lag 0
    grad += w[n-1] * (1.0 - 2.0 * h)
    # Positive lags
    for s in range(1, n):
        wp = w[n-1+s]
        if wp < 1e-16:
            continue
        m_s = n - s
        grad[:m_s] += wp * (1.0 - h[s:])
        grad[s:] -= wp * h[:m_s]
    # Negative lags
    for t in range(1, n):
        wn = w[n-1-t]
        if wn < 1e-16:
            continue
        m_t = n - t
        grad[t:] += wn * (1.0 - h[:m_t])
        grad[:m_t] -= wn * h[t:]
    
    return value, dx * grad

def lse_func(x, beta):
    v, _ = lse_value_grad(x, beta)
    return v

def lse_jac(x, beta):
    _, g = lse_value_grad(x, beta)
    return g

- A point where two lines cross (and the upper envelope changes from decreasing to increasing)

To find this:
1. Compute all pairwise crossing points: u_kl = (V_l0 - V_k0) / (coeff_k - coeff_l) for coeff_k ≠ coeff_l
2. Filter to those in [-h_old, 1-h_old]
3. Add the endpoints
4. At each candidate point, compute max_k (V_k0 + u * coeff_k)
5. Take the minimum

This is O(n²) per coordinate (for the pairwise crossings), and O(n³) total. For n=60, that's 60 * 60² = 216,000 operations per pass. Very fast!

But wait, I need to be careful: the max of linear functions at a point is determined by the line that's highest at that point. So at each candidate point, I need to check all k. That's O(n) per candidate point, and O(n²) candidate points, so O(n³) total per coordinate. For n=60, that's 216,000 per coordinate, 60*216,000 = 13 million per full pass. Should take about 10-20 seconds. That's a lot.

Let me optimize: instead of checking all candidate points, I can use the fact that the upper envelope of lines can be computed in O(n log n) time (using a convex hull / upper hull algorithm). Then the minimum of the upper envelope is at a specific vertex.

Alternatively, I can use a simpler approach: binary search on the value t* (the minimum of the max). For a given value M, check if there exists u such that all V_k(u) ≤ M. This is a system of linear inequalities in u:
V_k0 + u * coeff_k ≤ M for all k
→ u * coeff_k ≤ M - V_k0 for all k

This gives upper and lower bounds on u:
- If coeff_k > 0: u ≤ (M - V_k0) / coeff_k
- If coeff_k < 0: u ≥ (M - V_k0) / coeff_k
- If coeff_k = 0: need M ≥ V_k0

So for a given M, the feasible set for u is an interval [u_min, u_max] (possibly empty). I can check if this interval intersects [-h_old, 1-h_old].

This gives a binary search on M, with O(n) work per iteration. Total: O(n log(n/eps)) per coordinate. For n=60 and eps=1e-10, that's about 60 * 34 = 2040 operations per coordinate, 60 * 2040 = 122,400 per pass. Very fast!

But I also need to handle the s=0 quadratic term. For s=0:
V_0(t) = dx * (t - t² + c_0) where c_0 = sum_{i≠j} h[i](1-h[i])

This is a concave parabola in t. The condition V_0(t) ≤ M gives:
dt - dt² + dx*c_0 ≤ M
dt² - dt + (M - dx*c_0) ≥ 0

This is a quadratic inequality, which gives an interval for t (the complement of the roots). I can incorporate this into the check.
