1. Approach and rationale

1.1 Central idea

The supplied objective is

    C(h) = dx * max_l corr_l(h),     dx = 2.0 / n,
    corr_l(h) = np.correlate(h, 1.0 - h, mode="full")[l].

The essential bottleneck is therefore the multidimensional nonsmooth minimax structure, not the evaluation of a pair direction.

The primary search mechanism proposed here is a full Lagrange-model minimax linear programming direction finder, followed by an exact trust-region line search and exact objective acceptance. At a current feasible h:

1. Compute the complete correlation vector corr(h) exactly with `np.correlate`.
2. Build a basis matrix D whose columns are the exact first-order directional “units” for changing individual coordinates:

                 - np.correlate(h, e_p, "full").

   This uses the given evaluator directly and therefore avoids hand-coded indexing mistakes.

       D[l, :] d + theta <= max_corr - corr[l]

4. Evaluate the original exact evaluator along the full possible line h + alpha d using an analytically exact propagator, then accept only after a direct recomputation with the original `np.correlate` formula.
