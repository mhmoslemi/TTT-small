def _find_optimal_coord(h, j, n):
    """Find optimal value for coordinate j minimizing max_k F_k."""
    cv = _corr_vec(h)  # shape (2n-1,)
    s_vals = np.arange(2*n-1) - (n-1)  # lag values
    
    c = np.zeros(2*n-1)  # coefficient of h[j] in F_k
    # For lag s, F_s = (2/n) * sum_{valid i} h[i+s]*(1-h[i])
    # h[j] appears when:
    #   j = i+s -> i = j-s, valid if 0 <= j-s < n and 0 <= j < n -> term: h[j]*(1-h[j-s])
    #   j = i   -> term: h[i+s]*(1-h[j]) where i=j, valid if 0 <= j < n and j+s < n -> term: h[j+s]*(1-h[j])
    
    for k in range(2*n-1):
        s = s_vals[k]
        coef = 0.0
        # j appears as i+s: i = j-s
        if 0 <= j-s < n and 0 <= j < n:
            coef += (1.0 - h[j-s])
        # j appears as i: direct term h[j+s]*(1-h[j])
        if 0 <= j < n and 0 <= j+s < n:
            coef += -(h[j+s])  # (1-h[j]) * h[j+s] = h[j+s] - h[j]*h[j+s]

import time

def _score(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def _corr_vec(h):
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def _project(z):
    n = len(z)
    target = n / 2.0
    z = np.nan_to_num(z, nan=0.5, posinf=1.0, neginf=0.0)
    lo = -2.0 - np.max(z)
    hi = 2.0 - np.min(z)
    for _ in range(60):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(z + mid, 0.0, 1.0))
        if s < target:
            lo = mid
        else:
            hi = mid
    h = np.clip(z + (lo + hi) / 2.0, 0.0, 1.0)
    res = target - h.sum()
    if abs(res) > 1e-10:
        if res > 0:
            idx = np.argsort(1.0 - h)[::-1]
        else:
            idx = np.argsort(h)[::-1]
        for i in idx:
            if res > 0:
                add = min(res, 1.0 - h[i])
            else:
                add = max(res, h[i] - 1.0)
            if abs(add) < 1e-16:
                break
            h[i] += add
            res -= add
    return np.clip(h, 0.0, 1.0)

- h[l] -> h[l] - δ
- All other h[i] unchanged.

For each lag k:
F_k changes by δ * (∂F_k/∂h[j] - ∂F_k/∂h[l])

So F_k(δ) = F_k(0) + δ * (c_k^j - c_k^l)

where c_k^j = ∂F_k/∂h[j] and c_k^l = ∂F_k/∂h[l].

Wait, that's only true if F_k is linear in h[j] and h[l] separately, which it is (bilinear, but linear in each variable when others are fixed).

So F_k(δ) = F_k(0) + δ * (c_k^j - c_k^l) is exactly correct (not just approximate).

The feasible range for δ:
- 0 ≤ h[j] + δ ≤ 1 → -h[j] ≤ δ ≤ 1 - h[j]
- 0 ≤ h[l] - δ ≤ 1 → h[l] - 1 ≤ δ ≤ h[l]

So δ ∈ [max(-h[j], h[l]-1), min(1-h[j], h[l])]

And we minimize max_k (F_k(0) + δ * (c_k^j - c_k^l)) over this range.

This is a convex piecewise-linear function of δ, minimized by golden section.

This is a great addition to the coordinate descent because:
1. It preserves the sum constraint exactly.
2. It's exact (no gradient approximation).
3. It can escape from "stuck" states where single-coordinate moves don't help.
