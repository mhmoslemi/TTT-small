1. Approach and rationale

The task is to produce a step vector `h` of length `n` with the following constraints:

- `0 <= h[i] <= 1` for all `i`
- `sum(h) * (2.0 / n) = 1`, equivalently `sum(h) = n / 2.0`
- Objective metric, exactly as evaluated:

`C5(h) = max_k dx * np.correlate(h, 1.0 - h, mode="full")[k]`,
where `dx = 2.0 / n`.

This objective is nonconvex because entries of `h` are products `h[i] * h[j]` inside each shift score. A direct CVXPY formulation of the exact objective is therefore not appropriate as a proof of global optimality. Any solver method must be a local/global heuristic, and every returned candidate must be evaluated with the exact evaluator.

The supplied parent construction is already very close to the known upper bound. The bottleneck in prior improvement programs was that the search mostly followed a single linearized active-set LP local descent. Because the true maximum is nonsmooth, local LP linearizations can stagnate on one active pattern, and exploration of neighboring local basins is weak.

The new algorithm combines:

1. **Annealed soft-smoothed continuous optimization** of the exact unscaled overlap integrals, using SLSQP over the hdrind box. Smoothing by log-sum-exp over the shift scores can pass through sharp active-set corners and discover nearby discretizations that reduce the exact maximum.

2. **Exact active-set linear programming polishing**, reusing the best ideas from active LP linearization but only applied periodically to the exact improvements found by the smooth path.

3. **Diversity of feasible starts** built algorithmically from the parent: exact parent, symmetrized parent, shifted/permutation perturbations, and low-frequency deterministic/harmonic feasible starts. These are constrained by the exact sum-before-projector, but projection is used as a feasible-jump mechanism rather than direct optimization.

4. **Length validation/resampling**. When the parent length is `n0`, test nearby lengths and rescaled resolutions such as `n = n, 2*n, 3*n//2, 3*n` only if there is remaining budget. A refinement lower in exact `C5` must be final checked by the actual metric. This can be crucial if the parent is too coarse and a slightly finer discretization lowers the sampled maximum.
