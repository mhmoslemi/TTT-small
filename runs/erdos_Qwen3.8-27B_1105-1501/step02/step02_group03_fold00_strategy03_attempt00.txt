1. Approach and rationale

1.1 Diagnosis of the bottleneck

The supplied parent has exact evaluator value about \(C \approx 0.380958\). The target is about \(0.3808\), requiring a local refinement of only \(1.6\cdot 10^{-4}\). The previous program mixes a projected-gradient maximization of the worst overlap, several feasibility repairs, interpolation changes, active-set SLSQP polish, and random perturbation. The essential weakness is that the actual local minimax geometry is not treated correctly: it uses a smooth surrogate and a partly active counter constraint solver, and there is a serious risk that the full-correlation offsets and gradients are not exactly matched to the official `np.correlate` evaluator. For such a tiny improvement, a small wrong derivative row or an omission of an almost-active lag can prevent progress.

The new primary approach is a genuinely different local minimax engine:

- Work directly with the epigraph of the exact objective, but solve a first-order subproblem as a linear program.
- At each feasible iterate, form the full derivative matrix \(G_{p,i} = \partial C_p/\partial h_i\) for all official correlation lags. The LP solves

  \[
  \min_{d,\gamma} \gamma
  \quad\text{s.t.}\quad
  C_p(h)+G_{p,\cdot}d-\gamma \le 0,\;
  \sum_i d_i=0,\; h_i \le h_i+d_i \le 1,\; |d_i|\le\rho.
  \]

  If this LP returns \(\gamma < \max_p C_p(h)\), it gives a linearized descent direction for all linearized lags, including almost-active constraints. This is safer and richer than selecting a small active subset or smoothing with a log-sum-exp surrogate.

- Every proposed step is tested with the original evaluator and backtrack line search, so no unverified LP improvement is ever accepted.

This method is materially different from the previous smoothing-plus-SLSQP pipeline:

- It solves a first-order linear model with all lags and both feasibility directions, instead of a penalty or active-set nonlinear subproblem.
- It uses the objective \(C_p(h)+Gd\) only as a direction generator, not as an accepted objective.
- It combines this LP descent with a biconstant construction of symmetric candidates and global resolution transfer.

A secondary mechanism is retained for escaping LP false stops: a correct-gradient log-sum-exp smoothing optimized in the symmetric pair parameterization. The accepted bound is always re-evaluated via `np.correlate`, so the result remains a valid upper bound even if the subproblem is only a local relaxation approximation.

1.2 Hypotheses and limitations

- The LP first-order linearized model does not globally certify a step decrease because each \(C_p\) is a nonconvex bilinear function of \(h\). The exact line search is mandatory.
- The pair-symmetric family

  \[
  h_i+x_i=1,
  \qquad
  h_{n-1-i}=1-h_i,
  \]

  is not claimed to contain the global optimum. It is used for fast unfeasibility-free smoothing, while full-length LP can still examine asymmetric directions.
- No global optimality or mathematical guarantee of reaching \(0.3808\) is claimed. The returned value is safety checked as an upper bound via the official metric.
