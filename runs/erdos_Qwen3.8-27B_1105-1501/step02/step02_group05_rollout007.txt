The idea: let A be the set of active lags. We want to find d such that:
- sum(d) = 0
- For all s in A: g_s · d < 0 (decrease all active lags)
- ||d|| is small

This is equivalent to: minimize max_{s in A} g_s · d subject to sum(d) = 0, ||d|| ≤ r.

The optimal d is the negative of the projection of 0 onto conv{g_s : s in A} in the zero-sum subspace, scaled to have norm r.

We can find this by solving a small QP:
minimize t
subject to g_s · d ≤ t for all s in A
         sum(d) = 0
         ||d||² ≤ r²

This is a second-order cone program (SOCP), which can be solved by various methods. But for simplicity, I can use the following iterative approach:
1. Start with d = -mean of active gradients (projected to zero-sum)
2. Normalize to have norm r
3. Check if all active lags decrease; if not, adjust

- Find d in the zero-sum subspace that minimizes max_{s in A} g_s · d
- This is the negative of the point in conv{projection of g_s to zero-sum subspace} closest to 0

The closest point in a convex hull to 0 can be found by solving:
minimize ||x||²
subject to x in conv{y_1, ..., y_m}

This is a QP with m constraints, which is fast for small m.
