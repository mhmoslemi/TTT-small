1. Approach and rationale

1.1 Central idea

The current construction is optimized with a slow pairwise ternary descent that recomputes the exact correlation repeatedly for one pair. Replace it with an analytically structured pairwise coordinate descent. For a transfer of mass between two coordinates,

    h_i += t,   h_j -= t,   t in [lo, hi],

the full correlation vector at all 2n-1 lags is exactly a small set of quadratics in t:

    f'_ell(t) = f_ell + t (G_i,ell - G_j,ell) + t^2 kappa_{i,j,ell},

where G is the exact gradient matrix of correlation components with respect to h, and
kappa is zero except at two lag indices, where it equals 1. Hence the objective along this line

    Phi_{i,j}(t) = max_ell f'_ell(t) * dx

is convex. This permits most exact one-dimensional optimum estimation for each pair with a very cheap vectorized ternary line search, and exact acceptance only after rebuilding the actual objective and feasibility from the proposed h. Because costs are small for n around 24-70, combine this with global multi-start and multi-resolution search over smaller lengths. Smaller discrete constructions are explicitly preferred by the task, so search target sample sizes significantly below the supplied parent length, while retaining the parent as a fallback. The final return object uses the exact evaluator, never a surrogate circular objective or a relaxation.

1.2 Why this can improve the supplied parent

The supplied parent is a local construction. The exact objective is bilinear and nonconvex; therefore, coordinate descent using only crude ternary evaluations and with coarse step rules can stagnate. For a given pair, the one-dimensional objective is exactly convex when the feasible transfer interval is used. A convex line search over the whole feasible transfer interval can find a better point than moving only one gradient of additional moves. Repeating full pair sweeps tends to descend to a pairwise coordinate optimum faster and more reliably than the previous leaf closure.

Multi-resolution search is important because smaller n arrays often have a different feasible set and support metric density (`dx = 2/n`). Trial resolutions in 24-70 and around the parent may produce lower discrete values while satisfying the evaluator exactly.

1.3 Important limitations and honest scope

The problem is nonconvex; pairwise coordinate descent is a local method, and the line searches find good local minima along one-dimensional transfer intervals rather than global minima of h. Multiple deterministic and random initializations, several losses of resolution, and stochastic transfers from the best sequence are explorations to reduce local traps, but none proves global optimality. The output is therefore accepted only via exact re-evaluation using `compute_c5(h)` on the returned arrays. The strategy can improve, but it is not a certified global solver.
