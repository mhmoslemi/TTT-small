1. Approach and rationale

1.1 Central idea

The known parent construction is already close to a local coordinate optimum, so the key question is not how to do more single-pair line searches, but how to escape the local basin created by the nonsmooth maximum of linear correlations. The proposed method is a hybrid exact-objective local and global search:

1. The primary continuous local method is an active-set simultaneous direction method, not a coordinate-wise method. At the current feasible vector h, identify the constraints (correlation lags) that are at or near the current maximum correlation. Solve a small exact linear program for a simultaneous feasible direction that linearly decreases all of these near-maximum correlation components. The direction is then accepted or rejected only after the exact evaluator is used on the resulting vector. This directly attacks the failure mode of pairwise coordinate descent: several maximal lags can often be reduced only if many coordinates move at once.

2. The secondary continuous method is a smoothed-gradient stochastic-descent fallback. This uses a softmax weighting of top correlation lags and a feasible first-order gradient direction. It is accepted only by exact evaluation. It is a safe direction generator if the linear program becomes numerically degenerate or too conservative.

3. The primary combinatorial method is a balanced binary-sequence simulated annealing path. For even target lengths, the integral constraint sum(h)=n/2 is enforced by keeping exactly n/2 ones and n/2 zeros. Moves swap a randomly chosen 1-position with a randomly chosen 0-position, so feasibility is exact by construction. The annealing minimizes the exact raw maximum correlation, which is the same objective up to the constant positive factor dx. This is a genuinely different search space from the continuous parent and may discover low-l//overlap structures at smaller sample sizes.

4. A final pair-polish uses exact convex one-dimensional pair transfers. This is not the main method; it is used to clean up small valleys left by simultaneous-direction steps and to make binary discoveries exploit the continuous evaluator without requiring every small combinatorial step to be globally analogous.

All proposals are validated with the given evaluator:

C5(h)=max(np.correlate(h, 1-h, mode="full")) * (2/n).

No circular correlation, surrogate autocorrelation, relaxed objective, or theoretical lower bound is used for acceptance.

1.2 Why this can improve the supplied parent

Previous pairwise coordinate methods can get stuck when a one-pair move worsens the maximum even though a simultaneous move in many coordinates lowers several of the constrained near-maxima. The LP-based simultaneous step is the substantive algorithmic change: it solves the linearized minimax problem over the current active set and thus can choose coordinate transfers that are locally impossible pairwise. Exact unevaluated proposals are never accepted, so the method cannot claim a reduction that the original problem does not have.

The binary annealing component addresses a second issue. The task explicitly prefers smaller sample counts, and the continuous optimum on length 70 may not be the best available discrete structure at smaller n. A binary sequence is automatically feasible if it has exactly n/2 ones, and an annealing over balanced binary strings explores a very different pattern family. The method will convert the best binary sequence into a valid h vector and place it in the same global best store. If continuous refinement on this binary start produces a better or tie-smaller vector, that vector can supersede the binary one.

1.3 Important scope and limitations

The exact objective is a maximum of bilinear forms and is nonconvex. The method is a stochastic-exact local/global search and is not intended to prove global optimality. The active-set LP direction is a linearized direction; the exact nonlinear movement along that direction can fail to improve and the step is then rejected.
