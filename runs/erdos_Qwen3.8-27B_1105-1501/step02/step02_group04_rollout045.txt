Now let me think about the SLSQP approach more carefully. The key insight is that SLSQP can move all coordinates simultaneously, which can escape from local optima that pair moves can't.

Let me also think about basin hopping. The idea is:
1. Start from current best
2. Perturb: h_new = h + noise
3. Project to feasible set
4. Run short SLSQP or pair sweep
5. If result is better, accept
