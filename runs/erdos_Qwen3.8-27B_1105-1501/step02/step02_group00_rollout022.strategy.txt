1. Approach and rationale

1.1 Objective to optimize and nonconvexity

The returned object is a vector `h` of length `n` representing sampled values of a step function on `[0,2]`. The exact objective used by the evaluator is

`C5_exact(h) = max_{r=0}^{2n-2} ((2/n) * correlate(h, 1-h, mode="full")[r])`,

where `np.correlate(a,b,"full")[r]` is interpreted as summing terms whose paired indices are defined by NumPy's linear full-mode correlation. This is explicitly linear correlation with finite support, not circular correlation. Since the objective uses products of entries of `h`, the problem is generally nonconvex. Therefore there is no proof of global optimality from any local method. Every non-exact surrogate is only a generator of candidate points; final selection and every intermediate acceptance test must be made using the exact evaluator.

Associated exact constraints are:

- `h[i] >= 0` for all i,
- `h[i] <= 1` for all i,
- `sum_i h[i] = n/2`.

Equivalently, `dx=2/n`, `sum_i h[i]*dx=1`. The phrase “exactly” cannot be satisfied literally in arbitrary floating-point arithmetic; the implementation must use a feasibility repair mechanism and a tolerance-based acceptance check, then perform a final numerical consistency correction to make the mean constraint as exact as is realistically possible under floating point.

1.2 Why this plan differs from the previous LP-line-search code

The previous program primarily used a local LP linearization for `h -> h + alpha p`, followed by line search, then pair searches and perturbation restarts. That strategy can remain trapped in a basin of similar local patterns defined by a single LP model. This new plan uses two deliberately different mechanisms:

1. **An attempt to obtain discrete binary minimizing objects using an integer linear model.** If this succeeds, the solution is a `0/1` vector satisfying the mean-sum constraint. These are fundamentally different exploration points because the nonlinear product model is not being locally linearized into the same directions.

2. **A convex-synthesis stage that combines multiple feasible overlapping objects, especially any binary solutions, into continuous designs.** This is not equivalent to averaging the objective values: maximum bilinear overlap is nonconvex without convexity, but convex combinations of outer designs can reduce different active-lag maxima and create intermediate obstacle peaks. It also provides a new source for subsequent local line directions. The final projected gradient / line method also has a different structure from the old LP model: directions include active subgradient combinations, conditioned directions to top components and random usable degrees of freedom, and every update is exact.

Additional existing mechanisms include:
- exact score evaluation,
- exact score projective step updates,
- resampling and validation across dimensions,
- feasibility projector,
- defensive final feasible fallback.

All adaptations remain objective-exact and non-convex, but the central institutions are source design pool and convex synthesis, rather than a monolithic LP linear model.
