Let me also add a **direct coordinate descent** method as an alternative to LP:
- For each coordinate i, compute the optimal h[i] given all other h[j] fixed
- The optimal h[i] minimizes max_d c[d], which is a 1D problem (since only c[d] terms involving h[i] change)

Actually, the coordinate descent is:
For coordinate i, the correlation c[d] depends on h[i] linearly (in the terms where i is involved):
c[d] = A[d] + B[d]*h[i] for some constants A[d], B[d] (that depend on other h values and d)

The optimal h[i] is the value in [0,1] that minimizes max_d (A[d] + B[d]*h[i]).

This is a 1D convex optimization problem! We can solve it exactly.

For each d, the constraint A[d] + B[d]*h[i] ≤ t gives:
- If B[d] > 0: h[i] ≤ (t - A[d])/B[d]
- If B[d] < 0: h[i] ≥ (t - A[d])/B[d]
- If B[d] = 0: need A[d] ≤ t

So we want to minimize t subject to:
- 0 ≤ h[i] ≤ 1
- For each d with B[d] > 0: (t - A[d])/B[d] ≥ h[i], i.e., t ≥ A[d] + B[d]*h[i]
- For each d with B[d] < 0: (t - A[d])/B[d] ≤ h[i], i.e., t ≥ A[d] + B[d]*h[i]

The optimal t is max_d (A[d] + B[d]*h[i]), and we want to choose h[i] to minimize this.

This is equivalent to: minimize max( max_{d: B[d]>0} (A[d]+B[d]*h[i]), max_{d: B[d]<0} (A[d]+B[d]*h[i]) )

The first term is increasing in h[i], the second is decreasing. The optimal h[i] is where they cross (or at a boundary).

This gives an EXACT coordinate descent step! Let me implement this.

For coordinate i:
- B[d] for different d:
  - For negative lag d = -g (g > 0): c = sum h[j]*(1-h[j+g]). The terms involving h[i] are:
    - If i ≤ n-1-g: term h[i]*(1-h[i+g]), so B = 1-h[i+g]
    - If i-g ≥ 0 (i.e., i ≥ g): term h[i-g]*(1-h[i]), so B = -h[i-g]
  
  So B[d=-g] = (1-h[i+g]) if i ≤ n-1-g, plus (-h[i-g]) if i ≥ g.

  - For positive lag d = g (g > 0): c = sum h[j+g]*(1-h[j]). The terms involving h[i] are:
    - If i-g ≥ 0 (i.e., i ≥ g): term h[i]*(1-h[i-g]), so B = 1-h[i-g]
    - If i+g ≤ n-1 (i.e., i ≤ n-1-g): term h[i+g]*(1-h[i]), so B = -h[i+g]

  So B[d=g] = (1-h[i-g]) if i ≥ g, plus (-h[i+g]) if i ≤ n-1-g.

Given this, for each d, I can compute B[d] and A[d] = c[d] - B[d]*h[i] (the current c[d] minus the h[i] contribution).

Then I solve the 1D problem: minimize max_d (A[d] + B[d]*t) over t ∈ [0,1].

This is a linear programming problem in 1D, which can be solved by finding the intersection of the relevant lines.

Actually, an even simpler approach: binary search on t. For a given t, check if there exists h[i] ∈ [0,1] such that A[d] + B[d]*h[i] ≤ t for all d. This is a system of linear inequalities in h[i], which has a solution iff:
max_{d: B[d]<0} (t-A[d])/B[d] ≤ min_{d: B[d]>0} (t-A[d])/B[d]
and the result is in [0,1].

Binary search on t gives the optimal value.

This coordinate descent is EXACT (no approximation) and should converge to a local minimum. It might be faster than the LP approach because each step is O(n) instead of solving an LP.

def _project(v, target):

        return np.zeros(n)
