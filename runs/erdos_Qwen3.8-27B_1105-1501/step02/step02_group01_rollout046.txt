Actually, I realize I should also think about the "anti-concentric" pattern. One idea that might work well: construct the binary vector so that the ones are placed at positions that are "mutually far apart" in a certain sense. For example, using a quadratic residue pattern or a Bose-Chao difference set.

A difference set D in Z_n with parameters (n, k, λ) has the property that every non-zero element of Z_n can be written as a difference of two elements of D in exactly λ ways. This is related to our problem because the correlation at lag d counts the number of pairs in D at distance d.

If we use a difference set, the correlation at each non-zero lag would be exactly λ, which is the minimum possible maximum! However, difference sets exist only for specific parameter combinations, and they're defined on a cyclic group (whereas our problem is on a line, not a cycle).

For our problem on a line (not a cycle), the boundaries break the cyclic symmetry, so difference sets don't directly apply. But they give a good structural intuition: we want the ones to be "evenly distributed" in terms of pairwise distances.

One practical approach: use a "Beatty sequence" or "Fibonacci word" pattern, which has good distribution properties.

For example, the Fibonacci word is a binary sequence where the frequency of 1's is Φ-1 ≈ 0.618. But we need exactly n/2 ones, so this doesn't directly apply. However, we can use a "balanced" version.

A "balanced" binary word of length n with n/2 ones is one where the number of ones in any two substrings of the same length differ by at most 1. This is related to Sturmian words and can be constructed using the "mechanical word" with slope 1/2.

The mechanical word with slope 1/2 and intercept 0 is: w(i) = floor((i+1)/2) - floor(i/2), which gives 0,1,0,1,0,1,... for slope 1/2. That's just the alternating pattern, which we saw is bad.

For slope 1/2 with a different intercept, we get the same pattern (just shifted). So the mechanical word with slope 1/2 is not useful.
