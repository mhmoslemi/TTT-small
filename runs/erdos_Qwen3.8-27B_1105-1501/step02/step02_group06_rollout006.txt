For a given off, the gradient contribution is:

For off ≥ 0:
- First term: k+off valid means 0 ≤ k ≤ n-1-off, so k ranges from 0 to n-1-off

- Second term: k-off valid means off ≤ k < n, so k ranges from off to n-1
  grad[off:n] -= w * dx * h[0:n-off]

- Second term: k+t valid means 0 ≤ k ≤ n-1-t, so k ranges from 0 to n-1-t

        sm = smooth_max_val(h, beta)
        constraint_violation = np.sum(h) - n / 2.0
        return sm + mu * constraint_violation ** 2
    
    def obj_grad(h):
        g = smooth_max_grad(h, beta)
        g += 2 * mu * (np.sum(h) - n / 2.0) * np.ones(n)
        return g

    vals = np.correlate(h, 1.0 - h, mode='full') * (2.0 / n)
