This is a 1D minimax problem! The function to minimize is:

where a_p = corr_old[p] and c_p is fixed. This is a piecewise linear function of t (the max of linear functions). The minimum can be found by binary search or by finding the intersection points.

The constraint box is: t ∈ [max(-h[i], h[j]-1), min(1-h[i], h[j])]

For the piecewise linear function f(t) = max_p (a_p + t*c_p):
- If all c_p = 0, f is constant.
- Otherwise, f is convex (max of linear functions).
- The minimum is where the subgradient contains 0, i.e., where there exist positive weights summing to 1 on the active constraints such that sum = 0.

In practice, I can find the minimum by:
1. Finding all "break points" where the maximizing p changes.
2. Evaluating f at each break point and at the constraint boundaries.
3. Taking the minimum.

The break points occur where a_p + t*c_p = a_q + t*c_q for some pair (p,q), i.e., t = (a_q - a_p)/(c_p - c_q) (when c_p ≠ c_q).

Wait, for f(t) = max_p (a_p + t*c_p):
- The right derivative at t is max_{p active at t} c_p
- The left derivative at t is min_{p active at t} c_p
- f is minimized when left derivative ≤ 0 ≤ right derivative

So the algorithm is:
1. Start with t_lo, t_hi (the constraint bounds).
2. Find t* such that left_deriv(t*) ≤ 0 ≤ right_deriv(t*).
3. If such t* exists, it's the minimum.

To find t*, we can:
- Evaluate f at the midpoint.
- Determine which p's are active (within epsilon of max).
- Compute left and right derivatives.
- If left_deriv > 0: minimum is to the left, set t_hi = mid.
- If right_deriv < 0: minimum is to the right, set t_lo = mid.
- Otherwise: we've found the minimum.

This converges in O(log(range/eps)) iterations, each O(n) to evaluate.

```python
def compute_pair_coeff(h, i, j):
    """Compute c[p] = dx * (d corr[p]/d h[i] - d corr[p]/d h[j]) for all p."""
    n = len(h)
    dx = 2.0 / n
    
    def coeff(k):
        """Compute d corr[p] / d h[k] * dx for all p."""
        c = np.zeros(2*n-1)
        # For lag s >= 0 (p = n-1+s, s = 0..n-1):
        #   h[k] appears as first factor if k < n-s, i.e., s < n-k, i.e., s in [0, n-k-1]
        #     contribution: (1-h[k+s])
        #   h[k] appears as second factor if k >= s, i.e., s <= k
        #     contribution: -h[k-s]
        # For lag s < 0 (p = n-1+s, s = -(n-1)..-1, let t = -s = 1..n-1):
        #   h[k] appears as first factor if k >= t, i.e., t <= k
        #     contribution: (1-h[k-t])
        #   h[k] appears as second factor if k < n-t, i.e., t < n-k
        #     contribution: -h[k+t]
        
        # Simpler: for each p, s = p-(n-1)
        # dc = (1-h[k+s]) * [0<=k+s<n] - h[k-s] * [0<=k-s<n]
        
        # Vectorized:
        s = np.arange(-(n-1), n)  # all possible lags
        # (1-h[k+s]) where 0<=k+s<n
        ks = k + s
        mask1 = (ks >= 0) & (ks < n)
        term1 = np.where(mask1, 1.0 - h[ks], 0.0)
        
        ks2 = k - s
        mask2 = (ks2 >= 0) & (ks2 < n)
        term2 = np.where(mask2, -h[ks2], 0.0)
        
        return (term1 + term2) * dx
    
    return coeff(i) - coeff(j)
```

This is O(n) per coefficient computation (vectorized), so O(n) total for a pair. Much better!

import numpy as np
from scipy.optimize import minimize
import time

def exact_score(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.correlate(h, 1.0 - h, mode='full').max() * dx)

def make_feasible(z):
    n = len(z)
    target = n / 2.0
    z = np.asarray(z, dtype=float).copy()
    z = np.clip(z, 0.0, 1.0)
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(z + mid, 0.0, 1.0))
        if s < target:
            lo = mid
        else:
            hi = mid
    h = np.clip(z + (lo + hi) / 2.0, 0.0, 1.0)
    residual = target - np.sum(h)
    if abs(residual) > 1e-13:
        if residual > 0:
            order = np.argsort(1.0 - h)
        else:
            order = np.argsort(h)
        for idx in order:
            if residual > 0:
                add = min(residual, 1.0 - h[idx])
                if add > 1e-15:
                    h[idx] += add
                    residual -= add
            else:
                sub = min(-residual, h[idx])
                if sub > 1e-15:
                    h[idx] -= sub
                    residual += sub
            if abs(residual) < 1e-14:
                break
    return np.clip(h, 0.0, 1.0)

def interp_to(h_src, n_tgt):
    n_src = len(h_src)
    src_c = (np.arange(n_src) + 0.5) * (2.0 / n_src)
    tgt_c = (np.arange(n_tgt) + 0.5) * (2.0 / n_tgt)
    h_int = np.interp(tgt_c, src_c, h_src)
    return make_feasible(h_int)

def lse_grad(x, beta):

    dx = 2.0 / n
    vals = corr_values(x)
    m = vals.max()
    shifted = beta * (vals - m)
    w = np.exp(shifted)
    ws = w.sum()
    if ws < 1e-300:
        w = np.ones(2 * n - 1) / (2 * n - 1)
    else:
        w /= ws
    grad = np.zeros(n)

        if w[p] < 1e-15:
            continue
        s = p - (n - 1)
        if s >= 0:
            jf = np.arange(0, n - s)
            js = np.arange(s, n)
            grad[jf] += w[p] * (1.0 - x[jf + s])
            grad[js] -= w[p] * x[js - s]

    try:
