1. Approach and rationale

Central idea
-------------
The previous local machinery was based mainly on active-set quadratic approximations, smooth-max agreement, and SLSQP-style local steps. Those methods are respectable, but in this high-dimensional nonconvex minimax problem they can stall after reaching a stationary point because the exact maximum is a rigid envelope over all lags. The new approach starts from a genuinely different triad:

1. explicit combinatorial 0/1 exploration on the discrete grid, since a half-mass problem has a natural exact-integer feasible set;
2. exact coordinate-pair global one-dimensional line descent on continuous steps, with acceptance always based on the true nonconvex evaluator;
3. full-lag linearized feasible-direction searches using only convex subproblems, followed by mandatory re-evaluation with the official nonlinear objective.

The first component is algorithmically different because it optimizes a balanced binary vector h with exactly n/2 ones by simulated annealing and local combinatorial moves, not by gradient models. The second is different because it treats the exact score one scalar direction at a time along a two-coordinate transfer that is hard-projected to the box and mass constraint. The third is different from the earlier top-active-set QP because it uses all lag constraints simultaneously in a convex trust-region linearized feasibility subproblem, but then never trusts the model without an exact nonconvex re-check.

Why it might improve the parent
------------------------------
For a discrete vector h satisfying sum(h) = n/2 and h_i in {0,1},
the objective is
    C5_score(h) = dx * F_max(h),
where F_max(h) is the maximum over 2n-1 lags of integer cross-difference counts. These integer structures can be very far from gradients of continuous relaxations. A good balanced binary h can produce a score inside the current numerical basin or a valid distinct feasible point with nearby or lower exact score. Even if it does not reach the final target by itself, this supplies a completely new orientation for continuous polishing.

Coordinate-pair line descent is supplied since the feasible set is an intersection of the hyperplane sum(h)=n/2 and a box. Along any active vertex cut direction e_a - e_b, a single scalar can be globally examined only for that one-dimensional curve by exact evaluation. Such moves can reduce lags lying below the current maximum even if a full active-set model cannot detect them, by moving boundary mass targets together together.

The full-lag convex feasibility step uses an important but restricted convex subproblem. At a current vector h0, the exact nonconvex lag functions f_p(h) are locally linearized:
    f_p_lin(z) = f_p(h0) + ∇f_p(h0)^T (z - h0).
We solve a convex feasibility or risk-minimization problem in z. It may move many variables simultaneously, can find a strict full-coordinate direction t where the linearized model predicts that every high lag decreases, while preserving sums and boxes. This is a convex step, but it is only a search heuristic for the global nonconvex problem. Every solution is judged using the actual official evaluator.

Important limitations and hypotheses
------------------------------------
The objective is nonconvex because products h_i(1-h_j) generate bilinear/nonlinear structure. No global optimality guarantee, no proof of whether it reaches below 0.3808, because the simplex excludes cyclic/pastaut descent. The combinatorial component is an empirical hypothesis: good binary configurations are plausible but not proven to be optimal. Convex linearizations are surrogate predictors only. Every accepted candidate is another certified point whose score is bounded by its actually computed official score. If no candidate below the record is found, the program returns the best valid feasible point in the best state. Parent remains a fallback if available.
