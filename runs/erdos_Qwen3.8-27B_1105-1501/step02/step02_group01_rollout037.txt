One more idea: **coordinate descent with exact line search**. For each coordinate h[i], given all other h[j], find the optimal h[i] (with the constraint sum(h) = n/2). Since the constraint couples all coordinates, this isn't straightforward. But we can do a "pair" coordinate descent: for each pair (i,j), find the optimal redistribution of mass between them.

For a pair (i,j), the current mass is h[i] + h[j] = m (fixed by the constraint). We want to choose h[i] ∈ [max(0, m-1), min(1, m)] to minimize the objective. This is a 1D optimization problem for each pair!

The objective as a function of h[i] (with h[j] = m - h[i]):
f(h[i]) = max_k corr_k(h[i])

where corr_k is linear in h[i] (since each corr_k depends on h[i] and h[j] linearly when all others are fixed).

So f is a piecewise linear function of h[i] (the max of linear functions). We can find its minimum by checking the breakpoints.

This is a very clean approach! Let me implement it:

For a fixed pair (i,j) with m = h[i] + h[j]:
- h[i] can range over [max(0, m-1), min(1, m)]
- For each lag k, corr_k is a linear function of h[i]: corr_k = a_k * h[i] + b_k
- f(h[i]) = max_k (a_k * h[i] + b_k)
- The minimum of f over the interval is at a breakpoint or at an endpoint

The breakpoints are where a_k * h[i] + b_k = a_l * h[i] + b_l for some pair (k,l), i.e., h[i] = (b_l - b_k) / (a_k - a_l).

For n=50, there are 99 lags, so at most C(99,2) ≈ 4851 breakpoints. But most won't be in the feasible interval. We can compute the lower envelope (or upper envelope, since we want the max) and find its minimum.

Actually, the upper envelope of 99 line segments has at most 99 segments (in 1D). So we can:
1. For each lag k, compute a_k and b_k (the slope and intercept of corr_k as a function of h[i])
2. Find the upper envelope
3. Minimize the upper envelope over the feasible interval

This is O(n²) per pair evaluation, but very fast for n=50.

def pair_optimize(h, i, j):
    """Given h, optimize the pair (h[i], h[j]) keeping their sum fixed."""
    n = len(h)
    dx = 2.0 / n
    m = h[i] + h[j]  # fixed sum
    
    # h[i] ranges over [lo, hi]
    lo = max(0.0, m - 1.0)
    hi = min(1.0, m)
    if lo >= hi:
        return 0.0, h[i], h[j]
    
    # For each lag k (0 to 2n-2), corr_k = sum_valid h[a]*(1-h[b])
    # As a function of h[i] (with h[j] = m - h[i]):
    # corr_k changes by: (coeff_i - coeff_j) * h[i] + const
    # where coeff_i is the coefficient of h[i] in corr_k,
    # and coeff_j is the coefficient of h[j] in corr_k.
    
    # Let me compute the current corr_k and the coefficients.
    # corr_k = sum_{valid pairs (a,b) with b-a=s} h[a]*(1-h[b])
    # where s = k-(n-1)
    
    # Coefficient of h[i] in corr_k:
    # h[i] appears as h[a] when a=i: contributes (1-h[i+s]) to corr_k
    # h[i] appears as h[b] when b=i (a=i-s): contributes -h[i-s] to corr_k (from -h[a]*h[b] = -h[a]*h[i])
    # So coeff_i = (1-h[i+s]) [if valid] - h[i-s] [if valid]
    # Wait, that's not quite right. Let me be more careful.
    
    # corr_k = sum_{a: valid} h[a] * (1-h[a+s])
    #         = sum_{a: valid} h[a] - sum_{a: valid} h[a]*h[a+s]
    
    # The coefficient of h[i] in the first sum is 1 if i is in the valid range for the first factor.
    # The coefficient of h[i] in the second sum:
    #   h[i]*h[i+s] → coeff of h[i] is h[i+s]
    #   h[i-s]*h[i] → coeff of h[i] is h[i-s]
    # So coeff of h[i] in corr_k = [i in valid range for first sum] - h[i+s] - h[i-s] (with validity)
    
    # Similarly for h[j].
    
    # This is getting complex. Let me just compute it numerically.
    # corr_k(h[i]) is linear in h[i], so I can evaluate it at h[i]=lo and h[i]=hi
    # to get the line.
    
    # Save current h[i], h[j]
    old_hi, old_hj = h[i], h[j]
    
    # Evaluate corr at h[i]=lo, h[j]=hi_val
    h[i] = lo; h[j] = m - lo
    corr_lo = np.correlate(h, 1.0-h, mode='full')
    
    h[i] = hi; h[j] = m - hi
    corr_hi = np.correlate(h, 1.0-h, mode='full')
    
    # Reset
    h[i] = old_hi; h[j] = old_hj
    
    # For each k: corr_k(h[i]) = corr_lo[k] + (corr_hi[k] - corr_lo[k]) / (hi - lo) * (h[i] - lo)
    # = A_k * h[i] + B_k
    # where A_k = (corr_hi[k] - corr_lo[k]) / (hi - lo), B_k = corr_lo[k] - A_k * lo
    
    A = (corr_hi - corr_lo) / (hi - lo)
    B = corr_lo - A * lo
    
    # Now f(h[i]) = max_k (A_k * h[i] + B_k) for h[i] in [lo, hi]
    # Find the minimum of this convex piecewise-linear function.
    # The minimum is at the point where the max transitions from decreasing to increasing.
    # Equivalently, at a breakpoint where the "active" lag changes.
    
    # For a convex piecewise linear function, the minimum is where the subgradient
    # contains 0, or at an endpoint.
    
    # Binary search: f is convex, so we can binary search for the minimum.
    # f'(h[i]) from the left = max of A_k over k where (A_k*h[i]+B_k) is the max
    # Actually, for convex f, the subgradient at x is [min of active slopes, max of active slopes]
    
    # Simpler: just evaluate f at several points and find the minimum.
    # Or: the minimum is at a breakpoint or endpoint.
    # Breakpoints: h[i] = (B_l - B_k) / (A_k - A_l) for pairs where A_k ≠ A_l
    
    # For n=50, there are 99 lags. The number of relevant breakpoints is at most 99.
    # Let's just evaluate f at all breakpoints that fall in [lo, hi], plus endpoints.
    
    candidates = [lo, hi]
    for k in range(2*n-1):
        for l in range(k+1, 2*n-1):
            if abs(A[k] - A[l]) > 1e-12:
                x_bp = (B[l] - B[k]) / (A[k] - A[l])
                if lo <= x_bp <= hi:
                    candidates.append(x_bp)
    
    # That's O(n²) = O(99²) ≈ 10K evaluations of f, each O(n) = O(50)
    # Total: ~500K operations per pair. With n²/2 pairs ≈ 1250 pairs, that's 625M operations.
    # Too slow for a full pass. Let me limit to a subset of pairs.
    
    # Alternative: just use ternary search or golden section on the convex function.
    # 50 iterations of golden section gives precision ~ (0.618)^50 ≈ 1e-11, more than enough.
    best_val = np.inf
    best_x = lo
    phi = (1.0 + np.sqrt(5.0)) / 2.0
    a, b = lo, hi
    for _ in range(50):
        c = b - (b-a) / phi
        d = a + (b-a) / phi
        f_c = np.max(A * c + B)
        f_d = np.max(A * d + B)
        if f_c < f_d:
            b = d
        else:
            a = c
        x_mid = (a + b) / 2
        f_mid = np.max(A * x_mid + B)
        if f_mid < best_val:
            best_val = f_mid
            best_x = x_mid
    
    # Update h
    h[i] = best_x
    h[j] = m - best_x
    return best_val * dx, best_x, m - best_x

        if residual > 0:
            order = np.argsort(1.0 - h)[::-1]
        else:
            order = np.argsort(h)[::-1]
        for i in order:
            if residual > 0:
                add = min(residual, 1.0 - h[i])
            else:
                add = max(residual, -h[i])
            if abs(add) < 1e-15:
                break
            h[i] += add
            residual -= add
    return np.clip(h, 0.0, 1.0)

def interp_to_n(h_src, n_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return h_src.copy()
    x_src = (np.arange(n_src) + 0.5) * (2.0 / n_src)
    x_dst = (np.arange(n_dst) + 0.5) * (2.0 / n_dst)
    return np.interp(x_dst, x_src, h_src)

def push_binary(h, p=2.0):
    return make_feasible(h ** p)

def thue_morse_binary(n, rng=None):
    """Generate a Thue-Morse-like binary sequence of length n with n/2 ones."""
    t = np.zeros(n)
    for i in range(n):
        t[i] = bin(i).count('1') % 2
    # Ensure exactly n/2 ones
    n_ones = int(np.sum(t > 0.5))
    target = n // 2
    if n_ones > target:
        # Remove excess ones
        ones_idx = np.where(t > 0.5)[0]
        remove = np.random.default_rng(42).choice(ones_idx, n_ones - target, replace=False)
        t[remove] = 0
    elif n_ones < target:
        zeros_idx = np.where(t <= 0.5)[0]
        add = np.random.default_rng(42).choice(zeros_idx, target - n_ones, replace=False)
        t[add] = 1
    return t

def pair_cd(h, max_passes=200, tol=1e-12, time_limit=None, t_start=None, gamma=None):
    """Cycle coordinate descent on pairs."""
    h = h.copy()
    n = len(h)
    dx = 2.0 / n
    best_corr = float(np.correlate(h, 1.0 - h, mode='full').max())
    best_score = best_corr * dx
    best_h = h.copy()
    
    n_pairs = n * (n - 1) // 2
    pair_list = [(i, j) for i in range(n) for j in range(i + 1, n)]
    
    rng_local = np.random.default_rng(123)
    
    for p in range(max_passes):
        if time_limit is not None and t_start is not None:
            if time.time() - t_start > time_limit:
                break
        
        start_corr = best_corr
        rng_local.shuffle(pair_list)
        
        for idx in range(n_pairs):
            i, j = pair_list[idx]
            m = h[i] + h[j]
            lo = max(0.0, m - 1.0)
            hi = min(1.0, m)
            span = hi - lo
            if span < 1e-10:
                continue
            
            # Quick check: evaluate at midpoint vs current
            mid_x = (lo + hi) / 2.0
            # Just do golden section
            old_hi, old_hj = h[i], h[j]
            h[i] = lo; h[j] = m - lo
            corr_lo = np.correlate(h, 1.0 - h, mode='full')
            h[i] = hi; h[j] = m - hi
            corr_hi = np.correlate(h, 1.0 - h, mode='full')
            h[i] = old_hi; h[j] = old_hj
            
            A = (corr_hi - corr_lo) / span
            B = corr_lo - A * lo
            
            # Golden section
            phi = (1.0 + 2.2360679775) / 2.0  # 1.618...
            a, b = lo, hi
            for _ in range(30):
                c = b - (b - a) / phi
                d = a + (b - a) / phi
                fc = np.max(A * c + B)
                fd = np.max(A * d + B)
                if fc < fd:
                    b = d
                else:
                    a = c
            
            x_opt = (a + b) / 2.0
            f_opt = float(np.max(A * x_opt + B))
            
            if f_opt < best_corr - 1e-14:
                h[i] = x_opt
                h[j] = m - x_opt
                best_corr = f_opt
                best_score = best_corr * dx
                best_h = h.copy()
        
        if start_corr - best_corr < tol:
            break
    
    return best_h, best_score

def fast_swap(h, rng, max_iters=300000, time_limit=None, t_start=None):
    """Random swap local search."""
    h = h.copy()
    n = len(h)
    dx = 2.0 / n
    best_corr = float(np.correlate(h, 1.0 - h, mode='full').max())
    best_score = best_corr * dx
    best_h = h.copy()
    
    for it in range(max_iters):
        if time_limit is not None and t_start is not None:
            if time.time() - t_start > time_limit:
                break
        i = rng.integers(n)
        j = rng.integers(n)
        if i == j:
            continue
        if h[i] < h[j]:
            i, j = j, i
        d = min(h[i], 1.0 - h[j])
        if d < 0.005:
            continue
        d_try = d * rng.uniform(0.2, 1.0)
        
        h[i] -= d_try
        h[j] += d_try
        new_max = float(np.correlate(h, 1.0 - h, mode='full').max())
        
        if new_max < best_corr:
            best_corr = new_max
            best_score = best_corr * dx
            best_h = h.copy()
        else:
            h[i] += d_try
            h[j] -= d_try
    
    return best_h, best_score

def slsqp_polish(h0, beta=300, maxiter=80):
    """SLSQP with LSE-smoothed objective."""
    h = make_feasible(h0)
    n = len(h)
    dx = 2.0 / n
    
    def obj(x):
        corr = np.correlate(x, 1.0 - x, mode='full') * dx
        m = np.max(corr)
        shifted = np.clip(beta * (corr - m), -500, 0)
        e = np.exp(shifted)
        s = np.sum(e)
        if s < 1e-300:
            return m
        return m + np.log(s) / beta
    
    def grad(x):
        corr = np.correlate(x, 1.0 - x, mode='full') * dx
        m = np.max(corr)
        shifted = np.clip(beta * (corr - m), -500, 0)
        e = np.exp(shifted)
        s = np.sum(e)
        if s < 1e-300:
            weights = np.ones(2 * n - 1) / (2 * n - 1)
        else:
            weights = e / s
        g = np.zeros(n)
        for k in range(2 * n - 1):
            w = weights[k] * dx
            if w < 1e-14:
                continue
            s2 = k - (n - 1)
            if s2 >= 0:
                if s2 == 0:
                    g += (1.0 - x) - x
                else:
                    g[s2:] += (1.0 - x[:n - s2])
                    g[:n - s2] += (-x[s2:])
            else:
                m2 = -s2
                if m2 == 0:
                    g += (1.0 - x) - x
                else:
                    g[:n - m2] += (1.0 - x[m2:])
                    g[m2:] += (-x[:n - m2])
        return g * (1 + np.log(s) / (beta * s)) if s > 1e-300 else g
    
    # Simplified gradient (just the direct part, ignoring the log sum exp correction)
    def grad_simple(x):
        corr = np.correlate(x, 1.0 - x, mode='full') * dx
        m = np.max(corr)
        # Find active lags
        threshold = m - 0.01 * max(m, 0.01)
        active = np.where(corr >= threshold)[0]
        g = np.zeros(n)
        for k in active:
            s2 = k - (n - 1)
            if s2 >= 0:
                if s2 == 0:
                    g += (1.0 - x) - x
                else:
                    g[s2:] += (1.0 - x[:n - s2])
                    g[:n - s2] += (-x[s2:])
            else:
                m2 = -s2
                if m2 == 0:
                    g += (1.0 - x) - x
                else:
                    g[:n - m2] += (1.0 - x[m2:])
                    g[m2:] += (-x[:n - m2])
        g /= len(active)
        return g
    
    def eq_fun(x):
        return np.sum(x) - n / 2.0
    
    def eq_jac(x):
        return np.ones(n)
    
    try:
        res = minimize(
            obj, h, jac=grad_simple,
            method='SLSQP',
            bounds=[(0.0, 1.0)] * n,
            constraints=[{'type': 'eq', 'fun': eq_fun, 'jac': eq_jac}],
            options={'maxiter': maxiter, 'ftol': 1e-12}
        )
        if hasattr(res, 'x') and np.all(np.isfinite(res['x'])):
            return make_feasible(res['x'])
    except Exception:
        pass
    return h
