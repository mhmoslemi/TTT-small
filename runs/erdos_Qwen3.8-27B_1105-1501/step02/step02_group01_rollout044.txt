Old: h_old(i-d) * (1-h_old(i)) = h_old(i-d) * 0 = 0
New: h_new(i-d) * (1-h_new(i)) = h_new(i-d) * 1
Special: if i-d = j, h_new(i-d) = h_new(j) = 1, change = 1
        if i-d ≠ j, h_new(i-d) = h[i-d], change = h[i-d]

Case 3: k = j (and j+d is valid)
Old: h_old(j) * (1-h_old(j+d)) = 0
New: h_new(j) * (1-h_new(j+d)) = 1 * (1-h_new(j+d))
Special: if j+d = i, h_new(j+d) = h_new(i) = 0, change = 1*(1-0) = 1
        if j+d ≠ i, change = 1-h[j+d] = 1-h[j+d]

Case 4: k+d = j, i.e., k = j-d (and both valid, 0 ≤ j-d < n)
Old: h_old(j-d) * (1-h_old(j)) = h_old(j-d) * 1 = h[j-d]
New: h_new(j-d) * (1-h_new(j)) = h_new(j-d) * 0 = 0
Special: if j-d = i, h_new(j-d) = h_new(i) = 0, change = -h_old(i) = -1
        if j-d ≠ i, change = -h[j-d]

So total delta[d]:
delta[d] = 0

# Case 1: k=i
if 0 <= i+d < n:
    if i+d == j:
        delta[d] += -1
    else:
        delta[d] += -(1 - h[i+d])

# Case 2: k=i-d
if 0 <= i-d < n:
    if i-d == j:
        delta[d] += 1
    else:
        delta[d] += h[i-d]

# Case 3: k=j
if 0 <= j+d < n:
    if j+d == i:
        delta[d] += 1
    else:
        delta[d] += (1 - h[j+d])

# Case 4: k=j-d
if 0 <= j-d < n:
    if j-d == i:
        delta[d] += -1
    else:
        delta[d] += -h[j-d]

This gives O(1) per lag, O(n) total per swap.
