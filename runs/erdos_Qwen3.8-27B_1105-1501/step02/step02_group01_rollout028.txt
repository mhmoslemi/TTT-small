I can vectorize this:
```python
def compute_B(h, u, a, b, va, vb, n):
    L = 2*n - 1
    B = np.zeros(L)
    # Term from a: valid k in [n-1-a, 2n-2-a]
    k_lo1, k_hi1 = max(0, n-1-a), min(2*n-2, 2*n-2-a)
    if k_lo1 <= k_hi1:
        ks = np.arange(k_lo1, k_hi1+1)
        j1 = a + ks - (n-1)  # = ks - (n-1-a), ranges from a to a+(k_hi1-k_lo1)
        j2 = a - ks + (n-1)  # = (n-1-a) - (ks - (n-1-a)), ranges from a to ...
        B[k_lo1:k_hi1+1] += va * (1.0 - h[j1] - h[j2])
    
    # Term from b: valid k in [n-1-b, 2n-2-b]
    k_lo2, k_hi2 = max(0, n-1-b), min(2*n-2, 2*n-2-b)
    if k_lo2 <= k_hi2:
        ks = np.arange(k_lo2, k_hi2+1)
        j3 = b + ks - (n-1)
        j4 = b - ks + (n-1)
        B[k_lo2:k_hi2+1] += vb * (1.0 - h[j3] - h[j4])
    
    return B
```

This is O(n) per pair (just index lookups), much faster than two full correlations.
