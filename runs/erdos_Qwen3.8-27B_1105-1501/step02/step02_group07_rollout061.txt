Let me implement this optimization:

When we swap positions i (1→0) and j (0→1), the change in V_k (for lag k = idx - (n-1)) is:

For the "full" correlate of h and (1-h):
correlate[k] = Σ_i h[i] * (1-h[i+k]) for valid i

When h[i] changes from 1 to 0:
- For all k where i is the "first" index: contribute h[i]*(1-h[i+k]) changes from (1-h[i+k]) to 0. So Δ = -(1-h[i+k]) for each such k.
- For all k where i is the "second" index (i = p+k, so k = i-p): contribute h[p]*(1-h[i]) changes from (1-1)=0 to (1-0)=1 * h[p]. So Δ = +h[p] for each such k.

When h[j] changes from 0 to 1:
- For all k where j is the "first" index: contribute h[j]*(1-h[j+k]) changes from 0 to (1-h[j+k]). So Δ = +(1-h[j+k]).
- For all k where j is the "second" index: contribute h[p]*(1-h[j]) changes from h[p]*(1-0)=h[p] to h[p]*(1-1)=0. So Δ = -h[p].

So the total change for each lag k is:
ΔV_k = -(1-h[i+k]) + h[i-k] + (1-h[j+k]) - h[j-k]
(where terms are 0 if the index is out of range, and we use the OLD values of h)

This is O(1) per k, so O(n) total for all k. Much faster than O(n²)!

def swap_delta(h, i, j, V):
    """Compute change in V when swapping h[i]:1->0 and h[j]:0->1."""
    n = len(h)
    # i changes from 1 to 0
    # j changes from 0 to 1
    # V[k] for k = -(n-1) to (n-1), stored as V[k + n - 1]
    
    # Effect on V from i going 1->0:
    # As first index: -(1-h[i+k]) for valid i+k
    # As second index: +h[i-k] for valid i-k (since 1-h[i] goes from 0 to 1)
    
    # Effect on V from j going 0->1:
    # As first index: +(1-h[j+k]) for valid j+k
    # As second index: -h[j-k] for valid j-k (since 1-h[j] goes from 1 to 0)
    
    delta = np.zeros(2*n - 1)
    
    # i as first: k ranges from 0 to n-1-i, stored at index (k + n - 1)
    # h[i+k] for k=0,...,n-1-i
    if i < n:
        ks = np.arange(0, n - i)
        idx = ks + n - 1
        delta[idx] -= (1 - h[i + ks])
    
    # i as second: k ranges from -(i) to -(1), i.e., k = i-p for p=0,...,i-1
    # So k = -(p-i+1)... let me think again.
    # i is the second index: i = p + k, so k = i - p. p ranges from 0 to min(i, n-1).
    # k = i - p, so as p goes from 0 to i, k goes from i to 0.
    # But we also need i+k = i + (i-p) = 2i-p... no wait.
    # If i is the second index, then the pair is (p, p+k) = (p, i), so k = i-p.
    # p ranges from 0 to i (and p+k = i < n, which is always true).
    # The contribution is h[p]*(1-h[i]). Old: h[p]*(1-1) = 0. New: h[p]*(1-0) = h[p].
    # So Δ = +h[p] for p = 0, ..., i.
    # k = i-p, stored at index (i-p + n-1).
    if i >= 0:
        ps = np.arange(0, i + 1)
        ks = i - ps  # k values
        idx = ks + n - 1
        delta[idx] += h[ps]

    if j < n:
        ks = np.arange(0, n - j)
        idx = ks + n - 1
        delta[idx] += (1 - h[j + ks])
    
    # j as second: j = p + k, k = j - p, p = 0, ..., j
    # Old: h[p]*(1-h[j]) = h[p]*1 = h[p]. New: h[p]*(1-1) = 0.
    # Δ = -h[p]
    if j >= 0:
        ps = np.arange(0, j + 1)
        ks = j - ps
        idx = ks + n - 1
        delta[idx] -= h[ps]
    
    return delta

def fast_gradient(h, weights):
    n = len(h)
    grad = np.zeros(n)
    for idx in range(len(weights)):
        w = weights[idx]
        if abs(w) < 1e-14:
            continue
        s = idx - (n - 1)
        L = n - abs(s)
        if L <= 0:
            continue
        if s >= 0:
            grad[s:n] += w * (1.0 - h[0:L])
            grad[0:L] -= w * h[s:n]

            grad[0:L] += w * (1.0 - h[t:n])
            grad[t:n] -= w * h[0:L]
