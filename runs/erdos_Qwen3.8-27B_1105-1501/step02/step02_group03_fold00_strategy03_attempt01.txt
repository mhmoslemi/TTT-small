1. Approach and rationale

1.1 Central idea

The supplied parent is a good local point, with reported bound approximately 0.380958. The desired improvement is only of order 10^{-4}. The main bottleneck to exploit is the exact discrete minimax objective and its exact derivatives, because the supplied parent is close enough to the next local optimum that a correctly formulated active-constraint local solver can reduce the maximum by a finite amount.

The proposed method is materially different from the usual smoothed projected-gradient/active set pipeline in the following exact sense:

- It uses the actual `np.correlate(h, 1-h, mode="full")` indexing to define each constraint.
- It uses precisely derived gradients for every lag/constraint and validates them against the official objective direction by finite differences before committing to gradient-based nonlinear subproblems.
- It treats the problem as a true nonlinear active-cut local minimax solver, not as a long log-sum surrogate too far from the actual maximum.
- For each current best point, it solves targeted sublevel problems: `q_p(h) <= tau` for a locally proposed `tau < F(best_h)`. This is a direct feasibility/projection problem toward the desired improvement, not just minimizing a smooth approximation.
- Candidate candidates can temporarily violate some unmodeled constraints or the attempted `tau`. They are accepted only after full re-evaluation with the exact official evaluator. This prevents a local subproblem from incorrectly calling an invalid/incomplete solution an improvement.

The prior gradient formulation in the user-provided parent algorithm likely mixed sign/orientation for the correlation lags. A planned explicit finite-difference validation avoids this failure mode.

1.2 What will be accepted as an improvement

All lower-level subproblems are local. They may be nonconvex, infeasible, or incomplete. The only authoritative acceptance test is:

score(h) = max_k dx * np.correlate(h, 1-h, mode="full")[k]

and feasibility:

0 <= h_i <= 1, sum_i h_i = n/2.

A candidate is accepted only if it is explicitly repaired and achieved official score. If none of the local improvements succeeds, the returned answer must be a valid fallback/candidate from the supplied parent or a safe valid fallback. This method is not a proof of global optimality.

1.3 Main algorithmic difference from generic smooth-only method

Primary method:

For current feasible best point h and objective F = F(h), repeatedly solve local active minimax subproblems:

- min_t: minimize scalar t subject to t >= q_k(h) for a selected set of constraints.
- tau_projection: given tau = F(h) - desired_improvement, find an h near current h satisfying q_k(h) <= tau for selected k.

The `-tau_projection` stage is central. It is not “minimize overlap sum”; it is a local feasibility cut toward one target level. If tau is too ambitious, SLSQP may not return an improved candidate and the outer chain may immediately benchmark smaller tau values. If tau succeeds, the update is accepted only once exactly evaluated and repaired.

The greedy constraint set is dynamically widened by hidden violations after each subproblem, mimicking an active cutting-plane track, while final evaluation remains exact.

2. Mathematical specification

2.1 Exact discrete evaluator

Let x denote a one-dimensional numeric array of length n, with n >= 4. Let

dx = 2.0 / n.

Define

g_x = dx * max(np.correlate(x, 1.0 - x, mode="full")).

This must be exactly the evaluator used for candidate acceptance and final bound. It includes both positive and negative finite-support lags. Do not replace it by circular autocorrelation, by g = 1 - minimum autocorrelation, or by any regularized formula.

Feasibility for this discrete representation is:

0 <= x_i <= 1,
sum_i x_i = n / 2.

Do not consider finite-time sequences invalid for only the formal constraint and return them without repair. The harness’s own scoring function will expect these conditions. Desired nonnegative final fixed-precision tolerances are specified in section 3.10.

2.2 Official full-correlation indexing and constraints

For correlation vector q = np.correlate(x, 1-x, mode="full") let p index 0 to 2n-2.

The physical offset is

d_p = p - (n - 1).

Using the proven, tested mapping:

If d_p >= 0, L = n - d_p, then

q_p = sum_{j=0}^{L-1} x_{j+d_p} * (1 - x_j).

If d_p < 0, a = -d_p, L = n - a, then

q_p = sum_{j=0}^{L-1} x_j * (1 - x_{j+a}).

This follows from full correlation ordering where bin p corresponds to pairs i - j = p - (n - 1). For the zero lag p = n-1, d_0 = 0 and q_{n-1} = sum_i x_i (1 - x_i).

The final serial correlation values multiplied by dx are still recomputed with the official `np.correlate` function for all scores; the formulas above are needed for defining smooth quantities, active constraints, and gradient rows.

2.3 Exact gradients of the individual correlation terms

For a lag/constraint bin p, define g_p(d)/dx? Use the derivative of the full Term including dx:

A row gradient row[p, :] = d q_p / dx? Avoid ambiguity. Define G_p[i] = dx * ∂ q_p(x_i) / ∂x_i.

Then sum of components belongs naturally, and the log-sum and SLSQP subproblems use G rows.

Give exact formulas and maintain coordinate compatibility with the correlation mapping from section 2.2.

For p:

D = p - (n - 1).

If D >= 0:

Initialize r = zeros(n).
L = n - D.
For each k in 0..L-1, term is:

x_{k+D} (1 - x_k).

Derivative:

∂/∂x_{k+D}: dx * (1 - x_k).

∂/∂x_k: - dx * x_{k+D}.

Therefore implement as:

r[D:D+L] += dx * (1.0 - x[0:L])

r[0:L] -= dx * x[D:D+L]

This adds all overlap terms. If the slices overlap for D < L, both derivatives correctly accumulate.

If D < 0:

a = -D, L = n - a.
For k in 0..L-1, term:

x_k (1 - x_{k+a}).

Derivative:

∂/∂x_k: dx * (1 - x_{k+a}).

∂/∂x_{k+a}: - dx * x_k.

Implement:

r[0:L] += dx * (1.0 - x[a:n])

r[a:n] -= dx * x[0:L]

For D = 0, the above D>=0 formulas together yield dx * (1 - 2 x_i) rowwise.

For finite difference validation, D=0 must be scored and row compared bubble.

1. Approach and rationale

1.1 Core diagnosis and new direction

The supplied parent is expected to have official score approximately 0.380958, while the target is 0.3808. The requested gain is only about 1.6e-4. The most valuable missing capability is not another generic broad global-random search, but a correct, tight, local cut-plane minimax projection that can move the parent through a nearly flat maximum plateau using exact, consistent derivative directions.

The prior pipeline suffered from three compounding problems. First, the smooth weighted-gradient implementation may not have exactly matched the derivative of the precise correlation bins used by the authoritative evaluator. Second, the active-set solve was a short-term smoothing and projection heuristic: it did not explicitly ask whether the current point can locally be shifted into a slightly smaller sublevel set of the actual maximum. Third, active constraints were selected and solved without a robust post-solve hidden-violation loop against the full exact objective.

The proposed primary algorithm is therefore a corrected-gradient active-cut local minimax solver. The essential new driver is that it solves local subproblems of the following two forms from a feasible parent x:

- Min-t problem: choose t as small as possible subject to selecting active constraints q_k(x) <= t, x feasible.
- Tau-projection problem: try to find a nearby feasible point with a whole selected active set satisfying q_k(x) <= tau, where tau is chosen slightly below the current best objective score. This forces a genuine sublevel improvement attempted in the active neighborhood.

This is materially different from ordinary smoothed gradient descent or crossed heuristic log-sum objective: the tau template directly encodes "we want an improvement below the current max," not just a smooth approximation. It is also exactAccept under the original evaluator throughout: unrelied unmodeled constraints and tau success are validated explicitly.

A correct active-set min-t problem captures these simultaneous stabilizing: the active rows impose necessary local zero direction and bound geometry. The tau projection gives a slight favorable descent of active directions to be improved below the apex, which is exactly the local problem needing to be solved for a bound below the supplied parent.
