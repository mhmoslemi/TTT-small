Actually, let me think about this more carefully. The "max of linear functions" minimization in 1D:

Given lines L_s(y) = c_s + d_s * y for s = 0, ..., 2n-2, find y ∈ [0,1] minimizing max_s L_s(y).

The function f(y) = max_s L_s(y) is convex and piecewise linear. Its minimum occurs either:
- At a "kink" point (intersection of two lines that form the upper envelope)
- At a boundary (y=0 or y=1)

To find it:
1. Evaluate f at y=0 and y=1
2. Find the point where the slope of f changes from negative to positive

The slope of f at y is: max of d_s among lines that achieve the max at y (subgradient). Actually, for a convex piecewise linear function, the slope is nondecreasing. The minimum is where the slope crosses 0.

More practically:
- At y=0, compute which s maximizes L_s(0). Let s* be that index.
- The slope at y=0+ is d_{s*} (approximately).
- If d_{s*} > 0, the minimum is at y=0.
- If d_{s*} < 0, we need to increase y. The function f will stay at L_{s*} until it intersects another line. Find the next kink point.
- Continue until the slope becomes positive.

This is the "megiddo" or "parametric search" approach for 1D convex optimization. It's O(n) per evaluation and O(n log n) total if we're careful.

1. Compute all intersection points of pairs of lines (O(n²) points)
2. Filter to those in [0,1]
3. Evaluate f at each candidate (O(n) per evaluation, O(n³) total)

Alternative: Use a simpler heuristic. Since f is convex in y:
- If f(0) < f(1) and the slope at 0 is ≥ 0, optimum is y=0
- If f(1) < f(0) and the slope at 1 is ≤ 0, optimum is y=1
- Otherwise, the optimum is in (0,1). Use bisection on the subgradient:
  - At each y, compute the set of active lines S(y) = {s : L_s(y) = f(y)}
  - The subgradient is the convex hull of {d_s : s ∈ S(y)}
  - If 0 is in the subgradient, we're at the optimum
  - If all d_s > 0 for s ∈ S(y), we need to decrease y
  - If all d_s < 0 for s ∈ S(y), we need to increase y

def _corr_values(h):
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def _project(z):

    target = n / 2.0
    z = np.nan_to_num(z, nan=0.5, posinf=1.0, neginf=0.0)

    res = target - h.sum()
    if res > 1e-10:
        idx = np.argsort(1.0 - h)[::-1]
        for i in idx:
            add = min(res, 1.0 - h[i])
            h[i] += add
            res -= add
            if abs(res) < 1e-14:
                break
    elif res < -1e-10:
        idx = np.argsort(h)[::-1]
        for i in idx:
            sub = min(-res, h[i])
            h[i] -= sub
            res += sub
            if abs(res) < 1e-14:

    es = float(np.sum(np.exp(sh)))
    if es < 1e-300:

    return mc + np.log(es) / beta

def _active_lse_grad(x, active_idx, beta):
    n = len(x)
    dx = 2.0 / n
    cv = _corr_values(x)
    cv_a = cv[active_idx]
    mc = float(cv_a.max())
    sh = np.clip(beta * (cv_a - mc), -500.0, 0.0)
    ev = np.exp(sh)
    es = float(ev.sum())
    if es < 1e-300:
        w_a = np.full(len(active_idx), 1.0 / len(active_idx))
    else:
        w_a = ev / es
    grad = np.zeros(n)
    for ii, k in enumerate(active_idx):
        wk = w_a[ii]
        if wk < 1e-15:
            continue
        s = k - (n - 1)
        c = dx * wk
        if s >= 0:
            m = n - s
            grad[:m] += c * (1.0 - x[s:])
            grad[s:] += -c * x[:m]
        else:
            r = -s
            m = n - r
            grad[r:] += c * (1.0 - x[:m])
            grad[:m] += -c * x[r:]
    return grad

    n = len(x)

    return _active_lse_grad(x, np.arange(2*n-1), beta)
