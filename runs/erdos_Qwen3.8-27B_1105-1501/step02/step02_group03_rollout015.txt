To minimize this, we want to maximize sum h[i]^2, which means making h as "peaked" as possible (some 1s and some 0s). But we also need to consider other lags.

For a 0-1 anti-symmetric function (where u[i] ∈ {0,1}), we have h[i] ∈ {0,1} and h[i]+h[n-1-i]=1. So exactly m of the h values are 1 and m are 0, with the complementary symmetry.

In this case, sum h[i]^2 = m = n/2, so c[n-1] = n/2 - n/2 = 0.

So for 0-1 anti-symmetric functions, the lag-0 overlap is 0! The challenge is the other lags.

This is a great insight. For 0-1 anti-symmetric functions, we only need to worry about non-zero lags. And the non-zero lag overlaps depend on how the 1s and 0s are arranged.

This is essentially a combinatorial optimization problem (for 0-1 case) or a continuous relaxation (for [0,1] case).

For the continuous case with anti-symmetry, the optimization is over u ∈ [0,1]^m to minimize max_p c[p] where c[p] are the correlation values.

        u_best = get_u_from_h(best_h)
        
        for beta in [50000, 200000, 1000000, 5000000]:
            if time.time() >= deadline:
                break
            st.n = n_best
            st.beta = beta
            try:
                res = minimize(
                    st.func, u_best, jac=st.jac,
                    method='L-BFGS-B',
                    bounds=[(0, 1)] * (n_best//2),
                    options={'maxiter': 500, 'ftol': 1e-16, 'gtol': 1e-12}
                )
                if res.x is not None and np.all(np.isfinite(res.x)):
                    u_new = np.clip(res.x, 0, 1)
                    h_new = build_h(u_new, n_best)
                    sc = official_score(h_new)
                    if np.isfinite(sc) and sc < best_score:
                        best_h = h_new.copy()
                        best_score = sc
                        u_best = u_new
            except Exception:
                pass
    
    # Phase 3: Random restarts
    if time.time() < deadline:
        n_best = len(best_h)
        u_best = get_u_from_h(best_h)
        m = n_best // 2
        st.n = n_best
