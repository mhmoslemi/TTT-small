`np.correlate(a, v)` is defined as:
(corr)[k] = sum_n a[n+k] * v[n]

where the sum is over all n such that 0 ≤ n < len(v) and 0 ≤ n+k < len(a).

So for our case with a = h, v = (1-h), both of length n:
corr[k] = sum_{n: max(0,-k) ≤ n ≤ min(n-1, n-1-k)} h[n+k] * (1-h[n])

For k ≥ 0: n ranges from 0 to n-1-k, so corr[k] = sum_{n=0}^{n-1-k} h[n+k] * (1-h[n])
For k < 0: n ranges from -k to n-1, so corr[k] = sum_{n=-k}^{n-1} h[n+k] * (1-h[n])

In mode='full', the output is indexed from 0 to 2n-2, where the actual shift is k - (n-1). So:
out[0] corresponds to k = -(n-1): sum from n=n-1 to n-1: h[0]*(1-h[n-1])
out[n-1] corresponds to k = 0: sum from n=0 to n-1: h[n]*(1-h[n])
out[2n-2] corresponds to k = n-1: sum from n=0 to 0: h[n-1]*(1-h[0])

OK so the gradient of out[k] (where k is the full-mode index, shift s = k-(n-1)) with respect to h[i]:

Case 1: s ≥ 0 (k ≥ n-1)
out[k] = sum_{n=0}^{n-1-s} h[n+s] * (1-h[n])
∂out[k]/∂h[i] = 
  - From h[n+s] term: if i = n+s for some valid n, i.e., n = i-s ≥ 0 and n ≤ n-1-s, i.e., i-s ≥ 0 and i ≤ n-1, contribution: (1-h[i-s])
  - From (1-h[n]) term: if i = n for some valid n, i.e., i ≥ 0 and i ≤ n-1-s, contribution: -h[i+s]
  
  So: ∂out[k]/∂h[i] = (1-h[i-s]) * [i-s ≥ 0 and i ≤ n-1] - h[i+s] * [i ≥ 0 and i ≤ n-1-s]

Case 2: s < 0 (k < n-1), let s' = -s > 0
out[k] = sum_{n=s'}^{n-1} h[n-s'] * (1-h[n])
∂out[k]/∂h[i] = 
  - From h[n-s'] term: if i = n-s', i.e., n = i+s' ≥ s' and n ≤ n-1, i.e., i ≥ 0 and i ≤ n-1-s', contribution: (1-h[i+s'])
  - From (1-h[n]) term: if i = n, i.e., i ≥ s' and i ≤ n-1, contribution: -h[i-s']
  
  So: ∂out[k]/∂h[i] = (1-h[i+s']) * [i ≥ 0 and i ≤ n-1-s'] - h[i-s'] * [i ≥ s' and i ≤ n-1]

This matches what I had before. Good.

Now, the gradient of the LSE objective:
∂/∂h[i] [max_k out[k] + (1/beta)*log(sum_k exp(beta*(out[k] - max_k)))]
= sum_k w[k] * ∂out[k]/∂h[i]

where w[k] = exp(beta*(out[k] - max_k)) / sum_j exp(beta*(out[j] - max_j))

Now let me think about the main algorithm. I'll use a multi-phase approach:

Phase 1: Quick screening over different n values
Phase 2: LSE-SLSQP with adaptive beta
Phase 3: Coordinate descent polish
Phase 4: Binary local search (if time permits)

Let me also think about the coordinate descent step. For a given h, the score is max_k C(k). If we change h[i] by a small amount δ, the change in C(k) is δ * ∂C(k)/∂h[i] (to first order). So to reduce the maximum, we want to make h[i] move in the direction that reduces the most-violated C(k).

For the most-violated lag k*, the optimal direction for h[i] is:
- If ∂C(k*)/∂h[i] > 0, decrease h[i]
- If ∂C(k*)/∂h[i] < 0, increase h[i]

But we also need to maintain the sum constraint and box constraints.

Actually, a simpler approach: use the gradient of the LSE objective (with very large beta, so it's approximately the gradient of the max) and do a projected gradient step.

from scipy.optimize import minimize
import time

    n = len(h)
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def _corr_vec(h):
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def _project(z):
    n = len(z)
    target = n / 2.0
    z = np.nan_to_num(z, nan=0.5, posinf=1.0, neginf=0.0)
    lo = -2.0 - np.max(z)
    hi = 2.0 - np.min(z)
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(z + mid, 0.0, 1.0))
        if s < target:
            lo = mid
        else:
            hi = mid
    h = np.clip(z + (lo + hi) / 2.0, 0.0, 1.0)
    res = target - h.sum()
    if abs(res) > 1e-12:
        if res > 0:
            idx = np.argsort(1.0 - h)[::-1]
        else:
            idx = np.argsort(h)[::-1]
        for i in idx:
            if res > 0:
                add = min(res, 1.0 - h[i])
            else:
                add = max(res, h[i] - 1.0)
            if abs(add) < 1e-16:
                break
            h[i] += add
            res -= add
    return np.clip(h, 0.0, 1.0)

def _lse_obj(x, beta):
    cv = _corr_vec(x)
    mc = cv.max()
    sh = np.clip(beta * (cv - mc), -500, 0)
    es = np.sum(np.exp(sh))
    if es < 1e-300:
        return mc
    return mc + np.log(es) / beta

def _lse_grad(x, beta):
    n = len(x)
    cv = _corr_vec(x)
    mc = cv.max()
    sh = np.clip(beta * (cv - mc), -500, 0)
    ev = np.exp(sh)
    es = ev.sum()
    if es < 1e-300:
        w = np.full(2 * n - 1, 1.0 / (2 * n - 1))
    else:
        w = ev / es

        else:
            sp = -s
            g[sp:] += wk * (-x[:n-sp])
            g[:n-sp] += wk * (1.0 - x[sp:])
    return g

def _slsqp_lse(h0, beta, maxiter=100):
    n = len(h0)
    bounds = [(0.0, 1.0)] * n
    
    def _efun(x):
        return x.sum() - n / 2.0
    
    def _ejac(x):
        return np.ones(n)
    
    try:
        res = minimize(_lse_obj, h0, args=(beta,), jac=_lse_grad,
                       method='SLSQP', bounds=bounds,
                       constraints=[{'type': 'eq', 'fun': _efun, 'jac': _ejac}],
                       options={'maxiter': maxiter, 'ftol': 1e-14})
        if hasattr(res, 'x') and np.all(np.isfinite(res['x'])):
            return _project(res['x'])
    except Exception:
        pass
    return h0

def _cg_smooth(h0, beta, n_steps=2000, lr_init=0.01):
    """Conjugate gradient with backtracking line search on LSE objective."""
    n = len(h0)
    x = h0.copy()
    g = _lse_grad(x, beta)
    d = -g
    f = _lse_obj(x, beta)
    best_x = x.copy()
    best_f = f
    
    for step in range(n_steps):
        # Backtracking line search
        lr = lr_init
        for _ in range(30):
            x_new = _project(x + lr * d)
            f_new = _lse_obj(x_new, beta)
            if f_new < f:
                break
            lr *= 0.5
        else:
            break
        
        x = x_new
        f = f_new
        if f < best_f:
            best_f = f
            best_x = x.copy()
        
        g_new = _lse_grad(x, beta)
        if np.max(np.abs(g_new)) < 1e-12:
            break
        
        # Polak-Ribiere
        dg = np.dot(g_new - g, d)
        g2 = np.dot(g_new, g_new)
        if g2 < 1e-30:
            beta_cg = 0
        else:
            beta_cg = max(0, dg / g2)
        d = -g_new + beta_cg * d
        g = g_new
    
    return best_x

    """Coordinate descent targeting the top-m lags."""
    n = len(h)
    h = h.copy()
    best_s = _score(h)
    
    for rnd in range(n_rounds):
        cv = _corr_vec(h)
        mc = cv.max()
        
        # Get top-m lags
        idx = np.argsort(cv)[::-1][:top_m]
        
        improved = False

            best_local_s = mc  # current max

            candidates = [h[i]]

            for delta in [0.01, -0.01, 0.05, -0.05, 0.1, -0.1]:
                v = h[i] + delta
                if 0 <= v <= 1:
                    candidates.append(v)
            # Also try the "optimal" for the top lag
            # For lag s, the contribution from h[i] is...
            
            for v in candidates:
                h[i] = v
                # Adjust to maintain sum (simple: adjust the element farthest from 0.5)
                # Actually, this breaks the sum constraint. Let's use a different approach.
                h[i] = best_val

        g = _lse_grad(h, beta=100)
        # Projected gradient step

            s_new = _score(h_new)
            if s_new < best_s:

                best_s = s_new
