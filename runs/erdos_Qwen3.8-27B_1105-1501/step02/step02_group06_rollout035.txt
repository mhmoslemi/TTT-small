5. If the solution achieves the true objective ≤ t, we're done
6. Otherwise, add a new cut (linearization at the new point) and go to 3

This is essentially a cutting plane / outer approximation method. It should converge to a local optimum (since we're dealing with a nonconvex problem, it's a local outer approximation).

    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

    """Correct gradient of f_s with respect to h."""
    n = len(h)
    g = np.zeros(n)
    if s >= 0:
        for j in range(n):
            if j <= n - 1 - s:
