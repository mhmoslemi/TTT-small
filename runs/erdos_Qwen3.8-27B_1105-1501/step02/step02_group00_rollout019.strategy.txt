1. Approach and rationale

1.1 Central idea
The dominant reason the supplied upper bound can remain close to but slightly above the record is that the search tends to optimize one active linearization or one one-dimensional descent scheme of the nonconvex max-over-shift objective. At high quality solutions, almost every improvement requires a coordinated redistribution of several entries of `h` across many simultaneously active lags. A single-variable line search, a pure active-set LP linearization, or a purely local projected-gradient descent can satisfy only one active pattern and then stall.

The proposed algorithm is materially different because it changes the local optimization primitive. Instead of repeatedly constructing a linear direction and doing a scalar exact line search, it formulates the nonconvex problem explicitly with an auxiliary maximum variable and solves a local, smooth constrained nonlinear program:

- decision variable: `y = [h_0, ..., h_{N-1}, z]`
- objective: minimize `z`
- constraints: for every correlation lag, `z - score_lag(h) >= 0`, plus `sum_i h_i = N/2` and `0 <= h_i <= 1`

This epigraph formulation allows a smooth optimizer (SciPy SLSQP) to adjust all coordinates jointly so that the largest patterns of `h` and `1-h` are in one competitive equilibrium. Because the current score formula is explicit and differentiable, the optimizer receives exact analytical Jacobians for all constraints. The true nonconvexity remains, so every proposed solution must still be checked by the uncached original evaluator.

This plan also uses diverse feasible starts, exact symmetric/stratified pool combinations, exact-feasibility-compatible pair moves, binary local search, and short multi-resolution trials. The old parent best is retained as fallback, and every accepted candidate is judged by the exact evaluator from the task statement. The result is a basin-diverse KKT-continuation method rather than a single active-set LP descent method.

1.2 Why this can improve the parent
The parent optimum is expected to lie near the boundary of the linear-convex feasible polytope and to have many active correlation-lag constraints. The epigraph nonlinear program can move directly along the feasible face `sum(h)=N/2`, using `z` as a dynamic variable. When the current solution has, for example, several lags near the maximum, SLSQP can trade small conditional changes across many h widgets to reduce the margin between active lags and follow a quality route. More concretely, it can solve for an interior equality point instead of jumping at short grid points, and the exact acceptance test ensures that any move, even from a nonexact solver reported answer, is accepted only when it strictly improves the actual task metric. This kind of active-set balancing is not readily represented by a one-scalar linearization. Explicit solver status within tolerance or even infeasible status can yield useful feasible candidate regions if their final repaired vectors improve the exact bound.

1. Approach and rationale

1.1 Central mathematical idea

This plan uses a multi-basin local iteration on the exact nonconvex finite-dimensional epigraph formulation of the objective. The optimization variable is augmented with a scalar `z` that represents the largest unscaled correlation score. In each candidate run a smooth local constrained nonlinear program is solved:

- minimize `z`
- subject to `score_tau(h) <= z` for every finite-support correlation lag `tau`
- subject to `0 <= h_i <= 1` for all grid indices
- subject to `sum_i h_i == N/2`

The important difference from the previous parent strategy is that the primary local update mechanism is no longer one active LP linearization plus a one-dimensional line search. SLSQP receives exact gradient information for all correlation-lag constraints and can coordinate many coordinates simultaneously in order to “re-lever” the top active and near-active lags. This tends to reduce the gap between many near-tied constraints rather than using a few greedy active inequalities. It borrows the positive parts of previous parent construction but changes the search object: active-set/LP gradient descent vs. looser KKT-search from dynamic balance of all constraints.

The method is nonconvex because `score_tau(h)` is bilinear. Therefore no global proof of optimality can be made. Every claimed improvement must be judged with the uninterpolated original evaluator using `np.correlate(h, 1-h,'full')`. Initial parent, if supplied and correctly feasible (after utility repair), is always retained as an exact fallback candidate. The outer framework builds a pool that is diversified by symmetrization, binary thresholding, simple deterministic profile structures, cheap exact symmetric moves, convex mixtures, and optional resampling. This framework is materially different because the overwhelming local decision engine is SLSQP in epigraph space, while multiple basin seeds prevent it from repeatedly returning to only the starting local optimum.
