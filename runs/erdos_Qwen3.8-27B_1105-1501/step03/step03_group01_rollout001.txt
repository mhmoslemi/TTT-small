Let me analyze the problem carefully:

1. We need to find a step function h: [0,2] → [0,1] that minimizes C₅ = max_k ∫ h(x)(1-h(x+k)) dx
2. With discretization: n points over [0,2], dx = 2/n, sum(h)*dx = 1, so sum(h) = n/2
3. Current record: C₅ ≤ 0.38085, target is 0.3808
4. Previous program achieved 0.380917

The key insight from the strategy is to use exact one-dimensional line search over mean-preserving directions. The idea is:
- For a direction P with sum(P) = 0, the path h(t) = h + tP preserves the mass constraint
- The correlation along this path is quadratic in t for each lag
- We can find the exact minimum of max over all lags along this line

Let me think about what would actually work well here:

1. The LP-based approach in the previous code is good but slow for large n
2. The key improvement should come from better direction generation and faster line search

Let me think about the mathematical structure more carefully:

For h discretized at n points, we have:
- corr[d] = sum_i h[i] * (1 - h[i+d]) for valid i (this is what np.correlate computes)
- C₅ = dx * max_d corr[d]

For a direction P with sum(P) = 0:
- h(t) = h + tP
- corr_d(t) = sum_i (h[i] + tP[i]) * (1 - h[i+d] - tP[i+d])
  = sum_i h[i](1-h[i+d]) + t * sum_i (P[i](1-h[i+d]) - h[i]P[i+d]) - t² * sum_i P[i]P[i+d]

So for each lag d, corr_d(t) is a quadratic in t: a_d + b_d * t + c_d * t² where c_d ≤ 0 (since -sum P[i]P[i+d]... wait, not necessarily negative).

Actually c_d = -sum_i P[i]*P[i+d], which can be positive or negative.

The objective is max_d (a_d + b_d*t + c_d*t²) * dx.

This is a piecewise-quadratic function (max of quadratics), which is convex (max of convex functions... wait, quadratics with negative leading coefficient are concave, not convex).

Actually, the max of concave functions is not necessarily convex. So the line search could be complex. But in practice, the max is achieved by one or a few lags, so we can:
1. Identify the active lags (those achieving the max)
2. Find the minimum of the max over those active lags

A simpler approach: sample t on a grid, find the best t, then refine with golden section or ternary search on the sub-interval.

Let me think about a different approach that might be more effective:

**Approach: Subgradient/active-set method with exact 1D optimization**

1. Start from initial_h_values
2. At each iteration:
   a. Compute all lag correlations
   b. Identify the top-k lags (k small, like 3-5)
   c. Generate candidate directions:
      - Direction that directly reduces the top lag
      - Gradient of the sum of top-k lags (subgradient of max)
      - Random mean-zero directions
   d. For each direction, do exact 1D line search (bracketing + refinement)
   e. Accept the best improvement

The key difference from the previous approach:
- Use exact quadratic formulas for the line search (faster than repeated correlation)
- Better direction generation focused on the active constraints
- More aggressive trust region management

Let me also think about the LP approach. The LP at each step solves:
minimize t
subject to: G * p - t * 1 ≤ -scores, sum(p) = 0, |p| ≤ radius

This finds the direction that most rapidly decreases the maximum correlation. It's good but expensive.

A faster alternative: just use the subgradient of the max. If lag d* is the argmax, then the subgradient of the objective with respect to p is the row G[d*]. The negative of this gives the steepest descent direction for that particular lag.

But we need to project this to be mean-zero. So: d = -G[d*], then p = d - mean(d).

Then do exact 1D search along p.

    # Grid search
    ts = np.linspace(t_lo, t_hi, n_samples)

    # Refine with golden section around best

        lo_t = t_lo

    f2 = obj(c2)
    
    for _ in range(n_refine):
        if hi_t - lo_t < 1e-14:

            f2 = f1

def _lp_direction(h, scores, G, radius):
    """LP-based direction finding (from previous code, kept for comparison)."""
    n = len(h)
    c = np.zeros(n + 1)
    c[-1] = 1.0
    A_ub = np.zeros((2 * n - 1, n + 1))
    A_ub[:, :n] = G
    A_ub[:, n] = -1.0
    b_ub = -scores
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.zeros(1)
    bounds = [(max(-radius, -h[j]), min(radius, 1.0 - h[j])) for j in range(n)]
    bounds.append((None, None))
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs')
        if res.success:
            return res.x[:n]
    except Exception:
        pass
    return None

def _grad_matrix(h):
    """Build the 2n-1 x n gradient matrix G where G[k,j] = d(corr_k)/dh[j]."""
    n = len(h)
    G = np.zeros((2 * n - 1, n))
    
    # For k >= 0 (index n-1+k in full output): D[k] = sum_{n=0}^{n-1-k} h[n+k]*(1-h[n])
    for k in range(n):
        for j in range(n):
            contrib = 0.0
            if k <= j <= n - 1:
                contrib += (1.0 - h[j - k])
            if 0 <= j <= n - 1 - k:
                contrib += (-h[j + k])
            G[n - 1 + k, j] = contrib
    
    # For k < 0 (index n-1-k in full output, k = -g): D[-g] = sum_{m=0}^{n-1-g} h[m]*(1-h[m+g])
    for g in range(1, n):
        for j in range(n):
            contrib = 0.0
            if 0 <= j <= n - 1 - g:
                contrib += (1.0 - h[j + g])
            if g <= j <= n - 1:
                contrib += (-h[j - g])
            G[n - 1 - g, j] = contrib
    
    return G

        vals[i] = obj(ts[i])
    
    best_i = int(np.argmin(vals))
    best_t = ts[best_i]
    best_val = vals[best_i]
    
    # Golden section refinement
    if best_i > 0:
        lo_t = ts[best_i - 1]
    else:
        lo_t = t_lo
    if best_i < n_grid - 1:
        hi_t = ts[best_i + 1]
    else:
        hi_t = t_hi
    
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    c1 = hi_t - gr * (hi_t - lo_t)
    c2 = lo_t + gr * (hi_t - lo_t)
    f1 = obj(c1)
    f2 = obj(c2)
    
    for _ in range(32):
        if hi_t - lo_t < 1e-14:
            break
        if f1 < f2:
            hi_t = c2
            c2 = c1
            f2 = f1
            c1 = hi_t - gr * (hi_t - lo_t)
            f1 = obj(c1)
        else:
            lo_t = c1
            c1 = c2
            f1 = f2
            c2 = lo_t + gr * (hi_t - lo_t)
            f2 = obj(c2)
    
    opt_t = (lo_t + hi_t) / 2.0
    opt_val = obj(opt_t)
    if opt_val < best_val:
        best_t, best_val = opt_t, opt_val
    
    return best_t, best_val

def _resample(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return _project(h_new, n_new / 2.0)

def _soft_grad_direction(h, tau):
    """Generate direction from softmax-weighted subgradient."""
    n = len(h)
    dx = 2.0 / n
    scores = np.correlate(h, 1.0 - h, mode='full') * dx
    max_s = float(np.max(scores))
    exp_s = np.exp(tau * (scores - max_s))
    w = exp_s / float(np.sum(exp_s))
    
    G = _grad_matrix(h)
    direction = -float(np.dot(w, G))
    direction = _zero_mean(direction)
    return direction

def _make_direction_base(h, n_dir, rng, mode):
    """Generate diverse candidate directions."""
    n = len(h)
    dirs = []
    
    if mode == 0:
        # Subgradient of top-1
        scores = np.correlate(h, 1.0 - h, mode='full')
        top_k = int(np.argmax(scores))
        G = _grad_matrix(h)
        d = -G[top_k].copy()
        dirs.append(_zero_mean(d))
    elif mode == 1:
        # Subgradient of top-3
        scores = np.correlate(h, 1.0 - h, mode='full')
        top_idx = np.argsort(scores)[-3:]
        G = _grad_matrix(h)
        d = -np.mean(G[top_idx], axis=0)
