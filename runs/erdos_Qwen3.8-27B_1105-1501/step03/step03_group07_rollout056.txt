- ||d||_1 <= R (bounded step)
- The predicted maximum is minimized: min t

Using split variables p_j = max(d_j, 0), q_j = max(-d_j, 0), d_j = p_j - q_j:
- Variables: t, p_0, ..., p_{N-1}, q_0, ..., q_{N-1} → 2N+1 variables
- All p_j, q_j >= 0
- p_j = 0 if h_j is at its upper bound (h_j ≈ 1)
- q_j = 0 if h_j is at its lower bound (h_j ≈ 0)
- Objective: minimize t + λ * sum(p_j + q_j)  [λ for penalty on step size, or use explicit bound]
- Constraints:
  - t - sum_j (grad[r][j] * p_j - grad[r][j] * q_j) >= O[r] for active r

  - sum_j (p_j + q_j) <= R

This is a standard LP with 2N+1 variables and about (num_active + 2) constraints.
