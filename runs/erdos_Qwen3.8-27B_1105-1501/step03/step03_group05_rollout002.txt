1. Computing all the slopes L_k
2. The piecewise-linear (plus 2 quadratic bump) function's minimum can be found by checking where the max of the upper envelope achieves its minimum.

For a pure piecewise-linear function (all slopes, no quadratics), the minimum of max_k (a_k + b_k * δ) over δ in [δ_min, δ_max] occurs at:
- δ_min or δ_max (boundary), or
- A point where two (or more) of the lines are simultaneously at their maximum (a "crossing point" of the upper envelope).

With the quadratic terms, the picture is slightly more complex but still tractable. The quadratic terms have positive curvature, which means they push the maximum up for large |δ|, which can only help (the minimum will be at or near where the linear terms cross).

1. Generate candidate δ values: δ_min, δ_max, 0, and all crossing points of pairs of the (nearly) linear score functions.
2. For each candidate, evaluate the exact max.
3. Pick the best.

minimize t
subject to: t ≥ score_k(h) * dx for all k = 0, ..., 2n-2

The gradient of score_k with respect to h is the G matrix I described. We can compute it analytically.

For SLSQP, we need:
- Objective: f(x) = t (just the first variable)
- Constraints: t - score_k(h)*dx ≥ 0 for all k; sum(h) - n/2 = 0; 0 ≤ h[i] ≤ 1
- Gradient of objective: [1, 0, 0, ..., 0]
- Jacobian of constraints: can be computed from G matrix

This is a linearly-constrained problem in t (the t-constraints are linear in t), and the h-constraints involve bilinear terms (h * (1-h)), so it's not convex. But SLSQP can handle local nonconvexity.
