1. Approach and rationale

### 1.1 Central idea

The parent construction is already a high-quality local point. The remaining gap to the target is tiny, so brute-force local epigraph methods are very likely only polishing the same basin. The proposed method is materially different because it changes both the representation and the search mechanism:

1. First search a lower-dimensional, exactly feasible subspace generated by anti-periodic complement pairs:
   `H(y) = [y, 1-y]`, where `y` has `n/2` coordinates. For every `y` in `[0,1]^{n/2}`, the enlarged vector automatically satisfies `0 <= H_i <= 1` and `sum(H) = n/2`. This makes global search possible without equality penalties, formulas, or post-repair.

2. Use a derivative-free global optimizer over this low-dimensional feasible manifold, specifically scipy `differential_evolution`, initialized from the parent and from a feasible anti-complement projection of the parent. This explores structures outside the parent’s local basin while ensuring that every trial point returned by the global search is exactly feasible.

3. Promotion from a candidate family to exact full-space refinement uses feasibility-preserving active-direction line searches. At a vector `h`, compute the exact inactive/active correlation scores with the evaluator’s finite-support full correlation. Build search directions from a smooth maximum over all lags or a uniform average over only near-maximal lags. Each direction is forced to sum to zero. Then an exact objective is minimized only over the interval of positive step sizes that keeps every coordinate in `[0,1]` and the linear sum exactly unchanged. Because the exact final objective is recomputed with the original evaluator, smooth maximum failure is harmless.

4. A final exact pairwise transfer step gives feasibility-preserving one-dimensional local adjustments that can move mass between two coordinates while preserving `sum(h)` exactly. This complements multi-coordinate group directions.

The method is a heuristic global-plus-exact-local scheme. It does not claim a global optimum, and it does not prove that the returned bound is optimal. It only produces a verified upper bound for the discrete objective whenever a better feasible candidate is found. If the parent is already acceptable or the method fails, the code returns the best exact feasible candidate, including the parent.

### 1.2 What problem this targets

The hardest methodological bottleneck is that the original nonconvex epigraph formulation is very sensitive to hidden lags and feasibility repair. A generic continuous optimizer can improve the currently selected active constraints by increasing another lag, and projection after clipping can erase a tiny improvement. The proposed design reduces or avoids both issues:

- Global search leaves local basins only in quantities that are feasible by construction.
- Local refinement only accepts candidates using the exact `np.correlate(h, 1-h, "full")` metric.
- Every line and transfer direction is explicitly mean-zero and step-limited by box constraints. Hence there is no repair-induced improvement erosion during the primary optimization steps. A small joint feasibility repair is still available as final insurance.
