Let me think about this differently. The objective is F(h) = max_k f_k(h). At the current point h, suppose the active set is A = {k : f_k(h) = F(h)}. A descent direction must satisfy ∇f_k · d < 0 for all k in A (and ideally for all k, or at least for k close to active).

The LP finds a direction that decreases all f_k simultaneously (in the linear approximation). This is a strong condition that might be too restrictive. A better approach:

1. Compute the "margin" for each k: margin_k = F(h) - f_k(h) >= 0
2. We want ∇f_k · d * t < -margin_k * epsilon for some epsilon
3. Or more simply: we want the new max to be less than F(h)
4. Linear approximation: new F ≈ max_k (f_k + t * ∇f_k · d)
5. We want max_k (f_k + t * ∇f_k · d) < F(h)
6. For all k: f_k + t * ∇f_k · d < F(h), i.e., t * ∇f_k · d < F(h) - f_k = margin_k
7. For active k (margin_k = 0): t * ∇f_k · d < 0, so ∇f_k · d < 0 (for t > 0)
8. For inactive k: ∇f_k · d < margin_k / t

For step size t, the constraint is ∇f_k · d < margin_k / t for all k.

If we don't fix t, we can just require ∇f_k · d < 0 for active k, and ∇f_k · d < margin_k / t_max for others (with some t_max).
