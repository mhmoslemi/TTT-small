Let me analyze the problem and strategy carefully.

The key idea is to use exact one-dimensional line descent. For a feasible point `h` and a zero-sum direction `v`, the correlation scores along the line `h + alpha*v` are exact quadratics in alpha:

```
A(alpha) = A + alpha*B + alpha^2*C
```

where:
- `A = np.correlate(h, 1-h, 'full')`
- `B = np.correlate(v, 1-h, 'full') - np.correlate(h, v, 'full')`
- `C = -np.correlate(v, v, 'full')`

Then we minimize the maximum of these quadratics over the feasible alpha interval.

Let me verify the bilinearity:

Wait, that's not quite right either. Let me think again.

`np.correlate(x, y)` where x and y are the two inputs. It's bilinear:
`correlate(x1 + x2, y1 + y2) = correlate(x1,y1) + correlate(x1,y2) + correlate(x2,y1) + correlate(x2,y2)`

So: `correlate(h + a*v, (1-h) - a*v)`
`= correlate(h, 1-h) + correlate(h, -a*v) + correlate(a*v, 1-h) + correlate(a*v, -a*v)`
`= correlate(h, 1-h) - a*correlate(h, v) + a*correlate(v, 1-h) - a^2*correlate(v, v)`

So:
- `A = correlate(h, 1-h)`
- `B = -correlate(h, v) + correlate(v, 1-h)`
- `C = -correlate(v, v)`

This matches what was in the strategy. Good.

- For each coordinate i where v[i] > 0: alpha <= (1 - h[i]) / v[i], alpha >= -h[i] / v[i]
- For each coordinate i where v[i] < 0: alpha <= (1 - h[i]) / v[i] (which is negative), alpha >= -h[i] / v[i]

Actually let me redo this. We need 0 <= h[i] + alpha*v[i] <= 1 for all i.

If v[i] > 0:
- h[i] + alpha*v[i] >= 0 => alpha >= -h[i]/v[i]
- h[i] + alpha*v[i] <= 1 => alpha <= (1-h[i])/v[i]

If v[i] < 0:
- h[i] + alpha*v[i] >= 0 => alpha <= -h[i]/v[i]  (dividing by negative flips inequality)
- h[i] + alpha*v[i] <= 1 => alpha >= (1-h[i])/v[i]  (dividing by negative flips inequality)

If v[i] = 0: no constraint from this coordinate.

So overall:
- alpha_low = max over all i of the lower bounds
- alpha_high = min over all i of the upper bounds

- alpha_high = min(upper bounds, but must be >= 0)

Actually since h is feasible, alpha=0 is in the interval, so alpha_low <= 0 <= alpha_high automatically.

Now for finding the minimum of max of quadratics on [alpha_low, alpha_high]:

For each quadratic q_r(a) = A[r] + B[r]*a + C[r]*a^2, we want to minimize max_r q_r(a).

The minimum of a max of functions occurs either at:
1. A point where two (or more) quadratics are simultaneously at their maximum and their derivatives are equal (envelope point), or
2. A stationary point of one of the quadratics that is also the maximum, or
3. An endpoint of the interval.

For pairwise intersections: solve q_i(a) = q_j(a), i.e., (C[i]-C[j])*a^2 + (B[i]-B[j])*a + (A[i]-A[j]) = 0.

This is a quadratic in a with at most 2 real roots.

For n=64, we have 2*64-1 = 127 quadratics. Pairwise intersections: C(127,2) = 8001 pairs. Each gives at most 2 roots. Plus 127 stationary points. Plus 2 endpoints. Plus a grid. def _smooth_direction(h, beta):
    """Generate a smooth gradient direction."""
    n = len(h)
    scores = np.correlate(h, 1.0 - h, mode='full')
    max_s = float(np.max(scores))
    exp_vals = np.exp(beta * (scores - max_s))
    w = exp_vals / float(np.sum(exp_vals))
    
    # Build gradient: grad[i] = sum_d w[d] * dS_d/dh[i]
    # dS_d/dh[i] for lag d: 
    # S_d = sum_p h[p+d]*(1-h[p])
    # dS_d/dh[i] = (1-h[i-d]) if i-d is valid (as the h[p+d] term) - h[i+d] if i+d is valid (as the -h[p] term)
    # More precisely:
    # For offset d, S_d = sum_{p=low}^{high-1} h[p+d]*(1-h[p])
    # dS_d/dh[i] = (1-h[i-d]) * [0 <= i-d < n and 0 <= i < n] - h[i+d] * [0 <= i < n and 0 <= i+d < n]
    # Wait, let me be more careful.
    # S_d = sum_{p: valid} h[p+d] * (1 - h[p])
    # where valid means 0 <= p < n and 0 <= p+d < n
    # dS_d/dh[i]:
    #   i appears as (p+d) when p = i-d: contributes (1-h[i-d]) if 0<=i-d<n and 0<=i<n
    #   i appears as p: contributes -h[i+d] if 0<=i<n and 0<=i+d<n
    # So dS_d/dh[i] = (1-h[i-d])*(i-d in [0,n-1] and i in [0,n-1]) + (-h[i+d])*(i in [0,n-1] and i+d in [0,n-1])
    
    grad = np.zeros(n)
    for d in range(-(n-1), n):
        wd = w[n - 1 + d]
        if abs(wd) < 1e-15:
            continue
        if d >= 0:
            # p+d <= p+n-1, so p ranges from 0 to n-1-d
            # h[p+d] term: i = p+d ranges from d to n-1, contributes (1-h[i-d])
            # -h[p] term: i = p ranges from 0 to n-1-d, contributes -h[i+d]
            m = n - d
            for i in range(d, n):
                grad[i] += wd * (1.0 - h[i - d])
            for i in range(0, m):
                grad[i] += wd * (-h[i + d])
        else:
            g = -d
            # p+d >= 0 means p >= d, so p ranges from -d to n-1
            # h[p+d] term: i = p+d ranges from 0 to n-1-g, contributes (1-h[i-d]) = (1-h[i+g])
            # -h[p] term: i = p ranges from g to n-1, contributes -h[i+d] = -h[i-g]
            m = n - g
            for i in range(0, m):
                grad[i] += wd * (1.0 - h[i + g])
            for i in range(g, n):
                grad[i] += wd * (-h[i - g])
    
    v = -grad
    v = v - np.mean(v)
    return v

The correlation in `np.correlate(h, 1-h, mode='full')`:

`np.correlate(a, v, mode='full')` computes:

            v = _biased_random_direction(rng, n, h)
            result = _exact_line_step(h, v, cur_c5)
            if result is not None:
                h, cur_c5 = result
                if cur_c5 < best_c5:
                    best_h = h.copy()
                    best_c5 = cur_c5
                no_improve = 0
                improved = True
                break
        if improved:
            continue
        for _ in range(15):
            if time.time() > deadline:
                break
            i = int(rng.integers(n))
            j = int(rng.integers(n))
            if i == j:
                continue
            v = np.zeros(n)
            v[i] = 1.0
            v[j] = -1.0
            result = _exact_line_step(h, v, cur_c5)
            if result is not None:
                h, cur_c5 = result
                if cur_c5 < best_c5:
                    best_h = h.copy()
                    best_c5 = cur_c5
                no_improve = 0
                improved = True
                break
        if improved:
            continue
        no_improve += 1
    return best_h, best_c5


def _flip(h):
    return h[::-1].copy()


def _roll(h, k):
    return np.roll(h, k).copy()


def _binary_threshold(h):
    n = len(h)
    h_bin = np.zeros(n)
    h_bin[:n // 2] = 1.0
    return _repair_box_sum(h_bin, n / 2.0)


def _snap_binary(h, threshold=0.3):
    n = len(h)
    h_new = h.copy()
    h_new[h_new < threshold] = 0.0
    h_new[h_new > 1.0 - threshold] = 1.0
    return _repair_box_sum(h_new, n / 2.0)


def _resample(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return _repair_box_sum(h_new, n_new / 2.0)


def _mix(a, b, t):
    return t * a + (1.0 - t) * b


def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    rng = np.random.default_rng(seed)
    hard_deadline = t0 + budget_s * 0.96

    try:
        h0 = np.array(initial_h_values, dtype=float)
    except Exception:
        h0 = None

    if h0 is None or not np.all(np.isfinite(h0)) or len(h0) < 10:
        n0 = 64
        h0 = np.zeros(n0)
        h0[::2] = 1.0
        h0 = _repair_box_sum(h0, n0 / 2.0)

    n0 = len(h0)
    h = _repair_box_sum(h0, n0 / 2.0)
    best_h = h.copy()
    best_c5 = _exact_c5(h)
    best_n = n0

    # Phase 1: Deep line descent on parent resolution
    deadline1 = t0 + budget_s * 0.28
    h1, c5_1 = _local_line_descent(h, deadline1, rng, max_no_improve=400)
    if c5_1 < best_c5:
        best_c5 = c5_1
        best_h = h1.copy()

    # Phase 2: Transformations
    deadline2 = t0 + budget_s * 0.48
    transforms = [_flip(best_h)]
    for k in [1, -1, 2, -2, 3, -3, n0 // 4, -n0 // 4, n0 // 2]:
        transforms.append(_roll(best_h, k))
    transforms.append(_binary_threshold(best_h))
    transforms.append(_snap_binary(best_h, 0.25))
    transforms.append(_snap_binary(best_h, 0.4))
    for _ in range(6):
        pert = best_h + 0.08 * rng.standard_normal(n0)
        transforms.append(_repair_box_sum(pert, n0 / 2.0))
    transforms.append(_mix(best_h, _flip(best_h), 0.5))
    transforms.append(_mix(best_h, _roll(best_h, 1), 0.7))
    transforms.append(_mix(best_h, _binary_threshold(best_h), 0.6))

    per_t = max(5.0, (deadline2 - time.time()) / max(1, len(transforms)))
    for t_h in transforms:
        if time.time() > deadline2:
            break
        if t_h.shape != (n0,):
            continue
        t_h = _repair_box_sum(t_h, n0 / 2.0)
        t_c5 = _exact_c5(t_h)
        if t_c5 >= best_c5:
            sub_deadline = min(deadline2, time.time() + per_t * 0.4)
        else:
            sub_deadline = min(deadline2, time.time() + per_t)
        th, tc = _local_line_descent(t_h, sub_deadline, rng, max_no_improve=60)
        if tc < best_c5:
            best_c5 = tc
            best_h = th.copy()

    # Phase 3: Continue line descent on best
    deadline3 = t0 + budget_s * 0.60
    h3, c5_3 = _local_line_descent(best_h, deadline3, rng, max_no_improve=300)
    if c5_3 < best_c5:
        best_c5 = c5_3
        best_h = h3.copy()

    # Phase 4: Multi-resolution exploration
    deadline4 = t0 + budget_s * 0.84
    n_tries = sorted(set(x for x in
                         [best_n - 8, best_n - 4, best_n, best_n + 4,
                          best_n + 8, best_n + 16, best_n - 16,
                          32, 48, 56, 72, 80, 96, 112, 128]
                         if 16 <= x <= 200))
    remaining_n = len(n_tries)
    for n_try in n_tries:
        if time.time() > deadline4:
            break
        per_n = min(budget_s * 0.05, (deadline4 - time.time()) / max(1, remaining_n))
        remaining_n -= 1
        if per_n < 3.0:
            break
        h_r = _resample(best_h, n_try)
        deadline_r = min(deadline4, time.time() + per_n)
        h_r, c5_r = _local_line_descent(h_r, deadline_r, rng, max_no_improve=80)
        if c5_r < best_c5 - 1e-12:
            best_c5 = c5_r
            best_h = h_r.copy()
            best_n = n_try

    # Phase 5: Final deep polish
    deadline5 = t0 + budget_s * 0.95
    h5, c5_5 = _local_line_descent(best_h, deadline5, rng, max_no_improve=500)
    if c5_5 < best_c5:
        best_c5 = c5_5
        best_h = h5.copy()

    # Final feasibility check
    final_n = len(best_h)
    best_h = _repair_box_sum(best_h, final_n / 2.0)
    final_c5 = _exact_c5(best_h)
    if final_c5 > best_c5 + 1e-8:
        best_h = np.clip(best_h, 0.0, 1.0)
        final_c5 = _exact_c5(best_h)

    return best_h, final_c5, final_n
