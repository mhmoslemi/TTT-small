What about shifting? If we shift h by some amount (with wraparound or truncation), the scores change. But the integral is preserved only with wraparound, and the problem doesn't have wraparound (it's on [0,2] not a torus).

Actually, I realize I should think about what's special about this problem that might give structure.

The Erdos minimum overlap problem asks: what is the minimum possible value of max_k |∫ (h(x) - h(x+k))(1-h(x)(1-h(x+k))) dx| or something similar? Let me re-read the problem.

Actually the problem as stated is: minimize max_k ∫ h(x)(1-h(x+k)) dx.

This is the "overlap" between h and the complement of its shift. We want h to be as "spread out" as possible so that h and its shifted complements don't overlap much.

For the constant function h = 1/2 (which has integral 1 on [0,2]), the score is:
∫ (1/2)(1-1/2) dx = ∫ 1/4 dx = 1/4 = 0.25 for all k.
Wait, that gives C5 = 0.25? That can't be right since the current best is 0.38.

Oh wait, the integral is from 0 to 2, but h(x+k) is only defined where both x and x+k are in [0,2]. So for large |k|, the integral is over a shorter interval.

For h = 1/2 constant: ∫₀² h(x)(1-h(x+k)) dx = ∫₀^{2-|k|} (1/2)(1/2) dx = (1/4)(2-|k|) for |k| < 2, and 0 for |k| >= 2.
Maximum is at k=0: 2/4 = 0.5.

So constant function gives C5 = 0.5. That's much worse than 0.38.

The optimal h should be structured to minimize the overlap with its shifted complements. This means h should be "spread out" in a way that avoids correlation with shifted versions of its complement.

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    v = np.nan_to_num(v, nan=0.5, posinf=1.0, neginf=0.0)
    lo = float(v.min()) - 2.0
    hi = float(v.max()) + 2.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    x = np.clip(v - (lo + hi) / 2.0, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-12:
        if res > 0:
            mask = x < 1.0 - 1e-12
        else:
            mask = x > 1e-12
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _grad_matrix(h):
    n = len(h)
    G = np.zeros((2 * n - 1, n))
    for d in range(-(n - 1), n):
        r = n - 1 + d
        if d >= 0:
            m = n - d
            if m > 0:
                G[r, d:] += (1.0 - h[:m])
                G[r, :m] -= h[d:]
        else:
            g = -d
            m = n - g
            if m > 0:

def _line_search(h, d, max_iters=30):

            a_hi = min(a_hi, -h[i] / d[i])
    
    if a_hi - a_lo < 1e-15:
        return 0.0, cur_c5
    
    # Coarse sampling
    best_a = 0.0
    best_c5 = cur_c5
    n_samples = 16
    for a in np.linspace(a_lo + 1e-10 * max(1, a_hi - a_lo), a_hi - 1e-10 * max(1, a_hi - a_lo), n_samples):
        c5_t = _exact_c5(h + a * d)
        if c5_t < best_c5 - 1e-15:
            best_c5 = c5_t
            best_a = a
    
    if best_a == 0.0:
        return 0.0, cur_c5
    
    # Golden section refine
    span = a_hi - a_lo
    lo = max(a_lo, best_a - span * 0.12)
    hi = min(a_hi, best_a + span * 0.12)
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    c1 = hi - gr * (hi - lo)
    c2 = lo + gr * (hi - lo)
    f1 = _exact_c5(h + c1 * d)
    f2 = _exact_c5(h + c2 * d)

            hi = c2
            c2 = c1
            f2 = f1
            c1 = hi - gr * (hi - lo)
            f1 = _exact_c5(h + c1 * d)
        else:

            f1 = f2
            c2 = lo + gr * (hi - lo)
            f2 = _exact_c5(h + c2 * d)
    
    opt_a = (lo + hi) / 2.0
    opt_c5 = _exact_c5(h + opt_a * d)
    if opt_c5 < best_c5:

    return best_a, best_c5
