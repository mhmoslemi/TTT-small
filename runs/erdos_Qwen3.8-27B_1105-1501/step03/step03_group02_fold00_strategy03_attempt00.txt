1.1 Central idea  
The method keeps the supplied parent construction as the primary exact feasible fallback and then uses three interoperating, exact-objective search mechanisms that are materially different from a single nonlinear-epigraph polish:

1. Continuous zero-sum exact-trajectory polishing. Each candidate move is of the form h + alpha*d, where d has exactly zero mean-sum and alpha is chosen only inside the box-limited interval that guarantees every coordinate remains in [0,1]. Neither clipping plus repair nor post-projection is used as an ordinary descent step. This protects tiny improvements that would otherwise be lost by feasibility repair. Descent directions are generated from the actual correlations computed by the task evaluator: a smooth-max weighted gradient of the highest discrete score entries. Exact line search in alpha accepts only moves that reduce the returned C5 value.

2. Independent balanced binary topology search. A sequence with exactly n/2 entries set to 1 and the rest set to 0 is automatically feasible. Such binary sequences induce completely different active pair-products and can access minima involving different active lags. A randomized/biased swap-exchange simulated-annealing layer proposes balanced binary candidates. 3. Convex, exactly feasible mixtures of discrete topology and continuous parent.
