1. Approach and rationale

### 1.1 Central idea

The supplied parent is already a very high-quality feasible construction, so a coarse LP, epigraph, or full nonlinear solver will mostly re-solve the same local minimax problem. The proposed method improves upon that by optimizing the **exact discrete evaluator metric directly** and by using only **feasibility-preserving zero-sum moves** during search. The key ingredients are:

1. Every accepted update is scored only by the exact task objective  
   `C5(h) = max(np.correlate(h, 1 - h, mode="full")) * (2.0 / n_points)`.  
   No surrogate objective is ever retained as the final bound.

2. The feasible set is treated as the polytope  
   `P = { h : 0 <= h_i <= 1, sum(h_i) = n/2 }`.  
   Local moves are generated as `h + t*d`, where `d` has exactly zero mean-sum, so the sum constraint is preserved without repair. The stopping parameter `t` is chosen to respect the bounds exactly, so no clipping-repair step is used during exploration.

3. Descent directions come from two complementary sources:
   - **smoothed exact minimax gradients**: choose weights on high exact correlation scores and form the corresponding weighted gradient;
   - **zero-sum pair transfers**: move mass from one sample to another, which automatically preserves the mean and handles coordinates that are nearly bound.

4. A low-dimensional, exactly feasible **antipodal half-complement family** is searched as an independent global seed: `h = [y, 1 - y[pi]]`, with `y in [0,1]^(n/2)` and a small set of permutations `pi`. Every point in this family automatically satisfies `0 <= h <= 1` and `sum(h)=n/2`, so derivative-free global search is possible without equality penalties or repair. The resulting candidates are then relaxed back to full-space local refinement and accepted only by the exact evaluator.

5. The local line-search and pair-transfer engines are used both from the parent and from global seeds. This avoids the previous method’s reliance on keeping all nonlinear active constraints and on post-hoc projection. The method is still a heuristic; it is not claimed to be globally optimal. It is designed to preserve the best exact feasible solution at all times and to use the remaining budget to probe the boundary of the current local basin.

### 1.2 Bottleneck addressed

The previous parent-program-style approach has two practical failure modes for a gap as small as `0.380917 -> 0.3808`:

- A constrained nonlinear solver may improve only the currently selected active lags, while another lag becomes the hidden maximum. Range-based removal and repair can erase micro-improvements.
- Projection after clipping is not an exact conservation operation in the objective; it can move the iterate out of already-found local trade-offs.

The proposed plan avoids hiding maxima by always recomputing the complete discrete correlation array. It avoids erasing improvements during local update by constructing only exact zero-sum coordinate moves and by line-searching under the original exact maximum metric. The antipodal half-complement branch gives a structurally different seed family that is automatically balanced and bounded.

### 1.3 Material difference from prior approaches

This is not just another SLSQP epigraph method. The fixed top-level choice is an exact-evaluation, zero-sum, directional line and exchange debugger. The only nonlinear optimization capability is derivative-free global search on an automatically feasible family, not constrained convex-nonconvex epigraph solving. The accepted solution is always produced by exact line-search and exact pair-transfer stored vertices, with a final exact re-evaluation on the returned array.

### 1.4 Limitations and hypotheses

- The landscape is nonconvex. Descent with a smoothed maximum gradient is only one possible descent phase, not a certified stationary-point method.
- The antipodal branch is a hypothesis-driven seed family. It can be helpful for constructing balanced candidates, but it is not known to contain every local optimum; candidates may be relaxed to full space.
- The exact objective evaluation is used for all accepted decisions. Therefore, if any direction or smoothing heuristic becomes inappropriate, the worst outcome is that candidate generation wastes time; the returned score cannot degrade below the exact stored best except by final numerical validation.
