  - In S(d), h[i] appears as h[p+d] when p+d=i, i.e., p=i-d. Contribution: (1-h[i-d]) → now 0. So S(d) decreases by (1-h[i-d]) if i-d is valid.
  - h[i] appears as h[p] when p=i. Contribution: h[i+d]*(1-h[i]) → now h[i+d]*1 instead of h[i+d]*0 = h[i+d]. So S(d) INCREASES by h[i+d] if i+d is valid.
  
- h[j] changes from 0 to 1:
  - h[j] appears as h[p+d] when p+d=j, i.e., p=j-d. Contribution: h[j]*(1-h[j-d]) → now 1*(1-h[j-d]) instead of 0. So S(d) INCREASES by (1-h[j-d]) if j-d is valid.
  - h[j] appears as h[p] when p=j. Contribution: h[j+d]*(1-h[j]) → now h[j+d]*(1-1)=0 instead of h[j+d]*1. So S(d) DECREASES by h[j+d] if j+d is valid.

So the net change in S(d) is:
ΔS(d) = -(1-h[i-d])_valid + h[i+d]_valid + (1-h[j-d])_valid - h[j+d]_valid

Where _valid means the index is in [0,n-1].

This is O(n) to compute for all d. Then we can check if max_d S(d) + ΔS(d) < current_max.
