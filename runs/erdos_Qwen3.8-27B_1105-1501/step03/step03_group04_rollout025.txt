Let me try a different LP formulation:
- Instead of minimizing t such that G@p ≤ -scores + t (with p bounded by radius),
- Minimize t such that G@p ≤ 0 (all scores must decrease or stay the same), with p bounded by a small radius
- This ensures strict decrease

Or even better:
- Maximize the minimum decrease: maximize t such that G@p ≤ -t for all k, |p| ≤ radius, sum(p) = 0

This is a linear program that finds the direction that most evenly decreases all scores.

Let me also try a different approach: **subgradient method with exact line search**.

At each iteration:
1. Compute scores s
2. Find the active set A = argmax(s)
3. Compute the subgradient: g = (1/|A|) ∑_{k∈A} ∇s_k
4. Find the steepest feasible descent direction: p = -g projected onto the tangent space of the feasible set
5. Take a step in direction p with exact line search

The projection onto the tangent space {p : sum(p) = 0, box constraints} is:
p_projected = p - mean(p) (for the sum constraint)
Then clip to box constraints (but this might break the sum constraint, so we need to re-project)

This is simpler than the LP approach and should work well when the active set is small (1-3 lags).

Let me now write the final algorithm:

```python
import numpy as np
from scipy.optimize import linprog
import time

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _scores(h):
    return np.correlate(h, 1.0 - h, mode='full')

def _grad_matrix(h):
    """Compute gradient matrix G where G[k,j] = ds_k/dh_j."""
    n = len(h)
    G = np.zeros((2*n-1, n))
    for j in range(n):
        for k in range(2*n-1):
            shift = k - (n-1)
            val = 0.0
            jp = j + shift
            jm = j - shift
            if 0 <= jp < n:
                val += (1.0 - h[jp])
            if 0 <= jm < n:
                val -= h[jm]
            G[k, j] = val
    return G
```

Wait, this is O(n²) which for n=64 is 4096*64 = 262144. That's fine.

Actually, I can compute it more efficiently:

For a fixed j, m_k(j) = (1-h[j+k]) * [0≤j+k<n] - h[j-k] * [0≤j-k<n]

As k varies from 0 to 2n-2, shift = k-(n-1) varies from -(n-1) to n-1.
- jp = j + shift ranges from j-(n-1) to j+n-1
- jm = j - shift ranges from j-(n-1) to j+n-1

So m_k(j) is:
- For shift in [-(n-1-j), n-1-j]: (1-h[j+shift]) is valid (jp in [0,n-1])
- For shift in [-(j), n-1-j]: -h[j-shift] is valid (jm in [0,n-1])

Let me just use the direct formula. It's fast enough for n=64.

OK let me now write the complete solution. I'll focus on:

1. **Binary local search** (fast, can find good discrete solutions)
2. **Active-set steepest descent** (precise, uses the structure of the problem)
3. **LP-based direction finding** (robust, works when active set is large)
4. **Fine random perturbation search** (explores neighborhoods)
5. **Final polish** (combines all methods)

import numpy as np
from scipy.optimize import linprog
import time

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _scores(h):
    return np.correlate(h, 1.0 - h, mode='full')

def _project(v, target):
    n = len(v)
    lo, hi = float(v.min()) - 2.0, float(v.max()) + 2.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    tau = (lo + hi) / 2.0
    x = np.clip(v - tau, 0.0, 1.0)
    diff = target - float(np.sum(x))
    if abs(diff) > 1e-12:
        if diff > 0:
            mask = x < 1.0 - 1e-15
        else:
            mask = x > 1e-15
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += diff / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _grad_matrix(h):
    n = len(h)
    G = np.zeros((2 * n - 1, n))
    for j in range(n):
        for k in range(2 * n - 1):
            shift = k - (n - 1)
            val = 0.0
            jp = j + shift
            jm = j - shift
            if 0 <= jp < n:
                val += (1.0 - h[jp])
            if 0 <= jm < n:
                val -= h[jm]
            G[k, j] = val
    return G

def _steepest_descent(h, deadline, max_iters=50000):
    """Active-set steepest descent with exact line search."""
    n = len(h)
    target = n / 2.0
    dx = 2.0 / n
    h = h.copy()
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    
    for it in range(max_iters):
        if time.time() > deadline:
            break
        s = _scores(h)
        m = float(np.max(s))
        # Active set: lags within 1% of max
        active = np.where(s >= m * 0.99)[0]
        G = _grad_matrix(h)
        # Subgradient: average gradient over active set
        g = G[active].mean(axis=0)
        # Project onto tangent space: remove mean (sum constraint)
        g = g - np.mean(g)
        # Direction: negative gradient
        p = -g
        # Check box constraints for step size
        alpha_max = 1.0
        for j in range(n):
            if p[j] > 1e-14:
                alpha_max = min(alpha_max, (1.0 - h[j]) / p[j])
            elif p[j] < -1e-14:
                alpha_max = min(alpha_max, h[j] / (-p[j]))
        alpha_max = min(alpha_max, 0.5)
        if alpha_max < 1e-10:
            break
        # Line search: try several step sizes
        best_alpha = 0.0
        best_val = cur_c5
        for frac in [1.0, 0.7, 0.5, 0.3, 0.2, 0.1, 0.05]:
            a = alpha_max * frac
            h_try = h + a * p
            if np.any(h_try < -0.01) or np.any(h_try > 1.01):
                continue
            h_try = _project(h_try, target)
            c5_try = _exact_c5(h_try)
            if c5_try < best_val - 1e-13:
                best_val = c5_try
                best_alpha = a
        if best_alpha > 0:
            h = _project(h + best_alpha * p, target)
            cur_c5 = _exact_c5(h)
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
        else:
            break
    
    return best_h, best_c5

def _binary_local_search(n, deadline, rng, max_iters=1000000):
    """Local search over binary sequences."""
    m = n // 2
    h = np.zeros(n)
    pos = rng.permutation(n)
    h[pos[:m]] = 1.0
    
    s = _scores(h)
    max_s = float(np.max(s))
    best_h = h.copy()
    best_max = max_s
    stall = 0
    
    while time.time() < deadline and stall < 100 and max_s * (2.0/n) > 0.38:
        i = int(rng.integers(n))
        j = int(rng.integers(n))
        if h[i] == h[j]:
            continue
        h[i], h[j] = h[j], h[i]
        new_s = _scores(h)
        new_max = float(np.max(new_s))
        if new_max <= max_s:
            max_s = new_max
            stall = 0
            if max_s < best_max:
                best_max = max_s
                best_h = h.copy()
        else:
            h[i], h[j] = h[j], h[i]
            stall += 1
    
    return best_h, best_max * (2.0 / n)
