1. Approach and rationale

1.1 Central idea
Use a frequent, exactly evaluable binary/integer state representation for a large part of the search, while keeping the continuous parent as a valid fallback and using a smooth constrained descent phase only to polish fractional solutions. The objective is a maximum of finitely many correlation sums over all signed lags. For binary vectors satisfying the integer half-weight constraint, the exact objective becomes an integer maximum-count problem, which eliminates roundoff in the core search and allows very fast neighborhood scoring using bit positions. After a true binary candidate is obtained, the required evaluation still uses the evaluator's exact finite-support direct-correlation formula.

1.2 Why this addresses the parent bottleneck
The parent construction has length around 64 and a fractional objective very close to the target gap. Pure projected continuous gradient descent is easily trapped by the finite-support maximum: the active lag changes, and a descent direction generated for a small temperature but then projected back to the feasible affine-slice/bounds set can be destroyed by clipping and the sum constraint before the exact jump evaluation is checked. Binary/count-based local/global search can move between plateau states that all have the same integer maximum count, which continuous short-stake methods may reject because exact evaluation is flat or noisy. Even if the target upper bound requires fractional values, a better nearby binary branch can provide a better warm start, and the resulting fractional move can lower the maximum raw correlation beneath the integer lower cell when it relaxes the strict binary constraint.

1.3 Primary approach and fallback
The primary algorithm is: exact feasibility validation, multiple parent-derived random restarts in sample lengths, bit-based swap simulated annealing / random local search over exact half-weight binary vectors, exact validation. The secondary algorithm is: exact-objective line-searching projected smooth-gradient descent over continuous vectors, initialized from parent plus better binary continuous equivalents. The returned solution must always be the lowest exact-c5 candidate that is provably feasible.

1.4 Limitations and hypotheses, not claims
- It is a known or hypothesized optimal pattern, not proof.
- Binary count search may not reach the desired cardinality if the binary cell bound is below the continuous optimum.
- Continuous descent is safe but local/global because nonconvex and nonsmooth; every candidate is again evaluated by the exact evaluator objective before acceptance.
- Bit-state exact-to-correlation relationship is fully verified by the exact direct evaluation before return.

2. Mathematical specification

2.1 Exact discrete representation
Let `n` always be even, and the vector be `h[0..n-1]` on the grid `[0,2]` with `dx = 2.0 / n`. Feasibility requires:
- `0 <= h[i] <= 1` for each integer index.

For binary state, weights are exactly 0 or 1 and `sum(h)` must be `n//2` exactly.
Let `c = 1 - h` and set `q = 1` for binary objective discussion.
Exact evaluator objective:
```

for every signed lag `d = -(n-1), ..., n-1`, where correlations only include valid overlapping indices in the finite interval. Exactly:
```

```
Zero lag is included but never dominates for a binary half-weight vector (`h_i * (1-h_i) = 0`). Maximum integer overlap count:
```
