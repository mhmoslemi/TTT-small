Let me think about the exact line search more carefully:

Given h and direction v (zero-sum, normalized):
- A = correlate(h, 1-h, 'full')
- B = correlate(v, 1-h, 'full') - correlate(h, v, 'full')  
- C = -correlate(v, v, 'full')

For each lag r: score_r(alpha) = A[r] + B[r]*alpha + C[r]*alpha²

We want to minimize f(alpha) = max_r score_r(alpha) over the feasible alpha interval.

The feasible interval is determined by box constraints.

For n ≤ 96 (2n-1 ≤ 191 lags), we can enumerate all pairwise intersections:
- For each pair (i,j), solve C[i]-C[j] * alpha² + (B[i]-B[j]) * alpha + (A[i]-A[j]) = 0
- Also include stationary points of each individual quadratic
- Also include endpoints
- Then evaluate all candidates

This is O((2n-1)²) per line search, which for n=64 is about 127² ≈ 16129 operations per direction. That's very fast.

For the direction generation, the key insight is that we should focus on directions that are "下载使用" - i.e., descent directions for the maximum. The smooth gradient approach works well:
- g = G^T @ w where w are weights on the scores (e.g., softmax with temperature beta)
- v = -g, zero-sum, normalized

Let me also think about what makes this problem hard. The objective is the maximum of many quadratic functions, creating a non-smooth landscape. The exact line search handles this perfectly within each line, but the challenge is choosing good directions.

One key improvement over the previous approach: instead of using a smoothed surrogate and then doing line search, we can directly use the exact quadratic structure. This means:
1. We don't need the smooth gradient at all for the line search - we just need a direction.
2. The line search itself finds the exact best alpha on that line.
3. We can try many directions cheaply.

Let me also think about a "subgradient" direction. At a point where multiple lags are simultaneously active (at the max), any positive combination of their gradients gives a valid subgradient direction. So we can:
- Identify the set of active lags (those at or very near the max)
- Use their combined gradient as a descent direction
- This is equivalent to the smooth gradient with very high beta

For the multi-resolution approach: the key insight is that different discretizations capture different features. A solution optimal at n=64 might not be optimal at n=68 or n=72. We should try nearby resolutions and see if they yield better objectives.

import time

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _raw_scores(h):
    return np.correlate(h, 1.0 - h, mode='full')

def _project_box_sum(v, target):
    n = len(v)
    x = np.clip(np.asarray(v, dtype=float), 0.0, 1.0)
    # Water-filling to hit exact target
    for _ in range(200):
        diff = target - x.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            mask = x < 1.0 - 1e-15
        else:
            mask = x > 1e-15
        if not np.any(mask):
            break
        amt = diff / np.sum(mask)
        x[mask] += amt
        x = np.clip(x, 0.0, 1.0)
    # Final exact fix
    residual = target - x.sum()
    if abs(residual) > 1e-14:
        if residual > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = np.sum(mask)
        if cnt > 0:
            x[mask] += residual / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _line_search_exact(h, v, n_lags):
    """Exact line search for direction v at point h.
    Returns best alpha or None if no improvement possible."""
    n = len(h)
    A = np.correlate(h, 1.0 - h, mode='full').astype(float)
    B = np.correlate(v, 1.0 - h, mode='full').astype(float) - np.correlate(h, v, mode='full').astype(float)
    C = -np.correlate(v, v, mode='full').astype(float)
    
    # Feasible interval
    alpha_lo = 0.0
    alpha_hi = 0.0
    for i in range(n):
        if v[i] > 1e-15:
            alpha_lo = max(alpha_lo, -h[i] / v[i])
            alpha_hi = min(alpha_hi, (1.0 - h[i]) / v[i])
        elif v[i] < -1e-15:
            alpha_lo = max(alpha_lo, (1.0 - h[i]) / v[i])
            alpha_hi = min(alpha_hi, -h[i] / v[i])
    
    # Shrink slightly for numerical safety
    margin = 1e-14 * max(1.0, alpha_hi - alpha_lo)
    alpha_lo += margin
    alpha_hi -= margin
    if alpha_lo >= alpha_hi:
        return None, None, None, None
    
    # Generate candidates
    candidates = set()
    candidates.add(max(alpha_lo, 0.0))
    candidates.add(min(alpha_hi, 0.0))
    candidates.add(alpha_lo)
    candidates.add(alpha_hi)
    
    # Stationary points
    for r in range(n_lags):
        if abs(C[r]) > 1e-18:
            a_stat = -B[r] / (2.0 * C[r])
            if alpha_lo <= a_stat <= alpha_hi:
                candidates.add(a_stat)
    
    # Pairwise intersections (exact for n <= 96)
    m = n_lags
    for i in range(m):
        for j in range(i + 1, m):
            dC = C[i] - C[j]
            dB = B[i] - B[j]
            dA = A[i] - A[j]
            if abs(dC) > 1e-18:
                disc = dB * dB - 4.0 * dC * dA
                if disc >= -1e-14:
                    if disc < 0:
                        disc = 0.0
                    sq = np.sqrt(disc)
                    a1 = (-dB + sq) / (2.0 * dC)
                    a2 = (-dB - sq) / (2.0 * dC)
                    if alpha_lo <= a1 <= alpha_hi:
                        candidates.add(a1)
                    if alpha_lo <= a2 <= alpha_hi:
                        candidates.add(a2)
            elif abs(dB) > 1e-18:
                a_lin = -dA / dB
                if alpha_lo <= a_lin <= alpha_hi:
                    candidates.add(a_lin)
    
    # Uniform grid for safety
    n_grid = 50
    grid = np.linspace(alpha_lo, alpha_hi, n_grid)
    candidates.update(grid.tolist())
    
    # Evaluate all candidates
    best_alpha = None
    best_cost = np.inf
    cand_list = np.array(sorted(candidates))
    for a in cand_list:
        scores = A + a * B + a * a * C
        cost = float(np.max(scores))
        if cost < best_cost:
            best_cost = cost
            best_alpha = float(a)
    
    return best_alpha, best_cost, A, (alpha_lo, alpha_hi)

def _smooth_direction(h, beta):
    """Generate a smooth gradient direction."""
    n = len(h)
    scores = _raw_scores(h)
    max_s = float(np.max(scores))
    exp_vals = np.exp(beta * (scores - max_s))
    w = exp_vals / float(np.sum(exp_vals))
    # Gradient of each score w.r.t. h
    g = np.zeros(n)
    for d in range(-(n - 1), n):
        wd = w[n - 1 + d]
        if abs(wd) < 1e-15:

        lo = max(0, -d)
        hi = min(n, n - d)
        for p in range(lo, hi):
            q = p + d
            g[q] += wd * (1.0 - h[p])
            g[p] += -wd * h[q]
    # Make zero-sum and normalize
    g -= np.mean(g)
    norm = np.linalg.norm(g)
    if norm < 1e-15:
        return None
    return g / norm

import numpy as np
import time

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _raw_scores(h):
    return np.correlate(h, 1.0 - h, mode='full')

def _project_box_sum(v, target):
    n = len(v)
    x = np.clip(np.asarray(v, dtype=float), 0.0, 1.0)
    for _ in range(200):
        diff = target - x.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            mask = x < 1.0 - 1e-15
        else:
            mask = x > 1e-15
        if not np.any(mask):
            break
        amt = diff / np.count_nonzero(mask)
        x[mask] += amt
        x = np.clip(x, 0.0, 1.0)
    residual = target - x.sum()
    if abs(residual) > 1e-14:
        if residual > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = np.count_nonzero(mask)
        if cnt > 0:
            x[mask] += residual / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _compute_grad(h, w):
    """Compute G^T @ w where G is the Jacobian of raw scores."""
    n = len(h)
    g = np.zeros(n)
    for d in range(-(n - 1), n):
        wd = w[n - 1 + d]
        if abs(wd) < 1e-15:
            continue
        lo = max(0, -d)
        hi = min(n, n - d)
        g[lo + d:hi + d] += wd * (1.0 - h[lo:hi])
        g[lo:hi] += -wd * h[lo + d:hi + d]
    return g

def _smooth_direction(h, beta):
    n = len(h)
    scores = _raw_scores(h)
    max_s = float(np.max(scores))
    exp_vals = np.exp(beta * (scores - max_s))
    w = exp_vals / float(np.sum(exp_vals))
    g = _compute_grad(h, w)
    g -= np.mean(g)
    norm = np.linalg.norm(g)
    if norm < 1e-15:
        return None
    return g / norm

def _topk_direction(h, k):
    n = len(h)
    scores = _raw_scores(h)
    max_s = float(np.max(scores))
    # Select top k lags
    idx = np.argsort(-scores)[:k]
    w = np.zeros(2 * n - 1)
    w[idx] = 1.0 / k
    g = _compute_grad(h, w)
    g -= np.mean(g)
    norm = np.linalg.norm(g)
    if norm < 1e-15:
        return None
    return g / norm

def _random_direction(rng, n):
    v = rng.standard_normal(n)
    v -= np.mean(v)
    norm = np.linalg.norm(v)
    if norm < 1e-15:
        return None
    return v / norm

def _line_search(h, v):
    """Exact line search. Returns (best_alpha, best_raw_score) or (None, None)."""
    n = len(h)
    n_lags = 2 * n - 1
    
    A = np.correlate(h, 1.0 - h, mode='full').astype(float)
    B = (np.correlate(v, 1.0 - h, mode='full') - np.correlate(h, v, mode='full')).astype(float)
    C = -np.correlate(v, v, mode='full').astype(float)
    
    # Feasible interval
    alpha_lo = 0.0
    alpha_hi = 0.0
    pos = v > 1e-15
    neg = v < -1e-15
    if np.any(pos):
        alpha_lo = max(alpha_lo, float(np.max(-h[pos] / v[pos])))
        alpha_hi = min(alpha_hi, float(np.min((1.0 - h[pos]) / v[pos])))
    if np.any(neg):
        alpha_lo = max(alpha_lo, float(np.max((1.0 - h[neg]) / v[neg])))
        alpha_hi = min(alpha_hi, float(np.min(-h[neg] / v[neg])))
    
    span = alpha_hi - alpha_lo
    if span < 1e-12:
        return None, None
    
    margin = 1e-13 * max(1.0, span)
    a_lo = alpha_lo + margin
    a_hi = alpha_hi - margin
    if a_lo >= a_hi:
        return None, None
    
    # Generate candidates
    cands = [a_lo, a_hi, 0.0]
    
    # Stationary points
    stat = np.zeros(n_lags)
    has_stat = np.abs(C) > 1e-18
    stat[has_stat] = -B[has_stat] / (2.0 * C[has_stat])
    valid_stat = (stat >= a_lo) & (stat <= a_hi) & has_stat
    if np.any(valid_stat):
        cands.extend(stat[valid_stat].tolist())
    
    # Pairwise intersections
    for i in range(n_lags):
        dC = C[i] - C[i+1:]
        dB = B[i] - B[i+1:]
        dA = A[i] - A[i+1:]
        # Quadratic case
        quad_mask = np.abs(dC) > 1e-18
        if np.any(quad_mask):
            disc = dB[quad_mask]**2 - 4.0 * dC[quad_mask] * dA[quad_mask]
            disc = np.maximum(disc, 0.0)
            sq = np.sqrt(disc)
            r1 = (-dB[quad_mask] + sq) / (2.0 * dC[quad_mask])
            r2 = (-dB[quad_mask] - sq) / (2.0 * dC[quad_mask])
            masks1 = (r1 >= a_lo) & (r1 <= a_hi)
            masks2 = (r2 >= a_lo) & (r2 <= a_hi)
            if np.any(masks1):
                cands.extend(r1[masks1].tolist())
            if np.any(masks2):
                cands.extend(r2[masks2].tolist())
        # Linear case
        lin_mask = (np.abs(dC) <= 1e-18) & (np.abs(dB) > 1e-18)
        if np.any(lin_mask):
            r_lin = -dA[lin_mask] / dB[lin_mask]
            masks_l = (r_lin >= a_lo) & (r_lin <= a_hi)
            if np.any(masks_l):
                cands.extend(r_lin[masks_l].tolist())
    
    # Grid
    n_grid = 64
    cands.extend(np.linspace(a_lo, a_hi, n_grid).tolist())
    
    arr = np.array(cands, dtype=float)
    arr = arr[(arr >= a_lo) & (arr <= a_hi)]
    if len(arr) == 0:
        return None, None
    
    # Vectorized evaluation
    scores = A[None, :] + arr[:, None] * B[None, :] + arr[:, None]**2 * C[None, :]
    costs = np.max(scores, axis=1)
    best_idx = int(np.argmin(costs))
    
    return float(arr[best_idx]), float(costs[best_idx])

def _local_descent(h, deadline, rng, n_max_iters=50000):
    """Local descent using exact line search with various directions."""
    n = len(h)
    h_cur = h.copy()
    cur_c5 = _exact_c5(h_cur)
    best_h = h_cur.copy()
    best_c5 = cur_c5
    stall = 0
    
    beta_seqs = [
        [4.0, 10.0, 30.0],
        [10.0, 30.0, 100.0],
        [30.0, 100.0, 300.0],
    ]
    
    it = 0
    while it < n_max_iters and time.time() < deadline:
        # Choose direction
        it += 1
        phase = (it // 50) % len(beta_seqs)
        sub = it % 50
        if sub < 20:
            beta = beta_seqs[phase][min(sub // 7, 2)]
            v = _smooth_direction(h_cur, beta)
        elif sub < 35:
            k = [2, 3, 5][sub % 3]
            v = _topk_direction(h_cur, k)
        else:
            v = _random_direction(rng, n)
        
        if v is None:
            stall += 1
            continue

import numpy as np
import time

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _raw_scores(h):
    return np.correlate(h, 1.0 - h, mode='full')

def _project_box_sum(v, target):
    n = len(v)
    x = np.clip(np.asarray(v, dtype=float), 0.0, 1.0)
    for _ in range(300):
        diff = target - x.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = x < 1.0 - 1e-16
        else:
            mask = x > 1e-16
        if not np.any(mask):
            break
        amt = diff / np.count_nonzero(mask)
        x[mask] += amt
        x = np.clip(x, 0.0, 1.0)
    residual = target - x.sum()
    if abs(residual) > 1e-13:
        if residual > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = np.count_nonzero(mask)
        if cnt > 0:
            x[mask] += residual / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _compute_grad(h, w):
    n = len(h)
    g = np.zeros(n)
    for d in range(-(n - 1), n):
        wd = w[n - 1 + d]
        if abs(wd) < 1e-15:
            continue
        lo = max(0, -d)
        hi = min(n, n - d)
        g[lo + d:hi + d] += wd * (1.0 - h[lo:hi])
        g[lo:hi] += -wd * h[lo + d:hi + d]
    return g

def _smooth_direction(h, beta):
    n = len(h)
    scores = _raw_scores(h)
    max_s = float(np.max(scores))
    exp_vals = np.exp(beta * (scores - max_s))
    s = float(np.sum(exp_vals))
    if s < 1e-300:
        return None
    w = exp_vals / s
    g = _compute_grad(h, w)
    g -= np.mean(g)
    norm = float(np.linalg.norm(g))
    if norm < 1e-14:
        return None
    return g / norm

def _topk_direction(h, k):
    n = len(h)
    scores = _raw_scores(h)
    idx = np.argsort(-scores)[:min(k, 2 * n - 1)]
    w = np.zeros(2 * n - 1)
    w[idx] = 1.0 / len(idx)
    g = _compute_grad(h, w)
    g -= np.mean(g)
    norm = float(np.linalg.norm(g))
    if norm < 1e-14:
        return None
    return g / norm

    v -= np.mean(v)
    norm = float(np.linalg.norm(v))
    if norm < 1e-14:

    return v / norm

    if not np.isfinite(alpha_lo):
        alpha_lo = -2.0
    if not np.isfinite(alpha_hi):
        alpha_hi = 2.0
    span = alpha_hi - alpha_lo
    if span < 1e-13:
        return None, None
    margin = 1e-13 * max(1.0, span)
    a_lo = alpha_lo + margin
    a_hi = alpha_hi - margin
    if a_lo >= a_hi:
        return None, None
    cands = [a_lo, a_hi, 0.0]
    has_stat = np.abs(C) > 1e-18
    if np.any(has_stat):
        stat_pts = -B[has_stat] / (2.0 * C[has_stat])
        vs = (stat_pts >= a_lo) & (stat_pts <= a_hi)
        if np.any(vs):
            cands.extend(stat_pts[vs].tolist())
    I, J = np.triu_indices(n_lags, k=1)
    dC = C[I] - C[J]
    dB = B[I] - B[J]
    dA = A[I] - A[J]
    quad_mask = np.abs(dC) > 1e-18
    if np.any(quad_mask):
        disc = dB[quad_mask] ** 2 - 4.0 * dC[quad_mask] * dA[quad_mask]
        disc = np.maximum(disc, 0.0)
        sq = np.sqrt(disc)
        r1 = (-dB[quad_mask] + sq) / (2.0 * dC[quad_mask])
        r2 = (-dB[quad_mask] - sq) / (2.0 * dC[quad_mask])
        m1 = (r1 >= a_lo) & (r1 <= a_hi)
        m2 = (r2 >= a_lo) & (r2 <= a_hi)
        if np.any(m1):
            cands.extend(r1[m1].tolist())
        if np.any(m2):
            cands.extend(r2[m2].tolist())
    lin_mask = (np.abs(dC) <= 1e-18) & (np.abs(dB) > 1e-18)
    if np.any(lin_mask):
        r_lin = -dA[lin_mask] / dB[lin_mask]
        ml = (r_lin >= a_lo) & (r_lin <= a_hi)
        if np.any(ml):
            cands.extend(r_lin[ml].tolist())
    n_grid = 48
    cands.extend(np.linspace(a_lo, a_hi, n_grid).tolist())
    arr = np.array(cands, dtype=np.float64)
    arr = arr[(arr >= a_lo) & (arr <= a_hi)]
    if len(arr) == 0:
        return None, None
    arr_sq = arr * arr
    scores_mat = A[None, :] + arr[:, None] * B[None, :] + arr_sq[:, None] * C[None, :]
    costs = np.max(scores_mat, axis=1)
    best_idx = int(np.argmin(costs))
    return float(arr[best_idx]), float(costs[best_idx])

def _local_descent(h, deadline, rng, max_iters=80000):
    n = len(h)
    h_cur = h.copy()
    cur_c5 = _exact_c5(h_cur)
    best_h = h_cur.copy()
    best_c5 = cur_c5
    stall = 0
    it = 0
    while it < max_iters and time.time() < deadline:
        it += 1
        cycle = it % 100
        epoch = (it // 100) % 4
        if cycle < 30:
            if epoch == 0:
                beta = [3.0, 8.0][cycle % 2]
            elif epoch == 1:
                beta = [8.0, 20.0][cycle % 2]
            elif epoch == 2:
                beta = [20.0, 60.0][cycle % 2]
            else:
                beta = [60.0, 200.0][cycle % 2]
            v = _smooth_direction(h_cur, beta)
        elif cycle < 55:
            k = [2, 3, 5, 8][cycle % 4]
            v = _topk_direction(h_cur, k)
        elif cycle < 85:
            v = _random_direction(rng, n)
        else:
            beta = 50.0 + 50.0 * rng.random()
            v = _smooth_direction(h_cur, beta)
        if v is None:
            stall += 1
            continue
        alpha, raw_cost = _line_search(h_cur, v)
        if alpha is None or abs(alpha) < 1e-14:
            stall += 1
            continue
        h_try = h_cur + alpha * v
        h_try = _project_box_sum(h_try, n / 2.0)
        c5_try = _exact_c5(h_try)
        if c5_try < cur_c5 - 1e-13:
            h_cur = h_try
            cur_c5 = c5_try
            if cur_c5 < best_c5:
                best_c5 = c5_try
                best_h = h_cur.copy()
            stall = 0
        else:
            stall += 1
        if stall > 300:
            break
    return best_h, best_c5

def _pair_polish(h, deadline, max_rounds=20, pairs_per_round=2000):
    n = len(h)
    h_cur = h.copy()
    cur_c5 = _exact_c5(h_cur)
    best_h = h_cur.copy()
    best_c5 = cur_c5
    all_pairs = [(i, j) for i in range(n) for j in range(i + 1, n)]
    for rnd in range(max_rounds):
        if time.time() > deadline:
            break
        improved = False
        rng_p = np.random.default_rng(42 + rnd * 7919)
        rng_p.shuffle(all_pairs)
        for (i, j) in all_pairs[:pairs_per_round]:
            if time.time() > deadline:
                break
            if h_cur[i] < 1e-12 or h_cur[j] > 1.0 - 1e-12:
                continue
            v = np.zeros(n)
            v[i] = 1.0
            v[j] = -1.0
            alpha, _ = _line_search(h_cur, v)
            if alpha is None or abs(alpha) < 1e-14:
                continue
            h_try = h_cur + alpha * v
            h_try = _project_box_sum(h_try, n / 2.0)
            c5_try = _exact_c5(h_try)
            if c5_try < cur_c5 - 1e-13:
                h_cur = h_try
                cur_c5 = c5_try
                if cur_c5 < best_c5:
                    best_c5 = cur_c5
                    best_h = h_cur.copy()
                improved = True
        if not improved:
            break
    return best_h, best_c5

def _resample(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return _project_box_sum(h_new, n_new / 2.0)

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    hard_deadline = t0 + budget_s * 0.97
    rng = np.random.default_rng(seed)
    h0 = np.asarray(initial_h_values, dtype=np.float64)
    n0 = len(h0)
    h = _project_box_sum(h0, n0 / 2.0)
    best_h = h.copy()
    best_c5 = _exact_c5(h)
    best_n = n0
    # Phase 1: Deep local descent
    dl1 = t0 + budget_s * 0.32
    h1, c5_1 = _local_descent(h, dl1, rng)
    if c5_1 < best_c5:
        best_c5 = c5_1
        best_h = h1.copy()
        best_n = len(best_h)
    # Phase 2: Transform exploration
    dl2 = t0 + budget_s * 0.52
    h_flip = _project_box_sum(best_h[::-1].copy(), best_n / 2.0)
    c5_flip = _exact_c5(h_flip)
    if c5_flip < best_c5:
        h_flip, c5_flip = _local_descent(h_flip, min(dl2, time.time() + budget_s * 0.03), rng, 8000)
        if c5_flip < best_c5:
            best_c5 = c5_flip
            best_h = h_flip.copy()
    h_roll1 = _project_box_sum(np.roll(best_h, 1), best_n / 2.0)
    c5_r1 = _exact_c5(h_roll1)
    if c5_r1 < best_c5:
        h_roll1, c5_r1 = _local_descent(h_roll1, min(dl2, time.time() + budget_s * 0.03), rng, 8000)
        if c5_r1 < best_c5:
            best_c5 = c5_r1
            best_h = h_roll1.copy()
    h_roll2 = _project_box_sum(np.roll(best_h, best_n // 2), best_n / 2.0)
    c5_r2 = _exact_c5(h_roll2)
    if c5_r2 < best_c5:
        c5_r2 < best_c5
        h_roll2, c5_r2 = _local_descent(h_roll2, min(dl2, time.time() + budget_s * 0.02), rng, 5000)
        if c5_r2 < best_c5:
            best_c5 = c5_r2
            best_h = h_roll2.copy()
    # Binary threshold
    if time.time() < dl2:
        idx = np.argsort(-best_h)
        h_bin = np.zeros(best_n)
        h_bin[idx[:best_n // 2]] = 1.0
        h_bin = _project_box_sum(h_bin, best_n / 2.0)
        c5_bin = _exact_c5(h_bin)
        if c5_bin < best_c5 + 0.01:
            h_bin, c5_bin = _local_descent(h_bin, min(dl2, time.time() + budget_s * 0.03), rng, 8000)
            if c5_bin < best_c5:
                best_c5 = c5_bin
                best_h = h_bin.copy()
    # Mix candidates
    if time.time() < dl2:
        for wm in [0.3, 0.5, 0.7]:
            if time.time() > dl2:
                break
            h_mix = wm * best_h + (1.0 - wm) * h
            h_mix = _project_box_sum(h_mix, best_n / 2.0)
            c5_mix = _exact_c5(h_mix)
            if c5_mix < best_c5:
                h_mix, c5_mix = _local_descent(h_mix, min(dl2, time.time() + budget_s * 0.02), rng, 5000)
                if c5_mix < best_c5:
                    best_c5 = c5_mix
                    best_h = h_mix.copy()
    # Phase 3: Multi-resolution
    dl3 = t0 + budget_s * 0.78
    n_cand = sorted(set(x for x in [best_n - 4, best_n + 4, best_n - 8, best_n + 8,
                                    best_n + 12, best_n + 16, 48, 56, 72, 80,
                                    96, 112, 128, 144]
                        if 24 <= x <= 256 and x % 2 == 0 and x != best_n))
    for n_try in n_cand:
        if time.time() > dl3 - 10:
            break
        per_time = min(budget_s * 0.035, (dl3 - time.time()) / 2.0)
        if per_time < 8:
            break
        h_r = _resample(best_h, n_try)
        dl_r = time.time() + per_time * 0.65
        h_r, c5_r = _local_descent(h_r, dl_r, rng, 15000)
        if c5_r < best_c5 and time.time() < dl3 - 5:
            dl_p = min(dl3, time.time() + per_time * 0.3)
            h_r, c5_r = _pair_polish(h_r, dl_p, max_rounds=5, pairs_per_round=500)
        if c5_r < best_c5 - 1e-10:
            best_c5 = c5_r
            best_h = h_r.copy()
            best_n = n_try
    # Phase 4: More local descent on best
    dl4 = t0 + budget_s * 0.90
    h4, c5_4 = _local_descent(best_h, dl4, rng, 100000)
    if c5_4 < best_c5:
        best_c5 = c5_4
        best_h = h4.copy()
        best_n = len(best_h)
    # Phase 5: Pair polish
    if time.time() < hard_deadline:
        hp, c5p = _pair_polish(best_h, hard_deadline, max_rounds=30, pairs_per_round=3000)
        if c5p < best_c5:
            best_c5 = c5p
            best_h = hp.copy()
    # Final projection and evaluation
    best_h = _project_box_sum(best_h, len(best_h) / 2.0)
    final_c5 = _exact_c5(best_h)
    final_n = len(best_h)
    if final_c5 > best_c5 + 1e-10:
        best_h = _project_box_sum(h0, n0 / 2.0)
        final_c5 = _exact_c5(best_h)
        final_n = n0
    return best_h, final_c5, final_n
