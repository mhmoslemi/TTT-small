```python
def build_S(h):
    n = len(h)
    m = 2 * n - 1
    S = np.zeros((n, m))
    for d in range(m):
        shift = d - (n - 1)
        # First term: (1-h[i+shift]) for valid i
        if shift >= 0:
            S[:n-shift, d] += (1.0 - h[shift:])
        else:
            S[-shift:, d] += (1.0 - h[:n+shift])
        # Second term: -h[i-shift] for valid i
        if shift >= 0:
            S[shift:, d] -= h[:n-shift]
        else:
            S[:n+shift, d] -= h[-shift:]
    return S
```

This is O(n) per d (vectorized), and O(n) values of d, so O(n²) total. Fast!

Now for the incremental update of S when h[i] changes by δ:
S[k, d] depends on h[i] if:
- In the first term: k+shift_d = i, i.e., shift_d = i-k, i.e., d = n-1+i-k
- In the second term: k-shift_d = i, i.e., shift_d = k-i, i.e., d = n-1+k-i

So for a given i, the affected (k, d) pairs are:
- From first term: d = n-1+i-k for k where 0≤k<n and 0≤k+shift<n (which is automatically satisfied if d is valid)
  This gives d = n-1+i-k, so k = n-1+i-d. For d in [0, 2n-2], k = n-1+i-d ranges from n-1+i-(2n-2) to n-1+i-0 = i-1 to i+2n-3... 
  Hmm, this is getting complicated. Let me just loop over d.

For each d (shift = d-(n-1)):
- If i+shift is in [0,n): S[i+shift, d] changes. The term is -h[i+shift-shift] = -h[i]. Wait no.
  
  Let me re-derive. S[k, d] = (1-h[k+shift]) * [valid] - h[k-shift] * [valid]
  
  The term -h[k-shift] contains h[i] when k-shift = i, i.e., k = i+shift.
  So if 0 ≤ i+shift < n, then S[i+shift, d] has the term -h[i].
  When h[i] changes by δ, S[i+shift, d] changes by -δ.
  
  The term (1-h[k+shift]) contains h[i] when k+shift = i, i.e., k = i-shift.
  So if 0 ≤ i-shift < n, then S[i-shift, d] has the term -h[i] (since 1-h[k+shift] = 1-h[i]).
  When h[i] changes by δ, S[i-shift, d] changes by -δ.

So the update rule is:
For each d (shift = d-(n-1)):
  if 0 ≤ i+shift < n: S[i+shift, d] += -δ (for h[i] increasing by δ)
  if 0 ≤ i-shift < n: S[i-shift, d] += -δ

And for h[j] decreasing by δ (changing by -δ):
  if 0 ≤ j+shift < n: S[j+shift, d] += δ
  if 0 ≤ j-shift < n: S[j-shift, d] += δ

```python
def update_S(S, h, i, j, delta, n):
    """Update S after h[i] += delta and h[j] -= delta"""
    for d in range(2 * n - 1):
        shift = d - (n - 1)
        ip = i + shift
        if 0 <= ip < n:
            S[ip, d] -= delta
        im = i - shift
        if 0 <= im < n:
            S[im, d] -= delta
        jp = j + shift
        if 0 <= jp < n:
            S[jp, d] += delta
        jm = j - shift
        if 0 <= jm < n:
            S[jm, d] += delta
```
