1. Approach and rationale

1.1 Central idea.
The supplied parent construction is already a good local point, but the current algorithm spends most of its time in smoothed-gradient/LP polish at the same finite-resolution basin. The key structural fact missing from that pipeline is that the exact objective has unusually simple pieces when one enforces the mass constraint by transferring mass between two coordinates. For a single resample lag, the value of  
`np.correlate(h,1-h,mode="full")` as a function of a two-coordinate transfer `h_i += a`, `h_j -= a` is exactly a quadratic in `a`; the coefficient matrix and quadratic terms can be built analytically. Therefore a coordinate-edge line search can minimize the exact score vector along a feasible, box-respecting, sum-preserving 1D subspace without numerical projection or correlation re-evaluation at every trial point. This enables robust local descent, but because the problem is nonconvex it must be combined with multi-start exploration.

1.2 Why this should improve the supplied parent.
The parent and the supplied program already optimize approximately; the last few decimal digits are usually missed because small coordinates need exact minimax balancing rather than smooth gradient steps. Pairwise exact line descent fixes mass exactly and can correct several coordinates at a time depending on the best line minimizer. A modern constrained minimax solver (`scipy.optimize.minimize(method="SLSQP")`) with analytic gradient of all 2n-1 constraints targets KKT-like stationary points in higher dimension. Multi-start solving from perturbed parents, mirrored/rolled parents, and randomized feasible vectors widens basins. Random exact line descent is still used for safe recovery and rapid improvement, not as a global heuristic.

1.3 Limitations.
- Pairwise line descent is a first-order local subproblem; it cannot guarantee global improvement.
- SLSQP on the nonconvex minimax formulation is a local method; every returned vector must be validated by the exact task objective and feasible compromise exact.
- Multi-resolution may waste time. It is optional and should only be activated when there is several hundred seconds left.
- The program must always return the verified best feasible point; it must not return the raw result of a failed solver or the output of a sequence of clipping/rescaling operations.

1.4 Primary selected approach.
Use a hybrid: parent + randomized feasible starts; analytic pairwise exact line minimization along decompositions e_i - e_j; full analytic constrained SLSQP polishing of the minimax problem with parameters `(t,h)`; exact final resample filtering. Retain at least one explicit fallback at parent resolution. Prefer `n_words = len(initial_h_values)` as main rank and resampling only reduces later.
