1. Approach and rationale

1.1 Central idea

The target construction is already deep in a flat, nonsmooth local basin of the exact finite-support evaluator. The decisive question is therefore not whether another linearized LP step can be taken from the same point, but how to generate candidate moves that address the maximum constraint from several distinct perspectives while never accepting any candidate unless the authoritative `np.correlate(h, 1 - h, "full") * dx` objective improves the saved best value.

The proposed implementation uses a two-level, exact-acceptance search:

- A global continuous logic centered on high-order p-norm annealing. Instead of climbing a single active-lag LP trust region, it minimizes a smooth surrogate \(F_p(h)=(\sum_s s(h)_s^p)^{1/p}\) over increasingly large \(p\). Its gradient blends all lag scores, then hardens toward the true max. A constrained projected line search evaluates the true evaluator at every proposed point.
- A “structured finite-design” layer that generates binary and thresholded starting points from the supplied parent and from compact combinatorial families. Binary designs are natural vertices of the feasible polytope. A short simulated-annealing block-move lets exact-sum exchanges explore genuinely different marked sequences. Continuous polishing is then applied to any design from this layer that gives a promising exact value or complementary score profile.
- An active-row diagonal-block recovery mechanism. At an approaching non-smooth local minimum, many lag constraints are nearly active. The solver constructs least-squares equalization directions for the current maximum row band and separates these into block updates built from active product terms. These directions are mathematically different from a global LP direction: they equalize the current envelope, not simply reduce the predicted maximum.

The phase schedule is deliberately different from a perturbation-and-LP chain. It starts with the exact evaluator and parent configuration, performs a high-order smooth convexification/soft-maxide descent, then uses binary design exploration and active-row denoising around discovered basins. Every actual global update is made with the exact evaluator.

1.2 Why this addresses the existing bottleneck

The parent is at approximately 0.380915 under the exact evaluator; the desired upper bound is approximately 0.38080. This gap is very small relative to the curvature of lag score envelopes. It is not necessarily a curvature problem; it is likely a basin/flatness problem. LP directions from a current point provide only local predictions, while random coordinate perturbations attack the coordinate deltas without using the lags that are jointly controlling the objective. The high-order p-norm objective supplies a stable descent field throughout nearly tied lag bands. Active-row diagonals isolate the exact transactions that produce the largest overlap entries, and binary exchange paths provide a distinct combinatorial neighborhood. The combination should create correlations that a single LP model cannot see.

Block moves in the binary layer preserve the half-density constraint exactly. As a result, they avoid constraints hidden by projection steps and can repair score profiles with discrete level shifts, something especially useful near a 0/1 optimum or a polytope vertex.

This is not a proof of global optimality. The global landscape is nonconvex because scores contain products \(h_i(1-h_j)\). The method is a strongly guarded stochastic/nondeterministic optimizer: only strict improvements to the accepted exact objective alter the global best. Its usefulness is supported by extensive local/global exploration and by exact acceptance, not by any completeness claim.

1.3 Distinction from linearized LP and simple smooth-weight search

Prior schemes use local linear approximation/trust-region updates and perturbation restarts. The overridden mechanism here is order-p annealing in unconstrained smooth maximum space and explicit active-row least-squared equalization. It is a full nonconvex descent solver over fractional commensurate多篇 interference scores, with many exact-direction line searches.
