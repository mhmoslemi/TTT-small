S_d(h') = S_d(h) + δ * [sum_k (e_i[k] - e_j[k]) * (1-h[k+d]) + sum_k h[k] * (-(e_i[k+d] - e_j[k+d]))] + δ² * [(e_i - e_j) . something]

The linear part:

The quadratic part exists only when i and j interact:
When k = i and k+d = j (i.e., d = j-i): the term is (h[i]+δ)*(1-h[j]+δ) vs h[i]*(1-h[j]), change = δ*(1-h[j]) + δ*h[i] + δ²
When k = j and k+d = i (i.e., d = i-j): the term is (h[j]-δ)*(1-h[i]-δ) vs h[j]*(1-h[i]), change = -δ*(1-h[i]) - δ*h[j] + δ²

So the total quadratic coefficient for lag d:
Q_d = 1 if d = j-i or d = i-j (and the indices are valid), 0 otherwise.

This is very sparse! At most 2 lags have nonzero Q.

- L = array of linear coefficients (length 2n-1)
- Q = array of quadratic coefficients (length 2n-1), nonzero at at most 2 positions

```python
def _pair_linear_coeffs(h, i, j):
    """Compute linear coefficients L_d for perturbation +δ at i, -δ at j"""
    n = len(h)
    L = np.zeros(2*n-1)
    # Contribution from h[i] changing by +δ
    # h[i] appears as first factor in S_d when d = 0,1,...,n-1-i (lag where i+d < n)
    # Actually, in np.correlate(h, 1-h, 'full'), the indexing is specific.
    # Let me just use the definition: S_d for d=-(n-1),...,(n-1)
    # S_d = sum_{k: 0<=k<n, 0<=k+d<n} h[k] * (1-h[k+d])
    
    for d in range(-(n-1), n):
       _coeff = 0.0
        # h[i] as first factor: valid if 0 <= i < n and 0 <= i+d < n
        if 0 <= i < n and 0 <= i+d < n:
            _coeff += (1.0 - h[i+d])
        # h[i] as second factor (in 1-h[i]): valid if 0 <= i-d < n and 0 <= i < n
        if 0 <= i-d < n and 0 <= i < n:
            _coeff += -h[i-d]
        # h[j] as first factor: valid if 0 <= j < n and 0 <= j+d < n
        if 0 <= j < n and 0 <= j+d < n:
            _coeff += -(1.0 - h[j+d])
        # h[j] as second factor: valid if 0 <= j-d < n and 0 <= j < n
        if 0 <= j-d < n and 0 <= j < n:
            _coeff += h[j-d]
        L[d + n - 1] = _coeff
    return L
```

def _precompute_g(h):
    """g[k][d] = gradient contribution of h[k] to correlation at lag d
