For the coordinate descent, let me use the following approach:
- For each coordinate i (in random order), find the optimal value of h[i] given all other coordinates fixed, subject to the sum constraint.
- The sum constraint means if I change h[i] by δ, I need to compensate by changing the sum of other coordinates by -δ. The simplest way: adjust one "companion" coordinate.

1. For coordinate i, try h[i] ∈ {0, 0.1, ..., 1}

This is NOT convex in general because of the h[j]h[j+d] terms. So gradient-based methods might get stuck.

2. Use gradient/LP methods to fine-tune the "fuzzy" coordinates (those not near 0 or 1)
3. Use discrete moves (swaps, flips) to adjust the binary structure
4. Iterate
