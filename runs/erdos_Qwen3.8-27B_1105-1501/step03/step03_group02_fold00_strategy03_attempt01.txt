1. Approach and rationale
-------------------------

### 1.1 Central idea

The parent construction is already near a local minimizer of the discrete evaluation
`max(np.correlate(h, 1-h, mode="full")) * (2/n)`. The gap from `0.380917` to the target `0.3808` is very small, so a coarse global method is likely unhelpful unless it reaches a genuinely different region of the feasible set. The proposed primary method is therefore a direct, feasibility-preserving, exact-objective descent method with deliberately diverse starting points.

The method does not search by solving an epigraph or LP approximation and then repairing the result. Instead, every substantive step is moved along a feasible, zero-sum direction and its exact objective is checked. Search directions are produced from the true finite-support correlation scores and gradients, but the objective used to accept or reject an iterate is always the original evaluator:

`raw_scores = np.correlate(h, 1.0 - h, mode="full"); C5 = max(raw_scores) * 2.0 / len(h)`.

A set of complementary pieces makes the method materially different from a standard SLSQP/LP loop:

1. Use zero-sum directions except for structured seeds. During the main local search, candidate changes are constructed to preserve the linear mass constraint naturally, not by clipping and rescaling.
2. Use many directions from one current iterate: uniform averages over the top exact-score lags, exponentially weighted smooth maximum gradients over all exact-score lags, and small random complementary directions.
3. Use exact one-dimensional line searches over the full feasible interval in both directions. This prevents a line from being chosen merely to reduce a smooth surrogate while increasing a hidden active lag.
4. Use direct pair-transfer line searches, which move mass between two coordinates while preserving the sum exactly. These are simple but are effective when gradients are nearly orthogonal to a useful descent path near box constraints.
5. Generate independent seeds from smooth low-order cosine/sine basis constructions, randomized/balanced waves, thresholded constructions, optional periodic or block forms, and graded perturbations of the best vector. These are repaired exactly and tested exactly before local polish. The method can use structured global-looking seeds without imposing that all local optima lie in a special family.
6. Multi-resolution refinement around the best parent resolution is optional. It is used only as an independent route to a better vector under the exact evaluator for the resolution actually returned.

The overall scheme is heuristic, because the objective is a max of bilinear finite-support forms over a nonconvex compact feasible set. It is not claimed to be globally optimal. It is designed to preserve the best verified feasible candidate at all times and to return the parent if no better feasible construction is found.

### 1.2 Why this could improve the parent

The parent program reached about `0.380917` by repeated epigraph-style optimization and full-score polishing. For a remaining gap near `1e-4`:

- A global nonlinear solve over the full `n` coordinates may stagnate in the same local basin.
- A smooth maximum gradient can miss multiple active/disactive lags if only a few smooth parameters are used.
- Post-clipping/rescaling repair can erase a microscopic exact reduction.
- Hidden inactive lags can become the maximum when active lags are pushed down.

The proposed approach addresses these by:

- always recomputing all correlations, not only an active subset, when deciding exact acceptance;
- moving along zero-sum directions that preserve the sum constraint to machine precision before a separate feasibility revalidation;
- accepting only exact re-evaluated improvements;
- producing directions from several active/top lag weighting modes, including smooth aggregations over all lags;
- injecting many structurally different feasible seeds before polish, so that small changes outside the parent basin can be tested.

### 1.3 Distinguishing facts and hypotheses

Facts:

- The exact evaluation function is finite support and uses both lag signs.
- The constraints are box constraints and a linear mean/sum constraint.
- Every exact score is a bilinear function of the coordinates, so there is no general convexity in the original variables.
- The gradient formulas below match the `np.correlate(h, 1-h, mode="full")` evaluator if output-index orientation is checked at startup.

Hypotheses:

- A combination of top-average and smooth exponents can produce descent direction sets that are richer than a single smooth maximum parameter.
- Pair-transfer line searches and low-dimensional wave seeds can find other feasible basins whose exact objective is slightly below the parent.
- Multi-resolution interpolation may find better discrete samples near the continuous optimum but is only accepted when its exact returned-length metric is better.

Fallback guarantee: If the heuristic fails to improve the supplied parent, the final returned vector is the repaired parent, which is valid under the supplied evaluator, assuming `initial_h_values` is valid.

2. Mathematical specification

### 2.1 Discrete variables and feasible set

For a returned vector `h` of length `n = n_points`, define

```
target = n / 2
dx = 2.0 / n
```

The required feasible set is:

```
0 <= h[i] <= 1 for i = 0, ... , n-1
sum_i h[i] = target
```

The exact objective is:

```
raw = np.correlate(h, 1.0 - h, mode="full")   # length 2*n - 1
C5 = max(raw) * dx
```

Smaller `C5` is better.

### 2.2 Internal score and gradient indexed to `np.correlate`

Let the output index of `np.correlate` be `r = 0, ... , 2*n-2`. Define the finite-support lag associated with that index by

```
s = r - (n - 1)
```

The exact raw score at output index `s` is `Q_s`. The formulas are:

- If `s = 0`:

```
Q_0 = sum_{i=0}^{n-1} h[i] * (1 - h[i])

grad_Q0[i] = 1 - 2*h[i]
```

- If `s > 0`, with `d = s` and `m = n - d`:

```
Q_d = sum_{i=0}^{m-1} h[i+d] * (1 - h[i])

For each i in 0,...,m-1:
    grad_Qd[i]     -= h[i+d]
    grad_Qd[i+d]   += 1 - h[i]
```

All other gradient entries are zero.

- If `s < 0`, with `g = -s` and `m = n - g`:

```
Q_{-g} = sum_{i=0}^{m-1} h[i] * (1 - h[i+g])

For each i in 0,...,m-1:
    grad_Q_{-g}[i]     += 1 - h[i+g]
    grad_Q_{-g}[i+g]   -= h[i]
```

All other gradient entries are zero.

Implementation requirement: at program startup, construct a small deterministic nonzero vector `h_test` that is not invariant under reversal and compute both an array according to the above score formulas and `np.correlate(h_test, 1 - h_test, mode="full")`. The formula array must be ordered by `s = r - (n-1)`. If it is considered incorrect, reverse only the output-order association as needed inside the implementation so that gradients are paired with the actual output positions of `np.correlate`. ### 2.3 Zero-sum feasible directions

A direction vector `d` in `R^n` is usable for a move with fixed positive sum if

```
sum_i d[i] = 0    (to numerical tolerance)
```

Given feasible `h`, the feasible line interval along `d` is:

```
d1 = set of indices where d[i] > eps
dn = set of indices where d[i] < -eps
```

If no effective direction entries exist, skip.

The lower bound for negative steps is:

```
lower = 0 if no positive entries else - minimum_{i in d1} h[i] / d[i]
```

The upper bound for positive steps is:

```
upper = 0 if no negative entries else minimum_{i in dn} (1 - h[i]) / (-d[i])
```

The full feasible interval for a general parameter `alpha` is:

```
alpha in [lower, upper]
```

Set `eps_d = 1e-12`. If `lower >= -eps_d` use no negative side; if `upper <= eps_d` use no positive side. The line search evaluates both sides.

After a candidate `h_cand = h + alpha * d`, compute the sum residual:

```
res = target - sum(h_cand)
```

If `abs(res)` is larger than a tight tolerance, perform an infeasibility-safe numerical repair as described in 2.7. If repair is impossible, reject the candidate.

2. Build candidate step sample sets:

5. Run golden section for about 18-25 reductions, or until bracket width is `1e-12` times interval length, or until deadline.
6. Return the best alpha (`zero alpha` if no improvement) and final point after evaluating the exact objective of final balanced candidate.

The line-search candidate must include the original best point in its basin but actual improvement is determined by exact re-evaluation. If the objective is not finite, decrement-probe with reduced candidates.
