At a local minimum of the minimax problem, we have:
- The active set S = {s : F_s = max} has |S| ≥ 2 (otherwise it's not a true minimax)
- The average active gradient projected to the tangent space is zero (KKT condition)
- This means no single direction can reduce all active terms simultaneously

To escape such a point, we need to:
1. Perturb h to change the active set
2. Use a direction that reduces the non-active terms (which become active after the move)
3. Use a second-order direction (exploiting the curvature)

The quadratic structure is exactly what enables #3! Even at a KKT point, the curvature (second derivative) can provide a descent direction. Specifically, if the Hessian of the max objective is negative definite in some direction, we can descend.

For the quadratic line search: at a KKT point, the first-order change b_s·d = 0 for all active s. The second-order change is c_s·α². If c_s < 0 for the active s (i.e., q_s = -c_s > 0, meaning the function is concave in that direction), then the objective decreases to second order.

So the quadratic line search can find improvements even at first-order stationary points! This is a key advantage.

Let me make sure my implementation handles this: the direction d should be chosen to maximize the second-order decrease, i.e., minimize max_s c_s (for the active set). Since c_s = -q_s = -Σ d_i d_{i+s}, we want to maximize q_s = Σ d_i d_{i+s} for the active s.

Actually, the optimal direction at a KKT point is the one that maximizes the minimum second-order decrease. This is a semidefinite programming problem, but we can approximate it.
