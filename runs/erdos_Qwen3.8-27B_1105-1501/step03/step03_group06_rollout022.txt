```python
    target = n / 2.0
```

**Direct minimax subgradient with momentum**:

The function C(h) = max_i g_i(h) is the maximum of differentiable functions. Its subdifferential at h is the convex hull of {∇g_i(h) : i ∈ A(h)} where A(h) is the active set.

The steepest descent direction is:

This is a QP:

s.t. sum(w) = 1, w ≥ 0

For small |A| (say 5-10), this QP is tiny and can be solved very fast.

```python
    active_lags = top_K - (n - 1)
    G_A = np.vstack([_grad_row(h, d) for d in active_lags])  # (K, n)

    # This is equivalent to: min 0.5 * ||G_A^T w||^2 s.t. sum(w)=1, w>=0
    # KKT: G_A G_A^T w + 1*lambda - mu = 0, mu >= 0, mu_i * w_i = 0

    from scipy.optimize import minimize as _min
    
    def qp_obj(w):
        Gw = G_A.T @ w
        return 0.5 * float(np.dot(Gw, Gw))
    
    def qp_jac(w):
        Gw = G_A.T @ w
        return G_A @ Gw
    
    qp_cons = [{'type': 'eq', 'fun': lambda w: np.sum(w) - 1.0,
                'jac': lambda w: np.ones(K)}]
    qp_bounds = [(0.0, 1.0)] * K
    w0 = np.ones(K) / K
    
    try:
        qp_res = _min(qp_obj, w0, jac=qp_jac, method='SLSQP',
                     bounds=qp_bounds, constraints=qp_cons,
                     options={'maxiter': 100, 'ftol': 1e-14})
        w = np.clip(qp_res.x, 0.0, 1.0)
        w /= np.sum(w)
    except Exception:
        w = np.ones(K) / K
    
    # Descent direction
    d = -G_A.T @ w
    # Make sum(d) = 0 (to preserve integral constraint)
    d -= np.mean(d)
    
    return d
```

At each iteration:

```python
def _solve_weight_qp(M, K, maxiter=200):
    """Solve min 0.5*w'*M*w s.t. sum(w)=1, w>=0 using projected gradient."""
    w = np.ones(K) / K
    # Step size: 1 / L where L = max eigenvalue of M
    # For simplicity, use a fixed small step or backtracking
    L = float(np.max(np.abs(np.linalg.eigvals(M)))) + 1e-10
    step = 1.0 / L
    
    for _ in range(maxiter):
        grad = M @ w
        w_new = w - step * grad
        # Project onto simplex {w: sum(w)=1, w>=0}
        w_new = _project_simplex(w_new)
        if np.max(np.abs(w_new - w)) < 1e-12:
            break
        w = w_new
    return w
```

I need a `_project_simplex` function:
```python
def _project_simplex(v):
    """Project v onto the probability simplex {w: sum(w)=1, w>=0}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)
```

This is the standard Aidad & Wright simplex projection.
