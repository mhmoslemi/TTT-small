```python
def _project(v, target):
    # Project v onto {x : 0 <= x_i <= 1, sum(x) = target}
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo = float(v.min()) - 2.0
    hi = float(v.max()) + 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    x = np.clip(v - (lo + hi) / 2.0, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-12:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x
```

```python
    bounds.append((None, None))
```

OK so `linprog(c, A_ub, b_ub, A_eq, b_eq, bounds)` minimizes c^T x subject to the constraints.

c^T x = α (the last variable). So it's MINIMIZING α.

And the constraint is G @ p - α ≤ -scores, i.e., α ≥ scores + G @ p for all k.

So we're minimizing α subject to α ≥ max_k (scores_k + (G @ p)_k).

At the optimum, α* = max_k (scores_k + (G @ p)_k).

And we choose p to minimize this maximum. That's exactly what we want!

So the LP is correct: it finds the direction p that minimizes the predicted maximum correlation. Then we do a line search along p.

```python
    def __init__(self, n, target):
        self.n = n
        self.target = target
        self.dx = 2.0 / n
        self.ncorr = 2 * n - 1
    
    def ineq_fun(self, x):
        h = x[:self.n]
        t = x[self.n]
        corr = np.correlate(h, 1.0 - h, mode='full')
        return t - self.dx * corr
    
    def ineq_jac(self, x):
        n = self.n
        h = x[:n]
        dx = self.dx
        J = np.zeros((self.ncorr, n + 1))
        J[:, n] = 1.0
```
