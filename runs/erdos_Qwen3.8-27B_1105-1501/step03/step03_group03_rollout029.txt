Let me now think about the active-set SLSQP more carefully.

For the problem:
min h: max_k S_k(h)
s.t. sum(h) = n/2, 0 ≤ h ≤ 1

The KKT conditions at an optimal point h* (assuming interior, i.e., 0 < h* < 1) are:
- There exists λ such that for all k in active set A:
  sum_k∈A w_k * ∇S_k(h*) = λ * 1 (where sum w_k = 1, w_k ≥ 0)
- For k not in A: S_k(h*) < max S_j(h*)

The active set A is typically small (maybe 5-15 constraints out of 127).

So the approach is:
1. Compute scores, find active set A (e.g., top 10 scores)
2. Solve: min μ s.t. S_k(h) ≤ μ for k ∈ A, sum(h) = n/2, 0 ≤ h ≤ 1
   Using SLSQP with only |A| + 1 inequality constraints + 1 equality + bounds
3. After solving, check if any non-active constraint is violated (S_k > μ for k ∉ A)
4. If so, add it to A and repeat
5. If not, we've found a KKT point

This should be much more efficient than the smoothed approach because:
- SLSQP handles a small number of constraints efficiently
- We're optimizing the true objective, not a surrogate
- The active set is small, so the problem is well-conditioned

Let me also think about the subgradient approach. The subdifferential of f(h) = max_k S_k(h) at h is:
∂f(h) = conv{∇S_k(h) : k ∈ A(h)}

where A(h) = {k : S_k(h) = max_j S_j(h)} is the active set.

A natural subgradient is the average of gradients of active constraints:
g = (1/|A|) * sum_{k∈A} ∇S_k(h)

But a better subgradient for min-max problems is the one that minimizes the norm (minimum norm subgradient), which is a QP:
min ||sum w_k ∇S_k(h)||²
s.t. sum w_k = 1, w_k ≥ 0, k ∈ A

This gives the steepest descent direction for the nonsmooth function.

For the step size, Polyak's rule uses:
α_k = (f(h_k) - f*) / ||g_k||²

where f* is the optimal value (unknown). An approximation uses:
α_k = (f(h_k) - f_lb) / ||g_k||²

where f_lb is a lower bound on f*.

    m = G_active.shape[0]
    n = G_active.shape[1]
    if m == 1:
        return G_active[0]

        Gw = G_active.T @ w
        return float(np.dot(Gw, Gw))
    def qp_jac(w):
        Gw = G_active.T @ w
        return 2.0 * (G_active @ (G_active.T @ w))
    bounds = [(0.0, 1.0)] * m
    cons = [{'type': 'eq', 'fun': lambda w: np.sum(w) - 1.0,

    w0 = np.ones(m) / m

        return G_active.T @ w

def min_convex_pl(m, c, lo=0.0, hi=1.0):
    """Find min of max_d (m[d]*t + c[d]) over t in [lo, hi]."""
    K = len(m)
    # Sort by slope
    idx = np.argsort(m)
    m_s = m[idx]
    c_s = c[idx]
    
    # Build upper envelope
    # The upper envelope is a sequence of lines, each active on an interval [t_left, t_right]
    # Start with the line that has the highest value at t=lo
    # Then walk to the right
    
    # Actually, let's just evaluate at all breakpoints + endpoints
    candidates = [lo, hi]
    for i in range(K):
        for j in range(i+1, K):
            if m_s[j] != m_s[i]:
                t_cross = (c_s[i] - c_s[j]) / (m_s[j] - m_s[i])
                if lo <= t_cross <= hi:
                    candidates.append(t_cross)
    
    best_val = np.inf
    best_t = lo
    for t in candidates:
        val = np.max(m_s * t + c_s)
        if val < best_val:
            best_val = val
            best_t = t
    return best_t, best_val
```

def upper_envelope(m_s, c_s):
    """Build upper envelope of lines sorted by slope. Returns list of (m, c, t_start, t_end)."""
    # m_s sorted ascending
    stack = []
    for i in range(len(m_s)):
        while len(stack) >= 2:
            # Check if the second-to-last line is obsolete
            m1, c1 = stack[-2]
            m2, c2 = stack[-1]
            m3, c3 = m_s[i], c_s[i]
            # Intersection of line 2 and 3 is to the left of intersection of line 1 and 2
            if m3 == m2:
                if c3 >= c2:
                    stack.pop()
                continue
            t_12 = (c1 - c2) / (m2 - m1)
            t_23 = (c2 - c3) / (m3 - m2)
            if t_23 <= t_12:
                stack.pop()
            else:
                break
        stack.append((m_s[i], c_s[i]))
    # Compute breakpoints
    env = []
    for i in range(len(stack)):
        m, c = stack[i]
        if i == 0:
            t_start = -np.inf
        else:
            m_prev, c_prev = stack[i-1]
            t_start = (c_prev - c) / (m - m_prev)
        if i == len(stack) - 1:
            t_end = np.inf
        else:
            m_next, c_next = stack[i+1]
            t_end = (c - c_next) / (m_next - m)
        env.append((m, c, t_start, t_end))
    return env
```

- At each breakpoint t_b in [0,1]: the value is where two lines cross

The minimum is the smallest of these values.
