1. Approach and rationale

1.1 Central idea
The previous and the contemplated previous strategies mostly optimize a smooth surrogate maximum, do projected subgradient/pairwise moves, or try exhaustive finite binary/value-lattice relaxations. A different core is to treat the discrete problem as a finite number of differentiable inequality constraints joined by a single epigraph variable and let a constrained nonlinear-programming method solve those exact constraints at the actual regulator resolution. The optimization variable is a vector h in [0,1]^n together with one scalar raw maximum point z. Constraints are all exact finite-support correlations raw_k(h) <= z and the exact mass equality sum h = n/2. Minimizing z*scale exactly minimizes the discrete C5 in the local NLP model. A second stage tests whether a candidate can be pushed below explicit numeric thresholds by minimizing squared constraint excess at fixed threshold. A final global organization supplies exact nonlinear-programming local solves in structured mapped/basinhopping starting points, resolution resamplings, and strict exact objective acceptance.

This is materially different from a subgradient smoothing method because it gives the solver access to all exact correlation constraints simultaneously through analytic gradients, not one gradient combination at a time. It also lets the solver work in the natural epigraph set c_k <= z, where feasibility, bounds, and mass are exact constraints. The penalty-excess method also solves a different model: h with all lags above a threshold as optimizable residuals; direct exact evaluation determines if a lower constant is actually obtained.

1.2 Why this can improve the supplied parent
The parent has attained a very small gap near a plateau. Smoother or pairwise subgradient moves may settle at a flat active set, whereas epigraph NLP can allocate nonzero multipliers to multiple active lags and identify directions that simultaneously reduce them. Resolution sweeps add a separate mode: increasing resolution can reduce discretization maxima or create another basin while resampling the best solution in a smooth way. The threshold-execution stage is specifically tailored to the target C5 bound: it attempts to find a valid region for a preselected threshold (for example 0.38080), then exact evaluation either establishes the improved bound or rejects it.

1.3 Primary method and fallback hierarchy
Primary, always-used component:
- parent validation and exact scoring;
- analytic exact correlations and analytic active raw gradients;
- an epigraph bound constrained NLP using Scout SciPy SLSQP;
- joint continuous [0,1]/sum repair after every solution;
- exact final score re-evaluation and strict improvement acceptance.

Extension components for time budget:
- structured starting suspects rather than pure high-dimensional random;
- resolution interpolation/search over even sample lengths;
- threshold-squared-excess feasibility seeks;
- local basin perturbations with modest temperature/seed features.

These components are organized by time budget. Parent is always retained as valid fallback.

1.4 Hypotheses and limitations
- SLSQP/SQID is nonconvex and cannot guarantee a global optimum. The exact evaluator always decides the accepted candidate: accept no hypothetical constraint model result unless final h passes exact bounds, mass tolerance and exact c5 evaluation.
- The exact epigraph model h and z and constraint raw<=z describes the original discrete squared field exactly; the nonconvexity comes from bilinear raw terms. No claim of convexity.
- Prefix derivatives are thoroughly analytically derived and must be numerically verified; a wrong formula is invalidated by the internal validation phase.
- Resolution interpolation resamples the continuous piecewise/point curve; it does not guarantee lower or smoother exact values. Only exact scaled answer is comparable among n.
- The threshold procedure can be infeasible over a reachable plateau; if no candidate returns below the best c5, return parent or best exact candidate.

2. Mathematical specification

2.1 Exact discrete evaluator and variables
Let n be an even integer. Let h ∈ R^n denote evaluation grid point values at x centers x_i = (i + 0.5)/n. The finite-support direct correlation required by the evaluator is:
`raw_full = np.correlate(h, 1.0 - h, mode="full")`, length 2n-1.
Let dx = 2.0/n and define `raw_k(h) = raw_full[r]` where `r = k + (n-1)`, `k = -(n-1),...,n-1`. The scored C5 is `dx * max_k raw_k(h)`.
Feasibility over the discrete sample is:
`0 <= h_i <= 1`, `sum(h_i) = n/2`. Since this is float arithmetic, all returned vectors should satisfy the sum to at least machine tolerance and final computation after mutation guarantees distance from authority.

For h fixed, the output corresponds mainly to `raw_k = sum_i h_{i+k} q_i` where q=1-h and valid terms satisfy 0<=i<n, 0<=i+k<n. This maps as follows:
- For k=0: `raw_0 = sum_i h_i (1-h_i)`, grad_i = `1 - 2 h_i`.
- For k > 0: `raw_k = sum_{i=0}^{n-k-1} h_{i+k}(1-h_i)`. Its derivative wrt h_j is `+ (1-h_{j-k})` when j>=k, and `- h_{j+k}'`? Matrix form:
`g = zeros(n); if k >=0: g[k:n] += 1 - h[0:n-k]; g[0:n-k] -= h[k:n]`.
- For k < 0 (put l=-k): `raw_k = sum_{i=0}^{n-l-1} h_i (1-h_{i+l})`. Vector form:
`g[0:n-l] += 1 - h[l:n]; g[l:n] -= h[0:n-l]`.
This is directly tied to the raw values used by the evaluator and should be validated with finite differences on a random vector against the analytic array. No circular correlations are used.

2.2 Exact epigraph nonlinear program
Introduce one scalar z representing a raw point, not scaled. The epigraph model for the local problem at fixed n is:
Variables: `(h_1,...,h_n,z)`.
Minimize objective one scalar scaled constraint `z * dx`.
Constraints:
- `z - raw_k(h) >= 0`, for each of the 2n-1 full-correlation entries.
- `sum_i h_i - n/2 = 0`.
- `0 <= h_i <= 1` and `z >= 0`.
Because the objective minimizes z upper bound and the constraints require every raw correlation <= z, any feasible local model solution gives a strict lower or matching exact objective `z*dx`. This method is exact for the NLP, but nonconvex due to raw terms. Surface may permit escape. The precondition is feasible: start at feasible h and z: `z = max(raw(h))` and h corrected to exact bounds/mass.

A feasible local model result z* may be less than previous objective. The repair vector is found by inspecting the maximum raw values after joint feasibility projection. Candidate acceptance is exact: recompute values vector and exact c5 and accept only if c5 is below the incumbent within tolerance.
