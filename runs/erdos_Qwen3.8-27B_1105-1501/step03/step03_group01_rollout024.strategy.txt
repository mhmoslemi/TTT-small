1. Approach and rationale

1.1 Central idea

The supplied parent is a locally refined step-vector of modest length, but the objective
maximum of many bilinear finite-support overlaps is highly non-smooth and highly
constrained. Previous approaches centered on linearization/local model solvers, stochastic
re-sampling, and subgradient or pairwise movement. They can stall because the true
objective cannot see improvement directions in many flat, max-dominated regions. This plan uses the following materially different core: solve a sequence of smooth surrogate constrained minimizations of the exact discrete maximum, using scipy's constrained local optimizer SLSQP, with analytic gradients from soft-max approximation, then restore feasibility with an exact joint feasibility mechanism, accept candidates only by the original evaluator, and repair the final candidate with exact pair transfers. The smooth surrogate is not claimed to solve the original nonconvex problem. It is used as a highly effective device to move through the box-constrained affine constraint system while seeing all lags at once. After each surrogate minimum, the original finite support correlation objective is used for every acceptance and for final values.

1.2 Why this may improve the parent

The exact objective is max over encuentra all 2n-1 finite-support lags. Most previous gypsum/soft gradient routines either follow a single active lag or local random moves, which are unable to move multiple constraints simultaneously within smooth regions. The soft-max objective handles all lags with a differentiable measure and places near optimal divideable weighted gradient using softmax weights. The box constraints 0<=h_i<=1 and the exact linear constraint sum h_i = n/2 are supplied to the constrained nonlinear optimizer. The optimizer can take large feasible steps, discover several edges of the nonconvex feasible set at once, and bridge phases from active maxima propagation. Starting from a set of algorithmic multi-resolution seeds enables diverse local sheets. A mild pair exact quadratic line search afterward around final candidate expects to capture very small one sub-block residues; it is not needed as the primary mechanism.

1.3 What is justified and what is heuristic

Objective formulas, gradients, and feasibility repairs are exact or consistent exhaustive operations. The smooth surrogate solver is a local solver for a smooth approximation, so it can only accept any restart. The convergence of the combined stochastic program is empirical; no optimality claim is made. Non-smoothness, stale active index changes, and numerical feasibility are treated by acceptance on the original objective and by joint feasible vector repair mechanisms.

2. Mathematical specification

2.1 Discrete vector and exact objective

For a fixed output length n, define dx = 2.0 / n. The decision vector h is real and length n. Each vector corresponds to midpoint values on x_i = (i+0.5) dx. The feasible set is

    0 <= h_i <= 1 for i = 0, ..., n-1,
    sum_{i=0}^{n-1} h_i = n/2.

The integrated constraint and box constraints are formulated over the discrete samples in exactly the same way as the evaluator. Let

    corr(h,1-h) = np.correlate(h,1-h,'full')

and

    C_exact(h) = dx * max(corr(h,1-h)).

All candidates are evaluated by this score, including externally supplied `evaluate_erdos_solution` for final output. No circular correlation is combined into any formula. Only correlations of length 2n-1 are used. The correlation uses the evaluator order: first vector h, second vector 1-h.

2.2 Quadratic-representation for restricted path optimization
