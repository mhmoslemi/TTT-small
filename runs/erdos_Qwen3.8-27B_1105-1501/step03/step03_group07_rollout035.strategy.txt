1. Approach and rationale

1.1 Central idea

The supplied parent solution is close to the target and appears to be trapped by a local finite-support minimax optimum. Earlier attempts are centered on soft-gradient/ph-over-lags methods, pairwise moves, line searches, and discrete heuristic neighborhoods. This plan instead makes the primary optimization engine a **smoothed exact minimax envelope solved with constrained nonlinear programming**, followed by an **epigraph nonlinear program that treats the active (or all) lag inequalities explicitly**. Exact feasibility and exact evaluation are preserved at every accepted return point.

The two core mechanisms are:

- **Smooth envelope NLP**: minimize a log-sum-exp surrogate over the scaled correlation values of all signed finite-support shifts, subject to the exact interval-mean equality and box constraints, using a smooth optimizer (SLSQP/trust-constr). This naturally lets many near-active shifts exert force simultaneously, instead of a parent that follows a single temperature-weighted gradient direction and only occasionally uses full gradients.
- **Exact epigraph NLP**: solve the local problem  
  minimize t subject to exact scaled shifted-overlap inequalities for a set of lag constraints and box/equality constraints. The epigraph model can be solved once with a small active set, then re-solved after adding missing violated constraints or, for small enough n, directly with all constraints.

This is materially different from the parent because it does not search by subgradient momentum or pairwise coordinate moves. It solves a smooth or constraint-coupled finite-dimensional nonlinear program whose exact result is then accepted or rejected by the official evaluator. Global diversity is supplied by alternative parents (binary sequences, perturbations, resampled resolutions, and random smooth structured starts), but the improvement engine is the constrained minimax NLP.

1.2 Why it should help

The problem is a nonsmooth min (h) max_s F_s(h). A subgradient method treats only a few lags and cannot easily expose a multi-lag displacement. The epigraph form directly expresses the maximum constraints and, through gradient coupling, moves all variables in a way that reduces the grammar of simultaneously active lag inequalities. The smooth LSE mode offers a differentiable path to a basin where more lags become near-tight. The epigraph mode then refines a local point to high precision with exact final verification.

1.3 Limitations (not claims)

- The original problem is nonconvex. Both log-sum-exp smoothing and epigraph NLPs use local solvers without nonconvex global optimality guarantees.
- The epigraph local solve with a restricted active set may raise inactive constraints; the official exact evaluator rejects the resulting point unless it improves the true maximum.
- Smooth LSE can be numerically delicate for small temperature; the plan uses stable evaluation and annealing.
- The returned value is always feasible by a joint feasibility repair mechanism and exactly reverified. It is accepted only when the exact official metric improves the retained parent and the repair does not increase the value beyond the recorded bound.
- If these methods fail, the retained feasible parent construction is returned unchanged.

2.1 Grid, units, and exact objective

- h in [0, 1]^n

- exact metric:
  `C(h) = max_{r = -(n-1), ..., n-3, n-1} dx * F_r(h)`,

The authoritative evaluation in the Python harness is always:
`float(np.max(np.correlate(h, 1 - h, mode="full")) * (2.0 / n))`.
The exact evaluator must be retuned. Internal constraint arrays and internal gradients use the direct offset definition. It is a fact that they contain exactly the same `2n-1` finite overlap terms, though their conventional ordering may be reverse or permuted relative to `np.correlate`; the evaluator only takes the maximum, and the epigraph model only uses constraints over all offsets, so a fixed offset-keyed own correspondence is valid as long as gradients correspond to corresponding constraints.
