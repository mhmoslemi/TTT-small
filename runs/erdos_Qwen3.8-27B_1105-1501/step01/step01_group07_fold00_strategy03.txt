1. Approach and rationale

The parent construction was obtained by smoothed maximum-gradient movement plus stochastic coordinate and two-coordinate repairs. That is a useful but limited local exploration scheme: random coordinate moves change one or two boundary-sensitive correlations at a time, while the true minimax objective is controlled by a small active set of lags that often need to be decreased simultaneously. The parent is therefore likely trapped in a basin where the individual coordinates and adjacent pairs are already locally insensitive, yet a coordinated move in the full vector could reduce the maximum overlap.

The proposed replacement is a direct constrained minimax formulation over the entire vector, with exact finite-support overlap constraints and analytic first derivatives. The primary mechanism is:

- Represent the problem as an epigraph nonlinear program: minimize a scalar overlap upper bound t subject to the exact finite-correlation values being no larger than t, the preserved boundary-correlation definitions, 0 ≤ h_i ≤ 1, and sum_i h_i = n/2.
- Solve this full-dimensional problem from many feasible starting points using a constrained local nonlinear optimizer. The formulation is not convex because the overlap functions contain bilinear terms h_i(1-h_j), and no global optimality claim is made. It is justified as a substantially richer local descent model than random gradients or random pair moves: simultaneous changes across all components are allowed while all current finite-support lags are kept in the active constraint model.
- Every proposal is projected onto the exact feasible box and sum constraint and is accepted only after evaluating the true task metric max(np.correlate(h, 1-h, "full")) * dx. Thus the method never claims or trusts an inaccurate surrogate objective for the final reported bound.
- Two auxiliary diversification mechanisms are added to avoid staying near the parent basin:
  1. A binary Hamming-neighborhood integer subproblem, solved only when useful and under a strict time limit, using SciPy's mixed-integer programming when available. It optimizes an exact linearized version of selected active overlaps over binary vectors close to a current best binary quantization.
  2. Deterministic local pair polishing along sum-preserving interleaved coordinate moves, with a scalar one-dimensional optimizer or grid plus bounded minimization evaluator, restricted to promising pairs.

This differs from the prior algorithm in a substantive way: the local model is an epigraph constrained program over all coordinates and all finite lags, with analytic gradients, not a scalar-smoothed soft-max gradient plus random coordinate jumps. It is designed to escape parent basins by structured starts, binary Milp-style local improvements, and resolution/pair polishing, while retaining the supplied parent as a validated fallback.

Important limitations:
- The true problem is nonconvex; the nonlinear constrained solver is a local method. No proof of global optimality or guaranteed achievement of 0.3808 is given.
- The Milp component is local under the heuristic Hamming and active-lag restriction and is optional; if it is too slow in the environment it is skipped without harming feasibility.
- The pair polishing is not a branch-and-bound sequence; it is a final local sharpening step.
- The final bound is exact after final repair and exact evaluation, but repair can lose a small intermediate gain.

2. Mathematical specification

Given n points h[0..n-1], dx = 2/n, feasibility:

- 0 ≤ h[i] ≤ 1.
- sum_i h[i] = n/2.
- objective:

C5(h) = max_{r=0}^{2n-2} F(h, r) * dx.

The lag used by np.correlate, 1-h, mode="full" is conventionally r = n-1 + k, where k = -(n-1), ..., n-1. The exact value associated with k may be written as:

For k ≥ 0 (fewer first-vector indices used):

F_nk(h) = sum_{j=0}^{n-k-1} h[j] * (1 - h[j+k]).

For k < 0, write p = -k > 0:

F_nk(h) = sum_{j=0}^{n-p-1} h[j+p] * (1 - h[j]).

The reported score is:

score_exact(h) = dx * max_k F_nk(h).

This matches true correlation finite-support evaluator. It includes both directions only because the set of all k is used. It does not use circular correlation, and it keeps all boundary truncations.

Epigraph variable:

z = [h[0], ..., h[n-1], t], where t is a scalar minimizing the maximum overlap.

For every k, define nonlinear constraint:

g_k(z) = F_nk(h) - t ≤ 0.

Feasible starting points:

- h0 feasible by construction or repair.
- t0 = score_exact(h0).
- If using a regularized epigraph, z_weighted = [h[0..n-1], t], h_ref is the start point's feasible vector.

A convenient regularized objective for local runs is:

minimize t + lambda_q * sum_i (h[i] - h_ref[i])^2.

lambda_q ∈ {0, 0.02}. lambda_q = 0 gives the strict minimax epigraph. lambda_q > 0 encourages nearby feasible local descent and can produce different local optima; use it for some starts.

Analytic gradients of F_nk(h) used by both objective and constraints:

For k ≥ 0, m = n-k:

gradient vector grad(h) briefly:

grad[j] += dx * (1 - h[j+k]) for j = 0,...,m-1.
grad[j+k] -= dx * h[j] for j = 0,...,m-1.

For k < 0 with p=-k and m = n-p:

grad[j+p] += dx * (1 - h[j]) for j = 0,...,m-1.
grad[j] -= dx * h[j+p] for j = 0,...,m-1.

Then for epigraph constraint g_k(h,t):

∂g_k/∂h = grad(h).
∂g_k/∂t = -1.

For equality constraint:

eq(z) = sum_{i=0}^{n-1} h[i] - n/2 = 0.
∇eq = [1^n, 0].

For objective with lambda_q regularization:

∂obj/∂h_i = 1 for t variable plus 2 * lambda_q * (h_i - h_ref_i) for i < n.
∂obj/∂t = 1.
For lambda_q = 0, only t variable coefficient is 1.

Binary Hamming active-lag subproblem:

Use only for a reference binary vector x_ref ∈ {0,1}^n and target m = n/2 for even n. For an odd target, skip Milp. The variables are:

- x[0..n-1] integer 0/1.
- y[u] continuous [0,1] for every selected overlap pair (name derived from selected lags).
- v[0..n-1] continuous [0,1] for Hamming distance.
- t continuous [0, inf).

For each selected pair (first index a, second index b) for a nonnegative-direction formula:

x_a - product - x_b contributes. Impose:

y <= x_a.
y <= 1 - x_b.

This upper hull is exact at binary x for min-overlap problems: given x, minimizing the overlap constraint y will set y = x_a(1-x_b). No lower bound constraints are needed because the objective of minimizing overlaps gives each y its maximum feasible value independently for each x.

For a selected lag k and all overlap occurrences in its finite support:

overlap_lhs(k) = dx * (sum_x_first - sum_y_selected_for_k).

where sum_x_first uses h[j] (h[j+k] for negative lag definitions). Add constraint:

overlap_lhs(k) - t <= 0.

For each i in {0,..,n-1}, Hamming variables v enforce:

if x_ref[i] == 0: v[i] >= x[i] - 0.
if x_ref[i] == 1: v[i] >= 1 - x[i].

and objective (Hamming bound):

sum_i v[i] <= D.

No need for integrality of v; for integer x and constraints above minimum sum_i v[i] is exactly bit flips.

Also integer constraint:

sum_i x_i = n/2.

For binary Milp, solve over Hamming local box distance <= D. Starting D values: 4, 6, 10, 14 (if time allows). As scalary selected active lag K from 12 to 22 if later. The vectors are evaluated through exact objective after solve. If selected constraints hidden overlap columns become > t, solve may produce a point evaluated as worse or better; after true acceptance evaluation always occurs. Do not claim a global true Milp optimum unless all lags are selected. Since active-lag reduction speeds computations using robust settings.
