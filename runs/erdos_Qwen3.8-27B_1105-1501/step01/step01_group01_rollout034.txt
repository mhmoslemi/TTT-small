def binary_score(bits, n):
    """Compute max correlation for a binary sequence represented as int."""
    max_c = 0
    full_mask = (1 << n) - 1
    for s in range(n):
        if s == 0:
            continue
        if s > 0:
            mask = (1 << (n - s)) - 1
            ones_shifted = (bits >> s) & mask
            zeros = (~bits) & mask
            c = (ones_shifted & zeros).bit_count()
        # Also compute for negative shift
        t = s
        ones_shifted_neg = (bits << t) & full_mask
        zeros_neg = (~bits) & full_mask
        mask_valid = full_mask ^ ((1 << t) - 1)  # positions >= t
        c_neg = (ones_shifted_neg & zeros_neg & mask_valid).bit_count()
        if c > max_c:
            max_c = c
        if c_neg > max_c:
            max_c = c_neg
    return max_c

def binary_local_search(bits, n, max_iters=10000, rng=None):
    """Local search on binary sequences with pair swaps."""
    current_score = binary_score(bits, n)
    zeros = [i for i in range(n) if (bits >> i) & 1 == 0]
    ones = [i for i in range(n) if (bits >> i) & 1 == 1]
    
    for it in range(max_iters):
        improved = False
        # Try random swaps
        for _ in range(20):
            a = rng.choice(zeros)
            b = rng.choice(ones)
            new_bits = bits | (1 << a) & ~(1 << b)  # set a to 1, b to 0
            new_score = binary_score(new_bits, n)
            if new_score < current_score:
                bits = new_bits
                current_score = new_score
                # Update zeros and ones
                # a was 0, now 1
                # b was 1, now 0
                zeros.remove(a)
                ones.append(a)
                ones.remove(b)
                zeros.append(b)
                improved = True
                break
        if not improved:
            # Try all pairs (expensive but thorough)
            best_pair = None
            best_score = current_score
            for a in zeros:
                for b in ones:
                    new_bits = bits | (1 << a) & ~(1 << b)
                    new_score = binary_score(new_bits, n)
                    if new_score < best_score:
                        best_score = new_score
                        best_pair = (a, b, new_bits)
            if best_pair:
                a, b, bits = best_pair
                current_score = best_score
                zeros.remove(a)
                ones.append(a)
                ones.remove(b)
                zeros.append(b)
            else:
                break
    return bits, current_score

The LSE surrogate is:
Φ(h) = max_j C_j + (1/β) * log(sum_j exp(β(C_j - max_j C)))

where C_j = dx * c_j and c_j is the raw correlation.

The gradient:
∂Φ/∂h[p] = sum_j w_j * ∂C_j/∂h[p]

where w_j = exp(β(C_j - C_max)) / sum_k exp(β(C_k - C_max)) (these sum to 1)

And ∂C_j/∂h[p] = dx * ∂c_j/∂h[p]

So ∂Φ/∂h[p] = dx * sum_j w_j * ∂c_j/∂h[p]

Note: there's NO 1/β factor in the gradient of Φ! Let me re-derive.

Φ(h) = C_max + (1/β) log(Σ_j e^{β(C_j - C_max)})

∂Φ/∂h[p] = Σ_j (1/β) * e^{β(C_j-C_max)} / Σ_k e^{β(C_k-C_max)} * β * ∂C_j/∂h[p]
           = Σ_j w_j * ∂C_j/∂h[p]
           = dx * Σ_j w_j * ∂c_j/∂h[p]

Yes! The β cancels out. The gradient of Φ is simply the weighted average of the gradients of C_j, where the weights are the softmax weights.

This is important because it means the gradient doesn't depend on β (except through the weights w_j). For large β, w_j concentrates on the max, and the gradient approaches the gradient of the max function (at the unique max). For small β, the weights are more uniform.

**Iterative reweighting / mirror descent approach:**

The problem is to minimize max_j C_j(h) subject to h ∈ [0,1]^n, sum(h) = n/2.

This can be reformulated as a convex optimization if we fix the "dual" variables. Specifically, by duality:
min_h max_j C_j(h) = min_h max_{p ∈ Δ} Σ_j p_j C_j(h)

where Δ is the simplex. The inner max over p is trivial (just take p concentrated on the max). But we can use a minimax formulation:

min_h max_{p ∈ Δ} Σ_j p_j C_j(h)

By von Neumann's minimax theorem (if the problem were convex-concave, which it's not exactly due to bilinear C_j), we could swap:
max_{p ∈ Δ} min_h Σ_j p_j C_j(h)

But since C_j is bilinear (not linear), the minimax theorem doesn't directly apply. However, we can still use an iterative approach:
1. Given p, minimize Σ_j p_j C_j(h) over h (this is a quadratic program, solvable)
2. Update p to point to the max C_j(h)
3. Iterate

This is essentially the **multiplicative weights** or **exponentiated gradient** method applied to the game form of the problem.

Step 1: minimize Σ_j p_j C_j(h) = Σ_j p_j dx Σ_i h[i+s_j](1-h[i+j])
This is a quadratic function of h (since each term is h[i]*h[j]). Specifically:
= dx * Σ_j p_j Σ_i h[i+s_j] - dx * Σ_j p_j Σ_i h[i+s_j] * h[i]

The first term is linear in h, the second is quadratic. So we're minimizing a quadratic over a polytope. This can be done with scipy's minimize or even analytically for small n.

Actually, for the quadratic term: Σ_j p_j Σ_i h[i+s_j] * h[i] = h^T (Σ_j p_j A_j) h where A_j is the matrix representing the quadratic form at shift j.
