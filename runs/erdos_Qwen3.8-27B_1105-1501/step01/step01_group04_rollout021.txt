But actually, for the local search, I just need to know if the max decreased. I can track the current max and the count of k's achieving it. If the swap decreases all the max-achieving k's (and doesn't increase any other k above the current max), it's an improvement.

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def compute_overlaps(h):
    """Compute over(k) for k=1..n-1"""
    n = len(h)
    # over(k) = sum_{i=0}^{n-1-k} h[i]*(1-h[i+k])
    # This is the first n-1 elements of np.correlate(h, 1-h, 'full') starting from index n-1
    corr = np.correlate(h, 1.0 - h, mode='full')
    return corr[n-1:]  # lags 0, 1, ..., n-1

def to_binary(h, n):
    """Project h to a binary-like solution with sum = n/2"""
    # For odd n: 49 ones, 1 half, 49 zeros (for n=99)
    # For even n: n/2 ones, n/2 zeros
    h = h.copy()
    if n % 2 == 0:
        # Sort and threshold
        sorted_idx = np.argsort(h)[::-1]
        h[:] = 0.0
        h[sorted_idx[:n//2]] = 1.0
    else:
        # Need sum = n/2 (e.g., 49.5 for n=99)
        # Use n//2 ones, one 0.5, rest zeros
        sorted_idx = np.argsort(h)[::-1]
        h[:] = 0.0
        h[sorted_idx[:n//2]] = 1.0
        h[sorted_idx[n//2]] = 0.5
    return h

def local_search_binary(h, max_iters=10000):
    """Best-improvement local search using all swaps"""
    n = len(h)
    best_c5 = compute_c5(h)
    best_h = h.copy()
    
    for it in range(max_iters):
        ones = np.where(h == 1.0)[0]
        zeros = np.where(h == 0.0)[0]
        
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        best_delta = 0
        best_move = None
        
        for i in ones:
            for j in zeros:
                h_test = h.copy()
                h_test[i] = 0.0
                h_test[j] = 1.0
                c5 = compute_c5(h_test)
                if c5 < best_c5 - 1e-12:
                    best_delta = c5
                    best_move = (i, j)
        
        if best_move is None:
            break  # local optimum
        
        i, j = best_move
        h = h.copy()
        h[i] = 0.0
        h[j] = 1.0
        best_c5 = best_delta
        best_h = h.copy()
    
    return best_h, best_c5

Let me think about a better approach. Instead of trying all swaps one at a time, I can:

2. For each candidate swap (i,j), compute the new correlation array analytically
3. Find the swap that minimizes max(new_corr)

The analytical update: when h[i] changes from 1 to 0 and h[j] changes from 0 to 1:

For the full correlation corr_full[m] = ∑_t h[t]·(1-h[t+m-(n-1)]) (where the sum is over valid t):

The change in corr_full[m] is:
- Contribution from position i: h[i] changes from 1 to 0
  - affects corr_full[m] where the formula involves h[i]·(1-h[i+m-(n-1)]) or h[t]·(1-h[i])
  
This is getting complicated with the full correlation indexing. Let me just use the forward overlap:

over[k] = ∑_{i=0}^{n-1-k} h[i]·(1-h[i+k]) for k=0,...,n-1

When h[i]: 1→0 and h[j]: 0→1:

Δover[k] = 
  (if i ≤ n-1-k) [-(1-h[i+k])] +  (if j ≤ n-1-k) [+(1-h[j+k])]
  + (if k ≤ i) [h[i-k]] - (if k ≤ j) [h[j-k]]
  - (if i ≤ n-1-k and j ≤ n-1-k and i+k == j) [correction term]
  - (if i ≤ n-1-k and j ≤ n-1-k and j+k == i) [correction term]

The correction terms handle the case where i+k=j or j+k=i, which would double-count.

This is O(n) per swap, and with 2450 swaps, that's O(n²) per sweep = 99² ≈ 10K operations. Very fast!
