1. Approach and rationale

The previous parent situation is highly local-optimum sensitive: the objective is the exact maximum over all discrete lags, and a good point usually has several lag constraints simultaneously active. A pure summed-gradient or single-stage SLSQP descent can either move mass against the wrong balance of active offsets or fail to make coordinated, box-feasible moves when several constraints participate. The plan below therefore changes the local search method and adds two complementary generator families:

A. An exact linearized minimax local descent via a small LP per iteration. At each local step, the nonconvex minimax problem is replaced only for search-direction selection by the convex linear programming subproblem obtained by freezing current correlation values and using exact analytic Jacobians. The LP chooses a feasible tangent direction that is predicted to reduce the largest current correlations while not allowing nonactive correlations to gain too much. Every resulting point is repaired to the exact target sum and accepted only if the authoritative evaluator improves.

B. A discrete balanced-sequence optimizer over 0/1 patterns (and explicit half-mass if the target sum is half-integral). In the original evaluator, a discrete improvement that is also nearly 0/1 can expose structure that continuous gradient methods miss, and it serves as an additional basin of attraction. Successful discrete states can be converted into feasible continuous states for further LP polishing.

C. The parent, if supplied, is never copied numerically into the code and is not thrown away. It is used as the initial feasible archive, canonicalized, projected, interpolated to neighboring resolutions, read by the discrete pipeline, and used as the guaranteed fallback. Small-scale continuous interpolation and population averaging transfer parent structure without importing long numeric tables.

This is not a global optimization proof. The exact objective is bilinear and nonconvex; LP substeps are only descent-direction surrogates and SLSQP local NLP polish is only a final refinement. The only accepted improvements are those of the original evaluator with the exact box and mass constraints. The method is materially different from the previous program: it does not rely on random multi-coordinate gradient plus random pair jumps as the main engine; it instead uses LP-generated tangent directions subject to the active offsets, adds exact discrete annealing, and applies stricter feasibility projection and cross-resolution ancestry.

2. Mathematical specification

Let the evaluated sequence be h ∈ R^n with samples representing equal-width steps on [0,2]. Let dx = 2/n. Feasibility is:

0 ≤ h_i ≤ 1 for all i,
∑_i h_i = n/2,
with the operations performed in double precision but validated after every acceptance.

Let dx = 2/n. The authoritative score is

score(h) = max_{r=0,...,2n-2} c_r(h) dx,

where c_r(h) is the full correlation entry:

np.correlate(h, 1-h, mode="full")[r].

Define the offset

s = r - (n-1).

With the standard np.correlate convention, the correlation entry for offset s is

c_s(h) = ∑_{j: 0≤j<n and 0≤j+s<n} h_{j+s} (1 - h_j).

The analytic gradient of the scaled correlation entry c_s(h) dx with respect to h is:

If s ≥ 0:
- For j = s,...,n-1: add dx (1 - h_{j-s}) to g_j, because h_j appears as the first factor h_{j+s}.
- For j = 0,...,n-s-1: add dx (-h_{j+s}) to g_j, because h_j appears as part of 1-h_j in the second factor.

If s < 0:
- For j = 0,...,n+s-1: add dx (1 - h_{j-s}) to g_j. More explicitly, if a=-s, for j=0,...,n-a-1, add dx (1-h_{j+a}).
- For j = -s,...,n-1: add dx (-h_{j+s}) to g_j. More explicitly, if a=-s, for j=a,...,n-1, add dx (-h_{j-a}).

The gradient matrix G(h) is a (2n-1) × n matrix whose row r is scaled by dx according to the above. It must match finite-difference finite tests against c_s(h) dx; if a sign convention discrepancy appears, adjust the correlation evaluation helper to one that is verified against the official scorer. Smooth or LP substeps are only used to propose steps; all accepted states are scored using the official evaluator vector:

np.max(np.correlate(h, 1-h, mode="full")) * dx.

An exact feasibility repair, not a generic clip-and-rescale, is required. Use project_to_target(v,n) as the minimal-L2-ish stable feasible projection:

- target = n/2.
- If target == n, return all ones; if target == 0 return zeros.

For discrete optimization, when n is even, exactly n/2 entries are 1 and all others 0, which is automatically feasible.
