```python
def grad_lse(h, beta):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    max_c = np.max(corr)
    shifted = np.clip(beta * (corr - max_c), -500.0, 0.0)
    exp_vals = np.exp(shifted)
    exp_sum = np.sum(exp_vals)
    if exp_sum < 1e-300:
        return np.zeros(n)
    w = exp_vals / exp_sum
    u = 1.0 - 2.0 * h
    return dx * np.correlate(w, u, mode='valid')
```

This is O(n) time (correlate for small arrays is O(n²) but with small constant, and for n≤64 it's trivially fast).
