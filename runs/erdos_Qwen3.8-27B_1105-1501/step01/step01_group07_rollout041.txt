def solve_1d_convex(A, s, lo, hi):
    """
    Find argmin of max_k (A[k] + s[k]*x) for x in [lo, hi].
    A: array of intercepts (length m)
    s: array of slopes (length m)
    Returns optimal x.
    """
    # Start at lo, find active line
    x = lo
    active = argmax(A + s*lo)
    # Walk to the right
    while True:
        # Find the next breakpoint: where another line crosses the active line
        # The active line is A[active] + s[active]*x
        # Another line k crosses it at x = (A[active] - A[k]) / (s[k] - s[active]) (if s[k] > s[active])
        # We want the smallest such x that is > current x and ≤ hi
        next_x = hi
        next_active = None
        for k in range(len(A)):
            if k == active:
                continue
            if s[k] > s[active]:
                x_cross = (A[active] - A[k]) / (s[k] - s[active])
                if x_cross > x and x_cross < next_x:
                    next_x = x_cross
                    next_active = k
        if next_active is None or next_x >= hi:
            # No more breakpoints before hi, minimum is at hi or at current x
            # Since we're walking right and the function was decreasing, min is at next_x or hi
            return min(next_x, hi)
        # Check if function is still decreasing at next_x
        # The derivative from the right at next_x is s[next_active]
        # The derivative from the left is s[active]
        # If s[next_active] > 0, function is increasing, so min is at next_x
        # If s[next_active] < 0, function is still decreasing, continue
        # Actually, the minimum is where the slope changes from negative to positive.
        # At a breakpoint, the slope
        # jumps from s[active] to s[next_active].
        # If s[active] < 0 and s[next_active] > 0, the min is exactly at next_x.
        # If s[next_active] < 0, continue walking.
        # If s[active] >= 0, the min was at a previous point (shouldn't happen if we started at lo and walked right).
        if s[next_active] >= 0:
            return next_x
        # Otherwise, continue
        x = next_x
        active = next_active
    # This should not be reached
    return hi
```

Wait, this isn't quite right either. The minimum of a convex function is where the subdifferential contains 0. For a piecewise-linear convex function, this means the slope changes from negative to positive (or is zero).

Let me think again. Walking from left to right:
- At the left endpoint, the active line has some slope.
- As we move right, the active line changes at breakpoints.
- The slope of the upper envelope is non-decreasing (since it's convex).
- The minimum is where the slope crosses zero (or where it goes from negative to positive).

So the algorithm is:
1. Start at x = lo. Find the active line (max value).
2. If its slope ≥ 0, the minimum is at lo.
3. Otherwise, find the next breakpoint (where another line with steeper slope takes over).
4. Move to that breakpoint.
5. Repeat until the slope becomes ≥ 0.

At a breakpoint where the slope jumps from s_old < 0 to s_new > 0, the minimum is exactly at that point (the function has a "kink" there, and the subdifferential [s_old, s_new] contains 0).

If the slope jumps from s_old < 0 to s_new < 0, continue to the next breakpoint.
If the slope is exactly 0 at any point, that's a minimum (the whole interval where slope=0 is optimal, but any point works).
