Let me analyze this problem carefully.

The task is to find a step function h: [0, 2] → [0, 1] that minimizes the overlap integral C₅ = max_k ∫ h(x)(1-h(x+k)) dx, subject to ∫₀² h(x) dx = 1.

The previous program achieved C₅ bound = 0.381121, and the current record is C₅ ≤ 0.38085. The target is to beat 0.3808.

The strategy suggests using exact one-dimensional line search along various directions (gradient, pair-transfer, random) with quadratic fitting of the correlation function along the line. This is a good approach because:

1. The objective is a max of quadratic functions of h
2. Along any feasible line h(t) = h + t*d, each correlation is a quadratic in t
3. We can find the exact minimum of the max along that line

Let me implement this approach:

1. Start with `initial_h_values` (n=99)
2. Compute the exact objective
3. Generate directions (gradient-based, pair-transfer, random)
4. For each direction, find the exact minimum along the feasible line segment
5. Accept improvements
6. Repeat with perturbation when stuck

Key implementation details:

- For lag L ≥ 0: c_{n-1+L} = Σ_{i=0}^{n-1-L} (h[i+L]+t*d[i+L])(1-h[i]-t*d[i])
  = Σ (h[i+L] - h[i]h[i+L] + t*d[i+L] - t*d[i]h[i+L] - t*h[i+L]d[i] - t²*d[i+L]d[i])
  
  Wait, let me be more careful:
  c_L(t) = Σ_{i=0}^{n-1-L} (h[i+L] + t*d[i+L])*(1 - h[i] - t*d[i])
  = Σ (h[i+L](1-h[i]) + t*d[i+L]*(1-h[i]) - t*h[i+L]*d[i] - t²*d[i+L]*d[i])
  = c_L(0) + t*Σ(d[i+L]*(1-h[i]) - h[i+L]*d[i]) + t²*Σ(-d[i+L]*d[i])

So A_k = -Σ d[i+L]*d[i], B_k = Σ(d[i+L]*(1-h[i]) - h[i+L]*d[i]), C_k = c_L(0)

For negative lag -M:
c_{-M}(t) = Σ_{i=0}^{n-1-M} (h[i]+t*d[i])*(1-h[i+M]-t*d[i+M])
= Σ(h[i]*(1-h[i+M]) + t*d[i]*(1-h[i+M]) - t*h[i]*d[i+M] - t²*d[i]*d[i+M])

So A_k = -Σ d[i]*d[i+M], B_k = Σ(d[i]*(1-h[i+M]) - h[i]*d[i+M]), C_k = c_{-M}(0)

For lag 0:
c_0(t) = Σ (h[i]+t*d[i])*(1-h[i]-t*d[i])
= Σ(h[i] - h[i]² + t*d[i] - t*h[i]*d[i] - t*h[i]*d[i] - t²*d[i]²)
= c_0(0) + t*Σ d[i]*(1-2h[i]) + t²*Σ(-d[i]²)

Wait, let me redo: (h_i + t*d_i)(1 - h_i - t*d_i) = h_i(1-h_i) + t*d_i*(1-h_i) - t*h_i*d_i - t²*d_i²
= h_i(1-h_i) + t*d_i*(1-2h_i) - t²*d_i²

So A_0 = -Σ d[i]², B_0 = Σ d[i]*(1-2h[i]), C_0 = Σ h[i](1-h[i])

Good. So for each correlation output, I can compute A, B, C coefficients exactly in O(n) time per correlation, or O(n²) total for all correlations. Actually, I can compute them more efficiently.

Let me think about the total number of correlations: 2n-1. For each, computing A, B, C requires O(n) work (summing over the overlapping indices). So total is O(n²) which for n=99 is about 10,000 operations. That's fast.

Then the phi(t) = max_k (A_k t² + B_k t + C_k) is the maximum of 2n-1 quadratic functions.

To find the minimum of phi(t) on [t_lo, t_hi]:
- The minimum occurs at:
  1. An endpoint
  2. A vertex of one of the quadratics (where derivative = 0 and that quadratic is the max)
  3. An intersection point of two quadratics (where they are equal and both are the max)

For n=99, we have 197 quadratics. Pairwise intersections: 197*196/2 ≈ 19,300 pairs. For each pair, solving a quadratic equation is O(1). So this is very fast.

Then we need to check which candidates actually have phi(t) = max at that point. We can just evaluate phi at each candidate and take the minimum.

Actually, a simpler approach: since the number of quadratics is moderate (~200), we can:
1. Find all vertices (where A_k > 0 and t_v = -B_k/(2A_k) is in [t_lo, t_hi])
2. Find all pairwise intersections
3. Add endpoints
4. Evaluate phi(t) at all candidates
5. Return the best

But 19,300 intersection candidates might be a lot to evaluate. However, evaluating phi(t) requires computing max of 197 quadratics at a point, which is O(197). So total is about 19,300 * 197 ≈ 3.8M operations per line. That's still fast enough.

      - Compute A, B, C for all correlations
      - Find exact minimum of max(quadratics) on [t_lo, t_hi]

import numpy as np
import time

def compute_c_scaled(h):
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def compute_c5(h):
    return float(np.max(compute_c_scaled(h)))

def make_feasible(h, target):
    h = np.clip(h, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) < 1e-12:
        return h
    # Water filling
    lo, hi = -1.0, 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(h - mid, 0.0, 1.0))
        if s > target:
            lo = mid
        else:
            hi = mid
    result = np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)
    # Fix residual
    residual = target - np.sum(result)
    if abs(residual) > 1e-14:
        # Find interior points
        interior = np.where((result > 1e-10) & (result < 1.0 - 1e-10))[0]
        if len(interior) > 0:
            result[interior[0]] += residual
            result = np.clip(result, 0.0, 1.0)
    return result

def feasible_interval(h, d):
    """Find t range where h + t*d is in [0,1]"""
    n = len(h)
    t_lo = -np.inf
    t_hi = np.inf
    pos = d > 1e-14
    neg = d < -1e-14
    if np.any(pos):
        t_hi = min(t_hi, np.min((1.0 - h[pos]) / d[pos]))
    if np.any(neg):
        t_lo = max(t_lo, np.min(-h[neg] / d[neg]))
    # Cap
    t_lo = max(t_lo, -10.0)
    t_hi = min(t_hi, 10.0)
    if t_lo >= t_hi:
        return None
    return t_lo, t_hi

def quad_coeffs(h, d):
    """Compute A, B, C for each correlation along h(t) = h + t*d
    Returns arrays of length 2n-1"""
    n = len(h)
    m = 2 * n - 1
    A = np.zeros(m)
    B = np.zeros(m)
    C = compute_c_scaled(h)
    
    # For lag L >= 0 (position n-1+L):
    # c = sum_{i=0}^{n-1-L} (h[i+L]+t*d[i+L])(1-h[i]-t*d[i])
    # A = -sum d[i+L]*d[i], B = sum(d[i+L]*(1-h[i]) - h[i+L]*d[i])
    for L in range(n):
        if L == 0:
            continue  # handle separately
        idx = np.arange(n - L)
        ii = idx
        ij = idx + L
        A[n - 1 + L] = -np.sum(d[ij] * d[ii])
        B[n - 1 + L] = np.sum(d[ij] * (1 - h[ii]) - h[ij] * d[ii])
    
    # For lag -M (position n-1-M):
    # c = sum_{i=0}^{n-1-M} (h[i]+t*d[i])(1-h[i+M]-t*d[i+M])
    # A = -sum d[i]*d[i+M], B = sum(d[i]*(1-h[i+M]) - h[i]*d[i+M])
    for M in range(1, n):
        idx = np.arange(n - M)
        ii = idx
        ij = idx + M
        A[n - 1 - M] = -np.sum(d[ii] * d[ij])
        B[n - 1 - M] = np.sum(d[ii] * (1 - h[ij]) - h[ii] * d[ij])
    
    # Lag 0 (position n-1):
    # c = sum (h[i]+t*d[i])(1-h[i]-t*d[i]) = sum(h[i](1-h[i]) + t*d[i](1-2h[i]) - t^2*d[i]^2)
    A[n - 1] = -np.sum(d * d)
    B[n - 1] = np.sum(d * (1 - 2 * h))
    
    return A, B, C

def exact_line_min(A, B, C, t_lo, t_hi):
    """Find t in [t_lo, t_hi] minimizing max_k(A_k t^2 + B_k t + C_k)"""
    m = len(A)
    
    # candidate t values
    candidates = [t_lo, t_hi]
    
    # Vertices
    for k in range(m):
        if A[k] > 1e-14:
            tv = -B[k] / (2 * A[k])
            if t_lo < tv < t_hi:
                candidates.append(tv)
    
    # Pairwise intersections (limit to avoid too many)
    # For each pair (i,j): (A_i-A_j)t^2 + (B_i-B_j)t + (C_i-C_j) = 0
    # Only do this if m is not too large
    if m <= 300:
        for i in range(m):
            for j in range(i + 1, m):
                da = A[i] - A[j]
                db = B[i] - B[j]
                dc = C[i] - C[j]
                if abs(da) < 1e-14:
                    # Linear: db*t + dc = 0
                    if abs(db) > 1e-14:
                        t = -dc / db
                        if t_lo < t < t_hi:
                            candidates.append(t)
                else:
                    disc = db * db - 4 * da * dc
                    if disc >= 0:
                        sq = np.sqrt(disc)
                        t1 = (-db + sq) / (2 * da)
                        t2 = (-db - sq) / (2 * da)
                        if t_lo < t1 < t_hi:
                            candidates.append(t1)
                        if t_lo < t2 < t_hi:
                            candidates.append(t2)
    
    # Dense grid as fallback
    n_grid = 200
    grid = np.linspace(t_lo, t_hi, n_grid)
    candidates.extend(grid.tolist())
    
    candidates = np.array(candidates)
    candidates = np.clip(candidates, t_lo, t_hi)
    
    # Evaluate phi at all candidates
    best_t = t_lo
    best_val = np.inf
    for t in candidates:
        vals = A * t * t + B * t + C
        val = np.max(vals)
        if val < best_val:
            best_val = val
            best_t = t
    
    # Refine around best_t with finer grid
    span = t_hi - t_lo
    refine_width = max(0.05 * span, 0.1)
    t_ref_lo = max(t_lo, best_t - refine_width)
    t_ref_hi = min(t_hi, best_t + refine_width)
    for t in np.linspace(t_ref_lo, t_ref_hi, 500):
        vals = A * t * t + B * t + C
        val = np.max(vals)
        if val < best_val:
            best_val = val
            best_t = t
    
    return best_t, best_val

def active_gradient(h):
    """Compute a subgradient-like vector for the max of correlations"""
    n = len(h)
    dx = 2.0 / n
    corr = compute_c_scaled(h)
    c_max = np.max(corr)
    
    # Active set: top correlations
    r = max(4, min(20, n // 5))
    thresh = c_max - 0.002
    active = corr >= thresh
    if np.sum(active) < r:
        # Just use top r
        idx = np.argsort(corr)[-r:]
        active = np.zeros(len(corr), dtype=bool)
        active[idx] = True
    
    # Weighted gradient
    g = np.zeros(n)
    m = 2 * n - 1
    for k in range(m):
        if not active[k]:
            continue
        lag = k - (n - 1)
        w = corr[k]  # weight by correlation value
        if lag > 0:
            L = lag
            for i in range(n - L):
                g[i + L] += w * (1 - h[i])
                g[i] -= w * h[i + L]
        elif lag < 0:
            M = -lag
            for i in range(n - M):
                g[i] += w * (1 - h[i + M])
                g[i + M] -= w * h[i]
        else:
            g += w * (1 - 2 * h)
    
    g *= dx
    return g

def eval_phi_candidates(A, B, C, candidates):

import time

def compute_c_scaled(h):
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def compute_c5(h):

def make_feasible(h, target):
    n = len(h)
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) < 1e-12:
        return h
    # Water filling
    lo, hi = -1.0, 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(h - mid, 0.0, 1.0))
        if s > target:
            lo = mid
        else:
            hi = mid
    mu = (lo + hi) / 2.0
    result = np.clip(h - mu, 0.0, 1.0)
    residual = target - np.sum(result)
    if abs(residual) > 1e-14:
        interior = np.where((result > 1e-10) & (result < 1.0 - 1e-10))[0]
        if len(interior) > 0:
            result[interior[0]] += residual
            result = np.clip(result, 0.0, 1.0)
    return result

def feasible_interval(h, d):
    t_lo = -np.inf
    t_hi = np.inf
    pos = d > 1e-14
    neg = d < -1e-14
    if np.any(pos):
        t_hi = min(t_hi, np.min((1.0 - h[pos]) / d[pos]))
    if np.any(neg):
        t_lo = max(t_lo, np.min(-h[neg] / d[neg]))
    t_lo = max(t_lo, -5.0)
    t_hi = min(t_hi, 5.0)
    if t_lo >= t_hi - 1e-10:
        return None
    return (t_lo, t_hi)

def quad_coeffs(h, d):
    n = len(h)
    m = 2 * n - 1
    A = np.zeros(m)
    B = np.zeros(m)
    C = compute_c_scaled(h)
    
    # Positive lags
    for L in range(1, n):
        idx = np.arange(n - L)
        ii = idx
        ij = idx + L
        A[n - 1 + L] = -np.sum(d[ij] * d[ii])
        B[n - 1 + L] = np.sum(d[ij] * (1 - h[ii]) - h[ij] * d[ii])
    
    # Negative lags
    for M in range(1, n):
        idx = np.arange(n - M)
        ii = idx
        ij = idx + M
        A[n - 1 - M] = -np.sum(d[ii] * d[ij])
        B[n - 1 - M] = np.sum(d[ii] * (1 - h[ij]) - h[ii] * d[ij])
    
    # Zero lag
    A[n - 1] = -np.sum(d * d)
    B[n - 1] = np.sum(d * (1 - 2 * h))
    
    return A, B, C

def exact_line_min(A, B, C, t_lo, t_hi):
    m = len(A)
    
    # Candidate t values
    candidates = [t_lo, t_hi]
    
    # Vertices
    for k in range(m):
        if A[k] > 1e-14:
            tv = -B[k] / (2.0 * A[k])
            if t_lo < tv < t_hi:
                candidates.append(tv)
    
    # Pairwise intersections (vectorized)
    # For speed, use numpy broadcasting
    # A_i - A_j, B_i - B_j, C_i - C_j for all pairs
    # This is O(m^2) which for m=197 is ~39000 pairs
    Ai = A[:, np.newaxis]
    Aj = A[np.newaxis, :]
    Bi = B[:, np.newaxis]
    Bj = B[np.newaxis, :]
    Ci = C[:, np.newaxis]
    Cj = C[np.newaxis, :]
    
    da = Ai - Aj  # (m, m)
    db = Bi - Bj
    dc = Ci - Cj
    
    # Only consider upper triangle (i < j)
    mask_upper = np.triu(np.ones((m, m), dtype=bool), k=1)
    
    # For quadratic case: da*t^2 + db*t + dc = 0
    disc = db * db - 4.0 * da * dc
    # Valid where disc >= 0 and |da| > eps
    valid_quad = mask_upper & (np.abs(da) > 1e-14) & (disc >= 0)
    
    if np.any(valid_quad):
        sq = np.sqrt(np.maximum(disc, 0.0))
        t1 = (-db + sq) / (2.0 * da)
        t2 = (-db - sq) / (2.0 * da)
        
        valid_t1 = valid_quad & (t1 > t_lo) & (t1 < t_hi)
        valid_t2 = valid_quad & (t2 > t_lo) & (t2 < t_hi)
        
        candidates.extend(t1[valid_t1].tolist())
        candidates.extend(t2[valid_t2].tolist())
    
    # Linear case: da ≈ 0, db*t + dc = 0
    valid_lin = mask_upper & (np.abs(da) <= 1e-14) & (np.abs(db) > 1e-14)
    if np.any(valid_lin):
        tl = -dc / db
        valid_tl = valid_lin & (tl > t_lo) & (tl < t_hi)
        candidates.extend(tl[valid_tl].tolist())
    
    # Dense grid
    n_grid = 300
    candidates.extend(np.linspace(t_lo, t_hi, n_grid).tolist())
    
    candidates = np.array(candidates)
    candidates = np.clip(candidates, t_lo, t_hi)
    
    # Evaluate all candidates at once
    t = candidates[np.newaxis, :]
    vals = A[:, np.newaxis] * t * t + B[:, np.newaxis] * t + C[:, np.newaxis]
    phi_vals = np.max(vals, axis=0)

def make_feasible(h, target):

        directions.append(d)
    # Random directions
    for _ in range(n_rand):
        d = rng.randn(n)
        d -= np.mean(d)
        max_abs = np.max(np.abs(d))
        if max_abs > 1e-14:
            directions.append(d / max_abs)
    return directions


def run(seed=42, budget_s=1100, **kwargs):
    t_start = time.time()
    rng = np.random.RandomState(seed)

    h_init = None
    try:
        if len(initial_h_values) > 0:
            h_init = np.array(initial_h_values, dtype=float)
    except (NameError, TypeError):
        pass

    if h_init is not None:
        n = len(h_init)
    else:
        n = 99
    target = float(n) / 2.0

    if h_init is not None:
        h = make_feasible(h_init, target)
    else:
        h = np.zeros(n)
        h[:n // 2] = 1.0
        if n % 2 == 1:
            h[n // 2] = 0.5
        h = make_feasible(h, target)

    best_h = h.copy()
    best_c5 = compute_c5(h)

    def elapsed():
        return time.time() - t_start

    def remaining():
        return budget_s - elapsed()

    stall = 0
    stall_limit = 200
    perturb_scale = 0.08
    iter_count = 0

    while remaining() > 50:
        g = active_subgradient(h)
        directions = generate_directions(h, g, n, rng)

        improved = False
        for d in directions:
            if remaining() < 30:
                break
            d = normalize_direction(d)
            if d is None:
                continue
            h_new, c5_new = do_line_search(h, d, target, best_c5)
            if h_new is not None:
                h = h_new
                best_c5 = c5_new
                best_h = h.copy()
                improved = True

        iter_count += 1
        if not improved:
            stall += 1
            if stall > stall_limit:
                # Perturb
                scale = perturb_scale * (1.0 + 0.3 * np.sin(iter_count * 0.1))
                if rng.rand() < 0.6:
                    h = best_h + scale * rng.randn(n)
                else:
                    h = h + scale * rng.randn(n)
                h = make_feasible(h, target)
                # Also try targeted perturbation on active coordinates
                if rng.rand() < 0.3:
                    corr = compute_c_scaled(h)
                    active = np.where(corr > np.max(corr) - 0.01)[0]
                    # Perturb coordinates involved in active correlations
                    for k in active[:10]:
                        lag = k - (n - 1)
                        if lag > 0:
                            idx = np.arange(n - lag)
                            for i in idx[rng.randint(n - lag)]:
                                h[i] += 0.05 * rng.rand()
                                h[i + lag] -= 0.05 * rng.rand()
                    h = make_feasible(h, target)
                stall = 0
                perturb_scale = max(perturb_scale * 0.9, 0.02)
        else:
            stall = 0
            perturb_scale = min(perturb_scale * 1.02, 0.15)

    # Final refinement: try all pairs on best solution
    if remaining() > 60:
        h_cur = best_h.copy()
        c5_cur = best_c5
        g = active_subgradient(h_cur)
        sorted_idx = np.argsort(g)
        # Try top pairs in order of gradient difference
        pairs_to_try = []
        for i in sorted_idx[:n // 2]:
            for j in sorted_idx[-(n // 2):]:
                if i != j and h_cur[i] < 1.0 - 1e-8 and h_cur[j] > 1e-8:
                    pairs_to_try.append((int(i), int(j)))
        rng.shuffle(pairs_to_try)
        for i, j in pairs_to_try:
            if remaining() < 30:
                break
            d = np.zeros(n)
            d[i] = 1.0
            d[j] = -1.0
            h_new, c5_new = do_line_search(h_cur, d, target, c5_cur)
            if h_new is not None:
                h_cur = h_new
                c5_cur = c5_new
                if c5_cur < best_c5:
                    best_c5 = c5_cur
                    best_h = h_cur.copy()

    best_c5 = compute_c5(best_h)
    return best_h, best_c5, len(best_h)
