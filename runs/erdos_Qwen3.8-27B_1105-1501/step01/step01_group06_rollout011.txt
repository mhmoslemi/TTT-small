One more thought: the pair-exchange line search uses a uniform grid of 32 points + refinement. This might miss the exact optimum. A better approach is to use the structure of the problem:

The function f(δ) = max_k (S_k + δ*b_k + δ²*c_k) is the max of quadratics. Its minimum on [0,T] occurs at:
- An endpoint (0 or T)
- A point where two curves intersect (δ where g_a(δ) = g_b(δ))
- The vertex of a concave curve (only k=0 is concave, vertex at δ = -b_0/(2*c_0) = b_0/4)

So the exact minimum can be found by:
1. Checking δ=0 and δ=T
2. Checking δ=b_0/4 (if in [0,T])
3. For each pair of curves (g_a, g_b), finding their intersection in [0,T] and checking if it's a local min of the max

Step 3 is expensive (O(n²) intersections to check). In practice, it's enough to:
1. Find the active set at δ=0 (curves at the max)
2. For each active curve and the concave curve (k=0), find intersection
3. Check a few more candidates

Actually, a simpler and effective approach:
1. Evaluate f at δ=0, T, and b_0/4 (if valid)
2. Find the minimum over a fine grid (64 points)
3. Do a few iterations of golden section or ternary search around the minimum

Since f is the max of quadratics, it's piecewise smooth and has at most O(n) pieces. A fine grid of 64-128 points should capture the minimum well.

```python
import numpy as np
import time

def c5_official(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def project_feasible(v, target):
    lo, hi = v.min() - 1, v.max() + 1
    for _ in range(80):
        mid = (lo + hi) / 2
        if np.sum(np.clip(v - mid, 0, 1)) > target:
            lo = mid
        else:
            hi = mid
    return np.clip(v - (lo + hi) / 2, 0, 1)

def compute_S(h):
    return np.correlate(h, 1.0 - h, mode='full')

def pair_line_search(h, i, j, S, n):
    T = min(1.0 - h[i], h[j])
    if T < 1e-13:
        return 0.0, float(np.max(S))
    
    nc = 2 * n - 1
    b = np.zeros(nc)
    di = j - i
    
    # Compute b_k for all k
    for k in range(-(n-1), n):
        v = 0.0
        if 0 <= j+k < n: v += h[j+k]
        if 0 <= i+k < n: v -= h[i+k]
        if 0 <= i-k < n: v -= h[i-k]
        if 0 <= j-k < n: v += h[j-k]
        b[k+n-1] = v
    
    # Compute c_k
    c = np.zeros(nc)
    c[n-1] = -2.0  # k=0
    c[di+n-1] += 1.0  # k=j-i
    c[-di+n-1] += 1.0  # k=i-j
    
    # Line search: minimize max(S + delta*b + delta^2*c) over [0, T]
    deltas = np.linspace(0, T, 64)
    vals = np.array([np.max(S + d*b + d*d*c) for d in deltas])
    idx = np.argmin(vals)
    best_val = vals[idx]
    best_delta = deltas[idx]
    
    # Refine
    if 0 < idx < 63:
        lo_d = max(0.0, deltas[idx] - T/64)
        hi_d = min(T, deltas[idx] + T/64)
        deltas2 = np.linspace(lo_d, hi_d, 32)
        vals2 = np.array([np.max(S + d*b + d*d*c) for d in deltas2])
        idx2 = np.argmin(vals2)
        if vals2[idx2] < best_val:
            best_val = vals2[idx2]
            best_delta = deltas2[idx2]
    
    return best_delta, best_val

def subgradient(h, S, n, tol=1e-3):
    """Compute subgradient of max_k S_k(h)."""
    max_S = np.max(S)
    active = S >= max_S - tol * (abs(max_S) + 1)
    grad = np.zeros(n)
    for k in range(-(n-1), n):
        if not active[k+n-1]:
            continue
        # grad[i] += (1-h[i+k]) - h[i-k]
        # Vectorize:
        for i in range(n):
            val = 0.0
            ik = i + k
            if 0 <= ik < n:
                val += 1.0 - h[ik]
            ik2 = i - k
            if 0 <= ik2 < n:
                val -= h[ik2]
            grad[i] += val
    na = np.sum(active)
    if na > 0:
        grad /= na
    return grad

def optimize_pairs(h, n, target, time_limit, rng):
    """Optimize using pair exchanges."""
    t0 = time.time()
    S = compute_S(h)
    cur_max = float(np.max(S))
    stagnant = 0
    n_best = 0
    
    while time.time() - t0 < time_limit:
        # Get subgradient for direction
        grad = subgradient(h, S, n)
        
        # Score pairs: move from high grad (donor) to low grad (target)
        order = np.argsort(grad)
        # Try top candidates
        n_don = min(40, n)
        targets = order[:n_don]
        donors = order[-n_don:]
        
        best_improvement = 0
        best_move = None
        
        for i in targets:
            for j in donors:
                if i == j:
                    continue
                T = min(1.0 - h[i], h[j])
                if T < 1e-12:
                    continue
                delta, new_max = pair_line_search(h, i, j, S, n)
                improvement = cur_max - new_max
                if improvement > best_improvement:
                    best_improvement = improvement
                    best_move = (i, j, delta)
        
        if best_move is not None and best_improvement > 1e-10:
            i, j, delta = best_move
            h[i] = min(1.0, max(0.0, h[i] + delta))
            h[j] = min(1.0, max(0.0, h[j] - delta))
            S = compute_S(h)
            cur_max = float(np.max(S))
            stagnant = 0
            n_best += 1
        else:
            stagnant += 1
            if stagnant >= 15:
                # Random perturbation
                n_pert = rng.integers(3, 15)
                idx = rng.choice(n, size=n_pert, replace=False)
                h[idx] += rng.normal(0, 0.05, n_pert)
                h = project_feasible(h, target)
                S = compute_S(h)
                cur_max = float(np.max(S))
                stagnant = 0
    
    return h, cur_max
```

Term 2: +s * Σ_m (δ_mi - δ_mj)(1-h[m+k])
= +s * ((1-h[i+k]) - (1-h[j+k])) = +s * (h[j+k] - h[i+k])

So the linear coefficient (b_k) = -h[i-k] + h[j-k] + h[j+k] - h[i+k]

Let me define:
A_p = h_pad[p:p+2n-1] + h_pad[p:p+2n-1][::-1]  (for each position p)

Then b_k for pair (i,j) = A_j - A_i (elementwise subtraction of vectors of length 2n-1).

I can precompute A for all positions p = 0, ..., n-1:
A = np.zeros((n, 2n-1))
for p in range(n):
    A[p] = h_pad[p:p+2n-1] + h_pad[p:p+2n-1][::-1]

This takes O(n²) time but only once per iteration. Then for each pair (i,j), b = A[j] - A[i] is O(n).

Even better, I can precompute this matrix once and then the pair evaluation is just:
b = A[j] - A[i]  (O(n) vector subtraction)
Then the line search is O(n * n_samples).
