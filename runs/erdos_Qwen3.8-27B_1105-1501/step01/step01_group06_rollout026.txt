def exact_subgrad(h):
    """Compute subgradient of the exact max function at h"""
    n = len(h)
    dx = 2.0 / n
    c_vals = compute_overlaps(h)
    k_star = int(np.argmax(c_vals))
    # d = k_star - (n-1)
    d = k_star - (n - 1)
    grad = np.zeros(n)
    if d >= 0:
        idx1 = np.arange(0, n - d)
        grad[idx1] += dx * (1.0 - h[idx1 + d])
        idx2 = np.arange(d, n)
        grad[idx2] -= dx * h[idx2 - d]

        d2 = -d
        idx1 = np.arange(d2, n)
        grad[idx1] += dx * (1.0 - h[idx1 - d2])
        idx2 = np.arange(0, n - d2)
        grad[idx2] -= dx * h[idx2 + d2]
    return grad

def smooth_grad(h, beta):
    n = len(h)
    dx = 2.0 / n
    c_vals = compute_overlaps(h)
    c_max = float(np.max(c_vals))
    shifted = np.clip(beta * (c_vals - c_max), -500.0, 500.0)
    exp_s = np.exp(shifted)
    weights = exp_s / float(np.sum(exp_s))

            grad[idx1] += w * (1.0 - h[idx1 - d2])
            idx2 = m[:n - d2]
            grad[idx2] -= w * h[idx2 + d2]
    return grad

def proj_grad_descent(h, n, target_sum, beta, n_steps, lr0, use_exact=False):
    h = h.copy()
    best_h = h.copy()
    best_c5 = eval_c5(h)
    for step in range(n_steps):
        if use_exact:
            g = exact_subgrad(h)
        else:
            g = smooth_grad(h, beta)
        lr = lr0 / (1.0 + 0.02 * step)
        h_new = project_feasible(h - lr * g, target_sum)
        c5 = eval_c5(h_new)
        if c5 < best_c5:

            best_h = h_new.copy()
        h = h_new

            grad[d:] -= w * h[:n-d]
        else:
            d2 = -d
            grad[d2:] += w * (1.0 - h[:n-d2])
            grad[:n-d2] -= w * h[d2:]
    return grad

def topk_grad(h, k):

    n = len(h)
    dx = 2.0 / n
    c_vals = compute_overlaps(h)

            best_h = h_new.copy()
        h = h_new
    return best_h, best_c5

        c_max = float(np.max(c_vals))
        shifted = np.clip(beta * (c_vals - c_max), -500.0, 500.0)
        return c_max + float(np.log(np.sum(np.exp(shifted)))) / beta

One more thought: I should also try a **coordinate descent** approach where I optimize one (or a few) coordinates at a time. For each coordinate i, the optimal value (given all others) can be found by solving a 1D optimization problem. This is exact and fast.

For coordinate i, fixing all other h[j] (j≠i):
The overlap at shift d involves h[i] if i is in the valid range for that shift.
O(d) = dx · [h[i]·(1-h[i+d]) + Σ_{j≠i, valid} h[j](1-h[j+d])]  (when i is the "first" index)
     = dx · [(1-h[i+d])·h[i] + C_d]  (where C_d doesn't depend on h[i])

Similarly, O(d') where i appears as the "second" index (i = j+d', j = i-d'):
O(d') = dx · [h[i-d']·(1-h[i]) + Σ_{j≠i, valid} h[j](1-h[j+d'])]
      = dx · [h[i-d']·(-h[i]) + D_{d'}]

So the dependence of O(d) on h[i] is linear when h[i] appears as the first factor, and also linear when it appears as the second factor (with negative sign in the (1-·) term).

The total dependence is:
O(d) = a_d · h[i] + b_d (linear in h[i] for each shift d)

So the max over d of (a_d · h[i] + b_d) is a piecewise linear function of h[i] (in [0,1]). We can minimize this exactly by trying the breakpoints!

This is the key insight for **exact coordinate descent**:
- For each coordinate i, the objective as a function of h[i] is a convex piecewise linear function
- The minimum is at one of the breakpoints (where two O(d) values are equal)
- We can find the optimal h[i] in O(n) time (try all n-1 possible breakpoints)

This makes coordinate descent very efficient! Each full pass is O(n²) (n coordinates × O(n) per coordinate).

Let me implement this:

For coordinate i, the overlap at shift d (where d = k - (n-1) in the full correlation indexing):
- h[i] appears in O(d) as h[i]·(1-h[i+d]) if 0≤i<n and 0≤i+d<n
- h[i] appears in O(d) as h[i-d]·(1-h[i]) if 0≤i-d<n and 0≤i<n

So:
O(d) = dx · [h[i]·(1-h[i+d])·1_{valid} + (1-h[i])·h[i-d]·1_{valid} + rest_d]
     = dx · [h[i]·(1-h[i+d])·1_{0≤i+d<n} + h[i-d]·(1-h[i])·1_{0≤i-d<n} + rest_d]
     = dx · [h[i]·(1-h[i+d])·1_{0≤i+d<n} - h[i-d]·h[i]·1_{0≤i-d<n} + h[i-d]·1_{0≤i-d<n} + rest_d]
     = dx · [h[i]·((1-h[i+d])·1_{0≤i+d<n} - h[i-d]·1_{0≤i-d<n}) + (h[i-d]·1_{0≤i-d<n} + rest_d)]

Let a_d = dx · ((1-h[i+d])·1_{0≤i+d<n} - h[i-d]·1_{0≤i-d<n})
Let b_d = dx · (h[i-d]·1_{0≤i-d<n} + rest_d)

Then O(d) = a_d · h[i] + b_d

The max over d of (a_d · h[i] + b_d) is a convex piecewise linear function of h[i]. Its minimum over h[i] ∈ [0,1] is at:
- h[i] = 0, or
- h[i] = 1, or
- A breakpoint where a_d1·h[i]+b_d1 = a_d2·h[i]+b_d2 for some d1≠d2
  → h[i] = (b_d2 - b_d1) / (a_d1 - a_d2) (if a_d1 ≠ a_d2)

So the algorithm for coordinate i:
1. Compute a_d and b_d for all d
2. Find all breakpoints h[i] = (b_d2 - b_d1) / (a_d1 - a_d2) in [0,1]
3. Evaluate the objective at h[i]=0, h[i]=1, and all breakpoints
4. Choose the best one

But wait, we also need to maintain the constraint sum(h) = n/2. If we change h[i], we need to adjust something else. This makes it more complex.

One approach: after changing h[i], redistribute the change to another coordinate (or spread it evenly across all coordinates). But this breaks the exactness.

Alternative: Use a "Lagrangian" approach. Introduce a Lagrange multiplier λ for the sum constraint:
minimize max_d O(d) + λ·(sum(h) - n/2)

For this Lagrangian, the coordinate-wise minimization is:
minimize max_d (a_d·h[i] + b_d) + λ·h[i]
= maximize over d of (a_d·h[i] + b_d) + λ·h[i]
= max_d ((a_d + λ)·h[i] + b_d)

This is still a convex piecewise linear function of h[i], and we can find its minimum exactly!

Then we update λ using a subgradient method: λ_{new} = λ_{old} - η·(sum(h) - n/2)

This is the **dual decomposition** approach. It's guaranteed to find the optimal solution (in the limit) and each step is O(n²).
