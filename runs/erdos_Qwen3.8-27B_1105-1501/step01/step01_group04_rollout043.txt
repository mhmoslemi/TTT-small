δ_i = old_h[j] - old_h[i]
δ_j = old_h[i] - old_h[j] = -δ_i

Δcorr[k] = δ_i * M[i,k] + δ_j * M[j,k] = δ_i * (M[i,k] - M[j,k])

After the swap, h[i] and h[j] change. This affects:
- M[i, k] for all k (since h[i] is in the formula)
- M[j, k] for all k
- M[p, k] for p ≠ i,j: M[p,k] uses h[p-k+n-1] and h[p+k-n+1]. These equal i or j for specific k values:
  - h[p-k+n-1] = h[i] when p-k+n-1 = i ⟹ k = p-i+n-1
  - h[p+k-n+1] = h[i] when p+k-n+1 = i ⟹ k = i-p+n-1
  Similarly for j.

So after changing h[i] by δ_i:
- M[p, p-i+n-1] changes by -δ_i (because (1-h) at that position changes by -δ_i)
  Valid when i ≤ p-i+n-1 ≤ i+n-1 ⟹ 2i-n+1 ≤ p ≤ n-1. And 0 ≤ p ≤ n-1.
  Also need the index p-k+n-1 = i to be in [0,n-1], which it is by construction.
  
- M[p, i-p+n-1] changes by +δ_i (because h at that position changes by δ_i)
  Valid when n-1-p ≤ i-p+n-1 ≤ 2n-2-p ⟹ ... let me just check 0 ≤ i-p+n-1 ≤ 2n-2.
  i-p+n-1 ≥ 0 ⟹ p ≤ i+n-1 (always true since p ≤ n-1 ≤ i+n-1 for i ≥ 0)
  i-p+n-1 ≤ 2n-2 ⟹ p ≥ i-n+1 (always true since p ≥ 0 ≥ i-n+1 for i ≤ n-1)
  
  But also need the k-value to be in the valid range for the B term: n-1-p ≤ k ≤ 2n-2-p.
  k = i-p+n-1: n-1-p ≤ i-p+n-1 ⟹ 0 ≤ i (true). i-p+n-1 ≤ 2n-2-p ⟹ i ≤ n-1 (true).
  So always valid.

So the update after h[i] changes by δ_i:
1. M[i, k] for k in [i, i+n-1]: the (1-h[i-k+n-1]) term... wait, M[i,k] itself contains h[i-k+n-1] and h[i+k-n+1]. When h[i] changes, does M[i,k] change?

M[i,k] = (1-h[i-k+n-1]) * [i ≤ k ≤ i+n-1] - h[i+k-n+1] * [n-1-i ≤ k ≤ 2n-2-i]

The first term involves h[i-k+n-1]. This is h[i] when i-k+n-1 = i, i.e., k = n-1.
The second term involves h[i+k-n+1]. This is h[i] when i+k-n+1 = i, i.e., k = n-1.

So M[i, n-1] changes when h[i] changes!
M[i, n-1] = (1-h[i-(n-1)+n-1]) * [i ≤ n-1 ≤ i+n-1] - h[i+(n-1)-n+1] * [n-1-i ≤ n-1 ≤ 2n-2-i]
= (1-h[i]) * [i ≤ n-1] - h[i] * [n-1-i ≤ n-1]
= (1-h[i]) - h[i] = 1 - 2*h[i]

When h[i] changes by δ: M[i, n-1] changes by -2δ. ✓ (consistent with: first term changes by -δ, second by +δ, net = -2δ)

For M[p,k] with p ≠ i:
- First term (1-h[p-k+n-1]): equals (1-h[i]) when p-k+n-1 = i, i.e., k = p-i+n-1.
  Change: -δ_i
  Valid when i ≤ k ≤ i+n-1: i ≤ p-i+n-1 ≤ i+n-1 ⟹ 2i-n+1 ≤ p ≤ n-1.
  
- Second term h[p+k-n+1]: equals h[i] when p+k-n+1 = i, i.e., k = i-p+n-1.
  Change: +δ_i
  Valid when n-1-p ≤ k ≤ 2n-2-p: n-1-p ≤ i-p+n-1 ≤ 2n-2-p ⟹ 0 ≤ i ≤ n-1 (always true).

So the M update after h[i] changes by δ_i and h[j] changes by δ_j:
- M[i, n-1] += -2*δ_i
- M[j, n-1] += -2*δ_j
- For each p ≠ i,j:
  - If 2i-n+1 ≤ p ≤ n-1: M[p, p-i+n-1] += -δ_i
  - M[p, i-p+n-1] += δ_i
  - If 2j-n+1 ≤ p ≤ n-1: M[p, p-j+n-1] += -δ_j
  - M[p, j-p+n-1] += δ_j

This is O(n) updates per swap. Good.

Now let me code this up efficiently. The key data structures:
- h: array of length n
- corr: array of length 2n-1 (the current correlation values)
- M: 2D array of shape (n, 2n-1)

Memory: n * (2n-1) * 8 bytes. For n=256: 256 * 511 * 8 ≈ 1MB. Fine.

The algorithm:
```
Initialize h, corr, M
best = max(corr)
Loop:
  For each candidate swap (i, j) in random order:
    δ = h[j] - h[i]
    If δ == 0: continue
    Δcorr = δ * (M[i] - M[j])

    If new_max < best:

      corr += Δcorr
      h[i], h[j] = h[j], h[i]
      # Update M

      update_M(M, h, j, -δ, n)  # wait, δ_j = -δ
      best = new_max
      improved = True
```

- h[j] changes by δ_j = old_h[i] - old_h[j] = -δ

- For each q: M[q, q-p+n-1] += -δ_p (if valid)

```python
import numpy as np
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def build_M(h):
    n = len(h)
    M = np.zeros((n, 2*n-1))
    for i in range(n):
        # M[i,k] = (1-h[i-k+n-1]) * [i ≤ k ≤ i+n-1] - h[i+k-n+1] * [n-1-i ≤ k ≤ 2n-2-i]
        # First term: k in [i, i+n-1], index = i-k+n-1 in [0, n-1]
        k_start1 = i
        k_end1 = i + n - 1
        # index = i - k + n - 1, for k in [i, i+n-1]: index in [n-1, 0]
        idx1 = i - np.arange(k_start1, k_end1+1) + n - 1
        M[i, k_start1:k_end1+1] += (1 - h[idx1])
        
        # Second term: k in [n-1-i, 2n-2-i], index = i+k-n+1 in [0, n-1]
        k_start2 = n - 1 - i
        k_end2 = 2*n - 2 - i
        idx2 = i + np.arange(k_start2, k_end2+1) - n + 1
        M[i, k_start2:k_end2+1] -= h[idx2]
    return M

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def swap_local_search(h, time_budget, seed=42, max_passes=100000):
    n = len(h)
    h = h.copy().astype(float)
    corr = compute_corr(h)
    M = build_M(h)
    best = float(np.max(corr))
    t0 = time.time()
    rng = np.random.RandomState(seed)
    
    passes = 0
    while passes < max_passes:
        passes += 1
        if time.time() - t0 > time_budget:
            break
        
        # Generate random permutation of pairs
        # For efficiency, use random sampling
        n_pairs = min(n * (n-1) // 2, 5000)
        # Sample pairs
        indices = np.random.RandomState(seed + passes).choice(n * (n-1) // 2, size=min(n_pairs, n*(n-1)//2), replace=False)
        # Convert to (i,j) pairs
        # This is complex; let's just sample i,j
        i_list = rng.randint(0, n, size=n_pairs)
        j_list = rng.randint(0, n, size=n_pairs)
        
        best_delta = 0  # we want to minimize max, so we want the swap that reduces max most
        best_pair = None
        best_new_corr = None
        
        for idx in range(n_pairs):
            i = i_list[idx]
            j = j_list[idx]
            if i == j:
                continue
            delta = h[j] - h[i]
            if abs(delta) < 1e-10:
                continue
            
            # Δcorr = delta * (M[i] - M[j])
            dcorr = delta * (M[i] - M[j])
            new_corr = corr + dcorr
            new_max = float(np.max(new_corr))
            
            if new_max < best - 1e-12:
                best_delta = new_max - best
                best_pair = (i, j)
                best_new_corr = new_corr
        
        if best_pair is not None:
            i, j = best_pair
            delta = h[j] - h[i]
            # Accept
            corr = best_new_corr
            old_hi = h[i]
            old_hj = h[j]
            h[i] = old_hj
            h[j] = old_hi
            
            # Update M
            # h[i] changed by delta_i = delta
            # h[j] changed by delta_j = -delta
            update_M(M, i, delta, n)
            update_M(M, j, -delta, n)
            
            best = best_new_corr.max()
        else:
            # No improvement found in this pass
            # Try deterministic scan of all pairs
            if n <= 120:
                found = False
                for i in range(n):
                    for j in range(i+1, n):
                        delta = h[j] - h[i]
                        if abs(delta) < 1e-10:
                            continue
                        dcorr = delta * (M[i] - M[j])
                        new_max = float(np.max(corr + dcorr))
                        if new_max < best - 1e-12:
                            corr = corr + dcorr
                            old_hi = h[i]
                            h[i] = h[j]
                            h[j] = old_hi
                            update_M(M, i, delta, n)
                            update_M(M, j, -delta, n)
                            best = new_max
                            found = True
                            break
                    if found:
                        break
                if not found:
                    break  # Local optimum
            else:
                break
    
    return h, best * (2.0 / n)

def update_M(M, p, delta, n):
    """Update M after h[p] changes by delta."""
    # M[p, n-1] += -2*delta
    M[p, n-1] += -2.0 * delta
    
    # For each q in [0, n-1], q ≠ p:
    # M[q, q-p+n-1] += -delta (if i ≤ k ≤ i+n-1 is satisfied, i.e., p ≤ q-p+n-1 ≤ p+n-1)
    #   ⟺ 2p-n+1 ≤ q ≤ n-1
    # M[q, p-q+n-1] += delta (always valid as shown)
    
    q_values = np.arange(n)
    # First update: M[q, q-p+n-1] for q in [max(0, 2p-n+1), n-1]
    q_min = max(0, 2*p - n + 1)
    q_max = n - 1
    if q_min <= q_max:
        q_range = np.arange(q_min, q_max + 1)
        k_vals = q_range - p + n - 1
        # k_vals should be in [p, p+n-1] (the valid range for the first term)
        # Verify: q_min - p + n - 1 = (2p-n+1) - p + n - 1 = p ✓
        # q_max - p + n - 1 = n-1-p+n-1 = 2n-2-p ✓ (which is p+n-1 when... no)
        # Actually k should be in [p, p+n-1] for the first term to be valid.
        # q-p+n-1 ranges from (2p-n+1)-p+n-1 = p to (n-1)-p+n-1 = 2n-2-p
        # We need k ≤ p+n-1: 2n-2-p ≤ p+n-1 ⟹ n-1 ≤ 2p ⟹ p ≥ (n-1)/2
        # So for small p, some k_vals might exceed p+n-1.
        # Let's add a mask.
        valid = (k_vals >= p) & (k_vals <= p + n - 1)
        q_valid = q_range[valid]
        k_valid = k_vals[valid]
        M[q_valid, k_valid] += -delta
    
    # Second update: M[q, p-q+n-1] += delta for all q
    # k = p-q+n-1, should be in [n-1-q, 2n-2-q] (valid range for second term)
    # p-q+n-1 ≥ n-1-q ⟹ p ≥ 0 (always true)
    # p-q+n-1 ≤ 2n-2-q ⟹ p ≤ n-1 (always true for p in [0,n-1])
    # So always valid. But k must be in [0, 2n-2]:
    # p-q+n-1 ≥ 0 ⟹ q ≤ p+n-1 (always true since q ≤ n-1 ≤ p+n-1)
    # p-q+n-1 ≤ 2n-2 ⟹ q ≥ p-n+1 (always true since q ≥ 0 ≥ p-n+1)
    k_vals2 = p - q_values + n - 1
    M[q_values, k_vals2] += delta
```

```python
def initial_M(h):

    n = len(h)
    M = np.zeros((n, 2*n-1), dtype=np.float64)
    for i in range(n):

        M[i, ks2] -= h[idx2]
    return M
```
