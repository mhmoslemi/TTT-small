- LP solve: depends on size, but for 139 constraints × 140 variables, HIGHS should do it in <1ms
- Line search: a few calls to compute_c5, each O(n²)

Total: maybe 5-10ms per iteration. In 1100s, we could do ~100,000 iterations. That's plenty.

But in practice, many iterations will fail (no improvement) and just reduce delta. So the effective number of successful steps is much less.

Let me think about a better strategy:

1. First, do a quick SLP phase to make progress (say 100 iterations)
2. Then, switch to a more targeted approach: identify the "tight" lags (those within 1e-3 of the max) and focus on reducing them
3. Use the LP but only include the tight lags as explicit constraints (others are "soft")

Actually, including all lags as constraints in the LP is fine and probably better (it prevents making other lags worse).

One important detail: the LP might find a direction d where the linearized objective decreases but the actual objective increases (due to the quadratic terms). The backtracking handles this, but if it always fails, we're stuck.

To handle this, I can:
1. Reduce delta (smaller steps → better linearization)
2. After a few failures, try a different approach (e.g., pure gradient descent)

Let me also add a direct subgradient step as a fallback:
- The subdifferential of max_k L_k(h) at h is the convex hull of {∇L_k(h) : L_k(h) = max}
- A natural choice is the average of the gradients of the active lags
- Take a step in the negative of this subgradient

def project_onto_constraint(h, target_sum):
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        proj = np.clip(h - mid, 0.0, 1.0)
        if np.sum(proj) > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def compute_c5(h):
    dx = 2.0 / len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    return np.max(corr) * dx

def compute_all_lags(h):
    dx = 2.0 / len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    return corr * dx

def compute_lag_gradients(h):
    n = len(h)
    dx = 2.0 / n
    n_lags = 2 * n - 1
    grads = np.zeros((n_lags, n))
    j = np.arange(n)
    for k in range(n_lags):
        s = k - (n - 1)
        g = np.zeros(n)
        fv = (j + s >= 0) & (j + s < n)
        sv = (j - s >= 0) & (j - s < n)
        g[fv] += dx * (1.0 - h[j[fv] + s])
        g[sv] -= dx * h[j[sv] - s]
        grads[k] = g
    return grads

def subgradient_step(h, lr):
    """Direct subgradient descent step on the max of lags."""
    n = len(h)
    lags = compute_all_lags(h)
    current_c5 = np.max(lags)
    target_sum = float(np.sum(h))
    
    # Active lags: those within 1% of max
    tol = 0.01 * current_c5
    active = np.where(lags >= current_c5 - tol)[0]
    
    # Average gradient of active lags
    grads = compute_lag_gradients(h)
    avg_grad = np.mean(grads[active], axis=0)
    
    h_new = h - lr * avg_grad
    h_new = project_onto_constraint(h_new, target_sum)
    c5_new = compute_c5(h_new)
    
    if c5_new < current_c5:
        return h_new, c5_new
    return h, current_c5
