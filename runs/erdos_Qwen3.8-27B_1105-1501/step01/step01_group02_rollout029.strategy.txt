1. Approach and rationale

1.1 Central idea

Use a trust-region sequential linear programming (SLP) engine for the nonsmooth Chebyshev overlap objective, but retain the original deterministic evaluator for every accepted candidate. The second half of the program adds two cheap, exactly feasible refinement engines that attack apparent local minima which SLP cannot escape:

- Exact one-dimensional pair-exchange line polishing: a pair of coordinates is shifted in opposite directions, preserving the mass constraint exactly; the evaluator is called along the whole feasible interval.
- A discrete unit-exchange search over a quantized representation: the function values are forced to integer multiples of a grid step, and mass can only be moved from one coordinate to another. This preserves feasibility structurally and enables a fast simulated/annealing population-like search.

The important algorithmic research direction is not yet another projected gradient/coordinate-descent method. In the truly constrained feasible set

    0 <= h_i <= 1,   sum_i h_i = n / 2,

one individual coordinate cannot be moved independently. Therefore local methods must either randomize two-dimensional exchanges or solve a structured constrained subproblem. The proposed SLP subproblem moves many coordinates simultaneously, chooses the best possible linearized Chebyshev direction under a trust region and the exact equality and box constraints, and then verifies everything with the actual evaluator. A gradient-based smooth-max method cannot do this exactly because reducing a soft objective does not guarantee reducing the true maximum overlap. This plan instead minimizes the exact affine supporting model of the maximum of many smooth lag functions and only keeps true evaluator improvements.

1.2 Why this can improve the parent

The supplied parent has C5 about 0.381011. The claimed target is around 0.3808/0.38085. Only approximately 2e-4 is needed. Such a small reduction is unlikely to come from coarse, random, fixed-size two-index moves. It should come from an algorithm that balances all currently critical overlaps. At a good quasi-stationary point many lag constraints usually are nearly tied. The SLP subproblem is specifically designed for a max-of-many-constraints objective: it computes gradients of all near-maximal lag constraints and solves the best simultaneous first-order movement. The line and discrete searches then handle the nonconvex exact curvature neglected by the linear subproblem.

1.3 Claims versus heuristics

Justified structure:

- The exact objective and gradient formula are index-exact with the supplied `np.correlate(h, 1-h, mode="full")`.
- The SLP subproblem is a linear program with an objective and affine constraints, so a stated LP solver is supported.
- Exact pair and discrete unit moves preserve the sum constraint algebraically or structurally.
- Final scores are computed by the actual objective, not the linear surrogate, soft objective, LP objective, or best smooth value.

Explicit hypotheses:

- That the hidden optimum is better reached from shift-complement, reflection-complement, simple structural, parent, noisy, or quantized starts than by a single basin is a hypothesis. Candidates from multiple starts are compared by exact score.
- Multi-start and stochastic behavior may decrease several LPs but cannot prove global optimality. The returned value is a certified upper bound for the discretized problem by direct evaluation of the final vector.
- The original program is likely nonconvex. No claim is made that final result is provably globally optimal for the full feasible set.

1.4 Alternative algorithms considered and why they are rejected as the primary method

- `SLSQP` on the original nonsmooth max objective may fail on difficult Jacobians or stop at poor KKT stationary points because the inequality function f has products and multi-cusp constraints. It requires a less transparent handling of the exact sum and relaxation. SLP retains a fully convex LP in every step and exact acceptance.
- Trying to formulate `t >= f_k(h)` directly in a convex framework would generally require replacing `h_i(1-h_j)` with a nonlinear constraint that violates CVXPY rules or using McCormick products that require an MIP relaxation. An MIP search could be longer and less reliable under the time budget.
- A global branch-and-bound or exhaustive binary branch is infeasible with the budget for n about 70 or more. A greedy LP-based method is the right nonconvex optimization framework here.
- Another direct classical smooth-max gradient method would have too much similarity to the previous attempts; SLP crosses fewer hyperplanes and less far compared to the parent movement.

2. Mathematical specification

2.1 Exact discrete representation and evaluator

Let n be the final vector length, an integer. Let dx = 2 / n and

    target = n / 2.

The feasible variables h ∈ R^n satisfy

    0 <= h_i <= 1   for all i,
    sum_i h_i = target.

The evaluator objective is exactly

    corr = np.correlate(h, 1-h, mode="full")   # length 2n-1
    C5(h) = (2/n) * max_k corr[k].

No circular correlation or periodic extension is assumed.

For later use, define the signed lag

    s = k - (n - 1),    s in {-(n-1), ..., n-1}.

With the evaluator convention, the raw overlap vector is

    R_s(h) = sum over i valid of h[i] * (1 - h[i-s]),

where

    i_low  = max(0, s)
    i_high = min(n - 1, n - 1 + s).

Then

    F_s(h) = dx * R_s(h)

is the scaled objective for signed lag s, and C5 = max over all s of F_s.

2.2 Active set and scaling of gradients

Derivation for the gradient matching this convention:

    ∂R_s/∂h_p =

    + (1 - h[p-s])   if p is in the first valid interval [i_low, i_high],
    - h[p+s]         if p is in the second valid interval [max(0,-s), min(n-1,n-1-s)],
    otherwise 0.

The scaled gradient for constraint

    F_s = dx * R_s

is

    G_s = dx * (∂R_s/∂h).

The correctness-critical behavior is dependence on `np.correlate` indexing and correct handling of the both-lags boundary sets.
