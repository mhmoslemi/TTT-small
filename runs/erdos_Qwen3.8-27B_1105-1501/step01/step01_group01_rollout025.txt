Now let me think about the CVXPY local QP. The idea is:
- At the current best h, compute the active set (lags achieving the max).
- Solve a QP to find the best local improvement while keeping all lags ≤ current max + small tolerance.
- This is a standard "active set" method for minimax problems.

Actually, a simpler and more effective approach: solve the minimax as a QP by introducing a variable t:
min t
s.t. r_k(h) ≤ t for all k
     sum(h) = n/2
     0 ≤ h ≤ 1

But r_k(h) is bilinear, not linear. So this is a QCQP (quadratically constrained QP), which can be solved by CVXPY.

The constraints r_k(h) ≤ t can be written as:
Σ_{(p,q) at lag k} h[p]*(1-h[q]) ≤ t

Expanding: Σ h[p] - Σ h[p]*h[q] ≤ t

The term h[p]*h[q] is a product of two variables, which makes this non-convex. So CVXPY won't directly handle this.

However, if we linearize around the current h:
h[p]*(1-h[q]) ≈ h0[p]*(1-h0[q]) + (1-h0[q])*(h[p]-h0[p]) + h0[p]*(-(h[q]-h0[q]))
= h0[p]*(1-h0[q]) + (1-h0[q])*Δ[p] - h0[p]*Δ[q]

where Δ = h - h0. This gives a linear approximation, and the QP becomes:
min t
s.t. [linear in Δ] ≤ t for all k
     sum(Δ) = 0
     0 ≤ h0 + Δ ≤ 1

This is a linear program (LP)! We can solve it with any LP solver. But it's only a local approximation.

A better approach: use the "semismooth" Newton method for minimax problems. The objective f(h) = max_k r_k(h) is the max of bilinear functions. At a point where the active set is {k1, ..., km}, the "directional derivative" in direction Δ is:
f'(h; Δ) = max_{k ∈ active} ∇r_k(h) · Δ

We can use this to define a descent direction. But this is essentially what the coordinate descent is already doing.

    k = np.arange(2 * n - 1)
    s = k - (n - 1)  # shape (2n-1,)
    
    # For index i:

    idx1 = i - s  # shape (2n-1,)
    valid1 = (idx1 >= 0) & (idx1 < n)

    idx2 = i + s
    valid2 = (idx2 >= 0) & (idx2 < n)

    grad_i[valid1] = (1.0 - h[idx1[valid1]])
