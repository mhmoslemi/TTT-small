One more consideration: the line search with golden section assumes the function is unimodal (which it is, being convex). But golden section converges linearly. Actually, I can do even better: since f(delta) = max_j (a_j + delta * b_j) where a_j = corr_old[j] and b_j = coeff[j], I can find the exact minimum as follows:

1. The function is convex piecewise linear.
2. The minimum on [0, T] is either at 0, at T, or at a point where the slope changes from negative to positive.
3. The slope of line j is b_j. At the minimum, the active line(s) must have slope 0 in the subgradient sense.
4. Equivalently, at the minimum, there exist lines p and q (possibly the same) such that:
   - a_p + delta*b_p = a_q + delta*b_q (they're both max at this delta)
   - b_p <= 0 <= b_q
   - delta is in [0, T]
   - All other lines have value <= this at delta

The crossing point of lines p and q is delta = (a_q - a_p) / (b_p - b_q) (when b_p ≠ b_q).

So the algorithm is:
1. For each pair (p, q) with b_p < b_q, compute delta_pq = (a_q - a_p) / (b_q - b_p)
2. If delta_pq is in [0, T], check if it's a valid candidate (i.e., at delta_pq, lines p and q are indeed among the maximizers)
3. Also check delta=0 and delta=T
4. Return the best

This is O((2n-1)^2) per pair, which for n=63 is 125^2 = 15625 checks. Each check is O(n) to verify (checking all lines at that delta). Total: 15625 * 125 ≈ 2 million operations per pair. That's a bit much if we do 20 pairs per iteration.

Alternative: just use golden section with 30-40 iterations. Each iteration is O(n) = O(125). Total: 40 * 125 = 5000 operations per pair. For 20 pairs: 100,000 operations per iteration. That's much better.

Let me go with golden section.

import numpy as np
import time

def eval_c5(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full') * dx))

def project_feasible(v, target_sum):
    n = len(v)
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(v - (lo + hi) / 2.0, 0.0, 1.0)

def get_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def line_search_pair(h, i, j, corr):
    """Minimize max(corr + delta*coeff) over delta in [0, T].
    Returns (best_delta, best_value)."""
    n = len(h)
    T = min(float(h[j]), float(1.0 - h[i]))
    if T < 1e-14:
        return 0.0, float(np.max(corr)) * (2.0 / n)
    
    dx = 2.0 / n
    coeff = np.zeros(2 * n - 1)
    for k in range(2 * n - 1):
        lag = k - (n - 1)
        c = 0.0
        if 0 <= i - lag < n:
            c += (1.0 - h[i - lag])
        if 0 <= i + lag < n:
            c -= h[i + lag]
        if 0 <= j - lag < n:
            c -= (1.0 - h[j - lag])
        if 0 <= j + lag < n:
            c += h[j + lag]
        coeff[k] = c
    
    def f_at(delta):
        return float(np.max(corr + delta * coeff)) * dx
    
    # Check if any movement helps
    f0 = f_at(0.0)
    fT = f_at(T)
    if fT >= f0 and f_at(0.5 * T) >= f0:
        return 0.0, f0
    
    # Golden section search
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    a, b = 0.0, T
    c_pt = b - gr * (b - a)
    d_pt = a + gr * (b - a)
    fc = f_at(c_pt)
    fd = f_at(d_pt)
    
    for _ in range(60):
        if b - a < 1e-15:
            break
        if fc < fd:
            b = d_pt
            d_pt = c_pt
            fd = fc
            c_pt = b - gr * (b - a)
            fc = f_at(c_pt)
        else:
            a = c_pt
            c_pt = d_pt
            fc = fd
            d_pt = a + gr * (b - a)
            fd = f_at(d_pt)
    
    best_delta = (a + b) / 2.0
    return best_delta, f_at(best_delta)

def compute_subgrad(h, corr):
    n = len(h)
    dx = 2.0 / n
    max_val = float(np.max(corr))
    if max_val < 1e-14:
        return np.zeros(n)
    tol = max(1e-10, 0.01 * max_val)
    active = np.where(corr >= (max_val - tol))[0]
    n_active = len(active)
    if n_active == 0:
        return np.zeros(n)
    
    subgrad = np.zeros(n)
    for j in active:
        lag = j - (n - 1)
        if lag >= 0:
            subgrad[lag:] += (1.0 - h[:n - lag])
            subgrad[:n - lag] -= h[lag:]
        else:
            lag2 = -lag
            subgrad[:n - lag2] += (1.0 - h[lag2:])
            subgrad[lag2:] -= h[:n - lag2]
    subgrad *= dx / n_active
    return subgrad
