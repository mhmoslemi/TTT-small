1. Approach and rationale

1.1 Central idea
Keep the supplied parent construction as the first valid fallback, but replace the previous projected-coordinate search with a search restricted to two exact, constraint-preserving “complement-symmetric” manifolds:

- Shift-complement manifold: for even length n = 2m, h[:m] = a, h[m:] = 1-a.
- Reflection-complement manifold: for even length n = 2m, for p<m, h[p] = a[p] and h[n-1-p] = 1-a[p].

These mappings make the equality sum constraint automatic in exact arithmetic: each paired contribution is x + (1-x) = m, so any a in [0,1]^k maps to a box-feasible vector and, up to machine precision, to the required sum. A final box-sum projection repairs any floating-point residue. The main local optimization is performed over the small independent vector a with a stable smooth-max surrogate, then exact accepted only after evaluation by the original objective. The parent is also improved directly using feasible two-coordinate exchange line searches. The result is therefore materially different from the previous algorithm: it deliberately searches in valid equality-sum submanifolds with independent coordinates, and it combines smooth L-BFGS-B on those submanifolds with exact coordinate and two-coordinate line polishing. The original parent construction and the non-manifold direct parent remain in the candidate pool.

1.2 Why this can improve the parent
The feasible region is {0 ≤ h_i ≤ 1, sum h_i = n/2}. Moving one full h_i alone violates the sum constraint, so any meaningful local search must either use derivatives projected onto the hyperplane or exchange mass between coordinates. The supplied parent refines mainly by smooth projected gradients followed by coarse coordinate-like and fixed-step pair moves. This strategy instead creates a coordinate representation in which the sum constraint is algebraically encoded. Single-coordinate changes on the manifold correspond to feasible joint changes in the original h and therefore allow clean coordinate descent. Soft-max optimization with L-BFGS-B moves many coordinates jointly on those manifolds. Exact later searching by coordinate line searches and true two-coordinate exchanges can find tiny reductions that are missed by soft optimization. The method does not assume global optimality. It is a justified heuristic: what is accepted is only an exact evaluator score of a feasible vector, and the non-symmetric parent is retained.

1.3 Assumptions explicitly marked as hypotheses
- Whether the hidden optimum of this finite request can be captured or significantly improved by the shift-complement or reflection-complement manifolds is a hypothesis, not a theorem.
- Smooth soft-max descent may have lower smooth objective but higher exact maximum. Candidate acceptance therefore always uses exact max, never the surrogate loss.
- The supplied parent may itself be outside those manifolds. After manifold projection the exact score could be worse, so parent and transformed starts are compared by the original evaluator.

2. Mathematical specification

2.1 Discretized representation and exact objective
Let n be the returned length, dx = 2/n, and target sum S = n/2. On successful return, constraints must satisfy 0 ≤ h_i ≤ 1 and sum_i h_i ≈ S at machine precision; the final repair mechanism described below enforces this to tolerance, and an evaluator with exact numerical equality should accept integer/binary solutions exactly.

The exact evaluator is:
F_r(h) = dx * Σ_{h_i, h_j terms} h_i (1 - h_j) for r=0,...,2n-2, and C5(h) = max_r F_r(h).
This matches np.correlate(h, 1-h, mode="full") * dx. A safe implementation calls this operation directly for exact scoring.

For gradient formulas, index r corresponds to lag s = r - (n - 1). The vectorized objective G_r = raw correlation (not yet multiplied by dx) can be written:
G_r = Σ_{(i,j): i-j=s} h_i (1-h_j),
over valid i,j∈{0,...,n-1}. Then F_r = dx * G_r eventually. This index convention matches the supplied evaluator convention:  r = n-1 + (i-j).

2.2 Full gradient used in the workflow
The derivative of F_r with respect to h is only needed internally for smooth surrogate and coordinate rankings. It is computed after exact correlation.

For each r, with x = r-(n-1), using linear weights w_r that come from softmax:
- h contribution: for integer i from max(0, x) to min(n-1, n-1+x), add w_r*dx*(1 - h_{i-x}).
- 1-h contribution: for integer j from max(0, -x) to min(n-1, n-1-x), subtract w_r*dx*h_{j+x}.
The resulting grad_h matches the sign convention of np.correlate(h, 1-h, mode="full") when tested by small finite differences. If finite-difference verification is desired, test random length 6 and interval center taps.

2.3 Complement-symmetric manifolds
For an even full length n=2m:

Shift-complement map SC(a):
- a length m.
- h[:m] = a.
- h[m:] = 1 - a.
- sum(h)=m=n/2 exactly mathematically.
- bounds: OK if each a∈[0,1].

Reflection-complement map RC(a):
- a length m.
- for p=0,...,m-1, pair q=n-1-p, h[p]=a[p], h[q]=1-a[p].
- sum(h)=m=n/2 exactly mathematically.
- bounds: OK if each a∈[0,1].

These maps are linear projections of the box and equality constraints. They are not relaxations of the original feasible set; they are feasible subsets. Candidate quality comparison is still based on the full objective over all 2n-1 lags of the mapped full vector.

- RC: a_p = 0.5*(h_p + 1 - h_{n-1-p}), then clip to [0,1].
The full mapped candidate is then recovered, a final exact box-sum projection is applied, and the exact evaluator is called. Exact acceptance is what matters; the projection is only a recovery mechanism.

2.4 Global feasible-box exact projection
Define a top-level helper project_box_sum(x, target). Operation:
1. copy, replace non-finite by 0/1;
2. clip current x to [0,1];
3. if sum(x) is not target within about 1e-12, binary search scalar shift c in interval [-4, max(x)+4] so that sum(clip(x-c,0,1)) is near target using about 60 iterations;

choose i≠j, direction d=u_i t, u_j -t, all others 0.
