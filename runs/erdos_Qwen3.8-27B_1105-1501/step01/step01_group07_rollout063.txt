    lo = max(-h[i], h[j] - 1.0)
    hi = min(1.0 - h[i], h[j])
    if hi - lo < 1e-15:
        return 0.0, float(np.max(S)), S
    
    # f(δ) = max_C (S[C] + δ * g[C])
    # Grid search + golden section
    grid = np.linspace(lo, hi, 20)
    f_vals = np.array([np.max(S + d * g) for d in grid])
    best_idx = int(np.argmin(f_vals))
    
    # Golden section around best grid point
    span = (hi - lo) / 20.0
    a = max(lo, grid[best_idx] - 1.5*span)
    b = min(hi, grid[best_idx] + 1.5*span)
    
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    # Golden section search
    c = b - gr * (b - a)
    d = a + gr * (b - a)
    fc = np.max(S + c * g)
    fd = np.max(S + d * g)
    for _ in range(40):
        if fc < fd:
            b = d; d = c; fd = fc
            c = b - gr * (b - a)
            fc = np.max(S + c * g)
        else:
            a = c; c = d; fc = fd
            d = a + gr * (b - a)
            fd = np.max(S + d * g)
    
    best_delta = (a + b) / 2.0
    best_score = float(np.max(S + best_delta * g))
    return best_delta, best_score, S + best_delta * g

With discretization: C₅ = max(np.correlate(h, 1-h, mode="full") * dx)

But wait - the integral ∫ h(x)(1-h(x+k)) dx over what domain? It should be over the region where BOTH x and x+k are in [0,2]. The correlation automatically handles this (it only sums over valid indices).

And the max is over all valid k (all shifts where there's overlap). The full correlation gives all shifts from -(n-1)*dx to (n-1)*dx.

For k=0: ∫₀² h(x)(1-h(x)) dx = ∫h - ∫h² = 1 - ∫h²

For the constant h=1/2: this is 1 - 2*(1/4) = 1/2. And the max over all k would be 1/2 (at k=0).

For a binary h with 35 ones: at k=0, the integral is 0 (since h(1-h)=0 for binary h).

So the k=0 term is always ≤ 1/2 for any h with ∫h=1 (by the fact that h(1-h) ≤ 1/4 max, and ∫h(1-h) = 1-∫h² ≤ 1-1=0 for binary, up to 1-1/2=1/2 for constant).

Wait, for binary h: ∫h² = ∫h = 1 (since h² = h for binary). So ∫h(1-h) = 1-1 = 0. ✓

For h=1/2 constant: ∫h² = 2*(1/4) = 1/2. ∫h(1-h) = 1-1/2 = 1/2.

So the k=0 term ranges from 0 (binary) to 1/2 (constant). It's not the bottleneck for good solutions.

The bottleneck is at intermediate k values, where the overlap is large but the function isn't perfectly periodic.
