Let me also think about one more thing: the "smooth LSE" approach. The log-sum-exp function:
  L_β(h) = (1/β) log(∑_k exp(β · c_k(h) · dx))

approximates max_k c_k(h)·dx as β → ∞. For finite β, it's smooth and differentiable.

The gradient is:
  ∇L_β(h) = (1/β) · (∑_k exp(β·c_k(h)·dx) · ∇(c_k(h)·dx)) / (∑_k exp(β·c_k(h)·dx))
           = dx · (∑_k p_k · ∇c_k(h))  where p_k = exp(β·c_k·dx) / ∑_j exp(β·c_j·dx)

The gradient of c_k with respect to h:
  ∂c_k/∂h[i] = sum of contributions from terms in c_k that involve h[i]

For the correlate, c_k = ∑_m h[m+shift]·(1-h[m]) where shift = k-(n-1).
  ∂c_k/∂h[i] = (contribution as first factor) + (contribution as second factor)
  
First factor: h[i] appears as h[m+shift] when m = i-shift = i-(k-(n-1))
  ∂/∂h[i] of h[i]·(1-h[m]) = (1-h[m]) = (1-h[i-(k-(n-1))])
  Valid when 0 ≤ i-(k-(n-1)) < n

Second factor: h[i] appears as h[m] when m = i
  ∂/∂h[i] of h[i+shift]·(1-h[i]) = -h[i+shift] = -h[i+(k-(n-1))]
  Valid when 0 ≤ i+(k-(n-1)) < n

Note: when both are valid and i-(k-(n-1)) = i, i.e., k = n-1, we have:
  ∂c_{n-1}/∂h[i] = (1-h[i]) + (-h[i]) = 1 - 2h[i]

This makes sense: c_{n-1} = ∑_i h[i]·(1-h[i]), and ∂/∂h[i] = 1-2h[i]. ✓

Let me also add one more optimization idea that's different from everything above: **gradient projection with line search**.

The idea:
1. Compute the gradient of the active constraint: ∇c_{k*}(h)
2. Project the negative gradient onto the feasible set (plane ∑h = n/2, box [0,1]^n)
3. Do a line search along the projected direction

This is essentially "projected gradient descent" for the min-max problem, using only the active constraint's gradient.

The advantage over pairwise CD: it can move in a direction that involves many variables simultaneously, which might be more efficient when the optimum requires coordinated changes.

The disadvantage: the line search is 1D but the function is not convex along arbitrary directions (only along pairwise directions). So the line search might not find the true minimum along the direction.

I'll use a "backtracking" line search: start with a full step, reduce by half until the objective decreases.

Let me implement this as an additional method:

```python
def grad_step(h, max_iter=100):
    """One step of projected subgradient method on active constraint."""
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    active_k = np.argmax(corr)
    
    # Compute gradient of c_{active_k}
    shift = active_k - (n - 1)
    grad = np.zeros(n)
    for i in range(n):
        # h[i] as first factor: m = i - shift
        m = i - shift
        if 0 <= m < n:
            grad[i] += (1.0 - h[m])
        # h[i] as second factor: m = i, first at i+shift
        if 0 <= i + shift < n:
            grad[i] += (-h[i + shift])
    
    grad *= dx  # Scale by dx for the actual objective
    
    # Project: find d in null space of [1,1,...,1] that minimizes grad·d
    # The projection of -grad onto the plane sum(d)=0 is:
    # d = -grad + (mean(grad)) * ones
    mean_grad = np.mean(grad)
    d = -grad + mean_grad  # This ensures sum(d) = 0
    
    # Line search
    cur_f = np.max(corr) * dx
    alpha = 1.0
    for _ in range(30):
        h_new = h + alpha * d
        if np.all(h_new >= -1e-10) and np.all(h_new <= 1.0 + 1e-10):
            h_trial = np.clip(h_new, 0.0, 1.0)
            f_trial = score_exact(h_trial)
            if f_trial < cur_f:
                return h_trial, f_trial
        alpha *= 0.5
    return h, cur_f
```
