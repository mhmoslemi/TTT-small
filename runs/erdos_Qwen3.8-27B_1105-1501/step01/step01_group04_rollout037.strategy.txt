1. Approach and rationale

1.1 Central idea

Use a **target-feasibility search in the exact evaluator**.  Instead of optimizing a smoothed maximum or descending only where the current maximum correlation occurs, the primary optimizer repeatedly asks the question:

> “Using the exact discrete evaluator, can I find a feasible vector whose every scaled correlation entry stays below a slightly smaller constant  τ?”

For each trial bound τ, it solves a smooth, global-constraint-safe surrogate feasibility problem:

- variables are the same sample values h[0..n-1];
- constraints are the actual task constraints 0 ≤ h_i ≤ 1 and sum h_i = n/2;
- objective is a smooth penalized sum of soft-positive violations of the upper-bound constraints  dx·correlation_k(h) ≤ τ.

The surrogate is never treated as the final answer. Every proposed vector that becomes exactly feasible is evaluated using the authoritative evaluator

  C₅(h) = dx · max_k np.correlate(h, 1-h, "full")[k].

Only an exact evaluator improvement is accepted into the global best candidate. A sequence of τ values is tried, from moderately below the current best bound down to very small steps. Once a candidate improves the exact C₅, the target schedule is re-centered at the new exact value. This is materially different from the current parent/local strategies: the optimizer directly enforces an external constant threshold through a smooth feasibility objective, giving simultaneous pressure on the correlation constraints that determine that threshold, rather than following only a single gradient direction against the current maximum.

1.2 Why this may improve the current parent construction

The current target improvement is very small. If the parent is sitting in a good local basin, methods that descend only the current maximum can stall because:

- many correlations are nearly tied at the maximum;

A feasibility objective against τ penalizes each correlated pair according to a smooth soft-plus penalty with sharpness chosen around the attempted improvement size. This applies equal linearization pressure to all correlations near the attempted bound. The exact sequence of candidates is judged by the true evaluator.
