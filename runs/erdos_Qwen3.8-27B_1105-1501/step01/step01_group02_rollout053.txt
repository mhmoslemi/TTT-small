But since the line search finds the best δ for that pair, a "worse" result means the best δ for that pair is still worse than the current state. In that case, accepting it would be a "downhill" move in the neighborhood of pair (i,j).

I think a simpler anti-stagnation strategy is better:
- If stuck for N iterations, try a random perturbation
- If still stuck, try a bigger perturbation
- Periodically try a completely random restart (but keep the best found)
