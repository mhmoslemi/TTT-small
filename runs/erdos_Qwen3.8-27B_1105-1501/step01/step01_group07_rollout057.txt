def make_feasible(y, n=None):

    return g

But the function `score_exact` just computes the correlation - it doesn't check feasibility. The feasibility is maintained by construction (we're doing h[i]+a + h[j]-a = h[i]+h[j], so the sum is preserved, and a is chosen so both stay in [0,1]).

But there's a subtlety: the golden section finds the minimum of c_max(a), but c_max(a) might be minimized at a point where the "active" lag changes. Since c_max is convex, golden section will still find the right point.

def make_feasible(y, n=None):
    if n is None:
        n = len(y)
    y = np.asarray(y, dtype=np.float64).copy()
    target = n / 2.0
    lo = float(np.min(y)) - 1.5
    hi = float(np.max(y)) + 1.5
    for _ in range(50):
        mid = 0.5 * (lo + hi)
        s = np.sum(np.clip(y - mid, 0.0, 1.0))
        if s > target:
            lo = mid
        else:
            hi = mid
    z = np.clip(y - 0.5 * (lo + hi), 0.0, 1.0)
    diff = target - np.sum(z)
    if abs(diff) > 1e-12:
        if diff > 0:
            order = np.argsort(z)
            for idx in order:
                if diff <= 1e-13:
                    break
                add = min(diff, 1.0 - z[idx])
                z[idx] += add
                diff -= add
        else:
            order = np.argsort(z)[::-1]
            for idx in order:
                if -diff <= 1e-13:
                    break
                sub = min(-diff, z[idx])
                z[idx] -= sub
                diff += sub
    return np.clip(z, 0.0, 1.0)
