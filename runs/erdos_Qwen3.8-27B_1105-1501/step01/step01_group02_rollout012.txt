**Algorithm: Iterated Local Search (ILS)**

1. Start from current h
2. Repeat:
   a. Do best-improvement local search:
      - For each pair (i,j) in random order:
        - Find best t by scanning 20 points in feasible range
        - Apply if improvement
      - Stop when no improvement in a full pass
   b. Perturb: make k random pair moves (k ~ 3-10)
   c. If perturbed solution improves best, restart from there
   d. If stuck for many iterations, try a larger perturbation

This is a standard ILS approach that works well for combinatorial optimization.

    """Project onto box + sum constraint."""
    x = np.clip(np.asarray(x, dtype=float), 0.0, 1.0)

        if abs(s - target) < 1e-13:
