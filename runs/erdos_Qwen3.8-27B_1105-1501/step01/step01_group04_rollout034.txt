Let me think about this more concretely:

For a given lag k, corr_k = sum_i h[i] * (1-h[i-k]).
To reduce corr_k, we want to:
- Decrease h[i] where h[i-k] is small (so the product h[i]*(1-h[i-k]) is large)
- Or increase h[i-k] where h[i] is large (so the product h[i]*(1-h[i-k]) is large)

But changing h[i] also affects other lags. The key is to make changes that reduce the active lags without increasing the max.

**Algorithm: Greedy active-lag reduction**

1. Compute C₅ and identify active lags (corr_k ≥ C₅ - ε).
2. For each active lag k, find the pair (i, i-k) that contributes most to corr_k (i.e., h[i]*(1-h[i-k]) is maximized).
3. Propose a change: decrease h[i] by δ and increase h[i-k] by δ (or some other balanced change).
4. Evaluate the new C₅. If it improved, accept; otherwise, try the next pair.
5. Repeat until no improvement is found or time runs out.

This is essentially a greedy local search guided by the active set.

**Better binary local search: First-improvement with active set**

1. Compute corr and identify active lags (top T).
2. For each active lag k, the correlation is sum_t h[t]*(1-h[t-k]).
3. The "contribution" of position t to corr_k (as the first factor) is h[t]*(1-h[t-k]).
4. To reduce corr_k, we want to reduce the contributions from positions where h[t]=1 and h[t-k]=0.
5. A swap that moves h[i] from 1 to 0 (where i is such a position for an active lag) will reduce that lag.
6. But the same swap might increase other lags.

So the algorithm is:
1. For each active position i (h[i]=1), find which active lags it "helps" (where h[i-k]=0 for active lag k).
2. Try moving i to an inactive position j, and check if the max correlation decreases.
3. Accept the first improving move (or the best improving move).

For efficiency, when we move i to j, the change in corr_k for a specific lag k is:
Δk = [h[i-k]-1 + h[i+k]] * 1_{valid} + [1-h[j-k] - h[j+k]] * 1_{valid}

Wait, I realize I should just compute this more carefully.

Let me define h as a binary vector (for simplicity, even n). A swap moves position i (h[i]=1) to position j (h[j]=0).

The new vector h' has h'[i]=0, h'[j]=1, and h'[t]=h[t] for t≠i,j.

The new correlation at lag k:
corr'_k = corr_k + Δk

where Δk = [contribution change from i going 1→0] + [contribution change from j going 0→1]

Contribution change from i (1→0):
- As first factor at position i: old contribution = 1*(1-h[i-k]) = 1-h[i-k], new = 0. Change = -(1-h[i-k]) = h[i-k]-1
  (valid when 0≤i-k<n)
- As second factor (h[t-k]=h[i] when t=i+k): old contribution = h[i+k]*(1-1) = 0, new = h[i+k]*(1-0) = h[i+k]. Change = +h[i+k]
  (valid when 0≤i+k<n)

Contribution change from j (0→1):
- As first factor at position j: old = 0, new = 1*(1-h[j-k]) = 1-h[j-k]. Change = +(1-h[j-k])
  (valid when 0≤j-k<n)
- As second factor (h[t-k]=h[j] when t=j+k): old = h[j+k]*(1-0) = h[j+k], new = h[j+k]*(1-1) = 0. Change = -h[j+k]
  (valid when 0≤j+k<n)

Total: Δk = (h[i-k]-1)·1_{0≤i-k<n} + h[i+k]·1_{0≤i+k<n} + (1-h[j-k])·1_{0≤j-k<n} - h[j+k]·1_{0≤j+k<n}

For a binary h, h[i-k] ∈ {0,1}, so:
- If h[i-k]=0: contribution is -1
- If h[i-k]=1: contribution is 0
- h[i+k]: 0 or 1
- If h[j-k]=0: contribution is +1
- If h[j-k]=1: contribution is 0
- h[j+k]: 0 or 1

So Δk ∈ {-2, -1, 0, 1, 2} (roughly), and we want Δk ≤ 0 for all active k (and not too positive for inactive k).

A "good" swap has Δk ≤ 0 for all active k and max(corr_k + Δk) < max(corr_k).

For the local search, I'll:
1. Compute the top T active lags.
2. For each candidate (i, j) swap, compute Δk for k in the active set.
3. If max_{k∈active}(corr_k + Δk) < current_max, and max_{k∉active}(corr_k + Δk) ≤ current_max, accept.

The check for inactive lags can be done by computing the full max(corr + delta) using numpy (O(n) per swap).

For n=99, there are at most 49*49 = 2401 swaps to consider per sweep (for even n=98: 49 ones * 49 zeros = 2401). Each evaluation is O(n) = O(99). Total per sweep: ~240K operations. With numpy, this should take a few ms per sweep.

```python
import numpy as np
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_to_box_sum(h, target):
    lo = float(h.min()) - 1.0
    hi = float(h.max()) + 1.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(h - mid, 0.0, 1.0))
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def smooth_max_gradient(h, alpha):
    n = len(h)
    corr = compute_corr(h)
    max_c = np.max(corr)
    shifted = alpha * (corr - max_c)
    # Clip for numerical stability
    shifted = np.clip(shifted, -50, 0)
    exp_c = np.exp(shifted)
    p = exp_c / np.sum(exp_c)
    
    # Compute gradient
    one_minus_h = 1.0 - h
    grad = np.zeros(n)
    for j in range(n):
        # First sum: sum_{l=0}^{n-1} (1-h[l]) * p[j+n-1-l]
        # p indices: j+n-1, j+n-2, ..., j (reversed: j, j+1, ..., j+n-1)
        first = np.dot(one_minus_h, p[j:j+n][::-1])
        # Second sum: sum_{l=0}^{n-1} h[l] * p[n-1-j+l]
        # p indices: n-1-j, n-j, ..., 2n-2-j
        second = np.dot(h, p[n-1-j:2*n-1-j])
        grad[j] = first - second
    
    return float(max_c), grad

def optimize_gradient(h0, time_budget, alpha0=10.0, alpha_growth=1.02, lr0=0.01, seed=42):
    n = len(h0)
    target = float(n) / 2.0
    h = np.clip(h0.astype(float).copy(), 0.0, 1.0)
    h = project_to_box_sum(h, target)
    best_h = h.copy()
    best_c5 = compute_c5(h)
    t0 = time.time()
    
    alpha = alpha0
    lr = lr0
    momentum = 0.85
    v = np.zeros(n)
    stall = 0
    stall_limit = 300
    
    while time.time() - t0 < time_budget:
        max_c, grad = smooth_max_gradient(h, alpha)
        v = momentum * v - lr * grad
        h_new = project_to_box_sum(h + v, target)
        c5 = compute_c5(h_new)
        
        if c5 < best_c5:
            best_c5 = c5
            best_h = h_new.copy()
            stall = 0
        else:
            stall += 1
        
        h = h_new
        
        if stall > stall_limit:
            rng = np.random.RandomState(seed + stall)
            h = best_h + 0.03 * rng.randn(n)
            h = project_to_box_sum(h, target)
            v = np.zeros(n)
            stall = 0
            lr = max(lr * 0.5, 0.001)
        
        alpha *= alpha_growth
        lr = max(lr * 0.995, 0.0005)
    
    return best_h, best_c5
