For the line search along direction d from point h:
- We need to find α that minimizes max_s C_s(h + α*d)
- Subject to 0 ≤ h[i] + α*d[i] ≤ 1 for all i
- And sum(h + α*d) = n/2 (already satisfied if sum(d) = 0)

The feasible range of α:
- For d[i] > 0: α ≤ (1 - h[i]) / d[i]
- For d[i] < 0: α ≥ -(h[i]) / (-d[i]) = h[i] / d[i] (which is negative, so α ≥ 0 handles this)
- Actually: 0 ≤ h[i] + α*d[i] ≤ 1
  - If d[i] > 0: 0 ≤ h[i] + α*d[i] ≤ 1 => -h[i]/d[i] ≤ α ≤ (1-h[i])/d[i]. Since α ≥ 0 and h[i] ≥ 0, the lower bound is ≤ 0, so α ≥ 0. Upper: α ≤ (1-h[i])/d[i].
  - If d[i] < 0: 0 ≤ h[i] + α*d[i] ≤ 1 => (1-h[i])/d[i] ≤ α ≤ -h[i]/d[i]. Since d[i] < 0, (1-h[i])/d[i] ≤ 0, so lower bound is 0. Upper: α ≤ -h[i]/d[i] = h[i]/(-d[i]).
  - If d[i] = 0: no constraint on α from this coordinate.

So α_max = min over i with d[i]≠0 of the upper bound.

For the objective: C_s(h + α*d) is a quadratic in α for each s. The max of finitely many quadratics can have at most O(n²) critical points, but in practice near a good point it's well-behaved.

I'll use a simple approach: evaluate on a grid of α values in [0, α_max], find the best, then refine with golden section.

        grad[:n-s] -= ws * h[s:]

        if wp < 1e-15:
