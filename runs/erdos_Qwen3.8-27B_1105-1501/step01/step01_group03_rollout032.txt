Now let me think about the active-set exact descent more carefully.

The idea: instead of using smooth max, focus on the top few lags (active set). The exact gradient of max(C_k) at the active set is a convex combination of the individual lag gradients. If we use equal weights on the top Q lags (or weights proportional to how close they are to the max), we get a descent direction for the max.

Actually, at a point where C_{k1} = C_{k2} = ... = C_{kQ} = max, the subdifferential of max is the convex hull of {e_{k1}, ..., e_{kQ}}. So any convex combination gives a subgradient. Using equal weights is a common choice.

For a strictly active set (only one lag is at the max), the gradient is just that lag's gradient.

For the projected gradient step:
1. Compute g = weighted combination of active lag gradients
2. Compute search direction d = -g (in h-space)
3. Project d onto the feasible set (box + sum constraint):
   - This is a quadratic program: min ||d - d_raw||^2 s.t. 0 <= h_i + d_i <= 1, sum(d_i) = 0
   - Can be solved by bisection on a scalar parameter (similar to the sum-constraint projection)
4. Line search: find best step α > 0 such that f(h + α*d) < f(h)

For the projection step, given raw direction d_raw:
We want to find d that minimizes ||d - d_raw||^2 subject to:
- -h_i <= d_i <= 1 - h_i for all i
- sum(d_i) = 0

This is equivalent to: d_i = clip(d_raw_i - λ, -h_i, 1-h_i) for some λ, where λ is chosen so that sum(d_i) = 0.

Since sum(clip(d_raw_i - λ, -h_i, 1-h_i)) is a monotonically decreasing function of λ (each term is non-increasing in λ, and at least one is strictly decreasing for λ in a range), we can find λ by bisection.

def sigmoid(x):
    out = np.empty_like(x, dtype=float)
    pos = x >= 0
    out[pos] = 1.0 / (1.0 + np.exp(-x[pos]))
    ex = np.exp(x[~pos])
    out[~pos] = ex / (1.0 + ex)
    return out

def safe_logit(h):
    h = np.clip(h, 1e-10, 1.0 - 1e-10)

        end = min(n, n - k)
        F[k + n - 1] = np.sum(h[start:end] * (1.0 - h[start + k:end + k]))

    start = max(0, -k)
    end = min(n, n - k)

def _sigmoid(x):
    out = np.empty_like(x, dtype=float)
    pos = x >= 0
    out[pos] = 1.0 / (1.0 + np.exp(-x[pos]))
    ex = np.exp(x[~pos])
    out[~pos] = ex / (1.0 + ex)
    return out


def _safelogit(h):

def official_score(h):

def compute_all_F(h, n):

    for k in range(-(n - 1), n):
        start = max(0, -k)
        end = min(n, n - k)
        F[k + n - 1] = np.sum(h[start:end] * (1.0 - h[start + k:end + k]))
    return F


def compute_lag_grad(h, k, n):
    grad = np.zeros(n)
    start = max(0, -k)
    end = min(n, n - k)
    if start < end:
        grad[start:end] += (1.0 - h[start + k:end + k])
    s2 = max(0, k)
    e2 = min(n, n + k)
    if s2 < e2:
        grad[s2:e2] += -h[s2 - k:e2 - k]
    return grad

    es = np.exp(shifted - m)
