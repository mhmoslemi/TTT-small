    """Project h onto {x : 0 <= x_i <= 1, sum(x) = target_sum}."""

= h[i+s] - h[j+s] + h[i-s] - h[j-s]  (with out-of-bounds = 0)

This is linear in δ, so corr_new[k] = corr[k] + δ * change[k].

The maximum of corr_new is max_k (corr[k] + δ * change[k]). We want to find δ in [0, min(1-h[j], h[i])] that minimizes this maximum.

This is a 1D minimax problem: minimize max_k (a_k + δ * b_k) over δ in [0, D].

This can be solved by checking the breakpoints where the "active" lag changes. The function f(δ) = max_k (a_k + δ*b_k) is a convex piecewise-linear function of δ. Its minimum can be found by:
1. Evaluating at δ=0 and δ=D
2. Finding the optimal point where two lines cross at the maximum

For a simpler approach, since n is small, we can just do a fine grid search or use ternary search.

Actually, the simplest efficient approach: since f(δ) is convex piecewise linear, the minimum is either at an endpoint or at a "kink" where the active set changes. We can find it by:
- Evaluating f at δ=0 and δ=D
- If f is decreasing at 0 and increasing at D, the minimum is in between
- Use binary search or evaluate at the optimal point

                break
            start_time = time.time()
            start_budget = min(15.0, deadline - start_time - 2)
            if start_budget < 5:
                break

            if s == 0:
                h_init = make_structured(n, 0)
            elif s == 1:
                h_init = make_structured(n, 1)
            elif s == 2:
                h_init = make_structured(n, 2)
            else:
                h_init = make_random_binary(n, rng)

            result_h, result_c5 = optimize_single(h_init, rng, start_budget)
            if result_c5 < best_c5:
                best_c5 = result_c
                best_h = result_h.copy()
                best_n = n

    # Final polish on best solution
    if best_h is not None and time.time() < budget_s - 10:
        n_best = len(best_h)
        target_sum = n_best / 2.0
        best_h = project_onto_constraint(best_h, target_sum)
        v_best = compute_v_matrix(best_h)
        while time.time() < budget_s - 5:
            best_h, improved, c5_val = continuous_pair_sweep(best_h, v_best)
            if c5_val < best_c5:
                best_c5 = c5_val
            if improved == 0:
                break

    # Final check
    if best_h is not None:
        n_final = len(best_h)
        target_final = n_final / 2.0
        best_h = project_onto_constraint(best_h, target_final)
        final_c5 = compute_c5(best_h)
        if final_c5 < best_c5:
            best_c5 = final_c5

    if best_h is None:
        # Fallback: create a simple solution
        n = n_parent
        h = make_random_binary(n, rng)
        h = project_onto_constraint(h, n / 2.0)
        v = compute_v_matrix(h)
        h, _, _ = continuous_pair_sweep(h, v)
        best_h = h
        best_c5 = compute_c5(h)
        best_n = n

    return best_h, best_c5, len(best_h)
