C_r(h) = sum_p h_{p+q}(1-h_p)

When we set h_i = x, h_j = S-x:
- Terms involving h_i: h_i appears as either the "first" or "second" factor
- If h_i is the first factor: term = x * (1 - h_p) which is linear in x

So each C_r(x) is a quadratic (or linear/constant) in x. The max of quadratics is not necessarily convex or concave. It's piecewise quadratic with the pieces changing at the intersections of the quadratics.

Given this, golden section is not guaranteed to work globally. But my approach of first sampling to find the region, then using golden section within a small neighborhood, should work well in practice.

    # Better: use physical positions

    h = np.interp(xt % 2.0, xs, parent, left=parent[0], right=parent[-1])

def repair(v, n_target):
    h = np.array(v, dtype=float).copy().ravel()
    if len(h) < n_target:
        h = np.pad(h, (0, n_target - len(h)), constant_values=0.5)
    else:
        h = h[:n_target]
    h = np.clip(h, 0.0, 1.0)
    target = n_target / 2.0
    for _ in range(500):
        residual = target - np.sum(h)
        if abs(residual) < 1e-14:
            break
        if residual > 0:
            idx = np.argmax(1.0 - h)
            h[idx] = min(1.0, h[idx] + residual)
        else:
            idx = np.argmax(h)
            h[idx] = max(0.0, h[idx] + residual)
    return h

        return repair(np.full(n_new, 0.5), n_new)

    h = np.interp(xt, xs, parent, left=parent[0], right=parent[-1])
    return repair(h, n_new)

                h, did = pair_line_search(h, i, j)
