1. Approach and rationale

The proposed method replaces the parent program’s hand-coded annealed projected-gradient plus coordinate/random-increment approach with a constrained smooth-max nonlinear programming framework, continued by an exact feasible line-search over two-coordinate exchanges. The central idea is:

- Treat the objective as the maximum of the 2n-1 lag correlations.
- Replace this maximum by a carefully annealed sigmoid/log-sum-exp approximation.
- Optimize the smooth surrogate with a classical constrained optimizer that directly handles the box and equality constraints, rather than relying on repeated projection as the dominant update method.
- Accept candidates only after re-evaluating them with the original evaluator and enforcing the exact feasibility constraints again.
- Escape poor smooth solutions by generating coercive alternatives from the supplied parent through reflection, cyclic shift, local noise, up-resampling, and fractional pair exchanges.

This addresses the actual weakness of the supplied parent descent logic: a single coordinate cannot be moved while the sum is fixed; therefore, an effective move must involve coordinated changes among coordinates and must preserve the equality constraint before the exact objective is evaluated. Smooth-max SLSQP-style optimization moves coordinated variables along feasible directions. The additional exact 1-dimensional pair line searches are much stronger than fixed step two-coordinate increments and can repair the final local residual because every step preserves sum exactly.

Important facts used:

- The evaluator objective is exact at discrete lag indices and includes both lag signs:
  C5(h) = max_{s=-(n-1),...,n-1} dx * sum_{valid i} h_i (1 - h_{i-s}), dx = 2/n.
- The equality constraint is linear and feasible for any n: target sum S = n/2.
- Moving two coordinates as h_i -> h_i+t, h_j -> h_j-t preserves the equality constraint exactly for any t in a computed feasible interval. This forms a valid local feasible move space after the main smooth step, because tangent moves of the bounded-sum set are spanned by coordinate-pair exchanges.

Important limitations and honesty:

- The problem is nonconvex due to h_i h_j terms. The smooth optimization is a local method. It does not claim a global optimum.
- Every accepted candidate is assessed by the original non-smooth objective. A smooth decrease can be accepted only for a different temperature step, but it will not be reported as final unless its exact non-smooth value improves the best valid candidate.
- The method relies on the supplied parent being near a strong local structure. It also relies on random restart-like moves to escape bad smooth paths; that is a hypothesis, but all moves are heuristic refinements with monotone exact acceptance and a valid fallback.

2. Mathematical specification

2.1 Discrete representation and exact objective

Let h be a real array of length n, with 0 <= h_i <= 1 and sum_i h_i = S = n/2. Define dx = 2/n.

The evaluator corresponds to the finite-support bilinear correlation vector:

  G_s(h) = dx * sum_{i: 0 <= i < n and 0 <= i-s < n} h_i * (1 - h_{i-s}), for s = -(n-1),...,n-1.

This convention matches np.correlate(h, 1-h, mode="full") * dx, where the output index z = (n-1)+s corresponds to shift s. In particular:

- Lag z = n-1 is s=0:
  G_0 = dx * sum_i h_i (1 - h_i) = dx * (S - sum_i h_i^2).
- Lag z=0 is s=-(n-1):
  G_y = G_{-(n-1)} = dx * h_0 * (1 - h_{n-1}).
- Lag z=2n-2 is s=n-1:
  G = dx * h_{n-1} * (1 - h_0).

The exact objective is E(h) = max_z G_z(h). The positive pairs are generated by np.correlate mode full. Do not replace this with a circular correlation or ignore boundary-lag effects.

2.2 Smooth surrogate objective

For temperature T > 0, define:

  Phi_T(h) = T * log(sum_z exp(E_z(h)/T)),

where E_z(h) = G_z(h) is already multiplied by dx. Then Phi_T(h) >= E(h) and Phi_T(h) -> E(h) as T -> 0+.

For numerical stability, evaluate:

  M = max_z E_z(h)
  d_z = (E_z(h) - M) / T
  d_z clipped to <=0 and >= -80 to avoid overflow/underflow
  w_z = exp(d_z) / sum_j exp(d_j).

Then:

  Phi_T(h) = M + T * log(sum_j exp(d_j)).

The gradient of Phi_T with respect to h_i is:

  grad_i Phi_T(h) = sum_z w_z * grad_i E_z(h).

This is a smooth surrogate. The final best candidate is judged later using E(h), not Phi_T(h).
