Let me think about one more idea: **successive convex approximation (SCA)**. At each iteration, I approximate the non-convex max-of-quadratics as a convex problem (linear or quadratic) and solve it. This could be more effective than plain gradient descent.

Specifically, at the current point h₀, I can linearize each corr_k around h₀:
corr_k(h₀ + Δh) ≈ corr_k(h₀) + ∇corr_k(h₀)·Δh

Then min max_k [corr_k(h₀) + ∇corr_k(h₀)·Δh] * dx subject to feasibility is a linear program!

This is the "cutting plane" or "linearized" approach. Each iteration solves an LP (or QP if I use a second-order approximation).

With cvxpy, I could solve this LP efficiently. Let me try this approach:

```python
import cvxpy as cp

def sca_step(h0, target_sum, n):
    """One SCA iteration: linearize and solve LP."""
    dx = 2.0 / n
    corr = compute_corr(h0)
    m = np.max(corr)
    
    # Only consider top lags (for efficiency)
    top_k = 20
    idx = np.argsort(corr)[-top_k:]
    c_top = corr[idx]
    
    # Compute gradients for top lags
    grads = np.zeros((top_k, n))
    for i, k in enumerate(idx):
        s = k - (n-1)
        g = np.zeros(n)
        if s >= 0:
            g[:n-s] = (1.0 - h0[s:])
            if s > 0:
                g[s:] -= h0[:n-s]
        else:
            sp = -s
            g[sp:] = (1.0 - h0[:n-sp])
            g[:n-sp] -= h0[sp:]
        grads[i] = g
    
    # LP: min t
    # s.t. c_top[i] + grads[i]·Δh <= t/dx, for all i
    #      0 <= h0 + Δh <= 1
    #      sum(h0 + Δh) = n/2
    
    delta_h = cp.Variable(n)
    t = cp.Variable()
    
    constraints = [
        delta_h >= -h0,
        delta_h <= 1 - h0,
        cp.sum(h0 + delta_h) == target_sum
    ]
    
    for i in range(top_k):
        constraints.append(c_top[i] + grads[i] @ delta_h <= t)
    
    obj = cp.Minimize(t)
    prob = cp.Problem(obj, constraints)
    prob.solve(solver=cp.GLPK)  # or CBC
    
    if delta_h.value is not None:
        h_new = h0 + delta_h.value
        h_new = np.clip(h_new, 0, 1)
        h_new = project_onto_constraint(h_new, target_sum)
        return h_new
    return h0
```

Let me try a different approach: **Frank-Wolfe (conditional gradient) method**. This is designed for optimization over polytopes (like our {h: 0≤h≤1, sum(h)=n/2}).

At each iteration:
1. Compute gradient g of the objective at current point h
2. Find the vertex v of the polytope that minimizes g·v (this is a linear program, but for our polytope it's easy: v[i] = 1 for the n/2 indices with smallest g[i], 0 otherwise)
3. Move: h_new = (1-γ)h + γv, where γ is step size

The advantage: each iteration only requires computing the gradient (O(n²)) and sorting (O(n log n)). No projection needed!

Let me implement this:

```python
def frank_wolfe_step(h, grad, target_sum, gamma):
    """One Frank-Wolfe step."""
    n = len(h)
    # Find vertex: set h[i]=1 for the indices with smallest gradient
    # (since we're minimizing)
    idx = np.argsort(grad)
    v = np.zeros(n)
    v[idx[:int(target_sum)]] = 1.0
    # Frank-Wolfe update
    h_new = (1 - gamma) * h + gamma * v
    return h_new
```
