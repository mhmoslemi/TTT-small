**Improved Coordinate Descent:**

The key insight is that for each coordinate j, we need to minimize:

- f is a convex piecewise-linear function.
- Its minimum on [lo, hi] is at one of: lo, hi, or a breakpoint.
- The breakpoints are where two lines S0[d] + delta*g[d] cross, i.e., delta = (S0[d1] - S0[d2]) / (g[d2] - g[d1]).

- At delta, the subgradient is {g[d] : d in argmax}. 
- If all active g[d] > 0, minimum is to the left.
- If all active g[d] < 0, minimum is to the right.
- Otherwise, delta is optimal.

This is essentially binary search, which takes O(log(1/ε)) iterations, each O(n).

Actually, let me step back and think about the problem differently.

The objective is C(h) = (2/n) * max_d A[d] where A[d] = Σ_i h[i] * (1-h[i+d-(n-1)]].

For the optimal solution, many of the A[d] values will be close to the maximum (they'll be "active"). The optimization is essentially trying to equalize these active values while keeping them as low as possible.

This is similar to a load balancing problem: we want to distribute the "load" (the correlation values) as evenly as possible across the lags, while minimizing the maximum load.

**New approach: Subgradient of the smooth approximation**

Let C_ε(h) = (2/n) * log(Σ_d exp(ε * A[d])) where ε is a small positive number (inverse temperature).

As ε → ∞, C_ε → (2/n) * max A[d] = C(h).
For finite ε, C_ε is a smooth over-approximation of C(h).

The gradient:
∂C_ε/∂h[j] = (2/n) * (1/Σ exp(ε*A[d])) * Σ_d ε * exp(ε*A[d]) * ∂A[d]/∂h[j]
= (2/n) * ε * Σ_d p_d * g_j[d]
where p_d = exp(ε*A[d]) / Σ exp(ε*A[d]) is a probability distribution over d.

So the gradient is a weighted average of the individual gradients g_j[d], where the weights p_d concentrate on the lags with large A[d].

This is like a "soft" version of the subgradient, where instead of using only the argmax lag, we use a mixture of all lags weighted by their exponentiated values.

We can then use this gradient in a projected gradient method:
h ← project([0,1]^n ∩ {sum = n/2}, h - η * ∇C_ε(h))

The step size η can be chosen by line search.

The advantage of this approach:
1. It's smooth, so gradient-based methods work well.
2. It naturally focuses on the active lags (large A[d]).
3. We can anneal ε: start with small ε (more uniform, smoother) and increase it (more focused, closer to the true max).

Let me also add a "pair swap" method that's different from the previous one: instead of swapping two coordinates, we transfer mass from one coordinate to another while preserving the sum. This is a 2D subproblem that can be solved exactly.

Actually, for the pair swap (i, j): we change h[i] by +δ and h[j] by -δ (or vice versa). The change in A is:
ΔA = δ * (g_i - g_j) where g_i and g_j are the gradient vectors for coordinates i and j.

So we need to minimize max(A + δ * (g_i - g_j)) over δ in the feasible range. This is the same 1D problem as before (minimize max of affine functions), which is convex in δ.

The feasible range: δ ∈ [-h[i], 1-h[j]] (for δ > 0, meaning increase h[i] and decrease h[j]).
And δ ∈ [h[j]-1, h[i]] (for δ < 0, meaning decrease h[i] and increase h[j]).
Combined: δ ∈ [min(-h[i], h[j]-1), max(1-h[j], h[i])].
But since -h[i] <= 0 and h[j]-1 <= 0, and 1-h[j] >= 0 and h[i] >= 0:
δ ∈ [-(max(h[i], 1-h[j])), max(1-h[j], h[i])]... 

Actually it's simpler: δ > 0 means h[i] increases by δ (needs h[i]+δ <= 1, so δ <= 1-h[i]) and h[j] decreases by δ (needs h[j]-δ >= 0, so δ <= h[j]). So δ_max = min(1-h[i], h[j]).
δ < 0: h[i] decreases by |δ| (needs δ >= -h[i]) and h[j] increases by |δ| (needs |δ| <= 1-h[j], so δ >= -(1-h[j])). So δ_min = max(-h[i], -(1-h[j])).

So δ ∈ [max(-h[i], h[j]-1), min(1-h[i], h[j])].

This is the same as the coordinate descent but with a combined gradient (g_i - g_j) instead of a single gradient.

For the pair swap, we can compute g_i - g_j in O(n) (two O(n) vector ops), then solve the 1D minimization in O(n log n) or O(n) (using the convex piecewise-linear structure).

The advantage of pair swaps over single-coordinate updates: we can move mass between coordinates without the intermediate projection step, which preserves the sum constraint exactly.
