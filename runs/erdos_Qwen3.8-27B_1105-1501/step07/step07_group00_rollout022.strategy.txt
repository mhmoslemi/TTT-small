1. Approach and rationale

The current parent construction uses exact finite-lag correlation, but the previous search is dominated by trust-region-ish linearized moves, random binary pair evolution, short resampling, and tiny basin hopping. The main bottleneck in that pattern is that each search phase follows the same primal objective very cosely: it repeatedly re-weights active lags and takes small linearized steps. That tends to improve a local KKT point by very small amounts while never exploring broad, smooth, full-dimensional feasible excursions in the continuous problem.

The proposed method is materially different: optimize the actual nonconvex objective as a smooth minimax surface using a constrained gradient method directly in the original continuous variables, with adaptive smoothing that interpolates between averaging all lags and concentrating on active lags. The original objective is never replaced by a model in the final output. Every candidate produced by the smooth optimizer is re-projected to exact feasibility and scored by the exact evaluator `max(np.correlate(h, 1-h, "full") * dx)`.

The method is based on three ideas:

1. Smooth minimax objective:
   Replace the max over lags by a log-sum-exp envelope
   `f_beta(h) = beta * log(sum_j exp(S_j(h) / beta))`,
   where `S_j(h)` is the exact scaled score vector. The smoothing parameter `beta` is a plain positive energy scale, not a relaxation. As `beta` decreases toward a small value, `f_beta(h)` approaches the true maximum. The exact objective is used for every acceptance decision. This allows gradient methods to move over broad regions; later small `beta` values force descent on all currently near-maximal lags.

2. Direct constrained continuous optimization:
   The variables remain `h[i]`, with explicit bounds `[0, 1]` and equality `sum(h) = n / 2`. A gradient feasible constrained optimizer is used; no topological variable transform that breaks the integral constraint is used. The gradient of the smooth objective is the normalized weighted sum of exact analytic gradients of each lag. No matrix is omitted: the gradient uses the same finite-lag formulas implemented with slices so that the derivative matches the discrete non-circular evaluator.

3. Seed diversity through joint feasible operations:
   Instead of a large numerical parent table or many ad hoc shifts, the algorithm generates a pool of diverse valid starts from the parent using low-dimensional perturbations, rotations by interpolation, thresholded binary-like mixtures, averages of pool members, and mirror/phase variants. The search repeatedly applies the smooth/constrained optimizer from these feasible starts and records exact-evaluate得分 candidates. A final active-set LP and exact polynomial line search polish converts approximate smooth maximizers into near-exact maximax approx. Resolution resizing is optional and only accepted by exact objective.

This is not a claim of global optimality. It is a higher quality local/multi-start algorithm whose exploration geometry is significantly different from the prior small-trust-region library. The main hypothesis is that the parent is located in a smooth optimum whose smooth surrogate has not been followed sufficiently along nonlinear paths that couple all lag peaks; log-sum-exp constrained descent can find slightly lower exact maxima. Limitations: smooth objective may overweight submaximal lags at large beta; SLSQP-style optimizers can prematurely converge; all candidates are still case-sensitive to the exact scores. All routines guard against failures and preserve the best valid candidate.
