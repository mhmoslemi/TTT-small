1. Approach and rationale

The parent line-search methods repeatedly apply one-coordinate moves, random pair mass transfers, LP-derived active-set directions, selector binary updates, and resampling. The proposed runner will use a different move family that can transfer mass simultaneously to many coordinates in a way that is still exactly evaluated by the official objective.

The core idea is a **weighted active-constraint gradient-sorted mass-allocation line move**. At a feasible vector h, use the raw correlation vector

```
R = np.correlate(h, 1-h, mode="full")
```

and assign weights to the currently most restrictive raw values. For each weight vector `w`, compute the gradient field

```
g = sum_i w_i grad R_i
```

for the raw discrete evaluator, sort the resistance of individual `h_i` coordinates, and construct a new mass-feasible target vector `v` with `sum(v)=n/2` that concentrates the unit mass at the best gradient-sorted coordinates. Then move along the mass-preserving segment

```
h_alpha = h + alpha*(v-h)
```

As long as `alpha` is within the interval mandated by the bounds `0<=h_i<=1`, this move preserves the mass and box constraints. Along this segment the evaluator is not approximated; the correlation is bilinear in the sampled vectors, so the raw values exactly obey

```
raw(alpha) = raw(0)
             + alpha * (corr(p, 1-h)-corr(h, p))
             - alpha**2 * corr(p, p)
```

with `p=v-h`. Exactly minimizing or finding a strong point of that scalar piecewise-quadratic-like maximum gives a candidate updated solution. It is accepted only by re-verifying the official evaluator. If the move fails, the current solution is kept; the resulting proposal set is searched by sorted gradients, complementary sorted gradients, deterministic noise variations, active-band weighting, perturbations, resolution transfer, and a modest deterministic pair/coordinate polish. No claim of global optimality is made. The returned value is always a feasible discrete vector whose objective is computed from the prescribed evaluator.

The method is materially different from the earlier program because the central move direction is **not** produced by a random pair or a regular LP/projection path but by an active-set weighted linearization followed by selection of a single balanced vertex of the mass-hyperplane and a mathematically exact line segment evaluation. The LP, surface-smooth maximization, coordinate cycle, SA and ordinary random pair bisection are replaced by a primary FW-like proposal generator with exact acceptance.
