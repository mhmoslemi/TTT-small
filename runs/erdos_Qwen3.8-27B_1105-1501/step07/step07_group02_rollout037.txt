Let me analyze the problem carefully:

1. We need to find a step function h: [0,2] → [0,1] that minimizes C₅ = max_k ∫ h(x)(1-h(x+k)) dx
2. With discretization: n_points samples, dx = 2/n_points, sum(h) = n_points/2
3. C₅ = max(np.correlate(h, 1-h, mode="full") * dx)
4. Current record: C₅ ≤ 0.38085, previous achieved 0.380889
5. Target: C₅ ≤ 0.3808

The strategy suggests using a dense gradient-based approach with log-sum-exp smoothed weights over all lags, rather than just pairwise swaps. Let me design an implementation that:

1. Uses the parent `initial_h_values` as starting point
2. Implements a dense descent direction from the smoothed gradient of the max-correlation
3. Uses exact line search along dense directions
4. Includes binary SA and pair optimization as backup
5. Explores different n values

Key insight from the strategy: Instead of only doing pairwise transfers (sparse directions), compute a dense gradient from the log-sum-exp of all correlations, project it to be zero-sum, and do exact line search along that direction. This is a fundamentally different approach from the previous program which only used pair moves.

Let me think about the gradient computation:

For R = np.correlate(h, 1-h, mode="full"), each entry R[r] for r = 0, ..., 2n-2 corresponds to a lag. The lag index is k = r - (n-1), ranging from -(n-1) to (n-1).

For a given lag k:
R[k + n - 1] = sum_{i} h[i] * (1 - h[i + k]) for valid i

where the valid range depends on k.

If k >= 0: valid i are 0 to n-1-k
R = sum_{i=0}^{n-1-k} h[i] * (1 - h[i+k])

If k < 0: let p = -k, valid i are p to n-1
R = sum_{i=p}^{n-1} h[i] * (1 - h[i-p])

The derivative of R[k+n-1] with respect to h[j]:
For k >= 0:
- If j is in [0, n-1-k]: term h[j]*(1-h[j+k]) contributes (1-h[j+k])
- If j is in [k, n-1]: term h[j-k]*(1-h[j]) contributes -h[j-k]
- If both apply (j in [k, n-1-k]): net contribution is (1-h[j+k]) - h[j-k]

For k < 0 (p = -k):
- If j is in [p, n-1]: term h[j]*(1-h[j-p]) contributes (1-h[j-p])
- If j is in [0, n-1-p]: term h[j+p]*(1-h[j]) contributes -h[j+p]

So the gradient of R[r] (where r = k + n - 1) with respect to h[j] can be computed efficiently.

For the log-sum-exp surrogate: S(h) = (1/beta) * log(sum_r exp(beta * R[r]))
dS/dh[j] = sum_r w[r] * dR[r]/dh[j] where w[r] = exp(beta*R[r]) / sum exp(beta*R_r)

Then the descent direction is d = -dS/dh[j], projected to be zero-sum: d = d - mean(d).

For the exact line search along direction d:
h(t) = h + t*d
R(t) = R(0) + t*A - t^2*B

where A[r] = dR[r]/dt = sum_j d[j] * dR[r]/dh[j] evaluated at h
and B[r] = sum_j d[j]^2 * d2R[r]/dh[j]^2 ... wait, no.

Actually, since R is bilinear in h and (1-h):
R(t) = correlate(h + t*d, 1 - h - t*d)
     = correlate(h, 1-h) + t*(correlate(d, 1-h) - correlate(h, d)) - t^2*correlate(d, d)

So A = correlate(d, 1-h) - correlate(h, d) and B = correlate(d, d).

The objective max_r R(t)[r] is the max of quadratics, which is convex in t (each quadratic opens downward since B[r] >= 0, so -t^2*B[r] is concave... wait, R(t)[r] = R0[r] + t*A[r] - t^2*B[r], which is concave in t since B[r] >= 0). The max of concave functions is not necessarily concave, so the max is not convex. But we can still do line search.

Actually wait - max of concave functions is concave? No! Max of concave functions is not necessarily concave. Min of convex is not necessarily convex. Max of convex is convex. Min of concave is concave.

So max of concave quadratics is generally not convex or concave. But each individual R(t)[r] is a concave quadratic (opens downward). We want to find t that minimizes max_r R(t)[r].

We can do this by bisection: for a given value v, check if there exists t such that R(t)[r] <= v for all r. This is equivalent to checking if for all r: t^2*B[r] - t*A[r] + (v - R0[r]) >= 0, i.e., each quadratic in t is non-negative.

Actually, a simpler approach: just do a grid search + golden section on t, evaluating the exact max at each point. Since we have the exact formula R(t) = R0 + t*A - t^2*B, evaluating at any t is O(n) (just compute the max of the array).

Let me now write the code:

import numpy as np
import time

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo, hi = float(v.min()) - 1.0, float(v.max()) + 1.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-10:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x = x.copy()
            x[mask] += res / cnt
    return np.clip(x, 0.0, 1.0)

def _grad_dense(h, beta):
    """Compute dense gradient of log-sum-exp over correlations.
    Returns gradient vector g where dS/dh[j] = g[j]."""
    n = len(h)
    L = 2 * n - 1
    R = np.correlate(h, 1.0 - h, mode='full')
    M = float(np.max(R))
    # weights
    w = np.exp(beta * (R - M))
    ws = float(np.sum(w))
    if ws < 1e-300:
        # fallback: uniform over top
        top = R > M - 1.0 / beta
        w = np.where(top, 1.0, 0.0)
        ws = float(np.sum(w))
        if ws == 0:
            w = np.ones(L) / L
        else:
            w /= ws
    else:
        w /= ws
    
    # For each lag r, compute dR[r]/dh[j]
    # R[r] corresponds to lag k = r - (n-1)
    # Grad will be accumulated as sum_r w[r] * dR[r]/dh[j]
    
    # Efficient computation using convolution-like structure
    # For lag k >= 0: R = sum_{i=0}^{n-1-k} h[i]*(1-h[i+k])
    # dR/dh[j] = (1-h[j+k]) if j < n-k  (j acts as first factor)
    #           - h[j-k] if j >= k       (j acts as second factor)
    #           (both if k <= j < n-k)
    
    # For lag k < 0 (p = -k): R = sum_{i=p}^{n-1} h[i]*(1-h[i-p])
    # dR/dh[j] = (1-h[j-p]) if j >= p    (j acts as first factor)
    #           - h[j+p] if j < n-p      (j acts as second factor)
    
    # Instead of looping over all lags (O(n^2)), let's think about this differently.
    # 
    # Actually for n ~ 180, L = 359, so looping over lags is O(n * L) = O(n^2) ~ 32400.
    # That's fine for each gradient evaluation.
    
    grad = np.zeros(n)
    one_mh = 1.0 - h
    
    for r in range(L):
        if w[r] < 1e-15:
            continue
        k = r - (n - 1)
        if k >= 0:
            m = n - k
            # h[i] for i in [0, m-1], h[i+k] for i in [0, m-1]
            # dR/dh[j]: 
            #   j in [0, m-1]: contributes (1-h[j+k]) = one_mh[j+k]
            #   j in [k, n-1]: contributes -h[j-k]
            if m > 0:
                grad[:m] += w[r] * one_mh[k:k+m]  # j + k ranges from k to k+m-1
                grad[k:] += -w[r] * h[:m]  # j - k ranges from 0 to m-1
        else:
            p = -k
            m = n - p
            # h[i] for i in [p, n-1], h[i-p] for i in [p, n-1]
            # dR/dh[j]:
            #   j in [p, n-1]: contributes (1-h[j-p]) = one_mh[j-p]
            #   j in [0, m-1]: contributes -h[j+p]
            if m > 0:
                grad[p:] += w[r] * one_mh[:m]  # j - p ranges from 0 to m-1
                grad[:m] += -w[r] * h[p:p+m]  # j + p ranges from p to p+m-1
    
    return grad, R, M

def _dense_line_search(R0, A, B, t_lo, t_hi):
    """Find t in [t_lo, t_hi] minimizing max_r(R0[r] + t*A[r] - t^2*B[r])."""
    def obj(t):
        return float(np.max(R0 + t * A - t * t * B))
    
    # Grid + golden section
    n_grid = 60
    ts = np.linspace(t_lo, t_hi, n_grid)
    vals = np.array([obj(t) for t in ts])
    best_idx = int(np.argmin(vals))
    lo = ts[max(0, best_idx - 1)]
    hi = ts[min(n_grid - 1, best_idx + 1)]
    
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    c1 = hi - gr * (hi - lo)
    c2 = lo + gr * (hi - lo)
    f1 = obj(c1)
    f2 = obj(c2)
    for _ in range(30):
        if hi - lo < 1e-13:
            break
        if f1 < f2:
            hi, c2, f2 = c2, c1, f1
            c1 = hi - gr * (hi - lo)
            f1 = obj(c1)
        else:
            lo, c1, f1 = c1, c2, f2
            c2 = lo + gr * (hi - lo)
            f2 = obj(c2)
    
    opt_t = (lo + hi) / 2.0
    best_t = opt_t
    best_v = obj(opt_t)
    for t_check in [t_lo, t_hi, ts[best_idx], c1, c2]:
        v = obj(t_check)
        if v < best_v:
            best_v = v
            best_t = t_check
    return best_t, best_v

def _dense_descent(h, deadline, beta_start=5.0, beta_end=40.0, max_iter=200, radius=0.1, seed=42):
    """Dense gradient descent with exact line search."""
    n = len(h)
    target = n / 2.0
    h = _project(h.copy(), target)
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    rng = np.random.default_rng(seed)
    stall = 0
    
    for it in range(max_iter):
        if time.time() > deadline:
            break
        if stall > 30:
            break
        
        beta = beta_start + (beta_end - beta_start) * (it / max(max_iter - 1, 1))
        grad, R, M = _grad_dense(h, beta)
        
        # Project to zero-sum (descent direction)
        d = -grad
        d = d - np.mean(d)
        
        # Scale direction
        norm = np.max(np.abs(d))
        if norm < 1e-15:
            stall += 1
            continue
        d = d / norm
        
        # Feasible interval
        pos_mask = d > 0
        neg_mask = d < 0
        t_lo = 0.0
        t_hi = radius
        if np.any(pos_mask):
            t_hi = min(t_hi, (1.0 - h[pos_mask]).min() / d[pos_mask].max())
        if np.any(neg_mask):
            t_lo = max(0.0, -h[neg_mask].min() / (-d[neg_mask].max()))
        
        # Also allow negative t (reverse direction) for robustness
        t_lo_neg = -radius
        if np.any(pos_mask):
            t_lo_neg = max(t_lo_neg, -h[pos_mask].min() / d[pos_mask].max())  # h + t*d >= 0 for pos
        # Actually let me just search in [-radius, radius] but ensure feasibility
        # Better: compute exact feasible range
        t_min = 0.0
        t_max = 0.0
        for j in range(n):
            if d[j] > 1e-15:
                t_max = min(t_max, (1.0 - h[j]) / d[j]) if t_max > 0 else (1.0 - h[j]) / d[j]
                t_min = max(t_min, -h[j] / d[j])
            elif d[j] < -1e-15:
                t_min = max(t_min, -h[j] / d[j])  # wait this is wrong
                # h[j] + t*d[j] >= 0 => t <= -h[j]/d[j] (since d[j] < 0, -h[j]/d[j] = h[j]/|d[j]|)
                # h[j] + t*d[j] <= 1 => t >= (1-h[j])/d[j] (which is negative since d[j]<0)
                t_max = min(t_max if t_max != 0 else (1.0 - h[j]) / d[j], -h[j] / d[j])
                t_min = max(t_min, (1.0 - h[j]) / d[j])
        
        # Simpler approach: 
        t_lo = -radius
        t_hi = radius
        if np.any(d > 0):
            t_hi = min(t_hi, ((1.0 - h) / d)[d > 0].min() if False else 1e10)
            # (1-h[j])/d[j] for d[j]>0
            tp = (1.0 - h[d > 0]) / d[d > 0]
            t_hi = min(t_hi, float(tp.min()))
            tm = h[d > 0] / d[d > 0]
            t_lo = max(t_lo, -float(tm.min()))
        if np.any(d < 0):
            tp = (1.0 - h[d < 0]) / d[d < 0]  # these are negative
            t_lo = max(t_lo, float(tp.max()))
            tm = h[d < 0] / d[d < 0]  # these are negative  
            t_hi = min(t_hi, -float(tm.max()))
        
        if t_hi - t_lo < 1e-10:
            stall += 1
            continue
        
        # Compute A and B
        A = np.correlate(d, 1.0 - h, mode='full') - np.correlate(h, d, mode='full')
        B = np.correlate(d, d, mode='full')
        
        t_opt, val_opt = _dense_line_search(R, A, B, t_lo, t_hi)
        
        h_try = h + t_opt * d
        # Project to maintain exact constraint
        h_try = _project(h_try, target)
        c5_try = _exact_c5(h_try)
        
        if c5_try < best_c5 - 1e-12:
            best_c5 = c5_try
            best_h = h_try.copy()
        if c5_try < cur_c5 - 1e-12:
            h = h_try
            cur_c5 = c5_try
            stall = 0
        else:
            stall += 1
            # Try smaller step
            for frac in [0.5, 0.25, 0.1]:
                t_sm = t_opt * frac
                if t_sm < t_lo or t_sm > t_hi:
                    continue
                h_sm = h + t_sm * d
                h_sm = _project(h_sm, target)
                c5_sm = _exact_c5(h_sm)
                if c5_sm < cur_c5 - 1e-12:
                    h = h_sm
                    cur_c5 = c5_sm
                    stall = 0
                    if c5_sm < best_c5 - 1e-12:
                        best_c5 = c5_sm
                        best_h = h_sm.copy()
                    break
    
    return best_h, best_c5

def _resample(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return _project(h_new, n_new / 2.0)

def _to_binary(h, n):
    idx = np.argsort(h)[-n // 2:]
    h_bin = np.zeros(n)
    h_bin[idx] = 1.0
    return h_bin

def _pair_optimize(h, deadline, radius=0.15, n_pairs=50, beta=20.0, stall_limit=100, seed=42):
    """Original pair-based optimization as fallback."""
    n = len(h)
    target = n / 2.0
    h = _project(h.copy(), target)
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    S0 = np.correlate(h, 1.0 - h, mode='full')
    radius = float(radius)
    stall = 0
    rng = np.random.default_rng(seed)
    
    while time.time() < deadline:
        if stall > stall_limit or radius < 1e-6:
            break
        w = np.exp(beta * (S0 - np.max(S0)))
        ws = float(np.sum(w))
        if ws < 1e-30:
            w = np.ones(2*n-1) / (2*n-1)
        else:
            w /= ws
        # Compute weighted gradient for pair selection
        G = np.zeros(n)
        one_mh = 1.0 - h
        for r in range(2*n-1):
            if w[r] < 1e-15:
                continue
            k = r - (n-1)
            if k >= 0:
                m = n - k
                if m > 0:
                    G[:m] += w[r] * one_mh[k:k+m]
                    G[k:] += -w[r] * h[:m]
            else:
                p = -k
                m = n - p
                if m > 0:
                    G[p:] += w[r] * one_mh[:m]
                    G[:m] += -w[r] * h[p:p+m]
        
        # Select pairs: move from high G to low G
        sort_idx = np.argsort(G)
        n_half = min(n_pairs, n // 2)
        sources = sort_idx[-n_half:]
        sinks = sort_idx[:n_half]
        
        best_step = None
        best_c5_try = cur_c5
        for ii in range(len(sinks)):
            if time.time() > deadline:
                break
            sink = int(sinks[ii])
            source = int(sources[ii])
            if sink == source:
                continue
            t_lo = max(-h[sink], h[source] - 1.0, -radius)
            t_hi = min(1.0 - h[sink], h[source], radius)
            if t_hi - t_lo < 1e-13:
                continue
            d = np.zeros(n)
            d[sink] = 1.0
            d[source] = -1.0
            A = np.correlate(d, one_mh, mode='full') - np.correlate(h, d, mode='full')
            B = np.correlate(d, d, mode='full')
            t_opt, val_opt = _dense_line_search(S0, A, B, t_lo, t_hi)
            h_try = h.copy()
            h_try[sink] += t_opt
            h_try[source] -= t_opt
            c5_try = _exact_c5(h_try)
            if c5_try < best_c5_try - 1e-14:
                best_c5_try = c5_try
                best_step = h_try
        
        if best_step is not None:
            h = _project(best_step, target)
            cur_c5 = _exact_c5(h)
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            S0 = np.correlate(h, 1.0 - h, mode='full')
            stall = 0
            radius = min(radius * 1.02, 0.28)
        else:
            stall += 1
            radius *= 0.78
            if stall % 40 == 0 and radius < 0.02:
                radius = 0.10
    return best_h, best_c5

def _binary_sa(h_bin, deadline, max_iter=20000, T_init=0.003, seed=999):
    n = len(h_bin)
    cur = h_bin.copy()
    cur_c5 = _exact_c5(cur)
    best_h = cur.copy()
    best_c5 = cur_c5
    rng = np.random.default_rng(seed)
    T = T_init
    stall = 0
    for _ in range(max_iter):
        if time.time() > deadline:
            break
        if stall > 200:
            break
        i = int(rng.integers(0, n))
        j = int(rng.integers(0, n))
        if i == j or cur[i] == cur[j]:
            stall += 1
            continue
        h_new = cur.copy()
        h_new[i], h_new[j] = h_new[j], h_new[i]
        new_c5 = _exact_c5(h_new)
        delta = new_c5 - cur_c5
        if delta < 0 or rng.random() < np.exp(-delta / max(T, 1e-12)):
            cur = h_new
            cur_c5 = new_c5
            if cur_c5 < best_c5 - 1e-14:
                best_c5 = cur_c5
                best_h = cur.copy()
                stall = 0
            T *= 0.9997
        else:
            stall += 1
    return best_h, best_c5

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    deadline = t0 + budget_s
    
    h0 = np.array(initial_h_values, dtype=float)

    best_h = h_init.copy()
    best_c5 = _exact_c5(h_init)
    
    # Phase 1: Dense gradient descent at parent n (30% time)
    d1 = t0 + budget_s * 0.30
    h1, c5_1 = _dense_descent(h_init, d1, beta_start=3.0, beta_end=30.0, max_iter=300, radius=0.12, seed=1)
    if c5_1 < best_c5:
        best_c5 = c5_1

    # Phase 2: Pair optimization refinement (20% time)

    if c5_2 < best_c5:
        best_c5 = c5_2
        best_h = h2.copy()

            h_pol, c5_pol = _dense_descent(h_pol, sub_dl2, beta_start=10.0, beta_end=50.0, max_iter=100, radius=0.08, seed=333)

    n_curr = len(best_h)
    h5 = _project(best_h.copy(), n_curr / 2.0)

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo, hi = float(v.min()) - 1.0, float(v.max()) + 1.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-10:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x = x.copy()
            x[mask] += res / cnt
    return np.clip(x, 0.0, 1.0)

def _grad_scaled(h, beta):
    """Return scaled gradient of log-sum-exp, correlation vector, and max."""
    n = len(h)
    L = 2 * n - 1
    R = np.correlate(h, 1.0 - h, mode='full')
    M = float(np.max(R))
    shifted = R - M
    w = np.exp(beta * shifted)
    ws = float(np.sum(w))
    if ws < 1e-300:
        top_mask = shifted > -1.0 / max(beta, 1.0)
        w = top_mask.astype(float)
        ws = float(np.sum(w))
        if ws == 0:
            return np.zeros(n), R, M
        w /= ws
    else:
        w /= ws
    
    grad = np.zeros(n)
    one_mh = 1.0 - h
    for r in range(L):

def _line_search(R0, A, B, t_lo, t_hi):
    """Minimize max_r(R0[r] + t*A[r] - t^2*B[r]) over t in [t_lo, t_hi]."""
    if t_hi - t_lo < 1e-14:
        return t_lo, float(np.max(R0))
    
    def obj(t):
        return float(np.max(R0 + t * A - t * t * B))

    bi = int(np.argmin(vals))
    lo = ts[max(0, bi - 1)]
    hi = ts[min(n_grid - 1, bi + 1)]
    
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    c1 = hi - gr * (hi - lo)
    c2 = lo + gr * (hi - lo)
    f1 = obj(c1)
    f2 = obj(c2)

            c2 = lo + gr * (hi - lo)
            f2 = obj(c2)

        vc = obj(tc)
        if vc < best_v:

            best_t = tc

import numpy as np
import time

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo, hi = float(v.min()) - 1.0, float(v.max()) + 1.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-10:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x = x.copy()
            x[mask] += res / cnt
    return np.clip(x, 0.0, 1.0)

def _grad_scaled(h, beta):
    n = len(h)
    L = 2 * n - 1
    R = np.correlate(h, 1.0 - h, mode='full')
    M = float(np.max(R))
    shifted = R - M
    w = np.exp(beta * shifted)
    ws = float(np.sum(w))
    if ws < 1e-300:
        top_mask = shifted > -2.0 / max(beta, 1.0)
        w = top_mask.astype(float)
        ws = float(np.sum(w))
        if ws == 0:
            return np.zeros(n), R, M
        w /= ws
    else:
        w /= ws
    grad = np.zeros(n)
    one_mh = 1.0 - h
    for r in range(L):
        wr = w[r]
        if wr < 1e-15:
            continue
        k = r - (n - 1)
        if k >= 0:
            m = n - k
            if m > 0:
                grad[:m] += wr * one_mh[k:k + m]
                grad[k:] -= wr * h[:m]
        else:
            p = -k
            m = n - p
            if m > 0:
                grad[p:] += wr * one_mh[:m]
                grad[:m] -= wr * h[p:p + m]
    return grad, R, M

def _line_search(R0, A, B, t_lo, t_hi):
    if t_hi - t_lo < 1e-14:
        return t_lo, float(np.max(R0))

    def obj(t):
        return float(np.max(R0 + t * A - t * t * B))

    n_grid = 50
    ts = np.linspace(t_lo, t_hi, n_grid)
    vals = np.array([obj(t) for t in ts])
    bi = int(np.argmin(vals))
    lo = ts[max(0, bi - 1)]
    hi = ts[min(n_grid - 1, bi + 1)]
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    c1 = hi - gr * (hi - lo)
    c2 = lo + gr * (hi - lo)
    f1 = obj(c1)
    f2 = obj(c2)
    for _ in range(25):
        if hi - lo < 1e-13:
            break
        if f1 < f2:
            hi, c2, f2 = c2, c1, f1
            c1 = hi - gr * (hi - lo)
            f1 = obj(c1)
        else:
            lo, c1, f1 = c1, c2, f2
            c2 = lo + gr * (hi - lo)
            f2 = obj(c2)
    best_t = (lo + hi) / 2.0
    best_v = obj(best_t)
    for tc in [t_lo, t_hi, ts[bi], c1, c2]:
        vc = obj(tc)
        if vc < best_v:
            best_v = vc
            best_t = tc
    return best_t, best_v

def _feasible_interval(h, d, radius):
    t_lo = -radius
    t_hi = radius
    pos = d > 1e-15
    neg = d < -1e-15
    if np.any(pos):
        t_hi = min(t_hi, float(((1.0 - h[pos]) / d[pos]).min()))
        t_lo = max(t_lo, float((-h[pos] / d[pos]).min()))
    if np.any(neg):
        t_hi = min(t_hi, float((-h[neg] / d[neg]).min()))
        t_lo = max(t_lo, float(((1.0 - h[neg]) / d[neg]).max()))
    if t_lo > t_hi:
        t_lo = t_hi = (t_lo + t_hi) / 2.0
    return t_lo, t_hi

def _dense_descent(h, deadline, beta_start=5.0, beta_end=40.0, max_iter=200, radius=0.1, seed=42):
    n = len(h)
    target = n / 2.0
    h = _project(h.copy(), target)
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    rng = np.random.default_rng(seed)
    stall = 0

    for it in range(max_iter):
        if time.time() > deadline:
            break
        if stall > 30:
            break
        frac = it / max(max_iter - 1, 1)
        beta = beta_start + (beta_end - beta_start) * frac
        grad, R, M = _grad_scaled(h, beta)
        d = -(grad - np.mean(grad))
        if it % 12 == 6:
            rv = rng.standard_normal(n)
            d += 0.15 * (rv - np.mean(rv))
            d -= np.mean(d)
        norm = np.max(np.abs(d))
        if norm < 1e-12:
            stall += 1
            continue
        d /= norm
        t_lo, t_hi = _feasible_interval(h, d, radius)
        if t_hi - t_lo < 1e-10:
            d = -d
            t_lo, t_hi = _feasible_interval(h, d, radius)
            if t_hi - t_lo < 1e-10:
                stall += 1
                continue
        A = np.correlate(d, 1.0 - h, mode='full') - np.correlate(h, d, mode='full')
        B = np.correlate(d, d, mode='full')
        t_opt, _ = _line_search(R, A, B, t_lo, t_hi)
        best_t = t_opt
        h_try = _project(h + t_opt * d, target)
        c5_try = _exact_c5(h_try)
        best_val = c5_try
        for f in [0.6, 0.3, 0.15]:
            t_f = t_opt * f
            if t_f < t_lo or t_f > t_hi:
                continue
            h_f = _project(h + t_f * d, target)
            c5_f = _exact_c5(h_f)
            if c5_f < best_val:
                best_val = c5_f
                best_t = t_f
        h_new = _project(h + best_t * d, target)
        c5_new = _exact_c5(h_new)
        if c5_new < cur_c5 - 1e-13:
            h = h_new
            cur_c5 = c5_new
            stall = 0
        else:
            stall += 1
            radius = max(radius * 0.92, 0.03)
        if cur_c5 < best_c5 - 1e-13:
            best_c5 = cur_c5
            best_h = h.copy()
        elif c5_new < best_c5 - 1e-13:
            best_c5 = c5_new
            best_h = h_new.copy()
    return best_h, best_c5

def _resample(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return _project(h_new, n_new / 2.0)

def _to_binary(h, n):
    idx = np.argsort(h)[-n // 2:]
    h_bin = np.zeros(n)
    h_bin[idx] = 1.0
    return h_bin

def _pair_optimize(h, deadline, radius=0.15, n_pairs=50, beta=20.0, stall_limit=100, seed=42):
    n = len(h)
    target = n / 2.0
    h = _project(h.copy(), target)
    cur_c5 = _exact_c5(h)
    best_h = h.copy()

    S0 = np.correlate(h, 1.0 - h, mode='full')

        if stall > stall_limit or radius < 1e-6:

        if ws < 1e-30:

        else:
            w /= ws
        G = np.zeros(n)
        one_mh = 1.0 - h

            if w[r] < 1e-15:

                m = n - k
                if m > 0:
                    G[:m] += w[r] * one_mh[k:k + m]
                    G[k:] -= w[r] * h[:m]
            else:
                p = -k
                m = n - p
                if m > 0:
                    G[p:] += w[r] * one_mh[:m]
                    G[:m] -= w[r] * h[p:p + m]
        sort_idx = np.argsort(G)
        nh = min(n_pairs, n // 2)
        sources = sort_idx[-nh:]
        sinks = sort_idx[:nh]
        n_rand = min(15, nh // 3)
        all_sinks = list(sinks)
        all_sources = list(sources)
        for _ in range(n_rand):
            a = int(rng.integers(0, n))
            b = int(rng.integers(0, n))
            if a != b:
                all_sinks.append(a)
                all_sources.append(b)
        best_step = None
        best_c5_try = cur_c5
        for ii in range(len(all_sinks)):
            if time.time() > deadline:
                break
            sink = all_sinks[ii]
            source = all_sources[ii]
            if sink == source:
                continue
            t_lo = max(-h[sink], h[source] - 1.0, -radius)
            t_hi = min(1.0 - h[sink], h[source], radius)
            if t_hi - t_lo < 1e-13:

            d = np.zeros(n)
            d[sink] = 1.0
            d[source] = -1.0
            A = np.correlate(d, one_mh, mode='full') - np.correlate(h, d, mode='full')

            t_opt, _ = _line_search(S0, A, B, t_lo, t_hi)

                best_step = h_try
        if best_step is not None:

            if cur_c5 < best_c5:

                best_h = h.copy()

def _binary_sa(h_bin, deadline, max_iter=20000, T_init=0.003, seed=999):

                best_h = cur.copy()
