The objective C5(h) = max_k f_k(h) where f_k(h) = score_k(h) is a piecewise-linear function (it's actually piecewise quadratic since each f_k is quadratic). At any non-degenerate point, only one (or a few) constraints are active.

The full-constraint LP approach:
1. Compute all scores
2. Build the gradient matrix G (2n-1 rows, n columns)
3. Solve: min τ subject to G @ d - τ ≤ -scores, sum(d) = 0, bounds on d
4. Get direction d, do line search
