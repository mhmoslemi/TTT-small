def _lp_direction(h, scores, G, radius, active_margin=0.0):
    """Find LP direction using full or active-set constraints."""
    n = len(h)
    n_rows = 2 * n - 1
    
    # Select active rows
    if active_margin > 0:
        max_score = float(np.max(scores))
        active = np.where(scores >= max_score - active_margin)[0]
    else:
        active = np.arange(n_rows)
    
    if len(active) == 0:
        return None
    
    # Build LP
    # Variables: p[0..n-1], eta
    # Minimize eta
    # s.t. G[active] @ p - eta <= -scores[active]
    #      sum(p) = 0
    #      -min(radius, h[j]) <= p[j] <= min(radius, 1-h[j])
    #      eta >= 0 (handled by the constraints)
    
    c = np.zeros(n + 1)
    c[-1] = 1.0
    
    A_ub = np.zeros((len(active), n + 1))
    A_ub[:, :n] = G[active]
    A_ub[:, n] = -1.0
    b_ub = -scores[active]
    
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.zeros(1)
    
    bounds = []
    for j in range(n):
        lo = max(-radius, -h[j])
        hi = min(radius, 1.0 - h[j])
        bounds.append((lo, hi))
    bounds.append((0.0, None))  # eta >= 0
    
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs')
        if res.success:
            return res.x[:n]
    except Exception:
        pass
    return None

This looks cleaner. Let me now think about the binary optimization.

For binary sequences, the score at lag d is:
R_d = Σ_{i=0}^{n-d-1} h_i * (1 - h_{i+d})

For binary h, this counts the number of (i, i+d) pairs where h_i=1 and h_{i+d}=0.

After swapping positions i and j (h_i: 1→0, h_j: 0→1):
The change in R_d is:
- For each lag d, the pairs involving i or j change.

Specifically, the pairs that change are:
- (i, i+d) and (i-d, i) for position i (changed from 1 to 0)
- (j, j+d) and (j-d, j) for position j (changed from 0 to 1)

So ΔR_d = [new contribution from i and j] - [old contribution from i and j]

For position i (h_i: 1→0):
- Old: h_i * (1-h_{i+d}) + (1-h_{i-d}) * h_i = (1-h_{i+d}) + (1-h_{i-d}) (for valid indices)
- New: 0 * (1-h_{i+d}) + (1-h_{i-d}) * 0 = 0
- Change at i: -(1-h_{i+d}) - (1-h_{i-d}) (for valid)
