Let me also think about the line search. After getting direction d from LP:
- x(α) = h + α*d
- The objective along this line is max_l (F_l + α*∇F_l·d - α²*Q_l(α)) wait no...

Actually the objective is NOT quadratic in a simple way. Let me recompute:

F_l(h + αd) = ∑_i (h_{i+l} + αd_{i+l})(1 - h_i - αd_i)
            = ∑_i [h_{i+l}(1-h_i) + α d_{i+l}(1-h_i) - α h_{i+l} d_i - α² d_{i+l} d_i]
            = F_l(h) + α ∑_i [d_{i+l}(1-h_i) - h_{i+l} d_i] - α² ∑_i d_{i+l} d_i

So yes, it IS quadratic in α for each lag! And the objective is max of quadratics, which is piecewise convex in α.

So: F_l(α) = F_l(0) + α * G_l - α² * Q_l

where G_l = ∇F_l·d and Q_l = (d shifted)·d (the "self-correlation" of d at lag l).

The line search minimizes max_l (F_l(0) + α*G_l - α²*Q_l) over α ∈ [0, α_max].

This can be done with a grid + golden section, as in the previous code. The previous code already does this correctly with the expansion:
C_0 + α*L_1 - α²*Q_2

where C_0 = corr(h, 1-h), L_1 = corr(d, 1-h) - corr(h, d), Q_2 = corr(d, d).

import numpy as np
from scipy.optimize import linprog
import time

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo, hi = float(v.min()) - 2.0, float(v.max()) + 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-13:
        mask = (x < 1.0) if res > 0 else (x > 0.0)
        cnt = int(np.sum(mask))
        if cnt > 0:
            x = x.copy()
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _corr_expansion(h, d):
    """Precompute C0, L1, Q2 for line search.
    F_l(alpha) = C0_l + alpha*L1_l - alpha^2*Q2_l
    """
    C0 = np.correlate(h, 1.0 - h, mode='full')
    L1 = np.correlate(d, 1.0 - h, mode='full') - np.correlate(h, d, mode='full')
    Q2 = np.correlate(d, d, mode='full')
    return C0, L1, Q2

def _line_search(h, d, dx, radius, n_grid=40):
    """Exact line search along direction d. Returns (best_alpha, best_c5)."""
    n = len(h)
    C0, L1, Q2 = _corr_expansion(h, d)
    
    # Compute max feasible alpha
    t_hi = radius
    pos = d > 1e-15
    neg = d < -1e-15
    if np.any(pos):
        t_hi = min(t_hi, float(np.min((1.0 - h[pos]) / d[pos])))
    if np.any(neg):
        t_hi = min(t_hi, float(np.min(h[neg] / (-d[neg]))))
    if t_hi < 1e-14:
        return 0.0, float(np.max(C0) * dx)
    
    # Grid search
    grid_t = np.linspace(0.0, t_hi, n_grid)
    grid_f = np.empty(n_grid)
    for idx in range(n_grid):
        t = grid_t[idx]
        grid_f[idx] = float(np.max(C0 + t * L1 - t * t * Q2)) * dx
    best_idx = int(np.argmin(grid_f))
    lo_b = grid_t[max(0, best_idx - 2)]
    hi_b = grid_t[min(n_grid - 1, best_idx + 2)]
    
    # Golden section refinement
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    if hi_b - lo_b < 1e-10:
        opt_t = grid_t[best_idx]
        opt_val = float(grid_f[best_idx])
    else:
        c1 = hi_b - gr * (hi_b - lo_b)
        c2 = lo_b + gr * (hi_b - lo_b)
        f1 = float(np.max(C0 + c1 * L1 - c1 * c1 * Q2)) * dx
        f2 = float(np.max(C0 + c2 * L1 - c2 * c2 * Q2)) * dx
        for _ in range(40):
            if hi_b - lo_b < 1e-12:
                break
            if f1 < f2:
                hi_b, c2, f2 = c2, c1, f1
                c1 = hi_b - gr * (hi_b - lo_b)
                f1 = float(np.max(C0 + c1 * L1 - c1 * c1 * Q2)) * dx
            else:
                lo_b, c1, f1 = c1, c2, f2
                c2 = lo_b + gr * (hi_b - lo_b)
                f2 = float(np.max(C0 + c2 * L1 - c2 * c2 * Q2)) * dx
        opt_t = (lo_b + hi_b) / 2.0
        opt_val = float(np.max(C0 + opt_t * L1 - opt_t * opt_t * Q2)) * dx
    
    # Also check endpoints
    f0 = float(np.max(C0) * dx)
    fhi = float(np.max(C0 + t_hi * L1 - t_hi * t_hi * Q2)) * dx
    
    candidates = [(opt_t, opt_val), (0.0, f0), (t_hi, fhi)]
    best_c = min(candidates, key=lambda x: x[1])
    return best_c[0], best_c[1]

def _lp_minimax_direction(h, radius, max_active=80, tol_frac=0.15):
    """Solve LP minimax subproblem to get descent direction.
    
    minimize t
    subject to: grad_l(F) . d - t <= -F_l  for all active l
                 sum(d) = 0
                 bounds on d_i
    
    Returns direction d or None if LP fails.
    """
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    F = corr * dx  # scaled correlation values
    max_F = float(F.max())
    
    # Select active constraints: those within tol_frac of max, plus some margin
    threshold = max_F - max(tol_frac * max_F, 0.02)
    active_idx = np.where(F >= threshold)[0]
    
    # Also always include the top max_active by value
    top_idx = np.argsort(-F)[:max_active]
    active_idx = np.unique(np.concatenate([active_idx, top_idx]))
    
    m = len(active_idx)
    if m == 0:
        return None
    
    # Build constraint matrix A (m x (n+1)) and b
    # For each active lag r, compute gradient of F_r w.r.t. h
    # A[r, :n] = grad(F_r), A[r, n] = -1
    # b[r] = -F[r]
    
    A = np.zeros((m, n + 1))
    b = np.empty(m)
    
    center = n - 1
    for ii, r in enumerate(active_idx):
        k = int(r) - center
        b[ii] = -float(F[int(r)])
        A[ii, n] = -1.0
        
        if k > 0:
            # F = sum_{i=0}^{n-k-1} h_{i+k}(1-h_i)
            # grad: for j in [0, k-1]: -h_{j+k}
            #       for j in [k, n-k-1]: (1-h_{j-k}) - h_{j+k}
            #       for j in [n-k, n-1]: (1-h_{j-k})
            A[ii, 0:n-k] -= h[k:n]  # -h_{j+k} for j in [0, n-k-1]
            A[ii, k:n] += (1.0 - h[0:n-k])  # +(1-h_{j-k}) for j in [k, n-1]
        elif k < 0:
            u = -k
            # F = sum_{i=0}^{n-u-1} h_i(1-h_{i+u})
            # grad: for j in [0, u-1]: (1-h_{j+u})
            #       for j in [u, n-u-1]: (1-h_{j+u}) - h_{j-u}
            #       for j in [n-u, n-1]: -h_{j-u}
            A[ii, 0:n-u] += (1.0 - h[u:n])  # +(1-h_{j+u}) for j in [0, n-u-1]
            A[ii, u:n] -= h[0:n-u]  # -h_{j-u} for j in [u, n-1]
        else:
            # F = sum h_i(1-h_i), grad = 1 - 2h_i
            A[ii, :] = 0  # will set below
            A[ii, :n] = 1.0 - 2.0 * h
        A[ii, :n] *= dx
    
    # Bounds on d_i: max(-r, -h_i) <= d_i <= min(r, 1-h_i)
    lb = np.maximum(-radius, -h)
    ub = np.minimum(radius, 1.0 - h)
    
    # t bound: [0, max_F + 0.05]
    bounds = list(zip(lb, ub))
    bounds.append((0.0, max_F + 0.05))
    
    # Objective: minimize t
    c_obj = np.zeros(n + 1)
    c_obj[n] = 1.0
    
    # Equality: sum(d) = 0
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = [0.0]
    
    result = linprog(c_obj, A_ub=A, b_ub=b, A_eq=A_eq, b_eq=b_eq,
                     bounds=bounds, method='highs')
    
    if result is not None and result.success and result.x is not None:
        d = result.x[:n]
        if np.max(np.abs(d)) > 1e-10:
            return d
    return None

def _subgradient_direction(h, corr, active_count=10):
    """Fallback: average gradient of top active constraints."""
    n = len(h)
    dx = 2.0 / n
    F = corr * dx
    max_F = float(F.max())
    top_idx = np.argsort(-F)[:active_count]
    
    g = np.zeros(n)
    center = n - 1
    for r in top_idx:
        k = int(r) - center
        if k > 0:
            g[0:n-k] -= h[k:n]
            g[k:n] += (1.0 - h[0:n-k])
        elif k < 0:
            u = -k
            g[0:n-u] += (1.0 - h[u:n])
            g[u:n] -= h[0:n-u]
        else:
            g[:] = 1.0 - 2.0 * h
        g *= dx
    
    g /= len(top_idx)
    d = -g
    d = d - np.mean(d)
    return d

def _lp_descent_loop(h, deadline, radius_init=0.10, max_iter=5000, use_lp=True):
    """Main LP-based descent loop."""
    n = len(h)
    target = n / 2.0
    dx = 2.0 / n
    h = h.copy()
    cur = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur
    radius = radius_init
    stall = 0
    lp_fail_count = 0
    
    for _ in range(max_iter):
        if time.time() > deadline:
            break
        if stall > 100:
            break
        if radius < 1e-5:
            break
            
        corr = np.correlate(h, 1.0 - h, mode='full')
        
        # Try LP direction
        d = None
        if use_lp:
            d = _lp_minimax_direction(h, radius, max_active=80, tol_frac=0.15)
            if d is None:
                lp_fail_count += 1
                radius *= 0.7
                if lp_fail_count > 5:
                    use_lp = False
                    lp_fail_count = 0
        
        # Fallback to subgradient
        if d is None:
            d = _subgradient_direction(h, corr, active_count=10)
            d = np.clip(d, -radius, radius)
            d = d - np.mean(d)
        
        if np.max(np.abs(d)) < 1e-12:
            stall += 1
            radius *= 0.7
            continue
        
        alpha, new_c5 = _line_search(h, d, dx, radius)
        
        if new_c5 < cur - 1e-13:
            h = h + alpha * d
            h = _project(h, target)
            cur = _exact_c5(h)
            if cur < best_c5:
                best_c5 = cur
                best_h = h.copy()
            stall = 0
            lp_fail_count = 0
            radius = min(radius * 1.03, 0.25)
        else:
            stall += 1
            radius *= 0.72
    
    return best_h, best_c5

def _to_binary(h, n):
    idx = np.argsort(h)[-n // 2:]
    h_bin = np.zeros(n)
    h_bin[idx] = 1.0
    return h_bin

def _binary_pair_search(h_bin, deadline, max_iters=50000, seed=42):
    """Binary local search: swap a 1 with a 0."""
    n = len(h_bin)
    dx = 2.0 / n
    cur = h_bin.copy()
    cur_c5, cur_corr = _exact_c5(cur), np.correlate(cur, 1.0-cur, mode='full')
    best_h = cur.copy()
    best_c5 = cur_c5
    rng = np.random.default_rng(seed)
    ones = list(np.where(cur > 0.5)[0])
    zeros = list(np.where(cur <= 0.5)[0])
    stall = 0
    best_stall = 0
    
    for it in range(max_iters):
        if time.time() > deadline:
            break
        if best_stall > 5000:
            break
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        # Targeted: focus on positions that affect max correlations
        max_idx = int(np.argmax(cur_corr))
        k = max_idx - (n - 1)
        
        # Try swaps near the active correlation
        n_tries = min(50, len(ones) * len(zeros))
        best_delta = 0.0
        best_move = None
        
        for _ in range(n_tries):
            # Weight toward positions in the active correlation
            if abs(k) > 0:
                # Positions j in [0, n-|k|-1] contribute to this lag
                if k > 0:
                    j1_pool = zeros[:max(1, min(len(zeros), n-k))]
                    j2_pool = ones[k:k+max(1, min(len(ones), n-k))] if k < len(ones) else ones[:1]
                else:
                    j1_pool = zeros[-max(1, min(len(zeros), n+k)):] if n+k > 0 else zeros[:1]
                    j2_pool = ones[:max(1, min(len(ones), n+k))]
                
                if len(j1_pool) > 0 and len(j2_pool) > 0:
                    oz = int(j1_pool[int(rng.integers(0, len(j1_pool)))])
                    oi = int(j2_pool[int(rng.integers(0, len(j2_pool)))])
                else:
                    oz = int(zeros[int(rng.integers(0, len(zeros)))])
                    oi = int(ones[int(rng.integers(0, len(ones)))])
            else:
                oz = int(zeros[int(rng.integers(0, len(zeros)))])
                oi = int(ones[int(rng.integers(0, len(ones)))])
            
            cur[oi] = 0.0
            cur[oz] = 1.0
            new_c5 = _exact_c5(cur)
            cur[oi] = 1.0
            cur[oz] = 0.0
            
            delta = new_c5 - cur_c5
            if delta < best_delta:
                best_delta = delta
                best_move = (oi, oz)
        
        if best_move is not None and best_delta < -1e-14:
            oi, oz = best_move
            cur[oi] = 0.0
            cur[oz] = 1.0
            cur_c5 += best_delta
            cur_corr = np.correlate(cur, 1.0 - cur, mode='full')
            # Update lists
            ones.remove(oi)
            ones.append(oz)
            zeros.remove(oz)
            zeros.append(oi)
            if cur_c5 < best_c5 - 1e-14:
                best_c5 = cur_c5
                best_h = cur.copy()
                stall = 0
                best_stall = 0
            else:
                stall += 1
        else:
            stall += 1
            best_stall += 1
    
    return best_h, best_c5

def _binary_sa(h_bin, deadline, max_iters=50000, temp_init=0.003, seed=42):
    """Binary simulated annealing."""
    n = len(h_bin)
    dx = 2.0 / n
    cur = h_bin.copy()
    cur_c5 = _exact_c5(cur)
    best_h = cur.copy()
    best_c5 = cur_c5
    rng = np.random.default_rng(seed)
    ones = list(np.where(cur > 0.5)[0])
    zeros = list(np.where(cur <= 0.5)[0])
    T = temp_init
    stall = 0
    best_stall = 0
    
    for it in range(max_iters):
        if time.time() > deadline:
            break
        if best_stall > 3000:
            break
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        i = int(rng.integers(0, len(ones)))
        j = int(rng.integers(0, len(zeros)))
        oi = ones[i]
        oz = zeros[j]
        
        cur[oi] = 0.0
        cur[oz] = 1.0
        new_c5 = _exact_c5(cur)
        delta = new_c5 - cur_c5
        
        if delta < -1e-14 or rng.random() < np.exp(-delta / max(T, 1e-15)):
            cur = cur  # already modified
            cur_c5 = new_c5
            ones[i] = oz
            zeros[j] = oi
            if cur_c5 < best_c5 - 1e-14:

                best_h = cur.copy()
                stall = 0
                best_stall = 0
            else:
                stall += 1
            T = max(0.0003, T * 0.9998)
        else:
            cur[oi] = 1.0
            cur[oz] = 0.0
            stall += 1
            best_stall += 1

def _resample(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return _project(h_new, n_new / 2.0)

def _smooth_perturb(h, amplitude, rng):
    n = len(h)
    x = np.arange(n, dtype=float)
    freqs = rng.uniform(0.3, 6.0, size=5)
    phases = rng.uniform(0, 2 * np.pi, size=5)
    amps = rng.uniform(0.3, 1.0, size=5)
    perturb = np.zeros(n)
    for f, p, a in zip(freqs, phases, amps):
        perturb += a * np.sin(2.0 * np.pi * f * x / n + p)
    perturb *= amplitude
    perturb += amplitude * 0.2 * rng.normal(0, 1, n)
    return _project(h + perturb, n / 2.0)

def _block_swap_search(h_bin, deadline, max_iters=20000, seed=77):
    n = len(h_bin)
    cur = h_bin.copy()
    cur_c5 = _exact_c5(cur)
    best_h = cur.copy()
    best_c5 = cur_c5
    rng = np.random.default_rng(seed)
    stall = 0
    for _ in range(max_iters):
        if time.time() > deadline:
            break
        if stall > 1500:
            break
        length = int(rng.integers(2, min(6, n // 4)))
        i = int(rng.integers(0, n - length))
        j = int(rng.integers(0, n - length))
        if abs(i - j) < length:
            stall += 1
            continue
        block1 = cur[i:i+length].copy()
        block2 = cur[j:j+length].copy()
        if np.sum(block1) != np.sum(block2):
            stall += 1
            continue
        trial = cur.copy()
        trial[i:i+length] = block2
        trial[j:j+length] = block1
        new_c5 = _exact_c5(trial)
        if new_c5 < cur_c5 - 1e-14:
            cur = trial
            cur_c5 = new_c5
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = cur.copy()
            stall = 0
        else:
            stall += 1
    return best_h, best_c5

Let me think about this differently. The average correlation value across all lags is:
sum_l c_l = sum_m sum_l h[m+l](1-h[m])

For each m with h[m]=0: contributes #{l: h[m+l]=1 and m+l valid} = number of 1s in the valid range starting from m.
For each m with h[m]=1: contributes 0.

This is hard to compute in closed form, but roughly, for a random arrangement of 90 ones and 90 zeros in 180 positions, the expected correlation at each lag is about 90*90/180 = 45... no that's not right.

For lag l, c_l = #{m: 0≤m<180-|l|, h[m]=0, h[m+l]=1} (approximately).
For a random arrangement, E[c_l] ≈ (180-|l|) * (90/180) * (90/180) = (180-|l|) * 0.25.

For l=0: E[c_0] = 180 * 0.25 = 45. But c_0 = #{m: h[m]=0, h[m]=1} = 0! Because h[m] can't be both 0 and 1.

Wait, I made an error. c_l for l≠0:
c_l = sum_{m valid} h[m](1-h[m+l]) for one convention, or h[m+l](1-h[m]) for another.

Let me stick with the numpy convention:
c[n-1+l] = sum_m h[m+l]*(1-h[m]) for l > 0

For l=0: c[n-1] = sum_m h[m]*(1-h[m]) = sum_m h[m] - sum_m h[m]^2

For binary h: c[n-1] = 90 - 90 = 0.

For binary h and l ≠ 0:
c_l = #{m: h[m]=0, h[m+l]=1} (for valid m)

The number of valid m for lag l is n-|l| = 180-|l|.

For a random binary vector with exactly 90 ones:
E[c_l] = (180-|l|) * P(h[m]=0) * P(h[m+l]=1)

But h[m] and h[m+l] are not independent (fixed total). However, for large n, approximately:
E[c_l] ≈ (180-|l|) * (90/180) * (90/179) ≈ (180-|l|) * 0.2507

For l=1: ≈ 179 * 0.2507 ≈ 44.9
For l=90: ≈ 90 * 0.2507 ≈ 22.6
For l=179: ≈ 1 * 0.2507 ≈ 0.25

So the expected max is around 45-50 (considering many lags, the max will be above the mean). The standard deviation for each lag is roughly sqrt((180-|l|) * 0.25 * 0.75) ≈ sqrt(180*0.1875) ≈ 5.8.

So we need to get the max down from ~45 to 34, which is about 2 standard deviations below the mean. That's challenging but possible with optimization.

Now, for the continuous case: if h takes values in [0,1] with mean 0.5 (since sum = n/2, mean = 0.5), then:
c_l = sum_m h[m+l](1-h[m])

For h[m] = h[m+l] = 0.5: each term = 0.25, total = (180-|l|) * 0.25.
Same as binary in expectation!

But the continuous case allows more flexibility in how the "mass" is distributed, potentially lowering the max.
