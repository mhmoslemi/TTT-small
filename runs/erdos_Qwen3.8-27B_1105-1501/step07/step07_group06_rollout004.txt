- h[a]: 1*(1-1)=0 → 0*(1-0)=0. Change: 0

For a binary sequence h, when we swap h[a]: 1→0 and h[b]: 0→1:

The correlation C[k] = sum over valid (i,j) with i-j=k-(n-1) of h[i]*u[j] where u=1-h.

Actually, let me just use the formula I derived:

For k = n-1+tau (tau > 0): C[k] = sum_{i=0}^{n-1-tau} h[i]*(1-h[i+tau])
For k = n-1-tau (tau > 0): C[k] = sum_{i=0}^{n-1-tau} h[i+tau]*(1-h[i])
For k = n-1: C[k] = sum h[i](1-h[i]) = 0 for binary

When h[a] goes 1→0 and h[b] goes 0→1:

For C[n-1+tau], tau > 0:
- a contributes as first index (i=a, need a < n-tau): old term = 1*(1-h[a+tau]), new = 0, delta = -(1-h[a+tau])
- a contributes as second index (i+tau=a, i=a-tau, need a-tau >= 0 and a < n): old term = h[a-tau]*(1-1)=0, new = h[a-tau]*(1-0)=h[a-tau], delta = +h[a-tau]
- b contributes as first index (i=b, need b < n-tau): old term = 0*(1-h[b+tau])=0, new = 1*(1-h[b+tau]), delta = +(1-h[b+tau])
- b contributes as second index (i+tau=b, i=b-tau, need b-tau >= 0): old term = h[b-tau]*(1-0)=h[b-tau], new = h[b-tau]*(1-1)=0, delta = -h[b-tau]

So delta_C[n-1+tau] = sum of applicable terms.

Similarly for C[n-1-tau], tau > 0:
C[n-1-tau] = sum_{i=0}^{n-1-tau} h[i+tau]*(1-h[i])
- a as first index (i+tau=a, i=a-tau): old = 1*(1-h[a-tau]), new = 0, delta = -(1-h[a-tau])
- a as second index (i=a): old = h[a+tau]*(1-1)=0, new = h[a+tau]*(1-0)=h[a+tau], delta = +h[a+tau]
- b as first index (i+tau=b, i=b-tau): old = 0*(1-h[b-tau])=0, new = 1*(1-h[b-tau]), delta = +(1-h[b-tau])
- b as second index (i=b): old = h[b+tau]*(1-0)=h[b+tau], new = h[b+tau]*(1-1)=0, delta = -h[b+tau]

```python
def _swap_delta_all(h, a, b):
    """Compute delta for all corr entries when h[a]:1->0, h[b]:0->1.
    h is binary. Returns array of length 2n-1."""
    n = len(h)
    delta = np.zeros(2*n - 1)
    
    # For each tau from 1 to n-1:
    # C[n-1+tau] delta:
    for tau in range(1, n):
        d = 0.0
        # a as first: need a < n - tau, i.e., a + tau < n
        if a + tau < n:
            d += -(1.0 - h[a + tau])  # = h[a+tau] - 1
        # a as second: need a - tau >= 0
        if a - tau >= 0:
            d += h[a - tau]
        # b as first: need b < n - tau
        if b + tau < n:
            d += (1.0 - h[b + tau])
        # b as second: need b - tau >= 0
        if b - tau >= 0:
            d += -h[b - tau]
        delta[n - 1 + tau] += d
        
        # C[n-1-tau] delta (for the negative lag side):
        d2 = 0.0
        if a - tau >= 0:
            d2 += -(1.0 - h[a - tau])
        if a + tau < n:
            d2 += h[a + tau]
        if b - tau >= 0:
            d2 += (1.0 - h[b - tau])
        if b + tau < n:
            d2 += -h[b + tau]
        delta[n - 1 - tau] += d2
    
    return delta
```

- a as second: valid for tau = 1, 2, ..., a. Contribution: h[a-tau] (a vector of length a)
- b as first: valid for tau = 1, 2, ..., n-1-b. Contribution: 1 - h[b+tau] (vector of length n-1-b)
- b as second: valid for tau = 1, 2, ..., b. Contribution: -h[b-tau] (vector of length b)

    # delta[0] corresponds to C[0] = n-1-(n-1) = tau=-(n-1) on negative side
    # delta[n-1] corresponds to C[n-1] = tau=0
    # delta[n-1+tau] corresponds to C[n-1+tau] = positive tau
    # delta[n-1-tau] corresponds to C[n-1-tau] = negative tau (i.e., index n-1-tau)

    # neg_delta[tau-1] = change in C[n-1-tau] for tau=1,...,n-1
