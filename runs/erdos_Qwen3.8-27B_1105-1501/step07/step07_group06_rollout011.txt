def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo, hi = float(v.min()) - 2.0, float(v.max()) + 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-12:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x = x.copy()
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)

    h_new = np.interp(x_new, x_old, h)

Actually, for the inner loop, the fastest approach might be to precompute the FFT of (1-h) and only recompute the FFT of h after each swap. But since h changes at only 2 positions, I can update the FFT incrementally:

FFT(h')[k] = FFT(h)[k] + (-1) * exp(-2πi*k*i/N) + 1 * exp(-2πi*k*j/N)

Where N is the FFT length. This is O(N) per swap instead of O(N log N).

Then the correlation is:
correlate(h', 1-h') = IFFT(FFT(h') * conj(FFT(1-h')))

But wait, 1-h' also changes (at the same 2 positions). So I need to update both FFTs.

FFT(h')[k] = FFT(h)[k] - exp(-2πi*k*i/N) + exp(-2πi*k*j/N)
FFT(1-h')[k] = FFT(1-h)[k] + exp(-2πi*k*i/N) - exp(-2πi*k*j/N)

Then the product is:
FFT(h') * conj(FFT(1-h')) = [FFT(h) + d_i] * conj([FFT(1-h) + d_j_conj])
where d_i(k) = -exp(-2πi*k*i/N) + exp(-2πi*k*j/N)
and d_j_conj(k) = +exp(-2πi*k*i/N) - exp(-2πi*k*j/N) = -d_i(k)

So: FFT(h') * conj(FFT(1-h')) = [A + d] * conj(B - d) where A = FFT(h), B = FFT(1-h), d = d_i
= A*conj(B) - A*d + d*conj(B) - d*conj(d)
