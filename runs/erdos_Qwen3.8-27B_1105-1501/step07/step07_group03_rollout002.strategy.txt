1. Approach and rationale

The central task is to return a feasible discrete vector `h` minimizing
`C = dx * max_l np.correlate(h, 1-h, mode='full')[l]`, with `dx = 2/n` and
`sum(h)=n/2`. The supplied parent construction is already a strong local point, but it contains mostly pure smooth-gradient, block-direction, and binary simulated-annealing components. The main weakness of the prior scheme is that many promising affine directions are explored implicitly using projected full-gradient steps, while the actual finite-support objective can often be reduced much more cleanly by performing exact global minimization along a few numerically constructed feasible affine lines. I therefore propose a deterministic-plus-randomized exact line-search minimax algorithm, augmented by targeted binary pair-swapping and nonuniform resolution resizing.

The main scientifically justified observation is that for any feasible zero-sum direction `d`, the objective along the affine segment `h(a)=h+a*d` is known exactly without re-calling the evaluator at every test point:

`raw(a) = raw(0) + a*T - a^2*Q`, where

`T = correlate(d, 1-h, 'full') - correlate(h, d, 'full')`,

`Q = correlate(d, d, 'full')`,

and `peak(a) = dx * max(raw(a))` is an exact one-dimensional function of `a`.  
The direction `d` is constructed so that `sum(d)=0` and the path remains in `[0,1]^n` for `a` in a supported interval. This avoids the inefficiency of repeatedly projecting additive gradient steps and permits exact global search on each candidate ray, including both smooth-gradient descent directions and Frank-Wolfe-type binary vertex directions.

Secondary novel components:

1. A targeted binary pair-swap stage that uses weighted gradients to choose high-descent one-zero swaps, followed by exact evaluation of each tested move. This is different from purely random simulated annealing and is useful for making the solution more binary-like where exact objectives support it.

2. Resolution migration through exact interpolation plus projection, with parent sections tested at even sizes around the parent. Returning the returned `n_points` with smaller length when scores are numerically tied is justified by the problem's speed preference.

This is a nonconvex local/near-local search. No global optimality claim is made. Acceptance is always exact against the published evaluator formula; retained fallback retains the supplied parent and never worsens it.
