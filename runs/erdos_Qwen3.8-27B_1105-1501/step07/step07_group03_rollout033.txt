The key insight from the strategy is to use a linear programming approach to find directions that simultaneously reduce multiple active lag constraints, rather than just using gradient-based methods. This is fundamentally different from the previous approach which relied on smooth gradients and pair swaps.

Key elements:
1. Start from `initial_h_values` (n=180 samples)
2. Use LP-based direction finding: select top active lags, build linearized constraints, solve an LP to find a direction that reduces the maximum

Let me think about the LP approach more carefully:

For a given h, the raw correlation at lag r is:
`raw(r) = sum_i h[i] * (1-h[i+r])` (with appropriate bounds)

The linearization around h is:
`raw_r(x) ≈ raw_r(h) + sum_i (∂raw_r/∂h_i)(x_i - h_i)`

The partial derivatives are:
- ∂raw_r/∂h_i = (1-h[i+r]) - h[i] (for the terms where both are in range)

Actually, let me be more careful. The correlation `np.correlate(h, 1-h, mode='full')` computes:
`c[r] = sum_i h[i] * (1-h)[i + (r - (n-1))]` for valid i

Let me think about this differently. For a given h, the overlap at shift k is:
`O(k) = sum_i h[i] * (1 - h[i+k])` (with appropriate bounds)

The linearization: `O(k, x) ≈ O(k, h) + sum_i [∂O(k)/∂h_i] * (x_i - h_i)`

Where `∂O(k)/∂h_i = (1 - h[i+k]) - h[i]` (when both indices are valid)

So the LP would be:
minimize t
subject to: O(k_j, h) + sum_i g_i^j * (x_i - h_i) <= t  for j in active_lags
           sum(x) = target
           h_i - delta <= x_i <= h_i + delta  (trust region)
           0 <= x_i <= 1

This is a linear program with n+1 variables and (n + n_active + 1) constraints.

For n=180, this is manageable with scipy's linprog or cvxpy.

Let me design the algorithm:

1. Start from initial_h_values, project to exact feasibility
2. Main loop:
   a. Compute raw = correlate(h, 1-h, 'full')
   b. Select top K lags (e.g., K=10-20) as "active"
   c. Build LP: minimize t subject to linearized active lags <= t, box constraints, sum constraint
   d. Get LP solution x_lp
   e. Direction d = x_lp - h
   f. Exact line search along d: minimize max_r (raw(r) + alpha * T(r) - alpha^2 * Q(r))
      where T(r) = correlate(d, 1-h) - correlate(h, d) and Q(r) = correlate(d, d)
   g. If improvement, update h
   h. If no improvement, try alternative strategies (binary moves, random perturbations)

Let me also think about the exact line search more carefully.

If h_new = h + alpha * d, then:
`raw(r, h_new) = sum_i (h[i] + alpha*d[i]) * (1 - h[i+r'] - alpha*d[i+r'])`
`= raw(r, h) + alpha * (sum_i d[i]*(1-h[i+r']) - sum_i h[i]*d[i+r'])`
`- alpha^2 * sum_i d[i]*d[i+r']`
`= raw(r, h) + alpha * T(r) - alpha^2 * Q(r)`

where:
- T(r) = correlate(d, 1-h, 'full')[r] - correlate(h, d, 'full')[r]
- Q(r) = correlate(d, d, 'full')[r]

This is a quadratic in alpha for each lag r. We need to find alpha that minimizes max_r of these quadratics.

def _lp_direction(h, delta, n_active=15):
    n = len(h)
    raw = np.correlate(h, 1.0 - h, mode='full')
    top_idx = np.argsort(-raw)[:n_active]
    
    # Build A_ub, b_ub for active lag constraints
    A_rows = []
    b_vals = []
    for r in top_idx:
        d = r - (n - 1)
        g = _lag_gradient(h, d)
        # g . x - t <= -raw[r]
        row = np.append(g, -1.0)
        A_rows.append(row)
        b_vals.append(-raw[r])
    
    A_ub = np.array(A_rows)
    b_ub = np.array(b_vals)
    
    # Equality: sum(x) = target
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([n / 2.0])
    
    # Bounds
    bounds = []
    for i in range(n):
        lo = max(0.0, h[i] - delta)
        hi = min(1.0, h[i] + delta)
        bounds.append((lo, hi))
    bounds.append((0.0, None))  # t >= 0
    
    # Objective: minimize t
    c = np.zeros(n + 1)
    c[n] = 1.0
    
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')
    
    if res.success:
        x_lp = res.x[:n]
        d = x_lp - h
        return d, raw, top_idx
    return None, raw, top_idx

np.correlate(a, v, mode='full') computes:
c[k] = sum_i a[i+k] * conj(v[i]) for k = -(n_v-1), ..., n_a-1

Actually, the numpy docs say:
c_{mn} = \sum_{i} a_{i+m} \overline{v_n}

where m ranges from -(N-1) to M-1 (if a has length M and v has length N).

So for correlate(h, 1-h, 'full') where both have length n:
c[k] = sum_i h[i+k] * (1-h)[i] for k = -(n-1), ..., n-1

The output has length 2n-1, indexed from 0 to 2n-2.
The correspondence is: output index r corresponds to k = r - (n-1).

So raw[r] = sum_i h[i + r - (n-1)] * (1-h[i]) for valid i.

Let m = r - (n-1) = shift.

If m >= 0: raw[r] = sum_{i=0}^{n-1-m} h[i+m] * (1-h[i])
If m < 0: raw[r] = sum_{i=0}^{n-1+m} h[i+m] * (1-h[i]) (where i+m >= 0, so i >= -m)
           = sum_{i=-m}^{n-1} h[i+m] * (1-h[i])

In both cases: raw[r] = sum_{i: 0<=i<n, 0<=i+m<n} h[i+m] * (1-h[i])

The gradient w.r.t. h[j]:
- h[j] appears as h[i+m] when i+m = j, i.e., i = j-m. Valid when 0 <= j-m < n.
  Contribution: (1-h[j-m])
- h[j] appears in (1-h[i]) when i = j. Valid when 0 <= j+m < n, i.e., 0 <= j < n and j+m < n.
  Wait, (1-h[i]) where i = j means h[j] appears with coefficient -h[j+m] (from the h[i+m] = h[j+m] term).
  Valid when 0 <= j+m < n.

So: grad[j] = (1-h[j-m]) * [0 <= j-m < n] - h[j+m] * [0 <= j+m < n]

Where the bracket notation means 1 if the condition is true, 0 otherwise.

from scipy.optimize import linprog

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo, hi = float(v.min()) - 2.0, float(v.max()) + 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-13:
        if res > 0:
            mask = x < 0.9999999
        else:
            mask = x > 1e-9
        cnt = int(np.sum(mask))
        if cnt > 0:
            x = x.copy()
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _lag_gradient(h, m):
    n = len(h)
    g = np.zeros(n)
    if m >= 0:
        gm = n - m
        g[m:] += (1.0 - h[:gm])
        g[:gm] -= h[m:]
    else:
        p = -m
        gp = n - p
        g[:gp] += (1.0 - h[p:])
        g[p:] -= h[:gp]
    return g

def _solve_lp(h, active_idx, delta):
    n = len(h)
    raw = np.correlate(h, 1.0 - h, mode='full')
    
    A_rows = []
    b_vals = []
    for r in active_idx:
        m = r - (n - 1)
        g = _lag_gradient(h, m)
        row = np.append(g, -1.0)
        A_rows.append(row)
        b_vals.append(-raw[r])
    
    if not A_rows:
        return None
    
    A_ub = np.array(A_rows)
    b_ub = np.array(b_vals)
    
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([n / 2.0])
    
    bounds = []
    for i in range(n):
        lo = max(0.0, h[i] - delta)
        hi = min(1.0, h[i] + delta)
        bounds.append((lo, hi))
    bounds.append((0.0, None))
    
    c = np.zeros(n + 1)
    c[n] = 1.0
    
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq, 
                      bounds=bounds, method='highs')
        if res.success:
            return res.x[:n] - h
    except Exception:
        pass
    return None

    return best_alpha, best_val

def _lp_optimize(h, deadline, n_active=20, delta_init=0.15, stall_limit=60):
    n = len(h)
    target = n / 2.0
    h = h.copy()
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    stall = 0
    delta_cur = delta_init
    delta_base = delta_init
    
    while time.time() < deadline and stall < stall_limit:
        u = 1.0 - h
        raw = np.correlate(h, u, mode='full')
        mx = float(np.max(raw))
        
        # Select active lags
        active_mask = raw > (mx - 0.02 * mx)  # within 2% of max
        active_cnt = int(np.sum(active_mask))
        if active_cnt < 5:
            active_mask = raw > (0.95 * mx)
            active_cnt = int(np.sum(active_mask))
        if active_cnt > n_active:
            all_active = np.where(active_mask)[0]
            active_idx = all_active[np.argsort(-raw[all_active])[:n_active]]
        else:
            active_idx = np.where(active_mask)[0]
        
        if len(active_idx) == 0:
            stall = stall_limit
            break
        
        # Solve LP
        d = _solve_lp(h, active_idx, delta_cur)
        
        if d is None or np.linalg.norm(d) < 1e-12:
            stall += 1
            delta_cur = min(delta_cur * 1.4, 0.5)
            if delta_cur > 0.4:
                delta_cur = delta_base
            continue
        
        # Line search
        T = np.correlate(d, u, mode='full') - np.correlate(h, d, mode='full')
        Q = np.correlate(d, d, mode='full')
        
        # Compute alpha_max
        alpha_max = 1.0
        pos = d > 1e-12
        neg = d < -1e-12
        if np.any(pos):
            alpha_max = min(alpha_max, float(np.min((1.0 - h[pos]) / d[pos])))
        if np.any(neg):
            alpha_max = min(alpha_max, float(np.min(h[neg] / (-d[neg]))))
        alpha_max = max(alpha_max, 1e-12)
        
        best_alpha, best_val = _line_search_minimax(raw, T, Q, alpha_max, n_top=15)
        
        if best_alpha < 1e-10:
            stall += 1
            delta_cur *= 0.8
            if delta_cur < 0.03:
                delta_cur = delta_base * 0.5
            continue
        
        h_new = h + best_alpha * d
        h_new = _project(h_new, target)
        actual = _exact_c5(h_new)
        
        if actual < cur_c5 - 1e-14:
            h = h_new
            cur_c5 = actual
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            stall = 0
            delta_cur = max(delta_cur * 0.97, 0.02)
        else:
            stall += 1
            delta_cur *= 0.75
            if delta_cur < 0.02:
                delta_cur = delta_base * 0.6
    
    return best_h, best_c5

import numpy as np
import time
from scipy.optimize import linprog

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo, hi = float(v.min()) - 2.0, float(v.max()) + 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-13:
        if res > 0:
            mask = x < 0.9999999
        else:
            mask = x > 1e-9
        cnt = int(np.sum(mask))
        if cnt > 0:
            x = x.copy()
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _lag_gradient(h, m):
    n = len(h)
    g = np.zeros(n)
    if m >= 0:
        gm = n - m
        if gm > 0:
            g[m:] += (1.0 - h[:gm])
            g[:gm] -= h[m:]
    else:
        p = -m
        gp = n - p
        if gp > 0:
            g[:gp] += (1.0 - h[p:])
            g[p:] -= h[:gp]
    return g

def _solve_lp(h, active_idx, delta):
    n = len(h)
    u = 1.0 - h
    raw = np.correlate(h, u, mode='full')
    A_rows = []
    b_vals = []
    for r in active_idx:
        m = r - (n - 1)
        g = _lag_gradient(h, m)
        row = np.empty(n + 1)
        row[:n] = g
        row[n] = -1.0
        A_rows.append(row)
        b_vals.append(-raw[r])
    if not A_rows:
        return None
    A_ub = np.array(A_rows)
    b_ub = np.array(b_vals)
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([n / 2.0])
    bounds = []
    for i in range(n):
        lo = max(0.0, h[i] - delta)
        hi = min(1.0, h[i] + delta)
        bounds.append((lo, hi))
    bounds.append((0.0, None))
    c = np.zeros(n + 1)
    c[n] = 1.0
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs')
        if res.success:
            d = res.x[:n] - h
            if np.linalg.norm(d) > 1e-14:
                return d
    except Exception:
        pass
    return None

def _line_search_minimax(raw, T, Q, alpha_max, n_top=15):
    if alpha_max <= 1e-12:
        return 0.0
    def f(alpha):
        return float(np.max(raw + alpha * T - alpha * alpha * Q))
    candidates = [0.0, alpha_max]
    top_idx = np.argsort(-raw)[:n_top]
    for idx in top_idx:
        if Q[idx] > 1e-14:
            av = T[idx] / (2.0 * Q[idx])
            if 1e-8 < av < alpha_max - 1e-8:
                candidates.append(av)
    for i in range(len(top_idx)):
        for j in range(i + 1, len(top_idx)):
            ri, rj = int(top_idx[i]), int(top_idx[j])
            A = Q[rj] - Q[ri]
            B = T[ri] - T[rj]
            C = raw[ri] - raw[rj]
            if abs(A) > 1e-14:
                disc = B * B - 4.0 * A * C
                if disc >= 0:
                    sd = np.sqrt(disc)
                    for aa in [(-B + sd) / (2.0 * A), (-B - sd) / (2.0 * A)]:
                        if 1e-8 < aa < alpha_max - 1e-8:
                            candidates.append(aa)
            elif abs(B) > 1e-14:
                aa = -C / B
                if 1e-8 < aa < alpha_max - 1e-8:
                    candidates.append(aa)
    grid = np.linspace(0.0, alpha_max, 25)
    candidates.extend(grid.tolist())
    best_alpha = 0.0
    best_val = f(0.0)
    for alpha in candidates:
        alpha = max(0.0, min(alpha, alpha_max))
        v = f(alpha)
        if v < best_val:
            best_val = v
            best_alpha = alpha
    step = alpha_max / 25
    lo = max(0.0, best_alpha - 2.0 * step)
    hi = min(alpha_max, best_alpha + 2.0 * step)
    if hi - lo > 1e-11:
        gr = (np.sqrt(5.0) - 1.0) / 2.0
        c1 = hi - gr * (hi - lo)
        c2 = lo + gr * (hi - lo)
        f1 = f(c1)
        f2 = f(c2)
        for _ in range(55):
            if hi - lo < 1e-14:
                break
            if f1 < f2:
                hi, c2, f2 = c2, c1, f1
                c1 = hi - gr * (hi - lo)
                f1 = f(c1)
            else:
                lo, c1, f1 = c1, c2, f2
                c2 = lo + gr * (hi - lo)
                f2 = f(c2)
        opt = (lo + hi) / 2.0
        if f(opt) < best_val:
            best_val = f(opt)
            best_alpha = opt
    return best_alpha

def _lp_optimize(h, deadline, n_active=20, delta_init=0.12, stall_limit=50):
    n = len(h)
    target = n / 2.0
    h = h.copy()
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    stall = 0
    delta_cur = delta_init
    while time.time() < deadline and stall < stall_limit:
        u = 1.0 - h
        raw = np.correlate(h, u, mode='full')
        mx = float(np.max(raw))
        if mx < 1e-12:
            break
        active_mask = raw > (mx - 0.015 * mx)
        if int(np.sum(active_mask)) < 5:
            active_mask = raw > (0.95 * mx)
        if int(np.sum(active_mask)) > n_active:
            all_act = np.where(active_mask)[0]
            active_idx = all_act[np.argsort(-raw[all_act])[:n_active]]
        else:
            active_idx = np.where(active_mask)[0]
        if len(active_idx) == 0:
            break
        d = _solve_lp(h, active_idx, delta_cur)
        if d is None:
            stall += 1
            delta_cur = min(delta_cur * 1.5, 0.5)
            if delta_cur > 0.4:
                delta_cur = delta_init
            continue
        T = np.correlate(d, u, mode='full') - np.correlate(h, d, mode='full')
        Q = np.correlate(d, d, mode='full')
        alpha_max = 1.0
        pos = d > 1e-12
        neg = d < -1e-12
        if np.any(pos):
            alpha_max = min(alpha_max, float(np.min((1.0 - h[pos]) / d[pos])))
        if np.any(neg):
            alpha_max = min(alpha_max, float(np.min(h[neg] / (-d[neg]))))
        alpha_max = max(alpha_max, 1e-12)
        best_alpha = _line_search_minimax(raw, T, Q, alpha_max, n_top=15)
        if best_alpha < 1e-10:
            stall += 1
            delta_cur *= 0.75
            if delta_cur < 0.02:
                delta_cur = delta_init * 0.5
            continue
        h_new = h + best_alpha * d
        h_new = _project(h_new, target)
        actual = _exact_c5(h_new)
        if actual < cur_c5 - 1e-14:
            h = h_new
            cur_c5 = actual
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            stall = 0
            delta_cur = max(delta_cur * 0.96, 0.015)
        else:
            stall += 1
            delta_cur *= 0.7
            if delta_cur < 0.015:
                delta_cur = delta_init * 0.6
    return best_h, best_c5

def _binary_sa(h_bin, deadline, max_iter=40000, T_init=0.003):

def _pair_sweep(h_bin, deadline):
    n = len(h_bin)
    cur = h_bin.copy()
    cur_c5 = _exact_c5(cur)
    best_h = cur.copy()
    best_c5 = cur_c5
    ones = list(np.where(cur > 0.5)[0])
    zeros = list(np.where(cur <= 0.5)[0])
    improved = True
    while improved and time.time() < deadline:
        improved = False
        for oi in ones:
            if time.time() > deadline:
                break
            for oz in zeros:
                h_try = cur.copy()
                h_try[oi] = 0.0
                h_try[oz] = 1.0
                c_try = _exact_c5(h_try)
                if c_try < cur_c5 - 1e-15:

                    cur_c5 = c_try
                    best_h = cur.copy()
                    best_c5 = c_try
                    ones = list(np.where(cur > 0.5)[0])
                    zeros = list(np.where(cur <= 0.5)[0])
                    improved = True
                    break
    return best_h, best_c5

def _to_binary(h):
    n = len(h)
    idx = np.argsort(h)[-n // 2:]
    h_bin = np.zeros(n)
    h_bin[idx] = 1.0
    return h_bin

def _resample(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return _project(h_new, n_new / 2.0)

def _smooth_perturb(h, amplitude, rng):
    n = len(h)
    x = np.arange(n, dtype=float)
    perturb = np.zeros(n)
    for _ in range(4):
        f = rng.uniform(0.5, 6.0)
        p = rng.uniform(0, 2 * np.pi)
        a = rng.uniform(0.3, 1.0)
        perturb += a * np.sin(2.0 * np.pi * f * x / n + p)
    perturb *= amplitude
    perturb += amplitude * 0.1 * rng.normal(0, 1, n)
    return _project(h + perturb, n / 2.0)

def _gradient_optimize(h, deadline, beta=20.0, radius=0.2, stall_limit=50):
    n = len(h)
    dx = 2.0 / n
    target = n / 2.0
    h = h.copy()
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    stall = 0
    beta_cur = beta
    radius_cur = radius
    rng = np.random.default_rng(777)
    while time.time() < deadline and stall < stall_limit:
        u = 1.0 - h
        raw = np.correlate(h, u, mode='full')
        mx = float(np.max(raw))
        shifted = raw - mx
        vp = np.exp(np.clip(beta_cur * shifted, -80, 0))
        w = vp / (float(np.sum(vp)) + 1e-30)
        g = np.zeros(n)
        for r in range(2 * n - 1):
            ww = w[r]
            if ww < 1e-12:
                continue
            d_shift = r - (n - 1)
            lr = _lag_gradient(h, d_shift)
            g += ww * lr
        g -= np.mean(g)
        d = -g
        d -= np.mean(d)
        nm = np.linalg.norm(d)
        if nm < 1e-12:
            stall += 1
            radius_cur *= 0.8
            continue
        d /= nm
        T = np.correlate(d, u, mode='full') - np.correlate(h, d, mode='full')
        Q = np.correlate(d, d, mode='full')
        alpha_max = radius_cur
        pos = d > 1e-12
        neg = d < -1e-12
        if np.any(pos):
            alpha_max = min(alpha_max, float(np.min((1.0 - h[pos]) / d[pos])))
        if np.any(neg):
            alpha_max = min(alpha_max, float(np.min(h[neg] / (-d[neg]))))
        alpha_max = max(alpha_max, 1e-12)
        best_alpha = _line_search_minimax(raw, T, Q, alpha_max, n_top=12)
        if best_alpha < 1e-10:
            stall += 1
            radius_cur *= 0.75
            beta_cur = max(beta_cur * 0.9, 5.0)
            continue
        h_new = h + best_alpha * d
        h_new = _project(h_new, target)
        actual = _exact_c5(h_new)
        if actual < cur_c5 - 1e-14:
            h = h_new
            cur_c5 = actual
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            stall = 0
            radius_cur = min(radius_cur * 1.03, 0.35)

            beta_cur = max(beta_cur * 0.92, 5.0)

def _pair_swap_cont(h, deadline, n_pairs=5000, radius=0.25, seed=111):

        if c5_6 < best_c5:
            best_c5 = c5_6
            best_h = h6.copy()

    best_h = _project(best_h, len(best_h) / 2.0)
    final_c5 = _exact_c5(best_h)
    return best_h, final_c5, len(best_h)
