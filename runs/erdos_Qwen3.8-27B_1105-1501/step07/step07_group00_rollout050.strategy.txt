1. Approach and rationale

The key idea is to attack the nonconvex minimax objective from a qualitatively different side than a purely fractional trust-region LP.  The supplied parent has likely reached a local fractional basin.  Instead of only perturbing that construction, the proposed method uses the exact combinatorial structure of step functions.  For binary `h`, the whole overlap objective becomes an integer count of 0-to-1 and 1-to-0 transitions at each finite lag.  This count admits a small linear-integer formulation using only binary cell variables and one auxiliary auxiliary "difference" variable per unordered pair.  Unlike product variables `x_i x_j`, this formulation uses the identity

`count_0->1(d) = (number of unequal pairs at distance d + signed imbalance of ones) / 2`

where the signed imbalance is a simple sum difference.  This yields a much smaller and more precise exact-integer model.  Solving it, or merely finding feasible/incomplete incumbent solutions before a solver time limit, can reveal binary step constructions in basins unreachable by the supplied continuous parent.  Those binary constructions can then be relaxed, averaged, shifted, mirrored, and polished with the true evaluator.

The second part is targeted validation and correction.  A local fractional polishing routine uses exact vectorized correlation evaluation for candidate scoring and exact quadratic line search for every proposed direction, with full first-order gradient information.  It does not rely on auxiliary surrogate objective values.  Small reference sequences are preferred whenever their exact value is no worse than the incumbent.

Important assumptions and limitations:
- A large integer linear feasibility/minimization model is NP-hard in general.  Solver timeouts, unavailable solvers, and numerical tolerances may reduce the number and quality of discovered seeds.  No claim of optimality or global proof is implied.
- The integer model is exact only for identical binary values.  Relaxation or fractional solver outputs must be rounded and re-evaluated with the actual evaluator before being accepted.
- The true evaluation includes both lag signs and finite, non-circular truncation implied by `np.correlate(..., mode='full')`.  No circular autocorrelation substitution is used.
- Exact feasibility `0 <= h[i] <= 1` and `sum h[i] = n/2` is achieved by exact-design binary helpers or by a joint water-filling projection.  Sequential clipping then simple rescaling is prohibited as an exact projection.

The central substantive difference from earlier stochastic binary annealing is the constructed positive-transition integer formulation.  It guides binary search by exact, global finite-lag equality inequalities rather than repeated full `np.correlate` evaluations over random proposals.  The continuous stage is retained for fractional release of valuable seeds, but it is no longer the primary exploration engine.

2. Mathematical specification

2.1 Grid and evaluator

Let `n = n_points`, `dx = 2.0 / n`, and `h` be a one-dimensional array of length `n`.  Define the unweighted score vector

`R(h) = np.correlate(h, 1.0 - h, mode='full')`.

Its length is `2n - 1`.  Index

`ell = d + n - 1`

corresponds to signed lag `d` in the ordered output used by the evaluator.  The objective is

`C5(h) = max(R(h)) * dx`.

The exact evaluator is used for every accepted result, every returned objective, and every comparison between candidates.

For binary `b[i] in {0,1}` with `sum(b) = n/2`, the value at lag `d >= 1` is

`R_+(d) = sum_{j=0}^{n-d-1} b[j+d] * (1 - b[j])`,

the count of ordered pairs `(left, right)` separated by distance `d` where `left = 0` and `right = 1`.  At lag `-d` it is

`R_-(d) = sum_{j=0}^{n-d-1} b[j] * (1 - b[j+d])`,

the count where `left = 1` and `right = 0`.

Define for each distance `d`

`E_d = sum_{j=0}^{n-d-1} 1[ b[j+d] != b[j] ]`

and the signed imbalance

`B_d = sum_{j=0}^{n-d-1} b[j+d] - sum_{j=0}^{n-d-1} b[j]`.

For each individual pair, the following identities are exact:

if `b[j+d]=1, b[j]=0`, then `B contribution = +1`, `E contribution = 1`, `R_+ = 1`, `R_- = 0`;
if `b[j+d]=0, b[j]=1`, then `B contribution = -1`, `E contribution = 1`, `R_+ = 0`, `R_- = 1`;
if the pair is equal, then all contributions are zero.

Hence

`R_+(d) = (E_d + B_d) / 2`,
`R_-(d) = (E_d - B_d) / 2`.

At lag zero, binary `b` gives unweighted score exactly zero because `b[j](1-b[j])=0`.  The evaluator still includes it; no extra constraint is needed for binary exact models.

Thus, a candidate with maximum unweighted count at most integer `K` satisfies the integer inequalities

`E_d + B_d <= 2K` and `E_d - B_d <= 2K`

for every `d = 1,...,n-1`.  Because the right sides are even integers and `E_d` and `B_d` have the same parity for binary variables, integer feasibility in this system is exactly equivalent to `max_d R_+/R_- <= K`.

The integer model minimizes `K` or enforces `K <= K_req`, and incorporates

`sum_i b[i] = n/2`,
`b[i] in {0,1}`.

If `n` is odd, exact balanced binary assignment is impossible.  Binary connection attempts use only even lengths.  Continuous functions can always be feasible for odd parent length because its target is a real value.

2.2 Integer linear absolute-difference formulation

For a chosen even length `n`, introduce binary `x_i` for each cell and slack/absolute-value vectors tailored to pairs of each separation `d`.  For pair `(j, i=j+d)` with `d=1,...,n-1`, an auxiliary variable `s_{j,d}` represents the absolute difference `|x_i - x_j|`.  It is restricted by

`s_{j,d} >= x_{j+d} - x_j`,
`s_{j,d} >= x_j - x_{j+d}`,
`0 <= s_{j,d} <= 1`.

The correct integrality is `x_i integer binary`.  The auxiliary variable can be binary or continuous with the above bounds; if all `x` are binary, either choice forces the correct value for unequal pairs under finite optimal incumbent solving.  It is safer to model `s` as binary when a MILP solver is available, because the model is then pure integer and the exact bound condition is unambiguous.  If solver capacity is insufficient, a continuous-s relaxation is tried only for heuristic candidate generation, not as proof.

Define

`D_d = sum_{j=0}^{n-d-1} s_{j,d}`
`B_d = sum_{j=0}^{n-d-1} x_{j+d} - sum_{j=0}^{n-d-1} x_j`.

For a target integer upper bound `K`, impose

`D_d + B_d <= 2K` for all positive-lag indices,
`D_d - B_d <= 2K` for all corresponding negative-lag indices.

Alternately impose an integer or continuous variable `M` with

`D_d + B_d <= 2M`,
`D_d - B_d <= 2M`,
`M >= 0`,

and minimize `M`.  Every feasible binary `x` yields a valid h vector.  An incumbent with fractional variable values is downloaded only after attempting binary rounding by taking `round(x)` if it preserves the balance target exactly; otherwise it is converted into a binary candidate using top-half selection plus low-amplitude water-filling and then scored using exact correlation.

2.3 Continuous gradient and quadratic line model

For any feasible fractional `h`, the unweighted score at a positive-lag index `ell` with signed offset `d >= 0` is

`R_ell = sum_{j=0}^{n-1-d} h[j+d] * (1 - h[j]) = sum_{j=0}^{n-1-d} h[j+d] - h[j+d] h[j]`.

For negative offset `g = -d > 0`,

`R_ell = sum_{j=0}^{n-1-g} h[j] * (1 - h[j+g]) = sum_{j=0}^{n-1-g} h[j] - h[j] h[j+g]`.

The finite support and exact offsets follow NumPy's non-circular vector; do not wrap indices.

At current `h`, define a direction array `p` satisfying an equality tangent `sum p = 0`.  Let

`A = np.correlate(h, 1.0 - h, mode='full')`,
`T = np.correlate(p, 1.0 - h, mode='full') - np.correlate(h, p, mode='full')`,
`Q = np.correlate(p, p, mode='full')`.

Because the score is a product, along the pre-projection ray

`h(t) = h + t p`

the unweighted score vector is exactly

`R(t) = A + t T - t^2 Q`.

The predicted objective along this ray is

`phi(t) = max(R(t)) * dx`.

This is exact for all `t`.  During line search one must keep `h + t p` in the box by using

`tmax = infinity initially`, then for positive entries of `p`:
`tmax = min(tmax, (1-h[pos])/p[pos])`;
for negative entries:
`tmax = min(tmax, h[neg]/(-p[neg]))`.

The LP direction is proposed without component bounds, but projection after application can break the predicted ray.  Consequently, the actual h after projection must be evaluated by the true evaluator.  Acceptance is based solely on actual exact improvement.

2.4 Linearized active-set subproblem

For a vector of active score indices, let `G` be the matrix of polynomial gradients, where row `r` represents the gradient of `R_{ell(r)}`.  For positive offset `d`, row entries are computed by accumulation:

for `j=0,...,n-d-1`:
`coeff[j+d] += 1 - h[j]`,
`coeff[j]   -= h[j+d]`.

For negative offset `g=-d>0`:

for `j=0,...,n-g-1`:
`coeff[j]   += 1 - h[j+g]`,
`coeff[j+g] -= h[j]`.

The linearized search problem is

variables: direction vector `y` of length `n` and scalar `tau`.
minimize `tau`
subject to, for each active score row,
`G_r^T y - tau <= -R_{ell(r)}`.

Also enforce

`sum(y_i) = 0`,
`l_i <= y_i <= u_i`,

where bounds are from a current trust radius and the physical bounds of `h`:

`l_i = max(-radius, -h[i])`,
`u_i = min(radius, 1-h[i])`.

This is a linear program and is solved with a reliable LP solver, preferably the SciPy HiGHS method.  Its exact support is linear objective/constraints and an equality sum constraint.  The feasibility constraints and direction bounds are exact and solver-compatible.  If it fails or produces a zero direction, alternative heuristic directions are used.

2.5 Candidate score vector helpers

A helper `_scores(h)` always returns the exact unweighted vector.  A helper `_exact_c5(h)` clamps input only for evaluation preprocessing if tiny floating noise exists, never for accepted proof, computes `R` and `dx` and returns `float(np.max(R) * dx)`.  A validation helper accepts arrays whose final values, after joint projection or their own binary construction, satisfy

`sum(h) = n/2` to absolute tolerance `<= 1e-10`,
`min(h) >= -1e-11`,
`max(h) <= 1 + 1e-11`,
`h` finite.

A further correction is applied to exactly target the sum by normalizing with equal deltas only on dimensions which remain strictly inside the open interval `(0,1)` or by integer construction.  The final accepted vector is reprojected and exact-scored with the supplied formula.

2.6 Exact joint projection

Projection is not done as clipping then scaling.  Define `_project(v, target)` as water filling:

- Start with `v = np.asarray(v, dtype=float)` and initially clip to a slightly widened feasible range not less than `[0,1]`.
- If target is outside `[0,n]`, the request is invalid; in this problem target is always `n/2`.
- Solve by bisection for a scalar offset `theta` such that

`S(theta) = sum_i clip(v_i - theta, 0, 1) = target`.

The feasible bisection interval is from `min(v)-2` to `max(v)+2`.  Iterate until `S(theta)` is within machine tolerance of target.
- The natural projected vector is

`h = clip(v - theta, 0, 1)`.

Because floating error may leave an extremely small target residual, inspect `target - sum(h)`.  If nonzero:
  * if the residual is positive, add it equally to coordinates with values strictly below 1 and strictly above a small interior threshold.
  * if negative, subtract it equally from coordinates strictly above 0 and strictly below 1.
  * If no interior coordinate exists, target is impossible for the current dimension/box and the projection request is rejected by caller.
- Clip final values to the exact box `[0,1]` after correction.  For binary arrays, known sums are exact and must use a dedicated `round_to_binary_balanced` binary procedure rather than rounding via absolute projection.

For binary balancing of fractional `v`, use deterministic or jittered top-half selection:
- Add optional seed noise only for proposal generation.
- Choose `m = n//2` largest entries.  Set one variable to one.  Set all others zero.
- If `n` is odd, skip exact binary mode.
This sum is exactly `m` as a float and satisfies bounds exactly.
