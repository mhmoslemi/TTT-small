```python
def _subgradient(h, top_k=10):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    # Get top-k indices
    idx = np.argsort(corr)[-top_k:]
    g = np.zeros(n)
    for idx_k in idx:
        k = abs(int(idx_k - (n - 1)))
        if k == 0:
            # val(0) = sum h[i](1-h[i])
            # d/dh[j] = 1 - 2*h[j]
            g += 1.0 - 2.0 * h
        else:
            # g_k[j] = (1-h[j-k]) * 1[k<=j<=n-1] - h[j+k] * 1[0<=j<=n-k-1]
            m = n - k
            # First term: j in [k, n-1]
            g[k:] += (1.0 - h[:m])
            # Second term: j in [0, m-1]
            g[:m] -= h[k:]
    return g / len(idx)
```

Now let me think about the FW oracle:
We want to minimize <g, v> subject to 0<=v<=1, sum(v)=n/2.
Since we want to DECREASE f, and g = ∇f (subgradient), we want to minimize <g, v>.
The minimum is achieved by setting v[j]=1 where g[j] is smallest, v[j]=0 where g[j] is largest.

So: sort g ascending, set v = 1 for first n/2 positions, v = 0 for the rest.

Then the FW step is:
h_new = (1-α)*h + α*v

We need to choose α. Options:
- Greedy: α = 2/(t+2) (standard FW step size)
- Line search: minimize f((1-α)h + αv) over α in [0,1]
- Strong step: if v is very different from h, take a larger step

For the line search, note that f is the max of bilinear functions, so f((1-α)h + αv) is the max of quadratic functions in α. We can find the minimum by:
1. Computing the correlation at α=0 and α=1
2. For each active shift k, the value at α is:
   val_k((1-α)h + αv) = (1-α)² val_k(h) + α(1-α)[something] + α² val_k(v) + cross terms

Actually, let me think about this more carefully.

Let p = v - h. Then h(α) = h + αp.
val_k(h(α)) = Σ_{overlap} (h[i]+αp[i]) * (1-h[i+k]-αp[i+k])
            = Σ h[i](1-h[i+k]) + α Σ [p[i](1-h[i+k]) - h[i]p[i+k]] - α² Σ p[i]p[i+k]
            = val_k(h) + α * A_k - α² * B_k

where A_k = Σ_{overlap} [p[i](1-h[i+k]) - h[i]p[i+k]]
and B_k = Σ_{overlap} p[i]p[i+k]

Note: A_k is the directional derivative (since val is bilinear, the taylor expansion is exact).
And B_k >= 0 (since it's a sum of products... wait, p[i] can be negative, so B_k can be negative).

Actually B_k = Σ p[i]p[i+k]. If p has both positive and negative entries, B_k can be anything.

So f(h(α)) = max_k [val_k(h) + α*A_k - α²*B_k]

This is the max of quadratic functions in α. The minimum of this max can be found by:
1. Sampling α on a grid
2. Refining with golden section or bisection

But since each individual function is at most quadratic (actually, it IS quadratic, not just at most), the maximum of quadratics is a piecewise-quadratic function. Its minimum can be found by checking the critical points.
