1. Approach and rationale

The parent construction is already near the current record, so another purely local smooth-max-gradient continuation is likely to improve only marginally. The algorithm proposed here attacks a different bottleneck: efficient generation and exact evaluation of many globally diverse balanced binary candidates, followed by high-confidence continuous polishing around the best discrete candidates.

The central ideas are:

A. Exact recursive correlation updating for balanced bit moves. Instead of re-forming `np.correlate(h, 1-h, mode="full")` for every proposed move, maintain the full raw correlation vector and update it after a coordinate change using the exact bilinear dependence of the objective. A balanced swap is applied as two exact one-coordinate updates using the current intermediate vector. This allows many more discrete proposals per second than exact re-correlation can permit. The returned score is always recomputed with the evaluator formula, so the dynamic method can accelerate search without replacing the target objective.

B. Targeted highest-overlap proposals. New proposals are not only random balanced swaps. They are seeded from the currently largest positive and negative lag terms. If a positive or negative lag is at or near the current maximum, the algorithm proposes swapping one variable that contributes most to the largest term with one balanced opposite-valued variable outside or opposite to that term. The resulting swaps are always scored by exact correlation evaluation.

C. Multiple finite-grid lengths are searched explicitly. TheEvaluator is still exact for every returned vector.

D. Balanced objective formula. The input length is `n`, `dx = 2.0 / float(n)`, and the objective is `score(h) = dx * max(np.correlate(h, 1.0 - h, mode="full"))`. Indices are `r = 0, ..., 2n-2`; let `L = r - (n-1)`. Valid terms are:
