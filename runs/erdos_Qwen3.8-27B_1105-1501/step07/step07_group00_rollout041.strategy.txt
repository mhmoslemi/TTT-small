1. Approach and rationale

The present construction plateaued at approximately 0.380889. The previous search is almost entirely a continuous trust-region linear programming/local smoothing loop with occasional pair swaps. It is therefore likely trapped in the same fractional basin reached from the supplied parent.

The proposed strategy keeps the parent as a validated fallback and rigorous safety reference, but changes the search neighborhood dramatically by separating the problem into two regimes:

1. Exact combinatorial search over balanced binary step values, where the objective becomes an integer count of ordered one-to-zero pairs. This regime can be explored efficiently with exact incremental score updates, simulated annealing, genetic/recombination operators, and deterministic low-multiplicity seeds. The binary optimum need not be used directly, but it can expose qualitatively different partitions of the interval into occupied and unoccupied cells.

2. Continuous polishing from these binary or half-binary states using a full first-order linearized minimax trust-region LP plus exact quadratic 1D line search. The continuous problem is nonconvex; the contribution of the double of the solver is not to prove optimality but to transition from constructed discrete basins into nearby relaxed and smoothed representatives.

The central improvement is that binary plateau problems, which fractional continuous directions tunnel through poorly, can be escaped by discrete combinatorial moves. Fractional averaging then often captures the intersection of several binary assumptions and becomes a better candidate for LP descent. Returning the final combination to exact evaluator before declaring improvement prevents surrogate or incremental errors from polluting the bound.

Important limitations and hypotheses:

* The combinational SA is local, not a proof of global optimum. It may still miss the combinatorial basin yielding the best constant.
* Binary and fractional global-search basins are different from one another. A candidate that looks good in count improvement may not survive exact LP acceptance.
* The lower is better objective is judged solely by `max(np.correlate(h, 1-h, "full") * dx)`. Every algorithmic citation of an improved value must re-evaluate this exact expression.
* `sum(h)` must equal `n_points/2`. Numeric projection, correcting one component and revalidation are required.

When no parent construction is available, the plan still uses deterministic and random exact balanced seeds.

2. Mathematical specification

Let `n = n_points`, `dx = 2.0 / n`. For each integer lag `d = i - j` with `-(n-1) <= d <= n-1`, define unweighted integer or fractional count

for `d` fixed and valid `j`:

`C[d_index] = sum h[j + d] * (1 - h[j])`

where `j` ranges over `(max(0, -d), min(n, n - d))`.

The evaluator order corresponds to output index

`idx = d + (n - 1)`, `idx = 0 ... 2n - 2`.

The objective is

`C5(h) = max_d C[d_index] * dx`.

Boundary terms include only valid overlapping pairs, not circular cyclic lags. Do not introduce an invalid substitution into autocorrelation that changes these boundaries.

Feasibility:

`0 <= h[i] <= 1`

`sum h[i] * dx = 1`, or numerically

`sum h[i] = n/2`.

For binary `b[i] in {0,1}`, define `R = {i: b[i] = 1}`, `Z = {...}`. Then count values are

`A[d_index] = #{(i,j) in R x Z : i - j = d}`.

The objective is `max A * dx`. For half binary averages, counts become halves and exact continuity holds.

Derivative for continuous LP:

For lag `d`, write `f_d(h) = h[j+d] (1-h[j])`. The derivative row `G_d` has entries for each valid `j`:

`G_d[j+d] += 1 - h[j]`

`G_d[j] -= h[j+d]`

If a box cell affects two positions (which can occur at offset `d = 0` from diagonal terms), these updates accumulate. It is easiest topackage derivative construction by active lag.

Line-expansion coefficients:

For a direction `dvec`,

`score(t) = C0 + t T - t^2 Q`

where

`C0 = correlate(h, 1-h, "full")`

`T  = correlate(dvec, 1-h, "full") - correlate(h, dvec, "full")`

`Q  = correlate(dvec, dvec, "full")`

This is exact polynomial expansion. Acceptance compares actual exact score using max plus dx.
