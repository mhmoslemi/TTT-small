1. Approach and rationale

1.1 Central idea

The supplied parent is a continuous vector near the current record. The main difficulty is that the objective is the maximum of many finite-support bilinear overlap terms. Random directional line searches can correct the largest overlaps locally, but they cannot exploit a stronger global combinatorial structure. The proposed method therefore changes the primary source of new candidates: it searches on a binary level by minimizing submodular quadratic surrogates of the overlap problem by a directed min-cut solver. Those binary/genetic candidates are then transferred back to the continuous domain, averaged with the parent, and polished with exact-objective techniques.

1.2 Why this is materially different

The parent program mainly generated local directions with soft-max gradients, random Fourier/blocked perturbations, pair swaps, a simple simulated annealing on a binary threshold, and basin hopping. The new method introduces a separate global submodular step: for a set of active lags or distances, it solves an exact binary subproblem over all circularly balanced assignments. The exact binary binary assignment is not a heuristic and is not produced by simulated annealing. It solves a quadratic cut surrogate globally, under a scalar cardinality penalty, and afterwards candidates are accepted only if the original evaluator improves the bound.

The core change is: precise count-balanced global discrete optimization on lower-dimensional smoothed constraints followed by original-metric acceptance and continuous polishing. This can create new, well-spread patterns plus local refinement, as a way to escape the local plateau and allow global improvements.

1.3 Limitations and expected behavior

Because the submodular cut problem optimizes a weighted sum or distance-associated gas, not original overlapping quadratic terms in the exact weight of maximum over lags, it is not a solver for the original problem. Its candidate generation functions only. Every candidate that is rejected by the exact maximum overlap problem is discarded. The method is not an optimality proof.

The binary level changes direction because relaxation mismatched smooth weights and cardinality from constrained integrable. The method does not guarantee a new exact lag accept step. It does have high complexity allowing exact ways.
