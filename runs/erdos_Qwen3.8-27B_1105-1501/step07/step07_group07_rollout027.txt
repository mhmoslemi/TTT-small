def _push_relabel(n_nodes, adj, s, t):

    Push-relabel max-flow.
    adj: list of lists, adj[u] = list of [v, residual_cap, rev_index]

    height = [0] * n_nodes
    excess = [0] * n_nodes
    height[s] = n_nodes

    for i, [v, cap, _] in enumerate(adj[s]):

For a swap of positions i (1→0) and j (0→1), the change in the score at lag d is:
- The score at lag d is R_d = sum_k x_k (1-x_{k+d})
- After the swap, the positions that change are i and j
- The affected terms are:
  - From position i as the "first" index: term x_i(1-x_{i+d}) changes from 1*(1-x_{i+d}) = (1-x_{i+d}) to 0*(1-x_{i+d}) = 0
    Change: -(1-x_{i+d})
  - From position i as the "second" index (i.e., k+d=i, so k=i-d): term x_{i-d}(1-x_i) changes from x_{i-d}*1 = x_{i-d} to x_{i-d}*0 = 0
    Change: -x_{i-d}
  - From position j as the "first" index: term x_j(1-x_{j+d}) changes from 0 to 1*(1-x_{j+d}) = (1-x_{j+d})
    Change: +(1-x_{j+d})
  - From position j as the "second" index: term x_{j-d}(1-x_j) changes from x_{j-d}*0 = 0 to x_{j-d}*1 = x_{j-d}
    Change: +x_{j-d}

So the total change at lag d is:
ΔR_d = -(1-x_{i+d}) - x_{i-d} + (1-x_{j+d}) + x_{j-d}

def _project_sum(v, target):
    n = len(v)
    if target <= 0: return np.zeros(n)
    if target >= n: return np.ones(n)
    lo, hi = float(v.min()) - 1.0, float(v.max()) + 1.0

        else: hi = mid
    theta = (lo + hi) / 2.0

    if abs(res) > 1e-14:
