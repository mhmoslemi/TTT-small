1. Approach and rationale

The supplied parent is already close to the record, so a purely local continuation of the same heuristic is likely to stagnate. The new design attacks three independent bottlenecks instead of only polishing the parent:

A. Exact finite-sum feasibility is built into a large part of the search by using an anti-palindromic half-vector representation. For an even length `n = 2m`, any `x in [0,1]^m` yields a feasible full vector `h` of length `n` by setting the first half to `x` and the second half to the reversed complement of `x`. This satisfies `0 <= h <= 1` and `sum(h) = n/2` structurally, with no separate reopenable projection that silently changes the evaluated objective.

B. The main continuous optimizer is no longer only a fixed set of ad-hoc gradient line searches. A smooth-max mixed finite-difference/BFGS search in the anti-palindromic subspace is combined with an exact-sum one-dimensional minimax line search in full-dimensional spaces. C. Multiple resolutions are searched deliberately. The discrete objective includes the finite-support boundary terms and scaling by `2/n`, so the optimum ratio can depend on `n`.
