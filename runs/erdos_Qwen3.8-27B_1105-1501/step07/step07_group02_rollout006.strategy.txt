1. Approach and rationale

1.1 Central idea

The authorized discrete problem is

C5(h) = max_{r=0}^{2n-2} [np.correlate(h, 1-h, mode="full")[r]] * (2/n),

where h is an n-point vector satisfying

0 <= h_i <= 1,    sum_i h_i = n/2.

The supplied parent construction is already a high-quality local solution produced mainly by one-coordinate transfer or sparse pairwise motions. The proposed new algorithm breaks away from that structure by continuously and simultaneously moving many h_i values through dense, low-rank directions derived from the active overlap correlations.

The central algorithmic object is an active-correlation equalizing least-norm direction. For a current feasible h, several rows of the correlation vector R(h)=corr(h,1-h,full) are selected because they are close to the current maximum M(h). A linearized system is solved for a dense tangent movement d with sum(d)=0 so that, to first order, several selected correlation rows are moved toward a common lower active level. The exact objective along the same direction is then searched as a globally optimized maximum of quadratic slices using finite lags. Only candidates whose authoritative np.correlate score is smaller than the current score are accepted.

This materially differs from the previous parent strategy in that the primary update moves a coherent block of coordinates. It is not a single sink/source exchange or binary swap, and it does not rely on a coordinate transfer loop. It also differs from a generic epigraph nonlinear solve because no full epigraph variables or nonlinear programming solver machinery is required for the core step: a small linearized least-norm system gives a dense descent proposal, and the expensive higher-order nonlinear effects are handled exactly by one-dimensional exact correlation line search.

1.2 Why it can improve the supplied parent

The current objective is the maximum of 2n-1 finite-support quadratic functions. When the maximum is controlled by several near-active lags, a good local move often must reduce those lags together. Sparse face coordinate transfers can have the following defect: moving one coordinate reduces the top lag but increases another, forcing the line search into an extremely small step. A dense direction matching the active row gradients can cause a larger simultaneous reduction. 1. APPROACH AND RATIONALE

1.1 Central idea

The task is to minimize the finite-support directed overlap objective

C5(h) = max_r R_r(h) * dx, where R(h) = np.correlate(h, 1 - h, mode="full"), dx = 2/n,

subject to the exact feasibility constraints

0 <= h_i <= 1 for all i,    sum_i h_i = n/2.

The supplied parent construction is a high-quality local solution produced mainly by one-coordinate transfers or sparse discrete movements. Its main bottleneck is structural: a single or pairwise move changes too few coordinates to reduce several active correlation rows coherently. The proposed method improves this by moving many coordinates simultaneously through dense, low-rank directions derived from multiple active correlation rows.

At each local iteration, a set of top/near-top correlation rows is selected. The algorithm solves a small weighted least-norm linearized system for a dense zero-sum direction d that would, at first order, move those selected correlation rows toward a lower common active level. The exact continuous slice of the original finite-support objective along that same direction is

max_r [R_r(0) + t A_r - t^2 B_r],

where

A_r = corr(d, 1-h, full)_r - corr(h, d, full)_r,
B_r = corr(d, d, full)_r.

The optimizer performs an exact line search over all feasible scalar steps t subject to the box constraints h_i + t d_i in [0,1], and always re-evaluates accepted moves using the authoritative np.correlate objective. This is fully nonconvex and local, but it can escape sparse-move traps by moving many coordinates together.

1.2 Why the new method can improve on the supplied parent

The objective is the maximum of 2n-1 quadratic functions. The current optimum is likely to have many near-active lags each depending on overlapping coordinate sum terms. A one-dimensional transfer or binary swap perturbs only two coordinates and often improves the chosen active row while creating a new overshoot elsewhere. The dense active-row direction is intended to reduce a local choice of active rows collectively. After solving the least-norm direction, the exact quadratic line search, rather than a surrogate, chooses the step and verdict.

The method does not claim global optimality. It can only certify a lower C5 value when an accepted move is checked by the original evaluator.

1.3 Main structural distinction from regular constructions

The central change is not a renamed step or a simple parameter sweep. The dense movement direction is obtained by solving a weighted extremal linearized system with several top-row constraints and a mass-conservation constraint.
