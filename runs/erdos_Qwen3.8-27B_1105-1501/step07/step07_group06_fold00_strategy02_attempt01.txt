1. Approach and rationale

The parent is already very close to the record, so merely running another local smooth-max gradient or single-solution simulated annealing trajectory is likely to only polish the parent and not explore the other extremal balanced binary basins that are known to drive the discrete problem. The new main idea is a population-based memetic search over strictly balanced binary sequences, combined with exact finite-grid objective evaluation and a final continuous low-dimensional smoothing stage.

The central claim is practical, not global-optimal: for this finite evaluator, a set of balanced wire signals and exact pairwise-exchange operators can efficiently sample away from the parent, while the supplied parent and the best exact candidate found by the method are retained as valid upper bounds. Binary candidates satisfy the exact cardinality constraint by construction, and recombination/mutation are designed to preserve the exact number of ones. Any discontinuous binary candidate that looks promising is then converted to a feasible continuous vector and polished using smooth/line-search methods. The final answer is always re-evaluated with the original evaluator.

This differs from the parent and from earlier proposed approaches in three substantive ways:

- The global search is not centered on one trajectory. It maintains a population of balanced binary parents and children selected from more than 60 candidates through finite exact scores and diversity/local archiving. It is not simply an additional smooth-max direction.
- Population diversity comes from cardinality-preserving recombination and swap mutations, which are exact and particularly suited to this zero-one form. Greedy local improvements are run only on promising children, so each step evaluates exact binary candidates but not massive all-pair exhaustives.
- The method transfers binary search into continuous improvement: promising binary solutions are expanded via complement-preserving compression to fractional values and then polished by an exact line search along finite gradients. This is used only as local finishing work, not as the only search.

Justified facts:

- The evaluator only sees the returned vector and the exact finite correlation of `h` with `1-h`. A method that optimizes a surrogate but never rechecks this objective is invalid. Since every stored candidate here is checked with the exact formula, no surrogate value is treated as a bound.
- Binary balanced vectors automatically satisfy `sum(h) = n/2` when the count of ones is `n/2`. The genetic operators are presented to guarantee exact feasibility as well.
- Multiple geometric lengths are studied because the correlation boundary terms scale with `dx = 2/n`, and the exact finite-grid optimum may improve at different lengths. Returning a shorter vector is permitted but not forced if that worsens the exact bound.
- The method is explicitly nonconvex and only local. No global optimality is claimed.

Major limitations:

- Binary search can roll into sub-optimal boundary optimum, and many offers may all map to the same objective score. Population diversity and auxiliary tie-breaking pass through the high-score region and weakens tabu; GA--Local rejects some sometimes; If the continuous support is limited. The main basis is possible extension of line DP and the GA method.

The search’s physical key is that the recorded parent gets an independent exploration process, not a copy-and-raise. Local enough prior exact derivatives and allowed to constrain binary forces on initial, sibling, different but close initial times. Genetic recombination that swaps between good candidate runs creates many possibilities far from the parent’s Gleason support treatment.
