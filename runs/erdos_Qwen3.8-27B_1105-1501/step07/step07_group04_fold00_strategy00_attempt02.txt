1. Approach and rationale

The previous program reached about 0.380889 by combining full-domain projected subgradient steps, binary simulated annealing, pair swaps, block swaps, and multi-size attempts. The main bottlenecks are that (a) full-domain optimization is dominated by random moves and used generic projections that can break the value but not the balance, (b) the binary state space is large, and (c) the exact objective is nonsmooth and bilinear, so purely smooth objective methods do not reliably improve the maximum overlap unless they are tightly tied to the original correlation objective.

The new algorithm keeps the same exploration workflow but focuses on three complementary improvements:

1. Symmetric half-parameterization.
   The discrete overlap objective is naturally invariant under the operation
   \[
   (Sh)_i = 1-h_{n-1-i}.
   \]
   If we represent \(h\) only by first-half values \(v_j\), with
   \[
   h_i=v_i,\quad i=0,\dots,n/2-1,
   \]
   and
   \[
   h_{n-1-i}=1-v_i,
   \]
   the constraint \(\sum_i h_i=n/2\) is automatically satisfied, for even \(n\), without projection. This turns the problem into a nonnegative bounded problem with fewer variables. It also lets us use a smooth-log-sum-exp (LSE) objective with analytical gradients and L-BFGS-B under only box constraints.

2. Convex trust-region direction for the full symmetric problem.
   At a continuous \(h\), the correlations as a function of a feasible displacement are locally linearized. Keeping only the active or near-active lag inequalities and minimizing a convex quadratic-over-approximately-linear trust-region problem gives a nontrivial non-maximizing trust-region direction. Because it is a convex QP, it can replace the generic subgradient direction used before, but the real solution is always accepted only by the original exact objective period.

3. Discrete refinement using exact objective on the symmetric balanced variables.
   Flipping an entire symmetric pair is automatically feasible and does not require a pair swap to preserve balance. We can explore the binary complementary-pair space efficiently and use a non-symmetric binary pair localhost full domain. These local optimizers maintain integer-feasible exact drivers on the returned candidate.

4. Deterministic multi-init global smooth search.
   Use groups of deterministic starts: symmetrized parent, binary symmetric parent, low rational/axisym mirror transformations, periodic permutations. Each start undergoes beam internal tau schedule and final hard activation acceptance. The subspace methods get survival value from local optimization, and the sym starts can quickly explore symmetric low overlap constructions closer to the possible nonconvex peak frame.

This is richer than a direct CVXPY call on the original quasiconvex objective because the core method exactly evaluates the task objective for all steps and adopts a high-order real variable model after running intensive symmetric programmable methods.

Running this model should better reach the symbolic solution found in the approx value set, and guarantees less memory time over that approximate parent.
