- Quadratic when they are paired (i+D=j or j+D=i or D=0 with i=j which is excluded, or the self-pair)

This means C(t) = max_k (quadratic or linear in t) is convex but not piecewise-linear. It's piecewise where each piece is either linear or quadratic.

Hmm, this makes the optimization a bit harder. But it's still a 1D convex minimization, so golden section search works perfectly.

For the golden section search, I need to evaluate C(t) at arbitrary t values. To do this:
1. Compute the base scores: S_k = correlate(h, 1-h, 'full')
2. For a given t, compute the adjusted scores: S'_k = S_k + delta_k(t)
   where delta_k(t) accounts for the change at positions i and j.

The delta at each k:
- Terms involving i: (h[i]+t) replaces h[i] in all products
- Terms involving j: (h[j]-t) replaces h[j] in all products
- If both i and j appear in the same product (i.e., i+D=j or j+D=i), there's a cross term.

Let me compute delta_k(t) explicitly:

For lag D (correlation index k = n-1+D):
The base term sum is S_k = sum_m h[m]*(1-h[m+D])

The new sum is S'_k = sum_m h'[m]*(1-h'[m+D]) where h'[i]=h[i]+t, h'[j]=h[j]-t, h'[m]=h[m] elsewhere.

The difference S'_k - S_k comes from terms where m ∈ {i,j} or m+D ∈ {i,j}.

Let me define:
- A = set of m where h'[m] ≠ h[m] = {i, j}
- B = set of m where h'[m+D] ≠ h[m+D] = {m-D : m ∈ {i,j}} = {i-D, j-D}

The affected m values are A ∪ B = {i, j, i-D, j-D}.

For each m in (A ∪ B) that is valid (0<=m<n, 0<=m+D<n):
  old = h[m] * (1-h[m+D])
  new = h'[m] * (1-h'[m+D])
  where h'[x] = h[x]+t if x==i, h[x]-t if x==j, h[x] otherwise.

This gives delta_k(t) as a function of t. It's at most quadratic (when both i and j appear in the same product).

For the golden section search, I'll just evaluate C(t) directly at each trial point. The evaluation is O(n) (compute delta for all k). With ~30 golden section iterations, that's O(30n) per pair. For n=128, that's ~4000 operations per pair. Very fast.

def _pair_minimize(h, i, j, base_scores, n):
    """Find t that minimizes C5 for the pair move h[i]+=t, h[j]-=t.
    base_scores = correlate(h, 1-h, 'full') (without dx factor)
    Returns (best_t, best_max_corr)."""
    dx = 2.0 / n
    # Feasible range
    t_min = max(-h[i], h[j] - 1.0)
    t_max = min(1.0 - h[i], h[j])
    if t_max - t_min < 1e-12:
        return 0.0, float(np.max(base_scores))
    
    def c_at_t(t):
        # Compute max of (base_scores[k] + delta_k(t)) for all k
        # delta_k(t) is the change in correlation at index k due to the pair move
        max_c = 0.0
        for D in range(-(n-1), n):
            k = n - 1 + D
            delta = _delta_k(h, i, j, D, t, n)
            val = base_scores[k] + delta
            if val > max_c:
                max_c = val
        return max_c * dx
    
    # Golden section search
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    lo = t_min
    hi = t_max
    c1 = hi - gr * (hi - lo)
    c2 = lo + gr * (hi - lo)
    f1 = c_at_t(c1)
    f2 = c_at_t(c2)
    for _ in range(25):
        if hi - lo < 1e-10:
            break
        if f1 < f2:
            hi = c2; f2 = f1; c2 = c1
            c1 = hi - gr * (hi - lo); f1 = c_at_t(c1)
        else:
            lo = c1; f1 = f2; c1 = c2
            c2 = lo + gr * (hi - lo); f2 = c_at_t(c2)
    opt_t = (lo + hi) / 2.0
    opt_c = c_at_t(opt_t)
    return opt_t, opt_c
