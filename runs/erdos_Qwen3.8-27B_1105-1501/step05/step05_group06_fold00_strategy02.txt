1.1 Central observation

The provided evaluator defines the target for a one-dimensional array `array h[i]` of length `n` as

    dx = 2.0 / n
    scores = dx * np.correlate(h, 1.0 - h, mode="full")
    C5 = max(scores)

under the constraints `0 <= h[i] <= 1` and `sum(h) = n/2`. The supplied parent is already extremely close to the quantitative goal, so a generic global solver is unlikely to be useful. What remains is a high-precision exploitation problem inside a complicated non-smooth bilinear optimization landscape.

The proposed method departs from linearized pair-move or smooth p-norm/SLSQP-only workflows by making a discrete, globally seeded search the first exploitable step. The exact evaluator is binary-valued to the extent that many useful configurations are near 0/1, with small fractional corrections. Designing purely with continuous first-order methods gets stuck on plateaus; a constrained 0/1 search, followed by simultaneous support-aware continuous line shaving, reaches a different set of local basins and allows small continuous corrections on the basin discovered.

This plan is experimentally motivated, not proven globally optimal. It returns only candidates verified directly with the official exact evaluator. Its precise limitations are:

- the binary simulated annealing phase is a stochastic combinatorial heuristic; it is not exhaustive and does not certify global optimality;
- the support polish phase is exact only in terms of acceptance (final admissibility is tested with `np.correlate` and the mass repair operator), but it can terminate in a local minimum;
- changing the sampling length `n` changes the discrete value by approximating it closer to the continuous piecewise constant representation, and smaller groups may yield faster evaluation and sometimes shorter bounds; the best feasible exact result is returned.

If the target is not reached, the initially supplied parent - explicitly repaired and measured - remains the returned safe fallback.
