1. Approach and rationale

1.1 Central idea
The supplied parent construction is a balanced, bounded continuous discretization. The previous search over plausible local weighted-linear directions can approach a tight local minimum but has limited ability to change topology because every proposed step is a small convex combination with an LP/weighted-gradient predictor. This new method proposes a different class of large moves: at each cycle it forms a directed, balanced-overlap surrogate whose binary minimizers can be found globally by an s-t min-cut problem with a cardinality (exact half-mass) approximate solution. The surrogate is not a relaxation claiming global optimality for the original objective. It is a candidate generator for balanced topological moves. Every candidate is only accepted after direct evaluation of the authoritative objective `max(np.correlate(h, 1-h, full)) * 2/n`. This allows a single run to escape narrow local valleys relative to the parent and to explore different support patterns.

1.2 Why this may improve the task
The exact objective is a maximum over all shifts. The previous first-order descent algorithms mostly move existing fractional mass. The majorized directed cut method can move and reshuffle entire one/zero support patterns while respecting average mass by using parametric min-cuts with cardinality. For a fixed set of active shifts, the weighted sum of overlap objective functions is directed-cut representable on binary variables. A min-cut over that surrogate can make large nonlocal adjustments. The output variable is allowed to be continuous by combining balanced binary solutions and by constrained convex interpolation; this lets the candidate exploit both discrete supports and fractional plateaus while retaining a provably feasible `sum = n/2` repair mechanism.

1.3 Secondary refinement
A direct minimax nonlinear solver formulation is implemented as a polish: minimize `t` subject to exact-overlap constraints `C_j(h) <= t`, `sum(h) = K`, and `0 <= h_i <= 1`. This is supported by `scipy.optimize.minimize(method="SLSQP")` as a local function with analytic constraints. It uses the same evaluator orientation and can refine active differences missed by the majorized candidate moves. This minimax formulation is materially different from projecting a weighted gradient; it treats the current objective as an auxiliary-variable constraint and computes its exact gradient. It also does not assert global optimality. It returns a candidate only after the original unrestricted score is re-evaluated.

1.4 Bottleneck addressed
A small number of small-radius continuous directions can stagnate when several active lags have nearly balanced coordinates. The majorization subproblem solves a globally optimum binary approximation to a sum of active constraints, not an approximate first-order step. The combination of (1) many binary structural moves, (2) midpoint interpolation between over- and under-count cuts, and (3) direct semi-active minimax polishing creates a hybrid local search that can move through constrained valleys.
