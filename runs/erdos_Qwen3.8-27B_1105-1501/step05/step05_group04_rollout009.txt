This is a necessary condition for the discrete optimum. If we can find a direction d such that:
- d is in the null space of the active constraints (d is orthogonal to all active gradients, approximately)
- d decreases the objective (second-order improvement)

...then we can improve.

But this is essentially what the LP approach does. The issue is that near the optimum, the LP might not find a useful direction because the active set is large and the feasible direction set is small.

Alternative: Use a second-order method. The Hessian of the smoothing objective is:
H = G^T @ (diag(p) - p*p^T)/beta @ G

This is the "natural gradient" of the log-sum-exp. It's positive semi-definite (it's the covariance of the distribution p under the metric G). So the smoothing objective is locally convex (in the Riemannian sense), and Newton's method would converge quickly.

    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def lag_values(h):
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def project_box_sum(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo = float(v.min()) - 2.0
    hi = float(v.max()) + 2.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-12:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def lag_jacobian(h):
    n = len(h)
    dx = 2.0 / n
    G = np.zeros((2*n-1, n))
    for k in range(-(n-1), n):
        r = k + n - 1
        if k >= 0:
            G[r, k:] += dx * (1.0 - h[:n-k])
            G[r, :n-k] += -dx * h[k:]
        else:
            a = -k
            G[r, :n-a] += dx * (1.0 - h[a:])
            G[r, a:] += -dx * h[:n-a]
    return G

def smooth_obj_and_grad(h, beta):
    F = lag_values(h)
    m = float(np.max(F))
    z = (F - m) / beta
    z = z - np.max(z)
    exp_z = np.exp(z)
    S = float(np.sum(exp_z))
    obj = m + beta * np.log(S)
    p = exp_z / S
    G = lag_jacobian(h)
    grad = G.T @ p
    return obj, grad

Wait, I need to be careful. The smoothing objective phi_beta(h) = m + beta * log(sum exp((F_k - m)/beta)) is what we want to minimize. Its gradient is sum_k p_k * grad F_k = G^T @ p.

But there's a subtlety: m = max(F) depends on h, so d(phi)/dh includes the derivative of m. However, since m = max(F) and the max is achieved at some index k*, we have:
d(phi)/dh = d(m)/dh + beta * (1/S) * sum_k exp((F_k-m)/beta) * (dF_k/dh - dm/dh)
= dm/dh + (1/S) * sum_k exp((F_k-m)/beta) * dF_k/dh - (1/S) * sum_k exp((F_k-m)/beta) * dm/dh
= dm/dh + (G^T p) - (sum p_k) * dm/dh
= dm/dh + G^T @ p - dm/dh
= G^T @ p

So the gradient is indeed G^T @ p, and the max term cancels out.
