For the gradient approach:

For a soft-max with temperature β:

= (1 - h[i+d]) * [i+d < n and i >= max(0,-d) and i < min(n,n-d)] - h[i-d] * [i-d in valid range]

Actually, for the two-coordinate problem, the "gradient" with respect to δ for pair (i,j) is:

where a_d(i,j) is the coefficient we computed above (the derivative of S_d with respect to δ for this specific pair).

So the best pair to try is the one that minimizes Σ_d w_d * a_d(i,j), i.e., the pair where the weighted sum of directional derivatives is most negative.

This is equivalent to: for each i, compute g_i = Σ_d w_d * (∂S_d/∂h[i]), then the best pair is (i*, j*) where g_i* is most positive and g_j* is most negative (or we want to minimize g_i - g_j, which is the directional derivative for the move h_i += δ, h_j -= δ).

Wait, the directional derivative for the move "increase h_i by δ, decrease h_j by δ" is:
Σ_d w_d * (∂S_d/∂h_i - ∂S_d/∂h_j) = g_i - g_j

So we want to minimize g_i - g_j, i.e., maximize g_j - g_i, so we want i with large g_i and j with small g_j.

The best pair is: i* = argmax g, j* = argmin g. And the best δ direction is from i* to j*.

But this is a greedy approach - it might not find the globally best pair. In practice, we can try the top K pairs.

    n = len(h)
    dx = 2.0 / n
    scores = _scores(h)
    # Soft-max weights
    max_s = np.max(scores)
    exp_s = np.exp(beta * (scores - max_s))
    w = exp_s / np.sum(exp_s)  # w[d_idx] for d_idx = 0, ..., 2n-2, where d = d_idx - (n-1)
    
    # For each i, compute g_i = sum_d w[d_idx] * dx * [(1-h[i+d])*1{0<=i+d<n} - h[i-d]*1{0<=i-d<n}]
    g = np.zeros(n)
    for i in range(n):

            d = d_idx - (n-1)
            val = 0.0
            if 0 <= i+d < n:
                val += (1.0 - h[i+d])
            if 0 <= i-d < n:
                val += -h[i-d]
            g[i] += w[d_idx] * val
    g *= dx
    return g

    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _scores(h):
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo = float(v.min()) - 2.0
    hi = float(v.max()) + 2.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    x = np.clip(v - (lo + hi) / 2.0, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-12:

        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))

        if best_pair is not None and best_new_c5 < best_c5 - 1e-14:
            i, j = best_pair
            h[i] += best_delta
            h[j] -= best_delta
            h = np.clip(h, 0.0, 1.0)
            h = _project(h, n / 2.0)
            actual_c5 = _exact_c5(h)
            if actual_c5 < best_c5:
                best_c5 = actual_c5
                best_h = h.copy()
            stall = 0
            improved = True
        else:
            stall += 1
    
    return best_h, best_c5
