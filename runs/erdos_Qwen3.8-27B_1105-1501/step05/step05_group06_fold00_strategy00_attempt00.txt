1. Approach and rationale
=========================
The current parent construction is close to a local optimum. The previous approach mainly used linearized movement directions, top-lag subgradients, and approximate pair moves; their exact-line predictions omitted the second-order effect generated when the two paired entries themselves appear in the same lag term. For a vector `h`, a transfer of mass between two indices is the most essential feasible direction compatible with finally maintaining the discrete mass exactly. Along any such two-index transfer, the exact finite-support correlation scores are not merely approximately linear: each lag score is a quadratic function with a nonnegative quadratic coefficient or a linear function, and their maximum is convex over the feasible transfer interval. This gives an exact one-dimensional convex subproblem for every pair move, even though the original problem is nonconvex because of products `h_i h_j`.

The proposed method therefore uses the exact discrete evaluator as the fundamental measurement device. It repeatedly verifies candidate transfers using the vectorized correlation objective and replaces approximate pair descent with exact pair minimization. Major points:

* For a pair move `h_a += alpha`, `h_b -= alpha`, the feasible interval for `alpha` is explicit, and the exact objective along this interval is a maximum of convex quadratics/lines.
* Exact gradient information is still useful for generating promising pairs, but acceptance is always decided by full vectorized evaluation.
* The method maintains the mass exactly: every accepted local move changes two entries by opposite amounts, and final outputs are restored with a joint projection, not by clip-plus-rescale.
* Search is seeded from the supplied parent, but also includes nearby perturbations, multi-resolution transformations, and exact-pair polishing. Larger resolutions provide better mass allocation; smaller resolutions can find structured basins with fewer grid artifacts. The fallback always returns a valid feasible parent if local search fails.

The exact pair-descent is the novelty: it replaces approximate coordination steps with a repair-free, exact convex line search. This approach is heuristic; it is not a proof of global optimality, but every returned result is an exact upper-bound candidate for the specified discrete evaluator.

2. Mathematical specification
=============================
2.1 Representation and evaluator
---------------------------------
For length `m`, input displacement is `dx = 2.0 / m`. Feasible vectors satisfy
```
0 <= h[i] <= 1, sum_i h[i] = m / 2.
```
The exact score vector is
```
score_v = np.correlate(h, 1 - h, mode='full') * dx,
C5(h) = max(score_v).
```
The output vector has size `L = 2m - 1`. The interpretation of row indices used below is consistent with NumPy's linear correlation ordering used by the evaluator.

2.2 Feasible set and objective
-----------------------------
The objective is nonconvex due to terms `h_i * (1 - h_j)` and hence products `h_i h_j` where `i + offset = j`. A feasible move preserving the sum is
```
h(alpha) = h + alpha*(e_a - e_b),
```
with `a != b`. Constraints `0 <= h_i <= 1` imply
```
upper_gain    = 1 - h[a]
lower_gain    = -h[a]
upper_loss    = h[b]
lower_loss    = h[b] - 1
alpha_min     = max(lower_gain, lower_loss)
alpha_max     = min(upper_gain, upper_loss)
```
If the interval has width below a numerical tolerance, the pair is skipped. A transfer in the opposite direction is covered by allowing negative `alpha` in the same notation.

2.3 Exact one-dimensional path
------------------------------
Let `S_r(h)` be row `r` of the score vector (not the maximum, just the component). For
```
h(alpha): h_a -> h_a + alpha, h_b -> h_b - alpha,
```
each correlation component can be written exactly as
```
S_r(alpha) = S_r(0) + alpha * (G[r,a] - G[r,b]) + q_r(alpha),
q_r(alpha) = dx*alpha^2   if r equals the two rows in which the unordered pair {a,b} occurs,
q_r(alpha) = 0           otherwise.
```
There are exactly two such rows for `a != b`: one corresponding to `a-b` and one to `b-a`. Use row indices
```
row_pos = m - 1 + (a - b),
row_neg = m - 1 - (a - b).
```
These are valid because `|a-b| <= m-1`. The coefficient `dx` is correct because `G` below is constructed for the already-DP-scaled `S_r` score rows, not for raw correlation counts.

The line objective is
```
F_{a,b}(alpha) = max_r S_r(alpha).
```
Each component is a line (`q_r=0`) or a convex quadratic (`q_r=dx*alpha^2>=0`). The maximum of convex functions is convex. Hence `F_{a,b}` is convex on `[alpha_min, alpha_max]`. Every minimum is global along the pair line.

The path preserves the sum exactly due to `+alpha` and `-alpha`. If floating contexts create mass drift only from acceptance choices held outside the pair move, it can be repaired at the end; stored accepted pair states should avoid clipping and use the exact interval endpoints.

2.4 Exact gradient matrix
------------------------
For exact calculation: for each score row `r`, define `A[r,i] = d S_r / d h[i]`. It matches the correlation evaluator ordering. Implement it as follows:
* Set `A[r,i] = dx * (1 - 2*h[i])` for `r = m - 1`.
* For positive lag `d` from `1` to `m - 1` (first argument index exceeds second by `d`), row `r = m - 1 + d` has terms
```
h[i+d] * (1 - h[i]), i=0..m-d-1.
```
Set `A[r, d:] += dx * (1 - h[:m-d])` and `A[r, :m-d] += -dx * h[d:]`.

```

```
