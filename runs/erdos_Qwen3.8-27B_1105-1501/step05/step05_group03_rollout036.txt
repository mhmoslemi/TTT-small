One important detail: for the L-BFGS-B inner loop, I need to provide the gradient of the AL objective. Let me make sure this is correct.

AL objective:
L(h, t) = t + (μ/2) * Σ_k [max(0, s_k - t)]² + (ν/2) * (Σ h_i - target)² + λ * (Σ h_i - target)

where s_k = dx * score_k = dx * corr[k], corr = np.correlate(h, 1-h, 'full')

Gradient:
∂L/∂t = 1 - μ * Σ_k max(0, s_k - t)
∂L/∂h_j = -μ * Σ_k max(0, s_k - t) * dx * G[k,j] + ν * (Σ h_i - target) + λ

where G[k,j] = ∂corr[k]/∂h_j (the gradient of the raw correlation without dx).

Let me define:
w_k = max(0, s_k - t) (the violation amount for constraint k)

Then:
∂L/∂t = 1 - μ * Σ_k w_k
∂L/∂h_j = -μ * dx * Σ_k w_k * G[k,j] + (ν * (sum(h) - target) + λ)

The term Σ_k w_k * G[k,j] is the j-th component of the vector w^T @ G, where w has shape (2n-1,) and G has shape (2n-1, n).

This can be computed efficiently:
- Compute G (the full gradient matrix): O(n²)
- Compute w^T @ G: O(n²)

Total gradient computation: O(n²) which is fine for n=128.

```python
import numpy as np
from scipy.optimize import minimize
import time

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo = float(v.min()) - 2.0
    hi = float(v.max()) + 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    x = np.clip(v - (lo + hi) / 2.0, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-12:
        mask = (x < 1.0) if res > 0 else (x > 0.0)
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += res / cnt
    return np.clip(x, 0.0, 1.0)

def _grad_matrix(h):
    """G[k, j] = d(corr[k]) / dh[j] where corr = np.correlate(h, 1-h, 'full')"""
    n = len(h)
    G = np.zeros((2 * n - 1, n))
    one_h = 1.0 - h
    # k = n-1 corresponds to d=0
    G[n - 1, :] = 1.0 - 2.0 * h
    # For d > 0: k = n-1+d
    for d in range(1, n):
        m = n - d
        G[n - 1 + d, :m] += one_h[d:]
        G[n - 1 + d, d:] -= h[:m]
        # For d < 0: k = n-1-d
        m2 = n - d
        G[n - 1 - d, d:] += one_h[:m2]
        G[n - 1 - d, :m2] -= h[d:]
    return G
```
