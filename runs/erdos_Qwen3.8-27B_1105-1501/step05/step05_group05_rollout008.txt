Let me also think about **Anderson acceleration** for the fixed-point iteration:

The LSE gradient descent can be viewed as a fixed-point iteration: h_{k+1} = P(h_k - α * ∇f(h_k)) where P is the projection.

Anderson acceleration maintains a history of {x_k, F(x_k)} and extrapolates to accelerate convergence.

Simple version (Anderson-1):
- Keep x_prev, g_prev
- x_new = x_k + ω * (x_k - x_prev) where ω is chosen to minimize ||F(x_new)||
- F(x) = x - P(x - α*∇f(x)) (the fixed-point residual)

This can give 2-5x speedup.

Let me also think about **Barzilai-Borwein step size**:
α_k = (Δx)·(Δg) / ||Δg||² (BB-min or BB-max)
where Δx = x_k - x_{k-1}, Δg = g_k - g_{k-1}.

This often gives much better step sizes than fixed α.

def _grad_score_lag(h, d):
    """Gradient of score for lag d with respect to h."""
    n = len(h)
    g = np.zeros(n)
    if d >= 0:
        m = n - d
        if m > 0:
            g[:m] += (1.0 - h[d:d+m])
            g[d:] += -h[:m]
    else:
        g2 = -d
        m = n - g2
        if m > 0:
            g[:m] += -h[g2:g2+m]
            g[g2:] += (1.0 - h[:m])
    return g

def _grad_lse(h, beta, top_m=0):
    """Gradient of log-sum-exp (or top-m) of scores, centered to zero-sum."""
    n = len(h)
    s = _scores(h)
    if top_m > 0:
        # Hard top-m weighting
        idx = np.argsort(s)[::-1][:top_m]
        s_max = s[idx[0]]
        w = np.zeros(len(s))
        w[idx] = 1.0 / top_m
    else:
        s_max = float(np.max(s))
        v = beta * (s - s_max)
        exp_v = np.exp(v)
        w = exp_v / float(np.sum(exp_v))
    
    grad = np.zeros(n)
    for r in range(2*n-1):
        if w[r] < 1e-15:
            continue
        d = r - (n-1)
        g = _grad_score_lag(h, d)
        grad += w[r] * g
    grad -= grad.mean()
    return grad, s
