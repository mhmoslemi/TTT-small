1. Approach and rationale

1.1 Central idea

The supplied parent is already close to a local optimum for earlier LP/tangent direction + pair-search methods. The improvement target (`< 0.38085`, ideally `< 0.3808`) is therefore more likely to require coordinated, high-dimensional, non-linear moves than simple local infinitesimal transfers. The proposed central search mechanism is therefore deliberately different: 

- Use a differentiable soft-max surrogate of the finite-lag maximum, with analytic gradients, and solve the smoothed high-dimensional constrained problem using a standard constrained gradient optimizer (`SLSQP`).
- Generate multiple diverse feasible starting vectors from the parent, including projection-repaired smooth low-frequency, mirror-shifted, and random perturbations.

2. Mathematical specification

2.1 Exact problem, objective, and indexing

A candidate is a length `n` cell vector `h` representing samples on the length-2 interval. Define:

- `dx = 2 / n`.
- `target = n / 2`.
- objective using official evaluation:
  `C5(h) = dx * max(np.correlate(h, 1 - h, mode='full'))`.

This formula includes all `2n - 1` finite correlations, both positive/negative offsets; all boundary truncations are evaluated by the same function. Do not replace this by periodic/circular correlation. All integers `n` allowed though preferred adaptive grid even for fixed target integer.

The proposal internally interprets the unmultiplied score as the finite-lag vector. Define row index `r = 0, ..., 2n-2`, signed offset `d = r - (n-1)`:

- For `d >= 0`, `m = n - d`; score row `S[d] = sum_{j=0}^{m-1} h[j+d] * (1 - h[j])`.
- For `d < 0`, let `g = -d`; `m = n - g`; `S[d] = sum_{j=0}^{m-1} h[j] * (1 - h[j+g])`.
- Exact scaled score is `dx * S[d]`. This matches the official expansion orientation used below. A small implementation sanity check (`soft objective gradient` test) confirms internal orientation. The final objective always calls `np.correlate` and maxima.

The candidate pool may have final vector lengths different than parent; every candidate vector's objective is intrinsic to its length and `dx`, and parent fallback always survives supporting comparisons. Exact formula is consistent across lengths.
