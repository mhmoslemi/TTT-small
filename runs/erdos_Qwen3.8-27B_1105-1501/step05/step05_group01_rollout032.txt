But wait, we can be smarter. The minimum of max of linear functions on [0,1] can be found by:
- Binary search on the value: for a given value v, check if there exists x in [0,1] such that A_k + B_k * x <= v for all k. This is feasible iff max_k A_k <= v and min_k (A_k - v)/(-B_k) constraint... actually this is a feasibility problem in 1D.

For a given v: A_k + B_k * x <= v for all k means:
- If B_k > 0: x <= (v - A_k) / B_k
- If B_k < 0: x >= (v - A_k) / B_k  [i.e., x >= (A_k - v) / (-B_k)]
- If B_k = 0: A_k <= v

So the feasible set for x is [max_{B_k<0} (A_k-v)/(-B_k), min_{B_k>0} (v-A_k)/B_k] ∩ [0,1].

def _coord_optimize(h, i, scores):
    """Find optimal value of h[i] given all other coordinates fixed.
    Returns (new_value, new_scores) or (None, scores) if no improvement."""
    n = len(h)
    cur = h[i]
    dx = 2.0 / n
    
    # Compute B_k for all lags
    # scores = np.correlate(h, 1-h, mode='full') has 2n-1 entries
    # Entry j corresponds to lag q = j - (n-1)
    B = np.zeros(2*n-1)
    for j in range(2*n-1):
        q = j - (n-1)
        if q >= 0:
            # S_q = sum_m h[m+q]*(1-h[m])
            in_first = (q <= i <= n-1)  # i appears as h[m+q]
            in_second = (0 <= i <= n-1-q)  # i appears as h[m]
            if in_first and in_second:
                B[j] = 1.0 - h[i-q] - h[i+q]
            elif in_first:
                B[j] = 1.0 - h[i-q]
            elif in_second:
                B[j] = -h[i+q]
            else:
                B[j] = 0.0
        else:
            g = -q
            # S_{-g} = sum_m h[m]*(1-h[m+g])
            in_first = (0 <= i <= n-1-g)  # i appears as h[m]
            in_second = (g <= i <= n-1)  # i appears as h[m+g]
            if in_first and in_second:

            elif in_first:
                B[j] = 1.0 - h[i+g]
            elif in_second:
                B[j] = -h[i-g]
            else:
                B[j] = 0.0

    f0 = float(np.max(A))
    f1 = float(np.max(A + B))
    
    v_lo = float(np.min(np.minimum(A, A+B)))  # lower bound on optimal v

    # Simplest: just use v_lo = min(f0, f1) - 0.5 (should be below optimum)

    # >= min_k min(A_k, A_k+B_k)
    v_lo = float(np.min(np.minimum(A, A + B)))

    best_x = cur if cur >= 0 and cur <= 1 else 0.5
    best_val = max(f0, f1)
    if f0 < best_val:
        best_val = f0
        best_x = 0.0
    if f1 < best_val:
        best_val = f1
        best_x = 1.0
