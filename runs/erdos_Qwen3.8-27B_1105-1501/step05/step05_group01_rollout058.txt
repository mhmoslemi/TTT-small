- Remove: (1-h[i+s]) [if i+s < n] + h[i-s] [if i-s >= 0]
- Add: (1-h[j+s]) [if j+s < n] + h[j-s] [if j-s >= 0]

But wait, after the swap, h[i] becomes 0 and h[j] becomes 1. So the correlations involving i and j as the "other" position also change. Let me be more careful.

Original corr at lag s (s > 0): sum_{i=0}^{n-1-s} h[i]*(1-h[i+s])

After swap (h[i] 1→0, h[j] 0→1):
New corr at lag s = sum of the same terms, but:
- If 0 <= i < n-s: the term at position i goes from h[i]*(1-h[i+s]) = 1*(1-h[i+s]) to 0*(1-h'[i+s]) where h' is after swap.
  - If i+s != j: new term = 0
  - If i+s == j: new term = 0*(1-1) = 0 (same)
- If i+s >= 0 and i+s < n: the term h[i-s]*(1-h[i]) at the position where the "second" index is i goes from h[i-s]*(1-1) = 0 to h'[i-s]*(1-0) = h'[i-s].
  - If i-s != j: new term = h[i-s] (since h[i-s] unchanged)
  - If i-s == j: new term = h'[j] = 1 (was h[j] = 0 before, so it changes from 0*... wait)

This is getting really messy. Let me just do the O(n) recompute. For n=156, it's fast enough.

Actually, for the binary case, I can use a different approach: precompute for each position i the "contribution vector" c_i[s] which is the contribution of h[i] to corr[s]. Then a swap (i,j) changes the correlation by:
new_corr[s] = old_corr[s] - c_i[s] + c_j[s] (adjusted for the fact that h changed)

Hmm, but c_i depends on the values of h at other positions. So it's not static.

Let me just go with the straightforward approach: for each candidate swap, recompute the correlation in O(n log n) using FFT, or O(n²) directly. For n=156, O(n²) = ~24000 operations per swap, which is fast.

Actually, np.correlate for n=156 takes about 156*311 ≈ 48000 multiply-adds, which is very fast (microseconds). So I can afford to check many swaps.

Let me design the algorithm:

**Phase 1: Binary optimization**
- Start from the binary extraction of initial_h_values
- Use simulated annealing with pair swaps and block moves
- Accept moves based on a Metropolis criterion
- Track the best solution

**Phase 2: Continuous polish**
- Starting from the best binary solution, use subgradient descent or projected gradient
- Allow fractional values to reduce the peak

**Phase 3: Multi-n exploration**
- Try different n values (resample the best solution)
- Re-optimize at each n

**Phase 4: Final polish**
- Combine the best solutions and do a final round of optimization

Let me think about what specific moves to use in the binary phase:

1. **Pair swap (1,0) → (0,1)**: Pick a 1 at position i and a 0 at position j, swap them.
2. **Double swap (1,0) and (1,0) → (0,1) and (0,1)**: Pick two 1s at i1, i2 and two 0s at j1, j2. Move 1 from i1 to j1 and 1 from i2 to j2.
3. **Block move**: Move a contiguous block of 1s (length L) from one position to another.

For efficiency, I'll focus on pair swaps and double swaps, which are the most local and have the smallest search space.

For the annealing schedule, I'll use a geometric cooling: T = T0 * alpha^step.

Now, for the continuous phase, I'll use a projected subgradient method:
1. Compute the max and its location (or set of locations within epsilon of max)
2. Compute the subgradient at those locations
3. Take a step in the negative subgradient direction
4. Project back to [0,1] × {sum = n/2}

The projection is the "water-filling" operation.

Let me also think about a **smoothing** approach: start with the binary solution and gradually "smooth" it by averaging with a kernel. This can reduce sharp peaks in the correlation.

Actually, I think the most promising approach is:

1. **Binary SA with block moves** - this should find good binary structures
2. **Subgradient polish** - this should extract the last bits of improvement

Let me also consider: what if the optimal solution is not close to binary? What if fractional values are important?

For the zero lag: corr[0] (in the correlate sense, which is index n-1) = sum h[i]*(1-h[i]). This is maximized when h[i] = 1/2 for all i (giving n/4), and minimized at the extremes (0 or 1, giving 0). So binary is definitely better for the zero lag.

For non-zero lags: the situation is more nuanced. A fractional value h[i] = a contributes a*(1-b) to the lag where h[i+k] = b. By making a and b both fractional, we can potentially reduce the peak.

For example, if at some lag k, we have many positions where h[i]=1 and h[i+k]=0, we could reduce some of the h[i] values to 0.5, which would halve the contribution at that lag but increase the zero-lag contribution.

The optimal fractional values depend on the tradeoff between the zero lag and the non-zero lags. This is exactly what the subgradient method should find.

Let me now write the code. I'll aim for something that:
1. Is different from the previous approach (uses SA + block moves + subgradient)
2. Has good time management
3. Explores multiple n values
4. Has a robust final polish

import numpy as np
from scipy.optimize import linprog
import time

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo, hi = float(v.min()) - 2.0, float(v.max()) + 2.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-12:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def _binary_extract(h, n):
    """Extract a binary solution from h by taking the top n/2 values."""
    half = n // 2
    idx = np.argsort(h)[-half:]
    b = np.zeros(n)
    b[idx] = 1.0
    return b

def _swap_eval(h, i, j, corr):
    """Evaluate the effect of swapping h[i] and h[j]. Returns new max corr."""
    # This is a quick check - for binary, swapping a 1 and a 0
    # We'll just recompute for now
    h_new = h.copy()
    h_new[i], h_new[j] = h_new[j], h_new[i]
    new_corr = _corr(h_new)
    return float(np.max(new_corr)), new_corr

def _block_move_eval(h, src_start, src_len, dst_start, corr):
    """Evaluate a block move: move h[src_start:src_start+src_len] to dst_start."""
    # Only valid if the destination is all zeros
    block = h[src_start:src_start+src_len].copy()
    dst_region = h[dst_start:dst_start+src_len]
    if np.any(dst_region > 0):
        return None, None
    h_new = h.copy()
    h_new[src_start:src_start+src_len] = 0.0
    h_new[dst_start:dst_start+src_len] = block
    new_corr = _corr(h_new)
    return float(np.max(new_corr)), new_corr

def _binary_sa(h, deadline, n_iters=None, T0=0.3, T1=0.01, alpha=0.9995):
    """Simulated annealing on binary sequences using pair swaps and block moves."""
    n = len(h)
    dx = 2.0 / n
    h = _binary_extract(h, n).copy()
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    corr = _corr(h)
    
    rng = np.random.default_rng(777)
    T = T0
    ones = np.where(h == 1.0)[0]
    zeros = np.where(h == 0.0)[0]
    
    if n_iters is None:
        n_iters = 50000
    
    for step in range(n_iters):
        if time.time() > deadline:
            break
        T = T0 * (T1/T0) ** (step / n_iters)
        
        move_type = rng.random()
        if move_type < 0.6:
            # Pair swap
            if len(ones) < 1 or len(zeros) < 1:
                break
            i = ones[rng.integers(len(ones))]
            j = zeros[rng.integers(len(zeros))]
            if i == j:
                continue
            # Try the swap
            h[j] = 1.0
            h[i] = 0.0
            new_c5 = _exact_c5(h)
            delta = new_c5 - cur_c5
            if delta < 0 or rng.random() < np.exp(-delta / max(T, 1e-10)):
                cur_c5 = new_c5
                # Update ones/zeros
                ones = np.where(h == 1.0)[0]
                zeros = np.where(h == 0.0)[0]
                if cur_c5 < best_c5:
                    best_c5 = cur_c5
                    best_h = h.copy()
            else:
                # Revert
                h[i] = 1.0
                h[j] = 0.0
        elif move_type < 0.85:
            # Double swap
            if len(ones) < 2 or len(zeros) < 2:
                break
            i1 = ones[rng.integers(len(ones))]
            i2 = ones[rng.integers(len(ones))]
            j1 = zeros[rng.integers(len(zeros))]
            j2 = zeros[rng.integers(len(zeros))]
            if len({i1, i2, j1, j2}) < 4:
                continue
            # Try the double swap
            h[j1], h[j2] = 1.0, 1.0
            h[i1], h[i2] = 0.0, 0.0
            new_c5 = _exact_c5(h)
            delta = new_c5 - cur_c5
            if delta < 0 or rng.random() < np.exp(-delta / max(T, 1e-10)):
                cur_c5 = new_c5
                ones = np.where(h == 1.0)[0]
                zeros = np.where(h == 0.0)[0]
                if cur_c5 < best_c5:
                    best_c5 = cur_c5
                    best_h = h.copy()
            else:
                h[i1], h[i2] = 1.0, 1.0
                h[j1], h[j2] = 0.0, 0.0
        else:
            # Block move (length 2 or 3)
            blen = int(rng.integers(2, 4))
            if n < blen + 2:
                continue
            # Find a block of 1s
            found = False
            for _ in range(20):
                pos = int(rng.integers(0, n - blen))
                if np.all(h[pos:pos+blen] == 1.0):
                    found = True
                    break
            if not found:
                # Try random pair swap instead
                continue
            # Find destination (all zeros)
            dst_found = False
            for _ in range(20):
                dst = int(rng.integers(0, n - blen))
                if dst == pos or (dst < pos + blen and dst + blen > pos):
                    continue
                if np.all(h[dst:dst+blen] == 0.0):
                    dst_found = True
                    break
            if not dst_found:
                continue
            # Try the move
            h[dst:dst+blen] = 1.0
            h[pos:pos+blen] = 0.0
            new_c5 = _exact_c5(h)
            delta = new_c5 - cur_c5
            if delta < 0 or rng.random() < np.exp(-delta / max(T, 1e-10)):
                cur_c5 = new_c5
                ones = np.where(h == 1.0)[0]
                zeros = np.where(h == 0.0)[0]
                if cur_c5 < best_c5:
                    best_c5 = cur_c5
                    best_h = h.copy()
            else:
                h[pos:pos+blen] = 1.0
                h[dst:dst+blen] = 0.0
    
    return best_h, best_c5

def _subgrad_step(h, step_size, n_active=3):
    """One subgradient descent step on the C5 objective."""
    n = len(h)
    dx = 2.0 / n
    corr = _corr(h)
    max_val = np.max(corr)
    active = np.where(corr >= max_val - 1e-6)[0]
    if len(active) > n_active:
        active = active[:n_active]
    
    # Compute subgradient as average over active constraints
    grad = np.zeros(n)
    for l in active:
        s = l - (n - 1)  # signed lag
        # d corr[l] / d h[j]
        if s >= 0:
            # corr[l] = sum_{i=0}^{n-1-s} h[i]*(1-h[i+s])
            # d/dh[j] = (1-h[j+s]) for j in [0, n-1-s] (first factor)
            #          -h[j-s] for j in [s, n-1] (second factor, h[i+s]=h[j], i=j-s)
            if s == 0:
                # corr = sum h[i]*(1-h[i]), d/dh[j] = 1 - 2*h[j]
                grad += (1.0 - 2.0 * h)
            else:
                # First factor: j in [0, n-1-s]
                first = np.zeros(n)
                first[:n-s] = 1.0 - h[s:]
                grad += first
                # Second factor: j in [s, n-1], contribution -h[j-s]
                second = np.zeros(n)
                second[s:] = -h[:n-s]
                grad += second
        else:
            s2 = -s  # positive distance
            # corr[l] = sum_{i=s2}^{n-1} h[i]*(1-h[i-s2])
            # d/dh[j] = (1-h[j-s2]) for j in [s2, n-1] (first factor, i=j)
            #          -h[j+s2] for j in [0, n-1-s2] (second factor, i-s2=j, i=j+s2)
            first = np.zeros(n)
            first[s2:] = 1.0 - h[:n-s2]
            grad += first
            second = np.zeros(n)
            second[:n-s2] = -h[s2:]
            grad += second
    
    grad /= len(active)
    
    # Take step
    h_new = h - step_size * grad
    h_new = _project(h_new, n / 2.0)
    return h_new

def _subgrad_loop(h, deadline, initial_step=0.02):
    """Subgradient descent loop with adaptive step size."""
    n = len(h)
    h = h.copy()
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    step = initial_step
    stall = 0
    
    while time.time() < deadline:
        h_new = _subgrad_step(h, step)
        new_c5 = _exact_c5(h_new)
        if new_c5 < cur_c5 - 1e-12:
            h = h_new
            cur_c5 = new_c5
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            stall = 0
            step = min(step * 1.1, 0.1)
        else:
            stall += 1
            step *= 0.9
            if stall > 100:
                break
    
    return best_h, best_c5

def _resample(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return _project(h_new, n_new / 2.0)

def _line_search_robust(h, d, dx, radius, n_samples=50):
    """Robust line search with multiple brackets."""
    n = len(h)
    S0 = _corr(h)
    T = np.correlate(d, 1.0 - h, mode='full') - np.correlate(h, d, mode='full')
    C = np.correlate(d, d, mode='full')
    
    # Feasibility bounds
    pos = d > 1e-15
    neg = d < -1e-15
    t_hi = radius
    t_lo = -radius
    if np.any(pos):
        t_hi = min(t_hi, float(np.min((1.0 - h[pos]) / d[pos])))
    if np.any(neg):
        t_lo = max(t_lo, float(np.max(h[neg] / d[neg])))
    
    if t_hi - t_lo < 1e-14:
        return 0.0, _exact_c5(h)
    
    # Evaluate on a grid
    ts = np.linspace(t_lo, t_hi, n_samples)
    vals = np.array([float(np.max(S0 + t * T - t*t * C)) * dx for t in ts])
    
    # Find the best region
    best_idx = int(np.argmin(vals))
    
    # Golden section around the best grid point
    lo = ts[max(0, best_idx-1)]
    hi = ts[min(len(ts)-1, best_idx+1)]
    
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    c1 = hi - gr * (hi - lo)
    c2 = lo + gr * (hi - lo)
    f1 = float(np.max(S0 + c1 * T - c1*c1 * C)) * dx
    f2 = float(np.max(S0 + c2 * T - c2*c2 * C)) * dx
    
    for _ in range(40):
        if hi - lo < 1e-10:
            break
        if f1 < f2:
            hi = c2; c2 = c1; f2 = f1
            c1 = hi - gr * (hi - lo)
            f1 = float(np.max(S0 + c1 * T - c1*c1 * C)) * dx
        else:
            lo = c1; c1 = c2; f1 = f2
            c2 = lo + gr * (hi - lo)
            f2 = float(np.max(S0 + c2 * T - c2*c2 * C)) * dx
    
    opt_t = (lo + hi) / 2.0
    opt_val = float(np.max(S0 + opt_t * T - opt_t*opt_t * C)) * dx
    return opt_t, opt_val

def _lp_direction(h, scores, radius):
    """LP-based direction finding."""
    n = len(h)
    # Build gradient matrix
    G = np.zeros((2*n-1, n))
    for d in range(-(n-1), n):
        r = n - 1 + d
        if d >= 0:
            m = n - d
            if m > 0:
                G[r, :m] += (1.0 - h[d:])
                G[r, d:] += -h[:m]
        else:
            g = -d
            m = n - g
            if m > 0:
                G[r, :m] += (1.0 - h[g:])
                G[r, g:] += -h[:m]
    
    c = np.zeros(n + 1)
    c[-1] = 1.0
    A_ub = np.zeros((2*n-1, n+1))
    A_ub[:, :n] = G
    A_ub[:, n] = -1.0
    b_ub = -scores
    A_eq = np.zeros((1, n+1))
    A_eq[0, :n] = 1.0
    b_eq = np.zeros(1)
    bounds = []
    for j in range(n):
        lo = max(-radius, -h[j])
        hi2 = min(radius, 1.0 - h[j])
        bounds.append((lo, hi2))
    bounds.append((None, None))
    
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs')
        if res.success:
            return res.x[:n]
    except Exception:
        pass
    return None

def _local_optimize(h, deadline, use_lp=True, use_subgrad=True):
    """Combined local optimization: LP + subgradient + line search."""
    n = len(h)
    dx = 2.0 / n
    h = h.copy()
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    
    stall = 0
    while time.time() < deadline and stall < 50:
        improved = False
        
        # Try LP direction
        if use_lp and n <= 200:
            scores = _corr(h)
            p = _lp_direction(h, scores, 0.15)
            if p is not None and np.max(np.abs(p)) > 1e-12:
                alpha, new_c5 = _line_search_robust(h, p, dx, 0.15)
                if new_c5 < cur_c5 - 1e-13:
                    h = h + alpha * p
                    h = _project(h, n/2.0)
                    cur_c5 = _exact_c5(h)
                    if cur_c5 < best_c5:
                        best_c5 = cur_c5
                        best_h = h.copy()
                    improved = True
        
        # Try subgradient step
        if use_subgrad and not improved:
            h_new = _subgrad_step(h, 0.015)
            new_c5 = _exact_c5(h_new)
            if new_c5 < cur_c5 - 1e-13:
                h = h_new
                cur_c5 = new_c5
                if cur_c5 < best_c5:
                    best_c5 = cur_c5
                    best_h = h.copy()
                improved = True
        
        if not improved:
            stall += 1
            # Try a random perturbation direction
            rng = np.random.default_rng(int(time.time() * 1000) % 100000)
            d = rng.normal(0, 1, n)
            d -= d.mean()  # maintain sum constraint approximately
            alpha, new_c5 = _line_search_robust(h, d, dx, 0.05)
            if new_c5 < cur_c5 - 1e-13:
                h = h + alpha * d
                h = _project(h, n/2.0)
                cur_c5 = _exact_c5(h)
                if cur_c5 < best_c5:
                    best_c5 = cur_c5
                    best_h = h.copy()
                stall = 0
    
    return best_h, best_c5
