c[r] = sum_j h[j + r - (n-1)] * (1-h[j]) (with appropriate index validation)

Let d = r - (n-1). Then c[r] = sum_j h[j+d] * (1-h[j]) for valid j.

∂c[r]/∂h[i] = sum_j [∂h[j+d]/∂h[i] * (1-h[j]) + h[j+d] * ∂(1-h[j])/∂h[i]]
             = (1-h[i-d]) if i-d >= 0 and i-d is a valid j (i.e., i-d + d = i is valid, which it is)
               Wait, I need: j+d = i → j = i-d. So the first term contributes (1-h[i-d]) if i-d is in [0, n-1] and i-d is a valid j for this r.
             
             + (-h[i-d]) if j = i, i.e., h[i+d] appears → contributes -h[i+d] if i+d is in [0, n-1]

Actually let me be more careful. For c[r] with d = r-(n-1):
c[r] = sum_{j: 0<=j<n, 0<=j+d<n} h[j+d] * (1-h[j])

∂c[r]/∂h[i]:
- h[j+d] = h[i] when j+d = i, i.e., j = i-d. Valid if 0 <= i-d < n and 0 <= j < n (same condition) and j+d = i < n (same).
  Contribution: (1-h[j]) = (1-h[i-d])
  
- (1-h[j]) = (1-h[i]) when j = i. Valid if 0 <= i < n and 0 <= i+d < n.
  Contribution: h[j+d] * (-1) = -h[i+d]

So: ∂c[r]/∂h[i] = (1-h[i-d]) * [0 <= i-d < n] - h[i+d] * [0 <= i+d < n]

where d = r - (n-1).

This is correct! And it's O(1) per (r, i) pair, so the full gradient matrix is O(n²) to compute.

For the LSE smoothing, the gradient of the objective is:
∇_i C5_smooth = (2/n) * sum_r w_r * ∂c[r]/∂h[i]

where w_r = softmax(β * c[r]).

This gives a direction. But we also need to maintain feasibility (0 <= h <= 1, sum = n/2).

The projected gradient step:
1. Compute g = ∇C5_smooth
2. Subtract mean(g) to ensure sum(step) = 0 (maintains sum constraint)
3. h_new = h - α * g_projected
4. Project h_new to [0,1]^n with sum = n/2
5. Line search on α

This is essentially gradient descent with projection. It should work well for this smooth problem.

The key hyperparameter is β (the sharpness of the LSE). Large β ≈ exact max (nonsmooth), small β ≈ mean (too smooth). A good choice is β such that the effective number of active terms is small (like 3-5).

Let me also think about the Hessian for Newton-type steps. The Hessian of c[r] with respect to h is:
∂²c[r]/∂h[i]∂h[j] = -δ_{i-d, j} * ... 

Actually, c[r] is bilinear in h, so its Hessian is constant (doesn't depend on h). This means a Newton step would be very powerful.

The Hessian of c[r]:
c[r] = sum_j h[j+d] * (1-h[j]) = sum_j h[j+d] - sum_j h[j+d]*h[j]

The Hessian of -sum_j h[j+d]*h[j] with respect to (h[i], h[j]):
= -δ_{i, j+d} - δ_{j, i+d} (off-diagonal terms)
  - 0 for diagonal (since h[j+d]*h[j] is linear in each variable separately when the other is fixed, unless i = j+d AND i = j+d simultaneously, which would be i=j+d=j, so d=0, but then c[r] for d=0 is sum h[j]*(1-h[j]) which IS quadratic in the same variable)

Wait, for d=0: c[n-1] = sum_j h[j]*(1-h[j]) = sum_j h[j] - sum_j h[j]²
This IS quadratic! So the Hessian for d=0 has diagonal entries -2.

For d ≠ 0: c[r] = sum_j h[j+d] - sum_j h[j+d]*h[j]
The Hessian has -1 at positions (i, i+d) and (i+d, i) for valid i, and 0 elsewhere.

So the full Hessian of the objective (max of c[r]) is a block structure. This is useful for Newton methods but complex to implement.

For a simpler approach, I'll use gradient descent with the LSE smoothing, combined with:
- Exact line search (using the quadratic structure of each c[r])
- Active set refinement (once the LSE has converged close to the true max)
- Direct pair moves for final polishing

import numpy as np
import time
from scipy.optimize import linprog

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _project(v, target):
    """Project v onto {x: 0<=x<=1, sum(x)=target}"""
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    # Bisection for water level
    lo = float(v.min()) - 2.0
    hi = float(v.max()) + 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-10:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _corr_and_grad(h):
    """Compute correlation and its gradient (Jacobian)."""
    n = len(h)
    c = np.correlate(h, 1.0 - h, mode='full')
    # Gradient: d c[r] / d h[i] = (1-h[i-d]) * [0<=i-d<n] - h[i+d] * [0<=i+d<n]
    # where d = r - (n-1)
    # We'll compute this as a matrix (2n-1) x n
    # But for memory efficiency, we'll compute the LSE gradient directly
    return c

def _lse_gradient(h, beta):
    """Compute gradient of log-sum-exp(max_k c[k] * beta) / beta."""
    n = len(h)
    c = np.correlate(h, 1.0 - h, mode='full')
    # Softmax weights
    c_scaled = c * beta
    c_max = c_scaled.max()
    exp_c = np.exp(c_scaled - c_max)
    w = exp_c / exp_c.sum()
    
    # For each r, d = r - (n-1)
    # grad_i = sum_r w[r] * [(1-h[i-d_r]) * [0<=i-d_r<n] - h[i+d_r] * [0<=i+d_r<n]]
    # We can compute this efficiently:
    # Term 1: sum_r w[r] * (1-h[i-d_r]) * [0<=i-d_r<n]
    #         = sum_r w[r] * (1-h[i-(r-(n-1))]) * [0<=i-(r-(n-1))<n]
    #         For fixed i: r-(n-1) = i-j where j is valid, so r = n-1+i-j
    #         = sum_{j: 0<=j<n, 0<=n-1+i-j<2n-1} w[n-1+i-j] * (1-h[j])
    
    # Actually, let me just compute it directly using the correlation structure.
    # grad[i] = sum_r w[r] * (1-h[i-d_r]) * I[0<=i-d_r<n] - sum_r w[r] * h[i+d_r] * I[0<=i+d_r<n]
    
    # First term: for each i, sum over r where i-d_r is valid
    # i - d_r = i - (r - (n-1)) = i + n - 1 - r
    # Valid when 0 <= i+n-1-r < n, i.e., n-1+i - (n-1) < r <= n-1+i, i.e., r in [i, n-1+i]
    # Wait: 0 <= i+n-1-r < n means n-1+i-n < r <= n-1+i, i.e., i-1 < r <= n-1+i
    # So r ranges from max(0, i) to min(2n-2, n-1+i)... 
    
    # This is getting complicated. Let me just use a different approach:
    # Compute the gradient using the bilinear structure directly.
    
    # c[r] = sum_j h[j+d] * (1-h[j]) where d = r-(n-1)
    # sum_r w[r] * c[r] = sum_r w[r] * sum_j h[j+d_r] * (1-h[j])
    #                    = sum_j (1-h[j]) * sum_r w[r] * h[j+d_r]
    #                    = sum_j (1-h[j]) * A[j]
    # where A[j] = sum_r w[r] * h[j+d_r]
    
    # Similarly, the gradient:
    # d/dh[i] [sum_j (1-h[j]) * A[j]] where A depends on h...
    
    # Actually, let me just do it the direct way for n=122. It's fast enough.
    
    # For each i (0 to n-1):
    # grad[i] = sum_r w[r] * [(1-h[i-d_r]) * I(0<=i-d_r<n) + (-h[i+d_r]) * I(0<=i+d_r<n)]
    
    # Let me vectorize: for fixed i, the terms involving h are:
    # (1-h[i-d_r]) for r where i-d_r is in [0,n-1]
    # -h[i+d_r] for r where i+d_r is in [0,n-1]
    
    # d_r = r - (n-1), so i - d_r = i - r + (n-1) and i + d_r = i + r - (n-1)
    
    # For term 1: i - r + (n-1) in [0, n-1] means r in [i, n-1+i] intersect [0, 2n-2]
    # For term 2: i + r - (n-1) in [0, n-1] means r in [n-1-i, n-1+i] intersect [0, 2n-2]
    
    # Let me just compute it with a loop over i (n=122, this is fine)
    grad = np.zeros(n)
    r_range = np.arange(2*n - 1)
    d = r_range - (n - 1)  # effective lag for each r
    
    for i in range(n):
        # Term 1: (1-h[i-d_r]) where i-d_r in [0, n-1]
        idx1 = i - d  # = i - r + (n-1)
        mask1 = (idx1 >= 0) & (idx1 < n)
        # Term 2: -h[i+d_r] where i+d_r in [0, n-1]
        idx2 = i + d  # = i + r - (n-1)
        mask2 = (idx2 >= 0) & (idx2 < n)
        
        grad[i] = float(np.sum(w[mask1] * (1.0 - h[idx1[mask1]])) - np.sum(w[mask2] * h[idx2[mask2]]))
    
    return grad * (2.0 / n)  # multiply by dx to get gradient of C5

def _line_search_c5(h, direction, base_c5):
    """Line search: find best alpha in [0, alpha_max] minimizing C5(h + alpha*dir)."""
    n = len(h)
    dx = 2.0 / n
    
    # Compute S0, T, Q for the quadratic in alpha
    S0 = np.correlate(h, 1.0 - h, mode='full')
    T = np.correlate(direction, 1.0 - h, mode='full') - np.correlate(h, direction, mode='full')
    Q = np.correlate(direction, direction, mode='full')
    
    # C5(alpha) = dx * max_r (S0[r] + alpha*T[r] - alpha^2*Q[r])
    
    # Find valid alpha range (feasibility)
    pos = direction > 1e-14
    neg = direction < -1e-14
    alpha_max = 1.0
    if np.any(pos):
        alpha_max = min(alpha_max, float(np.min((1.0 - h[pos]) / direction[pos])))
    if np.any(neg):
        alpha_max = min(alpha_max, float(np.min(-h[neg] / direction[neg])))
    
    if alpha_max < 1e-14:
        return 0.0, base_c5
    
    # Grid search + golden section
    n_grid = 64
    grid = np.linspace(0.0, alpha_max, n_grid)
    vals = S0[None, :] + grid[:, None] * T[None, :] - (grid[:, None]**2) * Q[None, :]
    obj = np.max(vals, axis=1) * dx
    
    best_i = int(np.argmin(obj))
    best_alpha = grid[best_i]
    best_obj = obj[best_i]
    
    # Refine with golden section
    if 0 < best_i < n_grid - 1:
        a, b = grid[best_i-1], grid[best_i+1]
    else:
        a, b = 0.0, alpha_max
    
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    c1 = b - gr * (b - a)
    c2 = a + gr * (b - a)
    f1 = float(np.max(S0 + c1*T - c1*c1*Q)) * dx
    f2 = float(np.max(S0 + c2*T - c2*c2*Q)) * dx
    
    for _ in range(40):
        if b - a < 1e-13:
            break
        if f1 < f2:
            b, c2, f2 = c2, c1, f1
            c1 = b - gr * (b - a)
            f1 = float(np.max(S0 + c1*T - c1*c1*Q)) * dx
        else:
            a, c1, f1 = c1, c2, f2
            c2 = a + gr * (b - a)
            f2 = float(np.max(S0 + c2*T - c2*c2*Q)) * dx
    
    opt_alpha = (a + b) / 2.0
    opt_obj = float(np.max(S0 + opt_alpha*T - opt_alpha*opt_alpha*Q)) * dx
    
    if opt_obj < best_obj:
        best_alpha, best_obj = opt_alpha, opt_obj
    
    return best_alpha, best_obj

def _binary_local_search(h, deadline, rng):
    """Fast local search on binary sequences using swaps."""
    n = len(h)
    target = n // 2
    dx = 2.0 / n
    
    # Ensure binary
    sorted_idx = np.argsort(-h)
    h = np.zeros(n)
    h[sorted_idx[:target]] = 1.0
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    
    corr = np.correlate(h, 1.0 - h, mode='full')
    max_val = corr.max()
    
    ones = set(np.where(h == 1.0)[0].tolist())
    zeros = set(np.where(h == 0.0)[0].tolist())
    
    T = 0.005
    T_min = 1e-6
    cooling = 0.9995
    patience = 0
    max_patience = 50000
    
    while time.time() < deadline:
        if patience > max_patience:
            if T <= T_min:
                break
            T = max(T_min, T * 0.9)
            patience = 0
        
        # Try a swap
        if not ones or not zeros:
            break
        i = ones[rng.integers(len(ones))]
        j = zeros[rng.integers(len(zeros))]
        
        # Compute new C5 after swap
        h[i] = 0.0
        h[j] = 1.0
        new_corr = np.correlate(h, 1.0 - h, mode='full')
        new_c5 = float(new_corr.max()) * dx
        delta = new_c5 - cur_c5
        
        if delta < 0 or (T > T_min and rng.random() < np.exp(-delta / T)):
            cur_c5 = new_c5
            ones.discard(i)
            zeros.discard(j)
            ones.add(j)
            zeros.add(i)
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
                patience = 0
            else:
                patience += 1
        else:
            h[i] = 1.0
            h[j] = 0.0
        
        T = max(T_min, T * cooling)
    
    return best_h, best_c5

def _gradient_descent(h_init, deadline, beta_init=20.0):
    """Gradient descent with LSE smoothing."""
    n = len(h_init)
    target = n / 2.0
    h = _project(h_init, target)
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    
    beta = beta_init
    lr = 0.05
    stall = 0
    
    while time.time() < deadline:
        if stall > 200:
            break
        
        # Compute LSE gradient
        grad = _lse_gradient(h, beta)
        
        # Project to sum-zero (maintain sum constraint)
        grad_centered = grad - np.mean(grad)
        
        # Line search
        alpha, new_c5 = _line_search_c5(h, -lr * grad_centered, cur_c5)
        
        if new_c5 < cur_c5 - 1e-12:
            h = _project(h + alpha * (-lr * grad_centered), target)
            actual_c5 = _exact_c5(h)
            if actual_c5 < cur_c5:
                cur_c5 = actual_c5
                if cur_c5 < best_c5:
                    best_c5 = cur_c5
                    best_h = h.copy()
                    stall = 0
                else:
                    stall += 1
                # Decrease beta as we converge (sharper max approximation)
                beta = min(beta * 1.1, 200.0)
                # Decrease learning rate slowly
                lr = max(lr * 0.999, 0.005)
            else:
                stall += 1
                lr *= 0.9
        else:
            stall += 1
            lr *= 0.8
            if lr < 0.001:
                break
    
    return best_h, best_c5

def _active_set_refine(h, deadline):
    """Refine using active set (lags near the max)."""
    n = len(h)
    target = n / 2.0
    dx = 2.0 / n
    h = h.copy()
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    
    max_corr = 24  # threshold for "active"
    
    while time.time() < deadline:
        corr = np.correlate(h, 1.0 - h, mode='full')
        active = np.where(corr >= corr.max() - 1.0)[0]  # lags within 1 of max
        
        if len(active) == 0:
            break
        
        # Try to reduce all active lags simultaneously
        # Build a system: for each active lag r, we want to decrease corr[r]
        # Direction: negative gradient of active lags, averaged
        grad = np.zeros(n)
        for r in active:
            d = r - (n - 1)
            for i in range(n):
                idx1 = i - d
                if 0 <= idx1 < n:
                    grad[i] += (1.0 - h[idx1])
                idx2 = i + d
                if 0 <= idx2 < n:
                    grad[i] -= h[idx2]
        grad /= len(active)
        grad -= np.mean(grad)  # maintain sum
        
        # Line search
        alpha, new_c5 = _line_search_c5(h, -grad, cur_c5)
        
        if new_c5 < cur_c5 - 1e-12:
            h = _project(h + alpha * (-grad), target)
            actual = _exact_c5(h)
            if actual < cur_c5:
                cur_c5 = actual
                if cur_c5 < best_c5:
                    best_c5 = cur_c5
                    best_h = h.copy()
            else:
                break
        else:
            break
    
    return best_h, best_c5

def _pair_swap_refine(h, deadline):
    """Refine using pair swaps with exact line search."""
    n = len(h)
    target = n / 2.0
    dx = 2.0 / n
    h = h.copy()
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    rng = np.random.default_rng(777)
    
    # Get interior points (fractional values)
    while time.time() < deadline:
        # Try random pair moves
        i = rng.integers(n)
        j = rng.integers(n)
        if i == j:
            continue
        d = np.zeros(n)
        d[i] = 1.0
        d[j] = -1.0
        alpha, new_c5 = _line_search_c5(h, d, cur_c5)
        if alpha > 1e-10 and new_c5 < cur_c5 - 1e-12:
            h = _project(h + alpha * d, target)
            actual = _exact_c5(h)
            if actual < cur_c5:
                cur_c5 = actual
                if cur_c5 < best_c5:
                    best_c5 = cur_c5
                    best_h = h.copy()
            else:
                h = best_h.copy()  # revert
                cur_c5 = best_c5
        elif new_c5 < cur_c5 - 1e-12:
            h = _project(h + alpha * d, target)
            actual = _exact_c5(h)
            if actual < best_c5:
                best_c5 = actual
                best_h = h.copy()
    
    return best_h, best_c5

def _multi_resolution(h_best, deadline, rng):
    """Try different resolutions to escape local minima."""
    n_best = len(h_best)
    best_h = h_best.copy()
    best_c5 = _exact_c5(h_best)
    
    # Try nearby resolutions
    for dn in [-2, 2, -4, 4, -6, 6, 8, -8]:
        if time.time() > deadline:
            break
        n_try = n_best + dn
        if n_try < 40 or n_try > 200 or n_try % 2 != 0:
            continue
        
        # Downsample or Upsample
        x_old = (np.arange(n_best) + 0.5) / n_best
        x_new = (np.arange(n_try) + 0.5) / n_try
        h_try = np.interp(x_new, x_old, h_best)
        h_try = _project(h_try, n_try / 2.0)
        
        # Optimize at this resolution
        sub_dl = min(deadline, time.time() + 15)
        h_opt, c5_opt = _gradient_descent(h_try, sub_dl, beta_init=30.0)
        
        if c5_opt < best_c5:
            # Try binary search too
            sub_dl2 = min(deadline, time.time() + 10)
            h_bin, c5_bin = _binary_local_search(h_opt, sub_dl2, rng)
            if c5_bin < c5_opt:
                h_opt, c5_opt = h_bin, c5_bin
            # Polish
            sub_dl3 = min(deadline, time.time() + 10)
            h_opt2, c5_opt2 = _gradient_descent(h_opt, sub_dl3, beta_init=50.0)
            if c5_opt2 < c5_opt:
                h_opt, c5_opt = h_opt2, c5_opt2
        
        if c5_opt < best_c5 - 1e-10:
            best_c5 = c5_opt
            best_h = h_opt.copy()
    
    return best_h, best_c5

def _sine_init(n, freq, phase):
    """Create a structured initial condition."""
    x = np.arange(n)
    h = 0.5 + 0.5 * np.sin(2 * np.pi * freq * x / n + phase)
    return _project(h, n / 2.0)

def _alternating_init(n, rng):
    """Create an alternating-block initial condition."""
    h = np.zeros(n)
    pos = 0
    while pos < n:
        blk = int(rng.integers(1, max(2, n//8 + 1)))
        if int(pos // blk) % 2 == 0:
            h[pos:pos+blk] = 1.0
        pos += blk
    return _project(h, n / 2.0)
