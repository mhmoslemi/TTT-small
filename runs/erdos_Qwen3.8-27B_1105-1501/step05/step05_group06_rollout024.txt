        idx = n - 1 + d
        delta = 0
        if j + d < n:
            delta -= h[j + d]  # was h[j+d], now 0

    #   corr[n-1+d] changes by:
    #     +h[i+d] (if i+d < n) - (1-h[i-d]) (if i-d >= 0)  [from i]

    #     -(1-h[i+d]) (if i+d < n) + h[i-d] (if i-d >= 0)  [from i]
    #     +(1-h[j+d]) (if j+d < n) - h[j-d] (if j-d >= 0)  [from j]

This is O(n) per swap, which is great. Let me now write the full algorithm.

Actually, I realize there might be a subtlety: when I update corr for position i, I'm using the current values of h[i+d] and h[i-d]. But I haven't yet changed h[i] (I do that after the loop). And h[j] hasn't been changed either. So the updates are correct as long as i ≠ j (which they aren't, since one is a 1 and the other is a 0).

Wait, but what if i+d = j or j+d = i? Then I'd be using the old value of h[j] (which is 0) when computing the update for position i. But after I set h[j]=1, the value would be different. However, since I'm computing the DELTA for the swap, and the delta for position i's change doesn't depend on h[j] (it depends on h[i+d] and h[i-d]), this is fine as long as i+d ≠ j and i-d ≠ j. If i+d = j, then h[i+d] = h[j] = 0 (current value), and the delta would be +0 for the "i in first position" case. But after the swap, h[j] = 1, so the actual new value of that term would be h[i+d]*(1-h[i]) = 1*1 = 1 (since h[i] was 1, now 0). Hmm, this is getting confusing.

Let me think again. The delta for position i (going from 1 to 0) at lag d:
- If i is in the "first" position (j in the formula): the term h[i+d]*(1-h[i]) changes from h[i+d]*0 = 0 to h[i+d]*1 = h[i+d]. Delta = h[i+d].
  - Here h[i+d] is the value at position i+d, which is NOT i (since d≥1) and NOT necessarily j.
  - If i+d = j, then h[i+d] = h[j] = 0 (current, before swap). So delta = 0.
  - But after the swap, h[j] = 1, so the actual term would be 1*1 = 1, not 0.
  - So the delta would be 1, not 0!

This means I need to be careful: if i+d = j, the delta for position i's change is affected by position j's change.

The solution: compute the delta for the COMBINED swap (both i and j change simultaneously), not sequentially.

For the combined swap (i: 1→0, j: 0→1), the change in corr at index n-1+d:

Original terms involving i or j in the sum for corr[n-1+d] = sum_k h[k+d]*(1-h[k]):
- If i <= n-1-d: term at k=i is h[i+d]*(1-h[i]) = h[i+d]*0 = 0. After swap: h[i+d]*(1-0) = h[i+d].
  - But if i+d = j: after swap, h[i+d] = h[j] = 1. So new term = 1.
  - If i+d ≠ j: h[i+d] is unchanged. New term = h[i+d].
- If i >= d: term at k=i-d is h[i]*(1-h[i-d]) = 1*(1-h[i-d]). After swap: 0*(1-h[i-d]) = 0.
  - Delta = -(1-h[i-d]).
  - If i-d = j: h[i-d] = h[j] = 0 (before swap). Delta = -(1-0) = -1.
  - After swap, h[i-d] = h[j] = 1, but the term is 0*(1-1) = 0 either way. So delta is still -1.
  - Wait, the delta is old - new = (1-h[i-d]) - 0 = 1-h[i-d]. If i-d=j, this is 1-0=1 (using old h[j]=0). But actually, the new value is 0*(1-h_new[j]) = 0*(1-1) = 0. And the old value is 1*(1-h_old[j]) = 1*(1-0) = 1. So delta = 1-0 = 1. ✓

- If j <= n-1-d: term at k=j is h[j+d]*(1-h[j]) = h[j+d]*1 = h[j+d]. After swap: h[j+d]*(1-1) = 0.
  - Delta = -h[j+d].
  - If j+d = i: h[j+d] = h[i] = 1 (before swap). Delta = -1.
  - After swap, h[j+d] = h[i] = 0, so new term = 0*0 = 0. Old term = 1*1 = 1. Delta = -1. ✓

- If j >= d: term at k=j-d is h[j]*(1-h[j-d]) = 0*(1-h[j-d]) = 0. After swap: 1*(1-h[j-d]) = 1-h[j-d].

  - If j-d = i: h[j-d] = h[i] = 1 (before swap). Delta = 1-1 = 0.
  - After swap, h[j-d] = h[i] = 0, so new term = 1*(1-0) = 1. Old term = 0*(1-1) = 0
