The projected gradient step:
1. Compute grad = dPhi/dh
2. Project onto the affine constraint: grad_proj = grad - (sum(grad)/n) * ones (this projects onto the hyperplane sum(h) = const)
3. Actually, we need to project the negative gradient onto the feasible set, which means:
   - Start with h_new = h - alpha * grad
   - Project h_new onto {0 <= h_i <= 1, sum(h) = n/2}
4. Find alpha by line search (backtracking)

The projection onto {0 <= h_i <= 1, sum(h) = n/2} is exactly the _project function we already have.

So the projected gradient step is:
1. grad = _pnorm_grad(h, q)
2. For alpha in [alpha_max, alpha_max*r, alpha_max*r^2, ...]:
     h_cand = _project(h - alpha * grad, n/2)
     if f(h_cand) < f(h) - c*alpha*||grad||^2: accept
3. If no alpha works, the step is too small.

This is simpler and more robust than SLSQP for the high-q regime.

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo = float(v.min()) - 2.0
    hi = float(v.max()) + 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    x = np.clip(v - (lo + hi) / 2.0, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-12:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x
