Let me think about the Newton method more carefully.

For the log-sum-exp F(h) = (1/β) log(Σ exp(β S_d)):
- Gradient: g = Σ w_d ∇S_d
- Hessian: H = β(Σ w_d ∇S_d∇S_d^T - gg^T) + Σ w_d ∇²S_d

The Newton step solves: H δ = -g
Then we take h_new = h + α δ and project.

The issue is that H may be indefinite. In that case, we need:
- If H is PD: take the Newton step
- If H is indefinite: use a gradient step or a modified Newton (flip the direction of negative eigenvalues)

For a damped version:
- Try α = 1, 0.5, 0.25, ... until F(h + αδ) < F(h) (or until projected version improves C₅)

Actually, since we're really trying to minimize max(S_d) (not the log-sum-exp), we should check improvement in terms of max(S_d), not F. The log-sum-exp is just a smooth surrogate.

Let me simplify: I'll use the log-sum-exp gradient for direction information, but check improvement in terms of the actual max score. This is like a "smoothed subgradient" method.

For the Newton step, I'll solve (H + λI)δ = -g with a small regularization λ to ensure PD.

Here's my refined algorithm:

```python
def _newton_polish(h, deadline, beta=50.0, max_iters=100):
    n = len(h)
    target = n / 2.0
    h = h.copy()
    best_h = h.copy()
    best_c5 = _exact_c5(h)
    
    for it in range(max_iters):
        if time.time() > deadline:
            break
        
        scores = _scores(h)
        s_max = scores.max()
        s_shifted = scores - s_max
        w = np.exp(beta * s_shifted)
        w /= w.sum()
        
        # Compute gradient
        g = np.zeros(n)
        for d_idx in range(2 * n - 1):
            if w[d_idx] < 1e-12:
                continue
            d = d_idx - (n - 1)
            g += w[d_idx] * _score_grad(h, d)
        
        # Remove mean (to respect the sum constraint approximately)
        g_centered = g - g.mean()
        
        # Try Newton step
        # Build Hessian (expensive, but n is small)
        H = _build_hessian(h, w, beta)
        
        # Solve (H + reg*I) δ = -g_centered
        reg = 0.01
        try:
            delta = np.linalg.solve(H + reg * np.eye(n), -g_centered)
        except:
            delta = -g_centered / (np.linalg.norm(g_centered) + 1e-15)
        
        # Line search with projection
        best_alpha = 0
        best_new_c5 = best_c5
        for alpha in [1.0, 0.5, 0.25, 0.125, 0.0625, 0.03125]:
            h_try = _project(h + alpha * delta, target)
            c5_try = _exact_c5(h_try)
            if c5_try < best_new_c5:
                best_new_c5 = c5_try
                best_alpha = alpha
                h_try_best = h_try
        
        if best_alpha > 0 and best_new_c5 < best_c5 - 1e-15:
            h = h_try_best
            best_c5 = best_new_c5
            best_h = h.copy()
        else:
            # Try gradient step
            g_norm = np.linalg.norm(g_centered)
            if g_norm < 1e-12:
                break
            for alpha in [0.01, 0.005, 0.001]:
                h_try = _project(h - alpha * g_centered / g_norm, target)
                c5_try = _exact_c5(h_try)
                if c5_try < best_c5:
                    h = h_try
                    best_c5 = c5_try
                    best_h = h.copy()
                    break
    
    return best_h, best_c5
```

The Hessian construction for n=128:
- 255 lags, each with bandwidth |d|
- Total non-zeros: O(n²) 
- Building time: O(n²) per iteration

For n=128, this is about 16K operations per Hessian. Solving the 128×128 system is about 2M operations. Total per Newton step: ~2M operations. At 100M ops/sec, that's 20ms per step. In 30 seconds, I can do ~1500 Newton steps. That's plenty.

But wait, I need to be more careful about the Hessian construction. Let me think about it.

H = β(Σ w_d ∇S_d ∇S_d^T - gg^T) + Σ w_d ∇²S_d

The ∇S_d ∇S_d^T terms: each ∇S_d is an n-vector. The outer product is n×n. Summing over d: O(n² * n_lags) = O(n³) in the worst case. For n=128, that's 128³ ≈ 2M. Fine.

The ∇²S_d terms: each is a banded matrix with 2(n-|d|) non-zeros. Summing: O(n * n_lags) = O(n²). Fine.

Total Hessian construction: O(n³) per step, which is about 2M for n=128. That's fine.

Actually, I realize I can be smarter. The outer product Σ w_d ∇S_d ∇S_d^T can be computed as:
Let G be the matrix with rows ∇S_d^T (shape (2n-1, n)).
Then Σ w_d ∇S_d ∇S_d^T = G^T (W G) / ... 

Actually: Σ_d w_d ∇S_d ∇S_d^T = (G * w)^T @ (G * w) ... no.

Let me just compute it directly. G is (2n-1) × n. Each row d is ∇S_d^T.
Σ_d w_d ∇S_d ∇S_d^T = G^T @ diag(w) @ G

This is O(n² * n_lags) = O(n³). For n=128, that's fine.

```python
import numpy as np
from scipy.optimize import linprog, minimize
import time

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _scores(h):
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo = float(v.min()) - 2.0
    hi = float(v.max()) + 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    x = np.clip(v - (lo + hi) / 2.0, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-12:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _score_grad(h, d):
    n = len(h)
    dx = 2.0 / n
    grad = np.zeros(n)
    if d >= 0:
        m = n - d
        if m > 0:
            grad[:m] += (1.0 - h[d:])
            grad[d:] += h[:m]
    else:
        g = -d
        m = n - g
        if m > 0:
            grad[g:] += (1.0 - h[:m])
            grad[:m] += h[g:]
    return grad * dx

def _lse_grad(h, beta):
    scores = _scores(h)
    s_max = scores.max()
    w = np.exp(beta * (scores - s_max))
    w /= w.sum()
    g = np.zeros(len(h))
    for d_idx in range(len(scores)):
        if w[d_idx] < 1e-13:
            continue
        d = d_idx - (len(h) - 1)
        g += w[d_idx] * _score_grad(h, d)
    return g, w, scores

def _build_hessian(h, w, beta):
    n = len(h)
    dx = 2.0 / n
    H = np.zeros((n, n))
    # Σ w_d ∇²S_d
    for d_idx in range(2 * n - 1):
        w_d = w[d_idx]
        if w_d < 1e-13:
            continue
        d = d_idx - (n - 1)
        if d == 0:
            continue
        m = n - abs(d)
        if m <= 0:
            continue
        off = abs(d)
        for i in range(m):
            H[i, i + off] -= w_d * dx
            H[i + off, i] -= w_d * dx
    # β (Σ w_d ∇S_d ∇S_d^T - gg^T)
    g = np.zeros(n)
    for d_idx in range(2 * n - 1):
        w_d = w[d_idx]
        if w_d < 1e-13:
            continue
        d = d_idx - (n - 1)
        gd = _score_grad(h, d)
        g += w_d * gd
        H += beta * w_d * np.outer(gd, gd)
    H -= beta * np.outer(g, g)
    return H, g

def _newton_lse(h, deadline, beta_init=30.0, beta_end=200.0, max_iters=500):

    target = n / 2.0
    h = h.copy()
    best_h = h.copy()
    best_c5 = _exact_c5(h)
    
    for it in range(max_iters):
        if time.time() > deadline:
            break
        frac = it / max(1, max_iters - 1)
        beta = beta_init * (beta_end / beta_init) ** frac
        
        g, w, scores = _lse_grad(h, beta)
        g_c = g - g.mean()
        
        H, _ = _build_hessian(h, w, beta)
        
        # Regularize for PD
        reg = 0.005
        try:
            delta = np.linalg.solve(H + reg * np.eye(n), -g_c)
        except:
            delta = -g_c / (np.linalg.norm(g_c) + 1e-15)
        
        cleaned = False
        for alpha in [1.0, 0.7, 0.5, 0.35, 0.25, 0.15, 0.1, 0.05]:
            h_try = _project(h + alpha * delta, target)
            c5_try = _exact_c5(h_try)
            if c5_try < best_c5 - 1e-15:
                h = h_try
                best_c5 = c5_try
                best_h = h.copy()
                cleaned = True
                break
        
        if not cleaned:
            # Gradient fallback
            gn = np.linalg.norm(g_c)
            if gn < 1e-13:
                break
            for alpha in [0.01, 0.005, 0.002, 0.001]:
                h_try = _project(h - alpha * g_c, target)
                c5_try = _exact_c5(h_try)
                if c5_try < best_c5 - 1e-15:

                    best_c5 = c5_try

def _fw_optimize(h, deadline, beta=50.0, max_iters=10000):
    n = len(h)
    target = n / 2.0
    h = h.copy()
    best_h = h.copy()
    best_c5 = _exact_c5(h)
    n_active = n // 2
    
    for it in range(max_iters):
        if time.time() > deadline:
            break
        g, w, scores = _lse_grad(h, beta)
        
        # FW: minimize g·v over {v: 0≤v≤1, sum(v)=n/2}
        # Optimal: v=1 at positions with smallest g values
        idx = np.argsort(g)
        v = np.zeros(n)
        v[idx[:n_active]] = 1.0
        
        gamma = 2.0 / (it + 2.0)
        h_new = (1.0 - gamma) * h + gamma * v
        h_new = _project(h_new, target)
        c5_new = _exact_c5(h_new)
        
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new.copy()
        h = h_new
    
    return best_h, best_c5

def _lp_direction(h, scores, radius):
    n = len(h)
    n_lags = len(scores)
    dx = 2.0 / n
    
    # Build gradient matrix
    G = np.zeros((n_lags, n))
    for d_idx in range(n_lags):
        d = d_idx - (n - 1)
        if d >= 0:
            m = n - d
            if m > 0:
                G[d_idx, :m] += (1.0 - h[d:])
                G[d_idx, d:] += h[:m]
        else:
            g = -d
            m = n - g
            if m > 0:
                G[d_idx, g:] += (1.0 - h[:m])
                G[d_idx, :m] += h[g:]
    G *= dx
    
    c = np.zeros(n + 1)
    c[-1] = 1.0
    A_ub = np.zeros((n_lags, n + 1))
    A_ub[:, :n] = G
    A_ub[:, n] = -1.0
    b_ub = -scores
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.zeros(1)
    bounds = []
    for j in range(n):
        bounds.append((max(-radius, -h[j]), min(radius, 1.0 - h[j])))
    bounds.append((None, None))
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs')
        if res.success:
            return res.x[:n], res.x[-1]
    except:
        pass
    return None, None

def _line_search_c5(h, p, c5_cur):
    n = len(h)
    alpha_max = 0.999
    for j in range(n):
        if p[j] > 1e-14:
            alpha_max = min(alpha_max, (1.0 - h[j]) / p[j])
        elif p[j] < -1e-14:
            alpha_max = min(alpha_max, h[j] / (-p[j]))
    alpha_max = max(alpha_max, 1e-12) * 0.99
    
    # Golden section
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    lo, hi = 0.0, alpha_max
    c1 = hi - gr * (hi - lo)
    c2 = lo + gr * (hi - lo)
    f1 = _exact_c5(_project(h + c1 * p, n / 2.0))
    f2 = _exact_c5(_project(h + c2 * p, n / 2.0))
    for _ in range(25):
        if hi - lo < 1e-14:
            break
        if f1 < f2:
            hi = c2; f2 = f1; c2 = c1
            c1 = hi - gr * (hi - lo)
            f1 = _exact_c5(_project(h + c1 * p, n / 2.0))
        else:
            lo = c1; f1 = f2; c1 = c2
            c2 = lo + gr * (hi - lo)
            f2 = _exact_c5(_project(h + c2 * p, n / 2.0))
    opt_a = (lo + hi) / 2.0
    opt_c5 = _exact_c5(_project(h + opt_a * p, n / 2.0))
    return opt_a, opt_c5

def _local_lp(h, deadline, radius_init=0.2, max_iters=3000, stall_limit=100):

def _resample(h, n_new):
    n = len(h)
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return _project(h_new, n_new / 2.0)

def _pair_polish(h, deadline, passes=10):
    n = len(h)
    h = h.copy()
    best_h = h.copy()
    best_c5 = _exact_c5(h)
    step = max(1, n // 64)
    
    for _pass in range(passes):
        if time.time() > deadline:
            break
        improved = False
        for j in range(0, n, step):
            if time.time() > deadline:
                break
            if h[j] <= 1e-9 or h[j] >= 1.0 - 1e-9:
                continue
            for k in range(j + step, n, step):
                if h[k] <= 1e-9 or h[k] >= 1.0 - 1e-9:
                    continue
                for sign in [1, -1]:
                    if sign > 0:
                        a_max = min(1.0 - h[j], h[k])
                    else:
                        a_max = min(h[j], 1.0 - h[k])
                    if a_max < 1e-11:
                        continue
                    lo_a, hi_a = 0.0, a_max
                    for _ in range(8):
                        m1 = lo_a + (hi_a - lo_a) / 3.0
                        m2 = hi_a - (hi_a - lo_a) / 3.0
                        h1 = h.copy(); h1[j] += sign * m1; h1[k] -= sign * m1
                        f1 = _exact_c5(h1)
                        h2 = h.copy(); h2[j] += sign * m2; h2[k] -= sign * m2
                        f2 = _exact_c5(h2)
                        if f1 < f2:
                            hi_a = m2
                        else:
                            lo_a = m1
                    a_opt = (lo_a + hi_a) / 2.0
                    if a_opt < 1e-11:
                        continue
                    h_try = h.copy()
                    h_try[j] += sign * a_opt
                    h_try[k] -= sign * a_opt
                    h_try = np.clip(h_try, 0.0, 1.0)
                    c5_try = _exact_c5(h_try)
                    if c5_try < best_c5 - 1e-15:
                        best_c5 = c5_try
                        best_h = h_try.copy()
                        h = h_try.copy()
                        improved = True
        if not improved:
            break
    return best_h, best_c5

def _slsqp_smooth(h, deadline, beta_init=40.0, beta_final=300.0, n_phases=3):
    n = len(h)
    target = n / 2.0
    h = h.copy()
    best_h = h.copy()
    best_c5 = _exact_c5(h)
    
    for phase in range(n_phases):
        if time.time() > deadline:
            break
        frac = phase / max(1, n_phases - 1)
        beta = beta_init * (beta_final / beta_init) ** frac
        
        def obj(hf):
            S = _scores(hf)
            s_max = S.max()
            shifted = np.clip(beta * (S - s_max), -500, 0)
            return s_max + np.log(np.mean(np.exp(shifted))) / beta
        
        def grad(hf):
            S = _scores(hf)
            s_max = S.max()
            shifted = np.clip(beta * (S - s_max), -500, 0)
            w = np.exp(shifted)
            wsum = w.sum()
            if wsum < 1e-300:
                w = np.zeros(len(S))
                w[int(np.argmax(S))] = 1.0
            else:
                w /= wsum
            G = np.zeros((len(S), n))
            for d_idx in range(len(S)):
                d = d_idx - (n - 1)
                G[d_idx, :] = _score_grad(hf, d)
            return G.T @ w
        
        try:
            res = minimize(obj, h, jac=grad, method='SLSQP',
                          bounds=[(0.0, 1.0)] * n,
                          constraints=[{'type': 'eq',
                                        'fun': lambda x: np.sum(x) - target,
                                        'jac': lambda x: np.ones(n)}],
                          options={'maxiter': 100, 'ftol': 1e-14})
            if np.all(np.isfinite(res.x)):
                h_new = _project(res.x, target)
                c5_new = _exact_c5(h_new)
                if c5_new < best_c5:
                    best_c5 = c5_new
                    best_h = h_new.copy()
                h = h_new
        except:
            pass
    return best_h, best_c5
```

```python
def _project(v, target):

    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo = float(np.min(v)) - 2.0

            f2 = f1
            c2 = c1
            c1 = hi - gr * (hi - lo)
            f1 = _exact_c5(_project(h + c1 * p, target))
        else:
            lo = c1
            f1 = f2
            c1 = c2
            c2 = lo + gr * (hi - lo)
            f2 = _exact_c5(_project(h + c2 * p, target))
    opt_a = (lo + hi) / 2.0
    opt_c5 = _exact_c5(_project(h + opt_a * p, target))
    return opt_a, opt_c5

def _local_lp(h, deadline, radius_init=0.25, max_iters=4000, stall_limit=120):
    n = len(h)
    target = n / 2.0
    h = h.copy()
    best_h = h.copy()
    best_c5 = _exact_c5(h)
    radius = radius_init
    stall = 0
    for it in range(max_iters):
        if time.time() > deadline:
            break
        if stall > stall_limit:
            if it < 200:
                radius = min(radius * 1.5, 0.35)
                stall = 0
                continue
            break
        scores = _scores(h)
        p, t = _lp_direction(h, scores, radius)
        if p is None or float(np.max(np.abs(p))) < 1e-14:
            stall += 1
            radius *= 0.85
            if radius < 1e-7:
                break
            continue
        alpha, new_c5 = _line_search_c5(h, p)
        if new_c5 < best_c5 - 1e-14:
            h = _project(h + alpha * p, target)
            h_c5 = _exact_c5(h)
            if h_c5 < best_c5:
                best_c5 = h_c5
                best_h = h.copy()
            stall = 0
            radius = min(radius * 1.12, 0.45)
        else:
            stall += 1
            radius *= 0.85
            if stall > 50 and radius < 0.04:
                radius = 0.12
    return best_h, best_c5

def _resample(h, n_new):
    n = len(h)
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return _project(h_new, n_new / 2.0)

def _quasi_init(n, alpha):
    x = (np.arange(n) + 0.5) / n
    h = ((x * alpha) % 1.0) < 0.5
    h = h.astype(float)
    return _project(h, n / 2.0)

def _pair_polish(h, deadline, passes=12):
    n = len(h)
    h = h.copy()
    best_h = h.copy()
    best_c5 = _exact_c5(h)
    step = max(1, n // 80)
    for _pass in range(passes):
        if time.time() > deadline:
            break
        improved = False
        for j in range(0, n, step):
            if time.time() > deadline:
                break
            if h[j] <= 1e-9 or h[j] >= 1.0 - 1e-9:
                continue
            for k in range(j + step, n, step):
                if h[k] <= 1e-9 or h[k] >= 1.0 - 1e-9:
                    continue
                for sign in [1, -1]:
                    if sign > 0:
                        a_max = min(1.0 - h[j], h[k])
                    else:
                        a_max = min(h[j], 1.0 - h[k])
                    if a_max < 1e-11:
                        continue
                    lo_a, hi_a = 0.0, a_max
                    for _ in range(8):
                        m1 = lo_a + (hi_a - lo_a) / 3.0
                        m2 = hi_a - (hi_a - lo_a) / 3.0
                        h1 = h.copy()
                        h1[j] += sign * m1
                        h1[k] -= sign * m1
                        f1 = _exact_c5(h1)
                        h2 = h.copy()
                        h2[j] += sign * m2
                        h2[k] -= sign * m2
                        f2 = _exact_c5(h2)
                        if f1 < f2:
                            hi_a = m2
                        else:
                            lo_a = m1
                    a_opt = (lo_a + hi_a) / 2.0
                    if a_opt < 1e-11:
                        continue
                    h_try = h.copy()
                    h_try[j] += sign * a_opt
                    h_try[k] -= sign * a_opt
                    h_try = np.clip(h_try, 0.0, 1.0)
                    c5_try = _exact_c5(h_try)
                    if c5_try < best_c5 - 1e-15:
                        best_c5 = c5_try
                        best_h = h_try.copy()
                        h = h_try.copy()
                        improved = True
        if not improved:
            break
    return best_h, best_c5

def _fw_optimize(h, deadline, beta=60.0, max_iters=8000):
    n = len(h)
    target = n / 2.0
    h = h.copy()
    best_h = h.copy()
    best_c5 = _exact_c5(h)
    n_act = n // 2
    for it in range(max_iters):
        if time.time() > deadline:
            break
        g, w, scores = _lse_grad(h, beta)
        idx = np.argsort(g)
        v = np.zeros(n)
        v[idx[:n_act]] = 1.0
        gamma = 2.0 / (it + 2.0)
        h_new = (1.0 - gamma) * h + gamma * v
        h_new = _project(h_new, target)
        c5_new = _exact_c5(h_new)
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new.copy()
        h = h_new
    return best_h, best_c5

def _slsqp_obj(hf, beta, target):
    S = _scores(hf)
    s_max = S.max()
    shifted = np.clip(beta * (S - s_max), -500.0, 0.0)
    return s_max + np.log(np.mean(np.exp(shifted))) / beta

def _slsqp_grad(hf, beta, target):
    S = _scores(hf)
    n = len(hf)
    s_max = S.max()
    shifted = np.clip(beta * (S - s_max), -500.0, 0.0)
    w = np.exp(shifted)
    wsum = float(np.sum(w))
    if wsum < 1e-300:
        w = np.zeros(len(S))
        w[int(np.argmax(S))] = 1.0
    else:
        w /= wsum
    g = np.zeros(n)
    for d_idx in range(len(S)):
        if w[d_idx] < 1e-13:
            continue
        d = d_idx - (n - 1)
        g += w[d_idx] * _score_grad(hf, d)
    return g

def _slsqp_eq_fun(hf, beta, target):
    return np.sum(hf) - target

def _slsqp_eq_jac(hf, beta, target):
    return np.ones(len(hf))
```
