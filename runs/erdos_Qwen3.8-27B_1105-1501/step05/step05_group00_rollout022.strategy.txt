1. Approach and rationale

   1.1 Primary scientific decision

   The current parent construction has n = len(initial_h_values), and its reported bound is about 0.380891. The improved target is 0.3808. The central hypothesis used here is that the parent is already deep in a local min-max landscape, and the remaining 8.9e-5 gap is not best attacked by broad simulated annealing or whole-variable LP linearizations, but by local movements that directly target the small set of active correlation peaks while exactly preserving the original evaluation formula.

   The proposed method is a coordinate-transfer min-max descent with four ingredients:

   1. An exact line-search scheme over sparse zero-sum coordinate directions. A candidate direction is typically a pair specifying that a small amount of mass is moved from coordinate i to coordinate j. The path h + α d is exactly represented by the identity
      correlate(h + α d, 1 - (h + α d), 'full') =
      S0 + α [correlate(d, 1 - h, 'full') - correlate(h, d, 'full')]
          - α^2 correlate(d, d, 'full'),
      where S0 = correlate(h, 1 - h, 'full'). Multiplying any of these raw arrays by dx = 2/n gives the exact evaluator values along the path. This stage has no projection or clipping inside the line path; the feasible interval is derived from the box constraints, and any accepted endpoint is projected only to remove floating-point drift.

   2. Active-peak gradient screening. For the current feasible h, the largest correlation values are weighted, and a weight-decomposed directional gradient over h coordinates is used only as a proposal heuristic. Candidate pair directions are chosen so that moving eligible donor mass toward eligible recipient mass is plausible as a descent for that weighted active peak sum. The objective used for acceptance is still the exact max of the finite-support evaluator, not a surrogate. This gives an inexpensive proposal mechanism without pretending to have globally solved a convex relaxation.

   3. Determinitimate paired local search plus limited stochastic regeneration. Rather than a broad SA phase that randomizes full vector moves, the search uses a deterministic beam of candidate nonzero pair directions, taken from:
      - high gradient donors and low gradient recipients,
      - coordinates included in active peak row ranges,
      - endpoints and near-endpoints because finite-support lag constraints include one-sided boundary overlap zones that the exact evaluator must count,
      - a small random perturbation of the accepted feasible current vector.

   4. Multi-resolution support. The parent is preserved unless a strictly smaller exact evaluator value is found. The program also tests transformed vectors at the parent resolution plus a small set of even offsets, including shorter resolutions. Because the independent optimization variable is h as sampled on [0, 2] at any chosen n, smaller n values can genuinely represent different discrete controls. Scores are compared only through the exact evaluator for the returned n.

   The method is heuristic, nonconvex, and local. No global optimality or guarantee of reaching 0.3808 is asserted. The fallback is a valid parent vector and its exact normalized C5 value.

   1.2 Why this is materially different from the prior strategy

   The prior pipeline exchanged most of its effort among a large LP linearization loop, binary and graded simulated annealing, SLSQP-style smoothing, and general pair refinement. The proposal above replaces broad exploratory annealing by a precise active-peak pair-transfer search. The decisive change is that candidate proposals preserve the sum constraint without any nonlinear projection for the usual pair flow d_i = -1, d_j = +1, and their paths are optimized exactly using the correlation quadratic identity. The local optimization focus is not “improve surrogate locally” but “attempt to lower the maximum active rows by moving capacity between coordinates that the active row gradients indicate are useful, and accept only if the exact correlation array lowers the active peak.” In addition, endpoint-aware candidate generation, fixed beam pair proposals, and resolution transfer are implemented as a coherent local search framework, not random one-point Gaussian SA.
