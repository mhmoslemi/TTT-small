            d_ = a + gr * (b - a)

            # Update S and G
            S = _scores_vec(h)
            G = _grad_matrix(h)
            accepted += 1

Actually, let me reconsider the approach. The previous solution already does a lot of local optimization. The key question is: can pair transfer optimization beat the LP-based approach?

The LP approach finds the best direction within a ball of radius r, subject to the linearized constraints. This is a very strong local search - it's essentially finding the best descent direction in a polytope.

The pair transfer approach is weaker in that it only explores 1D directions. However:
1. It does EXACT 1D optimization (no linearization error)
2. It preserves feasibility exactly (no projection needed)
3. It can make large steps when the objective allows

In practice, the LP approach with small radius is similar to taking small steps in the best direction. The pair transfer with exact optimization might be better for large steps but worse for small steps.

I think the key to improvement is in the GLOBAL search (finding better starting points) rather than the LOCAL search. Let me focus more on:
1. Diverse starting points
2. Binary SA for finding good basins
3. Multi-resolution

Let me also add one more technique: **coordinate descent with exact optimization**. For each coordinate i, find the optimal value h[i] (with all others fixed) subject to the sum constraint. This is:
- Fix h[j] for j ≠ i
- The sum constraint gives: h[i] = target - ∑_{j≠i} h[j]
- This must satisfy 0 ≤ h[i] ≤ 1
- If the constraint is satisfied, the new h[i] is forced (no freedom)
- So this doesn't work as a free optimization

The pair transfer is the natural "degree of freedom" in this problem: we can move mass between two coordinates while preserving the sum.

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _scores_vec(h):
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def _project(v, target):
    n = len(v)
    v = np.asarray(v, dtype=float)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo = float(v.min()) - 2.0
    hi = float(v.max()) + 2.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    x = np.clip(v - (lo + hi) / 2.0, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-12:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _grad_matrix(h):
    n = len(h)
    dx = 2.0 / n
    G = np.zeros((2 * n - 1, n))
    G[n - 1, :] = dx * (1.0 - 2.0 * h)
    for d in range(1, n):
        m = n - 1 + d
        G[m, :n - d] += dx * (1.0 - h[d:])
        G[m, d:] -= dx * h[:n - d]
        m2 = n - 1 - d
        G[m2, d:] += dx * (1.0 - h[:n - d])
        G[m2, :n - d] -= dx * h[d:]
    return G

def _pair_search(S, dG, t_lo, t_hi, n_iter=22):

        return (t_lo + t_hi) / 2.0

    a, b = t_lo, t_hi

    d_ = a + gr * (b - a)

    fd = float(np.max(S + d_ * dG))

def _resample(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
