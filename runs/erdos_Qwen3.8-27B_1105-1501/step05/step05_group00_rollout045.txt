Now let me think about the LP more carefully. The parent code builds the full gradient matrix (2n-1 rows) and includes all lags in the LP. This is correct but might be overkill. 

For the LP direction, we want:
minimize u
subject to: G_k · d - u ≤ -S_k for all k (i.e., G_k·d + S_k ≤ u)
            sum(d) = 0
            -radius ≤ d_i ≤ radius

The key constraint is that the predicted new score (S_k + G_k·d) should be ≤ u for all k. We minimize u to get the best decrease.

But we only really care about the lags that are near the maximum. For lags far below the maximum, the constraint G_k·d + S_k ≤ u is automatically satisfied if u is close to max(S) and the direction doesn't increase them too much. So including all lags is conservative but safe.

For efficiency, we could include only "near-active" lags (say within 20% of the max) in the LP, and check the rest after the step. But this might be risky. Let's keep all lags for safety but maybe use a smaller problem.

Actually, for n=122, the LP has 123 variables and 243+1 constraints. HiGHS should solve this in <1ms. So it's not a bottleneck.

**Key idea: Use the smooth surrogate gradient as an additional direction**

The log-sum-exp gradient gives a smooth approximation to the max gradient. It naturally weights the active lags more heavily. This might give a better direction than the LP in some cases.

For the log-sum-exp:
ψ_β(h) = (1/β)·ln(∑_k exp(β·f_k(h)))

∇ψ_β(h) = ∑_k w_k · ∇f_k(h) where w_k = exp(β·f_k)/∑exp(β·f_j)

For large β, this concentrates on the active lags. For moderate β, it's a smoother blend.

The direction -∇ψ_β (projected onto sum=0) might give a better step than the LP direction.

Let me also think about **SLSQP with log-sum-exp**:

minimize: ψ_β(h) = (1/β)·ln(∑_k exp(β·(corr_k·dx)))
subject to: sum(h) = n/2
            0 ≤ h_i ≤ 1

This is a smooth NLP. SLSQP should be able to handle it. The challenge is choosing β:
- Too small: the surrogate is too far from the max, so the solution is different
- Too large: numerical instability in exp

A good strategy: start with β = 1/τ where τ ≈ 0.01·C₅, then increase β geometrically, using the previous solution as a warm start.

For n=122, SLSQP with 122 variables and 1 equality constraint should be fast (maybe 1-10 seconds per β value).
