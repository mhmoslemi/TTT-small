1. Approach and rationale

1.1 Central idea

The supplied parent is already close to a local minimax optimum, but the dominant practical bottleneck is not first-order smoothness of the objective; it is that, near the optimum, a large set of lag-overlap scores is simultaneously very close to the maximum. Reducing the maximum requires moving mass in a direction that lowers a selected cluster of high scores much more than it raises the remaining high scores. Standard supergradient, log-sum-exp smoothing, or generic gradient steps often stall because they either spread the update over many irrelevant lags or reduce one active lag while slightly increasing another.

This plan uses a materially different primary engine: a target-residual least-squares leveling mechanism. At a current feasible vector h, choose a candidate target bound C_target strictly smaller than the current exact objective. Define active rows to be the actual finite-support correlation rows whose raw overlap value is above the corresponding continuous target. Solve a regularized linear least-squares problem whose equation asks a zero-mean displacement p to reduce the active residuals according to their residual-driven priorities. The resulting p is then entered into the exact quadratic one-dimensional evaluation line h + α p, where the full evaluator, not a surrogate, is used to select or reject α. If the exact objective improves, commit and lower the target; otherwise shrink the target-gap, adapt the trust radius, and retry. This is distinct from smoothing the maximum because it solves an explicit leveling problem toward an attainable lower bound, and distinct from pure gradient descent because the direction is chosen to equalize the predicted reductions across the active constraint set.

The method is combined with deterministic and stochastic multiscale exploration:
- exact validation and repair of the supplied parent;
- mirrored, complemented, low-frequency, and directly constructed alternative seeds at related resolutions;
- interpolation, upsampling, and downsampling with joint feasibility repair;
- the target-residual least-squares leveling stage;
- exact line updates along momentum and random zero-mean directions when the deterministic leveling stage stalls.

Every proposed vector that may replace the incumbent is checked with the authoritative evaluator
  C5(h) = max(np.correlate(h, 1 - h, mode="full")) * (2/n)
and by a joint feasibility repair/projection that enforces 0 <= h_i <= 1 and sum_i h_i = n/2.

1.2 Why this addresses the parent bottleneck

Facts:
- The official evaluator uses finite-support linear correlation, not circular correlation. The full-correlation indexing and the boundary overlap length of each row must be respected.
- The objective is nonconvex because of products h_i h_j. No convex formulation of the exact problem is claimed.
- The box constraints and the mass constraint must be treated jointly. Simple clipping and then scaling can violate the bounds; simple sum correction can violate the present parent bounds. A joint projection mechanism is needed.
- The exact value at a certain discretization n is not necessarily denoted by a common scale. A vector at one n may have a lower exact C5 than a finer vector even if it is a coarser approximation. Candidates with different n may therefore be compared only through the actual evaluator at their own n.

The active-residual leveling method is designed for the practically observed phenomenon that several rows have scores close to each other. Instead of only moving along a single supergradient, it solves a small operational tangent problem that asks how much each active score should decrease relative to the suggested conservative progress downward. Since each candidate is checked exactly afterward, the nonconvexity is accepted and handled by candidate acceptance, not by claiming convexity.

Hypotheses:
- The parent's local basin retains a modest descent direction in a finely sampled formulation that is invisible at n = 122 because of discretization and flat active rows.
- Continuation over successively smaller intended gaps unlocks the next descent step at dimensions larger than the parent.
- Low-frequency and complementary initializations may provide alternative basins from which exact polishing can fall returned to a lower objective near the continuous limit.

No optimality claim is made. The output is the exact best candidate discovered within the time budget.

2. Mathematical specification

2.1 Exact representation and objective

For an array h of length n >= 32, let
  dx = 2.0 / n
  target = n / 2.0
  scores_raw = np.correlate(h, 1.0 - h, mode="full")
This array has length M = 2n - 1 and index r = 0, ..., M - 1. The official bound is
  C5(h) = dx * max(scores_raw).

All algorithmic objectives, except for progress control and final reporting, may use scores_raw, but acceptance is always based on scaled exact C5(h) and its recomputation from the evaluator.

A feasibility check must require:
  all h_i finite;
  -1e-12 <= h_i <= 1 + 1e-12 numerically, but committed values are repaired to satisfy actual bounds;
  |sum(h) - target| <= 1e-10 in an internal acceptance tolerance, and after final answer make this as close to zero as floating-point arithmetic allows.

2.2 Correlation row formula and calibration

The algorithm requires a formula matching the full-returned row r. It should not assume the sign convention. Let
  lag(e) = candidate value for signed lag e.
At runtime this should be certified by a small deterministic calibration on a length about 40 feasible vector constructed without relying on the parent.

Use one of the following candidate orientations. For signed lag ell:

If ell >= 0:
  formula = sum_{i=0}^{n-1-ell} h[i+ell] * (1 - h[i])

If ell < 0:
  g = -ell
  formula = sum_{i=0}^{n-1-g} h[i] * (1 - h[i+g])

Try the candidate represented by a global multiplier sigma_row in {+1, -1}:

If changing the actual evaluator ordering creates exactly reversed scores, this testing chooses the other sign. In addition to a score calibration, test the Jacobian corresponding to the same chosen orientation with finite differences. The full formula/gradient calibration should minimize a metric such as mean absolute score difference plus mean absolute gradient difference over all rows r and coordinate j. The result is stored for the chosen problem lengths:

  gradient_flip = sigma_grad in {+1, -1}
The gradient must be derived for the row formula matching scores_raw row, multiplied by gradient_flip.

If all algorithmic signs after testing are unreliable, the method should still continue using the most likely calibration, because the final direction is tested exactly. But the best output uses the calibrated signs.

2.3 Exact row gradient

Use raw scores without dx in the least-squares direction calculation. Given signed lag ell from the calibrated row map, the raw gradient is:

If ell >= 0:
  initialize g = zeros(n)
  for i = 0, ..., n-1-ell:
      u = i + ell
      g[u] += (1 - h[i])
      g[i] -= h[u]

If ell < 0:
  g_pos = -ell
  initialize g = zeros(n)
  for i = 0, ..., n-1-g_pos:
      u = i + g_pos
      g[i] += (1 - h[u])
      g[u] -= h[i]

The gradient of the actual raw score array entry is then
  gradient_row = gradient_flip * g.
For ell = 0, this returns 1 - 2h_i, derived by one common accumulation path, avoiding the need for a special case.

Algorithm:

2. Bisection search for theta in

3. Compute x_i = clip(v_i - theta, 0, 1).
4. Let residual = target - sum(x).

5. If residual > 0 and there is at least one index with x_i < 1:

6. If residual still matters, recompute theta on the most recent adjust and repeat endpoints twice. Such a case indicates an impossible repair under current scaling and must never accidentally become the best candidate.
