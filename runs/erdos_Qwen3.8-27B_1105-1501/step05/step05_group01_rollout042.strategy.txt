1. APPROACH AND RATIONALE

1.1. Central idea

The supplied parent is a good continuous discretization, but it is already close to a local optimum under the previous local linear-programming and pair-swap procedure. The proposed method keeps the exact discrete objective as the only accepted gain, but changes the search to a hybrid between:

- A discrete/binary set search over balanced bit strings, because balanced binary encodings have the exact zero-lag objective value 0 and can be searched by exact swaps and block moves.
- A continuous nonsmooth local polish, because target gains are small and fractional vectors can reduce peak overlap below binary grid values.
- Exact global finite-interval minimization on each proposed direction, not only a one-bracket golden search, so curve-shaped nonconvex line objectives are handled more reliably.
- Multi-resolution basin hopping, because the parent grid can be a discrete approximation and finer/coarser resamplings can reveal better local basins.

The primary search is not a single convex relaxation. The exact function is inherently nonconvex. Convexity is not claimed. The advantages over the previous method are:

1. Exact balanced binary direct moves with alpha equal to the full discrete transition, rather than only infinitesimal line-search along unit transfers. This lets the search jump across local valleys.
2. Multi-bit block transfers with line-search choices, which combine local determinism and stochastic escape.
3. Explicit basin hopping with a candidate pool and controlled simulated acceptance.
4. Active-set LP directions that are attempted together but never trusted; every candidate is only accepted by the exact finite-correlation objective.
5. Multi-resolution candidates with parent fallback all the way through.

This strategy can find values better than the previous record, but no global optimality or guaranteed achievement of 0.3808 is claimed. The parent projection is always retained as a valid fallback.

1.2. Limitations and hypotheses

The method may stall in the parent basin or choose poor sub-families. It may not find the global optimum. Smoothing and LP directions are heuristics and can point away from the true finite family; exact verification controls that. The main hypothesis is that more exact but locally structured bounded traveling from balanced binary pools and more robust line subdivision can yield a lower exact maximum than repeated local linearization only.
