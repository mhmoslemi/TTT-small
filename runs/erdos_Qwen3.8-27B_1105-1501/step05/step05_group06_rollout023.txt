`f_k = sum_{i=0}^{n-1-k} h[i+k] * (1-h[i])`

```python
def _build_G(h):
    n = len(h)
    dx = 2.0 / n
    G = np.zeros((2 * n - 1, n))
    c = n - 1
    # Lag 0
    G[c, :] = dx * (1.0 - 2.0 * h)
    # Positive lags (index c+k)
    for k in range(1, n):
        m = n - k
        # ∂f_k/∂h[j] = (1-h[j-k]) for j >= k, minus h[j+k] for j <= m-1
        # For j = k, ..., n-1: add (1-h[j-k])
        G[c+k, k:] += dx * (1.0 - h[:m])  # j-k = 0,1,...,m-1, so 1-h[0],1-h[1],...
        # For j = 0, ..., m-1: add -h[j+k]
        G[c+k, :m] += -dx * h[k:]  # j+k = k, k+1, ..., n-1
        # Negative lags (index c-k)
        # ∂f_{-k}/∂h[j] = (1-h[j+k]) for j <= m-1, minus h[j-k] for j >= k
        G[c-k, :m] += dx * (1.0 - h[k:])  # j+k = k, k+1, ..., n-1
        G[c-k, k:] += -dx * h[:m]  # j-k = 0, 1, ..., m-1
    return G
```
