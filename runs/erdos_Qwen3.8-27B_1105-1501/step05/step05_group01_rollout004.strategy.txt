1. Approach and rationale

1.1 Central idea

The supplied parent vector is a valid high-quality point, but it appears to sit close to a local optimum for local unit-transfer / linearized LP searches. Improvement at the target level `≈3.808e-1` is therefore likely to require nontrivial shifts in the whole shape of the discrete profile, not just one-cell pair exchanges. The proposed method is materially different from the earlier LP/pair-swap/search pattern in three substantive ways:

1. **Exact finite-support minimax optimization in the full high-dimensional vector, using a smooth LSE surrogate and optional SLSQP/LSE optimization of the entire vector.**  
   The search optimizes a differentiable log-sum-exp approximation of the exact nonsmooth maximum over all finite-lag overlap scores, with an analytic gradient. This allows large, well-aligned moves in the full vector, rather than repeatedly generating line directions from infinitesimal pair transfers.

2. **Low-dimensional constrained global search over function families whose representation is always feasibly projected to the exact discrete constraint.**  
   Candidate profiles are generated by a low-dimensional array of control values. The low-dimensional variables are chosen globally (for example, with exact or smoothed Powell/BasinHopping/DE), then mapped to the grid by interpolation and joint feasibility repair. Only the exact original objective decides acceptance. This can move outside the parent’s local basin through compact smooth or structured shapes.

3. **Robust exact line minimization over full random/block/gradient directions, not just binary pair moves or bracket-assuming golden search.**  
   Any proposed direction has zero mass sum, preserving the integral constraint without a projection that would otherwise corrupt the objective. The line objective is evaluated from the quadratic correlation model (exact along the feasible box segment) and searched by dense grid plus multi-bracket refinement. Every candidate is accepted only after full re-projected exact re-evaluation.

This plan is not a convex relaxation and does not claim global optimality. It is a multi-scale, exact-acceptance, nonconvex global/local search designed to expose rare downhill directions missed by local pair LP searches.

1.2 Why this could improve the parent

- The parent is full-dimensional; smoothing alone would destroy it, but projected basis/control correction moves around large-scale shape distortion.  
- Exact acceptance is monotone: only lower values of `np.correlate(h, 1-h)` times `dx/time` compared by the official metric are retained.  
- The LSE surrogate is used only for generating candidates; the surrogate is **never** accepted as final and can never differentiate boundary-close optima from exact ones.  
- Low-dimensional water-filling representatives and full random/block directions provide directions that are not generated by local linear active-set models.  
- Exact quadratic-line modeling along structured directions is safe and cheap because correlation products are polynomials along a one-dimensional affine segment; therefore a reliable dense search on a segment can escape local flat low plateau shapes.

1.3 Limitations

- The LSE surrogate may create trajectories that exactify to slightly higher exact values; only exact storage is kept.
- Low-dimensional Powell/DE may be slow for too many variables; therefore maximum dimension, maximum objective evaluations, and time checks must be enforced.
- SLSQP works on the smooth problem subject to constraints; true nonsmooth minimizers of the maximum may be only nearby rather than attained. Exact polynomial line searches and active pair polishing recover nonsmooth gains but still do not prove global optimality.
- Smaller grids may lower evaluation time and the required comparable bound on the discrete grid, but a parent with n=156 is supplied, so any multiresolution switch must always retain the best exact score across all returned lengths.

2. Mathematical specification

2.1 Exact discrete representation

For an input vector `h` of length `n`:

- The unit is `dx = 2.0 / n`.
- The feasible constraint set is `h[i] in [0,1]` and `sum_i h[i] = target`, where `target = n / 2.0`. The target may be half-integer for odd n.
- The score entries correspond exactly to the vector
  `Craw(h) = np.correlate(h, 1.0 - h, mode="full")`, as produced by the evaluator, and the exact upper bound is
  `exact_c5(h) = dx * max(Craw(h))`.
- All `2n - 1` correlation entries, positive and negative offsets, are included; no circular correlation or autocorrelation transformation is trusted. The proposed internal derivative formulas must be consistent with this finite linear correlation convention.

For vector tools not directly using `np.correlate` for an internal score orientation, define explicitly that the result must satisfy the same evaluator. For each signed offset `q` from exactly `-(n-1)` to `n-1`:

- for `q >= 0` (over-lap of `h[q:]` with `1-h[:n-q]`):
  `S_k(h) = sum_{i=0}^{n-q-1} h[i+q] * (1 - h[i])`,
- for `q < 0`, let `g = -q`:
  `S_k(h) = sum_{i=0}^{n-g-1} h[i] * (1 - h[i+g])`,
- the corresponding scaled score is `dx * S_k(h)`.

The returned candidate score must be the direct evaluator or an equivalent implementation that includes all finite boundary omissions. Since the evaluator is available, the final accepted score always uses direct `np.correlate` on the returned vector.

2.2 Joint feasibility projection

A persistent operation required by all generation schemes is stable projection of any raw vector `v` into `K = {x: 0 <= x <= 1, sum x = target}`. Do **not** apply clipping and then rescaling as independent operations. Use the monotone scalar water-fill and then a bounded residual correction.

Define `project_feasible(v)`:

1. Compute `s = sum(np.clip(v, 0, 1))`. The algorithm assumes a finite array; if it is invalid, return the safe fallback vector used at startup.
2. If `target <= 1e-14`, return an exact `n`-vector of zeros. If `target >= n - 1e-14`, return an exact all-ones vector.
3. Find scalar `theta` by bisection on
   `g(t) = sum(clip(v - t, 0, 1))`.
   - Set `lo = min(v) - 1.0` and `hi = max(v) + 1.0` initially; expand endpoints exponentially if needed so `g(lo) > target > 0 <= g(hi)`.
   - Iterate at least 100 times, updating according to `g(mid) > target`. Use floating summation only; the vectorization is memory-light.
4. Form `x = clip(v - theta, 0, 1)`.
5. Compute `r = target - sum(x)`:
   - If `r > 0`, fill indices with `x[i] < 1`. Prefer interior indices with largest slack `1-x[i]`; otherwise any non-on-entry. Add total positive mass `r` without allowing `x[i] > 1`, in no more than two sorted sweeps.
   - If `r < 0`, remove `|r|` from indices with `x[i] > 0`, again prefer interior indices and never remove below zero.
6. After residual correction, if `abs(sum(x)-target) > 1e-9`, do not silently accept. Apply one more residual repair and, if still outside, keep earlier feasible reference candidate.

Although exact `sum == target` cannot be guaranteed by floating arithmetic, final feasibility checks must use a tolerance no greater than `1e-9`, and in practice the function will attempt a strictly projected candidate before any other.

2.3 Smooth log-sum-exp objective and analytic gradient

To optimize the continuous high-dimensional problem, use
`J_tau(h) = logsumexp(scores(h) / tau) * tau`
where `scores(h) = dx * Craw(h)`. Use stable numerical evaluation:

- Let `M = max(scores)`.
- Let `z_r = exp((scores[r] - M) / tau)`, where `scores[r] = dx * Craw[r]`.
- The scaled soft objective is `M + tau * log(sum(z))`.
- Let `w_r = z_r / sum(z)`, weights summing to 1 with high near-max mass.

A full gradient for the scaled soft objective, `grad h J_tau(h)`, is obtained by accumulating gradient contributions of the unscaled finite overlap scores and multiplying by `dx`:

- start with `g = zeros(n)`.
- For every lag index corresponding to offset `q`, get its weight `w`.
- For `q >= 0` and `m = n - q`:
  `g[q:n] += w * (1 - h[0:m])`
  `g[0:m] -= w * h[q:n]`
- For `q < 0`, with `gshift = -q` and `m = n - gshift`:
  `g[0:m] += w * (1 - h[gshift:n])`
  `g[gshift:n] -= w * h[0:m]`
- Finally multiply `g` by `dx`. Ensure all lag weights correspond to the exact lag order returned by the evaluator through direct correlation; the gradient accumulation orientation is needed for proposal only and is independently validated elsewhere.

If `tau` is below an implementation floor (`tau_min`), approximate `j` replacement with weights among entries `scores` within tolerance of `M`, stabilized by `max((M - scores)/tau_min, 0)` but the SLSQP phase keeps `tau >= tau_min_highdim`. Do not evaluate with `tau=0` directly.

This LSE function is only a surrogate maximizer; optimization acceptance always uses `exact_c5`, not `J_tau`.

2.4 Exact score vector along a one-dimensional direction

Let `d` be any direction with `sum(d) = 0`. Along `h_t = h + t d`, the finite-support correlation vector is exactly the quadratic polynomial

`mobile(t) = S0 + t T - t^2 Q`,

where:

- `S0 = Craw(h)`,
- `T = correlate(d, 1 - h) - correlate(h, d)`,
- `Q = correlate(d, d)`,

with the same `mode="full"` convention. The exact scaled maximum along the line segment is

`phi(t) = dx * max(mobile(t))`.

This is exact, not a local linear approximation, for every `t` such that `h_t` lies in its box. This formula drives all exact line searches.

The box interval `[t_lo, t_hi]` is obtained by scanning entries:

- initialize `t_lo = -radius` and `t_hi = radius`, with `radius > 0`,
- for every index with `|d_j| > eps`:
  - if `d_j > 0`: `t_lo = max(t_lo, -h_j/d_j)`, `t_hi = min(t_hi, (1-h_j)/d_j)`,
  - if `d_j < 0`: write `p = -d_j`;
    `t_hi = min(t_hi, h_j/p)`,
    `t_lo = max(t_lo, -(1-h_j)/p)`.

After translating into the direction once, if `t_hi <= t_lo`, return current h. The direction may be rescaled to have maximum absolute entry `1.0` after mean subtraction. This normalization still explores the same ray and avoids tiny arcs produced only by huge scores.
