1. Approach and rationale

The central idea is to attack the nonconvex minimax problem through an explicit epigraph formulation in the heuristic objective space, supplemented by reliable exact-objective descent and repair mechanisms. The previous parent is already close to a local optimum for the discrete evaluator, so broad first-order or projection-gradient methods may make only tiny progress unless they treat several near-maximal lags simultaneously and allow the objective value itself, not only a directional penalty, to move downward.

The proposed primary algorithm is:

- Start from the supplied parent, validated and feasibly repaired.
- Improve it with a hierarchy of exploit methods:
  1. exact active-set LP direction with a strengthened near-maximal active set and exact line search,
  2. direct SLSQP on the epigraph variables `(h, t)` with all lag constraints included,
  3. log-sum-exp smoothing with variable smoothing parameter, giving better starting points for the epigraph solver,
  4. sparse coordinate moves for boundary refinement.
- Explore a few transferred basins by resampling the parent to smaller or moderately larger resolutions, exploiting the fact that coarse problems can reveal useful shapes and can be improved faster.
- Use time-limited local solving, hard deadline checks, callback interruption, and always evaluate every accepted candidate with the authoritative discrete evaluator:
  `max(np.correlate(h, 1-h, full mode)) * (2/n)`.

Why this may beat the parent:

- Parent-scale LP polish is useful, but its trust region is often too local and active set too compact because of machine precision near a flat max plateau. A larger near-active set plus direct epigraph NLP can reduce the nested max even when a small LP linearization finds no strict descent.
- The epigraph SLSQP approach introduces a lower scalar variable `t` and simultaneously adjusts `h` so that all active lag constraints decrease together. This is closer to the true KKT structure of the minimax constraint system than optimizing only directional max penalty.
- Smoothing gives a differentiable surrogate with gradients from all almost-active lags, allowing escape from weak local stagnation. SLSQP or L-BFGS-like reduced dependence after smoothing can then feed improved seeds.
- Resolution cycling and feasibility projection via exact box/hyperplane projection preserve the ability to return a smaller but feasible candidate if the evaluator supports it. Smaller n is acceptable and faster, but exact comparison must use the authoritative metric, not surrogate values.

This method remains heuristic and does not guarantee global optimality. It does guarantee feasible returned points if the final projection is rechecked, and every returned objective is exactly recomputed with the supplied metric. It avoids bilinear CVXPY misuse: all nonlinear NLP constraints are handled by a general-purpose local NLP routine, and every accepted objective is settled by the exact discrete evaluator, not by solver surplus.

2. Mathematical specification

2.1 Discrete representation and objective

Let `n = n_points`, `dx = 2/n`, and `h in [0,1]^n`. The feasibility constraints are:

- `0 <= h_i <= 1` for all `i = 0,...,n-1`,
- weighted sum constraint: `sum_i h_i = n/2`.

The authoritative discrete objective is:

- `C5(h) = max_{r=0,...,2n-2} dx * correlate_full[h, 1-h][r]`.

Use a natural Lag value formula consistent with `np.correlate(h, 1-h, mode="full")`:

For `s = r - (n-1)`, define:

- If `s >= 0`:  
  `F_s(h) = dx * sum_{i=0}^{n-1-s} h[i+s] * (1 - h[i])`.

- If `s < 0`, write `a = -s > 0`:  
  `F_s(h) = dx * sum_{i=0}^{n-1-a} h[i] * (1 - h[i+a])`.

The vector `[F_s : s = -(n-1),...,n-1]` matches the ordering of `np.correlate(h, 1-h, "full")` and therefore yields the same maximum. Every algorithm may optimize this retrieved max surrogate, but the final accepted value is always computed using `np.correlate(h, 1-h, mode="full") * dx`.

2.2 Gradient of each Lag value

Let `g_s(j)` denote the derivative of `F_s` with respect to `h[j]`, already multiplied by `dx`.

For a given `s` and length `n`, compute a gradient row vector `G_s` of length `n`:

Case `s > 0`:

- If `j >= s`: add `dx * (1 - h[j-s])` for the first factor contribution.
- If `j <= n-1-s`: add `-dx * h[j+s]` for the complement-factor contribution.

Case `s < 0`, let `a = -s`:

- If `j <= n-1-a`: add `dx * (1 - h[j])`.
- If `j >= a`: add `-dx * h[j-a]`.

Case `s = 0`:

- Add `dx * (1 - h[j])`.
- Add `-dx * h[j]`.
- Equivalently `G_0[j] = dx * (1 - 2*h[j])`.

The full Jacobian `F_fin(h)` has rows `G_s` ordered by increasing `s = -(n-1),...,n-1`, matching the correlation vector. This row is the derivative of the Lag value with respect to `h`, including `dx`.

2.3 Exact feasibility and exact max functions

Implement the following helper functions at top level:

- `eval_c5(h)`:
  1. `n = len(h)`
  2. `dx = 2.0 / n`
  3. `corr = np.correlate(h, 1.0 - h, mode="full")`
  4. return `float(np.max(corr) * dx)`.

- `lag_values(h)` returning length `2n-1` vector matching its row order.

- `lag_jacobian(h)` returning shape `(2n-1, n)` matrix.

Both should avoid side effects and avoid mutating inputs. Use `np.float64` arrays.

2.4 Joint feasibility projection

Since box constraints and linear equality cannot generally be enforced by repeated clipping and scaling, use exact Euclidean projection onto `{0 <= x <= 1, sum x = target}`.

Function `project_box_sum(v, target)`:

- If `target <= 0`, return zero.
- If `target >= len(v)`, return ones.
- Find scalar `theta` by bisection satisfying `sum(clip(v - theta, 0, 1)) = target`.
- Lower bracket `lo = min(v) - 2`, upper bracket `hi = max(v) + 2`.
- Run at least 80 bisection iterations enough for `float` precision.
- Set `x = clip(v - theta, 0, 1)`.
- If the sum residual `r = target - sum(x)` is larger than a very small residual (say `1e-12`), distribute it among coordinates strictly inside `(0,1)` if possible. If no interior coordinates exist, because `target` is feasible and the root should be exact in typical float range, leave as is only if residual below `1e-10`; otherwise perform a small corrective fixed-point loop clipping after moves and rounding only at the final return.
- For any seed or solver output, set values slightly outside `[-eps, 1+eps]` due solver noise, first set `np.nan_to_num`, clip naive `0,1`, call `project_box_sum`, and duplicate absolute `min(h, 0)`, `max(h,1)` to clean.

Every solver variable representing a candidate `h` should be passed through this feasibility mechanism before exact evaluation if the solver may drift.

2.5 Objective surrogates

Smoothed maximum surrogate:

Let `F(h)` be the natural lag values from Section 2.1 and `J(h)` its Jacobian rows from Section 2.2. For a positive smoothing parameter `beta`, define:

- `m = max(F)`, `Z_l = exp((F_l - m)/beta)`, `P_l = Z_l / sum(Z_l)`.
- `phi_beta(h) = m + beta * log(sum_l Z_l)`.

Gradient:

- `grad phi_beta = sum_l P_l * J_l`.

As `beta` decreases, `phi_beta` tends upward to max(F), and its gradient becomes concentrated on the active/near active Lag constraints. Its use is as a gathering or smoothing step; candidates are only accepted by exact `eval_c5` after feasibility restoration.

Epigraph NLP:

Let the NLP variable be `x = [h_0,...,h_{n-1}, t]`, length `n+1`.

Objective:

- minimize `t` (optionally plus negligible active-smoothing term, but default is pure `t` to focus on the upper bound).

Linear equality:

- `sum_{j=0}^{n-1} h_j - n/2 = 0`.

Box and variable bounds:

- `h_j in [0,1]` for all `j`.
- `t` lower bound: choose max(0, sampled_c5 - 0.05) safely, or 0.
- `t` upper bound: `max(1.0, sampled_c5 + 0.1)`; never greater than 1 unless a generated initial candidate has exact objective inadvertently above it due poor input (then feed a larger upper bound in the solver call).

Inequality constraints:

- For every lag `s`, `F_s(h) - t <= 0`.

Constraint Jacobian:

- For each row `r` and rows 0 through n-1, `J_{r,j}(h) - t = J_r(h)_j`.
- Last column entry equals `-1` for each inequality row.

This NLP is nonconvex because the Lag values are bilinear in `h`. The goal is to find lower feasible patterns, not a global certificate. Every candidate is evaluated by the authoritative exact evaluator; the epigraph is accepted only if the exact objective improves and feasibility is restored.
