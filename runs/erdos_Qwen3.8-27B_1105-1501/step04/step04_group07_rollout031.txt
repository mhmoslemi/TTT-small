        # 0 <= 0.5 - alpha => alpha <= 0.5
        # 0.5 - alpha <= 1 => -alpha <= 0.5 => alpha >= -0.5
        # So alpha in [-0.5, 0.5]. Makes sense!
        
        # General: h[i] + alpha*V[i] in [0,1] where V[i] < 0
        # Let v = -V[i] > 0
        # h[i] - alpha*v in [0,1]
        # 0 <= h[i] - alpha*v => alpha*v <= h[i] => alpha <= h[i]/v
        # h[i] - alpha*v <= 1 => -alpha*v <= 1 - h[i] => alpha*v >= h[i] - 1 => alpha >= (h[i]-1)/v
        # So alpha in [(h[i]-1)/v, h[i]/v] = [-(1-h[i])/v, h[i]/v]
        # Since v > 0: lower = -(1-h[i])/v (≤ 0), upper = h[i]/v (≥ 0)
        
        alphas_lo = (h[neg_mask] - 1.0) / (-V[neg_mask])  # = -(1-h)/(-V) = (1-h)/V < 0
        # Wait: (h-1)/(-V) where -V > 0, h-1 ≤ 0, so this is ≤ 0. Good.
        alphas_hi = h[neg_mask] / (-V[neg_mask])  # h ≥ 0, -V > 0, so ≥ 0. Good.
        lo = max(lo, float(np.min(alphas_lo)))  # Wait, we need alpha >= all lower bounds
        hi = min(hi, float(np.min(alphas_hi)))  # and alpha <= all upper bounds
        
    lo = max(lo, -10.0)  # safety
    hi = min(hi, 10.0)   # safety
    if lo > hi:
        lo, hi = 0.0, 0.0
    return lo, hi

But random swaps might get stuck. Let me add:
1. **Simulated annealing**: Accept worse moves with some probability.
2. **Double swaps**: Swap two ones with two zeros.
3. **Directed moves**: Swap a 1 and a 0 that specifically reduces the max score.

For directed moves:
- Find the lag r* that achieves the max score.
- To reduce score at r*, we want to either:
  - Decrease h[m] where h[m]=1 and h[m+r*-n+1]=0 (these contribute to the score)
  - Increase h[m] where h[m]=0 and h[m+r*-n+1]=1 (these would reduce the contribution)
  
  A swap (set h[i]: 1→0, h[j]: 0→1) reduces score at r* if:
  - h[i]=1, h[i+r*-n+1]=0 (removes a contribution) AND h[j]=0, h[j+r*-n+1]=1 (adds a non-contribution)
  
  But we need to check all lags, not just r*.
