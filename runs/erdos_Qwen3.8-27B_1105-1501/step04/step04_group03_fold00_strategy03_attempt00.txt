1. Approach and rationale
-------------------------

The target solution remains a finite, pointwise constrained step function `h` on `[0,2]`, evaluated solely by the prescribed estimator

```
C5(h) = (2/n) * max_lag [ np.correlate(h, 1-h, mode="full")[lag] ].
```

The previous program made extensive use of LP linearization, smoothed-max SLSQP, and low-resolution reoptimization. Those are strong, but they reduce a nonconvex, nonsmooth discrete minimization to tangential surrogate models and only occasionally test the exact objective along the resulting directions. The essential weakness is this: the accepted move is first chosen from a smoothed or linearized model and only then checked exactly. The true combinatorial degradation landscape contains many cheap feasible paired redistributions that a global surrogate direction can miss because the smoothing or trust-region step is coarse, while exact one-dimensional feasible moves still discover real local patterns.

The proposed method changes the search unit. A working unit must be exactly feasible with respect to both

- `0 <= h_i <= 1`, and
- total mass sum `sum(h) = n/2`,

and its step is chosen by optimizing the *exact C5* function, not its surrogate. The most natural such directions are paired, mass-preserving moves: increase one sample by a scalar amount while decreasing another by the same amount. These are the smallest nontrivial directions that preserve the sum exactly. The method repeatedly performs exact one-dimensional line minimization along a sequence of such directions, staging from a broad exhaustive parent sweep, then a population-based, genetically informed descent, then optional tangent directions and resolution migrations. At no point is an unverified model accepted; every returning state uses exact C5 evaluation and exact feasibility validation.

This is materially different from the parent program:

- It does not use SLSQP on a log-sum-exp surrogate.
- It does not use LP linearized descent as its primary engine.
- It performs exact coordinate/pair line minimization over feasible two-coordinate directions.
- It constructs an explicit population whose improvements are retained only after full exact evaluation and local pair polishing.
- It separates one-dimensional minimax search from resolution transfer.
- It retains a deterministic validated parent as fallback if the result is invalid or if no exact improvement exists.

The search goal is modest: improve the supplied parent from about `0.380907` toward `0.38080`. Exact pair sag directions often produce incremental reductions without hitting population stall. The method is not globally optimal and must not be presented as such. Convergence is empirical and stochastic. Any presented validation test is only for the validated candidate, not the entire unknown landscape.

2. Mathematical specification

2.1 Discrete domain and exact objective
Let `h` be a length `n = n_points` vector indexed `i=0,...,n-1`. The integrator grid density is

```
dx = 2.0 / n.
```

The exact accepted objective is

```
C5(h) = dx * max( np.correlate(h, 1.0-h, mode="full") )
```

evaluated over all `2n-1` lags. The coefficient inclusion of the integral over partial overlap is inherently included with this raw finite-support correlation. Do not simplify this into an autocorrelation-only form and do not ignore finite-boundary terms.

Feasibility is

```
for all i: 0 <= h[i] <= 1
sum_i h[i] = n / 2
```

In implementation, equality is enforced to a numerical tolerance and then tiny repaired so that the representation has total sum exactly within machine precision. Smaller `n` is preferred after a tie in C5.

2.3 Paired exact feasible directions
For two distinct indices `i` and `j`, choose a direction sign `s` in `{+1,-1}`. The base direction is

```
d_s = s * e_i - s * e_j
```

A move is

```
h_alpha = h + alpha * d_s,    alpha >= 0
```

The sum is exactly preserved because every positive component is balanced by an equal negative component:

```
sum(h_alpha) = sum(h) + alpha*(s-s) = sum(h)
```

The bound constraints enforce a maximal solution

For `s = +1`:

```
alpha_max = min(1 - h[i], h[j])
```

For `s = -1`:

```
alpha_max = min(h[i], 1 - h[j])
```

Equivalently, if general step vector `p` with components `p_i` in `{+1,-1}` and exactly one `+` and one `-`, then

```
alpha_max = min_{p_i>0} (1 - h_i)/p_i
            min_{p_i<0} h_i/(-p_i)
```

Numerically subtract a tiny safety slice, e.g. `1e-15`, from `alpha_max` and skip pairs with `alpha_max < 1e-14`. Feasibility is exact rather than repaired after movement, except for a final tiny-mass repair described below to correct only floating cancellation rounding.

For a given feasible direction `p` and `alpha_max`, define

```

```
