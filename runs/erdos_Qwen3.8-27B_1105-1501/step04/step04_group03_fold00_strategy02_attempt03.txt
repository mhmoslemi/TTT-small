1. Approach and rationale

1.1 Central idea
The supplied parent solution is already near a local optimum of the discrete minimax objective. The objective is a maximum over many bilinear finite-overlap scores. The previous engines mainly use linearized LP directions, smooth soft-max gradients, and pairwise polish. Those methods can become trapped when several near-maximum lags must be moved in a coordinated, non-convex way.

The new plan uses a primal active-subspace least-squares correction as the main descent engine, combined with an exact paired-coordinate annealing phase and a derivative-free low-dimensional subspace phase. The center of the new method is not LP, soft-max smoothing, or pure local polishing. For each near-active set of maximizing lags, the algorithm constructs a feasible-sum zero-mean direction by solving a least-squares system that requests a coordinated first-order lowering of every active lag. That solves a very different subproblem than LP minimizing the worst row of a linear model. It attempts to reduce the whole active front rather than progressively chopping the worst row. Because the true objective is loss on a maximum of bilinear terms, all directions are followed only through exact one-dimensional line search on the original evaluator objective. The accepted move is allowed only if the exact objective improves.

The second phase performs exact paired-coordinate moves that preserve `sum(h)` exactly. These moves are evaluated directly by the original objective and occasionally accepted under a temperature schedule. This phase is scale-aware, allows non-strictly better current states, and can traverse barriers that a strict descent method cannot cross.

The third phase uses derivative-free random low-dimensional subspaces. Local high-dimensional optimization can be trapped in a small basin, while a low-dimensional projection of the feasible space can discover a better path. The high-dimensional direction is updated by minimizing the same exact objective inside the projection. This is useful when the parent is close to optimum and only a curved low-order deformation is needed.

Evaluation is not a surrogate. All candidate dates and improvements, all proposed c5 values, and the final output are recomputed by the exact evaluator. The algorithm is local after initialization, but very diverse initialization and repeated crossing phases allow it to escape the parent basin. It should not be claimed globally optimal.
