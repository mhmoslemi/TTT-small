1. Approach and rationale

1.1 Central idea

Implement a non-convex search whose primary object of comparison is the discrete evaluator itself, not a smoothed surrogate. The method alternates between three exact, feasible search mechanisms:

1. A combinatorial Metropolis/basin-hopping search over exactly balanced binary masks. For a mask with exactly n/2 entries equal to 1 and the rest 0, every proposal preserves both feasibility constraints by construction, and the evaluator is computed directly on every proposed mask.

2. A one-dimensional, exactly feasible “blur a balanced mask” family. For a balanced mask, replace mask entries by 1-d and non-mask entries by d, where d is scanned over [0, 0.5]. The sum is exactly n/2 for every d. This lets acceptably good binary structures transmit successively into fractional vectors without projection artifacts.

3. Exact diagonal coordinate refinements. For any currently feasible vector, select a pair (i,j) and move only h_i and h_j along h_i = t, h_j = h_i^old + h_j^old - t, with t in the interval required by zero and one bounds. This preserves the global sum automatically. A dense plus golden-section line search evaluates the evaluator on this feasible plane and accepts exact improvements.

The parent construction is validated, kept permanently as a fallback, and used to seed several balanced masks and resolution conversions. The parent is not assumed to be near a global minimizer and is not the only basis for updates. If a stage cannot be finished inside the remaining budget, the program returns the best previously validated exact-scoring candidate, eventually the parent if no other valid feasible candidate was found.

1.2 Why this mechanism addresses the supplied problem

The optimizer is minimax over 2n-1 finite-support cross-correlation terms. The supplied parent has already been polished by continuous active-set style methods, which tend to make a vector locally stationary under the continuous cones induced by the active lags. A viable different exploration mechanism is to step far outside that active cone:

- Balanced binary masks concentrate the zero-lag penalty h_i(1-h_i) at its minimum and expose a very different feasible geometry. If a robust combinatorial structure exists at the supplied resolution, it can jump discretely across the several-point correlation-count mesh available in that geometry.
- Binary state space is cheap to perturb by portion (1 to 0 shifts compensated by 1 after swaps), so many exact evaluator calls can be made.
- Moving a pair of samples along a globally sum-preserving diagonal is the essential feasible two-coordinate adsorption localized near a correlation peak. Repeating these exact lines lets fractional samples move collectively beyond the original vector basin; unlike global projection moves, no operator preserves bounds by clipping after moving and then discarding the result due feasibility damage.
