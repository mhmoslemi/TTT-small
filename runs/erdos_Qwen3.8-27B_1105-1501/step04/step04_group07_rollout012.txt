    # Returns the optimal value in [0, 1]

        if fm < best_f:

            best_f = fm
    
    return best_v

For a set S of size 32 in Z_64 (cyclic group), the "cyclic autocorrelation" tells us about the overlap at each shift. We want a set with "flat" autocorrelation (all non-zero shifts have the same correlation).

A (64, 32, λ) difference set would have all non-zero shifts with correlation λ. The parameters would need to satisfy: 32*31 = 63*λ, so λ = 32*31/63 = 992/63 ≈ 15.75. Not an integer, so no perfect difference set exists.

But we can get close. The best we can do is have correlations of 15 and 16 (or similar).

For the non-cyclic (linear) case, it's different. The problem uses linear correlation, not circular.

    # Steepest descent on binary sequences via swaps
    n = len(h)
    target = n // 2
    h = (h >= 0.5).astype(float)
    # Ensure exactly target ones
    ones_count = int(h.sum())
    if ones_count != target:
        if ones_count > target:
            idx = np.where(h == 1)[0]
            np.random.shuffle(idx)
            h[idx[ones_count - target:]] = 0
        else:
            idx = np.where(h == 0)[0]
            np.random.shuffle(idx)
            h[idx[:target - ones_count]] = 1
    cur_c5 = _c5(h)
    for it in range(max_iters):
        ones_idx = np.where(h == 1)[0]
        zeros_idx = np.where(h == 0)[0]
        best_delta = 0
        best_i, best_j = -1, -1
        for i in ones_idx:
            for j in zeros_idx:
                h[i] = 0
                h[j] = 1
                new_c5 = _c5(h)
                delta = cur_c5 - new_c5
                h[i] = 1
                h[j] = 0
                if delta > best_delta:
                    best_delta = delta
                    best_i, best_j = i, j
        if best_i < 0:
            break  # local minimum
        h[best_i] = 0
        h[best_j] = 1
        cur_c5 -= best_delta
    return h, cur_c5
