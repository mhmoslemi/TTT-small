def _project(v, target):
    n = len(v)
    if target <= 0: return np.zeros(n)
    if target >= n: return np.ones(n)
    lo = v.min() - 2.0
    hi = v.max() + 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        if np.sum(np.clip(v - mid, 0, 1)) > target:
            lo = mid
        else:
            hi = mid
    x = np.clip(v - (lo + hi) / 2.0, 0, 1)
    res = target - x.sum()
    if abs(res) > 1e-10:
        if res > 0:
            m = x < 1 - 1e-14
        else:
            m = x > 1e-14
        c = m.sum()
        if c > 0:
            x[m] += res / c
            x = np.clip(x, 0, 1)
    return x

def _exact_c5(h):

def _raw_scores(h):

def _resample_area(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    # Mass-preserving: each old cell has width 2/n, new cell has width 2/n_new
    # Cell i of old covers [2i/n, 2(i+1)/n]
    # Cell j of new covers [2j/n_new, 2(j+1)/n_new]
    # Overlap of cell i and cell j:
    # left = max(2i/n, 2j/n_new), right = min(2(i+1)/n, 2(j+1)/n_new)
    # overlap = max(0, right - left)
    # new_h[j] = sum_i h[i] * overlap(i,j) / (2/n_new)
    #         = sum_i h[i] * overlap(i,j) * n_new / 2

    x_new = (np.arange(n_new) + 0.5) / n_new

Wait, is linear interpolation equivalent to mass-preserving for step functions? Let me think...

If h is a step function (constant on each interval [i*dx, (i+1)*dx]), and I want to resample to a new grid, the mass-preserving approach computes the exact overlap of each new cell with the old cells.

For a step function, the value in a new cell that partially overlaps two old cells is the weighted average of the two old values, where the weights are the overlap fractions. This is exactly linear interpolation!

Wait, no. Linear interpolation gives the value at the center of the new cell, which is the weighted average of the two nearest old values. But mass-preserving gives the average value over the new cell, which is also a weighted average but with different weights (based on cell overlap, not point evaluation).

For step functions, if the new cell center falls between two old cell centers, linear interpolation gives:
h_new[j] = h[i] * (1 - t) + h[i+1] * t
where t is the fraction of the way from old cell i to old cell i+1.

Mass-preserving gives:
h_new[j] = h[i] * (overlap with cell i) / (new cell width) + h[i+1] * (overlap with cell i+1) / (new cell width)

These are the same! Because the overlap fractions sum to 1 and correspond to the interpolation weights.

Actually wait, this is only true if the new cell overlaps at most 2 old cells. For very different resolutions, a new cell might overlap more old cells. But for nearby resolutions (like n=90 to n=88), each new cell overlaps at most 2-3 old cells, and linear interpolation is a good approximation.
