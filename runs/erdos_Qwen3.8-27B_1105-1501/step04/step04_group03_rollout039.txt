def exact_c5(h):

def project(v, target):

        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo, hi = -2.0, 2.0

        else:
            hi = mid

**Idea: Use the dual problem.**

The problem is: min_h max_k f_k(h) subject to h ∈ [0,1]^n, 1ᵀh = n/2

The dual (in a relaxed sense) is: max_{λ ≥ 0, 1ᵀλ = 1} min_h Σ_k λ_k f_k(h) subject to h ∈ [0,1]^n

For fixed λ, the inner problem is a QP (since f_k is quadratic in h). We could alternate:
1. Given h, update λ: λ_k ∝ exp(f_k(h) / τ) (softmax over the scores)
2. Given λ, solve the QP: min_h Σ_k λ_k f_k(h) subject to constraints

This is essentially the mirror descent / multiplicative weights approach. Step 1 is the same as the LSE gradient method. Step 2 is a QP that we could solve with scipy.

Actually, for step 2, the objective is:
Σ_k λ_k [sum_i h[i](1-h[i+d_k]) * dx]
= dx * Σ_k λ_k [sum_i h[i] - sum_i h[i]*h[i+d_k]]
= dx * [n * sum(h) - sum_k λ_k sum_i h[i]*h[i+d_k]]

Wait, sum_i h[i] = n/2 is constant. So we're minimizing:
-dx * sum_k λ_k sum_i h[i]*h[i+d_k]

Which is a quadratic form in h. We can write it as -dx * hᵀ M h where M is a matrix.

Actually, let me be more careful:
f_k(h) = dx * sum_i h[i] * (1 - h[i+d_k])
       = dx * sum_i h[i] - dx * sum_i h[i] * h[i+d_k]

The first term is dx * n/2 (constant). So we minimize:
min_h -dx * Σ_k λ_k Σ_i h[i] * h[i+d_k]
= min_h -dx * hᵀ (Σ_k λ_k A_k) h

where A_k is the matrix representing the shift by d_k.

This is: min_h -hᵀ Q h subject to 0 ≤ h ≤ 1, 1ᵀh = n/2

where Q = dx * Σ_k λ_k A_k.

Since we're minimizing -hᵀQh = maximizing hᵀQh, and Q is (presumably) positive semidefinite (it's a weighted sum of symmetric matrices), this is a concave maximization, i.e., a convex minimization of -hᵀQh.

Wait, is Q symmetric? A_k represents the operation h → shift(h, d_k), so (A_k)_{ij} = 1 if j = i + d_k. This is not symmetric in general. But hᵀA_k h = Σ_i Σ_j h_i (A_k)_{ij} h_j = Σ_i h_i h_{i+d_k}. And hᵀA_kᵀh = Σ_i h_i h_{i-d_k} = same thing (just reindexing). So yes, hᵀA_k h is the same whether we use A_k or A_kᵀ.

So the problem is: min_h -hᵀ(Σ_k λ_k A_k)h subject to constraints, which is a QP.

We can solve this with scipy.optimize.minimize using the BFGS or L-BFGS-B method with bounds and a linear equality constraint.

This "alternating" approach (update λ, solve QP) is essentially the same as the LSE gradient method but with exact QP solves instead of gradient steps. It should converge faster.

    target = n / 2.0

    # Q[i,j] = sum_k lambdas[k] * (1 if j=i+d_k or i=j+d_k)
    # Actually, for the quadratic form h^T Q h = sum_k lambdas[k] * sum_i h[i]*h[i+d_k]
    # We need Q such that h^T Q h = that expression
    # Q is symmetric: Q[i,j] = sum_k lambdas[k] * (1_{j=i+d_k} + 1_{i=j+d_k}) / 2
    # Wait, sum_i h[i]*h[i+d] = sum_i h[i] * h[i+d]
    # = h^T S_d h where (S_d)_{i,j} = 1 if j = i+d
    # But h^T S_d h = sum_i sum_j h_i (S_d)_{ij} h_j = sum_i h_i h_{i+d}
    # And (S_d)^T has (S_d^T)_{ij} = 1 if i = j+d, i.e., j = i-d

    # The symmetric part is (S_d + S_d^T)/2 which has entries 1/2 at (i, i+d) and (i+d, i)
    
    # For the gradient: d/dh_j of sum_i h[i]*h[i+d] = h[j+d] + h[j-d] (with boundary handling)
    # This is the j-th component of (S_d + S_d^T) @ h
    
    def obj(h):
        val = 0.0
        for k in range(2*n-1):
            if lambdas[k] < 1e-15:
                continue
            d = k - (n-1)
            if d >= 0:
                m = n - d
                val += lambdas[k] * np.dot(h[:m], h[d:d+m])
            else:
                g = -d
                m = n - g
                val += lambdas[k] * np.dot(h[g:g+m], h[:m])
        return -dx * val
    
    def grad(h):
        g = np.zeros(n)
        for k in range(2*n-1):
            if lambdas[k] < 1e-15:
                continue
            d = k - (n-1)
            if d >= 0:
                m = n - d
                if m > 0:
                    g[:m] += lambdas[k] * h[d:d+m]
                    g[d:d+m] += lambdas[k] * h[:m]
            else:
                g_ = -d
                m = n - g_
                if m > 0:
                    g[g_:g_+m] += lambdas[k] * h[:m]
                    g[:m] += lambdas[k] * h[g_:g_+m]
        return -dx * g
    
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x: np.sum(x) - target,
             'jac': lambda x: np.ones(n)}]
    
    res = minimize(obj, h_init, jac=grad, method='SLSQP',
                   bounds=bounds, constraints=cons,
                   options={'maxiter': 200, 'ftol': 1e-14})
    if res.success:
        return project(res.x, target)
    return h_init

    # Safety: never return worse than parent
    parent_h = project(h0, n0 / 2.0)
    parent_c5 = exact_c5(parent_h)
    if final_c5 > parent_c5 + 1e-14:
        best_h = parent_h
        final_c5 = parent_c5
        best_n = n0

    return best_h, final_c5, best_n
