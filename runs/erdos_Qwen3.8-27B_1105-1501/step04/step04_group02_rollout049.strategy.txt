2. Mathematical specification

2.1 Exact discrete objective

For an array h of length n, use dx = 2 / n. The official objective is

C5(h) = dx * max_r np.correlate(h, 1 - h, mode="full")[r]

where r ranges over 2n - 1 lag indices. This is finite-support linear correlation, not circular correlation, and includes both lag directions.

For algorithmic gradients, define a lag score set in an explicit indexing that has the same multiset of values as the official output. Let m = 2n - 1 and for r in 0..m-1 set d = r - (n - 1).

For d >= 0:

S_r(h) = sum_{i=0}^{n-d-1} h[i+d] * (1 - h[i])

For d < 0, let s = -d:

S_r(h) = sum_{i=0}^{n-s-1} h[i] * (1 - h[i+s])

The set {S_r} is the same as the label multiset produced by np.correlate(h, 1-h, mode="full") up to a reversal of the lag order, so its maximum equals the official raw maximum.
