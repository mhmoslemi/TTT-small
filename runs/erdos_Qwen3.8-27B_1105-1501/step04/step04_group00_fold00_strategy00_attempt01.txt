2. Mathematical specification

Let n be the number of discrete samples. Use even `n = 2m`. Build a full length n sequence from a half length m vector `x`.

Definitions:

  `x_i = -1` corresponds to left-half value `h_i = 0`, right-half mirror value `h_{n-1-i} = 1`.
  `x_i = +1` corresponds to left-half value `h_i = 1`, right-half mirror value `h_{n-1-i} = 0`.
  More generally:

    `h_left[i] = (1 + x_i) / 2`, `0 <= i < m`
    `h_right = 1 - h_left[::-1]`
    `h = h_left concat h_right`

This construction always gives:
1. `0 <= h_i <= 1` whenever `-1 <= x_i <= 1`.
2. The integral constraint is exact because every mirrored pair sums to 1:

    `sum_j h_j = sum_{i=0}^{m-1} (h_left[i] + h_right[m-1-i]) = sum_i (h_left[i] + 1 - h_left[i]) = m = n/2`

In floating point, a tiny sum drift can happen from the summation order. Define a final feasibility repair: add `(n/2 - sum(h))/n` to one pair while preserving mirror identity only approximately if the correction `< 1e-12`; this changes objective by at most machine epsilon and ensures the evaluator check passes. For exactness and simplicity, most returns will already be sum-safe because of the mirror-pair formula; the repair is only needed after arbitrary resampling.

Define the signed complement-symmetric vector:

    `u_i = 2*h_i - 1`, `i = 0..n-1`

Then:

    `u_i = x_i`, `i = 0..m-1`
    `u_j = -x_{n-1-j}`, `j = m..n-1`

This is equivalently:

    `u = [x[0],...,x[m-1], -x[m-1],...,-x[0]]`

The finite discrete evaluator is:

    `C(h) = dx * max_l corr_l`, `dx = 2/n`, for all `2n-1` full-correlation lags.
    `corr_l = sum_i h_i*(1-h_{i+l})`, where the sum is over overlaps only.

For the constructed complement-symmetric `h`, the positive and negative lag scores are equal, and the full objective can be reduced to positive lags `l = 0..n-1`. For each `l`, let:

    `N_l = n - l`
    `r_l = sum_{i=0}^{n-l-1} u_i * u_{i+l}`

For `l = 0`, `r_0 = sum_i u_i^2`.

Then the overlap at positive lag l is:

    `score_l = N_l/4 - r_l/4 = (N_l - r_l)/4`

Therefore the evaluator objective is:

    `C = dx * max_{0 <= l < n} (N_l - r_l)/4 = max_{0 <= l < n} (N_l - r_l) / (2n)`

Define the dimensionless hard quantity:

    `T(x) = max_{0 <= l < n} (n - l - r_l)`

Then:

    `C(h(x)) = T(x) / (2n)`

This is the quantity minimizing when optimizing. The same expression is used for exact coordinate line searches, scaled back to `C`.

Boundary derivation check: for each positive lag l the finite-window sum of `u_i - u_{i+l}` is exactly zero under antisymmetry, eliminating prefix/boundary terms. The exact distinct signs of the two symmetric lags collapse to identical values, so the maximum over the evaluator's full mode exactly equals the positive-lag formula. Final candidate acceptance still uses the original evaluator.

Smooth objective with soft maximum:

    `T_beta(x) = (1/beta) log (sum_l exp(beta * (n-l - r_l)))`

This approaches `T(x)` as `beta -> infinity` and is differentiable. Use stable log-sum-exp:

  Let `V_l = n-l-r_l`.
  Let `Vmax = max_l V_l`.
  Let `b_l = exp(beta*(V_l - Vmax))`.
  Let `B = sum_l b_l`.
  Then `T_beta = Vmax + log(B)/beta`.
  Soft weights are: `w_l = b_l / B`.

Gradient of `r_l` with respect to the full vector u:

For l = 0:

    `grad_u r_0 = 2 u`

For l > 0:

For each pair `(i, i+l)` in `i=0..n-1-l`:
    pair contributes to derivative at position i: `u_{i+l}`
    pair contributes to derivative at position i+l: `u_i`

Weight all positive-lags contributions by `w_l`. Let the weighted gradient dimensionless of `T_beta` be:

    `grad_u^full = - weighted_sum_l grad_u r_l`

because `V_l = n-l-r_l` is the negative derivative of its r term. There is no extra factor of beta because `T_beta` has one l multiplication and division by beta.

Fold to half variables. The variable `x_j` appears as `u_j` at full position `j` with coefficient +1, and at full position `q = n-1-j` as `u_q = -x_j` with coefficient -1. Therefore:

Coordinate-subproblem convexity:

Fix all coordinates except `x_c`. In the antisymmetrized full u vector, coordinate x_c appears at positions `p = c` and `q = n-1-c`, with values `+t` and `-t`, respectively.
