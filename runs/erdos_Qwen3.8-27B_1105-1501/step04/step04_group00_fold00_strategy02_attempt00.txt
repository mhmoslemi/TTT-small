2.1 Objective, row indexing, and units

    F(h) = max_{r=0,...,2n-2} S_r(h),
    S_r(h) = dx np.correlate(h, 1.0 - h, mode="full")[r],

This is finite linear support, not circular, and all output indices are kept. Numerical signs and indexing must be confirmed. A robust mapping from output index r to lag d is

    d = r - (n - 1).

When d >= 0 let m = n - d. The score term consistent with `np.correlate(h, 1-h)` is

    S_{n-1+d} = dx sum_{i=0}^{m-1} h_{i+d} (1 - h_i).

The row partial derivatives are

    ∂S_{n-1+d} / ∂h_{j} (j = 0,...,m-1) = -dx h_{j+d},
    ∂S_{n-1+d} / ∂h_{j+d} (j = 0,...,m-1) = dx (1 - h_j).

    S_{n-1-g} = dx sum_{i=0}^{m-1} h_i (1 - h_{i+g}).
