A better approach might be to **explicitly handle the active set** and solve a more targeted problem.

**Active set approach:**
1. Identify active lags A = {k : scores[k] >= max - epsilon}
2. For each active lag, the constraint is S_k(h) <= C (where C is the current max)
3. We want to find the minimum C such that there exists h with S_k(h) <= C for all k in A, sum(h) = n/2, 0<=h<=1
4. This is a nonconvex feasibility problem (because S_k is bilinear)

But we can approximate it:
- Linearize S_k around current h: S_k(h) ≈ S_k(h) + g_k * (h - h_0)
- Then the problem becomes: minimize C subject to g_k * (h - h_0) <= C - S_k(h_0) for all k in A
- This is an LP! And it's exactly what the previous program does (essentially).

So the LP approach should be optimal within its linearization. The issue is the radius: if the radius is too small, we make slow progress; if too large, the linearization is inaccurate.

def pair_grad_contrib(h, scores):
    """For each coordinate i, compute its weighted contribution to active lags.
    Returns array where contrib[i] > 0 means i is "pushing up" the max,
    and contrib[i] < 0 means i is "pushing down."
    Moving mass from high-contrib to low-contrib should reduce the max."""
    n = len(h)
    m = float(np.max(scores))
    delta = 0.02 * m + 1e-6
    active_mask = scores >= m - delta
    if active_mask.sum() < 1:
        active_mask = np.zeros(2*n-1, dtype=bool)
        active_mask[int(np.argmax(scores))] = True
    
    # Weights based on closeness to max
    w = np.where(active_mask, (scores - (m - delta)) / (delta + 1e-15), 0.0)
    w = np.clip(w, 0, 1)
    w_sum = w.sum()
    if w_sum < 1e-15:
        w = active_mask.astype(float)
        w_sum = 1.0
    w = w / w_sum
    
    contrib = np.zeros(n)
    center = n - 1
    for k in range(2 * n - 1):
        if not active_mask[k]:
            continue
        wk = w[k]
        d = k - center
        if d >= 0:
            m_len = n - d
            if m_len <= 0: continue
            # S_k = sum_{i=0}^{m_len-1} h[i] * (1-h[i+d])
            # dS_k/dh[j] = (1-h[j+d]) for j < m_len  (from h[j] as first factor)
            #               - h[j-d] for j >= d       (from (1-h[j]) as second factor, where j = i+d)
            # But j must also satisfy: j < n and j >= d
            if m_len > 0:
                # j from 0 to m_len-1: contribution from first factor
                contrib[:m_len] += wk * (1.0 - h[d:d+m_len])
            # j from d to n-1: contribution from second factor, where i = j-d
            # i ranges from 0 to m_len-1, so j = i+d ranges from d to d+m_len-1 = n-1
            if d < n:
                contrib[d:] += wk * (-1.0) * h[:m_len]
        else:
            q = -d
            m_len = n - q
            if m_len <= 0: continue
            # S_k = sum_{i=0}^{m_len-1} h[i+q] * (1-h[i])
            # dS_k/dh[j]:
            #   j as first factor (h[j]): j = i+q, so i = j-q >= 0, j >= q

            #   j in (1-h[j]): j = i, so j < m_len
            #     contribution = -h[j+q]
            # j from q to n-1: first factor
            if q < n:

            # j from 0 to m_len-1: second factor
            contrib[:m_len] += wk * (-1.0) * h[q:q+m_len]
    
    return contrib
