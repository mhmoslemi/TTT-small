Great, so F(t) is convex. I can use bisection on the subgradient to find the minimum.

The subgradient of F(t) at a point t is:
∂F(t) = { sum_{d ∈ argmax} (D[d] + 2*Q[d]*t) }

(When the max is achieved at a unique d, the subgradient is the singleton {D[d] + 2*Q[d]*t}.)
(When achieved at multiple d's, it's the convex hull of {D[d] + 2*Q[d]*t : d ∈ argmax}. Since each is a scalar, it's [min, max] of those values.)

Bisection:
- lo, hi = feasible range
- For ~50 iterations:

  - Compute g_d = corr[d] + D[d]*mid + Q[d]*mid² for all d
  - Find argmax set A
  - subgrad_low = min(D[d] + 2*Q[d]*mid for d in A)
  - subgrad_high = max(D[d] + 2*Q[d]*mid for d in A)
  - If subgrad_high < 0: F is decreasing at mid, so t* < mid → hi = mid
  - If subgrad_low > 0: F is increasing at mid, so t* > mid → lo = mid
  - Else: t* ≈ mid, break

This is O(n) per iteration, O(n) iterations total. Very fast!

def paired_cd_pass(h, order=None):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    F0 = float(np.max(corr) * dx)
    eps = 1e-8
    improved = False
    best_t = 0.0
    best_F = F0
    
    if order is None:
        pairs = [(i, j) for i in range(n) for j in range(i+1, n)]
    else:
        pairs = order
    
    for (i, j) in pairs:
        # Compute D and Q via finite differences
        h_p = h.copy()
        h_p[i] += eps
        h_p[j] -= eps
        cp = np.correlate(h_p, 1.0 - h_p, mode='full')
        
        h_m = h.copy()
        h_m[i] -= eps
        h_m[j] += eps
        cm = np.correlate(h_m, 1.0 - h_m, mode='full')
        
        D = (cp - cm) / (2.0 * eps)
        Q = (cp + cm - 2.0 * corr) / (2.0 * eps * eps)
        
        # Feasible range for t
        t_lo = max(-h[i], h[j] - 1.0)
        t_hi = min(1.0 - h[i], h[j])
        if t_lo >= t_hi:
            continue
        
        # Bisection to find optimal t
        lo, hi = t_lo, t_hi
        for _ in range(50):
            mid = (lo + hi) / 2.0
            g = corr + D * mid + Q * mid * mid
            max_g = np.max(g)
            A = np.where(g >= max_g - 1e-14)[0]
            sg = D[A] + 2.0 * Q[A] * mid
            if np.max(sg) < 0:
                hi = mid
            elif np.min(sg) > 0:
                lo = mid
            else:
                break
        
        t_star = (lo + hi) / 2.0
        # Clip to feasible range
        t_star = max(t_lo, min(t_hi, t_star))
        
        # Evaluate
        h_new = h.copy()
        h_new[i] += t_star
        h_new[j] -= t_star
        corr_new = np.correlate(h_new, 1.0 - h_new, mode='full')
        F_new = float(np.max(corr_new) * dx)
        
        if F_new < best_F - 1e-14:
            h = h_new
            corr = corr_new
            best_F = F_new
            improved = True
    
    return h, best_F, improved
