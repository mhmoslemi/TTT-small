```python
    f2 = float(np.max(S0 + c2 * T - c2*c2 * C)) * dx
```

```python
    f2 = float(np.max(S0 + c2 * T - c2*c2 * C)) * dx

            c1 = b - gr * (b - a)
            f1 = float(np.max(S0 + c1 * T - c1*c1 * C)) * dx
        else:
            a = c1; c1 = c2; f1 = f2
            c2 = a + gr * (b - a)
            f2 = float(np.max(S0 + c2 * T - c2*c2 * C)) * dx

    opt_val = float(np.max(S0 + opt_t * T - opt_t*opt_t * C)) * dx

        best_val = opt_val
```

Wait, this pair descent is too slow. For n=112, each sweep has C(112,2) ≈ 6000 pairs, and each pair requires a line search which involves multiple np.correlate calls (each O(n)). So each sweep is about 6000 * 30 * 2 * 112 ≈ 40M floating point operations. That's probably 20-50ms per sweep in NumPy. With 400 seconds, we can do about 8000-20000 sweeps. That might be enough.

But actually, there's a much more efficient way to do the pair descent. Instead of computing the full correlation for each pair, I can use the incremental formula.

For pair (i,j), the direction is d = e_i - e_j. We need:
- S0 = corr(h, 1-h) [precomputed, O(n²) to compute once]
- T = corr(d, 1-h) - corr(h, d) [O(n) to compute for each pair since d is sparse]
- C = corr(d, d) [O(1) since d has only 2 non-zero entries]

For T, since d = e_i - e_j:
corr(e_i, 1-h)[k] = (1-h)[i-k] if 0 ≤ i-k < n, else 0 [O(1) to evaluate at a specific k, O(i) non-zero entries]
corr(h, e_i)[k] = h[i+k] if 0 ≤ i+k < n, else 0 [O(n-i) non-zero entries]

So T[k] = (1-h)[i-k] (if valid) - (1-h)[j-k] (if valid) - h[i+k] (if valid) + h[j+k] (if valid)

This has at most O(n) non-zero entries. Computing T for one pair is O(n).

But we still need to compute max_r (S0[r] + α*T[r] - α²*C[r]) for various α, which is O(n) per evaluation.

So per pair: O(n) to compute T and C, then O(n) per line search evaluation, times ~30 evaluations = O(n) per pair (since the line search evaluations are O(n) each but we do O(1) of them... wait, no, 30 evaluations * O(n) = O(n)).

Total per pair: O(n). Total per sweep: O(n³). For n=112: ~1.4M operations per sweep. At ~100M operations per second (rough NumPy speed), that's about 14ms per sweep. With 400s, that's about 28,000 sweeps.

Actually, that's a lot of sweeps. The pair descent should converge much faster than that. Let me add a convergence check: if C5 hasn't improved in 50 consecutive sweeps, stop.

OK, let me also think about a faster version of the pair descent that avoids the full line search for most pairs.

**Fast pair descent:**
1. Precompute S0 = corr(h, 1-h)
2. For each pair (i,j):
   a. Compute the directional derivative: df/dα at α=0 = max over active r of T[r]
   b. If df/dα ≈ 0 (within tolerance), skip
   c. Otherwise, do a quick 5-point check to see if there's improvement
   d. If yes, do the full line search

The directional derivative at α=0 is:
d/dα [max_r (S0[r] + α*T[r] - α²*C[r])] |_{α=0}
= max over r where S0[r] = max(S0) of T[r]

If this max is < -ε (some negative value), then decreasing α (i.e., α < 0) might help... wait, no. If the derivative is negative, then increasing α helps (the function is decreasing at α=0).

Actually, the derivative of max_r g_r(α) at α=0 is max_r g_r'(0) where g_r are the active functions (those with g_r(0) = max). If this is negative, the max can be reduced by increasing α. If positive, by decreasing α. If zero, we're at a local minimum for this direction.

So:
- Compute active set: S = {r : S0[r] == max(S0)} (or within tolerance)
- Compute T for this pair
- derivative = max(T[r] for r in S)
- If |derivative| < tolerance, skip
- Otherwise, try the line search

This pre-filter should eliminate most pairs (those that don't help any active constraint).

```python
def _active_lp(h, deadline, K=15, radius_init=0.15):
    n = len(h)
    target = n / 2.0
    dx = 2.0 / n
    h = h.copy().astype(float)
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    radius = radius_init
    stall = 0
    
    while time.time() < deadline and stall < 80:
        S0 = np.correlate(h, 1.0 - h, mode='full')
        max_val = float(np.max(S0))
        # Select top K constraints
        idx = np.argsort(S0)[::-1][:K]
        
        # Compute gradient matrix only for these K rows
        G = _compute_grads(h)  # Full matrix, O(n²)
        G_k = G[idx, :]  # K x n
        
        # LP: minimize t subject to G_k @ p - t*ones ≤ -S0[idx], sum(p) = 0, bounds
        c = np.zeros(n + 1)
        c[-1] = 1.0
        A_ub = np.zeros((K, n + 1))
        A_ub[:, :n] = G_k
        A_ub[:, n] = -1.0
        b_ub = -S0[idx]
        A_eq = np.zeros((1, n + 1))
        A_eq[0, :n] = 1.0
        b_eq = np.zeros(1)
        bounds = [(max(-radius, -h[j]), min(radius, 1.0 - h[j])) for j in range(n)]
        bounds.append((None, None))
        
        try:
            res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                          bounds=bounds, method='highs')
            if res.success:
                p = res.x[:n]
                p_norm = float(np.max(np.abs(p)))
                if p_norm > 1e-12:
                    alpha, new_c5 = _line_search(h, p, dx, radius)
                    if new_c5 < cur_c5 - 1e-13:
                        h = h + alpha * p
                        h = _waterfill(h, target)
                        cur_c5 = _exact_c5(h)
                        if cur_c5 < best_c5:
                            best_c5 = cur_c5
                            best_h = h.copy()
                        stall = 0
                        radius = min(radius * 1.1, 0.3)
                        continue
        except Exception:
            pass
        
        stall += 1
        radius *= 0.8
        if radius < 0.01:
            radius = 0.05
    
    return best_h, best_c5
```

```python
def _subgradient_loop(h, deadline):
    n = len(h)
    target = n / 2.0
    dx = 2.0 / n
    h = h.copy().astype(float)
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    lr = 0.05
    stall = 0
    rng = np.random.default_rng(999)
    
    while time.time() < deadline and stall < 60:
        S0 = np.correlate(h, 1.0 - h, mode='full')
        max_val = float(np.max(S0))
        active_tol = max_val - 0.05 * max_val  # within 5% of max
        active = np.where(S0 >= active_tol)[0]
        
        # Compute weighted gradient
        weights = np.exp(-(max_val - S0[active]) / (0.01 * max_val + 1e-10))
        weights /= weights.sum()
        
        G = _compute_grads(h)
        grad = np.zeros(n)
        for idx, w in zip(active, weights):
            grad += w * G[idx, :]
        
        grad -= grad.mean()  # Ensure zero sum
        gn = np.linalg.norm(grad)
        if gn < 1e-13:
            stall += 1
            continue
        grad /= gn
        
        # Try both directions
        best_alpha = 0.0
        best_new_c5 = cur_c5
        for sign in [1.0, -1.0]:
            d = sign * grad
            alpha, new_c5 = _line_search(h, d, dx, lr)
            if new_c5 < best_new_c5:
                best_new_c5 = new_c5
                best_alpha = alpha * sign
        
        if best_new_c5 < cur_c5 - 1e-13:
            h = h + best_alpha * grad
            h = _waterfill(h, target)
            cur_c5 = _exact_c5(h)
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            stall = 0
            lr = min(lr * 1.05, 0.5)
        else:
            stall += 1
            lr *= 0.85
            if lr < 0.01:
                # Random restart of learning rate
                lr = 0.1
    
    return best_h, best_c5
```

```python
def _resample(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return _waterfill(h_new, n_new / 2.0)

def _resolution_search(h_best, c5_best, deadline, n_list):
    best_h = h_best.copy()
    best_c5 = c5_best
    for n_try in n_list:
        if time.time() > deadline:
            break
        h_r = _resample(h_best, n_try)
        # Brief optimization
        sub_dl = min(deadline, time.time() + 15)
        h_r, c5_r = _pair_descent(h_r, sub_dl, stall_limit=50)
        if c5_r < best_c5 - 1e-6:
            best_c5 = c5_r
            best_h = h_r.copy()
    return best_h, best_c5
```
