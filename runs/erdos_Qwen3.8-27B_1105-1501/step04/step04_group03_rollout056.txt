So for each lag d (where j±d is valid), g[n-1+d] is an affine function of h[j]. The overall objective (max of all g's plus λ*h[j]) is a convex piecewise-linear function of h[j] on [0,1].

To minimize it, we can:
1. Evaluate at a set of candidate points: 0, 1, and the breakpoints where the "active" g changes
2. Or use ternary search (since it's convex)

The number of breakpoints is at most 2(n-1) (one for each lag where h[j] appears, giving at most 2 linear pieces per lag, but actually the max of many linear functions has breakpoints where pairs of them are equal, which could be O(n²) in the worst case but in practice much less).

In practice, we can just evaluate the objective at a fine grid of points in [0,1] (say 100 points) and take the best. Or use the fact that it's a max of linear functions and find the minimum analytically.

Actually, for a max of m affine functions on [0,1], the minimum is at a point where two of the functions are equal (a "kink") or at a boundary. We can find all kinks by solving pairs of linear equations, but that's O(m²). For m ≈ 2n ≈ 200, that's 40000 comparisons per coordinate, times n=92 coordinates = 3.7M operations per sweep. That's feasible.

But actually, there's a simpler approach: since the function is convex and piecewise linear on [0,1], we can use a "bisection on the subgradient" approach:
- At any point x, compute the subgradient (which is the set of slopes of the active functions)
- If min subgradient > 0, the minimum is to the left
- If max subgradient < 0, the minimum is to the right
- If 0 is in the subgradient, we've found the minimum

This is essentially bisection and converges in O(log(1/ε)) iterations.

def softmax_obj_grad(h, tau):

    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')

    # Gradient

Actually, for shift with lag d, the contribution of h[j] is:
- If j+d is valid: h[j] * (1-h[j+d])
- If j-d is valid: h[j-d] * (1-h[j])

If I change h[j] from a to b:
- For shift d (where j+d valid): change = (b-a) * (1-h[j+d])
- For shift d (where j-d valid, i.e., lag = -(j-i) for i=j-d): change = -(b-a) * h[j-d]
