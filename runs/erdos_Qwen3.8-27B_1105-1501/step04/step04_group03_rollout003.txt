Key insight: The problem is C₅ = max_k ∫ h(x)(1-h(x+k)) dx. This is the maximum over all shifts of the "overlap" between h and (1-h). 

The integral ∫ h(x)(1-h(x+k)) dx measures how much h at position x overlaps with the "complement" of h at position x+k.

If h is constant 0.5 everywhere, then h(x)(1-h(x+k)) = 0.25 always, so the integral over [0,2] is 0.5. So C₅ ≤ 0.5 for the trivial solution.

To do better, we want h to be more "structured" so that at the worst shift, h and (1-h) overlap less.

Key mathematical insight: The sum over all shifts of ∫ h(x)(1-h(x+k)) dx relates to the autocorrelation of h. Specifically:
- ∑_k ∫ h(x)(1-h(x+k)) dx over all k from -n+1 to n-1
- This equals ∫ [h(x) * (number of k where 1-h is defined at x+k)] dx - ∫ h(x) * (sum of h(x+k)) dx

Actually, let me think more carefully. The key quantity is:
S(d) = ∑_i h[i] * (1-h[i+d]) for d ≥ 0 (with appropriate bounds)

And C₅ = max_d S(d) * dx

The average of S(d) over all d is related to the mean of h. Since ∑h = n/2, the average value of h is 1/2.

For the average overlap: 
Average of S(d) over all d should be approximately (n/2) * (n/2) / n = n/4 (roughly), so the average C₅ contribution is about 0.5.

To get below 0.5, we need to make the maximum shift have less overlap than average. This means we want the overlap to be "spread out" or concentrated at low-overlap shifts.

Let me think about what structure helps. If h has a periodic structure with period p, then the overlaps at multiples of p will be high, and at other shifts will be lower (or vice versa).

For the Erdős problem, the known constructions involve patterns that avoid high overlap at all shifts. The optimal construction is believed to have C₅ close to some value.

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')

def project_to_feasible(v, target):

    if abs(residual) > 1e-12:
        if residual > 0:

        else:
            mask = x > 1e-10

            else:
                idx = int(np.argmin(x))

    return x

def active_lag_gradient(h, scores, top_k, tau):
    n = len(h)
    dx = 2.0 / n
    center = n - 1
    max_s = float(np.max(scores))
    
    # Select active lags
    # Use top_k lags or those within threshold
    threshold = max_s - tau * max(0.01, max_s)
    active = np.where(scores >= threshold)[0]
    if len(active) == 0:
        active = np.array([center])
    # Limit to top_k
    if len(active) > top_k:
        active = active[np.argsort(scores[active])[-top_k:]]
    
    # Compute weights
    w_raw = np.exp((scores[active] - max_s) / max(tau * max_s, 1e-10))
    w = w_raw / np.sum(w_raw)
    
    # Compute weighted gradient
    grad = np.zeros(n)
    for idx in range(len(active)):
        k = active[idx]
        d = k - center
        wk = w[idx] * dx
        if d >= 0:
            m = n - d
            if m > 0:
                # S = sum_{i=0}^{m-1} h[i+d]*(1-h[i])
                # dS/dh[i] for i in [0, m-1]: += -h[i+d]
                grad[:m] += wk * (-h[d:d+m])
                # dS/dh[i] for i in [d, n-1]: += (1-h[i-d])
                grad[d:] += wk * (1.0 - h[:m])
        else:
            g = -d
            m = n - g
            if m > 0:
                # S = sum_{i=0}^{m-1} h[i]*(1-h[i+g])
                # dS/dh[i] for i in [0, m-1]: += (1-h[i+g])
                grad[:m] += wk * (1.0 - h[g:g+m])
                # dS/dh[i] for i in [g, n-1]: += -h[i-g]
                grad[g:] += wk * (-h[:m])
    
    return grad

    scores = compute_scores(h)
    grad = active_lag_gradient(h, scores, top_k, tau)
    
    # Project gradient to maintain sum constraint
    mean_g = np.mean(grad)
    p = mean_g - grad  # sum(p) = 0
    p_scale = np.max(np.abs(p))
    if p_scale < 1e-14:
        return None, None
    p = p / p_scale
    
    alpha, new_c5 = line_search_exact(h, p, n/2.0, c5_cur, max_alpha)
    if alpha > 1e-10 and new_c5 < c5_cur - 1e-12:
        new_h = h + alpha * p
        new_h = np.clip(new_h, 0.0, 1.0)
        new_h = project_to_feasible(new_h, n / 2.0)
        return new_h, compute_c5(new_h)
    
    # Try negative direction too

    new_h[j] -= sign * amount
    if new_h[i] < 0 or new_h[i] > 1 or new_h[j] < 0 or new_h[j] > 1:
        return None
    return new_h

def resample(h_old, n_new):

    if n_new == n_old:

    x_old = (np.arange(n_old) + 0.5) / n_old

    h_new = np.interp(x_new, x_old, h_old)
