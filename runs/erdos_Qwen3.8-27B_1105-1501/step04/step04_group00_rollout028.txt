Now, for efficiency, instead of computing the full gradient matrix (2n-1 × n), I can compute the weighted gradient directly:

```python
def _weighted_grad(h, weights):
    """Compute weighted sum of gradients for each lag."""
    n = len(h)
    grad = np.zeros(n)
    for d in range(-(n-1), n):
        w = weights[n-1+d]
        if abs(w) < 1e-15:
            continue
        # Add w * grad_for_lag(h, d)
        if d >= 0:
            m = n - d
            if m <= 0:
                continue
            grad[:m] += w * (1.0 - h[d:])
            grad[d:] -= w * h[:m]
        else:
            g = -d
            m = n - g
            if m <= 0:
                continue
            grad[g:] += w * (1.0 - h[:m])
            grad[:m] -= w * h[g:]
    return grad * (2.0 / n)
```

This is O(n²) but with the sparse skipping of zero weights, it can be much faster when only a few lags have significant weight.
