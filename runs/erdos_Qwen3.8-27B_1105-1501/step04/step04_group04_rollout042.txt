```python
def compute_coefs(h, n):
    # coef[i, k] = coefficient of h[i] in corr[k] for np.correlate(h, 1-h, 'full')
    L = 2*n - 1
    coef = np.zeros((n, L))
    for k in range(L):
        s = k - (n - 1)
        # valid n range
        n_lo = max(0, -s)
        n_hi = min(n, n - s)  # n_hi is exclusive
        for n_idx in range(n_lo, n_hi):
            # term: h[n_idx + s] * (1 - h[n_idx])
            # h[n_idx + s] contributes coefficient (1 - h[n_idx]) to h[n_idx+s]
            i = n_idx + s
            if 0 <= i < n:
                coef[i, k] += (1.0 - h[n_idx])
            # h[n_idx] contributes coefficient -h[n_idx+s] to h[n_idx]
            coef[n_idx, k] += (-h[n_idx + s])
    return coef
```

1. Evaluate at δ_lo and δ_hi.

3. Find all intersection points of pairs of lines within [δ_lo, δ_hi].
4. At each intersection, check if both lines are ≥ all others (i.e., they're on the upper envelope).
5. The minimum is the lowest value on the upper envelope.

    n_coarse = 50

    values = np.max(F[None, :] + a[None, :] * deltas[:, None], axis=1)
    best_idx = np.argmin(values)

        return delta_lo, np.max(F + a * delta_lo)
    if best_idx == n_coarse - 1:
        return delta_hi, np.max(F + a * delta_hi)
    
    # Phase 2: narrow to [deltas[best_idx-1], deltas[best_idx+1]]
    lo_d = deltas[best_idx - 1]
    hi_d = deltas[best_idx + 1]
