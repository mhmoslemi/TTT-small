def project(v, target):

    n = len(v)
    if target <= 0: return np.zeros(n)

    # Term 3: -h[i-d] valid when 0 ≤ i-d < n, i.e., i-n < d ≤ i

At d=0: d_h[i]*d_h[i] + d_h[j]*d_h[j] = sign² + sign² = 2sign² = 2
So Q[0] = -2 (independent of sign!)

At d=j-i: d_h[i]*d_h[j] = sign*(-sign) = -sign² = -1
So Q[j-i] = -(-1) = 1 (independent of sign!)

- For sign=+1: new_score = score + t*L + t²*Q
- For sign=-1: new_score = score - t*L + t²*Q

So I can compute L once per pair and use it for both signs.
