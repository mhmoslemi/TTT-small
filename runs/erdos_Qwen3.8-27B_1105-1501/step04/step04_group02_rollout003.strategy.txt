1. Approach and rationale

The task is a discrete nonconvex minimax box-constrained problem. The exact objective is

F(h) = dx * max_r np.correlate(h, 1 - h)[r],  dx = 2/n,

with 0 <= h_j <= 1 and sum_j h_j = n/2 exactly. The numerical optimum is continuous but sits at the edge of a binary model: many components are near 0 or 1, and the maximum is determined by a small set of “active” lags. The goal is to improve the supplied parent by roughly 1e-4 in C5. A single smoothed descent direction is too weak; one needs to combine:

- exact smoothing using raw correlation scores, because the finite support and all lag directions matter;
- an active-set linear-programming direction that tries to make a decreasing linearization possible for only the top active lags (not all lags), then exact line search validates it;
- a target downward continuation minimizing squared exceedance of a threshold below the current best; if it reaches the threshold, improvement is discovered, otherwise it gives a very good descent candidate;
- second-order/nullspace line search for plateaus where active gradients alone block first-order movement;
- pairwise fractional-exchange moves because local improvements are often exchange-like (increase one fractional component and decrease another) and the nonconvexity is dominated by products involving active score rows;
- adaptive resolution, evaluated by the exact discrete post, so the returned vector may use a better resolution and, when tied but strictly better metric, a smaller n as requested.

1. Approach and rationale

The objective is fixed-dimensional, discrete, minimax, and nonconvex because entries multiply through products h_i*h_j inside each correlation score. The current parent is already close to a high-quality local optimum, so merely minimizing a smooth soft-max is expected to stall: it balances all scores but does not exploit that only a small number of active correlation lags block lowering C5, and it ignores second-order and exchange-like moves inside the active set.

The proposed method uses the exact objective as the sole acceptance criterion and combines five complementary exact-score-aware engines:

1. A T-reduction “target driving” solver using raw squared exceedance above a threshold lower than the current best. If the minimizer reaches threshold, a new record is found. If it does not, it still produces a valid point below the old max, because it only tries to decrease scores above threshold.
2. An active-top-lag linear-programming descent direction: on only the strongest active lags, solve for a zero-sum displacement p such that all selected active linearized scores decrease, while feasible box bounds are honored. Line search uses the exact evaluator; invalid/over-shooting directions are rejected. Radius and active-subset sweeps find stronger directions than using only a global soft-max gradient.
3. A p-norm / soft-max annealing procedure for smooth surrogate minimization from diversified parent-like states. It is not accepted directly; each resulting state is tested by exact C5 evaluation and used as a new starting point for the active targeting engines.
4. Second-order/nullspace descent when top-derivative linear descent fails: sample random directions orthogonal to selected active gradients (with zero-sum run) and exact line search. At an active-set KKT local optimum, first-order directions vanish, but second-order/cross-lag tradeoffs are only discoverable by this step.
5. Pairwise fractional-exchange moves because constructions here often have many entries near 0/1 and a few fractional entries; local improvement is most easily found by increasing one active fractional component and decreasing another, while sum is preserved. Line-optimized pair moves on a selected pair list give cheap robust moves that generic gradient/soft-max misses.

Multi-resolution is included. The objective is evaluated exactly for whatever returned h array is chosen. Resolution changes use area-preserving resampling and exact projection; transfers are only accepted as best when exact re-evaluation improves (strictly, or ties with smaller n because smaller is preferred). No surrogate, relaxation, smoothing, or internal bound produces final output without exact re-evaluation.

This plan should improve the parent because it attacks the bottleneck via exact active-lag tradeoffs (LP, second order) and targeted threshold feasibility/minimization, whose details are cisfully specific inside the parent vector components—sufficient to exploit small potential reduction from ~0.380903 to near 0.38080 while still having a good fallback.
