Let me analyze the problem carefully:

1. We need to find a step function h: [0,2] → [0,1] with ∫₀² h(x) dx = 1 that minimizes C₅ = max_k ∫ h(x)(1-h(x+k)) dx

2. The discretization: n points over [0,2], dx = 2/n, sum(h) * dx = 1, so sum(h) = n/2.

3. The evaluation: C₅ = max(np.correlate(h, 1-h, mode="full") * dx)

4. Current record: C₅ ≤ 0.38085, previous program achieved 0.380903.

5. We have `initial_h_values` with n=90 samples.

Key insights for improvement:
- The previous program used gradient descent with softmax approximation, LP-based local search, direction search, multi-resolution, perturbation refinement, and pair refinement.
- The strategy suggests using SLSQP on the epigraph form of the problem, which is a fundamentally different approach.

Let me think about what could actually improve the result:

1. **SLSQP on epigraph form**: The problem is minimize T subject to S_r(h) ≤ T for all r, sum(h) = n/2, 0 ≤ h ≤ 1. This is a nonlinear program (because S_r are bilinear in h). SLSQP can handle this.

2. **Key advantage**: SLSQP directly optimizes the max constraint structure, rather than approximating it with softmax or only looking at currently active constraints. It can coordinate reducing multiple constraints simultaneously.

3. **Multi-resolution**: Trying different n values and resampling can escape local optima.

4. **Pair refinement**: Exact pair moves that preserve sum can polish the solution.

Let me think about the gradient of S_r more carefully:

For lag d ≥ 0: S_r = Σ_{i=0}^{n-d-1} h[i+d] * (1-h[i])
- ∂S_r/∂h[i] for i in [0, n-d): -h[i+d] (from the (1-h[i]) term)
- ∂S_r/∂h[i+d] for i in [0, n-d): (1-h[i]) (from the h[i+d] term)

So for index j:
- If j < n-d: ∂S_r/∂h[j] gets -h[j+d] from the first part
- If j ≥ d: ∂S_r/∂h[j] gets (1-h[j-d]) from the second part

For lag d < 0, let g = -d:
S_r = Σ_{i=0}^{n-g-1} h[i] * (1-h[i+g])
- ∂S_r/∂h[i] for i in [0, n-g): (1-h[i+g])
- ∂S_r/∂h[i+g] for i in [0, n-g): -h[i]

So for index j:
- If j < n-g: ∂S_r/∂h[j] gets (1-h[j+g])
- If j ≥ g: ∂S_r/∂h[j] gets -h[j-g]

Now, the key thing about SLSQP with this problem:
- n+1 variables (h_0, ..., h_{n-1}, T)
- 2n-1 inequality constraints (S_r ≤ T)
- 1 equality constraint (sum(h) = n/2)
- n+1 box constraints

For n=90, that's 91 variables and 179 inequality constraints. SLSQP should handle this, but it might be slow. Let me think about how to make it efficient.

Actually, for SLSQP, the constraint Jacobian is a (2n-1) × (n+1) matrix. Each row r has the gradient of S_r in the first n columns and -1 in the last column. This is a dense matrix of size ~179 × 91 ≈ 16300 entries, which is manageable.

The main concern is the number of function evaluations SLSQP needs. With maxiter set appropriately (say 50-100), it should complete in reasonable time.

Let me also think about alternative approaches:

1. **Subgradient method**: Instead of SLSQP, use a direct subgradient approach for the minimax. The subgradient of max_r S_r(h) is any convex combination of the gradients of the active constraints. This is what the previous program was doing with the softmax approximation. The advantage of SLSQP is that it uses second-order information implicitly.

2. **Dual approach**: The LP approximation in the previous program was essentially solving a dual problem. SLSQP might be more effective because it handles the nonlinearity directly.

3. **Active set identification**: At the optimum, only a few constraints are typically active. If we can identify which ones, we can solve a smaller problem.

Phase 1: Initialize from parent, quick gradient warmup
Phase 2: SLSQP epigraph solve at current resolution
Phase 3: Multi-resolution search with SLSQP at each
Phase 4: Pair refinement
Phase 5: Final SLSQP polish

import numpy as np
from scipy.optimize import minimize
import time

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo = float(v.min()) - 2.0
    hi = float(v.max()) + 2.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    x = np.clip(v - (lo + hi) / 2.0, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-10:
        if res > 0:
            mask = x < 1.0 - 1e-14
        else:
            mask = x > 1e-14
        cnt = int(np.sum(mask))
        if cnt > 0:
            x = x.copy()
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _raw_scores(h):
    """Compute raw correlation scores (without dx factor)."""
    n = len(h)
    m = 2 * n - 1
    scores = np.zeros(m)
    for r in range(m):
        d = r - (n - 1)
        if d >= 0:
            mlen = n - d
            scores[r] = np.dot(h[d:], 1.0 - h[:mlen])
        else:
            g = -d
            mlen = n - g
            scores[r] = np.dot(h[:mlen], 1.0 - h[g:])
    return scores

def _raw_grad_matrix(h):
    """Compute the gradient matrix for all raw scores. G[r] = grad of S_r w.r.t. h."""
    n = len(h)
    m = 2 * n - 1
    G = np.zeros((m, n))
    for r in range(m):
        d = r - (n - 1)
        if d >= 0:
            mlen = n - d
            G[r, :mlen] += -h[d:]
            G[r, d:] += 1.0 - h[:mlen]
        else:
            g = -d
            mlen = n - g
            G[r, :mlen] += 1.0 - h[g:]
            G[r, g:] += -h[:mlen]
    return G

def _slsqp_solve(h, deadline, maxiter=None, ftol=1e-9):
    """Solve the epigraph NLP using SLSQP.
    
    minimize T subject to S_r(h) - T <= 0, sum(h) = n/2, 0 <= h <= 1
    """
    n = len(h)
    target = n / 2.0
    h = h.copy()
    cur_c5 = _exact_c5(h)
    
    if maxiter is None:
        if n <= 80:
            maxiter = 80
        elif n <= 120:
            maxiter = 60
        else:
            maxiter = 40
    
    # Initial T
    scores = _raw_scores(h)
    T0 = float(np.max(scores)) + 0.01
    
    def objective(x):
        return x[n]
    
    def obj_grad(x):
        g = np.zeros(n + 1)
        g[n] = 1.0
        return g
    
    def constraint_func(x):
        hvec = x[:n]
        T = x[n]
        scores = _raw_scores(hvec)
        return scores - T
    
    def constraint_jac(x):
        hvec = x[:n]
        G = _raw_grad_matrix(hvec)
        jac = np.empty((2 * n - 1, n + 1))
        jac[:, :n] = G
        jac[:, n] = -1.0
        return jac
    
    constraints = [
        {'type': 'ineq', 'fun': constraint_func, 'jac': constraint_jac},
        {'type': 'eq', 'fun': lambda x: np.sum(x[:n]) - target,
         'jac': lambda x: np.concatenate([np.ones(n), [0.0]])}
    ]
    
    bounds = [(0.0, 1.0)] * n + [(0.0, float(n))]
    
    x0 = np.concatenate([h, [T0]])
    
    try:
        res = minimize(objective, x0, method='SLSQP', jac=obj_grad,
                       constraints=constraints, bounds=bounds,
                       options={'maxiter': maxiter, 'ftol': ftol, 'disp': False})
        if res.x is not None and np.all(np.isfinite(res.x)):
            h_new = res.x[:n]
            h_new = _project(h_new, target)
            c5_new = _exact_c5(h_new)
            if c5_new < cur_c5:
                return h_new, c5_new
    except Exception:
        pass
    
    return h, cur_c5

def _grad_optimize(h, deadline, tau_init=15.0, lr_init=0.02, mom_beta=0.9):
    """Gradient descent with softmax approximation of max."""
    n = len(h)
    target = n / 2.0
    h = h.copy()
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    mom = np.zeros(n)
    tau = tau_init
    lr = lr_init
    stall = 0
    while time.time() < deadline:
        dx = 2.0 / n
        scores = np.correlate(h, 1.0 - h, mode='full') * dx
        max_s = float(np.max(scores))
        shifted = tau * (scores - max_s)
        exp_s = np.exp(shifted)
        w = exp_s / float(np.sum(exp_s))
        # Compute weighted gradient efficiently
        G = _raw_grad_matrix(h)
        grad = (w @ G) * dx
        mom = mom_beta * mom + (1.0 - mom_beta) * grad
        h_new = h - lr * mom
        h_new = _project(h_new, target)
        c5_new = _exact_c5(h_new)
        if c5_new < cur_c5 - 1e-13:
            h = h_new
            cur_c5 = c5_new
            stall = 0
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            lr = min(lr * 1.03, 0.15)
            tau = min(tau * 1.02, 200.0)
        else:
            stall += 1
            lr *= 0.92
            if stall > 80:
                break
            if stall % 30 == 0:
                tau = max(tau_init, tau * 0.8)
    return best_h, best_c5

def _pair_refine(h, deadline, max_passes=100):
    """Local pair refinement."""
    n = len(h)
    target = n / 2.0
    h = h.copy()
    best_h = h.copy()
    best_c5 = _exact_c5(h)
    rng = np.random.default_rng(12345)
    
    for _pass in range(max_passes):
        if time.time() > deadline:
            break
        improved = False
        # Select a subset of pairs
        if n > 60:
            n_pairs = min(200, n * 3)
        else:
            n_pairs = n * (n - 1) // 2
        # Random pairs
        for _ in range(n_pairs):
            if time.time() > deadline:
                break
            j = rng.integers(0, n)
            k = rng.integers(0, n)
            if j == k:
                continue
            if h[j] <= 1e-8 or h[j] >= 1.0 - 1e-8 or h[k] <= 1e-8 or h[k] >= 1.0 - 1e-8:
                continue
            for (dj, dk) in [(1.0, -1.0), (-1.0, 1.0)]:
                am = h[j] if dj < 0 else (1.0 - h[j])
                am2 = h[k] if dk < 0 else (1.0 - h[k])
                am = min(am, am2)
                if am < 1e-12:
                    continue
                for frac in [0.5, 0.8, 1.0]:
                    h_t = h.copy()
                    h_t[j] += dj * am * frac
                    h_t[k] += dk * am * frac
                    if h_t[j] < -1e-6 or h_t[j] > 1.0 + 1e-6 or h_t[k] < -1e-6 or h_t[k] > 1.0 + 1e-6:
                        continue
                    h_t = np.clip(h_t, 0.0, 1.0)
                    c5_t = _exact_c5(h_t)
                    if c5_t < best_c5 - 1e-12:
                        best_c5 = c5_t
                        best_h = h_t.copy()
                        h = h_t.copy()
                        improved = True
                        break
        if not improved:
            break
    return best_h, best_c5

def _resample(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return _project(h_new, n_new / 2.0)

def _multi_resolution(h_best, n_best, deadline, time_budget):
    """Try nearby resolutions and optimize at each."""
    best_h = h_best.copy()
    best_c5 = _exact_c5(h_best)
    best_n = n_best
    offsets = [0, -2, 2, -4, 4, -6, 6, -8, 8, -10, 10, -14, 14, -20, 20]
    tried = set()
    time_per = max(5.0, time_budget / len(offsets))
    
    for dn in offsets:
        if time.time() > deadline:
            break
        n_try = n_best + dn
        if n_try < 40 or n_try > 200:
            continue
        if n_try in tried:
            continue
        tried.add(n_try)
        h_r = _resample(best_h, n_try)
        c5_r = _exact_c5(h_r)
        # Brief gradient optimization
        sub_dl = min(deadline, time.time() + time_per * 0.4)
        if time.time() < sub_dl:
            h_r, c5_r = _grad_optimize(h_r, sub_dl, tau_init=20.0, lr_init=0.015, mom_beta=0.9)
        # SLSQP if size allows
        if time.time() < deadline and n_try <= 140:
            sub_dl2 = min(deadline, time.time() + time_per * 0.5)
            if time.time() < sub_dl2:
                h_r, c5_r = _slsqp_solve(h_r, sub_dl2, maxiter=30)
        if c5_r < best_c5 - 1e-11:
            best_c5 = c5_r
            best_h = h_r.copy()
            best_n = n_try
    
    return best_h, best_c5, best_n

def _active_set_slsqp(h, deadline, top_k=20):
    """SLSQP using only the top-k active constraints for efficiency."""
    n = len(h)
    target = n / 2.0
    h = h.copy()
    cur_c5 = _exact_c5(h)
    
    maxiter = 50
    if n > 120:
        maxiter = 30
    
    scores = _raw_scores(h)
    top_indices = np.argsort(scores)[::-1][:top_k]

        return x[n]

        g = np.zeros(n + 1)

        return g

        jac = np.empty((len(top_indices), n + 1))

        return jac
    
    constraints = [

    except Exception:

def _lp_direction(h, scores, radius):
    """Find LP direction minimizing max_r (scores_r + G_r . p) subject to ||p||_inf <= radius, sum(p)=0."""
    n = len(h)
    m = 2 * n - 1
    G = _raw_grad_matrix(h)
    
    # LP: min t s.t. scores[r] + G[r].p <= t, -radius <= p_i <= radius, sum(p) = 0
    # Variables: p_0,...,p_{n-1}, t
    from scipy.optimize import linprog
    
    c_vec = np.zeros(n + 1)
    c_vec[-1] = 1.0
    
    A_ub = np.zeros((m, n + 1))
    A_ub[:, :n] = G
    A_ub[:, n] = -1.0
    b_ub = -scores
    
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.zeros(1)
    
    bounds = []
    for j in range(n):
        bounds.append((max(-radius, -h[j]), min(radius, 1.0 - h[j])))
    bounds.append((None, None))
    
    try:
        res = linprog(c_vec, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs')
        if res.success:
            return res.x[:n]
    except Exception:
        pass
    return None

def _line_search(h, p, c5_cur, alpha_max):
    """Line search along direction p."""
    best_t = 0.0
    best_val = c5_cur
    n_grid = 25
    ts = np.linspace(0.0, alpha_max, n_grid)
    vals = np.full(n_grid, c5_cur + 1.0)
    for i, t in enumerate(ts):
        h_t = h + t * p
        if h_t.min() >= -1e-12 and h_t.max() <= 1.0 + 1e-12:
            vals[i] = _exact_c5(h_t)
    idx = int(np.argmin(vals))
    best_t, best_val = ts[idx], vals[idx]
    return best_t, best_val

def _lp_local(h, deadline, radius_init=0.15):
    """LP-based local search."""
    n = len(h)
    target = n / 2.0
    h = h.copy()
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    radius = radius_init
    stall = 0
    while time.time() < deadline:
        if stall > 60:
            break
        dx = 2.0 / n
        scores = np.correlate(h, 1.0 - h, mode='full') * dx
        p = _lp_direction(h, scores / dx, radius)  # use raw scores
        if p is None or float(np.max(np.abs(p))) < 1e-14:
            stall += 1
            radius *= 0.6
            if radius < 1e-7:
                break
            continue
        alpha_max = 1.0
        for j in range(n):
            if p[j] > 1e-14:
                alpha_max = min(alpha_max, (1.0 - h[j]) / p[j])
            elif p[j] < -1e-14:
                alpha_max = min(alpha_max, h[j] / (-p[j]))
        alpha_max = max(alpha_max, 1e-10)
        alpha, new_c5 = _line_search(h, p, cur_c5, alpha_max)
        if new_c5 < cur_c5 - 1e-13:
            h = h + alpha * p
            h = _project(h, target)
            cur_c5 = _exact_c5(h)
            stall = 0
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            radius = min(radius * 1.15, 0.5)
        else:
            stall += 1
            radius *= 0.65
            if stall % 15 == 0 and radius < 0.02:
                radius = 0.08
    return best_h, best_c5

2. For n=90, that's 91 variables and 180 constraints

            break
        scores = _raw_scores(h)
        top_idx = np.argsort(scores)[::-1][:top_k]
        h_new, c5_new = _slsqp_solve(h, min(deadline, time.time() + 30),
                                      maxiter=40, use_active=True, top_k=top_k)
        if c5_new < cur_c5 - 1e-12:
            h = h_new
            cur_c5 = c5_new
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
        else:
            break
    return best_h, best_c5

def _grad_optimize(h, deadline, tau_init=15.0, lr_init=0.02, mom_beta=0.9):
    n = len(h)
    target = n / 2.0
    h = _project(h.copy(), target)
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    mom = np.zeros(n)
    tau = tau_init
    lr = lr_init
    stall = 0
    while time.time() < deadline:
        dx = 2.0 / n
        scores = np.correlate(h, 1.0 - h, mode='full') * dx
        max_s = float(np.max(scores))
        shifted = tau * (scores - max_s)
        exp_s = np.exp(shifted)
        w = exp_s / float(np.sum(exp_s))
        G = _raw_grad_matrix(h)
        grad = (w @ G) * dx
        mom = mom_beta * mom + (1.0 - mom_beta) * grad
        h_new = h - lr * mom
        h_new = _project(h_new, target)
        c5_new = _exact_c5(h_new)
        if c5_new < cur_c5 - 1e-13:
            h = h_new
            cur_c5 = c5_new
            stall = 0
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            lr = min(lr * 1.03, 0.15)
            tau = min(tau * 1.02, 200.0)
        else:
            stall += 1
            lr *= 0.92
            if stall > 80:
                break
            if stall % 30 == 0:
                tau = max(tau_init, tau * 0.8)
    return best_h, best_c5

def _lp_direction(h, scores_raw, radius):
    n = len(h)
    m = 2 * n - 1
    G = _raw_grad_matrix(h)
    c_vec = np.zeros(n + 1)
    c_vec[-1] = 1.0
    A_ub = np.zeros((m, n + 1))
    A_ub[:, :n] = G
    A_ub[:, n] = -1.0
    b_ub = -scores_raw
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.zeros(1)
    bounds = []
    for j in range(n):
        bounds.append((max(-radius, -h[j]), min(radius, 1.0 - h[j])))
    bounds.append((None, None))
    try:
        res = linprog(c_vec, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs')
        if res.success:
            return res.x[:n]
    except Exception:
        pass
    return None

def _line_search(h, p, c5_cur, alpha_max):
    best_t = 0.0
    best_val = c5_cur
    n_grid = 25
    ts = np.linspace(0.0, alpha_max, n_grid)
    for i, t in enumerate(ts):
        h_t = h + t * p
        if h_t.min() >= -1e-12 and h_t.max() <= 1.0 + 1e-12:
            v = _exact_c5(h_t)
            if v < best_val:
                best_val = v
                best_t = t
    return best_t, best_val

def _lp_local(h, deadline, radius_init=0.15):
    n = len(h)
    target = n / 2.0
    h = _project(h.copy(), target)
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    radius = radius_init
    stall = 0
    while time.time() < deadline:
        if stall > 60:
            break
        scores_raw = _raw_scores(h)
        p = _lp_direction(h, scores_raw, radius)
        if p is None or float(np.max(np.abs(p))) < 1e-14:
            stall += 1
            radius *= 0.6
            if radius < 1e-7:
                break
            continue
        alpha_max = 1.0
        for j in range(n):
            if p[j] > 1e-14:
                alpha_max = min(alpha_max, (1.0 - h[j]) / p[j])
            elif p[j] < -1e-14:
                alpha_max = min(alpha_max, h[j] / (-p[j]))
        alpha_max = max(alpha_max, 1e-10)
        alpha, new_c5 = _line_search(h, p, cur_c5, alpha_max)
        if new_c5 < cur_c5 - 1e-13:
            h = h + alpha * p
            h = _project(h, target)
            cur_c5 = _exact_c5(h)
            stall = 0
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            radius = min(radius * 1.15, 0.5)
        else:
            stall += 1
            radius *= 0.65
            if stall % 15 == 0 and radius < 0.02:
                radius = 0.08
    return best_h, best_c5

def _pair_refine(h, deadline, max_passes=200, seed=12345):
    n = len(h)
    target = n / 2.0
    h = _project(h.copy(), target)
    best_h = h.copy()
    best_c5 = _exact_c5(h)
    rng = np.random.default_rng(seed)
    for _pass in range(max_passes):
        if time.time() > deadline:
            break
        improved = False
        n_pairs = min(300, n * 4) if n > 50 else n * (n - 1) // 2
        for _ in range(n_pairs):
            if time.time() > deadline:
                break
            j = int(rng.integers(0, n))
            k = int(rng.integers(0, n))
            if j == k:
                continue
            if h[j] <= 1e-8 or h[j] >= 1.0 - 1e-8 or h[k] <= 1e-8 or h[k] >= 1.0 - 1e-8:
                continue
            for (dj, dk) in [(1.0, -1.0), (-1.0, 1.0)]:
                am = (1.0 - h[j]) if dj > 0 else h[j]
                am2 = (1.0 - h[k]) if dk > 0 else h[k]
                am = min(am, am2)
                if am < 1e-12:
                    continue
                for frac in [0.5, 0.8, 1.0]:
                    h_t = h.copy()
                    h_t[j] += dj * am * frac
                    h_t[k] += dk * am * frac
                    if h_t[j] < -1e-6 or h_t[j] > 1.0 + 1e-6 or h_t[k] < -1e-6 or h_t[k] > 1.0 + 1e-6:
                        continue
                    h_t = np.clip(h_t, 0.0, 1.0)
                    c5_t = _exact_c5(h_t)
                    if c5_t < best_c5 - 1e-12:
                        best_c5 = c5_t
                        best_h = h_t.copy()
                        h = h_t.copy()
                        improved = True
                        break
        if not improved:
            break
    return best_h, best_c5

def _resample(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return _project(h_new, n_new / 2.0)

def _multi_resolution(h_best, n_best, deadline, time_budget):
    best_h = h_best.copy()
    best_c5 = _exact_c5(h_best)
    best_n = n_best
    offsets = [0, -2, 2, -4, 4, -6, 6, -8, 8, -10, 10, -12, 12, -16, 16, -20]
    tried = set()
    n_offsets = len(offsets)
    time_per = max(8.0, time_budget / n_offsets)
    for dn in offsets:
        if time.time() > deadline:
            break
        n_try = n_best + dn
        if n_try < 40 or n_try > 200:
            continue
        if n_try in tried:
            continue
        tried.add(n_try)
        h_r = _resample(best_h, n_try)
        c5_r = _exact_c5(h_r)
        sub_dl = min(deadline, time.time() + time_per * 0.3)
        if time.time() < sub_dl and n_try <= 130:
            h_r, c5_r = _slsqp_solve(h_r, sub_dl, maxiter=30)
        if time.time() < deadline:
            sub_dl2 = min(deadline, time.time() + time_per * 0.35)
            h_r, c5_r = _lp_local(h_r, sub_dl2, radius_init=0.12)
        if time.time() < deadline:
            sub_dl3 = min(deadline, time.time() + time_per * 0.25)
            h_r, c5_r = _slsqp_solve(h_r, sub_dl3, maxiter=25, use_active=True, top_k=20)
        if c5_r < best_c5 - 1e-11:
            best_c5 = c5_r
            best_h = h_r.copy()
            best_n = n_try
    return best_h, best_c5, best_n

def _perturb_refine(h_best, deadline, budget_s, seed=42):
    n = len(h_best)
    target = n / 2.0
    rng = np.random.default_rng(seed)
    best_h = h_best.copy()
    best_c5 = _exact_c5(h_best)
    scale = 0.03
    time_per = max(10.0, budget_s * 0.03)
    attempt = 0
    while time.time() < deadline and attempt < 100:
        attempt += 1
        h_pert = best_h + rng.normal(0, scale, n)
        h_pert = _project(h_pert, target)
        sub_dl = min(deadline, time.time() + time_per * 0.4)
        if time.time() < sub_dl:
            h_try, c5_try = _slsqp_solve(h_pert, sub_dl, maxiter=25, use_active=True, top_k=20)
        else:
            h_try, c5_try = h_pert, _exact_c5(h_pert)
        sub_dl2 = min(deadline, time.time() + time_per * 0.4)
        if time.time() < sub_dl2:
            h_try, c5_try = _lp_local(h_try, sub_dl2, radius_init=0.08)
        if c5_try < best_c5 - 1e-11:
            best_c5 = c5_try
            best_h = h_try.copy()
            scale = max(0.005, scale * 0.8)
        else:
            scale = min(0.2, scale * 1.3)
    return best_h, best_c5

def _hard_active_search(h, deadline, top_k_list=None):
    n = len(h)
    target = n / 2.0
    h = _project(h.copy(), target)
    best_h = h.copy()
    best_c5 = _exact_c5(h)
    if top_k_list is None:
        top_k_list = [15, 20, 30, 40, 60, 80]
    for top_k in top_k_list:
        if time.time() > deadline:
            break
        if top_k >= 2 * n - 1:
            top_k = 2 * n - 1
        sub_dl = min(deadline, time.time() + 20)
        h_new, c5_new = _slsqp_solve(h, sub_dl, maxiter=35, use_active=True, top_k=top_k)
        if c5_new < best_c5 - 1e-12:
            best_c5 = c5_new
            best_h = h_new.copy()
            h = h_new.copy()
        else:
            h, _ = _slsqp_solve(h, min(deadline, time.time() + 10),
                                maxiter=20, use_active=True, top_k=top_k)
            if c5_new < best_c5 - 1e-12:
                best_c5 = c5_new
                best_h = h_new.copy()
    return best_h, best_c5
