1. Approach and rationale

1.1 Central idea

The existing parent construction already reaches approximately \(C_5 = 0.380907\). The gap to the target \(0.38085\) – and ultimately \(0.3808\) – is small, so the goal is not to find an entirely new construction in one shot, but to combine several complementary mechanisms that each reliably find small, cheap-to-evaluate improvements around nearby discretizations and around local minima.

The proposed method is a three-layer search:

1. A hierarchical multi-resolution search over several sample sizes. This uses cheaper coarse grids to discover favorable basins, then transfers candidates upward or downward in resolution and evaluates them using the authoritative exact objective.

2. A smooth-envelope constrained minimizer. The exact objective is the maximum of \((2n-1)\) quadratic functions. We replace the maximum only inside the optimizer by a log-sum-exp envelope, optimize the smoothed problem with equality constraints, and always re-evaluate all candidates using the original exact \(C_5\). The previous program used this idea, but with relatively short settle phases. The new program will do adaptive warmStarted smoothing, more careful walks in direction space, and exact final line polishing.

3. A stochastic/global diversification layer over the best known candidates. Unlike the previous program, which mainly regularizes and LP-localizes, this plan adds an explicit constrained local descent–basin-hopping/stochastic-annealing layer, pool-based competitive selection, and selective constraint-aware swap searches. This allows escaping shallow local minima without abandoning high-quality feasible counters.

This combination addresses the bottleneck: the objective is a nonsmooth maximum of bilinear finitesupport terms, with a hard box-plus-affine-simplicity constraint. Pure smoothing may stall near an overly symmetric surrogate optimum; exact active-set line search recovers the true maximum; random perturbations and pool mixing help find neighboring basins; variable grid sizes supply cheap global information.

The method is heuristic. It does not certify global optimality. All acceptance decisions are made with the exact evaluator, so returned values are valid upper bounds whenever the returned sequence satisfies the box and sum constraints.
