    n = len(v)

        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    v = np.asarray(v, dtype=float)
    lo, hi = v.min() - 1.0, v.max() + 1.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        if np.sum(np.clip(v - mid, 0.0, 1.0)) > target:
            lo = mid
        else:
            hi = mid
    x = np.clip(v - (lo + hi) / 2.0, 0.0, 1.0)

3. If k0 = k1, the minimum is at an endpoint.
4. Otherwise, the minimum is at the intersection: t* = (B_k0 - B_k1) / (a_k1 - a_k0).

But this only works if there are exactly two active constraints at the minimum. In general, there could be more.

The robust approach is still golden section, which I'll keep. Let me just reduce the iterations to 25.

Actually, let me think about this differently. The function f(t) = max_k (B_k + t·a_k) is the pointwise maximum of linear functions. Its minimum over [0,1] can be found by:

1. If max_k (B_k) ≤ max_k (B_k + a_k), the minimum might be at 0.
2. If min_k (a_k) ≥ 0, f is non-decreasing, so min is at 0.
3. If max_k (a_k) ≤ 0, f is non-increasing, so min is at 1.
4. Otherwise, use bisection on the subgradient:
   - At t, the subgradient is the set {a_k : k is active at t}.
   - If min subgradient > 0, f is increasing at t, so the minimum is to the left.
   - If max subgradient < 0, f is decreasing at t, so the minimum is to the right.
   - Otherwise, t is a minimum (or on a flat region).

This bisection on the subgradient is O(log(1/ε)) evaluations, same as golden section but potentially faster in practice.

Let me implement this:

```python
def _min_max_linear(B, a, lo=0.0, hi=1.0, iters=30):
    """Minimize f(t) = max_i (B_i + t*a_i) over t in [lo, hi]."""
    for _ in range(iters):
        mid = (lo + hi) / 2.0
        f_mid = B + mid * a
        f_max = float(np.max(f_mid))
        active = np.where(f_mid >= f_max - 1e-12)[0]
        min_grad = float(np.min(a[active]))
        max_grad = float(np.max(a[active]))
        if min_grad > 1e-12:
            hi = mid  # f is increasing at mid, min is to the left
        elif max_grad < -1e-12:
            lo = mid  # f is decreasing at mid, min is to the right
        else:
            break  # found a minimum (or flat region)
    return (lo + hi) / 2.0
```

This is cleaner and uses fewer function evaluations. Each evaluation is just a numpy max over an array of size 2N-1, which is very fast.
