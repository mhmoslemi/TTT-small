1. Approach and rationale

1.1 Central idea

The supplied vector h is viewed as an n-sample step-function discretization over the interval [0,2] with spacing dx=2/n. The exact score used by the evaluation is

C5(h) = dx * max_r corr(h, 1-h, mode="full")[r],

where corr is the same non-circular finite-support correlation used by the evaluator. Feasibility is exactly the intersection base polygon

B = {h in [0,1]^n : sum_i h_i = n/2}.

The main new engine is a full-lag first-order trust-region SQP:

- For every lag score in the true max-of-correlations objective, build an affine Taylor model about the current feasible h.
- Solve the small convex epigraph linear program

minimize over delta, tau: tau

subject to

score_l + grad_l · delta <= tau for every lag l,

sum_i delta_i = 0,

0 <= h_i + delta_i <= 1,

|delta_i| <= rho.

Because the first model is exact to first order in every component objective, the entire collection of current and near-bottleneck lags controls the candidate step. This differs from a top-k-only linearized model or a smoothed norm model: it does not let just one or two active lags dictate a direction and then later create a previously ignored lag as the new bottleneck.

- Solve the convex model with HiGHS/scipy linear programming.
- Submit the resulting candidate step to the exact original objective by line search or by direct exact re-evaluation.
- Accept only if the exact recomputed C5 is below the current value enough numerical tolerance. This keeps each accepted step trusted while still globally moving using only exact, objective-faithful validation.

Around and above the local engine, the plan inserts global diversification: a faithful parent copy; symmetrized projects; projected noise at several scales; a bounded dimension change/resampling exploration; an exchange, simulated-annealing-like search; and a “proper stricter” region polishing the best moderate and stronger vector states.
