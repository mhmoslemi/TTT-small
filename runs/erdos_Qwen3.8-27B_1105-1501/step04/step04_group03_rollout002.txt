   - Before: contributes if h[i-d]=0 and h[i]=1. After: h[i]=0, so no contribution.
   - Change: -[h[i-d]=0] (for valid i-d)
   
   Wait, but h[i-d] might be j! If i-d = j, then before h[j]=1, so this pair didn't contribute (need h[i-d]=0). After h[j]=0, so it would contribute... but h[i] is now 0, so it still doesn't contribute (need h[a+d]=1).
   
   Hmm, I need to be more careful about interactions.

Let me just say: the change in S_d from swapping (i: 0→1, j: 1→0) is:
ΔS_d = -[h[i+d]=1 and i+d≠j] - [h[i-d]=0 and i-d≠j and h[i]=1 before] 
      + [h[j-d]=0 and j-d≠i and the new h[j]=0 makes (j,j+d) a new "0→1" pair if h[j+d]=1]
      ... 

This is getting too complicated to reason about analytically. Let me just compute the objective directly after each swap. For n=92, computing the objective is O(n) per evaluation (using FFT or direct correlation), and each swap requires O(n) work. With n=92, this is fast enough.

Actually, np.correlate is O(n²) in the worst case, but for n=92 it's very fast (maybe 10μs). So I can do millions of swap evaluations per second.

But this is O(n²) per iteration, and with n=92, that's about 2300 swaps per iteration. Each swap costs O(n²) for the correlation (n=92, 2n-1=183 lags, each requiring up to 92 products). So about 183*92 ≈ 16836 operations per evaluation. With 2300 evaluations per iteration, that's about 39 million operations per iteration. At maybe 100M ops/sec in numpy, that's about 0.4s per iteration. With 1100s budget, I can do about 2000 iterations. That should be enough to converge.

But wait, I can be smarter. Instead of trying all pairs, I can focus on the most promising swaps. The key is: which swap will reduce the maximum score the most?

The maximum score is at some lag d*. To reduce S_{d*}, I should:
- Find a pair (i, i+d*) where h[i]=0 and h[i+d*]=1, and swap them (this reduces S_{d*} by 1)
- But the swap might increase other scores

A good heuristic: prioritize swaps that reduce the maximum score without significantly increasing other scores.

Let me implement a more targeted approach:

import numpy as np
from scipy.optimize import minimize
import time

def exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def project(v, target):
    n = len(v)
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(v - mid, 0.0, 1.0))
        if s > target:
            lo = mid
        else:
            hi = mid
    x = np.clip(v - (lo + hi) / 2.0, 0.0, 1.0)
    residual = target - np.sum(x)
    if abs(residual) > 1e-10:
        if residual > 0:
            mask = x < 1.0 - 1e-10
        else:
            mask = x > 1e-10
        cnt = np.sum(mask)
        if cnt > 0:
            x[mask] += residual / cnt
    return np.clip(x, 0.0, 1.0)

def thue_morse_binary(n):
    """Thue-Morse sequence as binary, adjusted to have exactly n/2 ones."""
    tm = np.array([bin(i).count('1') % 2 for i in range(n)], dtype=float)
    ones = int(np.sum(tm))
    target = n // 2
    if ones == target:
        return tm
    if ones > target:
        idx = np.where(tm == 1)[0]
        tm[idx[:ones - target]] = 0
    else:
        idx = np.where(tm == 0)[0]
        tm[idx[:target - ones]] = 1
    return tm

def m_sequence_binary(n, seed_bit=1):

def binary_swap_search(h, deadline, rand_seed=42):
    """Local search on binary solutions using pairwise swaps."""
    n = len(h)
    rng = np.random.default_rng(rand_seed)
    h = h.copy()

    stall_count = 0

        zeros = np.where(h == 0)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break

        scores = np.correlate(h, 1.0 - h, mode='full')
        max_idx = np.argmax(scores)
        d_max = max_idx - (n - 1)

        candidate_pairs = []
        if d_max >= 0:
            for i in range(n - d_max):

                    candidate_pairs.append((i, i + d_max))
        else:
            g = -d_max
            for i in range(g, n):
                if h[i] == 0 and h[i - g] == 1:
                    candidate_pairs.append((i - g, i))
        
        # Also add some random pairs
        for _ in range(50):
            i = zeros[rng.integers(len(zeros))]
            j = ones[rng.integers(len(ones))]
            candidate_pairs.append((i, j))

            if h[i] != 0 or h[j] != 1:

            h[j] = 0.0

            if c5_try < best_c5 - 1e-14:

def continuous_refine(h, deadline):
    """Refine a solution in continuous space using gradient-based optimization."""
    n = len(h)
    target = n / 2.0
    
    # Compute gradient of the soft-max of scores
    def soft_max_grad(h, tau):
        scores = np.correlate(h, 1.0 - h, mode='full')
        dx = 2.0 / n
        max_s = np.max(scores)
        exp_s = np.exp((scores - max_s) / tau)
        Z = np.sum(exp_s)
        w = exp_s / Z
        grad = np.zeros(n)
        for r in range(2 * n - 1):
            if w[r] < 1e-15:
                continue
            d = r - (n - 1)
            if d >= 0:
                m = n - d
                grad[:m] -= w[r] * h[d:d+m]  # -h[j+d] for j in [0, m-1]
                grad[d:n] += w[r] * (1.0 - h[:m])  # (1-h[j-d]) for j in [d, n-1]
            else:
                g = -d
                m = n - g
                grad[g:n] += w[r] * (1.0 - h[:m])  # (1-h[j-g]) for j in [g, n-1]
                grad[:m] -= w[r] * h[g:n]  # -h[j+g] for j in [0, m-1]
        return dx * grad, dx * (max_s + tau * np.log(Z))
    
    h = h.copy()
    best_c5 = exact_c5(h)
    tau = 0.1
    
    for step in range(2000):
