1. Approach and rationale

The supplied duplicate program already optimizes the exact discrete objective by smooth max functions, SLSQP epigraph steps, and fractional-direction LP polishing. The central remaining bottleneck is that the exact objective is the pointwise maximum of many nonconvex bilinear terms, so ordinary smooth or projected-gradient steps can become trapped in narrow basins. A more coherent improvement is to use the exact separable structure of one side of the correlation: if the shifted/complement side is fixed, the maximum correlation becomes a purely linear function of the other arrangement. The corresponding linear program can therefore be solved exactly, with only the original box and mass constraints, and its candidate can be accepted strictly on the true task objective.

The proposed primary method is an LP-driven alternating/single-side linearization loop:

- Start with a feasible candidate h.
- Fix a “side” vector y used as the second argument estimate in the bilinear objective. The second side contribution is written as 1-y because the original term is h*(1-h). The LP varies only the first side a and minimizes the maximum linearized overlap against fixed y.
- Solve that LP with all 2*n-1 lag constraints plus sum(a)=n/2 and 0<=a<=1.
- Combine the a produced by the Lp with the current base arrangement along a line, because the exact objective along that line may be much better than either endpoint and may lie in a basin that pure LP-hard jumps miss.
- Accept the exact objective of the line-searched combination only if it decreases the exact task score. Do not use the LP value as the score.
- Repeat from the improved candidate, while also trying a small number of side-variant transformations (rotation, reversal, binary quantization, previous LP output) to escape one-sided linear fixed points.

This differs from the previous program in a substantive way. The previous LP used subgradient-style descent directions built from the current gradient; here each LP solves a strictly convex/linear feasibility-an-alternating fixed-point subproblem for the first side with exact linear constraints. This is a valid convex subproblem because it uses only one side of the bilinear product at a time. The original nonconvexity is handled solely by exact acceptance and restarts, so no unverifiable global optimality claim is made.

The second major improvement is a more diversified initialization and interlacing strategy:

- Begin from the supplied parent and also from algorithmically generated rotations/reversals of it, quantized versions of it, resampled parents on several scales, deterministic binary sequences, and a compact local binary annealing stage.
- Run the LP-bearing local polish on the best candidate first, then run a limited global scan over resolutions and randomized basin escapes.
- Add a lightweight two-coordinate line-search enforced pass to adjust mass between variables on the manifold sum=constant, because the exact objective is often sensitive to simultaneous movement of two coordinates at the max lags.
- Finish with several high-precision SLSQP and smooth-max steps from the immediate best candidate, not as replacements for LP,but as overshoot and polish steps.

The target 0.3808 is achievable only if the search escapes the parent basin by tiny amounts recovered through precise evaluation. The acceptance criterion uses exactly the evaluator form, so the returned score is always a defensible upper bound on the discrete problem.

2. Mathematical specification

Let the discrete representation be h ∈ R^n, with samples intended to approximate h on [0,2] with dx = 2/n. Feasibility is:

- 0 <= h[i] <= 1 for all i.
- sum_i h[i] = n/2.

For generic capital F_r with r in {0,...,2n-2}, matched to the full-array output of np.correlate(h, 1-h, mode='full'), define s = r-(n-1) and

F_r(h) = sum_{i} h_i * (1 - h_{i+s})

where the sum runs over all i satisfying 0 <= i < n and 0 <= i+s < n; absent pairs are omitted. The exact evaluation is

C5_exact(h) = (2/n) * max_r F_r(h).

That ignores any symmetrization or normalization other than discrete dx; positive and negative lag rows are both present in the full result. Do not replace this by circular correlation or by an autocorrelation formula that lacks the incomplete overlap counts.

L_y(a) = max_r sum_{i valid for lag r} a_i * (1 - y_{i+s}).

Constraints for the fixed-side LP:

For every r, set j = i+s where valid. Add the constraint

sum_{i valid} a_i * (1 - y_{i+s}) <= t.

The LP variables are a ∈ R^n and t ∈ R. The objective is minimize t subject to box limits, a equality sum(a)=n/2, and all lag constraints t >= row expressions above. This subproblem is exactly an LP and completely independent of the nonconvex true objective except through the acceptance step.

The true score of a generated a is still computed directly from C5_exact(a), or from a line combination, never from the LP bound t.
