1. Approach and rationale

1.1 Central idea

The supplied problem is a finite-dimensional, nonconvex minimax problem:
find h_i in [0,1] with sum_i h_i = n/2, minimizing
C(h) = max_{q=0}^{2n-2} dx * Corr_q [h_i (1-h_j)] with dx=2/n.

The parent method inverts this by solving smoothed full-constraint relaxations, descending thresholds, and polishing selected active constraints with local SLSQP. That is continuous in character despite being stored in a discrete vector. The plan below deliberately changes the dominant search geometry:

1. Optimize exactly on binary masks first. A binary h with exactly n/2 ones is always feasible and maximally avoids the lag-zero penalty h_i(1-h_i), which is the largest possible stationary penalty at zero shift. Exact pair-exchange local search over binary masks explores a completely different combinatorial neighborhood than active-set or smoothed continuous methods. It directly changes which mass elements are followed, and which mass elements follow in finite windows, which is the geometry that produces nonzero-lag overlap peaks.

2. Convert selected strong binary masks into a one-dimensional family:
   value = 1-d, all mask positions = 1,
   value = d, all mask positions = 0,
with 0 <= d <= 0.5 and exactly n/2 positions in each group. This family preserves the mean exactly and requires no post-hoc repair. One-dimensional, cheap continuous optimization over d can reveal a genuinely fractional improvement around a binary pattern that binary local search cannot see, especially for resolving intersections of competing maximum correlations. This is a representation change, not simply a hyperparameter tweak to continuous SLSQP.

3. Optimize feasible continuous vectors by exact pairwise coordinate-limit line searches in their original design. For pair (i,j), holding h_i+h_j fixed gives a feasible one-dimensional segment. The segment is then sampled and locally refined using exact objective evaluations. Because the pair sum is preserved, this leverages exact sum feasibility without special cluster algorithms and together with repeated cycles maps a nonconvex whole-vector descent comparable to previous derivative set paths.

4. Use stochastic mask chaining plus exhaustive all-swap descent to escape combinatorial basins, then use the two-level and pairwise line-search operators to continuously finish.

5. Resolution length is optional, bounded, and only compared using the exact integer-specific formula. If larger/smaller intervals give a strictly smaller exact objective, its return (and they are valuable despite insistence on shorter arrays logically comparable due the exact objective).

This plan does not solve the continuous original upper-bound problem globally. It returns a valid upper bound only if its exact vector scoring is returned. It explores exact masks, mask-edge masks, and feasible continuous orthogonal lines. It differs from the earlier strategy in: exact combinatorial minimax search, one-dimensional exact line traversals, a smoothed mask family with measurement time/refining list strictly built around consecutive length candidates, and no need for smooth max or hugging minute reconstructing bias penalties.

1.1 Central idea

The evaluator defines a step function by samples:
- length `n = len(h)`,
- `dx = 2.0 / n`,
- required mean constraint `sum(h) = n / 2`,
- `0 <= h[i] <= 1`,

This is a nonconvex minimax problem because the overlapped terms are products `h[i] * (1 - h[j])`. Earlier approaches smooth the maximum, repeatedly solve nearby active-grid minimax subproblems, project by root-clipping, and polish selected active correlations with continuous local solvers. The plan here treats the discrete objective as a configuration over feasible levels, not as an already-smooth convex hypersurface. It uses three exact-feasible operations that the previous method does not prioritize:

1. Exact binary-mask combinatorial optimization

Transposition of one `1` to one `0` gives an exact feasible new binary mask. Exhaustive all-exchange descent and randomized restarts search the combinatorial geometry of which mass cells precede which mass cells in finite shifted windows.
