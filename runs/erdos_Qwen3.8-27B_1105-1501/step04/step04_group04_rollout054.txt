def compute_lse_gradient(h, beta):
    n = len(h)
    dx = 2.0 / n
    # Compute F_d for all d
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    # Softmax weights
    max_F = np.max(corr)
    exp_F = np.exp(beta * (corr - max_F))
    w = exp_F / np.sum(exp_F)
    # Compute gradient
    g = np.zeros(n)
    L = 2 * n - 1  # number of lags
    for r in range(L):
        d = r - (n - 1)  # lag
        if abs(w[r]) < 1e-15:
            continue
        low = max(0, -d)
        high = min(n, n - d)

        g[i] += w[r] * dx * (1.0 - h[i + d])
        g[i + d] += w[r] * (-dx * h[i])
    return g, np.sum(w * corr)  # gradient and LSE value

import numpy as np

def exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def project_box_sum(v, target):
    """Project v onto {0 <= x <= 1, sum(x) = target}"""
    n = len(v)
    v = np.clip(v.copy(), 0.0, 1.0)
    for _ in range(100):
        s = np.sum(v)
        diff = target - s
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = v < 1.0 - 1e-15
        else:
            mask = v > 1e-15
        cnt = np.sum(mask)
        if cnt == 0:
            break
        v[mask] += diff / cnt
        v = np.clip(v, 0.0, 1.0)
    return v

def lse_value_and_weights(h, beta):
    """Compute LSE value and softmax weights for the correlation coefficients."""
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    max_c = np.max(corr)
    exp_c = np.exp(beta * (corr - max_c))
    w = exp_c / np.sum(exp_c)
    lse_val = max_c + np.log(np.sum(exp_c)) / beta
    return lse_val, w, corr

            break

        t_adam = 0
        lr = 0.05
        beta1, beta2, eps = 0.8, 0.999, 1e-8

            g = g - np.mean(g)  # tangential to sum constraint
            
            t += 1
            m = beta1 * m + (1 - beta1) * g
            v = beta2 * v + (1 - beta2) * g**2
            m_hat = m / (1 - beta1**t)
            v_hat = v / (1 - beta2**t)
            step = -lr * m_hat / (np.sqrt(v_hat) + eps)
            
            # Line search
            best_factor = 0.0
            for factor in [1.0, 0.7, 0.5, 0.3, 0.15, 0.05]:
                trial = project_box_sum(h + factor * step, target)
                tc5 = exact_c5(trial)
                if tc5 < cur_c5 - 1e-14:
                    best_factor = factor
                    break
            
            if best_factor > 0:
                h = project_box_sum(h + best_factor * step, target)
                cur_c5 = exact_c5(h)
                if cur_c5 < best_c5:
                    best_c5 = cur_c5
                    best_h = h.copy()
                stall = 0
            else:
                stall += 1
                lr *= 0.85
                if lr < 1e-5:
                    break
    
    return best_h, best_c5

Hmm, the pair search with random candidates is not very efficient. Let me think of a better way.

Actually, for the pair (i,j), the objective as a function of t is:
f(t) = max_k (F_k(h) + t * b_k)

where b_k is the rate of change of F_k for the transfer. Since this is the max of linear functions, it's convex in t. The minimum is where the subgradient contains 0, i.e., where the "slope" changes from negative to positive.

To find the minimum of a convex piecewise-linear function, we can:
1. Evaluate at t=0, t=t_lo, t=t_hi
2. If the minimum is interior, find the breakpoint where the slope changes sign

But computing all breakpoints is O(n) per pair. For a fast search, we can use a ternary search or golden section search on the convex function, requiring O(log(1/eps)) evaluations.

Actually, since f(t) is convex and piecewise linear, the minimum is at a breakpoint (or at the boundary). The breakpoints are where two linear functions cross: a_k + b_k * t = a_m + b_m * t, i.e., t = (a_m - a_k) / (b_k - b_m).

With up to 2n-1 linear functions, there are O(n^2) breakpoints, but only O(n) are relevant (those where the max function "changes"). We can find them by computing the upper envelope.

For a practical implementation, let me use a simple approach:
1. Compute f(t_lo), f(t_hi), f(0)
2. If f(0) is already the min, skip
3. Otherwise, do a fine grid search over [min(t_lo, 0), max(t_hi, 0)]
4. Take the best

The grid should be fine enough to resolve the breakpoints. With 2n-1 linear functions, the breakpoints are at rational points, so a grid of size O(n) should capture the minimum.

But this is O(n * cost_of_eval) per pair, and cost_of_eval is O(n) (for the correlation). So each pair takes O(n^2), and with many pairs, this could be slow.

A faster approach: compute b_k analytically (O(n) per pair), then find the minimum of max_k (a_k + b_k * t) in O(n log n) using a convex optimization (ternary search on the 1D convex function, each evaluation O(n)).
