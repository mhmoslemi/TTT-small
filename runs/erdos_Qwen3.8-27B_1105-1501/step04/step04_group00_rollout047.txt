But if k is not a multiple of the grid spacing... well, in the discrete problem, k IS a multiple of the grid spacing (since we're computing correlations on the discrete grid).

So the discrete problem is well-defined, and the value C₅ = 0.380894 is the exact value for that discrete step function. The question is whether a different discrete step function (perhaps with a different n) can achieve a lower C₅.

For the Erdős problem, the constant C₅ is the infimum over all measurable h: [0,2] → [0,1] with ∫h = 1. Any specific discretization gives an upper bound on C₅. So we want to minimize over all possible step functions (at any resolution).

The key insight: a finer discretization (larger n) can approximate the optimal continuous function more closely, but the optimization is harder. A coarser discretization (smaller n) is easier to optimize but can't approximate the optimum as well.

Given that we're at 0.380894 with n=128, and the target is 0.3808, the gap is very small (0.0001). This suggests we're very close to the optimum for n=128, and the improvement needs to come from either:
1. Better optimization at n=128 (finding a slightly better local minimum)
2. A different n that happens to give a better value
3. A fundamentally different structure

Let me focus on option 1: better optimization at n=128.

The key question is: is 0.380894 the global minimum for n=128, or is there a better local minimum we haven't found?

Given the landscape of the problem (max of many linear functions = convex function), the global minimum should be findable by convex optimization if we could do it exactly. But the LP + line search approach is a heuristic that works well in practice.

Let me try a different approach: **use scipy.optimize.minimize with the SLSQP or trust-constr method** on the smooth approximation of the objective.

The smooth approximation: instead of max_k g_k(h), use log-sum-exp:
F(h) = (1/β) log(Σ_k exp(β * g_k(h)))

As β → ∞, this approaches the max. For moderate β (say 50-200), it's smooth enough for gradient methods.

The gradient of F is:
∇F = (Σ_k exp(β*g_k) * ∇g_k) / (Σ_k exp(β*g_k))

This is a weighted average of the gradients of the individual scores, weighted by their "activity" (softmax of the scores).

This is exactly the "weighted gradient" approach from the previous code! Let me make it more effective.

Actually, let me combine approaches:
1. Use the LP method for the main optimization (it's more effective for minimax)
2. Use the weighted gradient method as a complement (it can escape local minima that the LP gets stuck in)
3. Use perturbation + re-optimization to explore different basins

import numpy as np
from scipy.optimize import linprog, minimize
import time

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _scores(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return corr * dx

def _project(v, target):
    n = len(v)
    target = float(target)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo = float(v.min()) - 2.0
    hi = float(v.max()) + 2.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-10:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _grad_matrix(h):
    n = len(h)
    dx = 2.0 / n
    G = np.zeros((2 * n - 1, n))
    for d in range(-(n - 1), n):
        r = n - 1 + d
        if d >= 0:
            m = n - d
            if m > 0:
                G[r, :m] += (1.0 - h[d:]) * dx
                G[r, d:] += -h[:m] * dx
        else:
            g = -d
            m = n - g
            if m > 0:
                G[r, :m] += (1.0 - h[g:]) * dx
                G[r, g:] += -h[:m] * dx
    return G

def _lp_direction(h, scores, G, radius, top_k):
    n = len(h)
    n_lags = len(scores)
    if top_k is not None and top_k < n_lags:
        idx = np.argsort(scores)[-top_k:]
        scores_k = scores[idx]
        G_k = G[idx]
    else:
        scores_k = scores.copy()
        G_k = G
    n_rows = len(scores_k)
    c = np.zeros(n + 1)
    c[-1] = 1.0
    A_ub = np.zeros((n_rows, n + 1))
    A_ub[:, :n] = G_k
    A_ub[:, n] = -1.0
    b_ub = -scores_k
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.zeros(1)
    bounds = []
    for j in range(n):
        lo_j = max(-radius, -h[j])
        hi_j = min(radius, 1.0 - h[j])
        if lo_j > hi_j:
            lo_j = hi_j = 0.0
        bounds.append((lo_j, hi_j))
    bounds.append((None, None))
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs')
        if res.success:
            return res.x[:n], float(res.x[-1])
    except Exception:
        pass
    return None, None

def _line_search(h, p):
    n = len(h)
    alpha_max = 0.5
    for j in range(n):
        if p[j] > 1e-14:
            alpha_max = min(alpha_max, (1.0 - h[j]) / p[j])
        elif p[j] < -1e-14:
            alpha_max = min(alpha_max, h[j] / (-p[j]))
    alpha_max = max(alpha_max, 1e-12)
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    lo = 0.0
    hi = alpha_max
    c1 = hi - gr * (hi - lo)
    c2 = lo + gr * (hi - lo)
    f1 = _exact_c5(h + c1 * p)
    f2 = _exact_c5(h + c2 * p)
    for _ in range(35):
        if hi - lo < 1e-15:
            break
        if f1 < f2:
            hi = c2
            f2 = f1
            c2 = c1
            c1 = hi - gr * (hi - lo)
            f1 = _exact_c5(h + c1 * p)
        else:
            lo = c1
            f1 = f2
            c1 = c2
            c2 = lo + gr * (hi - lo)
            f2 = _exact_c5(h + c2 * p)
    opt_a = (lo + hi) / 2.0
    opt_c5 = _exact_c5(h + opt_a * p)
    f0 = _exact_c5(h)
    if f0 < opt_c5:
        return 0.0, f0
    return opt_a, opt_c5

def _local_optimize(h, deadline, top_k_list=None, radius_init=0.08, max_iters=10000):
    if top_k_list is None:
        top_k_list = [3, 4, 5, 3, 4]
    n = len(h)
    target = n / 2.0
    radius = radius_init
    h = h.copy()
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    stall = 0
    ti = 0
    n_tk = len(top_k_list)
    for it in range(max_iters):
        if time.time() > deadline:
            break
        if stall > 80:
            break
        if radius < 5e-9:
            break
        tk = top_k_list[ti % n_tk]
        scores = _scores(h)
        G = _grad_matrix(h)
        p, t_val = _lp_direction(h, scores, G, radius, top_k=tk)
        if p is None or float(np.max(np.abs(p))) < 1e-14:
            stall += 1
            radius *= 0.5
            ti += 1
            if radius < 5e-9:
                break
            continue
        alpha, new_c5 = _line_search(h, p)
        if new_c5 < cur_c5 - 1e-13:
            h = h + alpha * p
            h = np.clip(h, 0.0, 1.0)
            h = _project(h, target)
            cur_c5 = _exact_c5(h)
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            stall = 0
            radius = min(radius * 1.08, 0.25)
        else:
            stall += 1
            radius *= 0.55
            ti += 1
            if stall > 20 and radius < 0.01:
                radius = 0.04
    return best_h, best_c5

def _weighted_grad(h, deadline, beta_start=20, beta_end=200, n_steps=500):
    """Smoothed subgradient method"""
    n = len(h)
    target = n / 2.0
    h = h.copy()
    best_h = h.copy()
    best_c5 = _exact_c5(h)
    cur_c5 = best_c5
    for step in range(n_steps):
        if time.time() > deadline:
            break
        frac = step / max(1, n_steps - 1)
        beta = beta_start + (beta_end - beta_start) * frac
        scores = _scores(h)
        s_max = np.max(scores)
        # Softmax weights
        w = np.exp(beta * (scores - s_max))
        sw = np.sum(w)
        if sw < 1e-300:
            idx = int(np.argmax(scores))
            w = np.zeros(len(scores))
            w[idx] = 1.0
        else:
            w /= sw
        G = _grad_matrix(h)
        grad = G.T @ w
        grad -= grad.mean()  # Project onto sum=0 subspace
        gn = np.linalg.norm(grad)
        if gn < 1e-15:
            break
        grad /= gn
        # Backtracking line search
        alpha = 0.05
        for _ in range(40):
            h_new = _project(h - alpha * grad, target)
            c5_new = _exact_c5(h_new)
            if c5_new < cur_c5 - 1e-14:
                h = h_new
                cur_c5 = c5_new
                if cur_c5 < best_c5:
                    best_c5 = c5_new
                    best_h = h.copy()
                break
            alpha *= 0.65
            if alpha < 1e-12:
                break
    return best_h, best_c5

def _resample(h, n_new):
    n = len(h)
    if n_new == n:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(n_new) + 0.5) / n_new
    h_new = np.interp(x_new, x_old, h)
    return _project(h_new, n_new / 2.0)

def _quasi_periodic_init(n, alpha):
    x = np.arange(n) / n
    h = ((x * alpha) % 1.0) < 0.5
    h = h.astype(float)
    return _project(h, n / 2.0)

def _binary_sa(n, deadline, rng, n_iters=25000):
    target = n // 2
    h = np.zeros(n)
    positions = rng.permutation(n)
    h[positions[:target]] = 1.0
    cur_c5 = _exact_c5(h)
    best_h = h.copy()
    best_c5 = cur_c5
    T = 0.025
    T_min = 0.0002
    cool = (T_min / T) ** (1.0 / max(n_iters, 1))
    ones = np.where(h == 1.0)[0]
    zeros = np.where(h == 0.0)[0]
    for it in range(n_iters):
        if time.time() > deadline:
            break
        i = ones[rng.integers(len(ones))]
        j = zeros[rng.integers(len(zeros))]
        h[i] = 0.0
        h[j] = 1.0
        new_c5 = _exact_c5(h)
        if new_c5 < cur_c5 or rng.random() < np.exp((cur_c5 - new_c5) / T):
            cur_c5 = new_c5
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = h.copy()
            ones = np.where(h == 1.0)[0]
            zeros = np.where(h == 0.0)[0]
        else:
            h[i] = 1.0
            h[j] = 0.0
        T *= cool
    return best_h, best_c5

def _pair_polish(h, deadline, max_passes=4):
    n = len(h)
    h = h.copy()
    best_h = h.copy()
    best_c5 = _exact_c5(h)
    for _pass in range(max_passes):
        if time.time() > deadline:
            break
        improved = False
        step = max(1, n // 40)
        for j in range(0, n, step):
            if time.time() > deadline:
                break
            if h[j] < 1e-8 or h[j] > 1.0 - 1e-8:
                continue
            for k in range(j + step, min(j + 5 * step, n), step):
                if h[k] < 1e-8 or h[k] > 1.0 - 1e-8:
                    continue
                for sign in [1, -1]:
                    if sign > 0:
                        a_max = min(1.0 - h[j], h[k])
                    else:
                        a_max = min(h[j], 1.0 - h[k])
                    if a_max < 1e-10:
                        continue
                    lo_a, hi_a = 0.0, a_max
                    for _ in range(7):
                        m1 = lo_a + (hi_a - lo_a) / 3.0
                        m2 = hi_a - (hi_a - lo_a) / 3.0
                        h1 = h.copy()
                        h1[j] += sign * m1
                        h1[k] -= sign * m1
                        f1 = _exact_c5(h1)
                        h2 = h.copy()
                        h2[j] += sign * m2
                        h2[k] -= sign * m2
                        f2 = _exact_c5(h2)
                        if f1 < f2:
                            hi_a = m2
                        else:
                            lo_a = m1
                    a_opt = (lo_a + hi_a) / 2.0
                    h_try = h.copy()
                    h_try[j] += sign * a_opt
                    h_try[k] -= sign * a_opt
                    h_try = np.clip(h_try, 0.0, 1.0)
                    c5_try = _exact_c5(h_try)
                    if c5_try < best_c5 - 1e-14:
                        best_c5 = c5_try
                        best_h = h_try.copy()
                        h = h_try.copy()
                        improved = True
        if not improved:
            break
    return best_h, best_c5
