     = c[r] + (t - h[i]) * alpha_d + (t' - h[j]) * beta_d where t' = s-t
     = c[r] + delta_i * alpha_d + delta_j * beta_d
     where delta_i = t - h[i], delta_j = (s-t) - h[j] = t' - h[j] = -delta_i (since delta_i + delta_j = (t + s - t) - (h[i]+h[j]) = s - s = 0)
     
     So delta_j = -delta_i!
     
     c_new[r] = c[r] + (t - h[i]) * (alpha_d - beta_d)
     
   So I just need the difference vector: diff[d] = alpha_d - beta_d for each shift d.
   
   alpha_d = (1-h[i-d])*1_{0≤i-d<n} - h[i+d]*1_{0≤i+d<n}
   beta_d = (1-h[j-d])*1_{0≤j-d<n} - h[j+d]*1_{0≤j+d<n}
   
   diff[d] = alpha_d - beta_d
   
   And c_new[r] = c[r] + (t-h[i]) * diff[d] where d = r-(n-1)
   
   The objective is max_r c_new[r] * dx = max_r (c[r] + (t-h[i])*diff[d(r)]) * dx
   
   Let u = t - h[i], so u ∈ [t_lo - h[i], t_hi - h[i]]
   Objective: max_r (c[r] + u * diff[r]) * dx (where diff is indexed by r)
   
   This is the max of (2n-1) linear functions of u, and we want to minimize it.

So the algorithm for each pair update:
1. Compute diff[r] for all r (O(n) work)
2. Find u* = argmin_{u in [u_lo, u_hi]} max_r (c[r] + u * diff[r])
3. Set h[i] += u*, h[j] -= u*

Step 2 is the 1D piecewise-linear convex minimization. Here's an efficient algorithm:
- The function f(u) = max_r (c[r] + u * diff[r]) is convex and piecewise linear
- f'(u) (subgradient) = [min{diff[r] : r active}, max{diff[r] : r active}] where active means c[r]+u*diff[r] = f(u)
- f is minimized where 0 is in the subgradient

Simple approach:
- If all diff[r] ≥ 0, f is non-decreasing, so u* = u_lo
- If all diff[r] ≤ 0, f is non-increasing, so u* = u_hi
- Otherwise, the minimum is at an intersection point of two lines

Fast method (O(n) for n=2n-1 lines):
1. Find the range of u where each line is on the upper envelope
2. The minimum is at the leftmost point where the envelope's slope changes from negative to positive

Even simpler for practical purposes:
1. Compute f at u_lo and u_hi
2. If f(u_lo) ≤ f(u_hi) and the slope at u_lo ≥ 0: u* = u_lo
3. Otherwise, do a binary search / bisection on the "kink" point

Actually, the simplest correct approach that's fast enough:
- Since we have at most 2n-1 = 223 lines (for n=112), we can afford to:
  1. Sort the lines by their slope (diff[r])
  2. Walk through them maintaining the upper envelope
  3. Find where the slope of the envelope crosses 0

But for simplicity, let me just use a few evaluation points:
- Evaluate at u_lo, u_hi, and a few points in between
- The minimum is at one of the "kinks" which are intersection points of pairs of lines
- For a practical approach: use the fact that the minimizer must be at a point where two lines cross (or at a boundary)
- We can find the candidate kink points by: for each pair of lines with different slopes, their intersection is at u = (c[r2]-c[r1])/(diff[r1]-diff[r2])
- But that's O(n²) candidates...

Let me just use a practical approach: 
- Do a coarse grid (say 30 points) to find the approximate location
- Then refine with the active-set method

Or even simpler: since this is 1D convex, just use scipy's minimize_scalar or a manual bisection on the derivative.

For the derivative approach:
- At a given u, the subdifferential is [min_active_slope, max_active_slope]
- If min_active_slope > 0, we need to decrease u
- If max_active_slope < 0, we need to increase u
- Otherwise, we've found the minimum

To compute the active set at u: find all r with c[r] + u*diff[r] ≥ f(u) - ε

This is O(n) per evaluation. With 30 bisection steps, that's O(30n) per pair update. For n=112 pairs per sweep, that's about 30*112*112 ≈ 380000 operations per sweep. Very fast.

```python
import numpy as np
from scipy.optimize import linprog
import time

def _exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _project(v, target):
    n = len(v)
    if target <= 0:
        return np.zeros(n)
    if target >= n:
        return np.ones(n)
    lo, hi = float(v.min()) - 2.0, float(v.max()) + 2.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        s = float(np.sum(np.clip(v - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    x = np.clip(v - theta, 0.0, 1.0)
    res = target - float(np.sum(x))
    if abs(res) > 1e-13:
        if res > 0:
            mask = x < 1.0
        else:
            mask = x > 0.0
        cnt = int(np.sum(mask))
        if cnt > 0:
            x[mask] += res / cnt
            x = np.clip(x, 0.0, 1.0)
    return x

def _pl_minimize_1d(c_frozen, diff, u_lo, u_hi):
    """Minimize max_r (c_frozen[r] + u * diff[r]) over u in [u_lo, u_hi].
    Returns optimal u."""
    n_lines = len(c_frozen)
    if u_hi - u_lo < 1e-14:
        return u_lo
    
    # Check if all slopes have same sign
    if np.all(diff >= -1e-15):
        return u_lo
    if np.all(diff <= 1e-15):
        return u_hi
    
    # Bisection on subgradient
    a, b = u_lo, u_hi
    for _ in range(50):
        if b - a < 1e-12:
            break
        mid = (a + b) / 2.0
        vals = c_frozen + mid * diff
        f_val = float(np.max(vals))
        # Active set: lines within tolerance of max
        active = vals >= f_val - 1e-10
        min_slope = float(np.min(diff[active]))
        max_slope = float(np.max(diff[active]))
        if min_slope > 1e-10:
            # f is increasing at mid, go left
            b = mid
        elif max_slope < -1e-10:
            # f is decreasing at mid, go right
            a = mid
        else:
            # 0 is in subdifferential
            break
    return (a + b) / 2.0

def _paired_cd(h, deadline, n_sweeps=50000, seed=42):
    """Paired coordinate descent maintaining sum constraint."""
    n = len(h)
    dx = 2.0 / n
    h = h.copy()
    cur_f = _exact_c5(h)
    best_h = h.copy()
    best_f = cur_f
    stall = 0
    rng = np.random.default_rng(seed)
    
    # Precompute shift indices
    # For shift d (r = n-1+d), h[i] appears in:
    # alpha_d = (1-h[i-d])*1_{0<=i-d<n} - h[i+d]*1_{0<=i+d<n}
    
    for sweep in range(n_sweeps):
        if time.time() > deadline:
            break
        if stall > 200:
            break
        
        # Update correlation
        c_frozen = np.correlate(h, 1.0 - h, mode='full')
        
        sweep_improved = False
        # Random permutation of pair indices
        pairs = rng.permutation(n // 2)
        
        for pi in pairs:
            i = 2 * pi
            j = min(i + 1, n - 1)
            if i == j:
                continue
            s = h[i] + h[j]
            if s <= 1e-14 or s >= 2.0 - 1e-14:
                continue
            u_lo = max(0.0, s - 1.0) - h[i]
            u_hi = min(1.0, s) - h[i]
            if u_hi - u_lo < 1e-14:
                continue
            
            # Compute diff[r] = alpha_d(i) - beta_d(j) for r = n-1+d, d from -(n-1) to n-1
            diff = np.zeros(2 * n - 1)
            for d in range(-(n - 1), n):
                r = n - 1 + d
                # alpha_d for index i
                a_i = 0.0
                if 0 <= i - d < n:
                    a_i += (1.0 - h[i - d])
                if 0 <= i + d < n:
                    a_i -= h[i + d]
                # beta_d for index j
                b_j = 0.0
                if 0 <= j - d < n:
                    b_j += (1.0 - h[j - d])
                if 0 <= j + d < n:
                    b_j -= h[j + d]
                diff[r] = a_i - b_j
            
            u_opt = _pl_minimize_1d(c_frozen, diff, u_lo, u_hi)
            if abs(u_opt) > 1e-14:
                h[i] += u_opt
                h[j] -= u_opt
                h[i] = np.clip(h[i], 0.0, 1.0)
                h[j] = np.clip(h[j], 0.0, 1.0)
                sweep_improved = True
        
        if sweep_improved:
            # Recompute and check improvement
            new_f = _exact_c5(h)
            if new_f < best_f - 1e-12:
                best_f = new_f
                best_h = h.copy()
            cur_f = new_f
            stall = 0
        else:
            stall += 1
    
    return best_h, best_f
```

```python
def _compute_alpha(h, i):
    n = len(h)
    alpha = np.zeros(2 * n - 1)
    # d ranges from -(n-1) to n-1, index = d + (n-1)
    # (1-h[i-d]) for d where 0 ≤ i-d < n, i.e., i-n+1 ≤ d ≤ i
    d_start = max(-(n-1), i - (n-1))  # = i - n + 1

        alpha[d + n - 1] += (1.0 - h[i - d])

    d_end2 = min(n-1, n - 1 - i)
    for d in range(d_start2, d_end2 + 1):
        alpha[d + n - 1] -= h[i + d]
    return alpha
```

The upper envelope of lines {c[r] + u*diff[r]} changes slope only at intersection points. The minimum of the envelope is at the point where the slope changes from negative to positive.

For a faster exact method:
1. Find the line that achieves the max at u_lo → call it r1
2. Find the line that achieves the max at u_hi → call it r2
3. If r1 == r2 and diff[r1] < 0: minimum is at u_hi
   If r1 == r2 and diff[r1] > 0: minimum is at u_lo
4. Otherwise, the minimum is at the intersection of the "last" line with negative slope and the "first" line with positive slope on the envelope.

This is getting complicated. Let me just use the bisection approach which is simple and correct.

```python
    """Compute alpha vector for coordinate i: alpha[r] = d(c[r])/d(h[i])."""
    n = len(h)
    size = 2 * n - 1
    alpha = np.zeros(size)
    
    # Part 1: (1-h[i-d]) for d where 0 <= i-d < n
    # alpha[i + n - 1 - k] += (1-h[k]) for k = 0, ..., n-1
    # i.e., alpha[i : i+n] in reverse order gets (1-h)
    s1 = max(0, i)
    e1 = min(size, i + n)
    if e1 > s1:

    # alpha[n-1-i+k] += -h[k] for k = 0, ..., n-1

        return u_lo

    neg_mask = diff < -1e-15

        if min_sl >= -1e-12:
            b = mid
        elif max_sl <= 1e-12:

        else:

        c_base = np.correlate(h, 1.0 - h, mode='full')
        sweep_changed = 0
        perm = rng.permutation(n_pairs)
        
        for pi in perm:
            i = 2 * pi
            j = i + 1
            if j >= n:
                continue
            s_val = h[i] + h[j]
            if s_val < 1e-12 or s_val > 2.0 - 1e-12:
                continue
            u_lo = max(0.0, s_val - 1.0) - h[i]
            u_hi = min(1.0, s_val) - h[i]
            if u_hi - u_lo < 1e-14:
                continue
            
            diff = alphas[i] - alphas[j]
            u_opt = _pl_minimize(c_base, diff, u_lo, u_hi)
            
            if abs(u_opt) > 1e-13:
                h[i] += u_opt
                h[j] -= u_opt
                # Clip (shouldn't be needed but safety)
                h[i] = np.clip(h[i], 0.0, 1.0)
                h[j] = np.clip(h[j], 0.0, 1.0)
                sweep_changed += 1
                # Update alphas for i and j (they changed)
                # Actually, we should update all alphas since h changed
                # But that's expensive. Let's just recompute at end of sweep.
        
        if sweep_changed > 0:
            # Recompute alphas
            alphas = np.array([_compute_alpha(h, i) for i in range(n)])
            new_f = _exact_c5(h)
            if new_f < best_f - 1e-12:
                best_f = new_f
                best_h = h.copy()
            stall = 0
        else:
            stall += 1
    
    return best_h, best_f
```

Wait, there's an issue. When I update h[i] and h[j], the alphas for ALL coordinates change (because they depend on h). But I'm using stale alphas for subsequent pairs in the same sweep. This is like a Gauss-Seidel vs Jacobi issue.

In Gauss-Seidel style, I'd recompute alpha for i and j after each update, and use the updated values for subsequent pairs. But alpha for coordinate k depends on h at positions k±d for all d, so changing h[i] affects alpha[k] for all k. This makes it impractical to maintain exact alphas in a Gauss-Seidel fashion.

Alternative: use the stale alphas (Jacobi-style within a sweep) and recompute at the end. This should still converge, just maybe slower.

Actually, there's a subtlety: when I use stale alphas, the linearization is slightly wrong. The function max(c_base + u*diff) with stale c_base and diff might not be a valid upper/lower bound on the true function. But in practice, for small updates, it should be close enough.

Let me instead recompute c_base and alphas periodically (every few pairs) to keep them fresh.

Actually, let me reconsider. The issue is:
- c_base = corr(h) changes when we update h
- diff = alpha[i] - alpha[j] also changes

If I recompute c_base after every pair update, that's O(n) (correlation is O(n) for the whole thing... actually np.correlate is O(n²) or O(n log n) depending on implementation). For n=112, it's fast.

And recomputing alphas is O(n²) total (n coordinates, each O(n)). For n=112, that's about 12500 operations.

So the cost per pair update is:
- c_base: O(n²) ≈ 12500 (or O(n log n) with FFT)
- diff for this pair: O(n)
- 1D minimization: O(n * 40) ≈ 4500
- Update alphas: O(n²) ≈ 12500

Total per pair: about 30000 operations. For n/2 = 56 pairs per sweep: 1.7M per sweep. In 1100 seconds, if each sweep takes about 0.05s (rough estimate for Python with numpy), we can do about 22000 sweeps.

But the 1M operations estimate might be off. Let me think about it more carefully.

Actually, np.correlate for n=112 is very fast (probably < 10μs). The alpha computation is the bottleneck since it involves Python loops.

Let me vectorize the alpha computation more aggressively. Instead of computing alpha for each i separately, I can compute all alphas at once:

alpha[i][r] = (1-h[i-d])*1_{0≤i-d<n} - h[i+d]*1_{0≤i+d<n} where d = r-(n-1)

This is essentially a convolution/correlation of (1-h) and -h with the index structure.

Actually, alpha[i] is:
- The first part is a reverse correlation of (1-h) with a delta at position i
- The second part is a forward correlation of h with a delta at position i

Let me think of it as:
alpha[i] = (1-h) ⊛ e_i (reverse) + (-h) ⊛ e_i (forward)

Where ⊛ denotes the appropriate correlation.

Actually, I think the simplest efficient approach is:
- alpha[i] for all i simultaneously can be computed as a matrix
- alpha_matrix[i, r] = d(c[r])/d(h[i])

This matrix has a specific structure (it's related to the incidence matrix of the shift operators).

For now, let me just precompute all alphas and recompute them after each sweep. Within a sweep, I'll use potentially stale alphas but update c_base periodically.

Actually, you know what, let me just go with a simpler but effective approach:

1. Use the LP-based local search from the previous code (which was the most effective component)
2. Add the paired coordinate descent as an additional method
3. Try more n values
4. Use better perturbation strategies

def _exact_c5(h):
    n = len(h)

    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _project(v, target):

    lo, hi = float(v.min()) - 2.0, float(v.max()) + 2.0

            x = np.clip(x, 0.0, 1.0)

def _grad_matrix(h):
    n = len(h)
    G = np.zeros((2 * n - 1, n))
    for d in range(-(n - 1), n):
        r = n - 1 + d
        if d >= 0:
            m = n - d
            if m > 0:
                G[r, d:] += (1.0 - h[:m])
                G[r, :m] += -h[d:]
        else:
            g = -d
            m = n - g
            if m > 0:
                G[r, :m] += (1.0 - h[g:])
                G[r, g:] += -h[:m]
    return G
