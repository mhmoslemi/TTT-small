So, for each delta, the sum is the dot product of h[0:m] and (1 - h[delta:m + delta]).

But how to compute this for all deltas efficiently?

This seems challenging. However, for small n_points, it's manageable. For example, with n_points=47, it's 47^2 = 2209 operations, which is acceptable for the time budget.

But during optimization, the objective function is called many times. For example, with 5000 iterations, each with O(n^2) operations, this could be 5000 * 2209 = around 11 million operations, which is manageable in Python for 100 seconds.

So, perhaps this is acceptable.

Another optimization: precompute the 1 - h array once, and reuse it.

In the objective function, we can compute 1 - h once, then for each delta, compute the sum of h[x] * (1 - h[x + delta]).

So, modifying the objective function:

def objective(h):
    n_points = len(h)
    dx = 2.0 / n_points
    one_minus_h = 1.0 - h
    max_integral = 0.0
    for delta in range(n_points):
        m = n_points - delta
        if m <= 0:
            continue
        # x ranges from 0 to m-1
        # x + delta ranges from delta to delta + m - 1 = delta + (n_points - delta) - 1 = n_points - 1
        # So, the slice for h is h[0:m], and for one_minus_h is one_minus_h[delta:delta + m]
        sum_val = np.dot(h[0:m], one_minus_h[delta:delta + m])
        integral = sum_val * dx
        if integral > max_integral:
            max_integral = integral
    return max_integral

This uses numpy's dot product, which is faster than a Python for loop. This would significantly speed up the computation.

def generate_structured_initial(n_points, num_pulses):
