def smooth_gradient_descent(h0, n, deadline):
    target = n / 2.0
    dx = 2.0 / n
    best_h = h0.copy()
    best_c5 = evaluate_c5(h0)
    
    # Adaptive tau schedule
    tau = initial_tau
    h_curr = h0.copy()
    
    while time < deadline:
        # Compute objective and gradient
        c = correlate(h_curr, 1-h_curr) * dx
        m = c.max()
        weights = softmax((c - m) / tau)
        
        # Gradient (vectorized)
        grad = compute_grad(weights, h_curr, dx)
        
        # Step size (backtracking or fixed)
        alpha = step_size / (norm(grad) + eps)
        
        # Step + project
        h_new = project_feasible(h_curr - alpha * grad, target)
        
        # Check improvement
        c5_new = evaluate_c5(h_new)
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new
            h_curr = h_new
        else:
            # Reduce step size / tau
            alpha *= 0.5
            tau *= 0.9
        
        # Reduce tau periodically
        tau *= 0.95
        if tau < min_tau:
            tau = min_tau
    
    return best_h, best_c5
```

def efficient_gradient(h, w, dx):
    n = len(h)
    corr1 = np.correlate(1.0 - h, w, 'full')
    corr2 = np.correlate(w, h, 'full')
    idx = slice(2*n-2, n-2, -1)
    term1 = corr1[idx]
    term2 = corr2[idx]
    return dx * (term1 - term2)
```

**Coordinate descent idea**: For each coordinate j, find the optimal value of h[j] (given all other h's fixed) that minimizes the max. This is a 1D optimization problem for each coordinate.

For a fixed j, c_k as a function of h[j] is:
c_k = (terms not involving h[j]) + h[j] * (contributions involving h[j])

The contributions of h[j] to c_k:
- From h[j+d_k] * (1-h[j]): if j = i + d_k for some i, then h[j] * (1-h[i])
- From h[i] * (1-h[i+d_k]): if i = j, then h[j] * (1-h[j+d_k])... wait, (1-h[i]) where i+d_k = j, i.e., i = j-d_k.

Let me be more careful. c_k = sum_i h[i+d_k] * (1-h[i]).

h[j] appears in:
1. h[i+d_k] = h[j] when i+d_k = j, i.e., i = j-d_k. Contribution: (1-h[j-d_k]) * h[j] (if j-d_k is valid)
2. (1-h[i]) = (1-h[j]) when i = j. Contribution: h[j+d_k] * (1-h[j]) (if j+d_k is valid)

So ∂c_k/∂h[j] = (1-h[j-d_k])_valid - h[j+d_k]_valid

And c_k as a function of h[j] is linear! (Given all other h's fixed.)

Wait, that's interesting. c_k is linear in h[j] (for fixed other h's). So the max over k is a piecewise-linear function of h[j], and we can find its minimum in [0,1] by checking the breakpoints.

The breakpoints occur where two c_k values are equal, i.e., where c_k1(h[j]) = c_k2(h[j]). Since each c_k is linear in h[j], the intersection points are easy to compute.

So for each coordinate j:
1. Compute the current c values (with h[j] at its current value)
2. For each pair of active k's, find the h[j] value where they're equal
3. Check the max at each candidate point (current value, 0, 1, and all intersection points)
4. Choose the h[j] that minimizes the max
