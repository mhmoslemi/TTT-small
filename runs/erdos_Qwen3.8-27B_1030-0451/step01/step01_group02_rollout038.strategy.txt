1. Approach and rationale

1.1 Central idea: exact lag-shift pair moves plus antipodal global regeneration  
Instead of relying mainly on general nonlinear solvers or global LP-style linearizations around the full high-dimensional vector, the new search centers on exact displacements that are immediately scored with the original evaluator. The essential primitive is a pair displacement that preserves the mass constraint exactly and its exact effect on every sampled lag. For any current feasible vector h and any sparse sum-zero displacement d, the corrected overlap vector can be updated in O(n) time without recomputing the full correlation. Candidate displacements are accepted only when the exact max overlap improves (or, in annealing, when the annealed criterion accepts it). This is materially different from the previous parent polish, which frequently generated directions with active-set LP/SLSQP and then spent time on expensive global linearizations whose exact feasibility and improvement were not always local or stable.

1.2 Antipodal state space for diversity and stricter feasibility  
The interval/objective has a symmetry: if h(x) is replaced on the discretized grid by its reflected complement 1 - h(2 - x), the complete lag-overlap vector is just relavered or invariant up to reflection, but the max is the same. Many high-quality balanced overlaps admit an approximately antipodal representative of the form:

    h_i = x_i,  h_{n-1-i} = 1 - x_i,    i=0,...,floor(n/2)-1

For even n this exactly enforces both 0 ≤ h_i ≤ 1 and sum(h)=n/2 once x_i is in [0,1]. This gives a reduced, always feasible state space with n/2 variables and no awkward sum-repair inside local steps. It is not claimed to include the global optimum; as a heuristic it is highly useful because it gives many balanced starts on a smaller manifold and makes exact simulation/refinement faster and more robust.

1.3 What exactly is being optimized  
The program optimizes the canonical discrete evaluation exactly:

    C(h) = max_k (2.0 / n_points) * np.correlate(h, 1.0 - h, mode="full")[k]

No circular correlation or boundary-blind autocorrelation surrogate is used for final acceptance. The internal O(n) update formulas are an algebraic implementation of this exact lag relation. Whenever there is a discrepancy between internal vector updates and the authoritative evaluator, the internal representation is discarded or recompiled from the authoritative evaluator and that candidate/path is ignored for descent unless the authoritative score is better than the stored best.

1.4 Why it can improve 0.381086 toward 0.3808  
The previous parent is near a high-dimensional many-lag equalization point. Gains of a few 10^-4 are often only obtainable by testing many highly constrained, locally balanced changes. The new method has three complementary advantages:

- Exact local moves on lags: direction moves use the exact quadratic lag relation, so denominator line decisions use real discrete values rather than surrogate-only evaluations.
- Antipodal forced symmetry: it generates diverse balanced sequences and reduces the effective dimension, allowing far more global starts within the same budget.
- Stochastic full vector + binary simulated annealing: pair swaps directly explore the discrete metric because exact incremental updates cost O(n) per move, and realistic small changes in the active set can be found by annealing rather than by continuous descent.

The proposed pipeline keeps the supplied parent as a valid fallback. No optimality or global bound is claimed. The lower returned value is valid only because it is verified directly via the evaluator.

2. Mathematical specification

2.1 Discrete state and constraints  
Let n = n_points, dx = 2.0 / n. A candidate is h = array of length n. Constraints are:

- 0 ≤ h[i] ≤ 1, all i
- sum(h) * dx = 1, equivalently sum(h) = target, target = n / 2.

For returned candidates the program must use even n whenever possible (target is then an integer, and binary states are possible). Odd n candidates are allowed only if they are feasible and the authoritative score is strict pure for objective comparison; the final fallback is always even n.

2.2 Authored objective orientation  
Define internally an unscaled lag vector A(k), k = -(n-1),...,n-1, with k linked to full correlation vector position k + (n - 1):

    A(k) = dx * sum_{i,j in [0,n-1], i-j=k} h[i] * (1 - h[j])

This equals np.correlate(h, 1-h,"full") * dx up to possible reversal. The program enforces equality internally by direct comparison at initialization and at calibrations. In implementation, A is a real array indexed by python 0..2n-2, but true logical k is idx - (n-1). The exact score is:

    C(h) = max(A(k))

2.3 Exact affine-quadratic lag update for displacement d  
Suppose current state A is exact for current h. Let a displacement vector d satisfy sum(d)=0. For x(t)=h + t*d, the lag vector is exactly:

    A_t(k) = A_0(k) + t * dx * D_d(k) + t^2 * dx * Q_d(k)

    D_d(k) = sum_i d[i] * (1 - h[i - k]) - sum_i d[i] * h[i + k]
    Q_d(k) = - sum_i d[i] * d[i - k]

Derivation: substituting h + t d into h_i(1 - h_j), expanding, and using i - j = k yields these exact formulas. Verification should be emergency-calibrating: if the chosen linkage of k with np.correlate gives mismatch larger than tolerance, reverse the lag order.
