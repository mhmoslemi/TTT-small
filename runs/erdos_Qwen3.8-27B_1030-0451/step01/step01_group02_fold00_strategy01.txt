1. Approach and rationale

1.1 Central idea  
The implementation will not mainly use general SLSQP/LP/SQP polish. Its central algorithm is a multi-lag active-constraint least-squared Newton-like step for the exact discrete max-overlap objective. At every local state it:

1. computes the exact finite-support correlation values for all lags;
2. selects the currently relevant high-overlap subset of lags, normally the top lag constraints plus all lags within a small band of the maximum;
3. forms first-order linearized change equality/inequality rows for those active lags;
4. solves a very small linear least-norm problem for a displacement in h that, to first order, lowers the active linearized overlap levels while preserving the mass constraint exactly;
5. tests constructed points by the authoritative exact discrete objective and repairs feasibility exactly before acceptance;
6. repeats using an adaptive active set, active band, and step scale.

This differs from earlier proposals that either solve one LPที่ทำแทน or run low-level nonlinear projective smooth log-sum-exp SLSQP-style solver. Here the update handles several strong lag constraints simultaneously through an equalizing linear-system step, and the resulting direction is always checked using the original objective.

1.2 Diversity from compressed bounded-function representatives  
The local active-constraint solver is capable only near a starting construction. To prevent dependence on one discrete basin, the program generates multiple starting vectors in a compact bounded-sum space:

- Fourier/mean-zero tangent modes using logistic reparameterization, giving exact box constraints and an exact mass constraint through a one-dimensional monotone shift root. This prevents large clipping penalties and gives smooth low-dimensional candidates.
- Transportive resampling of the supplied parent construction across several resolutions, with exact feasibility repair and direct exact C₅ comparison.
- Optional midpoint projection of the parent vector onto the same small Fourier/logistic manifold, producing a smoothed low-dimensional candidate that can later be relaxed by the high-dimensional active-lag solver.
- Occasional binary exchange candidates using gradient/subgradient information and exact move tests. The output remains a valid feasible h vector whenever the exchange improves the exact objective.

The final result returned is always the best exact C₅ objective found over all such candidates, including the carried parent if it remains best. A single method is not assumed globally optimal.

1.3 What need not remain unstated  
- No global optimality claim for h is made. The program is a multi-start nonconvex heuristic.
- The used KKT-like least-norm step is not a globally valid convex optimization of the original problem. It solves a linearized active-subproblem and tests it with the original quadratic/bilinear objective.
- Exact C₅ is always computed only with the authoritative finite-support linear-correlation formula over all lags. If the internal formula were ever wrong, exact re-evaluation prevents an invalid acceptance.
- Feasibility is exact in operations: either by the logistic reparameterization or by a feasible-set projection/waterfilling adjustment, followed by an explicit recheck and final re-evaluation of C₅ on the repaired vector.

2. Mathematical specification

2.1 Discrete representation and exact objective  
A candidate is a vector h ∈ R^n with

0 ≤ h_i ≤ 1, i=0,...,n-1,
∑_{i=0}^{n-1} h_i = n/2.

The evaluator's dx is

dx = 2 / n.

The exact objective is

C₅(h) = max_{q=-(n-1),...,n-1} dx · ∑ h_{i+q} (1-h_i)
where sums are taken only over valid overlapping indices. The program must also validate this against

max(np.correlate(h, 1.0 - h, mode="full") * dx).

The output vector must satisfy bounds and sum exactly up to floating tolerance, and the final bound must be recomputed with the exact finite-support correlation formula.

2.2 Lag/list calibration  
The internal gradient implementation will be aligned with `np.correlate`, not arranged blindly. Use standard lags

k = 0,...,2n-2,
central lag c = n-1,
lag offset d = ±(k-c).

The program calibrates the sign. For a random feasible vector (for example average 0.5 plus noise followed by feasibility repair), compute

C_eval = np.correlate(h, 1.0-h, "full") * dx.

For transform_dir = 1 and -1, calculate an aligned copy C_form_vec with

d = transform_dir * (k - (n-1)).

If errors are within tolerance, store the valid `corr_dir` once and reuse it. Use `corr_dir` in all gradient-row formulas. The input sequence maximum is invariant to reversed orientation; the gradient alignment still needs validation.

2.3 Correlation values for one lag offset  
For offset d ∈ {-(n-1),...,n-1}, define exact value using normalized dx:

If d = 0:
C_0 = dx · ∑_{i=0}^{n-1} h_i(1-h_i).

If d > 0:
C_d = dx · ∑_{i=0}^{n-d-1} h_{i+d} (1-h_i).

If d < 0, let s = -d:
C_d = dx · ∑_{i=0}^{n-s-1} h_i (1-h_{i+s}).

This defines a pullback value accessible through the calibrated k-to-d map.

2.4 Exact gradient of one lag constraint  
Let G_d denote grad_h C_d.

If d = 0:
G_d,j = dx · (1 - 2 h_j).

If d > 0, L = n-d:
- For j ∈ [0, L-1], G_d[j] += -dx · h_{j+d}       (h_j is the (1-h_i) factor)
- For j ∈ [d, n-1], G_d[j] += dx · (1 - h_{j-d})   (j=i+d is the h_{i+d} factor)

If d < 0, s=-d, L = n-s:
- For j ∈ [0, L-1], G_d[j] += dx · (1 - h_{j+s})        (j=i factor)
- For j ∈ [s, n-1], G_d[j] += -dx · h_{j-s}             (h_{i+s} second factor)

Create each active gradient row under calibrated mapping. Use only exact h values, never discrete linear-correct minus false optimum assumptions. A safe sanity check is to compare a finite-difference derivative coefficient for a small random persistent row, worthwhile only in exact testing style, not part of main production.
