```python
    lo, hi = -5.0, 5.0
    
    for outer in range(20):
        if time_check is not None and time_check() < 10.0:
            break
        
        mid = 0.5 * (lo + hi)
        lam = mid
        
        h_inner = h.copy()
        c_inner = np.correlate(h_inner, 1.0 - h_inner, mode='full')
        
        for p in range(max_passes):
            if time_check is not None and time_check() < 10.0:
                break
            max_delta = 0.0
            for i in range(n):
                hi_val = h_inner[i]
                slopes = compute_slopes(h_inner, i)
                
                deltas = grid - hi_val
                c_try = c_inner[None, :] + deltas[:, None] * slopes[None, :]
                c_try[:, n-1] = c_inner[n-1] + deltas * (1.0 - 2.0 * hi_val) - deltas**2
                objs = np.max(c_try, axis=1) + lam * grid  # add lambda * t
                best_j = int(np.argmin(objs))
                best_t = grid[best_j]
                
                delta = best_t - hi_val
                if abs(delta) > 1e-14:
                    c_inner += delta * slopes
                    c_inner[n-1] += delta * (1.0 - 2.0 * hi_val) - delta * delta
                    h_inner[i] = best_t
                    max_delta = max(max_delta, abs(delta))
            
            if max_delta < 1e-13:
                break
        
        err = h_inner.sum() - target
        if err > 0:
            lo = mid  # need to decrease sum, so increase lambda
        else:
            hi = mid  # need to increase sum, so decrease lambda
        
        # Track best feasible solution
        h_proj = project_to_sum(h_inner, target)
        val = evaluate_exact(h_proj)
        if val < best_val:
            best_val = val
            h = h_proj.copy()
    
    return h, best_val
```

The correlation c[m] = sum_{i' in valid range} h[i'+k] * (1-h[i']) where k = m-(n-1).

When I change h[i] from h[i] to t = h[i] + delta:

The change in c[m] comes from terms where h[i] appears:
1. h[i] = h[i'+k] when i' = i-k. The term is h[i]*（1-h[i-k]).
   Change: (h[i]+delta)*(1-h[i-k]) - h[i]*(1-h[i-k]) = delta*(1-h[i-k])
   Valid condition: i' = i-k must be in the valid range [a, b] = [max(0,-k), min(n-1, n-1-k)]
   AND 0 ≤ i-k ≤ n-1 (for h[i-k] to be defined)

For condition 2, I need both max(0,-k) ≤ i ≤ min(n-1,n-1-k) AND 0 ≤ i+k ≤ n-1.
The first condition already implies 0 ≤ i ≤ n-1. The second condition (0 ≤ i+k ≤ n-1) is additional.
