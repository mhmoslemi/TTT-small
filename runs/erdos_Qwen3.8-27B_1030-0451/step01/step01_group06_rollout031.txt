Fix h_-j = (h_0, ..., h_{j-1}, h_{j+1}, ..., h_{n-1}).
For each lag k (output index r = 0..2n-2, lag = r-(n-1)):
Q_r = c_r + d_r * h_j

where c_r and d_r depend on h_-j.

Then we want: min_{x ∈ [0,1]} max_r (c_r + d_r * x)

This is a 1D problem. The function f(x) = max_r (c_r + d_r * x) is convex piecewise-linear in x. Its minimum is at:
- x = 0, or
- x = 1, or
- a point where two lines intersect and the maximum changes

To find the optimal x, we can:
1. Evaluate f(0) and f(1)
2. Find all intersection points of pairs of lines within [0,1]
3. Check f at each intersection point
4. Take the minimum

But there are O(n²) intersection points, which for n=120 and 239 lags is O(239²) ≈ 57000 per coordinate. That might be too slow for a full sweep.

A faster approach: since f(x) = max_r (c_r + d_r * x), we can find the minimum by:
- The minimum of a convex PL function on [0,1] is where the subgradient contains 0, or at a boundary.
- The subgradient at x is [min_r d_r, max_r d_r] (for the active set... actually it's the convex hull of {d_r : r in active set}).

A simpler approach: binary search on the value. For a given value v, check if min_{x ∈ [0,1]} max_r (c_r + d_r*x) ≤ v. This is equivalent to: exists x ∈ [0,1] such that c_r + d_r*x ≤ v for all r. This is a system of linear inequalities in x:
- If d_r > 0: x ≤ (v - c_r) / d_r
- If d_r < 0: x ≥ (v - c_r) / d_r
- If d_r = 0: need c_r ≤ v

So the feasible set for x is an interval [max of lower bounds, min of upper bounds] intersected with [0,1]. We can binary search on v to find the minimum.

But this is O(log(1/eps)) * O(n) per coordinate, and O(n) coordinates per sweep. Total: O(n² * log(1/eps)) per sweep. For n=120, that's about 120*120*30 ≈ 432,000 operations per sweep. Very fast!

```python
def golden_section_1d(f, a, b, tol=1e-10, max_iter=100):
    phi = (1 - np.sqrt(5)) / 2  # ≈ -0.618
    c = b + phi * (b - a)  # = a + (1-phi)*(b-a)
    d = a - phi * (b - a)  # = a + phi*(b-a) + (b-a) = ... 
    # Actually: c = a + (1-phi)*(b-a), d = a + phi*(b-a) + ... 
    # Standard golden section:
    # c = b - (b-a)/phi, d = a + (b-a)/phi  where phi = (1+sqrt(5))/2 ≈ 1.618
    # Or: c = a + (b-a)*(3-sqrt(5))/2, d = a + (b-a)*(sqrt(5)-1)/2
    
    gr = (np.sqrt(5) - 1) / 2  # ≈ 0.618
    c = a + (1 - gr) * (b - a)
    d = a + gr * (b - a)
    fc = f(c)
    fd = f(d)
    for _ in range(max_iter):
        if b - a < tol:
            break
        if fc < fd:
            b = d
            d = c
            fd = fc
            c = a + (1 - gr) * (b - a)
            fc = f(c)
        else:
            a = c
            c = d
            fc = fd
            d = a + gr * (b - a)
            fd = f(d)
    return 0.5 * (a + b)
```

import time

def evaluate_exact(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    return float(np.max(corr))

def project_feasible(x, target_sum):
    # Bisection on lambda for clip(x - lambda, 0, 1)
    x = np.asarray(x, dtype=np.float64).copy()
    n = len(x)
    if n == 0: return x
    lo = float(np.min(x)) - 2.0
    hi = float(np.max(x)) + 2.0
    for _ in range(80):
        mid = 0.5*(lo+hi)
        s = np.sum(np.clip(x-mid, 0, 1))
        if s > target_sum: lo = mid
        else: hi = mid
    lam = 0.5*(lo+hi)
    h = np.clip(x-lam, 0, 1)
    # Fix residual
    res = h.sum() - target_sum
    for _ in range(10):
        if abs(res) < 1e-13: break
        if res > 0:
            order = np.argsort(h)[::-1]
            for idx in order:
                dec = min(res, h[idx])
                h[idx] -= dec; res -= dec
                if res <= 0: break
        else:
            order = np.argsort(h)
            for idx in order:
                inc = min(-res, 1-h[idx])
                h[idx] += inc; res += inc
                if res >= 0: break
    return h

def coord_descent(h, max_sweeps=100, deadline=None):
    """Coordinate descent with exact 1D minimization per coordinate."""
    n = len(h)
    m = 2*n - 1
    dx = 2.0/n
    h = h.copy()
    corr = np.correlate(h, 1-h, mode='full') * dx
    best_c5 = float(np.max(corr))
    
    gr = (np.sqrt(5) - 1) / 2.0
    
    for sweep in range(max_sweeps):
        if deadline and time.time() > deadline:
            break
        improved = False
        for j in range(n):
            # Compute gradient coefficients d_r
            d = np.zeros(m)
            for r in range(m):
                lag = r - (n-1)
                c = 0.0
                if 0 <= j-lag < n:
                    c += 1.0 - h[j-lag]
                if 0 <= j+lag < n:
                    c -= h[j+lag]
                d[r] = dx * c
            
            hj = h[j]
            # Golden section search
            a, b = 0.0, 1.0
            c_pt = a + (1-gr)*(b-a)
            d_pt = a + gr*(b-a)
            # Evaluate f at c_pt and d_pt
            fc = _f_eval(corr, d, hj, dx, n, c_pt)
            fd = _f_eval(corr, d, hj, dx, n, d_pt)
            for _ in range(50):
                if b - a < 1e-10: break
                if fc < fd:
                    b = d_pt; d_pt = c_pt; fd = fc
                    c_pt = a + (1-gr)*(b-a); fc = _f_eval(corr, d, hj, dx, n, c_pt)
                else:
                    a = c_pt; c_pt = d_pt; fc = fd

            x_opt = 0.5*(a+b)
