1. Approach and rationale

The objective is the finite-support overlap maximum
\[
J(h)=\max_{r=0,\ldots,2N-2} dx\;\mathrm{corr}_r(h,1-h),\qquad dx=2/N,
\]
with the feasible set defined by coordinate bounds and one affine equality. The supplied parent was optimized by a homotopy log-sum-exp smoothing plus SLSQP. This is a reasonable local method, but it has two important limiting effects:

- it optimizes a smoothed surrogate and relies on SLSQP steps that are not directly tied to the exact active constraints; very small necessary improvements can be lost when the smoothing temperature, equality tolerance, or step trust region are mismatched;
- the search is effectively a single descending trajectory with some perturbation, so it can spend most of the budget around one local attraction basin.

The proposed primary algorithm is a strictly exact-objective random/active constrained line-search method built around zero-sum direction moves in the box-simplex. Each proposed move is evaluated not in an abstract local model but on the real one-dimensional restriction
\[
\delta\mapsto J(h+\delta a),\qquad \sum_i a_i=0,
\]
using the same covariance relation as the true evaluator. Since \(h+\delta a\) preserves the sum exactly while bounds are enforced by an explicit interval for \(\delta\), every accepted candidate is valid and strictly improves the exact objective.

The steps are chosen primarily by:

- top active constraint subgradients (translated into network/Frank-Wolfe-style pairwise directions \(a=e_i-e_j\));
- smooth gradient directions \(-G+\mbox{mean}(G)\) lifted to zero-sum;
- randomized directions for escaping local minima;
- nonmonotone “exploring point” restarts, while the globally stored candidate is always the best exact value seen.

This differs from the previous algorithm by directly minimizing the exact maximum along entire feasible intervals, preserving constraints implicitly, and using the true active constraints to choose normalized mass-transfer directions. The algorithm is local and nonconvex: it is not claimed globally optimal, but each accept rule is based on the authoritative evaluation rule. The parent value is retained as a fallback.

2. Mathematical specification

Let \(N\) be the number of samples and \(dx=2/N\). Define
\[
b=1-h,\quad c_r(h)=dx\,\mathrm{np.correlate}(h,b,\text{mode="full"})[r],\quad r=0,\dots,2N-2,
\]
and
\[
J(h)=\max_r c_r(h).
\]
The feasible constraints are:
\[
0\le h_i\le 1,\qquad \sum_i h_i=N/2.
\]

For the line-search, choose a direction vector \(a\in\mathbb R^N\) with zero sum. This can be enforced exactly by replacing \(a\leftarrow a-\mathrm{mean}(a)\) after any construction. Set
\[
h(\delta)=h+\delta a,
\]
so that \(\sum_i h_i(\delta)=\sum_i h_i\) for every \(\delta\). Expand the correlation using bilinearity:
\[
\begin{aligned}
c_r(\delta)
&=dx\,\mathrm{corr}_r(h(\delta),1-h(\delta))\\
&=dx\big(
\mathrm{corr}_r(h,b)
+\delta(\mathrm{corr}_r(a,b)-\mathrm{corr}_r(h,a))
-\delta^2\mathrm{corr}_r(a,a)
\big),
\end{aligned}
\]
where \(b=1-h\). Define arrays of coefficients indexed by the full correlation index \(r\):
\[
A_r=c_r(0),\qquad L_r=dx(\mathrm{corr}_r(a,b)-\mathrm{corr}_r(h,a)),\qquad Q_r=-dx\,\mathrm{corr}_r(a,a).
\]
Then the exact objective along the line is
\[
F(\delta)=\max_r (A_r+\delta L_r+\delta^2 Q_r).
\]
The value formula must match the evaluation convention: always use the \(r=0,\dots,2N-2\) full correlation output and multiply only once by \(dx\).

The bound interval for \(\delta\) comes from
\[
0\le h_i+\delta a_i\le1.
\]
For each \(i\):
