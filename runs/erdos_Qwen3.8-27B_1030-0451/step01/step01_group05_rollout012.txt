def compute_grad(h, w, n):
    grad = np.zeros(n)
    center = n - 1
    for K in range(2*n-1):
        wk = w[K]
        if wk < 1e-15:
            continue
        s = K - center
        if s >= 0:
            # First factor: i in [0, n-1-s], partner i+s
            grad[:n-s] += wk * (1.0 - h[s:])
            # Second factor: i in [s, n-1], partner i-s
            grad[s:] -= wk * h[:n-s]

            # First factor: i in [m, n-1], partner i-s = i+m
            grad[m:] += wk * (1.0 - h[:n-m])
            # Second factor: i in [0, n-1-m], partner i-s = i+m

For the continuous case, if h is a characteristic function of a set A⊂[0,2] with |A|=1, then ∫h(x)(1-h(x+k))dx = |A \ (A-k)| (the measure of points in A that are not in A shifted by k). We want to minimize max_k |A \ (A-k)|.

This is related to the "difference set" or "sumset" problems in additive combinatorics. The minimum possible value is related to the structure of A.

For a union of intervals, the optimal structure is known in some cases. For example, if A is a single interval of length 1, then A \ (A-k) has measure min(|k|, 1) for |k|≤1 and 0 for |k|>1 (within the domain). So the maximum is 1.

If A is two intervals of length 0.5 each, placed optimally, we might do better. The key is to make A \ (A-k) small for all k simultaneously.

In the discrete case with h∈[0,1] (not just {0,1}), fractional values might help smooth out the corners.
