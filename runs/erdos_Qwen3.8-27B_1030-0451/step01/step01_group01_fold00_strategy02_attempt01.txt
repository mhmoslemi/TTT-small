1. Approach and rationale

1.1 Central idea

Treat the task as an exact-goal multistart nonconvex extraction problem rather than as a single local descent attempt on a smooth heuristic objective. The proposed master algorithm does three things that are different from the previous LP-trust-region / LSE-SLSQP / projected-gradient pipeline:

(1) It repeatedly solves a “target-violation” auxiliary problem. (2) It performs exact one-dimensional pairwise line search using the exact correlation objective, not a surrogate. A pairwise line move preserves the sum-constraint exactly, so the acceptance test can reject or accept with the actual evaluator. This exact 1D move is a generic nonconvex local exploration mechanism, and efficient because the correlation trajectory along a pairwise move can be represented by one vector expression.

(3) It maintains a small population of valid candidates and drives multi-resolution search. The search may move to finer or coarser gridded representations; every transferred candidate is restored to feasibility before its objective is computed. The method explicitly avoids claiming a global optimum. The nonconvexity is not obviously tractable for a global proof at this size and budget. The aim is a better feasible candidate, accepted only when the `np.correlate`-based metric has decreased.
