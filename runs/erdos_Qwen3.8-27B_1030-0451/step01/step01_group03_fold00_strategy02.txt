1. Approach and rationale

Central idea

The parent construction is already within a narrow tolerance of the target, so the remaining task is not a broad global search but a high-precision nonconvex refinement problem. The prior approach primarily used a smoothed log-sum-exp surrogate over all correlation lags and a constrained smooth optimizer. That has three limitations:

1. The smoothed surrogate often accepts a candidate only for reducing averaged liability, while exact `max` improvements can be blocked by the surrogate’s soft tail.
2. The optimizer moves in a full gradient projection direction that can be too diffuse and may stall near many active lags.
3. The method is not strongly based on exact finite-lag candidate acceptance; it often descends through surrogate accuracy rather than through verified exact objective reductions.

The proposed primary algorithm is an exact-checked, feasible-pair, active-let descent (PAD). Instead of optimizing a globally smoothed function, every proposal is constrained to satisfy the exact mass constraint, and every trial update is a finite feasible inter-coordinate transfer:

`h[source] += delta`, `h[sink] -= delta`, with bounds enforcing `0 <= h <= 1`.

The direction is selected by weighting only the currently relevant finite-lag correlations using a dynamic active set. Pair transfers are usually good for local overlap tuning because they preserve `sum(h)=n/2` directly. After each proposal, the true objective

`C5(h) = max_l np.correlate(h, 1-h, 'full')[l] * dx`

is recomputed exactly. Candidates are accepted either when they reduce exact `C5`, or in temporary escape mode with capped degradation before another exact descent continuation. The parent is retained as a hard fallback. If no verified improvement is found, the parent is returned exactly.

Why this could improve the parent

- Exact acceptance prevents stagnation due purely to surrogate mismatch.
- Pair transfers are small, local, and maintain the equality constraint without imposing a full projection that distorts active gradient directions.
- Dynamic active weights can oscillate among near-max lags rather than minimizing a smoothed mean over many irrelevant lags.
- The method can be run from many exactly feasible structural starting points, unlike a pure parent-initialized local descent.
- Multi-resolution transfer may find better constructions if the current parent resolution contains hidden jitter.

Limitations

This is still a heuristic local/nonconvex search. It does not claim global optimality. It may stall, and improvements are not guaranteed if the supplied parent is already near an isolated local optimum. The plan defines all fallbacks and exact containment conditions so that, at minimum, an exact feasible already-known solution is returned.

Different from prior plans

The prior and earlier generated plans primarily use full-dimensional smooth-SLSQP schedules, random makeovers, soft scoring, or simulated annealing. Here the primary primitive is a linearly locally exact active-gradient pair-transfer search on the raw objective, combined with deterministic feasible rank-direction transform transformations and resolution stages. Any smoothing-like weighting is restricted to choose a direction; every candidate is accepted only after exact objective evaluation. So the mathematical metric, candidate geometry, and acceptance estimates differ.

2. Mathematical specification

Representation and exact metric

For returned vector `h` of length `n_points = n`, define `dx = 2.0 / n`. The returned vector itself is the discrete node sample for the step construction; the same constants are used by the official evaluator.

Exact raw correlation vector:

`cv(l) = np.correlate(h, 1-h, mode='full')[l] * dx`, for `l=0,...,2n-2`.

Exact objective to minimize:

`C5(h) = max_l cv(l)`.

Do not replace it by circular correlation or autocorrelation. Do not try to conceives interference lower-bound or an equivalent transition-autocorrelation formula unless proved for this exact finite-support transform.

Feasibility

`h[i]` must satisfy:

- `h[i] >= 0`
- `h[i] <= 1`
- `sum(h) = n/2`

For odd `n`, `n/2` is fractional and remains the valid sum target. Continuous values make this generally feasible.

Gradient of one lag

For a lag `l`, let shift `d = l - (n - 1)`. When optimizing the combination:

`Q_l(h) = sum_i h_i * (1 - h_j)`

held by this discrete correlation convention, the gradient contributions are computed using exact index bounds. One correct relation, using `om = 1 - h`:

For each cross term over `l`, add and subtract contributions corresponding to finite correlation overlap:

- Let `lo1 = max(0, d)`, `hi1 = min(n-1, n-1+d)`.
- For valid `i=lo1..hi1`, add to `grad[i]` the normalized weight times `om[i-d]`, using derivative from first term; subtract from `grad[i-d]` the same factor times `h[i]`? Equivalently use the exact implementation formula below.

The gradient helper must behave consistently with NumPy `np.correlate` ordering. To avoid orientation ambiguity, the first version includes a self-check described in section 6.

For a subset of lags `A`, normalized weights `w_l`, surrogate aggregate objective:

`U(h) = sum_{l in A} w_l cv_l(h)`

The finite-difference-style implementation for a selected lag:

```
d = l - (n-1)
lo1 = max(0, d)
hi1 = min(n-1, n-1+d)
if lo1 <= hi1:
    grad[lo1:hi1+1] += weight * om[lo1-d : hi1+1-d]
lo2 = max(0, -d)
hi2 = min(n-1, n-1-d)
if lo2 <= hi2:
    grad[lo2:hi2+1] -= weight * h[lo2+d : hi2+1+d]
```

The scaling with `dx` is recommended so it matches raw objective; since pair selection uses sign comparisons, global scale is harmless, but use same convention.

Pair-move feasibility

A step moving coordinate `source` and `sink`:

```
h[source] += delta
h[sink]   -= delta
```

preserves sum exactly. Valid interval:

`delta_min = 0`

`delta_max = min(1 - h[source], h[sink])`

Repeated delta computations should avoid storing otherwise extremely fractionable.

Active surrogate direction for pair descent

Given active weights `w_l`, compute aggregate gradient `grad_aggregate`. For pair moves, comparisons hold even with finite precision but determine descent sign.

For increase source `s`, decrease sink `k`, directional derivative estimate is:

`derivative = grad_aggregate[s] - grad_aggregate[k]`

This transfer tends to lower `U` if derivative is negative. For a pair transfer:

 migliore source-candidate `source`: smaller aggregate gradient

sink: larger aggregate gradient

bound interval: `delta_max = min(1-h[source], h[sink])`

The aggregate derivative on that line is `delta * (grad[source] - grad[sink])`. If positive or small less than tol, candidate is largely non-descent under the model.

Feasible exact-valued repair after transforms

Transformations can destroy integral. A joint feasibility repair should be supplied. A deterministic monotone water-fill algorithm can do it.

Given arbitrary finite vector `y` with entries clipped to finite range and target `T=n/2`:

1. A scalar function:

`F(shift) = sum(clip(y + shift, 0, 1))`

is monotone nondecreasing continuous piecewise.

2. Since `F(-large) roughly 0` and `F(large) roughly n`, solve `F(shift) = T` by bisection using 90 or more bisections. This makes integral nearly correct.

3. Remaining numerical residual `R=T - y_clipped.sum()` is repaired by transferring residual equally over components satisfying interior `1e-10 < value < 1-1e-10` where possible:

`clip_vals = clip(y + shift,0,1)`

If `R !=0`, add `R/c_interior` to each interior variable. If residual pushes into bounds, then do this in small sub-rectangle intervals until the target is reached or residual is within `1e-9`. If no interior component exists, the root shift lies in a saturated flat region. Check whether target is integer and representable by saturated sums: use proportional clipping from floor/ceil target basis: for integer target, accept as feasible; for non-integer target, apply a localized quantile correction: move `a` nonzero variables by equal amounts until exact. In implementation, if the repair signature reports impossible or abs(sum-target)>tiny, discard the corresponding candidate.

Exact arithmetic can produce a sum that remains 1e-13 away; that is valid for returned arrays. No candidate should be hard-quad clipped to bounds followed by relaxation; clip and shift transforms cannot enforce both constraints unless combined/waterfilled in one step.

1. Approach and rationale

Central idea

The parent construction has already been locally tuned by smoothed gradient optimization and is close to the target, so the remaining work should not assume one broad continuous surrogate can pull it into an adjacent basin. The principal proposed algorithm is an exact-checked active-let feasible-pair descent (PAD). It builds candidate directions from the actual, non-smooth objective

`C5(h) = max_l np.correlate(h, 1-h, mode='full')[l] * dx`

but, instead of minimizing a global smooth surrogate with a constrained nonlinear solver, it generates only feasible pairwise coordinate transfers that preserve the integral constraint exactly:

`h[source] += delta`, `h[sink] -= delta`, with `0 <= h <= 1` maintained by the chosen bound. The candidate direction is selected using an active weighted gradient derived from only the currently most restrictive lag indices. Every candidate is then evaluated by the true discrete objective. Exact improvements are accepted; occasional capped-degradation random pair moves are used only to escape a local plateau and are always guarded by storing the independent global best.

This approach differs materially from the provided previous program and from the earlier proposed strategies. The prior program mainly uses a log-sum-exp surrogate and SLSQP moves in the full-dimensional feasible set; the earlier generated proposals add broad simulated annealing and general pair-transfer ideas, but they remain coupled with surrogate or graph-based smoothing loops and found inconsistent routes. Here the primary high-value mechanism is:

1. deterministic/seeded selection of candidate pair moves using the true finite-lag objective’s active constraints;
2. exact immediate feasibility by pair transfers, not by a final matrix-project each move after arbitrary transforms;
3. exact-objective line-search acceptance of tiny or moderate feasible deltas;
4. compound multi-start construction from the parent by compact, algorithmic transforms (rank transpositions, edge-transfer patterns, interpolation resolutions), then PAD polishing both in same and selected higher/lower resolution;
5. ultimate protected return of the supplied exact parent when nothing valid improves it.

The hypothesis is that the current parent is near a local vertex of a reciprocal local minimum region. A pair-transfer search follows a grid of exactly feasible relations that more effectively hops across near-tied active constraints than projected gradient or smooth surrogate, because the objective only cares about the finite maximum constraints and the pair mechanism directly moves mass between coordinates while avoiding gross mass-project grade render differing. This is a heuristic local/neighbor tuning strategy, not a global proof. Previous methods frequently can pass a slightly greater surrogate event and coarse viewport.
