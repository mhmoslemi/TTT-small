def minimize_single_lag(h, d, dx, target, max_iter=50):
    """Minimize C_d while maintaining constraints."""
    n = len(h)
    h = h.copy()
    for _ in range(max_iter):
        g = grad_lag(h, d, dx)
        g -= np.mean(g)  # project to feasibility direction
        gnorm = np.linalg.norm(g)
        if gnorm < 1e-14: break
        
        # Line search
        best_lam = 0
        best_c = C_d(h, d, dx)
        for lam in [1.0, 0.5, 0.25, 0.125, 0.0625, 0.03125]:
            h2 = np.clip(h - lam * g / gnorm, 0, 1)
            h2 = make_feasible(h2, target)
            c2 = C_d(h2, d, dx)
            if c2 < best_c:
                best_c = c2; best_lam = lam
        if best_lam == 0: break
        h = h - best_lam * g / gnorm
        h = np.clip(h, 0, 1)
        h = make_feasible(h, target)
    return h

The problem min_h max_k C_k(h) can be written as:

The C_k(h) are convex in h (since C_k = linear - quadratic, and the quadratic part is -h^T A h which is... wait, is it convex?)

The term -sum h[i]*h[i+d] is NOT convex (it's the negative of a product). So the overall problem is non-convex.

However, if we fix one variable and optimize the other, it becomes linear. This suggests alternating minimization could work.

Actually, for a fixed lag d:

If we fix all h except h[j], then C_d as a function of h[j] is:
- If j appears in the first sum (j >= d): contributes dx * h[j]
- If j appears in the second sum (j < n-d as h[j] or j >= d as h[j+d]): contributes -dx * h[j] * h[j±d]

Wait: C_d = dx * sum_i h[i+d]*(1-h[i])

If I fix all h except h[j]:

- h[j] appears in the term h[j+d]*(1-h[j]) if j < n-d (as h[i] with i=j)

= dx * h[j] * (1-h[j-d] - h[j+d]) + dx * h[j+d]  [constant part]

This is LINEAR in h[j]! The coefficient of h[j] is dx*(1-h[j-d]-h[j+d]).

This is a crucial insight! For any single lag, the objective is linear in any single coordinate. This means we can do exact coordinate minimization in O(1) per coordinate (just check if the coefficient is positive or negative and set h[j] to 0 or 1 accordingly).

Even better: we can do **exact coordinate minimization**. For each coordinate j, given all other coordinates fixed, the objective max_k C_k as a function of h[j] is the max of linear functions, hence convex. We can find the exact minimizer by checking where the derivatives cross zero.

Let me formalize:
For coordinate j, define f_j(t) = max_k C_k(h with h[j] replaced by t) for t ∈ [0,1].
This is the max of linear functions, so it's a piecewise linear convex function.
The minimum is at a "kink" (where two or more C_k achieve the max simultaneously) or at a boundary.

To find the minimum exactly:
1. Compute all C_k values at the current h[j]
2. For each k, compute the slope of C_k with respect to h[j] (call it s_k)
3. The function f_j(t) = max_k (a_k + s_k * t) where a_k = C_k - s_k * h[j] (the intercept)
4. Find t* that minimizes max_k (a_k + s_k * t) over t ∈ [0,1]

This is a 1D convex piecewise linear optimization! We can solve it exactly by:
- The slopes s_k determine the shape
- The minimum is where the "upper envelope" of the lines has a minimum
- Equivalently, find t where the subgradient contains 0

The subgradient of f_j at t is the set of convex combinations of slopes s_k for those k achieving the max. We want 0 to be in the subgradient, which means we need some with positive slope and some with negative slope (or all zero).

   - Actually, just do a ternary search or bisection on the subgradient

```python
def coord_descent(h, C, deadline, max_sweeps=5000):
    n = len(h)
    target = n / 2.0
    dx = 2.0 / n
    ctr = n - 1
    h = h.copy()
    C = C.copy()
    
    for sweep in range(max_sweeps):
        if time.time() > deadline - 5: break
        improved = False
        for j in range(n):
            # Compute slopes s_k for coordinate j
            s = np.zeros(2*n-1)  # slopes of C_k wrt h[j]
            # For d > 0: s for lag d in C
            # h[j] appears in C_d if:
            #   j >= d (as h[j] = h[i+d] with i=j-d): slope = dx*(1-h[j-d]) if 0<=j-d<n-d
            #   j < n-d (as h[j] in (1-h[j]) = 1-h[i] with i=j): slope = -dx*h[j+d] if 0<=j+d<n
            
            for d in range(1, n):
                # h[j] as h[i+d] with i = j-d
                if d <= j <= n-1 and j-d < n-d:
                    k = ctr + d  # position in correlation array
                    s[k] += dx * (1.0 - h[j-d])
                # h[j] as h[i] with i = j, in (1-h[j])
                if 0 <= j <= n-d-1:
                    k = ctr + d
                    s[k] -= dx * h[j+d]
                
                # Also for lag -d: h[j] appears
                # C_{-d} = dx * sum_i h[i]*(1-h[i+d])
                # h[j] as h[i] with i=j: slope = dx*(1-h[j+d]) if j < n-d
                # h[j] as h[i+d] with i=j-d: slope = -dx*h[j-d] if d <= j < n
                
                if 0 <= j < n-d:
                    k2 = ctr - d
                    s[k2] += dx * (1.0 - h[j+d])
                if d <= j < n:
                    k2 = ctr - d
                    s[k2] -= dx * h[j-d]
            
            # h[j] in C_0: slope = dx*(1-2*h[j])
            s[ctr] = dx * (1.0 - 2.0 * h[j])
            
            # Now find t that minimizes max_k (C[k] + s[k]*(t - h[j]))
            # = min_t max_k (C[k] - s[k]*h[j] + s[k]*t)
            # Binary/ternary search
            old_val = h[j]
            # Ternary search on [0, 1]
            lo, hi = 0.0, 1.0
            for _ in range(25):  # enough for precision
                m1 = lo + (hi - lo) / 3
                m2 = hi - (hi - lo) / 3
                f1 = np.max(C + s * (m1 - old_val))
                f2 = np.max(C + s * (m2 - old_val))
                if f1 < f2:
                    hi = m2
                else:
                    lo = m1
            t_star = (lo + hi) / 2
            
            if abs(t_star - old_val) > 1e-10:
                change = t_star - old_val
                C += s * change
                h[j] = t_star
                improved = True
        
        if not improved:
            break
    
    return h, np.max(C)
```
