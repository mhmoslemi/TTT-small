    Given h, index i, and current correlation C (scaled),
    find the optimal t = h[i] that minimizes max_k C_k(t).

    C_{n-1}(t) = C_{n-1} + (t - t²) - (h[i] - h[i]²)
    where s_k = (1 - h[i+d_k]) - (h[i-d_k]) [with 0 for out of bounds]

    dx = 2.0 / n

    shifts = np.arange(2*n - 1) - ci  # shifts[k] = k - (n-1)
    
    # Compute slope array

    valid_m = (i - shifts >= 0) & (i - shifts < n)
    
    h_p = np.zeros(2*n - 1)
    h_m = np.zeros(2*n - 1)
    if np.any(valid_p):

    if np.any(valid_m):

        vals = C + (t - hi_val) * slope
        vals[ci] = C[ci] + (t - t*t) - (hi_val - hi_val*hi_val)
