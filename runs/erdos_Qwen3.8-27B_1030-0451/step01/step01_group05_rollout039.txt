For lag k with shift s = k - center:
J[k, a] - J[k, b] = (contribution of position a) - (contribution of position b)

The contribution of position i to J[k, i] is:
- If i is in the "m" position (i.e., m=i is valid): (1 - h[i-s])
- If i is in the "m-s" position (i.e., m-s=i, so m=i+s is valid): -h[i+s]

So J[k, i] = (1-h[i-s]) * I(i valid as m) + (-h[i+s]) * I(i+s valid as m)

where "i valid as m" means max(0,s) ≤ i ≤ min(n-1, n-1+s)
and "i+s valid as m" means max(0,s) ≤ i+s ≤ min(n-1, n-1+s)

For the difference J[k,a] - J[k,b]:
= [(1-h[a-s]) * I_a - h[a+s] * I'_a] - [(1-h[b-s]) * I_b - h[b+s] * I'_b]

where I_a = 1 if a is valid as m for this lag, I'_a = 1 if a+s is valid as m, etc.

This can be computed in O(L) time for a given pair (a,b), which is fast.

def pair_gradient_diff(h, a, b):
    """Compute J[:, a] - J[:, b] for the given h"""
    n = len(h)
    L = 2 * n - 1
    center = n - 1
    diff = np.zeros(L)
    for s in range(-(n-1), n):
        k = s + n - 1
        m_lo = max(0, s)
        m_hi = min(n - 1, n - 1 + s)
        # Contribution of a
        contrib_a = 0.0
        if m_lo <= a <= m_hi:
            contrib_a += (1.0 - h[a - s])
        if m_lo <= a + s <= m_hi:
            contrib_a += (-h[a + s])
        # Contribution of b
        contrib_b = 0.0
        if m_lo <= b <= m_hi:
            contrib_b += (1.0 - h[b - s])
        if m_lo <= b + s <= m_hi:
            contrib_b += (-h[b + s])
