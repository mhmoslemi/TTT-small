1. Approach and rationale

1.1 Central idea

The discrete objective

C(h) = max_k dx · sum_i h[a_t^(k)] · (1 - h[b_t^(k)]),  dx = 2 / n,

is the maximum of many overlapping box-constrained affine/quadratic terms. The supplied parent construction was mostly improved by explicit LP/SQP-style local subproblems. The new method instead treats the problem as a feasibility-preserving smooth minimax reduction:

- Use a hidden one-dimensional translation of an unconstrained logit/potential vector to enforce the volume constraint exactly at every function evaluation.
- Smooth the maximum with a log-sum-exp surrogate whose weights emphasize the currently large lag-overlap terms and suppress irrelevant constraints.
- Take full-dimensional quasi-Newton steps in the potential/logit space using L-BFGS-B. The search variable is always mapped back to a feasible h before the authoritative objective is checked.
- Use low-dimensional Fourier/logit basis configurations to produce genuinely different starting basins, especially when the parent maps every local controller into the same local valley.
- Finish low-resolution and high-resolution candidates with exact objective revaluation and a small exact coordinate-transfer pass. The final acceptance criterion is always the original non-smooth-max metric using `np.correlate`, never a surrogate, relaxation, circular approximation, or convex objective.

This is substantively different from the preceding parent program because it avoids LP linearization/cache drift as the primary mechanism and instead uses a reparameterization guaranteeing feasibility plus a log-sum-exp smooth minimax trajectory over the original shifted-lag terms. It is still nonconvex and should not be claimed globally optimal.

1.2 Why this addresses the bottleneck

The true minimax surface has many active lags and tight flat directions. A linearization of the maximum can move into a direction that improves several currently active terms only infinitesimally, while clipping/sum repair can destroy the endpoint quality. The log-sum-exp surrogate gives every near-maximal constraint a gradient contribution; the logistic-potential design prevents violation of the volume constraint by construction rather than through repeated `clip + greedily adjust`, which frequently degrades precision near optimal endpoints. Low-dimensional/global starting points are included because the parent can be trapped in a local valley where no local active-set surrogate produces a descent direction that reduces the true maximum.

1.3 Scope and limitations

The algorithm is deterministic apart from the supplied seed. It returns the best exact discrete solution discovered. It may be prevented by a failed hidden sum root, numerical saturation of expit, L-BFGS-B non-convergence, or simply because the smoother misses toward the true active surface. No relaxation is used as final evaluation; no convexity claim is made for the full problem. The exact objective includes all finite-lag boundary terms and both lag directions as implemented by `np.correlate`; it must never be replaced by circular correlation or an autocorrelation-only proxy.

2. Mathematical specification

2.1 Discrete feasible set and exact metric

Let n be the returned number of samples,

dx = 2.0 / n,
target = n / 2.

The constraints are:

- 0 <= h_i <= 1 for every i,
- sum_i h_i = target within numerical precision, where dx · sum_i h_i = 1.

Let v = 1.0 - h. The authoritative correlation metric is

c(h) = max_{k=0,...,2n-2} (np.correlate(h, v, mode="full")[k]) * dx.

All final `c5_bound` values must be produced by this formula or an algebraically checked equivalent; because the formula can be evaluated in all orientations directly, a small orientation calibration is described below for gradients only.

2.2 Lag alignment and derivative compatibility

Let `M = 2*n - 1` and `ctr = n - 1`. Each index k in correlation order corresponds to a shift:

d = f * (k - ctr),

where `f` is either +1 or -1. For a finite shift `d`:

- If d >= 0, overlap pairs are (a_t,b_t) = (t+d,t), t = 0,...,n-d-1, and

  C_k(h) = dx · sum_t h[t+d] * (1 - h[t]).

- If d < 0, write q = -d. The pairs are (a_t,b_t) = (t,t+q), t = 0,...,n-q-1, and

  C_k(h) = dx · sum_t h[t] * (1 - h[t+q]).

The value `f` should be calibrated at program start: construct a short feasible random or sinusoidal h of length about 9, compute the exact `np.correlate(h, 1-h, "full")` vector, compute the above aligned vector for both signs f, and choose the sign with smaller maximum absolute difference. This removes uncertainty regarding the orientation of `np.correlate`. Once chosen, the same `f` must be used for every gradient formula. The final `c(h)` formula need not depend on `f`, because it is the raw evaluator.

For any selected lag k and associated shift d, the partial derivative of `C_k` with respect to entries of h is:

- If d > 0:

  ∂C_k/∂h_{t+d} += dx * (1 - h[t]),

  ∂C_k/∂h_t -= dx * h[t+d].

- If d < 0, q = -d:

  ∂C_k/∂h_t += dx * (1 - h[t+q]),

  ∂C_k/∂h_{t+q} -= dx * h[t].

- If d = 0:

  ∂C_k/∂h_t += dx * (1 - 2h[t]).

These formulas are linear, sparse, and exactly consistent with the shifted overlap integral that was calibrated to the `np.correlate` order.

2.3 Smooth minimax objective

Let

C = (C_0,...,C_{M-1})

be the exact shifted-lag metric for a feasible h, and let

F = max_k C_k.

For tau > 0 define the normalized softmax weights

w_k(tau) = exp((C_k - F) / tau) / sum_{j=0}^{M-1} exp((C_j - F) / tau).

A numerically safe objective is

f_tau(h) = sum_k w_k(tau) * C_k

equivalently obtained from the Mathias-function/LSE representation. This smooth surrogate converges to the maximum as tau -> 0 and its full derivative is

∇_h f_tau = sum_k w_k(tau) * ∇_h C_k.

It is deliberately over-emphatic of constraints close to the maximum, while not completely ignoring weaker constraints. There is no convexity claim: C_k contains negative pair-products; f_tau is only a smooth local guide.

When tau is below about `5e-4`, use literal active-set uniform weights instead of expmin: choose all constraints satisfying `C_k >= F - delta`, with `delta = max(1e-7, 0.3*tau)`, and set their weights to 1/count. In the limiting exact minimax, directional descent based only on the original constraints may be cache-free, so all achieved candidates will then be tested by exact `c(h)`.

σ(t) = 1 / (1 + exp(-t)).

z_i = u_i,
