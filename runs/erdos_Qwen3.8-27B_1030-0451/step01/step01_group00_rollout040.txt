The problem is that at lag = -half_period, we get the maximum overlap of 1s with 0s.

So for a periodic pattern with period p and m ones per period, at lag = -m (or +m), we get approximately m*(p-m)/p * (2/n) per period... this is getting complicated.

Let me think about this differently. The key constraint is that the "worst" lag gives the maximum. For a periodic pattern, the worst lag is at the anti-period (half the period), where the maximum number of 1s align with 0s.

To minimize the worst case, we need a pattern where at no lag do too many 1s align with 0s. This is essentially a "low cross-correlation" problem.

The best known sequences for this are related to Barker sequences, Costas arrays, and other low-autocorrelation sequences. But those typically have different optimization criteria.

For our problem (minimizing the maximum of h(x)(1-h(x+k)) over k), the optimal binary pattern should have the property that at every shift, the number of (1,0) pairs is minimized.

This is equivalent to: for every shift k, the number of positions where h[i]=1 and h[i+k]=0 is minimized. This is the same as: the cross-correlation of h with its complement is minimized in the max sense.

This is related to "complementary codes" and "Golay complementary sequences." A Golay complementary pair (A, B) has the property that R_A(k) + R_B(k) = 0 for all k ≠ 0, where R is the aperiodic autocorrelation.

But for our single-sequence problem, we want the aperiodic cross-correlation of h with (1-h) to be minimized in the max sense.

Note: R_{h,1-h}(k) = R_h(k) - R_h(0) = R_h(k) - (number of 1s) for the aperiodic case.

Wait, that's not quite right either. Let me define:
S(k) = sum_i h[i] * (1-h[i+k]) = sum_i h[i] - sum_i h[i]*h[i+k] = (# of 1s in the overlapping range) - R_h_overlap(k)

where R_h_overlap(k) = sum_i h[i]*h[i+k] over the valid range.

So S(k) = N_ones_overlap(k) - R_h_overlap(k).

For a balanced sequence (n/2 ones), at lag 0: S(0) = n/2 - n/2 = 0 (for binary).
At other lags, S(k) = N_ones_overlap(k) - R_h_overlap(k).

To minimize max S(k), we want R_h_overlap(k) to be as close to N_ones_overlap(k) as possible, i.e., the 1s should be "spread out" so that at any shift, the 1s tend to land on other 1s rather than 0s.

This is exactly the "low autocorrelation" property! We want the autocorrelation of the binary sequence to be close to the maximum possible (which would be the case if all 1s were in one block, but that gives bad cross-correlation at the anti-period).

Actually wait, I think I'm overcomplicating this. Let me just focus on the optimization algorithm.

The key insight from the analysis: for a truly binary solution, C₅ is determined by the maximum "1-to-0" count at any lag, times 2/n. For non-binary solutions, the values are smoother.

Given the current best of 0.381039, which corresponds to a "1-to-0" count of about 0.381039 * n/2 at the worst lag (for n=81, that's about 15.4), we need to find a pattern where the worst lag has fewer than about 15.4 "effective" pairs.

For n=81, the average would be 81/4 ≈ 20.25, so we're already doing 25% better than average. To get to 0.3808, we need about 15.39 effective pairs, which is a tiny improvement.

This suggests we need a very careful local optimization, not a completely different approach. The previous algorithm is close; we just need to squeeze out a bit more.

Let me focus on improving the optimization algorithm:

1. **Better gradient**: Use the exact subgradient of the max (average of active gradients) rather than a softmax approximation.

2. **Adaptive stepping**: Use a backtracking line search with a more aggressive initial step.

3. **Perturbation schedule**: Use periodically increasing perturbations to escape local minima.

4. **Multi-resolution**: Try slightly different n values (e.g., 80, 81, 82, 83) to find a slightly better discretization.

5. **Coordinate refinement**: After the main optimization, do individual coordinate updates.

6. **Binary perturbation**: Periodically try to push the solution toward binary (project h_i to {0,1} for a subset of coordinates) and then re-optimize.

import numpy as np
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode="full")

def project_constraint(p, n):
    target = n / 2.0
    p = np.where(np.isfinite(p), p, 0.5)
    lo = float(np.min(p)) - 1.5
    hi = float(np.max(p)) + 1.5
    for _ in range(100):
        mid = 0.5 * (lo + hi)
        proj = np.clip(p - mid, 0.0, 1.0)
        s = float(np.sum(proj))
        if s > target:
            lo = mid
        else:
            hi = mid
    lam = 0.5 * (lo + hi)
    proj = np.clip(p - lam, 0.0, 1.0)
    diff = target - float(np.sum(proj))
    if abs(diff) > 1e-12:
        mask = (proj > 1e-10) & (proj < 1.0 - 1e-10)
        nm = int(np.sum(mask))
        if nm > 0:
            proj[mask] += diff / nm
            proj = np.clip(proj, 0.0, 1.0)
            diff2 = target - float(np.sum(proj))
            if abs(diff2) > 1e-14:
                mask2 = (proj > 0) & (proj < 1.0)
                if np.sum(mask2) > 0:
                    proj[mask2] += diff2 / np.sum(mask2)
                    proj = np.clip(proj, 0.0, 1.0)
    return proj

def corr_grad_at_lag(h, lag):
    """Gradient of correlation at a specific lag."""
    n = len(h)
    dx = 2.0 / n
    g = np.zeros(n)
    if lag == 0:
        g = (1.0 - 2.0 * h) * dx
    elif lag > 0:
        g[lag:] = (1.0 - h[:n-lag]) * dx
        g[:n-lag] -= h[lag:] * dx
    else:
        L = -lag
        g[:n-L] = (1.0 - h[L:]) * dx
        g[L:] -= h[:n-L] * dx
    return g

def max_subgradient(h, corr, top_k=10):
    """Subgradient of max(corr): average of top-k correlation gradients."""
    n = len(h)
    f = float(np.max(corr))
    # Weight by proximity to max
    # Use exponential weighting
    c = corr - f
    # Scale
    tau = 50.0
    w = np.exp(tau * c)
    w_sum = w.sum()
    if w_sum < 1e-300:
        # All equal, use top_k
        idx = np.argsort(corr)[::-1][:top_k]
        grad = np.zeros(n)
        for k in idx:
            grad += corr_grad_at_lag(h, k - (n-1))
        return grad / len(idx)
    w = w / w_sum
    grad = np.zeros(n)
    for k in range(len(corr)):
        if w[k] < 1e-12:
            continue
        lag = k - (n - 1)
        grad += w[k] * corr_grad_at_lag(h, lag)
    return grad

def make_start(n, seed_val):
    rng = np.random.RandomState(seed_val)
    x = np.linspace(0.0, 2.0, n, endpoint=False)
    h = np.ones(n) * 0.5
    # Add structured noise
    for freq in [1, 2, 3, 5, 7, 11]:
        h += 0.1 / freq * np.sin(2.0 * np.pi * freq * x + rng.rand() * 2 * np.pi)
    h += rng.randn(n) * 0.03
    return project_constraint(h, n)

def optimize_local(h0, time_limit, seed_val=42):
    n = len(h0)
    h = h0.astype(float).copy()
    best_h = h.copy()
    best_c5 = compute_c5(h)
    rng = np.random.RandomState(seed_val)
    t0 = time.time()
    step = 0.5 / n
    
    # Adaptive parameters
    tau_values = [5, 15, 50, 150, 400]
    n_tau = len(tau_values)
    tau_alloc = time_limit / n_tau
    
    for pass_i in range(n_tau):
        tau = tau_values[pass_i]
        pass_t0 = time.time()
        stall_count = 0
        max_stall = 30
        
        while time.time() - pass_t0 < tau_alloc and time.time() - t0 < time_limit - 3:
            corr = compute_corr(h)
            c5_val = float(np.max(corr) * (2.0/n))
            
            if c5_val < best_c5 - 1e-13:
                best_c5 = c5_val
                best_h = h.copy()
                stall_count = 0
            
            # Compute gradient
            f = float(np.max(corr))
            c_shifted = corr - f
            w = np.exp(tau * c_shifted)
            w_sum = w.sum()
            if w_sum < 1e-300:
                break
            w = w / w_sum
            
            grad = np.zeros(n)
            for k in range(len(corr)):
                if w[k] < 1e-10:
                    continue
                lag = k - (n - 1)
                grad += w[k] * corr_grad_at_lag(h, lag)
            
            gnorm = float(np.linalg.norm(grad))
            if gnorm < 1e-14:
                # Stuck, add random perturbation
                h = project_constraint(h + rng.randn(n) * 0.03, n)
                stall_count += 1
                continue
            
            # Line search
            made_progress = False
            for bt in range(12):
                h_new = project_constraint(h - step * grad, n)
                corr_new = compute_corr(h_new)
                c5_new = float(np.max(corr_new) * (2.0/n))
                if c5_new <= c5_val + 1e-13:
                    h = h_new
                    if c5_new < c5_val - 1e-12:
                        made_progress = True
                        stall_count = 0
                    break
                step *= 0.5
            else:
                # Failed, try smaller step or different direction
                step = max(step, 0.01 / n)
                h_alt = project_constraint(h - step * grad + rng.randn(n) * 0.01, n)
                h = h_alt
            
            # Update step size
            if made_progress:
                step = min(step * 1.3, 2.0 / n)
            else:
                step = max(step * 0.7, 0.005 / n)
                stall_count += 1
            
            if stall_count > max_stall:
                # Escape: larger perturbation
                h = project_constraint(h + rng.randn(n) * 0.05, n)
                step = 0.3 / n
                stall_count = 0
    
    return best_h, best_c5

def binary_sharpen(h, n, alpha=0.3):
    """Push h toward binary: h_i -> h_i + alpha*(h_i - h_i^2) which increases |h_i - 0.5|"""
    # h^2 - h = h(h-1) < 0 for h in (0,1)
    # To push toward 0 or 1: h_new = h + alpha*(h - 0.5)*|h-0.5| * 2
    # Simpler: h_new = h + alpha * (h - h^2) * sign(h - 0.5)
    # Or: h_new = h + alpha * h * (1-h) * sign(h - 0.5)
    sign = np.sign(h - 0.5)
    sign[sign == 0] = 1
    h_new = h + alpha * h * (1 - h) * sign
    return project_constraint(h_new, n)
