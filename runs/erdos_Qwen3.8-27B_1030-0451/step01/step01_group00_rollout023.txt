```python
def make_slope_table(h):
    n = len(h)
    m = 2 * n - 1
    slope_table = np.zeros((n, m))
    for L in range(-(n-1), n):
        idx = L + (n-1)
        # Determine valid range of i
        i_min = max(0, -L)
        i_max = min(n-1, n-1-L)
        if i_min > i_max:
            continue
        indices = np.arange(i_min, i_max+1)
        # First factor contribution: for each i in valid range, slope_table[i, idx] += (1-h[i+L])
        slope_table[indices, idx] += (1.0 - h[indices + L])
        # Second factor contribution: for each i in valid range, slope_table[i+L, idx] -= h[i]
        slope_table[indices + L, idx] -= h[indices]
    return slope_table
```

This is O(n) per L, and there are O(n) values of L, so O(n²) total. For n=81, that's 6561 operations. Very fast.
