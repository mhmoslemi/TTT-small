1. Approach and rationale

The objective is a continuous but nonconvex minimax problem: after discretization we want
F(h) = max_j c_j(h)
where c(h) is the finite-support linear correlation between h and 1-h over the sampling grid, subject to
0 <= h_i <= 1 and sum_i h_i = n/2.
The supplied evaluator is authoritative:
score(h) = max(full_correlation(h, 1-h, valid grid shift distances)) * (2/n).
This strategy does not replace the evaluator by the wrong intuition 1 minus an autocorrelation. It works directly with the exact correlation vector c as supplied by compute_corr, computed with the same orientation and lag support as np.correlate with mode "full" and scaled by dx=2/n.

The most promising improvement over a smoothed gradient or logsumexp surrogate is to minimize the exact max constraint directly, while using a smoothing surrogate only to warm-start the local solver. The previous construction can stagnate because the maximum constraint is hidden in a smooth penalty and coordinate representation. Instead, one should consider active correlation constraints and solve a local linearized/nonlinear constraint subproblem that explicitly minimizes an auxiliary scalar upper bound T for all correlation constraints. That is a mathematical change of the local method rather than merely retuning tau values.

At the same time, nonconvexity makes single-start polish insufficient. Therefore the strongest parent construction should be retained as fallback and used for multi-resolution transfer, sharpening, and interpolation. In parallel a small set of other balanced starting points should be optimized locally. This gives diversity without becoming a generic random search.

Specific algorithmic components:
- Exact objective validation after every proposal, including rounding/feasibility repair.
- A direct exact active-set constrained nonlinear optimization using SciPy SLSQP over variables (h,T), thus minimizing F exactly.
- A graded sequence of smoothing surrogate objectives with logsumexp approximation of max, but candidate acceptance always based on the original exact score.
- Supplementary pair-coordinate constrained line searches that preserve the equality constraint and respect bounds exactly; these provide exact objective news and escape small flat regions left by surrogate methods.
- Multi-scale handling: parent resolution and a few larger local meshes obtained by interpolation, for a better representation, while storing all valid candidates separately. Smaller sequences are preferred only among true ties/nonimprovements.

Important limitations:
- The local constrained solver is not global. It may return a local stationary point. Only exact score comparisons are trusted.
- Nonlinear constraints in SLSQP are nonconvex; success flags should be treated as heuristic only, and every result gets exact re-evaluation and repair.
- Increasing n is not guaranteed to monotonically lower the discrete score, because exact finite-support objective changes with grid resolution. Hence all n are precise candidates and feasible validation is mandatory.
- Smoothing changes the objective; it only accelerates descent from non-optimal points. True acceptance is the exact evaluator only.
