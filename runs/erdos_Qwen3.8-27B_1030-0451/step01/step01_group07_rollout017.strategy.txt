1. Approach and rationale

1.1 Central idea

The supplied parent is already a feasible discrete construction close to the goal, so the problem is a difficult nonconvex local-basin polishing problem: a generic smoothed descent method repeatedly moves all coordinates and then restores the sum constraint, which can destroy useful boundary structure and can stagnate at active-lag plateaux.

The proposed method is different from a smooth log-sum-exp descent because it primarily searches exact one-dimensional mass-transfer lines. A move has the form

    h_i changes by -t, h_j changes by +t,

with t restricted to the interval in which both coordinates remain inside [0,1]. This automatically preserves the global constraint sum(h)=n/2 and is a feasible trajectory in the full continuous optimization set. For each selected pair (i,j), the gradient of an active-excess objective identifies whether mass should move from i to j or vice versa; a one-dimensional exact minimization or grid search then drives h along the best transfer line using the true evaluator. The result is a coordinate-transfer local method with exact feasibility, exact initialization, and exact acceptance, followed by stochastic transfer restarts and transform/multi-resolution diversification.

1.2 Why this addresses the bottleneck

- Exact feasibility is built into the transfer step. There is no subsequent global clipping-plus-rescaling that violates the box or the mass constraint.
- The method targets the two positions with the strongest conflicting active-lag sensitivity, rather than moving the entire profile orthogonal to a single smoothed gradient.
- The one-dimensional local solver can jump a coordinate toward a bound, or to a nontrivial optimum on the pair line. This can trigger sequences of 0/1-like boundary movements that the parent may not have reached.
- Only the exact objective `max(np.correlate(h,1-h,mode='full'))*2/n` decides which candidate becomes the accepted current or global best. Surrogates are only direction indicators.
- The problem is nonconvex because of quadratic terms h_i(1-h_j). No convex global optimum is claimed. The algorithm is explicitly a local/global-search heuristic with a validated feasible fallback.

1.3 Important limitations

- The method is not globally optimal.
- A pair line is a restricted one-dimensional projection; improvements requiring several simultaneous pair moves may require many accepting cycles or external perturbations.
- The active-excess gradient is a heuristic alignment device, not a certificate. The original evaluator is the sole acceptance authority.
- Runtime is controlled by time-based scheduling and a finite line-search budget. The fallback is always the best valid candidate already found, including the supplied parent if nothing improves it.
