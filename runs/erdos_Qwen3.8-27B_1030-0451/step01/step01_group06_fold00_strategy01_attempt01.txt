1. Approach and rationale

Central idea. Formulate the discrete Erdős overlap objective as a true epigraph nonlinear program,

    minimize t
    subject to 0 <= h_i <= 1,
               sum_i h_i = n/2,
               np.correlate(h, 1 - h, mode='full') * dx <= t
               for all 2n - 1 lags,

and solve this epigraph problem locally for many valid starting constructions using SciPy’s SLSQP constraints. The proposed method is materially different from the current parent loop because the parent method iteratively solved only a first-order linear LP approximation of the nonsmooth maximum constraints inside a trust region. Here the full nonlinear constraints Q_r(h) <= t are available to the nonlinear solver, so the solver may use curvature through the BFGS/epigraph dynamics rather than only a supporting hyperplane of Q_r. Exact objective values are still recomputed from the authoritative evaluator and only exact decreases are accepted.

Why this may improve. The dominant bottleneck in the current construction is local trapping around a linearized active-set configuration. Many correlations are nearly active and move in a coupled nonlinear way; iterative linear replacement can force steps into the wrong one of many possible local inequalities. The epigraph solver treats h and t simultaneously and can exploit the inequality geometry more directly. To counter the nonconvexity and local traps, the program also performs:

- algorithmic parent validation and valid transformations (complement, reflection, symmetrization);
- active-shadow gradient lines from weighted sums of active correlation gradients;
- feasible random restarts and transformed starts;
- one-upscale downscale transfer where time allows;
- a strict exact-objective acceptance rule after every solver, projection, and perturbation.

Fact/justification: the objective is generally nonconvex and this is not a global optimizer. The justification for considering it an improvement is that it optimizes a formulation unavailable to the prior LP and extends the search with exact-metric acceptance. Hypothesis: direct epigraph local solving plus diverse transformed starts can discover lower values than the first-order LP trap, but this is unverified.

Limitations.
- SLSQP on a nonconvex epigraph may converge to any nearby local minimum.
- Full nonlinear constraint evaluations and Jacobians are more expensive than a few subset correlations.
- If a safe parent cannot be obtained, there is no theoretical guarantee of recovering the current bound. Retain any valid candidate and a deterministic feasible fallback.
- Upscaling/downscaling changes the exact metric; candidates are accepted only by their own direct evaluator score.

2. Mathematical specification

2.1 Exact representation and evaluation

For a returned vector h of length n:

    n must satisfy n < 2500.
    dx = 2.0 / n.
    target_sum = n / 2.0.

Correlation vector Q is exactly

    Q = np.correlate(h, 1.0 - h, mode='full') * dx,

so Q has length p = 2n - 1. The objective is

    C5(h) = max(Q) = float(np.max(Q)).

The output index r corresponds to signed lag

    l = r - (n - 1),  l = -(n-1), ..., n-1.

With the np.correlate convention used in the task, for a fixed lag l,

    Q_l(h) = dx * sum_{j valid} h_{j+l} * (1 - h_j),

where the term is included only when 0 <= j < n and 0 <= j + l < n. This convention will be checked numerically before analytic constraints are used; if the check fails and no correction succeeds, numerical finite-difference Jacobians are used instead of analytic Jacobians.

Constraints:

    0 <= h_i <= 1, i = 0,...,n-1,
    sum(h) = n/2.

They are checked jointly rather than by separate clip/rescale.

2.2 Joint feasibility projection

Define project_box_sum(x, target) which returns a vector y with 0 < y_i < 1 approximately and sum(y) = target increasingly exactly.

Algorithm:

1. Convert x to float64, replace non-finite values with 0.5.
2. If target <= 0, return zeros-like feasible construction; if target >= n, return all ones-like feasible construction. Normally target = n/2 is strictly between 0 and n.
3. Bisection on a scalar shift lambda for the monotone function

       S(lambda) = sum_i clip(x_i - lambda, 0, 1).

   Use lo = min(x) - 2, hi = max(x) + 2 for at least 80 iterations. After the bisection, set y = clip(x - lambda, 0, 1).
4. Compute residual r = sum(y) - target.
5. While |r| > 1e-11 and capacity remains:
   - If r > 0, subtract r from entries sorted descending; for a selected entry i, delta = min(r, y_i), y_i -= delta, r -= delta.
   - If r < 0, add in to entries sorted ascending; for selected i, delta = min(-r, 1 - y_i), y_i += delta, r += delta.
6. Repeat the bisection twice on y to remove cumulative drift, then finish with targeted clamp-preserving adjustments as in step 5.

All candidates coming from solvers, transformations, random seeds, and downsampling are passed through this projection before exact evaluation. Rounding in evaluation accommodation is permitted, but the final vector is produced by this mechanism and has sum within a very small numerical tolerance of target.

2.3 Exact analytic correlation gradient rows

For the signed lag l corresponding to output row r = l + n - 1, the gradient of Q_l with respect to h has entries

    grad_l(h)_i =
        dx * (1 - h_{i-l})   if 0 <= i-l < n,
        - dx * h_{i+l}       if 0 <= i+l < n.

The two conditions can be true simultaneously only for l = 0, where it becomes

1. Approach and rationale

Central idea. Replace the parent LP-approximation process by a direct epigraph nonlinear-program formulation and solve it without linearizing the correlations over a trust region. For a vector h of length n, introduce an epigraph variable t and solve

    minimize t
    subject to 0 <= h_i <= 1,
               sum_i h_i = n/2,
               Q_r(h) <= t for every one of the 2n - 1 correlation lags.

Here Q(h) is the exact vector returned by np.correlate(h, 1.0 - h, mode='full') * dx. The reported bound is always recomputed exactly from this vector after any solver step, projection, transformation, or perturbation.

This is materially different from the prior attempt, whose core update repeatedly solved a first-order linear programming approximation of all correlation constraints within an active subset. The new method keeps the full nonlinear inequalities available to a local nonlinear constrained solver. The epigraph variable lets the solver choose both a descent direction for h and a reduction of the scalar maximum simultaneously. Because the problem remains nonconvex, local solvers are used only to generate candidates; every candidate must win by the authoritative discrete objective. To cover nonconvexity, the same epigraph solver is run not only on the original nonsymmetric variables, but also on a symmetric reduced-variable version of the problem, on transformed parents, and on diversified seeded local searches. These epigraph searches are supplemented by a small active-gradient exact-line polish that needs no solver fiber.

Why it is targeted at the present trap. Near the current construction, many lags may be nearly active. A linear active-set LP decides one affine direction while ignoring how different Q_r rows curve and interact as the entire vector changes. The epigraph method can internally move h and t together under the nonlinear rows; in addition, the symmetric reduced-variable formulation eliminates two-for-one symmetric coordinate duplication and can move in a lower-dimensional landscape less hostile to the local optimizer. Not every method individually can prove the improvement, but the plan is built to retain the parent and to accept only strict exact-objective decreases.

- The optimization is nonconvex. The method is local and stochastic in its many restarts; it does not claim a global optimum.
- The nonconvex epigraph subproblems may time out, fail to converge, or stop at worse scores; then current valid solutions are retained, never replaced by invalid accepted candidates.
- Constraints with SLSQP remain only as local nonlinear-program attempts; it is a heuristic acceptance mechanism rather than global convergence.

2. Mathematical specification

2.1 Exact discrete evaluation and lag convention

Given a vector h with entries h_i, i = 0,...,n - 1, feasible length 2n - 1 correlations are exactly generated by

    dx = 2.0 / n,
    Q = np.correlate(h, 1.0 - h, mode='full') * dx.

The correlation vector length is p = 2n - 1. The exact problem bound is

    C5 = float(np.max(Q)).

Index output row r = 0,...,2n - 1 to signed shift

    l = r - (n - 1).

In the convention consistent with the evaluator, for lag l

    Q_l(h) = dx * sum over all j such that 0 <= j < n and 0 <= j + l < n of
             h_{j+l} * (1 - h_j).

This includes both lag directions and boundary-truncated overlaps. Do not replace this by a periodic, zero-padded, or symmetric autocorrelation formula unless the resulting rows reproduce exactly the same np.correlate order and finite-boundary truncations.

2.2 Feasible constraints and joint projection
