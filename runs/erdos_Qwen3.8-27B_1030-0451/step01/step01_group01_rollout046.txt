Terms involving h[j]:
- n = j: term changes from h[j+L]*(1-h[j]) to h[j+L]*(1-h[j]+δ), change = δ*h[j+L]
- n+L = j (n = j-L): term changes from h[j]*(1-h[j-L]) to (h[j]-δ)*(1-h[j-L]), change = -δ*(1-h[j-L])

But if i and j are at the lag distance (j = i+L or i = j+L), there's overlap:
- If j = i+L: the term with n=i is h[j]*(1-h[i]), which involves BOTH h[i] and h[j].
  From h[i] side: change = -δ*h[j] (treating h[j] as fixed)
  From h[j] side: change = -δ*(1-h[i]) (treating h[i] as fixed)
  Total (linear approximation): -δ*h[j] - δ*(1-h[i])
  Actual: (h[j]-δ)(1-h[i]-δ) - h[j](1-h[i]) = -δ - δ*h[j] + δ*h[i] + δ²
  Difference: δ² (the quadratic term)

- If i = j+L: the term with n=j is h[i]*(1-h[j]), involving both.
  From h[i] side: change = δ*(1-h[j])
  From h[j] side: change = δ*h[i]
  Total (linear): δ*(1-h[j]) + δ*h[i]
  Actual: (h[i]+δ)(1-h[j]+δ) - h[i](1-h[j]) = δ + δ*h[i] + δ*(1-h[j]) - δ... 
  
  Wait: (h[i]+δ)(1-h[j]+δ) = h[i](1-h[j]) + h[i]δ + δ(1-h[j]) + δ²
  Change = δ*h[i] + δ*(1-h[j]) + δ²
  Linear formula gives: δ*(1-h[j]) + δ*h[i]
  Difference: δ²

So in both cases, the correction is +δ². Let me define:
q[m] = 1 if the specific m corresponds to lag L = j-i (where n=i gives the overlapping term) or L = i-j (where n=j gives the overlapping term).

More precisely:
- m1 = n-1 + (j-i): the lag where n=i gives n+L=j. q[m1] = 1.
- m2 = n-1 + (i-j): the lag where n=j gives n+L=i. q[m2] = 1.

And the total change is:
Δc[m] = δ*d[m] + δ²*q[m]

where d[m] is as I computed before (the sum of all four contributions), and q[m] is the quadratic correction.

Now, for the 1D minimization, I need to minimize:
f(δ) = max_m (cv[m] + δ*d[m] + δ²*q[m])

over δ ∈ [d_lo, d_hi].

Since q[m] ≥ 0 for all m (it's 0 or 1), each function cv[m] + δ*d[m] + δ²*q[m] is convex in δ (it's a quadratic with non-negative leading coefficient, or linear). The max of convex functions is convex. So f is convex and I can use ternary search or bisection.

    """Greedy pair-exchange optimization with exact 1D line search."""
    n = len(h)
    dx = 2.0 / n
    h = h.copy()

    # Precompute index arrays for efficient access
    
    for sweep in range(max_sweeps):
        improved = False
        for i in range(n):
            for j in range(i+1, n):
                d_lo = max(-h[i], h[j] - 1.0)
                d_hi = min(1.0 - h[i], h[j])
                if d_hi - d_lo < 1e-12:
                    continue
                
                # Compute d[m] vector
                h_ip = np.zeros(2*n-1)
                h_im = np.zeros(2*n-1)
                h_jp = np.zeros(2*n-1)
                h_jm = np.zeros(2*n-1)
                
                idx = (i + L_arr >= 0) & (i + L_arr < n)
                h_ip[idx] = h[i + L_arr[idx]]
                idx = (i - L_arr >= 0) & (i - L_arr < n)
                h_im[idx] = h[i - L_arr[idx]]
                idx = (j + L_arr >= 0) & (j + L_arr < n)
                h_jp[idx] = h[j + L_arr[idx]]
                idx = (j - L_arr >= 0) & (j - L_arr < n)
                h_jm[idx] = h[j - L_arr[idx]]

                q = np.zeros(2*n-1)
                m1 = n-1 + (j-i)
                m2 = n-1 + (i-j)
                if 0 <= m1 < 2*n-1:
                    q[m1] = 1.0
                if 0 <= m2 < 2*n-1:
                    q[m2] = 1.0
                
                # Minimize max(cv + delta*d + delta^2*q) over [d_lo, d_hi]
                # Use ternary search (convex function)
                a, b = d_lo, d_hi
                for _ in range(35):
                    m1t = a + (b-a)*0.333
                    m2t = b - (b-a)*0.333
                    f1 = np.max(cv + m1t*d + m1t*m1t*q)
                    f2 = np.max(cv + m2t*d + m2t*m2t*q)
                    if f1 < f2:
                        b = m2t
                    else:
                        a = m1t
                delta = 0.5*(a+b)

                if new_max < cv.max() - 1e-11:
                    h[i] += delta
                    h[j] -= delta

                    improved = True
                    new_c = cv.max() * dx
                    if new_c < best_c:
                        best_c = new_c
                        best_h = h.copy()
        
        if not improved:
            break
    
    return best_h, best_c
