1. Approach and rationale

1.1 Central idea

The supplied parent solution is already almost at the target, so the remaining problem is to break through a local plateau rather than to resample a smooth gradient basin. The previous approach relied primarily on a smoothed maximum plus a few gradient-like updates and a polish. The new primary method is materially different: it performs direct exact-objective minimax search in a constrained low-dimensional subspace and in a second-order-free coordinate movement structure.

The core search maps a low-dimensional coefficient vector to a feasible array after an exact projection, then evaluates the true evaluator’s objective on the projected feasible vector. Inside this map, one-dimensional grid/bracket line searches, full projected active-gradient line moves, and explicit pair-wise mass-exchange moves are performed. Each proposed point is accepted or rejected only after evaluating the actual comb-overlap objective. There is no use of circular correlation, no replacement by an unconstrained autocorrelation minimum, and no final claim of a global optimum.

The method is able to make progress in situations where an analytic gradient is blocked by competing peak constraints because pair moves and projected random subspace directions can redistribute mass without internally fitting all active constraints using the same smooth surrogate. Restricting coefficients to a subspace with a continuous projection makes the search robust, cheap, and directly legal: every evaluated candidate, whether generated by a coordinate search, a pair move, or a random perturbation, is always represented to the evaluator by a feasible vector after projection.

1.2 Why it could improve the parent

The plateaus in finite minimax correlation problems often come from the interaction of several restricted lag constraints: lowering one active peak raises another, while the boundary terms of shorter overlaps impose different elasticities. A greedy smoothed maximum can waste steps moving in an averaged direction that ignores those constraints. The new acceptance strategy:

- evaluates a point exactly, so an infinite sequence of rejected proposals can later become an accepted movement through a feasible-looking high coordinate value in a subspace;
- samples smooth directions in Fourier and active-gradient subspaces, which form a different geometry from point-wise pure projected gradient descent;
- lets local mass transfers move finite amount between a constrained entry and another entry in a bounded way through small grid or scalar bracket lines;
- attempts resolutions near the parent resolution in order to avoid local discretization artifacts or to use a slightly finer piecewise-constant h to damp peaks;
- preserves the already-best state at all times and returns the parent whenever all exploratory improvements fail, retaining feasibility.

1.3 Justified facts and hypotheses

Justified:

- the exact objective must be matched to `np.correlate(h, 1.0 - h, "full") * (2.0 / n)` and both directions of correlation must be retained;
- `0 <= h_i <= 1` and `sum(h)=n/2` can be enforced as one joint constrained feasibility projection, not as independent clipping and rescaling;
- the product terms `h_i (1-h_j)` make the objective nonconvex in general, and every proposed or accepted bound must be certified only by the feasible vector scored by the evaluator.

Hypotheses, not proofs:

- the retained parent may not be globally optimal because discretization and the nonconvex feasible set admit many local minima;
- an initial plateau near `0.381039` can be climbed or defect by feasible random-direction and exact-pair exact-objective search;
- a modestly higher sample resolution may yield a feasible vector with a lower evaluator value, but each resolution is scored independently and cannot be equated with another discretization without recomputing it exactly.

2. Mathematical specification

2.1 Representation and exact objective

For a feasible vector `h ∈ R^n`, let

`dx = 2.0 / n`.

Use the evaluator-compliant formula over correlation index `q = 0,...,2n-2`:

`lag = q - (n - 1)`.

The raw evaluator correlation used by `np.correlate` is

`R_q(h) = sum_{i=0}^{n-1} [h_i * (1 - h_{i-lag})]` where terms are present only if `0 <= i-lag <= n-1`.

The scaled objective is

`C_q(h) = dx * R_q(h)`,
`C(h) = max_q C_q(h)`.

This does not include a hidden circular sum and it keeps both positive and negative `lag` effects. The allowed accepted bound must be the maximum C_q for the exact candidate h used in the returned tuple.

2.2 Feasible set and joint projection

The feasible set is

`F_n = {h in [0,1]^n : sum_i h_i = n/2}`.

A robust feasible projection for an arbitrary finite input vector `p` is used:

1. Let `target = n/2`. Clip every nonfinite entry into `[0,1]` arbitrarily for internal projection; if the whole input is invalid, return an interior feasible vector.

2. Project using one-dimensional threshold bracketing. Solve for a scalar lambda such that

`sum_i clip(p_i - lambda, 0, 1) = target`.

The scalar function is continuous and monotone decreasing in lambda. Start the bracket at

`lower = min(p) - 1.0`, `upper = max(p) + 1.0`.

Run at least 70 bisection steps. Then

`h'(lambda) = clip(p - lambda, 0, 1)`.

This is a valid projection into the feasible set in the usual sense, and by construction sums to the target up to numerical precision.

3. Final exact consistent correction. Compute residual `r = target - sum(h')`. If `abs(r)` is above a tolerance `1e-10`, repair it while preserving the box:

- If `r > 0`, find entries with room `h_i < 1 - tiny`. Allocate as much as possible, preferring large slack. Repeatedly increase one remaining room entry or several such entries until residual is bounded by `1e-12`. This is possible whenever a strict interior solution is feasible; if the exact repair fails because of accumulated floating error, move a small amount between one interior entry and one boundary entry.
- If `r < 0`, do the opposite using entries with `h_i > tiny`.

After repair, again enforce `0 <= h_i <= 1` with only arithmetic `min(1, max(0,h_i))` and add/subtract a small mass only from interior entries. Since the residual is at round-off scale before repair, the pair uses only a few scalar operations and cannot change the objective in a significant way. Never rescale after clipping, because that violates the bounds.

Every nonfeasible proposal (line-search point, pair move, subspace point) must pass through this projection before it is scored or considered for acceptance.

2.3 Exact gradient formula used only for directions

The objective is not smooth, but each raw correlation `R_q(h)` is differentiable. Its gradient rows are needed for choosing heuristic directions in a safe local line-search. For a fixed scale `dx`, the gradient contribution to `C_q = dx R_q` is `dx` times the raw gradient.

For each lag value `L` and corresponding normalized objective value `C_q`, build an n-dimensional gradient vector g_q:

- If `L >= 0`, the overlapping pairs are `i = L,...,n-1`, `j = i-L = 0,...,n-L-1`, with term `h_i (1-h_j)`. Add:
  `g_q[L:L+n-L] += dx * (1.0 - h[:n-L])` and subtract:
  `g_q[:n-L] -= dx * h[L:L+n-L]`.
  This uses the equivalent indexing `g_q[h_i] += dx*(1-h_j)`.

- If `L < 0`, write `P = -L`. The valid pairs are `i=0,...,n-P-1`, `j=i+P=P,...,n-1`. Add:
  `g_q[:n-P] += dx * (1.0 - h[P:])` and subtract:
  `g_q[P:] -= dx * h[:n-P]`.

If `i=j`, both operations should happen once, producing `dx*(1-2h_i)`, which the sum above handles naturally.

A sanity test is required, but it is not claimed elsewhere: on `n=2` with vector `[a,b]`, the `q` values should correspond to lag `-(n-1)` giving only `a*(1-b)`, the middle lag to `a(1-a)+b(1-b)`, and the last lag to `b*(1-a)`. If the orientation is wrong, negate/invert shift by translating `q index` in the formula before using gradients.

2.4 Heuristic directional state and active weights

For a current feasible h, compute the normalized correlation vector `c = [C_q]` exactly. Sorting descending gives active peaks. Let top set be the top row `m = min(max(8, floor(n/4)), 60)` plus any row satisfying `c_j >= max(c) - 0.02` in values, capped by the row limit. To create a weighted gradient direction:

`z_j = c_j - max(c)` for active rows; compute stable weights `w_j = exp(max(z_j, -700))`; normalize `sum w = 1`; and form

`g = sum_j w_j g_q(j)`.

This is a heuristic descent field, often close to a convexified active set. The candidate direction for line search is `-g`, normalized by its infinity norm if it is not zero.

When the gradient becomes small or numerically invalid, choose a random zero-mean direction or abandon full-gradient line for a while. This stage is only proposal generation; acceptance always requires recomputing the exact full maximum using `np.correlate`.

- each column is mean-zero (`sum(B_i)=0`) so unbiased moves can be projected over the equality without simple mass drift; a small saved numerical zeroing is needed;
- columns are orthogonalized enough not to waste dimensions;
- each column is individually scaled such that its maximum absolute entry is no more than a small scaled value `col_scale = 0.4`.

`h(theta) = project(href + B @ theta)`.

`f(theta) = C(h(theta)) = dx * max_q R_q(h(theta))`.
