1. Approach and rationale

The objective is the exact finite-support nonsmooth min–max problem
\[
C(h)=\max_l Q_l(h),\qquad Q(h)=\texttt{np.correlate}(h,1-h,\text{mode="full"})*(2/n),
\]
with simultaneous box and equality constraints \(0\le h_i\le1\), \(\sum_i h_i=n/2\). The main difficulty is that decreasing the current maximum lag often requires moving many variables at once, and the first-order information is concentrated on only a few near-active lags. The previous line of thought relied on active-lag tangent LP moves, a single smoothing path, or target-violation forms; those can stall because they either ignore weak but soon-active lags or move in a trust segment that is too local.

The proposed program materially changes the search pattern. It builds a primary exact-objective incumbent directly from the supplied parent, then runs a composite search over several independently constructed feasible parents:
- a smooth logarithmic-sum-exp surrogate is solved by constrained quasi-Newton/SLSQP repeated over a continuation in smoothing width;
- after each smoothing stage, exact-objective acceptance is strict;
- a distinct “target deficit” least-upper-penalty model is used to attack one proposed upper bound at a time;
- exact directional repair steps, random feasible perturbations, shift/reflection/complement/low-pass/binarization candidates, and multi-resolution transfer are all considered;
- a single validated best candidate is retained throughout, so a supplied valid parent is never lost.

This is not presented as a global optimizer. It only refines candidate structures and transfers discovery decisions through the true finite-support correlation evaluator. The rationale for smoothing the max is that differentiable optimization machinery becomes available; the rationale for the target penalty is that moving from one candidate score \(v\) to \(v-\delta\) is a different nonconvex feasibility-energy problem and smooth maximum continuation can miss it. Multi-resolution is intended to leave a discrete grid artifact that can trap a native-resolution local method. Downscaling fine candidates preserves a packing decision under a coarser view when the exact score supports it.

Correctness assurances are separated from heuristics:
- exact correlation and exact feasibility are re-derived and tester-validated;
- any accepted score is computed by the same evaluator used for the task;
- all transforms preserve or repair feasibility;
- non-smooth local methods are local only; only accepted refined vectors are used for final reporting.

2. Mathematical specification

2.1 Variables, units, and exact objective

For a runtime vector \(h\in\mathbb{R}^n\), define
\[
dx=2.0/n,\qquad S=n/2.
\]
Feasibility is simultaneously
\[
0\le h_i\le1,\qquad \sum_i h_i=S.
\]
The authoritative score is required to be exactly
\[
C(h)=\max_r Q_r(h),\qquad
Q(h)=np.correlate(h,1-h,\texttt{mode="full"})*dx.
\]
All \(2n-1\) output entries and both lag directions are included. Do not replace \(Q\) by autocorrelation or a circular convolution, and do not replace \(Q\) with \(S-\text{autocorr}(h)\); finite support removes boundary overlap mass.

Let the output index \(r=0,\dots,2n-2\) be mapped by a lag label \(\ell=r-(n-1)\). The formulas below are written in the expected orientation, but every run performs a validation comparing these formulas with the evaluator and continues with the validated, correctly oriented table. If it fails after one swap test, the gradient subsystem may be disabled and only exact transformations/fallback search are executed; never use an untested analytic gradient for a solve.

For \(d=1,\dots,n-1\), define correlation rows:
\[
Q_0=dx\sum_i h_i(1-h_i),
\]
\[
Q_{+d}=dx\sum_{i=0}^{n-d-1}h_{i+d}(1-h_i),
\]
\[
Q_{-d}=dx\sum_{i=0}^{n-d-1}h_i(1-h_{i+d}).
\]
A compact constructor `correlation_direct(h)` should implement these three operations, then compare with
`np.correlate(h, 1.0 - h, "full") * (2.0/n)`
for at least two small runtime-generated vectors and one intentionally non-binary weighted vector. If absent in runtime, generate a deterministic test vector algorithmically: for even preliminary \(m\), `x = np.linspace(0,1,m)` combined with projection; no large literal arrays.

2.2 Joint feasibility projection

Use one repairer `project_box_sum(x, target)` not a sequence of clipping followed by independent scaling, because clipping/scaling repeatedly breaks the other constraint. Algorithm:
1. Replace NaN/Inf by 0.5, coerce to float64, take flattened copy.
2. Let lower endpoint \(L=\min_i x_i-2\), upper endpoint \(U=\max_i x_i+2\). Define monotone
\[
s(\lambda)=\sum_i \operatorname{clip}(x_i-\lambda,0,1).
\]
3. Binary-search \(80\) iterations for \(\lambda\) with \(s(\lambda)\approx target\):
   - if \(s(\text{mid})>target\), set `lo=mid`;
   - else set `hi=mid`.
   Return \(\lambda=(lo+hi)/2\).
4. Start \(h_i=\operatorname{clip}(x_i-\lambda,0,1)\). Compute residual \(r=\sum_i h_i-target\).
5. If \(r>0\), iterate indices in descending \(h_i\) and subtract
\[
\Delta_i=\min(r,h_i),
\]
updating residual. If \(r<0\), iterate ascending \(h_i\) and add
\[
\Delta_i=\min(-r,1-h_i).
\]
Repeat at most 20 times. Return feasible vector with \(0\le h_i\le1\) and \(|\sum_i h_i-target|\le1e-10\). If the repair still fails because of extreme numerical/invalid inputs, replace by the constant construction
\[
\text{fallback}(n,n even)=0.5\cdot \mathbf{1}_n;
\]
if first supplied after making length even, use length 120 and constant 0.5.

The target passed to this repair must always be the runtime length `/2`, never a hardcoded 60.

2.3 Correlation gradients for arbitrary lag coefficients

For a coefficient array \(\beta_r\) for the existing output order, define
\[
G(h,\beta)=\sum_r \beta_r \nabla_h Q_r(h).
\]
At \(G\)'s output orientation, assemble by lag distance:
- distance zero coefficient \(w_0=\beta_{n-1}\);
- for distance \(d\), \(a_d=\beta_{n-1+d}\), \(b_d=\beta_{n-1-d}\).
Naive row formulation:
For zero lag:
\[
\nabla Q_0=dx(1-2h).
\]
For positive \(d\),
\[
\nabla Q_{+d}:
\begin{cases}
- dx\,h_{i+d}, & i=0,\dots,n-d-1,\\
+dx(1-h_{i-d}), & i=d,\dots,n-1.
\end{cases}
\]
For negative \(-d\),
\[
\nabla Q_{-d}:
\begin{cases}
+dx(1-h_{i+d}), & i=0,\dots,n-d-1,\\
-dx\,h_{i-d}, & i=d,\dots,n-1.
\end{cases}
\]
Efficient implementation: start \(g=dx*w_0*(1-2h)\). For \(d=1..n-1\), let left length be \(n-d\). Add
\[
g[:n-d]+=dx(-a_d*h[d:]+b_d*(1-h[d:]))
\]
\[
g[d:]+=dx(a_d*(1-h[:n-d])-b_d*h[:n-d]).
\]
This computes exactly the derivative of a weighted sum of correlation rows. The orientation chosen by the validation test must agree; if a mismatch is found by testing a random feasible direction with finite differences, swap the assigned roles of \(a_d\) and \(b_d\) and retest; stop gradient optimization if the mismatch remains.

Finite-difference validation helper: on runtime-generated (not hardcoded) random feasible h and a random direction z whose nullspace mean is removed, for a lag whose row coefficient is 1 and all others zero, perturb h by ±1e-6 and compare directional finite difference with coefficient-summed aggregate gradient row. Required tolerance about \(1e-8\) for small test dimension.

2.4 Smooth surrogate and its gradient

For a smoothing width \(\tau>0\), define numerically stable
\[
F_\tau(h)=M(h)+\tau\log\sum_r\exp((Q_r(h)-M(h))/\tau),
\qquad M=\max_r Q_r,
\]
where exponent arguments are clipped from below to avoid underflow, typically by comparing to \(M\) and using
\[
u_r=\max((Q_r-M)/\tau,-745).
\]
Let
\[
w_r=\exp(u_r)/\sum_s\exp(u_s).
\]
If the denominator underflows or becomes zero due to numerical failure, use a fallback unit weight on every lag tied at current maximum (or top five lags), which is a stable limitation claim only for the surrogate; exact calculations remain unchanged.

Analytic gradient:
\[
\nabla F_\tau(h)=\sum_r w_r\nabla Q_r,
\]
which can be produced by the aggregate-gradient helper with coefficient vector \(\beta=w\). Scale is not divided here because the surrogate objective scale is already O(0.38).

This surrogate has bias \(F_\tau-C\in[0,\tau\log(2n-1)]\). That bias is only a heuristic local guide; every final accepted candidate is evaluated by exact \(C(h)\), usually only after joint projection.

2.5 Target-deficit penalty model and its gradient

Given a current controlled candidate with exact score \(v\) and a proposed target \(T=v-\delta\), use margin width \(\eta>0\) and define
\[
\Psi_{T,\eta}(h)=\frac{1}{2n-1}\sum_r \eta\log\left(1+\exp\left(\frac{Q_r-T}{\eta}\right)\right).
\]
The value and stability calculate `(Q-T)/eta` after clipping (approximately `[-745, 745]`). Use logistic weights:
\[
\sigma_r=\operatorname{sigmoid}((Q_r-T)/\eta).
\]
The objective’s scalar derivative is zero for all active constant \(T\), so
\[
\nabla\Psi_{T,\eta}=\frac{1}{2n-1}\sum_r \sigma_r \nabla Q_r.
\]
Use the same aggregate-gradient helper and pass normalized score. If objective is too noisy/saturates, multiply by \(\eta\) internally. Smaller \(\eta\) gives sharper focus on violations near target; large \(\eta\) is more global and can escape predicated local plateau. Success or low surrogate value never establishes exact attainment of \(T\); all candidate returns are accepted only after exact C(h) checks.

2.6 Feasible perturbations and transformations

- Random subspace/permutation move: draw `z`; set `z -= z.mean()`; candidate raw `h + a*z`; project.
- Modes of feasible candidate: `1-h`, `h[::-1]`, `1-h[::-1]`; feasible because sum/bounds preserved in exact arithmetic and float bounded if input is.
- Circular or circular shifts (`np.roll`) leave sum exactly, but bounds remain inside [0,1] so are feasible; exact objective likely different. Produce four rolls by small counts and one more random if time.
- Fourier/fast low-pass: robust low-pass approximation same length without scipy: pad with edge values, convolve with `[0.25,0.5,0.25]`; then project box-sum.
- Binary candidates: for thresholds θ = 0.1,0.25,0.5,0.75,0.9 choose `b=(h>θ)`, project. Because sum is not generally n/2, make sum-step feasibility from projection. Also continuous mixings `a*b+(1-a)*h` for a∈{0.25,0.5,0.75}, then project.
- For parent length not feasible/nonlocal, first project flat for parent plus same transformations.
- Reduction/growth:
  * exact repeat upscale by integer factor m: `np.repeat(h,m)` preserves sum exactly relative to new target;
  * noninteger growth or interpolation: sample old grid midpoints and new grid midpoints in [0,2), linearly interpolate `h_float`, project;
  * averaged downscale if length divisible by m: reshape and average groups, bounds/sum preserved to rounding, then project if necessary.
Dim style: retain parent behavior but per-step use custom kernel the resolution not equivalent mathematical one. It simply provides geometrically distinct candidates for each length, and the reported length is current regardless.
