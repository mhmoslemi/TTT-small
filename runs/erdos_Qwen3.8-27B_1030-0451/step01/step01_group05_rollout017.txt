Let me think about the line search more carefully. The feasible interval for d is:
- `d_lo = max(-h[a], h[b]-1)`
- `d_hi = min(1-h[a], h[b])`

If `d_lo >= d_hi`, the pair is infeasible (already at bound).

The function to minimize is `f(d) = dx * max_k (raw[k] + d*lin[k] + d^2*quad[k])`.

Since `quad` is nonzero at only 3 positions, I can separate:
- The "background" max: `max_{k: quad[k]=0} (raw[k] + d*lin[k])` - this is the max of lines, hence convex.
- The 3 "special" quadratics: `raw[k] + d*lin[k] + d^2*quad[k]` for k in {center, center+(a-b), center+(b-a)}.

The overall f(d) = max(background_max(d), special1(d), special2(d), special3(d)).

For the background, since it's a max of lines, its minimum is well-behaved (the "lower envelope" of the upper bound of lines). For the special quadratics, they can dip below the background (if quad[k] < 0, i.e., at center where quad=-2) or rise above (if quad[k] > 0).

At the center (k=n-1), quad=-2, so the special quadratic is `raw[center] + d*lin[center] - 2d^2`, which is a downward parabola. This means at the center, the overlap DECREASES quadratically with d. This makes sense: increasing h[a] and decreasing h[b] both reduce the self-overlap h[i](1-h[i]) at their respective positions.

At the cross positions, quad=+1, so the overlap INCREASES quadratically. This means moving mass creates new overlap at those specific shifts.

The competition between these effects determines the optimal d.

For the line search, I'll use:
1. Coarse grid: 31 points over [d_lo, d_hi].
2. Find the best point.
3. Fine grid: 31 points over a small neighborhood of the best (or golden section).
4. Return the best.

            lo = mid
        else:
            hi = mid
    mu = (lo + hi) / 2.0
    h = np.clip(z - mu, 0.0, 1.0)

        cnt = int(np.sum(interior))
        if cnt > 0:

    L = 2 * n - 1
    center = n - 1
    col = np.zeros(L)

    col[i:i+n] += 1.0 - h[::-1]
    # Second part: h[i] in (1-h[n]), valid k in [center-i, 2n-2-i]
    col[center-i:2*n-1-i] -= h
    return col

        d = (d_lo + d_hi) / 2.0
        val = raw + d * lin + d * d * quad
        return d, float(np.max(val))
    
    # Coarse grid
    ds = np.linspace(d_lo, d_hi, n_grid)

            m = np.max(val)
            if m < best_val:
                best_val = m
                best_d = d
