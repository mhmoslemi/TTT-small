(We're doing h[i] += δ, h[j] -= δ)

To find the optimal δ for min max_k (a_k + δ*b_k):
This is a 1D LP. The optimal solution is at a "vertex" which is either a bound or an intersection of two constraints.

Efficient method: 
- Sort the b_k values.
- Walk through them maintaining the active constraint.
- Actually, the simplest is: the optimal δ satisfies that at the optimum, at least two constraints are tight (or one constraint is tight and it's the best single one).

For O(m) constraints (m = 2n-1 lags), the 1D LP can be solved in O(m log m) time using the fact that it's equivalent to finding the lower envelope of lines.

But for simplicity, I'll use a ternary/binary search approach:
- The function f(δ) = max_k (a_k + δ*b_k) is convex (max of linear functions).
- We can find its minimum by ternary search or by binary search on the subgradient.

Binary search on subgradient:
- f'(δ) (subgradient) = max_k b_k where a_k + δ*b_k = f(δ) (i.e., the b of the active constraint).
- Actually, the subgradient of f at δ is {sum α_k b_k : α_k ≥ 0, sum α_k = 1, α_k > 0 only if a_k + δ*b_k = f(δ)}.
- f is minimized when 0 ∈ subgradient, i.e., when there exist active constraints with both positive and negative b_k (or a single one with b_k = 0).

So: binary search for δ such that the maximum active b_k ≥ 0 and the minimum active b_k ≤ 0.

More precisely: 
- At δ, let A(δ) = {k : a_k + δ*b_k = max_j (a_j + δ*b_j)}.
- If min_{k∈A} b_k > 0: increase δ (the max is increasing, we can reduce it by going left).
  Wait, if all active b_k > 0, then for δ' > δ, all active values increase, so f(δ') > f(δ). So we should decrease δ.
- If max_{k∈A} b_k < 0: decrease δ.
- Otherwise (some active b_k > 0 and some < 0, or all = 0): we're at the optimum (or very close).

This gives a clean binary search!

At each iteration of the binary search, we need to:
1. Compute f(δ) = max_k (a_k + δ*b_k) → O(m)
2. Find the active set A(δ) → same pass

        alpha[active] = 1.0 / np.sum(active)

        e = np.exp(a)
        s = np.sum(e)
        alpha = e / s

        else:

            grad[dd:] += ak * dx * (1.0 - h[:n-dd])
            grad[:n-dd] -= ak * dx * h[dd:]
    
    return grad

- If 0 ≤ i ≤ n-1-dd: h[i] appears as h[t-dd] with t=i+dd, contributes -h[i+dd]

So:
- For 0 ≤ i < dd: only second term: -h[i+dd]
- For dd ≤ i ≤ n-1-dd: both: (1-h[i-dd]) - h[i+dd]
- For n-1-dd < i ≤ n-1: only first: (1-h[i-dd])

Now, for a specific pair (i, j) and all lags:

I can compute b_k for each k (or equivalently for each d = k - (n-1)):

For d = 0: b = (1-2h[i]) - (1-2h[j]) = 2*(h[j] - h[i])

For d > 0:
∂c_d/∂h[i]:
  if i < d: (1-h[i+d])
  elif i ≤ n-1-d: (1-h[i+d]) - h[i-d]
  else: -h[i-d]

∂c_d/∂h[j]: same formula with j instead of i.

For d < 0, dd = -d:
∂c_d/∂h[i]:
  if i < dd: -h[i+dd]
  elif i ≤ n-1-dd: (1-h[i-dd]) - h[i+dd]
  else: (1-h[i-dd])

This is O(1) per (d, coordinate) pair, so O(n) per pair of coordinates for all lags.

Total for pair_line_search: O(n) to compute b_k, then O(n * log(precision/range)) for the ternary search.

def pair_line_search(h, i, j, C, dx):
    n = len(h)
    # Compute b_k = dC_k/dh[i] - dC_k/dh[j] for all k
    # C_k = c_k * dx, so dC_k/dh[i] = dx * dc_k/dh[i]
    
    b = np.zeros(2*n - 1)
    ctr = n - 1
    
    for k in range(2*n - 1):
        d = k - ctr
        # Compute dc_d/dh[i] and dc_d/dh[j]
        bi = _dc_dh(d, i, h, n)
        bj = _dc_dh(d, j, h, n)
        b[k] = dx * (bi - bj)
    
    # Ternary search for min of max(C + delta * b) over delta in [dl, du]
    dl = max(-h[i], h[j] - 1.0)
    du = min(1.0 - h[i], h[j])
    if dl >= du:
        return 0.0, float(C[i])  # no feasible move
    
    # Ternary search
    for _ in range(80):
        m1 = dl + (du - dl) / 3.0
        m2 = du - (du - dl) / 3.0
        f1 = np.max(C + m1 * b)
        f2 = np.max(C + m2 * b)
        if f1 < f2:
            du = m2
        else:
            dl = m1
    
    delta = 0.5 * (dl + du)
    return delta, float(np.max(C + delta * b))

Wait, is it? The c_k(h) as a function of δ (when h[i]+=δ, h[j]-=δ):
c_k(δ) = c_k(0) + δ * (∂c_k/∂h[i] - ∂c_k/∂h[j])

Is c_k linear in δ? Let's check:
c_k = sum_{valid t} h[t] * (1-h[t+d])

When we change h[i] += δ and h[j] -= δ:
- If t = i: h[i+δ] * (1-h[i+d]) → (h[i]+δ)(1-h[i+d])
- If t+d = i (i.e., t = i-d): h[i-d] * (1-(h[i]+δ)) → h[i-d](1-h[i]-δ)
- If t = j: (h[j]-δ) * (1-h[j+d])
- If t+d = j: h[j-d] * (1-(h[j]-δ)) → h[j-d](1-h[j]+δ)

So:
c_k(δ) = c_k(0) + δ*(1-h[i+d]) - δ*h[i-d] - δ*(1-h[j+d]) + δ*h[j-d]
= c_k(0) + δ*[(1-h[i+d]) - h[i-d] - (1-h[j+d]) + h[j-d]]
= c_k(0) + δ*[∂c_k/∂h[i] - ∂c_k/∂h[j]]

Yes! c_k is linear in δ for a pair move. So the 1D search is exact (not just a linear approximation). The function f(δ) = max_k c_k(δ) is the max of linear functions, which is convex, and the ternary search will find its minimum exactly.

import numpy as np
import time

def exact_C5(h):
    if len(h) == 0:
        return 0.0
    dx = 2.0 / len(h)
    c = np.correlate(h, 1.0 - h, "full") * dx
    return float(np.max(c))

def make_feasible(x, target):
    n = len(x)
    x = np.asarray(x, dtype=float).ravel()
    if not np.all(np.isfinite(x)):
        x = np.full(n, target / n)
    x = np.clip(x, 0.0, 1.0)
    # Find shift lambda: want sum(clip(x - lambda, 0, 1)) = target
    # This is monotonically decreasing in lambda
    lo = -1.0 - float(np.max(x))
    hi = 1.0 - float(np.min(x))
    for _ in range(100):
        mid = 0.5 * (lo + hi)
        s = float(np.sum(np.clip(x - mid, 0.0, 1.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    x = np.clip(x - 0.5 * (lo + hi), 0.0, 1.0)
    # Fix any residual
    diff = target - float(np.sum(x))
    if abs(diff) > 1e-12:
        # Simple fix: adjust one element
        if diff > 0:
            idx = np.argmin(x)
            x[idx] = min(1.0, x[idx] + diff)
        else:
            idx = np.argmax(x)
            x[idx] = max(0.0, x[idx] + diff)
    return x

def compute_C(h):
    dx = 2.0 / len(h)
    return np.correlate(h, 1.0 - h, "full") * dx

def dc_dh_single(d, idx, h, n):
    """Compute dc_d/dh[idx] for lag d."""
    if d == 0:
        return 1.0 - 2.0 * h[idx]
    elif d > 0:
        if idx < d:
            return 1.0 - h[idx + d]
        elif idx <= n - 1 - d:
            return (1.0 - h[idx + d]) - h[idx - d]
        else:
            return -h[idx - d]
    else:
        dd = -d
        if idx < dd:
            return -h[idx + dd]
        elif idx <= n - 1 - dd:
            return (1.0 - h[idx - dd]) - h[idx + dd]
        else:
            return 1.0 - h[idx - dd]

def compute_subgradient(h, tau, dx):
    """Compute the gradient of the smooth max approximation."""
    n = len(h)
    C = np.correlate(h, 1.0 - h, "full") * dx
    Cmax = float(np.max(C))
    
    if tau < 1e-14:
        # Hard active set
        active = C >= Cmax - 1e-10
        cnt = float(np.sum(active))
        if cnt == 0:
            active = np.zeros_like(C)
            active[int(np.argmax(C))] = 1.0
            return active * _raw_grad_one(h, n)  # won't work like this
        alpha = np.zeros_like(C)
        alpha[active] = 1.0 / cnt
    else:
        a = (C - Cmax) / tau
        e = np.exp(a)
        s = float(np.sum(e))
        alpha = e / s
    
    # Compute weighted sum of gradients
    grad = np.zeros(n)
    ctr = n - 1
    for k in range(2 * n - 1):
        ak = float(alpha[k])
        if ak < 1e-14:
            continue
        d = k - ctr
        coeff = ak * dx
        if d == 0:
            grad += coeff * (1.0 - 2.0 * h)
        elif d > 0:
            grad[:n-d] += coeff * (1.0 - h[d:])
            grad[d:] -= coeff * h[:n-d]
        else:
            dd = -d
            grad[dd:] += coeff * (1.0 - h[:n-dd])
            grad[:n-dd] -= coeff * h[dd:]
    
    return grad

def pair_line_search(h, i, j, C, dx):
    """Find optimal delta for h[i]+=delta, h[j]-=delta using exact 1D search."""
    n = len(h)
    ctr = n - 1
    
    # Compute b_k = dC_k/dh[i] - dC_k/dh[j]
    b = np.zeros(2 * n - 1)
    for k in range(2 * n - 1):
        d = k - ctr
        bi = dc_dh_single(d, i, h, n)
        bj = dc_dh_single(d, j, h, n)
        b[k] = dx * (bi - bj)
    
    # Feasible range for delta
    dl = max(-h[i], h[j] - 1.0)
    du = min(1.0 - h[i], h[j])
    if dl >= du - 1e-15:
        return 0.0, float(np.max(C))
    
    # Ternary search (80 iterations for high precision)
    for _ in range(80):
        m1 = dl + (du - dl) / 3.0
        m2 = du - (du - dl) / 3.0
        f1 = float(np.max(C + m1 * b))
        f2 = float(np.max(C + m2 * b))
        if f1 <= f2:
            du = m2
        else:
            dl = m1
    
    delta = 0.5 * (dl + du)
    best_val = float(np.max(C + delta * b))
    return delta, best_val

def subgradient_descent(h, deadline, n_iters=100):
    n = len(h)
    target = 0.5 * n
    dx = 2.0 / n
    C = compute_C(h)
    best_c = float(np.max(C))
    best_h = h.copy()
    
    tau = 0.1
    v = np.zeros(n)
    momentum = 0.7
    
    for it in range(n_iters):
        if time.time() > deadline:
            break
        
        g = compute_subgradient(h, tau, dx)
        
        # Step size: start large, decay
        lr = 2.0 / (np.linalg.norm(g) + 1e-10) * 0.5
        lr = min(lr, 0.1)
        
        v = momentum * v + lr * g
        h_new = make_feasible(h - v, target)
        
        C_new = compute_C(h_new)
        c_new = float(np.max(C_new))
        
        if c_new < best_c:
            best_c = c_new
            best_h = h_new.copy()
            h = h_new
        else:
            # Rejected: reduce step
            lr *= 0.5
            h_new = make_feasible(h - 0.5 * v, target)
            C_new = compute_C(h_new)
            c_new = float(np.max(C_new))
            if c_new < best_c:
                best_c = c_new
                best_h = h_new.copy()
                h = h_new
        
        tau *= 0.95
    
    return best_h, best_c

def pair_search_optimize(h, deadline, rng, max_stall=30):
    n = len(h)
    target = 0.5 * n

    C = compute_C(h)
    best_c = float(np.max(C))
    best_h = h.copy()
    stall = 0

        cur_c = float(np.max(C))

            best_h = h.copy()
        
        # Compute subgradient for pair selection (use small tau for near-exact)
        g = compute_subgradient(h, 0.005, dx)

        pairs = []
        for kk in range(5):

            j = int(order[n-1-kk])

def downsample(h, n_new):
    n_old = len(h)
    if n_new == n_old:
        return h.copy()
    # Nearest-neighbor style
    idx = np.round(np.arange(n_new) * n_old / n_new).astype(int)
    idx = np.clip(idx, 0, n_old - 1)
    h_new = h[idx]
    return make_feasible(h_new, 0.5 * n_new)

def upsample(h, n_new):
    n_old = len(h)
    if n_new <= n_old:
        return downsample(h, n_new)
    x_old = (np.arange(n_old) + 0.5) * (2.0 / n_old)
    x_new = (np.arange(n_new) + 0.5) * (2.0 / n_new)
    h_new = np.interp(x_new, x_old, h)
    return make_feasible(h_new, 0.5 * n_new)
