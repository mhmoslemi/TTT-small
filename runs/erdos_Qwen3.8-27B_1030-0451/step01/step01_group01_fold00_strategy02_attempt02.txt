1. Approach and rationale

1.1 Central idea

Build a direct-objective, population-based intelligent search that, at all times, obtains and ranks candidate vectors only from the *exact* task metric
`C(h) = max(np.correlate(h, 1.0 - h, mode="full") * dx)`, with no surrogate objective around the main selection loop.

The important change relative to the supplied prior program (and the high-level target-violation / LP-trust / SLSQP framing) is that the fine polishing mechanism is not a linearization, log-sum-exp surrogate, smooth objective, block LP, or a separate target threshold `tau` feasibility problem. Instead it is a family of *strict one-dimensional pairwise subproblems* that are solved directly on the exact objective path. For each pair `(i,j)` with preserved pair sum `s = h_i + h_j`, we replace the admissible range of the single coordinate `p = h_i` by `q = s-p` and minimize the original maximum correlation on that feasible line, while all other grid values remain fixed.

This is not a convex global claim about the original problem. The global problem remains nonconvex. However, the one-dimensional objective path induced by a pair-preserving line has a very useful structural property: every correlation component along the line is affine or a convex quadratic, therefore the componentwise maximum is convex. Consequently, a bounded scalar minimizer (e.g. golden-section elimination) is expected to find the global minimizer on that line to numerical tolerance. This gives a genuinely local-exact improvement mechanism that can push far below a merely `1e-2`-step coordinate perturbation, while preserving harvested global diversification.

1.2 Why this can improve the parent

The parent reports `C5 = 0.381072` and target is `0.3808`. The gap is tiny. The high-probability source of small but decisive gains is exact local descent through the continuum of sample values, not only integer or discrete block mutations. The previous program focused heavily on smooth/large-scale surrogate mechanisms; this plan adds new precise local exploration: pair-preserving exact descent. The global population side exists because a single start is often trapped in a pair-line-stationary point. A population of diverse vector basins, blind moves, and difference-based variation supplies perturbation starts; immediate exact pair descent turns many of those additional starts into better local optima. If the global search fails or time expires, returning parent remains possible and is guaranteed to preserve any discovered improvement.

2. Mathematical specification

2.1 Grid representation and exact task objective

Let `n` be the configured current grid length. We represent a candidate as an array

```text
h = {h[0], h[1], ..., h[n-1]},  dx = 2.0 / n
```

For every candidate the authoritative scalar objective is computed exactly as

```text
C5_exact(h) = np.max(np.correlate(h, 1.0 - h, mode="full")) * (2.0 / n)
```

and the evaluation returns this scalar. The two-sided correlation computation is required; do not only compute autocorrelation or replace it with `1 - min autocorr`.

Numpy `np.correlate` releases a correlation output vector with exactly `2n - 1` finite contributions, corresponding to both positive and negative lags, with the finite-support boundary counts. No periodic closure is used. If measured program-grade bugs expected confusing, memory concern immediately uses.
