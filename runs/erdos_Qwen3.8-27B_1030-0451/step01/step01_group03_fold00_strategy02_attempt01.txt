1. Approach and rationale
====================

The central idea is to replace broad smooth-minimax surrogates with an exact active-set, minimax Newton/SQP step built from the actual original discrete correlation objective. The supplied parent is already in a difficult local plateau. A smoothed maximum objective sees a broad average of near-active lags, and many of its descent directions are filtered away or made misleading by inactive constraints and boundary effects. The new primary solver uses the exact worst lags, their exact bilinear gradients, and a small convex trust-region subproblem whose predicted lowering of those exact worst correlations is the only reason to move. Every proposed direction is then accepted only after full exact re-evaluation of the true evaluator. This addresses the dominant bottleneck: previous behavior tends to decrease the smooth objective slowly while staying on a higher plateau in the exact max objective, or to stall because the smooth equalization leaves the local active max constraints unsatisfied or mis-predicted.

This remains a local NLP method and does not claim global optimality. It is different from standard SLSQP on a log-sum-exp smoothing and different from generic simulated annealing/random smoothing in the following substantive ways:

- The subproblem is formulated directly over the actual active lags and exact local linearization of the exact evaluator.
- A step is accepted by exact, full, two-sided linear correlation evaluation, not by the provisional active-set surrogate.
- Steps are generated as linearized minimax directions with sum preservation and bounds, so candidates stay structurally feasible.
- Multiple resolutions are tried with explicit midpoint interpolation and re-feasibilization for exact-compared objective values.

Secondary exploration uses value-preserving deterministic rerankings, but these are subordinate to the primary active-set SQP descent.

2. Mathematical specification
=============================

Representation
---------------

Let `n = n_points`, `dx = 2.0 / n`. The evaluator uses

    C_exact(h) = max_lag_k  dx * sum_i h_i * (1 - h_{i+d})

with all lags both positive and negative represented by the full real-valued linear correlation

    Cvec = np.correlate(h, 1.0 - h, mode="full") * dx
    C_exact = max(Cvec)

The lag vector has length `2n - 1`. Index `ℓ ∈ {0, ..., 2n-2}` corresponds to integer displacement

    d = ℓ - (n - 1).

For displacement d, valid source indices are

    i_lower = max(0, -d)
    i_upper = min(n - 1, n - 1 - d)

where all indices are non-negative and both `i` and `i + d` lie in `[0, n-1]`.

Feasible set
------------

A returns vector must satisfy:

    0 <= h_i <= 1 for all i
    sum_i h_i = n / 2

The equivalence follows from `sum(h) * dx = 1`. If the parent supplied by the runtime is odd-length, first form a nearby even length by interpolating it to the nearest adjacent even length, then repair. The output length is always the length of the returned vector, so no odd-length return is produced. If no parent is supplied, start from an even fallback length 240.

Original evaluation contract
----------------------------

No simplified objective may be used for acceptance. The only score for a candidate is exact `C_exact(candidate_h)` recomputed with `np.correlate(candidate_h, 1-candidate_h, "full") * dx`.

Exact gradient of a single lag
-------------------------------

For each displacement d and index ℓ = d + n - 1,

    C_ℓ(h) = dx * Σ_{i=i_lower}^{i_upper} h_i (1 - h_{i+d}).

The gradient satisfies

    ∂C_ℓ/∂h_i = dx * (1 - h_{i+d})
    ∂C_ℓ/∂h_{i+d} = -dx * h_i

for all valid pairs. A row of the exact Jacobian for this nonzero integer lag is built directly from this formula, with all invalid boundary indices excluded.

Exact local min-max step
------------------------

At a feasible point `h`, compute

    C = C_vector(h)
    m = max(C)
    old_score = m

Select a set A of active correlations. Initially, and continuously, A must include the current argmax lag and all lags satisfying

    C_ℓ >= m - gap_tol

up to a maximum number `K_max`. The constant `gap_tol` decreases over restarts as described below. Define normalized active gap

    b_ℓ = m - C_ℓ  <= 0.

We search for a tangent direction `d_vec` and scalar `z` such that, linearly for the active lags,

    C_ℓ + g_ℓ · d_vec <= m + z.

Equivalently,

    g_ℓ · d_vec - z <= b_ℓ,  ℓ ∈ A.

The step direction is constrained by

    Σ_i d_i = 0
    -Δ <= d_i <= Δ

where Δ is a step-size trust region. `z` is the predicted lowering of the active maximum. A negative predicted `z` or some value smaller than currently attained corresponds to predicted descent.

Linearized minimax trust-region subproblem with linprog
Req
Represent

    d_i = p_i - q_i, p_i >= 0, q_i >= 0,

and enforce

    |d_i| <= Δ by dp + dn <= Δ (Linprog as standalone bound variable factorization linear with constraints, including lower bounds; variables p, q can be paired with upper constraints through a mapping optional, but keeping Δ individually retained simpler method: enforce p_i <= Δ and q_i <= Δ and dp_i + q_i <= Δ through row-bound? The latter row is linear and maintains allowed absolute when dp*+dn* chosen from previous dir. This remains constraints; better no equality, because penalty discourages simultaneous P/Q start.)

A linear LP subproblem is therefore:

    minimize   z + η Σ_i (p_i + q_i)

subject to, for all active ℓ:

    Σ_i g_{ℓ,i} p_i - Σ_i g_{ℓ,i} q_i - z <= m - C_ℓ

subject to:

    Σ_i p_i - Σ_i q_i = 0
    0 <= p_i <= Δ
    0 <= q_i <= Δ
    q_i ∈ [0,Δ]
    p_i + q_i <= Δ

subject to z ∈ [ -zlimit, 0].

This is a convex piecewise-linear LP: objective is affine plus linear L1 penalty; constraints are linear. `η` can be zero; with `η=0` it is a pure Chebyshev minimax linear reduction. Use small `η > 0` to discourage the arbitrary back-and-common bound. The raw gradient entries are O(dx) and small; do not rescale only constraints while leaving objective unscaled unless the identical scaling is mathematically equivalent. For stability, `scipy.optimize.linprog` default preprocessing should be used. If high fails, retry with alternate SciPy method available on the installation. The solver never sees the nonlinear product constraints; it sees only the linearized inactive/active-veto directional equations. That is accepted as heuristic, not proof.
