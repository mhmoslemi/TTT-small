Actually, the cleanest approach for this problem is:

**Coordinate descent with "compensating" updates.**

When I change h[j] from c to t, the sum changes by (t-c). To compensate:
- If t > c: I need to decrease some other coordinate(s) by (t-c) total.
- If t < c: I need to increase some other coordinate(s) by (c-t) total.

The "best" compensating coordinate is the one that minimizes the increase in the objective. This is a 2D subproblem (optimize h[j] and h[j'] with the constraint h[j] + h[j'] = c + c').

For a 2D subproblem:
min_{t, t'} max_k (O[k] + (t-c)*a_k + (t'-c')*a'_k)
subject to t + t' = c + c', 0 ≤ t ≤ 1, 0 ≤ t' ≤ 1.

Since t' = c + c' - t, this becomes:
min_t max_k (O[k] + (t-c)*a_k + (c+c'-t-c')*a'_k)
= min_t max_k (O[k] + (t-c)*(a_k - a'_k) + (c'-c)*a'_k)
= (c'-c)*a'_k is constant for each k...

t' - c' = (c + c' - t) - c' = c - t = -(t - c).

So: (t-c)*a_k + (t'-c')*a'_k = (t-c)*a_k + (c-t)*a'_k = (t-c)*(a_k - a'_k).

So the 2D problem reduces to:
min_t max_k (O[k] + (t-c)*(a_k - a'_k))
subject to t ∈ [max(0, c+c'-1), min(1, c+c')].

This is the same 1D problem! With the coefficient (a_k - a'_k) instead of a_k.

So the "compensating coordinate descent" is:
1. Pick a pair (j, j').
2. Compute a_k (for j) and a'_k (for j').
3. Solve the 1D problem with coefficient (a_k - a'_k).
4. Update both coordinates.

This maintains the sum constraint exactly!
