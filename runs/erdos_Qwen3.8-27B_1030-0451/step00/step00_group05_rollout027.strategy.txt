1. Approach and rationale

1.1 Central idea

The target problem is a discrete constrained minimax nonlinear optimization:

- decide `h_i` for `i = 0, ..., n-1` in the box `0 <= h_i <= 1`;
- enforce the exact mass constraint `sum_i h_i = n/2`;
- minimize the maximum over all finite-support lags of `dx * corr(h, 1-h)` on the exact output produced by `np.correlate(h, 1-h, mode="full")`.

The supplied parent profile is already close to the published upper-bound record. The likely remaining improvement is therefore a local polish: reduce a small number of dominant lag correlations without increasing any other lag above the new maximum. The optimization direction should use gradients of the active (largest) lag constraints, while acceptance is made by the original exact evaluator.

I propose a materially self-contained algorithm called TMDR: Top-Max Directional Ratchet. Its central components are:

1. exact discrete feasibility repair using projection onto the capped simplex;
2. exact evaluation using the task's finite-support linear correlation;
3. analytic gradient accumulation for a smoothed/top-active surrogate that contains only the largest correlations, with a proper finite-support lag sign convention;

1. Approach and rationale

1.1 Central idea

The problem is to discretize the overlap profile as a vector `h` of length `n`, with

`0 <= h[i] <= 1`, `sum_i h[i] = n/2`, `dx = 2/n`,

and minimize the exact finite-support maximum

`C5(h) = max_k dx * np.correlate(h, 1 - h, mode="full")[k]`.

The supplied parent construction at about `n=131` is likely close to a local optimum at the published bound `~0.38085`. The remaining target `<=0.3808` is about `5e-6` tighter, so the main missing ingredient is a more finely targeted local move that can adjust several nearly tied maximum lag constraints simultaneously without letting another lag become the new maximum.

The proposed algorithm is TMDR: Top-Max Directional Ratchet.

The core is a local descent mechanism with the following essential differences from simple projection, smoothing, or generic random search:

1. It computes an analytic finite-support gradient of the largest correlation terms using the exact `np.correlate` lag sign convention.
2. It chooses top-active correlation output indices with decaying exponential weights and takes a projected descent direction for that weighted top-active surrogate; this is a surrogate only for candidate generation. The accepted best solution is always selected by the unsimplified original objective.
3. It uses non-monotone local state updates: the global best is updated only when the exact objective improves, but the running local state may temporarily accept a small exact increase if the smoothed top constraint value decreases, while bounded above by an explicit exact allowance. This helps walk across exact plateau boundaries that are common near the record profile.
4. It stores and refines a deduplicated pool of feasible candidates by exact score, not by the surrogate, and records the best feasible parent or generated vector for fallback.
5. It allows nearby resampled target resolutions, because exact discrete support can slightly lower the discrete objective. Candidate resolution changes are judged by exact evaluation, not by a global substitution.
6. It has deterministic timing and deadline termination, so the function returns a feasible weighted candidate before the budget expires, never something infeasible or uncalled.

The method is local and nonconvex. It is not a certified global optimum. The justification is precise: the feasible set defined by a box and one equality is convex, and each correlation value is continuously differentiable in the vector interior with a piecewise smooth structure on the boundary. The smoothed maximum approximation is a smooth surrogate for the non-smooth exact max. No convexity needs to be claimed for the full minimax subproblem. Every final candidate is tested by the task's evaluator-aligned objective.

1.2 Why this can improve the supplied parent

Near `0.38085`, the relevant top correlations are typically not singletons. Repeatedly lowering a single largest lag often raises a neighboring lag, causing a staircase or flat floor. The top-active surrogate smooths groups of top lags that are within a current temperature of the local maximum. Its gradient gives a coordinated move that pushes down all relevant top correlations in proportion to their present importance. The exact acceptance chooses successful outcomes. Reversal and near-length resolution candidates offer alternate discrete basins, with the current parent always retained when it is feasible.

1.3 Limitations and factual bounds

- This is heuristic local and global-search usage without a global proof of optimality or feasibility completeness.
- The local weighted-descent gradient is derived from the exact finite-support correlation expression and verified internally by finite-difference checks over the current active top-region. Even if the check fails, exact candidate evaluation still produces assumption-free rejection/acceptance. The global best output is always repaired and re-evaluated before return.
- The exact feasible constraints are enforced through projection; clip and rescaling are not done independently. Full explanation is in section 3.
- Any proposal is used to store only if it passes exact corrected feasibility, finite range, and finite correlations. The returned objective is recomputed with `np.correlate` after the array is finally repaired.

2. Mathematical specification

2.1 Exact vector representation and discrete objective

For the return vector

`h = h[:n]`, `n = n_points >= 3`,

the integration mesh is

`x_i = 2*i/n`, `dx = 2/n`,

and the feasible conditions are

`0 <= h[i] <= 1` for all `i`, and `sum(h) = n/2`.

The task function objective is only minimization of the max lag value. Define

`u[i] = 1 - h[i]`, `full = np.correlate(h, u, mode="full") * dx`,

with `full` length `2*n - 1`. The candidate score is `max(full)`. Use exactly this result; do not use circular correlation. Do not ignore either lag sign. All candidates must include all `2n -1` lags.

For indexing of orientation: full has center index `c0 = n - 1`. The lag offset is `r = k - c0`. In raw correlation terms:

* positive lag `R`, `1 <= R <= n - 1`:

`Y_plus_R = sum_{i=0}^{n-1-R} h[i+R] * (1 - h[i])`

* zero lag:

`Y0 = sum_i h[i] * (1 - h[i]) = sum_i (h[i] - h[i]^2)`

In full, index `c0 + R` contains positive lag `R`, and index `c0 - R` contains negative lag `R`.

For the corresponding negative lag scalar output, which is not the same value generally, the raw expression is:

`Y_minus_R = sum_{i=0}^{n-1-R} h[i] * (1 - h[i+R])`.

Multiply each expression by `dx` to get the lag objective value.

2.2 Exact active smoothed surrogate and gradient

Let `C[k]` denote the exact scaled correlation value at the full output index. The pointwise max is nonsmooth; use an exponential top window to form a gradient surrogate. Maintain a temperature `T > 0`, window width `W_active` and top cap `K_active`. Define top active indices as the indices whose values lie within `W_active` of the maximum, of which at most `K_active` are used if there are more than enough ties. A concrete mapping:

* Find active values `C_i >= M - L_active`.
* Take highest entries if more than `K_active`, accumulating a small allowance `slack` that might equal an active ceiling threshold.
* Handle ties by index only for deterministic order.

For active indices, compute relative normalized weights

`z_i = (C_i - max(C_i in active)) / T`,
`B_i = exp(-max(0, max_active - C_i) / T)`, and after the exponent and normalization,

`p_i` are positive probabilities on the selected top indexes, total normalized to sum `1`.

The active-smoother score for step generation is

`F_active(h) = sum_i p_i * C_i`,

where `p` is fixed during the directional calculation for that round. `F_active` is a sectionally smooth function. Its exact scaled gradient has contributions to each `h[j]` from all active pairs. Use a temporary map of weights:

* For zero full index containing `p0 = p[index0]`:

`G0[j] = p0 * dx * (1 - 2*h[j])`.

* For each positive lag output weight `wp` at index `c0 + R`, active pair interval `i = 0,...,(n-1-R)`:

Let `a[i] = h[i]` and `b[i] = h[i+R]`. Add to the low side:

`dv0 += - dx * wp * b`.

Add to the high side:

`dvR += dx * wp * (1 - a)`.

* For each negative lag output weight `wn` at index `c0 - R`, active interval again length `n - R`:

Add to the low side:

`dv0 += dx * wn * (1 - b)`.

Add to the high side:

`dvR += - dx * wn * a`.

Create `D_raw = G0 + first halves + second halves`. Because the constraint family includes all lag signs, including both pair assignments in one accumulation machine follows the evaluator alignment.

Then make a tangent direction:

`D = -D_raw` or `D = D_raw` according to `D_raw` gradient of a maximization surrogate; the descent derivative is the negative of the gradient of the active smoothing score. After the sign, subtract the mean:

`D = D - mean(D)`.

This mean subtraction is intended to enforce infinitesimal `sum(h)` conservation so that projection does not undo the direction.

Before the actual merit-function evaluation, compute

`gAngNorm = max(abs(D), machine epsilon scale)`.

Create normalized tangent `v = D / gAngNorm`.

If `gAngNorm` is too small (`<=1e-16`, anywhere is nearly zero or degenerate), mark the current iteration as no valid deterministic descent attempt and trigger a noise attempt.
