1. Approach and rationale

1.1 Central idea: a trust-region linearized active-overlap minimizer

Represent the construction as a feasible discrete vector
    h ∈ R^n,  0 ≤ h_i ≤ 1,  ∑_i h_i = n/2,
where n is invariantly chosen from the supplied/constructed vector length. The exact task objective is
    F(h) = max_j dx * np.correlate(h, 1-h, mode="full")[j],
with dx = 2/n, and j runs over all 2n - 1 finite-support lags. The returned score must exactly match this expression.

The substantive algorithmic idea is to repeatedly solve convex, linearized minimax subproblems of the form

    minimize τ
    subject to
        τ >= C_j(h0) + G_j(h0)^T d,     for every full-correlation row j,
        0 <= h0_i + d_i <= 1,           for every i,
        ∑_i d_i = 0,
        ||d||_∞ <= ρ,

and then evaluate the true nonlinear exact objective only at the resulting feasible candidate.

Here:
- h0 is the current feasible center,
- C_j(h0) is the exact scaled correlation row j at h0,
- G_j(h0) is the exact scaled gradient of that row with respect to h,
- d is a tentative displacement,
- τ is the linearized maximum over all 2n-1 exact correlation constraints,
- ρ is a control radius.

This is materially different from top-constraint penalties, simulated annealing swaps, smoothed-gradient descent, or generic stochastic moves. Those directly perturb h and return an accepted candidate. The proposed method instead creates each candidate by solving a convex epigraph approximation of the full finite-support covariance epigraph. The subproblem is genuinely able to coordinate multiple active plain-signed lags, residual boundary terms, box limits, and the integral equality in one step. It does not merely lower the current largest lag; it lowers the local piecewise-maximal model of all lags. Candidate acceptance is nevertheless judged only by the original nonlinear np.correlate objective, so a false linear-publication move is harmless and rejected.

1.2 Why this could improve the supplied parent

The supplied parent is close to a local plateau. The improve margin from 0.38085 to 0.3808 is tiny, so a tiny coordinated move is more plausible than because of moving one lag at a time. The LP epigraph can generate a tangent vector lowering many near-tied active values simultaneously while respecting all other correlations under the linearization. It also applies the integral constraint and box constraints strictly linearly.

If the parent is at or near an actual local minimum, a first-order tangent model may reduce τ but still increase later nonlinear boundary terms. Trust-region acceptance uses exact values and reduces or breaks the radius, then tries stochastic second order perturbations. Multi-resolution transfer and neighbor resolutions are included because discrete finite-support boundary interactions can expose nearby basins with a slightly different maximum.

1.3 Limitations and factual status

- This is a local heuristic. It is not a global proof.
- The original problem is nonconvex because h_i h_{i+k} terms occur in the finite-support correlations. The convex LP is a local affine model.
- The returned bound is not claimed to be a certified global optimum; it is a feasible construction vetted by the exact metric.
- If the finite differences/gradient formulas are incorrect, candidate evaluation still judges candidates exactly; wrong destinations only cause false rejection/time loss.
