So F(h) = max_k (1 - ∫h(x)h(x+k)dx) = 1 - min_k ∫h(x)h(x+k)dx

The function ∫h(x)h(x+k)dx is quadratic in h (bilinear form), specifically it's h^T Q_k h where Q_k is a shift matrix. This is NOT convex in general (it could be indefinite).

So F(h) = 1 - min_k h^T Q_k h, which is the negative of a minimum of quadratic forms. This is generally non-convex.

However, if we restrict h to be binary (0 or 1), then h^T Q_k h = sum_i h[i]h[i+k] which is just the count of adjacent pairs, a linear function of the "pair variables." The problem becomes combinatorial.

For the continuous relaxation, the problem is non-convex, so we need local search methods.

Let me go with a practical approach:
1. Start from initial_h_values
2. Use a local search that tries small perturbations (transfers between pairs of positions)
3. Accept if it improves (hill climbing) or with some probability (simulated annealing)
4. Also try to "snap" to binary at the end and see if that helps

For the local search in continuous space:
- Move: transfer ε from h[i] to h[j] (i.e., h[i] -= ε, h[j] += ε)
- This maintains the sum constraint
- Need 0 ≤ h[i]-ε and h[j]+ε ≤ 1

The effect on C5:
C5 = max_k (1 - h^T Q_k h) * ... 

Actually, let me just compute the effect directly using the correlation.
new_corr = correlate(h_new, 1-h_new, 'full')
This is O(n^2) per evaluation.

For n=338, each evaluation takes about 1μs (numpy correlate on 338-length arrays).
If I try 10000 random moves per second, that's 10ms of compute per second. Very fast.

So I can do millions of local search moves in the time budget.
