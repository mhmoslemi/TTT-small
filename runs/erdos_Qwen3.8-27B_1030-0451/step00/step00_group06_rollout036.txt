        F, grad = softmax_c5_and_grad(v, beta)
        # Add penalty

        return F + penalty, grad + pen_grad
    
    result = minimize(objective, h, method='L-BFGS-B', 
                      bounds=[(0,1)]*n,
                      options={'maxiter': 200, 'gtol': 1e-6})
    return result.x

This is related to the theory of "low-autocorrelation sequences" and "Golay complementary sequences" in signal processing. In the continuous case, it's related to "sidelobe minimization."

For the discrete case with n points, we have a vector h ∈ [0,1]^n with sum n/2, and we want to minimize the max of the cross-correlation with (1-h).

One approach from signal processing: use a "Barker-like" sequence or a "m-sequence" (maximum-length sequence) modulated to [0,1].

Actually, let me think about the binary case first. If h is binary (0 or 1) with exactly n/2 ones:
- h(1-h) = 0 always (at lag 0)
- At lag k: the overlap is the number of positions where h has a 1 and h shifted has a 0, times dx.

This is the "Hamming correlation" of the binary sequence. For a random binary sequence with n/2 ones, the expected Hamming correlation at lag k is approximately (n/2)(1/2) = n/4 (for the positions where both are defined). So C5 ≈ (n/4)*dx = (n/4)(2/n) = 1/2. Not great.

For a specific sequence like a "balanced" sequence (like the Thue-Morse sequence), the autocorrelation is low. But we need cross-correlation with (1-h), which for binary h is:
h ⋆ (1-h) at lag = (number of 1s in h that align with 0s in shifted h)

For a random balanced sequence, this is ≈ n/4. For a "good" sequence, it could be lower.

But since we're allowed to use fractional values (h ∈ [0,1]), we have more flexibility than binary.
