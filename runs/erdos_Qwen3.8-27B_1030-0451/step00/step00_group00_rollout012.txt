Also, I need to be more careful about the LP approach. Let me think about whether the linearization is correct.

For g_m(h) = sum_{i: 0≤i<n, 0≤i+m<n} h[i] * (1 - h[i+m]):

The gradient with respect to h[j] is:
- If j appears as the first index: (1 - h[j+m]) [when 0≤j+m<n]
- If j appears as the second index: -h[j-m] [when 0≤j-m<n]

So d g_m / d h[j] = (1-h[j+m])*[0≤j+m<n] - h[j-m]*[0≤j-m<n]

The linearization at h0:
g_m(h) ≈ g_m(h0) + sum_j (d g_m/dh[j])_{h0} * (h[j] - h0[j])

For the constraint g_m(h) * dx ≤ t:
[g_m(h0) + sum_j grad_j * (h[j] - h0[j])] * dx ≤ t
g_m(h0) * dx + sum_j grad_j * (h[j] - h0[j]) * dx ≤ t
sum_j (grad_j * dx) * h[j] - t ≤ g_m(h0) * dx - sum_j (grad_j * dx) * h0[j]

So the LP constraint is:
sum_j (grad_j * dx) * h[j] - t ≤ (g_m(h0) - sum_j grad_j * h0[j]) * dx

which is what I had. Good.
