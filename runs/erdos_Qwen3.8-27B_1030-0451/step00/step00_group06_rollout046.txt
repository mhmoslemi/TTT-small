    For offset = 0: corr[j] = dx * [h[i](1-h[i]) + C_j] which is quadratic (concave parabola).

So for offset ≠ 0, each corr[j] is affine in t. For offset = 0, it's a concave quadratic.

The max of affine functions is convex. The max of affine functions and a concave quadratic... is still convex? No, the max of a convex function and a concave function is not necessarily convex.

Actually, a concave quadratic is not convex, so the max of affine (convex) and concave quadratic (non-convex) is non-convex in general.

However, the concave quadratic term (for offset 0) is: dx * [t(1-t) + C_0] = dx * [-t² + t + C_0]
This is a downward parabola, so it's bounded above by dx * [1/4 + C_0] at t = 1/2.

In practice, the offset-0 term might or might not be in the maximum set. If it is, the 1D problem is non-convex but still easy to solve (check critical points and boundaries).

Let me just do a simple coordinate descent:
1. For each coordinate i (in some order), find the best h[i] given all others fixed.
2. Use a 1D optimization (e.g., check t = 0, 1, and the point where the derivative of the max is 0).

For the 1D subproblem:
- Define f(t) = max_j corr_j(t) where corr_j(t) is the value of correlation at lag j when h[i] = t.
- For j with offset ≠ 0: corr_j(t) = a_j * t + b_j (affine)
- For j with offset = 0: corr_j(t) = -dx * t² + dx * t + b_0 (concave quadratic)
- f(t) = max(all these)
- Minimize f(t) over t ∈ [0, 1].

Since f is the max of (at most one) concave quadratic and many affine functions, it's a "unimodal-ish" function. The minimum is either at t=0, t=1, or at a point where two of the functions intersect and are both at their maximum.

For practical purposes, I can just sample t at fine resolution (e.g., 100 points) and pick the best. This is O(100 * n_corr) per coordinate, which is fine.

Actually, even simpler: I can just evaluate f(t) at a few candidate points:
- t = current h[i]
- t = 0, t = 1
- Points where the "active" corr values (those near the max) intersect with others

But for robustness, let me just do a fine grid search in [0,1] for t. With n_corr ~ 800 (for n=417) and 200 grid points, that's 160k evaluations per coordinate, and 417 coordinates gives 66M total per sweep. That's too slow in Python.

Let me be smarter. For each coordinate i, I can compute the coefficients a_j and b_j for all j in O(n) time (using the structure of the correlation). Then f(t) = max_j (a_j * t + b_j) for the affine ones, and f(t) = max(f_affine(t), f_quad(t)) for the quadratic one.

The max of affine functions is a piecewise linear convex function. I can find its minimum efficiently by finding the "breakpoints" (where the active affine function changes). But this is complex.

A simpler approach: just evaluate f(t) at the current value and at a few perturbed values (like current ± epsilon), and take a gradient step. This is essentially what the subgradient method does, but applied coordinate by coordinate.

def run(seed=42, budget_s=1100, **kwargs):
    np.random.seed(seed)
    t0 = time.time()
    
    # Get initial values
    try:
        h0 = np.array(initial_h_values, dtype=float)
    except NameError:
        h0 = None
    if h0 is None:
        n = 417
        h0 = np.full(n, 0.5)
    
    n = len(h0)
    h0 = make_feasible(h0, n)
    best_h = h0.copy()
    best_c5, _ = evaluate_c5(h0)
    
    def remaining():
        return budget_s - (time.time() - t0)
    
    # Main optimization loop
    h = best_h.copy()
    momentum = np.zeros(n)
    beta = 0.9  # momentum coefficient
    step = 0.01
    
    for iteration in range(10000):
        if remaining() < 30:
            break
        
        # Compute subgradient
        grad, curr_c5, _ = subgradient_topk(h, n, top_k=20)
        
        # Project gradient onto constraint tangent
        grad -= np.mean(grad)
        
        # Momentum update
        momentum = beta * momentum + (1 - beta) * grad
        
        # Take step
        h_new = h - step * momentum  # Note: minimize, so negative gradient
        h_new = np.clip(h_new, 0, 1)
        h_new = make_feasible(h_new, n)
        
        c5_new, _ = evaluate_c5(h_new)
        
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new.copy()
            h = h_new
        else:
            h = h + step * 0.5 * momentum  # or keep h
            step *= 0.95
        
        # Periodically try a smooth step
        if iteration % 50 == 0 and remaining() > 100:
            # Try a different top_k
            top_k_var = [10, 30, 50][iteration // 50 % 3]
            grad2, _, _ = subgradient_topk(h, n, top_k=top_k_var)
            grad2 -= np.mean(grad2)
            h_try = h - step * 0.5 * grad2
            h_try = np.clip(h_try, 0, 1)
