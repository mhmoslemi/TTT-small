1. Approach and rationale

1.1 Central idea

The reported parent is already very good, so the main bottleneck is almost certainly not a radically different coarse construction but a small, carefully controlled improvement in a relevant local basin. The plan therefore uses an exact-evaluator guarded local search driven by active correlation information, combined with a diversified outer loop over a modest set of strong alternative starting points.

The primary method is not a generic smoothed-gradient descent statement, not a hard epigraph nonlinear program, not an active-cut linear-programming SLP, and not a claim of convex line minimization. It is a constrained active-edge exact-transfer search:

- At every iterate it forms the exact correlation vector from the authoritative evaluator.
- It identifies a set of correlated lags that are near the maximum and uses their exact gradients to rank feasible transfer moves, especially coordinate-pair transfers that preserve the mass constraint exactly.
- For each proposed feasible line or coordinate-pair direction, it never trusts model predictions. It takes a small set of exact points on the feasible line, evaluates the original evaluator exactly, and uses the exact evaluator as the sole formal acceptance gate.
- The local current point is only replaced when the exact objective improves. Every accepted candidate is immediately compared against a global best vector and can be returned even if the local trajectory later fails.

This is materially different from trusting a surrogate smooth maximum or asking a convex relaxation/SLS subproblem to define accepted steps. The search is built directly from applications of the convex hull of active constraints and exact one-dimensional probes, but no step is accepted solely by a local surrogate. The overall method remains explicitly local and heuristic; no global optimum is claimed.
