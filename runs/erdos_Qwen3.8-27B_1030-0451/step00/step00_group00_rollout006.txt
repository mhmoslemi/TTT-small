import numpy as np
from scipy.optimize import minimize
import time

def build_h_from_p(p):
    m = len(p)
    n = 2 * m
    h = np.empty(n)
    h[:m] = p
    h[m:] = 1.0 - p
    return h

def extract_p_from_h(h):
    m = len(h) // 2
    p = h[:m].copy()
    return p

def exact_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return dx * np.max(corr)

def smooth_c5(p, eta=0.05):
    h = build_h_from_p(p)
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    # Smooth max: (1/eta) * log(sum(exp(eta * corr)))
    max_c = np.max(corr)
    lse = max_c + np.log(np.sum(np.exp(eta * (corr - max_c)))) / eta
    return dx * lse

def coordinate_descent(p, n_rounds=50, time_limit=None, start_time=None):
    m = len(p)
    best_c5 = exact_c5(build_h_from_p(p))
    for rnd in range(n_rounds):
        if time_limit is not None and start_time is not None:
            if time.time() - start_time > time_limit:
                break
        improved = False
        for i in range(m):
            # Try to improve p[i]
            old_val = p[i]
            # Grid search
            best_val = old_val
            best_obj = best_c5
            # Try a range of values
            for t in np.linspace(0, 1, 21):
                if abs(t - old_val) < 1e-6:
                    continue
                p[i] = t
                c5 = exact_c5(build_h_from_p(p))
                if c5 < best_obj:
                    best_obj = c5
                    best_val = t
            p[i] = best_val
            if best_val != old_val:
                improved = True
                best_c5 = best_obj
        if not improved:
            break
    return p, best_c5

Actually, I realize I should think more carefully about the coordinate descent. The key insight is that for a fixed coordinate i, the objective f(t) = max_k R_k(t) where R_k is linear in t. So f is the max of linear functions, hence convex. A convex function on [0,1] achieves its minimum either at a boundary or at a point where the subgradient contains 0 (i.e., where the slopes of the active constraints change sign).

For a piecewise linear convex function, I can find the minimum by:
1. Evaluating at a few points to find the approximate location
2. Then using the fact that the minimum is where the left slope ≤ 0 ≤ right slope

The slope of R_k with respect to t (when p[i] = t) can be computed analytically. But for simplicity, let me just do a fine grid search that's efficient enough.

With m=169 and a grid of, say, 32 points per coordinate, that's 169*31 = 5239 evaluations per round. Each is O(n) ≈ O(338). Total per round: ~1.8M operations. Very fast.

h[i] appears in corr[k] when:

- In (1-h[j]) = (1-h[i]): j = i. Contribution: -h[i+k] if 0 ≤ i+k < n.

h[i+m] appears in corr[k] when:
- As h[j+k] = h[i+m]: j+k = i+m, so j = i+m-k. Contribution: (1-h[i+m-k]) * (-delta) if 0 ≤ i+m-k < n.
- In (1-h[j]) = (1-h[i+m]): j = i+m. Contribution: -h[i+m+k] * (-delta) = +h[i+m+k] * delta if 0 ≤ i+m+k < n.

So the total change in corr[k] when we change p[i] by delta:
Δcorr[k] = delta * [(1-h[i-k]) * 1[0≤i-k<n] - h[i+k] * 1[0≤i+k<n]
                    - (1-h[i+m-k]) * 1[0≤i+m-k<n] + h[i+m+k] * 1[0≤i+m+k<n]]

This is a fixed coefficient for each k (depending on current h). So new_corr[k] = old_corr[k] + delta * coef[k].

Then the new C5 = dx * max_k new_corr[k] = dx * max_k (old_corr[k] + delta * coef[k]).

This is the max of linear functions of delta, so it's convex and piecewise linear in delta. I can find its minimum efficiently!

The slopes are coef[k] for each k. The function f(delta) = max_k (old_corr[k] + delta * coef[k]) is convex. Its minimum is where 0 is in the subgradient, i.e., where min_k coef[k] (for active k) ≤ 0 ≤ max_k coef[k] (for active k).

For a piecewise linear convex function, I can find the minimum by:
1. Evaluating at delta = 0 (current)
2. Checking the left and right derivatives
3. If the minimum is at a breakpoint, finding it

But finding the exact breakpoint where two lines cross requires solving old_corr[a] + delta*coef[a] = old_corr[b] + delta*coef[b], i.e., delta = (old_corr[b] - old_corr[a]) / (coef[a] - coef[b]).

The number of breakpoints is O(n) (number of k values), so I can find the minimum in O(n log n) time by sorting.

Actually, there's a simpler approach. Since f(delta) is convex and piecewise linear, I can find its minimum by:
1. Computing left derivative at 0: d_left = min{coef[k] : old_corr[k] + 0*coef[k] = max} (minimum slope among maximizers)
2. Computing right derivative at 0: d_right = max{coef[k] : old_corr[k] + 0*coef[k] = max} (maximum slope among maximizers)
3. If d_left ≤ 0 ≤ d_right, then 0 is a minimizer (current value is optimal)
4. If d_right < 0, decrease delta (go left)
5. If d_left > 0, increase delta (go right)
6. Otherwise, find the breakpoint

But finding the exact breakpoint is tricky. Let me just use a simple approach:
- Binary search or ternary search on delta in [0 - old, 1 - old] (the valid range)
- Since f is convex, ternary search works

Actually, for a convex function, I can use bisection on the subgradient:
- At each point, compute the subgradient (set of slopes of active lines)
- If all slopes are positive, go left
- If all slopes are negative, go right
- If 0 is in the subgradient, we're at a minimum

    # Left derivative at delta: min{coef[k] : old_corr[k] + delta*coef[k] = max}
    # Right derivative at delta: max{coef[k] : old_corr[k] + delta*coef[k] = max}
    
    for _ in range(60):  # 60 iterations gives ~1e-18 precision
        mid = (lo + hi) / 2
        vals = old_corr + mid * coef
        max_val = vals.max()
        # Tolerance for "active" (maximizing) terms
        active = np.isclose(vals, max_val, atol=1e-10)
        if not np.any(active):
            active = vals == max_val
        slopes = coef[active]
        
        if slopes.min() <= 0 <= slopes.max():
            # 0 is in subgradient, mid is a minimizer
            break
        elif slopes.min() > 0:
            hi = mid  # All slopes positive, go left
        else:
            lo = mid  # All slopes negative, go right
    
    # Evaluate at the bisection result and boundaries
    candidates = [lo, hi, mid] + [0.0]
    best_delta = 0
    best_val = np.inf
    for d in candidates:
        if d < lo - 1e-12 or d > hi + 1e-12:
            continue
        d = np.clip(d, lo, hi)
        val = np.max(old_corr + d * coef)
        if val < best_val:
            best_val = val
            best_delta = d
    
    return best_delta, best_val
