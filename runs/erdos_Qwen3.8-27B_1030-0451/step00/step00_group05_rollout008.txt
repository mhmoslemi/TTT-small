The Erdős minimum overlap problem asks us to find a step function h: [0, 2] → [0, 1] that minimizes:

C₅ = max_k ∫ h(x)(1 - h(x+k)) dx

Subject to:
- 0 ≤ h(x) ≤ 1
- ∫₀² h(x) dx = 1

With discretization over n_points samples, dx = 2/n_points, sum(h) = n/2.

The evaluation is: C₅ = max(np.correlate(h, 1-h, mode="full") * dx)

Current record: C₅ ≤ 0.38085

Key insights:
- The objective is max over all lags of the correlation between h and 1-h
- This is a minimax problem - we want to minimize the maximum overlap
- The constraint is that h has integral 1 over [0,2], meaning average value 0.5

Let me think about the mathematical structure. If h(x) is a step function with average 0.5, then:
- ∫ h(x)(1-h(x+k)) dx measures the "overlap" where h is high but h shifted by k is low
- We want this to be small for ALL k simultaneously

A simple strategy: make h as "balanced" as possible - roughly 0.5 everywhere with small perturbations. But we need to minimize the MAX, so we need to be careful about where the peaks are.

Let me think about good algorithmic approaches:

1. **Pairwise exchange (exact feasible moves)**: Pick two indices i,j and transfer mass from one to the other. This preserves the sum constraint exactly.

2. **Gradient-guided**: Compute which lags are "active" (close to the maximum), compute gradients of those active lags, and move in the direction that reduces them.

3. **Annealing**: Allow some uphill moves to escape local minima.

def make_feasible(h, target_sum):

    # Adjust sum
    diff = target_sum - np.sum(h)
    if abs(diff) > 1e-10:
        # Distribute adjustment
        if diff > 0:
            # Need to add mass - add to positions where h < 1
            room = 1.0 - h
            total_room = np.sum(room)
            if total_room > 1e-10:
                h += diff * room / total_room
                h = np.clip(h, 0, 1)
        else:
            # Need to remove mass - remove from positions where h > 0
            avail = h
            total_avail = np.sum(avail)
            if total_avail > 1e-10:
                h += diff * avail / total_avail
                h = np.clip(h, 0, 1)

            h[idx] = min(1.0, h[idx] + residual)
        else:
            idx = np.argmax(h)
            h[idx] = max(0.0, h[idx] + residual)
    return h

def make_feasible(h, target_sum):
    """Ensure 0<=h<=1 and sum(h)=target_sum."""
    h = np.asarray(h, dtype=np.float64).copy()
    n = len(h)
    h = np.clip(h, 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) > 1e-12:

        if diff > 0:
            room = 1.0 - h
            total_room = np.sum(room)
            if total_room > 1e-15:
                h += (diff / total_room) * room
        else:
            avail = h
            total_avail = np.sum(avail)
            if total_avail > 1e-15:
                h += (diff / total_avail) * avail
        h = np.clip(h, 0.0, 1.0)
    # Final nudge
    residual = target_sum - np.sum(h)
    if abs(residual) > 1e-10:

        if residual > 0:

            h[idx] = min(1.0, h[idx] + residual)
        else:
            idx = np.argmax(h)
            h[idx] = max(0.0, h[idx] + residual)
    return h

def smooth_max_gradient(h, full_corr, dx, k_active=15, tau_frac=0.02):
    """Compute gradient of the softmax-smoothed max of the correlation values."""
    n = len(h)
    center = n - 1
    M = len(full_corr)  # 2n-1
    
    values = full_corr * dx
    max_val = np.max(values)
    
    # Softmax weights for top-k active lags
    k = min(k_active, M)
    top_idx = np.argpartition(values, -k)[-k:]
    tau = max(tau_frac * max_val, 1e-8)
    
    w = np.zeros(M)
    active = values[top_idx]
    exp_w = np.exp((active - max_val) / tau)
    w[top_idx] = exp_w / np.sum(exp_w)
    
    # Gradient accumulation
    grad = np.zeros(n)
    
    # Zero lag contribution
    w0 = w[center]
    if w0 > 0:
        grad += w0 * (1.0 - 2.0 * h)

    for r in range(1, n):

        # Positive lag r at index center + r

            wp = w[idx_p]

            grad[:L] += wn * (1.0 - h[r:r+L])
            grad[r:] -= wn * h[:L]
    
    return grad * dx
