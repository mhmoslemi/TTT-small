We want to minimize max_r out'[r] = max_r (out[r] + δ * (s_j[r] - s_i[r])).

This is a 1D convex piecewise-linear problem in δ. The minimum can be found by:
1. Computing d[r] = s_j[r] - s_i[r] for all r
2. Finding δ that minimizes max_r (out[r] + δ * d[r])

This is equivalent to: minimize max_r (out[r] + δ * d[r]) subject to 0 ≤ δ ≤ min(h[i], 1-h[j]).

The function f(δ) = max_r (out[r] + δ * d[r]) is convex in δ (max of affine functions). We can find its minimum using:
- The subgradient at δ is: the set of r that achieve the maximum, weighted by d[r].
- The minimum is where the subgradient contains 0.

A practical approach: since f is piecewise linear with at most 2N-1 breakpoints, we can find the breakpoints and check each one.

The breakpoints occur where out[r] + δ*d[r] = out[r'] + δ*d[r'] for some r ≠ r':
δ = (out[r'] - out[r]) / (d[r] - d[r'])

There are O((2N-1)²) such breakpoints, but most are irrelevant (outside the feasible range or not actually breakpoints of the max).

def optimal_delta(out, d, hi_max):
    """Find δ in [0, hi_max] that minimizes max_r (out[r] + δ*d[r])."""
    if hi_max <= 0:
        return 0.0
    
    def f(delta):
        return np.max(out + delta * d)
    
    f0 = f(0)
    fmax = f(hi_max)
    
    if fmax >= f0:
        # Minimum might be at 0 or in between
        # Check subgradient at 0
        argmax_at_0 = np.where(out == f0)[0]
        d_at_argmax = d[argmax_at_0]
        if np.all(d_at_argmax >= 0):
            return 0.0  # f is non-decreasing at 0
        # Otherwise find minimum by bisection
        lo, hi2 = 0.0, hi_max
    else:
        # f is decreasing at hi_max
        argmax_at_max = np.where(out + hi_max * d == fmax)[0]
        d_at_argmax = d[argmax_at_max]
        if np.all(d_at_argmax <= 0):
            return hi_max  # f is non-increasing at hi_max
        lo, hi2 = 0.0, hi_max
    
    # Bisection on subgradient
    for _ in range(50):
        mid = (lo + hi2) / 2
        vals = out + mid * d
        fmid = np.max(vals)
        argmax = np.where(vals == fmid)[0]
        d_vals = d[argmax]
        if np.any(d_vals < 0):
            # Can decrease further (or need to go right if all positive)
            if np.all(d_vals < 0):
                lo = mid
            else:
                return mid  # 0 is in subgradient
        elif np.all(d_vals > 0):
            hi2 = mid
        else:
            return mid  # d = 0 at argmax
    
    return (lo + hi2) / 2
```

def precompute_shift_vectors(h):
    """Precompute s_p for all positions p."""
    N = len(h)
    one_minus_h = 1.0 - h
    S = np.zeros((N, 2*N-1))

        for r in range(p, p+N):
            q = p + N - 1 - r
            S[p, r] = one_minus_h[q]
    return S
```

This is an N x (2N-1) matrix. For N=120, that's 120 x 239 ≈ 28680 values. Computing it takes O(N²) = O(14400) operations. Fast.

        r_end = p + n  # exclusive
