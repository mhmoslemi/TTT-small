Let me think about coordinate descent. If I fix all coordinates except h[j], then C(k) becomes:
C(k) = C(k; h_j) where h_j appears in specific terms.

For a given lag k, h[j] appears in C(k) if:
- j is in the valid range for the first factor: h[j] * (1-h[j-k]) → contributes (1-h[j-k]) to ∂C/∂h[j]
- j-k is in the valid range: h[j-k] * (1-h[j]) → contributes -h[j-k] to ∂C/∂h[j]

So ∂C(k)/∂h[j] = (1-h[j-k]) - h[j+k] (with validity checks)

For coordinate descent, we want to minimize max_k C(k) by changing one h[j] at a time.

For a fixed j, C(k) as a function of h[j] is:
C(k) = C(k; 0) + h[j] * [∂C(k)/∂h[j]] (since C is linear in h[j] when other coordinates are fixed)

Wait, is C(k) linear in h[j] when other coordinates are fixed? Let's check:
C(k) = sum_i h[i](1-h[i-k])

If we change only h[j]:
- The term where i=j: h[j](1-h[j-k])
- The term where i-k=j, i.e., i=j+k: h[j+k](1-h[j])

So C(k) = [sum of terms not involving h[j]] + h[j](1-h[j-k]) + h[j+k](1-h[j])
= const + h[j] - h[j]h[j-k] + h[j+k] - h[j+k]h[j]
= const + h[j] + h[j+k] - h[j](h[j-k] + h[j+k])
= const + h[j] + h[j+k] - h[j] * (h[j-k] + h[j+k])

This is linear in h[j]! (Since h[j-k] and h[j+k] are fixed when we only change h[j].)

So for each lag k, C(k) = a_k * h[j] + b_k where:
a_k = ∂C(k)/∂h[j] = (1-h[j-k]) - h[j+k] (with validity)
b_k = C(k) - h[j] * a_k

We want to choose h[j] ∈ [0,1] to minimize max_k (a_k * h[j] + b_k), subject to the sum constraint.

This is a 1D minimax problem! We can solve it exactly by finding the h[j] that minimizes the maximum of a set of linear functions.

The optimal h[j] is where the two "extreme" lines cross (or at a boundary 0 or 1).

This is much more efficient than full gradient descent!

            h_r = (rng.random(n_try) < 0.5).astype(np.float64)
            t_trial = min(time.time(), t0 + budget_s * 0.9)
            h_b, c_b = _optimize(h_r, n_try, t_trial, rng)
            if c_b < best_c5:
                best_h, best_c5 = h_b, c_b
    # Phase 4: final refinement
    if best_h is not None and time.time() < t0 + budget_s - 5:
        t_end = t0 + budget_s - 2
        h_b, c_b = _optimize(best_h, len(best_h), t_end, rng)
        if c_b < best_c5:
            best_h, best_c5 = h_b, c_b
    # Verify
    if best_h is not None:
        n_final = len(best_h)
        if _c5(best_h, 2.0 / n_final) < best_c5:
            pass
    return best_h, best_c5, len(best_h)
