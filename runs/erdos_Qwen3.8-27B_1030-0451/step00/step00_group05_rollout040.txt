Let me analyze this problem carefully.

I need to find a step function h: [0, 2] → [0, 1] that minimizes:
C₅ = max_k ∫ h(x)(1 - h(x+k)) dx

Subject to:
- 0 ≤ h(x) ≤ 1
- ∫₀² h(x) dx = 1 (i.e., sum(h) = n/2)

The current record is C₅ ≤ 0.38085, and I need to beat 0.3808.

The strategy suggests a TMDR (Top-Max Directional Ratchet) approach with:
1. Computing the gradient of the top active correlation terms
2. Using a smoothed surrogate for the max
3. Projected descent with non-monotone acceptance
4. Resolution changes

Let me think about the mathematics more carefully.

Given h of length n, dx = 2/n, and the full correlation:
`full = np.correlate(h, 1-h, mode="full") * dx`

The full correlation has length 2n-1. The center index is c0 = n-1.

For lag R (positive):
Y_plus_R = sum_{i=0}^{n-1-R} h[i+R] * (1 - h[i]) * dx
This is at index c0 + R in full.

For lag -R (negative):
Y_minus_R = sum_{i=0}^{n-1-R} h[i] * (1 - h[i+R]) * dx
This is at index c0 - R in full.

Note: Y_plus_R and Y_minus_R are NOT the same in general.

Now, the gradient of the objective with respect to h[j]:

For the zero lag at index c0:
Y0 = sum_i h[i] * (1 - h[i]) = sum_i (h[i] - h[i]^2)
dY0/dh[j] = 1 - 2*h[j]

For positive lag R at index c0 + R:
Y_plus_R = sum_{i=0}^{n-1-R} h[i+R] * (1 - h[i])

dY_plus_R/dh[j]:
- If j is in [0, n-1-R]: h[j] appears as (1-h[j]) term, so derivative = -h[j+R]
- If j is in [R, n-1]: h[j] appears as h[j] term (where j = i+R, so i = j-R), so derivative = (1-h[j-R])

For negative lag -R at index c0 - R:
Y_minus_R = sum_{i=0}^{n-1-R} h[i] * (1 - h[i+R])

dY_minus_R/dh[j]:
- If j is in [0, n-1-R]: h[j] appears as h[j] term, so derivative = (1-h[j+R])
- If j is in [R, n-1]: h[j] appears as (1-h[j]) term (where j = i+R, so i = j-R), so derivative = -h[j-R]

So the total gradient of the surrogate F = sum_k p_k * C[k]:

dF/dh[j] = sum_k p_k * dC[k]/dh[j]

where C[k] = full[k] * dx... wait, let me be more careful.

Actually, `full = np.correlate(h, 1-h, mode="full") * dx`. So C[k] = full[k].

Let me just think of it as:
C[k] = dx * raw_correlation[k]

where raw_correlation is np.correlate(h, 1-h, mode="full").

The gradient of C[k] with respect to h is dx times the gradient of raw_correlation[k].

For the surrogate F = sum_k p_k * C[k], the gradient is:
dF/dh[j] = dx * sum_k p_k * d(raw_correlation[k])/dh[j]

Now, for the descent direction, I want to decrease F, so the direction is -dF/dh[j].

But I need to maintain sum(h) = n/2. So I project onto the hyperplane sum(h) = n/2 by subtracting the mean of the gradient.

Then I also need to project onto [0,1]^n.

Let me think about the algorithm:

1. Start with initial_h_values (n=131)
2. Compute the correlation vector C
3. Identify top active indices (those within temperature T of the max)
4. Compute weights p_k for active indices (softmax-like)
5. Compute the gradient of the weighted surrogate
6. Project: subtract mean, then clip to [0,1] and repair sum
7. Take a step in the projected direction
8. Evaluate exact objective
9. Accept if better (or with some non-monotone criterion)
10. Repeat

Let me also think about what "projection" means here. We have:
- 0 <= h[i] <= 1
- sum(h) = n/2

This is a simplex-like constraint (bounded box + one equality). The exact projection onto this set is:
1. Compute the unconstrained projected point
2. Find the correct box constraints that are active
3. Adjust the free variables to satisfy the sum constraint

A simpler approach: 
1. Start with candidate h_new = h + step * direction
2. Subtract mean to fix sum: h_new = h_new - (sum(h_new) - n/2) / n
3. Clip to [0, 1]
4. If sum changed due to clipping, do a water-filling to restore sum

Actually, let me use a simpler iterative projection:
1. h_new = h + step * v (where v is the projected direction with zero mean)
2. Clip: h_new = np.clip(h_new, 0, 1)
3. If sum(h_new) != n/2, adjust: add/subtract to non-bound entries
4. Repeat until convergence

import numpy as np

def project_onto_constraint(h, n):
    """Project h onto {0 <= h[i] <= 1, sum(h) = n/2}"""
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    # Water filling to fix sum
    current_sum = np.sum(h)
    diff = target - current_sum
    if abs(diff) < 1e-12:
        return h
    # Find non-bound entries
    if diff > 0:
        # Need to increase sum: add to entries < 1
        free = h < 1.0 - 1e-12
    else:
        # Need to decrease sum: subtract from entries > 0
        free = h > 1e-12
    n_free = np.sum(free)
    if n_free == 0:
        return h
    # Distribute evenly among free entries
    adj = diff / n_free
    # Check if this would violate bounds
    if diff > 0:
        max_adj = min(1.0 - h[free], -adj) if adj < 0 else (1.0 - h[free])
    # Simpler: just add adj to free entries and re-clip
    h_new = h.copy()
    h_new[free] += adj
    h_new = np.clip(h_new, 0, 1)
    # May need iteration for exact sum
    for _ in range(50):
        s = np.sum(h_new)
        d = target - s
        if abs(d) < 1e-15:
            break
        if d > 0:
            free = h_new < 1.0 - 1e-12
        else:
            free = h_new > 1e-12
        if not np.any(free):
            break
        h_new[free] += d / np.sum(free)
        h_new = np.clip(h_new, 0, 1)
    return h_new

def compute_c5(h):
    """Compute C5 = max of full correlation * dx"""
    n = len(h)
    dx = 2.0 / n
    one_minus_h = 1.0 - h
    corr = np.correlate(h, one_minus_h, mode="full") * dx
    return np.max(corr)

def compute_gradient_surrogate(h, T, K_active, W_active):
    """
    Compute gradient of the top-active smoothed surrogate.
    Returns the gradient vector and the active indices/weights.
    """
    n = len(h)
    dx = 2.0 / n
    one_minus_h = 1.0 - h
    corr = np.correlate(h, one_minus_h, mode="full")
    C = corr * dx  # scaled correlation values
    M = np.max(C)
    
    # Find active indices: those within W_active of max, top K_active
    active_mask = C >= (M - W_active)
    if np.sum(active_mask) > K_active:
        # Take top K_active
        active_indices = np.argsort(C)[::-1][:K_active]
    else:
        active_indices = np.where(active_mask)[0]
    
    # Compute softmax weights
    C_active = C[active_indices]
    z = (M - C_active) / T
    B = np.exp(-z)
    p = B / np.sum(B)
    
    # Compute gradient
    # dC[k]/dh[j] for each active k
    # grad[j] = dx * sum_k p[k] * d(raw_corr[k])/dh[j]
    grad = np.zeros(n)
    c0 = n - 1
    
    for idx, pk in zip(active_indices, p):
        R = idx - c0  # lag
        if R == 0:
            # Zero lag: dY0/dh[j] = 1 - 2*h[j]
            grad += pk * dx * (1.0 - 2.0 * h)
        elif R > 0:
            # Positive lag R: Y_plus_R = sum_{i=0}^{n-1-R} h[i+R] * (1-h[i])
            # dY_plus_R/dh[j]:
            #   if j in [0, n-1-R]: derivative of (1-h[j]) * h[j+R] -> -h[j+R]
            #   if j in [R, n-1]: derivative of h[j] * (1-h[j-R]) -> (1-h[j-R])
            lo = 0
            hi = n - R
            # Low side: j in [0, hi-1], contribution = -h[j+R]
            for j in range(lo, hi):
                grad[j] += pk * dx * (-h[j + R])
            # High side: j in [R, n-1], contribution = (1-h[j-R])
            for j in range(R, n):
                grad[j] += pk * dx * (1.0 - h[j - R])
        else:
            # Negative lag: R < 0, let R_abs = -R
            R_abs = -R
            # Y_minus_R_abs = sum_{i=0}^{n-1-R_abs} h[i] * (1-h[i+R_abs])
            # dY_minus/dh[j]:
            #   if j in [0, n-1-R_abs]: derivative of h[j] * (1-h[j+R_abs]) -> (1-h[j+R_abs])
            #   if j in [R_abs, n-1]: derivative of (1-h[j]) * h[j-R_abs] -> -h[j-R_abs]
            hi = n - R_abs
            for j in range(0, hi):
                grad[j] += pk * dx * (1.0 - h[j + R_abs])
            for j in range(R_abs, n):
                grad[j] += pk * dx * (-h[j - R_abs])
    
    return grad, active_indices, p

def project_feasible(h, n):
    """Project h onto {0 <= h[i] <= 1, sum(h) = n/2}"""
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(100):
        s = np.sum(h)
        d = target - s
        if abs(d) < 1e-14:
            break
        if d > 0:
            mask = h < 1.0 - 1e-14
        else:
            mask = h > 1e-14

            break
        h[mask] += d / np.count_nonzero(mask)
