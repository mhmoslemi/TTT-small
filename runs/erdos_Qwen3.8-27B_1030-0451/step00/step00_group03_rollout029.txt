    n = len(y)

    a = -y.max() - 0.5

def project_box_mean(y):

    fb = _phi(b)

So I can just search over the full interval [t_lo, t_hi] which goes from negative to positive. The convex function f(t) will have its minimum somewhere in this interval. If the minimum is at t=0, no improvement is possible.

This is cleaner. Let me use this formulation.

Now, for the precomputed gradient g, when t is negative, it means we're transferring in the opposite direction (from j to i). The formula still works:
result_new[k] = corr[k] + t * g[k]

where g[k] = d(corr[k])/d(h[j]) - d(corr[k])/d(h[i])

This is correct for any t in the feasible interval.

1. Starts from the parent
2. Does intensive guided + random pair search
3. Periodically tries resolution changes
4. Optionally does SLSQP polish
5. Returns the best found

def exact_c5(h):
    """Official evaluator."""

    return float(np.max(corr) * dx)

def project_box_mean(y):
    """Project onto {x: 0<=x_i<=1, sum(x)=n/2}."""
    y = np.asarray(y, dtype=np.float64).ravel().copy()
    n = len(y)
    target = 0.5 * n
    y = np.where(np.isfinite(y), y, 0.5)
    
    # Bisection for shift
    a = -y.max() - 0.5
    b = 1.0 - y.min() + 0.5

                r -= d
