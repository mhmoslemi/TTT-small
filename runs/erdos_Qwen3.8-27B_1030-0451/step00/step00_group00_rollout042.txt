    dx = 2.0 / len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")

def project_to_polytope(h, target_sum):
    """Project h onto {x: 0<=x<=1, sum(x)=target_sum} using bisection"""
    # Find lambda such that sum(clamp(h - lambda, 0, 1)) = target_sum
    lo, hi = -1.0, 1.0  # lambda bounds
    for _ in range(60):
        mid = (lo + hi) / 2
        clamped = np.clip(h - mid, 0, 1)
        s = np.sum(clamped)
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    clamped = np.clip(h - (lo + hi) / 2, 0, 1)
    # Adjust for any floating point error
    diff = target_sum - np.sum(clamped)

        if np.any(mask):

    m = np.max(corr)

  - If i is in first factor position (n+k=i, n=i-k): valid if 0≤i-k≤n-1-k, i.e., k≤i≤n-1. Change: -(1-h[i-k])
  - If i is in second factor position (n=i): valid if 0≤i≤n-1-k. Change: +h[i+k]

  And for c[0]:
  c[0] = sum_{n=0}^{n-1} h[n] * (1-h[n])
  - If h[i] changes from 1 to 0: the term changes from 1*(1-1)=0 to 0*(1-0)=0. No change!
  Wait, that can't be right. Let me recheck.
  c[0] = sum h[n]*(1-h[n]). If h[i] goes from 1 to 0:
  Old term: 1*(1-1) = 0
  New term: 0*(1-0) = 0
  So indeed no change for lag 0! That makes sense because h[i]*(1-h[i]) = 0 for both h[i]=0 and h[i]=1.

  For non-binary h, it would be different (h*(1-h) is maximized at h=0.5), but for binary it's always 0.

So for binary h, the change in c[k] when flipping h[i] from 1 to 0 is:
- For k > 0: Δc[k] = -(1-h[i-k]) * 1[k≤i≤n-1] + h[i+k] * 1[0≤i≤n-1-k]
- For k = 0: Δc[k] = 0
- For k < 0 (m = -k): Δc[k] = -(1-h[i+m]) * 1[0≤i≤n-1-m] + h[i-m] * 1[m≤i≤n-1]

And when flipping h[j] from 0 to 1:
- For k > 0: Δc[k] = +(1-h[j-k]) * 1[k≤j≤n-1] - h[j+k] * 1[0≤j≤n-1-k]
  (The sign is flipped because we're adding instead of removing)
  Wait: if h[j] goes from 0 to 1:
  - Term in first factor: was 0*(1-h[n]) = 0, now 1*(1-h[n]). Change: +(1-h[n])
    For n=j-k: +(1-h[j-k]) if k≤j≤n-1
  - Term in second factor: was h[n+k]*(1-0) = h[n+k], now h[n+k]*(1-1) = 0. Change: -h[n+k]
    For n=j: -h[j+k] if 0≤j≤n-1-k
  
  So Δc[k] for h[j]: 0→1:
  - k > 0: +(1-h[j-k]) * 1[k≤j] - h[j+k] * 1[j≤n-1-k]
  - k = 0: 0
  - k < 0 (m=-k): +(1-h[j+m]) * 1[j≤n-1-m] - h[j-m] * 1[j≥m]

So the total change when swapping h[i]:1→0 and h[j]:0→1 is:
Δc[k] = [change from removing i] + [change from adding j]

This allows us to compute the change in C5 = max_k c[k]*dx without recomputing the full correlation.

But it's O(n) to compute Δc for all k (since each k has a O(1) change). Then finding the new max is O(n). So each swap evaluation is O(n).

For n=338, that's about 338 ops per swap. We can do millions per second!

    """Compute change in correlation when swapping h[i]:1->0 and h[j]:0->1"""
    # Returns array of changes for each lag
    dc = np.zeros(2*n - 1)
    
    # Remove h[i]=1
    for k in range(1, n):
        # k > 0
        if k <= i <= n-1:
            dc[k + n - 1] -= (1 - h[i-k])
        if 0 <= i <= n-1-k:
            dc[k + n - 1] += h[i+k]
        # k < 0 (lag = -k)
        if 0 <= i <= n-1-k:
            dc[-k + n - 1] -= (1 - h[i+k])
        if k <= i <= n-1:
            dc[-k + n - 1] += h[i-k]
    
    # Add h[j]=1
    for k in range(1, n):
        # k > 0
        if k <= j <= n-1:
            dc[k + n - 1] += (1 - h[j-k])
        if 0 <= j <= n-1-k:
            dc[k + n - 1] -= h[j+k]
        # k < 0
        if 0 <= j <= n-1-k:
            dc[-k + n - 1] += (1 - h[j+k])
        if k <= j <= n-1:
            dc[-k + n - 1] -= h[j-k]
    
    return dc

Actually, let me use the lag notation. Let lag range from -(n-1) to (n-1).

The correlation at lag L is:
c[L] = sum of h[a] * (1-h[b]) where a - b = L and both a, b are in [0, n-1]

When we change h[i] from 1 to 0:
- For each b where a = i and a - b = L (i.e., L = i - b, b = i - L):
  If 0 ≤ b < n and 0 ≤ i < n: the term h[i]*(1-h[b]) = (1-h[b]) changes to 0.
  So c[L] decreases by (1-h[b]) = (1-h[i-L])
  Valid when 0 ≤ i-L < n, i.e., i-n+1 ≤ L ≤ i

- For each a where b = i and a - b = L (i.e., L = a - i, a = i + L):
  If 0 ≤ a < n: the term h[a]*(1-h[i]) = 0 changes to h[a]*(1-0) = h[a].
  So c[L] increases by h[a] = h[i+L]
  Valid when 0 ≤ i+L < n, i.e., -i ≤ L ≤ n-1-i

Similarly for h[j] from 0 to 1:
- c[L] increases by (1-h[j-L]) for valid L (j-n+1 ≤ L ≤ j)
- c[L] decreases by h[j+L] for valid L (-j ≤ L ≤ n-1-j)

So the total change in c[L] for the swap is:
Δc[L] = -(1-h[i-L]) * 1[i-n+1≤L≤i] + h[i+L] * 1[-i≤L≤n-1-i]
       + (1-h[j-L]) * 1[j-n+1≤L≤j] - h[j+L] * 1[-j≤L≤n-1-j]

This is O(1) per L (with indicator conditions), so O(n) total for all L.

Then the new C5 = max(c[L] + Δc[L]) * dx for all L.
