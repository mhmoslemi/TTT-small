1. Approach and rationale

1.1 Central idea

The required sequence is a finite-dimensional step-feasible vector

h = (h[0], ..., h[n-1]) in [0,1]^n

satisfying the area constraint

sum(h) = n/2 = 1/dx, where dx = 2/n.

The authoritative objective is

F(h) = max_{r = -(n-1), ..., n-1} F_r(h)

where F_r are the discrete lag-overlap integrals produced by

score_exact(h) = max(np.correlate(h, 1-h, "full")) * dx.

This objective is a maximum over 2n-1 bilinear functions. It is not smooth everywhere, not convex, and not a simple sum-of-overlaps objective. Therefore the search must use a combination of:

- derivative or perturbative directions for a smooth surrogate,
- a first-order linear trust-region model for the currently active lags,
- exact line searches and exact acceptance tests,
- feasibility projection/enforcement so that the area and box constraints always hold,
- several starting points derived from the supplied `initial_h_values`, when available, plus algorithmic alternatives for robustness.

The supplied parent is expected to already be close to the current record. The bottleneck is therefore not the low-dimensional global structure but local polishing: lowering the maximum active overlap by a few 1e-5. A direct global MILP or convex solver would be too large or invalid because bilinear terms are nonconvex. A local exact-driven method with active-lag modeling is safer and cheaper.

1.2 Why this can improve the parent

At a candidate h, the maximizer lags determine which direction can reduce the objective. A simple gradient of a smooth surrogate focuses on the largest lags. A linear-program subproblem on the first-order gradients of the active lags gives a coordinated direction that tries to decrease all currently binding constraints, not just a single largest lag. Exact evaluation is required because the linear model can be misleading due to bilinear curvature, boundary corrections, and possible switching of which lag is active.

Exact line search is essential: from a proposed feasible direction v with sum(v)=0 and v within box-sufficient bounds, any convex scaling mu in [0,1] gives a feasible or near-feasible move. Testing mu = 1.0, 0.5, 0.25, etc. avoids overshooting the local quadratic model.

The current record is close, so most of the power should be applied to parent-derived multi-resolution local refinement. Multi-resolution and randomized pattern starts are secondary diversity mechanisms.

1.3 Important limitations and honesty

- The nonlinear minimax problem is nonconvex. No returned candidate is a global optimum unless proven by exhaustive enumeration, which is computationally infeasible here.
- The LP subproblem is a local model, not a convex relaxation of the full problem. Its solution must be checked using the exact evaluator before acceptance.
- A smooth log-sum-exp surrogate is only a guide. It can point in a direction that temporarily worsens the true maximum; exact acceptance must decide.
- Higher resolution changes the exact discrete objective. Candidates at different n are not directly comparable by their parent values or interpolation values; the only final criterion is the exact score at the returned n.
- Random restarts may find nothing better than the parent. The parent, if valid and finite, remains the final fallback.

2. Mathematical specification

2.1 Representation and exact feasible set

Let n_points = n. Let dx = 2.0 / n.

Feasible set:

S_n = {h in R^n : 0 <= h_i <= 1 for all i, sum_i h_i = n/2}.

The area constraint is exactly sum(h) * dx = (n/2) * (2/n) = 1.

The final h must be a finite float vector and must satisfy:

- np.all(np.isfinite(h))

2.2 Exact lag formula and selector indices

The evaluator uses:

corr = np.correlate(h, 1-b, "full") * dx
b = 1-h
score = max(corr)

The lag index mapping for raw lag r, where r = -(n-1), ..., n-1, is:

group_index q = r + (n-1).

For a given raw lag q or r, define terms:

If r >= 0:

a_indices = [r, r+1, ..., n-1]
b_indices = [0, 1, ..., n-r-1]

and

F_r(h) = dx * sum_{t=0}^{n-r-1} h[a_indices[t]] * (1 - h[b_indices[t]]).

If r < 0:

let s = -r.

a_indices = [0, 1, ..., n-s-1]
b_indices = [s, s+1, ..., n-1]

and again

F_r(h) = dx * sum h[a] * (1 - h[b]).

This exactly matches `np.correlate(h, 1-h, "full")` addressing, using the second argument as the conj/reference-side. It includes negative and positive lags separately and uses finite-support zero padding, not circular convolution.

Important edge case r=0:

F_0(h) = dx * sum_i h_i * (1-h_i).

In the formula with a_i=b_i=i, the gradient formulas below produce the correct dx*(1-2h_i).

2.3 Objective gradients for bilinear terms

For any lag weight vector w[q] over q=0,...,2n-2, define

F_w(h) = sum_q w[q] * F_{r(q)}(h).

Let all terms be preflattened. Define arrays:

term_a[t] = first-coordinate index in term t,
term_b[t] = second-coordinate index in term t,
term_group[t] = q of the lag group containing term t.

Let lag_weight = w. Let term_weight = w[term_group].

Then

F_w(h) = dx * sum_t term_weight[t] * (h[term_a[t]] - h[term_a[t]] * h[term_b[t]]).

Gradient:

grad_F_w(h) = dx * (
    bincount(term_a, weights = term_weight * (1 - h[term_b]), minlength=n)
  - bincount(term_b, weights = term_weight * h[term_a], minlength=n)
)

where the two bincounts accumulate by index. This works when a=b in r=0 terms because the second `h_i` term and the first `1-h_i` term both contribute appropriately.

Use this same gradient builder for:

- individual active-lag gradients, by setting one lag weight to 1 and all others to 0;
- model gradients for sum or max of active lags;
- smooth log-sum-exp gradients by setting lag_weight to the softmax-surrogate lag weights.
