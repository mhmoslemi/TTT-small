        old_src = cur_h[src]
        old_dst = cur_h[dst]
        cur_h[src] = old_src - delta
        cur_h[dst] = old_dst + delta
        
        new_c = exact_metric(cur_h)
        
        if new_c < cur_c:
            cur_c = new_c
            no_improve = 0
            if cur_c < best_c:
                best_c = cur_c
                best_h = cur_h.copy()
        elif rng.random() < math.exp(-(new_c - cur_c) / T):
            cur_c = new_c
            no_improve += 1
        else:
            cur_h[src] = old_src
            cur_h[dst] = old_dst
            no_improve += 1
        
        if no_improve > max_no_improve:

            cur_h = best_h + rng.normal(0, 0.01, n)
            cur_h = project(cur_h, target)
            cur_c = exact_metric(cur_h)
            no_improve = 0
    
    return best_h, best_c

Wait, I have a bug: upsample goes from smaller to larger. I need a separate downsample function (which is actually the same as upsample with n_old > n_new).

Let me fix: `np.interp` works for both upsampling and downsampling, as long as the x-coordinates are properly set up.

```python
def resample(h, n_old, n_new):
    mid_old = (np.arange(n_old) + 0.5) * (2.0 / n_old)
    mid_new = (np.arange(n_new) + 0.5) * (2.0 / n_new)
    return np.interp(mid_new, mid_old, h)
```

This works for both n_new > n_old (upsample) and n_new < n_old (downsample).
