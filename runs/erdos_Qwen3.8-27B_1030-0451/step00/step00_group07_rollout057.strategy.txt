1. Approach and rationale

1.1 Central idea

The search is performed on an explicit reduced feasible manifold that is obtained by imposing the anti-reflection/complement relation

    h(x) + h(2 - x) = 1

on the discrete vector. For an even number of samples N, this relation makes every mirrored pair sum to one. The normalized mass condition then holds structurally without using an equality constraint, clipping, and then rescaling in separate steps. If N is odd, the point exactly opposite the symmetry center is fixed at 1/2 and the remaining mirrored pairs are constrained in the same way.

The complementary half-length variables are

    y_k = h_k - 1/2,   0 <= k < M,  M = floor(N/2),

with the corresponding mirrored sample forced to be

    h_{N-1-k} = 1 - h_k = 1/2 - y_k.

Thus necessary and sufficient feasibility on this manifold is just

    -1/2 <= y_k <= +1/2.

The exact task objective is still evaluated with the literal evaluator

    np.max(np.correlate(h, 1 - h, mode="full")) * (2.0 / N).

Reducing from N variables to M variables is the central departure from a direct full-dimensional minimax optimizer. The optimization remains local/unconstrained in a bounded box instead of being one constrained and potentially ill-conditioned minimax problem in N variables with sum(h)=N/2.

The optimization cycle is:

1. Validate and register the supplied parent if it exists, as a rigorous fallback.
2. Fold the parent into the anti-reflected manifold by

       y_k <- 1/2 * (parent_k - parent_{N-1-k})

   and optionally use sign flips and clamped transformations of this y.
3. Use an annealed log-sum-exp surrogate for the exact objective only to obtain feasible descent directions and iterates, with analytic gradients derived directly from the evaluator-derived lag pairs.
4. After every solver step, whenever a feasible vector is produced, score it with the exact finite-lag evaluator. Smooth objective values and epigraph variables are never used as the reported result.
