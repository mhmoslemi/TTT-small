For h of length n, np.correlate(h, 1-h, mode='full') gives a vector of length 2n-1.

For lag L (where the output index is n-1+L):
- If L ≥ 0: y_L = Σ_{u=0}^{n-1-L} h[u+L] * (1-h[u])
- If L < 0: let R = -L: y_L = Σ_{u=0}^{n-1-R} h[u] * (1-h[u+R])

The objective is C5 = dx * max(L) y_L.

For the penalty approach, let's define:
P(h) = Σ_L max(0, dx*y_L - T)² where T is a threshold (target).

The gradient with respect to h[i]:

For y_L (L ≥ 0): y_L = Σ_{u=0}^{n-1-L} h[u+L]*(1-h[u])
∂y_L/∂h[i]:
- If i appears as h[u+L] (i.e., u = i-L, valid when 0 ≤ i-L ≤ n-1-L, i.e., L ≤ i ≤ n-1): contributes (1-h[i-L])
- If i appears as h[u] (i.e., u = i, valid when 0 ≤ i ≤ n-1-L, i.e., i ≤ n-1-L): contributes -h[i+L]

For y_L (L < 0, R = -L): y_L = Σ_{u=0}^{n-1-R} h[u]*(1-h[u+R])
∂y_L/∂h[i]:
- If i appears as h[u] (i = u, valid when 0 ≤ i ≤ n-1-R): contributes (1-h[i+R])
- If i appears as h[u+R] (i = u+R, valid when R ≤ i ≤ n-1): contributes -h[i-R]

So the full gradient for the penalty:
∂P/∂h[i] = dx * Σ_L 2*max(0, dx*y_L - T) * ∂y_L/∂h[i]

import numpy as np

def repair(arr):
    """Make arr satisfy 0<=h<=1 and sum(h)=n/2."""
    arr = np.asarray(arr, dtype=np.float64).flatten().copy()
    n = len(arr)
    arr = np.clip(arr, 0.0, 1.0)
    target = n / 2.0
    diff = arr.sum() - target
    if abs(diff) > 1e-13:
        if diff > 0:
            order = np.argsort(-arr)
            for i in order:
                if abs(diff) < 1e-13:
                    break
                red = min(arr[i], diff)
                arr[i] -= red
                diff -= red
        else:
            order = np.argsort(arr)
            for i in order:
                if abs(diff) < 1e-13:
                    break
                add = min(1.0 - arr[i], -diff)
                arr[i] += add
                diff += add
    return np.clip(arr, 0.0, 1.0)

def eval_c5(h):
    n = len(h)
    dx = 2.0 / n
    vals = np.correlate(h, 1.0 - h, mode='full') * dx
    return float(np.max(vals)), vals

def gradient_penalty(h, threshold, vals, top_k=None):
    n = len(h)
    dx = 2.0 / n
    viol = np.maximum(0.0, vals - threshold)
    if top_k is not None and top_k < len(vals):
        # Only use top_k most violated
        order = np.argsort(-viol)
        viol_topk = np.zeros_like(viol)
        viol_topk[order[:top_k]] = viol[order[:top_k]]
        viol = viol_topk
    active = viol > 1e-14
    if not active.any():
        return np.zeros(n)
    grad = np.zeros(n)
    center = n - 1
    for idx in np.where(active)[0]:
        L = idx - center
        w = 2.0 * viol[idx] * dx
        if L == 0:
            grad += w * (1.0 - 2.0 * h)
        elif L > 0:
            grad[:n - L] += w * (-h[L:])
            grad[L:] += w * (1.0 - h[:n - L])
        else:
            R = -L
            grad[:n - R] += w * (1.0 - h[R:])
            grad[R:] += w * (-h[:n - R])
    return grad
