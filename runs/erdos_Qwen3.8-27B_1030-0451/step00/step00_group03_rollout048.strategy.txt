1. Approach and rationale

1.1 Central idea

Solve the supplied discrete problem directly, without replacing it by an infinite-domain or circular-autocorrelation surrogate. The search variables are the original sample values h[0:n], with dx = 2/n, bounds 0 <= h[i] <= 1, and exact mean sum(h) dx = 1, equivalently sum(h) = n/2. The authoritative objective is

    C5(h) = max_{m=0,...,2n-2} dx * np.correlate(h, 1 - h, mode="full")[m].

The objective is the maximum of many nonconvex bilinear functions, so no unconstrained CVXPY convex formulation is claimed. The implementation will be a nonconvex local-search and exact-candidate-acceptance procedure. It should be viewed as a disciplined optimizer over the discrete min-max objective and will only return candidates whose exact objective has been recomputed by the task formula.

The main mechanism is a hierarchy:

1. Feasibility is repaired by the exact Euclidean projection onto the intersection of the box and the affine mean constraint. That projection is clipping after adding a single scalar shift alpha:

    P(y) = clip(y + alpha, 0, 1)

where alpha is chosen so that sum(P(y)) = n/2. This has a rigorous feasibility foundation and avoids the invalid "clip then rescale" repair.

2. A smoothed log-sum-exp version of the max is minimized with a projected-gradient descent. The projector exactly enforces the box and integral constraints at every intermediate iterate, while every iteration produces an exact original C5 value from the original correlation formula.

3. Potentially good copies are polished by a tight epigraph SLSQP solve:

    minimize t
    subject to h in [0,1]^n, sum(h)=n/2,
               f_m(h) <= t for a selected active subset of lags m.

The original problem is nonconvex, so SLSQP can only be expected to find local stationary or near-stationary points. It is nevertheless effective for tightening near-formed candidates from 0.38085 toward the target near 0.38080.

4. Bottom-up resolution continuity: the supplied parent length 64 is retained as a fallback, then enhanced using restricted resolutions 64, 96, 128, 160, 192, 256, and for occasional later checks 320, always staying below the recommended 2500. Candidate improvedness is always judged by exact recomputation, not by any resolution error model.

5. Search diversity is supplied by:
