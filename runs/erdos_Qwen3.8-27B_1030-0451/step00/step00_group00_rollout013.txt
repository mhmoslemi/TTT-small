Actually, for a convex 1D function, the most reliable and fast method is the "bisection on subgradient" approach:

```python
def minimize_convex_1d(Q, A, G, s_lo, s_hi, tol=1e-8):
    """Minimize F(s) = max_r(Q_r + A_r*s + G_r*s^2) over [s_lo, s_hi]."""
    # F is convex. Find where 0 is in the subgradient.
    # Subgradient at s: [min_{r: active} (A_r + 2*G_r*s), max_{r: active} (A_r + 2*G_r*s)]
    # where active = {r : Q_r + A_r*s + G_r*s^2 = F(s)}
    
    lo = s_lo
    hi = s_hi
    
    for _ in range(50):
        if hi - lo < tol:
            break
        mid = 0.5 * (lo + hi)
        vals = Q + A*mid + G*mid*mid
        f_val = np.max(vals)
        active = vals >= f_val - 1e-12
        grad_lo = np.min(A[active] + 2*G[active]*mid)
        grad_hi = np.max(A[active] + 2*G[active]*mid)
        if grad_lo > 0:
            # F is increasing at mid, go left
            hi = mid
        elif grad_hi < 0:
            # F is decreasing at mid, go right
            lo = mid
        else:
            # 0 is in subgradient, mid is optimal
            return mid
    return 0.5 * (lo + hi)
```
