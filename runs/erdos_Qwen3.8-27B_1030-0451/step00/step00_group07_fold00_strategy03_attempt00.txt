1. Approach and rationale

1.1 Central idea
The returned array `h` is not merely a set of heuristic parameters: it is a length-N decision vector in the exact feasible polytope

- `0 <= h_i <= 1`,
- `sum_i h_i = N/2`,

and the only permitted objective is the literal evaluator

```text
C(h) = max_r [ dx * np.correlate(h, 1-h, mode="full")[r] ],
dx = 2 / N
```

over all `2N-1` finite-support lags. No circular autocorrelation, absolute-value correlation, smoothing surrogate, or “1 minus autocorrelation” identity may replace this objective.

The proposed primary method is a DC / convex majorization trust-region search:

- Write every one-lag overlap term exactly in terms of `u_i = 2 h_i - 1`, which maps `0 <= h_i <= 1` to `-1 <= u_i <= 1`, and the integral constraint to `sum_i u_i = 0`.
- Each correlation term is a bilinear quadratic form. Its negative endpoint-square part is concave, while the pairwise difference-squared part is convex.
- At the current feasible iterate, majorize the concave negative-square part by its tangent. This yields a convex quadratic upper surrogate for every selected lag term.
- Given a selected finite set of currently dominant lag terms, solve the convex minimax trust-region subproblem

```text
minimize t
subject to  -1 <= u_i <= 1,
            sum_i u_i = 0,
            surrogate_s(u) <= t   for all selected lags s.
```

This is a legitimate convex epigraph problem because each selected surrogate is an affine plus positive-semidefinite quadratic function and the set `{(u,t) : surrogate_s(u) <= t}` is convex. The subproblem is only a local upper surrogate to the original nonconvex task.
- Convert the solver’s `u` back to `h`, perform approved line search in the original feasible polytope, and evaluate the proposed point exclusively with the exact evaluator. Save only exact feasible improvements.

This differs materially from smoothing-log-sum-exp methods, active LP linearizations, or purely random/block-annealing schemes. The core novelty is that it exploits the exact algebraic DC structure of each shifted `h(1-h-shift)` term, not just a gradient or linear approximation around the current point, and it then uses exact rejection on the original evaluator to make any unsafe local model irrelevant to the returned bound.

1.2 Bottleneck addressed
The target improvement from the current near-record around `0.38085` to about `0.3808` is tiny. Such improvements typically require moving the solution through local equilibria where many truncated one-sided constraints are tied or nearly tied. Smooth surrogate methods may create false descent directions and then reject them because neglected nonactive shifted terms rise; exact LP linearizations may only improve first-order directions. The DC majorization defines a globally valid convex upper envelope for selected bilinear terms at the current iterate and places the search directly on the geometry of the original bilinear overlap terms. Exact rejection allows it to cross basins without ever accepting a surrogate success.

1.3 What is mathematically justified and what is heuristic
Justified:

- The exact evaluator is finite, one-sided, and boundary-aware.
- The feasible polytope for the returned vector is well-defined: box plus one linear equality.
- The algebraic DC rewriting and tangent majorization are valid pointwise upper models of each shifted correlation term.
- The convex surrogate subproblem is a legitimate convex upper model on the chosen active lag set.
- Any final returned value is an actual task bound if feasibility is verified and the exact evaluator output is recomputed.

Heuristic or untested:

- The DC trust-region search does not prove global optimality.
- Active-set selection affects speed and quality.
- Random initialization and multi-resolution transfers may help discover a better basin; this is a hypothesis, not a proven fact.
- Solver success depends on numerical solver behavior and time budget; no optimality claim survives solver failure.

1.4 Fallback requirement
If `initial_h_values` is available and feasible, it is the guaranteed first incumbent. If it is unavailable or invalid, a deterministic feasible fallback such as a mass-projected sinusoidal or uniform vector is newly generated algorithmically. The program must always return a feasible validated vector, even if the search fails.

2. Mathematical specification

2.1 Representation, constraints, and exact objective
For a run choosing `n_points = N`:

- `h ∈ R^N`, `dx = 2 / N`, `target = N/2`.
- Feasibility: `0 <= h_i <= 1` and `sum_i h_i = target`.
- Strict expected bound:

```text
C(h) = max_{r=0}^{2N-2} np.correlate(h, 1-h, mode="full")[r] * dx.
```

Equivalent scalar form:

```text
C(h) = dx * max_r corr_r,    corr = np.correlate(h, 1-h, "full").
```

The final returned value must equal the scalar computed by this exact formula for the returned vector and returned `N`.

2.2 Shift notation and direct lag terms
Use integer shifts `s = -(N-1), ..., N-1`. For shift `s`, define

- `ell_s = N - abs(s)`.
- `left_start_s = max(0, -s)`.
- indices `I_s = left_start_s, left_start_s+1, ..., left_start_s+ell_s-1`.
- corresponding `J_s = I_s + s`.

The direct shifted overlap term is

```text
T_s(h) = dx * sum_{p=0}^{ell_s-1} h[I_s[p]] * (1 - h[J_s[p]]).
```

The set `{T_s(h) : s = -(N-1),...,N-1}` should be the same multiset, up to permutation, as the evaluator terms. This fact is checked at runtime by sorting the evaluator terms and this direct set for several deterministic H vectors and comparing with a tight tolerance. The search uses the direct shifts; the final bound uses `np.correlate`.

If the direct term set cannot be validated, disable the DC/convex subproblem search but continue exact random and transfer-based local generation, retaining the parent or fallback. No candidate with an unvalidated surrogate path is ever accepted through surrogate claims.

2.3 `u` transformed variables
Define

```text
u_i = 2 h_i - 1,   u_i ∈ [-1,1].
h_i = (u_i + 1) / 2.
```

For a pair `(i,j)` associated with shift `s`, let

```text
h_i(1-h_j) = ((1 + u_i)/2) * ((1 - u_j)/2)
           = 1/4 + (u_i - u_j)/4 - u_i u_j/4.
```

For distinct variables this can be rewritten exactly as a difference-of-convex quadratic:

```text
h_i(1-h_j)
 = 1/4 + (u_i-u_j)/4
   + (1/8) * [ (u_i-u_j)^2 - u_i^2 - u_j^2 ].   (raw D-C form)
```

For a shift with a pair set that may contain `i=j`, the same pairwise expression works if the pair is treated as having two endpoint contributions; this recovers `h_i(1-h_i) = (1 - u_i^2)/4`.

2.4 Majorization at the current point
Let the current safe iterate satisfy

```text
h^0 ∈ [0,1]^N, sum h^0 = N/2,    u^0 = 2 h^0 - 1.
```

For a pair `(i,j)`, replace the concave negative square terms by tangent upper bounds:

```text
- u_i^2  <=  -2 u_i^0 u_i + (u_i^0)^2,
- u_j^2  <=  -2 u_j^0 u_j + (u_j^0)^2.
```

Therefore the pairwise surrogate upper bound for one shift constraint is

```text
P_s(u; u^0)
  = dx * sum_{pairs (i,j) in s} [
        1/4
      + (u_i - u_j)/4
      + ((u_i - u_j)^2)/8
      + ((u_i^0)^2 + (u_j^0)^2)/8
      - (u_i^0 * u_i + u_j^0 * u_j)/4
    ].
```

Properties to verify:

- For `u = u^0`, `P_s(u^0; u^0) = T_s(h^0)` exactly to numerical precision.
- For all `u ∈ [-1,1]^N`, `T_s(h(u)) <= P_s(u; u^0)`.
- `P_s` is convex in `u` because its quadratic part is a nonnegative combination of `(u_i-u_j)^2`, and the remaining terms are affine.
- The epigraph constraint `P_s(u; u^0) <= t` is convex.

2.5 Active selected epigraph subproblem
At a current feasible `h^0`, compute direct terms `T_s` for all shifts. Select an active set `A` from the largest terms and near-max terms. On `A`, solve approximately:

```text
minimize t
subject to sum_{i=0}^{N-1} u_i = 0,
           -1 <= u_i <= 1,
           P_s(u; u^0) <= t   for s in A.
```

Because only exact feasible points generated by interpolation from current point and solver point are accepted, an active set that omits a lag that later becomes maximal is harmless: such proposals are rejected by the original evaluator.

2.6 Constraint gradients and solver formulation
Let the solver variable vector be

```text
x = [u_0, ..., u_{N-1}, t].
```

Objective:

```text
f_0(x) = t,
grad f_0 = [0, ..., 0, 1].
```

Equality constraint:

```text
g_eq(x) = sum_{i=0}^{N-1} u_i = 0,
Jac g_eq = [1, ..., 1, 0].
```

Box bounds:

- `u_i ∈ [-1, 1]`.
- `t ∈ [0, 2]`. The lower bound is harmless; the upper bound avoids the solver wandering into impossible values.

Inequality constraints are slacks

```text
g_s(x) = t - P_s(u; u^0) >= 0.
```

For pairwise flat gradient, for pair `(i,j)` and current pair difference `a = u_i - u_j`:

```text
partial P_s / partial u_i =
    dx * [ 1/4 + a/4 - u_i^0/4 ].

partial P_s / partial u_j =
    dx * [ -1/4 - a/4 - u_j^0/4 ].
```

For constraint weights/slack Jacobian:

```text
partial g_s / partial [u] = - gradient[P_s]
partial g_s / partial [t] = 1.
```

If pair `i=j`, adding the `i` and `j` contributions gives the correct combined derivative for the same coordinate.

2.7 Active-set parameters
For all shifts, compute `T_s`. Let

```text
c_direct = max_s T_s.
```

To be risk-averse, create the active set from this validated direct maximum.

Construct `A` by:

1. Always include the largest term.
2. Include all shifts satisfying `T_s >= c_direct - eta`.
