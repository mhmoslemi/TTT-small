1. Approach and rationale

1.1 Central idea. The discrete problem is a nonconvex minimax over a box-constrained, fixed-mass polytope. The proposed construction does not try to move only along feasible coordinate-pair directions. It changes the parameterization: every smooth descent candidate is represented by an unconstrained vector and is converted, on demand, into an exactly balanced step vector by solving a one-dimensional shifted-logistic normalization problem. This gives a strict joint feasibility map:

    z  ->  h(z),   0 < h_i(z) < 1,   sum_i h_i(z) = n/2.

The main descent stages then optimize a smooth upper approximation of the exact correlation maximum over z. Acceptance, publication of a new bound, fallback selection, and final output are always decided by the original evaluator

    max_k dx * sum valid h_i(z) (1 - h_j(z))

computed with `np.correlate(h, 1-h, "full") * dx`. The parameter change is the substantive difference from earlier feasible-pair/Frank-Wolfe style plans: constraints are built into the decision variable rather than generated by many short exact-pair acceptance loops. A derivative-free direct exact Powell stage and a small multi-start population are used to counter the nonconvexity of the exact objective, but all accepted candidates are queried by the true evaluator.

1.2 Why this may improve the supplied parent. The supplied parent is already a high-quality point near a local optimum. Naive clipping/remass checks often break feasibility or move away from the relevant boundary. The shifted-logistic parameterization preserves mass and bounds to tight tolerance automatically, allowing the smooth surrogate to move continuously near saturated coordinates without needing repeated coordinate pair corrections. The smooth maximum gradient can use information from many nearly tied lags at once: pairs/cycles use one or a few active terms. The exact direct Powell objective can polish points whose full max is lower but whose smooth surrogate remains rough. Multi-start perturbations, reversal/complementary starts, and deterministic balanced starts explore disconnected basins that can exist around local optima of this finite-support cross-correlation problem. This is heuristic; optimization in the smooth/logit transformed problem does not prove global optimality and the exact objective may occasionally worsen during descent. It is therefore used to propose candidates, not to certify optimality.

1.3 Bottlenecks addressed.

- Joint box and mass constraint. Raw unnormalized vectors cannot normally be clipped and rescaled simultaneously without making every sum-correction damage bounds. The shifted-logistic normalization avoids this split: the map is bounded and mass constraint is solved by one monotone root.
- Fluctuation over many nearly tied lags. A direct active-coordinate pair move can become stuck when gradients alternate between lags. Softmax weighting over all correlation entries gives a smooth aggregate gradient and lets a quasi-Newton method move a larger pattern.
- Surrogate overreliance. The softened max is a bound with a controllable approximation gap, but the true score can differ. Exact evaluation is used in every function call (both objective and gradient cache evaluations), in a direct exact Powell search, and at final output. Therefore no surrogate score becomes the reported bound.
- Boundary values. The parent may have exact zeros/ones. Starting from logit parameters in exact boundaries would be forbidden, so parent data are converted to a high-accuracy interior representative. If the exact optimum lies on boundary, a strict representative may only approach it; the parent is always retained and closure via hard clipped projection is available for candidate generation and final checking.
- Local minima. The proposed default retains parent fallback, tries structured parent variants, deterministic balanced/mechanical seeds, and randomized restarts around the best interior vector. Dimension transfers are occasionally attempted for much smaller resolutions because the discrete objective is legal for any n, but a new resolution is only kept if its exact evaluator score improves.

1.4 Limitations. No global proof is claimed. The transformed logistic parameterization omits strict boundary points (values exactly 0 or 1) and uses regularized derivatives when all sampled coordinates are nearly saturated. A smooth local maximum score approximated by finite-neighborhood descent can be close but not exact; acceptance filters by exact score. Cross-dimensional comparison compares two different discretizations objectively through the same dimensionless score, but not by parameter count alone.

2. Mathematical specification

2.1 Discrete representation and exact metric. For a candidate vector

    h = (h_0,...,h_{n-1}), dx = 2.0/n

define q = 1 - h and use exactly the evaluator convention:

    C5(h) = dx * max_{m=0,...,2n-2} np.correlate(h, q, mode="full")_m.

All lags and both directions are included automatically by full linear correlation, finite support and zero padding. Let S = n/2.

With the NumPy formula `np.correlate(a,v, mode="full")`, output index m can be written using offset

    r_m = m - (n - 1),

and valid second-array/correlation index j satisfying

    j_low = max(0, -r_m),
    j_high = min(n, n - r_m),

    term_m(h) = sum_{j=j_low}^{j_high-1} h_{j+r_m} * (1 - h_j).

Then

    Phi_m(h) = term_m(h) * dx,
    C5(h) = max_m Phi_m(h).

This is the sole authoritative formula. Do not replace the maximum by an autocorrelation identity, and do not force h to be binary.

2.2 Feasible polytope and strict-logit normalization. The continuous feasible polytope is

    sum sigma(z_i-a_high) <= S.

This tolerance range is sufficient for bounds [-20,20] and S=n/2. At the root, h_i lies in (0,1) to machine precision and sum h_i is solved to about 1e-14 absolute residual in the function evaluation, depending on floating rounding. 1. Approach and rationale

1.1 Central idea. The discrete objective
    C5(h) = dx * max_m [np.correlate(h, 1-h, mode="full")_m],  dx = 2/n
is a finite nonconvex minimax problem over the polytope P={h: 0<=h_i<=1, sum_i h_i=n/2}. The plan does not rely on local pair moves or a direct convex relaxation. It introduces an exact constraint transpose: every candidate during smooth optimization is represented by a raw design vector `z` and mapped to a feasible vector by a unique shifted-logistic mass-normalization equation. The smooth maximum of Phi_m is therefore minimized in a space in which the constraints are satisfied automatically. Accepted points are evaluated and published using the literal evaluator. A direct exact Powell stage then searches against the true objective to compensate for the surrogate maximum error.

1.2 Why this may improve the supplied parent. The parent is already near a local plateau. In a standard coordinate or pair direction, small improvements may be blocked by saturating entries and an active set that ties many lags. A shifted-logistic optimization move simultaneously changes many values and the normalization shift. The log-sum-exp approximation of the maximum distributes gradient over all near-maximal correlated lags. The hard threshold features can be converted to smooth interior starting analogs, and when strict interior coordinates are not enough, a convex clipped project is retained for hard/mixed proposals and for final exact-sum closure. The combined method is dedicated to improving around the parent exact optimum, and the parent is a guaranteed fallback. It is explicitly a nonconvex heuristic and not a global certificate.

1.3 Bottleneck handled. The solution treats three real difficulties together:
  - exact feasibility of sum and box: solved by one one-dimensional monotone map; no repeated clip followed by uniform scaling which generally destroys the sum constraint;
  - active lag ties: smooth weights include all entries of the correlation vector, making a smooth descent direction reasonable for the max;
  - nonconvex local plateau: multi-start algorithmic parent/threshold/balanced seeds, best-vector perturbations and direct exact Powell prevent the entire run from being trapped only by smooth-max derivative behavior.

1.4 Justified facts versus heuristic hypotheses. Justified: the normalized projection map is strictly feasible and monotone root is unique; the log-sum-exp is a guaranteed upper bound with bounded additive gap. Heuristic/unestablished: the composite method may improve the parent but gives no proof of global optimality. Boundary coordinates cannot be directly represented by these log parameters, so strict values exactly 0 or 1 are handled by clipped maps or parent fallback, while a wrapped/logit search approaches the boundary implicitly. It is also possible that a transition-low resolution has a lower exact score - that would be purely an additional discretization effect and is not assumed.
