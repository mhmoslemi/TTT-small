```python
    # Final: re-evaluate and return
    best_c5 = evaluate_c5(best_h)
    N_final = len(best_h)
    
    # Ensure sum constraint is satisfied (should be automatic for anti-palindromic)
    # But verify
    S_target = N_final / 2.0
    if abs(best_h.sum() - S_target) > 1e-10:
        best_h = project_feasible(best_h, S_target)
        best_c5 = evaluate_c5(best_h)
    
    return best_h, best_c5, N_final
```
