<strategy>
1. Approach and rationale

The objective is
\[
C_5(h)=\max_{q=0,\dots,2n-2} z_q(h),\qquad z_q(h)=\frac{2}{n}\,\text{corr}_q(h,1-h),
\]
subject to
\[
0\le h_i\le 1,\qquad \sum_{i=0}^{n-1}h_i=\frac{n}{2}.
\]
The supplied parent is already very close to the target, so the bottleneck is not constructing a totally new global discretization but escaping a shallow local region and polishing/finishing the parent until the exact evaluator gives a value below 0.3808.

The central plan is:

1. Keep the problem exactly as evaluated, but add two surrogate layers:
   - a smooth-max objective whose gradient can be computed efficiently;
   - an epigraph minimax local solver, where a scalar variable t upper-bounds every exact correlation lag and t is minimized.
   Both surrogate methods are run as local methods only. Final acceptance and return require recomputation of the original evaluator metric.

2. Enforce feasibility by an exact differentiable/nontrivial water-filled projection onto the box-plus-sumpolytope after all surrogate displacement and by final repair before return.

3. Explore the parent’s neighborhood in several coherent ways:
   - direct parent polish;
   - reflected/complemented symmetries that preserve the exact objective and increase basin diversity;
   - spatially random perturbations around the parent;
   - upsampling parent to two or four times its resolution, optimizing more finely, then downsampling through block averages to recover a compact candidate;
   - more distant random constructions as diversity starts.

The solver combination explicitly does not claim a global optimum. Nonconvex products enter every lag; a CVXPY global model would be invalid unless a certified convex relaxation and activation recovery were supplied, which is outside the budget. Therefore use surrogate local minimizers, track all accepted candidates using the exact objective, and retain a validated parent fallback.

2. Mathematical specification

2.1 Discrete representation

Let n_points = n, dx = 2/n, T = n/2. A candidate is h in R^n.

For q = 0,...,2n-2 define lag ell_q = q-(n-1), integer in -(n-1),...,n-1. The correlation values in the lags used internally must be arranged in the same order as q. A convenient equivalent direct definition is:
\[
C_q(h)=\sum_{u=\max(0,-\ell_q)}^{\min(n-1,n-1-\ell_q)}
 h_{u+\ell_q}(1-h_u),
\]
and z_q(h)=dx C_q(h). The actual evaluator is authoritative:
\[
\hat C_5(h)=\max_q \left(\text{np.correlate}(h,1-h,\text{"full"})\right)_q dx.
\]
For final evaluation, always call np.correlate(h,1-h,mode="full") and take max()*dx. The manual C vector is for optimized storage consistent with that formula.

Target objective minimization:
\[
\min_{h,t} t \quad \text{s.t. } z_q(h)-t\le 0 \quad \forall q, \quad
0\le h_i\le1, \sum_i h_i=T.
\]
This epigraph form is exact for the max if all lag constraints are enforced. The feasible set is nonconvex because z_q is bilinear.

2.2 Gradient for an individual exact lag

Let b_i=1-h_i. The unscaled derivative \partial C_q / \partial h_i is
\[
\frac{\partial C_q}{\partial h_i}
 =
\begin{cases}
 b_{i-\ell}, & 0\le i-\ell<n,\\
 -h_{i+\ell}, & 0\le i+\ell<n,
\end{cases}
\]
with the two contributions added where valid. Equivalently, derivatives use slicing in a vectorized way:

- ell = 0:
  C_0 = dot(h,b);
  row = dx*(b-h)=dx*(1-2h).
- ell>0, length L=n-ell:
  C_ell = dot(h[ell:], b[:L]);
  derivative row:
    row[ell:] += dx*b[:L]
    row[:L]   -= dx*h[ell:]
- ell<0, ell=-a, length L=n-a:
  C_{-a}=dot(h[:L], b[a:]);
  derivative row:
    row[:L]   += dx*b[a:]
    row[a:]   -= dx*h[:L]

This exactly constructs all derivatives of z = corr(h,1-h)*dx.

2.3 Smooth-max objective and gradient

Given z of length m=2n-1 and temperature tau>0, define the smooth surrogate
\[
F_\tau(h) = z_q^* + \tau\log\sum_q \exp\left(\frac{z_q-z_q^*}{\tau}\right),
\]
where q^* is any maximum lag, implemented stably by shifting z-z^*. Let softmax weights p_q be the result. The gradient is
\[
\nabla_h F_\tau(h) = \sum_q p_q [\nabla_h z_q(h)].
\]
The vector is assembled by the same row slices above. During optimization, p_q with exp argument below -50 may be dropped to zero (without changing total by more than negligible amounts) to save time.

F_tau replaces the hard max during PGD but is not accepted as final proof. Because F_tau may have a bias tau log(number of weighted lags), record candidate hard objective H=C_eval_technical(h) every so many iterations and independently train blob the accepted best path for lower H.

\[
y(\lambda)=\operatorname{clip}(x-\lambda,0,1),\quad \sum_i y_i(\lambda)=T.
\]
Since \sum y_i λ is continuous and decreasing, find λ by bracket expansion (or clearly sorted numeric fallback) followed by 50-60 bisection iterations anchored with sum_y above and below T. Use tolerance relative to floating numerical summation. Failed repair returns derived fallback.
