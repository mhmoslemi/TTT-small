1. Approach and rationale

The search starts from any supplied parent sequence and treats the discretized problem as a nonconvex box-constrained min–max problem over a finite set of bilinear correlation constraints. The supplied evaluator is linear correlation with finite support, not circular correlation, and the returned bound must be the maximum over all `2 n - 1` lags, computed exactly with `dx = 2/n`. Because the objective is finite-dimensional, nonconvex, and only slightly needed to be improved from `0.38085` to near `0.3808`, the chosen primary method is a local-to-semiglobal projected active-constraint descent. It uses exact feasibility repair, exact scoring for acceptance, smooth approximations only for generating directions, and resolution up-scaling from the parent to escape a low-resolution trap.

Central idea:

- At a feasible candidate `h`, compute all overlap constraints.
- Honor the constraints that are currently largest by assigning softmax-like positive weights to the highest one or several constraints.
- Compute the exact gradient of the weighted sum of these chosen smooth bilinear functions with respect to the `h` variables.
- Move in the negative weighted-gradient direction and immediately project the result back to the joint feasible set `0 <= h_i <= 1` and `sum_i h_i = n/2`.
- Accept a step only if it improves the exact current local objective or is a smooth descent move that still keeps the exact score near the current local value. Update the best global candidate by exact exposition score only.
- Add several justified variations: different active-set sizes, smoothing temperatures, small random feasible perturbations, and resolution transfers by linear interpolation plus joint projection. This prevents long stagnation and can improve resolution effects without claiming global optimality.

Why this can improve the supplied parent:

- The supplied parent is likely already in a good local basin. Small local improvements of size a few `1e-5` are achievable by moving exactly in the negative direction of the dominant face constraints.
- The exact integral identity
  `sum_lag (C_lag / dx) = (sum_i h_i) (sum_j (1-h_j)) = n^2 / 4`
  allows correlation mass to be redistributed among lags. Optimizing weighted highest constraints gives a principled way to reduce the maximum by trading mass away from the currently largest constraints.
- Resolution transfer can reduce several discrete alignment artifacts, but every post-transfer candidate is re-scored with the authoritative linear-correlation metric, so it cannot falsely improve by changing discretization conventions.

Important limitations and facts:

- No global optimality is claimed. The problem is nonconvex because products `h_i(1-h_j)` occur.
- The smooth weighted objective is a heuristic surrogate. It is used only to generate directions, while exact scoring and best-candidate storage guarantee that no returned solution has a stated bound larger than its exact computed objective.
- Interpolation may initially make the higher-resolution score worse. This is allowed and only beneficial if followed by local refinement. The parent remains a valid fallback at all times.
- Clipping after a linear move is not a feasible correction; the joint projection method section 2.5 is mandatory for every candidate.

2. Mathematical specification

2.1 Representation and constraints

For a candidate vector `h` of length `n`:

- `dx = 2.0 / n`.
- Feasibility requires:
  - `0 <= h[i] <= 1` for every `i = 0, ..., n-1`.
  - `sum(h) * dx = 1`, equivalently `sum(h) = n/2`.
- The sum constraint target is `target_sum = 0.5 * n`, a float value. For odd `n` it is a half-integer; nevertheless, the initial parent is length 64 and the planned schedule generally uses even sizes.

2.2 Exact objective

The returned bound must be computed as

`C(h) = max( np.correlate(h, 1-h, mode="full") ) * dx`.

Internal search uses an equivalent finite-support lag vector. Define for each signed lag `d = -(n-1), ..., n-1`

`C_direct(d) = dx * sum over i where 0 <= i < n and 0 <= i+d < n of h[i] * (1 - h[i+d])`.

This direct vector contains the same numerical values as the full linear-correlation vector, possibly in reversed lag order, and therefore has exactly the same maximum. The coder may use the direct vector internally for gradient calculations, but final acceptance, best-storage, and the returned `c5_bound` must use an exact evaluator whose logic is:

`return float(np.max(np.correlate(h, 1-h, mode="full")) * (2.0/len(h)))`.

If a resolved `score_exact` helper computes that expression, use it as the sole authoritative scoring function for:

- initial parent score;
- every accepted local move;
- best global candidate storage;
- final returned bound.

2.3 Constant mass identity

With exact feasibility, every pair `(i,j)` with `0 <= i,j < n` appears once in exactly one full-support correlation lag `d = j - i`, so

`sum_d sum_i h[i] (1-h[i+d]) = (sum_i h[i]) (sum_j (1-h[j])) = (n/2)*(n/2) = n^2/4`.

Therefore the total unscaled correlation mass is fixed. The search minimizes how concentrated that fixed mass is in the largest lags. This explains why optimizing weighted active constraints is meaningful and why adding the sum of all constraints with equal weights cannot help: it is constant.

2.4 Active-constraint weighted surrogate

At a feasible current candidate, compute the direct overlap values `C_direct`, capped for severe outliers by a tiny numerical floor (all values finite after projection). Let the full sorted list descending be `C_sorted[0] >= C_sorted[1] >= ...`.

Choose a positive integer

`active_count = min(2*n-1, max acknowledged parameters, e.g. 16, 24, 32, 64)`.

Let `p_i` for the selected active positions be positive weights summing exactly to 1. The smooth surrogate is

`S_slow(h) = sum_{i=1}^{active_count} p_i * C_chosen_i(h)`.

Weights can be generated by softmax among the chosen constraints. To avoid overflow, use stable logits:

- Choose a temperature `T > 0`.
- For selected chosen values `v_j`, define
  `e_j = exp((v_j - max_selected_value) / T)`.
- Set `p_j = e_j / sum_i e_i`.

If `max_selected_value - min_selected_value` is very small, the weights become nearly uniform, which is desirable at local plateaus. If `T` is small, weights concentrate on the current peak, producing an approximate max-min jacobian.

The surrogate is not convex. It is an active-set linear-mass-transfer proxy for a locally smooth version of the exact max objective. It is used only for gradient directions and line-search decisions; every displayed or stored bound is from the exact objective.

2.5 Gradient of the weighted active sum

For each selected direct lag `d`, define the valid index interval:

`start_d = max(0, -d)`.
`stop_d = n - max(0, d)` using Python half-open slice semantics.

Let `I = np.arange(start_d, stop_d)` and `J = I + d`.

The contribution for lag `d` is

`V_d = sum_{i in I} h_i * (1 - h_{i+d})`,
`C_d = dx * V_d`.

Since `dx` is a positive scalar, the gradient of the normalized weighted surrogate is proportional to the weighted sum of the gradients of the unscaled `V_d`. For a lag `d` with weight `p` (`unused inactive lags have `p=0`):

For every pair `(i, j=i+d)`,
- derivative with respect to `h_i` contributes
  `p * (1 - h_j)`.
- derivative with respect to `h_j` contributes
  `-p * h_i`.

Thus for each selected lag:

- `I_i = start_d, ..., stop_d-1`,
- `J_i = I_i + d`,
- `grad[I_i] += p * (1 - h[I_i+d])`,
- `grad[J_i] += p * (-h[I_i])`.

For `d=0`, both contributions apply to the same index, and the code accumulates both, which correctly gives `p * (1-h_i) - p * h_i = p * (1-2h_i)`.

The direction for a trial move is

`d_h = - grad / max(max(|grad|), tiny)`.

Use `tiny=1e-14` to avoid division by zero. The first-order direction is normalized in infinity norm so that trial step size `alpha` has approximately a per-coordinate step limit.

2.6 Joint feasibility projection

The feasible set is the intersection of a coordinate box and one hyperplane. Clipping and an independent final scaling cannot be used as separate corrections. Use Euclidean-like projection:

Given any vector `x`, project to

`F = { y: 0 <= y_i <= 1, sum_i y_i = target_sum }`.

Define for a scalar `theta`

`f(theta) = sum_i clip(x_i - theta, 0, 1) - target_sum`.

`f(theta)` is continuous and strictly nonincreasing. Choose bracket bounds:

- `lo = min(x) - 1.0`, where all terms are at least 1 so `f(lo) >= n - target_sum >= 0`.
- `hi = max(x)`, where all terms are at most 0 so `f(hi) <= -target_sum <= 0`.

Use 35 to 45 bisection iterations:

- `mid = (lo+hi)/2`.
- If `f(mid) > 0`, set `lo = mid` (need a larger shift to decrease mass).
- Otherwise set `hi = mid`.
- Return `theta = (lo+hi)/2`.

Then

`y = clip(x - theta, 0, 1)`.

Finally correct floating rounding by exact sum repair:

- Let `err = target_sum - sum(y)`.
- If `|err| <= 1e-11`, clip very small values:
  - Set any `y_i` in `[-eps, eps]` to `0.0`.
  - Set any `y_i` in `[1-eps, 1+eps]` to `1.0`.
  - Recompute `err` once and distribute it.

Distribute `err` over feasible slack:

While `|err| > 1e-10` and available iterations remain:

- Compute lower slack `sl_lo_i = y_i` and upper slack `sl_hi_i = 1 - y_i`.
- If `err > 0`, select indices with `sl_hi_i > 1e-9` and add equally `err / count`, bounded by slack.
- If `err < 0`, select indices with `sl_lo_i > 1e-9` and add equally `err / count`, bounded by `-sl_lo_i` (i.e., reduce no below 0).
- Recompute and clip tiny transient violations.

Because the projection bracket is feasible in theory and target_sum is achievable in `[0,n]`, this repair succeeds unless floating catastrophic degeneracy occurs. If it fails, use the constant vector `full(n,0.5)` as a known feasible fallback for that resolution; its sum is `n/2` exactly within binary floating point for typical sizes, and it respects bounds.

The helper `project_feasible(h, n)` must always return a vector that has been passed through this projection, not just clipping. Every projected trial candidate used for acceptance or for interpolation starts must be projected before scoring.

2.7 Resolution transfer

When increasing resolution from parent length `n_old` to `n_new`, use linear interpolation of the supplied parent representation:

- Use sample centers `x_old = 2 * (np.arange(n_old) + 0.5) / n_old`.
- Use sample centers `x_new = 2 * (np.arange(n_new) + 0.5) / n_new`.
- Compute `z = np.interp(x_new, x_old, h_old)` with endpoints handled by nearest-edge values (standard `np.interp` behavior).
- Project `z` with `project_feasible(z,n_new)` to enforce the new sum and box constraints.

This transfer preserves approximate shape but does not claim exact objective inheritance. The parent best candidate and its exact score are retained; higher resolution is accepted only for lower exact scores.

1. Approach and rationale

The search starts from any supplied parent sequence and aims to reduce the exact discrete Erdos-overlap objective by locally improving the largest finite-support linear-correlation constraints. The supplied objective is not circular and not autocorrelation with the unshifted vector removed; it is the maximum over all `2 n - 1` signed lags of

`max vector np.correlate(h, 1-h, full) * dx`,

with `dx = 2/n`. The returned bound and every acceptance decision must therefore be computed using that exact evaluator or by a helper whose logic is checked to be identical.

The central method is a constrained active-constraint projected descent. The exact feasible set is a hyperplane intersecting a box. Joint Euclidean-style projection is used after every trial move. At each iterate, the current largest overlap constraints are assigned positive weights, their exact weighted gradient is computed, and a projected move opposite the gradient is tested by line search. The smooth weighted objective is only a direction surrogate; the exact full lag score is always used for accepting the best candidate. The method is therefore not a global optimum claim. It should be understood as a high-precision local and semi-global improvement method on top of a good parent.

Why this addresses the parent bottleneck:

- The supplied record likely lies in a narrow local basin where the maximum is determined by a small number of dominant lags. Changing only those dominant coefficients, while preserving sum and bounds exactly, can reduce the maximum by a few units in the fifth decimal.
- The total linear-correlation mass is fixed under exact feasibility: every pair `(i,j)` appears exactly once among all lags, hence the sum of unscaled correlation values is `(n/2)*(n/2)`. Thus the problem is essentially redistribution of a fixed mass away from the highest lags. Weighted gradients of the highest constraints make that redistribution explicit.
- Resolution transfer by interpolation followed by projection can reduce low-resolution discretization artifacts. However, higher resolution is accepted only after exact scoring, and the parent score remains a fallback throughout.

Important facts versus hypotheses:

- Exact fact: joint projection preserves `0 <= h_i <= 1` and `sum(h) = n/2` in a single mechanism. Clipping plus independent rescaling does not.
- Exact fact: the direct signed-lag vector contains the same values, possibly reversed relative to `np.correlate`, so its maximum is equal. Use it for gradients and internal surrogate weights.
- Exact fact: the problem is nonconvex. No global optimality is claimed.
- Hypothesis/heuristic: smooth top-constraint descent and random perturbations will find a slightly lower curve than the parent. Different weights, temperatures, perturbation radii, and resolution scales are used to mitigate this stochastic dependence.
- If no improvement is found within the budget, the parent remains returned because its exact bound is still valid. The algorithm must not fabricate or paste large initial arrays.

2. Mathematical specification

2.1 Vector, grid, and constraints

For a candidate vector `h` of length `n`:

- `dx = 2/n`.
- Feasible if `0 <= h_i <= 1` for all `i`.
- Feasible if `sum_i h_i = n/2`, equivalently `sum_i h_i * dx = 1`.
- `n` is derived at runtime. If the parent is present, use its length. Otherwise use a small constructed even size, preferably `64`, with `n <= 2500`.

2.2 Authoritative objective

Define the exact scorer as follows in conceptual form:

Given one-dimensional `h` length `n`, set `b = 1 - h`, compute the full linear correlation vector `np.correlate(h, b, mode="full")`, multiply it by `2/n`, and return the maximum finite entry as a float.

All stored objective values, acceptance thresholds, variation-comparison values, and the final tuple's `c5_bound` must be produced by this authoritative score. If the internal direct-lag scorer ever disagrees with this authoritative maximum beyond a very small tolerance, use the authoritative scorer for that candidate and abort gradient-based line-search atoms for that iteration. Return the parent or best stored candidate through emissions if such mismatch occurs.

2.3 Direct lag value for gradients

For signed lag `d = -(n-1), ..., n-1`, define

`start_d = max(0, -d)` and `stop_d = n - max(0,d)` using half-open slice notation.

The direct lag contribution is

`C_d = dx * sum_{i=start_d}^{stop_d-1} h_i * (1 - h_{i+d})`.

The array of all `C_d` in increasing signed-lag order has the same element set as `np.correlate(h, 1-h, full) * dx`, though the lag axis may be reversed. The maximum is identical.

2.4 Constant mass identity

With exact feasibility, each ordered pair `(i,j)` with `0 <= i,j < n` occurs exactly once as `j = i+d` for some lag `d`. Thus the sum of all unscaled lag sums

`sum_d sum_i h_i (1-h_{i+d})`

equals `(sum_i h_i) (sum_j (1-h_j)) = (n/2)^2 = n^2/4`. This identity is a sanity check and explains why minimizing the maximum amounts to redistributing fixed mass from highly correlated lags. Any surrogate that adds all constraints with equal weights has no effect because that sum is constant.

2.5 Active surrogate and weights

At a current iterate, compute direct lag values `C_d`. Select `q` strongest constraints, where `q` is an explicit parameter, and assign positive weights `p_k` summing to one. A stable softmax among selected values is:

- Let selected largest values be `r_1 >= r_2 >= ... >= r_q`.
- Let `m = r_1`.
- For temperature `T > 1e-7`, let `e_k = exp((r_k - m)/T)`.
- Set `p_k = e_k / sum_j e_j`.

If `T` is very small, all weight is on the current maximum. If `T` is larger, weights flatten, which allows descent while a plateau of constraints shifts.

The surrogate objective is

`S = sum_k p_k C_{d_k}`.

Use this surrogate only for the line-search descent condition, never for storing the final returned bound.

2.6 Exact gradient

For lag `d`, let `I` be integer indices from `start_d` to `stop_d - 1`. Let `J = I + d`. For each pair:

- the derivative of `h_i (1 - h_j)` with respect to `h_i` is `1 - h_j`;
- the derivative with respect to `h_j` is `-h_i`.

For selected lag `d_k` weight `p_k`, accumulate:

`grad[I] += p_k * (1 - h[J])`,

`grad[J] += p_k * (-h[I])`,

with additive accumulation because indices can overlap across lags, including the `d=0` case. The full gradient of the weighted surrogate in unscaled score units is the sum over selected lags. The final step scale is irrelevant up to line search because `dx` is positive, but keep it consistent using unscaled values or scaled values both fine.

Use a tiny normalization of the direction: let `s = max(max(abs(grad)), 1e-14)`, and set move direction `V = -grad / s`.

If the largest `grad` magnitude is smaller than `1e-9` and exact descent attempts have failed, enter perturbation or resolution stages; do not use a meaningless random direction without some descent/projection safeguard.

2.7 Joint feasibility projection

Projection is mandatory for every trial move, every perturbation, and every interpolation. Given any real `x` length `n` and target sum `s = n/2`, find `theta` such that

`sum_i clip(x_i - theta, 0, 1) = s`.

The function `f(theta) = sum_i clip(x_i - theta,0,1) - s` is continuous and decreasing. Use a bracket:

- `lo = min(x) - 1`: all clipped terms are at least 1, so `f(lo) >= n - s >= 0`.
- `hi = max(x)`: all clipped terms are at most 0, so `f(hi) <= -s <= 0`.

Bisect for `theta` for 35 to 45 iterations. Return the clipped projected vector and then run an exact rounding repair.

Rounding repair insisting both constraints:

1. Clip values with tolerance about `1e-10` to exact `0` or `1`.
2. Compute `err = s - sum(h)`.
3. If `|err| <= 1e-11`, stop.
4. If `err > 0`, distribute `err` uniformly over coordinates with upper slack `1 - h_i > 1e-9`, never exceeding their个体的 slack.
5. If `err < 0`, distribute negative amount over coordinates with lower slack `h_i > 1e-9`, never below zero.
6. Repeat five to eight rounds until absolute error below `1e-9` or `1e-10`. If failure occurs due a degenerate corner, fall back to constant vector `full(n,0.5)` for that `n`.

This is a single joint feasibility mechanism: box constraints and sum constraint are all represented by the shifted-clipping bracket before repair.
