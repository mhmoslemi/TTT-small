1. Approach and rationale

1.1 Central idea

The exact discrete objective is the finite-support correlation score

```
C(h) = max { np.correlate(h, 1-h, mode="full") * dx : all 2*n_points-1 lags }.
```

The difficulty is that the maximum changes which lag constraints are relevant, and each lag score contains bilinear terms `h_i * h_j`. Therefore, a direct convex program is not available, and a single local derivative step can move in a direction that is optimal for one nonsmooth branch while worsening another active lag. The proposed solver addresses both facts by combining:

1. a constrained smooth homotopy: replace the maximum only temporarily by a log-sum-exp surrogate whose gradient is an exact convex combination of active-lag gradients;
2. a strict feasibility mechanism: every candidate passed to acceptance testing is first mapped onto the exact feasible affine set `0 <= h_i <= 1`, `sum(h)=n/2`;
3. a fallback/escape phase: once the smooth treatment has reduced the surrogate, perform line relaxations in tangent-direction pairs `(i,+-j)` and compare against the original unsimplified objective;
4. multi-resolution warm starts: use the supplied parent at its own resolution as the anchor, but also transfer it to nearby and finer `n_points` grids. A transfer is accepted only after exact re-evaluation; never accept a resolution-scaled estimate without validation.

The method returns the best exact finite-grid score encountered, not a relaxed surrogate value. No global-optimality claim is made.

1.2 Why this should improve the parent

The supplied parent is likely a local optimum on its displayed `n_points=47` grid. Any real improvement must exploit one or more of the following:

- The active maximum lag set may move when smooth gradients pull many near-active constraints downward instead of insisting on one active branch.
- The parent may be awkwardly discretized; transfer to an even or nearby resolution can smooth or reallocate mass in a way that reduces highest neighbor products after exact re-evaluation.
- Locally orthogonal pair coordinate moves can dissolve fractions at pairwise maxima and produce strict exact-score reductions that a single smooth max-gradient search misses.
- A smooth max surrogate makes all near-active constraints draggable by gradients whereas a derivative-free/line-rule search can repair local fractional collisions.

1.3 Distinction and lifesaving exactness

The method is expressly not "solve a convex program, then project": The exact objective is not convex. No fixed loop uses a claimed convex relaxation as the objective. During a smooth inner search a surrogate is acceptable, but a candidate becomes the final returned solution only if it is projected, bounded, finite, and evaluated by the exact official correlation score. The surplus parent record remains available throughout. The final return may be the parent, an improved transferred vector, or a finer-grid vector; if no smaller exact score was confirmed, it returns the best retained fallback.

The primary architecture is "constrained log-sum-exp homotopy + exact feasible-projected evaluation + final pair slashing". The high-level control is deterministic because the public brute-force solution in such constrained noncompact tasks often uses precise repeated stops and starts.
