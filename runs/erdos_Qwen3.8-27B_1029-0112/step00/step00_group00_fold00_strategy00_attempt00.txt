1. Approach and rationale

The central problem is a nonconvex minimax optimization over a step vector `h` of length `n`:
- `0 <= h[i] <= 1`
- `sum(h) = n/2`
- minimize `C5(h) = max_k np.correlate(h, 1-h, mode="full") * dx`, where `dx = 2/n`.

The main bottleneck is that the objective is the maximum over `2n-1` overlaps, including the zero-lag term `dx * sum_i h[i]*(1-h[i])`, and the objective is generally bilinear and nonsmooth. A standard CVXPY solve cannot globally optimize this because of the product terms without giving a convex relaxation. A local nonlinear program can still be very useful as a descent heuristic, but the true objective cannot be reliably minimized by converting it globally into a convex program.

Use a hybrid strategy:
1. Exact feasibility repair for all continuous sizes.
2. Construct good seeds by transferring the supplied parent to larger even-size resolutions; at even sizes it is often useful to use binary or near-binary seeds because the zero-lag term is zero for a binary sequence with exact half density.
3. Run a smooth minimax surrogate, specifically a log-sum-exp approximation, with `scipy.optimize.minimize` using toplevel functions and only exact bound/equality constraints.
4. Use constrained exact pair-transfer local search and simulated annealing. These moves preserve sum and bounds exactly, and every move is judged with the exact evaluator.
5. Consider several resolutions and several starting points: parent resolution, exact binary seeds of doubled resolution from the parent, and larger interpolations of lottery-best solutions; immediately return the exact best valid vector before time expires.

This plan is a search algorithm, not a proof of global optimality. The reported optimum is only the best exact candidate found during the budget and validated against the evaluator.

2. Mathematical specification

2.1 Representation and constrained feasible polytope

For a chosen resolution `n`, let `h` be a real vector with `n` samples over `[0,2]`. The evaluator’s feasible polytope is
`P = { h in [0,1]^n : sum(h) = n/2 }`.

This target sum is the integral `1` with `dx = 2/n`, since
`dx * sum(h) = (2/n) * (n/2) = 1`.

All candidate updates must satisfy `h in P`. The strategy must not validly create candidates by clipping and then rescaling independently, because that generally breaks the sum. Use exact projection functions and exact pair transfers instead.

2.2 Exact objective

Let `b = 1 - h`. The reported objective is
`score(h) = dx * max(np.correlate(h, b, mode="full"))`.

For optimization and gradient construction we may also use the equivalent signed sorted set of discrete shifts:
for integer shift `t = -(n-1), ..., n-1`:
- if `t > 0`, `O_t = dx * sum_{i=0}^{n-1-t} h[i] * (1 - h[i+t])`
- if `t < 0`, define `d = -t`, `O_t = dx * sum_{i=d}^{n-1} h[i] * (1 - h[i-d])`
- if `t = 0`, `O_0 = dx * sum_i h[i] * (1 - h[i])`.

The max over these signed shifts is the same numeric maximization problem as the evaluator’s full-correlation max up to a permutation of array indices. Final accepted candidates must still be recomputed using the actual `np.correlate` formula.

2.3 Derivatives of overlap terms

For `d >= 1`, define
`O_plus(d) = dx * sum_{i=0}^{n-1-d} h[i]*(1-h[i+d])`
`O_minus(d) = dx * sum_{i=d}^{n-1} h[i]*(1-h[i-d])`

Derivatives for these magnitudes are:
- For `O_plus(d)`:
  `grad = dx * ( I[j <= n-1-d] - I[j >= d] )`
- For `O_minus(d)`:
  `grad = dx * ( I[j >= d] - I[j <= n-1-d] )`

For the zero shift:
`O_zero = dx * sum_j h[j]*(1-h[j])`
`grad_zero[j] = dx * (1 - 2*h[j])`.

Include the zero shift explicitly in all smoothed Möller objective construction. Omitting it sharply penalizes binary-like solutions.

2.4 Smooth minimax surrogate and its validation

Since `score` is nonsmooth and nonconvex, use a log-sum-exp surrogate
`Phi_beta(h) = (1/beta) * log( sum_index_j exp(beta * F_j(h)) )`
where `F_j(h)` are the exact overlap entries including zero shift. Use a stable log-sum-exp implementation with the maximum subtracted to avoid overflow.

Gradient:
`grad Phi_beta = sum_j w_j * grad F_j`, where `w_j = exp(beta F_j - z)` normalized so `sum_j w_j = 1` and `z = max_i(beta F_i)`.

Important:
- `Phi_beta` is only a surrogate; use increasing `beta` values.
- Every `h` vector generated by smooth optimization must be projected to `P` and scored with the exact `score`.
- Do not accept a surrogate value as the reported `c5_bound`; return only the exact recomputed `score`.

2.5 Feasible pair transfer

To move in the feasible polytope exactly, use moves of the form
`h[i] -> h[i] + alpha`, `h[j] -> h[j] - alpha`, `i != j`,
with bounds satisfied by
`0 <= alpha <= min(1 - h[i], h[j])`.
The sum is unchanged exactly, up to floating arithmetic, and bounds are preserved.

For an exact conservative commitment, call a final cap residual driver after every committed transfer:
- compute `res = n/2 - sum(h)`;
- if `abs(res) > tol`, move the residual into an index that has capacity in the required direction; otherwise distribute it proportionally unbound atomic entries;
- if failure, rebuild from the best backup using projection.

2.6 Resolution transfer

From a valid parent `p`, create child candidates at larger resolution by:
- choosing `n_child`, preferably even;
- creating a continuous linearly interpolated `h_interp` of length `n_child`;
- repairing it to `P` by exact projection;
- optionally converting a near-continuous candidate into binary with exact sum and evaluating exact objective.

Because final scores over different resolutions are independent valid discrete values, the best candidate over any `n_child` can beat the parent on the evaluator.
