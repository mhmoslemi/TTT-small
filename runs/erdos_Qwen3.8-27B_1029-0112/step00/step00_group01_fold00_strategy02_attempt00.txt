1. Approach and rationale

The authoritative problem is a finite-support bilinear minimax problem on a discretized design vector. For returned length n, the evaluator is

F(h) = max_{r=0}^{2n-2} [np.correlate(h, 1-h, "full")_r] * (2/n),

subject to 0 <= h_i <= 1 and sum_i h_i = n/2. This is not a circular correlation and not a periodic autocorrelation: overlap lengths at the boundaries are shorter, the full index array contains all positive and negative shifts, and boundary terms are part of the objective. A correct method must first reproduce all 2n-1 full correlations exactly.

The current best-parent value is very close to the desired threshold, so an effective approach is a globalized local construction rather than an abstract global optimizer. The strategy is built on four mutually reinforcing finite-support searches:

A. Trust-region minimax linearization QP. At a current feasible vector h, compute all exact full-correlation values and their exact finite-support bilinear gradients. For only the currently near-maximal lags, solve a convex first-order linearized minimax QP with exact box constraints, the exact sum constraint, and a trust-region radius. This QP directly addresses active constraints rather than merely descending a smoothed log-sum-exp aggregate: it can balance many active lags simultaneously and reduce the envelope of near-maximal correlations. Since each original constraint is nonconvex, the QP is a local convex model; the resulting vector is accepted only after the original exact evaluator confirms any global improvement.

B. Exact pair-transfer local search. The most feasible nontrivial moves preserving sum(h)=n/2 are transfers between pairs: h_p = x and h_q = S-x with fixed S. The exact evaluator is smooth piecewise quadratic in x along such a transfer. The method samples and golden-sections this one-dimensional feasible interval with the original evaluator, which automatically includes the non-smooth maximum and boundary effects. The pair subset is guided by gradient-influence, complement-symmetric indices, and incident pairs of large correlations, but exact acceptance is mandatory.

C. Exact direct line descent and randomized basin exploration. Starting from the parent, construct complement-symmetric and projectively repaired perturbations. Start the local searches in several neighborhoods. This prevents dependence on a single local basin and lets the trust-region QP and pair-transfer stage break ties created by nearly equal active overlaps.

D. Parent-preserving hierarchical resolution refinement. If the supplied parent has length about 63, refine it by exact repetition to length 126. The parent-derived repeated vector remains feasible and, when present, is retained as a fallback. The refinement stage searches for lower correlation maxima in the enlarged design variables and retains the best exact value found over all lengths.

The primary property that distinguishes this plan is that its core mechanism is first-order linearized exact-constraint QP solving and exact pair-transfer quadratic line minimization, not plain projected gradient descent on a smoothed surrogate. Smooth gradients may be used to select directions or candidate pairs, but no candidate is ever returned because of the surrogate; every intermediate and final accepted state is validated against the original correlation evaluator.

Limitations, stated honestly: no solver outcome certifies a global optimum. Nonconvex bilinear constraints mean the convex QP is only locally predictive. The plan is therefore a multi-start local discovery method with safe fallback, not an optimality proof. The program retains the best evaluated feasible vector.

C_5(h) = dx * max_{r=0}^{M-1} K_r(h),
K_r(h) = np.correlate(h, q, mode="full")_r.

Thus K_r has raw units, while the exact normalized correlation vector is

R_r(h) = dx * K_r(h).

The target bound and objective are scaled values of R. Use this normalized R in every model without replacing the evaluator.

The feasible set is

0 <= h_i <= 1 for i=0,...,n-1,

For an odd n, S is a half-integer, such as parent n=63 giving S=31.5.

s_r = n-1-r.

Then raw K_r = sum over i such that i and i+s_r are valid indices of h_i * q_{i+s_r}. This corresponds to the reversed-second-array convention. The direct computation is

The normalized gradient row is G_r = dx * g_raw. For multiple active constraints, build two arrays:

C = normalized exact correlation values length M,
G = shape (M, n), where G_r = gradient of C_r.

Do not use matrices with partial circular shifts or circular gradients. The boundary structure follows the direct shift lengths. This is important because all correlations not included in an active constraint still affect PHP through boundaries.

2.4 Feasible projection and repair

Projecting a raw direction onto {0<=h<=1, sum=S}:

projection(h)=clip(lambda-offset signed v - lambda, 0, 1).

The sum of clipped values is monotone nonincreasing in lambda. Find lambda by bisection:
1. low = min(v)-1; high = max(v).
2. while sum(clamp(v-high,0,1)) > S, high = high + max(1, high-min(v)-? or +2) until sum <= small positive target. Or high = max(v)+10 for an adaptive sufficient high bound; extend while necessary.
3. while high-low > sqrteps, mid=(low+high)/2; if sum(clamp(v-mid,0,1)) > S then low=mid else high=mid.
4. Return clamp(v-high,0,1) or clamp(v-mid,0,1) with whichever is closer to S; keep in [0,1] via numeric microclip.
5. repair_sum_exact after projection: compute residual = S - sum(h). If |residual| <= 1e-11, leave; otherwise project toward a nearby point inside box that removes the residual: if residual>0, find indices with room upward, subtract constants keeping sum. If residual<0, find room downward. Loop until residual is zero or negative fi or re-run bisection. Projection and final loop correct only double-precision accumulation; for exact semantics, avoid repeated cumulative sums on perturbed sums.

A single bisection may reach a close clip at sums violating target by roundoff, but the microcorrection must enforce nearly exact mean of n/2.

2.5 Linearized minimax QP

Model relationships are derivative tangents of nonlinear constraints. The practical core search step uses normalized h values and the normalized correlation constraints C_ell <= t, t in normalized-score units. For a select active set A subset of normalized lags, local linear approximation of the current exact correlation C_l is

C_l(h+delta) ≈ C_l + G_l dot delta.

Let G_A be the active rows and C_A their exact active values. At the current feasible center h0, define

w0 = G_A dot h0.
LP/QP model is de-saturated to require

t >= C_A + G_A dot (z-h0) = G_A dot z + (C_A - G_A dot h0).

Thus all constraints are linear in decision vector x=(z,t). The QP is

Decision x ∈ R^{n+1}.
Variables z = x[0:n], t = x[n].

Convex piecewise-to-model objective

minimize   t + 0.5*bias * ||z - h0||_2^2.

The quadratic regularization is convex and does not solve the original bilinear problem, it gives model-prox regularization to avoid distant extrapolation.
