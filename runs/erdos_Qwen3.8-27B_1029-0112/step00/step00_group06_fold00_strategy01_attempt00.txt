1. Approach and rationale

1.1 Central idea: Chebyshev-linearized trust-region descent on the original objective

The supplied evaluator minimizes

    C(h) = max_r  corr_r(h),        corr_r(h) = dx * sum_{(i,j) in P_r} h_i (1-h_j),

where r ranges over all 2n-1 full-correlation lags, dx = 2/n, h_i in [0,1], and sum_i h_i = n/2. The problem is nonconvex because each term contains products h_i h_j. The proposed algorithm is a Chebyshev/trust-region method:

At the current feasible vector h, build the exact first-order model of all correlation values around h:

    corr_r(h + d) approx corr_r(h) + g_r(h)^T d,

where g_r(h) is the exact gradient of corr_r. Then solve the linear program

    minimize t
    subject to  corr_r(h) + g_r(h)^T d <= t   for every lag r,
                sum_i d_i = 0,
                l_i(rho) <= d_i <= u_i(rho),  0 <= h_i + d_i <= 1,
                |d_i| <= rho for all i.

The scalar t approximates the new maximum correlation. The LP chooses a direction d that lowers the maximum of the linearized correlations as much as possible while keeping the updated vector inside the box and exactly preserving the mass through sum d_i = 0. The smaller the trust radius rho, the more accurate the first-order model becomes. The actual update is accepted only after evaluating the original evaluator on h + alpha d for a sequence of alpha values. No smoothing surrogate, log-sum-exp, rounding, or mixed-integer relaxation is used by the primary method.

This is materially different from a randomized projected-gradient or stochastic smoothing method. The previous-family proposed optimization approximated the max by a smooth surrogate and searched with projected gradient plus exploration. Here the local search is built from the nonsmooth objective’s own active/linearized constraints: all individual lag constraints enter exactly as linear inequalities, and the local step is the solution of a minimax linear program. The resulting direction directly equalizes and decreases the worst correlations instead of descending one smoothed scalar. The method is local and non-global, but it is well matched to the final tiny improvement task: starting from or near the current construction, it uses a rigorous linear certificate, all lag asymmetries, and exact acceptance.

1.2 Why this could improve the supplied parent

The supplied parent construction is only about 0.38085, with a very small gap to the target 0.A tiny local improvement must reduce a handful of near-maximal lag constraints. The methodology is specifically designed for that: every lag appears as a constraint in the LP, and the optimizer minimizes the maximal linearized lag, not a soft averaged objective. If one lag is very bad, its gradient is enforced in the LP. If several lags are near tied, the LP solves for a direction that reduces their maximum simultaneously, a capability čeți objection. The finite-support correlation boundary terms are treated correctly because the gradient is computed from the same exact pair partition used by the correlation output, not from a periodic autocorrelation or an internal heuristic.

1.3 Important limitations and provenance of facts

- The bilinear objective is nonconvex. The LP uses a first-order local model. No global optimality is claimed.
- The step is accepted against the exact evaluator. Thus final returns are always exact valid upper bounds if feasible, but whether the algorithm finds a strict improvement over the parent is a hypothesis to be tested as the final code runs.
- Feasibility is maintained rigorously: search directions have zero sum, active bounds are built from the current velocity percentages, and a joint repair mechanism is used for generated / mixed candidates and the final answer.
- Global exploration is auxiliary only. The local Chebyshev LP is the core primitive that separates this plan from earlier smooth/random descent plans. Small deterministic re-entries, complements, reversals, resolution shifts, and safe mixtures provide diversity without making the method identical to them.
