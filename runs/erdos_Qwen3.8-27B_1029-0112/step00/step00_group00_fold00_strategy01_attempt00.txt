The final objective is a finite-lag mutual correlation between h and its complement over the same finite grid; it is not a circular correlation, not a simplified minimum autocorrelation formula, and not dominated by just the zero lag. Every candidate must be scored using the exact two-sided full-lag correlation expression from the problem statement.

1.2. Main bottleneck and objective structure

The task is a nonconvex minimization. For each lag τ, the correlation term is

C_τ(h) = dx sum_{pairs in overlap} h_i(1-h_j),

where the pairs are determined by the full correlation and by the selected lag; because both functions have only length n samples and mode='full' is used, each lag contains only a subset of all pairs as τ moves away from zero. For each h index i, C_τ as a polynomial is bilinear: the same h_i can appear as first-stage contribution h_i(1-h_j) and as second-stage contribution h_k(1-h_i), but the overall value is only a truncated affine/bilinear collection. The objective is the maximum of these correlations over all lags. The largest difficulty is handling this nonsmooth maximum without replacing it by a smoothing surrogate whose value is used as the reported objective. Surrogate models can move the iterate but cannot certify or cause reported improvement.

1.3. Proposed solution: exact-acceptance active-constraint LP descent

The primary proposed method is an accept/reject descriptive local/global search built from non-ascent exact evaluation:

- At the current feasible h, inspect the exact full-lag correlation values.
- Choose active or near-active causal constraints according to large values.
- Build a linearized inequality for each chosen lag: estimate the value of a candidate displacement y from h using the exact gradient of the given correlation value at h. This subproblem is linear except for max function and linear constraints, and solves a convex linear program for a candidate direction and predicted epigraph value.
- Use exactly the proposed displacement or a aligned subgradient direction in a one-dimensional exact line search along the ray z(α)=h+αy. The line search and candidate generation immediately produce a valid feasible endpoint and evaluate the full exact objective.
- Accept the new h only if its exact reported C5, calculated with the original evaluator, improves the current best exact objective. No predicted, smoothed, or relaxed value is ever treated as score.
- Continue with multiple simplex point, dimensions and diversified initializations, always retaining the best validated feasible candidate array seen.

This method is materially different from a least-squares smoothing surrogate or one-shot smooth constrained SLSQP formulation. It leaves the exact maximum intact and explicitly treats active lags as constraints. It tolerates the induced nonconvexity structurally by rejecting any step whose nonconvex effect causes the original objective to worsen.

1.4. Heuristic versus mathematically justified claims

The following are exact:

- objective is defined and measured by the stated np.correlate expression for all 2n-1 full lags;
- the finite-digration domain and product terms correctly identify gradients only for the selected finite lag and overlap;
- by using supplies or compatible dyadic integer values along with explicit total-mass correction, every eventually stored and returned vector satisfies box constraints mathematically and exact dyadic sum condition;
- any candidate reported is evaluated again under original constraints after feasibility repair and exact repeat verification.

The following are heuristics:

- active-set LP direction is not the global minimizer of the objective of h sporadic;
- interpolation and deterministic/non-noise initialization can improve parent structure, not guaranteed;
- symmetrization, filtering and global random replacements may worsen exact objective; each tested and accepted only after exact comparison;
- dynamic resolution cascade improves chances without mathematically guaranteeing monotonic convergence after resize.

Do not claim global optimality.

2. Mathematical specification

2.1. Exact discrete evaluator

Let h be a float64 array of shape (n,). dx=2/n. The reported bound is

score(h) = max_t c_t dx,

where c=np.correlate(h, 1-h, 'full') length 2n-1, and t = 0,...,2n-2. The sign convention used by the evaluator is fixed and must not be changed except via use of its result. For clarity, if full index t corresponds to lag τ=t-(n-1), the correlation is

c_t = sum_{i: 0≤i<n, 0≤i-τ<n} h_i (1 - h_{i-τ}).

This includes all overlapping pairs for the positive and negative finite support. Failing to include outside support in group (simple boundary) is intentional and matches the evaluator. Do not replace this by 1 - autocorrelation or circular metrics.

2.2. Exact gradients for linearization

For a full-lag correlation C_t(h) computed from h and q=1-h, term by term:

C_t(h)=dx sum_{(i,j)} h_i(1-h_j),

for each valid pair (i,j) for given τ=t-(n-1). The pair set is

i_min = max(0, τ)
count = n - |τ|
i_k = i_min + k, j_k = i_k - τ, k=0,...,count-1.

For each pair:

∂C_t/∂h_i += dx(1-h_j),
∂C_t/∂h_j += -dx h_i.
