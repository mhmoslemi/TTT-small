1. Approach and rationale
------------------------

The central idea is a candidate-acceptance framework for a nonconvex finite-support correlation problem: use smooth surrogate objectives and projected feasible moves, but only retain a candidate after checking the supplied exact discrete objective `C5`. The supplied parent construction, if present, is validated and retained as a fallback; every search move is feasible with respect to `0 <= h[i] <= 1` and `sum_i h[i] = n/2`, and every independently produced array is then repaired joint feasibility check. Because the exact objective is quadratic/bilinear with boundary terms (finite-support linear correlation), a direct convex solver cannot be claimed as globally optimal. The search is therefore local and relaxed, with multiple diversification schedules: smoothed multi-temperature projected descent, active-lag line search, pair-transfer precise coordinate polishing, multi-resolution refinement when time remains, and a few independent global-style initializations. The important limitation to admit explicitly is that optimum is not certified; the returned value is the best exact value found among feasible returned nodes.

2. Mathematical specification
-----------------------------

Let the returned resolution be `n`, with `dx = 2/n` and sample vector `h` in `R^n`.

The authoritative evaluator is:

`C5 = max_lags np.correlate(h, 1 - h, mode="full") * dx`.

This max is over all `2*n - 1` full correlation indices, including both lag directions and boundary partial correlations. Do not replace it with a circular or periodic autocorrelation or by a min-autocorrelation transform. The finite-support boundary terms must be preserved exactly. The corresponding discrepancy function is

`C_r(h) = dx * (np.correlate(h, 1-h, mode="full"))_r`.

Feasibility set:

- `h_i ∈ [0, 1]` for all `i`,
- `sum(h) = S`, where `S = n / 2`.

If `n` is odd, `S` is a half-integer and must be satisfied numerically to tolerance, but the final repair procedure in section 5 forces equality as near exact as double precision permits.

Smooth surrogate. At a current feasible `h`, let `v_i = 1 - h_i` and compute exact scaled correlations

`J_r(h) = dx * correlate(h, v)_r`.

For temperature `τ > 0`, define the stable log-sum-exp objective

`F_τ(h) = τ * logsumexp(J_r / τ)`.

`F_τ` is smooth and satisfies `max J ≤ F_τ ≤ max J + τ log(M)` for `M = 2n - 1`; as `τ` decreases, `F_τ` approaches the exact max but remains an approximation used only to produce directions. The soft aggregate weight vector is

`p_r = exp(J_r / τ) / sum_s exp(J_s / τ)`.

An exact weighted linear functional used for gradient validation is

`G_p(h) = sum_r p_r J_r(h)`.

The gradient `∇F_τ` is a normalized convex combination of gradients of the individual correlations. A complex smooth objective is ready for constrained projected updates:

`g = ∇F_τ(h) + (dx) * sum_r p_r ∇ correlate_r(h, 1 - h)`.

In implementation, scale one valid objective array representation. If the orientation helper below cannot be validated, the algorithm may use an approximate active-lag gradient or a low-resolution numerical directional gradient, but the final candidate is always judged by exact `C5`.
