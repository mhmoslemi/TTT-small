1. Approach and rationale
   1.1 Target and bottleneck  
       The objective is a binary/continuous combinatorial minimax: minimize the maximum, over all discrete lags, of the piecewise-constant integral approximated by exact finite-support correlation. The production record is very close to the desired bound 0.3808. This requires a tighter configuration, not a coarse grid search over integer positions. The existing parent construction is an initialization, not a guaranteed limit. Dominant improvements likely require (i) exploiting the continuous variable relaxation with a carefully smoothed minimax surrogate; (ii) resolving the active peaks near exact values; and (iii) testing binary candidates whose exact constraints are trivially satisfied. The algorithm does not attempt to prove or guarantee global optimality. It produces a valid, fully evaluated upper bound.
   1.2 Core strategy  
       Use three complementary candidate streams, retain the lowest exact final evaluator score among all valid candidates, and require deadline-aware return of the best valid candidate.
       1.2.1 Exact parent validation and grid transfer. Immediately validate the supplied parent and its constrained version on likely suitable resolutions. This gives a high-quality valid fallback and seed for downstream search.
       1.2.2 Continuous minimax optimization with smooth surrogate. Perform multiple started optimizations of a softmax/power p-norm surrogate for the vector of lag scores. The surrogate is smoothly differentiable. The gradient is exact surrogate gradient, chosen from a known lag scoring formula, so L-BFGS/SLSQP has analytic gradients. The final score is not accepted from the surrogate; it is accepted only from the task's exact metric.
       1.2.3 Exact binary discrete local/simulated improvement. Convert promising continuous candidates into balanced binary step functions and run greedy, swap-based local/simulated searches whose feasibility is exact and whose scoring uses the exact task evaluator. Binary search is cheap, highly robust to constraint-projector errors, and may discover corner improvements not found by smoothed continuous optimization.
   1.3 Why it can improve the parent  
       The parent is one local construction on a small grid. Higher resolution, smoothing, improved active-peak equalization, and a different balanced word seed can lower discrete maxima. The optimization is nonconvex; the multi-seed, multi-resolution approach supplies escape from local basins. Binary local search may close small margins, since any valid move has an exactly computable exact vector. Continuous smoothing addresses small boundary terms that binary rounding may not capture by itself.
   1.4 Known hypotheses, not proof  
       It is plausible an optimum or near-optimum uses values near binary and complement symmetry. This is a hypothesis, not a proven converse. The code will evaluate all candidate without assuming it. If a symmetric/complement-mirrored seed decreases the exact score, it is used. The method can still return non-symmetric or non-binary candidates.
   1.5 Failure handling principle  
       No numerical step is trusted as a direct bound. If any optimizer step fails due nonfinite values, tightening constraints, solver termination, deadline or numerical singular behavior, the program must fall back only to a previously exact-evaluated valid candidate. This applies even when the candidate is merely the parent.
