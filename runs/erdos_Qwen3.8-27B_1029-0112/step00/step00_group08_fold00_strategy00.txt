1. Approach and rationale

The task is a finite-dimensional non-convex max-of-products problem:
h is sampled at equal resolution over [0,2], must lie in [0,1]^n, have discrete sum n/2, and the authoritative evaluator is
    C(h) = max_{r=0}^{2n-2} (np.correlate(h, 1-h, mode='full')[r] * 2/n).
The objective is not convex and is not the sum of h, even though the feasible h has sum n/2, because the correlation only involves pairs that stay inside the finite array. Therefore the algorithm must judge every candidate with the exact evaluator and must not rely on convex relaxations for the final acceptance.

The central strategy is a hierarchy of conservative, exact-score-driven local improvements:
1. Start from the supplied parent construction, validate it exactly, and use it as fallback.
2. Refine the parent at multiple discrete resolutions (80, then 120/160/240/320 as time permits). Upsampling can increase resolution and then projection restores the exact constraint.
3. Use projected normalized-gradient/quasi-subgradient descent of an annealed weighted maximum of the relevant correlation lags. The weights select lags that dominate the actual maximum; a true feasibility projection restores the box and the sum constraint at every trial step.
4. Use exact continuous pair line searches that preserve sum exactly by moving mass between two sampled h values. Pairwise lines often escape flat regions created by the visible max of smooth descent and can make fine local improvements, which are important when the target improvement is only a few 1e-4.
5. Run optional discrete/binary local reinforcement using exact incremental updates of the entire correlation array. Binary moves are cheap and provide alternate feasible starting points to avoid optimization basins that are too fractional.
6. Never call any subproblem “globally optimal” without proof; candidates are stored from the actual evaluator and are never accepted unless they satisfy the feasibility thresholds and improve or remain equal.

The main bottleneck addressed is local plateau behavior and constraint violation. The better method is to combine simple, fast feasibility with many selection passes over bottleneck lags and exact pairwise line polishing. Higher resolutions are attempted because the exact evaluator changes if the shape is resampled, and finer discretization can only help if the same continuous-looking construction is optimized again. If a lower size is improved, it is transferred upward and then reoptimized; if a larger size fails to improve, the previous fallback is returned.
