




\section{Target-Level Statistical Analysis}
\label{app:statistical-analysis}

The main evaluation in
Table~\ref{tab:sweep_asr_clean_minus_cta} uses ten attack targets and
six independently initialized victims for each target. The six victim
runs associated with one target share the target image and optimized
poison set. Treating all 60 victim outcomes as independent would
therefore overstate the effective sample size. We instead use the target
as the unit of statistical analysis.
For selection method
$v\in\{\mathrm{Random},\mathrm{DPP}\}$, let
$a^{(v)}_{t,s}\in\{0,1\}$ indicate attack success for target $t$ and
victim $s$. We first compute the success rate associated with each
target
\[
r^{(v)}_t
=
\frac{1}{6}
\sum_{s=1}^{6}
a^{(v)}_{t,s},
\qquad
t=1,\ldots,10.
\]
The ASR reported in the main evaluation is
\[
\mathrm{ASR}^{(v)}
=
\frac{1}{10}
\sum_{t=1}^{10}
r^{(v)}_t.
\]
Standard errors are computed across these ten target-level success
rates.

Random and DPP are evaluated on the same targets and victim protocol,
so their comparison is paired. For each target we define
\[
d_t
=
r^{(\mathrm{DPP})}_t
-
r^{(\mathrm{Random})}_t
\]
and compute
\[
\Delta
=
\frac{1}{10}
\sum_{t=1}^{10}d_t.
\]

We estimate uncertainty in $\Delta$ using paired bootstrap resampling
over targets. Each bootstrap sample resamples the ten target indices
with replacement and retains all six associated victim outcomes for
both selection methods. This preserves the dependence among victim runs
belonging to the same target and the pairing between Random and DPP.

Tables~\ref{tab:main-stats-convnet}--\ref{tab:main-stats-vgg} report
the target-level standard errors and paired 95\% bootstrap confidence
intervals for every configuration in the main evaluation. CTA remains
reported in Table~\ref{tab:sweep_asr_clean_minus_cta} to avoid
duplicating values.

The configuration-level results show that the improvement is not driven
by a small number of favorable settings.
Table~\ref{tab:aggregate-statistics} summarizes all 108 matched
comparisons. DPP improves ASR in 101 configurations, ties Random in
two, and is lower in five. The mean paired improvement is $23.8$
percentage points and the median improvement is $23.3$ points. In
72 configurations, the paired 95\% bootstrap interval lies strictly
above zero.

We also test whether the signed improvements are systematically positive
across the full sweep. A two-sided sign-flip permutation test over the
108 paired configuration-level differences gives $p<10^{-5}$. This
aggregate result complements the individual confidence intervals and
provides evidence that the improvement is consistent across the
evaluated architectures, attacks, class pairs, and poison fractions.
