Actually, for a minimax problem where the functions are bilinear, the cutting-plane approach works like this:

- The linearization at h₀ is: O_k(h) ≈ O_k(h₀) + ∇O_k(h₀)^T (h - h₀)

- We want g[i] - g[j] < 0 (to decrease the max), i.e., g[i] < g[j]
- The best pairs have the largest (g[j] - g[i]) > 0

So I can sort pairs by (g[j] - g[i]) and only try the top K.

def lag_gradient(h, k, n):

    s = k - (n - 1)

        g[:rem] -= h[s:]
    else:
        p = -s
        rem = n - p
        g[:rem] += (1.0 - h[p:])
        g[p:] -= h[:rem]
    return g * dx
