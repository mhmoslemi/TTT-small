1. Approach and rationale

The task is a constrained nonconvex finite-horizon cross-correlation minimizer

        F(h) = max_r dx * sum_i h_i * (1 - h_{i+lag(r)})

with variables h in R^n, bounds 0 <= h_i <= 1, and the exact average constraint sum_i h_i = n/2. The authoritative evaluator evaluates exactly the full linear correlation vector with implicit zero extension, not circular correlation, and multiplies it by dx = 2/n. A feasible candidate is judged only by the final exact numerical value of this maximum. The previous strategy bottleneck was that it mainly optimized a smooth log-sum-exp surrogate and then performed generic pair moves; when the original maximum is determined by only a few boundary-affected lags, the surrogate can drag the solution away from the true constrained maximum, and pair coordinate descent alone is a low-tangent subproblem search that can stall in the parent basin.

The plan here is a coherent local-global finite-budget optimizer built around three principles.

First, preserve the given construction as a certified fallback and never allow a candidate to replace the best solution unless its exact evaluator score, after full repair and feasibility restoration, is strictly better. The parent is transformed, refined, and possibly interpolated to other resolutions, but all accepted improvements are re-evaluated with the authoritative objective.

Second, directly change objective approximation and search directions. Instead of relying only on a finite-beta log-sum-exp objective, use:

- a direct exact-max SLSQP approximation using an active-set average subgradient;
- a log-sum-exp SLSQP family for smoother global approximation and basin escape;
- active-lag projected gradient line searches, where the direction is derived from the correlation gradients of the current most restrictive lags;
- edge-focused pair line searches whose candidate pairs are generated only from terms appearing in active correlations, rather than all n(n-1)/2 pairs;
- low-dimensional mode perturbations and binning perturbations for less local diversity;
- multiresolution interpolation and averaging of distinct best candidates.

This combination is appropriate because F is nonconvex, and no global lower bound is claimed. The only facts asserted are: the final accepted value equals the supplied evaluator objective on the returned vector, and feasibility is enforced by a bisection-based linear checkpoint. For all other claims, the plan is a heuristic search strategy intended to escape local maxima of the previous method.

Third, manage time deterministically. The program must return before the requested deadline. The core loop tracks elapsed time before every solver phase, before large coordinate ascent passes, and between line-search iterations.
