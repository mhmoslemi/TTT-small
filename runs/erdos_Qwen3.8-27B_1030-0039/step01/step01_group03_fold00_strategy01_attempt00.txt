1. Approach and rationale

1.1 Central idea

The implementation keeps the supplied parent h as an executable fallback, but it does not try to polish it only with a single smooth loss or by random pairwise exchanges. It treats the objective as the maximum of about 2n−1 discrete cross‑correlation terms and directly reduces active directional fields of those maxima.

The new primary mechanism is:

1. compute exact finite-support correlation values of the current construction;
2. identify correlation values close to the current maximum;
3. estimate active gradients/contributions from those terms;
4. build feasible zero-normal-sum block directions, not only adjacent/pair exchanges, including:
   - negative smoothed-softmax gradients restricted to active terms;
   - contribution–gradient fields built from the same active terms;
   - Fourier/spectral directions;
   - random distributed exchange fields;
5. execute exact scalar line searches along those fields;
6. capture feasible scalar candidate arrays;
7. accept a line-search result only if the exact evaluator gives a strict improvement;
8. afterwards use exact two-coordinate line polishing, especially on pairs associated with active terms;
9. repeat through a multi-resolution hierarchy without discarding the previously best valid smaller-resolution result.

This differs substantively from the earlier program in three ways:

- The earlier program relied primarily on SLSQP minimization of a log-sum-exp smoothing of the maximum and projected pairwise SLSQP moves. The new method makes the active set itself produce engineered feasible one-dimensional directions and judges all proposals directly by the exact maximum.
- The earlier proposed strategy restricted itself to active pairwise line searches and broader random pair line sweeps. The new method adds generalized block directions carrying many simultaneous zero-sum increments/decrements, including fields derived from the gradients of active maxima. A directional line search can find configurations where many coordinates must move together, which pairwise-coordinate exchanges cannot represent in one step.
- Instead of limiting geometry search to parent size 135 and selected multiples below 180, the new plan permits a wider, safely validated multi-size corridor and returns the exact best among all visited feasible usable resolutions. The sole comparison metric is the full np.correlate objective, so improvements are not conflated with a coarse-grid drop.

1.2 Why this addresses the bottleneck

The nonconvexity comes from maximums of products h[i] * h[i+shift] and combinatorially many potential bottlenecks. Local SLSQP drift leaves the parent near an active set it cannot escape during a single continuous path. A group of possible active correlation values can define a local direction field: increase values in regions that reduce the active terms and decrease values in regions that reduce them, while removing mass elsewhere to preserve the sum constraint. Executing this direction as a line field gives the search a feasible global escape route. Afterwards, exact-degree two-variable lines can lock in the improvement by exploiting nonlinearity of exact geometry along individual coordinate pairs. Robust fallback against a parent value is the required constraint.
