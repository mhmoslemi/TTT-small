Let me also think about whether the problem structure helps. The overlap integral ∫h(x)(1-h(x+k))dx can be written as:
∫h(x)dx - ∫h(x)h(x+k)dx = 1 - R(k)

where R(k) = ∫h(x)h(x+k)dx is the autocorrelation of h.

So C₅ = max_k (1 - R(k)) = 1 - min_k R(k)

We want to maximize min_k R(k), i.e., make the autocorrelation as "flat" as possible (minimize its variation). This is related to the concept of "low autocorrelation" sequences but in continuous space.

For a step function with mean 1/2 (since ∫₀² h = 1 and the interval length is 2, so the "density" is 1/2), the autocorrelation at lag 0 is ∫h(x)²dx ≥ (∫h)²/2 = 1/2 (by Cauchy-Schwarz, since the interval length is 2). And at large lags (|k| ≥ 2), the overlap is zero (since h is supported on [0,2]).

In the discrete setting with n points over [0,2], the lags correspond to d = 0, 1, ..., n-1 (in terms of index shift), and the integral is approximated by dx * sum of products over the overlapping region.

So the problem is really about designing h to make the autocorrelation as flat as possible over the range [0, 2] (or [-2, 2] for the full correlation).

This is a well-studied problem in signal processing (minimum peak sidelobe sequences, etc.), but in continuous form.

import numpy as np
from scipy.optimize import minimize, brentq, minimize_scalar
import time

class SearchInterrupt(Exception):
    pass

def evaluate_exact(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode="full") * dx))

def project_feasible(x, n):
    S = n / 2.0
    def F(t):
        return float(np.sum(np.clip(x + t, 0.0, 1.0)) - S)
    x_clipped = np.clip(x, -2.0, 2.0)
    lo = -float(np.max(x_clipped)) - 0.5
    hi = 1.0 - float(np.min(x_clipped)) + 0.5
    try:
        t_star = brentq(F, lo, hi, xtol=1e-14, maxiter=60)
    except:
        x_pos = np.clip(x, 0.0, 1.0)
        s = float(np.sum(x_pos))
        if abs(s - S) < 1e-10:
            return x_pos
        t_star = (S - s) / n
    return np.clip(x + t_star, 0.0, 1.0)

def smooth_grad(h, n, beta):
    """Returns (psi, gradient) for the log-sum-exp smoothed objective."""
    dx = 2.0 / n
    s = np.correlate(h, 1.0 - h, mode="full") * dx
    m = float(np.max(s))
    exps = np.exp(beta * (s - m))
    Z = float(np.sum(exps))
    p = exps / Z
    psi = (m + float(np.log(Z))) / beta
    
    g = np.zeros(n)
    for j in range(2 * n - 1):
        d = j - (n - 1)
        alpha = p[j] * dx
        if alpha < 1e-16:
            continue
        if d >= 0:
            k = n - d
            if k <= 0:
                continue
            g[:k] += alpha * (-h[d:])
            g[d:] += alpha * (1.0 - h[:k])
        else:
            pv = -d
            k = n - pv
            if k <= 0:
                continue
            g[:k] += alpha * (-h[pv:])
            g[pv:] += alpha * (1.0 - h[:k])
    
    return psi, g

def slsqp_stage(h0, n, beta, maxiter, time_fn):
    def obj(x):
        time_fn()
        val, _ = smooth_grad(x, n, beta)
        return val
    
    def jac(x):
        time_fn()
        _, gv = smooth_grad(x, n, beta)
        return gv
    
    def eq_con(x):
        return float(np.sum(x) - n / 2.0)
    
    constraints = [{'type': 'eq', 'fun': eq_con}]
    bounds = [(0.0, 1.0)] * n
    
    try:
        res = minimize(obj, h0, jac=jac, method='SLSQP',
                      bounds=bounds, constraints=constraints,
                      options={'maxiter': maxiter, 'ftol': 1e-14})
        x_new = project_feasible(res.x, n)
        return x_new
    except SearchInterrupt:

def transfer(h_old, n_new):

    h_new = np.interp(x_new, x_old, h_old)
