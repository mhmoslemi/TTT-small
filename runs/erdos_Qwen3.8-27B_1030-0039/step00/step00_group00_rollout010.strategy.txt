1. Approach and rationale
------------------------

### Central idea

Use the supplied 45-sample construction as a validated starting point if it exists, then perform a resolution-aware nonconvex minimization of the accepted exact objective

0<=h_i<=1,

sum_i h_i * (2/n) = 1,

F(h) = max over the full np.correlate(h, 1-h, mode="full") entries times dx.

The exact evaluator is nonconvex and nonsmooth because it is a pointwise maximum of bilinear terms. We therefore avoid asserting any global optimality. The main search is a feasible local/globalized local search:

- A differentiable smoothed maximum surrogate log-sum-exp, minimized by SLSQP under box and sum constraints. Analytic gradients make this efficient.
- Exact-objective candidate evaluation after every surrogate/local candidate.
- Resolution refinement: transfer the parent to 2x, 3x, 4x, etc. only by integral-exact block transformations, optimize there, then transfer candidates back and evaluate at multiple resolutions.
- Feasible random perturbation and simulated-annealing restarts seeded from the current best to escape surrogate-induced local minima.
- Optional exact binary MILP/or local binary search on even grid sizes if feasible in the remaining time.

The reason this can beat the supplied parent is that the current parent is already close to the target but likely only locally optimal on its small discrete grid. Small improvements near 0.38085 can come from slight redistribution of mass among neighboring grid points and from more accurate/lower-resolution-to-higher-resolution steps. The exact evaluator remains the only acceptance test, so surrogate errors cannot silently produce an invalid lower bound.

### Limitations and status of claims

- The SLSQP/log-sum-exp method is heuristic: it can improve the objective but is not guaranteed to find a global minimizer.
- The smoother objective is not the exact objective. Every returned and stored candidate is re-evaluated by the authoritative evaluator.
- Timing control is done between stages and by conservative iteration limits. If a central solver routine unexpectedly exceeds a stage estimate, the main function must still return the best feasible candidate saved by the time-control logic; every stage is launched only if enough time remains to finish a final validation and return.
- No claim is made that any one local search step is globally optimal. A lower C5 value is meaningful only after a candidate passes constraints and the exact objective.

2. Mathematical specification
-----------------------------

### 2.1 Representation, constraints, and authoritative objective

Let n_points = N. A returned vector is

h = (h_0, ..., h_{N-1}), with h_i in [0,1].

dx = 2.0 / N.

The constraint is equivalently

sum_i h_i = N / 2

within numerical tolerance. In code and validation, target_sum is the float value N / 2.0; do not replace it by an integer unless N is even, and even then preserve float arithmetic consistently.

The authoritative objective used by the task is exactly:

c_vals = np.correlate(h, 1 - h, mode="full") * dx

C5 = np.max(c_vals).

Important: this is linear correlation over finite support, not circular correlation. It must include every full output lag, both directions. Do not use a circular objective, Fourier approximation, variance-based proxy, or an "1 - min autocorrelation" replacement without a derivation that exactly yields the finite-support values below. Any attack on this objective must retain the boundary terms and both lag directions.

### 2.2 Exact multiset of correlation terms used for surrogate calculations

For gradient/sc surrogate convenience, one can compute a vector containing the same multiset of values as the 2N - 1 correlation entries. This vector need not have the same lag ordering as np.correlate, because only the maximum matters; however, each entry must be paired with its true gradient. The multiset is:

- Center lag t = 0:

A_0 = sum_{i=0}^{N-1} h_i (1 - h_i).

- For each shift s = 1, ..., N - 1:

A_s = sum_{i=0}^{N-1-s} h_i (1 - h_{i+s}),

B_s = sum_{i=0}^{N-1-s} h_{i+s} (1 - h_i).

The two values represent the pair (i, i+s) in the two opposite correlation directions. With dx multiplication, the set contains exactly the evaluator values up to a permutation. In implementation, create:

vals = [dx*A_0]
for s = 1 to N-1:
    vals.append(dx*A_s)
    vals.append(dx*B_s)

This list length is 2N - 1. If a unit check is run, sort(vals) should agree within tolerance with sort(np.correlate(h, 1-h, full)*dx), and the max should agree. If a custom multiset check ever fails, the implementation must fall back to using np.correlate for scoring and either disable gradient use or use numerical finite differences.

### 2.3 Analytic gradients of the exact overlap terms
