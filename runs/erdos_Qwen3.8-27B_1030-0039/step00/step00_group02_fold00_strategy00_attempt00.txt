1. Approach and rationale

The objective is a finite-support correlation minimization:
maximize over all lags of `dx * sum_i h[i] * (1 - h[i + lag in a paired valid index set])`, subject to `0 <= h_i <= 1` and exact discrete integral `sum(h)*dx = 1`, equivalently `sum(h) = n/2`. The problem is nonconvex because h also appears through paired products `h[i] h[j]`. There is no credible way to prove a global optimum from a local method on a single machine within 1100 seconds. The therefore adopted approach is a constrained smooth minimax local/global hybrid that starts from the supplied construction, preserves feasibility at every returned evaluation, and uses many independent local improvements with several starting points, several expressions and symmetry restrictions, and several discretizations to obtain the smallest exact evaluator score found.

The central idea is:

1. Optimize a smooth surrogate of the max, the log-sum-exp (LSE) of the correlation terms, because it is differentiable and encourages all large lags to be reduced simultaneously.
2. Optimize with a nonlinear solver that can impose exact equality `sum(h) = n/2` and bounds `0 <= h <= 1`. For symmetric candidates, reduce the variable dimension via mirror variables and use the corresponding exact symmetric sum constraint. This reduces dimension and makes the problem more tractable.
3. Maintain a running best record evaluated by the original exact evaluator, not by the LSE surrogate. All accepted best records are repaired to satisfy bounds and exact sum after optimization.
4. Run two complementary searches:
   - an evolutionary feasible-subspace search using only exact/folded/repaired objectives, to explore parent basin, binary-like, distributed and random global patterns;
   - a sequence of smooth LSE continuation runs (`tau` descending from coarse to close to exact max) with a full nonlinear solver, using the best exact candidate found as the dynamic starting point. This is the main local polish engine. Virial derivatives are exact for the chosen smooth objective according to the actual correlation indexing convention.
5. Include resolution expansion: transfer the current best to doubled resolution, reoptimize in the higher-dimensional feasible/capped simplex, evaluate exactly and compare. This can obtain paths in continuous representative classes not represented in the original grid and is carried over to the best fallback if it improves the original evaluator. It is not claimed to be a lower bound; the evaluator returns the exact score of the returned vector.
