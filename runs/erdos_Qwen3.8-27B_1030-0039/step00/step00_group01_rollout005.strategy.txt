C5(h) = max_k [ dx * np.correlate(h, 1-h, modeanger="full") ]_k, dx = 2 / n,

where h is a vector of length n with 0 <= h_i <= 1 and sum_i h_i = n/2. This is a nonconvex multiaffine min-max objective in the coordinates of h. The substantive differences from a simple gradient or fixed-step stochastic search are:

1. Feasibility is treated exactly as a box-plus-simplex constraint. Every accepted candidate is repaired with a monotone water-filling projection plus a final residual transfer so that 0 <= h_i <= 1 and sum_i h_i = n/2 after each meaningful accept.

2. Local improvement is performed by exact one-dimensional scans along mass-transfer directions. For each coordinate pair or small zero-sum block, the algorithm evaluates the exact full correlation sequence at many points along the feasible segment and then locally refines the best segment. Do not assume convexity of this one-dimensional curve: diagonal terms h_i(1-h_i) make the curve nonconvex, so the implementation must use dense evaluation plus bounded local refinement and must always verify the final score with the original metric.
