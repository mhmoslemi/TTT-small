Let me verify: np.correlate(a, v) computes sum(a[m] * v[m+k]) for each k. So np.correlate(h, 1-h, mode="full") computes:

For the gradient computation, I need to understand what each correlation term represents.

Let h have length N. Define g = 1 - h.
np.correlate(h, g, mode="full") has 2N-1 entries.

The k-th entry (0-indexed from 0 to 2N-2) represents:
- For k < N: sum_{i=0}^{N-1-k} h[i] * g[i+k] = sum_{i=0}^{N-1-k} h[i] * (1-h[i+k])
- For k >= N: this is the "other direction"

Wait, numpy's correlate documentation says:
numpy.correlate(a, v) = sum_n a[n+k] * conj(v[n]) for full mode (with appropriate indexing)

Actually let me just look at it empirically:
- a = [a0, a1, ..., a_{N-1}]
- v = [v0, v1, ..., v_{N-1}]
- np.correlate(a, v, "full") output has 2N-1 elements
- output[k] for k = 0 to 2N-2:
  - This is the cross-correlation where v is "reversed and shifted"

Standard definition: (a ⋆ v)[k] = sum_n a[n+k] * conj(v[n])

For full mode, k ranges from -(N-1) to N-1, giving 2N-1 values.

In numpy's 0-indexed output:
- output[0] = a[0] * v[N-1] (k = -(N-1))
- output[1] = a[0]*v[N-1] + a[1]*v[N-2] (k = -(N-2))
- ...
- output[N-1] = sum_{i=0}^{N-1} a[i]*v[i] (k = 0)
- ...
- output[2N-2] = a[N-1]*v[0] (k = N-1)

So for h and g = 1-h:
- output[N-1] = sum_i h[i] * (1-h[i]) = sum_i h[i] - sum_i h[i]^2 = N/2 - sum h[i]^2
- output[N-1+s] = sum_{i=0}^{N-1-s} h[i+s] * (1-h[i]) for s = 1, ..., N-1
- output[N-1-s] = sum_{i=0}^{N-1-s} h[i] * (1-h[i+s]) for s = 1, ..., N-1

So the terms are:
- Center: A_0 = sum_i h_i(1-h_i)
- For s = 1,...,N-1:
  - A_s = sum_{i=0}^{N-1-s} h_i(1-h_{i+s})  [this is output[N-1-s]]
  - B_s = sum_{i=0}^{N-1-s} h_{i+s}(1-h_i)  [this is output[N-1+s]]

And C5 = dx * max(A_0, A_1, B_1, ..., A_{N-1}, B_{N-1})

Now for gradients:
- A_0 = sum_i h_i - sum_i h_i^2, dA_0/dh_j = 1 - 2h_j
- A_s = sum_{i=0}^{N-1-s} h_i - sum_{i=0}^{N-1-s} h_i * h_{i+s}
  - dA_s/dh_j:
    - If j <= N-1-s: contributes 1 - h_{j+s}
    - If j >= s and j <= N-1: contributes -h_{j-s}
    - If both (s <= j <= N-1-s): total = 1 - h_{j+s} - h_{j-s}
- B_s = sum_{i=0}^{N-1-s} h_{i+s} - sum_{i=0}^{N-1-s} h_i * h_{i+s}
  - dB_s/dh_j:
    - If j >= s and j <= N-1: contributes 1 - h_{j-s}
    - If j <= N-1-s: contributes -h_{j+s}
    - If both (s <= j <= N-1-s): total = 1 - h_{j-s} - h_{j+s}

Interesting - A_s and B_s have the same gradient structure (just with s and N-1-s swapped in a sense). Actually they're identical in gradient! Because A_s = sum_{i=0}^{N-1-s} h_i * h_{i+s} with a - sign, and same for B_s. Wait no:

A_s = sum_{i=0}^{N-1-s} h_i(1-h_{i+s}) = sum_{i=0}^{N-1-s} h_i - sum_{i=0}^{N-1-s} h_i * h_{i+s}

B_s = sum_{i=0}^{N-1-s} h_{i+s}(1-h_i) = sum_{i=0}^{N-1-s} h_{i+s} - sum_{i=0}^{N-1-s} h_i * h_{i+s}

So the "cross" terms are the same: -sum h_i * h_{i+s}, but the linear terms differ.

For the gradient of the log-sum-exp surrogate:
S = log(sum_l exp(beta * f_l)) / beta where f_l = dx * (term_l)

The gradient is: sum_l w_l * grad(f_l) where w_l = softmax(beta * f_l) = exp(beta*f_l) / sum exp(beta*f_l)

def repair_feasible(h):
    """Project h onto {0 <= h_i <= 1, sum(h) = N/2}"""
    h = np.asarray(h, dtype=np.float64).copy()
    N = len(h)
    h[~np.isfinite(h)] = 0.5
    h = np.clip(h, 0.0, 1.0)
    target = N / 2.0
    # Bisection for scalar shift t: find t such that sum(clip(h - t, 0, 1)) = target
    lo = -1.0
    hi = 2.0
    for _ in range(200):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(h - mid, 0.0, 1.0))
        if s > target:
            lo = mid
        else:
            hi = mid
    t = (lo + hi) / 2.0
    h_out = np.clip(h - t, 0.0, 1.0)
    # Exact correction
    diff = target - np.sum(h_out)
    if abs(diff) > 1e-14:
        if diff > 0:
            idx = np.where(h_out < 1.0 - 1e-15)[0]
        else:
            idx = np.where(h_out > 1e-15)[0]
        if len(idx) > 0:
            per = diff / len(idx)
            h_out[idx] = np.clip(h_out[idx] + per, 0.0, 1.0)
            # If still off, try again
            diff2 = target - np.sum(h_out)
            if abs(diff2) > 1e-14:

    N = len(h)
    g = 1.0 - h
    c = np.correlate(h, g, mode="full")

def smooth_objective(h, beta):
    """Log-sum-exp surrogate: (1/beta) * log(sum exp(beta * f_l))"""
    N = len(h)
    dx = 2.0 / N
    c = np.correlate(h, 1.0 - h, mode="full") * dx
    c_max = np.max(c)
    if c_max < 0:
        c_max = 0
    shifted = beta * (c - c_max)
    # Clip for numerical stability
    shifted = np.clip(shifted, -500, 500)
    e = np.exp(shifted)
    s = np.sum(e)
    if s <= 0 or not np.isfinite(s):
        return c_max
    return c_max + np.log(s) / beta

def smooth_gradient(h, beta):
    """Gradient of smooth_objective with respect to h."""
    N = len(h)
    dx = 2.0 / N
    c = np.correlate(h, 1.0 - h, mode="full") * dx
    c_max = np.max(c)
    shifted = beta * (c - c_max)
    shifted = np.clip(shifted, -500, 500)
    e = np.exp(shifted)
    s = np.sum(e)
    if s <= 0 or not np.isfinite(s):
        return np.zeros(N)
    w = e / s  # softmax weights, length 2N-1
    
    # Now compute gradient: sum_l w[l] * grad_f_l
    # The correlation output index l corresponds to:
    # l = N-1: center term, grad = dx*(1-2*h)
    # l = N-1-s (s=1..N-1): A_s = sum_{i=0}^{N-1-s} h[i]*(1-h[i+s])
    # l = N-1+s (s=1..N-1): B_s = sum_{i=0}^{N-1-s} h[i+s]*(1-h[i])
    
    grad = np.zeros(N)
    
    # Center term: l = N-1
    grad += w[N-1] * dx * (1.0 - 2.0 * h)
    
    # For each s = 1, ..., N-1:
    for s in range(1, N):
        # A_s at position N-1-s: sum_{i=0}^{N-1-s} h[i]*(1-h[i+s])
        # d/dh[j]: 
        #   if j <= N-1-s: +1 - h[j+s]
        #   if j >= s:     -h[j-s]
        wA = w[N-1-s]
        if wA > 1e-18:
            # Contribution from "h[i]" part: for i=0..N-1-s, d/dh[i] of h[i] = 1
            # Contribution from "-h[i]*h[i+s]" part: d/dh[i] = -h[i+s], d/dh[i+s] = -h[i]
            grad[:N-s] += wA * dx * 1.0  # +dx*1 for h[i]
            grad[:N-s] -= wA * dx * h[s:]  # -dx*h[i+s] for i=0..N-1-s
            grad[s:] -= wA * dx * h[:N-s]  # -dx*h[i] for i+s = s..N-1
        
        # B_s at position N-1+s: sum_{i=0}^{N-1-s} h[i+s]*(1-h[i])
        # d/dh[j]:
        #   if j >= s: +1 - h[j-s]
        #   if j <= N-1-s: -h[j+s]
        wB = w[N-1+s]
        if wB > 1e-18:
            grad[s:] += wB * dx * 1.0  # +dx*1 for h[i+s]
            grad[s:] -= wB * dx * h[:N-s]  # -dx*h[i] for i=0..N-1-s
            grad[:N-s] -= wB * dx * h[s:]  # -dx*h[i+s] for i+s = s..N-1
    
    return grad

        return transfer_interp(h, N // factor)
    h2 = h.reshape(-1, factor).mean(axis=1)

    N = len(h)

    dst = (np.arange(new_N) + 0.5) * 2.0 / new_N
    h2 = np.interp(dst, src, h, left=h[0], right=h[-1])
