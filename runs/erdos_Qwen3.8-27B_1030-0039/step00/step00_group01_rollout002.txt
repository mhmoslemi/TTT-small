For 0 < k ≤ 32: first term = k (m from 32-k to 31), second term = 0 (m ≥ 32 and m < 32-k is empty since 32-k ≤ 32)
For k = 32: first term = 32, second term = 0
For -32 ≤ k < 0: by symmetry, same as |k|

Hmm this is getting complicated. The point is the block pattern is not great.

Let me just focus on optimizing from the parent and from a few random starts.

One more thought: the problem is equivalent to minimizing the maximum "cross-correlation" between h and 1-h. This is related to the "aperiodic autocorrelation" problem. Known good constructions include:
- Legendre sequences
- Barker sequences  
- m-sequences

But these are for binary sequences. For continuous-valued h, we have more flexibility.

import time

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode="full")

def find_delta_opt(corr, d, lo, hi):
    if hi - lo < 1e-14:
        return 0.0
    lo_orig, hi_orig = lo, hi
    for _ in range(50):
        mid = (lo + hi) * 0.5
        vals = corr + d * mid
        mv = np.max(vals)
        active = vals >= mv - 1e-13
        d_act = d[active]
        if np.min(d_act) >= -1e-14:
            hi = mid
        elif np.max(d_act) <= 1e-14:
            lo = mid
        else:
            break
    return (lo + hi) * 0.5

    diff = target - h.sum()
    if abs(diff) < 1e-12:
        return h

    if free.sum() == 0:
        free = np.ones(len(h), dtype=bool)
