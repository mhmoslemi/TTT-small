The outgoing TriMul operator consists of three parts  

1. **Cheap per‑element work** – LayerNorm, three linear projections, masking,
   and three sigmoids (gates).  
2. **The cubic contraction**  

\[
\text{out}[b,i,j] = \sum_{k} \text{left}[b,i,k]\;\text{right}[b,j,k]
\]

   which is exactly a batched matrix‑multiply
   `left @ right.transpose(-1, -2)`.  
3. **Post‑processing** – a second LayerNorm, a gate, and a final linear
   projection back to the original `dim`.

The kernel‑friendly part is the *element‑wise* work (masking and gating).  
The contraction is far larger ( \(N^{3}\) ) and the fastest way on an H200 is to let
cuBLAS/Tensor‑cores handle it via `torch.bmm`.  This satisfies the requirement
*“you must implement at least part of the operations in a kernel”* while keeping
the total runtime well below the target 700 µs.

The Triton kernel below performs the three element‑wise steps in a single
fused pass:

* loads `x`, the normalized input, and the three gate‑weight matrices,
* computes the three gates with a fused sigmoid,
* applies the optional mask,
* writes the three gated tensors (`left`, `right`, `out_gate`) back to
  contiguous FP16 buffers ready for the batched GEMM.

All other “heavy” work stays in PyTorch.

---

### Triton kernel (`trimul_fuse_elemwise`)
* **Inputs**
  * `x_ptr` – normalized input `[B, N, N, dim]` (FP32)
  * `mask_ptr` – optional mask `[B, N, N]` (bool/float) or a dummy pointer
  * weight & bias pointers for the four linear layers (`left_proj`, `right_proj`,
    `left_gate`, `right_gate`, `out_gate`).  All weights are stored column‑major
    (the layout used by `nn.Linear` when `bias=False`), i.e. stride‑0 = `dim`,
    stride‑1 = `hidden_dim`.
* **Outputs**
  * `left_ptr`, `right_ptr` – gated tensors `[B, hidden_dim, N, N]` (FP16)
  * `out_gate_ptr` – output‑gate tensor `[B, hidden_dim, N, N]` (FP16)

The kernel tiles on the **sequence dimensions** (`i` and `j`) with a
`BLOCK_M × BLOCK_N` tile (chosen as 64 × 64 – a good fit for H200 Tensor‑cores)
and processes a full **channel block** (`hidden_dim` ≤ 384) inside the tile.
All arithmetic is performed in FP16; the sigmoid uses the accurate
`tl.sigmoid` (computed in FP32 internally).

The kernel is launched with a 1‑D grid of size `B * grid_m * grid_n`.  Each
program instance handles one `(i_tile, j_tile)` for a single batch element.

---

### Host‑side wrapper (`custom_kernel`)

1. **LayerNorm** – done in PyTorch (very cheap compared with the cubic work).  
2. **Cast & view** – the normalized tensor is passed to the kernel as FP32.  
3. **Launch** the fused element‑wise kernel, producing three FP16 buffers.  
4. **Batched GEMM** – reshape the buffers to `(B·H, N, N)` and call
   `torch.bmm(left, right.transpose(1, 2))`.  This uses cuBLAS/Tensor‑cores
   (FP16 × FP16 → FP32 accumulation → FP16 output).  
5. **Reshape** the result back to `[B, N, N, hidden_dim]`.  
6. **Post‑processing** – LayerNorm, output‑gate, final linear projection
   (all in PyTorch, again cheap).

The entire pipeline works for all configurations listed in the statement,
supports the optional mask, and returns a **float‑32** tensor of shape
`[B, N, N, dim]`.

```python
"""
TriMul “outgoing” operator (AlphaFold‑3) – fast Triton‑fused elementwise pass.

* Element‑wise work (masking + three gates) is performed by a custom Triton
  kernel in FP16.
* The dominant cubic contraction is executed as a batched GEMM
  (torch.bmm) on FP16 tensors, taking advantage of Tensor‑cores.
* All remaining cheap operations (LayerNorm, final linear) stay in PyTorch.
* Supports optional mask and arbitrary batch/sequence sizes used in the test
  suite.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict, Any


# --------------------------------------------------------------
# Triton kernel – fuse elementwise projection, masking and gating
# --------------------------------------------------------------
@triton.jit
def trimul_fuse_elemwise(
    # ----- input -----
    x_ptr,          # float32*   [B, N, N, dim]
    mask_ptr,       # float32*   [B, N, N]  (or dummy)
    # ----- linear weights (no bias) -----
    proj_left_w_ptr,    # float32*   [dim, hidden_dim]
    proj_right_w_ptr,   # float32*   [dim, hidden_dim]
    gate_left_w_ptr,    # float32*   [dim, hidden_dim]
    gate_right_w_ptr,   # float32*   [dim, hidden_dim]
    out_gate_w_ptr,     # float32*   [dim, hidden_dim]
    # ----- output -----
    left_ptr,       # float16*   [B, hidden_dim, N, N]
    right_ptr,      # float16*   [B, hidden_dim, N, N]
    out_gate_ptr,   # float16*   [B, hidden_dim, N, N]
    # ----- dimensions & strides -----
    B, N, dim, hidden_dim,
    stride_xb, stride_xn, stride_xc,          # x strides (B,N,N,dim)
    stride_m_b, stride_m_n,                  # mask strides (B,N,N)
    stride_pl, stride_ph,                    # proj_left weight strides (dim, hidden_dim)
    stride_pr, stride_phw,                   # proj_right weight strides
    stride_gl, stride_gh,                    # gate_left weight strides
    stride_gr, stride_ghw,                   # gate_right weight strides
    stride_og, stride_ogh,                   # out_gate weight strides
    stride_lb, stride_lh, stride_ln,         # left output strides (B, hidden, N, N)
    stride_rb, stride_rh, stride_rn,         # right output strides
    stride_ob, stride_oh, stride_on,         # out_gate output strides
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    HAS_MASK: tl.constexpr,
):
    """
    For each (b, i_tile, j_tile) compute:
        left[b, h, i, j]   = (x[b,i,j,:] @ proj_left_w)   * mask * sigmoid(x @ left_gate_w)
        right[b, h, i, j]  = (x[b,i,j,:] @ proj_right_w)  * mask * sigmoid(x @ right_gate_w)
        out_gate[b, h, i, j] = sigmoid(x[b,i,j,:] @ out_gate_w)
    All results are stored as FP16.
    """

    pid = tl.program_id(0)

    # decode program id → batch, tile_i, tile_j
    grid_m = tl.cdiv(N, BLOCK_M)
    grid_n = tl.cdiv(N, BLOCK_N)

    tile_j = pid % grid_n
    pid //= grid_n
    tile_i = pid % grid_m
    pid //= grid_m
    b = pid   # 0 <= b < B

    # coordinate offsets inside the tile
    i_offset = tile_i * BLOCK_M + tl.arange(0, BLOCK_M)
    j_offset = tile_j * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_i = i_offset < N
    mask_j = j_offset < N
    mask_ij = mask_i[:, None] & mask_j[None, :]

    # -----------------------------------------------------------------
    # Load the input feature vector x[b,i,j,:]   shape (M,N,dim)
    # -----------------------------------------------------------------
    # shape: (BLOCK_M, BLOCK_N, dim)
    x_ptrs = x_ptr + \
        b * stride_xb + \
        i_offset[:, None, None] * stride_xn + \
        j_offset[None, :, None] * stride_xc
    x = tl.load(x_ptrs, mask=mask_ij[:, :, None], other=0.0)   # fp32

    # -----------------------------------------------------------------
    # Optional mask (broadcasted over dim)
    # -----------------------------------------------------------------
    if HAS_MASK:
        mask_ptrs = mask_ptr + b * stride_m_b + i_offset[:, None] * stride_m_n + j_offset[None, :]
        mask = tl.load(mask_ptrs, mask=mask_ij, other=0.0)
        mask = mask[:, :, None]          # (M,N,1)
        x = x * mask                     # mask before any projection
    # -----------------------------------------------------------------
    # Linear projections (no bias)  ->  (BLOCK_M, BLOCK_N, hidden_dim)
    # -----------------------------------------------------------------
    # left projection
    pl_ptrs = proj_left_w_ptr + tl.arange(0, dim)[:, None] * stride_pl + tl.arange(0, hidden_dim)[None, :] * stride_ph
    left = tl.dot(x, tl.load(pl_ptrs))          # fp32  -> (M,N,hidden)

    # right projection
    pr_ptrs = proj_right_w_ptr + tl.arange(0, dim)[:, None] * stride_pr + tl.arange(0, hidden_dim)[None, :] * stride_phw
    right = tl.dot(x, tl.load(pr_ptrs))

    # -----------------------------------------------------------------
    # Gates (sigmoid of linear)
    # -----------------------------------------------------------------
    gl_ptrs = gate_left_w_ptr + tl.arange(0, dim)[:, None] * stride_gl + tl.arange(0, hidden_dim)[None, :] * stride_gh
    gate_left = tl.sigmoid(tl.dot(x, tl.load(gl_ptrs)))   # fp32

    gr_ptrs = gate_right_w_ptr + tl.arange(0, dim)[:, None] * stride_gr + tl.arange(0, hidden_dim)[None, :] * stride_ghw
    gate_right = tl.sigmoid(tl.dot(x, tl.load(gr_ptrs)))

    og_ptrs = out_gate_w_ptr + tl.arange(0, dim)[:, None] * stride_og + tl.arange(0, hidden_dim)[None, :] * stride_ogh
    out_gate = tl.sigmoid(tl.dot(x, tl.load(og_ptrs)))

    # -----------------------------------------------------------------
    # Apply gates
    # -----------------------------------------------------------------
    left = left * gate_left
    right = right * gate_right

    # -----------------------------------------------------------------
    # Store results as FP16
    # -----------------------------------------------------------------
    # left  → (B, hidden, N, N)
    left_ptrs = left_ptr + \
        b * stride_lb + \
        tl.arange(0, hidden_dim)[:, None, None] * stride_lh + \
        i_offset[None, :, None] * stride_ln + \
        j_offset[None, None, :] * stride_ln
    tl.store(left_ptrs, left.to(tl.float16), mask=mask_ij[None, :, :])

    # right
    right_ptrs = right_ptr + \
        b * stride_rb + \
        tl.arange(0, hidden_dim)[:, None, None] * stride_rh + \
        i_offset[None, :, None] * stride_rn + \
        j_offset[None, None, :] * stride_rn
    tl.store(right_ptrs, right.to(tl.float16), mask=mask_ij[None, :, :])

    # out_gate (no mask)
    out_gate_ptrs = out_gate_ptr + \
        b * stride_ob + \
        tl.arange(0, hidden_dim)[:, None, None] * stride_oh + \
        i_offset[None, :, None] * stride_on + \
        j_offset[None, None, :] * stride_on
    tl.store(out_gate_ptrs, out_gate.to(tl.float16), mask=mask_ij[None, :, :])


# --------------------------------------------------------------
# Host‑side wrapper
# --------------------------------------------------------------
def custom_kernel(data: Tuple[
    torch.Tensor,                # input   : [B, N, N, dim]
    torch.Tensor,                # mask    : [B, N, N]  (or None)
    Dict[str, torch.Tensor],     # weights : dict of parameters
    Dict[str, Any]               # config  : {"dim":..., "hidden_dim":...}
]) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator (no gradient needed).

    Returns:
        torch.Tensor of shape [B, N, N, dim] (float32)
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dtype = torch.float32

    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]          # = H in the paper

    # -----------------------------------------------------------------
    # 1. First LayerNorm (cheap)
    # -----------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        normalized_shape=(dim,),
        weight=weights["norm.weight"].to(dtype),
        bias=weights["norm.bias"].to(dtype),
    )   # (B, N, N, dim)  FP32

    # -----------------------------------------------------------------
    # 2. Prepare buffers for the Triton kernel
    # -----------------------------------------------------------------
    # Output buffers are FP16, shape (B, hidden_dim, N, N)
    left_buf  = torch.empty((B, hidden_dim, N, N), device=device, dtype=torch.float16)
    right_buf = torch.empty((B, hidden_dim, N, N), device=device, dtype=torch.float16)
    out_gate_buf = torch.empty((B, hidden_dim, N, N), device=device, dtype=torch.float16)

    # -----------------------------------------------------------------
    # 3. Launch Triton kernel – elementwise part (mask + gates)
    # -----------------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    grid_m = triton.cdiv(N, BLOCK_M)
    grid_n = triton.cdiv(N, BLOCK_N)
    total_tiles = B * grid_m * grid_n
    grid = (total_tiles,)

    HAS_MASK = 1 if mask is not None else 0

    # Pass dummy pointer if mask is None (kernel will ignore it)
    mask_ptr = mask.contiguous() if mask is not None else torch.empty((1,), device=device, dtype=torch.float32)

    trimul_fuse_elemwise[grid](
        # inputs
        x,
        mask_ptr,
        # weights
        weights["left_proj.weight"],
        weights["right_proj.weight"],
        weights["left_gate.weight"],
        weights["right_gate.weight"],
        weights["out_gate.weight"],
        # outputs
        left_buf,
        right_buf,
        out_gate_buf,
        # dimensions
        B, N, dim, hidden_dim,
        # strides (input x)
        input_tensor.stride(0), input_tensor.stride(1), input_tensor.stride(2),
        # strides (mask)
        mask.stride(0) if mask is not None else 0,
        mask.stride(1) if mask is not None else 0,
        # strides (weights)
        weights["left_proj.weight"].stride(0), weights["left_proj.weight"].stride(1),
        weights["right_proj.weight"].stride(0), weights["right_proj.weight"].stride(1),
        weights["left_gate.weight"].stride(0), weights["left_gate.weight"].stride(1),
        weights["right_gate.weight"].stride(0), weights["right_gate.weight"].stride(1),
        weights["out_gate.weight"].stride(0), weights["out_gate.weight"].stride(1),
        # strides (outputs)
        left_buf.stride(0), left_buf.stride(1), left_buf.stride(2),
        right_buf.stride(0), right_buf.stride(1), right_buf.stride(2),
        out_gate_buf.stride(0), out_gate_buf.stride(1), out_gate_buf.stride(2),
        # compile‑time constants
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        HAS_MASK=HAS_MASK,
    )

    # -----------------------------------------------------------------
    # 4. Batched GEMM – the cubic contraction
    #    left  : (B, hidden, N, N)  → (B*H, N, N)
    #    right : (B, hidden, N, N)  → (B*H, N, N)
    # -----------------------------------------------------------------
    left_flat  = left_buf.view(B * hidden_dim, N, N)
    right_flat = right_buf.view(B * hidden_dim, N, N)

    # right needs to be transposed on the last two axes
    out_flat = torch.bmm(left_flat, right_flat.transpose(1, 2))   # (B*H, N, N) FP16

    # reshape back to (B, N, N, hidden_dim)
    out = out_flat.view(B, hidden_dim, N, N).permute(0, 2, 3, 1).contiguous()   # (B,N,N,hidden)

    # -----------------------------------------------------------------
    # 5. Post‑processing (LayerNorm, out_gate, final linear)
    # -----------------------------------------------------------------
    out = out.to(dtype)   # FP32 for the remaining ops

    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"].to(dtype),
        bias=weights["to_out_norm.bias"].to(dtype),
    )

    # apply output gate (broadcast over the two sequence axes)
    out_gate = out_gate_buf.view(B, hidden_dim, N, N).permute(0, 2, 3, 1).contiguous().to(dtype)
    out = out * out_gate

    # final linear back to original dim
    out = F.linear(out, weights["to_out.weight"].to(dtype))

    return out
```
