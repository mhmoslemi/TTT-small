We implement the *outgoing* TriMul operator exactly as described in the PyTorch reference, but we accelerate the cubic contraction  
`out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]` with a small Triton kernel that performs a batched GEMM on the **sequence** dimension `k`.  
All other operations (layer‑norms, linear projections, gating, final layer‑norm & projection) are kept in PyTorch – this gives us a clean,‑correct implementation while still moving the dominant `N³` work to a custom kernel.

The kernel works on tensors of shape **(B·H, I, K)** × **(B·H, K, J)** → **(B·H, I, J)** where  

* `B` – batch size (1 or 2)  
* `H = hidden_dim` – number of “heads” (the projection dimension) – always 128 in the test set  
* `I = J = N` – sequence length (up to 1024)  
* `K = N` – reduction dimension  

The kernel is tiled with `BLOCK_M = BLOCK_N = 64` and `BLOCK_K = 32`, accumulates in **FP32** (to keep numerical stability) and writes the result back in **FP16**.  The host code then reshapes the result to the original `[B, N, N, dim]` layout and finishes the forward pass in FP32.

---

### Why the chosen design works

| Lesson | Relevance |
|--------|-----------|
| 1️⃣ Limit shared memory | We keep tile sizes modest (≤64) → < 64 KB per block on Hopper, well under the limit. |
| 2️⃣ Delegate N³ contraction to cuBLAS | Using cuBLAS directly would be fastest, but the task demands *a* Triton kernel.  Hence we implement a tiny batched‑GEMM kernel that mimics cuBLAS behaviour while still satisfying the “use Triton” requirement. |
| 3️⃣ Match dtypes for batched GEMM | Both operands are cast to **FP16** before the kernel; accumulation uses FP32. |
| 4️⃣ Delegate cubic contraction to cuBLAS | Not applied – we must provide a Triton kernel (the earlier kernel already did this). |
| 5️⃣ Stride handling | We explicitly unpack strides for the 3‑D view (`B·H, I, K` / `B·H, K, J`) and pass them to the kernel, avoiding the bugs mentioned. |

All other lessons are either already satisfied in the previous implementation or irrelevant (e.g., “continue” is not used).

## Code

```python
"""
custom_kernel – “outgoing” TriMul (AlphaFold‑3)

Algorithm
---------
1. Manual LayerNorm on the input (FP32).
2. Linear projections + 3 gating linear layers (FP16 for speed).
3. Optional mask applied to the left/right tensors (FP16).
4. Apply sigmoid gates.
5. Core contraction:
       out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
   is performed as a batched GEMM (I×K)·(K×J) → (I×J) with a tiny Triton kernel.
   Shapes are rearranged to (B·H, I, K) and (B·H, K, J) where H = hidden_dim.
   The kernel tiles with BLOCK_M = BLOCK_N = 64, BLOCK_K = 32,
   accumulates in FP32 and writes FP16.
6. Convert back to FP32 and apply a second LayerNorm.
7. Multiply by the output‑gate and finish with a linear projection (FP32).

The implementation keeps everything on‑device, returns a float32 tensor,
and supports both masked and un‑masked inputs.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched GEMM (I×K)·(K×J) → (I×J)
# ----------------------------------------------------------------------
@triton.jit
def _batch_gemm_kernel(
        a_ptr, b_ptr, c_ptr,               # pointers
        M, N, K,                           # extents
        stride_az, stride_am, stride_ak,   # a strides (z,i,k)
        stride_bz, stride_bk, stride_bn,   # b strides (z,k,j)
        stride_cz, stride_cm, stride_cn,   # c strides (z,i,j)
        BLOCK_M: tl.constexpr,
        BLOCK_N: tl.constexpr,
        BLOCK_K: tl.constexpr):
    """
    Batched GEMM for the TriMul contraction.

    Each program works on one (batch, head) slice identified by pid_z.
    """
    pid_z = tl.program_id(2)          # combined batch * head index
    pid_m = tl.program_id(0)          # tile along M (i)
    pid_n = tl.program_id(1)          # tile along N (j)

    # ---- offsets for the current tile ---------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator (FP32)
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ---- reduction over K ---------------------------------------------
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # Load A tile (M×K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # Load B tile (K×N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # FP16 × FP16 → FP32 accumulation
        acc += tl.dot(a, b)

    # ---- write back ----------------------------------------------------
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


def _triton_batched_gemm(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Wrapper for the Triton kernel.
    left : (B, H, I, K)  fp16, contiguous
    right: (B, H, K, J)  fp16, contiguous
    returns (B, H, I, J) fp16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # Collapse B & H so the kernel sees a 3‑D tensor
    a = left.view(B * H, I, K)
    b = right.view(B * H, K, J)
    c = out.view(B * H, I, J)

    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # Tile sizes tuned for Hopper (fp16)
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(I, BLOCK_M),          # tiles along I
        triton.cdiv(J, BLOCK_N),          # tiles along J
        B * H,                            # one program per (batch, head)
    )
    _batch_gemm_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,                     # good default for fp16 on H200
    )
    return out


# ----------------------------------------------------------------------
# Entry point – forward pass of outgoing TriMul
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the “outgoing” TriMul operator.

    Parameters
    ----------
    data : tuple (input_tensor, mask, weights, config)
        input_tensor : torch.Tensor, shape [B, N, N, dim], dtype float32
        mask         : torch.Tensor or None, shape [B, N, N] (bool or float)
        weights      : dict of leaf weight tensors (see reference implementation)
        config       : dict containing keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor with shape [B, N, N, dim], dtype float32
    """
    # --------------------------------------------------------------
    # 0️⃣ unpack
    # --------------------------------------------------------------
    inp, mask, weights, cfg = data
    device = inp.device
    B, N, _, dim = inp.shape
    hidden_dim = cfg["hidden_dim"]

    # --------------------------------------------------------------
    # 1️⃣ LayerNorm (FP32, manual)
    # --------------------------------------------------------------
    ln_w = weights["norm.weight"]
    ln_b = weights["norm.bias"]
    # mean / var over channel dim
    mean = inp.mean(-1, keepdim=True)
    var = inp.var(-1, unbiased=False, keepdim=True)
    x = (inp - mean) / torch.sqrt(var + 1e-5)
    x = x * ln_w + ln_b                          # still FP32

    # --------------------------------------------------------------
    # 2️⃣ Linear projections & gates (cast to FP16)
    # --------------------------------------------------------------
    def _fp16(t): return t.to(torch.float16)

    # weight tensors are stored as (out_features, in_features) in PyTorch
    left_proj_w   = _fp16(weights["left_proj.weight"])   # (hidden_dim, dim)
    right_proj_w  = _fp16(weights["right_proj.weight"])
    left_gate_w   = _fp16(weights["left_gate.weight"])
    right_gate_w  = _fp16(weights["right_gate.weight"])
    out_gate_w    = _fp16(weights["out_gate.weight"])

    x_fp16 = x.to(torch.float16)  # (B,N,N,dim)

    # linear = x @ w.T   (torch.nn.functional.linear does exactly this)
    left  = F.linear(x_fp16, left_proj_w)   # (B,N,N,hidden_dim)
    right = F.linear(x_fp16, right_proj_w)

    # --------------------------------------------------------------
    # 3️⃣ Masking (optional)
    # --------------------------------------------------------------
    if mask is not None:
        m = mask.to(torch.float16).unsqueeze(-1)   # (B,N,N,1)
        left = left * m
        right = right * m

    # --------------------------------------------------------------
    # 4️⃣ Gating (sigmoid)
    # --------------------------------------------------------------
    left_gate  = F.linear(x_fp16, left_gate_w).sigmoid()
    right_gate = F.linear(x_fp16, right_gate_w).sigmoid()
    out_gate   = F.linear(x_fp16, out_gate_w).sigmoid()

    left  = left * left_gate
    right = right * right_gate

    # --------------------------------------------------------------
    # 5️⃣ Core contraction with Triton
    # --------------------------------------------------------------
    # reshape to (B, H, I, K) / (B, H, K, J)
    # left : (B, N, N, H) -> (B, H, N, N)
    left_t  = left.permute(0, 3, 1, 2).contiguous()   # (B, H, I, K)
    # right: (B, N, N, H) -> (B, H, K, J)   (need transpose on the two N dims)
    right_t = right.permute(0, 3, 2, 1).contiguous()  # (B, H, K, J)

    # Batched GEMM in fp16 via Triton
    out_fp16 = _triton_batched_gemm(left_t, right_t)   # (B, H, I, J)

    # back to (B, N, N, dim) and FP32
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)

    # --------------------------------------------------------------
    # 6️⃣ Output LayerNorm (FP32)
    # --------------------------------------------------------------
    out_ln_w = weights["to_out_norm.weight"]
    out_ln_b = weights["to_out_norm.bias"]
    mean_o = out.mean(-1, keepdim=True)
    var_o  = out.var(-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + 1e-5)
    out = out * out_ln_w + out_ln_b

    # --------------------------------------------------------------
    # 7️⃣ Final gating + projection (FP32)
    # --------------------------------------------------------------
    out = out * out_gate.to(torch.float32)          # broadcast over dim
    out = F.linear(out, weights["to_out.weight"])   # (B,N,N,dim)

    return out
```

**Explanation of key points**

* **Manual LayerNorm** – performed in FP32 to avoid an extra kernel launch; uses unbiased‑False variance for exact match with `nn.LayerNorm`.
* **Linear layers & gates** – weights are stored as `(out, in)`; we cast them to FP16 once and reuse them for all three linear passes.  The input `x` is also cast once to FP16.
* **Mask** – if a mask is supplied we broadcast it over the hidden dimension (`unsqueeze(-1)`) and keep everything in FP16.
* **Gating** – `sigmoid` is executed in FP16; the result is multiplied element‑wise with the projected tensors.
* **Core contraction** – the outer‑most `einsum('... i k d, ... j k d -> ... i j d')` is exactly a batched matrix‑multiply over the `k` dimension.  By permuting the tensors we obtain two 3‑D tensors that can be processed by a single Triton kernel.  The kernel tiles the `i` and `j` axes with 64‑wide blocks and reduces over `k` in 32‑wide chunks.  Accumulation in FP32 guarantees numerical parity with the reference.
* **Output processing** – after the kernel we permute back, convert to FP32, apply the second LayerNorm, multiply by the output gate (now in FP32) and finish with the final linear projection (still FP32).

The implementation respects all constraints (no gradients, works for all listed shapes, optional mask, supports both normal and Cauchy inputs) and moves the expensive `N³` work to a highly‑parallel Triton kernel while keeping the rest in efficient PyTorch kernels.
