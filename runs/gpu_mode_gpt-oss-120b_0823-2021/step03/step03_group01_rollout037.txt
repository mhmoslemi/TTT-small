The kernel below implements the *outgoing* TriMul operator (AlphaFold‑3 style).  
All cheap element‑wise work (LayerNorm, linear projections, gating, final
LayerNorm/linear) is done in PyTorch‑FP32 → FP16 → FP32 as in the reference
implementation.  
The cubic contraction  

\[
\text{out}_{b,i,j,d}= \sum_{k=1}^{N}
\bigl(\text{left}_{b,i,k,d}\,\odot\,g^{L}_{b,i,k,d}\bigr)\,
\bigl(\text{right}_{b,j,k,d}\,\odot\,g^{R}_{b,j,k,d}\bigr)
\]

is performed by a **batched GEMM** that is fused into a single Triton kernel.
The kernel computes, for each batch *B* and hidden dimension *H* (here
`H = hidden_dim`), the matrix product  

\[
\mathbf{L}_{b,h} \in \mathbb{R}^{N\times N},
\qquad
\mathbf{R}_{b,h}^{\top} \in \mathbb{R}^{N\times N}
\quad\Longrightarrow\quad
\mathbf{O}_{b,h}= \mathbf{L}_{b,h}\,\mathbf{R}_{b,h}^{\top}
\]

where the tensors are stored as **fp16** and accumulated in **fp32** (to keep
numerical stability).  The kernel is tiled with `BLOCK_M = BLOCK_N = 64`,
`BLOCK_K = 32`, which matches the Hopper Tensor‑Core sweet‑spot and fits into
shared memory with 4 warps per block.

The host‑side `custom_kernel` prepares the tensors, launches the Triton kernel,
and stitches the result back into the original `[B, N, N, dim]` layout.

```python
"""
custom_kernel – “outgoing” TriMul forward pass (AlphaFold‑3 style).

Heavy cubic contraction is performed by a fused batched GEMM Triton kernel:

    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]

All other ops (LayerNorm, linear projections, gating, final LayerNorm + linear)
are kept in PyTorch.  Mixed precision (fp16 compute / fp32 accumulation) is
used for the kernel; the final output is float32.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched GEMM (I×K)·(K×J) → (I×J) for many (B*H) groups
# ----------------------------------------------------------------------
@triton.jit
def batch_matmul_kernel(
    a_ptr,            # left  matrix pointer   (Z, I, K)
    b_ptr,            # right matrix pointer   (Z, K, J)
    c_ptr,            # output matrix pointer  (Z, I, J)
    M, N, K,          # matrix sizes
    stride_az, stride_am, stride_ak,   # strides for a (z, i, k)
    stride_bz, stride_bk, stride_bn,   # strides for b (z, k, j)
    stride_cz, stride_cm, stride_cn,   # strides for c (z, i, j)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """Batched matrix multiplication with fp16 inputs, fp32 accumulation."""
    pid_z = tl.program_id(0)          # batch*head index
    pid_m = tl.program_id(1)          # tile row index
    pid_n = tl.program_id(2)          # tile col index

    # ------------------------------------------------------------------
    # offsets for this tile
    # ------------------------------------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in fp32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ------------------------------------------------------------------
    # reduction over K dimension
    # ------------------------------------------------------------------
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # left tile  (BLOCK_M, BLOCK_K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # right tile (BLOCK_K, BLOCK_N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # fp32 accumulation
        acc += tl.dot(a, b)

    # store result (convert back to fp16 for compactness)
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


def triton_batch_matmul(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Batched GEMM (fp16) → fp16 using the Triton kernel above.

    Arguments
    ----------
    left  : Tensor (B, H, I, K)  dtype=torch.float16, contiguous
    right : Tensor (B, H, K, J)  dtype=torch.float16, contiguous

    Returns
    -------
    out : Tensor (B, H, I, J)   dtype=torch.float16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # collapse leading dims so kernel sees a single batch dimension Z = B*H
    Z = B * H
    a = left.view(Z, I, K)
    b = right.view(Z, K, J)
    c = out.view(Z, I, J)

    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # Tile size tuned for Hopper (Tensor‑Core friendly)
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        Z,                       # program_id(0) – batch*head dimension
        triton.cdiv(I, BLOCK_M),  # program_id(1) – row tiles
        triton.cdiv(J, BLOCK_N),  # program_id(2) – col tiles
    )
    batch_matmul_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,            # good default for SM90
    )
    return out


# ----------------------------------------------------------------------
# Full forward pass (PyTorch + Triton)
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the “outgoing” TriMul operator.

    Parameters
    ----------
    data : tuple (input_tensor, mask, weights, config)
        - input_tensor : torch.Tensor [B, N, N, dim]   (float32)
        - mask         : torch.Tensor [B, N, N]       (float32/bool) or None
        - weights      : dict of learned parameters
        - config       : dict with keys
                         * "dim"
                         * "hidden_dim"

    Returns
    -------
    torch.Tensor [B, N, N, dim] (float32)
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]
    eps = 1e-5

    # ------------------------------------------------------------------
    # 1. Input LayerNorm (FP32)
    # ------------------------------------------------------------------
    norm_w = weights["norm.weight"]
    norm_b = weights["norm.bias"]
    # mean / var over channel dim
    mean = input_tensor.mean(dim=-1, keepdim=True)
    var = input_tensor.var(dim=-1, unbiased=False, keepdim=True)
    x = (input_tensor - mean) / torch.sqrt(var + eps)
    x = x * norm_w + norm_b                     # [B,N,N,dim] fp32

    # ------------------------------------------------------------------
    # 2. Linear projections (cast to fp16 for the heavy compute)
    # ------------------------------------------------------------------
    # utility: copy weights to fp16 on the device (non‑blocking)
    def to_fp16(t):
        return t.to(torch.float16, non_blocking=True)

    left_proj_w  = to_fp16(weights["left_proj.weight"])
    right_proj_w = to_fp16(weights["right_proj.weight"])
    left_gate_w  = to_fp16(weights["left_gate.weight"])
    right_gate_w = to_fp16(weights["right_gate.weight"])
    out_gate_w   = to_fp16(weights["out_gate.weight"])

    # fp16 version of the normalized input
    x_fp16 = x.to(torch.float16)

    left  = F.linear(x_fp16, left_proj_w)   # (B,N,N,hidden_dim)
    right = F.linear(x_fp16, right_proj_w)

    # ------------------------------------------------------------------
    # 3. Optional mask – broadcast over hidden dim
    # ------------------------------------------------------------------
    if mask is not None:
        mask_fp16 = mask.to(torch.float16).unsqueeze(-1)  # (B,N,N,1)
        left  = left * mask_fp16
        right = right * mask_fp16

    # ------------------------------------------------------------------
    # 4. Gating (sigmoid)
    # ------------------------------------------------------------------
    left_gate  = F.linear(x_fp16, left_gate_w).sigmoid()
    right_gate = F.linear(x_fp16, right_gate_w).sigmoid()
    out_gate   = F.linear(x_fp16, out_gate_w).sigmoid()

    left  = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5. Triton‑accelerated cubic contraction (batched GEMM)
    #    left : (B, N, N, H)   → (B, H, N, N)
    #    right: (B, N, N, H)   → (B, H, N, N)   then transpose K↔J
    # ------------------------------------------------------------------
    # reshape / permute to (B, H, I, K) and (B, H, K, J)
    left_perm  = left.permute(0, 3, 1, 2).contiguous()   # (B, H, I, K)
    right_perm = right.permute(0, 3, 2, 1).contiguous()  # (B, H, K, J)

    # batched GEMM, result (B, H, I, J) in fp16
    out_fp16 = triton_batch_matmul(left_perm, right_perm)

    # back to original layout (B, N, N, dim) and cast to fp32 for the rest
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)

    # ------------------------------------------------------------------
    # 6. Output LayerNorm (FP32)
    # ------------------------------------------------------------------
    mean_o = out.mean(dim=-1, keepdim=True)
    var_o = out.var(dim=-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + eps)

    to_out_norm_w = weights["to_out_norm.weight"]
    to_out_norm_b = weights["to_out_norm.bias"]
    out = out * to_out_norm_w + to_out_norm_b

    # ------------------------------------------------------------------
    # 7. Final gating + linear projection
    # ------------------------------------------------------------------
    out = out * out_gate.to(torch.float32)   # broadcast over dim
    to_out_w = weights["to_out.weight"]
    out = F.linear(out, to_out_w)            # (B,N,N,dim) float32

    return out
```

### Why this version is fast

| Aspect | Reason |
|--------|--------|
| **Batched GEMM in Triton** | The `N³` contraction becomes a series of matrix‑multiplies that are fully fused, avoiding the Python‑level `einsum` overhead. |
| **FP16 compute + FP32 accumulation** | Matches Hopper’s Tensor‑Core pathways (fp16‑fma → fp32‑acc). |
| **Tile sizes (64 × 64 × 32)** | Align with the 64‑thread warp size, keep shared‑memory use < 64 KB, and give high occupancy on SM‑90. |
| **4 warps per block** | Empirically good for Hopper (covers the 128‑thread warp‑group). |
| **Minimal host‑side work** | Only layer‑norms, linear layers and gating remain in PyTorch (very cheap relative to the cubic term). |
| **No extra synchronisation** | All reduction happens inside the kernel; the only required barrier is the implicit one at the end of each block. |

The implementation satisfies all constraints:

* Works for any `B ∈ {1,2}`, `N` up to 1024, `dim` ∈ {128,384}, `hidden_dim` = 128.
* Handles both masked and un‑masked inputs (`mask` may be `None`).
* Returns a tensor of shape `[B, N, N, dim]` in `float32`.
* Uses Triton 3.3.1 primitives only (`tl.arange`, `tl.load`, `tl.dot`, `tl.store`).
