"""
custom_kernel – “outgoing” TriMul forward (AlphaFold‑3 style).

The heavy N³ contraction

    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]

is performed by a custom Triton batched‑GEMM kernel.  All surrounding
operations (LayerNorm, linear projections, sigmoid gates, output‑LayerNorm and
final linear) are kept in native PyTorch because they are cheap compared with
the cubic work and because they avoid extra kernel launches.  Mixed‑precision
(fp16 arithmetic / fp32 accumulation) is used inside the Triton kernel; the
final result is cast back to fp32 so the rest of the model can stay in fp32.

The kernel works for any batch size B ∈ {1,2}, any sequence length N up to
1024 and any hidden dimension H (called ``hidden_dim`` in the config).  The
layout required by the kernel is (B, H, I, K) for the left operand and
(B, H, K, J) for the right operand, where I = J = N and K = N.  We simply
reshape the tensors after the linear projections/gates so that a single launch
covers the whole batch * hidden‑dim* dimension (Z = B*H).

The implementation follows the usual Triton “tile‑loop‑reduce” pattern with
BLOCK_M = BLOCK_N = 64 and BLOCK_K = 32 – a good fit for Hopper/Tensor‑Core
matmuls while staying well under the shared‑memory limit.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched GEMM (I×K)·(K×J) → (I×J)
#   acc   : fp32   (to keep numeric quality)
#   a,b   : fp16   (Tensor‑Core friendly)
# ----------------------------------------------------------------------
@triton.jit
def _batch_matmul_kernel(
    a_ptr,            # left  matrix pointer   (Z, I, K)
    b_ptr,            # right matrix pointer   (Z, K, J)
    c_ptr,            # output matrix pointer  (Z, I, J)
    M, N, K,          # matrix sizes
    stride_az, stride_am, stride_ak,   # strides for a (z,i,k)
    stride_bz, stride_bk, stride_bn,   # strides for b (z,k,j)
    stride_cz, stride_cm, stride_cn,   # strides for c (z,i,j)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    # ------------------------------------------------------------------
    # 1)  tile indices
    # ------------------------------------------------------------------
    pid_z = tl.program_id(0)          # batch*head dimension
    pid_m = tl.program_id(1)          # row tile index
    pid_n = tl.program_id(2)          # col tile index

    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in fp32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ------------------------------------------------------------------
    # 2)  reduction over K
    # ------------------------------------------------------------------
    for start_k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = start_k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # left tile: (BLOCK_M, BLOCK_K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # right tile: (BLOCK_K, BLOCK_N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # fp32 accumulation (Tensor‑Core dot works on fp16, result fp32)
        acc += tl.dot(a, b)

    # ------------------------------------------------------------------
    # 3)  write back (convert to fp16 to match the rest of the pipeline)
    # ------------------------------------------------------------------
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


def _triton_batch_matmul(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Batched GEMM using the Triton kernel above.

    Parameters
    ----------
    left  : Tensor (B, H, I, K)  dtype=torch.float16, contiguous
    right : Tensor (B, H, K, J)  dtype=torch.float16, contiguous

    Returns
    -------
    out : Tensor (B, H, I, J) dtype=torch.float16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # Collapse leading dimensions → Z = B*H so the kernel sees a 3‑D tensor.
    Z = B * H
    a = left.view(Z, I, K)
    b = right.view(Z, K, J)
    c = out.view(Z, I, J)

    # Strides in element units (not bytes)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # Tuned tile sizes for Hopper (Tensor‑Core friendly)
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        Z,                 # program_id(0) → batch*head
        triton.cdiv(I, BLOCK_M),   # program_id(1) → row tiles
        triton.cdiv(J, BLOCK_N),   # program_id(2) → col tiles
    )

    _batch_matmul_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,            # 4 warps works well on SM90
    )
    return out


# ----------------------------------------------------------------------
# Full forward pass (PyTorch + Triton)
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the “outgoing” TriMul operator.

    Arguments
    ----------
    data : tuple (input_tensor, mask, weights, config)
        input_tensor : torch.Tensor [B, N, N, dim]   (float32)
        mask         : torch.Tensor [B, N, N]       (bool/float) or None
        weights      : dict of parameter tensors (all fp32)
        config       : dict with keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor [B, N, N, dim] (float32)
    """
    inp, mask, weights, config = data
    device = inp.device
    B, N, _, dim = inp.shape
    hidden = config["hidden_dim"]
    eps = 1e-5

    # ------------------------------------------------------------------
    # 1) Input LayerNorm (FP32, keep full precision)
    # ------------------------------------------------------------------
    w_norm = weights["norm.weight"]
    b_norm = weights["norm.bias"]
    mean = inp.mean(dim=-1, keepdim=True)
    var = inp.var(dim=-1, unbiased=False, keepdim=True)
    x = (inp - mean) / torch.sqrt(var + eps)
    x = x * w_norm + b_norm                     # [B,N,N,dim]  fp32

    # ------------------------------------------------------------------
    # 2) Linear projections – move to fp16 for the cubic work
    # ------------------------------------------------------------------
    def _to_fp16(t):
        return t.to(torch.float16, non_blocking=True)

    left_proj_w  = _to_fp16(weights["left_proj.weight"])
    right_proj_w = _to_fp16(weights["right_proj.weight"])
    left_gate_w  = _to_fp16(weights["left_gate.weight"])
    right_gate_w = _to_fp16(weights["right_gate.weight"])
    out_gate_w   = _to_fp16(weights["out_gate.weight"])

    x_fp16 = x.to(torch.float16)

    left  = F.linear(x_fp16, left_proj_w)   # (B,N,N,hidden)
    right = F.linear(x_fp16, right_proj_w)

    # ------------------------------------------------------------------
    # 3) Optional mask (broadcast over the hidden dimension)
    # ------------------------------------------------------------------
    if mask is not None:
        mask_fp16 = mask.to(torch.float16).unsqueeze(-1)          # (B,N,N,1)
        left  = left * mask_fp16
        right = right * mask_fp16

    # ------------------------------------------------------------------
    # 4) Gating – sigmoid on fp16 activations
    # ------------------------------------------------------------------
    left_gate  = F.linear(x_fp16, left_gate_w).sigmoid()
    right_gate = F.linear(x_fp16, right_gate_w).sigmoid()
    out_gate   = F.linear(x_fp16, out_gate_w).sigmoid()

    left  = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5) Rearrange to (B, H, I, K) and (B, H, K, J) for the kernel
    # ------------------------------------------------------------------
    # left : (B, N, N, H) → (B, H, N, N)
    left_perm  = left.permute(0, 3, 1, 2).contiguous()
    # right: (B, N, N, H) → need (B, H, K, J) where K=N, J=N.
    # The einsum uses right[b, j, k, d]; we therefore transpose the
    # two sequence axes before permuting.
    right_perm = right.permute(0, 3, 2, 1).contiguous()

    # ------------------------------------------------------------------
    # 6) Cubic contraction with Triton
    # ------------------------------------------------------------------
    out_fp16 = _triton_batch_matmul(left_perm, right_perm)   # (B, H, N, N)

    # Back to the original layout and dtype (fp32) for the rest of the model
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)  # (B,N,N,dim)

    # ------------------------------------------------------------------
    # 7) Output LayerNorm (FP32)
    # ------------------------------------------------------------------
    w_out_norm = weights["to_out_norm.weight"]
    b_out_norm = weights["to_out_norm.bias"]
    mean_o = out.mean(dim=-1, keepdim=True)
    var_o  = out.var(dim=-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + eps)
    out = out * w_out_norm + b_out_norm

    # ------------------------------------------------------------------
    # 8) Final gating + linear projection (FP32)
    # ------------------------------------------------------------------
    out = out * out_gate.to(torch.float32)          # broadcast over dim
    w_out = weights["to_out.weight"]
    out = F.linear(out, w_out)                     # (B,N,N,dim)

    return out
```

### Why this version is fast enough
1. **Dominant work on Triton** – the only O(N³) operation (the contraction) is
   executed by a fused batched‑GEMM kernel that uses fp16 Tensor‑Core math
   with fp32 accumulation.  This gives roughly the same throughput as cuBLAS
   `bmm` but stays within the “must‑use‑some‑Triton” rule.

2. **Small‑tile, low‑shared‑mem layout** – `BLOCK_M = BLOCK_N = 64` and
   `BLOCK_K = 32` keep the per‑CTA shared‑memory footprint well below the
   Hopper limit while allowing 4 warps (8 threads per warp) to fully occupy
   the SM.

3. **Mixed‑precision pipeline** – everything that touches the cubic term is
   cast to fp16 early, limiting the amount of data moved in and out of the
   kernel.  The rest of the network (layer‑norms, gates, final projection)
   stays in fp32 for numerical stability.

4. **No extra synchronizations** – the kernel works on independent
   `(batch, head)` slices, so no inter‑CTA communication is required.

The implementation respects all constraints (no gradients, supports masked /
unmasked inputs, works for the listed dimensions, and runs on an NVIDIA
H200).
