--------------------

The outgoing `TriMul` operator consists of five stages  

1. **Input Layer‑Norm** – standard `torch.nn.functional.layer_norm`.  
2. **Linear projections** – four linear layers (`left_proj`, `right_proj`,
   `left_gate`, `right_gate`, `out_gate`).  
3. **Fusion of mask & gates** – element‑wise multiplication

```
left_fused  = left  * left_gate  * mask
right_fused = right * right_gate * mask
```

   This part must be executed by a **Triton kernel** (the only mandatory
   kernel in the solution).  

4. **Batched matrix multiplication** – the $N^3$ contraction

```
out[b, i, j, h] = Σ_k left_fused[b,i,k,h] * right_fused[b,j,k,h]
```

   is performed as a batched GEMM after reshaping the tensors to
   `(B*H, N, N)`.  Using `torch.bmm` (cuBLAS/Tensor‑cores) gives the best
   throughput on an H200.  

5. **Hidden‑dim Layer‑Norm, out‑gate, final projection** – again pure PyTorch.

All arithmetic that participates in the GEMM is kept in **FP16** (Tensor‑core
friendly) while the accumulators are FP32 (default for `torch.bmm`).  The
final result is converted back to FP32 to match the reference implementation.

The Triton kernel (`_apply_mask_and_gate_kernel`) works on a 1‑D grid,
processes a contiguous block of elements and supports the two execution
modes required by the spec:

* `nomask = True` → `HAS_MASK = False`  (mask is ignored, `m = 1.0`).
* `nomask = False` → `HAS_MASK = True` (mask broadcasted over the hidden
  dimension).

The kernel receives **all strides** of the tensors so it works for any
contiguous layout (the reference tensors are contiguous after the `to()`
calls).  The block size is chosen as `BLOCK = 1024`, a good trade‑off for the
H200 (covers ∼8 KiB of FP16 data per block, well within shared‑memory limits).

The host‑side `custom_kernel` function glues everything together,
converts weights to the proper dtype, and returns a tensor of shape
`[B, N, N, C]` in `float32`.

```python
"""
custom_kernel – outgoing TriMul (AlphaFold‑3)

Algorithm
---------
1️⃣ Input LayerNorm (FP32)
2️⃣ Linear projections → (B,N,N,H)   (FP32 → FP16)
3️⃣ Triton kernel fuses mask & gates:
       left_fused  = left  * left_gate  * mask
       right_fused = right * right_gate * mask
4️⃣ Reshape to (B*H, N, N) and perform a batched GEMM
       out[b,h] = left_fused[b,h] @ right_fused[b,h].T
5️⃣ Hidden‑dim LayerNorm, multiply by out_gate and final linear projection
   (all back in FP32)

Only step 3 is executed on Triton; the remaining work uses highly‑optimized
PyTorch/cuBLAS kernels.  All heavy arithmetic is in FP16 with FP32
accumulation, final output is FP32.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict, Any


# ----------------------------------------------------------------------
#  Triton kernel – fuse mask and per‑element gates
# ----------------------------------------------------------------------
@triton.jit
def _apply_mask_and_gate_kernel(
    # input tensors (FP16)
    left_ptr, right_ptr,          # (B,N,N,H)
    left_gate_ptr, right_gate_ptr,# (B,N,N,H)
    mask_ptr,                     # (B,N,N,1)  or nullptr
    # output tensors
    out_left_ptr, out_right_ptr,  # (B,N,N,H)

    # shape parameters (int32)
    B, N, H,

    # strides (int64) for the 4‑D tensors
    stride_l0, stride_l1, stride_l2, stride_l3,   # left / right
    stride_rg0, stride_rg1, stride_rg2, stride_rg3, # left_gate / right_gate
    stride_m0, stride_m1, stride_m2,                # mask (no hidden dim)

    # compile‑time constants
    HAS_MASK: tl.constexpr,
    BLOCK: tl.constexpr,
):
    """
    For each element (b,i,j,h):
        out_left  = left  * left_gate  * mask
        out_right = right * right_gate * mask
    """
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)          # linear index
    total = B * N * N * H
    mask = offs < total

    # -------- decode linear index to (b,i,j,h) -------------
    tmp = offs
    h = tmp % H
    tmp = tmp // H
    j = tmp % N
    tmp = tmp // N
    i = tmp % N
    b = tmp // N

    # -------- load left / right ----------------------------
    idx_lr = (
        b * stride_l0 + i * stride_l1 + j * stride_l2 + h * stride_l3
    )
    left = tl.load(left_ptr + idx_lr, mask=mask, other=0.0)
    right = tl.load(right_ptr + idx_lr, mask=mask, other=0.0)

    # -------- load gates ------------------------------------
    idx_gate = (
        b * stride_rg0 + i * stride_rg1 + j * stride_rg2 + h * stride_rg3
    )
    lgate = tl.load(left_gate_ptr + idx_gate, mask=mask, other=0.0)
    rgate = tl.load(right_gate_ptr + idx_gate, mask=mask, other=0.0)

    # -------- load mask (if present) -----------------------
    if HAS_MASK:
        idx_mask = b * stride_m0 + i * stride_m1 + j * stride_m2
        m = tl.load(mask_ptr + idx_mask, mask=mask, other=0.0)
    else:
        m = 1.0

    # -------- fused writes ---------------------------------
    out_l = left * lgate * m
    out_r = right * rgate * m

    tl.store(out_left_ptr + idx_lr, out_l, mask=mask)
    tl.store(out_right_ptr + idx_lr, out_r, mask=mask)


# ----------------------------------------------------------------------
#  Host‑side entry point
# ----------------------------------------------------------------------
def custom_kernel(
    data: Tuple[
        torch.Tensor,                 # input (B,N,N,C) float32
        torch.Tensor,                 # mask (B,N,N)  bool/float or None
        Dict[str, torch.Tensor],      # weights (float32)
        Dict[str, Any]                # config {"dim":C, "hidden_dim":H}
    ]
) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.

    Parameters
    ----------
    data : tuple
        (x, mask, weights, config)
        x          – (B, N, N, C) torch.float32
        mask       – (B, N, N) torch.bool / torch.float32 / None
        weights    – dict with all learned parameters (float32)
        config     – {"dim": C, "hidden_dim": H}

    Returns
    -------
    torch.Tensor
        (B, N, N, C) float32
    """
    x, mask, weights, config = data
    device = x.device
    dtype = torch.float32

    B, N, _, C = x.shape
    H = config["hidden_dim"]

    # --------------------------------------------------------------
    # 1️⃣ Input LayerNorm (FP32)
    # --------------------------------------------------------------
    x = F.layer_norm(
        x,
        normalized_shape=(C,),
        weight=weights["norm.weight"].to(dtype),
        bias=weights["norm.bias"].to(dtype),
    )

    # --------------------------------------------------------------
    # 2️⃣ Linear projections (produce FP16 tensors)
    # --------------------------------------------------------------
    # Note: all linear layers are bias‑free → we can use F.linear directly
    left      = F.linear(x, weights["left_proj.weight"].to(dtype))   # (B,N,N,H)
    right     = F.linear(x, weights["right_proj.weight"].to(dtype))
    left_gate = torch.sigmoid(F.linear(x, weights["left_gate.weight"].to(dtype)))
    right_gate= torch.sigmoid(F.linear(x, weights["right_gate.weight"].to(dtype)))
    out_gate  = torch.sigmoid(F.linear(x, weights["out_gate.weight"].to(dtype)))

    # Cast everything to FP16 (contiguous layout required for Triton)
    left_fp16      = left.to(torch.float16).contiguous()
    right_fp16     = right.to(torch.float16).contiguous()
    left_gate_fp16 = left_gate.to(torch.float16).contiguous()
    right_gate_fp16= right_gate.to(torch.float16).contiguous()

    if mask is None:
        # dummy mask – not read because HAS_MASK=False
        mask_fp16 = torch.empty(0, device=device, dtype=torch.float16)
        has_mask = False
    else:
        # mask shape (B,N,N) -> (B,N,N,1) for broadcasting over H
        mask_fp16 = mask.to(torch.float16).unsqueeze(-1).contiguous()
        has_mask = True

    # ------------------------------------------------------------------
    # 3️⃣ Triton kernel – apply mask and gates
    # ------------------------------------------------------------------
    left_fused  = torch.empty_like(left_fp16)
    right_fused = torch.empty_like(right_fp16)

    total_elements = B * N * N * H
    BLOCK = 1024                          # empirically good for H200
    grid = (triton.cdiv(total_elements, BLOCK),)

    _apply_mask_and_gate_kernel[grid](
        # pointers
        left_fp16,
        right_fp16,
        left_gate_fp16,
        right_gate_fp16,
        mask_fp16,
        left_fused,
        right_fused,
        # shape
        B, N, H,
        # strides for left/right (identical)
        left_fp16.stride(0), left_fp16.stride(1),
        left_fp16.stride(2), left_fp16.stride(3),
        # strides for gates
        left_gate_fp16.stride(0), left_gate_fp16.stride(1),
        left_gate_fp16.stride(2), left_gate_fp16.stride(3),
        # strides for mask (no hidden dim)
        mask_fp16.stride(0) if has_mask else 0,
        mask_fp16.stride(1) if has_mask else 0,
        mask_fp16.stride(2) if has_mask else 0,
        # compile‑time args
        HAS_MASK=has_mask,
        BLOCK=BLOCK,
    )

    # --------------------------------------------------------------
    # 4️⃣ Batched GEMM (FP16 inputs → FP16 output, FP32 accumulation)
    # --------------------------------------------------------------
    # reshape to (B*H, N, N)
    left_mat  = left_fused.permute(0, 3, 1, 2).reshape(B * H, N, N)   # (B*H,N,N)
    right_mat = right_fused.permute(0, 3, 1, 2).reshape(B * H, N, N)  # (B*H,N,N)

    # out_mat[b] = left_mat[b] @ right_mat[b].T
    out_mat = torch.bmm(left_mat, right_mat.transpose(1, 2))          # (B*H,N,N)

    # reshape back to (B, N, N, H) and convert to FP32 for the next LayerNorm
    out = out_mat.view(B, H, N, N).permute(0, 2, 3, 1).contiguous().to(dtype)

    # --------------------------------------------------------------
    # 5️⃣ Hidden‑dim LayerNorm, out‑gate, final projection (FP32)
    # --------------------------------------------------------------
    out = F.layer_norm(
        out,
        normalized_shape=(H,),
        weight=weights["to_out_norm.weight"].to(dtype),
        bias=weights["to_out_norm.bias"].to(dtype),
    )
    out = out * out_gate                # broadcast (B,N,N, H) * (B,N,N, H)
    out = F.linear(out, weights["to_out.weight"].to(dtype))   # (B,N,N,C)

    return out
```
