We implement the *outgoing* TriMul operator (the contraction  

```
out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
```

) with a **hybrid strategy**:

1. **Cheap ops** – LayerNorm, linear projections, masking and gating – stay in
   pure PyTorch (FP32).  
2. **Heavy cubic contraction** – the batched matrix‑multiply on the
   `(B·H, N, N)` tensors – is performed by a **custom Triton kernel** that
   computes a batched GEMM in FP16 with FP32 accumulation (Tensor‑Core‑friendly).

The kernel tiles the output matrix into `BLOCK_M × BLOCK_N` blocks and iterates
over the reduction dimension `K` in chunks of `BLOCK_K`.  Each program instance
computes one tile for a specific `bh = b*H + h`.  The algorithm mirrors the
standard blocked GEMM used in cuBLAS but is written entirely in Triton, thus
fulfilling the “implement at least part of the ops in a kernel” requirement.

All tensor reshapes/permutes are done on the host side; the kernel receives
contiguous FP16 buffers together with explicit strides, making it robust to
different input layouts.

The final output is cast back to FP32, a second LayerNorm, output‑gate
application and a final linear projection are performed in PyTorch, exactly as
the reference implementation.

```python
"""
custom_kernel – outgoing TriMul (AlphaFold‑3) with a fused Triton batched GEMM.

The kernel computes, for every batch‑head pair (b, h):
    out[b*h, i, j] = Σ_k left[b*h, i, k] * right[b*h, j, k]   (right is transposed)

Implementation details
----------------------
* Left / Right tensors are FP16, accumulated in FP32 for numerical stability.
* Tiling: BLOCK_M × BLOCK_N output tile, reduction over K in BLOCK_K chunks.
* One program instance per (bh, tile_m, tile_n) → grid size = BH * ceil(N/BM) * ceil(N/BN).
* Strides are passed explicitly; the kernel works for any contiguous layout.
* Remaining ops (LayerNorm, Linear, gating, final projection) stay in PyTorch
  (FP32) because they are negligible compared to the O(N³) contraction.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict, Any


# ---------------------------------------------------------------------------
# Triton kernel: batched GEMM for the cubic contraction
# ---------------------------------------------------------------------------
@triton.jit
def _trimul_batched_gemm_kernel(
    left_ptr,          # const float16*  [BH, N, N]
    right_ptr,         # const float16*  [BH, N, N]  (will be read transposed)
    out_ptr,           #       float16*  [BH, N, N]
    BH, N,             # problem sizes
    stride_lbh, stride_lbn, stride_lbk,   # left strides
    stride_rbh, stride_rbn, stride_rbk,   # right strides
    stride_obh, stride_obn, stride_obk,   # out strides
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Compute a (BLOCK_M × BLOCK_N) tile of the product
        out[bh, i, j] = Σ_k left[bh,i,k] * right[bh,j,k]   (right is transposed)

    Arguments
    ---------
    left_ptr, right_ptr, out_ptr : pointers to the FP16 buffers.
    BH, N                         : batch‑head count and sequence length.
    stride_*                     : strides (in elements) for each tensor.
    BLOCK_M, BLOCK_N, BLOCK_K    : tiling parameters (compile‑time constants).
    """
    pid = tl.program_id(0)               # linear id over (bh, tile_m, tile_n)

    # -------------------------------------------------
    # Decode the 3‑D program id
    # -------------------------------------------------
    num_tiles_m = tl.cdiv(N, BLOCK_M)
    num_tiles_n = tl.cdiv(N, BLOCK_N)

    tile_n = pid % num_tiles_n
    pid //= num_tiles_n
    tile_m = pid % num_tiles_m
    pid //= num_tiles_m
    bh = pid                              # 0 <= bh < BH

    # -------------------------------------------------
    # Offsets for this tile
    # -------------------------------------------------
    offs_m = tile_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = tile_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < N
    mask_n = offs_n < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # -------------------------------------------------
    # Loop over K dimension
    # -------------------------------------------------
    for kk in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = kk * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # left[bh, i, k]   shape (M, K)
        l_ptr = (left_ptr +
                 bh * stride_lbh +
                 offs_m[:, None] * stride_lbn +
                 offs_k[None, :] * stride_lbk)
        l = tl.load(l_ptr,
                    mask=mask_m[:, None] & mask_k[None, :],
                    other=0.0).to(tl.float32)

        # right[bh, j, k] needs to be read as (K, N) because we multiply
        # left[i,k] * right[j,k] = left[i,k] * (right^T)[k,j]
        r_ptr = (right_ptr +
                 bh * stride_rbh +
                 offs_k[:, None] * stride_rbk +
                 offs_n[None, :] * stride_rbn)
        r = tl.load(r_ptr,
                    mask=mask_k[:, None] & mask_n[None, :],
                    other=0.0).to(tl.float32)

        # GEMM: (M,K) @ (K,N) → (M,N)
        acc += tl.dot(l, r)

    # -------------------------------------------------
    # Write result back (cast to FP16)
    # -------------------------------------------------
    out_ptrs = (out_ptr +
                bh * stride_obh +
                offs_m[:, None] * stride_obn +
                offs_n[None, :] * stride_obk)
    tl.store(out_ptrs,
             acc.to(tl.float16),
             mask=mask_m[:, None] & mask_n[None, :])


# ---------------------------------------------------------------------------
# Host‑side wrapper
# ---------------------------------------------------------------------------
def custom_kernel(
    data: Tuple[
        torch.Tensor,                # input  : [B, N, N, dim] (float32)
        torch.Tensor,                # mask   : [B, N, N]  (or None)
        Dict[str, torch.Tensor],     # weights : dict of parameters
        Dict[str, Any],              # config  : {"dim":..., "hidden_dim":...}
    ]
) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.

    Returns
    -------
    torch.Tensor of shape [B, N, N, dim] (float32)
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dtype = torch.float32

    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]        # also called H in the paper

    # --------------------------------------------------------------------
    # 1. LayerNorm + linear projections (PyTorch, FP32)
    # --------------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        normalized_shape=(dim,),
        weight=weights["norm.weight"].to(dtype),
        bias=weights["norm.bias"].to(dtype),
    )

    left = F.linear(x, weights["left_proj.weight"].to(dtype))   # (B,N,N,H)
    right = F.linear(x, weights["right_proj.weight"].to(dtype))

    # --------------------------------------------------------------------
    # 2. Optional mask (broadcast over hidden dimension)
    # --------------------------------------------------------------------
    if mask is not None:
        mask_ = mask.unsqueeze(-1)          # (B,N,N,1)
        left = left * mask_
        right = right * mask_

    # --------------------------------------------------------------------
    # 3. Gating (sigmoid)
    # --------------------------------------------------------------------
    left_gate = torch.sigmoid(F.linear(x, weights["left_gate.weight"].to(dtype)))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"].to(dtype)))
    out_gate = torch.sigmoid(F.linear(x, weights["out_gate.weight"].to(dtype)))

    left = left * left_gate
    right = right * right_gate

    # --------------------------------------------------------------------
    # 4. Prepare tensors for the Triton GEMM
    #    (B,N,N,H) -> (B, H, N, N) -> (BH, N, N)   , cast to FP16
    # --------------------------------------------------------------------
    left = left.permute(0, 3, 1, 2).contiguous()   # (B, H, N, N)
    right = right.permute(0, 3, 1, 2).contiguous()

    left_fp16 = left.view(B * hidden_dim, N, N).to(torch.float16)
    right_fp16 = right.view(B * hidden_dim, N, N).to(torch.float16)

    out_fp16 = torch.empty_like(left_fp16)        # (BH, N, N), FP16

    # --------------------------------------------------------------------
    # 5. Launch Triton kernel
    # --------------------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    BH = B * hidden_dim
    grid_m = triton.cdiv(N, BLOCK_M)
    grid_n = triton.cdiv(N, BLOCK_N)
    total_tiles = BH * grid_m * grid_n
    grid = (total_tiles,)

    _trimul_batched_gemm_kernel[grid](
        left_fp16,
        right_fp16,
        out_fp16,
        BH,
        N,
        # strides for left   (BH, N, N)
        left_fp16.stride(0),
        left_fp16.stride(1),
        left_fp16.stride(2),
        # strides for right  (BH, N, N)
        right_fp16.stride(0),
        right_fp16.stride(1),
        right_fp16.stride(2),
        # strides for out    (BH, N, N)
        out_fp16.stride(0),
        out_fp16.stride(1),
        out_fp16.stride(2),
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # --------------------------------------------------------------------
    # 6. Convert back to (B, N, N, H) FP32 and finish with PyTorch ops
    # --------------------------------------------------------------------
    out = out_fp16.view(B, hidden_dim, N, N).permute(0, 2, 3, 1).contiguous()  # (B,N,N,H)
    out = out.to(dtype)                                                        # FP32 for norm

    # to_out_norm
    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"].to(dtype),
        bias=weights["to_out_norm.bias"].to(dtype),
    )

    # output gate (broadcast over N,N)
    out = out * out_gate

    # final linear back to original dim
    out = F.linear(out, weights["to_out.weight"].to(dtype))

    return out
```

**Key points**

* The kernel processes the cubic contraction in a single launch, dramatically
  reducing runtime compared with the naïve Python loops.
* FP16 + FP32 accumulation exploits Tensor‑Core performance on the H200 while
  preserving numerical quality.
* All other operations remain in PyTorch, keeping the implementation simple and
  ensuring correctness across the various test configurations.
