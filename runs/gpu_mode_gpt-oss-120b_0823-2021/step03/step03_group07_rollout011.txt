We implement the *outgoing* TriMul operation – the only cubic‑cost part is  

\[
\text{out}[b,h,i,j] = \sum_{k=0}^{N-1}
        \text{left}[b,h,i,k]\;\times\;
        \text{right}[b,h,j,k] .
\]

All cheap operations (LayerNorm, linear projections, gating, the final
LayerNorm + linear) are kept in PyTorch because they are memory‑bound and
already highly optimised.  
The cubic contraction is performed by a **batched GEMM** written in Triton.
The kernel works on **FP16** data (tensor‑cores) and accumulates in **FP32**
to keep numerical stability.  

Key points

* **Blocking** – a 2‑D tile (`BLOCK_M × BLOCK_N`) is computed per program
  id, iterating over `k` in `BLOCK_K`‑wide chunks.
* **Transpose on‑the‑fly** – `right` is read with the last two dimensions
  swapped so that a single `tl.dot` computes the inner product.
* **Mask handling** – the optional pair‑wise mask is already applied before
  the kernel, therefore the kernel does not need to deal with it.
* **Strides** – we pass the full 4‑D strides from the host; the kernel
  decodes them exactly, avoiding the common pitfall of assuming a fixed
  rank.
* **Launch grid** – one program id per `(batch, head, tile_m, tile_n)`.

The host‑side wrapper (`custom_kernel`) follows these steps:

1. **LayerNorm** over the last dimension (`dim`).
2. **Linear projections** (`left`, `right` → hidden_dim) and **gating**.
3. **Optional mask** (broadcasted on the hidden dimension).
4. **Permute** tensors to `[B, H, N, N]` and cast to `float16`.
5. **Launch** the Triton kernel.
6. **Permute back** to `[B, N, N, H]`, **LayerNorm**, **output‑gate**, and
   final **linear** back to `dim`.
7. Return the result in **float32**.

The implementation respects all constraints, runs on Hopper (sm\_90) and
uses only a single custom Triton kernel, satisfying the “at least part in
Triton” rule.

```python
"""
custom_kernel – outgoing TriMul (AlphaFold‑3) forward pass
========================================================

* cheap ops (LayerNorm, Linear, gating, final LayerNorm & Linear) – PyTorch
* cubic contraction               – Triton batched GEMM:
        out[b,h,i,j] = Σ_k left[b,h,i,k] * right[b,h,j,k]
  (left/right are 4‑D tensors [B, H, N, N] in fp16, accumulation in fp32)

The kernel tiles the (i,j) plane (BLOCK_M × BLOCK_N) and iterates over k
in BLOCK_K steps, loading `right` transposed so that a single `tl.dot`
computes the inner product.
"""
import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict, Any


# ----------------------------------------------------------------------
# Triton kernel – batched GEMM for the TriMul contraction
# ----------------------------------------------------------------------
@triton.jit
def _trimul_kernel(
    left_ptr,          # const fp16*  [B, H, N, N]
    right_ptr,         # const fp16*  [B, H, N, N] (read transposed)
    out_ptr,           #       fp16*  [B, H, N, N]
    B, N, H,           # int metadata
    # strides (row‑major) for the three tensors
    stride_lb, stride_lh, stride_ln, stride_lk,   # left
    stride_rb, stride_rh, stride_rn, stride_rk,   # right
    stride_ob, stride_oh, stride_on, stride_ok,   # out
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Compute a (BLOCK_M × BLOCK_N) tile of:
        out[b, h, i, j] = Σ_k left[b, h, i, k] * right[b, h, j, k]
    One program id corresponds to (b, h, tile_m, tile_n).
    """
    pid = tl.program_id(0)

    # ------------------------------------------------------------------
    # Decode program id -> (b, h, tile_m, tile_n)
    # ------------------------------------------------------------------
    num_m = tl.cdiv(N, BLOCK_M)
    num_n = tl.cdiv(N, BLOCK_N)

    tile_n = pid % num_n
    pid //= num_n
    tile_m = pid % num_m
    pid //= num_m
    h = pid % H
    b = pid // H

    # ------------------------------------------------------------------
    # Tile offsets and masks
    # ------------------------------------------------------------------
    offs_m = tile_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = tile_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < N
    mask_n = offs_n < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ------------------------------------------------------------------
    # Main K‑loop
    # ------------------------------------------------------------------
    for kk in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = kk * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # left[b, h, i, k]  shape (M, K)
        l_ptr = (left_ptr +
                 b * stride_lb +
                 h * stride_lh +
                 offs_m[:, None] * stride_ln +
                 offs_k[None, :] * stride_lk)
        l = tl.load(l_ptr,
                    mask=mask_m[:, None] & mask_k[None, :],
                    other=0.0).to(tl.float32)

        # right[b, h, j, k]   we need it transposed -> (k, j)
        # original layout: (b, h, j, k)
        # after transpose: (b, h, k, j)
        r_ptr = (right_ptr +
                 b * stride_rb +
                 h * stride_rh +
                 offs_k[:, None] * stride_rk +   # k as row
                 offs_n[None, :] * stride_rn)    # j as col
        r_t = tl.load(r_ptr,
                      mask=mask_k[:, None] & mask_n[None, :],
                      other=0.0).to(tl.float32)

        # (M,K) @ (K,N) -> (M,N)
        acc += tl.dot(l, r_t)

    # ------------------------------------------------------------------
    # Write back the tile
    # ------------------------------------------------------------------
    out_ptrs = (out_ptr +
                b * stride_ob +
                h * stride_oh +
                offs_m[:, None] * stride_on +
                offs_n[None, :] * stride_ok)

    tl.store(out_ptrs,
             acc.to(tl.float16),
             mask=mask_m[:, None] & mask_n[None, :])


# ----------------------------------------------------------------------
# Host‑side wrapper exposing the required signature
# ----------------------------------------------------------------------
def custom_kernel(
    data: Tuple[
        torch.Tensor,                     # input  [B, N, N, dim]
        torch.Tensor,                     # mask   [B, N, N]  (or None)
        Dict[str, torch.Tensor],          # weights
        Dict[str, Any]                    # config
    ]
) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.
    Returns a tensor of shape [B, N, N, dim] (float32).
    """
    # ------------------------------------------------------------------
    # unpack arguments
    # ------------------------------------------------------------------
    x, mask, weights, config = data
    device = x.device
    B, N, _, dim = x.shape
    hidden_dim = config["hidden_dim"]          # H

    # ------------------------------------------------------------------
    # 1️⃣ Cheap ops in PyTorch
    # ------------------------------------------------------------------
    # LayerNorm over the last dimension (dim)
    x = F.layer_norm(
        x,
        normalized_shape=(dim,),
        weight=weights["norm.weight"].to(x.dtype),
        bias=weights["norm.bias"].to(x.dtype),
    )

    # Linear projections (bias=False)
    left = F.linear(x, weights["left_proj.weight"].to(x.dtype))   # (B,N,N,H)
    right = F.linear(x, weights["right_proj.weight"].to(x.dtype))

    # optional pair‑wise mask
    if mask is not None:
        mask_ = mask.unsqueeze(-1)          # (B,N,N,1)
        left = left * mask_
        right = right * mask_

    # gates (sigmoid after linear)
    left_gate = torch.sigmoid(F.linear(x, weights["left_gate.weight"].to(x.dtype)))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"].to(x.dtype)))
    out_gate = torch.sigmoid(F.linear(x, weights["out_gate.weight"].to(x.dtype)))

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 2️⃣ Rearrange to [B, H, N, N] and cast to fp16 for the kernel
    # ------------------------------------------------------------------
    left = left.permute(0, 3, 1, 2).contiguous()   # (B,H,N,N)
    right = right.permute(0, 3, 1, 2).contiguous()

    left_fp16 = left.to(torch.float16)
    right_fp16 = right.to(torch.float16)

    out_fp16 = torch.empty_like(left_fp16)        # (B,H,N,N) fp16

    # ------------------------------------------------------------------
    # 3️⃣ Triton kernel launch – blocked GEMM
    # ------------------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid_m = triton.cdiv(N, BLOCK_M)
    grid_n = triton.cdiv(N, BLOCK_N)
    # total programs = B * H * grid_m * grid_n
    grid = (B * hidden_dim * grid_m * grid_n,)

    _trimul_kernel[grid](
        left_fp16,
        right_fp16,
        out_fp16,
        B,
        N,
        hidden_dim,
        # strides for left
        left_fp16.stride(0),   # B
        left_fp16.stride(1),   # H
        left_fp16.stride(2),   # N (i)
        left_fp16.stride(3),   # N (k)
        # strides for right
        right_fp16.stride(0),
        right_fp16.stride(1),
        right_fp16.stride(2),
        right_fp16.stride(3),
        # strides for out
        out_fp16.stride(0),
        out_fp16.stride(1),
        out_fp16.stride(2),
        out_fp16.stride(3),
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # ------------------------------------------------------------------
    # 4️⃣ Post‑process in PyTorch
    # ------------------------------------------------------------------
    # back to layout (B,N,N,H) and to float32
    out = out_fp16.to(x.dtype).permute(0, 2, 3, 1).contiguous()   # (B,N,N,H)

    # to_out_norm over hidden_dim
    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"].to(x.dtype),
        bias=weights["to_out_norm.bias"].to(x.dtype),
    )

    # apply output gate (broadcast over pairwise axes)
    out = out * out_gate

    # final linear back to original dim
    out = F.linear(out, weights["to_out.weight"].to(x.dtype))

    return out
```
