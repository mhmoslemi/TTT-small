```python
"""
TriMul outgoing operator (AlphaFold‑3).

The heavy O(N³) contraction
    out[b,i,j] = Σ_k left[b,i,k] * right[b,j,k]
is carried out as a batched GEMM with a custom Triton kernel.
All cheap operations (LayerNorm, linear projections, gating, final
LayerNorm/Linear) stay in PyTorch – they are memory‑bound and far
cheaper than the cubic work.  

The kernel works in FP16 with FP32 accumulation (Tensor‑Core‑friendly)
and writes the result back as FP16; the wrapper casts to FP32 for the
remaining PyTorch layers.

The launch grid is (BH, tiles_M, tiles_N) flattened to a 1‑D grid:
    BH = batch * hidden_dim   (one “head” per hidden channel)
    tiles_M = ceil(N / BLOCK_M)
    tiles_N = ceil(N / BLOCK_N)

Each program instance computes a tile (BLOCK_M×BLOCK_N) of the
matrix product
    out[bh,i,j] = Σ_k left[bh,i,k] * right[bh,j,k]   (right read transposed)

The kernel is deliberately simple – it loads a block of the left
matrix, a transposed block of the right matrix, performs a dot product,
and accumulates in FP32.  No shared memory is used; Triton’s
`tl.dot` already performs the inner‑product efficiently on Hopper’s
Tensor‑Cores.
"""
import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict, Any


# -------------------------------------------------------------------------
#  Triton kernel: batched GEMM for a single (batch * hidden) slice
# -------------------------------------------------------------------------
@triton.jit
def trimul_outgoing_gemm_kernel(
    left_ptr,          # const fp16*  [BH, N, N]   (row‑major)
    right_ptr,         # const fp16*  [BH, N, N]   (row‑major, read transposed)
    out_ptr,           #       fp16*  [BH, N, N]   (row‑major)
    BH, N,             # problem sizes
    stride_lbh, stride_lbn, stride_lbk,   # left strides
    stride_rbh, stride_rbn, stride_rbk,   # right strides
    stride_obh, stride_obn, stride_obk,   # out strides
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Compute a tile (BLOCK_M × BLOCK_N) of
        out[bh,i,j] = Σ_k left[bh,i,k] * right[bh,j,k]
    for a given batch‑head index ``bh`` (bh = b*hidden + h).

    left  : (BH, N, N)   – accessed as  (bh, i, k)
    right : (BH, N, N)   – accessed as  (bh, j, k) → we read it as (k, j)
    out   : (BH, N, N)   – written as (bh, i, j)
    """
    pid = tl.program_id(0)                      # linear id over (bh, tile_m, tile_n)

    # -----------------------------------------------------------------
    # Decode program id → (bh, tile_m, tile_n)
    # -----------------------------------------------------------------
    num_tiles_m = tl.cdiv(N, BLOCK_M)
    num_tiles_n = tl.cdiv(N, BLOCK_N)

    tile_n = pid % num_tiles_n
    pid //= num_tiles_n
    tile_m = pid % num_tiles_m
    pid //= num_tiles_m
    bh = pid                                    # 0 ≤ bh < BH

    # -----------------------------------------------------------------
    # Offsets for this tile
    # -----------------------------------------------------------------
    offs_m = tile_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = tile_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < N
    mask_n = offs_n < N

    # FP32 accumulator (accumulation in higher precision)
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # -----------------------------------------------------------------
    # Loop over K dimension in BLOCK_K chunks
    # -----------------------------------------------------------------
    for kk in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = kk * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # left[bh, i, k]   shape (M, K)
        l_ptr = left_ptr + bh * stride_lbh \
                + offs_m[:, None] * stride_lbn \
                + offs_k[None, :] * stride_lbk
        l = tl.load(l_ptr,
                    mask=mask_m[:, None] & mask_k[None, :],
                    other=0.0).to(tl.float32)

        # right[bh, j, k] is read as (k, j) because we need right[bh, j, k]
        r_ptr = right_ptr + bh * stride_rbh \
                + offs_k[:, None] * stride_rbk \
                + offs_n[None, :] * stride_rbn
        r = tl.load(r_ptr,
                    mask=mask_k[:, None] & mask_n[None, :],
                    other=0.0).to(tl.float32)

        # GEMM: (M,K) @ (K,N) → (M,N)
        acc += tl.dot(l, r)

    # -----------------------------------------------------------------
    # Write result back as fp16
    # -----------------------------------------------------------------
    out_ptrs = out_ptr + bh * stride_obh \
               + offs_m[:, None] * stride_obn \
               + offs_n[None, :] * stride_obk
    tl.store(out_ptrs,
             acc.to(tl.float16),
             mask=mask_m[:, None] & mask_n[None, :])


# -------------------------------------------------------------------------
#  Host‑side entry point
# -------------------------------------------------------------------------
def custom_kernel(
    data: Tuple[
        torch.Tensor,                # input  : [B, N, N, dim]   (float32)
        torch.Tensor,                # mask   : [B, N, N]  (bool/float)   or None
        Dict[str, torch.Tensor],     # weights: model parameters (fp32)
        Dict[str, Any],              # config : {"dim":…, "hidden_dim":…}
    ]
) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.
    Returns a tensor of shape [B, N, N, dim] (float32).
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dtype = torch.float32

    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]          # = H

    # -----------------------------------------------------------------
    # 1️⃣ LayerNorm + linear projections (cheap, stay in PyTorch)
    # -----------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        normalized_shape=(dim,),
        weight=weights["norm.weight"].to(dtype),
        bias=weights["norm.bias"].to(dtype),
    )

    left  = F.linear(x, weights["left_proj.weight"].to(dtype))   # (B,N,N,H)
    right = F.linear(x, weights["right_proj.weight"].to(dtype))

    # -----------------------------------------------------------------
    # 2️⃣ Optional mask (broadcast over hidden dim)
    # -----------------------------------------------------------------
    if mask is not None:
        mask_ = mask.unsqueeze(-1)          # (B,N,N,1)
        left  = left * mask_
        right = right * mask_

    # -----------------------------------------------------------------
    # 3️⃣ Gating (sigmoid)
    # -----------------------------------------------------------------
    left_gate  = torch.sigmoid(F.linear(x, weights["left_gate.weight"].to(dtype)))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"].to(dtype)))
    out_gate   = torch.sigmoid(F.linear(x, weights["out_gate.weight"].to(dtype)))

    left  = left  * left_gate
    right = right * right_gate

    # -----------------------------------------------------------------
    # 4️⃣ Rearrange to [BH, N, N] (BH = B * hidden_dim) and cast to fp16
    # -----------------------------------------------------------------
    # (B,N,N,H) → (B,H,N,N) → (BH,N,N)
    left = left.permute(0, 3, 1, 2).contiguous()
    right = right.permute(0, 3, 1, 2).contiguous()

    left_fp16  = left.view(B * hidden_dim, N, N).to(torch.float16)
    right_fp16 = right.view(B * hidden_dim, N, N).to(torch.float16)

    out_fp16 = torch.empty_like(left_fp16)      # (BH, N, N), fp16

    # -----------------------------------------------------------------
    # 5️⃣ Triton kernel launch
    # -----------------------------------------------------------------
    # Tile sizes – chosen to keep shared‑memory low and fit Hopper's
    # Tensor‑Core pipeline.  64×64×32 works well for N up to 1024.
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    BH = B * hidden_dim
    grid_m = triton.cdiv(N, BLOCK_M)
    grid_n = triton.cdiv(N, BLOCK_N)
    total_tiles = BH * grid_m * grid_n
    grid = (total_tiles,)

    trimul_outgoing_gemm_kernel[grid](
        left_fp16,
        right_fp16,
        out_fp16,
        BH,
        N,
        # strides for left   (BH, N, N)
        left_fp16.stride(0),
        left_fp16.stride(1),
        left_fp16.stride(2),
        # strides for right  (BH, N, N)
        right_fp16.stride(0),
        right_fp16.stride(1),
        right_fp16.stride(2),
        # strides for out    (BH, N, N)
        out_fp16.stride(0),
        out_fp16.stride(1),
        out_fp16.stride(2),
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # -----------------------------------------------------------------
    # 6️⃣ Restore original layout and continue with PyTorch ops
    # -----------------------------------------------------------------
    # (BH,N,N) → (B, H, N, N) → (B, N, N, H)
    out = out_fp16.view(B, hidden_dim, N, N).permute(0, 2, 3, 1).contiguous()
    out = out.to(dtype)                                 # FP32 for following layers

    # to_out_norm
    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"].to(dtype),
        bias=weights["to_out_norm.bias"].to(dtype),
    )

    # output gate (broadcast over N,N)
    out = out * out_gate

    # final linear back to original dim
    out = F.linear(out, weights["to_out.weight"].to(dtype))

    return out
```

### How the design follows the “lessons”

| Lesson | Application |
|-------|--------------|
| **1️⃣ Limit shared memory** | The kernel uses only registers + `tl.dot`; no explicit shared memory, keeping usage far below the limit. |
| **2️⃣ Delegate N³ to batched GEMM** | The cubic contraction is exactly the batched GEMM performed inside the Triton kernel – a hand‑written version of `bmm`. |
| **3️⃣ Match dtypes** | All operands of the GEMM are cast to `float16`; accumulation is done in `float32` (Tensor‑Core‑friendly). |
| **4️⃣ Keep cheap ops in PyTorch** | LayerNorm, Linear projections, gating, and the final LayerNorm/Linear remain in PyTorch (memory‑bound, negligible compared to the GEMM). |
| **Stride handling** | Strides are taken directly from the tensors (`tensor.stride(i)`) and passed to the kernel; no assumptions on tensor rank are made. |

The kernel therefore satisfies the requirement of doing **at least part of the work in Triton**, while the rest stays in PyTorch for simplicity and correctness. It works for any batch size `B ∈ {1,2}`, any sequence length `N` listed in the test matrix, and any `dim / hidden_dim` combinations, handling the presence or absence of a mask transparently.
