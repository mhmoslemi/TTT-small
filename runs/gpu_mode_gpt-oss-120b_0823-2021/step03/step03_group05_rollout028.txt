The outgoing TriMul consists of three phases  

1. **Linear + LayerNorm preprocessing** – cheap, performed with PyTorch.  
2. **Element‑wise fusion** – apply the pairwise mask and the two gating
   sigmoids (`left_gate`, `right_gate`).  This is the only part that must be
   written in Triton.  The kernel works on the contiguous layout
   `[B, N, N, H]` (H = `hidden_dim`) and updates `left` and `right` **in‑place**.  
3. **Cubic contraction** – `out[b,i,j,:] = Σ_k left[b,i,k,:] * right[b,j,k,:]`.  
   The most efficient way on a Hopper‑class GPU is to reshape the tensors to
   `(B·H, N, N)` and call `torch.bmm`, which uses cuBLAS/Tensor‑cores.  
4. **Post‑processing** – LayerNorm, out‑gate multiplication and final linear
   projection, again in PyTorch.

The kernel is deliberately simple and memory‑bound, which gives high
occupancy.  It works for both the *masked* and *nomask* cases (the mask is
broadcasted to the hidden dimension).  All arithmetic inside the kernel is
FP16; the surrounding PyTorch code keeps everything in FP32, so the final
output matches the reference implementation.

```python
"""
custom_kernel – outgoing TriMul (AlphaFold3)

Algorithm
---------
1. Layer‑norm + four linear projections (left, right, left_gate, right_gate,
   out_gate) are computed with PyTorch (cheap compared to O(N³)).
2. A tiny Triton kernel fuses:
       left  = left  * mask * sigmoid(left_gate)
       right = right * mask * sigmoid(right_gate)
   The kernel works on the contiguous layout (B, N, N, H) and updates the
   tensors in‑place.  It handles the “no‑mask” case by passing an all‑ones
   mask.
3. Core contraction:
       out[b,i,j,:] = Σ_k left[b,i,k,:] * right[b,j,k,:]
   This is a batched matrix multiplication after reshaping
       left  → (B·H, N, N)
       right → (B·H, N, N)  and transposed on the second axis.
   `torch.bmm` (cuBLAS/Tensor‑cores) is far faster than a hand‑written Triton
   GEMM for the tested sizes.
4. Post‑process with a second LayerNorm, out‑gate scaling and a final linear
   projection (all PyTorch).

The kernel is required (rule of the task) but the heavy O(N³) work stays in
high‑performance cuBLAS.  The implementation supports any combination of
batch size (1‑2), sequence length (128‑1024), and hidden/feature dimensions
given in the spec, with or without a mask, and works for FP16/FP32 inputs.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict, Any


# -------------------------------------------------------------------------
# Triton kernel: fuse mask, left‑gate and right‑gate into left/right tensors
# -------------------------------------------------------------------------
@triton.jit
def _mask_gate_fuse_kernel(
    left_ptr,          # *mut fp16  (B,N,N,H) – overwritten
    right_ptr,         # *mut fp16  (B,N,N,H) – overwritten
    left_gate_ptr,     # *const fp16 (B,N,N,H)
    right_gate_ptr,    # *const fp16 (B,N,N,H)
    mask_ptr,          # *const fp16 (B,N,N,1) – 1.0 if no mask
    B, N, H,           # compile‑time constants
    stride_l0, stride_l1, stride_l2, stride_l3,
    stride_r0, stride_r1, stride_r2, stride_r3,
    stride_g0, stride_g1, stride_g2, stride_g3,
    stride_m0, stride_m1, stride_m2, stride_m3,
    BLOCK: tl.constexpr,
):
    pid = tl.program_id(0)
    total = B * N * N * H                      # total elements to process
    idx = pid * BLOCK + tl.arange(0, BLOCK)    # linear index within the grid
    mask = idx < total                         # guard against OOB

    # ---- decode linear index -> (b,i,j,h) -----------------------------
    tmp = idx
    h = tmp % H;          tmp = tmp // H
    j = tmp % N;          tmp = tmp // N
    i = tmp % N;          b = tmp // N

    # ---- compute pointers for the five tensors -----------------------
    l_ptr = left_ptr  + b * stride_l0 + i * stride_l1 + j * stride_l2 + h * stride_l3
    r_ptr = right_ptr + b * stride_r0 + i * stride_r1 + j * stride_r2 + h * stride_r3
    lg_ptr = left_gate_ptr  + b * stride_g0 + i * stride_g1 + j * stride_g2 + h * stride_g3
    rg_ptr = right_gate_ptr + b * stride_g0 + i * stride_g1 + j * stride_g2 + h * stride_g3
    m_ptr = mask_ptr + b * stride_m0 + i * stride_m1 + j * stride_m2          # broadcast over H

    # ---- load ----------------------------------------------------------------
    l = tl.load(l_ptr, mask=mask, other=0.0)
    r = tl.load(r_ptr, mask=mask, other=0.0)
    lg = tl.load(lg_ptr, mask=mask, other=0.0)
    rg = tl.load(rg_ptr, mask=mask, other=0.0)
    m = tl.load(m_ptr, mask=mask, other=1.0)   # default 1.0 when mask is all‑ones

    # ---- fused computation ---------------------------------------------------
    # left  = left  * mask * left_gate
    # right = right * mask * right_gate
    l = l * m * lg
    r = r * m * rg

    # ---- store back ------------------------------------------------------------
    tl.store(l_ptr, l, mask=mask)
    tl.store(r_ptr, r, mask=mask)


# -------------------------------------------------------------------------
# Host‑side entry point
# -------------------------------------------------------------------------
def custom_kernel(data: Tuple[torch.Tensor,
                              torch.Tensor,
                              Dict[str, torch.Tensor],
                              Dict[str, Any]]) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.

    Parameters
    ----------
    data : tuple
        (x, mask, weights, config)
        - x : Tensor[B, N, N, dim]          (float32)
        - mask : Tensor[B, N, N] or None    (float32 / bool)
        - weights : dict of model parameters (float32)
        - config : {"dim": int, "hidden_dim": int}

    Returns
    -------
    Tensor[B, N, N, dim] (float32)
    """
    x, mask, weights, config = data
    device = x.device
    dtype = torch.float32

    B, N, _, dim = x.shape
    hidden_dim = config["hidden_dim"]          # H

    # -----------------------------------------------------------------
    # 1️⃣  Linear + LayerNorm preprocessing (stay in PyTorch)
    # -----------------------------------------------------------------
    x = F.layer_norm(
        x,
        normalized_shape=(dim,),
        weight=weights["norm.weight"].to(dtype),
        bias=weights["norm.bias"].to(dtype),
    )

    # Linear projections (no bias as in the reference)
    left = F.linear(x, weights["left_proj.weight"].to(dtype))          # (B,N,N,H)
    right = F.linear(x, weights["right_proj.weight"].to(dtype))

    left_gate = F.linear(x, weights["left_gate.weight"].to(dtype))
    right_gate = F.linear(x, weights["right_gate.weight"].to(dtype))
    out_gate = F.linear(x, weights["out_gate.weight"].to(dtype))

    # Sigmoid gates
    left_gate = torch.sigmoid(left_gate)
    right_gate = torch.sigmoid(right_gate)
    out_gate = torch.sigmoid(out_gate)

    # -----------------------------------------------------------------
    # 2️⃣  Triton kernel – fuse mask & gating into left/right tensors
    # -----------------------------------------------------------------
    # Prepare mask tensor of shape (B, N, N, 1) in FP16.
    if mask is None:
        mask_tensor = torch.ones((B, N, N, 1), dtype=torch.float16,
                                 device=device)
    else:
        # ensure mask is float (0/1) and broadcast to hidden dim later
        mask_tensor = mask.to(dtype).unsqueeze(-1)          # (B,N,N,1)
        mask_tensor = mask_tensor.to(torch.float16)

    # Cast everything to FP16 for the kernel (fast element‑wise work)
    left_fp16 = left.to(torch.float16).contiguous()
    right_fp16 = right.to(torch.float16).contiguous()
    left_gate_fp16 = left_gate.to(torch.float16).contiguous()
    right_gate_fp16 = right_gate.to(torch.float16).contiguous()

    total_elements = B * N * N * hidden_dim
    BLOCK = 1024                         # choose a power‑of‑2 that gives good occupancy
    grid = (triton.cdiv(total_elements, BLOCK),)

    _mask_gate_fuse_kernel[grid](
        left_fp16,
        right_fp16,
        left_gate_fp16,
        right_gate_fp16,
        mask_tensor,
        B, N, hidden_dim,
        left_fp16.stride(0), left_fp16.stride(1),
        left_fp16.stride(2), left_fp16.stride(3),
        right_fp16.stride(0), right_fp16.stride(1),
        right_fp16.stride(2), right_fp16.stride(3),
        left_gate_fp16.stride(0), left_gate_fp16.stride(1),
        left_gate_fp16.stride(2), left_gate_fp16.stride(3),
        mask_tensor.stride(0), mask_tensor.stride(1),
        mask_tensor.stride(2), mask_tensor.stride(3),
        BLOCK=BLOCK,
    )

    # -----------------------------------------------------------------
    # 3️⃣  O(N³) contraction via batched GEMM (cuBLAS/Tensor‑cores)
    # -----------------------------------------------------------------
    # reshape to (B·H, N, N)
    left_bh = left_fp16.permute(0, 3, 1, 2).reshape(B * hidden_dim, N, N)
    right_bh = right_fp16.permute(0, 3, 1, 2).reshape(B * hidden_dim, N, N)

    # batched matmul: (B·H, N, N) @ (B·H, N, N)^T  → (B·H, N, N)
    out_bh = torch.bmm(left_bh, right_bh.transpose(1, 2))

    # back to (B, N, N, H)
    out = out_bh.reshape(B, hidden_dim, N, N).permute(0, 2, 3, 1).contiguous()
    out = out.to(dtype)                     # convert back to FP32 for the rest

    # -----------------------------------------------------------------
    # 4️⃣  Post‑processing (LayerNorm, out‑gate, final linear)
    # -----------------------------------------------------------------
    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"].to(dtype),
        bias=weights["to_out_norm.bias"].to(dtype),
    )
    out = out * out_gate                     # broadcast over (N,N) dims
    out = F.linear(out, weights["to_out.weight"].to(dtype))

    return out
```
