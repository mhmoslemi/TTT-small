We implement the *outgoing* TriMul operator (AlphaFold‑3) with a **hybrid** strategy:

1. **Layer‑Norm & linear layers** – performed in PyTorch (FP32 → FP16) because they are cheap
   compared with the cubic contraction and keep the implementation simple.

2. **Mask & gating** – also handled in PyTorch (still FP16).

3. **Core contraction** – the expensive `einsum('... i k d, ... j k d -> ... i j d')`
   is a batched matrix‑multiply over the *k* dimension:

   \[
   out_{b,i,j,d}= \sum_{k} \; left_{b,i,k,d}\; right_{b,j,k,d}
   \]

   When the hidden dimension *d* (= `hidden_dim`) is treated as a **head** dimension,
   the contraction can be expressed as many independent GEMMs:

   * left : \( (B, H, I, K) \)  
   * right: \( (B, H, K, J) \)  

   where `H = hidden_dim`, `I = J = N`, `K = N`.  
   We therefore launch a **triton kernel** that computes a *batched GEMM* for every
   `(batch, head)` pair.  The kernel is a classic tiled fp16 × fp16 → fp32
   accumulation implementation tuned for Hopper (SM‑90) with:

   * `BLOCK_M = BLOCK_N = 64` – tile size in the output `i/j` dimensions.  
   * `BLOCK_K = 32`            – reduction tile size.  
   * `num_warps = 4`           – good occupancy for fp16 on H200.

   The kernel reads tiles of `left` and `right`, performs `tl.dot` (fp16 → fp32
   accumulate) and writes the result back in fp16.  The whole batch‑head
   dimension is collapsed to a single program‑id (`pid_z`).

4. **Post‑processing** – convert the result back to FP32, apply the second
   LayerNorm, the output gate and the final linear projection (all in PyTorch).

The implementation respects all constraints:

* Works for any `B ∈ {1,2}`, `N ∈ {128,…,1024}`, `dim ∈ {128,384}`,
  `hidden_dim ∈ {128,384,768}`.  
* Handles the optional mask (`nomask` flag).  
* No gradients are required – everything is performed in inference mode.  
* At least one non‑trivial operation (the N³ contraction) is executed in a
  custom Triton kernel.  

Below is the complete, self‑contained code.

```python
"""
custom_kernel – outgoing TriMul (AlphaFold‑3)

Algorithm
---------
1.  FP32 LayerNorm on the input tensor.
2.  Cast to fp16 and apply four linear projections (left/right) plus three
    gating linear layers (left_gate, right_gate, out_gate).  All linear ops are
    performed with torch.nn.functional.linear for speed.
3.  Optional pair‑wise mask is multiplied into the left/right tensors.
4.  Apply sigmoid gating.
5.  Core contraction:
        out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
    This is a batched GEMM (I×K)·(K×J) → (I×J) for every (batch, head) pair.
    A Triton kernel tiles the multiplication (BLOCK_M = BLOCK_N = 64,
    BLOCK_K = 32) and accumulates in FP32, writing FP16.
6.  Convert back to FP32, second LayerNorm, multiply by the output‑gate and
    final linear projection to the original dimension.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel – batched GEMM (I×K)·(K×J) → (I×J)
# ----------------------------------------------------------------------
@triton.jit
def _batch_gemm_kernel(
    a_ptr,            # left  tensor (B*H, I, K)  fp16
    b_ptr,            # right tensor (B*H, K, J)  fp16
    c_ptr,            # output    (B*H, I, J)    fp16
    M, N, K,          # extents
    stride_az, stride_am, stride_ak,   # a strides (z,i,k)
    stride_bz, stride_bk, stride_bn,   # b strides (z,k,j)
    stride_cz, stride_cm, stride_cn,   # c strides (z,i,j)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    # program IDs
    pid_z = tl.program_id(2)          # (batch * head)
    pid_m = tl.program_id(0)          # tile row   (i)
    pid_n = tl.program_id(1)          # tile col   (j)

    # tile start offsets
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # loop over K dimension in tiles
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # load A tile  (M×K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # load B tile  (K×N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # fp16·fp16 → fp32 accumulate
        acc += tl.dot(a, b)

    # write result (convert back to fp16)
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[:, None],
    )


def _triton_batched_gemm(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Batched GEMM for the TriMul contraction.

    left  : (B, H, I, K)   fp16, contiguous
    right : (B, H, K, J)   fp16, contiguous
    returns: (B, H, I, J) fp16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # Collapse batch*head dimension – kernel expects 3‑D tensors
    a = left.view(B * H, I, K)
    b = right.view(B * H, K, J)
    c = out.view(B * H, I, J)

    # strides (in elements)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # Tile sizes tuned for Hopper (fp16, 4 warps)
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(I, BLOCK_M),          # tiles along I (i dimension)
        triton.cdiv(J, BLOCK_N),          # tiles along J (j dimension)
        B * H,                            # one program per (batch, head)
    )
    _batch_gemm_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,
    )
    return out


# ----------------------------------------------------------------------
# Entry point – forward pass of outgoing TriMul
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the “outgoing” TriMul operator (no gradients).

    Parameters
    ----------
    data : tuple (input_tensor, mask, weights, config)
        input_tensor : torch.Tensor, shape [B, N, N, dim], dtype float32
        mask         : torch.Tensor (bool/float) or None, shape [B, N, N]
        weights      : dict of parameter tensors (see reference implementation)
        config       : dict with keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor  shape [B, N, N, dim], dtype float32
    """
    # --------------------------------------------------------------
    # 0️⃣ Unpack
    # --------------------------------------------------------------
    inp, mask, weights, cfg = data
    device = inp.device
    B, N, _, dim = inp.shape
    hidden_dim = cfg["hidden_dim"]          # = H

    # --------------------------------------------------------------
    # 1️⃣ First LayerNorm (FP32, manual for speed)
    # --------------------------------------------------------------
    ln_w = weights["norm.weight"]
    ln_b = weights["norm.bias"]
    # mean/var over last dim (dim)
    mean = inp.mean(-1, keepdim=True)
    var = inp.var(-1, unbiased=False, keepdim=True)
    x = (inp - mean) / torch.sqrt(var + 1e-5)
    x = x * ln_w + ln_b                     # still FP32

    # --------------------------------------------------------------
    # 2️⃣ Linear projections & gates – cast to FP16
    # --------------------------------------------------------------
    def to_fp16(t): return t.to(torch.float16)

    # weight matrices are stored as (out_features, in_features) like nn.Linear
    left_proj_w   = to_fp16(weights["left_proj.weight"])
    right_proj_w  = to_fp16(weights["right_proj.weight"])
    left_gate_w   = to_fp16(weights["left_gate.weight"])
    right_gate_w  = to_fp16(weights["right_gate.weight"])
    out_gate_w    = to_fp16(weights["out_gate.weight"])

    x_fp16 = x.to(torch.float16)                       # (B, N, N, dim)

    left  = F.linear(x_fp16, left_proj_w)              # (B, N, N, H)
    right = F.linear(x_fp16, right_proj_w)             # (B, N, N, H)

    # --------------------------------------------------------------
    # 3️⃣ Optional mask (broadcast over hidden dim)
    # --------------------------------------------------------------
    if mask is not None:
        m = mask.to(torch.float16).unsqueeze(-1)       # (B, N, N, 1)
        left = left * m
        right = right * m

    # --------------------------------------------------------------
    # 4️⃣ Gating (sigmoid)
    # --------------------------------------------------------------
    left_gate  = F.linear(x_fp16, left_gate_w).sigmoid()
    right_gate = F.linear(x_fp16, right_gate_w).sigmoid()
    out_gate   = F.linear(x_fp16, out_gate_w).sigmoid()

    left  = left * left_gate
    right = right * right_gate

    # --------------------------------------------------------------
    # 5️⃣ Core contraction via Triton batched GEMM
    # --------------------------------------------------------------
    # reshape to (B, H, I, K) / (B, H, K, J)
    # left  : (B, N, N, H) -> (B, H, N, N)   (i,k)
    # right : (B, N, N, H) -> (B, H, N, N)   need (k,j) = (N,N) with transpose
    left_t  = left.permute(0, 3, 1, 2).contiguous()          # (B, H, I, K)
    right_t = right.permute(0, 3, 2, 1).contiguous()         # (B, H, K, J)

    # batched GEMM in fp16
    out_fp16 = _triton_batched_gemm(left_t, right_t)        # (B, H, I, J)

    # back to (B, N, N, dim) and FP32
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)

    # --------------------------------------------------------------
    # 6️⃣ Second LayerNorm (FP32)
    # --------------------------------------------------------------
    out_ln_w = weights["to_out_norm.weight"]
    out_ln_b = weights["to_out_norm.bias"]
    mean_o = out.mean(-1, keepdim=True)
    var_o = out.var(-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + 1e-5)
    out = out * out_ln_w + out_ln_b

    # --------------------------------------------------------------
    # 7️⃣ Output gate & final projection (FP32)
    # --------------------------------------------------------------
    out = out * out_gate.to(torch.float32)              # broadcast over dim
    out = F.linear(out, weights["to_out.weight"])      # (B,N,N,dim)

    return out
```

**Key Points**

* The heavy `O(N³)` part is executed in the custom Triton kernel, satisfying the
  requirement that *some* work be done on‑device.
* All tensor shapes and strides are handled generically, so any of the test
  configurations listed in the problem statement are supported.
* No gradient bookkeeping is required – everything runs in inference mode.
* The kernel uses fp16 arithmetic with fp32 accumulation, which is optimal for
  Hopper (SM‑90) Tensor‑core performance while preserving numerical quality.
