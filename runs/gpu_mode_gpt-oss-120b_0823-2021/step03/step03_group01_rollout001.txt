The “outgoing’’ TriMul operator consists of three stages that dominate the runtime:

1. **Linear + gating** – cheap element‑wise work, done in PyTorch (FP16 for speed).  
2. **Cubic contraction**  

   \[
   \text{out}_{b,i,j,d}= \sum_{k=0}^{N-1}
        \text{left}_{b,i,k,d}\;\times\;
        \text{right}_{b,j,k,d}
   \]

   This is exactly a **batched matrix multiplication** for every head `d` (the hidden
   dimension).  We implement it with a single Triton kernel that fuses the three
   dimensions `(B, hidden_dim, N, N)` into a 3‑D batched GEMM:
   * `Z = B * hidden_dim` –‑ the batch dimension seen by the kernel.  
   * `left`  → `(Z, I, K)`   (`I = N`, `K = N`)  
   * `right` → `(Z, K, J)`   (`J = N`)  

   The kernel computes `C = A @ B` with **fp16 inputs** and **fp32 accumulation**,
   storing the result back in fp16.  Afterwards we reshape to the original
   `[B,N,N,dim]` layout and finish the remaining LayerNorm / gating / linear
   steps in PyTorch.

3. **Output LayerNorm + final linear** – also kept in PyTorch.

The kernel is deliberately small (no shared‑memory staging, only a single
`tl.dot` per K‑tile) because Hopper’s Tensor‑Core units can already handle a
`64×64×32` tile efficiently.  The chosen tile sizes (`BLOCK_M = BLOCK_N = 64`,
`BLOCK_K = 32`) respect the SM90 shared‑memory budget and give good occupancy.
The implementation follows the “batched GEMM” pattern that worked well in the
previous attempt, but we tighten a few details:

* **Strides are passed exactly as they appear** – we never assume a fixed rank.
* **Mask handling** is performed before the kernel (still in FP16) so the kernel
  sees already‑masked tensors and does not need a branch.
* **All tensors are contiguous** after the required permutations, guaranteeing
  coalesced loads.
* The kernel is launched with three program‑id axes (`pid_m`, `pid_n`, `pid_z`);
  this matches the natural 3‑D launch grid for batched GEMM on Hopper.

The final function `custom_kernel` follows the required signature
`(input_tensor, mask, weights, config)` and returns a `torch.float32` tensor of
shape `[B, N, N, dim]`.

```python
"""
custom_kernel – “outgoing” TriMul forward pass (AlphaFold‑3 style).

The heavy cubic contraction
    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
is executed by a fused batched GEMM Triton kernel (fp16 input, fp32
accumulation).  All other ops (LayerNorm, linear projections, gating,
final LayerNorm + linear) are performed in PyTorch for simplicity.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched GEMM (I×K)·(K×J) → (I×J)
# ----------------------------------------------------------------------
@triton.jit
def _batch_gemm_kernel(
    a_ptr,            # left tensor  (Z, I, K)
    b_ptr,            # right tensor (Z, K, J)
    c_ptr,            # output      (Z, I, J)
    M, N, K,          # matrix extents
    stride_az, stride_am, stride_ak,   # strides for a (z,i,k)
    stride_bz, stride_bk, stride_bn,   # strides for b (z,k,j)
    stride_cz, stride_cm, stride_cn,   # strides for c (z,i,j)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    # --------------------------------------------------------------
    # 1) program ids (row‑tile, col‑tile, batch‑tile)
    # --------------------------------------------------------------
    pid_m = tl.program_id(0)          # tile row
    pid_n = tl.program_id(1)          # tile col
    pid_z = tl.program_id(2)          # batch * head

    # --------------------------------------------------------------
    # 2) tile offsets
    # --------------------------------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in fp32 (more numerically stable)
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # 3) K‑loop
    # --------------------------------------------------------------
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # Load A tile   (BLOCK_M, BLOCK_K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # Load B tile   (BLOCK_K, BLOCK_N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # Accumulate
        acc += tl.dot(a, b)           # fp16·fp16 → fp32

    # --------------------------------------------------------------
    # 4) write result (convert back to fp16)
    # --------------------------------------------------------------
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


def _triton_batch_gemm(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Batched GEMM for tensors of shape (B, H, I, K) and (B, H, K, J).
    All tensors must be fp16, contiguous and on the same CUDA device.

    Returns a fp16 tensor of shape (B, H, I, J).
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2, "inner dimensions must match"

    # output allocation
    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # Collapse leading dimensions for the kernel → Z = B*H
    Z = B * H
    a = left.view(Z, I, K)
    b = right.view(Z, K, J)
    c = out.view(Z, I, J)

    # Strides (in element units, not bytes)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # Tiling – chosen to be friendly to Tensor‑Core on SM90
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(I, BLOCK_M),   # rows
        triton.cdiv(J, BLOCK_N),   # cols
        Z,                         # batch*head
    )
    _batch_gemm_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,               # good default for Hopper
    )
    return out


# ----------------------------------------------------------------------
# Full forward pass (PyTorch + Triton)
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the “outgoing” TriMul operator.

    Parameters
    ----------
    data : (input_tensor, mask, weights, config)
        input_tensor : torch.Tensor [B, N, N, dim] (float32)
        mask         : torch.Tensor [B, N, N] (bool/float) or None
        weights      : dict of parameter tensors (see docstring above)
        config       : dict with keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor [B, N, N, dim] (float32)
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]
    eps = 1e-5

    # --------------------------------------------------------------
    # 1. Input LayerNorm   (float32, keep stable)
    # --------------------------------------------------------------
    norm_w = weights["norm.weight"]
    norm_b = weights["norm.bias"]
    mean = input_tensor.mean(dim=-1, keepdim=True)
    var = input_tensor.var(dim=-1, unbiased=False, keepdim=True)
    x = (input_tensor - mean) / torch.sqrt(var + eps)
    x = x * norm_w + norm_b                     # [B,N,N,dim]  fp32

    # --------------------------------------------------------------
    # 2. Linear projections (+ gating) – we work in fp16 for speed
    # --------------------------------------------------------------
    def _to_fp16(t):
        return t.to(torch.float16, non_blocking=True)

    # weight tensors (already stored as float32 in the dict)
    left_proj_w   = _to_fp16(weights["left_proj.weight"])
    right_proj_w  = _to_fp16(weights["right_proj.weight"])
    left_gate_w   = _to_fp16(weights["left_gate.weight"])
    right_gate_w  = _to_fp16(weights["right_gate.weight"])
    out_gate_w    = _to_fp16(weights["out_gate.weight"])

    # cast normalized input once
    x_fp16 = x.to(torch.float16)

    left  = F.linear(x_fp16, left_proj_w)   # (B,N,N,hidden_dim)
    right = F.linear(x_fp16, right_proj_w)

    # --------------------------------------------------------------
    # 3. Optional mask (broadcast over hidden dim)
    # --------------------------------------------------------------
    if mask is not None:
        mask_fp16 = mask.to(torch.float16).unsqueeze(-1)   # (B,N,N,1)
        left = left * mask_fp16
        right = right * mask_fp16

    # --------------------------------------------------------------
    # 4. Gating (sigmoid) – still fp16
    # --------------------------------------------------------------
    left_gate  = F.linear(x_fp16, left_gate_w).sigmoid()
    right_gate = F.linear(x_fp16, right_gate_w).sigmoid()
    out_gate   = F.linear(x_fp16, out_gate_w).sigmoid()

    left  = left * left_gate
    right = right * right_gate

    # --------------------------------------------------------------
    # 5. Triton batched GEMM: left @ right^T over the K dimension
    #    left  : (B, N, N, hidden) -> (B, H, I, K)
    #    right : (B, N, N, hidden) -> (B, H, K, J)   (note the transpose)
    # --------------------------------------------------------------
    # bring head dimension to second axis
    left_perm  = left.permute(0, 3, 1, 2).contiguous()   # (B, H, I, K)
    right_perm = right.permute(0, 3, 2, 1).contiguous()  # (B, H, K, J)

    out_fp16 = _triton_batch_gemm(left_perm, right_perm)   # (B, H, I, J)

    # back to original layout and to fp32 for the rest of the pipeline
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)  # (B,N,N,dim)

    # --------------------------------------------------------------
    # 6. Output LayerNorm (float32)
    # --------------------------------------------------------------
    mean_o = out.mean(dim=-1, keepdim=True)
    var_o  = out.var(dim=-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + eps)

    to_out_norm_w = weights["to_out_norm.weight"]
    to_out_norm_b = weights["to_out_norm.bias"]
    out = out * to_out_norm_w + to_out_norm_b

    # --------------------------------------------------------------
    # 7. Final gating + projection (float32)
    # --------------------------------------------------------------
    out = out * out_gate.to(torch.float32)          # broadcast over dim
    to_out_w = weights["to_out.weight"]
    out = F.linear(out, to_out_w)                  # (B,N,N,dim)

    return out
```

**Key points**

* The kernel handles the N³ contraction in a single launch, keeping the
  memory traffic minimal (only two reads and one write per tile).
* Using `fp16` for the heavy matrix multiply gives roughly‑2× higher Tensor‑Core
  throughput on Hopper, while `fp32` accumulation preserves numerical quality.
* All LayerNorm and gating steps stay in PyTorch (float32 → float16 conversion
  only when needed) which simplifies the implementation and avoids the need for
  custom reduction kernels.

With the above implementation the operator meets the required correctness for
