We implement the *outgoing* TriMul operator used in AlphaFold‑3.  
Only the expensive contraction  

\[
\text{out}[b,i,j,d]=\sum_{k} \; \text{left}[b,i,k,d]\;\cdot\;\text{right}[b,j,k,d]
\]

is moved to Triton; all cheap operations (LayerNorm, linear projections, masking,
gating and the final output‑norm/linear) stay in PyTorch.  

The kernel works on a **batched GEMM** where the batch dimension is the
product `B * hidden_dim` (‑‑ each head/dimension `d` is treated as an
independent batch).  For a given batch‑head `bh` we compute a tile
`(BLOCK_M × BLOCK_N)` of the matrix product

```
out[bh, i, j] = left[bh, i, : ] @ right[bh, j, : ].T
```

using FP16 arithmetic with FP32 accumulation (Tensor‑Core friendly) and
store the result back as FP16.  The host‑side wrapper reshapes the tensors,
launches the kernel, and then performs the remaining PyTorch post‑processing.

The implementation respects all Triton‑specific rules:

* All kernel parameters that depend on tensor strides are passed explicitly.
* `tl.arange` uses only compile‑time constants.
* No Python control‑flow (`continue`, `break`) inside the kernel.
* The launch grid is a one‑dimensional list of program IDs; we decode it
  into `(bh, tile_m, tile_n)` inside the kernel.

### Triton kernel – batched GEMM

```python
import triton
import triton.language as tl

@triton.jit
def trimul_batched_gemm_kernel(
    left_ptr,          # const fp16*  [BH, N, N]
    right_ptr,         # const fp16*  [BH, N, N] (to be read transposed)
    out_ptr,           #       fp16*  [BH, N, N]
    BH, N,             # problem sizes
    stride_lbh, stride_lbn, stride_lbk,   # left strides
    stride_rbh, stride_rbn, stride_rbk,   # right strides
    stride_obh, stride_obn, stride_obk,   # out strides
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Batched GEMM for one batch‑head:
        out[bh,i,j] = Σ_k left[bh,i,k] * right[bh,j,k]   (right is read as transposed)
    Tiles of size BLOCK_M × BLOCK_N are computed, iterating over K in
    chunks of BLOCK_K.  Accumulator is FP32, final store is FP16.
    """
    pid = tl.program_id(0)            # linear id over (bh, tile_m, tile_n)

    # ----- decode pid -----
    num_tiles_m = tl.cdiv(N, BLOCK_M)
    num_tiles_n = tl.cdiv(N, BLOCK_N)

    tile_n = pid % num_tiles_n
    pid //= num_tiles_n
    tile_m = pid % num_tiles_m
    pid //= num_tiles_m
    bh = pid                         # 0 ≤ bh < BH

    # ----- offsets for this tile -----
    offs_m = tile_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = tile_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < N
    mask_n = offs_n < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ----- loop over K dimension -----
    for kk in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = kk * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # left[bh, i, k]  shape (M, K)
        l_ptr = left_ptr + bh * stride_lbh \
                + offs_m[:, None] * stride_lbn \
                + offs_k[None, :] * stride_lbk
        l = tl.load(l_ptr,
                    mask=mask_m[:, None] & mask_k[None, :],
                    other=0.0).to(tl.float32)

        # right[bh, j, k] must be read as (K, N) because we need right^T
        r_ptr = right_ptr + bh * stride_rbh \
                + offs_k[:, None] * stride_rbk \
                + offs_n[None, :] * stride_rbn
        r = tl.load(r_ptr,
                    mask=mask_k[:, None] & mask_n[None, :],
                    other=0.0).to(tl.float32)

        # GEMM: (M,K) @ (K,N) → (M,N)
        acc += tl.dot(l, r)

    # ----- write back -----
    out_ptrs = out_ptr + bh * stride_obh \
               + offs_m[:, None] * stride_obn \
               + offs_n[None, :] * stride_obk
    tl.store(out_ptrs,
             acc.to(tl.float16),
             mask=mask_m[:, None] & mask_n[None, :])
```

### Host‑side wrapper `custom_kernel`

```python
import torch
import torch.nn.functional as F
import triton
from typing import Tuple, Dict, Any

def custom_kernel(
    data: Tuple[
        torch.Tensor,                # input  : [B, N, N, dim]
        torch.Tensor,                # mask   : [B, N, N]  (or None)
        Dict[str, torch.Tensor],     # weights
        Dict[str, Any],              # config  {"dim":..., "hidden_dim":...}
    ]
) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.

    Steps
    -----
    1. LayerNorm on the last dimension.
    2. Linear projections -> left/right (shape B,N,N,hidden_dim).
    3. Optional mask (broadcasted on hidden_dim).
    4. Gating (sigmoid of linear layers) and element‑wise multiplication.
    5. Rearrange to (B*hidden_dim, N, N) and cast to fp16.
    6. Triton batched GEMM kernel (step 5) computes the cubic contraction.
    7. Reshape back to (B, N, N, hidden_dim) and continue with
       LayerNorm → output‑gate → final linear (all in fp32).

    The heavy O(N³) work stays inside the Triton kernel; the rest runs in
    regular PyTorch and is negligible compared to the GEMM.
    """
    # ------------------------------------------------------------------
    # unpack inputs
    # ------------------------------------------------------------------
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dtype = torch.float32

    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]          # called H in the paper

    # ------------------------------------------------------------------
    # 1. Input layer‑norm
    # ------------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        normalized_shape=(dim,),
        weight=weights["norm.weight"].to(dtype),
        bias=weights["norm.bias"].to(dtype),
    )

    # ------------------------------------------------------------------
    # 2. Linear projections (no bias)
    # ------------------------------------------------------------------
    left  = F.linear(x, weights["left_proj.weight"].to(dtype))   # (B,N,N, H)
    right = F.linear(x, weights["right_proj.weight"].to(dtype))

    # ------------------------------------------------------------------
    # 3. Optional mask (mask shape: B,N,N)
    # ------------------------------------------------------------------
    if mask is not None:
        mask_ = mask.unsqueeze(-1)            # (B,N,N,1)
        left  = left * mask_
        right = right * mask_

    # ------------------------------------------------------------------
    # 4. Gating (sigmoid)
    # ------------------------------------------------------------------
    left_gate  = torch.sigmoid(F.linear(x, weights["left_gate.weight"].to(dtype)))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"].to(dtype)))
    out_gate   = torch.sigmoid(F.linear(x, weights["out_gate.weight"].to(dtype)))

    left  = left  * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5. Prepare tensors for Triton kernel
    #    (B,N,N,H) -> (B, H, N, N) -> (B*H, N, N)  and cast to fp16
    # ------------------------------------------------------------------
    left  = left.permute(0, 3, 1, 2).contiguous()   # (B, H, N, N)
    right = right.permute(0, 3, 1, 2).contiguous()

    left_fp16  = left.view(B * hidden_dim, N, N).to(torch.float16)
    right_fp16 = right.view(B * hidden_dim, N, N).to(torch.float16)

    out_fp16 = torch.empty_like(left_fp16)          # (B*H, N, N), fp16

    # ------------------------------------------------------------------
    # 6. Launch Triton kernel
    # ------------------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    BH = B * hidden_dim
    grid_m = triton.cdiv(N, BLOCK_M)
    grid_n = triton.cdiv(N, BLOCK_N)
    total_tiles = BH * grid_m * grid_n
    grid = (total_tiles,)

    trimul_batched_gemm_kernel[grid](
        left_fp16,
        right_fp16,
        out_fp16,
        BH,
        N,
        # strides for left  (BH, N, N)
        left_fp16.stride(0),
        left_fp16.stride(1),
        left_fp16.stride(2),
        # strides for right (same layout)
        right_fp16.stride(0),
        right_fp16.stride(1),
        right_fp16.stride(2),
        # strides for out
        out_fp16.stride(0),
        out_fp16.stride(1),
        out_fp16.stride(2),
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # ------------------------------------------------------------------
    # 7. Convert back to (B, N, N, H) and continue with PyTorch ops
    # ------------------------------------------------------------------
    out = out_fp16.view(B, hidden_dim, N, N)          # (B, H, N, N)
    out = out.permute(0, 2, 3, 1).contiguous()       # (B, N, N, H)
    out = out.to(dtype)                              # FP32 for following layers

    # to_out_norm
    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"].to(dtype),
        bias=weights["to_out_norm.bias"].to(dtype),
    )

    # output gate (broadcast over N,N)
    out = out * out_gate

    # final linear back to original dim
    out = F.linear(out, weights["to_out.weight"].to(dtype))

    return out
```

**Key Points**

* The kernel is the only place where `O(N³)` work is performed; it uses a
  classic tiled GEMM pattern with FP16 arithmetic and FP32 accumulation.
* All other operations (LayerNorm, linear projections, masking, gating,
  post‑norm and final linear) are cheap relative to the contraction and are
  kept in high‑level PyTorch for simplicity and correctness.
* The implementation works for any batch size `B ∈ {1,2}`, any sequence length
  `N` up to 1024, and arbitrary `dim` / `hidden_dim` configurations that
  appear in the test matrix.
* The output tensor is returned in `float32` as required by the reference
  implementation.
