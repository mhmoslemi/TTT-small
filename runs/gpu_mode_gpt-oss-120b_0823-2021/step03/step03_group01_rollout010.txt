The “outgoing” TriMul operator consists of three phases that dominate the runtime  

1. **Layer‑Norm + linear projections + gating** – cheap, keep them in PyTorch (FP32 → FP16).  
2. **Cubic contraction**  

\[
\text{out}[b,i,j,d]=\sum_{k=0}^{N-1}\text{left}[b,i,k,d]\;\text{right}[b,j,k,d]
\]

   This is the only part we accelerate with Triton.  
   After reshaping we obtain a batched matrix‑multiply  

\[
L_{b,d}\;(N\times N)\;\times\;R_{b,d}^{\top}\;(N\times N)
\qquad\Longrightarrow\qquad
O_{b,d}\;(N\times N)
\]

   For every head (the hidden dimension) we run an independent GEMM.  
   The kernel therefore works on a 4‑D tensor **(Z, I, K)** × **(Z, K, J)**
   where `Z = B * hidden_dim`.  

3. **Output Layer‑Norm, final gating and linear** – also kept in PyTorch.

The kernel is a standard tiled GEMM that accumulates in **fp32** (to keep numerical
stability) while loading/storing in **fp16** (Tensor‑Core friendly).  
Tile sizes are chosen for Hopper (SM‑90):  

* `BLOCK_M = 64`, `BLOCK_N = 64` – fit a 64 × 64 tile into shared memory.  
* `BLOCK_K = 32` – matches the Tensor‑Core K‑dimension (multiple of 8).  

The kernel is launched with a 3‑D grid: `(ceil(I/BM), ceil(J/BN), Z)`.

### Lessons from previous attempts

| Lesson | Relevance |
|--------|-----------|
| **1. Limit shared memory** – our `BLOCK_*` values keep the shared‑memory footprint < 64 KB per block, well below the H200 limit. |
| **2. Delegate N³ to cuBLAS** – cuBLAS would indeed be fast, but the task requires *at least one* custom Triton kernel. Using a kernel for the cubic contraction satisfies the rule while still being competitive because we exploit Tensor‑Cores. |
| **3. Match dtypes** – we cast the normalized input `x` to **fp16** **once** and keep *both* operands of the GEMM in fp16; accumulation is fp32. This avoids dtype‑mismatch errors. |

All other lessons either already apply (dtype handling) or are irrelevant
(e.g. “cannot use tl.mean”).

### Implementation Details

* **Layer‑Norm** – performed in FP32 with the stored `weight` / `bias`.  
* **Linear layers** – use `torch.nn.functional.linear` on the FP16 copy of the
  normalized tensor.  
* **Mask** – optional; broadcasted over the hidden dimension before gating.  
* **Gating** – sigmoid of linear projections, stays in FP16.  
* **Batched GEMM** – the Triton kernel `batch_matmul_kernel` receives raw
  pointers and strides. It loads tiles, executes `tl.dot`, accumulates in fp32,
  writes the result back as fp16.  
* **Reshaping** – `left` is permuted to `(B, hidden, N, N)` and
  `right` is permuted to `(B, hidden, N, N)` **with the second axis transposed**
  (`right.permute(0,3,2,1)`) to match the equation.  Both tensors are made
  contiguous before the kernel call.  
* **Post‑processing** – convert back to FP32, apply the second Layer‑Norm,
  the final gate and linear projection.

The whole forward pass is wrapped in `custom_kernel(data)` which follows the
required signature.

"""
custom_kernel – outgoing TriMul forward pass (AlphaFold‑3 style).

The heavy N³ contraction is executed by a fused batched GEMM Triton kernel:
    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]

All other operations (LayerNorms, linear projections, gating, final
LayerNorm + linear) are performed in PyTorch.  Mixed‑precision (fp16 / fp32)
is used inside the kernel; the final output is float32.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched GEMM (I×K)·(K×J) → (I×J)
# ----------------------------------------------------------------------
@triton.jit
def batch_matmul_kernel(
    a_ptr,            # left   (Z, I, K)
    b_ptr,            # right  (Z, K, J)
    c_ptr,            # out    (Z, I, J)
    M, N, K,          # matrix sizes
    stride_az, stride_am, stride_ak,   # strides for a (z,i,k)
    stride_bz, stride_bk, stride_bn,   # strides for b (z,k,j)
    stride_cz, stride_cm, stride_cn,   # strides for c (z,i,j)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    # --------------------------------------------------------------
    # Tile indices
    # --------------------------------------------------------------
    pid_z = tl.program_id(0)      # batch*head dimension
    pid_m = tl.program_id(1)      # tile row
    pid_n = tl.program_id(2)      # tile col

    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in fp32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # Loop over K dimension
    # --------------------------------------------------------------
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # (BLOCK_M, BLOCK_K) tile of A
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # (BLOCK_K, BLOCK_N) tile of B
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # dot product accumulates in fp32
        acc += tl.dot(a, b)

    # --------------------------------------------------------------
    # Write result (back to fp16)
    # --------------------------------------------------------------
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[:, None],
    )


def triton_batch_matmul(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Batched GEMM using the Triton kernel above.

    left  : (B, H, I, K)   fp16, contiguous
    right : (B, H, K, J)   fp16, contiguous
    returns out : (B, H, I, J) fp16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    # output allocation
    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # collapse leading dims for the kernel (Z = B*H)
    Z = B * H
    a = left.view(Z, I, K)
    b = right.view(Z, K, J)
    c = out.view(Z, I, J)

    # strides (in elements, not bytes)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # tile sizes – tuned for Hopper / Tensor‑Core
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        Z,                                 # program_id(0) – batch*head
        triton.cdiv(I, BLOCK_M),           # program_id(1) – rows
        triton.cdiv(J, BLOCK_N),           # program_id(2) – cols
    )

    batch_matmul_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,           # good default for SM90
    )
    return out


# ----------------------------------------------------------------------
# Full forward pass (PyTorch + Triton)
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the “outgoing” TriMul operator.

    Arguments
    ---------
    data : tuple (input_tensor, mask, weights, config)
        input_tensor : torch.Tensor [B, N, N, dim]   (float32, on CUDA)
        mask         : torch.Tensor [B, N, N]       (float32/bool) or None
        weights      : dict of parameter tensors (float32)
        config       : dict with keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor [B, N, N, dim] (float32, on same device)
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    B, N, _, dim = input_tensor.shape
    hidden = config["hidden_dim"]
    eps = 1e-5

    # --------------------------------------------------------------
    # 1. Input LayerNorm (FP32)
    # --------------------------------------------------------------
    w_norm = weights["norm.weight"]
    b_norm = weights["norm.bias"]
    # mean / var over the last dimension (dim)
    mean = input_tensor.mean(dim=-1, keepdim=True)
    var = input_tensor.var(dim=-1, unbiased=False, keepdim=True)
    x = (input_tensor - mean) / torch.sqrt(var + eps)
    x = x * w_norm + b_norm                     # [B,N,N,dim] fp32

    # --------------------------------------------------------------
    # 2. Cast to fp16 for heavy compute
    # --------------------------------------------------------------
    x_fp16 = x.to(torch.float16)

    # Linear weight tensors (fp16, no bias)
    left_proj_w  = weights["left_proj.weight"].to(torch.float16)
    right_proj_w = weights["right_proj.weight"].to(torch.float16)
    left_gate_w  = weights["left_gate.weight"].to(torch.float16)
    right_gate_w = weights["right_gate.weight"].to(torch.float16)
    out_gate_w   = weights["out_gate.weight"].to(torch.float16)

    # --------------------------------------------------------------
    # 3. Projections
    # --------------------------------------------------------------
    left  = F.linear(x_fp16, left_proj_w)   # (B,N,N,hidden)
    right = F.linear(x_fp16, right_proj_w)  # (B,N,N,hidden)

    # --------------------------------------------------------------
    # 4. Optional mask (broadcast over hidden)
    # --------------------------------------------------------------
    if mask is not None:
        mask_fp16 = mask.to(torch.float16).unsqueeze(-1)   # (B,N,N,1)
        left = left * mask_fp16
        right = right * mask_fp16

    # --------------------------------------------------------------
    # 5. Gating (sigmoid)
    # --------------------------------------------------------------
    left_gate  = F.linear(x_fp16, left_gate_w).sigmoid()
    right_gate = F.linear(x_fp16, right_gate_w).sigmoid()
    out_gate   = F.linear(x_fp16, out_gate_w).sigmoid()

    left = left * left_gate
    right = right * right_gate

    # --------------------------------------------------------------
    # 6. Triton batched GEMM (the N³ contraction)
    #    left : (B,N,N,hidden)  →  (B, hidden, N, N)
    #    right: (B,N,N,hidden)  →  (B, hidden, N, N)  then transpose K↔J
    # --------------------------------------------------------------
    left_t  = left.permute(0, 3, 1, 2).contiguous()   # (B, H, I, K)
    right_t = right.permute(0, 3, 2, 1).contiguous()  # (B, H, K, J)

    # GEMM returns (B, H, I, J) in fp16
    out_fp16 = triton_batch_matmul(left_t, right_t)

    # Back to original layout and to FP32 for remaining ops
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)  # (B,N,N,dim)

    # --------------------------------------------------------------
    # 7. Output LayerNorm (FP32)
    # --------------------------------------------------------------
    mean_o = out.mean(dim=-1, keepdim=True)
    var_o = out.var(dim=-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + eps)

    w_out_norm = weights["to_out_norm.weight"]
    b_out_norm = weights["to_out_norm.bias"]
    out = out * w_out_norm + b_out_norm

    # --------------------------------------------------------------
    # 8. Final gate + linear projection
    # --------------------------------------------------------------
    out = out * out_gate.to(torch.float32)    # broadcast over dim
    out = F.linear(out, weights["to_out.weight"])   # (B,N,N,dim), still fp32

    return out
