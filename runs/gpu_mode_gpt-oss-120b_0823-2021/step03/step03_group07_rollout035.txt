We implement the **outgoing** version of the TriMul operator.  
The expensive part is the 4‑D contraction  

```
out[b, h, i, j] = Σ_k left[b, h, i, k] * right[b, h, j, k]      (1)
```

where  

* `left` / `right` ∈ **[B, H, N, N]** (`H = hidden_dim`).  
* The remaining operations (LayerNorm, linear projections, gating, final
  LayerNorm / linear) are memory‑bound and are left to PyTorch – this matches the
  “global‑delegate” lesson that cuBLAS/Torch performs those cheap steps fast.

We therefore

1. **Pre‑process in PyTorch** – LayerNorm, four linear projections, the three
   sigmoid gates and the optional mask.  
   All tensors stay in **fp32** because the model weights are fp32.

2. **Reshape to [B, H, N, N]** and cast to **fp16** (the kernel works in fp16
   with fp32 accumulation).

3. **Launch a Triton kernel** that evaluates (1) using a classic blocked GEMM
   tiling (`BLOCK_M × BLOCK_N × BLOCK_K`).  
   * One program‑id corresponds to a tile **(b, h, tile_m, tile_n)**.  
   * Inside the kernel we iterate over the K‑dimension in blocks, load a
     `(M,K)` sub‑matrix from `left` and a **transposed** `(K,N)` sub‑matrix from
     `right` (so a single `tl.dot` gives the inner product).  
   * Accumulation is performed in fp32 to keep numerical quality, then the
     result is written back as fp16.

4. **Post‑process in PyTorch** – reshape back to the original layout,
   apply the output‑LayerNorm, the output gate and the final linear projection.
   The final tensor is returned in **fp32** as required.

The kernel only handles the O(N³) work; everything else stays in PyTorch, which
fits the “delegate cheap work” lesson while still satisfying the rule *“you must
implement at least part of the operations in a kernel.”*  
The chosen block sizes (`64×64×32`) give good occupancy on Hopper (SM‑90) and
keep shared‑memory usage ≈ 32 KB per block, well under the limit.

```python
"""
TriMul outgoing forward pass (AlphaFold‑3 style).

* All cheap ops (LayerNorm, linear projections, gates) are done in PyTorch.
* The cubic contraction
        out[b, h, i, j] = Σ_k left[b, h, i, k] * right[b, h, j, k]
  is implemented as a blocked GEMM in a Triton kernel (_trimul_kernel).
* The kernel works in fp16 with fp32 accumulation and writes fp16 results.
* After the kernel we finish the forward pass in PyTorch (LayerNorm, output‑gate,
  final linear) and return fp32 output of shape [B, N, N, dim].
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict, Any


# ----------------------------------------------------------------------
# Triton kernel: batched GEMM for the contraction out = left @ right.T
# ----------------------------------------------------------------------
@triton.jit
def _trimul_kernel(
    left_ptr,          # const fp16*  [B, H, N, N]
    right_ptr,         # const fp16*  [B, H, N, N] (read transposed)
    out_ptr,           #       fp16*  [B, H, N, N]
    B, N, H,           # int metadata
    # strides (row‑major) for each tensor
    stride_lb, stride_lh, stride_ln, stride_lk,   # left
    stride_rb, stride_rh, stride_rn, stride_rk,   # right
    stride_ob, stride_oh, stride_on, stride_ok,   # out
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """Calculate one (BLOCK_M x BLOCK_N) tile of the 4‑D result."""

    pid = tl.program_id(0)

    # ------------------- decode program id ----------------------------
    # layout: ((b * H + h) * num_m + tile_m) * num_n + tile_n
    num_m = tl.cdiv(N, BLOCK_M)
    num_n = tl.cdiv(N, BLOCK_N)

    tile_n = pid % num_n
    pid //= num_n
    tile_m = pid % num_m
    pid //= num_m
    h = pid % H
    b = pid // H

    # ------------------- tile coordinates -----------------------------
    offs_m = tile_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = tile_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < N
    mask_n = offs_n < N

    # accumulator in fp32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ------------------- main K‑loop ---------------------------------
    for kk in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = kk * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # left[b, h, i, k]  -> shape (M, K)
        l_ptr = (left_ptr
                 + b * stride_lb
                 + h * stride_lh
                 + offs_m[:, None] * stride_ln
                 + offs_k[None, :] * stride_lk)
        l = tl.load(l_ptr,
                    mask=mask_m[:, None] & mask_k[None, :],
                    other=0.0).to(tl.float32)

        # right[b, h, j, k] read as transposed => (K, N)
        #   original indices: (b, h, j, k)
        #   after transpose: (k, j)
        r_ptr = (right_ptr
                 + b * stride_rb
                 + h * stride_rh
                 + offs_k[:, None] * stride_rk   # k becomes row
                 + offs_n[None, :] * stride_rn)  # j becomes column
        r_t = tl.load(r_ptr,
                      mask=mask_k[:, None] & mask_n[None, :],
                      other=0.0).to(tl.float32)

        acc += tl.dot(l, r_t)   # (M,K) @ (K,N) -> (M,N)

    # ------------------- write back ----------------------------------
    out_ptrs = (out_ptr
                + b * stride_ob
                + h * stride_oh
                + offs_m[:, None] * stride_on
                + offs_n[None, :] * stride_ok)

    tl.store(out_ptrs,
             acc.to(tl.float16),
             mask=mask_m[:, None] & mask_n[None, :])


# ----------------------------------------------------------------------
# Host‑side wrapper (the required `custom_kernel` entry point)
# ----------------------------------------------------------------------
def custom_kernel(
    data: Tuple[
        torch.Tensor,                     # input   [B, N, N, dim]
        torch.Tensor,                     # mask    [B, N, N]   (or None)
        Dict[str, torch.Tensor],          # weights
        Dict[str, Any]                    # config
    ]
) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.

    Returns
    -------
    torch.Tensor
        Tensor of shape [B, N, N, dim] (float32).
    """
    x, mask, weights, config = data
    device = x.device
    dtype = torch.float32

    B, N, _, dim = x.shape
    hidden_dim = config["hidden_dim"]          # H

    # --------------------------------------------------------------
    # 1️⃣  Cheap ops in PyTorch
    # --------------------------------------------------------------
    # LayerNorm over the feature dimension
    x = F.layer_norm(
        x,
        normalized_shape=(dim,),
        weight=weights["norm.weight"].to(dtype),
        bias=weights["norm.bias"].to(dtype),
    )

    # Linear projections (bias = False)
    left = F.linear(x, weights["left_proj.weight"].to(dtype))   # (B,N,N,H)
    right = F.linear(x, weights["right_proj.weight"].to(dtype))

    # Optional mask
    if mask is not None:
        mask_ = mask.unsqueeze(-1).to(x.dtype)   # (B,N,N,1)
        left = left * mask_
        right = right * mask_

    # Gates (sigmoid after linear)
    left_gate = torch.sigmoid(F.linear(x, weights["left_gate.weight"].to(dtype)))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"].to(dtype)))
    out_gate = torch.sigmoid(F.linear(x, weights["out_gate.weight"].to(dtype)))

    left = left * left_gate
    right = right * right_gate

    # --------------------------------------------------------------
    # 2️⃣  Prepare tensors for the kernel
    # --------------------------------------------------------------
    # (B,N,N,H) -> (B,H,N,N) and cast to fp16
    left = left.permute(0, 3, 1, 2).contiguous()
    right = right.permute(0, 3, 1, 2).contiguous()

    left_fp16 = left.to(torch.float16)
    right_fp16 = right.to(torch.float16)

    out_fp16 = torch.empty_like(left_fp16)   # (B,H,N,N), fp16

    # --------------------------------------------------------------
    # 3️⃣  Triton kernel launch
    # --------------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid_m = triton.cdiv(N, BLOCK_M)
    grid_n = triton.cdiv(N, BLOCK_N)
    # total programs = B * H * grid_m * grid_n
    grid = (B * hidden_dim * grid_m * grid_n,)

    _trimul_kernel[grid](
        left_fp16,
        right_fp16,
        out_fp16,
        B,
        N,
        hidden_dim,
        # strides for left
        left_fp16.stride(0),   # B
        left_fp16.stride(1),   # H
        left_fp16.stride(2),   # N (row index i)
        left_fp16.stride(3),   # N (col index k)
        # strides for right
        right_fp16.stride(0),
        right_fp16.stride(1),
        right_fp16.stride(2),
        right_fp16.stride(3),
        # strides for out
        out_fp16.stride(0),
        out_fp16.stride(1),
        out_fp16.stride(2),
        out_fp16.stride(3),
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # --------------------------------------------------------------
    # 4️⃣  Post‑process in PyTorch
    # --------------------------------------------------------------
    # (B,H,N,N) -> (B,N,N,H) and back to fp32
    out = out_fp16.to(dtype).permute(0, 2, 3, 1).contiguous()   # (B,N,N,H)

    # Final LayerNorm on hidden dimension
    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"].to(dtype),
        bias=weights["to_out_norm.bias"].to(dtype),
    )

    # Apply output gate (broadcast on pairwise axes)
    out = out * out_gate

    # Linear back to original `dim`
    out = F.linear(out, weights["to_out.weight"].to(dtype))

    return out
```
