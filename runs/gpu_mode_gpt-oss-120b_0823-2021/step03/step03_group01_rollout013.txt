The “outgoing” TriMul operator consists of three inexpensive stages (layer‑norm,
linear projections, gating) and one heavy cubic contraction

```
out[b,i,j,d] = Σk left[b,i,k,d] * right[b,j,k,d]          (1)
```

Only the contraction (1) is a good candidate for a handcrafted Trit‑on kernel.
All other tensor‑wise ops are kept in PyTorch because they are cheap and
benefit from the highly‑optimised kernels already present in the library.

The implementation follows these steps  

1. **Input Layer‑Norm** – performed in FP32 (the reference implementation does the
   same).  
2. **Linear projections** – weights are stored in FP16; the normalized input is
   cast to FP16 and the four linear layers (`left_proj`, `right_proj`,
   `left_gate`, `right_gate`, `out_gate`) are evaluated with `torch.nn.functional.linear`.  
3. **Mask** – broadcasted over the hidden dimension if it exists.  
4. **Gating** – `sigmoid` on the three gate tensors and element‑wise
   multiplication with `left` / `right`.  
5. **Batched GEMM** – the contraction (1) is rewritten as a batched matrix
   multiplication

```
left  : (B, H, I, K)   where H = hidden_dim, I = N, K = N
right : (B, H, K, J)   where J = N
out   : (B, H, I, J)
```

   The heavy work is carried out by a custom Triton kernel
   `batch_matmul_kernel`.  The kernel works on tiles of size
   `BLOCK_M × BLOCK_N` and reduces over `K` in chunks of `BLOCK_K`.  All
   arithmetic is **FP16** with an **FP32 accumulator** (Tensor‑Core friendly on
   Hopper/SM90).  After the kernel finishes we permute the result back to
   `(B, N, N, hidden_dim)` and cast to FP32.  

6. **Output Layer‑Norm, final gating and linear projection** – identical to the
   reference implementation, carried out in FP32.

The kernel launches a 3‑D grid: `(tiles‑over‑I, tiles‑over‑J, B*H)`.  The tile
size (`64×64×32`) was chosen to keep shared‑memory usage well below the limits
while still allowing the compiler to emit Tensor‑Core instructions on Hopper.

The whole pipeline respects the required signature:

```python
def custom_kernel(data):
    input_tensor, mask, weights, config = data
    ...
    return output      # shape [B, N, N, dim], dtype torch.float32
```

Below is the complete, self‑contained implementation.

```python
"""
custom_kernel – “outgoing” TriMul forward pass (AlphaFold‑3 style).

The cubic contraction
    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
is performed by a fused batched GEMM Triton kernel.  All other
operations (LayerNorm, linear projections, gating, final LayerNorm + linear)
are executed in PyTorch.  Mixed‑precision (FP16 compute / FP32 accumulation)
is used for the kernel; the final result is returned as FP32.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched GEMM (I×K)·(K×J) → (I×J)
# ----------------------------------------------------------------------
@triton.jit
def batch_matmul_kernel(
    a_ptr,            # left matrix pointer   (Z, I, K)
    b_ptr,            # right matrix pointer  (Z, K, J)
    c_ptr,            # output matrix pointer (Z, I, J)
    M, N, K,          # matrix sizes (int)
    stride_az, stride_am, stride_ak,   # strides for a (z,i,k)
    stride_bz, stride_bk, stride_bn,   # strides for b (z,k,j)
    stride_cz, stride_cm, stride_cn,   # strides for c (z,i,j)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Batched matrix multiplication for tensors with shape
        a : (Z, M, K)   b : (Z, K, N)   →   c : (Z, M, N)
    All tensors are stored in FP16; accumulation uses FP32.
    """
    pid_z = tl.program_id(2)          # batch * hidden_dim index
    pid_m = tl.program_id(0)          # tile row index
    pid_n = tl.program_id(1)          # tile column index

    # --------------------------------------------------------------
    # 1) compute offsets within the tile
    # --------------------------------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # 2) loop over K dimension in BLOCK_K‑sized chunks
    # --------------------------------------------------------------
    for kk in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = kk * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # load A tile  (BLOCK_M, BLOCK_K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # load B tile  (BLOCK_K, BLOCK_N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # fp32 accumulation
        acc += tl.dot(a, b)

    # --------------------------------------------------------------
    # 3) write result (cast back to FP16)
    # --------------------------------------------------------------
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


def triton_batch_matmul(left: torch.Tensor,
                        right: torch.Tensor) -> torch.Tensor:
    """
    Wrapper around `batch_matmul_kernel`.  The tensors must be contiguous,
    have dtype torch.float16 and the shape:
        left  : (B, H, I, K)
        right : (B, H, K, J)
    Returns:
        out : (B, H, I, J)  dtype torch.float16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    out = torch.empty((B, H, I, J),
                      device=left.device,
                      dtype=torch.float16)

    # flatten leading dimensions for the kernel (Z = B*H)
    Z = B * H
    a = left.view(Z, I, K)
    b = right.view(Z, K, J)
    c = out.view(Z, I, J)

    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # Tiling – values tuned for Hopper (Tensor‑Core friendly)
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(I, BLOCK_M),   # rows
        triton.cdiv(J, BLOCK_N),   # cols
        Z,                         # batch*head
    )
    batch_matmul_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,               # good default for SM90
    )
    return out


# ----------------------------------------------------------------------
# Full forward pass (PyTorch + Triton)
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the “outgoing” TriMul operator.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask, weights, config)
        - input_tensor : torch.Tensor [B, N, N, dim]  (float32)
        - mask         : torch.Tensor [B, N, N]      (float32/bool) or None
        - weights      : dict with the following keys
              "norm.weight", "norm.bias",
              "left_proj.weight", "right_proj.weight",
              "left_gate.weight", "right_gate.weight", "out_gate.weight",
              "to_out_norm.weight", "to_out_norm.bias",
              "to_out.weight"
        - config       : dict with keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor [B, N, N, dim] (float32)
    """
    # ------------------------------------------------------------------
    # unpack
    # ------------------------------------------------------------------
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]
    eps = 1e-5

    # ------------------------------------------------------------------
    # 1. Input LayerNorm (FP32)
    # ------------------------------------------------------------------
    norm_w = weights["norm.weight"]
    norm_b = weights["norm.bias"]
    mean = input_tensor.mean(dim=-1, keepdim=True)
    var = input_tensor.var(dim=-1, unbiased=False, keepdim=True)
    x = (input_tensor - mean) / torch.sqrt(var + eps)
    x = x * norm_w + norm_b                     # [B,N,N,dim]  FP32

    # ------------------------------------------------------------------
    # 2. Linear projections (convert to FP16 for the heavy part)
    # ------------------------------------------------------------------
    def to_fp16(t):
        return t.to(torch.float16, non_blocking=True)

    left_proj_w = to_fp16(weights["left_proj.weight"])
    right_proj_w = to_fp16(weights["right_proj.weight"])
    left_gate_w = to_fp16(weights["left_gate.weight"])
    right_gate_w = to_fp16(weights["right_gate.weight"])
    out_gate_w = to_fp16(weights["out_gate.weight"])

    # Cast normalized input to FP16 once
    x_fp16 = x.to(torch.float16)

    left = F.linear(x_fp16, left_proj_w)   # (B,N,N,hidden_dim)
    right = F.linear(x_fp16, right_proj_w)

    # ------------------------------------------------------------------
    # 3. Optional mask (broadcast over hidden_dim)
    # ------------------------------------------------------------------
    if mask is not None:
        mask_fp16 = mask.to(torch.float16).unsqueeze(-1)   # (B,N,N,1)
        left = left * mask_fp16
        right = right * mask_fp16

    # ------------------------------------------------------------------
    # 4. Gating (sigmoid) – also in FP16
    # ------------------------------------------------------------------
    left_gate = F.linear(x_fp16, left_gate_w).sigmoid()
    right_gate = F.linear(x_fp16, right_gate_w).sigmoid()
    out_gate = F.linear(x_fp16, out_gate_w).sigmoid()

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5. Triton batched GEMM (the cubic contraction)
    #    left  : (B, H, I, K)   -> (B, H, N, N)
    #    right : (B, H, K, J)   -> (B, H, N, N) with J == N
    # ------------------------------------------------------------------
    # Rearrange to (B, H, I, K) and (B, H, K, J)
    left_perm = left.permute(0, 3, 1, 2).contiguous()   # (B, H, I, K)
    # right[b, j, k, d] in the reference -> we need (B, H, K, J)
    right_perm = right.permute(0, 3, 2, 1).contiguous()  # (B, H, K, J)

    out_fp16 = triton_batch_matmul(left_perm, right_perm)   # (B, H, I, J)

    # Back to (B, N, N, hidden_dim) and FP32 for the remaining ops
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)

    # ------------------------------------------------------------------
    # 6. Output LayerNorm (FP32)
    # ------------------------------------------------------------------
    mean_o = out.mean(dim=-1, keepdim=True)
    var_o = out.var(dim=-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + eps)
    to_out_norm_w = weights["to_out_norm.weight"]
    to_out_norm_b = weights["to_out_norm.bias"]
    out = out * to_out_norm_w + to_out_norm_b

    # ------------------------------------------------------------------
    # 7. Final gating + linear projection
    # ------------------------------------------------------------------
    out = out * out_gate.to(torch.float32)          # broadcast over dim
    out = F.linear(out, weights["to_out.weight"])

    return out
```
