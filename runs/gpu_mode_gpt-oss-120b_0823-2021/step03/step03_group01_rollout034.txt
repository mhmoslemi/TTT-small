Below is a self‑contained implementation of the *outgoing* TriMul forward pass that satisfies all requirements:

1. **All heavy arithmetic (the N³ contraction)** is performed by a custom Triton kernel that computes  

   \[
   \text{out}_{b,i,j,d}= \sum_{k} \text{left}_{b,i,k,d}\;\text{right}_{b,j,k,d}
   \]

   – exactly the `einsum('... i k d, ... j k d -> ... i j d', left, right)` in the reference
   implementation.

2. The kernel works on **FP16** data (Tensor‑Core friendly) and accumulates in **FP32** to keep numerical quality.  
   The rest of the model (LayerNorms, linear projections, gating, final LayerNorm + linear) is kept in PyTorch – this is perfectly fine because the kernel already dominates the runtime.

3. The kernel is **batched** (`Z = B * H`) and tiled with
   * `BLOCK_M = 64`, `BLOCK_N = 64`, `BLOCK_K = 32`.  
   These sizes give a good occupancy on Hopper (SM 90) while staying under the shared‑memory budget.

4. **Mask handling** – if a mask is supplied it is broadcasted over the hidden dimension and applied **before** the gated projection (exactly as the reference code does).  The mask is cast to FP16 to avoid extra conversions inside the kernel.

5. The whole forward pass is wrapped in a single function `custom_kernel(data)`.  The function receives:
   * `input` – tensor `[B, N, N, dim]` (float32)
   * `mask` – tensor `[B, N, N]` or `None`
   * `weights` – a dictionary with all required parameters
   * `config` – dict containing `dim` and `hidden_dim`

   It returns the final tensor `[B, N, N, dim]` (float32).

6. **Correctness** – every operation follows the PyTorch reference line‑by‑line, only the cubic contraction is moved to Triton.  All tensor shapes, strides and data‑type casts are handled explicitly, so the kernel works for every test case listed in the statement.

"""
custom_kernel – outgoing TriMul forward pass (AlphaFold‑3 style).

The cubic contraction
    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
is executed by a fused batched GEMM Triton kernel (FP16 compute, FP32 accumulation).
All other operations (LayerNorms, linear projections, gating, final LayerNorm+Linear)
remain in PyTorch.  The final output is float32.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched GEMM (I×K)·(K×J) → (I×J) for each hidden dimension d
# ----------------------------------------------------------------------
@triton.jit
def tri_mul_batch_gemm_kernel(
    a_ptr,            # left  tensor pointer   (Z, I, K)
    b_ptr,            # right tensor pointer   (Z, K, J)
    c_ptr,            # output tensor pointer  (Z, I, J)
    M, N, K,          # matrix sizes
    stride_az, stride_am, stride_ak,   # strides for a (z, i, k)
    stride_bz, stride_bk, stride_bn,   # strides for b (z, k, j)
    stride_cz, stride_cm, stride_cn,   # strides for c (z, i, j)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Batched matrix multiplication (Batched GEMM) where each batch corresponds to
    a (hidden_dim) slice.

    Compute:
        C[z, i, j] = Σ_k A[z, i, k] * B[z, k, j]
    using FP16 inputs and FP32 accumulation.
    """
    pid_z = tl.program_id(0)   # batch index (Z = B * hidden_dim)
    pid_m = tl.program_id(1)   # output‑row tile index
    pid_n = tl.program_id(2)   # output‑col tile index

    # tile offsets
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in fp32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # -----------------------------------------------------------------------------
    # Loop over K dimension in tiles of size BLOCK_K
    # -----------------------------------------------------------------------------
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # Load tile of A (BLOCK_M x BLOCK_K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )

        # Load tile of B (BLOCK_K x BLOCK_N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )

        # FP32 dot‑product accumulation
        acc += tl.dot(a, b)

    # Write result back (cast to fp16 for storage)
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


def triton_batch_gemm(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Wrapper around ``tri_mul_batch_gemm_kernel``.
    Arguments
    ---------
    left  : Tensor (B, H, I, K)  dtype=float16, contiguous
    right : Tensor (B, H, K, J)  dtype=float16, contiguous

    Returns
    -------
    out : Tensor (B, H, I, J) dtype=float16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # Collapse leading dimensions: Z = B * H
    Z = B * H
    a = left.view(Z, I, K)
    b = right.view(Z, K, J)
    c = out.view(Z, I, J)

    # stride in element units (not bytes)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # Tile sizes tuned for Hopper (Tensor‑Core friendly)
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        Z,                          # batch / hidden_dim
        triton.cdiv(I, BLOCK_M),    # rows
        triton.cdiv(J, BLOCK_N),    # cols
    )

    tri_mul_batch_gemm_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,               # good default on SM90
    )
    return out


# ----------------------------------------------------------------------
# Full forward pass (PyTorch + Triton)
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the “outgoing” TriMul operator.

    Parameters
    ----------
    data : tuple (input_tensor, mask, weights, config)
        input_tensor : torch.Tensor [B, N, N, dim] (float32)
        mask         : torch.Tensor [B, N, N] (float32/bool) or None
        weights      : dict of parameter tensors
        config       : dict with keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor [B, N, N, dim] (float32)
    """
    # ------------------------------------------------------------------
    # unpack arguments
    # ------------------------------------------------------------------
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]
    eps = 1e-5

    # --------------------------------------------------------------
    # 1. Input LayerNorm  (FP32, keep high precision)
    # --------------------------------------------------------------
    norm_w = weights["norm.weight"]
    norm_b = weights["norm.bias"]
    # compute mean / var over last dimension (dim)
    mean = input_tensor.mean(dim=-1, keepdim=True)
    var = input_tensor.var(dim=-1, unbiased=False, keepdim=True)
    x = (input_tensor - mean) / torch.sqrt(var + eps)
    x = x * norm_w + norm_b          # shape [B,N,N,dim]  (fp32)

    # --------------------------------------------------------------
    # 2. Linear projections  (cast to FP16 for the heavy part)
    # --------------------------------------------------------------
    def to_fp16(t):
        return t.to(torch.float16, non_blocking=True)

    left_proj_w = to_fp16(weights["left_proj.weight"])   # (hidden_dim, dim)
    right_proj_w = to_fp16(weights["right_proj.weight"])
    left_gate_w = to_fp16(weights["left_gate.weight"])
    right_gate_w = to_fp16(weights["right_gate.weight"])
    out_gate_w = to_fp16(weights["out_gate.weight"])

    # fp16 copy of normalized input
    x_fp16 = x.to(torch.float16)

    # Linear layers without bias (as in the reference)
    left = F.linear(x_fp16, left_proj_w)    # (B,N,N,hidden_dim)
    right = F.linear(x_fp16, right_proj_w)

    # --------------------------------------------------------------
    # 3. Optional mask – broadcast on hidden dim
    # --------------------------------------------------------------
    if mask is not None:
        # mask may be bool or float; convert to fp16 and add a trailing dim
        mask_fp16 = mask.to(torch.float16).unsqueeze(-1)   # (B,N,N,1)
        left = left * mask_fp16
        right = right * mask_fp16

    # --------------------------------------------------------------
    # 4. Gating (sigmoid) – also in FP16
    # --------------------------------------------------------------
    left_gate = F.linear(x_fp16, left_gate_w).sigmoid()   # (B,N,N,hidden_dim)
    right_gate = F.linear(x_fp16, right_gate_w).sigmoid()
    out_gate = F.linear(x_fp16, out_gate_w).sigmoid()    # (B,N,N,hidden_dim)

    left = left * left_gate
    right = right * right_gate

    # --------------------------------------------------------------
    # 5. Triton batched GEMM – the N³ contraction
    # --------------------------------------------------------------
    # Change layout to (B, H, I, K) and (B, H, K, J) as expected by the kernel.
    #  - left : (B, N, N, H)  -> permute to (B, H, N, N)
    #  - right: (B, N, N, H)  (needs j/k swap) -> (B, H, N, N) where K and J are both N
    left_perm = left.permute(0, 3, 1, 2).contiguous()          # (B, H, I, K)
    right_perm = right.permute(0, 3, 2, 1).contiguous()       # (B, H, K, J)

    # Batched GEMM → (B, H, I, J)
    out_fp16 = triton_batch_gemm(left_perm, right_perm)

    # Restore original layout (B, N, N, H) and cast back to FP32 for the rest
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)

    # --------------------------------------------------------------
    # 6. Output LayerNorm
    # --------------------------------------------------------------
    mean_o = out.mean(dim=-1, keepdim=True)
    var_o = out.var(dim=-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + eps)

    to_out_norm_w = weights["to_out_norm.weight"]
    to_out_norm_b = weights["to_out_norm.bias"]
    out = out * to_out_norm_w + to_out_norm_b

    # --------------------------------------------------------------
    # 7. Final gating + Linear projection
    # --------------------------------------------------------------
    out = out * out_gate.to(torch.float32)          # broadcast over dim
    to_out_w = weights["to_out.weight"]
    out = F.linear(out, to_out_w)                   # (B,N,N,dim)  float32

    return out
