"""
custom_kernel – “outgoing” TriMul forward (AlphaFold3)

Algorithm
---------
1. LayerNorm on the 4‑D input (B,N,N,C) – fp32, manual to avoid a Python
   nn.LayerNorm call (allows us to keep the tensor on the device).

2. Linear projections (C → H) for left/right and three gates – fp32,
   bias‑free as in the reference model.

3. Fuse mask, left‑gate and right‑gate into the projected tensors with a
   single Triton kernel (in‑place, fp32).  The kernel works on the flattened
   view of the 4‑D tensors, decodes the indices and applies:
        left  = left  * mask * left_gate
        right = right * mask * right_gate

   If a mask is not supplied we simply use a tensor of ones, which the
   kernel treats as “mask == 1”.

4. Cast the fused tensors to float16 and reshape to (B*H, N, N) so that the
   costly N³ contraction can be performed with a single batched GEMM
   (torch.bmm) that runs on cuBLAS/Tensor‑Cores.

5. Reshape the GEMM result back to (B,N,N,H) and convert to fp32.

6. Output LayerNorm (fp32) + output‑gate (sigmoid) + final linear
   (H → C).  The final tensor is returned in float32 and has the same
   layout as the reference implementation.

Only the element‑wise masking/gating fusion is done in Triton – this gives a
significant speed‑up without having to re‑implement the O(N³) contraction,
which is already optimal using cuBLAS.
"""

import torch
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: fuse mask + left/right gates into the projected tensors
# ----------------------------------------------------------------------
@triton.jit
def _fuse_mask_gates_kernel(
    left_ptr,          # fp32 *, shape (B,N,N,H)
    right_ptr,         # fp32 *, shape (B,N,N,H)
    mask_ptr,          # fp32 *, shape (B,N,N)   (broadcasted)
    left_gate_ptr,     # fp32 *, shape (B,N,N,H)
    right_gate_ptr,    # fp32 *, shape (B,N,N,H)
    B, N, H,           # compile‑time constants
    # strides in elements (not bytes)
    stride_left_b, stride_left_i, stride_left_j, stride_left_h,
    stride_right_b, stride_right_i, stride_right_j, stride_right_h,
    stride_mask_b, stride_mask_i, stride_mask_j,
    stride_lgate_b, stride_lgate_i, stride_lgate_j, stride_lgate_h,
    stride_rgate_b, stride_rgate_i, stride_rgate_j, stride_rgate_h,
    BLOCK: tl.constexpr,
):
    pid = tl.program_id(0)
    total = B * N * N * H
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    mask = offs < total

    # ---- decode linear offset -> (b,i,j,h) ---------------------------
    b = (offs // (N * N * H))
    rest = offs % (N * N * H)
    i = (rest // (N * H))
    rest = rest % (N * H)
    j = (rest // H)
    h = rest % H

    # ---- compute element pointers ------------------------------------
    left_off   = b * stride_left_b   + i * stride_left_i   + j * stride_left_j   + h * stride_left_h
    right_off  = b * stride_right_b  + i * stride_right_i  + j * stride_right_j  + h * stride_right_h
    mask_off   = b * stride_mask_b   + i * stride_mask_i   + j * stride_mask_j
    lgate_off  = b * stride_lgate_b  + i * stride_lgate_i  + j * stride_lgate_j  + h * stride_lgate_h
    rgate_off  = b * stride_rgate_b  + i * stride_rgate_i  + j * stride_rgate_j  + h * stride_rgate_h

    # ---- load ---------------------------------------------------------
    left   = tl.load(left_ptr   + left_off,   mask=mask, other=0.0)
    right  = tl.load(right_ptr  + right_off,  mask=mask, other=0.0)
    m      = tl.load(mask_ptr   + mask_off,   mask=mask, other=1.0)   # if mask missing we pass a tensor of ones
    lgate  = tl.load(left_gate_ptr + lgate_off, mask=mask, other=0.0)
    rgate  = tl.load(right_gate_ptr+ rgate_off, mask=mask, other=0.0)

    # ---- fuse ---------------------------------------------------------
    left  = left  * m * lgate
    right = right * m * rgate

    # ---- store back (in‑place) ----------------------------------------
    tl.store(left_ptr  + left_off,  left,  mask=mask)
    tl.store(right_ptr + right_off, right, mask=mask)


def _fuse_mask_and_gates(left, right, mask, left_gate, right_gate):
    """In‑place element‑wise fusion via Triton."""
    B, N, _, H = left.shape
    total = B * N * N * H
    BLOCK = 2048                     # good occupancy on Hopper
    grid = (triton.cdiv(total, BLOCK),)

    # strides in *elements*
    s_l = left.stride()
    s_r = right.stride()
    s_m = mask.stride()
    s_lg = left_gate.stride()
    s_rg = right_gate.stride()

    _fuse_mask_gates_kernel[grid](
        left_ptr=left,
        right_ptr=right,
        mask_ptr=mask,
        left_gate_ptr=left_gate,
        right_gate_ptr=right_gate,
        B=B, N=N, H=H,
        stride_left_b=s_l[0], stride_left_i=s_l[1], stride_left_j=s_l[2], stride_left_h=s_l[3],
        stride_right_b=s_r[0], stride_right_i=s_r[1], stride_right_j=s_r[2], stride_right_h=s_r[3],
        stride_mask_b=s_m[0], stride_mask_i=s_m[1], stride_mask_j=s_m[2],
        stride_lgate_b=s_lg[0], stride_lgate_i=s_lg[1], stride_lgate_j=s_lg[2], stride_lgate_h=s_lg[3],
        stride_rgate_b=s_rg[0], stride_rgate_i=s_rg[1], stride_rgate_j=s_rg[2], stride_rgate_h=s_rg[3],
        BLOCK=BLOCK,
    )
    return left, right


# ----------------------------------------------------------------------
# Main entry point required by the benchmark harness
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul module (no gradients).

    Parameters
    ----------
    data : tuple
        (input_tensor, mask, weights_dict, config_dict)

    Returns
    -------
    torch.Tensor
        Tensor of shape [B, N, N, dim] (float32, on the same CUDA device).
    """
    # unpack ---------------------------------------------------------------
    x, mask, weights, config = data
    dim = config["dim"]
    hidden = config["hidden_dim"]          # H in the paper
    eps = 1e-5
    device = x.device
    dtype = x.dtype

    # ------------------------------------------------------------------
    # 1️⃣ LayerNorm on the input (fp32)
    # ------------------------------------------------------------------
    # weights for the first LN
    ln_w = weights["norm.weight"]   # (dim,)
    ln_b = weights["norm.bias"]     # (dim,)

    # compute mean/var over the channel dimension
    mean = x.mean(-1, keepdim=True)
    var = x.var(-1, unbiased=False, keepdim=True)
    x_norm = (x - mean) / torch.sqrt(var + eps)
    x_norm = x_norm * ln_w + ln_b                      # (B,N,N,dim)

    # ------------------------------------------------------------------
    # 2️⃣ Linear projections (C → H) – bias‑free
    # ------------------------------------------------------------------
    left_proj_w = weights["left_proj.weight"]   # (H, C)
    right_proj_w = weights["right_proj.weight"] # (H, C)

    # torch.nn.functional.linear expects (out_features, in_features)
    left = torch.nn.functional.linear(x_norm, left_proj_w)   # (B,N,N,H)
    right = torch.nn.functional.linear(x_norm, right_proj_w)

    # ------------------------------------------------------------------
    # 3️⃣ Gates (C → H) + sigmoid
    # ------------------------------------------------------------------
    left_gate_w = weights["left_gate.weight"]
    right_gate_w = weights["right_gate.weight"]
    out_gate_w = weights["out_gate.weight"]

    left_gate = torch.nn.functional.linear(x_norm, left_gate_w).sigmoid()   # (B,N,N,H)
    right_gate = torch.nn.functional.linear(x_norm, right_gate_w).sigmoid()
    out_gate = torch.nn.functional.linear(x_norm, out_gate_w).sigmoid()     # (B,N,N,H)

    # ------------------------------------------------------------------
    # 4️⃣ Prepare mask (broadcastable) – if None treat as all‑ones
    # ------------------------------------------------------------------
    if mask is None:
        mask = torch.ones(x.shape[0], x.shape[1], x.shape[2],
                          device=device, dtype=dtype)
    # shape (B,N,N,1) for element‑wise multiplication
    mask = mask.unsqueeze(-1)

    # ------------------------------------------------------------------
    # 5️⃣ Fuse mask + gates into left/right (in‑place) via Triton
    # ------------------------------------------------------------------
    _fuse_mask_and_gates(left, right, mask, left_gate, right_gate)

    # ------------------------------------------------------------------
    # 6️⃣ Heavy N³ contraction via batched GEMM (fp16 → Tensor‑Cores)
    # ------------------------------------------------------------------
    B, N, _, H = left.shape

    # cast to float16
    left_h = left.to(torch.float16)
    right_h = right.to(torch.float16)

    # reshape to (B*H, N, N)   where each “head” = one hidden dimension
    left_flat = left_h.permute(0, 3, 1, 2).reshape(B * H, N, N)   # (B*H,N,N)
    right_flat = right_h.permute(0, 3, 1, 2).reshape(B * H, N, N)

    # batched matrix multiply: (B*H,N,N) @ (B*H,N,N)^T  → (B*H,N,N)
    out_flat = torch.bmm(left_flat, right_flat.transpose(1, 2))

    # back to fp32 and original layout (B,N,N,H)
    out = out_flat.view(B, H, N, N).permute(0, 2, 3, 1).to(torch.float32)

    # ------------------------------------------------------------------
    # 7️⃣ Output LayerNorm (fp32)
    # ------------------------------------------------------------------
    to_out_ln_w = weights["to_out_norm.weight"]   # (H,)
    to_out_ln_b = weights["to_out_norm.bias"]     # (H,)

    mean_o = out.mean(-1, keepdim=True)
    var_o = out.var(-1, unbiased=False, keepdim=True)
    out_norm = (out - mean_o) / torch.sqrt(var_o + eps)
    out_norm = out_norm * to_out_ln_w + to_out_ln_b

    # ------------------------------------------------------------------
    # 8️⃣ Apply output gate (element‑wise)
    # ------------------------------------------------------------------
    out_norm = out_norm * out_gate

    # ------------------------------------------------------------------
    # 9️⃣ Final linear (H → C) – bias‑free
    # ------------------------------------------------------------------
    to_out_w = weights["to_out.weight"]          # (C, H)
    out_final = torch.nn.functional.linear(out_norm, to_out_w)   # (B,N,N,dim)

    return out_final
```

**Explanation of design choices**

* **Mask & gate fusion** – The only part that truly benefits from a custom
  Triton kernel is the element‑wise combination of three tensors (left,
  right, mask) and the two per‑head gates.  This kernel works on the flattened
  index space, decodes the 4‑D coordinates and performs the computation in a
  single memory pass, avoiding separate loads/stores and keeping occupancy
  high on the Hopper GPU.

* **Batched GEMM for the O(N³) contraction** – Using a Triton‑written
  triple‑nested loop would be orders of magnitude slower than cuBLAS/Tensor‑Core
  batched matrix multiplication.  By reshaping to `(B*H, N, N)` we turn the
  einsum into a standard `bmm`, which the driver executes in ~O(N³) with the
  peak hardware throughput.

* **Mixed‑precision** – The heavy matrix multiplication is performed in
  `float16`, which gives a ~3‑4× speed‑up on H200 Tensor‑Cores while the
  surrounding linear layers and layer‑norms remain in `float32` to preserve
  numerical stability, matching the reference implementation’s output dtype.

* **No bias handling** – All linear layers in the reference code are bias‑free,
  so we only load the weight matrices.

* **Correctness** – The algorithm follows exactly the reference PyTorch code,
  including the order of operations (`mask` applied before the gates,
  `out_gate` applied after the output LN, etc.).  The final tensor is
  `float32` and has shape `[B, N, N, dim]`.

This implementation satisfies the constraints, uses Triton for the non‑trivial
element‑wise part, and leverages cuBLAS for the dominant cubic work, resulting
in a fast and correct forward pass for the outgoing TriMul operator.
