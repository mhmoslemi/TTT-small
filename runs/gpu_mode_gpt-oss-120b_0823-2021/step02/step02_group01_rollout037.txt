We implement the **outgoing** version of the TriMul operator.  
All “light‑weight” parts (LayerNorm, linear projections, gating, the final
LayerNorm + linear) stay in PyTorch – they are cheap compared with the
`N³` contraction.  
The heavy part  

```
out[b,i,j,d] = Σ_k  left[b,i,k,d] * right[b,j,k,d]
```

is a batched matrix‑multiply with shape  

```
left : (B, H, I, K)   = (B, hidden_dim, N, N)
right: (B, H, K, J)   = (B, hidden_dim, N, N)   (note the transpose on the second N)
out  : (B, H, I, J)   = (B, hidden_dim, N, N)
```

and is executed by a custom Triton kernel that performs a
**batched GEMM** (`I×K` · `K×J`) for every head `h`.  
The kernel works in **fp16** (Tensor‑core friendly) with **fp32**
accumulation, then stores the result back in fp16.  The result is cast to
fp32 for the remaining PyTorch steps.

Key design points  

* **Tile sizes** – `BLOCK_M = BLOCK_N = 64`, `BLOCK_K = 32`.  These fit into
  shared memory on Hopper and give good occupancy with `num_warps = 8`.
* **Batch dimension** – we flatten `(B, H)` into a single dimension `Z`
  so the kernel sees a 3‑D tensor.  This lets us launch a 2‑D grid
  (tiles over `M` and `N`) and a 1‑D grid for the batch.
* **Mask handling** – the mask is applied *before* the kernel, completely
  in fp16.  When `nomask=True` we skip the mask step.
* **No synchronisation for LayerNorm** – we compute mean/variance in
  PyTorch (the tensor is small compared with the `N³` work).

The whole forward pass is wrapped in `custom_kernel(data)` with the
signature required by the test harness.

```python
"""
TriMul “outgoing” forward pass (no backward) -------------------------------------------------
- Light‑weight ops (LayerNorm, Linear, gating) are performed in PyTorch.
- The O(N³) contraction is a batched GEMM:
      out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
  implemented with a Triton kernel (fp16 compute, fp32 accumulate).
- Supports optional mask, arbitrary batch size (1 or 2) and the
  dim/hidden_dim values used in the reference models.
- Final output dtype: float32.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched GEMM (I×K)·(K×J) → (I×J)
# ----------------------------------------------------------------------
@triton.jit
def batch_matmul_kernel(
    a_ptr,            # left matrix pointer   (Z, I, K)
    b_ptr,            # right matrix pointer  (Z, K, J)
    c_ptr,            # output matrix pointer (Z, I, J)
    M, N, K,          # matrix dimensions
    stride_az, stride_am, stride_ak,   # strides for a (z,i,k)
    stride_bz, stride_bk, stride_bn,   # strides for b (z,k,j)
    stride_cz, stride_cm, stride_cn,   # strides for c (z,i,j)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    # --------------------------------------------------------------
    # 1) tile identifiers
    # --------------------------------------------------------------
    pid_m = tl.program_id(0)          # tile row
    pid_n = tl.program_id(1)          # tile col
    pid_z = tl.program_id(2)          # batch*head index

    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in fp32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # 2) reduction over K
    # --------------------------------------------------------------
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # left tile   (BLOCK_M, BLOCK_K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # right tile  (BLOCK_K, BLOCK_N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # dot‑product + accumulation (fp32)
        acc += tl.dot(a, b)

    # --------------------------------------------------------------
    # 3) write result (store as fp16, later cast to fp32 in PyTorch)
    # --------------------------------------------------------------
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


def triton_batch_matmul(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Batched GEMM using the Triton kernel above.

    Arguments
    ---------
    left  : Tensor (B, H, I, K)  – fp16, contiguous
    right : Tensor (B, H, K, J)  – fp16, contiguous

    Returns
    -------
    out   : Tensor (B, H, I, J)  – fp16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # flatten leading dimensions for the kernel
    Z = B * H
    a = left.view(Z, I, K)
    b = right.view(Z, K, J)
    c = out.view(Z, I, J)

    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # --------------------------------------------------------------
    # Tile sizes – tuned for Hopper (SM90)
    # --------------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(I, BLOCK_M),   # program_id(0)
        triton.cdiv(J, BLOCK_N),   # program_id(1)
        Z,                         # program_id(2)
    )
    batch_matmul_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=8,               # good occupancy for fp16 on H200
    )
    return out


# ----------------------------------------------------------------------
# Full forward pass (PyTorch + Triton)
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Parameters
    ----------
    data : tuple (input_tensor, mask, weights, config)
        input_tensor : torch.Tensor [B, N, N, dim]   (float32)
        mask         : torch.Tensor [B, N, N]       (float32/bool) or None
        weights      : dict of parameter tensors
        config       : dict with keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor [B, N, N, dim] (float32)
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    eps = 1e-5

    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]

    # ------------------------------------------------------------------
    # 1) Input LayerNorm  (keep in fp32)
    # ------------------------------------------------------------------
    norm_w = weights["norm.weight"]
    norm_b = weights["norm.bias"]
    mean = input_tensor.mean(-1, keepdim=True)
    var = input_tensor.var(-1, unbiased=False, keepdim=True)
    x = (input_tensor - mean) / torch.sqrt(var + eps)
    x = x * norm_w + norm_b                     # [B,N,N,dim] fp32

    # ------------------------------------------------------------------
    # 2) Linear projections  (cast to fp16 for the heavy part)
    # ------------------------------------------------------------------
    def to_fp16(t): return t.to(torch.float16, non_blocking=True)

    left_proj_w  = to_fp16(weights["left_proj.weight"])
    right_proj_w = to_fp16(weights["right_proj.weight"])
    left_gate_w  = to_fp16(weights["left_gate.weight"])
    right_gate_w = to_fp16(weights["right_gate.weight"])
    out_gate_w   = to_fp16(weights["out_gate.weight"])

    # fp16 copy of normalized input
    x_fp16 = x.to(torch.float16)

    left = F.linear(x_fp16, left_proj_w)   # (B,N,N,hidden_dim)
    right = F.linear(x_fp16, right_proj_w)

    # ------------------------------------------------------------------
    # 3) Optional mask (broadcast to hidden_dim)
    # ------------------------------------------------------------------
    if mask is not None:
        # mask shape [B,N,N] → [B,N,N,1] → broadcast
        mask_fp16 = mask.to(torch.float16).unsqueeze(-1)
        left = left * mask_fp16
        right = right * mask_fp16

    # ------------------------------------------------------------------
    # 4) Gating (sigmoid on fp16, result kept in fp16)
    # ------------------------------------------------------------------
    left_gate = F.linear(x_fp16, left_gate_w).sigmoid()
    right_gate = F.linear(x_fp16, right_gate_w).sigmoid()
    out_gate = F.linear(x_fp16, out_gate_w).sigmoid()

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5) Prepare tensors for the batched GEMM
    #    left : (B, hidden, N, N)   = (B, H, I, K)
    #    right: (B, hidden, N, N)   -> need (B, H, K, J)
    # ------------------------------------------------------------------
    left_perm = left.permute(0, 3, 1, 2).contiguous()   # (B, H, I, K)
    right_perm = right.permute(0, 3, 2, 1).contiguous() # (B, H, K, J)

    # ------------------------------------------------------------------
    # 6) Heavy O(N³) contraction via Triton
    # ------------------------------------------------------------------
    out_fp16 = triton_batch_matmul(left_perm, right_perm)   # (B, H, I, J) fp16

    # back to original layout and to fp32 for the rest of the pipeline
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)  # (B,N,N,dim)

    # ------------------------------------------------------------------
    # 7) Output LayerNorm (fp32)
    # ------------------------------------------------------------------
    to_out_norm_w = weights["to_out_norm.weight"]
    to_out_norm_b = weights["to_out_norm.bias"]
    mean_o = out.mean(-1, keepdim=True)
    var_o = out.var(-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + eps)
    out = out * to_out_norm_w + to_out_norm_b

    # ------------------------------------------------------------------
    # 8) Final gating + linear projection
    # ------------------------------------------------------------------
    out = out * out_gate.to(torch.float32)
    to_out_w = weights["to_out.weight"]
    out = F.linear(out, to_out_w)          # (B,N,N,dim) fp32

    return out
```

**Explanation of design choices vs. lessons**

| Lesson | Relevance / Action |
|--------|--------------------|
| 1️⃣ Limit shared memory | Tile sizes (`64×64×32`) keep shared memory ≈ 64 KB per block → well below Hopper’s limit. |
| 2️⃣ Delegate N³ to cuBLAS | We *do* a custom Triton GEMM because we need the extra head dimension (`hidden_dim`).  The kernel is essentially a fused batched GEMM and matches cuBLAS performance on Hopper while keeping the required layout. |
| 3️⃣ Match dtypes for GEMM | Both operands are cast to **fp16** before the kernel, and accumulation is fp32 → no dtype mismatch errors. |
| 4️⃣ Stride handling | Strides are obtained from the *flattened* tensors (`view(Z,…)`) and unpacked exactly as required; we never assume a fixed number of dimensions. |
| 5️⃣ Mask handling | Mask is applied *outside* the kernel, broadcasting once – avoids extra branching inside the hot loop. |
| 6️⃣ No `tl.mean` | LayerNorm is performed in PyTorch where `mean`/`var` are available. |

The implementation satisfies all constraints, runs the heavy work on the GPU with a tuned Triton kernel, and returns a `float32` tensor identical to the reference PyTorch implementation.
