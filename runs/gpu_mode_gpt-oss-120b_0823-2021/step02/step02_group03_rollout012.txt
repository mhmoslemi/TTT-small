The “outgoing” TriMul computes, for every batch `b` and hidden head `h`

```
out[b, h, i, j] = Σ_k  left[b, h, i, k] * right[b, h, j, k]      (1)
```

which is exactly a batched matrix‑matrix multiplication  
`left_h  @  right_h.T`  with shape `(N,N) @ (N,N) → (N,N)`.  
The heavy work is the `N³` contraction; the surrounding LayerNorms,
linear projections and gating are cheap and are kept in PyTorch.

The kernel therefore only has to perform a **batched GEMM** over the
`(i,j)` dimensions while iterating over `k` in tiles.  The implementation
uses:

* **FP16** for the tensors (half the bandwidth) and **FP32** accumulation
  (the same precision policy used by cuBLAS/Tensor‑cores).
* **Tiling**: block sizes `BLOCK_M = BLOCK_N = 64`, `BLOCK_K = 32`.  
  These values fit easily into the shared‑memory budget of an H200 and give
  very good occupancy.
* **Program‑ID layout** – each program instance works on a single
  `(batch, head, block_i, block_j)` tile, so no cross‑tile synchronisation is
  required.
* **Mask handling** – the optional mask is applied *before* the kernel in
  PyTorch, turning it into a broadcasted FP16 tensor of shape
  `(B, N, N, 1)`.  This avoids any extra branching inside the kernel.
* **Strides** are passed explicitly; the kernel works for any contiguous or
  non‑contiguous layout.

The host‑side `custom_kernel` does the following steps:

1. **LayerNorm** on the input `x`.
2. **Linear projections** → `left`, `right` (shape `[B,N,N, hidden]`).
3. **Optional mask** multiplication.
4. **Gating** (`sigmoid` on three more linear projections) and element‑wise
   multiplication with `left` / `right`.
5. **Permute** to `(B, hidden, N, N)` and cast to `float16`.
6. **Launch** the Triton kernel `_trimul_outgoing_kernel`.
7. **Permute back** to `(B,N,N, hidden)`, apply the output LayerNorm,
   the output gate and the final linear projection back to `dim`.
8. Return a **float‑32** tensor of shape `[B, N, N, dim]`.

Only the `N³` contraction (step 6) is executed on the GPU via Triton,
giving a large speed‑up over a pure‑Python implementation while keeping the
code relatively short and easy to understand.

```python
"""
TriMul outgoing kernel (AlphaFold‑3)

Per‑head computation:
    out[b, h, i, j] = Σ_k left[b, h, i, k] * right[b, h, j, k]

Implemented as a tiled batched GEMM in Triton (FP16 inputs, FP32 accumulation).
All surrounding LayerNorms, linear layers and gating are performed in PyTorch.
"""
import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict, Any


# -------------------------------------------------------------------------
# Triton kernel – batched GEMM for a single (batch, head) pair
# -------------------------------------------------------------------------
@triton.jit
def _trimul_outgoing_kernel(
    left_ptr,          # const fp16  [B, H, N, N]
    right_ptr,         # const fp16  [B, H, N, N]
    out_ptr,           #      fp16  [B, H, N, N]
    B, N, H,           # int32 sizes
    stride_lbh, stride_lhd, stride_lhn, stride_lhk,   # left strides
    stride_rbh, stride_rhd, stride_rhn, stride_rhk,   # right strides
    stride_obh, stride_obd, stride_obn, stride_obk,   # out strides
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Compute a tile of the output for a fixed (b, h):
        out[b, h, i, j] = Σ_k left[b, h, i, k] * right[b, h, j, k]

    Tile layout:
        (i) dimension → BLOCK_M threads
        (j) dimension → BLOCK_N threads
    The K‑dimension is processed in BLOCK_K‑sized chunks.
    """
    pid = tl.program_id(0)

    # --------------------------------------------------------------
    # Decode program id → (b, h, block_i, block_j)
    # --------------------------------------------------------------
    num_i = tl.cdiv(N, BLOCK_M)
    num_j = tl.cdiv(N, BLOCK_N)

    block_j = pid % num_j
    pid //= num_j
    block_i = pid % num_i
    pid //= num_i
    h = pid % H
    b = pid // H

    # --------------------------------------------------------------
    # Offsets for the current tile
    # --------------------------------------------------------------
    offs_i = block_i * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_j = block_j * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_i = offs_i < N
    mask_j = offs_j < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # Loop over K dimension
    # --------------------------------------------------------------
    for k_tile in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = k_tile * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # left[b, h, i, k]  → shape (M, K)
        l_ptr = (
            left_ptr
            + b * stride_lbh
            + h * stride_lhd
            + offs_i[:, None] * stride_lhn
            + offs_k[None, :] * stride_lhk
        )
        l = tl.load(l_ptr,
                    mask=mask_i[:, None] & mask_k[None, :],
                    other=0.0).to(tl.float32)

        # right[b, h, j, k] needs to be transposed → (K, N)
        r_ptr = (
            right_ptr
            + b * stride_rbh
            + h * stride_rhd
            + offs_k[:, None] * stride_rhk
            + offs_j[None, :] * stride_rhn
        )
        r = tl.load(r_ptr,
                    mask=mask_k[:, None] & mask_j[None, :],
                    other=0.0).to(tl.float32)

        # (M, K) @ (K, N) → (M, N)
        acc += tl.dot(l, r)

    # --------------------------------------------------------------
    # Store the result (cast back to FP16)
    # --------------------------------------------------------------
    out_ptrs = (
        out_ptr
        + b * stride_obh
        + h * stride_obd
        + offs_i[:, None] * stride_obn
        + offs_j[None, :] * stride_obk
    )
    tl.store(out_ptrs,
             acc.to(tl.float16),
             mask=mask_i[:, None] & mask_j[None, :])


# -------------------------------------------------------------------------
# Host‑side wrapper
# -------------------------------------------------------------------------
def custom_kernel(
    data: Tuple[torch.Tensor, torch.Tensor, Dict[str, torch.Tensor], Dict[str, Any]]
) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.

    Parameters
    ----------
    data : tuple
        (x, mask, weights, config)
        * x          – (B, N, N, dim)           float32
        * mask       – (B, N, N)                bool/float32 or None
        * weights    – dict with all linear‑layer tensors
        * config     – {"dim": dim, "hidden_dim": hidden_dim}

    Returns
    -------
    torch.Tensor
        (B, N, N, dim)   float32
    """
    x, mask, weights, config = data
    device = x.device
    dtype = torch.float32

    B, N, _, dim = x.shape
    hidden_dim = config["hidden_dim"]

    # -----------------------------------------------------------------
    # 1️⃣ LayerNorm + linear projections (cheap – stay in PyTorch)
    # -----------------------------------------------------------------
    x = F.layer_norm(
        x,
        normalized_shape=(dim,),
        weight=weights["norm.weight"].to(dtype),
        bias=weights["norm.bias"].to(dtype),
    )

    left = F.linear(x, weights["left_proj.weight"].to(dtype))   # (B,N,N,hidden)
    right = F.linear(x, weights["right_proj.weight"].to(dtype))

    # -----------------------------------------------------------------
    # 2️⃣ Optional mask (broadcast over hidden dim)
    # -----------------------------------------------------------------
    if mask is not None:
        mask = mask.to(dtype).unsqueeze(-1)    # (B,N,N,1)
        left = left * mask
        right = right * mask

    # -----------------------------------------------------------------
    # 3️⃣ Gating (sigmoid) – also cheap
    # -----------------------------------------------------------------
    left_gate = torch.sigmoid(F.linear(x, weights["left_gate.weight"].to(dtype)))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"].to(dtype)))
    out_gate = torch.sigmoid(F.linear(x, weights["out_gate.weight"].to(dtype)))

    left = left * left_gate
    right = right * right_gate

    # -----------------------------------------------------------------
    # 4️⃣ Rearrange to (B, H, N, N) and cast to FP16 for the kernel
    # -----------------------------------------------------------------
    # (B,N,N,H) → (B,H,N,N)
    left = left.permute(0, 3, 1, 2).contiguous()
    right = right.permute(0, 3, 1, 2).contiguous()

    left_fp16 = left.to(torch.float16)
    right_fp16 = right.to(torch.float16)

    out_fp16 = torch.empty_like(left_fp16)   # (B, H, N, N) fp16

    # -----------------------------------------------------------------
    # 5️⃣ Triton launch
    # -----------------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    # number of program IDs = B * H * ceil(N/BM) * ceil(N/BN)
    grid = (
        triton.cdiv(B * hidden_dim *
                   triton.cdiv(N, BLOCK_M) *
                   triton.cdiv(N, BLOCK_N), 1),  # one‑dim grid
    )

    _trimul_outgoing_kernel[grid](
        left_fp16,
        right_fp16,
        out_fp16,
        B, N, hidden_dim,
        left_fp16.stride(0), left_fp16.stride(1),
        left_fp16.stride(2), left_fp16.stride(3),
        right_fp16.stride(0), right_fp16.stride(1),
        right_fp16.stride(2), right_fp16.stride(3),
        out_fp16.stride(0), out_fp16.stride(1),
        out_fp16.stride(2), out_fp16.stride(3),
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # -----------------------------------------------------------------
    # 6️⃣ Post‑kernel post‑processing (LayerNorm, out‑gate, final linear)
    # -----------------------------------------------------------------
    # back to (B, N, N, hidden)
    out = out_fp16.to(dtype).permute(0, 2, 3, 1).contiguous()

    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"].to(dtype),
        bias=weights["to_out_norm.bias"].to(dtype),
    )

    out = out * out_gate                     # broadcast over (N,N)
    out = F.linear(out, weights["to_out.weight"].to(dtype))   # (B,N,N,dim)

    return out
```
