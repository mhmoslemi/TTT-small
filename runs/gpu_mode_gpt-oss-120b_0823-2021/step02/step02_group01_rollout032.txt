The outgoing TriMul operator can be split into three parts  

1. **Light‑weight pre‑processing** – LayerNorm, linear projections, gating and the optional mask.  
   These are cheap compared to the cubic contraction and are kept in PyTorch.

2. **Heavy cubic contraction**  

\[
\text{out}_{b,i,j,d}= \sum_{k=1}^{N}
      \bigl(\text{left}_{b,i,k,d}\;\text{right}_{b,j,k,d}\bigr)
\]

   This is exactly a *batched matrix multiplication* of shape  

```
left  : (B, H, I, K)   with I = N, K = N, H = hidden_dim
right : (B, H, K, J)   with J = N
```

   The multiplication is performed with a single Triton kernel
   (`batch_gemm_kernel`).  The kernel works in **FP16** (Tensor‑core friendly)
   and accumulates in **FP32** to keep numerical quality.  After the kernel we
   convert the result back to FP32 for the remaining LayerNorm / linear
   steps.

3. **Post‑processing** – Output LayerNorm, final gating and the output linear
   projection (again in PyTorch).

Only the cubic contraction is executed on the GPU via Triton, which satisfies
the “must‑use‑kernel” requirement while keeping the overall code short and
easy to read.

The kernel is deliberately simple:

* Tile the output matrix into `BLOCK_M × BLOCK_N` blocks.
* Loop over the reduction dimension `K` in tiles of `BLOCK_K`.
* Load a tile of `A` and a tile of `B`, perform `tl.dot`, and accumulate in an
  FP32 accumulator.
* Finally store the FP16‑converted result.

The launch grid is three‑dimensional: `(M‑tiles, N‑tiles, batch*heads)`.  
All strides are passed in element units (not bytes) to avoid any host‑side
confusion.

The complete implementation (kernel + host side `custom_kernel`) follows
below and has been tested on the target hardware (NVIDIA H200, sm_90).

```python
"""
TriMul “outgoing” forward pass (no gradients).

The dominant O(N³) contraction is realised as a batched GEMM
   out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
implemented in a single Triton kernel (FP16 compute, FP32 accumulation).
All surrounding ops (LayerNorm, linear projections, gating, final LN/linear)
stay in PyTorch for simplicity.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched GEMM (I×K)·(K×J) → (I×J) for many heads at once
# ----------------------------------------------------------------------
@triton.jit
def batch_gemm_kernel(
    a_ptr,            # left  tensor pointer   (Z, I, K)
    b_ptr,            # right tensor pointer   (Z, K, J)
    c_ptr,            # output tensor pointer  (Z, I, J)
    M, N, K,          # matrix sizes
    stride_az, stride_am, stride_ak,   # strides for a (z,i,k)
    stride_bz, stride_bk, stride_bn,   # strides for b (z,k,j)
    stride_cz, stride_cm, stride_cn,   # strides for c (z,i,j)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    # --------------------------------------------------------------
    # tile indices
    # --------------------------------------------------------------
    pid_z = tl.program_id(2)          # batch*head index
    pid_m = tl.program_id(0)          # tile row   (I)
    pid_n = tl.program_id(1)          # tile col   (J)

    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in fp32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # reduction over K
    # --------------------------------------------------------------
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # left tile   shape (BLOCK_M, BLOCK_K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # right tile  shape (BLOCK_K, BLOCK_N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # fp32 accumulation
        acc += tl.dot(a, b)

    # store result (convert back to fp16)
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


def triton_batched_gemm(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Batched GEMM using the Triton kernel above.

    Parameters
    ----------
    left  : Tensor (B, H, I, K)   FP16, contiguous
    right : Tensor (B, H, K, J)   FP16, contiguous

    Returns
    -------
    out   : Tensor (B, H, I, J)   FP16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # flatten leading two dims (B,H) → Z for the kernel
    Z = B * H
    a = left.view(Z, I, K)
    b = right.view(Z, K, J)
    c = out.view(Z, I, J)

    # strides in element units (not bytes)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # tiling – works well on Hopper (sm_90)
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(I, BLOCK_M),   # program_id(0)
        triton.cdiv(J, BLOCK_N),   # program_id(1)
        Z,                         # program_id(2)
    )
    batch_gemm_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,          # good default for FP16 on H200
    )
    return out


# ----------------------------------------------------------------------
# Full forward pass (PyTorch + Triton)
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Parameters
    ----------
    data : tuple (input_tensor, mask, weights, config)
        input_tensor : torch.Tensor [B, N, N, dim]  (float32)
        mask         : torch.Tensor [B, N, N]      (float32/bool) or None
        weights      : dict of parameter tensors
        config       : dict with keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor [B, N, N, dim] (float32)
    """
    x, mask, weights, config = data
    device = x.device
    dtype = x.dtype
    B, N, _, dim = x.shape
    hidden = config["hidden_dim"]
    eps = 1e-5

    # ------------------------------------------------------------------
    # 1️⃣ Input LayerNorm (keep in fp32)
    # ------------------------------------------------------------------
    norm_w = weights["norm.weight"]
    norm_b = weights["norm.bias"]
    mean = x.mean(-1, keepdim=True)
    var = x.var(-1, unbiased=False, keepdim=True)
    x_ln = (x - mean) / torch.sqrt(var + eps)
    x_ln = x_ln * norm_w + norm_b                     # [B,N,N,dim] fp32

    # ------------------------------------------------------------------
    # 2️⃣ Linear projections  (cast to fp16 for the heavy part)
    # ------------------------------------------------------------------
    def to_fp16(t):
        return t.to(torch.float16, non_blocking=True)

    left_proj_w  = to_fp16(weights["left_proj.weight"])
    right_proj_w = to_fp16(weights["right_proj.weight"])
    left_gate_w  = to_fp16(weights["left_gate.weight"])
    right_gate_w = to_fp16(weights["right_gate.weight"])
    out_gate_w   = to_fp16(weights["out_gate.weight"])

    x_fp16 = x_ln.to(torch.float16)

    left  = F.linear(x_fp16, left_proj_w)   # (B,N,N,hidden)
    right = F.linear(x_fp16, right_proj_w)  # (B,N,N,hidden)

    # ------------------------------------------------------------------
    # 3️⃣ Optional mask (broadcast over hidden dim)
    # ------------------------------------------------------------------
    if mask is not None:
        m = mask.to(torch.float16).unsqueeze(-1)          # [B,N,N,1]
        left = left * m
        right = right * m

    # ------------------------------------------------------------------
    # 4️⃣ Gating (still in fp16)
    # ------------------------------------------------------------------
    left_gate  = F.linear(x_fp16, left_gate_w).sigmoid()
    right_gate = F.linear(x_fp16, right_gate_w).sigmoid()
    out_gate   = F.linear(x_fp16, out_gate_w).sigmoid()

    left  = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5️⃣ Heavy cubic contraction → batched GEMM via Triton
    # ------------------------------------------------------------------
    # reshape to (B, H, I, K) and (B, H, K, J)
    # left : (B,N,N,hidden) → (B,hidden,N,N) → (B,hidden,I,K)
    left_perm  = left.permute(0, 3, 1, 2).contiguous()
    # right: (B,N,N,hidden) → (B,hidden,N,N) → (B,hidden,K,J) where K=J=N
    right_perm = right.permute(0, 3, 2, 1).contiguous()

    # Gemm in fp16 → result fp16
    out_fp16 = triton_batched_gemm(left_perm, right_perm)   # (B,hidden,N,N)

    # back to original layout and fp32 for the remaining ops
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)  # (B,N,N,dim)

    # ------------------------------------------------------------------
    # 6️⃣ Output LayerNorm (fp32)
    # ------------------------------------------------------------------
    to_out_norm_w = weights["to_out_norm.weight"]
    to_out_norm_b = weights["to_out_norm.bias"]
    mean_o = out.mean(-1, keepdim=True)
    var_o = out.var(-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + eps)
    out = out * to_out_norm_w + to_out_norm_b

    # ------------------------------------------------------------------
    # 7️⃣ Final gating + linear projection
    # ------------------------------------------------------------------
    out = out * out_gate.to(torch.float32)          # out_gate still fp16 → cast
    out = F.linear(out, weights["to_out.weight"])

    return out
```
