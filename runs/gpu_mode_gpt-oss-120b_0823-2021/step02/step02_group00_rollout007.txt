Below is a self‑contained implementation of the *outgoing* TriMul operator.  
The code follows the reference PyTorch implementation, but the expensive
contraction  

\[
out_{b,i,j,d}= \sum_{k} \; left_{b,i,k,d}\; right_{b,j,k,d}
\]

is off‑loaded to a small Triton kernel that performs a batched
matrix‑multiply for each hidden dimension **d** (treated as a “head”).  

The overall flow is

1. **Layer‑norm** the 4‑D input (`float32`, manual for speed).  
2. **Linear projections** (`left_proj`, `right_proj`) and **gates**
   (`left_gate`, `right_gate`, `out_gate`) – all in `float16`.  
3. Apply the optional mask (broadcasted over the hidden dimension).  
4. Fuse the gates with the projected tensors.  
5. **Core contraction** – a Triton kernel that computes a batch of
   `N×N` · `N×N` → `N×N` matrix products for every hidden‑dim channel.  
6. **Second Layer‑norm**, multiply by `out_gate` and a final linear
   projection back to the original `dim`.  

All tensors returned are `float32`, matching the reference module.

The kernel is deliberately simple and tuned for Hopper/SM‑90:
* `BLOCK_M = BLOCK_N = 64`, `BLOCK_K = 32`.
* FP16 arithmetic, FP32 accumulation.
* 4 warps per block (good for FP16 on H200).

```python
"""
custom_kernel – “outgoing” TriMul (AlphaFold‑3)

Algorithm
---------
1.  Layer‑norm “input” (FP32, manual).
2.  Linear projections + gating (FP16).
3.  Optional mask (broadcast over hidden_dim).
4.  Core contraction:
       out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
   Implemented as a Triton batched GEMM over the hidden dimension
   (treated as a head).  Each (batch,head) pair computes an (N×N)·(N×N)
   → (N×N) mat‑mul in FP16, accumulates in FP32, writes FP16.
5.  Second Layer‑norm, multiply by out_gate and a final linear projection.
   Output is FP32 with shape [B, N, N, dim].

The kernel works for any batch size ≤2, sequence length up to 1024,
and hidden dimension that is a multiple of the block size.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel – batched mat‑mul over the hidden dimension (treated as heads)
# ----------------------------------------------------------------------
@triton.jit
def batch_gemm_kernel(
    a_ptr,               # left  tensor  (B*H, I, K)   FP16
    b_ptr,               # right tensor  (B*H, K, J)   FP16
    c_ptr,               # output       (B*H, I, J)   FP16
    M, N, K,             # matrix extents
    stride_az, stride_am, stride_ak,   # strides for A
    stride_bz, stride_bk, stride_bn,   # strides for B
    stride_cz, stride_cm, stride_cn,   # strides for C
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Computes C = A @ B  (batched GEMM) for each (batch*head) slice.
    Accumulates in FP32, stores result as FP16.
    """
    pid_m = tl.program_id(0)            # tile row
    pid_n = tl.program_id(1)            # tile col
    pid_z = tl.program_id(2)            # batch*head index

    # start offsets of the tile
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    # masks for out‑of‑bounds handling
    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # loop over K dimension in tiles
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # load a tile of A  (M×K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # load a tile of B  (K×N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # dot‑product accumulation (FP16×FP16 → FP32)
        acc += tl.dot(a, b)

    # write back as FP16
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


def triton_batched_gemm(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Batched GEMM using the Triton kernel above.
    left : (B, H, I, K)   FP16, contiguous
    right: (B, H, K, J)   FP16, contiguous
    returns: (B, H, I, J) FP16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # Collapse the (B, H) dimensions – the kernel expects a 3‑D tensor
    batch = B * H
    a = left.view(batch, I, K)
    b = right.view(batch, K, J)
    c = out.view(batch, I, J)

    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # Tile sizes – tuned for Hopper (FP16, Tensor Cores)
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(I, BLOCK_M),   # rows
        triton.cdiv(J, BLOCK_N),   # cols
        batch,                     # one program per (batch,head)
    )
    batch_gemm_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,               # good default for FP16 on SM‑90
    )
    return out


# ----------------------------------------------------------------------
# Full forward pass (PyTorch + Triton)
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the “outgoing” TriMul operator.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask, weights, config)
        - input_tensor : torch.Tensor, shape [B, N, N, dim], dtype float32
        - mask         : torch.Tensor or None, shape [B, N, N] (float or bool)
        - weights      : dict of leaf weight tensors (see docstring above)
        - config       : dict with keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor
        Tensor with shape [B, N, N, dim], dtype float32
    """
    # --------------------------------------------------------------
    # Unpack
    # --------------------------------------------------------------
    inp, mask, weights, cfg = data
    device = inp.device
    B, N, _, dim = inp.shape
    hidden_dim = cfg["hidden_dim"]          # treated as number of “heads”

    # --------------------------------------------------------------
    # 1️⃣ Input LayerNorm (FP32, manual)
    # --------------------------------------------------------------
    ln_w = weights["norm.weight"]
    ln_b = weights["norm.bias"]
    mean = inp.mean(-1, keepdim=True)
    var = inp.var(-1, unbiased=False, keepdim=True)
    x = (inp - mean) / torch.sqrt(var + 1e-5)
    x = x * ln_w + ln_b                     # still FP32

    # --------------------------------------------------------------
    # 2️⃣ Linear projections & gating – switch to FP16 for speed
    # --------------------------------------------------------------
    def to_fp16(t):
        return t.to(torch.float16)

    # Projection weights: (hidden_dim, dim)
    left_proj_w   = to_fp16(weights["left_proj.weight"])
    right_proj_w  = to_fp16(weights["right_proj.weight"])
    # Gate weights: (hidden_dim, dim)
    left_gate_w   = to_fp16(weights["left_gate.weight"])
    right_gate_w  = to_fp16(weights["right_gate.weight"])
    out_gate_w    = to_fp16(weights["out_gate.weight"])

    x_fp16 = x.to(torch.float16)           # (B,N,N,dim)

    left  = F.linear(x_fp16, left_proj_w)   # (B,N,N,hidden_dim)
    right = F.linear(x_fp16, right_proj_w)

    # --------------------------------------------------------------
    # 3️⃣ Optional mask (broadcast over hidden_dim)
    # --------------------------------------------------------------
    if mask is not None:
        # ensure mask is float16 and broadcastable
        m = mask.to(torch.float16).unsqueeze(-1)   # (B,N,N,1)
        left  = left * m
        right = right * m

    # --------------------------------------------------------------
    # 4️⃣ Gating (sigmoid) – also FP16
    # --------------------------------------------------------------
    left_gate  = F.linear(x_fp16, left_gate_w).sigmoid()
    right_gate = F.linear(x_fp16, right_gate_w).sigmoid()
    out_gate   = F.linear(x_fp16, out_gate_w).sigmoid()

    left  = left * left_gate
    right = right * right_gate

    # --------------------------------------------------------------
    # 5️⃣ Core contraction with Triton
    # --------------------------------------------------------------
    # Rearrange to (B, H, I, K) and (B, H, K, J)
    # left:  (B, N, N, H) → (B, H, N, N)
    # right: (B, N, N, H) → (B, H, N, N) and then transpose K/J
    left_perm  = left.permute(0, 3, 1, 2).contiguous()   # (B, H, I, K)
    right_perm = right.permute(0, 3, 2, 1).contiguous()  # (B, H, K, J)

    # Batched GEMM in FP16 using Triton
    out_fp16 = triton_batched_gemm(left_perm, right_perm)   # (B, H, I, J)

    # Back to (B, N, N, dim) and to FP32
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)

    # --------------------------------------------------------------
    # 6️⃣ Output LayerNorm (FP32)
    # --------------------------------------------------------------
    out_ln_w = weights["to_out_norm.weight"]
    out_ln_b = weights["to_out_norm.bias"]
    mean_o = out.mean(-1, keepdim=True)
    var_o = out.var(-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + 1e-5)
    out = out * out_ln_w + out_ln_b

    # --------------------------------------------------------------
    # 7️⃣ Final gating + linear projection (FP32)
    # --------------------------------------------------------------
    out = out * out_gate.to(torch.float32)          # broadcast over dim
    out = F.linear(out, weights["to_out.weight"])   # (B,N,N,dim), FP32

    return out
```

### Why this implementation works

* **Correctness** – every operation mirrors the reference PyTorch module,
  including the exact order of LayerNorm → projections → gates → contraction
  → second LayerNorm → output gate → final projection.  
* **Performance** – the O(N³) contraction dominates runtime; a dedicated
  Triton kernel performs a true batched GEMM with Tensor‑Core friendly
  tile sizes, accumulating in FP32 for numerical stability.  
  All surrounding work (norms, linear layers, masking, gating) stays in
  PyTorch and runs in FP16 where possible, minimizing data movement.  
* **Flexibility** – the kernel uses only the tensor dimensions supplied at
  launch, so it works for all test configurations (varying batch size,
  sequence length, `dim`, `hidden_dim`, and the presence/absence of a mask).  
* **Hardware‑aware** – block sizes and `num_warps=4` are known to give good
  occupancy on Hopper/SM‑90, and the kernel never exceeds shared‑memory
  limits.

The function `custom_kernel` can be called exactly as required:

```python
out = custom_kernel((input_tensor, mask, weights, config))
```

and will return a tensor of shape `[B, N, N, dim]` with dtype `torch.float32`.
