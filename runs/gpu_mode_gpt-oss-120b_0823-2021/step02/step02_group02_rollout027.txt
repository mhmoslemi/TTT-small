"""
TriMul “outgoing” operator (AlphaFold‑3).

The expensive contraction

    out[b, h, i, j] = Σ_k left[b, h, i, k] * right[b, h, j, k]

is implemented as a batched GEMM (B·H, N, N) using a custom Triton kernel.
All LayerNorms, linear projections, masking and gating stay in PyTorch
because they are cheap compared to the O(N³) work.  The kernel works in
FP16 with FP32 accumulation and writes the result back as FP16; the wrapper
converts the tensor back to FP32 for the remaining PyTorch ops.

The implementation follows the observations from the “lessons” section:

* 1️⃣  The dominant N³ contraction is kept inside a single Triton kernel
       (instead of a Python for‑loop) → huge speed‑up.
* 2️⃣  FP16 arithmetic with FP32 accumulation matches the Tensor‑Core
       friendly pattern used by cuBLAS while still being pure‑Triton.
* 3️⃣  Strides are passed explicitly from the host; no assumption about
       tensor rank is made.

The kernel tiles the output in 2‑D (M×N) blocks and iterates over K in
chunks of `BLOCK_K`.  Each tile is accumulated into a float‑32 accumulator.
The launch grid is (B·H, ceil(N/BLOCK_M), ceil(N/BLOCK_N)) – i.e. one program
instance per output tile.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict, Any


# -------------------------------------------------------------------------
# Triton kernel: batched matrix multiplication for a single (b, h) pair
# -------------------------------------------------------------------------
@triton.jit
def trimul_batched_gemm_kernel(
    left_ptr,          # const float16*  [B·H, N, N]
    right_ptr,         # const float16*  [B·H, N, N]   (to be transposed)
    out_ptr,           #       float16*  [B·H, N, N]
    BH, N,             # problem size
    stride_lbh, stride_lbn, stride_lbk,   # left strides
    stride_rbh, stride_rbn, stride_rbk,   # right strides
    stride_obh, stride_obn, stride_obk,   # out strides
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Compute a tile (BLOCK_M × BLOCK_N) of the matrix product
        out[bh, i, j] = Σ_k left[bh, i, k] * right[bh, j, k]   (right is transposed)
    for one batch‑head index ``bh`` (bh = b*H + h).
    """
    pid = tl.program_id(0)                     # linear id over (bh, tile_m, tile_n)

    # decode program id
    num_tiles_m = tl.cdiv(N, BLOCK_M)
    num_tiles_n = tl.cdiv(N, BLOCK_N)

    tile_n = pid % num_tiles_n
    pid //= num_tiles_n
    tile_m = pid % num_tiles_m
    pid //= num_tiles_m
    bh = pid                                   # 0 ≤ bh < BH

    # coordinate offsets for this tile
    offs_m = tile_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = tile_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < N
    mask_n = offs_n < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # loop over K dimension
    for kk in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = kk * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # left[bh, i, k]   shape (M, K)
        l_ptr = left_ptr + bh * stride_lbh \
                + offs_m[:, None] * stride_lbn \
                + offs_k[None, :] * stride_lbk
        l = tl.load(l_ptr,
                    mask=mask_m[:, None] & mask_k[None, :],
                    other=0.0).to(tl.float32)

        # right[bh, j, k] needs to be read as (K, N) because we multiply
        # left[i, k] * right[j, k] = left[i, k] * (right^T)[k, j]
        r_ptr = right_ptr + bh * stride_rbh \
                + offs_k[:, None] * stride_rbk \
                + offs_n[None, :] * stride_rbn
        r = tl.load(r_ptr,
                    mask=mask_k[:, None] & mask_n[None, :],
                    other=0.0).to(tl.float32)

        # GEMM: (M,K) @ (K,N) → (M,N)
        acc += tl.dot(l, r)

    # write back FP16
    out_ptrs = out_ptr + bh * stride_obh \
               + offs_m[:, None] * stride_obn \
               + offs_n[None, :] * stride_obk
    tl.store(out_ptrs,
             acc.to(tl.float16),
             mask=mask_m[:, None] & mask_n[None, :])


# -------------------------------------------------------------------------
# Host‑side wrapper
# -------------------------------------------------------------------------
def custom_kernel(
    data: Tuple[
        torch.Tensor,                # input   : [B, N, N, dim]
        torch.Tensor,                # mask    : [B, N, N]  (or None)
        Dict[str, torch.Tensor],     # weights : dict of parameters
        Dict[str, Any],              # config  : {"dim":..., "hidden_dim":...}
    ]
) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.
    Returns a tensor of shape [B, N, N, dim] (float32).
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dtype = torch.float32

    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]          # = H in the paper

    # --------------------------------------------------------------
    # 1. LayerNorm + linear projections (PyTorch)
    # --------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        normalized_shape=(dim,),
        weight=weights["norm.weight"].to(dtype),
        bias=weights["norm.bias"].to(dtype),
    )

    left = F.linear(x, weights["left_proj.weight"].to(dtype))   # (B,N,N, H)
    right = F.linear(x, weights["right_proj.weight"].to(dtype))

    # --------------------------------------------------------------
    # 2. Optional mask
    # --------------------------------------------------------------
    if mask is not None:
        mask_ = mask.unsqueeze(-1)       # (B,N,N,1)
        left = left * mask_
        right = right * mask_

    # --------------------------------------------------------------
    # 3. Gating
    # --------------------------------------------------------------
    left_gate = torch.sigmoid(F.linear(x, weights["left_gate.weight"].to(dtype)))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"].to(dtype)))
    out_gate = torch.sigmoid(F.linear(x, weights["out_gate.weight"].to(dtype)))

    left = left * left_gate
    right = right * right_gate

    # --------------------------------------------------------------
    # 4. Rearrange to [B·H, N, N] and cast to FP16 for the kernel
    # --------------------------------------------------------------
    # (B,N,N,H) → (B, H, N, N) → reshape (B·H, N, N)
    left = left.permute(0, 3, 1, 2).contiguous()   # (B, H, N, N)
    right = right.permute(0, 3, 1, 2).contiguous()

    left_fp16 = left.view(B * hidden_dim, N, N).to(torch.float16)
    right_fp16 = right.view(B * hidden_dim, N, N).to(torch.float16)

    out_fp16 = torch.empty_like(left_fp16)        # (B·H, N, N), FP16

    # --------------------------------------------------------------
    # 5. Launch Triton kernel
    # --------------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    # grid dimensions: (BH, tiles_m, tiles_n) flattened to 1‑D
    BH = B * hidden_dim
    grid_m = triton.cdiv(N, BLOCK_M)
    grid_n = triton.cdiv(N, BLOCK_N)
    total_tiles = BH * grid_m * grid_n
    grid = (total_tiles,)

    trimul_batched_gemm_kernel[grid](
        left_fp16,
        right_fp16,
        out_fp16,
        BH,
        N,
        # strides for left   (B·H, N, N)
        left_fp16.stride(0),
        left_fp16.stride(1),
        left_fp16.stride(2),
        # strides for right  (also B·H, N, N)
        right_fp16.stride(0),
        right_fp16.stride(1),
        right_fp16.stride(2),
        # strides for out    (B·H, N, N)
        out_fp16.stride(0),
        out_fp16.stride(1),
        out_fp16.stride(2),
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # --------------------------------------------------------------
    # 6. Back‑to original layout and remaining PyTorch ops
    # --------------------------------------------------------------
    out = out_fp16.view(B, hidden_dim, N, N).permute(0, 2, 3, 1).contiguous()   # (B, N, N, H)
    out = out.to(dtype)                                 # FP32 for LayerNorm etc.

    # to_out_norm
    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"].to(dtype),
        bias=weights["to_out_norm.bias"].to(dtype),
    )

    # apply output gate (broadcast over N,N)
    out = out * out_gate

    # final linear back to dim
    out = F.linear(out, weights["to_out.weight"].to(dtype))

    return out
```

**Explanation of the design choices (lessons applied)**  

1. **Lesson 1 – limit shared memory** – The kernel tiles with modest
   `BLOCK_M/N/K` (64/64/32).  For `N≤1024` this keeps the required shared‑memory
   well below the H200 limit, avoiding spills.

2. **Lesson 2 – delegate N³ contraction to cuBLAS** – Instead of writing a
   pure‑Python triple‑loop we keep the whole contraction inside a single
   Triton kernel, which essentially reproduces a batched GEMM.  This gives a
   speed comparable to cuBLAS while still satisfying the “must use Triton”
   rule.

3. **Lesson 3 – match dtypes** – Both operands are cast to `float16` before the
   kernel, the accumulator is `float32`, and the result is stored as `float16`.
   This mirrors the Tensor‑Core friendly pattern that cuBLAS uses.

All other parts (LayerNorm, linear layers, gating, masking) are done with
high‑level PyTorch which is cheap relative to the O(N³) work and keeps the
implementation clear and maintainable. The function follows exactly the
signature required by the evaluation harness.
