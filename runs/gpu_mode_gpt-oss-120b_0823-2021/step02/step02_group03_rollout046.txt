The “outgoing’’ TriMul computes, for every batch *b* and hidden channel *h*  

\[
\text{out}[b,h,i,j]=\sum_{k=0}^{N-1}\text{left}[b,h,i,k]\;\cdot\;\text{right}[b,h,j,k]\;,
\]

i.e. a batched matrix‑matrix multiplication `(left_h) @ (right_h).T`.  
All surrounding operations (LayerNorm, linear projections, sigmoid‑gates, the final
`to_out` linear) are cheap compared with the **N³** contraction, therefore they
remain in PyTorch.  

The heavy part is turned into a **single Triton kernel** that performs a tiled
GEMM for each `(b, h)` pair:

* tile sizes – `BLOCK_M = 64`, `BLOCK_N = 64`, `BLOCK_K = 32` – fit comfortably
  into the shared‑memory budget of an H200 while giving good occupancy.
* Each program‑ID encodes `(b, h, block_i, block_j)`.  
  Inside the kernel we load a `BLOCK_M × BLOCK_K` tile from **left** and a
  `BLOCK_K × BLOCK_N` tile from **right** (the latter is accessed transposed so
  we can use `tl.dot`).  
  Accumulation is performed in FP32, the result is stored as FP16 and later
  cast back to FP32 on the host.
* Optional masking is applied **before** the kernel (the mask is broadcasted
  over the hidden dimension and multiplied with the projected tensors).

The host‑side `custom_kernel` therefore performs:

1. **LayerNorm** on `x`.  
2. **Linear projections** → `left`, `right`.  
3. **Mask** (if present) and **gates** (`sigmoid`).  
4. **Permute** to shape `[B, H, N, N]` and cast to FP16.  
5. **Launch** the Triton kernel.  
6. **Permute back** to `[B, N, N, H]`, apply the second LayerNorm, the output
   gate and the final linear projection.

The implementation is fully self‑contained, works for any batch size `B∈{1,2}`,
any sequence length `N`, and any hidden dimension `H = hidden_dim`.  
All tensors stay on the device; only the kernel (the O(N³) part) is written in
Triton, satisfying the requirement that *“at least part of the operations be
in a kernel”*.

```python
"""
custom_kernel – outgoing TriMul (AlphaFold‑3)

Algorithm
---------
*   x  : (B, N, N, dim)  – float32 input
*   norm(x) → (B,N,N,dim)
*   left  = x @ W_left   (Linear)   → (B,N,N,hidden)
*   right = x @ W_right  (Linear)   → (B,N,N,hidden)
*   optional mask is applied element‑wise on the last dim.
*   left  *= sigmoid(x @ W_left_gate )
*   right *= sigmoid(x @ W_right_gate)
*   out   = Σ_k left[...,i,k] * right[...,j,k]   (batched GEMM)
*   out   is LayerNorm’ed, multiplied by sigmoid(x @ W_out_gate)
*   out   = out @ W_to_out   (Linear) → (B,N,N,dim)

The heavy contraction (the Σ over k) is performed by a Triton kernel that
computes a tiled batched matrix‑multiply for each (batch, hidden) slice.
All arithmetic inside the kernel is FP16 → FP32 accumulation → FP16 store.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict, Any


# -------------------------------------------------------------------------
# Triton kernel: batched GEMM for each hidden slice
# -------------------------------------------------------------------------
@triton.jit
def _trimul_outgoing_kernel(
    left_ptr,          # const fp16 * [B, H, N, N]
    right_ptr,         # const fp16 * [B, H, N, N]
    out_ptr,           #       fp16 * [B, H, N, N]
    B, N, H,           # int32 scalars
    stride_lbh, stride_lhd, stride_lhn, stride_lhk,   # left strides
    stride_rbh, stride_rhd, stride_rhn, stride_rhk,   # right strides
    stride_obh, stride_obd, stride_obn, stride_obk,   # out strides
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Compute one (batch, hidden) tile:
        out[b, h, i, j] = Σ_k left[b, h, i, k] * right[b, h, j, k]
    """
    pid = tl.program_id(0)

    # --------------------------------------------------------------
    # Decode the flat program id → (b, h, block_i, block_j)
    # --------------------------------------------------------------
    num_blocks_i = tl.cdiv(N, BLOCK_M)
    num_blocks_j = tl.cdiv(N, BLOCK_N)

    block_j = pid % num_blocks_j
    pid //= num_blocks_j
    block_i = pid % num_blocks_i
    pid //= num_blocks_i
    h = pid % H
    b = pid // H

    # --------------------------------------------------------------
    # Tile offsets + bounds masks
    # --------------------------------------------------------------
    offs_i = block_i * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_j = block_j * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_i = offs_i < N
    mask_j = offs_j < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # Loop over K dimension in tiles
    # --------------------------------------------------------------
    for k_tile in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = k_tile * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # left[b, h, i, k]  shape (M, K)
        l_ptr = (
            left_ptr
            + b * stride_lbh
            + h * stride_lhd
            + offs_i[:, None] * stride_lhn
            + offs_k[None, :] * stride_lhk
        )
        l = tl.load(l_ptr,
                    mask=mask_i[:, None] & mask_k[None, :],
                    other=0.0).to(tl.float32)

        # right[b, h, j, k] needs to be transposed → we load (K, N)
        r_ptr = (
            right_ptr
            + b * stride_rbh
            + h * stride_rhd
            + offs_k[:, None] * stride_rhk
            + offs_j[None, :] * stride_rhn
        )
        r = tl.load(r_ptr,
                    mask=mask_k[:, None] & mask_j[None, :],
                    other=0.0).to(tl.float32)

        # (M, K) @ (K, N) → (M, N)
        acc += tl.dot(l, r)

    # --------------------------------------------------------------
    # Store result
    # --------------------------------------------------------------
    out_ptrs = (
        out_ptr
        + b * stride_obh
        + h * stride_obd
        + offs_i[:, None] * stride_obn
        + offs_j[None, :] * stride_obk
    )
    tl.store(out_ptrs,
             acc.to(tl.float16),
             mask=mask_i[:, None] & mask_j[None, :])


# -------------------------------------------------------------------------
# Host‑side wrapper
# -------------------------------------------------------------------------
def custom_kernel(data: Tuple[torch.Tensor,
                               torch.Tensor,
                               Dict[str, torch.Tensor],
                               Dict[str, Any]]) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.

    Args
    ----
    data : (x, mask, weights, config)
        x        : (B, N, N, dim)      float32
        mask     : (B, N, N)           bool/float32 or None
        weights  : dict of all linear / LN parameters
        config   : {"dim": dim, "hidden_dim": hidden_dim}

    Returns
    -------
    out : (B, N, N, dim)   float32
    """
    x, mask, weights, config = data
    device = x.device
    dtype = torch.float32

    B, N, _, dim = x.shape
    hidden_dim = config["hidden_dim"]

    # -----------------------------------------------------------------
    # 1️⃣ LayerNorm + Linear projections (still in PyTorch – cheap)
    # -----------------------------------------------------------------
    x = F.layer_norm(
        x,
        normalized_shape=(dim,),
        weight=weights["norm.weight"].to(dtype),
        bias=weights["norm.bias"].to(dtype),
    )

    left  = F.linear(x, weights["left_proj.weight"].to(dtype))   # (B,N,N,hidden)
    right = F.linear(x, weights["right_proj.weight"].to(dtype))

    # -----------------------------------------------------------------
    # 2️⃣ Optional mask (broadcasted over hidden dimension)
    # -----------------------------------------------------------------
    if mask is not None:
        # mask: (B,N,N) → (B,N,N,1) → (B,N,N,hidden) by broadcasting
        mask_f = mask.to(dtype).unsqueeze(-1)
        left  = left * mask_f
        right = right * mask_f

    # -----------------------------------------------------------------
    # 3️⃣ Gating (sigmoid)
    # -----------------------------------------------------------------
    left_gate  = torch.sigmoid(F.linear(x, weights["left_gate.weight"].to(dtype)))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"].to(dtype)))
    out_gate   = torch.sigmoid(F.linear(x, weights["out_gate.weight"].to(dtype)))

    left  = left * left_gate
    right = right * right_gate

    # -----------------------------------------------------------------
    # 4️⃣ Rearrange to (B, H, N, N) and cast to fp16 for the kernel
    # -----------------------------------------------------------------
    # (B,N,N,H) -> (B,H,N,N)
    left = left.permute(0, 3, 1, 2).contiguous()
    right = right.permute(0, 3, 1, 2).contiguous()

    left_fp16  = left.to(torch.float16)
    right_fp16 = right.to(torch.float16)

    out_fp16 = torch.empty_like(left_fp16)   # (B,H,N,N) fp16

    # -----------------------------------------------------------------
    # 5️⃣ Triton launch – one program per (b, h, tile_i, tile_j)
    # -----------------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    # number of tiles in i / j
    num_i = triton.cdiv(N, BLOCK_M)
    num_j = triton.cdiv(N, BLOCK_N)

    # total programs = B * H * num_i * num_j
    total_progs = B * hidden_dim * num_i * num_j
    grid = (total_progs,)

    _trimul_outgoing_kernel[grid](
        left_fp16,
        right_fp16,
        out_fp16,
        B, N, hidden_dim,
        left_fp16.stride(0), left_fp16.stride(1),
        left_fp16.stride(2), left_fp16.stride(3),
        right_fp16.stride(0), right_fp16.stride(1),
        right_fp16.stride(2), right_fp16.stride(3),
        out_fp16.stride(0), out_fp16.stride(1),
        out_fp16.stride(2), out_fp16.stride(3),
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # -----------------------------------------------------------------
    # 6️⃣ Remaining PyTorch post‑processing
    # -----------------------------------------------------------------
    # back to (B,N,N,H)
    out = out_fp16.to(dtype).permute(0, 2, 3, 1).contiguous()   # (B,N,N,hidden)

    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"].to(dtype),
        bias=weights["to_out_norm.bias"].to(dtype),
    )

    out = out * out_gate                # broadcast over N,N
    out = F.linear(out, weights["to_out.weight"].to(dtype))   # (B,N,N,dim)

    return out
```

**Key points**

* Only the O(N³) contraction is off‑loaded to Triton; everything else stays in
  PyTorch, which is both simple and fast.
* The kernel works for any batch size, any hidden dimension, and any sequence
  length that fits in GPU memory.
* Mask handling is performed outside the kernel to keep the kernel logic
  straightforward.
* All arithmetic inside the kernel uses FP16 for bandwidth and FP32 for
  accumulation, matching the precision strategy of the reference implementation.
* The final output is returned as `torch.float32`, matching the original PyTorch
  module’s contract.
