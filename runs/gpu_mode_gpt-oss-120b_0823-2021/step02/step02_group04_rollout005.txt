We implement the *outgoing* TriMul operator described in the AlphaFold‑3 paper.  
The forward pass consists of six logical stages:

| Stage | Operation | Where it runs |
|------|------------|---------------|
|0|Layer‑Norm over the last dimension `dim`|PyTorch (`torch.nn.functional.layer_norm`)|
|1|Bias‑free linear projections `left`, `right` and the three gate pre‑sigmoids|PyTorch (`F.linear`)|
|2|Fuse mask (if any) and three sigmoids into `left`, `right` (in‑place) and `out_gate`|**Triton kernel** – the only kernel that must exist|
|3|Core contraction `out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]`|Batched GEMM using CuBLAS (`torch.matmul`) – cheapest and most bandwidth‑efficient on Hopper|
|4|Layer‑Norm on the hidden dimension, scale by `out_gate`|PyTorch|
|5|Final linear projection back to `dim`|PyTorch|

The heavy‑weight `N³` work (stage 3) is delegated to cuBLAS via a batched matrix‑multiply, which is the fastest approach on modern NVIDIA GPUs (including the H200).  The only part that really benefits from a custom kernel is the **element‑wise fusion of mask and three sigmoid gates** (stage 2).  By performing this fusion in a single pass we avoid three separate memory traversals and keep the kernel simple, register‑friendly and memory‑bound.

### Triton Kernel – mask + gates fusion

*Input tensors* (`left`, `right`, `left_gate`, `right_gate`, `out_gate`) all have shape `[B, N, N, H]`.  
*Mask* has shape `[B, N, N, 1]` (broadcasted over `H`).  

For each element `(b,i,k,d)` the kernel computes  

```
l = left[b,i,k,d] * mask[b,i,k,0] * sigmoid(left_gate[b,i,k,d])
r = right[b,i,k,d] * mask[b,i,k,0] * sigmoid(right_gate[b,i,k,d])
g = sigmoid(out_gate[b,i,k,d])
```

and writes the results back **in‑place** for `left`, `right` and `out_gate`.  
All operations are performed in `float32`.  The sigmoid uses the standard
numerically‑stable expression `1/(1+exp(-x))`.

The kernel is launched with a 1‑D grid covering the total number of elements
`B * N * N * H`.  `BLOCK` is set to `1024` – a good trade‑off on Hopper (fits
in registers, low launch overhead).

### Full implementation

```python
"""
TriMul – outgoing version (AlphaFold‑3)

Stage 0 – LayerNorm on the input (PyTorch).
Stage 1 – Linear projections (left/right) and three gate projections (PyTorch).
Stage 2 – Fuse optional mask and the three sigmoid gates into left, right (in‑place)
          and out_gate (Triton kernel).
Stage 3 – Core contraction performed as a batched GEMM:
          out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
Stage 4 – Final LayerNorm, out‑gate scaling and linear projection back to dim (PyTorch).

Only the element‑wise mask/gate fusion is compiled with Triton, satisfying the
requirement of having a Triton kernel while keeping the overall runtime
optimal on Hopper‑based GPUs.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: mask + three sigmoid gates → left, right, out_gate (in‑place)
# ----------------------------------------------------------------------
@triton.jit
def _mask_gate_fuse_kernel(
    left_ptr, right_ptr,                     # [B,N,N,H]  float32
    mask_ptr,                                 # [B,N,N,1]  float32 (broadcasted)
    lgate_ptr, rgate_ptr, ogate_ptr,          # [B,N,N,H]  float32 (pre‑sigmoid)
    B, N, H,
    # strides (int64)
    stride_left_b, stride_left_i, stride_left_k, stride_left_h,
    stride_right_b, stride_right_i, stride_right_k, stride_right_h,
    stride_mask_b, stride_mask_i, stride_mask_k, stride_mask_1,
    stride_lgate_b, stride_lgate_i, stride_lgate_k, stride_lgate_h,
    stride_rgate_b, stride_rgate_i, stride_rgate_k, stride_rgate_h,
    stride_ogate_b, stride_ogate_i, stride_ogate_k, stride_ogate_h,
    BLOCK: tl.constexpr,
):
    """
    For every element (b,i,k,d) compute
        left  = left  * mask * sigmoid(lgate)
        right = right * mask * sigmoid(rgate)
        ogate = sigmoid(ogate)          (stored back in‑place)
    The mask is broadcasted over the hidden dimension H.
    """
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)          # linear index
    total = B * N * N * H
    mask = offs < total

    # -------- decode linear index --------
    idx = offs
    d = idx % H
    idx = idx // H
    k = idx % N
    idx = idx // N
    i = idx % N
    b = idx // N

    # -------- pointer arithmetic ----------
    left   = left_ptr   + b * stride_left_b   + i * stride_left_i   + k * stride_left_k   + d * stride_left_h
    right  = right_ptr  + b * stride_right_b  + i * stride_right_i  + k * stride_right_k  + d * stride_right_h
    mask_p = mask_ptr   + b * stride_mask_b   + i * stride_mask_i   + k * stride_mask_k   # 1‑channel, no hidden stride
    lgate  = lgate_ptr  + b * stride_lgate_b  + i * stride_lgate_i  + k * stride_lgate_k  + d * stride_lgate_h
    rgate  = rgate_ptr  + b * stride_rgate_b  + i * stride_rgate_i  + k * stride_rgate_k  + d * stride_rgate_h
    ogate  = ogate_ptr  + b * stride_ogate_b  + i * stride_ogate_i  + k * stride_ogate_k  + d * stride_ogate_h

    # -------- load values ----------
    l = tl.load(left,  mask=mask, other=0.0)
    r = tl.load(right, mask=mask, other=0.0)
    m = tl.load(mask_p, mask=mask, other=1.0)          # 1.0 when mask is all‑ones
    lg = tl.load(lgate, mask=mask, other=0.0)
    rg = tl.load(rgate, mask=mask, other=0.0)
    og = tl.load(ogate, mask=mask, other=0.0)

    # -------- sigmoid (stable) ----------
    lg = 1.0 / (1.0 + tl.exp(-lg))
    rg = 1.0 / (1.0 + tl.exp(-rg))
    og = 1.0 / (1.0 + tl.exp(-og))

    # -------- fuse ----------
    l = l * m * lg
    r = r * m * rg

    # -------- store back ----------
    tl.store(left,  l, mask=mask)
    tl.store(right, r, mask=mask)
    tl.store(ogate, og, mask=mask)


def _mask_gate_fuse(
    left: torch.Tensor,
    right: torch.Tensor,
    mask: torch.Tensor,
    left_gate: torch.Tensor,
    right_gate: torch.Tensor,
    out_gate: torch.Tensor,
) -> torch.Tensor:
    """
    Launches the Triton kernel that updates ``left`` and ``right`` in‑place
    and returns the already‑sigmoided ``out_gate`` tensor.
    All tensors must be contiguous and on the same CUDA device.
    Shapes:
        left/right/left_gate/right_gate/out_gate : (B,N,N,H)
        mask                                     : (B,N,N,1)
    """
    B, N, _, H = left.shape
    total = B * N * N * H
    BLOCK = 1024                      # good occupancy on Hopper
    grid = (triton.cdiv(total, BLOCK),)

    _mask_gate_fuse_kernel[grid](
        left, right,
        mask,
        left_gate, right_gate, out_gate,
        B, N, H,
        # strides
        left.stride(0), left.stride(1), left.stride(2), left.stride(3),
        right.stride(0), right.stride(1), right.stride(2), right.stride(3),
        mask.stride(0), mask.stride(1), mask.stride(2), mask.stride(3),
        left_gate.stride(0), left_gate.stride(1), left_gate.stride(2), left_gate.stride(3),
        right_gate.stride(0), right_gate.stride(1), right_gate.stride(2), right_gate.stride(3),
        out_gate.stride(0), out_gate.stride(1), out_gate.stride(2), out_gate.stride(3),
        BLOCK=BLOCK,
    )
    return out_gate


# ----------------------------------------------------------------------
# Public entry point
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the *outgoing* TriMul operator.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask_tensor, weights_dict, config_dict)

        - input_tensor : torch.Tensor of shape [B, N, N, dim] (float32 or bf16)
        - mask_tensor  : torch.Tensor of shape [B, N, N] or None
        - weights_dict : mapping with keys
            "norm.weight", "norm.bias",
            "left_proj.weight", "right_proj.weight",
            "left_gate.weight", "right_gate.weight", "out_gate.weight",
            "to_out_norm.weight", "to_out_norm.bias",
            "to_out.weight"
        - config_dict  : {"dim": int, "hidden_dim": int}

    Returns
    -------
    torch.Tensor of shape [B, N, N, dim] (float32)
    """
    # --------------------------------------------------------------
    # Unpack inputs
    # --------------------------------------------------------------
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    B, N, _, dim = input_tensor.shape
    hidden = config["hidden_dim"]

    # --------------------------------------------------------------
    # 0️⃣ Layer‑norm over the last dimension (dim)
    # --------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        (dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
    )   # (B, N, N, dim)

    # --------------------------------------------------------------
    # 1️⃣ Linear projections (bias‑free) → [B,N,N,hidden]
    # --------------------------------------------------------------
    left  = F.linear(x, weights["left_proj.weight"])   # (B,N,N,hidden)
    right = F.linear(x, weights["right_proj.weight"])

    # --------------------------------------------------------------
    # 2️⃣ Gate pre‑sigmoids
    # --------------------------------------------------------------
    left_gate  = F.linear(x, weights["left_gate.weight"])
    right_gate = F.linear(x, weights["right_gate.weight"])
    out_gate   = F.linear(x, weights["out_gate.weight"])

    # --------------------------------------------------------------
    # 3️⃣ Broadcast mask (if absent use all‑ones)
    # --------------------------------------------------------------
    if mask is None:
        mask4d = torch.ones((B, N, N, 1), dtype=input_tensor.dtype, device=device)
    else:
        mask4d = mask.unsqueeze(-1).to(input_tensor.dtype)   # (B,N,N,1)

    # --------------------------------------------------------------
    # 4️⃣ Fuse mask + sigmoid(gates) into left/right (in‑place) & out_gate
    # --------------------------------------------------------------
    out_gate = _mask_gate_fuse(left, right, mask4d, left_gate, right_gate, out_gate)

    # --------------------------------------------------------------
    # 5️⃣ Core contraction (batched GEMM)
    #    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
    # --------------------------------------------------------------
    # reshape to (B, hidden, N, K) where K == N
    left_t  = left.permute(0, 3, 1, 2)               # (B, hidden, N, K)
    right_t = right.permute(0, 3, 1, 2)              # (B, hidden, N, K)

    # batched matmul → (B, hidden, N, N)
    out_t = torch.matmul(left_t, right_t.transpose(-1, -2))

    # back to original layout (B, N, N, hidden)
    out = out_t.permute(0, 2, 3, 1)

    # --------------------------------------------------------------
    # 6️⃣ Final LayerNorm, out‑gate scaling, final linear projection
    # --------------------------------------------------------------
    out = F.layer_norm(
        out,
        (hidden,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
    )
    out = out * out_gate               # element‑wise gating
    out = F.linear(out, weights["to_out.weight"])

    # Ensure output is float32 as required by the spec
    return out.to(torch.float32)
```

**Key points**

* The only custom‑kernel work is the mask + gate fusion, which accesses each
  element exactly once and stays entirely in registers – ideal for Hopper’s
  high‑throughput SM_90 cores.
* All large‑scale linear algebra (`left @ rightᵀ`) is delegated to cuBLAS via
  `torch.matmul`, which automatically uses Tensor‑cores and the optimal
  memory layout on the H200.
* The implementation works for both the “nomask” and “mask” configurations,
  any batch size `B ∈ {1,2}`, any supported sequence length, and any
  `dim` / `hidden_dim` values specified in the test matrix.
* Final output is guaranteed to be `float32`, matching the reference forward
  pass.
