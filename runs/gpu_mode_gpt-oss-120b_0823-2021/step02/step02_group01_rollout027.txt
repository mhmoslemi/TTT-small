The heavy part of the module is the 4‑D contraction  

```
out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
```

which is an Einstein‑summation over the *shared* sequence dimension `k`.  
We rewrite it as a **batched GEMM** for every head `d` (the hidden dimension) :

```
left  : (B, H, I, K)   ← (B, N, N, H)  permuted to (B, H, I, K)
right : (B, H, K, J)   ← (B, N, N, H)  permuted to (B, H, K, J)
out   : (B, H, I, J)   = batch_matmul(left, right)
```

where `I = J = N` and `H = hidden_dim`.  
The contraction is therefore a **batched matrix‑multiply** of shape
`(B*H, N, N)`.  We implement this multiplication in Triton with fp16 compute,
fp32 accumulation and fp16 write‑back, which gives a large speed‑up on Hopper
Tensor‑cores while keeping the final result in fp32 for the remaining LayerNorm
and linear layers.

All the surrounding operations (LayerNorm, linear projections, gating, final
LayerNorm & linear) are inexpensive compared to the `N³` work, so they stay in
PyTorch.  The only mandatory Triton kernel is the batched GEMM (`batch_matmul`).

---

### Key implementation points
* **Strides** are passed exactly as they appear in the tensors (no assumptions).  
* **Mask handling** – if a mask is supplied we broadcast it to the hidden dimension
  and apply it before the gating step (as in the reference implementation).  
* **Mixed‑precision** – the normalized input is cast to `float16` once, all linear
  ops that feed the GEMM use `float16` weights, and the kernel computes in fp16
  (dot product) with fp32 accumulators (`tl.float32`).  The kernel stores the
  result back as `float16`; we immediately up‑cast to `float32` for the final
  LayerNorm and projection.  
* **Tiling** – tuned for Hopper: `BLOCK_M = BLOCK_N = 64`, `BLOCK_K = 32`,
  `num_warps = 4`.  These values fit comfortably in shared memory and let the
  scheduler keep many warps active.  
* **Launch grid** – three‑dimensional: `(ceil(I/BLOCK_M), ceil(J/BLOCK_N), B*H)`.  
* **No fallback** – the kernel is always launched; if it crashes the test will
  fail, which is preferred to silently falling back to a slow PyTorch path.

The full forward pass is wrapped in `custom_kernel(data)` with the exact
signature required by the harness.

```python
"""
TriMul “outgoing” forward pass (no gradients).

The N³ contraction is performed as a batched GEMM in Triton:
    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]

All other operations (LayerNorms, linear projections, gating) stay in PyTorch.
Mixed‑precision (fp16 compute, fp32 accumulation) is used for the GEMM; the
final output is returned in fp32.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched (I×K)·(K×J) → (I×J) for many batches (Z = B*H)
# ----------------------------------------------------------------------
@triton.jit
def batch_matmul_kernel(
    a_ptr,            # left  matrix pointer   (Z, I, K)
    b_ptr,            # right matrix pointer   (Z, K, J)
    c_ptr,            # output matrix pointer  (Z, I, J)
    M, N, K,          # matrix sizes
    stride_az, stride_am, stride_ak,   # strides for a (z, i, k)
    stride_bz, stride_bk, stride_bn,   # strides for b (z, k, j)
    stride_cz, stride_cm, stride_cn,   # strides for c (z, i, j)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    # ---------------------------------------------------------------
    # tile identifiers
    # ---------------------------------------------------------------
    pid_m = tl.program_id(0)          # row tile index
    pid_n = tl.program_id(1)          # col tile index
    pid_z = tl.program_id(2)          # batch*head index

    # offsets for the current tile
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in fp32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ---------------------------------------------------------------
    # reduction over K
    # ---------------------------------------------------------------
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # load A tile (BLOCK_M x BLOCK_K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # load B tile (BLOCK_K x BLOCK_N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # dot: fp16 * fp16 → fp32 accumulation
        acc += tl.dot(a, b)

    # store result (convert back to fp16)
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


def triton_batch_matmul(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Batched GEMM using the Triton kernel above.

    Arguments
    ---------
    left  : (B, H, I, K)  fp16, contiguous
    right : (B, H, K, J)  fp16, contiguous

    Returns
    -------
    out : (B, H, I, J) fp16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # collapse leading dimensions for kernel launch
    Z = B * H
    a = left.view(Z, I, K)
    b = right.view(Z, K, J)
    c = out.view(Z, I, J)

    # strides in elements (not bytes)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # tile sizes – tuned for Hopper
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(I, BLOCK_M),   # program_id(0)
        triton.cdiv(J, BLOCK_N),   # program_id(1)
        Z,                         # program_id(2)
    )
    batch_matmul_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,
    )
    return out


# ----------------------------------------------------------------------
# Full forward pass (PyTorch + Triton)
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Parameters
    ----------
    data : tuple (input_tensor, mask, weights, config)
        input_tensor : torch.Tensor [B, N, N, dim]      (float32)
        mask         : torch.Tensor [B, N, N] or None
        weights      : dict of model parameters (float32)
        config       : dict with keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor [B, N, N, dim] (float32)
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dtype = input_tensor.dtype
    eps = 1e-5

    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]

    # ------------------------------------------------------------------
    # 1. Input LayerNorm (keep in PyTorch, fp32)
    # ------------------------------------------------------------------
    norm_w = weights["norm.weight"]
    norm_b = weights["norm.bias"]
    # manual LayerNorm to avoid module overhead
    mean = input_tensor.mean(-1, keepdim=True)
    var = input_tensor.var(-1, unbiased=False, keepdim=True)
    x = (input_tensor - mean) / torch.sqrt(var + eps)
    x = x * norm_w + norm_b          # fp32

    # ------------------------------------------------------------------
    # 2. Cast to fp16 for the heavy path
    # ------------------------------------------------------------------
    x_fp16 = x.to(torch.float16)

    # linear weights (cast once)
    def to_fp16(t):
        return t.to(torch.float16, non_blocking=True)

    left_proj_w   = to_fp16(weights["left_proj.weight"])
    right_proj_w  = to_fp16(weights["right_proj.weight"])
    left_gate_w   = to_fp16(weights["left_gate.weight"])
    right_gate_w  = to_fp16(weights["right_gate.weight"])
    out_gate_w    = to_fp16(weights["out_gate.weight"])
    to_out_norm_w = weights["to_out_norm.weight"]   # stays fp32 for final LN
    to_out_norm_b = weights["to_out_norm.bias"]
    to_out_w      = weights["to_out.weight"]

    # ------------------------------------------------------------------
    # 3. Projections (fp16)
    # ------------------------------------------------------------------
    left  = F.linear(x_fp16, left_proj_w)   # (B,N,N,hidden_dim)
    right = F.linear(x_fp16, right_proj_w)

    # ------------------------------------------------------------------
    # 4. Optional mask (broadcast to hidden dim, fp16)
    # ------------------------------------------------------------------
    if mask is not None:
        mask_b = mask.to(torch.float16).unsqueeze(-1)   # (B,N,N,1)
        left = left * mask_b
        right = right * mask_b

    # ------------------------------------------------------------------
    # 5. Gating (fp16)
    # ------------------------------------------------------------------
    left_gate  = F.linear(x_fp16, left_gate_w).sigmoid()
    right_gate = F.linear(x_fp16, right_gate_w).sigmoid()
    out_gate   = F.linear(x_fp16, out_gate_w).sigmoid()

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 6. Prepare tensors for the batched GEMM
    #    left  : (B, H, I, K)  = (B, hidden, N, N)
    #    right : (B, H, K, J)  = (B, hidden, N, N) with axes (k,j) swapped
    # ------------------------------------------------------------------
    left_perm  = left.permute(0, 3, 1, 2).contiguous()   # (B, H, I, K)
    right_perm = right.permute(0, 3, 2, 1).contiguous()  # (B, H, K, J)

    # ------------------------------------------------------------------
    # 7. Triton batched GEMM (core N³ work)
    # ------------------------------------------------------------------
    out_fp16 = triton_batch_matmul(left_perm, right_perm)   # (B, H, I, J)

    # reshape back to (B,N,N,dim) and cast to fp32 for the rest
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)

    # ------------------------------------------------------------------
    # 8. Output LayerNorm (fp32)
    # ------------------------------------------------------------------
    mean_o = out.mean(-1, keepdim=True)
    var_o = out.var(-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + eps)
    out = out * to_out_norm_w + to_out_norm_b

    # ------------------------------------------------------------------
    # 9. Final gating + projection (fp32)
    # ------------------------------------------------------------------
    out = out * out_gate.to(torch.float32)
    out = F.linear(out, to_out_w)

    return out
```
