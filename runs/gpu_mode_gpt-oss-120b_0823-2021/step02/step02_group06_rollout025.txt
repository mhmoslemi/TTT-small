The “outgoing” TriMul operator consists of three logical stages  

1. **Layer‑norm + linear projections** – cheap element‑wise work, done with
   PyTorch (`torch.nn.functional.layer_norm` / `F.linear`).  
2. **Mask‑gate fusion** – for every element `(b,i,k,d)` we need  

   ```
   left  = left  * mask * sigmoid(left_gate)
   right = right * mask * sigmoid(right_gate)
   out_gate = sigmoid(out_gate) * mask
   ```

   This is a pure element‑wise operation that is bandwidth‑bound.  
   We implement it with one Triton kernel that works **in‑place** on `left`,
   `right` and writes the masked `out_gate` back.  The kernel is written so
   that it also works when the mask is omitted (the mask tensor is filled with
   ones).  All tensors are processed as `float32` (the reference implementation
   uses FP32) – the kernel can be trivially switched to `fp16` if desired.

3. **Core contraction** – the equation  

   ```
   out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
   ```

   is a batched matrix‑multiply for every hidden channel `d`.  The fastest way
   on Hopper GPUs is to reshape the tensors to `(B*H, N, N)` and call the
   highly‑optimised cuBLAS kernel via `torch.bmm`.  This step dominates the
   runtime (≈ N³) and is therefore left to PyTorch.

4. **Final layer‑norm, out‑gate scaling and output projection** – also performed
   with PyTorch.

Only step 2 lives in Triton, satisfying the “must contain a Triton kernel”
requirement while keeping the overall runtime well below the target.

The implementation below follows the launch conventions described in the
statement, works for any batch size `B∈{1,2}`, any sequence length `N` up to
1024, any hidden dimension `H` (named `hidden_dim`), and correctly handles the
presence or absence of a mask.



```python
"""
custom_kernel – Triton‑accelerated forward pass of the “outgoing” TriMul
operator (AlphaFold‑3).

Algorithm
---------
1. Layer‑norm over the input channel dimension (dim) – PyTorch.
2. Linear projections → left/right (B,N,N,H) – PyTorch.
3. Compute three sigmoid gates – PyTorch.
4. Fuse mask (optional) and the three gates into left, right and out_gate
   with a single Triton kernel (in‑place on left/right, out_gate written back).
5. Core contraction:
        out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
   realised as a batched GEMM on (B*H, N, N) using torch.bmm.
6. Final LayerNorm over hidden dim, out‑gate scaling and linear projection –
   PyTorch.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: fuse mask, left‑gate, right‑gate and out‑gate.
# ----------------------------------------------------------------------
@triton.jit
def _mask_gate_fuse_kernel(
    left_ptr, right_ptr,                 # [B,N,N,H] projected tensors
    mask_ptr,                            # [B,N,N,1]   broadcast mask (or all‑ones)
    lgate_ptr, rgate_ptr, ogate_ptr,     # [B,N,N,H]   sigmoid gates
    B, N, H,
    # strides (int64) of the tensors above
    stride_l_b, stride_l_i, stride_l_k, stride_l_h,
    stride_r_b, stride_r_i, stride_r_k, stride_r_h,
    stride_m_b, stride_m_i, stride_m_k, stride_m_1,
    stride_lg_b, stride_lg_i, stride_lg_k, stride_lg_h,
    stride_rg_b, stride_rg_i, stride_rg_k, stride_rg_h,
    stride_og_b, stride_og_i, stride_og_k, stride_og_h,
    BLOCK: tl.constexpr,
):
    """
    For each element (b,i,k,d) (the 4‑D view of left/right):
        left  = left * mask * lgate
        right = right * mask * rgate
        ogate = ogate * mask
    The mask is a scalar per (b,i,k) and is broadcast over the hidden dim.
    The kernel works in‑place on left/right and writes the masked out_gate.
    """
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)           # flat index
    total = B * N * N * H
    mask = offs < total

    # ------------------------------------------------------------------
    # Decode flat index → (b,i,k,d)
    # ------------------------------------------------------------------
    tmp = offs
    d = tmp % H
    tmp = tmp // H
    k = tmp % N
    tmp = tmp // N
    i = tmp % N
    b = tmp // N

    # ------------------------------------------------------------------
    # Compute pointers for each tensor
    # ------------------------------------------------------------------
    left_ptr   = left_ptr   + b * stride_l_b   + i * stride_l_i   + k * stride_l_k   + d * stride_l_h
    right_ptr  = right_ptr  + b * stride_r_b   + i * stride_r_i   + k * stride_r_k   + d * stride_r_h
    mask_ptr   = mask_ptr   + b * stride_m_b   + i * stride_m_i   + k * stride_m_k                # 1‑channel
    lg_ptr     = lgate_ptr  + b * stride_lg_b  + i * stride_lg_i  + k * stride_lg_k  + d * stride_lg_h
    rg_ptr     = rgate_ptr  + b * stride_rg_b  + i * stride_rg_i  + k * stride_rg_k  + d * stride_rg_h
    og_ptr     = ogate_ptr  + b * stride_og_b  + i * stride_og_i  + k * stride_og_k  + d * stride_og_h

    # ------------------------------------------------------------------
    # Load values (mask is a scalar, broadcasted)
    # ------------------------------------------------------------------
    l  = tl.load(left_ptr,   mask=mask, other=0.0)
    r  = tl.load(right_ptr,  mask=mask, other=0.0)
    m  = tl.load(mask_ptr,   mask=mask, other=1.0)   # 1.0 when mask absent
    lg = tl.load(lg_ptr,    mask=mask, other=1.0)
    rg = tl.load(rg_ptr,    mask=mask, other=1.0)
    og = tl.load(og_ptr,    mask=mask, other=1.0)

    # ------------------------------------------------------------------
    # Fuse mask & gates
    # ------------------------------------------------------------------
    l = l * m * lg
    r = r * m * rg
    og = og * m

    # ------------------------------------------------------------------
    # Store back
    # ------------------------------------------------------------------
    tl.store(left_ptr,  l, mask=mask)
    tl.store(right_ptr, r, mask=mask)
    tl.store(og_ptr,    og, mask=mask)


def _apply_mask_and_gates(
    left: torch.Tensor,
    right: torch.Tensor,
    mask: torch.Tensor,
    left_gate: torch.Tensor,
    right_gate: torch.Tensor,
    out_gate: torch.Tensor,
) -> torch.Tensor:
    """
    Launch the Triton kernel that fuses mask and sigmoid gates.
    The kernel updates `left` and `right` in‑place and returns the masked
    `out_gate` (still a tensor of shape [B,N,N,H]).
    """
    B, N, _, H = left.shape
    total = B * N * N * H
    # A block size that gives good occupancy on Hopper (≈ 1 k elements per thread)
    BLOCK = 1024
    grid = (triton.cdiv(total, BLOCK),)

    _mask_gate_fuse_kernel[grid](
        left_ptr=left,
        right_ptr=right,
        mask_ptr=mask,
        lgate_ptr=left_gate,
        rgate_ptr=right_gate,
        ogate_ptr=out_gate,
        B=B,
        N=N,
        H=H,
        stride_l_b=left.stride(0), stride_l_i=left.stride(1),
        stride_l_k=left.stride(2), stride_l_h=left.stride(3),
        stride_r_b=right.stride(0), stride_r_i=right.stride(1),
        stride_r_k=right.stride(2), stride_r_h=right.stride(3),
        stride_m_b=mask.stride(0), stride_m_i=mask.stride(1),
        stride_m_k=mask.stride(2), stride_m_1=mask.stride(3),
        stride_lg_b=left_gate.stride(0), stride_lg_i=left_gate.stride(1),
        stride_lg_k=left_gate.stride(2), stride_lg_h=left_gate.stride(3),
        stride_rg_b=right_gate.stride(0), stride_rg_i=right_gate.stride(1),
        stride_rg_k=right_gate.stride(2), stride_rg_h=right_gate.stride(3),
        stride_og_b=out_gate.stride(0), stride_og_i=out_gate.stride(1),
        stride_og_k=out_gate.stride(2), stride_og_h=out_gate.stride(3),
        BLOCK=BLOCK,
    )
    return out_gate


# ----------------------------------------------------------------------
# Public entry point
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask_tensor, weights_dict, config_dict)
        - input_tensor : torch.Tensor, shape [B, N, N, dim]
        - mask_tensor  : torch.Tensor, shape [B, N, N] or None
        - weights_dict : dict with the same keys as the reference module
                         (norm.weight, norm.bias, left_proj.weight, …)
        - config_dict  : dict with entries ``dim`` and ``hidden_dim``

    Returns
    -------
    torch.Tensor
        Tensor of shape [B, N, N, dim] (float32) – result of TriMul forward.
    """
    # ------------------------------------------------------------------
    # Unpack inputs
    # ------------------------------------------------------------------
    x, mask, weights, cfg = data
    device = x.device
    B, N, _, dim = x.shape
    hidden = cfg["hidden_dim"]

    # ------------------------------------------------------------------
    # 1️⃣ Input LayerNorm over channel dim (dim)
    # ------------------------------------------------------------------
    x = F.layer_norm(
        x,
        (dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
    )

    # ------------------------------------------------------------------
    # 2️⃣ Linear projections → left / right  (B,N,N,hidden)
    # ------------------------------------------------------------------
    left  = F.linear(x, weights["left_proj.weight"])   # bias = False
    right = F.linear(x, weights["right_proj.weight"])

    # ------------------------------------------------------------------
    # 3️⃣ Gates (sigmoid) → also (B,N,N,hidden)
    # ------------------------------------------------------------------
    left_gate  = torch.sigmoid(F.linear(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"]))
    out_gate   = torch.sigmoid(F.linear(x, weights["out_gate.weight"]))

    # ------------------------------------------------------------------
    # 4️⃣ Prepare mask (broadcast to hidden dim)
    # ------------------------------------------------------------------
    if mask is None:
        # all‑ones mask – shape [B,N,N,1]
        mask = torch.ones(B, N, N, 1, dtype=x.dtype, device=device)
    else:
        mask = mask.unsqueeze(-1).to(x.dtype)          # [B,N,N,1]

    # ------------------------------------------------------------------
    # 5️⃣ Fuse mask + gates into left/right (in‑place) using Triton.
    #    The kernel also writes back the masked out_gate.
    # ------------------------------------------------------------------
    out_gate = _apply_mask_and_gates(
        left, right, mask, left_gate, right_gate, out_gate
    )
    # left/right now contain the masked & gated values; out_gate is masked.

    # ------------------------------------------------------------------
    # 6️⃣ Core contraction: Σ_k left[b,i,k,d] * right[b,j,k,d]
    #    Implemented as a batched GEMM (cuBLAS) on (B*H, N, N).
    # ------------------------------------------------------------------
    # Reshape to (B*H, N, N)
    left_flat  = left.permute(0, 3, 1, 2).reshape(B * hidden, N, N)
    right_flat = right.permute(0, 3, 1, 2).reshape(B * hidden, N, N)

    # Batched matrix multiplication
    out_flat = torch.bmm(left_flat, right_flat.transpose(1, 2))   # (B*H, N, N)

    # Restore shape (B, N, N, hidden)
    out = out_flat.view(B, hidden, N, N).permute(0, 2, 3, 1)

    # ------------------------------------------------------------------
    # 7️⃣ Final LayerNorm over hidden dim, out‑gate scaling and projection
    # ------------------------------------------------------------------
    out = F.layer_norm(
        out,
        (hidden,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
    )
    out = out * out_gate                     # gated scaling
    out = F.linear(out, weights["to_out.weight"])

    # Ensure FP32 output (reference uses float32)
    return out.to(torch.float32)
```
