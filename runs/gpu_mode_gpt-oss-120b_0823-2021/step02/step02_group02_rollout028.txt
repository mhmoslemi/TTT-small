"""
tri_mul_outgoing – “outgoing” TriMul from AlphaFold‑3.

The heavy O(N³) contraction

    out[b, h, i, j] = Σ_k left[b, h, i, k] * right[b, h, j, k]

is performed by a small Triton kernel that tiles the (i, j) plane while
accumulating over k.  All other operations (LayerNorm, linear projections,
gating, final LayerNorm + linear) are done in PyTorch because they are
memory‑bound and already heavily optimized in cudnn/cuBLAS.  The kernel works
in FP16 with FP32 accumulation and writes the result back as FP16; the host
code casts the result to FP32 before the remaining PyTorch ops.

The implementation follows the “block‑GEMM” pattern used in the Triton
documentation:

* one program instance processes a tile of size (BLOCK_M, BLOCK_N) for a
  particular (batch, head) pair.
* the k‑dimension is streamed in chunks of BLOCK_K.
* masks are applied only for the out‑of‑bounds part of the tile.
* strides are passed explicitly – this is the only place where we need a
  custom kernel, satisfying the requirement of “at least part of the
  operations in a kernel”.

The wrapper `custom_kernel` mirrors the reference PyTorch `TriMul` forward
method (no gradients) and returns a tensor of shape `[B, N, N, dim]`
(dtype = float32).
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict, Any


# -------------------------------------------------------------------------
# Triton kernel: tiled batched GEMM for one head (hidden_dim slice)
# -------------------------------------------------------------------------
@triton.jit
def _trimul_outgoing_kernel(
    left_ptr,          # const fp16*  [B, H, N, N]   (row‑major)
    right_ptr,         # const fp16*  [B, H, N, N]
    out_ptr,           #       fp16*  [B, H, N, N]
    B, N, H,           # int scalars
    stride_lbh, stride_lbh1, stride_lbn, stride_lbk,   # strides of left
    stride_rbh, stride_rbh1, stride_rbn, stride_rbk,   # strides of right
    stride_obh, stride_obh1, stride_obn, stride_obk,   # strides of out
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Compute a tile of the contraction
        out[b, h, i, j] = Σ_k left[b, h, i, k] * right[b, h, j, k]

    The layout is [B, H, N, N] (contiguous, row‑major).  The kernel processes
    a (BLOCK_M × BLOCK_N) tile of the (i, j) plane for a fixed (b, h) pair
    and accumulates over K in chunks of BLOCK_K.
    """
    pid = tl.program_id(0)                     # linear id over (b, h, tile_i, tile_j)

    # -----------------------------------------------------------------
    # decode pid → (b, h, tile_i, tile_j)
    # -----------------------------------------------------------------
    num_h = H
    num_m = tl.cdiv(N, BLOCK_M)                # tiles along i
    num_n = tl.cdiv(N, BLOCK_N)                # tiles along j

    tile_j = pid % num_n
    pid //= num_n
    tile_i = pid % num_m
    pid //= num_m
    h = pid % num_h
    b = pid // num_h

    # -----------------------------------------------------------------
    # offsets for this tile
    # -----------------------------------------------------------------
    offs_i = tile_i * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_j = tile_j * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_i = offs_i < N
    mask_j = offs_j < N

    # accumulator in FP32 (better numeric stability)
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # -----------------------------------------------------------------
    # stream over K
    # -----------------------------------------------------------------
    for kk in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = kk * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # left[b, h, i, k]  → shape (M, K)
        l_ptr = (
            left_ptr
            + b * stride_lbh
            + h * stride_lbh1
            + offs_i[:, None] * stride_lbn
            + offs_k[None, :] * stride_lbk
        )
        l = tl.load(
            l_ptr,
            mask=mask_i[:, None] & mask_k[None, :],
            other=0.0,
        ).to(tl.float32)

        # right[b, h, j, k] (need its transpose for the dot)
        # we load (k, j) so that a dot with l (M×K) produces (M×N)
        r_ptr = (
            right_ptr
            + b * stride_rbh
            + h * stride_rbh1
            + offs_k[:, None] * stride_rbk
            + offs_j[None, :] * stride_rbn
        )
        r = tl.load(
            r_ptr,
            mask=mask_k[:, None] & mask_j[None, :],
            other=0.0,
        ).to(tl.float32)

        # matrix‑multiply‑accumulate
        acc += tl.dot(l, r)                      # (M,K) @ (K,N) → (M,N)

    # -----------------------------------------------------------------
    # write result back as fp16
    # -----------------------------------------------------------------
    out_ptrs = (
        out_ptr
        + b * stride_obh
        + h * stride_obh1
        + offs_i[:, None] * stride_obn
        + offs_j[None, :] * stride_obk
    )
    tl.store(
        out_ptrs,
        acc.to(tl.float16),
        mask=mask_i[:, None] & mask_j[None, :],
    )


# -------------------------------------------------------------------------
# Host side wrapper – matches the signature required by the evaluation harness
# -------------------------------------------------------------------------
def custom_kernel(
    data: Tuple[
        torch.Tensor,          # input tensor   [B, N, N, dim]
        torch.Tensor,          # mask tensor    [B, N, N]   (or None)
        Dict[str, torch.Tensor],
        Dict[str, Any],
    ]
) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.
    Returns:
        Tensor of shape [B, N, N, dim] (float32)
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dtype = torch.float32

    B, N, _, dim = input_tensor.shape          # input layout: (B, N, N, dim)
    hidden_dim = config["hidden_dim"]          # H in the paper

    # -----------------------------------------------------------------
    # 1️⃣ LayerNorm over the channel dimension (dim)
    # -----------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        normalized_shape=(dim,),
        weight=weights["norm.weight"].to(dtype),
        bias=weights["norm.bias"].to(dtype),
    )

    # -----------------------------------------------------------------
    # 2️⃣ Linear projections (bias‑free)
    # -----------------------------------------------------------------
    left = F.linear(x, weights["left_proj.weight"].to(dtype))   # (B,N,N,hidden)
    right = F.linear(x, weights["right_proj.weight"].to(dtype))

    # -----------------------------------------------------------------
    # 3️⃣ Optional mask (broadcasted on the hidden dim)
    # -----------------------------------------------------------------
    if mask is not None:
        mask_ = mask.unsqueeze(-1)        # (B,N,N,1)
        left = left * mask_
        right = right * mask_

    # -----------------------------------------------------------------
    # 4️⃣ Gating – sigmoid on linear projections of the *pre‑norm* tensor
    # -----------------------------------------------------------------
    left_gate = torch.sigmoid(F.linear(x, weights["left_gate.weight"].to(dtype)))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"].to(dtype)))
    out_gate = torch.sigmoid(F.linear(x, weights["out_gate.weight"].to(dtype)))

    left = left * left_gate
    right = right * right_gate

    # -----------------------------------------------------------------
    # 5️⃣ Rearrange to [B, H, N, N] and cast to fp16 for the kernel
    # -----------------------------------------------------------------
    # (B,N,N,H) → (B,H,N,N)
    left = left.permute(0, 3, 1, 2).contiguous()
    right = right.permute(0, 3, 1, 2).contiguous()
    left_fp16 = left.to(torch.float16)
    right_fp16 = right.to(torch.float16)

    out_fp16 = torch.empty_like(left_fp16)   # (B, H, N, N) fp16 buffer

    # -----------------------------------------------------------------
    # 6️⃣ Triton launch – tile sizes tuned for Hopper (SM90)
    # -----------------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    # grid: one program per (b, h, tile_i, tile_j)
    grid_m = triton.cdiv(N, BLOCK_M)
    grid_n = triton.cdiv(N, BLOCK_N)
    grid = (B * hidden_dim * grid_m * grid_n,)

    _trimul_outgoing_kernel[grid](
        left_fp16,
        right_fp16,
        out_fp16,
        B,
        N,
        hidden_dim,
        # strides of left tensor
        left_fp16.stride(0),   # stride over B
        left_fp16.stride(1),   # stride over H
        left_fp16.stride(2),   # stride over N (row)
        left_fp16.stride(3),   # stride over N (col)
        # strides of right tensor
        right_fp16.stride(0),
        right_fp16.stride(1),
        right_fp16.stride(2),
        right_fp16.stride(3),
        # strides of output tensor
        out_fp16.stride(0),
        out_fp16.stride(1),
        out_fp16.stride(2),
        out_fp16.stride(3),
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # -----------------------------------------------------------------
    # 7️⃣ Back‑to original layout (B, N, N, H) and continue in PyTorch
    # -----------------------------------------------------------------
    out = out_fp16.to(dtype).permute(0, 2, 3, 1).contiguous()   # (B,N,N,hidden)

    # -----------------------------------------------------------------
    # 8️⃣ Output LayerNorm + gating
    # -----------------------------------------------------------------
    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"].to(dtype),
        bias=weights["to_out_norm.bias"].to(dtype),
    )
    out = out * out_gate                     # broadcast over (N,N)

    # -----------------------------------------------------------------
    # 9️⃣ Final linear back to original dim
    # -----------------------------------------------------------------
    out = F.linear(out, weights["to_out.weight"].to(dtype))

    return out
```

**Explanation of the lesson analysis**

* **Lesson 1 (shared‑memory limit)** – the kernel uses modest tile sizes
  (`64 × 64 × 32`) which keep shared‑memory well under the H200 limit; no extra
  `num_stages` is needed.

* **Lesson 2 (delegate to cuBLAS)** – while a pure `torch.bmm`‑based solution
  would be fast, the problem statement requires *some* computation to be done
  inside a Triton kernel.  We therefore keep the dominant contraction in a
  custom kernel and leave the surrounding linear/LN work to PyTorch, achieving
  a good balance between speed and the mandatory kernel usage.

* **Lesson 3 (matching dtypes for batched GEMM)** – both inputs to the kernel
  are cast to `float16`; accumulation is performed in `float32` and the result
  is stored back as `float16`.  This follows the best practice for Tensor‑core
  utilisation on Hopper.

The final implementation satisfies all constraints, runs entirely on the
GPU, and returns a `float32` tensor of shape `[B, N, N, dim]`.
