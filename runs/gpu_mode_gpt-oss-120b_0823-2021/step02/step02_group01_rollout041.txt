The “outgoing” TriMul operator consists of three stages that dominate the runtime:

1. **Layer‑norm & linear projections** – cheap, keep them in PyTorch.
2. **Masking & gating** – also cheap, stay in PyTorch.
3. **Core N³ contraction**  

   ```
   out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
   ```

   This is a batched matrix‑multiply of shape  
   `(B, H, I, K)  @  (B, H, K, J) → (B, H, I, J)`  
   where `H = hidden_dim`, `I = J = N`, `K = N`.  
   The contraction is the only part that needs to be accelerated.

We implement the contraction with a **custom Triton kernel** that performs a
batched GEMM (`I×K` · `K×J`).  The kernel works in **FP16** (Tensor‑core
friendly) while accumulating in **FP32** for numerical stability.  All
remaining operations (LayerNorm, gating, final LayerNorm + linear) are kept in
PyTorch to avoid the overhead of moving many small tensors in‑and‑out of the
kernel.

The implementation follows the “lessons learned” from the previous
attempts:

| Lesson | What we do (or deliberately do not do) |
|--------|----------------------------------------|
| 1 Limit shared memory | Tile sizes `BLOCK_M = BLOCK_N = 64`, `BLOCK_K = 32` – fits comfortably in the SM‑90 shared‑memory budget. |
| 2 Delegate N³ to cuBLAS | **We do not** rely on cuBLAS because the contraction carries the extra hidden‑dim `H`. A single batched GEMM per head is required, which Triton handles efficiently. |
| 3 Match dtypes | Both operands are cast to **FP16** before the kernel; accumulation is FP32. The result is cast back to FP32 for the rest of the pipeline. |
| 4 Stride handling | Strides are read exactly from the tensors (4‑D for the batched view) to avoid mismatches. |
| 5 No fallback | The kernel is always launched; a failure will raise an error, making debugging easier. |

The kernel is launched with a 3‑D grid: `(num_tiles_M, num_tiles_N, B*H)`.  
Each program instance computes a `BLOCK_M × BLOCK_N` tile of the output
matrix for a single `(batch, head)` pair.

The full `custom_kernel` function:

* extracts the weight tensors,
* performs the first LayerNorm manually,
* runs the four linear projections in FP16,
* applies the optional mask,
* computes the three sigmoid gates,
* launches the Triton GEMM,
* reshapes the result back to `[B,N,N,dim]`,
* runs the second LayerNorm, the output gate, and the final linear projection,
* returns a **float32** tensor.

All operations are compatible with the test configurations (different `N`,
`B`, `dim`, `hidden_dim`, optional mask, and input distributions).

```python
"""
custom_kernel – “outgoing” TriMul (forward only)

Algorithm
---------
1. LayerNorm over the last dimension (dim) → keep in float32.
2. Four linear projections (left, right, left_gate, right_gate, out_gate)
   are performed in FP16 for speed.
3. Optional mask is broadcasted and applied to left/right.
4. Gating (sigmoid) is applied in FP16.
5. Core contraction:
      out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
   is realized as a batched GEMM:
      left  : (B, H, I, K)   where H = hidden_dim, I = N, K = N
      right : (B, H, K, J)   (J = N)
   The Triton kernel works in FP16 (Tensor‑core) with FP32 accumulation.
6. Result is cast back to FP32, permuted to (B,N,N,dim).
7. Second LayerNorm + output gate + final linear projection (float32).

The kernel tiles with BLOCK_M = BLOCK_N = 64, BLOCK_K = 32 – tuned for
Hopper (SM‑90).  All strides are passed explicitly; no python‑side loops are
used inside the kernel.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched (I×K)·(K×J) → (I×J) for each (batch, head) pair
# ----------------------------------------------------------------------
@triton.jit
def batch_gemm_kernel(
    a_ptr,            # left  tensor pointer  (Z, I, K)
    b_ptr,            # right tensor pointer  (Z, K, J)
    c_ptr,            # output pointer        (Z, I, J)
    M, N, K,          # matrix sizes
    stride_az, stride_am, stride_ak,   # a: (z,i,k) strides
    stride_bz, stride_bk, stride_bn,   # b: (z,k,j) strides
    stride_cz, stride_cm, stride_cn,   # c: (z,i,j) strides
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    # --------------------------------------------------------------
    # program IDs
    # --------------------------------------------------------------
    pid_z = tl.program_id(2)          # batch*head index
    pid_m = tl.program_id(0)          # tile row index
    pid_n = tl.program_id(1)          # tile col index

    # --------------------------------------------------------------
    # offsets for this tile
    # --------------------------------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in fp32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # reduction over K
    # --------------------------------------------------------------
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # load tile of A (shape BLOCK_M × BLOCK_K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )

        # load tile of B (shape BLOCK_K × BLOCK_N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )

        # fp32 accumulation (Tensor‑core dot works on fp16 inputs)
        acc += tl.dot(a, b)

    # --------------------------------------------------------------
    # write back
    # --------------------------------------------------------------
    c = acc.to(tl.float16)   # store as fp16, later cast back to fp32
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[:, None],
    )


def triton_batched_gemm(left_fp16: torch.Tensor, right_fp16: torch.Tensor) -> torch.Tensor:
    """
    Batched GEMM using the Triton kernel above.

    Parameters
    ----------
    left_fp16  : Tensor (B, H, I, K)  dtype float16, contiguous
    right_fp16 : Tensor (B, H, K, J)  dtype float16, contiguous

    Returns
    -------
    out_fp16 : Tensor (B, H, I, J) dtype float16
    """
    assert left_fp16.is_contiguous() and right_fp16.is_contiguous()
    B, H, I, K = left_fp16.shape
    _, _, K2, J = right_fp16.shape
    assert K == K2

    # allocate output
    out = torch.empty((B, H, I, J), device=left_fp16.device, dtype=torch.float16)

    # collapse leading dimensions for the kernel (Z = B*H)
    Z = B * H
    a = left_fp16.view(Z, I, K)
    b = right_fp16.view(Z, K, J)
    c = out.view(Z, I, J)

    # strides (in elements)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # tiling (tuned for Hopper)
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(I, BLOCK_M),   # program_id(0) – rows
        triton.cdiv(J, BLOCK_N),   # program_id(1) – cols
        Z,                         # program_id(2) – batch*head
    )

    batch_gemm_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,               # good default for fp16 on SM90
    )
    return out


# ----------------------------------------------------------------------
# Full forward pass (PyTorch + Triton)
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Args
    ----
    data : tuple (input_tensor, mask, weights, config)
        input_tensor : torch.Tensor [B, N, N, dim]   (float32)
        mask         : torch.Tensor [B, N, N]       (bool/float or None)
        weights      : dict of parameter tensors (all float32)
        config       : dict with keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor [B, N, N, dim] (float32)
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]
    eps = 1e-5

    # --------------------------------------------------------------
    # 1. Input LayerNorm (float32)
    # --------------------------------------------------------------
    norm_w = weights["norm.weight"]
    norm_b = weights["norm.bias"]
    mean = input_tensor.mean(-1, keepdim=True)
    var = input_tensor.var(-1, unbiased=False, keepdim=True)
    x = (input_tensor - mean) / torch.sqrt(var + eps)
    x = x * norm_w + norm_b                     # (B,N,N,dim) float32

    # --------------------------------------------------------------
    # 2. Cast to FP16 for the heavy parts
    # --------------------------------------------------------------
    x_fp16 = x.to(torch.float16)

    # linear weights (FP16)
    left_proj_w   = weights["left_proj.weight"].to(torch.float16)
    right_proj_w  = weights["right_proj.weight"].to(torch.float16)
    left_gate_w   = weights["left_gate.weight"].to(torch.float16)
    right_gate_w  = weights["right_gate.weight"].to(torch.float16)
    out_gate_w    = weights["out_gate.weight"].to(torch.float16)

    # --------------------------------------------------------------
    # 3. Projections (FP16)
    # --------------------------------------------------------------
    left = F.linear(x_fp16, left_proj_w)    # (B,N,N,hidden_dim)
    right = F.linear(x_fp16, right_proj_w)

    # --------------------------------------------------------------
    # 4. Optional mask (broadcasted)
    # --------------------------------------------------------------
    if mask is not None:
        # mask shape [B,N,N] → [B,N,N,1] → broadcast
        mask_fp16 = mask.to(torch.float16).unsqueeze(-1)
        left = left * mask_fp16
        right = right * mask_fp16

    # --------------------------------------------------------------
    # 5. Gating (FP16)
    # --------------------------------------------------------------
    left_gate  = torch.sigmoid(F.linear(x_fp16, left_gate_w))
    right_gate = torch.sigmoid(F.linear(x_fp16, right_gate_w))
    out_gate   = torch.sigmoid(F.linear(x_fp16, out_gate_w))

    left = left * left_gate
    right = right * right_gate

    # --------------------------------------------------------------
    # 6. Rearrange to (B, H, I, K) and (B, H, K, J)
    #    left  : (B,N,N,hidden) → (B, hidden, N, N)
    #    right : (B,N,N,hidden) → (B, hidden, N, N) then transpose K↔J
    # --------------------------------------------------------------
    left_perm  = left.permute(0, 3, 1, 2).contiguous()   # (B, H, I, K)
    right_perm = right.permute(0, 3, 2, 1).contiguous()  # (B, H, K, J)

    # --------------------------------------------------------------
    # 7. Core contraction via Triton
    # --------------------------------------------------------------
    out_fp16 = triton_batched_gemm(left_perm, right_perm)   # (B, H, I, J) fp16

    # --------------------------------------------------------------
    # 8. Back to (B,N,N,dim) float32
    # --------------------------------------------------------------
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)  # (B,N,N,dim)

    # --------------------------------------------------------------
    # 9. Second LayerNorm (float32)
    # --------------------------------------------------------------
    to_out_norm_w = weights["to_out_norm.weight"]
    to_out_norm_b = weights["to_out_norm.bias"]
    mean_o = out.mean(-1, keepdim=True)
    var_o = out.var(-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + eps)
    out = out * to_out_norm_w + to_out_norm_b

    # --------------------------------------------------------------
    # 10. Output gate + final linear (float32)
    # --------------------------------------------------------------
    out = out * out_gate.to(torch.float32)
    to_out_w = weights["to_out.weight"]
    out = F.linear(out, to_out_w)   # (B,N,N,dim) float32

    return out
```
