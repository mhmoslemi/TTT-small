```python
import torch
from torch import nn, einsum
import math

# Reference code in PyTorch
class TriMul(nn.Module):
    def __init__(
        self,
        dim: int,
        hidden_dim: int,
    ):
        super().__init__()

        self.norm = nn.LayerNorm(dim)

        self.left_proj = nn.Linear(dim, hidden_dim, bias=False)
        self.right_proj = nn.Linear(dim, hidden_dim, bias=False)

        self.left_gate = nn.Linear(dim, hidden_dim, bias=False)
        self.right_gate = nn.Linear(dim, hidden_dim, bias=False)
        self.out_gate = nn.Linear(dim, hidden_dim, bias=False)

        self.to_out_norm = nn.LayerNorm(hidden_dim)
        self.to_out = nn.Linear(hidden_dim, dim, bias=False)

    def forward(self, x: torch.Tensor, mask: torch.Tensor) -> torch.Tensor:
        """
        x: [bs, seq_len, seq_len, dim]
        mask: [bs, seq_len, seq_len]

        Returns:
            output: [bs, seq_len, seq_len, dim]
        """
        batch_size, seq_len, _, dim = x.shape

        x = self.norm(x)

        left = self.left_proj(x)
        right = self.right_proj(x)

        mask = mask.unsqueeze(-1)
        left = left * mask
        right = right * mask

        left_gate = self.left_gate(x).sigmoid()
        right_gate = self.right_gate(x).sigmoid()
        out_gate = self.out_gate(x).sigmoid()

        left = left * left_gate
        right = right * right_gate

        out = einsum('... i k d, ... j k d -> ... i j d', left, right)
        # This einsum is the same as the following:
        # out = torch.zeros(batch_size, seq_len, seq_len, dim, device=x.device)
        
        # # Compute using nested loops
        # for b in range(batch_size):
        #     for i in range(seq_len):
        #         for j in range(seq_len):
        #             # Compute each output element
        #             for k in range(seq_len):
        #                 out[b, i, j] += left[b, i, k, :] * right[b, j, k, :]

        out = self.to_out_norm(out)
        out = out * out_gate
        return self.to_out(out)
```

## Triton launch convention

Every failure mode below has appeared in this search. Read this before writing.

A `@triton.jit` function is NOT a Python function. It is launched with a grid
subscript, and its `tl.constexpr` parameters exist only inside it:

```python
@triton.jit
def my_kernel(x_ptr, y_ptr, n, BLOCK: tl.constexpr):
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    m = offs < n
    tl.store(y_ptr + offs, tl.load(x_ptr + offs, mask=m, other=0.0), mask=m)

def custom_kernel(data):
    ...
    BLOCK = 128                                   # a host variable YOU define
    grid = (triton.cdiv(n, BLOCK),)               # host-side, use triton.cdiv
    my_kernel[grid](x, y, n, BLOCK=BLOCK)         # note the [grid] subscript
```

- `my_kernel(...)` without `[grid]` raises "Cannot call @triton.jit'd outside
  the scope of a kernel".
- `BLOCK`, `BLOCK_M`, `BLOCK_N` are not defined on the host unless you define
  them there. Referencing one you only declared as a `tl.constexpr` parameter
  raises NameError.
- `tl.cdiv` is device-side. On the host use `triton.cdiv`.
- Define the kernel at module top level, never nested inside `custom_kernel`.

You do not have to move everything into Triton. A correct submission that keeps
most of the computation in PyTorch and moves one hot region into a kernel scores;
one that fails to launch scores zero.

```python
"""
TriMul – “outgoing” version (AlphaFold‑3)

Algorithm
---------
1. Layer‑norm over the last dimension (dim).
2. Two linear projections → left / right  (shape [B,N,N,H]).
3. Three linear gates → left_gate, right_gate, out_gate  (shape [B,N,N,H]).
4. Fuse mask (optional) and the three gates into left/right/out_gate with a
   single Triton kernel (in‑place on left/right, out_gate is written back).
   This keeps the whole element‑wise work on the GPU and removes an extra
   launch.
5. Core Tensor‑contraction
        out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
   is a batched matrix‑multiply for every hidden channel *d*:
        left  : (B, H, N, K)   where K = N
        right : (B, H, N, K)
        out   = left @ right.transpose(-1,-2)   → (B, H, N, N)
   The result is permuted back to (B, N, N, H).
6. Final Layer‑norm over the hidden dimension, out‑gate scaling and a linear
   projection back to *dim* are performed with PyTorch (highly‑optimized).

Only step 4 is implemented in Triton – this satisfies the “must contain a
Triton kernel” requirement while keeping the overall runtime optimal on
Hopper‑class GPUs.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: fuse optional mask, left‑gate, right‑gate and out‑gate.
# ----------------------------------------------------------------------
@triton.jit
def _mask_gate_fuse_kernel(
    left_ptr, right_ptr,               # [B,N,N,H]  projected tensors
    mask_ptr,                          # [B,N,N,1]  broadcast mask (or all‑ones)
    lgate_ptr, rgate_ptr, ogate_ptr,   # [B,N,N,H]  sigmoid‑gates
    B, N, H,
    # strides (int64) of the tensors above
    stride_l_b, stride_l_i, stride_l_k, stride_l_h,
    stride_r_b, stride_r_i, stride_r_k, stride_r_h,
    stride_m_b, stride_m_i, stride_m_k, stride_m_1,
    stride_lg_b, stride_lg_i, stride_lg_k, stride_lg_h,
    stride_rg_b, stride_rg_i, stride_rg_k, stride_rg_h,
    stride_og_b, stride_og_i, stride_og_k, stride_og_h,
    BLOCK: tl.constexpr,
):
    """
    For every element (b,i,k,d)  (the 4‑D view of left/right):
        left  = left  * mask * lgate
        right = right * mask * rgate
        out_gate[b,i,k,d] = ogate * mask               # store back
    The mask is a scalar per (b,i,k) and is broadcast over the hidden dim.
    """
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)           # flat offsets
    total = B * N * N * H
    mask = offs < total

    # --------------------------------------------------------------
    # Decode flat index → (b,i,k,d)
    # --------------------------------------------------------------
    tmp = offs
    d = tmp % H
    tmp = tmp // H
    k = tmp % N
    tmp = tmp // N
    i = tmp % N
    b = tmp // N

    # --------------------------------------------------------------
    # Compute the pointers for each tensor
    # --------------------------------------------------------------
    left_ptr   = left_ptr   + b * stride_l_b   + i * stride_l_i   + k * stride_l_k   + d * stride_l_h
    right_ptr  = right_ptr  + b * stride_r_b   + i * stride_r_i   + k * stride_r_k   + d * stride_r_h
    mask_ptr   = mask_ptr   + b * stride_m_b   + i * stride_m_i   + k * stride_m_k                # 1‑channel
    lg_ptr     = lgate_ptr  + b * stride_lg_b  + i * stride_lg_i  + k * stride_lg_k  + d * stride_lg_h
    rg_ptr     = rgate_ptr  + b * stride_rg_b  + i * stride_rg_i  + k * stride_rg_k  + d * stride_rg_h
    og_ptr     = ogate_ptr  + b * stride_og_b  + i * stride_og_i  + k * stride_og_k  + d * stride_og_h

    # --------------------------------------------------------------
    # Load (mask is broadcast, so we load a scalar and reuse)
    # --------------------------------------------------------------
    l   = tl.load(left_ptr,   mask=mask, other=0.0)
    r   = tl.load(right_ptr,  mask=mask, other=0.0)
    m   = tl.load(mask_ptr,   mask=mask, other=1.0)   # 1.0 when mask absent
    lg  = tl.load(lg_ptr,     mask=mask, other=1.0)
    rg  = tl.load(rg_ptr,     mask=mask, other=1.0)
    og  = tl.load(og_ptr,     mask=mask, other=1.0)

    # --------------------------------------------------------------
    # Fuse
    # --------------------------------------------------------------
    l = l * m * lg
    r = r * m * rg
    og = og * m                                   # out‑gate only needs mask

    # --------------------------------------------------------------
    # Store results back
    # --------------------------------------------------------------
    tl.store(left_ptr,  l,  mask=mask)
    tl.store(right_ptr, r,  mask=mask)
    tl.store(og_ptr,    og, mask=mask)


def _apply_mask_and_gates(
    left: torch.Tensor,
    right: torch.Tensor,
    mask: torch.Tensor,
    left_gate: torch.Tensor,
    right_gate: torch.Tensor,
    out_gate: torch.Tensor,
) -> torch.Tensor:
    """
    Launches the Triton kernel above.  The kernel works *in‑place* on `left`
    and `right`.  The returned tensor is the masked & gated `out_gate`.
    """
    B, N, _, H = left.shape
    total = B * N * N * H
    BLOCK = 1024                     # empirically good for H200
    grid = (triton.cdiv(total, BLOCK),)

    _mask_gate_fuse_kernel[grid](
        left_ptr=left,
        right_ptr=right,
        mask_ptr=mask,
        lgate_ptr=left_gate,
        rgate_ptr=right_gate,
        ogate_ptr=out_gate,
        B=B,
        N=N,
        H=H,
        stride_l_b=left.stride(0), stride_l_i=left.stride(1),
        stride_l_k=left.stride(2), stride_l_h=left.stride(3),
        stride_r_b=right.stride(0), stride_r_i=right.stride(1),
        stride_r_k=right.stride(2), stride_r_h=right.stride(3),
        stride_m_b=mask.stride(0), stride_m_i=mask.stride(1),
        stride_m_k=mask.stride(2), stride_m_1=mask.stride(3),
        stride_lg_b=left_gate.stride(0), stride_lg_i=left_gate.stride(1),
        stride_lg_k=left_gate.stride(2), stride_lg_h=left_gate.stride(3),
        stride_rg_b=right_gate.stride(0), stride_rg_i=right_gate.stride(1),
        stride_rg_k=right_gate.stride(2), stride_rg_h=right_gate.stride(3),
        stride_og_b=out_gate.stride(0), stride_og_i=out_gate.stride(1),
        stride_og_k=out_gate.stride(2), stride_og_h=out_gate.stride(3),
        BLOCK=BLOCK,
    )
    # out_gate now contains the masked sigmoid; return it for later use.
    return out_gate


# ----------------------------------------------------------------------
# Main entry point required by the problem statement
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Triton‑accelerated forward pass of the “outgoing” TriMul operator.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask_tensor, weights_dict, config_dict)

        * input_tensor : torch.Tensor of shape [B, N, N, dim] (float32 or bf16)
        * mask_tensor  : torch.Tensor of shape [B, N, N] (float32 0/1) or None
        * weights_dict : dict containing the same keys as the reference
                         PyTorch implementation (LayerNorm weights/bias,
                         linear weights, etc.)
        * config_dict  : dict with entries ``dim`` and ``hidden_dim``

    Returns
    -------
    torch.Tensor
        Tensor of shape [B, N, N, dim] (float32) – the result of the forward pass.
    """
    # ------------------------------------------------------------------
    # Unpack inputs
    # ------------------------------------------------------------------
    x, mask, weights, cfg = data
    device = x.device
    B, N, _, dim = x.shape
    hidden = cfg["hidden_dim"]

    # ------------------------------------------------------------------
    # 1️⃣ Layer‑norm over `dim`
    # ------------------------------------------------------------------
    x = F.layer_norm(
        x,
        (dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
    )

    # ------------------------------------------------------------------
    # 2️⃣ Linear projections (no bias) → left / right  [B,N,N,hidden]
    # ------------------------------------------------------------------
    left  = F.linear(x, weights["left_proj.weight"])   # (B,N,N,hidden)
    right = F.linear(x, weights["right_proj.weight"])

    # ------------------------------------------------------------------
    # 3️⃣ Gates (sigmoid) → also [B,N,N,hidden]
    # ------------------------------------------------------------------
    left_gate  = torch.sigmoid(F.linear(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"]))
    out_gate   = torch.sigmoid(F.linear(x, weights["out_gate.weight"]))

    # ------------------------------------------------------------------
    # 4️⃣ Optional mask handling (broadcast to hidden dimension)
    # ------------------------------------------------------------------
    if mask is None:
        # all‑ones mask – shape [B,N,N,1] for broadcasting
        mask = torch.ones(B, N, N, 1, dtype=x.dtype, device=device)
    else:
        mask = mask.unsqueeze(-1).to(x.dtype)          # [B,N,N,1]

    # ------------------------------------------------------------------
    # 5️⃣ Fuse mask + gates into left/right (in‑place) via Triton.
    #    The kernel also writes back the masked out_gate.
    # ------------------------------------------------------------------
    out_gate = _apply_mask_and_gates(
        left, right, mask, left_gate, right_gate, out_gate
    )   # left/right are now masked & gated; out_gate is masked

    # ------------------------------------------------------------------
    # 6️⃣ Core contraction: Σ_k left[b,i,k,d] * right[b,j,k,d]
    #    Implemented as a batched matmul per hidden channel.
    # ------------------------------------------------------------------
    # (B,N,N,hidden) → (B, hidden, N, K)   where K == N
    left_t  = left.permute(0, 3, 1, 2)   # (B, H, N, K)
    right_t = right.permute(0, 3, 1, 2)  # (B, H, N, K)

    # Batched matmul: (B,H,N,K) @ (B,H,K,N) → (B,H,N,N)
    out_t = torch.matmul(left_t, right_t.transpose(-1, -2))

    # Back to original layout (B,N,N,hidden)
    out = out_t.permute(0, 2, 3, 1)

    # ------------------------------------------------------------------
    # 7️⃣ Final LayerNorm over hidden dim, out‑gate scaling and projection
    # ------------------------------------------------------------------
    out = F.layer_norm(
        out,
        (hidden,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
    )
    out = out * out_gate                     # gated scaling
    out = F.linear(out, weights["to_out.weight"])

    # Ensure the output dtype matches the reference (float32)
    return out.to(torch.float32)
```


## Lessons from earlier kernels in this search

Extracted from kernels already generated and benchmarked here. Empirical
findings, not part of the specification above, and they do not override any rule
stated in it.

**Observed to help**
1. [local] Limit shared memory usage
   When launching a Triton kernel, set BLOCK_M, BLOCK_N, and BLOCK_K to values (e.g., ≤64) that keep required shared memory below the device limit; if needed, lower num_stages.
2. [global] Delegate N³ contraction to cuBLAS
   Reshape the left and right tensors to (B*H, N, N) and compute out = torch.bmm(left, right.transpose(1,2)); this leverages cuBLAS/Tensor‑cores for the dominant O(N³) work while keeping the program simple and fast.
3. [local] Match dtypes for batched GEMM
   If you cast one operand (e.g., the weight matrix) to float16 for speed, also cast the other operand to float16 before the batched matmul, or keep both in float32; mixing float32 and float16 raises a runtime error.

**Observed to fail**
1. [local] Match stride unpacking to tensor rank
   Do not assume a tensor has three strides; use tensor.stride() and unpack exactly the number of dimensions the kernel expects, or pass strides explicitly from the caller.
