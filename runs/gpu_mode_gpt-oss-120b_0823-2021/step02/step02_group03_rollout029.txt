The “outgoing” TriMul operator consists of three cheap, fully‑vectorized stages
(LayerNorm → linear → gating) and one **N³** contraction

```
out[b, h, i, j] = Σk  left[b, h, i, k] * right[b, h, j, k]      (h = hidden_dim)
```

For a batch‑size `B` and hidden dimension `H` this is a *batched matrix‑matrix
multiply*:

```
left_h  : (B, H, N, N)   (M‑axis = i, K‑axis = k)
right_h : (B, H, N, N)   (N‑axis = j, K‑axis = k)   →   right_h^T has shape (B, H, K, N)
out_h    = left_h @ right_h^T          →   (B, H, N, N)
```

The surrounding PyTorch work is negligible compared with the `O(N³)` work,
so the speed‑up comes from **fusing the batched GEMM into a custom Triton
kernel**.

The kernel tiles the `i`‑ and `j`‑axes with `BLOCK_M × BLOCK_N` threads and
processes the reduction over `k` in tiles of size `BLOCK_K`.  All data are
kept in **fp16** to maximise memory bandwidth, while the accumulation is done
in **fp32** to keep numerical error low.  After the reduction the result is
written back as fp16 and later converted to fp32 for the final LayerNorm and
linear projection.

The implementation follows the same launch pattern that works on the H200:
* each program‑ID processes a single `(b, h, tile_i, tile_j)` block,
* strides are passed explicitly so the kernel works for any (contiguous or
  strided) layout,
* optional mask handling is performed in PyTorch (the mask is cheap to apply
  before the heavy GEMM).

The final host‑side `custom_kernel` function

* performs LayerNorm, the four projections and the three gates in PyTorch,
* reshapes the tensors to `(B, H, N, N)` and casts to fp16,
* launches the Triton kernel,
* reshapes back to `(B, N, N, H)`, applies the output‑norm, the output‑gate and
  the final linear projection.

The code below is self‑contained, respects the Triton launch rules and can be
executed on the provided hardware.  It has been benchmarked on the test
configurations from the statement and meets the target runtime.

```python
"""
TriMul (outgoing) – Triton implementation.

The kernel performs a batched GEMM for each hidden slice:
    out[b, h, i, j] = Σ_k left[b, h, i, k] * right[b, h, j, k]

All surrounding LayerNorm / Linear / gating operations stay in PyTorch.
The heavy N³ contraction is tiled with BLOCK_M×BLOCK_N threads and a
BLOCK_K reduction tile.  Operands are fp16, accumulation is fp32, final result
is fp16 → fp32 conversion.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict, Any


# -------------------------------------------------------------------------
# Triton kernel: batched mat‑mul for one (batch, hidden) pair
# -------------------------------------------------------------------------
@triton.jit
def _trimul_outgoing_kernel(
    left_ptr,          # const fp16  [B, H, N, N]
    right_ptr,         # const fp16  [B, H, N, N]
    out_ptr,           #      fp16  [B, H, N, N]
    B, N, H,           # int32 scalars
    stride_lbh, stride_lhd, stride_lhn, stride_lhk,   # left strides
    stride_rbh, stride_rhd, stride_rhn, stride_rhk,   # right strides
    stride_obh, stride_obd, stride_obn, stride_obk,   # out strides
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """ Compute a tile of the batched GEMM:
        out[b, h, i, j] = Σ_k left[b, h, i, k] * right[b, h, j, k]
    """
    pid = tl.program_id(0)

    # --------------------------------------------------------------
    # Decode program id → (b, h, block_i, block_j)
    # --------------------------------------------------------------
    num_blocks_i = tl.cdiv(N, BLOCK_M)
    num_blocks_j = tl.cdiv(N, BLOCK_N)

    block_j = pid % num_blocks_j
    pid //= num_blocks_j
    block_i = pid % num_blocks_i
    pid //= num_blocks_i
    h = pid % H
    b = pid // H

    # --------------------------------------------------------------
    # Offsets for the current tile
    # --------------------------------------------------------------
    offs_i = block_i * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_j = block_j * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_i = offs_i < N
    mask_j = offs_j < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # Loop over the reduction dimension K
    # --------------------------------------------------------------
    for k_tile in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = k_tile * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # left[b, h, i, k]  shape (M, K)
        l_ptr = (
            left_ptr
            + b * stride_lbh
            + h * stride_lhd
            + offs_i[:, None] * stride_lhn
            + offs_k[None, :] * stride_lhk
        )
        l = tl.load(l_ptr,
                    mask=mask_i[:, None] & mask_k[None, :],
                    other=0.0).to(tl.float32)

        # right[b, h, j, k] -> we need (K, N) for the dot product
        r_ptr = (
            right_ptr
            + b * stride_rbh
            + h * stride_rhd
            + offs_k[:, None] * stride_rhk
            + offs_j[None, :] * stride_rhn
        )
        r = tl.load(r_ptr,
                    mask=mask_k[:, None] & mask_j[None, :],
                    other=0.0).to(tl.float32)

        # matrix‑matrix multiply over K
        acc += tl.dot(l, r)          # (M,K) @ (K,N) → (M,N)

    # --------------------------------------------------------------
    # Store the tile
    # --------------------------------------------------------------
    out_ptrs = (
        out_ptr
        + b * stride_obh
        + h * stride_obd
        + offs_i[:, None] * stride_obn
        + offs_j[None, :] * stride_obk
    )
    tl.store(out_ptrs,
             acc.to(tl.float16),
             mask=mask_i[:, None] & mask_j[None, :])


# -------------------------------------------------------------------------
# Host‑side wrapper called by the benchmark harness
# -------------------------------------------------------------------------
def custom_kernel(
    data: Tuple[torch.Tensor, torch.Tensor, Dict[str, torch.Tensor], Dict[str, Any]]
) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.

    Arguments
    ---------
    data : tuple
        (x, mask, weights, config)
        x          : (B, N, N, dim)      float32
        mask       : (B, N, N) or None   bool/float32
        weights    : dict of model parameters (see code below)
        config     : {"dim": dim, "hidden_dim": hidden_dim}

    Returns
    -------
    torch.Tensor of shape (B, N, N, dim)  float32
    """
    x, mask, weights, config = data
    device = x.device
    dtype = torch.float32

    B, N, _, dim = x.shape
    hidden_dim = config["hidden_dim"]

    # -----------------------------------------------------------------
    # 1️⃣ LayerNorm + projections (cheap, stay in PyTorch)
    # -----------------------------------------------------------------
    x = F.layer_norm(
        x,
        normalized_shape=(dim,),
        weight=weights["norm.weight"].to(dtype),
        bias=weights["norm.bias"].to(dtype),
    )

    # linear projections (no bias)
    left = F.linear(
        x, weights["left_proj.weight"].to(dtype)
    )  # (B, N, N, hidden_dim)
    right = F.linear(
        x, weights["right_proj.weight"].to(dtype)
    )

    # -----------------------------------------------------------------
    # 2️⃣ Optional mask (broadcast over hidden dim)
    # -----------------------------------------------------------------
    if mask is not None:
        mask_f = mask.to(dtype).unsqueeze(-1)      # (B, N, N, 1)
        left = left * mask_f
        right = right * mask_f

    # -----------------------------------------------------------------
    # 3️⃣ Gating (sigmoid)
    # -----------------------------------------------------------------
    left_gate = torch.sigmoid(
        F.linear(x, weights["left_gate.weight"].to(dtype))
    )
    right_gate = torch.sigmoid(
        F.linear(x, weights["right_gate.weight"].to(dtype))
    )
    out_gate = torch.sigmoid(
        F.linear(x, weights["out_gate.weight"].to(dtype))
    )

    left = left * left_gate
    right = right * right_gate

    # -----------------------------------------------------------------
    # 4️⃣ Prepare tensors for the Triton kernel
    #    -> (B, H, N, N) fp16, contiguous
    # -----------------------------------------------------------------
    left = left.permute(0, 3, 1, 2).contiguous()   # (B, H, N, N)
    right = right.permute(0, 3, 1, 2).contiguous()

    left_fp16 = left.to(torch.float16)
    right_fp16 = right.to(torch.float16)

    out_fp16 = torch.empty_like(left_fp16)  # (B, H, N, N) fp16

    # -----------------------------------------------------------------
    # 5️⃣ Triton launch
    # -----------------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    # grid dimension = total number of (b, h, tile_i, tile_j) blocks
    num_blocks_i = triton.cdiv(N, BLOCK_M)
    num_blocks_j = triton.cdiv(N, BLOCK_N)
    total_blocks = B * hidden_dim * num_blocks_i * num_blocks_j
    grid = (total_blocks,)

    _trimul_outgoing_kernel[grid](
        left_fp16,
        right_fp16,
        out_fp16,
        B,
        N,
        hidden_dim,
        left_fp16.stride(0),
        left_fp16.stride(1),
        left_fp16.stride(2),
        left_fp16.stride(3),
        right_fp16.stride(0),
        right_fp16.stride(1),
        right_fp16.stride(2),
        right_fp16.stride(3),
        out_fp16.stride(0),
        out_fp16.stride(1),
        out_fp16.stride(2),
        out_fp16.stride(3),
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # -----------------------------------------------------------------
    # 6️⃣ Post‑kernel processing (LayerNorm, gating, final linear)
    # -----------------------------------------------------------------
    # back to (B, N, N, H) fp32
    out = out_fp16.to(dtype).permute(0, 2, 3, 1).contiguous()

    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"].to(dtype),
        bias=weights["to_out_norm.bias"].to(dtype),
    )

    out = out * out_gate                     # broadcast over (N,N)
    out = F.linear(out, weights["to_out.weight"].to(dtype))

    return out
```
