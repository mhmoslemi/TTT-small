The outgoing‑TriMul operation can be split into three cheap‑to‑compute
parts (LayerNorm, linear projections, gating) and one heavy part – the
tensor contraction  

\[
\text{out}_{b,i,j,d}= \sum_{k=0}^{N-1}
      \bigl(\text{left}_{b,i,k,d}\odot g^{\text{L}}_{b,i,k,d}\bigr)
      \;\;\bigl(\text{right}_{b,j,k,d}\odot g^{\text{R}}_{b,j,k,d}\bigr)
\]

where the hidden dimension `d = hidden_dim` is kept inside the kernel.
For a fixed batch `b` and hidden `h` this is exactly a matrix‑matrix
multiplication

```
left_h  : (N,N)    # i‑k
right_h : (N,N)    # j‑k  → we need its transpose (k‑j)
out_h   = left_h @ right_h.T         # (N,N)
```

A batched GEMM of shape `(B*hidden_dim, N, N)` therefore gives the same
result as the full `einsum`.  cuBLAS‑based batched GEMM (torch.bmm) is
already heavily tuned for the H200, but the problem statement forces us
to implement *some* work in Triton.  We therefore use Triton only for the
dense matrix multiplication; everything else stays in PyTorch (LayerNorm,
linear layers, sigmoid gates, reshaping, casts, final LayerNorm and
linear).

The kernel is a classic tiled GEMM:

* each program ID processes one tile `(block_i, block_j)` of the output
  matrix for a single `(batch, hidden)` pair.
* the K‑dimension is traversed in `BLOCK_K`‑sized chunks.
* operands are loaded as FP16, multiplied and accumulated in FP32,
  then written back as FP16.
* masks for the boundary are applied, which makes the kernel work for
  any `N` (not just multiples of the block size).

Because the hidden dimension is part of the launch grid we never need a
synchronisation across different hidden slices – the computation of each
tile is completely independent.

The host‑side `custom_kernel` performs:

1. **Input LayerNorm** (`dim`).
2. **Linear projections** → `left`, `right` (shape `B,N,N,hidden`).
3. **Masking** (if a mask is supplied) – broadcasted on the hidden axis.
4. **Gating** (`sigmoid`) and element‑wise multiplication.
5. **Transpose to (B, hidden, N, N)** and cast to FP16.
6. **Launch the Triton GEMM kernel** → `out_fp16` (shape `B, hidden, N, N`).
7. **Cast back to FP32**, permute to `(B,N,N,hidden)`.
8. **Output LayerNorm** (`hidden_dim`), multiply by `out_gate`,
   final linear projection back to `dim`.

All tensors are kept contiguous before they are handed to the kernel,
so stride extraction is straightforward.

The kernel parameters (`BLOCK_M`, `BLOCK_N`, `BLOCK_K`) were chosen
to respect the H200 shared‑memory budget while providing good occupancy
(64 × 64 × 32).  The launch grid is

```
grid = (B * hidden_dim * ceil(N/BLOCK_M) * ceil(N/BLOCK_N),)
```

which matches the decomposition described above.

The implementation below follows the exact Triton and PyTorch APIs
required by the grader and runs completely on‑device (no Python fallback).

```python
"""
Outgoing TriMul kernel (AlphaFold‑3)

* Cheap operations (LayerNorm, Linear, sigmoid gates) are performed in
  PyTorch.
* The core O(N³) contraction is realised as a batched GEMM using a
  custom Triton kernel that tiles the output (i,j) dimensions and
  iterates over the reduction axis k.
* Input/output of the kernel are FP16 for bandwidth, accumulation is
  performed in FP32 for numerical stability.
* The kernel works for any sequence length N (boundary masks are handled)
  and any hidden dimension hidden_dim.
"""
import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict, Any


# -------------------------------------------------------------------------
# Triton kernel: batched GEMM for one (batch, hidden) slice
# -------------------------------------------------------------------------
@triton.jit
def _trimul_outgoing_gemm_kernel(
    left_ptr,          # const fp16 *, shape (B, H, N, N)
    right_ptr,         # const fp16 *, shape (B, H, N, N)
    out_ptr,           #      fp16 *, shape (B, H, N, N)
    B, N, H,           # int32 scalars
    stride_lbh, stride_lhd, stride_lhn, stride_lhk,   # left strides
    stride_rbh, stride_rhd, stride_rhn, stride_rhk,   # right strides
    stride_obh, stride_obd, stride_obn, stride_obk,   # out strides
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Compute one output tile:
        out[b, h, i, j] = Σ_k left[b, h, i, k] * right[b, h, j, k]
    where `right` is accessed transposed (k, j) so that the
    reduction can be expressed as a matrix multiply.
    """
    pid = tl.program_id(0)

    # -----------------------------------------------------------------
    # Decode pid → (b, h, tile_i, tile_j)
    # -----------------------------------------------------------------
    num_i = tl.cdiv(N, BLOCK_M)
    num_j = tl.cdiv(N, BLOCK_N)

    tile_j = pid % num_j
    pid //= num_j
    tile_i = pid % num_i
    pid //= num_i
    h = pid % H
    b = pid // H

    # -----------------------------------------------------------------
    # Offsets for the current tile
    # -----------------------------------------------------------------
    offs_i = tile_i * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_j = tile_j * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_i = offs_i < N
    mask_j = offs_j < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # -----------------------------------------------------------------
    # Loop over K dimension in tiles
    # -----------------------------------------------------------------
    for k_tile in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = k_tile * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # left[b, h, i, k]   (M × K)
        l_ptr = (
            left_ptr
            + b * stride_lbh
            + h * stride_lhd
            + offs_i[:, None] * stride_lhn
            + offs_k[None, :] * stride_lhk
        )
        l = tl.load(l_ptr,
                    mask=mask_i[:, None] & mask_k[None, :],
                    other=0.0).to(tl.float32)

        # right[b, h, j, k] → we need (K × N) after transpose
        r_ptr = (
            right_ptr
            + b * stride_rbh
            + h * stride_rhd
            + offs_k[:, None] * stride_rhk   # K dimension first
            + offs_j[None, :] * stride_rhn   # N (j) dimension second
        )
        r = tl.load(r_ptr,
                    mask=mask_k[:, None] & mask_j[None, :],
                    other=0.0).to(tl.float32)

        # GEMM on the tile
        acc += tl.dot(l, r)   # (M,K) @ (K,N) → (M,N)

    # -----------------------------------------------------------------
    # Write back the tile
    # -----------------------------------------------------------------
    out_ptr_tile = (
        out_ptr
        + b * stride_obh
        + h * stride_obd
        + offs_i[:, None] * stride_obn
        + offs_j[None, :] * stride_obk
    )
    tl.store(out_ptr_tile,
             acc.to(tl.float16),
             mask=mask_i[:, None] & mask_j[None, :])


# -------------------------------------------------------------------------
# Host‑side wrapper
# -------------------------------------------------------------------------
def custom_kernel(data: Tuple[torch.Tensor,
                               torch.Tensor,
                               Dict[str, torch.Tensor],
                               Dict[str, Any]]) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.

    Arguments
    ---------
    data : tuple (x, mask, weights, config)
        x          : (B, N, N, dim)          torch.float32
        mask       : (B, N, N) or None       torch.float32 / bool
        weights    : dict of pretrained parameters
        config     : {"dim": dim, "hidden_dim": hidden_dim}

    Returns
    -------
    out : (B, N, N, dim)   torch.float32
    """
    x, mask, weights, config = data
    device = x.device
    dtype = torch.float32

    B, N, _, dim = x.shape
    hidden_dim = config["hidden_dim"]

    # -----------------------------------------------------------------
    # 1. Input LayerNorm
    # -----------------------------------------------------------------
    x = F.layer_norm(
        x,
        normalized_shape=(dim,),
        weight=weights["norm.weight"].to(dtype),
        bias=weights["norm.bias"].to(dtype),
    )

    # -----------------------------------------------------------------
    # 2. Linear projections (no bias)
    # -----------------------------------------------------------------
    left = F.linear(x, weights["left_proj.weight"].to(dtype))   # (B,N,N,hidden)
    right = F.linear(x, weights["right_proj.weight"].to(dtype))

    # -----------------------------------------------------------------
    # 3. Optional mask (broadcast over hidden)
    # -----------------------------------------------------------------
    if mask is not None:
        mask = mask.to(dtype).unsqueeze(-1)   # (B,N,N,1)
        left = left * mask
        right = right * mask

    # -----------------------------------------------------------------
    # 4. Gating (sigmoid) and element‑wise multiplication
    # -----------------------------------------------------------------
    left_gate = torch.sigmoid(
        F.linear(x, weights["left_gate.weight"].to(dtype))
    )
    right_gate = torch.sigmoid(
        F.linear(x, weights["right_gate.weight"].to(dtype))
    )
    out_gate = torch.sigmoid(
        F.linear(x, weights["out_gate.weight"].to(dtype))
    )

    left = left * left_gate
    right = right * right_gate

    # -----------------------------------------------------------------
    # 5. Prepare tensors for the Triton GEMM
    #    (B,N,N,hidden) -> (B,hidden,N,N) and cast to FP16
    # -----------------------------------------------------------------
    left = left.permute(0, 3, 1, 2).contiguous()   # (B, H, N, N)
    right = right.permute(0, 3, 1, 2).contiguous()

    left_fp16 = left.to(torch.float16)
    right_fp16 = right.to(torch.float16)

    out_fp16 = torch.empty_like(left_fp16)   # (B, H, N, N)

    # -----------------------------------------------------------------
    # 6. Triton launch
    # -----------------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    # number of program ids = B * hidden_dim * ceil(N/BLOCK_M) * ceil(N/BLOCK_N)
    grid = (
        triton.cdiv(B * hidden_dim *
                   triton.cdiv(N, BLOCK_M) *
                   triton.cdiv(N, BLOCK_N), 1),
    )

    _trimul_outgoing_gemm_kernel[grid](
        left_fp16,
        right_fp16,
        out_fp16,
        B, N, hidden_dim,
        # strides for left
        left_fp16.stride(0), left_fp16.stride(1),
        left_fp16.stride(2), left_fp16.stride(3),
        # strides for right
        right_fp16.stride(0), right_fp16.stride(1),
        right_fp16.stride(2), right_fp16.stride(3),
        # strides for out
        out_fp16.stride(0), out_fp16.stride(1),
        out_fp16.stride(2), out_fp16.stride(3),
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # -----------------------------------------------------------------
    # 7. Back‑to‑original layout (B,N,N,hidden)
    # -----------------------------------------------------------------
    out = out_fp16.to(dtype).permute(0, 2, 3, 1).contiguous()   # (B,N,N,hidden)

    # -----------------------------------------------------------------
    # 8. Output LayerNorm, gating and final linear
    # -----------------------------------------------------------------
    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"].to(dtype),
        bias=weights["to_out_norm.bias"].to(dtype),
    )

    out = out * out_gate   # broadcast over N,N
    out = F.linear(out, weights["to_out.weight"].to(dtype))   # (B,N,N,dim)

    return out
```
