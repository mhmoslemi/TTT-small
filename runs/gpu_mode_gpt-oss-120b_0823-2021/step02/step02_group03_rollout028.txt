The “outgoing” TriMul computes  

\[
\text{out}_{b,i,j,:}= \sum_{k=1}^{N}
      \bigl(\text{left}_{b,i,k,:}\odot g^{L}_{b,i,k,:}\bigr)\;
      \bigl(\text{right}_{b,j,k,:}\odot g^{R}_{b,j,k,:}\bigr)
\]

where `left/right` are linear projections of the input tensor `x`,
`gL/gR` are sigmoid‑gates, and a final gate‑*out* and linear projection are
applied after a LayerNorm.  

The only cubic‑cost part is the contraction over the third axis `k`.  
All cheap operations (LayerNorm, linear layers, gating, masking) are kept in
PyTorch – they are inexpensive compared to the \(N^{3}\) work.  

The contraction is turned into a batched matrix‑multiply:

```
left_h  : (B, H, N, N)      # H = hidden_dim
right_h : (B, H, N, N)

out_h[b, h] = left_h[b, h] @ right_h[b, h].T          # (N,N) @ (N,N) → (N,N)
```

We implement a **tiled batched GEMM** in Triton that works on a single
`(b, h)` pair at a time.  The kernel:

* tiles the output (i‑axis, j‑axis) with `BLOCK_M × BLOCK_N` threads,
* iterates over `k` in tiles of size `BLOCK_K`,
* loads tiles of `left` and `right` in FP16, promotes them to FP32,
* accumulates in FP32 (`acc`) to keep precision,
* writes the result back as FP16.

The surrounding host function (`custom_kernel`) performs the cheap steps,
casts the tensors to FP16, launches the kernel, then finishes the
post‑processing (LayerNorm, out‑gate, final linear) in PyTorch.

The implementation respects all Triton‑specific rules
(`tl.constexpr` parameters, explicit stride handling, proper grid sizing)
and runs on the H200 (SM 90) with good occupancy (`BLOCK_M=64,
BLOCK_N=64, BLOCK_K=32`).

```python
"""
custom_kernel – outgoing TriMul (AlphaFold‑3)

The heavy computation is the N×N “outer‑product” over the third axis:

    out[b, i, j, d] = Σ_k left[b, i, k, d] * right[b, j, k, d]

After linear projections and sigmoid gating we reshape the tensors to
(B, H, N, N) and perform a batched matrix‑multiply
    out_h[b, h] = left_h[b, h] @ right_h[b, h].T
with a custom Triton kernel.  All other ops (LayerNorm, gating,
final linear) are done with PyTorch.  The kernel works in FP16 for
bandwidth, accumulates in FP32 and writes back FP16; the final result is
converted to FP32.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict, Any


# -------------------------------------------------------------------------
# Triton kernel: batched GEMM for a single (batch, hidden) slice
# -------------------------------------------------------------------------
@triton.jit
def _trimul_outgoing_kernel(
    left_ptr,          # const fp16  [B, H, N, N]
    right_ptr,         # const fp16  [B, H, N, N]
    out_ptr,           # mut   fp16  [B, H, N, N]
    B, N, H,           # int32 sizes
    # strides of left   (b, h, i, k)
    stride_lbh, stride_lhd, stride_lhn, stride_lhk,
    # strides of right  (b, h, j, k)
    stride_rbh, stride_rhd, stride_rjn, stride_rjk,
    # strides of out    (b, h, i, j)
    stride_obh, stride_obd, stride_obn, stride_obj,
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Compute out[b, h, i, j] = Σ_k left[b, h, i, k] * right[b, h, j, k]
    for a single (b, h) pair.  Tile sizes are BLOCK_M×BLOCK_N and we tile
    over K with BLOCK_K.
    """
    pid = tl.program_id(0)

    # --------------------------------------------------------------
    # Decode pid → (b, h, block_i, block_j)
    # --------------------------------------------------------------
    num_i = tl.cdiv(N, BLOCK_M)
    num_j = tl.cdiv(N, BLOCK_N)

    block_j = pid % num_j
    pid = pid // num_j
    block_i = pid % num_i
    pid = pid // num_i
    h = pid % H
    b = pid // H

    # --------------------------------------------------------------
    # Offsets for the current tile
    # --------------------------------------------------------------
    offs_i = block_i * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_j = block_j * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_i = offs_i < N
    mask_j = offs_j < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # Loop over K dimension
    # --------------------------------------------------------------
    for k_tile in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = k_tile * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # left[b, h, i, k]  (M × K)
        l_ptr = (
            left_ptr
            + b * stride_lbh
            + h * stride_lhd
            + offs_i[:, None] * stride_lhn
            + offs_k[None, :] * stride_lhk
        )
        l = tl.load(l_ptr,
                    mask=mask_i[:, None] & mask_k[None, :],
                    other=0.0).to(tl.float32)

        # right[b, h, j, k] needs to be transposed → (K × N)
        r_ptr = (
            right_ptr
            + b * stride_rbh
            + h * stride_rhd
            + offs_k[:, None] * stride_rjk
            + offs_j[None, :] * stride_rjn
        )
        r = tl.load(r_ptr,
                    mask=mask_k[:, None] & mask_j[None, :],
                    other=0.0).to(tl.float32)

        # GEMM on the tile
        acc += tl.dot(l, r)          # (M,K) @ (K,N) → (M,N)

    # --------------------------------------------------------------
    # Store the tile
    # --------------------------------------------------------------
    out_ptrs = (
        out_ptr
        + b * stride_obh
        + h * stride_obd
        + offs_i[:, None] * stride_obn
        + offs_j[None, :] * stride_obj
    )
    tl.store(out_ptrs,
             acc.to(tl.float16),
             mask=mask_i[:, None] & mask_j[None, :])


# -------------------------------------------------------------------------
# Host‑side wrapper
# -------------------------------------------------------------------------
def custom_kernel(data: Tuple[torch.Tensor, torch.Tensor,
                               Dict[str, torch.Tensor],
                               Dict[str, Any]]) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.

    Args:
        data = (x, mask, weights, config)
        x        : (B, N, N, dim)      torch.float32
        mask     : (B, N, N) or None   torch.bool / float32
        weights  : dict of pretrained tensors
        config   : {"dim": dim, "hidden_dim": hidden_dim}

    Returns:
        out      : (B, N, N, dim)      torch.float32
    """
    x, mask, weights, config = data
    device = x.device
    dtype = torch.float32

    B, N, _, dim = x.shape
    hidden_dim = config["hidden_dim"]

    # -----------------------------------------------------------------
    # 1️⃣ Cheap ops in PyTorch
    # -----------------------------------------------------------------
    # LayerNorm over the last channel
    x = F.layer_norm(
        x,
        normalized_shape=(dim,),
        weight=weights["norm.weight"].to(dtype),
        bias=weights["norm.bias"].to(dtype),
    )

    # Linear projections (no bias)
    left  = F.linear(x, weights["left_proj.weight"].to(dtype))   # (B,N,N,hidden)
    right = F.linear(x, weights["right_proj.weight"].to(dtype))

    # -----------------------------------------------------------------
    # 2️⃣ Optional mask (broadcasted over hidden dim)
    # -----------------------------------------------------------------
    if mask is not None:
        mask_f = mask.to(dtype).unsqueeze(-1)          # (B,N,N,1)
        left = left * mask_f
        right = right * mask_f

    # -----------------------------------------------------------------
    # 3️⃣ Gating (sigmoid)
    # -----------------------------------------------------------------
    left_gate  = torch.sigmoid(F.linear(x, weights["left_gate.weight"].to(dtype)))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"].to(dtype)))
    out_gate   = torch.sigmoid(F.linear(x, weights["out_gate.weight"].to(dtype)))

    left  = left * left_gate
    right = right * right_gate

    # -----------------------------------------------------------------
    # 4️⃣ Prepare tensors for the Triton kernel
    #    (B,N,N,hidden) -> (B,hidden,N,N) and cast to fp16
    # -----------------------------------------------------------------
    left = left.permute(0, 3, 1, 2).contiguous()   # (B, H, N, N)
    right = right.permute(0, 3, 1, 2).contiguous()

    left_fp16 = left.to(torch.float16)
    right_fp16 = right.to(torch.float16)

    out_fp16 = torch.empty_like(left_fp16)          # (B, H, N, N) fp16

    # -----------------------------------------------------------------
    # 5️⃣ Triton launch
    # -----------------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    # number of program IDs = B * H * ceil(N/BLOCK_M) * ceil(N/BLOCK_N)
    grid = (
        triton.cdiv(B * hidden_dim *
                   triton.cdiv(N, BLOCK_M) *
                   triton.cdiv(N, BLOCK_N), 1),
    )

    _trimul_outgoing_kernel[grid](
        left_fp16,
        right_fp16,
        out_fp16,
        B, N, hidden_dim,
        left_fp16.stride(0), left_fp16.stride(1),
        left_fp16.stride(2), left_fp16.stride(3),
        right_fp16.stride(0), right_fp16.stride(1),
        right_fp16.stride(2), right_fp16.stride(3),
        out_fp16.stride(0), out_fp16.stride(1),
        out_fp16.stride(2), out_fp16.stride(3),
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # -----------------------------------------------------------------
    # 6️⃣ Finish in PyTorch
    # -----------------------------------------------------------------
    # back to (B,N,N,hidden)
    out = out_fp16.to(dtype).permute(0, 2, 3, 1).contiguous()

    # LayerNorm over hidden dimension
    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"].to(dtype),
        bias=weights["to_out_norm.bias"].to(dtype),
    )

    # Apply out‑gate and final linear projection
    out = out * out_gate
    out = F.linear(out, weights["to_out.weight"].to(dtype))

    return out
```

The kernel **must** be defined at module top‑level (as above) and launched
with an explicit grid.  All strides are passed from the host, so the kernel
works for any contiguous or non‑contiguous layout.  The implementation
conforms to the Triton 3.3.1 API and targets the NVIDIA H200 (SM 90).
