The “outgoing” TriMul operator can be split into three logical stages  

1. **Light‑weight work** – LayerNorm, linear projections, gating and the
   final LayerNorm / linear. These are cheap compared to the cubic‑cost
   contraction and are kept in pure PyTorch (fast BLAS + torch kernels).  

2. **Heavy work** – the einsum  

   ```
   out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
   ```

   This is a batched matrix multiplication with shapes  

   * `left`  : (B, H, I, K)   where `H = hidden_dim`, `I = N`, `K = N`  
   * `right` : (B, H, K, J)   where `J = N`  

   The contraction is identical to `torch.bmm` on each head, therefore the
   core can be expressed as a **tri‑dimensional GEMM**.  We implement it with a
   single Triton kernel that computes a tiled `I×K` × `K×J` product for each
   `(B, H)` pair.  The kernel uses FP16 arithmetic (Tensor‑cores) with FP32
   accumulation for numerical stability and stores the result back in FP16.
   Afterwards the tensor is cast to FP32 for the remaining (float‑32) steps.

3. **Re‑ordering** – The tensors are permuted before and after the kernel
   so that the Triton kernel works on contiguous memory (stride‑1 in the
   reduction dimension).  The permutation is cheap (`.permute(...).contiguous()`).

The implementation follows the “lessons learned” from earlier attempts:

| Lesson | How it is applied / why it is irrelevant |
|--------|------------------------------------------|
| **Limit shared memory** – keep `BLOCK_M,N ≤ 64`, `BLOCK_K = 32`. | Tile sizes are chosen to fit comfortably in the H200 shared‑memory budget. |
| **Delegate N³ to cuBLAS** – use cuBLAS for the contraction. | We *do* use a custom Triton kernel because the problem asks for a kernel and because we want to fuse the `left/right` layout permutation with the GEMM.  The kernel is essentially the same algorithm as cuBLAS but written in Triton, enabling future fusions. |
| **Match dtypes** – both operands FP16. | We cast the normalized input and all linear‑projected tensors to FP16 before the GEMM. |
| **Stride unpacking** – pass exact strides. | The kernel receives the three strides for each tensor (`z,i,k`/`z,k,j`/`z,i,j`). No assumptions on extra dimensions are made. |
| **Avoid unnecessary synchronisation** – compute mean/var in PyTorch. | LayerNorms stay in PyTorch; they are cheap compared to the GEMM and avoid writing a custom reduction kernel. |

The final `custom_kernel` function follows the signature required by the
grader and returns a **float‑32** tensor of shape `[B, N, N, dim]`.

```python
"""
TriMul “outgoing” forward pass (no gradients).

The cubic contraction
    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
is performed by a custom Triton kernel that treats the hidden dimension
as a “head” dimension and executes a batched GEMM (I×K)·(K×J) → (I×J)
for each head.  All other operations (LayerNorm, linear projections,
gating, final LayerNorm/linear) are carried out with PyTorch.
Mixed precision (fp16 compute, fp32 accumulation) is used for the
GEMM; the final result is cast back to fp32.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched GEMM for the N³ contraction
# ----------------------------------------------------------------------
@triton.jit
def tri_mul_gemm_kernel(
    a_ptr,            # left  tensor (Z, I, K)   fp16
    b_ptr,            # right tensor (Z, K, J)   fp16
    c_ptr,            # output (Z, I, J)          fp16
    M, N, K,          # dimensions I, J, K
    stride_az, stride_am, stride_ak,   # a strides (z,i,k)
    stride_bz, stride_bk, stride_bn,   # b strides (z,k,j)
    stride_cz, stride_cm, stride_cn,   # c strides (z,i,j)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    # --------------------------------------------------------------
    # Tile indices
    # --------------------------------------------------------------
    pid_z = tl.program_id(0)      # batch*head dimension
    pid_m = tl.program_id(1)      # row tile
    pid_n = tl.program_id(2)      # col tile

    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in fp32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # Loop over K dimension
    # --------------------------------------------------------------
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )   # (BLOCK_M, BLOCK_K) fp16

        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )   # (BLOCK_K, BLOCK_N) fp16

        # fp32 accumulation (Tensor‑core dot works on fp16 -> fp32)
        acc += tl.dot(a, b)

    # --------------------------------------------------------------
    # Store result (converted back to fp16)
    # --------------------------------------------------------------
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


def triton_batched_gemm(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Batched GEMM for TriMul.

    left  : (B, H, I, K)   fp16, contiguous
    right : (B, H, K, J)   fp16, contiguous
    returns: (B, H, I, J)  fp16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # Collapse leading dimensions for the kernel
    Z = B * H
    a = left.reshape(Z, I, K)
    b = right.reshape(Z, K, J)
    c = out.reshape(Z, I, J)

    # strides in element units
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # Tile sizes – tuned for Hopper (SM90)
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        Z,                                 # program_id(0) – batch*head
        triton.cdiv(I, BLOCK_M),           # program_id(1) – rows
        triton.cdiv(J, BLOCK_N),           # program_id(2) – cols
    )
    tri_mul_gemm_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,            # works well for fp16 on H200
    )
    return out


# ----------------------------------------------------------------------
# Public entry point
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Parameters
    ----------
    data : tuple (input_tensor, mask, weights, config)
        input_tensor : torch.Tensor [B, N, N, dim] (float32)
        mask         : torch.Tensor [B, N, N] (float32/ bool) or None
        weights      : dict of parameter tensors (see docstring above)
        config       : dict with keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor [B, N, N, dim] (float32)
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    eps = 1e-5

    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]

    # ------------------------------
    # 1. Input LayerNorm (float32)
    # ------------------------------
    norm_w = weights["norm.weight"]
    norm_b = weights["norm.bias"]
    mean = input_tensor.mean(-1, keepdim=True)
    var = input_tensor.var(-1, unbiased=False, keepdim=True)
    x = (input_tensor - mean) / torch.sqrt(var + eps)
    x = x * norm_w + norm_b               # still fp32

    # -------------------------------------------------
    # 2. Linear projections & gating (cast to fp16)
    # -------------------------------------------------
    def to_fp16(t):
        return t.to(torch.float16, non_blocking=True)

    left_proj_w = to_fp16(weights["left_proj.weight"])
    right_proj_w = to_fp16(weights["right_proj.weight"])
    left_gate_w = to_fp16(weights["left_gate.weight"])
    right_gate_w = to_fp16(weights["right_gate.weight"])
    out_gate_w = to_fp16(weights["out_gate.weight"])

    # keep the final LayerNorm / linear in fp32
    to_out_norm_w = weights["to_out_norm.weight"]
    to_out_norm_b = weights["to_out_norm.bias"]
    to_out_w = weights["to_out.weight"]

    x_fp16 = x.to(torch.float16)

    left = F.linear(x_fp16, left_proj_w)   # (B,N,N,hidden_dim)
    right = F.linear(x_fp16, right_proj_w)

    # -------------------------------------------------
    # 3. Apply mask (if present) – broadcast over hidden dim
    # -------------------------------------------------
    if mask is not None:
        # mask: [B,N,N] → [B,N,N,1]
        mask_fp16 = mask.to(torch.float16).unsqueeze(-1)
        left = left * mask_fp16
        right = right * mask_fp16

    # -------------------------------------------------
    # 4. Gating
    # -------------------------------------------------
    left_gate = F.linear(x_fp16, left_gate_w).sigmoid()
    right_gate = F.linear(x_fp16, right_gate_w).sigmoid()
    out_gate = F.linear(x_fp16, out_gate_w).sigmoid()

    left = left * left_gate
    right = right * right_gate

    # -------------------------------------------------
    # 5. Triton batched GEMM (the N³ contraction)
    # -------------------------------------------------
    # Permute to (B, H, I, K) and (B, H, K, J) where
    #   I = N (row index i), J = N (col index j), K = N (summation index)
    left_perm = left.permute(0, 3, 1, 2).contiguous()   # (B, H, I, K)
    right_perm = right.permute(0, 3, 2, 1).contiguous() # (B, H, K, J)

    out_fp16 = triton_batched_gemm(left_perm, right_perm)   # (B, H, I, J) fp16

    # Restore original layout: (B, N, N, hidden_dim) → (B, N, N, dim)
    out = out_fp16.permute(0, 2, 3, 1).contiguous()   # (B,N,N,hidden_dim)
    out = out.to(torch.float32)                       # back to fp32

    # -------------------------------------------------
    # 6. Output LayerNorm (float32)
    # -------------------------------------------------
    mean_o = out.mean(-1, keepdim=True)
    var_o = out.var(-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + eps)
    out = out * to_out_norm_w + to_out_norm_b

    # -------------------------------------------------
    # 7. Final gating + linear projection (float32)
    # -------------------------------------------------
    out = out * out_gate.to(torch.float32)
    out = F.linear(out, to_out_w)

    return out
```
