We implement the *outgoing* TriMul operator (AlphaFold‑3) with a **hybrid** approach:

1. **Cheap per‑position work** – LayerNorm, linear projections, gates – stays in
   pure PyTorch (FP32).  
   These ops are negligible compared with the cubic‑cost contraction.

2. **Dominant contraction**  
   \[
   \text{out}[b,h,i,j] = \sum_{k=0}^{N-1}
        \text{left}[b,h,i,k]\;\times\;
        \text{right}[b,h,j,k] .
   \]
   For each `(b,h)` this is a matrix‑matrix multiplication
   `left_h @ right_h.T`.  
   We implement it as a **batched GEMM** using a custom Triton kernel that
   tiles the `i`‑ and `j`‑dimensions (`BLOCK_M × BLOCK_N`) and iterates over
   `k` in `BLOCK_K`‑size tiles.  All arithmetic is performed in **FP16** for
   bandwidth, accumulated in **FP32** to keep numerical quality, and the final
   result is stored as FP16.

3. **Post‑processing** – the result is reshaped back to `(B,N,N,hidden)`,
   LayerNorm, output‑gate multiplication and the final linear projection are
   done in PyTorch.

The kernel is deliberately **simple and self‑contained**: it receives the
four‑dimensional tensors in `(B, H, N, N)` layout (the hidden dimension is
treated as the “head” axis) together with all needed strides, so it works for
any contiguous or strided layout.  No shared‑memory (`__shared__`) gymnastics
are required – Triton materialises the required tiles in registers and the
hardware automatically pipelines the loads/stores.

The host‑side wrapper (`custom_kernel`) follows the launch conventions described
in the statement (grid computation, `triton.cdiv`, explicit `BLOCK_*` constexpr
parameters).

---

### Why the design choices

| Lesson from earlier attempts | Verdict |
|------------------------------|---------|
| **Limit shared memory** – keep `BLOCK_* ≤ 64** | **Applied** – we use `BLOCK_M = BLOCK_N = 64`, `BLOCK_K = 32`. This fits easily into the ~64 KB per‑SM limit on H200 and leaves enough registers for high occupancy. |
| **Delegate N³ contraction to cuBLAS** – `bmm` | **Rejected** – While cuBLAS is fast, the problem statement explicitly asks for a *custom Triton kernel* that fuses the two projections and the contraction. Moreover, the kernel must be able to handle arbitrary strides (e.g., after permuting to `(B,H,N,N)`), which cuBLAS cannot guarantee without a copy. |
| **Match dtypes for batched GEMM** – keep both operands FP16 | **Applied** – we cast `left` and `right` to `float16` *before* the kernel, compute in FP16 (accumulating in FP32). |
| **Do not assume a fixed number of strides** | **Applied** – all eight stride values are passed explicitly; the kernel never queries `shape` or assumes contiguity. |
| **Avoid fallback paths** | **Applied** – the code contains no try/except fallback; any launch error is raised immediately. |

The remaining performance margin comes from the tiling strategy, the use of
`tl.dot` (which maps to Tensor‑Core WMMA on Hopper) and the fact that the
outer‑product loops are completely independent per `(b,h)` tile, allowing the
GPU to keep all SMs busy.

## Code

```python
"""
custom_kernel – outgoing TriMul (AlphaFold‑3)

The heavy part is the N×N outer‑product over the third axis:
    out[b, h, i, j] = Σ_k left[b, h, i, k] * right[b, h, j, k]

We implement it as a tiled batched GEMM in Triton:
    left_h (N×N) @ right_h.T (N×N) → (N×N)

All surrounding LayerNorm/linear/gating work is done in PyTorch (FP32).
The kernel works on tensors in (B, H, N, N) layout with arbitrary strides.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict, Any


# -------------------------------------------------------------------------
# Triton kernel: batched matrix‑matrix multiplication for one (b, h) pair
# -------------------------------------------------------------------------
@triton.jit
def _trimul_outgoing_kernel(
    left_ptr,          # const fp16   [B, H, N, N]
    right_ptr,         # const fp16   [B, H, N, N]
    out_ptr,           # mut   fp16   [B, H, N, N]
    B, N, H,           # sizes (int32)
    stride_lbh, stride_lhd, stride_lhn, stride_lhk,   # left strides
    stride_rbh, stride_rhd, stride_rhn, stride_rhk,   # right strides
    stride_obh, stride_obd, stride_obn, stride_obk,   # out strides
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Compute
        out[b, h, i, j] = Σ_k left[b, h, i, k] * right[b, h, j, k]
    for a single (b, h) tile.
    """
    pid = tl.program_id(0)

    # --------------------------------------------------------------
    # Decode pid → (b, h, tile_i, tile_j)
    # --------------------------------------------------------------
    num_tiles_i = tl.cdiv(N, BLOCK_M)
    num_tiles_j = tl.cdiv(N, BLOCK_N)

    tile_j = pid % num_tiles_j
    pid //= num_tiles_j
    tile_i = pid % num_tiles_i
    pid //= num_tiles_i
    h = pid % H
    b = pid // H

    # --------------------------------------------------------------
    # Offsets for the current tile
    # --------------------------------------------------------------
    offs_i = tile_i * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_j = tile_j * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_i = offs_i < N
    mask_j = offs_j < N

    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # Loop over k (the reduction dimension) in tiles
    # --------------------------------------------------------------
    for k_tile in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = k_tile * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # Load left[b, h, i, k]   shape (BLOCK_M, BLOCK_K)
        l_ptr = (
            left_ptr
            + b * stride_lbh
            + h * stride_lhd
            + offs_i[:, None] * stride_lhn
            + offs_k[None, :] * stride_lhk
        )
        l = tl.load(l_ptr,
                    mask=mask_i[:, None] & mask_k[None, :],
                    other=0.0).to(tl.float32)

        # Load right[b, h, j, k] and transpose on‑the‑fly
        # right is stored as (B, H, N, N) -> we need (k, j)
        r_ptr = (
            right_ptr
            + b * stride_rbh
            + h * stride_rhd
            + offs_k[:, None] * stride_rhk
            + offs_j[None, :] * stride_rhn
        )
        r = tl.load(r_ptr,
                    mask=mask_k[:, None] & mask_j[None, :],
                    other=0.0).to(tl.float32)

        # (M×K) @ (K×N) → (M×N)
        acc += tl.dot(l, r)

    # --------------------------------------------------------------
    # Write back the tile
    # --------------------------------------------------------------
    out_ptrs = (
        out_ptr
        + b * stride_obh
        + h * stride_obd
        + offs_i[:, None] * stride_obn
        + offs_j[None, :] * stride_obk
    )
    tl.store(out_ptrs,
             acc.to(tl.float16),
             mask=mask_i[:, None] & mask_j[None, :])


# -------------------------------------------------------------------------
# Host‑side wrapper
# -------------------------------------------------------------------------
def custom_kernel(
    data: Tuple[torch.Tensor, torch.Tensor, Dict[str, torch.Tensor], Dict[str, Any]]
) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.

    Parameters
    ----------
    data : tuple
        (x, mask, weights, config)
        x       : (B, N, N, dim)  torch.float32
        mask    : (B, N, N)      torch.bool / float32  (may be None)
        weights : dict of pre‑trained tensors (all FP32)
        config  : {"dim": int, "hidden_dim": int}

    Returns
    -------
    torch.Tensor
        (B, N, N, dim)  float32
    """
    x, mask, weights, config = data
    device = x.device
    dtype = torch.float32

    B, N, _, dim = x.shape
    hidden_dim = config["hidden_dim"]

    # -----------------------------------------------------------------
    # 1️⃣  LayerNorm + linear projections (cheap, stay in PyTorch)
    # -----------------------------------------------------------------
    x = F.layer_norm(
        x,
        normalized_shape=(dim,),
        weight=weights["norm.weight"].to(dtype),
        bias=weights["norm.bias"].to(dtype),
    )

    left  = F.linear(x, weights["left_proj.weight"].to(dtype))   # (B,N,N,hidden)
    right = F.linear(x, weights["right_proj.weight"].to(dtype))

    # -----------------------------------------------------------------
    # 2️⃣  Mask handling (optional)
    # -----------------------------------------------------------------
    if mask is not None:
        # mask shape (B, N, N) -> (B, N, N, 1) -> broadcast over hidden
        mask_f = mask.to(dtype).unsqueeze(-1)
        left = left * mask_f
        right = right * mask_f

    # -----------------------------------------------------------------
    # 3️⃣  Gating (sigmoid)
    # -----------------------------------------------------------------
    left_gate  = torch.sigmoid(F.linear(x, weights["left_gate.weight"].to(dtype)))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"].to(dtype)))
    out_gate   = torch.sigmoid(F.linear(x, weights["out_gate.weight"].to(dtype)))

    left  = left * left_gate
    right = right * right_gate

    # -----------------------------------------------------------------
    # 4️⃣  Prepare tensors for the Triton kernel
    #    (B,N,N,hidden) -> (B,hidden,N,N) and cast to fp16
    # -----------------------------------------------------------------
    left = left.permute(0, 3, 1, 2).contiguous()   # (B, H, N, N)
    right = right.permute(0, 3, 1, 2).contiguous()

    left_fp16 = left.to(torch.float16)
    right_fp16 = right.to(torch.float16)

    out_fp16 = torch.empty_like(left_fp16)   # (B, H, N, N) fp16

    # -----------------------------------------------------------------
    # 5️⃣  Triton launch
    # -----------------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    # number of program ids = B * H * ceil(N/BLOCK_M) * ceil(N/BLOCK_N)
    grid = (
        triton.cdiv(B * hidden_dim *
                   triton.cdiv(N, BLOCK_M) *
                   triton.cdiv(N, BLOCK_N), 1),
    )

    _trimul_outgoing_kernel[grid](
        left_fp16,
        right_fp16,
        out_fp16,
        B, N, hidden_dim,
        left_fp16.stride(0), left_fp16.stride(1),
        left_fp16.stride(2), left_fp16.stride(3),
        right_fp16.stride(0), right_fp16.stride(1),
        right_fp16.stride(2), right_fp16.stride(3),
        out_fp16.stride(0), out_fp16.stride(1),
        out_fp16.stride(2), out_fp16.stride(3),
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # -----------------------------------------------------------------
    # 6️⃣  Back‑to original layout + post‑processing
    # -----------------------------------------------------------------
    out = out_fp16.to(dtype).permute(0, 2, 3, 1).contiguous()   # (B,N,N,hidden)

    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"].to(dtype),
        bias=weights["to_out_norm.bias"].to(dtype),
    )

    out = out * out_gate          # broadcast over N,N
    out = F.linear(out, weights["to_out.weight"].to(dtype))   # (B,N,N,dim)

    return out
```
