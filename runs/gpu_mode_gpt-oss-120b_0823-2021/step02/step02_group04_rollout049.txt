We implement the *outgoing* TriMul operator (AlphaFold‑3) with a **single Triton kernel** that fuses the three sigmoid‑gates together with the optional mask.  
All other heavy work (the N³ contraction) is delegated to cuBLAS via a batched matrix‑multiply (`torch.matmul`) – this gives the best performance on Hopper/H200 while keeping the code simple and correct.

The kernel works on tensors of shape **[B, N, N, H]** (`H = hidden_dim`).  
For each element `(b,i,k,d)` it performs

```
left[b,i,k,d]   = left[b,i,k,d]   * mask[b,i,k] * sigmoid(left_gate[b,i,k,d])
right[b,i,k,d]  = right[b,i,k,d]  * mask[b,i,k] * sigmoid(right_gate[b,i,k,d])
out_gate[b,i,k,d]= sigmoid(out_gate[b,i,k,d])
```

`mask` is broadcasted over the hidden dimension.  
The kernel updates `left`, `right` **in‑place** and writes the sigmoided `out_gate` back, so the host can continue with a single `torch.matmul`.

The overall forward pass is:

1. **LayerNorm** on the input (`dim`).
2. **Linear projections** → `left`, `right`, and the three *pre‑sigmoid* gate tensors.
3. **Mask & gate fusion** via the Triton kernel.
4. **Core contraction**  
   `out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]`  
   Implemented as a batched matmul after permuting to `(B, H, N, K)`.
5. **Final LayerNorm**, element‑wise multiplication by `out_gate`, and a final linear projection back to `dim`.

All tensors are kept in `float32` (the reference implementation uses `float32`).  
The kernel is written for arbitrary batch size `B∈{1,2}` and sequence lengths up to 1024, and works with or without a mask.

### Why the design matches the lessons

| Lesson | How it is applied / why not needed |
|--------|------------------------------------|
| **Limit shared memory** | The kernel only loads a few scalars per thread, no shared memory is used. |
| **Delegate N³ contraction to cuBLAS** | Exactly what we do – a batched `torch.matmul` (cuBLAS) handles the dominant work. |
| **Match dtypes for batched GEMM** | All tensors stay `float32`; no mixed‑precision conversion is required. |
| **Stride handling** | Strides are passed explicitly from the host; we never assume a fixed number of dimensions. |
| **Other suggestions (e.g., tiling, shared‑memory reductions)** | Not needed because the heavy part is off‑loaded to cuBLAS and the kernel only does element‑wise work. |

The only Triton kernel we need is the element‑wise mask‑gate fusion; it is lightweight, launches with a large block size (1024) to keep launch overhead low and fully utilizes the H200’s register file.

## Code

```python
"""
TriMul – outgoing version (AlphaFold‑3)

* Stage 0 – LayerNorm on the input (PyTorch).
* Stage 1 – Linear projections (left/right) and three gate projections
    (bias‑free, PyTorch).
* Stage 2 – Fuse optional mask and three sigmoid gates into the projected
    tensors using a single Triton kernel (in‑place).
* Stage 3 – Core contraction:
        out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
    performed as a batched matrix multiplication with cuBLAS.
* Stage 4 – Final LayerNorm, out‑gate scaling and linear projection back to dim
    (PyTorch).

The Triton kernel handles only the element‑wise part; the O(N³) work is
delegated to cuBLAS for optimal performance on Hopper/H200.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: mask + three sigmoid gates → left, right, out_gate (in‑place)
# ----------------------------------------------------------------------
@triton.jit
def _mask_gate_fuse_kernel(
    left_ptr, right_ptr,                 # [B,N,N,H] float32
    mask_ptr,                            # [B,N,N,1] float32 (broadcasted)
    left_gate_ptr, right_gate_ptr, out_gate_ptr,  # [B,N,N,H] float32 (pre‑sigmoid)
    B, N, H,
    # strides (int64)
    stride_left_b, stride_left_i, stride_left_k, stride_left_h,
    stride_right_b, stride_right_i, stride_right_k, stride_right_h,
    stride_mask_b, stride_mask_i, stride_mask_k, stride_mask_1,
    stride_lgate_b, stride_lgate_i, stride_lgate_k, stride_lgate_h,
    stride_rgate_b, stride_rgate_i, stride_rgate_k, stride_rgate_h,
    stride_ogate_b, stride_ogate_i, stride_ogate_k, stride_ogate_h,
    BLOCK: tl.constexpr,
):
    """
    For each element (b,i,k,d):
        left  = left  * mask * sigmoid(left_gate)
        right = right * mask * sigmoid(right_gate)
        out_gate = sigmoid(out_gate)     (stored back in‑place)

    mask is broadcasted over the hidden dimension (d).
    """
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)          # linear index
    total = B * N * N * H
    mask = offs < total

    # Decode linear index → (b,i,k,d)
    idx = offs
    d = idx % H
    idx = idx // H
    k = idx % N
    idx = idx // N
    i = idx % N
    b = idx // N

    # Compute pointers
    left   = left_ptr   + b * stride_left_b   + i * stride_left_i   + k * stride_left_k   + d * stride_left_h
    right  = right_ptr  + b * stride_right_b  + i * stride_right_i  + k * stride_right_k  + d * stride_right_h
    mask_p = mask_ptr   + b * stride_mask_b   + i * stride_mask_i   + k * stride_mask_k   # 1‑channel
    lgate  = left_gate_ptr  + b * stride_lgate_b  + i * stride_lgate_i  + k * stride_lgate_k  + d * stride_lgate_h
    rgate  = right_gate_ptr + b * stride_rgate_b + i * stride_rgate_i + k * stride_rgate_k + d * stride_rgate_h
    ogate  = out_gate_ptr   + b * stride_ogate_b   + i * stride_ogate_i   + k * stride_ogate_k   + d * stride_ogate_h

    # Load values
    l = tl.load(left,  mask=mask, other=0.0)
    r = tl.load(right, mask=mask, other=0.0)
    m = tl.load(mask_p, mask=mask, other=1.0)   # 1.0 if no mask (mask tensor of ones)
    lg = tl.load(lgate, mask=mask, other=0.0)
    rg = tl.load(rgate, mask=mask, other=0.0)
    og = tl.load(ogate, mask=mask, other=0.0)

    # Sigmoid (stable formulation)
    lg = 1.0 / (1.0 + tl.exp(-lg))
    rg = 1.0 / (1.0 + tl.exp(-rg))
    og = 1.0 / (1.0 + tl.exp(-og))

    # Fuse
    l = l * m * lg
    r = r * m * rg

    # Store back
    tl.store(left,  l, mask=mask)
    tl.store(right, r, mask=mask)
    tl.store(ogate, og, mask=mask)


def _apply_mask_and_gates(
    left: torch.Tensor,
    right: torch.Tensor,
    mask: torch.Tensor,
    left_gate: torch.Tensor,
    right_gate: torch.Tensor,
    out_gate: torch.Tensor,
) -> torch.Tensor:
    """
    Launches the Triton kernel that updates ``left`` and ``right`` in‑place
    and returns the sigmoided ``out_gate``.
    All tensors have shape (B, N, N, H) except ``mask`` which is (B, N, N, 1).
    """
    B, N, _, H = left.shape
    total = B * N * N * H
    BLOCK = 1024  # good trade‑off between occupancy and launch overhead
    grid = (triton.cdiv(total, BLOCK),)

    _mask_gate_fuse_kernel[grid](
        left, right,
        mask,
        left_gate, right_gate, out_gate,
        B, N, H,
        # strides
        left.stride(0), left.stride(1), left.stride(2), left.stride(3),
        right.stride(0), right.stride(1), right.stride(2), right.stride(3),
        mask.stride(0), mask.stride(1), mask.stride(2), mask.stride(3),
        left_gate.stride(0), left_gate.stride(1), left_gate.stride(2), left_gate.stride(3),
        right_gate.stride(0), right_gate.stride(1), right_gate.stride(2), right_gate.stride(3),
        out_gate.stride(0), out_gate.stride(1), out_gate.stride(2), out_gate.stride(3),
        BLOCK=BLOCK,
    )
    return out_gate  # already sigmoided


# ----------------------------------------------------------------------
# Public entry point
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask_tensor, weights_dict, config_dict)

        - input_tensor : torch.Tensor of shape [B, N, N, dim] (float32 or bf16)
        - mask_tensor  : torch.Tensor of shape [B, N, N] or None
        - weights_dict : mapping with keys:
            * "norm.weight", "norm.bias"
            * "left_proj.weight", "right_proj.weight"
            * "left_gate.weight", "right_gate.weight", "out_gate.weight"
            * "to_out_norm.weight", "to_out_norm.bias"
            * "to_out.weight"
        - config_dict  : {"dim": int, "hidden_dim": int}
    Returns
    -------
    torch.Tensor of shape [B, N, N, dim] (float32)
    """
    # --------------------------------------------------------------
    # unpack
    # --------------------------------------------------------------
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    B, N, _, dim = input_tensor.shape
    hidden = config["hidden_dim"]

    # --------------------------------------------------------------
    # 0️⃣ Input LayerNorm over the last dimension (dim)
    # --------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        (dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
    )  # (B, N, N, dim)

    # --------------------------------------------------------------
    # 1️⃣ Linear projections (bias‑free) → [B,N,N,hidden]
    # --------------------------------------------------------------
    left  = F.linear(x, weights["left_proj.weight"])   # (B,N,N,hidden)
    right = F.linear(x, weights["right_proj.weight"])

    # --------------------------------------------------------------
    # 2️⃣ Gate tensors (pre‑sigmoid) → same shape
    # --------------------------------------------------------------
    left_gate  = F.linear(x, weights["left_gate.weight"])
    right_gate = F.linear(x, weights["right_gate.weight"])
    out_gate   = F.linear(x, weights["out_gate.weight"])

    # --------------------------------------------------------------
    # 3️⃣ Prepare mask (broadcast to 4‑D) – if None use all‑ones
    # --------------------------------------------------------------
    if mask is None:
        mask4d = torch.ones((B, N, N, 1), dtype=input_tensor.dtype, device=device)
    else:
        mask4d = mask.unsqueeze(-1).to(input_tensor.dtype)   # (B,N,N,1)

    # --------------------------------------------------------------
    # 4️⃣ Fuse mask + sigmoid gates (Triton kernel)
    # --------------------------------------------------------------
    out_gate = _apply_mask_and_gates(left, right, mask4d,
                                    left_gate, right_gate, out_gate)

    # --------------------------------------------------------------
    # 5️⃣ Core contraction: out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
    # --------------------------------------------------------------
    # Convert to (B, hidden, N, K) for batched matmul
    left_t  = left.permute(0, 3, 1, 2)          # (B, hidden, N, K)
    right_t = right.permute(0, 3, 1, 2)         # (B, hidden, N, K)

    # Batched matmul over the K dimension
    # (B, hidden, N, N) = (B, hidden, N, K) @ (B, hidden, N, K)^T
    out_t = torch.matmul(left_t, right_t.transpose(-1, -2))

    # Back to original layout (B, N, N, hidden)
    out = out_t.permute(0, 2, 3, 1)

    # --------------------------------------------------------------
    # 6️⃣ Final LayerNorm → out_gate scaling → linear projection back to dim
    # --------------------------------------------------------------
    out = F.layer_norm(
        out,
        (hidden,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
    )
    out = out * out_gate                     # element‑wise gating
    out = F.linear(out, weights["to_out.weight"])

    # Final dtype must be float32 as required by the spec
    return out.to(torch.float32)
```

**Key points**

* The heavy N³ operation is performed by cuBLAS (`torch.matmul`), which on Hopper reaches near‑theoretical TFLOP performance.
* The Triton kernel is completely vectorised, processes `BLOCK=1024` elements per thread block, and uses only registers – no shared memory, no synchronization.
* All strides are passed explicitly, so the kernel works for any memory layout produced by PyTorch contiguous tensors.
* The function respects the optional mask (`nomask` case) by providing a mask of ones when `mask` is `None`.
* The output is forced to `float32`, matching the reference implementation.
