The TriMul “outgoing’’ update consists of three stages  

1. **Layer‑norm + linear projections + gating** – cheap `O(B·N²·C)` work that we keep in PyTorch.  
2. **Core contraction**  

\[
\text{out}_{b,h,i,j}= \sum_{k=0}^{N-1}
      \underbrace{\text{left}_{b,h,i,k}}_{\text{proj\,+gate}}
      \;\times\;
      \underbrace{\text{right}_{b,h,j,k}}_{\text{proj\,+gate}}
\]

   For every hidden slice `h` we have a matrix‑matrix multiply  
   `left[b,h] @ right[b,h].T` of shape `(N,N)`.  
   This is the only `O(N³)` part and must be done in a fast Triton kernel.  

3. **Output layer‑norm, gating and final linear** – again cheap, done in PyTorch.

The kernel works on **one (batch, hidden) tile** at a time, i.e. it computes a
`BLOCK_M × BLOCK_N` sub‑matrix of the result.  The K‑dimension is tiled with
`BLOCK_K`.  All arithmetic is performed in **FP16** for bandwidth, accumulated
in **FP32** to keep numerical quality, and the result is written back as FP16.
The surrounding PyTorch code converts back to `float32` and applies the last
normalisation / linear projection.

The implementation follows the classic triton “blocked GEMM’’ pattern:

* decode the program id → `(b, h, block_i, block_j)`
* load the current `M×K` tile of `left` and the transposed `K×N` tile of `right`
* `acc += tl.dot(left_tile, right_tile)`
* after the K‑loop store the accumulated FP32 result as FP16.

The kernel is launched with a 1‑D grid whose size equals

```
num_programs = B * H * ceil(N / BLOCK_M) * ceil(N / BLOCK_N)
```

All strides are passed explicitly so the kernel works for any contiguous or
non‑contiguous layout.

---

### Why the previous “global‑cuBLAS’’ suggestion is not used

* The problem statement explicitly asks for **“implement at least part of the
operations in a kernel’’** – a pure `torch.bmm` call would violate that.
* The Triton kernel also demonstrates the required “fusion’’ of the three‑dim
contraction, which is the essence of the TriMul operator.

---

### Lessons from earlier attempts

| Lesson | Relevance |
|--------|-----------|
| **Limit shared‑memory usage** – keep block sizes ≤ 64 × 64 × 32. | Applied – the chosen block sizes fit easily into the H200 shared‑memory budget. |
| **Delegate N³ to cuBLAS** – fast but violates “use a kernel”. | Not used (see above). |
| **Match dtypes for batched GEMM** – both operands must be FP16. | Applied – we cast `left` and `right` to `float16` before the kernel. |
| **Correct stride unpacking** – must pass exactly four strides for a 4‑D tensor. | Applied – all four strides are passed explicitly. |

No other lessons conflict with the current design.

```python
"""
TriMul outgoing kernel (AlphaFold‑3)

* Cheap parts (LayerNorm, linear projections, gating) are performed in PyTorch.
* The O(N³) contraction is executed by a custom Triton kernel that computes
  for each hidden slice h:
        out[b, h, i, j] = Σ_k left[b, h, i, k] * right[b, h, j, k]
  i.e. a batched matrix‑multiply (left @ rightᵀ).
* FP16 is used inside the kernel for bandwidth, accumulation in FP32,
  final output cast back to FP16 → FP32 in the host code.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict, Any


# -------------------------------------------------------------------------
# Triton kernel: batched GEMM for a single (batch, hidden) pair
# -------------------------------------------------------------------------
@triton.jit
def _trimul_outgoing_kernel(
    left_ptr,          # const fp16   [B, H, N, N]
    right_ptr,         # const fp16   [B, H, N, N]
    out_ptr,           #      fp16   [B, H, N, N]
    B, N, H,           # int32 scalars
    stride_lbh, stride_lhd, stride_lhn, stride_lhk,   # left strides
    stride_rbh, stride_rhd, stride_rhn, stride_rhk,   # right strides
    stride_obh, stride_obd, stride_obn, stride_obk,   # out strides
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Compute a BLOCK_M×BLOCK_N tile of
        out[b, h, i, j] = Σ_k left[b, h, i, k] * right[b, h, j, k]

    The K‑loop is tiled with BLOCK_K.  All loads/stores are masked.
    """
    pid = tl.program_id(0)

    # --------------------------------------------------------------
    # Decode program id → (b, h, tile_i, tile_j)
    # --------------------------------------------------------------
    num_tiles_i = tl.cdiv(N, BLOCK_M)
    num_tiles_j = tl.cdiv(N, BLOCK_N)

    tile_j = pid % num_tiles_j
    pid //= num_tiles_j
    tile_i = pid % num_tiles_i
    pid //= num_tiles_i
    h = pid % H
    b = pid // H

    # --------------------------------------------------------------
    # Offsets for the current tile
    # --------------------------------------------------------------
    offs_i = tile_i * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_j = tile_j * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_i = offs_i < N
    mask_j = offs_j < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # Loop over K dimension
    # --------------------------------------------------------------
    for k_tile in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = k_tile * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # left[b, h, i, k]   shape (M, K)
        l_ptr = (
            left_ptr
            + b * stride_lbh
            + h * stride_lhd
            + offs_i[:, None] * stride_lhn
            + offs_k[None, :] * stride_lhk
        )
        l = tl.load(l_ptr,
                    mask=mask_i[:, None] & mask_k[None, :],
                    other=0.0).to(tl.float32)

        # right[b, h, j, k] needs to be transposed → (K, N)
        r_ptr = (
            right_ptr
            + b * stride_rbh
            + h * stride_rhd
            + offs_k[:, None] * stride_rhk
            + offs_j[None, :] * stride_rhn
        )
        r = tl.load(r_ptr,
                    mask=mask_k[:, None] & mask_j[None, :],
                    other=0.0).to(tl.float32)

        # accumulate M×K @ K×N → M×N
        acc += tl.dot(l, r)

    # --------------------------------------------------------------
    # Write back the tile (cast to fp16)
    # --------------------------------------------------------------
    out_ptrs = (
        out_ptr
        + b * stride_obh
        + h * stride_obd
        + offs_i[:, None] * stride_obn
        + offs_j[None, :] * stride_obk
    )
    tl.store(out_ptrs,
             acc.to(tl.float16),
             mask=mask_i[:, None] & mask_j[None, :])

# -------------------------------------------------------------------------
# Host‑side wrapper
# -------------------------------------------------------------------------
def custom_kernel(
    data: Tuple[torch.Tensor, torch.Tensor,
                Dict[str, torch.Tensor],
                Dict[str, Any]]
) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.

    Parameters
    ----------
    data : tuple
        (x, mask, weights, config)
        x            : (B, N, N, dim)            float32
        mask         : (B, N, N)                 bool / float32  (may be None)
        weights      : dict of model parameters
        config       : {"dim": dim, "hidden_dim": hidden_dim}

    Returns
    -------
    torch.Tensor
        (B, N, N, dim)  float32
    """
    x, mask, weights, config = data
    device = x.device
    dtype = torch.float32

    B, N, _, dim = x.shape
    hidden_dim = config["hidden_dim"]

    # -----------------------------------------------------------------
    # 1️⃣ LayerNorm + Linear projections (cheap, stay in PyTorch)
    # -----------------------------------------------------------------
    x = F.layer_norm(
        x,
        normalized_shape=(dim,),
        weight=weights["norm.weight"].to(dtype),
        bias=weights["norm.bias"].to(dtype),
    )

    left  = F.linear(x, weights["left_proj.weight"].to(dtype))   # (B,N,N,hidden)
    right = F.linear(x, weights["right_proj.weight"].to(dtype))

    # -----------------------------------------------------------------
    # 2️⃣ Optional mask (broadcast over hidden dim)
    # -----------------------------------------------------------------
    if mask is not None:
        mask = mask.to(dtype).unsqueeze(-1)       # (B,N,N,1)
        left = left * mask
        right = right * mask

    # -----------------------------------------------------------------
    # 3️⃣ Gating (sigmoid)
    # -----------------------------------------------------------------
    left_gate  = torch.sigmoid(F.linear(x, weights["left_gate.weight"].to(dtype)))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"].to(dtype)))
    out_gate   = torch.sigmoid(F.linear(x, weights["out_gate.weight"].to(dtype)))

    left  = left * left_gate
    right = right * right_gate

    # -----------------------------------------------------------------
    # 4️⃣ Rearrange to (B, H, N, N) and cast to fp16 for the kernel
    # -----------------------------------------------------------------
    # (B,N,N,H) -> (B,H,N,N)
    left = left.permute(0, 3, 1, 2).contiguous()
    right = right.permute(0, 3, 1, 2).contiguous()

    left_fp16  = left.to(torch.float16)
    right_fp16 = right.to(torch.float16)

    out_fp16 = torch.empty_like(left_fp16)   # (B,H,N,N) fp16

    # -----------------------------------------------------------------
    # 5️⃣ Triton launch – blocked GEMM over the K dimension
    # -----------------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    # number of program ids = B * H * ceil(N/BLOCK_M) * ceil(N/BLOCK_N)
    grid = (
        triton.cdiv(B * hidden_dim *
                   triton.cdiv(N, BLOCK_M) *
                   triton.cdiv(N, BLOCK_N), 1),
    )

    _trimul_outgoing_kernel[grid](
        left_fp16,
        right_fp16,
        out_fp16,
        B, N, hidden_dim,
        left_fp16.stride(0), left_fp16.stride(1),
        left_fp16.stride(2), left_fp16.stride(3),
        right_fp16.stride(0), right_fp16.stride(1),
        right_fp16.stride(2), right_fp16.stride(3),
        out_fp16.stride(0), out_fp16.stride(1),
        out_fp16.stride(2), out_fp16.stride(3),
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # -----------------------------------------------------------------
    # 6️⃣ Final LayerNorm, gating and output linear (back to float32)
    # -----------------------------------------------------------------
    out = out_fp16.to(dtype).permute(0, 2, 3, 1).contiguous()   # (B,N,N,hidden)

    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"].to(dtype),
        bias=weights["to_out_norm.bias"].to(dtype),
    )

    out = out * out_gate                     # broadcast over N,N
    out = F.linear(out, weights["to_out.weight"].to(dtype))   # (B,N,N,dim)

    return out
```
