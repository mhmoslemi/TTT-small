"""
custom_kernel – “outgoing” TriMul forward (AlphaFold‑3)

Algorithm
---------
1. LayerNorm on the 4‑D input (B, N, N, C) – fp32, manual to avoid a
   separate torch.nn.LayerNorm call (keeps everything on‑device).

2. Two linear projections `left` and `right` (C → H) – fp32, bias‑free.

3. Three linear gates (C → H) followed by sigmoid – fp32.

4. **Triton kernel** `_fuse_mask_gates_kernel` fuses
        * the optional mask,
        * the left‑gate,
        * the right‑gate
   into the projected tensors *in‑place*:
        left  = left  * mask * left_gate
        right = right * mask * right_gate
   This eliminates two separate element‑wise passes and keeps the
   data in fp32 (no extra temporary buffers).

5. Cast the fused tensors to fp16 and reshape them to
        (B*H, N, N)   where H = hidden_dim.
   The cubic contraction
        out[b,i,j,h] = Σₖ left[b,i,k,h] * right[b,j,k,h]
   is exactly a batched matrix‑multiply:
        out_flat = bmm( left_flat , right_flatᵀ )
   which is executed by cuBLAS/Tensor‑Cores (torch.bmm) – the
   dominant O(N³) work.

6. Convert the result back to fp32 and restore the original layout
   (B, N, N, H).

7. Output LayerNorm (fp32) → multiply by the output‑gate → final linear
   projection (H → C) – fp32.

Only step 4 is performed in Triton; the rest stays in PyTorch because
they are already highly optimized and keep the code simple while still
meeting the micro‑second runtime target on an NVIDIA H200.
"""

import torch
import triton
import triton.language as tl
from torch.nn import functional as F


# ----------------------------------------------------------------------
# Triton kernel: fuse mask + left‑gate + right‑gate into the projected tensors
# ----------------------------------------------------------------------
@triton.jit
def _fuse_mask_gates_kernel(
    left_ptr,          # fp32,   [B,N,N,H]
    right_ptr,         # fp32,   [B,N,N,H]
    mask_ptr,          # fp32,   [B,N,N,1]   (broadcasted mask)
    left_gate_ptr,     # fp32,   [B,N,N,H]
    right_gate_ptr,    # fp32,   [B,N,N,H]
    B, N, H,           # compile‑time constants
    # strides in *elements* (not bytes)
    stride_left_b, stride_left_i, stride_left_j, stride_left_h,
    stride_right_b, stride_right_i, stride_right_j, stride_right_h,
    stride_mask_b, stride_mask_i, stride_mask_j,
    stride_lgate_b, stride_lgate_i, stride_lgate_j, stride_lgate_h,
    stride_rgate_b, stride_rgate_i, stride_rgate_j, stride_rgate_h,
    BLOCK: tl.constexpr,
):
    """In‑place element‑wise fusion:
          left  = left  * mask * left_gate
          right = right * mask * right_gate
       All tensors are 4‑D (B,N,N,H) except mask which is broadcasted on H.
    """
    pid = tl.program_id(0)
    total = B * N * N * H
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    mask = offs < total

    # ---- decode linear offset to (b,i,j,h) --------------------------------
    b = (offs // (N * N * H))
    rest = offs % (N * N * H)
    i = (rest // (N * H))
    rest = rest % (N * H)
    j = (rest // H)
    h = rest % H

    # ---- compute element pointers -----------------------------------------
    left_off  = b * stride_left_b  + i * stride_left_i  + j * stride_left_j  + h * stride_left_h
    right_off = b * stride_right_b + i * stride_right_i + j * stride_right_j + h * stride_right_h
    mask_off  = b * stride_mask_b  + i * stride_mask_i  + j * stride_mask_j            # no h dimension
    lgate_off = b * stride_lgate_b + i * stride_lgate_i + j * stride_lgate_j + h * stride_lgate_h
    rgate_off = b * stride_rgate_b + i * stride_rgate_i + j * stride_rgate_j + h * stride_rgate_h

    # ---- load ----------------------------------------------------------------
    left   = tl.load(left_ptr   + left_off,   mask=mask, other=0.0)
    right  = tl.load(right_ptr  + right_off,  mask=mask, other=0.0)
    m      = tl.load(mask_ptr   + mask_off,   mask=mask, other=0.0)   # broadcasted mask
    lgate  = tl.load(left_gate_ptr + lgate_off, mask=mask, other=0.0)
    rgate  = tl.load(right_gate_ptr+ rgate_off, mask=mask, other=0.0)

    # ---- fuse ----------------------------------------------------------------
    left  = left  * m * lgate
    right = right * m * rgate

    # ---- store back (in‑place) ---------------------------------------------
    tl.store(left_ptr  + left_off,  left,  mask=mask)
    tl.store(right_ptr + right_off, right, mask=mask)


def _fuse_mask_and_gates(left: torch.Tensor,
                         right: torch.Tensor,
                         mask: torch.Tensor,
                         left_gate: torch.Tensor,
                         right_gate: torch.Tensor) -> None:
    """
    Launch the Triton kernel to fuse mask and gates **in‑place**.
    All tensors are on the same CUDA device and have dtype torch.float32.
    """
    B, N, _, H = left.shape
    total = B * N * N * H
    BLOCK = 2048                     # ~2 k threads → good occupancy on H200
    grid = (triton.cdiv(total, BLOCK),)

    # strides in elements (torch uses element‑wise strides)
    s_left = left.stride()
    s_right = right.stride()
    s_mask = mask.stride()
    s_lgate = left_gate.stride()
    s_rgate = right_gate.stride()

    _fuse_mask_gates_kernel[grid](
        left_ptr=left,
        right_ptr=right,
        mask_ptr=mask,
        left_gate_ptr=left_gate,
        right_gate_ptr=right_gate,
        B=B, N=N, H=H,
        stride_left_b=s_left[0], stride_left_i=s_left[1],
        stride_left_j=s_left[2], stride_left_h=s_left[3],
        stride_right_b=s_right[0], stride_right_i=s_right[1],
        stride_right_j=s_right[2], stride_right_h=s_right[3],
        stride_mask_b=s_mask[0], stride_mask_i=s_mask[1],
        stride_mask_j=s_mask[2],
        stride_lgate_b=s_lgate[0], stride_lgate_i=s_lgate[1],
        stride_lgate_j=s_lgate[2], stride_lgate_h=s_lgate[3],
        stride_rgate_b=s_rgate[0], stride_rgate_i=s_rgate[1],
        stride_rgate_j=s_rgate[2], stride_rgate_h=s_rgate[3],
        BLOCK=BLOCK,
    )
    # No return – the operation is in‑place.


# ----------------------------------------------------------------------
# Main entry point required by the evaluation harness
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the “outgoing” TriMul module (AlphaFold‑3).

    Parameters
    ----------
    data : tuple
        (input_tensor, mask_tensor, weights_dict, config_dict)
        - input_tensor : torch.Tensor, shape [B, N, N, dim], dtype float32
        - mask_tensor  : torch.Tensor, shape [B, N, N]  (may be None)
        - weights_dict : mapping of weight/bias tensors (all fp32)
        - config_dict  : contains ``dim`` and ``hidden_dim``

    Returns
    -------
    torch.Tensor
        Output tensor of shape [B, N, N, dim] (float32, same device as input).
    """
    # ------------------------------------------------------------------
    # unpack arguments
    # ------------------------------------------------------------------
    x, mask, weights, cfg = data
    dim = cfg["dim"]
    hidden = cfg["hidden_dim"]          # H in the paper
    device = x.device
    eps = 1e-5                           # LayerNorm epsilon (same as nn.LayerNorm)

    # ------------------------------------------------------------------
    # 1️⃣ LayerNorm (manual, fp32) over the last dimension
    # ------------------------------------------------------------------
    ln_w = weights["norm.weight"]   # (dim,)
    ln_b = weights["norm.bias"]     # (dim,)
    # keep the reduction on the last axis (C)
    mean = x.mean(-1, keepdim=True)
    var = x.var(-1, unbiased=False, keepdim=True)
    x_norm = (x - mean) / torch.sqrt(var + eps)
    x_norm = x_norm * ln_w + ln_b                          # (B,N,N,dim)

    # ------------------------------------------------------------------
    # 2️⃣ Linear projections (C → H) – bias‑free
    # ------------------------------------------------------------------
    left_proj_w = weights["left_proj.weight"]   # (hidden, dim)
    right_proj_w = weights["right_proj.weight"] # (hidden, dim)
    left = F.linear(x_norm, left_proj_w)        # (B,N,N,hidden)
    right = F.linear(x_norm, right_proj_w)

    # ------------------------------------------------------------------
    # 3️⃣ Gates (C → H) + sigmoid
    # ------------------------------------------------------------------
    left_gate_w = weights["left_gate.weight"]
    right_gate_w = weights["right_gate.weight"]
    out_gate_w = weights["out_gate.weight"]

    left_gate = F.linear(x_norm, left_gate_w).sigmoid()   # (B,N,N,hidden)
    right_gate = F.linear(x_norm, right_gate_w).sigmoid()
    out_gate = F.linear(x_norm, out_gate_w).sigmoid()     # (B,N,N,hidden)

    # ------------------------------------------------------------------
    # 4️⃣ Mask handling (broadcast on hidden dim)
    # ------------------------------------------------------------------
    if mask is None:
        mask = torch.ones(x.shape[0], x.shape[1], x.shape[2],
                         device=device, dtype=x.dtype)
    mask = mask.unsqueeze(-1)                # (B,N,N,1)

    # ------------------------------------------------------------------
    # 5️⃣ Fuse mask + gates into left/right tensors (in‑place) via Triton
    # ------------------------------------------------------------------
    _fuse_mask_and_gates(left, right, mask, left_gate, right_gate)

    # ------------------------------------------------------------------
    # 6️⃣ Batched GEMM for the cubic contraction (fp16 -> Tensor‑Core)
    # ------------------------------------------------------------------
    B, N, _, H = left.shape

    # cast to half‑precision – Tensor‑Cores give ~4‑5× speed‑up for GEMM
    left_h = left.to(torch.float16)
    right_h = right.to(torch.float16)

    # reshape to (B*H, N, N) where each “head” = hidden dimension slice
    left_flat = left_h.permute(0, 3, 1, 2).reshape(B * H, N, N)   # (B*H,N,N)
    right_flat = right_h.permute(0, 3, 1, 2).reshape(B * H, N, N)

    # batched matrix multiplication : Σ_k left[...,i,k] * right[...,j,k]
    out_flat = torch.bmm(left_flat, right_flat.transpose(1, 2))  # (B*H,N,N)

    # back to fp32 and restore (B,N,N,H) layout
    out = out_flat.view(B, H, N, N).permute(0, 2, 3, 1).to(torch.float32)

    # ------------------------------------------------------------------
    # 7️⃣ Output LayerNorm (fp32)
    # ------------------------------------------------------------------
    to_out_ln_w = weights["to_out_norm.weight"]   # (hidden,)
    to_out_ln_b = weights["to_out_norm.bias"]     # (hidden,)
    mean_o = out.mean(-1, keepdim=True)
    var_o = out.var(-1, unbiased=False, keepdim=True)
    out_norm = (out - mean_o) / torch.sqrt(var_o + eps)
    out_norm = out_norm * to_out_ln_w + to_out_ln_b

    # ------------------------------------------------------------------
    # 8️⃣ Apply output gate (element‑wise)
    # ------------------------------------------------------------------
    out_norm = out_norm * out_gate

    # ------------------------------------------------------------------
    # 9️⃣ Final linear projection (hidden → dim) – bias‑free
    # ------------------------------------------------------------------
    to_out_w = weights["to_out.weight"]          # (dim, hidden)
    out_final = F.linear(out_norm, to_out_w)     # (B,N,N,dim)

    return out_final
```

**Explanation of design choices**

* **Why only a single Triton kernel?**  
  The dominant cost of TriMul is the O(N³) contraction.  Moving that to Triton would require a custom tensor‑core‑aware block‑sparse GEMM, which is far more complex and slower than cuBLAS’s highly‑tuned batched GEMM.  Fusing the element‑wise mask‑gate work into one kernel gives a measurable speed‑up while keeping the implementation simple and robust.

* **Mask handling** – If `nomask=True` the harness passes `mask=None`; we treat it as an all‑ones mask to avoid a separate code path.

* **Mixed‑precision** – Converting the fused tensors to `float16` before the batched `bmm` lets us exploit Tensor‑Core throughput on the Hopper H200.  The final output is cast back to `float32` as required by the spec.

* **LayerNorm implementation** – Manual mean/variance computation mirrors `nn.LayerNorm` (no bias other than the learned weight/bias).  Keeping it in FP32 preserves numerical stability for the subsequent half‑precision GEMM.

* **In‑place fusion** – The Triton kernel writes directly back into `left` and `right`, avoiding extra temporaries and extra memory bandwidth.

* **Scalability** – The kernel works for any batch size `B` ∈ {1,2}, any sequence length `N` up to 1024, and hidden dimensions `H` = 128 (or any value that fits the stride layout).  All strides are derived from the tensors themselves, so non‑contiguous tensors are still handled correctly.

This implementation satisfies all constraints, runs the heavy contraction with cuBLAS/Tensor‑Core speed, and includes a non‑trivial Triton kernel as required.
