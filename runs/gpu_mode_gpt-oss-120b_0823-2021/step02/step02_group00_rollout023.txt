We implement the *outgoing* TriMul operator from AlphaFold‑3.  
The heavy‑weight part of the forward pass is the tensor contraction  

\[
\text{out}_{b,i,j,d}= \sum_{k=0}^{N-1}
      \text{left}_{b,i,k,d}\;\text{right}_{b,j,k,d}
\]

which is an \(N^3\) operation per batch.  We accelerate it with a **batched
matrix‑multiply** Triton kernel.  The kernel treats each pair
\((b,d_{\text{hid}})\) (batch × hidden‑dim) as an independent matrix‑multiply
\((N\times N)·(N\times N) → (N\times N)\).  The kernel works in **fp16** (fast on
H200), accumulates in **fp32** for numeric stability and writes the result back
as fp16.  All other layers (LayerNorm, linear projections, sigmoids, gating,
final projection) are small‑scale tensor ops and are kept in PyTorch for
readability and to avoid unnecessary kernel launches.

The implementation follows these steps:

1. **Layer‑norm** the input (FP32, manual for speed, no need for `torch.nn`
   because the weight & bias are supplied).
2. **Linear projections** (`left_proj`, `right_proj`) and **gate linear
   layers** (`left_gate`, `right_gate`, `out_gate`) are performed with
   `torch.nn.functional.linear` on **fp16** tensors.
3. Apply the optional **mask** (broadcasted over the hidden dimension) and
   the **sigmoid gates**.
4. **Re‑arrange** tensors so the contraction becomes a batched GEMM:
   * left*:  (B, H, I, K)  =  (B, hidden_dim, N, N) → transpose to (B, H, N, N)  
   * right*: (B, H, K, J)  =  (B, hidden_dim, N, N) → transpose‑swap the two
   sequence axes → (B, H, N, N).
5. Call the Triton kernel `batch_matmul_kernel` that computes the batched
   GEMM for every `(batch, hidden_dim)` pair.
6. Reshape the result back to **(B, N, N, hidden_dim)** and cast to **fp32**.
7. **Second Layer‑norm**, multiply by the **output gate**, and apply the final
   linear projection (`to_out`) to obtain the output of shape
   `(B, N, N, dim)`.

The kernel uses the classic tiling strategy (BLOCK_M = BLOCK_N = 64,
BLOCK_K = 32) that fits comfortably into the shared‑memory budget of a Hopper
SM 90 and achieves high occupancy with `num_warps=4`.  All stride arguments are
passed in *element* units (not bytes) as required by Triton.

Below is the complete, self‑contained implementation.

```python
"""
custom_kernel – “outgoing” TriMul (AlphaFold‑3)

- Manual FP32 LayerNorm (uses supplied weight & bias).
- FP16 linear projections + gating (sigmoid).
- Optional mask applied in FP16.
- Core contraction performed by a Triton batched GEMM kernel:
      (B, H, N, N) · (B, H, N, N)ᵀ → (B, H, N, N)
  where H = hidden_dim.
- Accumulate in FP32, store as FP16, then cast back to FP32.
- FP32 second LayerNorm, output gating and final linear projection.

The kernel is tuned for Hopper (SM‑90) with BLOCK_M = BLOCK_N = 64,
BLOCK_K = 32, num_warps = 4.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# --------------------------------------------------------------
# Triton kernel: batched matrix multiply (I×K)·(K×J) → (I×J)
# --------------------------------------------------------------
@triton.jit
def batch_matmul_kernel(
    a_ptr,               # left matrix   (batch, I, K)
    b_ptr,               # right matrix  (batch, K, J)
    c_ptr,               # output matrix (batch, I, J)
    M, N, K,             # extents
    stride_az, stride_am, stride_ak,   # strides of a (z, m, k)
    stride_bz, stride_bk, stride_bn,   # strides of b (z, k, n)
    stride_cz, stride_cm, stride_cn,   # strides of c (z, m, n)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    # program IDs – tile indices
    pid_m = tl.program_id(0)          # row tile
    pid_n = tl.program_id(1)          # col tile
    pid_z = tl.program_id(2)          # batch * hidden_dim index

    # start offsets for this tile
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    # masks for out‑of‑bounds handling
    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # loop over K dimension
    for kk in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = kk * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # load A tile (BLOCK_M × BLOCK_K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # load B tile (BLOCK_K × BLOCK_N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # fused dot‑product (FP16 × FP16 → FP32)
        acc += tl.dot(a, b)

    # write result as FP16
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


def triton_batched_matmul(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Batched GEMM using the Triton kernel above.

    Args:
        left : (B, H, I, K)  fp16, contiguous
        right: (B, H, K, J)  fp16, contiguous

    Returns:
        out  : (B, H, I, J)  fp16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # collapse batch * hidden_dim for the kernel
    batch_dim = B * H
    a = left.view(batch_dim, I, K)
    b = right.view(batch_dim, K, J)
    c = out.view(batch_dim, I, J)

    # strides in element units
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(I, BLOCK_M),   # rows
        triton.cdiv(J, BLOCK_N),   # cols
        batch_dim,                 # one program per (batch, hidden_dim)
    )
    batch_matmul_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,               # fp16 friendly on Hopper
    )
    return out


# --------------------------------------------------------------
# Forward entry point
# --------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the “outgoing” TriMul operator.

    Parameters
    ----------
    data : tuple (input_tensor, mask, weights, config)
        input_tensor : torch.Tensor, shape [B, N, N, dim], dtype torch.float32
        mask         : torch.Tensor or None, shape [B, N, N] (float or bool)
        weights      : dict of leaf tensors (see docstring above)
        config       : dict containing keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor with shape [B, N, N, dim] (float32)
    """
    # --------------------------------------------------------------
    # Unpack inputs
    # --------------------------------------------------------------
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]

    # --------------------------------------------------------------
    # 1️⃣ First LayerNorm (manual, FP32)
    # --------------------------------------------------------------
    norm_w = weights["norm.weight"]          # (dim,)
    norm_b = weights["norm.bias"]            # (dim,)
    # mean & var over last dimension
    mean = input_tensor.mean(dim=-1, keepdim=True)
    var = input_tensor.var(dim=-1, unbiased=False, keepdim=True)
    x = (input_tensor - mean) / torch.sqrt(var + 1e-5)
    x = x * norm_w + norm_b                   # still FP32

    # --------------------------------------------------------------
    # 2️⃣ Linear projections & gates (cast to FP16 for speed)
    # --------------------------------------------------------------
    def _to_fp16(t): return t.to(torch.float16)

    left_proj_w   = _to_fp16(weights["left_proj.weight"])   # (hidden_dim, dim)
    right_proj_w  = _to_fp16(weights["right_proj.weight"])
    left_gate_w   = _to_fp16(weights["left_gate.weight"])
    right_gate_w  = _to_fp16(weights["right_gate.weight"])
    out_gate_w    = _to_fp16(weights["out_gate.weight"])

    x_fp16 = x.to(torch.float16)               # (B, N, N, dim)

    left = F.linear(x_fp16, left_proj_w)       # (B, N, N, hidden_dim)
    right = F.linear(x_fp16, right_proj_w)

    # --------------------------------------------------------------
    # 3️⃣ Optional mask (broadcast over hidden_dim)
    # --------------------------------------------------------------
    if mask is not None:
        m = mask.to(torch.float16).unsqueeze(-1)   # (B, N, N, 1)
        left = left * m
        right = right * m

    # --------------------------------------------------------------
    # 4️⃣ Gates (sigmoid)
    # --------------------------------------------------------------
    left_gate  = F.linear(x_fp16, left_gate_w).sigmoid()
    right_gate = F.linear(x_fp16, right_gate_w).sigmoid()
    out_gate   = F.linear(x_fp16, out_gate_w).sigmoid()

    left = left * left_gate
    right = right * right_gate

    # --------------------------------------------------------------
    # 5️⃣ Core contraction via Triton batched GEMM
    # --------------------------------------------------------------
    # reshape to (B, hidden_dim, N, N) and permute so the reduction axis is K
    left_perm = left.permute(0, 3, 1, 2).contiguous()   # (B, H, I, K)
    # right needs a transpose of the two sequence axes before permute
    right_perm = right.permute(0, 3, 2, 1).contiguous()  # (B, H, K, J)

    # batched matrix multiplication in FP16
    out_fp16 = triton_batched_matmul(left_perm, right_perm)   # (B, H, I, J)

    # back to (B, N, N, hidden_dim) and FP32
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)

    # --------------------------------------------------------------
    # 6️⃣ Second LayerNorm (FP32)
    # --------------------------------------------------------------
    to_out_norm_w = weights["to_out_norm.weight"]   # (hidden_dim,)
    to_out_norm_b = weights["to_out_norm.bias"]     # (hidden_dim,)
    mean_o = out.mean(dim=-1, keepdim=True)
    var_o = out.var(dim=-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + 1e-5)
    out = out * to_out_norm_w + to_out_norm_b

    # --------------------------------------------------------------
    # 7️⃣ Output gate & final linear projection (FP32)
    # --------------------------------------------------------------
    out = out * out_gate.to(torch.float32)          # broadcast over hidden_dim
    to_out_w = weights["to_out.weight"]             # (dim, hidden_dim)
    out = F.linear(out, to_out_w)                  # (B, N, N, dim)

    return out
```

**Key points**

* The only custom kernel is `batch_matmul_kernel`, which performs the dominant
  \(N^3\) contraction efficiently.
* All other layers stay in PyTorch; this keeps the code simple, avoids extra
  memory copies, and satisfies the requirement that *some* work is done in
  Triton.
* The implementation respects all launch‑convention rules (grid definition,
  `tl.constexpr` parameters, element‑wise strides).
* Output is always `torch.float32` as required by the spec.
