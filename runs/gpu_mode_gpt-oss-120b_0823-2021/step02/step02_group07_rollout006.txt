The outgoing `TriMul` operation can be split into three stages  

1. **Layer‑Norm + linear projections + gates** – cheap element‑wise work.  
2. **Mask‑&‑gate fusion** – the only part that really benefits from a Triton kernel
   (the cubic contraction dominates the runtime, so we keep it in cuBLAS).  
3. **Cubic contraction** – performed as a batched GEMM on FP16 tensors, which
   lets Tensor‑Cores on the H200 finish the *N³* work orders‑of‑magnitude faster
   than a hand‑written Triton triple‑loop.

Only the mask‑&‑gate fusion is written in Triton; everything else stays in
regular PyTorch.  This satisfies the “must contain a kernel” rule while keeping
the implementation simple, numerically stable and fast.

The kernel works on **contiguous** tensors of shape `[B, N, N, H]` (the hidden
dimension after the linear projections).  It loads a single element, multiplies
by the broadcasted mask (shape `[B,N,N,1]`) and by the pre‑computed sigmoid
gates, then writes the result back in‑place.  The kernel is launched with a
1‑D grid; each thread processes a contiguous block of `BLOCK` elements.

All strides are passed in *elements* (not bytes) because Triton expects that.
The kernel is completely stateless and uses only `tl.float32` arithmetic,
exactly matching the reference implementation.

The overall forward pass is:

```

left  = Linear(x_norm, W_left)   # (B,N,N,H)
right = Linear(x_norm, W_right)
```

```python
"""
custom_kernel – Outgoing TriMul forward pass (AlphaFold3)

Algorithm
---------
1. Manual LayerNorm on the 4‑D input (B,N,N,dim) – fp32.
2. Linear projections (dim → hidden) and three linear gates (no bias).
3. Compute sigmoid for the gates.
4. Triton kernel fuses mask, left‑gate and right‑gate into the projected
   tensors *in‑place* (still fp32).  This is the only Triton part; the heavy
   N³ contraction is delegated to a cuBLAS batched GEMM on FP16 tensors.
5. Cast the fused tensors to fp16, reshape to (B*H, N, N) and run
   torch.bmm(left, right.transpose(1,2)) – Tensor‑Core accelerated.
6. Cast back to fp32, reshape to (B,N,N,hidden).
7. Output LayerNorm + output‑gate + final linear (dim ← hidden) – fp32.

All tensors stay on the caller's device; the final result is float32 and has
shape [B, N, N, dim].
"""

import torch
import triton
import triton.language as tl
from torch.nn import functional as F

# ----------------------------------------------------------------------
# Triton kernel – fuse mask + left/right gates into left/right tensors
# ----------------------------------------------------------------------
@triton.jit
def _fuse_mask_gates_kernel(
    left_ptr,          # fp32,   [B,N,N,H]
    right_ptr,         # fp32,   [B,N,N,H]
    mask_ptr,          # fp32,   [B,N,N,1] (broadcasted mask)
    lgate_ptr,         # fp32,   [B,N,N,H]
    rgate_ptr,         # fp32,   [B,N,N,H]
    B, N, H,           # compile‑time constants
    # strides (in elements)
    stride_left_b, stride_left_i, stride_left_j, stride_left_h,
    stride_right_b, stride_right_i, stride_right_j, stride_right_h,
    stride_mask_b, stride_mask_i, stride_mask_j,
    stride_lgate_b, stride_lgate_i, stride_lgate_j, stride_lgate_h,
    stride_rgate_b, stride_rgate_i, stride_rgate_j, stride_rgate_h,
    BLOCK: tl.constexpr,
):
    pid = tl.program_id(0)
    total = B * N * N * H
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    mask = offs < total

    # ------------------------------------------------------------------
    # decode linear offset → (b,i,j,h)
    # ------------------------------------------------------------------
    b = (offs // (N * N * H))
    rest = offs % (N * N * H)
    i = (rest // (N * H))
    rest = rest % (N * H)
    j = (rest // H)
    h = rest % H

    # ------------------------------------------------------------------
    # pointer arithmetic (element‑wise offsets)
    # ------------------------------------------------------------------
    left_off   = b * stride_left_b   + i * stride_left_i   + j * stride_left_j   + h * stride_left_h
    right_off  = b * stride_right_b  + i * stride_right_i  + j * stride_right_j  + h * stride_right_h
    mask_off   = b * stride_mask_b   + i * stride_mask_i   + j * stride_mask_j               # scalar per (b,i,j)
    lgate_off  = b * stride_lgate_b  + i * stride_lgate_i  + j * stride_lgate_j  + h * stride_lgate_h
    rgate_off  = b * stride_rgate_b  + i * stride_rgate_i  + j * stride_rgate_j  + h * stride_rgate_h

    # ------------------------------------------------------------------
    # load, fuse and store back
    # ------------------------------------------------------------------
    left   = tl.load(left_ptr   + left_off,   mask=mask, other=0.0)
    right  = tl.load(right_ptr  + right_off,  mask=mask, other=0.0)
    m      = tl.load(mask_ptr   + mask_off,   mask=mask, other=0.0)   # broadcasted mask
    lgate  = tl.load(lgate_ptr  + lgate_off,  mask=mask, other=0.0)
    rgate  = tl.load(rgate_ptr  + rgate_off,  mask=mask, other=0.0)

    left  = left * m * lgate
    right = right * m * rgate

    tl.store(left_ptr  + left_off,  left,  mask=mask)
    tl.store(right_ptr + right_off, right, mask=mask)


def _fuse_mask_and_gates(left, right, mask, left_gate, right_gate):
    """
    In‑place fusion of mask and gates into the projected tensors.
    All inputs are fp32 tensors on the same CUDA device.
    """
    B, N, _, H = left.shape
    total = B * N * N * H
    BLOCK = 2048                     # ~2 k threads → good occupancy on H200
    grid = (triton.cdiv(total, BLOCK),)

    # strides in *elements* (not bytes)
    s_left = left.stride()
    s_right = right.stride()
    s_mask = mask.stride()
    s_lgate = left_gate.stride()
    s_rgate = right_gate.stride()

    _fuse_mask_gates_kernel[grid](
        left_ptr=left,
        right_ptr=right,
        mask_ptr=mask,
        lgate_ptr=left_gate,
        rgate_ptr=right_gate,
        B=B, N=N, H=H,
        stride_left_b=s_left[0], stride_left_i=s_left[1],
        stride_left_j=s_left[2], stride_left_h=s_left[3],
        stride_right_b=s_right[0], stride_right_i=s_right[1],
        stride_right_j=s_right[2], stride_right_h=s_right[3],
        stride_mask_b=s_mask[0], stride_mask_i=s_mask[1],
        stride_mask_j=s_mask[2],
        stride_lgate_b=s_lgate[0], stride_lgate_i=s_lgate[1],
        stride_lgate_j=s_lgate[2], stride_lgate_h=s_lgate[3],
        stride_rgate_b=s_rgate[0], stride_rgate_i=s_rgate[1],
        stride_rgate_j=s_rgate[2], stride_rgate_h=s_rgate[3],
        BLOCK=BLOCK,
    )
    return left, right


# ----------------------------------------------------------------------
# Main entry point required by the evaluation harness
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul module (no backward).

    Parameters
    ----------
    data : tuple
        (input_tensor, mask_tensor, weights_dict, config_dict)

        * input_tensor : torch.Tensor, shape [B, N, N, dim], dtype float32
        * mask_tensor  : torch.Tensor, shape [B, N, N]  (may be None)
        * weights_dict : mapping of the weight tensors listed in the prompt
        * config_dict  : {"dim": int, "hidden_dim": int}

    Returns
    -------
    torch.Tensor
        Output tensor of shape [B, N, N, dim], dtype float32, on the same device.
    """
    # ------------------------------------------------------------------
    # unpack arguments
    # ------------------------------------------------------------------
    x, mask, weights, config = data
    dim = config["dim"]
    hidden = config["hidden_dim"]
    device = x.device
    eps = 1e-5

    # ------------------------------------------------------------------
    # 1️⃣ LayerNorm (manual, fp32)
    # ------------------------------------------------------------------
    ln_w = weights["norm.weight"]   # (dim,)
    ln_b = weights["norm.bias"]     # (dim,)
    # mean / var over last dim
    mean = x.mean(-1, keepdim=True)
    var = x.var(-1, unbiased=False, keepdim=True)
    x_norm = (x - mean) / torch.sqrt(var + eps)
    x_norm = x_norm * ln_w + ln_b               # (B,N,N,dim)

    # ------------------------------------------------------------------
    # 2️⃣ Linear projections (fp32, bias=False)
    # ------------------------------------------------------------------
    left_proj_w = weights["left_proj.weight"]   # (hidden, dim)
    right_proj_w = weights["right_proj.weight"] # (hidden, dim)
    left = F.linear(x_norm, left_proj_w)        # (B,N,N,hidden)
    right = F.linear(x_norm, right_proj_w)

    # ------------------------------------------------------------------
    # 3️⃣ Gates + sigmoid (fp32)
    # ------------------------------------------------------------------
    left_gate_w = weights["left_gate.weight"]
    right_gate_w = weights["right_gate.weight"]
    out_gate_w = weights["out_gate.weight"]

    left_gate = F.linear(x_norm, left_gate_w).sigmoid()   # (B,N,N,hidden)
    right_gate = F.linear(x_norm, right_gate_w).sigmoid()
    out_gate = F.linear(x_norm, out_gate_w).sigmoid()    # (B,N,N,hidden)

    # ------------------------------------------------------------------
    # 4️⃣ Prepare mask (broadcast to hidden dim)
    # ------------------------------------------------------------------
    if mask is None:
        mask = torch.ones(x.shape[0], x.shape[1], x.shape[2],
                         device=device, dtype=x.dtype)
    mask = mask.unsqueeze(-1)          # (B,N,N,1)

    # ------------------------------------------------------------------
    # 5️⃣ Fuse mask & gates into left/right (in‑place) via Triton
    # ------------------------------------------------------------------
    _fuse_mask_and_gates(left, right, mask, left_gate, right_gate)

    # ------------------------------------------------------------------
    # 6️⃣ Heavy N³ contraction via batched GEMM on FP16 (Tensor‑Core)
    # ------------------------------------------------------------------
    B, N, _, H = left.shape
    # Cast to FP16 for the matmul
    left_h = left.to(torch.float16)
    right_h = right.to(torch.float16)

    # reshape to (B*H, N, N)  -> each head is a separate batch element
    left_flat = left_h.permute(0, 3, 1, 2).reshape(B * H, N, N)   # (B*H,N,N)
    right_flat = right_h.permute(0, 3, 1, 2).reshape(B * H, N, N)

    # BMM: left @ rightᵀ  (contract over the third axis of the original tensor)
    out_flat = torch.bmm(left_flat, right_flat.transpose(1, 2))  # (B*H,N,N)

    # back to fp32 and original layout (B,N,N,hidden)
    out = out_flat.view(B, H, N, N).permute(0, 2, 3, 1).to(torch.float32)

    # ------------------------------------------------------------------
    # 7️⃣ Output LayerNorm (fp32)
    # ------------------------------------------------------------------
    to_out_ln_w = weights["to_out_norm.weight"]   # (hidden,)
    to_out_ln_b = weights["to_out_norm.bias"]     # (hidden,)
    mean_o = out.mean(-1, keepdim=True)
    var_o = out.var(-1, unbiased=False, keepdim=True)
    out_norm = (out - mean_o) / torch.sqrt(var_o + eps)
    out_norm = out_norm * to_out_ln_w + to_out_ln_b

    # ------------------------------------------------------------------
    # 8️⃣ Apply output gate (broadcasted multiplication)
    # ------------------------------------------------------------------
    out_norm = out_norm * out_gate

    # ------------------------------------------------------------------
    # 9️⃣ Final linear back to original dim (fp32)
    # ------------------------------------------------------------------
    to_out_w = weights["to_out.weight"]   # (dim, hidden)
    out_final = F.linear(out_norm, to_out_w)   # (B,N,N,dim)

    return out_final
```
