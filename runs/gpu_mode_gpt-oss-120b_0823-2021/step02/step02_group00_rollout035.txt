We implement the *outgoing* TriMul operator exactly as described in the paper, but we move the **only cubic‑cost part** – the contraction  

\[
\text{out}_{b,i,j,d}= \sum_{k=0}^{N-1} \text{left}_{b,i,k,d}\;
                         \text{right}_{b,j,k,d}
\]

– into a custom Triton kernel.  
All the surrounding linear layers, LayerNorms and gating are performed with
PyTorch (they are cheap compared to the \(N^3\) work).  

Key points of the implementation

| Step | What we do | Details |
|------|------------|---------|
| 1️⃣   | Layer‑norm on the input | Manual FP32 mean/var, use the supplied `norm.weight` / `norm.bias`. |
| 2️⃣   | Linear projections & gates | Cast the input to **float16**, use `F.linear` with the provided weight tensors (already FP16‑cast). |
| 3️⃣   | Optional mask | Broadcast mask over the hidden dimension (if a mask is supplied). |
| 4️⃣   | Gating | `sigmoid` on the three gate projections, multiply into `left`/`right`. |
| 5️⃣   | **Triton kernel** – batched mat‑mul | We reshape `left` and `right` to `(B·H, N, N)` where `H = hidden_dim`. The kernel computes a *batch‑wise* matrix‑multiply  
`(I × K)·(K × J) → (I × J)` with tiling `BLOCK_M = BLOCK_N = 64`, `BLOCK_K = 32`.  
  * Accumulates in FP32 for numerical safety, stores FP16. |
| 6️⃣   | Post‑processing | Convert back to FP32, second LayerNorm, multiply by `out_gate`, final linear projection (`to_out`). |

The kernel follows the classic Triton GEMM pattern, but we keep the **batch**
dimension (`B·H`) as the third launch axis, so each `(batch, head)` pair is
handled independently – exactly the “outgoing” formulation required by AlphaFold‑3.

The implementation respects all constraints:

* Works for any `B ∈ {1,2}`, `N ∈ {128,…,1024}`, `dim ∈ {128,384}`, `hidden_dim = 128`.
* Supports presence/absence of the mask.
* All tensors are kept on the device, no host‑side copies.
* Final output is **float32**.
* At least one hot region (the cubic contraction) is executed in Triton.

```python
"""
custom_kernel – “outgoing” TriMul (AlphaFold‑3)

Algorithm
---------
1. Layer‑norm the input (FP32, manual for speed).
2. Four linear projections (left/right + three gates) using FP16 weights.
3. Optional mask is applied to left/right.
4. Gating (sigmoid) is applied.
5. Core contraction
        out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
   performed by a Triton kernel that treats each (batch, hidden‑dim) pair
   as an independent matrix‑multiply (N×N)·(N×N) → (N×N).
   The kernel works in fp16, accumulates in fp32 and writes fp16.
6. Convert back to FP32, apply a second LayerNorm, multiply by out_gate,
   and finish with a linear projection to the original dimension.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel – batched GEMM (I×K)·(K×J) → (I×J)
# ----------------------------------------------------------------------
@triton.jit
def batch_gemm_kernel(
    a_ptr,          # left matrix  (B·H, I, K)   fp16
    b_ptr,          # right matrix (B·H, K, J)   fp16
    c_ptr,          # output       (B·H, I, J)   fp16
    M, N, K,        # matrix extents
    stride_az, stride_am, stride_ak,   # strides of A
    stride_bz, stride_bk, stride_bn,   # strides of B
    stride_cz, stride_cm, stride_cn,   # strides of C
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    pid_m = tl.program_id(0)   # tile along M (rows)
    pid_n = tl.program_id(1)   # tile along N (cols)
    pid_z = tl.program_id(2)   # batch * hidden_dim index

    # start offset of the tile
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    # boundary masks
    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # loop over K dimension
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # load A tile (M × K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # load B tile (K × N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # dot‑product (fp16×fp16 → fp32)
        acc += tl.dot(a, b)

    # write result (convert back to fp16)
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


# ----------------------------------------------------------------------
# Python helper that launches the kernel
# ----------------------------------------------------------------------
def triton_batched_gemm(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    left  : (B, H, I, K)  fp16, contiguous
    right : (B, H, K, J)  fp16, contiguous
    returns: (B, H, I, J) fp16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # collapse batch*head dimension for the kernel
    batch = B * H
    a = left.view(batch, I, K)
    b = right.view(batch, K, J)
    c = out.view(batch, I, J)

    # strides in element units
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # tile sizes – tuned for Hopper / fp16
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(I, BLOCK_M),        # rows
        triton.cdiv(J, BLOCK_N),        # cols
        batch,                          # one program per (batch, head)
    )
    batch_gemm_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,            # good for fp16 on sm_90
    )
    return out


# ----------------------------------------------------------------------
# Full forward (PyTorch + Triton)
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask, weights, config)
        - input_tensor : torch.Tensor [B, N, N, dim]  (float32)
        - mask         : torch.Tensor [B, N, N] or None (float/bool)
        - weights      : dict of leaf weight tensors
        - config       : dict with keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor [B, N, N, dim] (float32)
    """
    # --------------------------------------------------------------
    # Unpack
    # --------------------------------------------------------------
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]

    # --------------------------------------------------------------
    # 1️⃣ First LayerNorm (FP32)
    # --------------------------------------------------------------
    norm_w = weights["norm.weight"]
    norm_b = weights["norm.bias"]
    # mean / var over the last dimension
    mean = input_tensor.mean(dim=-1, keepdim=True)
    var = input_tensor.var(dim=-1, unbiased=False, keepdim=True)
    x = (input_tensor - mean) / torch.sqrt(var + 1e-5)
    x = x * norm_w + norm_b                # still FP32

    # --------------------------------------------------------------
    # 2️⃣ Linear projections & gates (cast to FP16)
    # --------------------------------------------------------------
    def to_fp16(t): return t.to(torch.float16)

    # projection weights: (hidden_dim, dim)
    left_proj_w  = to_fp16(weights["left_proj.weight"])
    right_proj_w = to_fp16(weights["right_proj.weight"])

    # gate weights: (hidden_dim, dim)
    left_gate_w  = to_fp16(weights["left_gate.weight"])
    right_gate_w = to_fp16(weights["right_gate.weight"])
    out_gate_w   = to_fp16(weights["out_gate.weight"])

    x_fp16 = x.to(torch.float16)               # (B,N,N,dim)

    left  = F.linear(x_fp16, left_proj_w)      # (B,N,N,hidden_dim)
    right = F.linear(x_fp16, right_proj_w)

    # --------------------------------------------------------------
    # 3️⃣ Optional mask
    # --------------------------------------------------------------
    if mask is not None:
        m = mask.to(torch.float16).unsqueeze(-1)   # (B,N,N,1)
        left = left * m
        right = right * m

    # --------------------------------------------------------------
    # 4️⃣ Gating (sigmoid)
    # --------------------------------------------------------------
    left_gate  = F.linear(x_fp16, left_gate_w).sigmoid()
    right_gate = F.linear(x_fp16, right_gate_w).sigmoid()
    out_gate   = F.linear(x_fp16, out_gate_w).sigmoid()

    left = left * left_gate
    right = right * right_gate

    # --------------------------------------------------------------
    # 5️⃣ Heavy contraction with Triton
    # --------------------------------------------------------------
    # reshape to (B, H, I, K) and (B, H, K, J)
    left_perm  = left.permute(0, 3, 1, 2).contiguous()   # (B, H, I, K)
    right_perm = right.permute(0, 3, 2, 1).contiguous()  # (B, H, K, J)

    out_fp16 = triton_batched_gemm(left_perm, right_perm)   # (B, H, I, J)

    # back to (B, N, N, hidden_dim) and FP32
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)

    # --------------------------------------------------------------
    # 6️⃣ Second LayerNorm (FP32)
    # --------------------------------------------------------------
    to_out_norm_w = weights["to_out_norm.weight"]
    to_out_norm_b = weights["to_out_norm.bias"]
    mean_o = out.mean(dim=-1, keepdim=True)
    var_o  = out.var(dim=-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + 1e-5)
    out = out * to_out_norm_w + to_out_norm_b

    # --------------------------------------------------------------
    # 7️⃣ Final gating + linear projection (FP32)
    # --------------------------------------------------------------
    out = out * out_gate.to(torch.float32)       # broadcast over hidden dimension
    to_out_w = weights["to_out.weight"]
    out = F.linear(out, to_out_w)               # (B,N,N,dim)

    return out
```
