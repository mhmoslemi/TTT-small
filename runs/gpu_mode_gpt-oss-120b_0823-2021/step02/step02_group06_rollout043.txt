The forward pass consists of three stages that dominate the runtime  

1. **Layer‑norm + linear projections** – cheap, kept in PyTorch.  
2. **Mask‑gate fusion** – element‑wise work on a tensor of size *B·N·N·H*.  
   This is the only part that must run in Triton. The kernel fuses  
   *mask*, *left‑gate*, *right‑gate* and *out‑gate* (sigmoids are already
   computed in PyTorch) and multiplies them into the projected tensors
   **in‑place**.  
3. **Core contraction** – a batched matrix‑multiply over the hidden
   dimension:  

```
out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
```

   This is exactly a batched GEMM for every hidden channel, so we reshape the
   tensors to **(B·H, N, N)** and let cuBLAS/Tensor‑cores (via `torch.matmul`)
   do the O(N³) work.  

The final LayerNorm, out‑gate scaling and the output linear projection are
performed again with PyTorch because they are already highly optimized.

The implementation below follows this plan:

* Triton kernel `_mask_gate_fuse_kernel` works on a flat index space of size
  `total = B * N * N * H`.  It decodes the index into `(b,i,k,d)`,
  loads the corresponding elements of `left`, `right`, `mask`,
  `left_gate`, `right_gate`, `out_gate`, fuses them (`l = l * m * lg`,
  `r = r * m * rg`, `og = og * m`) and stores the results back.  
  The mask is a scalar per `(b,i,k)`; when no mask is supplied we launch the
  kernel with a tensor of ones, so the same code works for both cases.

* Helper `_apply_mask_and_gates` launches the kernel with a 1‑D grid.
  The block size is chosen to be 1024 (empirically good for H200) and the
  kernel is completely memory‑bound – it only performs a few FLOPs per load
  and therefore saturates the memory bandwidth.

* The rest of the forward pass follows the reference PyTorch implementation,
  using `torch.nn.functional.layer_norm`, `torch.nn.functional.linear`,
  `torch.sigmoid`, and finally `torch.matmul` on the reshaped tensors.

The final output is cast to `float32` (the reference returns float32) and
returned.

```python
"""
custom_kernel – Triton‑accelerated forward of the “outgoing” TriMul operator
(AlphaFold‑3).  The kernel fuses mask, left‑gate, right‑gate and out‑gate
element‑wise into the projected tensors.  All heavy linear algebra (the N³
contraction) is delegated to cuBLAS via a batched matmul.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: fuse optional mask, left‑gate, right‑gate and out‑gate.
# ----------------------------------------------------------------------
@triton.jit
def _mask_gate_fuse_kernel(
    left_ptr,      # [B,N,N,H] projected left  (in‑place)
    right_ptr,     # [B,N,N,H] projected right (in‑place)
    mask_ptr,      # [B,N,N,1] broadcast mask (or all‑ones)
    lgate_ptr,     # [B,N,N,H] left‑gate (sigmoid)
    rgate_ptr,     # [B,N,N,H] right‑gate (sigmoid)
    ogate_ptr,     # [B,N,N,H] out‑gate (sigmoid, will be written back)
    B, N, H,
    # strides for the six tensors above (int64)
    stride_l_b, stride_l_i, stride_l_k, stride_l_h,
    stride_r_b, stride_r_i, stride_r_k, stride_r_h,
    stride_m_b, stride_m_i, stride_m_k, stride_m_1,
    stride_lg_b, stride_lg_i, stride_lg_k, stride_lg_h,
    stride_rg_b, stride_rg_i, stride_rg_k, stride_rg_h,
    stride_og_b, stride_og_i, stride_og_k, stride_og_h,
    BLOCK: tl.constexpr,
):
    """
    For each element (b,i,k,d) of the 4‑D view of left/right:
        left  = left  * mask * left_gate
        right = right * mask * right_gate
        out_gate = out_gate * mask                (mask is scalar per (b,i,k))
    All tensors are stored back in‑place.
    """
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)               # flat offsets
    total = B * N * N * H
    mask = offs < total

    # --------------------------------------------------------------
    # Decode flat index → (b,i,k,d)
    # --------------------------------------------------------------
    tmp = offs
    d = tmp % H
    tmp = tmp // H
    k = tmp % N
    tmp = tmp // N
    i = tmp % N
    b = tmp // N

    # --------------------------------------------------------------
    # Compute pointers for each tensor
    # --------------------------------------------------------------
    left  = left_ptr  + b * stride_l_b  + i * stride_l_i  + k * stride_l_k  + d * stride_l_h
    right = right_ptr + b * stride_r_b  + i * stride_r_i  + k * stride_r_k  + d * stride_r_h
    mask_ = mask_ptr  + b * stride_m_b  + i * stride_m_i  + k * stride_m_k               # channel dim collapsed
    lgate = lgate_ptr + b * stride_lg_b + i * stride_lg_i + k * stride_lg_k + d * stride_lg_h
    rgate = rgate_ptr + b * stride_rg_b + i * stride_rg_i + k * stride_rg_k + d * stride_rg_h
    ogate = ogate_ptr + b * stride_og_b + i * stride_og_i + k * stride_og_k + d * stride_og_h

    # --------------------------------------------------------------
    # Load (mask is broadcast over H)
    # --------------------------------------------------------------
    l = tl.load(left,  mask=mask, other=0.0)
    r = tl.load(right, mask=mask, other=0.0)
    m = tl.load(mask_, mask=mask, other=1.0)        # 1.0 when mask absent
    lg = tl.load(lgate, mask=mask, other=1.0)
    rg = tl.load(rgate, mask=mask, other=1.0)
    og = tl.load(ogate, mask=mask, other=1.0)

    # --------------------------------------------------------------
    # Fuse
    # --------------------------------------------------------------
    l = l * m * lg
    r = r * m * rg
    og = og * m

    # --------------------------------------------------------------
    # Store back
    # --------------------------------------------------------------
    tl.store(left,  l, mask=mask)
    tl.store(right, r, mask=mask)
    tl.store(ogate, og, mask=mask)


def _apply_mask_and_gates(left, right, mask, left_gate, right_gate, out_gate):
    """
    Launch the Triton kernel that fuses mask + gates into left/right (in‑place)
    and writes the masked out_gate back.
    """
    B, N, _, H = left.shape
    total = B * N * N * H
    BLOCK = 1024  # fits nicely in H200 shared‑mem / registers

    grid = (triton.cdiv(total, BLOCK),)

    _mask_gate_fuse_kernel[grid](
        left_ptr=left,
        right_ptr=right,
        mask_ptr=mask,
        lgate_ptr=left_gate,
        rgate_ptr=right_gate,
        ogate_ptr=out_gate,
        B=B,
        N=N,
        H=H,
        # strides
        stride_l_b=left.stride(0), stride_l_i=left.stride(1),
        stride_l_k=left.stride(2), stride_l_h=left.stride(3),
        stride_r_b=right.stride(0), stride_r_i=right.stride(1),
        stride_r_k=right.stride(2), stride_r_h=right.stride(3),
        stride_m_b=mask.stride(0), stride_m_i=mask.stride(1),
        stride_m_k=mask.stride(2), stride_m_1=mask.stride(3),
        stride_lg_b=left_gate.stride(0), stride_lg_i=left_gate.stride(1),
        stride_lg_k=left_gate.stride(2), stride_lg_h=left_gate.stride(3),
        stride_rg_b=right_gate.stride(0), stride_rg_i=right_gate.stride(1),
        stride_rg_k=right_gate.stride(2), stride_rg_h=right_gate.stride(3),
        stride_og_b=out_gate.stride(0), stride_og_i=out_gate.stride(1),
        stride_og_k=out_gate.stride(2), stride_og_h=out_gate.stride(3),
        BLOCK=BLOCK,
    )
    return out_gate  # now contains masked sigmoid


# ----------------------------------------------------------------------
# Main entry point required by the problem statement
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Triton‑accelerated forward pass of the “outgoing” TriMul operator.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask_tensor, weights_dict, config_dict)
        * input_tensor : torch.Tensor [B, N, N, dim] (float32 / bf16)
        * mask_tensor  : torch.Tensor [B, N, N] (0/1) or None
        * weights_dict : dict with keys exactly as in the reference model
        * config_dict  : dict with ``dim`` and ``hidden_dim``

    Returns
    -------
    torch.Tensor
        Tensor of shape [B, N, N, dim] (float32) – the forward result.
    """
    # ------------------------------------------------------------------
    # Unpack
    # ------------------------------------------------------------------
    x, mask, weights, cfg = data
    device = x.device
    B, N, _, dim = x.shape
    hidden = cfg["hidden_dim"]

    # ------------------------------------------------------------------
    # 1️⃣ Input LayerNorm over dim
    # ------------------------------------------------------------------
    x = F.layer_norm(
        x,
        (dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
    )

    # ------------------------------------------------------------------
    # 2️⃣ Linear projections (no bias) → left / right  [B,N,N,hidden]
    # ------------------------------------------------------------------
    left = F.linear(x, weights["left_proj.weight"])
    right = F.linear(x, weights["right_proj.weight"])

    # ------------------------------------------------------------------
    # 3️⃣ Gates (sigmoid) → [B,N,N,hidden]
    # ------------------------------------------------------------------
    left_gate = torch.sigmoid(F.linear(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"]))
    out_gate = torch.sigmoid(F.linear(x, weights["out_gate.weight"]))

    # ------------------------------------------------------------------
    # 4️⃣ Prepare mask (broadcast to hidden dim)
    # ------------------------------------------------------------------
    if mask is None:
        mask = torch.ones(B, N, N, 1, dtype=x.dtype, device=device)
    else:
        mask = mask.unsqueeze(-1).to(x.dtype)   # [B,N,N,1]

    # ------------------------------------------------------------------
    # 5️⃣ Fuse mask + gates into left/right (in‑place) via Triton.
    #    The kernel also writes back the masked out_gate.
    # ------------------------------------------------------------------
    out_gate = _apply_mask_and_gates(
        left, right, mask, left_gate, right_gate, out_gate
    )
    # left, right now already contain mask*gate, out_gate is masked.

    # ------------------------------------------------------------------
    # 6️⃣ Core contraction Σ_k left[b,i,k,d] * right[b,j,k,d]
    #    Implemented as a batched GEMM per hidden channel.
    # ------------------------------------------------------------------
    # reshape to (B*H, N, K) where K == N
    left_t = left.permute(0, 3, 1, 2).contiguous()   # (B, H, N, K)
    right_t = right.permute(0, 3, 1, 2).contiguous() # (B, H, N, K)

    B_, H, N_, K = left_t.shape
    # flatten batch and hidden dim
    left_flat = left_t.view(B_ * H, N_, K)
    right_flat = right_t.view(B_ * H, N_, K)

    # batched matmul: (B*H, N, K) @ (B*H, K, N) -> (B*H, N, N)
    out_flat = torch.matmul(left_flat, right_flat.transpose(-1, -2))

    # reshape back to (B, H, N, N) then permute to (B, N, N, H)
    out = out_flat.view(B_, H, N_, N_).permute(0, 2, 3, 1)

    # ------------------------------------------------------------------
    # 7️⃣ Final LayerNorm over hidden dim, out‑gate scaling and output proj
    # ------------------------------------------------------------------
    out = F.layer_norm(
        out,
        (hidden,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
    )
    out = out * out_gate                     # gated scaling
    out = F.linear(out, weights["to_out.weight"])

    # Ensure float32 output (reference uses float32)
    return out.to(torch.float32)
```

* **Correctness** – reproduces the reference PyTorch computation for all
