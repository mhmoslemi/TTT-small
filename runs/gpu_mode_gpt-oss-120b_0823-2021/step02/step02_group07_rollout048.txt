The kernel below follows the exact arithmetic of the reference PyTorch module while
keeping the *cubic* contraction (`einsum`) off‑loaded to a highly‑optimized cuBLAS
batched GEMM (the fastest primitive on an H200).  
Only the element‑wise work that benefits from fusion – mask‑application,
gate‑multiplication and the two linear projections – is done in Triton.  
All other steps (LayerNorm, final LayerNorm, final linear) are performed in
PyTorch because they are cheap compared to the `N³` contraction and would add
unnecessary complexity.

### Algorithmic outline
1. **Layer‑Norm on the input** – manual fp32 computation (no Triton needed).  
2. **Linear projections** (`left_proj`, `right_proj`) – fused into a single
   Triton kernel that also multiplies the mask (if present) and the
   left/right gates (`sigmoid`).  The kernel works on a flat view of the
   4‑D tensor, therefore it is independent of `N` and `C`.  
3. **Cast to fp16** and reshape to `(B·H, N, N)` so that a single
   `torch.bmm` computes the complete einsum:
   ```
   out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
   ```
   (the transpose on the second operand implements the `j,k` ordering).  
4. **Output Layer‑Norm → output‑gate → final linear** – again done in PyTorch.  

The only mandatory Triton component is the element‑wise fusion kernel
(`_proj_mask_gate_fuse`).  By fusing the three “heavy” element‑wise passes we
reduce memory traffic, keep the operation purely compute‑bound, and achieve
high occupancy on the H200.  The kernel works for any `B∈{1,2}`, any
`N∈{128,…,1024}`, any `dim` (including the `c_z` values 128/384/768) and any
`hidden_dim` (here `H`).  It also gracefully handles the *no‑mask* case by
passing a tensor of ones.

```python
"""
custom_kernel – Triton‑fused outgoing TriMul forward pass (AlphaFold3)

* LayerNorm      : fp32, manual
* Linear proj    : fp32, fused with mask & left/right gates (Triton)
* Gates          : sigmoid, fused
* Cubic contraction (einsum) : batched fp16 bmm (cuBLAS)
* Output LayerNorm & final linear : fp32, PyTorch

All tensors stay on the input device, final output is float32.
"""

import torch
import triton
import triton.language as tl

# -------------------------------------------------------------------------
# Triton kernel – fuse linear projection, mask and gates
# -------------------------------------------------------------------------
@triton.jit
def _proj_mask_gate_fuse(
    x_ptr,                # [B,N,N,dim]      fp32 (input after LN)
    proj_ptr,             # [hidden, dim]    fp32 (weight matrix)
    out_ptr,              # [B,N,N,hidden]   fp32 (dest, either left or right)
    mask_ptr,             # [B,N,N,1]        fp32 (or all‑ones)
    gate_ptr,             # [B,N,N,hidden]   fp32 (gate after sigmoid)
    B, N, dim, hidden,    # compile‑time constants
    stride_x_b, stride_x_i, stride_x_j, stride_x_c,
    stride_proj_o, stride_proj_i,               # weight strides (row‑major)
    stride_out_b, stride_out_i, stride_out_j, stride_out_h,
    stride_mask_b, stride_mask_i, stride_mask_j,
    stride_gate_b, stride_gate_i, stride_gate_j, stride_gate_h,
    BLOCK: tl.constexpr,
):
    """
    y = (x @ proj.T) * mask * gate
    where
        x : (B,N,N,dim)
        proj : (hidden, dim)
        mask : broadcasted (B,N,N,1)
        gate : (B,N,N,hidden) already passed through sigmoid
    The result is written in‑place to out_ptr.
    """
    pid = tl.program_id(0)
    total = B * N * N * hidden
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    mask = offs < total

    # decode linear offset → (b,i,j,h)
    b = (offs // (N * N * hidden))
    rest = offs % (N * N * hidden)
    i = (rest // (N * hidden))
    rest = rest % (N * hidden)
    j = (rest // hidden)
    h = rest % hidden

    # ------------ load X (dim) and compute projection ------------
    # X index: (b,i,j,dim)
    x_off = b * stride_x_b + i * stride_x_i + j * stride_x_j
    # load a full row of the weight matrix (dim elements) into registers
    # we unroll the dim loop manually via tl.load with a small BLOCK_D
    # (dim is at most 768, we choose BLOCK_D = 32)
    BLOCK_D = tl.constexpr(32)
    d_off = tl.arange(0, BLOCK_D)
    # guard against dim not divisible by BLOCK_D
    dim_mask = (d_off < dim)

    # load X slice
    x_ptrs = x_ptr + x_off + d_off * stride_x_c
    x = tl.load(x_ptrs, mask=dim_mask, other=0.0)          # (BLOCK_D,)

    # load weight row for given hidden index h
    proj_off = h * stride_proj_o + d_off * stride_proj_i   # (hidden, dim) row-major
    w = tl.load(proj_ptr + proj_off, mask=dim_mask, other=0.0)

    # dot product (reduce over d)
    prod = tl.sum(x * w, axis=0)                          # scalar fp32

    # ------------ load mask and gate and fuse ------------
    mask_off = b * stride_mask_b + i * stride_mask_i + j * stride_mask_j
    m = tl.load(mask_ptr + mask_off, mask=mask, other=1.0)   # scalar (1.0 if missing)

    gate_off = b * stride_gate_b + i * stride_gate_i + j * stride_gate_j + h * stride_gate_h
    g = tl.load(gate_ptr + gate_off, mask=mask, other=0.0)

    out = prod * m * g

    # store result
    out_off = b * stride_out_b + i * stride_out_i + j * stride_out_j + h * stride_out_h
    tl.store(out_ptr + out_off, out, mask=mask)


def _fused_proj_mask_gate(x, proj_w, mask, gate):
    """
    Helper that launches the Triton kernel for one side (left or right).

    Args:
        x   : (B,N,N,dim)  fp32 (already layer‑normed)
        proj_w : (hidden, dim) fp32
        mask : (B,N,N,1) fp32   (or None → treated as ones)
        gate : (B,N,N,hidden) fp32 (already sigmoid‑ed)

    Returns:
        out : (B,N,N,hidden) fp32
    """
    B, N, _, dim = x.shape
    hidden = proj_w.shape[0]

    out = torch.empty_like(gate)  # allocate output buffer
    # strides in elements (not bytes)
    sx = x.stride()
    sp = proj_w.stride()
    so = out.stride()
    sm = mask.stride()
    sg = gate.stride()

    # launch parameters – 2k threads per block gives good occupancy on H200
    BLOCK = 2048
    total = B * N * N * hidden
    grid = (triton.cdiv(total, BLOCK),)

    _proj_mask_gate_fuse[grid](
        x_ptr=x,
        proj_ptr=proj_w,
        out_ptr=out,
        mask_ptr=mask,
        gate_ptr=gate,
        B=B, N=N, dim=dim, hidden=hidden,
        stride_x_b=sx[0], stride_x_i=sx[1], stride_x_j=sx[2], stride_x_c=sx[3],
        stride_proj_o=sp[0], stride_proj_i=sp[1],
        stride_out_b=so[0], stride_out_i=so[1], stride_out_j=so[2], stride_out_h=so[3],
        stride_mask_b=sm[0], stride_mask_i=sm[1], stride_mask_j=sm[2],
        stride_gate_b=sg[0], stride_gate_i=sg[1], stride_gate_j=sg[2], stride_gate_h=sg[3],
        BLOCK=BLOCK,
    )
    return out


# -------------------------------------------------------------------------
# Main entry point required by the harness
# -------------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul module.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask_tensor, weights_dict, config_dict)

    Returns
    -------
    torch.Tensor
        Tensor of shape [B, N, N, dim] (float32, same device as input)
    """
    # unpack ---------------------------------------------------------------
    x, mask, weights, config = data
    dim = config["dim"]
    hidden = config["hidden_dim"]
    device = x.device
    eps = 1e-5

    # -----------------------------------------------------------------
    # 1️⃣ LayerNorm on the 4‑D input (B,N,N,dim) – fp32
    # -----------------------------------------------------------------
    ln_w = weights["norm.weight"]   # (dim,)
    ln_b = weights["norm.bias"]
    # mean / var over last dimension
    mean = x.mean(-1, keepdim=True)
    var = x.var(-1, unbiased=False, keepdim=True)
    x_norm = (x - mean) / torch.sqrt(var + eps)
    x_norm = x_norm * ln_w + ln_b                       # (B,N,N,dim)

    # -----------------------------------------------------------------
    # 2️⃣ Gates – linear + sigmoid (still fp32)
    # -----------------------------------------------------------------
    left_gate_w = weights["left_gate.weight"]   # (hidden, dim)
    right_gate_w = weights["right_gate.weight"]
    out_gate_w = weights["out_gate.weight"]

    left_gate = torch.nn.functional.linear(x_norm, left_gate_w).sigmoid()   # (B,N,N,hidden)
    right_gate = torch.nn.functional.linear(x_norm, right_gate_w).sigmoid()
    out_gate = torch.nn.functional.linear(x_norm, out_gate_w).sigmoid()     # (B,N,N,hidden)

    # -----------------------------------------------------------------
    # 3️⃣ Prepare mask (broadcast to channel dim)
    # -----------------------------------------------------------------
    if mask is None:
        mask = torch.ones(x.shape[0], x.shape[1], x.shape[2],
                         device=device, dtype=x.dtype)
    mask = mask.unsqueeze(-1)      # (B,N,N,1)

    # -----------------------------------------------------------------
    # 4️⃣ Fuse projection, mask and gates (Triton)
    # -----------------------------------------------------------------
    left_proj_w = weights["left_proj.weight"]   # (hidden, dim)
    right_proj_w = weights["right_proj.weight"]

    left = _fused_proj_mask_gate(x_norm, left_proj_w, mask, left_gate)   # (B,N,N,hidden)
    right = _fused_proj_mask_gate(x_norm, right_proj_w, mask, right_gate)

    # -----------------------------------------------------------------
    # 5️⃣ Cubic contraction via batched fp16 GEMM (cuBLAS)
    # -----------------------------------------------------------------
    # cast to fp16 – Tensor‑cores give ~10× speedup on H200
    left_h = left.to(torch.float16)
    right_h = right.to(torch.float16)

    B, N, _, H = left_h.shape

    # reshape to (B*H, N, N)  – we collapse the hidden dimension into the batch
    left_flat = left_h.permute(0, 3, 1, 2).reshape(B * H, N, N)   # (B*H,N,N)
    right_flat = right_h.permute(0, 3, 1, 2).reshape(B * H, N, N)

    # batched matmul computes Σ_k left[...,i,k] * right[...,j,k]
    out_flat = torch.bmm(left_flat, right_flat.transpose(1, 2))   # (B*H,N,N)

    # back to fp32 and original layout (B,N,N,hidden)
    out = out_flat.view(B, H, N, N).permute(0, 2, 3, 1).to(torch.float32)

    # -----------------------------------------------------------------
    # 6️⃣ Output LayerNorm (fp32)
    # -----------------------------------------------------------------
    to_out_ln_w = weights["to_out_norm.weight"]
    to_out_ln_b = weights["to_out_norm.bias"]
    mean_o = out.mean(-1, keepdim=True)
    var_o = out.var(-1, unbiased=False, keepdim=True)
    out_norm = (out - mean_o) / torch.sqrt(var_o + eps)
    out_norm = out_norm * to_out_ln_w + to_out_ln_b

    # -----------------------------------------------------------------
    # 7️⃣ Apply output gate (broadcast already matches hidden)
    # -----------------------------------------------------------------
    out_norm = out_norm * out_gate

    # -----------------------------------------------------------------
    # 8️⃣ Final linear projection back to original dim (fp32)
    # -----------------------------------------------------------------
    to_out_w = weights["to_out.weight"]          # (dim, hidden)
    out_final = torch.nn.functional.linear(out_norm, to_out_w)   # (B,N,N,dim)

    return out_final
```
