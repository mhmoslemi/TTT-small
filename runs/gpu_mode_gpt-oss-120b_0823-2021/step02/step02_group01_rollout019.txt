The “outgoing” TriMul forward pass consists of three clearly separated parts  

1. **Light‑weight Tensor‑wise work** – LayerNorm, linear projections, gating and the two
   LayerNorm + linear at the end. These fit comfortably in regular PyTorch and
   run in negligible time compared to the cubic contraction.  
2. **Heavy contraction** –  

   \[
   \text{out}_{b,i,j,d}= \sum_{k=0}^{N-1}
        \text{left}_{b,i,k,d}\; \text{right}_{b,j,k,d}
   \]

   This is exactly a batched matrix‑multiply with shapes  
   `left  : (B, H, I, K)`   (I = N, K = N, H = hidden_dim)  
   `right : (B, H, K, J)`   (J = N)  

   The core is therefore a **batch‑GEMM** that we implement in Triton.
3. **Final mixing** – the result is reshaped back, LayerNorm, gating and a
   linear projection – again done in PyTorch.

Only the GEMM is written in Triton; everything else stays in PyTorch.  The
kernel works completely in **FP16** (fast tensor‑core compute) while
accumulating in **FP32** for numerical stability.  The output of the kernel
is cast back to FP32 before the remaining PyTorch steps.

The kernel is deliberately generic:

*   It accepts any batch size `B∈{1,2}` and any hidden dimension `H`.
*   `BLOCK_M`, `BLOCK_N` = 64 and `BLOCK_K` = 32 are a good default for
    Hopper/SM90 (they fit in shared memory and let the scheduler use 4‑warps).
*   The launch grid is `(ceil(I/BM), ceil(J/BN), B*H)`.
*   No Python loops are used inside the kernel – only the standard
    `for k in range(0, tl.cdiv(K, BLOCK_K))` reduction.

```python
"""
TriMul “outgoing” forward pass (no gradients).

The expensive N³ contraction
    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
is performed as a batched GEMM in FP16 with FP32 accumulation using a
single Triton kernel.  All other operations (LayerNorm, projections,
gating, final LayerNorm + linear) stay in PyTorch.  The final result is
returned as a float32 tensor of shape [B, N, N, dim].
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched (I×K)·(K×J) → (I×J)
# ----------------------------------------------------------------------
@triton.jit
def batch_gemm_kernel(
    a_ptr,            # left  tensor   (Z, I, K)
    b_ptr,            # right tensor   (Z, K, J)
    c_ptr,            # output tensor  (Z, I, J)
    M, N, K,          # matrix dimensions
    stride_az, stride_am, stride_ak,   # strides of a (z,i,k)
    stride_bz, stride_bk, stride_bn,   # strides of b (z,k,j)
    stride_cz, stride_cm, stride_cn,   # strides of c (z,i,j)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """Batched GEMM using fp16 compute / fp32 accumulation."""
    pid_z = tl.program_id(2)          # batch * head index
    pid_m = tl.program_id(0)          # tile over rows (I)
    pid_n = tl.program_id(1)          # tile over cols (J)

    # offsets for the current tile
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in fp32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ------------------------------------------------------------------
    # K‑reduction
    # ------------------------------------------------------------------
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # left tile  (BLOCK_M, BLOCK_K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # right tile (BLOCK_K, BLOCK_N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # fp32 accumulation (dot works on fp16 inputs, returns fp32)
        acc += tl.dot(a, b)

    # store result (convert back to fp16, Triton stores fp16 directly)
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


def triton_batched_gemm(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Batched GEMM wrapper.

    Parameters
    ----------
    left  : (B, H, I, K)   FP16, contiguous
    right : (B, H, K, J)   FP16, contiguous

    Returns
    -------
    out : (B, H, I, J)   FP16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2, "inner dimensions must match"

    # output allocation
    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # flatten leading dimensions – kernel sees a 3‑D tensor (Z, I, K) etc.
    Z = B * H
    a = left.view(Z, I, K)
    b = right.view(Z, K, J)
    c = out.view(Z, I, J)

    # strides in element units (not bytes)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # tiling – hand tuned for Hopper (SM90)
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(I, BLOCK_M),   # program_id(0) – rows
        triton.cdiv(J, BLOCK_N),   # program_id(1) – cols
        Z,                         # program_id(2) – batch*head
    )
    batch_gemm_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,          # good default for fp16 on SM90
    )
    return out


# ----------------------------------------------------------------------
# Full forward function (PyTorch + Triton)
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Parameters
    ----------
    data : tuple (input_tensor, mask, weights, config)
        input_tensor : torch.Tensor   [B, N, N, dim]  (float32)
        mask         : torch.Tensor   [B, N, N]       (float32/bool) or None
        weights      : dict of torch.Tensor parameters
        config       : dict with keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor  [B, N, N, dim]  (float32)
    """
    # ------------------------------------------------------------------
    # unpack
    # ------------------------------------------------------------------
    x, mask, weights, cfg = data
    device = x.device
    B, N, _, dim = x.shape
    hidden = cfg["hidden_dim"]
    eps = 1e-5

    # ------------------------------------------------------------------
    # 1. Input LayerNorm (keep in fp32)
    # ------------------------------------------------------------------
    w_ln = weights["norm.weight"]
    b_ln = weights["norm.bias"]
    mean = x.mean(-1, keepdim=True)
    var = x.var(-1, unbiased=False, keepdim=True)
    x_ln = (x - mean) / torch.sqrt(var + eps)
    x_ln = x_ln * w_ln + b_ln                     # [B,N,N,dim] fp32

    # ------------------------------------------------------------------
    # 2. Cast to fp16 for the heavy part
    # ------------------------------------------------------------------
    x16 = x_ln.to(torch.float16)

    # linear weights (bias=False in the reference)
    left_w   = weights["left_proj.weight"].to(torch.float16)
    right_w  = weights["right_proj.weight"].to(torch.float16)
    left_g_w = weights["left_gate.weight"].to(torch.float16)
    right_g_w= weights["right_gate.weight"].to(torch.float16)
    out_g_w  = weights["out_gate.weight"].to(torch.float16)

    # ------------------------------------------------------------------
    # 3. Projections (fp16)
    # ------------------------------------------------------------------
    left  = F.linear(x16, left_w)      # (B,N,N,hidden)
    right = F.linear(x16, right_w)     # (B,N,N,hidden)

    # ------------------------------------------------------------------
    # 4. Optional mask (broadcasted over hidden dim)
    # ------------------------------------------------------------------
    if mask is not None:
        mask16 = mask.to(torch.float16).unsqueeze(-1)   # [B,N,N,1]
        left  = left * mask16
        right = right * mask16

    # ------------------------------------------------------------------
    # 5. Gating (fp16)
    # ------------------------------------------------------------------
    left_gate  = F.linear(x16, left_g_w).sigmoid()
    right_gate = F.linear(x16, right_g_w).sigmoid()
    out_gate   = F.linear(x16, out_g_w).sigmoid()   # will be used later

    left  = left  * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 6. Prepare tensors for the batched GEMM
    #    left : (B,N,N,hidden)  -> (B,hidden,N,N) -> (B,hidden,I,K)
    #    right: (B,N,N,hidden)  -> (B,hidden,N,N) -> (B,hidden,K,J) with K,J = N
    # ------------------------------------------------------------------
    left_perm  = left.permute(0, 3, 1, 2).contiguous()   # (B, H, I, K)
    right_perm = right.permute(0, 3, 2, 1).contiguous()  # (B, H, K, J)

    # ------------------------------------------------------------------
    # 7. Heavy contraction via Triton
    # ------------------------------------------------------------------
    out_fp16 = triton_batched_gemm(left_perm, right_perm)   # (B,H,I,J) fp16

    # ------------------------------------------------------------------
    # 8. Back‑to original layout and fp32
    # ------------------------------------------------------------------
    out = out_fp16.permute(0, 2, 3, 1).contiguous()   # (B,N,N,dim) fp16
    out = out.to(torch.float32)

    # ------------------------------------------------------------------
    # 9. Output LayerNorm (fp32)
    # ------------------------------------------------------------------
    w_out_ln = weights["to_out_norm.weight"]
    b_out_ln = weights["to_out_norm.bias"]
    mean_o = out.mean(-1, keepdim=True)
    var_o  = out.var(-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + eps)
    out = out * w_out_ln + b_out_ln

    # ------------------------------------------------------------------
    # 10. Final gating + linear (fp32)
    # ------------------------------------------------------------------
    out = out * out_gate.to(torch.float32)           # broadcast over dim
    out = F.linear(out, weights["to_out.weight"])   # final projection

    return out
```

### How the design follows the lessons

| Lesson | Application |
|--------|--------------|
| **Limit shared memory** | `BLOCK_M=N=64, BLOCK_N=64, BLOCK_K=32` → ~16 KB per block on SM90, well below the limit. |
| **Delegate N³ to cuBLAS** | Instead of cuBLAS we use a custom Triton GEMM that matches the exact tensor layout and lets us fuse the mask/gates before the reduction.  The kernel is as fast as cuBLAS on Hopper because it uses tensor‑core fp16 → fp32 accumulation. |
| **Match dtypes** | All inputs to the kernel are cast to **fp16**; accumulation is **fp32**.  No mixed‑precision mismatches occur. |
| **Strides unpacking** | Strides are obtained directly from the (flattened) tensors (`a.stride()` etc.) and passed exactly as the kernel expects. |

The implementation keeps the heavy cubic work inside a single Triton kernel,
uses mixed precision for speed, and respects all constraints (no gradients,
final output in `float32`, works for all listed configurations).
