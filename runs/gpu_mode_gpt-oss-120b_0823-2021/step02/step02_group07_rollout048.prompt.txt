```python
import torch
from torch import nn, einsum
import math

# Reference code in PyTorch
class TriMul(nn.Module):
    def __init__(
        self,
        dim: int,
        hidden_dim: int,
    ):
        super().__init__()

        self.norm = nn.LayerNorm(dim)

        self.left_proj = nn.Linear(dim, hidden_dim, bias=False)
        self.right_proj = nn.Linear(dim, hidden_dim, bias=False)

        self.left_gate = nn.Linear(dim, hidden_dim, bias=False)
        self.right_gate = nn.Linear(dim, hidden_dim, bias=False)
        self.out_gate = nn.Linear(dim, hidden_dim, bias=False)

        self.to_out_norm = nn.LayerNorm(hidden_dim)
        self.to_out = nn.Linear(hidden_dim, dim, bias=False)

    def forward(self, x: torch.Tensor, mask: torch.Tensor) -> torch.Tensor:
        """
        x: [bs, seq_len, seq_len, dim]
        mask: [bs, seq_len, seq_len]

        Returns:
            output: [bs, seq_len, seq_len, dim]
        """
        batch_size, seq_len, _, dim = x.shape

        x = self.norm(x)

        left = self.left_proj(x)
        right = self.right_proj(x)

        mask = mask.unsqueeze(-1)
        left = left * mask
        right = right * mask

        left_gate = self.left_gate(x).sigmoid()
        right_gate = self.right_gate(x).sigmoid()
        out_gate = self.out_gate(x).sigmoid()

        left = left * left_gate
        right = right * right_gate

        out = einsum('... i k d, ... j k d -> ... i j d', left, right)
        # This einsum is the same as the following:
        # out = torch.zeros(batch_size, seq_len, seq_len, dim, device=x.device)
        
        # # Compute using nested loops
        # for b in range(batch_size):
        #     for i in range(seq_len):
        #         for j in range(seq_len):
        #             # Compute each output element
        #             for k in range(seq_len):
        #                 out[b, i, j] += left[b, i, k, :] * right[b, j, k, :]

        out = self.to_out_norm(out)
        out = out * out_gate
        return self.to_out(out)
```

## Triton launch convention

Every failure mode below has appeared in this search. Read this before writing.

A `@triton.jit` function is NOT a Python function. It is launched with a grid
subscript, and its `tl.constexpr` parameters exist only inside it:

```python
@triton.jit
def my_kernel(x_ptr, y_ptr, n, BLOCK: tl.constexpr):
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    m = offs < n
    tl.store(y_ptr + offs, tl.load(x_ptr + offs, mask=m, other=0.0), mask=m)

def custom_kernel(data):
    ...
    BLOCK = 128                                   # a host variable YOU define
    grid = (triton.cdiv(n, BLOCK),)               # host-side, use triton.cdiv
    my_kernel[grid](x, y, n, BLOCK=BLOCK)         # note the [grid] subscript
```

- `my_kernel(...)` without `[grid]` raises "Cannot call @triton.jit'd outside
  the scope of a kernel".
- `BLOCK`, `BLOCK_M`, `BLOCK_N` are not defined on the host unless you define
  them there. Referencing one you only declared as a `tl.constexpr` parameter
  raises NameError.
- `tl.cdiv` is device-side. On the host use `triton.cdiv`.
- Define the kernel at module top level, never nested inside `custom_kernel`.

You do not have to move everything into Triton. A correct submission that keeps
most of the computation in PyTorch and moves one hot region into a kernel scores;
one that fails to launch scores zero.

```python
"""
custom_kernel – “outgoing” TriMul forward pass (AlphaFold3)

Algorithm
---------
1.  LayerNorm on the 4‑D input (B,N,N,C)   →  fp32
2.  Linear projections  (C → H)           →  fp32
3.  Linear gates + sigmoid                →  fp32
4.  Triton kernel fuses mask, left‑gate,
    right‑gate into the projected tensors (in‑place, fp32)
5.  Cast to fp16 and reshape to (B*H, N, N)
6.  Batched GEMM:   out_h = left_h @ right_hᵀ   (torch.bmm, fp16, Tensor‑Core)
7.  Cast back to fp32, reshape to (B,N,N,H)
8.  LayerNorm + output‑gate + final linear (fp32)

The kernel only performs element‑wise work; the cubic contraction is
implemented by a highly tuned cuBLAS batched matmul, which is the
fastest way to compute the einsum
    out[..., i, j, d] = Σ_k left[..., i, k, d] * right[..., j, k, d]
for all heads d simultaneously.
"""

import torch
import triton
import triton.language as tl

# ------------------------------------------------------------------
# Triton kernel – fuse mask and both gates into left/right tensors
# ------------------------------------------------------------------
@triton.jit
def _fuse_mask_gates_kernel(
    left_ptr,          # [B,N,N,H]   fp32
    right_ptr,         # [B,N,N,H]   fp32
    mask_ptr,          # [B,N,N,1]   fp32 (broadcasted mask)
    left_gate_ptr,     # [B,N,N,H]   fp32
    right_gate_ptr,    # [B,N,N,H]   fp32
    B, N, H,           # compile‑time constants
    # strides (in elements, not bytes)
    stride_left_b, stride_left_i, stride_left_j, stride_left_h,
    stride_right_b, stride_right_i, stride_right_j, stride_right_h,
    stride_mask_b, stride_mask_i, stride_mask_j,
    stride_lgate_b, stride_lgate_i, stride_lgate_j, stride_lgate_h,
    stride_rgate_b, stride_rgate_i, stride_rgate_j, stride_rgate_h,
    BLOCK: tl.constexpr,
):
    pid = tl.program_id(0)
    total = B * N * N * H
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    mask = offs < total

    # decode linear offset → (b,i,j,h)
    b = (offs // (N * N * H))
    rest = offs % (N * N * H)
    i = (rest // (N * H))
    rest = rest % (N * H)
    j = (rest // H)
    h = rest % H

    # pointer arithmetic
    left_off   = b * stride_left_b   + i * stride_left_i   + j * stride_left_j   + h * stride_left_h
    right_off  = b * stride_right_b  + i * stride_right_i  + j * stride_right_j  + h * stride_right_h
    mask_off   = b * stride_mask_b   + i * stride_mask_i   + j * stride_mask_j
    lgate_off  = b * stride_lgate_b  + i * stride_lgate_i  + j * stride_lgate_j  + h * stride_lgate_h
    rgate_off  = b * stride_rgate_b  + i * stride_rgate_i  + j * stride_rgate_j  + h * stride_rgate_h

    # load
    left   = tl.load(left_ptr   + left_off,   mask=mask, other=0.0)
    right  = tl.load(right_ptr  + right_off,  mask=mask, other=0.0)
    m      = tl.load(mask_ptr   + mask_off,   mask=mask, other=0.0)   # broadcasted
    lgate  = tl.load(left_gate_ptr + lgate_off, mask=mask, other=0.0)
    rgate  = tl.load(right_gate_ptr+ rgate_off, mask=mask, other=0.0)

    # fuse
    left  = left  * m * lgate
    right = right * m * rgate

    # store back (in‑place)
    tl.store(left_ptr  + left_off,  left,  mask=mask)
    tl.store(right_ptr + right_off, right, mask=mask)


def _fuse_mask_and_gates(left, right, mask, left_gate, right_gate):
    """In‑place element‑wise fuse using Triton."""
    B, N, _, H = left.shape
    total = B * N * N * H
    BLOCK = 2048                     # ~2k threads → good occupancy on H200
    grid = (triton.cdiv(total, BLOCK),)

    # strides in *elements* (not bytes)
    s_left = left.stride()
    s_right = right.stride()
    s_mask = mask.stride()
    s_lgate = left_gate.stride()
    s_rgate = right_gate.stride()

    _fuse_mask_gates_kernel[grid](
        left_ptr=left,
        right_ptr=right,
        mask_ptr=mask,
        left_gate_ptr=left_gate,
        right_gate_ptr=right_gate,
        B=B, N=N, H=H,
        stride_left_b=s_left[0], stride_left_i=s_left[1],
        stride_left_j=s_left[2], stride_left_h=s_left[3],
        stride_right_b=s_right[0], stride_right_i=s_right[1],
        stride_right_j=s_right[2], stride_right_h=s_right[3],
        stride_mask_b=s_mask[0], stride_mask_i=s_mask[1],
        stride_mask_j=s_mask[2],
        stride_lgate_b=s_lgate[0], stride_lgate_i=s_lgate[1],
        stride_lgate_j=s_lgate[2], stride_lgate_h=s_lgate[3],
        stride_rgate_b=s_rgate[0], stride_rgate_i=s_rgate[1],
        stride_rgate_j=s_rgate[2], stride_rgate_h=s_rgate[3],
        BLOCK=BLOCK,
    )
    return left, right


# ------------------------------------------------------------------
# Main entry point required by the harness
# ------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward of the outgoing TriMul module.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask, weights_dict, config_dict)

    Returns
    -------
    torch.Tensor
        Tensor of shape [B, N, N, dim] (float32, on same CUDA device)
    """
    x, mask, weights, config = data
    dim = config["dim"]
    hidden = config["hidden_dim"]
    device = x.device

    # -------------------------------------------------
    # 1️⃣ LayerNorm (manual, fp32)
    # -------------------------------------------------
    eps = 1e-5
    ln_w = weights["norm.weight"]   # (dim,)
    ln_b = weights["norm.bias"]     # (dim,)
    mean = x.mean(-1, keepdim=True)
    var = x.var(-1, unbiased=False, keepdim=True)
    x_norm = (x - mean) / torch.sqrt(var + eps)
    x_norm = x_norm * ln_w + ln_b                         # (B,N,N,dim)

    # -------------------------------------------------
    # 2️⃣ Linear projections (fp32, no bias)
    # -------------------------------------------------
    left_proj_w = weights["left_proj.weight"]   # (hidden, dim)
    right_proj_w = weights["right_proj.weight"]
    left = torch.nn.functional.linear(x_norm, left_proj_w)   # (B,N,N,hidden)
    right = torch.nn.functional.linear(x_norm, right_proj_w)

    # -------------------------------------------------
    # 3️⃣ Gates (fp32) + sigmoid
    # -------------------------------------------------
    left_gate_w = weights["left_gate.weight"]
    right_gate_w = weights["right_gate.weight"]
    out_gate_w = weights["out_gate.weight"]
    left_gate = torch.nn.functional.linear(x_norm, left_gate_w).sigmoid()
    right_gate = torch.nn.functional.linear(x_norm, right_gate_w).sigmoid()
    out_gate = torch.nn.functional.linear(x_norm, out_gate_w).sigmoid()

    # -------------------------------------------------
    # 4️⃣ Mask handling (broadcast to channel dim)
    # -------------------------------------------------
    if mask is None:
        # treat as all‑ones if missing
        mask = torch.ones(x.shape[0], x.shape[1], x.shape[2],
                          device=device, dtype=x.dtype)
    mask = mask.unsqueeze(-1)          # (B,N,N,1)

    # -------------------------------------------------
    # 5️⃣ Fuse mask + gates into left/right (in‑place)
    # -------------------------------------------------
    _fuse_mask_and_gates(left, right, mask, left_gate, right_gate)

    # -------------------------------------------------
    # 6️⃣ Heavy N³ contraction via batched matmul (fp16)
    # -------------------------------------------------
    B, N, _, H = left.shape

    # Cast to fp16 – Tensor Cores get a huge speed boost
    left_h = left.to(torch.float16)
    right_h = right.to(torch.float16)

    # reshape to (B*H, N, N)
    left_flat = left_h.permute(0, 3, 1, 2).reshape(B * H, N, N)          # (B*H,N,N)
    right_flat = right_h.permute(0, 3, 1, 2).reshape(B * H, N, N)

    # batched matrix multiplication: each head contracts over the third axis
    out_flat = torch.bmm(left_flat, right_flat.transpose(1, 2))        # (B*H,N,N)

    # back to fp32 and original layout
    out = out_flat.view(B, H, N, N).permute(0, 2, 3, 1).to(torch.float32)  # (B,N,N,hidden)

    # -------------------------------------------------
    # 7️⃣ Output LayerNorm (fp32)
    # -------------------------------------------------
    to_out_ln_w = weights["to_out_norm.weight"]
    to_out_ln_b = weights["to_out_norm.bias"]
    eps_o = 1e-5
    mean_o = out.mean(-1, keepdim=True)
    var_o = out.var(-1, unbiased=False, keepdim=True)
    out_norm = (out - mean_o) / torch.sqrt(var_o + eps_o)
    out_norm = out_norm * to_out_ln_w + to_out_ln_b

    # -------------------------------------------------
    # 8️⃣ Apply output gate
    # -------------------------------------------------
    out_norm = out_norm * out_gate

    # -------------------------------------------------
    # 9️⃣ Final linear (fp32)
    # -------------------------------------------------
    to_out_w = weights["to_out.weight"]          # (dim, hidden)
    out_final = torch.nn.functional.linear(out_norm, to_out_w)   # (B,N,N,dim)

    return out_final
```


## Lessons from earlier kernels in this search

Extracted from kernels already generated and benchmarked here. Empirical
findings, not part of the specification above, and they do not override any rule
stated in it.

**Observed to help**
1. [local] Limit shared memory usage
   When launching a Triton kernel, set BLOCK_M, BLOCK_N, and BLOCK_K to values (e.g., ≤64) that keep required shared memory below the device limit; if needed, lower num_stages.
2. [global] Delegate N³ contraction to cuBLAS
   Reshape the left and right tensors to (B*H, N, N) and compute out = torch.bmm(left, right.transpose(1,2)); this leverages cuBLAS/Tensor‑cores for the dominant O(N³) work while keeping the program simple and fast.
3. [local] Match dtypes for batched GEMM
   If you cast one operand (e.g., the weight matrix) to float16 for speed, also cast the other operand to float16 before the batched matmul, or keep both in float32; mixing float32 and float16 raises a runtime error.

**Observed to fail**
1. [local] Match stride unpacking to tensor rank
   Do not assume a tensor has three strides; use tensor.stride() and unpack exactly the number of dimensions the kernel expects, or pass strides explicitly from the caller.
