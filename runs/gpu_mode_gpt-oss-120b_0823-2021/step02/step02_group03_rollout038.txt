The dominant work of the module is the three‑dimensional contraction  

\[
\text{out}_{b,i,j,d}= \sum_{k=0}^{N-1}
    \bigl(\text{left}_{b,i,k,d}\cdot g^{\text{L}}_{b,i,k,d}\bigr)\;
    \bigl(\text{right}_{b,j,k,d}\cdot g^{\text{R}}_{b,j,k,d}\bigr)
\]

where `left`/`right` are the linear projections of the input, `gL`/`gR` are the
sigmoid gates and `d` runs over the hidden dimension `H=hidden_dim`.  
For a fixed batch‑index `b` and hidden‑index `h` this is exactly a matrix‑matrix
multiply

```
left_h   : (N, N)   ←  left  [b, i, k, h]
right_h  : (N, N)   ←  right [b, j, k, h]  (will be transposed)
out_h    = left_h @ right_h.T          → (N, N)
```

All other operations (LayerNorm, linear layers, gating, final LayerNorm and
linear) are cheap compared with the O(N³) work and are therefore kept in
PyTorch.  The kernel only computes the batched GEMM for every `(b,h)` pair.
We tile the `i`‑ and `j`‑axes with `BLOCK_M × BLOCK_N` threads and iterate over
`k` in tiles of size `BLOCK_K`.  Operands are loaded as **FP16** (to exploit the
Tensor‑Core bandwidth of the Hopper‑H200) while the accumulation is performed
in **FP32** to keep numerical stability.  The result is written back as FP16
and later converted to FP32 for the remaining PyTorch post‑processing.

Key implementation points
* Strides are passed explicitly; the kernel works for any contiguous layout.
* Optional mask is applied **before** the kernel (still in FP32) – this avoids
  divergent control flow inside the kernel.
* The launch grid encodes `(batch, hidden, tile_i, tile_j)`.  
  `grid = (B * H * ceil(N/BM) * ceil(N/BN), )`.
* Block sizes `(64, 64, 32)` were chosen because they fit comfortably into the
  64 KB shared‑memory budget of the H200 and give high occupancy.
* The kernel is written with only device‑side constructs (`tl.program_id`,
  `tl.arange`, `tl.dot`, `tl.load`, `tl.store`).  No Python control‑flow
  inside the kernel.

```python
"""
TriMul “outgoing” kernel (AlphaFold‑3)

Implements the O(N³) contraction
    out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]

All cheap ops (layer‑norms, linear layers, gating, final projection) are done
in PyTorch.  The heavy work is performed by a Triton kernel that computes a
batched GEMM for each (batch, hidden) slice, using FP16 arithmetic with FP32
accumulation.
"""

from typing import Tuple, Dict, Any

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# -------------------------------------------------------------------------
# Triton kernel: batched GEMM for a single (batch, hidden) slice
# -------------------------------------------------------------------------
@triton.jit
def _trimul_outgoing_kernel(
    left_ptr,          # const fp16 *  [B, H, N, N]
    right_ptr,         # const fp16 *  [B, H, N, N]
    out_ptr,           #       fp16 *  [B, H, N, N]
    B, N, H,           # int32 scalars
    stride_lbh, stride_lhd, stride_lhn, stride_lhk,   # left strides
    stride_rbh, stride_rhd, stride_rhn, stride_rhk,   # right strides
    stride_obh, stride_obd, stride_obn, stride_obk,   # out strides
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Compute:
        out[b, h, i, j] = Σ_k left[b, h, i, k] * right[b, h, j, k]
    for a single (b, h) tile (i‑tile × j‑tile).
    """
    pid = tl.program_id(0)

    # --------------------------------------------------------------
    # Decode pid → (b, h, block_i, block_j)
    # --------------------------------------------------------------
    num_blocks_i = tl.cdiv(N, BLOCK_M)
    num_blocks_j = tl.cdiv(N, BLOCK_N)

    block_j = pid % num_blocks_j
    pid //= num_blocks_j
    block_i = pid % num_blocks_i
    pid //= num_blocks_i
    h = pid % H
    b = pid // H

    # --------------------------------------------------------------
    # Offsets for the current tile
    # --------------------------------------------------------------
    offs_i = block_i * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_j = block_j * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_i = offs_i < N
    mask_j = offs_j < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # Loop over K dimension in tiles
    # --------------------------------------------------------------
    for k_tile in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = k_tile * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # left[b, h, i, k]  (M × K)
        l_ptr = (
            left_ptr
            + b * stride_lbh
            + h * stride_lhd
            + offs_i[:, None] * stride_lhn
            + offs_k[None, :] * stride_lhk
        )
        l = tl.load(l_ptr,
                    mask=mask_i[:, None] & mask_k[None, :],
                    other=0.0).to(tl.float32)

        # right[b, h, j, k] – we need the K‑dimension as rows (K × N)
        r_ptr = (
            right_ptr
            + b * stride_rbh
            + h * stride_rhd
            + offs_k[:, None] * stride_rhk
            + offs_j[None, :] * stride_rhn
        )
        r = tl.load(r_ptr,
                    mask=mask_k[:, None] & mask_j[None, :],
                    other=0.0).to(tl.float32)

        # GEMM over K
        acc += tl.dot(l, r)          # (M,K) @ (K,N) → (M,N)

    # --------------------------------------------------------------
    # Write the result back (FP16)
    # --------------------------------------------------------------
    out_ptrs = (
        out_ptr
        + b * stride_obh
        + h * stride_obd
        + offs_i[:, None] * stride_obn
        + offs_j[None, :] * stride_obk
    )
    tl.store(out_ptrs,
             acc.to(tl.float16),
             mask=mask_i[:, None] & mask_j[None, :])


# -------------------------------------------------------------------------
# Host‑side wrapper
# -------------------------------------------------------------------------
def custom_kernel(
    data: Tuple[torch.Tensor, torch.Tensor, Dict[str, torch.Tensor], Dict[str, Any]]
) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.

    Args
    ----
    data : (x, mask, weights, config)
        x          : (B, N, N, dim)   torch.float32
        mask       : (B, N, N)       torch.float32 or None
        weights    : dict of pre‑trained tensors (see docstring above)
        config     : {"dim": dim, "hidden_dim": hidden_dim}

    Returns
    -------
    torch.Tensor of shape (B, N, N, dim)  (dtype=torch.float32)
    """
    x, mask, weights, config = data
    device = x.device
    dtype = torch.float32

    B, N, _, dim = x.shape
    hidden_dim = config["hidden_dim"]

    # -----------------------------------------------------------------
    # 1️⃣ Cheap preprocessing in PyTorch
    # -----------------------------------------------------------------
    # LayerNorm over the last dimension
    x = F.layer_norm(
        x,
        normalized_shape=(dim,),
        weight=weights["norm.weight"].to(dtype),
        bias=weights["norm.bias"].to(dtype),
    )

    # Linear projections (no bias)
    left = F.linear(x, weights["left_proj.weight"].to(dtype))   # (B,N,N,hidden)
    right = F.linear(x, weights["right_proj.weight"].to(dtype))

    # -----------------------------------------------------------------
    # 2️⃣ Optional mask (broadcast over hidden dim)
    # -----------------------------------------------------------------
    if mask is not None:
        # mask shape (B, N, N) → (B, N, N, 1) → broadcast
        mask_f = mask.to(dtype).unsqueeze(-1)
        left = left * mask_f
        right = right * mask_f

    # -----------------------------------------------------------------
    # 3️⃣ Gating (sigmoid) – cheap, stays in FP32
    # -----------------------------------------------------------------
    left_gate = torch.sigmoid(F.linear(x, weights["left_gate.weight"].to(dtype)))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"].to(dtype)))
    out_gate = torch.sigmoid(F.linear(x, weights["out_gate.weight"].to(dtype)))

    left = left * left_gate
    right = right * right_gate

    # -----------------------------------------------------------------
    # 4️⃣ Re‑arrange to (B, H, N, N) and cast to FP16 for the kernel
    # -----------------------------------------------------------------
    # (B,N,N,H) → (B,H,N,N)
    left = left.permute(0, 3, 1, 2).contiguous()
    right = right.permute(0, 3, 1, 2).contiguous()

    left_fp16 = left.to(torch.float16)
    right_fp16 = right.to(torch.float16)

    out_fp16 = torch.empty_like(left_fp16)   # (B,H,N,N) fp16

    # -----------------------------------------------------------------
    # 5️⃣ Triton launch – batched GEMM over (i,j) for each (b,h)
    # -----------------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    # total programs = B * H * ceil(N/BM) * ceil(N/BN)
    grid = (
        triton.cdiv(B * hidden_dim *
                   triton.cdiv(N, BLOCK_M) *
                   triton.cdiv(N, BLOCK_N), 1),
    )

    _trimul_outgoing_kernel[grid](
        left_fp16,
        right_fp16,
        out_fp16,
        B, N, hidden_dim,
        # strides for left
        left_fp16.stride(0), left_fp16.stride(1),
        left_fp16.stride(2), left_fp16.stride(3),
        # strides for right
        right_fp16.stride(0), right_fp16.stride(1),
        right_fp16.stride(2), right_fp16.stride(3),
        # strides for out
        out_fp16.stride(0), out_fp16.stride(1),
        out_fp16.stride(2), out_fp16.stride(3),
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # -----------------------------------------------------------------
    # 6️⃣ Post‑processing (still in PyTorch)
    # -----------------------------------------------------------------
    # back to (B,N,N,hidden)
    out = out_fp16.to(dtype).permute(0, 2, 3, 1).contiguous()

    # LayerNorm over hidden dimension
    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"].to(dtype),
        bias=weights["to_out_norm.bias"].to(dtype),
    )

    # Apply output gate (broadcast over N,N)
    out = out * out_gate

    # Final linear projection back to original dim
    out = F.linear(out, weights["to_out.weight"].to(dtype))

    return out
```
