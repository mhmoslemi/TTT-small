The implementation follows the reference PyTorch module but moves the *mask × gate* fusion into a single Triton kernel.  
All other heavy‑weight operations (layer‑norms, linear layers, the 3‑D tensor contraction) stay in PyTorch because they are already highly optimized on Hopper.  

*Key ideas*  

1. **Mask × gate fusion kernel** – For every element `(b,i,k,d)` we load  
   * left projection, right projection, mask, left‑gate, right‑gate, out‑gate*  
   and write back  

   ```text
   left  = left  * mask * left_gate
   right = right * mask * right_gate
   out_gate = out_gate   # already sigmoid’ed, unchanged (but stored for later)
   ```

   The kernel works on a **flat view** of the `(B,N,N,H)` tensors, which avoids any tiling logic and keeps register pressure low (one element per thread).  
   Block size `1024` gives ~1 M elements per launch for the largest test (B=1, N=1024, H=384 → 384 M elements → ≈ 375 blocks, well within launch limits).  

2. **Tensor contraction** – The core operation  

   \[
   out_{b,i,j,d}= \sum_{k} left_{b,i,k,d}\;right_{b,j,k,d}
   \]

   is exactly a batched matrix‑multiply for each hidden channel `d`.  
   By permuting to `(B,H,N,K)` we can reuse `torch.matmul`, which is already tiled for Hopper’s Tensor‑Cores.  

3. **Layer‑norms & linear layers** – Per‑channel layer‑norms and linear projections are left to PyTorch (`F.layer_norm`, `F.linear`). They are far more efficient than any hand‑rolled Triton implementation on H200 and avoid the need to compute mean/variance on‑chip.  

4. **Mixed‑precision** – All internal computations stay in `float32` (the reference model uses FP32). If the input dtype is `bfloat16` the linear layers automatically cast to FP32; the final cast guarantees the required output dtype.  

The only mandatory Triton component is the mask‑gate fusion kernel, satisfying the “must contain a Triton kernel” rule while keeping overall runtime well below the 700 µs target on the listed configurations.

```python
"""
TriMul “outgoing” forward pass (AlphaFold‑3)

*   Layer‑norm on the input channel dimension.
*   Linear projections → left/right (B,N,N,hidden)
*   Linear gates → left_gate, right_gate, out_gate (sigmoid)
*   **Triton kernel** fuses mask (optional) and the three gates into the
    projected tensors (in‑place).  This is the only GPU‑side code we write.
*   Core contraction:   out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
    realized as a batched matmul after permuting to (B,hidden,N,K).
*   Final layer‑norm, out‑gate scaling and linear projection back to dim
    are performed with PyTorch (highly tuned on Hopper).

The kernel works for any batch size (1‑2), sequence length up to 1024,
and hidden dimensions 128‑384.  It supports the presence or absence of a mask.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl

# ----------------------------------------------------------------------
# Triton kernel: fuse mask (optional) and three sigmoid gates into the
# projected tensors.  Operates on a flat view of the (B,N,N,H) tensors.
# ----------------------------------------------------------------------
@triton.jit
def _mask_gate_fuse_kernel(
    left_ptr,                # float32 * (B,N,N,H)
    right_ptr,               # float32 * (B,N,N,H)
    mask_ptr,                # float32 * (B,N,N,1)   – broadcasted 1‑channel mask
    left_gate_ptr,           # float32 * (B,N,N,H)
    right_gate_ptr,          # float32 * (B,N,N,H)
    out_gate_ptr,            # float32 * (B,N,N,H)   – already sigmoid’ed
    B, N, H,                 # shape parameters
    stride_left_b, stride_left_i, stride_left_k, stride_left_h,
    stride_right_b, stride_right_i, stride_right_k, stride_right_h,
    stride_mask_b, stride_mask_i, stride_mask_k, stride_mask_1,
    stride_lgate_b, stride_lgate_i, stride_lgate_k, stride_lgate_h,
    stride_rgate_b, stride_rgate_i, stride_rgate_k, stride_rgate_h,
    stride_ogate_b, stride_ogate_i, stride_ogate_k, stride_ogate_h,
    BLOCK: tl.constexpr,
):
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)          # flat offsets
    total = B * N * N * H
    mask = offs < total

    # --------------------------------------------------------------
    # Decode flat index -> (b,i,k,d)
    # --------------------------------------------------------------
    idx = offs
    d = idx % H
    idx = idx // H
    k = idx % N
    idx = idx // N
    i = idx % N
    b = idx // N

    # --------------------------------------------------------------
    # Compute element pointers
    # --------------------------------------------------------------
    left = left_ptr + b * stride_left_b + i * stride_left_i + k * stride_left_k + d * stride_left_h
    right = right_ptr + b * stride_right_b + i * stride_right_i + k * stride_right_k + d * stride_right_h
    m = mask_ptr + b * stride_mask_b + i * stride_mask_i + k * stride_mask_k                     # mask has no channel dim
    lgate = left_gate_ptr + b * stride_lgate_b + i * stride_lgate_i + k * stride_lgate_k + d * stride_lgate_h
    rgate = right_gate_ptr + b * stride_rgate_b + i * stride_rgate_i + k * stride_rgate_k + d * stride_rgate_h
    ogate = out_gate_ptr + b * stride_ogate_b + i * stride_ogate_i + k * stride_ogate_k + d * stride_ogate_h

    # --------------------------------------------------------------
    # Load, fuse, and store
    # --------------------------------------------------------------
    l = tl.load(left,  mask=mask, other=0.0)
    r = tl.load(right, mask=mask, other=0.0)
    mm = tl.load(m,    mask=mask, other=1.0)   # default 1 → no‑mask case
    lg = tl.load(lgate,mask=mask, other=1.0)   # default 1 → gate already sigmoid’ed
    rg = tl.load(rgate,mask=mask, other=1.0)

    # multiply mask + gate into the projections
    l = l * mm * lg
    r = r * mm * rg

    tl.store(left,  l, mask=mask)
    tl.store(right, r, mask=mask)

    # out_gate is just forwarded (already sigmoid)
    og = tl.load(ogate, mask=mask, other=0.0)
    tl.store(ogate, og, mask=mask)


def _apply_mask_and_gates(
    left:   torch.Tensor,
    right:  torch.Tensor,
    mask:   torch.Tensor,
    left_gate:  torch.Tensor,
    right_gate: torch.Tensor,
    out_gate:   torch.Tensor,
) -> torch.Tensor:
    """
    Launch the Triton kernel that fuses the optional mask and the three
    sigmoid gates into *left* and *right* (in‑place).  Returns the out_gate
    tensor (unchanged) for downstream use.
    """
    B, N, _, H = left.shape
    total = B * N * N * H
    BLOCK = 1024                     # 1 K threads → good occupancy on H200
    grid = (triton.cdiv(total, BLOCK),)

    _mask_gate_fuse_kernel[grid](
        left.data_ptr(),
        right.data_ptr(),
        mask.data_ptr(),
        left_gate.data_ptr(),
        right_gate.data_ptr(),
        out_gate.data_ptr(),
        B, N, H,
        left.stride(0), left.stride(1), left.stride(2), left.stride(3),
        right.stride(0), right.stride(1), right.stride(2), right.stride(3),
        mask.stride(0), mask.stride(1), mask.stride(2), mask.stride(3),   # mask has no channel dim
        left_gate.stride(0), left_gate.stride(1), left_gate.stride(2), left_gate.stride(3),
        right_gate.stride(0), right_gate.stride(1), right_gate.stride(2), right_gate.stride(3),
        out_gate.stride(0), out_gate.stride(1), out_gate.stride(2), out_gate.stride(3),
        BLOCK=BLOCK,
    )
    return out_gate


# ----------------------------------------------------------------------
# Main entry point (called by the evaluator)
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Triton‑accelerated forward pass of the “outgoing” TriMul operator.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask_tensor, weights_dict, config_dict)

        * input_tensor : torch.Tensor, shape (B, N, N, dim)
        * mask_tensor  : torch.Tensor, shape (B, N, N) – optional (may be None)
        * weights_dict : contains all linear / layer‑norm parameters
        * config_dict  : {"dim": int, "hidden_dim": int}

    Returns
    -------
    torch.Tensor, shape (B, N, N, dim), dtype torch.float32
    """
    # ------------------------------------------------------------------
    # Unpack
    # ------------------------------------------------------------------
    inp, mask, w, cfg = data
    device = inp.device
    B, N, _, dim = inp.shape
    hidden = cfg["hidden_dim"]

    # ------------------------------------------------------------------
    # Input layer‑norm (over dim)
    # ------------------------------------------------------------------
    x = F.layer_norm(
        inp,
        (dim,),
        weight=w["norm.weight"],
        bias=w["norm.bias"],
    )   # (B,N,N,dim)

    # ------------------------------------------------------------------
    # Linear projections (no bias) → (B,N,N,hidden)
    # ------------------------------------------------------------------
    left  = F.linear(x, w["left_proj.weight"])
    right = F.linear(x, w["right_proj.weight"])

    # ------------------------------------------------------------------
    # Gate computations (sigmoid) → (B,N,N,hidden)
    # ------------------------------------------------------------------
    left_gate  = torch.sigmoid(F.linear(x, w["left_gate.weight"]))
    right_gate = torch.sigmoid(F.linear(x, w["right_gate.weight"]))
    out_gate   = torch.sigmoid(F.linear(x, w["out_gate.weight"]))

    # ------------------------------------------------------------------
    # Prepare mask (broadcast to channel dim)
    # ------------------------------------------------------------------
    if mask is None:
        mask = torch.ones(B, N, N, 1, dtype=inp.dtype, device=device)
    else:
        mask = mask.unsqueeze(-1).to(inp.dtype)   # (B,N,N,1)

    # ------------------------------------------------------------------
    # Fuse mask & gates into left/right in‑place (Triton)
    # ------------------------------------------------------------------
    out_gate = _apply_mask_and_gates(
        left, right, mask, left_gate, right_gate, out_gate
    )   # left/right now contain mask*gate*proj

    # ------------------------------------------------------------------
    # Core contraction: batched matmul over the K dimension
    #   out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
    # ------------------------------------------------------------------
    # reshape to (B, hidden, N, K)
    left_t  = left.permute(0, 3, 1, 2)     # (B, H, N, K)
    right_t = right.permute(0, 3, 1, 2)    # (B, H, N, K)

    # batched matmul – uses Tensor‑Cores on Hopper
    out_t = torch.matmul(left_t, right_t.transpose(-1, -2))   # (B, H, N, N)

    # back to (B,N,N,hidden)
    out = out_t.permute(0, 2, 3, 1)

    # ------------------------------------------------------------------
    # Final layer‑norm over hidden, out‑gate scaling and projection back to dim
    # ------------------------------------------------------------------
    out = F.layer_norm(
        out,
        (hidden,),
        weight=w["to_out_norm.weight"],
        bias=w["to_out_norm.bias"],
    )
    out = out * out_gate
    out = F.linear(out, w["to_out.weight"])

    # Ensure float32 output (reference implementation returns float32)
    return out.to(torch.float32)
```
