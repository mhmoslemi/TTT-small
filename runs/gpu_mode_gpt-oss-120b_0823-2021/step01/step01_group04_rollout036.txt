The “outgoing” TriMul operator can be split into three logical stages  

1. **Point‑wise stage** – LayerNorm, four linear projections and three sigmoid gates, plus the optional mask.  
   *All of these are cheap element‑wise ops and can be fused into a single Trit‑kernel.*  
   The kernel loads the normalized tensor `x̂`, the four projection weight matrices and the mask, computes  

```
left  = (x̂ @ W_left )   * mask * sigmoid(x̂ @ W_left_gate )
right = (x̂ @ W_right)   * mask * sigmoid(x̂ @ W_right_gate)
out_gate = sigmoid(x̂ @ W_out_gate)   // kept as a separate tensor (later used after the N³ step)
```

   The kernel writes three contiguous tensors (`left`, `right`, `out_gate`) and therefore avoids any extra memory traffic.

2. **Heavy N³ stage** –  
   `out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]`.  
   This is exactly a batch of matrix multiplications for each hidden channel `h`.  
   By reshaping we obtain a single `torch.bmm` call (`(B·H, N, N) @ (B·H, N, N).transpose`) which is executed by cuBLAS (the fastest GEMM on H200).

3. **Post‑processing stage** – LayerNorm on the result, multiplication with the previously‑computed `out_gate`, and the final linear projection.  
   These are cheap and are kept in PyTorch.

The only **mandatory Triton component** is the element‑wise fuse kernel.  
All other heavy work is delegated to cuBLAS via `torch.bmm`, which is already highly tuned for the Hopper architecture.

---

### Why this design beats the previous attempt
| Issue in the previous kernel | Fix in the new design |
|------------------------------|-----------------------|
| The fuse kernel operated **in‑place** on already‑projected tensors → two extra passes (project → store → load) and a redundant mask‑gate kernel. | The new kernel **fuses the projections, the mask, and the gates** in a single pass, saving a whole memory round‑trip. |
| All linear projections were performed in PyTorch before the fuse kernel → extra kernel launch needed only for gating. | The kernel receives the *pre‑normalized* tensor and the four weight matrices and directly computes `left`, `right` and `out_gate`. |
| The N³ einsum was rewritten as a batched `bmm`, which is good, but the tensor layout required a costly transpose (`permute`). | We keep the layout `B, N, N, H` and reshape to `(B·H, N, N)` with `permute` **once**; this is a cheap view operation, not a copy. |
| No handling of the *no‑mask* case → unnecessary broadcasting of a mask of ones. | The kernel receives a flag `HAS_MASK` (`tl.constexpr`). When the flag is false the mask load is skipped and the mask factor is assumed to be `1.0`. |

The resulting kernel launch configuration (`BLOCK=1024`) gives ~1 k threads per program – optimal for the H200’s 64 KB shared‑memory per SM and provides enough parallelism for the largest test (`N=1024`).  
All arithmetic is performed in **float32** (the reference model uses FP32), but the kernel can be switched to FP16 by changing the `dtype` constant if needed.

---

### Triton kernel details
* **Inputs**
  * `x_ptr` – normalized input `[B,N,N,D]`
  * `w_left_ptr`, `w_right_ptr`, `w_lgate_ptr`, `w_rgate_ptr`, `w_outgate_ptr` – weight matrices stored as contiguous `[H,D]` (row‑major) tensors.
  * `mask_ptr` – optional mask `[B,N,N,1]`.
* **Outputs**
  * `left_ptr` – `[B,N,N,H]`
  * `right_ptr` – `[B,N,N,H]`
  * `out_gate_ptr` – `[B,N,N,H]`
* **Computation**
  1. Load a block of `x̂` (size `BLOCK`) and the corresponding rows of each weight matrix.
  2. Compute four matrix‑vector products (`dot`) to obtain the four linear results.
  3. Apply sigmoid to the two gate results and to the out‑gate result.
  4. Fuse mask (if present) and write `left`, `right`, `out_gate`.

The kernel is **stateless** and can be launched with a 1‑D grid covering `B·N·N·BLOCK_H` elements, where `BLOCK_H` is the hidden dim (`H`).

### Complete implementation

```python
"""
TriMul “outgoing” forward pass (alpha‑fold3 style).

The heavy N³ contraction is performed as a batched matrix‑multiply
(B·H, N, N) @ (B·H, N, N).T using cuBLAS (torch.bmm).  
All element‑wise work (layer‑norm, four linear projections, three sigmoid
gates and optional mask) is fused into a single Triton kernel, which
produces three tensors: left, right and out_gate.
"""

import torch
import triton
import triton.language as tl
import math
from typing import Tuple, Dict

# ----------------------------------------------------------------------
# Triton kernel – fuse LN output + four linear projections + mask + gates
# ----------------------------------------------------------------------
@triton.jit
def tri_mul_fuse_kernel(
    # input / output pointers (all float32)
    x_ptr,               # [B, N, N, D]   normalized input
    left_ptr,            # [B, N, N, H]   output left
    right_ptr,           # [B, N, N, H]   output right
    out_gate_ptr,        # [B, N, N, H]   output gate
    mask_ptr,            # [B, N, N, 1]   optional mask (ignored if HAS_MASK=0)
    # weight matrices – stored as [H, D] row‑major
    w_left_ptr,          # [H, D]
    w_right_ptr,         # [H, D]
    w_lgate_ptr,         # [H, D]
    w_rgate_ptr,         # [H, D]
    w_outgate_ptr,       # [H, D]
    # static sizes
    B, N, D, H,
    # strides (in elements)
    stride_x_b, stride_x_n1, stride_x_n2, stride_x_d,
    stride_left_b, stride_left_n1, stride_left_n2, stride_left_h,
    stride_right_b, stride_right_n1, stride_right_n2, stride_right_h,
    stride_outgate_b, stride_outgate_n1, stride_outgate_n2, stride_outgate_h,
    stride_mask_b, stride_mask_n1, stride_mask_n2,
    # compile‑time constants
    BLOCK: tl.constexpr,               # threads per program
    HAS_MASK: tl.constexpr,            # 1 if mask is present, else 0
):
    pid = tl.program_id(0)                         # linear program id
    total = B * N * N * H
    offs = pid * BLOCK + tl.arange(0, BLOCK)       # element indices for this thread
    mask = offs < total

    # -------------------------------------------------------------
    # Decode linear offset -> (b, i, j, h)
    # linear layout: ((b * N + i) * N + j) * H + h
    # -------------------------------------------------------------
    b = (offs // (N * N * H))
    rem = offs % (N * N * H)
    i = (rem // (N * H))
    rem = rem % (N * H)
    j = (rem // H)
    h = rem % H

    # -------------------------------------------------------------
    # Pointers to the required elements
    # -------------------------------------------------------------
    x_off   = (b * stride_x_b   +
               i * stride_x_n1  +
               j * stride_x_n2  +
               0 * stride_x_d)          # we will load a whole D‑vector later

    left_out_off   = (b * stride_left_b   +
                      i * stride_left_n1 +
                      j * stride_left_n2 +
                      h * stride_left_h)

    right_out_off  = (b * stride_right_b   +
                      i * stride_right_n1 +
                      j * stride_right_n2 +
                      h * stride_right_h)

    outgate_out_off = (b * stride_outgate_b   +
                       i * stride_outgate_n1 +
                       j * stride_outgate_n2 +
                       h * stride_outgate_h)

    if HAS_MASK:
        mask_off = (b * stride_mask_b +
                    i * stride_mask_n1 +
                    j * stride_mask_n2)
        m = tl.load(mask_ptr + mask_off, mask=mask, other=1.0)   # broadcast mask to channel dim
    else:
        m = 1.0

    # -------------------------------------------------------------
    # Load the D‑dimensional input vector for this (b,i,j)
    # -------------------------------------------------------------
    # Gather the whole row of x̂ (size D) – we use a small inner loop
    # because D (dim) is at most 384 → fits in registers.
    # NOTE: using tl.load with a vectorised pointer is not supported,
    # so we load element‑wise in a loop that is unrolled by the compiler.
    x_vec = tl.zeros([32], dtype=tl.float32)   # placeholder, will be overwritten
    # The loop is written manually to avoid Python for‑loops (triton limitation)
    # We rely on the compiler to unroll a constant‑size loop (D <= 384)
    # To keep the kernel simple we load with a stride of 1 over the D dimension.
    # tl.load supports a vector of contiguous elements via the `mask` argument,
    # but we need the exact D; we therefore use a ptr arithmetic trick:
    #   ptr = x_ptr + x_off
    #   tl.load(ptr + tl.arange(0, D) * stride_x_d)
    # This yields a 1‑D tensor of shape (D,).
    x_ptr_base = x_ptr + x_off
    x_vec = tl.load(x_ptr_base + tl.arange(0, D) * stride_x_d, mask=mask, other=0.0)

    # -------------------------------------------------------------
    # Compute four linear maps:  w @ x_vec.T   (shape H)
    # -------------------------------------------------------------
    # Weight rows are contiguous, stride = D
    w_left_row   = tl.load(w_left_ptr   + h * D + tl.arange(0, D))
    w_right_row  = tl.load(w_right_ptr  + h * D + tl.arange(0, D))
    w_lgate_row  = tl.load(w_lgate_ptr  + h * D + tl.arange(0, D))
    w_rgate_row  = tl.load(w_rgate_ptr  + h * D + tl.arange(0, D))
    w_outgate_row= tl.load(w_outgate_ptr+ h * D + tl.arange(0, D))

    # Dot products (reduce over D)
    left_lin   = tl.dot(x_vec, w_left_row)
    right_lin  = tl.dot(x_vec, w_right_row)
    lgate_lin  = tl.dot(x_vec, w_lgate_row)
    rgate_lin  = tl.dot(x_vec, w_rgate_row)
    outgate_lin= tl.dot(x_vec, w_outgate_row)

    # -------------------------------------------------------------
    # Apply sigmoid gates
    # -------------------------------------------------------------
    lgate = 1.0 / (1.0 + tl.exp(-lgate_lin))
    rgate = 1.0 / (1.0 + tl.exp(-rgate_lin))
    out_gate = 1.0 / (1.0 + tl.exp(-outgate_lin))

    # Fuse mask and gates
    left_val  = left_lin  * m * lgate
    right_val = right_lin * m * rgate

    # -------------------------------------------------------------
    # Store results
    # -------------------------------------------------------------
    tl.store(left_ptr   + left_out_off,   left_val,   mask=mask)
    tl.store(right_ptr  + right_out_off,  right_val,  mask=mask)
    tl.store(out_gate_ptr + outgate_out_off, out_gate, mask=mask)


# ----------------------------------------------------------------------
# Helper to launch the fuse kernel
# ----------------------------------------------------------------------
def fuse_pointwise(
    x_norm: torch.Tensor,          # [B,N,N,D]  already layer‑normed
    mask: torch.Tensor | None,     # [B,N,N,1] or None
    weights: Dict[str, torch.Tensor],
) -> Tuple[torch.Tensor, torch.Tensor, torch.Tensor]:
    """
    Returns (left, right, out_gate) each of shape [B,N,N,H] (float32).
    All heavy element‑wise work is done inside a Triton kernel.
    """
    B, N, _, D = x_norm.shape
    H = weights["left_proj.weight"].shape[0]

    device = x_norm.device
    dtype = x_norm.dtype

    # allocate output buffers (contiguous)
    left      = torch.empty((B, N, N, H), device=device, dtype=dtype)
    right     = torch.empty((B, N, N, H), device=device, dtype=dtype)
    out_gate  = torch.empty((B, N, N, H), device=device, dtype=dtype)

    # ensure mask is contiguous and has correct shape
    if mask is None:
        has_mask = 0
        mask_ptr = torch.empty(0, device=device, dtype=dtype)  # dummy
    else:
        has_mask = 1
        mask = mask.to(dtype).contiguous()
        mask_ptr = mask

    # Strides (in elements, not bytes)
    sx = x_norm.stride()
    sleft  = left.stride()
    sright = right.stride()
    sout   = out_gate.stride()
    smask  = mask_ptr.stride() if has_mask else (0, 0, 0, 0)

    # Weight matrices – they are stored as (H, D) row‑major tensors
    w_left   = weights["left_proj.weight"]
    w_right  = weights["right_proj.weight"]
    w_lgate  = weights["left_gate.weight"]
    w_rgate  = weights["right_gate.weight"]
    w_outgate= weights["out_gate.weight"]

    # launch configuration
    BLOCK = 1024                     # 1 k threads per program – good for H200
    total = B * N * N * H
    grid = (math.ceil(total / BLOCK),)

    tri_mul_fuse_kernel[grid](
        x_norm,
        left,
        right,
        out_gate,
        mask_ptr,
        # weight pointers
        w_left,
        w_right,
        w_lgate,
        w_rgate,
        w_outgate,
        # static sizes
        B, N, D, H,
        # strides
        sx[0], sx[1], sx[2], sx[3],
        sleft[0], sleft[1], sleft[2], sleft[3],
        sright[0], sright[1], sright[2], sright[3],
        sout[0], sout[1], sout[2], sout[3],
        smask[0], smask[1], smask[2],
        # compile‑time consts
        BLOCK=BLOCK,
        HAS_MASK=has_mask,
    )
    return left, right, out_gate


# ----------------------------------------------------------------------
# Main entry point required by the evaluation harness
# ----------------------------------------------------------------------
def custom_kernel(data: Tuple[torch.Tensor, torch.Tensor, Dict[str, torch.Tensor], Dict]) -> torch.Tensor:
    """
    Forward pass for the TriMul “outgoing” operator.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask, weights_dict, config_dict)

    Returns
    -------
    torch.Tensor
        Tensor of shape [B, N, N, dim] (float32, same device as input)
    """
    input_tensor, mask, weights, config = data
    dim        = config["dim"]          # D
    hidden_dim = config["hidden_dim"]  # H

    # ------------------------------------------------------------------
    # 1. LayerNorm on the input (exact same formula as nn.LayerNorm)
    # ------------------------------------------------------------------
    eps = 1e-5
    w_norm = weights["norm.weight"]
    b_norm = weights["norm.bias"]
    mean = input_tensor.mean(-1, keepdim=True)
    var  = input_tensor.var(-1, unbiased=False, keepdim=True)
    x_norm = (input_tensor - mean) * torch.rsqrt(var + eps)
    x_norm = x_norm * w_norm + b_norm          # shape [B,N,N,D]

    # ------------------------------------------------------------------
    # 2. Fuse projections, mask and gates into a Triton kernel
    # ------------------------------------------------------------------
    left, right, out_gate = fuse_pointwise(x_norm, mask, weights)

    # ------------------------------------------------------------------
    # 3. Heavy N³ contraction via batched GEMM
    #    out_h = left_h @ right_h.T   for each hidden channel h
    # ------------------------------------------------------------------
    B, N, _, H = left.shape
    # reshape to (B*H, N, N)
    left_flat  = left.permute(0, 3, 1, 2).reshape(B * H, N, N)   # (B*H, N, N)
    right_flat = right.permute(0, 3, 1, 2).reshape(B * H, N, N)  # (B*H, N, N)

    # batched matrix multiply
    out_flat = torch.bmm(left_flat, right_flat.transpose(1, 2))   # (B*H, N, N)

    # reshape back to [B, N, N, H]
    out = out_flat.view(B, H, N, N).permute(0, 2, 3, 1)           # (B,N,N,H)

    # ------------------------------------------------------------------
    # 4. Output LayerNorm + out‑gate
    # ------------------------------------------------------------------
    w_out_norm = weights["to_out_norm.weight"]
    b_out_norm = weights["to_out_norm.bias"]
    eps_o = 1e-5
    mean_o = out.mean(-1, keepdim=True)
    var_o  = out.var(-1, unbiased=False, keepdim=True)
    out_norm = (out - mean_o) * torch.rsqrt(var_o + eps_o)
    out_norm = out_norm * w_out_norm + b_out_norm

    # apply out_gate (already has shape [B,N,N,H])
    out_norm = out_norm * out_gate

    # ------------------------------------------------------------------
    # 5. Final linear projection back to dim
    # ------------------------------------------------------------------
    w_out = weights["to_out.weight"]                 # (dim, hidden_dim)
    # torch.nn.functional.linear expects weight shape (out_features, in_features)
    output = torch.nn.functional.linear(out_norm, w_out)   # (B,N,N,dim)

    return output.to(torch.float32)
```
