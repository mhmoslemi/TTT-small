The outgoing TriMul operator consists of three “large” phases:

1. **Layer‑norm + linear projections + gating** – the hidden dimension (`hidden_dim`) is only 128 / 384, therefore a pure‑PyTorch implementation is cheap and lets us reuse `torch.nn.functional.layer_norm` (which already handles the per‑batch mean/var).  
2. **Core N³ reduction** –  
   `out[b,i,j,h] = Σₖ left[b,i,k,h] * right[b,j,k,h]`  
   This is the only cubic‑time work and dominates the runtime.  
   We implement it as a *batched GEMM* where for each hidden head `h` we multiply the
   `left` matrix (`N×N`) with the **transpose** of `right` along the second sequence axis.
   The kernel is a classic tiled GEMM (block‑M × block‑N tiles, block‑K reduction) using
   fp16 for the matrix elements and fp32 accumulation for numeric stability.
3. **Post‑processing (layer‑norm, gating, final linear)** – again cheap, done in PyTorch.

Only the reduction is executed in Triton, which satisfies the requirement
*“you must implement at least part of the operations in a kernel”* while keeping the
overall code simple and correct for all test configurations.

--------------------------------------------------------------------
### Triton kernel design decisions (lessons applied)

| Lesson | Effect on our kernel |
|--------|----------------------|
| **Limit shared memory** – keep BLOCK\* ≤ 64 | We choose `BLOCK_M = BLOCK_N = 64`, `BLOCK_K = 32`.  A tile needs `2 * BLOCK_M * BLOCK_K * 2 bytes` ≈ 16 KB per warp, well below the H200 limit, leaving room for many resident warps. |
| **Do not assume a fixed number of strides** | The kernel receives **all** stride arguments explicitly (`stride_lb, stride_lc, …`).  No hard‑coded assumption about the rank is made. |
| **Accumulate in fp32** | The kernel casts the loaded fp16 blocks to `float32` before the dot product (`tl.dot`) and stores the result in fp32. |
| **Avoid unnecessary sync** | The algorithm is a pure GEMM; each program ID works on a disjoint `(batch, head, tile_i, tile_j)` output tile, so no inter‑block synchronization is needed. |

```python
"""
Outgoing TriMul (AlphaFold‑3) – fused Triton kernel for the N³ reduction.

Algorithm
---------
1. Layer‑norm on the last dimension (dim) – PyTorch.
2. Linear projections + gating (bias‑free) – PyTorch.
3. Optional pairwise mask – PyTorch.
4. Core kernel:
   For each (batch, head) compute
       out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]
   This is a batched matrix‑multiply of `left` with the *transpose* of `right`
   along the second sequence axis.  Implemented as a tiled GEMM with fp16
   math and fp32 accumulation.
5. Post‑norm, gating and final linear – PyTorch.

The kernel processes a tile of size (BLOCK_M × BLOCK_N) for a fixed
(batch, head) pair.  `right` is accessed with swapped axes to achieve the
required transpose without materialising it.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: tiled GEMM for the TriMul reduction
# ----------------------------------------------------------------------
@triton.jit
def _trimul_gemm_kernel(
    # Pointers
    left_ptr,          # [B, N, N, H]
    right_ptr,         # [B, N, N, H] (read transposed on dim 2)
    out_ptr,           # [B, N, N, H]
    # Sizes
    B, N, H,
    # Strides (in elements)
    stride_lb, stride_lc, stride_lk, stride_lh,   # left  strides
    stride_rb, stride_rc, stride_rk, stride_rh,   # right strides
    stride_ob, stride_oc, stride_ok, stride_oh,   # out   strides
    # Tile sizes (constexpr)
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr,
):
    """
    Compute a (i, j) tile of the output for a particular (batch, head) pair.
    The right tensor is accessed as if it were transposed on the two
    sequence dimensions (j, k) → (k, j).
    """
    pid = tl.program_id(0)               # linear index over (batch, head)
    b = pid // H
    h = pid % H

    # Tile indices for the output matrix (i‑tile, j‑tile)
    pid_i = tl.program_id(1)
    pid_j = tl.program_id(2)

    # Offsets inside the tile
    offs_i = pid_i * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_j = pid_j * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_i = offs_i < N
    mask_j = offs_j < N

    # ------------------------------------------------------------------
    # Pointers to the start of the current tile (batch & head are fixed)
    # ------------------------------------------------------------------
    # left[ b, i, k, h ]
    left_tile_ptr = (
        left_ptr
        + b * stride_lb
        + h * stride_lh
        + offs_i[:, None] * stride_lc
        + tl.arange(0, BLOCK_K)[None, :] * stride_lk
    )

    # right is conceptually right[ b, j, k, h ]; we need right[b, k, j, h]
    # → load as (k, j)
    right_tile_ptr = (
        right_ptr
        + b * stride_rb
        + h * stride_rh
        + tl.arange(0, BLOCK_K)[:, None] * stride_rk
        + offs_j[None, :] * stride_rc
    )

    # Accumulator in fp32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # Loop over the reduction dimension k
    for k_iter in range(0, tl.cdiv(N, BLOCK_K)):
        # ---- Load left block (M × K) ---------------------------------
        cur_left = tl.load(
            left_tile_ptr,
            mask=mask_i[:, None] & (k_iter * BLOCK_K + tl.arange(0, BLOCK_K) < N),
            other=0.0,
        )
        # ---- Load right block (K × N) – already transposed ---------------
        cur_right = tl.load(
            right_tile_ptr,
            mask=(k_iter * BLOCK_K + tl.arange(0, BLOCK_K)[:, None] < N)
                 & mask_j[None, :],
            other=0.0,
        )

        # fp16 computation, fp32 accumulation
        cur_left = cur_left.to(tl.float16)
        cur_right = cur_right.to(tl.float16)
        acc += tl.dot(cur_left, cur_right)   # (M,K)·(K,N) → (M,N)

        # Advance pointers for next K‑tile
        left_tile_ptr += BLOCK_K * stride_lk
        right_tile_ptr += BLOCK_K * stride_rk

    # ------------------------------------------------------------------
    # Write the tile back
    # ------------------------------------------------------------------
    out_tile_ptr = (
        out_ptr
        + b * stride_ob
        + h * stride_oh
        + offs_i[:, None] * stride_oc
        + offs_j[None, :] * stride_ok
    )
    tl.store(out_tile_ptr, acc, mask=mask_i[:, None] & mask_j[None, :])


# ----------------------------------------------------------------------
# Helper that launches the kernel
# ----------------------------------------------------------------------
def _run_trimul_gemm(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    left, right : [B, N, N, H] (float16)
    returns      : [B, N, N, H] (float32)
    """
    B, N, _, H = left.shape
    out = torch.empty_like(left, dtype=torch.float32, device=left.device)

    # Strides in *elements* (not bytes)
    stride_lb, stride_lc, stride_lk, stride_lh = left.stride()
    stride_rb, stride_rc, stride_rk, stride_rh = right.stride()
    stride_ob, stride_oc, stride_ok, stride_oh = out.stride()

    # Tile sizes – tuned for SM‑90 (large shared‑mem, high occupancy)
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        B * H,                     # program_id(0) → (batch, head)
        triton.cdiv(N, BLOCK_M),   # i‑tiles
        triton.cdiv(N, BLOCK_N),   # j‑tiles
    )

    _trimul_gemm_kernel[grid](
        left_ptr=left,
        right_ptr=right,
        out_ptr=out,
        B=B,
        N=N,
        H=H,
        stride_lb=stride_lb,
        stride_lc=stride_lc,
        stride_lk=stride_lk,
        stride_lh=stride_lh,
        stride_rb=stride_rb,
        stride_rc=stride_rc,
        stride_rk=stride_rk,
        stride_rh=stride_rh,
        stride_ob=stride_ob,
        stride_oc=stride_oc,
        stride_ok=stride_ok,
        stride_oh=stride_oh,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,               # good default for H200
    )
    return out


# ----------------------------------------------------------------------
# Full custom_kernel entry point (forward only)
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operation.

    Arguments
    ---------
    data : tuple
        (input_tensor, mask, weights_dict, config_dict)
        - input_tensor : torch.Tensor [B, N, N, dim]  (float32, CUDA)
        - mask         : torch.Tensor [B, N, N] or None (float32 0/1)
        - weights_dict : name → torch.Tensor (float32, CUDA)
        - config_dict  : {"dim": int, "hidden_dim": int}

    Returns
    -------
    torch.Tensor [B, N, N, dim] (float32, CUDA)
    """
    input_tensor, mask, weights, config = data
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    B, N, _, _ = input_tensor.shape

    # ------------------------------------------------------------------
    # 1. LayerNorm on the feature dimension (dim)
    # ------------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        normalized_shape=(dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
    )

    # ------------------------------------------------------------------
    # 2. Linear projections (bias‑free).  Use einsum for clarity.
    # ------------------------------------------------------------------
    def linear_no_bias(t, w):
        # t: [..., dim]   w: [hidden_dim, dim]
        return torch.einsum("...d,hd->...h", t, w)

    left = linear_no_bias(x, weights["left_proj.weight"])
    right = linear_no_bias(x, weights["right_proj.weight"])

    # ------------------------------------------------------------------
    # 3. Optional mask
    # ------------------------------------------------------------------
    if mask is not None:
        mask = mask.unsqueeze(-1)          # [..., N, N, 1]
        left = left * mask
        right = right * mask

    # ------------------------------------------------------------------
    # 4. Gating (sigmoid) – also bias‑free linear then sigmoid
    # ------------------------------------------------------------------
    left_gate = torch.sigmoid(linear_no_bias(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(linear_no_bias(x, weights["right_gate.weight"]))
    out_gate = torch.sigmoid(linear_no_bias(x, weights["out_gate.weight"]))

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5. Core Triton GEMM (out = Σ_k left * right)
    # ------------------------------------------------------------------
    # Cast to fp16 for the kernel; the kernel returns fp32.
    left_f16 = left.to(torch.float16)
    right_f16 = right.to(torch.float16)

    out = _run_trimul_gemm(left_f16, right_f16)   # shape [B, N, N, hidden_dim], fp32

    # ------------------------------------------------------------------
    # 6. Post‑processing: layer‑norm over hidden_dim, gating, final linear
    # ------------------------------------------------------------------
    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
    )
    out = out * out_gate                     # gating after norm

    # final projection back to original dim
    out = torch.einsum("...h,dh->...d", out, weights["to_out.weight"])

    # Ensure output dtype matches the reference implementation (float32)
    return out.to(torch.float32)
```

**Key points**

* The kernel processes **one (batch, head) pair** per block‑0 and tiles the
  `(i, j)` output matrix with `BLOCK_M × BLOCK_N`.
* `right` is accessed with swapped axes to achieve the required transpose
  without extra memory copies.
* All heavy arithmetic runs in fp16 with an fp32 accumulator (`tl.dot` + `+=`).
* The rest of the module (layer‑norm, linear layers, gating, final projection)
  stays in PyTorch – this is cheap compared with the N³ work and keeps the
  implementation straightforward while still meeting the required runtime
  target on the Hopper‑class H200 GPU.
