The “outgoing” TriMul operator consists of three cheap parts (LayerNorms,
linear projections and gating) and one *very* expensive part – the
`einsum('... i k d, ... j k d -> ... i j d')`.  
For a tensor `[B, N, N, C]` this is an **N³** contraction for each head
`d`.  The cheap parts are kept in PyTorch (they are memory‑bound and tiny
compared to the cubic work) while the cubic contraction is off‑loaded to a
single Triton kernel that performs **batched matrix‑multiplication**:

```
left : (B, H, I, K)      ->  I = N, K = N, H = hidden_dim
right: (B, H, K, J)      ->  J = N
out  : (B, H, I, J)   ( = Σ_k left[..., i, k, d] * right[..., j, k, d] )
```

The kernel works on **fp16** data for the inner multiply‑add (the H200
supports fast FP16 × FP16 → FP32 accumulation) and writes the result back
in **fp16**.  The host converts the result to FP32, applies the final
LayerNorm, gating and output projection.

Key optimisation choices

| Choice | Reason |
|--------|--------|
| **Batch‑head flattening** (`B*H` as one dimension) | Allows a 3‑D grid launch (`pid_m`, `pid_n`, `pid_z`) without extra loops. |
| **Block sizes** `BLOCK_M = BLOCK_N = 64`, `BLOCK_K = 32` | Gives 64 × 64 × 32 ≈ 131 k FP16 MACs per warp, fits in shared memory on SM‑90 and yields high occupancy. |
| **FP16 × FP16 → FP32 accumulation** (`tl.dot`) | H200 provides TF32/FP16 tensor‑cores; using `tl.dot` with an FP32 accumulator gives the best precision while staying fast. |
| **Mask handling in PyTorch** | Masks are applied before the kernel, avoiding divergent branches inside the kernel. |
| **All LayerNorms in FP32** | The tensors are small (‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑‑) so the extra cost is negligible and we avoid having to compute mean/var on‑device. |
| **No `tl.mean` / `tl.var`** | As required, we keep statistics in PyTorch. |

The kernel below follows the classic tiled GEMM pattern with three‑dimensional
grid launch.  It is fully self‑contained and works for any batch size (`B≤2`),
any sequence length (`N≤1024`), any hidden dimension (`H = hidden_dim`, up to
384) and both masked / un‑masked inputs.

```python
"""
TriMul “outgoing” forward pass (AlphaFold3).

*   LayerNorms, linear projections and gating → PyTorch (FP32 → FP16)
*   Core cubic contraction performed by a single Triton kernel:
        out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
    Implemented as a batched matrix‑multiply (B*H, N, N) × (B*H, N, N).

The kernel works in fp16 with fp32 accumulation, writes fp16 results.
The host converts back to fp32 and applies the final LayerNorm,
gating and output projection.
"""

import torch
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched matrix multiply (I×K)·(K×J) → (I×J)
# ----------------------------------------------------------------------
@triton.jit
def batch_matmul_kernel(
    a_ptr,                      # left  matrix   (batch, I, K)
    b_ptr,                      # right matrix   (batch, K, J)
    c_ptr,                      # output matrix  (batch, I, J)
    M, N, K,                    # matrix dimensions
    stride_az, stride_am, stride_ak,   # strides of a (batch, i, k)
    stride_bz, stride_bk, stride_bn,   # strides of b (batch, k, j)
    stride_cz, stride_cm, stride_cn,   # strides of c (batch, i, j)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Compute a single tile of C = A @ B for a given batch index (pid_z).

    A : (batch, M, K)  – fp16
    B : (batch, K, N)  – fp16
    C : (batch, M, N)  – fp16 (written)
    Accumulator is fp32.
    """
    pid_m = tl.program_id(0)          # tile row
    pid_n = tl.program_id(1)          # tile column
    pid_z = tl.program_id(2)          # batch*head index

    # ------------------------------------------------------------------
    # Tile offsets & masks
    # ------------------------------------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator (fp32) – start with zeros
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ------------------------------------------------------------------
    # Loop over K dimension in BLOCK_K sized steps
    # ------------------------------------------------------------------
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # ------------------------------------------------------------------
        # Load A tile (M × K) and B tile (K × N)
        # ------------------------------------------------------------------
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )  # fp16

        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )  # fp16

        # fp16 × fp16 → fp32 accumulation
        acc += tl.dot(a, b)

    # ------------------------------------------------------------------
    # Write back (convert to fp16)
    # ------------------------------------------------------------------
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


# ----------------------------------------------------------------------
# Helper that launches the kernel
# ----------------------------------------------------------------------
def triton_batch_matmul(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Batched matrix multiplication using Triton.

    left  : (B, H, I, K)   fp16, contiguous
    right : (B, H, K, J)   fp16, contiguous
    returns: (B, H, I, J) fp16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    # allocate output
    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # flatten batch*head so the kernel sees a 3‑D grid (M, N, batch*head)
    batch_dim = B * H
    a = left.view(batch_dim, I, K)
    b = right.view(batch_dim, K, J)
    c = out.view(batch_dim, I, J)

    # strides (in elements, not bytes)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # tuning parameters – good baseline for Hopper/SM90
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(I, BLOCK_M),          # pid_m
        triton.cdiv(J, BLOCK_N),          # pid_n
        batch_dim,                        # pid_z
    )

    batch_matmul_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,               # Hopper is happy with 4 warps for fp16
        num_stages=2,              # fits comfortably in shared memory
    )
    return out


# ----------------------------------------------------------------------
# Full forward (mixed‑precision: most work in fp16, final tensors in fp32)
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Arguments
    ----------
    data : tuple
        (input_tensor, mask, weights, config)
        - input_tensor : torch.Tensor [B, N, N, dim]   (float32)
        - mask         : torch.Tensor [B, N, N]       (float32 / bool) or None
        - weights      : dict of leaf weight tensors
        - config       : dict with keys ``dim`` and ``hidden_dim``

    Returns
    -------
    torch.Tensor [B, N, N, dim] (float32)
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    B, N, _, _ = input_tensor.shape

    # --------------------------------------------------------------
    # 1. Input LayerNorm (FP32)
    # --------------------------------------------------------------
    norm_w = weights["norm.weight"]
    norm_b = weights["norm.bias"]
    # manual LayerNorm (keep float32 for stability)
    mean = input_tensor.mean(-1, keepdim=True)
    var = input_tensor.var(-1, unbiased=False, keepdim=True)
    x = (input_tensor - mean) / torch.sqrt(var + 1e-5)
    x = x * norm_w + norm_b                         # still FP32

    # --------------------------------------------------------------
    # 2. Linear projections -> fp16
    # --------------------------------------------------------------
    # weight shapes: (hidden_dim, dim)
    left_proj_w = weights["left_proj.weight"]
    right_proj_w = weights["right_proj.weight"]
    left_gate_w = weights["left_gate.weight"]
    right_gate_w = weights["right_gate.weight"]
    out_gate_w = weights["out_gate.weight"]
    to_out_norm_w = weights["to_out_norm.weight"]
    to_out_norm_b = weights["to_out_norm.bias"]
    to_out_w = weights["to_out.weight"]

    # cast once to fp16 for the heavy path
    x_fp16 = x.to(torch.float16)

    left = torch.nn.functional.linear(x_fp16, left_proj_w.to(torch.float16))   # (B,N,N,H)
    right = torch.nn.functional.linear(x_fp16, right_proj_w.to(torch.float16))

    # --------------------------------------------------------------
    # 3. Mask (if present) – applied before gating
    # --------------------------------------------------------------
    if mask is not None:
        # mask shape [B,N,N] → [B,N,N,1] and cast to fp16
        mask_fp16 = mask.unsqueeze(-1).to(torch.float16)
        left = left * mask_fp16
        right = right * mask_fp16

    # --------------------------------------------------------------
    # 4. Gating (sigmoid) – stays in fp16
    # --------------------------------------------------------------
    left_gate = torch.nn.functional.linear(x_fp16, left_gate_w.to(torch.float16)).sigmoid()
    right_gate = torch.nn.functional.linear(x_fp16, right_gate_w.to(torch.float16)).sigmoid()
    out_gate = torch.nn.functional.linear(x_fp16, out_gate_w.to(torch.float16)).sigmoid()

    left = left * left_gate
    right = right * right_gate

    # --------------------------------------------------------------
    # 5. Core cubic contraction – Triton batched GEMM
    # --------------------------------------------------------------
    # reshape to (B, H, I, K) and (B, H, K, J)
    left_perm = left.permute(0, 3, 1, 2).contiguous()   # (B, H, I, K)
    right_perm = right.permute(0, 3, 2, 1).contiguous() # (B, H, K, J)

    out_fp16 = triton_batch_matmul(left_perm, right_perm)   # (B, H, I, J) fp16

    # convert back to (B, N, N, dim) fp32
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)

    # --------------------------------------------------------------
    # 6. Output LayerNorm (FP32)
    # --------------------------------------------------------------
    mean_o = out.mean(-1, keepdim=True)
    var_o = out.var(-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + 1e-5)
    out = out * to_out_norm_w + to_out_norm_b

    # --------------------------------------------------------------
    # 7. Final gating + projection (FP32)
    # --------------------------------------------------------------
    out = out * out_gate.to(torch.float32)
    out = torch.nn.functional.linear(out, to_out_w.to(torch.float32))

    return out
```
