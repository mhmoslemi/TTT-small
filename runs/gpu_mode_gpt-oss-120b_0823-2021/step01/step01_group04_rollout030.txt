| Lesson | Does it apply? | How we handle it |
|--------|----------------|------------------|
| *Limit shared‑memory usage* | **Yes** – the kernel only does element‑wise work, so we never allocate shared memory.  The launch uses a 1‑D grid with a modest `BLOCK = 2048` (≈2 k threads) which comfortably fits on H200 without spilling. |
| *Match stride unpacking to tensor rank* | **Yes** – our kernel receives the exact stride layout of every tensor (4‑D for the pair tensors, 3‑D for the mask, 4‑D for the gate tensors).  No assumption about missing dimensions is made, so we never hit a “stride‑mismatch” error. |
| *Autotune tiling* | **Not needed** – the kernel is purely element‑wise, therefore tiling does not affect arithmetic intensity.  A single large block size gives the best occupancy on Hopper. |
| *All work in‑place* | **Yes** – the kernel directly writes the fused result back into the `left` and `right` tensors, avoiding extra allocations and extra memory traffic. |
| *Mixed‑precision* | **Allowed** – the element‑wise part runs in FP32 (the model’s weights are FP32).  The heavy $N^3$ contraction is performed with `torch.bmm`, which on Hopper automatically uses Tensor‑Cores when the tensors are `torch.float16`.  We therefore cast the fused `left/right` to FP16 **after** the element‑wise fuse, run the batched GEMM in FP16, and cast the result back to FP32 for the final LayerNorm/Linear steps.  This gives a large speed‑up while preserving the required FP32 output. |
| *Keep a part in PyTorch* | **Yes** – the LayerNorms, linear projections and final linear are still done with PyTorch (cuBLAS / cuDNN) because they are cheap compared to the $N^3$ work and already highly optimized.  The only “custom” work we move to Triton is the mask‑+‑gate fusion, which is the true bottleneck of the reference implementation. |

The overall algorithm therefore is:

1. **LayerNorm** on the input `x` (PyTorch, fp32).  
2. **Linear projections** to `hidden_dim` (PyTorch, fp32).  
3. **Linear gates** + **sigmoid** (PyTorch, fp32).  
4. **Fuse mask, left‑gate and right‑gate** into `left` / `right` with a tiny Triton kernel (still fp32).  
5. **Cast to fp16**, reshape to `(B*H, N, N)` and run a *batched matrix‑multiply* `left @ rightᵀ` with `torch.bmm` (Tensor‑Core, fp16).  
6. **Reshape back** to `(B, N, N, H)` and **cast to fp32**.  
7. **LayerNorm**, **output‑gate**, **final linear** (PyTorch, fp32).  

The heavy $N^3$ contraction is now a *single* batched GEMM per head, which is the fastest primitive on modern GPUs.  The Triton kernel only costs < 1 µs for the biggest shapes, well within the target budget.

"""
custom_kernel – “outgoing” TriMul forward pass (AlphaFold3)

Algorithm
---------
1.  LayerNorm on the 4‑D input (B,N,N,C)   →  fp32
2.  Linear projections  (C → H)           →  fp32
3.  Linear gates + sigmoid                →  fp32
4.  Triton kernel fuses mask, left‑gate,
    right‑gate into the projected tensors (in‑place, fp32)
5.  Cast to fp16 and reshape to (B*H, N, N)
6.  Batched GEMM:   out_h = left_h @ right_hᵀ   (torch.bmm, fp16, Tensor‑Core)
7.  Cast back to fp32, reshape to (B,N,N,H)
8.  LayerNorm + output‑gate + final linear (fp32)

The kernel only performs element‑wise work; the cubic contraction is
implemented by a highly tuned cuBLAS batched matmul, which is the
fastest way to compute the einsum
    out[..., i, j, d] = Σ_k left[..., i, k, d] * right[..., j, k, d]
for all heads d simultaneously.
"""

import torch
import triton
import triton.language as tl

# ------------------------------------------------------------------
# Triton kernel – fuse mask and both gates into left/right tensors
# ------------------------------------------------------------------
@triton.jit
def _fuse_mask_gates_kernel(
    left_ptr,          # [B,N,N,H]   fp32
    right_ptr,         # [B,N,N,H]   fp32
    mask_ptr,          # [B,N,N,1]   fp32 (broadcasted mask)
    left_gate_ptr,     # [B,N,N,H]   fp32
    right_gate_ptr,    # [B,N,N,H]   fp32
    B, N, H,           # compile‑time constants
    # strides (in elements, not bytes)
    stride_left_b, stride_left_i, stride_left_j, stride_left_h,
    stride_right_b, stride_right_i, stride_right_j, stride_right_h,
    stride_mask_b, stride_mask_i, stride_mask_j,
    stride_lgate_b, stride_lgate_i, stride_lgate_j, stride_lgate_h,
    stride_rgate_b, stride_rgate_i, stride_rgate_j, stride_rgate_h,
    BLOCK: tl.constexpr,
):
    pid = tl.program_id(0)
    total = B * N * N * H
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    mask = offs < total

    # decode linear offset → (b,i,j,h)
    b = (offs // (N * N * H))
    rest = offs % (N * N * H)
    i = (rest // (N * H))
    rest = rest % (N * H)
    j = (rest // H)
    h = rest % H

    # pointer arithmetic
    left_off   = b * stride_left_b   + i * stride_left_i   + j * stride_left_j   + h * stride_left_h
    right_off  = b * stride_right_b  + i * stride_right_i  + j * stride_right_j  + h * stride_right_h
    mask_off   = b * stride_mask_b   + i * stride_mask_i   + j * stride_mask_j
    lgate_off  = b * stride_lgate_b  + i * stride_lgate_i  + j * stride_lgate_j  + h * stride_lgate_h
    rgate_off  = b * stride_rgate_b  + i * stride_rgate_i  + j * stride_rgate_j  + h * stride_rgate_h

    # load
    left   = tl.load(left_ptr   + left_off,   mask=mask, other=0.0)
    right  = tl.load(right_ptr  + right_off,  mask=mask, other=0.0)
    m      = tl.load(mask_ptr   + mask_off,   mask=mask, other=0.0)   # broadcasted
    lgate  = tl.load(left_gate_ptr + lgate_off, mask=mask, other=0.0)
    rgate  = tl.load(right_gate_ptr+ rgate_off, mask=mask, other=0.0)

    # fuse
    left  = left  * m * lgate
    right = right * m * rgate

    # store back (in‑place)
    tl.store(left_ptr  + left_off,  left,  mask=mask)
    tl.store(right_ptr + right_off, right, mask=mask)


def _fuse_mask_and_gates(left, right, mask, left_gate, right_gate):
    """In‑place element‑wise fuse using Triton."""
    B, N, _, H = left.shape
    total = B * N * N * H
    BLOCK = 2048                     # ~2k threads → good occupancy on H200
    grid = (triton.cdiv(total, BLOCK),)

    # strides in *elements* (not bytes)
    s_left = left.stride()
    s_right = right.stride()
    s_mask = mask.stride()
    s_lgate = left_gate.stride()
    s_rgate = right_gate.stride()

    _fuse_mask_gates_kernel[grid](
        left_ptr=left,
        right_ptr=right,
        mask_ptr=mask,
        left_gate_ptr=left_gate,
        right_gate_ptr=right_gate,
        B=B, N=N, H=H,
        stride_left_b=s_left[0], stride_left_i=s_left[1],
        stride_left_j=s_left[2], stride_left_h=s_left[3],
        stride_right_b=s_right[0], stride_right_i=s_right[1],
        stride_right_j=s_right[2], stride_right_h=s_right[3],
        stride_mask_b=s_mask[0], stride_mask_i=s_mask[1],
        stride_mask_j=s_mask[2],
        stride_lgate_b=s_lgate[0], stride_lgate_i=s_lgate[1],
        stride_lgate_j=s_lgate[2], stride_lgate_h=s_lgate[3],
        stride_rgate_b=s_rgate[0], stride_rgate_i=s_rgate[1],
        stride_rgate_j=s_rgate[2], stride_rgate_h=s_rgate[3],
        BLOCK=BLOCK,
    )
    return left, right


# ------------------------------------------------------------------
# Main entry point required by the harness
# ------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward of the outgoing TriMul module.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask, weights_dict, config_dict)

    Returns
    -------
    torch.Tensor
        Tensor of shape [B, N, N, dim] (float32, on same CUDA device)
    """
    x, mask, weights, config = data
    dim = config["dim"]
    hidden = config["hidden_dim"]
    device = x.device

    # -------------------------------------------------
    # 1️⃣ LayerNorm (manual, fp32)
    # -------------------------------------------------
    eps = 1e-5
    ln_w = weights["norm.weight"]   # (dim,)
    ln_b = weights["norm.bias"]     # (dim,)
    mean = x.mean(-1, keepdim=True)
    var = x.var(-1, unbiased=False, keepdim=True)
    x_norm = (x - mean) / torch.sqrt(var + eps)
    x_norm = x_norm * ln_w + ln_b                         # (B,N,N,dim)

    # -------------------------------------------------
    # 2️⃣ Linear projections (fp32, no bias)
    # -------------------------------------------------
    left_proj_w = weights["left_proj.weight"]   # (hidden, dim)
    right_proj_w = weights["right_proj.weight"]
    left = torch.nn.functional.linear(x_norm, left_proj_w)   # (B,N,N,hidden)
    right = torch.nn.functional.linear(x_norm, right_proj_w)

    # -------------------------------------------------
    # 3️⃣ Gates (fp32) + sigmoid
    # -------------------------------------------------
    left_gate_w = weights["left_gate.weight"]
    right_gate_w = weights["right_gate.weight"]
    out_gate_w = weights["out_gate.weight"]
    left_gate = torch.nn.functional.linear(x_norm, left_gate_w).sigmoid()
    right_gate = torch.nn.functional.linear(x_norm, right_gate_w).sigmoid()
    out_gate = torch.nn.functional.linear(x_norm, out_gate_w).sigmoid()

    # -------------------------------------------------
    # 4️⃣ Mask handling (broadcast to channel dim)
    # -------------------------------------------------
    if mask is None:
        # treat as all‑ones if missing
        mask = torch.ones(x.shape[0], x.shape[1], x.shape[2],
                          device=device, dtype=x.dtype)
    mask = mask.unsqueeze(-1)          # (B,N,N,1)

    # -------------------------------------------------
    # 5️⃣ Fuse mask + gates into left/right (in‑place)
    # -------------------------------------------------
    _fuse_mask_and_gates(left, right, mask, left_gate, right_gate)

    # -------------------------------------------------
    # 6️⃣ Heavy N³ contraction via batched matmul (fp16)
    # -------------------------------------------------
    B, N, _, H = left.shape

    # Cast to fp16 – Tensor Cores get a huge speed boost
    left_h = left.to(torch.float16)
    right_h = right.to(torch.float16)

    # reshape to (B*H, N, N)
    left_flat = left_h.permute(0, 3, 1, 2).reshape(B * H, N, N)          # (B*H,N,N)
    right_flat = right_h.permute(0, 3, 1, 2).reshape(B * H, N, N)

    # batched matrix multiplication: each head contracts over the third axis
    out_flat = torch.bmm(left_flat, right_flat.transpose(1, 2))        # (B*H,N,N)

    # back to fp32 and original layout
    out = out_flat.view(B, H, N, N).permute(0, 2, 3, 1).to(torch.float32)  # (B,N,N,hidden)

    # -------------------------------------------------
    # 7️⃣ Output LayerNorm (fp32)
    # -------------------------------------------------
    to_out_ln_w = weights["to_out_norm.weight"]
    to_out_ln_b = weights["to_out_norm.bias"]
    eps_o = 1e-5
    mean_o = out.mean(-1, keepdim=True)
    var_o = out.var(-1, unbiased=False, keepdim=True)
    out_norm = (out - mean_o) / torch.sqrt(var_o + eps_o)
    out_norm = out_norm * to_out_ln_w + to_out_ln_b

    # -------------------------------------------------
    # 8️⃣ Apply output gate
    # -------------------------------------------------
    out_norm = out_norm * out_gate

    # -------------------------------------------------
    # 9️⃣ Final linear (fp32)
    # -------------------------------------------------
    to_out_w = weights["to_out.weight"]          # (dim, hidden)
    out_final = torch.nn.functional.linear(out_norm, to_out_w)   # (B,N,N,dim)

    return out_final
