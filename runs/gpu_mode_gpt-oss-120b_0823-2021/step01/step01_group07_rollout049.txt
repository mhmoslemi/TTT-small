*Algorithm*  
1. **Layer‑norm** over the last dimension (`dim`). – cheap, done in PyTorch.  
2. **Linear projections** (`left_proj`, `right_proj`) and **gates** (`left_gate`,
   `right_gate`, `out_gate`). All are bias‑free, so they are simple `einsum`
   operations – also done in PyTorch.  
3. Optional **pair‑wise mask** is applied on the projected tensors.  
4. **Core O(N³) reduction**  

\[
\text{out}_{b,i,j,h}= \sum_{k=0}^{N-1}
        \text{left}_{b,i,k,h}\;\times\;
        \text{right}_{b,j,k,h}
\]

   This is a batched matrix‑multiply of `left[b,…,h]` (`N×N`) with the **transpose**
   of `right[b,…,h]` along the second sequence axis.  
   We implement it as a tiled GEMM in Triton:
   * tile‑sizes `BLOCK_M × BLOCK_N` (output i‑j tile) and reduction tile `BLOCK_K`.
   * each program processes a single `(batch, head)` pair (`b,h`).
   * `left` is read as‑is, `right` is read with swapped axes `j,k` → the kernel
     treats it as already transposed.
   * FP16 arithmetic for the dot, accumulation in FP32 (better numerical
     stability, still fast on Hopper).
5. **Post‑processing** – layer‑norm over `hidden_dim`, gate (`out_gate`), final
   linear projection back to `dim`. All done in PyTorch.

The kernel is deliberately simple and fits well in the shared‑memory budget of
SM‑90 (H200).  The launch grid is `(B*H, ceil(N/BLOCK_M), ceil(N/BLOCK_N))`
so each `program_id(0)` handles one `(batch, head)` pair, while
`program_id(1)`/`program_id(2)` tile the `i`/`j` dimensions.

```python
"""
TriMul “outgoing” forward pass (AlphaFold‑3 style).

The heavy O(N³) reduction is executed in a fused Triton GEMM kernel.
All other ops (layer‑norm, linear projections, gating) stay in PyTorch
to keep the implementation short and numerically stable.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl

# ----------------------------------------------------------------------
# Triton kernel: batched GEMM for left × rightᵀ
# ----------------------------------------------------------------------
@triton.jit
def trimul_gemm_kernel(
    # pointers
    left_ptr,    # [B, N, N, H]  (fp16)
    right_ptr,   # [B, N, N, H]  (fp16) – will be accessed transposed on axis 2
    out_ptr,     # [B, N, N, H]  (fp32)
    # sizes
    B, N, H,
    # strides (in elements, not bytes)
    stride_lb, stride_lc, stride_lk, stride_lh,   # left  strides (b, i, k, h)
    stride_rb, stride_rc, stride_rk, stride_rh,   # right strides (b, j, k, h)
    stride_ob, stride_oc, stride_ok, stride_oh,   # out   strides (b, i, j, h)
    # tile sizes
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr,
):
    """
    Compute a tile of out_{b,i,j,h} = Σ_k left_{b,i,k,h} * right_{b,j,k,h}
    where `right` is logically transposed on its second sequence axis.
    """

    pid0 = tl.program_id(0)              # linear index over (batch, head)
    b = pid0 // H
    h = pid0 % H

    pid_m = tl.program_id(1)              # tile row (i)
    pid_n = tl.program_id(2)              # tile col (j)

    # offsets for the i/j tiles
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < N
    mask_n = offs_n < N

    # base pointers for the current (b,h) pair
    left_base  = left_ptr + b * stride_lb + h * stride_lh
    right_base = right_ptr + b * stride_rb + h * stride_rh

    # pointers that will be stepped in the K‑loop
    # left:   (i, k)   → stride_c for i, stride_k for k
    # right:  (k, j)   → we treat right as transposed, so stride_k for k,
    #                       stride_c for j
    left_tile_ptr  = left_base + offs_m[:, None] * stride_lc \
                                 + tl.arange(0, BLOCK_K)[None, :] * stride_lk
    right_tile_ptr = right_base + tl.arange(0, BLOCK_K)[:, None] * stride_rk \
                                  + offs_n[None, :] * stride_rc

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # loop over K dimension
    for k in range(0, tl.cdiv(N, BLOCK_K)):
        cur_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        valid_k = cur_k < N

        # Load left block (M×K)
        left = tl.load(left_tile_ptr,
                       mask=mask_m[:, None] & valid_k[None, :],
                       other=0.0)

        # Load right block (K×N) – already transposed
        right = tl.load(right_tile_ptr,
                        mask=valid_k[:, None] & mask_n[None, :],
                        other=0.0)

        # FP16 dot, accumulate in FP32
        acc += tl.dot(left.to(tl.float16), right.to(tl.float16))

        # advance K‑pointers
        left_tile_ptr  += BLOCK_K * stride_lk
        right_tile_ptr += BLOCK_K * stride_rk

    # store result (still FP32)
    out_tile_ptr = out_ptr + b * stride_ob + h * stride_oh \
                                 + offs_m[:, None] * stride_oc \
                                 + offs_n[None, :] * stride_ok
    tl.store(out_tile_ptr, acc,
             mask=mask_m[:, None] & mask_n[None, :])

# ----------------------------------------------------------------------
# Helper that launches the kernel
# ----------------------------------------------------------------------
def trimul_gemm(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    left, right : [B, N, N, H]   (fp16)
    returns      : [B, N, N, H]   (fp32)
    """
    assert left.is_cuda and right.is_cuda
    B, N, _, H = left.shape

    out = torch.empty_like(left, dtype=torch.float32, device=left.device)

    # element‑wise strides (not bytes)
    stride_lb, stride_lc, stride_lk, stride_lh = left.stride()
    stride_rb, stride_rc, stride_rk, stride_rh = right.stride()
    stride_ob, stride_oc, stride_ok, stride_oh = out.stride()

    # Tile sizes – tuned for Hopper SM90 shared‑memory budget
    BLOCK_M = 64   # i‑direction
    BLOCK_N = 64   # j‑direction
    BLOCK_K = 32   # reduction

    grid = (
        B * H,                     # program_id(0) → (batch, head)
        triton.cdiv(N, BLOCK_M),  # i‑tiles
        triton.cdiv(N, BLOCK_N),  # j‑tiles
    )

    trimul_gemm_kernel[grid](
        left_ptr=left,
        right_ptr=right,
        out_ptr=out,
        B=B, N=N, H=H,
        stride_lb=stride_lb, stride_lc=stride_lc,
        stride_lk=stride_lk, stride_lh=stride_lh,
        stride_rb=stride_rb, stride_rc=stride_rc,
        stride_rk=stride_rk, stride_rh=stride_rh,
        stride_ob=stride_ob, stride_oc=stride_oc,
        stride_ok=stride_ok, stride_oh=stride_oh,
        BLOCK_M=BLOCK_M, BLOCK_N=BLOCK_N, BLOCK_K=BLOCK_K,
        num_warps=4,               # good default for fp16 GEMM on SM90
    )
    return out

# ----------------------------------------------------------------------
# Full custom kernel entry point
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Args
    ----
    data : tuple
        (input_tensor, mask, weights_dict, config_dict)
        - input_tensor : torch.Tensor [B, N, N, dim]  (float32, CUDA)
        - mask         : torch.Tensor [B, N, N] or None (float32 0/1)
        - weights_dict : mapping name → torch.Tensor (float32)
        - config_dict  : {"dim": int, "hidden_dim": int}
    Returns
    -------
    torch.Tensor [B, N, N, dim] (float32, CUDA)
    """
    input_tensor, mask, weights, config = data
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    B, N, _, _ = input_tensor.shape

    # ------------------------------------------------------------------
    # 1. Input LayerNorm over `dim`
    # ------------------------------------------------------------------
    norm_weight = weights["norm.weight"]
    norm_bias   = weights["norm.bias"]
    x = F.layer_norm(input_tensor,
                     normalized_shape=(dim,),
                     weight=norm_weight,
                     bias=norm_bias)

    # ------------------------------------------------------------------
    # 2. Linear projections (bias‑free)
    # ------------------------------------------------------------------
    # project: (..., dim) @ (hidden_dim, dim).T  → (..., hidden_dim)
    def linear_no_bias(tensor, w):
        # w shape: (hidden_dim, dim)
        return torch.einsum('...d,hd->...h', tensor, w)

    left  = linear_no_bias(x, weights["left_proj.weight"])
    right = linear_no_bias(x, weights["right_proj.weight"])

    # ------------------------------------------------------------------
    # 3. Optional mask
    # ------------------------------------------------------------------
    if mask is not None:
        mask = mask.unsqueeze(-1)          # (..., N, N, 1)
        left = left * mask
        right = right * mask

    # ------------------------------------------------------------------
    # 4. Gating (sigmoid)
    # ------------------------------------------------------------------
    left_gate  = torch.sigmoid(linear_no_bias(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(linear_no_bias(x, weights["right_gate.weight"]))
    out_gate   = torch.sigmoid(linear_no_bias(x, weights["out_gate.weight"]))

    left  = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5. Core Triton reduction: out_{b,i,j,h} = Σ_k left_{b,i,k,h} * right_{b,j,k,h}
    # ------------------------------------------------------------------
    left_f16  = left.to(torch.float16)
    right_f16 = right.to(torch.float16)

    out = trimul_gemm(left_f16, right_f16)          # (B, N, N, H) fp32

    # ------------------------------------------------------------------
    # 6. Post‑processing: layer‑norm over hidden_dim, gate, final linear
    # ------------------------------------------------------------------
    out = F.layer_norm(out,
                       normalized_shape=(hidden_dim,),
                       weight=weights["to_out_norm.weight"],
                       bias=weights["to_out_norm.bias"])

    out = out * out_gate                           # gating after norm

    # final projection back to original dim
    out = torch.einsum('...h,dh->...d', out, weights["to_out.weight"])

    return out.to(torch.float32)
```

**Explanation of the lessons & choices**

| Lesson | Relevance & Action |
|--------|--------------------|
| *Limit shared memory* | Tile sizes `64×64×32` keep the per‑SM shared‑memory usage ≈ 16 KB (fp16) → well below the H200 limit, leaving room for occupancy. |
| *Match stride unpacking* | Strides are taken directly from `tensor.stride()` for all four dimensions; no hard‑coded assumptions. |
| *Do not copy whole kernel verbatim* | The kernel is written from scratch (same pattern as classic GEMM but adapted for the transposed `right`). |
| *Keep most ops in PyTorch* | Layer‑norm, linear projections, and gating are cheap relative to the 𝑂(N³) work; keeping them in PyTorch avoids unnecessary complexity and ensures numerical stability. |
| *Mixed‑precision* | Input to the kernel is cast to `float16` for speed; accumulation is in `float32` and the final output stays `float32`. |

The implementation satisfies all constraints, runs fully on CUDA with a
Triton kernel for the dominant reduction, and returns a tensor of shape
`[B, N, N, dim]` in `float32`.
