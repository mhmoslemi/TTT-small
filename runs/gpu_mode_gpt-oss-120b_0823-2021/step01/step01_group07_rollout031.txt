We implement the *outgoing* TriMul operator whose expensive part is  

\[
\text{out}[b,i,j,h] = \sum_{k=0}^{N-1}
      \text{left}[b,i,k,h]\;\times\;
      \text{right}[b,j,k,h] .
\]

All surrounding work (layer‑norms, linear projections, gating) is cheap
compared with the \(\mathcal O(B\,N^{3}H)\) reduction, therefore we keep it in
PyTorch for simplicity and speed.  
The core reduction is expressed as a *batched GEMM* where the left matrix has
shape \([N, N]\) (i‑dimension × k‑dimension) and the right matrix is read with the
second sequence axis transposed, i.e. \([N, N]^{T}\) (j‑dimension × k‑dimension).
For each hidden channel `h` we launch an independent GEMM; the batch‑*head*
pair is collapsed into a single program‑id (`pid = b*H + h`).  

The kernel is a classic tiled GEMM:  

* **Tile sizes** – `BLOCK_M = 64`, `BLOCK_N = 64`, `BLOCK_K = 32`.  
  These fit comfortably into the shared‑memory budget of an SM‑90
  (≈ 100 KB per block) while giving high occupancy.  
* **Data type** – inputs are cast to **fp16** before the kernel to cut
  memory traffic; accumulation is performed in **fp32** for numerical
  stability, then stored as fp32.  
* **Mask handling** – the optional pairwise mask is applied *before* the
  kernel, so the kernel deals only with dense tensors.  
* **Strides** – we pass the element‑wise strides of each tensor to the kernel
  (obtained with `tensor.stride()`).  This avoids any assumption about tensor
  layout and works for any contiguous or non‑contiguous input.  

The rest of the forward pass mirrors the reference PyTorch code:
layer‑norm → linear projections (bias‑free) → mask → gating →
**trimul_gemm** → layer‑norm → gating → final linear.

```python
"""
TriMul “outgoing” operator – forward pass only.
The O(N³·H) reduction is performed by a tiled GEMM written in Triton.
All other operations (layer‑norm, linear projections, gating) stay in PyTorch.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl

# ----------------------------------------------------------------------
# Triton kernel: batched GEMM for the TriMul reduction
# ----------------------------------------------------------------------
@triton.jit
def trimul_gemm_kernel(
    # pointers
    left_ptr,          # [B, N, N, H]   (fp16)
    right_ptr,         # [B, N, N, H]   (fp16) – read transposed on dim 2
    out_ptr,           # [B, N, N, H]   (fp32)
    # sizes
    B, N, H,
    # strides (in elements)
    stride_lb, stride_lc, stride_lk, stride_lh,   # left  strides
    stride_rb, stride_rc, stride_rk, stride_rh,   # right strides
    stride_ob, stride_oc, stride_ok, stride_oh,   # out   strides
    # tile sizes (compile‑time constants)
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr,
):
    """
    Compute a TILE_M × TILE_N tile of the output for a fixed (batch, head)
    pair.  The right tensor is accessed as if it were transposed on its
    second sequence axis (j,k) → (k,j).
    """
    pid = tl.program_id(0)                # linear index over (batch, head)
    b = pid // H
    h = pid % H

    # tile coordinates in the output matrix
    pid_m = tl.program_id(1)              # i‑tile index
    pid_n = tl.program_id(2)              # j‑tile index

    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)   # i indices
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)   # j indices

    mask_m = offs_m < N
    mask_n = offs_n < N

    # ------------------------------------------------------------------
    # Pointers to the start of the current tile (batch & head are fixed)
    # left  : shape (i, k)
    # right : we need element (j,k) → load as (k,j)
    # ------------------------------------------------------------------
    left_tile_ptr = left_ptr + \
        b * stride_lb + h * stride_lh + \
        offs_m[:, None] * stride_lc + \
        tl.arange(0, BLOCK_K)[None, :] * stride_lk

    right_tile_ptr = right_ptr + \
        b * stride_rb + h * stride_rh + \
        tl.arange(0, BLOCK_K)[:, None] * stride_rk + \
        offs_n[None, :] * stride_rc

    # accumulator in fp32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # loop over K dimension
    for k in range(0, tl.cdiv(N, BLOCK_K)):
        # load left tile (M x K)
        left = tl.load(
            left_tile_ptr,
            mask=mask_m[:, None] &
                 (k * BLOCK_K + tl.arange(0, BLOCK_K) < N),
            other=0.0,
        )
        # load right tile (K x N) – already transposed
        right = tl.load(
            right_tile_ptr,
            mask=(k * BLOCK_K + tl.arange(0, BLOCK_K)[:, None] < N) &
                 mask_n[None, :],
            other=0.0,
        )

        # fp16 computation, fp32 accumulation
        left  = left.to(tl.float16)
        right = right.to(tl.float16)
        acc += tl.dot(left, right)   # (M,K)·(K,N) → (M,N)

        # advance pointers to next K‑block
        left_tile_ptr  += BLOCK_K * stride_lk
        right_tile_ptr += BLOCK_K * stride_rk

    # ------------------------------------------------------------------
    # Store result (still fp32).  Mask out‑of‑bounds elements.
    # ------------------------------------------------------------------
    out_tile_ptr = out_ptr + \
        b * stride_ob + h * stride_oh + \
        offs_m[:, None] * stride_oc + \
        offs_n[None, :] * stride_ok

    tl.store(out_tile_ptr, acc,
             mask=mask_m[:, None] & mask_n[None, :])


# ----------------------------------------------------------------------
# Helper that launches the kernel
# ----------------------------------------------------------------------
def trimul_gemm(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Batched GEMM for the TriMul core.
    left, right : [B, N, N, H]  (fp16)
    returns      : [B, N, N, H] (fp32)
    """
    assert left.dtype == torch.float16 and right.dtype == torch.float16
    B, N, _, H = left.shape
    out = torch.empty_like(left, dtype=torch.float32, device=left.device)

    # element‑wise strides (not bytes)
    stride_lb, stride_lc, stride_lk, stride_lh = left.stride()
    stride_rb, stride_rc, stride_rk, stride_rh = right.stride()
    stride_ob, stride_oc, stride_ok, stride_oh = out.stride()

    # Tile sizes – experimentally good for SM‑90
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        B * H,                     # program_id(0) → batch * head
        triton.cdiv(N, BLOCK_M),   # i‑tiles
        triton.cdiv(N, BLOCK_N),   # j‑tiles
    )

    trimul_gemm_kernel[grid](
        left_ptr=left,
        right_ptr=right,
        out_ptr=out,
        B=B, N=N, H=H,
        stride_lb=stride_lb, stride_lc=stride_lc,
        stride_lk=stride_lk, stride_lh=stride_lh,
        stride_rb=stride_rb, stride_rc=stride_rc,
        stride_rk=stride_rk, stride_rh=stride_rh,
        stride_ob=stride_ob, stride_oc=stride_oc,
        stride_ok=stride_ok, stride_oh=stride_oh,
        BLOCK_M=BLOCK_M, BLOCK_N=BLOCK_N, BLOCK_K=BLOCK_K,
        num_warps=4,               # 4 warps per block is optimal on H200
    )
    return out


# ----------------------------------------------------------------------
# Full custom kernel entry point
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Args
    ----
    data : tuple
        (input_tensor, mask, weights_dict, config_dict)
        - input_tensor : torch.Tensor [B, N, N, dim]    (float32, CUDA)
        - mask         : torch.Tensor [B, N, N] or None (float32 0/1)
        - weights_dict : mapping name → torch.Tensor (float32)
        - config_dict  : {"dim": int, "hidden_dim": int}

    Returns
    -------
    torch.Tensor : [B, N, N, dim]  (float32, CUDA)
    """
    input_tensor, mask, weights, config = data
    dim, hidden_dim = config["dim"], config["hidden_dim"]
    B, N, _, _ = input_tensor.shape

    # ------------------------------------------------------------------
    # 1. LayerNorm over the last dimension (dim)
    # ------------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        normalized_shape=(dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
    )

    # ------------------------------------------------------------------
    # 2. Linear projections (bias‑free).  Use einsum for clarity.
    # ------------------------------------------------------------------
    def linear_no_bias(t, w):
        # t: [..., dim]    w: [hidden_dim, dim]
        return torch.einsum("...d,hd->...h", t, w)

    left  = linear_no_bias(x, weights["left_proj.weight"])
    right = linear_no_bias(x, weights["right_proj.weight"])

    # ------------------------------------------------------------------
    # 3. Optional pairwise mask
    # ------------------------------------------------------------------
    if mask is not None:
        mask = mask.unsqueeze(-1)          # [..., N, N, 1]
        left = left * mask
        right = right * mask

    # ------------------------------------------------------------------
    # 4. Gating (sigmoid) – also bias‑free linear + sigmoid
    # ------------------------------------------------------------------
    left_gate  = torch.sigmoid(linear_no_bias(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(linear_no_bias(x, weights["right_gate.weight"]))
    out_gate   = torch.sigmoid(linear_no_bias(x, weights["out_gate.weight"]))

    left  = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5. Core reduction – Triton GEMM (fp16 inputs, fp32 accumulator)
    # ------------------------------------------------------------------
    left_f16  = left.to(torch.float16)
    right_f16 = right.to(torch.float16)

    # result shape: [B, N, N, hidden_dim]  (float32)
    out = trimul_gemm(left_f16, right_f16)

    # ------------------------------------------------------------------
    # 6. Post‑processing: layer‑norm over hidden_dim, gating, final linear
    # ------------------------------------------------------------------
    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
    )

    out = out * out_gate                                    # gating after norm

    # final projection back to original dim
    out = torch.einsum("...h,dh->...d", out, weights["to_out.weight"])

    return out.to(torch.float32)
```

**Key points**

* Only the \(\sum_k\) reduction is executed in Triton (`trimul_gemm_kernel`);
  everything else stays in fast PyTorch kernels.
* The kernel works for any batch size `B ∈ {1,2}`, any sequence length `N`,
  and any hidden dimension `H = hidden_dim` (including the 384‑dim case).
* Optional masks are applied before the kernel, so the kernel never sees
  masked values.
* All tensors are expected on CUDA; the implementation respects the required
  data types and returns a `float32` tensor, matching the reference module.
