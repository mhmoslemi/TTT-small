We implement the **outgoing** version of the TriMul operator from AlphaFold‑3.  
Only the heavy **einsum**  

```
out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
```

needs to be accelerated – everything else (LayerNorms, linear layers, gating,
masking, final projection) is cheap enough to stay in PyTorch.

The einsum is a *batched matrix‑multiply* for every hidden‑dimension channel
`d`:

```
left  : (B, N, N, H) → (B, H, N, K)   (permute 0,3,1,2)
right : (B, N, N, H) → (B, H, K, N)   (permute 0,3,2,1)
out   : (B, H, N, N)
```

So we need a kernel that computes many independent matrix products
`(N × K) · (K × N) → (N × N)` in a single launch.  
We fuse the **K‑loop** inside the kernel, keep the accumulator in **fp32**
(to preserve numerical quality) and write the result in **fp16**; the host
converts it back to **fp32** for the final LayerNorm / projection.

The kernel follows the classic “blocked GEMM” pattern used in the Triton
documentation, but we add a third grid dimension (`pid_z`) that folds the
batch * hidden‑dim dimension (`B*H`).  
All strides are passed from the host, so the kernel works for arbitrary
contiguity/layout (the tensors are made contiguous before launching).

**Why this is fast**

* **Large tiles** – `BLOCK_M = BLOCK_N = 64`, `BLOCK_K = 32`. On Hopper each tile
  fits into a single warp’s registers and shared‑memory usage stays < 64 KB,
  allowing `num_warps=8`.
* **Mixed‑precision accumulation** – multiplies are done in fp16, the
  accumulation is in fp32, giving the same accuracy as the reference code but
  the throughput of fp16 tensor cores.
* **One‑shot launch** – a single kernel processes all `B*H` products, removing
  kernel‑launch overhead.
* **Mask handling** – the mask is applied *before* the kernel in fp16, so no
  extra work inside the kernel.

The full forward pass is wrapped in `custom_kernel`.  
All tensors are kept on the same device; the only data movement is the final
`fp16 → fp32` cast.

```python
"""
custom_kernel – outgoing TriMul (AlphaFold‑3)

* LayerNorm + linear projections are performed in PyTorch (float32 → fp16).
* The core N³ einsum is rewritten as a batched matrix‑multiply and executed
  with a single Triton kernel (fp16 mul, fp32 accumulation).
* Final LayerNorm, gating and output projection are done in PyTorch.
* Supports optional mask (broadcasted on the last dimension).
"""

import torch
import triton
import triton.language as tl
from torch.nn import functional as F


# ----------------------------------------------------------------------
# Triton kernel: batched GEMM (I×K)·(K×J) → (I×J) for many (batch,head) pairs
# ----------------------------------------------------------------------
@triton.jit
def batch_gemm_kernel(
    a_ptr,  # left  matrix, shape (B*H, I, K)
    b_ptr,  # right matrix, shape (B*H, K, J)
    c_ptr,  # output matrix, shape (B*H, I, J)
    M, N, K,
    stride_az, stride_am, stride_ak,   # a strides (batch, i, k)
    stride_bz, stride_bk, stride_bn,   # b strides (batch, k, j)
    stride_cz, stride_cm, stride_cn,   # c strides (batch, i, j)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    # --------------------------------------------------------------
    # 1. Tile identifiers
    # --------------------------------------------------------------
    pid_m = tl.program_id(0)          # tile along M (rows)
    pid_n = tl.program_id(1)          # tile along N (cols)
    pid_z = tl.program_id(2)          # combined batch*head index

    # --------------------------------------------------------------
    # 2. Compute offsets for this tile
    # --------------------------------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # --------------------------------------------------------------
    # 3. Accumulator (fp32 for precision)
    # --------------------------------------------------------------
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # 4. Loop over K dimension in blocks
    # --------------------------------------------------------------
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # Load a tile of A
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # Load a tile of B
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # fp16 dot → fp32 accumulation
        acc += tl.dot(a, b)

    # --------------------------------------------------------------
    # 5. Write back (convert to fp16 to save bandwidth)
    # --------------------------------------------------------------
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


# ----------------------------------------------------------------------
# Helper that launches the kernel
# ----------------------------------------------------------------------
def triton_batched_gemm(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    left  : (B, H, I, K)   fp16, contiguous
    right : (B, H, K, J)   fp16, contiguous
    returns (B, H, I, J)   fp16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    # allocate output
    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # flatten batch*head for the kernel
    batch = B * H
    a = left.view(batch, I, K)
    b = right.view(batch, K, J)
    c = out.view(batch, I, J)

    # strides (in elements)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # Tile sizes – tuned for Hopper (SM90)
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(I, BLOCK_M),
        triton.cdiv(J, BLOCK_N),
        batch,
    )
    batch_gemm_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=8,          # 8 warps ≈ 256 threads → good occupancy on H200
    )
    return out


# ----------------------------------------------------------------------
# Full forward: PyTorch for cheap ops, Triton for the N³ core
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask, weights, config)
        - input_tensor : torch.Tensor [B, N, N, dim] (float32)
        - mask         : torch.Tensor [B, N, N] (float32/bool) or None
        - weights      : dict of leaf weight tensors
        - config       : dict with keys “dim” and “hidden_dim”

    Returns
    -------
    torch.Tensor [B, N, N, dim] (float32)
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]

    # ------------------------------------------------------------------
    # 1. Input LayerNorm (same as nn.LayerNorm)
    # ------------------------------------------------------------------
    ln_w = weights["norm.weight"]
    ln_b = weights["norm.bias"]
    # compute mean / var along last dimension (dim)
    mean = input_tensor.mean(-1, keepdim=True)
    var = input_tensor.var(-1, unbiased=False, keepdim=True)
    x = (input_tensor - mean) / torch.sqrt(var + 1e-5)
    x = x * ln_w + ln_b   # shape [B,N,N,dim]  (float32)

    # ------------------------------------------------------------------
    # 2. Linear projections (dim -> hidden_dim)
    #    Convert to fp16 before the heavy part
    # ------------------------------------------------------------------
    # weight shapes: (hidden_dim, dim)
    left_proj_w = weights["left_proj.weight"]
    right_proj_w = weights["right_proj.weight"]
    left_gate_w = weights["left_gate.weight"]
    right_gate_w = weights["right_gate.weight"]
    out_gate_w  = weights["out_gate.weight"]
    to_out_norm_w = weights["to_out_norm.weight"]
    to_out_norm_b = weights["to_out_norm.bias"]
    to_out_w = weights["to_out.weight"]

    # Cast once
    x_fp16 = x.to(torch.float16)

    left = F.linear(x_fp16, left_proj_w.to(torch.float16))    # [B,N,N,hidden]
    right = F.linear(x_fp16, right_proj_w.to(torch.float16))

    # ------------------------------------------------------------------
    # 3. Mask (if supplied)
    # ------------------------------------------------------------------
    if mask is not None:
        # mask may be bool or float; we need shape [B,N,N,1]
        mask_f = mask.to(torch.float16).unsqueeze(-1)
        left = left * mask_f
        right = right * mask_f

    # ------------------------------------------------------------------
    # 4. Gating (sigmoid)
    # ------------------------------------------------------------------
    left_gate = F.linear(x_fp16, left_gate_w.to(torch.float16)).sigmoid()
    right_gate = F.linear(x_fp16, right_gate_w.to(torch.float16)).sigmoid()
    out_gate = F.linear(x_fp16, out_gate_w.to(torch.float16)).sigmoid()

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5. Prepare tensors for the batched GEMM
    # ------------------------------------------------------------------
    # left  : [B,N,N,hidden] → (B, H, I, K)   where I=K=N, H=hidden_dim
    # right : [B,N,N,hidden] → (B, H, K, J)   where J=N
    left_perm = left.permute(0, 3, 1, 2).contiguous()   # (B, H, I, K)
    right_perm = right.permute(0, 3, 2, 1).contiguous() # (B, H, K, J)

    # ------------------------------------------------------------------
    # 6. Triton batched GEMM  (N³ part)
    # ------------------------------------------------------------------
    out_fp16 = triton_batched_gemm(left_perm, right_perm)   # (B, H, I, J)

    # ------------------------------------------------------------------
    # 7. Bring back to original layout and type
    # ------------------------------------------------------------------
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)   # (B,N,N,dim)

    # ------------------------------------------------------------------
    # 8. Output LayerNorm (to_out_norm)
    # ------------------------------------------------------------------
    mean_o = out.mean(-1, keepdim=True)
    var_o = out.var(-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + 1e-5)
    out = out * to_out_norm_w + to_out_norm_b

    # ------------------------------------------------------------------
    # 9. Final gating & projection
    # ------------------------------------------------------------------
    out = out * out_gate.to(torch.float32)
    out = F.linear(out, to_out_w.to(torch.float32))

    return out
```

**Key points**

* The kernel respects all Triton constraints (`tl.constexpr`, no Python loops,
  proper masks).
* All strides are supplied from the host, guaranteeing correct addressing for any
  contiguous layout.
* Memory usage per kernel launch stays well below the H200 limits, enabling
  `num_warps=8` and full tensor‑core utilization.
* The final tensor is returned in **float32**, matching the reference
  implementation.
