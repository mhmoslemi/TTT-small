We implement the *outgoing* TriMul operator exactly as described in the AlphaFold‑3 paper, but we move the **cubic‑cost** tensor contraction  

\[
\text{out}[b,i,j,d]=\sum_{k=0}^{N-1}
      \bigl(\text{left}[b,i,k,d]\odot\text{left\_gate}[b,i,k,d]\bigr)\;
      \bigl(\text{right}[b,j,k,d]\odot\text{right\_gate}[b,j,k,d]\bigr)
\]

into a high‑performance Triton kernel.  
All cheap per‑element work (LayerNorm, linear layers, gating, final LayerNorm,
final linear projection) stays in PyTorch‑torch‑compile friendly code.

The kernel works on **tiles of the (i, j) output plane** for a **single hidden
dimension `h`** (the “hidden_dim” from the model).  For each tile we iterate
over the `k` dimension in blocks, loading a *M×K* tile of `left` and a *K×N*
tile of the **transpose** of `right`.  The multiplication is performed in
FP32‑accumulate while the inputs/outputs are stored in FP16, which gives the
best HW utilization on Hopper (SM‑90) and matches the original AlphaFold‑3
implementation.

Key design choices  

| Decision | Reason |
|----------|--------|
| **Data layout `B,H,N,N` (batch, hidden, i, j)** | Allows a single kernel launch per `(b,h)` tile and removes the costly transpose of `right` inside Python. |
| **Tile sizes `BM=64, BN=64, BK=32`** | Fit comfortably in shared memory on H200 (≈ 64 KB) and give high occupancy. |
| **FP16 storage, FP32 accumulation** | Maximises memory bandwidth while keeping numerical accuracy. |
| **Mask handling inside the kernel** | When a mask is provided we multiply it into `left` and `right` before the kernel.  The kernel therefore only sees dense tensors. |
| **Launch grid = B × H × ceil(N/BM) × ceil(N/BN)** | One program id per output tile; simple 1‑D grid for Triton. |
| **Avoid `tl.mean` / extra synchronisations** | Triton has no built‑in mean; we compute the mean/variance for LayerNorm in PyTorch where it is cheap. |

The final pipeline is

```
x                = LayerNorm(x)                         # (B,N,N,D)
left  = Linear(x, left_proj)   * mask * sigmoid(Linear(x,left_gate))
right = Linear(x, right_proj)  * mask * sigmoid(Linear(x,right_gate))

# reshape → (B,H,N,N), cast to fp16
left_fp16  = left.permute(0,3,1,2).contiguous().to(torch.float16)
right_fp16 = right.permute(0,3,1,2).contiguous().to(torch.float16)

# Triton kernel: out_fp16[b,h,i,j] = Σ_k left_fp16[b,h,i,k] * right_fp16[b,h,j,k]
out_fp16 = torch.empty_like(left_fp16)
trimul_kernel[grid](
    left_fp16, right_fp16, out_fp16,
    B, N, H,
    *left_fp16.stride(),
    *right_fp16.stride(),
    *out_fp16.stride(),
    BLOCK_M=BM, BLOCK_N=BN, BLOCK_K=BK
)

# back to (B,N,N,H) → (B,N,N,D) → final LayerNorm & Linear
out = out_fp16.to(torch.float32).permute(0,2,3,1).contiguous()
out = LayerNorm(out) * out_gate
out = Linear(out, to_out)                                   # (B,N,N,D)
```

```python
"""
TriMul “outgoing” kernel (AlphaFold‑3).

The heavy N³ contraction is performed by a tiled Triton kernel that
computes for each (batch, hidden) pair:

    out[b,h,i,j] = Σ_k left[b,h,i,k] * right[b,h,j,k]

The kernel works on FP16 tensors with FP32 accumulation, using tile sizes
BM=64, BN=64, BK=32 which fit the H200 shared‑memory budget.
All surrounding LayerNorm / Linear / gating operations stay in PyTorch.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict, Any


# -------------------------------------------------------------------------
# Triton kernel: batched matmul for each hidden dimension
# -------------------------------------------------------------------------
@triton.jit
def trimul_kernel(
    left_ptr,            # *const fp16  [B, H, N, N]
    right_ptr,           # *const fp16  [B, H, N, N]
    out_ptr,             # *mut   fp16  [B, H, N, N]
    B, N, H,             # sizes (int32)
    stride_lb, stride_lh, stride_li, stride_lk,   # left strides
    stride_rb, stride_rh, stride_rj, stride_rk,   # right strides (j,k order)
    stride_ob, stride_oh, stride_oi, stride_ok,   # out strides
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Compute one output tile (BM×BN) for a given (batch, hidden) pair.
    The right tensor is accessed transposed, i.e. we read right[b,h,j,k]
    as (K × N) where K is the reduction axis.
    """
    pid = tl.program_id(0)

    # decode linear pid → (b, h, block_i, block_j)
    num_blocks_m = tl.cdiv(N, BLOCK_M)
    num_blocks_n = tl.cdiv(N, BLOCK_N)

    block_j = pid % num_blocks_n
    pid = pid // num_blocks_n
    block_i = pid % num_blocks_m
    pid = pid // num_blocks_m
    h = pid % H
    b = pid // H

    # tile offsets
    offs_i = block_i * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_j = block_j * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_i = offs_i < N
    mask_j = offs_j < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # loop over K dimension in blocks
    for kk in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = kk * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # left[b,h,i,k]   → shape (M, K)
        left_off = (
            b * stride_lb
            + h * stride_lh
            + offs_i[:, None] * stride_li
            + offs_k[None, :] * stride_lk
        )
        left = tl.load(left_ptr + left_off,
                       mask=mask_i[:, None] & mask_k[None, :],
                       other=0.0).to(tl.float32)

        # right[b,h,j,k]  → we need its transpose (k, j)
        # right layout is (B, H, N, N) with strides (rb, rh, rj, rk)
        # to get (k, j) we index (offs_k, offs_j)
        right_off = (
            b * stride_rb
            + h * stride_rh
            + offs_k[:, None] * stride_rk
            + offs_j[None, :] * stride_rj
        )
        right_t = tl.load(right_ptr + right_off,
                          mask=mask_k[:, None] & mask_j[None, :],
                          other=0.0).to(tl.float32)

        # accumulate dot product over K
        acc += tl.dot(left, right_t)   # (M,K) @ (K,N) → (M,N)

    # write back FP16
    out_off = (
        b * stride_ob
        + h * stride_oh
        + offs_i[:, None] * stride_oi
        + offs_j[None, :] * stride_ok
    )
    tl.store(out_ptr + out_off,
             acc.to(tl.float16),
             mask=mask_i[:, None] & mask_j[None, :])

# -------------------------------------------------------------------------
# Host‑side wrapper
# -------------------------------------------------------------------------
def custom_kernel(data: Tuple[torch.Tensor,
                               torch.Tensor,
                               Dict[str, torch.Tensor],
                               Dict[str, Any]]) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.
    The expensive N³ contraction is performed by `trimul_kernel`.
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dtype = torch.float32

    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]

    # ---------------------------------------------------------------
    # 1. LayerNorm + linear projections (PyTorch)
    # ---------------------------------------------------------------
    # LayerNorm
    norm_weight = weights["norm.weight"].to(dtype)
    norm_bias   = weights["norm.bias"].to(dtype)
    x = F.layer_norm(input_tensor,
                     normalized_shape=(dim,),
                     weight=norm_weight,
                     bias=norm_bias)

    # Linear projections (no bias)
    left_proj_w  = weights["left_proj.weight"].to(dtype)   # (hidden, dim)
    right_proj_w = weights["right_proj.weight"].to(dtype)

    left = F.linear(x, left_proj_w)    # (B,N,N,hidden)
    right = F.linear(x, right_proj_w)

    # ---------------------------------------------------------------
    # 2. Mask (optional)
    # ---------------------------------------------------------------
    if mask is not None:
        mask3 = mask.unsqueeze(-1)               # (B,N,N,1)
        left = left * mask3
        right = right * mask3

    # ---------------------------------------------------------------
    # 3. Gating
    # ---------------------------------------------------------------
    left_gate_w  = weights["left_gate.weight"].to(dtype)
    right_gate_w = weights["right_gate.weight"].to(dtype)
    out_gate_w   = weights["out_gate.weight"].to(dtype)

    left_gate  = torch.sigmoid(F.linear(x, left_gate_w))
    right_gate = torch.sigmoid(F.linear(x, right_gate_w))
    out_gate   = torch.sigmoid(F.linear(x, out_gate_w))

    left  = left * left_gate
    right = right * right_gate

    # ---------------------------------------------------------------
    # 4. Rearrange to (B, H, N, N) and cast to fp16 for the kernel
    # ---------------------------------------------------------------
    # (B,N,N,H) -> (B,H,N,N)
    left = left.permute(0, 3, 1, 2).contiguous()
    right = right.permute(0, 3, 1, 2).contiguous()
    left_fp16 = left.to(torch.float16)
    right_fp16 = right.to(torch.float16)

    # output buffer
    out_fp16 = torch.empty_like(left_fp16, dtype=torch.float16)

    # ---------------------------------------------------------------
    # 5. Launch Triton kernel
    # ---------------------------------------------------------------
    BM = 64
    BN = 64
    BK = 32

    # grid: one program per (b, h, tile_i, tile_j)
    grid_m = triton.cdiv(N, BM)
    grid_n = triton.cdiv(N, BN)
    total_programs = B * hidden_dim * grid_m * grid_n
    grid = (total_programs,)

    # strides in element order (B, H, N, N)
    stride_lb, stride_lh, stride_li, stride_lk = left_fp16.stride()
    stride_rb, stride_rh, stride_rj, stride_rk = right_fp16.stride()
    stride_ob, stride_oh, stride_oi, stride_ok = out_fp16.stride()

    trimul_kernel[grid](
        left_fp16,
        right_fp16,
        out_fp16,
        B, N, hidden_dim,
        stride_lb, stride_lh, stride_li, stride_lk,
        stride_rb, stride_rh, stride_rj, stride_rk,
        stride_ob, stride_oh, stride_oi, stride_ok,
        BLOCK_M=BM, BLOCK_N=BN, BLOCK_K=BK,
    )

    # ---------------------------------------------------------------
    # 6. Back‑to `(B,N,N,hidden)` and finish in PyTorch
    # ---------------------------------------------------------------
    out = out_fp16.to(dtype).permute(0, 2, 3, 1).contiguous()   # (B,N,N,hidden)

    # to_out_norm
    to_out_norm_w = weights["to_out_norm.weight"].to(dtype)
    to_out_norm_b = weights["to_out_norm.bias"].to(dtype)
    out = F.layer_norm(out,
                       normalized_shape=(hidden_dim,),
                       weight=to_out_norm_w,
                       bias=to_out_norm_b)

    # multiply by out gate (broadcast on N,N)
    out = out * out_gate

    # final linear back to dim
    to_out_w = weights["to_out.weight"].to(dtype)   # (dim, hidden)
    out = F.linear(out, to_out_w)

    return out
```

**Why this implementation is fast**

* The kernel does the full `N³` work and nothing else, so memory traffic is
  limited to three tensors of size `B·H·N·N` (≈ 2 × FP16 reads + 1 × FP16 write).
* Tile sizes are chosen to keep shared‑memory usage < 64 KB per SM, allowing
  the Hopper scheduler to keep many warps resident.
* Using `tl.dot` on `BLOCK_M×BLOCK_K` and `BLOCK_K×BLOCK_N` tiles exploits the
  matrix‑multiply units directly.
* All layer‑norm / linear / sigmoid operations stay in PyTorch where they are
  heavily optimized and benefit from `torch.compile` fusion.

The function `custom_kernel` follows the exact signature required by the
evaluation harness and returns a float‑32 tensor of shape `[B, N, N, dim]`.
