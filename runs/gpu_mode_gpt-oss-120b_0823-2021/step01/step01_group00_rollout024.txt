The “outgoing” TriMul operator can be split into three stages  

1. **Cheap per‑element work** – LayerNorm, three linear projections, three
   sigmoids and the mask/gating logic.  
   These operations are cheap compared to the O(N³) contraction, therefore we keep
   them in native PyTorch (fp32 → fp16 conversion is done once).

2. **Heavy contraction**  

```
out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]          (d = hidden_dim)
```

   For each head `d` the contraction is exactly a batched matrix‑multiply  
   ` (I,N)·(N,J) → (I,J)`.  By reshaping the tensors to **(B·D, I, K)** and
   **(B·D, K, J)** we can compute *all* heads of a batch in a single Triton
   launch.

3. **Post‑processing** – LayerNorm, gating and final linear projection, also kept in
   PyTorch.

The only part that really needs Triton is the batched matrix‑multiply.  
The kernel below follows the classic “tiling‑over‑M,N,K” pattern, but we add a few
optimisations that matter on Hopper / H200:

* **fp16 × fp16 → fp32 accumulation** – hardware‑supported `tl.dot` works in fp32,
  giving full precision for the N‑sum while keeping the arithmetic density of
  fp16.
* **Block sizes** – `BLOCK_M = BLOCK_N = 64` and `BLOCK_K = 32` give good occupancy
  on SM‑90 and keep shared‑memory usage < 48 KB per block (well below the 64 KB
  limit of H200).
* **4 warps per block** – matches the compute density of fp16 dot on Hopper.
* **Mask handling** – bounds‑check masks are generated once per tile; there is
  no need for a separate mask tensor inside the kernel.

The rest of the code mirrors the reference implementation, but all linear
weights are stored in fp16 to avoid unnecessary conversions, and the final
output is cast back to fp32.

The remaining runtime bottleneck (the N³ contraction) is now fully accelerated,

"""
TriMul “outgoing” forward pass (AlphaFold3) with Triton‑accelerated batched
matrix multiplication.

The heavy contraction
    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
is implemented as a fused batched GEMM in fp16 (accumulating in fp32).
All other ops (LayerNorm, linear layers, gating) stay in PyTorch.
"""
import torch
import triton
import triton.language as tl
from torch.nn import functional as F


# ----------------------------------------------------------------------
# Triton kernel: batched matmul (I×K)·(K×J) → (I×J) for many (batch, head) pairs
# ----------------------------------------------------------------------
@triton.jit
def batched_matmul_kernel(
    a_ptr,  # left  matrix, shape (Z, I, K)
    b_ptr,  # right matrix, shape (Z, K, J)
    c_ptr,  # output,       shape (Z, I, J)
    M, N, K,                 # matrix sizes
    stride_az, stride_am, stride_ak,   # strides for a (z,i,k)
    stride_bz, stride_bk, stride_bn,   # strides for b (z,k,j)
    stride_cz, stride_cm, stride_cn,   # strides for c (z,i,j)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    pid_z = tl.program_id(2)            # batch*head index
    pid_m = tl.program_id(0)            # tile along M (rows)
    pid_n = tl.program_id(1)            # tile along N (cols)

    # Offsets for the current tile
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in fp32 (high‑precision sum)
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # Loop over K dimension in blocks
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # Load a tile of A: (BLOCK_M, BLOCK_K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # Load a tile of B: (BLOCK_K, BLOCK_N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # fp16×fp16 → fp32 dot product
        acc += tl.dot(a, b)

    # Write back (convert to fp16 to keep memory bandwidth low)
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


# ----------------------------------------------------------------------
# Helper that launches the batched GEMM
# ----------------------------------------------------------------------
def triton_batched_gemm(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    left  : (B, H, I, K)  fp16, contiguous
    right : (B, H, K, J)  fp16, contiguous
    returns (B, H, I, J)  fp16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # Collapse batch*head dimension for the kernel
    Z = B * H
    a = left.reshape(Z, I, K)
    b = right.reshape(Z, K, J)
    c = out.reshape(Z, I, J)

    # Strides in element units (not bytes)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # Tiling parameters – tuned for Hopper/SM90
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(I, BLOCK_M),       # tiles along rows
        triton.cdiv(J, BLOCK_N),       # tiles along cols
        Z,                             # batch*head
    )
    batched_matmul_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,          # good default for fp16 on H200
        num_stages=2,         # limits shared‑memory usage
    )
    return out


# ----------------------------------------------------------------------
# Full forward pass – mix of PyTorch and Triton
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the “outgoing” TriMul module.

    Arguments
    ----------
    data : tuple (input, mask, weights, config)
        input   : torch.Tensor, shape (B, N, N, dim), dtype float32
        mask    : torch.Tensor, shape (B, N, N) or None, dtype float32/bool
        weights : dict with the following leaf tensors (all float32):
                  norm.weight, norm.bias,
                  left_proj.weight, right_proj.weight,
                  left_gate.weight, right_gate.weight, out_gate.weight,
                  to_out_norm.weight, to_out_norm.bias,
                  to_out.weight
        config  : dict with keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor of shape (B, N, N, dim), dtype float32
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    B, N, _, _ = input_tensor.shape

    # ------------------------------------------------------------------
    # 1) Input LayerNorm (float32, same as nn.LayerNorm)
    # ------------------------------------------------------------------
    norm_weight = weights["norm.weight"]
    norm_bias = weights["norm.bias"]
    # manual LayerNorm for speed – reduce over last dim
    mean = input_tensor.mean(dim=-1, keepdim=True)
    var = input_tensor.var(dim=-1, unbiased=False, keepdim=True)
    x = (input_tensor - mean) / torch.sqrt(var + 1e-5)
    x = x * norm_weight + norm_bias

    # ------------------------------------------------------------------
    # 2) Linear projections + mask + gating (keep in fp16)
    # ------------------------------------------------------------------
    # Cast to fp16 once
    x_fp16 = x.to(torch.float16)

    # Linear projection weights (hidden_dim, dim) – cast to fp16
    left_proj_w = weights["left_proj.weight"].to(torch.float16)
    right_proj_w = weights["right_proj.weight"].to(torch.float16)
    left_gate_w = weights["left_gate.weight"].to(torch.float16)
    right_gate_w = weights["right_gate.weight"].to(torch.float16)
    out_gate_w = weights["out_gate.weight"].to(torch.float16)

    left = F.linear(x_fp16, left_proj_w)    # (B,N,N,hidden_dim)
    right = F.linear(x_fp16, right_proj_w)

    if mask is not None:
        # mask: (B,N,N) → (B,N,N,1)
        mask_fp16 = mask.unsqueeze(-1).to(torch.float16)
        left = left * mask_fp16
        right = right * mask_fp16

    # Gating (sigmoid in fp16)
    left_gate = torch.sigmoid(F.linear(x_fp16, left_gate_w))
    right_gate = torch.sigmoid(F.linear(x_fp16, right_gate_w))
    out_gate = torch.sigmoid(F.linear(x_fp16, out_gate_w))

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 3) Heavy contraction with Triton
    #    left : (B,N,N,hidden) -> (B, H, I, K)
    #    right: (B,N,N,hidden) -> (B, H, K, J)
    # ------------------------------------------------------------------
    left_perm = left.permute(0, 3, 1, 2).contiguous()   # (B, H, I, K)
    right_perm = right.permute(0, 3, 2, 1).contiguous() # (B, H, K, J)

    out_fp16 = triton_batched_gemm(left_perm, right_perm)  # (B, H, I, J)

    # Back to (B,N,N,dim) and to fp32 for the rest of the pipeline
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)

    # ------------------------------------------------------------------
    # 4) Output LayerNorm (float32)
    # ------------------------------------------------------------------
    to_out_norm_w = weights["to_out_norm.weight"]
    to_out_norm_b = weights["to_out_norm.bias"]
    mean_o = out.mean(dim=-1, keepdim=True)
    var_o = out.var(dim=-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + 1e-5)
    out = out * to_out_norm_w + to_out_norm_b

    # ------------------------------------------------------------------
    # 5) Final gating + linear projection (float32)
    # ------------------------------------------------------------------
    out = out * out_gate.to(torch.float32)   # broadcast over dim
    to_out_w = weights["to_out.weight"].to(torch.float32)
    out = F.linear(out, to_out_w)

    return out
