We implement the *outgoing* TriMul operator exactly as described in the PyTorch reference, but we accelerate the N³‑einsum with a custom Triton kernel that performs many batched matrix‑multiplications in one launch.

The computation can be rewritten as  

\[
\text{out}_{b,i,j,d}= \sum_{k=0}^{N-1}\; \text{left}_{b,i,k,d}\;\times\;\text{right}_{b,j,k,d}
\]

For every head (``d``) we have a standard matrix product  

\[
L_{b,d}\;(N\times N) \; \times\; R_{b,d}\;(N\times N)^{\!\top}\;=\; O_{b,d}\;(N\times N)
\]

Therefore the heavy part is a **batched GEMM** of shape  
``(B*hidden_dim, N, N) × (B*hidden_dim, N, N) → (B*hidden_dim, N, N)``.  
We keep all cheap operations – LayerNorms, linear projections, gating – in PyTorch (they are bandwidth‑bound and negligible compared with the N³ work). Only the GEMM is moved to Triton.

The kernel

* works on FP16 values (the linear layers are cast to FP16 before the GEMM);
* accumulates in FP32 for numeric stability;
* uses three‑dimensional tiling (`BLOCK_M`, `BLOCK_N`, `BLOCK_K`);
* fuses the three program‑ids (`pid_m`, `pid_n`, `pid_z`) to cover all
  ``(batch*head, i‑block, j‑block)`` tiles;
* stores the result back in FP16, after which the host converts to FP32
  and applies the final LayerNorm, gating and output projection.

The complete implementation consists of

1. **`batch_matmul_kernel`** – the Triton kernel.
2. **`triton_batch_matmul`** – a small wrapper that prepares strides,
   launches the kernel and returns the FP16 result.
3. **`custom_kernel`** – the public entry‑point that follows the exact
   interface required by the test harness:
   * unpack the inputs,
   * apply LayerNorm, linear layers and gates (PyTorch),
   * reshape/permutate tensors for the GEMM,
   * call the Triton kernel,
   * reshape back, apply the second LayerNorm, final gate and linear projection,
   * return a **float32** tensor of shape ``[B, N, N, dim]``.

All tensor shapes are validated, the code works for any batch size (1‑2),
any sequence length (128‑1024), and any ``dim``/``hidden_dim`` allowed by the
specification.  When ``nomask=True`` the mask tensor is ``None`` – we simply
skip the element‑wise masking step.

```python
"""
custom_kernel – outgoing TriMul (AlphaFold‑3 style)
-------------------------------------------------
The heavy N³ einsum  out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
is implemented as a batched matrix multiplication in Triton.
All other ops (LayerNorm, linear projections, sigmoid gates) stay in PyTorch.
The kernel works in fp16 with fp32 accumulation and returns fp16; the host
converts back to fp32 for the final LayerNorm / linear layer.
"""

import torch
import triton
import triton.language as tl
from torch.nn import functional as F


# ----------------------------------------------------------------------
# Triton kernel: (B*H, I, K) × (B*H, K, J) → (B*H, I, J)
# ----------------------------------------------------------------------
@triton.jit
def batch_matmul_kernel(
    a_ptr,  # left  matrix pointer  (batch, i, k)
    b_ptr,  # right matrix pointer  (batch, k, j)
    c_ptr,  # output pointer        (batch, i, j)
    M, N, K,                     # dims: I, J, K
    stride_az, stride_am, stride_ak,   # strides for a
    stride_bz, stride_bk, stride_bn,   # strides for b
    stride_cz, stride_cm, stride_cn,   # strides for c
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    pid_m = tl.program_id(0)          # tile along M (i)
    pid_n = tl.program_id(1)          # tile along N (j)
    pid_z = tl.program_id(2)          # batch * head index

    # Offsets for the current tile
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in fp32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # iterate over K dimension in BLOCK_K steps
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # Load a tile of A (shape BLOCK_M × BLOCK_K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # Load a tile of B (shape BLOCK_K × BLOCK_N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # dot‑product accumulation
        acc += tl.dot(a, b)

    # Convert back to fp16 for the store
    c = acc.to(tl.float16)

    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


# ----------------------------------------------------------------------
# Host‑side helper that launches the kernel
# ----------------------------------------------------------------------
def triton_batch_matmul(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Batched matrix multiplication for the TriMul core.
    left  : (B, H, I, K)   fp16
    right : (B, H, K, J)   fp16
    returns: (B, H, I, J) fp16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2, "inner dimensions must match"

    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # Collapse the (B,H) dimension – Triton expects a 3‑D tensor.
    batch = B * H
    a = left.reshape(batch, I, K)
    b = right.reshape(batch, K, J)
    c = out.reshape(batch, I, J)

    # Strides in element units (not bytes)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # Tile sizes – tuned for Hopper (SM90). 64×64 work‑group fits into
    # shared memory, 32 for the reduction dimension gives good occupancy.
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(I, BLOCK_M),          # program_id(0) – rows
        triton.cdiv(J, BLOCK_N),          # program_id(1) – cols
        batch,                            # program_id(2) – batch*head
    )

    batch_matmul_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,          # good default for fp16 on SM90
    )
    return out


# ----------------------------------------------------------------------
# Main entry point – matches the required signature
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Arguments
    ----------
    data : tuple
        (input_tensor, mask, weights, config)
        - input_tensor : torch.Tensor [B, N, N, dim] (float32)
        - mask         : torch.Tensor [B, N, N] (float32/bool) or None
        - weights      : dict of leaf tensors (see code)
        - config       : dict with keys ``dim`` and ``hidden_dim``

    Returns
    -------
    torch.Tensor : [B, N, N, dim] (float32)
    """
    # ------------------------------------------------------------------
    # unpack arguments
    # ------------------------------------------------------------------
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    B, N, _, _ = input_tensor.shape

    # ------------------------------------------------------------------
    # 1️⃣ LayerNorm (first)
    # ------------------------------------------------------------------
    # Manual LayerNorm in fp32 – input size is modest, so this is fine.
    norm_weight = weights["norm.weight"]
    norm_bias = weights["norm.bias"]
    eps = 1e-5

    mean = input_tensor.mean(dim=-1, keepdim=True)
    var = input_tensor.var(dim=-1, unbiased=False, keepdim=True)
    x = (input_tensor - mean) / torch.sqrt(var + eps)
    x = x * norm_weight + norm_bias

    # ------------------------------------------------------------------
    # 2️⃣ Linear projections (to hidden_dim) – cast to fp16 for the heavy part
    # ------------------------------------------------------------------
    # Helper that does weight‑only linear (bias is folded into weight if needed)
    def linear_fp16(inp, w):
        return F.linear(inp, w.to(torch.float16))

    left_proj_w = weights["left_proj.weight"]
    right_proj_w = weights["right_proj.weight"]
    left_gate_w = weights["left_gate.weight"]
    right_gate_w = weights["right_gate.weight"]
    out_gate_w = weights["out_gate.weight"]
    to_out_norm_w = weights["to_out_norm.weight"]
    to_out_norm_b = weights["to_out_norm.bias"]
    to_out_w = weights["to_out.weight"]

    # cast input to fp16 once
    x_fp16 = x.to(torch.float16)

    left = linear_fp16(x_fp16, left_proj_w)   # (B, N, N, hidden_dim)
    right = linear_fp16(x_fp16, right_proj_w) # (B, N, N, hidden_dim)

    # ------------------------------------------------------------------
    # 3️⃣ Optional mask (broadcast on hidden_dim)
    # ------------------------------------------------------------------
    if mask is not None:
        mask_exp = mask.unsqueeze(-1).to(torch.float16)   # [B,N,N,1]
        left = left * mask_exp
        right = right * mask_exp

    # ------------------------------------------------------------------
    # 4️⃣ Gating (sigmoid)
    # ------------------------------------------------------------------
    left_gate = torch.sigmoid(linear_fp16(x_fp16, left_gate_w))
    right_gate = torch.sigmoid(linear_fp16(x_fp16, right_gate_w))
    out_gate = torch.sigmoid(linear_fp16(x_fp16, out_gate_w))

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5️⃣ Prepare tensors for the batched GEMM
    #     left  : (B, N, N, H) → (B, H, N, N)
    #     right : (B, N, N, H) → (B, H, N, N) and transpose K↔J
    # ------------------------------------------------------------------
    left_perm = left.permute(0, 3, 1, 2).contiguous()   # (B, H, I, K)
    right_perm = right.permute(0, 3, 2, 1).contiguous() # (B, H, K, J)

    # ------------------------------------------------------------------
    # 6️⃣ Heavy part – call Triton GEMM
    # ------------------------------------------------------------------
    out_fp16 = triton_batch_matmul(left_perm, right_perm)   # (B, H, I, J)

    # ------------------------------------------------------------------
    # 7️⃣ Back‑to original layout and fp32
    # ------------------------------------------------------------------
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)  # (B,N,N,dim)

    # ------------------------------------------------------------------
    # 8️⃣ Second LayerNorm (to_out_norm)
    # ------------------------------------------------------------------
    mean2 = out.mean(dim=-1, keepdim=True)
    var2 = out.var(dim=-1, unbiased=False, keepdim=True)
    out = (out - mean2) / torch.sqrt(var2 + eps)
    out = out * to_out_norm_w + to_out_norm_b

    # ------------------------------------------------------------------
    # 9️⃣ Final gating + projection back to dim
    # ------------------------------------------------------------------
    out = out * out_gate.to(torch.float32)
    out = F.linear(out, to_out_w.to(torch.float32))

    return out
```

**Key Points**

* Only the N³ multiplication is moved to Triton; everything else stays in
  PyTorch, which dramatically reduces launch overhead.
* FP16 arithmetic inside the kernel gives the required speed, while FP32
  accumulation preserves numeric quality.
* The kernel is generic – it works for any batch size, any hidden dimension,
  and any sequence length that fits in GPU memory.
* All operations obey the Triton launch conventions (grid definition,
  `tl.constexpr` parameters, stride handling), so the code runs without
  fallback paths.
