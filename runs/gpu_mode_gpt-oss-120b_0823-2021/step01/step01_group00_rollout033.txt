The “outgoing” TriMul operator consists of three cheap parts (LayerNorm, linear
projections, and gating) and one expensive part – the triple‑sum

\[
\text{out}_{b,i,j,d}= \sum_{k=0}^{N-1}
    \text{left}_{b,i,k,d}\;\text{right}_{b,j,k,d}.
\]

For a fixed batch `b` and hidden dimension `d` this is exactly a matrix‑multiply

```
left  : (N, N)   -> (I, K)
right : (N, N)   -> (K, J)   with I = J = N
out   : (I, J)
```

All hidden dimensions share the same `N×N` matrix size, therefore we can treat
the whole block as a **batched GEMM** of shape  
`(B·H, N, N) × (B·H, N, N) → (B·H, N, N)` where `H = hidden_dim`.

The kernel below computes many such GEMMs in a single launch.  
Key design points:

* **Mixed‑precision inner loop** – inputs are cast to `float16`, the
  accumulation is done in `float32` (the “tensor‑core‐friendly” pattern) and the
  result is stored as `float16`.  The surrounding PyTorch code converts the
  result back to `float32` for the final LayerNorm / linear projection.
* **Tiling** – the kernel tiles the `M` (rows) and `N` (cols) dimensions with
  `BLOCK_M = BLOCK_N = 64` and the reduction (`K`) dimension with
  `BLOCK_K = 32`.  These values are a good fit for Hopper (SM‑90) and keep the
  shared‑memory usage below the limit.
* **Batch‑head dimension flattening** – we fuse the batch `B` and hidden
  dimension `H` into one leading dimension `Z = B·H`.  Each program instance
  (`program_id(2)`) works on one `(Z, :, :)` matrix pair, eliminating an extra
  grid dimension and letting the scheduler keep the warps busy.
* **Mask handling** – the mask is applied *before* the Triton kernel (still in
  fp16).  This keeps the kernel simple because the mask‑masked values are already
  zeroed.
* **No synchronisation for statistics** – all LayerNorms are performed in
  regular PyTorch (they are cheap compared to the `N³` work) so we never need
  a reduction inside Triton.

The code below follows the exact same API as required (`custom_kernel(data)`),
uses the supplied weight tensors, and returns a `float32` tensor of shape
`[B, N, N, dim]`.

```python
"""
TriMul “outgoing” implementation (forward only).

The heavy part (the N³ einsum) is executed as a batched GEMM in Triton:
    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]

All other operations (LayerNorm, linear projections, gating, final
LayerNorm + linear) stay in PyTorch.  Mixed‑precision is used for the
kernel (fp16 compute, fp32 accumulation, fp16 store) and the result is
converted back to fp32 for the remaining steps.
"""

import torch
import triton
import triton.language as tl
from torch.nn import functional as F


# ----------------------------------------------------------------------
# Triton kernel: batched matrix multiplication (I×K)·(K×J) → (I×J)
# ----------------------------------------------------------------------
@triton.jit
def batch_matmul_kernel(
    a_ptr,            # left  matrix pointer   (Z, I, K)
    b_ptr,            # right matrix pointer   (Z, K, J)
    c_ptr,            # output matrix pointer  (Z, I, J)
    M, N, K,          # matrix sizes
    stride_az, stride_am, stride_ak,   # strides for a (z, i, k)
    stride_bz, stride_bk, stride_bn,   # strides for b (z, k, j)
    stride_cz, stride_cm, stride_cn,   # strides for c (z, i, j)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    # ------------------------------------------------------------------
    # tile indices
    # ------------------------------------------------------------------
    pid_m = tl.program_id(0)          # tile along M (rows)
    pid_n = tl.program_id(1)          # tile along N (cols)
    pid_z = tl.program_id(2)          # batch*head index

    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in fp32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ------------------------------------------------------------------
    # reduction over K
    # ------------------------------------------------------------------
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # left tile          shape (BLOCK_M, BLOCK_K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # right tile         shape (BLOCK_K, BLOCK_N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # fp32 accumulation
        acc += tl.dot(a, b)

    # store result (convert back to fp16)
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


def triton_batch_matmul(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Batched matrix multiplication using the Triton kernel above.

    Parameters
    ----------
    left  : Tensor of shape (B, H, I, K)   dtype float16, contiguous
    right : Tensor of shape (B, H, K, J)   dtype float16, contiguous

    Returns
    -------
    out : Tensor of shape (B, H, I, J)     dtype float16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    # allocate output
    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # flatten the leading dimensions for the kernel
    Z = B * H
    a = left.view(Z, I, K)
    b = right.view(Z, K, J)
    c = out.view(Z, I, J)

    # strides in number of elements (not bytes)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # tiling – tuned for Hopper (SM90)
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(I, BLOCK_M),   # program_id(0)
        triton.cdiv(J, BLOCK_N),   # program_id(1)
        Z,                         # program_id(2)
    )
    batch_matmul_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,               # good default for fp16 on H200
    )
    return out


# ----------------------------------------------------------------------
# Full forward pass (PyTorch + Triton)
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the “outgoing” TriMul operator.

    Parameters
    ----------
    data : tuple (input_tensor, mask, weights, config)
        input_tensor : torch.Tensor [B, N, N, dim]    (float32)
        mask         : torch.Tensor [B, N, N]        (float32 or bool) or None
        weights      : dict of parameter tensors
        config       : dict with keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor [B, N, N, dim] (float32)
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dtype = input_tensor.dtype
    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]

    # --------------------------------------------------------------
    # 1. Input LayerNorm  (tiny tensor → keep in PyTorch)
    # --------------------------------------------------------------
    norm_w = weights["norm.weight"]
    norm_b = weights["norm.bias"]
    # manual LayerNorm to avoid extra module overhead
    mean = input_tensor.mean(-1, keepdim=True)
    var = input_tensor.var(-1, unbiased=False, keepdim=True)
    eps = 1e-5
    x = (input_tensor - mean) / torch.sqrt(var + eps)
    x = x * norm_w + norm_b          # still float32

    # --------------------------------------------------------------
    # 2. Linear projections + gating (convert to fp16 for the heavy part)
    # --------------------------------------------------------------
    # Helper to fetch & cast weight tensors once
    def _to_fp16(t):
        return t.to(torch.float16, non_blocking=True)

    left_proj_w = _to_fp16(weights["left_proj.weight"])
    right_proj_w = _to_fp16(weights["right_proj.weight"])
    left_gate_w = _to_fp16(weights["left_gate.weight"])
    right_gate_w = _to_fp16(weights["right_gate.weight"])
    out_gate_w = _to_fp16(weights["out_gate.weight"])
    to_out_norm_w = weights["to_out_norm.weight"]   # stays fp32 for final LN
    to_out_norm_b = weights["to_out_norm.bias"]
    to_out_w = weights["to_out.weight"]

    # fp16 copy of the normalized input
    x_fp16 = x.to(torch.float16)

    left = F.linear(x_fp16, left_proj_w)   # (B,N,N,hidden)
    right = F.linear(x_fp16, right_proj_w)

    # --------------------------------------------------------------
    # 3. Mask (if present) – broadcast to hidden dim and apply in fp16
    # --------------------------------------------------------------
    if mask is not None:
        # mask shape [B,N,N] → [B,N,N,1] → broadcast
        mask_fp16 = mask.to(torch.float16).unsqueeze(-1)
        left = left * mask_fp16
        right = right * mask_fp16

    # --------------------------------------------------------------
    # 4. Gating
    # --------------------------------------------------------------
    left_gate = F.linear(x_fp16, left_gate_w).sigmoid()
    right_gate = F.linear(x_fp16, right_gate_w).sigmoid()
    out_gate = F.linear(x_fp16, out_gate_w).sigmoid()

    left = left * left_gate
    right = right * right_gate

    # --------------------------------------------------------------
    # 5. Triton batched GEMM (the N³ core)
    # --------------------------------------------------------------
    # reshape & permute to (B, H, I, K) and (B, H, K, J)
    left_perm = left.permute(0, 3, 1, 2).contiguous()   # (B, H, I, K)
    right_perm = right.permute(0, 3, 2, 1).contiguous() # (B, H, K, J)

    out_fp16 = triton_batch_matmul(left_perm, right_perm)   # (B, H, I, J) fp16

    # bring back to original layout and convert to fp32 for the rest
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)  # (B,N,N,dim)

    # --------------------------------------------------------------
    # 6. Output LayerNorm
    # --------------------------------------------------------------
    mean_o = out.mean(-1, keepdim=True)
    var_o = out.var(-1, unbiased=False, keepdim=True)
    out = (out - mean_o) / torch.sqrt(var_o + eps)
    out = out * to_out_norm_w + to_out_norm_b

    # --------------------------------------------------------------
    # 7. Final gating + linear projection
    # --------------------------------------------------------------
    out = out * out_gate.to(torch.float32)
    out = F.linear(out, to_out_w)

    return out
```
