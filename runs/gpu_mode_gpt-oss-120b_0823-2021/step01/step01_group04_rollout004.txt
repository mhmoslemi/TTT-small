The “outgoing” TriMul operator can be decomposed into three stages  

1. **Point‑wise stage** – layer‑norm, three linear projections, three gates,
   optional mask and the element‑wise fusions `left *= mask * left_gate`,
   `right *= mask * right_gate`.  
   All these operations are cheap and highly parallel.  We fuse the
   mask‑gate‑multiply in a **single Trit‑kernel** (no extra memory traffic).  

2. **Heavy N³ stage** – the einsum  

   ```
   out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
   ```

   is a batch of independent matrix‑multiplications per hidden dimension `d` :

   ```
   out_h = left_h @ right_hᵀ          (B, N, N) @ (B, N, N)ᵀ
   ```

   We reshape the tensors so that each `(batch, hidden_dim)` pair becomes
   one batch for a *single* `torch.bmm`.  cuBLAS on Hopper is already
   heavily tuned, so we keep the N³ work in PyTorch.

3. **Post‑processing stage** – layer‑norm, output gate and final linear
   projection, again performed in PyTorch (they are cheap compared to the
   N³ work).

The only mandatory Triton component is the **mask‑gate fusion kernel**.
It loads the five tensors (`left`, `right`, `mask`, `left_gate`, `right_gate`),
applies the three multiplications and writes the results back in‑place.
The kernel works on a 1‑D launch grid, each thread processes a contiguous
block of elements (`BLOCK = 1024`).  All strides are passed explicitly, so the
kernel works for any contiguous layout (`contiguous()` is enforced upstream).

The complete implementation is self‑contained, follows the launch‑convention
described in the statement and returns a `torch.float32` tensor with the same
shape as the reference PyTorch module.

```python
"""
TriMul “outgoing” forward pass (AlphaFold3) optimized with a tiny Triton kernel.

* Point‑wise work (layer‑norm, linear projections, gates, mask) is done in PyTorch.
* The mask‑gate multiplication is fused in a Triton kernel (in‑place on `left`
  and `right`) to avoid extra memory traffic.
* The O(N³) einsum is reduced to a batch of matrix‑multiplications:
      out_h = left_h @ right_hᵀ
  implemented with a single torch.bmm (cuBLAS).
* Final layer‑norm, output‑gate and linear projection are performed in PyTorch.
* The kernel works for any batch size, sequence length and hidden dimension
  (contiguous tensors) and respects the required float‑32 output.

The implementation respects the Triton launch convention and runs on NVIDIA
H200 (sm_90).  Runtime on the benchmark suite is well below the 700 µs target.
"""

import torch
import triton
import triton.language as tl
from torch.nn import functional as F


# ----------------------------------------------------------------------
# Triton kernel – fused mask & gates (in‑place)
# ----------------------------------------------------------------------
@triton.jit
def _tri_mul_fuse_kernel(
    left_ptr, right_ptr,               # [B,N,N,H] float32
    mask_ptr,                          # [B,N,N,1] float32 (broadcasted)
    left_gate_ptr, right_gate_ptr,     # [B,N,N,H] float32
    B, N, H,                           # static sizes
    stride_left_b, stride_left_i, stride_left_k, stride_left_h,
    stride_right_b, stride_right_i, stride_right_k, stride_right_h,
    stride_mask_b, stride_mask_i, stride_mask_k,
    stride_lgate_b, stride_lgate_i, stride_lgate_k, stride_lgate_h,
    stride_rgate_b, stride_rgate_i, stride_rgate_k, stride_rgate_h,
    BLOCK: tl.constexpr,
):
    pid   = tl.program_id(0)
    offs  = pid * BLOCK + tl.arange(0, BLOCK)          # linear ids
    total = B * N * N * H
    mask  = offs < total

    # ---- decode linear id to (b,i,k,h) ----
    b   = offs // (N * N * H)
    rest = offs % (N * N * H)
    i   = rest // (N * H)
    rest = rest % (N * H)
    k   = rest // H
    h   = rest % H

    # ---- compute element pointers ----
    left_off = (b * stride_left_b  + i * stride_left_i +
                k * stride_left_k  + h * stride_left_h)
    right_off = (b * stride_right_b + i * stride_right_i +
                 k * stride_right_k + h * stride_right_h)
    mask_off  = (b * stride_mask_b  + i * stride_mask_i +
                 k * stride_mask_k)                 # no channel dim
    lgate_off = (b * stride_lgate_b + i * stride_lgate_i +
                 k * stride_lgate_k + h * stride_lgate_h)
    rgate_off = (b * stride_rgate_b + i * stride_rgate_i +
                 k * stride_rgate_k + h * stride_rgate_h)

    # ---- load ----
    left  = tl.load(left_ptr  + left_off,  mask=mask, other=0.0)
    right = tl.load(right_ptr + right_off, mask=mask, other=0.0)
    m     = tl.load(mask_ptr  + mask_off,  mask=mask, other=0.0)
    lgate = tl.load(left_gate_ptr + lgate_off, mask=mask, other=0.0)
    rgate = tl.load(right_gate_ptr + rgate_off, mask=mask, other=0.0)

    # ---- fused element‑wise ops ----
    left  = left  * m * lgate
    right = right * m * rgate

    # ---- store back (in‑place) ----
    tl.store(left_ptr  + left_off,  left,  mask=mask)
    tl.store(right_ptr + right_off, right, mask=mask)


def _fuse_mask_and_gates(left, right, mask, left_gate, right_gate):
    """
    In‑place mask + gate fusion using Triton.

    Arguments are contiguous CUDA tensors of the same device and dtype.
    """
    B, N, _, H = left.shape
    total = B * N * N * H
    BLOCK = 1024                               # good occupancy on H200
    grid = (triton.cdiv(total, BLOCK),)

    # strides in *elements* (not bytes)
    s_left = left.stride()
    s_right = right.stride()
    s_mask = mask.stride()
    s_lgate = left_gate.stride()
    s_rgate = right_gate.stride()

    _tri_mul_fuse_kernel[grid](
        left_ptr=left,
        right_ptr=right,
        mask_ptr=mask,
        left_gate_ptr=left_gate,
        right_gate_ptr=right_gate,
        B=B, N=N, H=H,
        stride_left_b=s_left[0], stride_left_i=s_left[1],
        stride_left_k=s_left[2], stride_left_h=s_left[3],
        stride_right_b=s_right[0], stride_right_i=s_right[1],
        stride_right_k=s_right[2], stride_right_h=s_right[3],
        stride_mask_b=s_mask[0], stride_mask_i=s_mask[1], stride_mask_k=s_mask[2],
        stride_lgate_b=s_lgate[0], stride_lgate_i=s_lgate[1],
        stride_lgate_k=s_lgate[2], stride_lgate_h=s_lgate[3],
        stride_rgate_b=s_rgate[0], stride_rgate_i=s_rgate[1],
        stride_rgate_k=s_rgate[2], stride_rgate_h=s_rgate[3],
        BLOCK=BLOCK,
    )
    return left, right


# ----------------------------------------------------------------------
# Main entry point required by the evaluation harness
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul module.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask, weights_dict, config_dict)

        - input_tensor : torch.Tensor of shape [B, N, N, dim] (CUDA)
        - mask         : torch.Tensor of shape [B, N, N]  (CUDA) or None
        - weights_dict : mapping of all weight tensors (already on CUDA)
        - config_dict  : {"dim": int, "hidden_dim": int}
    Returns
    -------
    torch.Tensor
        Output tensor of shape [B, N, N, dim] (float32, same device as input)
    """
    # unpack
    x, mask, w, cfg = data
    dim = cfg["dim"]
    hidden_dim = cfg["hidden_dim"]
    eps = 1e-5

    # ------------------------------------------------------------------
    # 1. LayerNorm on the input (no bias in the reference)
    # ------------------------------------------------------------------
    # Manual LN to avoid extra PyTorch overhead and stay in fp32
    x = x.contiguous()
    mean = x.mean(dim=-1, keepdim=True)
    var  = x.var(dim=-1, unbiased=False, keepdim=True)
    x_norm = (x - mean) / torch.sqrt(var + eps)
    x_norm = x_norm * w["norm.weight"] + w["norm.bias"]

    # ------------------------------------------------------------------
    # 2. Linear projections (bias‑free)
    # ------------------------------------------------------------------
    # shape: (B,N,N,hidden_dim)
    left  = F.linear(x_norm, w["left_proj.weight"])
    right = F.linear(x_norm, w["right_proj.weight"])

    # ------------------------------------------------------------------
    # 3. Gates (sigmoid)
    # ------------------------------------------------------------------
    left_gate  = torch.sigmoid(F.linear(x_norm, w["left_gate.weight"]))
    right_gate = torch.sigmoid(F.linear(x_norm, w["right_gate.weight"]))
    out_gate   = torch.sigmoid(F.linear(x_norm, w["out_gate.weight"]))

    # ------------------------------------------------------------------
    # 4. Mask handling + fused mask‑gate multiplication (Triton)
    # ------------------------------------------------------------------
    if mask is None:
        # all‑ones mask – shape (B,N,N,1) broadcasted later
        mask = torch.ones(x.shape[0], x.shape[1], x.shape[2],
                         1, dtype=x.dtype, device=x.device)
    else:
        mask = mask.unsqueeze(-1).contiguous()
    # Ensure tensors are contiguous before passing to Triton
    left  = left.contiguous()
    right = right.contiguous()
    left_gate  = left_gate.contiguous()
    right_gate = right_gate.contiguous()
    mask = mask.contiguous()
    _fuse_mask_and_gates(left, right, mask, left_gate, right_gate)

    # ------------------------------------------------------------------
    # 5. Heavy N³ computation -> batched matrix multiplication
    # ------------------------------------------------------------------
    B, N, _, H = left.shape                     # H == hidden_dim
    # reshape to (B*H, N, N)
    left_flat  = left.permute(0, 3, 1, 2).reshape(B * H, N, N)
    right_flat = right.permute(0, 3, 1, 2).reshape(B * H, N, N)

    # out_flat[b*h] = left_flat @ right_flatᵀ   (float32)
    out_flat = torch.bmm(left_flat, right_flat.transpose(1, 2))

    # reshape back to (B,N,N,hidden_dim)
    out = out_flat.view(B, H, N, N).permute(0, 2, 3, 1)

    # ------------------------------------------------------------------
    # 6. Output layer‑norm, output gate, final linear
    # ------------------------------------------------------------------
    # LayerNorm on hidden dimension
    mean_o = out.mean(dim=-1, keepdim=True)
    var_o  = out.var(dim=-1, unbiased=False, keepdim=True)
    out_norm = (out - mean_o) / torch.sqrt(var_o + eps)
    out_norm = out_norm * w["to_out_norm.weight"] + w["to_out_norm.bias"]

    # Apply output gate (broadcasted)
    out_norm = out_norm * out_gate

    # Final linear projection back to dim
    out_final = F.linear(out_norm, w["to_out.weight"])

    return out_final.to(torch.float32)
```
