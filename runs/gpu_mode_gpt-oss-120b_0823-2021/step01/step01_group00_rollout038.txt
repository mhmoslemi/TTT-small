Below is a self‑contained implementation of the *outgoing* TriMul operator that

* follows the reference PyTorch code,
* keeps the cheap `LayerNorm` / linear‑gate parts in PyTorch (they are memory‑bandwidth bound, not compute bound), and
* accelerates the only N³‑cost operation  

```
out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
```  

with a **single Trit‑fusion** that performs a batched matrix‑multiply for every
(head = `hidden_dim`) simultaneously.

Key ideas
---------

| Idea | Reason |
|------|--------|
| **Batched GEMM** – reshape `left` to *(B·H, I, K)* and `right` to *(B·H, K, J)* and compute many GEMMs in one launch. | The `einsum` is exactly a set of independent matrix‑multiplies.  Using a GEMM‑style kernel gives‑you the full SM‑level parallelism of H200. |
| **FP16 compute, FP32 accumulation** – load inputs as `float16`, accumulate in `float32` (`tl.dot` does the conversion automatically). | H200’s Tensor‑Core units give ≈2× speed‑up for FP16 · FP16 → FP32.  Accumulating in FP32 guarantees numerical parity with the reference. |
| **Tile sizes tuned for Hopper** – `BLOCK_M = BLOCK_N = 64`, `BLOCK_K = 32`. | Fit into shared memory, give high occupancy and let the scheduler keep 4 warps per CTA (recommended for fp16 on SM90). |
| **Mask handling on the host** – the mask is applied before the heavy kernel (element‑wise mul, cheap). | Avoids an extra conditional in the kernel, which would kill performance. |
| **Manual LayerNorm** – a lightweight per‑element reduction performed in FP32 on the host (the tensor is only `B·N·N·dim` ≈ few MB, so this is not a bottleneck). | Triton does not provide a built‑in `mean`/`var`; doing it in PyTorch is simplest and still fast. |
| **No extra synchronisations** – the kernel only reads from two inputs and writes one output, no intra‑CTA sync needed. | Keeps the launch latency low (≈ 700 µs target). |

The final function `custom_kernel` follows the exact signature required by the
grader, uses the weight tensors supplied in `weights`, and returns a **`float32`**
tensor with the same shape as the input.

```python
"""
TriMul “outgoing” implementation (forward only).

The heavy N³ work is done with a single Triton kernel that computes a
batched matrix‑multiply:

    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]

by reshaping the tensors to (B·H, I, K) @ (B·H, K, J) → (B·H, I, J).
All layer‑norms, linear layers and masks are handled in PyTorch (float32 → fp16
where appropriate). The kernel uses fp16 precision for the multiply‑add and
accumulates in fp32 to match the reference output.
"""

import torch
import triton
import triton.language as tl
from torch.nn import functional as F


# ----------------------------------------------------------------------
# Triton kernel : batched GEMM (I×K)·(K×J) -> (I×J)
# ----------------------------------------------------------------------
@triton.jit
def batch_gemm_kernel(
    a_ptr,            # left matrix  (B·H, I, K)
    b_ptr,            # right matrix (B·H, K, J)
    c_ptr,            # output       (B·H, I, J)
    M, N, K,          # dimensions
    stride_az, stride_am, stride_ak,   # strides for a (batch, i, k)
    stride_bz, stride_bk, stride_bn,   # strides for b (batch, k, j)
    stride_cz, stride_cm, stride_cn,   # strides for c (batch, i, j)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    pid_z = tl.program_id(2)          # batch*head index
    pid_m = tl.program_id(0)          # tile along M (i)
    pid_n = tl.program_id(1)          # tile along N (j)

    # --------------------------------------------------------------
    # Offsets for the current tile
    # --------------------------------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # Accumulator in fp32 (Tensor Cores add in fp32 automatically)
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # Loop over K dimension in blocks
    # --------------------------------------------------------------
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # Load a block of A (shape BLOCK_M × BLOCK_K)
        a = tl.load(
            a_ptr
            + pid_z * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        )
        # Load a block of B (shape BLOCK_K × BLOCK_N)
        b = tl.load(
            b_ptr
            + pid_z * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        )
        # fp16·fp16 -> fp32 accumulation
        acc += tl.dot(a, b)

    # --------------------------------------------------------------
    # Store result (convert back to fp16 for bandwidth)
    # --------------------------------------------------------------
    c = acc.to(tl.float16)
    tl.store(
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


# ----------------------------------------------------------------------
# Helper that launches the kernel
# ----------------------------------------------------------------------
def triton_batched_gemm(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    left  : (B, H, I, K)   fp16, contiguous
    right : (B, H, K, J)   fp16, contiguous
    returns: (B, H, I, J) fp16
    """
    assert left.is_contiguous() and right.is_contiguous()
    B, H, I, K = left.shape
    _, _, K2, J = right.shape
    assert K == K2

    # allocate output
    out = torch.empty((B, H, I, J), device=left.device, dtype=torch.float16)

    # flatten batch*head for the kernel
    batch_dim = B * H
    a = left.reshape(batch_dim, I, K)
    b = right.reshape(batch_dim, K, J)
    c = out.reshape(batch_dim, I, J)

    # strides in elements (not bytes)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bk, stride_bn = b.stride()
    stride_cz, stride_cm, stride_cn = c.stride()

    # tile sizes – good for Hopper/Tensor‑Cores
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(I, BLOCK_M),          # program id 0
        triton.cdiv(J, BLOCK_N),          # program id 1
        batch_dim,                        # program id 2
    )
    batch_gemm_kernel[grid](
        a_ptr=a,
        b_ptr=b,
        c_ptr=c,
        M=I,
        N=J,
        K=K,
        stride_az=stride_az,
        stride_am=stride_am,
        stride_ak=stride_ak,
        stride_bz=stride_bz,
        stride_bk=stride_bk,
        stride_bn=stride_bn,
        stride_cz=stride_cz,
        stride_cm=stride_cm,
        stride_cn=stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,          # empirically good for fp16 on SM90
    )
    return out


# ----------------------------------------------------------------------
# Full forward (host side + Triton acceleration)
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Parameters
    ----------
    data : tuple (input, mask, weights, config)
        input   – torch.Tensor [B, N, N, dim] (float32)
        mask    – torch.Tensor [B, N, N] (float32 or bool) or None
        weights – dict of leaf weight tensors (all float32)
        config  – dict with keys ``dim`` and ``hidden_dim``

    Returns
    -------
    torch.Tensor [B, N, N, dim] (float32)
    """
    # ------------------------------------------------------------------
    # Unpack arguments
    # ------------------------------------------------------------------
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]          # = H in the paper

    B, N, _, _ = input_tensor.shape

    # ------------------------------------------------------------------
    # 1) Input LayerNorm (same as nn.LayerNorm(dim) in reference)
    # ------------------------------------------------------------------
    # Manual LN to avoid extra torch.nn overhead
    eps = 1e-5
    mean = input_tensor.mean(-1, keepdim=True)
    var = input_tensor.var(-1, unbiased=False, keepdim=True)
    x = (input_tensor - mean) / torch.sqrt(var + eps)
    x = x * weights["norm.weight"] + weights["norm.bias"]   # shape [B,N,N,dim]

    # ------------------------------------------------------------------
    # 2) Linear projections + gating (float32 → fp16 for the heavy part)
    # ------------------------------------------------------------------
    # All linear layers are bias‑free in the reference
    # weight shape: (out_features, in_features)  i.e. (hidden_dim, dim)
    # Convert weights once to fp16
    left_proj_w  = weights["left_proj.weight"].to(torch.float16)
    right_proj_w = weights["right_proj.weight"].to(torch.float16)
    left_gate_w  = weights["left_gate.weight"].to(torch.float16)
    right_gate_w = weights["right_gate.weight"].to(torch.float16)
    out_gate_w   = weights["out_gate.weight"].to(torch.float16)

    x_fp16 = x.to(torch.float16)

    left = F.linear(x_fp16, left_proj_w)          # (B,N,N,hidden_dim)
    right = F.linear(x_fp16, right_proj_w)        # (B,N,N,hidden_dim)

    # ------------------------------------------------------------------
    # 3) Apply mask (if any) – cheap element‑wise op, keep in fp16
    # ------------------------------------------------------------------
    if mask is not None:
        # mask can be bool or float; we treat non‑zero as True
        mask_fp16 = mask.unsqueeze(-1).to(torch.float16)   # (B,N,N,1)
        left = left * mask_fp16
        right = right * mask_fp16

    # ------------------------------------------------------------------
    # 4) Gating (sigmoid after linear)
    # ------------------------------------------------------------------
    left_gate  = F.linear(x_fp16, left_gate_w).sigmoid()
    right_gate = F.linear(x_fp16, right_gate_w).sigmoid()
    out_gate   = F.linear(x_fp16, out_gate_w).sigmoid()

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5) Triton accelerated batched GEMM
    #    left : (B,N,N,hidden_dim)  -> (B,H,N,N) after permute
    #    right: (B,N,N,hidden_dim)  -> (B,H,N,N) after permute & transpose
    # ------------------------------------------------------------------
    # permute to (B, H, I, K) and (B, H, K, J) where I=J=N, K=hidden_dim
    left_perm  = left.permute(0, 3, 1, 2).contiguous()   # (B,H,N,N)
    right_perm = right.permute(0, 3, 2, 1).contiguous()  # (B,H,N,N) = (B,H,K,J)

    # batched GEMM → (B, H, N, N) in fp16
    out_fp16 = triton_batched_gemm(left_perm, right_perm)

    # reshape back to (B,N,N,dim) and cast to fp32 for the rest of the pipeline
    out = out_fp16.permute(0, 2, 3, 1).contiguous().to(torch.float32)

    # ------------------------------------------------------------------
    # 6) Output LayerNorm (nn.LayerNorm(hidden_dim) in reference)
    # ------------------------------------------------------------------
    eps = 1e-5
    mean = out.mean(-1, keepdim=True)
    var = out.var(-1, unbiased=False, keepdim=True)
    out = (out - mean) / torch.sqrt(var + eps)
    out = out * weights["to_out_norm.weight"] + weights["to_out_norm.bias"]

    # ------------------------------------------------------------------
    # 7) Final gating + projection back to dim
    # ------------------------------------------------------------------
    out = out * out_gate.to(torch.float32)          # broadcast over dim
    out = F.linear(out, weights["to_out.weight"].to(torch.float32))

    return out
```
