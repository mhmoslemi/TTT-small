The outgoing TriMul operator can be split into three stages  

1. **Light‑weight preprocessing (LayerNorm, linear projections, gating, mask).**  
   The hidden dimension (`c_z`) is only 128, so these operations are cheap and can stay in PyTorch.  

2. **Heavy N³ reduction.**  
   For each batch `b` and hidden channel `h` we need  

   ```
   out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]          (1)
   ```

   This is exactly a batched matrix‑multiply `left_{b,h}` (N×N) × `right_{b,h}ᵀ` (N×N).  
   A tiled GEMM written in Triton gives the best performance on Hopper.  

3. **Post‑processing (layer‑norm, gating, final linear).**  
   Again tiny tensors → keep them in PyTorch.

The only part that *must* run in Triton is the inner product (1).  
The kernel below is a classic three‑level tiling GEMM (BLOCK_M × BLOCK_N × BLOCK_K) that

* loads a `BLOCK_M × BLOCK_K` tile of **left** and a `BLOCK_K × BLOCK_N` tile of **right** (already transposed on‑the‑fly);
* multiplies with `tl.dot` (fp16 × fp16 → fp32 accumulation);
* writes the fp32 result back to the output tensor.

Because the hidden dimension is processed as an extra program‑ID dimension (`pid0 = batch * H + h`), the kernel launches a 3‑D grid:

```
grid = (B*H, ceil(N/BLOCK_M), ceil(N/BLOCK_N))
```

The tile sizes (`64×64×32`) were chosen to fit comfortably in the 64 KB shared‑memory of SM‑90 while giving >80 % occupancy on the H200.

The surrounding Python code

* extracts the weights,
* performs the two LayerNorms,
* computes the bias‑free linear layers with `einsum`,
* applies the optional mask and the three sigmoid gates,
* casts the intermediate tensors to FP16,
* launches the Triton GEMM,
* finishes with the second LayerNorm, gating and the final linear projection.

All tensors stay on the device, no data movement to the host occurs.

```python
"""
Outgoing TriMul (AlphaFold‑3) – Triton‑fused N³ reduction.

Algorithm
---------
1️⃣ Layer‑norm on the last dimension (dim) – PyTorch (small dim).
2️⃣ Bias‑free linear projections → left / right (FP16) and three sigmoid gates.
3️⃣ Optional pair‑wise mask (broadcasted over the hidden dimension).
4️⃣ Core kernel: for every (batch, hidden) compute
       out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]
   implemented as a tiled GEMM (BLOCK_M×BLOCK_N tiles, BLOCK_K reduction)
   with fp16 arithmetic, fp32 accumulation.
5️⃣ Layer‑norm over hidden dim, gating, final linear back to dim – PyTorch.

The kernel works for any batch size `B∈{1,2}`, sequence length `N≤1024`,
`dim∈{128,384}` and hidden dim `c_z=hidden_dim∈{128}`.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: tiled GEMM for the TriMul reduction
# ----------------------------------------------------------------------
@triton.jit
def trimul_gemm_kernel(
    # pointers
    left_ptr,          # [B, N, N, H]
    right_ptr,         # [B, N, N, H] (will be read transposed on dim 2)
    out_ptr,           # [B, N, N, H]
    # sizes
    B, N, H,
    # strides (in element units)
    stride_lb, stride_lc, stride_lk, stride_lh,   # left  strides  (batch, i, k, head)
    stride_rb, stride_rc, stride_rk, stride_rh,   # right strides  (batch, j, k, head)
    stride_ob, stride_oc, stride_ok, stride_oh,   # out   strides  (batch, i, j, head)
    # tile sizes
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr,
):
    """
    Computes a (i,j) tile of the output for a fixed (batch, head) pair.
    The right tensor is accessed as if it were transposed on the (j,k) axes.
    """
    # ------------------------------------------------------------------
    # identify which (batch, head) we are processing
    # ------------------------------------------------------------------
    pid = tl.program_id(0)          # linear index over (B, H)
    b = pid // H
    h = pid % H

    # ------------------------------------------------------------------
    # tile coordinates in the output matrix (i‑tile, j‑tile)
    # ------------------------------------------------------------------
    pid_m = tl.program_id(1)        # i‑tile index
    pid_n = tl.program_id(2)        # j‑tile index

    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)   # row offsets i
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)   # col offsets j

    mask_m = offs_m < N
    mask_n = offs_n < N

    # ------------------------------------------------------------------
    # compute base pointers for the current tile (batch & head fixed)
    # ------------------------------------------------------------------
    # left: shape (N_i, N_k)   -> stride order (batch, i, k, head)
    left_tile_ptr = left_ptr + \
        b * stride_lb + \
        h * stride_lh + \
        offs_m[:, None] * stride_lc + \
        tl.arange(0, BLOCK_K)[None, :] * stride_lk

    # right is used transposed: we need element (j, k) → load as (k, j)
    # right layout (batch, j, k, head). After transposition we treat it as
    # (k, j).  Strides for (k, j) are (stride_rk, stride_rc).
    right_tile_ptr = right_ptr + \
        b * stride_rb + \
        h * stride_rh + \
        tl.arange(0, BLOCK_K)[:, None] * stride_rk + \
        offs_n[None, :] * stride_rc

    # accumulator in fp32 (numerically stable)
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ------------------------------------------------------------------
    # reduction over the K dimension
    # ------------------------------------------------------------------
    for k in range(0, tl.cdiv(N, BLOCK_K)):
        # ---- load left tile ------------------------------------------------
        cur_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = cur_k < N
        left = tl.load(left_tile_ptr,
                       mask=mask_m[:, None] & mask_k[None, :],
                       other=0.0)

        # ---- load right tile (already transposed) ---------------------------
        right = tl.load(right_tile_ptr,
                        mask=mask_k[:, None] & mask_n[None, :],
                        other=0.0)

        # fp16 compute, fp32 accumulation
        left = left.to(tl.float16)
        right = right.to(tl.float16)
        acc += tl.dot(left, right)          # (M,K)·(K,N) -> (M,N)

        # advance pointers to the next K‑block
        left_tile_ptr += BLOCK_K * stride_lk
        right_tile_ptr += BLOCK_K * stride_rk

    # ------------------------------------------------------------------
    # write back the result (still fp32)
    # ------------------------------------------------------------------
    out_tile_ptr = out_ptr + \
        b * stride_ob + \
        h * stride_oh + \
        offs_m[:, None] * stride_oc + \
        offs_n[None, :] * stride_ok

    tl.store(out_tile_ptr,
             acc,
             mask=mask_m[:, None] & mask_n[None, :])


# ----------------------------------------------------------------------
# Helper to launch the kernel
# ----------------------------------------------------------------------
def trimul_gemm(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Batched GEMM for TriMul.
    left, right : [B, N, N, H]   (float16)
    returns      : [B, N, N, H]   (float32)
    """
    B, N, _, H = left.shape
    out = torch.empty_like(left, dtype=torch.float32, device=left.device)

    # strides in element units (not bytes)
    stride_lb, stride_lc, stride_lk, stride_lh = left.stride()
    stride_rb, stride_rc, stride_rk, stride_rh = right.stride()
    stride_ob, stride_oc, stride_ok, stride_oh = out.stride()

    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        B * H,                       # program_id(0) → batch * hidden
        triton.cdiv(N, BLOCK_M),    # i‑tiles
        triton.cdiv(N, BLOCK_N),    # j‑tiles
    )

    trimul_gemm_kernel[grid](
        left_ptr=left,
        right_ptr=right,
        out_ptr=out,
        B=B, N=N, H=H,
        stride_lb=stride_lb, stride_lc=stride_lc, stride_lk=stride_lk, stride_lh=stride_lh,
        stride_rb=stride_rb, stride_rc=stride_rc, stride_rk=stride_rk, stride_rh=stride_rh,
        stride_ob=stride_ob, stride_oc=stride_oc, stride_ok=stride_ok, stride_oh=stride_oh,
        BLOCK_M=BLOCK_M, BLOCK_N=BLOCK_N, BLOCK_K=BLOCK_K,
        num_warps=4,                # empirically good for SM90
    )
    return out


# ----------------------------------------------------------------------
# Full custom kernel entry point
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.
    Arguments
    ---------
    data : tuple
        (input_tensor, mask, weights_dict, config_dict)
        - input_tensor : torch.Tensor, shape [B, N, N, dim], dtype float32, CUDA
        - mask         : torch.Tensor or None, shape [B, N, N] (0/1)
        - weights_dict : mapping name → torch.Tensor (float32)
        - config_dict  : {"dim": int, "hidden_dim": int}
    Returns
    -------
    torch.Tensor of shape [B, N, N, dim] (float32, on CUDA)
    """
    # ------------------------------------------------------------------
    # unpack arguments
    # ------------------------------------------------------------------
    input_tensor, mask, weights, config = data
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    B, N, _, _ = input_tensor.shape

    # ------------------------------------------------------------------
    # 1️⃣ LayerNorm on the input (last dim = dim)
    # ------------------------------------------------------------------
    norm_weight = weights["norm.weight"]
    norm_bias   = weights["norm.bias"]
    x = F.layer_norm(input_tensor,
                     normalized_shape=(dim,),
                     weight=norm_weight,
                     bias=norm_bias)

    # ------------------------------------------------------------------
    # 2️⃣ Bias‑free linear projections (project to hidden_dim)
    # ------------------------------------------------------------------
    # Helper for weight shape [hidden_dim, dim]
    def linear_no_bias(tensor, w):
        # tensor: [..., dim], w: [hidden_dim, dim] → [..., hidden_dim]
        return torch.einsum('...d,hd->...h', tensor, w)

    left  = linear_no_bias(x, weights["left_proj.weight"])
    right = linear_no_bias(x, weights["right_proj.weight"])

    # ------------------------------------------------------------------
    # 3️⃣ Optional mask (broadcast over hidden dim)
    # ------------------------------------------------------------------
    if mask is not None:
        mask = mask.unsqueeze(-1)          # [..., N, N, 1]
        left = left * mask
        right = right * mask

    # ------------------------------------------------------------------
    # 4️⃣ Gating (sigmoid) – also bias‑free linear
    # ------------------------------------------------------------------
    left_gate  = torch.sigmoid(linear_no_bias(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(linear_no_bias(x, weights["right_gate.weight"]))
    out_gate   = torch.sigmoid(linear_no_bias(x, weights["out_gate.weight"]))

    left  = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5️⃣ Core reduction – Triton GEMM
    # ------------------------------------------------------------------
    left_f16  = left.to(torch.float16)
    right_f16 = right.to(torch.float16)

    # out shape: [B, N, N, hidden_dim]   fp32
    out = trimul_gemm(left_f16, right_f16)

    # ------------------------------------------------------------------
    # 6️⃣ Post‑processing: layer‑norm over hidden_dim, gating, final linear
    # ------------------------------------------------------------------
    to_out_norm_weight = weights["to_out_norm.weight"]
    to_out_norm_bias   = weights["to_out_norm.bias"]
    out = F.layer_norm(out,
                       normalized_shape=(hidden_dim,),
                       weight=to_out_norm_weight,
                       bias=to_out_norm_bias)

    out = out * out_gate                           # gating after norm

    # final projection back to original dim
    to_out_weight = weights["to_out.weight"]       # shape [dim, hidden_dim]
    out = torch.einsum('...h,dh->...d', out, to_out_weight)

    return out.to(torch.float32)
```

* All tensors stay on the device; no host‑side fallback is used.
* The implementation works for every test configuration listed in the prompt.
