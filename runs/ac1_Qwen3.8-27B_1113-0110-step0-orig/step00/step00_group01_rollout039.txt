$H_{pq} = 2 \delta_{q, k-p}$ (i.e., $H_{pq} = 2$ if $p + q = k$, else 0).

This is a "anti-diagonal" matrix (for a given $k$). Its eigenvalues are $\pm 2$ (it's a permutation matrix times 2, which has eigenvalues $\pm 2$). So the Hessian is indefinite (has both positive and negative eigenvalues). This confirms that $(a*a)_k$ is not convex.

Therefore, the overall problem is non-convex, and we need heuristic methods.

Given the non-convexity, let me go with a practical approach:

1. **LP-based best response** (as described in the state of the art): This has the nice property that it monotonically decreases the objective.

2. **Local search with multiple perturbations**: To escape local minima.

3. **Different starting points**: To explore the landscape.

def solve_best_response_lp(a, M):

    Solve: max 1'b s.t. (a*b)_k <= M for all k, b >= 0.
    Returns optimal b and optimal value.
    """
    n = len(a)
    num_rows = 2 * n - 1

    # Actually: (a*b)_k = sum_j a[j] * b[k-j] where k-j is in [0, n-1]
    # So the coefficient of b[j] in constraint k is a[k-j] if 0 <= k-j <= n-1, i.e., k-n+1 <= j <= k
    # Wait, I need to be more careful.
    # (a*b)_k = sum_{j=0}^{n-1} a[k-j] * b[j] where a[m] = 0 if m not in [0,n-1]
    # So coefficient of b[j] in row k is a[k-j] if 0 <= k-j <= n-1, else 0
    # i.e., j is in [k-n+1, k] intersected with [0, n-1]

    # and the value at column j is a[k-j]
    
    # This is a "convolution" matrix, which is a Toeplitz-like matrix.

    return res.x, res.fun * (-1)  # res.fun is -1'b*, so -res.fun = 1'b*

Actually, I can construct the matrix more efficiently using the structure. The matrix C is a "convolution matrix" or "Toeplitz + Hankel" matrix. Specifically:

$C_{k,j} = a_{k-j}$ if $0 \le k-j \le n-1$, else 0.

Let $d = k-j$. Then $C_{k,j} = a_d$ if $0 \le d \le n-1$.

The "diagonals" of C correspond to fixed $d = k-j$. For $d = 0$: entries $(j,j)$ for $j=0,...,n-1$, all equal to $a_0$. For $d = 1$: entries $(j+1, j)$ for $j=0,...,n-2$, all equal to $a_1$. Etc.

**Faster alternative: Use the dual greedy + complementary slackness**

The dual greedy is O(n^2) time (for each $j$, we compute the sum over the window, which is O(1) with prefix sums). So the total is O(n).

Wait, actually the greedy is:
For $j = 0, 1, \ldots, n-1$:
  $s_j = \sum_{k=j}^{j+n-1} y_k$
  if $s_j < 1/a_j$: $y_{j+n-1} += 1/a_j - s_j$

To compute $s_j$ efficiently, we can maintain a running sum. When we move from $j$ to $j+1$:
$s_{j+1} = s_j - y_j + y_{j+n}$

So each step is O(1), and the total is O(n)! 

After computing $y^*$, we need to find $b^*$. From complementary slackness:
- $b_j^* > 0$ iff $a_j \cdot s_j^* = 1$ (where $s_j^* = \sum_{k=j}^{j+n-1} y_k^*$)
- For $k$ where $y_k^* > 0$: $(a*b^*)_k = M$

The set of $j$ where $b_j^* > 0$ is determined. Let's call it $J^+$. The set of $k$ where $y_k^* > 0$ is $K^+$.

We need to solve: $(a*b^*)_k = M$ for all $k \in K^+$, with $b_j^* = 0$ for $j \notin J^+$.

This is a linear system: for each $k \in K^+$, $\sum_{j \in J^+} a_{k-j} b_j^* = M$ (where $a_m = 0$ if $m \notin [0,n-1]$).

If $|K^+| = |J^+|$, this is a square system and can be solved directly. Otherwise, we need to find a feasible solution.

In practice, $|K^+|$ might be much smaller than $n$ (only a few positions achieve the max), and $|J^+|$ might be similar. So the system might be small and easy to solve.

**Spectral approach**: Design $a$ such that its (aperiodic) autocorrelation is as flat as possible. This is related to "low PAPR" sequence design.

For the aperiodic case, if we want $(a*a)_k \approx C$ for all $k$, we can write:
$(a*a)_k = \sum_i a_i a_{k-i} \approx C$

This is a set of quadratic equations. For $k = 0$: $a_0^2 = C$. For $k = 1$: $2a_0 a_1 = C$. For $k = 2$: $2a_0 a_2 + a_1^2 = C$. Etc.

From $k=0$: $a_0 = \sqrt{C}$.
From $k=1$: $a_1 = C/(2a_0) = \sqrt{C}/2$.
From $k=2$: $a_2 = (C - a_1^2)/(2a_0) = (C - C/4)/(2\sqrt{C}) = (3C/4)/(2\sqrt{C}) = 3\sqrt{C}/8$.
From $k=3$: $2a_0 a_3 + 2a_1 a_2 = C$. So $a_3 = (C - 2a_1 a_2)/(2a_0) = (C - 2 \cdot \sqrt{C}/2 \cdot 3\sqrt{C}/8)/(2\sqrt{C}) = (C - 3C/8)/(2\sqrt{C}) = (5C/8)/(2\sqrt{C}) = 5\sqrt{C}/16$.

Pattern: $a_k = \binom{2k}{k} / 4^k \cdot \sqrt{C}$? Let me check:
- $a_0 = 1 \cdot \sqrt{C}$ ✓ ($\binom{0}{0}/1 = 1$)
- $a_1 = 1/2 \cdot \sqrt{C}$ ✓ ($\binom{2}{1}/4 = 2/4 = 1/2$)
- $a_2 = 3/8 \cdot \sqrt{C}$ ✓ ($\binom{4}{2}/16 = 6/16 = 3/8$)
- $a_3 = 5/16 \cdot \sqrt{C}$? Let me check: $\binom{6}{3}/64 = 20/64 = 5/16$ ✓

So $a_k = \frac{\binom{2k}{k}}{4^k} \sqrt{C}$.

This is the sequence of "flat aperiodic autocorrelation"! It's related to the central binomial coefficients.

But this sequence is infinite ($a_k$ is defined for all $k \ge 0$). For a finite sequence of length $n$, we'd truncate it. The issue is that the truncated sequence won't have exactly flat autocorrelation (the "edge effects" will cause the convolution to deviate from flat at the boundaries).

Let me compute the sum of this sequence: $\sum_{k=0}^{\infty} \frac{\binom{2k}{k}}{4^k} = \sum_{k=0}^{\infty} \binom{2k}{k} / 4^k = 1/\sqrt{1-1} = \infty$.

Wait, that diverges! The terms $\binom{2k}{k}/4^k \approx 1/\sqrt{\pi k}$ for large $k$, so the sum diverges like $\sqrt{k}$.

So we can't have an infinite sequence with flat autocorrelation. For a finite sequence of length $n$, we'd take $a_k = \binom{2k}{k}/4^k$ for $k = 0, \ldots, n-1$ and truncate. The sum is approximately $\int_0^n 1/\sqrt{\pi x} dx = 2\sqrt{n/\pi}$.

The convolution of this truncated sequence will be approximately flat in the "interior" but will deviate at the edges (because the sequence is cut off). The max will be at the center (where the full sum is available) and the edges will be lower.

Let me estimate the performance of this sequence. For $n = 6121$:
- $a_k = \binom{2k}{k}/4^k \approx 1/\sqrt{\pi k}$ for $k \ge 1$ (and $a_0 = 1$)
- Sum $S \approx 1 + 2\sqrt{n/\pi} \approx 1 + 2\sqrt{6121/\pi} \approx 1 + 2 \cdot 44.1 \approx 89.2$

The convolution at the center: $(a*a)_{n-1} = \sum_{i=0}^{n-1} a_i a_{n-1-i}$.

For large $n$, $a_i \approx 1/\sqrt{\pi i}$ and $a_{n-1-i} \approx 1/\sqrt{\pi (n-1-i)}$.
$(a*a)_{n-1} \approx \sum_{i=1}^{n-1} 1/(\pi \sqrt{i(n-1-i)}) + a_0 a_{n-1} + a_{n-1} a_0$

$\sum_{i=1}^{n-1} 1/\sqrt{i(n-i)} \approx \int_0^n dx/\sqrt{x(n-x)} = \pi$ (the beta function integral).

So $(a*a)_{n-1} \approx 1/\pi \cdot \pi + 2/\sqrt{\pi(n-1)} \approx 1 + 2/\sqrt{\pi n}$.
