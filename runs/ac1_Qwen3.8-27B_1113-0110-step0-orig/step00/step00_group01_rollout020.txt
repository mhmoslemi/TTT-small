**Approach: Direct optimization using the structure**

Since the objective is J(a) = 2n * max(c) / (sum a)^2 where c = convolve(a,a), and it's scale-invariant, let's fix sum(a) = sqrt(2n) (as in the state of the art) and minimize max(c).

**Subgradient method:**
1. Fix sum(a) = S (some constant)
2. Compute c = convolve(a, a)
3. Let K = {k : c[k] = max(c)} (set of maximizing positions)
4. For k in K, the subgradient of c[k] w.r.t. a[i] is 2*a[k-i] (with a[m]=0 for m out of range)
5. Update: a[i] <- a[i] - eta * (sum_{k in K} 2*a[k-i] / |K|)
6. Project onto {a >= 0, sum(a) = S}

The projection onto {a >= 0, sum(a) = S} is:
- a_proj = max(0, a - lambda) where lambda is chosen so that sum(a_proj) = S

This is a "water-filling" or "soft thresholding" projection.

This is very efficient! Each iteration is O(n) for the convolution (using FFT, it's O(n log n)), O(n) for the gradient, and O(n) for the projection.

Let me code this up:

```python
def subgradient_step(a, eta, n):
    c = np.convolve(a, a)  # O(n^2) or O(n log n) with FFT
    max_c = c.max()
    K = np.where(c == max_c)[0]  # positions achieving max
    # Subgradient: average gradient over maximizing positions
    grad = np.zeros(n)
    for k in K:
        for i in range(n):
            if 0 <= k - i < n:
                grad[i] += 2 * a[k - i]
    grad /= len(K)
    
    a_new = a - eta * grad
    # Project onto {a >= 0, sum(a) = S}
    S = a.sum()
    # Find lambda such that sum(max(0, a_new - lambda)) = S
    # Binary search for lambda
    lo, hi = a_new.min(), a_new.max()
    for _ in range(50):
        mid = (lo + hi) / 2
        if (np.maximum(0, a_new - mid)).sum() > S:
            lo = mid
        else:
            hi = mid
    lambda_val = (lo + hi) / 2
    a_proj = np.maximum(0, a_new - lambda_val)
    return a_proj
```

Hmm, this is getting complicated. Let me simplify by just using the direct convolution approach:

The gradient of c_k with respect to a is: grad_k[i] = a[k-i] + a[k-i] = 2*a[k-i] (as derived earlier, with a[m]=0 for m outside [0,n-1]).

The soft-subgradient is: grad[i] = sum_k w_k * 2*a[k-i]

Now, sum_k w_k * a[k-i] = sum_k w_k * a[k-i]. Let j = k-i: = sum_j w_{j+i} * a[j].

This is the cross-correlation of w and a at "lag" i (in a specific sense). 

Let me just compute it using numpy's correlate or a sliding dot product via stride tricks:

```python

```

Wait, `sliding_window_view(w, n)` gives windows of size n from w (length 2n-1). The number of windows is (2n-1) - n + 1 = n. Each window is w[i:i+n] for i = 0, ..., n-1. Then `windows @ a` gives result[i] = sum_j w[i+j] * a[j] = g[i]. 

But this creates an (n, n) view and does an (n,n) @ (n,) multiplication, which is O(n^2). For n=6121, that's about 37M operations. In numpy, this should take about 10-50 ms. That's acceptable!

Actually, even better: since we're doing this every iteration, and each iteration is O(n^2) for this step, the total time for T iterations is O(T * n^2). For T = 10000 and n = 6121, that's 37 * 10000 = 370M operations, which in numpy should take about 10-30 seconds. Very manageable!

But wait, I can do even better with FFT. The operation `windows @ a` where windows is a sliding window of w is equivalent to a cross-correlation, which can be done in O(n log n) with FFT.

Let me use the FFT approach for the gradient computation:

    # = sum_j a[j] * w[i+j] for j=0..n-1, i=0..n-1

    #

    # In terms of convolution: g[i] = (A * W_reversed)[i + (2n-2) - (n-1)]

    # We want sum_j A[j] * W[i+j] = sum_j A[j] * W[j+i] = (A ⊛ W)[-i]

    #
