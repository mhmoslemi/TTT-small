3. Find k* = argmax(c).
4. For all j where a[k*-j] > 0: reduce b_j to make c[k*] = M.
   Specifically, we want sum_j a[k*-j] b_j = M.
   If we reduce b_j uniformly: b_j <- b_j * (M / c[k*]) for j in support of a shifted by k*.
   But this might violate other constraints.
5. Repeat.

This is essentially a "coordinate descent" on the constraints. Let me formalize:

```
Initialize b = a (normalized)
Repeat:
  c = a * b
  M = c.max()
  k* = argmax(c)
  # Reduce b to make c[k*] <= M_target
  # c[k*] = sum_j a[k*-j] b_j
  # We want to reduce this. Scale b_j for j in {j : a[k*-j] > 0}
  support = [j for j in range(n) if 0 <= k*-j < n and a[k*-j] > 0]
  scale = min(1, M_target / c[k*])
  b[support] *= scale
```

This is a "projected" approach that enforces one constraint at a time. It's similar to the "Vaidya" or "multiplicative weights" approach.

- (a * b*)[k] = M for k in the "active set" (where the constraint is binding).
- (a * b*)[k] < M for k not in the active set.

The dual of the LP is:

subject to: sum_k y_k * a[k-j] >= 1 for all j

The dual variables y_k tell us which constraints are "tight" (active). If y_k > 0, then (a*b*)[k] = M.

4. Update: y_k <- y_k * (d_j / 1) for the j with the smallest d_j. (Or use a more sophisticated update.)

    # T[row_idx[i], col_idx[i]] = a[offset] where i = j*n + offset

        c_obj = -np.ones(n)
        res = linprog(c_obj, A_ub=T, b_ub=np.full(2*n-1, M_val),
                     method='HiGHS', bounds=[(0, None)]*n)
        return res
