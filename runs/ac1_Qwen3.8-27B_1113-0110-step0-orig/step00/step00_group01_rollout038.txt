Let me analyze this problem carefully.

We need to minimize:
J(a) = 2n · max(convolve(a, a)) / (sum(a))²

where a is a non-negative sequence of length n.

The key insight is that this is related to the "sidon set" or "B_h sequences" problem in combinatorics. The self-convolution max_b represents the maximum number of collisions (pairs that sum to the same value), and we want to minimize this relative to the sum squared.

For a sequence of all 1s of length n:
- convolve gives a triangle: 1, 2, 3, ..., n, n-1, ..., 1
- max_b = n
- sum_a = n
- J = 2n · n / n² = 2

So the all-ones sequence gives exactly 2.

To do better than 2, we need to reduce the peak of the self-convolution relative to the sum squared.

Key observation: If we think of the sequence as a measure, the self-convolution at position k tells us how much "mass" is at positions i and j with i+j=k. We want to spread out the mass so that no single sum is too concentrated.

This is essentially the problem of finding a "flat" sequence in terms of its autocorrelation.

Alternative: **Descent on the "energy" of the convolution.** Instead of just looking at the max, look at the sum of squares of the convolution (which is related to the L⁴ norm of the Fourier transform). This is a smooth function and has a well-defined gradient.

minimize sum_k (a*a)(k)² subject to sum(a) = 1, a ≥ 0.

The gradient of sum_k (a*a)(k)² w.r.t. a_m is:
4 * sum_k (a*a)(k) * d(a*a)(k)/da_m = 4 * sum_k (a*a)(k) * 2*a[k-m] = 8 * ((a*a) * a)(m)

where the last convolution is the "triple convolution"! This can be computed as:
((a*a) * a)(m) = (a * a * a)(m)

Using FFT: compute A = FFT(a), then triple_conv = IFFT(A³). This is O(n log n)!

So the gradient of the "energy" E = sum (a*a)² is:
∇E[m] = 8 * (a*a*a)(m)

And I can do gradient descent on E instead of M. The advantage is that E is smooth (actually, it's a polynomial in a, so it's C∞). The disadvantage is that minimizing E doesn't exactly minimize M, but they're correlated (a flat convolution has both low max and low energy).

This might be a better approach! Let me use it as the primary method and use M-based evaluation for tracking.

Here's the refined algorithm:
1. Minimize E(a) = sum_k (a*a)(k)² using gradient descent (or mirror descent).
2. The gradient is 8 * (a*a*a)(m), computable via FFT in O(n log n).
3. Use mirror descent: a ← max(0, a - η * ∇E) or a ← a * exp(-η * ∇E / max(∇E)).
4. Track the actual score 2n*M.

This should be much faster per iteration since I only need one FFT (for a*a*a) and one for scoring (a*a). Actually, I can compute a*a from the same FFT: if A = FFT(a), then a*a = IFFT(A²) and a*a*a = IFFT(A³).

So per iteration:
1. Compute A = FFT(a, 2n) [or use scipy's fftconvolve which does this internally]
2. conv2 = IFFT(A²) = a*a
3. conv3 = IFFT(A³) = a*a*a
4. Update a.

This is 2 FFTs + 1 IFFT per iteration, which is very fast.
