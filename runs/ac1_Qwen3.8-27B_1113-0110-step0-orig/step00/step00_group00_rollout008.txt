    = sum_i [1 + eps*(f_i + f_{k-i}) + eps^2 * f_i * f_{k-i}]

The linear term: eps * sum_i (f_i + f_{k-i}) = eps * [sum_i f_i + sum_i f_{k-i}]

For the first sum: sum_i f_i (over valid i) depends on k.
For the second sum: sum_i f_{k-i} = sum_j f_j (over valid j = k-i).

So both sums are essentially "the sum of f over the overlap region", which for large k (near the center) is approximately sum_all f_i, and for small k (near the edges) is smaller.

This means the perturbation delta_c_k = eps * 2 * S(k) where S(k) is the sum of f over the overlap at lag k.

For a uniform f (f_i = c for all i), S(k) = c * overlap_length(k), and delta_c_k is proportional to the overlap length, which is the same triangular shape. This doesn't help (it just scales the same pattern).

For a non-uniform f, we can shape the perturbation. We want delta_c_k to be negative at the center and positive at the edges.

Since S(k) = sum of f over the overlap, and the overlap is largest at the center, if f values are negative at the center and positive at the edges, then S(k) would be negative at the center and positive at the edges. But f can't be negative (well, a = 1 + eps*f must be non-negative, so f > -1/eps).

So the perturbation approach works: make f negative in the middle and positive at the edges (within bounds). This reduces the central peak.

But this is just first-order. For a meaningful reduction (25%), we need eps to be of order 0.5 or more, which is beyond first-order accuracy. So we need the full iterative approach.

Uses FFT-based convolution, top-K active lag tracking, and adaptive step sizing.

Key insight: symmetric sequences are bounded below by 2.0, so we search

import numpy as np

def _fft_convolve(a):
    """Compute full linear self-convolution of a using FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size *= 2
    A = np.fft.rfft(a, size=size)
    C = A * A
    return np.fft.irfft(C, size=size)[:2 * n - 1]


def _subgradient(active_mask, a):
    """Compute subgradient s[i] = sum_k active_mask[k] * a[k-i] for valid k-i."""
    n = len(a)
    # Use correlate: np.correlate(h, a, 'valid')[i] = sum_j h[i+j]*a[j]
    # which equals sum_k h[k]*a[k-i] with k=i+j
    result = np.correlate(active_mask, a, mode='valid')
