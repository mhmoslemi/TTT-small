c[1] = 2xy
c[2] = 2xz + y²
c[3] = 2yz
c[4] = z²

We want to minimize max(x², 2xy, 2xz+y², 2yz, z²).

By symmetry, set x = z:
c = [x², 2xy, 2x²+y², 2xy, x²], 2x+y=1.
Max = max(x², 2x(1-2x), 2x²+(1-2x)²)
= max(x², 2x-4x², 6x²-4x+1)

At x=1/4, y=1/2:
x² = 1/16, 2x-4x² = 1/2-1/4 = 1/4, 6x²-4x+1 = 6/16-1+1 = 6/16 = 3/8
max = 3/8. Score = 2*3*3/8 = 9/4 = 2.25.

At x=1/3, y=1/3:
x² = 1/9, 2x-4x² = 2/3-4/9 = 2/9, 6x²-4x+1 = 6/9-4/3+1 = 1/3
max = 1/3. Score = 2.

At x=0, y=1:
c = [0, 0, 1, 0, 0]. max = 1. Score = 6.

So for n=3 symmetric, the best is x=1/3 (uniform) with score 2. Or maybe slightly off?
