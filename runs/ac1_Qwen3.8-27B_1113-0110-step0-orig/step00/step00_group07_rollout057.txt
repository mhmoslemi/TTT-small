- The pairs with the largest products contribute most to C[k*]
- For the largest product pair (i, j) where i+j=k* and a[i]*a[j] is large:

  - This reduces the product (and hence C[k*]) while keeping sum constant

```python
def balance_peak(a, k_star, alpha=0.1):
    """Balance pairs (i, k_star-i) to reduce C[k_star]."""
    n = len(a)
    lo = max(0, k_star - n + 1)
    hi = min(n - 1, k_star)
    if lo > hi:
        return a
    a_new = a.copy()
    for i in range(lo, hi + 1):
        j = k_star - i
        if i == j:
            continue
        if i < j:  # Only process each pair once
            # Transfer from larger to smaller
            diff = a[i] - a[j]
            transfer = alpha * abs(diff) / 2
            if a[i] > a[j]:
                a_new[i] -= transfer
                a_new[j] += transfer
            else:
                a_new[i] += transfer
                a_new[j] -= transfer
    return np.maximum(a_new, 0)
```
