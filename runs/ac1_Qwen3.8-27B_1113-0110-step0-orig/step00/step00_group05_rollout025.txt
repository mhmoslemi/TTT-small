`2n * max(convolve(a,a)) / (sum(a))^2`

Let's define `s = sum(a)` and normalize so that `s = 1` (we can always scale). Then we want to minimize `2n * max(convolve(a,a))` subject to `sum(a) = 1, a >= 0`.

This is equivalent to: find a non-negative sequence of length n, summing to 1, that minimizes the peak of its self-convolution.

The self-convolution `b = convolve(a, a)` satisfies:
- `b >= 0` (since a >= 0)
- `sum(b) = 1`
- `b` is a "valid" self-convolution (it has the structure of being a convolution of a non-negative sequence with itself)
- `b[0] = a[0]^2`, `b[2n-2] = a[n-1]^2`
- `b` is symmetric: `b[k] = b[2n-2-k]`

So we want to minimize `max(b)` subject to `b` being symmetric, non-negative, summing to 1, and being a valid self-convolution of a non-negative sequence.

If we ignore the "valid self-convolution" constraint, the minimum of max(b) over symmetric non-negative b summing to 1 (length 2n-1) is `1/(2n-1)` (uniform), giving objective `2n/(2n-1) ≈ 1`.

But the constraint that b must be a self-convolution is binding.

Key structural properties of self-convolutions of non-negative sequences:
1. `b[k] = sum_i a[i]*a[k-i]` (with valid indices)
2. This means `b[k] >= a[i]*a[k-i]` for any valid i, k-i.
3. In particular, `b[k] >= a[0]*a[k]` for k < n, and `b[k] >= a[k-n+1]*a[n-1]` for k >= n.

These are strong constraints. For instance, if a[0] > 0, then b[k] >= a[0]*a[k] for all k < n, which means the first n elements of b are "dominated" by a scaled version of a.

This suggests that having a[0] = 0 (and a[n-1] = 0) can help, since then these constraints vanish.
