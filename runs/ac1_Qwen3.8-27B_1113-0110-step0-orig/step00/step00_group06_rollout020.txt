import numpy as np

def simplex_project(v, S):
    """Project vector v onto the simplex {x: sum(x) = S, x >= 0}."""
    n = len(v)
    if n == 0:
        return v
    # Find the threshold
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - S))[0]
    if len(rho) == 0:
        return np.full(n, S/n)
    rho = rho[-1]
    theta = (cssv[rho] - S) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

import numpy as np
import time

def simplex_project(v, S):
    """Project v onto {x: sum(x) = S, x >= 0}."""
    v = np.asarray(v, dtype=np.float64).copy()
    n = v.size
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - S)
    rho_candidates = np.where(cond)[0]
    if len(rho_candidates) == 0:
        return np.full(n, S / n)
    rho = rho_candidates[-1]
    theta = (cssv[rho] - S) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

Actually, let me reconsider. The problem is:
- Minimize f(a) = max_k conv(a)[k]
- Subject to: sum(a) = 1, a >= 0

f is convex (max of linear functions). The feasible set is a convex polytope (the simplex). So this is a convex optimization problem.

For convex problems, we can use:
1. Subgradient method (slow, O(1/sqrt(k)))
2. Ellipsoid method (polynomial in n and 1/epsilon, but impractical for n=5582)
3. Cutting-plane method (generate linear underestimators of f)
4. Barzilai-Borwein step size (empirically fast for subgradient methods)
5. Smoothing: approximate the max with a soft-max (log-sum-exp) to get a smooth objective, then use gradient methods

Option 5 is promising! The soft-max: `sigma(x) = (1/tau) * log(sum exp(tau * x_k))` approximates max(x_k) as tau -> infinity. For finite tau, it's smooth and we can use standard gradient methods.

The gradient of the soft-max: `d(sigma)/d(x_i) = exp(tau * x_i) / sum_j exp(tau * x_j)` (a softmax-like weight).

Then we can use projected gradient (or even Adam) with the soft-max objective.

Hmm, this requires the chain rule: `d(soft_max(conv))/d(a) = sum_k (softmax_weight[k]) * d(conv[k])/d(a)`.

The softmax weights are `exp(tau * conv[k]) / sum_j exp(tau * conv[j])`. For large tau, these concentrate on the max indices (converging to the subgradient we've been using).

The gradient computation:
```python
weights = np.exp(tau * conv - tau * conv.max())  # for numerical stability
weights /= weights.sum()
grad = np.zeros(n)
for k in range(2*n-1):
    if weights[k] < 1e-15:
        continue
    lo = max(0, k - n + 1)
    hi = min(n-1, k)
    ji = np.arange(lo, hi+1)
    ai = k - ji
    grad[ji] += 2.0 * weights[k] * a[ai]
```

This is O(n) per non-zero weight, and for moderate tau, only O(log(1/tau)) indices have significant weight. So it's still fast.

The step:

a_new = _simplex_project(a - alpha * grad, 1.0)
