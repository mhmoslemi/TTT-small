import numpy as np
import time

def project_simplex(v):
    """Project vector v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    # If all elements are already non-negative and sum to 1, return as is
    # Otherwise, use the water-filling algorithm
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.where(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)

OK this is getting very long. Let me just write the actual implementation.

Key computational steps per iteration:
1. C = np.convolve(s, s) — O(n log n) via FFT
2. weights = softmax(β * (C - C_max)) — O(n)
3. a_flip = s[::-1]
4. c = np.convolve(a_flip, weights)[n-1:2n-1] — O(n log n) via FFT
5. grad = 2 * c
6. direction = grad - mean(grad) (to preserve sum)
7. s_new = s - η * direction
8. s_new = project_simplex(s_new)

Steps 1 and 4 each use FFT, so they're O(n log n). For n = 4498, this should be fast.

Let me now think about the learning rate. I'll use a simple adaptive scheme:
- Start with η_0 = some initial value (e.g., 0.01)
- If the objective doesn't decrease, halve η
- If it decreases well, increase η slightly

Or I can use the Nesterov accelerated gradient method with a fixed decreasing step size.

Actually, for the soft-max approximation, the gradient is Lipschitz continuous (for fixed β), so I can use the standard gradient descent rate: η = 1/L where L is the Lipschitz constant.

import numpy as np

def project_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v.copy()
    # Water-filling algorithm
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho_candidates = np.arange(1, n+1)
    valid = u * rho_candidates > (cssv - 1)
    if not np.any(valid):
        return np.ones(n) / n
    rho = np.max(rho_candidates[valid]) - 1
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

    grad = 2.0 * grad_half
    
    return grad, C_max, weights
