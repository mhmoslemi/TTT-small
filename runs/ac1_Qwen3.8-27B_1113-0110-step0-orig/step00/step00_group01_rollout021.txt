1. Compute |FFT(a)|^2
2. Compute the "target" spectrum: flat (or inverse of current |FFT(a)|^2)
3. Update a to have the target spectrum
4. Project back to non-negative

This is similar to the GS (Gerchberg-Saxton) algorithm in ptychography.

5. A_new = A * (target / |A|^2)^0.5 = A * (1/|A|^2)^0.5 = A/|A| (unit magnitude!)

import numpy as np
import time

def compute_conv(a, fft_size):
    """Compute full linear convolution of a with itself via FFT."""
    A = np.fft.rfft(a, fft_size)
    conv = np.fft.irfft(A * A, fft_size)
    return conv[:2*len(a)-1]

def subgradient_step(a, conv, num_active, fft_size, n):
    """Compute subgradient of 2*n*max(conv) w.r.t. a."""
    max_val = conv.max()
    # Find indices near the maximum
    threshold = max_val * 0.99
    active = np.where(conv >= threshold)[0]
    
    if len(active) == 0:
        active = np.array([np.argmax(conv)])
    
    if len(active) > num_active:
        top = np.argsort(conv[active])[-num_active:]
        active = active[top]
    
    # Compute subgradient
    subgrad = np.zeros(n)
    for k in active:
        lo = max(0, k - n + 1)
        hi = min(k, n - 1)
        # subgrad[lo:hi+1] += a[k-hi : k-lo+1]
        subgrad[lo:hi+1] += a[k - hi : k - lo + 1]
    
    subgrad *= 2.0 / len(active)
    return subgrad, max_val

    lr = 0.5 / n
    momentum = 0.9
    v = np.zeros(n)
    num_active = 100
    
    it = 0
    no_improve = 0

        conv = compute_conv(a, fft_size)
        subgrad, max_val = subgradient_step(a, conv, num_active, fft_size, n)
        
        # Heavy ball momentum
        v = momentum * v + (1 - momentum) * subgrad
        a = a - lr * v * n  # Scale by n to get O(1) steps

Actually, I realize I should think more carefully about what makes a good sequence for this problem.

The key constraint: we want conv(a,a) to be as flat as possible. The "average" value is (sum a)^2/(2n-1). For sum a = 1, that's 1/(2n-1).

The peak is at (or near) the center for most reasonable sequences. To reduce the peak, we need to reduce the "concentration" of a.

One insight: if a is symmetric (a[i] = a[n-1-i]), then conv is also symmetric, and the peak is at the center. The center value is sum_i a[i]^2 (the energy). So for symmetric sequences, we want to minimize the energy sum(a[i]^2) subject to sum(a) = 1 and a >= 0. By Cauchy-Schwarz, the minimum energy is 1/n (achieved by a[i] = 1/n, the uniform sequence). But the uniform sequence has peak = 1/n at the center, and the "average" is 1/(2n-1). The ratio is (2n-1)/n ≈ 2.

To do better, we need a non-symmetric sequence! For a non-symmetric sequence, the peak might not be at the center, and the center value (sum a[i]*a[n-1-i]) might be less than sum a[i]^2.
