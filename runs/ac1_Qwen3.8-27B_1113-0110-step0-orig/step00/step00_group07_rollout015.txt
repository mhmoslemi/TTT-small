So we want to minimize max_k (p*p_full)[k] where p is a probability distribution on {0, ..., n-1}.

The minimum possible max is 1/(2n-1) (if the convolution were perfectly uniform), giving score = 2n/(2n-1) ≈ 1.

So the problem is: find a probability distribution p on {0,...,n-1} that minimizes the maximum of its self-convolution.

This is a well-studied problem! It's related to "minimum peak sensitivity" or "minimum autocorrelation" problems.

For non-negative probability distributions, what's the best we can do?

One approach: think of p as a probability mass function. The self-convolution (p*p)[k] = P(X+Y=k) where X and Y are i.i.d. with distribution p. We want to minimize the maximum point probability of X+Y.

This is equivalent to: given a distribution on {0,...,n-1}, minimize the maximum probability of any sum of two i.i.d. draws.

The sum X+Y lives on {0,...,2n-2} (2n-1 possible values). The total probability mass is 1, so by pigeonhole, max >= 1/(2n-1).

To achieve this bound, we'd need P(X+Y=k) = 1/(2n-1) for all k. This is possible if and only if the distribution of X+Y is uniform on {0,...,2n-2}.

When does the sum of two i.i.d. discrete variables have a uniform distribution?

If X is uniform on {0,...,n-1}, then X+Y (with Y also uniform on {0,...,n-1}) has a triangular distribution, not uniform.

For the sum to be uniform, we need a special structure. One possibility: if n is a prime and we use a cyclic group structure... but our domain is {0,...,n-1} with standard addition, not modular.

Actually, for the standard (non-modular) sum, it's impossible to get a perfectly uniform distribution of X+Y when X,Y are on {0,...,n-1}, because P(X+Y=0) = P(X=0)*P(Y=0) = p[0]^2, while P(X+Y=n-1) = sum_i p[i]*p[n-1-i]. These can't all be equal unless very specific conditions are met.

For P(X+Y=0) = p[0]^2 = 1/(2n-1), we need p[0] = 1/sqrt(2n-1).
For P(X+Y=2n-2) = p[n-1]^2 = 1/(2n-1), we need p[n-1] = 1/sqrt(2n-1).

But then p[0] + p[n-1] = 2/sqrt(2n-1), and the remaining n-2 entries must sum to 1 - 2/sqrt(2n-1).

For large n, 2/sqrt(2n-1) ≈ 2/sqrt(2n), so the remaining mass is approximately 1. This seems feasible.

But we also need P(X+Y=1) = p[0]*p[1] + p[1]*p[0] = 2*p[0]*p[1] = 1/(2n-1).
So p[1] = 1/(2*p[0]*(2n-1)) = 1/(2*(1/sqrt(2n-1))*(2n-1)) = sqrt(2n-1)/(2*(2n-1)) = 1/(2*sqrt(2n-1)).
