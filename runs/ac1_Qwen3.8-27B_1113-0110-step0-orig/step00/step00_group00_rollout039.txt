Actually, you know what, let me reconsider the problem from scratch.

The objective is: 2n * max(conv(a,a)) / sum(a)^2

For this to be < 2, we need max(conv(a,a)) < sum(a)^2 / n.

Now, sum(a)^2 / n = n * (mean(a))^2.

And max(conv(a,a)) >= conv(a,a)[n-1] = sum_j a[j] * a[n-1-j] (the center).

For a symmetric sequence, this equals sum(a[j]^2), and by Cauchy-Schwarz, sum(a[j]^2) >= (sum(a))^2/n.

But for a non-symmetric sequence, conv(a,a)[n-1] = sum_j a[j]*a[n-1-j] can be less than sum(a[j]^2).

However, max(conv(a,a)) could be at a different position than the center.

Let me think about what happens with a "ramp" sequence: a[j] = j+1 for j = 0, ..., n-1.

a = [1, 2, 3, ..., n]
sum = n(n+1)/2
sum^2 = n^2(n+1)^2/4
sum^2/n = n(n+1)^2/4

conv(a,a)[k] for the linear convolution:
c[k] = sum_{j=max(0,k-n+1)}^{min(k, n-1)} (j+1)(k-j+1)

For k = n-1 (center):
c[n-1] = sum_{j=0}^{n-1} (j+1)(n-j) = sum_{j=0}^{n-1} (j+1)(n-j)
= sum_{j=0}^{n-1} [nj - j^2 + n - j]
= sum_{j=0}^{n-1} [n(j+1) - j(j+1)]
= n * sum_{j=0}^{n-1}(j+1) - sum_{j=0}^{n-1} j(j+1)
= n * n(n+1)/2 - sum_{j=0}^{n-1}(j^2+j)
= n^2(n+1)/2 - [n(n-1)(2n-1)/6 + n(n-1)/2]
= n^2(n+1)/2 - n(n-1)(2n-1+3)/6
= n^2(n+1)/2 - n(n-1)(2n+2)/6
= n^2(n+1)/2 - n(n-1)(n+1)/3
= n(n+1)[n/2 - (n-1)/3]
= n(n+1)[(3n-2n+2)/6]
= n(n+1)(n+2)/6

So c[n-1] = n(n+1)(n+2)/6 for the ramp sequence.
