```python
        options = {'maxiter': int(budget / 3), 'ftol': 1e-7, 'disp': True}
        res = _minimize(score_fun, x0, method='L-BFGS-B', bounds=[(0, None)]*n_optimal, tol=1e-7, options=options)
        if res.success and float(res.x).sum() >= 0.01:
            return list(res.x)
    except:
        pass
    
    return list(HEIGHTS_1)  # Return uniform fallback if no improvement
```

1. Coefficients are normalized to sum≥0.01
2. Convolution metrics are accurate
3. Gradient descent respects simplex constraints
4. Adaptation steps occur while anticipating future improvements
