2. **Gradient-based methods** using a smooth approximation of the max.

4. **Iterative projection** - project onto the constraint that the convolution is below a threshold.

= sum_{j in J_k} [δ(j,i) * a_{k-j}] + sum_{j in J_k} [a_j * δ(k-j, i)]
= (if i in J_k) a_{k-i} + (if k-i in J_k) a_{k-(k-i)}
= (if i in J_k) a_{k-i} + (if k-i in J_k) a_i

Now, i in J_k iff max(0, k-n+1) <= i <= min(k, n-1) iff 0 <= k-i < n (given 0 <= i < n).
k-i in J_k iff max(0, k-n+1) <= k-i <= min(k, n-1) iff 0 <= i < n (given 0 <= k-i < n).

So both conditions are equivalent to: 0 <= k-i < n (given 0 <= i < n).

If 0 <= k-i < n:
- First term: a_{k-i}
- Second term: a_i
- Total: a_{k-i} + a_i

But wait, when i = k-i (k = 2i), the term j = i = k-i is counted only once in the sum, but we're getting two contributions. Let me check:
- First sum: j = i, valid (since i in J_k). Contribution: a_{k-i} = a_i.
- Second sum: j = k-i = i, valid (since k-i in J_k). Contribution: a_j = a_i.
- Total: 2*a_i.

But the actual derivative of a_i^2 is 2*a_i. ✓

When i ≠ k-i:
- First sum: j = i. Contribution: a_{k-i}.
- Second sum: j = k-i. Contribution: a_{k-i}.

Wait, that gives 2*a_{k-i}, not a_{k-i} + a_i. Let me recheck.

Second sum: sum_{j in J_k} a_j * δ(k-j, i) = a_{k-i} (when j = k-i is in J_k).

Hmm, δ(k-j, i) means k-j = i, i.e., j = k-i. So the contribution is a_{j} when j = k-i, which is a_{k-i}.

So total = a_{k-i} + a_{k-i} = 2*a_{k-i} (when i ≠ k-i).

And when i = k-i: total = a_i + a_i = 2*a_i = 2*a_{k-i}. Same formula!

So in all cases: dc_k/da_i = 2 * a_{k-i} (when 0 <= k-i < n), else 0.

Great, so the formula is: dc_k/da_i = 2 * a_{k-i} if 0 <= k-i < n, else 0.

This is essentially 2 * (a * a)[k-i]... no wait, it's 2 times the value of a at index k-i.

Now, for the smooth objective F(a) = log(sum_k exp(beta * c_k)):
∇_i F = (1/Z) * sum_k beta * exp(beta * c_k) * 2 * a_{k-i} * [0 <= k-i < n]

where Z = sum_k exp(beta * c_k).

Let w_k = beta * exp(beta * c_k) / Z. Then:
∇_i F = 2 * sum_k w_k * a_{k-i} * [0 <= k-i < n]
= 2 * sum_{j=0}^{n-1} w_{i+j} * a_j  (reindexing with j = k-i, so k = i+j)

Wait, k-i = j means k = i+j. So:
∇_i F = 2 * sum_{j=0}^{n-1} w_{i+j} * a_j * [0 <= i+j < 2n-1]

This is a cross-correlation-like operation between w and a!

So the gradient is: ∇_i F = 2 * (w * a)_i where * is a specific cross-correlation.

More precisely, if I define v_j = a_j and u_k = w_k, then:
∇_i F = 2 * sum_j u_{i+j} * v_j

This is like a "reversed convolution" or cross-correlation.

For the constraint sum(a) = 1 (normalization), the projected gradient is:
∇_i F - λ where λ = (1/n) * sum_j ∇_j F (to maintain sum = 1).

Or better, use the log-barrier for non-negativity and do multiplicative updates:
a_i <- a_i * exp(-eta * (∇_i F - mean(∇F))) (approximately)

Or use a multiplicative weight update:
a_i <- a_i / (1 + eta * ∇_i F) (or similar)

Actually, for the constraint a >= 0 and sum(a) = 1, a natural approach is:
- Compute the "potential" φ_i = sum_{k: 0<=k-i<2n-1} w_k * a_{k-i} (this is half the gradient)
- Update: a_i <- a_i * exp(-eta * (φ_i - mean(φ)))
- Renormalize.

Let me think about a simpler approach that might work well:

**Algorithm: Iterative Flattening**
1. Start with a non-negative sequence a (normalized).
2. Compute c = conv(a, a).
3. Compute "excess" e_k = c_k - mean(c) = c_k - (sum a)^2/(2n-1).
4. For each position i, compute how much reducing a_i would reduce the excess at the critical positions.
5. Update a_i in proportion to the excess it contributes.

A concrete version:
- For each i, the "contribution" to the max is: d_i = sum_{k: c_k = max} 2*a_{k-i} (from the gradient formula).
- Reduce a_i proportionally to d_i.

But this only works on the max positions, which might be too sparse.

Better: use the soft max (softmax) to get weights on all positions.
