Let me also think about whether there's a smarter approach to the continuous optimization.

The key insight: the objective is max_k corr(k). At the optimum, multiple shifts will be at (or near) the max. The subgradient points in the direction that decreases the average of the top-k correlations.

A better approach might be:
- Use a "log-sum-exp" smoothing: f(h) = (1/β) * log(sum_k exp(β * corr(k)))
- This is a smooth approximation of the max, and its gradient is well-defined
- As β → ∞, it approaches the max
- For the gradient: ∂f/∂h[i] = (1/β) * sum_k (β * ∂corr(k)/∂h[i]) * exp(β*corr(k)) / sum_j exp(β*corr(j))
  = sum_k (∂corr(k)/∂h[i]) * softmax(β * corr)k

This is essentially the soft-max gradient the previous code uses. The issue is choosing β.

Another idea: **proximal gradient with exact projection**. Instead of the soft-max, we can:
1. Compute the gradient at the current max shift
2. Take a step in that direction
3. Project back to the constraint set

This is a "constraint-following" approach where we always work on the worst shift.

Let me also consider: **Can we use the structure of the optimal solution?**

For the Erdős problem, the optimal h is believed to be close to a "balanced" sequence - one where the 1s are distributed as evenly as possible. This suggests h should be close to a square wave or a sequence with low autocorrelation.

A specific construction: h(x) = 1 if {x * α} < 0.5 for some irrational α. This gives a "Weyl sequence" that has good distribution properties. But this might not be optimal.

Another construction: Use a low-discrepancy sequence (like a van der Corput sequence) to place the 1s.

Let me try a hybrid approach:
1. Generate several candidate starting points (balanced random, Weyl-sequence-based, low-discrepancy)
2. Optimize each with the continuous method
3. Pick the best and do binary local search

Actually, I think the most impactful improvement will be in the local search phase. Let me focus on making the binary local search more effective:

1. **Parallel evaluation of all single swaps**: The previous code does this correctly with the D matrix.
2. **2-swap moves**: When no single swap improves, try 2-swaps. This is O(N⁴) naively, but we can be smarter.
3. **Adaptive perturbation**: When stuck, make a larger structural change (e.g., reverse a segment, or swap a block of bits).
4. **Multi-start**: Run the local search from several different starting points.

For the 2-swap, the key observation is:
- A 2-swap (turn off p1,p2 and turn on q1,q2) changes the correlation by D[p1]+D[p2]-Dz[q1]-Dz[q2]
- We want to minimize max_s (c[s] + D[p1,s] + D[p2,s] - Dz[q1,s] - Dz[q2,s])
- This is harder to optimize than single swap

A simpler 2-swap: just do two consecutive single swaps. If the first swap makes things worse but the second fixes it, the net effect is an improvement. This is essentially what simulated annealing does.

import numpy as np
import time

def fft_corr(h):
    N = len(h)
    L = 2 * N - 1
    H = np.fft.rfft(h, L)
    G = np.fft.rfft(np.flip(1.0 - h), L)
    return np.fft.irfft(H * G, L)

def compute_c5(h, N):
    return float(np.max(fft_corr(h))) * (2.0 / N)

def project_sum(h, target):
    h = np.clip(h, 0.0, 1.0)
    s = float(h.sum())
    if abs(s - target) < 1e-12:
        return h
    lo, hi = -1.0, 1.0
    for _ in range(40):
        mid = 0.5 * (lo + hi)
        if float(np.clip(h - mid, 0.0, 1.0).sum()) > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - 0.5 * (lo + hi), 0.0, 1.0)

def corr_grad_shift(s, h, N):
    g = np.zeros(N)
    if s == 0:
        g[:] = 1.0 - 2.0 * h
    elif s > 0:
        g[:N-s] += (1.0 - h[s:])
        g[s:] -= h[:N-s]
    else:
        m = -s
        g[m:] += (1.0 - h[:N-m])
        g[:N-m] -= h[m:]
    return g

def subgrad_opt(h_init, N, deadline, k=15, lr0=0.015, beta=0.88):
    h = h_init.astype(float).copy()
    target = N / 2.0
    dx = 2.0 / N
    best_h = h.copy()
    best_pk = float(np.max(fft_corr(h)))
    m = np.zeros(N)
    lr = lr0
    it = 0
    while time.time() < deadline:
        y = h + m
        corr = fft_corr(y)
        pk = float(np.max(corr))
        if pk < best_pk - 1e-15:
            best_pk = pk
            best_h = h.copy()
        idx = np.argpartition(corr, -k)[-k:]
        g = np.zeros(N)
        for ii in idx:
            s = int(ii - (N - 1))
            g += corr_grad_shift(s, y, N)
        g /= len(idx)
        h_new = project_sum(y - lr * g, target)
        m = beta * (h_new - h)
        h = h_new
        it += 1
        if it % 60 == 0:
            lr *= 0.997
        if it % 300 == 0:
            beta = min(0.95, 0.82 + it * 0.00008)
    return best_h, best_pk * dx

def ensure_binary(h, N):
    h_bin = (h > 0.5).astype(float)
    n1 = int(h_bin.sum())
    target = N // 2
    if n1 == target:
        return h_bin
    rng = np.random.RandomState(77)
    if n1 > target:
        ones = np.where(h_bin == 1)[0]
        idx = rng.choice(ones, n1 - target, replace=False)
        h_bin[idx] = 0
    else:
        zeros = np.where(h_bin == 0)[0]
        idx = rng.choice(zeros, target - n1, replace=False)
        h_bin[idx] = 1
    return h_bin

def build_delta_tables(h, N):
    """Precompute D[p, s] = change in correlation at shift s when h[p] flips from 1 to 0."""
    shifts = np.arange(2 * N - 1) - (N - 1)
    p_all = np.arange(N)[:, None]
    s_all = shifts[None, :]
    pm = p_all - s_all
    pp = p_all + s_all
    vm = (pm >= 0) & (pm < N)
    vp = (pp >= 0) & (pp < N)
    pm_c = np.clip(pm, 0, N - 1)
    pp_c = np.clip(pp, 0, N - 1)
    hm = np.where(vm, h[pm_c], 0.0)
    hp = np.where(vp, h[pp_c], 0.0)
    D = -(1.0 - hm) * vm.astype(float) + hp * vp.astype(float)
    return D

def local_search(h, N, deadline, max_sweeps=2000, perturb_every=25):
    h = ensure_binary(h, N)
    best_c = float(np.max(fft_corr(h)))
    best_h = h.copy()
    stall = 0
    rng = np.random.RandomState(55)

            break
        c = fft_corr(h)
        P = float(c.max())
        if P < best_c - 1e-13:
            best_c = P
            best_h = h.copy()
            stall = 0
        else:
            stall += 1
        
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        if len(ones) < 1 or len(zeros) < 1:
            break
        
        D = build_delta_tables(h, N)
        Dz = D[zeros, :]
        
        best_new_P = P
        best_pq = None
        for p in ones:
            base = c + D[p, :]
            cand = base[None, :] - Dz
            npk = cand.max(axis=1)
            mi = int(np.argmin(npk))
            if npk[mi] < best_new_P - 1e-15:

                for _ in range(n_r):

                    q = int(zeros[rng.randint(len(zeros))])

                stall = 0
            else:
                # Try 2-swap

    return best_h, best_c * (2.0 / N)
