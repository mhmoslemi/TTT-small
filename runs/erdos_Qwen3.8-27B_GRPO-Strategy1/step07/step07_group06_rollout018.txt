```python
def quick_max_corr(h, critical_lags, N):
    """Compute max correlation at given critical lags only"""
    # For each lag k (0-indexed from N-1 in full correlate),
    # corr at lag k = sum h[i] * (1-h[i+k]) for valid i
    mx = 0
    for lag in critical_lags:
        # lag is offset from center (N-1)
        if lag >= 0:
            # i ranges from 0 to N-1-lag
            vals = h[:N-lag] * (1 - h[lag:N])
        else:
            M = -lag
            vals = h[M:N] * (1 - h[:N-M])
        c = vals.sum()
        if c > mx:
            mx = c
    return mx
```

This is much faster than FFT for checking a few lags! For N=380 and checking 10-20 lags, each check is O(N) = 380 ops, vs O(N log N) for FFT.
