Coordinate descent: for each i, find the optimal h[i] (given all other h[j]) that minimizes the max correlation. This is a 1D problem (bisection on h[i]) that can be solved exactly for each i.

For a fixed h[i] = t (0 ≤ t ≤ 1), the correlation at shift L is:

The contribution from i depends on t and the relationship between i and L. This is linear in t for each shift! So corr_L(t) = a_L * t + b_L for some coefficients a_L, b_L.

The max over L is then max_L (a_L * t + b_L), which is a piecewise linear function of t. I can find the t that minimizes this max by finding the intersection points.

This is a 1D optimization that can be done in O(N) time per coordinate. With N=380, one full pass takes O(N²) = 144,400 operations. That's fast!
