        return h
    lo, hi = -1.0, 1.0

            M = -s

Hmm, let me think again. corr_k = sum_i h[i]*(1-h[i+k]). This is quadratic in h.

For binary h, h[i]*(1-h[i+k]) is either 0 or 1. Specifically:

- Otherwise: contributes 0

So corr_k = number of positions i where h[i]=1 and h[i+k]=0.

This is equivalent to: corr_k = #{(i, i+k) : h[i]=1, h[i+k]=0}

For a balanced binary sequence, this is related to the "boundary" between 1s and 0s at scale k.

        if cF2 < bc: bc, bh = cF2, hF2

    final_c5 = c5_of(bh)
    return bh, final_c5, len(bh)
