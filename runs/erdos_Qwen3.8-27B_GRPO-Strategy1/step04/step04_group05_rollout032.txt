**Key insight**: The problem is nearly convex in h (it's a max of bilinear functions). If we fix the constraint sum(h)=N/2, the feasible set is a hyperplane intersected with a hypercube.

**Approach: Frank-Wolfe (conditional gradient) method**

The FW method for min f(h) s.t. h in S (convex):
- At each step, solve min_{l in S} <g, l> where g is a subgradient
- Move: h_new = (1-t)h + t*l

The extreme points of {0≤h≤1, sum(h)=N/2} are the binary vectors with exactly N/2 ones.

So the linear subproblem is: given gradient g, find the binary vector e with N/2 ones that minimizes <g, e>. This means: pick the N/2 smallest components of g.

This is O(N log N) per iteration! Very fast.

And the step size can be t = 2/(s+2) where s is the iteration count, or we can use line search.

```python
def frank_wolfe(h, N, iterations, deadline):
    target = N / 2.0
    h = h.copy()
    best_h = h.copy()
    best_peak = float(np.max(compute_corr(h)))
    
    for it in range(iterations):
        if time.time() > deadline:
            break
        corr = compute_corr(h)
        peak = float(np.max(corr))
        if peak < best_peak:
            best_peak = peak
            best_h = h.copy()
        
        # Find top K lags for subgradient
        K = 10
        top_k = np.argpartition(corr, -K)[-K:]
        # Weights: proportional to how close to max
        vals = corr[top_k]
        weights = np.exp((vals - vals.max()) * 10)  # Sharpen
        weights /= weights.sum()
        
        # Compute subgradient
        grad = np.zeros(N)
        center = N - 1
        for wk, ki in zip(weights, top_k):
            L = ki - center
            if L == 0:
                grad += wk * (1.0 - 2.0 * h)
            elif L > 0:
                grad[:N-L] += wk * (1.0 - h[L:])
                grad[L:] -= wk * h[:N-L]
            else:
                M = -L
                grad[:N-M] += -wk * h[M:]  # Wait, let me recheck
                grad[M:] += wk * (1.0 - h[:N-M])
        
        # Solve linear subproblem: min <grad, l> s.t. l binary, sum(l)=N/2
        # Pick N/2 smallest components of grad
        # l[i] = 1 if grad[i] is in bottom N/2
        thresh_idx = N // 2
        l = (np.argsort(grad) < thresh_idx).astype(float)
        # Verify sum
        # (argsort gives exactly N/2 indices, so sum = N/2)
        
        # Combine
        s = it + 1
        t = 2.0 / (s + 2)
        h_new = (1 - t) * h + t * l
        h_new = project_sum(h_new, target)
        
        # Line search
        best_t = t
        best_val = float(np.max(compute_corr(h_new)))
        for trial_t in [t*0.5, t*0.75, t*1.25, t*1.5]:
            h_trial = (1 - trial_t) * h + trial_t * l
            h_trial = project_sum(h_trial, target)
            val = float(np.max(compute_corr(h_trial)))
            if val < best_val:
                best_val = val
                best_t = trial_t
        h = (1 - best_t) * h + best_t * l
        h = project_sum(h, target)
    
    return best_h, best_peak * (2.0/N)
```

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_sum(h, target):
    h = np.clip(h, 0.0, 1.0)
    s = float(h.sum())

    lo, hi = -2.0, 2.0
