    m = np.max(corr)
    return m + np.log(np.sum(np.exp(T * (corr - m)))) / T

def project(h, n):
    target = n / 2.0

            hi = mid
        else:

Actually, is it? c_k(h) = Σ_m h[m+k]·(1-h[m]). If we vary h[i] while keeping all other h[j] fixed:
- For lag k where m=i appears: h[i]·(1-h[i-k]) or (1-h[i+k])·h[i]
- For lag k where m+k=i: h[i]·(1-h[i-k])
- For lag k where m=i and m+k=i: h[i]·(1-h[i]) (only at k=0, which is 0 for binary)

So c_k as a function of h[i] is either:
- h[i]·c (linear increasing)
- (1-h[i])·c (linear decreasing)
- h[i]·(1-h[i]) (concave, but only at k=0)
- or a constant

The max of these is the max of linear and constant functions, which is convex. So yes, it's convex (piecewise linear, convex) as a function of h[i]. Golden section will find the global minimum.
