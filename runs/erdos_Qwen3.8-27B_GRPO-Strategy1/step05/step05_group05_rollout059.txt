For k < 0, let k = -p where p > 0. Valid n is [p, n-1].
- i-k = i+p is valid: p ≤ i+p ≤ n-1 → 0 ≤ i ≤ n-1-p = n-1+
  i+p ≥ p: i ≥ 0 (always)
  i+p ≤ n-1: p ≤ n-1-i
  So term appears when 0 ≤ p ≤ n-1-i, i.e., -(n-1-i) ≤ k < 0.

- j-k = j+p: valid when p ≤ j+p ≤ n-1 → 0 ≤ j ≤ n-1-p. So 0 ≤ p ≤ n-1-j.
