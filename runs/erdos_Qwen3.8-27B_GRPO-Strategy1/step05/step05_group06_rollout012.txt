For a convex piecewise linear function f(t) = max_m(a_m + b_m*t) on [0,1]:
- The minimum is at a point where the subgradient contains 0, or at a boundary.
- I can find this by:
  1. Compute f(0) and f(1).
  2. The slope of f at any point is the sum of b_m for active m's (those achieving the max).
  3. Use a "walk" algorithm: start at t=0, find active set, compute slope. If slope < 0, increase t until active set changes. If slope > 0, we're at the minimum (or boundary).

The "walk" algorithm:
- At current t, active set A = {m: a_m + b_m*t = f(t)}
- slope = sum_{m in A} b_m
- If slope >= 0: t is the minimizer (or very close)
- If slope < 0: need to increase t. Find the next breakpoint:
  For m not in A: t_m = (a_m - a_{m'}) / (b_{m'} - b_m) for some m' in A where b_{m'} > b_m
  Take the smallest positive t_m. Increase t to that value, update active set.
- If slope <= 0 at t=1: t=1 is the minimizer.

This is O(m) per step, and there are at most m steps. Total O(m²) = ~100k per coordinate. That's slower than minimize_scalar.
