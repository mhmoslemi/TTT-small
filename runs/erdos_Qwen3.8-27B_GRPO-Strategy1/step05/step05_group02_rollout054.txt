    if s_low2 <= s_high2:
        s_vals2 = np.arange(s_low2, s_high2+1)
        j_vals2 = i - s_vals2  # = i-s
        delta[s_vals2 + n-1] += -val_change * h[j_vals2]
    
    return delta

But even O(n) per candidate is a lot if we check all O(n²) possible swaps. Let me think about a smarter approach.

For a swap of positions i and j (h[i]=1, h[j]=0):
- Effect on correlation: combination of flip-at-i (1→0) and flip-at-j (0→1)
- Total delta = delta_for_1_to_0(i) + delta_for_0_to_1(j)
- New max = max(old_corr + total_delta)

We can precompute the current correlation and the "threshold" (current max). Then for a swap to be improving, we need:
- All correlation values that were at the max must decrease (or at least not increase)
- No new correlation value exceeds the old max
