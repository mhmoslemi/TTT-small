Actually, one more idea: **subgradient method** for the max. The subgradient of max_k c_k at a non-differentiable point is the convex hull of the active gradients. I can use a Frank-Wolfe (conditional gradient) approach:

1. At current h, compute c_k and identify active set A = {k: c_k ≈ max}
2. Compute subgradient g = (1/|A|) ∑_{k∈A} ∇c_k
3. Solve: min_{v ∈ [0,1]^n, sum(v)=n/2} g·v (this is just: set v[i]=1 where g[i]<0 and v[i]=0 where g[i]>0, with sum constraint)
4. h ← h + α(g·v direction)

This is the Frank-Wolfe algorithm! And it's simple to implement. The inner problem is:
min g·v s.t. 0≤v≤1, sum(v)=n/2

The solution is: sort g, set v[i]=1 for the n/2 smallest g[i], v[i]=0 for the rest, and interpolate at the boundary.

This is O(n log n) per iteration!

Let me add this as an additional optimization phase.

                jh = j + lag

        # Actually, let me do this more carefully
        order = np.argsort(g)
        v = np.zeros(n)
        v[order[:n//2]] = 1.0
        # Step

        h_new = proj_h(h_new, n)

        if c5_new < best_c5:
