```python
    hm = np.where(vm, h[pm_c], 0.0)
    return -(1.0 - hp) * vp.astype(float) + hm * vm.astype(float)
```

Wait, I want to double-check this. E[p,L] should be the delta to corr[L] when h[p] goes 1→0.

delta_off(p, L) = -(1-h[p+L])*I(p+L valid) + h[p-L]*I(p-L valid)

So E[p, L] = -(1-h[p+L])*vp + h[p-L]*vm.

In the code above:
- `pp = pos + sv` = p + L, `vp` = valid(p+L)
- `pm = pos - sv` = p - L, `vm` = valid(p-L)
- `hp = h[p+L]` (where valid), `hm = h[p-L]` (where valid)
- E = -(1-hp)*vp + hm*vm = -(1-h[p+L])*vp + h[p-L]*vm ✓

And for the swap (p off, q on):
new_corr[L] ≈ corr[L] + E[p,L] - E[q,L]

(the approximation ignores the overlap terms when p±L = q or q±L = p)

Now for the search:

```python
def swap_local_search(h, N, deadline, max_sweeps=2000, sample_p=150, sample_q=150):

                break

        zeros = np.where(h == 0)[0]
        if len(ones) < 1 or len(zeros) < 1:
            break

        # Sample
        if len(ones) > sample_p:

        if len(zeros) > sample_q:

        else:

        best_pq = None
```

Actually, the vectorized operation `cand = base[None, :] - E[q_list, :]` creates an array of shape (sample_q, 2N-1). For sample_q=150, 2N-1=759, that's 150*759 = 114K elements. Actually, let me reconsider. The bottleneck is the matrix subtraction and max. Let me think about optimizing.

For a fixed p, base = c + E[p]. Then I need to find q that minimizes max_L (base[L] - E[q,L]).

This is equivalent to: find q that minimizes max_L (base[L] - E[q,L]).

The key observation: E[q,L] is a "sparse" vector (nonzero only at specific L values for each q). But computing the max over L for each q is still O(N) per q.

Alternative: I can limit the search to the top-k lags (where corr is largest) and only check those. This is an approximation but much faster.

Let me use this approach:
1. Find the top k lags (e.g., k=20)
2. For those lags only, compute the max after swap
3. This reduces the problem to O(sample_p * sample_q * k)

```python
        else:

        else:
            q_list = zeros

        for p in p_list:
```

Now let me think about the continuous optimization. The previous code uses Nesterov. Let me try Adam with a smoothed max (log-sum-exp):

f(h) = (1/tau) * log(sum_k exp(tau * corr_k))

where tau is a temperature. As tau→∞, this approaches the max. For finite tau, we get a smooth approximation.

The gradient of log-sum-exp:
∂f/∂h[i] = (1/tau) * sum_k exp(tau*corr_k) * tau * (∂corr_k/∂h[i]) / sum_k exp(tau*corr_k)
= sum_k softmax_k * (∂corr_k/∂h[i])

where softmax_k = exp(tau*corr_k) / sum_j exp(tau*corr_j).

import numpy as np

def fft_corr(h):
    N = len(h)
    L = 2 * N - 1
    H = np.fft.fft(h, L)
    G = np.fft.fft(np.flip(1.0 - h), L)
    return np.real(np.fft.ifft(H * G))

def compute_c5(h, N):
    return float(np.max(fft_corr(h))) * (2.0 / N)

def project_sum(h, target):
    h = np.clip(h, 0.0, 1.0)
    s = float(h.sum())
    if abs(s - target) < 1e-10:
        return h
    lo, hi = -1.0, 1.0
    for _ in range(50):
        mid = (lo + hi) * 0.5
        if float(np.clip(h - mid, 0.0, 1.0).sum()) > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) * 0.5, 0.0, 1.0)

def make_E(h, N):
    idx = np.arange(2*N-1)
    shifts = idx - (N-1)
    pos = np.arange(N)[:, None]
    sv = shifts[None, :]
    pp = pos + sv
    pm = pos - sv
    vp = (pp >= 0) & (pp < N)
    vm = (pm >= 0) & (pm < N)
    pp_c = np.clip(pp, 0, N-1)
    pm_c = np.clip(pm, 0, N-1)
    hp = np.where(vp, h[pp_c], 0.0)
    hm = np.where(vm, h[pm_c], 0.0)
    return -(1.0 - hp)*vp.astype(np.float64) + hm*vm.astype(np.float64)
