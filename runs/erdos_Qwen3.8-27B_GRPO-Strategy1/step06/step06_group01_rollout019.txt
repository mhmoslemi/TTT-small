```python
def fft_corr(h):
    N = len(h)
    L = 2 * N - 1
    H = np.fft.fft(h, L)
    G = np.fft.fft(np.flip(1.0 - h), L)
    return np.real(np.fft.ifft(H * G))

def compute_c5(h, N):

def project_sum(h, target):
```

```python
            grad[:N-L] -= h[L:]
        else:
            M = -L
            grad[:N-M] += (1.0 - h[M:])
            grad[M:] -= h[:N-M]
        
        # Also add lag-0 penalty gradient (to keep lag-0 small)
        # Lag 0: ∑h[i](1-h[i]), gradient = 1-2h for each i
        # But weighted small to not dominate
        grad += 0.1 * (1.0 - 2.0 * h)
        
        # Find the position most able to reduce the top correlation
        # while not increasing other top correlations too much
        # Simply: take a step in -gradient direction
        h_new = project_sum(h - 0.003 * grad, target)
        
        # Check improvement
        corr_new = fft_corr(h_new)
        c_new = float(corr_new.max())
        if c_new < best_c - 1e-10:
            h = h_new
            corr = corr_new
            best_c = c_new
            best_h = h.copy()
    
    return best_h, best_c * (2.0 / N)
```

Hmm, but this is very slow (one FFT per iteration). For N=380, one FFT takes maybe 50μs. 5000 iterations = 0.25s. That's fine.

But the step size of 0.003 might be too small or too large. Let me use adaptive step size.

Actually, I realize there's a much better approach for the final polish. Since we're very close to binary:

1. Start from binary solution (or nearly binary)
2. Identify the 1-3 positions where making a fractional value would most reduce the max correlation
3. Set those positions to optimal fractional values (solving a small subproblem)
4. Re-project for the sum constraint

This is a "sparse continuous" approach. Let me think about it:

If I change exactly one position from 1 to v (where v < 1):
- Lag-0: increases by (1-v)v = v - v²
- Lag L: changes by (v-1)*(1-h[i+L]) + (1-v)*h[i-L]... 

Actually this is getting complicated with the sum constraint. If I change h[j] from 1 to v, I need to compensate elsewhere to maintain the sum. The simplest compensation: change h[j'] from 0 to 1-v. But that's a coupled change.

Alternatively: change h[j] from 1 to 1-ε, and h[j'] from 0 to ε. The sum is preserved. The effect on correlations:
- For each lag L: Δcorr_L = -(ε*(1-h[j+L]) - ε*h[j-L]) + (ε*(1-h[j'+L]) - ε*h[j'-L])
  = -ε*(1-h[j+L]-h[j-L]) + ε*(1-h[j'+L]-h[j'-L])

We want to minimize the max over L of (corr_L + Δcorr_L).

This is a 2-variable optimization (choice of j, j' and ε). For a given (j, j'), the optimal ε minimizes the max. This can be solved analytically or by bisection.

But the search over (j, j') pairs is O(N²) ≈ 144k for N=380. For each pair, solving for optimal ε is O(log(1/δ)). Total: ~144k * 20 = 3M operations. Very fast!

Let me implement this:

    """Try all pairs (j, j') and find optimal epsilon for each."""
    h = h_bin.astype(float).copy()
    corr = fft_corr(h)
    best_c = float(corr.max())
    best_h = h.copy()
    
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]

    # ∂corr_L/∂h[j] = (1-h[j+L]) - h[j-L] (with boundary: missing terms = 0)
    # For the change h[j]: 1→1-ε, h[j']: 0→ε:
    # Δcorr_L = -ε*g_L[j] + ε*g_L[j'] where g_L[j] = ∂corr_L/∂h[j]
    # = ε*(g_L[j'] - g_L[j])
    
    # We want: max_L (corr_L + ε*(g_L[j'] - g_L[j])) < best_c
    # i.e., for all L: ε*(g_L[j'] - g_L[j]) < best_c - corr_L
    
    # This gives: ε < (best_c - corr_L) / (g_L[j'] - g_L[j]) for all L where g_L[j'] - g_L[j] > 0
    # And: ε > (best_c - corr_L) / (g_L[j'] - g_L[j]) for L where g_L[j'] - g_L[j] < 0
    # (but we want corr_L + ε*(...) < best_c, so if coeff < 0, decreasing corr_L, which helps)
    
    # Actually: we want corr_L + ε*d_L < best_c for all L
    # where d_L = g_L[j'] - g_L[j]
    # If d_L > 0: ε < (best_c - corr_L) / d_L
    # If d_L < 0: ε > (best_c - corr_L) / d_L (which is negative, always satisfied for ε > 0)
    # If d_L = 0: need corr_L < best_c (already true)
    
    # So the constraint is: 0 ≤ ε ≤ min_{L: d_L > 0} (best_c - corr_L) / d_L
    # We want the LARGEST ε (to reduce the top correlation most)
    # But also ε ≤ 1 (can't go below 0)
    
    # Optimal: ε* = min(1, min_{L: d_L > 0} (best_c - corr_L) / d_L)
    # Then check: does this actually reduce the max?
    # New max = max_L (corr_L + ε* * d_L)

    # g_L[j] = (1-h[j+L]) - h[j-L] for valid j
    # This is: g_L = (1-h) shifted by -L minus h shifted by +L
    # In FFT terms, this is related to the derivative of the correlation
    
    # For each (j, j') pair:

    # Need to compute min over L where d_L > 0 of (best_c - corr_L) / d_L

    # G[L, j] = ∂corr_L / ∂h[j]
