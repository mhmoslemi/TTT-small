Let me also add a "correlation cache" approach: since we're only changing 2 elements, we can compute the delta to corr in O(N) without FFT:

When h[p] changes from 1 to 0 and h[q] from 0 to 1:
- The correlation C[m] = sum_i h[i] * (1-h[i+m-N+1]) changes by:
  - Remove contribution of h[p]=1: subtract (1-h[p+m-N+1]) for valid m
  - Add contribution of (1-h)[p] going from 0 to 1: add h[i] for i where i+m-N+1=p
  - Add contribution of h[q]=1 (new): add (1-h[q+m-N+1]) for valid m
  - Remove contribution of (1-h)[q] going from 1 to 0: subtract h[i] for i where i+m-N+1=q

Let me implement this:

```python
def swap_change(h, p, q):
    """Compute ΔC when h[p]:1→0 and h[q]:0→1. O(N) without FFT."""
    N = len(h)
    L = 2*N - 1
    dC = np.zeros(L)
    
    # h[p]: 1→0
    # Remove: (1-h)[p+m-N+1] for m where 0≤p+m-N+1<N → m in [N-1-p, 2N-2-p]
    lo = max(N-1-p, 0)
    hi = min(2*N-2-p, L-1)
    if lo <= hi:
        m_vals = np.arange(lo, hi+1)
        j_vals = p + m_vals - N + 1
        dC[lo:hi+1] -= (1.0 - h[j_vals])
    
    # (1-h)[p]: 0→1
    # Add: h[i] for m where i+m-N+1=p → m = p-i+N-1, i in [0,N-1] → m in [p, p+N-1]
    lo = max(p, 0)
    hi = min(p+N-1, L-1)
    if lo <= hi:
        m_vals = np.arange(lo, hi+1)
        i_vals = p + N - 1 - m_vals
        dC[lo:hi+1] += h[i_vals]
    
    # h[q]: 0→1
    # Add: (1-h)[q+m-N+1] for m where 0≤q+m-N+1<N → m in [N-1-q, 2N-2-q]
    lo = max(N-1-q, 0)
    hi = min(2*N-2-q, L-1)
    if lo <= hi:
        m_vals = np.arange(lo, hi+1)
        j_vals = q + m_vals - N + 1
        dC[lo:hi+1] += (1.0 - h[j_vals])
    
    # (1-h)[q]: 1→0
    # Remove: h[i] for m where i+m-N+1=q → m = q-i+N-1, i in [0,N-1] → m in [q, q+N-1]
    lo = max(q, 0)
    hi = min(q+N-1, L-1)
    if lo <= hi:
        m_vals = np.arange(lo, hi+1)
        i_vals = q + N - 1 - m_vals
        dC[lo:hi+1] -= h[i_vals]
    
    return dC
```

For the "remove (1-h)[q]" term: we subtract h[i_vals]. If i_vals includes p, then h[p] was 1 (old), so we subtract 1. Correct.
