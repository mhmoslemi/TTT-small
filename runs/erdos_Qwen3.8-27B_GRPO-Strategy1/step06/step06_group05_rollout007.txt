Actually, I realize I should double-check the correlation formula. The problem says:
C₅ = max_k ∫ h(x)(1-h(x+k)) dx

And the evaluation is: C₅ = max(np.correlate(h, 1-h, mode="full")) * dx

np.correlate(a, v, 'full') computes:
c[m] = sum_n a[n] * conj(v[n+m-(len(v)-1)]) for m = 0, ..., len(a)+len(v)-2

So for a=h (length N), v=1-h (length N):
c[m] = sum_n h[n] * (1-h)[n+m-(N-1)] for m = 0, ..., 2N-2

The integral ∫ h(x)(1-h(x+k)) dx is approximated by sum_i h[i] * (1-h[i+k_dx]) * dx

where k_dx is the shift in discrete units.

For shift s (in discrete units), the integral is:
sum_i h[i] * (1-h[i+s]) * dx (with h out of range = 0)

What index m in np.correlate corresponds to shift s?
c[m] = sum_n h[n] * (1-h[n+m-N+1])

If we want the sum over i of h[i]*(1-h[i+s]), that's:
sum_i h[i] * (1-h[i+s])

Comparing: we need n+m-N+1 = i+s, i.e., m = N-1+s.
So c[N-1+s] = sum_i h[i]*(1-h[i+s]) for s >= 0 (and the shift ranges from -(N-1) to N-1).

So the max over all shifts s in [-(N-1), N-1] of sum_i h[i]*(1-h[i+s]) gives the max correlation.

def fft_corr(h):
    N = len(h)
    L = 2 * N - 1
    H = np.fft.rfft(h, L)
    G = np.fft.rfft(np.flip(1.0 - h), L)
    return np.fft.irfft(H * G, L)

    N = len(h)
    return float(np.max(fft_corr(h))) * (2.0 / N)

            lo = mid
        else:
            hi = mid

def grad_power(h, p=30):
    N = len(h)
    L = 2*N - 1
    c = fft_corr(h)
    w = np.where(c > 0, c**(p-1), 0.0)
    if w.sum() == 0:
        return np.zeros(N)
    w /= w.sum()  # normalize for numerical stability
    jm = np.arange(N)[:, None]
    km = np.arange(L)[None, :]
    i1 = km + (N-1) - jm
    v1 = (i1 >= 0) & (i1 < N)
    i2 = km - jm
    v2 = (i2 >= 0) & (i2 < N)
    i1c = np.clip(i1, 0, N-1)
    i2c = np.clip(i2, 0, N-1)
    t1 = (np.where(v1, (1-h)[i1c], 0.0) * w[None, :]).sum(axis=1)
    t2 = (np.where(v2, h[i2c], 0.0) * w[None, :]).sum(axis=1)
    return t1 - t2

def continuous_opt(h, N, deadline, p=30, lr0=0.04):

    v = np.zeros(N)

    lr = lr0
    t = 0
    while time.time() < deadline:
        t += 1
        g = grad_power(h, p)
        g -= g.mean()
        m = b1*m + (1-b1)*g
        v = b2*v + (1-b2)*g*g
        mh = m/(1-b1**t)
        vh = v/(1-b2**t)
        h = project(h + lr*mh/(np.sqrt(vh)+eps), target)
        c = c5_val(h)
        if c < best_c:
            best_c = c
            best = h.copy()
        if t % 200 == 0:
            lr *= 0.92
    return best, best_c
