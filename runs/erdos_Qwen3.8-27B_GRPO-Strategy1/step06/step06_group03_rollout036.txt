delta[j] = Σ_{n ∈ affected} [h_new[n+s_j]*(1-h_new[n]) - h[n+s_j]*(1-h[n])]

where affected = {n : n = p or n = q or n+s_j = p or n+s_j = q}

For a fixed (p,q) pair, affected n values are: {p, q, p-s_j, q-s_j} which can have up to 4 distinct values.

For vectorization: I can precompute for each position i in h, the contribution to the correlation delta. But this is essentially what np.correlate does.

Actually, the most efficient correct approach for the algorithm:

1. Compute the full new correlation: c_new = fft_corr(h_new) where h_new differs from h only at p and q.
2. But this is O(N log N) per candidate, which is too slow for 150*150 candidates.

Alternative: Use the structure of the change. Since only 2 positions change, I can compute the delta in O(N):

delta_p[j] for h[p] 1→0:
  For each j: the terms affected are those where n+s_j = p or n = p.
  - n+s_j = p → j = center + p - n. For valid n: j ranges over center + p - n for n in [0, N-1] ∩ [p-(N-1), p].
    At these j, s_j = p-n, and the delta is -(1-h[n]) (from the h[n+s] factor changing).
