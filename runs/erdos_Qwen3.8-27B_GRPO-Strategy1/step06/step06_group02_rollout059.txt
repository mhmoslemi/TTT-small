    """Compute the change in correlation vector for swap p:1->0, q:0->1"""
    # Lags range from -(N-1) to N-1, indexed as 0 to 2N-2
    L = np.arange(-(N-1), N)  # actual lags
    # Term 1: h[p-L] where 0<=p-L<N
    t1 = np.where((p-L >= 0) & (p-L < N), h[p-L], 0.0)
    # Term 2: -(1-h[p+L]) where 0<=p+L<N, for binary this is -h[p+L] + 1
    # Actually: -(1-h[p+L]) = h[p+L] - 1
    t2 = np.where((p+L >= 0) & (p+L < N), h[p+L] - 1.0, 0.0)

- Compute new_maxes = max over L of (C + base + M1 - M2) for all q simultaneously

new_max_q = max over L of C_plus_base[L] + M1[q,L] - M2[q,L]

This is equivalent to: for each q, take the element-wise sum of C_plus_base with (M1[q] - M2[q]) and find the max.

In numpy: (C_plus_base[None,:] + M1 - M2).max(axis=1)

This creates a (nz, 2N-1) temp array. Unavoidable for the direct approach.
