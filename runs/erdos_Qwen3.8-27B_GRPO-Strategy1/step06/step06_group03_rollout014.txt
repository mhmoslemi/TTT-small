Δ(L) = -(1 - h[p+L]) + (1 - h'[q+L]) + h[p-L](1-h'[p]) - h[q-L](1-h'[q])

where h' is after the swap. This simplifies to:

Since h[p]=1, h[q]=0:
- (1 - h[p+L]) = 1 - h[p+L] (old value at the h[i] position for i=p)
- After swap, h'[q]=1, so the new h[i] contribution at i=q is (1 - h'[q+L])
  - If q+L = p: h'[p] = 0, so 1 - 0 = 1
  - If q+L = q: h'[q] = 1, so 1 - 1 = 0 (but i=q, so this is 1*(1-1) = 0)
  - Otherwise: 1 - h[q+L]
- h[p-L] * (1 - h'[p]): h'[p] = 0, so this is h[p-L] * 1 = h[p-L] (if p-L valid)
- h[q-L] * (1 - h'[q]): h'[q] = 1, so this is h[q-L] * 0 = 0 (if q-L valid)
  Old value was h[q-L] * (1-0) = h[q-L]
  So change is 0 - h[q-L] = -h[q-L]

Special cases:
- If p+L = q: then 1 - h[p+L] = 1 - h[q] = 1. And for the q+L term, q+L = q+L (not p unless 2L=0).
  Wait, p+L = q means L = q-p.
- If q+L = p: then L = p-q = -(q-p). And 1 - h'[q+L] = 1 - h'[p] = 1 - 0 = 1.
- If p-L = q: then L = p-q. And h[p-L] = h[q] = 0.
- If q-L = p: then L = q-p. And h[q-L] = h[p] = 1.

So the formula becomes:
Δ(L) = [-(1-h[p+L]) if p+L valid] + [(1-h'[q+L]) if q+L valid] + [h[p-L] if p-L valid] + [-h[q-L] if q-L valid]

- If q+L = q: h'[q] = 1, so 1-1 = 0
- Else: 1-h[q+L]

And h[p-L] (old h, since we're computing the change):
- If p-L = q: h[q] = 0
- If p-L = p: h[p] = 1 (but L=0)
- Else: h[p-L]

And h[q-L] (old h):
- If q-L = p: h[p] = 1
- If q-L = q: h[q] = 0 (but L=0)
- Else: h[q-L]
