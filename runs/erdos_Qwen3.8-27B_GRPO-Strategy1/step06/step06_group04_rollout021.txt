    grad = np.zeros(N)

            continue

            if M < N:

                grad[:seg] += w[k_idx] * (1.0 - h[M:])
                grad[M:] -= w[k_idx] * h[:seg]

One approach: vectorize the swap evaluation. Instead of doing 30 sequential FFTs, compute the effect of 30 candidate swaps in parallel using the swap delta formula.

For a candidate swap (p, q):
- delta_C = effect of h[p]: 1→0 plus effect of h[q]: 0→1
- The new C = C_old + delta_C
- The new max = max(C_old + delta_C)

If I can compute delta_C for 30 candidates in vectorized numpy, that's much faster than 30 FFTs.

Let me derive the vectorized swap delta:

For h[p]: 1→0:
- Forward (L >= 0, C index N-1+L):
  - p as h[i+L] (i=p-L): valid for L=0..p. C[N-1+L] -= (1-h[p-L])
  - p as h[i] (i=p): valid for L=0..N-1-p. C[N-1+L] += h[p+L]
- Backward (L < 0, M=-L, C index N-1-M):
  - p as h[i] (i=p): valid for M=1..p. C[N-1-M] -= (1-h[p-M])
  - p as h[i-M] (i=p+M): valid for M=1..N-1-p. C[N-1-M] += h[p+M]

For h[q]: 0→1:
- Forward:
  - q as h[i+L] (i=q-L): valid for L=0..q. C[N-1+L] += (1-h[q-L])
  - q as h[i] (i=q): valid for L=0..N-1-q. C[N-1+L] -= h[q+L]
- Backward:
  - q as h[i] (i=q): valid for M=1..q. C[N-1-M] += (1-h[q-M])
  - q as h[i-M] (i=q+M): valid for M=1..N-1-q. C[N-1-M] -= h[q+M]

So the total delta for swap (p,q):
- C[N-1+L] for L=0..N-1: 
  += h[p+L] (if L<=N-1-p) - (1-h[p-L]) (if L<=p) + (1-h[q-L]) (if L<=q) - h[q+L] (if L<=N-1-q)
  (with the convention that h[x]=0 for x<0 or x>=N)

- C[N-1-M] for M=1..N-1:
  += h[p+M] (if M<=N-1-p) - (1-h[p-M]) (if M<=p) + (1-h[q-M]) (if M<=q) - h[q+M] (if M<=N-1-q)

This can be written as:
delta_forward[L] = h[p+L] * (L<=N-1-p) - (1-h[p-L]) * (L<=p) + (1-h[q-L]) * (L<=q) - h[q+L] * (L<=N-1-q)
for L = 0, 1, ..., N-1

delta_backward[M] = h[p+M] * (M<=N-1-p) - (1-h[p-M]) * (M<=p) + (1-h[q-M]) * (M<=q) - h[q+M] * (M<=N-1-q)
for M = 1, 2, ..., N-1

And C_new = C + delta where delta[N-1+L] = delta_forward[L] and delta[N-1-M] = delta_backward[M].

For vectorized computation of 30 candidates, I can create a (30, N) array and compute all deltas at once. Then max(C + delta) for each candidate.

    target = N / 2.0

    best_h = h.copy()
    best_pk = float(np.max(fft_corr(h)))
    y = h.copy()  # Nesterov momentum position
    lr = lr0
    beta = 0.85
    temp = temp0
    stall = 0
    
    while time.time() < deadline:
        C = fft_corr(y)
        pk = float(np.max(C))
        if pk < best_pk - 1e-14:
            best_pk = pk
            best_h = y.copy()
            stall = 0
        else:
            stall += 1
        
        # Subgradient at top-k peaks
        top = np.argpartition(C, -k_peaks)[-k_peaks:]
        C_top = C[top]
        w = np.exp((C_top - C_top.max()) / max(temp, 1e-10))
        w /= w.sum()
        
        grad = np.zeros(N)
        center = N - 1
        for wi, ai in zip(w, top):
            if wi < 1e-8:
                continue
            L = int(ai - center)
            if L == 0:
                grad += wi * (1.0 - 2.0 * y)
            elif L > 0:
                seg = N - L
                grad[L:N] += wi * (1.0 - y[:seg])
                grad[:seg] -= wi * y[L:N]
            else:
                M = -L
                if M < N:
                    seg = N - M
                    grad[:seg] += wi * (1.0 - y[M:N])
                    grad[M:N] -= wi * y[:seg]

        h_prev = h.copy()
        h = project_sum(y - lr * grad, target)
        beta_new = (1 + np.sqrt(1 + 4 * beta * beta)) / 2
        y = h + beta_new * (h - h_prev)
        y = np.clip(y, 0.0, 1.0)
        
        if stall > 300:

            h = project_sum(h, target)
            y = h.copy()
            lr = max(lr, lr0 * 0.8)
            stall = 0
        
        if stall % 100 == 0:
            lr = max(0.002, lr * 0.998)
            temp = max(0.0005, temp * 0.997)
