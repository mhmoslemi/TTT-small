Key insight: the previous program uses random sampling in the IL search (sample_sz=60-90). This means it doesn't explore all possible moves. With N=380, there are 190 ones and 190 zeros, so 190*190 = 36100 possible swaps. Evaluating all of them per iteration is O(36100 * 2N) ≈ 36100 * 760 ≈ 27M operations. In numpy, this is very fast (< 1 second).

So my main improvement: **exhaustive swap search** instead of random sampling.

For each swap (i in ones, j in zeros):
- New max = max(corr + inc_i - inc_j)
- Pick the swap with minimum new max

To make this efficient:
- Precompute inc_i for all i (N vectors of length 2N-1): O(N²)
- For each (i,j): compute max of (corr + inc_i - inc_j): this is a vector op of length 2N-1

Total: N² * (2N-1) ≈ 54M for N=380. In numpy with vectorization over i (but not j), this is:
- For each i (190 iterations): compute corr + inc_i (length 759), then for each j (190): max(corr + inc_i - inc_j)
  - This is 190 * 190 * 759 ≈ 27M ops per i... no wait.
  
Let me re-think the vectorization:
- For fixed i: A = corr + inc_i (length 759)
- For all j simultaneously: B[j] = max(A - inc_j) for j in zeros
  - This is: for each j, max over k of (A[k] - inc_j[k])
  - In numpy: B = np.max(A[None,:] - inc_j[zeros][:,:], axis=1) → shape (190, 1)
  - This is 190 * 759 ≈ 144K ops per i
- Total: 190 * 144K ≈ 27M ops per full sweep

In numpy, 27M simple ops take about 0.1-0.5 seconds. So we can do multiple sweeps per second.

```python
def exhaustive_swap_search(h, N, deadline, max_sweeps=100):
    h = h.astype(float).copy()
    corr = fft_corr(h)
    best_c = float(np.max(corr))
    
    # Precompute flip increments for all positions
    # inc[i] = change in corr if h[i] flips 1→0
    inc = np.zeros((N, 2*N-1))
    center = N - 1
    for i in range(N):
        # As h[j], j=i: k from -i to N-1-i
        k_lo = max(0, center - i)  # index in output
        k_hi = min(2*N-2, center + N-1-i)
        # h[i+k] - 1 for k in [-i, N-1-i]
        ks = np.arange(-i, N-i)
        valid = (ks >= -(N-1)) & (ks <= N-1)
        idx = ks + center
        inc[i, idx] += h[i + ks] - 1.0  # for 1→0
        
        # As h[j+k], j=i-k: k from i-N+1 to i
        k_lo2 = max(-(N-1), i-N+1)
        k_hi2 = min(N-1, i)
        ks2 = np.arange(k_lo2, k_hi2+1)
        idx2 = ks2 + center
        inc[i, idx2] += h[(i - ks2)]  # for 1→0, Δ = h[i-k]
    
    best_h = h.copy()
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        ones = np.where(h > 0.5)[0]
        zeros = np.where(h < 0.5)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        best_val = best_c
        best_i, best_j = -1, -1
        
        for i in ones:
            A = corr + inc[i]  # corr if we flip i: 1→0
            # For each j in zeros: new_corr = A - inc[j] (since flipping j: 0→1 is -inc[j])
            # Wait: inc[j] is the change for j: 1→0. For j: 0→1, the change is -inc[j].
            # So if we flip i (1→0) AND flip j (0→1): change = inc[i] + (-inc[j]) = inc[i] - inc[j]
            # new_corr = corr + inc[i] - inc[j]
            # max_new = max(corr + inc[i] - inc[j]) = max(A - inc[j])
            
            new_vals = np.max(A[None, :] - inc[zeros][:, :], axis=1)
            min_idx = np.argmin(new_vals)
            if new_vals[min_idx] < best_val - 1e-12:
                best_val = new_vals[min_idx]
                best_i, best_j = i, zeros[min_idx]
        
        if best_i >= 0:
            h[best_i] = 0
            h[best_j] = 1
            corr = fft_corr(h)
            best_c = float(np.max(corr))
        else:
            break
    
    return h, best_c
```

Wait, the increment computation in the loop is O(N) per i, and we have N positions, so O(N²) total for precomputation. Let me vectorize:

Actually, for the increment at position i:
- Part 1: h[i+k] - 1 for k in range(-i, N-i), clipped to valid range
- Part 2: h[i-k] for k in range(i-N+1, i+1), clipped to valid range

This is essentially a segment of h. Let me precompute more carefully.

For position i, the increment (1→0 flip) at lag k (where k is the actual shift, -N+1 to N-1):
- Contribution as h[j] (j=i): valid when 0 ≤ i+k < N, i.e., -i ≤ k ≤ N-1-i
  Δ = h[i+k] - 1
- Contribution as h[j+k] (j+k=i, j=i-k): valid when 0 ≤ i-k < N, i.e., i-N+1 ≤ k ≤ i
  Δ = h[i-k]

So inc[i, k] = (h[i+k] - 1) * [−i ≤ k ≤ N−1−i] + h[i−k] * [i−N+1 ≤ k ≤ i]

This is a simple formula. For all i simultaneously:
inc[i, k] depends on h[i+k] and h[i-k], which are different elements of h.

I can vectorize this using advanced indexing:
```python
ks = np.arange(-(N-1), N)  # all lags
# For each i, valid k range 1: [-i, N-1-i]
# valid k range 2: [i-N+1, i]
```

This is a bit complex to fully vectorize. For N=380, the O(N²) loop (380² = 144K iterations) is fine.

Let me also think about the subgradient approach:

For continuous h ∈ [0,1]^N with sum constraint:
C₅(h) = max_k corr_k(h) * 2/N

Subgradient of corr_k w.r.t. h:
∂corr_k/∂h[i] = (1-h[i+k])*[valid1] - h[i-k]*[valid2]

The subgradient of C₅ is the average of ∂corr_k for k achieving the max.

Steepest descent: h_new = h - lr * subgrad, then project to [0,1]^N with sum constraint.

The projection to {h ∈ [0,1]^N : sum(h) = N/2} is done by:
1. h - μ for some μ (shift)
2. Clip to [0,1]
3. Find μ such that sum = N/2 (bisection)

This is the same project_01 function from before.

For the learning rate, I can use a diminishing schedule: lr_t = c / sqrt(t) or fixed with restart.

```python
import numpy as np
import time

def fft_corr(h):
    N = len(h)
    L = 2*N - 1
    H = np.fft.fft(h, L)
    G = np.fft.fft(np.flip(1.0-h), L)
    return np.real(np.fft.ifft(H*G))

def compute_c5(h):
    N = len(h)
    return float(np.max(fft_corr(h))) * (2.0/N)

def project_01(h, target):
    h = np.clip(h, 0, 1)
    s = h.sum()
    if abs(s - target) < 1e-10:
        return h
    lo, hi = -1.0, 1.0
    for _ in range(60):
        mid = (lo+hi)/2
        if np.clip(h-mid, 0, 1).sum() > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h-(lo+hi)/2, 0, 1)

def subgrad_descent(h, N, deadline, k_top=30):
    h = h.astype(float).copy()
    target = N/2.0
    best_h = h.copy()
    best_c = compute_c5(h)
    itr = 0
    while time.time() < deadline:
        corr = fft_corr(h)
        top_idx = np.argsort(corr)[-k_top:]
        # Compute subgradient: average of gradients at top lags
        grad = np.zeros(N)
        center = N - 1
        for ai in top_idx:
            k = int(ai - center)
            if k == 0:
                grad += (1 - 2*h)
            elif k > 0:
                grad[k:] += (1 - h[:N-k])
                grad[:N-k] -= h[k:]
            else:
                m = -k
                if m < N:
                    grad[:N-m] += (1 - h[m:])
                    grad[m:] -= h[:N-m]
        grad /= len(top_idx)
        
        lr = 0.5 / (1 + itr*0.02)
        h_new = project_01(h - lr*grad, target)
        
        c_new = compute_c5(h_new)
        if c_new < best_c:
            best_c = c_new
            best_h = h_new.copy()
        
        # Momentum
        if not hasattr(subgrad_descent, '_m'):
            subgrad_descent._m = np.zeros(N)
        subgrad_descent._m = 0.8*subgrad_descent._m + 0.2*grad
        h = project_01(h - 0.3*lr*subgrad_descent._m, target)
        itr += 1
    
    return best_h, best_c
```

```python
import numpy as np
import time

def fft_corr(h):
    N = len(h)
    L = 2*N - 1
    H = np.fft.fft(h, L)
    G = np.fft.fft(np.flip(1.0 - h), L)
    return np.real(np.fft.ifft(H * G))

def compute_c5(h):
    N = len(h)
    return float(np.max(fft_corr(h))) * (2.0 / N)

def project_01(h, target):
    h = np.clip(h, 0.0, 1.0)
    s = h.sum()
    if abs(s - target) < 1e-12:
        return h
    lo, hi = -1.0, 1.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        if np.clip(h - mid, 0, 1).sum() > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0, 1)

def build_increments(h, N):
    inc = np.zeros((N, 2*N - 1))
    center = N - 1
    for i in range(N):
        k1_lo = max(-(N-1), -i)
        k1_hi = min(N-1, N-1-i)
        ks = np.arange(k1_lo, k1_hi + 1)
        inc[i, ks + center] += h[i + ks] - 1.0
        k2_lo = max(-(N-1), i - (N-1))
        k2_hi = min(N-1, i)
        ks2 = np.arange(k2_lo, k2_hi + 1)
        inc[i, ks2 + center] += h[i - ks2]
    return inc

def exhaustive_il(h, N, deadline, max_sweeps=500):
    h = h.astype(np.float64).copy()
    best_h = h.copy()
    corr = fft_corr(h)
    best_c = float(np.max(corr))
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        ones = np.where(h > 0.5)[0]
        zeros = np.where(h < 0.5)[0]
        if len(ones) < 1 or len(zeros) < 1:
            break
        inc = build_increments(h, N)
        best_val = best_c
        best_i, best_j = -1, -1
        for i in ones:
            A = corr + inc[i]
            cands = np.max(A[None, :] - inc[zeros], axis=1)
            mi = int(np.argmin(cands))
            if cands[mi] < best_val - 1e-14:
                best_val = float(cands[mi])
                best_i, best_j = i, zeros[mi]
        if best_i < 0:
            break
        h[best_i] = 0.0
        h[best_j] = 1.0
        corr = fft_corr(h)
        mc = float(np.max(corr))
        if mc < best_c:
            best_c = mc
            best_h = h.copy()
        else:
            h[best_i] = 1.0
            h[best_j] = 0.0
            corr = fft_corr(h)
            break
    return best_h, best_c * (2.0 / N)

def anneiled_il(h, N, deadline, temp0=0.01, cooling=0.997, max_sweeps=400):
    h = h.astype(np.float64).copy()
    best_h = h.copy()
    corr = fft_corr(h)
    best_c = float(np.max(corr))
    temp = temp0
    rng = np.random.RandomState(123)
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        ones = np.where(h > 0.5)[0]
        zeros = np.where(h < 0.5)[0]
        if len(ones) < 1 or len(zeros) < 1:
            break
        inc = build_increments(h, N)
        best_val = best_c
        best_i, best_j = -1, -1
        for i in ones:
            A = corr + inc[i]
            cands = np.max(A[None, :] - inc[zeros], axis=1)
            mi = int(np.argmin(cands))
            if cands[mi] < best_val - 1e-14:
                best_val = float(cands[mi])
                best_i, best_j = i, zeros[mi]
        if best_i < 0:
            if rng.random() < temp:
                best_i = int(rng.choice(ones))
                best_j = int(rng.choice(zeros))
            else:
                break
        h[best_i] = 0.0
        h[best_j] = 1.0
        corr = fft_corr(h)
        mc = float(np.max(corr))
        if mc < best_c:
            best_c = mc
            best_h = h.copy()
        else:
            accept = np.log(1.0 + 1e-10) > -1.0 / temp
            if not accept:
                h[best_i] = 1.0
                h[best_j] = 0.0
                corr = fft_corr(h)
            if rng.random() < temp * 0.5:
                p = int(rng.choice(ones))
                q = int(rng.choice(zeros))
                h[p] = 0.0
                h[q] = 1.0
                corr_new = fft_corr(h)
                if float(np.max(corr_new)) >= mc:
                    h[p] = 1.0
                    h[q] = 0.0
                    corr = corr
            else:
                corr = fft_corr(h)
        temp *= cooling
    return best_h, best_c * (2.0 / N)

def subgrad_cont(h, N, deadline, k_top=40):
    h = h.astype(np.float64).copy()
    target = N / 2.0
    best_h = h.copy()
    best_pk = float(np.max(fft_corr(h)))
    mom = np.zeros(N)
    itr = 0
    center = N - 1
    while time.time() < deadline:
        corr = fft_corr(h)
        pk = float(np.max(corr))
        if pk < best_pk:
            best_pk = pk
            best_h = h.copy()
        top = np.argsort(corr)[-k_top:]
        grad = np.zeros(N)
        for ai in top:
            k = int(ai - center)
            if k == 0:
                grad += (1.0 - 2.0 * h)
            elif k > 0:
                grad[k:] += (1.0 - h[:N-k])
                grad[:N-k] -= h[k:]
            else:
                m = -k
                if m < N:
                    grad[:N-m] += (1.0 - h[m:])
                    grad[m:] -= h[:N-m]
        grad /= float(len(top))
        lr = 0.8 / (1.0 + 0.05 * itr)
        mom = 0.85 * mom + 0.15 * grad
        h = project_01(h - lr * mom, target)
        itr += 1
        if itr % 500 == 0 and itr > 2000:
            break
    return best_h, best_pk * (2.0 / N)
```
