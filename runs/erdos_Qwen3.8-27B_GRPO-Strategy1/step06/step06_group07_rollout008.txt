Let j = m-M: sum_{j=0}^{N-1-M} h[j] * (1-h[j+M])

So:
- For L ≥ 0: corr(L) = sum_{m=0}^{N-1-L} h[m+L] * (1-h[m])
- For L < 0: corr(L) = sum_{m=-L}^{N-1} h[m+L] * (1-h[m]) = sum_{j=0}^{N-1+L} h[j] * (1-h[j-L])

Let me unify: corr(L) = sum_{j: 0≤j<N, 0≤j+L<N} h[j+L] * (1-h[j])

Now, the effect of changing h[p] by δ:
h[p] appears in:
1. The h[j+L] factor when j+L = p, i.e., j = p-L. Contribution: δ * (1-h[p-L]) if 0 ≤ p-L < N and 0 ≤ p < N.
2. The (1-h[j]) factor when j = p. Contribution: h[p+L] * (-δ) if 0 ≤ p < N and 0 ≤ p+L < N.

Total: δ*(1-h[p-L]) - δ*h[p+L] = δ*(1 - h[p-L] - h[p+L])

where h[out_of_range] = 0.

So A[p][L_index] where L = L_index - (N-1):
A[p][L] = h[p-L] + h[p+L] (with OOB = 0)

And the effect of changing h[p] by δ is: δ * (1 - A[p])

For a swap (p: 1→0, q: 0→1): δ_p = -1, δ_q = +1
new_corr = corr + (-1)*(1-A[p]) + (+1)*(1-A[q])
= corr - 1 + A[p] + 1 - A[q]
= corr + A[p] - A[q]

OK so the formula IS: new_corr = corr + A[p] - A[q].
