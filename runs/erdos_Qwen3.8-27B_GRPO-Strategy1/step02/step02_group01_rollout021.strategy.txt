The step function h_i(x) : [0,2] → [0,1] with samples at x_i = i/(n-1)*2 (adjustments for resolution handled via interpolation)

**Objective Function**:  
Minimize C = \max_k ∫\_{-∞}^∞ h(x)(1-h(x+k)) dx  
Discrete: \max(k) (np.correlate(h, 1-h, mode='full') * (2/n)

**Variables**:  
h ∈ [0,1] with integral constrained to exactly 1/2 per unit interval

**Optimality Conditions**:  
While the problem is non-convex, we approximate it with a smoothed version to enable gradient-based optimization:
C_smooth(h,T) = [1/n] * ∑_{k} min(1, T*(∫ h(x)g_k(x)dx - μ))  (where g_k(x) is the shifted delta function)

This problem is then solved using a bounded optimization approach with equality constraints.

   ```python
   def project_feasible(h, n=None):
       h_temp = np.clip(h.copy(), 0.0, 1.0)
       n_here = n if n is not None else len(h_temp)
       target = n_here / 2.0
       current_sum = np.sum(h_temp)
       
       # Simple projection until integral condition met
       while not (np.abs(current_sum - target) < 1e-6 and all(0<=x<=1 for x in h_temp)):
           diff = target - current_sum
           if abs(diff) < 1e-6:
               break
           room = 1 - h_temp if diff > 0 else h_temp
           room_sum = np.sum(room)
           h_temp += (diff / room_sum) if room_sum > 1e-6 else 0
           current_sum += (diff / room_sum) * room_sum if room_sum > 1e-6 else 0
   ```

3. **Gradient Calculation**:

   ```python
   def compute_overlap(h):
   ```
