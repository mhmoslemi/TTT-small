Let me try yet another approach: **Frank-Wolfe (conditional gradient method)**.

The FW method works on the polytope P = {h ∈ [0,1]^N, sum(h) = N/2}.
- Linear oracle: given a linear function c^T h, find h ∈ P that minimizes c^T h.
  For our P, the solution is: set the |c|_smallest N/2 coordinates to 1 and the rest to 0.
  (Because we want to maximize c^T h, so set h=1 where c is most negative and h=0 where c is most positive.)
  
  Wait, we want to MINIMIZE the objective, so we use the gradient g = -grad_obj.
  The FW step: h_FW = argmin_{z ∈ P} g^T z = set z=1 where g is most negative (bottom N/2), z=0 otherwise.
  
- FW update: h_{t+1} = (1-γ_t) h_t + γ_t h_FW
  where γ_t = 2/(t+2) or from line search.

This is interesting because it naturally stays on the polytope (convex combination of points in P is in P). And the linear oracle is just a sort + threshold, which is O(N log N).
