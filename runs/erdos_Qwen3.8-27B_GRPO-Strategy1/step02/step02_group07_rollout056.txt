Wait, for coordinate descent: if I fix all h[i] except h[j], the objective becomes:
C(h) = max_k [sum_i h[i]*(1-h[i+m_k])]

For a specific lag k with shift m_k:
C_{m_k} = sum_i h[i] - sum_i h[i]*h[i+m_k]

As a function of h[j] (with others fixed):
C_{m_k}(h[j]) = ... + h[j] - h[j]*h[j+m_k] - h[j-m_k]*h[j] + ...
= ... + h[j]*(1 - h[j+m_k] - h[j-m_k]) + ...

This is linear in h[j]! So the optimum is at h[j]=0 or h[j]=1 (the boundary), unless the coefficient of h[j] is 0 (then any value works).

But we have the max over k, and the sum constraint. So it's not simply a 1D problem.

Actually, for the max: C(h) = max_k C_{m_k}(h). If I only change h[j], each C_{m_k} changes linearly in h[j]. The max of linear functions is convex in h[j]. So the minimum over h[j] ∈ [0,1] is at a breakpoint (where two correlations are equal) or at 0 or 1.

This is a "minimax" subproblem in 1D. I can solve it by:
1. For each k, compute the coefficient a_k = 1 - h[j+m_k] - h[j-m_k]
2. C_{m_k}(h[j]) = B_k + a_k * h[j] where B_k is the part not involving h[j]
3. Find h[j] ∈ [0,1] that minimizes max_k (B_k + a_k * h[j])

This is a 1D minimax of linear functions, solvable by checking all breakpoints.
