corr[k] = Σᵢ h[i] * (1-h[i+k]) (with appropriate bounds)

d(corr[k])/d(h[j]) = (1-h[j+k]) - h[j-k] (with appropriate bounds)

This is the cross-correlation of (1-h) with a delta at position j+k, minus the cross-correlation of h with a delta at position j-k.

Actually, for the full correlation:

d(corr_full[k])/d(h[j]) = g[j+k] - h[j-k] = (1-h[j+k]) - h[j-k]

(with appropriate index bounds, treating out-of-bounds as 0)

The log-sum-exp gradient:
LSE(x) = max_i x_i + log(Σ exp(x_i - max_i))
d LSE / d x_j = exp(x_j - max) / Σ exp(x_i - max) = softmax(x)_j

So d smooth_c5 / d h[j] = dx * Σ_k softmax_k * ((1-h[j+k]) - h[j-k])

    # Create a (2n-1) x n matrix where row k has the vector d(corr[k])/d(h) 
    # Then grad = soft @ matrix + penalty_grad

    #   element j: g[j+k-(n-1)] - h[j-k+n-1] (OOb=0)
    # = g shifted by (k-(n-1)) - h shifted by (n-1-k)
    # 
    # g shifted by s: g_shifted_s[j] = g[j+s] if valid, else 0
    # This is np.roll(g, -s) with OOB zeroed... not quite.
    
    # For a shift s, "g shifted by s" means the element at position j is g[j+s] (if in bounds).
    # This is like taking g and shifting it left by s positions.
    
    # I can precompute all shifts using scipy or just do:
    # shift_g(s, j) = g[j+s] if 0<=j+s<n else 0
    # shift_h(s, j) = h[j+s] if 0<=j+s<n else 0
    
    # For the gradient:
    # grad_raw[j] = sum_k soft[k] * (shift_g(k-n+1, j) - shift_h(n-1-k, j))
    #            = sum_k soft[k] * shift_g(k-n+1, j) - sum_k soft[k] * shift_h(n-1-k, j)
    
    # First term: sum_k soft[k] * g[j+k-n+1]
    # Let s = k-n+1 (ranges from -(n-1) to n-1)
    # = sum_s soft[s+n-1] * g[j+s]
    
    # I can compute this as: for each s, add soft[s+n-1] * (g shifted by s) to the result.
    # "g shifted by s" at position j is g[j+s] if valid.
    
    # Using numpy: for a given s, the shifted array is:
    # if s >= 0: [0]*s + g[:n-s]  (length n)
    # if s < 0:  g[-s:] + [0]*(-s) (length n)
    
    # This is just np.roll with zero padding, or:
    # shifted = np.zeros(n); shifted[max(0,-s):n-max(0,s)] = g[max(0,s):n+min(0,s)]
    # Hmm, getting complicated. Let me just use a simple approach.
    
    # For n <= 200, I'll compute the gradient using a loop over the 2n-1 lags:
    # This is at most 399 iterations, each doing O(n) work. Total O(n * 2n) = O(n²). Fine.
    
    pen_grad = 2 * lam * (h.sum() - n / 2.0)
    grad = np.full(n, dx * 0.0 + pen_grad)  # start with penalty gradient
    # Add the correlation gradient
    # grad[j] += dx * sum_k soft[k] * (g[j+k-n+1] - h[j-k+n-1])
    
    # Compute term1[j] = sum_k soft[k] * g[j+k-n+1]
    # and term2[j] = sum_k soft[k] * h[j-k+n-1]
    # Then grad += dx * (term1 - term2)
    
    # Term1: for each k, g[j+k-n+1] is g shifted by (k-n+1)
    # I'll accumulate:
    for k in range(2*n - 1):
        w = soft[k]
        if w < 1e-15:
            continue
        s = k - (n-1)  # shift for g: g[j+s]
        if s >= 0:
            # g[j+s] valid when j in [0, n-s-1]
            if s < n:
                grad[:n-s] += dx * w * g[s:]
        else:
            # g[j+s] = g[j-|s|] valid when j in [|s|, n-1]
            t = -s
            if t < n:
                grad[t:] += dx * w * g[:n-t]
        # Now term2: h[j-k+n-1] = h[j + (n-1-k)] = h[j - s]
        # h[j-s] valid when j in [s, n-1] if s>=0, or j in [0, n+|s|-1] if s<0
        s2 = -s  # = n-1-k
        if s2 >= 0:
            if s2 < n:
                grad[s2:] -= dx * w * h[:n-s2]
        else:
            t2 = -s2
            if t2 < n:
                grad[:n-t2] -= dx * w * h[t2:]
    
    return val, grad

    n = len(h)
    dx = 2.0 / n

    return np.max(corr) * dx

    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    m = np.max(corr)
    val = m + np.log(np.sum(np.exp(T * (corr - m)))) / T
    return val * dx

            total = room.sum()
            if total < 1e-15:

import time


def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * dx


def smooth_c5(h, T):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    m = np.max(corr)
    val = m + np.log(np.sum(np.exp(T * (corr - m)))) / T
    return val * dx


def project_feasible(h, n):
    h = np.clip(h.astype(float), 0.0, 1.0).copy()
    target = n / 2.0
    for _ in range(100):
        diff = target - h.sum()
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            room = 1.0 - h
            total = room.sum()
            if total < 1e-15:
                break
            h += room * (diff / total)
        else:
            total = h.sum()
            if total < 1e-15:
                break
            h *= (target - 1e-15) / total
        h = np.clip(h, 0.0, 1.0)
    # Final fix: if still off, adjust largest elements
    diff = target - h.sum()

        idx = np.argsort(h)[:-1][::-1] if diff > 0 else np.argsort(h)[1:]
        step = diff / len(idx)

            if diff > 0 and h[i] < 1.0:
                h[i] = min(1.0, h[i] + step)
            elif diff < 0 and h[i] > 0.0:
                h[i] = max(0.0, h[i] + step)
    return h
