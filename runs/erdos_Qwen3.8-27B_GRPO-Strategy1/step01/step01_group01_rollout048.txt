Let me also think about whether I should use cvxpy for a cutting-plane approach. The problem is:
minimize C
subject to: corr[k] * dx ≤ C for all k
           0 ≤ h[i] ≤ 1
           sum(h) = n/2

This is a linear program! (For fixed h, each corr[k] is linear in h. And C is a variable.) Wait, is corr[k] linear in h?

corr[k] = sum_i h[i] * (1 - h[i+k])

This is sum_i h[i] - sum_i h[i]*h[i+k]. The term h[i]*h[i+k] is quadratic, not linear! So it's NOT a linear program.

Unless... for binary h, h[i]*h[i+k] = h[i] AND h[i+k], which can be linearized with additional variables. But for continuous h, it's genuinely quadratic.

So the problem is a quadratic program (minimize a linear objective subject to quadratic inequality constraints). This could potentially be solved with cvxpy if the constraints are convex... but they're not (h[i]*h[i+k] is not concave in general).

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def proj(h, n):
    h = np.clip(h, 0.0, 1.0)
    tgt = n / 2.0
    for _ in range(300):
        d = tgt - np.sum(h)
        if abs(d) < 1e-14:
            break
        m = h < 1.0 if d > 0 else h > 0.0
        cnt = np.count_nonzero(m)
        if cnt == 0:
            break
        h[m] += d / cnt
        h = np.clip(h, 0.0, 1.0)
