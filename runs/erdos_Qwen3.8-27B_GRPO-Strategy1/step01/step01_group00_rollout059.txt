This is related to the autocorrelation of the binary sequence! Specifically, if we define the autocorrelation of h as R(s) = sum h[n]*h[n+s], then:
c(s) = sum h[n] - sum h[n]*h[n+s] = (number of 1s in valid range) - R(s)

The "number of 1s in valid range" depends on s (for edge effects). For |s| < n, the valid range has n-|s| elements.

So c(s) = (n-|s|)/2 (if exactly half are 1s, approximately) - R(s)
Actually, sum h[n] for valid n depends on which n are valid. For shift s, valid n are max(0,-s) to min(n-1, n-1-s).

    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

    return np.correlate(h, 1.0 - h, mode='full')

    if abs(s - target) < 1e-12:

                    h[idx] += add
                    diff -= add

            for idx in order:
                if h[idx] > 0.0:
                    sub = min(-diff, h[idx])
                    h[idx] -= sub
                    diff += sub
                    if abs(diff) < 1e-12:
                        break

    x_new = np.arange(new_n) * (2.0 / new_n)

        # Case 2: n=i-s, valid when 0 <= i-s < n  (and s != 0 to avoid double counting)
        c2 = (i - s_vals >= 0) & (i - s_vals < n) & (s_vals != 0)
        
        # For each t in grid, compute delta in corr at changed indices
        # delta[t, j] for changed index j:
        # Case 1: (t - old_val) * (1 - h[i+s_j])
        # Case 2: (old_val - t) * h[i-s_j]
        # At s=0: t*(1-t) - old_val*(1-old_val)

        d2 = np.zeros(len(s_vals))

        if np.any(c2):
            d2[c2] = h[i - s_vals[c2]]

        #          = (t-old) + (old² - t²) = (t-old) + (old-t)(old+t) = (t-old)(1 - old - t)

        # For s=0: delta = (t - old_val) * (1 - old_val - t)  [quadratic in t]

            p = s0_pos[0]
            delta_sq = (t_grid - old_val) * (1.0 - old_val - t_grid)
            delta_linear[:, p] = delta_sq
        
        new_vals = corr[idx][None, :] + delta_linear  # (grid, len(s_vals))
        max_changed = np.max(new_vals, axis=1)  # (grid,)

        best_pos = np.argmin(overall_max)

        if best_val < np.max(corr):
            h[i] = best_t

    return h
