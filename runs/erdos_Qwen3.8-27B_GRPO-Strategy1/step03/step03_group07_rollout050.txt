To minimize f_d, we want R_h(d) to be as large as possible.

But we want to minimize MAX over all d of f_d. So we want ALL lags to have large autocorrelation.

This is a "maximally autocorrelated" sequence problem! We want a {0,1} sequence (approximately) with n/2 ones that has its minimum autocorrelation (over all lags) as large as possible.

This is related to "Golay sequences" and "Barker sequences."

For a random binary sequence with n/2 ones, the expected autocorrelation at lag d is approximately (n-d)/4 (since P(both 1) ≈ 1/4). So f_d ≈ (n-d)/2 - (n-d)/4 = (n-d)/4.

The max of (n-d)/4 over d is at d=0, giving n/4. Then C₅ ≈ n/4 * 2/n = 1/2.

For a structured sequence, we can do much better. The goal is C₅ ≈ 0.38, which means the max correlation is about 0.38 * n/2 = 0.19n.

        except Exception:
            pass

    best_h = make_feasible(best_h, n)
    best_c5 = compute_c5(best_h)
    return best_h, best_c5, n
