4. This is essentially what the polish function does

The swap approach is different: instead of changing one coordinate, swap two coordinates (one going up, one going down) to maintain the sum constraint.

For a swap of positions i and j where h[i] < h[j]:
- New h[i] = min(1, h[i] + delta)
- New h[j] = max(0, h[j] - delta)
- where delta = h[j] - h[i] (full swap) or some fraction

The effect on correlation:
For each lag k (from -(N-1) to N-1):
- The correlation at k involves pairs (t, t+k) for valid t
- The swap affects all lags where either i or j appears in one of these pairs
- Specifically, lag k is affected if (i-k is valid) or (i+k is valid) or (j-k is valid) or (j+k is valid)

This is complex to track incrementally. Let me just recompute the correlation after each swap attempt.

For N=380, np.correlate takes about 50-100 microseconds. So we can do about 10,000-20,000 evaluations per second. In 200 seconds, we can do about 2-4 million swap evaluations. That should be more than enough for a good local search.

    return float(np.max(corr)) * dx

    h = np.clip(h, 0.0, 1.0)
    for _ in range(50):
        s = float(h.sum())
        diff = s - target
        if abs(diff) < 1e-13:
            return h
        h2 = h - diff / len(h)
        if h2.min() >= -1e-12 and h2.max() <= 1.0 + 1e-12:

        lo, hi = -2.0, 2.0

                lo = mid
            else:

        return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def grad_fn(h, N, tau, topK):
    dx = 2.0 / N
    corr = np.correlate(h, 1.0 - h, mode='full')
    c5 = float(np.max(corr)) * dx
    center = N - 1
    nc = len(corr)
    sc = tau * (corr - corr.max())
    w_sm = np.exp(sc)
    w_sm /= w_sm.sum()
    k = max(1, min(topK, nc))
    idx_top = np.argsort(corr)[-k:]
    w_top = np.zeros(nc)
    w_top[idx_top] = 1.0 / k
    alpha = min(1.0, max(0.0, (tau - 10.0) / 40.0))
    w = (1.0 - alpha) * w_sm + alpha * w_top
    grad = np.zeros(N)

        wi = w[ai]

            grad += wi * (1.0 - 2.0 * h)
        elif L > 0:
            grad[L:] += wi * (1.0 - h[:N-L])
            grad[:N-L] -= wi * h[L:]
        else:
            M = -L
            grad[:N-M] += wi * (1.0 - h[M:])
            grad[M:] -= wi * h[:N-M]

def optimize(h, N, target, deadline, tau0, tau1, tk0, tk1, lr0, mom, warmup):

    best_h = h.copy()
    best_c5 = compute_c5(h, dx)
    v = np.zeros(N)
    sq = np.full(N, 1e-4)
    it = 0
    while time.time() < deadline:
        it += 1
        t_frac = min(it / max(1, warmup), 1.0)
        tau = tau0 + (tau1 - tau0) * t_frac

        if c5v < best_c5 - 1e-14:

            best_h = h.copy()

        sq = 0.9*sq + 0.1*(g*g)

        h = h - lr_eff * step_scale * v
        h = project_sum(h, target)
    return best_h, best_c5

def compute_c5(h, dx):

def project_sum(h, target):
    h = np.clip(h, 0.0, 1.0)
    for _ in range(50):
        s = float(h.sum())
        diff = s - target

            return h
        h2 = h - diff / len(h)
        if h2.min() >= -1e-12 and h2.max() <= 1.0 + 1e-12:
            return np.clip(h2, 0.0, 1.0)
