For the O(N) per-swap evaluation, let me think more carefully:

Given h (binary), corr[k] = Σ_m h[m] * g[m+k-(N-1)] where g = 1-h, for valid indices.

Let's index corr as corr_full[0..2N-2] (length 2N-1).
corr_full[k] = Σ_{m: 0≤m<N, 0≤m+k-(N-1)<N} h[m] * g[m+k-(N-1)]

Let t = m + k - (N-1), so k = t - m + N - 1.
corr_full[m + t - N + 1] += h[m] * g[t] for valid m,t.

When h[i]: 1→0 (g[i]: 0→1):
- Remove terms where h[i] is first factor: for each valid t, corr_full[i + t - N + 1] -= g[t]
  - t ranges over [0, N-1] (all valid), so k ranges over [i-t+N-1] for t in [0,N-1]
  - Actually t must satisfy 0 ≤ t < N, and k = i + t - (N-1) must be in [0, 2N-2]
  - k = i + t - N + 1, t in [0, N-1], so k in [i-N+1, i]
  - Valid k: max(0, i-N+1) to min(2N-2, i)
  - Contribution: -g[t] = -(1-h[t]) where t = k - i + N - 1
  
- Remove terms where g[i] is second factor: for each valid m, corr_full[m + i - N + 1] -= h[m] * g[i]
  - But g[i] was 0 before, so these terms were 0. After the flip, g[i]=1, so we ADD h[m]*1.
  - Wait, I'm computing the change. Before flip: g[i]=0, so terms with g[i] as second factor contributed 0.
  - After flip: g[i]=1, so those terms now contribute h[m]*1.
  - m must satisfy: 0 ≤ m < N and k = m + i - N + 1 in [0, 2N-2]
  - So m in [N-1-i, N-1] (from k ≥ 0) and m in [0, 2N-2-i+N-1] = [0, 3N-3-i] (always valid)
  - m in [max(0, N-1-i), min(N-1, N-1)] = [N-1-i, N-1] (if N-1-i ≥ 0)
  - For m in [N-1-i, N-1]: corr_full[m+i-N+1] += h[m]

So total change when h[i]: 1→0:
- For k in [max(0, i-N+1), min(2N-2, i)]: corr[k] -= (1-h[k-i+N-1])
- For m in [max(0, N-1-i), N-1]: corr[m+i-N+1] += h[m]

And when h[j]: 0→1 (g[j]: 1→0):
- Remove terms where h[j] is first factor (h[j] was 0, so no change to first-factor terms)
  - Actually after flip h[j]=1, so we ADD terms: for valid t, corr_full[j+t-N+1] += g[t]
  - Wait, before: h[j]=0, so first-factor terms contributed 0. After: h[j]=1, they contribute g[t].
  - k = j + t - N + 1, t in [0, N-1], k in [j-N+1, j]
  - For k in [max(0, j-N+1), min(2N-2, j)]: corr[k] += (1-h[k-j+N-1])
  
- Terms where g[j] is second factor: before g[j]=1, contributed h[m]*1. After g[j]=0, contributes 0.
  - For m in [max(0, N-1-j), N-1]: corr[m+j-N+1] -= h[m]

So a swap (i: 1→0, j: 0→1) has total change:
- corr[k] changes by:
  - From i removal (first factor): -(1-h[valid_index]) for k in range_i
  - From i removal (second factor, g[i]: 0→1): +h[m] for m in range
  - From j addition (first factor): +(1-h[valid_index]) for k in range_j
  - From j addition (second factor, g[j]: 1→0): -h[m] for m in range

    """Weighted gradient of correlation values w.r.t. h."""
    N = len(h)

                grad[M:] -= w * h[:N - M]

    """L-BFGS-B with smooth max and penalty constraint."""
    dx = 2.0 / N
    penalty = 50.0
    bounds = [(0.0, 1.0)] * N

    def obj(x):
        corr = compute_corr(x) * dx
        m = np.max(corr)
        val = m + np.log(np.sum(np.exp(alpha * (corr - m)))) / alpha
        s = np.sum(x) - target
        val += penalty * s * s
        return val

        corr = compute_corr(x) * dx
        m = np.max(corr)
        w = np.exp(alpha * (corr - m))
        w /= np.sum(w)

        g += 2.0 * penalty * s

            best_c5 = c2b
            best_h = h2b.copy()

    # Phase 5: Try periodic initialization at N=380
    if time.time() < deadline - 180:
        for period in [6, 8, 10, 12]:
            if N % period != 0:
                continue
            hp = periodic_initial(N, period)
            d6 = time.time() + (deadline - time.time()) * 0.4
            hp_b, cp = binary_local_search(hp, N, d6, rng, n_proposals=300, max_stall=30)
            if cp < best_c5:
                best_c5 = cp
                best_h = hp_b.copy()
            if time.time() < deadline - 100:
                break

    # Phase 6: Final polish local search
    if time.time() < deadline - 15:
        Nb = len(best_h)
        h_f = best_h.astype(float)
        h_f, c_f = binary_local_search(h_f, Nb, deadline - 3, rng,
                                       n_proposals=500, max_stall=25)
        if c_f < best_c5:
            best_c5 = c_f
            best_h = h_f.astype(float)

    final_c5 = compute_c5(best_h, len(best_h))
    return best_h, final_c5, len(best_h)
