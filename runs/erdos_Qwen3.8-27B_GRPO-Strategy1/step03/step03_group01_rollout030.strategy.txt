**2. Mathematical Specification**

**Representation**:
- Function h represented on a grid of n points from [0,2] with step dx=2/n
- Gradient for each coordinate computed via discrete differentiation

**Objective**:
Minimize C₅ = maxₖ ∫h(x)(1-h(x+k))dx ≈ maxₖ (dx × correlation lag k)

**Constraints**:
- ∑h[i] = n/2
- 0 ≤ h[i] ≤ 1
- These are enforced via projections

**Optimization Formulation**:
At iteration t:
1. Evaluate current objective value C₅(h)
2. Hybridize gradient components based on:
   - Unconstrained gradient (local changes)
   - Contribution smoothing (global view)
3. Update each coordinate with probability proportional to:
   - Gradient magnitude
   - Coordiate's "importance" in the binding constraint

**Feasibility**: Projected simplex turns ensure feasible solutions always. The projection is a barycentric projection onto the [0,1] interval with sum adjustment.

**Gradient Budget**: Each iteration evaluates up to n correlations (each O(n)) but with approximations and cached operations where possible.
