Another idea: **Guided local search**. After finding the current maximum lag L*, try swaps that specifically reduce the overlap at lag L*. We can compute which pairs of positions contribute to the overlap at lag L* and prefer swaps that involve those positions.

For lag L (shift), the overlap is:
∑_{i=0}^{N-1-L} h[i] * (1-h[i+L])  (for positive L, within range)

The contributing pairs are (i, i+L) where h[i]=1 and h[i+L]=0. If we swap one of these 1s with a 0 at some other position, we reduce the overlap at lag L.

Let me implement a "guided" move:
1. Find the lag L* with maximum overlap
2. Find all positions i where h[i]=1 and h[i+L*]=0 (these contribute to the max)
3. Pick one such i and try to swap h[i] with a random 0
4. Also try double swaps involving two such positions

This should be more effective than purely random swaps.

            flip_j = zeros_now[rng.choice(len(zeros_now), min(k, len(zeros_now)), replace=False)]
            cur[flip_i] = 0.0
            cur[flip_j] = 1.0
            cur_c = c5_val(cur)
            T = 1.0
            no_imp = 0
    return best, best_c

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    deadline = t0 + budget_s - 3
    rng = np.random.RandomState(seed)
    h0 = np.array(initial_h_values, dtype=float)
    N = len(h0)
    best_h = h0.copy()
    best_c5 = c5_val(best_h)

    # Phase 1: Short continuous refinement
    d1 = t0 + budget_s * 0.10
    h1 = h0.copy() + rng.randn(N) * 0.05
    h1 = project_sum(h1, N / 2.0)
    h1, c1 = adam_cont(h1, N, N / 2.0, d1, lr0=0.018, k=12)
    if c1 < best_c5:
        best_c5, best_h = c1, h1

    # Phase 2: Main binary local search
    h2 = to_binary(best_h, N, rng)
    d2 = t0 + budget_s * 0.52
    h2, c2 = local_search(h2, d2, rng)
    if c2 < best_c5:
        best_c5, best_h = c2, h2

    # Phase 3: Second attempt from perturbed start
    if time.time() < deadline - 80:
        h3 = best_h + rng.randn(N) * 0.12
        h3 = project_sum(h3, N / 2.0)
        d3a = time.time() + min(20, (deadline - time.time()) * 0.1)
        h3c, c3a = adam_cont(h3, N, N / 2.0, d3a, lr0=0.01, k=10)
        h3b = to_binary(h3c, N, rng)
        d3b = time.time() + (deadline - time.time()) * 0.45
        h3b, c3b = local_search(h3b, d3b, rng)
        if c3b < best_c5:
            best_c5, best_h = c3b, h3b

    # Phase 4: Attempt from structured random start
    if time.time() < deadline - 50:
        h4 = (rng.rand(N) < 0.5).astype(float)
        h4 = to_binary(h4, N, rng)
        d4 = time.time() + (deadline - time.time()) * 0.5
        h4, c4 = local_search(h4, d4, rng)
        if c4 < best_c5:
            best_c5, best_h = c4, h4

    # Phase 5: Final intensive local search on best
    if time.time() < deadline - 4:
        hb = to_binary(best_h, N, rng)
        hb, c5 = local_search(hb, deadline - 1, rng)
        if c5 < best_c5:
            best_c5, best_h = c5, hb

    best_c5 = c5_val(best_h)
    return best_h, best_c5, N
