Actually, here's another idea: **Alternating minimization on the active set**

1. Find the worst shift k*
2. Fix all other constraints, minimize just f_{k*}(h) = sum_i h[i](1-h[i+k*])
   - This is: sum_i h[i] - sum_i h[i]h[i+k*] = n/2 - sum_i h[i]h[i+k*]
   - Minimizing this = maximizing sum_i h[i]h[i+k*]
   - This is a quadratic maximization, non-convex
   - But we can use SLSQP on this single objective
3. After reducing f_{k*}, recompute all correlations, find new worst, repeat

import time

def get_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def compute_c5(h):
    n = len(h)
    return np.max(get_corr(h)) * 2.0/n

def soft_loss(h, T, topk):
    corr = get_corr(h)
    if topk is not None and topk < len(corr):
        idx = np.argpartition(corr, -topk)[-topk:]
        corr = corr[idx]
    m = np.max(corr)
    n = len(h)
    return (m + np.log(np.sum(np.exp(T*(corr-m))))/T) * 2.0/n

def single_corr_loss(h, shift_idx):
    # Minimize correlation at a specific lag
    corr = get_corr(h)
    n = len(h)
    return corr[shift_idx] * 2.0/n

def sum_eq(x):
    return x.sum() - len(x)/2.0

def project(h, n):
    h = np.clip(h, 0, 1).copy()
    t = n/2.0 - h.sum()
    if abs(t) < 1e-14: return h
    if t > 0:
        r = 1-h; s = r.sum()
        if s > 1e-14: h = h + r*(t/s)
    else:
        r = h.copy(); s = r.sum()
        if s > 1e-14: h = h + r*(t/s)
    return np.clip(h, 0, 1)

Let me also think about whether there's a fundamentally better approach.

**Alternative: Use the structure of the correlation**

The correlation c[k] = sum_i h[i](1-h[i+k]) for shift k.

If I define g = 1-h, then c[k] = sum_i h[i]*g[i+k]. This is a cross-correlation.

The total sum over all k of c[k] = sum_k sum_i h[i]*g[i+k] = sum_i h[i] * sum_k g[i+k] = sum_i h[i] * (sum of g over all positions) = sum_i h[i] * (n - n/2) = sum_i h[i] * n/2 = (n/2) * (n/2) = n²/4.

So the average correlation is (n²/4) / (2n-1) ≈ n/8. For n=160, average ≈ 20. C₅_avg ≈ 20 * 2/160 = 0.25.

The max is 0.38, so it's about 1.5x the average. To reduce the max, we need to make the correlations more uniform.

This suggests: the optimal h should make all correlations roughly equal. This is like a "flat spectrum" problem.

**Spectral approach**: If we think of h as a signal, the correlation is related to the Fourier transform. Making all correlations equal is like making the power spectrum flat. But we have the constraint h ∈ [0,1] and sum(h) = n/2, which complicates things.

def get_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def compute_c5(h):
    n = len(h)
    return np.max(get_corr(h)) * 2.0 / n

def soft_loss(h, args):
    T, topk = args
    corr = get_corr(h)
    if topk is not None and topk < len(corr):
        idx = np.argpartition(corr, -topk)[-topk:]
        corr = corr[idx]
    m = np.max(corr)
    n = len(h)
    return (m + np.log(np.sum(np.exp(T * (corr - m)))) / T) * 2.0 / n

def single_shift_loss(h, args):
    ki = args
    corr = get_corr(h)
    n = len(h)
    return corr[ki] * 2.0 / n

    return x.sum() - len(x) / 2.0

def project(h, n):
    h = np.clip(h, 0.0, 1.0).copy()
    t = n / 2.0 - h.sum()
    if abs(t) < 1e-14:
        return h
    if t > 0:
        r = 1.0 - h
        s = r.sum()
        if s > 1e-14:
            h = h + r * (t / s)
    else:
        r = h.copy()
        s = r.sum()
        if s > 1e-14:
            h = h + r * (t / s)
    h = np.clip(h, 0.0, 1.0)
    # Final exact correction
    t2 = n / 2.0 - h.sum()
    if abs(t2) > 1e-12:
        idx = np.where(h != np.clip(h, 0, 1)[np.newaxis][0] if t2 > 0 else h != 0.0)
        if len(idx[0]) > 0:
            h[idx[0]] += t2 / len(idx[0])
            h = np.clip(h, 0, 1)
    return h
