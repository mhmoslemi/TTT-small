def project_feasible(h, n):

def projected_gradient(h, n_iters, top_m=8, use_bb=True):
    n = len(h)
    dx = 2.0/n
    h_cur = h.copy()
    best_h = h_cur.copy()
    best_c5, _ = compute_c5_and_corr(h_cur)
    g_prev = None
    h_prev = None
    step = 0.05
    stall = 0
    for it in range(n_iters):
        c5, corr = compute_c5_and_corr(h_cur)
        # Find top m lags
        top = np.argsort(corr)[-top_m:]
        top = top[corr[top] > np.max(corr) - 0.01*corr.max()]  # filter near-max
        if len(top) == 0:
            top = np.array([np.argmax(corr)])
        # Compute subgradient
        g = np.zeros(n)
        for idx in top:
            p = idx - (n-1)
            g += lag_gradient(h_cur, p)

            y_vec = g - g_prev
            sy = np.dot(s_vec, y_vec)
            yy = np.dot(y_vec, y_vec)

**Key idea: Use a "soft" version of the min-max.**

Instead of directly optimizing the max, use the softmax approximation:
f_T(h) = dx * (1/T) * log(Σ_k exp(T * corr[k]))

This is a smooth approximation to dx * max_k corr[k]. As T → ∞, f_T → C5.

The gradient of f_T is:
∇f_T(h) = dx * Σ_k (exp(T*corr[k]) / Σ_j exp(T*corr[j])) * ∇corr[k]
        = dx * Σ_k w_k * ∇corr[k]

where w_k = softmax(T * corr). This is a weighted average of the lag gradients, with the weights concentrated on the max lag as T → ∞.

This is actually what the previous code was doing with SLSQP on the softmax objective. The advantage of using this gradient directly (without SLSQP) is that I can use projected gradient, which is faster per iteration.

def softmax_grad(h, T, top_m=20):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    # Compute softmax weights (stable)
    m = np.max(corr)
    exps = np.exp(T * (corr - m))
    w = exps / exps.sum()
    # Only use top m weights (rest are negligible for large T)
    if T > 100:
        idx = np.argsort(w)[-top_m:]
        w_mask = np.zeros_like(w)
        w_mask[idx] = w[idx]
        w_mask /= w_mask.sum()

        g += w[j] * lag_grad(h, j - (n - 1))
    return g * dx, float(np.max(corr) * dx), m + np.log(exps.sum()) / T

C5 = max_k ∫_0^2 h(x)(1-h(x+k)) dx

The key lags to worry about are:
- k=0: ∫ h(x)(1-h(x)) dx (self-overlap, always ≥ 0)
- Small |k|: most terms in the sum
- Large |k|: fewer terms, but each term is still h(x)*(1-h(x+k))

The maximum is likely at a small positive or negative k.

def lag_grad(h, p):
    n = len(h)
    g = np.zeros(n)
    lo1 = max(0, -p)
    hi1 = min(n - 1, n - 1 - p)
    if lo1 <= hi1:

    lo2 = max(0, p)
    hi2 = min(n - 1, n - 1 + p)
    if lo2 <= hi2:
        g[lo2:hi2+1] -= h[lo2-p:hi2-p+1]
    return g

    for j in np.where(nz)[0]:

Actually, I realize I should double-check one thing: the `np.correlate(h, 1-h, mode='full')` computation. Let me verify that C5 = max(corr) * dx is the correct formula.

The overlap integral is ∫₀² h(x)(1-h(x+k)) dx. With our discretization:
∫₀² h(x)(1-h(x+k)) dx ≈ dx * Σ_i h[i] * (1-h[i+k]) (with appropriate boundary handling)

np.correlate(h, g, mode='full')[m] where g = 1-h:
= Σ_n h[n] * g[n + m - (n-1)]  (using n_points as n, confusing notation)

Let me use N for n_points:
np.correlate(h, g, mode='full')[m] = Σ_{i=0}^{N-1} h[i] * g[i + m - (N-1)]
     (where g[j] = 0 for j < 0 or j ≥ N)

For m = N-1+k (k ≥ 0):
= Σ_{i=0}^{N-1-k} h[i+k] * g[i] = Σ_{i=0}^{N-1-k} h[i+k] * (1-h[i])

This is the sum for shift k: Σ h[i+k]*(1-h[i]).
The integral is ≈ dx * this sum. ✓

For m = N-1-k (k ≥ 1):
= Σ_{i=k}^{N-1} h[i] * g[i-k] = Σ_{i=k}^{N-1} h[i] * (1-h[i-k])

This is the sum for shift -k. ✓

So C5 = dx * max_m np.correlate(h, 1-h, mode='full')[m]. ✓

Great, the formula is correct.
