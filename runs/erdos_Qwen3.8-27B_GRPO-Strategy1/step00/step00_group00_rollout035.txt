def subgradient_step(h, k_star):
    """Compute subgradient at the maximizing lag"""
    n = len(h)
    dx = 2.0 / n
    lag = k_star - (n - 1)
    grad = np.zeros(n)
    if lag >= 0:
        if lag < n:
            grad[lag:] += (1.0 - h[:n - lag])
            grad[:n - lag] -= h[lag:]
    else:
        m = -lag
        if m < n:
            grad[:n - m] += (1.0 - h[m:])
            grad[m:] -= h[:n - m]
    return grad * dx

Actually, the water-filling / projection algorithm for projecting onto {x: sum(x)=S, 0≤x≤1} is:
1. Set h = h0
2. Repeat:
   a. h = clip(h, 0, 1)
   b. If sum(h) == S, done
   c. If sum(h) > S: need to reduce. Find the "free" variables (not at bounds) and reduce them equally.
   d. If sum(h) < S: need to increase. Find the "free" variables (not at bounds) and increase them equally.

A simpler version that works well:
1. h = clip(h, 0, 1)
2. h += (S - sum(h)) / n
3. Iterate

This converges because each iteration reduces the error. Let me keep my iterative version.

Actually, there's a subtlety. If many h[i] are already at 0 or 1, the simple "add diff/n to all" approach will keep clipping and not converge properly. Let me use a better projection:

```python
def project_feasible(h, target_sum):
    h = h.copy()
    n = len(h)
    for _ in range(1000):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        # Find free variables
        if diff > 0:
            # Need to increase; can only increase variables < 1
            mask = h < 1.0 - 1e-15
            if not np.any(mask):
                break
            h[mask] += diff / np.sum(mask)
        else:
            # Need to decrease; can only decrease variables > 0
            mask = h > 1e-15
            if not np.any(mask):
                break
            h[mask] += diff / np.sum(mask)
        h = np.clip(h, 0.0, 1.0)
    return h
```

This is the proper water-filling projection and should converge in at most n iterations (each iteration fixes at least one variable at a bound).
