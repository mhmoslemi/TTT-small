For n=95, sum=47.5: we need 47 ones, one 0.5, and 47 zeros (or some other partition).

The optimal arrangement should minimize the maximum "cross-correlation with complement". This is a combinatorial problem.

For a periodic structure like: 111011101110... (period 4, 3 ones per period)
- This has density 3/4, not 1/2. Not suitable.

For density 1/2: 110011001100... (period 4, 2 ones per period)
- At shift 2: h and 1-h align perfectly → overlap = 0 at shift 2
- At shift 1: each 11 becomes 10 or 01 → some overlap
- At shift 3: similar to shift 1
- At shift 4: same as shift 0 → overlap = 0

Actually for 11001100..., the autocorrelation has peaks at multiples of 4.
The cross-correlation with complement at shift 2: h[x] vs 1-h[x+2]. Since h[x+2] = 1-h[x] (for period 4), 1-h[x+2] = h[x]. So overlap at shift 2 = sum h[x]^2 = n/2. That's BAD!

So the period-4 pattern is terrible. We need a more aperiodic pattern.

The best would be something like a "balanced" sequence from coding theory - a sequence where the partial sums (running sum of ±1) stay as close to 0 as possible. This minimizes the correlation with shifted versions.

For our problem, if we map h to s (where s[i] = 2*h[i] - 1 ∈ {-1, 1}), then:
overlap[k] = sum h[x](1-h[x+k]) = sum ((s[x]+1)/2)((1-s[x+k])/2)
= (1/4) sum (s[x]+1)(1-s[x+k])
= (1/4) sum (s[x] - s[x]s[x+k] + 1 - s[x+k])
= (1/4)(sum s[x] - sum s[x]s[x+k] + n' - sum s[x+k])
where n' is the number of valid pairs.

For a balanced sequence (sum s ≈ 0):
≈ (1/4)(n' - sum s[x]s[x+k])
= (1/4)(n' - autocorr_s[k])

So we want to minimize max_k (n' - autocorr_s[k]) = n'_max - min_k autocorr_s[k]

Which means we want to maximize the minimum autocorrelation of s! This is the "low autocorrelation" problem.

But for binary sequences of length 95 with 48 ones (or 47.5), finding the optimal sequence is a hard combinatorial problem. SA is a reasonable heuristic.

import numpy as np
import time


def compute_c5(h, dx):
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)


def make_binary_init(n, seed):
    rng = np.random.RandomState(seed)
    h = np.zeros(n, dtype=float)
    h[:n // 2] = 1.0
    if n % 2 == 1:
        h[n // 2] = 0.5
    rng.shuffle(h)
    return h


def repair_sum(h, target):
    h = np.clip(h, 0.0, 1.0)
    diff = target - h.sum()
    if abs(diff) < 1e-12:
        return h
    for _ in range(300):
        free = np.where((h > 0) & (h < 1))[0]
        if len(free) == 0:
            break
        h[free] += diff / len(free)
        h = np.clip(h, 0.0, 1.0)
        diff = target - h.sum()
        if abs(diff) < 1e-12:
            break
    return h
