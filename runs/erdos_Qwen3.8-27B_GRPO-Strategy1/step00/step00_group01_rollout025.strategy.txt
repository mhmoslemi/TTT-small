1. Approach and rationale:
   We tackle the Erdős minimum overlap problem using a convex optimization hierarchy (i.e., scenario-based approach) that leverages the fact that the maximum overlap among all shifts can be expressed as the maximum eigenvalue of a certain covariance matrix. This transforms the non-convex optimization into a sequence of convex problems. We start from the given 47-point initial solution and refine it by:

   - Interpreting the problem as minimizing the maximum "autocorrelation" score computed over all shifts
   - Formulating this minimax problem by introducing auxiliary variables and constraints
   - Projecting the initial solution to meet the sum constraint and intensity bounds
   - Iteratively solving a convex problem using an alternate projection-gradient method for enhanced convergence

2. Mathematical specification:
   - Variables:

     - `β`: A set of auxiliary variables representing the overlap scores for different shifts
