Wait, let me be more careful.

`conv_k = sum_j a[j] * a[k-j]`

If we change `a[i]` from `old` to `new`:
- The term `j = i`: was `old * a[k-i]`, now `new * a[k-i]`. Change: `(new - old) * a[k-i]`.
- The term `j = k-i` (if `k-i ≠ i`): was `a[k-i] * old`, now `a[k-i] * new`. Change: `(new - old) * a[k-i]`.
- If `k-i = i` (i.e., `k = 2i`): the term was `old * old = old^2`, now `new * new = new^2`. Change: `new^2 - old^2`.

So:
- If `k ≠ 2i`: `conv_k(new) = conv_k(old) + 2 * (new - old) * a[k-i]` (if `0 <= k-i < n`)
- If `k = 2i`: `conv_k(new) = conv_k(old) + new^2 - old^2`
- Otherwise: `conv_k(new) = conv_k(old)`

This is exact! So for each trial value of `a[i]`, we can compute the new `conv` in O(n) time (just updating the affected lags).

The affected lags are:
- `k = 2i` (one lag, quadratic change)
- `k = i + j` for `j = 0, ..., n-1` (i.e., `k = i, i+1, ..., i+n-1`, but clamped to `[0, 2n-2]`)

So at most `n` lags are affected, each with a linear change. This is very fast.

One more thought: the objective `2n * max(conv) / (sum)^2` is scale-invariant. So the actual values of `a` don't matter, only their ratios. This means we can work in the simplex (sum=1, a>=0) without loss of generality.

For the LSE gradient descent on the simplex:
- The gradient of `LSE(conv, beta)` (with sum=1 constraint) projected onto the simplex tangent space is:

  Then `a_new = project_simplex(a - lr * grad_proj)`

Actually, since we're on the simplex, the projected gradient is:
`grad_proj = grad - (1/n) * sum(grad) * ones`

Wait, the projection of a gradient onto the tangent space of the simplex is:
`P(grad) = grad - (sum(grad)/n) * ones`

This is the standard result for the simplex constraint.

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. LSE-smoothed gradient descent with Nesterov momentum and adaptive learning rate
2. Exact coordinate descent for final polishing
3. Peak-targeted mass redistribution
4. Multi-length exploration
"""

import numpy as np
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def convolve_ab(a, b):
    """Linear convolution of a and b via FFT."""
    size = len(a) + len(b) - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    B = np.fft.rfft(b, fft_size)
    return np.fft.irfft(A * B, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex (sum=1, v>=0)."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.arange(1, n + 1)
    cond = u * rho > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho_val = np.nonzero(cond)[0][-1]
    theta = (cssv[rho_val] - 1.0) / (rho_val + 1.0)
    return np.maximum(v - theta, 0.0)


def lse_weights(conv, beta):
    """Compute LSE softmax weights on convolution values."""
    bc = beta * (conv - conv.max())
    exp_bc = np.exp(bc)
    total = exp_bc.sum()
    if total < 1e-300:
        return np.ones(len(conv)) / len(conv)
    return exp_bc / total


def compute_gradient(a, weights):
    """Compute gradient of sum_k weights[k] * conv[k] w.r.t. a.
    grad[i] = 2 * sum_j a[j] * weights[i+j]
    """
    n = len(a)
    w_rev = weights[::-1]
    conv = convolve_ab(a, w_rev)
    # conv has length 3n-1
    # grad[i] = 2 * conv[2n-2-i]
    # For i=0: conv[2n-2], for i=n-1: conv[n-1]
    grad = 2.0 * conv[n-1 : 2*n-1][::-1]
    return grad


def lse_gradient_descent(a0, time_limit, beta_start=5.0, beta_end=2000.0,
                          lr_init=None, momentum=0.9, verbose=True):
    """LSE-smoothed gradient descent with momentum on the simplex."""
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    if lr_init is None:
        lr = 1.0 / np.sqrt(n)
    
    conv = fast_convolve(a)
    best_obj = conv.max()
    best_a = a.copy()
    
    v = np.zeros(n)  # momentum
    t0 = time.monotonic()
    it = 0
    no_improve = 0
    
    # Beta schedule: exponential from beta_start to beta_end
    total_steps_est = 5000
    beta = beta_start
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 1:
            break
        
        # Update beta (exponential schedule)
        progress = min(1.0, it / total_steps_est)
        beta = beta_start * (beta_end / beta_start) ** progress
        
        # Compute LSE weights and gradient
        conv = fast_convolve(a)
        w = lse_weights(conv, beta)
        grad = compute_gradient(a, w)
        
        # Project gradient onto simplex tangent space
        grad_proj = grad - grad.mean()
        
        # Nesterov momentum
        v = momentum * v + grad_proj
        v_norm = np.linalg.norm(v)
        if v_norm < 1e-15:
            no_improve += 1
            if no_improve > 100:
                break
            continue
        
        # Backtracking line search
        step = lr
        a_trial = a
        obj_trial = best_obj
        improved = False
        
        for _ in range(15):
            a_trial = project_simplex(a - step * v)
            conv_trial = fast_convolve(a_trial)
            obj_trial = conv_trial.max()
            if obj_trial < conv.max() * (1 - 1e-4):  # sufficient decrease
                a = a_trial
                improved = True
                break
            step *= 0.7
        
        if improved:
            if obj_trial < best_obj - 1e-10:
                best_obj = obj_trial
                best_a = a.copy()
                no_improve = 0
            else:
                no_improve += 1
            # Gradually increase lr
            lr = min(lr * 1.01, 10.0 / np.sqrt(n))
        else:
            no_improve += 1
            lr *= 0.8
            if no_improve > 50:
                # Reset momentum and try from best
                v = np.zeros(n)
                a = best_a.copy()
                lr = max(0.1 / np.sqrt(n), 1e-4)
                no_improve = 25
        
        if verbose and it % 500 == 0:
            elapsed = time.monotonic() - t0
            print(f"    LSE-GD: it={it}, beta={beta:.1f}, obj={best_obj:.8f}, "
                  f"lr={lr:.4f}, time={elapsed:.0f}s")
    
    return best_a, best_obj
