## 1. Approach and Rationale
The goal is to design a step function that minimizes the following objective function:  

``` obj = (2 * n * max(conv(a, a))) / (sum(a)**2) ```

Where conv(a, a) is the full convolution of the sequence a (which has np.inf handled by the previous program). The approach involves using advanced optimization techniques including:
- Frank-Wolfe method with adaptive constraints
- Projected Gradient methods with momentum
- Local Lipschitz optimization
- Global exploration via random perturbations and different starting points
- Multi-stage search strategy to balance between local refinement and global exploration

The key rationale is to use the parent sequence (if available) as a starting point but then systematically explore neighboring sequences in the non-negative space to find better solutions. We maintain a record of the best sequence found (normalized to have sum 1.0) and its objective value.

## 2. Mathematical Specification
We are optimizing over sequences a = (a₀, ..., aₙ₋₁) where:
- Each aᵢ ≥ 0
- The sequence is normalized: sum(a) = 1
- The Objective: 
    ``` obj = (2 * n * max(convolve_full(a, a))) ```
    where convolve_full returns the full convolution of length 2*n-1
