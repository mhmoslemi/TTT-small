`grad f_T = (1/T) * (1/sum_k exp(conv[k]/T)) * grad(sum_k exp(conv[k]/T))`
`= (1/T) * sum_k p_k * grad conv[k]`
where `p_k = exp(conv[k]/T) / sum_j exp(conv[j]/T)`.

And `grad conv[k] = 2 * hankel_mv(e_k, a)` where `e_k` is the k-th basis vector. More precisely, `grad_i conv[k] = 2 * sum_j [i+j=k] * a[j] = 2 * a[k-i]` (for valid indices).

So `grad f_T = (2/T) * sum_k p_k * a[k-i]` (with appropriate indexing).

This is the same as `2/T * hankel_mv(p, a)`.

import numpy as np
from scipy.optimize import minimize
import time

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def hankel_mv(p, a):
    return np.correlate(p, a, mode='valid')

def smoothed_obj_grad(a, T):
    """Compute smoothed objective and gradient using log-sum-exp."""
    conv = fast_convolve(a)
    # Numerically stable log-sum-exp
    conv_max = conv.max()
    exp_conv = np.exp((conv - conv_max) / T)
    log_sum = conv_max / T + np.log(exp_conv.sum())
    obj = T * log_sum
    p = exp_conv / exp_conv.sum()
    grad = 2.0 * hankel_mv(p, a)
    return obj, grad

def coord_descent(a, n_iterations, time_limit, start_time):
    """Coordinate descent: try moving mass between pairs of coordinates."""
    a = a.copy()
    n = len(a)
    best_obj = fast_convolve(a).max()
    
    for it in range(n_iterations):
        if time.monotonic() - start_time > time_limit:
            break
        
        conv = fast_convolve(a)
        k_peak = int(np.argmax(conv))
        
        # Find the coordinate that contributes most to the peak
        js = max(0, k_peak - n + 1)
        je = min(n - 1, k_peak)
        affected = np.arange(js, je + 1)
        contributions = a[affected] * a[k_peak - affected]
        
        if contributions.max() < 1e-15:
            continue
        
        j_hot = affected[np.argmax(contributions)]
        
        # Find a "cold" coordinate to move mass to
        # Try all cold coordinates and pick the best improvement
        outside = np.setdiff1d(np.arange(n), affected)
        if len(outside) == 0:
            outside = np.arange(n)
        
        j_cold = outside[np.argmin(a[outside])]
        
        # Binary search for the optimal amount to move
        lo, hi = 0.0, a[j_hot]
        best_delta = 0
        best_val = best_obj
        
        for _ in range(10):
            mid = (lo + hi) / 2
            if mid >= a[j_hot]:
                hi = mid
                continue
            candidate = a.copy()
            candidate[j_hot] -= mid
            candidate[j_cold] += mid
            candidate = np.maximum(candidate, 0)
            s = candidate.sum()
            if s < 1e-15:
                break
            candidate = candidate / s
            val = fast_convolve(candidate).max()
            if val < best_val:
                best_val = val
                best_delta = mid
                lo = mid
            else:
                hi = mid
        
        if best_delta > 1e-15:
            a[j_hot] -= best_delta
            a[j_cold] += best_delta
            a = np.maximum(a, 0)
            a = a / a.sum()
            best_obj = fast_convolve(a).max()
    
    return a, best_obj

- For binary sequences (+1/-1), the minimum peak auto-correlation grows like sqrt(n) (conjectured, proven for specific families like m-sequences: peak = n/(n-1) or similar).
- For real non-negative sequences, the problem is different.

For our problem (non-negative, sum = 1), the minimum peak of the auto-convolution is what we want to find.

Let me think about this differently. If we use a "random" sequence (entries drawn i.i.d. from some distribution), what's the expected peak of the convolution?

For a[i] ~ Uniform[0, 2/n] (so that E[sum] = 1), the convolution at a typical point k (in the middle) is approximately a sum of min(k+1, 2n-1-k, n) independent terms, each with mean (1/n)^2 = 1/n^2.

The number of terms at the peak (k = n-1) is n, so the expected value is n * 1/n^
