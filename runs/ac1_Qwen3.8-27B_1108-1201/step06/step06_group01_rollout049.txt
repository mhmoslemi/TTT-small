```python
def solve_qp_simplex(W, lr, max_iter=1000):
    """Solve min a^T W a s.t. a in simplex using projected gradient."""
    n = W.shape[0]
    a = np.ones(n) / n
    best_a = a.copy()
    best_val = a @ W @ a
    
    for it in range(max_iter):
        grad = 2 * W @ a
        a_new = proj_simplex(a - lr * grad)
        val = a_new @ W @ a_new
        if val < best_val:
            best_val = val
            best_a = a_new.copy()
        a = a_new
        # Line search / adaptive lr
        if it % 100 == 0:
            # Check convergence
            if np.max(np.abs(a_new - best_a)) < 1e-8:
                break
    
    return best_a, best_val
```

```python
    """Compute gradient of T*log(sum(exp(conv/T))) w.r.t. a.
    p[k] = exp(conv[k]/T) / sum(exp(conv[j]/T))
    Returns 2 * sum_m p_{j+m} * a_m for each j.
    """
    n = len(a)
    # Use FFT for efficiency
    size = 2 * (2*n-1) - 1  # enough for convolution
    size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, size)
    P = np.fft.rfft(p, size)  # p has length 2n-1
    # We want: grad_j = 2 * sum_m p[j+m] * a[m]
    # This is the cross-correlation of p and a
    # corrlac[j] = sum_m p[m+j] * a[m]
    # = (p reversed) * a at appropriate lag
    # Using FFT: IFFT(conj(FFT(p)) * FFT(a)) gives cross-correlation
    X = np.fft.irfft(np.conj(P) * A, size)
    # X[k] = sum_m p[m] * a[m+k] (for appropriate k)
    # We want sum_m p[m+j] * a[m] = X at some lag
    # Let's think differently: 
    # sum_m p[m+j]*a[m] = sum_m p[m+j]*a[m] 
    # Let l = m+j, m = l-j: sum_l p[l]*a[l-j] = (p * a_rev)[2n-2-j] ... 
    # This is getting complicated, let me just do it directly for now
    grad = np.zeros(n)
    for j in range(n):
        grad[j] = 2.0 * np.dot(p[j:j+n], a)
    return grad
```

```python
            p /= p.sum()
            idx = np.arange(n)
            H = p[idx[:,None] + idx[None,:]]
            return 2.0 * H @ a
        
        # Run L-BFGS-B
        result = scipy.optimize.minimize(
            obj, a, jac=grad, method='L-BFGS-B',
            bounds=[(0, None)]*n,
            options={'maxiter': 200, 'ftol': 1e-10, 'gtol': 1e-8}
        )
        
        a_new = np.maximum(result.x, 0)
        if a_new.sum() > 0:
            a_new = a_new / a_new.sum()
            obj_val = fast_convolve(a_new).max()
            if obj_val < best_obj:
                best_obj = obj_val
                best_a = a_new.copy()
        a = a_new
    
    return best_a, best_obj
```

Wait, but L-BFGS-B doesn't handle the normalization constraint sum(a)=1 directly. I should either:
1. Add it as a constraint (but L-BFGS-B doesn't support equality constraints)
2. Work on the simplex using a reparameterization
3. Just normalize after each step (which approximately preserves the optimization direction)

Option 3 is simplest and should work in practice. The normalization is a mild constraint since we're already in the positive orthant.

Actually, let me reconsider. The evaluate_sequence function doesn't require sum(a)=1. It computes:
2*n*max_b / (sum_a)^2

So the scale of a doesn't matter (the objective is scale-invariant). We can work without the normalization constraint and just normalize at the end for evaluation.

But for numerical stability, it's better to keep a normalized during optimization. Let me just normalize after each L-BFGS call.

Let me also think about what T values to use. The convolution values for a normalized sequence (sum=1) are on the order of 1/n to 1. So T should range from maybe 0.01 (sharp, close to true max) to 0.1 (smooth, easier to optimize).

Let me also think about a key trick: **the "peeling" or "deflation" approach**.

If the current bottleneck is a specific peak at lag k*, we can try to "deflate" it by:
- Identifying the variables that most contribute to lag k*: these are pairs (j, k*-j) where both j and k*-j are in [0,n-1]
- Reducing the product a_j * a_{k*-j} for the largest terms
- This can be done by reducing the larger of the pair and redistributing its mass

This is similar to what the peak_coordinate_descent does, but I can make it more efficient by:
- Using analytical 2-variable optimization (for a fixed pair (j, k-j), optimize the split)
- For a pair (j, m) where j+m = k, the contribution to lag k is a_j * a_m. If we fix a_j + a_m = c, the product is maximized at a_j = a_m = c/2 and minimized at the extremes. So to reduce the peak, we want to make the split more uneven.

Actually wait, we want to MINIMIZE the max of the convolution. So if the peak is at lag k, we want to reduce (a*a)_k. The contribution is sum_j a_j * a_{k-j}. To reduce this, we can:
- Reduce individual a_j values (but this affects other lags too)
- Make the "alignments" worse (i.e., for the pairs that contribute to lag k, make the products smaller)

The key trade-off is that reducing a_j helps lag k but hurts other lags where a_j also appears.

Let me also add a completely new idea: **use the dual variable interpretation**.

The problem can be written as:
min_{a >= 0, sum(a)=1} max_k (a*a)_k * 2n

The Lagrangian dual (for the max) gives:
min_{a >= 0, sum(a)=1} max_{p in simplex} 2n * p^T (a*a)

where p is a probability vector over the lags. By minimax:
= max_{p in simplex} min_{a >= 0, sum(a)=1} 2n * p^T (a*a)

The inner problem is: min_{a >= 0, sum(a)=1} 2n * sum_k p_k * (a*a)_k
= min_{a >= 0, sum(a)=1} 2n * a^T H(p) a

where H(p)_{j,m} = p_{j+m}.

This is a QP (possibly non-convex if H(p) is not PSD). But for the optimal p (which is the normalized softmax of the convolution at the solution), H(p) might be close to PSD.

The outer problem is to maximize over p in the simplex. This is a max-min problem. We can alternate:
- Given p, solve the inner QP to get a*
- Update p = softmax((a**a*)/T) for some temperature T

This is essentially the iteratively reweighted approach I discussed earlier. Let me implement this as well.

For the inner QP, if H(p) is PSD (or close to it), we can use projected gradient:
a_{t+1} = proj_simplex(a_t - lr * 2n * H(p) @ a_t)

If H(p) is not PSD, we can still try this (it will find a stationary point of the non-convex QP).

Let me now write the complete solution:

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Smoothed L-BFGS with adaptive temperature annealing
2. Iteratively reweighted quadratic (IRQ) method
3. Peak deflation coordinate refinement
4. Multi-n exploration
5. Simulated annealing with structured moves
"""

import numpy as np
from scipy.optimize import minimize
import time

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def compute_grad_smoothed(a, p):
    """Gradient of smoothed max: 2 * H(p) @ a where H(j,m) = p[j+m]"""
    n = len(a)
    idx = np.arange(n)
    H = p[idx[:, None] + idx[None, :]]
    return 2.0 * H @ a

def smoothed_lbfgs_phase(a0, time_limit, T_schedule=None):
    """
    Smoothed L-BFGS with temperature annealing.
    """
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    if T_schedule is None:
        T_schedule = [0.05, 0.03, 0.02, 0.01, 0.005, 0.003, 0.001]
    
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    t0 = time.monotonic()
    
    for Ti, T in enumerate(T_schedule):
        elapsed = time.monotonic() - t0
        remaining = time_limit - elapsed
        if remaining < 2:
            break
        t_budget = remaining / (len(T_schedule) - Ti)
        
        # Define objective and gradient
        conv = fast_convolve(a)
        
        def obj_grad(x):
            x = np.maximum(x, 0.0)
            xs = x.sum()
            if xs < 1e-15:
                return T, np.zeros(n)
            xn = x / xs
            cnv = fast_convolve(xn)
            scaled = cnv / T
            scaled -= scaled.max()
            val = T * np.log(np.sum(np.exp(scaled)))
            p = np.exp(scaled)
            p /= p.sum()
            idx = np.arange(n)
            H = p[idx[:, None] + idx[None, :]]
            g = 2.0 * H @ xn
            # Adjust for normalization (chain rule)
            g = g - np.sum(g) * xn  # project gradient to tangent space of simplex
            return val, g
        
        # Run L-BFGS-B
        try:
            result = minimize(
                obj_grad, a, jac=True, method='L-BFGS-B',
                bounds=[(0, None)] * n,
                options={'maxiter': int(max(50, t_budget * 50)), 
                         'ftol': 1e-12, 'gtol': 1e-8,
                         'maxfun': int(max(100, t_budget * 100))}
            )
            a_new = np.maximum(result.x, 0.0)
            if a_new.sum() > 1e-15:
                a_new = a_new / a_new.sum()
                obj_val = fast_convolve(a_new).max()
                if obj_val < best_obj:
                    best_obj = obj_val
                    best_a = a_new.copy()
                    print(f"    T={T}: improved to {best_obj:.8f}")
                a = a_new
        except Exception as e:
            print(f"    T={T}: L-BFGS failed: {e}")
            break
        
        elapsed = time.monotonic() - t0
        if time.monotonic() - t0 > time_limit - 1:
            break
    
    return best_a, best_obj

def irq_method(a0, time_limit, n_iter_max=5000):
    """
    Iteratively Rewearded Quadratic method.
    Alternates between:
    1. Computing weights w = softmax(conv/T)
    2. Running projected gradient on min a^T H(w) a s.t. a in simplex
    """
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    t0 = time.monotonic()
    
    T = 0.02
    idx = np.arange(n)
    
    for outer in range(n_iter_max):
        if time.monotonic() - t0 > time_limit - 0.5:
            break
        
        # Compute weights
        conv = fast_convolve(a)
        scaled = conv / T
        scaled -= scaled.max()
        w = np.exp(scaled)
        w /= w.sum()
        
        # Build Hankel matrix
        H = w[idx[:, None] + idx[None, :]]
        
        # Projected gradient on min a^T H a s.t. a in simplex
        lr = 1.0 / (2.0 * np.abs(H).max() * 2 * n)  # conservative
        lr = max(lr, 0.001)
        lr = min(lr, 0.1)
        
        for inner in range(200):
            if time.monotonic() - t0 > time_limit - 0.5:
                break
            grad = 2.0 * H @ a
            a_new = project_simplex(a - lr * grad)
            if np.max(np.abs(a_new - a)) < 1e-10:
                break
            a = a_new
        
        # Check improvement
        obj_val = fast_convolve(a).max()
        if obj_val < best_obj - 1e-12:
            best_obj = obj_val
            best_a = a.copy()
        
        # Anneal temperature
        if outer % 50 == 49:
            T *= 0.85
            if T < 0.001:
                T = 0.001
        
        # Restart if stuck
        if outer % 200 == 199:
            # Check if we're making progress
            pass
    
    return best_a, best_obj

def peak_deflation(a0, time_limit):
    """
    Targeted peak reduction: for each top peak, find the best 2-variable
    adjustment to reduce it while minimizing damage to other peaks.
    """
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    t0 = time.monotonic()
    
    for iteration in range(10000):
        if time.monotonic() - t0 > time_limit - 0.5:
            break
        
        conv = fast_convolve(a)
        peak_val = conv.max()
        
        if peak_val < best_obj:
            best_obj = peak_val
            best_a = a.copy()
        
        # Get top 3 peaks
        top_k = min(3, len(conv))
        peak_lags = np.argsort(conv)[::-1][:top_k]
        
        improved = False
        for k_peak in peak_lags:
            k_peak = int(k_peak)
            # Variables affecting this peak: j in [max(0, k-n+1), min(n-1, k)]
            js = max(0, k_peak - n + 1)
            je = min(n - 1, k_peak)
            if je - js + 1 < 2:
                continue
            
            # For each j in this range, the partner is k_peak - j
            # Contribution of pair (j, k-j) to lag k is a[j] * a[k-j]
            # To reduce the peak, we want to reduce these products
            # Strategy: for the pair with largest product, make the split more uneven
            
            max_product = 0
            best_pair = None
            for j in range(js, je + 1):
                partner = k_peak - j
                if 0 <= partner < n and partner != j:
                    prod = a[j] * a[partner]
                    if prod > max_product:
                        max_product = prod
                        best_pair = (j, partner)
                elif 0 <= partner < n and partner == j:
                    # a[j]^2 term
                    prod = a[j] ** 2
                    if prod > max_product:
                        max_product = prod
                        best_pair = (j, j)
            
            if best_pair is None:
                continue
            
            j1, j2 = best_pair
            
            if j1 == j2:
                # Self-term: a[j]^2. Can only reduce by reducing a[j]
                # Transfer mass from j to some other index
                # Find index m that doesn't contribute to this peak
                # (i.e., m + j != k_peak and m != k_peak - j when m is used)
                # Actually, a[m] contributes to lag k_peak if m is in [js, je] or k_peak-m is in [js, je]
                # This is complex. Just try transferring to a random index with small value.
                candidates = np.argsort(a)[:n//4]  # smallest values
                for m in candidates:
                    if m == j1:
                        continue
                    # Check if transferring hurts other peaks too much
                    for frac in [0.05, 0.1, 0.2]:
                        delta = a[j1] * frac
                        a_test = a.copy()
                        a_test[j1] -= delta
                        a_test[m] += delta
                        a_test = np.maximum(a_test, 0.0)
                        if a_test.sum() < 1e-15:
                            continue
                        a_test = a_test / a_test.sum()
                        c_new = fast_convolve(a_test)
                        if c_new.max() < best_obj - 1e-12:
                            a = a_test
                            best_obj = c_new.max()
                            best_a = a.copy()
                            improved = True
                            break
                    if improved:
                        break
            else:
                # Cross-term: a[j1] * a[j2]. Make split more uneven.
                total = a[j1] + a[j2]
                # Currently at ratio r = a[j1]/total. Optimal for min product is r=0 or r=1.
                # Try moving mass from the larger to the smaller
                if a[j1] > a[j2]:
                    src, dst = j1, j2
                else:
                    src, dst = j2, j1
                
                for frac in [0.05, 0.1, 0.2, 0.3, 0.5]:
                    delta = a[src] * frac
                    a_test = a.copy()
                    a_test[src] -= delta
                    a_test[dst] += delta
                    a_test = np.maximum(a_test, 0.0)
                    if a_test.sum() < 1e-15:
                        continue
                    a_test = a_test / a_test.sum()
                    c_new = fast_convolve(a_test)
                    if c_new.max() < best_obj - 1e-12:
                        a = a_test
                        best_obj = c_new.max()
                        best_a = a.copy()
                        improved = True
                        break
        
        if not improved and iteration > 0 and iteration % 50 == 0:
            # Perturb to escape local minimum
            rng = np.random.default_rng(iteration * 7919 + 13)
            noise = rng.standard_normal(n) * 0.002
            a = project_simplex(best_a + noise)
    
    return best_a, best_obj

def simulated_annealing_structured(a0, time_limit, T_start=0.01, T_end=0.0001):
    """
    Simulated annealing with structured moves informed by convolution structure.
    Moves: 
    1. Redistribute mass from a high-value index to a low-value index
    2. Swap mass between two indices
    3. "Peak deflation" move: reduce the index that most contributes to the current peak
    """
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    current_obj = best_obj
    t0 = time.monotonic()
    
    n_iters = 0
    total_iters_est = time_limit * 50  # rough estimate
    
    for it in range(total_iters_est):
        if time.monotonic() - t0 > time_limit - 0.5:
            break
        n_iters += 1
        
        # Temperature schedule (geometric cooling)
        progress = min(1.0, n_iters / max(1, total_iters_est))
        T_sa = T_start * (T_end / T_start) ** progress
        
        conv = fast_convolve(a)
        peak_k = int(np.argmax(conv))
        
        # Choose move type
        rng = np.random.default_rng()
        move_type = rng.random()
        
        a_new = a.copy()
        
        if move_type < 0.4:
            # Peak deflation: reduce index that contributes most to peak
            js = max(0, peak_k - n + 1)
            je = min(n - 1, peak_k)
            # Find j with largest contribution to peak
            contributions = np.array([a[j] * a[peak_k - j] for j in range(js, je + 1) 
                                     if 0 <= peak_k - j < n])
            if len(contributions) > 0 and contributions.max() > 0:
                best_j_offset = np.argmax(contributions)
                j = js + best_j_offset
                partner = peak_k - j
                
                # Transfer mass from j (or partner) to a random other index
                src = j if a[j] >= a[partner] else partner
                if a[src] > 1e-10:
                    # Choose destination: prefer indices far from peak contributors
                    dst_candidates = np.random.choice(n, size=min(10, n), replace=False)
                    for dst in dst_candidates:
                        if dst == src:
                            continue
                        delta = a[src] * rng.uniform(0.01, 0.15)
                        a_new = a.copy()
                        a_new[src] -= delta
                        a_new[dst] += delta
                        a_new = np.maximum(a_new, 0.0)
                        if a_new.sum() < 1e-15:
                            break
                        a_new = a_new / a_new.sum()
                        break
        elif move_type < 0.7:
            # Random redistribution
            i = rng.integers(n)
            j = rng.integers(n)
            if i != j and a[i] > 1e-10:
                delta = a[i] * rng.uniform(0.01, 0.2)
                a_new[i] -= delta
                a_new[j] += delta
                a_new = np.maximum(a_new, 0.0)
                if a_new.sum() > 1e-15:
                    a_new = a_new / a_new.sum()
        else:
            # Small Gaussian perturbation
            noise = rng.standard_normal(n) * 0.005
            a_new = project_simplex(a + noise)
        
        # Evaluate
        if a_new.sum() > 1e-15:
            new_obj = fast_convolve(a_new).max()
            delta_obj = new_obj - current_obj
            if delta_obj < 0 or rng.random() < np.exp(-delta_obj / max(T_sa, 1e-10)):
                a = a_new
                current_obj = new_obj
                if new_obj < best_obj:
                    best_obj = new_obj
                    best_a = a.copy()
    
    return best_a, best_obj
```
