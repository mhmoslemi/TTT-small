    rho = np.nonzero(cond)[0][-1]

    return np.maximum(v - theta, 0.0)

Actually, one more thought: the "swap-based local search" might be very effective as a final polish. The idea:

For each pair (i, j), consider transferring a small amount of mass from i to j (or vice versa). If this reduces the peak of the convolution, accept the move.

To make this efficient:
- Only consider pairs that are "likely" to help (e.g., from high-autocorrelation-contribution positions to low ones)
- Use a binary search to find the optimal transfer amount
- Limit the number of pairs considered per iteration

Actually, for the swap to reduce the peak at position k*, we need:
- The position i contributes a[i]*a[k*-i] to conv[k*]
- Moving mass from i to j changes conv[k*] by: -δ*a[k*-i] + δ*a[k*-j] (approximately, for small δ)
- This reduces conv[k*] if a[k*-j] < a[k*-i]

So we want to move mass from positions i where a[k*-i] is large to positions j where a[k*-j] is small.

This is the same insight as the gradient! The gradient points in the direction of reducing the peak.
