   So the KKT conditions are:
   1. sum_k y_k = 1, y_k >= 0
   2. y_k > 0 => (a*a)[k] = t (i.e., y is supported on A*)
   3. For j with a[j] > 0: 2*sum_{k in A*} y_k * a[k-j] = -eta (constant)
   4. For j with a[j] = 0: 2*sum_{k in A*} y_k * a[k-j] >= -eta
   5. 1^T a = 1, a >= 0

   Condition 3 says: for all j in the support of a, the weighted sum of a[k-j] over active lags is constant.

   Let me denote `c_j = sum_{k in A*} y_k * a[k-j]` (with the boundary handling). Then condition 3 is: `c_j = -eta/2` for all j in support.

   This is a system of linear equations in a (the unknowns are a[0],...,a[n-1] and eta).

   If the support is all of {0,...,n-1} (a[j] > 0 for all j), then we have n equations:
   `sum_{k in A*} y_k * a[k-j] = -eta/2` for j = 0, ..., n-1

   Plus the normalization: sum a = 1.

   That's n+1 equations in n+1 unknowns (a[0],...,a[n-1], eta). We can solve this linear system!

   But we need to verify that the solution has a[j] > 0 for all j and that the max is indeed at A*.

   If the solution violates a[j] >= 0 for some j, we set a[j] = 0 and remove that equation, reducing the system.

   This is essentially an active-set method for the KKT system!

   **Algorithm for KKT polish:**
   1. Start with a good candidate a (from FW or subgradient).
   2. Identify the active set A* (lags where (a*a)[k] is within epsilon of max).
   3. Set y_k = 1/|A*| for k in A* (equal weights as initial guess).
   4. Solve the linear system: for j in support, `sum_{k in A*} y_k * a[k-j] = C` (where C = -eta/2), and `sum a = 1`.
   5. Check: is a[j] >= 0 for all j? Is the max at A*?
   6. If not, adjust (set a[j]=0 for negative j, update A* based on new max, go to step 4).
   7. Repeat until convergence.

   Wait, but y_k should also be optimized. In the KKT system, y_k are unknowns too. So we have:
   - Unknowns: a[0],...,a[n-1], eta, y_{k_1},...,y_{k_s} (where A* = {k_1,...,k_s})
   - Equations:
     a. `sum_{k in A*} y_k * a[k-j] = C` for j in support (|support| equations)
     b. `sum a = 1` (1 equation)
     c. `sum y_k = 1` (1 equation)
     d. `y_k >= 0` (inequality)
     e. `a[j] >= 0` for all j (inequality)
     f. Complementary slackness: for j not in support, `sum_{k in A*} y_k * a[k-j] >= C`

   This is a quadratic system (because of the products y_k * a[k-j]). So it's not linear in the combined variables.

   However, if we fix y, it's linear in a. And if we fix a, the condition "sum y_k * a[k-j] = C for all j in support" is linear in y (with C as an additional unknown).

   So we can use an alternating approach:
   1. Fix y, solve for a (linear system).
   2. Fix a, solve for y (linear system / LP).
   3. Iterate.

   Step 2: Given a, find y >= 0 such that `sum_k y_k * a[k-j] = C` for all j in support, and `sum y = 1`.
   This is a linear system in (y, C) with |support| + 1 unknowns (y_{k_1}, ..., y_{k_s}, C) and |support| + 1 equations. If |support| = s, we have s+1 unknowns and s+1 equations. Solvable!

   But we also need y >= 0. So it's a linear system with inequality constraints on y. We can solve it as a small LP or just solve the linear system and check.

   Let me formalize:

   Let S = support(a) = {j : a[j] > 0}, |S| = m.
   Let A = active set = {k_1, ..., k_s}, |A| = s.

   From KKT:
   (i) For each j in S: `sum_{i=1}^{s} y_{k_i} * a[k_i - j] = C` (where a[k_i - j] is defined as 0 if k_i - j is not in [0, n-1])
   (ii) `sum_{i=1}^{s} y_{k_i} = 1`
   (iii) `sum_{j=0}^{n-1} a[j] = 1`
   (iv) `y_{k_i} >= 0`
   (v) `a[j] >= 0`
   (vi) For j not in S: `sum_{i=1}^{s} y_{k_i} * a[k_i - j] >= C`

   If m = s + 1 (one more support variable than active lags), then equations (i) give m equations in s+1 unknowns (y_{k_1},...,y_{k_s}, C). This is solvable!

   If m = s + 1, we can solve for (y, C) from (i) and (ii). Then check y >= 0.

   Then, given y, from (i): `sum_{i=1}^{s} y_{k_i} * a[k_i - j] = C` for j in S.
   This is m equations in m unknowns (a[j] for j in S). We can solve for a!

import numpy as np
from scipy.optimize import linprog
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    if n == 1:
        return np.array([a[0] * a[0]])
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = (u * np.arange(1, n + 1) > (cssv - 1))
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def solve_lp_oracle(f, M, time_limit=10):
    """Solve LP: max sum(g) s.t. (f*g)[k] <= M for all k, g >= 0."""
    n = len(f)
    c = -np.ones(n)
    A_ub = np.zeros((2 * n - 1, n))
    for j in range(n):
        A_ub[j:j + n, j] = f
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': time_limit})
        if res.success:
            g = np.maximum(res.x, 0.0)
            if g.sum() > 1e-15:
                return g
    except Exception:
        pass
    return None


def compute_conv_gradient(a, k):
    """Compute gradient of conv(a,a)[k] w.r.t. a."""
    n = len(a)
    grad = np.zeros(n)
    for j in range(n):
        partner = k - j
        if 0 <= partner < n:
            if partner == j:
                grad[j] = a[j]
            else:
                grad[j] = a[partner]
    return 2.0 * grad - np.where(np.arange(n) == k - np.arange(n), a, 0) if False else grad


def conv_grad(a, k):
    """Gradient of conv(a,a)[k] w.r.t. a. Result[j] = 2*a[k-j] if valid, with correction for j=k/2."""
    n = len(a)
    grad = np.zeros(n)
    js = max(0, k - n + 1)
    je = min(n - 1, k)
    for j in range(js, je + 1):
        partner = k - j
        if partner == j:
            grad[j] = 2.0 * a[j]
        else:
            grad[j] = 2.0 * a[partner]
    return grad


def conv_grad_fast(a, ks):
    """Compute weighted sum of conv gradients for multiple lags."""
    n = len(a)
    total = np.zeros(n)
    for idx, k in enumerate(ks):
        k = int(k)
        js = max(0, k - n + 1)
        je = min(n - 1, k)
        for j in range(js, je + 1):
            partner = k - j
            if partner == j:
                total[j] += 2.0 * a[partner]
            else:
                total[j] += 2.0 * a[partner]
    return total


def fw_lp_optimize(f0, time_limit, verbose=False):
    """Frank-Wolfe with LP oracle."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)

    conv = fast_convolve(f)
    M = conv.max()
    best_obj = M
    best_f = f.copy()

    t0 = time.monotonic()
    no_improve = 0
    it = 0
    m_exp = 1.0

    while time.monotonic() - t0 < time_limit:
        it += 1
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 0.5:
            break

        lp_time = min(15, max(2, remaining * 0.3))
        g = solve_lp_oracle(f, M * m_exp, time_limit=lp_time)
        if g is None:
            m_exp = min(m_exp * 1.2, 5.0)
            if m_exp > 4.0:
                g = np.ones(n) / n
                m_exp = 1.0
            else:
                continue

        g_sum = g.sum()
        if g_sum < 1e-15:
            break
        g = g / g_sum

        if np.max(np.abs(g - f)) < 1e-10:
            no_improve += 1
            if no_improve > 50:
                break
            m_exp = min(m_exp * 1.05, 3.0)
            continue

        best_alpha = 0.0
        best_val = M
        for alpha in [0.01, 0.03, 0.05, 0.1, 0.2, 0.3, 0.5, 0.7, 1.0]:
            ft = (1.0 - alpha) * f + alpha * g
            ft = np.maximum(ft, 0.0)
            st = ft.sum()
            if st < 1e-15:
                continue
            ft = ft / st
            val = fast_convolve(ft).max()
            if val < best_val:
                best_val = val
                best_alpha = alpha

        if best_alpha > 1e-12:
            f = (1.0 - best_alpha) * f + best_alpha * g
            f = np.maximum(f, 0.0)
            f = f / f.sum()
            conv = fast_convolve(f)
            M = conv.max()
            m_exp = 1.0

            if M < best_obj - 1e-15:
                best_obj = M
                best_f = f.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1
            m_exp = min(m_exp * 1.1, 5.0)

        if no_improve > 30:
            rng = np.random.default_rng(it * 104729 + 7)
            noise = rng.standard_normal(n) * 0.001
            f = project_simplex(best_f + noise)
            conv = fast_convolve(f)
            M = conv.max()
            m_exp = 1.0
            no_improve = 0

    return best_f, best_obj


def kkt_polish(a0, time_limit, verbose=False):
    """
    KKT-based polishing: identify active set, solve the KKT linear system,
    and iterate until convergence.
    """
    a = np.maximum(a0.astype(np.float64), 0.0)
    a = a / a.sum()
    n = len(a)

    best_a = a.copy()
    best_obj = fast_convolve(a).max()

    t0 = time.monotonic()
    it = 0

    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit - 0.1:
            break

        conv = fast_convolve(a)
        max_val = conv.max()

        # Identify active set: lags within tolerance of max
        tol = max(1e-6, 0.001 * max_val)
        active = np.where(conv >= max_val - tol)[0]

        if len(active) == 0:
            active = np.array([int(np.argmax(conv))])

        # Support of a
        support_thresh = 1e-10
        support = np.where(a > support_thresh)[0]
        m = len(support)
        s = len(active)

        if m == 0 or s == 0:
            break

        # Try to solve KKT system
        # Variables: a[j] for j in support, y_k for k in active, C
        # Equations:
        #   For each j in support: sum_{k in active} y_k * a[k-j] = C
        #   sum_{k in active} y_k = 1
        #   sum_{j in support} a[j] = 1
        #   a[j] >= 0, y_k >= 0

        # Phase 1: Fix y (equal weights), solve for a
        y = np.ones(s) / s

        # Build system: for j in support, sum_{i} y_i * a[active[i]-j] = C
        # Unknowns: a[support[0]], ..., a[support[m-1]], C
        # Total: m+1 unknowns, m equations (from conv constraints) + 1 (normalization) = m+1 equations

        # Matrix A_sys of size (m+1) x (m+1)
        # Rows 0..m-1: conv constraint for support[j]
        # Row m: normalization
        A_sys = np.zeros((m + 1, m + 1))
        b_sys = np.zeros(m + 1)

        for ii, j in enumerate(support):
            # sum_{i} y_i * a[active[i] - j] = C
            for i, k in enumerate(active):
                partner = k - j
                if 0 <= partner < n:
                    # a[partner] is in support?
                    idx_in_support = np.where(support == partner)[0]
                    if len(idx_in_support) > 0:
                        A_sys[ii, idx_in_support[0]] += y[i]
                    # If partner not in support, a[partner] = 0, contributes nothing
            A_sys[ii, m] = -1.0  # -C
            b_sys[ii] = 0.0

        # Normalization: sum a[j] for j in support = 1
        for ii in range(m):
            A_sys[m, ii] = 1.0
        b_sys[m] = 1.0

        try:
            sol = np.linalg.solve(A_sys, b_sys)
        except np.linalg.LinAlgError:
            try:
                sol = np.linalg.lstsq(A_sys, b_sys, rcond=None)[0]
            except Exception:
                break

        a_new = np.zeros(n)
        C_val = sol[m]
        for ii, j in enumerate(support):
            a_new[j] = sol[ii]

        # Check non-negativity
        if np.any(a_new[a_new > 0] < -1e-6):
            # Some variables went negative; clamp and retry with smaller support
            a_new = np.maximum(a_new, 0.0)
            sn = a_new.sum()
            if sn < 1e-12:
                break
            a_new = a_new / sn
        else:
            a_new = np.maximum(a_new, 0.0)
            sn = a_new.sum()
            if sn < 1e-12:
                break
            a_new = a_new / sn

        # Check if max is at active set
        conv_new = fast_convolve(a_new)
        new_max = conv_new.max()
        new_active = np.where(conv_new >= new_max - tol)[0]

        # Phase 2: Fix a, solve for y
        # For j in support: sum_{i} y_i * a_new[active[i]-j] = C
        # sum y_i = 1
        # Unknowns: y_0,...,y_{s-1}, C -> s+1 unknowns
        # Equations: m (conv) + 1 (normalization of y) = m+1
        # If m == s, we have s+1 unknowns and s+1 equations. Good.
        # If m != s, use least squares.

        A_y = np.zeros((m + 1, s + 1))
        b_y = np.zeros(m + 1)

        for ii, j in enumerate(support):
            for i, k in enumerate(active):
                partner = k - j
                if 0 <= partner < n:
                    A_y[ii, i] += a_new[partner]
            A_y[ii, s] = -1.0  # -C
            b_y[ii] = 0.0

        for i in range(s):
            A_y[m, i] = 1.0
        b_y[m] = 1.0

        try:
            if (m + 1) == (s + 1):
                y_sol = np.linalg.solve(A_y, b_y)
            else:
                y_sol = np.linalg.lstsq(A_y, b_y, rcond=None)[0]
        except Exception:
            y_sol = np.ones(s + 1) / (s + 1)

        y_new = np.maximum(y_sol[:s], 0.0)
        y_sum = y_new.sum()
        if y_sum < 1e-12:
            y_new = np.ones(s) / s
        else:
            y_new = y_new / y_sum

        # Update a using new y (rerun phase 1 with updated y)
        A_sys2 = np.zeros((m + 1, m + 1))
        b_sys2 = np.zeros(m + 1)
        for ii, j in enumerate(support):
            for i, k in enumerate(active):
                partner = k - j
                if 0 <= partner < n:
                    idx_in_support = np.where(support == partner)[0]
                    if len(idx_in_support) > 0:
                        A_sys2[ii, idx_in_support[0]] += y_new[i]
            A_sys2[ii, m] = -1.0
            b_sys2[ii] = 0.0
        for ii in range(m):
            A_sys2[m, ii] = 1.0
        b_sys2[m] = 1.0

        try:
            sol2 = np.linalg.solve(A_sys2, b_sys2)
        except np.linalg.LinAlgError:
            try:
                sol2 = np.linalg.lstsq(A_sys2, b_sys2, rcond=None)[0]
            except Exception:
                break

        a_new2 = np.zeros(n)
        for ii, j in enumerate(support):
            a_new2[j] = sol2[ii]
        a_new2 = np.maximum(a_new2, 0.0)
        sn2 = a_new2.sum()
        if sn2 < 1e-12:
            break
        a_new2 = a_new2 / sn2

        conv_final = fast_convolve(a_new2)
        obj_final = conv_final.max()

        if obj_final < best_obj - 1e-14:
            best_obj = obj_final
            best_a = a_new2.copy()
            a = a_new2.copy()
        else:
            # Try updating active set and continuing
            active_new = np.where(conv_final >= conv_final.max() - tol)[0]
            if len(active_new) != len(active):
                active = active_new
            else:
                # Converged or stuck
                if np.max(np.abs(a_new2 - a)) < 1e-10:
                    break

    return best_a, best_obj


def nesterov_subgradient(a0, time_limit, lr_init=0.003, max_k=20):
    """Nesterov-accelerated subgradient with adaptive peak tracking."""
    a = np.maximum(a0.astype(np.float64), 0.0)
    a = a / a.sum()
    n = len(a)

    y = a.copy()
    v = np.zeros(n)
    t_nest = 1.0
    lr = lr_init
    best_a = a.copy()
    best_obj = fast_convolve(a).max()

    t0 = time.monotonic()
    no_improve = 0
    it = 0

    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit - 0.1:
            break

        alpha = (1.0 + np.sqrt(1.0 + 4.0 * t_nest * t_nest)) / 2.0
        beta = (t_nest - 1.0) / alpha
        y = (1.0 + beta) * a - beta * y
        y = np.maximum(y, 0.0)
        ys = y.sum()
        if ys < 1e-15:
            y = a.copy()
        else:
            y = y / ys
        t_nest += 1.0

        conv = fast_convolve(y)
        max_k_eff = min(max_k, len(conv))
        peaks = np.argpartition(conv, -max_k_eff)[-max_k_eff:]
        pv = conv[peaks]
        order = np.argsort(pv)[::-1]

        # Use softmax-like weights
        T = 0.01 * max_val if max_val > 0 else 0.01
        weights = np.exp(-pv[order] / (T * max_val + 1e-15))
        weights = weights / weights.sum()

        sg = np.zeros(n)
        for rank, idx in enumerate(order):
            w = weights[rank]
            if w < 1e-12:
                continue
            k = int(peaks[idx])
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            for j in range(js, je + 1):
                partner = k - j
                if partner == j:
                    sg[j] += w * 2.0 * y[partner]
                else:
                    sg[j] += w * 2.0 * y[partner]

        v = beta * v - lr * sg
        a_new = a + v
        a_new = project_simplex(a_new)

        obj = fast_convolve(a_new).max()
        if obj < best_obj - 1e-14:
            best_obj = obj
            best_a = a_new.copy()
            no_improve = 0
        else:
            no_improve += 1

        a = a_new
        lr *= (1.0 - 0.0003)

        if no_improve > 80:
            rng = np.random.default_rng((it * 31 + 7) % (2**31))
            noise_scale = 0.001 * min(1.0, np.sqrt(no_improve / 80.0))
            a = project_simplex(best_a + rng.standard_normal(n) * noise_scale)
            y = a.copy()
            v = np.zeros(n)
            t_nest = 1.0
            no_improve = 0

    return best_a, best_obj


def smoothed_gradient(a0, time_limit, T_init=0.001, lr_init=0.02):
    """Smoothed gradient descent with softmax-weighted peaks."""
    a = np.maximum(a0.astype(np.float64), 0.0)
    a = a / a.sum()
    n = len(a)

    T = T_init
    lr = lr_init
    best_a = a.copy()
    best_obj = fast_convolve(a).max()

    t0 = time.monotonic()
    no_improve = 0
    it = 0

    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit - 0.1:
            break

        conv = fast_convolve(a)
        scaled = conv / T
        scaled -= scaled.max()
        p = np.exp(scaled)
        p = p / p.sum()

        # Gradient: sum_k p[k] * grad_k
        grad = np.zeros(n)
        for k_idx in range(len(p)):
            if p[k_idx] < 1e-14:
                continue
            k = k_idx
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            for j in range(js, je + 1):
                partner = k - j
                if partner == j:
                    grad[j] += p[k_idx] * 2.0 * a[partner]
                else:
                    grad[j] += p[k_idx] * 2.0 * a[partner]

        best_candidate = a
        best_val = conv.max()
        for trial_lr in [lr, lr * 0.5, lr * 0.25, lr * 0.1]:
            candidate = project_simplex(a - trial_lr * grad)
            c = fast_convolve(candidate)
            val = c.max()
            if val < best_val - 1e-15:
                best_val = val
                best_candidate = candidate

        a = best_candidate

        if best_val < best_obj - 1e-14:
            best_obj = best_val
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1

        if no_improve > 20:
            T *= 1.05
            lr *= 0.98
        if no_improve > 150:
            T = T_init
            lr = lr_init
            rng = np.random.default_rng((it * 31 + 7) % (2**31))
            a = project_simplex(best_a + rng.standard_normal(n) * 0.002)
            no_improve = 0

    return best_a, best_obj


def micro_polish(a0, time_limit):
    """Fine perturbation-based polish."""
    a = np.maximum(a0.astype(np.float64), 0.0)
    a = a / a.sum()
    n = len(a)

    best_a = a.copy()
    best_obj = fast_convolve(a).max()

    t0 = time.monotonic()
    it = 0
    scales = [0.0001, 0.0003, 0.0005, 0.001, 0.002]
    si = 0

    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit - 0.1:
            break

        scale = scales[si % len(scales)]
        rng = np.random.default_rng((it * 2654435761 + 1) % (2**32))

        for _ in range(8):
            if time.monotonic() - t0 > time_limit - 0.2:
                break
            convex = fast_convolve(a)
            peak_k = int(np.argmax(convex))
            js = max(0, peak_k - n + 1)
            je = min(n - 1, peak_k)

            noise = rng.standard_normal(n) * scale
            for j in range(js, je + 1):
                partner = peak_k - j
                if 0 <= partner < n:
                    noise[j] -= scale * 1.5 * a[partner]

            candidate = project_simplex(a + noise)
            c = fast_convolve(candidate)
            if c.max() < best_obj - 1e-15:
                a = candidate
                best_obj = c.max()
                best_a = a.copy()
                break

        if it % 50 == 0:
            si += 1

    return best_a, best_obj


def propose_candidate(seed=42, budget_s=1800):
    """
    Main entry point. Multi-phase hybrid search combining FW-LP,
    KKT polishing, Nesterov subgradient, and micro-polish.
    """
    rng = np.random.default_rng(seed)
    t0_total = time.monotonic()
    deadline = t0_total + max(10.0, float(budget_s) - 20.0)

    best_seq = None
    best_score = float('inf')

    def try_seq(a, label=""):
        nonlocal best_seq, best_score
        a = np.maximum(a, 0.0)
        s = a.sum()
        if s < 1e-15:
            return float('inf')
        a_norm = a / s
        score = float(evaluate_sequence(a_norm.tolist()))
        if np.isfinite(score) and score < best_score:
            best_score = score
            best_seq = a_norm.copy()
            elapsed = time.monotonic() - t0_total
            print(f"  NEW BEST [{label}]: {score:.8f} (n={len(a)}, t={elapsed:.0f}s)")
        return score

    # Load parent
    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            parent = p / p.sum()
            ps = evaluate_sequence(parent.tolist())
            print(f"Parent loaded: n={len(parent)}, score={ps:.8f}")
            try_seq(parent, "parent")
    except Exception as e:
        print(f"Could not load parent: {e}")

    if parent is None:
        parent = np.ones(768) / 768

    n_parent = len(parent)

    # === Phase 1: Multi-n FW exploration (~300s) ===
    print("\n=== Phase 1: Multi-n FW Exploration ===")
    t_phase = time.monotonic()

    candidate_ns = sorted(set([n_parent, max(256, n_parent - 128), min(1200, n_parent + 128),
                                512, 640, 768, 896, 1024]))
    candidate_ns = [n for n in candidate_ns if 256 <= n <= 1200]

    for n_try in candidate_ns:
        if time.monotonic() > deadline - 1200:
            break

        if n_try == n_parent:
            start = parent.copy()
        else:
            start = np.interp(np.linspace(0, 1, n_try),
                              np.linspace(0, 1, n_parent), parent)
            start = np.maximum(start, 0)
            ss = start.sum()
            if ss > 1e-10:
                start = start / ss
            else:
                start = np.ones(n_try) / n_try

        t_alloc = min(40, max(10, deadline - time.monotonic() - 1200))
        if t_alloc < 5:
            break
        print(f"  FW n={n_try}, t={t_alloc:.0f}s")
        a_opt, _ = fw_lp_optimize(start, time_limit=t_alloc)
        try_seq(a_opt, f"fw_n{n_try}")

    print(f"  Phase 1 best: {best_score:.8f} ({time.monotonic()-t_phase:.0f}s)")

    # === Phase 2: Deep FW on best (~400s) ===
    print("\n=== Phase 2: Deep FW ===")
    t_phase = time.monotonic()

    if best_seq is not None:
        n_best = len(best_seq)
        t_alloc = min(300, max(50, deadline - time.monotonic() - 600))
        if t_alloc > 20:
            print(f"  Deep FW n={n_best}, t={t_alloc:.0f}s")
            a_opt, _ = fw_lp_optimize(best_seq, time_limit=t_alloc)
            try_seq(a_opt, "deep_fw")

        # Perturbed restarts
        for scale in [0.003, 0.008]:
            t_alloc = min(60, max(10, deadline - time.monotonic() - 500))
            if t_alloc < 10:
                break
            f_pert = project_simplex(best_seq + rng.standard_normal(n_best) * scale)
            a_opt, _ = fw_lp_optimize(f_pert, time_limit=t_alloc)
            try_seq(a_opt, f"fw_pers{scale}")

    print(f"  Phase 2 best: {best_score:.8f} ({time.monotonic()-t_phase:.0f}s)")

    # === Phase 3: KKT Polish (~300s) ===
    print("\n=== Phase 3: KKT Polish ===")
    t_phase = time.monotonic()

    if best_seq is not None:
        t_alloc = min(200, max(30, deadline - time.monotonic() - 400))
        if t_alloc > 10:
            print(f"  KKT polish n={len(best_seq)}, t={t_alloc:.0f}s")
            a_opt, _ = kkt_polish(best_seq, time_limit=t_alloc)
            try_seq(a_opt, "kkt")

            # Another round with slightly different tolerance
            if time.monotonic() < deadline - 300:
                t_alloc2 = min(80, max(10, deadline - time.monotonic() - 300))
                if t_alloc2 > 5:
                    a_opt2, _ = kkt_polish(a_opt, time_limit=t_alloc2)
                    try_seq(a_opt2, "kkt2")

    print(f"  Phase 3 best: {best_score:.8f} ({time.monotonic()-t_phase:.0f}s)")

    # === Phase 4: Nesterov Subgradient (~250s) ===
    print("\n=== Phase 4: Nesterov Subgradient ===")
    t_phase = time.monotonic()

    if best_seq is not None:
        configs = [
            {'lr_init': 0.003, 'max_k': 20},
            {'lr_init': 0.006, 'max_k': 40},
            {'lr_init': 0.002, 'max_k': 15},
        ]
        for ci, cfg in enumerate(configs):
            t_alloc = min(80, max(10, deadline - time.monotonic() - 250))
            if t_alloc < 10:
                break
            print(f"  Nesterov cfg{ci}, t={t_alloc:.0f}s")
            a_opt, _ = nesterov_subgradient(best_seq, time_limit=t_alloc, **cfg)
            try_seq(a_opt, f"nest_{ci}")

    print(f"  Phase 4 best: {best_score:.8f} ({time.monotonic()-t_phase:.0f}s)")

    # === Phase 5: Smoothed Gradient (~150s) ===
    print("\n=== Phase 5: Smoothed Gradient ===")
    t_phase = time.monotonic()

    if best_seq is not None:
        for T_init, lr_init in [(0.0005, 0.015), (0.002, 0.01), (0.001, 0.025)]:
            t_alloc = min(50, max(10, deadline - time.monotonic() - 150))
            if t_alloc < 5:
                break
            print(f"  Smooth T={T_init}, lr={lr_init}, t={t_alloc:.0f}s")
            a_opt, _ = smoothed_gradient(best_seq, time_limit=t_alloc,
                                          T_init=T_init, lr_init=lr_init)
            try_seq(a_opt, f"smooth_T{T_init}")

    print(f"  Phase 5 best: {best_score:.8f} ({time.monotonic()-t_phase:.0f}s)")

    # === Phase 6: Final Micro-Polish + KKT (~150s) ===
    print("\n=== Phase 6: Final Polish ===")
    t_phase = time.monotonic()

    if best_seq is not None:
        t_alloc = min(60, max(10, deadline - time.monotonic() - 60))
        if t_alloc > 5:
            print(f"  Micro polish, t={t_alloc:.0f}s")
            a_opt, _ = micro_polish(best_seq, time_limit=t_alloc)
            try_seq(a_opt, "micro")

        t_alloc = min(50, max(10, deadline - time.monotonic() - 40))
        if t_alloc > 5:
            print(f"  Final KKT, t={t_alloc:.0f}s")
            a_opt, _ = kkt_polish(best_seq, time_limit=t_alloc)
            try_seq(a_opt, "final_kkt")

        t_alloc = min(30, max(5, deadline - time.monotonic() - 20))
        if t_alloc > 3:
            print(f"  Final micro, t={t_alloc:.0f}s")
            a_opt, _ = micro_polish(best_seq, time_limit=t_alloc)
            try_seq(a_opt, "final_micro")

    print(f"  Phase 6 best: {best_score:.8f} ({time.monotonic()-t_phase:.0f}s)")

    # Fallback
    if best_seq is None:
        best_seq = np.ones(384) / 384
        best_score = float(evaluate_sequence(best_seq.tolist()))

    # Final verification
    fs = float(evaluate_sequence(best_seq.tolist()))
    if np.isfinite(fs) and fs < best_score:
        best_score = fs

    print(f"\nFINAL SCORE: {best_score:.8f} (n={len(best_seq)}, total={time.monotonic()-t0_total:.0f}s)")
    return [float(x) for x in best_seq]
