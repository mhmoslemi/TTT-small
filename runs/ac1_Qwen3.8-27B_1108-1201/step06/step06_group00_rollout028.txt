**Pair Transfer Method:**

Given the current sequence `a` and the current max convolution value M, consider transferring a small amount of mass from position j to position i (j ≠ i). The new sequence is:
`a'[j] = a[j] - δ`
`a'[i] = a[i] + δ`
(with the constraint 0 <= δ <= a[j])

The change in the convolution at lag k is:
`Δconv[k] = conj[a'[i]+a'[j], a'][k] - conj[a,a][k]`

Let me compute this:
`conv[a'][k] = sum_p a'[p]*a'[k-p]`
= `sum_p (a[p] + δ*(1[p=i] - 1[p=j]))*a[k-p] + sum_p a[p]*δ*(1[k-p=i] - 1[k-p=j])`
= `conv[a][k] + δ*a[k-i] - δ*a[k-j] + δ*a[i-k] - δ*a[j-k]`

(using a[x] = 0 if x out of range)

So `Δconv[k] = δ*(a[k-i] + a[i-k] - a[k-j] - a[j-k])`

Let `d[k] = a[k-i] + a[i-k] - a[k-j] - a[j-k]`. Then `Δconv[k] = δ*d[k]`.

The new max is: `max_k (conv[k] + δ*d[k])`.

We want to minimize this over δ in [0, a[j]].

`max_k (conv[k] + δ*d[k])` is the max of linear functions of δ, so it's convex in δ. We can minimize it by finding the "flat point" where the subgradient contains 0.

The subgradient of `f(δ) = max_k (conv[k] + δ*d[k])` at δ is:
`∂f/∂δ = {d[k] : k in argmax (conv[k] + δ*d[k])}`

So we want `0 in {d[k] : k in argmax}`, i.e., some peak has d[k] < 0 and some peak has d[k] > 0 (or one has d[k] = 0).

If all peaks have d[k] < 0, increasing δ reduces all peaks → increase δ.
If all peaks have d[k] > 0, decreasing δ reduces all peaks → decrease δ (i.e., move mass the other way).
If there's a mix, the optimal δ is where the "active" peaks cross.

This can be solved in O(n) by:
1. Identify the set of "active" peaks (those in argmax)
2. If all have d[k] <= 0, set δ = a[j] (max transfer)
3. If all have d[k] >= 0, set δ = 0 (no transfer, or try the reverse direction)
4. Otherwise, the optimal δ is where the max of the active peaks is minimized. This is the δ where two active peaks are equal (a "crossing" point).

More precisely, the optimal δ* is:
`δ* = min over pairs (k1, k2) in active set with d[k1] > d[k2] of (conv[k2] - conv[k1]) / (d[k1] - d[k2])`

This is O(K^2) where K is the number of active peaks.

But we also need to check that no INACTIVE peak becomes the new max at δ*. So we need:
`conv[k] + δ* * d[k] <= f(δ*)` for all k (not just active ones).

This is an O(n) check.

So the total cost per pair (i, j) is O(n + K^2). With K = 20 active peaks and n = 768, this is about 1600 operations. We can try a few thousand pairs per second.

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    """Project onto probability simplex."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.arange(1, n + 1)
    cond = u * rho > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho_val = np.nonzero(cond)[0][-1]
    theta = (cssv[rho_val] - 1.0) / (rho_val + 1.0)
    return np.maximum(v - theta, 0.0)

def build_lp_matrix(f, constraint_indices):
    """Build sparse constraint matrix for the LP."""
    n = len(f)
    rows = []
    cols = []
    vals = []
    for idx, k in enumerate(constraint_indices):
        k = int(k)
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        if j_start <= j_end:
            js = np.arange(j_start, j_end + 1)
            rows.extend([idx] * len(js))
            cols.extend(js.tolist())
            vals.extend((f[k - js]).tolist())
    if not rows:
        return csr_matrix((0, n))
    return csr_matrix((vals, (rows, cols)), shape=(len(constraint_indices), n))

def solve_lp_direction(f, M, constraint_indices, time_limit=10):
    """LP: max sum(g) s.t. (f*g)[k] <= M for k in constraint_indices, g >= 0."""
    n = len(f)
    A = build_lp_matrix(f, constraint_indices)
    if A.shape[0] == 0:
        return np.ones(n) / n
    c = -np.ones(n)
    b_ub = np.full(A.shape[0], M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds,
                      method='highs', options={'presolve': True, 'time_limit': time_limit})
        if res.success and res.x is not None:
            return np.maximum(res.x, 0.0)
    except Exception:
        pass
    return None
