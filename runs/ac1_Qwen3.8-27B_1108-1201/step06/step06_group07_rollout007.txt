       n = len(a)
       size = 2 * n - 1
       fft_size = 1 << (size - 1).bit_length()
       A = np.fft.rfft(a, fft_size)
       return np.fft.irfft(A * A, fft_size)[:size]

   def project_simplex(v):
       """Euclidean projection onto the probability simplex."""
       n = len(v)
       if n == 1:
           return np.array([max(float(v[0]), 0.0)])
       u = np.sort(v)[::-1]
       cssv = np.cumsum(u)
       cond = u * np.arange(1, n + 1) > (cssv - 1)
       if not cond.any():
           return np.ones(n) / n
       rho = np.nonzero(cond)[0][-1]
       theta = (cssv[rho] - 1.0) / (rho + 1.0)
       return np.maximum(v - theta, 0.0)

   One more idea: **frequency domain optimization**. 
   
   The condition `b = ifft(|fft(a, 2n-1)|^2)` with `max(b) → min` is equivalent to making `|fft(a)|^2` have certain properties. Specifically, if `|fft(a)|^2` is constant (white spectrum), then `b` is a delta function (only the DC term is non-zero), which gives `b[0] = (sum a)^2 / (2n-1)` and all other b[k] = 0. But this is impossible for a non-negative a (the FFT of a non-negative sequence can't have a flat magnitude).

   However, we can get close by making the spectrum as flat as possible. This is the **PAPR reduction** problem in signal processing. The standard approaches are:
   - **SLR (Selected Mapping)**: randomly phase-shift and select.
   - **Tone reservation**: sacrifice some frequencies.
   - **Iterative methods**: IFFT → clip → FFT → modify → IFFT (like the SLS algorithm).

   The SLS (S Müller-Brunk) algorithm:
   1. Start with a.
   2. Compute b = ifft(|fft(a)|^2).
   3. Modify b: `b_new = min(b, M)` (clip the peaks).
   4. Compute a_new = ... (this step is tricky because we need a such that ifft(|fft(a)|^2) = b_new, which is not straightforward).

   Actually, the SLS algorithm works differently. It's for the forward problem (given a, reduce the peak of ifft(|fft(a)|^2)). The standard approach is:
   1. Compute the phase of fft(a).
   2. Modify the time-domain signal to reduce peaks.
   3. Re-compute the spectrum, keeping the phase but modifying the magnitude at peak frequencies.

   This doesn't directly apply to our problem because we need a to be non-negative.

   Let me abandon the frequency domain approach and stick with time-domain optimization.

   **Let me also think about the LP-based SCA more carefully.**

   The LP is:
   max sum(g)
   s.t. 2*conv(a, g)[k] - b_a[k] ≤ M for all k (linearized constraint)
      g ≥ 0

   The linearized constraint `2*conv(a,g)[k] - b_a[k] ≤ M` is:
   `2 * sum_j a[j]*g[k-j] ≤ M + b_a[k]`
   i.e., `sum_j a[j]*g[k-j] ≤ (M + b_a[k])/2`

   This is a linear constraint in g. The matrix is the Toeplitz matrix built from a.

   For the LP to be feasible, we need the RHS to be positive, which is always true since M > 0 and b_a[k] > 0.

   The LP has 2n-1 constraints and n variables. For n=768, that's 1535 constraints. The sparse matrix has about n^2/2 ≈ 295K non-zeros.
