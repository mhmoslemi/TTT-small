Let me think about the Adam implementation. For minimizing F(a) = max_k (a*a)[k] subject to a in simplex:

1. Compute softmax-smoothed peak: p_k = exp(conv[k]/T) / sum(exp(conv/T))
2. Compute gradient: grad[i] = 2 * sum_k p_k * conv_partner[k, i] where conv_partner relates to the derivative
   Specifically: grad[i] = 2 * sum_k p_k * a[k-i] (with a[m]=0 if m not in [0,n-1])
3. Adam update: 
   m = beta1*m + (1-beta1)*grad
   v = beta2*v + (1-beta2)*grad^2
   a_new = a - lr * m_hat / (v_hat + eps)
4. Project onto simplex.

The key is choosing T (temperature) and lr (learning rate) well.

Now let me also think about a potential issue: the LP oracle as formulated gives g that maximizes sum(g) subject to (f*g)[k] <= M. But we want to minimize max(conv(a,a)), not max(conv(f, a)). The FW method works because:

At the current point f, we linearize the objective. The "linear approximation" of max_k (a*a)[k] at point f, in the direction of g, is:
max_k (f*g)[k] (approximately, since (a*a)[k] - (f*f)[k] ≈ (f*(a-f))[k] + (f*(a-f))[k] = 2(f*(a-f))[k] when a is close to f).

Actually, the proper FW formulation for minimizing F(a) = max_k (a*a)[k] over the simplex:
- At point f, the subdifferential of F contains vectors of the form sum_k lambda_k * ∇_a (a*a)[k|a=f] where lambda_k >= 0, sum lambda_k = 1, and (f*f)[k] = F(f) for all k with lambda_k > 0.
- The FW oracle: g = argmin_{g in simplex} <s, g> where s is a subgradient.

For a single subgradient s[i] = 2*f[k*-i] (from a single active peak k*):
g = argmin_{g in simplex} 2*sum_i f[k*-i]*g[i] = e_{argmin_i f[k*-i]}

This is a basis vector! So the pure FW step would move all mass to a single point. In practice, we use a "shrunken" version or the LP approach.

The LP approach (maximize sum(g) s.t. (f*g)[k] <= M) is actually a different oracle - it's the oracle for a related problem. It finds the "flattest" possible g when convolved with f, under the constraint that the result doesn't exceed M.

This is actually very powerful: it finds the best "target" shape g such that when you convolve the current f with g, the result is bounded by M. Then you move toward g.

The intuition: if f is the "current" sequence and we want to reduce the peak of f*f, we look for a g such that f*g is flat (bounded by M). Then g becomes our new target.

This is like a "deconvolution" - we're asking: what shape g, when convolved with f, gives a flat result? If f*f currently has a peak at M_current, and we set M = M_current, then g is a "smoother" version of f.

"""
Minimizes 2*n*max(convolve(a,a))/(sum(a))^2 using a hybrid approach:
- Diverse analytical initializations (ramps, power laws, cosine windows)
- Adam-optimized projected subgradient with softmax-smoothed peaks  
- Frank-Wolfe with LP oracle for global refinement
- Multi-scale coordinate descent for final polish
- Adaptive multi-n exploration
"""

import numpy as np
from scipy.optimize import linprog
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def make_initializations(n):
    """Generate diverse initial sequences of length n, all normalized to sum=1."""
    inits = {}
    j = np.arange(n)
    
    # Uniform
    inits['uniform'] = np.ones(n) / n
    
    # Linear ramp
    ramp = j + 1
    inits['ramp'] = ramp / ramp.sum()
    
    # Reverse ramp
    inits['rev_ramp'] = (n - j) / (n*(n+1)/2)
    
    # Quadratic (parabola)
    quad = (j + 1) ** 2
    inits['quad'] = quad / quad.sum()
    
    # Power law p=0.5
    p05 = np.sqrt(j + 1)
    inits['p05'] = p05 / p05.sum()
    
    # Power law p=3
    p3 = (j + 1) ** 3
    inits['p3'] = p3 / p3.sum()
    
    # Cosine window
    cos_w = np.cos(np.pi * j / n) ** 2 + 0.1
    inits['cosine'] = cos_w / cos_w.sum()
    
    # Raised cosine
    rc = 0.5 * (1 + np.cos(2 * np.pi * j / n))
    rc = np.maximum(rc, 0.01)
    inits['raised_cos'] = rc / rc.sum()
    
    # Log
    log_w = np.log(j + 2)
    inits['log'] = log_w / log_w.sum()
    
    # Exponential
    exp_w = np.exp(j / (n / 4.0))
    inits['exp'] = exp_w / exp_w.sum()
    
    # S-curve (logistic)
    sig = 1.0 / (1.0 + np.exp(-4.0 * (j / n - 0.5)))
    sig = np.maximum(sig, 0.01)
    inits['sigmoid'] = sig / sig.sum()
    
    # Two-segment (step-like)
    step = np.ones(n)
    step[n//3:] = 2.0
    inits['step2'] = step / step.sum()
    
    # Three-segment
    seg3 = np.ones(n)
    seg3[n//4:n*3//4] = 1.5
    seg3[n*3//4:] = 0.5
    inits['seg3'] = seg3 / seg3.sum()
    
    return inits


def adam_subgradient(a0, time_limit, T_init=0.001, lr_init=0.02, beta1=0.8, beta2=0.999, eps=1e-8):
    """
    Adam-optimized projected subgradient method with softmax-smoothed peaks.
    """
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    m = np.zeros(n)  # First moment
    v = np.zeros(n)  # Second moment
    t_adam = 0
    
    T = T_init
    lr = lr_init
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit - 0.05:
            break
        
        # Compute convolution and softmax weights
        conv = fast_convolve(a)
        scaled = conv / T
        scaled -= scaled.max()  # numerical stability
        p = np.exp(scaled)
        p_sum = p.sum()
        if p_sum < 1e-30:
            p = np.zeros_like(conv)
            p[np.argmax(conv)] = 1.0
        else:
            p = p / p_sum
        
        # Compute gradient: grad[i] = 2 * sum_k p[k] * a[k-i] (with bounds)
        grad = np.zeros(n)
        # Use the structure: for each lag k, a[k-i] contributes to grad[i]
        # grad[i] = 2 * sum_k p[k] * a[k-i] where k-i in [0,n-1]
        # This is 2 * (p * a)[i] in a correlation sense
        # Actually: sum_k p[k] * a[k-i] = sum_m p[m+i] * a[m] (substituting m=k-i)
        # = correlation of p and a at lag i
        # We can compute this efficiently using FFT or direct computation
        
        # Direct computation using the fact that p is defined on [0, 2n-2] and a on [0, n-1]
        # For each i in [0, n-1]: grad[i] = 2 * sum_{m=0}^{n-1} p[m+i] * a[m]
        # This is the "valid" cross-correlation of p and a
        
        # Using np.correlate: np.correlate(p, a, 'valid') gives sum_m p[m+i]*a[m] for i=0..(len(p)-len(a))
        # len(p) = 2n-1, len(a) = n, so valid gives 2n-1-n+1 = n values. 
        
        corr = np.correlate(p, a, mode='valid')
        grad = 2.0 * corr
        
        # Adam update
        t_adam += 1
        m = beta1 * m + (1 - beta1) * grad
        v = beta2 * v + (1 - beta2) * grad ** 2
        m_hat = m / (1 - beta1 ** t_adam)
        v_hat = v / (1 - beta2 ** t_adam)
        
        a_new = a - lr * m_hat / (np.sqrt(v_hat) + eps)
        a_new = project_simplex(a_new)
        
        # Evaluate
        c_new = fast_convolve(a_new)
        obj = c_new.max()
        
        if obj < best_obj - 1e-15:
            best_obj = obj
            best_a = a_new.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        a = a_new
        
        # Adaptive parameter tuning
        if no_improve % 50 == 0 and no_improve > 0:
            if no_improve > 200:
                # Restart from best with perturbation
                noise_scale = 0.002 * np.sqrt(no_improve / 200.0)
                rng = np.random.default_rng(it)
                a = project_simplex(best_a + rng.standard_normal(n) * noise_scale)
                m = np.zeros(n)
                v = np.zeros(n)
                t_adam = 0
                no_improve = 0
                T = T_init
                lr = lr_init
            elif no_improve > 100:
                T *= 1.2  # Increase temperature (smoother)
                lr *= 0.9
            elif no_improve > 50:
                T *= 0.8  # Decrease temperature (sharper)
                lr *= 0.95
        
        # Slowly decrease learning rate
        lr *= (1.0 - 0.0001 * it)
        lr = max(lr, 0.0001)
        
        # Periodically re-heat temperature
        if it % 500 == 0:
            T = T_init * (1.0 + 0.5 * (it % 1000) / 1000.0)
    
    return best_a, best_obj


def fw_lp_optimize(f0, time_limit, m_schedule='adaptive'):
    """Frank-Wolfe with LP oracle and adaptive M relaxation."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    
    conv = fast_convolve(f)
    M = conv.max()
    best_obj = M
    best_f = f.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    m_expansion = 1.0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 0.3:
            break
        
        # Solve LP: max sum(g) s.t. (f*g)[k] <= M * m_expansion, g >= 0
        c_obj = -np.ones(n)
        A_ub = np.zeros((2 * n - 1, n))
        for j in range(n):
            A_ub[j:j + n, j] = f
        b_ub = np.full(2 * n - 1, M * m_expansion)
        bounds = [(0, None)] * n
        
        lp_time = min(20.0, remaining * 0.3)
        try:
            res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds,
                          method='highs', options={'presolve': True, 'time_limit': lp_time})
            if res.success:
                g = np.maximum(res.x, 0.0)
            else:
                g = None
        except Exception:
            g = None
        
        if g is None or g.sum() < 1e-15:
            m_expansion *= 1.1
            if m_expansion > 5.0:
                m_expansion = 1.0
                g = project_simplex(-fast_convolve(f) + np.mean(fast_convolve(f)))
            continue
        
        g = g / g.sum()
        
        if np.max(np.abs(g - f)) < 1e-12:
            no_improve += 1
            if no_improve > 20:
                break
            m_expansion = min(m_expansion * 1.02, 3.0)
            continue
        
        # Line search: find best alpha in [0, 1]
        best_alpha = 0.0
        best_val = M
        
        # Coarse search
        alphas = np.array([0.01, 0.02, 0.05, 0.1, 0.15, 0.2, 0.3, 0.4, 0.5, 0.7, 1.0])
        vals = np.zeros(len(alphas))
        for idx, alpha in enumerate(alphas):
            ft = (1.0 - alpha) * f + alpha * g
            ft = np.maximum(ft, 0.0)
            st = ft.sum()
            if st < 1e-15:
                vals[idx] = np.inf
                continue
            ft = ft / st
            vals[idx] = fast_convolve(ft).max()
        
        best_idx = np.argmin(vals)
        best_val = vals[best_idx]
        best_alpha = alphas[best_idx]
        
        # Fine bisection around best
        if 0 < best_idx < len(alphas) - 1:
            lo = alphas[best_idx - 1]
            hi = alphas[best_idx + 1]
            for _ in range(8):
                mid = (lo + hi) / 2.0
                ft = (1.0 - mid) * f + mid * g
                ft = np.maximum(ft, 0.0)
                st = ft.sum()
                if st < 1e-15:
                    break
                ft = ft / st
                val = fast_convolve(ft).max()
                if val <= best_val:
                    best_val = val
                    best_alpha = mid
                    lo = mid
                else:
                    hi = mid
        
        if best_alpha > 1e-12 and best_val < M:
            f = (1.0 - best_alpha) * f + best_alpha * g
            f = np.maximum(f, 0.0)
            f = f / f.sum()
            conv = fast_convolve(f)
            M = conv.max()
            m_expansion = max(1.0, m_expansion * 0.95)
            
            if M < best_obj - 1e-15:
                best_obj = M
                best_f = f.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1
            m_expansion = min(m_expansion * 1.05, 5.0)
        
        if no_improve > 30:
            # Perturb and restart
            rng = np.random.default_rng(it * 7919 + 13)
            noise_scale = 0.001 + 0.002 * min(1.0, no_improve / 100.0)
            f = project_simplex(best_f + rng.standard_normal(n) * noise_scale)
            conv = fast_convolve(f)
            M = conv.max()
            m_expansion = 1.0
            no_improve = 0
    
    return best_f, best_obj


def coordinate_polish(a0, time_limit):
    """
    Fine-grained coordinate descent: try moving mass between pairs of coordinates
    to reduce the max convolution value.
    """
    a = np.maximum(a0.astype(np.float64), 0.0)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    
    t0 = time.monotonic()
    stall = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit - 0.1:
            break
        
        conv = fast_convolve(a)
        # Focus on top peaks
        top_k = min(8, len(conv))
        peak_lags = np.argpartition(conv, -top_k)[-top_k:]
        peak_lags = peak_lags[np.argsort(conv[peak_lags])[::-1]]
        
        improved = False
        
        for k_peak in peak_lags[:4]:  # Only process top 4 peaks
            if time.monotonic() - t0 > time_limit - 1.0:
                break
            
            k_peak = int(k_peak)
            js = max(0, k_peak - n + 1)
            je = min(n - 1, k_peak)
            affected = np.arange(js, je + 1)
            
            if len(affected) < 2:
                continue
            
            # For each affected coordinate, compute its "responsibility" for the peak
            # a[j] contributes a[j] * a[k_peak - j] to conv[k_peak]
            contributions = np.array([a[j] * a[k_peak - j] for j in affected])
            
            # Try moving mass from high-contribution to low-contribution
            # Sample pairs for efficiency
            if len(affected) > 40:
                rng_pair = np.random.default_rng(it * 31 + k_peak)
                sample_idx = rng_pair.choice(len(affected), size=40, replace=False)
            else:
                sample_idx = np.arange(len(affected))
            
            best_gain = 1e-15
            best_move = None
            
            for ii in range(len(sample_idx)):
                j1 = affected[sample_idx[ii]]
                c1 = a[j1] * a[k_peak - j1] if 0 <= k_peak - j1 < n else 0
                if a[j1] < 1e-10:
                    continue
                
                for jj in range(len(sample_idx)):
                    if jj == ii:
                        continue
                    j2 = affected[sample_idx[jj]]
                    c2 = a[j2] * a[k_peak - j2] if 0 <= k_peak - j2 < n else 0
                    
                    # Move mass from higher contribution to lower
                    if c1 > c2:
                        src, dst = j1, j2
                    else:
                        src, dst = j2, j1
                    
                    if a[src] < 1e-10:
                        continue
                    
                    # Try small transfers
                    for frac in [0.02, 0.05, 0.1, 0.2]:
                        delta = a[src] * frac
                        if delta < 1e-12:
                            continue
                        a_test = a.copy()
                        a_test[src] -= delta
                        a_test[dst] += delta
                        if a_test[src] < -1e-12:
                            continue
                        a_test = np.maximum(a_test, 0.0)
                        a_test = a_test / a_test.sum()
                        c_new = fast_convolve(a_test)
                        new_max = c_new.max()
                        gain = best_obj - new_max
                        if gain > best_gain:
                            best_gain = gain
                            best_move = (src, dst, frac)
            
            if best_move is not None:
                src, dst, frac = best_move
                delta = a[src] * frac
                a[src] -= delta
                a[dst] += delta
