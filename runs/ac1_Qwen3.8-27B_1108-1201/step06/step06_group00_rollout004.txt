Actually, we can be smarter. When we change a[i] from x_old to x_new, the change in (a*a)[k] is:
- delta_k = a[k-i]*(x_new - x_old) + (x_new^2 - x_old^2) if k = 2i
- delta_k = a[k-i]*(x_new - x_old) otherwise (for valid k)
- delta_k = 0 for invalid k

So we can update the convolution in O(n) time per coordinate change. A full coordinate descent sweep is O(n^2). With n = 768, that's about 590K operations per sweep, which is very fast.

Let me design the coordinate descent more carefully:

For coordinate i:
1. Compute current convolution C[k] = (a*a)[k] for all k.
2. For each k where i is a valid index in the convolution:
   - If k = 2i: C[k] = a[i]^2 + R_k where R_k = sum_{j != i} a[j]*a[k-j]
   - If k != 2i: C[k] = a[i]*a[k-i] + R_k
3. We want to find x >= 0 that minimizes max_k C_new[k] where C_new is the updated convolution.

The key insight: only O(n) convolution terms are affected (those where i participates). The rest stay the same. Let M_other = max of the unaffected terms. Then we need:
max(max_k_affected C_new[k], M_other) to be minimized.

If M_other is the dominant constraint, we need C_new[k] <= M_other for all affected k, and we want to minimize x (or rather, we're free to choose x to satisfy these constraints while minimizing the max).

Actually, the objective is to minimize the overall max. Let's denote:
- M_fixed = max of (a*a)[k] for k not involving i.
- M_var(x) = max of (a*a)[k] for k involving i, as a function of x.
- Overall max = max(M_fixed, M_var(x)).

We want to minimize max(M_fixed, M_var(x)) over x >= 0.

If M_var(x) <= M_fixed for all x >= 0, then the optimum is x = 0 (wait, no, x = current value is fine, the max is M_fixed regardless).

Actually, we want to find x that minimizes max(M_fixed, M_var(x)). If M_var(x) can be made <= M_fixed, then any such x is optimal (the overall max is M_fixed). Otherwise, we want to minimize M_var(x) subject to M_var(x) > M_fixed, which means we want to minimize M_var(x) itself.

M_var(x) is the max of a set of linear/quadratic functions of x. It's a convex function of x. We can find its minimum using:
- Subgradient method (bisection on the subgradient containing 0).
- Or just evaluate at a few candidate points.

The candidate points are:
- x = 0
- The intersection points of pairs of the linear/quadratic functions.
- The vertex of the quadratic (if present).

For the linear functions f_k(x) = a[k-i]*x + R_k, the intersection of f_j and f_k is at x = (R_k - R_j) / (a[k-j] - a[k-i]) (if the denominators are nonzero).

This could be O(n^2) candidate points in the worst case, but typically many are dominated.

A simpler approach: just use ternary search or golden section search on the convex function M_var(x) over the range [0, x_max] where x_max is some upper bound (like the current max element).

Let me now write the actual code. I'll combine several optimization strategies:

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Frank-Wolfe with LP oracle (adaptive constraint selection)
2. LSE-smoothed gradient descent with Adam
3. Coordinate descent for 1D minimax refinement
4. Frequency-domain perturbation for diversification
5. Multi-length exploration
"""

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.arange(1, n + 1)
    cond = u * rho > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho_val = np.nonzero(cond)[0][-1]
    theta = (cssv[rho_val] - 1.0) / (rho_val + 1.0)
    return np.maximum(v - theta, 0.0)

def lse_smooth_max(conv, beta):
    """Compute LSE approximation of max and its gradient wrt conv."""
    bc = beta * conv
    bc_max = bc.max()
    exp_bc = np.exp(bc - bc_max)
    total = exp_bc.sum()
    if total < 1e-300:
        vals = np.ones(len(conv)) / len(conv)
    else:
        vals = exp_bc / total
    lse_val = (bc_max + np.log(total)) / beta
    return lse_val, vals

def compute_grad_lse(f, conv, weights):
    """Compute gradient of LSE(conv, beta) wrt f, given weights on conv elements."""
    n = len(f)
    grad = np.zeros(n)
    for k in range(2 * n - 1):
        w = weights[k]
        if w < 1e-15:
            continue
        lo = max(0, k - n + 1)
        hi = min(n - 1, k)
        i_range = np.arange(lo, hi + 1)
        grad[i_range] += w * 2.0 * f[k - i_range]
    return grad

def coordinate_descent_1d(f, conv, i, M_fixed):
    """Find optimal a[i] given all other coordinates fixed.
    Returns the new value of a[i]."""
    n = len(f)
    x_current = f[i]
    
    # Compute the affected convolution terms
    # For lag k, a[i] participates if max(0, k-n+1) <= i <= min(n-1, k)
    # which means k-n+1 <= i <= k and k >= i and k <= i + n - 1
    # i.e., k ranges from i to i + n - 1 (clamped to [0, 2n-2])
    k_min = max(0, i)  # k >= i (since a[k-i] needs k-i >= 0)
    k_max = min(2 * n - 2, i + n - 1)  # k <= i + n - 1 (since a[i] needs i <= n-1, and k-i <= n-1 means k <= i+n-1)
    
    # Actually: a[i] participates in (a*a)[k] if 0 <= i <= n-1 and 0 <= k-i <= n-1
    # So k-i >= 0 => k >= i, and k-i <= n-1 => k <= i + n - 1
    # Also k >= 0 and k <= 2n-2.
    
    affected_ks = np.arange(k_min, k_max + 1)
    
    # For each affected k, the convolution term is:
    # (a*a)[k] = a[i] * a[k-i] + (sum of other terms)
    # If k == 2*i: (a*a)[k] = a[i]^2 + other_terms
    # Else: (a*a)[k] = a[i] * a[k-i] + other_terms
    
    # Let's compute other_terms for each affected k
    # other_terms_k = conv[k] - a[i] * a[k-i] (if k != 2i)
    # other_terms_k = conv[k] - a[i]^2 (if k == 2i)
    
    # We want to find x >= 0 minimizing max(max_affected f_k(x), M_fixed)
    # where f_k(x) = x * a[k-i] + other_k (if k != 2i)
    #              f_k(x) = x^2 + other_k (if k == 2i)
    
    # Get coefficients
    coeffs = np.zeros(len(affected_ks))  # linear coefficients
    constants = np.zeros(len(affected_ks))  # constant terms
    is_quad = np.zeros(len(affected_ks), dtype=bool)  # whether it's quadratic
    
    for idx, k in enumerate(affected_ks):
        k = int(k)
        other_idx = k - i
        if other_idx == i:  # k == 2i
            # f_k(x) = x^2 + (conv[k] - x_current^2)
            constants[idx] = conv[k] - x_current * x_current
            is_quad[idx] = True
            coeffs[idx] = 0
        else:
            # f_k(x) = x * a[other_idx] + (conv[k] - x_current * a[other_idx])
            coeffs[idx] = f[other_idx]
            constants[idx] = conv[k] - x_current * f[other_idx]
    
    # Now find x >= 0 minimizing max(max_k f_k(x), M_fixed)
    # Since the function is convex in x, use ternary search on [0, x_upper]
    
    # Upper bound for x: current value * 2 or M_fixed / min_positive_coeff
    x_upper = max(x_current * 3, M_fixed / (np.max(coeffs) + 1e-15)) if np.max(coeffs) > 0 else x_current * 3
    x_upper = max(x_upper, 1e-10)
    
    def obj(x):
        max_val = M_fixed
        for idx in range(len(affected_ks)):
            if is_quad[idx]:
                val = x * x + constants[idx]
            else:
                val = x * coeffs[idx] + constants[idx]
            if val > max_val:
                max_val = val
        return max_val
    
    # Ternary search
    lo, hi = 0.0, x_upper
    for _ in range(60):
        m1 = lo + (hi - lo) / 3
        m2 = hi - (hi - lo) / 3
        if obj(m1) < obj(m2):
            hi = m2
        else:
            lo = m1
    
    x_opt = (lo + hi) / 2
    return x_opt

def coordinate_descent(f, conv, n_sweeps=10, time_limit=30.0):
    """Full coordinate descent with multiple sweeps."""
    n = len(f)
    f = f.copy().astype(np.float64)
    t0 = time.monotonic()
    
    for sweep in range(n_sweeps):
        if time.monotonic() - t0 > time_limit:
            break
        improved = False
        for i in range(n):
            if time.monotonic() - t0 > time_limit:
                break
            conv = fast_convolve(f)
            # M_fixed: max of convolution terms NOT involving coordinate i
            k_min = i
            k_max = min(2 * n - 2, i + n - 1)
            affected = np.zeros(2 * n - 1, dtype=bool)
            affected[k_min:k_max+1] = True
            M_fixed = conv[~affected].max() if (~affected).any() else 0.0
            
            x_new = coordinate_descent_1d(f, conv, i, M_fixed)
            if abs(x_new - f[i]) > 1e-12:
                f[i] = x_new
                improved = True
        
        if not improved:
            break
    
    return f

def lse_gradient_descent(f0, time_limit, beta_start=50.0, beta_end=50000.0):
    """LSE-smoothed gradient descent with Adam."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    
    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()
    
    beta = beta_start
    lr = 0.01
    m = np.zeros(n)  # Adam first moment
    v = np.zeros(n)  # Adam second moment
    t_adam = 0
    beta1, beta2, eps = 0.8, 0.999, 1e-8
    
    t0 = time.monotonic()
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        if time.monotonic() - t0 > time_limit - 1:
            break
        
        conv = fast_convolve(f)
        lse_val, weights = lse_smooth_max(conv, beta)
        grad = compute_grad_lse(f, conv, weights)
        
        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-15:
            break
        
        t_adam += 1
        m = beta1 * m + (1 - beta1) * grad
        v = beta2 * v + (1 - beta2) * grad ** 2
        m_hat = m / (1 - beta1 ** t_adam)
        v_hat = v / (1 - beta2 ** t_adam)
        
        step = lr * m_hat / (np.sqrt(v_hat) + eps)
        f_new = project_simplex(f - step)
        
        conv_new = fast_convolve(f_new)
        obj_new = conv_new.max()
        
        if obj_new < best_obj - 1e-15:
            best_obj = obj_new
            best_f = f_new.copy()
            f = f_new
            no_improve = 0
            lr = min(lr * 1.01, 0.1)
        else:
            no_improve += 1
            if no_improve % 20 == 0:
                lr *= 0.9
            if no_improve > 100:
                f = best_f.copy()
                no_improve = 0
                lr = 0.01
        
        # Increase beta gradually
        beta = min(beta * 1.005, beta_end)
    
    return best_f

def fw_lp_optimize(f0, time_limit, top_k=40):
    """Frank-Wolfe with LP oracle."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    
    conv = fast_convolve(f)
    M = conv.max()
    best_obj = M
    best_f = f.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    cur_top_k = top_k
    
    while time.monotonic() - t0 < time_limit - 5:
        it += 1
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 5:
            break
        
        # Build LP constraints for top peaks
        conv = fast_convolve(f)
        k_top = min(cur_top_k, 2 * n - 1)
        peak_idx = np.argpartition(conv, -k_top)[-k_top:]
        center = n - 1
        if center not in peak_idx:
            peak_idx = np.append(peak_idx, center)
        
        # Build sparse matrix
        rows = []
        cols = []
        vals = []
        for idx, k in enumerate(peak_idx):
            k = int(k)
            j_start = max(0, k - n + 1)
            j_end = min(n - 1, k)
            if j_start <= j_end:
                js = np.arange(j_start, j_end + 1)
                rows.extend([idx] * len(js))
                cols.extend(js.tolist())
                vals.extend((f[k - js]).tolist())
        
        if not rows:
            g = np.ones(n) / n
        else:
            A = csr_matrix((vals, (rows, cols)), shape=(len(peak_idx), n))
            c = -np.ones(n)
            b_ub = np.full(A.shape[0], M)
            bounds = [(0.0, None)] * n
            try:
                res = linprog(c, A_ub=A, b_ub=b_ub,
                              bounds=bounds, method='highs',
                              options={'presolve': True, 'time_limit': min(10, remaining * 0.1)})
                if res.success and res.x is not None:
                    g = np.maximum(res.x, 0.0)
                else:
                    g = None
            except Exception:
                g = None
        
        if g is None:
            cur_top_k = min(cur_top_k * 2, 2 * n - 1)
            no_improve += 5
            if no_improve > 40:
                # Restart with perturbation
                rng = np.random.default_rng(it * 7919 + 13)
                f = project_simplex(f + rng.standard_normal(n) * 0.01)
                conv = fast_convolve(f)
                M = conv.max()
                no_improve = 0
                cur_top_k = top_k
            continue
        
        gs = g.sum()
        if gs < 1e-15:
            break
        g = g / gs
        
        if np.max(np.abs(g - f)) < 1e-10:
            no_improve += 1
            if no_improve > 30:
                break
            continue
        
        # Line search
        best_alpha = 0.0
        best_val = M
        alphas = np.array([0.05, 0.1, 0.15, 0.2, 0.3, 0.4, 0.5, 0.7, 0.9, 1.0])
        for alpha in alphas:
            ft = (1.0 - alpha) * f + alpha * g
            ft = np.maximum(ft, 0.0)
            st = ft.sum()
            if st < 1e-15:
                continue
            ft /= st
            val = fast_convolve(ft).max()
            if val < best_val:
                best_val = val
                best_alpha = alpha
        
        if best_alpha > 1e-6:
            # Refine with golden section
            gr = (np.sqrt(5) - 1) / 2
            lo = max(0.0, best_alpha - 0.1)
            hi = min(1.0, best_alpha + 0.1)
            for _ in range(15):
                m1 = hi - gr * (hi - lo)
                m2 = lo + gr * (hi - lo)
                ft1 = (1 - m1) * f + m1 * g
                ft1 = np.maximum(ft1, 0); st1 = ft1.sum()
                if st1 > 1e-15: ft1 /= st1
                ft2 = (1 - m2) * f + m2 * g
                ft2 = np.maximum(ft2, 0); st2 = ft2.sum()
                if st2 > 1e-15: ft2 /= st2
                v1 = fast_convolve(ft1).max() if st1 > 1e-15 else 1e10
                v2 = fast_convolve(ft2).max() if st2 > 1e-15 else 1e10
                if v1 < v2:
                    hi = m2
                else:
                    lo = m1
            best_alpha = (lo + hi) / 2
            ft = (1 - best_alpha) * f + best_alpha * g
            ft = np.maximum(ft, 0)
            ft /= ft.sum()
            f = ft
            conv = fast_convolve(f)
            M = conv.max()
            
            if M < best_obj - 1e-14:
                best_obj = M
                best_f = f.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1
    
    return best_f, best_obj

def freq_perturb(f, rng, strength=0.03):
    n = len(f)
    F = np.fft.rfft(f)
    mag = np.abs(F)
    phase = np.angle(F)
    pert = rng.standard_normal(len(mag)) * strength
    mag_new = np.maximum(mag * (1.0 + pert), 0)
    F_new = mag_new * np.exp(1j * phase)
    f_new = np.fft.irfft(F_new, n)
    f_new = np.maximum(f_new, 0)
    s = f_new.sum()
    if s > 1e-15:
        f_new /= s
    return f_new

def try_sequence(a, best_tracker):
    a = np.maximum(a, 0.0)
    a = np.minimum(a, 1000.0)
    try:
        score = float(evaluate_sequence(a.tolist()))
    except Exception:
        return float('inf')
    if np.isfinite(score) and score < best_tracker[0]:
        best_tracker[0] = score
        best_tracker[1] = a.copy()
        print(f"  NEW BEST: {score:.8f} (n={len(a)})")
    return score

def interpolate_to_length(f, new_n):
    x_old = np.linspace(0, 1, len(f))
    x_new = np.linspace(0, 1, new_n)
    f_new = np.interp(x_new, x_old, f)
    f_new = np.maximum(f_new, 0)
    s = f_new.sum()
    if s > 1e-15:
        f_new /= s
    else:
        f_new = np.ones(new_n) / new_n
    return f_new
