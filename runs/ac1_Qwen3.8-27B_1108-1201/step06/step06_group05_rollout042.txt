**Key insight for algorithm design:**

The problem is to minimize max_k c[k] where c = conv(a, a), subject to sum(a) = 1, a ≥ 0. This is a non-convex problem (quadratic constraints). However:

1. The feasible set {a : sum(a) = 1, a ≥ 0} is the simplex (convex).
2. The objective max_k c[k] is the maximum of quadratic functions (each c[k] is quadratic in a).
3. The epigraph {a, t : c[k] ≤ t ∀k} is non-convex.

**Algorithm ideas:**

A. **Alternating projection / method of alternating directions:**
   - Step 1: Given a, compute c = conv(a,a). Find the peak t = max c[k].
   - Step 2: Find the closest point b to a (in some metric) such that conv(b,b) ≤ t * (1-epsilon) componentwise (or some relaxation).
   - This is hard because step 2 is non-convex.

B. **Subgradient with careful step size:**
   - The subgradient of max_k c[k] at a is c_subgrad = a[k*-j] where k* is the argmax.
   - Use a diminishing step size: lr_k = C / sqrt(k).
   - Project onto the simplex after each step.
   - This converges but slowly.

C. **Newton's method on the active set:**
   - At the optimum, there's a set of active peaks P and a support S.
   - Solve the KKT conditions: for j in S, sum_{k in P} lambda_k * a[k-j] = nu.
   - This is a linear system in (lambda, nu) given (a, S, P).
   - Update a using the gradient information.

D. **Penalty / barrier method:**
   - Minimize max_k c[k] + mu * barrier(a) where barrier enforces a > 0.
   - Or: minimize sum_k exp(beta * c[k]) / (2n-1) (softmax approximation of max).
   - The softmax version is smooth and can be minimized with gradient methods.

E. **Spectral approach:**
   - Use the DFT to diagonalize the convolution.
   - In the frequency domain, c[k] = IDFT(|A|^2)[k].
   - We want to minimize max_k IDFT(|A|^2)[k] subject to DFT constraints.
   - This might lead to a different optimization structure.

2. For each k in P: c[k] = t.
3. sum(a) = 1.
4. lambda[k] ≥ 0, lambda[k] * (c[k] - t) = 0.
5. a[j] ≥ 0, a[j] * (sum_{k in P} lambda[k] * dc[k]/da[j] - nu) = 0.

From (1): for j in S = support(a):
sum_{k in P} lambda[k] * (a[k-j] + a[k-j]*[k=2j]) = nu  (using the full derivative)

Or approximately (dropping the diagonal correction):
sum_{k in P} lambda[k] * a[k-j] = nu

This is a linear system in (lambda, nu): for each j in S, we get one equation. The unknowns are lambda (|P| variables) and nu (1 variable). Total unknowns: |P| + 1. Total equations: |S|.

If |S| = |P| + 1, the system is square and can be solved directly.
If |S| > |P| + 1, the system is overdetermined (least squares).
If |S| < |P| + 1, the system is underdetermined.

In practice, |S| is typically larger than |P| + 1 (the support is usually larger than the active set). So we'd use least squares.

Once we have lambda and nu, we can:
- Check if lambda ≥ 0 (dual feasibility). If not, the active set is wrong.
- Compute the "reduced costs" for j not in S: r_j = sum_{k in P} lambda[k] * a[k-j] - nu. If r_j < 0, then j should be added to S.
- Check if c[k] < t for k not in P (primal feasibility of the active set). If c[k] > t - epsilon for some k not in P, add k to P.

This gives us an active-set algorithm. The main computational cost is solving the linear system at each iteration, which is O(|S| * |P|^2) or so.

For n = 768, |S| could be up to 768 and |P| could be up to a few hundred. This is manageable.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Log-sum-exp smoothed objective with L-BFGS in log-parameter space (softmax parameterization)
2. Progressive temperature annealing for convergence to the true max
3. Active-set Newton polishing exploiting KKT conditions
4. Multi-n exploration with diverse initializations
5. Subgradient-driven perturbation restarts for escaping local minima

import numpy as np
from scipy.optimize import minimize, linprog
import time


def fast_convolve(a):
    """FFT-based auto-convolution."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def softmax_param_obj_grad(x, beta):
    """
    Objective and gradient for L-BFGS in log-parameter space.
    a = softmax(x) = exp(x - max(x)) / sum(exp(x - max(x)))
    Objective: (1/beta) * log(sum_k exp(beta * c[k])) where c = conv(a, a)
    """
    n = len(x)
    x_shifted = x - x.max()
    a = np.exp(x_shifted)
    a_sum = a.sum()
    a = a / a_sum

    c = fast_convolve(a)

    # Log-sum-exp for numerical stability
    c_max = c.max()
    scaled = beta * (c - c_max)
    log_sum_exp = c_max + np.log(np.exp(scaled).sum())
    obj = log_sum_exp / beta

    # Softmax weights
    p = np.exp(scaled)
    p /= p.sum()

    # Gradient wrt a: d/d(a_j) sum_k exp(beta*c[k]) = 2*beta*sum_k p[k]*a[k-j]
    # (the factor 2*beta is absorbed into scaling; for direction we use the correlate)
    grad_a = 2.0 * np.correlate(p, a, mode='valid')

    # Gradient wrt x (log-parameter):
    # d(a_i)/d(x_j) = a_i*(delta_ij - a_j)
    # grad_x_j = sum_i grad_a_i * a_i * (delta_ij - a_j)
    #           = a_j * grad_a_j - a_j * sum_i(grad_a_i * a_i)
    grad_a_dot_a = np.dot(grad_a, a)
    grad_x = a * (grad_a - grad_a_dot_a)

    return obj, grad_x


def lbfgs_anneal(a0, beta_schedule, maxiter_per_stage=500):
    """
    Run L-BFGS with progressive beta annealing.
    Returns optimized a.
    """
    n = len(a0)
    a = np.maximum(a0, 1e-15)
    a = a / a.sum()

    # Convert to log-parameter
    x = np.log(a)

    for beta in beta_schedule:
        res = minimize(
            softmax_param_obj_grad,
            x,
            args=(beta,),
            method='L-BFGS-B',
            jac=True,
            options={
                'maxiter': maxiter_per_stage,
                'ftol': 1e-14,
                'gtol': 1e-10,
                'maxls': 30,
            }
        )
        x = res.x
        # Convert back
        a = np.exp(x - x.max())
        a = a / a.sum()

    return a

    """
    Active-set Newton method exploiting KKT conditions.
    At the optimum: for j in S (support), sum_{k in P} lambda_k * a[k-j] = nu
    where P is the active peak set.
    """
    a = np.maximum(a0, 0.0)
    s = a.sum()
    if s < 1e-15:
        return a0, fast_convolve(a0).max()
    a = a / s
    n = len(a)

    best_a = a.copy()
    best_obj = fast_convolve(a).max()

    for it in range(max_iter):
        c = fast_convolve(a)
        t = c.max()

        if t < best_obj - 1e-14:
            best_obj = t
            best_a = a.copy()

        # Active peaks
        threshold = t * (1.0 - 0.0005)
        P = np.where(c >= threshold)[0]
        if len(P) == 0:
            break

        # Support
        S = np.where(a > 1e-12)[0]
        if len(S) == 0:
            break

        m = len(S)
        p_count = len(P)

        # Build KKT system: for j in S, sum_{k in P} lambda_k * a[k-j] = nu
        # A_sys @ [lambda_0, ..., lambda_{p-1}, nu]^T = 0
        A_sys = np.zeros((m, p_count + 1))
        for i, j in enumerate(S):
            A_sys[i, -1] = -1.0
            for k_idx in range(p_count):
                k = P[k_idx]
                idx = k - j
                if 0 <= idx < n:
                    A_sys[i, k_idx] = a[idx]

        # Solve for non-trivial solution (null space)
        try:
            U, S_vals, Vt = np.linalg.svd(A_sys)
        except np.linalg.LinAlgError:
            break

        # Use the right singular vector corresponding to smallest singular value
        sol = Vt[-1, :]
        lambda_vals = sol[:p_count].copy()
        nu_val = -sol[p_count]

        # Dual feasibility: lambda >= 0
        lambda_vals = np.maximum(lambda_vals, 0.0)
        lambda_sum = lambda_vals.sum()
        if lambda_sum < 1e-15:
            # Try the second smallest
            sol = Vt[-2, :]
            lambda_vals = np.maximum(sol[:p_count], 0.0)
            lambda_sum = lambda_vals.sum()
            if lambda_sum < 1e-15:
                break
        lambda_vals /= lambda_sum

        # Gradient direction (we want to decrease the active peaks)
        grad = np.zeros(n)
        for k_idx in range(p_count):
            if lambda_vals[k_idx] < 1e-14:
                continue
            k = P[k_idx]
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx_arr = np.arange(js, je + 1)
            grad[idx_arr] += lambda_vals[k_idx] * a[k - idx_arr]

        # Line search with backtracking
        best_candidate = a
        best_val = t
        step_sizes = [0.05, 0.02, 0.01, 0.005, 0.002, 0.001, 0.0005]
        for step in step_sizes:
            candidate = project_simplex(a - step * grad)
            c_new = fast_convolve(candidate)
            val = c_new.max()
            if val < best_val - 1e-15:
                best_val = val
                best_candidate = candidate
                break

        a = best_candidate

        if best_val < best_obj - 1e-14:
            best_obj = best_val
            best_a = a.copy()
        else:
            # Stalled - tighten active set or break
            if it > 50:
                threshold = t * (1.0 - 0.0001)
                P_tight = np.where(c >= threshold)[0]
                if len(P_tight) <= max(2, len(P) // 2):
                    # Try with tighter set but continue
                    pass
                else:
                    break
            if it > 200:
                break

    return best_a, best_obj


def subgrad_refine(a0, time_limit, top_k=10, lr_init=0.01):
    """Quick subgradient refinement with adaptive step size."""
    a = np.maximum(a0, 0.0)
    a = a / a.sum()
    n = len(a)
    v = np.zeros(n)
    lr = lr_init
    mom = 0.9
    best_a = a.copy()
    best_obj = fast_convolve(a).max()

    t0 = time.monotonic()
    no_improve = 0

    while time.monotonic() - t0 < time_limit:
        c = fast_convolve(a)
        obj = c.max()

        # Top-k peaks for subgradient
        if top_k >= len(c):
            peaks = np.arange(len(c))
            pk_vals = c
        else:
            peaks = np.argpartition(c, -top_k)[-top_k:]
            pk_vals = c[peaks]
        order = np.argsort(pk_vals)[::-1]
        weights = np.zeros(len(peaks))
        for rank, idx in enumerate(order):
            weights[idx] = 1.0 / (rank + 1) ** 1.5
        ws = weights.sum()
        weights /= ws

        sg = np.zeros(n)
        for i in range(len(peaks)):
            if weights[i] < 1e-14:
                continue
            k = int(peaks[i])
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx_arr = np.arange(js, je + 1)
            sg[idx_arr] += weights[i] * a[k - idx_arr]

        v = mom * v - lr * sg
        best_candidate = a
        best_val = obj
        for scale in [1.0, 0.5, 0.25, 0.125]:
            candidate = project_simplex(a + scale * v)
            val = fast_convolve(candidate).max()
            if val < best_val - 1e-16:
                best_val = val
                best_candidate = candidate
                break

        a = best_candidate
        if best_val < best_obj - 1e-14:
            best_obj = best_val
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
            v *= 0.9
            if no_improve > 50:
                lr *= 0.9
            if no_improve > 200:
                break

    return best_a, best_obj


def lp_oracle_solve(f, M, max_time=15):
    """Solve LP: max sum(g) s.t. (f*g)[k] <= M, g >= 0."""
    n = len(f)
    c_vec = -np.ones(n)
    # Build constraint matrix: for each k (0..2n-2), sum_j f[|k-j offset|] * g[j] <= M
    # (f*g)[k] = sum_j f[j]*g[k-j] (valid indices)
    # For a fixed k: (f*g)[k] = sum_j g[j] * f[k-j] where 0<=k-j<n
    # So the row for constraint k has entries f[k-j] in column j (if valid)
    A_ub = np.zeros((2 * n - 1, n))
    for j in range(n):
        # g[j] appears in (f*g)[k] with coefficient f[k-j] for k = j, j+1, ..., j+n-1
        A_ub[j:j + n, j] = f
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    try:
        res = linprog(c_vec, A_ub=A_ub, b_ub=b_ub, bounds=bounds,
                      method='highs', options={'time_limit': max_time, 'presolve': True})
        if res.success:
            return np.maximum(res.x, 0.0)
    except Exception:
        pass
    return None


def fw_lp_step(f, M, m_expand=1.0):
    """One Frank-Wolfe step with LP oracle."""
    n = len(f)
    g = lp_oracle_solve(f, M * m_expand)
    if g is None:
        return None
    g_sum = g.sum()
    if g_sum < 1e-15:
        return None
    g = g / g_sum
    return g
