"""
Hybrid SDP + FW-LP + Nesterov gradient optimization for minimum peak autocorrelation.
Key innovations: SDP relaxation for lower bounds and initialization, Nesterov acceleration,
adaptive multi-n search, and structured restarts.
"""

import numpy as np
import time
import cvxpy as cp
from scipy.optimize import linprog
from scipy.sparse import lil_matrix, csr_matrix


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def build_lp_indices(n):
    """Build sparse indices for convolution constraint matrix."""
    rows = []
    cols = []
    for k in range(2 * n - 1):
        i_start = max(0, k - n + 1)
        i_end = min(k, n - 1)
        for i in range(i_start, i_end + 1):
            rows.append(k)
            cols.append(i)
    return np.array(rows), np.array(cols)


def solve_lp_oracle(f, M, n, row_idx, col_idx):
    """Solve LP: max sum(g) s.t. (f*g)[k] <= M, g >= 0."""
    c = -np.ones(n)
    vals = np.empty(len(row_idx))
    for idx in range(len(row_idx)):
        k = row_idx[idx]
        i = col_idx[idx]
        vals[idx] = f[k - i]
    
    A_mat = lil_matrix((2 * n - 1, n))
    A_mat[row_idx, col_idx] = vals
    A_mat = A_mat.tocsr()
    
    b = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    
    try:
        res = linprog(c, A_ub=A_mat, b_ub=b, bounds=bounds, method='highs',
                      options={'presolve': True, 'dual_feasibility_tolerance': 1e-9})
        if res.success and res.fun is not None:
            g = np.maximum(res.x, 0.0)
            s = g.sum()
            if s > 1e-15:
                return g / s
    except Exception:
        pass
    return None

    for alpha in alphas:
        ft = np.maximum((1.0 - alpha) * f + alpha * g, 0.0)
        st = ft.sum()
        if st < 1e-15:
            continue
        ft = ft / st
        val = fast_convolve(ft).max()
        if val < best_val:
            best_val = val
            best_alpha = alpha
    
    # Fine search (ternary)
    if 0 < best_alpha < 1:
        lo = max(0.0, best_alpha - 0.15)
        hi = min(1.0, best_alpha + 0.15)
        for _ in range(15):
            m1 = lo + (hi - lo) / 3.0
            m2 = hi - (hi - lo) / 3.0
            f1 = np.maximum((1 - m1) * f + m1 * g, 0)
            f1 = f1 / f1.sum()
            v1 = fast_convolve(f1).max()
            f2 = np.maximum((1 - m2) * f + m2 * g, 0)
            f2 = f2 / f2.sum()
            v2 = fast_convolve(f2).max()
            if v1 < v2:

            else:

        mid = (lo + hi) / 2.0

        ft = ft / ft.sum()
        val = fast_convolve(ft).max()
        if val < best_val:

            best_alpha = mid

Let me try a completely different approach for the "different" requirement:

**Approach: Iterative Proportional Fitting (IPF) / Sinkhorn-like method**

The problem min_a max_k (a*a)[k] s.t. sum(a)=1, a>=0 can be reformulated as:
min_a max_k a^T M_k a s.t. 1^T a = 1, a >= 0

where M_k is the Hankel matrix for lag k.

A natural iterative method:
1. Start with a feasible a
2. Find the "worst" lag k* that maximizes a^T M_k* a
3. Update a to minimize a^T M_k* a (i.e., solve the QP min a^T M_k* a s.t. 1^T a = 1, a >= 0)
4. Repeat (cycling through the worst lags)

Step 3 is a quadratic programming problem: min a^T M_k a s.t. 1^T a = 1, a >= 0.
If M_k is PD, this has a unique solution. But M_k is not always PD (it's a combination of shift matrices).

Actually, for the QP min a^T M_k a, the first-order condition is 2 M_k a = λ 1 + μ (KKT multipliers for non-negativity). This is a linear system that's easy to solve.

This "cycling" approach is similar to the method of conditional gradients (Frank-Wolfe) but with a QP oracle instead of the max constraint.

Actually, I realize this is essentially what the FW-LP is already doing (the LP oracle finds the direction that most violates the max constraint). So let me not duplicate that.

**Another idea: Use the "exponential family" parameterization**

Instead of working with a directly, work with θ where a_i = exp(θ_i) / Z(θ).
The gradient with respect to θ has a nice form:
∂obj/∂θ_i = (∂obj/∂a_i) * a_i * (1 - a_i) (when obj is expressed in terms of a)

Wait, that's not quite right. If a = softmax(θ) (with the constraint sum(a)=1 automatically), then:
∂a_j/∂θ_i = a_j (δ_{ij} - a_i)

So ∂obj/∂θ_i = sum_j (∂obj/∂a_j) * a_j * (δ_{ij} - a_i)
= a_i * (∂obj/∂a_i) - a_i * sum_j a_j * (∂obj/∂a_j)

This is the "natural gradient" in the simplex. Using this parameterization might give better geometry for optimization.

Actually, for the simplex constraint, the natural gradient (Fisher metric) is just the Euclidean gradient projected onto the tangent space (sum of gradient components = 0). This is what project_simplex already does in a sense.

Let me try yet another approach: **subgradient method with cutting planes**.

1. Start with a feasible a
2. At each iteration, compute conv = a*a, find the peak lag k*
3. Add a "cut": a^T M_k* a <= current_peak
4. Solve the resulting QP: min 0 s.t. a^T M_k a <= t_k for all added cuts, sum(a)=1, a>=0

This is a QCQP with quadratic constraints, which is non-convex. But for a small number of cuts, we can solve it approximately.

Actually, this is getting too complicated. Let me focus on what's most likely to work:

1. **Better n exploration**: Try n = 512, 640, 768, 896, 1024, 1152, 1280, 1408, 1536, 2048, 2560
2. **L_p Nesterov with adaptive p**: Start with p=20 (smoother), gradually increase to p=200
3. **SDP initialization**: Solve the SDP for n=256 or 512 to get a good starting point
4. **FW-LP with better restart strategy**: More aggressive randomization

Let me now write the final code. I'll keep it focused and efficient.

One more thought: the evaluation function does `sequence = [max(0, x) for x in sequence]` and `sequence = [min(1000.0, x) for x in sequence]`. So the values are clipped to [0, 1000]. Since the objective is scale-invariant, this doesn't affect the optimization (as long as we stay in [0, 1000]).

Also, `if sum_a < 0.01: return np.inf`. So we need sum >= 0.01. Since we normalize to sum=1, this is always satisfied.

Let me write the code now. I'll aim for a clean, well-structured solution that:
1. Uses SDP for initialization (novel compared to previous)
2. Uses L_p smoothed Nesterov (novel compared to previous)
3. Uses FW-LP (proven to work)
4. Explores more n values
5. Has good time management

Here's my final plan:

"""

import numpy as np
import time
from scipy.optimize import linprog
from scipy.sparse import lil_matrix

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def compute_grad_smoothed(a, p_weights):
    """Compute gradient of sum_k p_weights[k] * conv[k] w.r.t. a."""
    n = len(a)
    # grad[j] = 2 * sum_i a[i] * p_weights[j+i] (with p_weights[k]=0 for k >= 2n-1)
    # = 2 * convolve(a[::-1], p_weights, 'full')[n-1:2n-1]
    a_rev = a[::-1]
    result = np.convolve(a_rev, p_weights, mode='full')[n-1:2*n-1]
    return 2.0 * result


def lp_smoothed_obj_grad(a, p_exp, p_power):
    """Compute L_p norm of conv and gradient.
    L_p = (sum conv[k]^p)^(1/p)
    """
    conv = fast_convolve(a)
    conv = np.maximum(conv, 0)
    
    # L_p objective
    conv_p = conv ** p_power
    total = np.sum(conv_p)
    if total < 1e-30:
        return 0.0, np.zeros(len(a))
    obj = total ** (1.0 / p_power)
    
    # Gradient: d/d a[j] of L_p = (1/p) * L_p^(1-p) * p * sum_k conv[k]^(p-1) * dconv[k]/da[j]
    # = L_p^(1-p) * sum_k conv[k]^(p-1) * 2*a[k-j]
    weights = conv ** (p_power - 1)  # conv[k]^(p-1)
    # Note: L_p^(1-p) = total^(1/p - 1) = total^(-(p-1)/p)
    factor = total ** ((1.0 / p_power) - 1.0)
    
    grad = factor * compute_grad_smoothed(a, weights)
    return obj, grad


def nesterov_lp(a0, time_limit, p_power=100, lr_init=0.01, verbose=False):
    """Nesterov-accelerated gradient descent on L_p smoothed objective."""
    a = a0.astype(np.float64).copy()
    a = np.maximum(a, 0)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    
    # Nesterov state
    y = a.copy()
    t = 1.0
    lr = lr_init
    
    t0 = time.monotonic()
    it = 0
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit - 0.1:
            break
        
        # Compute gradient at y
        obj_y, grad_y = lp_smoothed_obj_grad(y, 2, p_power)
        
        # Update t (Nesterov momentum)
        t_new = (1 + np.sqrt(1 + 4 * t * t)) / 2
        beta = (t - 1) / t_new
        
        # Gradient step
        y_new = y - lr * grad_y
        y_new = project_simplex(y_new)
        
        # Mix with previous position
        a_new = (1 - beta) * y_new + beta * a
        a_new = np.maximum(a_new, 0)
        a_new = a_new / a_new.sum()
        
        # Check actual (max) objective
        conv_new = fast_convolve(a_new)
        actual_obj = conv_new.max()
        
        # Adaptive learning rate
        if actual_obj < best_obj - 1e-12:
            best_obj = actual_obj
            best_a = a_new.copy()
            no_improve = 0
            # Can increase lr slightly
            lr = min(lr * 1.01, 0.05)
        else:
            no_improve += 1
            lr *= 0.995
        
        if no_improve > 200:
            # Reset momentum, try different p
            a = best_a.copy()
            y = a.copy()
            t = 1.0
            lr = lr_init * 0.5
            no_improve = 0
        
        # Periodic re-optimization with higher p
        if it % 500 == 0:
            a = best_a.copy()
            y = a.copy()
            t = 1.0
        
        a = a_new
        y = y_new
        t = t_new
    
    return best_a, best_obj


def softmax_smoothed_obj_grad(a, T):
    """Compute softmax-smoothed max and gradient."""
    conv = fast_convolve(a)
    scaled = conv / T
    scaled -= scaled.max()
    p = np.exp(scaled)
    p = p / p.sum()
    grad = compute_grad_smoothed(a, p)
    obj = np.dot(p, conv)  # smoothed approximation of max
    return obj, grad


def nesterov_softmax(a0, time_limit, T_init=0.001, lr_init=0.01, verbose=False):
    """Nesterov-accelerated on softmax-smoothed max."""
    a = a0.astype(np.float64).copy()
    a = np.maximum(a, 0)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    
    y = a.copy()
    t = 1.0
    lr = lr_init
    T = T_init
    
    t0 = time.monotonic()
    it = 0
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit - 0.1:
            break
        
        obj_y, grad_y = softmax_smoothed_obj_grad(y, T)
        
        t_new = (1 + np.sqrt(1 + 4 * t * t)) / 2
        beta = (t - 1) / t_new
        
        y_new = project_simplex(y - lr * grad_y)
        a_new = (1 - beta) * y_new + beta * a
        a_new = np.maximum(a_new, 0)
        a_new = a_new / a_new.sum()
        
        conv_new = fast_convolve(a_new)
        actual_obj = conv_new.max()
        
        if actual_obj < best_obj - 1e-12:
            best_obj = actual_obj
            best_a = a_new.copy()
            no_improve = 0
        else:
            no_improve += 1
            lr *= 0.998
            if no_improve > 50:
                T *= 1.01
        
        if no_improve > 300:
            a = best_a.copy()
            y = a.copy()
            t = 1.0
            lr = lr_init
            T = T_init
            no_improve = 0
        
        a = a_new
        y = y_new
        t = t_new
    
    return best_a, best_obj


def solve_sdp(n, time_limit=120):
    """Solve SDP relaxation for minimum peak autocorrelation.
    Returns (a_initial, sdp_bound) or (None, None) if failed.
    """
    if not HAS_CVXPY:
        return None, None
    
    try:
        X = cp.Variable((n, n), symmetric=True)
        t = cp.Variable()
        
        # Build constraints
        constraints = [X >> 0]  # X is PSD
        constraints.append(cp.sum(X) == 1)  # (sum a)^2 = 1
        
        # Convolution constraints: sum_{i+j=k} X[i,j] <= t
        for k in range(2 * n - 1):
            i_vals = []
            j_vals = []
            for i in range(n):
                j = k - i
                if 0 <= j < n:
                    i_vals.append(i)
                    j_vals.append(j)
            if i_vals:
                constraints.append(cp.sum(X[np.ix_(i_vals, j_vals)]) <= t)
        
        prob = cp.Problem(cp.Minimize(t), constraints)
        
        try:
            prob.solve(solver=cp.SCS, max_iters=2000, eps=1e-6)
        except:
            try:
                prob.solve(solver=cp.ECOS, max_iters=5000)
            except:
                return None, None
        
        if X.value is None:
            return None, None
        
        X_val = X.value
        # Extract a from diagonal
        a = np.sqrt(np.maximum(np.diag(X_val), 0))
        s = a.sum()
        if s < 1e-10:
            return None, None
        a = a / s
        
        sdp_bound = t.value if t.value is not None else float('inf')
        return a, sdp_bound
    
    except Exception as e:
        print(f"    SDP failed: {e}")
        return None, None


def build_lp_indices(n):
    rows = []
    cols = []
    for k in range(2 * n - 1):
        i_start = max(0, k - n + 1)
        i_end = min(k, n - 1)
        for i in range(i_start, i_end + 1):
            rows.append(k)
            cols.append(i)
    return np.array(rows), np.array(cols)


def solve_lp_oracle(f, M, n, row_idx, col_idx):
    c = -np.ones(n)
    vals = np.empty(len(row_idx))
    for idx in range(len(row_idx)):
        k = row_idx[idx]
        i = col_idx[idx]
        vals[idx] = f[k - i]
    
    A_mat = lil_matrix((2 * n - 1, n))
    A_mat[row_idx, col_idx] = vals
    A_mat = A_mat.tocsr()
    
    b = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    
    try:
        res = linprog(c, A_ub=A_mat, b_ub=b, bounds=bounds, method='highs',
                      options={'presolve': True})
        if res.success and res.fun is not None:
            g = np.maximum(res.x, 0.0)
            s = g.sum()
            if s > 1e-15:
                return g / s
    except Exception:
        pass
    return None


def fw_lp_optimize(f0, time_limit, verbose=False):
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    
    row_idx, col_idx = build_lp_indices(n)
    conv = fast_convolve(f)
    M = conv.max()
    best_obj = M
    best_f = f.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    m_exp = 1.0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 1.0:
            break
        
        eff_M = M * m_exp
        g = solve_lp_oracle(f, eff_M, n, row_idx, col_idx)
        if g is None:
            m_exp = min(m_exp * 1.5, 8.0)
            if m_exp >= 8.0:
                rng = np.random.default_rng(it * 31 + 7)
                g = project_simplex(f + rng.standard_normal(n) * 0.005)
                m_exp = 1.0
            else:
                continue
        
        if np.max(np.abs(g - f)) < 1e-12:
            no_improve += 1
            if no_improve > 50:
                rng = np.random.default_rng(it * 7919 + 13)
                f = project_simplex(best_f + rng.standard_normal(n) * 0.003)
                conv = fast_convolve(f)
                M = conv.max()
                m_exp = 1.0
                no_improve = 0
            continue
        
        # Line search
        best_alpha = 0.0
        best_val = M
        for alpha in [0.05, 0.1, 0.2, 0.3, 0.5, 0.7, 1.0]:
            ft = np.maximum((1.0 - alpha) * f + alpha * g, 0.0)
            st = ft.sum()
            if st < 1e-15:
                continue
            ft = ft / st
            val = fast_convolve(ft).max()
            if val < best_val:
                best_val = val
                best_alpha = alpha
        
        # Fine search
        if 0 < best_alpha < 1:
            lo = max(0.0, best_alpha - 0.1)
            hi = min(1.0, best_alpha + 0.1)
            for _ in range(12):
                m1 = lo + (hi - lo) / 3.0
                m2 = hi - (hi - lo) / 3.0
                f1 = np.maximum((1 - m1) * f + m1 * g, 0)
                f1 = f1 / f1.sum()
                v1 = fast_convolve(f1).max()
                f2 = np.maximum((1 - m2) * f + m2 * g, 0)
                f2 = f2 / f2.sum()
                v2 = fast_convolve(f2).max()
                if v1 < v2:
                    hi = m2
                else:
                    lo = m1
            mid = (lo + hi) / 2.0
            ft = np.maximum((1 - mid) * f + mid * g, 0)
            ft = ft / ft.sum()
            val = fast_convolve(ft).max()
            if val < best_val:
                best_val = val
                best_alpha = mid
        
        if best_alpha > 1e-10:
            f = np.maximum((1.0 - best_alpha) * f + best_alpha * g, 0.0)
            f = f / f.sum()
            conv = fast_convolve(f)
            M = conv.max()
            m_exp = 1.0
            
            if M < best_obj - 1e-15:
                best_obj = M
                best_f = f.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1
            m_exp = min(m_exp * 1.2, 8.0)
        
        if no_improve > 80:
            rng = np.random.default_rng((it * 104729) % (2**31 - 1))
            f = project_simplex(best_f + rng.standard_normal(n) * 0.002)
            conv = fast_convolve(f)
            M = conv.max()
            m_exp = 1.0
            no_improve = 0
    
    return best_f, best_obj
