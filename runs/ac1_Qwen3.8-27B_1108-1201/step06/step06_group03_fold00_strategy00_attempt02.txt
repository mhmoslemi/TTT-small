**Approach and Rationale**

We are minimizing the objective function `2 * n * max(convolve(a, a)) / (sum(a))^2` with non-negative step function coefficients. The key insight is that the optimal sparse sequence of length `n` (with `K` non-zero coefficients) naturally concentrates its mass at specific points, allowing for efficient computation and optimization. We start with a base sequence of length 768 from previous iterations (or initialize uniformly if not available) and use two powerful optimization techniques:

1. **Gauss-Legendre Quadrature Optimization**: Efficiently finds extremal points in the simplex using quadrature rules.
2. **Gradient Projection with Edge Shifting**: Enhances optimization by promoting boundary mass shifts, enabling the algorithm to escape local minima.

SpicySparseMinimizer explicitly generates coordinates for Gauss-Legendre quadrature at each iteration, ensuring key mass concentration points. The search explores multiple `n` values, starting from a base length and extending to longer sequences for higher dimensions. This strategy balances between finding optimal solutions for specific `n` with known good sparse configurations and exploring other lengths through iterative refinement.

**Mathematical Specification**

The goal is to minimize the invariant expression `2 * n * \|b\|_\infty / (sum(a))^2` by solving:
- **Constraint**: `sum(a) = \|a\|_1` (simplex)
- **Feature**: `a = (a_1, a_2, ..., a_K)` where `K` is the number of extremal points
- **Convolution**: `b_j = \|a\|_j * \|a\|_{j + K}`, with `j` ranging from `\|a\|_0` to `\|a\|_{2n - 2}`

The sparse optimization handles non-negativity by projecting onto the simplex, and the objective uses exact full mode convolution. Edge shifting augments gradients to ensure better local exploration.

        temp[random_point] += shift
        temp = temp / np.sum(temp)

        score_temp = np.max(conv)
        if score_temp < score:
