- Objective: f(a) = 2*n*max_k c_k / (sum a)^2. Since sum a = 1 (after normalization), this is 2*n*max_k c_k.
- c_k = sum_j a_j * a_{k-j} is a quadratic form in a.
- max_k c_k is the max of quadratic forms.
- A max of convex functions is convex IF each function is convex.
- c_k = sum_j a_j * a_{k-j}. Is this convex in a? It's a quadratic form a^T H_k a where H_k is a Hankel-like matrix. For this to be convex, H_k must be PSD.

H_k has entries H_k[j,m] = 1 if j+m = k (for 0-indexed, this means the (j,m) entry is 1 when j+m=k). This is an anti-diagonal matrix, which is a permutation matrix. Permutation matrices are NOT PSD in general (they have eigenvalues on the unit circle, including -1).

So c_k is a QUADRATIC FORM with an indefinite matrix. It's neither convex nor concave in general. Therefore, the problem is NOT convex!

This is why the problem is hard. The non-convexity comes from the quadratic nature of the auto-convolution.

However, on the simplex (a >= 0), the form c_k = sum_j a_j * a_{k-j} is always non-negative (since all terms are products of non-negative numbers). And it's bilinear in the pairs (a_j, a_{k-j}).

So the problem is a non-convex QCQP (quadratically constrained quadratic program). This explains why simple gradient methods might get stuck.

**Key algorithmic insight**: Since the problem is non-convex, we need:
1. Multiple starting points
2. Global search (or at least diverse local searches)
3. Exploitation of the specific structure (bilinear in pairs)

**Another idea: Coordinate descent with exact line search**

For coordinate j, fixing all other coordinates, c_k as a function of a_j is:
c_k = a_j * (sum of relevant a's) + (terms not involving a_j)

Specifically, c_k involves a_j when j is in the valid range for position k, i.e., when max(0, k-n+1) <= j <= min(k, n-1). In that case, c_k includes the term a_j * a_{k-j}.

So as a function of a_j (with all other a's fixed), c_k is LINEAR: c_k = a_j * a_{k-j} + const (for k where j is valid).

And max_k c_k is the max of linear functions of a_j, which is CONVEX in a_j!

This means we can do exact coordinate descent: for each coordinate j, find the value of a_j (given all others fixed, and the simplex constraint) that minimizes max_k c_k.

The simplex constraint when changing a_j: we need a_j >= 0 and sum a = 1. If we change a_j from its current value, we need to adjust another coordinate (or scale all others). 

Actually, for coordinate descent on the simplex, the standard approach is:
- Fix all coordinates except a_j
- The constraint is a_j >= 0 and sum_{i != j} a_i + a_j = 1
- So a_j = 1 - sum_{i != j} a_i (determined by the others)
- This means we can't independently change a_j without changing others!

Alternative: Use the "paired swap" approach:
- Pick two coordinates j and m
- Transfer mass: a_j -> a_j + t, a_m -> a_m - t (keeping sum = 1)
- Optimize over t >= max(-a_j, -a_m) (to keep both non-negative)
- The objective as a function of t is the max of linear functions (since each c_k is linear in t when only a_j and a_m change)
- So we can find the exact optimal t by checking the breakpoints!

This is a form of **coordinate descent with exact line search on pairs**. It's guaranteed to make progress (or identify a local optimum) at each step.

Actually, let me be more careful. When a_j -> a_j + t and a_m -> a_m - t:
c_k = sum_{valid l} a_l * a_{k-l}

The terms involving a_j: a_j * a_{k-j} (when k-j is valid) -> (a_j + t) * a_{k-j} = a_j * a_{k-j} + t * a_{k-j}
The terms involving a_m: a_m * a_{k-m} (when k-m is valid) -> (a_m - t) * a_{k-m} = a_m * a_{k-m} - t * a_{k-m}
Also the cross term: if k-j = m, i.e., k = j+m, then there's a term a_j * a_m -> (a_j+t)(a_m-t) = a_j*a_m + t(a_m - a_j) - t^2. This is QUADRATIC in t!

Similarly if k-m = j, i.e., k = j+m (same condition), the cross term appears.

So c_{j+m} has a -t^2 term. All other c_k are linear in t.

So the objective max_k c_k(t) is the max of:
- Linear functions (for all k != j+m)
- One quadratic function (for k = j+m, which is -t^2 + linear + const)

The max of these is a piecewise function. We can find its minimum by:
1. Computing all the breakpoints where the active constraint changes
2. Checking the minimum of the quadratic at its vertex (if it's the active constraint there)
3. Checking the values at all breakpoints

The number of breakpoints is at most 2n-2 (one for each pair of linear functions crossing), which is O(n). So each coordinate pair step is O(n^2) (O(n) breakpoints × O(n) to evaluate each).

Total cost per full sweep over all pairs: O(n^2) pairs × O(n^2) per pair = O(n^4). For n=768, that's about 3.5 × 10^11. Too slow!

But we don't need to check all pairs. We can be smarter:

import numpy as np
from scipy.optimize import linprog
import time

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def smooth_grad(a, T):

def corrected_fw_oracle(a, active_peaks):
    """
    Solve the correct Frank-Wolfe oracle:
    minimize t
    subject to: 2 * sum_j a[j] * g[k-j] <= t for all k in active_peaks
    sum(g) = 1, g >= 0
    """
    n = len(a)
    # Build constraint matrix
    # For each active peak k: sum_j a[j] * g[k-j] <= t/2
    # Valid j for peak k: max(0, k-n+1) <= j <= min(k, n-1)
    
    m = len(active_peaks)
    A_ub = np.zeros((m, n))
    for i, k in enumerate(active_peaks):
        js = max(0, k - n + 1)
        je = min(n - 1, k)
        A_ub[i, js:je+1] = a[k - je:js-1:-1]  # a[k-j] for j from je down to js
        # Wait, let me be more careful.
        # For j in [js, je]: coefficient of g[j] is a[k-j]
        # So A_ub[i, j] = a[k-j] for j in [js, je]
        for j in range(js, je+1):
            A_ub[i, j] = a[k-j]
    
    # We want: A_ub @ g <= t/2, sum(g) = 1, g >= 0
    # This is: minimize t s.t. 2*A_ub@g <= t, sum(g)=1, g>=0
    # Substitute: let's use the LP formulation
    # Variables: g[0],...,g[n-1], t
    # Minimize: t
    # Subject to: 2*A_ub@g - t <= 0 (m constraints)
    #             sum(g) = 1
    #             g >= 0, t >= 0
    
    # In linprog form: minimize c @ x
    c = np.zeros(n + 1)
    c[-1] = 1.0  # minimize t
    
    A_ub_full = np.zeros((m, n + 1))
    A_ub_full[:, :n] = 2.0 * A_ub
    A_ub_full[:, n] = -1.0  # 2*A_ub@g - t <= 0
    
    b_ub = np.zeros(m)
    
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0  # sum(g) = 1
    b_eq = np.array([1.0])
    
    bounds = [(0, None)] * n + [(0, None)]
    
    try:
        res = linprog(c, A_ub=A_ub_full, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq, 
                     bounds=bounds, method='highs', options={'presolve': True, 'max_time': 30})
        if res.success:
            return np.maximum(res.x[:n], 0)
    except Exception:
        pass
    return None

def mirror_descent_smooth(a0, time_limit, T_init=0.005, T_end=0.0005, lr_init=0.05):
    """
    Mirror descent (multiplicative updates) with smooth log-sum-exp objective.
    """
    a = np.maximum(a0.astype(np.float64), 1e-15)
    a = a / a.sum()
    n = len(a)
    T = T_init
    lr = lr_init
    
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    total_time = time_limit
    
    while time.monotonic() - t0 < total_time:
        it += 1
        
        # Anneal temperature
        progress = (time.monotonic() - t0) / total_time
        T = T_init * (T_end / T_init) ** progress
        
        # Compute smooth gradient
        grad, conv, p = smooth_grad(a, T)
        obj = conv.max()
        
        # Mirror descent update: a_j <- a_j * exp(-lr * grad_j) / Z
        # Use log-space for numerical stability
        log_a = np.log(a)
        v = log_a - lr * grad
        v -= v.max()  # for stability
        a_new = np.exp(v)
        a_new = a_new / a_new.sum()
        
        # Check improvement
        conv_new = fast_convolve(a_new)
        obj_new = conv_new.max()
        
        if obj_new < obj - 1e-15:
            a = a_new
            if obj_new < best_obj - 1e-15:
                best_obj = obj_new
                best_a = a.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            # Try smaller step
            improved = False
            for scale in [0.5, 0.25, 0.125, 0.0625]:
                v = log_a - lr * scale * grad
                v -= v.max()
                a_try = np.exp(v)
                a_try = a_try / a_try.sum()
                obj_try = fast_convolve(a_try).max()
                if obj_try < obj - 1e-15:
                    a = a_try
                    obj = obj_try
                    improved = True
                    if obj < best_obj - 1e-15:
                        best_obj = obj
                        best_a = a.copy()
                        no_improve = 0
                    else:
                        no_improve += 1
                    break
            if not improved:
                no_improve += 1
                lr *= 0.9
        
        # Adapt learning rate
        if no_improve > 50:
            lr *= 0.8
        if no_improve > 200:
            # Perturb and restart
            rng = np.random.default_rng((it * 48271 + 13) % (2**31 - 1))
            noise = rng.standard_normal(n) * 0.01
            a = np.maximum(a + noise, 1e-15)
            a = a / a.sum()
            lr = lr_init
            no_improve = 0
            T = T_init * 0.5
    
    return best_a, best_obj

def subgrad_corrected(a0, time_limit, top_k=20, lr_init=0.03):

    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    v = np.zeros(n)
    lr = lr_init
    mom = 0.9
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit - 0.05:
            break
        
        conv = fast_convolve(a)
        peaks = np.argpartition(conv, -top_k)[-top_k:]
        pv = conv[peaks]
        # Inverse rank weighting
        order = np.argsort(pv)[::-1]
        weights = np.zeros(top_k)
        for rank, idx in enumerate(order):
            weights[idx] = 1.0 / (rank + 1) ** 1.5
        ws = weights.sum()
        weights /= ws
        
        # Compute subgradient
        sg = np.zeros(n)
        for i in range(top_k):
            if weights[i] < 1e-14:
                continue
            k = int(peaks[i])
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx_arr = np.arange(js, je + 1)
            sg[idx_arr] += weights[i] * a[k - idx_arr]
        sg *= 2.0
        
        # Momentum step
        v = mom * v - lr * sg
        
        # Line search
        best_candidate = a
        best_val = conv.max()
        for scale in [1.0, 0.7, 0.5, 0.35, 0.25, 0.125]:
            candidate = project_simplex(a + scale * v)
            c = fast_convolve(candidate)
            val = c.max()
            if val < best_val - 1e-16:
                best_val = val
                best_candidate = candidate
                break
        
        a = best_candidate
        
        if best_val < best_obj - 1e-15:
            best_obj = best_val
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
            v *= 0.9
            lr *= 0.98
        
        if no_improve > 50:
            lr *= 0.9
        if no_improve > 200:
            rng = np.random.default_rng((it * 31 + 7) % (2**31 - 1))
            noise = 0.003 + 0.005 * min(1.0, (no_improve - 200) / 200.0)
            a = project_simplex(best_a + rng.standard_normal(n) * noise)
            v = np.zeros(n)
            lr = lr_init
            mom = 0.9
            no_improve = 0
    
    return best_a, best_obj

def corrected_fw(a0, time_limit, peak_tol=0.005, max_lp_time=20):
    """
    Corrected Frank-Wolfe with proper directional derivative oracle.
    """
    a = np.maximum(a0.astype(np.float64), 0.0)
    a = a / a.sum()
    n = len(a)
    
    conv = fast_convolve(a)
    M = conv.max()
    best_obj = M
    best_a = a.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 1.0:
            break
        
        conv = fast_convolve(a)
        M = conv.max()
        
        # Identify active peaks (within peak_tol fraction of max)
        threshold = M * (1.0 - peak_tol)
        active_peaks = np.where(conv >= threshold)[0]
        
        if len(active_peaks) == 0:
            active_peaks = np.array([np.argmax(conv)])
        
        # Solve corrected FW oracle
        g = corrected_fw_oracle(a, active_peaks)
        if g is None:
            no_improve += 1
            if no_improve > 20:
                # Fallback: use the negative gradient direction
                conv = fast_convolve(a)
                k_max = np.argmax(conv)
                g = np.zeros(n)
                js = max(0, k_max - n + 1)
                je = min(n - 1, k_max)
                idx_arr = np.arange(js, je + 1)
                g[idx_arr] = a[k_max - idx_arr]
                gs = g.sum()
                if gs > 0:
                    g = g / gs
                else:
                    break
            continue
        
        gs = g.sum()
        if gs < 1e-15:
            break
        g = g / gs
        
        # Check if g is same as a (convergence)
        if np.max(np.abs(g - a)) < 1e-13:
            no_improve += 1
            if no_improve > 30:
                break
            continue
        
        # Line search
        best_alpha = 0.0
        best_val = M
        alphas = [0.02, 0.05, 0.1, 0.15, 0.2, 0.3, 0.4, 0.5, 0.7, 0.85, 1.0]
        for alpha in alphas:
            ft = (1.0 - alpha) * a + alpha * g
            ft = np.maximum(ft, 0.0)
            st = ft.sum()
            if st < 1e-15:
                continue
            ft = ft / st
            val = fast_convolve(ft).max()
            if val < best_val:
                best_val = val
                best_alpha = alpha
        
        if best_alpha > 1e-10:
            # Bisection refinement
            lo = max(0.0, best_alpha - 0.03)
            hi = min(1.0, best_alpha + 0.03)
            for _ in range(8):
                mid = (lo + hi) / 2.0
                ft = (1.0 - mid) * a + mid * g
                ft = np.maximum(ft, 0.0)
                st = ft.sum()
                if st < 1e-15:
                    break
                ft = ft / st
                val = fast_convolve(ft).max()
                if val < best_val:
                    best_val = val
                    best_alpha = mid
                    lo = mid
                else:
                    hi = mid
            
            a = (1.0 - best_alpha) * a + best_alpha * g
            a = np.maximum(a, 0.0)
            a = a / a.sum()
            
            if best_val < best_obj - 1e-15:
                best_obj = best_val
                best_a = a.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1
        
        if no_improve > 40:
            # Perturb
            rng = np.random.default_rng(it * 7919 + 13)
            scale = 0.003 + 0.005 * min(1.0, no_improve / 80.0)
            a = project_simplex(best_a + rng.standard_normal(n) * scale)
            no_improve = 0
        
        # Adapt peak tolerance
        if no_improve > 15:
            peak_tol = max(0.001, peak_tol * 0.8)
        elif no_improve == 0:
            peak_tol = min(0.02, peak_tol * 1.2)
    
    return best_a, best_obj

def pair_swap_refine(a0, time_limit):
    """
    Pair-swap with exact (or near-exact) line search for final polishing.
    For each pair (j, m), optimize the transfer t that minimizes max conv.
    """
    a = np.maximum(a0.astype(np.float64), 0.0)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    
    t0 = time.monotonic()
    rng = np.random.default_rng(12345)
    
    while time.monotonic() - t0 < time_limit:
        # Pick a random pair
        j = rng.integers(0, n)
        m = rng.integers(0, n)
        if j == m:
            continue
        
        # Optimize t: a[j] + t, a[m] - t
        # Valid range: t in [-a[j], a[m]]
        # Objective: max_k c_k(t) where c_k(t) = c_k(0) + t*(a[k-j] - a[k-m]) - t^2*(delta_{k,j+m} stuff)
        
        conv0 = fast_convolve(a)
        
        # Compute the linear coefficients
        # c_k(t) = c_k(0) + t * (a[k-j] - a[k-m]) - t^2 * (1 if k==j+m and j!=m, with correction)
        # Actually: the cross term a_j * a_{k-j} becomes (a_j+t)*a_{k-j} = a_j*a_{k-j} + t*a_{k-j}
        # And a_m * a_{k-m} becomes (a_m-t)*a_{k-m} = a_m*a_{k-m} - t*a_{k-m}
        # Plus if k-j = m (i.e., k = j+m): the term a_j * a_m becomes (a_j+t)(a_m-t) = a_j*a_m + t(a_m-a_j) - t^2
        # Similarly if k-m = j (same condition k = j+m): handled above
        
        # So the coefficient of t in c_k is: a[k-j] - a[k-m] (with a[k-j]=0 if k-j out of range)
        # Plus if k = j+m: additional (a_m - a_j) from the cross term
        # And the coefficient of t^2 in c_k is: -1 if k = j+m, else 0
        
        linear = np.zeros(2*n-1)
        quadratic = np.zeros(2*n-1)
        
        # For j contribution: c_k gets t * a[k-j] for valid k-j
        js_min = 0
        js_max = n - 1
        for k in range(2*n-1):
            kj = k - j
            if 0 <= kj < n:
                linear[k] += a[kj]
            km = k - m
            if 0 <= km < n:
                linear[k] -= a[km]
        
        # Cross term: if k = j + m (and j != m):
        k_cross = j + m
        if k_cross < 2*n - 1:
            # The cross term a_j * a_m: derivative w.r.t. t is (a_m - a_j)
            # Second derivative: -1
            linear[k_cross] += (a[m] - a[j])  # additional linear term from cross
            quadratic[k_cross] = -1.0
        
        # Now find t that minimizes max_k (conv0[k] + t*linear[k] + t^2*quadratic[k])
        # subject to t in [-a[j], a[m]]
        
        t_lo = -a[j]
        t_hi = a[m]
        
        # Use golden section or bisection to find the minimum
        # The function f(t) = max_k (conv0[k] + t*linear[k] + t^2*quadratic[k]) is convex in t
        # (max of convex functions: each c_k(t) is convex since quadratic[k] <= 0 means concave... wait)
        # Actually quadratic[k] = -1 for k=j+m, 0 otherwise.
        # c_{j+m}(t) = conv0[j+m] + t*linear[j+m] - t^2: this is CONCAVE in t.
        # The other c_k(t) are LINEAR in t.
        # So f(t) = max(linear functions, one concave quadratic).
        # The max of linear functions is convex. The max with a concave function is... not necessarily convex!
        # Hmm, this complicates things.
        
        # Let me just use a grid search over t in [t_lo, t_hi]
        # For n=768, a grid of 100 points should be fine
        t_grid = np.linspace(t_lo, t_hi, 100)
        best_t = 0.0
        best_t_val = conv0.max()
        
        for t in t_grid:
            if t == 0:
                continue
            a_try = a.copy()
            a_try[j] += t
            a_try[m] -= t
            if a_try[j] < -1e-15 or a_try[m] < -1e-15:
                continue
            a_try = np.maximum(a_try, 0)
            st = a_try.sum()
            if st < 1e-15:
                continue
            a_try = a_try / st
            val = fast_convolve(a_try).max()
            if val < best_t_val:
                best_t_val = val
                best_t = t
        
        if best_t != 0 and best_t_val < best_obj - 1e-15:
            a[j] += best_t
            a[m] -= best_t
            a = np.maximum(a, 0)
            a = a / a.sum()
            best_obj = best_t_val
            best_a = a.copy()
    
    return best_a, best_obj
