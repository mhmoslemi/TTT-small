So `(a*a)[n-1] = 1/2`. And `(a*a)[0] = 1/4`, `(a*a)[2n-2] = 1/4`.

So `max = 1/2 > 1/n` for large n. Not good.

The point is: creating "gaps" in the sequence can reduce the central peak but creates other issues.

Let me think about what the optimal structure looks like.

For the problem to have `max(conv) < 1/n`, we need a sequence where:
1. The "self-overlap" at the center is reduced (avoid having `a_j` and `a_{n-1-j}` both large)
2. But we also need to keep the "edge overlaps" small

This suggests a structure where the sequence alternates between high and low values in a pattern that avoids creating large products at any lag.

This is related to the concept of a "Costas array" or "Golomb ruler" - sequences where all pairwise differences are distinct (or nearly distinct).

In the continuous setting, we want a density `a(x)` on `[0, n]` such that the autocorrelation `R(k) = integral a(x) a(x+k) dx` is as flat as possible (minimizing the peak).

The optimal solution is related to the "minimum peak sidelobe" problem in radar/communications.

Anyway, let me focus on the practical algorithm. Given the small gap to close (0.002), I'll implement:

1. **Multi-peak subgradient with exact active set**: Track all peaks within ε of the maximum, compute the weighted subgradient.

2. **Projected gradient with backtracking line search**: More robust than fixed step size.

3. **LP oracle (infrequent)**: Use the LP from the previous code but only every K iterations.

4. **Pairwise "mass transfer"**: Find pairs (i,j) where transferring mass from i to j reduces the maximum peak.

5. **Multi-n exploration**: Try n = 640, 768, 896, 1024.

6. **Simulated annealing on top of gradient flow**: Occasionally accept worse solutions to escape local minima.

Let me think about the line search more carefully. The function `max_k (a*a)[k]` is convex? No, it's not convex in general (it's the max of quadratic forms, and those quadratics are not necessarily convex).

Actually, each `(a*a)[k] = a^T H_k a` where `H_k` is a (symmetric) Hankel matrix. `H_k` is PSD if and only if... hmm, it's not always PSD.

For example, `H_0` has `H_0[j,j] = 1` for all `j`, and `H_0[j,k] = 1` if `j+k = 0` (only `j=k=0`). Wait no, `H_k[j,m] = 1` if `j+m = k` (for the convolution `(a*a)[k] = sum_{j+m=k} a_j a_m`... no that's not right either.

Let me be more careful. `(a*a)[k] = sum_j a_j * a_{k-j}` where the sum is over valid `j`. This can be written as `a^T P_k a` where `P_k` is a matrix with `P_k[j, k-j] = 1` (and `P_k[k-j, j] = 1` for symmetry, since `a^T P a = sum_{j,m} a_j P[j,m] a_m` and we want `sum_j a_j a_{k-j}`).

Actually: `(a*a)[k] = sum_{j: 0<=j<n, 0<=k-j<n} a_j * a_{k-j}`.

Let `S_k = {j : 0<=j<n, 0<=k-j<n}`. Then `(a*a)[k] = sum_{j in S_k} a_j * a_{k-j}`.

If we define `P_k[j,m] = 1` if `m = k-j` and `j,m in S_k`, else 0. Then `(a*a)[k] = sum_{j,m} a_j P_k[j,m] a_m = a^T P_k a`.

But `P_k` is not symmetric in general (unless we treat it differently). Actually, `P_k[j,m] = 1` iff `m = k - j`. And `P_k[m,j] = 1` iff `j = k - m`, i.e., `m = k - j`. So actually `P_k` IS symmetric! (because the condition `m = k-j` is equivalent to `j = k-m`).

So `(a*a)[k] = a^T P_k a` where `P_k` is symmetric. Is `P_k` PSD? The eigenvalues of `P_k`... `P_k` is a permutation matrix (it maps `j` to `k-j`), possibly with some zero rows/columns. A permutation matrix that is symmetric is a product of transpositions, and its eigenvalues are ±1. So `P_k` is NOT PSD in general (it has negative eigenvalues).

This means `(a*a)[k]` is not a convex function of `a` in general. The problem is non-convex.

However, the max of non-convex functions is still non-convex, so we can't use standard convex optimization tools.

Given this, the subgradient method is appropriate (it works for any locally Lipschitz function).

Let me now write the actual code. I'll focus on efficiency and the specific insights:

1. The subgradient of `max_k (a*a)[k]` at a point where peaks `k_1, ..., k_m` are active is:
   `g = sum_l w_l * 2 * (P_{k_l} @ a)`
   where `P_{k_l} @ a` is the "reflected and shifted" version of `a`.

2. Specifically, `(P_k @ a)[j] = a_{k-j}` if `0 <= k-j < n`, else 0.

3. This can be computed efficiently by indexing.

Let me code this up:

```python
def subgradient_conj(a, peaks, weights):
    """Compute weighted sum of subgradients at given peaks."""
    n = len(a)
    g = np.zeros(n)
    for k, w in zip(peaks, weights):
        if w < 1e-15:
            continue
        # (P_k @ a)[j] = a[k-j] if 0 <= k-j < n
        js = np.arange(n)
        ks = k - js
        valid = (ks >= 0) & (ks < n)
        g[valid] += w * 2.0 * a[ks[valid]]
    return g
```

This is O(n * m) where m is the number of active peaks. For m = 10 and n = 768, that's about 7680 operations per gradient step, which is fast.

For the line search, I'll use backtracking:
- Start with a trial step size
- If the objective increases, halve the step size
- Accept when the objective decreases

Now, for the LP oracle, I'll adapt the previous code's approach but make it more efficient:
- Only solve the LP every K iterations (e.g., K=50)
- Use the previous LP solution as a warm start hint (though scipy's linprog doesn't support warm starts directly)
- Limit the LP time to keep it bounded

Let me also add a "mass transfer" heuristic:
- For the peak position k, find the pair (i, k-i) with the largest product a_i * a_{k-i}
- Find position j (far from the peak's support) with smallest a_j
- Transfer a small amount of mass from i to j
- Check if the maximum peak decreased

This is a local search move that can escape plateaus.

Key innovations over previous approach:

2. Backtracking line search for robust step size selection

6. Simulated annealing acceptance for escaping local minima

import time


def fast_conv(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def active_set_subgradient(a, conv, eps_rel=0.005):
    """
    Compute subgradient of max(conv) using active set of peaks.
    Returns (gradient, objective_value, peak_count).
    """
    n = len(a)
    max_val = conv.max()
    if max_val < 1e-30:
        return np.zeros(n), 0.0, 0
    
    # Find peaks within eps_rel of max
    threshold = max_val * (1.0 - eps_rel)
    active = np.where(conv >= threshold)[0]
    
    # Weight peaks by how close they are to max (exponential weighting)
    peak_vals = conv[active]
    # Use temperature-based weighting
    T = max_val * 0.01  # small temperature
    weights = np.exp(-(max_val - peak_vals) / T)
    weights = weights / weights.sum()
    
    # Compute weighted subgradient
    g = np.zeros(n)
    for idx, k in enumerate(active):
        w = weights[idx]
        if w < 1e-15:
            continue
        k = int(k)
        # (P_k @ a)[j] = a[k-j] if 0 <= k-j < n
        js = np.arange(n)
        ks = k - js
        valid = (ks >= 0) & (ks < n)
        g[valid] += w * 2.0 * a[ks[valid]]
    
    return g, max_val, len(active)


def subgradient_optimize(a0, time_limit, eps_rel=0.005, lr_init=0.01, 
                          lp_interval=200, verbose=True):
    """
    Subgradient optimization with active set tracking, backtracking line search,
    and periodic LP oracle.
    """
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    best_a = a.copy()
    best_obj = fast_conv(a).max()
    
    lr = lr_init
    t0 = time.monotonic()
    it = 0
    no_improve = 0
    momentum = 0.9
    v = np.zeros(n)  # momentum buffer
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit - 0.05:
            break
        
        conv = fast_conv(a)
        max_val = conv.max()
        
        # Periodic LP oracle
        if lp_interval > 0 and it % lp_interval == 0:
            g_lp = solve_lp_quick(a, max_val, time_limit_lp=5.0)
            if g_lp is not None:
                g_lp_sum = g_lp.sum()
                if g_lp_sum > 1e-10:
                    g_lp = g_lp / g_lp_sum
                    # Take a step toward LP solution
                    for alpha in [0.1, 0.3, 0.5, 0.7, 1.0]:
                        candidate = (1 - alpha) * a + alpha * g_lp
                        candidate = np.maximum(candidate, 0)
                        cs = candidate.sum()
                        if cs < 1e-15:
                            continue
                        candidate = candidate / cs
                        c = fast_conv(candidate).max()
                        if c < best_obj - 1e-15:
                            a = candidate
                            best_obj = c
                            best_a = a.copy()
                            no_improve = 0
                            break
                        elif c < max_val:
                            a = candidate
                            max_val = c
                            break
                    continue
        
        # Compute active set subgradient
        g, cur_obj, n_active = active_set_subgradient(a, conv, eps_rel)
        
        # Momentum update
        v = momentum * v - lr * g
        a_trial = project_simplex(a + v)
        
        # Backtracking line search
        accepted = False
        for backtrack in range(10):
            candidate = project_simplex(a - lr * (0.5 ** backtrack) * g)
            c = fast_conv(candidate).max()
            if c < cur_obj - 1e-16:
                a = candidate
                obj = c
                accepted = True
                break
        
        if not accepted:
            # Try with momentum
            a_trial = project_simplex(a + v)
            c = fast_conv(a_trial).max()
            if c < cur_obj - 1e-16:
                a = a_trial
                obj = c
                accepted = True
        
        if not accepted:
            # No improvement, adapt
            lr *= 0.95
            no_improve += 1
            if no_improve > 100:
                # Random perturbation
                rng = np.random.default_rng(it * 31 + 7)
                a = project_simplex(best_a + rng.standard_normal(n) * 0.002)
                conv = fast_conv(a)
                cur_obj = conv.max()
                lr = lr_init * 0.5
                no_improve = 0
            continue
        
        # Update
        if obj < best_obj - 1e-14:
            best_obj = obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        # Adapt learning rate
        if no_improve > 50:
            lr *= 0.98
        elif no_improve <= 10:
            lr = min(lr * 1.01, lr_init)
        
        # Anneal momentum
        if it % 500 == 0:
            momentum = min(0.99, momentum + 0.001)
    
    return best_a, best_obj


def solve_lp_quick(f, M, time_limit_lp=5.0):
    """Solve LP: max sum(g) s.t. (f*g)[k] <= M for all k, g >= 0. Time-limited."""
    n = len(f)
    # For large n, this LP might be slow. Use a simplified version.
    if n > 2000:
        return None
    
    t_start = time.monotonic()
    c = -np.ones(n)
    # Build constraint matrix sparsely
    # (f*g)[k] = sum_j f_j * g[k-j] <= M
    # For each k, the constraint involves g[valid indices]
    A_ub = np.zeros((2 * n - 1, n))
    for j in range(n):
        A_ub[j:j + n, j] = f
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': max(1, time_limit_lp)})
        if time.monotonic() - t_start > time_limit_lp * 1.5:
            return None
        if res.success:
            return np.maximum(res.x, 0.0)
    except Exception:
        pass
    return None


def mass_transfer_optimize(a0, time_limit, verbose=True):
    """
    Local search via pairwise mass transfer.
    For each peak, find the pair contributing most and transfer mass to a "safe" position.
    """
    a = np.maximum(a0.astype(np.float64), 0.0)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_obj = fast_conv(a).max()
    
    t0 = time.monotonic()
    it = 0
    stale = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit - 0.05:
            break
        
        conv = fast_conv(a)
        max_val = conv.max()
        
        # Get top peaks
        top_k = min(5, len(conv))
        peaks = np.argpartition(conv, -top_k)[-top_k:]
        peaks = peaks[np.argsort(conv[peaks])[::-1]]
        
        improved = False
        for k_peak in peaks:
            k_peak = int(k_peak)
            # Find contributing pairs
            js = max(0, k_peak - n + 1)
            je = min(n - 1, k_peak)
            affected = np.arange(js, je + 1)
            if len(affected) == 0:
                continue
            
            products = a[affected] * a[k_peak - affected]
            j_max = affected[np.argmax(products)]
            
            # Find "safe" destination: position that minimizes impact on all peaks
            # Approximate: position with smallest contribution to any peak
            outside = np.setdiff1d(np.arange(n), affected)
            if len(outside) == 0:
                continue
            
            # Score each outside position by its max contribution to any peak
            # (approximation: use its value times a scaling factor)
            j_min = outside[np.argmin(a[outside])]
            
            # Try several transfer amounts
            for delta in [0.0001, 0.0002, 0.0005, 0.001, 0.002]:
                if a[j_max] < delta:
                    continue
                candidate = a.copy()
                candidate[j_max] -= delta
                candidate[j_min] += delta
                candidate = np.maximum(candidate, 0.0)
                candidate = candidate / candidate.sum()
                c = fast_conv(candidate).max()
                if c < best_obj - 1e-15:
                    a = candidate
                    best_obj = c
                    best_a = a.copy()
                    improved = True
                    break
            
            if improved:
                break
        
        if improved:
            stale = 0
        else:
            stale += 1
            if stale > 200:
                rng = np.random.default_rng(it * 7919 + 13)
                a = project_simplex(best_a + rng.standard_normal(n) * 0.001)
                c = fast_conv(a).max()
                if c < best_obj - 1e-15:
                    best_obj = c
                    best_a = a.copy()
                stale = 0
            if stale > 2000:
                break
    
    return best_a, best_obj

def cyclic_coordinate_descent(a0, time_limit, verbose=True):
    """
    Cyclic coordinate descent with lookahead.
    For each coordinate, find the optimal value given others fixed.
    """
    a = np.maximum(a0.astype(np.float64), 0.0)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_obj = fast_conv(a).max()
    
    t0 = time.monotonic()
    it = 0
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit - 0.05:
            break
        
        improved_any = False
        # Cycle through coordinates (subset for speed)
        step = max(1, n // 200)  # Try about 200 coordinates per sweep
        for j in range(0, n, step):
            if time.monotonic() - t0 > time_limit - 0.1:
                break
            
            # Try several values for a[j]
            # Current value and neighbors
            vals = [a[j] * 0.5, a[j] * 0.75, a[j] * 1.25, a[j] * 1.5,
                    a[j] - 0.001, a[j] + 0.001, a[j] - 0.0001, a[j] + 0.0001, 0.0]
            best_val = a[j]
            best_c = best_obj
            
            for v in vals:
                if v < 0:
                    v = 0.0
                trial = a.copy()
                trial[j] = v
                # Renormalize
                ts = trial.sum()
                if ts < 1e-15:
                    continue
                trial = trial / ts
                c = fast_conv(trial).max()
                if c < best_c - 1e-15:
                    best_c = c
                    best_val = v
            
            if best_val != a[j]:
                a[j] = best_val
                a = a / a.sum()
                best_obj = best_c
                best_a = a.copy()
                improved_any = True
        
        if not improved_any:
            no_improve += 1
            if no_improve > 20:
                rng = np.random.default_rng(it * 31 + 7)
                a = project_simplex(best_a + rng.standard_normal(n) * 0.001)
                best_obj = fast_conv(a).max()
                best_a = a.copy()
                no_improve = 0
            if no_improve > 100:
                break
        else:
            no_improve = 0
    
    return best_a, best_obj

import numpy as np

def fast_conv(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def active_set_subgradient(a, conv, eps_rel=0.005, temperature=0.01):
    """
    Compute subgradient of max(conv) using active set of peaks with
    exponential temperature weighting.
    Returns (gradient, objective_value, peak_count).
    """
    n = len(a)
    max_val = conv.max()
    if max_val < 1e-30:
        return np.zeros(n), 0.0, 0

    threshold = max_val * (1.0 - eps_rel)
    active = np.where(conv >= threshold)[0]

    peak_vals = conv[active]
    T = max_val * temperature
    weights = np.exp(-(max_val - peak_vals) / T)
    wsum = weights.sum()
    if wsum < 1e-30:
        weights = np.ones(len(active)) / len(active)
    else:
        weights = weights / wsum

    g = np.zeros(n)
    for idx in range(len(active)):
        w = weights[idx]
        if w < 1e-15:
            continue
        k = int(active[idx])
        js = np.arange(n)
        ks = k - js
        valid = (ks >= 0) & (ks < n)
        g[valid] += w * 2.0 * a[ks[valid]]

    return g, max_val, len(active)


def solve_lp_quick(f, M, time_limit_lp=5.0):
    """Solve LP: max sum(g) s.t. (f*g)[k] <= M for all k, g >= 0. Time-limited."""
    n = len(f)
    if n > 2500:
        return None

    t_start = time.monotonic()
    c = -np.ones(n)
    A_ub = np.zeros((2 * n - 1, n))
    for j in range(n):
        A_ub[j:j + n, j] = f
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n

    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': max(1, time_limit_lp)})
        if time.monotonic() - t_start > time_limit_lp * 2.0:
            return None
        if res.success:
            return np.maximum(res.x, 0.0)
    except Exception:
        pass
    return None


def subgradient_optimize(a0, time_limit, eps_rel=0.005, lr_init=0.01,

def mass_transfer_optimize(a0, time_limit, verbose=True):

        improved = False
        for k_peak in peaks:
            if time.monotonic() - t0 > time_limit - 0.1:
                break
            k_peak = int(k_peak)
            js = max(0, k_peak - n + 1)
            je = min(n - 1, k_peak)

            if len(affected) == 0:

            if len(outside) == 0:

            # Choose destination with minimum "harm" to other peaks

                if cs < 1e-15:
                    continue
                candidate = candidate / cs
                c = fast_conv(candidate).max()
                if c < best_obj - 1e-15:

                    best_obj = c

def cyclic_coordinate_descent(a0, time_limit, verbose=True):
    """
    Cyclic coordinate descent: for each coordinate, try several values
    and keep the best.
    """
    a = np.maximum(a0.astype(np.float64), 0.0)
    a = a / a.sum()
    n = len(a)

    best_a = a.copy()
    best_obj = fast_conv(a).max()

    t0 = time.monotonic()
    it = 0
    no_improve = 0

    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit - 0.05:
            break

        improved_any = False
        # Adaptive step size for cycling
        step = max(1, n // 300)

        start_offset = (it * step) % n
        for j in range(start_offset, start_offset + n, step):
            j = j % n
            if time.monotonic() - t0 > time_limit - 0.1:
                break

            vals = [a[j] * 0.7, a[j] * 1.3, a[j] - 0.0005, a[j] + 0.0005,
                    a[j] * 0.5, a[j] * 1.5, 0.0]
            best_val = a[j]
            best_c = best_obj

            for v in vals:
                if v < -1e-10:
                    v = 0.0
                trial = a.copy()
                trial[j] = max(0.0, v)
                ts = trial.sum()
                if ts < 1e-15:
                    continue
                trial = trial / ts
                c = fast_conv(trial).max()
                if c < best_c - 1e-15:
                    best_c = c
                    best_val = max(0.0, v)

            if best_val != a[j]:
                a[j] = best_val
                a = a / a.sum()
                best_obj = best_c
                best_a = a.copy()
                improved_any = True

        if not improved_any:
            no_improve += 1
            if no_improve > 30:
                rng = np.random.default_rng(it * 31 + 7)
                a = project_simplex(best_a + rng.standard_normal(n) * 0.001)
                best_obj = fast_conv(a).max()
                best_a = a.copy()
                no_improve = 0
            if no_improve > 150:
                break
        else:
            no_improve = 0

    return best_a, best_obj


def fourier_structured_init(n, parent, rng):
    """Generate a structured initialization based on parent + Fourier perturbation."""
    if parent is not None:
        a = np.interp(np.linspace(0, 1, n), np.linspace(0, 1, len(parent)), parent)
    else:
        a = np.ones(n) / n
    a = np.maximum(a, 0)
    s = a.sum()
    if s > 1e-10:
        a = a / s
    else:
        a = np.ones(n) / n

    # Add small Fourier perturbation
    x = np.arange(n, dtype=np.float64)
    M = min(8, n // 2)
    for m in range(1, M + 1):
        amp = rng.random() * 0.01
        phase = rng.random() * 2 * np.pi
        a += amp * np.cos(2.0 * np.pi * m * x / n + phase)

    a = np.maximum(a, 0)
    s = a.sum()
    if s > 1e-10:
        a = a / s
    return a

                                             eps_rel=0.005, lp_interval=100)
            try_update(a_opt2, "fourier_freq_{}".format(freq_scale))

    print("  Phase 2 best: {:.8f} (elapsed {:.0f}s)".format(state[0], time.monotonic() - t_phase))

    # === Phase 3: Local Refinement (~400s) ===
    print("\n=== Phase 3: Local Refinement ===")
    t_phase = time.monotonic()

    if state[1] is not None:
        # Mass transfer (long run)
        remaining = deadline - time.monotonic() - 250
        if remaining > 15:
            t_alloc = min(remaining, 200)
            print("  Mass transfer, t={:.0f}s".format(t_alloc))
            a_opt, _ = mass_transfer_optimize(state[1], time_limit=t_alloc)
            try_update(a_opt, state, "mass_transfer")

        # Coordinate descent
        remaining = deadline - time.monotonic() - 100
        if remaining > 15:
            t_alloc = min(remaining, 150)
            print("  Coord descent, t={:.0f}s".format(t_alloc))
            a_opt, _ = cyclic_coordinate_descent(state[1], time_limit=t_alloc)
            try_update(a_opt, state, "coord_desc")

        # Another mass transfer pass on the result
        if state[1] is not None:
            remaining = deadline - time.monotonic() - 60
            if remaining > 10:
                t_alloc = min(remaining, 40)
                a_opt2, _ = mass_transfer_optimize(state[1], time_limit=t_alloc)
                try_update(a_opt2, state, "mt_round2")

    print("  Phase 3 best: {:.8f} (elapsed {:.0f}s)".format(state[0], time.monotonic() - t_phase))

    # === Phase 4: Final Polish (~200s) ===
    print("\n=== Phase 4: Final Polish ===")
    t_phase = time.monotonic()

    if state[1] is not None:
        # Fine subgradient
        remaining = deadline - time.monotonic() - 60
        if remaining > 10:
            t_alloc = min(remaining, 80)
            print("  Fine subgrad, t={:.0f}s".format(t_alloc))
            a_opt, _ = subgradient_optimize(state[1], time_limit=t_alloc, lr_init=0.001,
                                            eps_rel=0.002, lp_interval=40,
                                            temperature=0.005)
            try_update(a_opt, state, "fine_sg")

        # Fine mass transfer
        remaining = deadline - time.monotonic() - 30
        if remaining > 5:
            t_alloc = min(remaining, 30)
            a_opt2, _ = mass_transfer_optimize(state[1], time_limit=t_alloc)
            try_update(a_opt2, state, "fine_mt")

        # Micro perturbations with quick optimization
        remaining = deadline - time.monotonic() - 15
        if remaining > 3:
            for i in range(8):
                remaining = deadline - time.monotonic() - 5
                if remaining < 2:
                    break
                noise = rng.standard_normal(len(state[1])) * 0.0005
                f_pert = project_simplex(state[1] + noise)
                a_opt3, _ = subgradient_optimize(f_pert, time_limit=min(remaining, 4),
                                                 lr_init=0.001, lp_interval=0)
                try_update(a_opt3, state, "micro_{}".format(i))

    print("  Phase 4 best: {:.8f} (elapsed {:.0f}s)".format(state[0], time.monotonic() - t_phase))

    # Fallback
    if state[1] is None:
        state[1] = np.ones(384) / 384
        state[0] = float(evaluate_sequence(state[1].tolist()))

    # Final verification and potential last-moment improvement
    fs = float(evaluate_sequence(state[1].tolist()))
    if np.isfinite(fs) and fs < state[0]:
        state[0] = fs

    # One last try: if we have time, do a quick coordinate descent
    remaining = deadline - time.monotonic()
    if remaining > 10 and state[1] is not None:
        a_final, _ = cyclic_coordinate_descent(state[1], time_limit=min(remaining, 15))
        try_update(a_final, state, "final_coord")

    print("\nFINAL SCORE: {:.8f} (n={})".format(state[0], len(state[1])))
    return [float(x) for x in state[1]]
