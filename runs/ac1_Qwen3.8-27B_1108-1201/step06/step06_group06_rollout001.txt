Actually, one more thought: the key insight I want to exploit is that **mirror descent with the negative entropy regularizer (i.e., the exponentiated gradient method) is particularly well-suited for non-negative variables**. The update is:
a_new[j] ∝ a[j] * exp(-η * g[j])

where g is the gradient. This automatically maintains non-negativity and can be much more efficient than projecting onto the simplex.

The step size η can be chosen via backtracking line search.

Combined with Nesterov momentum:
- Maintain a "lookahead" point y = a + μ(v) where v is the momentum
- Compute gradient at y
- Update: v = μ*v + (1-μ)*g(y) (or Adam-style adaptive)
- a_new ∝ a * exp(-η * (g(y) + momentum terms))

Let me code this up.

Actually, for the mirror descent, the proper update for minimizing f(a) subject to a ≥ 0, sum(a) = 1 is:
a_new = argmin_g { η*f(a) + D_Ω(a, a_old) }
where D_Ω is the Bregman divergence of the regularizer Ω(a) = Σ a[j]*log(a[j]) (negative entropy).

The solution is:
a_new[j] = a_old[j] * exp(-η * g[j]) / Z
where Z = Σ_j a_old[j] * exp(-η * g[j])

This is the "exponentiated gradient" or "multiplicative weights" update.

For the Nesterov variant, we compute the gradient at the "lookahead" point:
y = (1-β) * a + β * a_prev (or y = a + β*(a - a_prev))
g_y = ∇f(y)
a_new[j] = a[j] * exp(-η * g_y[j]) / Z

"""
Optimized step function search using mirror descent with Nesterov momentum,
SCA-LP hybrid, and adaptive temperature scheduling.
"""

import numpy as np
from scipy.optimize import linprog

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    """Euclidean projection onto probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def compute_grad(a, p):
    """Compute gradient of sum_k p[k]*(a*a)[k] w.r.t. a using FFT.
    grad[j] = 2 * sum_m a[m] * p[j+m]
    """
    n = len(a)
    fft_size = 1 << (3 * n - 1).bit_length()
    A = np.fft.rfft(a[::-1].copy(), fft_size)
    P = np.fft.rfft(p, fft_size)
    conv = np.fft.irfft(A * P, fft_size)
    return 2.0 * conv[n-1:2*n-1]

    """Compute softmax weights for the autocorrelation peaks."""
    scaled = conv / T
    scaled -= scaled.max()
    w = np.exp(scaled)
    s = w.sum()
    if s < 1e-300:
        return np.ones(len(conv)) / len(conv)
    return w / s

        p = softmax_weights(conv_y, T)
        g = compute_grad(y, p)

    # 
    # For autocorrelation of real sequences: (a*a')[k] = (a'*a)[k] (they're the same)
    # Proof: (a*a')[k] = sum_i a[i]*a'[i+k], (a'*a)[k] = sum_i a'[i]*a[i+k]
    # Let j = i+k in the first: sum_j a[j-k]*a'[j] = sum_j a'[j]*a[j-k]
    # This equals (a'*a)[-k]... not (a'*a)[k].
    # Actually (a'*a)[k] = sum_i a'[i]*a[i+k]
    # And (a*a')[k] = sum_i a[i]*a'[i+k]
    # These are NOT the same in general! (a*a')[k] = (a'*a)[-k]
    # But since we're dealing with the full convolution (k goes from 0 to 2n-2), and
    # the autocorrelation is symmetric: (a*a)[k] = (a*a)[2n-2-k],
    # we have (a*a')[k] + (a*a')[2n-2-k] = ... this is getting complicated.
    # 
    # Let me just use the formula: linearized constraint for (a'*a')[k] is:
    # 2 * (a*a')[k] - (a*a)[k] <= t
    # where (a*a')[k] = sum_{i=0}^{n-1-k} a[i]*a'[i+k] (for k >= 0)
    # 
    # This is the standard "linearization of a quadratic" trick.

    conv_a = fast_convolve(a)
    # For each k, the constraint is: 2 * sum_i a[i]*a'[i+k] - conv_a[k] <= t
    # The coefficient of a'[j] in constraint k is: 2 * (a[j-k] if j>=k else 0) ... 
    # sum_i a[i]*a'[i+k]: the coefficient of a'[j] is a[j-k] (when i = j-k, so i+k = j)
    # So the coefficient is a[j-k] for j >= k, 0 for j < k.
    
    # Build the constraint matrix: A[k, j] = 2*a[max(0, j-k)] if j >= k else 0
    # Wait, for the full convolution (k from 0 to 2n-2):
    # (a*a')[k] = sum_i a[i]*a'[i+k] where both indices are in [0, n-1]
    # For k >= 0: i ranges from 0 to n-1-k, so a'[i+k] has index from k to n-1
    #   coefficient of a'[j] (where j = i+k, so i = j-k): a[j-k] if 0 <= j-k <= n-1-k, i.e., k <= j <= n-1
    # For k < 0 (i.e., we'd use the symmetry): (a*a')[k] = (a'*a)[-k]
    #   But in our formulation, k goes from 0 to 2n-2 (full linear convolution)
    #   (a*a')[k] for k in [0, 2n-2] = sum_i a[i]*a'[i+k] with bounds
    #   For k >= n: i+k >= n for all i >= 0, so (a*a')[k] = 0
    #   So we only need k from 0 to n-1 (since for k >= n, the constraint is trivially satisfied)
    #   Wait, that's not right. The linear convolution of two length-n sequences has length 2n-1.
    #   (a*a')[k] = sum_{i: 0<=i<n, 0<=i+k<n} a[i]*a'[i+k]
    #   For k = 0: sum_i a[i]*a'[i] (n terms)
    #   For k = 1: sum_{i=0}^{n-2} a[i]*a'[i+1] (n-1 terms)
    #   ...
    #   For k = n-1: a[0]*a'[n-1] (1 term)
    #   For k = n: 0 (no valid i)
    #   For k > n: 0
    #   
    # But wait, the convolution (a*a') has length 2n-1, with:
    # (a*a')[k] = sum_i a[i]*a'[k-i] for i = max(0,k-n+1) to min(k, n-1)
    # This is the standard convolution formula.
    # For k = 0: a[0]*a'[0]
    # For k = 1: a[0]*a'[1] + a[1]*a'[0]
    # ...
    # For k = n-1: sum_{i=0}^{n-1} a[i]*a'[n-1-i]
    # For k = n: a[1]*a'[n-1] + ... + a[n-1]*a'[0]
    # For k = 2n-2: a[n-1]*a'[n-1]
    
    # So (a*a')[k] involves a'[k-i] for various i. The coefficient of a'[j] is a[k-j] (when 0 <= k-j <= n-1).
    
    # This is a Toeplitz-like matrix. Let me build it.
    
    # Actually, for the SCA approach, I realize the LP is:
    # min t
    # s.t. 2*(a*a')[k] - (a*a)[k] <= t, k = 0, ..., 2n-2
    #      a' >= 0
    #      sum(a') = 1
    #
    # The constraint matrix has rows for each k and columns for each a'[j].
    # Entry (k,j) = 2*a[k-j] if 0 <= k-j <= n-1, else 0. (minus the (a*a)[k] on the RHS)
    # b[k] = t + (a*a)[k]
    
    # This is a linear program with 2n-1 + 1 = 2n variables (2n-1 for a' and 1 for t)
    # and 2n-1 inequality constraints + 1 equality + n non-negativity.
    
    # For n=768, that's 1537 variables and 1536+1 = 1537 constraints. Should be solvable.
    
    # Let me build the constraint matrix.
    # Row k: [2*a[k-j] for j=0,...,n-1, -1] <= (a*a)[k]
    # (the -1 is for the variable t: we want 2*(a*a')[k] - t <= (a*a)[k], i.e., 2*(a*a')[k] - t - (a*a)[k] <= 0)
    # Wait, let me reformulate: 2*(a*a')[k] - (a*a)[k] <= t
    # => 2*(a*a')[k] - t <= (a*a)[k]
    # So row k: [2*a[k-j] for j] , -1] dot [a'; t] <= (a*a)[k]
    
    # Plus: sum(a') = 1 => [1,...,1, 0] dot [a'; t] = 1
    # Plus: a'[j] >= 0
    
    # Objective: minimize t => c = [0,...,0, 1]
    
    m = 2 * n - 1  # number of rows
    # Build A_ub (m x (n+1))
    A_ub_vals = []
    A_ub_rows = []
    A_ub_cols = []
    
    for k in range(m):
        for j in range(n):
            idx = k - j
            if 0 <= idx < n:
                A_ub_vals.append(2.0 * a[idx])
                A_ub_rows.append(k)
                A_ub_cols.append(j)
        # Coefficient of t
        A_ub_vals.append(-1.0)
        A_ub_rows.append(k)
        A_ub_cols.append(n)
    
    A_ub = lil_matrix((m, n + 1))
    A_ub[A_ub_rows, A_ub_cols] = A_ub_vals
    A_ub = A_ub.tocsr()
    
    b_ub = conv_a.copy()
    
    # Equality: sum(a') = 1
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([1.0])
    
    c = np.zeros(n + 1)
    c[n] = 1.0  # minimize t
    
    bounds = [(0, None)] * n + [(None, None)]  # a' >= 0, t free
    
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs', options={'presolve': True})
        if res.success:
            a_new = np.maximum(res.x[:n], 0.0)
            s = a_new.sum()
            if s > 1e-15:
                a_new = a_new / s
                return a_new
    except Exception:
        pass
    return None

def sca_optimize(a0, time_limit):
    """SCA optimization: iterate LP solves with line search."""
    a = np.maximum(a0.astype(np.float64), 0.0)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit - 1.0:
            break
        
        a_dir = sca_lp_step(a, n, best_obj)
        if a_dir is None:
            no_improve += 1
            if no_improve > 20:
                break
            continue
        
        # Line search between a and a_dir
        best_alpha = 0.0
        best_alpha_obj = best_obj
        for alpha in [0.1, 0.2, 0.3, 0.5, 0.7, 0.9, 1.0]:
            candidate = (1 - alpha) * a + alpha * a_dir
            candidate = np.maximum(candidate, 0)
            cs = candidate.sum()
            if cs < 1e-15:
                continue
            candidate = candidate / cs
            obj = fast_convolve(candidate).max()
            if obj < best_alpha_obj:
                best_alpha_obj = obj
                best_alpha = alpha
        
        if best_alpha > 0:
            a = (1 - best_alpha) * a + best_alpha * a_dir
            a = np.maximum(a, 0)
            a = a / a.sum()
            obj = fast_convolve(a).max()
            if obj < best_obj:
                best_obj = obj
                best_a = a.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1
            if no_improve > 30:
                # Restart with perturbation
                rng = np.random.default_rng((it * 7919 + 13) % (2**31 - 1))
                a = project_simplex(best_a + rng.standard_normal(n) * 0.005)
                no_improve = 0
    
    return best_a, best_obj

def try_seq(a, label, best_ref):
    """Evaluate and update best."""
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        return best_ref
    a_norm = a / s
    score = float(evaluate_sequence(a_norm.tolist()))
    if np.isfinite(score) and score < best_ref[1]:
        print(f"  NEW BEST [{label}]: {score:.8f} (n={len(a)})")
        return (a_norm.copy(), score)
    return best_ref
