Wait, I realize there might be an issue with the cross-correlation computation. Let me verify the FFT formula.

We want: cross[i] = sum_{j=0}^{n-1} a[j] * w[i+j] for i = 0, 1, ..., n-1

This is the cross-correlation of w and a at lag i: (w ⋆ a)[i]

The cross-correlation theorem (for the convention (f ⋆ g)[n] = sum_m f[m+n] * conj(g[m])):
DFT{(f ⋆ g)[n]} = DFT{f} * conj(DFT{g})

So: cross = IFFT(W * conj(A)) where W = DFT(w padded), A = DFT(a padded)

In numpy with real FFT:
W = rfft(w_padded) gives the positive frequency components
A = rfft(a_padded)
cross = irfft(W * conj(A))

Let me verify this is correct. For real sequences:
DFT{f ⋆ g} = F * conj(G) where F = DFT(f), G = DFT(g)

Using rfft/irfft (which work on the full DFT implicitly):
irfft(rfft(w) * conj(rfft(a))) should give the cross-correlation (w ⋆ a)

Wait, but conj(rfft(a)) is not the same as rfft(conj(a)) for the one-sided spectrum. Let me be more careful.

For real sequences, the full DFT satisfies G[k] = conj(G[N-k]). The rfft gives G[0], G[1], ..., G[N/2].

The product W * conj(A) in the full DFT domain:
P[k] = W[k] * conj(A[k]) for k = 0, ..., N-1

P is also Hermitian (since both W and A are Hermitian, and the product of a Hermitian and the conj of another Hermitian is Hermitian):
P[k] = W[k] * conj(A[k])
P[N-k] = W[N-k] * conj(A[N-k]) = conj(W[k]) * A[k] = conj(P[k]) ✓

So we can use rfft/irfft correctly.

cross_full = irfft(rfft(w_padded) * conj(rfft(a_padded)))

And cross[i] = cross_full[i] for i = 0, ..., n-1.
