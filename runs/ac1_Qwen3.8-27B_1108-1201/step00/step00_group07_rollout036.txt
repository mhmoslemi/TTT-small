import numpy as np
import time

def normalize_to_sum(f, target):
    s = np.sum(f)
    if s < 1e-15:
        return np.full_like(f, target / len(f))
    return f * (target / s)

def subgradient_of_peak(f, peak_indices):
    """Compute subgradient of max_{k in peak_indices} (f*f)_k w.r.t. f."""
    n = len(f)
    grad = np.zeros(n)
    for k in peak_indices:
        # (f*f)_k = sum_j f_j * f_{k-j}
        # d/d f_j: f_{k-j} (if 0<=k-j<n) + f_{j-k} (if 0<=j-k<n)
        # First term: j from max(0,k-n+1) to min(n-1,k), add f[k-j]
        lo1 = max(0, k - n + 1)
        hi1 = min(n - 1, k)
        if lo1 <= hi1:
            js = np.arange(lo1, hi1 + 1)
            grad[js] += f[k - js]
        # Second term: j from max(0,k) to min(n-1,k+n-1), add f[j-k]
        lo2 = max(0, k)
        hi2 = min(n - 1, k + n - 1)
        if lo2 <= hi2:
            js = np.arange(lo2, hi2 + 1)
            grad[js] += f[js - k]
    return grad

Hmm, let me just parameterize by r and find the optimal r.

Let s = r (I'll use s for the ratio).
f_j = c * s^j.
(f*f)_{n-1} = c^2 * s^{n-1} * n.
sum = c * (s^n - 1)/(s-1).

Objective = 2n * c^2 * s^{n-1} * n / (c^2 * (s^n-1)^2/(s-1)^2)
= 2n^2 * s^{n-1} * (s-1)^2 / (s^n - 1)^2

For large n, if s > 1: s^n dominates, so (s^n-1)^2 ≈ s^{2n}.
Objective ≈ 2n^2 * s^{n-1} * (s-1)^2 / s^{2n} = 2n^2 * (s-1)^2 / s^{n+1}.

To minimize this over s > 1: take log and differentiate.
log(objective) ≈ log(2n^2) + 2*log(s-1) - (n+1)*log(s).
d/ds: 2/(s-1) - (n+1)/s = 0.
2s = (n+1)(s-1) = (n+1)s - (n+1).
(n+1) = (n+1-2)s = (n-1)s.
s = (n+1)/(n-1) ≈ 1 + 2/n.

So the optimal ratio is s ≈ 1 + 2/n (for large n).

With s = 1 + 2/n:
s - 1 = 2/n.
s^{n+1} = (1+2/n)^{n+1} ≈ e^2 (for large n).
Objective ≈ 2n^2 * (2/n)^2 / e^2 = 2n^2 * 4/(n^2 * e^2) = 8/e^2 ≈ 8/7.389 ≈ 1.083.

Wow! So with the geometric ratio s = 1 + 2/n, the objective is about 1.083!
