So: $\nabla F(f)_i = \frac{2 \sum_k p_k f_{k-i}}{\sum_k p_k} - \frac{2}{S}$

This can be computed efficiently using convolution:
Let $w_k = p_k / \sum_k p_k$ (softmax weights, summing to 1 over $k = 0, \ldots, 2n-2$).
Then $\sum_k w_k f_{k-i}$ is a "cross-correlation" of $w$ and $f$, which can be computed via FFT.

So the algorithm is:
1. Compute $c = f * f$ (via FFT).
2. Compute $w_k = \text{softmax}(T \cdot c_k)$.
3. Compute $h = w * f$ (cross-correlation via FFT): $h_i = \sum_k w_k f_{k-i}$.
4. Gradient: $g_i = 2 h_i - 2/S$.
5. Update: $f_i \leftarrow \max(0, f_i - \eta g_i)$, then project onto $\sum f = 1$.

This is efficient! Each iteration is $O(n \log n)$ due to the FFTs.

For $n = 4806$, each iteration takes maybe 1-2 ms. In 1800 seconds, we can do millions of iterations.
