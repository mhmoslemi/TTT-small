conv((1-t)*a + t*b, (1-t)*a + t*b) = (1-t)^2 conv(a,a) + 2t(1-t) conv(a,b) + t^2 conv(b,b)

So each convolution value is a quadratic in t: c_k(t) = (1-t)^2 * A_k + 2t(1-t) * B_k + t^2 * C_k
where A_k = conv(a,a)[k], B_k = conv(a,b)[k], C_k = conv(b,b)[k].

We want to minimize max_k c_k(t) over t in [0, 1]. This is a 1D problem that we can solve by:
- Evaluating at t = 0, 1, and at points where c_k(t1) = c_k(t2) for the "active" pairs.
- Or just doing a fine grid + refinement.

For efficiency, I'll do a coarse grid (say 20 points) + golden section refinement.

2. **Multiple LP directions**: Instead of just one LP, solve multiple LPs with different M values (tightly around the current max) and combine the directions.

3. **Symmetry exploitation**: The objective is invariant under reversal (a -> reversed(a)). We can exploit this to reduce the search space or to generate additional directions.

4. **Averaging with reversed**: Combine a with its reverse: a_sym = (a + reverse(a))/2. This might help because it ensures the sequence is symmetric, which could be beneficial.

def fast_convolve(a):
