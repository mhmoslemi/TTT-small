This LP approach is very elegant and likely to work well. Let me implement it.

The LP is:
Maximize: sum_j g_j
Subject to: sum_i f_i * g_{j-i} <= M for all j = 0, ..., 2n-2

This is a linear program with 2n-1 constraints and n variables. For n=128, that's 255 constraints and 128 variables - very manageable.

After solving, we get g*. Rescale: g = sqrt(2n) / sum(g*) * g*.
Then blend: f_new = (1-t)*f + t*g.
The key property: since f*g <= M componentwise, the new f_new * f_new will have smaller peaks (this needs proof but is the intuition).

Actually, let me verify the property. If f*g <= M and f*f <= M (componentwise), then:
f_new * f_new = (1-t)^2 f*f + 2t(1-t) f*g + t^2 g*g

We know f*f <= M and f*g <= M. But we don't know about g*g. If g*g also <= M, then f_new*f_new <= M. But g*g might exceed M.

import time

def fast_convolve(a, b=None):
    if b is None:
        b = a
    n = len(a)
    m = len(b)
    size = n + m - 1

    A = np.fft.rfft(a, fft_size)
    B = np.fft.rfft(b, fft_size)
    result = np.fft.irfft(A * B, fft_size)
    return result[:size]

def compute_objective(a):
    n = len(a)
    S = a.sum()
    if S < 1e-10:
        return float('inf')
    conv = fast_convolve(a)
    return 2.0 * n * conv.max() / (S * S)

def solve_lp_for_g(f, M):
    """
    Solve: maximize sum(g) subject to f*g <= M (componentwise), g >= 0.
    f has length n, g has length n.
    f*g has length 2n-1.
    """
    n = len(f)
    
    # Constraint: (f * g)[k] <= M for k = 0, ..., 2n-2
    # (f*g)[k] = sum_i f[i] * g[k-i] (valid indices)
    # This is a linear constraint in g.
    
    # Build constraint matrix A_ub such that A_ub @ g <= M
    # A_ub has shape (2n-1, n)
    # A_ub[k, j] = f[j] if 0 <= k-j < n, else 0
    # i.e., A_ub[k, j] = f[k-j] if 0 <= k-j < n, else 0
    
    A_ub = np.zeros((2*n-1, n))
    for k in range(2*n-1):
        for j in range(n):
            idx = k - j
            if 0 <= idx < n:
                A_ub[k, j] = f[idx]
    
    # Maximize sum(g) => minimize -sum(g)
    c = -np.ones(n)
    b_ub = np.full(2*n-1, M)
    
    # Bounds: g >= 0
    bounds = [(0, None)] * n
    
    result = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    
    if result.success:
        return result.x
    else:
        return None

def lp_iteration(f, t_param=0.3):
    """
    One LP-based iteration.
    f should be non-negative.
    Returns new f.
    """
    n = len(f)
    # Normalize
    S = f.sum()
    if S < 1e-10:
        return f
    f_norm = f / S  # sum = 1
    
    M = fast_convolve(f_norm).max()
    
    g = solve_lp_for_g(f_norm, M)
    if g is None:
        return f
    
    # Rescale g to sum = 1
    g_sum = g.sum()
    if g_sum < 1e-10:
        return f
    g = g / g_sum
    
    # Blend
    f_new = (1 - t_param) * f_norm + t_param * g
    f_new = np.maximum(f_new, 0)
    
    return f_new
