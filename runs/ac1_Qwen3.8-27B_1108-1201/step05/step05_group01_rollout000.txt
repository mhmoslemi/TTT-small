`C[k] = A[k]^2` where `A = DFT_N(a)` and `C = DFT_N(c)`.

So `c = IDFT_N(C) = IDFT_N(A^2)`.

We want `c` to be flat (all values approximately equal to `1/(2n-1)` since `sum(c) = (sum(a))^2 = 1`).

For `c` to be approximately flat, `C` must be approximately a delta at `k=0` (DC). That is, `C[0] ≈ 1` and `C[k] ≈ 0` for `k ≠ 0`.

But `C[0] = A[0]^2 = (sum a)^2 = 1`. And `C[k] = A[k]^2` for `k ≠ 0`.

So we want `A[k]^2 ≈ 0` for `k ≠ 0`, which means `A[k] ≈ 0` for `k ≠ 0`. This means `a` is approximately constant (uniform). But that gives a triangular conv, not a flat one!

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1

    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    """Euclidean projection onto the probability simplex."""
    n = len(v)
    if n == 1:
        sv = v[0] if v[0] > 0 else 1e-15
        return np.array([sv / sv])
    u = np.sort(v)[::-1]

    rho = np.arange(1, n + 1)

    if not cond.any():
        return np.ones(n) / n
    idx = np.nonzero(cond)[0][-1]
    theta = (cssv[idx] - 1.0) / (idx + 1.0)
