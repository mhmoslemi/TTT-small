One idea: **Direct bisection on M with a feasibility check**.

The problem: find a >= 0, sum(a) = 1, such that max_k conv_k <= M.

This is a non-convex feasibility problem. But we can try:

The primal is: min max_k a^T H_k a s.t. a >= 0, sum(a) = 1.

By min-max theorem (Sion's theorem), this equals:
min_{a in simplex} max_{p in simplex} sum_k p_k * a^T H_k a

The inner max is over a probability distribution p on the lags. For a fixed p, the inner problem is:

This is a Hankel matrix. For it to be PSD, we need the sequence (p_0, p_1, ..., p_{2n-2}) to be a "moment sequence" of some measure. A sufficient condition is p_k >= 0 for all k, but that's not sufficient in general for Hankel matrices.

**Approach: Iterative peak reduction with二次 interpolation**

1. Start with the parent sequence.
2. In each iteration:
   a. Compute the autocorrelation and find all peaks above a threshold.
   b. For each peak, compute the "contribution" of each pair (i, j) with i+j = k.
   c. Find the pair that contributes most to the peak.
   d. Reduce one of the pair's values and increase a "safe" position (one that doesn't contribute to any high peak).
3. Use quadratic interpolation to determine the optimal step size.

This is similar to coordinate descent but with a focus on the peak structure.

Let me think about implementation details:

For step (c): The peak at position k has value conv[k] = sum_j a[j]*a[k-j]. The contribution of the pair (j, k-j) is a[j]*a[k-j] (times 2 if j != k-j, times 1 if j = k-j).

To reduce conv[k], we want to decrease a[j]*a[k-j] for the largest contributors.

For step (d): A "safe" position m is one where a[m] is small AND m doesn't appear in any high-peak convolution. Specifically, m is safe if for all peaks k with conv[k] > threshold, either m > k or k-m is out of range.

def project_simplex(v):
    """Euclidean projection onto the probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])

def logsoftmax(a):

    m = a.max()
    return m + np.log(np.sum(np.exp(a - m)))

    # Second term: only k-j=i, i.e., j=k-i: a[k-i] (if 0 <= k-i < n)

def smooth_optimize_log(a0, time_limit, T_init=0.001, lr_init=0.02):

def antisymmetric_init(n, rng):
    """
    Create an initial sequence with antisymmetric structure around the center.
    a[j] + a[n-1-j] = constant (approximately)

    """
    half = n // 2
    x = np.arange(half, dtype=np.float64)
    # Create a profile that's high at edges, low in middle
    profile = np.exp(-0.5 * (x / (0.3 * half))**2)
    # Add asymmetry
    asym = rng.standard_normal(half) * 0.05
    profile = profile + asym
    profile = np.maximum(profile, 0.01)
    
    if n % 2 == 0:
        a = np.zeros(n)
        a[:half] = profile
        a[half:] = profile[::-1]
    else:
        a = np.zeros(n)
        a[:half] = profile
        a[half+1:] = profile[::-1]
        a[half] = profile.mean()
    
    a = np.maximum(a, 0)
    a = a / a.sum()
    return a
