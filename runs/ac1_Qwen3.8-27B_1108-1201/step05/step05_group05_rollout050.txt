Actually, let me reconsider the problem. The objective is:

After normalizing sum(p) = 1, this becomes 2*n*max(conv(p,p)).

The coordinate descent approach:
- For coordinate j, with current value p[j] = a:

Let me derive the quadratic coefficients more carefully.

Let n = len(p), a = p[j], D = 1 - a.

For a given k (0 <= k <= 2n-2):
The set of valid indices is S_k = [max(0, k-n+1), min(n-1, k)].

conv[k] = sum_{i in S_k} p[i] * p[k-i]

When we set p'[j] = t and p'[i] = p[i]*s for i ≠ j, where s = (1-t)/D:

conv'[k] = sum_{i in S_k} p'[i] * p'[k-i]

Let me separate the terms:
- If j in S_k and k-j in S_k:
  - The term i=j: p'[j]*p'[k-j] = t * p[k-j]*s (if k-j ≠ j) or t^2 (if k-j = j)
  - The term i=k-j: p'[k-j]*p'[j] = p[k-j]*s * t (if k-j ≠ j) or t^2 (if k-j = j)
  - Other terms: p[i]*s * p[k-i]*s = p[i]*p[k-i]*s^2

So:
- If k = 2j (j is the center):
  conv'[k] = t^2 + s^2 * (conv[k] - a^2)
  
- If j in S_k but k-j ≠ j:
  conv'[k] = 2*t*p[k-j]*s + s^2 * (conv[k] - 2*a*p[k-j])
  (where conv[k] - 2*a*p[k-j] is the sum of terms not involving p[j])

- If j not in S_k:
  conv'[k] = s^2 * conv[k]

Now, s = (1-t)/D, so:

Case k = 2j:
conv'[k] = t^2 + ((1-t)/D)^2 * (conv[k] - a^2)
= t^2 + (1-2t+t^2)(conv[k]-a^2)/D^2
= [t^2*D^2 + (1-2t+t^2)(conv[k]-a^2)] / D^2
= [t^2*D^2 + (conv[k]-a^2) - 2t*(conv[k]-a^2) + t^2*(conv[k]-a^2)] / D^2
= [t^2*(D^2 + conv[k]-a^2) - 2t*(conv[k]-a^2) + (conv[k]-a^2)] / D^2

Let R = conv[k] - a^2. Then:
conv'[k] = [(D^2 + R)*t^2 - 2R*t + R] / D^2

D^2 + R = (1-a)^2 + conv[k] - a^2 = 1 - 2a + a^2 + conv[k] - a^2 = 1 - 2a + conv[k]

So: conv'[k] = [(1-2a+conv[k])*t^2 - 2(conv[k]-a^2)*t + (conv[k]-a^2)] / (1-a)^2

Case j in S_k, k ≠ 2j:
Let B = p[k-j], R = conv[k] - 2*a*B
conv'[k] = 2*t*B*(1-t)/D + R*(1-t)^2/D^2
= [2*t*B*(1-t)*D + R*(1-2t+t^2)] / D^2
= [2*B*D*t - 2*B*D*t^2 + R - 2*R*t + R*t^2] / D^2
= [(R - 2*B*D)*t^2 + (2*B*D - 2*R)*t + R] / D^2

D = 1-a, so:
conv'[k] = [(R - 2*B*(1-a))*t^2 + (2*B*(1-a) - 2*R)*t + R] / (1-a)^2

Case j not in S_k:
conv'[k] = conv[k]*(1-t)^2/(1-a)^2 = [conv[k]*t^2 - 2*conv[k]*t + conv[k]]/(1-a)^2

Great, so in all cases, conv'[k](t) = (A_k*t^2 + B_k*t + C_k) / (1-a)^2

where the coefficients depend on k, j, and the current p.

Now, to find t* = argmin max_k conv'[k](t), we can:
1. For a candidate M, check if there exists t in [0, 1) such that A_k*t^2 + B_k*t + C_k <= M*(1-a)^2 for all k.
2. This is a system of quadratic inequalities in 1D. Each gives an interval (or empty set) of feasible t.
3. The intersection of all intervals must be non-empty.
4. Binary search on M to find the minimum.

For each quadratic A*t^2 + B*t + C <= M*D2 (where D2 = (1-a)^2):
A*t^2 + B*t + (C - M*D2) <= 0

If A > 0: the solution is between the two roots.
If A = 0: linear inequality.
If A < 0: the solution is outside the roots (or all t if discriminant < 0).

We can compute the intersection of all feasible intervals.

This is O(n) per feasibility check, and we need O(log(precision)) checks for bisection. Total: O(n * log(precision)) per coordinate.

For n = 768, this is very fast. We can do many sweeps.

    # Search in [t_samples[max(0,best_idx-3)], t_samples[min(len-1, best_idx+3)]]
    lo = t_samples[max(0, best_idx - 3)]
    hi = t_samples[min(len(t_samples)-1, best_idx + 3)]
    
    phi = (np.sqrt(5.0) - 1.0) / 2.0
    for _ in range(50):
        c = hi - phi * (hi - lo)
        d = lo + phi * (hi - lo)
        vc = (A * c*c + B * c + C).max() / D2
        vd = (A * d*d + B * d + C).max() / D2
        if vc < vd:
            hi = d
        else:
            lo = c
    
    t_opt = (lo + hi) / 2.0
    t_opt = max(0.0, min(t_opt, 1.0 - 1e-10))
    
    return t_opt

Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using fast exact coordinate descent
with quadratic coefficient precomputation, multiple diverse initializations,
frequency-domain seeding, and subgradient polishing.
"""

import numpy as np
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not np.any(cond):
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def flat_spectrum_init(n, seed=0):
    """Initialize with approximately flat power spectrum."""
    rng = np.random.default_rng(seed)
    fft_size = 1 << (2 * n - 1 - 1).bit_length()
    half = fft_size // 2 + 1
    phases = rng.uniform(0, 2 * np.pi, half)
    spectrum = np.exp(1j * phases)
    spectrum[0] = 1.0  # DC component real and positive
    if fft_size % 2 == 0:
        spectrum[-1] = 1.0  # Nyquist real
    sig = np.fft.irfft(spectrum, fft_size)
    sig = sig[:n]
    sig = np.maximum(sig, 0)
    ss = sig.sum()
    if ss < 1e-10:
        sig = np.abs(sig[:n])
        ss = sig.sum()
    if ss > 1e-10:
        sig /= ss
    else:
        sig = np.ones(n) / n
    return sig


def cosine_taper_init(n):
    """Cosine-tapered initialization."""
    x = np.linspace(0, np.pi, n)
    sig = np.sin(x) ** 2  # = (1-cos(2x))/2, non-negative
    sig = np.maximum(sig, 0)
    ss = sig.sum()
    if ss > 1e-10:
        sig /= ss
    return sig


def gaussian_taper_init(n):
    """Gaussian-tapered initialization."""
    center = (n - 1) / 2.0
    sigma = n / 4.0
    x = np.arange(n)
    sig = np.exp(-0.5 * ((x - center) / sigma) ** 2)
    sig = np.maximum(sig, 1e-10)
    sig /= sig.sum()
    return sig


def interpolate_seq(f, new_n):
    """Interpolate a sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp /= ss
    else:
        f_interp = np.ones(new_n) / new_n
    return f_interp

def sg_polish(f0, time_limit, lr=0.001, mom=0.93, top_k=50, temp=0.00003):

    v = np.zeros(n)
    conv = fast_convolve(f)

    t0 = time.monotonic()
    no_improve = 0
    cur_lr = lr
    cur_temp = temp
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        k_act = min(top_k, len(conv))
        peaks = np.argpartition(conv, -k_act)[-k_act:]
        
        pv = conv[peaks]
        scaled = pv / cur_temp
        scaled -= scaled.max()
        w = np.exp(scaled)
        ws = w.sum()
        if ws < 1e-15:
            w = np.zeros(len(peaks))
            w[np.argmax(pv)] = 1.0
        else:
            w /= ws
        
        sg = np.zeros(n)
        for i in range(len(peaks)):
            if w[i] < 1e-13:

            k = int(peaks[i])
            js = max(0, k - n + 1)
