`g'(x) = 2*r*r' * bg[k] + (r'*x + r) * cross[k] + 2*x*diag[k]`

where `r' = dr/dx = -1/s`.

`g'(x) = 2*r*(-1/s)*bg[k] + ((-1/s)*x + r)*cross[k] + 2*x*diag[k]`
`= -2*r*bg[k]/s + (-x/s + (1-x)/s)*cross[k] + 2*x*diag[k]`
`= -2*r*bg[k]/s + (1-2x)/s * cross[k] + 2*x*diag[k]`

Yes, that matches what I had. Good.

But wait, there's a subtlety: we're minimizing `max_k g_k(x)`, and the derivative of the max is the derivative of the active constraint. But if the active constraint changes as x varies (i.e., a different k becomes the max), the function is not differentiable at that point. The bisection method still works if the function is convex, but as we showed, it might not be.

A safer approach: instead of bisection, use a **discrete search** followed by refinement:
1. Evaluate g(x) at 20 equally spaced points in [0, 1]
2. Find the best point
3. Do 15 more evaluations in a small interval around the best
4. Use the result as the new x

This is O(35 * n) per coordinate, which for n=768 is about 27K operations per coordinate, or 21M per pass. With the overhead of Python, this might take about 1-2 seconds per pass. So in 1800 seconds, we can do 900-1800 passes. That's a lot!

But wait, we also need to recompute the full convolution after each coordinate update (to keep `conv` up to date). That's O(n log n) per coordinate, so O(n^2 log n) per pass. For n=768, that's about 5.9M * 10 = 59M operations per pass, or about 0.5-1 second. So we can do 1800-3600 passes.

After changing a[j] from x_old to x_new:

where bg, cross, diag are as computed above.

```python
    a = a_init.copy().astype(np.float64)

    if s < 1e-15:

    conv = np.convolve(a, a)  # O(n^2) or O(n log n) with FFT
    best_obj = conv.max()
    best_a = a.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    rng = np.random.default_rng(42)
    
    while time.monotonic() - t0 < time_limit:
        pass_improved = False
        max_improvement = 0.0
        
        for j in range(n):
            if time.monotonic() - t0 > time_limit:
                break

            if x_old < 1e-14:

            s_others = 1.0 - x_old
            if s_others < 1e-12:
                continue
            
            # Precompute bg, cross, diag for coordinate j
            bg = conv - compute_contrib(conv, a, j)  # O(n)
            cross, diag = compute_cross_diag(a, j)  # O(n)

            best_x = x_old
            best_val = best_obj
            for x in xs:
                r = (1.0 - x) / s_others
                val = (r*r*bg + r*x*cross + x*x*diag).max()
                if val < best_val:
                    best_val = val
                    best_x = x
            
            # Fine: 15 points around best
            span = 0.05
            xs2 = np.linspace(max(0, best_x - span), min(1, best_x + span), 15)
            for x in xs2:
                r = (1.0 - x) / s_others
                val = (r*r*bg + r*x*cross + x*x*diag).max()
                if val < best_val:
                    best_val = val
                    best_x = x
            
            x_new = best_x
            if abs(x_new - x_old) < 1e-10:
                continue
            
            # Apply update
            r = (1.0 - x_new) / s_others
            a[j] = x_new
            mask = np.ones(n, dtype=bool)
            mask[j] = False
            a[mask] *= r
            a = np.maximum(a, 0.0)
            ss = a.sum()
            if ss > 1e-15:
                a /= ss
            
            # Update conv incrementally
            conv = r*r*bg + r*x_new*cross + x_new*x_new*diag
            
            obj = conv.max()
            improvement = best_obj - obj
            if improvement > max_improvement:
                max_improvement = improvement
            
            if obj < best_obj - 1e-12:
                best_obj = obj
                best_a = a.copy()
                pass_improved = True

                no_improve = 0
            elif no_improve > 5:
                break
        else:
            no_improve = 0
    
    return best_a, best_obj
```

```python
def compute_contrib(conv, a, j):
    """Compute the contribution of a[j] to conv."""
    n = len(a)
    contrib = np.zeros(2*n-1)
    x = a[j]
    # k = 2j: x^2
    if 2*j < 2*n-1:
        contrib[2*j] += x*x
    # k != 2j, 0 <= k-j < n: 2*x*a[k-j]
    # k ranges from j to j+n-1, but k != 2j
    k_min = max(0, j)
    k_max = min(2*n-2, j+n-1)
    for k in range(k_min, k_max+1):
        if k == 2*j:
            continue
        kj = k - j
        if 0 <= kj < n:
            contrib[k] += 2*x*a[kj]
    return contrib
```
