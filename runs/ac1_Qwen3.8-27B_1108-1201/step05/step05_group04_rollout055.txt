**Key optimization for coordinate descent:**

When we change `a[i]` from `old` to `new` (delta = new - old):

If we change a[i] to a[i]+delta:
- For conv[k]: the terms involving index i are:
  - j = i (if i+k is valid): contributes (a[i]+delta)*a[i+k] = a[i]*a[i+k] + delta*a[i+k]
  - j = i-k (if i-k is valid): contributes a[i-k]*(a[i]+delta) = a[i-k]*a[i] + delta*a[i-k]
  
  So the change is: delta*(a[i+k] (if valid) + a[i-k] (if valid))

- For conv[0]: if i is in [0, n-1] (always true), then:
  - j = i: a[i]*a[i] changes to (a[i]+delta)^2, change = 2*a[i]*delta + delta^2
  - But wait, conv[0] = sum_j a[j]*a[j] = sum_j a[j]^2. Only the j=i term changes.
  - So change in conv[0] = (a[i]+delta)^2 - a[i]^2 = 2*a[i]*delta + delta^2

- For conv[k] where k != 0:
  - The terms involving a[i] are j=i (gives a[i]*a[i+k]) and j=i-k (gives a[i-k]*a[i])
  - Change = delta * a[i+k] (if i+k valid) + delta * a[i-k] (if i-k valid)
  - Note: if k=0, both terms give the same j=i, so we'd double count. But we handle k=0 separately.

So the update rule is:
- `new_conv[0] = old_conv[0] + 2*a[i]*delta + delta^2`
- `new_conv[k] = old_conv[k] + delta * (safe_a[i+k] + safe_a[i-k])` for k = 1, ..., 2n-2

where `safe_a[j] = a[j]` if 0<=j<n, else 0.

This means we can update the convolution in O(n) time (not O(n log n) as with FFT) for each trial value! This makes the coordinate descent much faster.

with incremental convolution updates. Key innovation: O(n) update per
coordinate change (instead of O(n log n) FFT), enabling ~50x more iterations.
Combined with multi-start, length adaptation, and structured perturbations.

import numpy as np
import time

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    """Euclidean projection onto the probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def coord_descent(f_init, time_limit, n_candidates=11, verbose=False):

    if s < 1e-15:
        f = np.ones(n) / n

        f = f / s

                ])
            else:

                    conv[i:i+n] -= 2.0 * delta * f
