The peak of the time-domain linear convolution is related to the "time-domain peak" of the inverse DTFT of |A(f)|^2. To minimize this peak, we want |A(f)|^2 to be as flat as possible (by the uncertainty principle, a flat spectrum gives the minimum peak).

But there's a catch: a is non-negative, which constrains A(f). Specifically, A(0) = sum(a) > 0, and A(f) is the DTFT of a non-negative sequence, so it satisfies certain constraints (it's in the "non-negative" cone in the frequency domain).

The spectral equalization step:
1. Compute A(f) = DFT(a) (use DFT as approximation to DTFT, or use the actual values)
2. Compute P(f) = |A(f)|^2
3. Target: P_target(f) = constant (or some desired shape)
4. Update: A_new(f) = A(f) * (P_target(f) / P(f))^alpha
5. a_new = IDFT(A_new(f))
6. Project a_new onto {a >= 0, sum(a) = 1}

This is similar to the "Gerchberg-Saxton" algorithm or "alternating projections" used in phase retrieval.

def compute_subgradient(a, conv, top_k=50):
    """Compute smoothed subgradient using top-k peaks."""
    n = len(a)
    if top_k >= len(conv):
        peaks = np.arange(len(conv))
        weights = np.ones(len(peaks)) / len(peaks)
    else:
        peaks = np.argpartition(conv, -top_k)[-top_k:]
        # Use softmax weights
        max_c = conv[peaks].max()
        weights = np.exp(0.5 * (conv[peaks] - max_c))
        weights /= weights.sum()
    
    grad = np.zeros(n)
    for i in range(len(peaks)):
        if weights[i] < 1e-10:
            continue
        k = int(peaks[i])
        # grad[j] += 2 * weights[i] * a[k-j] for valid j
        # This is: grad = 2 * weights[i] * (a reflected and shifted by k)
        js = max(0, k - n + 1)
        je = min(n - 1, k)
        # a[k-j] for j in [js, je]
        idx = np.arange(js, je + 1)
        grad[idx] += 2.0 * weights[i] * a[k - idx]
    
    return grad

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp /= ss
    return f_interp
