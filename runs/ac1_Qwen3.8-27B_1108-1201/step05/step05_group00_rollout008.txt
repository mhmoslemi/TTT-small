But I think the reweighting method will be more effective for making larger improvements. Let me focus on that.

Let me also think about **using the structure of the problem more directly**. The objective is:

f(a) = 2*n*max(conv(a,a)) / (sum(a))^2

Since we can normalize sum(a) = 1, this is just 2*n*max(conv(a,a)).

The key constraint is that conv(a,a)[k] = sum_i a[i]*a[k-i] <= M for all k.

This is a set of quadratic (bilinear) inequalities. The feasible region {a >= 0, sum(a) = 1, conv(a,a)[k] <= M for all k} is non-convex in a.

But we can use a **bisection + LP relaxation** approach:
1. Bisect on M.
2. For a given M, check if the feasibility problem is satisfiable.
3. The feasibility problem is: a >= 0, sum(a) = 1, conv(a,a)[k] <= M for all k.

The bilinear constraints conv(a,a)[k] = sum_i a[i]*a[k-i] <= M can be relaxed. One relaxation is to use the **Arzelà-Beppo-Lemarche** type inequality or the **Schur complement** for the 2x2 case.

For a single constraint sum_i a[i]*a[k-i] <= M, we can't easily relax it to a convex constraint. But we can use the fact that for fixed a[k-i], the constraint is linear in a[i], and vice versa. This suggests an **alternating minimization** approach:

1. Fix all a[j] except a[i]. The constraint sum_j a[j]*a[k-j] <= M becomes: a[i]*a[k-i] + (sum_{j≠i} a[j]*a[k-j]) <= M, which is linear in a[i].
2. So for each i, the feasible range of a[i] is [0, (M - sum_{j≠i} a[j]*a[k-j]) / a[k-i]] (if a[k-i] > 0).

This gives us a **coordinate-wise feasibility check** that can be done in O(n) per coordinate.

But this is for checking feasibility of a given M, not for finding the optimal a.

Let me think about a different approach: **Direct coordinate descent on M**.

At each iteration:
1. Find the highest peak c[k*].
2. Reduce M to c[k*].
3. For each index i, compute the maximum value a[i] can take while keeping all c[k] <= M.
4. Set a[i] to its maximum feasible value (or a fraction of it).
5. Renormalize.
6. Repeat.

Wait, this doesn't quite work because changing a[i] affects all c[k] that involve i.

Let me try yet another approach: **The method of "water filling"**.

Think of the peaks c[k] as "water levels". We want to equalize them. The "water" is the mass of a. Moving mass from one position to another changes the water levels.

The "water filling" algorithm:
1. Compute c = conv(a, a).
2. Find the highest peak level M = max(c).
3. For each peak k with c[k] close to M, try to "drain" it by moving mass from contributing indices.
4. The "drainage" causes "flow" to other peaks, raising their levels.
5. Continue until all peaks are balanced.

This is analogous to the water-filling algorithm in information theory.

OK, I think I've been overthinking this. Let me just write a practical implementation that combines several techniques:

1. **Fast reweighting** (multiplicative weights on heat)
2. **Smoothed gradient** (existing method, with better hyperparameter sweep)
3. **Peak targeting** (coordinate descent on the hottest peak)
4. **n exploration** (try different sequence lengths)

"""
Hybrid optimization for minimizing 2*n*max(conv(a,a))/(sum(a))^2:
- Multiplicative reweighting for global structure
- Smoothed gradient descent for local refinement
- Peak-targeting coordinate descent for fine polishing
- Multi-n exploration for global search
"""

import numpy as np
from scipy.optimize import linprog
import time

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def hankel_mv(p, a):
    return np.correlate(p, a, mode='valid')

def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def solve_lp_oracle(f, M):
    n = len(f)
    c_obj = -np.ones(n)
    A_ub = np.zeros((2 * n - 1, n))
    for j in range(n):
        A_ub[j:j + n, j] = f
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    try:
        res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'presolve': True})
        if res.success:
            return np.maximum(res.x, 0.0)
    except Exception:
        pass
    return None

def reweighting_optimize(a0, time_limit, T_init=0.005, eta_init=0.5):
    """Multiplicative weight reweighting to flatten the convolution."""
    a = np.maximum(a0, 0.0).astype(np.float64)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    T = T_init
    eta = eta_init
    
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit - 0.05:
            break
        
        c = fast_convolve(a)
        
        # Softmax weights emphasizing peaks
        scaled = c / T
        scaled -= scaled.max()
        w = np.exp(scaled)
        w = w / w.sum()
        
        # Heat at each index
        heat = hankel_mv(w, a)
        
        # Multiplicative update
        a_new = a / (1.0 + eta * heat)
        a_new = np.maximum(a_new, 0.0)
        s_new = a_new.sum()
        if s_new < 1e-15:
            break
        a_new = a_new / s_new
        
        obj = fast_convolve(a_new).max()
        if obj < best_obj - 1e-15:
            best_obj = obj
            best_a = a_new.copy()
            no_improve = 0
            a = a_new
        else:
            no_improve += 1
            a = a_new  # still update, but track best
        
        # Adapt
        if no_improve > 30:
            T *= 1.1
            eta *= 0.95
        if no_improve > 100:
            T *= 0.7
            eta = eta_init * 0.5
        if no_improve > 300:
            rng = np.random.default_rng((it * 7919 + 1) % (2**31))
            a = project_simplex(best_a + rng.standard_normal(n) * 0.005)
            T = T_init
            eta = eta_init
            no_improve = 0
    
    return best_a, best_obj
