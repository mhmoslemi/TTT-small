Let me reconsider. For a uniform sequence a = [v, v, ..., v]:
`b[k] = (n - |k-(n-1)|) * v^2` for k = 0, ..., 2n-2.

This is a "triangle" shape with the peak at k = n-1, value = n*v^2.

So for uniform, max is at the center (k = n-1), value = n*v^2.
`sum_a = n*v`.
Objective = `2n * n*v^2 / (n*v)^2 = 2n^2*v^2/(n^2*v^2) = 2`.

Now, can we do better than 2? We need `max(b) / S^2 < 1/n` (since objective = 2n * max(b)/S^2 < 2 means max(b) < S^2/n).

The average of b[k] over all k is `S^2/(2n-1)`. So we need `max(b) < S^2/n` which is possible since `S^2/(2n-1) < S^2/n` for n > 1.

So the question is: can we shape a non-negative sequence so that its self-convolution has a maximum less than `S^2/n`?

For uniform, the max is exactly `S^2/n`. Can we do better?
