where u has length 2n-1 and v has length n. The result has length (2n-1) - n + 1 = n.

cross_corr[m] = sum_j u[m+j] * v[j] for j = 0 to n-1.

YES! That's exactly what we want!

So: grad = 2 * np.correlate(w_full, a, mode='valid')

where w_full has length 2n-1 and a has length n. The result has length n.

Let me verify with a simple example:
a = [1, 2, 3], n=3
w_full = w[0:5] (length 5 = 2*3-1)

grad[0] = 2 * (w[0]*a[0] + w[1]*a[1] + w[2]*a[2]) = 2*(w[0]*1 + w[1]*2 + w[2]*3)
grad[1] = 2 * (w[1]*a[0] + w[2]*a[1] + w[3]*a[2]) = 2*(w[1]*1 + w[2]*2 + w[3]*3)
grad[2] = 2 * (w[2]*a[0] + w[3]*a[1] + w[4]*a[2]) = 2*(w[2]*1 + w[3]*2 + w[4]*3)

np.correlate(w_full, a, mode='valid'):
The 'valid' mode returns only those parts of the correlation that do not rely on the zero-padded parts.
For u of length M=5 and v of length N=3, the valid correlation has length M-N+1 = 3.

np.correlate(u, v, 'valid')[m] = sum_{j=0}^{N-1} u[m+j] * v[j]

So:
result[0] = u[0]*v[0] + u[1]*v[1] + u[2]*v[2] = w[0]*1 + w[1]*2 + w[2]*3 ✓
result[1] = u[1]*v[0] + u[2]*v[1] + u[3]*v[2] = w[1]*1 + w[2]*2 + w[3]*3 ✓
result[2] = u[2]*v[0] + u[3]*v[1] + u[4]*v[2] = w[2]*1 + w[3]*2 + w[4]*3 ✓

So grad = 2 * np.correlate(w_full, a, mode='valid') is correct.

Now, for efficiency with large n, we can use FFT:
- np.correlate for large arrays might be slow in the direct mode
- We can use FFT-based correlation

Actually, for n=768, the arrays are small enough that np.correlate should be fast. Let me check: w_full has length 1535, a has length 768. The correlation computation is O(n * (2n-1)) = O(2n^2) ≈ 1.2M operations. That's fast enough.

But for the LSE, we need to compute this gradient at each iteration. If we do 1000 iterations, that's 1.2B operations, which might be a few seconds. Should be fine.

**New Algorithm: FFT-based LSE with adaptive beta + active set refinement**

1. Start from parent (or good initialization).
2. Phase 1: Coarse LSE with low beta (to explore).
3. Phase 2: Fine LSE with increasing beta (to sharpen).
4. Phase 3: Active set refinement - identify the exact set of peaks at the maximum, and solve a local QP to reduce them simultaneously.
5. Phase 4: Very fine LSE with high beta.
6. Phase 5: Try nearby lengths.

The key improvement over the previous program:
- Much faster gradient computation (using np.correlate instead of the loop-based compute_grad_weighted)
- Better beta scheduling

- More aggressive peak targeting in the final stages

Let me also think about the active set refinement more carefully.

At the optimum (or near it), suppose the peaks at the maximum are at lags k_1, k_2, ..., k_p. We want to find a direction d such that:
- b[k_i] decreases for all i (or at least the max decreases)
- Sum(d) = 0 (to maintain normalization)
- a + t*d >= 0 (non-negativity)

The first-order condition for b[k_i] to decrease is:
∇b[k_i]^T * d < 0

Since ∇b[k_i][m] = 2*a[k_i - m] (if valid), this means:
sum_m a[k_i - m] * d[m] < 0

We want to find d that satisfies all these simultaneously. One approach:
- d = -sum_i alpha_i * ∇b[k_i] (with alpha_i > 0)
- Then project onto the simplex tangent space (sum d = 0) and non-negativity cone.

This is similar to the FW-LP but with a simpler direction (just the sum of gradients instead of solving an LP).

Actually, the LP in FW already does something similar but more optimally. The LP finds the BEST direction (maximizing sum(g) subject to all constraints), while the simple gradient sum is a heuristic.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Fast FFT-based LSE gradient descent with adaptive beta
2. Active-set peak refinement
3. Multi-length exploration with interpolation
4. Peak elimination micro-polish
Key improvements: O(n log n) gradient via np.correlate, better beta schedule,
active set identification, and targeted peak reduction.
"""

import numpy as np
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex {x: x>=0, sum(x)=1}."""
    n = len(v)
    if n == 0:
        return v
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.arange(1, n + 1)
    cond = u * rho > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho_val = np.nonzero(cond)[0][-1] + 1
    theta = (cssv[rho_val - 1] - 1.0) / rho_val
    return np.maximum(v - theta, 0.0)


def lse_gradient(f, w_full):
    """
    Compute gradient of LSE objective.
    f: sequence (length n), normalized to sum=1
    w_full: weights on convolution lags (length 2n-1)
    Returns gradient (length n).
    """
    # grad[m] = 2 * sum_j w_full[m+j] * f[j] for j=0..n-1
    # This is np.correlate(w_full, f, mode='valid')
    grad = 2.0 * np.correlate(w_full, f, mode='valid')
    return grad


def lse_optimize_v2(f0, time_limit, beta_start=10.0, beta_end=20000.0, 
                     lr_init=None, momentum_init=0.90, n_peaks=None):
    """
    Improved LSE gradient descent with fast gradient computation.
    """
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    
    if lr_init is None:
        lr = 3.0 / n
    else:
        lr = lr_init
    
    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()
    
    beta = beta_start
    momentum = momentum_init
    v = np.zeros(n)
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        conv = fast_convolve(f)
        
        # Compute LSE weights
        bc = beta * conv
        bc_max = bc.max()
        exp_bc = np.exp(bc - bc_max)
        w = exp_bc / exp_bc.sum()
        
        # Fast gradient
        grad = lse_gradient(f, w)
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-15:
            no_improve += 100
            break
        grad /= grad_norm
        
        # Momentum update
        v = momentum * v - lr * grad
        f_new = project_simplex(f + v)
        
        if np.all(f_new == 0):
            f_new = f.copy()
            obj_new = best_obj
        else:
            conv_new = fast_convolve(f_new)
            obj_new = conv_new.max()
        
        if obj_new < best_obj - 1e-14:
            best_obj = obj_new
            best_f = f_new.copy()
            f = f_new
            no_improve = 0
            lr = min(lr * 1.002, 10.0 / n)
        else:
            no_improve += 1
            if no_improve >= 5:
                lr *= 0.95
                momentum = max(0.80, momentum - 0.005)
            if no_improve > 50:
                f = best_f.copy()
                v = np.zeros(n)
                lr = max(2.0 / n, 0.001)
                beta = min(beta * 1.5, beta_end)
                momentum = 0.88
                no_improve = 0
        
        # Gradually increase beta
        if beta < beta_end:
            beta *= 1.003
    
    return best_f, best_obj


def active_set_refine(f0, time_limit, n_top=20):
    """
    Identify top peaks and use a weighted subgradient to reduce them.
    Focus exclusively on the highest peaks.
    """
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    conv_len = 2 * n - 1
    
    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    lr = 2.0 / n
    momentum = 0.92
    v = np.zeros(n)
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        conv = fast_convolve(f)
        
        # Find top peaks
        k_top = min(n_top, conv_len)
        peak_indices = np.argpartition(conv, -k_top)[-k_top:]
        peak_vals = conv[peak_indices]
        
        # Weight by how much above the second-highest
        max_val = peak_vals.max()
        # Exponential weighting emphasizing the highest
        scaled = peak_vals - peak_vals.min()
        w_peaks = np.exp(5.0 * scaled / max(max(scaled.max(), 1e-15)))
        w_peaks /= w_peaks.sum()
        
        # Build full weight vector (only top peaks matter)
        w_full = np.zeros(conv_len)
        w_full[peak_indices] = w_peaks
        
        # Fast gradient
        grad = lse_gradient(f, w_full)
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-15:
            no_improve += 100
            break
        grad /= grad_norm
        
        v = momentum * v - lr * grad
        f_new = project_simplex(f + v)
        
        conv_new = fast_convolve(f_new)
        obj_new = conv_new.max()
        
        if obj_new < best_obj - 1e-14:
            best_obj = obj_new
            best_f = f_new.copy()
            f = f_new
            no_improve = 0
        else:
            no_improve += 1
            if no_improve % 20 == 0:
                lr *= 0.95
            if no_improve > 150:
                # Try random restart
                rng = np.random.default_rng((it * 7919 + 13) % 1000000)
                f = project_simplex(best_f + rng.standard_normal(n) * 0.001)
                v = np.zeros(n)
                lr = max(1.0 / n, 0.0005)
                no_improve = 0
    
    return best_f, best_obj


def peak_elimination(f0, time_limit, n_peaks=5):
    """
    Directly target the single highest peak using its exact gradient.
    Very aggressive step sizes with backtracking.
    """
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    
    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        conv = fast_convolve(f)
        
        # Get top peaks
        k_top = min(n_peaks, 2*n-1)
        peak_idxs = np.argpartition(conv, -k_top)[-k_top:]
        
        # Weight: emphasize highest peak strongly
        pv = conv[peak_idxs]
        max_pv = pv.max()
        # Very sharp weighting
        w = np.zeros(2*n-1)
        for idx in peak_idxs:
            w[idx] = np.exp(10.0 * (conv[idx] - max_pv) / max_pv)
        w_sum = w.sum()
        if w_sum < 1e-15:
            w[peak_idxs[np.argmax(pv)]] = 1.0
        else:
            w /= w_sum
        
        # Gradient
        grad = lse_gradient(f, w)
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-15:
            break
        grad /= grad_norm
        
        # Backtracking line search
        best_alpha = 0.0
        best_val = conv.max()
        for alpha in [0.01, 0.02, 0.05, 0.1, 0.2, 0.3, 0.5, 0.7, 1.0]:
            f_try = project_simplex(f - alpha * grad)
            val = fast_convolve(f_try).max()
            if val < best_val:
                best_val = val
                best_alpha = alpha
        
        if best_alpha > 0:
            f = project_simplex(f - best_alpha * grad)
            val = fast_convolve(f).max()
            if val < best_obj - 1e-14:
                best_obj = val
                best_f = f.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1
        
        if no_improve > 100:
            break
    
    return best_f, best_obj

def interpolate_to_length(f, new_n):
    """Interpolate a normalized sequence to a new length."""
    x_old = np.linspace(0, 1, len(f))
    x_new = np.linspace(0, 1, new_n)
    f_new = np.interp(x_new, x_old, f)
    f_new = np.maximum(f_new, 0)
    s = f_new.sum()
    if s > 1e-15:
        f_new /= s
    else:
        f_new = np.ones(new_n) / new_n
    return f_new


def fw_lp_simple(f0, time_limit):
    """Simplified FW with LP oracle for initial exploration."""
    from scipy.sparse import csr_matrix
    from scipy.optimize import linprog
    
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    
    conv = fast_convolve(f)
    M = conv.max()
    best_obj = M
    best_f = f.copy()
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        
        # Build LP: max sum(g) s.t. conv(f, g)[k] <= M for all k, g >= 0
        # conv(f, g)[k] = sum_i f[i] * g[k-i] (valid indices)
        # This is a linear function of g for each k.
        
        # Build constraint matrix A where A[k, j] = coefficient of g[j] in conv(f,g)[k]
        # conv(f,g)[k] = sum_j f[k-j] * g[j] (where k-j is valid index of f)
        # So A[k, j] = f[k-j] if 0 <= k-j < n, else 0
        
        rows = []
        cols = []
        vals = []
        for k in range(2 * n - 1):
            j_start = max(0, k - n + 1)
            j_end = min(n - 1, k)
            if j_start <= j_end:
                js = np.arange(j_start, j_end + 1)
                rows.extend([k] * len(js))
                cols.extend(js.tolist())
                vals.extend(f[k - js].tolist())
        
        A = csr_matrix((vals, (rows, cols)), shape=(2*n-1, n))
        c = -np.ones(n)
        b_ub = np.full(2*n-1, M)
        bounds = [(0.0, None)] * n
        
        try:
            res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds,
                         method='highs', options={'presolve': True, 'time_limit': 20})
            if not (res.success and res.x is not None):
                no_improve += 1
                if no_improve > 30:
                    break
                M *= 1.1
                continue
            g = np.maximum(res.x, 0.0)
        except Exception:
            no_improve += 1
            if no_improve > 30:
                break
            M *= 1.1
            continue
        
        gs = g.sum()
        if gs < 1e-15:
            break
        g /= gs
        
        if np.max(np.abs(g - f)) < 1e-12:
            no_improve += 1
            if no_improve > 30:
                break
            M *= 1.05
            continue
        
        # Line search
        best_alpha = 0.0
        best_val = M
        for alpha in [0.1, 0.2, 0.3, 0.5, 0.7, 1.0]:
            ft = np.maximum((1.0 - alpha) * f + alpha * g, 0.0)
            st = ft.sum()
            if st < 1e-15:
                continue
            ft /= st
            val = fast_convolve(ft).max()
            if val < best_val:
                best_val = val
                best_alpha = alpha
        
        if best_alpha > 1e-10:
            f = np.maximum((1.0 - best_alpha) * f + best_alpha * g, 0.0)
            f /= f.sum()
            conv = fast_convolve(f)
            M = conv.max()
            if M < best_obj - 1e-14:
                best_obj = M
                best_f = f.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1
            M *= 1.05
        
        if no_improve > 40:
            break
    
    return best_f, best_obj


def random_init(n, seed):
    """Generate a random non-negative normalized sequence."""
    rng = np.random.default_rng(seed)
    f = rng.exponential(1.0, size=n)
    f /= f.sum()
    return f


def structured_init(n, seed):
    """Generate a structured non-negative normalized sequence."""
    rng = np.random.default_rng(seed)
    # Mix of sinusoidal and random
    x = np.arange(n) / n
    freq = rng.integers(1, 5)
    phase = rng.uniform(0, 2 * np.pi)
    f = 1.0 + 0.3 * np.cos(2 * np.pi * freq * x + phase)
    f += 0.1 * rng.standard_normal(n)
    f = np.maximum(f, 0.0)
    f /= f.sum()
    return f

import numpy as np

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    c = np.fft.irfft(A * A, fft_size)[:size]
    return c


def project_simplex(v):
    """Euclidean projection onto probability simplex {x: x>=0, sum(x)=1}."""
    n = len(v)
    if n == 0:
        return v
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.arange(1, n + 1)
    cond = u * rho > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    idx = np.nonzero(cond)[0][-1]
    theta = (cssv[idx] - 1.0) / (idx + 1)
    return np.maximum(v - theta, 0.0)


def lse_gradient(f, w_full):

    return 2.0 * np.correlate(w_full, f, mode='valid')

    return 4.0 * np.correlate(b, f, mode='valid')

def interpolate_to_length(f, new_n):
    """Interpolate a normalized sequence to a new length."""
    x_old = np.linspace(0, 1, len(f))

    f_new = np.maximum(f_new, 0)
    s = f_new.sum()
    if s > 1e-15:

    else:
        f_new = np.ones(new_n) / new_n

    f = np.maximum(f0.astype(np.float64), 0.0)

        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    lr = lr_init if lr_init is not None else 3.0 / n
    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()
    beta = beta_start
    momentum = momentum_init
    v = np.zeros(n)
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    best_lr = lr

    while time.monotonic() - t0 < time_limit:
        it += 1
        conv = fast_convolve(f)
        bc = beta * conv
        bc_max = bc.max()
        exp_bc = np.exp(bc - bc_max)
        w = exp_bc / exp_bc.sum()
        grad = lse_gradient(f, w)
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-15:
            no_improve += 200
            break
        grad /= grad_norm
        v = momentum * v - lr * grad
        f_new = project_simplex(f + v)

                no_improve = 0

def active_set_refine(f0, time_limit, n_top=25, sharpness=8.0):
    """Target top peaks with sharp exponential weighting."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    conv_len = 2 * n - 1
    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()
    t0 = time.monotonic()
    no_improve = 0
    lr = 2.5 / n
    momentum = 0.93
    v = np.zeros(n)
    it = 0

    while time.monotonic() - t0 < time_limit:
        it += 1
        conv = fast_convolve(f)
        k_top = min(n_top, conv_len)
        peak_indices = np.argpartition(conv, -k_top)[-k_top:]
        pv = conv[peak_indices]
        max_pv = pv.max()
        if max_pv < 1e-15:
            break
        scaled = pv - pv.min()
        if scaled.max() < 1e-15:
            w_peaks = np.ones(k_top) / k_top
        else:
            w_peaks = np.exp(sharpness * scaled / scaled.max())
            w_peaks /= w_peaks.sum()
        w_full = np.zeros(conv_len)
        w_full[peak_indices] = w_peaks
        grad = lse_gradient(f, w_full)
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-15:
            no_improve += 200
            break
        grad /= grad_norm
        v = momentum * v - lr * grad
        f_new = project_simplex(f + v)
        if f_new.sum() < 1e-15:
            f_new = f.copy()
            obj_new = best_obj
        else:
            obj_new = fast_convolve(f_new).max()
        if obj_new < best_obj - 1e-14:
            best_obj = obj_new
            best_f = f_new.copy()
            f = f_new
            no_improve = 0
        else:
            no_improve += 1
            if no_improve % 25 == 0:
                lr *= 0.94
            if no_improve > 120:
                rng = np.random.default_rng((it * 104729 + 3) % 999983)
                f = project_simplex(best_f + rng.standard_normal(n) * 0.002)
                v = np.zeros(n)
                lr = max(1.0 / n, 0.0005)
                no_improve = 0

    return best_f, best_obj


def peak_elimination(f0, time_limit, n_peaks=4):
    """Directly target the highest peaks with aggressive backtracking."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    conv_len = 2 * n - 1
    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()
    t0 = time.monotonic()
    no_improve = 0
    it = 0

    while time.monotonic() - t0 < time_limit:
        it += 1
        conv = fast_convolve(f)
        k_top = min(n_peaks, conv_len)
        peak_idxs = np.argpartition(conv, -k_top)[-k_top:]
        max_val = conv.max()
        w_full = np.zeros(conv_len)
        for idx in peak_idxs:
            w_full[idx] = np.exp(15.0 * (conv[idx] - max_val) / max(max_val, 1e-15))
        w_sum = w_full.sum()
        if w_sum < 1e-15:
            w_full[peak_idxs[np.argmax(conv[peak_idxs])]] = 1.0
        else:
            w_full /= w_sum
        grad = lse_gradient(f, w_full)
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-15:
            break
        grad /= grad_norm
        best_alpha = 0.0
        best_val = conv.max()
        for alpha in [0.005, 0.01, 0.02, 0.05, 0.1, 0.15, 0.2, 0.3, 0.5]:
            f_try = project_simplex(f - alpha * grad)
            val = fast_convolve(f_try).max()
            if val < best_val:
                best_val = val
                best_alpha = alpha
        if best_alpha > 0:
            f = project_simplex(f - best_alpha * grad)
            val = fast_convolve(f).max()
            if val < best_obj - 1e-14:
                best_obj = val
                best_f = f.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1
        if no_improve > 150:
            rng = np.random.default_rng((it * 31 + 17) % 999983)
            f = project_simplex(best_f + rng.standard_normal(n) * 0.001)
            no_improve = 0
            it += 1

    return best_f, best_obj

        it += 1
        rows = []
        cols = []
        vals = []
        for k in range(2 * n - 1):
            j_start = max(0, k - n + 1)
            j_end = min(n - 1, k)
            if j_start <= j_end:
                js = np.arange(j_start, j_end + 1)
                rows.extend([k] * len(js))
                cols.extend(js.tolist())
                vals.extend((f[k - js]).tolist())
        A = csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
        c = -np.ones(n)
        b_ub = np.full(2 * n - 1, M * m_exp)
        bounds = [(0.0, None)] * n
        try:
            res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds,
                          method='highs', options={'presolve': True, 'time_limit': 20})
            if not (res.success and res.x is not None):
                no_improve += 1
                m_exp = min(m_exp * 1.1, 10.0)
                if m_exp > 5.0:
                    break
                continue
            g = np.maximum(res.x, 0.0)
        except Exception:
            no_improve += 1
            m_exp = min(m_exp * 1.1, 10.0)
            if m_exp > 5.0:
                break
            continue
        gs = g.sum()
        if gs < 1e-15:
            break
        g /= gs
        if np.max(np.abs(g - f)) < 1e-12:
            no_improve += 1
            m_exp = min(m_exp * 1.05, 8.0)
            if no_improve > 40:
                break
            continue
        best_alpha = 0.0
        best_val = conv.max()
        for alpha in [0.1, 0.2, 0.3, 0.5, 0.7, 1.0]:
            ft = np.maximum((1.0 - alpha) * f + alpha * g, 0.0)
            st = ft.sum()
            if st < 1e-15:
                continue
            ft /= st
            val = fast_convolve(ft).max()
            if val < best_val:
                best_val = val
                best_alpha = alpha
        if best_alpha > 1e-10:
            f = np.maximum((1.0 - best_alpha) * f + best_alpha * g, 0.0)
            f /= f.sum()
            conv = fast_convolve(f)
            M = conv.max()
            m_exp = 1.0
            if M < best_obj - 1e-14:
                best_obj = M
                best_f = f.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1
            m_exp = min(m_exp * 1.08, 10.0)
        if no_improve > 50:
            rng = np.random.default_rng(it * 31 + 7)
            f = project_simplex(best_f + rng.standard_normal(n) * 0.003)
            conv = fast_convolve(f)
            M = conv.max()
            m_exp = 1.0
            no_improve = 0

    return best_f, best_obj


def coordinate_descent(f0, time_limit, max_iter=5000):
    """Simple coordinate descent: try adjusting each coordinate."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()
    t0 = time.monotonic()
    it = 0

    while time.monotonic() - t0 < time_limit and it < max_iter:
        it += 1
        improved = False
        for i in range(n):
            if f[i] < 1e-8:
                continue
            for delta in [0.001, 0.005, 0.01]:
                for sign in [-1, 1]:
                    f_try = f.copy()
                    if sign == -1:
                        amt = min(f[i], delta)
                        f_try[i] -= amt
                        # Distribute to neighbor
                        j = (i + 1) % n
                        f_try[j] += amt
                    else:
                        j = (i + 1) % n
                        amt = min(f[j], delta)
                        f_try[j] -= amt
                        f_try[i] += amt
                    f_try = np.maximum(f_try, 0)
                    ss = f_try.sum()
                    if ss < 1e-15:
                        continue
                    f_try /= ss
                    val = fast_convolve(f_try).max()
                    if val < best_obj - 1e-12:
                        best_obj = val
                        best_f = f_try.copy()
                        f = f_try
                        improved = True
                        break
                if improved:
                    break
            if improved:
                break
        if not improved:
            break

    return best_f, best_obj


def combine_sequences(f1, f2, alpha):
    """Interpolate between two sequences of same length."""
    return np.maximum((1 - alpha) * f1 + alpha * f2, 0.0)


def propose_candidate(seed=42, budget_s=1800):
    """
    Multi-phase optimization:
    Phase 1: Quick LSE warmup from parent
    Phase 2: Sum-of-squares optimization (smooth L2 surrogate)
    Phase 3: LSE with increasing beta (sharpening)
    Phase 4: FW-LP global direction
    Phase 5: Active set + peak elimination
    Phase 6: Multi-length exploration
    Phase 7: Random restarts with structured inits
    Phase 8: Final micro-polish
    """
    deadline = time.monotonic() + max(1.0, float(budget_s) - 30.0)
    best_tracker = [float('inf'), None]

    # Load parent
    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            parent = p / p.sum()
            ps = evaluate_sequence(parent.tolist())
            print(f"Parent: n={len(parent)}, score={ps:.8f}")
            if np.isfinite(ps):
                best_tracker[0] = ps
                best_tracker[1] = parent.copy()
    except Exception:
        pass

    if parent is None:
        parent = np.ones(768) / 768
        ps = evaluate_sequence(parent.tolist())
        best_tracker[0] = ps
        best_tracker[1] = parent.copy()
        print(f"Default: n=768, score={ps:.8f}")

    n_parent = len(parent)

    # === Phase 1: Quick LSE warmup ===
    print(f"\n=== Phase 1: LSE Warmup (n={n_parent}) ===")
    t = min(120, deadline - time.monotonic())
    if t > 20:
        f_opt, obj = lse_optimize(parent, time_limit=t,
                                   beta_start=8.0, beta_end=3000.0,
                                   lr_init=3.0 / n_parent)
        try_sequence(f_opt, best_tracker)

    # === Phase 2: Sum-of-squares optimization ===
    print(f"\n=== Phase 2: Sum-of-Squares (n={len(best_tracker[1])}) ===")
    current = best_tracker[1].copy()
    n_cur = len(current)
    t = min(180, deadline - time.monotonic())
    if t > 30:
        f_opt, obj = sumsq_optimize(current, time_limit=t,
                                     lr_init=2.0 / n_cur)
        try_sequence(f_opt, best_tracker)

    # === Phase 3: LSE with high beta ===
    print(f"\n=== Phase 3: LSE High Beta ===")
    current = best_tracker[1].copy()
    n_cur = len(current)
    t = min(200, deadline - time.monotonic())
    if t > 30:
        f_opt, obj = lse_optimize(current, time_limit=t,
                                   beta_start=50.0, beta_end=20000.0,
                                   lr_init=2.0 / n_cur)
        try_sequence(f_opt, best_tracker)

    # === Phase 4: FW-LP ===
    print(f"\n=== Phase 4: FW-LP ===")
    current = best_tracker[1].copy()
    t = min(200, deadline - time.monotonic())
    if t > 60:
        f_opt, obj = fw_lp_simple(current, time_limit=t)
        try_sequence(f_opt, best_tracker)

    # === Phase 5: Active set + Peak elimination ===
    print(f"\n=== Phase 5: Active Set + Peak Elim ===")
    current = best_tracker[1].copy()
    n_cur = len(current)
    t = min(120, deadline - time.monotonic())
    if t > 20:
        f_opt, obj = active_set_refine(current, time_limit=t, n_top=30, sharpness=10.0)
        try_sequence(f_opt, best_tracker)

    current = best_tracker[1].copy()
    t = min(100, deadline - time.monotonic())
    if t > 20:
        f_opt, obj = peak_elimination(current, time_limit=t, n_peaks=3)
        try_sequence(f_opt, best_tracker)

    # === Phase 6: Multi-length exploration ===
    print(f"\n=== Phase 6: Multi-length Exploration ===")
    n_best = len(best_tracker[1])
    t6_end = deadline - 150
    length_candidates = []
    for offset in [-96, -64, -32, 32, 64, 96, 128, -128]:
        nl = n_best + offset
        if 256 <= nl <= 1536:
            length_candidates.append(nl)
    for nl in [384, 448, 512, 576, 640, 704, 768, 832, 896, 960, 1024]:
        if nl not in length_candidates:
            length_candidates.append(nl)
    length_candidates = sorted(set(length_candidates), key=lambda x: abs(x - n_best))

    for nl in length_candidates[:5]:
        t_rem = t6_end - time.monotonic()
        if t_rem < 40:
            break
        t_alloc = min(60, t_rem * 0.35)
        if t_alloc < 15:
            break
        f_init = interpolate_to_length(best_tracker[1], nl)
        print(f"  LSE n={nl}, t={t_alloc:.0f}s")
        f_opt, _ = lse_optimize(f_init, time_limit=t_alloc,
                                 beta_start=20.0, beta_end=5000.0)
        try_sequence(f_opt, best_tracker)
        # Quick active set follow-up
        t_rem2 = t6_end - time.monotonic()
        if t_rem2 > 20:
            f_opt2, _ = active_set_refine(f_opt, time_limit=min(25, t_rem2 - 10),
                                           n_top=20, sharpness=10.0)
            try_sequence(f_opt2, best_tracker)

    # === Phase 7: Random restarts ===
    print(f"\n=== Phase 7: Random Restarts ===")
    t7_end = deadline - 100
    rng = np.random.default_rng(seed)
    for i in range(8):
        t_rem = t7_end - time.monotonic()
        if t_rem < 30:
            break
        t_alloc = min(45, t_rem * 0.3)
        if t_alloc < 15:
            break
        # Vary length and initialization
        nl = n_best + int(rng.integers(-64, 65))
        nl = max(384, min(1024, nl))
        # Structured init
        x = np.arange(nl) / nl
        freq = rng.integers(1, 6)
        phase = rng.uniform(0, 2 * np.pi)
        f_init = 1.0 + 0.2 * np.cos(2 * np.pi * freq * x + phase)
        f_init += 0.05 * rng.standard_normal(nl)
        f_init = np.maximum(f_init, 0.0)
        f_init /= f_init.sum()
        f_opt, _ = lse_optimize(f_init, time_limit=t_alloc,
                                 beta_start=5.0, beta_end=3000.0)
        try_sequence(f_opt, best_tracker)

    # === Phase 8: Final micro-polish ===
    print(f"\n=== Phase 8: Final Polish ===")
    current = best_tracker[1].copy()
    n_cur = len(current)

    # Very high beta LSE
    t = min(100, deadline - time.monotonic() - 30)
    if t > 15:
        print(f"  High-beta LSE t={t:.0f}s")
        f_opt, _ = lse_optimize(current, time_limit=t,
                                 beta_start=500.0, beta_end=50000.0,
                                 lr_init=1.0 / n_cur)
        try_sequence(f_opt, best_tracker)

    # Peak elimination with 2 peaks
    current = best_tracker[1].copy()
    t = min(60, deadline - time.monotonic() - 15)
    if t > 10:
        print(f"  Peak elim (2) t={t:.0f}s")
        f_opt, _ = peak_elimination(current, time_limit=t, n_peaks=2)
        try_sequence(f_opt, best_tracker)

    # Active set with many peaks, very sharp
    current = best_tracker[1].copy()
    t = min(50, deadline - time.monotonic() - 10)
    if t > 8:
        print(f"  Active set (50, sharp=15) t={t:.0f}s")
        f_opt, _ = active_set_refine(current, time_limit=t, n_top=50, sharpness=15.0)
        try_sequence(f_opt, best_tracker)

    # Coordinate descent micro-adjustments
    current = best_tracker[1].copy()
    t = min(60, deadline - time.monotonic() - 5)
    if t > 10:
        print(f"  Coord descent t={t:.0f}s")
        f_opt, _ = coordinate_descent(current, time_limit=t, max_iter=2000)
        try_sequence(f_opt, best_tracker)

    # Final evaluation
    if best_tracker[1] is not None:
        final_seq = best_tracker[1]
        final_score = float(evaluate_sequence(final_seq.tolist()))
        if np.isfinite(final_score):
            print(f"\nFINAL: score={final_score:.10f}, n={len(final_seq)}")
            return [float(x) for x in final_seq]

    print("WARNING: Using fallback")
    fallback = np.ones(768) / 768
    return [float(x) for x in fallback]
