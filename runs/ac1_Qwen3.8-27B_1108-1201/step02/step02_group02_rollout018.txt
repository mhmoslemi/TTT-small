At the optimum, for the problem:
`min max_k c_k(a)` subject to `sum(a) = S`, `a >= 0`

The KKT conditions say:
- There exist multipliers λ_k >= 0 (for each peak constraint) and μ (for the sum constraint) and ν_j >= 0 (for non-negativity) such that:
  - `sum_k λ_k * d(c_k)/da_j + μ - ν_j = 0` for all j
  - `λ_k * c_k = 0` (complementary slackness: only active peaks have λ_k > 0)
  - `ν_j * a_j = 0` (if a_j > 0, then ν_j = 0)

For interior points (a_j > 0):
`sum_k λ_k * 2*a[k-j] = -μ` (constant across all j)

This means: `w ⊛ a` is constant, where `w = 2*sum_k λ_k * e_k` (a weighted sum of peak positions).

In other words, at the optimum, the cross-correlation of the active peak weights with the sequence is constant. This is a strong structural condition!

This suggests that an alternating approach might work:
1. Given a sequence a, find the peak weights w (the active peaks)
2. Given the peak weights w, find the sequence a that makes w ⊛ a constant (this is a linear system!)
3. Iterate

Step 2 is interesting: if we want `(w ⊛ a)[j] = const` for all j, with `sum(a) = S` and `a >= 0`, we can solve this as a linear system (or optimization).

def fft_convolve(a, b):
    n = len(a)
    m = len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:n + m - 1]

Wait, I realize there's an issue with my gradient computation. Let me re-derive it.

The objective is `f(a) = 2n * max(c) / (sum(a))^2` where `c = convolve(a, a)`.

For the soft version: `f(a) = 2n * soft_max(c, T) / (sum(a))^2`

But since the problem is scale-invariant, I can just minimize `soft_max(c, T)` subject to `sum(a) = S`.

The gradient of `soft_max(c, T)` w.r.t. `a[j]`:
`d(soft_max)/da[j] = sum_k w[k] * d(c[k])/da[j]`

where `w[k] = exp((c[k]-c_max)/T) / sum(exp((c-c_max)/T))`

And `d(c[k])/da[j] = 2*a[k-j]` if `0 <= k-j < n`, else 0.

So: `d(soft_max)/da[j] = 2 * sum_k w[k] * a[k-j] * [0 <= k-j < n]`
`= 2 * sum_{m: 0<=m<n} w[m+j] * a[m]`
`= 2 * (a ⊛ w)[j]` (cross-correlation of a and w at lag j)

Where `(a ⊛ w)[j] = sum_m a[m] * w[m+j]`

To compute `(a ⊛ w)[j]` for j = 0, ..., n-1:
- w has length 2n-1, a has length n
- `(a ⊛ w)[j] = sum_{m=0}^{n-1} a[m] * w[m+j]`
- This is valid as long as m+j < 2n-1, i.e., m < 2n-1-j, which is always true since m < n and j >= 0.

To compute via FFT:
`(a ⊛ w)[j] = (flip(a) * w)[n-1+j]` where `*` is linear convolution.

Let me verify: `(flip(a) * w)[k] = sum_i flip(a)[i] * w[k-i] = sum_i a[n-1-i] * w[k-i]`
Let j' = n-1-i: `= sum_{j'} a[j'] * w[k-(n-1-j')] = sum_{j'} a[j'] * w[k-n+1+j']`
For k = n-1+j: `= sum_{j'} a[j'] * w[j+j']` ✓

import numpy as np
import time

# Helper functions (top-level)

def fft_convolve(a, b):
    """Fast linear convolution via FFT."""
    n = len(a)
    m = len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:n + m - 1]

def compute_score(a):
    """Compute the evaluation score (fast local version)."""
    n = len(a)
    a = np.clip(a, 0.0, 1000.0)
    s = np.sum(a)
    if s < 0.01:
        return np.inf
    c = fft_convolve(a, a)
    return float(2.0 * n * np.max(c) / (s * s))

def normalize(a, S):
    """Normalize sequence to have sum S, maintaining non-negativity."""
    a = np.clip(a, 0, None)
    s = np.sum(a)
    if s < 1e-10:
        return np.ones(len(a)) * S / len(a)
    return a * (S / s)

def adam_soft_peak(a0, time_budget, rng, T_start=10.0, T_end=0.001, lr=0.02,

    n = len(a0)
    S = np.sqrt(2.0 * n)
    a = normalize(a0.copy(), S)

    best_score = compute_score(a)
    
    m_arr = np.zeros(n)
    v_arr = np.zeros(n)
    eps = 1e-8
    t = 0
    step = 0
    patience = 0
    stall_threshold = 2000
    
    t0 = time.monotonic()
    elapsed_check = 0
    
    while time.monotonic() - t0 < time_budget:
        elapsed = time.monotonic() - t0
        frac = min(1.0, elapsed / (time_budget * 0.85))
        T = T_start * (T_end / T_start) ** frac
        T = max(T, T_end)
        
        c = fft_convolve(a, a)
        c_max = np.max(c)
        
        if T > 1e-8:
            w = np.exp((c - c_max) / T)
            w_sum = np.sum(w)
            if w_sum < 1e-30:
                break
            w /= w_sum
        else:
            w = np.zeros(2*n-1)
            peak_mask = c >= c_max * (1 - 1e-10)
            w[peak_mask] = 1.0 / np.sum(peak_mask)
        
        # Gradient
        r = fft_convolve(a[::-1], w)
        grad = 2.0 * r[n-1:2*n-1]
        
        t += 1
        m_arr = beta1 * m_arr + (1 - beta1) * grad
        v_arr = beta2 * v_arr + (1 - beta2) * grad**2
        m_hat = m_arr / (1 - beta1**t)
        v_hat = v_arr / (1 - beta2**t)

        a_new = normalize(a_new, S)

                patience = 0

            patience = 0
            # Reset Adam state

def subgradient_polish(a0, time_budget, rng, n_steps_per_epoch=1000, verbose=False):
    """Subgradient descent on the true peak."""
    n = len(a0)
    S = np.sqrt(2.0 * n)
    a = normalize(a0.copy(), S)
    best_a = a.copy()
    best_score = compute_score(a)
    
    t0 = time.monotonic()
    step = 0
    lr = 0.01
    
    while time.monotonic() - t0 < time_budget:
        c = fft_convolve(a, a)
        c_max = np.max(c)
        
        # Find peak positions (all significant peaks)
        threshold = c_max * 0.99
        peak_mask = c >= threshold
        peak_indices = np.where(peak_mask)[0]
        
        # Subgradient: average over peaks
        grad = np.zeros(n)
        for k in peak_indices:
            # d(c[k])/da[j] = 2*a[k-j] if 0 <= k-j < n
            valid = (k - np.arange(n) >= 0) & (k - np.arange(n) < n)
            if np.any(valid):

        # Update
        a_new = a - lr * grad
        a_new = normalize(a_new, S)
        
        # Adaptive lr
        step += 1
        lr = 0.01 / (1.0 + 0.001 * step)
        
        a = a_new

        best_a = a.copy()

"""
Multi-phase optimization for minimizing peak autocorrelation of non-negative step functions.
Uses Adam with soft-peak annealing as the main optimizer, combined with subgradient
polish, coordinate descent, and targeted peak-reduction moves. Multiple initializations
and sequence lengths are explored within the time budget.
"""

import numpy as np
import time


def fft_convolve(a, b):
    """Fast linear convolution via FFT."""
    n = len(a)
    m = len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:n + m - 1]


def compute_score(a):
    """Compute the evaluation score (fast local version)."""
    n = len(a)
    a = np.clip(a, 0.0, 1000.0)
    s = np.sum(a)
    if s < 0.01:
        return np.inf
    c = fft_convolve(a, a)
    return float(2.0 * n * np.max(c) / (s * s))


def normalize(a, S):
    """Normalize sequence to have sum S, maintaining non-negativity."""
    a = np.clip(a, 0.0, None)
    s = np.sum(a)
    if s < 1e-10:
        return np.ones(len(a)) * S / len(a)
    return a * (S / s)


def adam_soft_peak(a0, time_budget, rng, T_start=10.0, T_end=0.005, lr_base=0.05,
                   beta1=0.85, beta2=0.999, verbose=False):
    """Adam optimizer with soft-peak annealing and adaptive learning rate."""
    n = len(a0)
    S = np.sqrt(2.0 * n)
    a = normalize(a0.astype(np.float64).copy(), S)

    best_a = a.copy()
    best_score = compute_score(a)

    m_arr = np.zeros(n)
    v_arr = np.zeros(n)
    eps = 1e-8
    t = 0
    step = 0
    patience = 0
    stall_threshold = 3000

    # Adapt T to the problem scale
    c_init = fft_convolve(a, a)
    c_spread = np.max(c_init) - np.percentile(c_init, 5)
    T = max(T_start, c_spread * 0.3)
    T_end_eff = max(T_end, c_spread * 0.005)

    t0 = time.monotonic()

    while time.monotonic() - t0 < time_budget:
        elapsed = time.monotonic() - t0
        frac = min(1.0, elapsed / (time_budget * 0.88))

        # Exponential T annealing
        T_cur = T * (T_end_eff / T) ** frac
        T_cur = max(T_cur, 1e-7)

        c = fft_convolve(a, a)
        c_max = np.max(c)

        # Soft-max weights
        if T_cur > 1e-6:
            exponent = (c - c_max) / T_cur
            exponent = np.clip(exponent, -500, 0)
            w = np.exp(exponent)
            w_sum = np.sum(w)
            if w_sum < 1e-30:
                w = np.zeros(2 * n - 1)
                w[np.argmax(c)] = 1.0
            else:
                w /= w_sum
        else:
            # Hard mode: use top few peaks
            top_k = min(3, 2 * n - 1)
            sorted_idx = np.argsort(c)[::-1][:top_k]
            w = np.zeros(2 * n - 1)
            w[sorted_idx] = 1.0 / top_k

        # Gradient via cross-correlation
        r = fft_convolve(a[::-1], w)
        grad = 2.0 * r[n - 1:2 * n - 1]

        # Adam update
        t += 1
        m_arr = beta1 * m_arr + (1 - beta1) * grad
        v_arr = beta2 * v_arr + (1 - beta2) * grad ** 2
        m_hat = m_arr / (1 - beta1 ** t)
        v_hat = v_arr / (1 - beta2 ** t)

        # LR scales with T (larger T = bolder exploration)
        current_lr = lr_base * (0.5 + 0.5 * T_cur / T)

        a_new = a - current_lr * m_hat / (np.sqrt(v_hat) + eps)
        a_new = normalize(a_new, S)

        if not np.all(np.isfinite(a_new)):
            a_new = a.copy()
        a = a_new
        step += 1

        # Periodic score check
        if step % 150 == 0:
            cur_score = compute_score(a)
            if cur_score < best_score:
                best_score = cur_score
                best_a = a.copy()
                patience = 0
            else:
                patience += 150

            if verbose and step % 5000 == 0:
                print(f"      step={step}, T={T_cur:.4f}, cur={cur_score:.6f}, best={best_score:.6f}, t={elapsed:.1f}s")

        # Patience-based perturbation
        if patience >= stall_threshold:
            sigma = 0.05 + 0.1 * (T_cur / T)
            a = a * np.exp(rng.normal(0, sigma, n))
            a = normalize(a, S)
            patience = 0
            m_arr = np.zeros(n)
            v_arr = np.zeros(n)
            t = 0

    final_score = compute_score(a)
    if final_score < best_score:
        best_score = final_score
        best_a = a.copy()

    return best_a, best_score


def subgradient_polish(a0, time_budget, rng, verbose=False):
    """Subgradient descent targeting the true peak positions."""
    n = len(a0)
    S = np.sqrt(2.0 * n)
    a = normalize(a0.astype(np.float64).copy(), S)
    best_a = a.copy()
    best_score = compute_score(a)

    t0 = time.monotonic()
    step = 0

    while time.monotonic() - t0 < time_budget:
        c = fft_convolve(a, a)
        c_max = np.max(c)

        # Find significant peak positions
        threshold = c_max * (1.0 - 0.01)
        peak_mask = c >= threshold
        peak_indices = np.where(peak_mask)[0]

        # Compute subgradient (average over peaks)
        grad = np.zeros(n)
        for k in peak_indices:
            offsets = np.arange(n)
            diff = k - offsets
            valid = (diff >= 0) & (diff < n)
            if np.any(valid):
                grad[valid] += 2.0 * a[diff[valid]]
        grad /= len(peak_indices)

        # Adaptive step size
        lr = 0.02 / (1.0 + 0.002 * step)
        a_new = a - lr * grad
        a_new = normalize(a_new, S)
        a = a_new
        step += 1

        if step % 500 == 0:
            cur_score = compute_score(a)
            if cur_score < best_score:
                best_score = cur_score
                best_a = a.copy()
            if verbose:
                print(f"      subgrad step={step}, cur={cur_score:.6f}, best={best_score:.6f}")

    final_score = compute_score(a)
    if final_score < best_score:
        best_score = final_score
        best_a = a.copy()

    return best_a, best_score


def peak_reduction_moves(a0, time_budget, rng, verbose=False):
    """Targeted moves that reduce the peak by redistributing energy among contributing pairs."""
    n = len(a0)
    S = np.sqrt(2.0 * n)
    a = normalize(a0.astype(np.float64).copy(), S)
    best_a = a.copy()
    best_score = compute_score(a)

    t0 = time.monotonic()
    iterations = 0

    while time.monotonic() - t0 < time_budget:
        c = fft_convolve(a, a)
        peak_k = int(np.argmax(c))

        # Find contributing pairs (i, peak_k - i) for valid i
        valid_i = np.arange(max(0, peak_k - n + 1), min(n, peak_k + 1))
        if len(valid_i) == 0:
            break

        # Contributions: a[i] * a[peak_k - i]
        partners = peak_k - valid_i
        contribs = a[valid_i] * a[partners]

        # Target the top contributors: decrease the larger, increase the smaller
        top_idx = np.argsort(contribs)[::-1][:max(3, n // 16)]

        for idx in top_idx:
            i = valid_i[idx]
            j = partners[idx]
            if i == j:
                continue
            # Transfer energy from larger to smaller
            if a[i] > a[j]:
                source, target = i, j
            else:
                source, target = j, i
            delta = rng.uniform(0.02, 0.08) * a[source]
            trial = a.copy()
            trial[source] = max(0, trial[source] - delta)
            trial[target] = trial[target] + delta
            trial = normalize(trial, S)
            sc = compute_score(trial)
            if sc < best_score:
                best_score = sc
                best_a = trial.copy()
                a = trial

        # Also try random pair redistributions
        for _ in range(5):
            i = int(rng.integers(0, n))
            j = int(rng.integers(0, n))
            if i == j:
                continue
            delta = rng.uniform(-0.1, 0.1) * a[i]
            trial = a.copy()
            trial[i] = max(0, trial[i] - delta)
            trial[j] = max(0, trial[j] + delta)
            trial = normalize(trial, S)
            sc = compute_score(trial)
            if sc < best_score:
                best_score = sc
                best_a = trial.copy()
                a = trial

        # Occasionally perturb globally
        if rng.random() < 0.1:
            a = a * np.exp(rng.normal(0, 0.03, n))
            a = normalize(a, S)

        iterations += 1

    final_score = compute_score(a)
    if final_score < best_score:
        best_score = final_score
        best_a = a.copy()

    return best_a, best_score


def coordinate_descent_polish(a0, time_budget, rng, verbose=False):
    """Coordinate descent: sweep through coordinates, trying to improve each one."""
    n = len(a0)
    S = np.sqrt(2.0 * n)
    a = normalize(a0.astype(np.float64).copy(), S)
    best_a = a.copy()
    best_score = compute_score(a)

    t0 = time.monotonic()
    order = rng.permutation(n)
    sweep = 0

    while time.monotonic() - t0 < time_budget:
        for j in order:
            if time.monotonic() - t0 > time_budget:
                break

            base_val = a[j]
            if base_val < 1e-6:
                # Try increasing from near-zero
                candidates = [0.01 * S / n, 0.05 * S / n, 0.1 * S / n]
            else:
                candidates = [base_val * f for f in [0.3, 0.5, 0.7, 1.3, 1.5, 2.0]]
                candidates.append(0.0)

            best_local = best_score
            best_cand = a[j]

            for cand_val in candidates:
                trial = a.copy()
                trial[j] = cand_val
                trial = normalize(trial, S)
                sc = compute_score(trial)
                if sc < best_local:
                    best_local = sc
                    best_cand = cand_val

            if best_cand != a[j]:
                a = a.copy()
                a[j] = best_cand
                a = normalize(a, S)
                if best_local < best_score:
                    best_score = best_local
                    best_a = a.copy()

        sweep += 1
        order = rng.permutation(n)

    final_score = compute_score(a)
    if final_score < best_score:
        best_score = final_score
        best_a = a.copy()

    return best_a, best_score


def make_initialization(n, init_type, rng, alpha=0.5):
    """Create initial sequence with given structure."""
    t = np.arange(n, dtype=np.float64)
    if init_type == 'random':
        a = 1.0 + 0.4 * rng.standard_normal(n)
    elif init_type == 'chirp':
        a = 1.0 + alpha * np.cos(np.pi * t * t / n)
    elif init_type == 'multi_tone':
        a = np.ones(n)
        for k in range(1, 6):
            freq = rng.uniform(0.4, 2.5) * k
            phase = rng.uniform(0, 2 * np.pi)
            a += (0.2 / k) * np.cos(2 * np.pi * freq * t / n + phase)
    elif init_type == 'gaussian_bump':
        center = n / 2
        a = 1.0 + 0.6 * np.exp(-((t - center) ** 2) / (2 * (n / 4) ** 2))
    elif init_type == 'cosine':
        a = 1.0 + 0.3 * np.cos(2 * np.pi * t / n)
    elif init_type == 'sawtooth':
        a = 1.0 + 0.3 * (2 * (t / n - np.floor(t / n + 0.5)))
    else:
        a = np.ones(n)
    return np.clip(a, 0.01, None)


def resample_sequence(seq, new_n):
    """Resample sequence to new length via linear interpolation."""
    x_old = np.linspace(0, 1, len(seq))
    x_new = np.linspace(0, 1, new_n)
    return np.interp(x_new, x_old, seq)
