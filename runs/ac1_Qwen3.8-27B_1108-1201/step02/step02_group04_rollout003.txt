**Algorithm: Frank-Wolfe (conditional gradient) method**

The Frank-Wolfe method for minimizing a convex function f over a polytope P:
1. Start with x_0 in P
2. At each step:
   a. Compute s = argmin_{y in P} <grad f(x), y> (the "linear oracle")
   b. Take a step: x_new = (1-t) * x + t * s
   c. Choose step size t (e.g., 2/(k+2) or by line search)

For our problem:
- P = {a : sum(a) = 1, a >= 0} (the simplex)
- f(a) = max_k (a*a)[k] (or the smoothed version)

The gradient (or subgradient) of f at a is:
If we use the smoothed version f_smooth(a) = tau * log(sum_k exp((a*a)[k] / tau)):
grad f_smooth = (1/sum_k exp(conv[k]/tau)) * sum_k exp(conv[k]/tau) * grad conv[k]
= sum_k w_k * 2 * a_cross[k, :]

where w_k = exp(conv[k]/tau) / sum_j exp(conv[j]/tau) and a_cross[k, :] is the vector with entries 2*a[k-i] (the gradient of conv[k] w.r.t. a).

The linear oracle: minimize <grad, y> subject to y in simplex.
The minimum of a linear function over the simplex is achieved at a vertex: y = e_i where i = argmin_j grad[j].

So the Frank-Wolfe step is:
s = e_{argmin grad}
x_new = (1-t) * x + t * e_{argmin grad}

This means we're moving towards the coordinate with the smallest gradient! Intuitively, this makes sense: we want to increase the coordinate that most reduces the peak of the autocorrelation.

But this is a very "sparse" update - we're only changing one coordinate per step. This might be slow.

    n = len(a)

    scaled = conv / tau
    scaled -= scaled.max()

def project_simplex(v):
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u > (cssv - 1) / np.arange(1, n+1)
    rho = np.argmax(~cond)  # first index where condition fails
    # Actually, we want the last k where cond[k] is True
    # rho is the first index where cond is False
    theta = (cssv[rho-1] - 1) / rho if rho > 0 else 0.0
    # Wait, this is getting confusing. Let me use the standard formulation.
    
    # Standard: find rho = max{k : v_(k) > (sum_{i=1}^k v_(i) - 1) / k}
    # Then lambda = (sum_{i=1}^rho v_(i) - 1) / rho
    # proj(v)_i = max(v_i - lambda, 0)
    
    arange = np.arange(1, n+1, dtype=float)
    lam_candidates = (cssv - 1) / arange
    # We need the largest k such that u[k-1] > lam_candidates[k-1]
    valid = u > lam_candidates
    if not valid.any():
        return np.ones(n) / n
    rho = np.max(np.where(valid)[0]) + 1  # 1-indexed
    lam = (cssv[rho-1] - 1) / rho
    return np.maximum(v - lam, 0)
