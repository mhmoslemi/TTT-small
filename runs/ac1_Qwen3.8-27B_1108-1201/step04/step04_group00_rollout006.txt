This is a system of 2n-1 equations in n unknowns (with the constraint sum a_i = 1 and a_i >= 0). For n > 1, this is overdetermined, so we can't satisfy all equations exactly. The problem is to find the a that best satisfies them in a max-norm sense.

This is reminiscent of "frame" theory or "tight frames" in signal processing.

**Algorithm idea: Alternating minimization on the flatness constraint**

Define the "flatness error" at lag k: e_k = conv[k] - target, where target = 1/(2n-1) (or some other value).

We want to minimize max_k |e_k| or max_k e_k (since we only care about the peak).

**Practical approach**: I'll combine the following:
1. Smoothed subgradient descent with the log-sum-exp smoothing
2. Newton steps using the structure of the Hessian
3. Active set focusing
4. Multiple restarts

For the Newton method, the key computation is:
- Gradient of smooth max: g = sum_k w_k * 2 * B_k * a (this is a weighted sum of "shifted" versions of a)
- Hessian: H = (1/temp) * sum_k w_k * (2*B_k*a)(2*B_k*a)^T + 2*sum_k w_k * B_k

The Hessian H is an n×n matrix. For n=768, this is 768×768 = ~600K elements. We can form it explicitly.

Actually, let me compute the Hessian more carefully:
- (B_k * a)_i = a_{k-i} (if valid)
- So (2*B_k*a)(2*B_k*a)^T is a rank-1 matrix with entries 4*a_{k-i}*a_{k-j}
- sum_k w_k * 4*a_{k-i}*a_{k-j} = 4 * sum_k w_k * a_{k-i} * a_{k-j}

Let u_k = a_{k-i} and v_k = a_{k-j}. Then sum_k w_k * u_k * v_k is like a weighted correlation.

For the second term: 2*sum_k w_k * B_k has entries 2*w_{i+j} (if i+j < 2n-1).

So H_{i,j} = (1/temp) * 4 * sum_k w_k * a_{k-i}^+ * a_{k-j}^+ + 2 * w_{i+j}^+

where a_m^+ = a_m if 0<=m<n else 0, and w_m^+ = w_m if 0<=m<2n-1 else 0.

The first term can be computed as: for each k, the contribution to H is (4/temp) * w_k * (a_k)(a_k)^T where (a_k)_i = a_{k-i}^+. This is a sum of (2n-1) rank-1 matrices, each O(n²) to add. Total: O((2n-1)*n²) which for n=768 is about 1535 * 590000 ≈ 900M. That's too slow to do at every iteration.

Alternative: Use matrix-free Newton (GMRES with Hessian-vector products).

H * v = (1/temp) * 4 * sum_k w_k * (B_k * a) * (B_k * v) + 2 * (W * v)

where W is the Hankel matrix with W_{i,j} = w_{i+j}.

(B_k * a) is just a shifted/reversed version of a: (B_k * a)_i = a_{k-i}^+
(B_k * v)_i = v_{k-i}^+

So (H * v)_i = (4/temp) * sum_k w_k * a_{k-i}^+ * v_{k-i}^+ + 2 * sum_j w_{i+j}^+ * v_j

The first sum: for fixed i, sum over k of w_k * a_{k-i} * v_{k-i} (with bounds). Let m = k-i, then this is sum_m w_{m+i} * a_m * v_m (with appropriate bounds on m and m+i). This is like a weighted elementwise product summed... but the weight depends on m+i, so it's not just elementwise.

Actually, for fixed i: sum_k w_k * a_{k-i}^+ * v_{k-i}^+ = sum_{m: 0<=m<n, 0<=m+i<2n-1} w_{m+i} * a_m * v_m

This is (w_shifted * (a ⊙ v)) where ⊙ is elementwise and w_shifted depends on i. This is O(n) per i, so O(n²) total for the full H*v. That's 768² = 590K operations, which is fast!

For the second term: (W * v)_i = sum_j w_{i+j}^+ * v_j = sum_{j: 0<=i+j<2n-1} w_{i+j} * v_j

This is a correlation between w and v, which can be computed via FFT in O(n log n)!

So H*v can be computed in O(n log n) + O(n²) = O(n²) (dominated by the first term).

For n=768, O(n²) ≈ 600K operations per Hessian-vector product. With GMRES taking ~n iterations in the worst case (but typically much fewer for well-conditioned problems), this is feasible.

Actually, let me simplify. Instead of full Newton, let me use a **diagonal approximation** of the Hessian (like L-BFGS but just diagonal). The diagonal of H is:
H_{i,i} = (4/temp) * sum_k w_k * a_{k-i}^+² + 2 * w_{2i}^+

This can be computed in O(n * 2n) = O(n²) time, or faster with FFT.

Then use a diagonal-Newton (or "scaling BFGS") step:
d = -g / H_diag (elementwise division, with floor on H_diag)

This is equivalent to a gradient method with adaptive per-coordinate step sizes.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using smoothed Newton optimization
with active-set detection, adaptive per-coordinate scaling, and multi-length
exploration. Exploits the constant-Hessian structure of auto-convolution.
"""

import numpy as np
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def compute_smooth_grad_w(conv, temp, a):
    """
    Compute softmax weights and subgradient of smooth max.
    Returns (weights, subgradient) where subgradient is in R^n.
    """
    size = len(conv)
    n = len(a)
    shifted = conv / temp
    shifted -= shifted.max()
    w = np.exp(shifted)
    ws = w.sum()
    if ws < 1e-300:
        w = np.zeros(size)
        w[np.argmax(conv)] = 1.0
    else:
        w /= ws
    
    # Subgradient: sg[j] = 2 * sum_k w_k * a_{k-j} (with bounds)
    sg = np.zeros(n)
    for k in range(size):
        if w[k] < 1e-12:
            continue
        js = max(0, k - n + 1)
        je = min(n - 1, k)
        # a_{k-j} for j in [js, je]
        # a_{k-j}: when j=js, k-j = k-js; when j=je, k-j = k-je
        idx = np.arange(js, je + 1)
        sg[idx] += 2.0 * w[k] * a[k - idx]
    
    return w, sg


def smooth_newton_optimize(f0, time_limit, verbose=False):
    """
    Smoothed Newton-like optimization with adaptive temperature and
    per-coordinate scaling from the Hessian diagonal.
    """
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f0)) / len(f0)
    else:
        f = f / s
    n = len(f)
    
    conv = fast_convolve(f)
    M = conv.max()
    best_f = f.copy()
    best_M = M
    
    temp = M * 0.01  # initial temperature
    base_temp = M * 0.001
    lr = 0.1
    t0 = time.monotonic()
    it = 0
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        
        # Compute smooth gradient and weights
        w, sg = compute_smooth_grad_w(conv, temp, f)
        
        # Compute Hessian diagonal for scaling
        # H_jj = (4/temp) * sum_k w_k * a_{k-j}^2 + 2 * w_{2j}
        H_diag = np.full(n, 2.0 * w[2 * np.arange(n)] if 2 * (n - 1) < len(w) else 2.0 * np.zeros(n))
        # Wait, w has length 2n-1, and 2*j ranges from 0 to 2n-2, so w[2*j] is valid
        H_diag = 2.0 * w[2 * np.arange(n)]
        
        # Add the first term: (4/temp) * sum_k w_k * a_{k-j}^2
        for k in range(len(conv)):
            if w[k] < 1e-12:
                continue
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            vals = a[k - idx] if False else f[k - idx]  # fixed indices
            H_diag[idx] += (4.0 / temp) * w[k] * vals * vals
        
        # Scale the gradient
        H_diag = np.maximum(H_diag, 1e-10)
        step = sg / H_diag
        
        # Adaptive step size
        alpha = lr / (1.0 + 0.1 * it)
        f_new = f - alpha * step
        f_new = project_simplex(f_new)
        
        # Evaluate
        conv_new = fast_convolve(f_new)
        M_new = conv_new.max()
        
        if M_new < best_M - 1e-14:
            best_M = M_new
            best_f = f_new.copy()
            no_improve = 0
            f = f_new
            conv = conv_new
            # Decrease temp slowly
            temp = max(temp * 0.995, base_temp)
        else:
            no_improve += 1
            # Try smaller step
            if no_improve % 5 == 0:
                alpha *= 0.5
                f_new = f - alpha * step
                f_new = project_simplex(f_new)
                conv_new = fast_convolve(f_new)
                M_new = conv_new.max()
                if M_new < M:
                    f = f_new
                    conv = conv_new
                    M = M_new
                    if M < best_M:
                        best_M = M
                        best_f = f_new.copy()
                        no_improve = 0
            if no_improve > 30:

                temp = max(temp * 2.0, M * 0.05)
                no_improve = 0
                # Small perturbation
                rng = np.random.default_rng(it * 7 + 3)
                f = project_simplex(best_f + rng.standard_normal(n) * (lr * 0.01))
                conv = fast_convolve(f)
                M = conv.max()
        
        if verbose and it % 100 == 0:
            print(f"    SN iter {it}: M={M:.10f}, best={best_M:.10f}, temp={temp:.6f}")
    
    return best_f, best_M


def active_set_cd(f0, time_limit, top_k=10, verbose=False):
    """
    Coordinate descent focusing on the top_k active convolution lags.
    At each step, identify which coordinates contribute most to the active lags,
    and update those coordinates.
    """
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f0)) / len(f0)
    else:
        f = f / s
    n = len(f)
    
    conv = fast_convolve(f)
    M = conv.max()
    best_f = f.copy()
    best_M = M
    
    t0 = time.monotonic()
    it = 0
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        
        # Identify active lags
        k_actual = min(top_k, len(conv))
        active_k = np.argpartition(conv, -k_actual)[-k_actual:]
        active_k = active_k[np.argsort(conv[active_k])[::-1]]
        
        # Find coordinates that contribute to active lags
        # For lag k, coordinate j contributes if a_j * a_{k-j} is large
        # Focus on coordinates j where a_{k-j} is large (for some active k)
        contrib = np.zeros(n)
        for k in active_k:
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            contrib[js:je+1] += a[k-js:je+1-js+1] if False else f[k - np.arange(js, je+1)]
        
        # Get top contributing coordinates
        n_coords = min(20, n)
        top_coords = np.argpartition(contrib, -n_coords)[-n_coords:]
        
        # For each top coordinate, try to adjust it
        improved = False
        for j in top_coords:
            old_val = f[j]
            if old_val < 1e-10:
                continue
            
            best_jval = old_val
            best_jobj = M
            
            # Try multiplicative adjustments
            for mult in [0.5, 0.7, 0.85, 1.0, 1.15, 1.3, 1.5]:
                new_val = old_val * mult
                if new_val <= 0 or new_val >= 0.99:
                    continue
                f_trial = f.copy()
                f_trial[j] = new_val
                # Renormalize others to keep sum = 1
                remaining = 1.0 - new_val
                others_sum = f.sum() - old_val
                if others_sum < 1e-10:
                    continue
                mask = np.ones(n, dtype=bool)
                mask[j] = False
                f_trial[mask] *= remaining / others_sum
                
                conv_t = fast_convolve(f_trial)
                obj_t = conv_t.max()
                if obj_t < best_jobj - 1e-14:
                    best_jobj = obj_t
                    best_jval = new_val
                    f_trial_best = f_trial.copy()
            
            if best_jval != old_val:
                f = f_trial_best
                conv = fast_convolve(f)
                M = conv.max()
                improved = True
                if M < best_M - 1e-14:
                    best_M = M
                    best_f = f.copy()
                    no_improve = 0
        
        if not improved:
            no_improve += 1
            if no_improve > 20:
                # Perturb and retry
                rng = np.random.default_rng(it * 13 + 5)
                f = project_simplex(best_f + rng.standard_normal(n) * 0.002)
                conv = fast_convolve(f)
                M = conv.max()
                no_improve = 0
        
        if verbose and it % 50 == 0:
            print(f"    ASD iter {it}: M={M:.10f}, best={best_M:.10f}")
    
    return best_f, best_M


def subgradient_polish(f0, time_limit, verbose=False):
    """
    Fast subgradient polishing with temperature annealing and
    momentum. Uses top-k active lags for efficiency.
    """
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f0)) / len(f0)
    else:
        f = f / s
    n = len(f)
    
    conv = fast_convolve(f)
    M = conv.max()
    best_f = f.copy()
    best_M = M
    
    v = np.zeros(n)
    lr = 0.05
    mom = 0.9
    temp = M * 0.01
    top_k = max(5, n // 10)
    
    t0 = time.monotonic()
    it = 0
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        
        # Get top-k active lags
        k_actual = min(top_k, len(conv))
        peaks = np.argpartition(conv, -k_actual)[-k_actual:]
        
        # Compute weighted subgradient
        pv = conv[peaks]
        scaled = pv / temp
        scaled -= scaled.max()
        w = np.exp(scaled)
        w /= w.sum()
        
        sg = np.zeros(n)
        for i in range(len(peaks)):
            if w[i] < 1e-13:
                continue
            k = int(peaks[i])
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            sg[idx] += 2.0 * w[i] * f[k - idx]
        
        # Momentum update
        v = mom * v - lr * sg
        f_new = project_simplex(f + v)
        
        conv_new = fast_convolve(f_new)
        M_new = conv_new.max()
        
        if M_new < best_M - 1e-14:
            best_M = M_new
            best_f = f_new.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        f = f_new
        conv = conv_new
        M = M_new
        
        # Adaptive learning rate
        lr *= 0.9995
        temp *= 1.002
        
        if no_improve > 200:
            rng = np.random.default_rng((it * 31 + 7) % 1000000)
            f = project_simplex(best_f + rng.standard_normal(n) * 0.001)
            v = np.zeros(n)
            lr = max(0.02, lr * 2)
            conv = fast_convolve(f)
            M = conv.max()
            no_improve = 0
    
    return best_f, best_M


def interpolate_sequence(f, new_n):
    """Interpolate to new length using cosine taper."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp /= ss
    return f_interp
