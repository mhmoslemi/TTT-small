- `a` is not normalized
- `c = auto_conv(a)`
- `s = a.sum()`
- `obj = 2*n*max(c) / s^2`

When we change `a[i]` by `delta`:
- `c_new[k] = c[k] + 2*delta*a[k-i] + delta^2*[k=2i]`
- `s_new = s + delta`
- `obj_new = 2*n*max(c_new) / s_new^2`

This is clean! No renormalization needed during the search. We just need `s + delta > 0`.

Wait, I have a bug. When I apply the update:
- `a[i] = a_i + d_opt`
- But I also need to update `c` correctly.
- The formula `c[k_start:k_end] += 2.0 * d_opt * a_slice` uses `a_slice = a[0:n]` which is the OLD values (before updating `a[i]`). That's correct!
- Then `c[2*i] += d_opt * d_opt` adds the quadratic term. Also correct.
- But wait: `a_slice = a[0:n]` includes `a[i]` = `a_i` at position `i`. The term for `k=2i` uses `a[k-i] = a[i] = a_i`. So the linear update `2*d_opt*a_slice[i] = 2*d_opt*a_i` is already included in `c[k_start:k_end] += 2.0 * d_opt * a_slice`. Then we add `d_opt^2` on top. Total change at `k=2i`: `2*d_opt*a_i + d_opt^2` ✓.

But there's another issue: after the update, `s` changes from 1 to `1 + d_opt`. The convolution `c` now corresponds to the new (unnormalized) `a`. Next time we do a coordinate step, we use this new `c` and `s`.

Actually, I think it's cleaner to renormalize after each sweep (not after each coordinate step). This keeps `s = 1` for most of the time and avoids the scaling complexity.

Let me simplify: Don't renormalize during a sweep, but renormalize at the end of each sweep.

Actually, even simpler: just renormalize after each coordinate step. The cost is O(n) which is negligible.

Let me also reconsider: the rank-1 update trick gives us O(n) per evaluation in the golden section. With 18 iterations of golden section, that's 18*O(n) = O(18n) per coordinate. For n=368, that's about 6600 ops per coordinate, 368*6600 ≈ 2.4M ops per sweep. At ~1ns per op, that's 2.4ms per sweep. In 1800s, we can do ~750,000 sweeps!

That's way more than enough. The bottleneck will be convergence, not speed.

Now, the question is: will coordinate descent converge to the global optimum? Probably not, but it should get very close to a good local optimum. The key is to:
1. Start from a good initialization
2. Use random coordinate ordering (to avoid cycles)
3. Periodically try different starting points

Let me now think about the L-BFGS approach as a complement:

For L-BFGS, I'll use the softmax parameterization:
- `a = exp(theta) / sum(exp(theta))`
- Minimize `f(theta) = 2*n*max(auto_conv(softmax(theta)))` — but this isn't smooth

Use smoothing: `f_T(theta) = 2*n*T*log(sum(exp(c[k]/T)))` where `c = auto_conv(softmax(theta))`

For small T, this is close to the true objective. We can anneal T.

The gradient computation is as I derived earlier. Let me implement it cleanly.

Actually, for L-BFGS, I'll just use `scipy.optimize.minimize` with the `L-BFGS-B` method on the original variables with bounds `[0, None]` and a penalty for the sum constraint. Or better, use the softmax parameterization.

Let me now write the complete solution:

"""
Multi-method optimizer: coordinate descent with rank-1 updates + L-BFGS polishing
for minimizing 2*n*max(auto_conv(a))/(sum(a))^2.
"""
import numpy as np
from scipy.optimize import minimize, linprog
import time

def fast_conv(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def obj_normalized(a):
    """Objective for normalized (sum=1) array: 2*n*max(c)."""
    n = len(a)
    return 2.0 * n * fast_conv(a).max()

def normalize(a):
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s

def coord_descent(a, time_limit, rng, verbose=False):
    """
    Coordinate descent with golden section and rank-1 conv updates.
    Works with unnormalized a; tracks s = sum(a).
    """
    a = np.maximum(a.astype(np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a))
        s = float(len(a))
    n = len(a)
    
    c = fast_conv(a)
    c_max = c.max()
    best_obj = 2.0 * n * c_max / (s * s)
    best_a = a.copy()
    
    t0 = time.monotonic()
    sweep = 0
    stall = 0
    
    while time.monotonic() - t0 < time_limit:
        sweep += 1
        improved = False
        order = list(range(n))
        rng.shuffle(order)
        
        for i in order:
            if time.monotonic() - t0 > time_limit:
                break
            
            a_i = a[i]
            
            # Delta range: delta >= -a_i (to keep a[i] >= 0), delta > -s (to keep s > 0)
            d_lo = max(-a_i, -s + 1e-10) + 1e-12
            d_hi = max(0.01, min(0.5, 3.0 * a_i + 0.005))
            if d_hi <= d_lo:
                d_hi = d_lo + 0.001
            
            # Precompute for fast evaluation
            k_start = i
            k_end = min(i + n, 2 * n - 1)
            a_slice = a[0:n].copy()  # a[k-i] for k in [k_start, k_end-1]
            c_base = c[k_start:k_end].copy()
            
            # Max outside affected range
            max_out = 0.0
            if k_start > 0:
                max_out = max(max_out, float(c[:k_start].max()))
            if k_end < len(c):
                max_out = max(max_out, float(c[k_end:].max()))
            
            two_n = 2.0 * n
            
            def eval_d(d):
                if a_i + d < -1e-15 or s + d < 1e-10:
                    return np.inf
                new_c = c_base + 2.0 * d * a_slice
                idx_self = 2 * i - k_start
                if 0 <= idx_self < len(new_c):
                    new_c[idx_self] += d * d
                s_new = s + d
                return two_n * max(new_c.max(), max_out) / (s_new * s_new)
            
            # Golden section
            gr = 0.6180339887498949
            x1 = (1.0 - gr) * (d_hi - d_lo) + d_lo
            x2 = gr * (d_hi - d_lo) + d_lo
            f1 = eval_d(x1)
            f2 = eval_d(x2)
            
            for _ in range(20):
                if f1 < f2:
                    d_hi = x2
                    x2, f2 = x1, f1
                    x1 = (1.0 - gr) * (d_hi - d_lo) + d_lo
                    f1 = eval_d(x1)
                else:
                    d_lo = x1
                    x1, f1 = x2, f2
                    x2 = gr * (d_hi - d_lo) + d_lo
                    f2 = eval_d(x2)
            
            d_opt = (d_lo + d_hi) / 2.0
            f_opt = eval_d(d_opt)
            
            cur_obj = two_n * c_max / (s * s)
            if f_opt < cur_obj - 1e-13:
                # Apply update
                a[i] = a_i + d_opt
                c[k_start:k_end] += 2.0 * d_opt * a_slice
                idx_self = 2 * i
                c[idx_self] += d_opt * d_opt
                s = s + d_opt
                c_max = c.max()
                if f_opt < best_obj:
                    best_obj = f_opt
                    best_a = a.copy()
                improved = True
        
        if improved:
            stall = 0
        else:
            stall += 1
            if stall > 3:
                # Restart from best with noise
                a = best_a + rng.standard_normal(n) * 0.002
                a = np.maximum(a, 0)
                s = a.sum()
                if s < 1e-15:
                    break
                c = fast_conv(a)
                c_max = c.max()
                best_obj = 2.0 * n * c_max / (s * s)
                stall = 0
            elif stall == 2:
                # Reduce range
                pass
    
    return normalize(best_a), best_obj

def lbfgs_smooth(a0, time_limit, T_init=0.002, T_min=0.0001, verbose=False):
    """L-BFGS on softmax-parameterized smoothed objective."""
    a = normalize(a0.astype(np.float64))
    n = len(a)
    
    # Initialize theta from a
    theta = np.log(a + 1e-30)
    
    best_obj = obj_normalized(a)
    best_a = a.copy()
    
    T = T_init
    t0 = time.monotonic()
    
    while time.monotonic() - t0 < time_limit:
        def obj_grad(theta):
            # softmax
            t_max = theta.max()
            a_s = np.exp(theta - t_max)
            a_s /= a_s.sum()
            
            c = fast_conv(a_s)
            c_shift = c / T - (c / T).max()
            w = np.exp(c_shift)
            w_s = w.sum()
            p = w / w_s
            
            obj = T * np.log(w_s) + c.max()  # = T * log(sum(exp(c/T)))
            obj = 2.0 * n * obj
            
            # Gradient w.r.t. a: dF/da[i] = 2 * sum_k p[k] * dc[k]/da[i]
            # dc[k]/da[i] = 2*a[k-i] for 0<=k-i<n (as derived)
            # So dF/da[i] = 4 * sum_{k: 0<=k-i<n} p[k] * a[k-i]
            # = 4 * (cross_corr(a, p))[i]
            
            # Cross-correlation via FFT
            fft_size = 1 << (3 * n).bit_length()
            A_ft = np.fft.rfft(a_s, fft_size)
            P_ft = np.fft.rfft(p, fft_size)
            cross = np.fft.irfft(np.conj(A_ft) * P_ft, fft_size)[:n]
            
            dF_da = 4.0 * cross
            
            # Chain rule: dF/dtheta[j] = a_s[j] * (dF_da[j] - sum(a_s * dF_da))
            mean_g = np.dot(a_s, dF_da)
            grad = a_s * (dF_da - mean_g)
            
            return obj, grad
        
        # Run L-BFGS for a few iterations
        t_sub = min(60.0, time_limit - (time.monotonic() - t0))
        if t_sub < 5:
            break
        
        res = minimize(obj_grad, theta, method='L-BFGS-B',
                      options={'maxiter': 200, 'maxfun': 500,
                               'maxls': 50, 'maxcor': 20})
        
        # Evaluate result
        t_max = res.x.max()
        a_new = np.exp(res.x - t_max)
        a_new /= a_new.sum()
        new_obj = obj_normalized(a_new)
        
        if new_obj < best_obj:
            best_obj = new_obj
            best_a = a_new.copy()
            theta = res.x.copy()
            if verbose:
                print(f"    L-BFGS: obj={best_obj:.8f}, T={T:.6f}")
        
        # Anneal T
        T = max(T * 0.8, T_min)
        
        if T == T_min and new_obj >= best_obj:
            # Try one more time with smaller step
            break
    
    return best_a, best_obj

def gen_inits(n, parent, rng):
    """Generate diverse initializations."""
    inits = []
    
    # Uniform
    inits.append(np.ones(n) / n)
    
    # Edge-heavy (U-shape)
    x = np.arange(n, dtype=np.float64)
    edge = 1.0 / (np.minimum(x, n - 1 - x) + 1.0)
    inits.append(edge / edge.sum())
    
    # Two humps
    h1 = np.exp(-0.5 * ((x - 0.2 * n) / (0.15 * n)) ** 2)
    h2 = np.exp(-0.5 * ((x - 0.8 * n) / (0.15 * n)) ** 2)
    inits.append((h1 + h2) / (h1 + h2).sum())
    
    # Center hump
    h = np.exp(-0.5 * ((x - 0.5 * n) / (0.2 * n)) ** 2)
    inits.append(h / h.sum())
    
    # Cosine
    c = np.abs(np.cos(np.pi * x / n)) + 0.1
    inits.append(c / c.sum())
    
    # Random Dirichlet
    inits.append(rng.dirichlet(np.ones(n) * 0.5))
    
    # Mirror symmetric random
    half = rng.dirichlet(np.ones(n // 2) * 0.5)
    sym = np.concatenate([half, half[::-1]])
    inits.append(sym / sym.sum())
    
    # Parent interpolation
    if parent is not None:
        px = np.interp(np.linspace(0, 1, n), np.linspace(0, 1, len(parent)), parent)
        inits.append(normalize(px))
        # Blended
        inits.append(normalize(0.7 * inits[-1] + 0.3 * np.ones(n) / n))
    
    return inits
