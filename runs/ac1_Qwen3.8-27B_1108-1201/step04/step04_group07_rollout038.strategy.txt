## Approach and Rationale
We will use an evolutionary strategy with fitness sharing to minimize the objective function. The key idea is to represent sequences in multiplicative form by a base vector and a scalar \( w \), i.e., candidate_sequence = w * (project_simplex(base_vector + random_noise) / sum(project_simplex(base_vector + random_noise))^{n-1}) \).

This approach maintains several base sequences of fixed lengths and explores combinations of them during crossover. The defense against dropping below the coefficient cap is handled during local search, but we focus on improving the peak amplitude of the autocorrelation function near the center by:

1. Starting with a uniform distribution and offset adjustments
2. Using perceptron-like filters to model pulse response
3. Applying a "ridge push" transformation to eliminate negative values and large peaks
4. Optimizing over multiple orders and transition strengths

The core innovation compared to the parent program is the state-specific memory queue of base sequences and the slowed cooling schedule that prioritizes center-edge transitions.

## Mathematical Specification
We define the sequence space as:

1. `x`: Sequence of `n` coefficients
2. `norm(x)`: Normalized sum of `x` = 1
3. `clip(x)`: Each coefficient capped at [0, 1000]
4. `energy(x)`: Convolution max divided by sum(x)^2 = energy metric
5. `jump_strength`: Learning rate multiplier for Frank-Wolfe steps (ranging from 0 to 1)
6. `temperature`: Variable to control current search aggression (initialized to 1, decreased over time)

### Objective Analysis
We minimize: -2.3 * jump_strength * temperature + (energy(clip(x)))/(temperature + 0.2)

### Distance Matrix Projection
We build a pairwise distance matrix between sequences allowing faster combinatorial operations:

`d(i, j) = abs(energy(clip(x_i)) - energy(clip(x_j))) + abs(len(x_i) - len(x_j))/100`
