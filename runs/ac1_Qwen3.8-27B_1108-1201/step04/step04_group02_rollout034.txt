```python
def compute_grad_fast(a, w):
    """Compute grad[i] = 2 * sum_j a[j] * w[i+j] using FFT."""
    n = len(a)
    N = 1 << (3*n - 2 - 1).bit_length()
    A = np.fft.rfft(a, N)
    W = np.fft.rfft(w, N)
    corr = np.fft.irfft(A * np.conj(W), N)
    return 2.0 * corr[:n]
```

This is O(N log N) ≈ O(n log n) which is much better than O(n^2).

**Coordinate descent on the simplex (with proportional rescaling of the rest):**

For coordinate i:
- Current: a[i] = x, rest sums to 1-x
- New: a[i] = x', rest scaled by (1-x')/(1-x)
- This changes the convolution in a complicated way

Alternative: **Free coordinate descent (no sum constraint during optimization)**

Since the problem is scale-invariant, I can:
1. Start with a on the simplex
2. Do coordinate descent to minimize max(conv(a)) with a >= 0 (no sum constraint)
3. The result will have sum close to 1 (since we started there and the objective is scale-invariant, the optimizer won't change the scale much)
4. Normalize at the end

For the free coordinate descent:
- For coordinate i, the 1D subproblem is:
  min_{x >= 0} max(C, {conv[k] + 2*(x - a_i)*a[k-i]} for k in [i, i+n-1], k≠2i,

This is a convex 1D problem solvable by golden section search.

The cost per coordinate: O(n * log(1/eps)) for the golden section search (each evaluation is O(n) to compute the max of n values).
Total cost per pass: O(n^2 * log(1/eps)) ≈ O(n^2 * 20) for n=384: about 2.9M operations per pass. Very fast!

```python
def coordinate_descent(a_init, n_passes=20, tol=1e-12):
    """
    Coordinate descent to minimize max(conv(a)) with a >= 0.
    1D subproblem solved by golden section search.
    """
    n = len(a_init)
    a = np.maximum(a_init.copy(), 0.0)
    # Don't normalize - work freely
    conv = fast_convolve(a)
    
    for p in range(n_passes):
        max_change = 0.0
        for i in range(n):
            ai = a[i]
            if ai < 1e-15 and conv.max() < 1e-15:
                continue
            
            # Affected range: k in [i, min(2n-2, i+n-1)]
            k_lo = i
            k_hi = min(2*n-2, i+n-1)
            
            # Unaffected max
            if k_lo > 0:
                C = np.max(conv[:k_lo])
            else:
                C = 0.0
            if k_hi < 2*n-2:
                C = max(C, np.max(conv[k_hi+1:]))
            
            # Affected conv values
            affected_k = np.arange(k_lo, k_hi+1)
            # a[k-i] for k in affected_k
            a_vals = a[affected_k - i]  # length = k_hi - k_lo + 1
            old_conv = conv[k_lo:k_hi+1].copy()
            
            two_i = 2*i
            has_quad = (k_lo <= two_i <= k_hi)
            quad_idx = two_i - k_lo if has_quad else -1
            
            def f_1d(x):
                # New affected conv values
                new_vals = old_conv + 2.0 * (x - ai) * a_vals
                if has_quad:
                    new_vals[quad_idx] = old_conv[quad_idx] - ai*ai + x*x
                return max(C, np.max(new_vals))
            
            # Golden section search for minimum of f_1d on [0, x_hi]
            x_hi_bound = max(ai * 2, 1.0/n) * 2  # generous upper bound
            
            # First, check if boundary is optimal
            f0 = f_1d(0.0)
            fmid = f_1d(x_hi_bound / 2)
            fhi = f_1d(x_hi_bound)
            
            if f0 <= fmid and f0 <= fhi:
                x_opt = 0.0
            elif fhi <= fmid and fhi <= f0:
                x_opt = x_hi_bound
            else:
                # Golden section in [0, x_hi_bound]
                gr = (np.sqrt(5.0) - 1.0) / 2.0
                xa = x_hi_bound * (1.0 - gr)
                xb = x_hi_bound * gr
                fa = f_1d(xa)
                fb = f_1d(xb)
                lo, hi = 0.0, x_hi_bound
                for _ in range(60):
                    if hi - lo < 1e-14:
                        break
                    if fa < fb:
                        hi = xb
                        xb = xa
                        fb = fa
                        xa = hi - gr * (hi - lo)
                        fa = f_1d(xa)
                    else:
                        lo = xa
                        xa = xb
                        fa = fb
                        xb = lo + gr * (hi - lo)
                        fb = f_1d(xb)
                x_opt = (lo + hi) / 2.0
            
            # Apply update
            a[i] = x_opt
            max_change = max(max_change, abs(x_opt - ai))
            
            # Update conv in place
            conv[k_lo:k_hi+1] = old_conv + 2.0 * (x_opt - ai) * a_vals
            if has_quad:
                conv[two_i] = old_conv[quad_idx] - ai*ai + x_opt*x_opt
        
        # Periodically recompute conv for numerical accuracy
        if p % 5 == 4:
            conv = fast_convolve(a)
    
    return a
```
