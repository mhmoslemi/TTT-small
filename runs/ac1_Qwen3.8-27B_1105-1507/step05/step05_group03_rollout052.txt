Let me think of a simpler improvement: **Reduced LP**

At any point in the iteration, only a subset of constraints are "important" - those where (a*a)[k] is close to M. We can solve a reduced LP with only these constraints, get a candidate g, verify it satisfies the full constraints, and if not, add the violated constraints.

This is the "cutting plane" or "constraint generation" approach.

Algorithm:
1. Start with a small set of constraints S (e.g., the top 20 values of (a*a)[k])
2. Solve LP with only constraints in S
3. Check if the solution g satisfies ALL constraints
4. If not, add the most violated constraint to S and goto 2
5. If yes, g is optimal for the full LP

This should be much faster than solving the full LP every time!

```python
"""
Minimizes J(a) = 2*n*max(conv(a,a))/(sum(a))^2 using:
1. LP mirror descent with cutting-plane (active set) LP solving
2. FFT-accelerated gradient computation for smooth methods
3. Multi-length exploration with smart resampling
4. Adaptive perturbation restarts
5. Final extended LP polish with warm-start approximation
"""

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
from scipy.signal import fftconvolve
import time


def fast_conv(a):
    """Full self-convolution via FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]


def cross_conv(a, b):
    """Cross-convolution of a and b via FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:2 * n - 1]


def compute_M(a):
    """Compute max of self-convolution."""
    return float(fast_conv(a).max())


def compute_J(a):
    """Compute J(a) = 2*n*max(conv(a,a))/(sum(a))^2."""
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))


def solve_lp_cutting_plane(a, M, max_constraints=200, max_rounds=20, time_limit=5.0):
    """
    Solve LP: max 1^T g s.t. (a@g)[k] <= M for all k, g >= 0
    Using cutting plane (constraint generation) approach.
    """
    n = len(a)
    t0 = time.monotonic()
    
    # Start with the most important constraints
    conv_a = fast_conv(a)
    # Sort by value, take top constraints
    top_k = np.argsort(conv_a)[::-1][:max_constraints]
    
    active_set = set(top_k.tolist())
    g = None
    
    for round_num in range(max_rounds):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Build constraint matrix for active set
        rows = []
        cols = []
        vals = []
        for k in sorted(active_set):
            j_min = max(0, k - n + 1)
            j_max = min(n - 1, k)
            for j in range(j_min, j_max + 1):
                rows.append(k)
                cols.append(j)
                vals.append(a[k - j])
        
        A = csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
        c = -np.ones(n)
        b_ub = np.full(2 * n - 1, M)
        bounds = [(0, None)] * n
        
        try:
            r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                        options={'time_limit': max(1, time_limit - (time.monotonic() - t0)),
                                 'presolve': True})
            if r.success and r.x is not None:
                g = np.maximum(r.x, 0)
                if g.sum() < 1e-15:
                    return None
            else:
                return None
        except Exception:
            return None
        
        # Check if g satisfies ALL constraints
        ag = cross_conv(a, g)
        violated = np.where(ag > M + 1e-10)[0]
        
        if len(violated) == 0:
            return g
        
        # Add most violated constraints
        violation_amounts = ag[violated] - M
        n_add = min(20, len(violated))
        worst = violated[np.argsort(violation_amounts)][::-1][:n_add]
        active_set.update(worst.tolist())
    
    # If we ran out of rounds, return the best g we have
    # (it might violate some constraints, but the line search will handle it)
    if g is not None:
        return g
    return None
```

The smoothed objective is:

This is smooth for tau > 0, and as tau -> infinity, it approaches max_k (a*a)[k].

We can optimize this with L-BFGS, using the fact that:
- The gradient can be computed in O(n log n) using FFT
- The Hessian (or at least a Lipschitz constant) can be bounded

The challenge is that we need to increase tau over time to approach the true max. This is similar to the "continuation method."

Algorithm:
1. Start with small tau (smooth)
2. Use L-BFGS to minimize f_tau(a) subject to a >= 0, sum(a) = 1
3. Increase tau
4. Repeat

Alternatively, we can use the **mirror descent** approach directly on the simplex with the smoothed objective. The Bregman divergence for the simplex with entropy is the KL divergence.

Mirror descent on the simplex:
a_{t+1} = argmin_{a in simplex} { <grad_t, a> + (1/eta) * KL(a || a_t) }

The solution has the form:
a_{t+1}[j] = a_t[j] * exp(-eta * grad_t[j]) / Z

where Z = sum_j a_t[j] * exp(-eta * grad_t[j])

This is a multiplicative! weight update, which is efficient.

**Algorithm: Smoothed Mirror Descent with Continuation**

1. Initialize a (from parent or random)
2. For tau in [tau_0, tau_1, ..., tau_T] (increasing):

      ii. Compute p = softmax(tau * c)
      iii. Compute grad = cross_correlation(p, a) via FFT
      iv. Compute a_new = a * exp(-eta * grad) / sum(a * exp(-eta * grad))
      v. If objective decreased, accept; else reduce eta and retry
   b. Record best a found
3. Return best a

The continuation schedule: start with small tau (very smooth, easy to optimize) and increase to large tau (approaches the true max).

For tau -> infinity, the softmax concentrates on the argmax, and we recover the standard subgradient method for the max function.

This approach has several advantages:
- Very fast per iteration (O(n log n))
- Naturally handles the simplex constraint
- Smooth, so we can use good step sizes
- The continuation handles the non-smoothness of the max

Let me think about the step size. For the mirror descent on the simplex with the KL divergence, the theoretical step size is eta = sqrt(2 * log(n) / (L * T)) where L is the Lipschitz constant of the gradient and T is the total number of iterations.

The Lipschitz constant of the gradient of f_tau is related to tau and the structure of the convolution. For our problem, it's roughly O(tau * n) (since the convolution matrix has entries bounded by 1 and n entries per row).

In practice, we can use a backtracking line search: try eta, if the objective increases, halve eta.

Actually, for mirror descent, the standard step size is eta_t = c / sqrt(t) for some constant c. Let me use this.

Let me also think about the number of iterations. With n=512 and O(n log n) per iteration, each iteration takes maybe 1-5 ms (including the FFT). So in 1500 seconds, we can do maybe 100K-500K iterations. That should be more than enough.

But we also need to increase tau over time. Let's say we use 10 different tau values, each with 10K iterations. Total: 100K iterations, which should take a few minutes.

Let me also add the LP mirror descent as a refinement step, since it has stronger theoretical guarantees.

"""
Minimizes J(a) = 2*n*max(conv(a,a))/(sum(a))^2 using:
1. FFT-accelerated smoothed mirror descent with continuation (main workhorse)
2. LP mirror descent with cutting-plane constraint generation
3. Multi-length exploration
4. Perturbation-based restarts
5. Final LP polish
"""

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time


def fast_conv(a):
    """Full self-convolution via FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]


def cross_conv(a, b):
    """Cross-convolution of a and b via FFT."""
    n_a = len(a)
    n_b = len(b)
    size = 1
    while size < n_a + n_b - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:n_a + n_b - 1]


def compute_M(a):
    """Compute max of self-convolution."""
    return float(fast_conv(a).max())


def compute_J(a):
    """Compute J(a) = 2*n*max(conv(a,a))/(sum(a))^2."""
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))


def smoothed_gradient(a, tau):
    """
    Compute gradient of f_tau(a) = (1/tau) log(sum_k exp(tau*(a*a)[k])).
    Uses FFT for O(n log n) complexity.
    """
    n = len(a)
    c = fast_conv(a)
    c_max = c.max()
    exp_c = np.exp(tau * (c - c_max))
    p = exp_c / exp_c.sum()
    
    # grad[j] = sum_m a[m] * p[j+m] for j=0,...,n-1
    # = conv(a_flipped, p)[j + n - 1]
    a_flipped = a[::-1]
    size = 1
    while size < 3 * n - 2:
        size <<= 1
    conv_result = np.fft.irfft(np.fft.rfft(a_flipped, size) * np.fft.rfft(p, size), size)
    grad = conv_result[n - 1: 2 * n - 1]
    
    return grad


def run_smoothed_mirror_descent(a, max_iters, deadline, tau_start=1.0, tau_end=200.0, 
                                 eta_start=0.1, eta_end=0.01, verbose=False):
    """
    Smoothed mirror descent with continuation on tau.
    a is the initial sequence (will be normalized).
    Returns optimized sequence (normalized to sum 1).
    """
    a = np.maximum(a.astype(np.float64), 1e-15)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_M = compute_M(a)
    
    # Adaptive step size
    eta = eta_start
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        # Continuation: linearly interpolate tau
        frac = it / max(1, max_iters)
        # Use sqrt schedule for smoother transition
        tau = tau_start + (tau_end - tau_start) * (frac ** 0.7)
        # Step size decreases over time
        eta = eta_start + (eta_end - eta_start) * frac
        
        # Compute gradient
        grad = smoothed_gradient(a, tau)
        
        # Mirror descent update: a_new = a * exp(-eta * grad) / Z
        log_updates = -eta * grad
        # Clip for numerical stability
        log_updates = np.clip(log_updates, -50, 50)
        updates = np.exp(log_updates)
        a_new = a * updates
        Z = a_new.sum()
        if Z < 1e-30:
            break
        a_new = a_new / Z
        
        # Check improvement
        M_new = compute_M(a_new)
        if M_new < best_M * (1 - 1e-12):
            best_M = M_new
            best_a = a_new.copy()
        a = a_new
        
        if verbose and it % 1000 == 0:
            print(f"      iter {it}: tau={tau:.1f} eta={eta:.4f} M={M_new:.10f} best_M={best_M:.10f}", flush=True)
    
    return best_a


def solve_lp_full(a, M, time_limit=5.0):
    """Solve the full LP: max 1^T g s.t. (a@g)[k] <= M, g >= 0."""
    n = len(a)
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        j_min = max(0, k - n + 1)
        j_max = min(n - 1, k)
        for j in range(j_min, j_max + 1):
            rows.append(k)
            cols.append(j)
            vals.append(a[k - j])
    
    A = csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    
    try:
        r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                    options={'time_limit': time_limit, 'presolve': True})
        if r.success and r.x is not None:
            g = np.maximum(r.x, 0)
            if g.sum() > 1e-15:
                return g
    except Exception:
        pass
    return None


def solve_lp_cutting(a, M, initial_constraints=100, max_rounds=30, time_limit=5.0):
    """
    Solve LP using cutting plane (constraint generation).
    Start with top constraints, add violated ones iteratively.
    """
    n = len(a)
    t0 = time.monotonic()
    
    conv_a = fast_conv(a)
    top_k = np.argsort(conv_a)[::-1][:initial_constraints]
    active_set = set(top_k.tolist())
    g = None
    
    for rd in range(max_rounds):
        if time.monotonic() - t0 > time_limit:
            break
        
        rows = []
        cols = []
        vals = []
        for k in sorted(active_set):
            j_min = max(0, k - n + 1)
            j_max = min(n - 1, k)
            for j in range(j_min, j_max + 1):
                rows.append(k)
                cols.append(j)
                vals.append(a[k - j])
        
        n_rows = len(rows)
        if n_rows == 0:
            continue
        
        A = csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
        c_vec = -np.ones(n)
        b_ub = np.full(2 * n - 1, M)
        bounds = [(0, None)] * n
        
        remaining = max(1.0, time_limit - (time.monotonic() - t0))
        try:
            r = linprog(c_vec, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                        options={'time_limit': remaining, 'presolve': True})
            if r.success and r.x is not None:
                g = np.maximum(r.x, 0)
                if g.sum() < 1e-15:
                    return None
            else:
                return None
        except Exception:
            return None
        
        # Check all constraints
        ag = cross_conv(a, g)
        violated = np.where(ag > M * (1 + 1e-9) + 1e-12)[0]
        
        if len(violated) == 0:
            return g
        
        # Add most violated
        violations = ag[violated] - M
        n_add = min(50, len(violated))
        worst_idx = violated[np.argsort(violations)][::-1][:n_add]
        active_set.update(worst_idx.tolist())
    
    return g


def line_search_analytic(a, g):
    """
    Find best t in [0,1] minimizing max_k ((1-t)*a + t*g)^2_k.
    Both a and g must be normalized to sum 1.
    """
    A = fast_conv(a)
    B = cross_conv(a, g)
    C = fast_conv(g)

    a_coef = A
    b_coef = 2.0 * (B - A)
    c_coef = C - 2.0 * B + A

    lo = 0.0
    hi = 1.0
    for _ in range(50):
        m1 = lo + (hi - lo) / 3.0
        m2 = hi - (hi - lo) / 3.0
        f1 = np.max(a_coef + b_coef * m1 + c_coef * m1 * m1)
        f2 = np.max(a_coef + b_coef * m2 + c_coef * m2 * m2)
        if f1 < f2:
            hi = m2
        else:
            lo = m1

    t = (lo + hi) / 2.0
    t = max(0.0, min(1.0, t))
    best_val = float(np.max(a_coef + b_coef * t + c_coef * t * t))
    return t, best_val

def resample_seq(src, dest_n):
    """Resample 1D sequence to new length via linear interpolation."""
    src = np.asarray(src, dtype=np.float64)
    if src.size == dest_n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, dest_n)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)
