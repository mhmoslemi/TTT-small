**Key new idea: "Peak surgery"**

Instead of trying to reduce the overall peak, let's do "surgery" on specific peaks:

1. Find all lags where conv(a,a)[k] > threshold (e.g., 1.1 * mean).
2. For each such lag k, compute the "excess" = conv(a,a)[k] - target.
3. Find the pair (i, j) with i+j=k that has the largest product a[i]*a[j].
4. Reduce a[i] and a[j] slightly, and distribute the mass to positions that don't contribute to any peak.

**Another idea: "Compressive sensing" style**

The convolution has 2n-1 values but is determined by only n parameters. So there's a lot of redundancy. We can exploit this:

1. Start with a uniform sequence.
2. At each step, find the "most constraining" convolution lag.
3. Find the minimum-norm adjustment to a that reduces the peak at that lag.
4. This is a quadratic program: min ||delta||^2 s.t. (a+delta * a + a * delta)[k*] <= target, sum(delta) = 0, a+delta >= 0.

The constraint (a+delta*a + a*delta)[k*] = (a*a)[k*] + 2*sum_i a[i]*delta[k*-i] (approximately, ignoring delta*delta terms).

So we want: sum_i a[i]*delta[k*-i] <= (target - (a*a)[k*])/2

This is a linear constraint on delta! So the QP is:
min ||delta||^2 s.t. c^T delta <= b, sum(delta) = 0, delta >= -a

This can be solved efficiently!

Let me formalize this:

**QP Peak Reduction:**
- Given current a, peak at lag k* with value V = (a*a)[k*].
- Target: reduce V to V*(1-epsilon) for some small epsilon.
- Solve: min 0.5*||delta||^2 s.t. sum_i a[i]*delta[k*-i] <= -epsilon*V/2, sum(delta) = 0, a+delta >= 0.

The constraint sum_i a[i]*delta[k*-i] can be written as:
sum_i a[k*-i]*delta[i] (where a[k*-i] is defined as 0 if k*-i is out of range)

Let w[i] = a[k*-i] if 0 <= k*-i < n, else 0.
Then the constraint is: w^T delta <= -epsilon*V/2.

The QP is:
min 0.5 * delta^T delta
s.t. w^T delta <= -epsilon*V/2
     1^T delta = 0
     delta >= -a

This can be solved with scipy.optimize.minimize or even analytically (it's a quadratic program with simple constraints).

```python
def qp_peak_reduction(a, k_star, epsilon=0.1):
    """Solve QP to reduce the peak at lag k_star."""
    n = len(a)
    conv = compute_conv(a)
    V = conv[k_star]
    
    # Weights for the linear constraint
    w = np.zeros(n)
    for i in range(n):
        j = k_star - i
        if 0 <= j < n:
            w[i] = a[j]
    
    # QP: min 0.5*delta^T*delta s.t. w^T*delta <= -eps*V/2, sum(delta)=0, delta >= -a
    # Use scipy minimize
    
    def objective(delta):
        return 0.5 * np.dot(delta, delta)
    
    constraints = [
        {'type': 'ineq', 'fun': lambda d: -epsilon*V/2 - w @ d},
        {'type': 'eq', 'fun': lambda d: np.sum(d)}
    ]
    bounds = [(-a[i], None) for i in range(n)]
    
    res = minimize(objective, np.zeros(n), method='SLSQP', bounds=bounds,
                   constraints=constraints)
    if res.success:
        a_new = a + res.x
        a_new = np.maximum(a_new, 0)
        s = np.sum(a_new)
        if s > 1e-10:
            a_new /= s
        return a_new
    return a
```

**Analytical solution to the QP (ignoring the delta >= -a constraint):**

The KKT conditions give:
delta = -lambda*w + mu*1

where lambda and mu are Lagrange multipliers.

From sum(delta) = 0: -lambda*sum(w) + mu*n = 0, so mu = lambda*sum(w)/n.

From w^T*delta = -epsilon*V/2 (active constraint):
-w^T*w*lambda + mu*w^T*1 = -epsilon*V/2
-w^T*w*lambda + lambda*sum(w)/n * sum(w) = -epsilon*V/2
-lambda*(w^T*w - (sum(w))^2/n) = -epsilon*V/2
lambda = (epsilon*V/2) / (w^T*w - (sum(w))^2/n)

So:
delta = -lambda*w + lambda*sum(w)/n * 1 = lambda * (sum(w)/n * 1 - w)

This is the projection of -w onto the subspace {d : sum(d) = 0}, scaled by lambda.

Then we clip: delta = max(delta, -a) and renormalize.

This is O(n) and very fast! Let me use this.

```python
def qp_peak_reduction_fast(a, k_star, epsilon=0.1):
    n = len(a)
    conv = compute_conv(a)
    V = conv[k_star]
    
    w = np.zeros(n)
    for i in range(n):
        j = k_star - i
        if 0 <= j < n:
            w[i] = a[j]
    
    w_centered = w - np.mean(w)
    w_norm_sq = np.dot(w_centered, w_centered)
    
    if w_norm_sq < 1e-15:
        return a.copy()
    
    lambda_val = (epsilon * V) / (2 * w_norm_sq)
    delta = -lambda_val * w_centered
    
    # Clip to maintain non-negativity
    a_new = a + delta
    a_new = np.maximum(a_new, 0)
    s = np.sum(a_new)
    if s > 1e-10:
        a_new /= s
    return a_new
```
