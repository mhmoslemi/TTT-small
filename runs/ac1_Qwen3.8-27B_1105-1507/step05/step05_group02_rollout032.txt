def fast_conv(a):
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]

    exp_b = np.exp(tau * (b - b_max))

Now let me think about the spectral projection method:

The idea is:
1. Compute F = DFT(a) (length n, circular)
2. Compute the circular autocorrelation: r = IDFT(|F|^2)
3. Note: r[0] = sum(a^2), r[m] = sum_j a[j]*a[(j+m)%n]
4. The linear convolution and circular autocorrelation are related but different
5. We want to minimize the max of the LINEAR convolution

A spectral approach for the linear convolution:
1. Pad a to length 2n-1: a_padded = [a, 0, ..., 0]
2. Compute A = FFT(a_padded)
3. The linear convolution is IDFT(A^2)
4. We want to minimize max(IDFT(A^2)) subject to a_padded[0:n] >= 0, a_padded[n:2n-1] = 0

This is a constraint satisfaction problem in the frequency domain. We can use a projection-based approach:
- Start with A = FFT(a_padded)
- Iteratively:
  a. Compute c = real(IDFT(A^2)) (the convolution)
  b. Find the max of c
  c. If max(c) > target, modify A to reduce the peak
     - One way: A_new[k] = A[k] * exp(-α * peak_indicator)
     - Another: solve a small optimization to find A' that minimizes max(IDFT(A'^2)) while staying close to A and satisfying the zero-padding constraint
  d. a_padded_new = real(IDFT(A_new))
  e. Enforce constraints: a_padded_new[0:n] = max(a_padded_new[0:n], 0), a_padded_new[n:2n-1] = 0
  f. A = FFT(a_padded_new)
