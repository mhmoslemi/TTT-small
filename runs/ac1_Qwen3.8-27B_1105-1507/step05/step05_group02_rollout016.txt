Let me think about the deflation step more carefully. The idea is:
- Find the peak positions in b
- The subgradient at the peak is 2 * (a shifted and flipped)
- Instead of just following the subgradient, we can "deflate" the peak by reducing the contribution of the terms that create it

For peak at position k: b[k] = sum_j a[j] * a[k-j]
To reduce b[k], we want to reduce the products a[j]*a[k-j] for the j that contribute most.
This is like a "water-filling" problem: reduce the large products while keeping sum(a) constant.

A simple deflation step:
1. Find peak positions k* (where b[k] > threshold)
2. For each peak k*, find the contributing pairs (j, k*-j)
3. Reduce a[j] and a[k*-j] proportionally to their product
4. Redistribute the reduced mass to positions that don't contribute to any peak

This is essentially what the LP does, but in a more direct way.

Actually, let me think about a simpler but potentially very effective approach:

**Projected subgradient with adaptive step size (Polyak's method)**:

If we know a lower bound on the optimal value (which we can estimate from the theoretical bound 2n/(2n-1)), we can use Polyak's step size:
alpha_k = (f(x_k) - f*) / ||g_k||^2

where f is the current value, f* is the lower bound estimate.

This is known to converge faster than 1/sqrt(k) step sizes.

Let me also think about the **proximal gradient** formulation:
minimize f(a) = logsumexp(tau * conv(a,a)) subject to a >= 0, sum(a) = 1

The proximal operator for the constraint set {a >= 0, sum(a) = 1} (the probability simplex) is the Euclidean projection onto the simplex, which has a closed-form solution (sort and threshold).

So FISTA with the simplex projection is:
1. Compute gradient of f at y_k
2. z_k = y_k - alpha_k * grad(y_k)
3. x_{k+1} = proj_simplex(z_k)
4. y_{k+1} = x_{k+1} + (t_k - 1)/(t_{k+1} + 1) * (x_{k+1} - x_k)

This is clean and efficient. The simplex projection is O(n log n) per iteration (or O(n) with the median trick).

Let me implement this approach. The key question is: what smooth objective to use?

Option A: f(a) = (1/tau) * logsumexp(tau * conv(a,a))
- Gradient: (2/tau) * sum_k softmax_k(tau*b) * (a shifted)
- As tau → ∞, this approaches max(b)
- Problem: for large tau, the softmax concentrates on the argmax, and the gradient becomes noisy

Option B: f(a) = (1/tau) * logsumexp(tau * (conv(a,a) - max(conv(a,a))))
- This is the same as Option A minus a constant, so same gradient
- But numerically more stable

Option C: Use a "trimmed" logsumexp where we only consider the top-m values
- This avoids the numerical issues of very large tau
- f(a) = (1/tau) * logsumexp(tau * top_m(b))

I'll go with Option B (or A, they're equivalent up to a constant).

Now, for the objective value tracking, I'll use the actual max(b) (not the smooth approximation) to track progress.

Let me also think about **initialization**. Good starting points:
1. The parent sequence (height_sequence_1)
2. Uniform
3. Curved: a[i] = 1 + epsilon*cos(pi*i/(n-1)) for various epsilon
4. From known good sequences (Barker, m-sequence patterns)
5. Random with smoothing

For the m-sequence inspired initialization: an m-sequence of length 2^m - 1 has nearly flat autocorrelation. If I map its ±1 values to [0, 1] (adding 1 and dividing by 2), I get a non-negative sequence with good autocorrelation properties.

For n=512, the closest m-sequence length is 511 (2^9 - 1). I can pad or truncate to get 512.

Let me now write the final code:

Minimizes J(a) = 2*n*max(conv(a,a))/(sum(a))^2 using:
1. FISTA (fast proximal gradient) with simplex projection and adaptive smoothness
2. L-BFGS-B polish on high-tau smooth objective
3. Basin-hopping with diverse initializations including m-sequence inspired starts
4. Spectral deflation for targeted peak reduction
Key improvements: adaptive tau, simplex-constrained FISTA, m-sequence init, L-BFGS polish

import numpy as np

def fast_conv(a):
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]

    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))

def proj_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)

def run_fista(a0, deadline, tau_start=5.0, tau_end=500.0, max_iters=10000, 
              alpha_start=0.5, alpha_decay=0.999):
    """FISTA with simplex projection and adaptive tau."""
    a = a0.copy().astype(np.float64)
    a = np.maximum(a, 1e-10)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_M = fast_conv(a).max()
    
    y = a.copy()
    t = 1.0
    alpha = alpha_start
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        # Adaptive tau: increase gradually
        frac = min(1.0, it / max_iters)
        tau = tau_start * (tau_end / tau_start) ** (frac ** 0.7)
        
        # Compute gradient of smooth objective at y
        _, grad_y, b_y, b_max_y = smooth_conv_grad(y, tau)
        
        # FISTA update
        z = y - alpha * grad_y
        a_new = proj_simplex(z)
        
        # Check improvement
        M = fast_conv(a_new).max()
        if M < best_M:
            best_M = M
            best_a = a_new.copy()
        
        # Nesterov momentum
        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t * t))
        y = a_new + ((t - 1.0) / t_new) * (a_new - a)
        y = np.maximum(y, 0)
        sy = y.sum()
        if sy < 1e-10:
            y = a_new.copy()
        else:
            y = y / sy
        
        a = a_new
        t = t_new
        alpha *= alpha_decay
    
    return best_a

def run_lbfgs_smooth(a0, deadline, tau=200.0, max_time=30):
    """Use L-BFGS-B on the smooth objective (normalized to sum=1 via softmax parameterization)."""
    a = a0.copy().astype(np.float64)
    a = np.maximum(a, 1e-10)
    a = a / a.sum()
    n = len(a)
    
    # Parameterize with log to ensure positivity
    # a_i = exp(z_i) / sum(exp(z_j))
    # Start from z = log(a)
    z0 = np.log(a + 1e-15)
    
    def objective(z):
        a_z = np.exp(z - z.max())
        a_z = a_z / a_z.sum()
        b = fast_conv(a_z)
        # Smooth max
        bm = b.max()
        shifted = np.clip(tau * (b - bm), -300, 300)
        exp_b = np.exp(shifted)
        smooth_max = bm + np.log(exp_b.sum()) / tau
        return smooth_max
    
    def gradient(z):
        a_z = np.exp(z - z.max())
        a_z = a_z / a_z.sum()
        b = fast_conv(a_z)
        bm = b.max()
        shifted = np.clip(tau * (b - bm), -300, 300)
        exp_b = np.exp(shifted)
        p = exp_b / exp_b.sum()
        
        # Gradient of smooth_max w.r.t. a_z
        n_local = len(a_z)
        grad_a = np.zeros(n_local)
        for k in range(len(p)):
            if p[k] < 1e-12:
                continue
            lo = max(0, k - n_local + 1)
            hi = min(n_local - 1, k)
            grad_a[lo:hi + 1] += 2.0 * p[k] * a_z[k - hi:k - lo + 1][::-1]
        
        # Chain rule: d/dz of sum_i a_z[i] * grad_a[i] where a_z = softmax-like
        # a_z[i] = exp(z_i) / S where S = sum(exp(z))
        # da_z[i]/dz[j] = a_z[i] * (delta(i,j) - a_z[j])
        # d obj/dz[j] = sum_i grad_a[i] * da_z[i]/dz[j]
        #              = sum_i grad_a[i] * a_z[i] * (delta(i,j) - a_z[j])
        #              = grad_a[j] * a_z[j] - a_z[j] * sum_i grad_a[i] * a_z[i]
        dot = np.dot(grad_a, a_z)
        grad_z = grad_a * a_z - a_z * dot
        return grad_z
    
    start_time = time.monotonic()
    try:
        result = minimize(objective, z0, method='L-BFGS-B', 
                         jac=gradient,
                         options={'maxiter': 2000, 'maxfun': 50000,
                                  'max_time': max_time, 'gtol': 1e-10})
        if result.x is not None:
            a_result = np.exp(result.x - result.x.max())
            a_result = a_result / a_result.sum()
            a_result = np.maximum(a_result, 0)
            M = fast_conv(a_result).max()
            # Compare with input
            M_orig = fast_conv(a).max()
            if M < M_orig:
                return a_result
    except Exception:
        pass
    
    return a

def make_m_sequence_init(n, rng):
    """Create initialization inspired by m-sequences."""
    # Find largest m such that 2^m - 1 <= n
    m = int(np.log2(n + 1))
    m_len = 2**m - 1
    
    # Generate m-sequence-like pattern using a simple LFSR
    # For simplicity, use a pseudo-random ±1 sequence with good correlation properties
    # Actually, let's just use a chirp/Zadoff-Chu inspired sequence
    t = np.linspace(0, 1, n, endpoint=False)
    
    # Zadoff-Chu inspired: constant modulus with low autocorrelation
    if m_len >= 7:
        # Use a simple Barker-like pattern
        seq = np.zeros(n)
        # Tile or truncate a good pattern
        base = np.array([1, 1, 1, -1, 1, -1, -1])  # Barker length 7
        repeats = (n // len(base)) + 1
        tiling = np.tile(base, repeats)[:n]
        seq = (tiling + 1) / 2  # map to [0, 1]
    else:
        seq = np.ones(n)
    
    # Add some structured variation
    seq += 0.1 * np.cos(2 * np.pi * rng.integers(1, 5) * t)
    seq = np.maximum(seq, 0.01)
    return seq / seq.sum()

def run_deflation(a, deadline, max_iters=200):
    """Directly reduce peaks in the autocorrelation."""
    a = a.copy().astype(np.float64)
    a = np.maximum(a, 0)
    a = a / a.sum()
    n = len(a)
    best_a = a.copy()
    best_M = fast_conv(a).max()
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        M = b.max()
        
        # Find active peaks
        tol = 0.01 * M
        active = np.where(b >= M - tol)[0]
        
        if len(active) == 0:
            break
        
        # Compute subgradient at active peaks with equal weight
        grad = np.zeros(n)
        for k in active:
            lo = max(0, k - n + 1)
            hi = min(n - 1, k)
            grad[lo:hi + 1] += a[k - hi:k - lo + 1][::-1]
        
        # Normalize gradient
        gn = np.linalg.norm(grad)
        if gn < 1e-15:
            break
        grad /= gn
        
        # Try different step sizes
        improved = False
        for step in [0.05, 0.03, 0.02, 0.01, 0.005]:
            a_new = np.maximum(a - step * grad, 0)
            a_new = a_new / a_new.sum()
            M_new = fast_conv(a_new).max()
            if M_new < best_M * (1 - 1e-10):
                a = a_new
                best_M = M_new
                best_a = a.copy()
                improved = True
                break
        
        if not improved:
            break
    
    return best_a

class BestTracker:
    def __init__(self):
        self.seq = None
        self.score = float('inf')
        self.t0 = time.monotonic()

    def update(self, a):
        if a is None:
            return
        a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
        if a.size == 0 or a.sum() < 0.01:
            return
        s = float(evaluate_sequence(a.tolist()))
        if np.isfinite(s) and s < self.score:
            self.score = s
            self.seq = a.copy()
            el = time.monotonic() - self.t0
            print(f"  ** J={s:.8f} n={a.size} t={el:.0f}s", flush=True)

    def report(self, label):
        if self.seq is not None:
            print(f"  {label}: J={self.score:.8f} n={self.seq.size}", flush=True)

def resample_seq(src, n):
    src = np.asarray(src, dtype=np.float64)
    if src.size == n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, n)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)

def make_inits(n, rng, parent):
    """Generate diverse initializations."""
    inits = []
    t = np.linspace(0, 1, n, endpoint=False)
    
    if parent is not None:
        p = resample_seq(parent, n)
        p = np.maximum(p, 1e-6)
        p = p / p.sum()
        inits.append(p.copy())
        inits.append(np.maximum(p + rng.normal(0, 0.02, n), 0.001))
        inits.append(np.maximum(p * (1 + 0.1 * rng.normal(0, 1, n)), 0.001))
    
    # Uniform
    inits.append(np.ones(n) / n)
    
    # Cosine variations
    for f in [1, 2, 3, 5]:
        for amp in [0.1, 0.2, 0.3]:
            inits.append(np.maximum(0.5 + amp * np.cos(2 * np.pi * f * t), 0.01))
    
    # Power law edges
    for alpha in [0.5, 0.7, 1.0, 1.5, 2.0, 3.0]:
        inits.append(np.maximum(t**alpha + (1-t)**alpha + 0.1, 0.01))
    
    # Gaussian-ish
    inits.append(np.exp(-3 * (t - 0.5)**2) + 0.1)
    inits.append(np.exp(-5*(t-0.3)**2) + np.exp(-5*(t-0.7)**2) + 0.05)
    
    # M-sequence inspired
    inits.append(make_m_sequence_init(n, rng))
    
    # Random smooth
    k = max(3, n // 32)
    kern = np.ones(k) / k
    inits.append(np.maximum(np.convolve(rng.uniform(0, 1, n), kern, 'same') + 0.1, 0.01))
    
    # Normalize all
    inits = [np.maximum(x, 0.001) / np.maximum(x, 0.001).sum() for x in inits]
    return inits
