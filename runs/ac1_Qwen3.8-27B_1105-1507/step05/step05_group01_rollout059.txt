The first sum can be computed with the cross-correlation trick (as above). The second sum is just: if `2j < 2n-1` and `conv[2j] > t`, add `2*(conv[2j]-t)*a[j]`.

For simplicity, I'll use the approximation `dP/da[j] ≈ 4 * sum_{k: conv[k]>t, 0<=k-j<n} (conv[k]-t) * a[k-j]` (which overcounts the `k=2j` term by a factor of 2, but for subgradient-like methods this is fine).

The projection onto the simplex `{a >= 0, sum(a) = 1}`:
```
def project_simplex(v):
    n = len(v)
    # Find tau such that sum(max(v[i] - tau, 0)) = 1
    # Use bisection
    lo = min(v) - 2
    hi = max(v)
    for _ in range(100):
        mid = (lo + hi) / 2
        s = np.sum(np.maximum(v - mid, 0))
        if s > 1:
            lo = mid
        else:
            hi = mid
    tau = (lo + hi) / 2
    return np.maximum(v - tau, 0)
```

This is O(n log n) per iteration (with bisection). For n=700, this is very fast.

Actually, there's a more efficient O(n log n) algorithm for simplex projection using sorting:
```
def project_simplex(v):
    n = len(v)
    mu = np.sort(v)[::-1]
    cv = np.cumsum(mu)
    rho = np.argmax(mu * np.arange(1, n+1) - (cv - 1) > 0)
    tau = (cv[rho] - 1) / (rho + 1)
    return np.maximum(v - tau, 0)
```

This is O(n log n) due to the sort.

Let me also think about the **learning rate schedule**. For the penalty method:
- `lr = alpha / (1 + beta * iteration)` or `lr = alpha / sqrt(iteration)`.
- `alpha` should be related to the Lipschitz constant of the gradient.

The Lipschitz constant of the penalty gradient is bounded by `4 * (2n-1) * max|a|` (roughly). For `a` on the simplex, `max|a| <= 1`, so the Lipschitz constant is at most `4*(2n-1) ≈ 8n`. For n=700, that's about 5600. So `lr < 1/5600 ≈ 0.00018`.
