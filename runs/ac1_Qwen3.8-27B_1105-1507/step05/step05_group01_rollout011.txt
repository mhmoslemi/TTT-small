    a = a / a.sum()
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    for t in range(max_iters):
        if time.monotonic() - start > time_budget:
            break
        eta = eta0 / (1 + t * decay)
        
        conv = compute_conv(a)
        k_star = int(np.argmax(conv))
        M = conv[k_star]
        
        # Subgradient: h[j] = 2*a[k_star - j] for valid j
        h = np.zeros(n)
        for j in range(n):
            idx = k_star - j
            if 0 <= idx < n:
                h[j] = 2 * a[idx]
        
        # Mirror descent step (multiplicative)
        a_new = a * np.exp(-eta * h)

        obj = compute_obj(a_new)
        if obj < best_obj:
            best_obj = obj
            best_a = a_new.copy()
        a = a_new
    
    return best_a, best_obj

Let me also think about whether there's a closed-form or near-closed-form solution. 

For the problem min max_k conv(a,a)[k] s.t. a >= 0, sum a = 1:

If we restrict to symmetric sequences (a[i] = a[n-1-i]), then the peak is at k=n-1 and equals ||a||^2. Minimizing ||a||^2 subject to a >= 0, sum a = 1 gives the uniform sequence a[i] = 1/n, with peak = 1/n.

For asymmetric sequences, the peak can be off-center. The question is: what's the minimum possible peak?

This is related to the "minimum peak autocorrelation" problem, which is well-studied in signal processing. For non-negative sequences, it's less studied.

I recall that for the "minimum peak short-time autocorrelation" problem, the optimal sequences are related to "Barker polynomials" or "Golay pairs" in the binary case, and to "chirp" or "clock" sequences in the real case.

For our non-negative real case, I suspect the optimal sequences have a "sawtooth" or "ramp" shape - linearly increasing from one end to the other. This would make the autocorrelation more uniform.
