Wait, I need to double-check the convolution indices. Let me be very careful.

Standard convolution: `(f * g)[m] = sum_j f[j] * g[m-j]`

I want: `grad[i] = 2 * sum_{j=0}^{n-1} p[i+j] * a[j]` for i = 0, ..., n-1

Let `a_rev[k] = a[n-1-k]`. Then `a[j] = a_rev[n-1-j]`.

`grad[i] = 2 * sum_{j=0}^{n-1} p[i+j] * a_rev[n-1-j]`

Let `l = n-1-j`, so `j = n-1-l`:
`grad[i] = 2 * sum_{l=0}^{n-1} p[i+n-1-l] * a_rev[l]`

Now, `(a_rev * p)[m] = sum_l a_rev[l] * p[m-l]`

So `(a_rev * p)[i+n-1] = sum_l a_rev[l] * p[i+n-1-l]`

Therefore: `grad[i] = 2 * (a_rev * p)[i+n-1]` for i = 0, ..., n-1.

So `grad = 2 * conv[n-1 : 2*n-1]` where `conv = a_rev * p` (the full convolution of length n + (2n-1) - 1 = 3n-2).

Let me verify with n=2: a=[a0,a1], p=[p0,p1,p2]
- a_rev = [a1, a0]
- conv = a_rev * p (length 2+3-1=4)
  - conv[0] = a1*p0
  - conv[1] = a1*p1 + a0*p0
  - conv[2] = a1*p2 + a0*p1
  - conv[3] = a0*p2
- grad = 2 * conv[1:3] = 2 * [a1*p1 + a0*p0, a1*p2 + a0*p1]
  - grad[0] = 2*(a0*p0 + a1*p1) ✓
  - grad[1] = 2*(a0*p1 + a1*p2) ✓

def fast_conv(a):

    return np.fft.irfft(fa * fa, size)[:2*n-1]

def compute_J(a):

def smooth_max_and_grad(a, tau):

    b = fast_conv(a)
    b_max = b.max()

    exp_b = np.exp(np.clip(tau * (b - b_max), -50, 50))

    return sm_val, grad

def nesterov_projected_grad(a, n_iters, deadline, tau_start, tau_end, lr_start, momentum):
    """Nesterov-accelerated projected gradient on smooth max with sum(a)=1."""
    a = np.maximum(a.copy(), 0)
    s = a.sum()
    if s < 1e-10:
        a = np.ones_like(a) / len(a)
    else:
        a = a / s
    n = len(a)
    
    best_a = a.copy()
    best_M = fast_conv(a).max()
    
    v = np.zeros(n)  # velocity for Nesterov
    it = 0
    
    while it < n_iters and time.monotonic() < deadline:
        frac = it / max(1, n_iters)
        tau = tau_start + (tau_end - tau_start) * (frac ** 0.5)
        lr = lr_start / (1.0 + 0.005 * it)
        
        # Nesterov: evaluate gradient at y = a + momentum * v
        y = a + momentum * v
        y = np.maximum(y, 0)
        s_y = y.sum()
        if s_y < 1e-10:
            y = a.copy()
        else:
            y = y / s_y
        
        _, grad = smooth_max_and_grad(y, tau)
        
        # Project gradient to tangent space (sum = 0)
        grad = grad - grad.mean()
        
        # Update
        v = momentum * v - lr * grad
        a_new = a + v
        a_new = np.maximum(a_new, 0)
        s_new = a_new.sum()
        if s_new < 1e-10:
            a_new = a.copy()
            v = np.zeros(n)
        else:
            a_new = a_new / s_new
        
        a = a_new
        it += 1
        
        # Check improvement (every few iterations to save time)
        if it % 10 == 0:
            M = fast_conv(a).max()
            if M < best_M * (1 - 1e-12):
                best_M = M
                best_a = a.copy()
    
    # Final check
    M = fast_conv(a).max()
    if M < best_M:
        best_M = M
        best_a = a.copy()
    
    return best_a

def block_refine(a, block_size, deadline):
