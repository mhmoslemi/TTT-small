# Mathematical Specification
We represent the sequence \(a\) of length \(n\) as a normalized vector, ensuring \(\sum_i a_i = 1\). The objective is:  
`\[obj(a) = 2 \times n \times \max_j (\text{convolve}(a, a)_j) / 1\]`  
where the convolution is defined as:  
`\[\text{convolve}(a, a)_j = \sum_{k} a_k a_{j-k} \quad \text{for } j \text{ from } 0 \text{ to } 2n-2\]`  

We solve the dual LP to project the gradient:  
`\[\min_{g \in \mathbb{R}^m} \quad \max_j (a * a)_j \quad \text{subject to } \sum_i g_i = 1, \quad g_i \geq 0\]`  
This formulation maintains a simultaneous check on constraints via binding hyperplanes.
