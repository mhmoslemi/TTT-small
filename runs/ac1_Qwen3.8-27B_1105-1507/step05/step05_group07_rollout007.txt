Hybrid optimizer for minimizing J(a) = 2n*max(conv(a,a))/(sum(a))^2.

import numpy as np
import time
from scipy.optimize import linprog
from scipy.sparse import csr_matrix


def fast_conv(a):
    """Full self-convolution via FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]


def compute_J(a):
    """Compute J(a) = 2*n*max(conv(a,a))/(sum(a))^2."""
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))


class ScoreTracker:

        self.best_score = float('inf')
        self.t_start = time.monotonic()

    def update(self, a, verbose=True):

        if a.size == 0 or a.sum() < 0.01:

        if np.isfinite(score) and score < self.best_score:

            self.best_score = score

**Alternative: Use the Riemann/DFT approach**

The self-convolution in the time domain corresponds to the squared magnitude of the DFT in the frequency domain:
(a*a)[k] = sum_j a[j]*a[k-j]

The DFT of (a*a) is |A(f)|^2 where A(f) = DFT(a).

So max_k (a*a)[k] is the peak of the inverse DFT of |A(f)|^2.

By the Parseval identity: sum_k (a*a)[k]^2 = (1/N) sum_f |A(f)|^4 (where N is the DFT size).

This means that if |A(f)|^2 is "flat" (constant), then (a*a)[k] is also "flat" (constant). This is the ideal case.

So the problem is equivalent to: find a ≥ 0, sum(a) = 1, such that |DFT(a)|^2 is as flat as possible.

This is related to the problem of finding "low PAPR" (peak-to-average power ratio) sequences, which is a well-studied problem in communications.

The classical approach for low PAPR is the "phased array" or "Golay complementary sequences" approach, but those require complex-valued sequences. For real non-negative sequences, the problem is more constrained.
