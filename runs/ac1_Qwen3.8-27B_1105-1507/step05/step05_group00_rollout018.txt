Let me reconsider the problem. We want to minimize max_k conv[k] where conv = a*a.

The sum of all conv[k] values is (sum a)^2. With 2n-1 terms, the average is (sum a)^2 / (2n-1).

This is like designing a "flat-top" autocorrelation, but for the self-convolution of a non-negative sequence.

**Key realization**: The self-convolution a*a is NOT the same as the autocorrelation. The autocorrelation at lag tau is sum_i a[i]*a[i+tau], while the self-convolution at position k is sum_i a[i]*a[k-i].

For the autocorrelation, the peak is always at lag 0 (value = sum a_i^2). But for the self-convolution, the peak can be anywhere.

So the problem is really about minimizing the peak of the self-convolution, which is different from minimizing the peak of the autocorrelation.

This is a QCQP. We can solve it iteratively.
