def compute_conv(a):
    if len(a) == 0:
        return np.array([])
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size *= 2

    conv = irfft(fa * fa[:len(fa) // 2] + fa[-1] * np.conj(fa[1:-1])), size)
    return conv[:2 * n - 1]

2. **Multi-Length Exploration**: For each candidate length derived from the parent sequence, the function uses `aggressive_lp_polish` to refine a sequence, aiming to find a locally optimal solution around that length.
3. **Final Polish**: The best sequence found is further refined using a combination of spectral shaping and peak-targeted perturbations to minimize the evaluation function globally.
4. **Fallback**: If the search fails to find a valid sequence within the time budget, a fallback sequence is used. This sequence is normalized and validated in the evaluator.

The algorithm balances between multiple lengths and intensively optimizes each candidate sequence to ensure both global exploration and local refinement are covered within the 1500-second time window.
