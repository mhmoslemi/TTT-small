Minimize max_k (a*a)[k] s.t. a >= 0, sum(a) = 1.

Introduce variable t: minimize t s.t. (a*a)[k] <= t for all k, a >= 0, sum(a) = 1.

The Lagrangian is: L = t + sum_k lambda_k * ((a*a)[k] - t) + sum_i mu_i * (-a_i) + nu * (sum(a) - 1)

= t(1 - sum_k lambda_k) + sum_k lambda_k * (a*a)[k] - sum_i mu_i * a_i + nu * (sum(a) - 1)

The dual function is: g(lambda, mu) = inf_{t, a} L(t, a, lambda, mu)

For the inf over t: if sum_k lambda_k ≠ 1, the inf is -inf. So we need sum_k lambda_k = 1.

For the inf over a >= 0: inf_a [sum_k lambda_k * (a*a)[k] - sum_i (mu_i - nu) * a_i]

This is a quadratic minimization over a >= 0. The objective is:
sum_k lambda_k * sum_j a_j * a_{k-j} - sum_i (mu_i - nu) * a_i
= sum_j (sum_k lambda_k * a_{k-j}) * a_j - sum_i (mu_i - nu) * a_i
= a^T Q a - c^T a

where Q is a symmetric matrix determined by lambda, and c_i = mu_i - nu.

This is a QP, which is convex if Q is positive semidefinite. Q is a "convolution matrix" weighted by lambda. If lambda >= 0, then Q is PSD (it's a weighted sum of rank-1 matrices... actually no, it's more complex).

Actually, Q_{ij} = sum_k lambda_k * (k-j indicator) ... let me think more carefully.

(a*a)[k] = sum_j a_j * a_{k-j}

So sum_k lambda_k (a*a)[k] = sum_k lambda_k sum_j a_j a_{k-j} = sum_j a_j sum_k lambda_k a_{k-j}

Let me define (lambda * a)[j] = sum_k lambda_k a_{k-j}. Wait, this is a correlation, not a convolution.

Actually: sum_k lambda_k * a_{k-j} = sum_m lambda_{j+m} * a_m (substituting m = k-j).

So sum_k lambda_k (a*a)[k] = sum_j a_j * sum_m lambda_{j+m} * a_m = a^T Q a

where Q_{jm} = lambda_{j+m} (with lambda_k = 0 for k outside [0, 2n-2]).

Q is symmetric: Q_{jm} = lambda_{j+m} = lambda_{m+j} = Q_{mj}. ✓

Is Q PSD? Q = sum_k lambda_k * v_k v_k^T where v_k is a vector with (v_k)_j = 1 if j + (k-j) = k, i.e., always... hmm this isn't quite right.

Actually, (a*a)[k] = a^T S_k a where S_k is a symmetric permutation-like matrix. Specifically, (a*a)[k] = sum_j a_j a_{k-j} = a^T P_k a where (P_k)_{j,k-j} = 1 if both indices are valid.

So Q = sum_k lambda_k P_k. If lambda_k >= 0, then Q is PSD (sum of PSD matrices).

So the dual problem is:
maximize g(lambda, mu) subject to sum_k lambda_k = 1, lambda_k >= 0, mu_i >= 0

This is a complex problem but it gives us a lower bound on the optimal value.

This approach is getting complicated. Let me focus on practical improvements to the existing LP-based approach.

**Practical improvements:**

1. **Better step size**: Instead of geometric decrease, use backtracking: try t=1, 0.5, 0.25, ... and use the largest t that decreases the objective.

2. **Multiple LP starts**: At each iteration, solve the LP with M slightly above the current max (e.g., M * 1.01, M * 1.05, M * 1.1). This allows the LP to find a different "shape" of g.

3. **Randomized LP**: Randomly drop some constraints to get a diverse set of best responses, then pick the best one.

4. **Block coordinate LP**: Instead of updating all n coordinates, divide into blocks and update one block at a time (treating the rest as fixed).

5. **Better initialization**: Use the dual information from the LP to construct a better initial point.

6. **Convex combination**: If we have multiple good solutions a_1, ..., a_m, try convex combinations.

"""
Optimized LP mirror descent with adaptive step sizes, constraint relaxation,
and diverse restarts for minimizing J(a) = 2n*max(conv(a,a))/(sum(a))^2.
"""

import numpy as np
import time
from scipy.optimize import linprog
from scipy.sparse import csr_matrix


def fast_conv(a):
    """Full self-convolution via FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]


def compute_J(a):
    """Compute J(a) = 2*n*max(conv(a,a))/(sum(a))^2."""
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))


def build_A_sparse(n, a):
    """Build sparse constraint matrix: A[k,j] = a[k-j] if 0<=k-j<n, else 0."""
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        j_min = max(0, k - n + 1)
        j_max = min(n - 1, k)
        for j in range(j_min, j_max + 1):
            rows.append(k)
            cols.append(j)
            vals.append(a[k - j])
    return csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))


def lp_best_response(a, M, seed=None, drop_frac=0.0):
    """LP: max sum(g) s.t. (a*g)[k] <= M for all k, g >= 0.
    Optionally drop a random fraction of constraints for diversity."""
    n = len(a)
    A_full = build_A_sparse(n, a)
    
    if drop_frac > 0 and seed is not None:
        rng = np.random.default_rng(seed)
        n_constraints = 2 * n - 1
        n_keep = int(n_constraints * (1 - drop_frac))
        # Always keep the most important constraints (where a*a is largest)
        conv_a = fast_conv(a)
        importance = conv_a.copy()
        # Randomly select constraints, biased toward important ones
        probabilities = importance + 1e-10
        probabilities /= probabilities.sum()
        kept = rng.choice(n_constraints, size=n_keep, replace=False, p=probabilities)
        kept = np.sort(kept)
        # Always include the top-k most important
        top_k = np.argsort(conv_a)[-min(10, n_keep):]
        kept = np.unique(np.concatenate([kept, top_k]))
        kept = kept[kept < n_constraints]
        A = A_full[kept]
        b_ub = np.full(len(kept), M)
    else:
        A = A_full
        b_ub = np.full(2 * n - 1, M)
    
    c = -np.ones(n)
    bounds = [(0, None)] * n
    try:
        r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                    options={'time_limit': 60, 'presolve': True})
        if r.success and r.x is not None:
            g = np.maximum(r.x, 0)
            if g.sum() > 1e-15:
                return g
    except Exception:
        pass
    return None


def run_lp_mirror_descent(a, max_iters, deadline, verbose=True):
    """LP mirror descent with adaptive step size and constraint relaxation."""
    a = np.maximum(a.astype(np.float64), 1e-10)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_M = fast_conv(a).max()
    best_J = 2 * n * best_M  # since sum(a)=1
    no_improve = 0
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b_conv = fast_conv(a)
        M = float(b_conv.max())
        
        # Try multiple M values for diversity
        M_candidates = [M, M * 1.01, M * 1.05, M * 1.1]
        
        best_g = None
        best_g_J = float('inf')
        
        for Mi in M_candidates:
            g = lp_best_response(a, Mi)
            if g is not None:
                g = np.maximum(g, 0.0)
                g_sum = g.sum()
                if g_sum > 1e-10:
                    g = g / g_sum
                    # Quick evaluation
                    # Try the best response directly
                    M_trial = fast_conv(g).max()
                    J_trial = 2 * n * M_trial
                    if J_trial < best_g_J:
                        best_g_J = J_trial
                        best_g = g.copy()
        
        if best_g is None:
            break
        
        # Adaptive step size: try multiple t values
        best_t = 0
        best_obj = 2 * n * fast_conv(a).max()
        
        for t in [1.0, 0.8, 0.5, 0.3, 0.2, 0.1, 0.05]:
            a_trial = np.maximum((1 - t) * a + t * best_g, 0)
            s = a_trial.sum()
            if s < 1e-10:
                continue
            a_trial = a_trial / s
            M_trial = fast_conv(a_trial).max()
            obj_trial = 2 * n * M_trial
            if obj_trial < best_obj:
                best_obj = obj_trial
                best_t = t
        
        if best_t > 0:
            a = np.maximum((1 - best_t) * a + best_t * best_g, 0)
            s = a.sum()
            a = a / s
            current_M = fast_conv(a).max()
            current_J = 2 * n * current_M
            
            if current_J < best_J - 1e-12:
                best_J = current_J
                best_a = a.copy()
                best_M = current_M
                no_improve = 0
                if verbose and it % 10 == 0:
                    print(f"    it={it}: J={current_J:.8f} (t={best_t:.2f})", flush=True)
            else:
                no_improve += 1
        else:
            no_improve += 1
        
        if no_improve > 50:
            break
        
        # Check time
        if time.monotonic() > deadline - 5:
            break
    
    return best_a


def coord_descent_fast(a, max_sweeps, deadline, seed=0):
    """Fast coordinate descent with incremental convolution."""
    n = len(a)
    a = np.maximum(a.copy().astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-10:
        a = np.ones(n)
        s = 1.0
    
    conv = fast_conv(a)
    best_obj = 2.0 * n * conv.max() / (s * s)
    best_a = a.copy()
    rng = np.random.default_rng(seed)
    no_improve = 0
    
    for sweep in range(max_sweeps):
        if time.monotonic() > deadline:
            break
        
        order = rng.permutation(n)
        improved = False
        
        for i in order:
            old = a[i]
            lo = max(0, i)
            hi = min(2 * n - 2, i + n - 1)
            a_slice = a[lo - i:hi - i + 1].copy()
            kq = 2 * i
            valid_kq = kq <= 2 * n - 2
            
            # Try several multipliers
            if old < 1e-10:
                candidates = [0.0, 1e-4, 1e-3, 1e-2, 0.1]
            else:
                candidates = [0.0, old * 0.1, old * 0.3, old * 0.5, old * 0.7, old * 1.3, old * 1.5, old * 2.0]
            
            best_val = old
            best_local = 2.0 * n * conv.max() / (s * s)
            
            for x in candidates:
                delta = x - old
                if abs(delta) < 1e-14:
                    continue
                
                conv[lo:hi + 1] += 2.0 * delta * a_slice
                if valid_kq:
                    conv[kq] += delta * delta
                
                new_s = s - old + x
                if new_s > 1e-10:
                    new_obj = 2.0 * n * conv.max() / (new_s * new_s)
                else:
                    new_obj = float('inf')
                
                if new_obj < best_local:
                    best_local = new_obj
                    best_val = x
                
                conv[lo:hi + 1] -= 2.0 * delta * a_slice
                if valid_kq:
                    conv[kq] -= delta * delta
            
            if abs(best_val - old) > 1e-12:
                delta = best_val - old
                conv[lo:hi + 1] += 2.0 * delta * a_slice
                if valid_kq:
                    conv[kq] += delta * delta
                a[i] = best_val
                s = s - old + best_val
                improved = True
        
        current_obj = 2.0 * n * conv.max() / (s * s)
        if current_obj < best_obj - 1e-12:
            best_obj = current_obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        if no_improve > 100:
            break
    
    a = best_a.copy()
    a = np.maximum(a, 0)
    if a.sum() > 0:
        a /= a.sum()
    return a


def subgradient_descent(a, max_iters, deadline, lr_init=0.1):
    """Subgradient descent with running average."""
    n = len(a)
    a = np.maximum(a.astype(np.float64), 1e-10)
    a = a / a.sum()
    
    best_a = a.copy()
    best_M = fast_conv(a).max()
    running_sum = np.zeros(n)
    count = 0
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        lr = lr_init / np.sqrt(it + 1)
        conv = fast_conv(a)
        M = conv.max()
        
        if M < best_M:
            best_M = M
            best_a = a.copy()
        
        # Subgradient of max_k (a*a)[k]
        tol = 1e-8 * M
        active = np.where(conv >= M - tol)[0]
        grad = np.zeros(n)
        for k in active:
            lo = max(0, k - n + 1)
            hi = min(n - 1, k)
            grad[lo:hi + 1] += 2.0 * a[k - hi:k - lo + 1][::-1]
        
        gnorm = np.linalg.norm(grad)
        if gnorm > 1e-15:
            grad /= gnorm
        
        a_new = a - lr * grad
        a_new = np.maximum(a_new, 0)
        s = a_new.sum()
        if s > 1e-10:
            a_new /= s
        else:
            a_new = a.copy()
        
        running_sum += a_new
        count += 1
        a = a_new
    
    if count > 50:
        a_avg = running_sum / count
        a_avg = np.maximum(a_avg, 0)
        s = a_avg.sum()
        if s > 1e-10:
            a_avg /= s
            M_avg = fast_conv(a_avg).max()
            if M_avg < best_M:
                best_a = a_avg
    
    return best_a


def resample_seq(src, dest_n):
    """Resample 1D sequence to new length."""
    src = np.asarray(src, dtype=np.float64)
    if src.size == dest_n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, dest_n)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)


def generate_initializations(n, rng, parent=None):
    """Generate diverse initial sequences."""
    inits = []
    t = np.linspace(0, 1, n, endpoint=False)
    
    if parent is not None:
        p = resample_seq(parent, n)
        if p.sum() > 0:
            p = p / p.sum()
        inits.append(p.copy())
        inits.append(np.maximum(p + rng.normal(0, 0.02, n), 0.001))
        inits.append(np.maximum(p + rng.normal(0, 0.05, n), 0.001))
        inits.append(np.maximum(p + rng.normal(0, 0.1, n), 0.001))
    
    inits.append(np.ones(n) / n)
    
    # Cosine variants
    for freq in [1, 2, 3, 4, 5, 7, 8]:
        for amp in [0.1, 0.2, 0.3, 0.5]:
            sig = 1.0 + amp * np.cos(2 * np.pi * freq * t)
            sig = np.maximum(sig, 0.01)
            inits.append(sig / sig.sum())
    
    # Smooth random
    ksize = max(3, n // 16)
    kernel = np.ones(ksize) / ksize
    for _ in range(5):
        smooth = np.convolve(rng.uniform(0.1, 1, n), kernel, mode='same')
        inits.append(smooth / smooth.sum())
    
    # Exponential decay (one-sided)
    for rate in [0.5, 1.0, 2.0, 4.0]:
        sig = np.exp(-rate * t)
        inits.append(sig / sig.sum())
        # Mirror
        inits.append(sig[::-1].copy() / sig.sum())
    
    # Bimodal
    for c1, c2 in [(0.2, 0.8), (0.1, 0.9), (0.3, 0.7)]:
        sig = np.exp(-((t - c1) / 0.1) ** 2) + np.exp(-((t - c2) / 0.1) ** 2)
        inits.append(sig / sig.sum())
    
    # Power law
    for p in [0.5, 1.0, 2.0, 3.0]:
        sig = (t + 0.01) ** (-p)
        inits.append(sig / sig.sum())
    
    return inits

import numpy as np

def fast_conv(a):
    """Full self-convolution via FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]


def compute_J(a):
    """Compute J(a) = 2*n*max(conv(a,a))/(sum(a))^2."""
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))


def build_A_sparse(n, a):
    """Build sparse matrix A where A[k,j] = a[k-j] if 0<=k-j<n."""
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        j_min = max(0, k - n + 1)
        j_max = min(n - 1, k)
        for j in range(j_min, j_max + 1):
            rows.append(k)
            cols.append(j)
            vals.append(a[k - j])
    return csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))


def lp_best_response(a, M, n_keep=None, seed=None):
    """
    LP: max sum(g) s.t. (a*g)[k] <= M for all k, g >= 0.
    Optionally keep only n_keep constraints (biased toward important ones).
    """

        rng = np.random.default_rng(seed)

        probs = conv_a + 1e-10

    rows = []
    cols = []
    vals = []

            cols.append(j)
            vals.append(a[k - j])

        if time.monotonic() > deadline:
            break

            if old < 1e-10:

                if valid_kq:
                    conv[kq] += delta * delta
                
                new_s = s - old + x
                if new_s > 1e-10:
                    new_obj = 2.0 * n * conv.max() / (new_s * new_s)

def subgradient_descent(a, max_iters, deadline, lr_init=0.12):
    """Subgradient descent with Polyak-style averaging."""
    n = len(a)
    a = np.maximum(a.astype(np.float64), 1e-10)
    a = a / a.sum()
    
    best_a = a.copy()
    best_M = float(fast_conv(a).max())
    running_sum = np.zeros(n)
    count = 0
    best_f = 2.0 * n * best_M
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        lr = lr_init / np.sqrt(it + 1)
        conv = fast_conv(a)
        M = float(conv.max())
        f = 2.0 * n * M
        
        if f < best_f:
            best_f = f
            best_M = M
            best_a = a.copy()
        
        # Subgradient
        tol = max(1e-9, 1e-7 * M)
        active = np.where(conv >= M - tol)[0]
        grad = np.zeros(n)
        for k in active:
            lo = max(0, k - n + 1)
            hi = min(n - 1, k)
            grad[lo:hi + 1] += 2.0 * a[k - hi:k - lo + 1][::-1]
        
        gnorm = np.linalg.norm(grad)
        if gnorm > 1e-15:
            grad /= gnorm
        
        a_new = a - lr * grad
        a_new = np.maximum(a_new, 0)
        s = a_new.sum()
        if s > 1e-10:
            a_new /= s
        else:
            a_new = a.copy()
        
        running_sum += a_new
        count += 1
        a = a_new
    
    if count > 100:
        a_avg = running_sum / count
        a_avg = np.maximum(a_avg, 0)
        s = a_avg.sum()
        if s > 1e-10:
            a_avg /= s
            M_avg = float(fast_conv(a_avg).max())
            if 2.0 * n * M_avg < best_f:
                best_a = a_avg
    
    return best_a


def resample_seq(src, dest_n):
    """Resample 1D sequence to new length via linear interpolation."""
    src = np.asarray(src, dtype=np.float64)
    if src.size == dest_n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, dest_n)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)


def generate_initializations(n, rng, parent=None):
    """Generate diverse initial sequences for exploration."""
    inits = []
    t = np.linspace(0, 1, n, endpoint=False)

            inits.append(perturbed / perturbed.sum())
    
    inits.append(np.ones(n) / n)
    
    # Cosine waves
    for freq in [1, 2, 3, 4, 5, 6, 8, 10]:

            sig = 1.0 + amp * np.cos(2 * np.pi * freq * t)
            sig = np.maximum(sig, 0.01)
            inits.append(sig / sig.sum())
    
    # Smooth random
    ksize = max(3, n // 16)
    kernel = np.ones(ksize) / ksize
    for _ in range(6):
        smooth = np.convolve(rng.uniform(0.1, 1.0, n), kernel, mode='same')
        inits.append(smooth / smooth.sum())
    
    # Exponential decay (one-sided)
    for rate in [0.5, 1.0, 2.0, 3.0, 5.0, 8.0]:
        sig = np.exp(-rate * t) + 0.01
        inits.append(sig / sig.sum())
        sig2 = np.exp(-rate * (1 - t)) + 0.01
        inits.append(sig2 / sig2.sum())
    
    # Bimodal
    for c in [0.15, 0.2, 0.25, 0.3]:
        sig = np.exp(-((t - c) / 0.08) ** 2) + np.exp(-((t - (1-c)) / 0.08) ** 2) + 0.01

            a_ext = a_ext / a_ext.sum()
            
            # Quick CD
            cd_budget = min(30, max(10, (p3_deadline - time.monotonic()) // 3))
            a_cd = coord_descent(a_ext, max_sweeps=2000,
                                  deadline=min(t0 + cd_budget, p3_deadline - 30),
                                  seed=seed + 2000 + new_n)
            J_cd = compute_J(a_cd)
            print(f"  n={new_n} CD: J={J_cd:.8f} ({time.monotonic()-t0:.1f}s)", flush=True)
            track(a_cd, f"(CD {new_n})")
            
            # Brief LP if time allows
            if time.monotonic() < p3_deadline - 20:
                a_lp = run_lp_mirror_descent(a_cd, max_iters=20,
                                              deadline=min(t0 + 50, p3_deadline - 10),
                                              verbose=False)
                J_lp = compute_J(a_lp)
                print(f"  n={new_n} LP: J={J_lp:.8f}", flush=True)
                track(a_lp, f"(LP {new_n})")
    
    print(f"  Phase 3 best: J={best_score:.8f}", flush=True)
    
    # === PHASE 4: Final polish ===
    p4_deadline = deadline
    print(f"\n{'=' * 60}", flush=True)
    print(f"PHASE 4: Final Polish (budget {p4_deadline - time.monotonic():.0f}s)", flush=True)
    print(f"{'=' * 60}", flush=True)
    
    if best_sequence is not None and time.monotonic() < p4_deadline - 20:
        # Subgradient with averaging
        sg_budget = min(50, max(10, (p4_deadline - time.monotonic()) // 3))
        a_sg = subgradient_descent(best_sequence, max_iters=5000,
                                    deadline=min(time.monotonic() + sg_budget, p4_deadline - 20),
                                    lr_init=0.1)
        J_sg = compute_J(a_sg)
        print(f"  Subgradient: J={J_sg:.8f}", flush=True)
        track(a_sg, "(SG)")
        
        # Final coordinate descent
        if time.monotonic() < p4_deadline - 15:
            cd_budget = min(40, max(10, (p4_deadline - time.monotonic()) // 2))
            a_fcd = coord_descent(best_sequence, max_sweeps=5000,
                                   deadline=min(time.monotonic() + cd_budget, p4_deadline - 10),
                                   seed=seed + 99999)
            J_fcd = compute_J(a_fcd)
            print(f"  Final CD: J={J_fcd:.8f}", flush=True)
            track(a_fcd, "(FinalCD)")
        
        # Final LP
        if time.monotonic() < p4_deadline - 10:
            a_flp = run_lp_mirror_descent(best_sequence, max_iters=20,
                                           deadline=p4_deadline, verbose=False)
            J_flp = compute_J(a_flp)
            print(f"  Final LP: J={J_flp:.8f}", flush=True)
            track(a_flp, "(FinalLP)")
    
    # Fallback
    if best_sequence is None:
        best_sequence = np.ones(512)
        best_score = float(evaluate_sequence(best_sequence.tolist()))
    
    print(f"\n{'=' * 60}", flush=True)
    print(f"FINAL: J={best_score:.8f} n={best_sequence.size} time={time.monotonic()-t_start:.0f}s", flush=True)
    print(f"{'=' * 60}", flush=True)
    
    return [float(x) for x in best_sequence]
