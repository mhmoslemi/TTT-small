Then C = ifft(fft(w_padded) * conj(fft(a_padded))) gives the cross-correlation.
C[i] = sum_j w_padded[j+i] * a_padded[j] (circular correlation).

Since w is only non-zero for j in [0, 2n-2] and a is only non-zero for j in [0, n-1], for i in [0, n-1]:
C[i] = sum_{j=0}^{n-1} w[j+i] * a[j] (as long as j+i < L, which is true for our sizes).

So c[i] = C[i] for i = 0, ..., n-1. 

Let me verify with a small example:
w = [w0, w1, w2, w3, w4] (length 5, so 2n-1=5, n=3)
a = [a0, a1, a2] (length 3)

c[0] = sum_j w[j] * a[j] = w0*a0 + w1*a1 + w2*a2
c[1] = sum_j w[j+1] * a[j] = w1*a0 + w2*a1 + w3*a2
c[2] = sum_j w[j+2] * a[j] = w2*a0 + w3*a1 + w4*a2

Cross-correlation C[k] = sum_j w[j+k] * conj(a[j]) (circular, with zero-padding to length L >= 5+3-1=7):

C[0] = w0*a0 + w1*a1 + w2*a2 + w3*a0 + w4*a1 + ... (WRONG, this includes wrap-around)

Wait, with proper zero-padding to length L >= 7:
w_padded = [w0, w1, w2, w3, w4, 0, 0]
a_padded = [a0, a1, a2, 0, 0, 0, 0]

Cross-correlation (circular)[:L] = ifft(fft(w_padded) * conj(fft(a_padded)))

The circular cross-correlation at lag k is:
sum_{j=0}^{L-1} w_padded[(j+k) mod L] * conj(a_padded[j])

For k=0: w0*a0 + w1*a1 + w2*a2 + 0 + 0 + 0 + 0 = w0*a0 + w1*a1 + w2*a2 ✓
For k=1: w1*a0 + w2*a1 + w3*a2 + 0 + 0 + 0 + 0 = w1*a0 + w2*a1 + w3*a2 ✓
For k=2: w2*a0 + w3*a1 + w4*a2 + 0 + 0 + 0 + 0 = w2*a0 + w3*a1 + w4*a2 ✓

So c[i] = C[i] for i = 0, 1, 2. 

So the FFT-based computation is:
```python
L = 1
while L < (2*n-1) + n - 1:  # = 3n-2
    L <<= 1
fw = np.fft.rfft(w, L)
fa = np.fft.rfft(a, L)
C = np.fft.irfft(fw * np.conj(fa), L)
c = C[:n]  # c[i] = sum_j w[j+i] * a[j]
grad = 2.0 * c
```

This is correct and O(n log n).

Now, let me also think about the multiplicative update approach more carefully.

**Multiplicative update (Sinkhorn-like):**

The idea is to find a such that conv(a,a) is as uniform as possible. This is like finding a "square root" of a uniform distribution under convolution.

If we define the "residual" r_k = b_k - 1/(2n-1) (positive where b is too high, negative where too low), we want to drive r to zero.

The multiplicative update: a[i] *= exp(-lr * p[i]) where p[i] measures how much a[i] "contributes to the peaks."

A natural choice: p[i] = sum_k max(r_k, 0) * a[k-i] / (b_k + eps)

This says: for each peak position k, the "blame" is distributed among the a[j] values proportionally to their contribution a[j]*a[k-j] / b_k = a[j] * a[k-j] / (sum_l a[l]*a[k-l]).

Simplifying: p[i] = sum_k max(b_k - target, 0) * a[k-i] / (b_k + eps)

where target = 1/(2n-1) (the uniform level).

Actually, even simpler: p[i] = sum_k (b_k / target - 1) * a[k-i] / (b_k + eps) * I(b_k > target)

Or the simplest: p[i] = sum_k (b_k - target)_+ * a[k-i] / b_k

Let me think about what happens in the limit of small lr:
- a[i] decreases proportionally to its contribution to the peaks.
- This should gradually flatten the convolution.

The convergence might be slow, but it's stable (no oscillations).

**Combined algorithm:**

I'll alternate between:
1. Gradient descent steps (fast, aggressive, but might oscillate).
2. Multiplicative updates (slow, stable, good for converging).
3. Occasional coordinate descent (local optimization).

```python
"""
Minimizes J(a) = 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Fast FFT-based gradient descent with soft-max annealing
2. Multiplicative (Sinkhorn-like) updates for balancing
3. Coordinate descent for local polishing
4. Multi-restart with diverse initializations and lengths
Key improvements: no LP calls, all iterations are O(n log n),
allowing millions of fast iterations within the time budget.
"""

import numpy as np
import time
from scipy.optimize import minimize_scalar

# Global constants
MAX_N = 2048

def fast_conv(a):
    """Full self-convolution via FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]

def compute_J(a):
    """Compute J(a) = 2*n*max(conv(a,a))/(sum(a))^2."""
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))

def compute_gradient(a, tau):
    """
    Compute gradient of soft-max objective.
    Returns (gradient, b_max, b).
    """
    n = len(a)
    b = fast_conv(a)
    b_max = float(b.max())
    
    # Soft max weights
    b_shifted = b - b.max()
    w = np.exp(b_shifted / tau)
    w = w / w.sum()
    
    # Gradient via FFT cross-correlation
    # grad[i] = 2 * sum_{j=0}^{n-1} w[j+i] * a[j]
    L = 1
    while L < 3 * n - 2:
        L <<= 1
    fw = np.fft.rfft(w, L)
    fa = np.fft.rfft(a, L)
    C = np.fft.irfft(fw * np.conj(fa), L)
    grad = 2.0 * C[:n]
    
    return grad, b_max, b

def gradient_descent_phase(a, deadline, max_iters=50000, tau_start=0.05, tau_end=0.001, lr_init=0.5):
    """
    Gradient descent with soft-max annealing.
    """
    a = np.maximum(a.astype(np.float64), 1e-12)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_bmax = fast_conv(a).max()
    no_improve = 0
    
    lr = lr_init
    tau = tau_start
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        # Compute gradient
        grad, b_max, b = compute_gradient(a, tau)
        
        # Try step
        a_new = a - lr * grad
        a_new = np.maximum(a_new, 0)
        s = a_new.sum()
        if s < 1e-10:
            lr *= 0.5
            if lr < 1e-10:
                lr = lr_init * 0.1
            continue
        a_new = a_new / s
        
        b_new = fast_conv(a_new)
        b_new_max = float(b_new.max())
        
        if b_new_max < b_max - 1e-15:
            a = a_new
            if b_new_max < best_bmax - 1e-14:
                best_bmax = b_new_max
                best_a = a_new.copy()
                no_improve = 0
            else:
                no_improve += 1
            # Slightly increase lr (be more aggressive)
            lr = min(lr * 1.02, 2.0)
        else:
            # Reduce lr
            lr *= 0.7
            no_improve += 1
        
        # Anneal tau
        frac = min(it / max_iters, 1.0)
        tau = tau_start * (tau_end / tau_start) ** frac
        
        if no_improve > 100:
            # Perturb
            a = a + np.random.normal(0, 0.01, n)
            a = np.maximum(a, 1e-8)
            a = a / a.sum()
            no_improve = 0
            lr = lr_init * 0.5
        
        if lr < 1e-12:
            lr = lr_init * 0.01
    
    return best_a, best_bmax

def multiplicative_update(a, lr=0.1, n_iter=100):
    """
    Sinkhorn-like multiplicative update to flatten the convolution.
    """
    a = np.maximum(a.astype(np.float64), 1e-12)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_bmax = fast_conv(a).max()
    
    target = 1.0 / (2 * n - 1)
    
    for it in range(n_iter):
        b = fast_conv(a)
        b_max = float(b.max())
        
        if b_max < best_bmax - 1e-14:
            best_bmax = b_max
            best_a = a.copy()
        
        # Compute pressure
        excess = np.maximum(b - target, 0)
        # p[i] = sum_k excess[k] * a[k-i] / (b[k] + eps)
        # Using FFT:
        w = excess / (b + 1e-15)
        L = 1
        while L < 3 * n - 2:
            L <<= 1
        fw = np.fft.rfft(w, L)
        fa = np.fft.rfft(a, L)
        C = np.fft.irfft(fw * np.conj(fa), L)
        p = C[:n]
        
        # Multiplicative update
        a = a * np.exp(-lr * p)
        a = np.maximum(a, 1e-15)
        a = a / a.sum()
        
        if b_max < target * (1 + 1e-6):
            break
    
    return best_a

def coordinate_descent(a, deadline, max_passes=10):

    Coordinate descent: for each coordinate, try a few candidate values.
    """
    a = np.maximum(a.astype(np.float64), 0)

    if s < 0.01:
        return a
    a = a / s
    n = len(a)
    
    best_a = a.copy()
    best_bmax = fast_conv(a).max()
    
    for p in range(max_passes):
        if time.monotonic() > deadline:
            break
        
        order = np.random.permutation(n)
        b = fast_conv(a)
        improved = False
        
        for i in order:
            if time.monotonic() > deadline:
                break
            
            ai = a[i]

            candidates = [0.0]
            if ai > 1e-8:
                candidates.extend([ai * 0.5, ai * 0.75, ai * 1.25, ai * 1.5])
            else:
                candidates.extend([0.01, 0.05, 0.1])
            
            best_val = b.max()
            best_new = ai
            
            for cand in candidates:
                if abs(cand - ai) < 1e-12:
                    continue
                a[i] = cand
                a_pos = np.maximum(a, 0)
                s_check = a_pos.sum()
                if
