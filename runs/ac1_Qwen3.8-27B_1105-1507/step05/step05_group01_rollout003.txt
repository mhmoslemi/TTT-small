So conv(a,a)[k] = a^T B_k a where B_k is a symmetric matrix (the "anti-identity" shifted). The eigenvalues of B_k are... it's a permutation matrix (specifically, a reversed identity for a particular shift). The eigenvalues of such a matrix are all on the unit circle (±1, and complex roots of unity).

Since B_k is not positive semidefinite in general (it has both positive and negative eigenvalues), the quadratic form a^T B_k a is NOT convex. So the problem of minimizing max_k a^T B_k a is non-convex.

This explains why the problem is hard and why simple convex optimization doesn't directly apply.

However, there's a useful reformulation. Note that:
a^T B_k a = (a * a)[k] where * denotes the appropriate "cross-correlation"

Actually, let me think about this differently using the FFT.

The DFT of a: A[m] = sum_k a[k] e^{-2πimk/n}
The circular autocorrelation: c[k] = sum_i a[i] a[i+k mod n] = IDFT(|A|^2)[k]

For the LINEAR autocorrelation, we can embed in a larger FFT:
If we zero-pad a to length 2n-1 (or next power of 2), then the linear autocorrelation is the IDFT of |FFT(a_padded)|^2, taking the appropriate portion.

So the peak of the linear autocorrelation is related to the peak of the IDFT of |A|^2.

To minimize the peak of IDFT(|A|^2), we want |A|^2 to be as flat as possible. But |A|^2 is the power spectrum, and we can't control it freely because A is the DFT of a non-negative sequence.

This connects to the theory of "low PAPR sequences" in communications!

**Key insight for the algorithm**: We can work in the frequency domain. The power spectrum |A[m]|^2 determines the autocorrelation. We want to minimize the peak of the autocorrelation, which is equivalent to minimizing the peak of IDFT(|A|^2).

But we're constrained to |A|^2 = |DFT(a)|^2 for some non-negative a. This is a hard constraint.

Alternative approach: Work directly with a, use subgradient/gradient methods.

**Subgradient of max_k conv(a,a)[k]**:
At the current point a, let S* = {k : conv(a,a)[k] = max}. Then a subgradient of the max function is any convex combination of the gradients of the active terms.

The gradient of conv(a,a)[k] with respect to a is:
d/da[i] conv[
</think>

Looking at this problem, I need to minimize `2*n*max(conv(a,a))/(sum(a))^2` for non-negative sequences. The key insight is that this is scale-invariant, so I can normalize `sum(a)=1` and minimize `2n * max(conv(a,a))`.

My approach differs from the previous LP-heavy method by using:
1. **Duel method** for coordinate-based optimization (faster per iteration)
2. **Subgradient step** targeting the convolution peak
3. **Spectral shaping** to flatten the power spectrum
4. **Adaptive multi-start** with diverse initializations
5. **Smoothing/truncation** as finishing heuristics

"""
Multi-strategy optimization for minimizing 2*n*max(conv(a,a))/(sum(a))^2.
Uses duel-method coordinate optimization, subgradient peak shaving, spectral
flattening, and multi-start search with diverse initializations.
"""

import numpy as np
from scipy.fft import rfft, irfft, next_fast_len
import time


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    size = next_fast_len(2 * n - 1)
    fa = rfft(a, size)
    conv = irfft(fa * fa, size)[:2 * n - 1]
    max_b = float(np.max(conv))
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    return 2.0 * n * max_b / (s * s)


def compute_conv_fft(a):
    """Compute linear convolution a*a via FFT."""
    n = len(a)
    size = next_fast_len(2 * n - 1)
    fa = rfft(a, size)
    conv = irfft(fa * fa, size)[:2 * n - 1]
    return conv


def duel_optimize(a, max_rounds, time_budget, verbose=False):
    """
    Duel method: iteratively find worst (i,j) pair and move mass.
    Each iteration: find k* = argmax conv, find worst pair (i,j) with i+j=k*,
    move mass from larger to smaller.
    """
    n = len(a)
    a = a.astype(np.float64).copy()
    s = np.sum(a)
    if s < 1e-10:
        a = np.ones(n)
        s = 1.0
    else:
        a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    conv = compute_conv_fft(a)
    no_improve = 0

    for rnd in range(max_rounds):
        if time.monotonic() - start > time_budget:
            break

        k_star = int(np.argmax(conv))

        # Find valid range for i
        i_min = max(0, k_star - n + 1)
        i_max = min(n - 1, k_star)

        if i_min > i_max:
            break

        # Find worst pair
        best_gamma = 0.0
        best_i = -1
        for i in range(i_min, i_max + 1):
            j = k_star - i
            gamma = (a[i] - a[j]) ** 2
            if gamma > best_gamma:
                best_gamma = gamma
                best_i = i

        if best_i < 0 or best_gamma < 1e-16:
            no_improve += 1
            if no_improve > 200:
                break
            # Perturb
            rng = np.random.default_rng(rnd * 31 + 7)
            a = a * np.exp(rng.normal(0, 0.03, n))
            a = np.maximum(a, 0)
            s = np.sum(a)
            if s < 1e-10:
                a = best_a.copy()
            else:
                a = a / s
            conv = compute_conv_fft(a)
            continue

        j = k_star - best_i
        x1 = a[best_i]
        x2 = a[j]

        a[best_i] = (x1 + x2) / 2.0
        a[j] = (x1 + x2) / 2.0

        obj = compute_obj(a)
        if obj < best_obj - 1e-15:
            best_obj = obj
            best_a = a.copy()
            no_improve = 0
        else:
            # Revert
            a[best_i] = x1
            a[j] = x2
            no_improve += 1
            if no_improve > 500:
                # Try smaller moves
                rng = np.random.default_rng(rnd * 17 + 3)
                for _ in range(10):
                    k = int(np.argmax(compute_conv_fft(a)))
                    i_min2 = max(0, k - n + 1)
                    i_max2 = min(n - 1, k)
                    if i_min2 > i_max2:
                        break
                    i = int(rng.integers(i_min2, i_max2 + 1))
                    j2 = k - i
                    avg = (a[i] + a[j2]) / 2.0
                    t = rng.uniform(0.1, 0.5)
                    a_new = a.copy()
                    a_new[i] = (1 - t) * a[i] + t * avg
                    a_new[j2] = (1 - t) * a[j2] + t * avg
                    obj_new = compute_obj(a_new)
                    if obj_new < best_obj:
                        best_obj = obj_new
                        best_a = a_new.copy()
                        a = a_new
                        no_improve = 0
                        break
                if no_improve > 600:
                    break

        if verbose and rnd % 5000 == 0:
            print(f"    Duel rnd={rnd}, obj={best_obj:.6f}")

    return best_a, best_obj


def subgradient_step(a, top_k=10, t=0.01):
    """Subgradient step to reduce peak of convolution."""
    n = len(a)
    a = a.astype(np.float64).copy()
    conv = compute_conv_fft(a)
    s = np.sum(a)

    # Get indices of top peaks
    sorted_idx = np.argsort(conv)[::-1][:top_k]
    # Count frequency of each position
    counts = np.zeros(n)
    for k in sorted_idx:
        k = int(k)
        i_min = max(0, k - n + 1)
        i_max = min(n - 1, k)
        for i in range(i_min, i_max + 1):
            j = k - i
            counts[i] += a[j]
            if i != j:
                counts[j] += a[i]

    # Subtract proportional to counts
    a = a - t * counts
    a = np.maximum(a, 0.0)
    new_s = np.sum(a)
    if new_s < 1e-10:
        return a  # Fallback: return unchanged
    return a / new_s


def smooth_sequence(a, width=3):
    """Apply sliding window smoothing."""
    n = len(a)
    if width <= 1:
        return a.copy()
    kernel = np.ones(width) / width
    a_pad = np.pad(a, width // 2, mode='edge')
    a_smooth = np.convolve(a_pad, kernel, mode='valid')[:n]
    a_smooth = np.maximum(a_smooth, 0)
    s = np.sum(a_smooth)
    if s > 1e-10:
        a_smooth /= s
    return a_smooth


def spectral_flatten(a, alpha=0.3, num_iters=50):
    """Flatten power spectrum to reduce autocorrelation peak."""
    n = len(a)
    a = a.astype(np.float64).copy()
    best = a.copy()
    best_obj = compute_obj(a)
    size = next_fast_len(n)

    for _ in range(num_iters):
        fa = rfft(a, size)
        mag = np.abs(fa)
        phase = np.angle(fa)

        target = np.mean(mag)
        mag_new = (1 - alpha) * mag + alpha * target
        fa_new = mag_new * np.exp(1j * phase)
        a_new = irfft(fa_new, n)
        a_new = np.maximum(a_new, 0)
        s = np.sum(a_new)
        if s < 1e-10:
            break
        a_new /= s
        obj = compute_obj(a_new)
        if obj < best_obj:
            best_obj = obj
            best = a_new.copy()
            a = a_new
        else:
            break

    return best


def spectral_perturb(a, strength=0.1, seed=42):
    """Perturb in frequency domain."""
    n = len(a)
    rng = np.random.default_rng(seed)
    size = next_fast_len(n)
    fa = rfft(a, size)
    mag = np.abs(fa)
    phase = np.angle(fa)
    mag_new = mag * np.exp(rng.normal(0, strength, len(mag)))
    fa_new = mag_new * np.exp(1j * phase)
    a_new = irfft(fa_new, n)
    a_new = np.maximum(a_new, 0)
    s = np.sum(a_new)
    if s > 1e-10:
        a_new /= s
    return a_new


def subgrad_optimize(a, time_budget, verbose=False):
    """Main subgradient optimization loop with adaptive step size."""
    n = len(a)
    a = a.astype(np.float64).copy()
    s = np.sum(a)
    if s < 1e-10:
        a = np.ones(n) / n
    else:
        a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    step = 0.02
    patience = 0
    max_patience = 50

    while time.monotonic() - start < time_budget:
        if time.monotonic() - start > time_budget:
            break

        a = subgradient_step(a, top_k=5, t=step)
        obj = compute_obj(a)

        if obj < best_obj - 1e-14:
            best_obj = obj
            best_a = a.copy()
            patience = 0
            step = min(step * 1.05, 0.05)
        else:
            patience += 1
            if patience >= max_patience:
                step *= 0.7
                patience = 0
                if step < 0.001:
                    break

        if verbose and (best_obj < 1.51 or patience % 50 == 0):
            print(f"    Subgrad obj={best_obj:.6f}, step={step:.5f}")

    return best_a, best_obj


def random_init(n, seed):
    """Generate diverse random initializations."""
    rng = np.random.default_rng(seed)
    k = np.arange(n)
    choice = rng.integers(0, 10)

    if choice == 0:
        f = rng.uniform(0.5, 3.0)
        phase = rng.uniform(0, 2 * np.pi)
        a = 1.0 + 0.7 * np.cos(2 * np.pi * f * k / n + phase)
    elif choice == 1:
        f1 = rng.uniform(0.3, 2.0)
        f2 = rng.uniform(2.0, 8.0)
        a = 1.0 + 0.4 * np.cos(2 * np.pi * f1 * k / n) + 0.3 * np.cos(2 * np.pi * f2 * k / n)
    elif choice == 2:
        a = rng.random(n)
        win = max(3, n // 15)
        kernel = np.ones(win) / win
        a = np.convolve(a, kernel, mode='same')
    elif choice == 3:
        a = np.ones(n)
        for _ in range(rng.integers(1, 5)):
            f = rng.uniform(0.5, 6.0)
            amp = rng.uniform(0.1, 0.5)
            a += amp * np.cos(2 * np.pi * f * k / n + rng.uniform(0, 2 * np.pi))
    elif choice == 4:
        nblocks = rng.integers(2, 8)
        a = np.ones(n)
        for b in range(nblocks):
            st = b * n // nblocks
            en = (b + 1) * n // nblocks
            a[st:en] = rng.uniform(0.3, 1.5)
    elif choice == 5:
        a = rng.random(n) + 0.1
    elif choice == 6:
        # Multi-scale structure
        a = np.ones(n)
        for _ in range(3):
            f = rng.uniform(1.0, 10.0)
            a += 0.2 * np.sin(2 * np.pi * f * k / n + rng.uniform(0, 2 * np.pi))
    elif choice == 7:
        # Triangle wave based
        period = max(3, n // rng.integers(2, 6))
        tri = np.zeros(n)
        for i in range(n):
            phase = (i % period) / period
            tri[i] = 1.0 - 4.0 * abs(phase - 0.5)
        a = 1.0 + 0.5 * tri
    elif choice == 8:
        # Power-law decay from center
        center = n / 2.0
        a = 1.0 + 0.5 * np.exp(-0.5 * ((k - center) / (n * 0.2)) ** 2)
    else:
        # Random walk smoothed
        a = np.cumsum(rng.standard_normal(n))
        a = a - np.min(a)
        a = a / (np.max(a) + 1e-10)
        a = 0.5 + 0.5 * a

    a = np.maximum(a, 0.01)
    s = np.sum(a)
    if s < 1e-10:
        a = np.ones(n) / n
    else:
        a = a / s
    return a


def resample_sequence(a, new_n):
    """Resample sequence to new length via interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)


def combined_search(a, time_budget, verbose=False):
    """Combined optimization: subgradient + duel + spectral + smoothing."""
    n = len(a)
    a = a.astype(np.float64).copy()
    s = np.sum(a)
    if s < 1e-10:
        a = np.ones(n) / n
    else:
        a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()

    phase = 0
    phase_names = ["subgrad", "duel", "spectral", "smooth", "subgrad2", "duel2"]
    phase_time = [0.3, 0.25, 0.1, 0.05, 0.2, 0.1]

    for pi in range(len(phase_names)):
        if time.monotonic() - start > time_budget:
            break
        remaining = time_budget - (time.monotonic() - start)
        if remaining < 1:
            break

        alloc = remaining * phase_time[pi] / sum(phase_time[pi:])
        name = phase_names[pi]

        if verbose:
            print(f"  Phase '{name}': {alloc:.1f}s")

        if name == "subgrad" or name == "subgrad2":
            a, obj = subgrad_optimize(a, time_budget=alloc)
            if obj < best_obj:
                best_obj = obj
                best_a = a.copy()
                a = a.copy()

        elif name == "duel" or name == "duel2":
            a, obj = duel_optimize(a, max_rounds=500000, time_budget=alloc)
            if obj < best_obj:
                best_obj = obj
                best_a = a.copy()
                a = a.copy()

        elif name == "spectral":
            for _ in range(3):
                if time.monotonic() - start > time_budget:
                    break
                a_new = spectral_flatten(a, alpha=0.3, num_iters=30)
                obj = compute_obj(a_new)
                if obj < best_obj:
                    best_obj = obj
                    best_a = a_new.copy()
                    a = a_new
                else:
                    break

        elif name == "smooth":
            for w in [3, 5, 7]:
                if time.monotonic() - start > time_budget:
                    break
                a_smooth = smooth_sequence(a, width=w)
                obj = compute_obj(a_smooth)
                if obj < best_obj:
                    best_obj = obj
                    best_a = a_smooth.copy()
                    a = a_smooth

    return best_a, best_obj
