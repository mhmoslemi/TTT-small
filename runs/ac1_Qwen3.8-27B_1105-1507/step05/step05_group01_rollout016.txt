"""
Multi-strategy optimizer for minimizing 2*n*max(conv(a,a))/(sum(a))^2.
Combines monotone parameterization, multiplicative gradient descent,
LP alternation, and simulated annealing for robust local search.
"""

import numpy as np
from scipy.optimize import linprog
from scipy.fft import rfft, irfft
import time


def compute_conv(a):
    n = len(a)
    if n == 0:
        return np.array([0.0])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    conv = irfft(fa * fa, size)
    return conv[:2 * n - 1]


def compute_obj(a):
    n = len(a)
    if n == 0:
        return np.inf
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)


def build_toeplitz_fast(a):
    n = len(a)
    m = 2 * n - 1
    A = np.zeros((m, n), dtype=np.float64)
    for j in range(n):
        end = min(j + n, m)
        A[j:end, j] = a[:end - j]
    return A


def solve_lp(a, M, relax=1.0):
    n = len(a)
    m = 2 * n - 1
    c = -np.ones(n)
    b_ub = np.full(m, M * relax)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c, A_ub=build_toeplitz_fast(a), b_ub=b_ub, bounds=bounds,
                      method='highs', options={'presolve': True})
        if res.status == 0:
            g = np.maximum(res.x, 0)
            s = float(np.sum(g))
            return g, s
    except Exception:
        pass
    return None, 0.0


def multiplicative_descent(a, num_iters=2000, time_budget=60.0, n_peaks=3):
    n = len(a)
    a = a.copy().astype(np.float64)
    s = np.sum(a)
    if s < 1e-10:
        a = np.ones(n) / n
    else:
        a = a / s
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    lr = 2.0 / n
    
    for it in range(num_iters):
        if time.monotonic() - start > time_budget:
            break
        
        conv = compute_conv(a)
        top_idx = np.argsort(conv)[::-1][:n_peaks]
        
        grad = np.zeros(n)
        for k in top_idx:
            k = int(k)
            w = conv[k]
            j_start = max(0, k - n + 1)
            j_end = min(n - 1, k)
            if j_start <= j_end:
                indices = np.arange(j_start, j_end + 1)
                src = k - indices
                grad[j_start:j_end+1] += w * 2.0 * a[src]
        
        gmax = np.max(grad)
        if gmax < 1e-15:
            break
        
        a_new = a * np.exp(-lr * grad / gmax)
        a_new = np.maximum(a_new, 1e-15)
        s_new = np.sum(a_new)
        a_new = a_new / s_new
        
        obj_new = compute_obj(a_new)
        if obj_new < best_obj - 1e-15:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new
            lr = max(lr * 0.9995, 0.001 / n)
        else:
            lr *= 0.7
    
    return best_a, best_obj

Hmm, I realize I should think more carefully about what will actually give an improvement. The parent already does LP alternation, peak-targeted perturbations, and spectral shaping. The question is: what's missing?

Let me think about the problem from a different angle.

The objective is 2n * max_b / (sum_a)^2. Let's normalize sum_a = 1, so we minimize 2n * max_b.

For the parent (n=700, obj=1.506669): max_b = 1.506669 / (2*700) = 0.001076.

The sum of all conv values = (sum_a)^2 = 1. There are 2*700-1 = 1399 values. The average is 1/1399 ≈ 0.000715.

So the peak is 0.001076 / 0.000715 ≈ 1.505 times the average. The conv is fairly flat, with the peak only 50% above average.

To improve the objective to 1.5027, we need max_b = 1.5027 / 1400 = 0.0010734. That's a reduction of 0.001076 - 0.0010734 = 0.0000026, or about 0.24% relative reduction in max_b.

This is a very small improvement. We need to very precisely flatten the autocorrelation.

Key question: what's the structure of the parent that gives this low peak? And how can we tweak it slightly to reduce the peak further?

I think the most effective approach is:
1. Load the parent.
2. Compute the conv and identify the top peaks.
3. For each top peak, compute the "sensitivity" of the peak to each a_j.
4. Make small, targeted adjustments to a_j to reduce the top peaks.
5. Use the LP as a polishing step.

The sensitivity of (conv(a,a))_k to a_j is 2*a_{k-j} (as computed before). So to reduce the peak at k*, we should decrease a_j for j where a_{k*-j} is large.

But we need to be careful: decreasing a_j might increase other peaks. So we need to consider the global effect.

A practical approach: use a "repelling" strategy. For the top peak at k*, apply a repulsive force to the positions that contribute most to that peak. The force on a_j is proportional to a_{k*-j} (the contribution of a_j to the peak).

This is essentially what the multiplicative gradient descent does. But we can make it more sophisticated by:
1. Using a smooth approximation of the max (to handle multiple peaks simultaneously).
2. Using an adaptive step size.
3. Adding a "regularization" term to keep the sequence from becoming too sparse.

Let me also consider the **soft-max** approach. Instead of tracking the single peak, use:
soft_max_M = (1/T) * log(sum_k exp(T * conv_k))

For large T, this approximates the max. For smaller T, it's a smooth function that's easier to optimize.

The gradient of soft_max with respect to a_j is:
d(soft_max)/da_j = (1/T) * (sum_k exp(T*conv_k) * T * d(conv_k)/da_j) / (sum_k exp(T*conv_k))
= sum_k [exp(T*conv_k) / sum_m exp(T*conv_m)] * d(conv_k)/da_j
= sum_k p_k * 2 * a_{k-j} (where p_k is the softmax weight)

This is a weighted average of the gradients at all positions, weighted by the softmax. For large T, it concentrates on the peak. For smaller T, it spreads the gradient over multiple positions.

This is a nice approach! Let me implement it.
