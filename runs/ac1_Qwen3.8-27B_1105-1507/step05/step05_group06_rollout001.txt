   - Exact 1D optimization per coordinate (using the convexity in delta)
   - Multiple passes
   - Random ordering

3. **LP mirror descent** (keeping from before but with improvements):
   - Better line search
   - Periodic restarts

4. **Multi-start** with diverse initializations

Let me code this up. I'll make the coordinate descent especially strong since we're close to the optimum and need fine-grained improvements.

For the coordinate descent, the key optimization is:
Given a with a[i] fixed, find the best value for a[i].
Let a[i] = x. Then c[k] as a function of x is:
c[k](x) = c[k]_old - 2*a[i]_old*a[k-i] + 2*x*a[k-i] + x^2*[k=2i... 

Wait, let me redo this. If we change a[i] from old to new:
delta = new - old
c_new[k] = c_old[k] + 2*delta*a[k-i] + delta^2 (if k = 2i)

But when we're optimizing a[i], we should express c[k] directly in terms of a[i]:
c[k] = (a[i] + sum_{j != i} a[j]) * (a[k-i] + ...) 

No, that's not right. Let me just use the delta formulation.

If current a[i] = x, and we want to try a[i] = y:
delta = y - x
c_new[k] = c[k] + 2*delta*a[k-i] + delta^2 * [k == 2i and 0 <= i <= n-1]

Wait, the delta^2 term: it's delta^2 * delta_{j,i} * delta_{k-j,i} = delta^2 if k = 2i.

But also, the indices k-i must be valid (0 <= k-i <= n-1).

So: for k in [i, i+n-1] intersect [0, 2n-2]:
  c_new[k] = c[k] + 2*(y-x)*a[k-i] + (y-x)^2 * [k == 2i]
For other k: c_new[k] = c[k]

And the sum changes: sum_new = sum_old + (y - x)

J(y) = 2n * max_k c_new[k] / sum_new^2

We want to minimize J(y) over y >= 0.

Since c_new[k] is linear in y (for k != 2i) or quadratic in y (for k = 2i), and we take the max, the function max_k c_new[k] is convex in y. And dividing by sum_new^2 (which is also a function of y) makes it more complex, but it should still be unimodal in y for reasonable ranges.

We can use scipy.minimize_scalar with bounds method to find the optimal y for each coordinate.

Let me now write the full code:

```python
"""
Minimizes J(a) = 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Soft-max projected gradient descent with Nesterov acceleration
2. Exact coordinate descent (1D convex minimization per coordinate)
3. LP mirror descent with bilinear line search
4. Multi-start with diverse initializations and length exploration
"""

import numpy as np
from scipy.optimize import linprog, minimize_scalar
from scipy.sparse import csr_matrix
import time


def fast_conv(a):
    """Full self-convolution via FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]


def cross_conv(a, b):
    """Full cross-convolution a*b via FFT."""
    n = max(len(a), len(b))
    size = 1
    while size < len(a) + len(b) - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:len(a) + len(b) - 1]


def compute_J(a):
    """Compute J(a) = 2*n*max(conv(a,a))/(sum(a))^2."""
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))


def softmax_obj_and_grad(a, tau):
    """
    Compute the soft-max approximation of max(conv(a,a)) and its gradient.
    Returns (value, gradient).
    """
    n = len(a)
    c = fast_conv(a)
    
    # Soft-max with temperature tau
    # Use shifted soft-max for numerical stability
    c_max = c.max()
    exp_c = np.exp(tau * (c - c_max))
    sum_exp = exp_c.sum()
    w = exp_c / sum_exp  # softmax weights
    
    value = c_max + np.log(sum_exp) / tau
    
    # Gradient: sum_k w[k] * grad c[k]
    # grad c[k] / grad a[j] = 2*a[k-j] (if valid) + a[k-j] * [k=2j]... 
    # Actually: d(c[k])/da[j] = 2*a[k-j] if 0<=k-j<=n-1 and j!=k/2
    #                                 a[k-j] if j=k/2 (i.e., 2j=k)
    #                                 0 otherwise
    # This is: (1 + [2j=k]) * a[k-j] if 0<=k-j<=n-1
    
    # More efficiently: grad[j] = sum_k w[k] * (1 + [2j==k]) * a[k-j] * [0<=k-j<=n-1]
    # = sum_k w[k] * a[k-j] * [0<=k-j<=n-1] + sum_k w[k] * a[k-j] * [k==2j] * [0<=k-j<=n-1]
    # = sum_{k-j in [0,n-1]} w[k] * a[k-j] + w[2j] * a[j] (if 2j < 2n-1)
    
    # First term: for fixed j, k ranges from j to j+n-1 (clipped to [0, 2n-2])
    # Let m = k-j, so m ranges from 0 to n-1
    # sum_m w[j+m] * a[m] for m in [0, n-1] (with j+m valid)
    
    # This is a cross-correlation of w with a!
    # grad_first[j] = sum_{m=0}^{n-1} w[j+m] * a[m] (where j+m < 2n-1)
    
    # We can compute this via FFT or directly
    # For efficiency, let's use the fact that it's a convolution:
    # grad_first = cross_correlation(w, a)
    
    # Actually, let's just compute it directly for clarity (n is at most ~2048)
    grad = np.zeros(n)
    for j in range(n):
        # k ranges from j to min(j+n-1, 2n-2)
        k_lo = j
        k_hi = min(j + n - 1, 2 * n - 2)
        if k_lo <= k_hi:
            # m = k - j ranges from 0 to k_hi - j
            grad[j] = np.sum(w[k_lo:k_hi+1] * a[:k_hi-k_lo+1])
        # Add the diagonal correction
        if 2 * j < 2 * n - 1:
            grad[j] += w[2 * j] * a[j]
    
    return value, grad


def softmax_obj_and_grad_fast(a, tau):
    """
    Fast computation of soft-max objective and gradient using FFT.
    """
    n = len(a)
    c = fast_conv(a)
    
    c_max = c.max()
    exp_c = np.exp(tau * (c - c_max))
    sum_exp = exp_c.sum()
    w = exp_c / sum_exp
    
    value = c_max + np.log(sum_exp) / tau
    
    # grad[j] = sum_{k=j}^{min(j+n-1, 2n-2)} w[k] * a[k-j] + w[2j]*a[j] (if 2j valid)
    # First term is the cross-correlation of w and a (reversed)
    # cross_corr[j] = sum_m w[j+m] * a[m] = (w * flip(a))[j + n - 1] ... 
    # Let me think about this differently.
    # Let r = flip(a) = a[::-1]. Then r[m'] = a[n-1-m'].
    # cross_corr[j] = sum_{m=0}^{min(n-1, 2n-2-j)} w[j+m] * a[m]
    # 
    # This is the convolution (w * a)[j + n - 1] ... no.
    # 
    # Actually: (w conv a)[k] = sum_i w[i] * a[k-i]
    # We want: sum_m w[j+m] * a[m] = sum_i w[i] * a[i-j] where i = j+m
    # = sum_i w[i] * a[i-j]
    # This is (flip(w) conv a)[n-1-j] ... hmm, let me just use FFT.
    # 
    # Let's define: h[j] = sum_{m} w[j+m] * a[m] for valid indices
    # This is the cross-correlation of w and a, specifically:
    # h[j] = <w[j:], a[:n]> (inner product of shifted w with a)
    # 
    # Equivalently: h = np.correlate(w, a, mode='full')[n-1:n-1+n]
    # Or: h[j] = sum_{m=0}^{n-1} w[j+m]*a[m] where j+m < len(w)
    # 
    # Using FFT: if we pad to size 2n, then:
    # Pad a to size>=2n, pad w to size>=2n
    # h[j] = sum_m FFT^{-1}[W * A] ... 
    # 
    # Actually the simplest: h is the convolution of w with flip(a), evaluated at specific positions.
    # flip(a) has length n. w has length 2n-1.
    # (w * flip(a))[k] = sum_i w[i] * flip(a)[k-i] = sum_i w[i] * a[n-1-(k-i)]
    # We want h[j] = sum_m w[j+m] * a[m]
    # Let i = j+m: h[j] = sum_i w[i] * a[i-j] where i goes from j to j+n-1
    # = sum_i w[i] * a[i-j]
    # 
    # And (flip(w) * a)[k] = sum_i flip(w)[i] * a[k-i] = sum_i w[2n-2-i] * a[k-i]
    # Let i' = 2n-2-i: = sum_{i'} w[i'] * a[k-2n+2+i']
    # 
    # This is getting complicated. Let me just use np.correlate or compute directly.
    # For n up to 2048, direct computation is O(n^2) = ~4M operations, which is fine.
    
    grad = np.zeros(n)
    # Use the efficient formula
    for j in range(n):
        k_hi = min(j + n - 1, 2 * n - 2)
        if k_hi >= j:
            # m goes from 0 to k_hi - j
            grad[j] = np.dot(w[j:k_hi+1], a[:k_hi-j+1])
        if 2 * j < 2 * n - 1:
            grad[j] += w[2 * j] * a[j]
    
    return value, grad


def prox_simplex(v, sigma):
    """
    Project v onto the set {x >= 0, sum(x) <= sigma} (or sum(x) = sigma for the simplex).
    Actually, we want projection onto {x >= 0, sum(x) = 1}.
    """
    # Project onto probability simplex
    n = len(v)
    # Use the standard algorithm
    u = np.sort(v)[::-1]
    cv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cv - 1))[0][-1]
    theta = (cv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)


def softmax_gradient_descent(a, deadline, tau_start=5.0, tau_end=500.0, 
                               n_anneal_steps=200, momentum=0.9):
    """
    Soft-max projected gradient descent with Nesterov momentum and annealed temperature.
    """
    a = np.maximum(a.astype(np.float64), 0)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_J = compute_J(a)
    
    v = a.copy()  # Nesterov momentum variable
    
    for it in range(n_anneal_steps):
        if time.monotonic() > deadline:
            break
        
        # Anneal temperature
        frac = it / max(1, n_anneal_steps - 1)
        tau = tau_start * (tau_end / tau_start) ** frac
        
        # Nesterov step
        a_eval = np.maximum(v - momentum * momentum * np.zeros(n), 0)
        # Actually, let's use a simpler version:
        # v_new = v + momentum * (a - v)
        # a_new = proj(v_new - eta * grad)
        
        val, grad = softmax_obj_and_grad_fast(a, tau)
        
        # Adaptive step size
        # Lipschitz constant estimate: ~ tau * 2 * max(a) * n (rough)
        # Use backtracking
        L = tau * 2.0 * n * (a.max() + 0.01)
        eta = 1.0 / L
        
        # Gradient step
        v = v + momentum * (a - v)  # Momentum update
        a_candidate = v - eta * grad
        
        # Project onto simplex
        a_candidate = prox_simplex(a_candidate, 1.0)
        
        if a_candidate.sum() < 0.01:
            break
        
        # Check improvement
        J_new = compute_J(a_candidate)
        
        if J_new < best_J - 1e-14:
            best_J = J_new
            best_a = a_candidate.copy()
        a = a_candidate
        
        if it % 50 == 0:
            print(f"    softmax GD: it={it}, tau={tau:.1f}, J={J_new:.8f}", flush=True)
    
    return best_a


def softmax_gradient_descent_v2(a, deadline, tau_schedule=None, max_iters=500):
    """
    Improved soft-max gradient descent with backtracking line search.
    """
    a = np.maximum(a.astype(np.float64), 0)
    s = a.sum()
    if s < 0.01:
        return a
    a = a / s
    n = len(a)
    
    best_a = a.copy()
    best_J = compute_J(a)
    
    momentum = 0.85
    v = a.copy()
    
    if tau_schedule is None:
        tau_schedule = np.logspace(np.log10(5), np.log10(500), max_iters)
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        tau = tau_schedule[min(it, len(tau_schedule) - 1)]
        
        # NesterovLook-ahead
        a_look = v + momentum * (v - a) if it > 0 else a.copy()
        a_look = np.maximum(a_look, 0)
        if a_look.sum() < 0.01:
            a_look = a.copy()
        else:
            a_look = a_look / a_look.sum()
        
        val, grad = softmax_obj_and_grad_fast(a_look, tau)
        
        # Backtracking line search
        eta = 0.1 / (tau * n)
        a_trial = v - eta * grad
        a_trial = prox_simplex(a_trial, 1.0)
        
        # We want to minimize the actual J, not the soft-max
        J_trial = compute_J(a_trial)
        
        backtracks = 0
        while J_trial > best_J + 1e-12 and backtracks < 20:
            eta *= 0.5
            a_trial = v - eta * grad
            a_trial = prox_simplex(a_trial, 1.0)
            J_trial = compute_J(a_trial)
            backtracks += 1
        
        if J_trial < best_J - 1e-14:
            best_J = J_trial
            best_a = a_trial.copy()
        
        # Update Nesterov
        a_new = a_trial
        v = a_trial + momentum * (a_new - a)
        a = a_new
        
        if it % 50 == 0:
            print(f"    softmax GD v2: it={it}, tau={tau:.1f}, J={best_J:.8f}", flush=True)
    
    return best_a


def coordinate_descent_exact(a, deadline, max_passes=30):
    """
    Exact coordinate descent: for each coordinate, find optimal value via 1D minimization.
    Uses the structure of how convolution changes when one coordinate changes.
    """
    a = np.maximum(a.astype(np.float64), 0)
    s = a.sum()
    if s < 0.01:
        return a
    a = a / s
    n = len(a)
    
    best_a = a.copy()
    best_J = compute_J(a)
    
    for p in range(max_passes):
        if time.monotonic() > deadline:
            break
        
        order = np.random.permutation(n)
        c = fast_conv(a)
        S = a.sum()
        improved = False
        any_change = False
        
        for i in order:
            if time.monotonic() > deadline:
                break
            
            ai = a[i]
            
            # Define the objective as a function of y = a[i]
            # c_new[k] = c[k] + 2*(y-ai)*a[k-i] + (y-ai)^2 * [k==2i]
            # S_new = S + (y-ai)
            # J(y) = 2n * max_k c_new[k] / S_new^2
            
            def obj(y):
                if y < 0 or S + (y - ai) < 0.01:
                    return float('inf')
                delta = y - ai
                # Compute new max
                # Affected k: from i to min(i+n-1, 2n-2)
                k_lo = i
                k_hi = min(i + n - 1, 2 * n - 2)
                
                if delta == 0:
                    return 2 * n * c.max() / (S * S)
                
                # New values for affected k
                new_vals = c[k_lo:k_hi+1].copy()
                for idx in range(len(new_vals)):
                    k = k_lo + idx
                    m = k - i  # = idx
                    new_vals[idx] += 2 * delta * a[m]
                    if k == 2 * i:
                        new_vals[idx] += delta * delta
                
                # Outside max
                if k_lo > 0:
                    outside = c[:k_lo].max()
                else:
                    outside = 0.0
                if k_hi < 2 * n - 2:
                    outside = max(outside, c[k_hi+1:].max())
                
                new_max = max(outside, new_vals.max())
                S_new = S + delta
                return 2 * n * new_max / (S_new * S_new)
            
            # Find optimal y using minimize_scalar
            # Search range: [0, 3*ai + 0.5/n]
            y_lo = 0.0
            y_hi = max(3 * ai + 0.5 / n, 1.0 / n)
            
            result = minimize_scalar(obj, bounds=(y_lo, y_hi), method='bounded',
                                     options={'xatol': 1e-10})
            
            if result.success and result.fun < 2 * n * c.max() / (S * S) - 1e-12:
                a[i] = result.x
                improved = True
                any_change = True
                # Update c and S
                delta = result.x - ai
                S = S + delta
                k_lo = i
                k_hi = min(i + n - 1, 2 * n - 2)
                for idx in range(k_hi - k_lo + 1):
                    k = k_lo + idx
                    m = k - i
                    c[k] += 2 * delta * a[m]
                    if k == 2 * i:
                        c[k] += delta * delta
        
        # Renormalize
        a = np.maximum(a, 0)
        S = a.sum()
        if S > 0.01:
            a = a / S
            c = fast_conv(a)
            J = 2 * n * c.max() / (S * S)  # S is now 1, so just 2n*c.max()
            J = compute_J(a)
            if J < best_J - 1e-14:
                best_J = J
                best_a = a.copy()
        
        if not improved:
            break
    
    return best_a


def build_lp_matrix(n, a):
    """Build sparse constraint matrix for LP."""
    total_entries = 0
    for k in range(2 * n - 1):
        j_min = max(0, k - n + 1)
        j_max = min(n - 1, k)
        total_entries += j_max - j_min + 1
    
    rows = np.empty(total_entries, dtype=np.int32)
    cols = np.empty(total_entries, dtype=np.int32)
    vals = np.empty(total_entries, dtype=np.float64)
    idx = 0
    for k in range(2 * n - 1):
        j_min = max(0, k - n + 1)
        j_max = min(n - 1, k)
        for j in range(j_min, j_max + 1):
            rows[idx] = k
            cols[idx] = j
            vals[idx] = a[k - j]
            idx += 1
    A = csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
    return A


def lp_mirror_descent(a, deadline, max_iters=3000, use_cd_every=30):
    """LP mirror descent with bilinear line search."""
    a = np.maximum(a.astype(np.float64), 1e-10)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_J = compute_J(a)
    no_improve = 0
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b_aa = fast_conv(a)
        M = float(b_aa.max())
        
        # Solve LP
        A = build_lp_matrix(n, a)
        c_vec = -np.ones(n)
        b_ub = np.full(2 * n - 1, M)
        bounds = [(0, None)] * n
        
        try:
            r = linprog(c_vec, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                        options={'time_limit': 30, 'presolve': True})
            if not (r.success and r.x is not None):
                break
            g = np.maximum(r.x, 0)
        except Exception:
            break
        
        g_sum = g.sum()
        if g_sum < 1e-15:
            break
        g = g / g_sum
        
        # Bilinear line search
        b_ag = cross_conv(a, g)
        b_gg = fast_conv(g)
        
        def line_obj(t):
            b = (1 - t) ** 2 * b_aa + 2 * t * (1 - t) * b_ag + t * t * b_gg
            return b.max()
        
        result = minimize_scalar(line_obj, bounds=(0.0, 1.0), method='bounded',
                                 options={'xatol': 1e-8})
        t_opt = float(result.x)
        
        a_new = np.maximum((1 - t_opt) * a + t_opt * g, 0)
        s = a_new.sum()
        if s < 1e-10:
            break
        a_new = a_new / s
        
        J_new = compute_J(a_new)
        
        if J_new < best_J - 1e-14:
            best_a = a_new.copy()
            best_J = J_new
            a = a_new
            no_improve = 0
        else:
            no_improve += 1
        
        if use_cd_every > 0 and it % use_cd_every == use_cd_every - 1:
            a_cd = coordinate_descent_exact(a, min(deadline, time.monotonic() + 30), max_passes=3)
            J_cd = compute_J(a_cd)
            if J_cd < best_J - 1e-14:
                best_J = J_cd
                best_a = a_cd.copy()
            a = a_cd
            no_improve = 0
        
        if no_improve > 80:
            a = a + np.random.normal(0, 0.03, n)
            a = np.maximum(a, 0.001)
            a = a / a.sum()
            no_improve = 0
    
    return best_a, best_J


def generate_diverse_inits(n, rng):
    """Generate diverse initializations."""
    inits = []
    t = np.linspace(0, 1, n, endpoint=False)
    
    inits.append(np.ones(n) / n)
    
    r = rng.uniform(0.5, 1.5, n)
    inits.append(r / r.sum())
    
    # Exponential decay
    for rate in [1, 2, 3, 5]:
        exp_dec = np.exp(-rate * t)
        inits.append(exp_dec / exp_dec.sum())
    
    # Rising exponential
    for rate in [1, 2, 3]:
        exp_rise = np.exp(rate * t)
        inits.append(exp_rise / exp_rise.sum())
    
    # Cosine window
    for freq in [1, 2, 3, 4, 6]:
        cw = 0.5 + 0.5 * np.cos(2 * np.pi * freq * t + rng.uniform(0, 2*np.pi))
        cw = np.maximum(cw, 0.01)
        inits.append(cw / cw.sum())
    
    # Asymmetric (important! symmetric sequences can't beat J=2)
    for alpha in [0.3, 0.5, 0.7]:
        asym = np.exp(-alpha * t) * (1 + (1-alpha) * np.exp(-2*(1-t)))
        inits.append(asym / asym.sum())
    
    # Random smooth
    ksize = max(3, n // 20)
    kernel = np.ones(ksize) / ksize
    sm = np.convolve(rng.uniform(0, 1, n), kernel, mode='same')
    sm = np.maximum(sm + 0.1, 0.01)
    inits.append(sm / sm.sum())
    
    # Power law
    for alpha in [0.5, 1.0, 1.5, 2.0]:
        pl = (t + 0.01) ** alpha
        inits.append(pl / pl.sum())
    
    return inits


def resample_seq(src, dest_n):
    """Resample 1D sequence to new length."""
    src = np.asarray(src, dtype=np.float64)
    if src.size == dest_n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, dest_n)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)


def propose_candidate(seed=42, budget_s=1500, **kwargs):
    """
    Multi-phase search for minimizing J(a) = 2n*max(conv(a,a))/(sum(a))^2.
    Uses soft-max gradient descent, coordinate descent, and LP mirror descent.
    """
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + float(budget_s) - 15.0
    t_start = time.monotonic()
    
    best_seq = None
    best_score = float('inf')
    
    def update_best(a):
        nonlocal best_seq, best_score
        a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
        if a.size == 0 or a.sum() < 0.01:
            return
        score = float(evaluate_sequence(a.tolist()))
        if np.isfinite(score) and score < best_score:
            best_score = score
            best_seq = a.copy()
            elapsed = time.monotonic() - t_start
            print(f"  ** J={score:.8f} n={a.size} t={elapsed:.0f}s", flush=True)
    
    # Load parent
    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        if p.ndim == 1 and p.size > 0 and np.all(np.isfinite(p)):
            parent = np.maximum(p, 0.0)
            update_best(parent)
            print(f"Parent loaded: n={parent.size}, J={best_score:.6f}", flush=True)
    except (NameError, AttributeError):
        pass
    
    if parent is None:
        parent = np.ones(256) / 256
        update_best(parent)
    
    # === PHASE 1: Coordinate descent on parent (quick win) ===
    p1_dl = min(t_start + 120, deadline - 600)
    print(f"\n{'='*60}", flush=True)
    print(f"PHASE 1: Coordinate Descent on parent (budget={p1_dl - t_start:.0f}s)", flush=True)
    print(f"{'='*60}", flush=True)
    
    a_cd = coordinate_descent_exact(parent, p1_dl, max_passes=20)
    update_best(a_cd)
    print(f"  Phase 1 done: best J={best_score:.8f}", flush=True)
    
    # === PHASE 2: Soft-max gradient descent ===
    p2_dl = min(t_start + 350, deadline - 500)
    print(f"\n{'='*60}", flush=True)
    print(f"PHASE 2: Soft-max Gradient Descent (budget={p2_dl - (p1_dl if best_seq is not None else t_start):.0f}s)", flush=True)
    print(f"{'='*60}", flush=True)
    
    if best_seq is not None:
        a_sgd = softmax_gradient_descent_v2(best_seq, p2_dl, max_iters=300)
        update_best(a_sgd)
        # Polish with CD
        a_cd = coordinate_descent_exact(a_sgd, min(p2_dl + 30, deadline - 400), max_passes=10)
        update_best(a_cd)
        print(f"  Phase 2 done: best J={best_score:.8f}", flush=True)
    
    # === PHASE 3: LP mirror descent ===
    p3_dl = min(t_start + 700, deadline - 300)
    print(f"\n{'='*60}", flush=True)
    print(f"PHASE 3: LP Mirror Descent (budget={p3_dl - p2_dl:.0f}s)", flush=True)
    print(f"{'='*60}", flush=True)
    
    if best_seq is not None:
        a_lp, J_lp = lp_mirror_descent(best_seq, p3_dl, max_iters=2000, use_cd_every=25)
        update_best(a_lp)
        a_cd = coordinate_descent_exact(a_lp, min(p3_dl + 30, deadline - 250), max_passes=10)
        update_best(a_cd)
        print(f"  Phase 3 done: best J={best_score:.8f}", flush=True)
    
    # === PHASE 4: Multi-start with diverse initializations ===
    p4_dl = min(t_start + 1050, deadline - 200)
    print(f"\n{'='*60}", flush=True)
    print(f"PHASE 4: Multi-start Diverse (budget={p4_dl - p3_dl:.0f}s)", flush=True)
    print(f"{'='*60}", flush=True)
    
    if best_seq is not None:
        n_best = best_seq.size
        inits = generate_diverse_inits(n_best, rng)
        # Add perturbed best

        inits[-1] = inits[-1] / inits[-1].sum()
        inits.append(np.maximum(best_seq + rng.normal(0, 0.1, n_best), 0.01))
