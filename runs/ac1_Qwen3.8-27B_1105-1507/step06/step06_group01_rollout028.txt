If the active set is S = {k0, k0+1, ..., k0+w} (a contiguous block of width w), and the multipliers are uniform (lambda_k = 1/(w+1)), then:
(B a)_j = (1/(w+1)) * sum_{k=k0}^{k0+w} a_{k-j}

sum_{k=k0}^{k0+w} a_{k-j} = (w+1)*nu = constant

This means that the "sliding window sum" of a is constant. This implies that a is periodic with period related to the window... actually no, it means a_{k-j} sums to a constant over a window of width w. This is a linear recurrence:
a_{k-w-j} + ... + a_{k-j} = C for all j.

This gives: a_{k-w+1-j} - a_{k-w-j} = 0, i.e., a_{m} = a_{m-w-1} (for valid indices).

So a is periodic with period w+1! That's a very specific structure.

For example, if w = n-2 (all but one constraint active), then a is periodic with period n-1. Since the support is [0, n-1], this means a_0 = a_{n-1} (the only relation from period n-1 within [0,n-1]).

Actually, let me reconsider the QP approach. The QP min a^T Q a subject to a >= 0, sum(a) = 1 is a standard problem. But if Q is not PSD, it's non-convex and might be hard to solve.

An alternative: instead of solving the QP directly, we can use it as a descent direction. Compute the gradient of q(a) = a^T Q a at the current point, and take a step in the negative gradient direction (projected onto the tangent space of the simplex).

The gradient of q(a) at a is: grad = 2 Q a (or Q a + Q^T a if Q is not symmetric; but Q is symmetric by construction since Q_{j,l} = Q_{l,j} = sum_k lambda_k * delta(j+l=k)).

So grad_j = 2 * sum_k lambda_k * a_{k-j} = 2 * (B a)_j.

The stationarity condition says (B a)_j = nu for all j with a_j > 0. So at the optimum, the gradient is constant on the support, which is the KKT condition for the simplex-constrained problem.

So the QP approach is equivalent to: at each iteration, compute B a (using the current dual multipliers), and the "descent direction" is -(B a) + mean(B a) (projected onto the tangent space). This is exactly what the mirror descent / FISTA approaches do, but with the multipliers from the LP dual instead of uniform weights!

This is a key insight: **The LP dual gives us the optimal weights for the linear combination of constraints, leading to a better descent direction than using all constraints equally.**

So the algorithm is:
1. Solve LP to get dual multipliers lambda.
2. Compute d = B(a; lambda) = [sum_k lambda_k * a_{k-j}]_j.
3. Take a step: a_new = proj_simplex(a - step * (d - d.mean())).
4. Or use mirror descent: a_new = proj_simplex(a * exp(-step * (log(d) - mean(log(d))))).
5. Repeat.

This is essentially the same as the previous mirror descent, but with a much better choice of "subgradient" (the LP dual gives the optimal subgradient of the max function).

Actually, I realize this is very close to what the previous code does in `run_mirror_descent`, except the previous code uses the subgradient at the single active index (the argmax), while the LP dual gives a weighted combination of subgradients from all active constraints. This should give a much better direction!

"""
Minimizes J(a) = 2*n*max(conv(a,a))/(sum(a))^2 using LP-guided descent with QP polish.
Key innovation: uses the LP dual (implicit) to get optimal subgradients for the max,
combined with direct QP solves for final refinement.
"""

import numpy as np
from scipy.optimize import linprog, minimize
from scipy.sparse import csr_matrix
import time


def fast_conv(a):
    """FFT-based linear self-convolution."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]


def compute_J(a):
    """Compute J(a) = 2*n*max(conv(a,a))/(sum(a))^2."""
    a = np.asarray(a, dtype=np.float64)
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))


def proj_simplex(v):
    """Project v onto the probability simplex."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cv = np.cumsum(u)
    rho_arr = np.arange(1, n + 1, dtype=np.float64)
    cond = (1.0 + u * rho_arr) > cv
    if not cond.any():
        theta = 0.0
    else:
        rho = int(np.argmax(~cond))
        if not (~cond).any():
            rho = n - 1
        theta = (cv[rho] - 1.0) / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    s = w.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return w / s


def build_A_matrix(a, active_indices, n):
    """Build sparse constraint matrix for LP.
    A[k, j] = a[k-j] if 0 <= k-j < n, else 0.
    """
    rows = []
    cols = []
    vals = []
    for idx, k in enumerate(active_indices):
        j_lo = max(0, k - (n - 1))
        j_hi = min(n - 1, k)
        for j in range(j_lo, j_hi + 1):
            rows.append(idx)
            cols.append(j)
            vals.append(a[k - j])
    return csr_matrix((vals, (rows, cols)), shape=(len(active_indices), n))


def get_active_set(b, M, n_active, eps_ratio=0.01):
    """Get active set: indices where b is close to M."""
    threshold = M * (1.0 - eps_ratio)
    idx = np.where(b >= threshold)[0]
    if len(idx) > n_active:
        # Take top n_active
        idx = idx[np.argsort(b[idx])[::-1][:n_active]]
    return idx.tolist()


def lp_best_response(a, M, active_indices, n):
    """Solve LP: max sum(g) s.t. conv(a,g)[k] <= M for k in active, g >= 0.
    Returns normalized g or None."""
    A = build_A_matrix(a, active_indices, n)
    if A.nnz == 0:
        return None
    
    c = -np.ones(n)
    b_ub = np.full(len(active_indices), M)
    bounds = [(0.0, None)] * n
    
    try:
        r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                    options={'time_limit': 15, 'presolve': True,
                             'dual_feasibility_tolerance': 1e-10,
                             'primal_feasibility_tolerance': 1e-10})
        if r.success:
            g = np.maximum(r.x, 0.0)
            g_sum = g.sum()
            if g_sum > 1e-10:
                g = g / g_sum
                # Verify the solution
                conv_ags = np.convolve(a, g, mode='full')
                if max(conv_ags[k] for k in active_indices) <= M * (1 + 1e-6):
                    return g
                else:
                    # Slightly infeasible, try to fix
                    return g
    except Exception:
        pass
    return None


def lp_guided_descent(a_init, deadline, n_active_start=20, n_active_max=100):
    """Main LP-guided descent algorithm."""
    a = np.maximum(a_init.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-10:
        a = np.ones_like(a) / len(a)
    else:
        a = a / s
    n = len(a)
    
    best_a = a.copy()
    best_M = fast_conv(a).max()
    no_improve = 0
    n_active = n_active_start
    
    for it in range(10000):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        M = b.max()
        
        # Get active set
        active = get_active_set(b, M, n_active)
        
        # Solve LP
        g = lp_best_response(a, M, active, n)
        if g is None:
            # Try with all near-max constraints
            n_active = min(n_active * 2, 2 * n - 1)
            active = get_active_set(b, M, n_active, eps_ratio=0.05)
            g = lp_best_response(a, M, active, n)
            if g is None:
                no_improve += 2
                if no_improve > 20:
                    break
                continue
        
        # Line search
        improved = False
        for t in [0.3, 0.5, 0.2, 0.7, 0.1, 0.8, 0.4, 0.15, 0.05]:
            a_trial = (1.0 - t) * a + t * g
            a_trial = np.maximum(a_trial, 0.0)
            s_t = a_trial.sum()
            if s_t < 0.01:
                continue
            a_trial = a_trial / s_t
            M_trial = fast_conv(a_trial).max()
            if M_trial < best_M * (1.0 - 1e-12):
                a = a_trial.copy()
                best_M = M_trial
                best_a = a.copy()
                improved = True
                break
        
        if improved:
            no_improve = 0
            # Can try smaller active set
            if n_active > n_active_start:
                n_active = max(n_active_start, int(n_active * 0.8))
        else:
            no_improve += 1
            n_active = min(n_active * 2, 2 * n - 1)
            if no_improve > 30:
                break
    
    return best_a


def build_Q_matrix(a, active_indices, n, lambda_vals=None):
    """Build the Q matrix for the QP: Q_{j,l} = sum_k lambda_k * delta(j+l=k).
    If lambda_vals is None, use uniform weights.
    """
    if lambda_vals is None:
        lambda_vals = np.ones(len(active_indices)) / len(active_indices)
    
    Q = np.zeros((n, n), dtype=np.float64)
    for idx, k in enumerate(active_indices):
        if k < 0 or k >= 2 * n - 1:
            continue
        w = lambda_vals[idx]
        j_lo = max(0, k - (n - 1))
        j_hi = min(n - 1, k)
        for j in range(j_lo, j_hi + 1):
            l = k - j
            if 0 <= l < n:
                Q[j, l] += w
    
    return Q


def qp_polish(a_init, deadline, n_active=50):
    """QP polish: minimize sum_k lambda_k * conv(a,a)[k] on the simplex."""
    a = np.maximum(a_init.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-10:
        a = np.ones_like(a) / len(a)
    else:
        a = a / s
    n = len(a)
    
    best_a = a.copy()
    best_M = fast_conv(a).max()
    
    for it in range(50):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        M = b.max()
        active = get_active_set(b, M, n_active, eps_ratio=0.02)
        
        # Build Q
        Q = build_Q_matrix(a, active, n)
        
        # Solve QP: min a^T Q a s.t. a >= 0, sum(a) = 1
        def qp_obj(x):
            return x @ Q @ x
        
        def qp_grad(x):
            return 2.0 * (Q @ x)
        
        constraints = [{'type': 'eq', 'fun': lambda x: x.sum() - 1.0,
                        'jac': lambda x: np.ones(len(x))}]
        bounds = [(0.0, None)] * n
        
        try:
            result = minimize(qp_obj, a, jac=qp_grad, method='SLSQP',
                             bounds=bounds, constraints=constraints,
                             options={'maxiter': 100, 'ftol': 1e-12})
            if result.success:
                a_trial = np.maximum(result.x, 0.0)
                s_t = a_trial.sum()
                if s_t > 0.01:
                    a_trial = a_trial / s_t
                    M_trial = fast_conv(a_trial).max()
                    if M_trial < best_M * (1.0 - 1e-10):
                        best_M = M_trial
                        best_a = a_trial.copy()
                        a = a_trial.copy()
                    else:
                        # Try with larger active set
                        continue
                else:
                    continue
            else:
                continue
        except Exception:
            continue
        
        # Check convergence
        if M < best_M * (1.0 - 1e-12):
            continue
        else:
            break
    
    return best_a


def resample_seq(src, dest_n):
    """Resample 1D sequence to new length."""
    src = np.asarray(src, dtype=np.float64)
    if src.size == dest_n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, dest_n)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)


def mirror_descent_step(a, b, n, step):
    """One step of mirror descent using the max constraint subgradient."""
    M = b.max()
    k_star = int(np.argmax(b))
    
    # Subgradient at k_star: grad[i] = 2*a[k_star-i] (if valid)
    grad = np.zeros(n)
    for i in range(n):
        j = k_star - i
        if 0 <= j < n:
            grad[i] = 2.0 * a[j]
    
    grad_tan = grad - grad.mean()
    
    # Multiplicative update
    log_w = -step * grad_tan
    log_w -= log_w.max()
    a_new = a * np.exp(log_w)
    a_new = np.maximum(a_new, 1e-15)
    a_new = a_new / a_new.sum()
    return a_new


def run_mirror_descent(a_init, max_iters, deadline, step_init=0.3):
    """Run mirror descent."""
    a = np.maximum(a_init.astype(np.float64), 1e-10)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_M = fast_conv(a).max()
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        M = b.max()
        
        step = step_init / (1.0 + 0.01 * it)
        a = mirror_descent_step(a, b, n, step)
        
        if M < best_M:
            best_M = M
            best_a = a.copy()
    
    M_final = fast_conv(a).max()
    if M_final < best_M:
        best_M = M_final
        best_a = a.copy()
    
    return best_a

def qp_projected_gradient(a_init, deadline, n_active=50, max_iters=5000):
    """Solve min a^T Q a s.t. a >= 0, sum(a) = 1 using projected gradient."""
    a = np.maximum(a_init.astype(np.float64), 0.0)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_M = fast_conv(a).max()
    
    t = 1.0
    y = a.copy()
    a_prev = a.copy()
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(y)
        M = b.max()
        active = get_active_set(b, M, n_active, eps_ratio=0.02)
        
        # Build Q (but only the diagonal-ish part for speed)
        # Actually, we need Q @ y, which is: (Qy)_j = sum_k lambda_k * y_{k-j}
        # This is convolution-like!
        lambda_vals = np.ones(len(active)) / len(active)
        Q_y = np.zeros(n)
        for idx, k in enumerate(active):
            w = lambda_vals[idx]
            j_lo = max(0, k - (n - 1))
            j_hi = min(n - 1, k)
            for j in range(j_lo, j_hi + 1):
                Q_y[j] += w * y[k - j]
        
        # FISTA step
        step = 1.0 / (2.0 * np.max(np.abs(Q_y)))  # crude Lipschitz estimate
        a_new = y - step * (Q_y - Q_y.mean()) / max(1.0, n / 100.0)
        a_new = proj_simplex(a_new)
        
        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t * t))
        alpha = (t - 1.0) / t_new if t > 1.0 else 0.0
        y_new = a_new + alpha * (a_new - a_prev)
        y_new = proj_simplex(y_new)
        
        a_prev = a
        a = a_new
        y = y_new
        t = t_new
        
        if (it + 1) % 10 == 0:
            M_cur = fast_conv(a).max()
            if M_cur < best_M:
                best_M = M_cur
                best_a = a.copy()
    
    return best_a

    """Solve dual LP: min M * sum(lambda) s.t. A^T lambda >= 1, lambda >= 0.
    Returns lambda or None."""
    A = build_A_matrix(a, active_indices, n)
    # Dual: min M * 1^T lambda s.t. A^T lambda >= 1, lambda >= 0
    # In standard form: min c^T x s.t. A_ub x <= b_ub, x >= 0
    # A^T lambda >= 1  =>  -A^T lambda <= -1
    A_dual_ub = -A.T  # n × |S|
    b_dual_ub = -np.ones(n)
    c_dual = M * np.ones(len(active_indices))
    bounds_dual = [(0.0, None)] * len(active_indices)

        r = linprog(c_dual, A_ub=A_dual_ub, b_ub=b_dual_ub, bounds=bounds_dual,
                    method='highs', options={'time_limit': 10, 'presolve': True})
        if r.success:
            return r.x
    except Exception:
        pass
    return None

    """Mirror descent step using the LP dual subgradient."""
    lambda_dual = solve_dual_lp(a, M, active_indices, n)
    if lambda_dual is None:
        return None
    
    # Compute the "optimal subgradient": grad_j = sum_k lambda_k * a_{k-j}
    A = build_A_matrix(a, active_indices, n)
    grad = A.T @ lambda_dual  # This is (A^T lambda)_j
    
    # Project to tangent space
    grad_tan = grad - grad.mean()
    
    # Multiplicative update
    log_w = -step * grad_tan
    log_w -= log_w.max()
    a_new = a * np.exp(log_w)
    a_new = np.maximum(a_new, 1e-15)
    a_new = a_new / a_new.sum()
    return a_new

```python
"""
Minimizes J(a) = 2*n*max(conv(a,a))/(sum(a))^2 using LP-dual-guided mirror descent
with primal LP interpolation and projected gradient QP polish.

Algorithm:
1. At each iteration, solve both primal and dual LPs for the active constraint set.
2. Use the dual multipliers to compute the optimal subgradient of the max function.
3. Take a mirror descent step using this subgradient.
4. Also compute the primal LP solution and use it for interpolation if it gives improvement.
5. Final polish with projected gradient on the QP defined by the dual multipliers.
"""

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time


def fast_conv(a):
    """FFT-based linear self-convolution."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]


def compute_J(a):
    """Compute J(a) = 2*n*max(conv(a,a))/(sum(a))^2."""
    a = np.asarray(a, dtype=np.float64)
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))


def proj_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cv = np.cumsum(u)
    rho_arr = np.arange(1, n + 1, dtype=np.float64)
    cond = (1.0 + u * rho_arr) > cv
    if not cond.any():
        theta = 0.0
    else:
        neg_cond = ~cond
        rho = int(np.argmax(neg_cond))
        theta = (cv[rho] - 1.0) / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    s = w.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return w / s


def build_A_sparse(a, active_indices, n):
    """Build sparse matrix A where A[k,j] = a[k-j] if valid."""
    rows = []
    cols = []
    vals = []
    for idx, k in enumerate(active_indices):
        j_lo = max(0, k - (n - 1))
        j_hi = min(n - 1, k)
        for j in range(j_lo, j_hi + 1):
            rows.append(idx)
            cols.append(j)
            vals.append(a[k - j])
    return csr_matrix((vals, (rows, cols)), shape=(len(active_indices), n))
