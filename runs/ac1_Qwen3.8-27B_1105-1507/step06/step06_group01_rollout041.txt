For the case k* is the only peak with the bilinear term:

- For k = k*: the constraint is C_{k*} + x*y <= M (or C_{k*} + x^2 <= M if j = k*/2)

{x, y >= 0 : x*S_k + y*T_k <= M - C_k for all k != k*, x*y <= M - C_{k*}}

We want to find (x, y) in this region that also keeps x + y as close to the original a_j + a_{k*-j} as possible (to maintain the normalization).

Actually, for coordinate descent, we're minimizing the objective (max of convolution) by adjusting x and y. The objective is:

This is a 2D non-convex optimization (due to the x*y term). But it's tractable!

1. For a given x, the optimal y is: y* = min( max_k (M_k - C_k - x*S_k) / T_k, (M - C_{k*})/x ) where M = f(x, y*)

2. Alternatively, use a 2D golden section or grid search.

  This is the max of linear functions in x, so it's a 1D convex problem. The minimum is where the "upper envelope" has a kink or where the derivative changes sign.

For the 1D problem: min_x max_k (A_k + B_k * x) where A_k = C_k + y0*T_k and B_k = S_k + (y0 if k=k* else 0).

The minimum of the upper envelope of lines is at a point where two lines intersect (or at a boundary x=0). We can find this by:
1. For each pair of lines (k1, k2), find the intersection x* = (A_k2 - A_k1) / (B_k1 - B_k2)
2. Check if x* is in the valid range and if both lines are on the upper envelope at x*
3. The minimum is the smallest f(x*) over all valid intersections, and at x = 0.

This is O(K^2) for K constraints, which is O(n) for our problem (since K ≈ n). For n = 768, that's about 295,000 pairs, which is fast.

def solve_1d_max_of_lines(A, B, x_lo=0.0, x_hi=None):
    """Minimize max_k (A[k] + B[k]*x) for x in [x_lo, x_hi]."""
    K = len(A)
    if K == 0:
        return x_lo, 0.0
    
    if x_hi is None:
        x_hi = max(10.0, 2.0 * max(A) / max(abs(B).max(), 1e-10))
    
    best_x = x_lo
    best_val = max(A + B * x_lo)
    
    # Check x_hi
    val_hi = max(A + B * x_hi)
    if val_hi < best_val:
        best_val = val_hi
        best_x = x_hi
    
    # Check intersections
    for i in range(K):
        for j in range(i + 1, K):
            if abs(B[i] - B[j]) < 1e-15:
                continue
            x_star = (A[j] - A[i]) / (B[i] - B[j])
            if x_lo <= x_star <= x_hi:
                # Check if both lines are on the upper envelope at x_star
                val_i = A[i] + B[i] * x_star
                val_j = A[j] + B[j] * x_star
                # Check upper envelope
                all_vals = A + B * x_star
                if abs(val_i - all_vals.max()) < 1e-10 and abs(val_j - all_vals.max()) < 1e-10:
                    if val_i < best_val:
                        best_val = val_i
                        best_x = x_star
    
    return best_x, best_val
```

Actually, there's a simpler approach: just use golden section search on the 1D convex function. The function f(x) = max_k(A_k + B_k * x) is convex, so golden section will converge in O(log((x_hi - x_lo)/eps)) iterations, each taking O(K) time. Total: O(K * log(range/eps)) which is much better.

```python
def solve_1d_convex(A, B, x_lo=0.0, x_hi=10.0, tol=1e-10):
    """Minimize f(x) = max_k(A[k] + B[k]*x) for x in [x_lo, x_hi] using golden section."""
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    
    def f(x):
        return np.max(A + B * x)
    
    a = x_lo
    b = x_hi
    c = b - gr * (b - a)
    d = a + gr * (b - a)
    fc = f(c)
    fd = f(d)
    
    for _ in range(100):
        if b - a < tol:
            break
        if fc < fd:
            b = d
            d = c
            fd = fc
            c = b - gr * (b - a)
            fc = f(c)
        else:
            a = c
            c = d
            fc = fd
            d = a + gr * (b - a)
            fd = f(d)
    
    x_opt = (a + b) / 2.0
    return x_opt, f(x_opt)
```

This is O(K * 100) = O(100K) per 1D solve, which for K = 768 is about 76,800 operations. Very fast!

S_k = (a*a)[k] with a[i]=1, a[j]=0 minus (a*a)[k] with a[i]=0, a[j]=0
    = contribution of a[i] to (a*a)[k] when a[j]=0

This is simpler to compute:
S_k = (number of times a[i] appears) * ... 

OK let me just compute it directly in code:

```python

This is getting quite complex. The issue is that when m = i and km = i (i.e., k = 2i), we get x^2, which is a quadratic in x. Similarly for y.

For the 2D subproblem, we have:
(a*a)[k] = C[k] + x*S[k] + y*T[k] + x^2*Qxx[k] + y^2*Qyy[k] + x*y*Qxy[k]

where:
- Qxx[k] = 1 if k = 2i, else 0
- Qyy[k] = 1 if k = 2j, else 0
- Qxy[k] = 2 if k = i+j = k* and i != j, else (1 if k = 2i = 2j = k*, i.e., i = j = k*/2)

This is a 2D problem with quadratic terms. The objective is:
f(x,y) = max_k (C[k] + x*S[k] + y*T[k] + x^2*Qxx[k] + y^2*Qyy[k] + x*y*Qxy[k])

For most k, Qxx[k] = Qyy[k] = Qxy[k] = 0, so the constraint is linear.
For k = 2i: there's an x^2 term.
For k = 2j: there's a y^2 term.
For k = k*: there's a 2*x*y term (or x^2 if i = j).

This is still tractable! The 1D subproblems (fixing y and optimizing x, or vice versa) become:
min_x max_k (C[k] + y*T[k] + x*S[k] + x^2*Qxx[k] + x*y*Qxy[k] + y^2*Qyy[k])
= max_k ((C[k] + y*T[k] + y^2*Qyy[k]) + x*(S[k] + y*Qxy[k]) + x^2*Qxx[k])

For most k, Qxx[k] = 0, so it's linear in x. For k = 2i, it's x^2 + x*S[2i] + (C[2i] + y*T[2i] + y^2*Qyy[2i]), which is a convex quadratic in x.

So the 1D problem is: min_x max(linear functions, one convex quadratic). This is still convex and can be solved with golden section.

OK, I think this approach is viable but complex to implement correctly. Let me simplify:

Instead of the full pair optimization, let me use a simpler approach:
1. For each pair (i, j) with i + j = k*, do a 2D golden section search on f(x, y).
2. Each evaluation of f(x, y) requires computing the max of the convolution, which is O(n) (since only O(n) convolution values change).

Actually, computing the full convolution after changing two elements is O(n) (the changed elements affect O(n) convolution positions). So each f evaluation is O(n), and golden section in 2D is about 400 evaluations, giving O(400n) per pair. For n = 768 and n/2 = 384 pairs, that's about 118 million operations per sweep. That's feasible.

But wait, we can be smarter. After changing a[i] and a[j], only the convolution positions k in [i, i+n-1] ∪ [j, j+n-1] change. The maximum over all positions is:
max( max over changed positions, max over unchanged positions )

We can precompute the max over unchanged positions and only update the changed ones.

```python
"""
Minimizes J(a) = 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Spectral flattening initialization (FFT-based iterative projection)
2. FISTA on adaptive log-sum-exp smooth approximation
3. Mirror descent with subgradient
4. Pair-based 2D coordinate descent exploiting convolution symmetry
5. LP cascade best-response with growing active sets and warm starts
6. Multi-length, multi-start search with diverse initializations
Key new ideas: spectral shaping init, pair-descent exploiting (i, k*-i) structure,
LP cascade with warm starts, and more aggressive length exploration.

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time


def fast_conv(a):
    """FFT-based linear self-convolution."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]


def compute_J(a):
    """Compute J(a) = 2*n*max(conv(a,a))/(sum(a))^2."""
    a = np.asarray(a, dtype=np.float64)
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))


def proj_simplex(v):
    """Project v onto the probability simplex."""
    n = len(v)
    if n == 0:
        return v
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cv = np.cumsum(u)
    rho_arr = np.arange(1, n + 1, dtype=np.float64)
    cond = u > (cv - 1.0) / rho_arr
    if not cond.any():
        theta = 0.0
    else:
        rho = int(np.argmax(~cond))
        theta = (cv[rho - 1] - 1.0) / rho if rho > 0 else 0.0
        if rho == 0:
            theta = 0.0
    w = np.maximum(v - theta, 0.0)
    s = w.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return w / s


def smooth_max_grad(a, tau):
    """Compute smooth max (log-sum-exp) of conv(a,a) and gradient."""
    n = len(a)
    b = fast_conv(a)
    b_max = b.max()
    exp_b = np.exp(tau * (b - b_max))
    p = exp_b / exp_b.sum()
    smooth_val = b_max + np.log(exp_b.sum()) / tau
    grad = np.zeros(n)
    for i in range(n):
        grad[i] = 2.0 * np.dot(p[i:i + n], a)
    return smooth_val, grad


def run_fista(a_init, tau_start, tau_end, max_iters, deadline, lr=0.3):
    """FISTA on smooth max approximation with adaptive tau."""
    a = np.maximum(a_init.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-10:
        a = np.ones_like(a) / len(a)
    else:
        a = a / s
    n = len(a)
    best_a = a.copy()
    best_M = fast_conv(a).max()
    t = 1.0
    y = a.copy()
    a_prev = a.copy()
    it = 0
    while it < max_iters and time.monotonic() < deadline:
        frac = min(1.0, it / max(1, max_iters))
        tau = tau_start * (tau_end / tau_start) ** frac
        _, grad_y = smooth_max_grad(y, tau)
        grad_tan = grad_y - grad_y.mean()
        step = lr / (1.0 + 0.05 * tau * it / 100.0)
        a_new = y - step * grad_tan
        a_new = proj_simplex(a_new)
        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t * t))
        alpha = (t - 1.0) / t_new if t > 1.0 else 0.0
        y_new = a_new + alpha * (a_new - a_prev)
        y_new = proj_simplex(y_new)
        a_prev = a
        a = a_new
        y = y_new
        t = t_new
        it += 1
        if it % 10 == 0 or it == max_iters - 1:
            M_cur = fast_conv(a).max()
            if M_cur < best_M:
                best_M = M_cur
                best_a = a.copy()
            M_y = fast_conv(y).max()
            if M_y < best_M:
                best_M = M_y
                best_a = y.copy()
    M_a = fast_conv(a).max()
    if M_a < best_M:
        best_M = M_a
        best_a = a.copy()
    return best_a


def run_mirror_descent(a_init, max_iters, deadline, step_init=0.3):
    """Mirror descent with KL geometry."""
    a = np.maximum(a_init.astype(np.float64), 1e-10)
    a = a / a.sum()
    n = len(a)
    best_a = a.copy()
    best_M = fast_conv(a).max()
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        b = fast_conv(a)
        k_star = int(np.argmax(b))
        grad = np.zeros(n)
        for i in range(n):
            j = k_star - i
            if 0 <= j < n:
                grad[i] = 2.0 * a[j]
        grad_tan = grad - grad.mean()
        step = step_init / (1.0 + 0.02 * it)
        log_w = -step * grad_tan
        log_w -= log_w.max()
        a_new = a * np.exp(log_w)
        a_new = np.maximum(a_new, 1e-15)
        a_new = a_new / a_new.sum()
        a = a_new
        M = b.max()
        if M < best_M:
            best_M = M
            best_a = a.copy()
    M_final = fast_conv(a).max()
    if M_final < best_M:
        best_M = M_final
        best_a = a.copy()
    return best_a


def build_active_lp(n, a, active_indices):
    """Build sparse LP matrix for active constraints."""
    rows = []
    cols = []
    vals = []
    for idx, k in enumerate(active_indices):
        for j in range(n):
            m = k - j
            if 0 <= m < n:
                rows.append(idx)
                cols.append(j)
                vals.append(a[m])
    A = csr_matrix((vals, (rows, cols)), shape=(len(active_indices), n))
    return A


def lp_best_response(a, M, n_active, x0=None):
    """Solve LP best response with top n_active convolution coefficients."""
    n = len(a)
    b = fast_conv(a)
    top_indices = np.argsort(b)[::-1][:min(n_active, len(b))]
    active = top_indices.tolist()
    A = build_active_lp(n, a, active)
    if A.nnz == 0:
        return None
    c = -np.ones(n)
    b_ub = np.full(len(active), M)
    bounds = [(0.0, None)] * n
    try:
        r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                    options={'time_limit': 10, 'presolve': True})
        if r.success and r.x is not None:
            g = np.maximum(r.x, 0.0)
            g_sum = g.sum()
            if g_sum > 1e-10:
                return g / g_sum
    except Exception:
        pass
    return None


def run_lp_cascade(a_init, max_iters, deadline, n_active_start=5, n_active_max=100):
    """LP cascade: start small, grow active set when stuck."""
    a = np.maximum(a_init.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-10:
        a = np.ones_like(a) / len(a)
    else:
        a = a / s
    n = len(a)
    best_a = a.copy()
    best_M = fast_conv(a).max()
    no_improve = 0
    cur_active = n_active_start
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        g = lp_best_response(a, best_M, cur_active)
        if g is None:
            cur_active = min(cur_active * 2, n_active_max)
            no_improve += 1
            if no_improve > 8:
                break
            continue
        improved = False
        for t in [0.5, 0.4, 0.3, 0.2, 0.1, 0.05, 0.01]:
            a_trial = (1.0 - t) * a + t * g
            a_trial = np.maximum(a_trial, 0.0)
            s_t = a_trial.sum()
            if s_t < 0.01:
                continue
            a_trial = a_trial / s_t
            M_trial = fast_conv(a_trial).max()
            if M_trial < best_M - 1e-14:
                a = a_trial.copy()
                best_M = M_trial
                best_a = a.copy()
                improved = True
                break
        if improved:
            no_improve = 0
            cur_active = max(5, int(cur_active * 0.7))
        else:
            no_improve += 1
            cur_active = min(int(cur_active * 1.8), n_active_max)
            if no_improve > 20:
                break
    return best_a


def coordinate_descent_1d(a, i, b, n):
    """Find optimal value for a[i] given all others via golden section."""
    x_cur = a[i]
    k_lo = i
    k_hi = min(2 * n - 2, i + n - 1)
    c_vals = []
    slopes = []
    has_quad = False
    quad_pos = -1
    for k in range(k_lo, k_hi + 1):
        if k == 2 * i:
            c = b[k] - x_cur * x_cur
            c_vals.append(c)
            slopes.append(0.0)
            has_quad = True
            quad_pos = len(c_vals) - 1
        else:
            j = k - i
            if 0 <= j < n:
                c = b[k] - 2.0 * x_cur * a[j]
                c_vals.append(c)
                slopes.append(2.0 * a[j])
            else:
                c_vals.append(b[k])
                slopes.append(0.0)
    if k_lo > 0 or k_hi < 2 * n - 2:
        mask = np.ones(2 * n - 1, dtype=bool)
        mask[k_lo:k_hi + 1] = False
        base_max = b[mask].max() if mask.any() else 0.0
    else:
        base_max = 0.0
    c_arr = np.array(c_vals)
    s_arr = np.array(slopes)

    def obj_at(x_test):
        vals = c_arr + s_arr * x_test
        m = base_max
        if vals.size > 0:
            vm = vals.max()
            if vm > m:
                m = vm
        if has_quad:
            qv = c_arr[quad_pos] + x_test * x_test
            if qv > m:
                m = qv
        return m

    lo = 0.0
    hi = max(2.0 * x_cur, np.sqrt(max(b.max(), 0.0)) + 0.5, 0.3)
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    a_pt = hi - gr * (hi - lo)
    b_pt = lo + gr * (hi - lo)
    fa = obj_at(a_pt)
    fb = obj_at(b_pt)
    for _ in range(50):
        if fa < fb:
            hi = b_pt
            b_pt = a_pt
            fb = fa
            a_pt = hi - gr * (hi - lo)
            fa = obj_at(a_pt)
        else:
            lo = a_pt
            a_pt = b_pt
            fa = fb
            b_pt = lo + gr * (hi - lo)
            fb = obj_at(b_pt)
    x_opt = (lo + hi) / 2.0
    if obj_at(0.0) <= obj_at(x_opt):
        x_opt = 0.0
    return max(0.0, x_opt)


def run_coordinate_descent(a_init, max_sweeps, deadline, seed=0):
    """Run coordinate descent sweeps."""
    rng_cd = np.random.default_rng(seed)
    a = np.maximum(a_init.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-10:
        a = np.ones_like(a) / len(a)
    else:
        a = a / s
    n = len(a)
    best_a = a.copy()
    best_M = fast_conv(a).max()
    no_improve = 0
    order = np.arange(n)
    for sweep in range(max_sweeps):
        if time.monotonic() > deadline:
            break
        rng_cd.shuffle(order)
        b = fast_conv(a)
        sweep_improved = False
        for i in order:
            x_opt = coordinate_descent_1d(a, i, b, n)
            if abs(x_opt - a[i]) > 1e-10:
                old = a[i]
                a[i] = x_opt
                k_lo = i
                k_hi = min(2 * n - 2, i + n - 1)
                for k in range(k_lo, k_hi + 1):
                    if k == 2 * i:
                        b[k] += (x_opt * x_opt - old * old)
                    else:
                        j = k - i
                        if 0 <= j < n:
                            b[k] += 2.0 * a[j] * (x_opt - old)
                sweep_improved = True
        s = a.sum()
        if s < 1e-10:
            break
        a = a / s
        M = fast_conv(a).max()
        if M < best_M * (1 - 1e-12):
            best_M = M
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        if not sweep_improved:
            no_improve += 3
        if no_improve > 15:
            break
    return best_a


def pair_coord_descent(a_init, max_sweeps, deadline, seed=0):
    """Pair-based coordinate descent exploiting (i, k*-i) symmetry for central peak."""
    rng_p = np.random.default_rng(seed)
    a = np.maximum(a_init.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-10:
        a = np.ones_like(a) / len(a)
    else:
        a = a / s
    n = len(a)
    k_star = n - 1
    best_a = a.copy()
    best_M = fast_conv(a).max()
    no_improve = 0
    for sweep in range(max_sweeps):
        if time.monotonic() > deadline:
            break
        b = fast_conv(a)
        sweep_improved = False
        # Iterate over pairs (i, k_star - i)
        pair_order = list(range(0, min(n, k_star + 1)))
        rng_p.shuffle(pair_order)
        for i in pair_order:
            j = k_star - i
            if j < 0 or j >= n or j == i:
                continue
            x0 = a[i]
            y0 = a[j]
            if x0 + y0 < 1e-12:
                continue
            # Try asymmetric perturbations
            sigma = 0.1 * (x0 + y0)
            best_local = b.max()
            best_x, best_y = x0, y0
            for d in [-1.5, -1.0, -0.5, -0.3, -0.1, 0.0, 0.1, 0.3, 0.5, 1.0, 1.5]:
                x_new = max(0.0, x0 + d * sigma)
                y_new = max(0.0, y0 - d * sigma)
                # Quick evaluation: update affected b values
                old_b_affected = {}
                k_lo_x = i
                k_hi_x = min(2 * n - 2, i + n - 1)
                k_lo_y = j
                k_hi_y = min(2 * n - 2, j + n - 1)
                k_lo = min(k_lo_x, k_lo_y)
                k_hi = max(k_hi_x, k_hi_y)
                for k in range(k_lo, k_hi + 1):
                    old_b_affected[k] = b[k]
                # Apply change
                a[i] = x_new
                a[j] = y_new
                # Recompute affected b
                b_new_local = b.copy()
                for k in range(k_lo, k_hi + 1):
                    new_val = 0.0
                    for m in range(n):
                        km = k - m
                        if 0 <= km < n:
                            new_val += a[m] * a[km]
                    b_new_local[k] = new_val
                M_local = max(b_new_local.max(), 0.0)
                if M_local < best_local - 1e-14:
                    best_local = M_local
                    best_x, best_y = x_new, y_new
                    b = b_new_local
            a[i] = best_x
            a[j] = best_y
            if best_x != x0 or best_y != y0:
                sweep_improved = True
                # Recompute full b for consistency
                b = fast_conv(a)
        s = a.sum()
        if s > 1e-10:
            a = a / s
        M = fast_conv(a).max()
        b = fast_conv(a)
        if M < best_M * (1 - 1e-12):
            best_M = M
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        if not sweep_improved:
            no_improve += 3
        if no_improve > 10:
            break
    return best_a


def spectral_flattening_init(n, n_iters=50, gamma=0.3, seed=42):
    """Initialize via iterative spectral flattening (FFT-based)."""
    rng = np.random.default_rng(seed)
    a = np.ones(n) / n
    for it in range(n_iters):
        # Zero-pad and compute FFT
        L = 2 * n
        a_pad = np.zeros(L)
        a_pad[:n] = a
        A = np.fft.rfft(a_pad)
        # Power spectrum
        P = np.abs(A) ** 2
        # DC component is (sum(a))^2
        dc = P[0]
        # Flatten: P_new = P^gamma (scale to preserve DC)
        P_pos = np.maximum(P, 1e-30)
        P_flat = P_pos ** gamma
        # Scale to preserve total energy (sum of P = sum of (a*a) = (sum a)^2)
        P_flat = P_flat * (dc / P_flat[0]) if P_flat[0] > 0 else P_flat
        # Target: make the AC part flatter
        # New amplitude spectrum
        A_new_mag = np.sqrt(P_flat)
        # Preserve phase
        phase = np.angle(A)
        A_new = A_new_mag * np.exp(1j * phase)
        # Inverse FFT
        a_new = np.fft.irfft(A_new, L)
        # Project: take first n elements, make non-negative
        a_candidate = a_new[:n]
        a_candidate = np.maximum(a_candidate, 0.0)
        s = a_candidate.sum()
        if s < 1e-10:
            break
        a_candidate = a_candidate / s
        # Blend with previous
        a = (1 - gamma) * a + gamma * a_candidate
        a = np.maximum(a, 1e-10)
        a = a / a.sum()
    return a


def generate_inits(n, rng, parent=None):
    """Generate diverse initial sequences."""
    inits = []
    t = np.linspace(0, 1, n, endpoint=False)
    if parent is not None and parent.size > 0:
        p = resample_seq(parent, n)
        if p.sum() > 0:
            inits.append(p / p.sum())
        for noise_std in [0.02, 0.05, 0.1, 0.2]:
            p_n = np.maximum(p + rng.normal(0, noise_std, n), 1e-4)
            inits.append(p_n / p_n.sum())
    inits.append(np.ones(n) / n)
    # Spectral flattening init (NEW!)
    for gamma in [0.3, 0.5, 0.7]:
        sf = spectral_flattening_init(n, n_iters=30, gamma=gamma, seed=int(rng.integers(10000)))
        inits.append(sf)
    # Windowed alternating (NEW!)
    for alpha in [0.2, 0.4, 0.6, 0.8]:
        window = 0.5 + 0.5 * np.cos(2 * np.pi * t)
        window = np.maximum(window, 0.05)
        alt = window * (1.0 + alpha * (-1.0) ** np.arange(n))
        alt = np.maximum(alt, 1e-4)
        inits.append(alt / alt.sum())
    # Cosine windows
    for freq in [1, 2, 3]:
        cos_w = 0.5 + 0.5 * np.cos(2 * np.pi * freq * t)
        cos_w = np.maximum(cos_w, 0.01)
        inits.append(cos_w / cos_w.sum())
    # Gaussian
    gauss = np.exp(-3.0 * (t - 0.5) ** 2) + 0.1
    inits.append(gauss / gauss.sum())
    # Smooth random
    ksize = max(3, n // 25)
    kernel = np.ones(ksize) / ksize
    smooth = np.convolve(rng.uniform(0, 1, n), kernel, mode='same')
    smooth = np.maximum(smooth, 0.01)
    inits.append(smooth / smooth.sum())
    # Spectral init: iterative peak reduction
    a_spec = np.ones(n) / n
    for _ in range(30):
        bs = fast_conv(a_spec)
        k_star_s = int(np.argmax(bs))
        corr = np.zeros(n)
        for i_s in range(n):
            j_s = k_star_s - i_s
            if 0 <= j_s < n:
                corr[i_s] = a_spec[j_s]
        a_spec = a_spec - 0.15 * (corr - corr.mean())
        a_spec = np.maximum(a_spec, 0.005)
        a_spec = a_spec / a_spec.sum()
    inits.append(a_spec.copy())
    return inits


def resample_seq(src, dest_n):
    """Resample 1D sequence to new length via linear interpolation."""
    src = np.asarray(src, dtype=np.float64)
    if src.size == dest_n:
        return src.copy()
    if src.size == 0:
        return np.ones(dest_n) / dest_n
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, dest_n)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)


class ScoreTracker:
    def __init__(self):
        self.best = None
        self.best_score = float('inf')
        self.t_start = time.monotonic()

    def update(self, a):
        a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
        if a.size == 0 or a.sum() < 0.01:
            return
        score = float(evaluate_sequence(a.tolist()))
        if np.isfinite(score) and score < self.best_score:
            self.best = a.copy()
            self.best_score = score
            elapsed = time.monotonic() - self.t_start
            print(f"  ** NEW BEST: J={score:.8f} n={a.size} t={elapsed:.0f}s", flush=True)

    def report(self, label=""):
        if self.best is not None:
            print(f"  {label}: J={self.best_score:.8f} n={self.best.size}", flush=True)


def run_phase_combined(a0, n, deadline_phase, seed):
    """Combined optimization pipeline for a single initialization."""
    best = a0.copy()
    best_M = fast_conv(a0).max()
    t_start = time.monotonic()
    phase_duration = max(1, deadline_phase - t_start)
    # Stage 1: FISTA (30%)
    t1 = t_start + 0.3 * phase_duration
    if time.monotonic() < t1:
        for tau in [50, 200, 500]:
            if time.monotonic() > t1:
                break
            sub_dl = min(t1, time.monotonic() + max(5, (t1 - time.monotonic()) / 2))
            a_f = run_fista(best, tau, tau * 2, 2000, sub_dl, lr=0.25)
            M_f = fast_conv(a_f).max()
            if M_f < best_M:
                best_M = M_f
                best = a_f.copy()
    # Stage 2: Mirror descent (15%)
    t2 = t_start + 0.45 * phase_duration
    if time.monotonic() < t2:
        a_md = run_mirror_descent(best, 3000, t2, step_init=0.15)
        M_md = fast_conv(a_md).max()
        if M_md < best_M:
            best_M = M_md
            best = a_md.copy()
    # Stage 3: LP cascade (30%)
    t3 = t_start + 0.75 * phase_duration
    if time.monotonic() < t3:
        a_lp = run_lp_cascade(best, 100, t3, n_active_start=5, n_active_max=80)
        M_lp = fast_conv(a_lp).max()
        if M_lp < best_M:
            best_M = M_lp
            best = a_lp.copy()
    # Stage 4: Pair coordinate descent (15%)
    t4 = t_start + 0.9 * phase_duration
    if time.monotonic() < t4:
        a_pc = pair_coord_descent(best, 10, t4, seed=seed + 500)
        M_pc = fast_conv(a_pc).max()
        if M_pc < best_M:
            best_M = M_pc
            best = a_pc.copy()
    # Stage 5: Standard coordinate descent (10%)
    if time.monotonic() < deadline_phase:
        max_sw = max(3, int((deadline_phase - time.monotonic()) / max(0.1, n / 80.0)))
        a_cd = run_coordinate_descent(best, max_sw, deadline_phase, seed=seed + 1)
        M_cd = fast_conv(a_cd).max()
        if M_cd < best_M:
            best_M = M_cd
            best = a_cd.copy()
    return best
