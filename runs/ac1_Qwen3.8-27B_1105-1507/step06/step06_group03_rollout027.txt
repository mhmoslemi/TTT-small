**Approach: Semidefinite Programming (SDP) relaxation**

The problem min max_k (a*a)[k] s.t. a >= 0, sum(a) = 1 can be written as:
min t s.t. sum_j a[j]*a[k-j] <= t for all k, a >= 0, sum(a) = 1.

This is a QP with non-convex quadratic constraints. An SDP relaxation would be:

min t s.t. sum_j X[j,k-j] <= t for all k, X PSD, rank(X) = 1, X >= 0, sum_{i,j} X[i,j] = 1.

Dropping the rank constraint gives an SDP relaxation. This might give a good lower bound and a feasible point (by projecting the SDP solution to rank 1).
