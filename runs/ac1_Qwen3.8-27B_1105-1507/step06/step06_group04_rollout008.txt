def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    return 2.0 * n * max_b / (s * s)


def normalize_simplex(a):
    """Project onto simplex: a >= 0, sum(a) = 1."""
    a = np.maximum(a, 0)
    s = np.sum(a)
    if s > 1e-15:
        a = a / s
    else:
        a = np.ones(len(a)) / len(a)
    return a

30. **Fourier-based design**:
In the frequency domain (for circular convolution), (a*a) corresponds to |A(ω)|^2.
We want |A(ω)|^2 to be as flat as possible, subject to a >= 0.

If |A(ω)|^2 = constant, then A(ω) = c * e^{iφ(ω)}, and a is the inverse Fourier transform of c*e^{iφ(ω)}. For a to be real and nonnegative, we need specific constraints on φ.

For a real sequence, A(-ω) = conj(A(ω)), so |A(ω)|^2 is symmetric.
For a to be nonnegative, the inverse FFT of |A(ω)|^2 * e^{iφ(ω)} must be >= 0.

If we choose |A(ω)|^2 = constant, then a = IDFT{c * e^{iφ(ω)}}. For this to be real, we need φ(-ω) = -φ(ω) (mod 2π). For it to be nonnegative, we need the right choice of φ.

The simplest case: φ(ω) = 0 for all ω, giving a uniform sequence (which we know gives obj=2).

A better case: choose φ(ω) = 2πfω/N (linear phase), which corresponds to a shifted version of the uniform (still obj=2).

To get a non-uniform a, we need a non-trivial φ. But the constraint a >= 0 is very restrictive.

Actually, for the LINEAR convolution (not circular), the Fourier approach is less clean. But for large n, the difference between linear and circular convolution is small (edge effects), so we can use it as a guide.

import numpy as np
from scipy.fft import rfft, irfft
import time


def compute_conv(a):
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    conv = irfft(fa * fa, size)
    return conv[:2 * n - 1]


def compute_obj(a):
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    return 2.0 * n * max_b / (s * s)

    a = np.maximum(a, 0)
    s = np.sum(a)
    if s > 1e-15:
        a = a / s
    else:
        a = np.ones(len(a)) / len(a)
    return a

            cands = [ai, 0.0]

                        if x_opt > 0 and x_opt < S + 1:
                            cands.append(x_opt)
                else:

                if has_two_i:

                    best_x = x

                    conv[two_i] += delta * delta

                S = S_rest + best_x

                    best_obj = curr_obj
                    best_a = a.copy()
                    sweep_improved = True
            else:
                # ai stays the same, but conv should be unchanged
                pass

The slice `a[k_start - i:k_end - i]` includes `a[i]` if `k_start - i <= i < k_end - i`, i.e., `k_start <= 2i < k_end`, which is exactly the condition `has_two_i`.
