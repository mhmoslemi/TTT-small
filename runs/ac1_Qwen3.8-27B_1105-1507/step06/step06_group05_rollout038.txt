```python
    w_ext = np.zeros(2*n-1)
    for i in range(top_k):
        w_ext[peak_indices[i]] += weights[i]
    
    # FFT of a (reuse for both conv and gradient)
    Af = fft(a, size)
    
    # Convolution (update)
    conv_new = np.real(ifft(Af * Af, size))[:2*n-1]
    
    # Gradient
    Wf = fft(w_ext, size)
    g = np.real(ifft(Wf * np.conj(Af), size))[:n]
    
    # Best vertex
    j_star = int(np.argmin(g))
    
    # FW step
    gamma = 2.0 / (t + 2)
    a_new = (1 - gamma) * a
    a_new[j_star] += gamma
    a_new = np.maximum(a_new, 0)
    s = a_new.sum()
    if s < 1e-15:
        a_new = np.ones(n) / n
    else:
        a_new /= s
    
    return a_new, conv_new
```

This uses 2 forward FFTs and 2 inverse FFTs per iteration, plus some O(n) work. Should be fast.

Now, one concern: the FW method with γ_t = 2/(t+2) has O(1/t) convergence for the function value of the *iterate* (not the average). The last iterate converges as O(1/t). So after 1M iterations, we expect to be within O(1/1M) = O(0.000001) of optimal (times the Lipschitz constant and problem geometry).

But in practice, FW can be much slower, especially when the solution is not a vertex (which is almost always the case here). The "faceting" phenomenon can cause slow progress.

To mitigate this, I can use:
1. **Strong Wolfe step size**: Instead of the fixed γ_t = 2/(t+2), use a line search to find the best step size.
2. **Averaging**: Keep track of the average iterate and periodically check its objective.
3. **Restarts**: Periodically restart from the current best point.

Let me also think about a different approach: **Mirror Descent** with the negative entropy regularization.

Mirror descent with entropy:
- Proximal mapping: prox(v) = exp(v) / sum(exp(v)) (softmax)
- Update: a_{t+1} = softmax(log(a_t) - η_t * g_t)

This is equivalent to multiplicative weight updates! And it has a nice interpretation: we're multiplicatively decreasing the coordinates with high gradient and increasing those with low gradient.

The convergence rate of mirror descent with negative entropy on the simplex is O(sqrt(log(n)/t)) for the duality gap, which is better than the Euclidean projection's O(1/sqrt(t)) when n is large.

Actually wait, the rate depends on the regularization. For mirror descent with ψ(a) = sum a_i * log(a_i) (negative entropy), the rate is O(sqrt(H / (t * R^2))) where H is the entropy of the uniform distribution = log(n), and R is the gradient norm bound.

For our problem:
- H = log(n) ≈ log(700) ≈ 6.6
- R = ||g||_2 <= 1 (since sum a = 1 and a >= 0, the max of a is at most 1, and g is a shifted version of a times 2)

So the rate is O(sqrt(6.6 / t)) which is about O(2.6/sqrt(t)).

After 1M iterations: O(2.6/1000) = O(0.0026). That's not great.

For FW with the last iterate: O(L * D / t) where D is the diameter. D = sqrt(2) for the simplex. L = 1 (gradient bound).
After 1M iterations: O(1.4/1M) = O(0.0000014). Much better in theory!

But in practice, FW can be much slower. Let me just implement both and see.

Actually, I think the best approach is:

1. **Phase 1**: Use the parent sequence as starting point
2. **Phase 2**: Run FW for a long time (it's very fast per iteration)
3. **Phase 3**: Use LP polishing (from previous code) on the FW result
4. **Phase 4**: Use pairwise coordinate descent for final micro-optimizations
5. **Phase 5**: Multi-n exploration

Let me also consider: should I use the averaged iterate or the last iterate from FW?

For FW with γ_t = 2/(t+2):
- The last iterate converges as O(1/t)
- The averaged iterate also converges as O(1/t) but with a worse constant

In practice, the last iterate often works well after an initial transient. I'll track both and use whichever is better.

One more thought: **freedom SWS (Separable and Weighted Step-size)** or **freedom FW** allows the step direction to be either toward the best vertex OR in a "free" direction (which can include decreasing some coordinates). This helps with the faceting problem.

The freedom FW algorithm:
1. Compute g, find v = argmin <g, v> over simplex (as before)
2. Compute the "free direction" d = v - a (direction to the best vertex)
3. Check if moving in direction -d (i.e., from v back toward a) gives better objective
4. If so, use a negative step (move away from v)

Actually, the standard freedom FW is:
1. s = argmin_{v in S} <g, v> (the "linear minimization oracle" solution)
2. x_{t+1} = x_t + γ_t * (s - x_t) if γ_t > 0
   x_{t+1} = x_t + γ_t * (x_t - s) if we want to go the other way (this is "freedom")

The step size can be negative (going from s back toward x_t or beyond).

For simplicity, I'll use the standard FW with γ_t = 2/(t+2) and a periodic restart mechanism.

```python
"""
Optimization for minimizing 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Frank-Wolfe (conditional gradient) with multi-peak soft-max gradient
2. LP alternating method for polishing
3. Pairwise coordinate descent for micro-optimization
4. Multi-n exploration
"""

import numpy as np
from scipy.optimize import linprog
from scipy.fft import rfft, irfft, fft, ifft
import time


def compute_conv(a):
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    conv = irfft(fa * fa, size)
    return conv[:2 * n - 1]


def compute_obj(a):
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    return 2.0 * n * max_b / (s * s)


def normalize(a):
    a = np.maximum(a, 0.0)
    s = float(np.sum(a))
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s


def frank_wolfe_optimize(a, time_budget=600.0, top_k=20, temp_scale=0.05, restart_every=50000):
    """Frank-Wolfe algorithm with multi-peak gradient and periodic restarts."""
    n = len(a)
    a = normalize(a.copy().astype(np.float64))
    
    size = 1
    while size < 3 * n - 1:
        size <<= 1
    
    conv = compute_conv(a)
    best_a = a.copy()
    best_obj = 2.0 * n * float(np.max(conv))
    
    start = time.monotonic()
    t = 0
    # Track average iterate
    avg_a = a.copy()
    avg_count = 0
    
    max_total_iters = 5000000
    
    while time.monotonic() - start < time_budget and t < max_total_iters:
        t += 1
        gamma = 2.0 / (t + 2.0)
        
        # Get top-k peaks
        if t == 1 or t % 10 == 0:
            # Recompute conv periodically to avoid drift
            conv = compute_conv(a)
        
        peak_indices = np.argpartition(conv, -top_k)[-top_k:]
        peak_indices = peak_indices[np.argsort(conv[peak_indices])[::-1]]
        cmax = conv[peak_indices[0]]
        
        if cmax < 1e-15:
            break
        
        # Soft-max weights
        temp = max(cmax * temp_scale, 1e-12)
        shifted = (conv[peak_indices] - cmax) / temp
        weights = np.exp(np.clip(shifted, -500, 0))
        w_sum = float(np.sum(weights))
        if w_sum < 1e-300:
            weights = np.zeros(top_k)
            weights[0] = 1.0
        else:
            weights /= w_sum
        
        # Build w_ext and compute gradient via FFT
        w_ext = np.zeros(2 * n - 1)
        for i in range(top_k):
            w_ext[peak_indices[i]] += weights[i]
        
        Af = fft(a, size)
        Wf = fft(w_ext, size)
        g = np.real(ifft(Wf * np.conj(Af), size))[:n]
        
        # Best vertex for FW
        j_star = int(np.argmin(g))
        
        # FW update
        a = (1.0 - gamma) * a
        a[j_star] += gamma
        a = np.maximum(a, 0.0)
        s = float(np.sum(a))
        if s < 1e-15:
            a = np.ones(n) / n
        else:
            a /= s
        
        # Track average
        avg_a += a
        avg_count += 1
        
        # Check objective periodically
        if t % 200 == 0:
            obj = 2.0 * n * float(np.max(conv)) if t % 10 != 0 else 2.0 * n * float(np.max(compute_conv(a)))
            if t % 1000 == 0:
                obj = 2.0 * n * float(np.max(compute_conv(a)))
            if obj < best_obj:
                best_obj = obj
                best_a = a.copy()
            
            # Also check average iterate
            if t % 1000 == 0:
                avg_a /= avg_count
                avg_obj = 2.0 * n * float(np.max(compute_conv(avg_a)))
                if avg_obj < best_obj:
                    best_obj = avg_obj
                    best_a = avg_a.copy()
                    avg_a = best_a.copy()  # Reset average from best
                    avg_count = 1
        
        # Periodic restart to escape local structures
        if t % restart_every == 0:
            t = 1  # Reset step counter
            avg_a = a.copy()
            avg_count = 1
    
    # Final check
    final_obj = 2.0 * n * float(np.max(compute_conv(a)))
    if final_obj < best_obj:
        best_a = a.copy()
    
    return best_a


def build_toeplitz(a):
    n = len(a)
    m = 2 * n - 1
    A = np.zeros((m, n), dtype=np.float64)
    for j in range(n):
        k_start = j
        k_end = min(j + n, m)
        A[k_start:k_end, j] = a[:k_end - k_start]
    return A


def solve_lp_max_sum(a, M, time_limit=30):
    n = len(a)
    A = build_toeplitz(a)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': time_limit})
        if res.status == 0:
            g = np.maximum(res.x, 0.0)
            s = float(np.sum(g))
            if s > 1e-10:
                return g / s
    except Exception:
        pass
    return None


def lp_polish(a, time_budget=120.0):
    """LP alternating method for polishing."""
    n = len(a)
    a = normalize(a.copy().astype(np.float64))
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    for it in range(100):
        if time.monotonic() - start > time_budget - 5:
            break
        
        conv = compute_conv(a)
        M = float(np.max(conv))
        
        remaining = time_budget - (time.monotonic() - start)
        if remaining < 10:
            break
        
        g = solve_lp_max_sum(a, M, time_limit=max(3, int(remaining * 0.5)))
        if g is None:
            break
        
        # Try several blend factors
        best_t = 0.0
        best_obj_t = best_obj
        for t in [0.1, 0.2, 0.3, 0.5, 0.7, 1.0]:
            a_try = normalize((1.0 - t) * a + t * g)
            obj_try = compute_obj(a_try)
            if obj_try < best_obj_t:
                best_obj_t = obj_try
                best_t = t
        
        a_new = normalize((1.0 - best_t) * a + best_t * g)
        obj_new = compute_obj(a_new)
        
        if obj_new < best_obj - 1e-14:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new
        
    return best_a


def pairwise_cd(a, time_budget=60.0):
    """Pairwise mass transfer coordinate descent."""
    n = len(a)
    a = normalize(a.copy().astype(np.float64))
    best_a = a.copy()
    best_obj = 2.0 * n * float(np.max(compute_conv(a)))
    start = time.monotonic()
    rng = np.random.default_rng(12345)
    
    iterations = 0
    while time.monotonic() - start < time_budget:
        iterations += 1
        conv = compute_conv(a)
        k_star = int(np.argmax(conv))
        
        # Find top contributors
        contrib = []
        for j in range(n):
            k2 = k_star - j
            if 0 <= k2 < n:
                contrib.append((a[j] * a[k2], j, k2))
        contrib.sort(reverse=True)
        
        improved = False
        for peak_val, j1, j2 in contrib[:8]:
            if time.monotonic() - start > time_budget:
                break
            if j1 == j2:
                continue
            
            # Try moving mass from j1 to random position
            for attempt in range(5):
                j_target = int(rng.integers(0, n))
                if j_target == j1 or j_target == j2:
                    continue
                
                for frac in [0.1, 0.25, 0.5]:
                    delta = frac * a[j1]
                    if delta > a[j1] * 0.9:
                        continue
                    a_try = a.copy()
                    a_try[j1] -= delta
                    a_try[j_target] += delta
                    a_try = normalize(a_try)
                    obj_try = 2.0 * n * float(np.max(compute_conv(a_try)))
                    
                    if obj_try < best_obj - 1e-14:
                        best_obj = obj_try
                        best_a = a_try.copy()
                        a = a_try
                        improved = True
                        break
        
        if not improved:
            # Random perturbation
            a = normalize(a * np.exp(rng.normal(0, 0.02, n)))
    
    return best_a


def resample_sequence(a, new_n):
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, float(a[0]))
    x_old = np.linspace(0.0, 1.0, n)
    x_new = np.linspace(0.0, 1.0, new_n)
    return np.interp(x_new, x_old, a)
```

```python
"""
Hybrid optimization for minimizing 2*n*max(conv(a,a))/(sum(a))^2 using:

2. LP alternating method (primary optimizer) with adaptive step-size

import numpy as np
from scipy.optimize import linprog
from scipy.fft import rfft, irfft, fft, ifft
import time


def compute_conv(a):
    """Compute linear convolution a*a using FFT."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    conv = irfft(fa * fa, size)
    return conv[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    return 2.0 * n * max_b / (s * s)


def normalize(a):
    """Normalize a to sum to 1, clipping negatives."""
    a = np.maximum(a, 0.0)
    s = float(np.sum(a))
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s


def build_toeplitz(a):
    """Build Toeplitz matrix for convolution with a."""
    n = len(a)
    m = 2 * n - 1
    A = np.zeros((m, n), dtype=np.float64)
    for j in range(n):
        k_start = j
        k_end = min(j + n, m)
        A[k_start:k_end, j] = a[:k_end - k_start]
    return A


def solve_lp_max_sum(a, M, time_limit=30):
    """Solve LP: max sum(g) s.t. conv(a,g) <= M, g >= 0."""
    n = len(a)
    A = build_toeplitz(a)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': time_limit,
                               'dual_feasibility_tolerance': 1e-10,
                               'primal_feasibility_tolerance': 1e-10})
        if res.status == 0:
            g = np.maximum(res.x, 0.0)
            s = float(np.sum(g))
            if s > 1e-10:
                return g / s
    except Exception:
        pass
    return None


def multiplicative_weight_descent(a, time_budget=60.0, top_k=5):
    """Fast multiplicative weight descent using multi-peak subgradients."""
    n = len(a)
    a = normalize(a.copy().astype(np.float64))
    best_a = a.copy()
    best_obj = 2.0 * n * float(np.max(compute_conv(a)))
    start = time.monotonic()
    t = 0

    while time.monotonic() - start < time_budget:
        t += 1
        conv = compute_conv(a)
        cmax = float(np.max(conv))

        # Get top-k peaks for multi-subgradient
        peak_indices = np.argpartition(conv, -top_k)[-top_k:]
        # Sort by value
        peak_indices = peak_indices[np.argsort(conv[peak_indices])[::-1]]

        # Soft-max weights over peaks
        temp = cmax * 0.05
        if temp < 1e-15:
            temp = 1e-15
        weights = np.exp((conv[peak_indices] - cmax) / temp)
        w_sum = float(np.sum(weights))
        if w_sum < 1e-300:
            weights = np.zeros(top_k)
            weights[0] = 1.0
        else:
            weights /= w_sum

        # Compute mixed subgradient
        g = np.zeros(n)
        for w, k in zip(weights, peak_indices):
            for j in range(n):
                k2 = k - j
                if 0 <= k2 < n:
                    g[j] += w * a[k2]

        # Adaptive step size
        g_max = float(np.max(g))
        g_min = float(np.min(g))
        g_range = g_max - g_min
        if g_range < 1e-15:
            g_range = 1.0
        eta = 2.0 / (np.sqrt(t + 1.0) * g_range)

        # Multiplicative update with numerical stability
        log_update = -eta * g
        log_update -= np.max(log_update)
        log_update = np.clip(log_update, -50, 50)
        update = np.exp(log_update)
        a_new = a * update
        s = float(np.sum(a_new))
        if s < 1e-15:
            break
        a_new = a_new / s
        a_new = np.maximum(a_new, 0)

        # Check improvement
        if t % 3 == 0:
            obj_new = 2.0 * n * float(np.max(compute_conv(a_new)))
            if obj_new < best_obj:
                best_obj = obj_new
                best_a = a_new.copy()

        a = a_new

    return best_a


def lp_alternate_adaptive(a, max_iters=80, time_budget=120.0):
    """LP alternating with adaptive step-size via line search on a grid."""
    n = len(a)
    a = normalize(a.copy().astype(np.float64))
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    no_improve = 0

    for it in range(max_iters):
        if time.monotonic() - start > time_budget - 5:
            break

        remaining = time_budget - (time.monotonic() - start)
        if remaining < 8:
            break

        conv = compute_conv(a)
        M = float(np.max(conv))

        lp_time = max(3, int(remaining * 0.5))
        g = solve_lp_max_sum(a, M, time_limit=lp_time)
        if g is None:
            break

        # Adaptive step-size: try a grid of step sizes
        best_t = 0.0
        best_obj_t = best_obj
        # Start with larger steps early, smaller later
        if no_improve < 5:
            t_values = [0.1, 0.2, 0.3, 0.5, 0.7, 1.0]
        elif no_improve < 15:
            t_values = [0.05, 0.1, 0.2, 0.3, 0.5]
        else:
            t_values = [0.02, 0.05, 0.1, 0.2]

        for t_val in t_values:
            a_try = normalize((1.0 - t_val) * a + t_val * g)
            obj_try = compute_obj(a_try)
            if obj_try < best_obj_t:
                best_obj_t = obj_try
                best_t = t_val

        if best_t > 0:
            a_new = normalize((1.0 - best_t) * a + best_t * g)
            obj_new = compute_obj(a_new)
            if obj_new < best_obj - 1e-14:
                best_obj = obj_new
                best_a = a_new.copy()
                a = a_new
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1
            # Perturb to escape
            if no_improve > 5:
                rng = np.random.default_rng((it * 31 + 7) % (2**31))
                a = normalize(best_a * np.exp(rng.normal(0, 0.03 + 0.01 * no_improve, n)))
                no_improve = 0

    return best_a


def simulated_annealing_lp(a, time_budget=200.0, rng_seed=42):
    """Simulated annealing: perturb, then polish with LP, accept if better."""
    n = len(a)
    a = normalize(a.copy().astype(np.float64))
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    rng = np.random.default_rng(rng_seed)

    # Annealing schedule
    sigma_start = 0.15
    sigma_end = 0.005
    total_time = time_budget

    step = 0
    while time.monotonic() - start < time_budget - 10:
        step += 1
        progress = (time.monotonic() - start) / total_time
        sigma = sigma_start * (sigma_end / sigma_start) ** progress

        # Generate perturbation
        pert_type = step % 4
        if pert_type == 0:
            # Gaussian multiplier
            a_try = best_a * np.exp(rng.normal(0, sigma, n))
        elif pert_type == 1:
            # Sinusoidal modulation
            freq = rng.uniform(1.0, 8.0)
            phase = rng.uniform(0, 2 * np.pi)
            mod = 1.0 + sigma * 2 * np.sin(2 * np.pi * freq * np.arange(n) / n + phase)
            a_try = best_a * mod
        elif pert_type == 2:
            # Blend with random Dirichlet
            a_rand = rng.dirichlet(np.ones(n) * 0.3)
            mix = rng.uniform(0.2, 0.6)
            a_try = (1 - mix) * normalize(best_a) + mix * a_rand
        else:
            # Block reversal
            a_try = best_a.copy()
            block_len = int(rng.integers(n // 4, n // 2 + 1))
            start_idx = int(rng.integers(0, n - block_len + 1))
            a_try[start_idx:start_idx + block_len] = a_try[start_idx:start_idx + block_len][::-1]

        a_try = normalize(a_try)

        # Polish with LP (short time budget)
        elapsed = time.monotonic() - start
        remaining = time_budget - elapsed
        if remaining < 15:
            break
        lp_alloc = min(remaining * 0.35, 30.0)
        a_try = lp_alternate_adaptive(a_try, max_iters=10, time_budget=lp_alloc)

        obj_try = compute_obj(a_try)

        # Accept if better, or with probability exp(-delta/T) (Metropolis)
        if obj_try < best_obj:
            best_obj = obj_try
            best_a = a_try.copy()
        else:
            # Metropolis acceptance (annealing)
            delta = obj_try - best_obj
            T = max(sigma * 0.01, 0.0001)
            if rng.random() < np.exp(-delta / T):
                a_try = a_try  # Accept worse solution temporarily
                # Don't update best, but continue from here
                # Actually for SA we should track current vs best separately
                # For simplicity, only accept better solutions but with the perturbation providing diversity

    return best_a


def pairwise_cd(a, time_budget=60.0, rng_seed=999):
    """Pairwise mass-transfer coordinate descent."""
    n = len(a)
    a = normalize(a.copy().astype(np.float64))
    best_a = a.copy()
    best_obj = 2.0 * n * float(np.max(compute_conv(a)))
    start = time.monotonic()
    rng = np.random.default_rng(rng_seed)

    while time.monotonic() - start < time_budget:
        conv = compute_conv(a)
        k_star = int(np.argmax(conv))

        # Identify top contributors to the peak
        contrib = []
        for j in range(n):
            k2 = k_star - j
            if 0 <= k2 < n:
                contrib.append((a[j] * a[k2], j, k2))
        contrib.sort(reverse=True)

        if not contrib:
            break

        improved = False
        for peak_val, j1, j2 in contrib[:6]:
            if time.monotonic() - start > time_budget:
                break
            if j1 == j2:
                continue

            for _ in range(4):
                j_target = int(rng.integers(0, n))
                if j_target == j1 or j_target == j2:
                    continue

                for frac in [0.05, 0.15, 0.3]:
                    delta = frac * a[j1]
                    if delta >= a[j1] * 0.9:
                        continue
                    a_try = a.copy()
                    a_try[j1] -= delta
                    a_try[j_target] += delta
                    a_try = normalize(a_try)
                    obj_try = 2.0 * n * float(np.max(compute_conv(a_try)))

                    if obj_try < best_obj - 1e-14:
                        best_obj = obj_try
                        best_a = a_try.copy()
                        a = a_try
                        improved = True
                        break

        if not improved and rng.random() < 0.15:
            a = normalize(a * np.exp(rng.normal(0, 0.02, n)))

    return best_a


def resample_sequence(a, new_n):
    """Resample sequence to new length via linear interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, float(a[0]))
    x_old = np.linspace(0.0, 1.0, n)
    x_new = np.linspace(0.0, 1.0, new_n)
    return np.interp(x_new, x_old, a)

    try:
        parent = np.asarray(height_sequence_1, dtype=np.float64)
        parent = np.clip(parent, 0.0, 1000.0)
        if parent.size > 0 and np.isfinite(parent).all():
            obj = compute_obj(parent)
            print(f"Parent loaded (n={parent.size}): obj={obj:.6f}")
            return parent.copy(), obj
    except Exception:
        pass
    return None, np.inf


def propose_candidate(seed=42, budget_s=1500):
    """
    Main search function with multi-phase hybrid strategy:
    Phase 1: Multiplicative weight descent (fast initialization)
    Phase 2: LP alternating (primary optimizer, longest time allocation)
    Phase 3: Simulated annealing with LP (escape local minima)
    Phase 4: Multi-n exploration
    Phase 5: Final intensive polish
    """
    start_time = time.monotonic()
    deadline = start_time + budget_s - 30.0

    best_seq = None
    best_score = np.inf

    # Load parent
    parent, parent_obj = try_load_parent()
    if parent is not None:
        best_score = parent_obj
        best_seq = parent.copy()

    n_parent = len(best_seq) if best_seq is not None else 700
    print(f"Initial: n={n_parent}, score={best_score:.8f}")

    # =========================================================
    # Phase 1: Fast multiplicative weight descent (60s)
    # =========================================================
    if best_seq is not None:
        print(f"\nPhase 1: Multiplicative weight descent")
        a_mw = normalize(best_seq.copy())
        mw_time = min(60.0, (deadline - start_time) * 0.04)
        a_mw = multiplicative_weight_descent(a_mw, time_budget=mw_time, top_k=5)
        obj_mw = compute_obj(a_mw)
        print(f"  MW result: {obj_mw:.8f}")
        if obj_mw < best_score:
            best_score = obj_mw
            best_seq = a_mw.copy()

    # =========================================================
    # Phase 2: LP alternating (primary, ~500s)
    # =========================================================
    if best_seq is not None:
        print(f"\nPhase 2: LP alternating (primary)")
        a_lp = normalize(best_seq.copy())

        for cycle in range(6):
            if time.monotonic() > deadline - 350:
                break
            remaining = deadline - time.monotonic()
            if remaining < 30:
                break
            alloc = min(remaining * 0.12, 100.0)

            a_lp = lp_alternate_adaptive(a_lp, max_iters=40, time_budget=alloc)
            obj_lp = compute_obj(a_lp)
            if obj_lp < best_score:
                best_score = obj_lp
                best_seq = a_lp.copy()
                print(f"  LP cycle {cycle}: {best_score:.8f} **")
            else:
                print(f"  LP cycle {cycle}: {obj_lp:.8f} (no improvement)")
                # Slight perturbation between cycles
                rng = np.random.default_rng(cycle * 1000 + seed)
                a_lp = normalize(a_lp * np.exp(rng.normal(0, 0.02, len(a_lp))))

    # =========================================================
    # Phase 3: Simulated annealing with LP (~300s)
    # =========================================================
    if best_seq is not None:
        print(f"\nPhase 3: Simulated annealing + LP")
        sa_time = min(300.0, (deadline - time.monotonic()) * 0.25)
        if sa_time > 30:
            a_sa = simulated_annealing_lp(best_seq, time_budget=sa_time, rng_seed=seed)
            obj_sa = compute_obj(a_sa)
            print(f"  SA result: {obj_sa:.8f}")
            if obj_sa < best_score:
                best_score = obj_sa
                best_seq = a_sa.copy()
                print(f"  ** New best! **")

    # =========================================================
    # Phase 4: Multi-n exploration (~150s)
    # =========================================================
    if best_seq is not None:
        print(f"\nPhase 4: Multi-n exploration")
        n_cur = len(best_seq)
        # Try nearby n values
        n_options = []
        for delta in [-150, -100, -75, -50, -25, 25, 50, 75, 100, 150, 200]:
            n_try = n_cur + delta
            if 200 <= n_try <= 1500:
                n_options.append(n_try)
        n_options = sorted(set(n_options))

        for n_try in n_options:
            if time.monotonic() > deadline - 60:
                break
            remaining = deadline - time.monotonic()
            if remaining < 30:
                break

            a_try = normalize(resample_sequence(best_seq, n_try))

            # Quick optimization at this n
            ew = min(remaining * 0.2, 40.0)
            a_try = lp_alternate_adaptive(a_try, max_iters=8, time_budget=ew)

            obj_try = compute_obj(a_try)
            status = " **" if obj_try < best_score else ""
            print(f"  n={n_try}: {obj_try:.8f}{status}")
            if obj_try < best_score:
                best_score = obj_try
                best_seq = a_try.copy()

    # =========================================================
    # Phase 5: Final intensive polish (~200s)
    # =========================================================
    if best_seq is not None:
        print(f"\nPhase 5: Final polish")
        n_final = len(best_seq)
        a_final = normalize(best_seq.copy())

        polish_rounds = 3
        for pr in range(polish_rounds):
            if time.monotonic() > deadline - 10:
                break
            remaining = deadline - time.monotonic()
            if remaining < 15:
                break

            # LP polish
            lp_alloc = min(remaining * 0.35, 60.0)
            if lp_alloc > 5:
                a_p = lp_alternate_adaptive(a_final, max_iters=15, time_budget=lp_alloc)
                obj_p = compute_obj(a_p)
                if obj_p < best_score:
                    best_score = obj_p
                    best_seq = a_p.copy()
                    a_final = a_p
                print(f"  Polish {pr} LP: {obj_p:.8f}")

            # Pairwise CD
            cd_alloc = min(remaining * 0.2, 30.0)
            if cd_alloc > 5:
                a_p = pairwise_cd(a_final, time_budget=cd_alloc, rng_seed=seed + pr)
                obj_p = compute_obj(a_p)
                if obj_p < best_score:
                    best_score = obj_p
                    best_seq = a_p.copy()
                    a_final = a_p
                print(f"  Polish {pr} CD: {obj_p:.8f}")

            # Quick MW
            mw_alloc = min(remaining * 0.1, 20.0)
            if mw_alloc > 5:
                a_p = multiplicative_weight_descent(a_final, time_budget=mw_alloc, top_k=8)
                obj_p = compute_obj(a_p)
                if obj_p < best_score:
                    best_score = obj_p
                    best_seq = a_p.copy()
                    a_final = a_p
                print(f"  Polish {pr} MW: {obj_p:.8f}")

    # =========================================================
    # Final validation and return
    # =========================================================
    if best_seq is None:
        best_seq = np.ones(200)
        best_score = compute_obj(best_seq)

    result = [float(max(0.0, min(1000.0, x))) for x in best_seq]

    # Ensure sum constraint
    s = sum(result)
    if s < 0.01:
        result = [1.0] * 100

    # Validate with the actual evaluation function
    val = evaluate_sequence(result)
    if val < np.inf and val < best_score:
        best_score = val

    elapsed = time.monotonic() - start_time
    print(f"\n{'='*60}")
    print(f"FINAL: n={len(result)}, score={best_score:.8f}, time={elapsed:.1f}s")
    print(f"{'='*60}")

    return result
```
