J(a) = 2n*max(conv(a,a))/(sum(a))^2. 
Uses peak identification, golden section line search, and multi-scale exploration.

import numpy as np
import time
from scipy.optimize import linprog
from scipy.sparse import coo_matrix

def fast_conv(a):
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]

def compute_J(a):
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))

def project_simplex(v):
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1, dtype=np.float64)
    cond = u - cssv / ind > 0
    k = np.where(cond)[0]
    if len(k) == 0:
        return np.ones(n) / n
    lam = cssv[k[-1]] / (k[-1] + 1)
    return np.maximum(v - lam, 0.0)

3. Find peak indices: K* = {k : conv[k] = max(conv)}
4. Compute subgradient: g[i] = (1/|K*|) * sum_{k in K*} 2*a[k-i] (with boundary handling)
5. Project gradient onto simplex tangent space: g = g - mean(g) (or use proper projection)
6. Step: a_new = a - step * g
7. Project to simplex: a_new = project_simplex(a_new)
8. Adaptive step size (barzily-borwein or backtracking)

This is essentially what the previous code's "smooth Adam" does, but without the smoothing. The subgradient method is simpler and might work better.

However, the subgradient of the max function can be noisy when there are multiple peaks. A better approach is to use the smoothed version:

F_tau(a) = (1/tau) * log(sum_k exp(tau * conv[k]))

whose gradient is:
grad F_tau[a_i] = sum_k w_k * 2*a[k-i] (with boundary handling)

where w_k = exp(tau*conv[k]) / sum_j exp(tau*conv[j])

This is exactly what the previous code does. The issue is the choice of tau and the step size.

**My improved approach:**

1. Use the smoothed objective with ADAPTIVE tau (increase tau when close to convergence, decrease when stuck)
2. Use a better step size rule (barzily-borwein type)
3. Combine with coordinate descent for polishing
4. Use multiple restarts with different initializations
5. Try different sequence lengths

Let me also think about a completely different angle:

**Frequency domain approach:**

We want to minimize max_k IFFT(|FFT(a)|^2)[k] subject to a >= 0, sum(a) = 1.

In the frequency domain, |FFT(a)|^2 is the power spectrum. The time-domain signal is the inverse FFT of the power spectrum. We want the time-domain signal to be as flat as possible (in terms of peak).

This is related to the problem of designing a signal with a flat power spectrum (equi-ripple in frequency) or equivalently, a signal whose autocorrelation has minimal peak sidelobes.

One approach: iterate between:
1. In frequency domain: modify |FFT(a)|^2 to reduce the peak of the IFFT
2. In time domain: enforce non-negativity and sum constraint

This is similar to the Gerchberg-Saxton algorithm or the error reduction method used in phase retrieval.

**Specifically:**
- Start with a (sum=1, a>=0)
- Compute A = FFT(a), P = |A|^2
- Compute p = IFFT(P) (this is conv(a,a) up to normalization)
- Identify peaks in p
- In frequency domain: reduce P at frequencies that contribute to the peaks
- In time domain: a_new = IFFT(sqrt(P_new) * exp(i*angle(A))), then project to {a >= 0, sum = 1}

This is a spectral method and might escape local optima that gradient-based methods get stuck in.

**Final algorithm design:**

Phase 1 (30% time): Spectral method (Gerchberg-Saxton style)
Phase 2 (30% time): Smoothed gradient with adaptive tau
Phase 3 (25% time): Coordinate descent with golden section
Phase 4 (15% time): Final polish and multi-length exploration

"""
Multi-method optimizer for J(a) = 2n*max(conv(a,a))/(sum(a))^2.
Combines spectral (Gerchberg-Saxton) iteration, adaptive smoothed gradient,
and coordinate descent with golden section search.
"""

import numpy as np
import time

def fast_conv(a):
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]

def compute_J(a):
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))

def project_simplex(v):
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1, dtype=np.float64)
    cond = u - cssv / ind > 0
    k = np.where(cond)[0]
    if len(k) == 0:
        return np.ones(n) / n
    lam = cssv[k[-1]] / (k[-1] + 1)
    return np.maximum(v - lam, 0.0)

def resample_seq(src, dest_n):
    src = np.asarray(src, dtype=np.float64)
    if src.size == dest_n:
        return src.copy()
    if src.size == 0:
        return np.ones(dest_n) / dest_n
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, dest_n)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)

def spectral_iteration(a, deadline, max_iters=5000, verbose=False):
    """
    Gerchberg-Saxton style iteration for minimizing peak autocorrelation.
    Alternates between:
    1. Frequency domain: flatten the power spectrum to reduce time-domain peaks
    2. Time domain: enforce non-negativity and normalization
    """
    n = len(a)
    a = np.maximum(a.astype(np.float64), 0)
    a = a / a.sum()
    best_a = a.copy()
    best_obj = compute_J(a)
    
    # FFT size for circular convolution (use 2n to avoid wraparound)
    size = 1
    while size < 2 * n:
        size <<= 1
    
    no_improve = 0
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        # Compute current autocorrelation
        conv = fast_conv(a)
        current_obj = 2.0 * n * conv.max()
        
        if current_obj < best_obj - 1e-10:
            best_obj = current_obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        if no_improve > 200:
            break
        
        # Frequency domain step
        A = np.fft.rfft(a, size)
        P = np.abs(A) ** 2  # Power spectrum
        
        # The peak in time domain corresponds to structure in freq domain
        # Strategy: apply a "peak reduction" in time domain via frequency modification
        # For each frequency bin, amplify it inversely proportional to its 
        # contribution to the peak
        
        # Simpler approach: use "time-domain feedback"
        # The error is (conv - target), where target is flat
        target = np.ones(2*n-1) / (2*n-1) * conv.sum()  # flat target
        error = conv - target
        
        # Project error onto the "achievable" set via frequency domain
        # Resize error to FFT size
        err_padded = np.zeros(size)
        err_padded[:2*n-1] = error
        
        # Frequency domain correction
        E = np.fft.rfft(err_padded)
        
        # Modify power spectrum: reduce power where error is positive
        # P_new = P / (1 + alpha * |E|)  ... or similar
        alpha = 0.1
        P_mod = P / (1.0 + alpha * np.abs(E) ** 2 / (np.max(np.abs(E)**2) + 1e-10))
        
        # Reconstruct with modified phase (keep original phase)
        phase = np.angle(A)
        A_new = np.sqrt(P_mod) * np.exp(1j * phase)
        
        # Time domain
        a_new = np.fft.irfft(A_new, size)[:n]
        
        # Enforce constraints
        a_new = np.maximum(a_new, 0)
        if a_new.sum() < 1e-10:
            a_new = best_a.copy()
        else:
            a_new = a_new / a_new.sum()
        
        # Line search
        for frac in [1.0, 0.7, 0.5, 0.3, 0.1]:
            a_try = (1 - frac) * a + frac * a_new
            a_try = np.maximum(a_try, 0)
            if a_try.sum() < 1e-10:
                continue
            a_try = a_try / a_try.sum()
            obj_try = compute_J(a_try)
            if obj_try < best_obj:
                a = a_try
                best_a = a_try.copy()
                best_obj = obj_try
                no_improve = 0
                break
            elif frac == 0.1:
                a = a_try  # accept anyway to make progress
                break
        
        if verbose and it % 100 == 0:
            print(f"    Spec it {it}: obj={best_obj:.8f}", flush=True)
    
    return best_a, best_obj

def adaptive_smooth_gradient(a, deadline, max_iters=10000, verbose=False):
    """
    Smoothed gradient descent with adaptive tau and Barzily-Borwein step size.
    """
    n = len(a)
    a = np.maximum(a.astype(np.float64), 1e-10)
    a = a / a.sum()
    best_a = a.copy()
    best_obj = compute_J(a)
    
    tau = 30.0
    tau_min = 5.0
    tau_max = 500.0
    lr = 0.1
    no_improve = 0
    
    # Adam state
    m = np.zeros(n)
    v = np.zeros(n)
    beta1, beta2, eps = 0.9, 0.999, 1e-8
    t_count = 0
    
    prev_grad = None
    prev_a = None
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        # Compute smoothed gradient
        conv = fast_conv(a)
        conv_shifted = conv - conv.max()
        exp_c = np.exp(tau * conv_shifted)
        w = exp_c / exp_c.sum()
        
        # Gradient: grad[i] = sum_k w[k] * 2*a[k-i] (with bounds)
        # Using FFT: conv(w, a_rev) and conv(w_rev, a_rev)
        a_rev = a[::-1]
        w_rev = w[::-1]
        fft_size = 1
        while fft_size < 3 * n:
            fft_size <<= 1
        A_fft = np.fft.rfft(a_rev, fft_size)
        W_fft = np.fft.rfft(w, fft_size)
        Wrev_fft = np.fft.rfft(w_rev, fft_size)
        
        conv1 = np.fft.irfft(W_fft * A_fft, fft_size)
        conv2 = np.fft.irfft(Wrev_fft * A_fft, fft_size)
        
        grad = np.zeros(n)
        for i in range(n):
            idx1 = n - 1 + i
            idx2 = 3 * n - 3 - i
            if 0 <= idx1 < len(conv1):
                grad[i] += conv1[idx1]
            if 0 <= idx2 < len(conv2):
                grad[i] += conv2[idx2]
        
        grad *= 2.0  # Factor of 2 from the smooth max gradient
        
        # Project to simplex tangent
        grad = grad - np.mean(grad)
        
        # Adam update
        t_count += 1
        m = beta1 * m + (1 - beta1) * grad
        v = beta2 * v + (1 - beta2) * grad ** 2
        m_hat = m / (1 - beta1 ** t_count)
        v_hat = v / (1 - beta2 ** t_count)
        
        # Adaptive learning rate
        if prev_grad is not None and prev_a is not None:
            ys = (a - prev_a).dot(grad - prev_grad)
            ss = (grad - prev_grad).dot(grad - prev_grad)
            if ss > 1e-15:
                lr_bb = ys / ss
                lr = 0.5 * lr + 0.5 * np.clip(lr_bb, 0.001, 1.0)
        
        a_new = a - lr * m_hat / (np.sqrt(v_hat) + eps)
        a_new = project_simplex(a_new)
        
        obj_new = compute_J(a_new)
        if obj_new < best_obj:
            best_obj = obj_new
            best_a = a_new.copy()
            no_improve = 0
            # Decrease tau (sharper approximation)
            tau = max(tau_min, tau * 0.98)
        else:
            no_improve += 1
            # Increase tau (smoother approximation)
            tau = min(tau_max, tau * 1.05)
            # Reduce learning rate
            lr *= 0.95
            
            if no_improve > 200:
                # Restart
                a = best_a + np.random.default_rng(it).normal(0, 0.02, n)
                a = project_simplex(a)
                m = np.zeros(n)
                v = np.zeros(n)
                t_count = 0
                no_improve = 0
                tau = 30.0
                lr = 0.1
        
        a = a_new
        prev_a = a.copy()
        prev_grad = grad.copy()
        
        if verbose and it % 200 == 0:
            print(f"    Grad it {it}: tau={tau:.1f} lr={lr:.4f} obj={best_obj:.8f}", flush=True)
    
    return best_a, best_obj

def coord_descent_gs(a, deadline, max_sweeps=3000, seed=42, verbose=False):
    """
    Coordinate descent with golden section search for exact 1D minimization.
    Uses prefix/suffix max for O(n) evaluation per coordinate.
    """
    n = len(a)
    a = np.maximum(a.copy().astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-10:
        a = np.ones(n) / n
    else:
        a = a / s
    
    conv = fast_conv(a)
    best_obj = 2.0 * n * conv.max()
    best_a = a.copy()
    rng = np.random.default_rng(seed)
    no_improve = 0
    
    for sweep in range(max_sweeps):
        if time.monotonic() > deadline:
            break
        
        # Precompute prefix and suffix max
        prefix_max = np.zeros(2*n)
        prefix_max[0] = -np.inf
        for i in range(2*n - 1 + 1):
            if i < 2*n - 1:
                prefix_max[i+1] = max(prefix_max[i], conv[i])
            else:
                prefix_max[i+1] = prefix_max[i]
        
        suffix_max = np.zeros(2*n + 1)
        suffix_max[2*n-1] = -np.inf
        for i in range(2*n - 2, -1, -1):
            suffix_max[i] = max(suffix_max[i+1], conv[i])
        
        # Order: peak-directed
        peak_thresh = conv.max() * 0.6
        peak_indices = np.where(conv >= peak_thresh)[0]
        candidate_coords = set()
        for k in peak_indices[:50]:  # Limit to top 50 peaks
            j_min = max(0, k - n + 1)
            j_max = min(n - 1, k)
            candidate_coords.update(range(j_min, j_max + 1))
        
        if len(candidate_coords) > n:
            candidate_coords = set(range(n))
        
        order = list(candidate_coords)
        rng.shuffle(order)
        
        improved = False
        
        for i in order:
            if time.monotonic() > deadline:
                break
            
            old = a[i]
            k_lo = i
            k_hi = min(2*n-2, i+n-1)
            kq = 2*i
            valid_kq = (kq <= 2*n-2 and kq >= k_lo and kq <= k_hi)
            
            # Unchanged max (outside [k_lo, k_hi])
            unc_lo = prefix_max[k_lo] if k_lo > 0 else 0.0
            unc_hi = suffix_max[k_hi+1] if k_hi+1 < 2*n-1 else 0.0
            unchanged_max = max(unc_lo, unc_hi)
            
            # a[k-i] for k in [k_lo, k_hi] is a[0], a[1], ..., a[n-1]
            a_region = a  # As shown earlier, this is always the full array
            
            def eval_at(val):
                val = max(0.0, val)
                d = val - old
                if abs(d) < 1e-15:
                    return 2.0 * n * max(unchanged_max, conv[k_lo:k_hi+1].max())
                nc = conv[k_lo:k_hi+1] + 2.0 * d * a_region[:k_hi-k_lo+1]
                if valid_kq:
                    nc[kq - k_lo] += d * d
                return 2.0 * n * max(unchanged_max, nc.max())
            
            # Quick discrete candidates
            candidates = [0.0]
            if old > 1e-10:
                candidates.extend(old * np.array([0.3, 0.5, 0.7, 1.3, 1.7, 2.5]))
            else:
                candidates.extend([1e-4, 1e-3, 1e-2])
            
            best_local = eval_at(old)
            best_val = old
            
            for x in candidates:
                obj_x = eval_at(x)
                if obj_x < best_local:
                    best_local = obj_x
                    best_val = x
            
            # Golden section around best_val
            if best_val > 1e-10:
                lo_g = max(0.0, best_val * 0.5)
                hi_g = best_val * 2.0
                if hi_g - lo_g < 1e-10:
                    lo_g, hi_g = 0.0, 1e-3
                
                gr = (np.sqrt(5) - 1) / 2
                c1 = lo_g + (1 - gr) * (hi_g - lo_g)
                c2 = lo_g + gr * (hi_g - lo_g)
                f1 = eval_at(c1)
                f2 = eval_at(c2)
                
                for _ in range(10):
                    if f1 < f2:
                        hi_g = c2
                        c2 = c1
                        f2 = f1
                        c1 = lo_g + (1 - gr) * (hi_g - lo_g)
                        f1 = eval_at(c1)
                    else:
                        lo_g = c1
                        c1 = c2
                        f1 = f2
                        c2 = lo_g + gr * (hi_g - lo_g)
                        f2 = eval_at(c2)
                
                gs_val = (lo_g + hi_g) / 2
                gs_obj = eval_at(gs_val)
                if gs_obj < best_local:
                    best_local = gs_obj
                    best_val = gs_val
            
            # Apply update
            if abs(best_val - old) > 1e-13:
                d = best_val - old
                a[i] = best_val
                conv[k_lo:k_hi+1] += 2.0 * d * a_region[:k_hi-k_lo+1]
                if valid_kq:
                    conv[kq] += d * d
                improved = True
        
        current_obj = 2.0 * n * conv.max()
        if current_obj < best_obj - 1e-10:
            best_obj = current_obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        if no_improve > 300:
            a = best_a + rng.normal(0, 0.01, n)
            a = np.maximum(a, 0)
            a = a / a.sum()
            conv = fast_conv(a)
            no_improve = 0
        
        if verbose and sweep % 200 == 0:
            print(f"    CD-GS sweep {sweep}: obj={best_obj:.8f}", flush=True)
    
    a = best_a.copy()
    a = np.maximum(a, 0)
    a = a / a.sum()
    return a, compute_J(a)

        inits.append(p.copy())

        inits.append(project_simplex(p + rng.normal(0, 0.08, n)))

    inits.append(np.ones(n) / n)
    
    for freq in [1, 2, 3, 5, 7]:

            inits.append(project_simplex(1.0 + amp * np.sin(2 * np.pi * freq * t)))
    
    for center in [0
