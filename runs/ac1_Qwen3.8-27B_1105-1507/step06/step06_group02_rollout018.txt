def fast_conv(a):

    # Numerical stability: subtract max (which is 0)
    p = np.exp(shifted)  # shifted <= 0, so p <= 1, max is 1
    p_sum = p.sum()
    if p_sum < 1e-300:
        # Fallback: uniform over argmax elements
        p = np.zeros_like(b)
        idx = np.where(b >= b_max - 1e-10)[0]
        p[idx] = 1.0 / len(idx)
    else:
        p /= p_sum
    
    # Compute grad[i] = 2 * sum_m p[i+m] * a[m] using FFT
    size = 1
    while size < 3 * n - 1:
        size <<= 1
    H = np.fft.rfft(p, size)
    a_rev = a[::-1]
    AR = np.fft.rfft(a_rev, size)
    conv = np.fft.irfft(H * AR, size)
    c = conv[n - 1:2 * n - 1]
    grad = 2.0 * c
    
    return grad, p, b, b_max


def smooth_max_value(a, tau):
    """Compute the smooth max value (for line search)."""
    b = fast_conv(a)
    b_max = b.max()
    shifted = tau * (b - b_max)
    log_sum = np.log(np.exp(shifted).sum())
    return b_max + log_sum / tau


def run_smooth_optimize(a, deadline, max_iters=100000, tau_start=5.0, tau_end=5000.0,
                        lr_init=0.5, momentum_init=0.85, momentum_end=0.95,
                        backtrack=0.5, backtrack_max=20, restart_every=500,
                        restart_perturb=0.01):
    """
    Smooth max optimization with Nesterov momentum and backtracking line search.
    """
    a = np.maximum(a.astype(np.float64), 1e-10)
    a = a / a.sum()
    n = len(a)
    best_a = a.copy()
    best_M = fast_conv(a).max()
    
    y = a.copy()
    v = np.zeros(n)  # momentum velocity
    
    # Track active set
    active_set = set(range(2 * n - 1))  # Start with all (will narrow)
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        frac = it / max_iters
        tau = tau_start * (tau_end / tau_start) ** (frac ** 0.5)
        mu = momentum_init + (momentum_end - momentum_init) * frac
        
        # Compute gradient at y (Nesterov lookahead point)
        grad, p, b, b_max = smooth_max_grad(y, tau)
        
        # Update active set: keep lags with significant weight
        active_set = set(np.where(p > 1e-8)[0].tolist())
        
        # Nesterov update: v = mu * v - lr * grad
        # Then y = a + v, take step from a in direction v
        # Standard Nesterov: 
        #   v_{k} = beta_k * v_{k-1}
        #   x_{k+1} = x_k - alpha_k * (grad(f(x_k)) + (beta_k - 1) / (1 + beta_k) * ... )
        # Simpler "heavy ball" style:
        #   v = mu * v - lr * grad
        #   a_new = a + v
        lr = lr_init * (0.1) ** frac  # Decay learning rate
        
        v = mu * v - lr * grad / (n ** 0.5)  # Scale by 1/sqrt(n) for stability
        
        # Backtracking line search
        a_old = a.copy()
        f_old = smooth_max_value(a_old, tau)
        c1 = 1e-4  # Armijo condition
        step = lr
        accepted = False
        for bt in range(backtrack_max):
            a_new = np.maximum(a + v, 0.0)
            s = a_new.sum()
            if s < 1e-10:
                a_new = a_old.copy()
                break
            a_new = a_new / s
            
            f_new = smooth_max_value(a_new, tau)
            if f_new <= f_old + c1 * (v @ grad) :  # Armijo: f_new <= f_old + c1 * grad^T * direction
                accepted = True
                break
            v = v * backtrack  # Shrink step
        
        if not accepted:
            a_new = np.maximum(a + 0.01 * v, 0.0)
            s = a_new.sum()
            if s > 1e-10:
                a_new = a_new / s
            else:
                a_new = a_old.copy()
        
        # Update best
        M_new = fast_conv(a_new).max()
        if M_new < best_M * (1 - 1e-12):
            best_M = M_new
            best_a = a_new.copy()
        
        # Restart with perturbation
        if it > 0 and it % restart_every == 0:
            a_new = np.maximum(a_new + restart_perturb * np.random.randn(n) * a_new.max(), 0.0)
            s = a_new.sum()
            if s > 1e-10:
                a_new = a_new / s
            v = np.zeros(n)  # Reset momentum
        
        a = a_new
        y = a + mu * v  # Nesterov lookahead
    
    return best_a

**New idea: Active-set quadratic programming**

If the active set is A = {k1, k2, ..., kp} (the lags where the max is achieved), then near the optimum:
f(a) ≈ max_{k in A} a^T Q_k a

The gradient is a weighted average of {Q_k a : k in A}, and the "Hessian" (if we use a quadratic model) involves the Q_k matrices.

We can set up a quadratic subproblem:
minimize (1/2) d^T H d + g^T d
subject to a + d >= 0, 1^T d = 0 (maintain normalization)

where g = sum_{k in A} w_k Q_k a (weighted gradient)
and H = sum_{k in A} w_k Q_k (approximate Hessian)

But Q_k is not PSD, so this QP is non-convex. However, for a "trust region" step (small d), it might work.

Alternatively, we can use the **KKT conditions** directly:
At the optimum with active set A:
- a^T Q_k a = M* for all k in A
- a^T Q_k a < M* for all k not in A
- sum_k w_k Q_k a = mu * 1 + nu (for some weights w_k >= 0, sum w_k = 1)
- nu_i >= 0, nu_i * a_i = 0

The first set of conditions gives us |A| equations:
a^T Q_k a = M* for k in A

Combined with sum a = 1, we have |A| + 1 equations in n + 0 unknowns (a and M*). For n=1024 and |A|=2, this is very underdetermined.

The gradient condition gives us n more equations (with the complementarity constraint).

This is a system of n + |A| + 1 nonlinear equations in n + 1 unknowns. We can solve it with Newton's method!

**Newton's method on the KKT system:**
Variables: a (length n), M (scalar), w (length |A|, with sum w = 1)

Equations:
1. a^T Q_k a - M = 0 for k in A (|A| equations)
2. 1^T a - 1 = 0 (1 equation)
3. sum_{k in A} w_k Q_k a - mu * 1 = 0 (n equations, but with mu as additional variable)
4. sum_k w_k - 1 = 0 (1 equation)
5. w_k >= 0 (inequality, handled by projection)
6. a_i >= 0 (inequality, handled by projection)

- 1^T a = 1
- a >= 0

This is a system of quadratic inequalities + linear equality + linear inequalities. For a fixed M, this is a feasibility problem.

We can solve it iteratively: start with some feasible a, and iteratively project onto each constraint:
- Project onto a^T Q_k a <= M (for each k)
- Project onto 1^T a = 1
- Project onto a >= 0

The projection onto a^T Q_k a <= M is non-trivial (it's a non-convex quadratic constraint), but for Q_k being an anti-identity matrix, it has a specific structure.

For Q_k being the exchange matrix (k = n-1): a^T J a = sum a[i]*a[n-1-i] <= M.
This is equivalent to: for each pair (i, n-1-i), a[i]*a[n-1-i] contributes to the sum.
