The key insight: to get obj < 2, we need the convolution to be FLATTER than the triangular shape. This means the off-peak values need to be HIGHER than the triangular profile, while the peak is LOWER.

In other words, we need "negative sidelobes" in the autocorrelation sense - the off-peak values should be close to the peak rather than tapering off.

For a real non-negative sequence, the convolution is always non-negative (since it's a sum of products of non-negative numbers). So we can't have negative values in the convolution. The best we can do is make all convolution values equal (or as close as possible).

The theoretical lower bound is 2n/(2n-1) ≈ 1, achieved when all 2n-1 convolution values are equal to S^2/(2n-1).

For the uniform sequence, the convolution values range from 1 to n (for unit values), with the average being S^2/(2n-1) = n^2/(2n-1) ≈ n/2. The peak is n, which is about 2x the average.

So the "flatness ratio" for uniform is 2. For the optimal, it should be 1. We're at a ratio of about 1.506 * (2n-1)/(2n) ≈ 1.503.
