**FISTA with softmax:**

The problem is: min M(a) = max_k (a*a)[k] subject to a >= 0, sum(a) = 1.

We approximate M(a) ≈ log-sum-exp(τ * (a*a)) / τ (soft-max).

The gradient of the soft-max approximation is:
∇_a soft_max(a, τ) = τ * A^T(softmax(τ * (a*a))) / τ = A^T(p) where p = softmax(τ*(a*a))

Wait, let me be more careful. Let f(a) = (1/τ) * log(sum_k exp(τ * b_k)) where b = a*a.
∂f/∂a_j = (1/τ) * sum_k exp(τ*b_k) * τ*∂b_k/∂a_j / sum_k exp(τ*b_k)
= sum_k p_k * ∂b_k/∂a_j
= (A^T p)_j

where p_k = exp(τ*b_k) / sum_k exp(τ*b_k) (the softmax weights).

So the gradient is exactly A^T(p) as I computed above.

For FISTA:
- y_k = x_k + (t_{k-1}-1)/(t_k+1) * (x_k - x_{k-1}) (Nesterov momentum)
- x_{k+1} = Proj( y_k - (1/L_k) * ∇f(y_k) )
- t_{k+1} = (1 + sqrt(1+4*t_k^2))/2

Where L_k is the Lipschitz constant of the gradient (for the soft-max approximation, L ≈ τ * ||A||^2, where ||A|| is the operator norm of the convolution).

The operator norm of the convolution operator a -> a*a... hmm, this is the bilinear form, not linear. The gradient A^T(p) is linear in p, but p depends on a. So the Lipschitz constant is harder to estimate.

For practical purposes, I'll use backtracking line search instead of a fixed step size.

**Backtracking line search for FISTA:**
At each iteration:
1. Compute gradient g = A^T(p) at the current point y
2. Try step size α: x_new = Proj(y - α*g)
3. Check if f(x_new) <= f(y) + <g, x_new - y> + (1/(2α))||x_new - y||^2
4. If not, α /= 2 and retry

This ensures global convergence for convex functions.

However, for our non-smooth objective (max), the soft-max approximation with large τ is close to the true objective but has a large Lipschitz constant (making small step sizes necessary). A better approach is to use a moderate τ and accept that we're solving a smoothed problem.

**Alternative: proximal gradient with the exact max**

Since M(a) = max_k (a*a)[k] is convex but non-smooth, we can use:
- Subgradient method (slow)
- prox-linear method (quadratic model)
- Proximal gradient with the soft-max as a smooth upper bound

I think the soft-max + FISTA + backtracking approach is the most practical.

- Increase τ gradually: τ_k = τ_0 * (τ_max/τ_0)^{k/K}

2. FISTA with adaptive softmax for the max-convolution
3. Active-set subgradient refinement
4. Multi-length exploration

import numpy as np

from math import sqrt

def fast_conv(a):
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]

def compute_J(a):
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))

def binomial_init(n):
    """Initialize with C(2j,j)/4^j coefficients of (1-z)^{-1/2}."""
    a = np.zeros(n)
    a[0] = 1.0
    for j in range(1, n):
        a[j] = a[j-1] * (2*j - 1) / (2*j)
    a = np.maximum(a, 0)
    a /= a.sum()
    return a

def fast_conv(a):
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]

def compute_J(a):
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))

def binomial_init(n):
    a = np.zeros(n)
    a[0] = 1.0
    for j in range(1, n):
        a[j] = a[j-1] * (2.0*j - 1.0) / (2.0*j)
    a = np.maximum(a, 0)
    a /= a.sum()
    return a

def compute_grad(a, p):
    n = len(a)
    g2 = np.convolve(p, a, mode='full')[:n]
    corr = np.correlate(p, a, mode='full')
    g1 = corr[n-1:2*n-1]
    return g1 + g2

def softmax_weights(b, tau):
