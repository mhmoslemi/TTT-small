And (1/|K|) * sum_{k∈K} a[k-i] = (m ⋆ a)[i]

So the subgradient is: 4n * (m ⋆ a)[i] (with the normalization 1/|K| absorbed in m)
Wait: ∂f/∂a[i] = 2n * sum_{k∈K} (1/|K|) * 2*a[k-i] = 4n * (m ⋆ a)[i]

where m[k] = 1/|K| for k∈K, 0 otherwise.

I can compute this via FFT!

Then I do gradient descent: a_new = a - lr * subgrad, then project to non-negative and normalize.

This is much more principled than the previous approaches. Let me implement this.

For the step size, I can use:
- Barzilai-Borwein: lr_k = ||a_k - a_{k-1}||^2 / ((a_k - a_{k-1})^T (g_k - g_{k-1}))
- Or adaptive: if objective increases, halve the step; if it decreases, maybe increase slightly.
- Or Polyak step: lr = (f(a) - f*) / ||g||^2 (but we don't know f*)

I'll use a combination: start with a reasonable step, use backtracking if objective increases.

Let me also add momentum: v = β*v - lr*grad, a = a + v, then project.

- Can do thousands of iterations in a second

def compute_conv(a):

    size = 1
    while size < 2*n - 1:

    conv = irfft(fa * fa, size)

def compute_obj(a):

    s = float(np.sum(a))
    if s < 0.01:

    conv = compute_conv(a)

def normalize(a):

def spectral_equalization(a, max_iters=200, time_budget=30.0):
    """POCS-style spectral equalization."""
    n = len(a)
    a = normalize(a.copy().astype(np.float64))
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    size = 1
    while size < 2*n:
        size <<= 1
    
    for it in range(max_iters):
        if time.monotonic() - start > time_budget:
            break
        
        A = fft(a, size)
        P = np.abs(A) ** 2
        p_mean = float(np.mean(P[P > 0]))
        if p_mean < 1e-30:
            break
        
        # Compress power spectrum toward uniform
        # Use a soft compression
        alpha = 0.3 + 0.4 * (it / float(max_iters))
        P_new = np.where(P > 0, P_mean + (P - p_mean) * (1 - alpha), 0)
        P_new = np.maximum(P_new, 0)
        
        # Preserve phase
        phase = np.angle(A)
        A_new = np.sqrt(P_new) * np.exp(1j * phase)
        
        a_new = np.real(ifft(A_new, size))[:n]
        a_new = np.maximum(a_new, 0.0)
        s = float(np.sum(a_new))
        if s < 1e-10:
            break
        a_new = a_new / s
        
        obj_new = compute_obj(a_new)
        if obj_new < best_obj:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new
        else:
            a = 0.7 * a + 0.3 * a_new
            a = normalize(a)
    
    return best_a

def lp_alternate(a, max_iters=20, time_budget=60.0):
    """LP-based alternating optimization."""
    n = len(a)
    if n > 500:
        return a  # Too large for LP
    
    a = normalize(a.copy().astype(np.float64))
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    for it in range(max_iters):
        if time.monotonic() - start > time_budget - 3:
            break
        remaining = time_budget - (time.monotonic() - start)
        if remaining < 5:
            break
        
        conv = compute_conv(a)
        M = float(np.max(conv))
        
        # Build Toeplitz matrix
        m_len = 2*n - 1
        A_mat = np.zeros((m_len, n))
        for j in range(n):
            k_start = j
            k_end = min(j + n, m_len)
            A_mat[k_start:k_end, j] = a[:k_end - k_start]
        
        c_vec = -np.ones(n)
        b_ub = np.full(m_len, M)
        bounds = [(0.0, None)] * n
        
        try:
            res = linprog(c_vec, A_ub=A_mat, b_ub=b_ub, bounds=bounds, 
                         method='highs', options={'presolve': True, 'time_limit': max(2, int(remaining*0.5))})
            if res.status == 0:
                g = np.maximum(res.x, 0.0)
                s = float(np.sum(g))
                if s > 1e-10:
                    g = g / s
                    # Try a few blend factors
                    for t in [0.3, 0.5, 0.7, 1.0]:
                        a_try = normalize((1-t)*a + t*g)
                        obj_try = compute_obj(a_try)
                        if obj_try < best_obj:
                            best_obj = obj_try
                            best_a = a_try.copy()
                    a = best_a.copy()
        except Exception:
            pass
    
    return best_a

conv[k] = sum_j a[j]*a[k-j] = (a * a)[k] (full convolution)

This can be written as a^T C_k a where C_k is a matrix that extracts the k-th lag of the autocorrelation.

Actually, (a*a)[k] = sum_j a[j]*a[k-j]. If I think of a as a vector, this is the inner product of a with a shifted version of a. Specifically:
(a*a)[k] = <a, S_k a> where (S_k a)[j] = a[k-j] (the k-th "anti-shift").

S_k is a matrix where (S_k)[j,i] = 1 if j = k-i, i.e., (S_k)[j,i] = δ_{j,k-i}.
This is a reversed shift matrix. S_k^T = S_{-k} (approximately).

The matrix M_k such that (a*a)[k] = a^T M_k a has M_k = (S_k + S_k^T)/2 (to make it symmetric).

M_k is symmetric and its eigenvalues are... for the full convolution (a of length 2n-1), M_k is a circulant-like matrix and its eigenvalues are cos(2πk*ω/(2n-1)) or something like that. In any case, M_k is not necessarily PSD.

So the constraint a^T M_k a ≤ t is NOT necessarily convex. This means the problem is NOT convex in general!

Wait, but I showed earlier that max_k conv[k] is convex because each conv[k] is a quadratic form... but a quadratic form a^T M a is convex only if M is PSD.

Let me check: is conv(a,a)[k] = sum_j a[j]*a[k-j] convex in a?

conv[k] = sum_j a[j]*a[k-j]

The Hessian with respect to a is: ∂²conv[k]/∂a[i]∂a[l] = δ_{i,k-l} + δ_{k-i,l} (from the two terms).
This is the matrix M_k I defined above.

For this to be PSD, we need a^T M_k a ≥ 0 for all a, i.e., conv(a,a)[k] ≥ 0 for all a. But conv(a,a)[k] = sum_j a[j]*a[k-j] can be negative if a has negative entries!

However, in our problem, a ≥ 0, so conv[k] ≥ 0 for all k. But that doesn't make the function convex - convexity is a property of the function over the entire space (or at least over a convex neighborhood).

So the problem is NOT convex in general. The subgradient method might not converge to the global optimum.

For #4, what do good sequences look like? They should have:
- Flat convolution (ideally)
- Non-negative entries
- sum = 1 (normalized)

A sequence with flat convolution has a flat power spectrum (|A(f)| is constant). For a non-negative real sequence, this means the sequence is the IFFT of a constant-magnitude spectrum (with some phase).

The phase is the free parameter. We need to find a phase such that the IFFT is non-negative.

This is a Phase Retrieval problem! Specifically:
- Find a phase θ(f) such that IFFT(e^{iθ(f)} * C) ≥ 0, where C is a constant.
- Equivalent: find a constant-magnitude spectrum whose inverse transform is non-negative.

For a sequence of length n, the DFT has n bins (or n/2+1 for real). We need to find n phases such that the IFFT is non-negative.

One approach: start with random phases, compute IFFT, project to non-negative, recompute FFT, and keep the magnitude constant. This is the "hybrid input-output" (HIO) or "error reduction" (ER) algorithm from phase retrieval!

Let me implement this:

```python
def phase_retrieval_flat_rect(n, max_iters=10000, time_budget=60.0):
    """
    Phase retrieval to find a non-negative sequence with flat power spectrum.
    Alternates between:
    - Frequency domain: enforce flat magnitude
    - Time domain: enforce non-negativity
    """
    size = n  # DFT size = n (circular convolution)
    
    # Wait, we need LINEAR convolution, not circular.
    # For linear convolution of length 2n-1 to be flat, we need the N-point DFT (N >= 2n-1) to have constant magnitude.
    # Let's use N = next_power_of_2(2n-1)
    
    N = 1
    while N < 2*n - 1:
        N <<= 1
    
    # Start with random phase
    rng = np.random.default_rng(42)
    phase = rng.uniform(0, 2*np.pi, N)
    # Enforce conjugate symmetry for real signal
    for k in range(1, N//2):
        phase[N-k] = -phase[k]
    phase[N//2] = 0  # Nyquist
    
    # Constant magnitude
    C = np.sqrt(N)  # arbitrary constant
    
    best_a = None
    best_obj = np.inf
    start = time.monotonic()
    
    # Current estimate
    a = np.zeros(N)
    
    for it in range(max_iters):
        if time.monotonic() - start > time_budget:
            break
        
        # Forward: compute spectrum
        A = fft(a, N)
        
        # Enforce flat magnitude in frequency domain
        A_new = C * np.exp(1j * phase)
        # Update phase from current a (this is the ER algorithm)
        # Actually, in ER: keep magnitude from target, phase from current
        # In HIO: only update where error is
        
        # Error reduction (simplest):
        a_new = np.real(ifft(A_new, N))[:n]
        
        # Project to non-negative
        a = np.maximum(a_new, 0.0)
        
        # Update phase from new a
        A_check = fft(a, N)
        mag_check = np.abs(A_check)
        # Where mag_check > 0, update phase
        nonzero = mag_check > 1e-10
        phase[nonzero] = np.angle(A_check[nonzero])
        
        # Evaluate
        obj = compute_obj(a)
        if obj < best_obj:
            best_obj = obj
            best_a = a.copy()
    
    return best_a, best_obj
```

Hmm, but this is the Error Reduction algorithm, which can get stuck in local minima. The Hybrid Input-Output (HIO) or Hybrid Projection (HyP) algorithms are better.

Actually, let me reconsider. The issue is that for LINEAR convolution to be flat, the condition is different from circular convolution.

For circular convolution (DFT of size N): |A(f)|^2 = constant means the circular autocorrelation is flat (a delta at 0).

For linear convolution: we want the linear autocorrelation to be flat. This is a different constraint.

If we zero-pad a to length N >= 2n-1 and take the N-point DFT, then:
|A(f)|^2 = DFT of the circular autocorrelation of the zero-padded a.
The circular autocorrelation of the zero-padded a is the same as the linear autocorrelation (because of the zero-padding).

So: if we want the linear convolution (autocorrelation) to be flat, we need |A_N(f)|^2 = constant, where A_N is the N-point DFT of the zero-padded a.

This means: the N-point DFT of a (zero-padded to N) should have constant magnitude.

So the phase retrieval formulation is correct! We need:
- a (length n, non-negative)
- Zero-padded to N >= 2n-1
- N-point DFT has constant magnitude
