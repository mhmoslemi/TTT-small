=> max(conv(a,a)) <= J_target * sum(a)^2 / (2n)

Setting sum(a) = 1:
max(conv(a,a)) <= J_target / (2n)

Let T = J_target / (2n). We need: exists a >= 0, sum(a) = 1, such that (a*a)[k] <= T for all k.

This is a feasibility problem with quadratic constraints. It's NP-hard in general, but we can use:
- SOCP relaxation
- Semidefinite programming (SDP) relaxation
- Jazz hands / spectral methods

The SDP relaxation would be:
minimize t
subject to [t  a^T; a  I] >= 0 (for each constraint (a*a)[k] <= t)
           sum(a) = 1
           a >= 0

But this is a set of matrix inequalities, which is very large for n=1024.

A simpler relaxation: the **copositive** or **SOCP** relaxation.

Actually, for the specific structure of the convolution, we can use the fact that:
(a*a)[k] = a^T P_k a where P_k is a 0-1 matrix (symmetric, with 1s on the k-th diagonal).

The constraint a^T P_k a <= t is a quadratic inequality. For P_k with rank r, we can write this as ||Q_k a|| <= sqrt(t) where Q_k Q_k^T = P_k (if P_k has a square root).

For P_k (the shift matrix), P_k is already a permutation-like matrix. Its eigenvalues are on the unit circle. So P_k = U D U^* where D has entries on the unit circle. This doesn't directly give a square root.

Actually, P_k is symmetric and has eigenvalues in {-1, 0, 1} (for the finite case). So P_k = P_k^T and P_k^2 = I (on the support). Wait, no. P_k is a banded matrix with 1s on the k-th off-diagonal. Its square has 1s on the 2k-th off-diagonal (where valid). So P_k^2 != I.

This SOCP approach is getting complicated. Let me just stick with the heuristic optimization.

**Another idea: Use the structure of the optimal solution**

From the KKT conditions of the min-max problem (ignoring non-negativity for a moment), at the optimum:
- The active constraints (where conv(a,a)[k] = max) should have a specific structure
- The gradient of the smooth max should be proportional to the all-ones vector (for the sum constraint)

This means: sum_k p_k * a[k-m] = constant for all m (at the optimum).

This is a linear system! If I can figure out which k's are active, I can solve for a directly.

But this is circular (I need to know the active set to solve for a, and I need a to know the active set). This is exactly what the LP approach does implicitly.

"""
Minimizes J(a) = 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Multi-scale Gerchberg-Saxton for structured initialization
2. FISTA with FFT-accelerated log-sum-exp smooth max gradient
3. LP best-response with Anderson acceleration for precise convergence
4. Coordinate descent local search for final polish
5. Multi-length exploration with adaptive time budget
Key improvements: FFT-based O(n log n) gradient, larger sequences, better time allocation,
numerically stable softmax, and coordinate descent refinement.

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time


def fft_conv_auto(a):
    """Full linear autocorrelation via FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    result = np.fft.irfft(fa * fa, size)
    return result[:2 * n - 1]


def fft_conv_cross(a, b):
    """Full linear cross-correlation via FFT."""
    n = len(a)
    m = len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    result = np.fft.irfft(fa * np.conj(fb), size)
    return result[:n + m - 1]


def compute_J(a):
    """Compute objective value."""
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fft_conv_auto(a)
    return float(2 * len(a) * b.max() / (s * s))


def smooth_max_and_grad(a, tau):
    """
    Compute smooth max approximation and its gradient.
    f(a) = tau * log(sum_k exp(b_k / tau)) where b = conv(a,a)
    grad[m] = 2 * sum_k p_k * a[k-m] (zero-extended)
    """
    n = len(a)
    b = fft_conv_auto(a)
    b_shifted = b / tau - b.max() / tau
    p = np.exp(b_shifted)
    p_sum = p.sum()
    if p_sum < 1e-300:
        p = np.full(len(b), 1.0 / len(b))
    else:
        p = p / p_sum
    # Gradient via cross-correlation: grad[m] = 2 * sum_k p[k] * a[k-m]
    # Use FFT: correlate(p, a) gives sum_k p[k]*a[k-m]
    lp = len(p)
    size = 1
    while size < lp + n - 1:
        size <<= 1
    fp = np.fft.rfft(p, size)
    fa = np.fft.rfft(a, size)
    # Cross-correlation r[m] = sum_k p[k] * a[k-m]
    # This is the "full" cross-correlation
    corr = np.fft.irfft(fp * np.conj(fa), size)
    # corr has length lp + n - 1, where corr[m] = sum_k p[k]*a[k-m]
    # for m = 0, ..., lp+n-2 (with appropriate zero extension)
    # Actually: corr[m] = sum_j p[j] * a[j-m] for valid indices
    # We want grad[m] = 2 * sum_k p[k] * a[k-m] for m = 0..n-1
    # corr[m] should give us exactly this for m = 0..n-1
    grad = 2.0 * corr[:n]
    return grad, p, b, float(b.max())


def fista_optimize(a, deadline, max_iters=5000, tau_start=0.5, tau_end=200.0,
                   lr_base=0.8, momentum_base=0.9):
    """FISTA with adaptive temperature and backtracking."""
    a = np.maximum(a.astype(np.float64), 1e-12)
    a = a / a.sum()
    n = len(a)
    best_a = a.copy()
    best_M = fft_conv_auto(a).max()
    y = a.copy()
    t_k = 1.0
    no_imp_count = 0

    for it in range(1, max_iters + 1):
        if time.monotonic() > deadline:
            break
        frac = min(1.0, it / max_iters)
        tau = tau_start * (tau_end / tau_start) ** (frac ** 0.4)
        lr = lr_base / (1.0 + 0.05 * it)

        grad, p, b, b_max = smooth_max_and_grad(y, tau)

        if b_max < best_M * (1.0 - 1e-11):
            best_M = b_max
            best_a = a.copy()
            no_imp_count = 0
        else:
            no_imp_count += 1
            if no_imp_count > 200 and it > 500:
                break

        # FISTA momentum
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t_k * t_k)) / 2.0
        alpha = (t_k - 1.0) / t_new

        a_candidate = np.maximum(y - lr * grad, 0.0)
        s = a_candidate.sum()
        if s < 1e-10:
            a_candidate = a.copy()
        else:
            a_candidate = a_candidate / s

        y = a_candidate + alpha * (a_candidate - a)
        y = np.maximum(y, 0.0)
        sy = y.sum()
        if sy < 1e-10:
            y = a_candidate.copy()
        else:
            y = y / sy
        a = a_candidate
        t_k = t_new

    return best_a


def gs_symmetric(a, n_iters=200, beta=0.85):
    """Gerchberg-Saxton to flatten the power spectrum (makes autocorrelation flat)."""
    a = np.maximum(a.astype(np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        return a
    a = a / s
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    best_a = a.copy()
    best_M = fft_conv_auto(a).max()

    for it in range(n_iters):
        F = np.fft.rfft(a, size)
        mag = np.abs(F)
        phase = np.angle(F)
        # Compress magnitude
        mag_flat = mag ** (1.0 - beta)
        mag_flat = mag_flat / (mag_flat.max() + 1e-30) * mag.max()
        F_new = mag_flat * np.exp(1j * phase)
        a_new = np.fft.irfft(F_new, size)[:n]
        a_new = np.maximum(a_new, 0)
        sc = a_new.sum()
        if sc < 1e-15:
            break
        a_new = a_new / sc
        M_c = fft_conv_auto(a_new).max()
        if M_c < best_M:
            best_M = M_c
            best_a = a_new.copy()
        a = a_new

    return best_a


def build_lp_matrix(n, a):
    """Build sparse matrix A where (a*g)[k] = (A@g)_k for k=0..2n-2."""
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        j_lo = max(0, k - n + 1)
        j_hi = min(n - 1, k)
        for j in range(j_lo, j_hi + 1):
            rows.append(k)
            cols.append(j)
            vals.append(a[k - j])
    return csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))


def lp_best_response(a, M):
    """Solve LP: max 1^T g s.t. conv(a,g) <= M, g >= 0."""
    n = len(a)
    A = build_lp_matrix(n, a)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    try:
        r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                    options={'presolve': True, 'dual_feasibility_tolerance': 1e-9,
                             'primal_feasibility_tolerance': 1e-9})
        if r.success and r.x is not None and r.x.sum() > 1e-15:
            return np.maximum(r.x, 0)
    except Exception:
        pass
    return None


def anderson_mix(history_x, history_g, m, extrapolate=True):
    """Anderson mixing: find convex combination of history to accelerate convergence."""
    if m < 2:
        return history_g[-1].copy()
    residuals = []
    for i in range(m):
        residuals.append(history_x[i] - history_g[i])
    R = np.array(residuals)
    G = R @ R.T + 1e-14 * np.eye(m)
    ones = np.ones(m)
    try:
        alpha = np.linalg.solve(G, ones)
        s = alpha.sum()
        if abs(s) < 1e-12:
            alpha = ones / m
        else:
            alpha = alpha / s
    except np.linalg.LinAlgError:
        alpha = ones / m
    if extrapolate:
        alpha = np.clip(alpha, -0.5, 2.0)
        alpha = alpha / alpha.sum()
    mixed = np.zeros(len(history_x[0]))
    for i in range(m):
        mixed += alpha[i] * history_g[i]
    return np.maximum(mixed, 0)


def lp_anderson_optimize(a, deadline, max_iters=150, window=5,
                         t_start=0.4, t_min=0.01):
    """LP best-response with Anderson acceleration."""
    a = np.maximum(a.astype(np.float64), 1e-10)
    a = a / a.sum()
    n = len(a)
    best_a = a.copy()
    best_M = fft_conv_auto(a).max()
    no_imp = 0
    hist_x = []
    hist_g = []

    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        b = fft_conv_auto(a)
        M = float(b.max())
        if M < best_M * (1.0 - 1e-12):
            best_M = M
            best_a = a.copy()
            no_imp = 0
        else:
            no_imp += 1
            if no_imp > 50:
                break

        g = lp_best_response(a, M)
        if g is None:
            break
        gs = g.sum()
        if gs < 1e-10:
            break
        g = g / gs

        # Step size with decay
        t = max(t_min, t_start / (1.0 + 0.03 * it))
        a_new = np.maximum((1.0 - t) * a + t * g, 0.0)
        s = a_new.sum()
        if s < 1e-10:
            a_new = a.copy()
        else:
            a_new = a_new / s

        # Anderson acceleration
        hist_x.append(a.copy())
        hist_g.append(a_new.copy())
        if len(hist_x) > window:
            hist_x.pop(0)
            hist_g.pop(0)

        if len(hist_x) >= 3:
            a_and = anderson_mix(hist_x, hist_g, len(hist_x))
            sa = a_and.sum()
            if sa > 1e-10:
                a_and = a_and / sa
                M_and = fft_conv_auto(a_and).max()
                M_new = fft_conv_auto(a_new).max()
                if M_and <= M_new * 1.02:
                    a = a_and
                else:
                    a = a_new
            else:
                a = a_new
        else:
            a = a_new

    return best_a


def coordinate_descent(a, deadline, n_trials=5000):
    """Local coordinate descent: try perturbing individual elements."""
    a = np.maximum(a.astype(np.float64), 0)
    a = a / a.sum()
    n = len(a)
    best_a = a.copy()
    best_M = fft_conv_auto(a).max()
    rng = np.random.default_rng(12345)
    trial = 0

    while trial < n_trials:
        if time.monotonic() > deadline:
            break
        trial += 1
        # Pick a random coordinate to perturb
        j = rng.integers(0, n)
        # Try small perturbations
        for delta in [0.001, -0.001, 0.005, -0.005, 0.01, -0.01]:
            a_trial = a.copy()
            a_trial[j] = max(0, a_trial[j] + delta)
            s = a_trial.sum()
            if s < 0.01:
                continue
            a_trial = a_trial / s
            M_trial = fft_conv_auto(a_trial).max()
            if M_trial < best_M * (1.0 - 1e-9):
                a = a_trial
                best_M = M_trial
                best_a = a.copy()
                break

    return best_a


def resample_sequence(src, n_new):
    """Resample a 1D sequence to a new length using linear interpolation."""
    src = np.asarray(src, dtype=np.float64)
    if src.size == n_new:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, n_new)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)


def make_window_inits(n, rng):
    """Create diverse window-function initializations."""
    inits = []
    t = np.linspace(0, 1, n, endpoint=False)

    # Uniform
    inits.append(np.ones(n))

    # Cosine windows with different parameters
    for alpha in [0.3, 0.5, 0.7, 1.0, 1.5, 2.0]:
        w = 0.5 + 0.5 * np.cos(2 * np.pi * (t - 0.5) * alpha)
        inits.append(np.maximum(w + 0.05, 0.01))

    # Asymmetric windows (key for breaking symmetry!)
    for skew in [0.3, 0.5, 0.7, 1.0, 1.5]:
        w = np.exp(-skew * (t - 0.5) ** 2 * 4)
        inits.append(np.maximum(w + 0.05, 0.01))

    # Linear sawtooth (maximally asymmetric)
    inits.append(np.maximum(0.1 + 0.9 * t, 0.05))
    inits.append(np.maximum(0.1 + 0.9 * (1 - t), 0.05))

    # Piecewise linear asymmetric
    peak = rng.uniform(0.2, 0.8)
    w = np.where(t < peak, t / peak, (1 - t) / (1 - peak)) if peak > 0 and peak < 1 else np.ones(n)
    inits.append(np.maximum(w + 0.05, 0.01))

    # Random smooth
    k = max(5, n // 16)
    kern = np.ones(k) / k
    inits.append(np.maximum(np.convolve(rng.uniform(0.2, 1.0, n), kern, 'same') + 0.05, 0.01))

    # Fourier-based asymmetric
    coeffs = rng.normal(0, 0.5, min(n // 2, 20))
    w = np.ones(n)
    for i, c in enumerate(coeffs):
        w += c * np.cos(2 * np.pi * (i + 1) * t + rng.uniform(0, 2 * np.pi))
    inits.append(np.maximum(w + 0.5, 0.01))

    return inits


def multi_scale_build(target_n, rng, deadline):
    """Build a good initial solution by multi-scale GS from small to large n."""
    scales = [64, 128, 256, 512, 1024, 2048, 4096]
    scales = [s for s in scales if s <= target_n]
    if not scales or scales[-1] < target_n:
        scales.append(target_n)

    a = np.ones(scales[0])
    for target in scales:
        if time.monotonic() > deadline:
            break
        if target > len(a):
            a = resample_sequence(a, target)
        a = np.maximum(a, 1e-4)
        a = a / a.sum()
        # GS iterations proportional to size
        n_iters = max(100, 50000 // target)
        a = gs_symmetric(a, n_iters=n_iters, beta=0.85)
        a = np.maximum(a, 1e-4)
        a = a / a.sum()

    if len(a) != target_n:
        a = resample_sequence(a, target_n)
        a = np.maximum(a, 1e-4)
        a = a / a.sum()
    return a

                                     t_start=0.4, t_min=0.02)
        best.update(a_lp1)
        print(f"  LP pass 1 done, J={compute_J(a_lp1):.8f}", flush=True)

        # Second LP pass: smaller steps for convergence
        if time.monotonic() < deadline - 100:
            p3b_dl = min(time.monotonic() + 300.0, deadline - 50.0)
            a_lp2 = lp_anderson_optimize(a_lp1, p3b_dl,
                                         max_iters=200, window=6,
                                         t_start=0.2, t_min=0.005)
            best.update(a_lp2)
            print(f"  LP pass 2 done, J={compute_J(a_lp2):.8f}", flush=True)

    best.report("Phase 3")

    # === Phase 4: Try other lengths with LP ===
    print(f"\n{'='*60}", flush=True)
    print("PHASE 4: Multi-length LP exploration", flush=True)
    print(f"{'='*60}", flush=True)

    if time.monotonic() < deadline - 60:
        for n_try in [1024, 2048, 1536]:
            if time.monotonic() > deadline - 40:
                break
            if n_try == best_n_key:
                continue
            # Resample best to this length
            a_res = resample_sequence(best.seq, n_try)
            a_res = np.maximum(a_res, 1e-6)
            a_res = a_res / a_res.sum()
            # Quick smooth
            a_res = fista_optimize(a_res, min(time.monotonic() + 30, deadline - 35),
                                   max_iters=500, tau_start=5.0, tau_end=100.0,
                                   lr_base=0.3)
            best.update(a_res)
            # LP polish
            if time.monotonic() < deadline - 30:
                a_lp = lp_anderson_optimize(a_res, min(time.monotonic() + 60, deadline - 25),
                                            max_iters=50, window=4,
                                            t_start=0.3, t_min=0.01)
                best.update(a_lp)

    best.report("Phase 4")

    # === Phase 5: Coordinate descent polish ===
    print(f"\n{'='*60}", flush=True)
    print("PHASE 5: Coordinate descent", flush=True)
    print(f"{'='*60}", flush=True)

    if best.seq is not None and time.monotonic() < deadline - 10:
        a_cd = coordinate_descent(best.seq, min(time.monotonic() + 120, deadline - 5),
                                  n_trials=20000)
        best.update(a_cd)

    # === Phase 6: Final LP micro-steps ===
    if best.seq is not None and time.monotonic() < deadline - 5:
        a_final = lp_anderson_optimize(best.seq, deadline,
                                       max_iters=100, window=5,
                                       t_start=0.1, t_min=0.002)
        best.update(a_final)

    best.report("FINAL")

    # Fallback
    if best.seq is None:
        best.seq = np.ones(128)
        best.score = compute_J(best.seq)

    total_time = time.monotonic() - best.t0
    print(f"\n{'='*60}", flush=True)
    print(f"RESULT: J={best.score:.8f} n={best.seq.size} time={total_time:.0f}s", flush=True)
    print(f"{'='*60}", flush=True)

    return [float(x) for x in best.seq]
