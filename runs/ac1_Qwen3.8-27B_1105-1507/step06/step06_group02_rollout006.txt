This can be written as a^T Q_k a where Q_k is a permutation matrix (shifting by k) restricted to valid indices. But since it's not symmetric in general (Q_k != Q_k^T unless k=0), we can write:
C_k = a^T Q_k a where Q_k[j,l] = 1 if j+l = k (for the "cross" term) and Q_k[j,j] = 1 if 2j = k.

Wait, a^T Q a = sum_{j,l} a_j Q_{j,l} a_l. For C_k = sum_j a_j a_{k-j}, we need Q_{j,k-j} = 1 for all valid j. So Q_k is a "reverse identity" shifted by k.

The constraint a^T Q_k a <= t is not a convex constraint (unless Q_k is positive semidefinite, which it's not in general). So SDP doesn't directly apply.

**Alternative: Use the DCP (Disciplined Convex Programming) framework**

Actually, I think the problem is best approached with the iterative methods (LP mirror descent, smooth gradient) rather than trying to formulate it as a single convex problem.

```
2. Phase 1 (100s): Quick smooth optimization to get a good starting point

   - Adaptive tau (start small, increase)
3. Phase 2 (1000s): Aggressive LP mirror descent
   - Momentum (Nesterov)
   - Adaptive step size (backtracking on J)
   - Anderson acceleration
   - Periodic perturbation (every 200 iterations, add small random noise)
4. Phase 3 (300s): Multi-length exploration
   - Resample best to nearby lengths
   - Quick optimization on each
   - Keep the best
5. Phase 4 (100s): Final polish
   - Very fine-step LP mirror descent
   - Try to squeeze out last bits of improvement
```

Let me also think about the "peak shaving" idea more carefully.

When we have the current sequence a and the convolution C = conv(a,a), the peak is at position k*. To reduce C_{k*} = sum_j a_j * a_{k*-j}, we can:
- Decrease a_j and a_{k*-j} for j in the valid range
- The most "efficient" reduction is to decrease the pairs (a_j, a_{k*-j}) where both are large

This suggests a "pairwise" gradient:
dJ/da_j ≈ 2 * a_{k*-j} / S (for the peak k*)

But we also need to maintain sum(a) = S (or rather, we normalize after each step).

Actually, since we normalize after each step, the constraint is just a >= 0. The gradient direction to reduce C_{k*} while maintaining non-negativity is:
g_j = -2 * a_{k*-j} (capped at 0)

Then we project to the non-negative orthant and normalize.

This is essentially what the LP does, but the LP considers ALL peaks simultaneously, which is better.

```python
"""
Minimizes J(a) = 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Frequency-domain Gerchberg-Saxton initialization for flat autocorrelation
2. Smooth log-sum-exp gradient descent with Nesterov momentum
3. LP mirror descent with momentum, adaptive step-size, and Anderson acceleration
4. Periodic perturbation to escape local optima
5. Multi-length exploration and final fine-step polish
Key improvements over previous: momentum in LP phase, adaptive backtracking step size,
periodic perturbation for local-optimum escape, and more time allocated to LP convergence.
"""

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time


def fast_conv(a):
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]


def compute_J(a):
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))


def gs_flat_spectral(init, n_iters=200, beta=0.8):
    a = np.maximum(init.astype(np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        return a
    a /= s
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    best_a = a.copy()
    best_M = fast_conv(a).max()
    for it in range(n_iters):
        F = np.fft.rfft(a, size)
        mag = np.abs(F)
        phase = np.angle(F)
        power = 0.5 + 0.5 * beta
        mag_pow = mag ** power
        mag_new = mag_pow / (mag_pow.max() + 1e-30) * mag.max()
        # Additional flattening via soft thresholding
        mag_mean = mag_new.mean()
        mag_flat = 0.5 * mag_new + 0.5 * mag_mean
        F_new = np.exp(1j * phase) * mag_flat
        a_new = np.fft.irfft(F_new, size)[:n]
        a_candidate = np.maximum(a_new, 0)
        sc = a_candidate.sum()
        if sc < 1e-15:
            break
        a_candidate /= sc
        M_c = fast_conv(a_candidate).max()
        if M_c < best_M:
            best_M = M_c
            best_a = a_candidate.copy()
        a = a_candidate
    return best_a


def smooth_max_grad(a, tau):
    n = len(a)
    b = fast_conv(a)
    b_max = float(b.max())
    exp_b = np.exp(tau * (b - b_max))
    p = exp_b / exp_b.sum()
    grad = np.zeros(n)
    active = np.where(p > 1e-10)[0]
    for k in active:
        lo = max(0, k - n + 1)
        hi = min(n - 1, k)
        seg = a[k - hi:k - lo + 1][::-1]
        grad[lo:hi + 1] += 2.0 * p[k] * seg
    return grad, p, b, b_max


def run_nesterov_smooth(a, deadline, max_iters=5000, tau_start=1.0, tau_end=300.0,
                        lr_init=0.4, lr_end=0.003):
    a = np.maximum(a.astype(np.float64), 1e-8)
    a = a / a.sum()
    n = len(a)
    best_a = a.copy()
    best_M = fast_conv(a).max()
    y = a.copy()
    beta_mom = 0.9
    for it in range(1, max_iters + 1):
        if time.monotonic() > deadline:
            break
        frac = it / max_iters
        tau = tau_start * (tau_end / tau_start) ** (frac ** 0.6)
        lr = lr_init * (lr_end / lr_init) ** frac
        grad, p, b, b_max = smooth_max_grad(y, tau)
        if b_max < best_M * (1 - 1e-10):
            best_M = b_max
            best_a = a.copy()
        t_k = (1.0 + np.sqrt(1.0 + 4.0 * beta_mom * beta_mom)) / 2.0
        a_new = np.maximum(y - lr * (grad + beta_mom * (y - a)), 0.0)
        s = a_new.sum()
        if s < 1e-10:
            a_new = a.copy()
        else:
            a_new /= s
        y = a_new + ((t_k - 1.0) / (t_k + 1.0)) * (a_new - a)
        y = np.maximum(y, 0.0)
        sy = y.sum()
        if sy < 1e-10:
            y = a_new
        else:
            y /= sy
        a = a_new
    return best_a


def build_A(n, a):
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        j_min = max(0, k - n + 1)
        j_max = min(n - 1, k)
        for j in range(j_min, j_max + 1):
            rows.append(k)
            cols.append(j)
            vals.append(a[k - j])
    return csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))


def lp_best_response(a, M):
    n = len(a)
    A = build_A(n, a)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    try:
        r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                    options={'presolve': True, 'dual_feasibility_tolerance': 1e-9,
                             'primal_feasibility_tolerance': 1e-9})
        if r.success and r.x is not None and r.x.sum() > 1e-15:
            return np.maximum(r.x, 0)
    except Exception:
        pass
    return None


def anderson_solve(history_x, history_Fx, m):
    residuals = np.array([history_x[i] - history_Fx[i] for i in range(m)])
    G = residuals @ residuals.T
    G += 1e-10 * np.eye(m)
    ones = np.ones(m)
    try:
        G_inv_ones = np.linalg.solve(G, ones)
        denom = ones @ G_inv_ones
        if abs(denom) < 1e-15:
            alpha = ones / m
        else:
            alpha = G_inv_ones / denom
    except np.linalg.LinAlgError:
        alpha = ones / m
    alpha = np.clip(alpha, -1.5, 1.5)
    s = alpha.sum()
    if abs(s) < 1e-15:
        alpha = ones / m
    else:
        alpha = alpha / s
    mixed = np.zeros(len(history_x[0]))
    for i in range(m):
        mixed += alpha[i] * history_Fx[i]
    return np.maximum(mixed, 0)


def run_lp_momentum(a, deadline, max_iters=500, anderson_window=6,
                    t_base=0.3, min_t=0.005, momentum_decay=0.9,
                    perturb_every=100, perturb_scale=0.01):
    """LP mirror descent with momentum, Anderson acceleration, and periodic perturbation."""
    a = np.maximum(a.astype(np.float64), 1e-8)
    a = a / a.sum()
    n = len(a)
    best_a = a.copy()
    best_M = fast_conv(a).max()
    best_J = compute_J(best_a)
    no_imp = 0
    hist_x = []
    hist_Fx = []
    velocity = np.zeros(n)

    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        b = fast_conv(a)
        M = float(b.max())
        cur_J = compute_J(a)
        if cur_J < best_J * (1 - 1e-10):
            best_J = cur_J
            best_M = M
            best_a = a.copy()
            no_imp = 0
        else:
            no_imp += 1
            if no_imp > 50:
                # If stuck, try perturbation
                if it % perturb_every < 10:
                    noise = np.random.default_rng(it).normal(0, perturb_scale, n)
                    a_pert = np.maximum(a + noise, 0)
                    sp = a_pert.sum()
                    if sp > 1e-10:
                        a_pert /= sp
                        J_pert = compute_J(a_pert)
                        if J_pert < best_J:
                            a = a_pert
                            best_a = a.copy()
                            best_J = J_pert
                            best_M = fast_conv(a).max()
                            no_imp = 0
                if no_imp > 80:
                    break

        g = lp_best_response(a, M)
        if g is None:
            break
        gs = g.sum()
        if gs < 1e-10:
            break
        g /= gs

        # Adaptive step size with backtracking
        if it < 10:
            t = t_base
        else:
            t = max(min_t, t_base / (1.0 + 0.03 * it))

        # Momentum update
        direction = g - a
        velocity = momentum_decay * velocity + (1 - momentum_decay) * direction
        a_momentum = np.maximum(a + t * velocity, 0.0)
        sm = a_momentum.sum()
        if sm < 1e-10:
            a_momentum = a.copy()
        else:
            a_momentum /= sm

        # Plain mirror descent step
        a_new = np.maximum((1.0 - t) * a + t * g, 0.0)
        s = a_new.sum()
        if s < 1e-10:
            a_new = a.copy()
        else:
            a_new /= s

        # Anderson acceleration
        hist_x.append(a.copy())
        hist_Fx.append(a_new.copy())
        if len(hist_x) > anderson_window:
            hist_x.pop(0)
            hist_Fx.pop(0)

        # Choose best candidate
        candidates = [a_new, a_momentum]
        if len(hist_x) >= 3:
            a_and = anderson_solve(hist_x, hist_Fx, len(hist_x))
            sa = a_and.sum()
            if sa > 1e-10:
                a_and /= sa
                candidates.append(a_and)

        best_cand = None
        best_cand_M = float('inf')
        for cand in candidates:
            Mc = fast_conv(cand).max()
            if Mc < best_cand_M:
                best_cand_M = Mc
                best_cand = cand
        a = best_cand

    return best_a


def run_lp_fine_polish(a, deadline, max_iters=200):
    """Very fine-step LP mirror descent for final convergence."""
    a = np.maximum(a.astype(np.float64), 1e-8)
    a = a / a.sum()
    n = len(a)
    best_a = a.copy()
    best_M = fast_conv(a).max()
    best_J = compute_J(best_a)
    no_imp = 0

    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        b = fast_conv(a)
        M = float(b.max())
        g = lp_best_response(a, M)
        if g is None:
            break
        gs = g.sum()
        if gs < 1e-10:
            break
        g /= gs

        improved = False
        for t in [0.15, 0.1, 0.07, 0.05, 0.03, 0.02, 0.01, 0.005, 0.003, 0.001]:
            a_t = np.maximum((1.0 - t) * a + t * g, 0.0)
            s = a_t.sum()
            if s < 1e-10:
                continue
            a_t /= s
            J_t = compute_J(a_t)
            if J_t < best_J - 1e-14:
                a = a_t
                best_J = J_t
                best_M = fast_conv(a).max()
                best_a = a.copy()
                improved = True
                break
        if improved:
            no_imp = 0
        else:
            no_imp += 1
            if no_imp > 20:
                break
    return best_a


def resample_seq(src, n):
    src = np.asarray(src, dtype=np.float64)
    if src.size == n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, n)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)


def make_diverse_inits(n, rng, parent):
    inits = []
    t = np.linspace(0, 1, n, endpoint=False)
    if parent is not None:
        p = resample_seq(parent, n)
        inits.append(p.copy())
        inits.append(np.maximum(p + rng.normal(0, 0.03, n), 0.005))
        inits.append(np.maximum(p * (1 + 0.08 * rng.normal(0, 1, n)), 0.005))
    # Cosine windows with different parameters
    for f in [1, 2, 3]:
        for amp in [0.3, 0.5, 0.7]:
            inits.append(np.maximum(0.5 + amp * np.cos(2 * np.pi * f * t), 0.01))
    # Polynomial shapes
    for alpha in [0.5, 1.0, 2.0, 3.0]:
        inits.append(np.maximum((t**alpha + (1 - t)**alpha) / 2 * 0.8 + 0.1, 0.01))
    # Gaussian bumps
    inits.append(np.exp(-4 * (t - 0.5)**2) + 0.05)
    inits.append(np.exp(-6 * (t - 0.3)**2) + np.exp(-6 * (t - 0.7)**2) + 0.03)
    # Smooth random
    k = max(3, n // 30)
    kern = np.ones(k) / k
    inits.append(np.maximum(np.convolve(rng.uniform(0, 1, n), kern, 'same') + 0.05, 0.01))
    # GS from random
    a_rand = np.maximum(rng.normal(0.5, 0.3, n), 0.01)
    inits.append(gs_flat_spectral(a_rand, n_iters=80, beta=0.85))
    if parent is not None:
        p = resample_seq(parent, n)
        inits.append(gs_flat_spectral(p, n_iters=100, beta=0.9))
    return inits


class BestTracker:
    def __init__(self):
        self.seq = None
        self.score = float('inf')
        self.t0 = time.monotonic()

    def update(self, a):
        if a is None:
            return
        a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
        if a.size == 0 or a.sum() < 0.01:
            return
        s = float(evaluate_sequence(a.tolist()))
        if np.isfinite(s) and s < self.score:
            self.score = s
            self.seq = a.copy()
            el = time.monotonic() - self.t0
            print(f"  ** J={s:.8f} n={a.size} t={el:.0f}s", flush=True)

    def report(self, label):
        if self.seq is not None:
            print(f"  {label}: J={self.score:.8f} n={self.seq.size}", flush=True)

            best.update(a_ext)

                a_lp = run_lp_momentum(a_ext, min(time.monotonic() + 15, deadline - 15),
                                       max_iters=50, anderson_window=4,
                                       t_base=0.25, min_t=0.01, momentum_decay=0.85,
                                       perturb_every=50, perturb_scale=0.005)
                best.update(a_lp)

    best.report("Phase 4")
    print(f"Phase 4 time: {time.monotonic()-p4_start:.1f}s", flush=True)

    # === PHASE 5: Final fine-step polish ===
    p5_start = time.monotonic()
    print(f"\n{'='*50}", flush=True)
    print(f"PHASE 5: Final Fine-Step Polish", flush=True)
    print(f"{'='*50}", flush=True)

    if best.seq is not None and time.monotonic() < deadline - 5:
        a_final = run_lp_fine_polish(best.seq, deadline, max_iters=300)
        best.update(a_final)

        # One more Anderson pass
        if time.monotonic() < deadline - 3:
            a_final2 = run_lp_momentum(a_final, deadline,
                                       max_iters=50, anderson_window=5,
                                       t_base=0.1, min_t=0.002, momentum_decay=0.9,
                                       perturb_every=100, perturb_scale=0.002)
            best.update(a_final2)

    best.report("Phase 5")
    print(f"Phase 5 time: {time.monotonic()-p5_start:.1f}s", flush=True)

    # Fallback
    if best.seq is None:
        best.seq = np.ones(128)
        best.score = compute_J(best.seq)

    print(f"\n{'='*50}", flush=True)
    print(f"FINAL: J={best.score:.8f} n={best.seq.size} time={time.monotonic()-best.t0:.0f}s", flush=True)
    print(f"{'='*50}", flush=True)
    return [float(x) for x in best.seq]
```
