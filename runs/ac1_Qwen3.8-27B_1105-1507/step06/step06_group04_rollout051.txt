def subgradient_at_peak(a, threshold_frac=0.0):

    Compute the subgradient of max_k (a*a)[k] at the current point.
    Uses a softmax-like weighting over the peak set for smoothness.

Let me think about the structure of optimal solutions. For the problem:

At the optimum, by KKT conditions, there should be a set of "active" peaks (positions k where (p*p)[k] = M) such that:
- The subgradient at these peaks, projected onto the tangent space of the simplex, contains 0.
- This means: there exist multipliers lambda_k >= 0 for active peaks such that:

  (The constant is the Lagrange multiplier for the sum constraint.)

This is a system of equations that characterizes the optimum. The "active set" K* and the multipliers lambda determine the solution.

At the optimum, the convolution values at active peaks are all equal to M, and the "weighted average" of the shifted p's (weighted by lambda) is constant across all coordinates.

This gives us a way to check if we're at the optimum: if there exists a probability distribution lambda on the peak set such that sum_k lambda_k * p[k-i] is constant in i, then we're at a KKT point.

**Improved Algorithm: KKT-based optimization**

1. Start with a feasible point p (on the simplex).
2. Compute conv = p*p and find the peak set K* (positions where conv[k] is within epsilon of max).
3. Solve for the "optimal" lambda distribution on K* that makes the weighted correlation as flat as possible:

5. Take a step and repeat.

But wait, in Δ_i(x), when k-i = j, we already have 2x*p_base[k-i] = 2x*0 = 0 (since p_base[j] = 0). And in Δ_j(x), when k-j = i, we have 2(c-x)*p_base[k-j] = 2(c-x)*0 = 0. So the cross term is NOT included in Δ_i or Δ_j. We need to add it separately.

So the full formula is:
(p*p)[k] = base[k] + Δ_i(x) + Δ_j(x) + cross(k)

where:
- base[k] = (p_base * p_base)[k] with p_base[i] = p_base[j] = 0
- Δ_i(x) = x^2 if 2i=k, else 2x*p_base[k-i] if 0≤k-i<n and 2i≠k, else 0
- Δ_j(x) = (c-x)^2 if 2j=k, else 2(c-x)*p_base[k-j] if 0≤k-j<n and 2j≠k, else 0
- cross(k) = 2x(c-x) if k=i+j, else 0

Let me verify: if k = i+j:
- Δ_i(x) = 2x*p_base[j] = 0 (since p_base[j]=0)
- Δ_j(x) = 2(c-x)*p_base[i] = 0 (since p_base[i]=0)
- cross(k) = 2x(c-x)
Total added: 2x(c-x) ✓ (the two cross terms p[i]*p[j] and p[j]*p[i])

If k = 2i (and i≠j):
- Δ_i(x) = x^2
- Δ_j(x) = 2(c-x)*p_base[2i-j] (if 0≤2i-j<n)
- cross(k) = 0 (unless 2i = i+j, i.e., i=j, which is excluded)
Total added: x^2 + 2(c-x)*p_base[2i-j] ✓

OK so the formula is correct. Now, (p*p)[k] as a function of x is:
- At most quadratic (sum of x^2, x, and constant terms)
- Specifically:
  - Coefficient of x^2: (1 if 2i=k) + (1 if 2j=k) + (-2 if k=i+j) [from cross term 2x(c-x) = 2cx-2x^2]
    Wait: cross term is 2x(c-x) = 2cx - 2x^2, so coefficient of x^2 is -2.
    And Δ_j has (c-x)^2 = c^2 - 2cx + x^2, so coefficient of x^2 is 1.
    And Δ_i has x^2 if 2i=k, coefficient 1.
    
  Let me just write the full expression:
  
  (p*p)[k] = base[k] + A_k * x^2 + B_k * x + D_k
  
  where:
  - From Δ_i: if 2i=k: A += 1, B += 0; elif 0≤k-i<n: A += 0, B += 2*p_base[k-i]
  - From Δ_j: if 2j=k: A += 1, B += -2c; elif 0≤k-j<n: A += 0, B += -2*p_base[k-j]
  - From cross: if k=i+j: A += -2, B += 2c
  - D_k: from Δ_j if 2j=k: D += c^2; that's it for D.

Wait, (c-x)^2 = c^2 - 2cx + x^2. So from Δ_j when 2j=k: A += 1, B += -2c, D += c^2.
From Δ_j when 2j≠k and 0≤k-j<n: B += -2*p_base[k-j] (since 2(c-x)*p = 2cp - 2xp).
From cross when k=i+j: A += -2, B += 2c (since 2x(c-x) = 2cx - 2x^2).

So:
A_k = [2i=k] + [2j=k] - 2*[k=i+j]
B_k = 2*[0≤k-i<n and 2i≠k]*p_base[k-i] - 2*[0≤k-j<n and 2j≠k]*p_base[k-j] - 2c*[2j=k] + 2c*[k=i+j]
D_k = c^2*[2j=k]
base_k = (p_base*p_base)[k]

Each (p*p)[k] is a quadratic in x: f_k(x) = base[k] + A_k*x^2 + B_k*x + D_k.

We want to minimize max_k f_k(x) over x ∈ [0, c].

This is a 1D convex optimization (min of max of convex functions). We can solve it with:
- Bisection on the subgradient
- Or ternary search (since it's unimodal)
- Or golden section search

The subgradient of max_k f_k(x) at a point x is the weighted average of f_k'(x) for active k's.
f_k'(x) = 2*A_k*x + B_k

At the optimum, 0 is in the subgradient, meaning there exist weights w_k ≥ 0, sum w_k = 1, such that:
sum_k w_k * (2*A_k*x + B_k) = 0

This gives x = -sum_k w_k * B_k / (2 * sum_k w_k * A_k) (if the denominator is non-zero).

For a practical approach, I'll use golden section search or a simple bisection method.

Actually, since we have at most 2n-1 quadratic functions, and we want to find the x that minimizes their maximum, we can use the following approach:
1. Start with x = 0 and x = c.
2. Evaluate max_k f_k(x) at several points.
3. Use golden section or bisection to find the minimum.

The function max_k f_k(x) is convex (as max of convex functions), so golden section will work.

import numpy as np
from scipy.fft import rfft, irfft
import time

def compute_conv(a):
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    conv = irfft(fa * fa, size)
    return conv[:2 * n - 1]

def compute_obj_normalized(p):
    """Assume p is already normalized (sum=1, p>=0). Return 2n*max(p*p)."""
    n = len(p)
    conv = compute_conv(p)
    return 2.0 * n * float(np.max(conv))

def normalize(a):
    a = np.maximum(a, 0).astype(np.float64)
    s = np.sum(a)
    if s > 1e-15:
        return a / s
    return np.ones(len(a), dtype=np.float64) / len(a)

def subgradient_peak(p, num_top=None):
    """
    Compute subgradient of max_k (p*p)[k] at p.
    Uses top-K peaks for a more focused gradient.
    """
    n = len(p)
    conv = compute_conv(p)
    cmax = float(np.max(conv))
    
    if num_top is not None and num_top < len(conv):
        # Use top K peaks
        top_idx = np.argsort(conv)[-num_top:]
        weights = np.zeros(len(conv))
        weights[top_idx] = 1.0 / num_top
    else:
        # Use all peaks within 1% of max
        threshold = cmax * 0.999
        peak_mask = conv >= threshold
        if not np.any(peak_mask):
            peak_mask[int(np.argmax(conv))] = True
        weights = peak_mask.astype(np.float64)
        weights /= np.sum(weights)
    
    # Compute sg[i] = 2 * sum_k weights[k] * p[k-i] (valid k-i)
    # = 2 * sum_j p[j] * weights[i+j]
    # Using FFT: corr[i] = sum_j p[j] * w[i+j] = ifft(conj(fft(p)) * fft(w))
    fft_size = 1
    while fft_size < 2 * n - 1:
        fft_size <<= 1
    
    P = rfft(p, fft_size)
    W = rfft(weights, fft_size)
    corr = irfft(np.conj(P) * W, fft_size)
    sg = 2.0 * corr[:n]
    
    return sg, conv, cmax

def exponentiated_gradient_step(p, sg, eta):
    """Mirror descent step: p_new ∝ p * exp(-eta * sg)."""
    # Center the subgradient (so that uniform direction doesn't change)
    sg_centered = sg - np.mean(sg)
    p_new = p * np.exp(-eta * sg_centered)
    p_new = np.maximum(p_new, 1e-15)
    p_new = p_new / np.sum(p_new)
    return p_new

def projected_gradient_step(p, sg, eta):
    """Standard projected gradient: p_new = proj_simplex(p - eta * sg)."""
    sg_centered = sg - np.mean(sg)
    p_new = p - eta * sg_centered
    p_new = np.maximum(p_new, 0)
    s = np.sum(p_new)
    if s > 1e-15:
        p_new = p_new / s
    else:
        p_new = np.ones(len(p)) / len(p)
    return p_new

def coordinate_descent_pair(p, i, j, max_iters=50):
    """
    Optimize p[i] and p[j] (with p[i]+p[j]=c fixed) using golden section.
    Returns new p.
    """
    n = len(p)
    c = p[i] + p[j]
    if c < 1e-15:
        return p
    
    # Compute base convolution (with p[i]=0, p[j]=0)
    p_base = p.copy()
    p_base[i] = 0
    p_base[j] = 0
    if np.sum(p_base) < 1e-15:
        # Only i and j are non-zero
        # (p*p)[k] = x^2 * δ(k,2i) + 2x(c-x)*δ(k,i+j) + (c-x)^2*δ(k,2j)
        # Simple case
        pass
    base_conv = compute_conv(p_base)
    
    # Precompute coefficients for each k
    # f_k(x) = base[k] + A_k*x^2 + B_k*x + D_k
    num_k = 2 * n - 1
    A = np.zeros(num_k)
    B = np.zeros(num_k)
    D = np.zeros(num_k)
    
    # From Δ_i:
    if 2 * i < num_k:
        A[2*i] += 1.0
    if 0 <= (i + j) < num_k:  # k = i + j (not from Δ_i directly, but handled in cross)
        pass  # handled in cross term
    # 2x * p_base[k-i] for 0 <= k-i < n, 2i ≠ k
    valid_k = np.arange(n) + i  # k values where k-i is in [0, n-1]
    valid_k = valid_k[valid_k < num_k]
    valid_k = valid_k[valid_k != 2*i]  # exclude 2i=k
    p_base_ki = p_base[valid_k - i]  # p_base[k-i] for valid k
    B[valid_k] += 2.0 * p_base_ki
    
    # From Δ_j: (c-x)^2 = c^2 - 2cx + x^2
    if 2 * j < num_k:
        A[2*j] += 1.0
        B[2*j] += -2.0 * c
        D[2*j] += c * c
    # 2(c-x) * p_base[k-j] = 2c*p_base[k-j] - 2x*p_base[k-j]
    valid_k_j = np.arange(n) + j  # k values where k-j is in [0, n-1]
    valid_k_j = valid_k_j[valid_k_j < num_k]
    valid_k_j = valid_k_j[valid_k_j != 2*j]
    p_base_kj = p_base[valid_k_j - j]
    B[valid_k_j] += -2.0 * p_base_kj
    # The 2c*p_base[k-j] part goes to D
    D[valid_k_j] += 2.0 * c * p_base_kj
    
    # Cross term: 2x(c-x) = 2cx - 2x^2, valid when k = i+j
    if 0 <= (i + j) < num_k:
        A[i + j] += -2.0
        B[i + j] += 2.0 * c
    
    # Now f_k(x) = base_conv[k] + A[k]*x^2 + B[k]*x + D[k]
    # We want to minimize max_k f_k(x) for x in [0, c]
    
    def eval_max(x):
        vals = base_conv + A * x * x + B * x + D
        return float(np.max(vals))
    
    # Golden section search
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    lo, hi = 0.0, c
    c1 = hi - gr * (hi - lo)
    c2 = lo + gr * (hi - lo)
    f1 = eval_max(c1)
    f2 = eval_max(c2)
    
    for _ in range(40):
        if hi - lo < 1e-10 * max(c, 1e-10):
            break
        if f1 < f2:
            hi = c2
            c2 = c1
            f2 = f1
            c1 = hi - gr * (hi - lo)
            f1 = eval_max(c1)
        else:
            lo = c1
            c1 = c2
            f1 = f2
            c2 = lo + gr * (hi - lo)
            f2 = eval_max(c2)
    
    x_opt = 0.5 * (lo + hi)
    p_new = p.copy()
    p_new[i] = x_opt
    p_new[j] = c - x_opt
    p_new = np.maximum(p_new, 0)
    s = np.sum(p_new)
    if s > 1e-15:
        p_new = p_new / s
    return p_new

def coordinate_descent_cyclic(p, num_rounds=1, time_budget=30.0):
    """Cyclic paired coordinate descent."""
    n = len(p)
    start = time.monotonic()
    best_p = p.copy()
    best_obj = compute_obj_normalized(p)
    rng = np.random.default_rng(42)
    
    for r in range(num_rounds):
        if time.monotonic() - start > time_budget:
            break
        # Random permutation of pairs
        # Use all pairs (i, j) where i < j, but sample for efficiency
        if n <= 200:
            pairs = [(i, j) for i in range(n) for j in range(i+1, n)]
            rng.shuffle(pairs)
        else:
            num_pairs = min(n * 2, 2000)
            pairs = []
            for _ in range(num_pairs):
                i = rng.integers(0, n)
                j = rng.integers(0, n)
                if i == j:
                    j = (j + 1) % n
                if i > j:
                    i, j = j, i
                pairs.append((i, j))
        
        for (i, j) in pairs:
            if time.monotonic() - start > time_budget:
                break
            p_new = coordinate_descent_pair(p, i, j)
            obj_new = compute_obj_normalized(p_new)
            if obj_new < best_obj:
                best_obj = obj_new
                best_p = p_new.copy()
            p = p_new  # always accept for exploration
    
    return best_p, best_obj
```

At the optimum, the KKT conditions say:
- There exist multiplier λ ≥ 0 (for the sum constraint) and weights w_k ≥ 0 on the active peak set such that:
  2 * sum_{k active} w_k * p[k-i] = λ for all i
  (with the convention that p[k-i] = 0 if k-i is out of range)

- p[i] ≥ 0 for all i
- (p*p)[k] = M for k active
- (p*p)[k] ≤ M for k not active

The key equation is: sum_{k active} w_k * p[k-i] = constant for all i.

This means the "weighted autocorrelation" of p (weighted by w on the active peaks) is constant. This is a very specific condition.

If the active set is just one point (the global max), then we need p[k*-i] to be constant in i, which means p is constant (uniform). But uniform gives a triangular convolution, so the max is at the center.

If the active set includes the center and its mirror (due to symmetry), we get more flexibility.

In practice, for a "good" sequence, the active set likely includes several positions near the center of the convolution.

Let me think about this from a different angle. What if we parameterize the sequence by its "active peak set" and solve the KKT conditions directly?

For a given active set K (sequence of peak positions) and a given p, the KKT condition is:
sum_{k in K} w_k * (p shifted by k) = constant * 1_vector

This is a system of n equations in |K| + 1 unknowns (the weights w and the constant). If |K| = n, it's a square system. If |K| < n, it's underdetermined.

For the simplest case: if the active set is {n-1} (just the center), then we need p[k-i] = p[n-1-i] to be constant, which is impossible unless p is uniform.

If the active set is {n-1, n-2, n-3, ...} (a range near the center), we have more flexibility.

This suggests that at the optimum, the convolution is "flat" over a range of positions near the center, and the peak is the same at all those positions.

**Algorithm: Flat-Convolution Optimization**

1. Target: make (p*p)[k] ≈ C for k in some "flat region" R = {r, r+1, ..., r+s-1} near the center.
2. This gives us |R| equations: (p*p)[k] = C for k in R.

5. If |R| < n, the system is underdetermined, and we can use the extra degrees of freedom to ensure p ≥ 0 and (p*p)[k] ≤ C for k not in R.

```python
"""
Peak-reduction optimization combining exact subgradient mirror descent,
adaptive step sizing, periodic LP refinement, and multi-length exploration.
Targets improvement below 1.5027 for the step function convolution peak problem.
"""

import numpy as np
from scipy.fft import rfft, irfft
from scipy.optimize import linprog
import time

# --- Core computation functions ---

def _next_pow2(m):
    size = 1
    while size < m:
        size <<= 1
    return size

def compute_conv(a):
    n = len(a)
    size = _next_pow2(2 * n - 1)
    fa = rfft(a, size)
    conv = irfft(fa * fa, size)
    return conv[:2 * n - 1]

def compute_obj(a):
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    return 2.0 * n * max_b / (s * s)

def compute_obj_norm(p):
    """p is normalized: sum=1, p>=0. Returns 2n*max(p*p)."""
    n = len(p)
    conv = compute_conv(p)
    return 2.0 * n * float(np.max(conv))

def normalize(a):
    a = np.maximum(a, 0.0).astype(np.float64)
    s = np.sum(a)
    if s > 1e-15:
        return a / s
    return np.ones(len(a), dtype=np.float64) / len(a)

def fft_cross_corr(a, w):
    """
    Compute cross-correlation: c[i] = sum_j a[j] * w[j+i] for i=0,...,len(a)-1.
    w must have length >= 2*len(a)-1.
    """
    n = len(a)
    size = _next_pow2(2 * n - 1)
    A = rfft(a, size)
    W = rfft(w, size)
    corr = irfft(np.conj(A) * W, size)
    return corr[:n]

def exact_subgradient(p, top_k=None):
    """
    Compute exact subgradient of max_k (p*p)[k].
    If top_k is given, use only the top-k peaks.
    Returns (sg, conv, cmax).
    """
    n = len(p)
    conv = compute_conv(p)
    cmax = float(np.max(conv))
    
    if conv.max() < 1e-30:
        return np.zeros(n), conv, cmax
    
    if top_k is not None and top_k < len(conv):
        top_idx = np.argpartition(conv, -top_k)[-top_k:]
        weights = np.zeros(len(conv))
        weights[top_idx] = 1.0 / top_k
    else:
        # Use peaks within 0.1% of max
        threshold = cmax * (1.0 - 1e-3)
        mask = conv >= threshold
        if not np.any(mask):
            mask[int(np.argmax(conv))] = True
        weights = mask.astype(np.float64)
        weights /= np.sum(weights)
    
    sg = 2.0 * fft_cross_corr(p, weights)
    return sg, conv, cmax

def mirror_descent_step(p, sg, eta):
    """Exponentiated gradient step (mirror descent)."""
    sg_centered = sg - np.mean(sg)
    # Clip to avoid overflow
    sg_centered = np.clip(sg_centered, -50.0, 50.0)
    p_new = p * np.exp(-
