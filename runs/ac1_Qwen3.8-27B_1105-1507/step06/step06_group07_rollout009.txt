6. Repeat.

Actually, there's a subtlety. The LP finds g that maximizes sum(g) subject to conv(a, g) <= M. But we want conv(g, g) to be small, not conv(a, g). The LP is a linearization of the problem.

The state-of-the-art approach blends: `f <- (1-t)f + t*g`. This is a trust-region step.

Let me think about what makes this problem tractable and where the previous program might be suboptimal:

1. **The LP might not be the best tool for large n**. For n > 1000, the LP might be slow. An alternative is to use a "greedy" or "water-filling" approach.

2. **The blending step might be too conservative**. Using t=1 (full step to g) might be better if we can verify improvement.

3. **The initialization matters a lot**. A good starting point saves optimization time.

4. **Length choice**: Longer sequences have more degrees of freedom but each LP is slower. There's an optimal length.

Let me think about an alternative to the LP that works for large n:

**Greedy peak reduction**:
1. Compute conv(a, a), find peak positions.
2. For each peak position k, the contribution is `sum_i a[i] * a[k-i]`.
3. To reduce this peak, we can reduce some a[i] that contribute to it.
4. The "cost" of reducing a[i] is that it also affects other convolution positions.
5. Use a simple heuristic: reduce a[i] proportionally to its contribution to the peak, then normalize.

This is like a "averaging" approach:
`a_new[i] = a[i] * (1 - lambda * peak_contribution[i])`
where `peak_contribution[i] = sum_{k in peaks} a[k-i] / peak_value`

Let me formalize this as an iterative algorithm:

**Algorithm: Iterated Convolution Smoothing**
1. Start with initial a (Hann window or parent).
2. Repeat:
   a. Compute b = conv(a, a).
   b. Compute weights: w[i] = sum_k a[max(0, min(n-1, k-i))] * I(b[k] > threshold)
      (i.e., for each position i, sum up its "partners" at peak positions)
   c. Update: a[i] = a[i] / (1 + alpha * w[i]) (or a[i] * exp(-alpha * w[i]))
   d. Normalize: a = a / sum(a)
3. Return a.

This is essentially a "self-avoiding" update: positions that contribute to peaks get reduced.

Actually, this is very similar to the "power iteration" for finding the eigenvector of a matrix with the largest eigenvalue, but applied to the convolution operator.

Let me think about it from a matrix perspective:
- T is the (2n-1) x n Toeplitz matrix representing convolution with a.
- We want to find g such that T@g has small max norm, while sum(g) is large.
- The LP does this exactly.
- A iterative approximation: `g_new = 1 / (1 + alpha * T^T @ T @ g_old)` (like a pseudo-inverse).

Wait, that's not quite right either. Let me think more carefully.

The LP is: max 1^T g s.t. T g <= M * 1, g >= 0.

The dual is: min M * 1^T y s.t. T^T y >= 1, y >= 0.

If we could solve the dual, the optimal y would tell us which constraints are binding. The complementary slackness tells us that g[i] > 0 only if (T^T y)[i] = 1.

A heuristic approach:
1. Initialize y uniformly (or proportional to the peak excess).
2. Compute `d[i] = (T^T y)[i] = sum_k y[k] * T[k,i] = sum_k y[k] * a[k-i]` (with bounds).
3. Set `g[i] = 1 / d[i]` (or `g[i] = max(0, 1 - d[i])` or similar).
4. Normalize g.
5. Update y based on the new constraint violations.

This is like a Jacobi/Kaczmarz iteration for the LP!

Let me try the **Kaczmarz method** (also known as the alternating projection method) for the LP:

The LP can be written as finding g in the polytope {g : Tg <= M, g >= 0} that maximizes 1^T g.

An alternative approach: **Block coordinate descent** or **column generation**.

Actually, I think the most effective approach for this problem, given the time constraint, is:

1. Use the **LP approach** for n <= 1000 (where it's fast enough).
2. For larger n, use a **gradient-based approach** with the log-sum-exp smoothing.
3. Combine both: use LP to get a good solution at moderate n, then resample and use gradient methods for larger n.
4. Add **randomized restarts** with different initial shapes.

Let me also consider a key insight: the optimal sequence might have a specific structure. For the continuous version, the optimal function for minimizing the peak of self-convolution (with non-negativity constraint) is related to the **Beta distribution** or **Laguerre polynomials**. 

Actually, I recall that for the problem of minimizing the L-infinity norm of the convolution of a non-negative function with itself, subject to L1 normalization, the optimal solution in the continuous case is related to the ** Gaussian function** (or more precisely, a function whose Fourier transform is as flat as possible).

But in the discrete case with non-negativity, the situation is different. Let me just focus on practical optimization.

"""
LP-iterative refinement with multi-length exploration for minimizing
2*n*max(conv(a,a))/(sum(a))^2. Uses the state-of-the-art LP approach
as the primary optimizer, combined with Adam log-space refinement
and multi-length search.
"""

import numpy as np
from scipy.optimize import linprog
from scipy.fft import rfft, irfft
import time


def compute_conv(a):
    """Compute linear convolution a*a using FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    conv = irfft(fa * fa, size)
    return conv[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)


def build_toeplitz_sparse(a):
    """Build the Toeplitz constraint matrix for LP.
    Returns (T, n) where T is (2n-1) x n and (T @ g)[k] = conv(a,g)[k]."""
    n = len(a)
    T = np.zeros((2 * n - 1, n), dtype=np.float64)
    for k in range(2 * n - 1):
        j_min = max(0, k - n + 1)
        j_max = min(k, n - 1)
        T[k, j_min:j_max + 1] = a[k - j_max:k - j_min + 1][::-1]
    return T


def solve_lp(a, M, time_limit=30):
    """Solve LP: max sum(g) s.t. conv(a,g)[k] <= M, g >= 0.
    Returns g (normalized to sum 1) or None."""
    n = len(a)
    T = build_toeplitz_sparse(a)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c, A_ub=T, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': time_limit})
        if res.status == 0:
            g = np.maximum(res.x, 0)
            s = float(np.sum(g))
            if s > 1e-10:
                return g / s
    except Exception:
        pass
    return None


def lp_iterate(a, n_iters=20, time_budget=120.0, verbose=True):
    """Iterative LP-based refinement.
    Each iteration: solve LP with current peak, blend with result."""
    start = time.monotonic()
    a = a.copy().astype(np.float64)
    a = np.maximum(a, 0)
    s = np.sum(a)
    if s < 1e-10:
        return a
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    n = len(a)
    
    for it in range(n_iters):
        if time.monotonic() - start > time_budget:
            break
        
        conv = compute_conv(a)
        M = float(np.max(conv))
        
        # Solve LP
        g = solve_lp(a, M, time_limit=min(30, time_budget * 0.3 / max(n_iters - it, 1)))
        if g is None:
            break
        
        # Try full step and blended steps
        best_iter_a = a.copy()
        best_iter_obj = best_obj
        
        for t in [0.3, 0.5, 0.7, 1.0]:
            a_try = (1 - t) * a + t * g
            a_try = np.maximum(a_try, 0)
            s_try = np.sum(a_try)
            if s_try < 1e-10:
                continue
            a_try = a_try / s_try
            obj_try = compute_obj(a_try)
            if obj_try < best_iter_obj:
                best_iter_obj = obj_try
                best_iter_a = a_try.copy()
        
        if best_obj - best_iter_obj > 1e-10:
            best_obj = best_iter_obj
            best_a = best_iter_a.copy()
            a = best_iter_a.copy()
            if verbose:
                print(f"    LP iter {it}: obj={best_obj:.8f}")
        elif verbose:
            print(f"    LP iter {it}: no improvement (obj={best_obj:.8f})")
        
        if best_obj - best_iter_obj < 1e-12:
            break
    
    return best_a


def smooth_obj_grad(a, beta):
    """Compute smoothed logsumexp objective and gradient."""
    n = len(a)
    conv = compute_conv(a)
    sum_a = float(np.sum(a))
    
    cmax = float(np.max(conv))
    shifted = beta * (conv - cmax)
    shifted = np.clip(shifted, -500, 500)
    e = np.exp(shifted)
    e_sum = float(np.sum(e))
    w = e / e_sum
    ls = cmax + np.log(e_sum) / beta
    
    obj = 2.0 * n * ls / (sum_a * sum_a)
    
    size = 1
    while size < 2 * n:
        size <<= 1
    W = rfft(w, size)
    A = rfft(a, size)
    cc = irfft(W * np.conj(A), size)
    
    grad_ls = 2.0 * cc[:n]
    grad_obj = (2.0 * n / (sum_a * sum_a)) * (grad_ls - ls / sum_a)
    
    return obj, grad_obj


def adam_log_opt(a, max_iters=10000, time_budget=60.0, beta_start=10.0,
                 beta_end=200.0, lr_start=0.04, lr_decay=0.99998):
    """Adam optimization in log-space with temperature annealing."""
    n = len(a)
    a = a.copy().astype(np.float64)
    a = np.maximum(a, 1e-12)
    s = np.sum(a)
    if s < 1e-10:
        return a
    a = a / s
    
    x = np.log(a)
    x -= np.mean(x)
    
    m = np.zeros(n)
    v = np.zeros(n)
    t_count = 0
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    
    best_a = a.copy()
    best_true_obj = compute_obj(a)
    
    start = time.monotonic()
    
    for it in range(max_iters):
        if time.monotonic() - start > time_budget:
            break
        
        progress = it / max(max_iters - 1, 1)
        beta = beta_start * (beta_end / beta_start) ** progress
        
        x_centered = x - np.max(x)
        a = np.exp(x_centered)
        a = a / np.sum(a)
        
        obj_sm, grad_a = smooth_obj_grad(a, beta)
        grad_x = grad_a * a
        
        t_count += 1
        lr_t = lr_start * (lr_decay ** it)
        m = beta1 * m + (1 - beta1) * grad_x
        v = beta2 * v + (1 - beta2) * (grad_x * grad_x)
        m_hat = m / (1 - beta1 ** t_count)
        v_hat = v / (1 - beta2 ** t_count)
        x = x - lr_t * m_hat / (np.sqrt(v_hat) + eps)
        
        if it % 500 == 0:
            x -= np.mean(x)
        
        if it % 200 == 0 or it == max_iters - 1:
            x_c = x - np.max(x)
            a_check = np.exp(x_c)
            a_check = a_check / np.sum(a_check)
            true_obj = compute_obj(a_check)
            if true_obj < best_true_obj:
                best_true_obj = true_obj
                best_a = a_check.copy()
    
    return best_a


def resample_sequence(a, new_n):
    """Resample sequence to new length via interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return a_new


def hann_window(n):
    """Generate a Hann window of length n, normalized to sum 1."""
    x = np.arange(n)
    w = 0.5 * (1 + np.cos(2 * np.pi * x / (n - 1)))
    return w / w.sum()


def blackman_window(n):
    """Generate a Blackman window of length n, normalized to sum 1."""
    x = np.arange(n)
    w = 0.42 - 0.5 * np.cos(2 * np.pi * x / (n - 1)) + 0.08 * np.cos(4 * np.pi * x / (n - 1))
    w = np.maximum(w, 0)
    return w / w.sum()


def gaussian_window(n, sigma_frac=0.4):
    """Generate a Gaussian window of length n, normalized to sum 1."""
    x = np.arange(n)
    center = (n - 1) / 2.0
    w = np.exp(-0.5 * ((x - center) / (sigma_frac * center)) ** 2)
    return w / w.sum()
