```python
def project_simplex(v):
    """Project v onto probability simplex {x >= 0, sum(x)=1}."""
    n = len(v)
```

**Active-set LP:**
At the current point a, let M = max_k (a*a)[k]. The active set is A = {k : (a*a)[k] >= M - ε} for some small ε.

We want to find a direction d such that:
- (a + d) >= 0
- sum(a + d) = sum(a) (to maintain normalization)
- (a + d)(a + d)[k] <= M for k in A (我们希望 reduce the active constraints)

Linearizing: (a + d)(a + d)[k] ≈ (a*a)[k] + 2 * (d * a)[k] for k in A.

So the LP becomes:
minimize alpha (a slack for how much we reduce the peak)
subject to: 2 * (d * a)[k] <= -alpha for k in A
           sum(d) = 0
           a + d >= 0 (i.e., d >= -a)

Or equivalently: maximize alpha
subject to: -2 * (d * a)[k] >= alpha for k in A
           sum(d) = 0
           d >= -a

This is a linear program! The variables are d[0..n-1] and alpha. The constraints are |A| + 2 (sum and non-negativity).

If |A| is small (say, 10-50), this LP is very fast!

After solving, we get a direction d. We then do a line search: find the best t in [0, 1] such that J(a + t*d) is minimized.

This is much faster than the full SCA-LP which has 2n-1 constraints.

```python
def active_set_lp(a, M, active_indices, max_time=5.0):
    """Solve active-set LP to find descent direction.
    Returns direction d and step size t.
    """
    n = len(a)
    m = len(active_indices)
    
    # LP: maximize alpha
    # s.t. -2 * (d*a)[k] >= alpha for k in active_indices
    #      sum(d) = 0
    #      d >= -a
    #
    # Variables: d[0..n-1], alpha (index n)
    # Objective: maximize alpha -> minimize -alpha
    #
    # (d*a)[k] = sum_j d[j] * a[k-j] (with a zero-padded)
    # So -2 * sum_j d[j] * a[k-j] - alpha >= 0
    # i.e., 2 * sum_j d[j] * a[k-j] + alpha <= 0
    
    rows = []
    cols = []
    vals = []
    
    for idx, k in enumerate(active_indices):
        for j in range(n):
            val = a[max(0, min(n-1, k-j))] if 0 <= k-j < n else 0
            if val != 0:
                rows.append(idx)
                cols.append(j)
                vals.append(2.0 * val)
        # alpha term: +1
        rows.append(idx)
        cols.append(n)
        vals.append(1.0)
    
    A_ub = coo_matrix((vals, (rows, cols)), shape=(m, n + 1)).tocsr()
    b_ub = np.zeros(m)
    
    # Equality: sum(d) = 0
    A_eq = coo_matrix((np.ones(n), (list(range(n)), list(range(n)))), shape=(1, n + 1)).tocsr()
    b_eq = [0.0]
    
    # Bounds: d[j] >= -a[j], alpha free
    bounds = [(-a[j], None) for j in range(n)] + [(None, None)]
    
    c_obj = np.zeros(n + 1)
    c_obj[n] = -1.0  # minimize -alpha
    
    try:
        r = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                    bounds=bounds, method='highs',
                    options={'time_limit': max_time})
        if r.success and r.x is not None:
            d = r.x[:n].copy()
            alpha = r.x[n]
            return d, alpha
    except Exception:
        pass
    return None, 0.0
```
