Let me think about the step size for subgradient descent. The standard approach is:
- `eta_t = gamma / sqrt(t)` (diminishing step size)
- Or Barzilai-Borwein: `eta_t = <s_{t-1}, y_{t-1}> / <y_{t-1}, y_{t-1}>` where `s = x_t - x_{t-1}` and `y = grad_t - grad_{t-1}`

For our problem, since we're projecting onto the simplex after each step, we can use a simpler approach:
- Take a step `a_new = a - eta * (grad - mean(grad))` (centering to maintain the sum)
- Project onto `a >= 0` (clip)
- Renormalize to `sum(a) = 1`
- If the objective didn't improve, halve `eta`

Actually, the centering step `grad - mean(grad)` ensures that the sum is preserved before the projection, which is a nice property.

Let me also think about the **pro**? of using the full subgradient vs. just the peak. The "full" subgradient would average over all bins (weighted by how close they are to the peak), which gives a smoother direction. This is the soft-max approach.

For the soft-max with parameter `tau`:
`f_tau(a) = tau * log(sum_k exp(conv(a,a)[k] / tau))`

Gradient: `∂f_tau/∂a[j] = sum_k p_k * ∂conv[k]/∂a[j]` where `p_k = exp(conv[k]/tau) / sum exp(conv[k']/tau)`.

This is a weighted average of the per-bin gradients, which is smoother than the peak subgradient.

For `tau` small, it's close to the peak subgradient. For `tau` large, it's a smooth approximation.

The computational cost is: one FFT for the convolution + O(n) for the gradient = O(n log n) per iteration. Much faster than the LP which is O(n^2) or worse.

So with 1500 seconds, we can do many more iterations of the FFT method than the LP method.

Let me estimate: for `n = 800`, one FFT of size 2048 takes ~1 microsecond. The gradient computation is O(n) = 800 operations. So one iteration is maybe 10-50 microseconds. In 1500 seconds, we could do ~100 million to 1 billion iterations. That's way more than enough.

The bottleneck will be the convergence rate, not the per-iteration cost.

Key insight: optimal solutions are asymmetric, so we don't enforce symmetry.

def compute_conv(a):
    """Full linear convolution a*a via FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))


def peak_subgradient(a):
    """
    Compute subgradient of max_k conv(a,a)[k] w.r.t. a.
    Returns (gradient, peak_location, peak_value, full_conv).
    """
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    conv = irfft(fa * fa, size)[:2 * n - 1]
    k_star = int(np.argmax(conv))

    grad = np.zeros(n)
    # conv[k] = sum_i a[i]*a[k-i]
    # d(conv[k])/d(a[j]) = a[k-j] (if 0<=k-j<n) + a[j-k] (if 0<=j-k<n)
    
    # Efficient computation:
    # First term: for j where 0 <= k_star - j < n, i.e., k_star - n < j <= k_star
    #   grad[j] += a[k_star - j]
    # Second term: for j where 0 <= j - k_star < n, i.e., k_star <= j < k_star + n
    #   grad[j] += a[j - k_star]

    j1_end = min(n - 1, k_star)

        # a[k_star - j] for j=j1_start,...,j1_end is a[k_star-j1_start],...,a[k_star-j1_end]
        # which is a reversed slice of a
        idx = k_star - np.arange(j1_start, j1_end + 1)
        grad[j1_start:j1_end + 1] += a[idx]
    
    j2_start = max(0, k_star)
    j2_end = min(n - 1, k_star + n - 1)
    if j2_start <= j2_end:
        # grad[j] += a[j - k_star] for j in [j2_start, j2_end]
        idx = np.arange(j2_start, j2_end + 1) - k_star
        grad[j2_start:j2_end + 1] += a[idx]
    
    return grad, k_star, float(conv[k_star]), conv

"""
Spectral optimization for minimum peak autocorrelation of non-negative sequences.
Uses FFT-based Adam optimization, dual LP polishing, multi-n exploration, and diverse initializations.
Key insight: optimal solutions are asymmetric; leverages spectral domain for fast gradients.
"""

import numpy as np
from scipy.fft import rfft, irfft
import time


def compute_conv(a):
    """Full linear convolution a*a via FFT. Returns array of length 2n-1."""
    n = len(a)
    if n == 0:
        return np.array([0.0])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))


def peak_gradient(a, k_star):
    """Compute gradient of conv(a,a)[k_star] w.r.t. a. O(n) via formula d/d(a[j]) = 2*a[k-j]."""
    n = len(a)
    grad = np.zeros(n)
    j_start = max(0, k_star - n + 1)
    j_end = min(n - 1, k_star)
    if j_start <= j_end:
        idx = k_star - np.arange(j_start, j_end + 1)
        grad[j_start:j_end + 1] = 2.0 * a[idx]
    return grad


def softmax_gradient(a, tau):
    """
    Compute gradient of soft-max: tau*log(sum exp(conv[k]/tau)).
    Returns (gradient, conv, peak).
    Uses FFT for O(n log n) computation.
    """
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    conv = irfft(fa * fa, size)[:2 * n - 1]
    peak = float(conv.max())

    # Softmax weights with numerical stability
    shifted = conv - peak
    log_w = shifted / tau
    log_w -= log_w.max()
    w = np.exp(log_w)
    w_sum = w.sum()
    if w_sum < 1e-300:
        # Fallback to peak subgradient
        k_star = int(np.argmax(conv))
        return peak_gradient(a, k_star), conv, peak
    w = w / w_sum

    # grad[j] = 2 * sum_{m=0}^{n-1} w[j+m] * a[m]  (cross-correlation)
    # Compute via FFT
    N = 1
    while N < n + (2 * n - 1) - 1:
        N <<= 1
    fw = rfft(w, N)
    fa2 = rfft(a, N)
    # Cross-correlation: cc[k] = sum_m a[m] * w[m-k] (circular, zero-padded to linear)
    cc = irfft(fa2 * np.conj(fw), N)
    # We want corr[j] = sum_m a[m] * w[m+j] = cc[(-j) % N]
    grad = np.zeros(n)
    for j in range(n):
        grad[j] = 2.0 * cc[(-j) % N]
    return grad, conv, peak


def spectral_adam_optimize(a_init, time_budget=100.0, verbose=False):
    """
    Adam-style optimization of max conv(a,a) using FFT-based gradients.
    Normalizes a to sum=1, a>=0 at each step.
    """
    n = len(a_init)
    a = np.maximum(a_init, 0).astype(np.float64).copy()
    s = float(np.sum(a))
    if s < 1e-10:
        a = np.ones(n) / n
    else:
        a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()

    # Adam hyperparameters
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    lr = 0.05
    tau = 0.05  # soft-max temperature (starts moderate, decreases)
    tau_min = 0.005
    tau_decay = 0.9995
    max_iter = 200000
    stall_count = 0
    stall_threshold = 500
    best_stall = best_obj

    m = np.zeros(n)  # first moment
    v = np.zeros(n)  # second moment
    t = 0

    for it in range(max_iter):
        if time.monotonic() - start > time_budget:
            break
        t += 1

        # Compute gradient (soft-max for smoothness)
        grad, conv, peak = softmax_gradient(a, tau)
        # Center gradient to preserve sum
        grad -= np.mean(grad)

        # Adam update
        m = beta1 * m + (1 - beta1) * grad
        v = beta2 * v + (1 - beta2) * grad * grad
        m_hat = m / (1 - beta1 ** t)
        v_hat = v / (1 - beta2 ** t)

        # Adaptive learning rate (decay over time)
        lr_t = lr / (1.0 + 0.001 * t)

        a_new = a - lr_t * m_hat / (np.sqrt(v_hat) + eps)
        a_new = np.maximum(a_new, 0)
        s_new = float(np.sum(a_new))
        if s_new < 1e-10:
            a_new = a.copy()
        else:
            a_new = a_new / s_new

        obj_new = compute_obj(a_new)
        if obj_new < best_obj - 1e-12:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new.copy()
            stall_count = 0
        else:
            a = a_new.copy()  # still move (for exploration)
            stall_count += 1

        # Decay temperature
        tau = max(tau_min, tau * tau_decay)

        # Periodic restart if stuck
        if stall_count > stall_threshold:
            if stall_count > stall_threshold * 3:
                # Hard restart: go back to best and perturb
                a = best_a * np.exp(np.random.default_rng(t).normal(0, 0.05, n))
                a = np.maximum(a, 0)
                s = float(np.sum(a))
                if s > 1e-10:
                    a = a / s
                m = np.zeros(n)
                v = np.zeros(n)
                t = 0
                lr = min(lr * 1.5, 0.5)
                stall_count = 0
            elif stall_count == stall_threshold:
                # Soft restart: reduce learning rate
                lr *= 0.7
                stall_count = 0

        if verbose and it % 5000 == 0:
            elapsed = time.monotonic() - start
            print(f"    spectral_adam [{elapsed:.1f}s] it={it}, obj={best_obj:.8f}, tau={tau:.5f}, lr={lr_t:.6f}")

    return best_a


def build_conv_matrix(a):
    """Build matrix A (2n-1 x n) such that A @ g = conv(a, g)."""
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        r = min(n, 2 * n - 1 - j)
        A[j:j + r, j] = a[:r]
    return A


def solve_dual_lp(a):
    """
    Solve the dual LP: max t s.t. A^T lambda >= t*1, sum(lambda)=1, lambda>=0.
    Returns (t_opt, lambda_opt) or (None, None).
    """
    n = len(a)
    a = a / np.sum(a)
    A = build_conv_matrix(a)
    # A is (2n-1) x n, A^T is n x (2n-1)
    At = A.T  # shape (n, 2n-1)

    from scipy.optimize import linprog
    # Variables: lambda (2n-1) and t (1), total = 2n
    n_var = 2 * n - 1 + 1
    c = np.zeros(n_var)
    c[-1] = -1.0  # minimize -t = maximize t

    # Constraints: A^T @ lambda - t*1 >= 0  =>  -A^T @ lambda + t*1 <= 0
    A_ub = np.zeros((n, n_var))
    A_ub[:, :2 * n - 1] = -At
    A_ub[:, -1] = 1.0
    b_ub = np.zeros(n)

    # Equality: sum(lambda) = 1
    A_eq = np.zeros((1, n_var))
    A_eq[0, :2 * n - 1] = 1.0
    b_eq = np.array([1.0])

    bounds = [(0, None)] * (2 * n - 1) + [(None, None)]

    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs',
                      options={'maxiter': 5000, 'presolve': True})
        if res.status == 0:
            t_opt = float(res.x[-1])
            lam_opt = np.maximum(res.x[:2 * n - 1], 0)
            return t_opt, lam_opt
    except Exception:
        pass
    return None, None


def lp_alternate_optimize(a_init, time_budget=60.0, verbose=False):
    """
    LP alternating: iteratively solve min-peak LP (via dual) and blend.
    """
    n = len(a_init)
    a = np.maximum(a_init, 0).astype(np.float64).copy()
    s = float(np.sum(a))
    if s < 1e-10:
        a = np.ones(n) / n
    else:
        a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    stall = 0

    max_iters = 200
    for it in range(max_iters):
        if time.monotonic() - start > time_budget:
            break

        # Solve dual LP to get t_opt (the min peak for unit-sum g)
        # Then the primal solution g gives the direction
        t_opt, lam_opt = solve_dual_lp(a)
        if t_opt is None:
            break

        # Recover primal solution from dual via complementary slackness
        # Or solve the primal LP directly
        # For simplicity, let's solve the primal
        from scipy.optimize import linprog
        A = build_conv_matrix(a)
        # Primal: min M s.t. A@g <= M, sum(g)=1, g>=0
        n_var = n + 1
        c = np.zeros(n_var)
        c[-1] = 1.0
        A_ub = np.zeros((2 * n - 1, n_var))
        A_ub[:, :n] = A
        A_ub[:, n] = -1.0
        b_ub = np.zeros(2 * n - 1)
        A_eq = np.zeros((1, n_var))
        A_eq[0, :n] = 1.0
        b_eq = np.array([1.0])
        bounds = [(0, None)] * n + [(0, None)]

        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs',
                      options={'maxiter': 5000})
        if res.status != 0:
            break

        g_lp = np.maximum(res.x[:n], 0)
        gs = float(np.sum(g_lp))
        if gs < 1e-10:
            break
        g_lp = g_lp / gs

        # Line search
        improved = False
        for t_blend in [1.0, 0.8, 0.6, 0.4, 0.3, 0.2, 0.1]:
            a_try = (1.0 - t_blend) * a + t_blend * g_lp
            a_try = np.maximum(a_try, 0)
            s_try = float(np.sum(a_try))
            if s_try < 1e-10:
                continue
            a_try = a_try / s_try
            obj_try = compute_obj(a_try)
            if obj_try < best_obj - 1e-12:
                best_obj = obj_try
                best_a = a_try.copy()
                a = a_try.copy()
                improved = True
                break

        if improved:
            stall = 0
            if verbose and it % 10 == 0:
                print(f"    LP alt it{it}: obj={best_obj:.8f}")
        else:
            stall += 1
            if stall > 15:
                break

    return best_a


def resample_sequence(a, new_n):
    """Resample sequence to new length via cubic interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n < 2:
        return np.full(new_n, a[0] if n == 1 else 0.0)
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    # Use linear for robustness
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)


def make_triangle(n, asymmetric=False, shift=0.3):
    """Create a triangular (or asymmetric triangular) sequence."""
    x = np.linspace(0, 1, n)
    if asymmetric:
        center = shift
    else:
        center = 0.5
    a = np.maximum(0, 1 - np.abs(x - center) / min(center, 1 - center + 1e-10))
    s = np.sum(a)
    if s < 1e-10:
        a = np.ones(n) / n
    else:
        a = a / s
    return a


def make_gaussian(n, center_frac=0.5, width_frac=0.3):
    """Create a Gaussian-shaped sequence."""
    x = np.linspace(0, 1, n)
    mu = center_frac
    sigma = width_frac
    a = np.exp(-0.5 * ((x - mu) / sigma) ** 2)
    s = np.sum(a)
    a = a / s
    return a


def make_ramp(n, power=1.0):
    """Create a power-law ramp: a[i] ∝ (i+1)^power or (n-i)^power."""
    x = np.arange(1, n + 1, dtype=np.float64)
    a = x ** power
    s = np.sum(a)
    a = a / s
    return a


def spectral_lp_alternate(a_init, time_budget=60.0, verbose=False):
    """
    Hybrid: alternate between spectral Adam steps and LP steps.
    """
    n = len(a_init)
    a = np.maximum(a_init, 0).astype(np.float64).copy()
    s = float(np.sum(a))
    if s < 1e-10:
        a = np.ones(n) / n
    else:
        a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()

    # Alternate: 5 spectral steps then 1 LP step
    spectral_steps = 200
    lp_every = 10
    lr = 0.03
    tau = 0.03
    m_mom = np.zeros(n)
    v_mom = np.zeros(n)
    t_adam = 0
    beta1, beta2, eps = 0.9, 0.999, 1e-8

    for it in range(spectral_steps):
        if time.monotonic() - start > time_budget:
            break

        if it % lp_every == 0 and it > 0:
            # LP step
            g_lp_result = lp_alternate_optimize(a, time_budget=0.05)
            if compute_obj(g_lp_result) < best_obj:
                best_obj = compute_obj(g_lp_result)
                best_a = g_lp_result.copy()
                a = g_lp_result.copy()
            continue

        # Spectral Adam step
        t_adam += 1
        grad, conv, peak = softmax_gradient(a, tau)
        grad -= np.mean(grad)
        m_mom = 0.9 * m_mom + 0.1 * grad
        v_mom = 0.999 * v_mom + 0.001 * grad * grad
        m_hat = m_mom / (1 - 0.9 ** t_adam)
        v_hat = v_mom / (1 - 0.999 ** t_adam)
        lr_t = lr / (1 + 0.005 * t_adam)
        a_new = a - lr_t * m_hat / (np.sqrt(v_hat) + eps)
        a_new = np.maximum(a_new, 0)
        s_new = float(np.sum(a_new))
        if s_new > 1e-10:
            a_new = a_new / s_new
            obj_new = compute_obj(a_new)
            if obj_new < best_obj - 1e-12:
                best_obj = obj_new
                best_a = a_new.copy()
            a = a_new
        tau = max(0.005, tau * 0.999)

    return best_a


def propose_candidate(seed=42, budget_s=1500):
    """
    Main search function. Uses spectral Adam optimization, LP alternating,
    multi-n exploration, and diverse initializations to minimize
    2*n*max(conv(a,a))/(sum(a))^2.
    """
    start_time = time.monotonic()
    deadline = start_time + float(budget_s) - 30.0
    rng = np.random.default_rng(seed)

    best_seq = None
    best_score = np.inf

    # Load parent
    try:
        parent_arr = np.asarray(height_sequence_1, dtype=np.float64)
        parent_arr = np.clip(parent_arr, 0, None)
        if parent_arr.size > 0 and np.isfinite(parent_arr).all():
            s = float(np.sum(parent_arr))
            if s > 0.01:
                parent = parent_arr / s
                best_score = compute_obj(parent)
                best_seq = parent.copy()
                print(f"Parent (n={parent.size}): obj={best_score:.8f}")
    except Exception:
        pass

    if best_seq is None:
        best_seq = make_triangle(800)
        best_score = compute_obj(best_seq)
        print(f"Default init (n=800, triangle): obj={best_score:.8f}")

    n_parent = len(best_seq)

    # Phase 1: Spectral Adam on parent (fast, many iterations)
    print(f"\n=== Phase 1: Spectral Adam (n={n_parent}) ===")
    remaining = deadline - time.monotonic()
    p1_budget = min(300.0, remaining * 0.3)
    a1 = spectral_adam_optimize(best_seq, time_budget=p1_budget, verbose=True)
    obj1 = compute_obj(a1)
    if obj1 < best_score:
        best_score = obj1
        best_seq = a1.copy()
        print(f"  Phase 1 result: obj={best_score:.8f}")
    else:
        print(f"  Phase 1 result: obj={obj1:.8f} (no improvement)")

    # Phase 2: Hybrid spectral+LP
    print(f"\n=== Phase 2: Hybrid Spectral+LP ===")
    remaining = deadline - time.monotonic()
    p2_budget = min(200.0, remaining * 0.25)
    a2 = spectral_lp_alternate(best_seq, time_budget=p2_budget, verbose=True)
    obj2 = compute_obj(a2)
    if obj2 < best_score:
        best_score = obj2
        best_seq = a2.copy()
        print(f"  Phase 2 result: obj={best_score:.8f}")
    else:
        print(f"  Phase 2 result: obj={obj2:.8f} (no improvement)")

    # Phase 3: Pure LP alternating
    print(f"\n=== Phase 3: LP Alternating ===")
    remaining = deadline - time.monotonic()
    p3_budget = min(150.0, remaining * 0.2)
    a3 = lp_alternate_optimize(best_seq, time_budget=p3_budget, verbose=True)
    obj3 = compute_obj(a3)
    if obj3 < best_score:
        best_score = obj3
        best_seq = a3.copy()
        print(f"  Phase 3 result: obj={best_score:.8f}")
    else:
        print(f"  Phase 3 result: obj={obj3:.8f} (no improvement)")

    # Phase 4: Multi-n exploration
    print(f"\n=== Phase 4: Multi-n Exploration ===")
    remaining = deadline - time.monotonic()
    n_best = len(best_seq)
    n_options = sorted(set([
        n_best - 100, n_best - 50, n_best - 20,
        n_best,
        n_best + 20, n_best + 50, n_best + 100,
        600, 700, 800, 900, 1000, 1200
    ]))
    n_options = [n for n in n_options if 200 <= n <= 1500]

    for n_try in n_options:
        remaining = deadline - time.monotonic()
        if remaining < 30:
            break
        if n_try == n_best:
            a_try = best_seq.copy()
        else:
            a_try = resample_sequence(best_seq, n_try)

        alloc = min(remaining * 0.15, 40.0)
        a_opt = spectral_adam_optimize(a_try, time_budget=alloc)
        obj_try = compute_obj(a_opt)
        if obj_try < best_score:
            best_score = obj_try
            best_seq = a_opt.copy()
            n_best = len(best_seq)
            print(f"  ** n={n_try}: obj={best_score:.8f} **")
        else:
            print(f"  n={n_try}: obj={obj_try:.8f}")

    # Phase 5: Diverse initializations
    print(f"\n=== Phase 5: Diverse Initializations ===")
    remaining = deadline - time.monotonic()
    n_best = len(best_seq)
    inits = []

    # Asymmetric triangle
    for shift in [0.3, 0.35, 0.4, 0.6, 0.65, 0.7]:
        inits.append(make_triangle(n_best, asymmetric=True, shift=shift))
    # Gaussians
    for mu in [0.3, 0.4, 0.5, 0.6, 0.7]:
        for sig in [0.15, 0.2, 0.25, 0.35]:
            inits.append(make_gaussian(n_best, mu, sig))
    # Ramps
    for p in [0.5, 1.0, 1.5, 2.0]:
        inits.append(make_ramp(n_best, p))
        inits.append(make_ramp(n_best, p)[::-1].copy())
    # Uniform
    inits.append(np.ones(n_best) / n_best)
    # Perturbed best
    for scale in [0.05, 0.1, 0.2]:
        a_p = best_seq * np.exp(rng.normal(0, scale, n_best))
        a_p = np.maximum(a_p, 0)
        a_p = a_p / np.sum(a_p)
        inits.append(a_p)

    # Sort initializations by their objective (try best ones first)
    init_objs = [(compute_obj(a_init), i, a_init) for i, a_init in enumerate(inits)]
    init_objs.sort(key=lambda x: x[0])

    for obj_init, idx, a_init in init_objs[:15]:
        remaining = deadline - time.monotonic()
        if remaining < 20:
            break
        if obj_init >= best_score:
            continue

        alloc = min(remaining * 0.1, 30.0)
        a_opt = spectral_adam_optimize(a_init, time_budget=alloc)
        obj_opt = compute_obj(a_opt)
        if obj_opt < best_score:
            best_score = obj_opt
            best_seq = a_opt.copy()
            print(f"  Init {idx} (n={n_best}): obj={best_score:.8f} **")
        else:
            print(f"  Init {idx}: obj={obj_opt:.8f} (init={obj_init:.8f})")

    # Phase 6: Final intensive polish
    print(f"\n=== Phase 6: Final Polish ===")
    remaining = deadline - time.monotonic()
    if remaining > 20:
        n_final = len(best_seq)
        a_final = best_seq.copy()

        # More spectral Adam with lower learning rate
        alloc = min(remaining * 0.4, 100.0)
        a_po = spectral_adam_optimize(a_final, time_budget=alloc, verbose=True)
        obj_po = compute_obj(a_po)
        if obj_po < best_score:
            best_score = obj_po
            best_seq = a_po.copy()
            a_final = a_po.copy()
            print(f"  Final spectral: obj={best_score:.8f}")

        # LP polish
        remaining = deadline - time.monotonic()
        if remaining > 20:
            alloc_lp = min(remaining * 0.3, 60.0)
            a_lp = lp_alternate_optimize(a_final, time_budget=alloc_lp, verbose=True)
            obj_lp = compute_obj(a_lp)
            if obj_lp < best_score:
                best_score = obj_lp
                best_seq = a_lp.copy()
                a_final = a_lp.copy()
                print(f"  Final LP: obj={best_score:.8f}")

        # One more spectral pass
        remaining = deadline - time.monotonic()
        if remaining > 15:
            a_last = spectral_adam_optimize(a_final, time_budget=min(remaining * 0.4, 30.0))
            obj_last = compute_obj(a_last)
            if obj_last < best_score:
                best_score = obj_last
                best_seq = a_last.copy()
                print(f"  Final spectral2: obj={best_score:.8f}")

    # Final validation
    if best_seq is None:
        best_seq = np.ones(200)
        best_score = compute_obj(best_seq)

    result = [float(max(0.0, min(1000.0, x))) for x in best_seq]
    val = evaluate_sequence(result)
    if val < np.inf:
        best_score = val
    else:
        result = [1.0] * 100
        best_score = 2.0

    elapsed = time.monotonic() - start_time
    print(f"\n=== FINAL: n={len(result)}, score={best_score:.8f}, time={elapsed:.1f}s ===")

    return result
