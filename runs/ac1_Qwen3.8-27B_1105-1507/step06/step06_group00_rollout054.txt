max = 288 at k=5. sum = 1+4+9+16 = 30. sum² = 900.

So the quadratic is worse. The issue is that for quadratics, (a*a)[2n-2] = a[n-1]² = n⁴ (for a[i]=(i+1)², a[n-1] = n², so a[n-1]² = n⁴). And (a*a)[n] ~ n⁵ (from the integral approximation). Wait, n⁵ > n⁴, so the max should be at k=n for large n.

For n=4: (a*a)[4] = 209, (a*a)[5] = 288, (a*a)[6] = 256. So max is at k=5, not k=4 or k=6.

For large n with a[i] = (i+1)²:
(a*a)[n] = sum_{i=1}^{n-1} (i+1)²(n+1-i)². Using the integral approximation: n⁵ * B(3,3) = n⁵ * 2!2!/5! = n⁵ * 4/120 = n⁵/30.
(a*a)[2n-2] = n⁴.
For large n, n⁵/30 > n⁴, so max is at k=n.

Objective ≈ 2n * n⁵/30 / (n³/3)² = 2n * n⁵/30 / n⁶/9 = 2n * n⁵/30 * 9/n⁶ = 18/30 = 3/5 = 0.6.

But for n=4, we got 2.56, not 0.6. The discrepancy is because n=4 is too small for the asymptotic formula. For n=100:
(a*a)[n] ≈ 100⁵/30 = 10¹⁰/30 ≈ 3.33 × 10⁸.
(a*a)[2n-2] = 100⁴ = 10⁸.
So max ≈ 3.33 × 10⁸.
