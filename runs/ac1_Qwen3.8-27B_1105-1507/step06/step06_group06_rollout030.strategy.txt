# Approach and Rationale
The central idea of this algorithm is to minimize the self-convolution maximum of a non-negative step function while maintaining normalization (sum of elements equals sqrt(2n)). This is achieved by exploring multiple resolutions (sequence lengths) and using gradient-based optimization in the time domain. Unlike frequency-domain methods, we focus on directly manipulating the coefficients and their spatial impacts. 

The bottleneck in previous approaches was the combinatorial nature of the problem and the heavy reliance on frequency-domain calculations. Our solution automates resolution changes within the optimization loop and handles constraints more effectively by keeping the search space bounded.

# Mathematical Specification
We optimize a sequence a of length n under the constraints:
1. Non-negativity: a_i >= 0 for all i
2. Normalization: sum(a) = sqrt(2n)

The objective is defined by the C code:
f(a) = (2n * max_{k}(a_k + a_{k + i})[where the index sum is bounded]) / (sum(a))^2

Note: The upper bound on indices is handled by mirroring edges, but since we use FFT from the evaluator, we ensure all coefficient operations remain within bounds.

For optimization, we use a constrained gradient descent approach. The gradient approximation is performed using central differences and then projected back onto the constraint space.

      iii. Use the Smoothed version as a starting point for optimization.
   c. After exploration, select the best candidate and its length for final optimization.

3. **Phase 2: Gradient-based Optimization**:
   a. Use Central Difference Gradient (CDG) to approximate the gradient of the objective.
   b. With gradient, use a projected gradient method to enforce constraints.
   c. Moves:
      i. Step size scaling (initially 0.05 with decay).
      ii. Local optimization by perturbing coefficients near the current step.
      iii. Ensure boundaries by mirroring coefficients when approaching edges.
   d. The optimization stops when:
      - Time exceeds the budget.
      - Objective converges (no improvement for a set number of iterations).
