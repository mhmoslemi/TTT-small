**Anderson Acceleration Details:**

The standard Anderson acceleration for a fixed-point iteration x_{k+1} = G(x_k):
- Keep a history of m recent iterates (x_k, G(x_k))
- At each step, find alpha that minimizes ||(1-1^T alpha) x_k + 1^T alpha G(x_k) - G((1-1^T alpha) x_k + 1^T alpha G(x_k))||
- In practice, we approximate: minimize ||sum alpha_i (x_i - G(x_i))||^2 s.t. sum alpha_i = 1
- Then set x_new = sum alpha_i G(x_i) (or sum alpha_i x_i)

The key parameters are:
- m (history length): typically 5-15
- Regularization: to handle ill-conditioned G matrix

For our problem, the fixed-point map is:
  G(a) = normalize(LP_best_response(a, max(conv(a,a))))

The convergence rate of the plain iteration is determined by the spectral radius of the Jacobian of G at the fixed point. Anderson acceleration can superlinearly converge if the conditions are met.

Let me implement a robust Anderson acceleration:

```python
def anderson_step(history_x, history_Gx, m, gamma=1.0):
    """
    Anderson acceleration step.
    history_x: list of previous iterates (length m)
    history_Gx: list of corresponding G(x) values (length m)
    Returns the new iterate.
    """
    # Differences: d_i = x_i - G(x_i)
    d = np.array([history_x[i] - history_Gx[i] for i in range(m)])
    # G matrix: G_{ij} = d_i . d_j
    Gmat = d @ d.T
    # Add regularization
    Gmat += 1e-10 * np.eye(m)
    # Solve Gmat @ alpha = ones
    ones = np.ones(m)
    try:
        alpha = np.linalg.solve(Gmat, ones)
    except np.linalg.LinAlgError:
        alpha = np.linalg.lstsq(Gmat, ones, rcond=None)[0]
    # Normalize
    alpha = alpha / alpha.sum()
    # New iterate: x_new = sum alpha_i * G(x_i)
    x_new = np.zeros_like(history_x[0])
    for i in range(m):
        x_new += alpha[i] * history_Gx[i]
    return np.maximum(x_new, 0.0)
```

Let me also add a **dual LP** approach as an alternative:

The dual LP is:
  minimize M * sum(lambda)
  subject to A^T @ lambda >= 1
             lambda >= 0

where A is the convolution matrix (A[k,j] = a[k-j]).

The dual has 2n-1 variables and n constraints (plus non-negativity). For n=1024, that's 2047 variables and 1024 constraints. The constraint matrix A^T is n x (2n-1), which is the transpose of A.

Solving the dual gives us lambda, from which we can compute the primal solution g = A^T @ lambda / (sum(A^T @ lambda)) (approximately, by complementary slackness).

Actually, the relationship between the primal and dual optima is:
- Primal: max 1^T g s.t. A g <= M*1, g >= 0
- Dual: min M * 1^T lambda s.t. A^T lambda >= 1, lambda >= 0

At optimality: g_j > 0 => (A^T lambda)_j = 1 (complementary slackness)
And: lambda_k > 0 => (A g)_k = M (complementary slackness)

So the dual tells us which constraints are active (lambda_k > 0), and the primal tells us which variables are positive (g_j > 0).

For our purposes, solving either the primal or dual LP gives us the same information. The dual might be faster because it has fewer inequality constraints (n vs 2n-1).

def lp_primal(A, M):
    """Solve primal LP: max 1^T g s.t. A g <= M*1, g >= 0"""
    n = A.shape[1]
    c = -np.ones(n)

                options={'presolve': True})

    return None

def anderson_mix(history_x, history_Gx, m, reg=1e-8):
    """Anderson mixing. Returns mixed point."""
    d = np.array([history_x[i] - history_Gx[i] for i in range(m)])
    Gmat = d @ d.T + reg * np.eye(m)
    ones = np.ones(m)
    try:
        alpha = np.linalg.solve(Gmat, ones)
    except np.linalg.LinAlgError:
        alpha = np.linalg.lstsq(Gmat, ones, rcond=None)[0]
    s = alpha.sum()
    if abs(s) < 1e-15:
        return history_Gx[-1].copy()
    alpha = alpha / s
    # Clip to avoid extreme extrapolation
    alpha = np.clip(alpha, -0.5, 2.0)
    alpha = alpha / alpha.sum()
    mixed = np.zeros_like(history_x[0])
    for i in range(m):
        mixed += alpha[i] * history_Gx[i]
    return np.maximum(mixed, 0.0)

Let me be more careful about the LP. Let me re-derive:

Given a (normalized, sum=1), and M = max(conv(a,a)):

LP:
  maximize: sum_j g_j
  subject to: for all k in {0, ..., 2n-2}: sum_j A[k,j] * g_j <= M
              g_j >= 0 for all j

where A[k,j] = a[k-j] if 0 <= k-j < n, else 0.

This LP is always feasible (g=0 is feasible) and bounded (g_j <= M / A[k,j] for any k where A[k,j] > 0).

The optimal g* gives the "best direction" to move a. After normalizing g* to have sum=1, we update a.

At the fixed point, a = g* (normalized), which means:
  (a*a)(k) <= M for all k
  And the LP says that no other non-negative vector (with the same or larger sum) can satisfy the constraints.

This is a variational characterization of the local minimum.

Now, one issue: the LP might have multiple optimal solutions. In that case, the specific solution returned by the LP solver matters. Different solvers (or different numerical precision) might give different g*, leading to different convergence paths.

To handle this, I could:
1. Add a small regularization to the objective: maximize sum(g) - epsilon * ||g||^2
   But this makes it a QP, not an LP.
2. Add a small perturbation to the constraints to break ties.
3. Accept that the solution depends on the solver and just proceed.

I'll go with option 3 for simplicity.

"""
Minimizes J(a) = 2*n*max(conv(a,a))/(sum(a))^2 using improved LP mirror descent
with Anderson acceleration, vectorized sparse matrix construction, adaptive restart,
and multi-phase strategy with neighboring length exploration.
Key improvements over previous: vectorized conv-matrix build, larger Anderson windows,
restart on stall, dual LP fallback, better time allocation, and aggressive final polish.
"""

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time


def fast_conv(a):
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]


def compute_J(a):
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))


class ConvMatrixBuilder:
    def __init__(self, n):
        self.n = n
        self.rows = []
        self.cols = []
        for k in range(2 * n - 1):
            j_min = max(0, k - n + 1)
            j_max = min(n - 1, k)
            for j in range(j_min, j_max + 1):
                self.rows.append(k)
                self.cols.append(j)
        self.rows = np.array(self.rows, dtype=np.int32)
        self.cols = np.array(self.cols, dtype=np.int32)
        self.nnz = len(self.rows)
        self.shape = (2 * n - 1, n)

    def build(self, a):
        vals = a[self.rows - self.cols].astype(np.float64)
        return csr_matrix((vals, self.rows, self.cols), shape=self.shape)


def lp_best_response(a, M, builder):
    n = len(a)
    A = builder.build(a)
    c = -np.ones(n)
    b_ub = np.full(A.shape[0], M)
    bounds = [(0, None)] * n
    try:
        r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                    options={'presolve': True, 'dual_feasibility_tolerance': 1e-9})
        if r.success and r.x is not None:
            g = np.maximum(r.x, 0)
            if g.sum() > 1e-12:
                return g
    except Exception:
        pass
    # Fallback: try with slightly relaxed M
    try:
        b_ub2 = np.full(A.shape[0], M * 1.001)
        r = linprog(c, A_ub=A, b_ub=b_ub2, bounds=bounds, method='highs',
                    options={'presolve': True})
        if r.success and r.x is not None:
            g = np.maximum(r.x, 0)
            if g.sum() > 1e-12:
                return g
    except Exception:
        pass
    return None


def anderson_mix(hist, m, reg=1e-8):
    """Anderson mixing on history of (x_i, Gx_i) pairs stored in hist."""
    d = np.array([hist[i][0] - hist[i][1] for i in range(m)])
    Gmat = d @ d.T + reg * np.eye(m)
    ones = np.ones(m)
    try:
        alpha = np.linalg.solve(Gmat, ones)
    except np.linalg.LinAlgError:
        try:
            alpha = np.linalg.pinv(Gmat) @ ones
        except Exception:
            return hist[-1][1].copy()
    s = alpha.sum()
    if abs(s) < 1e-15:
        return hist[-1][1].copy()
    alpha = alpha / s
    alpha = np.clip(alpha, -1.0, 3.0)
    alpha = alpha / alpha.sum()
    mixed = np.zeros_like(hist[0][0])
    for i in range(m):
        mixed += alpha[i] * hist[i][1]
    return np.maximum(mixed, 0.0)


def run_lp_anderson(a, deadline, max_iters=5000, window=10, t_base=0.25):
    """LP mirror descent with Anderson acceleration and restart on stall."""
    a = np.maximum(a.astype(np.float64), 1e-10)
    s = a.sum()
    if s < 1e-10:
        return a
    a = a / s
    n = len(a)
    builder = ConvMatrixBuilder(n)

    best_a = a.copy()
    best_M = fast_conv(a).max()
    hist = []
    no_imp = 0
    t = t_base
    stall_count = 0

    for it in range(max_iters):
        if time.monotonic() > deadline:
            break

        b = fast_conv(a)
        M = float(b.max())

        if M < best_M - 1e-14:
            best_M = M
            best_a = a.copy()
            no_imp = 0
            stall_count = 0
        else:
            no_imp += 1

        # Restart strategy
        if no_imp > 40:
            stall_count += 1
            if stall_count > 5:
                break
            # Perturb and restart
            a = a + 0.01 * np.random.default_rng(it).normal(0, 1, n)
            a = np.maximum(a, 1e-8)
            a = a / a.sum()
            hist = []
            no_imp = 0
            t = max(0.05, t * 0.7)
            continue

        g = lp_best_response(a, M, builder)
        if g is None:
            break
        gs = g.sum()
        if gs < 1e-10:
            break
        g = g / gs

        a_new = (1.0 - t) * a + t * g
        a_new = np.maximum(a_new, 0.0)
        s_new = a_new.sum()
        if s_new < 1e-10:
            a = a.copy()
            continue
        a_new = a_new / s_new

        # Anderson acceleration
        hist.append((a.copy(), a_new.copy()))
        if len(hist) > window:
            hist.pop(0)

        if len(hist) >= 3:
            a_and = anderson_mix(hist, len(hist))
            sa = a_and.sum()
            if sa > 1e-10:
                a_and = a_and / sa
                M_and = fast_conv(a_and).max()
                M_new = fast_conv(a_new).max()
                if M_and <= M_new + 1e-13:
                    a = a_and
                else:
                    a = a_new
            else:
                a = a_new
        else:
            a = a_new

        # Gradually reduce step size
        if it % 50 == 0 and it > 100:
            t = max(0.03, t * 0.9)

    return best_a


def smooth_grad_step(a, tau, lr):
    """One step of smooth max gradient descent with L2-norm scaling."""
    n = len(a)
    b = fast_conv(a)
    b_max = float(b.max())
    exp_b = np.exp(tau * (b - b_max))
    p = exp_b / exp_b.sum()

    grad = np.zeros(n)
    for k in range(2 * n - 1):
        if p[k] < 1e-10:
            continue
        j_min = max(0, k - n + 1)
        j_max = min(n - 1, k)
        for j in range(j_min, j_max + 1):
            grad[j] += 2.0 * p[k] * a[k - j]

    a_new = a - lr * grad
    a_new = np.maximum(a_new, 0.0)
    s_new = a_new.sum()
    if s_new < 1e-10:
        return a.copy()
    return a_new / s_new


def run_smooth_descent(a, deadline, max_iters=5000, tau_start=5.0, tau_end=200.0,
                       lr_init=0.3, lr_end=0.005):
    """Run smooth max gradient descent with Nesterov momentum."""
    a = np.maximum(a.astype(np.float64), 1e-8)
    a = a / a.sum()
    best_a = a.copy()
    best_M = fast_conv(a).max()
    y = a.copy()
    beta_mom = 0.85

    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        frac = min(1.0, it / max_iters)
        tau = tau_start * (tau_end / tau_start) ** (frac ** 0.7)
        lr = lr_init * (lr_end / lr_init) ** frac
        a_new = smooth_grad_step(y, tau, lr)
        M = fast_conv(a_new).max()
        if M < best_M * (1 - 1e-10):
            best_M = M
            best_a = a_new.copy()
        t_k = (1.0 + np.sqrt(1.0 + 4.0 * beta_mom * beta_mom)) / 2.0
        y = a_new + ((t_k - 1.0) / (t_k + 1.0)) * (a_new - a)
        y = np.maximum(y, 0.0)
        sy = y.sum()
        if sy < 1e-10:
            y = a_new
        else:
            y = y / sy
        a = a_new

    return best_a


def resample_seq(src, n):
    src = np.asarray(src, dtype=np.float64)
    if src.size == n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, n)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)
