Let me analyze this problem carefully.

The objective is to minimize: `2 * n * max(conv(a,a)) / (sum(a))^2`

where `conv(a,a)` is the linear convolution of the sequence with itself.

This is related to the "Golay complementary sequences" problem and related to minimizing the peak-to-average power ratio of the autocorrelation. The ideal minimum is 2 (achievable by certain sequences), but we're dealing with non-negative sequences, which makes it harder.

The target is 1.5027, and our current best is 1.506548. We need to improve by about 0.004.

Let me think about what makes this problem hard:
1. The sequence must be non-negative
2. We want to minimize the peak of the autocorrelation relative to the mean
3. The factor of `n` in the numerator means longer sequences can potentially do better (since the mean of the autocorrelation grows like n, but the peak might not grow as fast)

Key insights:
- For a uniform sequence of length n, conv(a,a) has a triangular shape with peak n*(1/n) = 1 and sum = 1, so objective = 2*n*1/1 = 2*n. That's terrible.
- Wait, let me recompute. If a = [1, 1, ..., 1] (n ones), then sum(a) = n, conv(a,a) = [1, 2, 3, ..., n, n-1, ..., 1], max = n. Objective = 2*n*n/n^2 = 2. Ah, so uniform gives exactly 2!

- For a sequence that's "more spread out" in a complementary sense, we can get below 2.

The key mathematical insight: if we think of the sequence as a probability distribution p (sum = 1), then we want to minimize `2*n*max(conv(p,p))`. The minimum possible value of max(conv(p,p)) for a probability distribution of length n is at least 1/n (when p is uniform), giving objective 2. But we can do better by making the convolution flatter.

Actually wait - for a probability distribution, the sum of conv(p,p) = sum(p)^2 = 1, and it has 2n-1 elements. So the average value is 1/(2n-1). The peak must be at least the average, so max(conv) >= 1/(2n-1), giving objective >= 2n/(2n-1) ≈ 1 for large n. But the non-negativity constraint and the structure of convolution make this harder to achieve.

Let me think about what sequences achieve low values:
- Sequences with "flat" autocorrelation are what we want
- This is similar to the problem of finding sequences with low peak sidelobe levels in radar/communication

   - **Iterative projection (POCS-like)**: Alternate between projecting onto the set {non-negative, sum=1} and the set {conv(a,a) has flat peak}. The latter can be approximated by modifying the frequency magnitude.
   - **Water-filling on convolution peaks**: Instead of just reducing the max peak, try to raise the "valleys" in the convolution while keeping peaks controlled.

Let me think more carefully about the spectral approach:

If a is a sequence of length n, then the periodic autocorrelation is related to |FFT(a)|^2. For the aperiodic autocorrelation (which is what conv(a,a) gives us), the relationship is more complex, but for large n, the periodic and aperiodic autocorrelations are similar in the middle.

The ideal case for minimizing the peak of the aperiodic autocorrelation would be to have |FFT(a)|^2 be as flat as possible (excluding the DC component). This is because the aperiodic autocorrelation at lag k is approximately (1/N) * sum |FFT(a)[f]|^2 * exp(2πifk/N) for the periodic case.

So the approach would be:
1. Start with some initial sequence
2. Compute FFT(a)
3. Modify the magnitude of FFT(a) to make it more flat (while keeping DC = sum(a))
4. Take inverse FFT
5. Project onto non-negative, sum=1
6. Repeat

This is essentially the Graessar or constant modulus algorithm applied to this problem.

Let me also think about a more targeted approach:

**Key observation**: The objective is `2*n*max(conv(a,a))/sum(a)^2`. If we normalize sum(a) = 1, it's `2*n*max(conv(a,a))`. So we want to minimize the peak of the convolution.

The convolution has 2n-1 elements. The sum of all elements = sum(a)^2 = 1. So the average is 1/(2n-1). If we could make all elements equal to 1/(2n-1), we'd get objective = 2n/(2n-1) ≈ 1.

But the constraints are:
- a >= 0
- sum(a) = 1
- conv(a,a) has specific structure (it's determined by a)

2. **Population-based optimization with elitism**: Maintain a population of diverse sequences, apply local optimization to each, and select the best ones for the next generation.

3. **Adaptive length search**: The optimal length might not be 700. Try a range of lengths.

import numpy as np
from scipy.optimize import linprog
from scipy.fft import fft, ifft, rfft, irfft
import time

def compute_conv(a):
    n = len(a)
    if n == 0:
        return np.array([0.0])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    conv = irfft(fa * fa, size)
    return conv[:2 * n - 1]

def compute_obj(a):
    n = len(a)
    if n == 0:
        return np.inf
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)

def project_nonneg_sum1(a):
    a = np.maximum(a, 0)
    s = np.sum(a)
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s

def spectral_flatten(a, target_flatness=0.5, n_iters=100):
    """
    Flatten the spectrum of a to reduce autocorrelation peaks.
    Uses iterative projection: modify spectrum, project back to non-negative.
    """
    n = len(a)
    a = project_nonneg_sum1(a.copy().astype(np.float64))
    N = 1
    while N < 2 * n - 1:
        N <<= 1
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    
    for it in range(n_iters):
        # Compute FFT
        fa = fft(a, N)
        
        # Target: make |fa| more flat (excluding DC)
        magnitude = np.abs(fa)
        dc = magnitude[0]
        
        # Get non-DC magnitudes
        non_dc_mag = magnitude.copy()
        non_dc_mag[0] = 0
        # Also zero out the Nyquist bin if N is even
        if N % 2 == 0:
            non_dc_mag[N//2] = 0
        
        max_non_dc = np.max(non_dc_mag)
        if max_non_dc < 1e-15:
            break
        
        # Blend toward flat
        target_mag = np.zeros(N)
        target_mag[0] = dc
        target_mag[1:] = max_non_dc  # flat target for non-DC
        if N % 2 == 0:
            target_mag[N//2] = max_non_dc
        
        # Blend
        new_mag = (1 - target_flatness) * magnitude + target_flatness * target_mag
        # Preserve phase
        phase = np.angle(fa)
        fa_new = new_mag * np.exp(1j * phase)
        
        # Inverse FFT
        a_new = ifft(fa_new).real[:n]
        a_new = project_nonneg_sum1(a_new)
        
        obj_new = compute_obj(a_new)
        if obj_new < best_obj:
            best_obj = obj_new
            best_a = a_new.copy()
        
        a = a_new
    
    return best_a, best_obj

def spectral_anneal(a, n_iters=200, cool_rate=0.995):
    """
    Spectral shaping with simulated annealing on the flatness parameter.
    """
    n = len(a)
    a = project_nonneg_sum1(a.copy().astype(np.float64))
    N = 1
    while N < 2 * n - 1:
        N <<= 1
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    rng = np.random.default_rng(42)
    
    for it in range(n_iters):
        fa = fft(a, N)
        magnitude = np.abs(fa)
        phase = np.angle(fa)
        
        # Random perturbation of the spectrum
        flatness = 0.3 + 0.4 * rng.random()
        noise_level = 0.1 + 0.2 * rng.random()
        
        # Target: blend between current and flat
        non_dc = magnitude.copy()
        non_dc[0] = 0
        max_ndc = np.max(non_dc)
        if max_ndc < 1e-15:
            break
        
        target = (1 - flatness) * magnitude + flatness * max_ndc
        target[0] = magnitude[0]
        
        # Add noise
        target = target * np.exp(rng.normal(0, noise_level, N))
        
        fa_new = target * np.exp(1j * phase)
        a_new = ifft(fa_new).real[:n]
        a_new = project_nonneg_sum1(a_new)
        
        obj_new = compute_obj(a_new)
        
        # Accept with annealing
        if obj_new < best_obj or rng.random() < np.exp(-(obj_new - best_obj) * 10):
            a = a_new
            if obj_new < best_obj:
                best_obj = obj_new
                best_a = a_new.copy()
    
    return best_a, best_obj

def build_toeplitz(a):
    n = len(a)
    A = np.zeros((2 * n - 1, n), dtype=np.float64)
    for j in range(n):
        k_start = j
        k_end = min(j + n, 2 * n - 1)
        A[k_start:k_end, j] = a[:k_end - k_start]
    return A

def solve_lp_max_sum(a, M, time_limit=20):
    n = len(a)
    if n > 2500:
        return None
    A = build_toeplitz(a)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': time_limit})
        if res.status == 0:
            g = np.maximum(res.x, 0)
            s = float(np.sum(g))
            if s > 1e-10:
                return g / s
    except Exception:
        pass
    return None

def lp_alternate(a, max_iters=50, time_budget=40.0):
    n = len(a)
    a = project_nonneg_sum1(a.copy().astype(np.float64))
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    stall = 0

    for it in range(max_iters):
        if time.monotonic() - start > time_budget:
            break

        conv = compute_conv(a)
        M = float(np.max(conv))

        g = solve_lp_max_sum(a, M, time_limit=15)
        if g is None:
            break

        best_t_obj = np.inf
        best_t_val = 0.5
        best_a_local = best_a.copy()

        for t in [0.05, 0.1, 0.2, 0.3, 0.5, 0.7, 1.0]:
            a_try = (1.0 - t) * a + t * g
            a_try = project_nonneg_sum1(a_try)
            obj_try = compute_obj(a_try)
            if obj_try < best_t_obj:
                best_t_obj = obj_try
                best_t_val = t
                best_a_local = a_try.copy()

        if best_t_obj < best_obj - 1e-12:
            best_obj = best_t_obj
            best_a = best_a_local.copy()
            a = best_a_local
            stall = 0
        else:
            stall += 1
            if stall > 10:
                break

    return best_a, best_obj

def chase_peak(a, n_steps=50, step_size=0.03):
    n = len(a)
    a = project_nonneg_sum1(a.copy().astype(np.float64))
    best_a = a.copy()
    best_obj = compute_obj(a)

    for _ in range(n_steps):
        conv = compute_conv(a)
        k_star = int(np.argmax(conv))

        grad = np.zeros(n)
        for i in range(n):
            j = k_star - i
            if 0 <= j < n:
                grad[i] = a[j]
            j2 = i + n - 1 - k_star
            if 0 <= j2 < n:
                grad[i] += a[j2]

        # Actually the gradient of conv[k] w.r.t. a[i] is:
        # conv[k] = sum_j a[j]*a[k-j]
        # d/d a[i] = a[k-i] (if 0 <= k-i < n) + a[k-i] (the symmetric term)
        # Wait, for i != k-i: d/d a[i] = a[k-i] + a[k-i] = 2*a[k-i]
        # For i == k-i (i.e., k = 2i): d/d a[i] = 2*a[i]
        # Actually: conv[k] = sum_{j=0}^{n-1} a[j]*a[k-j]
        # d/d a[i]: terms where j=i: a[k-i]; terms where k-j=i, i.e., j=k-i: a[i]
        # If i != k-i: both terms are present, giving a[k-i] + a[i]... 
        # Wait no. Let me be more careful.
        # conv[k] = sum_j a[j] * a[k-j] where 0<=j<n and 0<=k-j<n
        # d/d a[i] = sum_j [delta(j,i) * a[k-j] + a[j] * delta(k-j, i)]
        # = a[k-i] (if 0<=k-i<n) + a[k-i] (if 0<=k-i<n)
        # Wait, the second term: sum_j a[j] * delta(k-j, i) = a[k-i] (if 0<=k-i<n)
        # So d/d a[i] = 2 * a[k-i] (if 0 <= k-i < n)
        # Except when k-i = i, i.e., k = 2i, then it's just a[i] (since the same term appears twice in the sum? No...)
        # Actually when k = 2i, the term j=i gives a[i]*a[i], and its derivative is 2*a[i].
        # And the term j=k-i=i gives the same term. So it's still 2*a[i].
        # So in all cases: d(conv[k])/da[i] = 2*a[k-i] if 0<=k-i<n, else 0.
        
        grad = np.zeros(n)
        valid = (k_star >= 0) & (k_star < 2*n-1)  # always true

            j = k_star - i
            if 0 <= j < n:
                grad[i] = 2.0 * a[j]
        
        grad_centered = grad - np.mean(grad)

        for ss in [step_size, step_size * 0.5, step_size * 2.0]:
            a_try = a - ss * grad_centered
            a_try = project_nonneg_sum1(a_try)

            if obj_try < best_obj:
                best_obj = obj_try
                best_a = a_try.copy()
                a = a_try.copy()
                break

    return best_a, best_obj

def equalize_peaks(a, n_steps=50, time_budget=20.0):

    Try to equalize all convolution peaks rather than just chasing the max.
    Use a weighted subgradient where weights are proportional to (conv[k] - target).

    n = len(a)

        cmean = float(np.mean(conv[conv > 0])) if np.any(conv > 0) else cmax

        excess = np.maximum(conv - cmean, 0)
        total_excess = np.sum(excess)
        if total_excess < 1e-15:
            break
        weights = excess / total_excess
        
        # Compute gradient: grad[i] = sum_k weights[k] * 2*a[k-i] (if 0<=k-i<n)
        grad = np.zeros(n)
        # Use FFT for efficiency
        # grad[i] = 2 * sum_{k=i}^{i+n-1} weights[k] * a[k-i]
        # = 2 * (weights * a)[correlation]
        # Let's compute via convolution
        N_fft = 1
        while N_fft < 2 * n - 1:
            N_fft <<= 1
        fw = fft(weights, N_fft)
        fa = fft(a, N_fft)
        # correlation: sum_k w[k]*a[k-i] = ifft(fft(w) * conj(fft(a)))... 
        # Actually: (w * a)[m] = sum_k w[k]*a[m-k]
        # We want sum_k w[k]*a[k-i] = (w * a_rev)[...] 
        # Hmm, let me just do it directly for now (or use a simpler FFT approach)
        
        # sum_k w[k] * a[k-i] for i = 0, ..., n-1
        # = correlation of w and a, shifted

        # Let me just use the fact that for each k with significant weight:
        # grad[i] += 2 * weights[k] * a[k-i] for 0 <= k-i < n

        # This is a cross-correlation
        # cross_corr[i] = sum_k weights[k] * a[k+i] ... no
        # Let me think again.
        # sum_k weights[k] * a[k-i] where 0<=k<n and 0<=k-i<n

        # = sum_j weights[j+i] * a[j] for valid j
        # This is the cross-correlation of weights and a!
        # cross_corr_a_w[i] = sum_j a[j] * weights[j+i]

        #   k ranges from i to i+n-1 (so that k-i ranges from 0 to n-1)
        #   grad[i] = 2 * sum_{k=i}^{i+n-1} weights[k] * a[k-i]
        
        # This is like a "sliding dot product" - can compute with FFT
        # Let's pad weights to length N_fft and a to length N_fft
        # Then ifft(fft(weights) * fft(a_rev))[n-1+i] gives what we want?

        sig_idx = np.where(weights > 1e-8)[0]

def resample_sequence(a, new_n):
    n = len(a)
    if n == new_n:
        return a.copy()
    if n < 2:
        return np.full(new_n, a[0] if n > 0 else 1.0 / new_n)
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return a_new

def generate_initializations(n, rng, parent=None):
    inits = []
    
    # Uniform
    inits.append(np.ones(n) / n)
    
    # Gaussian centered
    x = np.linspace(-4, 4, n)
    g = np.exp(-x**2 / 3)
    inits.append(g / g.sum())
    
    # Sinc-like
    x = np.linspace(-3, 3, n)
    x_safe = np.where(np.abs(x) < 1e-10, 1e-10, x)
    sinc = np.sinc(x_safe / 3)
    sinc = np.maximum(sinc, 0)
    if sinc.sum() > 0:
        inits.append(sinc / sinc.sum())
    
    # Cosine bell
    x = np.linspace(0, 1, n)
    cosbell = np.cos(np.pi * (x - 0.5)) ** 2
    inits.append(cosbell / cosbell.sum())
    
    # Random
    rnd = rng.random(n) + 0.01
    inits.append(rnd / rnd.sum())
    
    # Plateau (flat in middle, zero at edges)
    plateau = np.zeros(n)
    w = max(10, n // 3)
    start = (n - w) // 2
    plateau[start:start+w] = 1.0
    inits.append(plateau / plateau.sum())
    
    # Multi-scale noise
    base = np.ones(n) / n
    noise = rng.normal(0, 0.3, n)
    multi = np.maximum(base + noise, 0)
    inits.append(multi / multi.sum())
    
    if parent is not None:
        inits.append(resample_sequence(parent, n))
        pert = resample_sequence(parent, n) * np.exp(rng.normal(0, 0.1, n))
        inits.append(project_nonneg_sum1(pert))
    
    return inits

def population_local_opt(a, time_budget=30.0):
    """Apply multiple local optimization methods in sequence."""
    n = len(a)
    a = project_nonneg_sum1(a.copy().astype(np.float64))
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    # Chase peak
    if time.monotonic() - start < time_budget * 0.3:
        a2, obj2 = chase_peak(a, n_steps=30, step_size=0.03)
        if obj2 < best_obj:
            best_obj = obj2
            best_a = a2.copy()
    
    # Equalize peaks
    if time.monotonic() - start < time_budget * 0.5:
        a3, obj3 = equalize_peaks(best_a, n_steps=30, 
                                  time_budget=min(10, time_budget - (time.monotonic() - start)))
        if obj3 < best_obj:
            best_obj = obj3
            best_a = a3.copy()
    
    # Spectral flatten
    if time.monotonic() - start < time_budget * 0.7:
        a4, obj4 = spectral_flatten(best_a, target_flatness=0.3, 
                                    n_iters=min(50, int((time_budget - (time.monotonic() - start)) * 5)))
        if obj4 < best_obj:
            best_obj = obj4
            best_a = a4.copy()
    
    # LP if n is small enough
    if n <= 1200 and time.monotonic() - start < time_budget * 0.8:
        remaining = time_budget - (time.monotonic() - start)
        if remaining > 5:
            a5, obj5 = lp_alternate(best_a, max_iters=15, time_budget=remaining * 0.7)
            if obj5 < best_obj:
                best_obj = obj5
                best_a = a5.copy()
    
    # Final chase peak
    if time.monotonic() - start < time_budget - 2:
        a6, obj6 = chase_peak(best_a, n_steps=20, step_size=0.02)
        if obj6 < best_obj:
            best_obj = obj6

"""
Multi-strategy optimization for minimizing 2*n*max(conv(a,a))/(sum(a))^2.
Key improvements over previous version:
1. Enhanced spectral shaping via iterative constant-modulus-style algorithm
2. Peak equalization using weighted subgradient over all significant peaks

4. Population-based search with spectral crossover
5. Targeted final polishing with alternating local methods

import numpy as np
from scipy.optimize import linprog
from scipy.fft import fft, ifft, rfft, irfft
import time


def compute_conv(a):
    """Compute linear convolution a*a using FFT."""
    n = len(a)
    if n == 0:
        return np.array([0.0])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    conv = irfft(fa * fa, size)
    return conv[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)


def project_nonneg_sum1(a):
    """Project onto {a >= 0, sum(a) = 1}."""
    a = np.maximum(a, 0)
    s = np.sum(a)
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s


def resample_sequence(a, new_n):
    """Resample sequence to new length via interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n < 2:
        return np.full(new_n, a[0] if n > 0 else 1.0 / new_n)
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    return np.interp(x_new, x_old, a)


def build_toeplitz(a):
    """Build Toeplitz matrix for convolution with a."""
    n = len(a)
    A = np.zeros((2 * n - 1, n), dtype=np.float64)
    for j in range(n):
        k_start = j
        k_end = min(j + n, 2 * n - 1)
        A[k_start:k_end, j] = a[:k_end - k_start]
    return A


def solve_lp_max_sum(a, M, time_limit=20):
    """Solve LP: max sum(g) s.t. (a*g)[k] <= M for all k, g >= 0. Returns normalized g."""
    n = len(a)
    if n > 2500:
        return None
    A = build_toeplitz(a)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': time_limit})
        if res.status == 0:
            g = np.maximum(res.x, 0)
            s = float(np.sum(g))
            if s > 1e-10:
                return g / s
    except Exception:
        pass
    return None


def solve_lp_minpeak(a, time_limit=20):
    """Solve LP: min M s.t. (a*g)[k] <= M, sum(g)=1, g>=0. Returns (g, M_opt)."""
    n = len(a)
    if n > 2000:
        return None, None
    A = build_toeplitz(a)
    c = np.zeros(n + 1)
    c[-1] = 1.0
    A_ub = np.zeros((2 * n - 1, n + 1))
    A_ub[:, :n] = A
    A_ub[:, n] = -1.0
    b_ub = np.zeros(2 * n - 1)
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([1.0])
    bounds = [(0.0, None)] * n + [(0.0, None)]
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': time_limit})
        if res.status == 0:
            g = np.maximum(res.x[:n], 0)
            s = np.sum(g)
            if s > 1e-10:
                g = g / s
                M_opt = float(res.x[n])
                return g, M_opt
    except Exception:
        pass
    return None, None


def lp_alternate(a, max_iters=50, time_budget=40.0):
    """LP alternating with adaptive line search and M relaxation."""
    n = len(a)
    a = project_nonneg_sum1(a.copy().astype(np.float64))
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    stall = 0

    for it in range(max_iters):
        if time.monotonic() - start > time_budget:
            break

        conv = compute_conv(a)
        M = float(np.max(conv))

        # Try slightly relaxed M to avoid infeasibility
        g = solve_lp_max_sum(a, M * 1.01, time_limit=15)
        if g is None:
            g = solve_lp_max_sum(a, M * 1.05, time_limit=15)
        if g is None:
            break

        # Extended line search
        best_t_obj = np.inf
        best_t_val = 0.3
        best_a_local = best_a.copy()

        candidate_ts = [0.02, 0.05, 0.1, 0.15, 0.2, 0.3, 0.4, 0.5, 0.7, 1.0]
        for t in candidate_ts:
            a_try = (1.0 - t) * a + t * g
            a_try = project_nonneg_sum1(a_try)
            obj_try = compute_obj(a_try)
            if obj_try < best_t_obj:
                best_t_obj = obj_try
                best_t_val = t
                best_a_local = a_try.copy()

        if best_t_obj < best_obj - 1e-12:
            best_obj = best_t_obj
            best_a = best_a_local.copy()
            a = best_a_local
            stall = 0
        else:
            stall += 1
            if stall > 15:
                break

    return best_a, best_obj


def chase_peak(a, n_steps=50, step_size=0.03):
    """Chase-the-peak: iteratively reduce the maximum convolution peak."""
    n = len(a)
    a = project_nonneg_sum1(a.copy().astype(np.float64))
    best_a = a.copy()
    best_obj = compute_obj(a)

    for step in range(n_steps):
        conv = compute_conv(a)
        k_star = int(np.argmax(conv))

        # Gradient of conv[k_star] w.r.t. a: grad[i] = 2*a[k_star-i] if 0<=k_star-i<n
        grad = np.zeros(n)
        i_start = max(0, k_star - n + 1)
        i_end = min(n, k_star + 1)
        if i_end > i_start:
            indices = np.arange(i_start, i_end)
            a_indices = k_star - indices
            grad[indices] = 2.0 * a[a_indices]

        grad_centered = grad - np.mean(grad)

        improved = False
        for ss in [step_size, step_size * 0.5, step_size * 0.75, step_size * 1.5, step_size * 2.0]:
            a_try = a - ss * grad_centered
            a_try = project_nonneg_sum1(a_try)
            obj_try = compute_obj(a_try)
            if obj_try < best_obj:
                best_obj = obj_try
                best_a = a_try.copy()
                a = a_try.copy()
                improved = True
                break

        if not improved:
            # Try smaller steps
            for ss in [step_size * 0.25, step_size * 0.1]:
                a_try = a - ss * grad_centered
                a_try = project_nonneg_sum1(a_try)
                obj_try = compute_obj(a_try)
                if obj_try < best_obj:
                    best_obj = obj_try
                    best_a = a_try.copy()
                    a = a_try.copy()
                    break
            else:
                if step > 3:
                    break

    return best_a, best_obj


def equalize_peaks(a, n_steps=50, time_budget=20.0):
    """
    Weighted subgradient that emphasizes all significant peaks,
    not just the maximum. Aims to equalize convolution values.
    """
    n = len(a)
    a = project_nonneg_sum1(a.copy().astype(np.float64))
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()

    for step in range(n_steps):
        if time.monotonic() - start > time_budget:
            break

        conv = compute_conv(a)
        cmax = float(np.max(conv))
        # Use a soft threshold: weights proportional to excess above a fraction of max
        threshold = cmax * 0.7
        excess = np.maximum(conv - threshold, 0)
        total_excess = np.sum(excess)
        if total_excess < 1e-15:
            # Fall back to just the max
            idx = int(np.argmax(conv))
            excess = np.zeros_like(conv)
            excess[idx] = 1.0
            total_excess = 1.0
        weights = excess / total_excess

        # Compute weighted gradient: grad[i] = sum_k weights[k] * 2*a[k-i] (if 0<=k-i<n)
        grad = np.zeros(n)
        # Only process significant weights for efficiency
        sig = weights > 1e-7
        sig_idx = np.where(sig)[0]
        for k_idx in sig_idx:
            i_start = max(0, k_idx - n + 1)
            i_end = min(n, k_idx + 1)
            if i_end > i_start:
                indices = np.arange(i_start, i_end)
                a_indices = k_idx - indices
                grad[indices] += 2.0 * weights[k_idx] * a[a_indices]

        grad_centered = grad - np.mean(grad)
        grad_norm = np.linalg.norm(grad_centered)
        if grad_norm < 1e-12:
            break

        grad_centered /= grad_norm

        for ss in [0.1, 0.05, 0.2, 0.02, 0.15]:
            a_try = a - ss * grad_centered
            a_try = project_nonneg_sum1(a_try)
            obj_try = compute_obj(a_try)
            if obj_try < best_obj:
                best_obj = obj_try
                best_a = a_try.copy()
                a = a_try.copy()
                break

    return best_a, best_obj


def spectral_flatten(a, n_iters=100, time_budget=25.0):
    """
    Iterative spectral shaping: alternate between modifying the spectrum
    to flatten |FFT(a)| and projecting back to non-negative sequences.
    Uses adaptive flatness parameter.
    """
    n = len(a)
    a = project_nonneg_sum1(a.copy().astype(np.float64))
    N = 1
    while N < 2 * n - 1:
        N <<= 1

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()

    # Progressive flatness: start aggressive, become conservative
    for it in range(n_iters):
        if time.monotonic() - start > time_budget:
            break

        progress = it / max(1, n_iters)
        flatness = 0.6 * (1 - progress * 0.5)  # decay from 0.6 to 0.3

        fa = fft(a, N)
        magnitude = np.abs(fa)
        phase = np.angle(fa)

        # Target: flatten non-DC magnitudes toward their mean
        non_dc_indices = list(range(1, N))
        if N % 2 == 0:
            non_dc_indices = [i for i in non_dc_indices if i != N // 2]

        non_dc_mags = magnitude[non_dc_indices]
        target_level = np.mean(non_dc_mags)

        # Create target magnitude
        new_mag = magnitude.copy()
        for idx in non_dc_indices:
            new_mag[idx] = (1 - flatness) * magnitude[idx] + flatness * target_level

        # Keep DC fixed
        new_mag[0] = magnitude[0]

        fa_new = new_mag * np.exp(1j * phase)
        a_new = ifft(fa_new).real[:n]
        a_new = project_nonneg_sum1(a_new)

        obj_new = compute_obj(a_new)
        if obj_new < best_obj:
            best_obj = obj_new
            best_a = a_new.copy()

        a = a_new

    return best_a, best_obj


def spectral_anneal(a, n_iters=150, time_budget=30.0, seed=42):
    """
    Spectral shaping with annealing: randomly perturb the spectrum
    and accept based on objective improvement.
    """
    n = len(a)
    a = project_nonneg_sum1(a.copy().astype(np.float64))
    N = 1
    while N < 2 * n - 1:
        N <<= 1

    best_a = a.copy()
    best_obj = compute_obj(a)
    rng = np.random.default_rng(seed)
    start = time.monotonic()

    T = 0.5
    for it in range(n_iters):
        if time.monotonic() - start > time_budget:
            break

        T = 0.5 * (0.01 / 0.5) ** (it / max(1, n_iters))

        fa = fft(a, N)
        magnitude = np.abs(fa)
        phase = np.angle(fa)

        # Random spectral modification
        mode = rng.integers(0, 3)
        if mode == 0:
            # Flatten
            flatness = 0.3 + 0.4 * rng.random()
            non_dc = magnitude.copy()
            non_dc[0] = 0
            if N % 2 == 0:
                non_dc[N // 2] = 0
            target = np.mean(non_dc[non_dc > 0]) if np.any(non_dc > 0) else 1.0
            new_mag = (1 - flatness) * magnitude + flatness * target
            new_mag[0] = magnitude[0]
        elif mode == 1:
            # Phase perturbation (keep magnitude)
            phase_pert = phase + rng.normal(0, 0.2, N)
            new_mag = magnitude.copy()
            fa_new = new_mag * np.exp(1j * phase_pert)
            a_new = ifft(fa_new).real[:n]
            a_new = project_nonneg_sum1(a_new)
            obj_new = compute_obj(a_new)
            delta = obj_new - best_obj
            if delta < 0 or rng.random() < np.exp(-delta / max(T, 1e-6)):
                a = a_new
                if obj_new < best_obj:
                    best_obj = obj_new
                    best_a = a_new.copy()
            continue
        else:
            # Magnitude noise
            new_mag = magnitude * np.exp(rng.normal(0, 0.1, N))
            new_mag[0] = magnitude[0]

        fa_new = new_mag * np.exp(1j * phase)
        a_new = ifft(fa_new).real[:n]
        a_new = project_nonneg_sum1(a_new)
        obj_new = compute_obj(a_new)

        delta = obj_new - best_obj
        if delta < 0 or rng.random() < np.exp(-delta / max(T, 1e-6)):
            a = a_new
            if obj_new < best_obj:
                best_obj = obj_new
                best_a = a_new.copy()

    return best_a, best_obj


def generate_initializations(n, rng, parent=None):
    """Generate diverse initial sequences of length n."""
    inits = []

    # Uniform
    inits.append(np.ones(n) / n)

    # Gaussian centered
    x = np.linspace(-3.5, 3.5, n)
    g = np.exp(-x ** 2 / 3)
    inits.append(g / g.sum())

    # Cosine bell
    x = np.linspace(0, 1, n)
    cosbell = np.cos(np.pi * (x - 0.5)) ** 2
    inits.append(cosbell / cosbell.sum())

    # Raised cosine
    rc = 0.5 * (1 + np.cos(2 * np.pi * x))
    inits.append(rc / rc.sum())

    # Random
    rnd = rng.random(n) + 0.01
    inits.append(rnd / rnd.sum())

    # Plateau
    plateau = np.zeros(n)
    w = max(10, n // 3)
    start = (n - w) // 2
    plateau[start:start + w] = 1.0
    inits.append(plateau / plateau.sum())

    # Sinusoidal
    sine = np.sin(np.pi * x) ** 2 + 0.05
    inits.append(sine / sine.sum())

    # Bimodal
    bimodal = np.exp(-((x - 0.3) ** 2) / 0.03) + np.exp(-((x - 0.7) ** 2) / 0.03)
    inits.append(bimodal / bimodal.sum())

    if parent is not None:
        inits.append(resample_sequence(parent, n))
        pert = resample_sequence(parent, n) * np.exp(rng.normal(0, 0.1, n))
        inits.append(project_nonneg_sum1(pert))

    return inits


def intensive_local_opt(a, time_budget=60.0, n_constraint_for_lp=1500):
    """
    Apply multiple local optimization methods in a smart sequence.
    """
    n = len(a)
    a = project_nonneg_sum1(a.copy().astype(np.float64))
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()

    def try_update(a_new, obj_new):
        nonlocal best_a, best_obj
        if obj_new < best_obj:
            best_obj = obj_new
            best_a = a_new.copy()
            return True
        return False

    # 1. Chase peak (fast, good initial improvement)
    rem = time_budget - (time.monotonic() - start)
    if rem > 5:
        a1, obj1 = chase_peak(a, n_steps=min(40, int(rem * 2)), step_size=0.03)
        if try_update(a1, obj1):
            a = best_a.copy()

    # 2. Equalize peaks (targets multiple peaks simultaneously)
    rem = time_budget - (time.monotonic() - start)
    if rem > 10:
        a2, obj2 = equalize_peaks(a, n_steps=min(40, int(rem)),
                                  time_budget=min(rem * 0.4, 20.0))
        if try_update(a2, obj2):
            a = best_a.copy()

    # 3. Spectral flatten
    rem = time_budget - (time.monotonic() - start)
    if rem > 10:
        a3, obj3 = spectral_flatten(a, n_iters=min(60, int(rem * 3)),
                                    time_budget=min(rem * 0.3, 15.0))
        if try_update(a3, obj3):
            a = best_a.copy()

    # 4. LP alternating (strongest local optimizer)
    if n <= n_constraint_for_lp:
        rem = time_budget - (time.monotonic() - start)
        if rem > 15:
            a4, obj4 = lp_alternate(a, max_iters=min(30, int(rem / 3)),
                                    time_budget=rem * 0.6)
            if try_update(a4, obj4):
                a = best_a.copy()

    # 5. Final chase peak polish
    rem = time_budget - (time.monotonic() - start)
    if rem > 3:
        a5, obj5 = chase_peak(a, n_steps=min(30, int(rem)), step_size=0.015)
        if try_update(a5, obj5):
            a = best_a.copy()

    # 6. Another LP pass if time allows and n is small
    if n <= 1000:
        rem = time_budget - (time.monotonic() - start)
        if rem > 15:
            a6, obj6 = lp_alternate(a, max_iters=min(20, int(rem / 3)),
                                    time_budget=rem * 0.7)
            if try_update(a6, obj6):
                a = best_a.copy()

    return best_a, best_obj


def try_load_parent():
    """Try to load parent sequence from global variable."""
    try:
        parent = np.asarray(height_sequence_1, dtype=np.float64)
        parent = np.clip(parent, 0, 1000.0)
        if parent.size > 0 and np.isfinite(parent).all():
            return parent.copy()
    except Exception:
        pass
    return None


def propose_candidate(seed=42, budget_s=1500):
    """
    Main search function combining spectral shaping, LP alternating,
    peak equalization, and population-based exploration.

    Strategy:
    1. Load parent and generate diverse initializations
    2. Quick screening with chase_peak
    3. Intensive local optimization on top candidates
    4. Population-based evolutionary search
    5. Final intensive polishing with LP and specialized methods
    """
    start_time = time.monotonic()
    deadline = start_time + float(budget_s) - 30.0
    rng = np.random.default_rng(seed)

    best_seq = None
    best_score = np.inf

    # Load parent
    parent = try_load_parent()
    if parent is not None:
        parent_obj = compute_obj(parent)
        print(f"Parent (n={parent.size}): obj={parent_obj:.6f}")
        if parent_obj < best_score:
            best_score = parent_obj
            best_seq = parent.copy()

    if best_seq is None:
        best_seq = np.ones(700)
        best_score = compute_obj(best_seq)
        parent = best_seq.copy()
        print(f"No parent found, using uniform n=700, obj={best_score:.6f}")

    n_parent = len(best_seq)
    print(f"Starting: best={best_score:.8f}, n_parent={n_parent}")

    # === Phase 1: Diverse initialization and screening (10% budget) ===
    print("\n=== Phase 1: Diverse Initialization ===")
    phase1_budget = min(120.0, (deadline - start_time) * 0.08)

    n_options = sorted(set([
        n_parent,
        max(100, n_parent - 50),
        max(100, n_parent + 50),
        max(100, n_parent + 100),
        min(2500, n_parent + 200),
        min(2500, n_parent + 400),
        min(2500, n_parent + 600),
    ]))
    n_options = [n for n in n_options if 50 <= n <= 3000]

    all_candidates = []
    per_n_budget = max(5.0, phase1_budget / max(1, len(n_options)))

    for n_try in n_options:
        if time.monotonic() > start_time + phase1_budget:
            break
        inits = generate_initializations(n_try, rng, parent)
        per_init_time = max(0.5, per_n_budget / max(1, len(inits)))

        for init in inits:
            if time.monotonic() > start_time + phase1_budget:
                break
            a_quick, obj_quick = chase_peak(init, n_steps=15, step_size=0.03)
            if obj_quick < np.inf:
                all_candidates.append((obj_quick, a_quick))
                if obj_quick < best_score:
                    best_score = obj_quick
                    best_seq = a_quick.copy()

    all_candidates.sort(key=lambda x: x[0])
    top_candidates = all_candidates[:10]
    print(f"  Generated {len(all_candidates)}, top5: {[f'{c[0]:.6f}' for c in top_candidates[:5]]}")

    # === Phase 2: Intensive optimization on top candidates (35% budget) ===
    print(f"\n=== Phase 2: Intensive Optimization ===")
    phase2_budget = min(530.0, (deadline - start_time) * 0.35)
    phase2_start = time.monotonic()

    for ci in range(min(6, len(top_candidates))):
        if time.monotonic() > phase2_start + phase2_budget:
            break
        remaining = phase2_budget - (time.monotonic() - phase2_start)
        alloc = min(90.0, remaining / max(1, 6 - ci))
        if alloc < 15:
            break

        obj_init, a_init = top_candidates[ci]
        n_init = len(a_init)
        print(f"  Cand {ci} (n={n_init}): obj={obj_init:.8f}, budget={alloc:.0f}s")

        a_opt, obj_opt = intensive_local_opt(a_init, time_budget=alloc,
                                             n_constraint_for_lp=1500)

        if obj_opt < best_score:
            best_score = obj_opt
            best_seq = a_opt.copy()
            print(f"  ** Cand {ci}: NEW BEST {best_score:.8f} **")
        else:
            print(f"  Cand {ci} final: {obj_opt:.8f}")

    # === Phase 3: Population-based evolutionary search (25% budget) ===
    print(f"\n=== Phase 3: Population Search ===")
    print(f"Best so far: {best_score:.8f}")
    phase3_budget = min(380.0, (deadline - time.monotonic()) * 0.22)
    phase3_start = time.monotonic()

    n_best = len(best_seq)
    pop_size = 6
    pop = [(best_score, best_seq.copy())]

    # Diversify
    for pi in range(pop_size -
