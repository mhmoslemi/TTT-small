Plus the overhead of the function call. So maybe 100 microseconds per step. We could do 10,000 steps in 1 second. That's plenty.

Actually wait, for n=512, the FFT size for convolution is 1024 (next power of 2 above 1023). And for the subgradient, we need FFT size 2048 (next power of 2 above 1534). So each step involves 2 FFTs of size 2048 and 1 FFT of size 1024 (for compute_J). That's maybe 200-500 microseconds total. So we can do ~5000-10000 steps per second.

With 1500 seconds, we can do millions of steps. The question is whether subgradient descent converges fast enough.

For subgradient methods, the convergence rate is O(1/sqrt(T)), so to get from J=1.51 to J=1.50, we need about (1.51/1.50)² ≈ 1.013 times more iterations... that's not quite right.

Actually, the subgradient convergence for a Lipschitz function is:
min_{t<=T} f(x_t) - f* <= G * R / sqrt(T)
where G is the Lipschitz constant and R is the diameter of the feasible set.

If G ≈ 2 and R ≈ 1 (for sum(a)=1, a>=0), then:
f(x_T) - f* <= 2/sqrt(T)

To get f(x_T) - f* < 0.01, we need T > 40000. That's feasible.
To get f(x_T) - f* < 0.001, we need T > 4,000,000. That's also feasible in 1500 seconds.

But this is a very pessimistic bound. In practice, with momentum and good step sizes, we should converge much faster.

Let me also think about the LP approach. For n=512, the LP has 512 variables and 1023 constraints. With HiGHS solver, this should take maybe 10-100ms per solve. So we can do about 10-100 LP solves per second. Over 1500 seconds, that's 15000-150000 LP solves. That's a lot.

The key question is: how much does each LP solve improve the solution? If each LP solve reduces J by a factor of (1-epsilon), then after T solves, J is reduced by (1-epsilon)^T. For epsilon=0.001 and T=1000, that's a reduction of about 0.37, which is way more than enough.

But in practice, the improvement per LP solve decreases as we get closer to the optimum.

1. **Phase 1 (first 30% of time): Multi-start subgradient**

   - For each, run 1000-5000 subgradient steps with momentum
   - Track the best

2. **Phase 2 (next 40% of time): LP mirror descent on the best**
   - Use the best from Phase 1
   - Run LP mirror descent with adaptive step size
   - Every 20 LP solves, also try a few subgradient steps in between

3. **Phase 3 (remaining 30% of time): Intensive polishing**

   - Try small perturbations and re-optimize
   - Try resampling to nearby lengths and re-optimizing

Let me also add a key improvement: **use the active set more intelligently**. Instead of using a fixed fraction (like 2%), use the lags that are "close to the maximum." The number of active constraints affects the smoothness of the subgradient.

```python
"""
Minimizes J(a) = 2*n*max(conv(a,a))/(sum(a))² using:
1. FFT-accelerated subgradient descent with Nesterov momentum
2. LP mirror descent for refinement (HiGHS solver)
3. Active-set-adaptive gradients (growing active set)
4. Multi-length exploration and resampling
5. Intensive final polishing with alternating LP/subgradient
"""

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import lil_matrix, csr_matrix
import time


def fast_conv(a):
    """Full self-convolution via FFT."""
    n = len(a)
    s = 1
    while s < 2 * n - 1:
        s <<= 1
    fa = np.fft.rfft(a, s)
    return np.fft.irfft(fa * fa, s)[:2 * n - 1]


def compute_J(a):
    """Compute J(a) = 2*n*max(conv(a,a))/(sum(a))^2."""
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))


def compute_b_and_J(a):
    """Compute convolution and J simultaneously."""
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return None, float('inf')
    b = fast_conv(a)
    J = float(2 * len(a) * b.max() / (s * s))
    return b, J


def subgradient_conv(a, active_frac=0.02, top_k=None):
    """
    Compute subgradient of max(conv(a,a)) w.r.t. a using FFT.
    Returns (subgradient_vector, max_b, n_active).
    """
    n = len(a)
    b = fast_conv(a)
    max_b = b.max()
    
    if top_k is not None and top_k < 2 * n - 1:
        active = np.argsort(b)[::-1][:top_k]
    else:
        threshold = max_b * (1.0 - active_frac)
        active = np.where(b >= threshold)[0]
    
    if len(active) == 0:
        active = np.array([int(np.argmax(b))])
    
    e_A = np.zeros(2 * n - 1)
    e_A[active] = 1.0
    
    # FFT size for convolving a (len n) with e_A (len 2n-1): need >= 3n-2
    S = 1
    while S < 3 * n - 2:
        S <<= 1
    
    fa = np.fft.rfft(a, S)
    fa_rev = np.fft.rfft(a[::-1], S)
    fe = np.fft.rfft(e_A, S)
    
    # (a * e_A)[m] for m = 0..n-1
    conv_result = np.fft.irfft(fa * fe, S)[:n]
    
    # (a ⊛ e_A)[m] = (a_rev * e_A)[n-1+m] for m = 0..n-1
    corr_full = np.fft.irfft(fa_rev * fe, S)
    corr_result = corr_full[n - 1:n - 1 + n]
    
    sg = (conv_result + corr_result) / len(active)
    return sg, max_b, len(active)


def build_A_sparse(a):
    """Build sparse constraint matrix for LP."""
    n = len(a)
    A = lil_matrix((2 * n - 1, n))
    for k in range(2 * n - 1):
        jl = max(0, k - n + 1)
        jh = min(n - 1, k)
        for j in range(jl, jh + 1):
            A[k, j] = a[k - j]
    return A.tocsr()


def lp_best_response(a, M):
    """LP: max sum(g) s.t. (a*g)_k <= M for all k, g >= 0."""
    n = len(a)
    c = -np.ones(n)
    A = build_A_sparse(a)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                options={'presolve': True, 'time_limit': 30})
    if r.success and r.x is not None:
        g = np.maximum(r.x, 0.0)
        if g.sum() > 1e-10:
            return g
    return None


def resample_seq(src, dest_n):
    """Resample 1D sequence to new length via linear interpolation."""
    src = np.asarray(src, dtype=np.float64)
    if src.size == dest_n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size, endpoint=False)
    t_new = np.linspace(0, 1, dest_n, endpoint=False)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)


def normalize(a):
    """Normalize to sum=1, non-negative."""
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        return a
    return a / s


class Tracker:
    def __init__(self):
        self.best = None
        self.best_score = float('inf')
        self.t_start = time.monotonic()
        self.eval_count = 0
    
    def update(self, a):
        if a is None:
            return
        a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
        if a.size == 0 or a.sum() < 0.01:
            return
        self.eval_count += 1
        score = float(evaluate_sequence(a.tolist()))
        if np.isfinite(score) and score < self.best_score:
            self.best = a.copy()
            self.best_score = score
            elapsed = time.monotonic() - self.t_start
            print(f"  *** NEW BEST: J={score:.8f} n={a.size} t={elapsed:.0f}s ***", flush=True)
    
    def report(self, label=""):
        if self.best is not None:
            print(f"  {label} Current best: J={self.best_score:.8f} n={self.best.size}", flush=True)


def run_subgradient_nesterov(a0, max_iters, deadline, tracker, eta_init=0.05, momentum=0.9):
    """
    Subgradient descent with Nesterov momentum and adaptive active set.
    Starts with small active set (sharp gradient), grows it over time.
    """
    a = normalize(a0.copy())
    current_J = compute_J(a)
    best_a = a.copy()
    best_J = current_J
    tracker.update(a)
    
    # Nesterov momentum
    y = a.copy()
    t_curr = 0
    
    for t in range(max_iters):
        if time.monotonic() > deadline:
            break
        t_curr = t + 1
        
        # Adaptive active set: start small, grow over time
        progress = min(1.0, t / (max_iters * 0.5))
        active_frac = 0.005 + 0.05 * progress  # 0.5% to 5.5%
        top_k = int(len(a) * (0.02 + 0.1 * progress))  # 2% to 12% of n
        
        sg, max_b, n_act = subgradient_conv(y, active_frac=active_frac, top_k=top_k)
        
        # Nesterov step size
        eta = 2.0 * eta_init / (np.sqrt(t_curr) + 1.0)
        
        # Gradient step
        a_new = y - eta * sg
        a_new = np.maximum(a_new, 0.0)
        s_new = a_new.sum()
        if s_new < 1e-10:
            a_new = a  # fallback
            s_new = 1.0
        a_new = a_new / s_new
        
        # Nesterov extrapolation
        # beta_t = (1 + sqrt(1 + 4*t^2)) / 2
        beta_t = 2.0 / (1.0 + np.sqrt(1.0 + 4.0 * t_curr * t_curr))
        y_new = a_new + beta_t * (a_new - a)
        y_new = np.maximum(y_new, 0.0)
        y_new = normalize(y_new)
        
        a = a_new
        y = y_new
        
        # Evaluate every few steps
        if t % 50 == 0 or t == max_iters - 1:
            J_new = compute_J(a)
            if J_new < best_J:
                best_J = J_new
                best_a = a.copy()
                tracker.update(a)
    
    # Final evaluation
    J_final = compute_J(a)
    if J_final < best_J:
        best_J = J_final
        best_a = a.copy()
    tracker.update(best_a)
    
    return best_a


def run_lp_mirror_descent(a0, max_iters, deadline, tracker):
    """
    LP mirror descent with adaptive step size and occasional subgradient mixing.
    """
    a = normalize(a0.copy())
    current_J = compute_J(a)
    best_a = a.copy()
    best_J = current_J
    tracker.update(a)
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        M = float(b.max())
        
        # Solve LP
        g = lp_best_response(a, M)
        if g is None:
            break
        
        g = np.maximum(g, 0.0)
        g_sum = g.sum()
        if g_sum < 1e-10:
            break
        g = g / g_sum
        
        # Line search over step sizes
        base_t = 1.0 / np.sqrt(it + 2)
        if it < 10:
            base_t = max(base_t, 0.3)
        elif it < 50:
            base_t = max(base_t, 0.15)
        else:
            base_t = max(base_t, 0.05)
        
        candidates_t = [base_t, min(1.0, base_t * 2.0), max(0.01, base_t * 0.5),
                        max(0.01, base_t * 0.25)]
        candidates_t = sorted(set(round(t, 6) for t in candidates_t if 0 < t <= 1.0),
                              reverse=True)
        
        improved = False
        for t_val in candidates_t:
            a_trial = (1.0 - t_val) * a + t_val * g
            a_trial = np.maximum(a_trial, 0.0)
            s_trial = a_trial.sum()
            if s_trial < 1e-10:
                continue
            a_trial = a_trial / s_trial
            J_trial = compute_J(a_trial)
            if J_trial < best_J - 1e-14:
                best_J = J_trial
                best_a = a_trial.copy()
                a = a_trial
                improved = True
                break
            elif J_trial < current_J - 1e-14:
                # Accept even if not new best
                a = a_trial
                current_J = J_trial
                improved = True
                break
        
        if not improved:
            # Try subgradient step as fallback
            sg, _, _ = subgradient_conv(a, active_frac=0.02)
            eta = 0.01
            a_trial = a - eta * sg
            a_trial = np.maximum(a_trial, 0.0)
            s_trial = a_trial.sum()
            if s_trial > 1e-10:
                a_trial = a_trial / s_trial
                J_trial = compute_J(a_trial)
                if J_trial < current_J:
                    a = a_trial
                    current_J = J_trial
                else:
                    # Convergence detected
                    break
            else:
                break
        
        if improved and it % 20 == 0:
            tracker.update(a)
            current_J = best_J if True else compute_J(a)
    
    tracker.update(best_a)
    tracker.update(a)
    return best_a


def run_alternating(a0, max_iters, deadline, tracker, lp_every=20):
    """
    Alternate between subgradient steps and LP steps.
    Subgradient for fast progress, LP for refinement.
    """
    a = normalize(a0.copy())
    current_J = compute_J(a)
    best_a = a.copy()
    best_J = current_J
    tracker.update(a)
    
    y = a.copy()
    
    for t in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        if (t + 1) % lp_every == 0:
            # LP step
            b = fast_conv(a)
            M = float(b.max())
            g = lp_best_response(a, M)
            if g is not None and g.sum() > 1e-10:
                g = g / g.sum()
                # Mix
                mix = 0.3 + 0.2 * min(1.0, t / max_iters)
                a_trial = (1 - mix) * a + mix * g
                a_trial = np.maximum(a_trial, 0.0)
                s = a_trial.sum()
                if s > 1e-10:
                    a_trial = a_trial / s
                    J_trial = compute_J(a_trial)
                    if J_trial < current_J:
                        a = a_trial
                        current_J = J_trial
                    if J_trial < best_J:
                        best_J = J_trial
                        best_a = a.copy()
                        tracker.update(a)
            y = a.copy()
        else:
            # Subgradient step
            progress = min(1.0, t / max_iters)
            active_frac = 0.005 + 0.03 * progress
            sg, max_b, _ = subgradient_conv(a, active_frac=active_frac)
            
            eta = 2.0 * 0.03 / (np.sqrt(t + 1) + 1.0)
            a_new = y - eta * sg
            a_new = np.maximum(a_new, 0.0)
            s_new = a_new.sum()
            if s_new < 1e-10:
                break
            a_new = a_new / s_new
            
            # Nesterov extrapolation
            beta_t = 2.0 / (1.0 + np.sqrt(1.0 + 4.0 * (t + 1) * (t + 1)))
            y = a_new + beta_t * (a_new - a)
            y = np.maximum(y, 0.0)
            y = normalize(y)
            
            a = a_new
            
            if t % 100 == 0:
                J_now = compute_J(a)
                if J_now < current_J:
                    current_J = J_now
                if J_now < best_J:
                    best_J = J_now
                    best_a = a.copy()
                    tracker.update(a)
    
    J_final = compute_J(a)
    if J_final < best_J:
        best_J = J_final
        best_a = a.copy()
    tracker.update(best_a)
    tracker.update(a)
    return best_a


def generate_inits(n, rng, parent=None):
    """Generate diverse initial sequences."""
    inits = []
    
    if parent is not None:
        inits.append(resample_seq(parent, n))
        # Perturbed parent
        p = resample_seq(parent, n)
        p += rng.normal(0, 0.05, n)
        inits.append(np.maximum(p, 0.01))
        p += rng.normal(0, 0.1, n)
        inits.append(np.maximum(p, 0.01))
    
    # Uniform
    inits.append(np.ones(n))
    
    # Random
    inits.append(rng.uniform(0.2, 1.0, n))
    
    t = np.linspace(0, 1, n, endpoint=False)
    
    # Cosine patterns
    for f in [1, 2, 3, 5]:
        inits.append(np.maximum(1.0 + 0.3 * np.cos(2 * np.pi * f * t), 0.05))
    
    # Gaussian bump
    inits.append(np.maximum(np.exp(-5 * (t - 0.5) ** 2) + 0.1, 0.05))
    
    # Two bumps
    inits.append(np.maximum(np.exp(-8 * (t - 0.3) ** 2) + np.exp(-8 * (t - 0.7) ** 2) + 0.05, 0.05))
    
    # Triangle
    inits.append(np.maximum(1.0 - 2 * np.abs(t - 0.5), 0.05))
    
    # Sine
    inits.append(np.maximum(0.5 + 0.4 * np.sin(2 * np.pi * t), 0.05))
    
    # Zipper pattern
    zip_pat = np.zeros(n)
    zip_pat[::2] = 1.0
    # Smooth it
    kernel = np.array([0.25, 0.5, 0.25])
    inits.append(np.maximum(np.convolve(zip_pat, kernel, mode='same') + 0.1, 0.05))
    
    return inits
```

Let me implement the log-sum-exp approach:

The gradient of (1/tau) * log(sum_k exp(tau * b_k)) with respect to a[i]:
= (1/tau) * sum_k (tau * exp(tau*b_k) / sum_l exp(tau*b_l)) * db_k/da[i]
= sum_k p_k * db_k/da[i]
where p_k = exp(tau*b_k) / sum_l exp(tau*b_l) (softmax of b)

And db_k/da[i] = a[k-i] + a[i-k] (for valid indices, with the 2i special case).

This is very similar to the subgradient, but with a "soft" active set (all lags get weight proportional to their softmax probability) instead of a hard active set.

For large tau, this approaches the max (and the softmax concentrates on the argmax).
For small tau, it's a smooth approximation.

Let me now think about the overall algorithm:

**Algorithm: Smoothed Gradient Descent with Adaptive Temperature**

1. Start with initial a (normalized, sum=1)
2. Set tau = tau_0 (initial temperature, e.g., tau = n)
3. For each iteration:
   a. Compute gradient using log-sum-exp with current tau
   b. Take a gradient step with momentum
   c. Periodically increase tau (making the objective sharper)
   d. Track the best solution

The step size for gradient descent on the smooth objective:
- The function is L-smooth with L = O(tau * n) (roughly)
- Optimal step size: 1/L = O(1/(tau*n))
- With momentum, we can be more aggressive

Let me estimate L more carefully. The Hessian of (1/tau)*log(sum exp(tau*b_k)) is:
H = (1/tau) * sum_k tau² * p_k * (db_k/dx)(db_k/dx)^T - (1/tau) * (sum_k tau * p_k * db_k/dx)(sum_l tau * p_l * (db_l/dx))^T

This is bounded by (tau/n) * sum_k ||db_k/dx||² ≈ (tau/n) * n * 4*||a||² = 4*tau*||a||² ≈ 4*tau (for ||a||=1 in l2, which for sum=1 means ||a||_2 <= 1).

Actually, ||db_k/dx||_2 = 2*||a||_2 (as computed before, since it's 2*a shifted). So ||db_k/dx||_2² = 4*||a||_2².

Sum over k: sum_k p_k * ||db_k/dx||_2² ≈ 4*||a||_2² (since sum p_k = 1).

So L ≈ tau * 4 * ||a||_2². For sum(a)=1 and a>=0, ||a||_2 <= 1, so L <= 4*tau.

Optimal step size: eta = 1/(4*tau). For tau=512, eta ≈ 1/2048 ≈ 0.0005. That's quite small.
