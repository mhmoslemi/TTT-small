This dual has 2n-1 variables and n constraints. For n=512, that's 1023 variables and 512 constraints. The primal has 512 variables and 1023 constraints. They're similar in size.

Actually, for HiGHS, either should be fast. Let me stick with the primal.

Now, let me think about a key improvement: **using the Lagrangian dual** instead of the LP.

The Lagrangian of the best response problem:
L(g, y) = sum_j g_j - sum_k y_k * (sum_j A[k,j] g_j - M)
= sum_j g_j * (1 - sum_k A[k,j] y_k) + M * sum_k y_k

The dual function: g*(y) = 0 if sum_k A[k,j] y_k >= 1 for all j, else infinity.
Dual: min M * sum_k y_k s.t. (A^T y)_j >= 1 for all j, y >= 0.

This is the same as the LP dual. So solving the LP directly is fine.

Let me think about another approach: **multiplicative weights update (MWU)**.

The MWU for this problem would be:
g_j = exp(-eta * (A^T y)_j) or something similar.

Actually, the standard MWU / exponentiated gradient for the problem:
min_{a >= 0, sum a = 1} max_k (a*a)_k

Can be written as a saddle point:
min_a max_{y in simplex} sum_k y_k * (a*a)_k - lambda*(sum a - 1)

The exponentiated gradient method would be:

where grad_j = sum_k y_k * d(a*a)_k / da_j

This is similar to what the LP mirror descent does, but the LP gives the optimal y for the current a.

This is more natural for the simplex constraint and might converge faster.

Actually, let me reconsider. The LP mirror descent with the Euclidean distance gives the LP best response. The LP mirror descent with the entropy distance (KL divergence) gives the multiplicative weights update.

The entropy version:

The solution is: g_j = a_j * exp(-eta * (A^T y)_j) / Z

Actually, I realize there's a subtlety. The autocorrelation r_k = sum_j a_j * a_{j+k} is related to the power spectrum via Wiener-Khinchin: P(k) = FFT(r). But the convolution (a*a)_k is different from the autocorrelation.

The convolution (a*a)_k = sum_j a_j * a_{k-j}. If we define the "reversed" sequence a_rev_j = a_{n-1-j}, then (a*a)_k = (a * a_rev)_k shifted... hmm, this is getting complicated.

Actually, (a*a)_k = sum_j a_j * a_{k-j}. Let me define b_j = a_{n-1-j} (reverse of a). Then:
(a*a)_{n-1+k} = sum_j a_j * a_{n-1+k-j} = sum_j a_j * b_{j-1-k+1} = sum_j a_j * b_{k-j}

So (a*a)_{n-1+k} = (a * b)_k where b is the reverse of a. This is the cross-correlation of a and b, which is the same as the autocorrelation if a is symmetric.

Anyway, the point is that the convolution peak structure depends on both the "autocorrelation-like" terms and the "cross-correlation" terms.

import numpy as np
from scipy.optimize import linprog, minimize
from scipy.sparse import lil_matrix
import time


def fast_conv(a):
    n = len(a)
    s = 1
    while s < 2 * n - 1:
        s <<= 1
    fa = np.fft.rfft(a, s)
    return np.fft.irfft(fa * fa, s)[:2 * n - 1]


def compute_J(a):
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))


def build_A_sparse(a):
    n = len(a)
    A = lil_matrix((2 * n - 1, n))
    for k in range(2 * n - 1):
        jl = max(0, k - n + 1)
        jh = min(n - 1, k)
        for j in range(jl, jh + 1):
            A[k, j] = a[k - j]
    return A.tocsr()


def lp_best_response(a, M):
    n = len(a)
    c = -np.ones(n)
    A = build_A_sparse(a)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                options={'presolve': True, 'time_limit': 5})
    if r.success and r.x is not None:
        g = np.maximum(r.x, 0.0)
        if g.sum() > 1e-10:
            return g
    return None


def gps_flatten(a, n_iters=200, target=None):
    """GPS algorithm to flatten the power spectrum."""
    n = len(a)
    a = np.maximum(a.astype(np.float64), 0)
    s = a.sum()
    if s < 1e-10:
        return np.ones(n) / n
    a = a / s
    
    if target is None:
        target = np.ones(n) / n  # Flat target (in time domain, corresponds to delta in freq)
    
    s_fft = 1
    while s_fft < 2 * n - 1:
        s_fft <<= 1
    
    for _ in range(n_iters):
        fa = np.fft.rfft(a, s_fft)
        # Compute power spectrum
        power = np.abs(fa) ** 2
        # Target: flat power spectrum
        target_power = np.ones_like(power) * (power.sum() / len(power))
        # Update amplitude, keep phase
        phase = np.angle(fa)
        new_amp = np.sqrt(target_power)
        fa_new = new_amp * np.exp(1j * phase)
        a_new = np.fft.irfft(fa_new, s_fft)[:n]
        a_new = np.maximum(a_new, 0)
        s_new = a_new.sum()
        if s_new < 1e-10:
            break
        a = a_new / s_new
    
    return a


def subgradient_descent(a, max_iters, deadline, tracker, eta_init=0.05, n_active_frac=0.25):

    n = len(a)
    a = np.maximum(a.astype(np.float64), 0.001)
    a /= a.sum()

    best_a = a.copy()
    best_J = current_J
    tracker.update(a)

        s_fft <<= 1

            break
        
        b = fast_conv(a)

        # We want: sum_k e_A[k] * a[k-m] (for k-m in [0,n))

        # = (a_reversed * e_A)[n-1+m] roughly

        # where corr(x, y, l) = sum_m x[m+l] * y[m]
        
        # corr(e_A, a, j) = sum_m e_A[m+j] * a[m]
        # This can be computed as: if we zero-pad a to length s_fft, then

def lp_mirror_descent(a, max_iters, deadline, tracker, use_momentum=False):
    """LP mirror descent with adaptive step sizes."""
    n = len(a)
    a = np.maximum(a.astype(np.float64), 0.001)
    a /= a.sum()
    current_J = compute_J(a)
    tracker.update(a)
    
    momentum_vec = np.zeros(n) if use_momentum else None
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        M = float(b.max())
        g = lp_best_response(a, M)
        if g is None:
            break
        
        g = np.maximum(g, 0.0)
        g_sum = g.sum()
        if g_sum < 1e-10:
            break
        g /= g_sum
        
        # Adaptive step size
        base_t = 2.0 / (it + 3)
        
        # Try multiple step sizes (backtracking-like)
        candidates_t = [base_t, min(1.0, base_t * 1.5), max(0.01, base_t * 0.75),
                        max(0.01, base_t * 0.5), 1.0 / (it + 1)]
        candidates_t = sorted(set(round(t, 6) for t in candidates_t if 0 < t <= 1.0), reverse=True)
        
        best_a = None
        best_J = current_J
        
        for t in candidates_t:
            if use_momentum:
                momentum_vec = 0.9 * momentum_vec + t * (g - a)
                a_trial = a + momentum_vec
            else:
                a_trial = (1.0 - t) * a + t * g
            a_trial = np.maximum(a_trial, 0.0)
            s = a_trial.sum()
            if s < 1e-10:
                continue
            a_trial /= s
            J_trial = compute_J(a_trial)
            if J_trial < best_J - 1e-15:
                best_J = J_trial
                best_a = a_trial.copy()
        
        if best_a is None:
            # Try very small step
            t_small = 0.02
            a_trial = (1.0 - t_small) * a + t_small * g
            a_trial = np.maximum(a_trial, 0.0)
            s = a_trial.sum()
            if s < 1e-10:
                break
            a_trial /= s
            J_trial = compute_J(a_trial)
            if J_trial < current_J - 1e-15:
                a = a_trial
                current_J = J_trial
            else:
                # Stuck, try a perturbation
                a_pert = a + 0.01 * np.random.randn(n)
                a_pert = np.maximum(a_pert, 0.001)
                a_pert /= a_pert.sum()
                a = a_pert
                current_J = compute_J(a)
                if current_J > best_J * 1.01:
                    break
        else:
            a = best_a
            current_J = best_J
        
        if it % 10 == 0:
            tracker.update(a)
    
    tracker.update(a)
    return a


def generate_asymmetric_inits(n, rng):
    """Generate asymmetric initial sequences."""
    inits = []
    t = np.linspace(0, 1, n, endpoint=False)
    
    # Linear ramp
    inits.append(np.maximum(t + 0.1, 0.01))
    inits.append(np.maximum(1 - t + 0.1, 0.01))
    
    # Exponential ramp
    inits.append(np.maximum(np.exp(3 * t - 1.5) + 0.05, 0.01))
    inits.append(np.maximum(np.exp(-3 * t + 1.5) + 0.05, 0.01))
    
    # Two-sided with different rates
    inits.append(np.maximum(np.exp(-4 * t) * 3 + 0.1, 0.01))
    inits.append(np.maximum(np.exp(-4 * (1 - t)) * 3 + 0.1, 0.01))
    
    # Asymmetric oscillation
    inits.append(np.maximum(0.5 + 0.4 * np.sin(2 * np.pi * t) * (1 - t) + 0.1, 0.01))
    inits.append(np.maximum(0.5 + 0.4 * np.sin(2 * np.pi * t) * t + 0.1, 0.01))
    
    # Block patterns (asymmetric)
    for frac in [0.3, 0.4, 0.6, 0.7]:
        block = np.zeros(n)
        block[:int(frac * n)] = 1.0
        inits.append(block + 0.05)
        block2 = np.zeros(n)
        block2[int((1-frac) * n):] = 1.0
        inits.append(block2 + 0.05)
    
    # Random asymmetric
    for _ in range(5):
        a = rng.uniform(0, 1, n)
        a = a + 0.5 * np.linspace(0, 1, n)  # Add asymmetric trend
        inits.append(np.maximum(a, 0.01))
    
    return inits


def resample_seq(src, dest_n):
    src = np.asarray(src, dtype=np.float64)
    if src.size == dest_n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, dest_n)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)


class ScoreTracker:
    def __init__(self):
        self.best = None
        self.best_score = float('inf')
        self.t_start = time.monotonic()
    
    def update(self, a):
        if a is None:
            return
        a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
        if a.size == 0 or a.sum() < 0.01:
            return
        try:
            score = float(evaluate_sequence(a.tolist()))
        except Exception:
            return
        if np.isfinite(score) and score < self.best_score:
            self.best = a.copy()
            self.best_score = score
            elapsed = time.monotonic() - self.t_start
            print(f"  * NEW BEST: J={score:.8f} n={a.size} t={elapsed:.0f}s", flush=True)
    
    def report(self, label=""):
        if self.best is not None:
            print(f"  {label} best: J={self.best_score:.8f} n={self.best.size}", flush=True)
