For an m-sequence of length p = 2^m - 1:
Periodic autocorrelation: R[0] = p, R[k] = -1 for k != 0 (mod p).

If we map to [1, c]:
The periodic autocorrelation of the mapped sequence:
R'[k] = sum_{i=0}^{p-1} s[i]*s[(i+k) mod p] where s[i] = 1 if m-seq[i] = +1, c if -1.

= p + (1-c)*0 + (1-c)*0 + (1-c)^2 * (-1)  [for k != 0]
= p - (1-c)^2

R'[0] = sum (1 + (1-c)*m[i])^2 = sum [1 + 2(1-c)m[i] + (1-c)^2 m[i]^2]

R'[k] = p - (1-c)^2 for k != 0

The ratio R'[0]/R'[k] = p(1+(1-c)^2) / (p-(1-c)^2)
