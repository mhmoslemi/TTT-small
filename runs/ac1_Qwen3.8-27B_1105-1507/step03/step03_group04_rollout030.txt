So if k = n-1 (the center): (∇_a conv(a,a)_{n-1})[j] = 2*a[n-1-j] = 2 * a_reversed[j].

The subgradient of f(a) = max_k conv(a,a)_k at a is in the convex hull of {2 * shift_k(a) : k in argmax}, where shift_k(a)[j] = a[k-j] (with zero-padding).

For projected subgradient descent on J(a) = 2n * max_k conv(a,a)_k / (sum a)^2:
- Fix sum(a) = 1 (by normalizing after each step)
- Take a step in the direction -∇f(a) (the subgradient direction)
- Project onto {a >= 0, sum(a) = 1}

The projection onto {a >= 0, sum(a) = 1} is: given v, find the largest λ such that max(v - λ, 0) has sum 1. This is a "water-filling" problem.

This gives us a new algorithm: **Projected Subgradient Descent with Normalization**

Algorithm:
1. Initialize a (non-uniform, e.g., a slight perturbation of uniform)
2. For each iteration:
   a. Compute b = conv(a, a), find k* = argmax b
   b. Compute gradient: grad[j] = 2*a[k*-j] (with zero-padding)
   c. Take step: v = a - η * grad
   d. Project: find λ such that max(v - λ, 0) has sum 1
   e. Set a = max(v - λ, 0)
3. Periodically evaluate J and track the best

The step size η is crucial. We can use:
- Fixed step: η = c / sqrt(t) (standard subgradient rate)
- Adaptive step: η = (J(a) - J_target) / ||grad||^2 (heuristic)
- Line search: try several η values and pick the best

This is simpler and potentially faster than the LP approach, and it doesn't have the "uniform fixed point" problem (because the subgradient at the uniform point is 2*uniform (since k* = n-1 and a_reversed = a for uniform), so the step would be a - η*2*a = (1-2η)*a, which is still uniform after normalization!).

Hmm, so the uniform point IS a fixed point of projected subgradient descent too. We need to break the symmetry.

**Key insight**: The uniform sequence is a local minimum of J (in the space of symmetric sequences) but NOT a global minimum. The global minimum is achieved by an asymmetric sequence. So we need to:
1. Start from an asymmetric initialization
2. Use the subgradient/LP to converge to a local minimum
3. Use restarts to explore different basins

The question is: how do we find a good asymmetric initialization?

**Structural insight**: For the optimal sequence, the convolution should be as flat as possible. The "obstruction" to flatness is:
- The boundary terms: conv[0] = a[0]^2, conv[2n-2] = a[n-1]^2
- The "overlap" terms in the middle

If we think of the sequence as having a "support" (the region where it's significantly non-zero), the convolution's support is 2*support - 1. To make the convolution flat, we want the support to be as large as possible (spread out).

But the boundary constraint (a[0]^2 must be small) forces the sequence to taper at the edges.

So the optimal sequence is approximately:
- A "flat top" in the interior
- A smooth taper at the edges
- The taper length should be about O(sqrt(n)) (to match the boundary constraint)

This is like a "truncated Gaussian" or a "truncated cosine" shape.

Let me formalize this. Suppose a[i] = c for i = m, ..., n-1-m, and tapers linearly to 0 over m steps at each end:
a[i] = c * (i/m) for i = 0, ..., m
a[i] = c for i = m, ..., n-1-m
a[i] = c * ((n-1-i)/m) for i = n-1-m, ..., n-1

The sum is approximately c*(n - m) (for large n).
The convolution at the center (k = n-1) is approximately c^2 * (n - m) (the "flat" part).
The sum^2 is c^2 * (n-m)^2.
J ≈ 2n * c^2 * (n-m) / (c^2 * (n-m)^2) = 2n / (n-m) = 2 * n/(n-m) = 2 / (1 - m/n)

For this to be < 2, we need m > 0, which it is. But the improvement is only O(m/n), which is small.

For n = 512 and m = 10: J ≈ 2 * 512/502 ≈ 2.04. Not much improvement.

So a simple trapezoid doesn't help much. We need a more sophisticated shape.

Let me think about what shape makes the convolution truly flat.

The convolution of a sequence with itself is the "autocorrelation" (with a sign flip in the index). For the convolution to be flat, we need:
sum_i a[i] * a[k-i] ≈ constant for all k.

This is like a "flat spectrum" condition in the frequency domain. Specifically, if A(ω) = FFT(a), then conv(a,a) has FFT = A(ω)^2 (not |A(ω)|^2, but A(ω)^2).

For the convolution to be flat (all values equal), we need A(ω)^2 = constant, i.e., |A(ω)| = constant and A(ω) has constant phase. But A(ω) is the DFT of a real, non-negative sequence, so it has specific constraints.

For a real sequence, A(ω) = |A(ω)| * e^{iφ(ω)}, and A(-ω) = conj(A(ω)).
A(ω)^2 = |A(ω)|^2 * e^{2iφ(ω)}.

For A(ω)^2 to be real and constant, we need:
1. |A(ω)| = constant (flat magnitude spectrum)
2. φ(ω) = 0 or π/2 (constant phase)

Condition 1 means a is a "flat spectrum" sequence, like a chirp or a Zadoff-Chu sequence (but those are complex). For real non-negative sequences, perfectly flat spectrum is not achievable.

Condition 2 means the sequence has a specific phase structure.

So the optimal real non-negative sequence is one that approximately satisfies these conditions. This is related to the theory of " οποιο flat-top" window functions in signal processing!

In signal processing, the "flat-top" window is designed to have a very flat main lobe in the frequency domain. Its time-domain shape is a sum of cosines:
w(n) = 1 - 0.41*cos(2πn/N) + 0.28*cos(4πn/N) - 0.08*cos(6πn/N) + 0.01*cos(8πn/N)

This is always positive (it's a window function). Its frequency response has a very flat top and rapid rolloff.

But we want the TIME-DOMAIN convolution to be flat, not the frequency-domain response. This is a different problem.

Actually, let me reconsider. The convolution in the time domain corresponds to multiplication in the frequency domain. So:
FFT(conv(a,a)) = A(ω)^2 (element-wise square, not conjugate)

For conv(a,a) to be flat (all equal to 1/(2n-1)), we need A(ω)^2 = 1/(2n-1) * (1, 1, ..., 1) (DC only... no, that's not right).

If conv(a,a) = c * (1, 1, ..., 1) (all ones, length 2n-1), then:
FFT(conv(a,a)) = c * (2n-1, 0, 0, ..., 0) (only DC component)
So A(ω)^2 = c * (2n-1, 0, 0, ..., 0)
This means A(ω) = 0 for all non-DC frequencies, which means a is a constant (DC only). But a constant of length n has conv(a,a) = a triangle, not flat.

So a perfectly flat convolution is impossible (as we already knew). The best we can do is approximate flatness.

            g = np.maximum(r.x, 0.0)
            if g.sum() > 1e-10:

    except Exception:
        pass
    return None


def bisect_step(a, g, J_cur, lo=0.0, hi=1.0, tol=0.005, max_iter=12):
    a = a / a.sum()
    g = g / g.sum()

    def J_at(t):
        at = a + t * (g - a)
        at = np.maximum(at, 0.0)
        s = at.sum()
        if s < 1e-10:
            return float('inf')
        return compute_J(at / s)

    best_t = 0.0
    best_J = J_cur

    for _ in range(max_iter):
        if hi - lo < tol:
            break
        mid1 = lo + (hi - lo) / 3.0
        mid2 = hi - (hi - lo) / 3.0
        J1 = J_at(mid1)
        J2 = J_at(mid2)
        if J1 < best_J:
            best_J = J1
            best_t = mid1
        if J2 < best_J:
            best_J = J2
            best_t = mid2
        if J1 < J2:
            hi = mid2
        else:
            lo = mid1

    J_end = J_at(hi)
    if J_end < best_J:
        best_J = J_end
        best_t = hi
    return best_t, best_J


def lp_round(a, M, rng):

def project_simplex(v, target=1.0):
    v = np.asarray(v, dtype=np.float64)
    n = len(v)
    if n == 0:
        return v
    mu = np.sort(v)[::-1]
    cv = np.cumsum(mu)
    rho = np.arange(1, n + 1)
    cond = mu - (cv - target) / rho > 0
    if not np.any(cond):
        return np.full(n, target / n)
    romax = int(np.max(rho[cond]))
    theta = (cv[romax - 1] - target) / romax
    w = np.maximum(v - theta, 0.0)
    s = w.sum()
    if s < 1e-15:
        return np.full(n, target / n)
    return w / s

        if self.best is not None:
            print(f"  {label} best: J={self.best_score:.8f} n={self.best.size}", flush=True)


def gen_initials(n, rng, parent):
    inits = []
    t = np.linspace(0, 1, n, endpoint=False)

    if parent is not None:
        p = resample_seq(parent, n)
        inits.append(p)
        inits.append(np.maximum(p + rng.normal(0, 0.08, n) * p, 0.01))
        inits.append(np.maximum(p + rng.normal(0, 0.03, n) * p, 0.01))

    inits.append(np.ones(n))
    inits.append(1.0 + 0.4 * np.cos(2 * np.pi * t))
    inits.append(1.0 + 0.3 * np.cos(4 * np.pi * t))
    inits.append(1.0 - 0.35 * np.cos(2 * np.pi * t))
    inits.append(1.0 + 0.3 * np.cos(2 * np.pi * t) + 0.15 * np.cos(4 * np.pi * t))
    inits.append(np.exp(-3.0 * (2 * t - 1) ** 2) + 0.05)
    inits.append(0.5 + 0.5 * t)
    inits.append(0.5 * (1 + np.sin(np.pi * t)))
    inits.append(np.abs(np.sin(np.pi * t)) + 0.1)

    # Strongly asymmetric ramp
    inits.append(0.3 + 0.7 * t)
    inits.append(0.3 + 0.7 * (1 - t))

    # Two-tone
    inits.append(1.0 + 0.3 * np.cos(6 * np.pi * t))
    inits.append(1.0 + 0.2 * np.cos(8 * np.pi * t))

    for init in inits:
        init = np.maximum(np.asarray(init, dtype=np.float64), 0.01)
        inits[-1] = init / init.sum()
    return inits


def propose_candidate(seed=42, budget_s=1500, **kwargs):
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + float(budget_s) - 20.0
    tracker = ScoreTracker()

    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        if p.ndim == 1 and p.size > 10 and np.all(np.isfinite(p)):
            parent = np.maximum(p, 0.0)
            tracker.update(parent)
            print(f"Parent loaded: n={parent.size}, J={tracker.best_score:.8f}", flush=True)
    except (NameError, AttributeError):
        pass

    if parent is None:
        parent = np.ones(256)

    # Phase 1: Explore multiple lengths from parent and standard inits
    print(f"\n{'='*50} Phase 1: Multi-length exploration {'='*50}", flush=True)
    t1 = time.monotonic()

    lengths_explore = [parent.size, 256, 384, 512, 640, 768]
    for n in lengths_explore:
        if time.monotonic() > deadline:
            break
        if n < 64:
            continue
        te = time.monotonic()
        print(f"  Exploring n={n}...", flush=True)
        inits = gen_initials(n, rng, parent)
        # Do a quick LP refinement on a few inits
        max_iters = max(50, int(min(200, 60.0 * (deadline - time.monotonic()) / max(1, budget_s * 0.3))))
        for a0 in inits[:6]:
            if time.monotonic() > deadline:
                break
            a_opt, J_opt = lp_mirror_descent(a0, max_iters, deadline, tracker, rng)

        print(f"    n={n}: {time.monotonic()-te:.1f}s", flush=True)

    tracker.report("Phase 1")

    # Phase 2: Focused refinement on best
    if tracker.best is not None and time.monotonic() < deadline:
        print(f"\n{'='*50} Phase 2: Focused LP refinement n={tracker.best.size} {'='*50}", flush=True)
        t2 = time.monotonic()
        n_best = tracker.best.size

        # Long LP run
        remaining = deadline - time.monotonic()
        max_iters = int(min(2000, max(100, remaining * 2.0)))
        a_opt, J_opt = lp_mirror_descent(tracker.best, max_iters, deadline, tracker, rng)

        # Subgradient polish
        if time.monotonic() < deadline:
            remaining = deadline - time.monotonic()
            max_iters = int(min(5000, max(200, remaining * 3.0)))
            a_opt, J_opt = subgradient_descent(a_opt, max_iters, deadline, tracker)

        # Another LP polish
        if time.monotonic() < deadline:
            a_opt, J_opt = lp_mirror_descent(a_opt, 300, deadline, tracker, rng)

        tracker.report(f"Phase 2: {time.monotonic()-t2:.1f}s")

    # Phase 3: Perturbation restarts
    if tracker.best is not None and time.monotonic() < deadline:
        print(f"\n{'='*50} Phase 3: Perturbation restarts {'='*50}", flush=True)
        t3 = time.monotonic()
        n_best = tracker.best.size

        for trial in range(30):
            if time.monotonic() > deadline:
                break
            a = tracker.best.copy().astype(np.float64)
            ptype = trial % 5

            if ptype == 0:
                a = a + rng.normal(0, 0.06, n_best)
            elif ptype == 1:
                a = a + rng.uniform(-0.1, 0.1, n_best)
            elif ptype == 2:
                k = max(3, n_best // 100)
                idx = rng.choice(n_best, size=k, replace=False)
                a[idx] *= rng.uniform(0.3, 3.0, k)
            elif ptype == 3:
                # Smooth perturbation
                noise = rng.normal(0, 0.08, n_best)
                kern = np.ones(7) / 7.0
                noise = np.convolve(noise, kern, mode='same')
                a = a + noise
            else:
                # Shift/cycle perturbation (breaks periodicity)
                shift = rng.integers(1, max(2, n_best // 16))
                a = np.roll(a, shift)
                # Smooth the discontinuity
                kern = np.ones(5) / 5.0
                a = np.convolve(a, kern, mode='same')

            a = np.maximum(a, 1e-5)
            a = a / a.sum()

            max_iters = max(30, int(min(200, 40.0 * (deadline - time.monotonic()) / max(1, budget_s * 0.25))))
            a_opt, J_opt = lp_mirror_descent(a, max_iters, deadline, tracker, rng)

        tracker.report(f"Phase 3: {time.monotonic()-t3:.1f}s")

    # Phase 4: Combined LP + Subgradient refinement
    if tracker.best is not None and time.monotonic() < deadline:
        print(f"\n{'='*50} Phase 4: Combined refinement n={tracker.best.size} {'='*50}", flush=True)
        t4 = time.monotonic()
        remaining = deadline - time.monotonic()
        max_iters = int(min(3000, max(100, remaining * 1.5)))
        a_opt, J_opt = combined_refine(tracker.best, max_iters, deadline, tracker, rng)
        tracker.report(f"Phase 4: {time.monotonic()-t4:.1f}s")

    # Phase 5: Fine length search around best
    if tracker.best is not None and time.monotonic() < deadline:
        print(f"\n{'='*50} Phase 5: Fine length search {'='*50}", flush=True)
        t5 = time.monotonic()
        n_best = tracker.best.size

        offsets = [-32, -16, -8, 8, 16, 32, 48, 64, -64, -48]
        for off in offsets:
            n_try = n_best + off
            if n_try < 64 or n_try > 4096 or time.monotonic() > deadline:
                continue
            a_res = resample_seq(tracker.best, n_try)
            a_res = a_res / max(a_res.sum(), 1e-10)
            max_iters = max(40, int(min(300, 50.0 * (deadline - time.monotonic()) / max(1, budget_s * 0.15))))
            a_opt, J_opt = lp_mirror_descent(a_res, max_iters, deadline, tracker, rng)
            if time.monotonic() < deadline:
                max_sg = max(100, int(min(2000, 20.0 * (deadline - time.monotonic()) / max(1, budget_s * 0.1))))
                a_opt, J_opt = subgradient_descent(a_opt, max_sg, deadline, tracker)

        tracker.report(f"Phase 5: {time.monotonic()-t5:.1f}s")

    # Phase 6: Final long refinement
    if tracker.best is not None and time.monotonic() < deadline:
        print(f"\n{'='*50} Phase 6: Final polish n={tracker.best.size} {'='*50}", flush=True)
        t6 = time.monotonic()
        remaining = deadline - time.monotonic()
        max_iters = int(min(5000, max(200, remaining * 3.0)))
        a_opt, J_opt = subgradient_descent(tracker.best, max_iters, deadline, tracker)

        if time.monotonic() < deadline:
            a_opt, J_opt = lp_mirror_descent(a_opt, 500, deadline, tracker, rng)

        if time.monotonic() < deadline:
            max_sg2 = int(min(3000, max(100, (deadline - time.monotonic()) * 4.0)))
            a_opt, J_opt = subgradient_descent(a_opt, max_sg2, deadline, tracker)

        tracker.report(f"Phase 6: {time.monotonic()-t6:.1f}s")

    # Fallback
    if tracker.best is None:
        tracker.best = np.ones(128)
        tracker.best_score = compute_J(tracker.best)
        print(f"  Fallback: J={tracker.best_score:.8f}", flush=True)

    print(f"\n{'='*50} FINAL RESULT {'='*50}", flush=True)
    print(f"J={tracker.best_score:.8f} n={tracker.best.size} "
          f"time={time.monotonic()-tracker.t_start:.1f}s", flush=True)

    result = np.clip(tracker.best, 0.0, 1000.0)
    if result.sum() < 0.01:
        result = np.ones(128)

    return [float(x) for x in result]
