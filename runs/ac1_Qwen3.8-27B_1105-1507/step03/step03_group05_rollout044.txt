   For the convolution, the value at lag k involves pairs (i, k-i) that sum to k. So:
   - Lag 0: only (0,0) → a[0]^2
   - Lag 1: (0,1) and (1,0) → a[0]*a[1] + a[1]*a[0] = 2*a[0]*a[1]
   - Lag n-1: all pairs (i, n-1-i) → sum_i a[i]*a[n-1-i]
   - Lag 2n-2: only (n-1, n-1) → a[n-1]^2

   So the convolution is symmetric: conv[k] = conv[2n-2-k]. And the "center" is at lag n-1.

   For a uniform sequence, conv[k] = n-|k-(n-1)| for k in [0, 2n-2], which is a triangle peaking at n-1 with value n. So max = n, sum = n, J = 2n*n/n^2 = 2.
