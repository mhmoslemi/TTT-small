For 0 <= t <= 1: max = 1 (if 1 >= 2t, i.e., t <= 0.5). For 0.5 <= t <= 1: max = 2t.

Case 0 <= t <= 0.5: J = 4/(1+t)^2. Minimized at t=0.5: J = 4/2.25 = 16/9 ≈ 1.78.
