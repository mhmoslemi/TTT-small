minimize max_k sum_i a[i]*a[k-i] / (sum a)^2, subject to a[i] >= 0.

This is a non-convex problem (max of linear functions in the ratio). But we can think about it from a different angle.

Define the "normalized" sequence p[i] = a[i]/sum(a), so sum(p) = 1, p[i] >= 0.
Then J = 2*n*max_k (p*p)[k] (since the sum normalizes out).

Wait: (a*a)[k] = sum_i a[i]*a[k-i] = (sum a)^2 * sum_i p[i]*p[k-i] = (sum a)^2 * (p*p)[k].
So J = 2*n*(sum a)^2*max_k(p*p)[k] / (sum a)^2 = 2*n*max_k(p*p)[k].

So we want to minimize 2*n*max_k(p*p)[k] where p is a probability distribution (non-negative, sums to 1).

This is equivalent to: find a probability distribution p on {0,...,n-1} that minimizes the peak of its self-convolution.

The self-convolution (p*p)[k] = sum_i p[i]*p[k-i] is the probability that X+Y=k where X,Y are independent with distribution p.

So we want to minimize the maximum point probability of the sum of two independent copies of a discrete random variable on {0,...,n-1}.

This is a well-studied problem in probability! The minimum possible peak of the sum distribution is related to the "smallest maximum probability mass function" problem.

By the central limit theorem, if p is spread out, the sum distribution is approximately normal with variance 2*Var(p). The peak of a normal with variance σ^2 is 1/(σ*sqrt(2π)).

For p uniform on {0,...,n-1}: Var(p) = (n^2-1)/12 ≈ n^2/12.
Peak of sum ≈ 1/(sqrt(2*n^2/12 * 2π)) = 1/(n*sqrt(4π/12)) = 1/(n*sqrt(π/3)) ≈ 1/(n*1.023).
J ≈ 2*n/(n*1.023) ≈ 1.954.

But we computed J=2 for uniform. The CLT gives an approximation; the actual peak for uniform is exactly 1/n (at the center), giving J=2.
