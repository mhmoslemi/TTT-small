Let me think about the LP more carefully:
- Primal: max sum(g) s.t. (a*g)_k <= M for all k, g >= 0
- Dual: min M * sum(y_k) s.t. sum_k y_k * a_{k-j} >= 1 for all j, y >= 0

The dual variables y_k tell us which lags are "binding." At optimality, the complementary slackness condition says: y_k > 0 implies (a*g)_k = M.

So the set of lags where y_k > 0 is exactly the set of "active" lags.

Now, for the next iteration, we want to find a new a' such that (a'*g)_k is minimized at the active lags. This is essentially what the LP best response does.
