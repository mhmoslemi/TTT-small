```python
def fast_conv(a):
```

```python
def multiplicative_weights(a, max_iters, deadline, tracker, eps=1e-8):
    """
    Minimize max_k (a*a)[k] using multiplicative weights (exponentiated gradient).
    a is normalized to sum to 1.
    """
    a = np.maximum(a.astype(np.float64), 1e-15)
    a = a / a.sum()
    current_J = compute_J(a)
    tracker.update(a)
    
    eta = 0.1  # Initial step size
    no_improve = 0
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        M = b.max()
        
        # Active set: indices where b[k] is close to M
        active = b >= M * (1 - 1e-6)  # or M - eps
        
        # Compute gradient
        n = len(a)
        grad = np.zeros(n)
        for k in np.where(active)[0]:
            lo = max(0, k - n + 1)
            hi = min(n - 1, k)
            for i in range(lo, hi + 1):
                grad[i] += 2.0 * a[k - i]
        
        # Multiplicative update
        # a_i *= exp(-eta * grad_i)
        # But this can cause underflow, so use log-space
        log_a = np.log(a + 1e-30)
        log_a -= eta * grad

        log_a -= log_a.max()
        a_new = np.exp(log_a)
        a_new = a_new / a_new.sum()
        a_new = np.maximum(a_new, 1e-15)
        a_new = a_new / a_new.sum()
        
        # Check improvement
        J_new = compute_J(a_new)
        if J_new < current_J - 1e-12:
            a = a_new
            current_J = J_new
            no_improve = 0
            if it % 20 == 0:
                tracker.update(a)
        else:
            no_improve += 1
            # Reduce step size
            eta *= 0.7
            if no_improve > 30:
                break
    
    tracker.update(a)
    return a
```

```python
def multiplicative_weights_opt(a, max_iters, deadline, tracker):

    no_improve = 0

        M = float(b.max())

        tol = max(1e-10, 1e-6 * M)
        active = (b >= M - tol).astype(np.float64)

        log_a -= log_a.max()
        a_new = np.exp(log_a)
        a_new = np.maximum(a_new, 1e-15)
        a_new = a_new / a_new.sum()

        if J_new < current_J - 1e-13:
            a = a_new
            current_J = J_new
            no_improve = 0
            if it % 50 == 0:

        else:
            no_improve += 1
            eta *= 0.8
            if no_improve > 50:
                break
    
    tracker.update(a)
```

Let me also think about a "dual" approach that might be complementary:

The problem min_a max_k C[k] s.t. sum(a)=1, a>=0 can be seen as a zero-sum game:
- Player 1 chooses a (mixed strategy over n "actions")
- Player 2 chooses k (pure strategy over 2n-1 "actions")
- Payoff is C[k] = sum_j a_j * a_{k-j}

Wait, this isn't quite a standard game because C[k] depends on a in a non-linear way (it's quadratic in a).

But we can still use game-theoretic ideas. The "best response" to a fixed a is to pick the k that maximizes C[k]. The "best response" to a fixed k (and fixed a) would be to put all mass on the j that maximizes a_j * a_{k-j}... but that doesn't quite work because a appears in both factors.

Let me think differently. Consider the problem:
min_a max_k sum_j a_j * a_{k-j} s.t. sum a = 1, a >= 0

If we fix a, the max is achieved at k* = argmax_k C[k].
If we fix k*, the optimal a would put mass on indices j that minimize a_j * a_{k*-j}... but this is circular.

The LP-based best response approach handles this correctly by solving:
max sum(g) s.t. sum_j g_j * a_{k-j} <= M for all k, g >= 0

This is the right approach. But it's slow. The multiplicative weights approach is an approximation.

Let me also consider: what if we use a "soft" active set? Instead of a hard threshold, use a softmax:
active_weight[k] = exp(b[k] / τ) / sum(exp(b/τ))

Then the "soft gradient" is:
grad_soft[i] = sum_k active_weight[k] * 2*a[k-i]

This gives a smooth gradient that captures all "near-peak" constraints, not just the exact peak. The temperature τ controls how "sharp" the weighting is.

As τ → 0, we get the exact subgradient (only the max is weighted).
As τ → ∞, we get the average gradient (all constraints equally weighted).

This is essentially what the LP does implicitly (it finds the worst-case k for the best response), but the softmax gives us a smooth approximation.

**Idea: Use the structure of the problem for a better initial guess**

The optima of this problem might have a specific structure. Let me think about what kind of sequence would have a flat self-convolution.

If we think of the sequence as a probability distribution on {0, 1, ..., n-1}, then the self-convolution is the distribution of the sum of two independent copies. We want this sum distribution to be as flat as possible on {0, 1, ..., 2n-2}.

The flat distribution on {0, ..., 2n-2} would require the original distribution to have a specific structure. In the continuous case, the uniform distribution on [0,1] has a triangular sum distribution (not flat). To get a flat sum, we'd need a specific distribution.

In the discrete case, one approach is to use "irregular" distributions that avoid the CLT peak. For example, a distribution concentrated on a few points might give a more uniform sum.

For instance, if a has mass only on even indices (like a "lattice" distribution), then the sum would be concentrated on even indices in the sum distribution... wait, that doesn't help.

Actually, let me think about it from the Fourier side. The self-convolution in time domain corresponds to |A(f)|^2 in frequency domain (where A is the DTFT of a). The time-domain peak corresponds to... hmm, it's not a simple relationship.

The max of the self-convolution is the L-infinity norm of the autocorrelation (with the specific sign convention of convolution vs. correlation). By Parseval/Plancherel, the L2 norm of the self-convolution equals the L2 norm of |A(f)|^2, which is fixed (it equals (sum a)^2 / (2π) in the continuous case). So we're trying to minimize the L-infinity norm given a fixed L2 norm, which means we want the self-convolution to be as flat as possible (equal L-infinity and L2 norms in the limit).

This confirms that the goal is to make the self-convolution as flat as possible.

**Practical approach for generating good initializations:**

1. **Random with smoothing**: Generate random sequences and smooth them.
2. **Fourier-based**: Generate a random phase function, take the inverse FFT, and use the absolute value (or a transformation) as the sequence.
3. **Iterative construction**: Start with a small sequence, optimize it, then use it as a building block for a larger sequence.

```python
"""
Minimizes J(a) = 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Soft multiplicative weights (exponentiated gradient) with annealing
2. FFT-based gradient computation (O(n log n) per iteration)
3. Periodic LP best-response for escape from local minima
4. Multiple diverse initializations
5. Length exploration and extension
6. Final polish with L-BFGS-B
"""

import numpy as np
from scipy.optimize import linprog, minimize
from scipy.sparse import csr_matrix
import time

def fast_conv(a):
    """Full self-convolution via FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]

def compute_J(a):
    """Compute J(a) = 2*n*max(conv(a,a))/(sum(a))^2."""
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))

def build_A_sparse(n, a):
    """Build sparse constraint matrix for LP."""
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        j_min = max(0, k - n + 1)
        j_max = min(n - 1, k)
        for j in range(j_min, j_max + 1):
            rows.append(k)
            cols.append(j)
            vals.append(a[k - j])
    A = csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
    return A

def lp_best_response(a, M):
    """LP: max sum(g) s.t. (a*g)[k] <= M for all k, g >= 0."""
    n = len(a)
    A = build_A_sparse(n, a)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    try:
        r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
        if r.success and r.x is not None:
            g = np.maximum(r.x, 0)
            if g.sum() > 1e-15:
                return g
    except Exception:
        pass
    return None

def soft_mw_optimize(a, max_iters, deadline, tracker, tau_init=0.05, tau_min=1e-4, eta_init=0.12):
    """
    Soft multiplicative weights optimization with annealed temperature.
    Uses exponentiated gradient with soft active set.
    """
    a = np.maximum(a.astype(np.float64), 1e-15)
    a = a / a.sum()
    current_J = compute_J(a)
    tracker.update(a)
    
    eta = eta_init
    tau = tau_init
    no_improve = 0
    n = len(a)
    best_a = a.copy()
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        M = float(b.max())
        
        # Soft weights: exponential of (b - M) / tau
        # Clip to avoid underflow
        diff = (b - M) / tau
        diff = np.maximum(diff, -50)  # Prevent underflow
        weights = np.exp(diff)
        wsum = weights.sum()
        if wsum < 1e-15:
            break
        weights = weights / wsum
        
        # Gradient via FFT correlation
        grad = 2.0 * np.correlate(weights, a, mode='full')[:n]
        
        gmax = grad.max()
        if gmax < 1e-15:
            break
        grad = grad / gmax
        
        # Multiplicative update in log space
        log_a = np.log(a) - eta * grad
        log_a -= log_a.max()
        a_new = np.exp(log_a)
        a_new = np.maximum(a_new, 1e-15)
        a_new = a_new / a_new.sum()
        
        J_new = compute_J(a_new)
        if J_new < current_J - 1e-14:
            a = a_new
            current_J = J_new
            best_a = a.copy()
            no_improve = 0
            # Anneal tau (make it sharper over time)
            tau = max(tau_min, tau * 0.997)
            # Slightly increase eta as we converge
            if it % 100 == 99:
                eta = max(0.01, eta * 0.95)
            if it % 200 == 0:
                tracker.update(a)
        else:
            no_improve += 1
            eta *= 0.7
            if no_improve > 60:
                break
    
    tracker.update(a)
    return best_a

def hard_mw_optimize(a, max_iters, deadline, tracker):
    """
    Hard multiplicative weights (exact subgradient) with backtracking.
    """
    a = np.maximum(a.astype(np.float64), 1e-15)
    a = a / a.sum()
    current_J = compute_J(a)
    tracker.update(a)
    
    eta = 0.08
    no_improve = 0
    n = len(a)
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        M = float(b.max())
        
        # Hard active set
        tol = max(1e-10, 1e-8 * M)
        active = (b >= M - tol).astype(np.float64)
        if active.sum() == 0:
            active[np.argmax(b)] = 1.0
        
        # Gradient
        grad = 2.0 * np.correlate(active, a, mode='full')[:n]
        gmax = grad.max()
        if gmax < 1e-15:
            break
        grad = grad / gmax
        
        # Try multiple step sizes
        best_a = None
        best_J = current_J
        for t in [eta, eta * 0.5, eta * 0.25, 0.01]:
            log_a = np.log(a) - t * grad
            log_a -= log_a.max()
            a_try = np.exp(log_a)
            a_try = np.maximum(a_try, 1e-15)
            a_try = a_try / a_try.sum()
            J_try = compute_J(a_try)
            if J_try < best_J - 1e-14:
                best_J = J_try
                best_a = a_try
                break
        
        if best_a is not None:
            a = best_a
            current_J = best_J
            no_improve = 0
            if it % 100 == 0:
                tracker.update(a)
        else:
            no_improve += 1
            eta *= 0.8
            if no_improve > 40:
                break
    
    tracker.update(a)
    return a

def lp_rescue(a, deadline, tracker, max_iters=50):
    """LP-based best response for escaping local minima."""
    a = np.maximum(a.astype(np.float64), 1e-15)
    a = a / a.sum()
    current_J = compute_J(a)
    tracker.update(a)
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        M = float(b.max())
        g = lp_best_response(a, M)
        if g is None:
            break
        g = g / g.sum()
        
        # Blend
        best_a = None
        best_J = current_J
        for t in [0.3, 0.2, 0.1, 0.05]:
            a_try = (1 - t) * a + t * g
            a_try = np.maximum(a_try, 1e-15)
            a_try = a_try / a_try.sum()
            J_try = compute_J(a_try)
            if J_try < best_J - 1e-14:
                best_J = J_try
                best_a = a_try
                break
        
        if best_a is not None:
            a = best_a
            current_J = best_J
            tracker.update(a)
        else:
            break
    
    return a

def resample_seq(src, dest_n):
    """Resample 1D sequence to new length."""
    src = np.asarray(src, dtype=np.float64)
    if src.size == dest_n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, dest_n)
    return np.maximum(np.interp(t_new, t_old, src), 1e-6)

def generate_diverse_inits(n, rng, parent=None):
    """Generate diverse initial sequences."""
    inits = []
    t = np.linspace(0, 1, n, endpoint=False)
    
    if parent is not None:
        p = resample_seq(parent, n)
        inits.append(p)
        # Perturbed versions
        for sigma in [0.03, 0.08, 0.15]:
            inits.append(np.maximum(p + rng.normal(0, sigma, n), 1e-6))
        # "Stretched" parent
        inits.append(np.maximum(p ** 2, 1e-6))
        inits.append(np.maximum(np.sqrt(p), 1e-6))
    
    # Uniform
    inits.append(np.ones(n))
    
    # Cosine families
    for freq in [1, 2, 3, 5, 8, 13]:
        for amp in [0.2, 0.5, 0.8]:
            inits.append(np.maximum(1.0 + amp * np.cos(2 * np.pi * freq * t + rng.uniform(0, 2*np.pi)), 0.01))
    
    # Power spectra-inspired
    for alpha in [0.5, 1.0, 1.5, 2.0, 3.0]:
        inits.append(np.maximum((t + 0.01) ** alpha, 1e-6))
        inits.append(np.maximum((1 - t + 0.01) ** alpha, 1e-6))
    
    # Gaussian bumps
    for center in [0.2, 0.3, 0.5, 0.7, 0.8]:
        for width in [0.05, 0.1, 0.2, 0.3]:
            inits.append(np.exp(-((t - center) / width) ** 2) + 0.05)
    
    # Double bump
    inits.append(np.exp(-((t-0.3)/0.1)**2) + np.exp(-((t-0.7)/0.1)**2) + 0.05)
    inits.append(np.exp(-((t-0.2)/0.08)**2) + np.exp(-((t-0.5)/0.15)**2) + np.exp(-((t-0.8)/0.08)**2) + 0.03)
    
    # Chirp
    for fmax in [2, 5, 10, 20]:
        inits.append(np.maximum(1.0 + 0.4 * np.cos(2 * np.pi * fmax * t**2), 0.01))
    
    # Block structure
    for nblocks in [4, 8, 16, 32]:
        if nblocks < n:
            block_size = n // nblocks
            blocks = rng.uniform(0.2, 1.0, nblocks)
```

        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))


def build_A_sparse(n, a):
    """Build sparse constraint matrix for LP: (a*g)[k] <= M."""
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        j_min = max(0, k - n + 1)
        j_max = min(n - 1, k)
        for j in range(j_min, j_max + 1):
            rows.append(k)
            cols.append(j)
            vals.append(a[k - j])
    A = csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
    return A


def lp_best_response(a, M):
    """LP: max sum(g) s.t. (a*g)[k] <= M for all k, g >= 0."""
    n = len(a)
    A = build_A_sparse(n, a)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    try:
        r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
        if r.success and r.x is not None:
            g = np.maximum(r.x, 0)
            if g.sum() > 1e-15:
                return g
    except Exception:
        pass
    return None


def soft_mw_optimize(a, max_iters, deadline, tracker, tau_init=0.08, tau_min=1e-5, eta_init=0.12):
    """
    Soft multiplicative weights (exponentiated gradient) with annealed temperature.
    Each iteration is O(n log n) via FFT-based gradient computation.
    """
    a = np.maximum(a.astype(np.float64), 1e-15)
    a = a / a.sum()
    current_J = compute_J(a)
    tracker.update(a)

    eta = eta_init
    tau = tau_init
    no_improve = 0
    n = len(a)

    for it in range(max_iters):
        if time.monotonic() > deadline:
            break

        b = fast_conv(a)
        M = float(b.max())

        # Soft weights: exp((b - M) / tau), clipped to avoid underflow
        diff = (b - M) / tau
        diff = np.maximum(diff, -40.0)
        weights = np.exp(diff)
        wsum = weights.sum()
        if wsum < 1e-15:
            break
        weights = weights / wsum

        # Gradient via FFT-based correlation
        grad = 2.0 * np.correlate(weights, a, mode='full')[:n]

        gmax = grad.max()
        if gmax < 1e-15:
            break
        grad = grad / gmax

        # Exponentiated gradient update
        log_a = np.log(a) - eta * grad
        log_a -= log_a.max()
        a_new = np.exp(log_a)
        a_new = np.maximum(a_new, 1e-15)
        a_new = a_new / a_new.sum()

        J_new = compute_J(a_new)
        if J_new < current_J - 1e-14:
            a = a_new
            current_J = J_new
            no_improve = 0
            tau = max(tau_min, tau * 0.998)
            if it > 500 and it % 500 == 0:
                eta = max(0.02, eta * 0.92)
            if it % 500 == 0:
                tracker.update(a)
        else:
            no_improve += 1
            eta *= 0.75
            if no_improve > 80:
                break

    tracker.update(a)
    return a


def hard_mw_optimize(a, max_iters, deadline, tracker, eta_init=0.08):
    """Hard subgradient multiplicative weights with backtracking line search."""
    a = np.maximum(a.astype(np.float64), 1e-15)
    a = a / a.sum()
    current_J = compute_J(a)
    tracker.update(a)

    eta = eta_init
    no_improve = 0
    n = len(a)

    for it in range(max_iters):
        if time.monotonic() > deadline:
            break

        b = fast_conv(a)
        M = float(b.max())

        # Hard active set with small tolerance
        tol = max(1e-12, 1e-9 * M)
        active = (b >= M - tol).astype(np.float64)
        if active.sum() == 0:
            active[np.argmax(b)] = 1.0

        # Gradient
        grad = 2.0 * np.correlate(active, a, mode='full')[:n]
        gmax = grad.max()
        if gmax < 1e-15:
            break
        grad = grad / gmax

        # Backtracking: try decreasing step sizes
        best_a = None
        best_J = current_J
        for t in [eta, eta * 0.5, eta * 0.25, 0.005]:
            log_a = np.log(a) - t * grad
            log_a -= log_a.max()
            a_try = np.exp(log_a)
            a_try = np.maximum(a_try, 1e-15)
            a_try = a_try / a_try.sum()
            J_try = compute_J(a_try)
            if J_try < best_J - 1e-14:
                best_J = J_try
                best_a = a_try
                break

        if best_a is not None:
            a = best_a
            current_J = best_J
            no_improve = 0
            if it % 200 == 0:
                tracker.update(a)
        else:
            no_improve += 1
            eta *= 0.8
            if no_improve > 50:
                break

    tracker.update(a)
    return a


def lp_rescue(a, deadline, tracker, max_iters=60):
    """LP-based best response for escaping local minima."""
    a = np.maximum(a.astype(np.float64), 1e-15)
    a = a / a.sum()
    current_J = compute_J(a)
    tracker.update(a)

    for it in range(max_iters):
        if time.monotonic() > deadline:
            break

        b = fast_conv(a)
        M = float(b.max())
        g = lp_best_response(a, M)
        if g is None:
            break
        g = np.maximum(g, 0)
        gsum = g.sum()
        if gsum < 1e-15:
            break
        g = g / gsum

        best_a = None
        best_J = current_J
        for t in [0.3, 0.2, 0.1, 0.05, 0.02]:
            a_try = (1 - t) * a + t * g
            a_try = np.maximum(a_try, 1e-15)
            a_try = a_try / a_try.sum()
            J_try = compute_J(a_try)
            if J_try < best_J - 1e-14:
                best_J = J_try
                best_a = a_try
                break

        if best_a is not None:
            a = best_a
            current_J = best_J
            tracker.update(a)
        else:
            break

    return a


def resample_seq(src, dest_n):
    """Resample 1D sequence to new length via linear interpolation."""
    src = np.asarray(src, dtype=np.float64)
    if src.size == dest_n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, dest_n)
    return np.maximum(np.interp(t_new, t_old, src), 1e-6)


def generate_diverse_inits(n, rng, parent=None):
    """Generate diverse initial sequences of length n."""
    inits = []
    t = np.linspace(0, 1, n, endpoint=False)

    if parent is not None:
        p = resample_seq(parent, n)
        inits.append(p)
        for sigma in [0.02, 0.05, 0.1, 0.2]:
            inits.append(np.maximum(p + rng.normal(0, sigma, n), 1e-6))
        inits.append(np.maximum(p ** 1.5, 1e-6))
        inits.append(np.maximum(p ** 0.7, 1e-6))
        inits.append(np.maximum(p * (2.0 - p * 0.5), 1e-6))

    inits.append(np.ones(n))

    # Cosine families with various frequencies and phases
    for freq in [1, 2, 3, 4, 5, 7, 11, 16]:
        for amp in [0.15, 0.4, 0.7]:
            phase = rng.uniform(0, 2 * np.pi)
            inits.append(np.maximum(1.0 + amp * np.cos(2 * np.pi * freq * t + phase), 0.01))

    # Power law
    for alpha in [0.3, 0.7, 1.3, 2.0, 3.0]:
        inits.append(np.maximum((t + 0.02) ** alpha, 1e-6))
        inits.append(np.maximum((1.0 - t + 0.02) ** alpha, 1e-6))

    # Gaussian bumps
    for center in [0.25, 0.4, 0.5, 0.6, 0.75]:
        for width in [0.05, 0.1, 0.2, 0.35]:
            inits.append(np.exp(-((t - center) / width) ** 2) + 0.05)

    # Multi-bump
    inits.append(np.exp(-((t-0.2)/0.08)**2) + np.exp(-((t-0.5)/0.12)**2) + np.exp(-((t-0.8)/0.08)**2) + 0.04)
    inits.append(np.exp(-((t-0.3)/0.15)**2) + np.exp(-((t-0.7)/0.15)**2) + 0.06)

    # Chirp
    for fmax in [3, 7, 15, 30]:
        inits.append(np.maximum(1.0 + 0.35 * np.cos(2 * np.pi * fmax * t ** 2), 0.01))

    # Block structure with smoothing
    for nblocks in [4, 8, 16, 32, 64]:
        if nblocks < n:
            block_size = max(1, n // nblocks)
            blocks = rng.uniform(0.2, 1.0, nblocks)
            seq = np.repeat(blocks, block_size)[:n]
            k = max(3, n // 40)
            kernel = np.ones(k) / k
            seq = np.convolve(seq, kernel, mode='same')
            inits.append(np.maximum(seq, 0.01))

    # Random smooth
    for smooth_deg in [10, 30, 100]:
        k = max(3, n // smooth_deg)
        kernel = np.ones(k) / k
        seq = np.convolve(rng.uniform(0, 1, n), kernel, mode='same')
        inits.append(np.maximum(seq + 0.08, 0.01))

    # Fourier random phase (band-limited random)
    nfreqs = max(1, n // 4)
    freqs = rng.choice(np.arange(1, n // 2 + 1), size=min(nfreqs, n // 2), replace=False)
    phases = rng.uniform(0, 2 * np.pi, len(freqs))
    amps = rng.uniform(0.3, 1.0, len(freqs))
    sig = np.ones(n) * 0.5
    for f, ph, am in zip(freqs, phases, amps):
        sig += am * np.cos(2 * np.pi * f * t + ph)
    inits.append(np.maximum(sig, 0.01))

    # Triangle / V
    inits.append(np.maximum(1.0 - 1.5 * np.abs(t - 0.5) * 2 + 0.3, 0.01))
    inits.append(0.3 + 0.7 * np.abs(2 * t - 1.0))

    # Alternating with noise
    alt = np.ones(n)
    alt[::2] = rng.uniform(0.3, 0.6)
    alt[::3] = rng.uniform(0.1, 0.4)
    inits.append(np.maximum(alt + rng.normal(0, 0.03, n), 0.01))

    return inits


def lbb_objective(x):
    """Objective for L-BFGS-B: minimize max(conv(x,x)) with normalization."""
    ax = np.maximum(x, 0.0)
    s = ax.sum()
    if s < 1e-8:
        return 1e10
    ax = ax / s
    b = fast_conv(ax)
    return float(b.max())


class ScoreTracker:
    """Tracks the best sequence found so far."""

    def __init__(self):
        self.best = None
        self.best_score = float('inf')
        self.t_start = time.monotonic()

    def update(self, a):
        a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
        if a.size == 0 or a.sum() < 0.01:
            return
        score = float(evaluate_sequence(a.tolist()))
        if np.isfinite(score) and score < self.best_score:
            self.best = a.copy()
            self.best_score = score
            elapsed = time.monotonic() - self.t_start
            print(f"  * J={score:.8f} n={a.size} t={elapsed:.1f}s", flush=True)

    def report(self, label=""):
        if self.best is not None:
            print(f"  {label} best: J={self.best_score:.8f} n={self.best.size} t={time.monotonic()-self.t_start:.0f}s", flush=True)


def propose_candidate(seed=42, budget_s=1500, **kwargs):
    """
    Multi-phase search:
    Phase 1: Soft MW on parent (fast, ~15% time)
    Phase 2: Diverse inits at parent length (~25% time)
    Phase 3: Hard MW refinement (~10% time)
    Phase 4: LP rescue (~10% time)
    Phase 5: Nearby lengths exploration (~20% time)
    Phase 6: L-BFGS-B + final polish (~15% time)
    Phase 7: Final combined optimization (~5% time)
    """
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + float(budget_s) - 15.0
    tracker = ScoreTracker()

    # Load parent
    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        if p.ndim == 1 and p.size > 0 and np.all(np.isfinite(p)):
            parent = np.maximum(p, 0.0)
            tracker.update(parent)
            print(f"Parent loaded: n={parent.size}, J={tracker.best_score:.6f}", flush=True)
    except (NameError, AttributeError):
        pass

    if parent is None:
        parent = np.ones(512)
        tracker.update(parent)

    n_parent = parent.size

    # === Phase 1: Soft MW on parent ===
    t0 = time.monotonic()
    phase_time = min(180, (deadline - t0) * 0.15)
    print(f"\n{'='*50} Phase 1: Soft MW on parent n={n_parent} budget={phase_time:.0f}s {'='*50}", flush=True)

    a = soft_mw_optimize(parent, 100000, t0 + phase_time, tracker,
                         tau_init=0.12, tau_min=1e-5, eta_init=0.15)
    tracker.report("Phase 1 done")

    # === Phase 2: Diverse initializations ===
    t0 = time.monotonic()
    phase_time = min(300, (deadline - t0) * 0.25)
    print(f"\n{'='*50} Phase 2: Diverse inits budget={phase_time:.0f}s {'='*50}", flush=True)

    inits = generate_diverse_inits(n_parent, rng, tracker.best)
    print(f"  Generated {len(inits)} initializations", flush=True)

    # Shuffle and take a subset if too many
    if len(inits) > 40:
        indices = rng.choice(len(inits), size=40, replace=False)
        inits = [inits[i] for i in sorted(indices)]

    time_per_init = phase_time / max(1, len(inits))

    for idx, a0 in enumerate(inits):
        if time.monotonic() > t0 + phase_time:
            break
        a0 = np.maximum(a0.astype(np.float64), 1e-15)
        s = a0.sum()
        if s < 1e-10:
            continue
        a0 = a0 / s

        remaining = max(1.0, t0 + phase_time - time.monotonic())
        budget = min(time_per_init * (1 + 0.5 * (len(inits) - idx) / len(inits)), remaining * 0.8)

        a = soft_mw_optimize(a0, int(max(200, budget / 0.0003)), time.monotonic() + max(1.0, budget),
                            tracker, tau_init=0.08, tau_min=1e-5, eta_init=0.12)

        if idx % 10 == 0:
            tracker.report(f"  Phase 2 init {idx}/{len(inits)}")

    tracker.report("Phase 2 done")

    # === Phase 3: Hard MW refinement on best ===
    if tracker.best is not None and time.monotonic() < deadline - 150:
        t0 = time.monotonic()
        phase_time = min(120, (deadline - t0) * 0.1)
        print(f"\n{'='*50} Phase 3: Hard MW budget={phase_time:.0f}s {'='*50}", flush=True)
        a = hard_mw_optimize(tracker.best, 50000, t0 + phase_time, tracker, eta_init=0.06)
        tracker.report("Phase 3 done")

    # === Phase 4: LP Rescue ===
    if tracker.best is not None and time.monotonic() < deadline - 100:
        t0 = time.monotonic()
        phase_time = min(100, (deadline - t0) * 0.1)
        print(f"\n{'='*50} Phase 4: LP Rescue budget={phase_time:.0f}s {'='*50}", flush=True)
        a = lp_rescue(tracker.best, t0 + phase_time, tracker, max_iters=60)
        tracker.report("Phase 4 done")

    # === Phase 5: Try nearby lengths ===
    if tracker.best is not None and time.monotonic() < deadline - 80:
        t0 = time.monotonic()
        phase_time = min(250, (deadline - t0) * 0.2)
        print(f"\n{'='*50} Phase 5: Length exploration budget={phase_time:.0f}s {'='*50}", flush=True)

        candidate_lengths = sorted(set([
            max(128, n_parent - 64), n_parent,
            min(1024, n_parent + 64), min(1024, n_parent * 2),
            384, 512, 640, 768, 1024
        ]))
        candidate_lengths = [n for n in candidate_lengths if 128 <= n <= 2048 and n != n_parent]

        if n_parent != 512:
            candidate_lengths.append(512)

        for new_n in candidate_lengths:
            if time.monotonic() > t0 + phase_time - 30:
                break

            a_ext = resample_seq(tracker.best, new_n)
            a
