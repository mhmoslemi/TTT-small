For Nesterov's accelerated gradient on the convex problem "minimize f(a) = max_k c[k](a) s.t. sum(a) = 1, a >= 0":

The update is:
- y_k = a_k + (t_{k-1} - 1)/(t_k + 1) * (a_k - a_{k-1}) (momentum)
- g = subgradient of f at y_k
- a_{k+1} = Proj_simplex(y_k - (1/t_k) * g)
- t_{k+1} = (1 + sqrt(1 + 4*t_k^2)) / 2

Where Proj_simplex is the Euclidean projection onto the probability simplex.

The projection onto the simplex {x : sum(x) = 1, x >= 0} can be computed in O(n log n) time using a sorted approach.

Let me implement this:

```python
def project_simplex(v):
    """Project vector v onto the probability simplex {x: sum(x)=1, x>=0}."""
    n = len(v)
    # Sort in decreasing order
    u = np.sort(v)[::-1]
    # Find rho
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)
```
