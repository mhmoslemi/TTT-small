from scipy import sparse, optimize
import time

def solve_lp(f, M):
    """Solve the LP: maximize sum(b) subject to convolve(f,b) <= M, b >= 0."""
    n = len(f)
    # Build the constraint matrix (sparse)
    # A_ub[k, j] = f[k-j] if 0 <= k-j < n, else 0
    # A_ub has shape (2n-1, n)
    
    rows = []
    cols = []
    vals = []
    
    for k in range(2*n - 1):
        for j in range(max(0, k-n+1), min(n, k+1)):
            idx = k - j
            if 0 <= idx < n:
                rows.append(k)
                cols.append(j)
                vals.append(f[idx])

        return res.x
    else:
        return None

So the subgradient of f(a) = max_k (a*a)[k] at point a (when max is at k*) is:
g[j] = 2*a[k*-j] if 0 <= k*-j < n, else 0.

This is just a shifted (and possibly reversed) version of a, multiplied by 2!

So the projected subgradient step is:
a_new = a - step_size * g, where g[j] = 2*a[k*-j] (shifted/reversed).
Then project onto {a: sum(a) = S, a >= 0}.

The projection onto {a: sum(a) = S, a >= 0} is: find the largest lambda such that sum(max(0, a - lambda)) = S, then set a_proj = max(0, a - lambda).

This is a 1D root-finding problem (bisection on lambda), which is O(n log(precision)).

So the overall algorithm is:
1. Compute k* = argmax (a*a)
2. Compute g[j] = 2*a[k*-j] (with boundary handling)
3. a_new = a - step_size * g
4. Project a_new onto {sum = S, a >= 0}
5. Repeat

This is O(n) per iteration (for the convolution to find k*, which is O(n log n) via FFT, and the projection which is O(n log(precision))).

            best_a = a.copy()
