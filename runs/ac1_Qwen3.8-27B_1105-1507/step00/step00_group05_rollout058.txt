The multiplicative subgradient descent:
1. Compute c = convolve(a, a) using FFT
2. Find m* = argmax(c)
3. Compute grad = 2 * (a reversed, shifted by m*) [vectorized]
4. Update: a *= exp(-eta * grad / max_grad)
5. Normalize: a /= a.sum()
6. Optionally: project to [0, inf) (clipping)

The learning rate eta is crucial. If it's too large, we might oscillate or diverge. If it's too small, we make slow progress.

A good strategy is to use a "backtracking" line search: start with a large eta, and if the objective increases, reduce eta.

```python
"""
Optimization of non-negative step function to minimize 2n*max(conv(conv)) / (sum)^2.
Uses smooth max gradient descent with multiple initializations including Pascal sequences.
"""
import numpy as np
import time
from math import comb, log

def pascal_sequence(n):
    """Generate Pascal (central binomial) sequence of length n."""
    a = np.zeros(n)
    for i in range(n):
        a[i] = comb(2*i, i) / (4.0 ** i)
    return a

def pascal_sequence_fast(n):
    """Generate Pascal sequence using recurrence for speed."""
    a = np.zeros(n)
    a[0] = 1.0
    for i in range(1, n):
        # C(2i,i)/4^i = C(2i-2,i-1)/4^{i-1} * (2i-1)/(2i)
        a[i] = a[i-1] * (2.0*i - 1.0) / (2.0 * i)
    return a

def fast_autocorr(a):
    """Compute full convolution of a with itself using FFT."""
    n = len(a)
    size = 1
    while size < 2*n - 1:
        size *= 2
    fa = np.fft.rfft(a, size)
    result = np.fft.irfft(fa * fa, size)[:2*n-1]
    return result

def smooth_max_weights(c, tau=0.01):
    """Compute softmax weights for smooth max."""
    shifted = c / tau - np.max(c / tau)
    w = np.exp(shifted)
    w /= w.sum()
    return w
