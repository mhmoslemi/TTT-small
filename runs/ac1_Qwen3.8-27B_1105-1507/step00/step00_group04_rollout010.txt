def compute_subgradient(a, active_lags, tol_frac=0.1):
    """
    Compute subgradient of max_k c[k] w.r.t. a.
    a: sequence of length n
    Returns: subgradient vector of length n
    """
    n = len(a)
    c = np.convolve(a, a)
    max_c = c.max()
    
    # Active set: lags where c[k] is within tol_frac of max
    active = c >= max_c * (1 - tol_frac)
    
    # Subgradient: average of gradients over active lags
    # dc[k]/da[j] = 2*a[k-j] if 0 <= k-j < n
    # This is equivalent to: for each active k, add 2*flip-shift of a
    grad = np.zeros(n)
    active_indices = np.where(active)[0]
    for k in active_indices:

        # i.e., j ranges from max(0, k-n+1) to min(n-1, k)
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        if j_start <= j_end:
            idx = np.arange(j_start, j_end + 1)
            grad[idx] += 2 * a[k - idx]
    
    grad /= len(active_indices)
    return grad, max_c

This is a 1D problem! The optimal `a[j]` is the smallest value that makes all `c[k] <= current_max` (or 0 if that's not needed).

In the radar/sonar community, the problem of designing sequences with low peak-to-average sidelobe ratio (PSLR) is well-studied. For complex sequences, algorithms like the "adaptive spectral partitioning" (ASP) algorithm or the "feedback projection" algorithm are used.

For non-negative sequences, the problem is different, but similar ideas apply.

**Feedback projection algorithm (adapted for non-negative sequences):**
1. Start with a random non-negative sequence, normalize
2. Compute the autocorrelation
3. Identify the "bad" lags (where autocorrelation is high)
4. In the frequency domain, reduce the power at frequencies that correspond to those lags
5. Transform back, take the real part (should be non-negative if we start non-negative and use a window), clip to non-negative
6. Repeat

**Alternative: Use the DFT to reduce peaks**

The autocorrelation `c[k]` is the inverse DFT of `|A(f)|²` where `A(f)` is the DFT of `a`. To reduce the peak of `c[k]` (which is at `k=0` or near it), we want to make `|A(f)|²` more uniform across frequencies.

For a non-negative sequence `a`, the DFT `A(f) = sum a[i] e^{-2πif/n}` has `|A(0)| = sum a = 1` (fixed). The other frequencies can be varied by changing `a`.

If we could make `|A(f)|` constant across all frequencies, then `c[k]` would be a delta (zero for all `k ≠ 0`). But this is impossible for a real non-negative sequence (the DFT of a real sequence has conjugate symmetry, and the sequence being non-negative imposes additional constraints).

A practical approach: iteratively flatten the power spectrum.

1. Compute `A(f) = DFT(a)`
2. Compute `|A(f)|`
3. Replace `A(f)` with `A(f) / |A(f)| * target` where `target` is some desired amplitude (e.g., the geometric mean)
4. Take inverse DFT, clip to non-negative
5. Repeat

This is similar to the Gerchberg-Saxton algorithm used in X-ray crystallography.

def gs_step(a, target_level=None):
    """One Gerchberg-Saxton iteration."""
    n = len(a)
    A = np.fft.rfft(a)  # Real FFT
    if target_level is None:
        target_level = np.sqrt(np.mean(np.abs(A)**2))
    # Scale the spectrum to have the target amplitude
    phase = np.angle(A)
    A_new = target_level * np.exp(1j * phase)
    # Make DC component correct
    A_new[0] = a.sum()  # Keep DC = sum(a)
    a_new = np.fft.irfft(A_new, n)
    a_new = np.maximum(a_new, 0)
    a_new = a_new / a_new.sum()
    return a_new
