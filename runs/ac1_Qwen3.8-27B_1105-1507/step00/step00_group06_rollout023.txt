Since the metric is scale-invariant, we can fix sum(f) = 1 (or any constant) and minimize max_k (f*f)[k]. This is a min-max problem.

We can use subgradient methods: at each iteration, the gradient of the max is the indicator of where the max is achieved (or a convex combination if there are ties). But the max is non-differentiable, so we use subgradients.

**Alternative: Use the LP-based approach from the SOTA description.**

The LP approach:
1. Given current f with M = max(f*f).
2. Solve: maximize sum(b) subject to b >= 0, (f*b)[k] <= M for all k.
3. Normalize b to have sum 1.
4. Update f <- (1-t)*f + t*b.

The key advantage is that the LP finds the "best" direction to move in one step. The constraint (f*b)[k] <= M ensures that the new sequence b, when convolved with the old f, doesn't exceed the current peak. By taking a convex combination, we maintain feasibility.

This is essentially a Frank-Wolfe / conditional gradient method applied to the non-convex problem.

For a sequence f of length n, the convolution (f*f)[k] for k = 0, ..., 2n-2.

If f is a "delta" at position p: f[p] = 1, rest 0. Then (f*f)[2p] = 1, rest 0. Max = 1, sum = 1, score = 2n*1/1 = 2n. Terrible.
