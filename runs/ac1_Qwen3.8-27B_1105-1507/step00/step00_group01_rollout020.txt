Actually, I want to be more careful about the subgradient computation. Let me derive it clearly.

`c[k] = sum_{j: valid} a[j] * a[k-j]`

where "valid" means `0 <= j < n` and `0 <= k-j < n`, i.e., `max(0, k-n+1) <= j <= min(n-1, k)`.

`dc[k]/da[i]`:
- The term `a[j] * a[k-j]` depends on `a[i]` if `j = i` or `k-j = i` (i.e., `j = k-i`).
- If `j = i` is valid: contributes `a[k-i]` (derivative of `a[j]` wrt `a[i]` is 1, times `a[k-j]`).
- If `j = k-i` is valid (and `k-i != i`): contributes `a[k-i]` (derivative of `a[k-j]` wrt `a[i]` is 1, times `a[j] = a[k-i]`).
  Wait, `a[j]` where `j = k-i` is `a[k-i]`. So the contribution is `a[k-i]`.
- If `j = i = k-i` (i.e., `i = k/2`): the term is `a[i]^2`, derivative is `2a[i]`.

So:
- If `0 <= i < n` and `0 <= k-i < n` and `i != k-i`: `dc[k]/da[i] = a[k-i] + a[k-i] = 2*a[k-i]`.
- If `i = k/2` (k even) and `0 <= i < n`: `dc[k]/da[i] = 2*a[i]`.
- Otherwise: `dc[k]/da[i] = 0`.

In all cases where the derivative is non-zero: `dc[k]/da[i] = 2*a[k-i]` (since if `i = k/2`, then `a[k-i] = a[i]`).

So the subgradient of `c[k]` is the vector `g` where `g[i] = 2*a[k-i]` if `0 <= k-i < n`, else 0.

This can be computed as: `g = 2 * reverse(a)[k-n+1 : k+1]` (padded with zeros to length n).

More precisely, `g[i] = 2*a[k-i]` for `i = max(0, k-n+1), ..., min(n-1, k)`, and 0 elsewhere.

This is essentially a shifted and reversed version of `a`.

For the averaged subgradient over M peaks: `grad = (1/M) * sum_{k in top_M} g_k`.

Then the update is:
1. `d = -grad` (descent direction).
2. Center it: `d = d - mean(d)` (to preserve the sum).
3. Update: `a_new = a + step * d`.
4. Project: `a_new = max(0, a_new)`.
5. Normalize: `a_new = a_new / sum(a_new)`.

Or we can use a fixed step size and rely on the projection to keep things stable.

Let me also think about convergence. The subgradient method converges slowly (O(1/sqrt(t)) for convex problems). But our problem is non-convex, so convergence is not guaranteed. However, in practice, it often works well.

To improve convergence, we can use:
- **Momentum**: `v = beta * v + (1-beta) * grad; d = -v - mean(-v)`.
- **Adaptive step size**: Use the norm of the gradient to scale the step.
- **Multiple peaks**: Using more peaks gives a smoother gradient and faster convergence.
