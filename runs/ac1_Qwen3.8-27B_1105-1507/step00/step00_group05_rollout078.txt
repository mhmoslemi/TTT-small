Actually, let me step back and think about this problem differently.

The objective is J = 2n * max(conv(s,s)) / (sum s)².

This is scale-invariant, so we can assume sum(s) = 1. Then J = 2n * max(conv(s,s)).

We want to minimize max(conv(s,s)) subject to sum(s) = 1, s >= 0, len(s) = n.

This is equivalent to: minimize the peak of the autocorrelation, given unit L1 norm.

For the continuous analog, this is related to "chatripod" or "multi-drop" designs. But let me think discretely.

The key constraint is that conv(s,s) at position n-1 (the middle) is sum_i s[i]*s[n-1-i]. For a symmetric sequence, this equals sum_i s[i]². By Cauchy-Schwarz, sum s[i]² >= (sum s[i])²/n = 1/n. So the middle is at least 1/n.

But the max of the convolution could be at a different position! If we can make the middle small while keeping other positions also small, we might beat the uniform case.

For the uniform sequence, ALL positions in the convolution are at most n*(1/n)² = 1/n. The middle achieves exactly 1/n.

For a non-uniform sequence, some positions might be larger than 1/n even if the middle is smaller.

So the question is: can we make ALL positions of conv(s,s) less than 1/n?

If yes, then J < 2. If no, then J >= 2.

For n=4, s = [1/3, 1/3, 0, 1/3]:

max = 2/9
1/n = 1/4 = 0.25
2/9 ≈ 0.222 < 0.25 ✓

So yes! We CAN make all positions less than 1/n. And indeed J = 2*4*(2/9)/(1)² = 16/9 < 2.

This is the key insight! For n=4, the sequence [1,1,0,1] (normalized) achieves max_b/sum² = 2/9 < 1/4 = 1/n.
