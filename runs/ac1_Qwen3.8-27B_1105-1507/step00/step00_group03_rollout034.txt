Actually, the simplest approach: use the definition directly with numpy's efficient operations.

g[i] = sum_{j=0}^{n-1} a[j] * w[i+j]

I can compute this as:
g = np.zeros(n)
for j in range(n):
    g[:n-j] += a[j] * w[j:n]  # w[i+j] for i=0..n-1-j means w[j..j+n-1-j] = w[j..n-1]

Wait: g[i] = sum_j a[j] * w[i+j]. For a fixed j, the contribution to g[i] is a[j] * w[i+j] for i = 0, 1, ..., n-1-j (since i+j < 2n-1 means i < 2n-1-j, but we only need i < n, and i+j < n+j ≤ 2n-2 for j ≤ n-2, and for j=n-1, i+
n-1 < 2n-1 means i < n, so i=0,...,n-1).

Wait, w has length 2n-1 (it's the convolution). So w[i+j] is valid as long as 0 <= i+j <= 2n-2. Since 0 <= i <= n-1 and 0 <= j <= n-1, we have 0 <= i+j <= 2n-2. So all terms are valid!

So: g[i] = sum_{j=0}^{n-1} a[j] * w[i+j]

For a fixed j, the contribution to g is: a[j] * w[j:j+n] (a slice of w of length n, starting at position j). This contributes to g[0], g[1], ..., g[n-1].

So: g = sum_{j=0}^{n-1} a[j] * w[j:j+n]

This is a linear combination of shifted versions of w! We can compute it as:

```python
# w has length 2n-1
# g has length n
# g[i] = sum_j a[j] * w[j+i] for j=0..n-1
# = sum_j a[j] * w[j:j+n][i]
# 
# This is the "cross-correlation" of a and w, but only the first n values
# Can be computed as:
# g = correlate(w, a, mode='valid')? Let's check.
# scipy.signal.correlate(w, a, mode='valid') gives:
# out[i] = sum_j w[j+i] * a[j] for j=0..len(a)-1
# = sum_j w[j+i] * a[j]
# That's exactly what we want! (with i = 0, ..., len(w)-len(a)=n-1)
```

So: g = scipy.signal.correlate(w, a, mode='valid') gives us exactly g[i] = sum_j w[j+i] * a[j] for i = 0, ..., n-1.

And we want g[i] = sum_j a[j] * w[i+j] = sum_j a[j] * w[j+i], which is the same thing! (just reordering the product).

So: g = 2 * scipy.signal.correlate(weights, a, mode='valid')

This is O(n log n) using FFT under the hood.
