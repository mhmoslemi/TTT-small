But we're dealing with the convolution, not the autocorrelation. The DFT of the convolution is the square of the DFT of the sequence. So we want |DFT(a)|^2 to be flat, i.e., |DFT(a)| to be flat.

For a length-n sequence, the DFT has n bins. If |DFT(a)[k]| = c for all k, then by Parseval:
sum_k |DFT(a)[k]|^2 = n * sum_i a[i]^2
n * c^2 = n * sum_i a[i]^2
c^2 = sum_i a[i]^2

Also, DFT(a)[0] = sum_i a[i] = S, so c = S/sqrt(n).
Thus sum_i a[i]^2 = S^2/n (which is the minimum possible by Cauchy-Schwarz, achieved when all a_i are equal).

So a perfectly flat DFT corresponds to a uniform sequence, which gives score 2.

But the linear convolution has 2n-1 points, while the DFT has only n points. The linear convolution is the circular convolution of a zero-padded sequence (length 2n-1) with itself.
