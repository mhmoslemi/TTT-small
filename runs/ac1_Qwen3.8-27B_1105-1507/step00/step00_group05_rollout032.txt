The sum is always p/2 regardless of alpha.

Let's compute the convolution for this:

For the m-sequence, the aperiodic autocorrelation C(k) = sum_i s_i * s_{k-i} is approximately:
- C(0) = p (or close to it for aperiodic)
- C(k) ≈ -1 for k ≠ 0 (with edge effects)

And sum_i s_i ≈ 0, sum_i s_{k-i} ≈ 0 (for the full sum).

So approximately:
b_k ≈ (1/4) * [N_k + 0 + alpha^2 * C(k)]
where N_k is the number of valid terms.

For k = p-1 (center, N_k = p):
b_{p-1} ≈ (1/4)(p + alpha^2 * C(p-1))

C(p-1) = sum_i s_i * s_{p-1-i} is the "anti-autocorrelation". For m-sequences, this is typically small (around -1 to a few units).

For k near 0 (N_k small):
b_0 = a_0^2 = ((1 + alpha*s_0)/2)^2

The maximum is likely at the center for large p.

J ≈ 2*p * (p + alpha^2*C(p-1))/4 / (p/2)^2 = 2*p*(p + alpha^2*C(p-1))/4 / (p^2/4)
  = 2*(p + alpha^2*C(p-1))/p = 2 + 2*alpha^2*C(p-1)/p

If C(p-1) < 0, this gives J < 2! For m-sequences, C(p-1) is typically negative (around -1 or so), so:
J ≈ 2 - 2*alpha^2/p

This is only slightly below 2, which isn't great.

**The fundamental problem**: For any sequence with a "dense" support (most entries non-zero), the convolution will have a peak at the center that's close to the sum of products. To get significantly below 2, we need the sequence to have a more structured pattern.

**What if we use a sparse sequence?**

- The convolution has at most m^2 non-zero terms (sparse)
- max_b is the maximum product sum at any lag

If the non-zero entries are all equal (value v), then sum_a = m*v.
The convolution at lag k is v^2 * (number of pairs (i,j) with a_i, a_j non-zero and i-j = k).

If the support is a "difference set" (like a Rao bound achieving set), then the number of pairs at each non-zero lag is approximately m/n (uniform), and the peak is at lag 0 with value v^2 (just one pair).

def lp_iteration(f, M):
    """
    Solve the LP: maximize sum(g) subject to (f*g)_k <= M for all k, g >= 0.
    Returns the optimal g.
    """
    n = len(f)
    
    # Build the sparse constraint matrix A for (f*g)_k <= M
    # (f*g)_k = sum_i f_i * g_{k-i} for valid i, k-i
    # For constraint k: sum_i f_i * g_{k-i} <= M
    # i ranges from max(0, k-n+1) to min(n-1, k)
    # Let j = k-i, so j ranges from k-min(n-1,k) to k-max(0,k-n+1) = max(0, k-n+1) to min(n-1,k)
    # Actually, let me think again.
    # (f*g)_k = sum_{i} f_i * g_{k-i} where 0<=i<n and 0<=k-i<n
    # So i >= 0, i < n, k-i >= 0, k-i < n
    # => i < n, i >= max(0, k-n+1), i <= k, i >= 0
    # So i from max(0, k-n+1) to min(k, n-1)
    # And the coefficient of g_j (where j = k-i) is f_i = f_{k-j}
    # So j from k - min(k, n-1) to k - max(0, k-n+1)
    # = max(0, k-n+1) to min(k, n-1)
    
    # The constraint is: sum_{j=max(0,k-n+1)}^{min(k,n-1)} f_{k-j} * g_j <= M
    
    # Build sparse matrix
    rows = []
    cols = []
    vals = []
    
    for k in range(2*n - 1):

        i_max = min(k, n - 1)
        for i in range(i_min, i_max + 1):

            rows.append(k)

    Smoothed subgradient descent to minimize max_k conv(a,a)_k
    subject to sum(a) = sum(a)_0, a >= 0.
    """
    n = len(a)
    s0 = a.sum()
    best = a.copy()
    best_score = np.convolve(a, a).max() / (s0**2)  # proportional to J
    
    for it in range(n_iters):
        b = np.convolve(a, a)
        max_b = b.max()
        # Softmax weights
        p = np.exp(tau * (b - max_b))
        p = p / p.sum()
        # Gradient
        grad = compute_grad(a, p)
        # Update
        eta = eta0 / (1 + it * 0.01)  # decreasing step size
        a = a - eta * grad
        # Project to non-negative
        a = np.maximum(a, 0)
        # Renormalize
        s = a.sum()
        if s > 0:
            a = a * s0 / s
        # Check improvement
        b = np.convolve(a, a)
        score = b.max() / (s0**2)
        if score < best_score:
            best = a.copy()
            best_score = score
    
    return best, best_score
