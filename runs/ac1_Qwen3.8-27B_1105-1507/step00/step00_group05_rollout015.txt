def compute_objective(x):
    """Compute J = 2*n*max(convolve(x,x))/sum(x)^2"""
    n = len(x)
    S = np.sum(x)
    if S < 1e-10:
        return np.inf
    b = np.convolve(x, x)
    max_b = np.max(b)
    return 2.0 * n * max_b / (S * S)

def fft_convolve(x):
    """Compute full convolution using FFT."""
    n = len(x)
    size = 2 * n - 1
    # Use next power of 2 for efficiency
    fft_size = 1
    while fft_size < size:
        fft_size *= 2
    X = np.fft.rfft(x, fft_size)
    B = X * X  # For real x, this gives the FFT of the convolution
    b = np.fft.irfft(B, fft_size)[:size]
    return b

def project_onto_simplex(v):
    """Project v onto {x: sum(x)=1, x>=0}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.where(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)

Now, the optimization:

minimize f(x) = 2n * max_k b[k] subject to sum(x)=1, x>=0.

Using subgradient method:
- At each step, find k* = argmax b.
- Compute g = grad_b_k(x, k*).
- Take step: x_new = x - alpha * g.
- Project: x_proj = project_onto_simplex(x_new).

The issue is that max is not differentiable, and the subgradient only gives information about one constraint. This can lead to oscillation.

A better approach: use a "smoothing" of the max. Instead of max(b), use a smooth approximation like the log-sum-exp:
f_ν(x) = (1/ν) * log(sum_k exp(ν*b[k]))

For large ν, this approximates max(b). The gradient is:
grad f_ν = (1/b_entropy) * sum_k b'[k] * exp(ν*b[k]) / sum_k exp(ν*b[k])

where b'[k] = grad b[k].

This gives a smooth objective that we can optimize with gradient descent.
