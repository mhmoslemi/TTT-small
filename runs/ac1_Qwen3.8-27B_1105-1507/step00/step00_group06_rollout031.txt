    n = len(a)
    b = get_convolution(a)

    sum_a = np.sum(a)
    if sum_a < 1e-10:

    """Compute subgradient of max(b) w.r.t. a."""
    n = len(a)

One more thought: I should also try "coordinate descent" as an alternative to subgradient. In coordinate descent, I update one element at a time. For a fixed a_{-i} (all elements except a_i), the objective as a function of x = a_i is:

T(x) = 2n * max_k (b_k^0 + d_k * x or x^2) / (S + x)^2

where S = sum_{j≠i} a_j, and d_k = 2*a_{k-i} (or d_k = 2x for k = 2i).

This is a 1D problem that can be solved by bisection or golden section search. But doing this for all n = 5582 coordinates in one pass would take 5582 * (cost of 1D optimization) which might be too slow.

However, I can do "random coordinate descent": pick a random coordinate each iteration and optimize it. This is O(1) per iteration (plus the cost of updating the convolution, which is O(n) if done incrementally).

If we change a_i by δ:
