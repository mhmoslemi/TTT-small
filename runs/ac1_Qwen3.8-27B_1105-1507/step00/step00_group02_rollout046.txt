```python
def optimize_weights(positions, n, alpha=0.01, max_iter=10000):
    m = len(positions)
    w = np.ones(m) / m  # initial equal weights
    for iter in range(max_iter):
        # Compute convolution
        seq = np.zeros(n)
        seq[positions] = w
        conv = np.convolve(seq, seq)
        max_k = np.argmax(conv)
        max_val = conv[max_k]
        
        # Compute subgradient
        subgrad = np.zeros(m)
        for i, pi in enumerate(positions):
            j_idx = max_k - pi
            if 0 <= j_idx < n:
                subgrad[i] += seq[j_idx]
        # Note: this counts ordered pairs, so subgrad[i] = sum_{j: pi+pj=k*} w_j
        
        # Update
        w = w - alpha * subgrad
        w = np.maximum(w, 0)
        if w.sum() > 0:
            w = w / w.sum()
        else:
            w = np.ones(m) / m
    
    return w
```

The question is: can max(conv) be less than (sum f)^2/n?

For the flat sequence, max(conv) = (sum f)^2/n exactly. To get below this, we need the convolution to be "flatter" than the flat sequence's convolution.

But the flat sequence's convolution is a triangle: [c^2, 2c^2, ..., n*c^2, ..., 2c^2, c^2]. The "average" of this triangle is (1/(2n-1)) * sum of triangle = (1/(2n-1)) * (sum f)^2 = n^2*c^2/(2n-1) ≈ n*c^2/2.

The peak is n*c^2, which is about 2x the average. To get a lower peak-to-average ratio, we need a "flatter" convolution.

But can we make the convolution flatter? The flat sequence already has a "natural" convolution shape (triangle). To make it flatter, we'd need to redistribute the energy.
