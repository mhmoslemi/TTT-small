import numpy as np

def project_simplex(v):
    """Project v onto the probability simplex using the Duchi et al. algorithm."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    r = np.arange(1, n + 1)
    cond = u - (cssv - 1.0) / r > 0
    if not np.any(cond):
        return v / v.sum()
    rho = np.where(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def make_two_lobe(n, ratio):

        return f, False

    if g_sum < 1e-15:

To minimize the peak, we want f to have low correlation with all its shifted-and-reversed versions. This is related to the concept of "low autocorrelation" sequences.

In radar/communications, "low autocorrelation" sequences (like Zadoff-Chu, etc.) are designed to have low peak sidelobe levels. But those are complex sequences. For real non-negative sequences, the problem is different.

For non-negative sequences, the "best" we can do is related to the "flat spectrum" problem. A sequence with a perfectly flat power spectrum (like a maximum length sequence, but those have positive and negative values) would have a delta-like autocorrelation.

For non-negative sequences, the "flattest" autocorrelation is achieved by sequences that are "as uniform as possible" while being non-negative. This circularly brings us back to the uniform sequence!
