**Pairwise swap approach:**
At each step:
1. Compute C and find k*.
2. Compute grad = grad C[k*] (a vector of length n).
3. Find a pair (i, j) such that moving mass from i to j (or vice versa) decreases C[k*] the most.
   Specifically, if we move δ from s[i] to s[j]: s[i] -= δ, s[j] += δ.
   The change in C[k*] is approximately δ * (grad[j] - grad[i]) (to first order).
   So we want grad[j] - grad[i] < 0, i.e., grad[j] < grad[i].
   The best pair is (i*, j*) = (argmax grad, argmin grad).
4. Determine the step size δ (by line search or a fixed fraction).
5. Update s.

This is essentially a "steepest descent" in the pairwise swap basis, which is a standard approach for simplex-constrained optimization.

    n = len(s)

        j_range = np.arange(j_min, j_max + 1)
        k_j = k_star - j_range
        grad[j_range] += s[k_j]
        mask = (k_j != j_range)
        grad[j_range[mask]] += s[j_range[mask]]
        
        # Find best pair to swap
        i = np.argmax(grad)  # position with highest grad (we want to decrease)
        j = np.argmin(grad)  # position with lowest grad (we want to increase)
        
        if grad[i] - grad[j] < tol:
            break
        
        # Determine step size
        # We want to find δ such that s[i] - δ >= 0 and the decrease is maximized.
        # To first order: ΔC ≈ δ * (grad[j] - grad[i]) < 0 (decrease)
        # To second order, we can do a line search.
        # For simplicity, use a fixed fraction:
        δ = min(s[i], 0.1 * s.mean())  # don't move too much at once
        # Actually, let's use a smarter step size
        δ = 0.5 * s[i]  # move half the mass
        
        s[i] -= δ
        s[j] += δ
        
    return s

            rho = np.where(v * np.arange(1, n+1) > (cssv - n))[0][-1]
            theta = (cssv[rho] - n) / (rho + 1)
            s = np.maximum(s_new - theta, 0)
            
            if t % 1000 == 0:
                print(f"  [{name}] iter {t}: score={score:.6f}, best={local_best_score:.6f}")
        
        if local_best_score < best_score:
            best_score = local_best_score
            best_s = local_best_s
            print(f"[{name}] New best: {best_score:.6f}")
    
    # Final verification
    final_score = float(evaluate_sequence([float(x) for x in best_s]))
    print(f"Final evaluated score: {final_score:.6f}")
    
    return [float(x) for x in best_s]

Wait, I realize there's a potential issue with the projected subgradient method. The learning rate schedule `lr = 1/sqrt(t)` is the standard one for subgradient methods, but it converges slowly (O(1/sqrt(T))). For a larger initial step, we might converge faster but risk oscillation.

Let me use a "backtracking line search" approach instead:
1. Try a step in the negative subgradient direction.
2. If the objective increases, halve the step size and retry.
3. This is more robust and often converges faster in practice.

Actually, for convex problems, the simplest and most robust approach is just the projected subgradient with a fixed or slowly decreasing step size. Let me use a "diminishing step size" with a larger initial value.

But wait, there's another issue. The objective `max_k C[k]` is not differentiable when multiple k values achieve the max. In that case, the subgradient is the average of the gradients of the active components. For the subgradient method to work well, we should use the full subdifferential (i.e., average over all active k values).

Let me modify: instead of using only the argmax, use the top-k values (or all values above a threshold) and average their gradients.
