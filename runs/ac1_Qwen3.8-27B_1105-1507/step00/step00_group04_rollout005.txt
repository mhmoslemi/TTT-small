```python
import numpy as np
import time
from scipy.optimize import linprog

def solve_lp(a, M):
    """Solve the LP to find the direction g."""
    n = len(a)
    # Maximize 1^T g = minimize -1^T g
    c = -np.ones(n)
    
    # Constraints: (a*g)[k] <= M for k = 0, ..., 2n-2
    # (a*g)[k] = sum_i a[i] * g[k-i] (with bounds 0 <= k-i < n)
    # This is a matrix times g: A[k,i] = a[k-i] if 0 <= k-i < n, else 0
    A = np.zeros((2*n-1, n))
    for k in range(2*n-1):
        for i in range(max(0, k-n+1), min(n, k+1)):
            A[k, i] = a[k-i]
    
    b = np.full(2*n-1, M)
    
    # Bounds: g >= 0
    bounds = [(0, None)] * n
    
    result = linprog(c, A_ub=A, b_ub=b, bounds=bounds, method='highs')
    if result.success:
        return result.x
    return None
```

Let me try a different approach. What if I use a longer sequence with a specific pattern?

Actually, let me reconsider the problem. The score is:
score = 2n * max(a*a) / (sum a)²

For large n, if we can make max(a*a) proportional to (sum a)²/n (like the uniform case gives exactly this), we get score = 2. To get score < 2, we need max(a*a) < (sum a)²/n.

The average value of (a*a)[k] is (sum a)²/(2n-1) ≈ (sum a)²/(2n). So the uniform case has max ≈ 2*average, while we want max < average * 2n/(2n-1) ≈ average.

Wait, that's not right. For the uniform case with a_i = c:
(a*a)[k] for k=0,...,n-1: (k+1)*c²
(a*a)[n-1] = n*c² (the max)
sum a = n*c
score = 2n * n*c² / (n*c)² = 2

The average of (a*a)[k] over all 2n-1 values is (n*c)²/(2n-1) ≈ n*c²/2 for large n.
The max is n*c². So max/average ≈ 2 for large n.

To get score = 1.5, we need max = 1.5/(2n) * (sum a)² = 1.5*n*c² (if sum = n*c).
So we need max(a*a) = 1.5 * n * c², but the uniform gives n*c². Wait, that's the opposite direction!

Let me redo. If sum(a) = S, then:
score = 2n * max(a*a) / S²
For uniform: max(a*a) = S²/n (since a_i = S/n, (a*a)[n-1] = n*(S/n)² = S²/n)
score = 2n * S²/n / S² = 2 ✓

For score = 1.5: max(a*a) = 1.5*S²/(2n) = 0.75*S²/n
So we need the peak to be 75% of the uniform case's peak. That means we need to reduce the peak by 25%.

The average of (a*a)[k] is S²/(2n-1). For the uniform case, the peak is S²/n ≈ 2*S²/(2n) = 2*average.
We want the peak to be 0.75*S²/n ≈ 1.5*average.

So we need the peak to be about 1.5 times the average, instead of 2 times. This means the convolution should be more "flat" than the uniform case.

This is the key insight: we need a sequence whose autocorrelation is flatter than that of the uniform sequence.

For the uniform sequence, the autocorrelation is triangular: it rises linearly to the peak and falls linearly. We want something flatter at the top.

One way to achieve this is to use a sequence that's approximately constant but with small oscillations that "fill in" the edges of the autocorrelation triangle while "reducing" the peak.

Actually, I think the right approach is to use a sequence whose DFT has specific properties. The autocorrelation is the inverse DFT of |DFT(a)|². So we want |DFT(a)|² to be as flat as possible (which would make the autocorrelation a delta function, but that's impossible for non-negative sequences).

For non-negative sequences, the DFT at frequency 0 is real and positive (it's the sum). The DFT at other frequencies can be complex.

The constraint that a ≥ 0 means that the inverse DFT of |DFT(a)|² (which is the autocorrelation) must be non-negative... wait, no. The autocorrelation of a non-negative sequence is always non-negative (it's a sum of products of non-negative numbers). So that's not a useful constraint.

Let me think about this differently. The problem is:
Minimize max_k (a*a)[k] subject to a ≥ 0, sum(a) = 1.

This is equivalent to: find a non-negative probability distribution a on {0,...,n-1} that minimizes the maximum probability mass function of the sum of two independent random variables with that distribution.

This is a beautiful reformulation! We're looking for a distribution on {0,...,n-1} that makes the sum X+Y (where X,Y are i.i.d. with that distribution) as "spread out" as possible (minimizing the pointwise maximum of the PMF).

The sum X+Y has support {0, 1, ..., 2n-2}. We want its PMF to be as flat as possible.

For the uniform distribution on {0,...,n-1}, X+Y has a triangular PMF with peak at n-1.

To make it flatter, we want to "push mass" from the center of the convolution to the edges. This means we want a distribution that puts more mass at the edges (0 and n-1) and less in the middle.

But wait, if we put too much mass at the edges, the convolution at 0 (which is a[0]²) and at 2n-2 (which is a[n-1]²) will be large.

So the optimal distribution should balance: reduce the central peak while not making the edge peaks too large.

This is a well-studied problem in probability! It's related to the "flat sum" problem or "minimum peak convolution" problem.

I recall that for this type of problem, the optimal solution often involves a distribution that's close to uniform but with a slight "bowl" shape (slightly higher at the edges, slightly lower in the middle).
