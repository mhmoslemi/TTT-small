**Smarter approach: "Capping" or "Water-filling"**

Instead of gradient descent, we can try to directly flatten the convolution:
1. Compute c = convolve(a, a)
2. Let M = max(c), target = mean(c) = S²/(2n-1)
3. For each lag k where c[k] > target, we want to reduce c[k]
4. The "coupling" between c[k] and a[m] is through the pairs (m, k-m)
5. We can set up a system: reduce c[k] for peak lags by adjusting a

This is essentially a nonlinear system. A simpler version:
- Identify the top few peaks
- For each peak at lag k, the "easiest" way to reduce it is to reduce a[m] where m is at a position that appears in many peaks
- But we also need to not create new peaks

This is getting complex. Let me just go with a well-tuned subgradient method plus some heuristics.

**Another idea: Use the DFT for efficiency**

Since convolution is multiplication in the frequency domain, we can:
1. Compute A = FFT(a, 2n-1) (or 2n for efficiency)
2. C = |A|² (element-wise)
3. c = IFFT(C).real[:2n-1]

This gives the full convolution in O(n log n) time.
