Since $a = (1/n) \mathbf{1}$, the constraint is $\frac{1}{n} \sum_{i} g_{k-i} \le 1/n$, i.e., $\sum_i g_{k-i} \le 1$ for each $k$.

This means the "sliding window sum" of $g$ (window of size $n$) must be $\le 1$. To maximize $\sum g$, we want to spread the mass of $g$ as much as possible while keeping the sliding window sum $\le 1$.

The optimal solution is $g_j = 1/n$ for all $j$ (the same as $a$)! So the best response of a uniform sequence is itself. This means the uniform sequence is a fixed point of the best-response iteration. It's a Nash equilibrium of the "game" but not the global optimum.

So the LP approach starting from uniform won't help. We need a good initial point.

**New idea: Start from a structured non-uniform sequence.**

What if the sequence has a "tent" shape? Like $a_j = 1 - |j - (n-1)/2| / ((n-1)/2)$ (triangular, peaked in the middle)?

Or what about a "U" shape (low in the middle, high at the edges)?

Let me think about this differently. The convolution $c_k = \sum_i a_i a_{k-i}$. For the peak to be small, we want no two elements of $a$ to "align" and create a large product-sum.

One heuristic: if $a$ is "sparse" (many zeros), then the convolution has many zeros and the peaks are smaller. But the sum constraint means the non-zero elements must be large, which increases the peak.

Another heuristic: if $a$ has a "fractal" or "self-similar" structure, the convolution might be more spread out.

    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = np.fft.fft(a, fsize)
    C = np.fft.ifft(A * A).real[:size]
    return C
