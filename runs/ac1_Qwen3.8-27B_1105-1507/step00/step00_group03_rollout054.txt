**Key idea**: The score is determined by the maximum convolution value. If we can identify which convolution lag is the maximum, we can specifically target that lag for reduction.

**Algorithm: Targeted perturbation**

1. Compute the convolution and find the argmax.
2. Generate a perturbation that specifically reduces the value at that lag.
3. Accept if the overall score improves.

For lag k being the maximum, b_k = sum_i a_i a_{k-i}. To reduce b_k, we want to decrease the products a_i a_{k-i}. One way: for each pair (i, k-i), decrease a_i if a_{k-i} is large, and vice versa.

This is essentially a "destabilizing" move: we want to make the sequence less "self-similar" at shift k.

Let me implement this:

**Approach: Use the Lagrange dual / KKT conditions.**

At the optimum (interior), we have:
- For all i: a_i > 0
- The constraint sum a_i = 1 is active
- The constraint max_k b_k = t is active at some set of lags S

By KKT: the gradient of the objective w.r.t. a_i should be proportional to 1 (from the sum constraint) plus a combination of the gradients of the active b_k constraints.

∂t/∂a_i = sum_{k in S, active} lambda_k * ∂b_k/∂a_i

∂b_k/∂a_i = a_{k-i} + a_{i-k} (if both in range, with care for boundaries)

So at the optimum: sum_{k in S} lambda_k * (a_{k-i} + a_{i-k}) = constant (for all i)

This is a system of equations that determines the optimal a_i. But we don't know S (the set of active constraints) a priori.

**Practical approach: Iterate on the active set.**

1. Start with a guess for S (e.g., S = {n-1} only, the center).
2. Solve for a_i that satisfies the KKT conditions with this S.
3. Check if the solution is valid (a_i >= 0, and b_k <= t for all k not in S).
4. If not, update S and repeat.

For S = {n-1}:

This means a_{n-1-i} = mu/lambda = constant for all i.
So a is constant (uniform)! Which gives score = 2.

    """Compute gradient of sum(b_k^2) w.r.t. a."""
    n = len(a)
    L = 1
    while L < 3*n:
        L *= 2
    
    A = np.fft.rfft(a, L)
    B = np.fft.rfft(b, L)
    
    # Part 1: cross_correlation of a and b: sum_m a[m]*b[m+i]
    # In FFT: ifft(conj(A) * B)[i] gives sum_m a[m]*b[(m+i) % L]
    # For linear: we need the "unwrapped" version
    part1 = np.fft.irfft(np.conj(A) * B, L)[:n]

    # ifft(A * conj(B))[i] gives sum_m a[m]*b[(i-m) % L]
    part2 = np.fft.irfft(A * np.conj(B), L)[:n]
    
    return 2 * (part1 + part2)
