**DFT-based approach:**

Let $N = 2n - 1$ (the length of the convolution). Let $\hat{p}_m = \sum_{k=0}^{n-1} p_k \omega^{km}$ where $\omega = e^{2\pi i / N}$.

Then $(p*p)[m] = \frac{1}{N} \sum_{\ell=0}^{N-1} |\hat{p}_\ell|^2 \omega^{-\ell m}$.

We want to minimize $\max_m (p*p)[m]$.

This is related to the "peak-to-average power ratio" (PAPR) of the sequence $|\hat{p}_\ell|^2$. If $|\hat{p}_\ell|$ is constant, then $p*p$ is a delta function (at lag 0), which is the opposite of what we want. We want $p*p$ to be flat, which means $|\hat{p}_\ell|^2$ should be concentrated at $\ell = 0$.

$|\hat{p}_0|^2 = (\sum p_k)^2 = 1$ (since $\sum p = 1$).
$\sum_\ell |\hat{p}_\ell|^2 = N \cdot \sum_k p_k^2$ (by Parseval).

If $p$ is uniform, $\sum p_k^2 = 1/n$, so $\sum_\ell |\hat{p}_\ell|^2 = N/n = (2n-1)/n \approx 2$.

For $p*p$ to be flat, we need $|\hat{p}_\ell|^2$ to be as concentrated as possible at $\ell = 0$. But $|\hat{p}_0|^2 = 1$ and $\sum_\ell |\hat{p}_\ell|^2 \approx 2$, so at most half the "energy" is at $\ell = 0$. The rest must be spread among the other $N-1$ frequency bins.

If the remaining energy is spread uniformly: $|\hat{p}_\ell|^2 = 1/(N-1)$ for $\ell \neq 0$.
Then $(p*p)[m] = \frac{1}{N} (1 + \sum_{\ell \neq 0} \frac{1}{N-1} \omega^{-\ell m})$.
For $m = 0$: $(p*p)[0] = \frac{1}{N} (1 + 1) = 2/N$.
For $m \neq 0$: $(p*p)[m] = \frac{1}{N} (1 - \frac{1}{N-1}) = \frac{1}{N} \cdot \frac{N-2}{N-1} \approx 1/N$.

import time

def convolve_fft(p):
    """Compute p*p using FFT for efficiency."""
    n = len(p)
    N = 1
    while N < 2 * n - 1:
        N *= 2
    F = np.fft.rfft(p, N)
    conv = np.fft.irfft(F * F, N)
    return conv[:2*n-1]

def mul_weight_update(p, m_star, eta):
    """Multiplicative weight update."""
    n = len(p)
    k_lo = max(0, m_star - (n - 1))
    k_hi = min(n - 1, m_star)
    g = np.zeros(n)
    if k_lo <= k_hi:
        ks = np.arange(k_lo, k_hi + 1)
        g[m_star - ks] = p[ks]

    log_p = np.log(np.maximum(p, 1e-300))
    log_p -= eta * g
    log_p -= log_p.max()
    new_p = np.exp(log_p)
    s = new_p.sum()
