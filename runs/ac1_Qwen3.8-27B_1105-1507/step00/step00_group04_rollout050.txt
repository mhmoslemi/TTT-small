                idx = k - j
                if 0 <= idx < len(a):

        a = a - lr * grad

        a = np.maximum(a, 0)
        S = np.sum(a)
        if S > 0:
            a = a / S
        else:
            a = np.ones(len(a)) / len(a)
    
    return a

def fast_convolution(a):

    n = len(a)

Actually, let me try a completely different angle. What if I formulate this as a sequence of quadratic programs?

The problem $\min_a \max_k C[k]$ s.t. $a \geq 0$, $\sum a = 1$ can be written as:
$\min_a t$ s.t. $C[k](a) \leq t$ for all $k$, $a \geq 0$, $\sum a = 1$.

Since $C[k]$ is quadratic, this is a non-convex QP. But we can linearize around the current point $a_0$:
$C[k](a_0 + d) \approx C[k](a_0) + \nabla_{a_0} C[k] \cdot d$

Then solve:
$\min_d t$ s.t. $C[k](a_0) + \nabla_{a_0} C[k] \cdot d \leq t$ for all $k$, $a_0 + d \geq 0$, $\sum (a_0 + d) = 1$

This is a linear program! We can solve it with scipy or cvxpy.

The LP has:
- Variables: $d \in \mathbb{R}^n$ and $t \in \mathbb{R}$
- Constraints: $C[k](a_0) + \nabla C[k] \cdot d \leq t$ for $k = 0, \ldots, 2n-2$ (that's $2n-1$ constraints)
- $a_0[j] + d[j] \geq 0$ for $j = 0, \ldots, n-1$ ($n$ constraints)
- $\sum (a_0[j] + d[j]) = 1$ (1 constraint)

Total variables: $n + 1$. Total constraints: $2n - 1 + n + 1 = 3n$.

For $n = 1000$, that's 1001 variables and 3000 constraints. This is a manageable LP!
