One more optimization: instead of computing the full convolution and then the gradient, I can compute both in one FFT pass:
1. `A = FFT(a, L)` where L >= 2n-1.
2. `B = A^2` (in frequency domain).
3. `b = IFFT(B).real[:2n-1]` (the full convolution).
4. Compute `w` from `b`.
5. `W = FFT(w, L2)` where L2 >= len(w) + n - 1 = 3n-2.
6. `A2 = FFT(a, L2)`.
7. `p = IFFT(W * conj(A2)).real[:n]`.
8. `grad = 2 * p`.

This is two FFT pairs, each O(n log n). Very fast.

Actually, I realize I can combine steps 5-7 more efficiently. Let me use the same L for both:
- L = next_power_of_2(3n-2) (large enough for both convolutions).
- `A_full = FFT(a, L)` (a zero-padded to L).
- `B_full = A_full^2`.
- `b = IFFT(B_full).real[:2n-1]`.
- Compute `w` from `b`, zero-pad to L.
- `W = FFT(w, L)`.
- `p = IFFT(W * conj(A_full)).real[:n]`.

This way, I only need one FFT of `a` (reused). Total: 2 forward FFTs + 2 inverse FFTs of length L.

For n = 5000, L = next_power_of_2(15000-2) = 16384. Each FFT is ~100K operations. Very fast.
