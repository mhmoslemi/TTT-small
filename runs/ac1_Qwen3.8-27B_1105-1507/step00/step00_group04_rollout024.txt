The gradient of $q[k]$ with respect to $p[j]$ is $p[k-j]$ (for valid indices). So:
$\frac{\partial q[k]}{\partial p[j]} = p[k-j]$ (if $0 \leq k-j < n$, else 0).

The gradient of $\max_k q[k]$ with respect to $p[j]$ is $p[k^*-j]$ where $k^*$ is the argmax.

A simple gradient descent step would be:
$p[j] \leftarrow p[j] - \eta \cdot p[k^*-j]$

But this might make $p[j]$ negative. We need a constrained update.

A better approach: **multiplicative update** (like EM or Sinkhorn):
$p[j] \leftarrow p[j] \cdot \exp(-\eta \cdot p[k^*-j])$

This keeps $p[j] > 0$ and reduces the values at positions that contribute most to the peak.

After each update, renormalize: $p \leftarrow p / \sum p$.

Or more practically, use a softmax over the lags:
$w[k] = \exp(q[k]/\tau) / \sum_k' \exp(q[k']/\tau)$ for some temperature $\tau$.

Then the "effective gradient" is $\sum_k w[k] p[k-j]$.

Update: $p[j] \leftarrow p[j] \cdot \exp(-\eta \cdot \sum_k w[k] p[k-j])$.

import numpy as np
import time
from scipy.optimize import linprog

def compute_conv(a):
    """Compute full linear convolution of a with itself."""
    return np.convolve(a, a)

def lp_peak_reduction(f, M, maxiter=100):
    """
    Solve the LP to find g that maximizes sum(g) subject to:
    - g >= 0
    - (f * g)[k] <= M for all k
    Returns g (unnormalized).
    """
    n = len(f)
    # Variables: g_0, ..., g_{n-1}
    # Objective: maximize sum(g) => minimize -sum(g)
    c = -np.ones(n)
    
    # Constraints: (f * g)[k] <= M for k = 0, ..., 2n-2
    # (f * g)[k] = sum_i f[i] * g[k-i] (valid i)
    # For each k, this is a linear function of g.
    
    # Build the constraint matrix A_ub
    # A_ub[i, j] is the coefficient of g_j in the constraint for k=i
    # (f*g)[k] = sum_{j: 0<=k-j<n} f[k-j] * g[j]
    # So A_ub[k, j] = f[k-j] if 0 <= k-j < n, else 0
    
    A_ub = np.zeros((2*n-1, n))
    for k in range(2*n-1):
        # j ranges from max(0, k-(n-1)) to min(n-1, k)
        j_min = max(0, k - (n-1))
        j_max = min(n-1, k)
        for j in range(j_min, j_max+1):
            A_ub[k, j] = f[k-j]
    
    b_ub = np.full(2*n-1, M)
    
    # Bounds: g_j >= 0
    bounds = [(0, None)] * n
    
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    
    if res.status != 0:
        return None
    
    return res.x
