Let me think about this problem from the perspective of the DFT. The linear convolution (a*a) can be computed as IFFT(FFT(a) * FFT(a)) with zero-padding. Specifically, if we zero-pad a to length 2n-1 (or more), then FFT(a_padded) * FFT(a_padded) and IFFT gives the linear convolution.

The maximum of the linear convolution is the L_infinity norm of IFFT(|FFT(a)|^2) (with appropriate zero-padding). We want to minimize this.

This is related to the "peak-to-average power ratio" (PAPR) problem in OFDM! In OFDM, you have a signal x = IFFT(X) where X is the frequency-domain data, and you want to minimize the PAPR = max|x|^2 / mean|x|^2.

Here, our "signal" is the convolution c = IFFT(|FFT(a_padded)|^2), and we want to minimize max|c| / mean|c| (approximately, since sum c = (sum a)^2 and there are 2n-1 values).

- Tone reservation

   (b) Update multiple coordinates at a time.
   (c) Use a different approach.

   Let's go with (a): minimize max_k (a*a)_k / (sum a)^2 subject to a >= 0. This is equivalent to minimizing max_k (a*a)_k subject to sum a = 1, a >= 0.

   In coordinate descent with the ratio form:
   - Fix a_j for j ≠ i, let S = sum_{j≠i} a_j, Q_k = (a*a)_k - a_i * C_k (the part not involving a_i).
   - The objective as a function of a_i (with a_i >= 0):
     f(t) = max_k (Q_k + t * C_k) / (S + t)^2
   - We want to minimize f(t) over t >= 0.

   This is a 1D optimization problem. The function is the max of functions of the form (Q_k + t*C_k)/(S+t)^2, each of which is unimodal (or at least has a simple structure).

   Let's analyze g_k(t) = (Q_k + t*C_k)/(S+t)^2.
   g_k'(t) = [C_k(S+t)^2 - (Q_k + t*C_k)*2(S+t)] / (S+t)^4
   = [(S+t)(C_k(S+t) - 2(Q_k + t*C_k))] / (S+t)^4
   = [C_k(S+t) - 2Q_k - 2t*C_k] / (S+t)^3
   = [C_k*S + C_k*t - 2Q_k - 2t*C_k] / (S+t)^3
   = [C_k*S - C_k*t - 2Q_k] / (S+t)^3
   = [t*(C_k) - C_k*S + 2Q_k] / (S+t)^3 ... let me redo.
   
   = [C_k*S - C_k*t - 2Q_k] / (S+t)^3

   Setting to 0: C_k*S - C_k*t - 2Q_k = 0 → t = (C_k*S - 2Q_k)/C_k = S - 2Q_k/C_k (if C_k ≠ 0).

   So each g_k is unimodal (decreases then increases, or vice versa) with a critical point at t_k = S - 2Q_k/C_k.

   The max of these is also unimodal (the max of unimodal functions with the same "center" tendency). So we can use golden section search or ternary search to find the optimal t.

   Actually, the max of unimodal functions is not necessarily unimodal. But in practice, it should be well-behaved.

3. **Water-filling / level-set approach**:

The idea is: given a target level T, find a >= 0, sum a = 1 such that (a*a)_k <= T for all k. If we can find the smallest such T, that gives us the optimal solution.

The feasibility problem "exists a >= 0, sum a = 1, (a*a)_k <= T for all k" can be attacked iteratively:
- Start with a = ones(n)/n.
- If (a*a)_k > T for some k, reduce the "energy" at positions that contribute to c_k.
- Specifically, for each k where c_k > T, we want to reduce sum_{i+j=k} a_i a_j. This can be done by reducing a_i and a_{k-i} for the pairs (i, k-i) that contribute most.

This is like a "pressure" model: positions with high convolution values "push back" on the a_i values.

Algorithm:
1. Set T = current max convolution value.
2. Iterate:
   a. For each k with c_k > T, compute the "excess pressure" e_k = c_k - T.
   b. Distribute this pressure to the contributing a_i values.
   c. Update a_i proportional to the pressure.
   d. Project to a >= 0, sum a = 1.
3. After convergence, reduce T and repeat.

This is getting complicated. Let me just go with the subgradient approach and make it work with good hyperparameters.

4. **Alternative: Use scipy optimization**:

We can formulate this as:
minimize max_k (a*a)_k
subject to sum a = 1, a >= 0

Using scipy.optimize.minimize with the 'SLSQP' method, defining the objective as max_k (a*a)_k and the constraints. But scipy's optimizers might be too slow for n=5582.

Actually, we can use a "smoothed max" approximation:
max_k c_k ≈ (1/alpha) * log(sum_k exp(alpha * c_k))

for large alpha. This makes the problem smooth and amenable to gradient-based optimization. The gradient is:
d/d a_i [log sum_k exp(alpha * c_k) / alpha] = (1/alpha) * sum_k c_k' * exp(alpha * c_k) / sum_k exp(alpha * c_k)

where c_k' = d c_k / d a_i = 2 * a[k-i] (as before).

This is essentially a "softmax-weighted" subgradient, which is smoother than the hard max subgradient.

Let me implement this approach:

This is like an expectation over the "active" positions, weighted by their proximity to the max. It's smoother and might converge faster.
