This is equivalent to wanting `(FFT(a))^2` to be as flat as possible (by convolution theorem), i.e., `|FFT(a)|^2` should be flat AND the phase of `FFT(a)` should be approximately constant (or vary linearly).

For a random sequence, `|FFT(a)|^2` is already approximately flat (by CLT), but the phase is random. The self-convolution `b = IFFT((FFT(a))^2)` will have fluctuations due to the random phase.

To reduce these fluctuations, we need to control the phase of FFT(a). This is where the optimization comes in.

An alternative approach: **iterative spectral interference cancellation**
1. Compute `F = FFT(a)`.
2. Compute `F^2` (this corresponds to the spectrum of the self-convolution).
3. We want `IFFT(F^2)` to be flat.
4. Equivalently, we want `F^2` to be as close to a constant as possible.
5. Update: modify the phase of F to make F^2 more constant.

This is reminiscent of the "phase-only" iterative methods in optics/x-ray crystallography.
