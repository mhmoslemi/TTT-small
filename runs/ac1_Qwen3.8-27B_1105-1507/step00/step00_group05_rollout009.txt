```python
    n = len(s)
    b = np.convolve(s, s)
    max_b = np.max(b)
    sum_a = np.sum(s)
```

```python
def optimize_sequence(n, T=15, K=5, alpha0=0.1, num_iters=10000):
    s = np.ones(n) / n  # normalized to sum = 1
    best_s = s.copy()
    best_J = evaluate(s)
    
    for t in range(num_iters):
        b = np.convolve(s, s)
        # Find top K lags
        top_idx = np.argpartition(b, -K)[-K:]
        # Compute gradient
        grad = np.zeros(n)
        for k in top_idx:
            for i in range(n):
                j = k - i
                if 0 <= j < n:
                    grad[i] += s[j]

        grad -= np.mean(grad)
        # Adaptive step size
        alpha = alpha0 / (1 + t * 0.001)

        s_new = s - alpha * grad
        s_new = np.maximum(s_new, 0)
        s_sum = s_new.sum()
        if s_sum < 1e-6:
            break
        s_new /= s_sum
        s = s_new
        J = evaluate(s)
        if J < best_J:
            best_J = J
            best_s = s.copy()
    
    return best_s, best_J
```

The inner loop `for i in range(n): j = k-i; if 0 <= j < n: grad[i] += s[j]` is O(n) per lag, so O(K*n) per iteration. Combined with the O(n^2) convolution, the total per iteration is O(n^2 + K*n) ≈ O(n^2).

The values k-i for i in [i_start, i_end] are: k-i_start, k-i_start-1, ..., k-i_end (decreasing).
k-i_start = k - max(0, k-n+1)

i_start = k-n+1, i_end = n-1
k-i ranges from k-(k-n+1) = n-1 down to k-(n-1) = k-n+1

So grad[k-n+1] += s[n-1], grad[k-n+2] += s[n-2], ..., grad[n-1] += s[k-n+1].

In numpy: grad[k-n+1:] += s[n-1:k-n-1:-1] = s[n-1], s[n-2], ..., s[k-n+1]

Let me verify: s[n-1:k-n-1:-1] in numpy gives s[n-1], s[n-2], ..., s[k-n+1] (n-1-(k-n+1)+1 = n-k-1... wait that doesn't seem right for the length).

The length of grad[k-n+1:] is n - (k-n+1) = 2n-1-k.
The length of s[n-1:k-n-1:-1] is n-1-(k-n+1)+1 = n-1-k+n-1+1 = 2n-k-1. Hmm, that's the same! 2n-1-k = 2n-k-1. Yes.

So:
Case 1 (k < n): grad[0:k+1] += s[k::-1]
Case 2 (k >= n): grad[k-n+1:n] += s[n-1:k-n-1:-1]

Wait, for k = n-1: Case 1 gives grad[0:n] += s[n-1::-1] = s[n-1], s[n-2], ..., s[0].
Case 2 would give grad[0:n] += s[n-1:-2:-1] = s[n-1], s[n-2], ..., s[0]. Same thing! Good.

Let's verify: for k=n, i ranges from n-n+1=1 to n-1. k-i ranges from n-1 to 1.
grad[1] += s[n-1], grad[2] += s[n-2], ..., grad[n-1] += s[1]. Yes!

Great, so the vectorized gradient computation is:

```python
def compute_gradient(s, top_lags):
    n = len(s)
    grad = np.zeros(n)
    for k in top_lags:
        if k < n:
            grad[0:k+1] += s[k::-1]
        else:
            grad[k-n+1:n] += s[n-1:k-n-1:-1]
    return grad / len(top_lags)
```

Actually wait, I need to reconsider. The peak-to-average ratio R = max_b / (sum_b/(2n-1)) = max_b * (2n-1) / sum_a^2.

J = 2*n*max_b/sum_a^2 = 2*n*R/(2n-1) ≈ R for large n.

But R depends on the sequence shape, not just n. So for a fixed shape (e.g., all-ones with sinusoidal perturbation), R might be approximately constant for large n. But the optimization landscape might be different for different n, and we might find a better shape for a specific n.

Let me also think about what the optimal shape might look like. For the all-ones sequence, the autocorrelation is a triangle. To make it flatter, we need to add "wiggles" to the sequence. The wiggles should be at frequencies that cause destructive interference at the peak of the autocorrelation.

The peak of the all-ones autocorrelation is at the center (lag n-1). The "shape" of the peak is triangular. To flatten it, we want to add a negative contribution at the center. Since the sequence must be non-negative, we can't directly add a negative contribution. But we can redistribute: make some elements larger and others smaller, such that the products s[i]*s[n-1-i] are reduced on average.

A sinusoidal perturbation s[i] = 1 + eps*sin(2*pi*m*i/n) would create a "ripple" in the autocorrelation. The question is whether this ripple reduces the overall max.

For the all-ones sequence, the autocorrelation is:
b[k] = n - |k - (n-1)| for k = 0, ..., 2n-2
This is a triangle with peak n at k = n-1.

Adding a sinusoidal perturbation:
s[i] = 1 + eps*sin(2*pi*m*i/n)
b[k] = sum_i s[i]*s[k-i] ≈ (n-|k-(n-1)|) + eps^2 * (correlation of the sinusoid at appropriate lag) + cross terms

The cross terms (linear in eps) will create a modulation of the triangle. The eps^2 term will create a small "bump" at specific lags.

For the purpose of reducing the max, the linear terms are more important (for small eps). The linear term at lag k is:
eps * (sum of sin over a range + sum of sin over a shifted range)

For a sinusoid with frequency m, the sum over a range of length L is approximately (L * sin(pi*m*L/n)) / (n * sin(pi*m/n)) (if the range is in the middle).

def fast_objective(s):
    """Compute J = 2*n*max(conv(s,s))/sum(s)^2 without safety checks."""
    n = len(s)
    b = np.convolve(s, s)
    max_b = b.max()
    sum_a = s.sum()
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)

def top_k_gradient(s, K=5):
    """Compute gradient of max(conv(s,s)) using top K lags."""
    n = len(s)
    b = np.convolve(s, s)
    # Get top K indices
    if K >= len(b):

    else:
