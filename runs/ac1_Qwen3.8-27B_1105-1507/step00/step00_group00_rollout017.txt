    """Gradient of (a*a)_k w.r.t. a."""
    n = len(a)
    lo = max(0, k - n + 1)
    hi = min(n - 1, k)
    grad = np.zeros(n)
    idx = np.arange(lo, hi + 1)
    grad[idx] = a[k - idx] + a[idx]

def _score_normalized(a):
    """Score assuming sum(a) = 1. Returns 2*n*max(conv)."""
    n = len(a)
    C = np.convolve(a, a)
    return 2.0 * n * C.max()

def _initializations(n, rng):

    inits = []
    
    # Uniform
    inits.append(np.ones(n) / n)
    
    # Triangular (Bartlett)
    if n % 2 == 1:

        tri = 1.0 - tri / (n/2.0)

    inits.append(tri / tri.sum())
    
    # Raised cosine (Hanning)

    hanning = 0.5 * (1 + np.cos(2 * np.pi * t))

    inits.append(hanning / hanning.sum())
    
    # Parabolic

    para = 1.0 - (2*t - 1)**2
    para = np.clip(para, 0.05, None)
    inits.append(para / para.sum())
    
    # Sine window
    t = np.arange(n) / n
    sine = np.sin(np.pi * t)

The key insight is that the problem is to make the linear autocorrelation as flat as possible. For a sequence of length $n$, the autocorrelation has $2n-1$ values summing to $S^2 = 1$ (when normalized). The ideal is all values equal to $1/(2n-1)$.

The gradient descent approach works by:
1. Computing the current autocorrelation
2. Finding the "hottest" lags (where the autocorrelation is above average)
3. Taking a gradient step to reduce those peaks

The gradient at a "hot" lag $k^*$ tells us which elements to decrease. Since $\partial C_{k^*}/\partial a_i = a_{k^*-i} + a_i$, decreasing $a_i$ reduces $C_{k^*}$.

But this is a bit like "chasing" the max: we reduce the current max, but then a different lag becomes the max, and we chase that. This might oscillate.

A better approach might be to use a "repulsion" model: think of each lag as a "particle" that we want to push down to the target level $1/(2n-1)$. The force on $a_i$ is the sum of forces from all lags where $a_i$ appears.

Let me think about this more carefully. The "energy" we want to minimize is:
$E(a) = \sum_k \max(0, C_k - t)^2$ for some threshold $t$ (e.g., $t = 1/(2n-1)$).

The gradient of this is:
$\partial E / \partial a_i = 2 \sum_k \max(0, C_k - t) \cdot \partial C_k / \partial a_i$
$= 2 \sum_k \max(0, C_k - t) \cdot (a_{k-i} + a_i)$ (for valid $k-i$)

This is a weighted sum of gradients, where the weight is how much each lag exceeds the target. This should be more stable than just chasing the single max.

But it's also $O(n^2)$ to compute (sum over all $2n-1$ lags, each requiring $O(n)$ work). For $n = 10000$, this is $O(n^2) = 10^8$ per iteration, which might be too slow.

A compromise: use only the top $K$ lags that exceed the target, where $K$ is small (e.g., 10-50). This is $O(Kn)$ per iteration.
