30. **A better analytical approach**:

Let me think about this problem from the perspective of the "Welch bound" or "sidelobe" theory.

We want to minimize max(a*a) / (sum a)^2 for non-negative a of length n.

This is equivalent to: find a non-negative sequence a with sum(a) = 1 that minimizes max(a*a).

The constraint sum(a) = 1 and a >= 0 defines a simplex. The function max(a*a) is convex (as the max of quadratic functions). So we're minimizing a convex function over a convex set, which means the minimum is at a unique point (or a face of the simplex).

At the optimum, the "active" convolution values (those that achieve the max) determine the solution.

If at the optimum, all convolution values are equal to some M, then:
sum_k (a*a)[k] = (2n-1)*M = (sum a)^2 = 1
So M = 1/(2n-1).
This gives objective = 2n/(2n-1) ≈ 1.

But as discussed, this is not achievable for non-negative sequences (except trivial cases).

The next best: M positions achieve the max, and the rest are lower. At the optimum, the gradient condition says:
For each active position m_j: 2*a[m_j - i] = λ + μ[i] (where μ[i] >= 0 is the multiplier for a[i] >= 0).

If no a[i] = 0 at the optimum (interior solution), then:
a[m_j - i] = λ/2 for all j and all i.
This means a is constant, which gives the uniform solution with M = 1/n.

So the optimal non-trivial solution must have some a[i] = 0 (on the boundary of the simplex).
