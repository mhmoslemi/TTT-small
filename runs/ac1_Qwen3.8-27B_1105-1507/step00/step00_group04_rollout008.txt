Now, for the local search, I need to be careful about memory and time. For a sequence of length n, each evaluation takes O(n log n) (with FFT) or O(n^2) (direct conv). For n=5000, that's about 25 million operations for direct conv, which should take a few ms.

Let me think about what local search moves to use:
1. Single element perturbation: change one element slightly. This is O(n) per evaluation (since the convolution changes only in a local region). But we'd still need to recompute the full convolution to find the max, unless we track where the max is.

2. Block perturbation: change a block of elements. Similar considerations.

3. Gradient-based: estimate the gradient of J with respect to each element. This requires 2n evaluations (forward and backward differences), which is expensive for large n.

4. A smarter approach: note that J = 2n * max_b / sum^2. If we know where the max is (say at position k*), then J is determined by b[k*] and sum. We can compute the gradient of b[k*] with respect to each a[i]:
   db[k*]/da[i] = a[k*-i] (if k*-i is in range)
   
   And d(sum^2)/da[i] = 2*sum*a[i]... wait, d(sum^2)/da[i] = 2*sum.
   
   So dJ/da[i] = 2n * [da[i]*a[k*-i] * sum^2 - max_b * 2*sum*a[i]] / sum^4
   = 2n / sum^3 * [a[i]*a[k*-i]*sum - 2*max_b*a[i]]
   = 2n*a[i] / sum^3 * [a[k*-i]*sum - 2*max_b]

Wait, this is only valid if the max position k* doesn't change when we perturb a[i]. If it does change, the gradient is different. But for small perturbations, the max position should be stable.

This gives us an analytical gradient (assuming fixed max position)! We can use this for gradient descent.

But we need to be careful: the max position might change, in which case the gradient is wrong. A practical approach is to:
1. Compute the current max position k*.
2. Use the gradient (assuming fixed k*) to propose a step.
3. Evaluate the actual new score.
4. If it improved, accept; otherwise, backtrack.

This is similar to a "gradient descent with line search" but with the caveat that the gradient might be wrong if the max position changes.
