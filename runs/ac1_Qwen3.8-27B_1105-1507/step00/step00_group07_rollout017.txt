**Approach: Use the structure of the problem to design a custom iterative algorithm.**

The constraint C_k <= t for all k can be written as:

This is a system of quadratic inequalities. For non-negative a, each C_k is a monotone increasing function of each a[i] (since all terms are products of non-negative numbers). So if we increase any a[i], all C_k that involve a[i] increase.

This monotonicity is useful! It means that if we have a feasible point a, any "smaller" point (component-wise) is also feasible.

**Algorithm: Start with a large feasible point and project down to sum = 1.**

1. Find the maximum c such that a = c * ones(n) is feasible: C_k = c^2 * min(k+1, 2n-1-k, n) for the triangular convolution. The peak is at k = n-1: C = c^2 * n. So c^2 * n <= t, giving c = sqrt(t/n).
   For sum = 1: c = 1/n. So t_min = 1/(n * n) * n = 1/n... wait.

   Score = 2*n*(1/n) / 1^2 = 2. ✓

This is equivalent to finding a "flatter" convolution.

**Idea: Use a "balancing" heuristic.**

At each step:
1. Compute C = convolve(a, a).
2. Find the lag k* with maximum C[k*].
3. The "problem" is that a[i]*a[k*-i] is large for some pairs.
4. Reduce the "stronger" element in each pair: for each i, if a[i] > a[k*-i], reduce a[i] and increase a[k*-i] (and vice versa).

This is like a "water-filling" or "balancing" step that tries to equalize a[i] and a[k*-i] for the peak lag.

More precisely:
For the peak lag k*, we have C[k*] = sum_i a[i]*a[k*-i].
By AM-GM: a[i]*a[k*-i] <= ((a[i]+a[k*-i])/2)^2.
Equality holds when a[i] = a[k*-i].

So if we can make a[i] = a[k*-i] for all i (i.e., make the sequence symmetric around k*/2), then C[k*] = sum_i (a[i]+a[k*-i])^2/4.

But we can't make the sequence symmetric around every k*/2 simultaneously (for different k's). So we need to balance across multiple lags.
