Key idea: Use a **gradiant-based** approach where we compute the gradient of J with respect to each element and take steps in the negative gradient direction.

The gradient of J = 2*n*max_b / S^2 with respect to a[i]:
- If max_b is at position k*, then d(max_b)/da[i] = a[k*-i] (if k*-i is valid, i.e., 0 <= k*-i < n)
- d(S)/da[i] = 1

= (2*n/S^2) * (a[k*-i] - 2*max_b/S)

Wait, let me be more careful. J = 2*n*M/S^2 where M = max_k c[k] and S = sum(a).

If M = c[k*] (assuming k* is the unique argmax), then:
dJ/da[i] = 2*n/S^2 * dc[k*]/da[i] - 2*n*M/S^3 * dS/da[i]
= 2*n/S^2 * a[k*-i] - 4*n*M/S^3

where a[k*-i] is 0 if k*-i is out of range.

To minimize J, we want to decrease a[i] where dJ/da[i] > 0 and increase a[i] where dJ/da[i] < 0.

dJ/da[i] > 0 when a[k*-i] > 2*M/S
dJ/da[i] < 0 when a[k*-i] < 2*M/S

So we want to:
- DECREASE a[i] when a[k*-i] is large (the "partner" element is large)
- INCREASE a[i] when a[k*-i] is small

This is interesting! It means we want to make the sequence "anti-correlated" with its reverse (shifted by k*). Specifically, where the reversed sequence has large values, we want the original to have small values.

This is essentially what makes the sequence asymmetric!

So the algorithm would be:
1. Compute the convolution and find k* = argmax(c).
2. For each i, compute the "gradient signal" g[i] = a[k*-i] - 2*M/S (with a[j]=0 for j out of range).
3. Update: a[i] -= eta * g[i] (or a[i] += eta * (2*M/S - a[k*-i]))
4. Clip to [0, 1000].
5. Repeat.

Let me also consider a "multi-peak" approach: instead of just looking at the single maximum, look at all peaks that are close to the maximum.

Here's my refined algorithm:

```
1. Start with parent sequence (or a random/asymmetric init).
2. For each iteration:
   a. Compute c = convolve(a, a)
   b. Find all positions where c[k] > (1-eps) * max(c) (the "hot" positions)
   c. Compute gradient: for each hot position k, contribute a[k-i] to grad[i]
   d. Weight by c[k] (or use soft-max weighting)
   e. Update a[i] -= eta * (weighted_sum - threshold)
   f. Clip to [0, 1000]
   g. If J improved, accept; else, reduce eta or try different direction.
3. Periodically try random restarts or larger perturbations.
```

This is essentially a "subgradient descent" or "mirror descent" on the non-smooth objective.

import time

def compute_score(a):
    n = len(a)
    S = a.sum()
    if S < 0.01:
        return np.inf
    c = np.convolve(a, a)
    max_b = c.max()
    return 2.0 * n * max_b / (S * S)

def smooth_max_and_grad(a, T):
    """Compute smooth max of convolution and its gradient w.r.t. a."""
    n = len(a)
    c = np.convolve(a, a)
    # Temperature-scaled softmax
    c_shifted = c - c.max()
    p = np.exp(c_shifted / T)
    p /= p.sum()

    grad = np.correlate(p, a, mode='valid')
