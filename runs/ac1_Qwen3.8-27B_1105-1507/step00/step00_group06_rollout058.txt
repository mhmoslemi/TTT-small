The idea is:
1. Start with an initial sequence `f` (normalized so that `sum f = sqrt(2n)` or some normalization).
2. Compute `M = max(f*f)`.
3. Find `g` that maximizes `sum g` subject to `g >= 0` and `(f*g)[k] <= M` for all `k`.
4. Rescale `g` to have the same sum as `f`.
5. Update `f <- (1-t)*f + t*g` for a small step size `t`.
6. Repeat.

The LP has `n` variables (the elements of `g`) and `2n-1` constraints (one for each lag of the convolution) plus `n` non-negativity constraints.
