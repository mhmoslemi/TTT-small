```python
import numpy as np
from scipy.optimize import linprog
import time

def solve_lp_direction(f, M):
    """Solve LP: max sum(g) s.t. f*g <= M, g >= 0."""
    n = len(f)
    # Variables: g_0, ..., g_{n-1}
    # Objective: maximize sum(g) → minimize -sum(g)
    c = -np.ones(n)
    
    # Constraints: (f*g)_k <= M for k = 0, ..., 2n-2
    # (f*g)_k = sum_{i: 0<=i<n, 0<=k-i<n} f_i * g_{k-i}
    # For a fixed k, the coefficient of g_j in (f*g)_k is f_{k-j} (if 0<=k-j<n)
    
    # A_ub has shape (2n-1, n), b_ub = M * ones(2n-1)
    A_ub = np.zeros((2*n-1, n))
    for k in range(2*n-1):
        for j in range(n):
            i = k - j
            if 0 <= i < n:
                A_ub[k, j] = f[i]
    b_ub = np.full(2*n-1, M)
    
    # Non-negativity: g >= 0, handled by bounds
    bounds = [(0, None)] * n
    
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    return res.x if res.success else None
```

The constraints become tr(Q_k^T X) <= t, tr(X) = sum a_i^2 (not directly sum(a)=1), sum(X_{i,i}) = sum a_i^2, and the constraint sum(a) = 1 becomes... hmm, this is tricky because sum(a) = 1 is not a constraint on X directly.

Actually, let me use a different formulation. Let s = sum(a) = 1. Then:
minimize max_k (a*a)_k / s^2 = max_k (a*a)_k (since s=1)
subject to sum(a) = 1, a >= 0.

The SDP relaxation would be:
minimize t
subject to: a^T Q_k a <= t for all k  →  tr(Q_k^T X) <= t where X = a*a^T
           sum(a) = 1  →  ? (this is the hard part)
           a >= 0  →  X_{i,j} >= 0, X_{i,i} = a_i^2

The constraint sum(a) = 1 is not easily expressed in terms of X. We could add a variable s and constrain s = sum(a), s^2 = 1, but that's not convex.

This approach seems promising but complex. Let me think of something simpler.

**Practical approach: Iterative refinement**

1. Start with the ideal sequence
2. Use a "peaking reduction" strategy:
   - Find the lag k* where (a*a)_{k*} is maximum
   - The subgradient tells us which elements to reduce
   - Form a direction that reduces (a*a)_{k*} while keeping sum = 1
   - Take a step in that direction
3. Use the LP approach as a more sophisticated version of step 2
