    """Fast convolution using FFT."""
    n = len(a)
    m = len(b)

Alternative: **Alternating Minimization**
1. Fix t (the target max convolution value).
2. Check if there exists a >= 0, sum(a) = 1, such that conv(a, a)[k] <= t for all k.
3. If yes, decrease t. If no, increase t.

But the feasibility check is non-convex (quadratic constraints).

Alternative: **Frank-Wolfe / Mirror Descent**
Use the fact that the feasible set {a >= 0, sum(a) = 1} is a simplex, and use Frank-Wolfe (conditional gradient) method.

At each step:
1. Compute the gradient of the objective (or a smooth approximation).
2. Solve the linear minimization over the simplex: min_{a >= 0, sum(a)=1} grad^T a = min_j grad[j]. So the FW step is to move towards the coordinate with the minimum gradient.
3. Take a convex combination: a_new = (1-eta) * a + eta * e_{j*} where j* = argmin_j grad[j].

This is simple but might be slow.

Alternative: **Proximal Gradient with Bregman Divergence**
Use the entropy proximal operator (which corresponds to the multiplicative update).

a_new[j] = a[j] * exp(-lr * grad[j]) / normalizer

This naturally maintains non-negativity and we just need to normalize for the sum constraint.

    beta = beta_start
    lr = lr_start

        if deadline is not None and time.monotonic() > deadline:
            break

        score = 2 * n * np.max(c)
        if score < best_score:
            best_score = score
            best_a = a.copy()
        
        # Soft-max weights
        c_scaled = beta * c
        max_cs = np.max(c_scaled)
        exp_cs = np.exp(c_scaled - max_cs)
        w = exp_cs / np.sum(exp_cs)
        
        # Gradient
        grad = 2.0 * np.correlate(w, a, mode='valid')
        
        # Multiplicative update (mirror descent with entropy)
        a_new = a * np.exp(-lr * grad / np.max(np.abs(grad) + 1e-10))
        a_new = np.maximum(a_new, 0)
        s = a_new.sum()
        if s > 1e-10:
            a_new = a_new / s
        else:
            a_new = a.copy()
        
        a = a_new
        beta = min(beta * 1.002, 50.0)
        lr = max(lr * 0.9998, 0.01)
    
    return best_a, best_score

Actually, I realize I've been confusing auto-correlation and auto-convolution. Let me clarify:

- Auto-correlation: R[k] = sum_j a[j] * a[j+k] (measures similarity at lag k)
- Auto-convolution: C[k] = sum_j a[j] * a[k-j] (the convolution of a with itself)

For a Zadoff-Chu sequence, this will have a peak at k = n-1 (where all n terms contribute) and smaller values elsewhere. It won't be flat.
