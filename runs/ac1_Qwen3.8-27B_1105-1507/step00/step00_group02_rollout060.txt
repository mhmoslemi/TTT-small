1. Compute all conv values (or just track the max)
2. Find k* = argmax
3. Compute gradient: grad[i] = 2*a[k*-i] if 0 <= k*-i < n, else 0
4. Update: a_new = a - lr * grad
5. Project: a_new = a_new / sum(a_new) (to maintain sum=1), then clip to [0, ∞) and renormalize
