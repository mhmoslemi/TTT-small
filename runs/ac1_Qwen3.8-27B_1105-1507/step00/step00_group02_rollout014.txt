**New approach: Multiplicative Weight Update / Game-based method**

The problem of minimizing `max_k (f*f)[k]` subject to `f >= 0, sum(f) = 1` can be viewed as a zero-sum game:
- Player 1 (minimizer) chooses `f` (a distribution over [n]).
- Player 2 (maximizer) chooses `k` (a distribution over [2n-1]).
- Payoff: `E_k[(f*f)[k]] = sum_k q(k) * (f*f)[k]`.

The minimax value is what we want to minimize. By von Neumann's minimax theorem, this equals the maxmin value.

The multiplicative weight algorithm:
1. Initialize `f` uniformly (or from the given sequence).
2. Initialize `q` uniformly over [2n-1].
3. For each iteration:

   c. Update `q` using multiplicative weights.

The QP: minimize `f^T C f` subject to `f in Δ_{n-1}` (the probability simplex).

2. At each step:

3. Repeat.

The step (a) is O(n) since C is sparse. Step (b) is O(n). Step (c) is O(n). So each iteration is O(n).

```python
def project_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    # Use the algorithm from Duchi et al. (2011)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    r = np.arange(1, n + 1)
    cond = u - (cssv - 1) / r > 0
    rho = np.where(cond)[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1)
    return np.maximum(v - theta, 0)
```
