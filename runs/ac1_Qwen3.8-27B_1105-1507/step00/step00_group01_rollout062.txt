```python
def compute_conv(a):
    """Compute a * a using FFT. Returns array of length 2*len(a)-1."""
    n = len(a)
    return irfft(rfft(a, 2 * n) ** 2)


def compute_objective(a):
    """Compute 2*n*max(a*a)/(sum a)^2."""
    n = len(a)
    s = float(np.sum(a))
    if s < 1e-10:
        return np.inf
    conv = compute_conv(a)
    return 2.0 * n * float(np.max(conv)) / (s * s)


def solve_lp_direction(f, M):
    """
    Solve LP: maximize sum(b) subject to (f*b)[k] <= M for all k, b >= 0.
    Returns the optimal b, or None if infeasible/unbounded.
    """
    n = len(f)
    # Build constraint matrix A (2n-1) x n where A[k,j] = f[k-j] if 0<=k-j<n
    # This is a lower-triangular Toeplitz matrix
    offsets = list(range(0, -n, -1))
    diagonals = [f[i] * np.ones(n) for i in range(n)]
    A = diags(diagonals, offsets, shape=(2 * n - 1, n), format='csr')
    
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    
    try:
        result = linprog(c, A_ub=A, b_ub=b_ub,
                         bounds=[(0, None)] * n, method='highs',
                         options={'presolve': True})
        if result.status == 0:
            return np.maximum(result.x, 0)
    except Exception:
        pass
    return None
```

```python
    """Build lower-triangular Toeplitz matrix (2n-1) x n in CSR format."""
    from scipy.sparse import csr_matrix
    m = 2 * n - 1
    
    # indptr: row k starts at indptr[k], ends at indptr[k+1]
    # Number of non-zeros in row k: min(k+1, n, 2n-1-k)
    row_nnz = np.minimum(np.arange(m) + 1, n)
    row_nnz = np.minimum(row_nnz, m - np.arange(m))
    indptr = np.zeros(m + 1, dtype=np.int64)
    indptr[1:] = np.cumsum(row_nnz)
    
    total_nnz = int(indptr[-1])
    data = np.empty(total_nnz, dtype=np.float64)
    indices = np.empty(total_nnz, dtype=np.int32)
    
    fill = 0
    for k in range(m):
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        count = j_end - j_start + 1
        data[fill:fill+count] = f[k - j_start : k - j_start + count]
        indices[fill:fill+count] = np.arange(j_start, j_end + 1, dtype=np.int32)
        fill += count
    
    return csr_matrix((data, indices, indptr), shape=(m, n))
```

The projection onto the simplex is a well-known operation that can be done in O(n log n) time.

This approach is:
- O(n log n) per step (FFT for convolution + O(n) for gradient + O(n log n) for projection).
- Simple to implement.
- Might converge slower than the LP method, but each step is much faster.

Let me implement both and compare.

For the gradient: at the maximum index `k*`, the subgradient w.r.t. `a_j` is:
`sg_j = a[k*-j] + a[j-k*]` (with boundary conditions: `a[i] = 0` for `i < 0` or `i >= n`).

This is essentially `2 * a[k*-j]` if the sequence is symmetric and `k* = n-1`. In general, it's the sum of two "reflected" copies of `a`.

We can compute this as a cross-correlation: `sg = correlate(a, a, shift=k*)` which can be done with FFT.

Actually, more precisely:
`sg_j = a[k*-j] + a[j-k*]` for `j = 0, ..., n-1`
where `a[i] = 0` for `i` outside `[0, n-1]`.

This is `sg = flip(a, shift=k*) + a, shift=-k*` which is a cross-correlation.

Using FFT: `sg = irfft(rfft(a, 2*n) * rfft(flip_a, 2*n))` where `flip_a` is `a` with appropriate shifts. Actually, it's simpler to just do it directly since it's O(n) for a fixed `k*`.

Wait, for a fixed `k*`, `sg_j = a[k*-j] + a[j-k*]` is just two shifted and possibly flipped copies of `a`. This is O(n) to compute.

So the full algorithm per step is:
1. Compute `conv = a * a` (FFT, O(n log n)).
2. Find `k* = argmax(conv)` (O(n)).
3. Compute subgradient `sg` (O(n)).
4. Update: `a_new = a - step_size * sg` (O(n)).
5. Project onto simplex (O(n log n)).
6. Check convergence.

Total per step: O(n log n). For `n = 6121`, each step is very fast (maybe 1-2 ms). We can do millions of steps in 1500 seconds.

The downside is that subgradient methods converge slowly (O(1/sqrt(T))). But with a good step size schedule and many iterations, it might work.

```python
def subgradient_step(a, step_size, rng):
    """One subgradient step for minimizing max(a*a) on the simplex."""
    n = len(a)
    
    # Compute convolution
    conv = compute_conv(a)
    k_star = int(np.argmax(conv))
    
    # Compute subgradient
    sg = np.zeros(n)
    for j in range(n):
        val = 0.0
        idx1 = k_star - j
        if 0 <= idx1 < n:
            val += a[idx1]
        idx2 = j - k_star
        if 0 <= idx2 < n:
            val += a[idx2]
        sg[j] = val
    
    # Update
    a_new = a - step_size * sg
    
    # Project onto simplex
    a_new = project_simplex(a_new, 1.0)
    
    return a_new, k_star, conv[k_star]


def project_simplex(v, target_sum):
    """Project v onto {x >= 0 : sum(x) = target_sum}."""
    n = len(v)
    # Scale to make target_sum = 1 for the standard algorithm
    v = v / (target_sum / n)  # This doesn't work simply...
    
    # Standard simplex projection:
    # Minimize 0.5 * ||x - v||^2 subject to x >= 0, sum(x) = target_sum
    # Solution: x_i = max(v_i - tau, 0) where tau is chosen so sum(x) = target_sum
    
    # Binary search for tau
    v_sorted = np.sort(v)[::-1]
    cv = np.cumsum(v_sorted)
    rho = np.nonzero(v_sorted * np.arange(1, n + 1) > (cv[-1] - target_sum))[0][-1]
    tau = (cv[rho] - target_sum) / (rho + 1)
    return np.maximum(v - tau, 0)
```

Wait, the standard simplex projection formula is:
Given `v`, find `x = argmin ||x - v||^2` subject to `x >= 0` and `sum(x) = 1`.
The solution is `x_i = max(v_i - tau, 0)` where `tau = (sum of top rho elements of v - 1) / rho` and `rho` is the largest index such that `v_(rho) > tau`.

For `target_sum != 1`, we can scale: `x_i = max(v_i - tau, 0)` where `tau = (sum of top rho elements of v - target_sum) / rho`.

Let me verify: `sum(x) = sum(max(v_i - tau, 0)) = sum of (v_i - tau) for i in top rho = sum_top_rho - rho * tau = target_sum`.
So `tau = (sum_top_rho - target_sum) / rho`. ✓

A better approach might be the **smoothed max** with a softmax. Let me implement that:

`F_T(a) = (1/T) * log(sum_k exp(T * (a*a)[k]))`

As `T -> inf`, `F_T(a) -> max_k (a*a)[k]`.

The gradient is:
`dF_T/da_j = sum_k w_k * (a[k-j] + a[j-k])`

where `w_k = T * (a*a)[k] * exp(T*(a*a)[k]) / sum_m exp(T*(a*a)[m])` are the softmax weights.

Computing `w_k` requires all convolution values, which we get from FFT. Then the gradient is a weighted sum of shifted copies of `a`, which can be computed as a convolution of `w` with `a` (using FFT).

Since the gradient computation is the bottleneck, and for a single `k*` (the argmax) it's just O(n), let me use the **subgradient method** (not smoothed) which only needs the gradient at the argmax:

`sg[j] = a[k*-j] + a[j-k*]` (with boundary conditions)

This is O(n) per step. The total cost per step is O(n log n) for the convolution + O(n) for the subgradient + O(n log n) for the projection.

For `n = 6121`, each step is about 50K operations, so we can do about 100K steps per second. In 1500 seconds, we can do 150M steps. That's more than enough.

The issue is convergence rate. Subgradient methods converge as O(1/sqrt(T)), so we might need a few million iterations to get good accuracy. With a step size of `1/sqrt(t)`, after `T` iterations, the error is O(1/sqrt(T)) times the Lipschitz constant.
