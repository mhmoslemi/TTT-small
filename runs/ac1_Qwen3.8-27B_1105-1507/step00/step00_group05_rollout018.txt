The key insight is that we want to minimize the peak of the autocorrelation (linear convolution) of a non-negative sequence. This is a well-studied problem in signal processing.

One effective approach is the "M destiné" method or "iterative amplitude adjustment":
1. Start with a random phase (or random amplitudes)
2. FFT → adjust amplitudes in frequency domain → IFFT → project onto non-negative
3. Iterate

Another approach: "alternating direction method of multipliers" (ADMM):
- Split the problem into: minimize b_max subject to b = convolve(a,a), a >= 0
- Introduce a variable c = convolve(a,a) and minimize max(c) subject to c = convolve(a,a), a >= 0
- The ADMM update alternates between:
  - Update c: c = min(b_current, threshold) (projection onto the max constraint)
  - Update a: solve a quadratic subproblem (minimize ||convolve(a,a) - c||² + ||a||² subject to a >= 0)

The second subproblem can be solved using the FFT (since it involves convolutions). This is similar to the "indirect binary search" or "spectral" methods used in radar sequence design.
