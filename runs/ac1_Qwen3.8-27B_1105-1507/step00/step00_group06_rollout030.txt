Let me analyze this problem carefully.

We need to minimize: `f(sequence) = (2 * n * max(convolve_full(a, a))) / (sum(a))^2`

Key observations:
1. The objective is scale-invariant: if we scale `a` by `c > 0`, then `max(conv(c*a, c*a)) = c^2 * max(conv(a,a))` and `(sum(c*a))^2 = c^2 * (sum(a))^2`. So the ratio is unchanged. This means we can normalize the sequence to have a fixed sum (e.g., sum = 1) without losing generality.

2. The objective becomes: minimize `2 * n * max(conv(a,a))` subject to `sum(a) = 1`, `a >= 0`.

3. The minimum possible value: By the properties of convolution, `conv(a,a)` at index `i` is `sum_j a_j * a_{i-j}`. The maximum of this is at least `(sum a)^2 / (2n-1)` by a pigeonhole/averaging argument (since `sum_i conv(a,a)_i = (sum a)^2`). So `max conv >= (sum a)^2/(2n-1)`, giving `f >= 2n/(2n-1) > 1`.

4. For a uniform sequence (all `a_i = 1/n`), `conv(a,a)_i = (min(i+1, 2n-1-i, n))/n^2`, so `max conv = 1/n`. Then `f = 2n * (1/n) / (1)^2 = 2`. This matches the previous result of 2.0.

5. To beat 2, we need a sequence where the convolution is more flat (peaky convolution is bad). This is related to "flat-top" or "low autocorrelation" sequences.

6. The theoretical lower bound is `lim_{n→∞} 2n/(2n-1) = 1`. So we want to approach 1.

Now, the key insight: this is essentially the problem of finding a non-negative sequence of length `n` whose autocorrelation is as flat as possible (minimizing the peak-to-average ratio).

For non-negative sequences, this is related to:
- Barker sequences (but those are ±1)
- Flat-top windows
- The problem is analogous to minimizing the peak sidelobe level

def _softmax_sharp(x, sharpness):
    """Softmax with sharpness parameter: exp(sharpness * x) / sum(exp(sharpness * x))."""
    x_shifted = sharpness * (x - np.max(x))
    e = np.exp(x_shifted)
    return e / np.sum(e)

def _proj_simplex(v):
    """Project vector v onto the probability simplex."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    cond = u > cssv / np.arange(1, n + 1)
    if not np.any(cond):
        return np.ones(n) / n

    return np.maximum(v - theta, 0)

Ah, I made an error earlier. It's `1.0`, not `1.4`. So the correlation values at indices 2, 3, 4 are `[1.4, 1.4, 1.0]`, which matches!

So `sum_k p_k * a_{k-m} = np.correlate(p, a, 'full')[m + (n-1)]` where `n = len(a)`.

Wait: for `m=0`, index is `0 + 2 = 2`: value `1.4`. ✓
For `m=1`, index is `1 + 2 = 3`: value `1.4`. ✓
For `m=2`, index is `2 + 2 = 4`: value `1.0`. ✓

So the formula is: `sum_k p_k * a_{k-m} = correlate(p, a, 'full')[m + len(a) - 1]`.

Therefore, the gradient of the smoothed max is:
`grad[m] = 2 * correlate(p, a, 'full')[m + n - 1]` for `m = 0, ..., n-1`.

Where `p = softmax(sharpness * c)` and `c = conv(a, a, 'full')`.

And `correlate(p, a, 'full') = convolve(p, a[::-1], 'full')`, which can be computed with FFT.

Let me now write the efficient version:

```python
def _compute_smooth_grad(a, sharpness):
    """Compute gradient of smoothed max of conv(a,a)."""
    n = len(a)
    c = np.convolve(a, a, mode='full')  # length 2n-1
    # Softmax
    c_shifted = sharpness * (c - c.max())
    exp_c = np.exp(c_shifted)
    p = exp_c / exp_c.sum()  # length 2n-1
    # Gradient: 2 * correlate(p, a, 'full')[n-1 : 2n-1]
    corr = np.convolve(p, a[::-1], mode='full')  # length 3n-2
    grad = 2.0 * corr[n-1:2*n-1]
    return c, grad
```
