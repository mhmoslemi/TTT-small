A better shadow: s[j] = sum_k p_k * a[k-j] (weighted by the "soft max" probabilities p_k). This captures the contribution to ALL lags, weighted by their "importance" (peaks are more important).

This is essentially the gradient of the smooth-max objective, which I derived earlier.

Let me use the log-sum-exp smoothing:
p_k = exp(g_k / tau) / sum_l exp(g_l / tau) where g_k = (conv(a,a))[k].

Then the "shadow" (gradient direction) is:
s[j] = sum_k p_k * a[k-j] (for valid k-j, i.e., 0<=k-j<n).

The descent direction for the peak is: reduce a[j] proportionally to s[j].
The "safe" direction is: increase a[j] where s[j] is small (low shadow).

So the update is:
a_new[j] = a[j] * exp(-alpha * (s[j] - s_mean) / s_std)

This is a "contrastive" update: reduce high-shadow indices, increase low-shadow indices.

The smooth objective is: f(a) = 2n * L / S^2 where L = log(sum_k exp(g_k/tau)), g_k = (conv(a,a))[k], S = sum(a).

The gradient is:
df/da[j] = 2n/S^3 * [S * dL/da[j] - 2L]

where dL/da[j] = (1/tau) * sum_k p_k * dg_k/da[j] = (2/tau) * sum_k p_k * a[k-j] (valid) = (2/tau) * s[j]

where s[j] = sum_k p_k * a[k-j] (the "shadow").

So df/da[j] = 2n/S^3 * [2S/tau * s[j] - 2L] = 4n/S^3 * [S/tau * s[j] - L]

The descent direction (to decrease f) is: -df/da[j] = 4n/S^3 * [L - S/tau * s[j]]

For this to be a valid descent direction, we want to move a[j] in the direction that decreases f. The direction component for each j is:
d[j] = L - S/tau * s[j]

If d[j] > 0, increasing a[j] decreases f.
If d[j] < 0, decreasing a[j] decreases f.

So the update should be: a_new[j] = a[j] + step * d[j] (additive), or multiplicatively: a_new[j] = a[j] * exp(step * d[j] / a[j]) (which is the same as exp(step * d[j]) for the additive case in log-space).

Actually, for multiplicative updates with non-negativity constraint, it's better to use:
a_new[j] = a[j] * exp(step * d[j]) where d[j] = L - S/tau * s[j]

But this doesn't preserve non-negativity (if a[j] = 0, it stays 0). Also, it doesn't preserve the sum.

A simpler approach: use the additive projected gradient:
a_new[j] = max(0, a[j] - step * df/da[j])
Then re-normalize if needed.
