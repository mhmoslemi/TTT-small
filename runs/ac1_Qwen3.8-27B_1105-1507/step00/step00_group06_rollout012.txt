    candidates.append(ramp)

    cos_seq = np.clip(cos_seq, 0.01, None)
    candidates.append(cos_seq)

    candidates.append(exp_seq)

    two_peak = np.zeros(n)
    two_peak[:n//4] = 1.0
    two_peak[3*n//4:] = 1.0
    candidates.append(two_peak)

    for c in candidates:
        c = np.clip(c, 0, 1000)
        if c.sum() < 0.01:
            continue
        s = float(evaluate_sequence(c.tolist()))
        if np.isfinite(s) and s < best_score:
            best = c.copy()
            best_score = s
            print(f"Better initialization: {best_score}")
    
    # Phase 2: Local search with blame-based updates
    lr = 0.3  # initial learning rate
    iteration = 0
    
    while time.monotonic() < deadline:
        # Compute convolution
        conv = np.convolve(best, best)
        M = conv.max()
        S = best.sum()
        
        # Find hot lags (top fraction)

        threshold = M * (0.90 + 0.05 * np.sin(iteration * 0.01))
        H = (conv >= threshold).astype(np.float64)
        
        # Compute blame
        blame = np.correlate(H, best, mode='valid')
        
        # Normalize
        blame_mean = blame.mean()
        blame_std = blame.std() + 1e-10
        
        # Update: multiplicative
        # Decrease high-blame elements, increase low-blame
        adjust = -lr * (blame - blame_mean) / (blame_std + 1e-10)
        # Clip to prevent extreme changes

        new_best = best * np.exp(adjust)

            best_score = score
            if iteration % 100 == 0:

        # Adapt learning rate

            if np.isfinite(s) and s < best_score * 1.05:

Hmm, but I'm not sure this will get us below 2. Let me think about what specifically makes a sequence have objective < 2.

We need max_k conv[k] < (sum a)^2 / n.

The center lag (k = n-1) has conv[n-1] = sum_i a[i]*a[n-1-i].
If the sequence is "anti-palindromic" (a[i] is large when a[n-1-i] is small), then conv[n-1] is small.

But other lags will be large. Specifically, lag k = 0 has conv[0] = a[0]^2, and lag k = 2n-2 has conv[2n-2] = a[n-1]^2.

For the max to be less than (sum a)^2/n, we need:
- a[0]^2 < (sum a)^2/n → a[0] < S/sqrt(n) → a[0] < S/sqrt(n)
- a[n-1]^2 < S^2/n → a[n-1] < S/sqrt(n)
- conv[n-1] = sum a[i]*a[n-1-i] < S^2/n
- All other conv[k] < S^2/n

The condition a[i] < S/sqrt(n) for all i means the sequence is bounded above. This is always satisfied if the sequence is "spread out" enough.

The key constraint is conv[n-1] < S^2/n, i.e., sum a[i]*a[n-1-i] < S^2/n.

By the rearrangement inequality, sum a[i]*a[n-1-i] is minimized when a is sorted in the same order as its reverse, i.e., when a is "anti-sorted" relative to its reverse.

If a is monotonically increasing, then a[n-1-i] is monotonically decreasing, and their dot product is minimized.

So a monotonically increasing (or decreasing) sequence should have a small center value!
