**Approach: Coordinate descent with clever updates**

For each position i, the optimal value (given all other positions fixed) can be found analytically or by a small search. This is because:
- The score depends on max(c), and c[k] is a quadratic in a[i] for each k that involves a[i].
- The constraint is a[i] >= 0.

For a fixed set of all other a[j] (j ≠ i), the score as a function of a[i] is:
score(x) = 2n * max_k c_k(x) / (1 + x - a[i])² (after normalization)

where c_k(x) is the k-th element of the convolution when a[i] is replaced by x.

This is a piecewise function (different k is the max in different ranges of x), but within each piece, it's a ratio of a linear function (in x) to a quadratic, which can be optimized in closed form.

def compute_c_fft(a, n=None):

    if n is None:

    fa = fft(a, size)
