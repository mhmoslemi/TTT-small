For the refinement phase (coordinate descent):
For coordinate i, given all other coordinates fixed, I want to find a[i] >= 0 that minimizes max_k b(k).

b(k) = a[i]*a[k-i] + c_k (where c_k is the contribution from other coordinates).

Since a[k-i] >= 0 for all valid k-i, increasing a[i] increases all b(k) that involve coordinate i. So the optimal a[i] is either 0 or the value that equalizes the peak.

Specifically, if a[i] = 0: max_b = max(c_k).
If a[i] > 0: the peak will be at the k where c_k + a[i]*a[k-i] is maximized. To minimize this, we want to balance the peaks.
