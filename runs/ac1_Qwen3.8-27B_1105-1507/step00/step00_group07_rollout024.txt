**Simpler approach: Spectrum shaping**
1. Start with a.
2. Compute A = FFT(a).
3. Compute |A|².
4. Generate a new |A_new|² = |A|²^α (with α < 1 to flatten).
5. Set A_new = |A_new|²^{1/2} * exp(i*arg(A)) (keep the same phase).
6. a_new = IFFT(A_new).
7. Project a_new onto {x ≥ 0, sum(x) = S}.
8. Repeat.

This is a form of "spectral reshaping" that gradually flattens the power spectrum while preserving the phase (and hence the "shape" of the sequence).

def spectral_reshape(a, alpha, S):
    """Flatten the power spectrum of a."""
    n = len(a)
    size = 1
    while size < 2 * n:
        size <<= 1
    A = np.fft.rfft(a, size)
    mag = np.abs(A)
    phase = np.angle(A)
    # Flatten: new_mag = mag^alpha (alpha < 1 flattens)
    mag_new = mag ** alpha if (mag > 0).any() else mag
    # Where mag is 0, keep it 0
    mag_new = np.where(mag > 0, mag ** alpha, 0)
    A_new = mag_new * np.exp(1j * phase)
    a_new = np.fft.irfft(A_new, size)[:n]
    a_new = project_onto_nonneg_sum(a_new, S)
