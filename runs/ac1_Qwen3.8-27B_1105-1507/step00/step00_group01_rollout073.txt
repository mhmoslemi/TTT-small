**Approach: Parametric family + gradient-based search**

Instead of optimizing a directly, I'll parameterize the sequence as:

where V(i) is a smooth potential function. I'll parameterize V as a sum of a few sine/cosine modes:

This gives a smooth, bounded sequence with K*2 free parameters (amplitudes and phases, or equivalently, sine and cosine coefficients).

For K = 5, I have 10 parameters to optimize. This is a much lower-dimensional problem!

The objective is still 2*n*max(conv(a,a)), but now I'm optimizing over 10 parameters instead of n.

I can use scipy.optimize or simple coordinate descent / gradient descent.

Let me compute the gradient with respect to the parameters:
- a[i] = exp(V_i) / Z where Z = sum exp(V_j)
- da[i]/dV[j] = a[i] * (delta_{ij} - a[j])
- dc[k]/dV[j] = sum_{i,l} dc[k]/da[i] * da[i]/dV[j] = sum_i 2*a[k-i]*a[i]*(delta_{i,j} - a[j])
  = 2*a[k-j]*a[j] - a[j] * sum_i 2*a[k-i]*a[i]
  = 2*a[k-j]*a[j] - 2*a[j]*c[k]

So dc[k]/dV[j] = 2*a[j]*(a[k-j] - c[k]) (with the convention that a[k-j] = 0 if k-j is out of range).

And d(max c)/dV[j] = 2*a[j]*(a[k*-j] - c[k*]) where k* is the argmax.

This is a clean formula! The gradient with respect to V[j] is proportional to a[j]*(a[k*-j] - c[k*]).

Intuition: if a[k*-j] > c[k*] (i.e., this position contributes more than average to the peak), we want to decrease V[j] (make a[j] smaller). If a[k*-j] < c[k*], we want to increase V[j].

This is a nice interpretation!

Now, for the parametric approach, I compute:
d(max c)/dA_k = sum_j 2*a[j]*(a[k*-j] - c[k*]) * dV[j]/dA_k

where dV[j]/dA_k = cos/sin(2*pi*k*j/(n-1) + phi_k) (or sin/cos if I use A_k*sin + B_k*cos parameterization).

This is O(n) per parameter, and O(n*K) total. Very fast!

def parametric_optimize(n, K, max_steps, lr):
    # Parameters: A[0:K], B[0:K] (amplitudes of sine and cosine modes)
    params = np.zeros(2*K)  # [A0, B0, A1, B1, ...]
    
    for step in range(max_steps):
        # Compute V and a
        theta = np.linspace(0, 2*np.pi, n, endpoint=False)
        V = np.zeros(n)
        for k in range(K):
            V += params[2*k] * np.cos(k+1)*theta) + params[2*k+1] * np.sin((k+1)*theta)
        
        # Wait, I should use frequencies that make sense for the sequence
        # Mode m: V_m(i) = A_m * cos(2*pi*m*i/(n-1)) + B_m * sin(2*pi*m*i/(n-1))
        
        # Actually, let me use a simpler parameterization
        # V[i] = sum_m (A_m * cos(2*pi*m*i/n) + B_m * sin(2*pi*m*i/n))
        
        a = np.exp(V - V.max())  # for numerical stability
        a /= a.sum()
        
        # Compute convolution
        c = fft_conv(a)
        k_star = np.argmax(c)
        c_max = c[k_star]
        
        # Compute gradient with respect to V
        # dV_grad[j] = 2*a[j]*(a[k*-j] - c[k*])
        V_grad = np.zeros(n)
        lo = max(0, k_star - n + 1)
        hi = min(n - 1, k_star)
        if lo <= hi:
            V_grad[lo:hi+1] = 2.0 * a[lo:hi+1] * (a[k_star - hi:k_star - lo] - c_max)
        
        # Project V_grad onto the parameter space
        # dV[j] = sum_m (A_m * cos(2*pi*m*j/n) + B_m * sin(2*pi*m*j/n))
        # So param_grad[2*m] = sum_j V_grad[j] * cos(2*pi*m*j/n)
        #    param_grad[2*m+1] = sum_j V_grad[j] * sin(2*pi*m*j/n)
        
        t = np.arange(n)
        param_grad = np.zeros(2*K)
        for m in range(K):
            freq = 2*np.pi*(m+1)/n
            param_grad[2*m] = np.dot(V_grad, np.cos(freq * t))
            param_grad[2*m+1] = np.dot(V_grad, np.sin(freq * t))
        
        # Update params with Adam or simple gradient descent
        params -= lr * param_grad
    
    return a

def _fft_conv(a):
    n = len(a)
    size = 2*n - 1
    N = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, N)
    return np.fft.irfft(A*A, N)[:size]
