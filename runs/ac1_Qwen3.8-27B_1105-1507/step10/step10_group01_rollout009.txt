- `i=0`: `k-i = 2`, in range, `2*a[2]` ✓
- `i=1`: `k-i = 1`, in range, `2*a[1]` ✓
- `i=2`: `k-i = 0`, in range, `2*a[0]` ✓
- `i=3`: `k-i = -1`, not in range, 0 ✓

So the formula is: `dc_k/da[i] = 2 * a[k-i]` if `0 <= k-i < n`, else 0.

Now, the subgradient of `max_k c_k` at point `a` (where the max is attained at `k*`) is:
`grad[i] = 2 * a[k*-i]` if `0 <= k*-i < n`, else 0.

And the gradient of `f(a) = max_k c_k / (sum a)^2` is:
`grad_f[i] = dc_{k*}/da[i] / (sum a)^2 - max_k c_k * 2*a[i] / (sum a)^3`
`= 2*a[k*-i] / (sum a)^2 - 2*c_{k*}*a[i] / (sum a)^3` (for valid `k*-i`)

On the simplex `sum a = 1`:
`grad_f[i] = 2*a[k*-i] - 2*c_{k*}*a[i]`

This is a nice formula! It says: to reduce the peak at lag `k*`, we should increase `a[i]` where `a[k*-i]` is large, and decrease `a[i]` where `a[i]` itself is large (weighted by the peak value).

For the smoothed version (log-sum-exp with parameter tau):
`g(a) = (1/tau) * log(sum_k exp(tau * c_k / (sum a)^2))`

The gradient is:
`grad_g[i] = sum_k p_k * (dc_k/da[i] / (sum a)^2 - 2*c_k*a[i]/(sum a)^3)`
where `p_k = exp(tau * c_k) / sum_j exp(tau * c_j)`

On the simplex:
`grad_g[i] = 2 * sum_k p_k * a[k-i] * 1{0<=k-i<n} - 2 * sum_k p_k * c_k * a[i]`
`= 2 * (p * a)[i] - 2 * (sum_k p_k * c_k) * a[i]`

where `(p * a)[i] = sum_k p[k] * a[i-k]` (cross-correlation, with appropriate bounds).

This can be computed efficiently using FFT!

OK so now I have a clear understanding of the gradient. Let me design the algorithm:

**Algorithm:**

1. **Initialization**: Start from parent sequence or a structured initialization (chirp, etc.)

2. **LP-driven phase** (main workhorse):
   - Solve LP to get direction `g`
   - Use gradient-based line search (not just grid)
   - Iterate until convergence

3. **Smoothed gradient phase**:
   - Use the log-sum-exp smoothed gradient
   - Nesterov momentum
   - Adaptive tau (start low, increase over time)
   - Adaptive step size (BB or backtracking)

4. **Exploration phase**:
   - Try different n values
   - Different initializations
   - Fourier perturbations

5. **Final polish**:
   - High-tau gradient descent
   - LP refinement

Let me now think about specific improvements:

**Improvement 1: Gradient-based line search**
Instead of grid search, use the gradient of the 1D function `f(t) = obj((1-t)*a + t*g)` to do line search. The gradient can be computed from the subgradient formula.

**Improvement 2: QP alternative**
Instead of LP (minimize peak), solve QP (minimize sum of squares). This gives a different direction that might be more effective.

QP: min `sum_k (conv(a,g)[k])^2` s.t. `sum g = 1, g >= 0`

This is a QP that can be solved with cvxpy. The solution tends to spread the energy more evenly.

**Improvement 3: Combined direction**
Use a convex combination of the LP direction and the QP direction.

**Improvement 4: Spectral initialization**
Initialize with `a[i] = exp(-alpha * (i - beta*n)^2 / n)` or `a[i] = 1 + eps*cos(2*pi*i^2/n)` or similar.

**Improvement 5: Adaptive n**
Try to find the optimal n by evaluating the objective at different n values around the current best.

```python
"""
Optimizes step function coefficients to minimize 2*n*max(conv(a,a))/(sum(a))^2.
Uses a combination of:
1. LP-driven optimization with gradient-based line search
2. QP-based direction (minimize sum of squares)
3. Smoothed gradient descent with Nesterov momentum
4. Multi-n exploration with structured initializations
5. Diverse restarts with Fourier perturbations
"""

import numpy as np
import cvxpy as cp
from scipy.fft import rfft, irfft, fft, ifft
from scipy.ndimage import uniform_filter1d
import time


def compute_conv(a):
    """Full linear convolution a*a via FFT."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))


def build_conv_matrix(a):
    """Build convolution matrix A (2n-1 x n) such that (A @ g)[k] = conv(a,g)[k]."""
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for k in range(2 * n - 1):
        for i in range(max(0, k - n + 1), min(n, k + 1)):
            A[k, i] = a[k - i]
    return A


def build_conv_matrix_fast(a):
    """Build convolution matrix efficiently using vectorized operations."""
    n = len(a)
    k_idx = np.arange(2 * n - 1)[:, None]
    i_idx = np.arange(n)[None, :]
    diff = k_idx - i_idx
    valid = (diff >= 0) & (diff < n)
    A = np.zeros((2 * n - 1, n))
    A[valid] = a[diff[valid]]
    return A


def solve_lp_minpeak(a):
    """Solve LP: min M s.t. conv(a,g)[k] <= M, sum(g)=1, g>=0."""
    n = len(a)
    a_norm = a / np.sum(a)
    A = build_conv_matrix_fast(a_norm)
    
    g = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [A @ g <= M, cp.sum(g) == 1]
    prob = cp.Problem(cp.Minimize(M), constraints)
    
    for solver in [cp.MOSEK, cp.CLARABEL, cp.SCS, cp.ECOS]:
        try:
            prob.solve(solver=solver)
            if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g.value, 0)
                s = float(np.sum(g_val))
                if s > 1e-10:
                    return g_val / s, float(M.value)
        except Exception:
            continue
    return None, None


def solve_qp_minsum(a):
    """Solve QP: min sum_k (conv(a,g)[k])^2 s.t. sum(g)=1, g>=0."""
    n = len(a)
    a_norm = a / np.sum(a)
    A = build_conv_matrix_fast(a_norm)
    
    g = cp.Variable(n, nonneg=True)
    constraints = [cp.sum(g) == 1]
    objective = cp.Minimize(cp.sum_squares(A @ g))
    prob = cp.Problem(objective, constraints)
    
    for solver in [cp.MOSEK, cp.CLARABEL, cp.SCS, cp.ECOS]:
        try:
            prob.solve(solver=solver)
            if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g.value, 0)
                s = float(np.sum(g_val))
                if s > 1e-10:
                    return g_val / s
        except Exception:
            continue
    return None


def gradient_smoothing(a, tau):
    """Compute smoothed gradient using log-sum-exp."""
    n = len(a)
    conv = compute_conv(a)
    max_conv = float(np.max(conv))
    tau_clipped = max(tau, 1.0)
    exp_vals = np.exp(tau_clipped * (conv - max_conv))
    sum_exp = float(np.sum(exp_vals))
    if sum_exp < 1e-300:
        p = np.zeros(len(conv))
        p[int(np.argmax(conv))] = 1.0
    else:
        p = exp_vals / sum_exp
    
    # Compute cross-correlation (p * a) efficiently
    N = 1
    while N < 3 * n:
        N <<= 1
    P = fft(p, N)
    A = fft(a, N)
    # (p * a)[i] = sum_k p[k] * a[i-k]  (cross-correlation)
    # This is ifft(conj(P) * A) for correlation, or ifft(P * conj(A)) for convolution
    # We want sum_k p[k] * a[i+k-... ] ... let me think.
    # conv(p, a)[m] = sum_k p[k] * a[m-k]
    # We want for each i: sum_k p[k] * a[k-i] (with bounds)
    # This is conv(p, a)[2*n-1+i-... ] hmm, let me just use the direct formula.
    
    # Actually, the gradient formula is:
    # grad[i] = 2 * sum_k p[k] * a[k-i] * 1{0<=k-i<n}
    # Let's compute this via cross-correlation
    # cross_corr[i] = sum_k p[k+i] * a[k] ... no.
    
    # Let me just compute it directly for clarity, or use the FFT trick.
    # sum_k p[k] * a[k-i] for k-i in [0, n-1]
    # = sum_j p[j+i] * a[j] for j in [0, n-1] and j+i in [0, 2n-2]
    # This is the cross-correlation of p and a at lag i.
    # cross_corr_p_a[i] = sum_j p[j+i] * a[j]
    
    # Using FFT: ifft(conj(fft(p)) * fft(a))[i] gives sum_j p[j] * a[j-i] (with circular convolution)
    # We need linear, so zero-pad.
    
    # Actually, let me think about this differently.
    # grad[i] = 2 * sum_{k: 0<=k-i<n} p[k] * a[k-i]
    # Let j = k-i, then k = j+i
    # grad[i] = 2 * sum_{j: 0<=j<n, 0<=j+i<2n-1} p[j+i] * a[j]
    # = 2 * sum_{j=0}^{n-1} p[j+i] * a[j] (since j+i < n+i < 2n-1 for j < n, i < n)
    
    # This is the cross-correlation of p (length 2n-1) and a (length n) at lag i.
    
    # Using FFT: 
    # cross_corr[i] = sum_j conj(p[j+i]) * a[j] ... no, p is real.
    # cross_corr[i] = sum_j p[j+i] * a[j]
    
    # If we compute ifft(conj(fft(p, N)) * fft(a, N))[:n], we get:
    # result[i] = sum_j p[j] * a[j-i] (circular, with zero padding making it linear)
    # Hmm, this is not quite what we want.
    
    # Let me use a different approach:
    # sum_j p[j+i] * a[j] = sum_j p'[j] * a[j-shift] where p' is p shifted...
    
    # Actually the simplest way: 
    # grad[i] = 2 * (p reversed cross-correlated with a)[n-1-i] ... this is getting complicated.
    
    # Let me just use the direct FFT-based computation:
    # We want: for each i in [0, n-1], compute sum_k p[k] * a[k-i] where k-i is in [0, n-1]
    # = sum_{j=0}^{n-1} a[j] * p[j+i]
    
    # This is: (a * p_flipped)[n-1-i] where p_flipped[k] = p[2n-2-k]
    # Because (a * p_flipped)[m] = sum_j a[j] * p_flipped[m-j] = sum_j a[j] * p[2n-2-m+j]
    # For m = n-1-i: = sum_j a[j] * p[2n-2-(n-1-i)+j] = sum_j a[j] * p[n-1+i+j]
    # That's not right either.
    
    # OK let me just compute it directly using the fact that for each i:
    # grad_component[i] = sum_{j=0}^{n-1} a[j] * p[j+i]
    
    # I'll use a simple vectorized approach:
    # For i=0: sum_j a[j] * p[j]
    # For i=1: sum_j a[j] * p[j+1]
    # ...
    # For i=n-1: sum_j a[j] * p[j+n-1]
    
    # This can be done with a sliding dot product, or more simply:
    # Create a matrix where row i is p[i:i+n] (dot with a)
    # Or use the FFT trick properly.
    
    # The clean way: 
    # Let q = p[0:2n-1] (length 2n-1)
    # We want for each i: dot(a, q[i:i+n])
    # = dot(a, q shifted left by i)
    # This is the "running dot product" which can be computed as:
    # ifft(fft(a, N) * conj(fft(q, N))) ... no.
    
    # Actually: dot(a, q[i:i+n]) = sum_j a[j] * q[j+i]
    # = (a * flip(q))[2n-1-i] ... let me verify.
    # (a * flip(q))[m] = sum_j a[j] * flip(q)[m-j] = sum_j a[j] * q[2n-2-(m-j)] = sum_j a[j] * q[2n-2-m+j]
    # For m = 2n-2-i: = sum_j a[j] * q[j+i] ✓
    
    # So: grad_component[i] = conv(a, flip(p))[2n-2-i]
    
    # Using FFT:
    N2 = 1
    while N2 < 2 * n + (2 * n - 1) - 1:
        N2 <<= 1
    # Actually N2 just needs to be >= 3n-2
    while N2 < 3 * n - 1:
        N2 <<= 1
    
    p_flipped = p[::-1]  # length 2n-1
    A_fft = fft(a, N2)
    Pf_fft = fft(p_flipped, N2)
    conv_result = ifft(A_fft * Pf_fft, N2).real  # length 3n-2
    
    # grad_component[i] = conv_result[2n-2-i]
    grad_component = conv_result[2*n-2 : 2*n-2-(n-1):-1]  # indices 2n-2, 2n-3, ..., n-1
    
    # Wait, let me re-index. i goes from 0 to n-1, and we want conv_result[2n-2-i]
    # So the array is [conv_result[2n-2], conv_result[2n-3], ..., conv_result[n-1]]
    # = conv_result[n-1 : 2n-1][::-1]
    
    grad_component = conv_result[n-1 : 2*n-1][::-1]
    
    # Now the full gradient (on simplex sum a = 1):
    # grad[i] = 2 * grad_component[i] - 2 * (sum_k p[k]*c_k) * a[i]
    # where c_k = conv(a,a)[k]
    
    weighted_sum = float(np.dot(p, conv))
    grad = 2.0 * (grad_component - weighted_sum * a)
    
    return grad


def lp_driven_optimize(a, time_budget=300.0, verbose=True, use_qp=False):
    """LP-driven optimization with improved line search."""
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    iter_count = 0
    consecutive_no_improve = 0
    stall_count = 0
    rng = np.random.default_rng(67890)
    
    while time.monotonic() - start < time_budget:
        remaining = time_budget - (time.monotonic() - start)
        if remaining < 2.0:
            break
        
        # Solve LP for direction
        g, M = solve_lp_minpeak(a)
        if g is None:
            break
        
        # Sometimes use QP direction for diversity
        if use_qp and iter_count % 5 == 2:
            g_qp = solve_qp_minsum(a)
            if g_qp is not None:
                g = 0.5 * g + 0.5 * g_qp
                g = np.maximum(g, 0)
                g = g / g.sum()
        
        # Line search with golden section
        best_t, obj_at_t = line_search_golden(a, g)
        
        iter_count += 1
        
        if obj_at_t < best_obj - 1e-12:
            a_try = (1 - best_t) * a + best_t * g
            a_try = np.maximum(a_try, 0)
            s_try = float(np.sum(a_try))
            if s_try > 1e-10:
                a_try = a_try / s_try
                best_obj = obj_at_t
                best_a = a_try.copy()
                a = a_try
                consecutive_no_improve = 0
                stall_count = 0
        else:
            consecutive_no_improve += 1
            stall_count += 1
            
            # Try small steps
            if consecutive_no_improve <= 3:
                for t_small in [0.05, 0.02, 0.01, 0.005]:
                    a_small = (1 - t_small) * a + t_small * g
                    a_small = np.maximum(a_small, 0)
                    s_small = float(np.sum(a_small))
                    if s_small > 1e-10:
                        a_small = a_small / s_small
                        obj_small = compute_obj(a_small)
                        if obj_small < best_obj - 1e-12:
                            best_obj = obj_small
                            best_a = a_small.copy()
                            a = a_small
                            consecutive_no_improve = 0
                            stall_count = 0
                            break
            
            if stall_count >= 8:
                # Perturb
                a = a + 0.01 * rng.standard_normal(n)
                a = np.maximum(a, 0)
                a = a / a.sum()
                stall_count = 0
                consecutive_no_improve = 0
                
                if iter_count > 200:
                    break
        
        if verbose and (iter_count % 20 == 0 or obj_at_t < best_obj - 1e-4):
            elapsed = time.monotonic() - start
            print(f"    LP it{iter_count}: obj={best_obj:.8f}, M={M:.6f}, time={elapsed:.0f}s")
    
    return best_a


def line_search_golden(a, g, n_grid=30):
    """Line search: golden section after grid."""
    n = len(a)
    
    # Coarse grid
    ts = np.linspace(0.01, 0.99, n_grid)
    objs = np.full(n_grid, np.inf)
    for i, t in enumerate(ts):
        a_try = (1 - t) * a + t * g
        a_try = np.maximum(a_try, 0)
        s = float(np.sum(a_try))
        if s > 1e-10:
            objs[i] = compute_obj(a_try)
    
    best_idx = int(np.argmin(objs))
    best_t = ts[best_idx]
    best_obj = objs[best_idx]
    
    # Golden section refinement around best
    if 0 < best_idx < n_grid - 1:
        lo = ts[max(0, best_idx - 1)]
        hi = ts[min(n_grid - 1, best_idx + 1)]
        gr = (np.sqrt(5) - 1) / 2  # golden ratio ~ 0.618
        
        for _ in range(20):
            x1 = hi - gr * (hi - lo)
            x2 = lo + gr * (hi - lo)
            
            a1 = (1 - x1) * a + x1 * g
            a1 = np.maximum(a1, 0)
            f1 = compute_obj(a1) if float(np.sum(a1)) > 1e-10 else np.inf
            
            a2 = (1 - x2) * a + x2 * g
            a2 = np.maximum(a2, 0)
            f2 = compute_obj(a2) if float(np.sum(a2)) > 1e-10 else np.inf
            
            if f1 < f2:
                hi = x2
            else:
                lo = x1
        
        mid = (lo + hi) / 2
        a_mid = (1 - mid) * a + mid * g
        a_mid = np.maximum(a_mid, 0)
        f_mid = compute_obj(a_mid) if float(np.sum(a_mid)) > 1e-10 else np.inf
        
        if f_mid < best_obj:
            best_t = mid
            best_obj = f_mid
    
    return best_t, best_obj


def gd_polish(a, time_budget=100.0, tau_init=50.0, tau_end=2000.0, verbose=False):
    """Nesterov accelerated gradient descent on smoothed objective."""
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    beta = 0.9
    base_lr = 2.0 / np.sqrt(n)
    lr = base_lr
    v = np.zeros(n)
    it = 0
    best_it = 0
    prev_obj = best_obj
    
    while time.monotonic() - start < time_budget:
        elapsed = time.monotonic() - start
        progress = min(1.0, elapsed / max(time_budget, 1e-10))
        tau = tau_init + (tau_end - tau_init) * progress ** 2.0
        
        # Nesterov look-ahead
        y = a + beta * v
        y = np.maximum(y, 0)
        s_y = float(np.sum(y))
        if s_y < 1e-10:
            y = best_a.copy()
        else:
            y = y / s_y
        
        # Compute gradient
        g = gradient_smoothing(y, tau)
        g_norm = float(np.linalg.norm(g))
        
        if g_norm < 1e-15:
            break
        
        # Adaptive learning rate
        lr = lr * 0.999  # slow decay
        if it % 10 == 0:
            # Backtracking step size
            lr_try = lr
            for _ in range(10):
                a_try = y - lr_try * g
                a_try = np.maximum(a_try, 0)
                s_try = float(np.sum(a_try))
                if s_try > 1e-10:
                    a_try = a_try / s_try
                    obj_try = compute_obj(a_try)
                    if obj_try < prev_obj * (1 - 1e-4 * lr_try * g_norm):
                        break
                lr_try *= 0.5
            lr = lr_try
        
        v = beta * v - lr * g
        a_new = y + v
        a_new = np.maximum(a_new, 0)
        s_new = float(np.sum(a_new))
        if s_new < 1e-10:
            a_new = best_a.copy()
            v = np.zeros(n)
        else:
            a_new = a_new / s_new
        
        obj_new = compute_obj(a_new)
        if obj_new < best_obj - 1e-14:
            best_obj = obj_new
            best_a = a_new.copy()
            best_it = it
            prev_obj = obj_new
        
        a = a_new
        it += 1
        
        # Reset if stuck
        if it - best_it > 20000:
            a = best_a.copy()
            v = np.zeros(n)
            best_it = it
    
    if verbose:
        print(f"    GD: obj={best_obj:.8f}, iters={it}")
    return best_a


def resample_sequence(a, new_n):
    """Resample sequence to new length."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, a[0])
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)


def chirp_init(n, gamma=1.0):
    """Chirp-like initialization."""
    x = np.arange(n)
    a = 1.0 + 0.5 * np.cos(gamma * 2.0 * np.pi * x * x / n)
    return np.maximum(a, 0.1) / np.sum(np.maximum(a, 0.1))


def gaussian_init(n, sigma_frac=0.3, center=0.5):
    """Gaussian initialization."""
    x = np.arange(n) / n
    a = np.exp(-0.5 * ((x - center) / sigma_frac) ** 2)
    return a / a.sum()


def exponential_init(n, rate=2.0):
    """Exponential initialization."""
    x = np.arange(n)
    a = np.exp(-rate * x / n)
    return a / a.sum()


def propose_candidate(seed=42, budget_s=1500):
    """
    Main search combining LP-driven optimization, QP directions,
    smoothed gradient descent, multi-n exploration, and diverse restarts.
    """
    start_time = time.monotonic()

    best_seq = None

    rng = np.random.default_rng(seed)
