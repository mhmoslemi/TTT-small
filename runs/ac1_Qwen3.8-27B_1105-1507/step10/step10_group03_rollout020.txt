3. Update q: q_new = (1-t)*q + t*delta_{k*}.
4. Solve min_a a^T (sum_k q_k Q_k) a s.t. sum(a)=1, a>=0.

Let me also think about the **coordinate descent** approach more carefully.

For coordinate i, given all other coordinates fixed:
- Let a_i = x (the variable).
- Let s = sum(a_j for j≠i) = 1 - x (since sum(a) = 1).
- b_k = x * a_{k-i} + (terms not involving a_i) [for k where k-i is in [0,n-1] and k-i ≠ i]
- b_{2i} = x^2 + (terms not involving a_i) [the term where both copies are a_i]

Wait, this is more subtle. Let me define:
- For k ≠ 2i: b_k = x * a_{k-i} + c_k (where c_k doesn't depend on x, assuming k-i ≠ i)
  Actually, b_k = sum_j a_j * a_{k-j}. The terms involving a_i are:
  - j = i: a_i * a_{k-i} = x * a_{k-i} (if 0 <= k-i < n and k-i ≠ i)
  - j = k-i: a_{k-i} * a_i = a_{k-i} * x (if 0 <= k-i < n and k-i ≠ i)
  - If k-i = i (i.e., k = 2i): the term is a_i * a_i = x^2 (counted once since j = i = k-i)
  
  So for k ≠ 2i: b_k = 2*x*a_{k-i} + c_k (if 0 <= k-i < n)
  For k = 2i: b_{2i} = x^2 + c_{2i}
  
  where c_k = b_k - (terms involving a_i).

The objective is max_k b_k (since sum(a)=1). We want to minimize max_k b_k over x >= 0.

This is a 1D optimization problem! We can solve it by:
1. Finding all k where b_k is "active" (close to the max).
2. For each active k, the constraint b_k <= t becomes:
   - If k ≠ 2i: 2*x*a_{k-i} + c_k <= t (linear in x)
   - If k = 2i: x^2 + c_{2i} <= t (quadratic in x)
3. The min t such that all constraints are satisfied with some x >= 0.

This can be solved by binary search on t, and for each t, checking if there exists x >= 0 satisfying all constraints. The feasible set for x is an intersection of intervals (from linear constraints) and possibly a quadratic constraint.

Actually, for the linear constraints: 2*a_{k-i}*x <= t - c_k, so x <= (t - c_k)/(2*a_{k-i}) (if a_{k-i} > 0).
For the quadratic: x^2 <= t - c_{2i}, so x <= sqrt(t - c_{2i}) (if t > c_{2i}).

So the feasible x is [0, min over all constraints]. The minimum t is the smallest value where this interval is non-empty.

This gives an efficient coordinate descent step!

def coordinate_descent(a, max_rounds=10, tol=1e-10):
    n = len(a)
    a = a.copy()
    s = float(np.sum(a))
    a = a / s
    
    for round in range(max_rounds):
        improved = False
        for i in range(n):
            # Compute current convolution
            conv = compute_conv(a)
            current_max = float(np.max(conv))
            
            # For coordinate i, find the optimal value
            # b_k = 2*x*a_{k-i} + c_k for k ≠ 2i (when 0 <= k-i < n)
            # b_{2i} = x^2 + c_{2i}
            # We need: all b_k <= t, minimize t, over x >= 0
            # Also need sum(a) = 1: (1-x) is the sum of others, so we need x in [0, 1]
            # (and all other a_j >= 0, which is already satisfied)
            
            # Compute c_k = conv_k - (current terms involving a_i)
            old_x = a[i]
            c = np.zeros(2 * n - 1)
            for k in range(2 * n - 1):
                k_minus_i = k - i
                if 0 <= k_minus_i < n:
                    if k_minus_i == i:
                        c[k] = conv[k] - old_x * old_x
                    else:
                        c[k] = conv[k] - 2 * old_x * a[k_minus_i]
                # else: c[k] = conv[k] (no contribution from a_i)
            
            # Now find min t s.t. exists x in [0, 1] with:
            #   2*x*a_{k-i} + c[k] <= t for all k where 0 <= k-i < n, k-i ≠ i
            #   x^2 + c[2i] <= t if 2i < 2n-1
            #   
            # For a given t, the constraint on x is:
            #   x <= (t - c[k]) / (2*a[k-i]) for all k where 0 <= k-i < n, k-i ≠ i, a[k-i] > 0
            #   x <= sqrt(t - c[2i]) if 2i < 2n-1 and a has the i-th coordinate
            #   x >= 0
            #   x <= 1
            #
            # So x_max(t) = min(1, min_k (t-c[k])/(2*a[k-i]), sqrt(t-c[2i]) if applicable)
            # We need x_max(t) >= 0.
            #
            # The minimum t is when x_max(t) = 0 just barely, i.e.,
            # the binding constraint gives t.
            #
            # Actually, let's just do a 1D binary search on t.
            # Lower bound: max(c) (when x=0)
            # Upper bound: current_max
            
            # When x = 0: all b_k = c[k], so t_min >= max(c)
            # When x = old_x: t = current_max
            
            t_lo = float(np.max(c))
            t_hi = current_max
            
            # Binary search
            for _ in range(50):
                t_mid = (t_lo + t_hi) / 2
                # Check if feasible
                x_max = 1.0

                    k_mi = k - i
                    if 0 <= k_mi < n:
                        if k_mi == i:
