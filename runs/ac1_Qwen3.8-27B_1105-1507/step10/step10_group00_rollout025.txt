def fista_smoothed(a_init, tau_schedule, time_budget, n):
    a = a_init.copy()
    s = a.sum()
    a = a / s  # normalize to simplex
    
    # FISTA parameters
    t = 1.0
    z = a.copy()  # momentum variable
    best_a = a.copy()
    best_obj = compute_obj(a)
    
    start = time.monotonic()
    it = 0
    
    while time.monotonic() - start < time_budget:
        # Adaptive tau
        tau = tau_schedule(it)
        
        # Compute conv and p
        conv = compute_conv(a)  # length 2n-1
        # Softmax for stability
        conv_shifted = conv - conv.max()
        p = np.exp(tau * conv_shifted)
        p = p / p.sum()
        
        # Compute gradient
        c1 = np.correlate(p, a, mode='full')[0:n]
        grad = 4.0 * n * c1
        
        # Step size (Lipschitz constant estimate)
        # The Hessian of the smoothed objective has norm bounded by ~ 4n * tau * max(conv - min(conv)) * 2 + 4n * max(a)
        # For simplicity, use a fixed step or adaptive step
        L = 4.0 * n * tau * conv.max() + 4.0 * n * a.max()
        step = 1.0 / L
        
        # Gradient step
        y = z - step * grad

        s_y = y.sum()
        if s_y < 1e-10:

        t_new = (1 + np.sqrt(1 + 4 * t * t)) / 2

        it += 1

        if it % 10 == 0:

                best_obj = obj
                best_a = a.copy()

Wait, there's an issue with the step size. The Lipschitz constant of the gradient of the smoothed objective on the simplex is not simply bounded by `4n * tau * conv.max() + 4n * a.max()`. 

The gradient is `grad_i = 4n * sum_k p_k * a_{k-i}`.

The Hessian involves derivatives of `p_k` (which depend on tau and conv) and derivatives of `a_{k-i}` (which is just a permutation).

`d grad_i / d a_j = 4n * sum_k (dp_k/da_j * a_{k-i} + p_k * da_{k-i}/da_j)`

`da_{k-i}/da_j = delta_{k-i, j} = delta_{k, i+j}`

So `sum_k p_k * da_{k-i}/da_j = p_{i+j}` (if 0 <= i+j <= 2n-2)

And `dp_k/da_j = tau * p_k * (d conv_k/da_j - sum_m p_m * d conv_m/da_j) = tau * p_k * (2*a_{k-j} - 2*sum_m p_m * a_{m-j})` (using the formula d conv_k/da_j = 2*a_{k-j})

Wait, `sum_m p_m * d conv_m/da_j = sum_m p_m * 2*a_{m-j} = 2 * c1[j]` (where c1 is the cross-correlation we computed).

So `dp_k/da_j = tau * p_k * 2 * (a_{k-j} - c1[j])`

And the Hessian element is:
`H_{ij} = 4n * sum_k [tau * 2 * p_k * (a_{k-j} - c1[j]) * a_{k-i} + p_k * delta_{k,i+j}]`
`= 4n * [2*tau * (sum_k p_k * a_{k-j} * a_{k-i} - c1[j] * sum_k p_k * a_{k-i}) + p_{i+j}]`
`= 4n * [2*tau * (c2_{ij} - c1[j] * c1[i]) + p_{i+j}]`

where `c2_{ij} = sum_k p_k * a_{k-j} * a_{k-i}`.

This is complex. For a safe upper bound on the Lipschitz constant (L), I can use:
`||H|| <= 4n * (2*tau * ||a||_2^2 * max(p) * something + max(p))`

**The key insight**: The objective `max_k conv_k(a)` on the simplex is convex. Even though it's not smooth, we can use **subgradient methods with Nesterov acceleration** effectively. The previous code already does this, but the learning rate schedule might not be optimal.

Let me try a different approach: **mirror descent / multiplicative weight updates**.

On the simplex, the mirror map is the negative entropy: `Phi(a) = sum_i a_i * log(a_i)`. Mirror descent with this map gives:
`a_i^{new} = a_i * exp(-eta * grad_i) / Z`

This is similar to the **exponentiated gradient** or **Hedge** algorithm. It has the advantage of staying in the interior of the simplex and being well-suited for the problem structure.

For the subgradient of `max_k conv_k`, the subgradient at `a` is `sum_k in_active lambda_k * g_k` where `g_k` is the gradient of `conv_k` and `lambda` is a distribution on the active set. The simplest choice is to put all weight on the argmax: `lambda = delta_{k*}` where `k* = argmax conv_k`.

Then the update is:
`a_i^{new} = a_i * exp(-eta * 2 * a_{k*-i}) / Z` (where out-of-range terms are 0)

This is very simple to compute! And it naturally stays in the simplex.

Let me try this approach. It's essentially the **exponentiated gradient** method for minimizing the peak of the autocorrelation.

For Nesterov acceleration, we'd apply this to the "lookahead" point.

Let me code this up:

def exp_gradient_descent(a_init, time_budget, n):
    a = a_init.copy()
    s = a.sum()
    a = a / s
    best_a = a.copy()
    best_obj = compute_obj(a)
    
    start = time.monotonic()
    it = 0
    eta = 1.0  # learning rate
    momentum = 0.9
    
    while time.monotonic() - start < time_budget:
        conv = compute_conv(a)
        k_max = np.argmax(conv)
        
        # Subgradient: 2 * a_{k_max - i} (out of range = 0)
        subgrad = np.zeros(n)
        for i in range(n):
            j = k_max - i
            if 0 <= j < n:
                subgrad[i] = 2.0 * a[j]
        
        # Exponentiated gradient update
        a_new = a * np.exp(-eta * subgrad)
        a_new = a_new / a_new.sum()
        
        obj = compute_obj(a_new)
        if obj < best_obj:
            best_obj = obj
            best_a = a_new.copy()
        
        a = a_new
        eta *= 0.999  # decay learning rate
        it += 1
    
    return best_a

Let me also think about what makes the LP approach good: it solves the **linearization** of the problem exactly at each step. The gap between the linear approximation and the true problem is what limits convergence.

A better approach might be to solve a **quadratic approximation** of the problem. At the current point `a`, the quadratic approximation of `conv_k(a + delta)` is:
`conv_k(a) + 2 * sum_j delta_j * a_{k-j} + sum_j delta_j^2 * delta_{k,2j} + 2 * sum_{j<l, j+l=k} delta_j * delta_l`

(This is exact since `conv_k` is quadratic.)

So the problem becomes:
`min M s.t. conv_k(a) + grad_k^T delta + delta^T Q_k delta <= M for all k, sum delta = 0, ||delta|| <= r`

where `Q_k` is a Hankel matrix (the "second derivative" part). This is a **quatically constrained quadratic program (QCQP)**, which is NP-hard in general. But for the specific structure here (Hankel matrices), it might be tractable.

Actually, a simpler approach: use a **trust region** method where we minimize the linearization subject to a quadratic constraint:
`min grad^T delta s.t. ||delta||^2 <= r^2, sum delta = 0, a + delta >= 0`

This is a QP that can be solved efficiently. But it's essentially the same as projected gradient descent.

```python
import numpy as np
import cvxpy as cp
from scipy.fft import rfft, irfft
import time

# Helper functions (top-level, no closures)

def compute_conv(a):
    """Full linear convolution a*a via FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]

def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2. Scale invariant."""
    n = len(a)
    s = float(np.sum(a))
    if s < 1e-10:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))

def build_conv_matrix(a):
    """Build matrix A (2n-1 x n) such that A @ g = conv(a, g)."""
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        r = min(n, 2 * n - 1 - j)
        A[j:j + r, j] = a[:r]
    return A

def solve_lp_minpeak(a):
    """Solve LP: min M s.t. conv(a,g)[k] <= M, sum(g)=1, g>=0."""
    n = len(a)
    a_norm = a / float(np.sum(a))
    A = build_conv_matrix(a_norm)
    g = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [A @ g <= M, cp.sum(g) == 1]
    prob = cp.Problem(cp.Minimize(M), constraints)
    for solver in [cp.CLARABEL, cp.SCS, cp.ECOS]:
        try:
            prob.solve(solver=solver)
            if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g.value, 0)
                s = float(np.sum(g_val))
                if s > 1e-10:
                    return g_val / s
        except:
            continue
    return None

def line_search(a, direction, t_max=1.5):
    """Golden section line search for blend a + t*direction."""
    # direction is such that we're looking at (1-t)*a + t*direction
    lo, hi = 0.0, t_max
    phi = (1 + np.sqrt(5)) / 2
    gr = 2 - phi
    
    def obj_at(t):
        a_try = (1 - t) * a + t * direction
        a_try = np.maximum(a_try, 0)
        s = a_try.sum()
        if s < 1e-10:
            return np.inf
        return compute_obj(a_try / s)
    
    c = lo + gr * (hi - lo)
    d = lo + (1 - gr) * (hi - lo)
    fc = obj_at(c)
    fd = obj_at(d)
    
    for _ in range(20):
        if fc < fd:
            hi = d; d = c; fd = fc
            c = lo + gr * (hi - lo); fc = obj_at(c)
        else:
            lo = c; c = d; fc = fd
            d = lo + gr * (hi - lo); fd = obj_at(d)
    
    t_best = c if fc < fd else d
    return t_best, min(fc, fd)

def fista_smoothed(a_init, time_budget, tau_start=1.0, tau_end=100.0):
    """FISTA with log-sum-exp smoothing."""
    a = a_init.copy()
    s = a.sum()
    a = a / s
    n = len(a)
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    it = 0
    t_k = 1.0
    z = a.copy()
    
    while time.monotonic() - start < time_budget:
        # Adaptive tau (exponential schedule)
        progress = (time.monotonic() - start) / time_budget
        tau = tau_start * (tau_end / tau_start) ** progress
        
        # Compute smooth objective and gradient
        conv = compute_conv(a)
        conv_max = conv.max()
        logits = tau * (conv - conv_max)
        p = np.exp(logits)
        p_sum = p.sum()
        if p_sum < 1e-300 or not np.isfinite(p_sum):
            # Fallback to hard max
            p = np.zeros(len(conv))
            p[np.argmax(conv)] = 1.0
        else:
            p = p / p_sum
        
        # Gradient: grad_i = 4n * sum_k p_k * a_{k-i}
        # = 4n * correlate(p, a, 'full')[i] for i in [0, n-1]
        c1 = np.correlate(p, a, mode='full')[0:n]
        grad = 4.0 * n * c1
        
        # Step size: use backtracking
        step = 1.0
        y = z - step * grad
        y = np.maximum(y, 0)
        s_y = y.sum()
        if s_y < 1e-10:
            step = 1e-3
            y = z - step * grad
            y = np.maximum(y, 0)
            s_y = y.sum()
        y_proj = y / s_y if s_y > 1e-10 else a.copy()
        
        # Simple: use fixed step based on problem scale
        # L ~ 8n * tau (rough Lipschitz bound)
        L = 8.0 * n * tau + 1.0
        step = 1.0 / L
        
        y = z - step * grad
        y = np.maximum(y, 0)
        s_y = y.sum()
        if s_y < 1e-10:
            y = a.copy()
        else:
            y = y / s_y
        
        # FISTA update
        t_new = (1 + np.sqrt(1 + 4 * t_k * t_k)) / 2
        z_new = y + (t_k - 1) / t_new * (y - a)
        z_new = np.maximum(z_new, 0)
        s_z = z_new.sum()
        if s_z < 1e-10:
            z_new = y.copy()
        else:
            z_new = z_new / s_z
        
        a = y
        z = z_new
        t_k = t_new
        it += 1
        
        # Periodic check
        if it % 5 == 0:
            obj = compute_obj(a)
            if obj < best_obj:
                best_obj = obj
                best_a = a.copy()
        
        # Stagnation detection
        if it % 100 == 0 and it > 100:
            obj = compute_obj(a)
            if not (obj < best_obj + 1e-12):
                # Reset momentum
                z = best_a.copy()
                t_k = 1.0
    
    obj_final = compute_obj(a)
    if obj_final < best_obj:
        best_a = a.copy()
        best_obj = obj_final
    
    return best_a

def exp_gradient(a_init, time_budget, eta_init=0.5):
    """Exponentiated gradient method (fast, O(n) per step after conv)."""
    a = a_init.copy()
    s = a.sum()
    a = a / s
    n = len(a)
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    it = 0
    eta = eta_init
    
    while time.monotonic() - start < time_budget:
        conv = compute_conv(a)
        k_max = int(np.argmax(conv))
        
        # Subgradient of max conv at a: 2*a_{k_max - i} (out of range = 0)
        subgrad = np.zeros(n)
        j_start = max(0, k_max - n + 1)
        j_end = min(n, k_max + 1)
        for i in range(n):
            j = k_max - i
            if 0 <= j < n:
                subgrad[i] = 2.0 * a[j]
        
        # Multiplicative update
        log_a = np.log(a + 1e-30)
        log_a_new = log_a - eta * subgrad
        # Normalize (softmax-like)
        log_a_new -= log_a_new.max()
        a_new = np.exp(log_a_new)
        a_new = a_new / a_new.sum()
        
        obj = compute_obj(a_new)
        if obj < best_obj:
            best_obj = obj
            best_a = a_new.copy()
            a = a_new
        else:
            # Reduce eta if no improvement
            a = a_new  # still move, but keep best
            if it % 100 == 0:
                eta *= 0.95
        
        eta *= 0.9999
        it += 1
    
    return best_a

def lp_polish(a_init, time_budget, max_iters=50):
    """LP-based polishing."""
    a = a_init.copy()
    s = a.sum()
    a = a / s
    n = len(a)
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    it = 0
    
    while time.monotonic() - start < time_budget and it < max_iters:
        g_lp = solve_lp_minpeak(a)
        if g_lp is None:
            break
        
        t_opt, obj_opt = line_search(a, g_lp, t_max=1.2)
        
        if t_opt > 1e-4 and obj_opt < best_obj - 1e-14:
            a_new = (1 - t_opt) * a + t_opt * g_lp
            a_new = np.maximum(a_new, 0)
            s_new = a_new.sum()
            if s_new > 1e-10:
                a_new = a_new / s_new
                obj_new = compute_obj(a_new)
                best_obj = obj_new
                best_a = a_new.copy()
                a = a_new
            it += 1
        else:
            # Try small perturbation
            rng = np.random.default_rng(hash((it, n)) & 0xFFFFFFFF)
            noise = rng.normal(0, 0.01, n)
            a_pert = a + noise
            a_pert = np.maximum(a_pert, 0)
            s_pert = a_pert.sum()
            if s_pert > 1e-10:
                a = a_pert / s_pert
            it += 1
    
    return best_a

def u_shaped_init(n, sharpness=3.0):
