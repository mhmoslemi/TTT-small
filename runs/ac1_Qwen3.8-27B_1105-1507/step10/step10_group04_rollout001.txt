"""
Optimizes step function coefficients to minimize 2*n*max(conv(a,a))/(sum(a))^2.
Uses refined LP polishing with active set tracking, KKT Newton polish,
symmetric sequence exploitation, and focused n-exploration.
"""

import numpy as np
import cvxpy as cp
from scipy.fft import rfft, irfft, fft, ifft
from scipy.optimize import minimize as scipy_minimize, fsolve
import time


def compute_conv(a):
    """Full linear convolution a*a via FFT."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))


def build_conv_matrix(a):
    """Build matrix A (2n-1 x n) such that A @ g = conv(a, g)."""
    n = len(a)
    A_rows = 2 * n - 1
    A = np.zeros((A_rows, n))
    for j in range(n):
        A[j:j + n, j] = a
    return A


def build_conv_matrix_active(a, active_indices):
    """Build reduced matrix with only active rows."""
    full = build_conv_matrix(a)
    return full[active_indices, :]


def solve_lp_full(a, warm_g=None, solver_pref=None):

    s = float(np.sum(a))
    if s < 1e-10:
        return None, None
    a_norm = a / s
    A = build_conv_matrix(a_norm)
    
    g = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [A @ g <= M, cp.sum(g) == 1]
    prob = cp.Problem(cp.Minimize(M), constraints)
    
    solvers = [cp.CLARABEL, cp.SCS, cp.PDLP, cp.ECOS]
    if solver_pref:
        solvers = [solver_pref] + [s for s in solvers if s != solver_pref]

        try:
            prob.solve(solver=solver)
            if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g.value, 0)
                sg = float(np.sum(g_val))
                if sg > 1e-10:
                    g_val = g_val / sg
                    return g_val, float(M.value)
        except Exception:
            continue
    return None, None

        # Let me just compute it directly (n is at most ~2000, so O(n^2) is fine for the polish)
        grad = np.zeros(n)
        for i in range(n):

            for k in active:

                if 0 <= k - i < n:
                    val += y_val[np.searchsorted(active, k)] * a[k - i]
                # a[i-k] if 0 <= i-k < n
                if 0 <= i - k < n:
                    val += y_val[np.searchsorted(active, k)] * a[i - k]

        # We want to minimize (max grad - min grad) on support
        # Gradient descent on this: move a in direction that reduces non-flatness
        # The derivative of grad[i] w.r.t. a[j] is:

        # Update a[i] proportionally to (mean_g - grad[i]) to flatten
        # This is like gradient descent on sum_i (grad[i] - mean_g)^2

        # But we need to maintain sum(a) = 1 and a >= 0
        lr = 1.0 / (float(np.max(np.abs(grad))) + 1e-10)

            a_new[i] += lr * (mean_g - grad[i])

            obj_new = compute_obj(a_new)
            if obj_new < best_obj - 1e-14:
                best_obj = obj_new
                best_a = a_new.copy()
                a = a_new
    
    return best_a

**Better approach for the polish:**

After the LP converges (g ≈ a), we know the active set S and the dual weights y. The KKT conditions require:
- grad[i] = 2*mu for all i in support (where grad is computed from y)
- a[i] >= 0
- sum(a) = 1

The issue is that y depends on a (through the matrix A), so we need to alternate:
1. Given a, compute y (solve dual LP)
2. Given y, solve for a that makes grad flat

Step 2 is: find a (on simplex, nonnegative) that minimizes max_i grad[i] - min_i grad[i] where grad[i] = sum_k y_k * (a[k-i] + a[i-k]).

Since grad is linear in a, this is a linear program!

min t
s.t. grad[i] <= t + c for all i in support (where c is the center)
     grad[i] >= c - t for all i in support
     sum(a) = 1
     a >= 0

But c is also a variable. Alternatively:
min (max_i grad[i] - min_i grad[i])
s.t. sum(a) = 1, a >= 0

This can be written as:
min t
s.t. grad[i] - grad[j] <= t for all i,j in support
     sum(a) = 1
     a >= 0

This is an LP in (a, t)! The number of constraints is |support|^2 + 1, which for |support|=800 is 640001 + 1. That might be too large.

Alternative: fix c = mean(grad) and solve:
min t
s.t. grad[i] <= c + t for all i

     sum(a) = 1
     a >= 0

This has 2|support| + 1 constraints. For |support|=800, that's 1601 constraints. Much more manageable!

But c changes as a changes... We can handle this by including c as a variable:
min t
s.t. grad[i] <= c + t for all i in support
     grad[i] >= c - t for all i in support
     sum(a) = 1
     a >= 0
     c free

This has 2|support| + 1 inequality constraints + 1 equality. Variables: a (n), t, c. Total: n+2 variables.

This is a clean LP! Let me use this.

Actually wait, I need to be more careful. The "flatness" condition at the KKT optimum is:
grad[i] = 2*mu for all i in support

where grad[i] = sum_{k in S} lambda_k * (a[k-i] + a[i-k])

And the complementary slackness says a[i] > 0 only if grad[i] = 2*mu, and a[i] = 0 implies grad[i] >= 2*mu.

So the condition is that grad is constant (= 2*mu) on the support, and >= 2*mu off the support.

If I fix the support and the active set S, and the dual weights lambda, then I need to find a such that:
- grad[i] = 2*mu for all i in support
- sum(a) = 1
- a >= 0

The flatness condition gives |support| - 1 independent equations (all grad[i] equal), plus sum(a) = 1 gives one more. Total: |support| equations for |support| unknowns (a[i] for i in support). This is a system of linear equations (since grad is linear in a)!

So I can solve:
[grad matrix] @ a_support = [2*mu] * 1
sum(a_support) = 1

where the grad matrix has entries M[i,j] = contribution of a[j] to grad[i].

M[i,j] = lambda[i+j] (if 0 <= i+j <= 2n-2) + lambda[|i-j|] (if 0 <= |i-j| <= 2n-2)

Wait, let me be more careful. grad[i] = sum_k lambda[k] * (a[k-i] + a[i-k]) where lambda is defined on positions 0 to 2n-2.

The contribution of a[j] to grad[i] is:
- lambda[k] where k - i = j, i.e., k = i + j: contributes lambda[i+j] (if 0 <= i+j <= 2n-2)
- lambda[k] where i - k = j, i.e., k = i - j: contributes lambda[i-j] (if 0 <= i-j <= 2n-2)

So M[i,j] = (lambda[i+j] if 0 <= i+j <= 2n-2 else 0) + (lambda[i-j] if 0 <= i-j <= 2n-2 else 0)

And we need M @ a_support = 2*mu * 1, sum(a_support) = 1.

This is a linear system! I can solve it directly.

But wait, lambda also depends on a (through the LP). So this is a fixed-point problem:
1. Given a, solve LP to get lambda (dual)
2. Given lambda, solve linear system for new a
3. Repeat
