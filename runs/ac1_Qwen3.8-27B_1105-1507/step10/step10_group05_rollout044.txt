**Approach: Iterative "water-filling" based on the dual**

The LP dual gives us weights w_k >= 0 on the convolution positions. The optimal solution satisfies:
- For each i: sum_k w_k * (contribution of a[i] to conv[k]) = lambda (Lagrange multiplier for sum constraint)
- Where "contribution of a[i] to conv[k]" = a[k-i] + a[i-k] (with boundary handling)

This is a fixed-point equation! We can iterate:
1. Start with a
2. Compute conv(a,a)
3. Set w_k = 1 for k where conv is near max, 0 elsewhere
4. Compute the "pressure" on each coordinate: p[i] = sum_k w_k * (a[k-i] + a[i-k])
5. Set a[i] = max(0, c - p[i]) for some constant c (water-filling)
6. Repeat

This is reminiscent of the "peaking" algorithms in OFDM. The constant c is chosen so that sum(a) = 1.

```python
"""
Optimizes step function coefficients to minimize 2*n*max(conv(a,a))/(sum(a))^2.
Uses a combination of:
1. Smoothed gradient descent with adaptive tau and backtracking line search
2. Exact coordinate descent on the non-smoothed objective
3. LP-based refinement
4. Multi-length exploration
5. Peak-reduction water-filling
Key novelty: Exact coordinate descent that directly minimizes the true (non-smooth)
objective by finding the optimal 1D update for each coordinate.
"""

import numpy as np
import time
from scipy.fft import rfft, irfft

def compute_conv(a):
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]

def compute_obj(a):
    n = len(a)
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    conv = compute_conv(a / s)
    return 2.0 * n * float(np.max(conv))

def compute_obj_fast(a, conv=None):
    """Compute objective using precomputed convolution if available."""
    n = len(a)
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    if conv is None:
        conv = compute_conv(a)
    return 2.0 * n * float(np.max(conv)) / (s * s)
```

Now let me think about the coordinate descent more carefully.

For coordinate i, with current value a_i and all other values fixed:
- s_other = sum(a) - a_i
- For a new value t, the new sum is s_other + t
- The convolution values change only for k in [i, i+n-1] (clamped to [0, 2n-2])
- For k in that range (k != 2i): new_conv[k] = conv[k] - 2*a_i*a[k-i] + 2*t*a[k-i]
- For k = 2i (if 2i < 2n-1): new_conv[k] = conv[k] - a_i^2 + t^2
- All other conv values stay the same

The objective is: F(t) = 2n * max(new_conv) / (s_other + t)^2

To find the optimal t:
- The max is the upper envelope of O(n) linear functions (plus one quadratic)
- F(t) is this envelope divided by (s_other + t)^2
- We want to minimize F(t) over t >= 0

Approach: 
1. Find the "current" max and which positions achieve it
2. The optimal t will reduce the max (or keep it the same while increasing the denominator)
3. Use golden-section search on F(t) over t in [0, 3*a_i] (or some reasonable range)

Golden section search requires ~30-40 evaluations to get good precision. Each evaluation is O(n). So per coordinate: 40*n = 32000 operations. For n=800 coordinates: 25.6 million per sweep. That's about 2-3 seconds per sweep. With 20-30 sweeps, that's 60-90 seconds. Very feasible!

Actually, I can be smarter. Since F(t) is the max of linear/quadratic functions divided by a quadratic, it's a "fraction of a convex function" which has special structure. But golden section should work fine.

Let me also consider: instead of golden section over the full range, I can:
1. Find the t that equalizes the top-2 peaks (this is often near optimal)
2. Refine around that point

For the "equalize top-2 peaks" approach:
- Find k1 = argmax(conv), k2 = second-highest
- Find t such that new_conv[k1] / (s_other+t)^2 = new_conv[k2] / (s_other+t)^2
- i.e., new_conv[k1] = new_conv[k2]
- This gives a linear equation in t (or quadratic if one of them is the t^2 term)

This is O(1) after identifying k1, k2. Then refine with a few golden section steps.

```python
    """Find the best value of a[i] given all other coordinates fixed."""
    n = len(a)
    a_i = a[i]
    s_other = float(np.sum(a)) - a_i
    if s_other < 1e-10:
        return a_i, compute_obj_fast(a, conv)
    
    # Affected range
    k_start = max(0, i)
    k_end = min(2*n - 2, i + n - 1)
    
    # Quick check: try a few candidate values
    candidates = [0.0, a_i * 0.5, a_i * 0.8, a_i, a_i * 1.2]
    # Add the "equalize" candidate
    # Find top 2 peaks
    conv_copy = conv.copy()
    top_indices = np.argsort(conv_copy)[::-1][:3]
    
    for k_star in top_indices:
        if k_start <= k_star <= k_end:
            j = k_star - i
            if 0 <= j < n:
                if k_star == 2 * i:
                    # t^2 + (conv[k_star] - a_i^2) = target
                    # Just add as candidate
                    pass
                else:
                    # 2*t*a[j] + (conv[k_star] - 2*a_i*a[j]) = target
                    # For equalization with another peak k2:
                    if len(top_indices) > 1:
                        k2 = top_indices[1]
                        if k_start <= k2 <= k2_end...:
                            pass
    
    # Simpler: just use golden section
    best_t = a_i
    best_obj = compute_obj_fast(a, conv)
    
    # Golden section search on [0, 3*a_i + 1]
    lo = 0.0
    hi = max(3*a_i + 0.1, 0.1)
    
    gr = (np.sqrt(5) - 1) / 2  # golden ratio conjugate
    
    def F(t):
        if t < 0:
            t = 0
        new_sum = s_other + t
        if new_sum < 0.01:
            return np.inf
        # Compute new max conv
        max_val = 0.0
        for k in range(k_start, k_end + 1):
            j = k - i
            if 0 <= j < n:
                if k == 2 * i:
                    val = conv[k] - a_i * a_i + t * t
                else:
                    val = conv[k] + 2 * (t - a_i) * a[j]
            else:
                val = conv[k]
            if val > max_val:
                max_val = val
        # Also check unaffected positions
        # The max of unaffected positions is <= original max
        unaffected_max = np.max(np.concatenate([conv[:k_start], conv[k_end+1:]])) if (k_start > 0 or k_end < 2*n-2) else 0
        max_val = max(max_val, unaffected_max)
        return 2.0 * n * max_val / (new_sum * new_sum)
    
    # Golden section
    x1 = hi - gr * (hi - lo)
    x2 = lo + gr * (hi - lo)
    f1 = F(x1)
    f2 = F(x2)
    
    for _ in range(30):
        if f1 < f2:
            hi = x2
            x2 = x1
            f2 = f1
            x1 = hi - gr * (hi - lo)
            f1 = F(x1)
        else:
            lo = x1
            x1 = x2
            f1 = f2
            x2 = lo + gr * (hi - lo)
            f2 = F(x2)
    
    best_t = (lo + hi) / 2
    best_obj = F(best_t)
    
    return best_t, best_obj
```

```python
def F_vectorized(t, s_other, conv, a, i, n, unaffected_max):
    new_sum = s_other + t
    if new_sum < 0.01:
        return np.inf
    # Affected positions
    k_start = max(0, i)
    k_end = min(2*n - 2, i + n - 1)
    ks = np.arange(k_start, k_end + 1)
    js = ks - i  # These are all in [0, n-1] by construction
    
    if 2 * i >= k_start and 2 * i <= k_end:
        # There's a quadratic term
        new_vals = conv[k_start:k_end+1].copy().astype(np.float64)
        new_vals = new_vals + 2 * (t - a[i]) * a[js]  # linear change
        # Fix the quadratic term
        idx = 2 * i - k_start
        new_vals[idx] = conv[2*i] - a[i]*a[i] + t*t
    else:
        new_vals = conv[k_start:k_end+1] + 2 * (t - a[i]) * a[js]
    
    max_val = max(np.max(new_vals), unaffected_max)
    return 2.0 * n * max_val / (new_sum * new_sum)
```
