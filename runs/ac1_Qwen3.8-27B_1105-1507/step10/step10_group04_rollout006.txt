Actually, let me think about this more carefully. The problem is:
  minimize_{a >= 0, sum(a)=1} max_k conv(a,a)[k]

This is a min-max problem. By the minimax theorem (Sion's theorem), since the feasible set is compact and the function is continuous, the min-max equals the max-min. So:
  min_a max_k f(a,k) = max_{p in simplex} min_a sum_k p_k f(a,k)

where f(a,k) = conv(a,a)[k] = sum_j a[j]*a[k-j].

The inner problem (for fixed p) is:

If I define the matrix T_k with (T_k)_{ij} = 1 if j = i-k (i.e., T_k is a shift matrix shifted by k), then:
conv(a,a)[k] = a^T T_k a where T_k has T_k[i,j] = 1 if j = i-k.

But T_k is not symmetric in general. However, a^T T_k a = a^T (T_k + T_k^T)/2 a (the antisymmetric part doesn't contribute to the quadratic form).

So the inner problem is: minimize a^T Q_p a subject to sum(a)=1, a>=0, where Q_p = (1/2) sum_k p_k (T_k + T_k^T).

This is a convex QP (if Q_p is PSD). Is Q_p PSD? Q_p = (1/2) sum_k p_k (T_k + T_k^T). Each T_k + T_k^T is a symmetric Toeplitz matrix. The sum of PSD matrices is PSD. But are T_k + T_k^T PSD?

T_k + T_k^T has (T_k + T_k^T)[i,j] = 1 if j = i-k OR j = i+k, else 0. This is a symmetric matrix with 1's on the k-th and -k-th diagonals. Its eigenvalues are 2*cos(2*pi*m*k/N) for m = 0,...,N-1 (in the cyclic case). For the linear (non-cyclic) case, it's more complicated, but the matrix is still not necessarily PSD.

For k=0: T_0 + T_0^T = 2I (PSD)
For k=1: T_1 + T_1^T has 1's on the ±1 diagonals. This is the adjacency matrix of a path graph, which has eigenvalues 2*cos(pi*m/(n-1)) for m=0,...,n-1. The minimum eigenvalue is 2*cos(pi*(n-1)/(n-1)) = -2. So it's NOT PSD!
