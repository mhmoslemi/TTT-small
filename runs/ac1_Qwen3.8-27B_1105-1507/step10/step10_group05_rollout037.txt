2. At step t:
   - Compute `k_t = argmax_k C_k(a_t)`
   - Compute subgradient `g_t = ∇C_{k_t}(a_t)` (the gradient of the active quadratic form)
   - Update: `a_{t+1} = proj_simplex(a_t - eta_t * g_t)`
3. Return the average of all iterates

The subgradient method with averaging converges to an O(1/sqrt(T))-approximation for Lipschitz functions. Since our function is smooth (it's actually differentiable almost everywhere), we might do better with accelerated methods.

But the issue is that the "max" makes it non-smooth, and the subgradient is only the gradient of one active component.

**Better approach: Use the smoothed objective with L-BFGS.**

The log-sum-exp smoothing gives a smooth approximation, and L-BFGS should converge quickly (quadratic convergence near the optimum for the smoothed problem). By animating tau to infinity, we approach the true optimum.

Let me estimate the computational cost:
- Each gradient evaluation: O(n log n) for the FFT + O(n) for the rest
- L-BFGS typically needs 100-500 iterations per tau value
- If I use 5-10 tau values: 500-5000 gradient evaluations total
- Total: 500-5000 * O(n log n) ≈ manageable for n=800

This should be much faster than the LP approach (which needs to solve an LP each iteration).

Let me also consider: should I use the simplex projection or the softmax parameterization?

**Simplex projection**: 
- Pro: allows a_i = 0
- Con: projection is O(n log n), and the method is less smooth
- The objective on the simplex is not differentiable at the boundary

**Softmax parameterization**:
- Pro: smooth, unconstrained optimization
- Con: can't reach a_i = 0, might be slower to converge near the boundary
- For our problem, I think all a_i > 0 at the optimum, so this should be fine

I'll go with the softmax parameterization for the main optimization, and use the simplex projection for the LP polishing step.

Now, let me also think about **what makes a good sequence** for this problem.

The objective is `2n * max_k C_k(a) / (sum a)^2`. After normalization (sum a = 1), it's `2n * max_k C_k(a)`.

For a "flat" auto-correlation, we want `C_k(a) ≈ 1/(2n-1)` for all k. This gives objective ≈ `2n/(2n-1) ≈ 1`.

But achieving this is impossible for non-negative sequences (it would require a "perfect difference set" or similar). The best we can do is minimize the maximum deviation from uniform.

One class of sequences that's known to have good auto-correlation properties is related to **Barker sequences** and **m-sequences** (for binary ±1 sequences). For non-negative real sequences, we might be able to do even better.

Another approach: think of it as a **quadratic program**. If I fix which k's are active (i.e., achieve the maximum), the problem becomes:
- min max(C_k(a) : k in active_set)
- s.t. a >= 0, sum a = 1

If I fix the active set and the maximum value M, this becomes:
- s.t. C_k(a) <= M for k in active_set
- C_k(a) <= M for all k (to ensure the active set is correct)
- a >= 0, sum a = 1

This is a quadratic constraint problem, which is harder than an LP.

But the LP approach (fixing a, optimizing g) is a relaxation that's easy to solve. Let me combine both:

"""
Optimizes step function coefficients to minimize 2*n*max(conv(a,a))/(sum(a))^2.
Uses smoothed L-BFGS with tau animation in softmax parameterization,
combined with LP polishing, multi-start diversification, and length exploration.
Key innovations: log-sum-exp smoothing with adaptive temperature, softmax
parameterization for automatic simplex constraint, FFT-based gradient computation,
and systematic multi-length search.
"""

import numpy as np
from scipy.optimize import minimize
from scipy.fft import rfft, irfft
import time
import math


def compute_conv(a):
    """Full linear convolution a*a via FFT. Returns array of length 2n-1."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_n = a / s
    c = compute_conv(a_n)
    return 2.0 * n * float(np.max(c))


def softmax_fn(z):
    """Numerically stable softmax."""
    z = z - np.max(z)
    e = np.exp(z)
    return e / np.sum(e)


def smooth_obj_grad(z, tau):
    """
    Compute smoothed objective and gradient w.r.t. z.
    a = softmax(z), f = 2n * (1/tau) * log(sum_k exp(tau * C_k(a)))
    where C_k = (a*a)[k].
    """
    n = len(z)
    a = softmax_fn(z)
    c = compute_conv(a)  # shape (2n-1,)

    c_max = float(np.max(c))
    scaled = tau * (c - c_max)
    # Clip for numerical stability
    scaled = np.clip(scaled, -500, 500)
    exp_c = np.exp(scaled)
    sum_exp = float(np.sum(exp_c))

    # log(sum exp(tau*c)) = tau*c_max + log(sum_exp)
    # (1/tau) * log(sum exp(tau*c)) = c_max + log(sum_exp)/tau
    lse = c_max + np.log(sum_exp) / tau
    obj = 2.0 * n * lse

    # Softmax weights
    p = exp_c / sum_exp  # shape (2n-1,)

    # Gradient w.r.t. a:
    # g_a[j] = 2n * (2 * X[j] - p[2j] * a[j])
    # where X[j] = sum_m p[m+j] * a[m] (cross-correlation)

    size = 1
    while size < 3 * n + 1:
        size <<= 1
    P = rfft(p, size)
    A = rfft(a, size)
    cross = irfft(np.conj(P) * A, size)
    X = cross[:n]

    g_a = 2.0 * X
    diag_idx = 2 * np.arange(n)
    valid = diag_idx < (2 * n - 1)
    g_a[valid] -= p[diag_idx[valid]] * a[valid]
    g_a *= 2.0 * n

    # Gradient w.r.t. z via softmax Jacobian:
    # df/dz_j = a_j * (g_a_j - sum_i a_i * g_a_i)
    dot = float(np.dot(a, g_a))
    g_z = a * (g_a - dot)

    return obj, g_z


def numerical_grad_check(z, tau, eps=1e-6):
    """Verify gradient correctness numerically."""
    n = len(z)
    obj, g_analytic = smooth_obj_grad(z, tau)
    g_numeric = np.zeros(n)
    for i in range(min(n, 20)):  # Check first 20 components
        z_plus = z.copy()
        z_plus[i] += eps
        z_minus = z.copy()
        z_minus[i] -= eps
        f_plus = smooth_obj_grad(z_plus, tau)[0]
        f_minus = smooth_obj_grad(z_minus, tau)[0]
        g_numeric[i] = (f_plus - f_minus) / (2 * eps)
    diff = np.max(np.abs(g_analytic[:20] - g_numeric))
    return diff


def project_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    idx = np.arange(1, n + 1)
    cond = u * idx > (cssv - 1.0)
    rho = np.where(cond)[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def build_conv_matrix(a):
    """Build matrix A (2n-1 x n) such that A @ g = conv(a, g)."""
    n = len(a)
    A = np.zeros((2 * n - 1, n))

        r = min(n, 2 * n - 1 - j)

def solve_lp(a):
    """Solve LP: min M s.t. conv(a,g)[k] <= M for all k, sum(g)=1, g>=0."""
    import cvxpy as cp
    n = len(a)

                g_val = np.maximum(g.value, 0)

def lp_polish(a, max_iters=5, verbose=False):
    """Apply LP-based polishing: find direction g minimizing peak of a*g, blend."""
    n = len(a)
    a = a.copy()
    s = np.sum(a)
    if s < 1e-10:
        return a
    a = a / s
    best_a = a.copy()
    best_obj = compute_obj(a)

    for it in range(max_iters):
        g = solve_lp(a)
        if g is None:
            break
        # Line search for blend parameter
        best_t = 0.0
        for t in [0.1, 0.2, 0.3, 0.5, 0.7, 1.0]:
            a_try = (1 - t) * a + t * g
            a_try = np.maximum(a_try, 0)
            s_try = np.sum(a_try)
            if s_try < 1e-10:
                continue
            a_try = a_try / s_try
            obj_try = compute_obj(a_try)
            if obj_try < best_obj - 1e-12:
                best_obj = obj_try
                best_a = a_try.copy()
                best_t = t
        if best_t == 0.0:
            break
        a = best_a
        if verbose:
            print(f"    LP iter {it}: obj={best_obj:.8f}, t={best_t}")

    return best_a


def resample_sequence(a, new_n):
    """Resample sequence to new length via linear interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:

        a_clipped = np.maximum(best_a, 1e-15)

def fourier_perturb(a, rng, strength=0.05):
    """Add structured Fourier perturbation."""
    n = len(a)
    pert = np.zeros(n)
    n_modes = min(8, n // 20)
    for k in range(1, n_modes + 1):
        freq = k * 2 * np.pi / n
        amp = strength * rng.uniform(0.2, 1.0) / k
        phase = rng.uniform(0, 2 * np.pi)
        pert += amp * np.cos(freq * np.arange(n) + phase)
    a_new = a * np.exp(pert)
    a_new = np.maximum(a_new, 0)
    s = np.sum(a_new)
    if s < 1e-10:
        return a.copy()
    return a_new / s

                print(f"Parent: n={n_init}, obj={best_score:.8f}")
    except Exception:
        best_seq = np.ones(n_init) / n_init
        best_score = compute_obj(best_seq)
        print(f"Default init: n={n_init}, obj={best_score:.8f}")

    # === Phase 1: Main smoothed L-BFGS on parent ===
    print("\n=== Phase 1: Smoothed L-BFGS (parent) ===")
    remaining = deadline - time.monotonic()
    p1_budget = min(remaining * 0.25, 300.0)
    if p1_budget > 30:
        a_opt = smooth_lbfgs_optimize(best_seq, time_budget=p1_budget, verbose=True)
        obj = compute_obj(a_opt)
        if obj < best_score:
            best_score = obj
            best_seq = a_opt.copy()
            print(f"  Phase 1: obj={best_score:.8f} **")
        else:
            print(f"  Phase 1: obj={obj:.8f} (no improvement)")

    # === Phase 2: LP polishing ===
    print("\n=== Phase 2: LP Polishing ===")
    remaining = deadline - time.monotonic()
    p2_budget = min(remaining * 0.1, 120.0)
    if p2_budget > 20:
        a_lp = lp_polish(best_seq, max_iters=10, verbose=True)
        obj = compute_obj(a_lp)
        if obj < best_score:
            best_score = obj
            best_seq = a_lp.copy()
            print(f"  LP: obj={best_score:.8f} **")
        else:
            print(f"  LP: obj={obj:.8f} (no improvement)")

    # === Phase 3: More L-BFGS with higher tau (refinement) ===
    print("\n=== Phase 3: High-tau L-BFGS refinement ===")
    remaining = deadline - time.monotonic()
    p3_budget = min(remaining * 0.15, 200.0)
    if p3_budget > 30:
        a_ref = smooth_lbfgs_optimize(best_seq, time_budget=p3_budget, verbose=True)
        obj = compute_obj(a_ref)
        if obj < best_score:
            best_score = obj
            best_seq = a_ref.copy()
            print(f"  Refine: obj={best_score:.8f} **")
        else:
            print(f"  Refine: obj={obj:.8f} (no improvement)")

    # === Phase 4: Multi-start diversification ===
    print("\n=== Phase 4: Multi-start Diversification ===")
    n_current = len(best_seq)
    n_starts = 6

    for r in range(n_starts):
        remaining = deadline - time.monotonic()
        if remaining < 60:
            break

        if r == 0:
            a_r = fourier_perturb(best_seq, rng, strength=0.03)
        elif r == 1:
            a_r = random_perturb(best_seq, rng, strength=0.05)
        elif r == 2:
            # Blend with uniform
            a_r = 0.8 * best_seq + 0.2 * np.ones(n_current) / n_current
            a_r = a_r / a_r.sum()
        elif r == 3:
            # Cosine-weighted
            x = np.linspace(0, 1, n_current)
            w = 0.5 + 0.5 * np.cos(np.pi * x)
            a_r = best_seq * (1 + 0.1 * rng.standard_normal(n_current))
            a_r = np.maximum(a_r, 0)
            a_r = a_r / a_r.sum()
        elif r == 4:
            # Mirror symmetric perturbation
            a_r = (best_seq + best_seq[::-1]) / 2.0
            a_r = a_r / a_r.sum()
            a_r = fourier_perturb(a_r, rng, strength=0.02)
        else:
            # Stronger perturbation
            a_r = random_perturb(best_seq, rng, strength=0.1)

        alloc = min(remaining * 0.15, 100.0)
        if alloc > 20:
            a_r = smooth_lbfgs_optimize(a_r, time_budget=alloc, verbose=False)
            obj_r = compute_obj(a_r)
            if obj_r < best_score:
                best_score = obj_r
                best_seq = a_r.copy()
                print(f"  Start {r}: obj={best_score:.8f} **")
            else:
                print(f"  Start {r}: obj={obj_r:.8f}")

    # === Phase 5: Length exploration ===
    print("\n=== Phase 5: Length Exploration ===")
    n_best = len(best_seq)
    n_candidates = []
    for dn in [-100, -75, -50, -25, 25, 50, 75, 100, 150, 200]:
        n_try = n_best + dn
        if 400 <= n_try <= 2000:
            n_candidates.append(n_try)
    n_candidates = sorted(set(n_candidates))[:6]
    print(f"  Trying lengths: {n_candidates}")

    for n_try in n_candidates:
        remaining = deadline - time.monotonic()
        if remaining < 60:
            break

        a_try = resample_sequence(best_seq, n_try)
        a_try = a_try / a_try.sum()

        alloc = min(remaining * 0.15, 100.0)
        if alloc > 20:
            a_try = smooth_lbfgs_optimize(a_try, time_budget=alloc, verbose=False)
            obj_try = compute_obj(a_try)
            # For fair comparison, the objective already accounts for n
            if obj_try < best_score:
                best_score = obj_try
                best_seq = a_try.copy()
                print(f"  n={n_try}: obj={best_score:.8f} **")
            else:
                print(f"  n={n_try}: obj={obj_try:.8f}")

    # === Phase 6: Final intensive polish ===
    print("\n=== Phase 6: Final Polish ===")
    remaining = deadline - time.monotonic()

    # LP polish
    if remaining > 40:
        a_final = lp_polish(best_seq, max_iters=8, verbose=True)
        obj = compute_obj(a_final)
        if obj < best_score:
            best_score = obj
            best_seq = a_final.copy()
            print(f"  Final LP: obj={best_score:.8f} **")

    # One more L-BFGS round with very high tau
    remaining = deadline - time.monotonic()
    if remaining > 30:
        a_final = smooth_lbfgs_optimize(best_seq, time_budget=min(remaining * 0.5, 100.0),
                                        verbose=True)
        obj = compute_obj(a_final)
        if obj < best_score:
            best_score = obj
            best_seq = a_final.copy()
            print(f"  Final LBFGS: obj={best_score:.8f} **")

    # Final LP
    remaining = deadline - time.monotonic()
    if remaining > 30:
        a_final = lp_polish(best_seq, max_iters=5, verbose=True)
        obj = compute_obj(a_final)
        if obj < best_score:
            best_score = obj
            best_seq = a_final.copy()
            print(f"  Ultra-final LP: obj={best_score:.8f} **")

    # Final validation
    if best_seq is None:
        best_seq = np.ones(100)
        best_score = 2.0

    result = [float(max(0.0, min(1000.0, x))) for x in best_seq]
    val = evaluate_sequence(result)
    if val < np.inf:
        best_score = val
    else:
        result = [1.0] * 100
        best_score = 2.0

    elapsed = time.monotonic() - start_time
    print(f"\n=== FINAL: n={len(result)}, score={best_score:.8f}, time={elapsed:.1f}s ===")

    return result
