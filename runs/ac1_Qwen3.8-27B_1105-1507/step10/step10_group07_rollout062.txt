This is a QCQP (quadratically constrained quadratic program) or can be seen as a non-convex optimization (since the feasible set is not convex in (a, t) due to the bilinear constraints).

Wait, actually (a*a)[k] = sum_j a[j]*a[k-j] is a quadratic form in a. Specifically, it's a^T Q_k a where Q_k is a symmetric matrix. The constraint a^T Q_k a ≤ t is not convex (Q_k is generally indefinite... actually for autocorrelation, Q_k has a specific structure).

For k = n-1 (center): a^T Q a = sum_i a[i] * a[n-1-i]. The matrix Q has Q[i,j] = 1 if i+j = n-1, 0 otherwise. This is the "exchange matrix" (anti-identity). It has eigenvalues +1 and -1 (and 0 if n is even and we're not careful). So it's indefinite, and the constraint is non-convex.

So the problem is genuinely non-convex! That's why we get values below 2.

Now I understand the problem better. The key is to find a sequence where ALL autocorrelation lags are small, not just the center one.

For the uniform sequence, the center lag is 1/n and all lags decrease linearly from the center. The max is at the center.

To beat this, we need to reduce the center lag below 1/n while keeping all other lags also below 1/n. This means we need a sequence where the "anti-diagonal" sum sum_i a[i]*a[n-1-i] < 1/n.

By AM-GM, a[i]*a[n-1-i] ≤ (a[i] + a[n-1-i])/2. Summing: sum_i a[i]*a[n-1-i] ≤ sum_i (a[i]+a[n-1-i])/2 = sum_i a[i] = 1. That's a useless bound.

But we can do better. If a[i] = a[n-1-i] for all i (palindromic), then a[i]*a[n-1-i] = a[i]^2, and sum = sum(a_i^2) ≥ 1/n. So palindromic sequences can't beat 2.

For non-palindromic sequences, we can have a[i]*a[n-1-i] < a[i]^2 for some i (when a[n-1-i] < a[i]) and > a[i]^2 for others. The question is whether the sum can be < 1/n.

Sum_i a[i]*a[n-1-i] < 1/n would require the "anti-diagonal pairing" to be favorable. This is like finding a permutation π (specifically, the anti-identity π(i) = n-1-i) such that sum a[i]*a[π(i)] < 1/n.

This is related to the rearrangement inequality! The anti-identity is a "reverse" permutation. By the rearrangement inequality, sum_i a[i]*a[π(i)] is minimized when one sequence is sorted ascending and the other descending (i.e., anti-sorted). So the minimum of sum a[i]*a[n-1-i] over all orderings of the values is achieved when a is sorted in one direction at one end and the other at the other end.

But we can't freely permute - the sequence positions are fixed! We're choosing the values, not the permutation.

For the LP-based peak reduction, here's a faster approach:
- Given current a, find the active lags S = {k : conv[k] ≥ M - eps}
- We want to find a direction d such that the active lags decrease
- The change in conv[k] for direction d is: delta[k] = 2 * conv(a, d)[k] + conv(d, d)[k]
- For small d, approx delta[k] ≈ 2 * conv(a, d)[k]
- We want conv(a, d)[k] < 0 for k in S (to reduce peaks)
- And sum(d) = 0 (to maintain normalization) or we handle it separately
- And a + d ≥ 0

This is essentially finding a d that has negative "cross-correlation" with a at the peak lags.

A simple approach: d = -a shifted by the peak lag. I.e., if the peak is at lag k*, then d[i] = -a[k*-i] (clipped to keep a+d ≥ 0).

Let me implement a fast version of the LP using bisection:

The LP is:
min M
s.t. (a*g)[k] ≤ M for all k
     sum(g) = 1
     g ≥ 0

This is equivalent to:
min M
s.t. sum_j g[j] * a[k-j] ≤ M for all k (where a[m]=0 if out of range)
     sum(g) = 1
     g ≥ 0

The constraint matrix is the convolution matrix of a, which is banded (each column has at most n nonzeros, but actually the convolution matrix is fine-structured).

For the bisection approach:
- Given M, check if there exists g ≥ 0, sum(g)=1, with (a*g)[k] ≤ M for all k
- This is a feasibility LP with n+1 variables (g[0..n-1] and sum constraint) and 2n-1 constraints
- We can check feasibility using the simplex method or by checking if the polytope is non-empty

Actually, for checking feasibility at a given M, we can use the following:
The constraints are: A @ g ≤ M * 1, where A[k,j] = a[k-j] (with appropriate indexing)
And: sum(g) = 1, g ≥ 0

The feasible set is a slice of the simplex. It's non-empty if and only if:
M ≥ min_{g ≥ 0, sum(g)=1} max_k (A*g)[k]

Which is exactly M* (the optimal value). So we can't easily check feasibility without solving the LP.

Alternative: use the dual. The dual of:
min M
s.t. A*g ≤ M*1
     1^T g = 1
     g ≥ 0

The dual is:

s.t. A^T y ≤ M' (where M' is the dual of M)
     y ≥ 0
     1^T y = 1

**Subgradient method for the LP**: 
The LP min max_k (a*g)[k] s.t. sum(g)=1, g≥0 can be solved by:
- Start with g = a/sum(a) (uniform on the support of a)
- Compute (a*g)[k] for all k
- Find the active set S
- Move g in the direction that reduces the active lags: g_new = g - eta * grad
- Project onto simplex

The gradient of max_k (a*g)[k] w.r.t. g is (1/|S|) * sum_{k∈S} (a reversed and shifted by k).

This is essentially the same as the subgradient method I described earlier, applied to g instead of a. The key difference is that here we're finding the LP direction (what g to mix with a), while the subgradient on a directly modifies a.

```python
import numpy as np
from scipy.fft import rfft, irfft, fft, ifft
import time

def compute_conv(a):
    """Full linear convolution a*a via FFT."""
    n = len(a)
    if n <= 1:
        return np.array([a[0]*a[0]]) if n == 1 else np.array([])
    size = 1
    while size < 2*n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2*n-1]

def compute_obj(a):
    """Compute 2n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    s = float(a.sum())
    if s < 1e-10:
        return np.inf
    conv = compute_conv(a)
    return 2.0 * n * float(np.max(conv)) / (s * s)

def project_simplex(v, target_sum=1.0):
    """Project v onto {x >= 0, sum(x) = target_sum}."""
    v = np.asarray(v, dtype=np.float64)
    n = len(v)
    if n == 0:
        return v
    # Project onto simplex with sum = target_sum
    # Scale: project v/target_sum onto standard simplex, then scale back
    u = np.sort(v / target_sum)[::-1]
    cssv = np.cumsum(u)
    idx = np.arange(1, n+1)
    cond = u * idx > (cssv - 1.0)
    rho_set = np.where(cond)[0]
    if len(rho_set) == 0:
        return np.full(n, target_sum / n)
    rho = rho_set[-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    result = np.maximum(v - theta * target_sum, 0.0)
    # Fix sum
    s = result.sum()
    if s > 1e-15:
        result = result * target_sum / s
    return result

def resample_sequence(a, new_n):
    """Resample sequence to new length via linear interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, a[0])
    x_old = np.linspace(0, 1, n, endpoint=True)
    x_new = np.linspace(0, 1, new_n, endpoint=True)
    return np.maximum(np.interp(x_new, x_old, a), 0.0)
```

"""
High-velocity coordinate descent + fast LP-direction subgradient hybrid optimizer.
Key innovations over previous approach:
1. Extremely fast coordinate descent (O(n^2) per pass via incremental conv update)
2. Fast LP-direction finding via subgradient on the dual (no CVXPY bottleneck)

4. Aggressive multi-length exploration with structured initializations

import numpy as np
from scipy.fft import rfft, irfft, fft, ifft
import time


def compute_conv(a):
    """Full linear convolution a*a via FFT. Returns array of length 2n-1."""
    n = len(a)
    if n == 0:
        return np.array([])
    if n == 1:
        return np.array([a[0] * a[0]])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 1e-10:
        return np.inf
    conv = compute_conv(a)
    return 2.0 * n * float(np.max(conv)) / (s * s)


def project_simplex(v, target_sum=1.0):
    """Project v onto {x >= 0, sum(x) = target_sum}."""
    v = np.asarray(v, dtype=np.float64)
    n = len(v)
    if n == 0:
        return v
    if n == 1:
        return np.array([max(0.0, target_sum)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    idx = np.arange(1, n + 1)
    cond = u * idx > (cssv - target_sum)
    rho_set = np.where(cond)[0]
    if len(rho_set) == 0:
        return np.full(n, target_sum / n)
    rho = rho_set[-1]
    theta = (cssv[rho] - target_sum) / (rho + 1.0)
    result = np.maximum(v - theta, 0.0)
    s = result.sum()
    if s > 1e-15:
        result = result * target_sum / s
    return result


def resample_sequence(a, new_n):
    """Resample sequence to new length via linear interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, a[0])
    x_old = np.linspace(0, 1, n, endpoint=True)
    x_new = np.linspace(0, 1, new_n, endpoint=True)
    return np.maximum(np.interp(x_new, x_old, a), 0.0)


def coord_descent_fast(a, time_budget=100.0, verbose=False, seed=42):
    """
    Fast coordinate descent with incremental convolution updates.
    Works on normalized sequences (sum=1).
    """
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64).copy()
    s = a.sum()
    if s < 1e-10:
        return a
    a = a / s

    conv = compute_conv(a)
    best_a = a.copy()
    best_obj = 2.0 * n * float(np.max(conv))
    start = time.monotonic()
    rng = np.random.default_rng(seed)
    it = 0
    no_improve = 0

    while time.monotonic() - start < time_budget:
        order = rng.permutation(n)

        for i in order:
            ai = a[i]
            if ai < 1e-14:
                continue

            # Profile: d(conv[k])/d(a[i]) = 2*a[k-i] for valid k-i
            lo = i
            hi = min(2 * n - 2, i + n - 1)
            if lo > hi:
                continue
            prof_len = hi - lo + 1
            # prof[k] = 2*a[k-i] for k in [lo, hi], i.e., a[0], a[1], ..., a[prof_len-1]
            prof = 2.0 * a[:prof_len]

            # Determine which direction to try
            current_max = float(np.max(conv))
            # Find peak lags and their sensitivity
            peak_threshold = current_max * 0.995
            peak_lags = np.where(conv >= peak_threshold)[0]

            peak_sens = []
            for k in peak_lags[:20]:
                ki = int(k) - i
                if 0 <= ki < n:
                    peak_sens.append(2.0 * a[ki])

            if peak_sens:
                avg_sens = float(np.mean(peak_sens))
            else:
                avg_sens = 0.0

            # Generate candidate d values
            if avg_sens > 1e-8:
                fracs = [0.0, -0.02, -0.05, -0.1, -0.2, -0.35, -0.5, -0.7]
            elif avg_sens < -1e-8:
                fracs = [0.0, 0.02, 0.05, 0.1, 0.2, 0.35, 0.5]
            else:
                fracs = [0.0, -0.05, 0.05, -0.15, 0.15]

            best_d = 0.0
            best_val = 2.0 * n * current_max

            for f in fracs:
                d = f * ai
                if ai + d < -1e-14:
                    continue
                s_new = 1.0 + d
                if s_new < 1e-10:
                    continue

                # Compute new max efficiently
                # conv[lo:hi+1] changes by d*prof, rest unchanged
                updated_slice = conv[lo:hi + 1] + d * prof
                new_max = float(np.max(updated_slice))
                # Check lags outside [lo, hi]
                if lo > 0:
                    outer_max = float(np.max(conv[:lo]))
                    if outer_max > new_max:
                        new_max = outer_max
                if hi < 2 * n - 2:
                    outer_max2 = float(np.max(conv[hi + 1:]))
                    if outer_max2 > new_max:
                        new_max = outer_max2

                obj_val = 2.0 * n * new_max / (s_new * s_new)
                if obj_val < best_val - 1e-14:
                    best_val = obj_val
                    best_d = d

            if best_d != 0.0:
                a[i] = ai + best_d
                # Incrementally update conv (using current a as approximation)
                conv[lo:hi + 1] += best_d * prof

        # End of pass: recompute conv and renormalize
        s = a.sum()
        if s < 1e-10:
            break
        a = a / s
        conv = compute_conv(a)

        curr_obj = 2.0 * n * float(np.max(conv))
        if curr_obj < best_obj - 1e-12:
            best_obj = curr_obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
            if no_improve > 20:
                scale = min(0.08, 0.015 * no_improve)
                a = a * np.exp(rng.normal(0, scale, n))
                a = np.maximum(a, 0.0)
                s = a.sum()
                if s < 1e-10:
                    a = best_a.copy()
                else:
                    a = a / s
                conv = compute_conv(a)
                no_improve = 0
                if it > 300:
                    break

        it += 1
        if verbose and it % 30 == 0:
            print(f"    CD it{it}: best={best_obj:.8f}, t={time.monotonic()-start:.0f}s")

    return best_a


def fast_lp_direction_subgrad(a, time_budget=60.0, verbose=False, seed=0):
    """
    Find LP direction g via subgradient method on the dual problem.
    Solves: min_g max_k (a*g)[k] s.t. g>=0, sum(g)=1
    using subgradient iterations (much faster than CVXPY).
    """
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = a.sum()
    if s < 1e-10:
        return None
    a_norm = a / s

    # Initialize g
    g = a_norm.copy()

    start = time.monotonic()
    rng = np.random.default_rng(seed)
    eta = 1.0 / np.sqrt(n)
    momentum = 0.75
    v = np.zeros(n)
    it = 0

    # Warm iterations to converge
    max_iters = int(time_budget * 30000)  # estimate max iterations

    while time.monotonic() - start < time_budget and it < max_iters:
        # Compute (a_norm * g) via FFT
        conv_ag = compute_conv_cross(a_norm, g)

        # Find active set (top peaks)
        max_val = float(np.max(conv_ag))
        if max_val < 1e-15:
            break

        # Subgradient: average of shifted/reversed a_norm at active lags
        peak_thresh = max_val * (1.0 - 0.01 * min(it / 100.0, 1.0))
        active = np.where(np.abs(conv_ag - max_val) < 0.05 * max_val)[0]
        if len(active) == 0:
            active = np.argsort(conv_ag)[::-1][:10]
        active = active[:50]  # limit

        # Gradient of max_k (a*g)_k w.r.t. g
        # d/dg_j [(a*g)_k] = a[k-j] (if valid)
        # So grad = (1/|active|) * sum_{k in active} shift_reverse(a, k)
        grad = np.zeros(n)
        for k in active:
            k = int(k)
            # (a*g)_k = sum_j a[k-j] * g[j]
            # d/dg_j = a[k-j] if 0 <= k-j < n
            # For valid j: k-n+1 <= j <= k, clipped to [0, n-1]
            j_start = max(0, k - (n - 1))
            j_end = min(n - 1, k)
            if j_start <= j_end:
                # a[k-j] for j in [j_start, j_end] = a[k-j_end] to a[k-j_start]
                # = a reversed and shifted
                a_slice = a[k - j_end:k - j_start + 1][::-1]
                grad[j_start:j_end + 1] += a_slice
        grad /= len(active)

        # Momentum update
        v = momentum * v + grad
        g_new = g - eta * v
        g_new = project_simplex(g_new, 1.0)

        # Check for improvement
        conv_new = compute_conv_cross(a_norm, g_new)
        max_new = float(np.max(conv_new))
        if it % 10 == 0 or it < 5:
            pass  # skip detailed tracking for speed

        g = g_new
        eta *= 0.9998
        it += 1

    return g


def compute_conv_cross(a, b):
    """Cross-convolution a*b via FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    fb = rfft(b, size)
    return irfft(fa * fb, size)[:2 * n - 1]


def subgradient_peak(a, time_budget=80.0, K=10, verbose=False, seed=0):
    """
    Subgradient method directly on a with peak weighting.
    Minimizes max_k conv_k subject to sum(a)=1, a>=0.
    """
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = a.sum()
    if s < 1e-10:
        return a
    a = a / s

    best_a = a.copy()
    best_obj = 2.0 * n * float(np.max(compute_conv(a)))
    start = time.monotonic()
    rng = np.random.default_rng(seed)

    lr = 3.0 / np.sqrt(n)
    momentum = 0.75
    v = np.zeros(n)
    it = 0
    stall = 0

    # Temperature schedule for softmax weighting of peaks
    tau_start = 2.0
    tau_end = 30.0

    while time.monotonic() - start < time_budget:
        progress = min(1.0, (time.monotonic() - start) / time_budget)
        tau = tau_start * (tau_end / tau_start) ** (progress ** 0.7)

        conv = compute_conv(a)
        max_conv = float(np.max(conv))

        if max_conv < 1e-15:
            break

        # Weighted subgradient using top peaks with softmax
        # Get the "profile" at top K peaks
        top_idx = np.argsort(conv)[::-1][:K]
        peak_vals = conv[top_idx]
        weights = np.exp(tau * (peak_vals - max_conv) / max_conv)
        weights /= weights.sum()

        # Gradient: (1/|S|) sum w_k * grad_k where grad_k[i] = 2*a[k-i]
        grad = np.zeros(n)
        for w, k in zip(weights, top_idx):
            k = int(k)
            # d(conv_k)/d(a_i) = 2*a[k-i] if 0<=k-i<n
            j_start = max(0, k - (n - 1))
            j_end = min(n - 1, k)
            if j_start <= j_end:
                a_slice = a[k - j_end:k - j_start + 1][::-1]
                grad[j_start:j_end + 1] += 2.0 * w * a_slice

        # Momentum and update
        v = momentum * v + grad
        a_new = a - lr * v
        a_new = project_simplex(a_new, 1.0)

        obj_new = 2.0 * n * float(np.max(compute_conv(a_new)))
        if obj_new < best_obj - 1e-13:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new
            stall = 0
        else:
            stall += 1
            if stall > 300:
                lr *= 0.5
                v *= 0.2
                stall = 0
                if lr < 1e-12:
                    break
            else:
                lr *= 0.999

        it += 1

    return best_a

        # Line search

        best_t_obj = best_obj
        for t in [0.03, 0.06, 0.1, 0.15, 0.2, 0.3, 0.4, 0.5, 0.7, 1.0]:

            a_try = np.maximum(a_try, 0.0)
            s_try = a_try.sum()
            if s_try < 1e-10:

def structured_init(n, kind='sine', rng=None):
    """Create structured initializations."""
    if rng is None:
        rng = np.random.default_rng(0)

    if kind == 'sine':
        a = np.sin(np.pi * (np.arange(n) + 0.5) / n)
    elif kind == 'gaussian':
        center = n / 2.0
        sigma = n / 4.0
        a = np.exp(-((np.arange(n) - center) / sigma) ** 2)
    elif kind == 'power_up':
        a = (np.arange(n) + 1) ** 0.5
    elif kind == 'power_down':
        a = (n - np.arange(n)) ** 0.5
    elif kind == 'bimodal':
        c1, c2 = n * 0.3, n * 0.7
        a = np.exp(-((np.arange(n) - c1) / (n * 0.1)) ** 2) + \
            np.exp(-((np.arange(n) - c2) / (n * 0.1)) ** 2)
    elif kind == 'linear_taper':
        a = np.minimum(np.arange(n) + 1, n - np.arange(n)).astype(float)
    else:
        a = np.ones(n)

    a = np.maximum(a, 0.0)
    a = a / a.sum()
    return a

            best_seq = a_cd.copy()
            print(f"  Main CD: {best_score:.8f} **")
        else:
            print(f"  Main CD: {obj_cd:.8f}")

    # === Phase 3: LP-direction search ===
    print("\n=== Phase 3: LP-Direction Search ===")
    remaining = deadline - time.monotonic()
    if remaining > 40:
        lp_budget = min(remaining * 0.20, 200.0)
        a_lp = lp_direction_line_search(best_seq, time_budget=lp_budget, verbose=True, seed=20)
        obj_lp = compute_obj(a_lp)
        if obj_lp < best_score:
            best_score = obj_lp
            best_seq = a_lp.copy()
            print(f"  LP-Dir: {best_score:.8f} **")
        else:
            print(f"  LP-Dir: {obj_lp:.8f}")

    # === Phase 4: Second CD round (after LP direction) ===
    print("\n=== Phase 4: CD Polish Round 2 ===")
    remaining = deadline - time.monotonic()
    if remaining > 30:
        cd_budget = min(remaining * 0.15, 150.0)
        a_cd2 = coord_descent_fast(best_seq, time_budget=cd_budget, seed=30)
        obj_cd2 = compute_obj(a_cd2)
        if obj_cd2 < best_score:
            best_score = obj_cd2
            best_seq = a_cd2.copy()
            print(f"  CD Round 2: {best_score:.8f} **")
        else:
            print(f"  CD Round 2: {obj_cd2:.8f}")

    # === Phase 5: Multi-length exploration ===
    print("\n=== Phase 5: Multi-Length Exploration ===")
    remaining = deadline - time.monotonic()
    n_current = len(best_seq)

    # Generate candidate lengths
    n_candidates = set()
    for delta in [-200, -100, 100, 200, 300, 500]:
        n_try = n_current + delta
        if 300 <= n_try <= 2500:
            n_candidates.add(n_try)
    # Add some fixed lengths
    for n_fixed in [600, 800, 1000, 1200, 1500, 1800, 2000, 2500]:
        if abs(n_fixed - n_current) > 50:
            n_candidates.add(n_fixed)

    n_candidates = sorted(n_candidates)
    # Filter to most promising (not too many)
    n_candidates = [n for n in n_candidates if 300 <= n <= 2500][:8]
    # Sort by distance from current (try nearby first)
    n_candidates.sort(key=lambda x: abs(x - n_current))

    for n_try in n_candidates:
        remaining = deadline - time.monotonic()
        if remaining < 40:
            break

        print(f"  Trying n={n_try} (remaining={remaining:.0f}s)")

        # Resample
        a_try = resample_sequence(best_seq, n_try)

        # Also try structured init
        a_struct = structured_init(n_try, 'sine', rng)
        # Mix: 50/50
        a_try = 0.5 * a_try + 0.5 * a_struct
        a_try = a_try / a_try.sum()

        # Optimize at this length
        alloc_cd = min(remaining * 0.35, 60.0)
        if alloc_cd > 10:
            a_try = coord_descent_fast(a_try, time_budget=alloc_cd, seed=n_try)

        remaining = deadline - time.monotonic()
        alloc_sg = min(remaining * 0.3, 30.0)
        if alloc_sg > 5:
            a_try = subgradient_peak(a_try, time_budget=alloc_sg, K=6, seed=n_try)

        obj_try = compute_obj(a_try)
        if obj_try < best_score:
            best_score = obj_try
            best_seq = a_try.copy()
            n_current = n_try
            print(f"  ** n={n_try}: obj={best_score:.8f} **")
        else:
            print(f"  n={n_try}: obj={obj_try:.8f}")

    # === Phase 6: Perturbation + re-optimization ===
    print("\n=== Phase 6: Perturbation + Re-optimization ===")
    remaining = deadline - time.monotonic()

    for p_idx in range(8):
        remaining = deadline - time.monotonic()
        if remaining < 30:
            break

        scale = 0.008 + 0.006 * p_idx
        a_pert = best_seq * np.exp(rng.normal(0, scale, len(best_seq)))
        a_pert = np.maximum(a_pert, 0.0)
        a_pert = a_pert / a_pert.sum()

        # Also try structured perturbation
        if p_idx % 3 == 0:
            a_struct = structured_init(len(best_seq), ['sine', 'gaussian', 'bimodal'][p_idx % 3], rng)
            a_pert = (1 - 0.3) * a_pert + 0.3 * a_struct
            a_pert = a_pert / a_pert.sum()

        alloc = min(remaining * 0.3, 80.0)
        if alloc > 10:
            a_pert = coord_descent_fast(a_pert, time_budget=alloc, seed=100 + p_idx)
            obj_pert = compute_obj(a_pert)
            if obj_pert < best_score:
                best_score = obj_pert
                best_seq = a_pert.copy()
                print(f"  Pert{p_idx} (s={scale:.4f}): obj={best_score:.8f} **")
            else:
                print(f"  Pert{p_idx} (s={scale:.4f}): obj={obj_pert:.8f}")

    # === Phase 7: Final intensive polish ===
    print("\n=== Phase 7: Final Polish ===")
    remaining = deadline - time.monotonic()
    if remaining > 20:
        final_budget = min(remaining * 0.6, 120.0)
        a_final = coord_descent_fast(best_seq, time_budget=final_budget, seed=999)
        obj_final = compute_obj(a_final)
        if obj_final < best_score:
            best_score = obj_final
            best_seq = a_final.copy()
            print(f"  Final CD: {best_score:.8f} **")
        else:
            print(f"  Final CD: {obj_final:.8f}")

    # Final LP-direction pass
    remaining = deadline - time.monotonic()
    if remaining > 15:
        lp_final_budget = min(remaining * 0.5, 40.0)
        a_final_lp = lp_direction_line_search(best_seq, time_budget=lp_final_budget, seed=2000)
        obj_flp = compute_obj(a_final_lp)
        if obj_flp < best_score:
            best_score = obj_flp
            best_seq = a_final_lp.copy()
            print(f"  Final LP: {best_score:.8f} **")

    # === Output ===
    if best_seq is None:
        best_seq = np.ones(200) / 200.0
        best_score = compute_obj(best_seq)

    # Clamp to valid range
    result = [float(max(0.0, min(1000.0, x))) for x in best_seq]

    # Validate
    val = evaluate_sequence(result)
    if val < np.inf and val < best_score
