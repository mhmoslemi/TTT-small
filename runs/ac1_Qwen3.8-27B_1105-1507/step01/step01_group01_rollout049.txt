**Critical insight**: The convolution (a*a)[k] for a length-n sequence is a polynomial in the "generating function" A(x) = sum a_i x^i. Specifically, (a*a)[k] is the coefficient of x^k in A(x)^2.

So we're looking for a polynomial A(x) with non-negative coefficients such that A(x)^2 is as flat as possible (all coefficients equal).

If A(x)^2 = c * (1 + x + x^2 + ... + x^{2n-2}), then all convolution values are equal = c = (sum a)^2/(2n-1).

This would require A(x) = sqrt(c) * sqrt(1 + x + ... + x^{2n-2}), which generally doesn't have non-negative coefficients.

So we need the best approximation to this ideal.

We want to find a non-negative coefficient polynomial A(x) of degree n-1 such that A(x)^2 is as close as possible to a constant times (1 + x + ... + x^{2n-2}).

We want to minimize max_k |A(x)^2 - B(x)|_k (the max coefficient difference).

def multiplicative_update(a, pressure, eta, flatten_weight=0.0):
    """
    Multiplicative update: a[j] *= exp(-eta * (pressure[j] - mean(pressure)))
    Optionally blend with uniform to prevent over-concentration.
    """
    n = len(a)
    p = pressure - float(np.mean(pressure))
    # Scale pressure for numerical stability
    pmax = float(np.max(np.abs(p)))
    if pmax > 1e-30:
        p = p / pmax
    
    a_new = a * np.exp(-eta * p)
    a_new = np.clip(a_new, 1e-10, 1000.0)
    
    if flatten_weight > 0:
        uniform = np.ones(n) / n
        a_new = (1 - flatten_weight) * a_new + flatten_weight * uniform
        a_new = np.clip(a_new, 0.0, 1000.0)

    if a_new is None:

    Choose a flat-ish power spectrum and randomize phases.

    L = 1
    while L < 2 * n - 1:
        L *= 2

    A = np.zeros(L, dtype=np.complex128)
    A[0] = n  # DC component (sum of a will be n)

    # We want |A(k)|^2 to be roughly constant for k=1,...,L-1
    # But the total energy is constrained: sum|A(k)|^2 = L * sum|a_padded|^2
    # Let's just use a moderate constant

    mag[0] = 0  # handle DC separately

    A_mag = np.ones(L)
    A_mag[0] = n
    A_mag[1:] = rng.exponential(1.0, L - 1) * 0.5
    A_mag[-1] = A_mag[1]  # conjugate symmetry for real signal
    
    A = A_mag * np.exp(1j * phase)
    # Enforce conjugate symmetry for real output
    A[-(L//2):0:-1] = np.conj(A[1:L//2+1])
    if L % 2 == 0:
        A[L//2] = float(A[L//2].real)  # Nyquist is real
    
    a_full = np.fft.irfft(A, L)
    a = a_full[:n]
    a = np.clip(a, 0.0, None)
    return normalize(a)

def random_init(n, seed, kind=0):

def normalize(a):
    a = np.asarray(a, dtype=np.float64)
    a = np.clip(a, 0.0, 1000.0)
    s = float(a.sum())
    if not np.isfinite(s) or s < 1e-300:

    n = len(a)
    if n == 0:
