   Let me think about this differently. The problem is essentially:
   
   Minimize max_k c[k] / (sum f)^2 subject to f >= 0, where c = f * f (linear convolution).

   The average of c[k] is 1/(2n-1) (since sum(c) = (sum(f))^2 = 1).

   Now, what optimization methods can find such sequences?
   
   Key approach: This is a minimax problem. We can use:
   1. **Multiplicative weights / Freund-Schapire**: Maintain weights on the lags k, and update f to minimize the weighted average of c[k]. The weights concentrate on the lags where c is largest.
   
   2. **Bisection on the max**: Binary search on M. For a given M, check if there exists f >= 0, sum(f) = 1, such that c[k] <= M for all k. This is a linear feasibility problem! (Because c[k] is linear in f if we fix the "other" f... wait, no, c[k] = sum_i f[i]*f[k-i] is quadratic in f.)
   
   Actually, it's NOT linear. c[k] = sum_i f[i]*f[k-i] is a quadratic form. So it's a quadratic feasibility problem, which is harder.
   
   But wait - if we use the LP approach from the previous solution: fix f and solve for g such that (f*g)[k] <= M for all k, g >= 0, maximize sum(g). This IS linear in g! And it's what the previous solution did.
   
   The Fenchel duality / alternating minimization approach:
   - Min over f >= 0, sum(f)=1 of max_k (f*f)[k]
   - = Min over f >= 0, sum(f)=1 of Max over p in simplex_k of sum_k p[k] * (f*f)[k]
   - The inner max over p is achieved at a vertex (p concentrated on argmax).
