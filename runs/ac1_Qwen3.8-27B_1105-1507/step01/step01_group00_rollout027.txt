**Alternative idea: use the structure of the problem more directly.**

The score is 2n * max_k conv(p,p)[k] where p is a probability vector of length n.

The minimum possible value of max_k conv(p,p)[k] is 1/(2n-1) (achieved if conv is perfectly flat).

For non-negative p, can we achieve conv close to flat?

conv(p,p)[k] = sum_i p[i]*p[k-i]

If p is uniform: conv[k] = min(k+1, 2n-1-k)/n², which peaks at n/(n²) = 1/n at k=n-1.

The "flat" target would be conv[k] ≈ 1/(2n-1) for all k. The ratio of peak to flat is (1/n)/(1/(2n-1)) = (2n-1)/n ≈ 2.

So the uniform distribution has a peak that's about 2x the flat value. We want to reduce this ratio to 1 (i.e., make conv flat).

What distributions make conv flat? In the continuous limit, if p(x) is a density on [0,1], then conv(p,p)(x) = ∫ p(t)p(x-t)dt. We want this to be constant for x in [0,2].

This is the "deconvolution" problem: find p such that p*p = constant. In the Fourier domain, this means |P(ω)|² = constant, so |P(ω)| = constant. This means p has a flat Fourier transform, which means p is a delta function (by the uncertainty principle, you can't have both p and P flat).

So it's impossible to have conv perfectly flat for a non-negative function. The best we can do is approximate it.

For discrete sequences, the problem is: find p in {0,...,n-1} with sum 1 such that the autocorrelation is as flat as possible.

This is related to the "平坦 autocorrelation" (flat autocorrelation) problem, which is well-studied in signal processing. For complex (can be negative) sequences, Barker sequences and related constructions give very flat autocorrelation. For non-negative sequences, the problem is harder.

LP-based iterative optimization with minpeak formulation, golden-section line search,
multiple initializations, and random perturbation for escaping local minima.
Minimizes 2n*max(conv(a,a))/sum(a)^2 by working with sum(a)=1 normalization.

import numpy as np
import time
from scipy.optimize import linprog
from scipy.sparse import csr_matrix, hstack


def build_conv_indices(n):
    """Precompute row and column indices for the convolution matrix of length-n sequences."""
    rows = []
    cols = []
    for k in range(2 * n - 1):
        j_min = max(0, k - (n - 1))
        j_max = min(k, n - 1)
        for j in range(j_min, j_max + 1):
            rows.append(k)
            cols.append(j)
    return np.array(rows, dtype=np.int32), np.array(cols, dtype=np.int32)


def make_conv_matrix(f, row_idx, col_idx):
    """Build sparse convolution matrix using precomputed indices."""
    f = np.asarray(f)
    vals = f[row_idx - col_idx]
    n = len(f)
    return csr_matrix((vals, (row_idx, col_idx)), shape=(2 * n - 1, n))


def solve_lp_minpeak(f, row_idx, col_idx):
    """Solve: min T s.t. (A_f * g)[k] <= T for all k, g >= 0, sum(g) = 1."""
    n = len(f)
    A = make_conv_matrix(f, row_idx, col_idx)
    c = np.zeros(n + 1)
    c[-1] = 1.0
    neg_ones = csr_matrix(-np.ones((2 * n - 1, 1)))
    A_ub = hstack([A, neg_ones], format='csr')
    b_ub = np.zeros(2 * n - 1)
    ones_row = csr_matrix(np.ones((1, n)))
    zero_col = csr_matrix(np.zeros((1, 1)))
    A_eq = hstack([ones_row, zero_col], format='csr')
    b_eq = np.array([1.0])
    bounds = [(0, None)] * (n + 1)
    try:
        result = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                         bounds=bounds, method='highs', options={'presolve': True})
        if result.success:
            g = result.x[:n]
            if g is not None and np.sum(g) > 1e-15:
                return g / np.sum(g)
    except Exception:
        pass
    return None


def golden_section_peak(c_f, c_fg, c_g, a=0.0, b=1.0):
    """Golden section search for min of max_k [(1-t)^2 c_f[k] + 2t(1-t)c_fg[k] + t^2 c_g[k]]."""
    def peak(t):
        return np.max((1 - t) ** 2 * c_f + 2 * t * (1 - t) * c_fg + t ** 2 * c_g)

    gr = (np.sqrt(5.0) - 1.0) / 2.0
    c = b - gr * (b - a)
    d = a + gr * (b - a)
    fc = peak(c)
    fd = peak(d)
    for _ in range(60):
        if fc < fd:
            b = d
            d = c
            fd = fc
            c = b - gr * (b - a)
            fc = peak(c)
        else:
            a = c
            c = d
            fc = fd
            d = a + gr * (b - a)
            fd = peak(d)
    return (a + b) / 2.0

def random_perturb_optimize(f_init, deadline, row_idx, col_idx, n_restarts=5, verbose=""):
    """Try multiple random perturbations of f_init, optimize each, return best."""
    f = f_init.copy().astype(np.float64)

    s = np.sum(f)

    best_f = f.copy()

    rng = np.random.default_rng(42)

    for r in range(n_restarts):
        if time.monotonic() > deadline - 10:

        # Perturb
        scale = 0.1 / (r + 1)
        perturbed = f + rng.uniform(-scale, scale, len(f))
        perturbed = np.clip(perturbed, 0.0, None)
        ps = np.sum(perturbed)
