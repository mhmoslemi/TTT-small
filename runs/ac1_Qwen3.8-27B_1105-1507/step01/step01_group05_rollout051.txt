   So `dc[k]/da[i] = a[k-i] + (a[i] if k-i != i else 0)` (when `0 <= k-i < n`)
   = `a[k-i] + a[i]` (when `k != 2i` and `0 <= k-i < n`)
   = `2*a[i]` (when `k = 2i`)
   = `0` (when `k-i < 0` or `k-i >= n`)

   So the linearized constraint at point `a` is:
   `c[k](a) + sum_i (dc[k]/da[i]) * (a_new[i] - a[i]) <= t`
   
   This is a linear constraint in `a_new`! So we can solve:
   minimize `t`
   subject to `c[k](a) + sum_i grad[k,i] * (a_new[i] - a[i]) <= t` for all k
   `sum(a_new) = 1`
   `a_new >= 0`
   
   This is a linear program! And it's a valid approximation for small steps.

   This is essentially a "linearized minimax" approach. It's different from the previous LP approach (which fixed `t = M` and maximized `sum(g)`).

3. **Another idea: Use the dual of the autocorrelation problem.**

The autocorrelation `c = convolve(a, a)` can be written as `c = C(a)` where `C` is a quadratic map. The constraint `max(c) <= t` defines a region in the space of `a`. We want to find `a` in this region with `sum(a) = 1` and `a >= 0`.

For a fixed `t`, this is feasible if and only if there exists `a >= 0` with `sum(a) = 1` and `C(a)[k] <= t` for all `k`. We can binary search on `t` to find the minimum feasible value.

But the feasibility check is a non-convex problem (quadratic constraints). However, we can relax it to a convex problem using SDP or other techniques.

Actually, for the feasibility check, we can use the following:
`C(a)[k] = sum_j a[j]*a[k-j] <= t`

This is a set of quadratic inequalities. The feasible region is non-convex in general. But we can over-approximate it:

One over-approximation: `C(a)[k] <= (sum_j a[j])^2 = 1` (trivial). Not useful.

Another: Use the fact that `C(a)[k] <= (sum_j a[j]^2) * something`. Not directly helpful.

def coordinate_descent(f, n_iter=5000, rng=None):
    """Polish with coordinate descent."""
    if rng is None:
        rng = np.random.default_rng(0)
    
    n = len(f)
    f = normalize(f)
    best_score = compute_score(f)
    
    for it in range(n_iter):
        # Pick a random coordinate
        i = int(rng.integers(0, n))
        old_val = f[i]
        
        # Try a few values
        best_x = old_val
        best_local_score = best_score
        
        for _ in range(10):
            # Random perturbation
            if _ == 0:
                x = old_val * (1 + rng.normal(0, 0.2))
            else:
                x = best_x * (1 + rng.normal(0, 0.1))
            x = max(0, x)
            
            f[i] = x
            f_new = normalize(f)
            s = compute_score(f_new)
            if s < best_local_score:
                best_local_score = s
                best_x = x
        
        f[i] = best_x
        f = normalize(f)
        best_score = compute_score(f)
    
    return f, best_score


def random_local_search(f, n_iter=5000, rng=None):
    """Random block perturbation local search."""
    if rng is None:
        rng = np.random.default_rng(0)
    
    n = len(f)
    f = normalize(f)
    best = f.copy()
    best_score = compute_score(f)
    
    for _ in range(n_iter):
        f_cand = f.copy()
        width = max(1, int(rng.integers(1, max(2, n // 32))))
        start = int(rng.integers(0, n - width))
        scale = np.exp(rng.normal(0, 0.3))
        f_cand[start:start+width] *= scale
        f_cand = normalize(f_cand)
