If a is symmetric (a[j] = a[n-1-j]), then b = a, and C_{n-1} = sum a[j]^2 >= 1/n.
If a is "anti-symmetric" in the sense that a[j] is large when a[n-1-j] is small, then C_{n-1} can be small.

Example: n=4, a = (1, 0, 0, 0) (not normalized, S=1).
C_{n-1} = C_3 = a[0]*a[3] + a[1]*a[2] + a[2]*a[1] + a[3]*a[0] = 0 + 0 + 0 + 0 = 0.
But C_0 = a[0]^2 = 1. So max C = 1, obj = 2*4*1/1 = 8. Bad.

Example: n=4, a = (0.5, 0.5, 0, 0). S=1.
C_0 = 0.25, C_1 = 0.25+0.25 = 0.5, C_2 = 0.25, C_3 = 0, ...
max C = 0.5, obj = 2*4*0.5/1 = 4. Still bad.

Example: n=4, a = (0.5, 0, 0.5, 0). S=1.
C_0 = 0.25, C_1 = 0, C_2 = 0.25, C_3 = 0, C_4 = 0.25, C_5 = 0, C_6 = 0.25.
max C = 0.25, obj = 2*4*0.25/1 = 2. Same as uniform!

Interesting. So for n=4, the best we can do might be 2? Or can we do better?

n=4, a = (0.4, 0.1, 0.1, 0.4). S=1.
C_0 = 0.16, C_1 = 0.04+0.04 = 0.08, C_2 = 0.16+0.01+0.16 = 0.33, C_3 = 0.04+0.04 = 0.08, ...
max C = 0.33, obj = 2*4*0.33/1 = 2.64. Worse.

n=4, a = (0.3, 0.4, 0.4, 0.3). S=1.
C_0 = 0.09, C_1 = 0.12+0.12 = 0.24, C_2 = 0.09+0.16+0.09 = 0.34, C_3 = 0.12+0.12 = 0.24, ...
max C = 0.34, obj = 2.72. Worse.

So for n=4, the best seems to be around 2 (uniform or the (0.5,0,0.5,0) pattern).

For larger n, we should be able to do better. The LP approach with n=150 got 1.516, which is significantly better than 2.

Let me now focus on practical improvements. I think the key improvements are:

1. **Use FFT for faster convolution computation** in the gradient-based method
2. **Combine gradient descent with LP** in a smart way
3. **Try larger n values** (up to 500-1000) since the theoretical bound approaches 1
4. **Use the log-sum-exp relaxation with adaptive temperature**

"""
Combined gradient-descent (log-sum-exp relaxation) and LP-based optimization
for minimizing 2*n*max(conv(a,a))/(sum(a))^2 over non-negative sequences.
Uses FFT for fast convolution, adaptive temperature, and multiple restarts.
"""

import numpy as np
from scipy.optimize import linprog
from scipy.fft import fft, ifft, next_fast_len
import time

def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    conv = np.convolve(a, a)
    max_b = float(np.max(conv))
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)

def fast_conv(a, b=None):
    """Fast convolution using FFT."""
    if b is None:
        b = a
    n = len(a) + len(b) - 1
    size = next_fast_len(n)
    fa = fft(a, size)
    fb = fft(b, size)
    return np.real(ifft(fa * fb))[:n]

def smooth_obj_grad(a, tau):
    """Compute smooth objective and gradient using log-sum-exp."""
    n = len(a)
    C = fast_conv(a, a)  # length 2n-1
    S = np.sum(a)
    
    # Log-sum-exp for numerical stability
    C_max = np.max(C)
    exp_C = np.exp(tau * (C - C_max))
    log_sum = np.log(np.sum(exp_C)) + tau * C_max
    LSE = (1.0 / tau) * log_sum
    
    # Weights
    w = exp_C / np.sum(exp_C)
    
    # Gradient of LSE w.r.t. a[i] = (2/tau) * sum_k w_k * a[k-i] * I[0<=k-i<n]
    # This is (2/tau) * conv(w, a) but only the "valid" part
    # Actually, the gradient is (2/tau) * sum_k w[k] * a[k-i] for valid k-i
    # This is a cross-correlation-like operation
    
    # grad[i] = (2/tau) * sum_k w[k] * a[k-i] * I[0 <= k-i < n]
    # Let m = k-i, so k = i+m, m in [0, n-1]
    # grad[i] = (2/tau) * sum_{m=0}^{n-1} w[i+m] * a[m] * I[i+m <= 2n-2]
    
    # This is (2/tau) * (w * a) where * is convolution, but truncated
    # Actually it's more like a cross-correlation
    
    # Let me compute it directly:
    # grad[i] = (2/tau) * sum_{m=0}^{min(n-1, 2n-2-i)} w[i+m] * a[m]
    
    # This is the cross-correlation of w and a, specifically:
    # grad = (2/tau) * np.convolve(w, a[:n]) ... no
    
    # Let me just compute it: for each i, grad[i] = (2/tau) * sum_{m=0}^{n-1} w[i+m] * a[m] if i+m < 2n-1
    # This is the "sliding dot product" of w and a
    
    # Using FFT: this is the same as the convolution of reversed w with reversed a, etc.
    # Let me just use the direct formula: it's (2/tau) * np.convolve(a, w[:2n-1]) evaluated at specific indices
    
    # Actually, let's think of it differently.
    # C[k] = sum_{j} a[j] * a[k-j]
    # dC[k]/da[i] = 2*a[k-i] if 0<=k-i<n (and k-i is valid)
    # 
    # grad_LSE[i] = (1/tau) * sum_k w[k] * dC[k]/da[i] = (2/tau) * sum_k w[k] * a[k-i] * I[0<=k-i<n]
    #
    # Let m = k-i: grad_LSE[i] = (2/tau) * sum_{m: 0<=m<n, 0<=i+m<2n-1} w[i+m] * a[m]
    # = (2/tau) * sum_{m=0}^{min(n-1, 2n-2-i)} w[i+m] * a[m]
    
    # This is the cross-correlation of (w) and (a), which can be computed as:
    # corr[i] = sum_m a[m] * w[i+m]
    # = (a * rev(w))[...] ... hmm
    
    # Let me use the fact that this is convolve(rev(a), w) or something.
    # Actually, the simplest way: use np.correlate or just compute it directly for small n.
    
    # For efficiency, note that this is a convolution:
    # grad[i] = sum_m a[m] * w[i+m] = (a * w_flipped)[n-1+i] ... not quite
    
    # Let me just use FFT-based approach:
    # Define g[i] = sum_{m=0}^{n-1} a[m] * w[i+m] for i = 0, ..., 2n-2
    # This is the cross-correlation cross_corr(w, a)[i] = sum_m a[m] * conj(w[m-i+...])
    # 
    # Actually, the cross-correlation (w ⋆ a)[i] = sum_m w[m+i] * a[m] = g[i]
    # In FFT terms: cross_corr = ifft(conj(fft(w, N)) * fft(a, N)) ... not exactly
    
    # The cross-correlation r[i] = sum_m x[m] * conj(y[m-i]) 
    # In our case we want g[i] = sum_m a[m] * w[m+i]
    # This is the "anti-correlation" or we can compute it as:
    # g = ifft(fft(a, N) * conj(fft(w, N))) ... let me verify
    
    # Actually, let me just compute it directly for the sizes we're working with.
    # For n up to 500, direct computation is O(n^2) = 250000, which is fast enough.
    
    # Direct computation:
    grad_LSE = np.zeros(n)
    # For each i, grad_LSE[i] = (2/tau) * sum_{m=0}^{min(n-1, 2n-2-i)} w[i+m] * a[m]
    # We can compute this as a "sliding sum"
    
    # Vectorized: create a matrix where row i has w[i:i+n] dot a
    # But that's O(n^2) memory. For n=500, that's 250000 floats = 2MB. Fine.
    
    # Actually, let me use a different approach. 
    # g[i] = sum_{m=0}^{n-1} a[m] * w[m+i]
    # This is the convolution of a and w evaluated at specific points.
    # Specifically, if we pad a to length 2n-1 (as is) and compute conv(rev(a), w)... 
    
    # Let's use: g = np.correlate(w, a, mode='full') 
    # np.correlate(w, a)[k] = sum_m w[m+k] * a[m] (for valid m)
    # Wait, np.correlate(a, v)[k] = sum_n a[n+k] * conj(v[n])
    # So np.correlate(w, a, 'full')[k] = sum_n w[n+k] * a[n] (for valid n)
    # That's exactly what we want! g[i] = np.correlate(w, a, 'full')[i]
    
    # Let me verify: np.correlate(w, a, mode='full') has length len(w)+len(a)-1
    # w has length 2n-1, a has length n
    # Result has length 2n-1+n-1 = 3n-2
    # The element at index i is sum_{valid m} w[m+i] * a[m]
    # For i = 0: sum_m w[m] * a[m] for m where m < 2n-1 and m < n, i.e., m = 0..n-1
    # For i = n-1: sum_m w[m+n-1] * a[m] for m where m+n-1 < 2n-1, i.e., m < n, and m < n, so m = 0..n-1
    # For i = 2n-2: sum_m w[m+2n-2] * a[m] for m where m+2n-2 < 2n-1, i.e., m < 1, so m = 0 only
    
    # So g[i] = correlate(w, a, 'full')[i] for i = 0, 1, ..., 2n-2
    # But we only need i = 0, ..., n-1 for our gradient.
    
    # Wait, I indexed wrong. Let me recheck.
    # We want grad_LSE[i] = (2/tau) * sum_{m=0}^{n-1} a[m] * w[i+m] for i = 0, ..., n-1
    # (with the understanding that w[i+m] is 0 if i+m >= 2n-1)
    
    # np.correlate(w, a, 'full')[i] = sum_m w[m+i] * conj(a[m]) = sum_m w[m+i] * a[m] (real)
    # For this to equal our sum, we need the sum to be over m where both m < n and m+i < len(w) = 2n-1.
    # np.correlate handles this automatically (only sums over valid indices).
    
    # So grad_LSE[i] = (2/tau) * np.correlate(w, a, 'full')[i] for i = 0, ..., n-1
    
    corr = np.correlate(w, a, mode='full')
    grad_LSE = (2.0 / tau) * corr[:n]
    
    obj = 2.0 * n * LSE / (S * S)
    grad = (2.0 * n / (S * S)) * grad_LSE - (4.0 * n * LSE / (S * S * S))
    
    return obj, grad

def build_A_matrix(a):
    """Build constraint matrix A for the LP. A[k,j] such that (A @ g)[k] = (a*g)_k."""
    n = len(a)
    N = 2 * n - 1
    A = np.zeros((N, n), dtype=np.float64)
    for k in range(N):
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        # A[k, j] = a[k-j] for j in [j_start, j_end]
        js = np.arange(j_start, j_end + 1)
        A[k, js] = a[k - js]
    return A

def solve_lp(a, M):
    """Solve LP: max sum(g) s.t. (a*g)[k] <= M for all k, 0 <= g_j <= 1000."""
    n = len(a)
    N = 2 * n - 1
    A = build_A_matrix(a)
    c = -np.ones(n)
    b_ub = np.full(N, M)
    bounds = [(0.0, 1000.0)] * n
    res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
    if res.status == 0:
        return res.x, float(-res.fun)
    return None, None

def gradient_descent(a, tau_start=10.0, tau_end=500.0, n_steps=2000, 
                     decay_rate=None, verbose=False, seed=0):
    """Run smooth gradient descent on the log-sum-exp relaxation."""
    n = len(a)
    rng = np.random.default_rng(seed)
    a = a.copy()
    S = np.sum(a)
    a = a / S  # normalize
    
    if decay_rate is None:
        decay_rate = (tau_end / tau_start) ** (1.0 / n_steps)
    
    best_a = a.copy()
    best_obj = compute_obj(best_a)
    
    for step in range(n_steps):
        tau = tau_start * (decay_rate ** step)
        _, grad = smooth_obj_grad(a, tau)
        
        # Adaptive step size
        # Scale gradient so the update has reasonable magnitude
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-15:
            break
        eta = 0.1 / grad_norm
        
        a_new = a - eta * grad
        a_new = np.clip(a_new, 0, None)
        S_new = np.sum(a_new)
        if S_new < 1e-10:
            a_new = a
            S_new = S
        a_new = a_new / S_new
        
        obj_new = compute_obj(a_new)
        if obj_new < best_obj:
            best_obj = obj_new
            best_a = a_new.copy()
            if verbose and step % 200 == 0:
                print(f"    GD step {step}: tau={tau:.1f}, obj={best_obj:.6f}")
        
        a = a_new
    
    return best_a, best_obj

def lp_refine(a, max_iter=100, verbose=False, seed=0):
    """LP-based refinement starting from initial point a."""
    n = len(a)
    rng = np.random.default_rng(seed)
    a = a.copy()
    S = np.sum(a)
    a = a / S
    best_a = a.copy()
    best_obj = compute_obj(best_a)
    
    if verbose:
        print(f"    LP start: obj={best_obj:.6f}")
    
    stall = 0
    for it in range(max_iter):
        conv = np.convolve(a, a)
        M = float(np.max(conv))
        
        g, g_sum = solve_lp(a, M)
        if g is None:
            break
        
        if g_sum <= 1.0 + 1e-6:
            stall += 1
            if stall > 10:
                # Perturb
                noise = np.exp(rng.normal(0, 0.2, n))
                a = best_a * noise
                a = np.clip(a, 0, None)
                s = np.sum(a)
                if s < 1e-10:
                    a = rng.random(n)
                    s = np.sum(a)
                a = a / s
                stall = 0
            continue
        stall = 0
        
        g = g / g_sum
        # Try multiple blending factors
        for t in [0.5, 0.3, 0.7]:
            a_new = (1 - t) * a + t * g
            a_new = np.clip(a_new, 0, None)
            s = np.sum(a_new)
            if s < 1e-10:
                continue
            a_new = a_new / s
            obj_new = compute_obj(a_new)
            if obj_new < best_obj:
                best_obj = obj_new
                best_a = a_new.copy()
                a = a_new
                if verbose and it % 20 == 0:
                    print(f"    LP it={it}: obj={best_obj:.6f}, t={t}")
                break
        else:
            # No improvement, try smaller step
            a_new = (1 - 0.1) * a + 0.1 * g
            a_new = np.clip(a_new, 0, None)
            s = np.sum(a_new)
            if s > 1e-10:
                a_new = a_new / s
                a = a_new
    
    return best_a, best_obj

def local_search(a, rng, n_iter=3000, verbose=False):
    """Local search with structured perturbations."""
    best_a = a.copy()
    best_obj = compute_obj(best_a)
    n = len(best_a)
    
    for it in range(n_iter):
        # Choose perturbation type
        choice = rng.integers(0, 4)
        candidate = best_a.copy()
        
        if choice == 0:
            # Block scaling
            width = max(1, min(n // 10, n // 5))
            w = int(rng.integers(1, width + 1))
            start = int(rng.integers(0, n - w + 1))
            candidate[start:start+w] *= np.exp(rng.normal(0, 0.2, w))
        elif choice == 1:
            # Gaussian bump
            center = rng.uniform(0, n)
            sigma = rng.uniform(n/20, n/5)
            amplitude = rng.normal(0, 0.3)
            x = np.arange(n)
            candidate *= np.exp(amplitude * np.exp(-0.5 * ((x - center) / sigma) ** 2))
        elif choice == 2:
            # Single element
            i = int(rng.integers(0, n))
            candidate[i] *= np.exp(rng.normal(0, 0.3))
        else:
            # Mirror perturbation
            i = int(rng.integers(0, n // 2))
            factor = np.exp(rng.normal(0, 0.3))
            candidate[i] *= factor
            candidate[n-1-i] /= factor
        
        candidate = np.clip(candidate, 0, None)
        s = np.sum(candidate)
        if s < 1e-10:
            continue
        obj_new = compute_obj(candidate)
        if obj_new < best_obj:
            best_obj = obj_new
            best_a = candidate
            if verbose and it % 500 == 0:
                print(f"    LS it={it}: obj={best_obj:.6f}")
    
    return best_a, best_obj

def structured_init(n, rng):
    """Generate structured initializations."""
    choice = rng.integers(0, 6)
    if choice == 0:
        a = rng.random(n)
    elif choice == 1:
        # Cosine
        freq = rng.uniform(0.5, 3.0)
        phase = rng.uniform(0, 2 * np.pi)
        a = np.maximum(0.01, np.cos(2 * np.pi * freq * np.arange(n) / n + phase))
    elif choice == 2:
        # Two humps
        c1, c2 = sorted(rng.uniform(0, n, 2))
        s1, s2 = rng.uniform(n/20, n/5, 2)
        x = np.arange(n)
        a = np.exp(-0.5*((x-c1)/s1)**2) + np.exp(-0.5*((x-c2)/s2)**2)
    elif choice == 3:
        # Linear ramp
        a = np.linspace(rng.uniform(0.1, 1), rng.uniform(0.1, 1), n)
        a = np.abs(a)
    elif choice == 4:
        # Periodic
        period = int(rng.integers(max(2, n//30), max(3, n//5)))
        pattern = rng.random(period) + 0.1
        a = np.tile(pattern, n // period + 1)[:n]
    else:
        # Symmetric random
        half = n // 2
        a_half = rng.random(half) + 0.1
        a = np.concatenate([a_half, a_half[::-1]])
        if n % 2 == 1:
            a = a[:n]
    
    s = np.sum(a)
    if s < 1e-10:
        a = rng.random(n)
        s = np.sum(a)
    return a / s

```python
"""
Combined gradient-descent (log-sum-exp relaxation) and LP-based optimization
for minimizing 2*n*max(conv(a,a))/(sum(a))^2 over non-negative sequences.
Uses FFT for fast convolution, adaptive temperature annealing, multi-scale n,
and structured initializations with local search refinement.
"""

import numpy as np
from scipy.optimize import linprog
from scipy.fft import fft, ifft, next_fast_len
import time


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    conv = np.convolve(a, a)
    max_b = float(np.max(conv))
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)


def fast_conv(a):
    """Fast autocorrelation (full convolution) using FFT."""
    n = len(a)
    size = next_fast_len(2 * n - 1)
    fa = fft(a, size)
    result = np.real(ifft(fa * fa))
    return result[:2 * n - 1]


def smooth_obj_and_grad(a, tau):
    """Compute smooth objective (log-sum-exp) and its gradient."""
    n = len(a)
    C = fast_conv(a)
    S = float(np.sum(a))

    # Numerically stable log-sum-exp
    C_max = float(np.max(C))
    exp_C = np.exp(tau * (C - C_max))
    sum_exp = float(np.sum(exp_exp)) if False else float(np.sum(exp_C))
    log_sum = np.log(sum_exp) + tau * C_max
    LSE = (1.0 / tau) * log_sum

    # Softmax weights
    w = exp_C / sum_exp

    # Gradient of LSE: (2/tau) * corr(w, a)[i] for i=0..n-1
    corr = np.correlate(w, a, mode='full')
    grad_LSE = (2.0 / tau) * corr[:n]

    obj = 2.0 * n * LSE / (S * S)
    # Full gradient (drop the constant term since we renormalize)
    grad = (2.0 * n / (S * S)) * grad_LSE

    return obj, grad


def gradient_descent(a_init, tau_start=5.0, tau_end=500.0, n_steps=2000,
                     verbose=False, seed=0, step_scale=0.1):
    """Annealed smooth gradient descent with log-sum-exp relaxation."""
    n = len(a_init)
    a = a_init.copy()
    S = float(np.sum(a))
    a = a / S

    best_a = a.copy()
    best_obj = compute_obj(best_a)

    if n_steps <= 1:
        return best_a, best_obj

    for step in range(n_steps):
        frac = step / max(1, n_steps - 1)
        tau = tau_start * (tau_end / tau_start) ** frac

        _, grad = smooth_obj_and_grad(a, tau)

        grad_norm = float(np.max(np.abs(grad)))
        if grad_norm < 1e-15:
            break

        eta = step_scale / grad_norm
        a_new = a - eta * grad
        a_new = np.clip(a_new, 0.0, None)
        S_new = float(np.sum(a_new))
        if S_new < 1e-10:
            continue
        a_new = a_new / S_new

        obj_new = compute_obj(a_new)
        if obj_new < best_obj:
            best_obj = obj_new
            best_a = a_new.copy()
            if verbose and (step % 500 == 0 or step < 5):
                print(f"      GD step={step}, tau={tau:.1f}, obj={best_obj:.6f}")

        a = a_new

    return best_a, best_obj


def build_A_matrix(a):
    """Build constraint matrix for LP: (A @ g)[k] = (a*g)[k]."""
    n = len(a)
    N = 2 * n - 1
    A = np.zeros((N, n), dtype=np.float64)
    for k in range(N):
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        js = np.arange(j_start, j_end + 1)
        A[k, js] = a[k - js]
    return A


def solve_lp(a, M):
    """Solve LP: max sum(g) s.t. (a*g)[k] <= M, 0 <= g_j <= 1000."""
    n = len(a)
    N = 2 * n - 1
    A = build_A_matrix(a)
    c = -np.ones(n)
    b_ub = np.full(N, M)
    bounds = [(0.0, 1000.0)] * n
    res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
    if res.status == 0:
        return res.x, float(-res.fun)
    return None, None


def lp_refine(a_init, max_iter=60, t_values=(0.5, 0.3, 0.7, 0.1),
              verbose=False, seed=0):
    """Alternating LP refinement with multiple step sizes."""
    n = len(a_init)
    rng = np.random.default_rng(seed)
    a = a_init.copy()
    S = float(np.sum(a))
    a = a / S
    best_a = a.copy()
    best_obj = compute_obj(best_a)

    if verbose:
        print(f"      LP start: obj={best_obj:.6f}")

    stall = 0
    for it in range(max_iter):
        conv = np.convolve(a, a)
        M = float(np.max(conv))

        g, g_sum = solve_lp(a, M)
        if g is None:
            break

        if g_sum <= 1.0 + 1e-6:
            stall += 1
            if stall > 12:
                # Perturb to escape local optimum
                noise = np.exp(rng.normal(0, 0.25, n))
                a = best_a * noise
                a = np.clip(a, 0, None)
                s = float(np.sum(a))
                if s < 1e-10:
                    a = rng.random(n) + 0.01
                    s = float(np.sum(a))
                a = a / s
                stall = 0
            continue
        stall = 0

        g = g / g_sum
        improved = False
        for t in t_values:
            a_new = (1.0 - t) * a + t * g
            a_new = np.clip(a_new, 0, None)
            s = float(np.sum(a_new))
            if s < 1e-10:
                continue
            a_new = a_new / s
            obj_new = compute_obj(a_new)
            if obj_new < best_obj - 1e-10:
                best_obj = obj_new
                best_a = a_new.copy()
                a = a_new
                improved = True
                if verbose and (it % 10 == 0):
                    print(f"      LP it={it}: obj={best_obj:.6f}, t={t}")
                break

        if not improved:
            # Try smallest step as default
            a_new = (1.0 - 0.1) * a + 0.1 * g
            a_new = np.clip(a_new, 0, None)
            s = float(np.sum(a_new))
            if s > 1e-10:
                a = a_new / s

    return best_a, best_obj


def local_search(a_init, rng, n_iter=3000, verbose=False):
    """Local search with diverse perturbation strategies."""
    best_a = a_init.copy()
    best_obj = compute_obj(best_a)
    n = len(best_a)

    for it in range(n_iter):
        choice = int(rng.integers(0, 5))
        candidate = best_a.copy()

        if choice == 0:
            # Block scaling
            max_w = max(1, n // 15)
            w = int(rng.integers(1, max_w + 1))
            start = int(rng.integers(0, n - w + 1))
            candidate[start:start + w] *= np.exp(rng.normal(0, 0.2, w))
        elif choice == 1:
            # Gaussian perturbation
            center = float(rng.uniform(0, n))
            sigma = float(rng.uniform(n / 20, n / 4))
            amplitude = float(rng.normal(0, 0.3))
            x = np.arange(n, dtype=np.float64)
            candidate *= np.exp(amplitude * np.exp(-0.5 * ((x - center) / sigma) ** 2))
        elif choice == 2:
            # Single element
            i = int(rng.integers(0, n))
            candidate[i] *= np.exp(float(rng.normal(0, 0.4)))
        elif choice == 3:
            # Mirror perturbation
            i = int(rng.integers(0, n // 2))
            factor = float(np.exp(rng.normal(0, 0.3)))
            candidate[i] *= factor
