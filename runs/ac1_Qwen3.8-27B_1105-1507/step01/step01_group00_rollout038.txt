def soft_max_gradient(a, beta=100):
    """Compute gradient of log-sum-exp(beta * conv(a,a)) w.r.t. a"""
    n = len(a)
    conv = np.convolve(a, a)
    # Softmax weights
    max_conv = np.max(conv)
    weights = np.exp(beta * (conv - max_conv))
    weights /= np.sum(weights)
    
    # Gradient
    grad = np.zeros(n)
    for k in range(2*n-1):
        if weights[k] < 1e-15:

        j_max = min(k, n-1)
        for j in range(j_min, j_max+1):
            grad[j] += 2.0 * weights[k] * a[k-j]
    return grad * beta

Let me try yet another approach: **iterative reweighted least squares (IRLS)** style.

The idea: we want to minimize `max_k Q(a)_k` where `Q(a)_k = sum_i a_i a_{k-i}`. This is equivalent to: find `a >= 0, sum(a)=S` that minimizes `t` subject to `Q(a)_k <= t` for all k.

This is a QUADRATIC program (QP) since Q(a)_k is quadratic in a. We could solve it directly with a QP solver!

The QP would be:
- Minimize t
- Subject to: `sum_i a_i * a_{k-i} <= t` for k=0,...,2n-2
- `sum_i a_i = S` (fix the sum)
- `a_i >= 0`

The constraints `sum_i a_i * a_{k-i} <= t` are quadratic (specifically, they're `a^T Q_k a <= t` where `Q_k` is a specific matrix). These are convex if `Q_k` is positive semidefinite.

Is `Q_k` PSD? `Q(a)_k = a^T Q_k a = sum_i a_i a_{k-i}`. This is NOT a standard quadratic form because it involves `a_i * a_j` where `j = k-i`, which is not the same as `a_i * a_i`. We can write it as:

`Q(a)_k = sum_i a_i * a_{k-i} = (1/2) sum_i sum_j a_i a_j (delta_{i+j,k} + delta_{i+j,k})`... no that's not right either.

Actually: `sum_i a_i a_{k-i}` where both indices must be in [0, n-1].

Let me write it as a quadratic form. Define a symmetric matrix `B_k` such that `a^T B_k a = sum_i a_i a_{k-i}`.

We have: `a^T B a = sum_i sum_j B_{ij} a_i a_j`.

We want `sum_i B_{ij} a_i a_j = a_i a_{k-i}` summed over valid i.

So: `B_{i,k-i} = 1/2` and `B_{k-i,i} = 1/2` for all valid i (to make it symmetric), and `B_{mm} = 2*B_{m,m} ... ` 

Wait, if `i = k-i`, i.e., `i = k/2`, then `a_i * a_{k-i} = a_i^2`. In the quadratic form, this appears as `B_{i,i} * a_i^2`. We need `B_{i,i} = 1` for this to work (since `a^T B a` has `B_{ii} a_i^2` for diagonal terms).

But for `i != k-i`: `a_i a_{k-i}` appears as both `B_{i,k-i} a_i a_{k-i}` and `B_{k-i,i} a_{k-i} a_i` in the sum `sum_i sum_j B_{ij} a_i a_j`. Since `a_i a_j = a_j a_i`, we get `2 B_{i,k-i} a_i a_{k-i}` (assuming `B` is symmetric). So we need `B_{i,k-i} = 1/2`.

So: `B_k` has `B_{i,k-i} = B_{k-i,i} = 1/2` for `i != k-i`, and `B_{i,i} = 1` when `i = k/2` (i.e., k is even and i=k/2).

Is `B_k` positive semidefinite? Let's check for small cases.

For k=0: `B_0[0,0] = 1` (since i=0, k-i=0, so it's a diagonal element with a_0^2). So `a^T B_0 a = a_0^2 >= 0`. PSD. ✓

For k=1: `B_1[0,1] = B_1[1,0] = 1/2`. `a^T B_1 a = a_0 a_1`. This is NOT PSD (can be negative if a_0 and a_1 have opposite signs, but we require a >= 0, so it's non-negative). But as a matrix, it's not PSD in general (its eigenvalues are 1/2 and -1/2).

So the QP is NOT a convex QP in general. This means we can't directly use a standard QP solver.

However, if we restrict to `a >= 0`, then `a^T B_k a = sum_i a_i a_{k-i} >= 0` always (since both factors are non-negative). The constraint set `{a >= 0: a^T B_k a <= t for all k}` is not necessarily convex, but it's the intersection of upper level sets of non-negative quadratic forms with the non-negative orthant.

This means we can't easily solve it as a convex QP. We need to use other methods.

Let me also add one more idea: **frequency domain shaping**. 

If we compute the DFT of `a` (zero-padded to length 2n), then the linear autocorrelation is related to the IDFT of |DFT(a)|^2 (with some zero-padding considerations). Specifically:

If we zero-pad `a` to length >= 2n-1 (say, length L = next power of 2 >= 2n-1), compute `A = FFT(a_padded, L)`, then:
- `IDFT(|A|^2)` gives the circular autocorrelation of the zero-padded sequence, which equals the linear autocorrelation (since the zero-padding prevents wrap-around).

So: `conv(a,a) = IDFT(|FFT(a_padded)|^2)[:2n-1]`

This means: to make `conv(a,a)` flat, we want `|FFT(a_padded)|^2` to be flat, i.e., `|FFT(a_padded)|` to be constant.

This is the "flat spectrum" or "white noise" property. A sequence with a flat power spectrum has uncorrelated values (like white noise), but we also need it to be non-negative, which makes it harder.

**Spectral shaping algorithm**:
1. Compute `A = FFT(a_padded)`
2. Compute the current power spectrum `|A|^2`
3. Define a target spectrum (e.g., flat, or slightly shaped)
4. Update the magnitude: `|A_new| = |A|^alpha * |A_target|^(1-alpha)` for some alpha in (0,1)
5. Keep the phase: `A_new = |A_new| * exp(i*angle(A))`
6. `a_new = IDFT(A_new)[:n]`
7. Project onto non-negative reals

This is similar to the Gerchberg-Saxton algorithm used in optics. Let me include this as an alternative optimizer.

Actually, I realize that for this problem, the "target spectrum" should be flat (all |A_k| equal). So step 4 becomes: `|A_new| = |A|^alpha * C^(1-alpha)` where C is the target amplitude (e.g., the geometric mean of |A|).

Let me code this up:

```python
def spectral_shaping_step(a, alpha=0.5):
    n = len(a)
    L = 1
    while L < 2*n - 1:
        L *= 2
    a_padded = np.zeros(L)
    a_padded[:n] = a
    A = np.fft.fft(a_padded)
    mag = np.abs(A)
    phase = np.angle(A)
    # Target: flat magnitude
    target_mag = np.full(L, np.mean(mag))
    # Geometric mean update
    mag_new = mag ** alpha * target_mag ** (1 - alpha)
    A_new = mag_new * np.exp(1j * phase)
    a_new = np.fft.ifft(A_new).real[:n]
    return a_new
```

This is O(n log n) per step, much faster than the O(n^2) subgradient! Let me combine both.

Multi-method optimization for step function with flat autocorrelation.
Combines soft-max subgradient descent, LP direction finding, and spectral shaping.

import numpy as np

from scipy.optimize import linprog
from scipy.sparse import csr_matrix


def build_conv_matrix_sparse(f):
    n = len(f)
    rows_list = []
    cols_list = []
    vals_list = []
    for k in range(2 * n - 1):
        j_min = max(0, k - (n - 1))
        j_max = min(k, n - 1)
        for j in range(j_min, j_max + 1):
            rows_list.append(k)
            cols_list.append(j)
            vals_list.append(f[k - j])
    return csr_matrix((vals_list, (rows_list, cols_list)), shape=(2 * n - 1, n))


def solve_lp_direction(f, M, time_limit=5.0):
    n = len(f)
    A = build_conv_matrix_sparse(f)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    try:
        result = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
        if result.success:
            return result.x
    except Exception:
        pass
    return None


def soft_max_subgrad(a, beta):
    n = len(a)
    conv = np.convolve(a, a)
    max_c = np.max(conv)
    shifted = beta * (conv - max_c)
    w = np.exp(shifted)
    w_sum = w.sum()
    if w_sum < 1e-300:
        w = np.zeros_like(conv)
        w[np.argmax(conv)] = 1.0
    else:
        w /= w_sum
    
    grad = np.zeros(n)
    for k in range(2 * n - 1):
        wk = w[k]
        if wk < 1e-18:
            continue
        j_min = max(0, k - n + 1)
        j_max = min(k, n - 1)
        start = k - j_max
        end = k - j_min + 1
        grad[j_min:j_max+1] += 2.0 * wk * a[start:end][::-1]
    
    return beta * grad


def project_nonneg_simplex(v, target_sum=1.0):
    """Project v onto {x >= 0, sum(x) = target_sum} using water-filling."""
    n = len(v)
    if target_sum <= 0:
        return np.zeros(n)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho_candidates = np.nonzero(u * np.arange(1, n + 1) > (cssv - target_sum))[0]
    if len(rho_candidates) == 0:
        return np.full(n, target_sum / n)
    rho = rho_candidates[-1]
    theta = (cssv[rho] - target_sum) / (rho + 1.0)
    return np.maximum(v - theta, 0)

    return a_new

def build_conv_matrix_sparse(f):
    """Build sparse matrix A where (A@g)[k] = convolve(f,g)[k]."""
    n = len(f)
    rows_list = []
    cols_list = []
    vals_list = []
    for k in range(2 * n - 1):
        j_min = max(0, k - (n - 1))
        j_max = min(k, n - 1)
        for j in range(j_min, j_max + 1):
            rows_list.append(k)
            cols_list.append(j)
            vals_list.append(f[k - j])
    return csr_matrix((vals_list, (rows_list, cols_list)), shape=(2 * n - 1, n))


def solve_lp_direction(f, M):
    """Solve LP: max sum(g) s.t. g >= 0, convolve(f,g)_k <= M."""
    n = len(f)
    if n > 4096:
        return None
    A = build_conv_matrix_sparse(f)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    try:
        result = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
        if result.success:
            return result.x
    except Exception:
        pass
    return None

def project_nonneg_simplex(v, target_sum=1.0):
    """Project v onto {x >= 0, sum(x) = target_sum}."""
    n = len(v)
    if target_sum <= 0:
        return np.zeros(n)
    v = v.copy()
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho_candidates = np.nonzero(u * np.arange(1, n + 1) > (cssv - target_sum))[0]
    if len(rho_candidates) == 0:
        return np.full(n, target_sum / n)
    rho = rho_candidates[-1]
    theta = (cssv[rho] - target_sum) / (rho + 1.0)
    result = np.maximum(v - theta, 0.0)
    # Fix numerical issues
    result = np.maximum(result, 0.0)
    s = result.sum()
    if s > 0 and abs(s - target_sum) > 1e-10:
        result *= target_sum / s
    return result

                            best_a = a.copy()
                            best_score = score
                            no_improve = 0
                            break
                    else:
                        no_improve += 1
                else:
                    no_improve += 1
            else:
                no_improve += 1
            continue

        # --- Coordinate descent every 60 iterations ---
        if it > 20 and it % 60 == 0:
            a_new = coordinate_descent_step(a)
            s_new = a_new.sum()
            if s_new > 1e-15:
                a_new = a_new / s_new
            score = evaluate_sequence(a_new.tolist())
            if np.isfinite(score) and score < best_score:
                a = a_new
                best_a = a.copy()
                best_score = score
                no_improve = 0
            else:
                no_improve += 1
            continue

        # --- Default: soft-max subgradient with momentum ---
        grad = soft_max_subgrad(a, temperature)
        v = momentum * v - lr * grad
        a_new = a + v
        a_new = project_nonneg_simplex(a_new, 1.0)

        score = evaluate_sequence(a_new.tolist())
        if np.isfinite(score) and score < best_score:
            a = a_new
            best_a = a.copy()
            best_score = score
            no_improve = 0
            if (it + 1) % 1000 == 0:
                print(f"  {verbose_prefix}it={it}: score={best_score:.6f} lr={lr:.5f} temp={temperature:.4f}")
        else:
            no_improve += 1
            if no_improve % 30 == 0:
                lr *= 0.85
                temperature *= 0.9  # Cool down (sharper focus)

        # Adaptive: slowly decay lr and cool temperature
        lr = max(lr * 0.9997, 1e-8)
        temperature = max(temperature * 0.9998, 0.001)

        # Restart mechanism
        if no_improve > 400:
            restart_count += 1
            if time.monotonic() > deadline - 60:
                break
            # Perturb the best and restart
            a = best_a + 0.05 * rng_local.standard_normal(n)
            a = project_nonneg_simplex(a, 1.0)
            v = np.zeros(n)
            lr = 0.05
            temperature = 0.03
            momentum = 0.5
            no_improve = 0
            print(f"  {verbose_prefix}Restart {restart_count} at it={it}, score={best_score:.6f}")

    return best_a, best_score


def make_initializations(n, rng):
    """Generate diverse initializations of length n."""
    inits = []
    idx = np.arange(n, dtype=np.float64)

    # Uniform
    inits.append(('uniform', np.ones(n)))

    # Cosine taper
    if n > 1:
        cos_t = 0.5 * (1.0 + np.cos(np.pi * idx / (n - 1)))
        inits.append(('cosine', np.maximum(cos_t, 0.01)))

    # Random
    inits.append(('random', rng.uniform(0.5, 1.5, size=n)))

    # Bell (centered)
    center = (n - 1) / 2.0
    bell = np.exp(-0.5 * ((idx - center) / (n / 6.0)) ** 2)
    inits.append(('bell', np.maximum(bell, 0.01)))

    # Linear ramp
    ramp = np.linspace(0.4, 1.6, n)
    inits.append(('ramp', ramp))

    # Two-peak (bimodal)
    two_peak = (np.exp(-0.5 * ((idx - n * 0.25) / (n / 8.0)) ** 2) +
                np.exp(-0.5 * ((idx - n * 0.75) / (n / 8.0)) ** 2))
    inits.append(('twopeak', np.maximum(two_peak, 0.01)))

    # Sinusoidal modulation
    sine = 1.0 + 0.3 * np.sin(2.0 * np.pi * idx / max(n - 1, 1) * 3)
    inits.append(('sine', np.maximum(sine, 0.05)))

    # Cosine-sine mix
    csm = 1.0 + 0.2 * np.cos(2.0 * np.pi * idx / max(n - 1, 1) * 2) + \
          0.1 * np.sin(2.0 * np.pi * idx / max(n - 1, 1) * 5)
    inits.append(('csm', np.maximum(csm, 0.05)))

    return inits


def propose_candidate(budget_s=1500, **kwargs):
    t0 = time.monotonic()
    deadline = t0 + max(0.0, float(budget_s) - 5.0)

    best_sequence = None
    best_score = float('inf')

    rng = np.random.default_rng(777)

    # Load parent
    try:
        parent = np.asarray(height_sequence_1, dtype=np.float64).copy()
        parent = np.clip(parent, 0.0, 1000.0)
        if parent.ndim == 1 and parent.size > 0 and np.all(np.isfinite(parent)):
            score = evaluate_sequence(parent.tolist())
            if np.isfinite(score):
                best_score = score
                best_sequence = parent.copy()
                print(f"Parent n={parent.size}: score={score:.6f}")
    except (NameError, Exception) as e:
        print(f"Could not load parent: {e}")

    # Determine lengths to try
    lengths_to_try = set()
    if best_sequence is not None:
        pn = len(best_sequence)
        lengths_to_try.add(pn)
        if pn // 2 >= 64:
            lengths_to_try.add(pn // 2)
        if pn * 2 <= 4096:
            lengths_to_try.add(pn * 2)

    # Add standard lengths
    for n in [256, 512, 1024, 2048]:
        lengths_to_try.add(n)

    lengths_to_try = sorted(lengths_to_try)

    # Phase 1: Quick screening (first ~120s)
    screen_time = 120.0
    screen_deadline = min(t0 + screen_time, deadline)

    candidates = []  # (sequence, score, n, label)

    for n in lengths_to_try:
        if time.monotonic() > screen_deadline - 5:
            break

        sub_deadline = min(screen_deadline, time.monotonic() + 15.0)
        print(f"\nScreening n={n}...")

        inits = make_initializations(n, rng)

        # Include parent if matching length
        if best_sequence is not None and n == len(best_sequence):
            inits.insert(0, ('parent', best_sequence.copy()))

        for label, f_init in inits:
            if time.monotonic() > sub_deadline - 2:
                break

            f_init = np.clip(f_init.astype(np.float64), 0.0, 1000.0)
            s = f_init.sum()
            if s < 1e-15:
                continue
            f_init = f_init / s

            score = evaluate_sequence(f_init.tolist())
            if not np.isfinite(score):
                continue

            if score < best_score:
                best_score = score
                best_sequence = f_init.copy()

            candidates.append((f_init.copy(), score, n, label))
            print(f"  n={n} {label}: {score:.6f}")

        # Quick optimization on best init for this n
        cands_for_n = [c for c in candidates if c[2] == n]
        if cands_for_n:
            best_for_n = min(cands_for_n, key=lambda x: x[1])
            quick_dl = min(screen_deadline, time.monotonic() + 8.0)
            f_opt, s_opt = optimize_candidate(best_for_n[0], quick_dl,
                                               verbose_prefix=f"[screen n={n}]")
            if s_opt < best_score:
                best_score = s_opt
                best_sequence = f_opt.copy()
                candidates.append((f_opt.copy(), s_opt, n, 'screen_opt'))

    print(f"\nAfter screening: best={best_score:.6f}, n={len(best_sequence) if best_sequence is not None else '?'}")

    # Phase 2: Deep optimization on top candidates
    if time.monotonic() < deadline - 30:
        # Get unique best per length
        candidates.sort(key=lambda x: x[1])
        seen_lengths = set()
        top_candidates = []
        for c in candidates:
            if c[2] not in seen_lengths:
                seen_lengths.add(c[2])
                top_candidates.append(c)
            if len(top_candidates) >= 4:
                break

        # Always include current best
        if best_sequence is not None:
            top_candidates.append((best_sequence.copy(), best_score, len(best_sequence), 'global_best'))

        # Deduplicate by checking if same sequence already included
        unique_tops = []
        for tc in top_candidates:
            dup = False
            for uc in unique_tops:
                if tc[2] == uc[2] and np.allclose(tc[0], uc[0], atol=1e-6):
                    dup = True
                    break
            if not dup:
                unique_tops.append(tc)
        top_candidates = unique_tops

        remaining = deadline - time.monotonic()
        time_per = remaining / max(len(top_candidates), 1)

        for i, (f_cand, s_cand, n_cand, label) in enumerate(top_candidates):
            if time.monotonic() > deadline - 20:
                break

            sub_deadline = min(deadline, time.monotonic() + time_per)
            print(f"\nDeep opt [{i+1}/{len(top_candidates)}]: n={n_cand}, init_score={s_cand:.6f}, time_budget={time_per:.0f}s")

            f_opt, s_opt = optimize_candidate(f_cand, sub_deadline,
                                               verbose_prefix=f"[deep n={n_cand}]")
            if s_opt < best_score:
                best_score = s_opt
                best_sequence = f_opt.copy()
                print(f"  *** New best: {best_score:.6f} (n={n_cand})")

    # Phase 3: Final polish on the global best
    if best_sequence is not None and time.monotonic() < deadline - 15:
        remaining = deadline - time.monotonic()
        if remaining > 20:
            print(f"\nFinal polish: n={len(best_sequence)}, remaining={remaining:.0f}s")
            f_opt, s_opt = optimize_candidate(best_sequence, deadline,
                                               verbose_prefix="[polish]")
            if s_opt < best_score:
                best_score = s_opt
                best_sequence = f_opt.copy()

    if best_sequence is None:
        return [1.0] * 256

    elapsed = time.monotonic() - t0
    print(f"\nFINAL: n={len(best_sequence)}, score={best_score:.6f}, time={elapsed:.1f}s")
    return [float(max(0.0, x)) for x in best_sequence]
