- conv(f + d, f + d) <= M - delta (for some small delta)
- f + d >= 0
- sum(f + d) = 1

This is approximately:
- conv(f, d) + conv(d, f) + conv(d, d) <= M - delta
- For small d: 2*conv(f, d) <= M - delta - M = -delta (linearizing)

So we want: 2*conv(f, d) <= -delta * ones(2n-1), which is:
conv(f, d) <= -delta/2 * ones(2n-1)

This is a linear constraint on d! And we can maximize sum(d) (to make progress) subject to these constraints and d >= -f (to keep f+d >= 0).

This is exactly what the LP in the previous code does! The constraint is conv(f, b) <= M (where b is the direction), and we maximize sum(b).

Wait, but in the previous code, the constraint is conv(f, b) <= M where M = max(conv(f, f)). This means the direction b must satisfy that the cross-convolution doesn't exceed the current peak. This is a valid constraint for ensuring that moving in direction b doesn't increase the peak (to first order).

The improvement comes from the fact that the LP finds the "best" direction (maximizing sum(b)) that satisfies this constraint. Then we move in that direction and the peak decreases.

OK so the LP approach is sound. The question is how to make it more effective:

1. **Better M**: Instead of using M = max(conv(f,f)), use a smaller M. This makes the LP more restrictive but might find a better direction.

2. **Active set**: Only enforce the constraint for lags where conv(f,f) is close to M. This makes the LP less restrictive and potentially finds a better direction.

3. **Multiple directions**: Solve the LP with different M values and try all resulting directions.

4. **Better step size**: Use line search to find the optimal step size in the LP direction.

Now let me think about the spectral method more carefully.

**Spectral method for minimum peak autocorrelation:**

The key equation: R = ifft(|F|^2) where F = fft(f, 2n).

We want to minimize max(R) subject to f >= 0, sum(f) = 1.

Idea: Use the fact that if R is flat, then |F|^2 is concentrated at DC (since ifft of a delta is constant, and fft of constant is delta). Wait, that's the opposite of what we want.

If R is flat (all values equal to 1/(2n-1)), then |F|^2 = fft(R) = (1/(2n-1)) * ones(N) (approximately, for zero-padded case). So we want |F|^2 to be as flat as possible!

This means we want f to have a flat power spectrum. This is the same as saying f should be "white noise" in the frequency domain.

So the spectral initialization should generate sequences with flat power spectra. The challenge is projecting to f >= 0 while maintaining the flat spectrum.

**Approach: Iterative projection between time and frequency domains**

1. Start with f (any non-negative, sum=1)
2. Compute F = fft(f, 2n)
3. Set |F| = 1 (flat amplitude in frequency domain)
4. f_new = ifft(exp(i*angle(F))).real
5. Project: f_new = max(f_new, 0), normalize
6. Repeat

This is similar to the Gerchberg-Saxton algorithm / Holy Grail algorithm used in optics for phase retrieval.

But there's a problem: after projection to non-negative, the spectrum is no longer flat. The iteration might not converge to a good solution.

A better approach: instead of setting |F| = 1, set |F| proportional to 1/sqrt(R) or some function that reduces the peak of R.

Actually, let me think about this differently. The problem is equivalent to:

Minimize max_k R(k) subject to R = ifft(|F|^2), f = ifft(F), f >= 0, sum(f) = 1.

One approach is to parameterize by the amplitude spectrum: let F = A * exp(i*phi), where A is the amplitude and phi is the phase. We want to find A and phi such that:
- ifft(A * exp(i*phi)) >= 0
- sum(ifft(A * exp(i*phi))) = 1
- max(ifft(A^2)) is minimized

For a given A, the best phi is the one that makes ifft(A * exp(i*phi)) as non-negative as possible. This is a phase retrieval problem.

For a given phi, the best A is the one that minimizes max(ifft(A^2)) subject to ifft(A * exp(i*phi)) >= 0 and sum = 1.

def spectral_refine_v2(f, n_iter=5000):
    n = len(f)
    f = normalize_nonneg(f.copy())
    best_f = f.copy()
    best_score = compute_score(f)

        R = np.fft.ifft(np.abs(F)**2).real
        M = R.max()
        k_peak = R.argmax()
        
        # The peak is at lag k_peak. We want to reduce R[k_peak].
        # R[k_peak] = sum_j f[j] * f[(k_peak - j) mod N]
        # To reduce this, we can reduce the overlap between f and its shifted version.
        
        # In the frequency domain, R = ifft(|F|^2), so:
        # R[k] = (1/N) * sum_m |F[m]|^2 * exp(2*pi*i*m*k/N)
        # To reduce R[k_peak], we want to reduce the contribution of exp(2*pi*i*m*k_peak/N)
        # which means we should reduce |F[m]| at frequencies where exp(2*pi*i*m*k_peak/N) is
        # in phase with the peak contribution.
        
        # Simple approach: reduce |F| proportionally to the "peak component"
        # peak_component[m] = |F[m]|^2 * cos(2*pi*m*k_peak/N)
        # (the real part contributes to R[k_peak])
        
        # Even simpler: just reduce the overall amplitude where it's largest
        A = np.abs(F)
        phase = np.angle(F)
        
        # Reduce the largest amplitudes more
        A_max = A.max()
        weight = 1.0 - 0.3 * (A / A_max) ** 2
        A_new = A * weight
        
        F_new = A_new * np.exp(1j * phase)
        f_new = np.fft.ifft(F_new).real
        f_new = normalize_nonneg(f_new)
        
        score = compute_score(f_new)

```python
"""
Hybrid optimization for minimizing 2*n*max(conv(f,f))/sum(f)^2.
Combines spectral initialization, LP-based direction finding with active set,
subgradient polishing, and diverse restarts across multiple sequence lengths.
"""

import numpy as np
from scipy.optimize import linprog
import time


def compute_score(f):
    """Compute 2*n*max(conv(f,f)) for normalized f (sum=1, f>=0)."""
    n = len(f)
    conv = np.convolve(f, f)
    return 2.0 * n * conv.max()


def normalize_nonneg(f):
    """Clip to non-negative and normalize to sum=1."""
    f = np.maximum(f, 0.0)
    s = f.sum()
    if s < 1e-15:
        return np.ones_like(f) / len(f)
    return f / s


def build_conv_matrix_active(f, active_lags):
    """Build constraint matrix for LP, only for active lags."""
    n = len(f)
    A = np.zeros((len(active_lags), n))
    for i, k in enumerate(active_lags):
        jmin = max(0, k - n + 1)
        jmax = min(n - 1, k)
        for j in range(jmin, jmax + 1):
            A[i, j] = f[k - j]
    return A


def build_conv_matrix(f):
    """Build full convolution matrix."""
    n = len(f)
    A = np.zeros((2 * n - 1, n))
    for k in range(2 * n - 1):
        jmin = max(0, k - n + 1)
        jmax = min(n - 1, k)
        for j in range(jmin, jmax + 1):
            A[k, j] = f[k - j]
    return A


def spectral_init(n, rng, method='flat'):
    """Generate a sequence with approximately flat power spectrum."""
    if method == 'flat':
        # Random phases, flat amplitude
        N = 2 * n
        phases = 2 * np.pi * rng.random(N)
        F = np.exp(1j * phases)
        # Ensure DC component gives positive sum
        F[0] = np.abs(F[0])
        f = np.fft.ifft(F).real
        f = np.maximum(f, 0)
        f = normalize_nonneg(f)
    elif method == 'compressed':
        # Start with flat, apply power compression
        N = 2 * n
        phases = 2 * np.pi * rng.random(N)
        A = rng.random(N) ** 0.5  # Mildly non-flat amplitude
        F = A * np.exp(1j * phases)
        F[0] = np.abs(F[0])
        f = np.fft.ifft(F).real
        f = np.maximum(f, 0)
        f = normalize_nonneg(f)
    elif method == 'structured':
        # Based on a cosine structure
        t = np.arange(n)
        f = 1.0 + 0.5 * np.cos(2 * np.pi * rng.random() * t / n) + \
            0.3 * np.cos(2 * np.pi * rng.random() * t / n + rng.random() * 2 * np.pi)
        f = np.maximum(f, 0)
        f = normalize_nonneg(f)
    else:
        f = np.ones(n) / n
    return f


def random_init(n, rng):
    """Generate a random non-negative sequence."""
    method = rng.integers(0, 4)
    if method == 0:
        f = rng.random(n)
    elif method == 1:
        f = rng.exponential(1.0, n)
    elif method == 2:
        f = np.abs(rng.standard_normal(n))
    else:
        f = rng.random(n) ** 2
    return normalize_nonneg(f)


def lp_refine(f, time_budget, rng, use_active_set=True, verbose=False):
    """
    LP-based refinement.
    f should be normalized (sum=1, f>=0).
    """
    n = len(f)
    f = f.astype(np.float64).copy()
    best_f = f.copy()
    best_score = compute_score(f)
    t = 0.5
    stall = 0
    start_time = time.monotonic()
    it = 0
    
    while time.monotonic() - start_time < time_budget:
        conv = np.convolve(f, f)
        M = conv.max()
        
        # Determine active set
        if use_active_set:
            threshold = 0.90 * M
            active_lags = np.where(conv >= threshold)[0]
            A = build_conv_matrix_active(f, active_lags)
            b_ub = np.full(len(active_lags), M)
        else:
            A = build_conv_matrix(f)
            b_ub = np.full(2 * n - 1, M)
        
        # Solve LP: maximize sum(b) subject to A @ b <= b_ub, b >= 0
        c_obj = -np.ones(n)
        try:
            res = linprog(c_obj, A_ub=A, b_ub=b_ub,
                         bounds=[(0, None)] * n, method='highs',
                         options={'presolve': True, 'time_limit': max(1.0, time_budget * 0.05)})
        except Exception:
            break
        
        if not res.success or res.x is None:
            break
        
        b = np.maximum(res.x, 0.0)
        b_sum = b.sum()
        if b_sum < 1e-15:
            break
        
        g = b / b_sum
        
        # Line search
        best_t = 0
        best_s = best_score
        for t_candidate in [0.05, 0.1, 0.2, 0.3, 0.5, 0.7, 1.0]:
            f_new = normalize_nonneg((1 - t_candidate) * f + t_candidate * g)
            s = compute_score(f_new)
            if s < best_s:
                best_s = s
                best_t = t_candidate
        
        if best_t > 0 and best_s < best_score - 1e-10:
            f = normalize_nonneg((1 - best_t) * f + best_t * g)
            best_f = f.copy()
            best_score = best_s
            stall = 0
            t = best_t  # Remember good step size
            if verbose and it % 10 == 0:
                print(f"    LP it={it}, score={best_score:.6f}, t={best_t:.2f}, "
                      f"active={len(active_lags) if use_active_set else 2*n-1}, "
                      f"elapsed={time.monotonic()-start_time:.1f}s")
        else:
            stall += 1
            if stall > 30:
                # Try perturbation
                f_pert = f + 0.05 * (2 * rng.random(n) - 1)
                f_pert = normalize_nonneg(f_pert)
                s_pert = compute_score(f_pert)
                if s_pert < best_score:
                    f = f_pert
                    best_f = f.copy()
                    best_score = s_pert
                    stall = 0
                    t = 0.3
                elif time.monotonic() - start_time > time_budget * 0.85:
                    break
                else:
                    stall = min(stall, 50)
        
        it += 1
    
    return best_f, best_score


def subgradient_polish(f, n_iter=3000, verbose=False):
    """
    Subgradient descent polishing.
    f should be normalized (sum=1, f>=0).
    """
    n = len(f)
    f = f.astype(np.float64).copy()
    best_f = f.copy()
    best_score = compute_score(f)
    
    alpha = 1.0 / n
    v = np.zeros(n)
    momentum = 0.5
    stall = 0
    
    for i in range(n_iter):
        conv = np.convolve(f, f)
        M = conv.max()
        k_star = conv.argmax()
        
        # Compute subgradient: s[m] = 2*f[k_star - m] for valid m
        jmin = max(0, k_star - n + 1)
        jmax = min(n - 1, k_star)
        s = np.zeros(n)
        m_vals = np.arange(jmin, jmax + 1)
        s[m_vals] = 2.0 * f[k_star - m_vals]
        
        # Momentum
        v = momentum * v + s
        f_new = normalize_nonneg(f - alpha * v)
        
        score_new = compute_score(f_new)
        if score_new < best_score:
            best_f = f_new.copy()
            best_score = score_new
            f = f_new
            alpha = min(alpha * 1.02, 5.0)
            stall = 0
        else:
            alpha *= 0.8
            stall += 1
            if stall > 200:
                break
        
        if verbose and i % 500 == 0:
            print(f"    SGD it={i}, score={best_score:.6f}, alpha={alpha:.2e}")
    
    return best_f, best_score


def local_search(f, rng, n_iter=2000):
    """Random local search to polish."""
    n = len(f)
    f = f.copy()
    best = f.copy()
    best_score = compute_score(f)
    
    for _ in range(n_iter):
        f_candidate = f.copy()
        width = max(1, int(rng.integers(1, max(2, n // 16))))
        start = int(rng.integers(0, n - width))
        scale = np.exp(rng.normal(0, 0.3))
        f_candidate[start:start + width] *= scale
        f_candidate = normalize_nonneg(f_candidate)
        score = compute_score(f_candidate)
        if score < best_score:
            best = f_candidate.copy()
            best_score = score
            f = f_candidate
    return best, best_score
