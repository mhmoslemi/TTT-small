Now let me also think about a completely different approach: **coordinate descent / greedy updates**.

At each step, find the index j that gives the best improvement if we move mass from j to some other index j'. This is like a "greedy swap" algorithm.

For a sequence f, consider moving ε from f[j] to f[j']:
- Change in (f*f)[k] = -ε*f[k-j] + ε*f[k-j'] + ... (second-order terms)
- We want to reduce the maximum, so we want to reduce the active lags.

This is expensive to evaluate naively, but with FFT we can compute the convolution efficiently.

Actually, for a single transfer of ε from position j to position j':
- New f = f - ε*e_j + ε*e_j'
- New conv = conv(f,f) - 2ε*(f shifted by j) + 2ε*(f shifted by j') + ε^2*conv(e_j - e_j', e_j - e_j')
  (ignoring the ε^2 term for small ε)
  
  More precisely:
  (f + δf)*(f + δf) = f*f + 2*f*δf + δf*δf
  where δf = -ε*e_j + ε*e_j'
  
  f*δf = -ε*(f shifted by j) + ε*(f shifted by j')
  (The convolution of f with e_j is f shifted by j)

So the change in the convolution at lag k is:
Δ(f*f)[k] = 2ε*(f[k-j'] - f[k-j]) + O(ε^2)

We want to reduce the maximum, so we want:
For all active k: 2ε*(f[k-j'] - f[k-j]) < 0
i.e., for all active k: f[k-j'] < f[k-j]

This means: at all active lags, the "source" position j has more "pressure" than the "destination" position j'.

The optimal (j, j') pair would be one that maximizes the minimum reduction across all active lags. This is a matrix golden section type problem.

For efficiency, I can precompute for each j the vector v_j where v_j[k] = f[k-j] (with zero padding), and then the "pressure" at position j is the average (or max) of v_j over active lags.

This is essentially what the subgradient method does, but the greedy method makes discrete moves while the subgradient method makes continuous moves.

Optimizes non-negative step function heights to minimize 2n*max(conv(f,f))/(sum(f))^2.
Uses diverse asymmetric initializations, adaptive mirror descent with periodic

def _fft_conv(f):
    """Full linear auto-convolution via FFT."""
    n = len(f)
    size = 1
    while size < 2*n - 1:
        size <<= 1
    F = np.fft.rfft(f, size)
    return np.fft.irfft(F*F, size)[:2*n-1]

def _score(f):
    """Compute score = 2n*max(conv)/sum^2. Assumes f is a numpy array."""
    n = len(f)
    S = f.sum()
    if S < 0.01:
        return np.inf
    M = _fft_conv(f).max()
    return 2.0*n*M/(S*S)

def _normalize(f):
    """Normalize to sum=1, clip negatives."""
    f = np.maximum(f, 0.0)
    S = f.sum()
    if S < 1e-30:
        return None
    return f/S

def _subgrad(f, active):
    """Compute subgradient of max_{k in active} (f*f)[k] at f.
    Returns vector g where g[j] = (2/|active|) * sum_{k in active} f[k-j]."""
    n = len(f)
    # Pad f to handle boundaries
    fp = np.zeros(2*n-1)
    fp[:n] = f
    g = np.zeros(n)
    for k in active:
        # g[j] += 2*f[k-j] for valid j
        # k-j ranges from k-(n-1) to k
        # We need 0 <= k-j < n, i.e., k-n+1 <= j <= k
        j_lo = max(0, k-n+1)
        j_hi = min(n-1, k)
        if j_hi >= j_lo:
            # f[k-j] for j in [j_lo, j_hi]
            # k-j ranges from k-j_hi to k-j_lo
            idx = k - np.arange(j_lo, j_hi+1)
            g[j_lo:j_hi+1] += 2.0*f[idx]
    g /= len(active)
    return g

def _mirror_descent(f0, max_iters, eta_scale, thresh_frac, deadline, perturb_every=200, perturb_frac=0.05):
    """Mirror descent with multiplicative updates. Returns (best_f, best_score)."""
    f = _normalize(f0.astype(np.float64).copy())
    if f is None:
        return f0.copy(), np.inf
    n = len(f)
    best_f = f.copy()
    best_score = _score(f)
    rng = np.random.default_rng(42)
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        h = _fft_conv(f)
        M = h.max()
        if M < 1e-30:
            break
        
        # Active set
        thresh = thresh_frac * M
        active = np.where(h >= thresh)[0]
        if len(active) == 0:
            active = np.array([np.argmax(h)])
        
        # Subgradient
        g = _subgrad(f, active)
        
        # Multiplicative update
        g_max = g.max()
        if g_max < 1e-30:
            break
        eta = eta_scale / g_max
        f = f * np.exp(-eta * g)
        f = _normalize(f)
        if f is None:
            f = np.ones(n)/n
        
        sc = _score(f)
        if sc < best_score:
            best_score = sc
            best_f = f.copy()
        
        # Periodic perturbation

            noise = rng.random(n) * perturb_frac
            f_p = f + noise
            f = _normalize(f_p)
            if f is not None:
                f = f
    
    return best_f, best_score

This is O(n * |K|) which for |K| ~ n/2 is O(n^2). For n=1024, that's about 1M operations per subgradient evaluation, which is fine.

But we can do even better with FFT. The sum over k in K of f[k-j] is the cross-correlation of f with the indicator of K, evaluated at position j.

Let I be the indicator vector of K (length 2n-1, with I[k] = 1 if k in K).
Then sum_{k in K} f[k-j] = sum_k I[k] * f[k-j] (with f out of range = 0).

This is the cross-correlation (I ⋆ f)[j] = sum_k I[k] * f[k-j].

Using FFT: cross-correlation can be computed as:

"""
Optimizes non-negative step function heights to minimize 2n*max(conv(f,f))/(sum(f))^2.
Uses diverse asymmetric initializations (exponential, power-law, skewed Gaussian),
smoothed-max subgradient descent with temperature annealing, adaptive step sizes,
periodic perturbation restarts, greedy coordinate swaps, and multi-length exploration.

import numpy as np
import time


def _fft_conv(f):
    """Full linear auto-convolution via FFT."""
    n = len(f)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    F = np.fft.rfft(f, size)
    return np.fft.irfft(F * F, size)[:2 * n - 1]


def _score(f):
    """Compute 2n*max(conv)/sum^2."""
    n = len(f)
    S = float(np.sum(f))
    if S < 0.01:
        return np.inf
    M = float(np.max(_fft_conv(f)))
    return 2.0 * n * M / (S * S)


def _normalize(f):
    """Normalize to sum=1, clip negatives. Returns None if degenerate."""
    f = np.maximum(np.asarray(f, dtype=np.float64), 0.0)
    S = float(np.sum(f))
    if S < 1e-30:
        return None
    return f / S


def _subgrad(f, active):
    """Subgradient of max_{k in active} (f*f)[k] at f."""
    n = len(f)
    g = np.zeros(n, dtype=np.float64)
    for k in active:
        j_lo = max(0, k - n + 1)
        j_hi = min(n - 1, k)
        if j_hi >= j_lo:
            g[j_lo:j_hi + 1] += f[k - j_hi:k - j_lo + 1][::-1]
    g *= 2.0 / float(len(active))
    return g


def _smoothed_subgrad(f, h, T):
    """Smoothed subgradient using softmax-weighted active set."""
    n = len(f)
    h_shift = h - h.max()
    weights = np.exp(T * h_shift)
    wsum = weights.sum()
    if wsum < 1e-300:
        return _subgrad(f, np.array([int(np.argmax(h))]))
    weights /= wsum
    g = np.zeros(n, dtype=np.float64)
    for k in range(2 * n - 1):
        if weights[k] < 1e-12:
            continue
        j_lo = max(0, k - n + 1)
        j_hi = min(n - 1, k)
        if j_hi >= j_lo:
            g[j_lo:j_hi + 1] += weights[k] * f[k - j_hi:k - j_lo + 1][::-1]
    g *= 2.0
    return g


def _mirror_descent(f0, max_iters, eta_scale, thresh_frac, deadline,
                    use_smoothed=False, T_start=5.0, T_end=50.0,
                    perturb_every=0, perturb_frac=0.03):
    """Mirror descent with multiplicative updates."""
    f = _normalize(f0.astype(np.float64).copy())
    if f is None:
        return f0.copy(), np.inf
    n = len(f)
    best_f = f.copy()
    best_score = _score(f)
    rng = np.random.default_rng(123)

    for it in range(max_iters):
        if time.monotonic() > deadline:
            break

        h = _fft_conv(f)
        M = float(h.max())
        if M < 1e-30:
            break

        if use_smoothed:
            progress = min(1.0, it / float(max(1, max_iters)))
            T = T_start + (T_end - T_start) * progress
            g = _smoothed_subgrad(f, h, T)
        else:
            thresh = thresh_frac * M + 1e-15
            active = np.where(h >= thresh)[0]
            if len(active) == 0:
                active = np.array([int(np.argmax(h))])
            g = _subgrad(f, active)

        g_max = float(g.max())
        if g_max < 1e-30:
            break

        eta = eta_scale / g_max
        log_ratio = -eta * g
        log_ratio = np.clip(log_ratio, -20.0, 20.0)
        f = f * np.exp(log_ratio)
        f = _normalize(f)
        if f is None:
            f = np.ones(n) / n

        sc = _score(f)
        if sc < best_score:
            best_score = sc
            best_f = f.copy()

        if perturb_every > 0 and (it + 1) % perturb_every == 0:
            noise = rng.random(n) * perturb_frac
            fp = f + noise
            f = _normalize(fp)
            if f is not None:
                pass
            else:
                f = best_f.copy()

    return best_f, best_score


def _greedy_refine(f, n_swaps, deadline):
    """Greedy coordinate transfer: move mass from high-pressure to low-pressure positions."""
    f = _normalize(f.astype(np.float64).copy())
    if f is None:
        return f, np.inf
    n = len(f)
    best_f = f.copy()
    best_score = _score(f)
    no_improve = 0

    for _ in range(n_swaps):
        if time.monotonic() > deadline:
            break
        if no_improve > 50:
            break

        h = _fft_conv(f)
        M = h.max()
        thresh = 0.98 * M
        active = np.where(h >= thresh)[0]
        if len(active) == 0:
            active = np.array([int(np.argmax(h))])

        g = _subgrad(f, active)

        src = int(np.argmax(g))
        dst = int(np.argmin(g))
        if src == dst:
            break

        for frac in [0.1, 0.05, 0.02, 0.01]:
            eps = f[src] * frac
            if eps < 1e-15:
                break
            f_trial = f.copy()
            f_trial[src] -= eps
            f_trial[dst] += eps
            f_trial = _normalize(f_trial)
            if f_trial is None:
                continue
            sc = _score(f_trial)
            if sc < best_score - 1e-12:
                best_score = sc
                best_f = f_trial.copy()
                f = f_trial
                no_improve = 0
                break
        else:
            no_improve += 1

    return best_f, best_score


def _init_uniform(n):
    return np.ones(n) / n

def _init_exp_sym(n, alpha):
    j = np.arange(n, dtype=np.float64)

    j = np.arange(n, dtype=np.float64)

    return _normalize(f)

        if s_sm < best_score:
            best_score = s_sm
            best_f = f_sm.copy()
            print(f"  Smoothed MD: ** NEW BEST {best_score:.6f}")
        f_cur = f_sm
        s_cur = s_sm

        # 2b: Hard-threshold mirror descent with varied thresholds
        for tf in [0.6, 0.8, 0.9, 0.95]:
            if time.monotonic() > deep_deadline - 30:
                break
            t_dead2 = min(deep_deadline - 30, time.monotonic() + 80)
            n_it2 = int((t_dead2 - time.monotonic()) * 200)
            f_t, s_t = _mirror_descent(f_cur, n_it2, 0.12, tf, t_dead2)
            if s_t < best_score:
                best_score = s_t
                best_f = f_t.copy()
                print(f"  TH={tf}: ** NEW BEST {best_score:.6f}")
            f_cur = f_t
            s_cur = s_t

        # 2c: Greedy refinement
        if time.monotonic() < deep_deadline - 40:
            t_g = min(deep_deadline - 30, time.monotonic() + 80)
            f_g, s_g = _greedy_refine(f_cur, 500, t_g)
            if s_g < best_score:
                best_score = s_g
                best_f = f_g.copy()
                print(f"  Greedy: ** NEW BEST {best_score:.6f}")
            f_cur = f_g
            s_cur = s_g

        # 2d: Perturbation restarts
        if time.monotonic() < deep_deadline - 20:
            for pf in [0.01, 0.03, 0.08]:
                if time.monotonic() > deep_deadline - 10:
                    break
                noise = rng.random(len(f_cur)) * pf
                f_pert = _normalize(f_cur + noise)
                if f_pert is None:
                    continue
                t_p = min(deep_deadline - 10, time.monotonic() + 50)
                n_it_p = int((t_p - time.monotonic()) * 250)
                f_pr, s_pr = _mirror_descent(f_pert, n_it_p, 0.15, 0.85, t_p)
                if s_pr < best_score:
                    best_score = s_pr
                    best_f = f_pr.copy()
                    print(f"  Perturb({pf}): ** NEW BEST {best_score:.6f}")
                f_cur = f_pr

        # 2e: One more smoothed pass from the best of this candidate
        if time.monotonic() < deep_deadline - 10:
            t_dead3 = min(deep_deadline - 5, time.monotonic() + 60)
            n_it3 = int((t_dead3 - time.monotonic()) * 250)
            f_fin, s_fin = _mirror_descent(f_cur, n_it3, 0.08, 0.9, t_dead3,
                                           use_smoothed=True, T_start=10.0, T_end=200.0)
            if s_fin < best_score:
                best_score = s_fin
                best_f = f_fin.copy()
                print(f"  Final smoothed: ** NEW BEST {best_score:.6f}")

    # Phase 3: Final fine-tuning on global best
    if time.monotonic() < deadline - 20:
        print(f"\n=== Final fine-tuning (score={best_score:.6f}) ===")
        t_final = deadline - 10
        n_it_final = int((t_final - time.monotonic()) * 300)

        # Very small step, high threshold
        f_vf, s_vf = _mirror_descent(best_f, n_it_final, 0.03, 0.99, t_final)
        if s_vf < best_score:
            best_score = s_vf
            best_f = f_vf.copy()
            print(f"  Final MD: ** NEW BEST {best_score:.6f}")

        # Greedy on the final result
        if time.monotonic() < deadline - 5:
            f_gf, s_gf = _greedy_refine(best_f, 300, deadline - 5)
            if s_gf < best_score:
                best_score = s_gf
                best_f = f_gf.copy()
                print(f"  Final greedy: ** NEW BEST {best_score:.6f}")

    # Verify and return
    final_list = [float(x) for x in best_f]
    final_score = float(evaluate_sequence(final_list))
    print(f"\nFinal verified score: {final_score:.6f} (n={len(final_list)})")

    if not np.isfinite(final_score) or final_score > 2.0:
        print("Falling back to parent.")
        return [float(x) for x in parent]

    return final_list
