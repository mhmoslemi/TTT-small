The key issue is: the LP approach finds a direction g that maximizes sum(g) subject to conv(f,g) <= M. This is a good direction, but it's not necessarily the best direction for reducing the objective.

A better approach might be:
1. Compute the current conv(f,f)
2. Identify the top K lags (those closest to the maximum)
3. Find a direction g that reduces the maximum of these top K lags the most

For step 3, we can solve:
min max_{k in top_K} d(conv_k)/dt at t=0
where conv(f+t*d, f+t*d)_k ≈ conv(f,f)_k + 2t*conv(f,d)_k (for small t)

So we want to minimize max_{k in top_K} conv(f,d)_k (since conv(f,f)_k is fixed).

Subject to: d >= -f (to maintain f+td >= 0 for small t>0), sum(d) = 0 (to maintain normalization).

This is: min max_{k in top_K} (A_k d) subject to d >= -f, sum(d) = 0.

This is an LP! Let me formulate it:
min t
s.t. conv(f,d)_k <= t for k in top_K
     d >= -f
     sum(d) = 0

where conv(f,d)_k = sum_j f[k-j]*d[j]

This LP has n variables and |top_K| + n + 1 constraints.

So the linear LP gives us a direction that's good for small t, but for larger t, the t^2 term matters.

We can handle this by:
1. Solving the LP to get direction d
2. Finding the best step size by 1D optimization (goldens section search)
3. Repeating

def build_conv_matrix(f):
    """Build sparse matrix A where (A@g)[k] = conv(f,g)[k] for k=0..2n-2."""
    n = len(f)

    cols = []
    vals = []

        j_max = min(k, n - 1)
        for j in range(j_min, j_max + 1):

def spectral_init(n, seed=0):
    """Generate initialization from flat power spectrum with random phases."""
    rng = np.random.default_rng(seed)
    # Random phases
    phases = rng.uniform(0, 2 * np.pi, size=n)
    # Flat amplitude (sqrt of desired power)
    spectra = np.exp(1j * phases)
    # Inverse DFT to get time domain
    f = np.real(np.fft.ifft(spectra))
    # Make non-negative: take absolute value or shift
    f = np.abs(f)
    # Alternative: use cosine transform for guaranteed non-negative
    # f = np.abs(np.fft.irfft(spectra[:n//2+1]))
    if np.sum(f) < 1e-10:
        f = np.ones(n)
    return f

    # Phase 2: Gradient polish (15% of time)
    t_phase2 = t0 + (budget_s - 15) * 0.45
    best_f, best_score = gradient_optimize(best_f, t_phase2, name="[P2-Grad] ")
    print(f"After P2: score={best_score:.8f}", flush=True)

    # Phase 3: LP with wider active set (15% of time)
    t_phase3 = t0 + (budget_s - 15) * 0.60
    best_f, best_score = lp_optimize_phase(best_f, t_phase3, name="[P3-LP-wide] ",
                                            use_reduction=True, top_k=7)
    print(f"After P3: score={best_score:.8f}", flush=True)

    # Phase 4: Gradient with smaller lr (15% of time)
    t_phase4 = t0 + (budget_s - 15) * 0.75
    best_f, best_score = gradient_optimize(best_f, t_phase4, name="[P4-Grad-fine] ")
    print(f"After P4: score={best_score:.8f}", flush=True)

    # Phase 5: Try original LP direction (10% of time)
    t_phase5 = t0 + (budget_s - 15) * 0.85
    best_f, best_score = lp_optimize_phase(best_f, t_phase5, name="[P5-LP-orig] ",
                                            use_reduction=False, top_k=3)
    print(f"After P5: score={best_score:.8f}", flush=True)

    # Phase 6: Final fine LP (10% of time)
    t_phase6 = total_deadline
    best_f, best_score = lp_optimize_phase(best_f, t_phase6, name="[P6-LP-final] ",
                                            use_reduction=True, top_k=5)
    print(f"After P6: score={best_score:.8f}", flush=True)

    # Verify with actual evaluate_sequence
    final_score = evaluate_sequence([float(x) for x in best_f])
    if not np.isfinite(final_score) or final_score > best_score * 1.001:
        print(f"Warning: evaluate_sequence gives {final_score}, fast gives {best_score}")
        # Fall back to parent
        parent_score = evaluate_sequence([float(x) for x in parent])
        if np.isfinite(parent_score) and parent_score < final_score:
            best_f = parent
            best_score = parent_score

    print(f"\nFINAL: n={len(best_f)}, score={best_score:.8f}, "
          f"time={time.monotonic()-t0:.1f}s", flush=True)
    return [float(x) for x in best_f]
