Let me think about the subgradient method more carefully.

At each iteration:
1. Compute c = conv(a, a) (length 2n-1).
2. Find the "active" peaks: positions where c[k] >= c_max - delta (for some small delta).
3. Compute the subgradient: g[i] = (1/|S|) * sum_{k in S} 2 * a[k-i] (for valid k-i).
4. Update: a_new = a - eta * g.
5. Project a_new onto the simplex.
6. Optionally: line search to find a good eta.

For efficiency, I can compute the subgradient without explicitly iterating over all active peaks:
- g = (1/|S|) * sum_{k in S} 2 * reverse_a[k]
- where reverse_a[k] is the vector with (reverse_a[k])[i] = a[k-i] if 0 <= k-i < n, else 0.

This is equivalent to: g[i] = 2/|S| * sum_{k in S} a[k-i] (for valid k).

If I denote h[k] = 1 if k is in S, else 0, then:
g[i] = 2/|S| * sum_k h[k] * a[k-i] = 2/|S| * (h * a)[i] (circular or linear convolution, depending on bounds)

Actually, this is a correlation: g[i] = 2/|S| * sum_k h[k] * a[k-i] = 2/|S| * (h ∘ a)[i] where ∘ denotes cross-correlation.

We can compute this efficiently using FFT!

So the algorithm is:
1. Compute c = conv(a, a) using FFT.
2. Compute h = indicator of active peaks.
3. Compute g = 2/|S| * cross_correlation(h, a) using FFT.
4. Update a -= eta * g, project to simplex.

This is O(n log n) per iteration! Very fast.

def project_simplex(v):

def spectral_flatten(a, max_iters=1000, verbose=False, mix=0.5):
    """
    Iterative spectral flattening: alternate between time domain (non-negativity + normalization)
    and frequency domain (flatten the power spectrum).
    """

    a = a.astype(np.float64).copy()

    S = a.sum()
    if S < 1e-15:

        S = 1.0

    best_score = compute_score(a)
    
    for it in range(max_iters):
        # Frequency domain: flatten |A|^2
        A = np.fft.rfft(a)
        mag = np.abs(A)
        # Target: flat spectrum (all |A|^2 equal)
        target_mag = np.ones_like(mag) * (np.sum(mag**2) / len(mag)) ** 0.5
        # Mix: move towards flat
        new_mag = mag * (1 - mix) + target_mag * mix
        # Preserve phase
        phase = np.angle(A)
        A_new = new_mag * np.exp(1j * phase)
        # Inverse FFT
        a_new = np.fft.irfft(A_new, n)
        # Project to non-negative and normalize
        a_new = np.maximum(a_new, 0)
        S_new = a_new.sum()
        if S_new < 1e-15:
            break
        a_new = a_new / S_new
        
        score = compute_score(a_new)
        if score < best_score:
            best_score = score
            best_a = a_new.copy()
        a = a_new
        
        if verbose and it % 100 == 0:
            print(f"  Spec iter {it}: score={best_score:.6f}")
    
    return best_a, best_score

def build_conv_matrix(f):
    """Build matrix A such that A @ b = np.convolve(f, b, mode='full')."""
    n = len(f)
    A = np.zeros((2 * n - 1, n))
    for k in range(2 * n - 1):
        j_start = max(0, k - n + 1)
        j_end = min(n, k + 1)
        for j in range(j_start, j_end):
            A[k, j] = f[k - j]
    return A

def compute_subgradient(a, active):
    """Compute the subgradient direction for minimizing max(conv(a,a))."""
    n = len(a)
    h = active.astype(np.float64)
    size = 1
    while size < 3 * n:
        size *= 2

    H_fft = np.fft.rfft(h, size)
    corr = np.fft.irfft(np.conj(A_fft) * H_fft)[:n]

    return corr
