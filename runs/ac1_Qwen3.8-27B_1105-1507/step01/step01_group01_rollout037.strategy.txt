<p>Alternatively, we can use the following formulation from the state-of-the-art:</p>
<pre style="background-color: #2d2d2d; padding:  and by lines:">

    Then, we wish to find the sequence g such that:
        maximize sum(b)            [where b is the constraint multiplier]
        subject to: ||f * g||_∞ <= M and g>=0.

    But the state-of-the-art shows that the optimum of this LP is attained at an extremepoint that is a combination of the current sequence and a complementary candidate.</p>

<p style="font-weight: bold;">Let's reimplement the LP step to handle symmetry and to be more memory-efficient.</font></p>

</p><h3>Implementation Details</3>
We will represent the sequence in two ways: as a full sequence for the convolution, but for the LP we can use half the sequence if we symmetrize the constraints.</h3>

1. **Symmetry Reduction:** We symmetrize the sequence so that a[i] = a[j] for i+j = n-1 (or rather, for i+j = k with k fixed, but the pattern is generally symmetric around the center). This means we only have free parameters for the first ceil(n/2) elements, and the others are determined by symmetry.

2. **Constraint Generation:** Instead of generating the full convolution vector (which has 2n-1 elements), we only generate the first half (due to symmetry) or use a sparse representation.

3. **Objective Update:** After the LP step, we project the new g to have symmetry and then normalize it properly for the next step.

Approach and Rationale

Our approach combines multiplicative updates with constraint handling and symmetry optimization. The key idea is to:

1. Start with a normalized sequence (sum=√(2n)) either by using the provided parent sequence or by generating random symmetric sequences

2. Perform iterative multiplicative updates that adjust the sequence coefficients to reduce the score while using an LP relaxation step to improve the convolution properties

3. The score is defined in a scale-independent way to allow aggressive normalization that exposes local extrema

4. Use symmetry to reduce the search space while ensuring the sequence evaluates to valid values

The central objective is to find a sequence where the maximum convolution coefficient is minimized relative to the square of its sum. We use a heuristic strategy that combines gradient-like updates with LP-aided shape optimization.

Mathematical Specification

We operate on sequences with fixed normalization (sum=√(2n) to make score comparisons meaningful. The search space is structured as symmetric sequences except when not specified otherwise.

A sequence is represented as a vector a with components:
- a[0] to a[div]
- a[div+1] to a[n-1] with a[i] = a[n-1-i] (if we use symmetric sequences)

We assume the sequence length n is given or we can explore multiple fixed lengths. The score is computed as:
score = (2 * n * max(convolve(a,a,'full'))) / (sum(a)²)

LP Relaxation Formulation: 

For the LP step, we consider an optimization to bound the convolution maximum M while maximizing the sum of 'important' coefficients (securing the Lipschitz bound). The core LP problem is defined as:
  min: ∑b_j
  subject to: 
      b_j ≥ 0
      ∑_{k} convolve(a,b)[k] ≤ M   (for all k)
  where M is a problem parameter

But note, this is an infinitely constrained linear program (semi-infinite). To make it tractable, we sample pivotal indices from the convolution curve.

   - Evaluate the current score accurately using the helper functions
