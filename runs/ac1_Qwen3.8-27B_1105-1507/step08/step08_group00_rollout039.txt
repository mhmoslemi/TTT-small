Actually, let me think more carefully about the Frank-Wolfe / accelerated LP approach.

The problem we're solving is:
`min f(a) = max_k (a*a)[k]` subject to `sum(a) = 1, a >= 0`

This is a non-convex problem (f is convex since it's the max of linear functions... wait, is it?)

Actually, `(a*a)[k] = sum_j a[j] * a[k-j]` is a quadratic form in `a`, and it's not linear. So `f(a) = max_k (a*a)[k]` is the max of quadratic functions, which is convex (max of convex functions is convex). Wait, is each `(a*a)[k]` convex in `a`?

`(a*a)[k] = sum_j a[j] * a[k-j]` - this is a quadratic form. The Hessian is `2 * A_k` where `A_k` is the matrix with `A_k[j, k-j] = 1` (and symmetric). This is generally not positive semidefinite, so `(a*a)[k]` is not necessarily convex.

For example, for k=0: `(a*a)[0] = sum_j a[j]^2` which is convex.
For k=1: `(a*a)[1] = sum_j a[j] * a[j+1]` which is `a^T B a` where `B` has 1/2 on the super/sub-diagonal. The eigenvalues of B range from -1 to 1, so it's indefinite.

So the problem is non-convex. The LP approach works because we fix one argument: `conv(a, g)[k] = sum_j a[j] * g[k-j]` which IS linear in `g` (for fixed `a`). So the LP is valid for finding the best `g` given `a`.

The alternating approach (fix a, optimize g via LP; fix g, optimize a via LP) is a block coordinate descent method. It's guaranteed to decrease the objective but may converge to a stationary point.

For acceleration, we can use Nesterov's acceleration for block coordinate methods, but that's complex. A simpler approach:

**Heavy-ball acceleration for the LP method:**
```

    a_{t+1} = a_t + step * v
    project a_{t+1} onto simplex
```

This should work well if the fixed points of the alternating LP are close to the optimum.

The convolution operator `T_a: g -> conv(a, g)` is a Toeplitz matrix. Its eigenvalues (approximately, for large n) are given by the DTFT of `a`. Specifically, if we consider the circulant approximation, the eigenvalues are `FFT(a)`.

The LP `min M s.t. T_a g <= M*1, sum(g)=1, g>=0` is essentially finding the minimum of a linear function over a polytope defined by the rows of `T_a`. The optimal `M` is related to the "width" of the feasible region in the direction of `T_a`.

Actually, let me think about this differently. The dual of the LP is:
`max sum_k y_k` subject to `T_a^T y <= 1, y >= 0`

where `T_a^T y` is the cross-correlation of `a` with `y` (similar to conv but with a specific structure).

The optimal `M*` of the primal equals the optimal value of the dual.

So `M* = max {sum y_k : conv_transpose(a, y) <= 1, y >= 0}`

import cvxpy as cp
from scipy.fft import rfft, irfft, fft, ifft
import time

def compute_conv(a):
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]

def compute_obj(a):
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))

def project_simplex(v):
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    idx = np.arange(1, n + 1)
    cond = u * idx > (cssv - 1.0)
    rho = np.where(cond)[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def build_conv_matrix(a):
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        r = min(n, 2 * n - 1 - j)
        A[j:j + r, j] = a[:r]
    return A

def solve_lp_minpeak(a):
    n = len(a)
    a_norm = a / np.sum(a)
    A = build_conv_matrix(a_norm)
    g = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [A @ g <= M, cp.sum(g) == 1]
    prob = cp.Problem(cp.Minimize(M), constraints)
    solvers = [cp.MOSEK, cp.CLARABEL, cp.PDLP, cp.ECOS, cp.SCS]
    for solver in solvers:
        try:
            prob.solve(solver=solver)
            if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g.value, 0)
                s = float(np.sum(g_val))
                if s > 1e-10:
                    return g_val / s, float(M.value)
        except Exception:
            continue
    return None, None

def smoothed_gradient_fft(a, tau):
    n = len(a)
    conv = compute_conv(a)
    max_conv = float(np.max(conv))
    exp_vals = np.exp(tau * (conv - max_conv))
    p = exp_vals / float(np.sum(exp_vals))
    
    N = 1
    while N < 3 * n:
        N <<= 1
    P = fft(p, N)
    A = fft(a, N)
    g_full = ifft(P * np.conj(A)).real
    g = 2.0 * g_full[:n]
    return g, conv

def resample_sequence(a, new_n):
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, a[0])
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)

def diverse_init(n, rng, mode=0):

        a = a / a.sum()
    elif mode == 2:
        centers = [n // 4, 3 * n // 4]
        widths = [n // 8, n // 8]
        a = np.zeros(n)
        for c, w in zip(centers, widths):
            a += np.exp(-((np.arange(n) - c) ** 2) / (2 * w ** 2))
        a = a / a.sum()
    elif mode == 3:
        x = np.linspace(-1, 1, n)
        a = 1.0 / (np.sqrt(1 - x**2 + 1e-6))
        a = a / a.sum()
    elif mode == 4:
        freqs = rng.integers(1, 5, size=4)

    else:
        x = np.linspace(0, np.pi, n)
        a = 0.5 + 0.5 * np.cos(x)

def peak_targeted_optimize(a, time_budget=60.0, verbose=False):
    """Target the top peaks specifically using local moves."""
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    it = 0
    while time.monotonic() - start < time_budget:
        conv = compute_conv(a)
        max_val = float(np.max(conv))
        # Find top peaks
        threshold = 0.95 * max_val
        peak_idx = np.where(conv >= threshold)[0]
        
        if len(peak_idx) == 0:
            break
        
        # For each peak, try to reduce it by adjusting specific coordinates
        improved = False
        for k in peak_idx[:5]:  # Only top 5 peaks
            k = int(k)
            # The peak at k is sum_j a[j]*a[k-j]
            # To reduce it, we can try to reduce a[j] for j that contribute most
            contributions = np.zeros(n)
            for j in range(n):
                k_j = k - j
                if 0 <= k_j < 2 * n - 1:
                    contributions[j] = a[j] * (a[k_j] if 0 <= k_j < n else 0)
            
            # Find the top contributing indices
            top_contrib = np.argsort(contributions)[::-1][:3]
            
            for idx in top_contrib:
                # Try reducing a[idx] slightly
                for delta in [0.01, 0.005, 0.001]:
                    a_try = a.copy()
                    a_try[idx] = max(0, a_try[idx] - delta)
                    # Redistribute to maintain sum=1
                    reduction = a[idx] - a_try[idx]
                    if reduction > 0:
                        # Add to a random non-peak position
                        other = np.random.randint(n)
                        if other != idx:
                            a_try[other] += reduction
                    s_try = float(np.sum(a_try))
                    if s_try > 0:
                        a_try = a_try / s_try
                        obj_try = compute_obj(a_try)
                        if obj_try < best_obj - 1e-12:
                            best_obj = obj_try
                            best_a = a_try.copy()
                            a = a_try
                            improved = True
                            break
                if improved:
                    break
        
        it += 1
        if not improved and it > 100:
            break
    
    return best_a

"""

import numpy as np
import cvxpy as cp
from scipy.fft import rfft, irfft, fft, ifft
import time


def compute_conv(a):
    """Full linear convolution a*a via FFT. Returns array of length 2n-1."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))


def project_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    idx = np.arange(1, n + 1)
    cond = u * idx > (cssv - 1.0)
    rho = np.where(cond)[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def build_conv_matrix(a):
    """Build matrix A (2n-1 x n) such that A @ g = conv(a, g)."""
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        r = min(n, 2 * n - 1 - j)
        A[j:j + r, j] = a[:r]
    return A


def solve_lp_minpeak(a, active_indices=None):

def solve_lp_minpeak_full(a):
    """Solve LP: min M s.t. conv(a,g) <= M, sum(g)=1, g>=0. Returns (g, M)."""
    n = len(a)
    a_norm = a / np.sum(a)

def golden_section_line_search(a, g, n_evals=8):
    """
    Find optimal t in [0,1] that minimizes compute_obj((1-t)*a + t*g).
    Uses golden section search.
    """
    phi = (np.sqrt(5) - 1) / 2  # golden ratio conjugate ~0.618

    lo = 0.0
    hi = 1.0

    for _ in range(n_evals):
        t1 = hi - phi * (hi - lo)
        t2 = lo + phi * (hi - lo)

        a1 = (1 - t1) * a + t1 * g
        a1 = np.maximum(a1, 0)
        s1 = float(np.sum(a1))
        if s1 > 1e-10:
            a1 = a1 / s1
            f1 = compute_obj(a1)
        else:
            f1 = np.inf

        a2 = (1 - t2) * a + t2 * g
        a2 = np.maximum(a2, 0)
        s2 = float(np.sum(a2))
        if s2 > 1e-10:
            a2 = a2 / s2
            f2 = compute_obj(a2)
        else:
            f2 = np.inf

        if f1 < f2:
            hi = t2
        else:
            lo = t1

    t_best = (lo + hi) / 2
    a_best = (1 - t_best) * a + t_best * g
    a_best = np.maximum(a_best, 0)
    s_best = float(np.sum(a_best))
    if s_best > 1e-10:
        a_best = a_best / s_best
    return a_best

def smoothed_gradient_fft(a, tau):
    """
    Compute gradient of log-sum-exp smoothed max of Q_k(a) using FFT cross-correlation.
    """
    n = len(a)
    conv = compute_conv(a)
    max_conv = float(np.max(conv))
    exp_vals = np.exp(tau * (conv - max_conv))
    p = exp_vals / float(np.sum(exp_vals))

    N = 1
    while N < 3 * n:
        N <<= 1
    P = fft(p, N)
    A = fft(a, N)
    g_full = ifft(P * np.conj(A)).real
    g = 2.0 * g_full[:n]
    return g, conv

def peak_targeted_cd(a, time_budget=60.0, verbose=False):
    """
    Coordinate descent targeting the top peaks.
    For the dominant peak, find the best (source, target) pair to move mass.
    """
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:

    stall = 0

    while time.monotonic() - start < time_budget:
        conv = compute_conv(a)
        max_k = int(np.argmax(conv))

        # Find the dominant contributing pair
        i_start = max(0, max_k - (n - 1))
        i_end = min(n - 1, max_k)

        if i_start > i_end:
            break

        # Compute contributions
        contribs = []
        for i in range(i_start, i_end + 1):
            j = max_k - i
            if 0 <= j < n:
                contribs.append((a[i] * a[j], i, j))

        if not contribs:
            break

        # Sort by contribution
        contribs.sort(reverse=True)

        improved = False
        # Try moving mass from top contributors to random targets
        for contrib_val, src, dst in contribs[:3]:
            if src == dst:
                continue

            # Try several deltas
            for delta_frac in [0.05, 0.02, 0.01, 0.005]:
                delta = delta_frac * max(a[src], 1e-10)
                if delta > a[src]:
                    continue

                # Try several targets
                targets = [src - max(1, n // 20), src + max(1, n // 20),
                           rng.integers(0, n), rng.integers(0, n), n - 1 - src]

                for tgt in targets:
                    tgt = int(tgt) % n
                    if tgt == src:
                        continue
                    a_try = a.copy()
                    a_try[src] -= delta
                    a_try[tgt] += delta
                    if a_try[src] < 0:
                        continue
                    s_try = float(np.sum(a_try))
                    if s_try < 1e-10:
                        continue
                    a_try = a_try / s_try
                    obj_try = compute_obj(a_try)
                    if obj_try < best_obj - 1e-14:

                        improved = True
                        break
                if improved:
                    break
            if improved:

        if improved:

        else:
            stall += 1

        if verbose and it % 20 == 0:

def resample_sequence(a, new_n):
    """Resample sequence to new length via linear interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, a[0])
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)


def diverse_init(n, rng, mode=0):

        centers = [n // 4, 3 * n // 4]

    elif mode == 3:

    else:
        x = np.linspace(0, np.pi, n)

    if p1_budget > 30:
        a_ts = two_stage_lp_polish(best_seq, time_budget=p1_budget, verbose=True)
        obj_ts = compute_obj(a_ts)
        if obj_ts < best_score:
            best_score = obj_ts
            best_seq = a_ts.copy()
            print(f"  2SLP: obj={best_score:.8f} **")
        else:
            print(f"  2SLP: obj={obj_ts:.8f}")

    # === Phase 2: Accelerated LP ===
    print(f"\n=== Phase 2: Accelerated LP ===")
    remaining = deadline - time.monotonic()
    p2_budget = min(remaining * 0.25, 250.0)
    if p2_budget > 30:
        a_alp = accelerated_lp(best_seq, time_budget=p2_budget, momentum=0.5, verbose=True)
        obj_alp = compute_obj(a_alp)
        if obj_alp < best_score:
            best_score = obj_alp
            best_seq = a_alp.copy()
            print(f"  ALP: obj={best_score:.8f} **")
        else:
            print(f"  ALP: obj={obj_alp:.8f}")

    # === Phase 3: High-tau Smoothed GD ===
    print(f"\n=== Phase 3: High-tau GD ===")
    remaining = deadline - time.monotonic()
    p3_budget = min(remaining * 0.2, 180.0)
    if p3_budget > 30:
        a_sgd = nesterov_smoothed_descent(best_seq, time_budget=p3_budget,
                                          tau_init=50.0, tau_end=800.0, verbose=True)
        obj_sgd = compute_obj(a_sgd)
        if obj_sgd < best_score:
            best_score = obj_sgd
            best_seq = a_sgd.copy()
            print(f"  GD: obj={best_score:.8f} **")
        else:
            print(f"  GD: obj={obj_sgd:.8f}")

    # === Phase 4: Peak-targeted coordinate descent ===
    print(f"\n=== Phase 4: Peak-Targeted CD ===")
    remaining = deadline - time.monotonic()
    p4_budget = min(remaining * 0.1, 100.0)
    if p4_budget > 15:
        a_cd = peak_targeted_cd(best_seq, time_budget=p4_budget, verbose=True)
        obj_cd = compute_obj(a_cd)
        if obj_cd < best_score:
            best_score = obj_cd
            best_seq = a_cd.copy()
            print(f"  PCD: obj={best_score:.8f} **")
        else:
            print(f"  PCD: obj={obj_cd:.8f}")

    # === Phase 5: Multi-n exploration ===
    print(f"\n=== Phase 5: Multi-n ===")
    remaining = deadline - time.monotonic()
    n_current = len(best_seq)

    n_options = sorted(set([
        max(200, n_current - 150), n_current + 100, n_current + 200,
        600, 1000, 1200, 1500
    ]))
    n_options = [n for n in n_options if 200 <= n <= 1500 and abs(n - n_current) > 50]

    for n_try in n_options[:4]:
        remaining = deadline - time.monotonic()
        if remaining < 60:
            break

        a_try = resample_sequence(best_seq, n_try)

        # Quick two-stage LP
        alloc = min(remaining * 0.2, 60.0)
        if alloc > 15:
            a_try = two_stage_lp_polish(a_try, time_budget=alloc)

        obj_try = compute_obj(a_try)
        if obj_try < best_score:
            best_score = obj_try
            best_seq = a_try.copy()
            n_current = n_try
            print(f"  ** n={n_try}: obj={best_score:.8f} **")
        else:
            print(f"  n={n_try}: obj={obj_try:.8f}")

    # === Phase 6: Diverse restarts with LP ===
    print(f"\n=== Phase 6: Diverse Restarts ===")
    remaining = deadline - time.monotonic()
    n_best = len(best_seq)

    for r in range(3):
        remaining = deadline - time.monotonic()
        if remaining < 60:
            break

        mode = r % 7
        a_r = diverse_init(n_best, rng, mode=mode)
        # Blend with current best
        blend = 0.3
        a_r = (1 - blend) * a_r + blend * best_seq
        a_r = np.maximum(a_r, 0)
        a_r = a_r / a_r.sum()

        alloc = min(remaining * 0.2, 80.0)
        if alloc > 20:
            half = alloc / 2
            a_r = two_stage_lp_polish(a_r, time_budget=half)
            remaining = deadline - time.monotonic()
            if remaining > 15:
                a_r = accelerated_lp(a_r, time_budget=min(remaining * 0.3, 40.0), momentum=0.6)

            obj_r = compute_obj(a_r)
            if obj_r < best_score:
                best_score = obj_r
                best_seq = a_r.copy()
                print(f"  Restart {r} (mode={mode}): obj={best_score:.8f} **")
            else:
                print(f"  Restart {r} (mode={mode}): obj={obj_r:.8f}")

    # === Phase 7: Final intensive polish ===
    print(f"\n=== Phase 7: Final Polish ===")
    remaining = deadline - time.monotonic()

    # Two-stage LP
    if remaining > 30:
        alloc = min(remaining * 0.35, 100.0)
        a_ts = two_stage_lp_polish(best_seq, time_budget=alloc, verbose=True)
        obj_ts = compute_obj(a_ts)
        if obj_ts < best_score:
            best_score = obj_ts
            best_seq = a_ts.copy()
            print(f"  Final 2SLP: obj={best_score:.8f} **")

    # High-tau GD
    remaining = deadline - time.monotonic()
    if remaining > 25:
        alloc = min(remaining * 0.3, 60.0)
        a_sgd = nesterov_smoothed_descent(best_seq, time_budget=alloc,
                                          tau_init=100.0, tau_end=1500.0)
        obj_sgd = compute_obj(a_sgd)
        if obj_sgd < best_score:
            best_score = obj_sgd
            best_seq = a_sgd.copy()
            print(f"  Final GD: obj={best_score:.8f} **")

    # Peak CD
    remaining = deadline - time.monotonic()
    if remaining > 15:
        alloc = min(remaining * 0.3, 40.0)
        a_cd = peak_targeted_cd(best_seq, time_budget=alloc)
        obj_cd = compute_obj(a_cd)
        if obj_cd < best_score:
            best_score = obj_cd
            best_seq = a_cd.copy()
            print(f"  Final PCD: obj={best_score:.8f} **")

    # One more LP
    remaining = deadline - time.monotonic()
    if remaining > 15:
        alloc = min(remaining * 0.5, 40.0)
        a_alp = accelerated_lp(best_seq, time_budget=alloc, momentum=0.7)
        obj_alp = compute_obj(a_alp)
        if obj_alp < best_score:
            best_score = obj_alp
            best_seq = a_alp.copy()
            print(f"  Final ALP: obj={best_score:.8f} **")

    # Final validation
    if best_seq is None:
        best_seq = np.ones(200)
        best_score = compute_obj(best_seq)

    result = [float(max(0.0, min(1000.0, x))) for x in best_seq]
    val = evaluate_sequence(result)
    if val < np.inf:
        best_score = val
    else:
        result = [1.0] * 100
        best_score = 2.0

    elapsed = time.monotonic() - start_time
    print(f"\n=== FINAL: n={len(result)}, score={best_score:.8f}, time={elapsed:.1f}s ===")

    return result
