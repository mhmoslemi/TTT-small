```python
        grad = np.zeros(n)
        for idx in range(top_k):
            k = int(top_indices[idx])
            w = weights[idx]
            j_min = max(0, k - n + 1)
            j_max = min(n - 1, k)
            if j_max >= j_min:
                js = np.arange(j_min, j_max + 1)
                grad[js] += w * 2.0 * a[k - js]
        
        # Normalize gradient (optional)
        # grad = grad / (np.max(grad) + 1e-10)
        
        # Mirror descent update
        log_update = -eta * grad
        # Clip to avoid underflow
        log_update = np.clip(log_update, -50, 50)
        a_new = a * np.exp(log_update)
        s = float(np.sum(a_new))
        if s < 1e-12:
            break
        a_new = a_new / s
        
        obj = 2.0 * n * float(np.max(compute_conv(a_new)))
        if obj < best_obj - 1e-12:
            best_obj = obj
            best_a = a_new.copy()
        
        a = a_new
        it += 1
        
        # Adaptive eta
        if it % 50 == 49:
            eta *= 0.99
    
    return best_a, best_obj
```

Hmm, I realize the softmax weights for the multi-lag subgradient need more thought. The idea is to weight the subgradients of the top lags proportionally to how close they are to the max. Lags that are closer to the max should get more weight.

A simple approach: w_k = (conv[k] - min_val) / (max_val - min_val) for the top lags, normalized to sum to 1.

Or: w_k = conv[k] / sum(conv[top_lags]).

Let me use the latter, it's simpler and more natural.
