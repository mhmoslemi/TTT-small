For the polishing step, I'll implement:
- **Pairwise swaps**: Move mass from one position to another, checking if it reduces the max coefficient.
- **Local quadratic model**: Build a quadratic approximation of max_k (a*a)_k near the current point and minimize it.

Actually, let me think about the local quadratic model more carefully. Near a point a*, we have:
(a+da)(a+da) ≈ a*a + 2*(a*da) (first order)
where (a*da)_k = sum_i a[i]*da[k-i] + da[i]*a[k-i] (symmetric cross-convolution).

The first-order change in the max coefficient is: max_k (a*da)_k (over the active set of peaks).

So the first-order problem is: min max_{k in S} (a*da)_k s.t. sum(da) = 0, a+da >= 0.

This is again an LP! And it's the same as the LP alternating (just without the constraint sum(da)=1, replaced by sum(da)=0 and a small step).

So the LP alternating IS the first-order method. To get second-order improvement, we need to include the quadratic term (da*da)_k.

For a small step, the quadratic term is small, so the LP alternating should be quite accurate. The main issue is the step size.

For the step size: we want to find t that minimizes max_k ((1-t)*a + t*g * ((1-t)*a + t*g))_k.

This is a 1D problem in t. We can solve it by:
1. Evaluating at a few points.
2.Using the fact that each coefficient is a quadratic in t: ((1-t)a + tg)((1-t)a + tg))_k = (1-t)^2 (a*a)_k + 2t(1-t)(a*g)_k + t^2(g*g)_k.
3. The max of quadratics is convex in t (max of convex functions is convex).
4. So we can use ternary search or golden section to find the optimal t.

This is a significant improvement over the fixed set of t values! Let me implement this.

Actually, for the max of quadratics to be convex, each (a*a)_k, (a*g)_k, (g*g)_k must make the individual quadratics convex. A quadratic at(t) + bt + ct^2 is convex iff c >= 0. Here c = (g*g)_k >= 0 (since g >= 0), so yes, each is convex.

So the objective t → max_k f_k(t) where f_k(t) = (1-t)^2 (a*a)_k + 2t(1-t)(a*g)_k + t^2(g*g)_k is convex. We can minimize it with golden section search!

But we have 2n-1 = 1599 quadratics to evaluate at each t. Each evaluation is O(n) to compute the max (just take the max of the 1599 values). So each function evaluation is O(n) = O(800). Golden section with 50 iterations is O(50*n) = O(40000), which is very fast.

Wait, but we also need to handle the normalization: (1-t)*a + t*g should sum to 1 (both a and g sum to 1, so this is automatically satisfied). And we need (1-t)*a + t*g >= 0 (which is satisfied for t in [0,1] since a,g >= 0).

So the step size problem is:
min_{t in [0,1]} max_k [(1-t)^2 A_k + 2t(1-t) B_k + t^2 C_k]
where A_k = (a*a)_k, B_k = (a*g)_k, C_k = (g*g)_k.

This is a convex 1D problem! We can solve it exactly with bisection on the derivative or golden section.

Even better: the minimum of the max of quadratics occurs where the derivative is zero. The derivative at point t is:
d/dt max_k f_k(t) = max_{k: f_k(t) = max} f_k'(t)

where f_k'(t) = 2(1-t)A_k - 2B_k + 2t C_k + 2(1-t)(-B_k)... let me just compute:
f_k(t) = (1-t)^2 A_k + 2t(1-t) B_k + t^2 C_k
f_k'(t) = -2(1-t)A_k + 2(1-2t)B_k + 2t C_k
        = -2A_k + 2tA_k + 2B_k - 4tB_k + 2tC_k
        = -2A_k + 2B_k + 2t(A_k - 2B_k + C_k)
        = -2(A_k - B_k) + 2t(A_k - 2B_k + C_k)

The derivative is linear in t for each k! So f_k'(t) is linear, meaning f_k(t) is quadratic (as expected).

For the max of quadratics, the optimal t* satisfies: there exists a set S of "active" indices such that f_k(t*) = f_{k'}(t*) for all k,k' in S, and f_k'(t*) >= 0 for k in S (with the max of derivatives being 0).

This is a small LP if the active set is small! But typically the active set might be large.

For practical purposes, golden section search is simplest and efficient enough.

2. **Better time management** with early termination of non-improving LPs.

Total: 801 variables, ~2401 constraints. This is very tractable for modern LP solvers.

With MOSEK or CLARABEL, this should solve in < 1 second typically.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using LP alternating with golden-section
line search, spectral polishing, and multi-n exploration.
Key improvements: exact 1D convex line search, faster LP with warm starts,
targeted coordinate descent polishing, and systematic n sweep.
"""

import numpy as np
import time
from scipy.fft import rfft, irfft
from scipy.optimize import linprog
import cvxpy as cp

def compute_conv(a):
    """Full linear convolution a*a via FFT."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return np.maximum(irfft(fa * fa, size)[:2 * n - 1], 0)

def compute_cross_conv(a, b):
    """Cross-convolution a*b via FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    fb = rfft(b, size)
    return np.maximum(irfft(fa * fb, size)[:2 * n - 1], 0)

def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    s = float(np.sum(a))
    if s < 1e-10:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))

def build_conv_matrix(a):
    """Build matrix A (2n-1 x n) such that A @ g = conv(a, g)."""
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        r = min(n, 2 * n - 1 - j)
        A[j:j + r, j] = a[:r]
    return A

def solve_lp_minpeak(a, M_hint=None):
    """
    Solve LP: min M s.t. conv(a,g)[k] <= M, sum(g)=1, g>=0.
    Returns (g_normalized, M_opt).
    """
    n = len(a)
    a = a / float(np.sum(a))
    
    if M_hint is not None:
        # Use CVXPY with warm start hint
        g = cp.Variable(n, nonneg=True)
        M = cp.Variable()
        constraints = [build_conv_matrix(a) @ g <= M, cp.sum(g) == 1]
        prob = cp.Problem(cp.Minimize(M), constraints)
        for solver in [cp.CLARABEL, cp.MOSEK, cp.ECOS]:
            try:
                prob.solve(solver=solver, verbose=False)
                if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                    g_val = np.maximum(g.value, 0)
                    s = float(np.sum(g_val))
                    if s > 1e-10:
                        return g_val / s, float(M.value)
            except Exception:
                continue
    
    # Fallback to scipy
    A = build_conv_matrix(a)
    c = np.zeros(n + 1)
    c[-1] = 1.0
    A_ub = np.zeros((2 * n - 1, n + 1))
    A_ub[:, :n] = A
    A_ub[:, n] = -1.0
    b_ub = np.zeros(2 * n - 1)
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([1.0])
    bounds = [(0, None)] * n + [(0, None)]
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                  bounds=bounds, method='highs', options={'presolve': True})
    if res.status == 0:
        g_val = np.maximum(res.x[:n], 0)
        s = float(np.sum(g_val))
        if s > 1e-10:
            return g_val / s, float(res.x[n])
    return None, None

def golden_section_line_search(a, g, A_coeff, B_coeff, C_coeff, tol=1e-10, max_iter=80):
    """
    Minimize max_k f_k(t) over t in [0,1] where
    f_k(t) = (1-t)^2 * A_k + 2t(1-t) * B_k + t^2 * C_k.
    This is a convex 1D problem. Uses golden section search.
    """
    phi = (np.sqrt(5) - 1) / 2  # golden ratio conjugate ≈ 0.618
    
    def f(t):
        vals = (1-t)**2 * A_coeff + 2*t*(1-t) * B_coeff + t**2 * C_coeff
        return float(np.max(vals))
    
    a_low, a_high = 0.0, 1.0
    c = a_high - phi * (a_high - a_low)
    d = a_low + phi * (a_high - a_low)
    fc = f(c)
    fd = f(d)
    
    for _ in range(max_iter):
        if a_high - a_low < tol:
            break
        if fc < fd:
            a_high = d
            d = c
            fd = fc
            c = a_high - phi * (a_high - a_low)
            fc = f(c)
        else:
            a_low = c
            c = d
            fc = fd
            d = a_low + phi * (a_high - a_low)
            fd = f(d)
    
    t_opt = (a_low + a_high) / 2
    return t_opt

def lp_alternating(a, time_budget=200.0, verbose=False):
    """LP alternating with golden-section line search."""
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    stall = 0
    rng = np.random.default_rng(12345)
    it = 0
    best_t = 0.3
    
    while time.monotonic() - start < time_budget:
        remaining = time_budget - (time.monotonic() - start)
        if remaining < 5.0:
            break
        
        # Solve LP
        t_lp_start = time.monotonic()
        g_lp, M_lp = solve_lp_minpeak(a)
        if g_lp is None:
            break
        
        # Compute coefficients for line search
        A_coeff = compute_conv(a)
        B_coeff = compute_cross_conv(a, g_lp)
        C_coeff = compute_conv(g_lp)
        
        # Golden section line search
        t_opt = golden_section_line_search(a, g_lp, A_coeff, B_coeff, C_coeff)
        
        # Evaluate at optimal t and a few nearby points
        candidates = [t_opt, min(1.0, t_opt + 0.05), max(0.0, t_opt - 0.05), best_t]
        best_t_obj = np.inf
        best_t_val = t_opt
        best_a_local = best_a.copy()
        
        for t in candidates:
            t = max(0.0, min(1.0, t))
            a_try = (1.0 - t) * a + t * g_lp
            a_try = np.maximum(a_try, 0)
            s_try = float(np.sum(a_try))
            if s_try < 1e-10:
                continue
            a_try = a_try / s_try
            obj_try = compute_obj(a_try)
            if obj_try < best_t_obj:
                best_t_obj = obj_try
                best_t_val = t
                best_a_local = a_try.copy()
        
        it += 1
        elapsed = time.monotonic() - start
        
        if best_t_obj < best_obj - 1e-10:
            best_obj = best_t_obj
            best_a = best_a_local.copy()
            a = best_a
            best_t = best_t_val
            stall = 0
            if verbose and it % 10 == 0:
                print(f"    LP it{it}: obj={best_obj:.8f}, t={best_t_val:.4f}, M={M_lp:.6f}, el={elapsed:.1f}s")
        else:
            stall += 1
            if stall > 20:
                # Escape: perturb and restart
                noise = 0.05 * min(stall // 20, 3)
                a = best_a * np.exp(rng.normal(0, noise, n))
                a = np.maximum(a, 0)
                s = float(np.sum(a))
                if s > 1e-10:
                    a = a / s
                best_a = a.copy()
                best_obj = compute_obj(a)
                stall = 0
                best_t = 0.3
                if verbose:
                    print(f"    LP it{it}: ESCAPE noise={noise:.3f}, obj={best_obj:.8f}")
    
    return best_a

def coordinate_polish(a, time_budget=60.0):
    """
    Coordinate descent polishing: try moving mass from peak-contributing
    positions to non-contributing positions.
    """
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    it = 0
    while time.monotonic() - start < time_budget:
        conv = compute_conv(a)
        k_star = int(np.argmax(conv))
        peak_val = conv[k_star]
        
        # Find all positions that contribute to the peak
        # Position i contributes a[i]*a[k_star-i] to conv[k_star]
        contrib_idx = []
        for i in range(n):
            j = k_star - i
            if 0 <= j < n:
                contrib_idx.append((a[i] * a[j], i, j))
        contrib_idx.sort(reverse=True)
        
        # Find positions NOT contributing to this peak
        non_contrib = [i for i in range(n) if not (0 <= k_star - i < n)]
        
        if not non_contrib:
            break
        
        improved = False
        for val, i, j in contrib_idx[:20]:
            if val < 1e-14:
                break
            for target in non_contrib[:5]:
                for frac in [0.02, 0.05, 0.1, 0.2]:
                    src = i if a[i] >= a[j] else j
                    delta = frac * a[src]
                    if delta < 1e-15 or delta >= a[src]:
                        continue
                    a[src] -= delta
                    a[target] += delta
                    new_conv = compute_conv(a)
                    new_obj = 2.0 * n * float(np.max(new_conv))
                    if new_obj < best_obj - 1e-12:

                        improved = True
                        break
                    else:
                        a[src] += delta
                        a[target] -= delta
                        break
        
        if not improved:
            # Try a different peak
            top_peaks = np.argsort(conv)[::-1][:5]
            found = False
            for k_try in top_peaks[1:]:
                k_try = int(k_try)
                non_contrib2 = [i for i in range(n) if not (0 <= k_try - i < n)]
                if not non_contrib2:
                    continue
                contrib2 = []
                for i in range(n):
                    j = k_try - i
                    if 0 <= j < n:
                        contrib2.append((a[i] * a[j], i, j))
                contrib2.sort(reverse=True)
                for val, i, j in contrib2[:10]:
                    if val < 1e-14:
                        break
                    for target in non_contrib2[:5]:
                        for frac in [0.05, 0.1]:
                            src = i if a[i] >= a[j] else j
                            delta = frac * a[src]
                            if delta < 1e-15:
                                continue
                            a[src] -= delta
                            a[target] += delta
                            new_conv = compute_conv(a)
                            new_obj = 2.0 * n * float(np.max(new_conv))
                            if new_obj < best_obj - 1e-12:
                                best_obj = new_obj
                                best_a = a.copy()
                                improved = True
                                found = True
                                break
                            else:
                                a[src] += delta
                                a[target] -= delta
                                break
                    if found:
                        break
                if found:
                    break
        
        if not improved:
            # Try random perturbations
            rng = np.random.default_rng(it * 31 + n)
            for _ in range(5):
                i = rng.integers(n)
                j = rng.integers(n)
                if i == j:
                    continue
                delta = 0.01 * a[i]

def resample_sequence(a, new_n):
    """Resample sequence to new length via linear interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 0:
        return np.ones(new_n) / new_n
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    a_new = np.maximum(a_new, 0)
    s = a_new.sum()
    if s > 1e-10:
        a_new /= s
    return a_new

def diverse_init(n, rng, mode=0):
    """Generate diverse initializations."""
    if mode == 0:
        return np.ones(n) / n
    elif mode == 1:
        a = rng.uniform(0, 1, n)
        return a / a.sum()
    elif mode == 2:
        # Two peaks
        centers = [n // 4, 3 * n // 4]
        a = np.zeros(n)
        for c in centers:
            a += np.exp(-((np.arange(n) - c) ** 2) / (2 * (n // 8) ** 2))
        return a / a.sum()
    elif mode == 3:
        # Triangle
        x = np.linspace(-1, 1, n)
        a = np.maximum(1.0 - np.abs(x), 0.01)
        return a / a.sum()
    elif mode == 4:
        # Semi-circle
        x = np.linspace(-1, 1, n)
        a = 1.0 / (np.sqrt(1 - x**2 + 0.01))
        return a / a.sum()
    elif mode == 5:
        # Frequency-modulated
        x = np.linspace(0, 1, n)
        a = 1.0 + 0.3 * np.sin(2 * np.pi * 3 * x + rng.uniform(0, 2*np.pi))
        a = np
