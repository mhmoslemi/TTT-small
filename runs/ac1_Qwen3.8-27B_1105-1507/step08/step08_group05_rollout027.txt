Instead of `g = LP(a)` (min peak of conv(a,g)), what if we solve:
`minimize max_k conv((1-t)*a + t*g, (1-t)*a + t*g)` over both g and t?

This is non-convex in general, but for fixed t, it's:
`minimize max_k [(1-t)^2 conv(a,a)[k] + t(1-t)(conv(a,g)[k] + conv(g,a)[k]) + t^2 conv(g,g)[k]]`
`= max_k [(1-t)^2 C[k] + 2t(1-t) D[k] + t^2 E[k]]`
where C = conv(a,a), D = conv(a,g), E = conv(g,g).

For fixed t, minimizing over g: the term `(1-t)^2 C[k] + 2t(1-t) D[k]` is linear in g (since D[k] = sum_{i+j=k} a[i]*g[j] is linear in g), and `t^2 E[k]` is quadratic. So it's not a simple LP.

The previous approach (fix a, optimize g to minimize max conv(a,g)) is a linearization that works well in practice. Let me stick with it but make it more efficient.

Wait, this O(n^2) loop might be slow for n=2000 (4M operations per gradient call, and L-BFGS might call it 100+ times). Let me use FFT instead.

The computation `grad[m] = 2/beta * sum_j a[j] * p[m+j]` for m=0..n-1 is a cross-correlation. I can compute it as:

Let `a_ext = [a[0], ..., a[n-1], 0, ..., 0]` (length 2n-1, zeros after n)
Let `p_ext = [0, ..., 0, p[0], p[1], ..., p[2n-2], 0, ..., 0]` (padded)

The cross-correlation `R[m] = sum_j a[j] * p[m+j]` can be computed as:
`R = ifft(conj(fft(a_ext, N)) * fft(p_ext, N))` for appropriate N.

Wait, let me be more careful. The cross-correlation of x and y is:
`(x ⋆ y)[τ] = sum_n x[n+τ] * conj(y[n])`

What I want is `R[m] = sum_j a[j] * p[m+j]`. Let me substitute `i = m+j`:
`R[m] = sum_i a[i-m] * p[i]` (with the constraint that 0 <= i-m < n and 0 <= i < 2n-1)

This is `R[m] = sum_i a[i-m] * p[i]` which is the cross-correlation of a and p at lag m (with a being the shorter sequence).

In terms of convolution: `R[m] = (a_flipped * p)[2n-2-m]` where `a_flipped = a[::-1]` and `*` is full convolution. Because:
`(a_flipped * p)[k] = sum_j a_flipped[j] * p[k-j] = sum_j a[n-1-j] * p[k-j]`
Let `i = n-1-j`: `= sum_i a[i] * p[k-n+1+i]`
So `(a_flipped * p)[k] = sum_i a[i] * p[i + k - n + 1]`

We want `R[m] = sum_j a[j] * p[j+m]`, so set `k - n + 1 = m`, i.e., `k = m + n - 1`.
`R[m] = (a_flipped * p)[m + n - 1]`

So I can compute the full convolution of `a[::-1]` and `p` using FFT, and pick out the right indices.

```python
def compute_smooth_grad_fft(a, beta):
    n = len(a)
    conv = compute_conv(a)
    cmax = np.max(conv)
    exp_vals = np.exp(beta * (conv - cmax))
    s = np.sum(exp_vals)
    logsumexp = np.log(s) / beta + cmax
    p = exp_vals / s
    # R[m] = (a[::-1] * p)[m + n - 1] for m = 0, ..., n-1
    a_flip = a[::-1]
    # Full convolution has length n + (2n-1) - 1 = 3n - 2
    size = 1
    while size < 3*n - 1:
        size <<= 1
    Af = rfft(a_flip, size)
    Pf = rfft(p, size)
    conv_full = irfft(Af * Pf, size)[:3*n-2]
    # R[m] = conv_full[m + n - 1] for m = 0..n-1
    R = conv_full[n-1:2*n-1]  # indices n-1, n, ..., 2n-2
    grad = 2.0 / beta * R
    return logsumexp, grad
```

This should be O(n log n) per evaluation. 

Now, for the optimization, I'll use the log-sum-exp parameterization:
`a[i] = exp(x[i]) / sum_j exp(x[j])`

The gradient of the objective w.r.t. x is:
`d f / dx[i] = sum_m (d f / da[m]) * da[m]/dx[i]`
`= sum_m g[m] * a[m] * (δ_mi - a[i])`
`= a[i] * (g[i] - sum_m g[m]*a[m])`
`= a[i] * (g[i] - g·a)`

where `g = df/da`.

So the gradient w.r.t. x is simply `a * (g - dot(g, a))`.

This is very clean! Let me use this.

For the optimizer, I'll use L-BFGS-B with this gradient. Since x is unbounded, L-BFGS-B works perfectly (no bounds needed, but I can add bounds for numerical stability).

Optimizes non-negative step function to minimize 2n*max(conv(a,a))/(sum(a))^2.
Uses logsumexp-smoothed objective with exact gradient (via FFT-based cross-correlation),
log-sum-exp parameterization for the simplex constraint, L-BFGS-B optimization,
and LP alternating for final precision.
"""

import numpy as np
from scipy.fft import rfft, irfft
from scipy.optimize import minimize, minimize_scalar
import time
import cvxpy as cp


def compute_conv(a):
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    n = len(a)
    s = float(np.sum(a))
    if s < 1e-10:
        return np.inf
    a_n = a / s
    conv = compute_conv(a_n)
    return 2.0 * n * float(np.max(conv))


def smooth_obj_and_grad_x(x, beta):
    """
    Objective and gradient w.r.t. log-sum-exp parameter x.
    a = softmax(x), objective = logsumexp(beta * conv(a,a)) / beta.
    """
    n = len(x)
    # Compute a = softmax(x)
    x_max = np.max(x)
    exp_x = np.exp(x - x_max)
    a = exp_x / np.sum(exp_x)
    
    # Compute conv
    conv = compute_conv(a)
    cmax = np.max(conv)
    exp_conv = np.exp(beta * (conv - cmax))
    s_exp = np.sum(exp_conv)
    obj = np.log(s_exp) / beta + cmax
    p = exp_conv / s_exp  # normalized weights (length 2n-1)
    
    # Gradient of obj w.r.t. a: g[m] = 2/beta * sum_j a[j] * p[m+j]
    # Compute R[m] = sum_j a[j] * p[m+j] via FFT cross-correlation
    a_flip = a[::-1]  # length n
    size = 1
    while size < 3 * n - 1:
        size <<= 1
    Af = rfft(a_flip, size)
    Pf = rfft(p, size)
    conv_full = irfft(Af * Pf, size)[:3 * n - 2]
    R = conv_full[n - 1:2 * n - 1]  # R[m] for m=0..n-1
    g = 2.0 / beta * R  # gradient w.r.t. a
    
    # Gradient w.r.t. x: dx[i] = a[i] * (g[i] - dot(g, a))
    ga = np.dot(g, a)
    grad_x = a * (g - ga)
    
    return obj, grad_x


def lp_alternate(a0, time_budget=60.0, verbose=False):
    """LP alternating: fix a, solve LP for g, mix, repeat."""
    n = len(a0)
    a = a0.astype(np.float64).copy()
    s = float(np.sum(a))
    if s < 1e-10:
        return a0.copy()
    a = a / s
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    stall_count = 0
    
    while time.monotonic() - start < time_budget:
        # Solve LP: min M s.t. conv(a, g)[k] <= M, sum(g) = 1, g >= 0
        a_n = a / float(np.sum(a))
        A = np.zeros((2 * n - 1, n))
        for j in range(n):
            r = min(n, 2 * n - 1 - j)
            A[j:j + r, j] = a_n[:r]
        
        g_var = cp.Variable(n, nonneg=True)
        M_var = cp.Variable()
        constraints = [A @ g_var <= M_var, cp.sum(g_var) == 1]
        prob = cp.Problem(cp.Minimize(M_var), constraints)
        
        g_val = None
        for solver in [cp.CLARABEL, cp.PDLP, cp.SCS]:
            try:
                prob.solve(solver=solver)
                if g_var.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                    g_val = np.maximum(g_var.value, 0)
                    gs = float(np.sum(g_val))
                    if gs > 1e-10:
                        g_val = g_val / gs
                    break
            except Exception:
                continue
        
        if g_val is None:
            break
        
        # Line search for best mixing parameter
        def line_obj(t):
            a_try = (1.0 - t) * a + t * g_val
            a_try = np.maximum(a_try, 0)
            st = float(np.sum(a_try))
            if st < 1e-10:
                return np.inf
            a_try = a_try / st
            return compute_obj(a_try)
        
        try:

        else:

                break

def resample_seq(a, new_n):
    n = len(a)
    if n == new_n:
        return a.copy()
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    return np.maximum(np.interp(x_new, x_old, a), 0)

"""
Optimizes non-negative step function to minimize 2n*max(conv(a,a))/(sum(a))^2.
Uses logsumexp-smoothed objective with exact FFT-based gradient, log-sum-exp
parameterization for the simplex, multi-stage beta annealing with L-BFGS-B,
and LP alternating for final precision improvement.
"""

import numpy as np
from scipy.fft import rfft, irfft
from scipy.optimize import minimize, minimize_scalar
import time
import cvxpy as cp


def compute_conv(a):
    """Full linear convolution of a with itself using FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 1e-10:
        return np.inf
    a_n = a / s
    conv = compute_conv(a_n)
    return 2.0 * n * float(np.max(conv))


def smooth_obj_and_grad_x(x, beta):
    """
    Smooth objective (logsumexp of beta*conv) and gradient w.r.t. log-param x.
    a = softmax(x). Returns (objective, gradient).
    """
    n = len(x)
    x_max = np.max(x)
    exp_x = np.exp(x - x_max)
    a = exp_x / np.sum(exp_x)

    conv = compute_conv(a)
    cmax = np.max(conv)
    shifted = beta * (conv - cmax)
    shifted_max = np.max(shifted)
    exp_shifted = np.exp(shifted - shifted_max)
    s_exp = np.sum(exp_shifted)
    obj = (np.log(s_exp) + shifted_max) / beta + cmax
    p = exp_shifted / s_exp

    # Gradient w.r.t. a: g[m] = 2/beta * sum_j a[j] * p[m+j]
    # Use FFT cross-correlation: R[m] = (a[::-1] * p)[m + n - 1]
    a_flip = a[::-1]
    size = 1
    while size < 3 * n - 1:
        size <<= 1
    Af = rfft(a_flip, size)
    Pf = rfft(p, size)
    conv_full = irfft(Af * Pf, size)[:3 * n - 2]
    R = conv_full[n - 1:2 * n - 1]
    g = 2.0 / beta * R

    # Gradient w.r.t. x: a * (g - dot(g,a))
    ga = np.dot(g, a)
    grad_x = a * (g - ga)

    return obj, grad_x


def build_conv_matrix(a):
    """Build (2n-1) x n matrix where A @ g = conv(a, g)."""
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        r = min(n, 2 * n - 1 - j)
        A[j:j + r, j] = a[:r]
    return A


def lp_solve_minpeak(a):
    """LP: min M s.t. conv(a,g) <= M, sum(g)=1, g>=0. Returns g or None."""
    n = len(a)
    a_n = a / float(np.sum(a))
    A = build_conv_matrix(a_n)
    g_var = cp.Variable(n, nonneg=True)
    M_var = cp.Variable()
    constraints = [A @ g_var <= M_var, cp.sum(g_var) == 1]
    prob = cp.Problem(cp.Minimize(M_var), constraints)
    for solver in [cp.CLARABEL, cp.PDLP, cp.SCS, cp.ECOS]:
        try:
            prob.solve(solver=solver)
            if g_var.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                gv = np.maximum(g_var.value, 0)
                gs = float(np.sum(gv))
                if gs > 1e-10:
                    return gv / gs
        except Exception:
            continue
    return None


def lp_alternate(a0, time_budget=60.0, verbose=False):
    """LP alternating with line search."""
    n = len(a0)
    a = a0.astype(np.float64).copy()
    s = float(np.sum(a))
    if s < 1e-10:
        return a0.copy()
    a = a / s
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    stall = 0

    while time.monotonic() - start < time_budget:
        g_lp = lp_solve_minpeak(a)
        if g_lp is None:
            break

        def line_obj(t):
            a_try = (1.0 - t) * a + t * g_lp
            a_try = np.maximum(a_try, 0)
            st = float(np.sum(a_try))
            if st < 1e-10:
                return np.inf
            return compute_obj(a_try / st)

        try:
            res = minimize_scalar(line_obj, bounds=(0.0, 1.0), method='bounded',
                                  options={'maxiter': 50, 'xatol': 0.003})
            best_t = res.x
        except Exception:
            best_t = 0.5

        a_try = (1.0 - best_t) * a + best_t * g_lp
        a_try = np.maximum(a_try, 0)
        st = float(np.sum(a_try))
        if st < 1e-10:
            break
        a_try = a_try / st
        obj_try = compute_obj(a_try)

        if obj_try < best_obj - 1e-14:
            best_obj = obj_try
            best_a = a_try.copy()
            a = best_a
            stall = 0
            if verbose:
                print(f"    LP: obj={best_obj:.10f}, t={best_t:.4f}, elapsed={time.monotonic()-start:.1f}s")
        else:
            stall += 1
            if stall > 12:
                break

    return best_a


def resample_seq(a, new_n):
    """Linear interpolation resampling."""
    n = len(a)
    if n == new_n:
        return a.copy()
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    return np.maximum(np.interp(x_new, x_old, a), 0)


def to_log_param(a):
    """Convert simplex vector to log-sum-exp parameter."""
    a = np.maximum(a, 1e-30)
    return np.log(a) - np.log(np.sum(a))


def from_log_param(x):
    """Convert log-sum-exp parameter to simplex vector."""
    x_max = np.max(x)
    exp_x = np.exp(x - x_max)
    return exp_x / np.sum(exp_x)


def smooth_optimize(x0, beta_start, beta_end, time_budget, verbose=False):
    """Multi-stage beta annealing with L-BFGS-B."""
    start = time.monotonic()
    best_obj = np.inf
    best_x = x0.copy()

    n_betas = max(3, int(time_budget / 30))
    betas = np.geomspace(beta_start, beta_end, n_betas)

    for bi, beta in enumerate(betas):
        remaining = time_budget - (time.monotonic() - start)
        if remaining < 5:
            break

        result = minimize(
            smooth_obj_and_grad_x,
            best_x,
            args=(beta,),
            method='L-BFGS-B',
            jac=True,
            options={'maxiter': 300, 'ftol': 1e-16, 'gtol': 1e-12,
                     'maxfun': 2000, 'maxls': 50}
        )

        x_cur = result.x
        a_cur = from_log_param(x_cur)
        true_obj = compute_obj(a_cur)
        if true_obj < best_obj:
            best_obj = true_obj
            best_x = x_cur.copy()
            if verbose:
                print(f"    beta={beta:.1f}: obj={best_obj:.10f}, elapsed={time.monotonic()-start:.1f}s")

    return best_x, best_obj


def nesterov_subgrad(a0, time_budget=60.0, top_k=5, verbose=False):
    """Nesterov-accelerated subgradient for the max-conv objective."""
    n = len(a0)
    a = a0.astype(np.float64).copy()
    s = float(np.sum(a))
    if s < 1e-10:
        return a0.copy()
    a = a / s
    y = a.copy()
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    step_size = 0.1
    patience = 0

    for it in range(300000):
        if time.monotonic() - start > time_budget:
            break
        conv_y = compute_conv(y)
        top_idx = np.argsort(conv_y)[::-1][:top_k]
        grad = np.zeros(n)
        for k in top_idx:
            k = int(k)
            i_start = max(0, k - n + 1)
            i_end = min(n - 1, k)
            if i_start <= i_end:
                m_start = k - i_end
                m_end = k - i_start
                grad[m_start:m_end + 1] += 2.0 * y[i_start:i_end + 1][::-1]
        grad /= len(top_idx)
        grad = grad - np.mean(grad)

        y_new = y - step_size * grad
        # Project to simplex
        n_ = n
        u = np.sort(y_new)[::-1]
        cssv = np.cumsum(u) - 1.0
        ind = np.arange(1, n_ + 1)
        cond = u - cssv / ind > 0
        if np.any(cond):
            i = np.max(ind[cond])
            theta = cssv[i - 1] / i
            a_new = np.maximum(y_new - theta, 0)
        else:
            a_new = np.ones(n_) / n_
        s_new = np.sum(a_new)
        if s_new < 1e-10:
            a_new = np.ones(n_) / n_
        else:
            a_new = a_new / s_new

        t_k = 2.0 / (it + 2.0)
        y = a_new + (1.0 - t_k) * (a_new - a)
        # Re-project y
        u2 = np.sort(y)[::-1]
        cssv2 = np.cumsum(u2) - 1.0
        cond2 = u2 - cssv2 / ind > 0
        if np.any(cond2):
            i2 = np.max(ind[cond2])
            theta2 = cssv2[i2 - 1] / i2
            y = np.maximum(y - theta2, 0)
            y = y / np.sum(y)
        else:
            y = np.ones(n_) / n_
        a = a_new

        if it % 20 == 0:
            obj = compute_obj(a)
            if obj < best_obj:
                best_obj = obj
                best_a = a.copy()
                patience = 0
            else:
                patience += 1
            if patience > 150:
                step_size = max(step_size * 0.5, 0.003)
                patience = 0
        if it % 1000 == 999:
            step_size = max(step_size * 0.95, 0.005)
        if verbose and it % 5000 == 0:
            print(f"      Nest it={it}: best={best_obj:.10f}, elapsed={time.monotonic()-start:.1f}s")

    return best_a
