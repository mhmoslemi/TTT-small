Let me now think about the convergence rate of mirror descent.

For a smooth convex function with L-Lipschitz gradient, mirror descent with step size eta = 1/(L*k) converges in O(L*D^2/k) where D is the diameter of the domain.

But our function isn't convex (as discussed), so convergence guarantees don't apply. However, in practice, soft-max smoothing makes it approximately smooth and convex locally, so mirror descent should work well.

The key parameter is the temperature τ. As τ → 0, the soft max approaches the hard max, and the function becomes less smooth (L grows like 1/τ). So we need to decrease τ gradually.

A good schedule: τ = τ_0 * exp(-α * t) where t is the iteration count, and α is chosen so that τ reaches a small value by the end of the optimization.
