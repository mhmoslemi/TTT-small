Fix all coordinates except `a[j]`. Let `S = sum(a)`, and we're changing `a[j]` from `v` to `t`.

After the change, `sum(a') = S - v + t`. The objective is:
`2n * max_k conv_k(a') / (S - v + t)^2`

For each k, `conv_k(a')` as a function of t:
- If neither `i=j` nor `i=k-j` is in the valid range for position k: `conv_k(a') = conv_k(a)` (constant)
- If exactly one of them is valid: `conv_k(a') = conv_k(a) - v*a[k-j] + t*a[k-j]` = `conv_k(a) + (t-v)*a[k-j]` (linear)
- If both are valid and `j != k-j` (i.e., `k != 2j`): `conv_k(a') = conv_k(a) - 2*v*a[k-j] + 2*t*a[k-j]` = `conv_k(a) + 2*(t-v)*a[k-j]` (linear)
- If `k = 2j` (and valid): `conv_k(a') = conv_k(a) - v^2 + t^2` (quadratic)

So the objective as a function of t is:
`f(t) = 2n * max_k g_k(t) / (S - v + t)^2`

where each `g_k(t)` is either constant, linear, or quadratic in t.

To find `min_{t>=0} f(t)`, we can:
1. Identify the set of "active" k's (those with large `g_k(t)` near the current t=v)
2. On the active set, `f(t)` is the max of O(|K|) functions divided by a quadratic
3. Use a 1D optimization (bisection on the derivative, or ternary search)

For the 1D optimization, since each `g_k(t)/(S-v+t)^2` is either:
- Constant / quadratic: monotonically decreasing or has a single critical point
- Linear / quadratic: has at most one critical point (can find analytically)
- Quadratic / quadratic: has at most two critical points

The max of such functions is unimodal under mild conditions. Let's use a safe numerical approach: golden section search on a bounded interval.

What's a good upper bound for t? If t is very large, `f(t) ≈ 2n * t^2 / t^2 = 2n` (from the k=2j term) or `2n * (m*t) / t^2 = 2n*m/t -> 0` (from linear terms). So for large t, the k=2j term dominates and f(t) → 2n. Since our current objective is ~1.5, we'd never want t that makes f(t) > 2n. So t < some reasonable bound.

Actually, a simpler approach: just use scipy's minimize_scalar on the 1D function.

Let me now write the full code:

```python
"""
Optimizer for minimizing 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Log-sum-exp smoothed gradient descent with adaptive beta
2. LP alternating with adaptive blending
3. Coordinate descent polish
4. Multi-n exploration
"""

import numpy as np
from scipy.fft import rfft, irfft
from scipy.optimize import minimize_scalar, linprog
import cvxpy as cp
import time


def compute_conv(a):
    """FFT-based full linear convolution of a with itself."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute 2n*max(conv(a,a))/sum(a)^2."""
    n = len(a)
    s = float(np.sum(a))
    if s < 1e-10:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))


def smoothed_conv_and_grad(a, beta):
    """Compute smoothed objective value and gradient using log-sum-exp.
    f_beta(a) = (1/beta) * log(sum_k exp(beta * conv_k(a)))
    Gradient computed as weighted sum of individual conv gradients.
    """
    n = len(a)
    S = float(np.sum(a))
    a_norm = a / S  # normalize to sum=1
    conv = compute_conv(a_norm)
    
    # Log-sum-exp for numerical stability
    max_conv = np.max(conv)
    log_sum_exp = max_conv + np.log(np.sum(np.exp(beta * (conv - max_conv))))
    f_val = log_sum_exp / beta  # This is (1/beta)*log(sum exp(beta*conv))
    # Actually we want the smoothed max: (1/beta)*log(sum exp(beta*(conv - max))) + max
    # But for the objective, we want 2n * smoothed_max
    # smoothed_max ≈ max + (1/beta)*log(sum exp(beta*(conv_k - max)))
    
    # Weights for the gradient
    w = np.exp(beta * (conv - max_conv))
    w /= np.sum(w)
    
    # Gradient of smoothed_max wrt a_norm:
    # d(smoothed_max)/da_norm[j] = sum_k w_k * d(conv_k)/da_norm[j]
    # d(conv_k)/da_norm[j] = a_norm[k-j] + a_norm[2j-k] (with bounds)
    # 
    # This is equivalent to: sum_k w_k * (a_norm[k-j] + a_norm[2j-k])
    # = (w * a_norm)[circular] evaluated at j + (w * reverse(a_norm))[circular] evaluated at j
    # Actually let's think of it as:
    # sum_k w[k] * a[k-j] (where a[k-j] is 0 if out of bounds)
    # + sum_k w[k] * a[2j-k] (where a[2j-k] is 0 if out of bounds)
    #
    # First term: cross-correlation of w and a, evaluated at lag j
    #   c1[j] = sum_k w[k] * a[k-j] = (w cross-correlate a)[j]
    #   This is the same as: if we flip w, it's a convolution
    #   c1[j] = sum_k w[k] * a[k-j]
    #   Let m = k-j, then k = m+j: c1[j] = sum_m w[m+j] * a[m]
    #   This is a cross-correlation.
    #
    # Second term: sum_k w[k] * a[2j-k]
    #   Let m = 2j-k, then k = 2j-m: sum_m w[2j-m] * a[m]
    #   This is also a cross-correlation (of w reversed and a)
    
    # Use FFT for efficiency
    n_fft = 1
    while n_fft < 4 * n:
        n_fft <<= 1
    
    A_fft = rfft(a_norm, n_fft)
    W_fft = rfft(w, n_fft)
    
    # First term: c1[j] = sum_k w[k] * a[k-j]
    # = sum_m w[m+j] * a[m] (letting m = k-j)
    # This is the cross-correlation of a and w at lag j
    # In FFT terms: IFFT(conj(A_fft) * W_fft) gives cross-correlation
    R1 = irfft(np.conj(A_fft) * W_fft, n_fft)
    # R1[j] = sum_m a[m] * w[m+j] (with circular wrapping)
    # We want sum_k w[k] * a[k-j] = sum_m a[m] * w[m+j] = R1[j] (for valid j)
    
    # Second term: c2[j] = sum_k w[k] * a[2j-k]
    # Let m = 2j-k: sum_m w[2j-m] * a[m]
    # This is the cross-correlation of a and w at lag (2j), which is tricky
    # Alternative: c2[j] = sum_k w[k] * a[2j-k]
    # Let's define w_rev[k] = w[2(n-1)-k]... no that doesn't help directly
    # 
    # Actually: c2[j] = sum_k w[k] * a[2j-k]
    # If we define w_flip[k] = w[-k] (circular flip), then:
    # c2[j] = sum_k w_flip[k] * a[2j+k]... no
    # 
    # Let me think again. c2[j] = sum_k w[k] * a[2j-k]
    # Let l = 2j - k, so k = 2j - l:
    # c2[j] = sum_l w[2j-l] * a[l]
    # This is the cross-correlation of w and a at lag 2j:
    # (w cross-correlate a)[2j] = sum_l w[l+2j] * a[l]... no
    # 
    # Standard cross-correlation: (f ⊛ g)[τ] = sum_t f[t+τ] * g[t]
    # So (w ⊛ a)[τ] = sum_t w[t+τ] * a[t]
    # c2[j] = sum_l w[2j-l] * a[l] = sum_l w[l + (2j-2l)] ... no this doesn't match
    # 
    # Let me use a different approach. c2[j] = sum_k w[k]*a[2j-k]
    # Define w2[k] = w[k] (same as w), but we want a[2j-k] which is a at index (2j-k).
    # If I define a_rev[i] = a[n-1-i], then a[2j-k] relates to a_rev in a shifted way.
    # 
    # Actually the simplest way: c2[j] = (w * a)[2j] where * denotes cross-correlation
    # (w * a)[τ] = sum_k w[k] * a[k-τ]... no
    # 
    # Let me just use the direct formula with FFT:
    # c2[j] = sum_k w[k] * a[2j-k]
    # Define b[k] = a[n-1-k] (reversed a)
    # Then a[2j-k] = b[n-1-(2j-k)] = b[n-1-2j+k]
    # c2[j] = sum_k w[k] * b[k + (n-1-2j)]
    # This is the cross-correlation of w and b at lag (n-1-2j)
    # 
    # This is getting complicated. Let me just use a simpler FFT approach:
    # 
    # Note that c2[j] = sum_k w[k] * a[2j-k] is the same as:
    # Let's define the "full cross-correlation" R[τ] = sum_k w[k] * a[k-τ]
    # Then c2[j] = R[-2j + 2j]... I'm confusing myself.
    # 
    # Let me just compute it directly for small n, or use a smarter FFT trick.
    
    # Actually, I realize there's a simpler way. Note that:
    # sum_k w[k] * a[2j-k] is the convolution of w and a evaluated at position 2j!
    # (w * a)[m] = sum_k w[k] * a[m-k]
    # So (w * a)[2j] = sum_k w[k] * a[2j-k] = c2[j] ✓
    
    # So: c1[j] = cross-correlation of a and w at lag j = (w * a_flipped)[j + n - 1]... 
    # Hmm, let me just use the convolution approach for both.
    
    # c2[j] = (w * a)[2j] where * is linear convolution
    # c1[j] = sum_k w[k] * a[k-j]
    #        Let's write this as: sum_k w[k-j+j] * a[k-j]... 
    #        = sum_m w[m+j] * a[m] (letting m = k-j)
    #        This is (w_shifted * a)[?] ... 
    #        Actually: (full cross-corr of a and w)[j] = sum_m a[m] * w[m+j] = c1[j]
    #        And this equals (a * w_flipped)[j + len(w) - 1] in convolution terms... 
    #        Or more simply: it's the same as the circular cross-correlation computed via FFT.
    
    # Let me just use the FFT cross-correlation formula:
    # IFFT(conj(FFT(a)) * FFT(w)) gives the circular cross-correlation
    # R_circ[τ] = sum_m a[m] * w[(m+τ) mod N]
    # 
    # For c1[j] = sum_m a[m] * w[m+j] (with w[m+j]=0 if m+j out of [0, 2n-2]):
    # If n_fft >= 4n, then for j in [0, n-1], m in [0, n-1], m+j is in [0, 2n-2] < n_fft
    # So no wrap-around: c1[j] = R_circ[j] = IFFT(conj(A_fft) * W_fft)[j]
    # Wait: R_circ[τ] = sum_m a[m] * w[(m+τ) mod n_fft]
    # For τ = j < n: (m+j) mod n_fft = m+j (since m < n, m+j < 2n < n_fft)
    # And w[m+j] is non-zero only for m+j < 2n-1, i.e., m < 2n-1-j
    # Since m < n always, this is fine.
    # So c1[j] = R_circ[j] where R_circ = IFFT(conj(A_fft) * W_fft)
    
    # Hmm wait, I need to double-check the FFT cross-correlation formula.
    # The circular cross-correlation is: (a ⊛ w)[τ] = sum_m a[m] * conj(w[m-τ])
    # In the real case: (a ⊛ w)[τ] = sum_m a[m] * w[m-τ]
    # FFT formula: IFFT(conj(FFT(a)) * FFT(w)) = (a ⊛ w)
    # So R[τ] = sum_m a[m] * w[m-τ]
    # 
    # c1[j] = sum_m a[m] * w[m+j] = R[-j] = R[n_fft - j] (circular)
    
    # For c2[j] = (w * a)[2j] (linear convolution):
    # The linear convolution can be computed as IFFT(FFT(w) * FFT(a))
    # conv_wa[m] = sum_k w[k] * a[m-k]
    # So c2[j] = conv_wa[2j]
    
    # Let me compute both:
    R_cross = irfft(np.conj(A_fft) * W_fft, n_fft)
    conv_wa = irfft(W_fft * A_fft, n_fft)
    
    grad = np.zeros(n)
    for j in range(n):
        # c1[j] = R_cross[n_fft - j] (which is R_cross[-j mod n_fft])
        c1 = R_cross[-j % n_fft]  # or R_cross[(n_fft - j) % n_fft]
        # c2[j] = conv_wa[2j]
        c2 = conv_wa[2 * j] if 2 * j < n_fft else 0.0
        grad[j] = c1 + c2
    
    # The gradient of f_beta = (1/beta)*log(sum exp(beta*conv)) wrt a_norm
    # is: sum_k w_k * d(conv_k)/da_norm = grad (as computed above)
    # 
    # But we need the gradient wrt a (not a_norm). Since a_norm = a/S:
    # d(f)/da = d(f)/da_norm * da_norm/da = d(f)/da_norm * (1/S)
    # (since d(a_norm)/da = I/S - a_norm * a^T / S^2, but for the gradient wrt the 
    #  unnormalized a, it's more complex)
    # 
    # Actually, let's just work with a_norm throughout (maintain sum=1).
    # The gradient of f_beta(a_norm) wrt a_norm is `grad`.
    # We need to project this onto the tangent space of the simplex:
    # grad_centered = grad - mean(grad)
    
    grad_centered = grad - np.mean(grad)
    
    return f_val, a_norm, grad_centered


def smoothed_optimize(a, time_budget=120.0, beta_start=1.0, beta_end=500.0,
                      beta_growth=1.05, verbose=False):
    """Optimize using log-sum-exp smoothed gradient with multiplicative updates."""
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64).copy()
    S = float(np.sum(a))
    if S < 1e-10:
        return a
    a = a / S
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    beta = beta_start
    lr = 1.0 / (2.0 * n)  # Initial learning rate
    momentum = np.zeros(n)
    mu = 0.5  # Momentum
    
    it = 0
    while time.monotonic() - start < time_budget:
        f_val, a_norm, grad = smoothed_conv_and_grad(a, beta)
        
        # Multiplicative (mirror) descent update:
        # a_new[j] = a[j] * exp(-lr * grad_centered[j])
        # Then normalize to sum = 1
        momentum = mu * momentum + (1 - mu) * grad
        a_new = a * np.exp(-lr * momentum)
        a_new = np.maximum(a_new, 1e-15)
        S_new = float(np.sum(a_new))
        a_new = a_new / S_new
        
        a = a_new
        it += 1
        
        if it % 100 == 0:
            obj = compute_obj(a)
            if obj < best_obj - 1e-14:
                best_obj = obj
                best_a = a.copy()
            if verbose:
                elapsed = time.monotonic() - start
                print(f"    Smoothed: it={it}, beta={beta:.1f}, obj={best_obj:.8f}, time={elapsed:.0f}s")
        
        # Grow beta
        if it % 50 == 0:
            beta *= beta_growth
            if beta > beta_end:
                beta = beta_end
            # Decay learning rate as beta grows
            lr = lr * 0.999
        
        # Occasionally try a larger step
        if it % 500 == 0:
            lr = 1.0 / (2.0 * np.sqrt(n))
    
    # Final check
    obj = compute_obj(a)
    if obj < best_obj:
        best_obj = obj
        best_a = a.copy()
    
    return best_a


def build_conv_matrix_fast(a):
    """Build the convolution matrix A such that A @ g = conv(a, g).
    Shape: (2n-1, n)"""
    n = len(a)
    # A[k, j] = a[k-j] if 0 <= k-j < n, else 0
    # For efficiency, use the Toeplitz structure
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        # For column j, A[k, j] = a[k-j] for k = j, j+1, ..., j+n-1
        k_start = j
        k_end = min(2 * n - 2, j + n - 1)
        length = k_end - k_start + 1
        A[k_start:k_end+1, j] = a[:length]
    return A


def solve_lp(a):
    """Solve LP: min M s.t. A@g <= M, sum(g)=1, g>=0.
    Returns (g, M) or (None, None)."""
    n = len(a)
    a = a / np.sum(a)
    A = build_conv_matrix_fast(a)
    
    # Try cvxpy
    g = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [A @ g <= M, cp.sum(g) == 1]
    prob = cp.Problem(cp.Minimize(M), constraints)
    
    for solver in [cp.CLARABEL, cp.SCS, cp.ECOS, cp.PDLP]:
        try:
            t0 = time.monotonic()
            prob.solve(solver=solver)
            if time.monotonic() - t0 > 30:
                continue
            if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g.value, 0)
                gs = float(np.sum(g_val))
                if gs > 1e-10:
                    return g_val / gs, float(M.value)
        except Exception:
            continue
    
    # Fallback: scipy linprog
    try:
        c = np.zeros(n + 1)
        c[-1] = 1.0
        A_ub = np.zeros((2 * n - 1, n + 1))
        A_ub[:, :n] = A
        A_ub[:, n] = -1.0
        b_ub = np.zeros(2 * n - 1)
        A_eq = np.ones((1, n + 1))
        b_eq = np.array([1.0])
        bounds = [(0, None)] * n + [(0, None)]
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs')
        if res.status == 0:
            g_val = np.maximum(res.x[:n], 0)
            gs = float(np.sum(g_val))
            if gs > 1e-10:
                return g_val / gs, float(res.x[n])
    except Exception:
        pass
    
    return None, None


def lp_alternate(a, time_budget=200.0, verbose=False):
    """LP alternating with adaptive blending."""
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64).copy()
    S = float(np.sum(a))
    if S < 1e-10:
        return a
    a = a / S
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    stall = 0
    
    while time.monotonic() - start < time_budget:
        g_lp, M_lp = solve_lp(a)
        if g_lp is None:
            break
        
        # Adaptive blending with line search
        best_local_obj = np.inf
        best_local_a = best_a.copy()
        
        # Try a range of t values, with emphasis on smaller t initially
        t_values = np.concatenate([
            np.linspace(0.01, 0.1, 10),
            np.linspace(0.1, 0.5, 10),
            np.linspace(0.5, 1.0, 6)
        ])
        
        for t in t_values:
            a_try = (1.0 - t) * a + t * g_lp
            a_try = np.maximum(a_try, 0)
            s_try = float(np.sum(a_try))
            if s_try < 1e-10:
                continue
            a_try = a_try / s_try
            obj_try = compute_obj(a_try)
            if obj_try < best_local_obj:
                best_local_obj = obj_try
                best_local_a = a_try.copy()
        
        if best_local_obj < best_obj - 1e-13:
            best_obj = best_local_obj
            best_a = best_local_a.copy()
            a = best_a.copy()
            stall = 0
            if verbose:
                elapsed = time.monotonic() - start
                print(f"    LP: obj={best_obj:.8f}, time={elapsed:.0f}s")
        else:
            stall += 1
            if stall > 5:
                # Perturbation
                rng = np.random.default_rng(int(time.monotonic() * 10000) % (2**31))
                scale = 0.1
                a = best_a * np.exp(rng.normal(0, scale, n))
                a = np.maximum(a, 0)
                s = float(np.sum(a))
                if s > 1e-10:
                    a = a / s
                stall = 0
    
    return best_a


def coordinate_descent(a, time_budget=60.0, verbose=False):
    """Coordinate descent: optimize one coordinate at a time using 1D search."""
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64).copy()
    S = float(np.sum(a))
    if S < 1e-10:
        return a
    a = a / S
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    def obj_1d(j, t, a_fixed, v):
        """Objective when a[j] = t (others fixed), normalized to sum=1."""
        a_try = a_fixed.copy()
        a_try[j] = t
        s = float(np.sum(a_try))
        if s < 1e-10:
            return np.inf
        a_try = a_try / s
        conv = compute_conv(a_try)
        return 2.0 * n * float(np.max(conv))
    
    for it in range(200):
        if time.monotonic() - start > time_budget:
            break
        
        improved = False
        for j in range(n):
            if time.monotonic() - start > time_budget:
                break
            
            v = a[j]
            # Search for optimal t in [0, 2*v + 0.1/n] (bounded)
            t_lo = 0.0
            t_hi = max(2.0 * v, 0.1 / n) + 0.5 / n
            
            # Use golden section search
            result = minimize_scalar(
                lambda t: obj_1d(j, t, a, v),
                bounds=(t_lo, t_hi),
                method='bounded',
                options={'xatol': 1e-10 / n}
            )
            
            if result.success and result.fun < best_obj - 1e-14:
                a[j] = result.x
                S = float(np.sum(a))
                a = a / S
                best_obj = compute_obj(a)
                best_a = a.copy()
                improved = True
        
        if not improved:
            break
    
    if verbose:
        print(f"    CoordDesc: obj={best_obj:.8f}")
    
    return best_a


def spectral_init(n, rng):
    """Initialize using spectral methods (flatten autocorrelation)."""
    # Start with random non-negative sequence
    a = np.abs(rng.standard_normal(n)) + 0.1
    a /= np.sum(a)
    
    # Iteratively flatten the autocorrelation in frequency domain
    for it in range(200):
        # Compute autocorrelation
        conv = compute_conv(a)
        # Target: make conv as flat as possible
        # In frequency domain: |A(f)|^2 should be flat
        n_fft = 1
        while n_fft < 4 * n:
            n_fft <<= 1
        
        A = rfft(a, n_fft)
        power = A.real**2 + A.imag**2
        
        # Modify power to flatten autocorrelation
        # Target power: make IFFT(power) as flat as possible
        # Simple approach: power_new = 1 / power (to "inverse" the spectrum)
        # But this might not be stable. Use a softer version.
        power_safe = np.maximum(power, 1e-10)
        power_new = 1.0 / np.sqrt(power_safe)
        
        # Take IFFT with the modified amplitude and original phase
        phase = np.angle(A)

def resample_seq(a, new_n):
    """Resample sequence to new length."""
    n = len(a)
    if n == new_n:
        return a.copy()
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 1e-10)
```
