But the convolution also has values at positions 0 and 2n-2, which are a[0]^2 and a[n-1]^2 respectively. For a uniform sequence, these are (1/n)^2 = 1/n^2, which is much smaller than 1/n.

So for a uniform sequence, the max is at the center, with value 1/n, giving obj = 2n*(1/n) = 2.

To get obj < 2, we need to reduce the central peak. The central peak is sum_i a[i]*a[n-1-i]. To reduce this, we want the sequence to be "anti-symmetric" in some sense - if a[i] is large, then a[n-1-i] should be small.

This is exactly what the optimization is doing! It's trying to make the convolution as flat as possible.
