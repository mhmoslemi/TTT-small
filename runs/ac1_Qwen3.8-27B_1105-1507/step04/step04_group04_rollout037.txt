  The inner minimization is a QP: `min a^T (sum_k lambda_k T_k) a s.t. sum(a)=1, a>=0`.
  
  This is a trust-region-like problem. If the matrix `H = sum_k lambda_k T_k` is positive definite, the unconstrained minimum is at `a=0`, which violates `sum(a)=1`. So the constrained minimum is on the boundary.

  Actually, for `a >= 0, sum(a) = 1`, the minimum of `a^T H a` is achieved at a vertex of the simplex (one coordinate is 1, rest are 0) if H has positive diagonal. This gives `min_i H_ii`.

  Wait, that's not right. The minimum of `a^T H a` over the simplex is not necessarily at a vertex. For example, if H is the all-ones matrix, then `a^T H a = (sum a_i)^2 = 1` for all `a` in the simplex.

  In general, the minimum is found by solving a QP. This is the "trust region" subproblem.

  So the dual ascent would be:
  1. Maintain `lambda` (weights on lags).
  2. Solve `min a^T H(a) a s.t. sum(a)=1, a>=0` where `H = sum_k lambda_k T_k`.

  3. Update `lambda` based on the resulting `a`: `lambda_k <- exp(b_k(a) / T_dual) / sum_j exp(b_j(a) / T_dual)`.
  4. Iterate.

  Actually, let me reconsider. The dual problem is:
  `max_{lambda} min_{a} sum_k lambda_k * a^T T_k a`
  s.t. `sum lambda = 1, lambda >= 0, sum(a) = 1, a >= 0`.

  The inner problem is: `min_a a^T H a` s.t. `sum(a) = 1, a >= 0` where `H = sum_k lambda_k T_k`.

  This is a convex QP (H is PSD since each T_k is PSD... wait, is T_k PSD?).

  `T_k` is the matrix such that `a^T T_k a = b[k] = sum_{i+j=k} a[i] * a[j]`.
  
  For `k = 0`: `a^T T_0 a = a[0]^2`, so `T_0` has a 1 at position (0,0).
  For `k = 1`: `a^T T_1 a = 2*a[0]*a[1]`, so `T_1` has 1 at (0,1) and (1,0).
  In general, `T_k` has 1s at positions (i, k-i) where both i and k-i are in [0, n-1].
  
  `T_k` is symmetric. Is it PSD? `a^T T_k a = sum_{i+j=k} a[i]*a[j]`. This can be negative! For example, if `k=1` and `a = [1, -1, 0, ...]`, then `a^T T_1 a = 2*1*(-1) = -2`.
  
  But we have the constraint `a >= 0`, so `a^T T_k a >= 0` for `a >= 0`. However, `T_k` itself is not necessarily PSD as a matrix.
  
  This means the QP `min a^T H a s.t. sum(a)=1, a>=0` might not be convex if H is not PSD on the feasible region.

def compute_conv(a):
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)
    return conv[:2 * n - 1]


def compute_obj(a):
    n = len(a)
    if n == 0:
        return np.inf
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)


def effective_gradient(a, weights):
    n = len(a)
    return 2.0 * np.correlate(weights, a, mode='full')[n - 1:n - 1 + n]


def softmax_weights(conv, T):
    max_c = np.max(conv)
    shifted = (conv - max_c) / T
    exp_shifted = np.exp(np.clip(shifted, -500, 500))
    s = np.sum(exp_shifted)
    if s < 1e-300:

        w[np.argmax(conv)] = 1.0
        return w
    return exp_shifted / s

def build_toeplitz(a):
    n = len(a)
    A = np.zeros((2 * n - 1, n), dtype=np.float64)
    for j in range(n):
        k_start = j
        k_end = min(j + n, 2 * n - 1)
        A[k_start:k_end, j] = a[:k_end - k_start]
    return A


def solve_lp_maxsum(a, M, time_limit=6):
    n = len(a)
    A = build_toeplitz(a)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': time_limit})
        if res.status == 0:
            g = np.maximum(res.x, 0)
            return g, float(np.sum(g))
    except Exception:
        pass
    return None, None
