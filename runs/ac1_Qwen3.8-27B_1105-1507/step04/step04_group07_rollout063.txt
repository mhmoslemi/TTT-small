$= a_{k-j} \cdot [0 \leq k-j < n] + a_{k-j} \cdot [0 \leq k-j < n]$

$= 2 a_{k-j} \cdot [0 \leq k-j < n]$

Wait, that gives $2a_{k-j}$ always (when valid). But that seems too simple. Let me check with a small example.

$a = [a_0, a_1, a_2]$, n=3.
$(a*a)_0 = a_0^2$
$(a*a)_1 = a_0 a_1 + a_1 a_0 = 2 a_0 a_1$
$(a*a)_2 = a_0 a_2 + a_1^2 + a_2 a_0 = 2a_0 a_2 + a_1^2$
$(a*a)_3 = a_1 a_2 + a_2 a_1 = 2 a_1 a_2$
$(a*a)_4 = a_2^2$

$\frac{\partial (a*a)_2}{\partial a_1} = 2a_1$ ✓ (matches $2a_{k-j} = 2a_{2-1} = 2a_1$)
$\frac{\partial (a*a)_2}{\partial a_0} = 2a_2$ ✓ (matches $2a_{k-j} = 2a_{2-0} = 2a_2$)
$\frac{\partial (a*a)_0}{\partial a_0} = 2a_0$ ✓ (matches $2a_{k-j} = 2a_0$)

Great, so the formula is:
$\frac{\partial (a*a)_k}{\partial a_j} = 2 a_{k-j}$ if $0 \leq k-j < n$, else 0.

This is simple! So the subgradient of $M = \max_k (a*a)_k$ is:

For the active set $A = \{k : (a*a)_k = M\}$:
$g_j = \frac{2}{|A|} \sum_{k \in A} a_{k-j}$ (where we only sum over valid $k-j$)

This can be computed efficiently using convolution: if we define the indicator vector of the active set as $e_k = 1/|A|$ for $k \in A$ and 0 otherwise, then:
$g_j = 2 \sum_k e_k a_{k-j} = 2 (e * a)_j$

Wait, that's the convolution of e with a, evaluated at j. But we need to be careful about the definition.

$(e*a)_j = \sum_k e_k a_{j-k}$... hmm, the indexing is getting confusing.

Let me just compute it directly: $g_j = \frac{2}{|A|} \sum_{k \in A, 0 \leq k-j < n} a_{k-j}$

This is equivalent to: for each active k, add $a_{k-j}$ to $g_j$ (when $0 \leq k-j < n$).

This can be computed as a "correlation" or cross-correlation between the active set indicator and a.

Let me define $e$ as a vector of length $2n-1$ where $e_k = 1/|A|$ for $k \in A$ and 0 otherwise. Then:
$g_j = 2 \sum_{k=0}^{2n-2} e_k \cdot a_{k-j}$ (with $a_m = 0$ for $m < 0$ or $m \geq n$)

This is the cross-correlation of $e$ and $a$, which can be computed via FFT.

OK so the subgradient is easy to compute. Now, for the full objective $J = 2nM/S^2$ with $S = \sum a_j$:

$\frac{\partial J}{\partial a_j} = \frac{2n}{S^2} g_j - \frac{4nM}{S^3} a_j$

where $g_j$ is the subgradient of M.

For projected subgradient descent on the simplex:
$a_j \leftarrow \max(0, a_j - \eta (g_j - 2M a_j / S))$
then normalize to sum to 1.

This is what the previous code does (approximately). The issue is convergence speed.

**Better approach: Use the full gradient of a smooth approximation**

Instead of the non-smooth max, use the log-sum-exp:
$M_\tau(a) = \frac{1}{\tau} \log \sum_k \exp(\tau (a*a)_k)$

The gradient is:
$\frac{\partial M_\tau}{\partial a_j} = 2 \sum_k p_k a_{k-j}$

where $p_k = \exp(\tau (a*a)_k) / \sum_l \exp(\tau (a*a)_l)$.

This is smoother and allows faster convergence. The previous code does this (LSE gradient descent), but maybe with suboptimal parameters.

"""
Minimizes J(a) = 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Adaptive LP best-response with progressive tightening
2. 1D golden-section line search for blend factor
3. Multi-length search (384-1024) with diverse initializations
4. LSE (log-sum-exp) gradient polishing
5. Deflation: targeted reduction of worst peaks
6. Subgradient descent with full active set
"""

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time

# Cache for sparse matrices
_spar_cache = {}

def get_sparsity(n):
    if n not in _spar_cache:
        rows = []
        cols = []
        for k in range(2 * n - 1):
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            for j in range(js, je + 1):
                rows.append(k)
                cols.append(j)
        _spar_cache[n] = (np.array(rows, dtype=np.int32), np.array(cols, dtype=np.int32), len(rows))
    return _spar_cache[n]

def fast_conv(a):
    """Fast linear convolution via FFT."""
    n = len(a)
    s = 1
    while s < 2 * n - 1:
        s <<= 1
    fa = np.fft.rfft(a, s)
    return np.fft.irfft(fa * fa, s)[:2 * n - 1]

def compute_J(a):
    """Compute the objective J = 2*n*max(conv)/sum^2."""
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))

def lp_best_response(a, M):
    """Find best response g: maximize sum(g) subject to a*g <= M, g >= 0."""
    n = len(a)
    rows, cols, nnz = get_sparsity(n)
    vals = np.empty(nnz)
    for i in range(nnz):
        k = rows[i]
        j = cols[i]
        vals[i] = a[k - j]
    A = csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                options={'presolve': True, 'time_limit': 5})
    if r.success and r.x is not None:
        g = np.maximum(r.x, 0.0)
        if g.sum() > 1e-10:
            return g / g.sum()
    return None

def golden_section_search(a, g, n_evals=20):
    """Find optimal blend factor t in [0,1] minimizing J((1-t)a + t*g)."""
    a = np.maximum(a, 0.0)
    g = np.maximum(g, 0.0)
    sa, sg = a.sum(), g.sum()
    if sa < 1e-10 or sg < 1e-10:
        return 1.0
    
    def obj(t):
        h = (1 - t) * a + t * g
        ss = h.sum()
        if ss < 1e-10:
            return float('inf')
        b = fast_conv(h)
        return b.max() / (ss * ss)
    
    # Golden section
    invphi = (5**0.5 - 1) / 2
    invphi2 = invphi * invphi
    lo, hi = 0.0, 1.0
    c = hi - invphi * (hi - lo)
    d = lo + invphi * (hi - lo)
    fc, fd = obj(c), obj(d)
    
    for _ in range(n_evals):
        if fc < fd:
            hi = d
            d = c
            fd = fc
            c = hi - invphi * (hi - lo)
            fc = obj(c)
        else:
            lo = c
            c = d
            fc = fd
            d = lo + invphi * (hi - lo)
            fd = obj(d)
    
    t = (lo + hi) / 2
    return t

def lp_optimize(a, max_iters, deadline, tracker, tighten_start=0.0, tighten_end=0.05):
    """LP-based optimization with adaptive tightening."""
    a = np.maximum(a.astype(np.float64), 1e-10)
    a /= a.sum()
    n = len(a)
    current_J = compute_J(a)
    tracker.update(a)
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        M = float(b.max())
        
        # Adaptive tightening
        progress = it / max(1, max_iters)
        tighten = tighten_start + (tighten_end - tighten_start) * progress
        M_tight = M * (1.0 - tighten)
        
        g = lp_best_response(a, M_tight)
        if g is None:
            g = lp_best_response(a, M)
        if g is None:
            break
        
        # Golden section search for optimal blend
        t = golden_section_search(a, g, n_evals=15)
        
        a_new = (1.0 - t) * a + t * g
        a_new = np.maximum(a_new, 1e-10)
        a_new /= a_new.sum()
        
        J_new = compute_J(a_new)
        if J_new < current_J - 1e-15:
            a = a_new
            current_J = J_new
        elif it > 5:
            # Try a smaller step
            t *= 0.3
            a_new = (1.0 - t) * a + t * g
            a_new = np.maximum(a_new, 1e-10)
            a_new /= a_new.sum()
            J_new = compute_J(a_new)
            if J_new < current_J - 1e-15:
                a = a_new
                current_J = J_new
            else:
                break
        
        if it % 5 == 0:
            tracker.update(a)
    
    tracker.update(a)
    return a

def lse_gradient_descent(a, max_iters, deadline, tracker):
    """Polish with log-sum-exp gradient descent."""
    a = np.maximum(a.astype(np.float64), 1e-8)
    a /= a.sum()
    n = len(a)
    current_J = compute_J(a)
    tracker.update(a)
    
    tau = 100.0
    lr = 0.1 / n
    momentum = 0.9
    v = np.zeros(n)
    best_lr = lr
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        b_max = b.max()
        
        # Compute soft-max weights
        exp_b = np.exp(tau * (b - b_max))
        p = exp_b / exp_b.sum()
        
        # Gradient of LSE: 2 * cross_correlation(p, a)
        s = 1
        while s < 3 * n:
            s <<= 1
        fp = np.fft.rfft(p, s)
        fa = np.fft.rfft(a, s)
        # (p * a) gives cross-correlation
        corr = np.fft.irfft(fp * np.conj(fa), s)
        grad = 2.0 * corr[:n]
        
        # Momentum update
        v = momentum * v + (1.0 - momentum) * grad
        a_new = a - lr * v
        a_new = np.maximum(a_new, 1e-8)
        a_new /= a_new.sum()
        
        J_new = compute_J(a_new)
        if J_new < current_J - 1e-15:
            a = a_new
            current_J = J_new
            best_lr = lr
            lr = min(lr * 1.05, 1.0 / n)
            tau = min(tau * 1.02, 500.0)
        else:
            lr *= 0.5
            v *= 0.5
            if lr < 1e-18:
                break
        
        if it % 50 == 0:
            tracker.update(a)
    
    tracker.update(a)
    return a

def subgradient_with_active_set(a, max_iters, deadline, tracker):
    """Subgradient descent using full active set."""
    a = np.maximum(a.astype(np.float64), 1e-10)
    a /= a.sum()
    n = len(a)
    current_J = compute_J(a)
    tracker.update(a)
    lr = 1.0 / n
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        M = float(b.max())
        
        # Active set: lags within tolerance of max
        tol = 1e-8 * M + 1e-12
        active = np.where(b >= M - tol)[0]
        
        # Compute subgradient
        # g_j = (2/|A|) * sum_{k in A} a[k-j] for valid k-j
        # This is 2 * (e * a) where e is the normalized active indicator
        e = np.zeros(2 * n - 1)
        e[active] = 1.0 / len(active)
        
        # Cross-correlation: g_j = 2 * sum_k e_k * a[k-j]
        # Use FFT
        s = 1
        while s < 3 * n:
            s <<= 1
        fe = np.fft.rfft(e, s)
        fa = np.fft.rfft(a, s)
        corr = np.fft.irfft(fe * np.conj(fa), s)
        grad = 2.0 * corr[:n]
        
        # Projected gradient step
        a_new = a - lr * grad
        a_new = np.maximum(a_new, 1e-10)
        a_new /= a_new.sum()
        
        J_new = compute_J(a_new)
        if J_new < current_J - 1e-15:
            a = a_new
            current_J = J_new
            lr = min(lr * 1.02, 5.0 / n)
        else:
            lr *= 0.7
        
        if it % 20 == 0:
            tracker.update(a)
    
    tracker.update(a)
    return a

def deflation_step(a, n_worst=5, max_iters=20, deadline=0, tracker=None):
    """Try to reduce the worst peaks by targeted coordinate adjustments."""
    a = np.maximum(a.astype(np.float64), 1e-10)
    a /= a.sum()
    n = len(a)
    current_J = compute_J(a)
    
    for _ in range(max_iters):
        if deadline and time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        # Find worst lags
        worst_lags = np.argsort(b)[-n_worst:]
        
        improved = False
        for k in worst_lags:
            # Find which j contribute most to lag k
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            contribs = np.array([a[j] * a[k - j] for j in range(js, je + 1)])
            
            # Try reducing the top contributor
            j_best = js + np.argmax(contribs)
            for scale in [0.5, 0.7, 0.3]:
                a_trial = a.copy()
                a_trial[j_best] *= scale
                # Redistribute mass
                mass_removed = a[j_best] * (1 - scale)
                # Add to random positions or spread
                a_trial = np.maximum(a_trial, 1e-10)
                ss = a_trial.sum()
                a_trial /= ss
                J_trial = compute_J(a_trial)
                if J_trial < current_J - 1e-12:
                    a = a_trial
                    current_J = J_trial
                    improved = True
                    break
        
        if not improved:
            break
    
    if tracker:
        tracker.update(a)
    return a

def resample_seq(src, dest_n):
    """Resample a sequence to a different length."""
    src = np.asarray(src, dtype=np.float64)
    if src.size == dest_n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, dest_n)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)

def generate_inits(n, rng, parent=None):
    """Generate diverse initial sequences."""
    inits = []
    t = np.linspace(0, 1, n, endpoint=False)
    
    if parent is not None:
        inits.append(resample_seq(parent, n))
        inits.append(resample_seq(parent[::-1], n))
        # Perturbed parent
        for sigma in [0.1, 0.05]:
            p = resample_seq(parent, n)
            p /= p.sum()
            p = p + rng.normal(0, sigma / np.sqrt(n), n)
            inits.append(np.maximum(p, 0.001))
    
    # Uniform
    inits.append(np.ones(n))
    
    # Random
    inits.append(rng.uniform(0.1, 1.0, n))
    
    # Cosine basis
    for freq in [2, 3, 5, 7, 11]:
        inits.append(1.0 + 0.3 * np.cos(2 * np.pi * freq * t + rng.uniform(0, 6.28)))
    
    # Multi-frequency
    inits.append(1.0 + 0.2 * np.sin(2*np.pi*t) + 0.15 * np.sin(4*np.pi*t) 
                + 0.1 * np.sin(7*np.pi*t) + 0.05 * np.sin(13*np.pi*t))
    
    # Flat spectrum (random phases)
    half = n // 2 + 1
    angles = rng.uniform(0, 2 * np.pi, half)
    A = np.zeros(n, dtype=complex)
    A[:half] = np.exp(1j * angles[:half])
    for k in range(1, n - n // 2):
        A[k] = np.conj(A[n - k])
    a = np.fft.ifft(A).real
    inits.append(np.maximum(a, 0.01))
    
    # Gaussian process
    for sigma in [0.5, 1.0, 2.0]:
        a = np.ones(n)
        for k in range(1, min(n, 20)):
            a += rng.normal(0, 1) * np.exp(-k * sigma / n) * np.cos(2*np.pi*k*t)
        inits.append(np.maximum(a, 0.01))
    
    # Tukey window variants
    for r in [0.3, 0.5, 0.7]:
        x = np.abs(np.linspace(-1, 1, n))
        w = np.ones(n)
        m = int(r * n / 2)
        if m > 0:
            w[:m] = 0.5 + 0.5 * np.cos(np.pi * (np.arange(m) - m + 0.5) / m)
            w[-m:] = w[:m]
        inits.append(w + 0.1)
    
    # Exponential decay from center
    center = n // 2
    for rate in [1, 3, 10]:
        a = np.exp(-rate * (np.arange(n) - center)**2 / n)
        inits.append(a + 0.05)
    
    # Sparse + smooth
    n_spikes = max(3, n // 20)
    positions = rng.choice(n, size=n_spikes, replace=False)
    sparse = np.zeros(n)
    sparse[positions] = 1.0
    kernel_size = max(3, n // 40)
    kernel = np.hanning(kernel_size)
    kernel /= kernel.sum()
    inits.append(np.convolve(sparse, kernel, mode='same') + 0.05)
    
    # Palindromic random
    half_n = n // 2
    a_half = rng.uniform(0.1, 1.0, half_n + (1 if n % 2 else 0))
    a_pal = np.concatenate([a_half, a_half[:n - len(a_half)][::-1]])
    inits.append(a_pal)
    
    # Normalize all
    result = []
    for x in inits:
        x = np.maximum(np.asarray(x, dtype=np.float64), 0.001)
        x /= x.sum()
        result.append(x)
    return result

class ScoreTracker:
    def __init__(self):
        self.best = None
        self.best_score = float('inf')
        self.t_start = time.monotonic()
    
    def update(self, a):
        a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
        if a.size == 0 or a.sum() < 0.01:
            return
        score = float(evaluate_sequence(a.tolist()))
        if np.isfinite(score) and score < self.best_score:
            self.best = a.copy()
            self.best_score = score
            elapsed = time.monotonic() - self.t_start
            print(f"  * J={score:.8f} n={a.size} t={elapsed:.1f}s", flush=True)
    
    def report(self, label=""):
        if self.best is not None:
            print(f"  {label} best: J={self.best_score:.8f} n={self.best.size}", flush=True)

"""
Minimizes J(a) = 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Sequential Linear Programming (SLP) - new primary method
2. LP best-response with adaptive tightening
3. 1D golden-section line search for blend factor
4. Multi-length search (384-1024) with diverse initializations
5. LSE (log-sum-exp) gradient polishing
6. Subgradient descent with full active set
7. Deflation: targeted reduction of worst peaks
"""

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time

_spar_cache = {}

def get_sparsity(n):
    if n not in _spar_cache:
        rows = []
        cols = []
        for k in range(2 * n - 1):
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            for j in range(js, je + 1):
                rows.append(k)
                cols.append(j)
        _spar_cache[n] = (np.array(rows, dtype=np.int32), np.array(cols, dtype=np.int32), len(rows))
    return _spar_cache[n]

def fast_conv(a):
    n = len(a)
    s = 1
    while s < 2 * n - 1:
        s <<= 1
    fa = np.fft.rfft(a, s)
    return np.fft.irfft(fa * fa, s)[:2 * n - 1]

def compute_J(a):
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))

def lp_best_response(a, M):
    n = len(a)
    rows, cols, nnz = get_sparsity(n)
    vals = np.empty(nnz)
    for i in range(nnz):
        k = rows[i]
        j = cols[i]
        vals[i] = a[k - j]
    A = csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                options={'presolve': True, 'time_limit': 5})
    if r.success and r.x is not None:
        g = np.maximum(r.x, 0.0)
        if g.sum() > 1e-10:
            return g / g.sum()
    return None

def slp_solve(a, M):
    """Sequential LP: minimize M subject to linearized constraints at point a.
    Returns (new_a, new_M) or (None, None) on failure."""
    n = len(a)
    a = np.maximum(a, 0.0)
    sa = a.sum()
    if sa < 1e-10:
        return None, None
    a_norm = a / sa
    
    b = fast_conv(a_norm)
    # Linearization: sum_j 2*a_norm[k-j] * a_j <= M + b_k
    # Variables: a_0,...,a_{n-1}, M (n+1 variables)
    # Minimize: M (variable index n)
    # Constraints: sum_j 2*a_norm[k-j]*a_j - M <= b_k for k=0..2n-2
    #             sum_j a_j = 1
    #             a_j >= 0, M >= 0
    
    rows, cols, nnz = get_sparsity(n)
    
    # Build constraint matrix (2n-1 + 1) x (n + 1)
    A_rows = []
    A_cols = []
    A_vals = []
    rhs = []
    
    # Inequality constraints: sum_j 2*a_norm[k-j]*a_j - M <= b_k
    for i in range(nnz):
        k = rows[i]
        j = cols[i]
        A_rows.append(k)
        A_cols.append(j)
        A_vals.append(2.0 * a_norm[k - j])
    # -M term in each constraint
    for k in range(2 * n - 1):
        A_rows.append(k)
        A_cols.append(n)
        A_vals.append(-1.0)
    rhs = list(b)
    
    A_ineq = csr_matrix((A_vals, (A_rows, A_cols)), shape=(2 * n - 1, n + 1))
    
    # Equality: sum a_j = 1
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = [1.0]
    
    # Objective: minimize M
    c_obj = np.zeros(n + 1)
    c_obj[n] = 1.0
    
    bounds_slp = [(0.0, None)] * n + [(0.0, None)]
    
    r = linprog(c_obj, A_ub=A_ineq, b_ub=np.array(rhs),
                A_eq=A_eq, b_eq=b_eq, bounds=bounds_slp,
                method='highs', options={'presolve': True, 'time_limit': 5})
    
    if r.success and r.x is not None:
        new_a = np.maximum(r.x[:n], 0.0)
        new_M = max(r.x[n], 0.0)
        if new_a.sum() > 1e-10:
            new_a /= new_a.sum()
            return new_a, new_M
    return None, None

def slp_iterate(a, max_iters, deadline, tracker, blend=1.0):
    """Run SLP iterations."""
    a = np.maximum(a.astype(np.float64), 1e-10)
    a /= a.sum()
    n = len(a)
    current_J = compute_J(a)
    tracker.update(a)
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        new_a, new_M = slp_solve(a, None)
        if new_a is None:
            break
        
        # Blend for stability
        a_new = (1.0 - blend) * a + blend * new_a
        a_new = np.maximum(a_new, 1e-10)
        a_new /= a_new.sum()
        
        J_new = compute_J(a_new)
        if J_new < current_J - 1e-15:
            a = a_new
            current_J = J_new
        else:
            # Try smaller blend
            for b in [0.5, 0.3, 0.1]:
                a_try = (1.0 - b) * a + b * new_a
                a_try = np.maximum(a_try, 1e-10)
                a_try /= a_try.sum()
                J_try = compute_J(a_try)
                if J_try < current_J - 1e-15:
                    a = a_try
                    current_J = J_try
                    break
            else:
                if it > 3:
                    break
        
        if it % 5 == 0:
            tracker.update(a)
    
    tracker.update(a)
    return a

def golden_section_search(a, g, n_evals=15):
    a = np.maximum(a, 0.0)
    g = np.maximum(g, 0.0)
    sa, sg = a.sum(), g.sum()
    if sa < 1e-10 or sg < 1e-10:
        return 1.0
    
    def obj(t):
        h = (1.0 - t) * a + t * g
        ss = h.sum()
        if ss < 1e-10:
            return float('inf')
        b = fast_conv(h)
        return b.max() / (ss * ss)
    
    invphi = (5.0**0.5 - 1.0) / 2.0
    lo, hi = 0.0, 1.0
    c = hi - invphi * (hi - lo)
    d = lo + invphi * (hi - lo)
    fc, fd = obj(c), obj(d)
    
    for _ in range(n_evals):
        if fc < fd:
            hi = d
            d = c
            fd = fc
            c = hi - invphi * (hi - lo)
            fc = obj(c)
        else:
            lo = c
            c = d
            fc = fd
            d = lo + invphi * (hi - lo)
            fd = obj(d)
    
    return (lo + hi) / 2.0

def lp_optimize(a, max_iters, deadline, tracker, tighten_start=0.0, tighten_end=0.05):
    a = np.maximum(a.astype(np.float64), 1e-10)
    a /= a.sum()
    n = len(a)
    current_J = compute_J(a)
    tracker.update(a)

            break
        
        b = fast_conv(a)
        M = float(b.max())
        
        progress = it / max(1, max_iters)
        tighten = tighten_start + (tighten_end - tighten_start) * progress
        M_tight = M * (1.0 - tighten)
        
        g = lp_best_response(a, M_tight)

            g = lp_best_response(a, M)
        if g is None:
            break

        a_new = (1.0 - t) * a + t * g

        J_new = compute_J(a_new)
        if J_new < current_J - 1e-15:
            a = a_new
            current_J = J_new
        else:
            t2 = t * 0.3
            if t2 < 0.01:
                break
            a_new = (1.0 - t2) * a + t2 * g
            a_new = np.maximum(a_new, 1e-10)
            a_new /= a_new.sum()
            J_new = compute_J(a_new)
            if J_new < current_J - 1e-15:
                a = a_new
                current_J = J_new
            else:
                break
        
        if it % 5 == 0:
            tracker.update(a)
    
    tracker.update(a)

def lse_gradient_descent(a, max_iters, deadline, tracker):
    a = np.maximum(a.astype(np.float64), 1e-8)
    a /= a.sum()
    n = len(a)
    current_J = compute_J(a)
    tracker.update(a)
    
    tau = 80.0
    lr = 0.05 / n
    momentum = 0.9
    v = np.zeros(n)
    stall = 0
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        b_max = b.max()
        
        exp_b = np.exp(tau * (b - b_max))
        p = exp_b / exp_b.sum()
        
        s = 1
        while s < 3 * n:
            s <<= 1
        fp = np.fft.rfft(p, s)
        fa = np.fft.rfft(a, s)
        corr = np.fft.irfft(fp * np.conj(fa), s)
        grad = 2.0 * corr[:n]
        
        v = momentum * v + (1.0 - momentum) * grad
        a_new = a - lr * v
        a_new = np.maximum(a_new, 1e-8)
        a_new /= a_new.sum()
        
        J_new = compute_J(a_new)
        if J_new < current_J - 1e-15:
            a = a_new
            current_J = J_new
            stall = 0
            lr = min(lr * 1.03, 0.5 / n)
            tau = min(tau * 1.01, 400.0)
        else:
            stall += 1
            lr *= 0.6
            v *= 0.5
            if lr < 1e-18 or stall > 50:
                break
        
        if it % 30 == 0:
            tracker.update(a)
    
    tracker.update(a)
    return a

def subgradient_descend(a, max_iters, deadline, tracker):
    a = np.maximum(a.astype(np.float64), 1e-10)
    a /= a.sum()
    n = len(a)
    current_J = compute_J(a)
    tracker.update(a)
    lr = 0.5 / n
    stall = 0
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        M = float(b.max())
        
        tol = max(1e-10 * M, 1e-14)
        active = np.where(b >= M - tol)[0]
        
        e = np.zeros(2 * n - 1)
        e[active] = 1.0 / len(active)
        
        s = 1
        while s < 3 * n:
            s <<= 1
        fe = np.fft.rfft(e, s)
        fa = np.fft.rfft(a, s)
        corr = np.fft.irfft(fe * np.conj(fa), s)
        grad = 2.0 * corr[:n]
        
        a_new = a - lr * grad
        a_new = np.maximum(a_new, 1e-10)
        a_new /= a_new.sum()
        
        J_new = compute_J(a_new)
        if J_new < current_J - 1e-15:
            a = a_new
            current_J = J_new
            stall = 0
            lr = min(lr * 1.02, 3.0 / n)
        else:
            stall += 1
            lr *= 0.7
            if stall > 30:
                break
        
        if it % 20 == 0:
            tracker.update(a)
    
    tracker.update(a)
    return a

def deflation_step(a, n_worst=5, max_rounds=15, deadline=0, tracker=None):
    a = np.maximum(a.astype(np.float64), 1e-10)
    a /= a.sum()
    n = len(a)
    current_J = compute_J(a)
    
    for _ in range(max_rounds):
        if deadline and time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        worst_lags = np.argsort(b)[-n_worst:]
        improved = False
        
        for k in worst_lags:
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            if je < js:
                continue
            contribs = np.array([a[j] * a[k - j] for j in range(js, je + 1)])
            j_best = js + int(np.argmax(contribs))
            
            for scale in [0.5, 0.7, 0.3, 0.8]:
                a_trial = a.copy()
                a_trial[j_best] *= scale
                a_trial = np.maximum(a_trial, 1e-10)
                ss = a_trial.sum()
                if ss < 1e-10:
                    continue
                a_trial /= ss
                J_trial = compute_J(a_trial)
                if J_trial < current_J - 1e-12:
                    a = a_trial
                    current_J = J_trial
                    improved = True
                    break
        
        if not improved:
            break
    
    if tracker:
        tracker.update(a)
    return a

def resample_seq(src, dest_n):

    if src.size == dest_n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, dest_n)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)

def generate_inits(n, rng, parent=None):
    inits = []
    t = np.linspace(0, 1, n, endpoint=False)
    
    if parent is not None:
        inits.append(resample_seq(parent, n))
        inits.append(resample_seq(parent[::-1], n))
        p = resample_seq(parent, n)
        p /= p.sum()
        inits.append(np.maximum(p + rng.normal(0, 0.05 / np.sqrt(n), n), 0.001))
        inits.append(np.maximum(p + rng.normal(0, 0.1 / np.sqrt(n), n), 0.001))
    
    inits.append(np.ones(n))
    inits.append(rng.uniform(0.1, 1.0, n))
    
    for freq in [2, 3, 5, 7, 11, 13, 17]:
        inits.append(1.0 + 0.3 * np.cos(2 * np.pi * freq * t + rng.uniform(0, 6.28)))
    
    inits.append(1.0 + 0.2 * np.sin(2 * np.pi * t) + 0.15 * np.sin(4 * np.pi * t)
                + 0.1 * np.sin(7 * np.pi * t) + 0.05 * np.sin(13 * np.pi * t))
    inits.append(1.0 + 0.15 * np.cos(2 * np.pi * 3.7 * t) + 0.1 * np.cos(2 * np.pi * 7.3 * t)
                + 0.08 * np.cos(2 * np.pi * 11.1 * t))
    
    # Flat spectrum
    for _ in range(2):
        half = n // 2 + 1
        angles = rng.uniform(0, 2 * np.pi, half)
        A = np.zeros(n, dtype=complex)
        A[:half] = np.exp(1j * angles[:half])
        for k in range(1, n - n // 2):
            A[k] = np.conj(A[n - k])
        a = np.fft.ifft(A).real
        inits.append(np.maximum(a, 0.01))
    
    # Gaussian process
    for sigma in [0.5, 1.5, 3.0]:
        a = np.ones(n)
        for k in range(1, min(n, 30)):
            a += rng.normal(0, 1) * np.exp(-k * sigma / n) * np.cos(2 * np.pi * k * t + rng.uniform(0, 6.28))
        inits.append(np.maximum(a, 0.01))
    
    # Window functions
    x = np.abs(np.linspace(-1, 1, n))
    for r in [0.2, 0.4, 0.6]:
        w = np.ones(n)
        m = max(1, int(r * n / 2))
        if m < n // 2:
            w[:m] = 0.5 + 0.5 * np.cos(np.pi * (np.arange(m) - m + 0.5) / m)
            w[-m:] = w[:m]
        inits.append(w + 0.05)
    
    # Exponential
    center = n // 2
    for rate in [2, 5, 15]:
        a = np.exp(-rate * (np.arange(n) - center) ** 2 / n)
        inits.append(a + 0.03)
    
    # Sparse + smooth
    n_spikes = max(3, n // 20)
    positions = rng.choice(n, size=n_spikes, replace=False)
    sparse = np.zeros(n)
    sparse[positions] = 1.0
    ksz = max(3, n // 30)
    kernel = np.hanning(ksz)
    kernel /= max(kernel.sum(), 1e-10)
    inits.append(np.convolve(sparse, kernel, mode='same') + 0.05)
    
    # Palindromic
    half_n = n // 2
    a_half = rng.uniform(0.1, 1.0, half_n + (1 if n % 2 else 0))
    a_pal = np.concatenate([a_half, a_half[:n - len(a_half)][::-1]])
    inits.append(a_pal)
    
    # Two-bump
    c1, c2 = rng.uniform(0.2, 0.4), rng.uniform(0.6, 0.8)
    w1, w2 = rng.uniform(0.05, 0.15), rng.uniform(0.05, 0.15)
    a = np.exp(-((t - c1) / w1) ** 2) + np.exp(-((t - c2) / w2) ** 2) + 0.05
    inits.append(a)
    
    result = []
    for x in inits:
        x = np.maximum(np.asarray(x, dtype=np.float64), 0.001)
        x /= x.sum()
        result.append(x)
    return result

class ScoreTracker:
    def __init__(self):
        self.best = None
        self.best_score = float('inf')
        self.t_start = time.monotonic()
    
    def update(self, a):
        a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
        if a.size == 0 or a.sum() < 0.01:
            return
        score = float(evaluate_sequence(a.tolist()))
        if np.isfinite(score) and score < self.best_score:
            self.best = a.copy()
            self.best_score = score
            elapsed = time.monotonic() - self.t_start
            print(f"  * J={score:.8f} n={a.size} t={elapsed:.1f}s", flush=True)
    
    def report(self, label=""):
        if self.best is not None:
            print(f"  {label} best: J={self.best_score:.8f} n={self.best.size}", flush=True)

def propose_candidate(seed=42, budget_s=1500, **kwargs):
    """
    Multi-phase search: SLP + LP best-response + LSE gradient + deflation.
    Explores multiple sequence lengths with diverse initializations.
    """
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + float(budget_s) - 25.0
    tracker = ScoreTracker()
    
    # Load parent
    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        if p.ndim == 1 and p.size > 0 and np.all(np.isfinite(p)):
            parent = np.maximum(p, 0.0)
            tracker.update(parent)
            print(f"Parent: n={parent.size}, J={tracker.best_score:.8f}", flush=True)
    except (NameError, AttributeError):
        pass
    
    # === Phase 1: Broad search ===
    print(f"\n{'='*60}", flush=True)
    print(f"Phase 1: Broad multi-length search", flush=True)
    print(f"{'='*60}", flush=True)
    
    lengths = [384, 512, 640, 768, 1024]
    phase1_time = 500
    phase1_deadline = min(deadline - 500, time.monotonic() + phase1_time)
    
    candidates = []
    
    for n in lengths:
        if time.monotonic() > phase1_deadline - 60:
            break
        
        t0 = time.monotonic()
        inits = generate_inits(n, rng, parent)
        n_inits = len(inits)
        time_per_init = max(8.0, (phase1_deadline - time.monotonic() - 20) / max(1, n_inits))
        
        for idx, a0 in enumerate(inits):
            if time.monotonic() > phase1_deadline - 20:
                break
            if time.monotonic() - t0 > time_per_init * (idx + 1) + 30:
                break
            
            t_init_end = t0 + time_per_init
            
            # SLP
            a = slp_iterate(a0, max(10, int(20.0 / max(1.0, n / 256.0))), 
                           min(t_init_end, phase1_deadline - 40), tracker, blend=0.8)
            
            # LP
            if time.monotonic() < t_init_end:
                a = lp_optimize(a, max(10, int(20.0 / max(1.0, n / 256.0))),
                               min(t_init_end + 10, phase1_deadline - 30), tracker,
                               tighten_start=0.0, tighten_end=0.03)
            
            # Quick LSE
            if time.monotonic() < t_init_end + 15:
                a = lse_gradient_descent(a, 100, min(t_init_end + 15, phase1_deadline - 20), tracker)
            
            J = compute_J(a)
            candidates.append((J, n, a.copy()))
        
        best_for_n = min((c[0] for c in candidates if c[1] == n), default=float('inf'))
        print(f"  n={n}: best J={best_for_n:.6f} ({time.monotonic()-t0:.1f}s)", flush=True)
    
    candidates.sort(key=lambda x: x[0])
    if candidates:
        print(f"  Top 5: {[f'J={c[0]:.6f},n={c[1]}' for c in candidates[:5]]}", flush=True)
    
    # === Phase 2: Deep optimization on top candidates ===
    print(f"\n{'='*60}", flush=True)
    print(f"Phase 2: Deep optimization", flush=True)
    print(f"{'='*60}", flush=True)
    
    phase2_deadline = deadline - 250
    top_k = min(6, len(candidates))
    
    for i in range(top_k):
        if time.monotonic() > phase2_deadline - 80:
            break
        
        J_init, n, a = candidates[i]
        t0 = time.monotonic()
        print(f"  Cand {i+1}: J={J_init:.6f}, n={n}", flush=True)
        
        # SLP with full blend
        a = slp_iterate(a, 40, min(phase2_deadline - 150, t0 + 80), tracker, blend=1.0)
        
        # LP with tightening
        if time.monotonic() < phase2_deadline - 100:
            a = lp_optimize(a, 50, min(phase2_deadline - 100, t0 + 150), tracker,
                          tighten_start=0.0, tighten_end=0.05)
        
        # SLP again
        if time.monotonic() < phase2_deadline - 60:
            a = slp_iterate(a, 30, min(phase2_deadline - 60, t0 + 200), tracker, blend=0.7)
        
        # Subgradient
        if time.monotonic() < phase2_deadline - 40:
            a = subgradient_descend(a, 300, min(phase2_deadline - 40, t0 + 230), tracker)
        
        # LSE
        if time.monotonic() < phase2_deadline - 20:
            a = lse_gradient_descent(a, 2000, min(phase2_deadline - 20, t0 + 260), tracker)
        
        # Deflation
        if time.monotonic() < phase2_deadline - 10:
            a = deflation_step(a, n_worst=3, max_rounds=10,
                             deadline=min(phase2_deadline - 10, t0 + 280), tracker=tracker)
        
        # Final LP
        if time.monotonic() < phase2_deadline - 3:
            a = lp_optimize(a, 15, min(phase2_deadline - 3, t0 + 300), tracker,
                          tighten_start=0.02, tighten_end=0.05)
        
        J_final = compute_J(a)
        print(f"    -> J={J_final:.8f} ({time.monotonic()-t0:.1f}s)", flush=True)
    
    # === Phase 3: Final intensive polish ===
    print(f"\n{'='*60}", flush=True)
    print(f"Phase 3: Final polish on best", flush=True)
    print(f"{'='*60}", flush=True)
    
    if tracker.best is not None and time.monotonic() < deadline - 40:
        a = tracker.best.copy()
        t0 = time.monotonic()
        
        # Extended SLP
        a = slp_iterate(a, 50, min(deadline - 60, t0 + 80), tracker, blend=0.9)
        
        # LP with aggressive tightening
        if time.monotonic() < deadline - 40:
            a = lp_optimize(a, 40, min(deadline - 40, t0 + 130), tracker,
                          tighten_start=0.02, tighten_end=0.08)
        
        # Long LSE
        if time.monotonic() < deadline - 20:
            a = lse_gradient_descent(a, 5000, min(deadline - 20, t0 + 180), tracker)
        
        # Deflation
        if time.monotonic() < deadline - 10:
            a = deflation_step(a, n_worst=5, max_rounds=15,
                             deadline=min(deadline - 10, t0 + 200), tracker=tracker)
        
        # Final SLP + LP
        if time.monotonic() < deadline - 5:
            a = slp_iterate(a, 20, min(deadline - 5, t0 + 220), tracker, blend=1.0)
        
        if time.monotonic() < deadline - 2:
            a = lse_gradient_descent(a, 2000, deadline - 1, tracker)
        
        print(f"  Phase 3: J={compute_J(a):.8f} ({time.monotonic()-t0:.1f}s)", flush=True)
    
    # Fallback
    if tracker.best is None:
        tracker.best = np.ones(256)
        tracker.best_score = compute_J(tracker.best)
        tracker.update(tracker.best)
    
    print(f"\n{'='*60}", flush=True)
    print(f"FINAL: J={tracker.best_score:.8f} n={tracker.best.size} "
          f"time={time.monotonic()-tracker.t_start:.1f}s", flush=True)
    print(f"{'='*60}", flush=True)
    
    return [float(x) for x in tracker.best]
