For k = alpha*(n-1), the sum has about n*min(alpha, 2-alpha, 1) terms (for 0 < alpha < 2).

conv[k] ≈ n * integral_0^{alpha} f(x) f(alpha - x) dx

For k = alpha*n (1 < alpha < 2):
conv[k] ≈ n * integral_{alpha-1}^{1} f(x) f(alpha - x) dx

And S ≈ n * integral_0^1 f(x) dx.

= 2 * max_alpha [integral_{...} f(x)f(alpha-x) dx] / (integral_0^1 f(x) dx)^2

So we want to minimize the ratio of the peak of the "continuous convolution" to the square of the integral.

For a constant f = 1: peak of continuous conv = min(alpha, 2-alpha, 1) (the length of the integration interval). Max is 1 at alpha=1. Integral = 1. Ratio = 1/1 = 1. Objective = 2*1 = 2.

For f(x) = x: integral = 1/2. 
Continuous conv at alpha: for 0<alpha<1, integral_0^alpha x(alpha-x) dx = alpha^3/2 - alpha^3/3 = alpha^3/6.
For alpha=1: 1/6.
For 1<alpha<2: integral_{alpha-1}^1 x(alpha-x) dx. Let u = x-(alpha-1), x = u+alpha-1.
= integral_0^{2-alpha} (u+alpha-1)(alpha-u-alpha+1) du = integral_0^{2-alpha} (u+alpha-1)(1-u) du
