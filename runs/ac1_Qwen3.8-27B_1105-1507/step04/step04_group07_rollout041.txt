db_k/da_j = a_{k-j} + a_{j-k} ... no wait.

b_k = sum_i a_i * a_{k-i}

The terms involving a_j are:

- When k-i = j, i.e., i = k-j: a_{k-j} * a_j

These are the same term (a_j * a_{k-j}) when i = j = k-j, i.e., k = 2j.

Wait, that's only if both i=j and i=k-j are valid, which requires 0 <= j < n and 0 <= k-j < n. In that case:

- From i=k-j: derivative of a_{k-j}*a_j w.r.t. a_j is a_{k-j}
- Total: 2*a_{k-j}

But if k = 2j, these are the same term, so the derivative is just 2*a_j (which equals 2*a_{k-j} since k-j = j). So the formula 2*a_{k-j} (when 0 <= k-j < n) is correct in all cases.

Therefore:
dLSE/da_j = sum_k p_k * 2 * a_{k-j} (for k where 0 <= k-j < n)
= 2 * sum_{m=0}^{n-1} p_{m+j} * a_m (where m = k-j, so k = m+j, and we need 0 <= m+j <= 2n-2)
= 2 * sum_{m=max(0,-j)}^{min(n-1, 2n-2-j)} p_{m+j} * a_m
= 2 * sum_{m=0}^{n-1} p_{m+j} * a_m (since 0 <= j < n and 0 <= m < n, so 0 <= m+j <= 2n-2)

(p ⊛ a)_j = sum_m p_{m+j} * a_m

This is the cross-correlation of p and a at lag j.

(p ⊛ a)_j = sum_m p_{m+j} * a_m

If we define p_rev[m] = p_{2n-2-m} (reversed p, length 2n-1), then:
(p ⊛ a)_j = sum_m p_{m+j} * a_m = sum_m p_rev[2n-2-m-j] * a_m = (p_rev * a)_{2n-2-j}

where * denotes linear convolution. So (p ⊛ a) = reversed(p_rev * a) = reversed(reversed(p) * a).

cross_correlation(p, a)[j] = ifft(fft(p, N) * conj(fft(a, N)))[j] (with N >= 2n-1+n-1 = 3n-2 for linear)

For this to equal the linear cross-correlation, we need N >= len(p) + len(a) - 1 = (2n-1) + n - 1 = 3n-2.

Then r_j = sum_k p_k * a_{k-j} for 0 <= k-j < n (with a_m = 0 outside [0,n-1]).

But we want (p ⊛ a)_j = sum_m p_{m+j} * a_m = sum_m p_{m+j} * a_m.

Let me substitute: let k = m+j, so m = k-j. Then:
(p ⊛ a)_j = sum_k p_k * a_{k-j} (with 0 <= k-j < n and 0 <= k < 2n-1)

This is exactly the cross-correlation r_j (for j = 0, ..., n-1), provided N is large enough.

So: dLSE/da_j = 2 * r_j where r = ifft(fft(p, N) * conj(fft(a, N))) and N >= 3n-2.

"""
Minimizes J(a) = 2*n*max(convolve(a,a))/(sum(a))^2 using:
1. L-BFGS-B on LSE-smoothed objective with adaptive temperature
2. LP best-response (conditional gradient / Frank-Wolfe) for refinement  
3. Multi-length search with diverse structured initializations
4. Spectral-domain initialization for flat autocorrelation targets
5. Simulated annealing with LP refinement for escape
"""

import numpy as np
from scipy.optimize import minimize, linprog
from scipy.sparse import csr_matrix
import time

# Global cache
_sparsity_cache = {}

def get_sparsity(n):
    if n not in _sparsity_cache:
        rows = []
        cols = []
        for k in range(2 * n - 1):
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            rows.extend([k] * (je - js + 1))
            cols.extend(range(js, je + 1))
        _sparsity_cache[n] = (np.array(rows), np.array(cols), len(rows))
    return _sparsity_cache[n]

def fast_conv(a):
    n = len(a)
    s = 1
    while s < 2 * n - 1:
        s <<= 1
    fa = np.fft.rfft(a, s)
    return np.fft.irfft(fa * fa, s)[:2 * n - 1]

def compute_J(a):
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))

def lse_objective_and_grad(x, tau):
    """
    Computes the LSE-smoothed objective and its gradient.
    x: the sequence (assumed non-negative and normalized, sum=1)
    tau: smoothing parameter (larger = sharper approximation to max)
    Returns (value, gradient)
    """
    a = np.maximum(x, 1e-15)
    s = a.sum()
    n = len(a)
    b = fast_conv(a)
    
    # LSE computation
    tb = tau * b
    tb_max = tb.max()
    exp_tb = np.exp(tb - tb_max)
    log_sum_exp = tb_max + np.log(exp_tb.sum())
    LSE = log_sum_exp / tau  # This approximates max(b)
    
    # Softmax weights
    p = exp_tb / exp_tb.sum()
    
    # Gradient of LSE w.r.t. a:
    # dLSE/da_j = sum_k p_k * db_k/da_j = 2 * sum_k p_k * a[k-j] (for valid k-j)
    # = 2 * cross_correlation(p, a)[j]
    s_fft = 1
    while s_fft < 3 * n:
        s_fft <<= 1
    fp = np.fft.rfft(p, s_fft)
    fa = np.fft.rfft(a, s_fft)
    corr = np.fft.irfft(fp * np.conj(fa), s_fft)
    dLSE_da = 2.0 * corr[n-1:n-1+n]
    
    # Full objective: J = 2n * LSE / s^2
    J_val = 2.0 * n * LSE / (s * s)
    
    # Gradient: dJ/da_j = 2n/s^2 * dLSE/da_j - 4n*LSE/s^3 * a_j
    grad = (2.0 * n / (s * s)) * dLSE_da - (4.0 * n * LSE / (s ** 3)) * a
    
    return J_val, grad

def optimize_lbfgs(a, tau_start, tau_end, max_iter, deadline, tracker):
    """
    L-BFGS-B optimization with annealing temperature.
    """
    a = np.maximum(a.astype(np.float64), 1e-8)
    a /= a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_J = compute_J(a)
    tracker.update(a)
    
    # Anneal tau from tau_start to tau_end
    n_anneal = max(1, max_iter // 10)
    
    for phase in range(n_anneal):
        if time.monotonic() > deadline:
            break
        
        tau = tau_start * (tau_end / tau_start) ** (phase / max(1, n_anneal - 1))
        iters_this_phase = max(1, max_iter // n_anneal)
        
        def obj_and_grad(x):
            a_trial = np.maximum(x, 1e-15)
            val, grad = lse_objective_and_grad(a_trial, tau)
            # Add a large penalty for going outside [0, 1] range (shouldn't happen with bounds)
            return val, grad
        
        # Use L-BFGS-B with bounds [0, None]
        # We need to handle the normalization constraint.
        # Option 1: parameterize in log-space (x = exp(z), then normalize)
        # Option 2: use the constraint sum(a) = 1
        # Option 3: since J is scale-invariant, just optimize without constraint
        #            and the optimizer will find the right scale.
        # Actually, since J is scale-invariant, we can drop the normalization
        # and just minimize 2n*LSE/s^2 directly. The optimizer will handle it.
        # But we need a >= 0, so use bounds [0, None].
        # Also, we need s > 0, so we need at least one positive element.
        
        result = minimize(
            obj_and_grad, a,
            method='L-BFGS-B',
            bounds=[(0, 10)] * n,
            options={'maxiter': iters_this_phase, 
                     'ftol': 1e-12, 'gtol': 1e-8,
                     'max_ls': 50}
        )
        
        a_new = np.maximum(result.x, 0)
        s_new = a_new.sum()
        if s_new > 1e-10:
            a_new /= s_new
            J_new = compute_J(a_new)
            if J_new < best_J:
                best_J = J_new
                best_a = a_new.copy()
                tracker.update(a_new)
            a = a_new
    
    tracker.update(best_a)
    return best_a

def lp_best_response(a, M):
    """Find g >= 0 maximizing sum(g) subject to conv(a,g) <= M."""
    n = len(a)
    rows, cols, nnz = get_sparsity(n)
    vals = np.empty(nnz)
    for i in range(nnz):
        k = rows[i]
        j = cols[i]
        vals[i] = a[k - j]
    A = csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                options={'presolve': True, 'time_limit': 20})
    if r.success and r.x is not None:
        g = np.maximum(r.x, 0.0)
        if g.sum() > 1e-10:
            return g
    return None

def run_lp_opt(a, max_iters, deadline, tracker, tighten=0.01):
    """LP-based conditional gradient method."""
    a = np.maximum(a.astype(np.float64), 1e-8)
    a /= a.sum()
    n = len(a)
    current_J = compute_J(a)
    tracker.update(a)

    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        b = fast_conv(a)
        M = float(b.max())
        M_tight = M * (1.0 - tighten)
        g = lp_best_response(a, M_tight)
        if g is None:
            g = lp_best_response(a, M)
        if g is None:
            break
        g = np.maximum(g, 0.0)
        gs = g.sum()
        if gs < 1e-10:
            break
        g /= gs

        best_a = None
        best_J = current_J
        for t in [0.1, 0.2, 0.3, 0.5, 0.7, 0.9]:
            a_trial = (1.0 - t) * a + t * g
            a_trial = np.maximum(a_trial, 0.0)
            ss = a_trial.sum()
            if ss < 1e-10:
                continue
            a_trial /= ss
            J_trial = compute_J(a_trial)
            if J_trial < best_J - 1e-14:
                best_J = J_trial
                best_a = a_trial.copy()
        if best_a is None:
            break
        a = best_a
        current_J = best_J
        if it % 10 == 0:
            tracker.update(a)
    tracker.update(a)
    return a

def resample_seq(src, dest_n):
    src = np.asarray(src, dtype=np.float64)
    if src.size == dest_n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, dest_n)
    result = np.interp(t_new, t_old, src)
    return np.maximum(result, 0.0)

def generate_inits(n, rng, parent=None):
    """Generate diverse initial sequences."""
    inits = []
    t = np.linspace(0, 1, n, endpoint=False)
    
    if parent is not None and parent.size > 0:
        inits.append(resample_seq(parent, n))
        inits.append(resample_seq(parent[::-1], n))
    
    # Constant
    inits.append(np.ones(n))
    
    # Random
    inits.append(rng.uniform(0.1, 1.0, n))
    inits.append(np.abs(rng.normal(0, 1, n)) + 0.1)
    
    # Flat spectrum (random phases)
    for _ in range(3):
        half = n // 2 + 1
        angles = rng.uniform(0, 2 * np.pi, half)
        A = np.zeros(n, dtype=complex)
        A[:half] = np.exp(1j * angles[:half])
        for k in range(1, n - n // 2):
            A[k] = np.conj(A[n - k])
        a = np.fft.ifft(A).real
        a = np.maximum(a, 0)
        if a.sum() > 1e-10:
            inits.append(a)
    
    # Windowed random
    window = 0.5 + 0.5 * np.cos(2 * np.pi * t)
    inits.append(rng.uniform(0, 1, n) * window + 0.05)
    inits.append(np.abs(rng.normal(0, 1, n)) * window + 0.05)
    
    # Multi-frequency
    inits.append(1.0 + 0.3 * np.cos(2*np.pi*3*t + rng.uniform(0, 6.28)) + 
                0.2 * np.cos(2*np.pi*7*t + rng.uniform(0, 6.28)))
    
    # Gaussian bumps
    centers = rng.uniform(0, 1, 3)
    bumps = sum(np.exp(-50*(t-c)**2) for c in centers)
    inits.append(bumps + 0.05)
    
    # Sparse spikes smoothed
    n_spikes = max(10, n // 10)
    positions = rng.choice(n, size=n_spikes, replace=False)
    sparse = np.zeros(n)
    sparse[positions] = 1.0
    ksize = max(5, n // 20)
    kernel = np.exp(-0.5 * (np.arange(-ksize//2, ksize//2+1))/(ksize//4))**2
    kernel /= kernel.sum()
    inits.append(np.convolve(sparse, kernel, mode='same') + 0.05)
    
    # Quadratic residue inspired
    mod = n  # Use n as modulus
    quad_res = np.array([(i*i) % mod for i in range(n)])
    a = (quad_res / max(1, quad_res.max()) + 0.5)
    inits.append(a)
    
    for x in inits:
        x = np.maximum(x, 0.001).astype(np.float64)
        x /= x.sum()
    return inits

def simulated_annealing(a, deadline, tracker, n_restarts=30, t0=0.1):
    """SA with LP refinement."""
    rng = np.random.default_rng(12345)
    n = a.size
    a = a.copy().astype(np.float64)
    current_J = compute_J(a)
    tracker.update(a)
    temp = t0
    
    for r in range(n_restarts):
        if time.monotonic() > deadline:
            break
        a_pert = a + rng.normal(0, temp, n)
        a_pert = np.maximum(a_pert, 1e-6)
        a_pert /= a_pert.sum()
        
        # Quick LP refinement
        a_ref = run_lp_opt(a_pert, max(3, 15 - r // 3), deadline, tracker, tighten=0.01)

Minimizes J(a) = 2*n*max(convolve(a,a))/(sum(a))^2 using:

import numpy as np
from scipy.optimize import minimize, linprog
from scipy.sparse import csr_matrix
import time

_sparsity_cache = {}

def get_sparsity(n):
    if n not in _sparsity_cache:
        rows = []
        cols = []
        for k in range(2 * n - 1):
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            rows.extend([k] * (je - js + 1))
            cols.extend(range(js, je + 1))
        _sparsity_cache[n] = (np.array(rows), np.array(cols), len(rows))
    return _sparsity_cache[n]

def fast_conv(a):
    n = len(a)
    s = 1
    while s < 2 * n - 1:
        s <<= 1
    fa = np.fft.rfft(a, s)
    return np.fft.irfft(fa * fa, s)[:2 * n - 1]

def compute_J(a):
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))

def lse_objective_and_grad(x, tau):
    a = np.maximum(x, 1e-15)
    s = a.sum()
    n = len(a)
    b = fast_conv(a)
    tb = tau * b
    tb_max = tb.max()
    exp_tb = np.exp(tb - tb_max)
    log_sum_exp = tb_max + np.log(exp_tb.sum())
    LSE = log_sum_exp / tau
    p = exp_tb / exp_tb.sum()
    s_fft = 1
    while s_fft < 3 * n:
        s_fft <<= 1
    fp = np.fft.rfft(p, s_fft)
    fa = np.fft.rfft(a, s_fft)
    corr = np.fft.irfft(fp * np.conj(fa), s_fft)
    dLSE_da = 2.0 * corr[:n]
    J_val = 2.0 * n * LSE / (s * s)
    grad = (2.0 * n / (s * s)) * dLSE_da - (4.0 * n * LSE / (s ** 3)) * a
    return J_val, grad

def optimize_lbfgs(a, tau_start, tau_end, max_phase_iters, deadline, tracker):

    a /= a.sum()

    tracker.update(a)
    n_phases = max(3, max_phase_iters // 10)
    for phase in range(n_phases):
        if time.monotonic() > deadline:
            break
        frac = phase / max(1, n_phases - 1)
        tau = tau_start * (tau_end / tau_start) ** frac
        iters_this = max(5, max_phase_iters // n_phases)
        def obj_and_grad(x):
            a_trial = np.maximum(x, 1e-15)
            if a_trial.sum() < 1e-14:
                return 1e10, np.zeros_like(x)
            val, grad = lse_objective_and_grad(a_trial, tau)
            return val, grad

def lp_best_response(a, M):

    rows, cols, nnz = get_sparsity(n)

        j = cols[i]

    A = csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                options={'presolve': True, 'time_limit': 30})
    if r.success and r.x is not None:
        g = np.maximum(r.x, 0.0)
        if g.sum() > 1e-10:
            return g
    return None

def run_lp_opt(a, max_iters, deadline, tracker, tighten=0.01):
    a = np.maximum(a.astype(np.float64), 1e-8)
    a /= a.sum()
    n = len(a)
    current_J = compute_J(a)
    tracker.update(a)
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        b = fast_conv(a)
        M = float(b.max())
        M_tight = M * (1.0 - tighten)
        g = lp_best_response(a, M_tight)
        if g is None:
            g = lp_best_response(a, M)
        if g is None:
            break
        g = np.maximum(g, 0.0)
        gs = g.sum()
        if gs < 1e-10:
            break
        g /= gs
        best_a = None
        best_J = current_J
        for t in [0.1, 0.2, 0.3, 0.5, 0.7, 0.9]:
            a_trial = (1.0 - t) * a + t * g
            a_trial = np.maximum(a_trial, 0.0)
            ss = a_trial.sum()
            if ss < 1e-10:
                continue
            a_trial /= ss
            J_trial = compute_J(a_trial)
            if J_trial < best_J - 1e-14:
                best_J = J_trial
                best_a = a_trial.copy()
        if best_a is None:
            break
        a = best_a
        current_J = best_J
        if it % 10 == 0:
            tracker.update(a)
    tracker.update(a)
    return a

def resample_seq(src, dest_n):
    src = np.asarray(src, dtype=np.float64)
    if src.size == dest_n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, dest_n)
    result = np.interp(t_new, t_old, src)
    return np.maximum(result, 0.0)

def generate_inits(n, rng, parent=None):
    inits = []
    t = np.linspace(0, 1, n, endpoint=False)
    if parent is not None and parent.size > 0:
        inits.append(resample_seq(parent, n))
        inits.append(resample_seq(parent[::-1], n))
    inits.append(np.ones(n))
    inits.append(rng.uniform(0.05, 1.0, n))
    inits.append(np.abs(rng.normal(0, 1, n)) + 0.05)
    for _ in range(4):
        half = n // 2 + 1
        angles = rng.uniform(0, 2 * np.pi, half)
        A = np.zeros(n, dtype=complex)
        A[:half] = np.exp(1j * angles[:half])
        for k in range(1, n - n // 2):
            A[k] = np.conj(A[n - k])
        a = np.fft.ifft(A).real
        a = np.maximum(a, 0)
        if a.sum() > 1e-10:
            inits.append(a)
    window = 0.5 + 0.5 * np.cos(2 * np.pi * t)
    inits.append(rng.uniform(0, 1, n) * window + 0.05)
    inits.append(np.abs(rng.normal(0, 1, n)) * window + 0.05)
    inits.append(1.0 + 0.3 * np.cos(2*np.pi*3*t + rng.uniform(0, 6.28)) +
                0.2 * np.cos(2*np.pi*7*t + rng.uniform(0, 6.28)) +
                0.1 * np.cos(2*np.pi*11*t + rng.uniform(0, 6.28)))
    centers = rng.uniform(0, 1, 4)
    bumps = sum(np.exp(-40*(t-c)**2) for c in centers)
    inits.append(bumps + 0.03)
    n_spikes = max(10, n // 8)
    positions = rng.choice(n, size=n_spikes, replace=False)
    sparse = np.zeros(n)
    sparse[positions] = 1.0
    ksize = max(5, n // 15)
    kernel = np.exp(-0.5 * (np.arange(-ksize//2, ksize//2+1)/(ksize//4.0))**2)
    kernel /= kernel.sum()
    inits.append(np.convolve(sparse, kernel, mode='same') + 0.03)
    inits.append(0.5 + 0.5 * np.cos(np.pi * t)**2)
    inits.append(0.3 + 0.7 * np.abs(np.sin(np.pi * t * 2)))
    for x in inits:
        x = np.maximum(x, 0.001).astype(np.float64)
        x /= x.sum()
    return inits

class ScoreTracker:
    def __init__(self):
        self.best = None
        self.best_score = float('inf')
        self.t_start = time.monotonic()
    def update(self, a):
        a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
        if a.size == 0 or a.sum() < 0.01:
            return
        score = float(evaluate_sequence(a.tolist()))
        if np.isfinite(score) and score < self.best_score:
            self.best = a.copy()
            self.best_score = score
            elapsed = time.monotonic() - self.t_start
            print(f"  * J={score:.8f} n={a.size} t={elapsed:.1f}s", flush=True)
    def report(self, label=""):
        if self.best is not None:
            print(f"  {label} best: J={self.best_score:.8f} n={self.best.size}", flush=True)

def simulated_annealing(a, deadline, tracker, n_restarts=30, t0=0.08):
    rng = np.random.default_rng(7777)
    n = a.size
    a = a.copy().astype(np.float64)
    current_J = compute_J(a)
    tracker.update(a)
    temp = t0
    for r in range(n_restarts):
        if time.monotonic() > deadline:
            break
        a_pert = a + rng.normal(0, temp, n)
        a_pert = np.maximum(a_pert, 1e-6)
        a_pert /= a_pert.sum()
        a_ref = run_lp_opt(a_pert, max(3, 12 - r // 4), deadline, tracker, tighten=0.01)
        J = compute_J(a_ref)
        delta = J - current_J
        if delta < 0 or rng.random() < np.exp(-delta / max(temp, 1e-10)):
            a = a_ref
            current_J = J
        temp *= 0.92
    tracker.update(a)
    return a

def coordinate_descent_polish(a, max_steps, deadline, tracker):
    a = a.copy().astype(np.float64)
    a = np.maximum(a, 1e-8)
    a /= a.sum()
    n = len(a)
    current_J = compute_J(a)
    tracker.update(a)
    rng = np.random.default_rng(4242)
    for step in range(max_steps):
        if time.monotonic() > deadline:
            break
        j = rng.integers(0, n)
        improved = False
        for scale in [0.7, 1.3, 0.5, 1.5, 0.85, 1.15, 0.95, 1.05]:
            a_trial = a.copy()
            a_trial[j] *= scale
            a_trial = np.maximum(a_trial, 1e-8)
            ss = a_trial.sum()
            if ss < 1e-10:
                continue
            a_trial /= ss
            J_trial = compute_J(a_trial)
            if J_trial < current_J - 1e-15:
                a = a_trial
                current_J = J_trial
                improved = True
                break
        if step % 200 == 0:
            tracker.update(a)
    tracker.update(a)
    return a

def propose_candidate(seed=42, budget_s=1500, **kwargs):
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + float(budget_s) - 20.0
    tracker = ScoreTracker()
    
    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        if p.ndim == 1 and p.size > 0 and np.all(np.isfinite(p)):
            parent = np.maximum(p, 0.0)
            tracker.update(parent)
            print(f"Parent: n={parent.size}, J={tracker.best_score:.8f}", flush=True)
    except (NameError, AttributeError):
        pass
    
    # Phase 1: Multi-length L-BFGS + PGD optimization
    lengths = [256, 384, 512, 768, 1024]
    available = deadline - time.monotonic() - 250
    time_weights = [1.0, 1.2, 1.5, 1.8, 2.2]
    tw_sum = sum(time_weights)
    
    for idx, n in enumerate(lengths):
        if time.monotonic() > deadline - 250:
            break
        time_alloc = available * time_weights[idx] / tw_sum
        t_phase_end = time.monotonic() + time_alloc
        if time.monotonic() >= t_phase_end - 40:
            continue
        
        print(f"\n{'='*50}", flush=True)
        print(f"Phase 1: n={n}, budget={time_alloc:.0f}s", flush=True)
        print(f"{'='*50}", flush=True)
        
        inits = generate_inits(n, rng, parent)
        best_for_n = None
        best_J_for_n = float('inf')
        n_inits = len(inits)
        init_budget = max(8.0, (t_phase_end - time.monotonic()) / n_inits)
        
        for idx_a, a0 in enumerate(inits):
            if time.monotonic() > t_phase_end - 30:
                break
            t0 = time.monotonic()
            a_opt = a0.copy()
            # L-BFGS with annealing
            if time.monotonic() < t_phase_end - 40:
                tau_s = 15 + n / 100
                tau_e = 80 + n / 15
                n_phases = max(3, int(init_budget / 8))
                a_opt = optimize_lbfgs(a_opt, tau_s, tau_e, n_phases * 10,
                                        t_phase_end - 40, tracker)
            # Projected gradient
            if time.monotonic() < t_phase_end - 30:
                n_pgd = max(200, int(30000 / n))
                a_opt = project_gradient_descent(a_opt, n_pgd, t_phase_end - 30, tracker,
                                                 tau0=30.0)
            # LP refinement
            if time.monotonic() < t_phase_end - 20:
                n_lp = max(3, int(init_budget / 10))
                a_opt = run_lp_opt(a_opt, n_lp, t_phase_end - 15, tracker, tighten=0.01)
            
            J = compute_J(a_opt)
            if J < best_J_for_n:
                best_J_for_n = J
                best_for_n = a_opt.copy()
                print(f"  init {idx_a+1}/{n_inits}: J={J:.8f} ({time.monotonic()-t0:.1f}s)",
                      flush=True)
        
        if best_for_n is not None:
            tracker.update(best_for_n)
            if parent is None or best_J_for_n < compute_J(resample_seq(parent, best_for_n.size)):
                parent = best_for_n.copy()
            tracker.report(f"Phase1 n={n}")
    
    # Phase 2: Focused optimization on best
    if tracker.best is not None and time.monotonic() < deadline - 200:
        t0 = time.monotonic()
        n = tracker.best.size
        print(f"\n{'='*50} Phase 2: Focus n={n} {'='*50}", flush=True)
        a = tracker.best.copy().astype(np.float64)
        # Multi-tau L-BFGS
        for tau in [30, 60, 120, 250, 500, 800]:
            if time.monotonic() > deadline - 200:
                break
            a = optimize_lbfgs(a, tau, tau * 3, 20, deadline - 200, tracker)
        # PGD with high tau
        if time.monotonic() < deadline - 150:
            a = project_gradient_descent(a, max(500, 200000 // n), deadline - 150, tracker,
                                         tau0=80.0)
        # LP
        if time.monotonic() < deadline - 100:
            a = run_lp_opt(a, 25, deadline - 100, tracker, tighten=0.005)
        tracker.report(f"Phase2 ({time.monotonic()-t0:.1f}s)")
    
    # Phase 3: SA escape
    if tracker.best is not None and time.monotonic() < deadline - 100:
        t0 = time.monotonic()
        n = tracker.best.size
        print(f"\n{'='*50} Phase 3: SA n={n} {'='*50}", flush=True)
        a = simulated_annealing(tracker.best, deadline - 100, tracker,
                                n_restarts=30, t0=0.06)
        if time.monotonic() < deadline - 50:
            a = optimize_lbfgs(a, 60, 400, 15, deadline - 50, tracker)
            if time.monotonic() < deadline - 30:
                a = run_lp_opt(a, 8, deadline - 30, tracker, tighten=0.005)
        tracker.report(f"Phase3 ({time.monotonic()-t0:.1f}s)")
    
    # Phase 4: Final polish
    if tracker.best is not None and time.monotonic() < deadline - 10:
        t0 = time.monotonic()
        print(f"\n{'='*50} Phase 4: Polish {'='*50}", flush=True)
        a = coordinate_descent_polish(tracker.best, 3000, deadline - 15, tracker)
        if time.monotonic() < deadline - 5:
            a = optimize_lbfgs(a, 100, 600, 10, deadline - 3, tracker)
            if time.monotonic() < deadline - 2:
                a = run_lp_opt(a, 5, deadline - 1, tracker, tighten=0.003)
        tracker.report(f"Phase4 ({time.monotonic()-t0:.1f}s)")
    
    if tracker.best is None:
        tracker.best = np.ones(256)
        tracker.best_score = compute_J(tracker.best)
        tracker.update(tracker.best)
    
    print(f"\n{'='*50} FINAL {'='*50}", flush=True)
    print(f"J={tracker.best_score:.8f} n={tracker.best.size} "
          f"time={time.monotonic()-tracker.t_start:.1f}s", flush=True)
    return [float(x) for x in tracker.best]
