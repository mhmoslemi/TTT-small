Actually, I think the key insight is: for LARGE n, the best sequences are those where the convolution is as flat as possible. The minimum J approaches 1 as n -> infinity (since J = 2*n*max/(sum)^2, and if max ~ 1/(2n), then J ~ 2n/(2n) = 1).

For n=512, we're looking at J values around 1.5, which means max(conv) is about 1.5/(2*512) = 0.00146 of (sum)^2. The average of conv is 1/(2*511) ≈ 0.000979 of (sum)^2. So the peak is about 1.5x the average.

To improve, we need to make the peak closer to the average. The "flatness" of the convolution is the key metric.

One approach: think of it as a "minimax" problem where we want to equalize the convolution values. The LP mirror descent does exactly this (it finds the best response that maximizes sum while keeping conv <= M, which effectively tries to equalize the active constraints).

Let me focus on making the LP mirror descent more effective:
1. Better warm-starting for the LP
2. More aggressive step sizes
3. Using the dual variables from the LP to guide the direction

Actually, I just realized something. The LP in the mirror descent is:
max sum(g) s.t. (a*g)[k] <= M for all k, g >= 0

The dual of this LP is:
min M * sum(lambda_k) s.t. sum_k lambda_k * a_{k-j} >= 1 for all j, lambda_k >= 0

The dual variables lambda_k tell us which constraints are "tight" in a weighted sense. We can use this information.

Let me also think about a different mirror: instead of the L2 mirror (which gives Euclidean projection), use the entropy mirror (which gives multiplicative updates). The entropy mirror descent update is:
a_j^{new} = a_j * exp(-eta * g_j) / Z

where g_j is the subgradient component and Z is a normalization constant. This is the "exponential gradient" or "Hedge" algorithm, which is known to work well for problems with simplex constraints.

Actually, for our problem, the constraint is sum(a) = 1, a >= 0, which is the simplex. The natural mirror for the simplex is the negative entropy: D(a, b) = sum a_j * log(a_j/b_j). The mirror descent update with this mirror is:
a_j^{new} = b_j * exp(-eta * g_j) / Z

This is multiplicatively proportional to exp(-eta * g), which is the "Hedge" or "Exponential Weight" algorithm.

Let me implement both L2 mirror descent and entropy mirror descent, and see which works better.

"""

2. Entropy mirror descent with LP best response

import numpy as np

def fast_conv(a):
    """Full self-convolution via FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]


def compute_J(a):
    """Compute J(a) = 2*n*max(conv(a,a))/(sum(a))^2."""
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))


def coord_descent(a, max_sweeps=1000, deadline=None, verbose=False, rng=None):
    """
    Coordinate descent with exact 1D minimization per coordinate.
    For each coordinate j, solves: min_{x>=0} max_k [(a*a)[k] with a_j replaced by x]
    """
    if rng is None:
        rng = np.random.default_rng(42)
    
    a = np.maximum(a.astype(np.float64), 1e-10)
    s = a.sum()
    a = a / s  # normalize to sum=1
    n = len(a)
    b = fast_conv(a)
    current_max = b.max()
    best_a = a.copy()
    best_max = current_max
    
    # Precompute the range of k affected by each coordinate j
    # Coordinate j affects (a*a)[k] for k in [j, j+n-1] (clipped to [0, 2n-2])
    
    for sweep in range(max_sweeps):
        if deadline is not None and time.monotonic() > deadline:
            break
        
        # Random or cyclic order
        if rng is not None and sweep > 0:
            order = rng.permutation(n)
        else:
            order = np.arange(n)
        
        improved = False
        for j in order:
            # Current value
            aj = a[j]
            
            # Compute the "base" convolution values (without a_j's contribution)
            # (a*a)[k] without a_j: subtract terms involving a_j
            # For k in [j, j+n-1] (clipped):
            #   if k == 2*j: subtract a_j^2
            #   else: subtract 2*a_j*a[k-j] (if 0 <= k-j < n)
            
            # Instead of modifying b, let's compute the affected values
            k_min = j  # minimum k where a_j appears (i=0, k-i=j -> k=j)
            k_max = min(2*n-2, j + n - 1)  # maximum k where a_j appears
            
            # For each affected k, compute c_k (base value without a_j)
            # and the coefficient of a_j and a_j^2
            affected_ks = np.arange(k_min, k_max + 1)
            
            # c_k = b[k] - (terms involving a_j)
            # Terms involving a_j in (a*a)[k]:
            #   a_j * a[k-j] if 0 <= k-j < n (this is the i=j term)
            #   a[k-j] * a_j if 0 <= k-j < n (this is the k-i=j term, i=k-j)
            #   If k=2j, these are the same term, so only a_j^2
            #   
            # More carefully:
            # (a*a)[k] = sum_i a[i]*a[k-i] for valid i
            # Terms with i=j: a[j]*a[k-j] = a_j * a[k-j] (if 0<=k-j<n)
            # Terms with k-i=j, i.e., i=k-j: a[k-j]*a[j] = a[k-j]*a_j (if 0<=k-j<n)
            # These are the same when k-j=j, i.e., k=2j
            # So: if k=2j: contribution is a_j^2
            #      else if 0<=k-j<n: contribution is 2*a_j*a[k-j]
            #      else: no contribution (but we said k is in [j, j+n-1], so 0<=k-j<=n-1)
            
            # Since k is in [j, min(2n-2, j+n-1)]:
            # k-j is in [0, min(n-1, 2n-2-j)]
            # So 0 <= k-j <= n-1 always holds in this range
            # Thus for all affected k:
            #   if k == 2j: base = b[k] - a_j^2, coef_linear = 0, coef_quad = 1
            #   else: base = b[k] - 2*a_j*a[k-j], coef_linear = 2*a[k-j], coef_quad = 0
            
            # Unaffected k: base = b[k], coef_linear = 0, coef_quad = 0
            
            # We want to find x >= 0 minimizing:
            # max( max_{unaffected k} b[k],  b[2j] - a_j^2 + x^2,  max_{affected k, k!=2j} (b[k] - 2*a_j*a[k-j] + 2*a[k-j]*x) )
            
            # Let M_unaffected = max of b[k] for k not in [k_min, k_max]
            if k_min > 0:
                M_unaffected_left = b[:k_min].max() if k_min > 0 else -np.inf
            else:
                M_unaffected_left = -np.inf
            if k_max < 2*n-2:
                M_unaffected_right = b[k_max+1:].max() if k_max + 1 < 2*n-1 else -np.inf
            else:
                M_unaffected_right = -np.inf
            M_unaffected = max(M_unaffected_left, M_unaffected_right)
            
            # For affected k (excluding k=2j if in range):
            k_2j = 2 * j
            affected_mask = np.ones(len(affected_ks), dtype=bool)
            quad_idx = -1
            if k_2j >= k_min and k_2j <= k_max:
                quad_idx = k_2j - k_min
                affected_mask[quad_idx] = False
            
            # Linear terms for non-quad affected k
            if affected_mask.any():
                linear_ks = affected_ks[affected_mask]
                # Coefficient of x: 2*a[k-j]
                idx_into_a = linear_ks - j  # k - j, which is in [0, n-1]
                linear_coefs = 2.0 * a[idx_into_a]
                # Base values: b[k] - 2*a_j*a[k-j]
                linear_bases = b[linear_ks] - 2.0 * aj * a[idx_into_a]
            else:
                linear_ks = np.array([], dtype=int)
                linear_coefs = np.array([])
                linear_bases = np.array([])
            
            # Quad term: base = b[k_2j] - a_j^2, value = base + x^2
            if quad_idx >= 0:
                quad_base = b[k_2j] - aj * aj
            else:
                quad_base = -np.inf
            
            # Now solve: min_{x>=0} max(quad_base + x^2, max_k(linear_bases[k] + linear_coefs[k]*x), M_unaffected)
            
            # Upper bound for x search
            # quad_base + x^2 <= current_max -> x <= sqrt(current_max - quad_base)
            upper = 2.0 * aj + 0.1  # start reasonable
            if quad_base > -np.inf:
                # We don't want x^2 + quad_base to be too large
                upper = max(upper, np.sqrt(max(0, best_max + 0.1 - quad_base)))
                upper = min(upper, 10.0)  # cap
            upper = max(upper, 2 * aj + 0.5)
            upper = min(upper, 5.0)  # safety cap
            
            # Define the 1D objective
            def obj_1d(x):
                val = M_unaffected
                if quad_base > -np.inf:
                    val = max(val, quad_base + x * x)
                if len(linear_ks) > 0:
                    val = max(val, np.max(linear_bases + linear_coefs * x))
                return val
            
            # Use minimize_scalar on [0, upper]
            try:
                res = minimize_scalar(obj_1d, bounds=(0, upper), method='bounded',
                                     options={'xatol': 1e-10})
                x_opt = res.x
            except:
                x_opt = aj
            
            # Update
            if abs(x_opt - aj) > 1e-12:
                a[j] = max(x_opt, 0.0)
                # Update b (convolution) - we can update incrementally
                # But for simplicity and correctness, recompute if needed
                # Actually, let's just update b incrementally:
                # b[k] changed by: (new terms) - (old terms)
                # Old: for k in [k_min, k_max]: old contribution was
                #   k=2j: a_j^2
                #   else: 2*a_j*a[k-j]
                # New: for k in [k_min, k_max]: new contribution is
                #   k=2j: x_opt^2
                #   else: 2*x_opt*a[k-j]
                
                # Actually it's easier to just recompute b after the full sweep
                # For now, let's track and recompute periodically
                improved = True
        
        # Recompute b at end of sweep (for correctness)
        b = fast_conv(a)
        current_max = b.max()
        
        if current_max < best_max - 1e-14:
            best_max = current_max
            best_a = a.copy()
        
        if verbose and sweep % 100 == 0:
            print(f"    CD sweep {sweep}: max_conv={current_max:.10f}")
        
        # Convergence check
        if sweep > 10 and current_max > best_max * (1 - 1e-12):
            # Check if we've converged
            if np.allclose(a, best_a, atol=1e-10):
                break
    
    return best_a


def entropy_mirror_descent(a, max_iters, deadline, lr_init=0.5, **kwargs):
    """
    Entropy mirror descent (exponential gradient) with LP best response.
    Update: a_j <- a_j * exp(-eta * grad_j) / Z
    """
    a = np.maximum(a.astype(np.float64), 1e-8)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    b = fast_conv(a)
    best_M = b.max()
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        M = float(b.max())
        
        # Compute subgradient of max_k (a*a)[k]
        active = np.where(b >= M - 1e-10 * M)[0]
        grad = np.zeros(n)
        for k in active:
            lo = max(0, k - n + 1)
            hi = min(n - 1, k)
            grad[lo:hi+1] += 2.0 * a[k-hi:k-lo+1][::-1]
        
        # Entropy mirror descent step
        eta = lr_init / (1 + 0.1 * it)
        a_new = a * np.exp(-eta * grad)
        s = a_new.sum()
        if s < 1e-10:
            a_new = a.copy()
        else:
            a_new = a_new / s
        
        M_new = fast_conv(a_new).max()
        if M_new < best_M:
            best_M = M_new
            best_a = a_new.copy()
        
        a = a_new
    
    return best_a


def build_A_sparse(n, a):
    """Build sparse constraint matrix for LP."""
    rows = []
    cols = []

    for k in range(2 * n - 1):

        j_max = min(n - 1, k)
        for j in range(j_min, j_max + 1):
            rows.append(k)
            cols.append(j)
            vals.append(a[k - j])
    A = csr_math...s, (rows, cols)), shape=(2 * n - 1, n))
    return A


def lp_best_response(a, M, time_limit=10):
    """LP: max sum(g) s.t. (a*g)[k] <= M for all k, g >= 0."""
    n = len(a)
    A = build_A_sparse(n, a)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    try:
        r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                    options={'time_limit': time_limit})
        if r.success and r.x is not None:
            g = np.maximum(r.x, 0)
            if g.sum() > 1e-15:
                return g, r
    except Exception:
        pass
    return None, None


def run_lp_mirror_descent(a, max_iters, deadline, use_entropy=False):
    """LP mirror descent with geometric line search."""
    a = np.maximum(a.astype(np.float64), 1e-8)
    a = a / a.sum()
    best_a = a.copy()
    b = fast_conv(a)
    best_M = b.max()
    no_improve = 0
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        M = float(b.max())
        g, lp_res = lp_best_response(a, M, time_limit=10)
        if g is None:
            break
        g = np.maximum(g, 0.0)
        g_sum = g.sum()
        if g_sum < 1e-10:
            break
        g /= g_sum
        
        # Line search
        improved = False
        base_t = max(0.1, 0.5 * (1 - 0.2 * it / max(1, max_iters)))
        for t in [base_t, base_t * 0.7, base_t * 0.5, base_t * 0.3, 0.05, 0.02]:
            a_trial = np.maximum((1 - t) * a + t * g, 0)
            s = a_trial.sum()
            if s < 1e-10:
                continue
            a_trial /= s
            M_trial = fast_conv(a_trial).max()
            if M_trial < best_M - 1e-14:
                a = a_trial
                best_M = M_trial
                best_a = a.copy()
                improved = True
                break
        
        if not improved:
            no_improve += 1
            if no_improve > 30:
                break
        else:
            no_improve = 0
    
    return best_a


def smooth_gradient_descent(a, max_iters, deadline, initial_tau=2.0, final_tau=80.0,
                            lr_init=0.3, lr_min=0.01):
    """Smooth gradient descent with adaptive log-sum-exp."""
    a = np.maximum(a.astype(np.float64), 1e-8)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    b = fast_conv(a)
    best_M = b.max()
    v = np.zeros(n)
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        frac = it / max(1, max_iters)
        tau = initial_tau + (final_tau - initial_tau) * (frac ** 0.5)
        lr = lr_init * (lr_min / lr_init) ** frac
        
        b = fast_conv(a)
        b_max = b.max()
        exp_b = np.exp(tau * (b - b_max))
        p = exp_b / exp_b.sum()
        
        grad = np.zeros(n)
        for k in range(2 * n - 1):
            pk = p[k]
            if pk < 1e-13:
                continue
            lo = max(0, k - n + 1)
            hi = min(n - 1, k)
            grad[lo:hi + 1] += 2.0 * pk * a[k - hi:k - lo + 1][::-1]
        
        v = 0.9 * v + lr * grad
        a_new = a - v
        a_new = np.maximum(a_new, 0.0)
        s = a_new.sum()
        if s < 1e-10:
            a_new = a.copy()
        else:
            a_new = a_new / s
        a = a_new
        
        M = fast_conv(a).max()
        if M < best_M * (1 - 1e-8):
            best_M = M
            best_a = a.copy()
    
    return best_a


def resample_seq(src, dest_n):
    """Resample 1D sequence to new length."""
    src = np.asarray(src, dtype=np.float64)
    if src.size == dest_n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, dest_n)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)


def generate_initializations(n, rng, parent=None):
    """Generate diverse initial sequences."""
    inits = []
    t_arr = np.linspace(0, 1, n, endpoint=False)
    
    if parent is not None:
        inits.append(resample_seq(parent, n))
        p = resample_seq(parent, n)
        inits.append(np.maximum(p + rng.normal(0, 0.02, n), 0.01))
        inits.append(np.maximum(p + rng.normal(0, 0.05, n), 0.01))
        inits.append(np.maximum(p + rng.normal(0, 0.1, n), 0.01))
    
    inits.append(np.ones(n))
    inits.append(rng.uniform(0.5, 1.0, n))
    
    for freq in [1, 2, 3, 5, 8, 13]:
        inits.append(np.maximum(1.0 + 0.3 * np.cos(2 * np.pi * freq * t_arr), 0.01))
        inits.append(np.maximum(1.0 + 0.4 * np.sin(2 * np.pi * freq * t_arr), 0.01))
    
    # Chirp
    inits.append(np.maximum(1.0 + 0.3 * np.cos(2 * np.pi * 3 * t_arr**2), 0.01))
    # Gaussian bumps
    inits.append(np.exp(-3.0 * (t_arr - 0.5)**2) + 0.1)
    inits.append(np.exp(-6.0*(t_arr-0.3)**2) + np.exp(-6.0*(t_arr-0.7)**2) + 0.05)
    # Multi-frequency
    inits.append(np.maximum(1.0 + 0.15*np.cos(4*np.pi*t_arr) + 0.15*np.cos(7*np.pi*t_arr) + 0.1*np.cos(11*np.pi*t_arr), 0.01))
    # Smooth random
    ksize = max(3, n // 20)
    kernel = np.ones(ksize) / ksize
    smooth = np.convolve(rng.uniform(0, 1, n), kernel, mode='same')
    inits.append(np.maximum(smooth + 0.1, 0.01))
    
    return inits
