4. Apply the perturbation

**Key insight for improvement**: The previous code's LP approach converges to a point where the active constraints (binding lags) form a specific pattern. At the optimum, the Lagrange multipliers (dual variables) of the LP tell us the "importance" of each lag. We can use this information to construct a better gradient direction.

Specifically, if y_k are the dual variables from the LP `max sum(g) s.t. a^T T_k g <= M, g >= 0`, then the optimal solution g* satisfies:
- `a^T T_k g* = M` for active k (where y_k > 0)
- `g*_i * (sum_k y_k * (T_k^T a)_i - 1) = 0` for each i (complementarity)

The vector `d_i = sum_k y_k * (T_k^T a)_i` is the "effective gradient" at the optimum. If `d_i > 1` for some i, then `g*_i = 0` (not used). If `d_i = 1`, then `g*_i` may be positive.

We can use `d` as the gradient direction for updating a:
- Where `d_i` is large (the element a_i contributes a lot to the peak conv), reduce a_i
- Where `d_i` is small, increase a_i

This gives a more informed update than the simple smooth-max gradient.

from scipy.optimize import linprog
import time

def compute_conv(a):
    """FFT-based convolution of a with itself."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)
    return conv[:2 * n - 1]

def compute_obj(a):
    n = len(a)
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)

def smooth_max_grad(conv, a, tau):
    """Compute gradient of smooth_max(conv, tau) w.r.t. a."""
    n = len(a)
    shifted = tau * (conv - conv.max())
    p = np.exp(shifted)
    p /= p.sum()
    # grad[i] = sum_j p[j] * a[j-i] (zero-padded)
    # = ifft(conj(FFT(p)) * FFT(a))[:n]

    P = np.fft.rfft(p, size)
    A = np.fft.rfft(a, size)
    C = np.fft.irfft(np.conj(P) * A, size)
    return C[:n], p

def build_toeplitz(a):
    n = len(a)
    A = np.zeros((2 * n - 1, n), dtype=np.float64)
    for j in range(n):
        k_start = j
        k_end = min(j + n, 2 * n - 1)
        A[k_start:k_end, j] = a[:k_end - k_start]
    return A

def solve_lp_maxsum(a, M):
    """Solve: max sum(g) s.t. A@g <= M, g >= 0."""
    n = len(a)
    A = build_toeplitz(a)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': 10})
        if res.status == 0:
            g = np.maximum(res.x, 0)
            return g, float(np.sum(g))
    except Exception:
        pass
    return None, None
