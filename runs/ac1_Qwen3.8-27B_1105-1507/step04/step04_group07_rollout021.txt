One more idea: **Spectral equalization**. 

The autocorrelation in the frequency domain is |A(ω)|^2 (periodic) or related to it (aperiodic). If we could make |A(ω)| as flat as possible (equi-ripple), the autocorrelation would be as "peaky" as a delta function (in the periodic case) or as flat as possible (in the aperiodic case).

For the aperiodic case, the relationship is:
ρ(k) = (1/2π) ∫ |A(ω)|^2 e^{ikω} dω

So if |A(ω)|^2 is constant (= C), then ρ(0) = C and ρ(k≠0) = 0. This gives perfect autocorrelation! But |A(ω)|^2 = C means A(ω) has constant magnitude, which for a real signal means it's a chirp (all-pass filter). And a real all-pass filter of finite length doesn't exist (except for trivial cases).

For a real non-negative signal, we can't achieve constant magnitude in the frequency domain. But we can get close.

The **Parks-McClellan** (Remez) algorithm designs filters with equi-ripple frequency response. We could adapt this idea to our problem:
- Design a non-negative sequence a whose |A(ω)|^2 is as flat as possible
- This would make the aperiodic autocorrelation as flat as possible (minimizing the peak)

But adapting Remez to this problem is non-trivial. Let me think of a simpler approach.

Actually, here's a key insight: **The problem is equivalent to minimizing the peak of the first difference of the periodic autocorrelation** (due to the boundary effects in linear vs circular convolution).

For circular autocorrelation: ρ_c(k) = (1/N) sum_{j=0}^{N-1} a_j * a_{(j-k) mod N}
For linear autocorrelation: ρ_l(k) = sum_{j} a_j * a_{j+k} (with zero padding)

The relationship: ρ_l(k) = ρ_c(k) - (boundary correction terms)

If we make the periodic autocorrelation flat (all values = 1/N after normalization), the linear autocorrelation will be flat except near the boundaries. The peak will be at the center (k=0 for aperiodic, which corresponds to k=n-1 in the convolution).

So the strategy is: **Make the periodic autocorrelation as flat as possible, subject to a ≥ 0.**

The periodic autocorrelation is flat iff |A(ω)| is constant for all ω (i.e., the sequence is a "Barker-like" sequence in the periodic sense).

For real sequences, a constant-magnitude DFT means the sequence is a **Zadoff-Chu** sequence (for complex) or a **Barker** sequence (for binary real). For real non-negative, the best we can do is approximate.

def fast_conv(a):
    """FFT-based linear convolution (autocorrelation)."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]

def compute_J(a):
    """Compute the objective function."""
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))

def compute_J_normalized(a):
    """Compute J assuming sum(a)=1 (for speed during optimization)."""
    b = fast_conv(a)
    return float(2 * len(a) * b.max())

def lse_grad(a, tau):

    Compute gradient of LSE approximation of max(conv(a,a)).

    grad_j = 2 * sum_k w_k * a[k-j] (for valid k-j)
    This is a cross-correlation computable via FFT.

    b = fast_conv(a)
    b_max = b.max()

    exp_b = np.exp(tau * (b - b_max))
    p = exp_b / exp_b.sum()  # p has length 2n-1

    fp = np.fft.rfft(p, size)
    fa = np.fft.rfft(a, size)

    # corr(j) = sum_i p(j+i) a(i) = sum_i p(j+i) a(i)
    # Let q = p reversed (q[k] = p[2n-2-k]), then:
    # corr(j) = sum_i q(2n-2-j-i) a(i) = (q * a)(2n-1-j)  [convolution]

    # corr(j) = <shifted_p, a> where shifted_p[i] = p[j+i]
    # = sum_{i=0}^{n-1} p[j+i] * a[i]

    # This gives circular cross-correlation r[m] = sum_i p[(m+i) mod size] * a[i]

    # cross[a, p](j) = sum_i a[i] * p[i+j]
    
    # Using FFT: cross-correlation = ifft(fft(a) * conj(fft(p)))
    # But we need to be careful about the definition.

    pa[:n] = a
    pp = np.zeros(size)
    pp[:2*n-1] = p

    # which is valid. Good.
    
    grad_vec = cross[size - np.arange(n)]
    # Hmm wait, for j=0: cross[size-0] = cross[size] which is index 0 (circular). Let me re-examine.
    # cross has indices 0 to size-1. cross[size-0] would be cross[size] which wraps to cross[0].
    # cross[0] = sum_i a[i] p[i-0] = sum_i a[i] p[i]. That's correct for j=0!
    # cross[1] = sum_i a[i] p[i-1]. For i=0, p[-1 mod size] = p[size-1] = 0 (since size > 2n-1). 
    # So cross[1] = sum_{i=1}^{n-1} a[i] p[i-1]. That's the cross-correlation at lag 1!
    
    # Actually I think I had the sign wrong. Let me redefine:
    # cross[m] = sum_i a[i] * p[(i - m) mod size]
    # For m=0: sum_i a[i] p[i] ✓ (this is what we want for j=0)
    # For m=1: sum_i a[i] p[i-1] = sum_{i=1}^{n-1} a[i] p[i-1]
    #   But we want sum_i a[i] p[i+1] for j=1.
    #   sum_i a[i] p[i+1] = sum_{i=0}^{n-2} a[i] p[i+1]
    #   This is cross[-1] = cross[size-1].
    
    # So: result[j] = cross[size-j] for j > 0, and cross[0] for j=0.
    # In numpy: indices [0, size-1, size-2, ..., size-(n-1)]
    
    idx = np.zeros(n, dtype=int)
    idx[0] = 0
    idx[1:] = size - np.arange(1, n)
    grad_vec = cross[idx]
    
    grad = 2.0 * grad_vec
    return grad, lse_val, p

def fista_lse(a, tau_init, tau_max, max_iters, deadline, tracker, lr_init=None):
    """
    FISTA (fast iterative shrinkage-thresholding / accelerated gradient)
    on the LSE-smoothed approximation of max(conv(a,a)).
    Works in normalized space (sum a = 1).
    """
    n = len(a)
    a = np.maximum(a.astype(np.float64), 1e-10)
    a /= a.sum()
    
    if lr_init is None:
        lr_init = 1.0 / (n * tau_init)
    
    current_J = compute_J(a)
    tracker.update(a)
    
    tau = tau_init
    lr = lr_init
    momentum = 2.0 / (3.0 + np.sqrt(1.0 + 12.0 * lr * lr * tau * tau))  # FISTA momentum
    
    a_curr = a.copy()
    y = a.copy()  # FISTA iterate
    t_kk = 1.0  # FISTA parameter
    
    best_J = current_J
    best_a = a.copy()
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        # Compute gradient of LSE at y
        grad_y, lse_val, p_y = lse_grad(y, tau)
        
        # FISTA update: a_new = y - lr * grad_y, project to simplex (a>=0, sum=1)
        a_new = y - lr * grad_y
        a_new = np.maximum(a_new, 1e-10)
        a_new /= a_new.sum()
        
        # Evaluate
        J_new = compute_J_normalized(a_new)
        
        # FISTA momentum update for y
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t_kk * t_kk)) / 2.0
        y = a_new + (t_kk - 1.0) / t_new * (a_new - a_curr)
        y = np.maximum(y, 1e-10)
        y /= y.sum()
        t_kk = t_new
        a_curr = a_new
        
        # Update
        if J_new < best_J:
            best_J = J_new
            best_a = a_new.copy()
            # Increase tau slowly (sharper approximation of max)
            if tau < tau_max:
                tau = min(tau_max, tau * 1.005)
                lr = 1.0 / (n * tau)
        else:
            # Reduce learning rate
            lr *= 0.8
            if lr < 1e-14:
                break
        
        if it % 20 == 0:
            tracker.update(best_a)
    
    tracker.update(best_a)
    return best_a

def plain_gradient_lse(a, tau_init, tau_max, max_iters, deadline, tracker):
    """Plain gradient descent with backtracking on LSE."""
    n = len(a)
    a = np.maximum(a.astype(np.float64), 1e-10)

    tau = tau_init

        if it % 30 == 0:

    tracker.update(a)

def active_set_lagrangian(a, max_iters, deadline, tracker):
    """
    Use Lagrangian dual: minimize max_k conv(a,a)_k subject to sum(a)=1, a>=0.
    At optimum, the active set A has KKT conditions.
    Iteratively: identify active set, solve subproblem on active set.
    """
    n = len(a)
    a = np.maximum(a.astype(np.float64), 1e-10)
    a /= a.sum()
    current_J = compute_J(a)
    tracker.update(a)
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        M = b.max()
        
        # Identify active set (indices within epsilon of max)
        eps = 1e-6 * M + 1e-10
        active = np.where(b >= M - eps)[0]
        
        if len(active) == 0:
            active = np.array([np.argmax(b)])
        
        # Gradient of the Lagrangian: 
        # L(a) = M + sum_{k in active} lambda_k * (conv(a,a)_k - M)
        # At optimum, gradient = 0 (projected)
        # grad_j = sum_{k in active} lambda_k * 2*a[k-j]
        # We want this to be constant (= mu) for all j with a_j > 0.
        
        # Compute the "pressure" at each point:
        # pressure[j] = sum_{k in active} 2 * p[k] * a[k-j]  (where p is uniform over active)
        p = np.zeros(2*n-1)
        p[active] = 1.0 / len(active)
        
        # Cross-correlation of p with a (same as lse_grad but with uniform p on active)
        size = 1
        while size < 3 * n:
            size <<= 1
        pa = np.zeros(size)
        pa[:n] = a
        pp = np.zeros(size)
        pp[:2*n-1] = p
        faf = np.fft.rfft(pa)
        fpf = np.fft.rfft(pp)
        cross = np.fft.irfft(faf * np.conj(fpf), size)
        
        idx = np.zeros(n, dtype=int)
        idx[0] = 0
        idx[1:] = size - np.arange(1, n)
        pressure = 2.0 * cross[idx]
        
        # The update direction: reduce pressure where it's high
        # a_new_j proportional to a_j * (1 - lr * pressure_j) for positive a_j
        # Or: a_new = a - lr * (pressure - mean(pressure[a>0])) for a>0
        pos_mask = a > 1e-10
        if pos_mask.sum() == 0:
            break
        mean_pressure = pressure[pos_mask].mean()
        direction = pressure - mean_pressure
        direction[~pos_mask] = 0
        
        # Backtracking line search
        lr = 0.5 / (n * max(M, 1e-10))
        for _ in range(20):
            a_new = a - lr * direction
            a_new = np.maximum(a_new, 1e-10)
            a_new /= a_new.sum()
            J_new = compute_J_normalized(a_new)
            if J_new < current_J - 1e-15:
                a = a_new
                current_J = J_new
                break
            lr *= 0.5
        else:
            break
        
        if it % 10 == 0:
            tracker.update(a)
    
    tracker.update(a)
    return a

def lp_best_response(a, M, time_limit=5):
    """LP: maximize sum(g) subject to conv(a,g) <= M, g >= 0."""
    n = len(a)
    rows = []
    cols = []
    vals = []
    for k in range(2*n-1):
        i_min = max(0, k - n + 1)
        i_max = min(n - 1, k)
        for i in range(i_min, i_max + 1):
            j = k - i
            if 0 <= j < n:
                rows.append(k)
                cols.append(i)
                vals.append(a[j])
    
    A = csr_matrix((vals, (rows, cols)), shape=(2*n-1, n))
    c = -np.ones(n)
    b_ub = np.full(2*n-1, M)
    bounds = [(0, None)] * n
    r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                options={'presolve': True, 'time_limit': time_limit})
    if r.success and r.x is not None:
        g = np.maximum(r.x, 0)
        if g.sum() > 1e-10:
            return g
    return None

def lp_opt_iteration(a, deadline, tracker, n_lp=20, tighten=0.02, min_slots=20):
    """LP-based optimization loop."""
    n = len(a)
    a = np.maximum(a.astype(np.float64), 1e-8)
    a /= a.sum()
    current_J = compute_J(a)
    tracker.update(a)
    
    used = 0
    for it in range(n_lp):
        if time.monotonic() > deadline - min_slots:
            break
        b = fast_conv(a)
        M = float(b.max())
        M_tight = M * (1.0 - tighten)
        
        g = lp_best_response(a, M_tight, time_limit=3)
        if g is None:
            g = lp_best_response(a, M, time_limit=3)
        if g is None:
            break
        g = np.maximum(g, 0)
        gs = g.sum()
        if gs < 1e-10:
            break
        g /= gs
        
        # Line search over mixing parameter
        used += 1
        best_a = None
        best_J = current_J
        for t in [0.3, 0.5, 0.7, 0.9, 0.1, 0.4, 0.6, 0.8]:
            a_trial = (1.0 - t) * a + t * g
            a_trial = np.maximum(a_trial, 0)
            ss = a_trial.sum()
            if ss < 1e-10:
                continue
            a_trial /= ss
            J_trial = compute_J(a_trial)
            if J_trial < best_J - 1e-14:
                best_J = J_trial
                best_a = a_trial
                used += 1
        
        if best_a is None:
            break
        a = best_a
        current_J = best_J
        if it % 5 == 0:
            tracker.update(a)
    
    tracker.update(a)
    return a

# ============ Initializations ============

def low_autocorrelation_init(n, rng):
    """
    Generate a sequence with low aperiodic autocorrelation.
    Uses the approach of iteratively adjusting a random sequence to flatten
    its autocorrelation, starting from a well-known structure.
    """
    # Start with a chirp-like real sequence
    t = np.arange(n) / n
    # Real part of a chirp, rectified
    a = np.abs(np.cos(2 * np.pi * t * t * 2)) + 0.1
    a = np.maximum(a, 0.01)
    a /= a.sum()
    
    # Quick gradient descent to flatten autocorrelation
    tau = 50.0
    lr = 0.1 / n
    for _ in range(50):
        b = fast_conv(a)
        M = b.max()
        exp_b = np.exp(tau * (b - M))
        p = exp_b / exp_b.sum()
        
        size = 1
        while size < 3 * n:
            size <<= 1
        pa = np.zeros(size)
        pa[:n] = a
        pp = np.zeros(size)
        pp[:2*n-1] = p
        cross = np.fft.irfft(np.fft.rfft(pa) * np.conj(np.fft.rfft(pp)), size)
        idx = np.zeros(n, dtype=int)
        idx[0] = 0
        idx[1:] = size - np.arange(1, n)
        grad = 2.0 * cross[idx]
        
        a = a - lr * grad
        a = np.maximum(a, 1e-8)
        a /= a.sum()
    
    return a

def hann_window_init(n, rng):
    """Hann window with random phase modulation."""
    t = np.linspace(0, 1, n)
    w = 0.5 * (1 - np.cos(2 * np.pi * t))
    # Add controlled randomness
    n_harm = rng.integers(2, 6)
    for _ in range(n_harm):
        freq = rng.uniform(1, n // 3)
        phase = rng.uniform(0, 2 * np.pi)
        w += 0.1 * np.cos(2 * np.pi * freq * t + phase)
    w = np.maximum(w, 0.01)
    w /= w.sum()
    return w

def multi_peak_init(n, rng):
    """Sequence with multiple peaks to spread energy."""
    n_peaks = rng.integers(3, 8)
    positions = np.sort(rng.uniform(0, 1, n_peaks))
    widths = rng.uniform(0.02, 0.1, n_peaks)
    heights = rng.uniform(0.5, 1.5, n_peaks)
    t = np.linspace(0, 1, n)
    a = 0.1
    for pos, wid, ht in zip(positions, widths, heights):
        a += ht * np.exp(-0.5 * ((t - pos) / wid) ** 2)
    a = np.maximum(a, 0.01)
    a /= a.sum()
    return a

def random_fourier_init(n, rng, n_bands=8):
    """Random Fourier coefficients with limited bandwidth."""
    half = n // 2 + 1
    coeffs = np.zeros(half)
    # Random amplitudes with roll-off
    for k in range(min(n_bands, half)):
        coeffs[k] = rng.normal(0, 1.0 / (1 + 0.3 * k))
    # Make real and symmetric
    A = np.zeros(n, dtype=complex)
    A[:half] = coeffs
    for k in range(1, n - n // 2):
        A[k] = np.conj(A[n - k])
    a = np.fft.ifft(A).real
    a = np.abs(a) + 0.1
    a /= a.sum()
    return a

def generate_inits(n, rng, parent=None):
    """Generate diverse initializations."""
    inits = []
    
    if parent is not None:
        # Resample parent
        if parent.size != n:
            t_old = np.linspace(0, 1, parent.size)
            t_new = np.linspace(0, 1, n)
            p_res = np.interp(t_new, t_old, parent)
        else:
            p_res = parent.copy()
        p_res = np.maximum(p_res, 0.01)
        p_res /= p_res.sum()
        inits.append(p_res)
        # Reversed
        p_rev = p_res[::-1].copy()
        inits.append(p_rev)
    
    inits.append(low_autocorrelation_init(n, rng))
    inits.append(hann_window_init(n, rng))
    inits.append(multi_peak_init(n, rng))
    inits.append(random_fourier_init(n, rng, n_bands=6))
    inits.append(random_fourier_init(n, rng, n_bands=12))
    
    # Uniform
    inits.append(np.ones(n) / n)
    
    # Cosine windows with different orders
    t = np.linspace(0, 1, n)
    for m in [1, 2, 3]:
        w = (1 - (2*t - 1)**(2*m)) ** m
        w = np.maximum(w, 0.01)
        w /= w.sum()
        inits.append(w)
    
    # Sawtooth-like
    inits.append(np.abs(2*t - 1) + 0.1)
    inits[-1] /= inits[-1].sum()
    
    # Random smooth
    x = np.cumsum(rng.normal(0, 1, n))
    x = x - x.min() + 0.1
    # Smooth
    kernel = np.ones(5) / 5
    x = np.convolve(x, kernel, mode='same')
    x = np.maximum(x, 0.01)
    x /= x.sum()
    inits.append(x)
    
    # Normalize all
    for i in range(len(inits)):
        inits[i] = np.maximum(inits[i], 0.01).astype(np.float64)
        inits[i] /= inits[i].sum()
    
    return inits

# ============ Score tracker ============

class ScoreTracker:
    def __init__(self):
        self.best = None
        self.best_score = float('inf')
        self.t_start = time.monotonic()
    
    def update(self, a):
        a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
        if a.size == 0 or a.sum() < 0.01:
            return
        score = float(evaluate_sequence(a.tolist()))
        if np.isfinite(score) and score < self.best_score:
            self.best = a.copy()
            self.best_score = score
            elapsed = time.monotonic() - self.t_start
            print(f"  * J={score:.8f} n={a.size} t={elapsed:.1f}s", flush=True)
    
    def report(self, label=""):
        if self.best is not None:
            print(f"  {label} best: J={self.best_score:.8f} n={self.best.size}", flush=True)

# ============ Coordinate descent ============

def coordinate_descent(a, max_steps, deadline, tracker):
    """Coordinate-wise optimization with exact line search."""
    a = np.maximum(a.astype(np.float64), 1e-10)
    a /= a.sum()
    n = len(a)
    current_J = compute_J(a)
    tracker.update(a)
    rng = np.random.default_rng(42)
    
    # Precompute which indices are affected by changing a[j]
    # Changing a[j] affects conv(a,a)[k] for k in [j, j+2*(n-1)-j] = [0, 2n-2] (all)
    # Specifically: conv(a,a)[k] includes terms a[j]*a[k-j] and a[k-j]*a[j]
    # So changing a[j] by delta changes conv(a,a)[k] by:
    #   2*delta*a[k-j] (if 0<=k-j<n) + delta^2 (if k=j)
    
    steps = 0
    for _ in range(max_steps):
        if time.monotonic() > deadline:
            break
        if steps > 500 * n:
            break
        
        j = rng.integers(0, n)
        current_val = a[j]
        if current_val < 1e-10:
            steps += 1
            continue
        
        # Try different scales
        best_trial = None
        best_J = current_J
        for scale in [0.5, 0.7, 1.3, 1.7, 0.3, 2.0, 0.85, 1.15]:
            a_trial = a.copy()
            a_trial[j] = current_val * scale
            a_trial = np.maximum(a_trial, 1e-10)
            ss = a_trial.sum()
            if ss < 1e-10:
                continue
            a_trial /= ss
            J_trial = compute_J(a_trial)
            if J_trial < best_J - 1e-14:
                best_J = J_trial
                best_trial = a_trial
                steps += 1
        
        if best_trial is not None:
            a = best_trial
            current_J = best_J
            if (steps - a.size * 50) % 200 == 0:
                tracker.update(a)
        else:
            steps += 1
    
    tracker.update(a)
    return a

# ============ Main proposal function ============

def propose_candidate(seed=42, budget_s=1500, **kwargs):
    """
    Main optimization loop combining:
    1. FISTA on LSE-smoothed objective
    2. LP-based best response
    3. Active-set Lagrangian
    4. Coordinate descent polish
    5. Multi-length search
    """
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + float(budget_s) - 30.0
    tracker = ScoreTracker()
    
    # Load parent
    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        if p.ndim == 1 and p.size > 0 and np.all(np.isfinite(p)):
            parent = np.maximum(p, 0.0)
            parent /= parent.sum()
            tracker.update(parent)
            print(f"Parent: n={parent.size}, J={tracker.best_score:.8f}", flush=True)
    except (NameError, AttributeError):
        print("No parent available, starting from scratch.", flush=True)
    
    # ============ Phase 1: Multi-length FISTA + LP ============
    print(f"\n{'='*60}", flush=True)
    print("Phase 1: Multi-length FISTA + LP optimization", flush=True)
    print(f"{'='*60}", flush=True)
    
    lengths = [512, 640, 768, 896]
    if parent is not None:
        lengths.insert(0, parent.size)
    
    # Remove duplicates and sort
    lengths = sorted(set(lengths))
    
    # Budget allocation: give more time to lengths near the best
    # Phase 1 should use about 50% of total time
    phase1_deadline = time.monotonic() + (float(budget_s) - 60) * 0.45
    
    for n in lengths:
        t_start = time.monotonic()
        time_left = phase1_deadline - t_start
        if time_left < 30:
            continue
        
        print(f"\n--- n={n} ---", flush=True)
        
        # Time budget for this length
        t_budget = min(time_left - 10, (float(budget_s) - 60) * 0.45 / len(lengths))
        if t_budget < 20:
            t_budget = 20
        
        inits = generate_inits(n, rng, parent)
        best_for_n = None
        best_J_for_n = float('inf')
        
        # Try each initialization with FISTA + LP
        init_time = max(15.0, t_budget / (len(inits) + 2))
        
        for idx, a0 in enumerate(inits):
            t0 = time.monotonic()
            if t0 > t_start + t_budget - 15:
                break
            
            # FISTA phase
            t_fista_end = min(t0 + init_time * 0.6, t_start + t_budget - 10)
            a = fista_lse(a0, tau_init=30, tau_max=200,
                         max_iters=500, deadline=t_fista_end,
                         tracker=tracker)
            
            # LP phase
            if time.monotonic() < t_start + t_budget - 5:
                t_lp_end = min(t0 + init_time, t_start + t_budget - 5)
                a = lp_opt_iteration(a, t_lp_end, tracker, n_lp=10, tighten=0.02)
            
            # Quick LSE polish
            if time.monotonic() < t_start + t_budget - 3:
                a = plain_gradient_lse(a, tau_init=80, tau_max=300,
                                      max_iters=100, deadline=t_start + t_budget - 3,
                                      tracker=tracker)
            
            J = compute_J(a)
            if J < best_J_for_n:
                best_J_for_n = J
                best_for_n = a.copy()
            
            if (t0 - t_start) % (init_time * 2) < init_time:
                print(f"    init {idx}: J={J:.8f} ({time.monotonic()-t0:.1f}s)", flush=True)
        
        if best_for_n is not None:
            tracker.update(best_for_n)
            if parent is None or best_J_for_n < compute_J(
                np.interp(np.linspace(0,1,best_for_n.size), 
                         np.linspace(0,1,parent.size), parent) if parent.size != best_for_n.size else parent):
                parent = best_for_n
            print(f"  Phase1 n={n}: J={best_J_for_n:.8f} ({time.monotonic()-t_start:.1f}s)", flush=True)
    
    tracker.report("After Phase 1")
    
    # ============ Phase 2: Focused refinement on best length ============
    if tracker.best is not None and time.monotonic() < deadline - 120:
        print(f"\n{'='*60}", flush=True)
        print("Phase 2: Focused refinement", flush=True)
        print(f"{'='*60}", flush=True)
        
        n = tracker.best.size
        a = tracker.best.copy().astype(np.float64)
        a /= a.sum()
        
        # Interleaved FISTA + LP + Active-set
        t_phase2_end = min(deadline - 60, time.monotonic() + (float(budget_s) - 60) * 0.3)
        
        for round_num in range(10):
            if time.monotonic() > t_phase2_end:
                break
            
            # FISTA
            t_sub = min(time.monotonic() + 30, t_phase2_end - 5)
            a = fista_lse(a, tau_init=100, tau_max=500,
                         max_iters=300, deadline=t_sub, tracker=tracker)
            
            # LP
            if time.monotonic() < t_phase2_end - 5:
                t_sub = min(time.monotonic() + 30, t_phase2_end - 5)
                a = lp_opt_iteration(a, t_sub, tracker, n_lp=8, tighten=0.015)
            
            # Active-set Lagrangian
            if time.monotonic() < t_phase2_end - 5:
                t_sub = min(time.monotonic() + 20, t_phase2_end - 5)
                a = active_set_lagrangian(a, max_iters=50, deadline=t_sub, tracker=tracker)
            
            print(f"  Round {round_num}: J={compute_J(a):.8f} ({time.monotonic()-tracker.t_start:.1f}s)", flush=True)
        
        tracker.report("After Phase 2")
    
    # ============ Phase 3: Escape local minima with perturbation ============
    if tracker.best is not None and time.monotonic() < deadline - 80:
        print(f"\n{'='*60}", flush=True)
        print("Phase 3: Perturbation + re-optimization", flush=True)
        print(f"{'='*60}", flush=True)
        
        n = tracker.best.size
        base = tracker.best.copy().astype(np.float64)
        base /= base.sum()
        
        t_phase3_end = min(deadline - 50, time.monotonic() + (float(budget_s) - 60) * 0.15)
        
        for pert_num in range(20):
            if time.monotonic() > t_phase3_end:
                break
            
            # Different perturbation strategies
            strategy = pert_num % 4
            if strategy == 0:
                # Gaussian noise
                a = base + rng.normal(0, 0.05, n)
            elif strategy == 1:
                # Sparse perturbation
                a = base.copy()
                n_pert = n // 10
                idx = rng.choice(n, n_pert, replace=False)
                a[idx] += rng.normal(0, 0.1, n_pert)
            elif strategy == 2:
                # Frequency-domain perturbation
                A = np.fft.rfft(base, n)
                A[rng.choice(len(A), len(A)//5, replace=False)] += rng.normal(0, 0.5, len(A)//5)
                a = np.fft.irfft(A, n)
            else:
                # Scale perturbation (multiply by random smooth function)
                t = np.linspace(0, 1, n)
                smooth = 1.0 + 0.2 * np.cos(2*np.pi*rng.uniform(1,5)*t + rng.uniform(0,6.28))
                a = base * smooth
            
            a = np.maximum(a, 1e-8)
            a /= a.sum()
            
            # Quick optimization
            t_sub = min(time.monotonic() + 10, t_phase3_end - 5)
            a = fista_lse(a, tau_init=50, tau_max=300, max_iters=200, deadline=t_sub, tracker=tracker)
            if time.monotonic() < t_phase3_end - 3:
                a = plain_gradient_lse(a, tau_init=100, tau_max=400, max_iters=100,
                                      deadline=t_phase3_end - 3, tracker=tracker)
        
        tracker.report("After Phase 3")
    
    # ============ Phase 4: Final polish ============
    if tracker.best is not None:
        print(f"\n{'='*60}", flush=True)
        print("Phase 4: Final polish (coordinate descent + fine LSE)", flush=True)
        print(f"{'='*60}", flush=True)
        
        a = tracker.best.copy().astype(np.float64)
        a /= a.sum()
        
        # Coordinate descent
        t_coord_end = min(deadline - 20, time.monotonic() + (float(budget_s) - 60) * 0.1)
        a = coordinate_descent(a, max_steps=100000, deadline=t_coord_end, tracker=tracker)
        
        # Fine LSE
        if time.monotonic() < deadline - 5:
            a = plain_gradient_lse(a, tau_init=200, tau_max=1000,
                                  max_iters=500, deadline=deadline - 5, tracker=tracker)
        
        # Final LP polish
        if time.monotonic() < deadline - 2:
            a = lp_opt_iteration(a, deadline - 1, tracker, n_lp=5, tighten=0.005, min_slots=5)
        
        tracker.report("After Phase 4")
    
    # ============ Fallback ============
    if tracker.best is None:
        print("WARNING: No valid solution found! Using uniform fallback.", flush=True)
        tracker.best = np.ones(256, dtype=np.float64)
        tracker.best_score = compute_J(tracker.best)
        tracker.update(tracker.best)
    
    final_score = compute_J(tracker.best)
    print(f"\n{'='*60}", flush=True)
    print(f"FINAL: J={tracker.best_score:.8f} (compute_J={final_score:.8f}) n={tracker.best.size}", flush=True)
    print(f"Total time: {time.monotonic() - tracker.t_start:.1f}s", flush=True)
    print(f"{'='*60}", flush=True)
    
    return [float(x) for x in tracker.best]
