**Idea: "Autocorrelation shaping" via frequency domain**

The DFT of a is A. The circular autocorrelation is |A|^2 (up to normalization). The linear autocorrelation is different but related.

For a long sequence (n >> 1), the linear and circular autocorrelations are similar in the "bulk" (for lags not too close to 0 or n-1). So we can approximately work in the frequency domain.

We want |A_k|^2 to be as flat as possible. This is equivalent to wanting A to have constant magnitude (a "flat spectrum" sequence). For a real, non-negative sequence, this is related to the concept of "transform-limit" sequences.

Algorithm:
1. Compute A = DFT(a)
2. Compute |A|^2 (power spectrum)
3. The "peak" in the power spectrum corresponds to the "peak" in the autocorrelation
4. Apply a nonlinearity to |A|: |A|_new = |A|^α for α < 1 (compresses peaks)
   Or: |A|_new = min(|A|, B) (clips peaks)
5. Reconstruct: a_new = IDFT(A_phase * |A|_new) where A_phase = A/|A|
6. Project a_new to be non-negative and sum to 1

This is essentially the "frequency domain" version of peak reduction, similar to the Müller-Andrade algorithm for PAPR reduction.

Actually, wait. The linear autocorrelation is not the same as the circular autocorrelation. Let me think about this more carefully.

For a sequence a of length n, the circular autocorrelation is:
R_circ[k] = sum_j a_j * a_{(j+k) mod n}

The DFT relationship: DFT(R_circ) = |A|^2 (up to normalization).

The linear autocorrelation is:
R_lin[k] = sum_j a_j * a_{j+k} (for k = 0, ..., n-1)
R_lin[k] = sum_j a_j * a_{j-k} (for k = -(n-1), ..., -1) = R_lin[-k]

The DFT of the zero-padded sequence gives the DTFT, and |DTFT|^2 is related to the linear autocorrelation.

Specifically, if we zero-pad a to length N >= 2n-1 and compute the DFT, then |DFT_N(a)|^2 (inverse DFT) gives the circular autocorrelation of the zero-padded sequence, which equals the linear autocorrelation (because the zero-padding prevents wrap-around).

So: 
1. Zero-pad a to length N >= 2n-1 (use N = next power of 2)
2. Compute A = FFT_N(a_padded)
3. |A|^2 gives the (circular) autocorrelation of the padded sequence = linear autocorrelation
4. To reduce peaks: modify |A|, keep phase, IFFT, take real part, clip to [0, ∞), truncate to length n, normalize

This is a valid approach! Let me implement it.

The key question is: what nonlinearity to apply to |A|?
- Clipping: |A|_new = min(|A|, threshold) - simple but can create artifacts
- Power compression: |A|_new = |A|^α for α in (0,1) - smooth
- Iterative: apply the nonlinearity, check if the result is non-negative, if not, adjust

```python
def freq_domain_peak_reduction(a, alpha=0.5, n_iters=100):
    n = len(a)
    N = 1
    while N < 2*n - 1:
        N <<= 1
    for _ in range(n_iters):
        a_pad = np.zeros(N)
        a_pad[:n] = a
        A = np.fft.fft(a_pad)
        mag = np.abs(A)
        phase = np.angle(A)
        # Apply power compression
        mag_new = mag ** alpha  # compress peaks
        A_new = mag_new * np.exp(1j * phase)
        a_new = np.fft.ifft(A_new).real[:n]
        a_new = np.maximum(a_new, 0)
        s = a_new.sum()
        if s < 1e-10:
            break
        a_new /= s
        if np.allclose(a_new, a, atol=1e-12):
            break
        a = a_new
    return a
```

```python
"""
Minimizes J(a) = 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Frequency-domain peak reduction (Müller-Andrade style)
2. Adaptive LSE gradient descent with Riemannian (multiplicative) updates
3. Alternating spectral/gradient optimization
4. LP-based escape for local minima
5. Multi-length, multi-initialization search
6. Sum-of-squares autocorrelation shaping
"""

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time

# Cache for sparsity pattern
_spar_cache = {}

def get_sparsity(n):
    if n not in _spar_cache:
        rows = []
        cols = []
        for k in range(2 * n - 1):
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            rows.extend([k] * (je - js + 1))
            cols.extend(range(js, je + 1))
        _spar_cache[n] = (np.array(rows, dtype=np.int32), np.array(cols, dtype=np.int32), len(rows))
    return _spar_cache[n]

def fast_conv(a):
    n = len(a)
    s = 1
    while s < 2 * n - 1:
        s <<= 1
    fa = np.fft.rfft(a, s)
    return np.fft.irfft(fa * fa, s)[:2 * n - 1]

def compute_J(a):
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))

def normalize_one(a):
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        return a
    return a / s

class ScoreTracker:
    def __init__(self):
        self.best = None
        self.best_score = float('inf')
        self.t_start = time.monotonic()
    
    def update(self, a):
        a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
        if a.size == 0 or a.sum() < 0.01:
            return
        score = float(evaluate_sequence(a.tolist()))
        if np.isfinite(score) and score < self.best_score:
            self.best = a.copy()
            self.best_score = score
            elapsed = time.monotonic() - self.t_start
            print(f"  * J={score:.8f} n={a.size} t={elapsed:.1f}s", flush=True)
    
    def report(self, label=""):
        if self.best is not None:
            print(f"  {label} best: J={self.best_score:.8f} n={self.best.size}", flush=True)

def freq_domain_smooth(a, alpha=0.7, n_iters=50, deadline=None):
    """Frequency-domain peak reduction via spectral shaping."""
    n = len(a)
    N = 1
    while N < 2 * n - 1:
        N <<= 1
    a = a.copy().astype(np.float64)
    a = normalize_one(a)
    
    for it in range(n_iters):
        if deadline is not None and time.monotonic() > deadline:
            break
        a_pad = np.zeros(N)
        a_pad[:n] = a
        A = np.fft.fft(a_pad)
        mag = np.abs(A)
        mag_max = mag.max()
        if mag_max < 1e-15:
            break
        # Power compression: raise to alpha power (alpha < 1 compresses peaks)
        mag_new = mag ** alpha
        phase = A / (mag + 1e-30)
        A_new = mag_new * phase
        a_new = np.fft.ifft(A_new).real[:n]
        a_new = np.maximum(a_new, 0.0)
        s = a_new.sum()
        if s < 1e-10:
            break
        a_new /= s
        if np.max(np.abs(a_new - a)) < 1e-14:
            break
        a = a_new
    return a

def lse_gradient_step(a, tau, lr, deadline=None):
    """One step of LSE gradient descent with multiplicative update."""
    n = len(a)
    b = fast_conv(a)
    b_max = b.max()
    exp_b = np.exp(tau * (b - b_max))
    p = exp_b / exp_b.sum()
    
    # Gradient of LSE: sum_k p_k * d(b_k)/da
    # d(b_k)/da_i = 2*a[k-i] if 0 <= k-i < n
    # Use FFT for efficiency
    N = 1
    while N < 3 * n:
        N <<= 1
    fp = np.fft.rfft(p, N)
    fa = np.fft.rfft(a, N)
    # correlation: sum_k p_k * a[k-i] = (p * a)(i) in circular sense
    # We need: grad[i] = 2 * sum_k p[k] * a[k-i] (where valid)
    # This is the cross-correlation of p and a, evaluated at lags 0..n-1
    corr = np.fft.irfft(fp * np.conj(fa), N)
    # corr[d] = sum_k p[k] * a[k-d] (circular)
    # For our purposes, we want sum_k p[k] * a[k-i] for i=0..n-1
    # This is corr[i] (the first n values)
    grad = 2.0 * corr[:n]
    
    # Multiplicative (Riemannian) update
    a_new = a * np.exp(-lr * grad)
    a_new = np.maximum(a_new, 1e-15)
    a_new /= a_new.sum()
    return a_new, grad

def lse_optimize(a, max_iters, deadline, tracker, tau0=20.0, tau_max=200.0, lr0=None):
    """Adaptive LSE gradient descent with multiplicative updates."""
    n = len(a)
    a = a.copy().astype(np.float64)
    a = normalize_one(a)
    current_J = compute_J(a)
    tracker.update(a)
    
    tau = tau0
    if lr0 is None:
        lr = 1.0 / (n * 10.0)
    else:
        lr = lr0
    momentum = 0.7
    v = np.zeros(n)
    stuck_count = 0
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        b_max = b.max()
        exp_b = np.exp(tau * (b - b_max))
        p = exp_b / exp_b.sum()
        
        N = 1
        while N < 3 * n:
            N <<= 1
        fp = np.fft.rfft(p, N)
        fa = np.fft.rfft(a, N)
        corr = np.fft.irfft(fp * np.conj(fa), N)
        grad = 2.0 * corr[:n]
        
        v = momentum * v + (1.0 - momentum) * grad
        a_new = a * np.exp(-lr * v)
        a_new = np.maximum(a_new, 1e-15)
        a_new /= a_new.sum()
        
        J_new = compute_J(a_new)
        if J_new < current_J - 1e-15:
            a = a_new
            current_J = J_new
            stuck_count = 0
            tau = min(tau_max, tau * 1.02)
            lr = min(lr * 1.01, 2.0 / (n * tau))
        else:
            stuck_count += 1
            lr *= 0.6
            v *= 0.5
            if lr < 1e-18:
                break
        if it % 50 == 0:
            tracker.update(a)
    
    tracker.update(a)
    return a

def sumsq_optimize(a, max_iters, deadline, tracker, target_ratio=0.3):
    """Minimize sum of squared deviations of autocorrelation from target."""
    n = len(a)
    a = a.copy().astype(np.float64)
    a = normalize_one(a)
    b = fast_conv(a)
    b_mean = b.sum() / len(b)  # = 1/(2n-1) for sum(a)=1
    # Target: slightly above mean to allow for boundary effects
    target = b_mean * (1.0 + target_ratio)
    
    current_J = compute_J(a)
    tracker.update(a)
    
    lr = 0.1 / n
    stuck = 0
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        # Gradient of sum_k (b_k - target)^2 w.r.t. a_i
        # = 2 * sum_k (b_k - target) * 2*a[k-i] (if valid)
        # = 4 * (p * a)(i) where p_k = b_k - target
        p = b - target
        N = 1
        while N < 3 * n:
            N <<= 1
        fp = np.fft.rfft(p, N)
        fa = np.fft.rfft(a, N)
        corr = np.fft.irfft(fp * np.conj(fa), N)
        grad = 4.0 * corr[:n]
        
        a_new = a - lr * grad
        a_new = np.maximum(a_new, 1e-8)
        a_new /= a_new.sum()
        
        # Ensure we're still reducing the peak (not just the sum of squares)
        J_new = compute_J(a_new)
        if J_new < current_J - 1e-15:
            a = a_new
            current_J = J_new
            stuck = 0
            lr = min(lr * 1.05, 1.0 / n)
        else:
            stuck += 1
            lr *= 0.7
            if lr < 1e-18:
                break
        if it % 100 == 0:
            tracker.update(a)
    
    tracker.update(a)
    return a

def lp_best_response(a, M, time_limit=5):
    """Find g that maximizes sum(g) subject to conv(a,g) <= M, g >= 0."""
    n = len(a)
    rows, cols, nnz = get_sparsity(n)
    vals = np.empty(nnz)
    for i in range(nnz):
        k = rows[i]
        j = cols[i]
        vals[i] = a[k - j]
    A = csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                options={'presolve': True, 'time_limit': time_limit})
    if r.success and r.x is not None:
        g = np.maximum(r.x, 0.0)
        if g.sum() > 1e-10:
            return g
    return None

def lp_escape(a, deadline, tracker, n_iterations=10, tighten=0.02):
    """Use LP to escape local minima."""
    n = len(a)
    a = a.copy().astype(np.float64)
    a = normalize_one(a)
    current_J = compute_J(a)
    
    for it in range(n_iterations):
        if time.monotonic() > deadline:
            break
        b = fast_conv(a)
        M = float(b.max())
        M_tight = M * (1.0 - tighten)
        g = lp_best_response(a, M_tight, time_limit=3)
        if g is None:
            g = lp_best_response(a, M, time_limit=3)
        if g is None:
            break
        g = normalize_one(g)
        
        best_a = None
        best_J = current_J
        for t in [0.1, 0.2, 0.3, 0.5, 0.7, 0.9]:
            a_trial = (1.0 - t) * a + t * g
            a_trial = normalize_one(a_trial)
            J_trial = compute_J(a_trial)
            if J_trial < best_J - 1e-14:
                best_J = J_trial
                best_a = a_trial
        if best_a is None:
            break
        a = best_a
        current_J = best_J
        tracker.update(a)
    
    return a

def alternating_optimize(a, deadline, tracker, n_cycles=20):
    """Alternate between frequency-domain and gradient-based optimization."""
    n = len(a)
    a = a.copy().astype(np.float64)
    a = normalize_one(a)
    tracker.update(a)
    
    alpha = 0.8
    for cycle in range(n_cycles):
        if time.monotonic() > deadline:
            break
        
        # Frequency domain step
        a = freq_domain_smooth(a, alpha=alpha, n_iters=5, deadline=deadline)
        tracker.update(a)
        
        # LSE gradient step
        a = lse_optimize(a, max_iters=50, deadline=deadline, tracker=tracker,
                        tau0=10.0 + 5.0 * cycle)
        
        # Adjust alpha: make it closer to 1 as we progress (less aggressive)
        alpha = min(0.99, alpha * 1.02)
    
    return a

def spectral_init(n, rng, freqs=None, amplitudes=None):
    """Initialize with a spectral (cosine) pattern."""
    t = np.arange(n) / n
    if freqs is None:
        freqs = rng.uniform(0.5, 5.0, size=rng.integers(2, 8))
    if amplitudes is None:
        amplitudes = rng.uniform(0.2, 1.0, size=len(freqs))
    
    a = np.ones(n) * 0.5
    for f, amp in zip(freqs, amplitudes):
        a += amp * np.cos(2 * np.pi * f * t + rng.uniform(0, 2 * np.pi))
    a = np.maximum(a, 0.01)
    return normalize_one(a)

def chirp_init(n, rng):
    """Initialize with a chirp-like (quadratic phase) pattern."""
    t = np.arange(n) / n
    chirp_rate = rng.uniform(2.0, 10.0)
    a = 0.5 + 0.5 * np.cos(2 * np.pi * chirp_rate * t**2)
    a = np.maximum(a, 0.01)
    return normalize_one(a)

def wang_init(n, rng):
    """Wang sequence-inspired initialization (square wave based)."""
    a = np.zeros(n)
    period = int(n / rng.integers(2, 6))
    for i in range(n):
        phase = (i // period) % 2
        a[i] = 1.0 if phase == 0 else 0.3
    a = np.maximum(a, 0.01)
    return normalize_one(a)

def resample_seq(src, dest_n):
    src = np.asarray(src, dtype=np.float64)
    if src.size == dest_n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size, endpoint=False)
    t_new = np.linspace(0, 1, dest_n, endpoint=False)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)

def generate_diverse_inits(n, rng, parent):
    """Generate diverse initializations."""
    inits = []
    
    if parent is not None and parent.size > 0:
        inits.append(resample_seq(parent, n))
        inits.append(resample_seq(parent[::-1], n))
        # Slightly perturbed parent
        p = resample_seq(parent, n)
        p = p + rng.normal(0, 0.05, n)
        inits.append(normalize_one(p))
    
    # Constant
    inits.append(np.ones(n) / n)
    
    # Linear ramp
    t = np.linspace(0, 1, n, endpoint=False)
    inits.append(normalize_one(0.1 + 0.9 * t))
    inits.append(normalize_one(0.1 + 0.9 * (1 - t)))
    
    # Chirp
    inits.append(chirp_init(n, rng))
    inits.append(chirp_init(n, rng))
    
    # Spectral
    inits.append(spectral_init(n, rng))
    inits.append(spectral_init(n, rng))
    inits.append(spectral_init(n, rng))
    
    # Wang-like
    inits.append(wang_init(n, rng))
    inits.append(wang_init(n, rng))
    
    # Random smooth
    a = rng.uniform(0, 1, n)
    # Smooth it
    kernel_size = max(3, n // 20)
    kernel = np.ones(kernel_size) / kernel_size
    a = np.convolve(a, kernel, mode='same')
    inits.append(normalize_one(a))
    
    # Flat spectrum (random phases)
    half = n // 2 + 1
    angles = rng.uniform(0, 2 * np.pi, half)
    A = np.zeros(n, dtype=complex)
    A[:half] = np.exp(1j * angles[:half])
    for k in range(1, n - n // 2):
        A[k] = np.conj(A[n - k])
    a = np.fft.ifft(A).real
    a = np.maximum(a, 0.01)
    inits.append(normalize_one(a))
    
    return inits

def coordinate_polish(a, max_steps, deadline, tracker):
    """Coordinate descent polishing."""
    a = a.copy().astype(np.float64)
    a = normalize_one(a)
    n = len(a)
    current_J = compute_J(a)
    tracker.update(a)
    rng = np.random.default_rng(12345)
    
    for step in range(max_steps):
        if time.monotonic() > deadline:
            break
        # Pick a random coordinate (or a few)
        n_coords = min(5, n)
        indices = rng.choice(n, size=n_coords, replace=False)
        improved = False
        for j in indices:
            for scale in [0.7, 1.3, 0.5, 1.5, 0.85, 1.15]:
                a_trial = a.copy()
                a_trial[j] *= scale
                a_trial = normalize_one(a_trial)
                J_trial = compute_J(a_trial)
                if J_trial < current_J - 1e-15:
                    a = a_trial
                    current_J = J_trial
                    improved = True
                    break
        if not improved and step % 10 == 9:
            tracker.update(a)
    
    tracker.update(a)
    return a
```
