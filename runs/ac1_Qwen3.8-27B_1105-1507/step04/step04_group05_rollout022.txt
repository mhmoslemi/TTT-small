The function (x,y) -> xy is not convex on R^2 \ R^2_+, but it IS convex on R^2_+ (it's a "perspective" function... no, actually xy is NOT convex on R^2_+ either. The Hessian is [[0,1],[1,0]] which has eigenvalues 1 and -1, so it's indefinite).

So f(a) = max_k (a*a)[k] is not convex. The problem is non-convex.

Given this, let me focus on practical heuristics:

1. **Fast CD**: The most promising. Each coordinate update is O(n) to update b, and O(1) to find the new max (if we track it). With n=400, one pass is O(n^2) = 160K operations, which takes ~1ms. So we can do thousands of passes in 1500 seconds.

2. **The CD step**: For coordinate i, we want to find x that minimizes J when a[i] = x. Since J = 2n * max_b / S^2 (with S = sum a), and max_b is a piecewise-linear (in x) function (since each b[k] is linear in x for x >= 0, except b[2i] which is quadratic), the max is a piecewise function, and J is piecewise. We can find the minimum by considering the "breakpoints" where the argmax of b changes.

Actually, for a fixed x = a[i], the convolution values are:
b_new[k] = b[k] + 2*(x - a[i])*a[k-i] + (x-a[i])^2 * 1_{k=2i}
Let dx = x - a[i]. Then:
b_new[k] = b[k] + 2*dx*a[k-i] for k != 2i
b_new[2i] = b[2i] + 2*dx*a[i] + dx^2

The function max_k b_new[k] is the max of linear (and one quadratic) functions of dx. It's convex in dx (max of convex functions). So J as a function of dx (with S also changing) is... J = 2n * max_b_new / (S + dx)^2. The numerator is convex in dx, the denominator is (S+dx)^2 which is convex for dx > -S. The ratio of convex/convex is not necessarily convex.

But in practice, for small changes in dx, the argmax of b_new doesn't change, and J is a smooth function of dx. So we can use Newton's method or golden section search on the piece where the argmax is fixed.

**Simplified CD approach**: 
- Track the current max value M and the set of k's where b[k] is close to M.
- For each coordinate i, the new max is determined by the active set.
- If we know which k is the argmax, we can solve for x analytically.

When b[k*] is the argmax and b[k*] = b[k*] + 2*dx*a[k*-i] (assuming k* != 2i):
We want to minimize (b[k*] + 2*dx*a[k*-i]) / (S + dx)^2.
Taking derivative: [2*a[k*-i]*(S+dx)^2 - (b[k*]+2*dx*a[k*-i])*2*(S+dx)] / (S+dx)^4 = 0
=> a[k*-i]*(S+dx) = b[k*] + 2*dx*a[k*-i]
=> a[k*-i]*S + a[k*-i]*dx = b[k*] + 2*dx*a[k*-i]
=> a[k*-i]*S - b[k*] = dx*a[k*-i]
=> dx = (a[k*-i]*S - b[k*]) / a[k*-i] = S - b[k*]/a[k*-i]

So the optimal x (if k* remains the argmax) is:
x = a[i] + dx = a[i] + S - b[k*]/a[k*-i]

If k* = 2i:
b_new[2i] = b[2i] + 2*dx*a[i] + dx^2
Minimize (b[2i] + 2*dx*a[i] + dx^2) / (S+dx)^2
Derivative: [ (2*a[i] + 2*dx)*(S+dx)^2 - (b[2i]+2*dx*a[i]+dx^2)*2*(S+dx) ] / (S+dx)^4 = 0
=> (a[i]+dx)*(S+dx) = b[2i] + 2*dx*a[i] + dx^2
=> a[i]*S + a[i]*dx + S*dx + dx^2 = b[2i] + 2*a[i]*dx + dx^2
=> a[i]*S + dx*(a[i] + S - 2*a[i]) = b[2i]
=> a[i]*S + dx*(S - a[i]) = b[2i]
=> dx = (b[2i] - a[i]*S) / (S - a[i])
=> x = a[i] + (b[2i] - a[i]*S) / (S - a[i]) = (a[i]*(S-a[i]) + b[2i] - a[i]*S) / (S-a[i]) = (b[2i] - a[i]^2) / (S - a[i])

OK so in both cases, we can compute the optimal x analytically (given that a particular k* is the argmax). The challenge is that the argmax might change.

**Strategy**: 
1. Compute b and find M = max(b) and the set A of k's where b[k] >= M - eps (active set).
2. For each coordinate i, compute the candidate x using each active k*, take the one that gives the smallest J, and verify.
3. Update a[i] and b.

This should be O(|A|) per coordinate, which is much better than O(n) if |A| << n.

Key questions:

2. Is the optimization getting stuck in a local minimum?

For (1): The "cost" of a longer sequence is that max_b scales as ~1/n (for well-designed sequences), so J = 2n * max_b ~ 2 * (constant). The constant depends on how well we can "flatten" the convolution. For a sequence designed to have flat convolution, the constant approaches 1 as n grows (since we can make the convolution more uniform). But in practice, there are constraints.

Actually, for any n, the minimum of max_b (with sum a = 1, a >= 0) is bounded below by 1/(2n-1) (by averaging). So J >= 2n/(2n-1) → 1 as n → ∞. But achieving this requires the convolution to be perfectly flat, which is impossible for non-negative sequences (since b[0] = a[0]^2 >= 0 and b[n-1] = sum a[j]a[n-1-j] > 0).

The question is: what's the best achievable ratio max_b / (1/(2n-1)) for each n? For large n, we can approximate the convolution as a continuous convolution, and the optimal might be a specific shape.

Let me think about this in the continuous limit. Let a(x) be a non-negative function on [0,1] with ∫a = 1. The convolution is (a*a)(t) = ∫_0^1 a(x)a(t-x)dx (with a=0 outside [0,1]). We want to minimize max_t (a*a)(t).

By the Fourier transform: (a*a)^ (t) = |a^(t)|^2. So we want to minimize max|a^(t)|^2 subject to a >= 0, ∫a = 1.

This is related to the "uncertainty principle" and "sidelobe minimization" in signal processing. The optimal solution is related to the Tangent method or the method of steepest descent for radar waveform design.

In the continuous case, the optimal a(x) that minimizes max|(a*a)(t)| is related to the "flat-top" window or specific designs. But for finite n, we need discrete optimization.

"""
Minimizes J(a) = 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Vectorized fast coordinate descent with analytical per-coordinate solutions
2. LP-based mirror descent for global exploration
3. Multi-length search with diverse initializations
4. Nesterov-accelerated subgradient descent
Key: O(n^2) per CD pass but with vectorized numpy operations for speed.
"""

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import lil_matrix
import time

def fast_conv(a):
    n = len(a)
    s = 1
    while s < 2 * n - 1:
        s <<= 1
    fa = np.fft.rfft(a, s)
    return np.fft.irfft(fa * fa, s)[:2 * n - 1]

def compute_J(a):
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))

class ScoreTracker:
    def __init__(self):
        self.best = None
        self.best_score = float('inf')
        self.t_start = time.monotonic()
    
    def update(self, a):
        a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
        if a.size == 0 or a.sum() < 0.01:
            return
        score = float(evaluate_sequence(a.tolist()))
        if np.isfinite(score) and score < self.best_score:
            self.best = a.copy()
            self.best_score = score
            print(f"  * NEW BEST: J={score:.8f} n={a.size} t={time.monotonic()-self.t_start:.0f}s", flush=True)

def vectorized_cd_pass(a, b, n):
    """One vectorized CD pass. Returns (a, b, J)."""
    S = a.sum()
    # Work with normalized a
    a = a / S
    b = fast_conv(a)
    M = float(b.max())
    J = 2.0 * n * M
    
    improved = 0
    for i in range(n):
        ai = a[i]
        
        # Find k values affected by i
        k_start = max(0, i)
        k_end = min(2*n-2, i+n-1)
        k_affected = np.arange(k_start, k_end+1)
        ki_vals = k_affected - i  # these are the indices into a
        
        # For each affected k, compute the "descent direction"
        # If we increase a[i] by dx, b[k] increases by 2*dx*a[k-i] (or +dx^2 if k=2i)
        # To decrease max_b, we want to decrease a[i] if a[i] contributes to max_b
        # or increase it if a[i] is small and contributes to offsetting
        
        # Analytical: for the k that achieves max, optimal x depends on k
        # For k where b[k] is max:
        #   if k != 2i: x_opt = ai + 1 - b[k]/a[k-i]
        #   if k == 2i: x_opt = ai + (b[k]-ai)/(1-ai)
        
        # Find the max k
        k_max = int(np.argmax(b))
        
        # But we should consider all near-max k's
        # For efficiency, just use the argmax
        ki = k_max - i
        if 0 <= ki < n:
            if k_max == 2 * i:
                denom = 1.0 - ai
                if abs(denom) > 1e-15:
                    x_cand = ai + (b[k_max] - ai) / denom
                else:
                    x_cand = 0.0
            else:
                if a[ki] > 1e-15:
                    x_cand = ai + 1.0 - b[k_max] / a[ki]
                else:
                    x_cand = 0.0
            x_cand = max(0.0, x_cand)
            
            # Evaluate
            dx = x_cand - ai
            if abs(dx) > 1e-14:
                # Quick check: will this reduce max?
                # New value at k_max:
                if k_max == 2 * i:
                    new_bkmax = b[k_max] + 2*dx*a[ki] + dx*dx
                else:
                    new_bkmax = b[k_max] + 2*dx*a[ki]
                
                # New max is at least max(new_bkmax, max of unaffected b)
                # Unaffected b values: b[k] for k not in [k_start, k_end]
                if len(k_affected) < 2*n-1:
                    unaffected_max = float(np.max(np.delete(b, k_affected))) if len(k_affected) < len(b) else 0.0
                else:
                    unaffected_max = 0.0
                
                # Check affected values
                new_affected = b[k_affected] + 2*dx*a[ki_vals]
                if 2*i in k_affected:
                    idx = 2*i - k_start
                    new_affected[idx] += dx*dx
                
                new_M = max(float(np.max(new_affected)), unaffected_max)
                new_J = 2.0 * n * new_M
                
                if new_J < J - 1e-12:
                    # Apply update
                    a[i] = x_cand
                    b[k_affected] = new_affected
                    M = new_M
                    J = new_J
                    improved += 1
    
    return a, b, J, improved

def cd_optimize(a, deadline, tracker, max_time_per_length=60):
    """Run CD optimization on sequence a."""
    a = np.maximum(a.astype(np.float64), 0.0).copy()
    S = a.sum()
    if S < 1e-10:
        return a
    a /= S
    n = len(a)
    b = fast_conv(a)
    J = 2.0 * n * float(b.max())
    
    tracker.update(a)
    t0 = time.monotonic()
    
    pass_num = 0
    stall = 0
    while time.monotonic() < deadline and time.monotonic() - t0 < max_time_per_length:
        a, b, J, improved = vectorized_cd_pass(a, b, n)
        pass_num += 1
        
        if improved == 0:
            stall += 1
            if stall > 20:
                break
        else:
            stall = 0
        
        if pass_num % 50 == 0:
            tracker.update(a)
            print(f"    n={n} pass={pass_num} J={J:.8f} improved={improved} t={time.monotonic()-t0:.1f}s", flush=True)
    
    tracker.update(a)
    return a

def resample_seq(src, dest_n):
    src = np.asarray(src, dtype=np.float64)
    if src.size == dest_n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, dest_n)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)

def build_A_sparse(a):
    n = len(a)
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        jl = max(0, k - n + 1)
        jh = min(n - 1, k)
        if jl <= jh:
            for j in range(jl, jh + 1):
                rows.append(k)
                cols.append(j)
                vals.append(a[k - j])
    A = lil_matrix((2 * n - 1, n))
    for idx in range(len(rows)):
        A[rows[idx], cols[idx]] = vals[idx]
    return A.tocsr()

def lp_best_response(a, M):
    n = len(a)
    c = -np.ones(n)
    A = build_A_sparse(a)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
    if r.success and r.x is not None:
        g = np.maximum(r.x, 0.0)
        if g.sum() > 1e-10:
            return g
    return None

def lp_mirror_descent(a, deadline, tracker, max_iters=100, tighten_base=0.005):
    """LP mirror descent."""
    a = np.maximum(a.astype(np.float64), 1e-6).copy()
    a /= a.sum()
    n = len(a)
    S = 1.0
    current_J = compute_J(a)
    tracker.update(a)
    
    tighten = tighten_base
    stall = 0
    t0 = time.monotonic()
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fast_conv(a)
        M = float(b.max())
        
        # Try tight constraint
        M_target = M * (1.0 - tighten)
        g = lp_best_response(a, M_target)
        
        if g is None:
            M_target = M * (1.0 - tighten * 0.3)
            g = lp_best_response(a, M_target)
            if g is None:
                tighten *= 0.5
                if tighten < 1e-8:
                    break
                continue
        
        g = np.maximum(g, 0.0)
        g /= g.sum()
        
        # Try multiple step sizes
        best_a = None
        best_J = current_J
        for t in [0.3, 0.5, 0.7, 0.9, 0.1, 0.2]:
            a_trial = (1-t)*a + t*g
            a_trial = np.maximum(a_trial, 0.0)
            if a_trial.sum() < 1e-10:
                continue
            a_trial /= a_trial.sum()
            J_trial = compute_J(a_trial)
            if J_trial < best_J - 1e-14:
                best_J = J_trial
                best_a = a_trial
        
        if best_a is None:
            stall += 1
            tighten *= 0.7
            if stall > 30:
                break
            continue
        
        a = best_a
        current_J = best_J
        stall = 0
        tighten = min(0.02, tighten * 1.02)
        
        if it % 10 == 0:
            tracker.update(a)
            print(f"    LP iter {it}: J={current_J:.8f} t={time.monotonic()-t0:.1f}s", flush=True)
    
    tracker.update(a)
    return a

def subgradient_descent(a, deadline, tracker, max_iters=5000):
    """Nesterov-accelerated subgradient descent."""
    a = np.maximum(a.astype(np.float64), 0.0).copy()
    S = a.sum()
    if S < 1e-10:
        return a
    a_yst = a.copy()  # for Nesterov
    n = len(a)
    current_J = compute_J(a)
    tracker.update(a)
    
    # Initial step size
    step = 1.0 / np.sqrt(2.0 * n)
    stall = 0
    t0 = time.monotonic()
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        if time.monotonic() - t0 > 120:
            break
        
        # Nesterov lookahead
        if it > 0:
            momentum = (it - 1) / (it + 2.0)  # (k-1)/(k+2) for Nesterov
        else:
            momentum = 0.0
        a_step = a + momentum * (a - a_yst)
        a_yst = a.copy()
        
        # Compute subgradient
        b = fast_conv(a_step)
        M = float(b.max())
        # Active set
        tol = 1e-4 * M
        active = np.where(b >= M - tol)[0]
        
        # Subgradient of max_b at a_step
        grad = np.zeros(n)
        for k in active:
            jl = max(0, k - n + 1)
            jh = min(n - 1, k)
            for j in range(jl, jh + 1):
                grad[j] += a_step[k - j]
        
        # Gradient of J = 2n*M (with S=1, so dJ/dai = 2n * dM/dai)
        # But we also need to project onto sum(a)=1, a>=0
        # The gradient of the constraint sum(a)=1 is 1, so we subtract mean
        grad = 2.0 * n * grad / len(active)
        grad -= np.mean(grad)  # project onto sum=0 hyperplane
        
        # Scale step
        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-15:
            break
        
        a_new = a - step * grad / gnorm
        a_new = np.maximum(a_new, 0.0)
        a_new_sum = a_new.sum()
        if a_new_sum < 1e-10:
            break
        a_new /= a_new_sum
        
        J_new = compute_J(a_new)
        if J_new < current_J - 1e-14:
            a = a_new
            current_J = J_new
            stall = 0
            step = min(1.0, step * 1.01)  # increase step slightly
        else:
            a = a_new  # still move (for exploration)
            stall += 1
            step *= 0.9
            if stall > 200:
                break
        
        if it % 100 == 0:
            tracker.update(a)
            print(f"    SG iter {it}: J={current_J:.8f} step={step:.4f} t={time.monotonic()-t0:.1f}s", flush=True)
    
    tracker.update(a)
