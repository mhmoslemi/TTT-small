```python
def project_simplex(v):
    """Project v onto the simplex {x: sum(x)=1, x>=0}."""
    n = len(v)
    # Algorithm from "Fast Euclidean Projection onto the Simplex"
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)
```

`logsumexp(tau * conv) = tau * max(conv) + log(sum(exp(tau*(conv - max(conv)))))`

So `f_smooth = (2n/tau) * logsumexp(tau * conv) = 2n * (max(conv) + (1/tau) * log(sum(exp(tau*(conv - max(conv))))))`

As `tau -> inf`, this approaches `2n * max(conv)`.

The gradient of `f_smooth` w.r.t. `x` (where `a = softmax(x)`) is:
`df_smooth/dx = (df_smooth/da) * (da/dx)`

`da/dx` is the softmax Jacobian: `da_i/dx_j = a_i * (delta_ij - a_j)`

So `df_smooth/dx_j = sum_i (df_smooth/da_i) * a_i * (delta_ij - a_j) = a_j * (df_smooth/da_j - sum_i (df_smooth/da_i) * a_i)`

This is the "centered gradient" times `a_j`.

Let me implement this:

```python
def obj_and_grad_smooth(x, tau=10):
    a = softmax(x)
    n = len(a)
    conv = compute_conv(a)
    
    # Smoothed value
    shifted = tau * (conv - np.max(conv))
    log_sum_exp = np.max(shifted) + np.log(np.sum(np.exp(shifted - np.max(shifted))))
    f = (2 * n / tau) * log_sum_exp
    
    # Gradient of f w.r.t. a
    w = np.exp(shifted - np.max(shifted))
    w /= np.sum(w)  # This is the softmax of (conv - max(conv)), which is the same as softmax(conv)
    
    # Wait, actually w should be exp(tau*conv) / sum(exp(tau*conv))
    # Which is the same as exp(tau*(conv - max(conv))) / sum(exp(tau*(conv - max(conv))))
    # Which is what we have above. ✓
    
    h = np.correlate(w, a, 'valid')
    da_grad = 4 * n * h  # df/da
    
    # df/dx = a * (da_grad - dot(a, da_grad))
    dot = np.dot(a, da_grad)
    dx_grad = a * (da_grad - dot)
    
    return f, dx_grad
```

This is clean and should work well with `scipy.optimize.minimize` using L-BFGS-B.

But wait, there's a subtlety. The softmax parametrization means we can never reach `a_i = 0`. The optimal solution likely has some `a_i = 0` (or very close to 0). The softmax will approach but never reach 0.

This is actually fine for our purposes - we can get very close to 0 with large negative `x_i`. And the softmax parametrization automatically handles the constraint `sum(a) = 1`.

Let me also think about whether we should try different approaches:

1. **Softmax parametrization + L-BFGS**: Clean, handles constraints automatically.
2. **Projected gradient on simplex**: More direct, can handle the boundary exactly.
3. **Alternating LP** (from previous work): Known to work well.
4. **Hybrid**: Use multiple methods and keep the best.

I think the best strategy is to combine several approaches:
1. Start with the parent sequence
2. Try softmax+L-BFGS with different tau values
3. Try projected gradient with the correct gradient
4. Try the alternating LP (from previous work)
5. Local search at the end
6. Explore different n values

Let me also think about the optimal n. The objective is `2n * max(conv) / sum(a)^2`. For the uniform sequence, this is always 2. For better sequences, it can be less than 2. The question is: does increasing n help?

For a "random" sequence, `max(conv) ~ sum(a)^2 * (1 + c*sqrt(log(n)/n))` or something like that. So `2n * max(conv) / sum(a)^2 ~ 2n * (1 + c*sqrt(log(n)/n)) / n = 2 + 2c*sqrt(log(n)/n)`. This decreases with n!

Wait, that's for random sequences. For optimized sequences, the behavior might be different.

Actually, let me think about it more carefully. For a sequence `a` with `sum(a) = 1`:
- `E[conv[k]] = 1/n` for all interior k (by symmetry of random sequences)
- `max(conv) ~ 1/n + c * sqrt(log(n)/n^3)` for random sequences (concentration)
- So `2n * max(conv) ~ 2n * (1/n + c * sqrt(log(n)/n^3)) = 2 + 2c * sqrt(log(n)/n)`

This suggests that for random sequences, the objective approaches 2 from above as n increases. But for optimized sequences, we can do much better than 2.

The question is: what's the theoretical minimum? For a sequence with exactly two nonzero elements (a "Barker-like" construction), the max convolution is achieved by the self-correlation at lag 0, which is `sum(a_i^2)`. With `sum(a) = 1`, this is minimized when all mass is spread uniformly, giving `1/n`. But then the peak of the full convolution is at lag 0 or the center...

Actually, I realize I should just focus on practical optimization rather than theory. Let me write the code.

Here's my refined plan:

1. **Helper functions**: FFT-based convolution, gradient computation, simplex projection, softmax
2. **Optimizer 1**: Projected gradient descent with backtracking line search and adaptive tau
3. **Optimizer 2**: L-BFGS on softmax parametrization
4. **Optimizer 3**: Alternating LP (improved from previous)
5. **Local search**: Random perturbations + re-optimization
6. **Main loop**: Try multiple n values, multiple initializations, all optimizers

Let me also consider: should I try to make the convolution "flat" (all lags equal)? This is the ideal - if `conv(a,a)[k] = c` for all k, then `max(conv) = c = sum(conv)/(2n-1) = sum(a)^2/(2n-1) = 1/(2n-1)`. Then the objective is `2n/(2n-1) ≈ 1`. But achieving perfect flatness is impossible for finite sequences (this is the "Golay complementary sequences" or "periodic minimal peak sidelobe" problem).

The practical target is to make the convolution as flat as possible, with the peak as low as possible relative to the mean.

```python
"""
Advanced step function optimization combining:
1. Projected gradient descent with exact (sub)gradient and adaptive smoothing
2. L-BFGS on log-parametrization (softmax)
3. Alternating LP for structured improvements
4. Intensive local search
5. Multi-n exploration

The key innovation is using the exact gradient of the smoothed max-convolution
objective, which enables much faster convergence than the previous heuristic approaches.
"""

import numpy as np
from scipy.optimize import linprog, minimize
import time

def compute_conv(a):
    """Compute linear convolution a*a via FFT. Returns array of length 2n-1."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)
    return conv[:2 * n - 1]

def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = np.sum(a)
    if s < 0.01:
        return np.inf
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    return 2.0 * n * max_b / (s * s)

def project_simplex(v):
    """Project v onto the probability simplex {x: sum(x)=1, x>=0}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0]
    if len(rho) == 0:
        return np.ones(n) / n
    theta = (cssv[rho[-1]] - 1) / (rho[-1] + 1.0)
    return np.maximum(v - theta, 0)

def softmax(x):
    """Numerically stable softmax."""
    x = x - np.max(x)
    e = np.exp(x)
    return e / np.sum(e)

def compute_grad_smoothed(a, tau):
    """Compute gradient of (2n/tau)*logsumexp(tau*conv(a,a)) w.r.t. a.
    
    Returns the gradient vector of length n.
    """
    n = len(a)
    conv = compute_conv(a)
    # Stable logsumexp and softmax weights
    c_max = np.max(conv)
    shifted = tau * (conv - c_max)
    # Clip for numerical stability
    shifted = np.clip(shifted, -500, 500)
    w = np.exp(shifted)
    w_sum = np.sum(w)
    if w_sum < 1e-300:
        # Degenerate: use hard max
        k_star = int(np.argmax(conv))
        h = np.zeros(n)
        for i in range(n):
            j = k_star - i
            if 0 <= j < n:
                h[i] = a[j]
        return 4.0 * n * h
    w /= w_sum
    # h[i] = sum_j a[j] * w[i+j] for i=0..n-1
    h = np.correlate(w, a, mode='valid')
    return 4.0 * n * h

def projected_gradient_optimize(a, time_budget=60.0, tau_init=5.0, tau_max=500.0):
    """Optimize using projected gradient with backtracking line search."""
    n = len(a)
    a = a.copy().astype(np.float64)
    s = np.sum(a)
    if s < 1e-10:
        return a, np.inf
    a = a / s
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    eta = 0.1
    tau = tau_init
    stall = 0
    patience = 200
    
    while time.monotonic() - start < time_budget:
        # Adaptive tau: increase over time
        progress = (time.monotonic() - start) / time_budget
        tau = tau_init * (tau_max / tau_init) ** (progress ** 0.5)
        
        grad = compute_grad_smoothed(a, tau)
        
        # Backtracking line search
        obj_current = compute_obj(a)
        step_size = eta
        improved = False
        for _ in range(30):
            a_new = project_simplex(a - step_size * grad)
            obj_new = compute_obj(a_new)
            if obj_new < obj_current - 1e-14:
                a = a_new
                best_obj_candidate = obj_new
                improved = True
                break
            step_size *= 0.5
        
        if not improved:
            # Try a very small step or random perturbation
            stall += 1
            if stall > 50:
                # Random restart in neighborhood
                rng = np.random.default_rng(int(time.monotonic() * 1000))
                a = a * np.exp(rng.normal(0, 0.05, n))
                a = np.maximum(a, 1e-15)
                a = project_simplex(a)
                stall = 0
                patience = max(patience // 2, 50)
                eta = 0.05
            else:
                a = project_simplex(a - 0.001 * grad)
            continue
        
        eta = min(step_size * 1.2, 1.0)
        
        obj = compute_obj(a)
        if obj < best_obj - 1e-13:
            best_obj = obj
            best_a = a.copy()
            stall = 0
        else:
            stall += 1
            if stall > patience:
                break
    
    return best_a, best_obj

def lbfgs_optimize(a, time_budget=60.0, tau=20.0):
    """Optimize using L-BFGS on log-parametrization."""
    n = len(a)
    a = a.copy().astype(np.float64)
    s = np.sum(a)
    if s < 1e-10:
        return a, np.inf
    a = a / s
    
    # Initial x in log-space
    a_clipped = np.maximum(a, 1e-15)
    x0 = np.log(a_clipped)
    
    def obj_fun(x):
        a_local = softmax(x)
        conv = compute_conv(a_local)
        c_max = np.max(conv)
        shifted = tau * (conv - c_max)
        shifted = np.clip(shifted, -500, 500)
        lse = np.max(shifted) + np.log(np.sum(np.exp(shifted - np.max(shifted))))
        return (2 * n / tau) * lse
    
    def obj_grad(x):
        a_local = softmax(x)
        conv = compute_conv(a_local)
        c_max = np.max(conv)
        shifted = tau * (conv - c_max)
        shifted = np.clip(shifted, -500, 500)
        w = np.exp(shifted)
        w_sum = np.sum(w)
        if w_sum < 1e-300:
            k_star = int(np.argmax(conv))
            h = np.zeros(n)
            for i in range(n):
                j = k_star - i
                if 0 <= j < n:
                    h[i] = a_local[j]
            da_grad = 4.0 * n * h
        else:
            w /= w_sum
            h = np.correlate(w, a_local, mode='valid')
            da_grad = 4.0 * n * h
        
        # df/dx = a * (df/da - dot(a, df/da))
        dot_val = np.dot(a_local, da_grad)
        dx_grad = a_local * (da_grad - dot_val)
        
        lse = np.max(shifted) + np.log(np.sum(np.exp(shifted - np.max(shifted))))
        f = (2 * n / tau) * lse
        return f, dx_grad
    
    start = time.monotonic()
    best_a = a.copy()
    best_obj = compute_obj(a)
    
    try:
        result = minimize(obj_grad, x0, method='L-BFGS-B',
                         options={'maxiter': 500, 'maxfun': 2000,
                                  'ftol': 1e-16, 'gtol': 1e-12,
                                  'iprint': -1})
        x_opt = result.x
        a_opt = softmax(x_opt)
        obj_opt = compute_obj(a_opt)
        if obj_opt < best_obj:
            best_a = a_opt
            best_obj = obj_opt
    except Exception as e:
        pass
    
    # Check time
    if time.monotonic() - start < time_budget - 5:
        # Try with higher tau
        try:
            result = minimize(obj_grad, x_opt, method='L-BFGS-B',
                            options={'maxiter': 300, 'maxfun': 1000,
                                     'ftol': 1e-16, 'gtol': 1e-12,
                                     'iprint': -1})
            x_opt2 = result.x
            a_opt2 = softmax(x_opt2)
            obj_opt2 = compute_obj(a_opt2)
            if obj_opt2 < best_obj:
                best_a = a_opt2
                best_obj = obj_opt2
        except Exception:
            pass
    
    return best_a, best_obj

def build_toeplitz(a):
    """Build Toeplitz matrix for convolution."""
    n = len(a)
    A = np.zeros((2 * n - 1, n), dtype=np.float64)
    for j in range(n):
        k_start = j
        k_end = min(j + n, 2 * n - 1)
        A[k_start:k_end, j] = a[:k_end - k_start]
    return A

def alternating_lp(a, time_budget=30.0):
    """Alternating LP: max sum(g) s.t. (a*g) <= M, g >= 0."""
    n = len(a)
    a = a.copy().astype(np.float64)
    s = np.sum(a)
    if s < 1e-10:
        return a, np.inf
    a = a / s
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    stall = 0
    
    while time.monotonic() - start < time_budget - 3:
        conv = compute_conv(a)
        M = float(np.max(conv))
        
        A = build_toeplitz(a)
        c = -np.ones(n)
        b_ub = np.full(2 * n - 1, M)
        bounds = [(0.0, None)] * n
        
        try:
            res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds,
                         method='highs', options={'presolve': True,
                                                   'time_limit': min(10, time_budget / 4)})
            if res.status != 0:
                break
            g = np.maximum(res.x, 0)
            sum_g = float(np.sum(g))
            if sum_g < 1e-10:
                break
        except Exception:
            break
        
        g = g / sum_g
        
        # Line search
        best_t = 0.0
        best_obj_ls = best_obj
        for t in [0.1, 0.2, 0.3, 0.5, 0.7, 1.0]:
            a_new = (1.0 - t) * best_a + t * g
            a_new = np.maximum(a_new, 0)
            s_new = np.sum(a_new)
            if s_new < 1e-10:
                continue
            a_new = a_new / s_new
            obj_new = compute_obj(a_new)
            if obj_new < best_obj_ls:
                best_obj_ls = obj_new
                best_t = t
        
        if best_t > 0 and best_obj_ls < best_obj - 1e-13:
            a_new = (1.0 - best_t) * best_a + best_t * g
            a_new = np.maximum(a_new, 0)
            a_new = a_new / np.sum(a_new)
            best_obj = best_obj_ls
            best_a = a_new
            a = a_new
            stall = 0
        else:
            stall += 1
            if stall > 30:
                break
    
    return best_a, best_obj

def random_init(n, seed):
    """Generate diverse random initializations."""
    rng = np.random.default_rng(seed)
    k = np.arange(n)
    choice = rng.integers(0, 8)
    
    if choice == 0:
        f = rng.uniform(0.5, 4.0)
        phase = rng.uniform(0, 2 * np.pi)
        a = 1.0 + 0.8 * np.cos(2 * np.pi * f * k / n + phase)
    elif choice == 1:
        f1 = rng.uniform(0.3, 2.0)
        f2 = rng.uniform(2.0, 6.0)
        a = 1.0 + 0.4 * np.cos(2 * np.pi * f1 * k / n) + 0.3 * np.cos(2 * np.pi * f2 * k / n)
    elif choice == 2:
        a = rng.random(n)
        win = max(3, n // 20)
        kernel = np.ones(win) / win
        a = np.convolve(a, kernel, mode='same')
    elif choice == 3:
        a = np.ones(n)
        for _ in range(rng.integers(1, 4)):
            f = rng.uniform(0.5, 5.0)
            amp = rng.uniform(0.1, 0.4)
            a += amp * np.cos(2 * np.pi * f * k / n + rng.uniform(0, 2 * np.pi))
    elif choice == 4:
        a = np.ones(n)
        for scale in range(3):
            f = rng.uniform(0.3 * (2 ** scale), 1.5 * (2 ** scale))
            amp = 0.3 / (scale + 1)
            a += amp * np.cos(2 * np.pi * f * k / n + rng.uniform(0, 2 * np.pi))
    elif choice == 5:
        center = n * rng.uniform(0.2, 0.8)
        width = n * rng.uniform(0.1, 0.5)
        a = 1.0 + 0.7 * np.exp(-0.5 * ((k - center) / width) ** 2)
    elif choice == 6:
        a = rng.random(max(5, n // 10))
        a = np.interp(k, np.arange(len(a)), a)
    else:
        a = np.ones(n)
        for _ in range(rng.integers(1, 3)):
            f = rng.uniform(0.5, 3.0)
            a += rng.uniform(0.2, 0.5) * np.sin(2 * np.pi * f * k / n + rng.uniform(0, 2 * np.pi))
    
    a = np.maximum(a, 0)
    s = np.sum(a)
    if s < 1e-10:
        a = np.ones(n)
        s = n
    return a / s

def resample_sequence(a, new_n):
    """Resample a sequence to a new length using interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    old_k = np.arange(n)
    new_k = np.linspace(0, n - 1, new_n)
    a_new = np.interp(new_k, old_k, a)
    a_new = np.maximum(a_new, 0)
    s = np.sum(a_new)
    if s > 1e-10:
        a_new = a_new / s
    return a_new

def optimize_single(a, time_budget=60.0, verbose=False):
    """Run full optimization pipeline on a single sequence."""
    n = len(a)
    a = a.copy().astype(np.float64)
    s = np.sum(a)
    if s < 1e-10:
        a = np.ones(n)
        s = n
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    if verbose:
        print(f"  Start: obj={best_obj:.8f}")
    
    # Phase 1: Projected gradient
    remaining = time_budget - (time.monotonic() - start)
    if remaining > 10:
        pg_time = min(remaining * 0.3, 30.0)
        a_new, obj = projected_gradient_optimize(best_a, time_budget=pg_time)
        if obj < best_obj - 1e-13:
            best_obj = obj
            best_a = a_new.copy()
            if verbose:
                print(f"  After PG: {best_obj:.8f}")
    
    # Phase 2: L-BFGS
    remaining = time_budget - (time.monotonic() - start)
    if remaining > 10:
        lb_time = min(remaining * 0.3, 25.0)
        a_new, obj = lbfgs_optimize(best_a, time_budget=lb_time)
        if obj < best_obj - 1e-13:
            best_obj = obj
            best_a = a_new.copy()
            if verbose:
                print(f"  After L-BFGS: {best_obj:.8f}")
    
    # Phase 3: Alternating LP
    remaining = time_budget - (time.monotonic() - start)
    if remaining > 10:
        lp_time = min(remaining * 0.3, 25.0)

            best_a = a_new.copy()
            if verbose:

    # Phase 4: Second round of PG with higher tau
    remaining = time_budget - (time.monotonic() - start)
    if remaining > 5:
        pg_time = min(remaining * 0.3, 20.0)
        a_new, obj = projected_gradient_optimize(best_a, time_budget=pg_time,

            if verbose:
                print(f"  After PG2: {best_obj:.8f}")
    
    # Phase 5: Final L-BFGS polish
    remaining = time_budget - (time.monotonic() - start)
    if remaining > 5:
        lb_time = min(remaining * 0.4, 15.0)
        a_new, obj = lbfgs_optimize(best_a, time_budget=lb_time, tau=100.0)
        if obj < best_obj - 1e-13:
            best_obj = obj
            best_a = a_new.copy()
            if verbose:
                print(f"  After L-BFGS2: {best_obj:.8f}")

def local_search(a, time_budget=60.0, verbose=False):
    """Intensive local search with perturbations and re-optimization."""
    n = len(a)
    a = a.copy().astype(np.float64)
    s = np.sum(a)
    if s < 1e-10:
        return a, np.inf
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    if verbose:
        print(f"  Local search start: {best_obj:.8f}")
    
    attempt = 0
    while time.monotonic() - start < time_budget - 10:
        attempt += 1
        remaining = time.monotonic()
        remaining_budget = time_budget - (time.monotonic() - start)
        if remaining_budget < 15:
            break
        
        rng = np.random.default_rng(attempt * 7919 + 12345)
        
        # Try different perturbation types
        pert_type = attempt % 4
        if pert_type == 0:
            # Multiplicative noise
            a_pert = best_a * np.exp(rng.normal(0, 0.03, n))
        elif pert_type == 1:
            # Additive noise on a few coordinates
            a_pert = best_a.copy()
            idx = rng.choice(n, size=max(1, n // 10), replace=False)
            a_pert[idx] += rng.normal(0, 0.02, len(idx))
        elif pert_type == 2:
            # Smooth perturbation
            noise = rng.normal(0, 0.05, max(5, n // 10))
            noise_full = np.interp(np.arange(n), np.arange(len(noise)), noise)
            a_pert = best_a + 0.1 * noise_full
        else:
            # Coordinate swap
            a_pert = best_a.copy()
            i, j = rng.integers(0, n, size=2)
            delta = rng.uniform(0.01, 0.05)
            if a_pert[i] >= delta:
                a_pert[i] -= delta
                a_pert[j] += delta
        
        a_pert = np.maximum(a_pert, 1e-12)
        s_pert = np.sum(a_pert)
        if s_pert < 1e-10:
            continue
        a_pert = a_pert / s_pert
        
        # Quick optimization
        sub_time = min(15.0, remaining_budget * 0.4)
        a_opt, obj = optimize_single(a_pert, time_budget=sub_time, verbose=False)
        
        if obj < best_obj - 1e-13:
```

Advanced step function optimization using Nesterov-accelerated projected gradient descent
with exact smoothed gradients, L-BFGS on log-parametrization, alternating LP, and local search.

Key innovations over previous approach:
- Exact gradient of the smoothed max-convolution objective (via FFT + correlation)
- Nesterov acceleration for O(1/t^2) convergence on the convex subproblem
- Adaptive smoothing parameter (tau) for smooth-to-sharp transition
- L-BFGS on softmax parametrization for complementary convergence
- Multi-phase pipeline with careful time budgeting
"""

import numpy as np
from scipy.optimize import linprog, minimize
import time


def compute_conv(a):
    """Compute linear convolution a*a via FFT. Returns array of length 2n-1."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)
    return conv[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = np.sum(a)
    if s < 0.01:
        return np.inf
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    return 2.0 * n * max_b / (s * s)


def project_simplex(v):
    """Project v onto the probability simplex {x: sum(x)=1, x>=0}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0]
    if len(rho) == 0:
        return np.ones(n) / n
    theta = (cssv[rho[-1]] - 1) / (rho[-1] + 1.0)
    return np.maximum(v - theta, 0)


def softmax_func(x):
    """Numerically stable softmax."""
    x = x - np.max(x)
    e = np.exp(x)
    return e / np.sum(e)


def compute_grad_smoothed(a, tau):
    """Compute gradient of (2n/tau)*logsumexp(tau*conv(a,a)) w.r.t. a.
    
    The gradient is 4n * h[i] where h[i] = sum_j a[j] * w[i+j],
    and w = softmax(tau * conv(a,a)).
    """
    n = len(a)
    conv = compute_conv(a)
    c_max = np.max(conv)
    shifted = tau * (conv - c_max)
    shifted = np.clip(shifted, -500, 500)
    w = np.exp(shifted)
    w_sum = np.sum(w)
    if w_sum < 1e-300:
        k_star = int(np.argmax(conv))
        h = np.zeros(n)
        for i in range(n):
            j = k_star - i
            if 0 <= j < n:
                h[i] = a[j]
        return 4.0 * n * h
    w /= w_sum
    h = np.correlate(w, a, mode='valid')
    return 4.0 * n * h
