def coordinate_descent_step(a, i, num_evals=100):
    """Optimize coordinate i of a, given all other coordinates fixed."""
    n = len(a)
    x_old = a[i]
    S = np.sum(a)
    S_without = S - x_old
    
    # Precompute conv of a without the i-th element contribution
    # conv[k] = D_k + E_k * x + F_k * x^2
    # where F_k = 1 if k == 2i else 0
    # E_k = 2*a[k-i] if 0 <= k-i < n and k != 2i else 0
    # D_k = conv[k] - E_k * x_old - F_k * x_old^2
    
    conv_current = compute_conv(a)
    
    E = np.zeros(2*n-1)
    F = np.zeros(2*n-1)
    
    # F[2i] = 1
    F[2*i] = 1.0
    
    # E[k] = 2*a[k-i] for valid k-i
    # k-i must be in [0, n-1], so k in [i, i+n-1]
    # Also k != 2i
    for k in range(i, i+n):
        if k < 2*n-1 and k != 2*i:
            E[k] = 2.0 * a[k-i]
    
    D = conv_current - E * x_old - F * x_old * x_old
    
    # Now minimize g(x) = 2*n * max_k(D[k] + E[k]*x + F[k]*x^2) / (S_without + x)^2
    # for x >= 0
    
    # Grid search
    x_max = max(2.0 * x_old, 0.1)
    x_vals = np.linspace(0, x_max, num_evals)
    
    best_x = x_old
    best_val = np.inf
    
    for x in x_vals:
        conv_vals = D + E * x + F * x * x
        max_val = np.max(conv_vals)
        s_val = S_without + x
        g_val = 2.0 * n * max_val / (s_val * s_val)
        if g_val < best_val:
            best_val = g_val
            best_x = x
    
    # Refine with finer grid around best
    if best_x > 0 and best_x < x_max:
        idx = np.argmin(x_vals == best_x)
        lo = x_vals[max(0, idx-3)]
        hi = x_vals[min(num_evals-1, idx+3)]
    else:
        lo = max(0, best_x * 0.5)
        hi = best_x * 1.5
    
    x_fine = np.linspace(lo, hi, 200)
    for x in x_fine:
        conv_vals = D + E * x + F * x * x
        max_val = np.max(conv_vals)
        s_val = S_without + x
        g_val = 2.0 * n * max_val / (s_val * s_val)
        if g_val < best_val:
            best_val = g_val
            best_x = x
    
    a[i] = best_x
    return best_val

def compute_conv(a):
    """FFT-based convolution of a with itself."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)
    return conv[:2 * n - 1]

def compute_obj(a):

    n = len(a)
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)

But I'm doing this for each of the n coordinates in a sweep, so it's O(n^2 log n) per sweep. For n=330, that's about 330 * 330 * 9 ≈ 1M operations per sweep, which is fine.

But actually, I can optimize this. Instead of recomputing the convolution from scratch each time, I can update it incrementally. When I change `a[i]` from `x_old` to `x_new`, the convolution changes by:
`delta_conv[k] = E_k * (x_new - x_old) + F_k * (x_new^2 - x_old^2)`

where E and F are as defined before. So I can maintain the convolution incrementally!

This brings the per-coordinate cost down to O(n) (for computing E and doing the 1D search) instead of O(n log n + n).

For n=330, the FFT convolution is very fast (maybe 10-20 microseconds), so even with 330 coordinates per sweep, it's only about 6ms per sweep. We can easily do thousands of sweeps in a minute.

Actually wait, I realize I'm overcomplicating this. Let me simplify:

For each coordinate i:
1. Compute the "base" values: for each k, what would conv[k] be as a function of x = a[i]?
   - `conv[k](x) = D[k] + E[k]*x + F[k]*x^2`
   - where D[k] = conv[k] - E[k]*x_old - F[k]*x_old^2
   - E[k] = 2*a[k-i] if 0 ≤ k-i < n and k ≠ 2i, else 0
   - F[k] = 1 if k = 2i, else 0

2. Do a 1D grid search to find optimal x.

3. Update a[i] = x and recompute conv.

The key optimization is that in step 2, for each x evaluation, I need to compute `max_k(D[k] + E[k]*x + F[k]*x^2)`. 

Note that D[k] + E[k]*x = conv[k] - E[k]*x_old - F[k]*x_old^2 + E[k]*x = conv[k] + E[k]*(x - x_old) - F[k]*x_old^2

And F[k]*x^2 is only non-zero at k=2i.

So: `D[k] + E[k]*x + F[k]*x^2 = conv[k] + E[k]*(x-x_old) + F[k]*(x^2 - x_old^2)`

For k ≠ 2i: `= conv[k] + 2*a[k-i]*(x-x_old)` (when k-i is valid)
For k = 2i: `= conv[2i] + (x^2 - x_old^2)`
For k where k-i is not valid: `= conv[k]`

So the max is:
`max(M_outside, max_{k in range, k≠2i}(conv[k] + 2*a[k-i]*(x-x_old)), conv[2i] + x^2 - x_old^2)`

Where M_outside is the max of conv[k] for k where k-i is not valid and k ≠ 2i.

This is O(n) per x evaluation (for the in-range max), and we do num_evals evaluations per coordinate.

Total per coordinate: O(n * num_evals)
Total per sweep: O(n^2 * num_evals)

For n=330, num_evals=150: 330^2 * 150 ≈ 16M per sweep. With numpy vectorization, this should take maybe 10-50ms per sweep. So we can do many sweeps.

Let me clean up the code and make it efficient:

def coordinate_descent_fast(a, num_sweeps=100, num_evals=100, time_budget=30.0):
    n = len(a)
    a = a.copy().astype(np.float64)
    s = np.sum(a)
    if s < 1e-10:
        return a
    a = a / s
    conv = compute_conv(a)
    best_obj = 2.0 * n * float(np.max(conv)) / (float(np.sum(a)) ** 2)
    best_a = a.copy()
    start = time.monotonic()
    
    for sweep in range(num_sweeps):
        if time.monotonic() - start > time_budget - 2:
            break
        any_change = False
        S = float(np.sum(a))
        
        for i in range(n):
            if time.monotonic() - start > time_budget - 2:
                break
            
            x_old = a[i]
            S_without = S - x_old
            
            k_start = i  # smallest k such that k-i >= 0
            k_end = min(2*n-2, i+n-1)  # largest k such that k-i <= n-1
            
            # M_outside: max of conv[k] for k not in [k_start, k_end] and k != 2i
            if 2*n-1 > 0:
                # Create mask
                inside = np.zeros(2*n-1, dtype=bool)
                inside[k_start:k_end+1] = True
                if 2*i < 2*n-1:
                    inside[2*i] = False
                if np.any(~inside):
                    M_outside = float(np.max(conv[~inside]))
                else:
                    M_outside = -np.inf
            else:
                M_outside = -np.inf
            
            # For in-range (k in [k_start, k_end], k != 2i):
            # new_conv[k] = conv[k] + 2*a[k-i]*(x - x_old)
            
            # Precompute the in-range conv and a values
            in_range_conv = conv[k_start:k_end+1].copy()
            in_range_a = a[k_start-i : k_end-i+1].copy()  # a[k-i] for k in [k_start, k_end]
            
            # Remove the 2i entry
            if 2*i >= k_start and 2*i <= k_end:
                idx_2i = 2*i - k_start
                mask_no_2i = np.ones(len(in_range_conv), dtype=bool)
                mask_no_2i[idx_2i] = False
                in_range_conv_no2i = in_range_conv[mask_no_2i]
                in_range_a_no2i = in_range_a[mask_no_2i]
            else:
                in_range_conv_no2i = in_range_conv
                in_range_a_no2i = in_range_a
            
            conv_2i = conv[2*i] if 2*i < 2*n-1 else 0.0
            
            # 1D search
            x_lo = 0.0
            x_hi = max(2.0 * x_old + 0.01, S / (4*n))
            x_hi = min(x_hi, S)
            
            x_grid = np.linspace(x_lo, x_hi, num_evals)
            best_x = x_old
            best_g = np.inf
            
            # Vectorized: for each x in x_grid, compute max
            # new_conv_in_range = in_range_conv_no2i + 2 * in_range_a_no2i[None,:] * (x_grid[:,None] - x_old)
            # max_in_range = max over axis=1
            # new_conv_2i = conv_2i + x_grid^2 - x_old^2
            # M_new = max(M_outside, max_in_range, new_conv_2i)
            # g = 2n * M_new / (S_without + x_grid)^2
            
            delta = x_grid - x_old  # shape (num_evals,)
            
            if len(in_range_conv_no2i) > 0:
                # (num_evals, len(in_range))
                in_range_new = in_range_conv_no2i[None, :] + 2.0 * in_range_a_no2i[None, :] * delta[:, None]
                max_in = np.max(in_range_new, axis=1)
            else:
                max_in = np.full(num_evals, -np.inf)
            
            new_2i = conv_2i + x_grid * x_grid - x_old * x_old
            
            M_new = np.maximum(np.maximum(M_outside, max_in), new_2i)
            s_grid = S_without + x_grid
            valid = s_grid > 1e-10
            g_vals = np.where(valid, 2.0 * n * M_new / (s_grid * s_grid), np.inf)
            
            idx_best = int(np.argmin(g_vals))
            best_x = float(x_grid[idx_best])
            best_g = float(g_vals[idx_best])
            
            # Refine
            lo = x_grid[max(0, idx_best - 2)]
            hi = x_grid[min(num_evals-1, idx_best + 2)]
            if hi > lo:
                x_fine = np.linspace(lo, hi, 50)
                delta_f = x_fine - x_old
                if len(in_range_conv_no2i) > 0:
                    in_range_f = in_range_conv_no2i[None, :] + 2.0 * in_range_a_no2i[None, :] * delta_f[:, None]
                    max_in_f = np.max(in_range_f, axis=1)
                else:
                    max_in_f = np.full(50, -np.inf)
                new_2i_f = conv_2i + x_fine * x_fine - x_old * x_old
                M_new_f = np.maximum(np.maximum(M_outside, max_in_f), new_2i_f)
                s_f = S_without + x_fine
                valid_f = s_f > 1e-10
                g_f = np.where(valid_f, 2.0 * n * M_new_f / (s_f * s_f), np.inf)
                idx_f = int(np.argmin(g_f))
                if g_f[idx_f] < best_g:
                    best_x = float(x_fine[idx_f])
                    best_g = float(g_f[idx_f])
            
            if abs(best_x - x_old) > 1e-10:
                a[i] = best_x
                S = S + (best_x - x_old)
                any_change = True
        
        # Recompute conv and check
        conv = compute_conv(a)
        S = float(np.sum(a))
        obj = 2.0 * n * float(np.max(conv)) / (S * S)
        if obj < best_obj - 1e-12:
            best_obj = obj
            best_a = a.copy()
        if not any_change:
            break
    
    return best_a

**Alternative: Semidefinite programming (SDP) relaxation**

The problem can be formulated as:
minimize `t`
subject to `conv(a,a)[k] <= t` for all k
`sum(a) = 1`
`a >= 0`

The objective is `2n * t`.

This is a linear program! (Linear in a and t, with linear constraints.)

Wait, is it? `conv(a,a)[k] = sum_j a[j]*a[k-j]` is quadratic in a. So it's NOT a linear program. It's a quadratic program (QP).

Specifically, it's a QP with quadratic constraints, which is in general NP-hard. But for our specific structure (the constraints are quadratic with a specific Toeplitz pattern), there might be special structure we can exploit.

Actually, the LP approach in the previous code was:
- Fix a, solve LP for g: max sum(g) s.t. (a*g)[k] <= M, g >= 0
- This is linear in g because a is fixed

This is the "alternating direction" approach, which is valid but might be slow.

For the direct QP:
minimize t
subject to `a^T T_k a <= t` for all k (where T_k is a matrix)
`sum(a) = 1`
`a >= 0`

This is a quadratically constrained program (QCP). It's non-convex because the constraints `a^T T_k a <= t` are not convex in general.

However, if we fix t, the feasible set is: `a^T T_k a <= t` for all k, which is the intersection of ellipsoids (if T_k is PSD) or hyperboloids (if T_k is indefinite). This is in general non-convex.

So direct QP solving is not straightforward. Let me stick with the coordinate descent + mirror descent approach.

import numpy as np
import time

def compute_conv(a):
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)
    return conv[:2*n-1]

def obj_val(a):
    n = len(a)
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)
