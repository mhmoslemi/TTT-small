```
    # Phase 2: LP polishing
    a = best_a.copy()
    a = lp_polish(a, time_budget=300)
    obj = compute_obj(a)
    if obj < best_obj:
        best_obj = obj
        best_a = a.copy()
    
    # Phase 3: More coordinate descent
    a = best_a.copy()
    a = coordinate_descent(a, max_sweeps=50, time_budget=300)
    obj = compute_obj(a)
    if obj < best_obj:
        best_obj = obj
        best_a = a.copy()
    
    # Phase 4: Try different n

        a_res = resample(best_a, n_try)
        a_res = coordinate_descent(a_res, max_sweeps=20, time_budget=60)
        obj = compute_obj(a_res)
        if obj < best_obj:
            best_obj = obj
            best_a = a_res.copy()
    
    # Phase 5: Final polish
    a = best_a.copy()
    a = lp_polish(a, time_budget=100)
    obj = compute_obj(a)
    if obj < best_obj:
        best_obj = obj
        best_a = a.copy()
    
    # Return
    return [float(x) for x in best_a]
```

Now let me think about the coordinate descent implementation more carefully.

For coordinate i with current value v = a[i]:
- G[k] = 2*a[k-i] for k in [i, i+n-1] (and 0 otherwise)
- H[k] = 1 if k == 2i, else 0
- f(delta) = max_k (conv[k] + delta*G[k] + delta^2*H[k])
- Minimize f(delta) subject to delta >= -v

Since f is convex (max of affine and convex quadratic functions), and we're minimizing over a 1D domain [−v, ∞), we can use:
- If v > 0: the domain is [−v, ∞). Since f(∞) = ∞ (the quadratic term dominates), the minimum is finite.
- We can use bisection on the subgradient.

The subgradient of f at delta is:
∂f(delta) = {G[k] + 2*delta*H[k] : k in argmax_k (conv[k] + delta*G[k] + delta^2*H[k])}

So the minimum is where 0 is in the subgradient, i.e., where there exists an active k such that G[k] + 2*delta*H[k] <= 0, and for all active k', G[k'] + 2*delta*H[k'] >= 0.

In practice, for most coordinates, the active set at the optimum will include the current peak (k = n-1 or wherever the max is) and possibly the quadratic term (k = 2i).

Let me just use a robust numerical approach: golden section search on [−v, v_max] where v_max is chosen so that f(v_max) > f(0).

Actually, since f is convex, I'll use the following:
1. Evaluate f at delta = 0 (current value): f(0) = max(conv)
2. Evaluate the subgradient at delta = 0: sg = max over active k of G[k]
3. If sg > 0: the minimum is at delta < 0 (decrease a[i])
4. If sg < 0: the minimum is at delta > 0 (increase a[i])
5. If sg = 0: we're at the optimum for this coordinate

Then use bisection to find the exact delta.

Let me code this up properly:

```python
def coordinate_optimize_delta(conv, a, i, n):
    """Find optimal delta for coordinate i. Returns delta_opt."""
    v = a[i]
    
    # G[k] = 2*a[k-i] for k in [i, i+n-1]
    G = np.zeros(2*n-1)
    G[i:i+n] = 2.0 * a
    
    # H[k] = 1 if k == 2i
    H = np.zeros(2*n-1)
    if 2*i < 2*n-1:
        H[2*i] = 1.0
    
    def f(delta):
        return float(np.max(conv + delta*G + delta*delta*H))
    
    def subgrad(delta):
        vals = conv + delta*G + delta*delta*H
        max_val = np.max(vals)
        active = vals >= max_val - 1e-12
        return float(np.max(G[active] + 2*delta*H[active]))
    
    # Lower bound on delta
    lo = -v  # can't make a[i] negative
    
    # Check subgradient at lo
    sg_lo = subgrad(lo)
    if sg_lo >= 0:
        return 0.0  # already at boundary, can't improve
    
    # Find upper bound where subgradient >= 0
    hi = 1e-6
    for _ in range(60):
        sg_hi = subgrad(hi)
        if sg_hi >= 0:
            break
        hi *= 2
    
    # Bisection
    for _ in range(60):
        mid = (lo + hi) / 2
        if subgrad(mid) < 0:
            lo = mid
        else:
            hi = mid
    
    return (lo + hi) / 2
```

This should be fast: each subgradient evaluation is O(n) (to compute the active set), and we do about 120 evaluations per coordinate. For n=600, that's about 72K operations per coordinate, and 600 coordinates per sweep, so about 43M operations per sweep. That's manageable.

Actually, I can speed this up by noting that the active set changes only at "breakpoints" where two convolution values are equal. Between breakpoints, the active set is constant, and the subgradient is linear in delta. So I can find the optimal delta analytically.

Let me also think about the LP polishing more carefully.

The LP: min M subject to conv(a, g)[k] <= M for all k, sum(g) = 1, g >= 0.

This has n+1 variables (g_0, ..., g_{n-1}, M) and 2n constraints (2n-1 inequality + 1 equality). For n=600, that's 601 variables and 1200 constraints. HiGHS should solve this in < 1 second.

The solution g* gives us a direction to move. The optimal M* tells us the "best achievable" max_conv if we could instantaneously jump to g*. We can use this for line search.

After solving the LP, we update: a_new = (1-t)*a + t*g* for some t in (0, 1]. We want to choose t to minimize the objective. Since the objective is not convex in t (it involves conv(a_new, a_new) which is quadratic in t), we can use a line search.

Actually, conv((1-t)a + tg, (1-t)a + tg) = (1-t)^2 conv(a,a) + 2t(1-t) conv(a,g) + t^2 conv(g,g).

So max_k [(1-t)^2 C[k] + 2t(1-t) D[k] + t^2 E[k]] where C = conv(a,a), D = conv(a,g), E = conv(g,g).

This is a 1D function of t (piecewise, since we take max over k). We can minimize it using golden section search or by finding the breakpoints.

For a "good" sequence, M is proportional to 1/n (since the sum of all convolution values is 1, and there are 2n-1 values, so the average is 1/(2n-1) ≈ 1/(2n)). The peak M is at least the average, so M >= 1/(2n-1), giving objective >= 2n/(2n-1) ≈ 1.

But we can't achieve M = 1/(2n-1) because of the boundary effects (conv[0] = a[0]^2, etc.). The more "spread out" the sequence is, the closer we can get to the uniform convolution.

So the theoretical minimum is 1 (achieved as n -> infinity with a perfectly flat convolution), and the practical minimum depends on n and the algorithm.

For n=600, the bound is 2n/(2n-1) = 1200/1199 ≈ 1.0008. So there's a lot of room for improvement, but in practice we're limited by the algorithm.

```python
"""
Coordinate descent + LP alternating optimization for minimizing
2*n*max(conv(a,a))/(sum(a))^2 with non-negative a.
Uses exact 1D subproblem solving per coordinate, with LP polishing
and multi-start to escape local minima.
"""

import numpy as np
from scipy.optimize import linprog
from scipy.fft import rfft, irfft
import time


def compute_conv(a):
    """Compute linear convolution a*a using FFT. Returns array of length 2n-1."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    conv = irfft(fa * fa, size)
    return conv[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)


def fft_convolve(a, b):
    """Linear convolution of a and b using FFT."""
    n, m = len(a), len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = rfft(a, size)
    fb = rfft(b, size)
    return irfft(fa * fb, size)[:n + m - 1]


def resample_sequence(a, new_n):
    """Resample sequence to new length via interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n < 2:
        return np.ones(new_n)
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return a_new


def coordinate_descent(a, max_sweeps=200, time_budget=60.0, verbose=False):
    """
    Coordinate descent: exactly minimize the objective with respect to one
    coordinate at a time. The 1D subproblem is convex and solved by bisection
    on the subgradient.
    """
    n = len(a)
    a = a.astype(np.float64).copy()
    s = np.sum(a)
    if s < 1e-10:
        return a
    a = a / s  # normalize to sum=1

    conv = compute_conv(a)
    best_obj = float(np.max(conv))
    start = time.monotonic()
    prev_best = best_obj

    for sweep in range(max_sweeps):
        if time.monotonic() - start > time_budget:
            break

        # Precompute G vectors for efficiency
        # G_i[k] = 2*a[k-i] for k in [i, i+n-1], else 0
        # We'll compute these on the fly for each coordinate

        total_improvement = 0.0
        for i in range(n):
            v = a[i]
            if v < 1e-15:
                # Can only increase
                delta_lo = 0.0
            else:
                delta_lo = -v

            # G[k] = 2*a[k-i] for valid k
            G = np.zeros(2 * n - 1)
            G[i:i + n] = 2.0 * a

            H = np.zeros(2 * n - 1)
            if 2 * i < 2 * n - 1:
                H[2 * i] = 1.0

            # Find optimal delta by bisection on subgradient
            def subgrad_at(delta):
                vals = conv + delta * G + delta * delta * H
                max_val = np.max(vals)
                active = vals >= max_val - 1e-10 * max(1.0, max_val)
                return float(np.max(G[active] + 2.0 * delta * H[active]))

            # Check if we can improve by decreasing (delta < 0)
            sg_at_lo = subgrad_at(delta_lo)
            if sg_at_lo >= 0:
                # Can't decrease; check if we should increase
                pass
            else:
                # Minimum is to the right of delta_lo
                pass

            # Check subgradient at delta=0
            sg_at_0 = subgrad_at(0.0)
            if sg_at_0 < 0:
                # Should increase a[i]: search in [0, upper]
                lo = 0.0
                hi = max(v, 1e-3)
                for _ in range(30):
                    if subgrad_at(hi) >= 0:
                        break
                    hi *= 2.0
                for _ in range(50):
                    mid = (lo + hi) / 2.0
                    if subgrad_at(mid) < 0:
                        lo = mid
                    else:
                        hi = mid
                delta_opt = (lo + hi) / 2.0
            elif sg_at_0 > 0:
                # Should decrease a[i]: search in [delta_lo, 0]
                hi = 0.0
                lo = delta_lo
                for _ in range(50):
                    mid = (lo + hi) / 2.0
                    if subgrad_at(mid) < 0:
                        lo = mid
                    else:
                        hi = mid
                delta_opt = (lo + hi) / 2.0
                delta_opt = max(delta_opt, delta_lo)
            else:
                delta_opt = 0.0

            # Apply
            if abs(delta_opt) > 1e-14:
                new_val = v + delta_opt
                if new_val < 0:
                    new_val = 0.0
                old_val = a[i]
                a[i] = new_val
                # Update conv incrementally
                # conv_new[k] = conv[k] + delta*G_old[k] + delta^2*H[k]
                # But G was computed with old a, and we've changed a[i]
                # The increment is: delta * 2 * a_old[k-i] + delta^2 * H[k]
                # where a_old = a before this update
                # Since G[i:i+n] = 2*a_old, and we set a[i] = new_val:
                # G[i:i+n] is still 2*a_old (computed before update)
                # So: conv += delta * G + delta^2 * H
                delta_actual = new_val - old_val
                conv += delta_actual * G + delta_actual * delta_actual * H
                total_improvement += abs(delta_actual)

        # Check convergence
        curr_obj = float(np.max(conv))
        if curr_obj < best_obj:
            best_obj = curr_obj

        if abs(prev_best - best_obj) < 1e-12:
            if verbose:
                print(f"  CD sweep {sweep}: converged at obj={best_obj:.8f}")
            break
        prev_best = best_obj

        if verbose and sweep % 10 == 0:
            print(f"  CD sweep {sweep}: obj={best_obj:.8f}")

    # Renormalize
    s = np.sum(a)
    if s > 1e-10:
        a = a / s

    return a


def solve_lp_minpeak(a, time_limit=10):
    """
    Solve LP: min M s.t. conv(a,g)[k] <= M for all k, sum(g)=1, g>=0.
    Returns (g_opt, M_opt) or (None, None).
    """
    n = len(a)
    # Build Toeplitz matrix: A[k, j] = a[k-j] if 0 <= k-j < n, else 0
    # conv(a,g)[k] = sum_j a[k-j] * g[j] (with appropriate bounds)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        # g[j] contributes to conv[k] for k = j to j+n-1
        # conv[k] includes a[k-j] * g[j]
        for k in range(j, j + n):
            A[k, j] = a[k - j]

    # LP: min M
    # Variables: g_0, ..., g_{n-1}, M
    # Objective: [0, 0, ..., 0, 1]
    c = np.zeros(n + 1)
    c[-1] = 1.0

    # Inequality: conv(a,g) - M <= 0 for each k
    # A_ub[g part] = A, A_ub[M part] = -1
    A_ub = np.zeros((2 * n - 1, n + 1))
    A_ub[:, :n] = A
    A_ub[:, n] = -1.0
    b_ub = np.zeros(2 * n - 1)

    # Equality: sum(g) = 1
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([1.0])

    bounds = [(0.0, None)] * n + [(0.0, None)]

    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': time_limit})
        if res.status == 0:
            g = np.maximum(res.x[:n], 0)
            s = np.sum(g)
            if s > 1e-10:
                g = g / s
                M_opt = float(res.x[n])
                return g, M_opt
    except Exception:
        pass
    return None, None


def solve_lp_maxsum(a, M, time_limit=10):
    """
    Solve LP: max sum(g) s.t. conv(a,g)[k] <= M for all k, g>=0.
    Returns (g_opt, sum_opt) or (None, None).
    """
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        for k in range(j, j + n):
            A[k, j] = a[k - j]

    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n

    try:
        res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': time_limit})
        if res.status == 0:
            g = np.maximum(res.x, 0)
            s = float(np.sum(g))
            if s > 1e-10:
                return g / s, s
    except Exception:
        pass
    return None, None


def lp_alternating(a, max_iters=50, time_budget=60.0, verbose=False):
    """LP alternating with line search."""
    n = len(a)
    a = a.astype(np.float64).copy()
    s = np.sum(a)
    if s < 1e-10:
        return a
    a = a / s

    conv = compute_conv(a)
    best_obj = float(np.max(conv))
    start = time.monotonic()
    stall = 0

    for it in range(max_iters):
        if time.monotonic() - start > time_budget:
            break

        M_curr = float(np.max(conv))

        # Solve LP: min M s.t. conv(a,g) <= M, sum(g)=1, g>=0
        g, M_opt = solve_lp_minpeak(a, time_limit=8)
        if g is None:
            # Fallback: use max-sum LP
            g, _ = solve_lp_maxsum(a, M_curr, time_limit=8)
            if g is None:
                break

        # Line search: minimize obj((1-t)*a + t*g) over t in [0,1]
        best_t = 0.0
        best_t_obj = best_obj
        # Use golden section or simple grid
        for t in np.linspace(0.1, 1.0, 20):
            a_try = (1.0 - t) * a + t * g
            a_try = np.maximum(a_try, 0)
            s_try = np.sum(a_try)
            if s_try < 1e-10:
                continue
            a_try = a_try / s_try
            obj_try = compute_obj(a_try)
            if obj_try < best_t_obj:
                best_t_obj = obj_try
                best_t = t

        if best_t_obj < best_obj - 1e-12:
            best_obj = best_t_obj
            a = (1.0 - best_t) * a + best_t * g
            a = np.maximum(a, 0)
            s = np.sum(a)
            if s > 1e-10:
                a = a / s
            conv = compute_conv(a)
            stall = 0
            if verbose:
                print(f"  LP alt {it}: obj={best_obj:.8f}, t={best_t:.3f}")
        else:
            stall += 1
            if stall > 15:
                # Perturb and try again
                rng = np.random.default_rng(it * 7919 + 42)
                a = a * np.exp(rng.normal(0, 0.05, n))
                a = np.maximum(a, 0)
                s = np.sum(a)
                if s > 1e-10:
                    a = a / s
                conv = compute_conv(a)
                stall = 0

    return a


def polish_sequence(a, time_budget=120.0, verbose=False):
    """Intensive polishing combining CD and LP."""
    n = len(a)
    a = a.astype(np.float64).copy()
    start = time.monotonic()

    best_a = a.copy()
    best_obj = float(np.max(compute_conv(a)))

    while time.monotonic() - start < time_budget - 10:
        remaining = time_budget - (time.monotonic() - start)
        if remaining < 15:
            break

        # Coordinate descent
        cd_time = min(remaining * 0.4, 60.0)
        a_new = coordinate_descent(best_a, max_sweeps=100, time_budget=cd_time)
        obj_new = float(np.max(compute_conv(a_new)))
        if obj_new < best_obj:
            best_obj = obj_new
            best_a = a_new.copy()
            if verbose:
                print(f"    CD: {best_obj:.8f}")

        # LP polishing
        remaining = time_budget - (time.monotonic() - start)
        if remaining > 20 and n <= 800:
            lp_time = min(remaining * 0.4, 60.0)
            a_new = lp_alternating(best_a, max_iters=30, time_budget=lp_time)
            obj_new = float(np.max(compute_conv(a_new)))
            if obj_new < best_obj:
                best_obj = obj_new
                best_a = a_new.copy()
                if verbose:
                    print(f"    LP: {best_obj:.8f}")

        # CD again
        remaining = time_budget - (time.monotonic() - start)
        if remaining > 15:
            cd_time = min(remaining * 0.5, 40.0)
            a_new = coordinate_descent(best_a, max_sweeps=100, time_budget=cd_time)
            obj_new = float(np.max(compute_conv(a_new)))
            if obj_new < best_obj:
                best_obj = obj_new
                best_a = a_new.copy()
                if verbose:
                    print(f"    CD2: {best_obj:.8f}")

        # Check for stuck
        if np.allclose(compute_conv(best_a), compute_conv(best_a + 0)):  # always true, just for structure
            pass

    return best_a
```

Looking at this problem, I need to minimize `2*n*max(conv(a,a))/(sum(a))^2` for non-negative sequences. The key insight is that for each coordinate, the 1D subproblem is convex (max of linear/quadratic functions), allowing exact minimization per coordinate via bisection on the subgradient. ```python
"""
Coordinate descent + LP alternating for minimizing 2*n*max(conv(a,a))/(sum(a))^2.
Uses exact 1D subproblem solving (bisection on subgradient) per coordinate,
LP polishing via HiGHS, and multi-start with perturbation to escape local minima.
"""

import numpy as np
from scipy.optimize import linprog
from scipy.fft import rfft, irfft
import time


def compute_conv(a):
    """Compute linear convolution a*a via FFT. Returns array of length 2n-1."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    conv = irfft(fa * fa, size)
    return conv[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)


def resample_sequence(a, new_n):
    """Resample sequence to new length via linear interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n < 2:
        return np.ones(new_n) / new_n
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return a_new


def coordinate_descent(a, max_sweeps=200, time_budget=60.0, verbose=False):
    """
    Exact coordinate descent: for each coordinate i, solve the 1D convex
    subproblem minimizing max_k conv_new[k] where conv_new depends quadratically
    (at k=2i) and linearly (elsewhere) on the change delta. Use bisection on
    the subgradient to find the exact minimizer.
    """
    n = len(a)
    a = a.astype(np.float64).copy()
    s = np.sum(a)
    if s < 1e-10:
        return a
    a = a / s

    conv = compute_conv(a)
    best_obj = float(np.max(conv))
    start = time.monotonic()
    prev_best = best_obj + 1.0

    for sweep in range(max_sweeps):
        if time.monotonic() - start > time_budget:
            break

        for i in range(n):
            v = a[i]
            delta_lo = -v if v > 0 else 0.0

            # G[k] = 2*a[k-i] for k in [i, i+n-1]
            G = np.zeros(2 * n - 1)
            G[i:i + n] = 2.0 * a

            H = 1.0 if 2 * i < 2 * n - 1 else 0.0
            h_idx = 2 * i

            # Subgradient evaluation
            def sg_at(delta):
                vals = conv + delta * G
                if H > 0:
                    vals[h_idx] += delta * delta
                max_val = np.max(vals)
                thresh = max_val - 1e-12 * max(1.0, abs(max_val))
                active = vals >= thresh
                sg = G[active].copy()
                if H > 0 and active[h_idx]:
                    sg = np.maximum(sg, G[h_idx] + 2.0 * delta)
                return float(np.max(sg))

            sg0 = sg_at(0.0)

            if abs(sg0) < 1e-10:
                continue

            if sg0 < 0:
                # Optimal delta > 0 (increase a[i])
                lo = 0.0
                hi = max(v * 0.5, 1e-4)
                for _ in range(40):
                    if sg_at(hi) >= 0:
                        break
                    hi *= 2.5
                for _ in range(50):
                    mid = (lo + hi) * 0.5
                    if sg_at(mid) < 0:
                        lo = mid
                    else:
                        hi = mid
                delta_opt = (lo + hi) * 0.5
            else:
                # Optimal delta < 0 (decrease a[i])
                hi = 0.0
                lo = delta_lo
                for _ in range(50):
                    mid = (lo + hi) * 0.5
                    if sg_at(mid) < 0:
                        lo = mid
                    else:
                        hi = mid
                delta_opt = (lo + hi) * 0.5
                delta_opt = max(delta_opt, delta_lo)

            if abs(delta_opt) < 1e-14:
                continue

            new_val = v + delta_opt
            if new_val < 0:
                new_val = 0.0
            actual_delta = new_val - v
            if abs(actual_delta) < 1e-14:
                continue

            a[i] = new_val
            # Incremental conv update
            conv += actual_delta * G
            if H > 0:
                conv[h_idx] += actual_delta * actual_delta

        # Renormalize after each sweep
        s = np.sum(a)
        if s > 1e-10:
            if abs(s - 1.0) > 1e-10:
                a = a / s
                conv = compute_conv(a)

        curr_obj = float(np.max(conv))
        if curr_obj < best_obj:
            best_obj = curr_obj

        if abs(prev_best - best_obj) < 1e-13:
            if sweep > 2:
                break
        prev_best = best_obj

        if verbose and sweep % 20 == 0:
            print(f"    CD sweep {sweep}: max_conv={best_obj:.10f}, elapsed={time.monotonic()-start:.1f}s")

    a = np.maximum(a, 0.0)
    s = np.sum(a)
    if s > 1e-10:
        a = a / s
    return a


def build_toeplitz(a):
    """Build matrix A where (A@g)[k] = conv(a,g)[k]."""
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        A[j:j + n, j] = a[:]
    return A


def solve_lp_minpeak(a, time_limit=10):
    """LP: min M s.t. conv(a,g)[k] <= M, sum(g)=1, g>=0."""
    n = len(a)
    A = build_toeplitz(a)
    c = np.zeros(n + 1)
    c[-1] = 1.0
    A_ub = np.zeros((2 * n - 1, n + 1))
    A_ub[:, :n] = A
    A_ub[:, n] = -1.0
    b_ub = np.zeros(2 * n - 1)
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([1.0])
    bounds = [(0.0, None)] * n + [(0.0, None)]
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': time_limit})
        if res.status == 0:
            g = np.maximum(res.x[:n], 0)
            s = np.sum(g)
            if s > 1e-10:
                return g / s, float(res.x[n])
    except Exception:
        pass
    return None, None


def solve_lp_maxsum(a, M, time_limit=10):
    """LP: max sum(g) s.t. conv(a,g)[k] <= M, g>=0."""
    n = len(a)
    A = build_toeplitz(a)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': time_limit})
        if res.status == 0:
            g = np.maximum(res.x, 0)
            s = float(np.sum(g))
            if s > 1e-10:
                return g / s, s
    except Exception:
        pass
    return None, None


def lp_alternating(a, max_iters=50, time_budget=60.0, verbose=False):
    """LP alternating with line search for step size."""
    n = len(a)
    a = a.astype(np.float64).copy()
    s = np.sum(a)
    if s < 1e-10:
        return a
    a = a / s

    conv = compute_conv(a)
    best_obj = float(np.max(conv))
    start = time.monotonic()
    stall = 0

    for it in range(max_iters):
        if time.monotonic() - start > time_budget:
            break

        M_curr = float(np.max(conv))

        # Solve min-peak LP
        g, M_opt = solve_lp_minpeak(a, time_limit=8)
        if g is None:
            g, _ = solve_lp_maxsum(a, M_curr, time_limit=8)
            if g is None:
                break

        # Line search
        best_t = 0.0
        best_t_obj = best_obj
        t_vals = np.concatenate([np.linspace(0.05, 0.5, 10), np.linspace(0.5, 1.0, 11)])
        for t in t_vals:
            a_try = (1.0 - t) * a + t * g
            a_try = np.maximum(a_try, 0)
            s_try = np.sum(a_try)
            if s_try < 1e-10:
                continue
            a_try = a_try / s_try
            obj_try = compute_obj(a_try)
            if obj_try < best_t_obj:
                best_t_obj = obj_try
                best_t = t

        if best_t_obj < best_obj - 1e-13:
            best_obj = best_t_obj
            a = (1.0 - best_t) * a + best_t * g
            a = np.maximum(a, 0)
            s = np.sum(a)
            if s > 1e-10:
                a = a / s
            conv = compute_conv(a)
            stall = 0
            if verbose:
                print(f"    LP iter {it}: max_conv={best_obj:.10f}, t={best_t:.3f}")
        else:
            stall += 1
            if stall > 10:
                rng = np.random.default_rng(it * 7919 + 42)
                a = a * np.exp(rng.normal(0, 0.03, n))
                a = np.maximum(a, 0)
                s = np.sum(a)
                if s > 1e-10:
                    a = a / s
                conv = compute_conv(a)
                stall = 0
            elif stall > 5:
                break

    return a


def polish_sequence(a, time_budget=120.0, verbose=False):
    """Intensive polishing: alternate CD and LP."""
    n = len(a)
    a = a.astype(np.float64).copy()
    start = time.monotonic()
    best_a = a.copy()
    best_obj = float(np.max(compute_conv(a)))
    round_num = 0

    while time.monotonic() - start < time_budget - 8:
        remaining = time_budget - (time.monotonic() - start)
        if remaining < 15:
            break
        round_num += 1

        # CD step
        cd_time = min(remaining * 0.35, 50.0)
        a_new = coordinate_descent(best_a, max_sweeps=150, time_budget=cd_time)
        obj_new = compute_obj(a_new)
        if obj_new < best_obj:
            best_obj = obj_new
            best_a = a_new.copy()
            if verbose:
                print(f"    Polish r{round_num} CD: obj={best_obj:.8f}")

        # LP step
        remaining = time_budget - (time.monotonic() - start)
        if remaining > 25 and n <= 800:
            lp_time = min(remaining * 0.35, 50.0)
            a_new = lp_alternating(best_a, max_iters=30, time_budget=lp_time)
            obj_new = compute_obj(a_new)
            if obj_new < best_obj:
                best_obj = obj_new
                best_a = a_new.copy()
                if verbose:
                    print(f"    Polish r{round_num} LP: obj={best_obj:.8f}")

        # Quick CD
        remaining = time_budget - (time.monotonic() - start)
        if remaining > 15:
            a_new = coordinate_descent(best_a, max_sweeps=50,
                                       time_budget=min(remaining * 0.4, 25.0))
            obj_new = compute_obj(a_new)
            if obj_new < best_obj:
                best_obj = obj_new
                best
