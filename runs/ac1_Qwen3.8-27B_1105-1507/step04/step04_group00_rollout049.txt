This is getting messy. Let me take a step back and design a cleaner algorithm.

**Clean Design:**

The core optimization problem is:
minimize  M(a) = max_k (a*a)[k]
subject to  sum(a) = 1, a >= 0

I'll use the following methods in sequence:

**Method 1: Smoothed Gradient Descent (SGD)**
- Use f_tau(a) = (1/tau) log sum_k exp(tau * (a*a)[k]) as a smooth approximation
- Gradient is well-defined and can be computed efficiently
- Use backtracking line search for the step size
- Animate tau from small to large
- Project onto simplex after each step (just clip and normalize)

**Method 2: Nesterov Accelerated Gradient (FISTA)**
- Same smooth objective, but with Nesterov momentum
- This should converge faster (O(1/k^2) vs O(1/k) in iterations to reach a given accuracy)

**Method 3: Frank-Wolfe with Away Steps (FW-AS)**
- Use the exact subgradient of M(a)
- Each iteration: compute subgradient, find closest and farthest vertices, take a step
- This converges to a stationary point of the non-convex problem
- No projection needed (the step is within the simplex by construction)

**Method 4: LP Mirror Descent**
- At each step, solve an LP to find the best response g
- Update a <- (1-t)*a + t*g
- This is the most precise method but the slowest per iteration

**Method 5: Coordinate Descent / Pairwise Swaps**
- Try swapping pairs of values, or adjusting individual coordinates
- Very fast per iteration, can be run many times

Let me implement all of these and combine them in a time-budgeted pipeline.

For the Frank-Wolfe method, I need to be careful about:
- Computing the subgradient: find all k where conv_k is within epsilon of max, compute the average gradient
- The step size: use 2/(t+2) or line search
- The away step: find the active coordinate with the largest gradient component

def fast_conv(a):
    """Full self-convolution via FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]


def compute_J(a):
    """Compute J(a) = 2*n*max(conv(a,a))/(sum(a))^2."""
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))


def smooth_gradient(a, tau):
    """
    Compute gradient of f_tau(a) = (1/tau)*log(sum_k exp(tau*conv_k(a)))
    Returns (gradient, softmax_weights, conv).
    """
    n = len(a)

    b_max = b.max()
    exp_arg = np.clip(tau * (b - b_max), -50, 50)
    exp_b = np.exp(exp_arg)
    p = exp_b / exp_b.sum()

        hi = min(n - 1, k)
        grad[lo:hi + 1] += 2.0 * pk * a[k - hi:k - lo + 1][::-1]
    return grad, p, b
