  g^{(k)}_j = 2 * a[k-j] (if 0 <= k-j < n, else 0)

The subgradient is the convex hull of {g^{(k)} : k in active_set}.
For the steepest descent direction, we use g = sum_k w_k * g^{(k)} where w_k is the "weight" (uniform over active set for max, or softmax for smoothed max).

Now, for FISTA on the smoothed version:
f_smooth(a) = (1/tau) * log(sum_k exp(tau * (a*a)_k))

grad f_smooth(a)_j = (1/tau) * sum_k exp(tau*(a*a)_k) * 2*a[k-j] / sum_l exp(tau*(a*a)_l)
= 2 * sum_k w_k * a[k-j] (where w is the softmax)

This can be computed efficiently! Let me think about how:
grad_j = 2 * sum_k w_k * a[k-j] for 0<=k-j<n

This is the cross-correlation of w and a, evaluated at specific lags.

Let me define: (w ⋆ a)(m) = sum_k w(k) * a(k-m)
Then grad_j = 2 * (w ⋆ a)(j)

The cross-correlation can be computed via FFT:
(w ⋆ a) = ifft(conj(FFT(w)) * FFT(a))

So the full gradient is:
grad = 2 * ifft(conj(FFT(w_padded)) * FFT(a_padded))[:n]

where w_padded is w zero-padded to at least 2n-1 length, and a_padded is a zero-padded to the same length.

Wait, I need to be careful. w has length 2n-1 (the convolution length), and a has length n.

Let me define:
- w_hat[k] = w[k] for k=0..2n-2, 0 otherwise (length >= 2n-1)
- a_hat[k] = a[k] for k=0..n-1, 0 otherwise (length >= 2n-1)

Then (w_hat ⋆ a_hat)(j) = sum_k w_hat[k] * a_hat[k-j]
= sum_{k=max(0,j)}^{min(2n-2, j+n-1)} w[k] * a[k-j]
= sum_{i=0}^{min(n-1, 2n-2-j)} w[i+j] * a[i]

And I want grad_j = 2 * this, for j = 0, ..., n-1.

Using FFT:
(w_hat ⋆ a_hat) = ifft(conj(FFT(w_hat)) * FFT(a_hat))

This gives a circular cross-correlation, so I need to zero-pad to at least (2n-1) + n - 1 = 3n - 2 to avoid wrap-around.

So: pad both w and a to length L >= 3n-1, compute FFT, multiply, IFFT, take first n elements.

For n=2048, L >= 6143, so L = 8192. FFT of length 8192 is very fast.

from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time

def fast_conv(a):
    """Full self-convolution via FFT."""
    n = len(a)
    size = 1
    while size < 2*n-1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa*fa, size)[:2*n-1]

def compute_J(a):
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s*s))

def project_simplex(a, r=1.0):
    """Project onto {x >= 0, sum(x) = r}."""
    n = len(a)
    # Project onto {x >= 0, sum(x) = r}
    # This is the same as projecting (a - r/n) onto the simplex {x >= 0, sum(x) = 0} + r/n
    # Standard algorithm:
    u = a - r/n
    # Sort in descending order
    s = np.sort(u)[::-1]
    # Find rho
    cssv = np.cumsum(s)
    rho = np.nonzero(s * np.arange(1, n+1) > (cssv - r/n))[0][-1]
    theta = (cssv[rho] - r/n) / (rho + 1.0)
    return np.maximum(a - theta, 0)

    # ||grad|| <= 2 * ||w|| * ||a|| = 2 (in the worst case, but typically much less)
    # The Hessian is bounded by 2*tau * (something related to the convolution operator)
    # Let me just use a safe step size with backtracking.

    prev_f = None

            break

        else:

        # = 2 * cross-correlation of w and y at lag j

        y_pad[:n] = y

        fw = np.fft.rfft(w_pad)

import numpy as np
from scipy.optimize import linprog

def fast_conv(a):
    """Full self-convolution via FFT."""
    n = len(a)
    if n == 0:
        return np.array([0.0])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]


def compute_J(a):
    """Compute J(a) = 2*n*max(conv(a,a))/(sum(a))^2."""
    a = np.maximum(np.asarray(a, dtype=np.float64), 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))


def project_nonneg_sum1(a):
    """Project onto {x >= 0, sum(x) = 1} using water-filling."""

    for _ in range(100):

        cnt = pos.sum()

            return np.ones(n) / n
        theta = (a[pos] .sum() - 1.0) / cnt
        u = np.maximum(a - theta, 0.0)
    # Final normalization
    s = u.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return u / s
