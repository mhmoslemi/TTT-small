- i = j: a[j] * a[k-j] (valid if 0 <= k-j < n)
- i = k-j: a[k-j] * a[j] (valid if 0 <= k-j < n)

These are the same condition! So:
- If 0 <= k-j < n and k-j ≠ j: b[k] includes 2 * a[j] * a[k-j]
- If k-j = j (i.e., k = 2j): b[k] includes a[j]^2
- Otherwise: b[k] doesn't include a[j]

So when a[j] changes by Δ = new - old:
- b[k] changes by 2*Δ*a[k-j] for 0 <= k-j < n, k ≠ 2j
- b[2j] changes by 2*old*Δ + Δ^2 = (new^2 - old^2) for k = 2j

This means only O(n) values of b change. So I can maintain b incrementally!
