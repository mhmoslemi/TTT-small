There are 2n-1 values in the convolution. If they were all equal, each would be S^2/(2n-1), and the score would be 2n/(2n-1) ≈ 1.

But we can't make them all equal because:
- conv(f,f)[0] = f[0]^2
- conv(f,f)[2n-2] = f[n-1]^2
- If f[0] and f[n-1] are small, these are small, but then the sum constraint forces other values to be large.

The constraint is that f ≥ 0 and sum f = S (fixed by normalization).

This is essentially a "flattening" problem: we want to spread the mass of the convolution as evenly as possible.

Key insight: The problem is related to the "flat autocorrelation" problem in signal processing. Sequences with flat autocorrelation are called "ideal" sequences and are used in radar and communications.

For the continuous analogue: if f is a density function on [0,1], we want to minimize max of f*f (convolution) subject to f ≥ 0 and ∫f = 1. The uniform density gives f*f a triangular shape with max 1 at the center. The "flat" convolution would be a top-hat, which corresponds to f being the inverse of a top-hat in Fourier space, which would be a sinc-like function (which can be negative).

So for non-negative f, we can't achieve a perfectly flat autocorrelation. The question is how close we can get.
