   **Key new idea: Use the structure of the problem more directly.**

   The objective is: minimize max_k (f*f)[k] subject to sum(f)=1, f>=0.

   This is equivalent to: find the smallest M such that there exists f>=0, sum(f)=1, with (f*f)[k] <= M for all k.

   This is a non-convex problem (the constraint involves products of f), but we can use bisection on M combined with feasibility checking.

   For a given M, the feasibility problem is:
   Find f such that:
   - f >= 0
   - sum(f) = 1
   - (f*f)[k] <= M for all k = 0, ..., 2n-2

   The constraints (f*f)[k] <= M are quadratic (bilinear) in f, so this is a non-convex feasibility problem. However, we can use it as a stopping criterion for iterative methods.

   **Better approach: Iterative watermarking / power iteration style**

   Think of it this way: if (f*f)[k] > M for some k, we want to reduce f at positions that contribute to (f*f)[k]. The positions that contribute to (f*f)[k] are the pairs (i, k-i).

   An iterative approach:
   1. Start with f (normalized)
   2. Compute C = conv(f, f)
   3. For each position k where C[k] > M_target, reduce f[i] and f[k-i] for the contributing pairs
   4. Renormalize
   5. Repeat

   This is similar to the "water-filling" or "peeling" approach.

   **Even better: Use the dual problem.**

   The problem min_{f>=0, sum(f)=1} max_k (f*f)[k] can be approached via:
   - Parametric: find smallest M s.t. feasibility holds

   **Algorithm: Iterative Convolution Flattening**
