And ∂c_m/∂x_j = x_{m-j} (if 0 ≤ m-j < n) + x_{j-m} (if 0 ≤ j-m < n, j ≠ m-j)
             = x_{m-j} (if 0 ≤ m-j < n) + x_{j-m} (if 0 ≤ j-m < n)
             (when j = m-j, i.e., 2j = m, we get 2*x_j, which is correctly counted by both terms)

So (L^T p)_j = sum_m p_m * [x_{m-j} * 1(0≤m-j<n) + x_{j-m} * 1(0≤j-m<n)]

Let me define the "cross-correlation" of p and x:
(cc1)_j = sum_m p_m * x_{m-j} * 1(0≤m-j<n, 0≤m<2n-1)
(cc2)_j = sum_m p_m * x_{j-m} * 1(0≤j-m<n, 0≤m<2n-1)

For cc1: m-j ranges from 0 to n-1, so m ranges from j to j+n-1. Also 0 ≤ m ≤ 2n-2.
So m ranges from max(0, j) to min(2n-2, j+n-1).
Let k = m-j: k ranges from 0 to min(n-1, 2n-2-j).
cc1_j = sum_{k=0}^{min(n-1, 2n-2-j)} p_{j+k} * x_k

For cc2: j-m ranges from 0 to n-1, so m ranges from j-(n-1) to j. Also 0 ≤ m ≤ 2n-2.
So m ranges from max(0, j-n+1) to min(2n-2, j).
Let k = j-m: k ranges from 0 to min(n-1, j).
cc2_j = sum_{k=0}^{min(n-1, j)} p_{j-k} * x_k

So grad_j = cc1_j + cc2_j.

Now, cc1 is a "reversed cross-correlation" and cc2 is a "normal cross-correlation". Together they form the gradient.

I can compute these using FFT:
- Pad x to length N (N >= 2n-1, preferably power of 2)
- Pad p to length N
- cc2_j = sum_k x_k * p_{j-k} for 0 ≤ k < n, 0 ≤ j-k < 2n-1
  This is the cross-correlation of x and p, evaluated at lags 0 to n-1.
  In FFT: ifft(fft(x, N) * conj(fft(p, N)))[0:n]
  
  Wait, the cross-correlation of x and p is: (x ⋆ p)(τ) = sum_k x(k+τ) conj(p(k)) = sum_k x(k) conj(p(k-τ))
  
  For real signals: (x ⋆ p)(τ) = sum_k x(k) p(k-τ)
  
  So (x ⋆ p)(j) = sum_k x(k) p(k-j) = sum_k x(k) p(k-j)
  
  But I want cc2_j = sum_k x_k * p_{j-k} = sum_k x(k) p(j-k)
  
  This is (p ⋆ x)(j) = sum_k p(k) x(k-j)... no.
  
  Let me just use: cc2_j = sum_k x_k * p_{j-k}
  If I define the cross-correlation as (f ⋆ g)(j) = sum_k f(k) g(k+j), then:
  cc2_j = sum_k x_k * p_{j-k} = sum_k x_k * p_{-(k-j)} 
  
  Hmm, this is getting confusing with signs. Let me just use np.fft to compute it.

  For the cross-correlation: corr(j) = sum_k a_k * b_{k+j}
  In FFT: correlate(a, b, 'full') can be computed as ifft(fft(a) * conj(fft(b)))

  Actually, in numpy: np.correlate(a, v, mode) computes sum a_{i+k} * conj(v_i) for various lags.

  Let me just use the direct computation for now since n=512 is fast enough.

Let me simplify my approach:

```python
def smooth_grad(x, beta, n):
    """Compute gradient of 2n*logsumexp(beta*conv(x,x))/sum(x)^2"""
    x = np.maximum(x, 1e-15)
    s = x.sum()
    x_norm = x / s
    c = fast_conv(x_norm)
    
    # softmax
    bc = beta * c
    bc_shifted = bc - bc.max()
    p = np.exp(bc_shifted)
    p = p / p.sum()
    
    # Gradient of logsumexp w.r.t. x_norm:
    # grad_cn_j = sum_m p_m * (x_{m-j} + x_{j-m}) [with bounds]
    grad_cn = np.zeros(n)
    for j in range(n):
        # First term: sum_m p_m * x_{m-j} for 0<=m-j<n, 0<=m<2n-1
        # m from j to min(2n-2, j+n-1)
        m_start = j
        m_end = min(2*n-1, j+n)
        if m_start < m_end:
            k = np.arange(0, m_end - m_start)
            grad_cn[j] += np.dot(p[m_start:m_end], x_norm[k])
        # Second term: sum_m p_m * x_{j-m} for 0<=j-m<n, 0<=m<2n-1
        # m from max(0, j-n+1) to min(2n-2, j)
        m_start2 = max(0, j-n+1)
        m_end2 = min(2*n-1, j+1)
        if m_start2 < m_end2:
            k = j - np.arange(m_start2, m_end2)
            grad_cn[j] += np.dot(p[m_start2:m_end2], x_norm[k])
    
    # Chain rule for normalization: x_norm = x/s
    # d(x_norm_i)/d(x_j) = (delta_ij * s - x_i) / s^2
    # d(f)/d(x_j) = sum_i (d(f)/d(x_norm_i)) * (d(x_norm_i)/d(x_j))
    #              = (grad_cn_j * s - x_j * sum(grad_cn)) / s
    #              = (grad_cn_j - x_norm_j * sum(grad_cn)) / s
    
    sum_g = grad_cn.sum()
    grad = (grad_cn - x_norm * sum_g) / s
    
    return grad
```

This is O(n²) per gradient evaluation. For n=512, that's about 262K multiply-adds per gradient. Very fast.

Now, for the optimization, I'll use:
1. L-BFGS-B with bounds [0, None] for each component
2. Multiple beta values (annealing from low to high)
3. Multiple starting points

Let me also add a **variance-minimizing objective** as an alternative:
minimize sum_m (c_m - mean(c))² subject to sum(x) = 1, x >= 0

This directly targets making the convolution flat, which is what we want. The gradient is simpler:
d/dx_j sum_m (c_m - mean(c))² = 2 * sum_m (c_m - mean(c)) * dc_m/dx_j

And dc_m/dx_j is the same as before.

Actually, the mean of c is (sum x)² / (2n-1) (since sum_m c_m = (sum x)²). So for normalized x (sum = 1), mean(c) = 1/(2n-1).

So the objective is: sum_m (c_m - 1/(2n-1))²

And minimizing this is equivalent to minimizing the variance of the convolution, which is a good proxy for minimizing the max.

Let me combine both objectives: minimize max(c) (via log-sum-exp) + λ * variance(c)

This should give a better landscape for optimization.

```python
"""
Minimizes J(a) = 2*n*max(convolve(a,a))/(sum(a))^2 using:
1. Multi-start smooth gradient descent with log-sum-exp and variance objectives
2. LP best-response refinement
3. Coordinate descent / local search
4. Adaptive time allocation
"""

import numpy as np
from scipy.optimize import linprog, minimize
import time

def fast_conv(a):
    n = len(a)
    s = 1
    while s < 2 * n - 1:
        s <<= 1
    fa = np.fft.rfft(a, s)
    return np.fft.irfft(fa * fa, s)[:2 * n - 1]

def compute_score(a):
    a = np.clip(a, 0.0, 1000.0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    n = len(a)
    b = fast_conv(a)
    return float(2.0 * n * b.max() / (s * s))

def build_conv_matrix(a):
    n = len(a)
    m = 2 * n - 1
    A = np.zeros((m, n))
    for k in range(m):
        jl = max(0, k - n + 1)
        jh = min(n - 1, k)
        if jl <= jh:
            A[k, jl:jh+1] = a[k-jh:k-jl+1][::-1]
    return A

def lp_best_response(a, M):
    n = len(a)
    A = build_conv_matrix(a)
    c = -np.ones(n)
    res = linprog(c, A_ub=A, b_ub=np.full(2*n-1, M),
                  bounds=[(0, None)] * n, method='highs')
    if res.success and res.x.sum() > 1e-10:
        return res.x
    return None

def smooth_obj_and_grad(x, beta, n, var_weight=0.0):
    """Smooth objective: 2n*logsumexp(beta*conv(x,x))/sum(x)^2 + var_weight*variance(conv(x_norm))"""
    x = np.maximum(x, 1e-15)
    s = x.sum()
    if s < 0.01:
        return 1e10, np.zeros_like(x)
    x_norm = x / s
    c = fast_conv(x_norm)
    
    # Log-sum-exp
    bc = beta * c
    bc_max = bc.max()
    exp_bc = np.exp(bc - bc_max)
    lse = bc_max + np.log(exp_bc.sum())
    
    obj = 2.0 * n * lse / (s * s)
    
    # Optional: add variance penalty
    if var_weight > 0:
        c_mean = 1.0 / (2*n - 1)  # Since sum(c) = (sum(x_norm))^2 = 1
        var = np.sum((c - c_mean)**2)
        obj += var_weight * var
    
    # Gradient of log-sum-exp part
    p = exp_bc / exp_bc.sum()
    
    grad_cn = np.zeros(n)
    for j in range(n):
        # Term 1: sum_m p_m * x_{m-j} for valid indices
        m_lo = j
        m_hi = min(2*n-1, j+n)
        if m_lo < m_hi:
            grad_cn[j] += np.dot(p[m_lo:m_hi], x_norm[:m_hi-m_lo])
        # Term 2: sum_m p_m * x_{j-m} for valid indices
        m_lo2 = max(0, j-n+1)
        m_hi2 = min(2*n-1, j+1)
        if m_lo2 < m_hi2:
            k = j - np.arange(m_lo2, m_hi2)
            grad_cn[j] += np.dot(p[m_lo2:m_hi2], x_norm[k])
    
    # Chain rule for normalization
    sum_g = grad_cn.sum()
    grad = beta * (grad_cn - x_norm * sum_g) / s
    
    # If variance penalty, add its gradient
    if var_weight > 0:
        c_mean = 1.0 / (2*n - 1)
        dc = 2.0 * (c - c_mean)  # d(var)/d(c_m) = 2*(c_m - mean)
        # Gradient of var w.r.t. x_norm:
        grad_var = np.zeros(n)
        for j in range(n):
            m_lo = j
            m_hi = min(2*n-1, j+n)
            if m_lo < m_hi:
                grad_var[j] += np.dot(dc[m_lo:m_hi], x_norm[:m_hi-m_lo])
            m_lo2 = max(0, j-n+1)
            m_hi2 = min(2*n-1, j+1)
            if m_lo2 < m_hi2:
                k = j - np.arange(m_lo2, m_hi2)
                grad_var[j] += np.dot(dc[m_lo2:m_hi2], x_norm[k])
        sum_gv = grad_var.sum()
        grad += var_weight * (grad_var - x_norm * sum_gv) / s
    
    return obj, grad

def smooth_obj_only(x, beta, n, var_weight=0.0):
    val, _ = smooth_obj_and_grad(x, beta, n, var_weight)
    return val

def run_smooth_optimization(a0, deadline, betas=None, var_weight=0.0):
    """Run smooth gradient optimization with beta annealing."""
    n = len(a0)
    if betas is None:
        betas = [10, 50, 200, 1000, 5000, 20000]
    
    best = a0.copy()
    best_score = compute_score(a0)
    
    for beta in betas:
        if time.monotonic() > deadline:
            break
        
        x0 = best.copy()
        x0 = np.maximum(x0, 1e-8)
        
        try:
            res = minimize(
                smooth_obj_only, x0, args=(beta, n, var_weight),
                jac=lambda x, b, nn, vw: smooth_obj_and_grad(x, b, nn, vw)[1],
                method='L-BFGS-B',
                bounds=[(0, None)] * n,
                options={'maxiter': 300, 'maxfun': 5000,
                         'ftol': 1e-18, 'gtol': 1e-14,
                         'iprint': -1}
            )
            if res.fun < 1e10:
                res_x = np.maximum(res.x, 0)
                if res_x.sum() > 0.01:
                    score = compute_score(res_x)
                    if score < best_score:
                        best = res_x.copy()
                        best_score = score
                        print(f"    beta={beta}: score={score:.6f}", flush=True)
        except Exception as e:
            print(f"    beta={beta}: error {e}", flush=True)
    
    return best, best_score

def lp_iteration(a, max_iters, deadline, base_t=0.5):
    """LP best-response iteration."""
    best_local = a.copy()
    best_score = compute_score(a)
    a = np.clip(a, 0.001, None)
    a = a / a.sum()
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        b = fast_conv(a)
        M = float(b.max())
        g = lp_best_response(a, M)
        if g is None or g.sum() < 1e-10:
            break
        g = g / g.sum()
        
        t = max(0.02, base_t * (1.0 - 0.5 * it / max_iters))
        a_new = (1.0 - t) * a + t * g
        a_new = np.clip(a_new, 0, None)
        if a_new.sum() < 1e-10:
            a = a_new
            continue
        a_new = a_new / a_new.sum()
        
        score = compute_score(a_new)
        if score < best_score:
            best_score = score
            best_local = a_new.copy()
            a = a_new
        else:
            t2 = t * 0.2
            a_new2 = (1.0 - t2) * a + t2 * g
            a_new2 = np.clip(a_new2, 0, None)
            if a_new2.sum() > 1e-10:
                a_new2 = a_new2 / a_new2.sum()
                score2 = compute_score(a_new2)
                if score2 < best_score:
                    best_score = score2
                    best_local = a_new2.copy()
            a = a_new2 if a_new2.sum() > 1e-10 else a
    
    return best_local, best_score

def generate_initializations(n, rng, parent=None):
    inits = []
    t = np.linspace(0, 1, n)
    
    if parent is not None and parent.size > 1:
        t_old = np.linspace(0, 1, parent.size)
        resampled = np.maximum(np.interp(t, t_old, parent), 0)
        if resampled.sum() > 0.01:
            inits.append(resampled / resampled.sum())
    
    inits.append(np.ones(n) / n)
    
    for freq in [1, 2, 3, 4, 5]:
        c = 1.0 + 0.3 * np.cos(2 * np.pi * freq * t)
        c = np.maximum(c, 0.01)
        inits.append(c / c.sum())
    
    # Random
    for _ in range(2):
        r = rng.uniform(0.1, 1.0, n)
        inits.append(r / r.sum())
    
    # Triangular
    c = 1.0 - np.abs(t - 0.5) * 0.5
    inits.append(np.maximum(c, 0.01) / np.maximum(c, 0.01).sum())
    
    # Sine bump (concentrated in middle)
    c = np.sin(np.pi * t) ** 2
    inits.append(c / c.sum())
    
    # Two bumps
    c = 0.5 + 0.5 * np.cos(4 * np.pi * t)
    c = np.maximum(c, 0.01)
    inits.append(c / c.sum())
    
    return inits

def coordinate_descent(a, deadline, n_trials=5000):
    """Simple coordinate descent: randomly pick a coordinate and optimize it."""
    n = len(a)
    best = a.copy()
    best_score = compute_score(a)
    rng = np.random.default_rng(123)
    
    for trial in range(n_trials):
        if time.monotonic() > deadline:
            break
        
        # Pick a random coordinate
        j = rng.integers(n)
        
        # Try a few perturbation magnitudes
        for delta in [0.1, -0.1, 0.05, -0.05, 0.2, -0.2]:
            a_new = best.copy()
            a_new[j] = max(0, a_new[j] + delta * a_new.mean())
            if a_new.sum() < 0.01:
                continue
            score = compute_score(a_new)
            if score < best_score:
                best_score = score
                best = a_new.copy()
                break
    
    return best, best_score
```
