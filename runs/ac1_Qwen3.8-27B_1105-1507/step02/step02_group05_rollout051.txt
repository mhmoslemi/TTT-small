df/da_j = sum_k w_k * (a_{k-j} + a_{j-k}) where w_k = exp(b_k/T) / sum(exp(b_l/T))

This is a convolution! df/da = w * a + w_reversed * a (approximately). More precisely:
sum_k w_k * a_{k-j} = (w * a)_j (cross-correlation)
sum_k w_k * a_{j-k} = (w_reversed * a)_j

So the gradient can be computed in O(n log n) using FFT!

This is a key insight. Let me formalize:
- w_k = softmax(b_k / T) for k = 0, ..., 2n-2
- grad_j = sum_k w_k * a_{|k-j|} ... no, not quite.

Let me redefine. Let's extend a to be zero outside [0, n-1]. Then:
grad_j = sum_{k=0}^{2n-2} w_k * (a_{k-j} + a_{j-k})

The first term sum_k w_k * a_{k-j} is the cross-correlation of w and a evaluated at position j.
The second term sum_k w_k * a_{j-k} is the cross-correlation of w_reversed and a evaluated at position j.

Where w_reversed_k = w_{2n-2-k}.

So grad = cross_corr(w, a) + cross_corr(w_reversed, a)

Both can be computed via FFT in O(n log n).

This means we can do gradient descent in O(n log n) per step!

**Algorithm:**
1. Initialize a (from height_sequence_1 or other)
2. Normalize: a = a / sum(a)
3. For each iteration:
   a. Compute b = conv(a, a) via FFT
   b. Compute w = softmax(b / T)
   c. Compute grad via FFT
   d. Update: a = a - lr * grad
   e. Project: a = max(a, 0), a = a / sum(a)
   f. Optionally decrease T

This is much simpler and potentially faster than the LP approach! Let me also think about learning rate scheduling.

Actually, I realize there's a subtlety. The soft-max is a smooth approximation to max, and as T → 0, it becomes the actual max. So we want to start with a larger T (smoother) and decrease it.

Also, I should be careful about the constraint sum(a) = 1. The gradient should be computed on the simplex. One approach: compute the gradient, then project onto the simplex (a >= 0, sum(a) = 1).

Let me also think about **momentum** (like in Adam or SGD with momentum) to help escape local minima.

**Combined approach:**
1. Start from height_sequence_1 (length 128)
2. Also try resampling to different lengths (256, 512, 1024, 2048)
3. For each length, run gradient descent with:
   - Soft-max temperature annealing (T from 0.1 to 0.01)
   - Learning rate scheduling
   - Momentum
   - Multiple restarts with noise
4. Compare results across lengths
5. Final polish with L-BFGS-B on the soft-max objective

Let me also think about another approach: **alternating minimization**.

The objective is J(a) = 2n * max_k b_k / sum(a)^2.
If we fix the "shape" of a (i.e., a / sum(a)), then J is deterministic.
If we fix the "peak positions" of b, we can solve for the optimal a that minimizes the peak.

Actually, here's another idea: **the "flat autocorrelation" approach**.

We want b_k to be as flat as possible. The ideal is b_k = C for all k. This means:
sum_j a_j * a_{k-j} = C for all k.

This is a system of quadratic equations in a. It's related to "perfect autocorrelation" sequences. For non-negative sequences, perfect autocorrelation is impossible (as noted), but we can get close.

One approach: start from a sequence, compute b, then try to "flatten" b by adjusting a. The adjustment that flattens b the most while maintaining non-negativity can be found by solving a small optimization problem.

"""
Minimizes J(a) = 2*n*max(convolve(a,a))/(sum(a))^2 using:
1. Soft-max gradient descent with FFT-based gradient computation
2. LP mirror descent with adaptive step sizes
3. Differential evolution for global exploration
4. L-BFGS-B with soft-max objective for final polish
Key new idea: O(n log n) gradient via FFT of softmax(conv(a,a))

import numpy as np
from scipy.optimize import linprog, minimize, differential_evolution
from scipy.sparse import lil_matrix
import time


def fast_conv(a):
    """Full self-convolution via FFT, O(n log n)."""
    n = len(a)
    s = 1
    while s < 2 * n - 1:
        s <<= 1
    fa = np.fft.rfft(a, s)
    return np.fft.irfft(fa * fa, s)[:2 * n - 1]


def compute_J(a):
    """Compute J(a) = 2*n*max(conv(a,a))/(sum(a))^2."""
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    b = fast_conv(a)
    return float(2 * len(a) * b.max() / (s * s))


def softmax(x, T):
    """Temperature-scaled softmax."""
    x = x - x.max()  # numerical stability
    ex = np.exp(x / T)
    return ex / ex.sum()


def soft_max_value(x, T):
    """Compute T * log(sum(exp(x/T))) in a numerically stable way."""
    x_max = x.max()
    return x_max + T * np.log(np.sum(np.exp((x - x_max) / T)))


def gradient_soft_max(a, T):
    """
    Compute gradient of soft_max(conv(a,a), T) w.r.t. a.
    Uses FFT for O(n log n) computation.
    
    grad_j = sum_k w_k * (a_{k-j} + a_{j-k})
    where w_k = softmax(b_k / T), b = conv(a,a)
    
    This equals cross_corr(w, a)_j + cross_corr(w_rev, a)_j
    """
    n = len(a)
    b = fast_conv(a)
    w = softmax(b, T)
    
    # cross_corr(w, a)_j = sum_k w_k * a_{k-j}
    # This is the correlation of w and a at lag j
    # = (w conv a)_j... wait, let me think.
    
    # Actually: sum_k w_k * a_{k-j} for k ranging over all valid indices
    # w has length 2n-1, a has length n
    # For a given j (0 <= j < n), k-j ranges over valid a indices when 0 <= k-j < n
    # So k ranges from j to j+n-1, and also k must be in [0, 2n-2]
    
    # Let's use FFT: cross_corr(w, a) = ifft(fft(w) * conj(fft(a)))
    # But we need to be careful with lengths.
    
    # Alternative: compute directly using the convolution structure
    # sum_k w_k * a_{k-j} = (w * a)_j where * is cross-correlation
    # In numpy: np.correlate(w, a, mode='full')[j + (2n-2) - (n-1)]... this is getting complicated.
    
    # Let me use a different approach: FFT
    # Extend a to length 2n-1 (zero-padded)
    # Then sum_k w_k * a_{k-j} is the cross-correlation at lag j
    
    s = 1
    while s < 4 * n:
        s <<= 1
    
    W = np.fft.rfft(w, s)
    A = np.fft.rfft(a, s)
    
    # cross_corr(w, a)_j = sum_k w_k * a_{k-j}
    # In frequency domain: ifft(W * conj(A)) gives sum_k w_{k-j} * a_k... 
    # Hmm, let me think more carefully.
    
    # cross_correlation(w, a)[d] = sum_k w[k] * a[k+d] (or a[k-d] depending on convention)
    # numpy.correlate(w, a, 'full')[d] = sum_k w[k] * a[k+d-(n_a-1)]
    
    # Let me just compute it directly for clarity (O(n^2) but n is small):
    # Actually for n up to a few thousand, O(n^2) might be too slow.
    # Let me use the FFT approach properly.
    
    # We want: g1_j = sum_{k=0}^{2n-2} w_k * a_{k-j} (with a_x = 0 if x notin [0,n-1])
    # This is the cross-correlation of w (length 2n-1) and a (length n) at lag j.
    # = ifft(FFT(w) * conj(FFT(a))) at the appropriate index
    
    # Let's use the full signal approach:
    # Pad both to length s
    # Cross-correlation at lag d: ifft(FFT(w_padded) * conj(FFT(a_padded)))[d]
    # where d goes from 0 to s-1, and the actual correlation values are at specific indices.
    
    # Actually, let me just use a simpler formulation:
    # g1_j = sum_k w_k * a_{k-j} = (a conv w_reversed)_j
    # where w_reversed_k = w_{2n-2-k}
    
    # Or even simpler: g1 = correlate(w, a) in the "valid" sense for j = 0..n-1
    
    # Let me just compute both terms using full convolution:
    # term1_j = sum_k w_k * a_{k-j}
    # If we define w_ext as w zero-padded to length s, and a_ext as a zero-padded to length s:
    # term1 = ifft(FFT(w_ext) * conj(FFT(a_ext)))
    # This gives the cross-correlation, and term1[j] is what we want (for j=0..n-1)
    
    w_ext = np.zeros(s)
    w_ext[:2*n-1] = w
    a_ext = np.zeros(s)
    a_ext[:n] = a
    
    W_ext = np.fft.rfft(w_ext)
    A_ext = np.fft.rfft(a_ext)
    
    # Cross-correlation: ifft(W * conj(A))
    # This gives sum_k w[k+d] * a[k] for each d... 
    # Actually, ifft(FFT(w) * conj(FFT(a)))_d = sum_k w[k+d] * conj(a[k])
    # For real signals: = sum_k w[k+d] * a[k]
    # We want sum_k w[k] * a[k-j] = sum_k w[k] * a[k-j]
    # Let m = k-j: sum_m w[m+j] * a[m] = cross_correlation at lag +j
    
    corr1 = np.fft.irfft(W_ext * np.conj(A_ext), s)
    # corr1[d] = sum_k w[k+d] * a[k] (with circular correlation due to FFT)
    # For our purposes (with sufficient zero-padding), corr1[j] = sum_k w[k+j] * a[k] for j in range
    
    # But wait, we want sum_k w[k] * a[k-j], which is corr at lag -j = corr at lag (s-j)
    # Or equivalently: sum_k w[k] * a[k-j] = sum_m w[m+j] * a[m] (substituting m = k-j)
    # So it IS corr1[j]!
    
    # Let me verify: corr1[j] = sum_k w[k+j] * a[k]
    # We want: sum_k w[k] * a[k-j]. Let m = k-j, so k = m+j:
    # = sum_m w[m+j] * a[m] = corr1[j] ✓
    
    # Now for the second term: g2_j = sum_k w_k * a_{j-k}
    # = sum_k w_k * a_{-(k-j)} = sum_k w_k * a_{|k-j|} (since a is only defined for non-negative)
    # Wait, a_{j-k} is non-zero only when 0 <= j-k < n, i.e., j-n+1 <= k <= j
    # This is: sum_k w_k * a_{j-k}
    # Let m = j-k: sum_m w_{j-m} * a_m = (w_reversed conv a)_j
    # where w_reversed[k] = w[2n-2-k]
    
    w_rev = w[::-1]  # w_reversed
    w_rev_ext = np.zeros(s)
    w_rev_ext[:2*n-1] = w_rev
    
    W_rev_ext = np.fft.rfft(w_rev_ext)
    # g2_j = sum_k w_rev[:, ...] ... 
    # g2_j = sum_m w_{j-m} * a_m
    # This is the convolution (w_rev * a)_j... let me check.
    # (w_rev * a)_j = sum_m w_rev[m] * a[j-m] = sum_m w[2n-2-m] * a[j-m]
    # That's not quite what we want.
    
    # Let me think differently. g2_j = sum_k w_k * a_{j-k}
    # = sum over valid k of w_k * a_{j-k}
    # This is the cross-correlation of w and a at lag j, but in the "other direction"
    # = (a conv w)_j... 
    # Convolution: (a * w)_j = sum_k a[k] * w[j-k] = sum_k w[j-k] * a[k]
    # So g2_j = (a * w)_j = convolution of a and w at position j
    
    # In FFT: convolution = ifft(FFT(a) * FFT(w))
    # But we need to handle the different lengths carefully.
    
    # (a * w)_j = sum_k a[k] * w[j-k]
    # Using FFT with zero-padding:
    conv_aw = np.fft.irfft(A_ext * W_ext, s)
    # conv_aw[j] = sum_k a[k] * w[j-k] (circular, but with padding it's linear)
    # This is exactly g2_j!
    
    grad = corr1[:n] + conv_aw[:n]
    return grad, b


def gradient_descent_softmax(a0, T_start, T_end, lr_start, lr_end, n_iters, deadline, tracker=None):
    """Run gradient descent with soft-max objective and temperature annealing."""
    a = a0.copy().astype(np.float64)
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-10:
        return a
    a /= s
    
    momentum = np.zeros_like(a)
    beta1 = 0.9
    beta2 = 0.999
    m_t = np.zeros_like(a)
    v_t = np.zeros_like(a)
    t = 0
    
    for it in range(n_iters):
        if time.monotonic() > deadline:
            break
        
        # Anneal temperature and learning rate
        progress = it / max(1, n_iters - 1)
        T = T_start * (T_end / T_start) ** progress
        lr = lr_start * (lr_end / lr_start) ** progress
        
        # Compute gradient
        grad, b = gradient_soft_max(a, T)
        
        # Adam update
        t += 1
        m_t = beta1 * m_t + (1 - beta1) * grad
        v_t = beta2 * v_t + (1 - beta2) * grad ** 2
        m_hat = m_t / (1 - beta1 ** t)
        v_hat = v_t / (1 - beta2 ** t)
        
        a_new = a - lr * m_hat / (np.sqrt(v_hat) + 1e-8)
        a_new = np.maximum(a_new, 0)
        s_new = a_new.sum()
        if s_new < 1e-10:
            break
        a_new /= s_new
        
        # Check improvement
        J_old = compute_J(a)
        J_new = compute_J(a_new)
        
        if J_new < J_old + 1e-12:
            a = a_new
        else:
            # Try smaller step
            a_trial = a - lr * 0.1 * m_hat / (np.sqrt(v_hat) + 1e-8)
            a_trial = np.maximum(a_trial, 0)
            s_trial = a_trial.sum()
            if s_trial > 1e-10:
                a_trial /= s_trial
                J_trial = compute_J(a_trial)
                if J_trial < J_old + 1e-12:
                    a = a_trial
                else:
                    # Keep old, reduce effective lr
                    lr *= 0.5
                    if lr < 1e-10:
                        break
        
        if tracker is not None and it % 50 == 0:
            tracker.update(a)
    
    if tracker is not None:
        tracker.update(a)
    return a


def build_A_sparse(a):
    """Build sparse constraint matrix for LP."""
    n = len(a)
    rows, cols, vals = [], [], []
    for k in range(2 * n - 1):
        jl = max(0, k - n + 1)
        jh = min(n - 1, k)
        if jl <= jh:
            cnt = jh - jl + 1
            rows.extend([k] * cnt)
            cols.extend(range(jl, jh + 1))
            vals.extend(a[k - jh:k - jl + 1][::-1].tolist())
    A = lil_matrix((2 * n - 1, n))
    for idx in range(len(rows)):
        A[rows[idx], cols[idx]] = vals[idx]
    return A.tocsr()


def lp_best_response(a, M):
    """LP: max sum(g) s.t. (a*g)_k <= M for all k, g >= 0."""
    n = len(a)
    c = -np.ones(n)
    A = build_A_sparse(a)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    r = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
    if r.success and r.x is not None:
        g = np.maximum(r.x, 0.0)
        if g.sum() > 1e-10:
            return g
    return None


def run_lp_iterations(a, max_iters, deadline, tracker):
    """LP mirror descent with adaptive step size."""
    a = np.maximum(a.astype(np.float64), 0.001)
    a /= a.sum()
    current_J = compute_J(a)
    tracker.update(a)

    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        b = fast_conv(a)
        M = float(b.max())
        g = lp_best_response(a, M)
        if g is None:
            break
        g = np.maximum(g, 0.0)
        g_sum = g.sum()
        if g_sum < 1e-10:
            break
        g /= g_sum

        base_t = max(0.05, 0.5 * (1.0 - it / float(2 * max_iters)))
        candidates_t = [base_t, min(1.0, base_t * 1.5), max(0.02, base_t * 0.5)]
        best_a = None
        best_J = current_J

        for t_val in candidates_t:
            a_trial = (1.0 - t_val) * a + t_val * g
            a_trial = np.maximum(a_trial, 0.0)
            s = a_trial.sum()
            if s < 1e-10:
                continue
            a_trial /= s
            J_trial = compute_J(a_trial)
            if J_trial < best_J - 1e-14:
                best_J = J_trial
                best_a = a_trial

        if best_a is None:
            break
        a = best_a
        current_J = best_J
        if it % 20 == 0:
            tracker.update(a)

    tracker.update(a)
    return a


def resample_seq(src, dest_n):
    """Resample 1D sequence to new length."""
    src = np.asarray(src, dtype=np.float64)
    if src.size == dest_n:
        return src.copy()
    t_old = np.linspace(0, 1, src.size)
    t_new = np.linspace(0, 1, dest_n)
    return np.maximum(np.interp(t_new, t_old, src), 0.0)


class ScoreTracker:
    def __init__(self):
        self.best = None
        self.best_score = float('inf')
        self.t_start = time.monotonic()

    def update(self, a):
        a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
        if a.size == 0 or a.sum() < 0.01:
            return
        score = float(evaluate_sequence(a.tolist()))
        if np.isfinite(score) and score < self.best_score:
            self.best = a.copy()
            self.best_score = score
            elapsed = time.monotonic() - self.t_start
            print(f"  * J={score:.8f} n={a.size} t={elapsed:.0f}s", flush=True)

    def report(self, label=""):
        if self.best is not None:
            print(f"  {label} best: J={self.best_score:.8f} n={self.best.size}", flush=True)


def generate_inits(n, rng, parent=None):
    """Generate diverse initial sequences."""
    inits = []
    if parent is not None:
        inits.append(resample_seq(parent, n))
    
    t = np.linspace(0, 1, n, endpoint=False)
    
    # Constant
    inits.append(np.ones(n))
    # Cosine windows
    for alpha in [0.5, 1.0, 1.5, 2.0, 3.0]:
        inits.append(np.abs(np.cos(np.pi * t)) ** alpha + 0.01)
    # Gaussian
    for sigma in [0.1, 0.2, 0.3, 0.5]:
        inits.append(np.exp(-((t - 0.5) ** 2) / (2 * sigma ** 2)) + 0.01)
    # Bump (flat top)
    for w in [0.2, 0.3, 0.5]:
        inits.append(np.where(np.abs(t - 0.5) < w, 1.0, 0.1))
    # Random
    inits.append(rng.uniform(0.1, 1.0, n))
    # Two peaks
    inits.append(np.exp(-((t - 0.25) ** 2) / 0.01) + np.exp(-((t - 0.75) ** 2) / 0.01) + 0.01)
    # Sinc-like
    x = (t - 0.5) * 5
    inits.append((np.sinc(x / np.pi) ** 2 + 0.01))
    # Raised cosine
    inits.append(0.5 * (1 + np.cos(2 * np.pi * t)) + 0.01)
    
    return inits


def run_gradient_descent_experiment(a0, n_iters, deadline, tracker, rng):
    """Run soft-max gradient descent with multiple temperature schedules."""
    a = a0.copy().astype(np.float64)
    a = np.maximum(a, 0.001)
    a /= a.sum()
    
    # Try different temperature ranges
    schedules = [
        (10.0, 0.5, 0.05, 0.005),  # T_start, T_end, lr_start, lr_end
        (5.0, 0.1, 0.03, 0.002),
        (20.0, 1.0, 0.1, 0.01),
        (1.0, 0.01, 0.01, 0.001),
    ]
    
    best_a = a.copy()
    best_J = compute_J(a)
    
    for T_s, T_e, lr_s, lr_e in schedules:
        if time.monotonic() > deadline:
            break
        a_trial = gradient_descent_softmax(a, T_s, T_e, lr_s, lr_e, n_iters, deadline, tracker)
        J_trial = compute_J(a_trial)
        if J_trial < best_J:
            best_J = J_trial
            best_a = a_trial
        # Also try from best_a directly
        a = best_a
    
    tracker.update(best_a)
    return best_a
