```python
def build_conv_matrix(f):
    """Build dense matrix A where (A@g)[k] = convolve(f,g)[k] for k=0..2n-2."""
    n = len(f)
    # A is (2n-1) x n
    # A[k, j] = f[k-j] if 0 <= k-j < n, else 0

        j_max = min(k, n-1)
        for j in range(j_min, j_max+1):
            A[k, j] = f[k-j]
    return A

def build_conv_matrix_sparse(f):
    """Build sparse matrix."""
    n = len(f)
    rows = []
    cols = []
    vals = []
    for k in range(2*n-1):
        j_min = max(0, k-(n-1))
        j_max = min(k, n-1)
        for j in range(j_min, j_max+1):
            rows.append(k)
            cols.append(j)
            vals.append(f[k-j])
    return csr_matrix((vals, (rows, cols)), shape=(2*n-1, n))

def compute_score(f):
    n = len(f)
    conv = np.convolve(f, f)
    M = np.max(conv)
    S = np.sum(f)
    if S < 0.01:
        return float('inf')
    return float(2 * n * M / (S * S))
```

If f is uniform (all ones), then conv(f, g)[k] = sum_j g[k-j] (sum over valid j). For k = n-1, this is sum_j g[j] = sum(g). So the constraint is sum(g) <= M = n. The LP becomes max sum(g) s.t. sum(g) <= n and various other constraints. The solution is sum(g) = n, which is bounded.

In general, since conv(f, g)[n-1] = sum_j f[j]*g[n-1-j] >= min(f) * sum(g) (if f has no zeros), the constraint gives sum(g) <= M / min(f). So the LP is bounded as long as f has no zeros.

If f has zeros, we need to be more careful, but the solution should still be bounded in practice.

```python
def lp_step_with_line_search(f, M, A_sparse, max_backtracks=20):
    n = len(f)
    S = np.sum(f)
    
    # Solve LP
    c = -np.ones(n)
    bounds = [(0, None)] * n
    result = linprog(c, A_ub=A_sparse, b_ub=np.full(2*n-1, M), bounds=bounds, method='highs')
    if not result.success:
        return f, compute_score(f)
    
    g = result.x
    sum_g = np.sum(g)
    if sum_g < 1e-15:
        return f, compute_score(f)
    
    # Rescale g to match sum of f
    g = g * (S / sum_g)
    
    # Line search
    best_alpha = 0
    best_score = compute_score(f)
    alpha = 0.5
    current_score = best_score
    
    for _ in range(max_backtracks):
        candidate = (1 - alpha) * f + alpha * g
        candidate = np.clip(candidate, 0, None)
        cand_sum = np.sum(candidate)
        if cand_sum < 1e-15:
            alpha *= 0.5
            continue
        candidate = candidate * (S / cand_sum)
        cand_score = compute_score(candidate)
        if cand_score < current_score:
            current_score = cand_score
            best_alpha = alpha
            best_score = cand_score
        else:
            alpha *= 0.5
        if alpha < 0.001:
            break
    
    if best_alpha > 0:
        new_f = (1 - best_alpha) * f + best_alpha * g
        new_f = np.clip(new_f, 0, None)
        new_f = new_f * (S / np.sum(new_f))
        return new_f, best_score
    return f, best_score
```

Wait, but this is only enforcing the top-k constraints of conv(f,f). The LP direction g might violate other (non-top-k) constraints. We need to check after solving.

Actually, the theoretical analysis of the LP direction method requires all constraints. Using only top-k is a heuristic that works well in practice because the non-top-k constraints are usually not binding for the solution g.

Let me verify: if g is the solution to the restricted LP (only top-k constraints), then conv(f, g)[k] <= M for the top-k k's. For other k's, conv(f, g)[k] might exceed M, but since these k's had conv(f,f)[k] << M, the violation is likely small and doesn't affect the objective much.

Now, let me also think about a **different approach entirely**: what if we parameterize the sequence in a special form?

**Idea: "Water-filling" parameterization**

The optimal solution should have the property that the top few convolution values are approximately equal (by the KKT conditions of the convex relaxation). So we can try to find a sequence where the top-K convolution values are all equal to some target T.

This gives us K equations (conv[k_i] = T for i=1,...,K) plus the normalization (sum = S) and non-negativity. We could try to solve this system.

But this is complicated for general K. Let me stick with the iterative approach.

**Another idea: Use the structure of the problem**

The convolution `conv(a,a)[k] = sum_j a[j]*a[k-j]` is a quadratic form. Specifically, `conv(a,a)[k] = a^T C_k a` where C_k is a symmetric matrix with (C_k)[j, l] = 1 if j+l = k (with appropriate bounds).

So the problem is: minimize max_k a^T C_k a subject to a >= 0, sum(a) = 1.

This is a "min-max quadratic program" which is non-convex in general. However, each individual constraint a^T C_k a <= t is a rotated second-order cone constraint (since C_k has rank... let me check).

Actually, C_k is a "permutation-like" matrix (it maps a to the "reversed" version shifted by k). Specifically, (C_k a)[j] = a[k-j] (with bounds). So C_k is a symmetric permutation matrix (or sub-matrix thereof).

For a symmetric permutation matrix, a^T C_k a = sum_j a[j]*a[k-j]. This is NOT a standard quadratic form with a positive semidefinite matrix (C_k is not PSD in general). So the constraint is non-convex.

However, note that for k = n-1, C_{n-1} is the "reversal" matrix, and a^T C_{n-1} a = sum_j a[j]*a[n-1-j]. By the substitution b[j] = a[n-1-j], this equals sum_j b[j]*a[j] = a^T b. This is just a dot product, which is non-convex.

OK so the problem is genuinely non-convex. The LP direction method (SCA) is the standard approach.

```python
"""
Optimized search for minimizing 2*n*max(conv(a,a))/sum(a)^2 using:
- LP-based direction finding with adaptive constraint set
- Backtracking line search
- Nesterov-accelerated subgradient descent
- Multi-start with diverse initializations across multiple lengths
- Periodic restarts to escape local minima
"""
import numpy as np
import time
from scipy.optimize import linprog
from scipy.sparse import csr_matrix

def compute_score(f):
    """Compute objective value."""
    n = len(f)
    conv = np.convolve(f, f)
    M = np.max(conv)
    S = np.sum(f)
    if S < 0.01:
        return float('inf')
    return float(2 * n * M / (S * S))

def build_sparse_conv_matrix(f, top_indices=None):
    """Build sparse matrix for convolution with f, optionally only for top indices."""
    n = len(f)
    if top_indices is None:
        top_indices = np.arange(2 * n - 1)
    
    rows = []
    cols = []
    vals = []
    for i, k in enumerate(top_indices):
        j_min = max(0, k - (n - 1))
        j_max = min(k, n - 1)
        for j in range(j_min, j_max + 1):
            rows.append(i)
            cols.append(j)
            vals.append(f[k - j])
    
    return csr_matrix((vals, (rows, cols)), shape=(len(top_indices), n))

def solve_lp_direction(f, M, top_k=None):
    """Solve LP: max sum(g) s.t. conv(f,g)[k] <= M for k in top_k (or all k), g >= 0."""
    n = len(f)
    if top_k is None or top_k >= 2 * n - 1:
        top_indices = np.arange(2 * n - 1)
    else:
        conv_ff = np.convolve(f, f)
        top_indices = np.argsort(conv_ff)[-top_k:]
    
    A = build_sparse_conv_matrix(f, top_indices)
    c = -np.ones(n)
    b_ub = np.full(len(top_indices), M)
    bounds = [(0, None)] * n
    
    try:
        result = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                         options={'presolve': True, 'dual_feasibility_tolerance': 1e-10})
        if result.success:
            return result.x
    except Exception:
        pass
    return None

def lp_optimize(f, deadline, top_k=100, verbose_prefix=""):
    """LP-based optimization with backtracking line search."""
    f = f.copy().astype(np.float64)
    best_f = f.copy()
    best_score = compute_score(f)
    n = len(f)
    S = np.sum(f)
    no_improve = 0
    it = 0
    
    while time.monotonic() < deadline:
        conv = np.convolve(f, f)
        M = np.max(conv)
        
        g = solve_lp_direction(f, M, top_k=top_k)
        if g is None or np.sum(g) < 1e-15:
            no_improve += 1
            if no_improve > 50:
                break
            continue
        
        # Rescale g to match sum of f
        g = g * (S / np.sum(g))
        
        # Backtracking line search
        best_alpha = 0
        current_best = best_score
        alpha = 0.5
        for _ in range(15):
            candidate = (1 - alpha) * f + alpha * g
            candidate = np.clip(candidate, 0, None)
            cand_sum = np.sum(candidate)
            if cand_sum < 1e-15:
                alpha *= 0.5
                continue
            candidate = candidate * (S / cand_sum)
            cand_score = compute_score(candidate)
            if cand_score < current_best:
                current_best = cand_score
                best_alpha = alpha
            else:
                alpha *= 0.5
            if alpha < 0.005:
                break
        
        it += 1
        if best_alpha > 0:
            f = (1 - best_alpha) * f + best_alpha * g
            f = np.clip(f, 0, None)
            f = f * (S / np.sum(f))
            best_f = f.copy()
            best_score = current_best
            no_improve = 0
            if it % 50 == 0:
                print(f"  {verbose_prefix}LP iter {it}: score={best_score:.6f} alpha={best_alpha:.4f}")
        else:
            no_improve += 1
            if no_improve > 100:
                break
    
    return best_f, best_score

def subgradient_optimize(f, deadline, top_k=10, lr_init=0.01, momentum=0.9, verbose_prefix=""):
    """Nesterov-accelerated subgradient descent."""
    f = f.copy().astype(np.float64)
    best_f = f.copy()
    best_score = compute_score(f)
    n = len(f)
    S = np.sum(f)
    y = f.copy()  # Nesterov's y
    v = np.zeros(n)  # momentum
    lr = lr_init
    no_improve = 0
    it = 0
    best_k = 0  # best iteration for Nesterov
    
    while time.monotonic() < deadline:
        # Nesterov step: evaluate gradient at y, not f
        conv_y = np.convolve(y, y)
        M_y = np.max(conv_y)
        S_y = np.sum(y)
        
        if M_y <= 0 or S_y < 1e-15:
            break
        
        # Compute subgradient at y
        grad = np.zeros(n)
        top_indices = np.argsort(conv_y)[-top_k:]
        for k in top_indices:
            j_min = max(0, k - (n - 1))
            j_max = min(k, n - 1)
            for j in range(j_min, j_max + 1):
                grad[j] += 2.0 * y[k - j]
        
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-15:
            break
        
        grad = grad / grad_norm
        
        # Update momentum
        v = momentum * v - lr * grad
        new_f = f + v
        new_f = np.clip(new_f, 0.0, None)
        new_sum = np.sum(new_f)
        if new_sum < 1e-15:
            lr *= 0.5
            no_improve += 1
            if no_improve > 200:
                break
            it += 1
            continue
        new_f = new_f * (S / new_sum)
        
        # Nesterov update
        beta = (1.0 + np.sqrt(1.0 + 4.0 * best_k * best_k)) / 2.0
        y = new_f + (best_k / beta) * (new_f - f)
        best_k = best_k + 1
        
        new_score = compute_score(new_f)
        it += 1
        
        if np.isfinite(new_score) and new_score < best_score:
            best_score = new_score
            best_f = new_f.copy()
            f = new_f
            no_improve = 0
            if it % 500 == 0:
                print(f"  {verbose_prefix}Sub iter {it}: score={best_score:.6f} lr={lr:.6f}")
        else:
            no_improve += 1
            f = new_f  # Still move (momentum)
            lr *= 0.99
            if no_improve > 500 or lr < 1e-8:
                break
    
    return best_f, best_score

def make_initializations(n, rng):
    """Create diverse initializations."""
    inits = []
    idx = np.arange(n, dtype=np.float64)
    
    inits.append(('uniform', np.ones(n)))
    
    cos_t = (1.0 + np.cos(np.pi * idx / (n - 1))) / 2.0
    cos_t = np.maximum(cos_t, 0.01)
    inits.append(('cosine', cos_t))
    
    # Various ramp shapes
    for p in [0.5, 1.0, 2.0, 4.0]:
        ramp = (idx / (n - 1)) ** p
        ramp = np.maximum(ramp, 0.01)
        inits.append((f'ramp_{p}', ramp))
        inits.append((f'ramp_rev_{p}', (1.0 - idx / (n - 1)) ** p + 0.01))
    
    # Exponential
    for rate in [1.0, 2.0, 4.0, 8.0]:
        exp_d = np.exp(-rate * idx / n)
        inits.append((f'exp_{rate}', exp_d))
        inits.append((f'exp_rev_{rate}', np.exp(-rate * (n - 1 - idx) / n)))
    
    # Gaussian
    center = (n - 1) / 2.0
    for sigma_mult in [0.3, 0.5, 0.7, 1.0]:
        bell = np.exp(-0.5 * ((idx - center) / (n * sigma_mult / 2.0)) ** 2)
        inits.append((f'gauss_{sigma_mult}', bell))
    
    # Sigmoid
    for beta in [2, 4, 8, 16]:
        s = 1.0 / (1.0 + np.exp(-beta * (idx / (n - 1) - 0.5)))
        inits.append((f'sigmoid_{beta}', s))
    
    # Random
    inits.append(('random', rng.uniform(0.1, 1.0, size=n)))
    
    # Power law
    for p in [0.5, 1.5, 3.0]:
        pl = ((idx + 1) / n) ** p
        inits.append((f'power_{p}', pl))
    
    return inits
```

**New idea: Use the "dual" problem**

The dual of "minimize max_k a^T C_k a subject to sum(a) = 1, a >= 0" involves finding a probability distribution over the k's that maximizes the minimum eigenvalue of a certain matrix. This is related to the "Slepian-Wang" problem.

Actually, let me think about this differently. The problem is equivalent to:
minimize t
subject to: a^T C_k a <= t for all k
           sum(a) = 1
           a >= 0

The Lagrangian is: L(a, t, λ, μ) = t + sum_k λ_k (a^T C_k a - t) + μ(sum(a) - 1) + sum_j ν_j (-a_j)

At optimality: 1 - sum_k λ_k = 0 (from ∂L/∂t = 0)
So sum_k λ_k = 1, meaning λ is a probability distribution.

And ∂L/∂a = 0 gives: 2 * sum_k λ_k * C_k * a + μ * 1 - ν = 0

This means that at the optimal point, the "average" Hessian (weighted by λ) applied to a is constant (equal to -μ) on the support of a.

This is a fixed-point / self-consistency condition. We can try to solve it iteratively:
1. Start with a probability distribution λ over lags
2. Find a that minimizes a^T (sum_k λ_k C_k) a subject to sum(a) = 1, a >= 0
   (This is a quadratic program!)
3. Update λ to concentrate on lags where a^T C_k a is largest
4. Repeat

This is essentially a **multiplicative weight update** or **F seguín** type algorithm for min-max problems!

Let me try a different approach. Instead of the QP, I'll use the subgradient method with the softmax (multiplicative weights) idea for the gradient:

**Algorithm (Softmax Subgradient):**

1. Start with a = some initialization
2. Compute conv(a,a)
3. Compute weights w[k] = exp(η * conv[k]) / sum_j exp(η * conv[j]) (softmax with temperature 1/η)
4. Compute the "weighted" gradient: grad[j] = 2 * sum_k w[k] * a[k-j] (where valid)
   (This is the gradient of sum_k w[k] * conv[k] with respect to a[j])
5. Update: a ← normalize(a - lr * grad), clip to non-negative
6. Repeat

This is a smoothed version of the subgradient method, where the "smoothing" is the softmax. As η → ∞, it converges to the standard subgradient (only the max lag contributes). As η → 0, all lags contribute equally.

The advantage of this approach is that it uses ALL lags (weighted), which might provide a smoother descent direction than just the top-k.

```python
def softmax_subgradient_optimize(f, deadline, eta=1.0, lr_init=0.01, momentum=0.9, verbose_prefix=""):
    f = f.copy().astype(np.float64)
    best_f = f.copy()
    best_score = compute_score(f)
    n = len(f)
    S = np.sum(f)
    v = np.zeros(n)
    lr = lr_init
    no_improve = 0
    it = 0
    
    while time.monotonic() < deadline:
        conv = np.convolve(f, f)
        M = np.max(conv)
        
        # Softmax weights
        # Scale to avoid overflow
        scaled = eta * conv / (M + 1e-15)  # max is eta
        weights = np.exp(scaled)
        weights = weights / np.sum(weights)
        
        # Weighted gradient: grad[j] = 2 * sum_k weights[k] * f[k-j]
        grad = np.zeros(n)
        # This is: grad = 2 * (convolution of weights with f, appropriately indexed)
        # conv_w_f[k] = sum_j weights[k-j] * f[j]
        # We want: grad[j] = 2 * sum_k weights[k] * f[k-j]
        # Let u = weights, v = f. Then (u*v)[j] = sum_k u[k] * v[j-k]... not quite.
        # Actually: sum_k weights[k] * f[k-j] = (weights * reverse(f))[j + n - 1 - ... ]
        # Let me just compute it directly:
        # conv_w = np.convolve(weights, f)  # length 2n-1 + 2n-1 - 1 = ... no
        # weights has length 2n-1, f has length n
        # np.convolve(weights, f) has length 2n-1+n-1 = 3n-2
        # (convolve(weights, f))[k] = sum_j weights[j] * f[k-j] (valid j)
        # We want grad[j] = 2 * sum_k weights[k] * f[k-j]
        # Let l = k-j, so k = l+j. grad[j] = 2 * sum_l weights[l+j] * f[l]
        # This is the cross-correlation of weights and f!
        # = 2 * np.correlate(weights, f, mode='...')
        
        # Actually, let's use: grad[j] = 2 * sum_k w[k] * f[k-j]
        # Define g[l] = w[l+j] for fixed j. This is a shifted version of w.
        # So grad[j] = 2 * sum_l g[l] * f[l] = 2 * <shifted_w_j, f>
        
        # This is equivalent to: grad = 2 * cross_correlate(w, f)
        # where cross_correlate(w, f)[j] = sum_k w[k] * f[k-j]
        
        # np.correlate(a, v) = sum_n a[n+k] * conj(v[n])
        # So np.correlate(w, f, 'same') gives sum_k w[k+j] * f[k] for j in range
        # That's not quite what we want.
        
        # Let's just compute it with a convolution:
        # rev_f = f[::-1], then conv(w, rev_f)[j + n - 1] = sum_k w[k] * rev_f[j+n-1-k]
        # = sum_k w[k] * f[n-1-(j+n-1-k)] = sum_k w[k] * f[k-j]
        # Yes! That's what we want.
        
        rev_f = f[::-1]
        conv_w_revf = np.convolve(weights, rev_f)
        # conv_w_revf has length (2n-1) + n - 1 = 3n-2
        # We want indices j + n - 1 for j = 0, ..., n-1
        grad = 2.0 * conv_w_revf[n-1:2*n-1]
        
        # Normalize
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-15:
            break
        grad = grad / grad_norm
        
        # Momentum update
        v = momentum * v - lr * grad
        new_f = f + v
        new_f = np.clip(new_f, 0.0, None)
        new_sum = np.sum(new_f)
        if new_sum < 1e-15:
            lr *= 0.5
            no_improve += 1
            if no_improve > 200:
                break
            it += 1
            continue
        new_f = new_f * (S / new_sum)
        
        new_score = compute_score(new_f)
        it += 1
        
        if np.isfinite(new_score) and new_score < best_score:
            best_score = new_score
            best_f = new_f.copy()
            f = new_f
            no_improve = 0
            if it % 200 == 0:
                print(f"  {verbose_prefix}SoftSG iter {it}: score={best_score:.6f}")
        else:
            no_improve += 1
            lr *= 0.99
            if no_improve > 500:
                break
    
    return best_f, best_score
```
