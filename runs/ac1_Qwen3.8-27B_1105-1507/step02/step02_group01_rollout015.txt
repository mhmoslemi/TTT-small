For n=100: 100 * 50 * 100 * 40 = 2 * 10^6. Very fast!

So the algorithm is fast for small n and might be slow for large n. Let me prioritize smaller n values.

Actually, wait. Let me reconsider the complexity. In the inner loop of solve_1d, I compute:
conv_vals = base_conv + quad * mid * mid + lin * mid

This is a vectorized operation on a vector of length 2n-1. So it's O(n) but with low constant (numpy vectorized). Then I find the max and the active set, which is O(n). So each bisection iteration is O(n) with small constant.

Total for one coordinate update: 40 * O(n) = O(40n) = O(12000) for n=300.
Total for one pass: n * O(40n) = O(40n^2) = O(3.6 * 10^6) for n=300.
Total for 50 passes: O(1.8 * 10^8). At ~1 ns per operation (optimistic for numpy), that's ~0.2 seconds. Actually, numpy operations on vectors of length 600 take maybe 1-2 microseconds. So 40 iterations * 300 coordinates * 50 passes * 2us = 1.2 seconds. That's fine!

def compute_obj(a):
    n = len(a)
    if n == 0:
        return np.inf
    conv = np.convolve(a, a)
    max_b = float(np.max(conv))
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)

def solve_1d_subproblem(a, p, n, max_iters=50):
    """Solve the 1D subproblem for coordinate p exactly using bisection on the subgradient."""
    sum_others = np.sum(a) - a[p]
    x_max = max(0.0, 1.0 - sum_others)
    
    if x_max <= 0:
        return 0.0
    
    # Compute base convolution (with a[p] = 0)
    a_base = a.copy()
    a_base[p] = 0.0
    base_conv = np.convolve(a_base.astype(np.float64), a_base.astype(np.float64))
    
    # Coefficients for the quadratic in x
    quad = np.zeros(2 * n - 1)
    lin = np.zeros(2 * n - 1)
    
    # Quadratic term: x^2 at k = 2p
    quad[2 * p] = 1.0
    
    # Linear terms: 2 * a[k-p] at k where 0 <= k-p < n and k-p != p
    j = np.arange(2 * n - 1) - p  # j[k] = k - p
    valid = (j >= 0) & (j < n) & (j != p)
    lin[valid] = 2.0 * a_base[j[valid]]  # a_base[p] = 0, so this is fine
    
    # Bisection on the subgradient
    lo = 0.0
    hi = x_max
    
    for _ in range(max_iters):
        mid = (lo + hi) / 2.0
        conv_vals = base_conv + quad * mid * mid + lin * mid
        f_val = np.max(conv_vals)
        # Subgradient: max of (2*quad[k]*mid + lin[k]) among active constraints
        active = conv_vals >= (f_val - 1e-14)
        f_prime = np.max(2.0 * quad[active] * mid + lin[active])
        
        if f_prime > 0:
            hi = mid
        else:
            lo = mid
    
    x_new = (lo + hi) / 2.0
    x_new = np.clip(x_new, 0.0, x_max)
    return x_new

def coordinate_descent(a, max_passes=200, tol=1e-12, time_limit=None, start_time=None):
    """Run coordinate descent to minimize max convolution."""
    n = len(a)
    a = a.astype(np.float64).copy()
    s = np.sum(a)
    if s < 1e-10:
        return a, np.inf
    a = a / s  # normalize to sum = 1
    
    if start_time is None:
        start_time = time.monotonic()
    
    best_a = a.copy()
    best_conv_max = float(np.max(np.convolve(a, a)))
    
    for pass_iter in range(max_passes):
        if time_limit and (time.monotonic() - start_time) > time_limit:
            break
        
        max_change = 0.0
        for p in range(n):
            x_new = solve_1d_subproblem(a, p, n)
            change = abs(x_new - a[p])
            a[p] = x_new
            max_change = max(max_change, change)
        
        # Check convergence
        conv_max = float(np.max(np.convolve(a, a)))
        if conv_max < best_conv_max:
            best_conv_max = conv_max
            best_a = a.copy()
        
        if max_change < tol:
            break
    
    return best_a, compute_obj(best_a)

def structured_init(n, rng, method=0):
    """Generate various structured initializations."""
    if method == 0:  # Uniform

    elif method == 5:  # Sparse random

        support = rng.choice(n, size=m, replace=False)
        a = np.zeros(n)
        a[support] = 1.0
    elif method == 6:  # Anti-ramp (high at edges)
        a = np.linspace(1.0, 0.1, n)
    elif method == 7:  # Binary random
        a = (rng.random(n) > 0.3).astype(float)
    elif method == 8:  # Periodic
        period = max(2, n // 5)
        a = np.tile(np.array([1.0, 0.3]), period)[:n] * 0.5 + 0.2
    else:  # Gaussian centered
        center = n / 2.0
        width = n * 0.3
        a = np.exp(-0.5 * ((np.arange(n) - center) / width) ** 2)

1. The `solve_1d_subproblem` function computes `base_conv` from scratch each time. This is O(n^2) due to the convolution. For n=300, that's 90000 operations per coordinate update. With 300 coordinates and 50 passes, that's 300 * 300 * 50 * (2*300) = 2.7 * 10^9 operations just for the convolutions. That might be too slow.

Let me optimize: instead of computing the full convolution each time, I can update it incrementally.

Actually, the convolution `np.convolve(a_base, a_base)` where a_base = a with a[p] = 0 is the same as the full convolution minus the terms involving a[p]. So:

base_conv = full_conv - (terms involving a[p])

The terms involving a[p] in the full convolution are:
- At position k=2p: a[p]^2
- At position k=p+j (j != p, 0<=j<n): 2*a[p]*a[j]

So I can compute base_conv = full_conv - those terms, which is O(n) instead of O(n^2).

Even better: I can precompute the full convolution once at the start of each pass, and then for each coordinate p, compute the "contribution of a[p]" to get base_conv.
