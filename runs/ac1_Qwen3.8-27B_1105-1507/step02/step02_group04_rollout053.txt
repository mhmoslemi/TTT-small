`b_{2i} = sum_j a_j * a_{2i-j}`. The term where `j=i` and `2i-j=i` (i.e., `j=i`) gives `a_i^2`. All other terms don't involve `a_i`. So:
`b_{2i}(x) = x^2 + (b_{2i}_old - a_old[i]^2)`

For `k ≠ 2i`: the terms involving `a_i` are `j=i` (gives `a_i * a_{k-i}`) and `j=k-i` (gives `a_{k-i} * a_i`). If `k-i = i` (i.e., `k=2i`), these are the same. Otherwise:
`b_k(x) = 2*x*a_{k-i} + (b_k_old - 2*a_old[i]*a_{k-i})` (if `0 <= k-i <= n-1` and `k-i ≠ i`)
or `b_k(x) = b_k_old` (if `k-i` is out of range or `k-i = i` which is the `k=2i` case)

OK so for the ternary search, I need to compute `max_k b_k(x)` quickly. I can precompute:
- `base_k = b_k_old - 2*a_old[i]*a_{k-i}` for `k ≠ 2i` (the part not involving `x`)
- `slope_k = 2*a_{k-i}` for `k ≠ 2i` (the coefficient of `x`)
- `quad_base = b_{2i}_old - a_old[i]^2` (the constant part of `b_{2i}`)

Then `b_k(x) = slope_k * x + base_k` for `k ≠ 2i`, and `b_{2i}(x) = x^2 + quad_base`.

To compute `max_k b_k(x)` for a given `x`:
- For the linear part: `max_k (slope_k * x + base_k)` - this is the upper envelope of lines, which I can compute in O(n) for a given `x`.
- For the quadratic: `x^2 + quad_base`
- Take the max of these.

So each evaluation is O(n), and with 30 ternary search iterations, it's O(30*n) per coordinate. For n=250 coordinates, total is O(30*250*250) ≈ 1.9M operations. Very fast!

And since the function is convex in x, I can also use binary search on the subgradient (derivative) to find the optimum more efficiently. The derivative of `max_k (slope_k * x + base_k)` at `x` is the `slope_k` of the active constraint(s). The derivative of `x^2 + quad_base` is `2x`. At the optimum, the subdifferential of the max should contain 0.

Actually, for a convex function that's the max of differentiable functions, the minimum is at a point where either:
- The derivative of the active function is 0 (interior minimum of one of the functions)
- The "kink" point where two functions cross (the left derivative < 0 < right derivative)

For the linear functions `slope_k * x + base_k`, the derivative is `slope_k` (constant). So the minimum of the max of these is at a kink point (intersection of two lines) or at the boundary `x = 0`.

For the quadratic `x^2 + quad_base`, the minimum is at `x = 0` (boundary) or where `2x = slope_k` for some active `k`.

This gives us an analytical solution! But it's complex to implement. Let me just use ternary search - it's simple and fast enough.

```python
import numpy as np
from scipy.optimize import linprog
import time

def compute_conv(a):
    n = len(a)
    size = 1
    while size < 2 * n:
        size <<= 1
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)
    return conv[:2 * n - 1]

def compute_obj(a):
    n = len(a)
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)

def coord_descent_step(a, i, iters=50):
    """Optimize coordinate i via ternary search."""
    n = len(a)
    a_old = a[i]
    b = compute_conv(a)  # current convolution
    
    # Precompute slopes and bases
    # For k = 2i: b_k(x) = x^2 + quad_base
    # For k ≠ 2i: b_k(x) = slope_k * x + base_k
    
    quad_base = b[2*i] - a_old * a_old if 2*i < len(b) else -np.inf
    quad_valid = (2*i < len(b))
    
    slopes = np.zeros(len(b))
    bases = b.copy()
    
    for k in range(len(b)):
        if k == 2*i:
            continue
        if 0 <= k - i < n:
            slopes[k] = 2.0 * a[k - i]
            bases[k] = b[k] - 2.0 * a_old * a[k - i]
        # else: slopes[k] = 0, bases[k] = b[k] (already set)
    
    def f(x):
        # max of all b_k(x)
        vals = slopes * x + bases
        if quad_valid:
            vals = np.maximum(vals, x * x + quad_base)
        return np.max(vals)
    
    # Ternary search on [0, upper]
    # Upper bound: current value + some margin
    upper = max(a_old * 3, 0.1, np.max(a) * 3)
    lower = 0.0
    
    for _ in range(iters):
        m1 = lower + (upper - lower) / 3
        m2 = upper - (upper - lower) / 3
        if f(m1) < f(m2):
            upper = m2
        else:
            lower = m1
    
    x_opt = (lower + upper) / 2
    a[i] = x_opt
    return a

def fista_smoothed(a, tau_start=10.0, tau_end=50.0, max_iter=5000, 
                    step_init=0.05, verbose=False):
    """FISTA with log-sum-exp smoothed objective."""
    n = len(a)
    a = a.copy().astype(np.float64)
    s = np.sum(a)
    a = a / s
    
    best_a = a.copy()
    best_obj = float(np.max(compute_conv(a)))
    
    y = a.copy()  # FISTA momentum variable
    t_k = 1.0
    
    for it in range(max_iter):
        frac = it / max(1, max_iter)
        tau = tau_start + (tau_end - tau_start) * frac
        
        conv_y = compute_conv(y)
        max_conv = np.max(conv_y)
        shifted = np.clip(tau * (conv_y - max_conv), -500, 500)
        weights = np.exp(shifted)
        w_sum = np.sum(weights)
        if w_sum > 1e-300:
            weights /= w_sum
        else:
            weights = np.zeros(len(conv_y))
            weights[int(np.argmax(conv_y))] = 1.0
        
        # Gradient: d/dy_i [sum_k w_k * b_k] = 2 * sum_k w_k * (dy/dy_i * b_k)
        # b_k = sum_j y_j * y_{k-j}
        # db_k/dy_i = y_{k-i} + y_{k-i} = 2*y_{k-i} (if k≠2i) or 2*y_i (if k=2i, which is y_i + y_i)
        # Actually db_k/dy_i = sum over terms: if j=i, contributes y_{k-i}; if k-j=i, contributes y_j
        # So db_k/dy_i = y_{k-i} + y_{k-i} = 2*y_{k-i} (when k-i is valid and k≠2i)
        # For k=2i: db_k/dy_i = 2*y_i
        # More generally: db_k/dy_i = y_{k-i} + y_{k-i} if 0<=k-i<n, with the understanding
        # that when k=2i, this is 2*y_i (same formula works!)
        
        # grad_i = sum_k w_k * 2 * y_{k-i} = 2 * (w * y)_i (correlation)
        # This is 2 * np.correlate(weights, y, 'full')[n-1 : 2n-1]... 
        # Actually, let me use the formula: grad_i = 2 * sum_k w_k * y_{k-i} (with valid indices)
        # = 2 * (w reversed correlate with y)
        
        # Using FFT: grad = 2 * ifft(fft(w) * fft(y)) ... no, that's convolution
        # We want: grad_i = 2 * sum_{k: 0<=k-i<n} w_k * y_{k-i}
        # Let j = k-i, so k = j+i: grad_i = 2 * sum_j w_{j+i} * y_j
        # This is the cross-correlation of w and y, evaluated at lag i.
        
        c = np.correlate(weights, y, mode='full')
        grad = 2.0 * c[:n]  # c[i] = sum_j weights[j+i] * y[j] for i=0,...,n-1
        # Wait, np.correlate(a, v, 'full')[k] = sum_j a[j+k] * v[j]
        # So c[i] = sum_j weights[j+i] * y[j] for valid j
        # That's exactly what we want!
        
        # Center gradient (for sum constraint)
        grad_c = grad - np.mean(grad)
        
        # Step
        x_new = y - step_init * grad_c
        x_new = np.maximum(x_new, 0)
        s_new = np.sum(x_new)
        if s_new < 1e-10:
            x_new = y
            s_new = 1.0
        x_new = x_new / s_new
        obj_new = float(np.max(compute_conv(x_new)))
        
        if obj_new < best_obj:
            best_obj = obj_new
            best_a = x_new.copy()
        
        # FISTA update
        t_new = (1 + np.sqrt(1 + 4 * t_k * t_k)) / 2
        y = x_new + ((t_k - 1) / t_new) * (x_new - y)
        y = np.maximum(y, 0)
        s_y = np.sum(y)
        if s_y < 1e-10:
            y = x_new
        else:
            y = y / s_y
        t_k = t_new
    
    return best_a
```

```python
"""
Optimization minimizing 2*n*max(conv(a,a))/(sum(a))^2 using:
1. FISTA with log-sum-exp smoothing for fast convergence
2. Active-set LP for global improvements  
3. Exact coordinate descent (exploiting 1D structure of each coordinate)
Focuses on n=200-300 range with intensive iterative refinement.
"""

import numpy as np
from scipy.optimize import linprog
import time


def compute_conv(a):
    """Compute autocorrelation conv(a,a) using FFT."""
    n = len(a)
    size = 1
    while size < 2 * n:
        size <<= 1
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)
    return conv[:2 * n - 1]


def obj_from_conv(n, conv, sum_a=1.0):
    """Compute objective from precomputed convolution."""
    return 2.0 * n * float(np.max(conv)) / (sum_a * sum_a)


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    conv = compute_conv(a)
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * float(np.max(conv)) / (sum_a * sum_a)


def normalize(a):
    """Normalize so sum(a) = 1 and a >= 0."""
    a = np.maximum(a, 0)
    s = np.sum(a)
    if s < 1e-10:
        return np.ones(len(a)) / len(a)
    return a / s


def fista_smoothed(a, total_iters=5000, tau_start=10.0, tau_end=80.0,
                   step_init=0.05, verbose=False):
    """
    FISTA (accelerated gradient) on the log-sum-exp smoothed objective.
    Minimizes max_k conv(a,a)_k subject to a >= 0, sum(a) = 1.
    """
    n = len(a)
    a = normalize(a.copy().astype(np.float64))
    best_a = a.copy()
    best_max = float(np.max(compute_conv(a)))
    
    y = a.copy()
    t_k = 1.0
    step = step_init
    
    for it in range(total_iters):
        frac = it / max(1, total_iters)
        tau = tau_start + (tau_end - tau_start) * frac
        
        conv_y = compute_conv(y)
        max_conv = float(np.max(conv_y))
        
        # Log-sum-exp weights
        shifted = np.clip(tau * (conv_y - max_conv), -700, 700)
        weights = np.exp(shifted)
        w_sum = float(np.sum(weights))
        if w_sum > 1e-300:
            weights = weights / w_sum
        else:
            weights = np.zeros(len(conv_y))
            weights[int(np.argmax(conv_y))] = 1.0
        
        # Gradient of smoothed objective
        c = np.correlate(weights, y, mode='full')
        grad = 2.0 * c[:n]
        grad_c = grad - np.mean(grad)
        
        # Step with backtracking
        x_new = y - step * grad_c
        x_new = np.maximum(x_new, 0)
        s_new = np.sum(x_new)
        if s_new < 1e-10:
            x_new = normalize(y)
        else:
            x_new = x_new / s_new
        
        obj_new = float(np.max(compute_conv(x_new)))
        
        if obj_new < best_max:
            best_max = obj_new
            best_a = x_new.copy()
        
        # FISTA momentum update
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t_k * t_k)) / 2.0
        y = x_new + ((t_k - 1.0) / t_new) * (x_new - y)
        y = normalize(y)
        t_k = t_new
        
        # Slowly decrease step
        if it > 500:
            step *= 0.999
            if step < 0.001:
                step = 0.001
        
        if verbose and it % 1000 == 0:
            print(f"    FISTA it={it}: max_conv={best_max:.8f}, tau={tau:.1f}")
    
    return best_a


def build_active_constraints(a, b, threshold=0.95):
    """Return indices k where b[k] > threshold * max(b)."""
    max_b = float(np.max(b))
    active = np.where(b > threshold * max_b)[0]
    return active


def solve_lp_active(a, M, active_idx):
    """
    Solve LP: max sum(g) s.t. (a*g)_k <= M for k in active_idx, g >= 0.
    Uses the structure that (a*g)_k = sum_j a_j * g_{k-j}.
    """
    n = len(a)
    num_constraints = len(active_idx)
    
    if num_constraints == 0:
        return None, None
    
    # Build constraint matrix A (num_constraints x n)
    # Row i: (a*g)_{active_idx[i]} = sum_j A[i,j] * g_j <= M
    # (a*g)_k = sum_{j: valid} a_j * g_{k-j}
    # So A[i,j] = a_{k-j} if k-j is valid (0 <= k-j < n), else 0
    # Wait: (a*g)_k = sum_j a_j * g_{k-j}
    # For this to be defined, we need 0 <= k-j < n, i.e., k-n < j < k
    # So A[i,j] = a_j if 0 <= active_idx[i] - j < n... 
    # No wait: (a*g)_k = sum_j a_j * g_{k-j}
    # For fixed k, the coefficient of g_m is a_{k-m} (where m = k-j, so j = k-m)
    # So A[i,m] = a_{k-m} if 0 <= k-m < n, i.e., k-n < m < k
    # i.e., A[i,m] = a[k-m] if max(0, k-n+1) <= m <= min(n-1, k)
    
    A = np.zeros((num_constraints, n), dtype=np.float64)
    for i, k in enumerate(active_idx):
        m_min = max(0, k - n + 1)
        m_max = min(n - 1, k)
        if m_min <= m_max:
            # A[i, m] = a[k - m] for m in [m_min, m_max]
            A[i, m_min:m_max + 1] = a[k - m_max:k - m_min + 1][::-1]
    
    c = -np.ones(n)
    b_ub = np.full(num_constraints, M)
    bounds = [(0.0, None)] * n
    
    try:
        res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': 20})
        if res.status == 0:
            return res.x, float(-res.fun)
    except Exception:
        pass
    return None, None


def lp_refine(a, max_iters=30, threshold=0.95, t=0.3, time_limit=60.0):
    """LP-based refinement using active set."""
    start = time.monotonic()
    a = normalize(a.copy().astype(np.float64))
    best_a = a.copy()
    best_obj = compute_obj(best_a)
    
    for it in range(max_iters):
        if time.monotonic() - start > time_limit:
            break
        
        b = compute_conv(a)
        M = float(np.max(b))
        active_idx = build_active_constraints(a, b, threshold)
        
        g, sum_g = solve_lp_active(a, M, active_idx)
        if g is None:
            break
        
        if sum_g <= 1.0 + 1e-6:
            # Try with a slightly larger M
            g, sum_g = solve_lp_active(a, M * 1.001, active_idx)
            if g is None or sum_g <= 1.0 + 1e-6:
                break
        
        g = normalize(g)
        a_new = (1.0 - t) * a + t * g
        a_new = normalize(a_new)
        
        obj_new = compute_obj(a_new)
        if obj_new < best_obj:
            best_obj = obj_new
            best_a = a_new.copy()
        
        a = a_new
    
    return best_a, best_obj


def coord_descent_round(a, iters_per_coord=40, random_order=False, rng=None, verbose=False):
    """One full round of coordinate descent."""
    n = len(a)
    a = a.copy()
    
    if random_order and rng is not None:
        order = rng.permutation(n)
    else:
        order = range(n)
    
    for i in order:
        a = _coord_step(a, i, iters_per_coord)
    
    return normalize(a)


def _coord_step(a, i, iters=40):
    """Exact optimization of coordinate i via ternary search."""
    n = len(a)
    a_old = a[i]
    b = compute_conv(a)
    b_len = len(b)
    
    # Precompute the linear structure
    quad_base = None
    if 2 * i < b_len:
        quad_base = b[2 * i] - a_old * a_old
    
    slopes = np.zeros(b_len)
    bases = b.copy()
    
    for k in range(b_len):
        if 2 * i < b_len and k == 2 * i:
            continue
        j = k - i
        if 0 <= j < n:
            slopes[k] = 2.0 * a[j]
            bases[k] = b[k] - 2.0 * a_old * a[j]
    
    def f(x):
        vals = slopes * x + bases
        if quad_base is not None:
            vals = np.maximum(vals, x * x + quad_base)
        return float(np.max(vals))
    
    # Ternary search on [0, hi]
    lo = 0.0
    hi = max(2.0 * a_old, 0.05, np.max(a) * 2.0)
    
    for _ in range(iters):
        m1 = lo + (hi - lo) / 3.0
        m2 = hi - (hi - lo) / 3.0
        if f(m1) < f(m2):
            hi = m2
        else:
            lo = m1
    
    x_opt = (lo + hi) / 2.0
    a[i] = x_opt
    return a


def full_coordinate_descent(a, num_rounds=100, random_order=False, seed=42, 
                             time_limit=120.0, verbose=False):
    """Run multiple rounds of coordinate descent."""
    start = time.monotonic()
    rng = np.random.default_rng(seed)
    a = normalize(a.copy().astype(np.float64))
    best_a = a.copy()
    best_obj = compute_obj(best_a)
    
    for r in range(num_rounds):
        if time.monotonic() - start > time_limit:
            break
        
        a_cur = coord_descent_round(a, iters_per_coord=40,
                                     random_order=random_order, rng=rng)
        obj_cur = compute_obj(a_cur)
        
        if obj_cur < best_obj:
            best_obj = obj_cur
            best_a = a_cur.copy()
            a = a_cur
        else:
            # Stuck, try with different random order
            a = coord_descent_round(a, iters_per_coord=40,
                                     random_order=True, rng=rng)
            obj_cur = compute_obj(a)
            if obj_cur < best_obj:
                best_obj = obj_cur
                best_a = a.copy()
        
        if verbose and r % 20 == 0:
            print(f"    CD round {r}: obj={best_obj:.8f}")
    
    return best_a, best_obj

def analytical_init(n, seed=0):
    """Generate analytical initializations."""
    rng = np.random.default_rng(seed)
    choices = [
        lambda: 0.5 * (1 + np.cos(2 * np.pi * np.arange(n) / n)),
        lambda: np.exp(-2.0 * (np.arange(n) / n - 0.5) ** 2),
        lambda: np.ones(n) * (1 - 0.5 * (np.arange(n) / n - 0.5) ** 2),
        lambda: 0.5 * (1 + np.cos(2 * np.pi * rng.uniform(1, 3) * np.arange(n) / n)),
        lambda: np.maximum(0, np.cos(np.pi * np.arange(n) / n)),
    ]
    a = choices[rng.integers(0, len(choices))]()
    return normalize(a)
```

```python
"""
Optimization minimizing 2n*max(conv(a,a))/(sum(a))^2 using exact coordinate descent
(exploiting the 1D structure of each coordinate in the max-convolution objective),
combined with FISTA initialization and periodic active-set LP steps.
The coordinate descent is the primary engine: each step exactly minimizes the
max-convolution over one coordinate (a 1D convex problem), making it much faster
to converge than subgradient methods.
"""

import numpy as np
from scipy.optimize import linprog
import time


def _next_power_of_2(m):
    """Return the next power of 2 >= m."""
    p = 1
    while p < m:
        p <<= 1
    return p


def compute_conv(a):
    """Compute autocorrelation conv(a,a) using FFT. Returns array of length 2n-1."""
    n = len(a)
    size = _next_power_of_2(2 * n)
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)
    return conv[:2 * n - 1]


def compute_obj(a):
    """Compute 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)


def normalize(a):
    """Clip to non-negative and normalize to sum 1."""
    a = np.maximum(a, 0.0)
    s = float(np.sum(a))
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s


def fista_smoothed(a, total_iters=2000, tau_start=10.0, tau_end=60.0,
                   step=0.03, verbose=False):
    """
    FISTA on log-sum-exp smoothed max-convolution.
    Minimizes max_k b_k with a>=0, sum(a)=1.
    """
    n = len(a)
    a = normalize(a.astype(np.float64).copy())
    best_a = a.copy()
    best_max = float(np.max(compute_conv(a)))

    y = a.copy()
    t_k = 1.0

    for it in range(total_iters):
        frac = it / max(1, total_iters)
        tau = tau_start + (tau_end - tau_start) * frac

        conv_y = compute_conv(y)
        max_conv = float(np.max(conv_y))
        shifted = np.clip(tau * (conv_y - max_conv), -700.0, 700.0)
        weights = np.exp(shifted)
        w_sum = float(np.sum(weights))
        if w_sum > 1e-300:
            weights /= w_sum
        else:
            weights = np.zeros(len(conv_y))
            weights[int(np.argmax(conv_y))] = 1.0

        # Gradient
        c = np.correlate(weights, y, mode='full')
        grad = 2.0 * c[:n]
        grad_c = grad - np.mean(grad)

        x_new = y - step * grad_c
        x_new = np.maximum(x_new, 0.0)
        s_new = float(np.sum(x_new))
        if s_new < 1e-10:
            x_new = normalize(y)
        else:
            x_new /= s_new

        obj_new = float(np.max(compute_conv(x_new)))
        if obj_new < best_max:
            best_max = obj_new
            best_a = x_new.copy()

        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t_k * t_k))
        y = x_new + ((t_k - 1.0) / t_new) * (x_new - y)
        y = normalize(y)
        t_k = t_new

    return best_a


def _build_lp_matrix(a, active_idx):
    """Build the constraint matrix for the LP."""
    n = len(a)
    A = np.zeros((len(active_idx), n), dtype=np.float64)
    for i, k in enumerate(active_idx):
        m_min = max(0, k - n + 1)
        m_max = min(n - 1, k)
        if m_min <= m_max:
            A[i, m_min:m_max + 1] = a[k - m_max:k - m_min + 1][::-1]
    return A


def solve_lp(a, M, active_idx, time_limit=15.0):
    """Solve LP: max sum(g) s.t. (a*g)_k <= M for k in active_idx, g >= 0."""
    n = len(a)
    if len(active_idx) == 0:
        return None
    A = _build_lp_matrix(a, active_idx)
    c = -np.ones(n)
    b_ub = np.full(len(active_idx), M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': time_limit})
        if res.status == 0:
            return res.x
    except Exception:
        pass
    return None


def lp_step(a, threshold=0.95, t_mix=0.3, time_limit=20.0, verbose=False):
    """One LP-based refinement step."""
    b = compute_conv(a)
    M = float(np.max(b))
    active = np.where(b > threshold * M)[0]
    g = solve_lp(a, M, active, time_limit=time_limit)
    if g is None:
        return a
    sum_g = float(np.sum(g))
    if sum_g <= 1.0 + 1e-6:
        return a
    g = normalize(g)
    a_new = (1.0 - t_mix) * a + t_mix * g
    return normalize(a_new)


def _coord_optimize(a, i, b, a_old, iters=35):
    """
    Optimize coordinate i given current b = conv(a,a).
    b_k(x) = s_k * x + c_k (linear) for k != 2i
    b_{2i}(x) = x^2 + c_{2i} (quadratic)
    Find x >= 0 minimizing max_k b_k(x) via ternary search.
    """
    n = len(a)
    b_len = len(b)

    # Identify quadratic term
    has_quad = (2 * i < b_len)
    quad_c = b[2 * i] - a_old * a_old if has_quad else 0.0

    # Build linear coefficients
    # For k != 2i: b_k(x) = 2*a[k-i]*x + (b[k] - 2*a_old*a[k-i]) if 0<=k-i<n
    #               b_k(x) = b[k] otherwise
    # We can work without explicitly building arrays: just evaluate f(x) directly

    # Precompute slopes and intercepts for speed
    slopes = np.zeros(b_len)
    intercepts = b.copy()

    for k in range(b_len):
        if has_quad and k == 2 * i:
            continue
        j = k - i
        if 0 <= j < n:
            slopes[k] = 2.0 * a[j]
            intercepts[k] = b[k] - 2.0 * a_old * a[j]

    def f(x):
        vals = intercepts + slopes * x
        if has_quad:
            vals = np.maximum(vals, x * x + quad_c)
        return float(np.max(vals))

    # Ternary search
    lo = 0.0
    hi = max(2.0 * a_old, 0.01, 1.5 * float(np.max(a)))

    for _ in range(iters):
        m1 = lo + (hi - lo) / 3.0
        m2 = hi - (hi - lo) / 3.0
        if f(m1) <= f(m2):
            hi = m2
        else:
            lo = m1

    return (lo + hi) / 2.0


def coord_descent_round(a, iters_per_coord=35, order=None):
    """One full round of exact coordinate descent."""
    n = len(a)
    a = a.copy()
    if order is None:
        order = range(n)

    for i in order:
        if a[i] < 1e-15:
            # Still optimize (might want to increase from 0)
            pass
        b = compute_conv(a)
        a_old = a[i]
        x_new = _coord_optimize(a, i, b, a_old, iters_per_coord)
        a[i] = x_new

    return a


def intensive_coord_descent(a, time_budget, seed=0, verbose=False):
    """
    Run many rounds of coordinate descent with periodic LP updates.
    This is the main optimization engine.
    """
    start = time.monotonic()
    rng = np.random.default_rng(seed)
    n = len(a)
    a = normalize(a.astype(np.float64).copy())
    best_a = a.copy()
    best_obj = compute_obj(a)

    round_count = 0
    lp_every = 40  # LP every 40 CD rounds

    while True:
        elapsed = time.monotonic() - start
        remaining = time_budget - elapsed
        if remaining < 2.0:
            break

        round_count += 1

        # Choose order
        if round_count % 5 == 0:
            order = rng.permutation(n)
        else:
            order = range(n)

        # Coordinate descent round
        a = coord_descent_round(a, iters_per_coord=35, order=order)
        obj = compute_obj(a)

        if obj < best_obj - 1e-14:
            best_obj = obj
            best_a = a.copy()
            if verbose and round_count % 100 == 0:
                print(f"    CD round {round_count}: obj={best_obj:.8f}")
        else:
            # No improvement, keep best
            a = best_a.copy()

        # Periodic LP
        if round_count % lp_every == 0 and remaining > 10.0 and n <= 500:
            a_lp = lp_step(a, threshold=0.92, t_mix=0.25,
                           time_limit=min(15.0, remaining * 0.1))
            obj_lp = compute_obj(a_lp)
            if obj_lp < best_obj:
                best_obj = obj_lp
                best_a = a_lp.copy()
                a = a_lp
                if verbose:
                    print(f"    LP at round {round_count}: obj={best_obj:.8f}")

    return best_a, best_obj


def try_parent_sequence():
    """Try to load parent sequence."""

        parent = np.asarray(height_sequence_1, dtype=np.float64)

def analytical_init(n, seed):
    """Generate a good analytical initialization."""
    rng = np.random.default_rng(seed)
    x = np.arange(n) / n
    choices = [
        lambda: 0.5 * (1.0 + np.cos(2.0 * np.pi * x)),
        lambda: np.exp(-3.0 * (x - 0.5) ** 2),
        lambda: 1.0 - 0.4 * np.sin(2.0 * np.pi * x),
        lambda: 0.5 * (1.0 + np.cos(2.0 * np.pi * rng.uniform(1.5, 2.5) * x)),
        lambda: np.maximum(0.1, 1.0 - np.abs(x - 0.5)),
        lambda: 0.5 * (1.0 + np.cos(np.pi * x)) ** 2,
    ]
    a = choices[rng.integers(0, len(choices))]()
    # Add small noise to break symmetry
    a += rng.normal(0, 0.01, n)
    return normalize(a)


def run_initialization(n, time_budget, seed, parent_a=None):
    """Run initialization pipeline for a given n."""
    start = time.monotonic()

    if parent_a is not None and len(parent_a) == n:
        a = normalize(parent_a.copy())
    else:
        # Best of several analytical inits
        best_a = None
        best_obj = np.inf
        for s in range(8):
            a_try = analytical_init(n, seed + s)
            o = compute_obj(a_try)
            if o < best_obj:
                best_obj = o
                best_a = a_try
        a = best_a

    # FISTA
    remaining = time_budget - (time.monotonic() - start)
    if remaining > 10:
        fista_t = min(25.0, remaining * 0.4)
        iters = int(fista_t * 300)  # ~300 iters/sec
        a = fista_smoothed(a, total_iters=max(500, iters),
                           tau_start=10.0, tau_end=50.0, step=0.03)

    # Quick LP
    remaining = time_budget - (time.monotonic() - start)
    if remaining > 10:
        for _ in range(3):
            a_new = lp_step(a, threshold=0.93, t_mix=0.3, time_limit=8.0)
            if compute_obj(a_new) < compute_obj(a):
                a = a_new

    # Quick CD
    remaining = time_budget - (time.monotonic() - start)
    if remaining > 5:
        a, _ = intensive_coord_descent(a, time_budget=remaining - 2,
                                         seed=seed, verbose=False)

    return a, compute_obj(a)


def propose_candidate(seed=42, budget_s=1500):
    """
    Main search function. Uses exact coordinate descent as the primary engine,
    combined with FISTA for initialization and periodic active-set LP for
    global improvements. Explores n in [200, 400].
    """
    start_time = time.monotonic()
    deadline = start_time + float(budget_s) - 30.0

    best_seq = None
    best_score = np.inf

    # Load parent
    parent, parent_obj = try_parent_sequence()
    if parent is not None:
        if parent_obj < best_score:
            best_score = parent_obj
            best_seq = parent.copy()

    # Determine n values
    n_values = [200, 250, 300, 350, 400]
    if parent is not None:
        np_ = len(parent)
        n_values = sorted(set(n_values + [np_, max(150, np_ - 50), min(500, np_ + 50)]))

    print(f"N values to explore: {n_values}")

    # Phase 1: Initialization and rough optimization
    phase1_time = (deadline - start_time) * 0.35
    time_per_n = max(15.0, phase1_time / len(n_values))

    for n in n_values:
        if time.monotonic() > deadline:
            break
        remaining = deadline - time.monotonic()
        if remaining < 10:
            break
        alloc = min(time_per_n, remaining)
        print(f"\nPhase 1: n={n}, budget={alloc:.0f}s")

        pa = parent if (parent is not None and len(parent) == n) else None
        a_opt, obj = run_initialization(n, alloc, seed + n * 7919, parent_a=pa)
        if obj < best_score:
            best_score = obj
            best_seq = a_opt.copy()
            print(f"  UPDATE: n={n}, obj={best_score:.6f}")

    # Phase 2: Intensive coordinate descent refinement
    if best_seq is not None:
        phase2_start = time.monotonic()
        phase2_budget = (deadline - phase2_start) * 0.55
        print(f"\nPhase 2: Intensive CD, n={len(best_seq)}, budget={phase2_budget:.0f}s")

        a_ref, obj_ref = intensive_coord_descent(
            best_seq, time_budget=phase2_budget, seed=seed + 999, verbose=True)
        if obj_ref < best_score:
            best_score = obj_ref
            best_seq = a_ref.copy()
            print(f"  UPDATE Phase 2: obj={best_score:.6f}")

    # Phase 3: Final polish
    if best_seq is not None:
        remaining = deadline - time.monotonic()
        if remaining > 10:
            print(f"\nPhase 3: Final polish, budget={remaining:.0f}s")
            n_best = len(best_seq)

            # LP with tight active set
            for thresh in [0.90, 0.85, 0.80]:
                if remaining - (time.monotonic() - time.monotonic()) < 5:
                    break
                a_lp = lp_step(best_seq, threshold=thresh, t_mix=0.2,
                               time_limit=min(15.0, remaining * 0.2))
                obj_lp = compute_obj(a_lp)
                if obj_lp < best_score:
                    best_score = obj_lp
                    best_seq = a_lp.copy()
                    print(f"  Phase 3 LP (thresh={thresh}): obj={best_obj:.6f}")

            # Final CD
            remaining = deadline - time.monotonic()
            if remaining > 5:
                a_cd, obj_cd = intensive_coord_descent(
                    best_seq, time_budget=remaining - 3, seed=seed + 777)
                if obj_cd < best_score:
                    best_score = obj_cd
                    best_seq = a_cd.copy()
                    print(f"  Phase 3 CD: obj={best_score:.6f}")

    # Fallback
    if best_seq is None:
        best_seq = np.ones(250)
        best_score = compute_obj(best_seq)

    elapsed = time.monotonic() - start_time
    print(f"\nFINAL: n={len(best_seq)}, score={best_score:.6f}, time={elapsed:.1f}s")

    result = [float(x) for x in best_seq]

    # Validate
    validation = evaluate_sequence(result)
    if validation < np.inf and abs(validation - best_score) > 1e-6:
        print(f"  Validation: computed={best_score:.6f}, actual={validation:.6f}")

    return result
```
