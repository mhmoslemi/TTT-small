The core difficulty is that the objective is the MAX of many quadratic forms. The subgradient is only defined at the active set, and the active set changes as we move. This leads to slow convergence of standard subgradient methods.

**Key insight for improvement**: At the optimum, several lags should be "active" (tied for the max). The optimal sequence should have the property that the top few convolution lagss are nearly equal. So we can use this as a diagnostic and a guide for optimization.

**New approach: "Leveling" algorithm**

1. Compute conv = a * a
2. Find the top-K lags (those closest to the max)
3. For the "lowest" of these top-K lags, try to increase it (by adjusting the sequence)
4. For the "highest" lags, try to decrease them
5. This is like a "water-filling" or "equalization" approach

Specifically:

- The positions that contribute least to m should be increased

**Alternative: Use the dual problem**

Uses a combination of multiplicative (mirror) descent, pairwise local search,
and adaptive perturbation for escape from local minima.

import numpy as np

import math

def _compute_score(f):
    """Fast score computation (objective value)."""
    n = len(f)
    conv = np.convolve(f, f)
    M = float(np.max(conv))
    S = float(np.sum(f))
    if S < 0.01:
        return float('inf')
    return float(2.0 * n * M / (S * S))

def _normalize(f, target_sum):
    """Normalize array to have the given sum."""
    s = float(np.sum(f))
    if s < 1e-15:
        return f.copy()
    return f * (target_sum / s)

def _mirror_descent_step(f, eta):
    """One step of multiplicative (mirror) descent.
    Reduces positions that contribute to high-conv lags.
    Returns new f with same sum.
    """
    n = len(f)
    conv = np.convolve(f, f)
    S = float(np.sum(f))
    avg = (S * S) / (2.0 * n - 1.0)
    
    # Weight: how much each lag exceeds the average
    excess = np.maximum(conv - avg, 0.0)
    total_excess = float(np.sum(excess))
    if total_excess < 1e-15:
        return f.copy()
    w = excess / total_excess
    
    # Compute pressure on each position
    # pressure[j] = sum_k w[k] * f[k-j] (for valid indices)
    pressure = np.zeros(n)
    for k in range(2 * n - 1):
        wk = w[k]
        if wk < 1e-12:
            continue
        j_min = max(0, k - n + 1)
        j_max = min(k, n - 1)
        # f[k-j] for j in [j_min, j_max]
        # = f[k-j_max : k-j_min+1] reversed
        pressure[j_min:j_max+1] += wk * f[k-j_max:k-j_min+1][::-1]
    
    max_p = float(np.max(pressure))
    if max_p < 1e-15:
        return f.copy()
    
    # Multiplicative update
    new_f = f * np.exp(-eta * pressure / max_p)
    new_f = np.clip(new_f, 1e-15, None)
    new_f = _normalize(new_f, S)
    return new_f
