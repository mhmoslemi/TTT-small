# Approach and rationale
We develop a multi-phase optimization strategy combining local search with global exploration to minimize the quotient of maximal convolution and normalized sum. The key insight is to use a combination of three distinct optimization phases: (1) Approximation through analytical initialization, (2) Initial optimization using linear programming, and (3) Fine-tuning with coordinate-wise descent. This approach leverages the scale-invariance of the objective function (since the objective depends only on the **relative** values of the sequence) while avoiding redundant computations through careful stochastic programming.

The central idea is to generate candidate sequences via multiple initialization methods, then systematically optimize each one using Linear Programming (LP) alternation to establish a strong local minimum, followed by iterative polishing with a variable-length coordinate refinement strategy. This method ensures both exploration and exploitation of promising solutions within the 1500-second budget.

    max_b = float(np.max(conv))
    sum_a = float(np.sum(a))

    if sum_a < 0.01:

def build_A(a):
    """Build constraint matrix for the convolution."""
    n = len(a)
    # Determine the active set for which the convolution is defined
    A_size = 2*n-1
    A = np.zeros((A_size, n), dtype=np.float64)
    
    for k in range(A_size):
        # Determine valid indices for the convolution
        j_start = max(0, k - n + 1)
        j_end = min(n-1, k)
        # Convolution indices j from j_start to j_end
        seq_len = j_end - j_start + 1
        # Place the necessary values
        vals = a[k - j_end: k - j_start+1][::-1]
        A[k, j_start:j_start+seq_len] = vals
        
    return A

def solve_lp_g(a, M_relax=2.0):
    """Solve linear program with constraint A*g <= M."""
    n = len(a)
    conv = np.convolve(a, a)
    M = float(np.max(conv)) * M_relax
    A = build_A(a)  # Matrix with outer bounds
    c = -np.ones(n)  # We're trying to maximize sum(g)
    b_ub = np.full_like(a, M) * len(a)  # Uniform constraint on each LP inequality
    bounds = [(0.0, None) for _ in range(n)]
    res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
    return res.x if res.status == 0 else None
