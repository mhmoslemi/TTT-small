Mathematical Specification
For a given sequence length _n_, we work with sequences _x_ = (x₀, x₁, ..., xₙ₋₁), each element satisfying 0 ≤ xᵢ ≤ 1000. The objective is to minimize _min_x_ ⊂ [𝐱]₂ * max_k | (x ⊗ x)[k] | / (sum x)², where ⊗ denotes full convolution.

The optimization alternates between:
1. **LP Segment**: Solving an SCS implementation of:
   Maximize: sum x
   Subject to: (x ⊗ x)[k] ≤ ±M for all valid _k_ (but note nonnegativity), where _M_ is the current max convolution value.

2. **Gradient Segment**: Computing the subgradient of the max constraint, (x ⊗ x)[k] ≤ (prev_max - reduction), and moving in that direction.

Key steps in LP segment:
- Build sparse LP matrix based on sequence convolution
- Ensure the solution respects the M bound and nonnegativity
- Return a step vector then scale by the current sum to maintain the norm
