def fft_conv(a):
    """Compute conv(a,a) using FFT."""
    n = len(a)
    size = 1
    while size < 2 * n:
        size <<= 1
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)

    conv = fft_conv(a)

Actually, I realize there's an even better approach. The problem is equivalent to:

This is a minimax problem. We can solve it as:
- Minimize M subject to conv_k <= M for all k, sum(a) = 1, a >= 0

This is a linear program! Because conv_k = sum_j a[j]*a[k-j] is quadratic in a, not linear. So it's actually a quadratic program (QP), not LP.
