Let me also think about the LP best-response method more carefully.

The LP best-response method:
- Given current a, compute M = max(b) where b = conv(a,a)
- Solve: max sum(g) s.t. conv(a, g) <= M, g >= 0
- This gives a "best response" g that, when convolved with a, doesn't exceed M
- Update: a_new = (1-t)*a + t*g (then normalize)

The intuition is: if a is far from optimal, there should exist a g such that conv(a,g) is more uniform (flat) than conv(a,a), and g should have a higher "spread." The LP finds such a g.

The key property: if a is optimal, then the LP should give back something proportional to a (a fixed point).

```python
import numpy as np
from scipy.optimize import linprog
import time

def fast_conv(a):
    n = len(a)
    s = 1
    while s < 2 * n - 1:
        s <<= 1
    fa = np.fft.rfft(a, s)
    return np.fft.irfft(fa * fa, s)[:2 * n - 1]

def compute_score(a):
    a = np.clip(a, 0.0, 1000.0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    n = len(a)
    b = fast_conv(a)
    return float(2.0 * n * b.max() / (s * s))

def build_conv_matrix(a):
    n = len(a)
    m = 2 * n - 1
    A = np.zeros((m, n))
    for k in range(m):
        jl = max(0, k - n + 1)
        jh = min(n - 1, k)
        if jl <= jh:
            A[k, jl:jh + 1] = a[k - jh:k - jl + 1][::-1]
    return A

def lp_best_response(a, M, max_iter=200):
    n = len(a)
    A = build_conv_matrix(a)
    c = -np.ones(n)
    res = linprog(c, A_ub=A, b_ub=np.full(2 * n - 1, M),
                  bounds=[(0, None)] * n, method='highs',
                  options={'maxiter': max_iter})
    if res.success and res.x.sum() > 1e-10:
        return res.x
    return None
```

To get J < 2, we need max(b) < s^2/n. Since b[n-1] is the center of the autocorrelation, and for "spread out" sequences it tends to be the maximum, we need to reduce b[n-1] below s^2/n.

b[n-1] = sum_j a[j]*a[n-1-j]

If we can make a[j] and a[n-1-j] "anti-correlated" (one large, one small), we can reduce this sum. But since a >= 0, the minimum of a[j]*a[n-1-j] is 0 (when one of them is 0). So the minimum of b[n-1] is 0 (achieved when a[j]*a[n-1-j] = 0 for all j, i.e., the support of a and its reverse don't overlap).

But if the support doesn't overlap with its reverse, then the sequence is concentrated at one end, and other lags of the autocorrelation will be large.

This is a trade-off. The optimal solution balances the peak at the center with the peaks at other lags.

    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2 * n - 1]
