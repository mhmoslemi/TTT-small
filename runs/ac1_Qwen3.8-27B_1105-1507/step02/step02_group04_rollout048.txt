Now I understand the problem better. The key is to create sequences where the convolution has a flat profile. The sequence should be "asymmetric" and have a specific structure.

Let me think about what the optimal structure looks like for large n.

If we want conv(a,a) to be as flat as possible (all elements ≈ (sum a)^2/(2n-1)), then in the frequency domain, |A(f)|^2 should be such that its inverse DFT is flat. A flat inverse DFT means the DFT of |A(f)|^2 is a delta at frequency 0. But DFT(|A|^2) = circular convolution of A with conj(A) (by the circular convolution theorem). For this to be a delta, we need A to be a "complex sequence with flat autocorrelation" (like a Zadoff-Chu sequence or m-sequence).

But the constraint is that a (the inverse DFT of A) must be non-negative. This is the key constraint.

For a real non-negative sequence a, A(f) = FFT(a) has the Hermitian symmetry A(-f) = conj(A(f)), and |A(f)|^2 is real and non-negative.

The inverse DFT of |A(f)|^2 is the circular autocorrelation of a (padded to length 2n-1 or the next power of 2).

So we want: the circular autocorrelation of a (padded) to be as flat as possible, subject to a >= 0.

This is a well-studied problem in signal processing! It's related to "minimum peak sidelobe level" (PSL) sequences, but with the non-negativity constraint.

For the non-negativity constraint, one approach is to use "amplitude-constrained" optimization.

def nesterov_smooth_descent(a, max_iter=5000, tau_start=3.0, tau_end=50.0,
                            verbose=False):
    """Nesterov-accelerated gradient descent on smoothed peak, with sum normalization."""
    n = len(a)
    a = a.copy().astype(np.float64)
    s = np.sum(a)
    a = a / s
    
    # Initialize velocity
    v = np.zeros(n)
    
    best_a = a.copy()
    best_max = float(np.max(compute_conv(a)))
    
    # Momentum parameter (beta for Nesterov)
    beta = 0.9
    
    # Initial step size
    eta = 0.05
    
    stall_count = 0
    patience = 300
    
    for it in range(max_iter):
        # Animate tau
        frac = it / max(1, max_iter)
        tau = tau_start + (tau_end - tau_start) * (frac ** 0.5)  # sqrt schedule
        
        # Nesterov lookahead
        if it == 0:
            a_look = a
        else:
            a_look = a + beta * v
        
        # Ensure non-negativity for gradient computation
        a_look = np.maximum(a_look, 0)
        s_look = np.sum(a_look)
        if s_look < 1e-10:
            break
        a_look = a_look / s_look
        
        # Compute smoothed gradient
        conv = compute_conv(a_look)
        smooth_val, grad = smooth_max_grad(conv, tau)
        
        # Project gradient onto sum constraint
        grad = grad - np.mean(grad)
        
        # Backtracking line search
        a_trial = a - eta * grad
        a_trial = np.maximum(a_trial, 0)
        s_trial = np.sum(a_trial)
        
        if s_trial < 1e-10:
            # Try smaller step
            eta *= 0.5
            continue
        
        a_trial = a_trial / s_trial
        trial_max = float(np.max(compute_conv(a_trial)))
        
        if trial_max < best_max - 1e-12:
            best_max = trial_max
            best_a = a_trial.copy()
            stall_count = 0
       
        
        # Update velocity and position
        if trial_max <= float(np.max(compute_conv(a))) + 0.5 * eta * np.sum(grad * grad) + 1e-10:
            v = beta * v - eta * grad
            a = a_trial
            # Slowly increase step
            eta = min(eta * 1.01, 0.1)
        else:
            eta *= 0.5
            if eta < 1e-10:
                break
        
        stall_count += 1
        if stall_count > patience:
            # Add perturbation
            rng = np.random.default_rng(it + 12345)
            noise = rng.normal(0, 0.02, n)
            a_pert = a + noise
            a_pert = np.maximum(a_pert, 0)
            s_p = np.sum(a_pert)
            if s_p > 1e-10:
                a_pert = a_pert / s_p
                pert_max = float(np.max(compute_conv(a_pert)))
                if pert_max < best_max:
                    a = a_pert
                    best_a = a_pert.copy()
                    best_max = pert_max
                    stall_count = 0
            else:
                break
        
        # Decay beta slightly
        if it > 1000:
            beta = max(0.5, beta * 0.999)
        
        if verbose and it % 1000 == 0:
            print(f"      Nesterov it={it}: smooth_val={smooth_val:.6f}, best_max={best_max:.6f}, eta={eta:.4f}")
    
    return best_a, best_max


def peak_shave(a, n_iter=500, verbose=False):
    """Iteratively shave the peak of the convolution by reducing contributing coordinates."""
    n = len(a)
    a = a.copy().astype(np.float64)
    s = np.sum(a)
    a = a / s
    s = 1.0  # normalized
    
    best_a = a.copy()
    best_max = float(np.max(compute_conv(a)))
    
    for it in range(n_iter):
        conv = compute_conv(a)
        peak_idx = int(np.argmax(conv))
        peak_val = conv[peak_idx]
        
        if peak_val < best_max * (1 - 1e-10):
            best_max = peak_val
            best_a = a.copy()
        
        # Compute contribution of each coordinate to the peak
        # conv[peak_idx] = sum_j a[j] * a[peak_idx - j] (valid j)
        contrib = np.zeros(n)
        for j in range(n):
            k = peak_idx - j
            if 0 <= k < n:
                contrib[j] = a[j] * a[k]
        
        # Reduce coordinates with high contribution to the peak
        # Use a "proportional reduction" scheme
        max_contrib = np.max(contrib)
        if max_contrib < 1e-15:
            break
        
        # Reduction amount
        eta = 0.05 + 0.05 * np.exp(-it / 100.0)
