Let me also think about the coordinate descent more carefully:

For coordinate i, fixing all other a[j]:
- `c[k] = C[k] + a[i] * a[k-i]` where C[k] = sum_{j≠i} a[j]*a[k-j]
- `sum_a = S_rest + a[i]` where S_rest = sum_{j≠i} a[j]
- Objective: `2n * max_k (C[k] + a[i]*a[k-i]) / (S_rest + a[i])^2`

Let t = a[i]. We want to minimize:
`f(t) = max_k (C[k] + t * a[k-i]) / (S_rest + t)^2` for t >= 0

Note that `a[k-i]` is 0 for most k (only when 0 <= k-i < n and a[k-i] > 0). Let's say the non-zero values of a[k-i] for k in [0, 2n-2] are at positions k = i, i+1, ..., i+n-1 (clipped to [0, 2n-2]).

So f(t) = max over at most 2n-1 terms of `(C[k] + t*a[k-i]) / (S_rest + t)^2`.

Each term `(C[k] + t*b) / (S_rest + t)^2` where b = a[k-i] >= 0:
- If b = 0: the term is C[k]/(S_rest+t)^2, which is decreasing in t (for t > -S_rest)
- If b > 0: the term has derivative `(b*(S_rest+t)^2 - 2*(C[k]+t*b)*(S_rest+t)) / (S_rest+t)^4`
  = `(S_rest+t)*(b*(S_rest+t) - 2*(C[k]+t*b)) / (S_rest+t)^4`
  = `(b*(S_rest+t) - 2*C[k] - 2*t*b) / (S_rest+t)^3`
  = `(b*S_rest + b*t - 2*C[k] - 2*b*t) / (S_rest+t)^3`
  = `(b*S_rest - 2*C[k] - b*t) / (S_rest+t)^3`
  
  This is zero when `b*S_rest - 2*C[k] - b*t = 0`, i.e., `t = S_rest - 2*C[k]/b`.

So each term is a unimodal function of t (increases then decreases, or just decreases). The max of such functions is also unimodal (or at least has a limited number of local maxima).

For a practical approach, I can use a golden section search or simply evaluate f(t) on a grid and then refine.

But actually, for the coordinate descent to be effective, I need to compute C[k] efficiently each time I change a coordinate. This requires O(n) work per coordinate (to compute the contribution of a[i] to each c[k]), so O(n^2) per full sweep. For n=250, that's about 62500 operations per sweep, which is very fast.

"""
Optimization for minimizing 2*n*max(conv(a,a))/(sum(a))^2 using multiplicative
subgradient updates, coordinate descent, and adaptive smoothing.
Explores multiple sequence lengths centered around the parent length.
"""

import numpy as np
import time


def compute_conv(a):
    """Compute conv(a,a) using FFT. Returns array of length 2n-1."""
    n = len(a)
    size = 1
    while size < 2 * n:
        size <<= 1
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)
    return conv[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)


def smoothed_weights(conv, tau):
    """Compute smoothed weights (normalized) for the max approximation."""
    max_conv = np.max(conv)
    shifted = tau * (conv - max_conv)
    shifted = np.clip(shifted, -500, 500)
    weights = np.exp(shifted)
    w_sum = weights.sum()
    if w_sum < 1e-300:
        weights = np.zeros(len(conv))
        weights[int(np.argmax(conv))] = 1.0
    else:
        weights /= w_sum
    return weights


def compute_gradient(weights, a):
    """Compute gradient of smoothed max: g[i] = 2 * sum_j w[i+j] * a[j]."""
    # Using np.correlate: correlate(weights, a, 'valid') gives sum_j w[i+j]*a[j]
    grad = 2.0 * np.correlate(weights, a, mode='valid')
    return grad


def multiplicative_optimize(a, time_budget=30.0, tau_start=3.0, tau_end=80.0,
                            eta_start=0.1, seed=0):
    """
    Multiplicative subgradient optimization.
    a[i] *= exp(-eta * (grad[i] - mean(grad)))
    with annealed tau and adaptive eta.
    """
    rng = np.random.default_rng(seed)
    a = a.astype(np.float64).copy()
    s = np.sum(a)
    a = a / s  # normalize to sum = 1
    
    start = time.monotonic()
    best_a = a.copy()
    best_conv_max = float(np.max(compute_conv(a)))
    
    n = len(a)
    max_iter = 50000
    it = 0
    stall_count = 0
    patience = 300
    
    for it in range(max_iter):
        elapsed = time.monotonic() - start
        if elapsed > time_budget:
            break
        
        frac = it / max(1, max_iter)
        tau = tau_start + (tau_end - tau_start) * frac
        eta = eta_start * (1.0 - 0.5 * frac)  # slowly decrease
        
        conv = compute_conv(a)
        current_max = float(np.max(conv))
        
        if current_max < best_conv_max - 1e-12:
            best_conv_max = current_max
            best_a = a.copy()
            stall_count = 0
        else:
            stall_count += 1
        
        if stall_count > patience:
            # Add multiplicative noise to escape
            noise = np.exp(rng.normal(0, 0.1, n))
            a = a * noise
            a = np.maximum(a, 1e-10)
            a = a / np.sum(a)
            stall_count = 0
            continue

        weights = smoothed_weights(conv, tau)
        grad = compute_gradient(weights, a)

        a = a * np.exp(-eta * grad_centered)
        a = np.maximum(a, 1e-15)

But actually, I can be smarter. Instead of recomputing the full convolution each time, I can compute the "delta" caused by changing one coordinate.

`c[k] = sum_j a[j]*a[k-j]`

If I change a[i] from t_old to t_new:
`c'[k] = c[k] + (t_new - t_old) * a[k-i]` (for the term j=i)
       + `a[k-i] * (t_new - t_old)` (for the term k-j=i, i.e., j=k-i)
       - correction if k-i==i (to avoid double counting the change in a[i]*a[i])

Wait, let me be more careful:
`c[k] = sum_j a[j]*a[k-j]`

The terms involving a[i] are:
- j = i: term = a[i]*a[k-i] (if 0 <= k-i < n)
- k-j = i, i.e., j = k-i: term = a[k-i]*a[i] (if 0 <= k-i < n and k-i != i)

If k-i != i: both terms exist, total = 2*a[i]*a[k-i]
If k-i == i (k = 2i): only one term, total = a[i]^2

So the change in c[k] when a[i] changes from t to t':
- If 0 <= k-i < n and k != 2i: delta = (t' - t) * 2 * a[k-i]
- If k == 2i: delta = t'^2 - t^2
- Otherwise: delta = 0

So I can compute the new max efficiently:
1. Start with the current conv array
2. For the changed coordinate, update the affected c[k] values (at most 2n-1 values, but only n of them change)
3. Find the new max

This makes each candidate evaluation O(n) instead of O(n log n).

"""
Optimization for minimizing 2*n*max(conv(a,a))/(sum(a))^2 using multiplicative
subgradient updates, vectorized coordinate descent, and adaptive smoothing.
Explores multiple sequence lengths with diverse smooth initializations.
Key improvements over parent: multiplicative (mirror descent) updates that
maintain positivity naturally, fast coordinate descent with O(n) updates,
and more diverse restarts with annealed parameters.
"""

import numpy as np
import time


def compute_conv(a):
    """Compute conv(a,a) using FFT. Returns array of length 2n-1."""
    n = len(a)
    size = 1
    while size < 2 * n:
        size <<= 1
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)
    return conv[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    conv = compute_conv(a)
    max_b = float(np.max(conv))
    sum_a = float(np.sum(a))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)


def smoothed_weights(conv, tau):
    """Compute normalized log-sum-exp weights approximating the max indicator."""
    max_conv = np.max(conv)
    shifted = tau * (conv - max_conv)
    shifted = np.clip(shifted, -500, 500)
    weights = np.exp(shifted)
    w_sum = weights.sum()
    if w_sum < 1e-300:
        weights = np.zeros(len(conv))
        weights[int(np.argmax(conv))] = 1.0
    else:
        weights /= w_sum
    return weights


def compute_gradient(weights, a):
    """Compute g[i] = 2 * sum_j w[i+j] * a[j] via cross-correlation."""
    return 2.0 * np.correlate(weights, a, mode='valid')


def multiplicative_optimize(a, time_budget=20.0, tau_start=3.0, tau_end=80.0,
                            eta_start=0.12, seed=0, noise_interval=200,
                            noise_scale=0.08):
    """
    Multiplicative subgradient (mirror descent with KL divergence).
    Update: a[i] *= exp(-eta * (grad[i] - mean(grad)))
    With annealed tau, adaptive eta, and periodic noise for exploration.
    """
    rng = np.random.default_rng(seed)
    a = a.astype(np.float64).copy()
    s = np.sum(a)
    if s < 1e-10:
        a = np.ones_like(a)
        s = 1.0
    a = a / s

    n = len(a)
    start = time.monotonic()
    best_a = a.copy()
    best_conv_max = float(np.max(compute_conv(a)))

    max_iter = 100000
    patience = 400
    stall_count = 0
    min_step = 1e-6

    for it in range(max_iter):
        elapsed = time.monotonic() - start
        if elapsed > time_budget:
            break

        frac = it / max(1, max_iter)
        tau = tau_start + (tau_end - tau_start) * frac
        eta = eta_start * (1.0 - 0.4 * frac)

        # Periodic noise to escape local minima
        if it > 0 and it % noise_interval == 0:
            scale = noise_scale * (1.0 + 0.5 * np.sin(it * 0.1))
            a = a * np.exp(rng.normal(0, max(0.02, scale), n))
            a = np.maximum(a, 1e-12)
            a = a / np.sum(a)
            stall_count = 0

        conv = compute_conv(a)
        current_max = float(np.max(conv))

        if current_max < best_conv_max - 1e-13:
            best_conv_max = current_max
            best_a = a.copy()
            stall_count = 0
        else:
            stall_count += 1

        if stall_count > patience:
            # Stronger perturbation
            scale = 0.15
            a = a * np.exp(rng.normal(0, scale, n))
            a = np.maximum(a, 1e-12)
            a = a / np.sum(a)
            stall_count = 0
            if eta < min_step:
                eta = min_step * 5
            continue

        weights = smoothed_weights(conv, tau)
        grad = compute_gradient(weights, a)

        # Center gradient to maintain sum
        grad_centered = grad - np.mean(grad)

        # Adaptive step: scale inverse to gradient magnitude
        grad_max = np.max(np.abs(grad_centered))
        if grad_max > 1e-12:
            eta_eff = eta * min(1.0, 1.0 / (grad_max * 0.5))
        else:
            eta_eff = eta

        # Multiplicative update (mirror descent)
        log_update = -eta_eff * grad_centered
        log_update = np.clip(log_update, -3.0, 3.0)
        a = a * np.exp(log_update)
        a = np.maximum(a, 1e-15)
        a = a / np.sum(a)

    return best_a


def coordinate_descent(a, max_sweeps=10, time_budget=8.0):
    """
    Vectorized coordinate descent.
    For each coordinate i, try candidate values and pick the best.
    Uses O(n) update per candidate (no FFT needed).
    """
    a = a.astype(np.float64).copy()
    n = len(a)
    s = float(np.sum(a))
    a = a / s
    conv = compute_conv(a)

    start = time.monotonic()
    n_conv = 2 * n - 1

    for sweep in range(max_sweeps):
        if time.monotonic() - start > time_budget:
            break

        improved = False
        # Randomize coordinate order
        order = np.random.default_rng(42 + sweep).permutation(n)

        for i in order:
            t_old = a[i]
            if t_old < 1e-12:
                continue
            s_rest = s - t_old

            # Affected k range: k such that 0 <= k-i < n => k in [i, i+n-1]
            k_min = i
            k_max = min(n_conv - 1, i + n - 1)
            if k_min > k_max:
                continue

            offsets = np.arange(k_min, k_max + 1) - i  # k - i values
            base_vals = conv[k_min:k_max + 1].copy()

            # Precompute a[offsets]
            a_off = a[offsets]

            # Max of unaffected region
            if k_min > 0:
                left_max = np.max(conv[:k_min])
            else:
                left_max = -np.inf
            if k_max < n_conv - 1:
                right_max = np.max(conv[k_max + 1:])
            else:
                right_max = -np.inf
            unaffected_max = max(left_max, right_max)

            # Current max
            cur_max = max(np.max(base_vals), unaffected_max)
            cur_obj = 2.0 * n * cur_max / (s * s)

            best_t = t_old
            best_obj = cur_obj
            best_new_conv = base_vals.copy()

            # Generate candidates
            # Include values that would "balance" the top bins
            top_k = int(np.argmax(base_vals))
            top_val = base_vals[top_k]

            candidates = [t_old * 0.3, t_old * 0.6, t_old * 1.4, t_old * 1.8, 0.0]
            # Add candidates based on balancing:
            # If top bin has a[off] > 0, reducing t reduces it
            if a_off[top_k] > 1e-9:
                # t that would reduce top bin to median level
                med_val = np.median(base_vals)
                t_balance = t_old + (med_val - top_val) / (2.0 * a_off[top_k])
                if t_balance > 0:
                    candidates.append(t_balance)
                    candidates.append(max(0.0, t_balance * 0.7))
                    candidates.append(t_balance * 1.3)

            for t_new in candidates:
                t_new = max(0.0, min(1000.0, t_new))
                if abs(t_new - t_old) < 1e-13:
                    continue

                # Compute new values at affected k
                deltas = 2.0 * (t_new - t_old) * a_off
                # Handle k = 2i case (center)
                center_idx = 2 * i - k_min
                if 0 <= center_idx < len(deltas):
                    # At k=2i: c[k] changes by t_new^2 - t_old^2 instead of 2*(t_new-t_old)*a[i]
                    # The formula 2*(t_new-t_old)*a[k-i] = 2*(t_new-t_old)*t_old is wrong
                    # Correct: c[2i] includes a[i]^2, so delta = t_new^2 - t_old^2
                    deltas[center_idx] = t_new * t_new - t_old * t_old

                new_vals = base_vals + deltas
                new_max = max(np.max(new_vals), unaffected_max)
                new_s = s_rest + t_new
                if new_s < 1e-10:
                    continue
                new_obj = 2.0 * n * new_max / (new_s * new_s)

                if new_obj < best_obj - 1e-14:
                    best_obj = new_obj
                    best_t = t_new
                    best_new_conv = new_vals.copy()

            if best_t != t_old:
                a[i] = best_t
                s = s_rest + best_t
                conv[k_min:k_max + 1] = best_new_conv
                improved = True

        if not improved:
            break

    return a


def initialize(n, idx, seed):
    """Generate diverse smooth initializations."""
    rng = np.random.default_rng(seed + idx * 7919)
    x = np.linspace(0, 1, n)

    choice = rng.integers(0, 8)
    if choice == 0:
        # Raised cosine
        phase = rng.uniform(-np.pi, np.pi)
        a = 0.5 * (1 + np.cos(2 * np.pi * x + phase))
    elif choice == 1:
        # Single Gaussian
        center = rng.uniform(0.2, 0.8)
        width = rng.uniform(0.08, 0.35)
        a = np.exp(-((x - center) / width) ** 2)
    elif choice == 2:
        # Double Gaussian
        c1, c2 = rng.uniform(0.1, 0.9, 2)
        w1, w2 = rng.uniform(0.08, 0.25, 2)
        a = np.exp(-((x - c1) / w1) ** 2) + np.exp(-((x - c2) / w2) ** 2)
    elif choice == 3:
        # Cosine with harmonics
        f1 = rng.uniform(0.5, 3.0)
        f2 = rng.uniform(2.0, 6.0)
        amp2 = rng.uniform(0.1, 0.5)
        a = 0.5 + 0.3 * np.cos(2 * np.pi * f1 * x) + amp2 * np.cos(2 * np.pi * f2 * x + rng.uniform(0, 2 * np.pi))
    elif choice == 4:
        # Flat with asymmetric taper
        taper_l = rng.uniform(0.1, 0.4)
        taper_r = rng.uniform(0.1, 0.4)
        a = np.ones(n)
        ml = max(1, int(n * taper_l * 0.5))
        mr = max(1, int(n * taper_r * 0.5))
        a[:ml] = np.linspace(0.1, 1.0, ml)
        a[-mr:] = np.linspace(1.0, 0.1, mr)
    elif choice == 5:
        # Power law(profile)
        center = rng.uniform(0.3, 0.7)
        power = rng.uniform(0.5, 3.0)
        a = np.exp(-power * np.abs(x - center) ** rng.uniform(1.0, 2.5))
    elif choice == 6:
        # Spline-interpolated random points
        n_ctrl = rng.integers(3, 8)
        ctrl_x = np.sort(rng.uniform(0, 1, n_ctrl))
        ctrl_y = rng.uniform(0.05, 1.0, n_ctrl)
        a = np.interp(x, ctrl_x, ctrl_y)
    else:
        # Bump function (compact support in middle)
        left = rng.uniform(0.1, 0.3)
        right = rng.uniform(0.7, 0.9)
        a = np.where((x >= left) & (x <= right),
                     np.sin(np.pi * (x - left) / (right - left)) ** 2, 0.0)

    a = np.maximum(a, 1e-6)
    s = np.sum(a)
    if s < 1e-6:
        a = np.ones(n) / n
    else:
        a = a / s
    return a

                best_score = obj
                best_seq = a_opt.copy()
                print(f"  NEW BEST: n={n}, r={r}, obj={best_score:.6f} (remaining {deadline - time.monotonic():.0f}s)")

    print(f"\nAfter exploration: best={best_score:.6f}, n={len(best_seq) if best_seq is not None else 0}")

    # Phase 2: Intensive polishing of the best solution
    if best_seq is not None and time.monotonic() < deadline - 8:
        a_cur = best_seq.copy()
        n_cur = len(a_cur)
        polish_round = 0

        while time.monotonic() < deadline - 5:
            polish_round += 1
            remaining = deadline - time.monotonic()
            if remaining < 5:
                break

            # Sub-phase A: Multiplicative with high tau (peak-focused)
            a_m = multiplicative_optimize(a_cur, time_budget=min(12.0, remaining * 0.35),
                                          tau_start=15.0 + polish_round * 5,
                                          tau_end=60.0 + polish_round * 15,
                                          eta_start=0.06, seed=seed + 1000 + polish_round,
                                          noise_interval=300, noise_scale=0.05)
            obj_m = compute_obj(a_m)
            if obj_m < best_score:
                best_score = obj_m
                best_seq = a_m.copy()
                a_cur = a_m.copy()
                print(f"  Polish {polish_round} mult: {best_score:.6f}")

            # Sub-phase B: Coordinate descent (multiple sweeps)
            remaining = deadline - time.monotonic()
            if remaining > 4:
                a_cd = coordinate_descent(a_cur, max_sweeps=15,
                                          time_budget=min(8.0, remaining * 0.3))
                obj_cd = compute_obj(a_cd)
                if obj_cd < best_score:
                    best_score = obj_cd
                    best_seq = a_cd.copy()
                    a_cur = a_cd.copy()
                    print(f"  Polish {polish_round} CD: {best_score:.6f}")

            # Sub-phase C: Perturbation + short re-optimization (every other round)
            remaining = deadline - time.monotonic()
            if remaining > 8 and polish_round % 2 == 1:
                rng = np.random.default_rng(seed + 5000 + polish_round * 7)
                scale = 0.04 + 0.03 * (polish_round % 4)
                a_pert = a_cur * np.exp(rng.normal(0, scale, n_cur))
                a_pert = np.maximum(a_pert, 1e-12)
                a_pert = a_pert / np.sum(a_pert)

                # Short optimization from perturbed point
                a_p_opt = multiplicative_optimize(a_pert, time_budget=min(5.0, remaining * 0.25),
                                                  tau_start=8.0, tau_end=40.0,
                                                  eta_start=0.1, seed=seed + 9000 + polish_round)
                # Quick CD
                a_p_opt = coordinate_descent(a_p_opt, max_sweeps=5,
                                             time_budget=min(3.0, remaining * 0.15))
                obj_p = compute_obj(a_p_opt)
                if obj_p < best_score:
                    best_score = obj_p
                    best_seq = a_p_opt.copy()
                    a_cur = a_p_opt.copy()
                    print(f"  Polish {polish_round} perturb: {best_score:.6f}")

    # Fallback
    if best_seq is None:
        best_seq = np.ones(50) / 50.0
        best_score = compute_obj(best_seq)

    elapsed = time.monotonic() - start_time
    print(f"\nDONE: n={len(best_seq)}, score={best_score:.6f}, time={elapsed:.1f}s")

    result = [float(x) for x in best_seq]
    validation = evaluate_sequence(result)
    if np.isfinite(validation):
        if abs(validation - best_score) > 1e-5:
            print(f"  Validation diff: computed={best_score:.6f}, actual={validation:.6f}")
        best_score = validation

    return result
