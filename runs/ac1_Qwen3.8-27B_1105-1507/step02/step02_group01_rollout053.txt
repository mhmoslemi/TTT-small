Hmm. The problem is that when we concentrate mass, the convolution at the "self-overlap" points is large.

Let me think about this more carefully. For a uniform sequence of length n, the convolution is a triangle with peak n at the middle. The sum is n, so obj = 2n*n/n^2 = 2.

For the convolution to have max less than sum^2/n, we need a "flatter" convolution than the triangle.

But for non-negative sequences, the convolution is always "peaked" somewhere. The question is where and how peaked.

Actually, I just realized something. Let me reconsider the problem.

The convolution (a*a)[k] = sum_j a[j]*a[k-j].

For k = n-1 (the middle): (a*a)[n-1] = sum_j a[j]*a[n-1-j].

Now, if a is a "step" function - say a[j] = 1 for 0 <= j < m and 0 otherwise, where m < n:
(a*a)[k] = min(k+1, m, 2m-1-k) for k = 0, ..., 2m-2, and 0 for k >= 2m-1.
max = m (at k = m-1).
sum = m.
obj = 2n*m/m^2 = 2n/m.

For this to be < 2: m > n. But m <= n, so this is impossible.

What about a two-step function: a[j] = 1 for 0 <= j < m and n-m <= j < n, and 0 otherwise?
sum = 2m.
The convolution will have contributions from:
- The "left" block convolving with itself: peak m at k = m-1
- The "right" block convolving with itself: peak m at k = 2(n-m)+m-1 = 2n-m-1... wait let me think.

Actually the right block is at positions n-m, n-m+1, ..., n-1. Its self-convolution has peak m at position 2(n-m)+m-1 = 2n-2m+m-1 = 2n-m-1.

The cross terms (left block * right block) contribute at positions from (n-m) to (n-m)+m-1 = n-1, with peak 2m at position (n-m)+... hmm this is getting complex.
