Actually, I realize there's an even better approach. Let me think about the problem as a **convex optimization in disguise** (sort of).

If we fix the "shape" of the convolution (i.e., which peaks are active), then the problem becomes:
```
min max_{k in S} conv(a,a)[k]
s.t. sum(a) = 1, a >= 0
```

where S is the set of active peaks. This is still non-convex (max of quadratics), but if we linearize around the current point, we get a convex problem that the LP approximately solves.

The key insight is: **at the optimum, the active set S should be stable** (the same peaks remain active). If the active set is changing rapidly, we're not at the optimum yet.

So a good strategy is:
1. Compute conv(a,a)
2. Identify the top m peaks (active set)
3. Solve: min t s.t. conv(a,a)[k] <= t for k in active set, sum(a')=1, a' >= 0, a' close to a
   (This is a QP, not LP, but we can approximate with LP)
4. Move towards the solution
5. Repeat

Actually, the LP approach does exactly this: it fixes `a` and finds the best `g` that would reduce the peaks. The difference is that in the LP, `a` is fixed and `g` is the variable, whereas in the true problem, `a` is the variable.

The "alternating" aspect is: update g (via LP), then blend a towards g. This is like a block coordinate descent.

**Key improvement**: Instead of a fixed blend factor t, use a **line search** to find the best t that actually reduces the objective.

Let me also think about **scaling**. The objective is scale-invariant, but the LP solution depends on the scale. If we normalize a to sum to 1, the LP solution g also sums to 1, so the blend (1-t)*a + t*g also sums to 1. Good.

**Another key idea: "Anti-peak" gradient**

Instead of just reducing the peak, what if we also consider reducing the *second* highest peak, *third* highest, etc.? The idea is that if we reduce the main peak, the second peak becomes the new main peak. So we should preemptively work on reducing multiple peaks.

This is the "multi-peak" subgradient I mentioned earlier. Let me formalize:

Given b = conv(a,a), let k_1, k_2, ..., k_m be the indices of the top m values of b. Define the weighted subgradient:

`g[j] = (1/m) * sum_{r=1}^{m} (a[k_r - j] + a[j - k_r])` (valid indices)

Then update: `a_new = normalize(max(a - eta * g, 0))`

This should be more effective than chasing a single peak because it works on multiple peaks simultaneously.

**Yet another idea: "Convolution matching"**

Instead of minimizing the peak, try to match the convolution to a target distribution. The target could be:
- Uniform: `t[k] = 1/(2n-1)` for all k
- Truncated: `t[k] = c` for k in some range, 0 elsewhere

We minimize `||conv(a,a) - t||^2` or `||conv(a,a) - t||_inf`.

The gradient of `||conv(a,a) - t||_

2` is `2 * conv(2*(b-t), a)` where b = conv(a,a). Wait, let me be more careful.

`f(a) = sum_k (b[k] - t[k])^2` where `b[k] = sum_i a[i]*a[k-i]`

`df/da[j] = 2 * sum_k (b[k] - t[k]) * db[k]/da[j] = 2 * sum_k (b[k] - t[k]) * (a[k-j] + a[j-k])`

This can be computed as `2 * conv(2*(b-t), a_flip)` (with appropriate indexing).

This is a smooth objective! And it encourages the convolution to match the target shape. If we set t to be uniform, we're trying to make the convolution as flat as possible.

"""
Advanced optimization for minimizing 2*n*max(conv(a,a))/(sum(a))^2.
Uses convolution-matching GD, multi-peak subgradient, LP polishing, 
sinusoidal perturbations, and multi-length exploration.
"""
import numpy as np
import time
from scipy.fft import rfft, irfft

def compute_conv(a):
    """Full linear convolution a*a via FFT."""
    n = len(a)
    N = 1
    while N < 2 * n - 1:
        N <<= 1
    fa = rfft(a, N)
    return irfft(fa * fa, N)[:2 * n - 1]

def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    b = compute_conv(a_norm)
    return 2.0 * n * float(np.max(b))

def build_conv_matrix(a):
    """Build matrix A (2n-1 x n) such that A @ g = conv(a, g)."""
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        r = min(n, 2 * n - 1 - j)
        A[j:j + r, j] = a[:r]
    return A

def solve_lp_minpeak(a):
    """Solve LP: min M s.t. conv(a,g)[k] <= M for all k, sum(g)=1, g>=0."""
    n = len(a)
    a = a / np.sum(a)
    A = build_conv_matrix(a)
    try:
        from scipy.optimize import linprog
        c = np.zeros(n + 1)
        c[-1] = 1.0
        A_ub = np.zeros((2 * n - 1, n + 1))
        A_ub[:, :n] = A
        A_ub[:, n] = -1.0
        b_ub = np.zeros(2 * n - 1)
        A_eq = np.zeros((1, n + 1))
        A_eq[0, :n] = 1.0
        b_eq = np.array([1.0])
        bounds = [(0, None)] * n + [(0, None)]
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs')
        if res.status == 0:
            g_val = np.maximum(res.x[:n], 0)
            s = float(np.sum(g_val))
            if s > 1e-10:
                return g_val / s
    except Exception:
        pass
    return None

def norm_step(a, eta, grad):
    """Take a gradient step, project to nonnegative, renormalize."""
    a_new = a - eta * grad
    a_new = np.maximum(a_new, 0)
    s = float(np.sum(a_new))
    if s < 1e-10:
        return None
    return a_new / s

def fft_gd(a, time_budget=60.0, mode='energy', n_peaks=1):
    """FFT-based gradient descent with multiple modes."""
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()

    eta = 0.5
    momentum = 0.7
    v = np.zeros(n)
    stall = 0
    max_stall = 100

    # Precompute FFT size
    N = 1
    while N < 3 * n - 1:
        N <<= 1

    for it in range(50000):
        if time.monotonic() - start > time_budget:
            break

        fa = rfft(a, N)
        b = irfft(fa * fa, N)[:2 * n - 1]

        if mode == 'energy':
            # Gradient of sum(b^2) = 2 * conv(2*b, a_flip) -> compute as conv(b, a) * 2
            # Actually: d/da[j] sum_k b[k]^2 = 2 * sum_k b[k] * db[k]/da[j]
            # db[k]/da[j] = a[k-j] + a[j-k] (valid)
            # So grad[j] = 2 * sum_k b[k] * (a[k-j] + a[j-k])
            # = 2 * (conv(b, a_flip))[j] + 2 * (conv(b_flip, a))[j]
            # But since b is symmetric (b[k] = b[2n-2-k]), conv(b, a_flip) = conv(b_flip, a)
            # So grad = 4 * conv(b, a_flip)[n-1 : 2n-1]
            b_pad = np.zeros(N)
            b_pad[:2*n-1] = b
            fb = rfft(b_pad, N)
            fa_flip = rfft(a[::-1], N)
            c_full = irfft(fb * fa_flip, N)
            grad = 4.0 * c_full[n-1:2*n-1]
            
        elif mode == 'peak':
            # Subgradient at the peak
            k_star = int(np.argmax(b))
            grad = np.zeros(n)
            a_flip = a[::-1]
            # grad[j] = a[k_star - j] (if valid) + a[j - k_star] (if valid, j != k_star)
            # This is conv(a, delta_{k_star}) essentially
            # More efficiently: grad = a shifted
            for j in range(n):
                val = 0.0
                if 0 <= k_star - j < n:
                    val += a[k_star - j]
                if j != k_star - j and 0 <= j - k_star < n:
                    val += a[j - k_star]
                grad[j] = val

        elif mode == 'multi_peak':
            # Weighted subgradient over top n_peaks peaks
            top_idx = np.argsort(b)[-n_peaks:]
            grad = np.zeros(n)
            for k_idx in top_idx:
                k_star = int(k_idx)
                for j in range(n):
                    val = 0.0
                    if 0 <= k_star - j < n:
                        val += a[k_star - j]
                    if j != k_star - j and 0 <= j - k_star < n:
                        val += a[j - k_star]
                    grad[j] += val
            grad /= n_peaks

        elif mode == 'matching':
            # Gradient towards matching a target distribution
            # Target: slightly above uniform for middle positions
            target = np.ones(2*n-1) / (2*n-1)
            # Boost the middle a bit since it naturally has more contributions
            # Actually, let's use the "achieved" distribution as target initially
            # No, let's use uniform as target
            diff = b - target
            # grad[j] = 2 * sum_k diff[k] * (a[k-j] + a[j-k])
            diff_pad = np.zeros(N)
            diff_pad[:2*n-1] = diff
            fdiff = rfft(diff_pad, N)
            fa_flip = rfft(a[::-1], N)
            c_full = irfft(fdiff * fa_flip, N)
            grad = 4.0 * c_full[n-1:2*n-1]

        else:
            grad = np.zeros(n)

        # Center the gradient (removes the constraint-redundant direction)
        grad = grad - np.mean(grad)

        # Momentum
        v = momentum * v - eta * grad
        a_new = a + v
        a_new = np.maximum(a_new, 0)
        s_new = float(np.sum(a_new))
        if s_new < 1e-10:
            eta *= 0.5
            v = np.zeros(n)
            continue
        a_new = a_new / s_new

        # Evaluate
        fa_new = rfft(a_new, N)
        b_new = irfft(fa_new * fa_new, N)[:2 * n - 1]
        obj_new = 2.0 * n * float(np.max(b_new))

        if obj_new < best_obj - 1e-12:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new
            stall = 0
            eta = min(eta * 1.003, 5.0)
            momentum = min(momentum + 0.0005, 0.95)
        else:
            stall += 1
            eta *= 0.98
            v *= 0.5
            if stall > max_stall:
                # Reset with small perturbation
                rng_local = np.random.default_rng(hash((n, it)) % (2**32))
                a = best_a * (1 + 0.03 * rng_local.normal(0, 1, n))
                a = np.maximum(a, 0)
                s = float(np.sum(a))
                if s > 1e-10:
                    a = a / s
                v = np.zeros(n)
                eta = 0.5
                momentum = 0.7
                stall = 0
                max_stall = min(max_stall + 50, 300)
            if eta < 1e-7:
                break

    return best_a

def lp_alternating(a, time_budget=60.0):
    """LP-based alternating optimization with line search."""
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    stall = 0

    for it in range(100):
        if time.monotonic() - start > time_budget:
            break

        g_lp = solve_lp_minpeak(a)
        if g_lp is None:
            break

        # Line search over t
        best_t_obj = np.inf
        best_t = 0.1
        for t in np.linspace(0.02, 1.0, 20):
            a_try = (1 - t) * a + t * g_lp
            s_try = float(np.sum(a_try))
            if s_try < 1e-10:
                continue
            a_try = a_try / s_try
            obj_try = compute_obj(a_try)
            if obj_try < best_t_obj:
                best_t_obj = obj_try
                best_t = t

        if best_t_obj < best_obj - 1e-11:
            best_obj = best_t_obj
            best_a = (1 - best_t) * a + best_t * g_lp
            best_a = np.maximum(best_a, 0)
            best_a = best_a / np.sum(best_a)
            a = best_a.copy()
            stall = 0
        else:
            stall += 1
            if stall > 15:
                break

    return best_a

def matching_gd(a, time_budget=60.0):

    n = len(a)

    if s < 1e-10:
        return a
    a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)

    # The "ideal" convolution for a flat target would be 1/(2n-1) everywhere

        grad = 4.0 * c_full[n-1:2*n-1]

        b_new = irfft(fa_new * fa_new, N)[:2*n-1]
        obj_new = 2.0 * n * float(np.max(b
