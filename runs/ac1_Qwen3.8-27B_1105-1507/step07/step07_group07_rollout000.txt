Now I understand the problem better. The key is:
1. Make the sequence asymmetric (skewed)
2. The "tail" of the distribution should be on the side where it contributes less to the max convolution
3. For a right-skewed sequence (increasing), the max convolution tends to be at a lag > n-1, and the value there is a sum of fewer products

Actually, let me think about this differently. The convolution b[k] for k >= n-1 has fewer terms:
- b[n-1] has n terms
- b[n] has n-1 terms
- b[n+j] has n-1-j terms
- ...
- b[2n-2] has 1 term: a[n-1]^2

For a right-skewed sequence (larger values at the end), b[n] = sum_{i=1}^{n-1} a[i]*a[n-i+1]... wait, let me be more careful.

b[k] = sum_i a[i]*a[k-i] where 0 <= i < n and 0 <= k-i < n.
For k = n: i ranges from 1 to n-1 (since k-i = n-i must be in [0, n-1], so i in [1, n-1]).
b[n] = sum_{i=1}^{n-1} a[i]*a[n-i]

For a right-skewed sequence (a[0] < a[1] < ... < a[n-1]):
b[n] = a[1]*a[n-1] + a[2]*a[n-2] + ... + a[n-1]*a[1]
This is a sum of products of large with small, medium with medium, etc.

b[n-1] = a[0]*a[n-1] + a[1]*a[n-2] + ... + a[n-1]*a[0]
This is also a sum of products of large with small, etc.

Hmm, they're similar. The difference is b[n-1] includes a[0]*a[n-1] and a[n-1]*a[0] (the two extreme products), while b[n] starts from a[1]*a[n-1].

For a strictly increasing sequence, b[n-1] > b[n] typically, because b[n-1] includes the a[n-1]*a[0] terms which are small, but also a[0]*a[n-1] which is small... actually they're the same terms just shifted.

Let me count: b[n-1] = sum_{i=0}^{n-1} a[i]*a[n-1-i]
b[n] = sum_{i=1}^{n-1} a[i]*a[n-i]

These are different sums. b[n-1] pairs a[i] with a[n-1-i], while b[n] pairs a[i] with a[n-i] (shifted by 1).
