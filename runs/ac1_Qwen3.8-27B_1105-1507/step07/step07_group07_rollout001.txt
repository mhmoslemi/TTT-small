This is getting tedious. Let me think about this more theoretically.

The objective is `2n * max_k R[k] / S^2` where R[k] = (a*a)[k].

For a "smoothly decreasing" sequence, the peak of the convolution tends to be at k=1 or k=2 (near the beginning), where the large values overlap with slightly smaller values.

The key question is: can we get the maximum below S^2/n?

Note that S^2 = (sum a_i)^2 = sum_i a_i^2 + 2*sum_{i<j} a_i*a_j

And R[0] = a[0]^2, R[1] = 2*a[0]*a[1], ..., R[n-1] = sum_i a[i]*a[n-1-i]

The sum of all R[k] = S^2 (this is a well-known identity: the sum of all elements of the autocorrelation equals the square of the sum).

So sum_k R[k] = S^2, and there are 2n-1 terms.
Therefore, the AVERAGE of R[k] is S^2/(2n-1).
By the pigeonhole principle, max R[k] >= S^2/(2n-1).

This gives objective >= 2n * S^2/(2n-1) / S^2 = 2n/(2n-1).

For large n, this approaches 1. So the theoretical lower bound is 1 (as n → ∞), achieved when all R[k] are equal to S^2/(2n-1).

This is a much better bound than 2! And it's achievable in principle for large n.
