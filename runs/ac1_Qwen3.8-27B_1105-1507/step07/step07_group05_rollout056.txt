What about a sequence that's concentrated in the middle? If a_{n/2} = 1, then conv[2*(n/2)] = 1, objective = 2n. Also terrible.

So we want to spread the mass in a way that avoids large peaks in the convolution.

Key insight: The convolution at lag k is essentially the "overlap" of a with a shifted by k positions. To minimize the max overlap, we want the sequence to be "spread out" in a way that no single shift creates a large overlap.

This is related to the concept of "sidelobes" in signal processing. We want a sequence whose autocorrelation has minimal peak sidelobe.

This is the same problem as designing a low-PAPR (Peak-to-Average Power Ratio) sequence, or a sequence with low autocorrelation sidelobes.

**Approach: Iterative water-filling / power iteration on the autocorrelation**

One classical approach is the "M" algorithm or "frequency domain" approach:
1. Start with a random sequence
2. Compute the DFT of the sequence
3. Modify the magnitudes (keep phases) to reduce peaks in the time domain
4. Inverse DFT
5. Repeat

But this is for complex sequences. For real non-negative sequences, we need a different approach.

**Approach: Subgradient method with multiple peak tracking**

The issue with the previous "chase_peak" is that it only tracks the single maximum. In practice, multiple peaks might be close to the maximum, and we should reduce all of them.

**Approach: Softmax gradient**

Use the softmax approximation: max(b) ≈ (1/tau) * log(sum(exp(tau * b)))
The gradient is: grad[i] = sum_k (exp(tau*b[k]) / sum(exp(tau*b[k]))) * a[k-i] (for valid k-i)

This naturally focuses on all near-peak elements, not just the single maximum.

The LP formulation is:
min M
s.t. conv(a, g)[k] <= M for all k = 0,...,2n-2
     sum(g) = 1
     g >= 0

This is a linear program in variables (g_0, ..., g_{n-1}, M) with 2n-1 + 1 = 2n constraints and n+1 variables. For n=800, that's 1600 constraints and 801 variables. This should be solvable.

The key insight from the SOTA description is the alternating method:
1. Fix a, solve LP for g
2. Blend: a_new = (1-t)*a + t*g
3. Repeat

def compute_conv(a, N=None):

    if N is None:

        while N < 2 * n - 1:

def topk_lp_alternating(a, time_budget=60.0, K=50, verbose=False):

            break

def resample_sequence(a, new_n):
    """Resample sequence to new length."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, a[0])
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)

def diversity_search(n, rng, num_starts=5):
    """Generate diverse initializations."""
    results = []
    for i in range(num_starts):
        mode = i % 7
        if mode == 0:
            a = np.ones(n) / n
        elif mode == 1:
            a = rng.uniform(0, 1, n)
            a = a / max(np.sum(a), 1e-10)
        elif mode == 2:
            # U-shaped
            x = np.arange(n) / max(n - 1, 1)
            a = (x - 0.5)**2 * 4 + 0.05
            a = a / np.sum(a)
        elif mode == 3:
            # Bimodal
            a = np.zeros(n)
            a[n//4] = 1
            a[3*n//4] = 1
            # Smooth it
            from scipy.ndimage import gaussian_filter1d
            a = gaussian_filter1d(a, sigma=n//20)
            a = a / max(np.sum(a), 1e-10)
        elif mode == 4:
            # Cosine raised
            x = np.linspace(0, np.pi, n)
            a = (1 + np.cos(x))**2 + 0.1
            a = a / np.sum(a)
        elif mode == 5:
            # Random smooth
            a = rng.uniform(0, 1, n)
            from scipy.ndimage import gaussian_filter1d
            a = gaussian_filter1d(a, sigma=n//10)
            a = a / max(np.sum(a), 1e-10)
        else:
            # Triangular (peaked in middle)
            x = np.arange(n)
            a = 1 - np.abs(x - n/2) / (n/2)
            a = a / max(np.sum(a), 1e-10)
        results.append(a)
    return results

"""

from scipy.fft import rfft, irfft
from scipy.optimize import linprog

def compute_conv(a, N=None):
    """Full linear convolution a*a via FFT."""
    n = len(a)
    if N is None:
        N = 1
        while N < 2 * n - 1:
            N <<= 1
    fa = rfft(a, N)
    return irfft(fa * fa, N)[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    b = compute_conv(a_norm)
    return 2.0 * n * float(np.max(b))


def compute_obj_normalized(a):
    """Assume a is already normalized (sum=1)."""
    n = len(a)
    b = compute_conv(a)
    return 2.0 * n * float(np.max(b))

        fw_rev = rfft(w_rev, N)
        
        conv_aw = irfft(fa * fw, N)
        conv_ar = irfft(fa * fw_rev, N)
        
        grad += conv_ar[2*n-2 : 2*n-2+n] + conv_aw[0:n]
    
    return grad


def adam_optimize(a, time_budget=60.0, verbose=False):
    """Adam-based optimization with multi-scale softmax gradient."""
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    lr = 0.1
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    m = np.zeros(n)
    v = np.zeros(n)
    t = 0
    N = get_N(n)
    stall = 0
    max_stall = 80
    
    for it in range(100000):
        if time.monotonic() - start > time_budget:
            break
        
        t += 1
        fa = rfft(a, N)
        b = irfft(fa * fa, N)[:2*n-1]
        
        grad = softmax_gradient_multiscale(a, b, N)
        grad = grad - np.mean(grad)
        
        m = beta1 * m + (1 - beta1) * grad
        v = beta2 * v + (1 - beta2) * grad**2
        m_hat = m / (1 - beta1**t)
        v_hat = v / (1 - beta2**t)
        
        a_new = a - lr * m_hat / (np.sqrt(v_hat) + eps)
        a_new = np.maximum(a_new, 0)
        s_new = float(np.sum(a_new))
        if s_new < 1e-10:
            lr *= 0.5
            continue
        a_new = a_new / s_new
        
        fa_new = rfft(a_new, N)
        b_new = irfft(fa_new * fa_new, N)[:2*n-1]
        obj_new = 2.0 * n * float(np.max(b_new))
        
        if obj_new < best_obj - 1e-13:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new
            stall = 0
            lr = min(lr * 1.008, 0.8)
        else:
            stall += 1
            lr *= 0.98
            if stall > max_stall:
                rng_local = np.random.default_rng(it * 7 + n)
                a = best_a * np.exp(rng_local.normal(0, 0.02, n))
                a = np.maximum(a, 0)
                s = float(np.sum(a))
                if s > 1e-10:
                    a = a / s
                else:
                    a = best_a.copy()
                m = np.zeros(n)
                v = np.zeros(n)
                lr = 0.1
                stall = 0
                max_stall = min(max_stall + 40, 250)
            if lr < 1e-12:
                break
        
        if verbose and it % 1000 == 0:
            print(f"          Adam it{it}: obj={best_obj:.8f}, lr={lr:.6f}")
    
    return best_a


def build_constraint_matrix(a, topK):
    """Build constraint matrix for LP: A[i,j] = a[topK[i] - j] if valid."""
    n = len(a)
    K = len(topK)
    A = np.zeros((K, n))
    for i in range(K):
        k = topK[i]
        j_min = max(0, k - n + 1)
        j_max = min(k, n - 1)
        if j_min <= j_max:
            A[i, j_min:j_max+1] = a[k - j_max:k - j_min + 1][::-1]
    return A


def solve_lp_given_matrix(A, n):
    """Solve LP: min M s.t. A@g <= M, sum(g)=1, g>=0."""
    c = np.zeros(n + 1)
    c[-1] = 1.0
    A_ub = np.zeros((A.shape[0], n + 1))
    A_ub[:, :n] = A
    A_ub[:, n] = -1.0
    b_ub = np.zeros(A.shape[0])
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([1.0])
    bounds = [(0, None)] * n + [(0, None)]
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                  bounds=bounds, method='highs')
    if res.status == 0:
        g_val = np.maximum(res.x[:n], 0)
        s_g = float(np.sum(g_val))
        if s_g > 1e-10:
            return g_val / s_g
    return None


def lp_alternating_adaptive(a, time_budget=120.0, K_start=50, K_max=300, verbose=False):
    """LP alternating with adaptive K and binary search line search."""
    n = len(a)
    a = a / np.sum(a)
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    stall = 0
    K = K_start
    
    for it in range(200):
        if time.monotonic() - start > time_budget:
            break
        
        b = compute_conv(a)
        topK = np.argsort(b)[-K:]
        A = build_constraint_matrix(a, topK)
        
        g_val = solve_lp_given_matrix(A, n)
        if g_val is None:
            K = max(K_start, K // 2)
            continue
        
        # Binary search for optimal t
        best_t_obj = np.inf
        best_t = 0.3
        lo, hi = 0.0, 1.0
        for _ in range(8):
            mid = (lo + hi) / 2
            a_try = (1 - mid) * a + mid * g_val
            a_try = np.maximum(a_try, 0)
            s_try = float(np.sum(a_try))
            if s_try < 1e-10:
                hi = mid
                continue
            a_try = a_try / s_try
            obj_try = compute_obj(a_try)
            if obj_try < best_t_obj:
                best_t_obj = obj_try
                best_t = mid
            # Check if objective is decreasing
            t_next = mid + (hi - mid) / 2
            a_chk = (1 - t_next) * a + t_next * g_val
            a_chk = np.maximum(a_chk, 0)
            s_chk = float(np.sum(a_chk))
            if s_chk > 1e-10:
                obj_chk = compute_obj(a_chk / s_chk)
                if obj_chk > best_t_obj:
                    hi = mid
                else:
                    lo = mid
            else:
                hi = mid
        
        if best_t_obj < best_obj - 1e-12:
            best_obj = best_t_obj
            best_a = (1 - best_t) * a + best_t * g_val
            best_a = np.maximum(best_a, 0)
            best_a = best_a / np.sum(best_a)
            a = best_a.copy()
            stall = 0
            # Increase K slowly for more constraints
            K = min(K * 1.1, K_max)
            if verbose and it % 10 == 0:
                print(f"          LP it{it}: obj={best_obj:.8f}, K={int(K)}, t={best_t:.3f}")
        else:
            stall += 1
            if stall > 15:
                K = max(K_start, int(K * 0.7))
                if stall > 30:
                    break
    
    return best_a


def coordinate_descent(a, time_budget=60.0, n_trials_per_pass=3, verbose=False):
    """
    Coordinate descent: try small perturbations to individual elements.
    """
    n = len(a)
    a = a / np.sum(a)
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    N = get_N(n)
    
    for it in range(200):
        if time.monotonic() - start > time_budget:
            break
        
        improved = False
        b = compute_conv(a)
        k_star = int(np.argmax(b))
        
        # Focus on elements that contribute to the peak
        contrib = np.zeros(n)
        for j in range(n):
            if 0 <= k_star - j < n:
                contrib[j] += a[k_star - j]
            if 0 <= j - k_star < n:
                contrib[j] += a[j - k_star]
        
        # Try reducing high-contribution elements and increasing low ones
        # Get indices sorted by contribution
        order = np.argsort(-contrib)
        
        # Try reducing top contributors
        for idx in order[:max(10, n // 10)]:
            if time.monotonic() - start > time_budget:
                break
            for frac in [0.01, 0.02, 0.05]:
                delta = -frac * a[idx]
                a_try = a.copy()
                a_try[idx] += delta
                if a_try[idx] < 0:
                    continue
                # Redistribute to lowest contributors
                remaining = -delta
                low_order = order[::-1][:10]
                per = remaining / len(low_order)
                for lidx in low_order:
                    a_try[lidx] += per
                a_try = np.maximum(a_try, 0)
                s_try = float(np.sum(a_try))
                if s_try < 1e-10:
                    continue
                a_try = a_try / s_try
                
                fa_try = rfft(a_try, N)
                b_try = irfft(fa_try * fa_try, N)[:2*n-1]
                obj_try = 2.0 * n * float(np.max(b_try))
                
                if obj_try < best_obj - 1e-13:
                    best_obj = obj_try
                    best_a = a_try.copy()
                    a = a_try
                    improved = True
                    break
        
        if not improved:
            break
    
    return best_a


def fft_gd_energy(a, time_budget=60.0, verbose=False):
    """FFT-based GD minimizing energy (L2) of auto-convolution as smooth proxy."""
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    eta = 0.3
    momentum = 0.7
    v = np.zeros(n)
    N = get_N(n)
    stall = 0
    
    for it in range(50000):
        if time.monotonic() - start > time_budget:
            break
        
        fa = rfft(a, N)
        b = irfft(fa * fa, N)[:2*n-1]
        
        # Gradient of sum(b^2)
        fb = rfft(b, N)
        conv_ab = irfft(fa * fb, N)
        b_rev = b[::-1]
        fb_rev = rfft(b_rev, N)
        conv_ar = irfft(fa * fb_rev, N)
        
        grad = np.zeros(n)
        grad += conv_ar[2*n-2 : 2*n-2+n]
        grad += conv_ab[0:n]
        grad *= 2.0
        grad = grad - np.mean(grad)
        
        v = momentum * v - eta * grad
        a_new = a + v
        a_new = np.maximum(a_new, 0)
        s_new = float(np.sum(a_new))
        if s_new < 1e-10:
            eta *= 0.5
            v = np.zeros(n)
            continue
        a_new = a_new / s_new
        
        fa_new = rfft(a_new, N)
        b_new = irfft(fa_new * fa_new, N)[:2*n-1]
        obj_new = 2.0 * n * float(np.max(b_new))
        
        if obj_new < best_obj - 1e-13:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new
            stall = 0
            eta = min(eta * 1.003, 2.0)
        else:
            stall += 1
            eta *= 0.98
            v *= 0.5
            if stall > 200:
                rng_local = np.random.default_rng(it + n)
                a = best_a * np.exp(rng_local.normal(0, 0.04, n))
                a = np.maximum(a, 0)
                s = float(np.sum(a))
                if s > 1e-10:
                    a = a / s
                v = np.zeros(n)
                eta = 0.3
                stall = 0
            if eta < 1e-9:
                break
    
    return best_a


def resample_sequence(a, new_n):
    """Resample sequence to new length."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, a[0])
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)


def diverse_init(n, rng, mode=0):
    """Generate diverse asymmetric initializations."""
    if mode == 0:
        # Asymmetric random
        a = rng.uniform(0, 1, n)
        a = a / max(np.sum(a), 1e-10)
    elif mode == 1:
        # Skewed (more mass on left)
        a = np.exp(-0.3 * np.arange(n) / n)
        a = a / np.sum(a)
    elif mode == 2:
        # Skewed (more mass on right)
        a = np.exp(-0.3 * (n - 1 - np.arange(n)) / n)
        a = a / np.sum(a)
    elif mode == 3:
        # Bimodal asymmetric
        a = np.zeros(n)
        a[n//5] = 1.0
        a[2*n//5] = 0.6
        a[4*n//5] = 0.3
        a = gaussian_filter1d(a, sigma=n//15)
        a = a / max(np.sum(a), 1e-10)
    elif mode == 4:
        # Sawtooth with noise
        a = np.linspace(1.0, 0.2, n)
        a += 0.05 * rng.standard_normal(n)
        a = np.maximum(a, 0)
        a = a / max(np.sum(a), 1e-10)
    elif mode == 5:
        # Cosine window (shifted for asymmetry)
        x = np.linspace(0, 0.7 * np.pi, n)
        a = 0.5 * (1 + np.cos(x)) + 0.1
        a = a / np.sum(a)
    else:
        # Random smooth asymmetric
        a = rng.uniform(0, 1, n)
        a = gaussian_filter1d(a, sigma=n//12)
        a = a / max(np.sum(a), 1e-10)
    return a


def optimize_single(a, time_budget=60.0, verbose=False):
    """Run a sequence of optimizers on a single candidate."""
    n = len(a)
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    # Step 1: Adam
    remaining = start + time_budget - time.monotonic()
    if remaining > 15:
        alloc = min(remaining * 0.4, 40.0)
        a1 = adam_optimize(best_a, time_budget=alloc)
        obj1 = compute_obj(a1)
        if obj1 < best_obj:
            best_obj = obj1
            best_a = a1
            if verbose:
                print(f"            Adam: {best_obj:.8f}")
    
    # Step 2: LP
    remaining = start + time_budget - time.monotonic()
    if remaining > 15:
        alloc = min(remaining * 0.35, 30.0)
        a2 = lp_alternating_adaptive(best_a, time_budget=alloc, K_start=50, K_max=200)
        obj2 = compute_obj(a2)
        if obj2 < best_obj:
            best_obj = obj2
            best_a = a2
            if verbose:
                print(f"            LP: {best_obj:.8f}")
    
    # Step 3: Energy GD
    remaining = start + time_budget - time.monotonic()
    if remaining > 10:
        alloc = min(remaining * 0.25, 20.0)
        a3 = fft_gd_energy(best_a, time_budget=alloc)
        obj3 = compute_obj(a3)
        if obj3 < best_obj:
            best_obj = obj3
            best_a = a3
            if verbose:
                print(f"            EGD: {best_obj:.8f}")
    
    # Step 4: Coordinate descent
    remaining = start + time_budget - time.monotonic()
    if remaining > 10:
        alloc = min(remaining * 0.3, 20.0)
        a4 = coordinate_descent(best_a, time_budget=alloc)
        obj4 = compute_obj(a4)
        if obj4 < best_obj:
            best_obj = obj4
            best_a = a4
            if verbose:
                print(f"            CD: {best_obj:.8f}")
    
    return best_a, best_obj
