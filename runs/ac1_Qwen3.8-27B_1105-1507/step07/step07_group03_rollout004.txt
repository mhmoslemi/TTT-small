This means the gradient of the objective with respect to a is essentially a "g autocorrelation" of the weight vector with a, where the weight vector is the softmax weights over the convolution values.

Let me define w[k] = softmax(beta * c[k]) for k = 0, ..., 2n-2.

Then ∂f/∂a[i] = 2 * sum_k w[k] * a[k-i] (where a[k-i] = 0 if k-i out of range)

This is: 2 * conv(w_padded, a)[i] where w_padded is w placed in the right position.

Actually, it's 2 * (w * a) where the convolution is... let me think.

sum_k w[k] * a[k-i] for k=0..2n-2.

Let j = k-i, so k = j+i. j ranges from -i to 2n-2-i, but a[j] is only non-zero for 0 ≤ j < n.

So sum_j w[j+i] * a[j] for j = max(0, i-(2n-2)) to min(n-1, 2n-2-i)

This is essentially a cross-correlation of w and a.

OK this is getting complicated. Let me just implement it numerically using FFT.

For the optimization, I'll use:
1. Softmax-approximated objective
2. Gradient computed via FFT
3. Projected gradient descent (project onto a >= 0, sum(a) = 1)
4. Adaptive learning rate
5. Multiple restarts with different initializations

Additionally, I'll add:
- A "peak targeting" mode where I only consider the top few peaks in the softmax
- Frequency domain initialization (try to make |FFT(a)|^2 flat from the start)
- Non-palindromic initial structures (shifted sequences, etc.)

Let me also think about the non-palindromic insight more. If a is palindromic, then c is also palindromic and the peak is at the center c[n-1] = sum(a_i^2) >= sum_a^2/n. But if a is NOT palindromic, the peak can be elsewhere and can be smaller.

For example, if a is concentrated at one end: a = [T, 0, 0, ..., 0, t] where T >> t and the 1 is at position n-1.
Then c[k] is small for most k, with peaks at k=0 (T^2), k=n-1 (2Tt), and k=2n-2 (t^2).
If T >> t, the peak is T^2, and sum_a ≈ T, so objective ≈ 2n*T^2/T^2 = 2n. Terrible.

What about a that's a "ramp"? a[i] = i+1 for i=0..n-1.
sum_a = n(n+1)/2
c[k] for k < n: sum_{i=0}^{n-1-k} (i+1)(i+k+1)
This is a quadratic in k, maximum at k=0 or k=n-1.

Not great. The key is to find a structure where the convolution is flat.

For complex sequences, Golay sequences achieve perfectly flat autocorrelation. For real non-negative sequences, we can't achieve perfect flatness, but we can get close.

One idea: use the "chirp" or "Kaiser" window shapes, or use sequences derived from the inverse of a flat spectrum (which is what the FFT flat spectrum method does).

Let me now write the actual code. I'll focus on:

1. **Softmax gradient descent**: The main optimization engine
2. **Frequency domain initialization**: Start close to flat spectrum
3. **Non-palindromic structure**: Bias the initial sequence to be non-symmetric
4. **Adaptive peak weighting**: Focus optimization on the actual peaks
5. **Multiple n exploration**: Try different sequence lengths
6. **Local search / refinement**: Fine-tune the best solution

"""
Optimization for minimizing 2*n*max(conv(a,a))/(sum(a))^2 using:
- Softmax-approximated gradient descent with adaptive peak weighting
- Frequency domain (flat spectrum) initialization
- Non-palindromic structural bias
- Multi-n exploration and local refinement
"""

import numpy as np
from scipy.fft import rfft, irfft, fft, ifft
import time


def compute_conv(a):
    """Full linear convolution a*a via FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    max_b = float(np.max(conv))
    return 2.0 * n * max_b


def softmax_gradient(a, beta=50.0, top_k=None):
    """Compute gradient of softmax-approximated max of conv(a,a).
    
    Returns gradient vector of same length as a.
    """
    n = len(a)
    conv = compute_conv(a)
    
    # Compute softmax weights
    if top_k is not None and top_k < len(conv):
        # Only consider top_k peaks
        top_idx = np.argsort(conv)[-top_k:]
        top_val = conv[top_idx]
        max_val = top_val.max()
        # Renormalize within top_k
        w_top = np.exp((top_val - max_val) * beta)
        w_top /= w_top.sum()
        w = np.zeros(len(conv))
        w[top_idx] = w_top
    else:
        max_val = conv.max()
        w = np.exp((conv - max_val) * beta)
        w_sum = w.sum()
        if w_sum > 0:
            w /= w_sum
        else:
            w = np.zeros(len(conv))
            w[conv.argmax()] = 1.0
    
    # Gradient: grad[i] = 2 * sum_k w[k] * a[k-i] (valid k-i)
    # This is 2 * cross_correlation(w, a)
    # Use FFT for efficiency
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    
    # conv(w, a) but with w of length 2n-1 and a of length n
    # result[i] = sum_k w[k] * a[k-i] for valid indices
    # This is like cross-correlation
    
    # Actually: sum_k w[k] * a[k-i] where a[j]=0 for j<0 or j>=n
    # = sum_j w[j+i] * a[j] where j+i is in [0, 2n-2]
    # This is the cross-correlation of w and a
    
    # Using FFT: cross_correlation = ifft(conj(fft(w, size)) * fft(a, size))
    # But w has length 2n-1, a has length n
    
    fw = fft(w, size)
    fa = fft(a, size)
    # cross-correlation: ifft(conj(fw) * fa) gives sum_k w[k] * a[k+i]... 
    # Let me think more carefully.
    
    # We want g[i] = sum_k w[k] * a[k-i] = sum_j w[j+i] * a[j]
    # This is (w cross-correlate a)[i] where cross-correlation is defined as
    # (w ⋆ a)[i] = sum_j w[j+i] * a[j]
    
    # In FFT terms: ifft(conj(fft(w)) * fft(a)) gives the circular cross-correlation
    # which for our padding should give the linear cross-correlation
    
    grad = 2.0 * ifft(np.conj(fw) * fa).real[:n]
    
    return grad, conv, w


def softmax_gradient_descent(a, n_iters=3000, time_budget=120.0, beta=None, top_k=None):
    """Gradient descent on softmax-approximated objective with non-negativity constraint."""
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    if beta is None:
        beta = 30.0
    if top_k is None:
        top_k = max(5, n // 10)
    
    # Adaptive parameters
    lr = 0.1
    beta_start = max(5.0, beta * 0.3)
    beta_end = beta * 2.0
    
    for it in range(n_iters):
        if time.monotonic() - start > time_budget:
            break
        
        # Anneal beta
        progress = it / max(1, n_iters)
        current_beta = beta_start + (beta_end - beta_start) * progress
        if progress > 0.5:
            current_top_k = max(1, int(top_k * (1 - (progress - 0.5) * 1.5)))
        else:
            current_top_k = top_k
        
        grad, conv, w = softmax_gradient(a, current_beta, current_top_k)
        
        # Normalize gradient
        grad_norm = np.linalg.norm(grad)
        if grad_norm > 1e-10:
            grad = grad / grad_norm
        
        # Gradient step
        a_new = a - lr * grad
        a_new = np.maximum(a_new, 0)
        s_new = float(np.sum(a_new))
        if s_new > 1e-10:
            a_new = a_new / s_new
            obj_new = compute_obj(a_new)
            if obj_new < best_obj - 1e-13:
                best_obj = obj_new
                best_a = a_new.copy()
                a = a_new
                # Occasionally increase lr
                if it % 100 == 50:
                    lr = min(lr * 1.05, 0.5)
            else:
                lr *= 0.95
        else:
            lr *= 0.5
        
        # Periodic exploration
        if it % 500 == 499:
            rng = np.random.default_rng(it)
            a = best_a * np.exp(rng.normal(0, 0.03, n))
            a = np.maximum(a, 0)
            s = float(np.sum(a))
            if s > 1e-10:
                a = a / s
            best_a = a.copy()
            best_obj = compute_obj(a)
            lr = 0.1
    
    return best_a


def flat_spectrum_init(n, rng, mode=0):
    """Generate initial sequence with approximately flat spectrum."""
    if mode == 0:
        # Start from uniform and iteratively flatten
        a = np.ones(n)
    elif mode == 1:
        # Random with flat spectrum projection
        a = rng.uniform(0, 1, n)
    elif mode == 2:
        # Non-palindromic: ramp-like
        a = np.linspace(0.5, 1.5, n)
    elif mode == 3:
        # Non-palindromic: asymmetric Gaussian
        x = np.arange(n)
        center = n * 0.3  # Off-center
        a = np.exp(-0.5 * ((x - center) / (n * 0.2)) ** 2) + 0.1
    elif mode == 4:
        # Two-bump asymmetric
        x = np.arange(n)
        a = np.exp(-0.5 * ((x - n*0.25) / (n*0.15)) ** 2) + \
            np.exp(-0.5 * ((x - n*0.7) / (n*0.1)) ** 2) * 0.7 + 0.05
    elif mode == 5:
        # Chirp-like
        x = np.arange(n) / n
        a = 0.5 + 0.3 * np.cos(2 * np.pi * (x + 0.5 * x**2)) + 0.2 * np.cos(4 * np.pi * x * 0.7)
        a = np.maximum(a, 0.01)
    else:
        # Random structured
        a = rng.uniform(0, 1, n)
        kernel = np.ones(3) / 3
        a = np.convolve(a, kernel, mode='same')
        a = np.maximum(a, 0.01)
    
    a = np.maximum(a, 0)
    s = float(np.sum(a))
    if s > 1e-10:
        a = a / s
    return a


def fft_flatten(a, n_iters=200, time_budget=30.0):
    """Iteratively flatten the power spectrum using GS algorithm."""
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    
    L = 1
    while L < 2 * n - 1:
        L <<= 1
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    for it in range(n_iters):
        if time.monotonic() - start > time_budget:
            break
        
        A = fft(a, L)
        mag = np.abs(A)
        mag_safe = np.maximum(mag, 1e-10)
        phase = A / mag_safe
        
        # Target: flat magnitude
        target_mag = np.sqrt(L) / n  # Normalized so that energy is preserved
        # Actually, we want |A|^2 to be flat, so |A| = constant
        # The constant should be such that sum(|A|^2) = L * sum(a^2) (Parseval)
        # For flat: |A|^2 = L * sum(a^2) / L = sum(a^2)
        # So |A| = sqrt(sum(a^2))
        target = np.sqrt(np.sum(a**2))
        
        A_new = phase * target
        a_new = ifft(A_new).real[:n]
        a_new = np.maximum(a_new, 0)
        s_new = float(np.sum(a_new))
        if s_new > 1e-10:
            a_new = a_new / s_new
            obj_new = compute_obj(a_new)
            if obj_new < best_obj - 1e-12:
                best_obj = obj_new
                best_a = a_new.copy()
                a = a_new
    
    return best_a


def peak_reduction(a, n_iters=500, time_budget=60.0):
    """Directly target and reduce the peak of the convolution."""
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    lr = 0.05
    
    for it in range(n_iters):
        if time.monotonic() - start > time_budget:
            break
        
        conv = compute_conv(a)
        k_star = int(np.argmax(conv))
        
        # Compute subgradient at the peak:
        # grad[i] = 2 * a[k_star - i] (if 0 <= k_star - i < n)
        grad = np.zeros(n)
        for i in range(n):
            j = k_star - i
            if 0 <= j < n:
                grad[i] = 2.0 * a[j]
        
        # Also consider the mean of convolution as a "baseline"
        # Only reduce contributions that are above average
        avg_conv = np.mean(conv)
        
        # Gradient step: reduce the peak by moving mass away
        a_new = a - lr * grad
        a_new = np.maximum(a_new, 0)
        s_new = float(np.sum(a_new))
        if s_new > 1e-10:
            a_new = a_new / s_new
            obj_new = compute_obj(a_new)
            if obj_new < best_obj - 1e-13:
                best_obj = obj_new
                best_a = a_new.copy()
                a = a_new
            else:
                lr *= 0.95
        else:
            lr *= 0.5
        
        # Occasionally try a different peak
        if it % 100 == 99:
            top_idx = np.argsort(conv)[-3:]
            k_star = int(top_idx[np.random.randint(3)])
            grad = np.zeros(n)
            for i in range(n):
                j = k_star - i
                if 0 <= j < n:
                    grad[i] = 2.0 * a[j]
            a_new = a - lr * grad
            a_new = np.maximum(a_new, 0)
            s_new = float(np.sum(a_new))
            if s_new > 1e-10:
                a_new = a_new / s_new
                obj_new = compute_obj(a_new)
                if obj_new < best_obj - 1e-13:
                    best_obj = obj_new
                    best_a = a_new.copy()
                    a = a_new
    
    return best_a


def resample_sequence(a, new_n):
    """Resample sequence to new length via linear interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, a[0])
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)
