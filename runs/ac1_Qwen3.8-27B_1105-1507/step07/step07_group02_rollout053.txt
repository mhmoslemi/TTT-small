max = 20 at k=4. Score = 2*4*20/64 = 2.5 (worse)

Hmm. Let me try to think about what sequences give score < 2.

For score < 2: `max(conv) < (sum a)^2 / n`.

Since `sum(conv) = (sum a)^2` and there are 2n-1 values, the mean is `(sum a)^2/(2n-1)`. We need max < (sum a)^2/n, which is about twice the mean (for large n). So we need the convolution to be reasonably flat - the max should be less than about twice the mean.

For a constant sequence, all conv values are proportional to the "triangle" (1, 2, 3, ..., n, n-1, ..., 2, 1) * c^2, and the max is n*c^2 = (sum)^2/n. So score = exactly 2.

To get score < 2, we need the convolution to be flatter than the triangle. The triangle shape is the worst case for non-negative sequences in some sense.

What if the sequence is periodic? Like a = [1, 0, 1, 0, 1, 0, ...]? Then the convolution has peaks at even positions and zeros at odd positions. The max would be large (concentrated), so score would be high. Not good.

What about a sequence with a specific "flat-top" property? 

Actually, let me think about this problem from the LP perspective. The LP says: given a, find g >= 0, sum(g)=1, that minimizes max_k (a*g)[k]. At the optimal g, the constraint is tight at certain positions (the "active set"). The optimum value is M = max_k (a*g)[k].

At a fixed point (a = g), we have: a minimizes max_k (a*a)[k] in the sense that there's no g that can reduce the max further (when convolved with a).

This means at the fixed point, for all k in the active set (where (a*a)[k] = M), the "direction" of improvement (reducing the contribution to conv[k]) is blocked by the non-negativity constraint or the sum constraint.

I think the practical approach is:
1. Use the parent sequence as a starting point.
2. Apply a more efficient optimization than LP.
3. Try multiple n values.
4. Use a combination of methods.

Let me design a practical algorithm:

**Algorithm: Smoothed Subgradient with FFT + Multi-start + n-sweeping**

```python
import numpy as np
import time
from scipy.fft import rfft, irfft

def compute_conv(a):
    n = len(a)
    if n == 1:
        return np.array([a[0]*a[0]])
    size = 1
    while size < 2*n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2*n-1]

def compute_obj(a):
    n = len(a)
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a = a / s
    conv = compute_conv(a)
    return 2.0 * n * float(np.max(conv))

def optimize_subgradient(a, time_budget=60.0, verbose=False):
    """
    Subgradient optimization of max(conv(a,a)) subject to sum(a)=1, a>=0.
    Uses smoothed max (softmax) for a differentiable objective.
    """
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        a = np.ones(n) / n
        return a
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    tau = 0.01  # initial temperature for softmax
    lr = 0.01
    patience = 0
    
    for it in range(2000):
        if time.monotonic() - start > time_budget:
            break
        
        conv = compute_conv(a)
        # Softmax weights
        max_conv = np.max(conv)
        w = np.exp((conv - max_conv) / tau)
        w /= np.sum(w)
        
        # Gradient: grad[i] = sum_k w[k] * a[k-i] (valid indices)
        # Compute via FFT
        # grad[i] = sum_{j=0}^{n-1} a[j] * w[i+j] for i = 0,...,n-1
        # Use the trick: grad = ifft(fft(w_padded) * fft(a_padded)) ... 
        # Actually let me use the correlation approach.
        # 
        # Note: (w * a_reversed)[n-1+i] = sum_j w[j] * a_rev[n-1+i-j] = sum_j w[j] * a[j-i]
        # That's not quite right either.
        #
        # Let me just use: conv(w, a)[k] = sum_j w[j] * a[k-j]
        # I want grad[i] = sum_j a[j] * w[i+j]
        # Let m = i+j: grad[i] = sum_m a[m-i] * w[m] = (a_rev * w)[2n-2-i+...] 
        #
        # Simplest: use numpy corrfunc or just FFT correlation.
        # corr = ifft(fft(w, N) * conj(fft(a, N))) gives cross-correlation.
        # cross_corr[m] = sum_j w[j+m] * conj(a[j]) (convention-dependent)
        #
        # Let me just do it with a padded FFT convolution:
        size = 1
        while size < 3*n:
            size <<= 1
        fw = np.fft.fft(w, size)
        fa = np.fft.fft(a, size)
        # conv(w, a)[k] = sum_j w[j] * a[k-j]
        wa = np.fft.ifft(fw * fa).real[:3*n-1]
        # I want grad[i] = sum_{j=0}^{n-1} a[j] * w[i+j]
        # = sum_j w[i+j] * a[j]
        # Note: conv(w, a_rev)[k] where a_rev[j] = a[n-1-j]
        # conv(w, a_rev)[k] = sum_j w[j] * a_rev[k-j] = sum_j w[j] * a[n-1-k+j]
        # Let l = n-1-k+j: = sum_l w[n-1-k+l] * a[l]
        # Set n-1-k+l = i+j... this is getting circular.
        #
        # Let me just use a direct O(n^2) approach for n <= 3000.
        
        if n <= 3000:
            # O(n^2) direct computation
            # grad[i] = sum_{j=0}^{n-1} a[j] * w[i+j] (where i+j < 2n-1)
            grad = np.zeros(n)
            for i in range(n):
                j_max = min(n, 2*n-1-i)
                grad[i] = np.dot(a[:j_max], w[i:i+j_max])
        else:
            # For large n, use FFT
            # grad[i] = sum_{j=0}^{n-1} a[j] * w[i+j]
            # Define b = w (length 2n-1), and we want the "diagonal" sum.
            # This is equivalent to: for the matrix D where D[i,j] = w[i+j], compute D @ a.
            # We can compute this as: D @ a = ifft(fft(w, 2*(2n-1)) * ... ) 
            # Actually, let's use the fact that this is a Toeplitz matrix-vector product.
            # D[i,j] = w[i+j] is a "Hankel" matrix (constant along anti-diagonals).
            # For Hankel matrix-vector products, we can use FFT.
            # 
            # D @ a = [sum_j w[j]a[j], sum_j w[j+1]a[j], ..., sum_j w[j+n-1]a[j]]
            # (with w indexed from 0 to 2n-2)
            # 
            # This is the "sliding dot product" of w with a.
            # We can compute it as: 
            # Reverse a: ar = a[::-1] (length n)
            # conv(w, ar)[k] = sum_j w[j] * ar[k-j] = sum_j w[j] * a[n-1-k+j]
            # For k = n-1: conv(w, ar)[n-1] = sum_j w[j] * a[j] (= grad[0])
            # For k = n-2: conv(w, ar)[n-2] = sum_j w[j] * a[j-1] ... 
            # Hmm, this gives grad in reverse order.
            # 
            # Let me try: conv(ar, w)[k] = sum_j ar[j] * w[k-j] = sum_j a[n-1-j] * w[k-j]
            # For k = 2n-2: = sum_j a[n-1-j] * w[2n-2-j] = sum_j a[j] * w[2n-2-(n-1-j)] = sum_j a[j] * w[n-1+j]
            # That's grad[n-1]!
            # For k = 2n-3: = sum_j a[j] * w[n-2+j] = grad[n-2]
            # So grad[i] = conv(ar, w)[2n-2-i] for i = 0,...,n-1
            # i.e., grad = conv(ar, w)[n-1 : 2n-1 : -1] (reversed slice)
            
            ar = a[::-1]
            size2 = 1
            while size2 < 2*(2*n-1):
                size2 <<= 1
            far = np.fft.fft(ar, size2)
            fw2 = np.fft.fft(w, size2)
            conv_aw = np.fft.ifft(far * fw2).real[:2*(2*n-1)-1]
            grad = conv_aw[2*n-2 : n-1 : -1]
        
        # Center the gradient to preserve sum
        grad_mean = np.mean(grad)
        grad_centered = grad - grad_mean
        
        # Update
        a_new = a - lr * grad_centered
        a_new = np.maximum(a_new, 0)
        s_new = float(np.sum(a_new))
        if s_new < 1e-10:
            lr *= 0.5
            continue
        a_new = a_new / s_new
        
        obj_new = compute_obj(a_new)
        
        if obj_new < best_obj - 1e-12:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new
            patience = 0
            # Slowly decrease temperature
            tau = max(tau * 0.999, 0.001)
        else:
            patience += 1
            if patience % 100 == 0:
                lr *= 0.9
                tau = max(tau * 0.95, 0.001)
            if patience > 500:
                # Restart with perturbation
                rng = np.random.default_rng(it * 7 + n)
                a = best_a * np.exp(rng.normal(0, 0.05, n))
                a = np.maximum(a, 0)
                a = a / np.sum(a)
                best_a = a.copy()
                best_obj = compute_obj(a)
                patience = 0
                lr = 0.01
        
        if verbose and it % 100 == 0:
            print(f"    subgrad it{it}: obj={best_obj:.8f}, tau={tau:.5f}, lr={lr:.5f}")
    
    return best_a

Actually, `np.dot(a[:j_max], w[i:i+j_max])` for each i is O(n) and there are n of them, so total is O(n^2) = 640,000 for n=800. Each dot product is very fast with numpy (vectorized). So the total time for one gradient computation is roughly n * (n/2) / (numpy speed) ≈ 800 * 400 / 1e9 ≈ 0.0003 seconds. That's fine!

Actually wait, the loop `for i in range(n): grad[i] = np.dot(...)` has n=800 iterations, each doing a dot product of length ~n/2=400. The total number of multiply-adds is ~n^2/2 = 320,000. For 2000 iterations, that's 2 seconds. Fine!

But actually, I can make this faster using the FFT trick I derived:
`grad = conv(a[::-1], w)[n-1 : 2n-1 : -1]`

Let me verify this. `conv(ar, w)[k] = sum_j ar[j] * w[k-j]` where ar[j] = a[n-1-j].
= sum_j a[n-1-j] * w[k-j]

Let i = n-1-j, so j = n-1-i:
= sum_i a[i] * w[k-(n-1-i)] = sum_i a[i] * w[k-n+1+i]

For k = 2n-2: = sum_i a[i] * w[n-1+i] -- this is grad[n-1] (since grad[n-1] = sum_j a[j]*w[n-1+j])
For k = 2n-3: = sum_i a[i] * w[n-2+i] = grad[n-2]
...
For k = n-1: = sum_i a[i] * w[i] = grad[0]

So grad[i] = conv(ar, w)[n-1+i] for i = 0,...,n-1.
i.e., grad = conv(ar, w)[n-1 : 2n-1] (a slice, not reversed!)

Let me verify with a small example. n=3, a=[a0,a1,a2], w=[w0,w1,w2,w3,w4].
ar = [a2, a1, a0]
conv(ar, w) has length 3+5-1=7:
conv[0] = a2*w0
conv[1] = a2*w1 + a1*w0
conv[2] = a2*w2 + a1*w1 + a0*w0
conv[3] = a2*w3 + a1*w2 + a0*w1
conv[4] = a2*w4 + a1*w3 + a0*w2
conv[5] = a1*w4 + a0*w3
conv[6] = a0*w4

grad[0] should be sum_j a[j]*w[0+j] = a0*w0 + a1*w1 + a2*w2
grad[1] should be sum_j a[j]*w[1+j] = a0*w1 + a1*w2 + a2*w3
grad[2] should be sum_j a[j]*w[2+j] = a0*w2 + a1*w3 + a2*w4

From conv:
conv[2] = a2*w2 + a1*w1 + a0*w0 = grad[0] ✓ (commutative sum)
conv[3] = a2*w3 + a1*w2 + a0*w1 = grad[1] ✓
conv[4] = a2*w4 + a1*w3 + a0*w2 = grad[2] ✓

So grad = conv(ar, w)[n-1 : n-1+n] = conv(ar, w)[2:5] for n=3.

In general: grad = conv(a[::-1], w)[n-1 : 2*n-1]

This can be computed in O(n log n) using FFT. 

Now let me put together a complete, efficient algorithm:

1. Start with the parent sequence (or a good initial guess).
2. Use FFT-based subgradient descent with smoothed max.
3. Periodically try different n values.
4. Use multiple random restarts.
5. Apply a final "polish" using more iterations at lower learning rate.

Let me also think about what initializations to try:
- The parent sequence
- Constant sequence (score = 2, baseline)
- Smooth asymmetric sequences (e.g., `a[i] = 1/(1+i/α)` normalized)
- Sequences from the previous LP optimization
- Random smooth sequences (Gaussian-smoothed noise)

One more idea: **simulated annealing** on the sequence. At each step, randomly perturb a few elements and accept if it improves the objective (or with probability exp(-Δ/T) if it worsens it). This can escape local minima.

Let me write the final code:

```python
"""
Minimize 2n*max(conv(a,a))/(sum(a))^2 for non-negative sequences.
Uses FFT-accelerated smoothed subgradient descent with multi-start,
n-sweeping, and simulated annealing for escape from local minima.
"""

import numpy as np
import time
from scipy.fft import rfft, irfft


def compute_conv(a):
    """Full linear convolution a*a via FFT."""
    n = len(a)
    if n == 1:
        return np.array([a[0] * a[0]])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a = a / s
    conv = compute_conv(a)
    return 2.0 * n * float(np.max(conv))


def compute_gradient_smoothed(a, tau):
    """
    Compute gradient of smoothed max of conv(a,a) w.r.t. a.
    Uses softmax smoothing with temperature tau.
    Returns gradient vector of same length as a.
    """
    n = len(a)
    conv = compute_conv(a)
    
    # Softmax weights
    max_c = np.max(conv)
    w = np.exp((conv - max_c) / tau)
    w /= np.sum(w)
    
    # grad[i] = sum_k w[k] * d(conv[k])/da[i] = sum_k w[k] * a[k-i] (valid)
    # = sum_{j=0}^{n-1} a[j] * w[i+j]
    # = conv(a[::-1], w)[n-1+i]
    
    ar = a[::-1]
    size = 1
    while size < 2 * (2 * n - 1) - 1:
        size <<= 1
    far = np.fft.fft(ar, size)
    fw = np.fft.fft(w, size)
    conv_aw = np.fft.ifft(far * fw).real
    grad = conv_aw[n - 1:2 * n - 1]
    
    return grad


def subgradient_optimize(a, time_budget=60.0, verbose=False):
    """
    Smoothed subgradient descent for min max(conv(a,a)) s.t. sum(a)=1, a>=0.
    """
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return np.ones(n) / n
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    tau = 1.0 / (2 * n - 1)  # initial temperature
    lr = 0.01 / np.sqrt(n)
    patience = 0
    max_patience = 300
    
    for it in range(5000):
        if time.monotonic() - start > time_budget:
            break
        
        grad = compute_gradient_smoothed(a, tau)
        grad_centered = grad - np.mean(grad)
        
        a_new = a - lr * grad_centered
        a_new = np.maximum(a_new, 0)
        s_new = float(np.sum(a_new))
        if s_new < 1e-10:
            lr *= 0.5
            continue
        a_new = a_new / s_new
        
        obj_new = compute_obj(a_new)
        
        if obj_new < best_obj:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new
            patience = 0
            tau = max(tau * 0.999, 0.1 / (2 * n - 1))
            lr = min(lr * 1.01, 0.1)
        else:
            patience += 1
            if patience > max_patience:
                # Perturb and restart
                rng = np.random.default_rng((it * 127 + n) % (2**32))
                a = best_a * np.exp(rng.normal(0, 0.03, n))
                a = np.maximum(a, 0)
                a = a / np.sum(a)
                best_a = a.copy()
                best_obj = compute_obj(a)
                patience = 0
                lr = 0.01 / np.sqrt(n)
                tau = 1.0 / (2 * n - 1)
        
        if verbose and it % 200 == 0:
            print(f"    subgrad it{it}: obj={best_obj:.8f}, tau={tau:.6f}, lr={lr:.6f}")
    
    return best_a


def annealing_optimize(a, time_budget=60.0, verbose=False):
    """
    Simulated annealing: randomly perturb pairs of elements, accept/reject.
    """
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return np.ones(n) / n
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    T = best_obj * 0.01  # initial temperature
    T_min = best_obj * 1e-6
    
    rng = np.random.default_rng(42)
    
    while time.monotonic() - start < time_budget:
        # Pick two random positions to swap mass
        i, j = rng.integers(0, n, 2)
        if i == j:
            continue
        delta = rng.normal(0, 0.05 / np.sqrt(n))
        
        a_new = a.copy()
        a_new[i] += delta
        a_new[j] -= delta
        a_new = np.maximum(a_new, 0)
        s_new = float(np.sum(a_new))
        a_new
