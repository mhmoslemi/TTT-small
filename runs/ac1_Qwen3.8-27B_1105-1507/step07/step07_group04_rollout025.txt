= sum_i [δ(i,j) * a[k-i] + a[i] * δ(k-i, j)]
= a[k-j] (from first term, valid if 0 <= k-j < n)
+ a[k-j] (from second term, valid if k-j = i for some valid i, i.e., 0 <= k-j < n)
= 2*a[k-j] (if 0 <= k-j < n)
= 0 (otherwise)

Wait, but when k-j = j (i.e., k=2j), both terms give a[j], so the total is 2*a[j]. This is consistent with the formula above (2*a[k-j] when k=2j gives 2*a[j]).

So: [∇conv_k(a)]_j = 2*a[k-j] if 0 <= k-j < n, else 0.

This means the gradient can be computed as:
∇conv_k(a)[j] = 2*a[k-j] * 1[0 <= k-j < n]

For the full subgradient of the objective (with max):
∇f(a)[j] = 2n * sum_{k in K} α_k * 2*a[k-j] * 1[0 <= k-j < n]
= 4n * sum_{k in K} α_k * a[k-j] * 1[0 <= k-j < n]

This is a weighted sum of shifted versions of a! We can compute this efficiently.

For simplicity, if we use a uniform distribution over the top-m peaks:
∇f(a)[j] ≈ (4n/m) * sum_{k in top_m} a[k-j] * 1[0 <= k-j < n]

This is (4n/m) times a weighted "anti-convolution" of a with the indicator of the top peaks.

Wait, it's NOT convex because max(conv(a,a)) is not convex in a (it's a max of quadratic functions, each of which is not convex since a can be negative... but a >= 0, so actually each conv_k(a) = sum_i a[i]*a[k-i] is... hmm, it's a quadratic form. The Hessian of conv_k(a) is 2*C_k where (C_k)_{ij} = 1 if i+j=k (wait, that's not right either).

conv_k(a) = sum_i a[i]*a[k-i]
∂²/∂a[j]∂a[l] = δ(j,l+k-j) + δ(k-j,l) ... this is getting complicated.

Actually, conv_k(a) = a^T B_k a where B_k is a matrix with (B_k)_{i,j} = 1/2 if i+j=k (for the symmetric part). Wait no:
conv_k(a) = sum_i a[i] a[k-i]

This is NOT a standard quadratic form a^T M a because the indices don't match. Let me write it as:
conv_k(a) = sum_i a[i] a[k-i] = sum_{i+j=k} a[i] a[j]

This IS a quadratic form: conv_k(a) = a^T C_k a where (C_k)_{i,j} = 1 if i+j=k and i≠j, and (C_k)_{i,i} = 1 if 2i=k.

Wait: a^T C_k a = sum_{i,j} a[i] C_{i,j} a[j]
We want this to equal sum_{i+j=k} a[i] a[j].
So C_{i,j} = 1 if i+j=k, 0 otherwise.
But then a^T C_k a = sum_{i,j: i+j=k} a[i] a[j] = sum_i a[i] a[k-i]. ✓

The Hessian of conv_k(a) is C_k + C_k^T. Since C_k is symmetric (if i+j=k then j+i=k), the Hessian is 2*C_k.

C_k has entries 1 at positions (i, k-i) for valid i. This is a "skew" matrix. Its eigenvalues can be positive or negative, so conv_k(a) is not necessarily convex or concave.

Therefore, the problem min max_k conv_k(a) is NOT convex, and we can't use standard convex optimization. The LP alternating approach is a non-convex heuristic.

"""
Improved optimizer for minimizing 2*n*max(conv(a,a))/(sum(a))^2.
Uses enhanced LP alternating with warm-starting, subgradient polishing,
diverse restarts, and multi-n exploration.
"""

import numpy as np
from scipy.fft import rfft, irfft
from scipy.optimize import linprog
import cvxpy as cp
import time


def compute_conv(a):
    """FFT-based full linear convolution of a with itself."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute 2n*max(conv(a,a))/sum(a)^2."""
    n = len(a)
    s = float(np.sum(a))
    if s < 1e-10:
        return np.inf
    a = a / s
    conv = compute_conv(a)
    return 2.0 * n * float(np.max(conv))


def build_conv_matrix(a):
    """Build matrix A (2n-1 x n) such that A @ g = conv(a, g)."""
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        k_start = j
        k_end = min(2 * n - 2, j + n - 1)
        A[k_start:k_end + 1, j] = a[:k_end - k_start + 1]
    return A


def solve_lp(a, max_iters=None):
    """Solve: min M s.t. conv(a,g)[k] <= M for all k, sum(g)=1, g>=0.
    Returns (g_normalized, M_value) or (None, None)."""
    n = len(a)
    a = a / np.sum(a)
    A = build_conv_matrix(a)

    # Try cvxpy solvers in order of preference
    g = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [A @ g <= M, cp.sum(g) == 1]
    prob = cp.Problem(cp.Minimize(M), constraints)

    for solver in [cp.CLARABEL, cp.PDLP, cp.SCS, cp.ECOS]:
        try:
            t0 = time.monotonic()
            prob.solve(solver=solver)
            if time.monotonic() - t0 > 60:
                continue
            if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g.value, 0)
                gs = float(np.sum(g_val))
                if gs > 1e-10:
                    return g_val / gs, float(M.value)
        except Exception:
            continue

    # Fallback to scipy
    try:
        c = np.zeros(n + 1)
        c[-1] = 1.0
        A_ub = np.zeros((2 * n - 1, n + 1))
        A_ub[:, :n] = A
        A_ub[:, n] = -1.0
        b_ub = np.zeros(2 * n - 1)
        A_eq = np.ones((1, n + 1))
        b_eq = np.array([1.0])
        bounds = [(0, None)] * n + [(0, None)]
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs')
        if res.status == 0:
            g_val = np.maximum(res.x[:n], 0)
            gs = float(np.sum(g_val))
            if gs > 1e-10:
                return g_val / gs, float(res.x[n])
    except Exception:
        pass

    return None, None


def subgradient_step(a, top_k=20):
    """Compute subgradient of 2n*max(conv(a,a)) at a (sum(a)=1).
    Uses uniform weights over top-k peaks. Returns centered gradient."""
    n = len(a)
    conv = compute_conv(a)
    # Get top-k peak positions
    if top_k >= len(conv):
        k_indices = np.arange(len(conv))
    else:
        k_indices = np.argsort(conv)[::-1][:top_k]

    # Gradient: [grad]_j = 2n * (1/K) * sum_{k in K} 2*a[k-j] * 1[0<=k-j<n]
    #          = (4n/K) * sum_{k in K} a[k-j] * 1[0<=k-j<n]
    n_fft = 1
    while n_fft < 4 * n:
        n_fft <<= 1

    # Build weight vector w of length 2n-1
    w = np.zeros(2 * n - 1)
    for k in k_indices:
        w[int(k)] = 1.0 / len(k_indices)

    # Compute grad[j] = sum_k w[k] * a[k-j] for valid k-j
    # = cross-correlation approach
    A_fft = rfft(a, n_fft)
    W_fft = rfft(w, n_fft)
    # R_aw[l] = sum_m a[m] * w[m-l] => we want sum_m a[m] * w[m+j] = R_aw[n_fft - j]
    R = irfft(np.conj(A_fft) * W_fft, n_fft)
    grad = np.zeros(n)
    for j in range(n):
        grad[j] = R[(n_fft - j) % n_fft]

    grad *= 4.0 * n  # Scale factor
    # Center for simplex projection
    grad -= np.mean(grad)
    return grad


def subgradient_optimize(a, time_budget=60.0, top_k=20, verbose=False):
    """Nesterov-accelerated subgradient method."""
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64).copy()
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()

    momentum = np.zeros(n)
    beta = 0.9
    lr = 0.5 / n
    x = a.copy()  # Nesterov lookahead

    for it in range(50000):
        if time.monotonic() - start > time_budget:
            break

        grad = subgradient_step(x, top_k=top_k)
        momentum = beta * momentum - lr * grad
        a_new = a + momentum
        a_new = np.maximum(a_new, 0)
        s_new = float(np.sum(a_new))
        if s_new < 1e-10:
            a_new = a.copy()
        else:
            a_new = a_new / s_new

        # Nesterov update
        t_k = 2.0 / (it + 2.0)
        x = a_new + (1 - t_k) * (a_new - a)
        x = np.maximum(x, 0)
        sx = float(np.sum(x))
        if sx > 1e-10:
            x = x / sx

        a = a_new
        obj = compute_obj(a)
        if obj < best_obj - 1e-13:
            best_obj = obj
            best_a = a.copy()

        if it % 200 == 199:
            lr *= 0.98

        if verbose and it % 5000 == 0:
            print(f"    SubGrad: it={it}, obj={best_obj:.8f}")

    return best_a


def lp_alternate(a, time_budget=200.0, verbose=False):
    """LP alternating with adaptive blending and perturbation."""
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64).copy()
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    stall = 0

    while time.monotonic() - start < time_budget:
        g_lp, M_lp = solve_lp(a)
        if g_lp is None:
            break

        # Adaptive blending: try a range of t values
        best_local_obj = np.inf
        best_local_a = best_a.copy()
        best_t = 0.3

        t_values = [0.05, 0.1, 0.15, 0.2, 0.25, 0.3, 0.4, 0.5, 0.6, 0.7, 0.8, 1.0]
        for t in t_values:
            a_try = (1.0 - t) * a + t * g_lp
            a_try = np.maximum(a_try, 0)
            s_try = float(np.sum(a_try))
            if s_try < 1e-10:
                continue
            a_try = a_try / s_try
            obj_try = compute_obj(a_try)
            if obj_try < best_local_obj:
                best_local_obj = obj_try
                best_local_a = a_try.copy()
                best_t = t

        if best_local_obj < best_obj - 1e-12:
            best_obj = best_local_obj
            best_a = best_local_a.copy()
            a = best_a.copy()
            stall = 0
            if verbose:
                elapsed = time.monotonic() - start
                print(f"    LP: obj={best_obj:.8f}, t={best_t:.2f}, time={elapsed:.0f}s")
        else:
            stall += 1
            if stall > 8:
                # Structured perturbation
                rng = np.random.default_rng((n * 7919 + int(time.monotonic() * 10000)) % (2**31))
                scale = min(0.05 + 0.02 * (stall // 8), 0.3)
                a = best_a * np.exp(rng.normal(0, scale, n))
                a = np.maximum(a, 0)
                s = float(np.sum(a))
                if s > 1e-10:
                    a = a / s
                    obj_p = compute_obj(a)
                    if obj_p < best_obj:
                        best_obj = obj_p
                        best_a = a.copy()
                stall = 0

    return best_a


def resample_seq(a, new_n):
    """Resample sequence to new length via linear interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, a[0])
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)


def diverse_initialization(n, rng):
    """Generate a diverse structured initialization."""
    choice = rng.integers(0, 5)
    if choice == 0:
        # Smooth bump
        x = np.linspace(0, 1, n)
        a = np.exp(-50 * (x - 0.5) ** 2)
    elif choice == 1:
        # Oscillatory
        x = np.linspace(0, 1, n)
        a = 0.5 + 0.5 * np.cos(2 * np.pi * 3 * x)
    elif choice == 2:
        # Two bumps
        x = np.linspace(0, 1, n)
        a = np.exp(-80 * (x - 0.3) ** 2) + np.exp(-80 * (x - 0.7) ** 2)
    elif choice == 3:
        # Random smooth
        a = np.ones(n)
        for _ in range(3):
            center = rng.integers(0, n)
            width = rng.integers(n // 10, n // 3)
            for i in range(n):
                d = min(abs(i - center), n - abs(i - center))
                a[i] *= 1.0 + rng.standard_normal() * np.exp(-d / (width * 0.5))
        a = np.maximum(a, 0.01)
    else:
        # Power law
        x = np.linspace(0.01, 1, n)
        a = x ** rng.uniform(0.5, 3.0)
    a = np.maximum(a, 0)
    s = float(np.sum(a))
    if s < 1e-10:
        a = np.ones(n) / n
    else:
        a = a / s
    return a
