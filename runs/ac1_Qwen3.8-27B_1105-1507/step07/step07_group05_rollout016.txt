Actually, let me reconsider the problem from scratch. We want to minimize:
2 * n * max_k (a*a)[k] / (sum a)^2

Let's normalize: let c = a / sum(a), so sum(c) = 1. Then:
Objective = 2 * n * max_k (c*c)[k]

where (c*c)[k] = sum_{i: 0<=i<n, 0<=k-i<n} c[i]*c[k-i]

Note that (c*c)[k] >= 0 for all k (since c >= 0).
Also, sum_k (c*c)[k] = (sum c)^2 = 1.

So we're distributing 1 unit of "mass" across 2n-1 bins (the convolution values), and we want the maximum bin to be as small as possible. The theoretical minimum for the max is 1/(2n-1) (perfectly uniform distribution), giving an objective of 2n/(2n-1) ≈ 1 for large n.

But we have the constraint that the convolution values must come from a valid non-negative sequence c. Not every distribution of mass across 2n-1 bins is achievable.

For the uniform c (all 1/n), the convolution is triangular: (c*c)[k] = (n-|k-(n-1)|)/n^2 for |k-(n-1)| < n. The max is 1/n at k=n-1.

To do better, we need a c that makes the convolution more uniform. This is like designing a "flat" autocorrelation, which is a well-studied problem in radar and communications.

For the continuous analog, the optimal is related to "flat-top" spectra. For discrete sequences, we can use:
- Costas arrays (for binary sequences)
- Zadoff-Chu sequences (for complex sequences)
- For non-negative real sequences, it's more constrained

I think the key insight is that for non-negative sequences, the best we can do is related to spreading the "mass" in a way that the autocorrelation approximates a flat profile. The U-shaped or W-shaped sequences might be good starting points.

import numpy as np

def compute_conv(a):
    """Full linear convolution a*a via FFT."""
    n = len(a)
    N = 1
    while N < 2 * n - 1:
        N <<= 1
    fa = rfft(a, N)
    return irfft(fa * fa, N)[:2 * n - 1]


def compute_obj(a):
    """Compute objective value."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    b = compute_conv(a_norm)
    return 2.0 * n * float(np.max(b))


def compute_obj_from_conv(a, b):
    """Compute objective given normalized a and its convolution b."""
    n = len(a)
    return 2.0 * n * float(np.max(b))
