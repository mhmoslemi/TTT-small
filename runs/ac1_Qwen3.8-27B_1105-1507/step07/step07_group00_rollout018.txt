3. Compute the target: c_target = ones(2n-1) / (2n-1) (normalized so sum = 1).

- Or: project onto the set {a : (a*a)[k] <= M for all k} for some M, then adjust M

finds the best "direction" g to move towards, given the current a. Then we do a line search.
