Actually, let me think about this problem more carefully from a theoretical standpoint.

The problem is: minimize max_k (a*a)[k] subject to a >= 0, sum(a) = 1 (WLOG, since the objective is homogeneous of degree 0).

The objective becomes: 2*n*max_k (a*a)[k].

Now, (a*a)[k] = sum_i a[i]*a[k-i]. This is a quadratic form. The constraint max_k (a*a)[k] <= M is equivalent to (a*a)[k] <= M for all k.

This is a non-convex problem (minimizing the max of quadratic functions), but we can use a bisection approach: for a given M, check if there exists a >= 0, sum(a) = 1 such that (a*a)[k] <= M for all k. This is checking feasibility of a system of quadratic inequalities, which is NP-hard in general.

However, the alternating approach (fixing one variable and optimizing the other) turns it into a convex problem at each step:
- Fix a, optimize g: min M s.t. (a*g)[k] <= M for all k, sum(g) = 1, g >= 0. This is an LP!
- Fix g, optimize a: same thing.

This is why the LP alternating approach works well.
