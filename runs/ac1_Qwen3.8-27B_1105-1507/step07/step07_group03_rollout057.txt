def compute_conv(a):
    n = len(a)
    size = 1
    while size < 2*n - 1:
        size <<= 1
    A = fft(a, size)
    return ifft(A * A).real[:2*n-1]

def compute_obj(a):
    n = len(a)
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_n = a / s
    conv = compute_conv(a_n)
    return 2.0 * n * float(np.max(conv))

def softmax_grad_conv(a, T=100):
    """Compute gradient of softmax-T * max(conv(a,a)). Returns (grad, conv, obj_soft)."""
    n = len(a)

Actually, let me reconsider the problem from scratch. The key insight I want to exploit:

The objective `2n * max(conv(a,a)) / (sum(a))^2` is minimized when `max(conv(a,a))` is as small as possible (relative to the sum).

For a sequence of length n with sum=1:
- The convolution has 2n-1 elements
- The sum of all convolution elements = (sum(a))^2 = 1
- So the average convolution element = 1/(2n-1)
- The max must be at least 1/(2n-1)

So the minimum possible objective is at least `2n / (2n-1) ≈ 1` for large n.

But we have additional constraints from non-negativity. The center of the convolution is `sum_i a[i]*a[n-1-i]`, and the edges are `a[0]^2` and `a[n-1]^2`.

For a "good" sequence, all convolution elements should be close to `1/(2n-1)`. This means:
- `a[0]^2 ≈ 1/(2n-1)` → `a[0] ≈ 1/sqrt(2n-1)`
- Similarly `a[n-1] ≈ 1/sqrt(2n-1)`
- The center `sum_i a[i]*a[n-1-i] ≈ 1/(2n-1)`

For the center to be this small while the sum is 1, the sequence must be very "spread out" AND non-symmetric.

This gives us a target: each element should be approximately `1/sqrt(2n-1)` (which is larger than `1/n` for large n). So the sequence should be more "spread" than uniform.

Wait, that doesn't make sense. If each element is `1/sqrt(2n-1)`, the sum would be `n/sqrt(2n-1) ≈ sqrt(n/2)`, which is much larger than 1. So we'd need to normalize.

Let me reconsider. If we want `conv(a,a)[k] ≈ 1/(2n-1)` for all k, and `sum(a) = 1`:

But we need `sum(a) = 1`. If all elements were `1/sqrt(2n-1)`, the sum would be `n/sqrt(2n-1) ≈ sqrt(n/2)`. To make the sum 1, we'd scale by `1/sqrt(n/2)`, giving each element `sqrt(2/n)/sqrt(2n-1) ≈ 1/n`.
