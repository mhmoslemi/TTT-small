Actually, one more thought: the LP approach is:
Given a, find g that minimizes max_k conv(a,g)[k] s.t. sum(g)=1, g>=0.

The optimal g will have the property that conv(a,g) is "flat" at the peak (multiple constraints are active). This is similar to the "minimax" approach in game theory.

A cleaner formulation: we want to find a and g simultaneously such that:
- max_k conv(a,a)[k] is minimized
- a is on the simplex

This is a bilinear optimization problem (non-convex). The alternating minimization (fix a, optimize g; fix g, optimize a) is a natural approach, and the LP is the "optimize g" step.

For the "optimize a" step (fix g, optimize a), we'd need to solve:
min max_k conv(a,g)[k] s.t. sum(a)=1, a>=0

But conv(a,g)[k] is LINEAR in a (for fixed g)! So this is also an LP:
min M
s.t. sum_i a[i]*g[k-i] <= M for all k (where g[k-i] is 0 if k-i out of range)
     sum(a) = 1
     a >= 0

So both steps are LPs! The alternating LP method should converge to a local minimum of the bilinear problem.

This is a great structure. Let me implement this carefully.

For the LP:
- Variables: a[0], ..., a[n-1], M (n+1 variables)
- Constraints: 
  - For each k in 0..2n-2: sum_{i} a[i] * g[k-i] <= M (2n-1 constraints)
  - sum(a) = 1 (1 constraint)
  - a[i] >= 0 (n constraints, handled by variable bounds)

Total: n+1 variables, 2n constraints (2n-1 inequality + 1 equality).

For n=800: 801 variables, 1600 constraints. This should be very fast with a modern LP solver.

```python
import numpy as np
import cvxpy as cp
from scipy.fft import rfft, irfft
import time

def compute_conv(a, b=None):
    """Compute linear convolution a*b (or a*a if b is None) via FFT."""
    if b is None:
        b = a
    n = len(a)
    m = len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = rfft(a, size)
    fb = rfft(b, size)
    return irfft(fa * fb, size)[:n + m - 1]

def compute_obj(a):
    """Compute 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    conv = compute_conv(a)
    return 2.0 * n * float(np.max(conv)) / (s * s)

def compute_obj_normalized(a):
    """Compute objective assuming sum(a)=1: 2*n*max(conv(a,a))."""
    n = len(a)
    conv = compute_conv(a)
    return 2.0 * n * float(np.max(conv))

def solve_lp_for_g(a, solver_hint=None):
    """
    Given a (sum=1), solve:
    min M s.t. conv(a, g)[k] <= M for all k, sum(g)=1, g>=0
    Returns g (sum=1) or None.
    """
    n = len(a)
    # Build constraint matrix: A[k, i] = a[k-i] if valid
    # conv(a,g)[k] = sum_i a[valid_i] * g[k-valid_i]
    # Actually: conv(a,g)[k] = sum_i a[i]*g[k-i] where 0<=i<n, 0<=k-i<n
    # So for fixed k: sum over i of a[i]*g[k-i]
    # Let j = k-i, so i = k-j: sum over j of a[k-j]*g[j]
    # Where 0<=j<n and 0<=k-j<n, i.e., max(0,k-n+1) <= j <= min(n-1, k)
    
    # The constraint matrix C has C[k,j] = a[k-j] if 0<=k-j<n, else 0
    # So C is a Toeplitz-like matrix with C[k,j] = a[k-j]
    
    # Build it as a sparse matrix
    from scipy.sparse import csr_matrix
    rows = []
    cols = []
    vals = []
    for k in range(2*n-1):
        j_start = max(0, k-(n-1))
        j_end = min(n-1, k)
        for j in range(j_start, j_end+1):
            rows.append(k)
            cols.append(j)
            vals.append(a[k-j])
    
    C = csr_matrix((vals, (rows, cols)), shape=(2*n-1, n))
    
    g = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [C @ g <= M, cp.sum(g) == 1]
    prob = cp.Problem(cp.Minimize(M), constraints)
    
    solvers = [cp.MOSEK, cp.CLARABEL, cp.SCS, cp.ECOS]
    if solver_hint:
        solvers = [solver_hint] + [s for s in solvers if s != solver_hint]
    
    for solver in solvers:
        try:
            prob.solve(solver=solver, verbose=False)
            if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g.value, 0)
                s = float(np.sum(g_val))
                if s > 1e-10:
                    return g_val / s, float(M.value)
        except Exception:
            continue
    
    return None, None

def solve_lp_for_a(g):
    """
    Given g (sum=1), solve:
    min M s.t. conv(a, g)[k] <= M for all k, sum(a)=1, a>=0
    Returns a (sum=1) or None.
    By symmetry, this is the same as solve_lp_for_g(g).
    """
    return solve_lp_for_g(g)
```

Wait, solve_lp_for_a(g) is the same as solve_lp_for_g(g) because conv(a,g) is the same form as conv(g,a) (just reversed). Actually no, conv(a,g) is not the same as conv(g,a) in general - they are reverses of each other. But the max is the same: max_k conv(a,g)[k] = max_k conv(g,a)[k]. So yes, solving for a given g is the same LP as solving for g given a (just with the roles swapped, and since the LP is min M s.t. C@x <= M, sum(x)=1, x>=0, the structure is the same).

Actually wait, it's not exactly the same LP. In solve_lp_for_g(a), the constraint matrix has entries C[k,j] = a[k-j]. In solve_lp_for_a(g), the constraint matrix has entries C'[k,i] = g[k-i]. These are different matrices (one uses a, the other uses g). But they have the same structure (both are "reversed Toeplitz" type).

So I can use the same function: solve_lp_for_x(fixed_sequence) returns the optimal x.

Now, the alternating method is:
1. Start with a_0 (sum=1)
2. g_{k+1} = solve_lp_for_g(a_k)
3. a_{k+1} = solve_lp_for_a(g_{k+1})
4. Repeat

This is like a "best response" iteration in a zero-sum game. It should converge to a local Nash equilibrium.

The question is: how fast does it converge, and does it get stuck in bad local minima?

To prevent getting stuck:
- After each iteration, check if the objective improved
- If stalled, perturb the current solution
- Use a "soft" version: instead of taking the full LP solution, take a step: a_new = (1-t)*a + t*a_lp

Let me now think about the implementation details for speed:

For n=800, the LP has 1599 constraints and 801 variables. With MOSEK, this should take maybe 10-50ms per solve. That's fast enough for thousands of iterations.

But building the sparse matrix each time takes O(n^2) = 640K operations, which is also fine.

Let me estimate: if each LP iteration takes 50ms, in 100 seconds we can do 2000 iterations. That should be enough for convergence.

Now let me think about what specific improvements could beat 1.506:

1. **Better convergence of alternating LP**: The key issue is that the alternating LP might oscillate. Using a damping factor (interpolation) can help.

2. **Multi-peak awareness**: Instead of just minimizing the single peak, we could add penalties for the top-K peaks to create a "flatter" convolution profile.

3. **Asymmetric exploration**: Since the solution must be asymmetric, we should ensure our search doesn't get pulled toward symmetry.

4. **n optimization**: The factor n in the objective means that for a given "shape quality", shorter sequences are preferred. But shorter sequences have fewer degrees of freedom. There's a sweet spot.

```python
"""
Hybrid alternating LP + subgradient optimization for minimizing
2*n*max(conv(a,a))/(sum(a))^2.
Key insight: optimal solutions are asymmetric; symmetric solutions have lower bound 2.
Uses alternating LP (both directions), top-K subgradient, and multi-n exploration.
"""

import numpy as np
import cvxpy as cp
from scipy.fft import rfft, irfft
from scipy.sparse import csr_matrix
import time

def compute_conv(a, b=None):
    if b is None:
        b = a
    n = len(a)
    m = len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = rfft(a, size)
    fb = rfft(b, size)
    return irfft(fa * fb, size)[:n + m - 1]

def compute_obj(a):
    n = len(a)
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    conv = compute_conv(a)
    return 2.0 * n * float(np.max(conv)) / (s * s)

def build_conv_matrix(fixed):
    """Build sparse matrix C where C @ x = conv(fixed, x)."""
    n = len(fixed)
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        j_start = max(0, k - (n - 1))
        j_end = min(n - 1, k)
        for j in range(j_start, j_end + 1):
            rows.append(k)
            cols.append(j)
            vals.append(fixed[k - j])
    return csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))

def solve_lp(fixed, solver_list=None):
    """
    Given 'fixed' (sum=1), solve:
    min M s.t. conv(fixed, x)[k] <= M for all k, sum(x)=1, x>=0
    Returns (x_normalized, M_opt) or (None, None).
    """
    n = len(fixed)
    C = build_conv_matrix(fixed)
    
    x = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [C @ x <= M, cp.sum(x) == 1]
    prob = cp.Problem(cp.Minimize(M), constraints)
    
    if solver_list is None:
        solver_list = [cp.MOSEK, cp.CLARABEL, cp.SCS]
    
    for solver in solver_list:
        try:
            prob.solve(solver=solver, verbose=False)
            if x.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                x_val = np.maximum(x.value, 0)
                s = float(np.sum(x_val))
                if s > 1e-10:
                    return x_val / s, float(M.value)
        except Exception:
            continue
    return None, None

def alternating_lp(a, time_budget=300.0, damping=1.0, verbose=False):
    """
    Alternating LP optimization.
    a: initial sequence (will be normalized to sum 1)
    Returns best sequence found.
    """
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    stall = 0
    consecutive_no_improve = 0
    
    while time.monotonic() - start < time_budget:
        # Step 1: Find optimal g given a
        g, M_g = solve_lp(a)
        if g is None:
            break
        
        # Step 2: Find optimal a_new given g
        a_lp, M_a = solve_lp(g)
        if a_lp is None:
            break
        
        # Apply damping
        a_try = (1.0 - damping) * a + damping * a_lp
        a_try = np.maximum(a_try, 0)
        s_try = float(np.sum(a_try))
        if s_try < 1e-10:
            break
        a_try = a_try / s_try
        
        obj_try = compute_obj(a_try)
        
        if obj_try < best_obj - 1e-10:
            best_obj = obj_try
            best_a = a_try.copy()
            a = a_try.copy()
            stall = 0
            consecutive_no_improve = 0
            if verbose:
                elapsed = time.monotonic() - start
                print(f"    ALT-LP: obj={best_obj:.8f}, M_g={M_g:.6f}, M_a={M_a:.6f}, t={elapsed:.1f}s")
        else:
            consecutive_no_improve += 1
            # Try with less damping
            if consecutive_no_improve % 10 == 0:
                for d in [0.5, 0.3, 0.1]:
                    a_try2 = (1.0 - d) * a + d * a_lp
                    a_try2 = np.maximum(a_try2, 0)
                    a_try2 = a_try2 / a_try2.sum()
                    obj_try2 = compute_obj(a_try2)
                    if obj_try2 < best_obj - 1e-10:
                        best_obj = obj_try2
                        best_a = a_try2.copy()
                        a = a_try2.copy()
                        consecutive_no_improve = 0
                        break
            if consecutive_no_improve > 50:
                # Perturb
                rng = np.random.default_rng(int(time.monotonic() * 1000) % (2**31))
                scale = min(0.3, 0.05 + 0.01 * (consecutive_no_improve // 50))
                a = best_a * np.exp(rng.normal(0, scale, n))
                a = np.maximum(a, 0)
                a = a / a.sum()
                best_a = a.copy()
                best_obj = compute_obj(a)
                consecutive_no_improve = 0
                stall = 0
    
    return best_a

def subgradient_optimize(a, time_budget=100.0, K=5, verbose=False):
    """
    Subgradient descent with top-K peaks, momentum, and adaptive step size.
    """
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    v = np.zeros(n)  # momentum
    momentum = 0.4
    step = 0.1 / np.sqrt(n)
    stall = 0
    
    it = 0
    while time.monotonic() - start < time_budget:
        # Compute top-K peaks
        conv = compute_conv(a)
        top_idx = np.argsort(conv)[::-1][:K]
        max_val = conv[top_idx[0]]
        if max_val < 1e-15:
            break
        
        # Softmax-weighted subgradient
        temps = conv[top_idx] - max_val
        weights = np.exp(temps / (0.1 * max_val))
        weights /= weights.sum()
        
        g = np.zeros(n)
        for w, k in zip(weights, top_idx):
            k = int(k)
            i_start = max(0, k - (n - 1))
            i_end = min(n - 1, k)
            if i_start <= i_end:
                j_start = k - i_end
                j_end = k - i_start
                g[i_start:i_end+1] += 2 * w * a[j_start:j_end+1][::-1]
        
        # Momentum update
        v = momentum * v + g
        norm_v = np.linalg.norm(v)
        if norm_v > 1e-15:
            v = v / norm_v  # normalize to unit step
        
        # Step with projection onto simplex
        a_try = a - step * v
        # Project onto simplex {x >= 0, sum(x) = 1}
        a_try = project_simplex(a_try)
        
        obj_try = compute_obj(a_try)
        if obj_try < best_obj - 1e-12:
            best_obj = obj_try
            best_a = a_try.copy()
            a = a_try.copy()
            stall = 0
            step = min(0.5, step * 1.01)  # slightly increase
        else:
            stall += 1
            if stall > 50:
                # Backtrack
                step *= 0.5
                if step < 1e-6 / np.sqrt(n):
                    # Perturb
                    rng = np.random.default_rng(it * 7919 + n)
                    a = best_a * np.exp(rng.normal(0, 0.1, n))
                    a = np.maximum(a, 0)
                    a = a / a.sum()
                    best_a = a.copy()
                    best_obj = compute_obj(a)
                    v = np.zeros(n)
                    step = 0.1 / np.sqrt(n)
                    stall = 0
            else:
                step *= 0.95
        
        it += 1
    
    return best_a

def project_simplex(v):
    """Project v onto {x >= 0, sum(x) = 1}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    idx = np.arange(1, n + 1)
    cond = u * idx > (cssv - 1.0)
    rho = np.where(cond)[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def resample(a, new_n):
    """Resample sequence to new length."""
    n = len(a)
    if n == new_n:
        return a.copy()
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)

def diverse_init(n, rng, mode=0):
    """Generate diverse asymmetric initializations."""
    x = np.arange(n)
    if mode == 0:
        # Shifted Gaussian
        center = n * rng.uniform(0.3, 0.7)
        width = n * rng.uniform(0.1, 0.3)
        a = np.exp(-((x - center)**2) / (2 * width**2))
    elif mode == 1:
        # Asymmetric triangular
        center = n * rng.uniform(0.35, 0.65)
        a = np.maximum(0, 1 - np.abs(x - center) / (n * 0.4))
    elif mode == 2:
        # Exponential ramp
        rate = rng.uniform(0.5, 2.0)
        a = np.exp(-rate * x / n)
    elif mode == 3:
        # Two bumps (asymmetric)
        c1 = n * rng.uniform(0.2, 0.4)
        c2 = n * rng.uniform(0.6, 0.8)
        w = n * rng.uniform(0.05, 0.15)
        a = np.exp(-((x-c1)**2)/(2*w**2)) + 0.7*np.exp(-((x-c2)**2)/(2*w**2))
    elif mode == 4:
        # Raised cosine (shifted)
        center = n * rng.uniform(0.3, 0.7)
        width = n * rng.uniform(0.2, 0.4)
        t = (x - center) / width
        a = np.maximum(0, 0.5 * (1 + np.cos(np.pi * t))) ** 2
    elif mode == 5:
        # Random smooth
        freqs = rng.integers(1, 5, size=4)
        phases = rng.uniform(0, 2*np.pi, size=4)
        coeffs = rng.uniform(0.1, 0.5, size=4)
        a = np.ones(n)
        for f, p, c in zip(freqs, phases, coeffs):
            a += c * np.sin(2*np.pi*f*x/n + p)
        a = np.maximum(a, 0.01)
    else:
        # Uniform
        a = np.ones(n)
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-10:
        a = np.ones(n)
    else:
        a = a / s
    return a
```

```python
"""
Hybrid alternating LP + subgradient optimization for minimizing
2*n*max(conv(a,a))/(sum(a))^2.
Key insight: optimal solutions must be asymmetric (symmetric solutions have lower bound 2).
Uses alternating LP (both directions are LPs), top-K subgradient with momentum,
coordinate refinement, and multi-n exploration.
"""

import numpy as np
import cvxpy as cp
from scipy.fft import rfft, irfft
from scipy.sparse import csr_matrix
import time


def compute_conv(a, b=None):
    """Compute linear convolution a*b via FFT."""
    if b is None:
        b = a
    n = len(a)
    m = len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = rfft(a, size)
    fb = rfft(b, size)
    return irfft(fa * fb, size)[:n + m - 1]


def compute_obj(a):
    """Compute 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    conv = compute_conv(a)
    return 2.0 * n * float(np.max(conv)) / (s * s)


def build_conv_matrix(fixed):
    """Build sparse matrix C (2n-1 x n) where C @ x = conv(fixed, x)."""
    n = len(fixed)
    rows = np.zeros(n * n, dtype=np.int32)
    cols = np.zeros(n * n, dtype=np.int32)
    vals = np.zeros(n * n, dtype=np.float64)
    idx = 0
    for k in range(2 * n - 1):
        j_start = max(0, k - (n - 1))
        j_end = min(n - 1, k)
        for j in range(j_start, j_end + 1):
            rows[idx] = k
            cols[idx] = j
            vals[idx] = fixed[k - j]
            idx += 1
    rows = rows[:idx]
    cols = cols[:idx]
    vals = vals[:idx]
    return csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))


def solve_lp_cvxpy(fixed):
    """Solve LP via cvxpy: min M s.t. conv(fixed,x)[k]<=M, sum(x)=1, x>=0."""
    n = len(fixed)
    C = build_conv_matrix(fixed)
    x = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [C @ x <= M, cp.sum(x) == 1]
    prob = cp.Problem(cp.Minimize(M), constraints)
    solvers = [cp.MOSEK, cp.CLARABEL, cp.SCS, cp.ECOS]
    for solver in solvers:
        try:
            prob.solve(solver=solver, verbose=False)
            if x.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                x_val = np.maximum(x.value, 0)
                s = float(np.sum(x_val))
                if s > 1e-10:
                    return x_val / s, float(M.value)
        except Exception:
            continue
    return None, None


def solve_lp_scipy(fixed):
    """Fallback LP via scipy linprog (HiGHS)."""
    n = len(fixed)
    C = build_conv_matrix(fixed)
    C_dense = C.toarray()
    # Variables: x[0..n-1], M
    # Minimize M -> c = [0,...,0, 1]
    c = np.zeros(n + 1)
    c[-1] = 1.0
    # Inequality: C@x - M <= 0 for each row
    A_ub = np.zeros((2 * n - 1, n + 1))
    A_ub[:, :n] = C_dense
    A_ub[:, n] = -1.0
    b_ub = np.zeros(2 * n - 1)
    # Equality: sum(x) = 1
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([1.0])
    bounds = [(0, None)] * n + [(0, None)]
    from scipy.optimize import linprog
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                  bounds=bounds, method='highs')
    if res.status == 0:
        x_val = np.maximum(res.x[:n], 0)
        s = float(np.sum(x_val))
        if s > 1e-10:
            return x_val / s, float(res.x[n])
    return None, None


def solve_lp(fixed):
    """Solve LP, trying cvxpy first then scipy."""
    result = solve_lp_cvxpy(fixed)
    if result[0] is not None:
        return result
    return solve_lp_scipy(fixed)


def project_simplex(v):
    """Project v onto {x >= 0, sum(x) = 1}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    idx = np.arange(1, n + 1)
    cond = u * idx > (cssv - 1.0)
    rho = np.where(cond)[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def alternating_lp(a, time_budget=300.0, damping=1.0, verbose=False):
    """Alternating LP: fix a, optimize g; fix g, optimize a; repeat."""
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    stall = 0
    it = 0

    while time.monotonic() - start < time_budget:
        # Solve for g given a
        g, M_g = solve_lp(a)
        if g is None:
            break

        # Solve for a_new given g
        a_lp, M_a = solve_lp(g)
        if a_lp is None:
            break

        # Try multiple damping values
        found_improve = False
        for d in [damping, 0.5, 0.3, 1.0, 0.7]:
            if d <= 0 or d > 1:
                continue
            a_try = (1.0 - d) * a + d * a_lp
            a_try = np.maximum(a_try, 0)
            s_try = float(np.sum(a_try))
            if s_try < 1e-10:
                continue
            a_try = a_try / s_try
            obj_try = compute_obj(a_try)
            if obj_try < best_obj - 1e-12:
                best_obj = obj_try
                best_a = a_try.copy()
                a = a_try.copy()
                stall = 0
                found_improve = True
                if verbose and it % 50 == 0:
                    elapsed = time.monotonic() - start
                    print(f"    ALT-LP it{it}: obj={best_obj:.8f}, d={d:.2f}, t={elapsed:.1f}s")
                break

        if not found_improve:
            stall += 1
            if stall > 30:

                rng_local = np.random.default_rng(it * 2654435761 + n)
                scale = min(0.25, 0.03 + 0.01 * (stall // 30))
                a = best_a * np.exp(rng_local.normal(0, scale, n))
                a = np.maximum(a, 0)

                best_a = a.copy()
                best_obj = compute_obj(a)

def subgradient_optimize(a, time_budget=100.0, K=5, verbose=False):
    """Subgradient descent with top-K peaks, momentum, adaptive step."""
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()

    v = np.zeros(n)
    momentum = 0.5
    step = 0.05 / np.sqrt(n)
    stall = 0
    it = 0

    while time.monotonic() - start < time_budget:
        conv = compute_conv(a)
        top_idx = np.argsort(conv)[::-1][:K]
        max_val = conv[top_idx[0]]
        if max_val < 1e-15:
            break

        # Softmax-weighted subgradient
        temps = (conv[top_idx] - max_val) / (0.05 * max_val + 1e-15)
        weights = np.exp(temps)
        weights /= weights.sum()

        g = np.zeros(n)
        for w, k in zip(weights, top_idx):
            k = int(k)
            i_start = max(0, k - (n - 1))
            i_end = min(n - 1, k)
            if i_start <= i_end:
                j_start = k - i_end
                j_end = k - i_start
                g[i_start:i_end + 1] += 2.0 * w * a[j_start:j_end + 1][::-1]

        # Momentum
        v = momentum * v + g
        vn = np.linalg.norm(v)
        if vn > 1e-15:
            v = v / vn

        a_try = a - step * v
        a_try = project_simplex(a_try)
        obj_try = compute_obj(a_try)

        if obj_try < best_obj - 1e-12:
            best_obj = obj_try
            best_a = a_try.copy()
            a = a_try.copy()
            stall = 0
            step = min(0.3, step * 1.005)
            momentum = min(0.7, momentum + 0.001)
        else:
            stall += 1
            step *= 0.97
            if stall > 100:
                rng_local = np.random.default_rng(it * 104729 + n)
                a = best_a * np.exp(rng_local.normal(0, 0.08, n))
                a = np.maximum(a, 0)
                a = a / a.sum()
                best_a = a.copy()
                best_obj = compute_obj(a)
                v = np.zeros(n)
                step = 0.05 / np.sqrt(n)
                momentum = 0.4
                stall = 0

        it += 1

    return best_a


def coordinate_refine(a, time_budget=30.0):
    """Paired coordinate descent: transfer mass to reduce peak."""
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    conv = compute_conv(a)

    while time.monotonic() - start < time_budget:
        k_star = int(np.argmax(conv))
        improved = False

        # Find contributors to peak
        contribs = []
        for i in range(n):
            j = k_star - i
            if 0 <= j < n:
                contribs.append((a[i] * a[j], i, j))
        contribs.sort(reverse=True)

        # Non-contributors
        contrib_set = set()
        for _, i, j in contribs:
            contrib_set.add(i)
            contrib_set.add(j)
        non_contrib = [x for x in range(n) if x not in contrib_set]

        if not non_contrib:
            break

        for cval, i, j in contribs[:15]:
            if time.monotonic() - start > time_budget:
                break
            if cval < 1e-10:
                break
            for target in non_contrib[:5]:
                for frac in [0.05, 0.1, 0.2, 0.3]:
                    delta = frac * a[i]
                    if a[i] - delta < 0:
                        continue
                    a[i] -= delta
                    a[target] += delta
                    new_conv = compute_conv(a)
                    new_obj = 2.0 * n * float(np.max(new_conv))
                    if new_obj < best_obj - 1e-12:
                        best_obj = new_obj
                        best_a = a.copy()
                        conv = new_conv
                        improved = True
                        break
                    else:
                        a[i] += delta
                        a[target] -= delta
                        break

        if not improved:
            break

    return best_a


def resample(a, new_n):
    """Resample sequence to new length via linear interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, a[0])
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)


def diverse_init(n, rng, mode=0):
    """Generate diverse asymmetric initializations."""
    x = np.arange(n, dtype=np.float64)
    if mode == 0:
        center = n * rng.uniform(0.3, 0.6)
        width = n * rng.uniform(0.12, 0.25)
        a = np.exp(-((x - center) ** 2) / (2 * width ** 2))
    elif mode == 1:
        center = n * rng.uniform(0.35, 0.6)
        a = np.maximum(0.0, 1.0 - np.abs(x - center) / (n * 0.35))
    elif mode == 2:
        rate = rng.uniform(0.8, 2.5)
        a = np.exp(-rate * x / n) + 0.3 * np.exp(-rate * (n - 1 - x) / n)
    elif mode == 3:
        c1 = n * rng.uniform(0.2, 0.35)
        c2 = n * rng.uniform(0.55, 0.75)
        w = n * rng.uniform(0.06, 0.12)
        a = np.exp(-((x - c1) ** 2) / (2 * w ** 2)) + 0.8 * np.exp(-((x - c2) ** 2) / (2 * w ** 2))
    elif mode == 4:
        center = n * rng.uniform(0.3, 0.6)
        width = n * rng.uniform(0.15, 0.3)
        t = (x - center) / (width + 1)
        a = np.maximum(0.0, 0.5 * (1 + np.cos(np.pi * t))) ** 2
    elif mode == 5:
        freqs = rng.integers(1, 5, size=3)
        phases = rng.uniform(0, 2 * np.pi, size=3)
        coeffs = rng.uniform(0.1, 0.4, size=3)
        a = np.ones(n)
        for f, p, c in zip(freqs, phases, coeffs):
            a += c * np.sin(2 * np.pi * f * x / n + p)
        a = np.maximum(a, 0.01)
    else:
        # Power-law (heavy tail on one side)
        alpha = rng.uniform(1.5, 4.0)
        a = (x + 1) ** (-alpha)
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-10:
        a = np.ones(n)
    else:
        a = a / s
    return a


def propose_candidate(seed=42, budget_s=1500):
    """
    Main search: alternating LP + subgradient + coordinate refine + multi-n.
    """
    start_time = time.monotonic()
    deadline = start_time + float(budget_s) - 15.0

    rng = np.random.default_rng(seed)
    best_seq = None
    best_score = np.inf

    # Load parent
    try:
        parent_arr = np.asarray(height_sequence_1, dtype=np.float64)
        parent_arr = np.clip(parent_arr, 0, None)
        if parent_arr.size > 0 and np.isfinite(parent_arr).all():
            s = float(np.sum(parent_arr))
            if s > 0.01:
                best_seq = parent_arr / s
                best_score = compute_obj(best_seq)
                print(f"Parent (n={parent_arr.size}): obj={best_score:.8f}")
    except Exception:
        pass

    if best_seq is None:
        best_seq = diverse_init(800, rng, mode=0)
        best_score = compute_obj(best_seq)
        print(f"Init (n=800): obj={best_score:.8f}")

    n_current = len(best_seq)

    # Phase 1: Alternating LP (primary)
    print(f"\n=== Phase 1: Alternating LP (n={n_current}) ===")
    remaining = deadline - time.monotonic()
    p1 = min(remaining * 0.33, 400.0)
    if p1 > 30:
        a_opt = alternating_lp(best_seq, time_budget=p1, damping=1.0, verbose=True)
        obj_opt = compute_obj(a_opt)
        if obj_opt < best_score:
            best_score = obj_opt
            best_seq = a_opt.copy()
            print(f"  P1 done: obj={best_score:.8f} **")
        else:
            print(f"  P1: obj={obj_opt:.8f} (no improvement)")

    # Phase 2: Subgradient refinement
    remaining = deadline - time.monotonic()
    p2 = min(remaining * 0.12, 120.0)
    if p2 > 15:
        print(f"\n=== Phase 2: Subgradient ===")
        a_sg = subgradient_optimize(best_seq, time_budget=p2, K=5)
        obj_sg = compute_obj(a_sg)
        if obj_sg < best_score:
            best_score = obj_sg
            best_seq = a_sg.copy()
            print(f"  P2 done: obj={best_score:.8f} **")
        else:
            print(f"  P2: obj={obj_sg:.8f}")

    # Phase 3: Coordinate refinement
    remaining = deadline - time.monotonic()
    p3 = min(remaining * 0.06, 40.0)
    if p3 > 10:
        print(f"\n=== Phase 3: Coordinate Refine ===")
        a_cd = coordinate_refine(best_seq, time_budget=p3)
        obj_cd = compute_obj(a_cd)
        if obj_cd < best_score:
            best_score = obj_cd
            best_seq = a_cd.copy()
            print(f"  P3 done: obj={best_score:.8f} **")
        else:
            print(f"  P3: obj={obj_cd:.8f}")

    # Phase 4: Second LP round with different damping
    remaining = deadline - time.monotonic()
    p4 = min(remaining * 0.2, 200.0)
    if p4 > 20:
        print(f"\n=== Phase 4: Alternating LP round 2 ===")
        a_opt2 = alternating_lp(best_seq, time_budget=p4, damping=0.7, verbose=False)
        obj_opt2 = compute_obj(a_opt2)
        if obj_opt2 < best_score:
            best_score = obj_opt2
            best_seq = a_opt2.copy()
            print(f"  P4 done: obj={best_score:.8f} **")
        else:
            print(f"  P4: obj={obj_opt2:.8f}")

    # Phase 5: Multi-n exploration
    remaining = deadline - time.monotonic()
    print(f"\n=== Phase 5: Multi-n Exploration ===")
    n_opts = sorted(set([
        n_current - 100, n_current - 50, n_current + 50, n_current + 100,
        n_current + 200, 600, 700, 900, 1000, 1100, 1200
    ]))
    n_opts = [x for x in n_opts if 400 <= x <= 1400]

    for n_try in n_opts[:10]:
        remaining = deadline - time.monotonic()
        if remaining < 35:
            break
        if n_try == n_current:
            a_try = best_seq.copy()
        else:
            a_try = resample(best_seq, n_try)

        alloc = min(remaining * 0.18, 50.0)
        a_opt_n = alternating_lp(a_try, time_budget=alloc, damping=1.0)
        obj_n = compute_obj(a_opt_n)

        if obj_n < best_score:
            best_score = obj_n
            best_seq = a_opt_n.copy()
            n_current = n_try
            print(f"  ** n={n_try}: obj={best_score:.8f} **")
        else:
            print(f"  n={n_try}: obj={obj_n:.8f}")

    # Phase 6: Diverse restarts
    remaining = deadline - time.monotonic()
    print(f"\n=== Phase 6: Diverse Restarts ===")
    n_best = len(best_seq)
    n_restarts = min(5, max(2, int(remaining / 40)))

    for r in range(n_restarts):
        remaining = deadline - time.monotonic()
        if remaining < 30:
            break
        mode = r % 7
        a_r = diverse_init(n_best, rng, mode=mode)
        blend = 0.3 + 0.1 * r
        a_r = (1.0 - blend) * a_r + blend * best_seq
        a_r = np.maximum(a_r, 0)
        a_r = a_r / a_r.sum()

        alloc = min(remaining * 0.2, 45.0)
        a_opt_r = alternating_lp(a_r, time_budget=alloc, damping=1.0)
        obj_r = compute_obj(a_opt_r)

        if obj_r < best_score:
            best_score = obj_r
            best_seq = a_opt_r.copy()
            print(f"  Restart {r} (mode={mode}): obj={best_score:.8f} **")
        else:
            print(f"  Restart {r} (mode={mode}): obj={obj_r:.8f}")

    # Phase 7: Final intensive polish
    remaining = deadline - time.monotonic()
    print(f"\n=== Phase 7: Final Polish ===")

    if remaining > 40:
        lp_alloc = min(remaining * 0.45, 120.0)
        a_f = alternating_lp(best_seq, time_budget=lp_alloc, damping=1.0, verbose=True)
        obj_f = compute_obj(a_f)
        if obj_f < best_score:
            best_score = obj_f
            best_seq = a_f.copy()
            print(f"  Final LP: obj={best_score:.8f} **")

    remaining = deadline - time.monotonic()
    if remaining > 25:
        sg_alloc = min(remaining * 0.4, 60.0)
        a_f2 = subgradient_optimize(best_seq, time_budget=sg_alloc, K=3)
        obj_f2 = compute_obj(a_f2)
        if obj_f2 < best_score:
            best_score = obj_f2
            best_seq = a_f2.copy()
            print(f"  Final SG: obj={best_score:.8f} **")

    remaining = deadline - time.monotonic()
    if remaining > 15:
        cd_alloc = min(remaining * 0.5, 30.0)
        a_f3 = coordinate_refine(best_seq, time_budget=cd_alloc)
        obj_f3 = compute_obj(a_f3)
        if obj_f3 < best_score:
            best_score = obj_f3
            best_seq = a_f3.copy()
            print(f"  Final CD: obj={best_score:.8f} **")

    # Final validation
    result = [float(max(0.0, min(1000.0, x))) for x in best_seq]
    val = evaluate_sequence(result)
    if val < np.inf:
        best_score = val
    else:
        result = [1.0] * 100
        best_score = 2.0

    elapsed = time.monotonic() - start_time
    print(f"\n=== FINAL: n={len(result)}, score={best_score:.8f}, time={elapsed:.1f}s ===")
    return result
```
