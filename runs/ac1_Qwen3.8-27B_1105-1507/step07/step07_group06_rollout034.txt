**Key algorithmic idea: Iterative projection**

Actually, a simpler version:

**General iterative approach: "Autocorrelation flattening"**

1. Start with a sequence a (e.g., the parent)
2. Compute the autocorrelation c = conv(a,a)
3. Find the peak position k*
4. "Push down" the peak by adjusting a:
   - For each j, the contribution to c[k*] from position j is a[j]*a[k*-j]
   - Reduce a[j] proportionally to a[k*-j] (the "partner" value)
   - Add the removed mass to positions where it won't create new peaks
5. Repeat

This is similar to the "harmonic coordinate descent" or "bottleneck" approach.

1. Taking the gradient of the max (which is the gradient of one of the tied lags)
2. Or using a subgradient (average of gradients of all tied lags)
3. Or using the smoothed max (log-sum-exp)

For efficiency, I'll use the "top-k" approach: consider the top-k lags and average their gradients.

   - Find top-k peak lags
   - Compute averaged gradient
   - Take a step with adaptive learning rate

   - Repeat (this is O(n) per iteration with FFT for convolution)

2. **LP alternating** (from the previous code, improved)

3. **Basin hopping with diverse perturbations**

4. **Spectral shaping initialization** (new idea)

Let me also think about the projection onto the simplex. Given a vector v, the projection onto {x >= 0, sum(x) = 1} is:
x_i = max(0, v_i - τ)
where τ is chosen so that sum x_i = 1.
This can be done in O(n log n) using sorting, or O(n) on average using selection.

For n=800, even O(n log n) is fast enough.

Actually, one more thought: the "shifted and reversed" gradient means that the natural "flow" is to move mass away from positions that are "aligned" with the peak lag. This creates a kind of "de-cohering" effect.

Let me also think about what happens with the smoothed objective. If I use log-sum-exp with temperature τ:
L(τ) = (1/τ) * log(sum_k exp(τ * c_k))

∂L/∂a_j = (1/τ) * sum_k exp(τ*c_k) * ∂c_k/∂a_j / sum_k exp(τ*c_k)
= sum_k w_k * 2 * a[k-j] * I(0<=k-j<n)

where w_k = exp(τ*c_k) / sum_m exp(τ*c_m) are the "soft-argmax" weights.

This is a weighted average of the shifted-reversed a vectors, weighted by the softmax of the correlation values. For large τ, this converges to the gradient of the max. For small τ, it's smoother.

This is exactly what the previous code's `smoothed_obj_and_grad` was doing! So the gradient method is already there. The question is whether the optimization path is good.

import numpy as np
import time
from scipy.fft import rfft, irfft
from scipy.optimize import minimize, linprog


def compute_conv(a):
    """Full linear convolution a*a via FFT. Returns array of length 2n-1."""
    n = len(a)
    if n == 1:
        return np.array([a[0]*a[0]])
    size = 1
    while size < 2*n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2*n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    s = float(np.sum(a))
    if s < 1e-10:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    max_b = float(np.max(conv))
    return 2.0 * n * max_b


def project_simplex(v):
    """Project v onto {x >= 0, sum(x) = 1}."""
    n = len(v)
    # Use bisection on the threshold
    v = np.maximum(v, 0)
    s = v.sum()
    if s < 1e-15:
        return np.ones(n) / n
    # We need x_i = max(0, v_i - tau), sum x_i = 1
    # Sort v in decreasing order
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    tau = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - tau, 0)


def gradient_peak(a, k_peak, n):
    """Compute gradient of c_{k_peak} w.r.t. a. Result: 2*a[k_peak - j] for valid j."""
    grad = np.zeros(n)
    # grad[j] = 2 * a[k_peak - j] if 0 <= k_peak - j < n
    lo = max(0, k_peak - n + 1)
    hi = min(n - 1, k_peak)
    if lo <= hi:
        grad[lo:hi+1] = 2.0 * a[k_peak - hi:k_peak - lo + 1][::-1]
    return grad


def gradient_smooth(a, tau, n):
    """Compute gradient of smoothed max (log-sum-exp) objective w.r.t. a."""
    conv = compute_conv(a)
    conv_max = np.max(conv)
    # Soft-argmax weights
    exp_vals = np.exp((conv - conv_max) * tau)
    w = exp_vals / np.sum(exp_vals)
    # Gradient: sum_k w_k * 2 * a[k-j] for valid j
    grad = np.zeros(n)
    for k in range(len(w)):
        if w[k] < 1e-10:
            continue
        lo = max(0, k - n + 1)
        hi = min(n - 1, k)
        if lo <= hi:
            grad[lo:hi+1] += w[k] * 2.0 * a[k - hi:k - lo + 1][::-1]
    return grad * (1.0 / tau)  # normalized by 1/tau from the log-sum-exp derivative


def peak_chase_descent(a, time_budget=100.0, tau_start=5.0, tau_end=200.0, 
                       n_steps=5000, top_k=1):
    """
    Fast gradient descent that chases the peak autocorrelation lag.
    Uses adaptive tau (smoothing) and step size.
    """
    n = len(a)
    a = np.maximum(a, 0).copy()
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    step_size = 0.5
    n_practical = min(n_steps, int(time_budget * 2000))  # estimate max steps
    
    for it in range(n_practical):
        if time.monotonic() - start > time_budget:
            break
        
        # Adaptive tau: start smooth, get sharper
        progress = it / max(1, n_practical)
        tau = tau_start * (tau_end / tau_start) ** progress
        
        conv = compute_conv(a)
        conv_max = np.max(conv)
        
        if top_k == 1:
            # Hard peak chase
            k_star = int(np.argmax(conv))
            grad = gradient_peak(a, k_star, n)
        else:
            # Top-k peak chase
            top_idx = np.argsort(conv)[::-1][:top_k]
            grad = np.zeros(n)
            for k in top_idx:
                grad += gradient_peak(a, int(k), n)
            grad /= len(top_idx)
        
        # Normalize gradient (it has magnitude ~ 2*sum(a) = 2)
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-15:
            break
        
        # Line search (backtracking)
        obj_current = 2.0 * n * conv_max  # current objective (with sum=1)
        
        accepted = False
        for _ls in range(10):
            a_try = a - step_size * grad
            a_try = project_simplex(a_try)
            obj_try = compute_obj(a_try)
            if obj_try < obj_current - 1e-15:
                a = a_try
                accepted = True
                if obj_try < best_obj:
                    best_obj = obj_try
                    best_a = a.copy()
                break
            else:
                step_size *= 0.7
        
        if not accepted:
            step_size *= 0.5
            if step_size < 1e-10:
                # Try a larger step in a slightly different direction
                step_size = 0.1
                a_try = a - step_size * grad + 0.01 * np.random.randn(n)
                a_try = project_simplex(a_try)
                if compute_obj(a_try) < obj_current:
                    a = a_try
        
        # Increase step size if we've been successful
        if accepted and it % 100 == 0:
            step_size = min(step_size * 1.2, 5.0)
        
        # Periodic check
        if it % 500 == 0:
            elapsed = time.monotonic() - start
            print(f"    PeakChase it={it}: obj={best_obj:.8f}, tau={tau:.1f}, step={step_size:.4f}, time={elapsed:.1f}s")
    
    return best_a


def lp_solve_minpeak(a_fixed, n):
    """
    Solve LP: min M s.t. conv(a_fixed, g)[k] <= M for all k, sum(g)=1, g>=0.
    Uses scipy linprog with HiGHS.
    """
    # Build the convolution matrix: A[k, j] such that (A @ g)[k] = conv(a_fixed, g)[k]
    # conv(a_fixed, g)[k] = sum_j a_fixed[j] * g[k-j]
    # For fixed k: sum_j a_fixed[k-j] * g[j] (where 0 <= k-j < n and 0 <= j < n)
    # So A[k, j] = a_fixed[k-j] if 0 <= k-j < n, else 0
    
    # This is a (2n-1) x n matrix
    A = np.zeros((2*n - 1, n))
    for k in range(2*n - 1):
        for j in range(n):
            idx = k - j
            if 0 <= idx < n:
                A[k, j] = a_fixed[idx]
    
    # LP: min M
    # s.t. A @ g - M <= 0 (for each row k)
    #      sum(g) = 1
    #      g >= 0, M >= 0
    
    # Variables: [g_0, ..., g_{n-1}, M] (n+1 variables)
    c = np.zeros(n + 1)
    c[n] = 1.0  # minimize M
    
    # Inequality: A @ g - M <= 0
    A_ub = np.zeros((2*n - 1, n + 1))
    A_ub[:, :n] = A
    A_ub[:, n] = -1.0
    b_ub = np.zeros(2*n - 1)
    
    # Equality: sum(g) = 1
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([1.0])
    
    bounds = [(0, None)] * (n + 1)
    
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs')
        if res.status == 0:
            g_val = np.maximum(res.x[:n], 0)
            s = float(np.sum(g_val))
            if s > 1e-10:
                g_val = g_val / s
                return g_val, float(res.x[n])
    except Exception:
        pass
    
    return None, None

def spectral_init(n, rng):
    """
    Initialize a sequence using spectral shaping.
    Try to create a sequence whose autocorrelation is as flat as possible.
    Approach: pick a random phase-modulated exponential, clip to positive.
    """
    # Method 1: Modulated exponential
    f0 = rng.uniform(0.1, 0.4)  # fraction of Nyquist
    phi = rng.uniform(0, 2*np.pi)
    t = np.arange(n) / n
    a = 0.5 + 0.5 * np.cos(2*np.pi*f0*t + phi)  # in [0, 1]
    a = np.maximum(a, 1e-10)
    a = a / np.sum(a)
    return a

def resample_sequence(a, new_n):
    """Resample sequence to new length using interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)
