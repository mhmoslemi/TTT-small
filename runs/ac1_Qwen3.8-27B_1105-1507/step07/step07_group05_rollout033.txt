The fundamental issue: for the peak to be at all below 1/n, we need c[k] < 1/n for ALL k. At k=0, c[0] = a[0]^2. So we need a[0] < 1/sqrt(n). Similarly, a[0]*a[1] < 1/(2n) (from c[1] = 2*a[0]*a[1] < 1/n).

Actually, the constraint is that for ALL k: sum_{valid i} a[i]*a[k-i] < 1/n.

This is a very strong constraint. Let's see if it's feasible.

Sum over all k of c[k] = 1. There are 2n-1 terms. If all c[k] < 1/n, then 1 = sum c[k] < (2n-1)/n ≈ 2. That's feasible (1 < 2), so it's not immediately contradictory.

But we also have c[0] = a[0]^2 < 1/n, so a[0] < 1/sqrt(n).

Actually, the constraint c[1] < 1/n just says a[0]*a[1] < 1/(2n). If a[0] is close to 1/sqrt(n), then a[1] < 1/(2*sqrt(n)).

For the uniform sequence, a[i] = 1/n for all i, and c[k] at the middle is 1/n (exactly at the boundary). So the uniform sequence is right at the boundary of feasibility for the middle lags, but the edge lags are well below 1/n.

To get below 2, we need to reduce the middle lags below 1/n while keeping edge lags also below 1/n. The question is: can we do this?

Let's think about it from the perspective of the "energy" in different lag ranges:
- Edge lags (k near 0 or 2n-1): few terms, naturally small
- Middle lags (k near n-1): about n terms, larger

The uniform sequence has the middle at exactly 1/n. To reduce it, we need to make some products a[i]*a[n-1-i] small. Since all values are non-negative, this means making either a[i] or a[n-1-i] small for many pairs.

One approach: make the sequence "anti-symmetric" in a sense. If a[i] is large for small i and small for large i, then a[i]*a[n-1-i] tends to be small (large * small + small * large).

But as we saw with the geometric sequence, this creates a peak at intermediate lags.

The key trade-off: reducing middle-peak by making the sequence asymmetric creates peaks at intermediate lags. The optimal balance is somewhere in between.

Let me try a different approach: **iterative proportional fitting / multiplicative updates**.

Algorithm:
1. Start with uniform a.
2. Find the peak lag k*.
3. For all i where a[i]*a[k*-i] contributes to c[k*], reduce a[i] and/or a[k*-i] proportionally.
4. Renormalize.
5. Repeat.

This is similar to the "water-filling" approach.
