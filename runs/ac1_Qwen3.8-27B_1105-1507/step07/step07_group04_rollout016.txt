```python
    # i=1: formula gives 2*a[1-1] = 2a[0] = 2x. d(2xy)/dy = 2x ✓
    # i=2: formula gives 2*a[1-2] = 2*a[-1] = 0. d(2xy)/dz = 0 ✓
    
    # Great, so the formula is confirmed:
    # d conv[k] / d a[i] = 2 * a[k-i] if 0 <= k-i < n, else 0.
    
    # This can also be written as: the gradient of conv[k] w.r.t. a is 2 * (a reversed and shifted by k).
    # Specifically, grad = 2 * a_shifted where a_shifted[i] = a[k-i] if 0<=k-i<n else 0.
    
    # So grad[k] = 2 * flip(a)[k:k+n] (with appropriate padding)
    
    # Actually, a simpler way to see it: the gradient of conv[k] w.r.t. a is 2*a[k::-1] padded appropriately.
    # Or: it's 2 * (a circularly shifted by k) but only the valid part.
    
    # For the subgradient of max(conv), we take the average (or any convex combination) of the gradients at the active lags.
    
    return grad, conv, max_val
```

OK so I've derived that d conv[k] / d a[i] = 2 * a[k-i] (if valid). This is a very clean formula.

Now, the objective is f(a) = 2*n*max(conv(a,a)) / (sum(a))^2.

Let S = sum(a), M = max_k conv[k].
f = 2*n*M / S^2

The subgradient w.r.t. a (ignoring the normalization for now, since we'll project back to sum=1):
If we fix S=1 (i.e., we're optimizing on the simplex), then:
f = 2*n*M
and the subgradient is 2*n * (subgradient of M)

The subgradient of M = max_k conv[k] is:
(1/|K|) * sum_{k in K} grad_k
where K is the set of active lags (where conv[k] = M) and grad_k is the gradient of conv[k].

So the subgradient of f is:
(2*n/|K|) * sum_{k in K} 2 * a[k-i] (for each i)

To minimize f on the simplex, we use projected subgradient:
a_new = project_simplex(a - alpha * subgrad)

Where project_simplex projects onto {a >= 0, sum(a) = 1}.

This is a natural algorithm. Let me implement it with:

- Averaging of iterates (for subgradient methods, the average is often better than the last iterate)

Let me also think about the LP approach more carefully.

The LP for a fixed a:
min M
s.t. conv(a, g)[k] <= M for all k
sum(g) = 1
g >= 0

This is a linear program with 2n-1 + 1 constraints and n+1 variables. For n=800, that's 1599 constraints and 801 variables. This should be solvable quickly with a good LP solver.

The optimal M gives a lower bound on the achievable peak for sequences in the "cone" generated by g (i.e., sequences of the form c*g for c>0).

The alternating method:
1. Given a, solve the LP to get g* and M*
2. Set a_new = (1-t)*a + t*g* for some t in (0,1]
3. Repeat

This is a block coordinate descent where we alternate between optimizing a (via subgradient) and optimizing g (via LP).

Actually, a cleaner formulation is:
- We want to minimize max_k conv(a,a)[k] subject to sum(a)=1, a>=0.
- This is a non-convex problem (the objective is non-convex in a).
- But if we fix one "copy" of a, the problem becomes convex in the other.
- Specifically: minimize max_k conv(a,g)[k] subject to sum(g)=1, g>=0 is a convex problem in g.

The alternating minimization:
1. Fix a, minimize max_k conv(a,g)[k] over g -> get g*
2. Fix g*, minimize max_k conv(g*,a)[k] over a -> get a*
3. Repeat

This is guaranteed to decrease the objective at each step (since we're doing exact minimization in each block).

But step 2 is the same type of problem as step 1, so it's symmetric. We can just use the LP for both steps.

Actually, both steps are the same LP! Because conv(a,g) = conv(g,a) (convolution is commutative).

So the algorithm is:
1. Start with some a.
2. Solve LP: min M s.t. conv(a,g)[k] <= M, sum(g)=1, g>=0. Get g*.
3. Replace a with g* (or blend: a = (1-t)*a + t*g*).
4. Repeat.

This is a very natural algorithm and should converge to a fixed point where a = g* (i.e., a is the solution to the LP with a as the fixed point).

At a fixed point, a minimizes max_k conv(a,g)[k] over g, which means a is a "best response" to itself. This is a Nash equilibrium of a certain game.

Let me implement this approach as the core of my solver, with some additional heuristics to escape local optima.

```python
import numpy as np
from scipy.fft import rfft, irfft
import time
import cvxpy as cp

def compute_conv(a):
    """Compute linear convolution a*a using FFT."""
    n = len(a)
    size = 1
    while size < 2*n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2*n-1]

def compute_obj(a):
    """Compute the objective function."""
    n = len(a)
    s = np.sum(a)
    if s < 1e-10:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * np.max(conv)

def build_conv_matrix(a):
    """Build matrix A such that A @ g = conv(a, g)."""
    n = len(a)
    m = 2*n - 1
    A = np.zeros((m, n))
    for j in range(n):
        # conv(a,g)[k] = sum_i a[i]*g[k-i]
        # For fixed j (index into g), g[j] appears in conv[k] when k-j is a valid index of a
        # i.e., 0 <= k-j < n, so j <= k < j+n
        # So A[k, j] = a[k-j] for j <= k < j+n
        for k in range(j, j+n):
            if k < m:
                A[k, j] = a[k-j]
    return A

def solve_lp(a):
    """Solve LP: min M s.t. conv(a,g)[k] <= M, sum(g)=1, g>=0."""
    n = len(a)
    a_norm = a / np.sum(a)
    m = 2*n - 1
    A = build_conv_matrix(a_norm)
    
    g = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [A @ g <= M, cp.sum(g) == 1]
    prob = cp.Problem(cp.Minimize(M), constraints)
    
    for solver in [cp.CLARABEL, cp.PDLP, cp.SCS, cp.ECOS]:
        try:
            prob.solve(solver=solver)
            if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g.value, 0)
                if np.sum(g_val) > 1e-10:
                    return g_val / np.sum(g_val), float(M.value)
        except:
            continue
    
    # Fallback to scipy
    from scipy.optimize import linprog
    c = np.zeros(n + 1)
    c[-1] = 1.0
    A_ub = np.hstack([A, -np.ones((m, 1))])
    b_ub = np.zeros(m)
    A_eq = np.hstack([np.ones((1, n)), np.array([[0.0]])])
    b_eq = np.array([1.0])
    bounds = [(0, None)] * n + [(None, None)]
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                  bounds=bounds, method='highs')
    if res.status == 0:
        g_val = np.maximum(res.x[:n], 0)
        if np.sum(g_val) > 1e-10:
            return g_val / np.sum(g_val), float(res.x[n])
    
    return None, None

def lp_alternating(a, max_iter=100, time_budget=60.0):
    """LP alternating optimization."""
    start = time.monotonic()
    best_a = a.copy()
    best_obj = compute_obj(a)
    
    for it in range(max_iter):
        if time.monotonic() - start > time_budget:
            break
        g, M = solve_lp(a)
        if g is None:
            break
        a_new = g
        obj_new = compute_obj(a_new)
        if obj_new < best_obj:
            best_obj = obj_new
            best_a = a_new.copy()
        a = a_new
    
    return best_a, best_obj
```

def compute_conv(a):
