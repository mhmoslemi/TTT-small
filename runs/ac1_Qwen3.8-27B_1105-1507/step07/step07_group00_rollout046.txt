- Length of `v_flipped`: 2n-1
- Length of linear convolution: n + 2n-1 - 1 = 3n-2
- We need indices from `n-1` to `2n-2`, which is n elements.

```python
def smooth_obj_and_grad(z, beta):
    n = len(z)
    # softmax
    z_shifted = z - np.max(z)
    exp_z = np.exp(z_shifted)
    a = exp_z / exp_z.sum()
    
    # Compute convolution
    conv_size = 2 * n - 1
    fft_size = 1
    while fft_size < conv_size:
        fft_size <<= 1
    fa = rfft(a, fft_size)
    conv = irfft(fa * fa, fft_size)[:conv_size]
    
    # Smooth max (logsumexp)
    max_conv = np.max(conv)
    exp_bconv = np.exp(beta * (conv - max_conv))
    sum_exp = exp_bconv.sum()
    smooth_val = max_conv + np.log(sum_exp) / beta
    obj = 2.0 * n * smooth_val
    
    # Weights for the logsumexp gradient
    w = exp_bconv / sum_exp  # sums to 1
    
    # Gradient of sum_k w[k]*conv[k] w.r.t. a
    # grad_a[i] = 2 * sum_{j=0}^{n-1} a[j] * w[i+j]
    # = 2 * conv(a, w_flipped)[2n-2-i]
    
    w_flipped = w[::-1]  # length 2n-1
    conv_fft_size = 1
    while conv_fft_size < n + conv_size - 1:  # n + (2n-1) - 1 = 3n-2
        conv_fft_size <<= 1
    fa2 = rfft(a, conv_fft_size)
    fw = rfft(w_flipped, conv_fft_size)
    conv_aw = irfft(fa2 * fw, conv_fft_size)
    
    # grad_a[i] = 2 * conv_aw[2n-2-i] for i=0..n-1
    # 2n-2-i for i=0..n-1 gives indices 2n-2, 2n-3, ..., n-1
    grad_a = 2.0 * conv_aw[n-1:2*n-1][::-1]
    
    # Gradient through softmax
    # da_i/dz_j = a_i * (delta_ij - a_j)
    # grad_z[i] = sum_j grad_a[j] * da_j/dz_i = a_i * (grad_a[i] - sum_j a_j * grad_a[j])
    dot = np.dot(a, grad_a)
    grad_z = a * (grad_a - dot)
    
    return obj, grad_z
```

- As beta → ∞, this approaches max_conv.

Now, the gradient through softmax:
- `grad_z[i] = a[i] * (grad_a[i] - dot(a, grad_a))`
- This ensures `sum_i grad_z[i] = 0` (invariance to adding a constant to z), which is correct for softmax.

Let me also think about whether I should use the logsumexp directly or a different smooth approximation.

Alternative: use `f(a) = (sum_k conv[k]^p)^(1/p)` for large p (L^p norm). This is also smooth for p > 1 and approaches the L^∞ norm as p → ∞.

The gradient of `(sum conv[k]^p)^(1/p)` is:
`= (1/p) * (sum conv[k]^p)^(1/p - 1) * p * sum_k conv[k]^{p-1} * d conv[k]/d a[i]`
`= (sum conv[k]^p)^{1/p - 1} * sum_k conv[k]^{p-1} * 2*a[k-i]`

This is similar in structure. The logsumexp is probably better because:
1. It's always well-defined (no issues with conv[k] = 0)
2. The "temperature" parameter beta controls the sharpness smoothly
3. It's the standard approach in optimization

Let me also consider using the "entropic regularization" approach. If we define:
`F(a) = 2n * (1/beta) * log(sum_k exp(beta * conv[k]))`

Then for large beta, this is approximately `2n * max_k conv[k] + 2n * (1/beta) * log(number_of_max_terms)`.

The gradient is well-behaved and we can use standard optimizers.

**Optimization strategy:**

1. Start with beta = n (moderate smoothing)
2. Use Adam optimizer with learning rate ~ 0.01/sqrt(n)
3. Every K iterations, increase beta by a factor
4. When convergence is detected, increase beta more aggressively
5. Periodically project back to the simplex (re-normalize)

Actually, since we're using the softmax parameterization, the simplex constraint is automatically satisfied. The issue is that the softmax might converge to a "spiky" distribution (some entries very close to 0), which is numerically problematic. To prevent this, I can:
- Add an entropy regularization: `-gamma * sum a[i] * log(a[i])` to the objective
- Or use the "elliptical" parameterization: `a[i] = (1-eps) * softmax(z)[i] + eps/n`

Let me also think about the n choice. The objective is `2n * max(conv)`. For a given "shape" of the sequence, if we resample to a different n, the max(conv) changes. For a smooth function f on [0,1], the convolution at the center is approximately `integral f(x)*f(1-x) dx / n` (roughly), so `max(conv) ~ C/n` and `2n * max(conv) ~ 2C`. The constant C depends on the shape.

So the choice of n might not matter much for smooth sequences, but for "structured" sequences (like those with specific number-theoretic properties), it could matter.

Let me now write the full algorithm:

```python
"""
Optimization via logsumexp-smoothed objective with Adam optimizer.
Uses softmax parameterization and adaptive temperature (beta) scheduling.
"""

import numpy as np
from scipy.fft import rfft, irfft
import time

def compute_conv(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1
    while fft_size < size:
        fft_size <<= 1
    fa = rfft(a, fft_size)
    return irfft(fa * fa, fft_size)[:size]

def compute_obj(a):
    n = len(a)
    s = np.sum(a)
    if s < 1e-10:
        return np.inf
    a = a / s
    conv = compute_conv(a)
    return 2.0 * n * float(np.max(conv))

def smooth_objective_and_grad(z, beta, n):
    """
    Compute the smooth objective and its gradient with respect to z.
    a = softmax(z), objective = 2n * logsumexp(beta * conv(a,a)) / beta + 2n * max(conv)
    
    Actually: 2n * (max_conv + log(sum(exp(beta*(conv-max_conv))))/beta)
    """
    z_max = np.max(z)
    exp_z = np.exp(z - z_max)
    a = exp_z / exp_z.sum()
    
    conv_size = 2 * n - 1
    fft_size = 1
    while fft_size < conv_size:
        fft_size <<= 1
    fa = rfft(a, fft_size)
    conv = irfft(fa * fa, fft_size)[:conv_size]
    
    max_conv = float(np.max(conv))
    shifted = beta * (conv - max_conv)
    # For numerical stability, clip
    shifted = np.clip(shifted, -500, 0)
    exp_shifted = np.exp(shifted)
    log_sum = np.log(exp_shifted.sum())
    smooth_val = max_conv + log_sum / beta
    obj = 2.0 * n * smooth_val
    
    # Gradient weights
    w = exp_shifted / exp_shifted.sum()
    
    # grad_a[i] = 2 * sum_j a[j] * w[i+j]
    # = 2 * conv(a, w_flipped)[2n-2-i]
    w_flipped = w[::-1]
    conv_fft_size = 1
    while conv_fft_size < 3 * n - 2:
        conv_fft_size <<= 1
    fa2 = rfft(a, conv_fft_size)
    fw = rfft(w_flipped, conv_fft_size)
    conv_aw = irfft(fa2 * fw, conv_fft_size)
    grad_a = 2.0 * conv_aw[n-1:2*n-1][::-1]
    
    # Softmax gradient
    dot = float(np.dot(a, grad_a))
    grad_z = a * (grad_a - dot)
    
    return obj, grad_z

def adam_optimize(z0, beta0, beta_max, time_budget, verbose=True):
    """
    Adam optimizer with adaptive beta.
    """
    n = len(z0)
    z = z0.copy()
    
    # Adam state
    m = np.zeros(n)
    v = np.zeros(n)
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    t = 0
    lr = 0.05 / np.sqrt(n)
    
    beta = beta0
    best_obj = np.inf
    best_z = z.copy()
    start = time.monotonic()
    
    patience = 0
    max_patience = 500
    
    it = 0
    while time.monotonic() - start < time_budget:
        obj, grad = smooth_objective_and_grad(z, beta, n)
        
        if obj < best_obj:
            best_obj = obj
            best_z = z.copy()
            patience = 0
        else:
            patience += 1
        
        # Update beta
        if it % 100 == 0 and patience > 100:
            beta = min(beta * 1.2, beta_max)
            patience = 0
            lr = lr * 0.7
        
        # Adam update
        t += 1
        m = beta1 * m + (1 - beta1) * grad
        v = beta2 * v + (1 - beta2) * (grad ** 2)
        m_hat = m / (1 - beta1 ** t)
        v_hat = v / (1 - beta2 ** t)
        z = z - lr * m_hat / (np.sqrt(v_hat) + eps)
        
        it += 1
        if it % 500 == 0 and verbose:
            elapsed = time.monotonic() - start
            # Compute true objective
            z_max = np.max(z)
            a = np.exp(z - z_max)
            a = a / a.sum()
            true_obj = compute_obj(a)
            print(f"  Adam it{it}: smooth_obj={obj:.8f}, true_obj={true_obj:.8f}, beta={beta:.1f}, lr={lr:.6f}, elapsed={elapsed:.1f}s")
    
    # Return the best a
    z_max = np.max(best_z)
    a = np.exp(best_z - z_max)
    a = a / a.sum()
    return a, compute_obj(a)

def lp_solve(a, M_target):
    """Solve LP: max sum(g) s.t. A@g <= M_target, g >= 0."""
    n = len(a)
    a = a / np.sum(a)
    
    # Use scipy linprog
    from scipy.optimize import linprog
    
    # A is (2n-1) x n, A[k, i] = a[k-i] if 0 <= k-i < n
    # We need: A @ g <= M_target
    # Build A sparsely... for n=800, A has 2n-1 rows and n cols
    # Each row k has at most n non-zeros, but typically min(k+1, n, 2n-1-k)
    
    # Actually, A[k, i] = a[i] * delta_valid(k-i) where valid means 0<=k-i<n
    # So A[k, i] = a[i] if 0 <= k-i < n, else 0
    # This means: for fixed i, A[k, i] = a[i] for k in [i, i+n-1]
    # So each column i has a[i] in rows i to i+n-1
    
    # For linprog: minimize -sum(g) s.t. A@g <= M_target, g >= 0
    # c = -1 for g variables
    # This is an LP with (2n-1) constraints and n variables
    
    # For n=800, this is 1599 constraints and 800 variables - might be slow with linprog
    # Let's try it
    
    c = -np.ones(n)
    # A_ub: (2n-1) x n
    # A_ub[k, i] = a[i] if 0 <= k-i < n
    A_ub = np.zeros((2*n-1, n))
    for i in range(n):
        A_ub[i:i+n, i] = a[i]
    b_ub = np.full(2*n-1, M_target)
    bounds = [(0, None)] * n
    
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if res.status == 0:
        g = np.maximum(res.x, 0)
        s = g.sum()
        if s > 1e-10:
            return g / s
    return None

def lp_alternating(a, time_budget, verbose=True):
    """LP alternating optimization."""
    n = len(a)
    a = a.copy()
    a = a / a.sum()
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    stall = 0
    
    it = 0
    while time.monotonic() - start < time_budget:
        conv = compute_conv(a)
        M_cur = float(np.max(conv))
        
        # Solve LP: find g that minimizes max conv(a,g)
        # Try with M slightly below current
        for M_factor in [0.99, 0.98, 0.97, 1.0, 1.01]:
            M_target = M_cur * M_factor
            g = lp_solve(a, M_target)
            if g is not None:
                break
        
        if g is None:
            if stall > 20:
                # Perturb
                rng = np.random.default_rng(it * 12345 + n)
                a = best_a * np.exp(rng.normal(0, 0.1, n))
                a = np.maximum(a, 0)
                a = a / a.sum()
                best_a = a.copy()
                best_obj = compute_obj(a)
                stall = 0
            it += 1
            continue
        
        # Line search
        best_t_obj = np.inf
        best_t = 0.5
        best_a_local = best_a.copy()
        
        for t in [0.1, 0.2, 0.3, 0.5, 0.7, 0.9, 1.0]:
            a_try = (1-t) * a + t * g
            a_try = np.maximum(a_try, 0)
            s = a_try.sum()
            if s < 1e-10:
                continue
            a_try = a_try / s
            obj_try = compute_obj(a_try)
            if obj_try < best_t_obj:
                best_t_obj = obj_try
                best_t = t
                best_a_local = a_try.copy()
        
        if best_t_obj < best_obj - 1e-12:
            best_obj = best_t_obj
            best_a = best_a_local.copy()
            a = best_a
            stall = 0
            if verbose and it % 5 == 0:
                elapsed = time.monotonic() - start
                print(f"  LP it{it}: obj={best_obj:.8f}, t={best_t:.2f}, elapsed={elapsed:.1f}s")
        else:
            stall += 1
            if stall > 30:
                rng = np.random.default_rng(it * 67890 + n)
                scale = min(0.3, 0.05 + 0.03 * (stall // 30))
                a = best_a * np.exp(rng.normal(0, scale, n))
                a = np.maximum(a, 0)
                a = a / a.sum()
                best_a = a.copy()
                best_obj = compute_obj(a)
                stall = 0
        
        it += 1
    
    return best_a

def resample_sequence(a, new_n):
    n = len(a)
```

"""
Optimizes step function heights to minimize 2*n*max(conv(a,a))/(sum(a))^2
using logsumexp-smoothed optimization with Adam, LP alternating, and n-sweep.
"""

import numpy as np
from scipy.fft import rfft, irfft
from scipy.optimize import linprog
import time


def compute_conv(a):
    """Full linear convolution a*a via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1
    while fft_size < size:
        fft_size <<= 1
    fa = rfft(a, fft_size)
    return irfft(fa * fa, fft_size)[:size]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a = a / s
    conv = compute_conv(a)
    return 2.0 * n * float(np.max(conv))


def softmax(z):
    z = z - np.max(z)
    e = np.exp(z)
    return e / e.sum()


def smooth_obj_grad(z, beta):
    """
    Compute smooth objective 2n*logsumexp(beta*conv(softmax(z),softmax(z)))/beta
    and its gradient w.r.t. z.
    """
    n = len(z)
    a = softmax(z)
    
    # Convolution
    conv_size = 2 * n - 1
    fft_size = 1
    while fft_size < conv_size:
        fft_size <<= 1
    fa = rfft(a, fft_size)
    conv = irfft(fa * fa, fft_size)[:conv_size]
    
    # Logsumexp
    max_c = float(np.max(conv))
    shifted = np.clip(beta * (conv - max_c), -500, 0)
    exp_s = np.exp(shifted)
    log_sum = float(np.log(exp_s.sum()))
    smooth_val = max_c + log_sum / beta
    obj = 2.0 * n * smooth_val
    
    # Weights
    w = exp_s / exp_s.sum()
    
    # Gradient of sum_k w[k]*conv[k] w.r.t. a[i]
    # = 2 * sum_j a[j] * w[i+j] for i=0..n-1
    # Computed as 2*conv(a, w_flip)[2n-2-i]
    w_flip = w[::-1]
    cfft = 1
    while cfft < 3 * n - 2:
        cfft <<= 1
    fa2 = rfft(a, cfft)
    fw = rfft(w_flip, cfft)
    conv_aw = irfft(fa2 * fw, cfft)
    grad_a = 2.0 * conv_aw[n - 1:2 * n - 1][::-1]
    
    # Softmax chain rule
    dot = float(np.dot(a, grad_a))
    grad_z = a * (grad_a - dot)
    
    return obj, grad_z


def adam_run(z0, beta_start, beta_end, time_budget, lr_scale=1.0, verbose=True):
    """Adam optimizer on softmax parameterization with increasing beta."""
    n = len(z0)
    z = z0.copy().astype(np.float64)
    
    m = np.zeros(n)
    v = np.zeros(n)
    b1, b2, eps = 0.9, 0.999, 1e-8
    
    lr = lr_scale * 0.1 / np.sqrt(n)
    beta = beta_start
    t = 0
    best_obj = np.inf
    best_z = z.copy()
    start = time.monotonic()
    patience = 0
    
    while time.monotonic() - start < time_budget:
        obj, grad = smooth_obj_grad(z, beta)

            best_obj = obj
            best_z = z.copy()

            patience += 1

def solve_min_peak_lp(a):
    """Solve LP: min M s.t. A@g <= M, sum(g)=1, g>=0. Returns normalized g or None."""
    n = len(a)
    a = a / a.sum()
    
    # Build A: A[k,i] = a[i] if 0 <= k-i < n
    # Use sparse-like structure
    A_ub = np.zeros((2 * n - 1, n + 1))
    for i in range(n):
        A_ub[i:i + n, i] = a[i]
    A_ub[:, n] = -1.0
    b_ub = np.zeros(2 * n - 1)
    
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([1.0])
    
    c = np.zeros(n + 1)
    c[n] = 1.0  # minimize M
    
    bounds = [(0, None)] * n + [(-np.inf, np.inf)]
    
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs')
        if res.status == 0:
            g = np.maximum(res.x[:n], 0)
            s = float(np.sum(g))
            if s > 1e-10:
                return g / s, float(res.x[n])
    except Exception:
        pass
    return None, None
