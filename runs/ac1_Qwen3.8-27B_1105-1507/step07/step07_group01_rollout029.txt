Fast LP-alternating optimizer with dual-guided refinement for minimizing
2*n*max(conv(a,a))/(sum(a))^2. Uses multiple n exploration, frequency-domain

import numpy as np
import time
from scipy.fft import rfft, irfft

def compute_conv(a):
    """Full linear convolution a*a via FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]

def compute_obj(a):
    """Compute 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))

def solve_lp_fast(a):
    """
    Solve LP: min M s.t. conv(a,g) <= M, sum(g)=1, g>=0.
    Returns (g_opt, M_opt). a should be normalized (sum=1).
    """
    n = len(a)
    # Build constraint matrix: (2n-1) x n, where A[k,i] = a[k-i] if valid
    A = np.zeros((2 * n - 1, n))
    for i in range(n):
        r = min(n, 2 * n - 1 - i)
        A[i:i+r, i] = a[:r]
    
    # Try solvers in order of speed
    try:
        import cvxpy as cp
        g = cp.Variable(n, nonneg=True)
        M = cp.Variable(nonneg=True)
        constraints = [A @ g <= M, cp.sum(g) == 1]
        prob = cp.Problem(cp.Minimize(M), constraints)
        
        for solver in ['CLARABEL', 'MOSEK', 'ECOS', 'SCS']:
            try:
                prob.solve(solver=solver)
                if g.value is not None:
                    g_val = np.maximum(g.value, 0)
                    s = float(np.sum(g_val))
                    if s > 1e-10:
                        return g_val / s, float(M.value)
            except:
                continue
    except:
        pass
    
    # Fallback: scipy linprog
    from scipy.optimize import linprog
    c = np.zeros(n + 1)
    c[-1] = 1.0
    A_ub = np.hstack([A, -np.ones((2*n-1, 1))])
    b_ub = np.zeros(2*n-1)
    A_eq = np.zeros((1, n + 1))

        s = float(np.sum(g_val))
        if s > 1e-10:
            return g_val / s, float(res.x[n])
    
    return None, None

The key question is: does this decrease the objective? The objective is max_k (a*a)[k]. After updating a to (1-t)*a + t*g*:

For the k* that achieves the max of (a*a):

(a*g*)[k*] - (a*a)[k*] <= 0

**Better approach: Instead of just using the LP direction, use a direction that simultaneously decreases all large convolution values.**

This is: find g that minimizes sum_k w_k * (a*g)[k] where w_k are proportional to (a*a)[k]^p for some p > 1 (to emphasize the peaks).

min sum_k w_k * (A @ g)_k = min (A^T w)^T g s.t. sum(g) = 1, g >= 0

Solution: g = e_{argmin_i (A^T w)_i} (all mass on the best index).

For a smoother version: g[i] ∝ exp(-beta * (A^T w)_i) / sum_j exp(-beta * (A^T w)_j)

This is a softmax over the negative correlations.

**Even better: Use the subgradient of the smooth max.**

smooth_max_T(conv) = T * log(sum_k exp(conv[k]/T))

The gradient (w.r.t. a) is:
grad[i] = sum_k softmax_k * A[k,i] = sum_k softmax_k * a[k-i]

where softmax_k = exp(conv[k]/T) / sum_j exp(conv[j]/T)

For small T, softmax concentrates on the peak, and grad ≈ 2 * a shifted by the peak position (which is the chase-peak method).
For large T, softmax is more uniform, and grad ≈ sum_k (1/(2n-1)) * a[k-i] = a[i] * (sum of a over valid range) ≈ a[i] * (some average).

By annealing T from large to small, we first make broad improvements and then fine-tune the peaks.

The objective 2n * max_k (a*a)[k] with sum(a) = 1 can be written as:
2n * max_k sum_i a[i] * a[k-i]

This is 2n times the maximum "autocorrelation" of a (in the linear sense).

If a is a probability distribution on {0, ..., n-1}, then (a*a)[k] is the probability that two independent draws from a differ by k. We want to minimize the maximum such probability.

This is equivalent to: find a distribution on {0, ..., n-1} such that the "difference distribution" is as uniform as possible.

The difference distribution is: P(X-Y = k) = sum_i P(X=i) * P(Y=i+k) = (a*a)[k] (with appropriate index shifting).

We want P(X-Y = k) ≈ 1/(2n-1) for all k.

This is a well-studied problem in combinatorics! It's related to "Sidon sets" and "difference sets."

A **difference set** in Z_n is a subset S of size k such that every nonzero element of Z_n is represented exactly λ times as a difference of two elements of S. For our problem, we want a "soft" difference set where the difference distribution is as uniform as possible.

For our continuous relaxation (a is a probability vector, not 0-1), this becomes: find a probability vector a on {0, ..., n-1} such that the convolution a*a is as uniform as possible.

This is exactly a "quantum" version of difference sets, and the optimal solutions are related to **Bose-Chowla difference sets** and **Singer difference sets** in the finite field construction.
