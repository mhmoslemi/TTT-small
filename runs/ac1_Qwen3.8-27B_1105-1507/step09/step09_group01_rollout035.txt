Let me also think about a key improvement: **simultaneous optimization of n and the sequence**.

The objective for a sequence of length n is 2n * max(conv) / S^2. Different n values will have different "capacity" to minimize the ratio. The previous approach tried n around 800. Let me try a wider range.

Another key idea: **exploiting the structure of the problem**. The objective depends on:
1. n (the length)
2. max of the autocorrelation
3. sum of the sequence

Since we can always scale, the problem reduces to: minimize max(conv(a,a)) subject to sum(a) = 1, a >= 0.

The constraint sum(a) = 1 means we're on the probability simplex. The objective is 2n * max(conv).

Now, a key observation: the max of conv is at least the value at any particular lag. In particular:
- conv[0] = a[0]^2
- conv[n-1] = sum a[i]*a[n-1-i] (the "center" of the autocorrelation)
- conv[2n-2] = a[n-1]^2

For the objective to be small, we need all these (and all intermediate lags) to be small. Since conv[0] = a[0]^2, we need a[0] to be small. Similarly a[n-1] should be small. This suggests the sequence should be "bump-like" - concentrated in the middle and small at the edges.

But wait, if the sequence is concentrated in the middle, then conv[n-1] = sum a[i]*a[n-1-i] will be large (since both factors are large simultaneously).

So there's a fundamental tension: we need a[0] and a[n-1] to be small (to keep conv[0] and conv[2n-2] small), but we also need the "autocorrelation at center" to be small, which requires the sequence to not be too concentrated.

This suggests an optimal shape that is somewhat spread out but with suppressed edges.

Let me think about what the theoretical lower bound is. We have:
- sum(conv[k]) = S^2 (total energy of autocorrelation equals square of sum)
- There are 2n-1 lags
- So average conv = S^2/(2n-1)
- Therefore max(conv) >= S^2/(2n-1)
- Objective >= 2n/(2n-1) → 1 as n → ∞

But we also have the constraint a >= 0, which means:
- conv[0] = a[0]^2 >= 0 (no additional constraint)
- The sequence must be non-negative

For a non-negative sequence with sum = 1:
- The minimum possible max autocorrelation is at least 1/n (achieved when all a_i are equal)
- Wait, conv[n-1] for uniform = sum a[i]^2 = n*(1/n)^2 = 1/n
- And conv[0] = (1/n)^2 = 1/n^2
- So max = 1/n for uniform
- Objective = 2n * (1/n) = 2

But we're achieving 1.5, which means max(conv) = 1.5/(2n) * S^2 = 0.75/n * S^2 (with S=1).

So we're achieving max(conv) ≈ 0.75/n, which is 75% of the uniform value. This means the autocorrelation is significantly flatter than uniform.

Let me also add a **dual approach**: Instead of optimizing a directly, I can think of the problem as:
min max_k conv(a,a)[k] subject to sum(a) = 1, a >= 0

The Lagrangian dual is:

This dual is:

"""
Optimizes step function coefficients to minimize 2*n*max(conv(a,a))/(sum(a))^2.
Uses mirror descent (multiplicative weights) with log-sum-exp smoothing,
LP-based polishing, Frank-Wolfe fallback, and multi-length exploration.
"""

import numpy as np
import cvxpy as cp
from scipy.fft import rfft, irfft, fft, ifft
import time


def compute_conv(a):
    """Full linear convolution a*a via FFT. Returns array of length 2n-1."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))


def compute_smoothed_gradient(a, tau):
    """Compute gradient of log-sum-exp smoothed max of conv(a,a).
    Returns gradient vector of length n."""
    n = len(a)
    conv = compute_conv(a)
    max_c = float(np.max(conv))
    exp_vals = np.exp(tau * (conv - max_c))
    p = exp_vals / float(np.sum(exp_vals))
    
    # g_j = 2 * sum_m a[m] * p[m+j] for j=0..n-1
    # = 2 * conv(a_rev, p)[j+n-1]
    a_rev = a[::-1]
    N = 1
    while N < 3 * n:
        N <<= 1
    h = irfft(rfft(a_rev, N) * rfft(p, N), N)[:3*n-1]
    g = 2.0 * h[n-1:2*n-1]
    return g, p, conv


def mirror_descent(a, time_budget=300.0, tau_init=5.0, tau_end=500.0, verbose=False):
    """Mirror descent (multiplicative weights) on the simplex."""
    n = len(a)
    a = np.maximum(a, 0).copy()
    s = float(np.sum(a))
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    it = 0
    eta = 1.0 / np.sqrt(n)
    best_it = 0
    
    while time.monotonic() - start < time_budget:
        elapsed = time.monotonic() - start
        progress = min(1.0, elapsed / time_budget)
        # Anneal tau
        tau = tau_init * (tau_end / tau_init) ** (progress ** 0.5)
        
        g, p, conv = compute_smoothed_gradient(a, tau)
        
        # Normalize gradient for stable exponentiation
        g_mean = float(np.mean(g))
        g_centered = g - g_mean
        
        # Backtracking line search for eta
        for _ in range(20):
            a_new = a * np.exp(-eta * g_centered)
            a_new = np.maximum(a_new, 0)
            s_new = float(np.sum(a_new))
            if s_new < 1e-15:
                eta *= 0.5
                continue
            a_new = a_new / s_new
            
            obj_new = compute_obj(a_new)
            if obj_new < best_obj or obj_new < compute_obj(a):
                a = a_new
                if obj_new < best_obj - 1e-14:
                    best_obj = obj_new
                    best_a = a.copy()
                    best_it = it
                break
            else:
                eta *= 0.5
        
        it += 1
        
        # Periodic eta adjustment
        if it % 200 == 0:
            eta = max(eta * 0.95, 0.01 / np.sqrt(n))
        
        # Stalling detection
        if it - best_it > max(1000, n):
            # Small perturbation
            a = best_a * (1 + 0.01 * np.random.randn(n))
            a = np.maximum(a, 0)
            a = a / a.sum()
            best_it = it
            eta = 1.0 / np.sqrt(n)
    
    return best_a, best_obj


def frank_wolfe(a, time_budget=100.0, K=5, verbose=False):
    """Frank-Wolfe (conditional gradient) method."""
    n = len(a)
    a = np.maximum(a, 0).copy()
    s = float(np.sum(a))
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    it = 0
    
    while time.monotonic() - start < time_budget:
        conv = compute_conv(a)
        # Use top-K peaks for subgradient
        top_idx = np.argsort(conv)[::-1][:K]
        peak_vals = conv[top_idx]
        max_pv = peak_vals[0]
        if max_pv < 1e-15:
            break
        weights = np.exp(5.0 * (peak_vals - max_pv) / max_pv)
        weights /= weights.sum()
        
        # Subgradient
        g = np.zeros(n)
        for w, k in zip(weights, top_idx):
            k = int(k)
            for j in range(n):
                m = k - j
                if 0 <= m < n:
                    g[j] += 2.0 * w * a[m]
        
        # FW step: v = e_{argmin(g)}
        j_min = int(np.argmin(g))
        t = 2.0 / (it + 2.0)
        a_new = (1.0 - t) * a + t * np.eye(n)[j_min]
        
        obj_new = compute_obj(a_new)
        if obj_new < best_obj - 1e-14:
            best_obj = obj_new
            best_a = a_new.copy()
        
        a = a_new
        it += 1
    
    return best_a, best_obj


def build_conv_matrix(a):
    """Build matrix A (2n-1 x n) such that A @ g = conv(a, g)."""
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        r = min(n, 2 * n - 1 - j)
        A[j:j + r, j] = a[:r]
    return A


def solve_lp_minpeak(a, M_target=None):
    """Solve LP: min M s.t. conv(a,g)[k] <= M for all k, sum(g)=1, g>=0."""
    n = len(a)
    a_norm = a / float(np.sum(a))
    A = build_conv_matrix(a_norm)
    
    g = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [A @ g <= M, cp.sum(g) == 1]
    if M_target is not None:
        constraints.append(M <= M_target)
    
    prob = cp.Problem(cp.Minimize(M), constraints)
    
    for solver in [cp.MOSEK, cp.CLARABEL, cp.SCS, cp.ECOS]:
        try:
            prob.solve(solver=solver)
            if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g.value, 0)
                s = float(np.sum(g_val))
                if s > 1e-10:
                    return g_val / s, float(M.value)
            elif prob.status == 'infeasible':
                return None, None
        except Exception:
            continue
    
    return None, None


def lp_polish(a, time_budget=200.0, verbose=False, seed=42):

    n = len(a)
    a = np.maximum(a, 0).copy()
    s = float(np.sum(a))
    if s < 1e-15:
        a = np.ones(n) / n
    else:

    last_t = 0.5

        if g_lp is None:
            break
        
        # Golden section search for optimal blend
        gr = (np.sqrt(5.0) - 1.0) / 2.0
        lo, hi = 0.01, 1.0
        c = hi - gr * (hi - lo)
        d = lo + gr * (hi - lo)
        
        def blend_eval(t):
            a_try = (1.0 - t) * best_a + t * g_lp
            a_try = np.maximum(a_try, 0)
            st = float(np.sum(a_try))
            if st < 1e-15:
                return 1e10
            return compute_obj(a_try / st)

                c = hi - gr * (hi - lo)

            else:

                d = lo + gr * (hi - lo)

        t_opt = (lo + hi) / 2.0

        a_try = np.maximum(a_try, 0)

def resample(a, new_n):
    """Resample to new length via interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, a[0])
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)


def diverse_init(n, rng, mode=0):
    """Generate diverse initializations."""
    if mode == 0:
        a = np.ones(n) / n
    elif mode == 1:
        a = rng.uniform(0, 1, n)
        a /= a.sum()
    elif mode == 2:
        # Bump in center
        x = np.arange(n) / n
        a = np.exp(-((x - 0.5) ** 2) / (2 * 0.2 ** 2))
        a /= a.sum()
    elif mode == 3:
        # Arcsine distribution
        x = np.linspace(-0.999, 0.999, n)
        a = 1.0 / np.sqrt(1 - x**2)
        a /= a.sum()
    elif mode == 4:
        # Two bumps
        x = np.arange(n) / n
        a = np.exp(-((x - 0.3) ** 2) / (2 * 0.1 ** 2)) + np.exp(-((x - 0.7) ** 2) / (2 * 0.1 ** 2))
        a /= a.sum()
    elif mode == 5:
        # Power law
        x = np.linspace(0.01, 1, n)
        a = x ** rng.uniform(-3, 3)
        a /= a.sum()
    elif mode == 6:
        # Triangle
        x = np.arange(n) / n
        a = 1 - np.abs(2 * x - 1)
        a /= a.sum()
    else:
        a = np.ones(n) / n
    return a

"""
Optimizes step function coefficients to minimize 2*n*max(conv(a,a))/(sum(a))^2.
Uses mirror descent (multiplicative weights) with log-sum-exp smoothing,
self-consistent field LP iteration, dual LP formulations, and multi-length search.
Key innovations: multiplicative weights for natural non-negativity, both min-peak
and max-sum LP variants, asymmetric structure exploitation, and adaptive tau annealing.
"""

import numpy as np
import cvxpy as cp
from scipy.fft import rfft, irfft, fft, ifft
import time


def compute_conv(a):
    """Full linear convolution a*a via FFT. Returns array of length 2n-1."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))


def compute_smoothed_gradient(a, tau):
    """Compute gradient of log-sum-exp smoothed max of conv(a,a) w.r.t. a.
    Returns (gradient, softmax_weights, conv)."""
    n = len(a)
    conv = compute_conv(a)
    max_c = float(np.max(conv))
    exp_vals = np.exp(tau * (conv - max_c))
    p = exp_vals / float(np.sum(exp_vals))
    # g_j = 2 * sum_m a[m] * p[j+m] for j=0..n-1
    # = 2 * conv(a_rev, p)[j+n-1]
    a_rev = a[::-1]
    N = 1
    while N < 3 * n:
        N <<= 1
    h = irfft(rfft(a_rev, N) * rfft(p, N), N)[:3 * n - 1]
    g = 2.0 * h[n - 1:2 * n - 1]
    return g, p, conv


def mirror_descent(a, time_budget=200.0, tau_init=5.0, tau_end=500.0, seed=0):
    """Mirror descent (multiplicative weights) on the simplex with adaptive step."""
    n = len(a)
    a = np.maximum(a, 0).copy()
    s = float(np.sum(a))
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    it = 0
    eta = 2.0 / np.sqrt(n)
    best_it = 0
    rng = np.random.default_rng(seed)

    while time.monotonic() - start < time_budget:
        elapsed = time.monotonic() - start
        progress = min(1.0, elapsed / time_budget)
        tau = tau_init * (tau_end / tau_init) ** (progress ** 0.6)

        g, p, conv = compute_smoothed_gradient(a, tau)
        g_centered = g - float(np.mean(g))

        # Backtracking on eta
        accepted = False
        eta_try = eta
        for _ in range(15):
            log_a_new = np.log(np.maximum(a, 1e-300)) - eta_try * g_centered
            # Clip to prevent overflow
            log_a_new = np.clip(log_a_new, -50, 50)
            a_new = np.exp(log_a_new)
            a_new = np.maximum(a_new, 0)
            s_new = float(np.sum(a_new))
            if s_new < 1e-15:
                eta_try *= 0.5
                continue
            a_new = a_new / s_new

            obj_new = compute_obj(a_new)
            if obj_new < best_obj - 1e-15 or (obj_new < compute_obj(a) - 1e-15):
                a = a_new
                if obj_new < best_obj - 1e-14:
                    best_obj = obj_new
                    best_a = a.copy()
                    best_it = it
                eta = eta_try
                accepted = True
                break
            else:
                eta_try *= 0.5

        if not accepted:
            eta *= 0.5

        it += 1

        # Periodic eta refresh
        if it % 500 == 0:
            eta = max(eta, 0.5 / np.sqrt(n))

        # Stalling: perturb and restart
        if it - best_it > max(2000, 2 * n):
            a = best_a * np.exp(rng.normal(0, 0.005, n))
            a = np.maximum(a, 0)
            a = a / a.sum()
            best_it = it
            eta = 2.0 / np.sqrt(n)

    return best_a, best_obj


def build_conv_matrix(a):
    """Build A (2n-1 x n) such that A @ g = conv(a, g)."""
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        r = min(n, 2 * n - 1 - j)
        A[j:j + r, j] = a[:r]
    return A


def solve_lp_minpeak(a):
    """LP: min M s.t. conv(a,g) <= M, sum(g)=1, g>=0."""
    n = len(a)
    a_norm = a / float(np.sum(a))
    A = build_conv_matrix(a_norm)
    g = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [A @ g <= M, cp.sum(g) == 1]
    prob = cp.Problem(cp.Minimize(M), constraints)
    for solver in [cp.MOSEK, cp.CLARABEL, cp.SCS, cp.ECOS]:
        try:
            prob.solve(solver=solver)
            if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g.value, 0)
                s = float(np.sum(g_val))
                if s > 1e-10:
                    return g_val / s, float(M.value)
            elif prob.status == 'infeasible':
                return None, None
        except Exception:
            continue
    return None, None


def solve_lp_maxsum(a, M_bound):

                s = float(np.sum(g_val))
                if s > 1e-10:

    return None, None


def blend_objective(t, a_base, a_candidate):
    """Evaluate objective at blend (1-t)*a_base + t*a_candidate."""
    a_try = (1.0 - t) * a_base + t * a_candidate
    a_try = np.maximum(a_try, 0)
    s_try = float(np.sum(a_try))
    if s_try < 1e-15:
        return 1e10
    return compute_obj(a_try / s_try)


def golden_section(f, lo, hi, max_iter=35, tol=0.01):
    """Golden section search for 1D minimization."""
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    c = hi - gr * (hi - lo)
    d = lo + gr * (hi - lo)
    fc = f(c)
    fd = f(d)
    for _ in range(max_iter):
        if abs(hi - lo) < tol:
            break
        if fc < fd:
            hi, d, fd = d, c, fc
            c = hi - gr * (hi - lo)
            fc = f(c)
        else:
            lo, c, fc = c, d, fd
            d = lo + gr * (hi - lo)
            fd = f(d)
    return (lo + hi) / 2.0

def resample(a, new_n):
    """Resample to new length via interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, a[0])
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)

        return np.ones(n) / n
    a = a / s
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    rng = np.random.default_rng(123)

    patch_sizes = [1, 2, 3, 5]

    while time.monotonic() - start < time_budget:
        improved = False
        for _ in range(n_patches):
            ps = rng.choice(patch_sizes)
            start_idx = rng.integers(0, max(1, n - ps))
            indices = np.arange(start_idx, min(n, start_idx + ps))

            # Try different modifications
            for strategy in ['scale', 'noise', 'zero', 'copy_neighbor']:
                a_try = best_a.copy()
                if strategy == 'scale':
                    factor = rng.uniform(0.3, 2.0)
                    a_try[indices] *= factor
                elif strategy == 'noise':
                    a_try[indices] *= np.exp(rng.normal(0, 0.3, ps))
                elif strategy == 'zero':
                    a_try[indices] = 0
                    if start_idx + ps < n:
                        a_try[indices] = 0.5 * a_try[indices + 1]
                elif strategy == 'copy_neighbor':
                    if start_idx > 0:
                        a_try[indices] = a_try[start_idx - 1: start_idx - 1 + ps]
                    elif start_idx + ps < n:
                        a_try[indices] = a_try[start_idx + ps: start_idx + ps + ps]

                a_try = np.maximum(a_try, 0)
                s_try = float(np.sum(a_try))
                if s_try < 1e-15:
                    continue
                a_try = a_try / s_try
                obj_try = compute_obj(a_try)

                if obj_try < best_obj - 1e-14:
                    best_obj = obj_try
                    best_a = a_try.copy()
                    improved = True
                    break

        if not improved:
            break

    return best_a, best_obj


def propose_candidate(seed=42, budget_s=1500):
    """
    Main search: mirror descent + self-consistent field LP + multi-n exploration.
    """
    start_time = time.monotonic()
    deadline = start_time + float(budget_s) - 20.0

    best_seq = None
    best_score = np.inf
    rng = np.random.default_rng(seed)

    # Load parent
    n_current = 800
    try:
        parent_arr = np.asarray(height_sequence_1, dtype=np.float64)
        parent_arr = np.clip(parent_arr, 0, None)
        if parent_arr.size > 0 and np.isfinite(parent_arr).all():
            s = float(np.sum(parent_arr))
            if s > 0.01:
                parent = parent_arr / s
                obj = compute_obj(parent)
                best_score = obj
                best_seq = parent.copy()
                n_current = parent.size
                print(f"Parent (n={n_current}): obj={obj:.8f}")
    except Exception:
        pass

    if best_seq is None:
        best_seq = np.ones(n_current) / n_current
        best_score = compute_obj(best_seq)
        print(f"Default init (n={n_current}): obj={best_score:.8f}")

    # === Phase 1: Mirror Descent Warmup ===
    print(f"\n=== Phase 1: Mirror Descent (n={n_current}) ===")
    remaining = deadline - time.monotonic()
    p1_budget = min(remaining * 0.2, 200.0)
    if p1_budget > 30:
        a_md, obj_md = mirror_descent(best_seq, time_budget=p1_budget,
                                      tau_init=5.0, tau_end=600.0, seed=0)
        if obj_md < best_score:
            best_score = obj_md
            best_seq = a_md.copy()
            print(f"  MD: obj={best_score:.8f} **")
        else:
            print(f"  MD: obj={obj_md:.8f}")

    # === Phase 2: Self-Consistent Field LP ===
    print(f"\n=== Phase 2: Self-Consistent Field LP ===")
    remaining = deadline - time.monotonic()
    p2_budget = min(remaining * 0.3, 350.0)
    if p2_budget > 40:
        a_scf, obj_scf = self_consistent_field(best_seq, time_budget=p2_budget,
                                               seed=7, verbose=True)
        if obj_scf < best_score:
            best_score = obj_scf
            best_seq = a_scf.copy()
            print(f"  SCF: obj={best_score:.8f} **")
        else:
            print(f"  SCF: obj={obj_scf:.8f}")

    # === Phase 3: LP Polish (both variants) ===
    print(f"\n=== Phase 3: LP Polish ===")
    remaining = deadline - time.monotonic()
    p3_budget = min(remaining * 0.2, 200.0)
    if p3_budget > 30:
        a_lp, obj_lp = lp_polish_both(best_seq, time_budget=p3_budget,
                                      seed=42, verbose=True)
        if obj_lp < best_score:
            best_score = obj_lp
            best_seq = a_lp.copy()
            print(f"  LP: obj={best_score:.8f} **")
        else:
            print(f"  LP: obj={obj_lp:.8f}")

    # === Phase 4: Mirror Descent (high tau) ===
    print(f"\n=== Phase 4: MD High-Tau ===")
    remaining = deadline - time.monotonic()
    p4_budget = min(remaining * 0.1, 80.0)
    if p4_budget > 20:
        a_md2, obj_md2 = mirror_descent(best_seq, time_budget=p4_budget,
                                        tau_init=50.0, tau_end=2000.0, seed=1)
        if obj_md2 < best_score:
            best_score = obj_md2
            best_seq = a_md2.copy()
            print(f"  MD2: obj={best_score:.8f} **")

    # === Phase 5: Multi-n Exploration ===
    print(f"\n=== Phase 5: Multi-n Exploration ===")
    remaining = deadline - time.monotonic()
    n_current = len(best_seq)

    n_options = []
    for delta in [-400, -300, -200, -100, 100, 200, 300, 400, 500, 600]:
        n_try = n_current + delta
        if 300 <= n_try <= 2500 and n_try not in n_options:
            n_options.append(n_try)
    for n_abs in [400, 600, 1000, 1200, 1400, 1600, 2000, 2400]:
        if 300 <= n_abs <= 2500 and n_abs not in n_options:
            n_options.append(n_abs)
    n_options = sorted(n_options)

    for n_try in n_options:
        remaining = deadline - time.monotonic()
        if remaining < 60:
            break

        print(f"  n={n_try} (rem={remaining:.0f}s)")
        a_try = resample(best_seq, n_try)

        alloc1 = min(remaining * 0.12, 30.0)
        if alloc1 > 10:
            a_try, _ = mirror_descent(a_try, time_budget=alloc1,
                                      tau_init=10, tau_end=400, seed=n_try)

        remaining = deadline - time.monotonic()
        alloc2 = min(remaining * 0.1, 50.0)
        if alloc2 > 15:
            a_try, _ = lp_polish_both(a_try, time_budget=alloc2, seed=n_try + 500)

        obj_try = compute_obj(a_try)
        if obj_try < best_score:
            best_score = obj_try
            best_seq = a_try.copy()
            n_current = n_try
            print(f"  ** n={n_try}: obj={best_score:.8f} **")
        else:
            print(f"  n={n_try}: obj={obj_try:.8f}")

    # === Phase 6: Diverse Restarts ===
    print(f"\n=== Phase 6: Diverse Restarts ===")
    remaining = deadline - time.monotonic()

    for r in range(5):
        remaining = deadline - time.monotonic()
        if remaining < 50:
            break

        n_try = max(400, min(2000, n_current + rng.integers(-150, 150)))
        mode = r % 8
        a_try = diverse_init(n_try, rng, mode)

        alloc1 = min(remaining * 0.18, 40.0)
        if alloc1 > 10:
            a_try, _ = mirror_descent(a_try, time_budget=alloc1,
                                      tau_init=10, tau_end=500, seed=100 + r)

        remaining = deadline - time.monotonic()
        alloc2 = min(remaining * 0.12, 40.0)
        if alloc2 > 15:
            a_try, _ = self_consistent_field(a_try, time_budget=alloc2, seed=200 + r)

        obj_try = compute_obj(a_try)
        if obj_try < best_score:
            best_score = obj_try
            best_seq = a_try.copy()
            print(f"  Restart {r} (n={n_try}, mode={mode}): obj={best_score:.8f} **")
        else:
            print(f"  Restart {r} (n={n_try}, mode={mode}): obj={obj_try:.8f}")

    # === Phase 7: Final Polish ===
    print(f"\n=== Phase 7: Final Polish ===")
    remaining = deadline - time.monotonic()
    if remaining > 60:
        alloc = min(remaining * 0.4, 150.0)
        a_final, obj_final = lp_polish_both(best_seq, time_budget=alloc,
                                            seed=999, verbose=True)
        if obj_final < best_score:
            best_score = obj_final
            best_seq = a_final.copy()
            print(f"  Final LP: obj={best_score:.8f} **")

    remaining = deadline - time.monotonic()
    if remaining > 30:
        alloc = min(remaining * 0.25, 60.0)
        a_md_f, obj_md_f = mirror_descent(best_seq, time_budget=alloc,
                                          tau_init=200, tau_end=5000, seed=42)
        if obj_md_f < best_score:
            best_score = obj_md_f
            best_seq = a_md_f.copy()
            print(f"  Final MD: obj={best_score:.8f} **")

    remaining = deadline - time.monotonic()
    if remaining > 20:
        alloc = min(remaining * 0.4, 40.0)
        a_local, obj_local = local_refine(best_seq, time_budget=alloc)
        if obj_local < best_score:
            best_score = obj_local
            best_seq = a_local.copy()
            print(f"  Local: obj={best_score:.8f} **")

    # Final validation
    if best_seq is None:
        best_seq = np.ones(200)
        best_score = compute_obj(best_seq)

    result = [float(max(0.0, min(1000.0, x))) for x in best_seq]
    val = evaluate_sequence(result)
    if val < np.inf:
        best_score = val
    else:
        result = [1.0] * 100

    elapsed = time.monotonic() - start_time
    print(f"\n=== FINAL: n={len(result)}, score={best_score:.8f}, time={elapsed:.1f}s ===")

    return result
