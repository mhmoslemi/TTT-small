- `b_{n-1} = Σ_i a[i] * a[n-1-i] = Σ_i a[i]²`
- So the peak is at k=n-1 with value `Σ a[i]²`.

For the flat sequence, `Σ a[i]² = n * (1/n)² = 1/n`.

For a non-symmetric sequence, `b_{n-1} = Σ a[i] a[n-1-i]`, which could be less than `Σ a[i]²` (by rearrangement inequality, if `a` is sorted, the minimum of `Σ a[i] a[n-1-i]` is when one is increasing and the other is decreasing, i.e., `a[i]` sorted and `a[n-1-i]` is the reverse).

So a "sawtooth" or monotone sequence could have a lower center peak! For example, if `a` is increasing, then `a[i]` and `a[n-1-i]` are "oppositely sorted", and `Σ a[i] a[n-1-i]` is minimized.

But wait, the objective also depends on the other peaks. Let's check: for a monotone sequence, what do the other peaks look like?

For `a = [1, 2, 3, ..., n]` (normalized):
- `b_0 = 1²` (small)
- `b_1 = 1*2 + 2*1 = 4` 
- `b_2 = 1*3 + 2*2 + 3*1 = 10`
- ...
- `b_{n-1} = Σ i*(n+1-i)` (this is the "oppositely sorted" sum)

Actually, for `a_i = i` (i=1,...,n):
`b_k = Σ_i a_i * a_{k+1-i} = Σ_i i * (k+1-i)` (appropriate range)

For k = n-1: `b_{n-1} = Σ_{i=1}^{n} i*(n-i) = n*Σi - Σi² = n*n(n+1)/2 - n(n+1)(2n+1)/6 = n(n+1)(3n - (2n+1))/6 = n(n+1)(n-1)/6 ≈ n³/6`

For k = n-2: `b_{n-2} = Σ_{i=1}^{n-1} i*(n-1-i) = (n-1)*Σi - Σi² (for i=1 to n-1) = (n-1)*(n-1)n/2 - (n-1)n(2n-1)/6`

This is getting complicated. The point is that for a monotone sequence, the peaks might be more "spread out" across different lags, which could reduce the maximum.

```python
import numpy as np
from scipy.optimize import linprog
from scipy.fft import rfft, irfft
import time

def compute_conv(a):
    """Full linear convolution a*a via FFT."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]

def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))

def solve_lp(a):
    """Fast LP: min M s.t. (a*g)_k <= M for all k, sum(g)=1, g>=0.
    Returns (g_opt, M_opt)."""
    n = len(a)
    # Build the convolution matrix A where (A @ g)[k] = (a*g)[k]
    # A[k, j] = a[k-j] if 0 <= k-j < n, else 0
    A = np.zeros((2*n-1, n))
    for j in range(n):
        # A[k, j] = a[k-j] for k = j, j+1, ..., j+n-1
        A[j:j+n, j] = a
    
    # LP variables: [g_0, ..., g_{n-1}, M]
    # Minimize M
    c = np.zeros(n+1)
    c[n] = 1.0
    
    # Inequality: A @ g - M <= 0
    A_ub = np.hstack([A, -np.ones((2*n-1, 1))])
    b_ub = np.zeros(2*n-1)
    
    # Equality: sum(g) = 1
    A_eq = np.zeros((1, n+1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([1.0])
    
    # Bounds: g_i >= 0, M free
    bounds = [(0, None)] * n + [(-np.inf, None)]
    
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                  bounds=bounds, method='highs')
    if res.success:
        g = np.maximum(res.x[:n], 0)
        s = g.sum()
        if s > 1e-15:
            return g / s, float(res.x[n])
    return None, None
```

Let me think about the "peak equalization" idea more carefully.

**Peak Equalization:**
The idea is: after the LP polish converges (the blending parameter t → 0), we're at a local optimum where the LP can't find a direction to reduce the peak. At this point, the top K peaks are likely "clustered" near the maximum. We can try to:
1. Identify the top K peaks
2. Solve a smaller LP that only constrains these K peaks
3. This gives a more aggressive direction that can break the local optimum

Actually, this is what the LP already does (it constrains all peaks, but only the active ones matter). So this might not help.

**Alternative: "Anti-peak" direction**
Instead of finding the direction that minimizes the max correlation with `a`, find the direction that maximizes the minimum correlation with `a` at the peak positions. This is a max-min problem:
```
max t
s.t. (a*g)_k >= t for k in S (peak positions)
     sum(g) = 1, g >= 0
```
This finds the direction that "fills up" the valleys. But this might not help reduce the peaks.

**Alternative: "Balanced" direction**
Find `g` that equalizes the top K peaks when blended:
```
min M
s.t. ((1-t)a + tg * a)_k <= M for k in S
     sum(g) = 1, g >= 0
```

Let me also think about a completely different approach:

**Approach: Direct minimization using the "implicit function" structure**

The objective is `f(a) = 2n * max_k (a*a)_k / (Σa)²`. This is homogeneous of degree 0 in `a` (scaling `a` doesn't change the objective). So we can fix `Σa = 1` and minimize `2n * max_k (a*a)_k`.

Now, `max_k (a*a)_k` is the maximum of `2n-1` quadratic forms. The minimum of this maximum, subject to `a ≥ 0, Σa = 1`, is what we want.

This is a minimax quadratic problem, which is generally non-convex. But we can use the following approach:

**Bisection on the target M:**
For a given target `M_target`, check if there exists `a ≥ 0, Σa = 1` such that `(a*a)_k ≤ M_target` for all k.

This feasibility problem is:
```
(a*a)_k ≤ M_target for all k
Σa = 1
a ≥ 0
```

This is a set of quadratic constraints. We can solve it using:
- Sequential quadratic programming (SQP)
- Penalty methods
- Interior point methods for the quadratically constrained quadratic program (QCQP)

But QCQP is NP-hard in general. However, our specific structure (each constraint is a "convolution" constraint) might make it tractable.

Alternatively, we can use the following iterative approach:
1. Start with a feasible point (e.g., uniform)
2. Linearize the quadratic constraints at the current point
3. Solve the resulting LP (or QP)
4. Update and repeat

This is essentially what the LP polish does, but with a different linearization.

Actually, I realize the LP polish is already doing a form of linearization: it fixes `a` and finds the best `g` such that `(a*g)_k ≤ M`. This is like a first-order approximation of `(a+δg)*(a+δg) ≈ a*a + δ(a*g + g*a)` for small δ.

```python
"""
Optimizes step function coefficients to minimize 2*n*max(conv(a,a))/(sum(a))^2.
Uses fast HiGHS LP polishing with adaptive line search, FFT-based Nesterov smoothed
gradient descent, peak-aware perturbation, and multi-length exploration.
Key improvements over parent: much faster LP (HiGHS vs cvxpy), better line search,
FFT-vectorized gradients, rotating constraint subsets, and tighter time management.

import numpy as np
from scipy.optimize import linprog
from scipy.fft import rfft, irfft, fft, ifft
import time


def compute_conv(a):
    """Full linear convolution a*a via FFT. Returns array of length 2n-1."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    cn = a / s
    conv = compute_conv(cn)
    return 2.0 * n * float(np.max(conv))


def build_conv_mat(a):
    """Build matrix A (2n-1 x n) such that A @ g = conv(a, g)."""
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        A[j:j + n, j] = a
    return A


def solve_lp_full(a):
    """Min M s.t. (a*g)_k <= M for all k, sum(g)=1, g>=0. Returns (g, M)."""
    n = len(a)
    A = build_conv_mat(a)
    c = np.zeros(n + 1)
    c[n] = 1.0
    A_ub = np.empty((2 * n - 1, n + 1))
    A_ub[:, :n] = A
    A_ub[:, n] = -1.0
    b_ub = np.zeros(2 * n - 1)
    A_eq = np.ones((1, n + 1))
    A_eq[0, n] = 0.0
    b_eq = np.array([1.0])
    bounds = [(0, None)] * n + [(-np.inf, None)]
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                  bounds=bounds, method='highs')
    if res.success:
        g = np.maximum(res.x[:n], 0)
        s = g.sum()
        if s > 1e-15:
            return g / s, float(res.x[n])
    return None, None

    return None, None


def lp_polish(a, time_budget, verbose=False, seed=123):
    """Fast LP polishing with adaptive line search and smart perturbation."""
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = float(a.sum())
    if s < 1e-10:
        return a
    a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    rng = np.random.default_rng(seed)
    it = 0
    stall = 0
    last_t = 0.2
    use_reduced = False

    while time.monotonic() - start < time_budget:
        if use_reduced:
            g, M_lp = solve_lp_reduced(a, K=30)
        else:
            g, M_lp = solve_lp_full(a)
        
        if g is None:
            if not use_reduced:
                use_reduced = True
                continue
            else:
                break

        # Adaptive t candidates
        t_vals = [0.02, 0.05, 0.08, 0.1, 0.15, 0.2, 0.3, 0.4, 0.5, 0.7, 1.0,
                  max(0.01, last_t * 0.4), max(0.01, last_t * 0.7),
                  last_t, min(1.0, last_t * 1.4), min(1.0, last_t * 2.0)]
        t_vals = sorted(set([t for t in t_vals if 0.005 <= t <= 1.0]))

        best_t = t_vals[0]
        best_a_try = None
        best_obj_try = best_obj

        for t in t_vals:
            a_try = (1.0 - t) * a + t * g
            a_try = np.maximum(a_try, 0)
            s_try = a_try.sum()
            if s_try < 1e-10:
                continue
            a_try = a_try / s_try
            obj_try = compute_obj(a_try)
            if obj_try < best_obj_try:
                best_obj_try = obj_try
                best_a_try = a_try.copy()
                best_t = t

        it += 1
        if best_a_try is not None:
            a = best_a_try
            best_obj = best_obj_try
            best_a = a.copy()
            last_t = best_t
            stall = 0
            use_reduced = False
            if verbose and it % 10 == 0:
                print(f"    LP it{it}: obj={best_obj:.8f}, t={last_t:.3f}, M={M_lp:.6f}")
        else:
            stall += 1
            # Peak-aware perturbation: perturb positions contributing most to max peak
            conv_a = compute_conv(a)
            max_k = int(np.argmax(conv_a))
            # Positions that contribute to peak at max_k
            i_start = max(0, max_k - (n - 1))
            i_end = min(n - 1, max_k)
            # Perturb these positions more
            pert = rng.normal(0, 0.02, n)
            pert[i_start:i_end + 1] *= 3.0
            a = best_a * np.exp(pert)
            a = np.maximum(a, 0)
            a = a / a.sum()
            if stall > 20 and stall % 5 == 0:
                # Bigger jump
                scale = 0.03 + 0.01 * (stall // 20)
                a = best_a * np.exp(rng.normal(0, scale, n))
                a = np.maximum(a, 0)
                a = a / a.sum()
            if verbose and stall % 10 == 0:
                print(f"    LP stall {stall}: obj={best_obj:.8f}")
            if stall > 60:
                break

    return best_a


def nesterov_smoothed_descent(a, time_budget, tau_init=5.0, tau_end=500.0, verbose=False):
    """Nesterov accelerated gradient descent on smoothed max(conv) over simplex."""
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = a.sum()
    if s < 1e-10:
        return a
    a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()

    beta = 0.85
    lr = 2.5 / np.sqrt(n)
    v = np.zeros(n)
    it = 0
    best_it = 0

    while time.monotonic() - start < time_budget:
        elapsed = time.monotonic() - start
        progress = min(1.0, elapsed / (time_budget * 0.85))
        tau = tau_init * (tau_end / tau_init) ** (progress ** 0.6)

        y = a + beta * v
        y = np.maximum(y, 0)
        s_y = y.sum()
        if s_y < 1e-10:
            y = best_a.copy()
        else:
            y = y / s_y

        # Smoothed gradient via FFT
        conv = compute_conv(y)
        max_c = float(np.max(conv))
        exp_vals = np.exp(tau * (conv - max_c))
        p = exp_vals / float(exp_vals.sum())

        # g[i] = 2 * sum_{j=0}^{n-1} p[i+j] * y[j]
        # Computed via: g = 2 * C[n-1 : 2n-1] where C = ifft(FFT(p) * FFT(y[::-1]))
        N = 1
        while N < 3 * n:
            N <<= 1
        P = fft(p, N)
        Y = fft(y[::-1], N)
        C = ifft(P * Y).real
        g = 2.0 * C[n - 1:2 * n - 1]

        v = beta * v - lr * g
        a_new = y + v
        a_new = np.maximum(a_new, 0)
        s_new = a_new.sum()
        if s_new < 1e-10:
            a_new = best_a.copy()
            v = np.zeros(n)
        else:
            a_new = a_new / s_new

        obj_new = compute_obj(a_new)
        if obj_new < best_obj - 1e-14:
            best_obj = obj_new
            best_a = a_new.copy()
            best_it = it

        a = a_new
        it += 1
        lr = max(1e-8, lr * 0.9998)

        if it - best_it > 20000:
            a = best_a.copy()
            v = np.zeros(n)
            lr = 2.0 / np.sqrt(n) * 0.5
            best_it = it

        if verbose and it % 5000 == 0:
            print(f"    NSD it{it}: obj={best_obj:.8f}, tau={tau:.1f}")

    return best_a


def peak_shave(a, time_budget, verbose=False):
    """Direct peak reduction via subgradient on top-K peaks."""
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = a.sum()
    if s < 1e-10:
        return a
    a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    lr = 0.5 / np.sqrt(n)
    momentum = 0.7
    v = np.zeros(n)
    stall = 0
    K = min(15, n)

    while time.monotonic() - start < time_budget:
        conv = compute_conv(a)
        top_idx = np.argsort(conv)[::-1][:K]
        peak_vals = conv[top_idx]
        max_pv = peak_vals[0]
        if max_pv < 1e-15:
            break
        weights = np.exp((peak_vals - max_pv) * 5.0 / (max_pv + 1e-15))
        weights /= weights.sum()

        # Subgradient: g[i] = sum_k w[k] * 2*a[k-i] (for valid k-i)
        g = np.zeros(n)
        for w, k in zip(weights, top_idx):
            k = int(k)
            i_start = max(0, k - (n - 1))
            i_end = min(n - 1, k)
            if i_start <= i_end:
                j_start = k - i_end
                j_end = k - i_start
                g[i_start:i_end + 1] += w * a[j_start:j_end + 1][::-1]
        g *= 2.0

        v = momentum * v + g
        a_new = a - lr * v
        a_new = np.maximum(a_new, 0)
        s_new = a_new.sum()
        if s_new < 1e-10:
            a = best_a
            continue
        a_new = a_new / s_new

        obj_new = compute_obj(a_new)
        if obj_new < best_obj - 1e-13:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new
            stall = 0
        else:
            stall += 1
            a = best_a
            lr *= 0.8
            v *= 0.5
            if lr < 1e-10:
                break

    return best_a


def resample_sequence(a, new_n):
    """Resample sequence to new length via linear interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, a[0])
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)


def propose_candidate(seed=42, budget_s=1500):

    """

    best_a = None
    best_score = np.inf

    try:
        parent_arr = np.asarray(height_sequence_1, dtype=np.float64)
        parent_arr = np.clip(parent_arr, 0, None)
        if parent_arr.size > 0 and np.isfinite(parent_arr).all():
            s = float(np.sum(parent_arr))
            if s > 0.01:
                best_a = parent_arr / s
                best_score = compute_obj(best_a)
                n_target = parent_arr.size
                print(f"Parent (n={parent_arr.size}): obj={best_score:.8f}")
    except Exception:
        pass

    if best_a is None:
        best_a = np.ones(n_target) / n_target
        best_score = compute_obj(best_a)
        print(f"Default init (n={n_target}): obj={best_score:.8f}")

    # === Phase 3: Second LP Pass (15%) ===

    p3_budget = min(remaining * 0.15, 180.0)
    if p3_budget > 20:
        # Perturb slightly for diversity
```
