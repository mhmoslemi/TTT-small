- This is a 1D problem: minimize max_k (c_k + d_k * a_i + a_i^2 * [k=2i or k=i+i'])
  where c_k and d_k are constants depending on the other coordinates

Actually, for fixed other coordinates, `conv(a,a)_k = a_i^2 * [k=2i is valid] + a_i * (sum of other terms involving a_i) + (constant not involving a_i)`.

More precisely:
`conv(a,a)_k = sum_{i+j=k} a_i a_j`

For a specific coordinate a_m:
- If k = 2m: contributes a_m^2
- If k = m + j (j != m): contributes a_m * a_j
- If k = j + m (j != m): contributes a_j * a_m (same as above)

So for coordinate m:
`conv(a,a)_k = [k=2m] * a_m^2 + a_m * (sum_{j: j+k-m < n, j != m} a_j) + (terms not involving a_m)`

Wait, let me be more careful. `conv(a,a)_k = sum_{i=0}^{k} a_i * a_{k-i}` (with a_i = 0 for i < 0 or i >= n).

The terms involving a_m are:
- i = m: a_m * a_{k-m} (valid if 0 <= k-m < n)
- i = k-m: a_{k-m} * a_m (valid if 0 <= k-m < n, and k-m != m)

So if k-m != m (i.e., k != 2m):
  Contribution = 2 * a_m * a_{k-m} (if 0 <= k-m < n)
  
If k = 2m:
  Contribution = a_m^2

So: `conv(a,a)_k = a_m^2 * [k=2m] + 2*a_m*a_{k-m} * [0<=k-m<n, k!=2m] + C_k`

where C_k is the part not involving a_m.

For the max over k, we want to minimize `max_k (a_m^2 * [k=2m] + 2*a_m*a_{k-m} * [valid, k!=2m] + C_k)`.

This is: `max( a_m^2 + C_{2m},  max_{k != 2m, valid} (2*a_m*a_{k-m} + C_k) )`

= `max( a_m^2 + C_{2m},  2*a_m * max_{k != 2m, valid} a_{k-m} + max_{k != 2m, valid} C_k )`

Wait, that's not right because the max of a sum is not the sum of maxes when they're at different k values.

Let me just define: for each k that a_m affects, the convolution value is a linear (or quadratic) function of a_m. The max of these is what we want to minimize. This is a 1D convex optimization problem (max of linear/quadratic functions is convex).

For each k:
- If k = 2m: f_k(a_m) = a_m^2 + C_{2m} (quadratic, convex)
- If k != 2m and 0 <= k-m < n: f_k(a_m) = 2*a_m*a_{k-m} + C_k (linear in a_m)
- Otherwise: f_k(a_m) = C_k (constant)

The max of these is convex in a_m, and we can find the minimum by bisection or by finding where the subgradient is zero.

The subgradient at a_m is:
- For k = 2m: 2*a_m (if this is the active constraint)
- For k != 2m: 2*a_{k-m} (if this is the active constraint)

At the optimum, the active constraints (those achieving the max) should have "balanced" subgradients.

This is getting complex. Let me just implement a simple version: for each coordinate, do a 1D golden section search over a reasonable range.

Actually, for n=800, doing 800 golden section searches per iteration might be too slow. Let me batch coordinates or use a simpler approach.

**Simpler coordinate descent**: For each coordinate i, compute the current max convolution. Then try a few values of a_i (slightly higher, slightly lower) and pick the best. This is like a stochastic coordinate descent.

OK let me just write the code. I'll combine several techniques and see what works.

Let me also think about efficiency. The main bottleneck is:
1. Computing conv(a,a) - O(n log n) with FFT
2. Solving the LP - O(n^2) or more with dense solvers

For n=800, the LP has 2n-1 = 1599 constraints and n = 800 variables. This should be solvable in < 1 second with a good LP solver.

```python
"""
Optimizes step function coefficients to minimize 2*n*max(conv(a,a))/(sum(a))^2.
Uses adaptive weighted LP polishing, FFT-smoothed gradient descent,
coordinate descent refinement, multi-length exploration, and diverse
structured initializations.
"""

import numpy as np
import cvxpy as cp
from scipy.fft import rfft, irfft, fft, ifft
import time

def compute_conv(a):
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]

def compute_obj(a):
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))

def project_simplex(v):
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    idx = np.arange(1, n + 1)
    cond = u * idx > (cssv - 1.0)
    rho = np.where(cond)[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def build_conv_matrix(a):
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        r = min(n, 2 * n - 1 - j)
        A[j:j + r, j] = a[:r]
    return A

def solve_lp_weighted(a, weights=None, M_target=None):
    """Solve LP: min M s.t. weights[k]*conv(a,g)[k] <= M, sum(g)=1, g>=0."""
    n = len(a)
    a_norm = a / np.sum(a)
    A = build_conv_matrix(a_norm)
    
    if weights is None:
        weights = np.ones(2 * n - 1)
    
    # Scale the matrix by weights
    A_weighted = A * weights[:, np.newaxis]
    
    g = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [A_weighted @ g <= M, cp.sum(g) == 1]
    if M_target is not None:
        constraints.append(M <= M_target)
    
    prob = cp.Problem(cp.Minimize(M), constraints)
    
    for solver in [cp.MOSEK, cp.CLARABEL, cp.SCS, cp.ECOS]:
        try:
            prob.solve(solver=solver)
            if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g.value, 0)
                s = float(np.sum(g_val))
                if s > 1e-10:
                    return g_val / s, float(M.value)
            elif prob.status == 'infeasible':
                return None, None
        except Exception:
            continue
    return None, None

def golden_section_search(f, a_lo, a_hi, tol=0.01, max_iter=40):
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    c = a_hi - gr * (a_hi - a_lo)
    d = a_lo + gr * (a_hi - a_lo)
    fc = f(c)
    fd = f(d)
    for _ in range(max_iter):
        if abs(a_hi - a_lo) < tol:
            break
        if fc < fd:
            a_hi = d
            d = c
            fd = fc
            c = a_hi - gr * (a_hi - a_lo)
            fc = f(c)
        else:
            a_lo = c
            c = d
            fc = fd
            d = a_lo + gr * (a_hi - a_lo)
            fd = f(d)
    return (a_lo + a_hi) / 2.0

def smoothed_gradient_fft(a, tau):
    n = len(a)
    conv = compute_conv(a)
    max_conv = float(np.max(conv))
    if max_conv < 1e-15:
        return np.zeros(n), conv
    exp_vals = np.exp(tau * (conv - max_conv))
    p = exp_vals / float(np.sum(exp_vals))
    N = 1
    while N < 3 * n:
        N <<= 1
    P = fft(p, N)
    A = fft(a, N)
    g_full = ifft(P * np.conj(A)).real
    g = 2.0 * g_full[:n]
    return g, conv

def nesterov_smoothed_descent(a, time_budget=120.0, tau_init=5.0, tau_end=300.0):
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    beta = 0.9
    lr = 3.0 / np.sqrt(n)
    v = np.zeros(n)
    prev_a = a.copy()
    prev_g = None
    it = 0
    best_it = 0
    while time.monotonic() - start < time_budget:
        elapsed = time.monotonic() - start
        progress = min(1.0, elapsed / (time_budget * 0.9))
        tau = tau_init * (tau_end / tau_init) ** (progress ** 0.7)
        y = a + beta * v
        y = np.maximum(y, 0)
        s_y = float(np.sum(y))
        if s_y < 1e-10:
            y = best_a.copy()
        else:
            y = y / s_y
        g, conv = smoothed_gradient_fft(y, tau)
        if prev_g is not None and it % 2 == 0:
            s_vec = y - prev_a
            y_vec = g - prev_g
            ss = float(np.dot(s_vec, s_vec))
            sy = float(np.dot(s_vec, y_vec))
            if ss > 1e-15 and abs(sy) > 1e-12:
                bb_lr = ss / abs(sy)
                lr = 0.5 * lr + 0.5 * min(max(bb_lr, 1e-8), 10.0 / np.sqrt(n))
        v = beta * v - lr * g
        a_new = y + v
        a_new = np.maximum(a_new, 0)
        s_new = float(np.sum(a_new))
        if s_new < 1e-10:
            a_new = best_a.copy()
            v = np.zeros(n)
        else:
            a_new = a_new / s_new
        obj_new = compute_obj(a_new)
        if obj_new < best_obj - 1e-13:
            best_obj = obj_new
            best_a = a_new.copy()
            best_it = it
        prev_a = a.copy()
        prev_g = g.copy()
        a = a_new
        it += 1
        lr = max(1e-8, lr * 0.9999)
        if it - best_it > 30000:
            a = best_a.copy()
            v = np.zeros(n)
            lr = 3.0 / np.sqrt(n) * 0.5
            best_it = it
    return best_a

def lp_polish_weighted(a, time_budget=200.0, verbose=False, seed=42):
    """LP polishing with adaptive weights and golden-section line search."""
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    rng = np.random.default_rng(seed)
    iter_count = 0
    no_improve = 0
    last_t = 0.5
    
    while time.monotonic() - start < time_budget:
        elapsed = time.monotonic() - start
        
        # Compute current convolution and weights
        conv_a = compute_conv(best_a)
        max_conv = float(np.max(conv_a))
        
        # Adaptive weights: tighter constraints at peak positions
        alpha = 1.0 + 0.5 * min(iter_count / 20.0, 1.0)  # increase over time
        weights = 1.0 + alpha * (1.0 - conv_a / max_conv)
        # Normalize weights so that the max weight is 1+alpha (at non-peaks)
        # and min weight is 1 (at peaks)
        
        g_lp, M_lp = solve_lp_weighted(best_a, weights=weights)
        if g_lp is None:
            # Fall back to unweighted
            g_lp, M_lp = solve_lp_weighted(best_a, weights=None)
            if g_lp is None:
                break
        
        # Golden section search
        def blend_obj(t):
            a_try = (1.0 - t) * best_a + t * g_lp
            a_try = np.maximum(a_try, 0)
            s_try = float(np.sum(a_try))
            if s_try < 1e-10:
                return 1e10
            a_try = a_try / s_try
            return compute_obj(a_try)
        
        t_opt = golden_section_search(blend_obj, 0.01, 1.0, tol=0.015, max_iter=35)
        a_try = (1.0 - t_opt) * best_a + t_opt * g_lp
        a_try = np.maximum(a_try, 0)
        a_try = a_try / a_try.sum()
        obj_try = compute_obj(a_try)
        iter_count += 1
        
        if obj_try < best_obj - 1e-14:
            best_obj = obj_try
            best_a = a_try.copy()
            last_t = t_opt
            no_improve = 0
            if verbose and iter_count % 5 == 0:
                print(f"    LPW it{iter_count}: obj={best_obj:.8f}, t={t_opt:.3f}, M={M_lp:.6f}")
        else:
            no_improve += 1
            if no_improve == 2:
                t_small = max(0.01, last_t * 0.2)
                a_try2 = (1.0 - t_small) * best_a + t_small * g_lp
                a_try2 = np.maximum(a_try2, 0)
                a_try2 = a_try2 / a_try2.sum()
                obj_try2 = compute_obj(a_try2)
                if obj_try2 < best_obj - 1e-14:
                    best_obj = obj_try2
                    best_a = a_try2.copy()
                    no_improve = 0
            elif no_improve >= 4:
                scale = 0.005 * min(no_improve, 10)
                a_pert = best_a * np.exp(rng.normal(0, scale, n))
                a_pert = np.maximum(a_pert, 0)
                a_pert = a_pert / a_pert.sum()
                no_improve = 0
                if iter_count > 80:
                    break
    return best_a

def coordinate_descent_polish(a, time_budget=60.0, n_sweeps=3):
    """Coordinate descent: for each coordinate, try local perturbation."""
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    for sweep in range(n_sweeps):
        if time.monotonic() - start > time_budget:
            break
        for i in range(n):
            if time.monotonic() - start > time_budget:
                break
            a_save = a[i]
            best_local = a_save
            best_local_obj = best_obj
            
            # Try a few perturbations
            for delta in [0.5, 0.2, -0.5, -0.2, 1.5, -1.5]:
                a[i] = a_save * (1 + delta * 0.01)
                if a[i] < 0:
                    a[i] = 0
                s_check = float(np.sum(a))
                if s_check < 1e-10:
                    a[i] = a_save
                    continue
                obj_check = compute_obj(a)
                if obj_check < best_local_obj - 1e-14:
                    best_local_obj = obj_check
                    best_local = a[i]
            a[i] = best_local
        
        # Renormalize
        a = a / a.sum()
        obj_check = compute_obj(a)
        if obj_check < best_obj:
            best_obj = obj_check
    
    return a

def resample_sequence(a, new_n):
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, a[0])
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)

def diverse_init(n, rng, mode=0):
    if mode == 0:
        a = np.ones(n) / n
    elif mode == 1:
        a = rng.uniform(0, 1, n)
        a = a / a.sum()
    elif mode == 2:
        # Cosine-based
        x = np.linspace(0, 1, n)
        f = rng.integers(1, 6)
        c = rng.uniform(0.3, 1.0)
        a = (1 + c * np.cos(2 * np.pi * f * x)) ** 2
        a = np.maximum(a, 1e-6)
        a = a / a.sum()
    elif mode == 3:
        # Squared sinusoid
        x = np.linspace(0, 1, n)
        f = rng.integers(1, 5)
        c = rng.uniform(0.5, 1.0)
        a = (1 + c * np.sin(2 * np.pi * f * x)) ** 2
        a = np.maximum(a, 1e-6)
        a = a / a.sum()
    elif mode == 4:
        # Bimodal
        c = rng.uniform(0.2, 0.5)
        x = np.linspace(0, 1, n)
        a = np.exp(-((x - c) ** 2) / (0.02 * c ** 2)) + np.exp(-((x - 1 + c) ** 2) / (0.02 * c ** 2))
        a = a / a.sum()
    elif mode == 5:
        # Arcsine distribution
        x = np.linspace(0.001, 0.999, n)
        a = 1.0 / np.sqrt(x * (1 - x))
        a = a / a.sum()
    elif mode == 6:
        # Power law
        x = np.linspace(0.01, 1, n)
        a = x ** rng.uniform(0.5, 3.0)
        a = a / a.sum()
    elif mode == 7:
        # Multi-frequency
        x = np.linspace(0, 1, n)
        a = np.ones(n)
        for _ in range(3):
            f = rng.integers(1, 8)
            p = rng.uniform(0, 2 * np.pi)
            a += 0.3 * np.sin(2 * np.pi * f * x + p)
        a = np.maximum(a, 0.01)
        a = a / a.sum()
    else:
        a = np.ones(n) / n
    return a
```

```python
"""
Optimizes step function coefficients to minimize 2*n*max(conv(a,a))/(sum(a))^2.
Combines adaptive weighted LP polishing, variance-flattening gradient steps,
FFT-smoothed Nesterov descent, peak-directed subgradient refinement,
diverse structured initializations, and multi-length exploration.

import numpy as np
import cvxpy as cp
from scipy.fft import rfft, irfft, fft, ifft
import time


def compute_conv(a):
    """Full linear convolution a*a via FFT. Returns array of length 2n-1."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))


def project_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    idx = np.arange(1, n + 1)
    cond = u * idx > (cssv - 1.0)
    rho = np.where(cond)[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def build_conv_matrix(a):
    """Build matrix A (2n-1 x n) such that A @ g = conv(a, g)."""
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        r = min(n, 2 * n - 1 - j)
        A[j:j + r, j] = a[:r]
    return A


def solve_lp(a, weights=None, M_target=None):
    """Solve LP: min M s.t. weights[k]*conv(a,g)[k] <= M, sum(g)=1, g>=0."""
    n = len(a)
    a_norm = a / np.sum(a)
    A = build_conv_matrix(a_norm)

    if weights is None:
        A_use = A
    else:
        A_use = A * weights[:, np.newaxis]

    g = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [A_use @ g <= M, cp.sum(g) == 1]
    if M_target is not None:
        constraints.append(M <= M_target)

    prob = cp.Problem(cp.Minimize(M), constraints)

    for solver in [cp.MOSEK, cp.CLARABEL, cp.SCS, cp.ECOS]:
        try:
            prob.solve(solver=solver)
            if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g.value, 0)
                s = float(np.sum(g_val))
                if s > 1e-10:
                    return g_val / s, float(M.value)
            elif prob.status == 'infeasible':
                return None, None
        except Exception:
            continue
    return None, None


def golden_section_search(f, a_lo, a_hi, tol=0.01, max_iter=40):
    """Golden section search for minimum of f on [a_lo, a_hi]."""
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    c = a_hi - gr * (a_hi - a_lo)
    d = a_lo + gr * (a_hi - a_lo)
    fc = f(c)
    fd = f(d)
    for _ in range(max_iter):
        if abs(a_hi - a_lo) < tol:
            break
        if fc < fd:
            a_hi = d
            d = c
            fd = fc
            c = a_hi - gr * (a_hi - a_lo)
            fc = f(c)
        else:
            a_lo = c
            c = d
            fc = fd
            d = a_lo + gr * (a_hi - a_lo)
            fd = f(d)
    return (a_lo + a_hi) / 2.0


def smoothed_gradient_fft(a, tau):
    """Compute gradient of log-sum-exp smoothed max using FFT."""
    n = len(a)
    conv = compute_conv(a)
    max_conv = float(np.max(conv))
    if max_conv < 1e-15:
        return np.zeros(n), conv
    exp_vals = np.exp(tau * (conv - max_conv))
    p = exp_vals / float(np.sum(exp_vals))
    N = 1
    while N < 3 * n:
        N <<= 1
    P = fft(p, N)
    A = fft(a, N)
    g_full = ifft(P * np.conj(A)).real
    g = 2.0 * g_full[:n]
    return g, conv


def variance_gradient(a):
    """Compute gradient of sum_k (conv(a,a)_k - mean)^2 for flattening."""
    n = len(a)
    conv = compute_conv(a)
    C = float(np.mean(conv))
    m = conv - C
    # g_i = 4 * sum_k m_k * a_{k-i} (valid k-i)
    # This is 4 * correlation of m with a
    N = 1
    while N < 3 * n:
        N <<= 1
    M_fft = fft(m, N)
    A_fft = fft(a, N)
    # sum_k m_k * a_{k-i} = ifft(M * conj(A))[i] ... let me verify
    # (m * a_rev)[i] = sum_k m_k * a_rev[i-k] = sum_k m_k * a[k-i]
    # a_rev[j] = a[-j mod N]... actually let's just use cross-correlation
    # sum_k m_k * a_{k-i} is the cross-correlation (m ⋅ a) at lag i
    # In FFT: ifft(fft(m) * conj(fft(a)))[i] = sum_k m[k] * a[k-i] (circular)
    corr = ifft(M_fft * np.conj(A_fft)).real
    g = 4.0 * corr[:n]
    return g, conv


def nesterov_smoothed_descent(a, time_budget=120.0, tau_init=5.0, tau_end=300.0):
    """Nesterov accelerated gradient descent on smoothed objective over simplex."""
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    beta = 0.9
    lr = 3.0 / np.sqrt(n)
    v = np.zeros(n)
    prev_a = a.copy()
    prev_g = None
    it = 0
    best_it = 0

    while time.monotonic() - start < time_budget:
        elapsed = time.monotonic() - start
        progress = min(1.0, elapsed / (time_budget * 0.9))
        tau = tau_init * (tau_end / tau_init) ** (progress ** 0.7)

        y = a + beta * v
        y = np.maximum(y, 0)
        s_y = float(np.sum(y))
        if s_y < 1e-10:
            y = best_a
        else:
            y = y / s_y

        g, conv = smoothed_gradient_fft(y, tau)

        if prev_g is not None and it % 2 == 0:
            s_vec = y - prev_a
            y_vec = g - prev_g
            ss = float(np.dot(s_vec, s_vec))
            sy = float(np.dot(s_vec, y_vec))
            if ss > 1e-15 and abs(sy) > 1e-12:
                bb_lr = ss / abs(sy)
                lr = 0.5 * lr + 0.5 * min(max(bb_lr, 1e-8), 10.0 / np.sqrt(n))

        v = beta * v - lr * g
        a_new = y + v
        a_new = np.maximum(a_new, 0)
        s_new = float(np.sum(a_new))
        if s_new < 1e-10:
            a_new = best_a.copy()
            v = np.zeros(n)
        else:
            a_new = a_new / s_new

        obj_new = compute_obj(a_new)
        if obj_new < best_obj - 1e-13:
            best_obj = obj_new
            best_a = a_new.copy()
            best_it = it

        prev_a = a.copy()
        prev_g = g.copy()
        a = a_new
        it += 1
        lr = max(1e-8, lr * 0.9999)

        if it - best_it > 30000:
            a = best_a.copy()
            v = np.zeros(n)
            lr = 3.0 / np.sqrt(n) * 0.5
            best_it = it

    return best_a

    it = 0

        g, conv = variance_gradient(a)

                lr *= 0.998

def lp_polish_adaptive(a, time_budget=200.0, verbose=False, seed=42):
    """LP polishing with adaptive weights, golden-section line search, and restarts."""
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    rng = np.random.default_rng(seed)
    iter_count = 0
    no_improve = 0
    last_t = 0.5
    best_improve = 0.0

    while time.monotonic() - start < time_budget:
        elapsed = time.monotonic() - start

        # Compute adaptive weights
        conv_a = compute_conv(best_a)
        max_conv = float(np.max(conv_a))
        if max_conv < 1e-15:
            break

        # Weights: tighter at peaks (lower weight = tighter constraint)
        alpha = 0.5 + 1.5 * min(float(iter_count) / 30.0, 1.0)
        normalized_conv = conv_a / max_conv
        weights = 1.0 + alpha * (1.0 - normalized_conv)

        g_lp, M_lp = solve_lp(best_a, weights=weights)
        if g_lp is None:
            g_lp, M_lp = solve_lp(best_a, weights=None)
            if g_lp is None:
                break

        # Golden section search for optimal blend
        def blend_obj(t):
            a_try = (1.0 - t) * best_a + t * g_lp
            a_try = np.maximum(a_try, 0)
            s_try = float(np.sum(a_try))
            if s_try < 1e-10:
                return 1e10
            a_try = a_try / s_try
            return compute_obj(a_try)

        t_opt = golden_section_search(blend_obj, 0.005, 1.0, tol=0.01, max_iter=35)
        a_try = (1.0 - t_opt) * best_a + t_opt * g_lp
        a_try = np.maximum(a_try, 0)
        a_try = a_try / a_try.sum()
        obj_try = compute_obj(a_try)
        iter_count += 1

        improvement = best_obj - obj_try
        if obj_try < best_obj - 1e-14:
            best_obj = obj_try
            best_a = a.try if hasattr(a, 'try') else a_try.copy()
            best_a = a_try.copy()
            last_t = t_opt
            no_improve = 0
            best_improve = max(best_improve, improvement)
            if verbose and (iter_count <= 10 or iter_count % 10 == 0):
                print(f"    LP it{iter_count}: obj={best_obj:.8f}, t={t_opt:.4f}, M={M_lp:.6f}, el={elapsed:.0f}s")
        else:
            no_improve += 1
            if no_improve == 2:
                t_small = max(0.005, last_t * 0.15)
                a_try2 = (1.0 - t_small) * best_a + t_small * g_lp
                a_try2 = np.maximum(a_try2, 0)
                a_try2 = a_try2 / a_try2.sum()
                obj_try2 = compute_obj(a_try2)
                if obj_try2 < best_obj - 1e-14:
                    best_obj = obj_try2
                    best_a = a_try2.copy()
                    no_improve = 0
                else:
                    no_improve += 1
            elif no_improve >= 5:
                # Perturb and try again
                scale = 0.004 * min(no_improve, 12)
                a_pert = best_a * np.exp(rng.normal(0, scale, n))
                a_pert = np.maximum(a_pert, 0)
                a_pert = a_pert / a_pert.sum()
                # Try blending perturbed version
                g_lp2, _ = solve_lp(a_pert, weights=weights)
                if g_lp2 is not None:
                    t_try = 0.3
                    a_try3 = (1.0 - t_try) * best_a + t_try * g_lp2
                    a_try3 = np.maximum(a_try3, 0)
                    a_try3 = a_try3 / a_try3.sum()
                    obj_try3 = compute_obj(a_try3)
                    if obj_try3 < best_obj - 1e-14:
                        best_obj = obj_try3
                        best_a = a_try3.copy()
                        no_improve = 0
                    else:
                        no_improve += 1
                if no_improve >= 8:
                    if verbose and iter_count > 30:
                        print(f"    LP: converging at it{iter_count}, obj={best_obj:.8f}")
                    break

        # Periodic variance-flattening step
        if iter_count % 12 == 6 and elapsed > 30:
            a_flat = variance_flatten(best_a, time_budget=min(15.0, (time_budget - elapsed) * 0.1))
            obj_flat = compute_obj(a_flat)
            if obj_flat < best_obj - 1e-12:
                best_obj = obj_flat
                best_a = a_flat.copy()
                no_improve = 0
                if verbose:
                    print(f"    LP+Var it{iter_count}: obj={best_obj:.8f}")

    return best_a


def subgradient_refine(a, time_budget=80.0, K=5):
    """Subgradient method with top-K peaks and momentum."""
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    lr = 2.0 / np.sqrt(n)
    momentum = 0.7
    v = np.zeros(n)
    stall = 0
    it = 0

    while time.monotonic() - start < time_budget:
        conv = compute_conv(a)
        top_idx = np.argsort(conv)[::-1][:K]
        peak_vals = conv[top_idx]
        max_pv = peak_vals[0]
        if max_pv < 1e-15:
            break
        weights = np.exp((peak_vals - max_pv) * 5.0 / max_pv)
        weights /= weights.sum()

        g = np.zeros(n)
        for w, k in zip(weights, top_idx):
            k = int(k)
            i_start = max(0, k - (n - 1))
            i_end = min(n - 1, k)
            if i_start <= i_end:
                j_start = k - i_end
                j_end = k - i_start
                g[i_start:i_end + 1] += w * a[j_start:j_end + 1][::-1]

        v = momentum * v + g
        a_new = a - lr * v
        a_new = project_simplex(a_new)
        obj_new = compute_obj(a_new)
        if obj_new < best_obj - 1e-13:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new
            stall = 0
        else:
            stall += 1
            if stall > 300:
                lr *= 0.5
                v *= 0.3
                stall = 0
                if lr < 1e-10:
                    break
            else:
                lr *= 0.995
        it += 1

    return best_a


def resample_sequence(a, new_n):
    """Resample sequence to new length via linear interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, a[0])
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)


def diverse_init(n, rng, mode=0):
    """Generate diverse initializations with various structures."""
    if mode == 0:
        a = np.ones(n) / n
    elif mode == 1:
        a = rng.uniform(0, 1, n)
        a = a / a.sum()
    elif mode == 2:
        # Cosine squared
        x = np.linspace(0, 1, n)
        f = rng.integers(1, 6)
        c = rng.uniform(0.3, 1.0)
        a = (1 + c * np.cos(2 * np.pi * f * x)) ** 2
        a = np.maximum(a, 1e-8)
        a = a / a.sum()
    elif mode == 3:
        # Sinusoid squared
        x = np.linspace(0, 1, n)
        f = rng.integers(1, 5)
        c = rng.uniform(0.5, 1.0)
        a = (1 + c * np.sin(2 * np.pi * f * x)) ** 2
        a = np.maximum(a, 1e-8)
        a = a / a.sum()
    elif mode == 4:
        # Bimodal (edges)
        c = rng.uniform(0.1, 0.3)
        x = np.linspace(0, 1, n)
        sigma = rng.uniform(0.02, 0.08)
        a = np.exp(-((x - c) ** 2) / (2 * sigma ** 2)) + np.exp(-((x - 1 + c) ** 2) / (2 * sigma ** 2))
        a = a / a.sum()
    elif mode == 5:
        # Arcsine (U-shaped)
        x = np.linspace(0.001, 0.999, n)
        a = 1.0 / np.sqrt(x * (1 - x) + 1e-8)
        a = a / a.sum()
    elif mode == 6:
        # Power law
        x = np.linspace(0.01, 1, n)
        a = x ** rng.uniform(0.5, 3.0)
        a = a / a.sum()
    elif mode == 7:
        # Multi-frequency
        x = np.linspace(0, 1, n)
        a = np.ones(n)
        for _ in range(3):
            f = rng.integers(1, 8)
            p = rng.uniform(0, 2 * np.pi)
            a += 0.3 * np.sin(2 * np.pi * f * x + p)
        a = np.maximum(a, 0.01)
        a = a / a.sum()
    elif mode == 8:
        # Triangular (inverted)
        x = np.linspace(0, 1, n)
        a = 1.0 - np.abs(2 * x - 1)
        a = a / a.sum()
    elif mode == 9:
        # Two Gaussians
        c1 = rng.uniform(0.1, 0.4)
        c2 = 1.0 - c1
        sig = rng.uniform(0.05, 0.2)
        x = np.linspace(0, 1, n)
        a = np.exp(-((x - c1) ** 2) / (2 * sig ** 2)) + np.exp(-((x - c2) ** 2) / (2 * sig ** 2))
        a = a / a.sum()
    else:
        a = np.ones(n) / n
    return a


def coordinate_polish(a, time_budget=40.0):
    """Simple coordinate descent: try small perturbations of each coordinate."""
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    best_obj = compute_obj(a)
    start = time.monotonic()
    deltas = [0.3, -0.3, 0.8, -0.8, 1.5, -1.5]

    sweeps_done = 0
    while time.monotonic() - start < time_budget:
        improved = False
        for i in range(n):
            if time.monotonic() - start > time_budget:
                break
            a_save = a[i]
            for d in deltas:
                a[i] = max(0.0, a_save * (1.0 + d * 0.01))
                s_chk = float(np.sum(a))
                if s_chk < 1e-10:
                    a[i] = a_save
                    continue
                obj_chk = compute_obj(a)
                if obj_chk < best_obj - 1e-14:
                    best_obj = obj_chk
                    improved = True
                    break
                a[i] = a_save
        a = a / a.sum()
        sweeps_done += 1
        if not improved and sweeps_done > 1:
            break

    return a


def propose_candidate(budget_s=1500):
    """
    Main search combining adaptive LP polishing, variance flattening,
    smoothed gradient descent, multi-length exploration, and diverse
    structured initializations.
    """
    start_time = time.monotonic()
    deadline = start_time + float(budget_s) - 20.0

    best_seq = None
    best_score = np.inf
    rng = np.random.default_rng(42)

    # Load parent
    n_target = 800
    try:
        parent_arr = np.asarray(height_sequence_1, dtype=np.float64)
        parent_arr = np.clip(parent_arr, 0, None)
        if parent_arr.size > 0 and np.isfinite(parent_arr).all():
            s = float(np.sum(parent_arr))
            if s > 0.01:
                parent = parent_arr / s
                obj = compute_obj(parent)
                best_score = obj
                best_seq = parent.copy()
                n_target = parent.size
                print(f"Parent (n={parent.size}): obj={obj:.8f}")
    except Exception:
        pass

    if best_seq is None:
        best_seq = np.ones(n_target) / n_target
        best_score = compute_obj(best_seq)
        print(f"Default init (n={n_target}): obj={best_score:.8f}")

    # === Phase 1: Diverse initializations + quick polish ===
    print(f"\n=== Phase 1: Diverse Init + Quick Polish ===")
    remaining = deadline - time.monotonic()

    candidates = [best_seq.copy()]
    obj_list = [best_score]

    for mode in range(10):
        a_init = diverse_init(n_target, rng, mode)
        obj_init = compute_obj(a_init)
        candidates.append(a_init)
        obj_list.append(obj_init)
        if obj_init < best_score:
            best_score = obj_init
            best_seq = a_init.copy()
            print(f"  Init mode {mode}: obj={obj_init:.8f} **")

    # Sort by objective and polish top 3
    sorted_idx = np.argsort(obj_list)
    for ci in sorted_idx[:3]:
        remaining = deadline - time.monotonic()
        if remaining < 40:
            break
        alloc = min(remaining * 0.12, 50.0)
        if alloc < 10:
            break
        polished = nesterov_smoothed_descent(candidates[ci], time_budget=alloc,
                                             tau_init=5.0, tau_end=200.0)
        obj_p = compute_obj(polished)
        if obj_p < best_score:
            best_score = obj_p
            best_seq = polished.copy()
            print(f"  Phase1 polish cand{ci}: obj={best_score:.8f} **")

    # === Phase 2: Main LP polishing ===
    print(f"\n=== Phase 2: LP Polishing ===")
    remaining = deadline - time.monotonic()
    p2_budget = min(remaining * 0.28, 280.0)
    if p2_budget > 30:
        a_lp = lp_polish_adaptive(best_seq, time_budget=p2_budget, verbose=True, seed=42)
        obj_lp = compute_obj(a_lp)
        if obj_lp < best_score:
            best_score = obj_lp
            best_seq = a_lp.copy()
            print(f"  Phase2 LP: obj={best_score:.8f} **")

    # === Phase 3: Variance flattening ===
    print(f"\n=== Phase 3: Variance Flattening ===")
    remaining = deadline - time.monotonic()
    p3_budget = min(remaining * 0.08, 60.0)
    if p3_budget > 10:
        a_flat = variance_flatten(best_seq, time_budget=p3_budget, verbose=True)
        obj_flat = compute_obj(a_flat)
        if obj_flat < best_score:
            best_score = obj_flat
            best_seq = a_flat.copy()
            print(f"  Phase3 Flatten: obj={best_score:.8f} **")

    # === Phase 4: Second LP round ===
    remaining = deadline - time.monotonic()
    if remaining > 80:
        p4_budget = min(remaining * 0.22, 180.0)
        a_lp2 = lp_polish_adaptive(best_seq, time_budget=p4_budget, verbose=True, seed=123)
        obj_lp2 = compute_obj(a_lp2)
        if obj_lp2 < best_score:
            best_score = obj_lp2
            best_seq = a_lp2.copy()
            print(f"  Phase4 LP2: obj={best_score:.8f} **")

    # === Phase 5: Coordinate polish ===
    remaining = deadline - time.monotonic()
    if remaining > 30:
        p5_budget = min(remaining * 0.06, 40.0)
        a_cd = coordinate_polish(best_seq, time_budget=p5_budget)
        obj_cd = compute_obj(a_cd)
        if obj_cd < best_score:
            best_score = obj_cd
            best_seq = a_cd.copy()
            print(f"  Phase5 Coord: obj={best_score:.8f} **")

    # === Phase 6: Multi-length exploration ===
    print(f"\n=== Phase 6: Multi-length Exploration ===")
    remaining = deadline - time.monotonic()
    n_current = len(best_seq)

    n_options = sorted(set([
        max(400, n_current - 200), max(400, n_current - 100),
        n_current + 100, n_current + 200, n_current + 400,
        1000, 1200, 1500, 2000
    ]))
    n_options = [n for n in n_options if 400 <= n <= 2500 and abs(n - n_current) > 80]

    for n_try in n_options[:5]:
        remaining = deadline - time.monotonic()
        if remaining < 70:
            break
        print(f"  Trying n={n_try} (remaining={remaining:.0f}s)")
        a_try = resample_sequence(best_seq, n_try)

        alloc1 = min(remaining * 0.12, 35.0)
        if alloc1 > 10:
            a_try = nesterov_smoothed_descent(a_try, time_budget=alloc1,
                                              tau_init=10.0, tau_end=200.0)

        remaining = deadline - time.monotonic()
        alloc2 = min(remaining * 0.2, 80.0)
        if alloc2 > 15:
            a_try = lp_polish_adaptive(a_try, time_budget=alloc2, seed=n_try)

        obj_try = compute_obj(a_try)
        if obj_try < best_score:
            best_score = obj_try
            best_seq = a_try.copy()
            n_current = n_try
            print(f"  ** n={n_try}: obj={best_score:.8f} **")
        else:
            print(f"  n={n_try}: obj={obj_try:.8f}")

    # === Phase 7: Perturbation + re-optimize ===
    print(f"\n=== Phase 7: Perturbation ===")
    remaining = deadline - time.monotonic()

    for r in range(6):
        remaining = deadline - time.monotonic()
        if remaining < 45:
            break
        scale = 0.006 + 0.004 * r
        a_pert = best_seq * np.exp(rng.normal(0, scale, len(best_seq)))
        a_pert = np.maximum(a_pert, 0)
        a_pert = a_pert / a_pert.sum()

        alloc = min(remaining * 0.25, 100.0)
        if alloc > 15:
            a_pert = lp_polish_adaptive(a_pert, time_budget=alloc, seed=300 + r)
            obj_pert = compute_obj(a_pert)
            if obj_pert < best_score:
                best_score = obj_pert
                best_seq = a_pert.copy()
                print(f"  Perturb {r} (scale={scale:.4f}): obj={best_score:.8f} **")

    # === Phase 8: Final intensive polish ===
    print(f"\n=== Phase 8: Final Polish ===")
    remaining = deadline - time.monotonic()
    if remaining > 25:
        alloc = min(remaining * 0.65, 150.0)
        a_final = lp_polish_adaptive(best_seq, time_budget=alloc, verbose=True, seed=999)
        obj_final = compute_obj(a_final)
        if obj_final < best_score:
            best_score = obj_final
            best_seq = a_final.copy()
            print(f"  Final LP: obj={best_score:.8f} **")

    # Final subgradient
    remaining = deadline - time.monotonic()
    if remaining > 15:
        alloc = min(remaining * 0.3, 30.0)
        a_sg = subgradient_refine(best_seq, time_budget=alloc, K=5)
        obj_sg = compute_obj(a_sg)
        if obj_sg < best_score:
            best_score = obj_sg
            best_seq = a_sg.copy()
            print(f"  Final SG: obj={best_score:.8f} **")

    # Final validation
    if best_seq is None:
        best_seq = np.ones(200)
        best_score = compute_obj(best_seq)

    result = [float(max(0.0, min(1000.0, x))) for x in best_seq]
    val = evaluate_sequence(result)
    if val < np.inf:
        best_score = val
    else:
        result = [1.0] * 100
        best_score = 2.0

    elapsed = time.monotonic() - start_time
    print(f"\n=== FINAL: n={len(result)}, score={best_score:.8f}, time={elapsed:.1f}s ===")

    return result
```
