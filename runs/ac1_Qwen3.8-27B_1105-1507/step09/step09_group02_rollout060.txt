((1-t)*p + t*g) * ((1-t)*p + t*g) = (1-t)^2 * (p*p) + 2t(1-t) * (p*g) + t^2 * (g*g)

The LP minimizes max(p*g) but doesn't control max(g*g). If g has a very high self-convolution peak, then for large t, the t^2*(g*g) term dominates and makes things worse.

So the optimal t might be very small (like 0.01 or 0.05), giving only tiny improvements per iteration.

**Key improvement**: Instead of blending with a fixed set of t values, do a proper line search. And also, consider modifying the LP to also penalize the self-convolution of g.

Modified LP:
minimize M + lambda * N
subject to (A_p @ g)[k] <= M for all k
(A_g @ g)[k] <= N for all k  [but A_g depends on g, so this is circular!]

This doesn't work directly. But we can approximate:
minimize M + lambda * max_k (g*g)[k]
≈ minimize M + lambda * C (where C is the current max of g*g, which we can estimate)

Or we can use a "trust region" approach:
minimize max_k ((1-t)*p + t*g) * ((1-t)*p + t*g)[k]
subject to sum(g) = 1, g >= 0
for a fixed small t.

For fixed t, this is:
minimize max_k [(1-t)^2 * pp[k] + 2t(1-t) * (A_p @ g)[k] + t^2 * (A_g @ g)[k]]

The last term (A_g @ g)[k] = sum_i g[i]*g[k-i] is quadratic in g, so this is a quadratic minimax problem. Not an LP.

But if t is small, we can drop the quadratic term:
minimize max_k [(1-t)^2 * pp[k] + 2t(1-t) * (A_p @ g)[k]]
= (1-t)^2 * max_k pp[k] + 2t(1-t) * max_k (A_p @ g)[k] (approximately, if the argmax is the same)

This is approximately the same as the original LP (minimize max(A_p @ g)).

So the LP approach is valid for small t. The key is to use small t and many iterations.

But if t is too small, progress is slow. The tradeoff is:
- Large t: fast progress but might overshoot
- Small t: safe but slow

The solution is to use an **adapive t** with line search. At each iteration:
1. Solve LP to get g
2. Try t = 0.1, 0.05, 0.02, 0.01, ... (decreasing)
3. For each t, compute the actual objective of (1-t)*p + t*g
4. Pick the t that gives the best objective
5. If no t improves, perturb and try again

This should be effective. Let me also add a "restart" mechanism: if we're stuck for too long, reset to the best point and try a different perturbation.

Now let me also think about the **gradient-based approach** as a complement to the LP.

The subgradient of f(p) = max_k (p*p)[k] at point p is:
g_sub = (A_{p}^T @ w) / sum(w)

where w_k = 1 if (p*p)[k] = max, else 0 (or a smoothed version).

Actually, more precisely, if S = {k : (p*p)[k] = max}, then any convex combination of {e_k : k in S} is a subgradient direction. The "steepest" subgradient is the one that gives the largest decrease.

For the smoothed version:
w_k = exp(tau * (p*p)[k]) / sum_j exp(tau * (p*p)[j])
g_smooth[j] = 2 * sum_k w_k * p[k-j] (as derived earlier)

This is the gradient of the smoothed objective F_tau(p).

Using Nesterov accelerated gradient descent with this gradient, projected onto the simplex, should give good results.

Let me combine both approaches:
1. Main loop: LP-based direction finding + line search
2. Periodically: Nesterov smoothed GD for a few hundred iterations
3. Perturbation when stuck

"""
Optimizes step function coefficients to minimize 2*n*max(conv(a,a))/(sum(a))^2.
Strategy: LP-based direction finding with adaptive line search, Nesterov 
accelerated smoothed gradient descent, multi-length exploration, and 
adaptive perturbation for escaping local minima.
"""

import numpy as np
from scipy.fft import rfft, irfft
from scipy.sparse import csr_matrix
from scipy.optimize import linprog
import time


def compute_conv(a):
    """Full linear convolution a*a via FFT."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj_normalized(p, n):
    """Compute 2*n*max(conv(p,p)) where p is already normalized (sum=1)."""
    conv = compute_conv(p)
    return 2.0 * n * float(np.max(conv))


def build_conv_matrix_sparse(p):
    """Build sparse matrix A such that A @ g = conv(p, g)."""
    n = len(p)
    rows = []
    cols = []
    vals = []
    for i in range(n):
        # Column i: A[k, i] = p[i] for k in [i, i+n-1] (clipped to [0, 2n-2])
        k_start = i
        k_end = min(i + n, 2 * n - 1)
        for k in range(k_start, k_end):
            rows.append(k)
            cols.append(i)
            vals.append(p[i])
    return csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))


def solve_lp_direction(p):
    """
    Solve LP: minimize M s.t. conv(p, g)[k] <= M, sum(g)=1, g>=0.
    Returns optimal g.
    """
    n = len(p)
    A = build_conv_matrix_sparse(p)
    
    # Variables: [g_0, ..., g_{n-1}, M]
    # Minimize: [0, 0, ..., 0, 1]
    c = np.zeros(n + 1)
    c[-1] = 1.0
    
    # Inequality constraints: G @ x <= h
    # conv(p,g)[k] - M <= 0 for each k  ->  A[k,:] @ g - M <= 0
    # -g_i <= 0 for each i
    n_constraints = (2 * n - 1) + n
    
    G = np.zeros((n_constraints, n + 1))
    h = np.zeros(n_constraints)
    
    # First 2n-1 rows: A @ g - M <= 0
    G[:2*n-1, :n] = A.toarray()
    G[:2*n-1, n] = -1.0
    
    # Last n rows: -g_i <= 0
    G[2*n-1:, :n] = -np.eye(n)
    
    # Equality: sum(g) = 1
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([1.0])
    
    result = linprog(c, A_ub=G, b_ub=h, A_eq=A_eq, b_eq=b_eq, 
                     bounds=[(0, None)] * n + [(None, None)],
                     method='highs')
    
    if result.success:
        g = result.x[:n]
        g = np.maximum(g, 0)
        s = g.sum()
        if s > 1e-10:
            g = g / s
        return g
    return None


def line_search(p, g, n, t_candidates=None):
    """Find best t in [0,1] for blending p and g."""
    if t_candidates is None:
        t_candidates = np.array([0.01, 0.02, 0.03, 0.05, 0.07, 0.1,
                                  0.15, 0.2, 0.3, 0.4, 0.5, 0.7, 1.0])
    
    best_t = 0.0
    best_obj = compute_obj_normalized(p, n)
    
    for t in t_candidates:
        p_try = (1 - t) * p + t * g
        p_try = np.maximum(p_try, 0)
        s = p_try.sum()
        if s < 1e-10:
            continue
        p_try = p_try / s
        obj = compute_obj_normalized(p_try, n)
        if obj < best_obj:
            best_obj = obj
            best_t = t
    
    return best_t, best_obj


def nesterov_smoothed_gd(p, n, time_budget, tau_init=5.0, tau_end=500.0):
    """Nesterov accelerated gradient descent on smoothed objective over simplex."""
    p = p.copy()
    best_p = p.copy()
    best_obj = compute_obj_normalized(p, n)
    start = time.monotonic()
    
    beta = 0.9
    lr = 2.0 / np.sqrt(n)
    v = np.zeros(n)
    prev_p = p.copy()
    
    it = 0
    stall = 0
    
    while time.monotonic() - start < time_budget:
        elapsed = time.monotonic() - start
        progress = min(1.0, elapsed / max(1, time_budget))
        tau = tau_init * (tau_end / tau_init) ** (progress ** 0.8)
        
        # Compute smoothed gradient
        conv = compute_conv(p)
        max_conv = conv.max()
        exp_vals = np.exp(tau * (conv - max_conv))
        w = exp_vals / exp_vals.sum()
        
        # Gradient: g[j] = 2 * sum_k w[k] * p[k-j] (valid k)
        # This is 2 * cross_correlation(w, p)[j]
        # Compute via direct sum (O(n^2)) or FFT
        # For n=800, O(n^2) = 640K which is fine
        grad = np.zeros(n)
        for j in range(n):
            k_start = j
            k_end = min(j + n, 2 * n - 1)
            if k_start < k_end:
                grad[j] = 2.0 * np.dot(w[k_start:k_end], p[k_end - j - 1::-1])
        
        # Nesterov step
        y = p + beta * v
        y = np.maximum(y, 0)
        s_y = y.sum()
        if s_y < 1e-10:
            y = best_p.copy()
        else:
            y = y / s_y
        
        # Recompute gradient at y
        conv_y = compute_conv(y)
        max_conv_y = conv_y.max()
        exp_vals_y = np.exp(tau * (conv_y - max_conv_y))
        w_y = exp_vals_y / exp_vals_y.sum()
        
        grad_y = np.zeros(n)
        for j in range(n):
            k_start = j
            k_end = min(j + n, 2 * n - 1)
            if k_start < k_end:
                grad_y[j] = 2.0 * np.dot(w_y[k_start:k_end], y[k_end - j - 1::-1])
        
        v = beta * v - lr * grad_y
        p_new = y + v
        p_new = np.maximum(p_new, 0)
        s_new = p_new.sum()
        if s_new < 1e-10:
            p_new = best_p.copy()
            v = np.zeros(n)
        else:
            p_new = p_new / s_new
        
        obj_new = compute_obj_normalized(p_new, n)
        if obj_new < best_obj - 1e-14:
            best_obj = obj_new
            best_p = p_new.copy()
            stall = 0
        else:
            stall += 1
            if stall > 5000:
                p = best_p.copy()
                v = np.zeros(n)
                lr *= 0.5
                stall = 0
                if lr < 1e-6:
                    break
        
        prev_p = p
        p = p_new
        it += 1
        lr *= 0.9999
        
        if it % 10000 == 0:
            print(f"    NSD it{it}: obj={best_obj:.8f}, tau={tau:.1f}")
    
    return best_p


def lp_polish(p, n, time_budget, verbose=True):
    """
    Main LP polishing loop with adaptive line search and perturbation.
    """
    p = p.copy()
    best_p = p.copy()
    best_obj = compute_obj_normalized(p, n)
    start = time.monotonic()
    it = 0
    stall = 0
    rng = np.random.default_rng(123)
    last_improve_time = start
    
    t_candidates_coarse = np.array([0.05, 0.1, 0.15, 0.2, 0.3, 0.5, 0.7])
    t_candidates_fine = np.array([0.005, 0.01, 0.02, 0.03, 0.05, 0.07, 0.1])
    
    while time.monotonic() - start < time_budget:
        elapsed = time.monotonic() - start
        if elapsed > time_budget:
            break
        
        g = solve_lp_direction(p)
        if g is None:
            break
        
        # Line search: try coarse first, then fine around best
        best_t, best_t_obj = line_search(p, g, n, t_candidates_coarse)
        
        if best_t > 0:
            # Try fine search around best_t
            fine_candidates = np.concatenate([
                np.array([max(0.001, best_t * 0.5), max(0.001, best_t * 0.7),
                          best_t, min(1.0, best_t * 1.3), min(1.0, best_t * 1.5)]),
                t_candidates_fine
            ])
            fine_t, fine_obj = line_search(p, g, n, fine_candidates)
            if fine_obj < best_t_obj:
                best_t, best_t_obj = fine_t, fine_obj
        
        it += 1
        if best_t_obj < best_obj - 1e-14:
            p_try = (1 - best_t) * p + best_t * g
            p_try = np.maximum(p_try, 0)
            p_try = p_try / p_try.sum()
            best_obj = best_t_obj
            best_p = p_try.copy()
            p = p_try
            stall = 0
            last_improve_time = time.monotonic()
            if verbose and it % 20 == 0:
                print(f"    LP it{it}: obj={best_obj:.8f}, t={best_t:.4f}, time={elapsed:.0f}s")
        else:
            stall += 1
            if stall == 5:
                scale = 0.01
            elif stall == 15:
                scale = 0.03
            elif stall == 30:
                scale = 0.05
            else:
                scale = min(0.1, 0.01 + 0.005 * stall)
            
            p = best_p * np.exp(rng.normal(0, scale, n))
            p = np.maximum(p, 0)
            p = p / p.sum()
            
            if verbose and stall % 10 == 0:
                print(f"    LP it{it}: stuck (stall={stall}), perturbing with scale={scale:.3f}")
            
            if stall > 60:
                # Big restart
                p = best_p * np.exp(rng.normal(0, 0.1, n))
                p = np.maximum(p, 0)
                p = p / p.sum()
                stall = 0
    
    return best_p, best_obj


def resample_sequence(p, new_n):
    """Resample probability vector to new length."""
    n = len(p)
    if n == new_n:
        return p.copy()
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    p_new = np.interp(x_new, x_old, p)
    p_new = np.maximum(p_new, 0)
    s = p_new.sum()
    if s > 1e-10:
        p_new = p_new / s
    else:
        p_new = np.ones(new_n) / new_n
    return p_new

Wait, I have a concern about the LP solver speed. Let me think about this more carefully.

For n=800, the LP has:
- 801 decision variables
- 2399 inequality constraints
- 1 equality constraint

The constraint matrix is mostly dense (the convolution part is (2n-1) x n = 1599 x 800, which is 1.28M entries, but many are zero).

Actually, let me count the non-zeros in the convolution matrix A:
- Row k has non-zeros in columns [max(0, k-n+1), min(k, n-1)]
- Number of non-zeros in row k = min(k+1, n, 2n-1-k)
- Total = sum_{k=0}^{2n-2} min(k+1, n, 2n-1-k)

For k = 0 to n-1: min(k+1, n, 2n-1-k) = k+1 (since k+1 <= n and k+1 <= 2n-1-k when k <= n-1)
For k = n to 2n-2: min(k+1, n, 2n-1-k) = 2n-1-k

Total = sum_{k=0}^{n-1} (k+1) + sum_{k=n}^{2n-2} (2n-1-k)
= n(n+1)/2 + (n-1)n/2
= n^2

So the total non-zeros is n^2 = 640,000 for n=800. This is a very sparse matrix (density = 640K / (1599*800) ≈ 50%).

Hmm, 50% density is not very sparse. Using scipy's linprog with HiGHS should still handle this in a few milliseconds.

Let me also consider: can I avoid the LP entirely and use a purely gradient-based approach that's faster per iteration?

The subgradient method:
1. Compute conv(p, p) (O(n log n) via FFT)
2. Find the argmax (or top-K)
3. Compute subgradient (O(n^2) directly, or O(n log n) with FFT)
4. Take a step and project onto simplex (O(n log n))

Each iteration is O(n^2) or O(n log n), much faster than the LP.

But the subgradient method is slower to converge. The LP gives the "best" direction in one shot.

I think the best strategy is:
- Use the LP for the main optimization (it's the most effective per iteration)
- Use gradient descent for fine-tuning between LP calls
- The LP should take ~10-50ms per call, allowing ~30000-150000 iterations in 1500 seconds

Let me also think about an alternative: instead of solving the full LP, I could solve a "reduced" LP with only the top-K active constraints. This would be much faster.

The "active set" approach:
1. At the current point p, identify the top-K peaks of conv(p, p)
2. Solve the LP with only those K constraints (plus g >= 0, sum(g) = 1)
3. Check if the solution satisfies the other constraints

Optimizes step function coefficients to minimize 2*n*max(conv(a,a))/(sum(a))^2.
Strategy: Reduced-constraint LP direction finding with adaptive line search,
Nesterov accelerated smoothed gradient descent with FFT-accelerated gradients,
multi-length exploration, and adaptive perturbation for local minimum escape.
"""

import numpy as np
from scipy.fft import rfft, irfft, fft, ifft
from scipy.sparse import csr_matrix
from scipy.optimize import linprog
import time


def compute_conv(a):
    """Full linear convolution a*a via FFT. Returns array of length 2n-1."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(np.asarray(a, dtype=np.float64), size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(p, n):
    """Compute 2*n*max(conv(p,p)) for normalized p (sum=1)."""
    conv = compute_conv(p)
    return 2.0 * n * float(np.max(conv))


def compute_smoothed_grad(p, w, n):
    """
    Compute gradient of smoothed max: grad[j] = 2 * sum_k w[k]*p[k-j].
    Uses FFT for O(n log n) computation.
    """
    N = 1
    while N < 3 * n:
        N <<= 1
    W = fft(w, N)
    P = fft(p, N)
    cross = ifft(W * np.conj(P)).real
    return 2.0 * cross[:n]


def project_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    idx = np.arange(1, n + 1)
    cond = u * idx > (cssv - 1.0)
    rho_arr = np.where(cond)[0]
    if len(rho_arr) == 0:
        return np.ones(n) / n
    rho = rho_arr[-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def line_search_obj(p, g, n, t_vals):

    best_obj = compute_obj(p, n)
    for t in t_vals:

        p_try = (1.0 - t) * p + t * g

        obj = compute_obj(p_try, n)
        if obj < best_obj:

            best_t = t
    return best_t, best_obj
