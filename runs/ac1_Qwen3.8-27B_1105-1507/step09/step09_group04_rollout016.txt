"""
Optimizes step function coefficients to minimize 2*n*max(conv(a,a))/(sum(a))^2.
Uses improved coordinate descent, LP-based direction with exact line search,
adaptive perturbation, and multi-length exploration.
"""

import numpy as np
from scipy.fft import rfft, irfft
import time
import cvxpy as cp


def compute_conv(a):
    """Full linear convolution a*a via FFT. Returns array of length 2n-1."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))


def coord_descent(a, time_budget=100.0, rng=None, verbose=False, start_time=None):

    S = float(np.sum(a))
    if S < 1e-10:
        a = np.ones(n) / n
        return a
    a = a / S
    conv = compute_conv(a)

    best_obj = float(np.max(conv))
    best_a = a.copy()
    gr = (np.sqrt(5) - 1) / 2.0
    stagnant = 0
    sweep = 0

    while time.monotonic() - start_time < time_budget:

        a = np.ones(n) / n
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    
    # Build convolution matrix A (2n-1 x n)
    # A[k, j] = a_norm[j] if k-j is in [0, n-1], where the convolution position is k
    # Actually: conv(a, g)[k] = sum_j a[j] * g[k-j]
    # So A[k, j] = a[j] if 0 <= k-j <= n-1, i.e., k-(n-1) <= j <= k
    # A is (2n-1) x n
    A = np.zeros((2 * n - 1, n))

**Alternative: Use the fact that the problem has a "bilinear" structure**

The objective is 2n * max_k (a^T Q_k a) / (1^T a)^2 where Q_k is the Toeplitz matrix for position k.

If we let p = a / ||a||_1 (so ||p||_1 = 1), then the objective is 2n * max_k p^T Q_k p.

We want to minimize max_k p^T Q_k p over the simplex.

This is a "minimax" problem. One approach is the von Neumann minimax theorem, but it requires convexity which we don't have.

Another approach: **Iterative row/column scaling**. If we think of the vector p as defining a "distribution" and the matrix Q_k as defining a "bilinear form", we can try to equalize the values p^T Q_k p across all k.

**Algorithm: Equiripple design**
1. Start with p = uniform.
2. Compute r[k] = p^T Q_k p for all k.
3. Let M = max(r).
4. For each k, the "excess" is r[k] - 1/(2n-1) (the target value if all were equal).
5. Adjust p to reduce the excess at the peak positions.

This is essentially what the coordinate descent does, but we can make it more systematic.
