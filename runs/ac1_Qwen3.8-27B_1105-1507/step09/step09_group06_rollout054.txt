        valid = (idx >= 0) & (idx < n)
        c[valid] += 2.0 * a[idx[valid]]
        
        # Water filling
        x_new = water_filling(c, lam_current, target=1.0)
        
        # Ensure non-negative and normalized
        x_new = np.maximum(x_new, 0)
        s_new = float(np.sum(x_new))
        if s_new < 1e-10:
            x_new = best_a.copy()
        else:
            x_new = x_new / s_new
        
        obj_new = compute_obj(x_new)
        
        if obj_new < best_obj - 1e-14:
            best_obj = obj_new
            best_a = x_new.copy()
            no_improve = 0
        else:
            no_improve += 1
            # Blend back towards best
            t = min(0.5, 0.1 * no_improve)
            x_new = (1 - t) * x_new + t * best_a
            x_new = np.maximum(x_new, 0)
            s_blend = float(np.sum(x_new))
            if s_blend > 1e-10:
                x_new = x_new / s_blend
        
        a = x_new
        it += 1
        
        # Adaptive lambda
        if it % 100 == 0:
            lam_current = lam * (1.0 + 0.1 * np.sin(it / 50.0))
        
        if no_improve > 50:
            # Restart with perturbation
            a = best_a.copy()
            noise = rng.normal(0, 0.01, n)
            a = a * np.exp(noise)
            a = np.maximum(a, 0)
            a = a / a.sum()
            no_improve = 0
        
        if verbose and it % 200 == 0:
            elapsed = time.monotonic() - start
            print(f"    DCA it{it}: obj={best_obj:.8f}, k*={k_star}, lam={lam_current:.2f}, t={elapsed:.0f}s")
    
    return best_a

Let me think about the spectral approach more carefully:

If we want to minimize the peak of the autocorrelation, in the frequency domain this means we want the power spectrum |A(omega)|^2 to be as flat as possible (since the peak of the autocorrelation is the DC component of |A(omega)|^2, and the other values are related to the other Fourier coefficients of |A(omega)|^2).

Wait, actually:

- Power spectrum P[omega] = |sum_i a[i] e^{-i*omega*i}|^2 = |A(omega)|^2

r[k] for k != 0 are the other Fourier coefficients of P.

We want to minimize max_k r[k]. Since r[0] = sum(a[i]^2) is the "energy", and the other r[k] should be small, we essentially want to minimize the "side lobes" of the autocorrelation.

- DMFS (Difference of Multi-Step Filters)

For continuous (non-constant-amplitude) sequences, the problem is even more flexible.

**Spectral Flattening Algorithm**:

2. Compute P = |A|^2 (power spectrum)

4. Reduce the excess: A_new[omega] = A[omega] * (1 - eta * excess[omega] / P[omega])
5. a_new = IFFT(A_new)
6. Project a_new to non-negative and sum=1
7. Repeat
