Let me try **coordinate descent**:

For coordinate `i`, the objective (center peak) as a function of `a[i]` is:
`f(a[i]) = a[i]^2 * (if i = n-1-i) + 2 * a[i] * a[n-1-i] + (constant)`

If `i = n-1-i` (i.e., `i = (n-1)/2`, only possible for odd n):
`f(a[i]) = a[i]^2 + C` (quadratic)

So for most coordinates, the objective is **linear** in that coordinate! This means the optimal solution is at the boundary (either 0 or as large as possible).

This is a crucial insight! For even `n` (or when `i != n-1-i`), the objective is linear in `a[i]`, so the optimum is at `a[i] = 0` (if the coefficient is positive) or `a[i]` as large as possible (if the coefficient is negative).

The coefficient of `a[i]` in the center peak is `2 * a[n-1-i]`. Since `a[n-1-i] >= 0`, the coefficient is always non-negative. So the optimum (for the center peak alone) is `a[i] = 0` for all `i`!

But that's not feasible (sum must be 1). So the constraint `sum(a) = 1` is binding, and the problem becomes:
- Minimize `sum_i a[i]*a[n-1-i]` subject to `sum(a) = 1`, `a >= 0`.

Since the coefficient of `a[i]` is `a[n-1-i]` (for `i != n-1-i`), we want to put mass where `a[n-1-i]` is small. This creates a feedback: we want `a[i]` large where `a[n-1-i]` is small, and vice versa.

This suggests an **alternating minimization**:
1. Fix all coordinates except `i`. Set `a[i] = 0` (or the minimum allowed by the sum constraint).
2. Redistribute the freed mass to coordinates `j` where `a[n-1-j]` is smallest.
3. Repeat.

But this ignores the other convolution coefficients (which also need to be bounded).

**Approach: Iterative proportional fitting / Sinkhorn-like method.**

1. Start with `a = uniform`.
2. Compute `conv = a * a`.
