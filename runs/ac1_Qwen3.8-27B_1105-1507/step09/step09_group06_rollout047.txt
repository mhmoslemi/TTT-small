    # Let me use: c_i = sum_{j=0}^{n-1} p_{i+j} * a_j

    # flip p: p_flip[k] = p[2n-2-k]

    # Then (q * r)[i] = sum_k q[k] r[i-k] = sum_k p[k] a[i-k]
    # We want sum_j p[i+j] a[j] = sum_j p[i+j] a[j]
    # Let m = i+j, so j = m-i: sum_m p[m] a[m-i] (for valid m, m-i)
    # = sum_m p[m] a[m-i] = (p * a_flip)[?] ... 
    #
    # Actually, the simplest way: 
    # c_i = sum_{j=0}^{n-1} p_{i+j} a_j
    # This is the cross-correlation of p and a at lag i (p leads by i).
    # In scipy: scipy.signal.correlate(p, a, mode='full')[n-1+i] gives this.
    # Or via FFT: 
    #   Let P_freq = FFT(p, N), A_freq = FFT(a, N)
    #   cross_corr = IFFT(P_freq * conj(A_freq))
    #   Then c_i = cross_corr[n-1+i] (with appropriate indexing)
    #
    # Let me just use the direct formula with ifft:
    #   c = ifft(fft(p, N) * conj(fft(a, N)))  -- this gives circular cross-correlation
    #   c[i] = sum_j p[(i+j) mod N] * a[j] (approximately, with N large enough)
    
    cross = ifft(fft(p, N) * np.conj(fft(a, N))).real
    # cross[i] = sum_j p[(i+j) % N] * a[j]
    # For i = 0, ..., n-1, and since p has support [0, 2n-2] and a has support [0, n-1],
    # p[(i+j) % N] = p[i+j] when i+j < N (which is true since i+j <= (n-1)+(n-1) = 2n-2 < N)
    # So cross[i] = sum_j p[i+j] * a[j] = c_i. 
    
    grad = 2.0 * cross[:n]  # gradient of smoothed max of conv
    
    obj = log_sum_exp / tau  # This is the smoothed max
    # Actually, the smoothed objective is (1/tau) * log(sum(exp(tau * conv_k)))
    # = max_conv + (1/tau) * log(sum(exp(tau*(conv - max_conv))))
    
    return obj, grad

Wait, I need to double-check the FFT cross-correlation formula.

The circular cross-correlation of two signals $x$ and $y$ of length $N$ is:
$(x \star y)[i] = \sum_{j=0}^{N-1} x[(i+j) \mod N] \cdot y[j]$

And $\text{FFT}(x \star y) = \text{FFT}(x) \cdot \overline{\text{FFT}(y)}$.

So $x \star y = \text{IFFT}(\text{FFT}(x) \cdot \overline{\text{FFT}(y)})$.

With $x = p$ (padded to $N$) and $y = a$ (padded to $N$):
$(p \star a)[i] = \sum_{j=0}^{N-1} p[(i+j) \mod N] \cdot a[j]$

Since $p$ is non-zero only for $j = 0, ..., 2n-2$ and $a$ is non-zero only for $j = 0, ..., n-1$:
$(p \star a)[i] = \sum_{j=0}^{n-1} p[(i+j) \mod N] \cdot a[j]$

For $i = 0, ..., n-1$ and $j = 0, ..., n-1$: $i + j \leq 2n - 2 < N$ (since $N \geq 3n$), so $(i+j) \mod N = i+j$.

Therefore: $(p \star a)[i] = \sum_{j=0}^{n-1} p[i+j] \cdot a[j] = c_i$. ✓

Great, so the formula is correct.

Now, for the L-BFGS approach, I need to handle the simplex constraint. The simplest way is to use the "log-sum-exp reparameterization": let $a_i = \exp(\theta_i) / \sum_j \exp(\theta_j)$, and optimize over $\theta$. But this adds $n$ parameters and the gradient needs the chain rule.

Alternatively, I can use scipy.optimize.minimize with method='L-BFGS-B' and bounds, but I need to handle the constraint $\sum a_i = 1$. I can fix one variable (say $a_0 = 1 - \sum_{i=1}^{n-1} a_i$) and optimize over the remaining $n-1$ variables.

Actually, the cleanest approach for L-BFGS with the simplex constraint is:
1. Parametrize $a_i = \exp(\theta_i) / Z$ where $Z = \sum_j \exp(\theta_j)$.
2. The gradient with respect to $\theta$ is: $\nabla_{\theta_i} f = (a_i - a_i^2) \cdot (g_i - \sum_j a_j g_j)$ where $g = \nabla_a f$.

Wait, let me derive this. Let $f(a(\theta))$ be the objective. Then:
$\frac{\partial f}{\partial \theta_i} = \sum_j \frac{\partial f}{\partial a_j} \frac{\partial a_j}{\partial \theta_i}$

$\frac{\partial a_j}{\partial \theta_i} = \frac{\delta_{ji} Z - a_j \exp(\theta_i)}{Z^2} = a_j (\delta_{ji} - a_i)$

So $\frac{\partial f}{\partial \theta_i} = \sum_j g_j a_j (\delta_{ji} - a_i) = g_i a_i - a_i \sum_j g_j a_j = a_i (g_i - \langle g, a \rangle)$

where $g = \nabla_a f$.

This is clean. Let me use this parametrization.

But wait, there's a subtlety: the smoothed objective $f_\tau(a) = \frac{1}{\tau} \log \sum_k \exp(\tau (a*a)_k)$ is defined for $a$ on the simplex. When we reparametrize, we're optimizing over $\theta \in \mathbb{R}^n$, and the mapping $\theta \mapsto a(\theta)$ is a diffeomorphism from $\mathbb{R}^n / \mathbb{R} \cdot 1$ to the interior of the simplex. The gradient formula above is correct.

However, L-BFGS doesn't handle the redundancy well (adding a constant to all $\theta_i$ doesn't change $a$). I can fix $\theta_0 = 0$ to remove the redundancy, or just let L-BFGS handle it (it usually works fine in practice since the Hessian is positive semi-definite but not degenerate in practice).

Let me also think about a key insight: the LP solution $g^*$ for a given $a$ is the solution to:
$\min_g \max_k (a*g)_k$ s.t. $g \geq 0, \sum g = 1$.

The optimal $g^*$ has the property that it "flattens" the cross-correlation $a * g^*$. If we then set $a = g^*$, the next LP will try to flatten $g^* * g^{**}$. This is like an iterative "flattening" process.

The key question is: does this converge to the global optimum of $\min_a \max_k (a*a)_k$? Not necessarily, but it often makes good progress.

One improvement: instead of a fixed blend $a \leftarrow (1-t)a + tg^*$, use the **Frank-Wolfe** step size:
$\gamma^* = \arg\min_{\gamma \in [0,1]} f((1-\gamma)a + \gamma g^*)$

This is a 1D line search that can be done efficiently.

Another improvement: use the **pairwise conditional gradient** method (PCG), which is more efficient than standard FW for large $n$.

"""
Optimizes step function coefficients using L-BFGS on log-sum-exp smoothed objective,
LP-based block coordinate descent, and multi-scale exploration.
Key differences from previous: scipy L-BFGS with softmax reparameterization,
golden-section LP blending, adaptive multi-temperature schedule.

import numpy as np
from scipy.fft import rfft, irfft, fft, ifft
from scipy.optimize import minimize, brewer_golden
import cvxpy as cp
import time


def compute_conv(a):
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 1e-10:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))


def softmax(a):
    a = a - np.max(a)
    e = np.exp(a)
    return e / np.sum(e)


def lBFGS_smoothed(a_init, tau, time_budget=60.0, verbose=False, seed=0):
    """
    Run L-BFGS-B on the log-sum-exp smoothed objective using softmax reparameterization.
    a_init: initial point on the simplex
    tau: smoothing parameter
    """
    n = len(a_init)
    a_init = np.maximum(a_init, 1e-15)
    a_init = a_init / np.sum(a_init)
    
    # Initial theta
    theta0 = np.log(a_init + 1e-15)
    theta0 -= np.mean(theta0)  # center
    
    best_a = a_init.copy()
    best_obj = compute_obj(a_init)
    start = time.monotonic()
    
    def obj_grad(theta):
        elapsed = time.monotonic() - start
        if elapsed > time_budget:
            raise RuntimeError("time budget exceeded")
        
        a = softmax(theta)
        conv = compute_conv(a)
        max_conv = float(np.max(conv))
        
        # Smoothed objective
        exp_vals = np.exp(tau * (conv - max_conv))
        log_sum = max_conv + np.log(np.sum(exp_vals))
        obj = log_sum / tau
        
        # Gradient wrt a
        p = exp_vals / np.sum(exp_vals)
        N = 1
        while N < 3 * n:
            N <<= 1
        P = fft(p, N)
        A = fft(a, N)
        cross = ifft(P * np.conj(A)).real
        g_a = 2.0 * cross[:n]
        
        # Gradient wrt theta: a_i * (g_a_i - sum(a * g_a))
        ag = float(np.dot(a, g_a))
        g_theta = a * (g_a - ag)
        
        return obj, g_theta
    
    try:
        result = minimize(obj_grad, theta0, method='L-BFGS-B',
                         options={'maxiter': 5000, 'ftol': 1e-15, 'gtol': 1e-12,
                                  'maxfun': 5000, 'disp': False})
    except Exception as e:
        if verbose:
            print(f"  L-BFGS error: {e}")
        return best_a
    
    # Check if we improved
    if result.fun < np.inf:
        theta_opt = result.x
        a_opt = softmax(theta_opt)
        obj_opt = compute_obj(a_opt)
        if obj_opt < best_obj:
            best_obj = obj_opt
            best_a = a_opt
    
    return best_a


def solve_lp_minpeak(a):
    """Solve LP: min M s.t. conv(a,g)[k] <= M, sum(g)=1, g>=0."""
    n = len(a)
    a_norm = a / np.sum(a)
    
    # Build constraint matrix
    # (a * g)[k] = sum_i a[i] * g[k-i] <= M for k = 0, ..., 2n-2
    # Coefficient of g[j] in constraint k: a[k-j] if 0 <= k-j < n, else 0
    # So A[k, j] = a[k-j] if 0 <= k-j < n
    
    A_mat = np.zeros((2 * n - 1, n))
    for k in range(2 * n - 1):
        j_start = max(0, k - (n - 1))
        j_end = min(n - 1, k)
        for j in range(j_start, j_end + 1):
            A_mat[k, j] = a_norm[k - j]
    
    g = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [A_mat @ g <= M, cp.sum(g) == 1]
    prob = cp.Problem(cp.Minimize(M), constraints)
    
    for solver in [cp.CLARABEL, cp.PDLP, cp.ECOS, cp.SCS, cp.MOSEK]:
        try:
            prob.solve(solver=solver)
            if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g.value, 0)
                s = float(np.sum(g_val))
                if s > 1e-10:
                    return g_val / s, float(M.value)
        except Exception:
            continue
    return None, None


def lp_step_golden(a, time_budget=30.0, verbose=False):
    """
    One LP step with golden section search for optimal blend.
    """
    n = len(a)
    a = a / np.sum(a)
    
    g_lp, M_lp = solve_lp_minpeak(a)
    if g_lp is None:
        return a, compute_obj(a)
    
    # Golden section search for optimal t in [0, 1]
    def f_of_t(t):
        a_try = (1.0 - t) * a + t * g_lp
        a_try = np.maximum(a_try, 0)
        s = float(np.sum(a_try))
        if s < 1e-10:
            return np.inf
        a_try = a_try / s
        return compute_obj(a_try)
    
    # Golden section
    gr = (np.sqrt(5) - 1) / 2  # golden ratio conjugate
    a_lo, a_hi = 0.0, 1.0
    c = a_hi - gr * (a_hi - a_lo)
    d = a_lo + gr * (a_hi - a_lo)
    fc, fd = f_of_t(c), f_of_t(d)
    
    start = time.monotonic()
    for _ in range(30):  # ~30 iterations for high precision
        if time.monotonic() - start > time_budget:
            break
        if fc < fd:
            a_hi = d
            d = c
            fd = fc
            c = a_hi - gr * (a_hi - a_lo)
            fc = f_of_t(c)
        else:
            a_lo = c
            c = d
            fc = fd
            d = a_lo + gr * (a_hi - a_lo)
            fd = f_of_t(d)
    
    t_opt = (a_lo + a_hi) / 2
    a_new = (1.0 - t_opt) * a + t_opt * g_lp
    a_new = np.maximum(a_new, 0)
    a_new = a_new / a_new.sum()
    
    return a_new, compute_obj(a_new)


def lp_descent(a, time_budget=300.0, verbose=False, seed=0):
    """
    LP-based block coordinate descent with golden section blending.
    """
    n = len(a)
    a = np.maximum(a, 0).copy()
    a = a / a.sum()
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    consecutive_fails = 0
    
    while time.monotonic() - start < time_budget:
        alloc = min(30.0, time_budget - (time.monotonic() - start))
        if alloc < 5:
            break
        
        a_new, obj_new = lp_step_golden(a, time_budget=alloc)
        
        if obj_new < best_obj - 1e-14:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new.copy()
            consecutive_fails = 0
            if verbose:
                print(f"    LP: obj={best_obj:.8f}, t={time.monotonic()-start:.0f}s")
        else:
            consecutive_fails += 1
            if consecutive_fails > 20:
                break
    
    return best_a


def multi_tau_lBFGS(a, time_budget=300.0, verbose=False, seed=0):

    Run L-BFGS with multiple tau values, from smooth to sharp.
    """
    n = len(a)
    a = np.maximum(a, 1e-15).copy()
    a = a / a.sum()
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    # Increasing tau schedule
    taus = [5, 10, 20, 50, 100, 200, 500, 1000]
    
    for tau in taus:
        remaining = time_budget - (time.monotonic() - start)
        if remaining < 20:
            break
        
        alloc = min(remaining * 0.3, 60.0)
        if alloc < 10:
            alloc = min(remaining, 30.0)
        
        a_new = lBFGS_smoothed(best_a, tau=tau, time_budget=alloc,
                               verbose=verbose, seed=seed)
        obj_new = compute_obj(a_new)
        
        if obj_new < best_obj - 1e-14:
            best_obj = obj_new
            best_a = a_new.copy()
            if verbose:
                print(f"    L-BFGS tau={tau}: obj={best_obj:.8f}")
        else:
            # Try from current a (not best) to escape
            a_try = lBFGS_smoothed(a, tau=tau, time_budget=alloc,
                                   verbose=False, seed=seed + tau)
            obj_try = compute_obj(a_try)
            if obj_try < best_obj:
                best_obj = obj_try
                best_a = a_try.copy()
            a = a_try  # continue from here
    
    return best_a


def perturb(a, scale=0.05, seed=0):
    """Gaussian perturbation with re-normalization."""
    rng = np.random.default_rng(seed)
    noise = rng.normal(0, 1, len(a)) * scale
    a_new = a * np.exp(noise)
    a_new = np.maximum(a_new, 0)
    s = float(np.sum(a_new))
    if s > 1e-10:
        a_new = a_new / s
    else:
        a_new = a.copy()
    return a_new


def resample(a, new_n):
    """Resample via linear interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)
