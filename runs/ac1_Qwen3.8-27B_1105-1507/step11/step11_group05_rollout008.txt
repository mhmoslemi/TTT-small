Actually, I realize there's a subtlety. The LP finds g that minimizes max_k (a*g)[k]. But the original problem is to minimize max_k (a*a)[k]. These are different! The LP step is a "linearization" - it treats a as fixed and optimizes g. The blend step then moves a towards g.

This is essentially a block coordinate descent on the non-convex problem, where we alternate between:
1. Fix a, minimize max_k (a*g)[k] over g (LP)
2. Fix g, minimize max_k (a*a)[k] over a (non-convex, handled by gradient)

The blending is a way to combine the two.

One improvement: instead of a fixed blend parameter, use the optimal blend (line search along the a-to-g direction).

Another improvement: after the LP gives g, instead of blending, we can use g as a direction for gradient descent on the original problem.

Let me also think about a completely different approach:

**Alternating Minimization with SDP relaxation:**

The problem min max_k c[k] s.t. sum(a)=1, a>=0 can be written as:
min M s.t. c[k] <= M for all k, sum(a)=1, a>=0

The constraints c[k] <= M are quadratic in a. We can relax these to a semidefinite program (SDP) by introducing a matrix variable X = a*a^T and using the constraint X >> 0, diag(X) = a^2, etc. But this gets complicated.

Alternatively, we can use the following trick: c[k] = a^T Q_k a where Q_k is a specific symmetric matrix. The constraint a^T Q_k a <= M is a quadratic constraint. The problem becomes a quadratically constrained quadratic program (QCQP), which is NP-hard in general but can be approximated.

def compute_conv(a):
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]

def compute_obj(a):
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))

def project_simplex(v):
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    rho_indices = np.nonzero(cond)[0]
    if len(rho_indices) == 0:
        return np.ones(n) / n
    rho = rho_indices[-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    proj = np.maximum(v - theta, 0.0)
    s = proj.sum()
    if s > 1e-15:
        return proj / s
    return np.ones(n) / n

def lse_grad(a, T):
    """Compute gradient of 2n*LSE_T(conv(a,a)) using FFT."""
    n = len(a)
    conv = compute_conv(a)
    cmax = np.max(conv)
    exp_vals = np.exp(np.clip(T * (conv - cmax), -500, 500))
    w = exp_vals / exp_vals.sum()
    
    # grad[i] = 4n * sum_j w[i+j] * a[j]
    # Using FFT: d[i] = conv(flip(w), a)[2n-2-i]
    fw = w[::-1]
    conv_size = 1

        conv_size <<= 1
    fa = rfft(a, conv_size)

    conv_result = irfft(fa * ffw, conv_size)
    indices = 2 * n - 2 - np.arange(n)
    d = conv_result[indices]
    return 4.0 * n * d

    n = len(a)

    """Subgradient using top-k active peaks."""
    n = len(a)
    conv = compute_conv(a)
    # Get top k peaks

    top_vals = conv[top_idx]
    # Weight by squared value (emphasize the highest peaks)
