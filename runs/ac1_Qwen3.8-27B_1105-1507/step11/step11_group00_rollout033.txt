Now I understand the problem better. The key is to find sequences where the convolution is as "flat" as possible. For large n, we want all the convolution values to be approximately equal.

The average convolution value is (sum a)^2 / (2n-1). So if we can achieve max ≈ average, the objective would be ≈ 2n/(2n-1) ≈ 1.

The challenge is that the "center" of the convolution (position n-1) has n terms while the edges have fewer. So we need to "weight" the sequence to compensate.

Specifically, if we want conv[k] ≈ C for all k, then:
- For k near 0: only a few terms, so a[0]^2 ≈ C, a[0]*a[1]+a[1]*a[0] ≈ C, etc.
- For k = n-1: n terms, so the sum of n products ≈ C.

This means the sequence should be "heavier" in the middle and "lighter" at the edges (or vice versa, depending on the structure).

Actually, for the convolution to be flat, we need:
sum_j a[j] * a[k-j] ≈ C for all k.

This is a system of (2n-1) equations in n unknowns. For n >= 2, it's overdetermined, so exact flatness is impossible. But we can get close.

This is related to the theory of "flat-top" windows and "minimum peak sidelobe" sequences.

import numpy as np

def fft_convolve(a):
    """Full linear convolution a*a via real FFT. Returns array of length 2n-1."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2. Assumes a>=0."""
    n = len(a)

    # Use FFT: correlation
    
    # g[i] = sum_k p[k] * a[k-i] for k-i in [0,n-1]
    #      + sum_k p[k] * a[i-k] for i-k in [0,n-1]
    # = (a * p_reversed)[i + n - 1] + (a * p)[i + n - 1]  ... approximately
    
    # Better: use the full convolution approach
    # Define b = p (length 2n-1), compute cross-correlation with a
    # g[i] = sum_k p[k] * (a[k-i] * 1[0<=k-i<n] + a[i-k] * 1[0<=i-k<n])
    
    # Using FFT: let's compute c = convolve(a, p) which has length n + (2n-1) - 1 = 3n-2
    # Then g[i] relates to specific entries of c.
    
    # Simpler approach using direct FFT correlation:
    N_fft = 1
    while N_fft < 3 * n:
        N_fft <<= 1
    
    # g[i] = sum_k p[k] * a[k-i] (where k-i in [0,n-1])
    # This is (a * flip(p))[i + (2n-1) - 1 - ... ] 
    # Let's just use: correlate(a, p) via FFT
    # correlate(a, p)[m] = sum_k a[k] * p[k+m]
    
    # Actually the cleanest way:
    # g[i] = sum_{k=0}^{2n-2} p[k] * (a[k-i] if 0<=k-i<n else 0)
    #      + sum_{k=0}^{2n-2} p[k] * (a[i-k] if 0<=i-k<n else 0)
    
    # First sum: let j = k-i, so k = j+i, j in [0,n-1], k in [i, i+2n-2] ∩ [0, 2n-2]
    # = sum_{j=0}^{n-1} a[j] * p[j+i] (where j+i < 2n-1)
    # = (a * p) cross-correlation type
    
    # Let's just do it with FFT cross-correlation
    fa = rfft(a, N_fft)
    fp = rfft(p, N_fft)
    
    # First term: sum_j a[j] * p[j+i] = ifft(fa * conj(fp))[i]... not quite
    # sum_j a[j] * p[j+i]: this is the cross-correlation of a and p at lag i
    # = ifft(conj(fa) * fp)[i] ... let me think
    # corr[i] = sum_j a[j] * p[j+i]
    # In frequency: FFT{corr} = conj(FFT{a}) * FFT{p} (with appropriate padding)
    
    # Actually: if we define cross_corr[i] = sum_j a[j] * p[j+i], then:
    # cross_corr = ifft(conj(fa) * fp)
    # But we need to be careful about the definition.
    
    # Let me use a simpler approach: just compute the two convolutions
    # term1[i] = sum_k p[k] * a[k-i] = (flip(a) * p)[i + n - 1]
    # where flip(a) has length n, p has length 2n-1, result has length 3n-2
    # (flip(a) * p)[m] = sum_j flip(a)[j] * p[m-j] = sum_j a[n-1-j] * p[m-j]
    # Let j' = n-1-j: = sum_j' a[j'] * p[m-n+1+j']
    # We want this to equal sum_k p[k] * a[k-i]
    # So m-n+1+j' = k, i.e., k = m-n+1+j', and a[k-i] = a[m-n+1+j'-i]
    # We need m-n+1+j'-i = j' → m = n-1+i
    # So term1[i] = conv(flip(a), p)[n-1+i]
    
    a_flipped = a[::-1]
    N_fft2 = 1
    while N_fft2 < len(a_flipped) + len(p) - 1:
        N_fft2 <<= 1
    fa_f = rfft(a_flipped, N_fft2)
    fp2 = rfft(p, N_fft2)
    conv1 = irfft(fa_f * fp2, N_fft2)
    
    # term1[i] = conv1[n-1+i] for i=0..n-1
    term1 = conv1[n - 1:2 * n - 1]
    
    # term2[i] = sum_k p[k] * a[i-k] = (a * p)[i + n - 1]... let me verify
    # (a * p)[m] = sum_j a[j] * p[m-j]
    # We want sum_k p[k] * a[i-k], let j = i-k, so k = i-j:
    # = sum_j a[j] * p[i-j] = (a * p)[i]... but p has length 2n-1
    # Actually (a*p)[i] = sum_j a[j] * p[i-j] for valid indices
    # This is what we want for term2!
    
    # But (a*p) has length n + (2n-1) - 1 = 3n-2
    conv2 = irfft(rfft(a, N_fft2) * rfft(p, N_fft2), N_fft2)[:3*n-2]
    term2 = conv2[0:n]  # term2[i] = conv2[i] for i=0..n-1
    
    # Wait, I need to double-check. Let me just use the formula:
    # g[i] = 2 * sum_k p[k] * a[|k-i| adjusted]... 
    
    # Actually, the simplest correct approach:
    # The autocorrelation c = conv(a,a) has c[k] = sum_j a[j]*a[j+k] for k>=0 (one-sided)
    # dc[k]/da[i] = a[i+k] (if valid) + a[i-k] (if valid) [for k != 0]
    #              = 2*a[i] (for k=0)
    # So d(max_c)/da[i] ≈ sum_k p[k] * (a[i+k]+a[i-k]) with appropriate bounds
    
    # This equals 2 * (a * p_centered)[i] where p_centered is p arranged symmetrically
    # But it's easier to just compute:
    # g[i] = sum_{k=-(n-1)}^{n-1} p_full[k+n-1] * (a[i+k] if 0<=i+k<n else 0)
    # where p_full is the full 2n-1 length array
    
    # Using FFT: g = ifft(fft(a_padded) * fft(p_something))
    
    # Let me just do it the direct FFT way that's guaranteed correct:
    # g[i] = sum_k p[k] * a[k-i] * 1[0<=k-i<n] + sum_k p[k] * a[i-k] * 1[0<=i-k<n]
    
    # First part: sum_k p[k] * a[k-i] for k-i in [0,n-1], i.e., k in [i, i+n-1] ∩ [0,2n-2]
    # = sum_{j=0}^{n-1} a[j] * p[j+i] (where j+i <= 2n-2)
    # This is the cross-correlation of a and p at lag i.
    
    # Using FFT: cross_corr[i] = sum_j a[j] * p[j+i] = ifft(conj(FFT(a)) * FFT(p))[i]
    # with zero-padding to length >= n + (2n-1) - 1 = 3n-2
    
    N3 = 1
    while N3 < 3 * n + 2:
        N3 <<= 1
    fa3 = np.fft.rfft(a, N3)
    fp3 = np.fft.rfft(p, N3)
    
    # cross_corr[i] = sum_j a[j] * p[j+i]
    # = ifft(conj(fa3) * fp3)[i]
    cc1 = np.fft.irfft(np.conj(fa3) * fp3, N3)
    # cc1[i] = sum_j a[j] * p[j+i] for i = 0..N3-1
    # We want i = 0..n-1, and p has length 2n-1, so j+i < 2n-1 is needed
    # For i in [0, n-1] and j in [0, n-1]: j+i in [0, 2n-2] which is < 2n-1. Good.
    part1 = cc1[0:n]
    
    # Second part: sum_k p[k] * a[i-k] for i-k in [0,n-1], i.e., k in [i-n+1, i] ∩ [0, 2n-2]
    # = sum_{j=0}^{n-1} a[j] * p[i-j] (where i-j >= 0, i.e., j <= i)
    # = sum_{j=0}^{min(i,n-1)} a[j] * p[i-j]
    # This is (a * p)[i] truncated = convolution of a and p at position i
    conv_ap = np.fft.irfft(fa3 * fp3, N3)
    part2 = conv_ap[0:n]
    
    g = 2.0 * (part1 + part2)
    return g


def mirror_descent_step(a, grad, eta):
    """Multiplicative weights: a <- a * exp(-eta * grad), normalized."""
    exponent = -eta * grad
    exponent = np.clip(exponent, -100, 100)
    a_new = a * np.exp(exponent)
    s = float(np.sum(a_new))
    if s < 1e-300:
        return a.copy()
    return a_new / s


def fista_step(a, grad, lr, momentum, proj_fn):
    """One FISTA step."""
    y = a + momentum * (a - proj_fn(a - lr * grad))
    y = np.maximum(y, 0)
    s = float(np.sum(y))
    if s > 0:
        y = y / s
    return proj_fn(a - lr * grad), y


def simplex_project(v, target_sum=1.0):
    """Project v onto {x >= 0, sum(x) = target_sum}."""
    n = len(v)
    v = np.maximum(v, 0)
    s = float(np.sum(v))
    if s > 0:
        v = v * target_sum / s
    return v


def edge_peaked_init(n, alpha=2.0):
    """Initialize with edge-peaked profile: large at edges, small in center."""
    j = np.arange(n, dtype=np.float64)
    dist = np.minimum(j, n - 1 - j).astype(np.float64)
    a = 1.0 / (1.0 + alpha * dist / n)
    a = np.maximum(a, 0)
    s = float(np.sum(a))
    if s > 0:
        a = a / s
    return a


def gaussian_init(n, sigma_frac=0.3):
    """Gaussian-shaped initialization (peaked in center)."""
    j = np.arange(n, dtype=np.float64)
    center = (n - 1) / 2.0
    sigma = sigma_frac * n
    a = np.exp(-0.5 * ((j - center) / sigma) ** 2)
    s = float(np.sum(a))
    if s > 0:
        a = a / s
    return a


def random_init(n, rng):
    """Random non-negative initialization."""
    a = rng.random(n)
    a = np.maximum(a, 0)
    s = float(np.sum(a))
    if s > 0:
        a = a / s
    return a


def mirror_descent_optimize(a, time_budget=200.0, tau_init=10.0, tau_end=2000.0,
                            verbose=False):
    """
    Mirror descent (multiplicative weights) with adaptive LSE temperature.
    This is the primary optimization method.
    """
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    rng = np.random.default_rng(12345)

    it = 0
    best_it = 0
    stall = 0
    prev_obj = best_obj

    while time.monotonic() - start < time_budget:
        elapsed = time.monotonic() - start
        remaining = time_budget - elapsed
        if remaining < 0.3:
            break
        progress = min(1.0, elapsed / max(time_budget, 1e-10))

        # Adaptive temperature: start low (nearly exact max), increase for smoothing
        tau = tau_init + (tau_end - tau_init) * (progress ** 0.7)

        conv = fft_convolve(a)
        g = compute_grad(a, conv, tau)
        g_max = float(np.max(np.abs(g)))
        if g_max < 1e-15:
            break

        # Adaptive step size
        eta = 1.5 / (g_max + 1e-10)
        # Decay step size over time
        eta *= (1.0 - 0.5 * progress)
        # Also scale with n for stability
        eta *= min(1.0, 50.0 / n)

        a_new = mirror_descent_step(a, g, eta)

        # Occasional perturbation for exploration
        if it % 50 == 40 and progress < 0.7:
            temp = 0.005 * (1.0 - progress)
            a_new = a_new + temp * rng.standard_normal(n)
            a_new = np.maximum(a_new, 0)
            s_new = float(np.sum(a_new))
            if s_new > 1e-10:
                a_new = a_new / s_new

        obj_new = compute_obj(a_new)

        if obj_new < best_obj - 1e-14:
            best_obj = obj_new
            best_a = a_new.copy()
            best_it = it
            stall = 0
        else:
            stall += 1
            # Backtrack: try smaller step
            if stall % 5 == 0:
                for factor in [0.5, 0.2, 0.1]:
                    a_bt = mirror_descent_step(a, g, eta * factor)
                    obj_bt = compute_obj(a_bt)
                    if obj_bt < best_obj - 1e-14:
                        best_obj = obj_bt
                        best_a = a_bt.copy()
                        a = a_bt
                        stall = 0
                        break
                else:
                    # No improvement, perturb
                    if stall > 30:
                        strength = 0.01 + 0.03 * progress
                        a = a * np.exp(strength * rng.standard_normal(n))
                        a = np.maximum(a, 0)
                        s_new = float(np.sum(a))
                        if s_new > 1e-10:
                            a = a / s_new
                        else:
                            a = best_a.copy()
                        stall = 0

        a = a_new
        prev_obj = obj_new
        it += 1

        if verbose and (it % 200 == 0 or it == 1):
            print(f"      MD it{it}: obj={best_obj:.8f}, tau={tau:.1f}, "
                  f"stall={stall}, t={time.monotonic()-start:.0f}s")

    return best_a


def fista_optimize(a, time_budget=100.0, tau=500.0, verbose=False):
    """FISTA (accelerated proximal gradient) on the smoothed objective."""
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()

    # Lipschitz constant estimate
    conv0 = fft_convolve(a)
    g0 = compute_grad(a, conv0, tau)
    L = float(np.linalg.norm(g0, np.inf)) + 1e-10
    lr = 1.0 / L

    t_k = 1.0
    a_prev = a.copy()

    it = 0
    while time.monotonic() - start < time_budget:
        if time.monotonic() - start < 0.1:
            pass
        remaining = time_budget - (time.monotonic() - start)
        if remaining < 0.2:
            break

        # FISTA momentum
        mu = (1.0 - t_k) / (t_k + 1.0)
        y = a + mu * (a - a_prev)
        y = np.maximum(y, 0)
        s_y = float(np.sum(y))
        if s_y > 0:
            y = y / s_y
        else:
            y = best_a.copy()

        conv_y = fft_convolve(y)
        g = compute_grad(y, conv_y, tau)

        # Gradient step
        v = y - lr * g
        a_new = simplex_project(v, 1.0)

        # Backtracking on lr if needed (check every 10 iters)
        if it % 10 == 5:
            obj_y = compute_obj(y)
            obj_new = compute_obj(a_new)
            if obj_new > obj_y + 1e-6 * lr * float(np.dot(g, a_new - y)):
                lr *= 0.5

        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t_k * t_k))
        a_prev = a.copy()
        a = a_new
        t_k = t_new

        obj_cur = compute_obj(a)
        if obj_cur < best_obj - 1e-14:
            best_obj = obj_cur
            best_a = a.copy()

        it += 1

        if verbose and it % 100 == 0:
            print(f"      FISTA it{it}: obj={best_obj:.8f}, lr={lr:.6f}, "
                  f"t={time.monotonic()-start:.0f}s")

    return best_a


def coordinate_descent_polish(a, time_budget=60.0, verbose=False):
    """
    Coordinate descent: for each coordinate i, find optimal a[i] that minimizes
    the objective, cycling through all coordinates.
    """
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    rng = np.random.default_rng(999)

    sweep = 0
    while time.monotonic() - start < time_budget:
        remaining = time_budget - (time.monotonic() - start)
        if remaining < 1.0:
            break

        # Random or sequential order
        if sweep % 3 == 0:
            order = np.arange(n)
        else:
            order = rng.permutation(n)

        improved = False
        for i in order:
            if time.monotonic() - start > time_budget - 0.5:
                break

            # Try several values for a[i]
            best_val = a[i]
            best_local_obj = best_obj  # approximate (using current max)
            
            # The current convolution
            conv_cur = fft_convolve(a)
            max_cur = float(np.max(conv_cur))
            sum_cur = float(np.sum(a))
            
            # Try multiplicative changes
            for factor in [0.5, 0.7, 0.85, 1.15, 1.3, 1.5, 2.0, 0.3]:
                a_try = a.copy()
                a_try[i] = a[i] * factor
                a_try = np.maximum(a_try, 0)
                s_try = float(np.sum(a_try))
                if s_try < 1e-10:
                    continue
                a_try = a_try / s_try
                obj_try = compute_obj(a_try)
                if obj_try < best_local_obj - 1e-12:
                    best_local_obj = obj_try
                    best_val = a_try[i]
                    improved = True

            if best_val != a[i]:
                a[i] = best_val
                s = float(np.sum(a))
                if s > 0:
                    a = a / s

        # Check overall improvement
        obj_now = compute_obj(a)
        if obj_now < best_obj - 1e-13:
            best_obj = obj_now
            best_a = a.copy()
        elif not improved:
            # No coordinate improved, try perturbation
            pert_mask = rng.random(n) < 0.1
            a[pert_mask] *= np.exp(0.05 * rng.standard_normal(pert_mask.sum()))
            a = np.maximum(a, 0)
            s = float(np.sum(a))
            if s > 0:
                a = a / s

        sweep += 1
        if verbose and sweep % 5 == 0:
            print(f"      CD sweep{sweep}: obj={best_obj:.8f}, "
                  f"t={time.monotonic()-start:.0f}s")

    return best_a


def resample(a, new_n):
    """Resample sequence to new length."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, a[0])
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)


def multistage_optimize(a, time_budget, verbose=False):
    """Run MD -> FISTA -> CD pipeline on a given sequence."""
    n = len(a)
    
    # Phase A: Mirror Descent
    alloc_a = time_budget * 0.5
    a = mirror_descent_optimize(a, time_budget=alloc_a, tau_init=5.0, tau_end=1000.0,
                                verbose=verbose)
    
    remaining = time_budget - alloc_a - (time_budget * 0.0)  # approximate
    elapsed = 0  # we don't track exactly here, the functions track internally
    
    # Phase B: FISTA
    alloc_b = time_budget * 0.3
    a = fista_optimize(a, time_budget=alloc_b, tau=300.0, verbose=verbose)
    
    # Phase C: Coordinate Descent
    alloc_c = time_budget * 0.2
    a = coordinate_descent_polish(a, time_budget=alloc_c, verbose=verbose)
    
    return a

        alloc1 = min(remaining * 0.4, 80.0)
        if alloc1 > 10:
            a_pol = mirror_descent_optimize(best_seq, time_budget=alloc1,
                                            tau_init=500.0, tau_end=5000.0)
            obj_pol = compute_obj(a_pol)
            if obj_pol < best_score:
                best_score = obj_pol
                best_seq = a_pol.copy()
                print(f"  Polish MD: obj={best_score:.8f} **")
            else:
                print(f"  Polish MD: obj={obj_pol:.8f}")
        
        # FISTA polish
        remaining = deadline - time.monotonic()
        alloc2 = min(remaining * 0.3, 50.0)
        if alloc2 > 10:
            a_pol2 = fista_optimize(best_seq, time_budget=alloc2, tau=1000.0)
            obj_pol2 = compute_obj(a_pol2)
            if obj_pol2 < best_score:
                best_score = obj_pol2
                best_seq = a_pol2.copy()
                print(f"  Polish FISTA: obj={best_score:.8f} **")
        
        # CD polish
        remaining = deadline - time.monotonic()
        alloc3 = min(remaining * 0.3, 40.0)
        if alloc3 > 5:
            a_pol3 = coordinate_descent_polish(best_seq, time_budget=alloc3)
            obj_pol3 = compute_obj(a_pol3)
            if obj_pol3 < best_score:
                best_score = obj_pol3
                best_seq = a_pol3.copy()
                print(f"  Polish CD: obj={best_score:.8f} **")
    
    # Safety: try a few more random restarts if time permits
    remaining = deadline - time.monotonic()
    if remaining > 30 and best_seq is not None:
        n_cur = len(best_seq)
        for restart in range(min(3, int(remaining // 25))):
            remaining = deadline - time.monotonic()
            if remaining < 25:
                break
            # Perturb best and re-optimize
            a_r = best_seq * np.exp(0.03 * rng.standard_normal(n_cur))
            a_r = np.maximum(a_r, 0)
            s_r = float(np.sum(a_r))
            if s_r > 0:
                a_r = a_r / s_r
            a_r = multistage_optimize(a_r, time_budget=min(remaining * 0.6, 40.0))
            obj_r = compute_obj(a_r)
            if obj_r < best_score:
                best_score = obj_r
                best_seq = a_r.copy()
                print(f"  Restart {restart}: obj={best_score:.8f} **")
            else:
                print(f"  Restart {restart}: obj={obj_r:.8f}")
    
    # Final validation
    if best_seq is None:
        best_seq = np.ones(100) / 100.0
        best_score = compute_obj(best_seq)
    
    result = [float(max(0.0, min(1000.0, x))) for x in best_seq]
    
    # Verify with the official evaluator
    val = evaluate_sequence(result)
    if val < np.inf:
        best_score = val
    else:
        # Fallback
        result = [1.0] * 100
        best_score = 2.0
    
    elapsed = time.monotonic() - start_time
    print(f"\n=== FINAL: n={len(result)}, score={best_score:.8f}, time={elapsed:.1f}s ===")
    
    return result
