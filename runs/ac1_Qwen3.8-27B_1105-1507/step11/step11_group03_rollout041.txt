`conv_k = sum_i a_i * a_{k-i}`

When I change `a_j` from `old` to `new`:
- For `k = 2j`: the term `a_j * a_j = a_j^2` changes from `old^2` to `new^2`.
  So `conv_{2j}(new) = conv_{2j}(old) - old^2 + new^2`
  Let `C_{2j} = conv_{2j}(old) - old^2`. Then `conv_{2j} = C_{2j} + new^2`.

- For `k ≠ 2j` (but `0 <= k-j < n`): the terms `a_j * a_{k-j}` and `a_{k-j} * a_j` each change from `old * a_{k-j}` to `new * a_{k-j}`.
  So `conv_k(new) = conv_k(old) - 2*old*a_{k-j} + 2*new*a_{k-j}`
  Let `C_k = conv_k(old) - 2*old*a_{k-j}`. Then `conv_k = C_k + 2*a_{k-j}*new`.

- For `k` where `k-j < 0` or `k-j >= n`: `conv_k` doesn't change.

So the function to minimize is:
`f(x) = max(C_{2j} + x^2, max_{k≠2j, valid} (C_k + 2*a_{k-j}*x), max_{invalid k} conv_k)`

The last term (invalid k) is constant, so it just adds a constant to the max.

Let `M0 = max_{invalid k} conv_k` (constant).
`f(x) = max(C_{2j} + x^2, max_{k valid, k≠2j} (C_k + 2*a_{k-j}*x), M0)`

This is a convex function of `x >= 0`. We can minimize it using:
1. Ternary search on `[0, 1]` (since `a_j <= 1` when sum = 1)
2. Or find the point where the derivative changes sign

For ternary search, we need about 50-100 evaluations of `f(x)`, each taking O(n) time. So each coordinate update is O(n * 100) = O(100n). For n coordinates, one full pass is O(100 * n^2). For n=800, that's 64 million operations per pass. At ~100M ops/sec, that's ~0.6 seconds per pass. We can do about 10-20 passes in 1500 seconds. That's reasonable.

Actually, we can be smarter. The function `f(x)` is the max of linear functions and one quadratic. The minimum occurs where two of these functions intersect (or at x=0). We can find all pairwise intersections and check the objective at each candidate point. This gives an exact solution in O(n^2) per coordinate (or O(n) if we sort the slopes).

But ternary search is simpler and good enough. Let me use it.

Actually, even better: since the function is the max of linear functions (plus one quadratic), it's piecewise linear (plus one quadratic piece). The minimum is at a breakpoint or at x=0. The breakpoints are where two linear functions cross, or where the quadratic crosses a line.

For the quadratic `C_{2j} + x^2` vs a line `C_k + 2*a_{k-j}*x`:
`C_{2j} + x^2 = C_k + 2*a_{k-j}*x`
`x^2 - 2*a_{k-j}*x + (C_{2j} - C_k) = 0`
`x = a_{k-j} ± sqrt(a_{k-j}^2 - C_{2j} + C_k)`

For two lines `C_k1 + 2*a_{k1-j}*x` vs `C_k2 + 2*a_{k2-j}*x`:
They cross at `x = (C_k2 - C_k1) / (2*(a_{k1-j} - a_{k2-j}))` (if denominators are non-zero).

This gives O(n^2) candidate points per coordinate, which is too many for n=800.

So ternary search is the way to go. Let me implement it with about 40 iterations (gives precision of about 1/40^3 ≈ 1.5e-5, which is more than enough).

Let me now write the full code:

```python
"""
Optimizes step function coefficients to minimize 2*n*max(conv(a,a))/(sum(a))^2.
Uses exact coordinate descent with ternary search, multiplicative weights (mirror descent),
and simulated annealing to escape local minima.
"""

import numpy as np
import time
from scipy.fft import rfft, irfft, fft, ifft

def compute_conv(a):
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]

def compute_obj(a):
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 1e-10:
        return np.inf
    a = a / s
    conv = compute_conv(a)
    return 2.0 * n * float(np.max(conv))

def smoothed_grad(a, tau):
    n = len(a)
    conv = compute_conv(a)
    max_c = float(np.max(conv))
    shifted = tau * (conv - max_c)
    shifted = np.clip(shifted, -500, 500)
    exp_v = np.exp(shifted)
    p = exp_v / float(np.sum(exp_v))
    
    N = 1
    while N < 2 * (2 * n - 1):
        N <<= 1
    P = fft(p, N)
    A = fft(a, N)
    cross = ifft(P * np.conj(A)).real
    g = 2.0 * cross[:n]
    return g, max_c

def coord_descent(a, time_budget, verbose=False, seed=42, max_passes=50):
    """Exact coordinate descent with ternary search for 1D subproblems."""
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    rng = np.random.default_rng(seed)
    
    # Pre-compute convolution
    conv = compute_conv(a)
    
    for pass_idx in range(max_passes):
        if time.monotonic() - start > time_budget - 5:
            break
        
        # Random order for this pass
        order = rng.permutation(n)
        
        for j in order:
            if time.monotonic() - start > time_budget - 5:
                    break
            
            # Get current value
            old = a[j]
            
            # Compute relevant convolution values
            # conv_k depends on a_j if 0 <= k-j < n, i.e., j <= k <= j+n-1
            k_min = max(0, j)
            k_max = min(2*n-2, j + n - 1)
            
            # For k = 2j: conv_k = C + x^2
            # For k != 2j (but valid): conv_k = C + 2*a_{k-j}*x
            # For invalid k: constant
            
            # Pre-compute constants
            C_2j = None
            if 0 <= 2*j <= 2*n-2:
                C_2j = conv[2*j] - old * old
            
            # For linear pieces: C_k + 2*a_{k-j}*x
            # Collect (slope, intercept) pairs
            slopes = []
            intercepts = []
            for k in range(k_min, k_max + 1):
                if k == 2 * j:
                    continue
                m = k - j  # 0 <= m < n
                if 0 <= m < n:
                    C_k = conv[k] - 2 * old * a[m]
                    slopes.append(2 * a[m])
                    intercepts.append(C_k)
            
            # Constant from invalid k
            M0 = float(np.max(conv))  # upper bound (includes valid k too, but that's fine for max)
            # Actually, let's compute it properly
            # Invalid k are those outside [k_min, k_max]
            if k_min > 0 or k_max < 2*n-2:
                mask = np.ones(2*n-1, dtype=bool)
                mask[k_min:k_max+1] = False
                if mask.any():
                    M0 = float(np.max(conv[mask]))
                else:
                    M0 = 0.0
            else:
                M0 = 0.0
            
            slopes = np.array(slopes) if slopes else np.array([0.0])
            intercepts = np.array(intercepts) if intercepts else np.array([0.0])
            
            # Define f(x) = max(C_2j + x^2, max(intercepts + slopes*x), M0)
            def f(x):
                val = M0
                if C_2j is not None:
                    val = max(val, C_2j + x * x)
                if len(intercepts) > 0:
                    val = max(val, float(np.max(intercepts + slopes * x)))
                return val
            
            # Ternary search on [0, 1]
            lo, hi = 0.0, 1.0
            for _ in range(40):
                m1 = lo + (hi - lo) / 3.0
                m2 = hi - (hi - lo) / 3.0
                if f(m1) < f(m2):
                    hi = m2
                else:
                    lo = m1
            
            x_new = (lo + hi) / 2.0
            x_new = max(0.0, min(1.0, x_new))
            
            # Update
            if abs(x_new - old) > 1e-12:
                a[j] = x_new
                # Update convolution
                delta = x_new - old
                # conv_k changes by delta * (a_{k-j} + a_{k-j}) = 2*delta*a_{k-j} for k != 2j
                # and by (x_new^2 - old^2) for k = 2j
                if 0 <= 2*j <= 2*n-2:
                    conv[2*j] += x_new*x_new - old*old
                for m in range(n):
                    k = m + j
                    if 0 <= k < 2*n-1:
                        if k != 2*j:
                            conv[k] += 2 * delta * a[m]
                
                # Check objective (periodically)
                if pass_idx % 5 == 4:
                    obj = 2.0 * n * float(np.max(conv))
                    if obj < best_obj - 1e-12:
                        best_obj = obj
                        best_a = a.copy()
        
        # End of pass: check and normalize
        s = float(np.sum(a))
        if s > 1e-10:
            a = a / s
            conv = compute_conv(a)  # Recompute to avoid drift
            obj = 2.0 * n * float(np.max(conv))
            if obj < best_obj - 1e-12:
                best_obj = obj
                best_a = a.copy()
            if verbose and pass_idx % 10 == 0:
                print(f"    CoordDec pass {pass_idx}: obj={best_obj:.10f}")
    
    return best_a

def multiplicative_weights(a, time_budget, verbose=False, seed=42):
    """Mirror descent with entropic regularization (multiplicative weights)."""
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    # Tau schedule: start high (smooth), anneal to low (sharp)
    tau_start = 5.0
    tau_end = 500.0
    total_iters = 2000
    
    # Step size schedule
    eta_start = 1.0 / np.sqrt(n)
    
    # Simulated annealing temperature
    T_start = 0.1
    T_end = 0.001
    
    for it in range(total_iters):
        if time.monotonic() - start > time_budget - 5:
            break
        
        # Anneal tau and temperature
        frac = it / total_iters
        tau = tau_start * (tau_end / tau_start) ** frac
        T = T_start * (T_end / T_start) ** frac
        eta = eta_start * (1.0 - 0.5 * frac)  # slowly decrease step size
        
        # Compute gradient
        g, max_c = smoothed_grad(a, tau)
        
        # Normalize gradient for step size
        g_max = float(np.max(np.abs(g)))
        if g_max < 1e-15:
            break
        
        # Multiplicative update
        # a_i *= exp(-eta * g_i / g_max)
        # But we need to be careful: this should decrease a_i where g_i > 0 (increase in obj)
        # and increase where g_i < 0
        # Since we're minimizing, we want to move in the -gradient direction
        # a_i_new = a_i * exp(-eta * g_i / g_max)
        
        updates = np.exp(-eta * g / g_max)
        updates = np.clip(updates, 0.1, 10.0)  # prevent extreme ratios
        a_new = a * updates
        a_new = np.maximum(a_new, 0)
        s_new = float(np.sum(a_new))
        if s_new < 1e-10:
            continue
        a_new = a_new / s_new
        
        # Evaluate
        obj_new = compute_obj(a_new)
        
        # Simulated annealing acceptance
        if obj_new < best_obj:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new
        else:
            # Accept with probability exp(-(obj_new - best_obj) / T)
            if np.random.default_rng(it).random() < np.exp(-(obj_new - best_obj) / (T + 1e-10)):
                a = a_new
            else:
                # Don't update a, try again
                pass
        
        if verbose and it % 200 == 0:
            print(f"    MW it{it:4d}: obj={best_obj:.10f}, tau={tau:.1f}, T={T:.4f}")
    
    return best_a

def high_tau_polish(a, time_budget, verbose=False, seed=42):
    """Final polishing with very high tau (nearly exact max targeting)."""
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    rng = np.random.default_rng(seed)
    
    tau_levels = [200, 500, 1000, 2000, 5000]
    
    for tau in tau_levels:
        if time.monotonic() - start > time_budget - 10:
            break
        
        iters = 200
        lr = 0.5 / np.sqrt(n)
        
        for it in range(iters):
            if time.monotonic() - start > time_budget - 10:
                break
            
            g, max_c = smoothed_grad(a, tau)
            g_norm = float(np.linalg.norm(g))
            if g_norm < 1e-15:
                break
            
            # Small step in negative gradient direction
            step = lr / (g_norm + 1e-10)
            a_new = a - step * g
            a_new = np.maximum(a_new, 0)
            s_new = float(np.sum(a_new))
            if s_new < 1e-10:
                break
            a_new = a_new / s_new
            
            obj_new = compute_obj(a_new)
            if obj_new < best_obj - 1e-14:
                best_obj = obj_new
                best_a = a_new.copy()
                a = a_new
            else:
                # Try smaller step
                step /= 2
                a_new = a - step * g
                a_new = np.maximum(a_new, 0)
                a_new = a_new / a_new.sum()
                obj_new = compute_obj(a_new)
                if obj_new < best_obj - 1e-14:
                    best_obj = obj_new
                    best_a = a_new.copy()
                    a = a_new
                else:
                    # Perturb
                    a = a + 0.005 * rng.standard_normal(n)
                    a = np.maximum(a, 0)
                    a = a / a.sum()
            
            lr *= 0.999
    
    return best_a

def lag_targeting(a, time_budget, verbose=False, seed=42):
    """Target specific lags where convolution is maximized."""
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    rng = np.random.default_rng(seed)
    
    max_iters = 500
    
    for it in range(max_iters):
        if time.monotonic() - start > time_budget - 10:
            break
        
        conv = compute_conv(a)
        max_val = float(np.max(conv))
        
        # Find peak lags
        threshold = max_val * 0.9995
        peak_lags = np.where(conv >= threshold)[0]
        
        # For each peak lag, compute the subgradient and try to reduce it
        # The subgradient of max(conv) w.r.t. a is the average of gradients at active lags
        subgrad = np.zeros(n)
        for lag in peak_lags:
            for i in range(n):
                j = lag - i
                if 0 <= j < n:
                    subgrad[i] += 2.0 * a[j]
        subgrad /= len(peak_lags)
        
        sgn = float(np.linalg.norm(subgrad))
        if sgn < 1e-15:
            break
        subgrad /= sgn
        
        # Try multiple step sizes
        improved = False
        for step in [0.0001, 0.0003, 0.001, 0.003, 0.01, 0.03]:
            a_try = a - step * subgrad
            a_try = np.maximum(a_try, 0)
            st = float(np.sum(a_try))
            if st < 1e-10:
                continue
            a_try = a_try / st
            obj_try = compute_obj(a_try)
            if obj_try < best_obj - 1e-13:
                best_obj = obj_try
                best_a = a_try.copy()
                a = a_try
                improved = True
                break
        
        if not improved:
            # Try adding to some coordinates to reduce specific lags
            for lag in peak_lags[:2]:
                # To reduce conv_lag, we want to reduce a_i * a_{lag-i} products
                # Try reducing the larger ones
                products = np.zeros(n)
                for i in range(n):
                    j = lag - i
                    if 0 <= j < n:
                        products[i] = a[i] * a[j]
                # Reduce the coordinate with largest product
                idx = np.argmax(products)
                a_try = a.copy()
                a_try[idx] *= 0.95
                a_try = a_try / a_try.sum()
                obj_try = compute_obj(a_try)
                if obj_try < best_obj - 1e-13:
                    best_obj = obj_try
                    best_a = a_try.copy()
                    a = a_try
                    improved = True
                    break
            
            if not improved:
                # Random perturbation
                a = a + 0.003 * rng.standard_normal(n)
                a = np.maximum(a, 0)
                a = a / a.sum()
                # If it got too bad, revert
                if compute_obj(a) > best_obj * 1.005:
                    a = best_a.copy()
        
        if verbose and it % 50 == 0:
            print(f"    LagTarget it{it:3d}: obj={best_obj:.10f}, n_peaks={len(peak_lags)}")
    
    return best_a

def make_init(n, mode, rng):
    """Create various initializations."""
    if mode == 0:
        return np.ones(n) / n
    elif mode == 1:
        x = np.linspace(-1, 1, n)
        a = np.maximum(np.sinc(x), 0.001)
        return a / a.sum()
    elif mode == 2:
        a = 0.54 - 0.46 * np.cos(2 * np.pi * np.arange(n) / max(1, n-1))
        return a / a.sum()
    elif mode == 3:
        x = np.arange(n) / max(1, n-1)
        a = 0.42 - 0.5 * np.cos(2*np.pi*x) + 0.08*np.cos(4*np.pi*x)
        return np.maximum(a, 0.01) / np.maximum(a, 0.01).sum()
    elif mode == 4:
        x = np.linspace(-3, 3, n)
        a = np.exp(-x**2)
        return a / a.sum()
    elif mode == 5:
        # "Anti-concentrated" - boost edges
        x = np.arange(n) / n
        a = 1.0 + 0.5 * np.cos(2*np.pi*x)**2
        return a / a.sum()
    elif mode == 6:
        # Periodic pattern
        x = np.arange(n)
        a = 1.0 + 0.3 * np.cos(2*np.pi*3*x/n)
        a = np.maximum(a, 0.1)
        return a / a.sum()
    elif mode == 7:
        # Random
        a = rng.uniform(0.1, 1.0, n)
        return a / a.sum()
    elif mode == 8:
        # Two-lobe
        x = np.arange(n) / n
        a = np.cos(2*np.pi*x)**2 + 0.5
        return a / a.sum()
    else:
        a = rng.exponential(1.0, n)
        return a / a.sum()
```

```python
"""
Optimizes step function coefficients to minimize 2*n*max(conv(a,a))/(sum(a))^2.
Uses exact coordinate descent with ternary search, multiplicative weights (mirror descent),
simulated annealing, lag targeting, and multi-start diversification.
"""

import numpy as np
import time
from scipy.fft import rfft, irfft, fft, ifft


def compute_conv(a):
    """Full linear convolution a*a via FFT. Returns array of length 2n-1."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    """Compute objective: 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 1e-10:
        return np.inf
    a = a / s
    conv = compute_conv(a)
    return 2.0 * n * float(np.max(conv))


def smoothed_grad(a, tau):
    """Compute gradient of log-sum-exp smoothed max of conv(a,a). Returns (grad, exact_max)."""
    n = len(a)
    conv = compute_conv(a)
    max_c = float(np.max(conv))
    shifted = tau * (conv - max_c)
    shifted = np.clip(shifted, -500, 500)
    exp_v = np.exp(shifted)
    p = exp_v / float(np.sum(exp_v))
    N = 1
    while N < 2 * (2 * n - 1):
        N <<= 1
    P = fft(p, N)
    A = fft(a, N)
    cross = ifft(P * np.conj(A)).real
    g = 2.0 * cross[:n]
    return g, max_c

def lag_targeting(a, time_budget, verbose=False, seed=42):

    n = len(a)

    s = float(np.sum(a))
    if s < 1e-10:
        return a

        if time.monotonic() - start > time_budget - 5:
            break

        conv = compute_conv(a)
        max_val = float(np.max(conv))
        threshold = max_val * 0.999
        peak_lags = np.where(conv >= threshold)[0]

        subgrad = np.zeros(n)
        for lag in peak_lags:
            for i in range(n):
                j = lag - i
                if 0 <= j < n:
                    subgrad[i] += 2.0 * a[j]

        if sgn < 1e-15:
            break
        subgrad /= sgn

        for step in [0.00005, 0.0001, 0.0003, 0.001, 0.003, 0.01, 0.03]:
            a_try = a - step * subgrad
            a_try = np.maximum(a_try, 0)
            st = float(np.sum(a_try))
            if st < 1e-10:
                continue
            a_try = a_try / st
            obj_try = compute_obj(a_try)
            if obj_try < best_obj - 1e-13:
                best_obj = obj_try
                best_a = a_try.copy()
                a = a_try
                improved = True
                break

                products = np.zeros(n)
                for i in range(n):
                    j = lag - i

            print(f"    LagTarget it{it:3d}: obj={best_obj:.10f}, n_peaks={len(peak_lags)}")

    return best_a


def high_tau_polish(a, time_budget, verbose=False, seed=42):
    """Final polishing with very high tau (nearly exact max targeting)."""
    n = len(a)
    a = np.maximum(a, 0).copy().astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s

    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    rng = np.random.default_rng(seed)

    tau_levels = [100, 300, 800, 2000, 5000]

    for tau in tau_levels:
        if time.monotonic() - start > time_budget - 10:
            break
        iters = 300
        lr = 1.0 / np.sqrt(n)

        for it in range(iters):
            if time.monotonic() - start > time_budget - 10:
                break

            g, max_c = smoothed_grad(a, tau)
            g_norm = float(np.linalg.norm(g))
            if g_norm < 1e-15:
                break

            a_new = a - lr * g
            a_new = np.maximum(a_new, 0)
            s_new = float(np.sum(a_new))
            if s_new < 1e-10:
                lr *= 0.5
                continue
            a_new = a_new / s_new

            obj_new = compute_obj(a_new)
            if obj_new < best_obj - 1e-14:
                best_obj = obj_new
                best_a = a_new.copy()
                a = a_new
                lr = min(lr * 1.05, 5.0 / np.sqrt(n))
            else:
                lr *= 0.7
                if lr < 1e-6:
                    a = a + 0.003 * rng.standard_normal(n)
                    a = np.maximum(a, 0)
                    a = a / a.sum()
                    lr = 1.0 / np.sqrt(n)

    return best_a


def make_init(n, mode, rng):
    """Create various structured initializations."""
    if mode == 0:
        return np.ones(n) / n
    elif mode == 1:
        x = np.linspace(-1, 1, n)
        a = np.maximum(np.sinc(x), 0.001)
        return a / a.sum()
    elif mode == 2:
        if n > 1:
            a = 0.54 - 0.46 * np.cos(2 * np.pi * np.arange(n) / (n - 1))
        else:
            a = np.ones(1)
        return a / a.sum()
    elif mode == 3:
        x = np.arange(n) / max(1, n - 1)
        a = 0.42 - 0.5 * np.cos(2 * np.pi * x) + 0.08 * np.cos(4 * np.pi * x)
        a = np.maximum(a, 0.01)
        return a / a.sum()
    elif mode == 4:
        x = np.linspace(-3, 3, n)
        a = np.exp(-x ** 2)
        return a / a.sum()
    elif mode == 5:
        x = np.arange(n) / n
        a = 1.0 + 0.5 * np.cos(2 * np.pi * x) ** 2
        return a / a.sum()
    elif mode == 6:
        x = np.arange(n)
        a = 1.0 + 0.3 * np.cos(2 * np.pi * 3 * x / n)
        a = np.maximum(a, 0.1)
        return a / a.sum()
    elif mode == 7:
        x = np.arange(n)
        a = 1.0 + 0.2 * np.cos(2 * np.pi * 5 * x / n) + 0.1 * np.cos(2 * np.pi * 7 * x / n)
        a = np.maximum(a, 0.05)
        return a / a.sum()
    elif mode == 8:
        a = rng.exponential(1.0, n)
        return a / a.sum()
    elif mode == 9:
        # Anti-peak: suppress center, boost edges
        x = np.arange(n)
        center = n / 2.0
        d = np.abs(x - center) / center
        a = 0.5 + 0.5 * d
        return a / a.sum()
    else:
        a = rng.uniform(0.1, 1.0, n)
        return a / a.sum()


def propose_candidate(seed=42, budget_s=1500):
    """
    Main search combining coordinate descent, multiplicative weights,
    lag targeting, high-tau polishing, and multi-start diversification.
    """
    start_time = time.monotonic()
    deadline = start_time + float(budget_s) - 25.0

    best_seq = None
    best_score = np.inf
    rng = np.random.default_rng(seed)

    # Load parent
    try:
        parent_arr = np.asarray(height_sequence_1, dtype=np.float64)
        parent_arr = np.clip(parent_arr, 0, None)
        if parent_arr.size > 0 and np.isfinite(parent_arr).all():
            s = float(np.sum(parent_arr))
            if s > 0.01:
                parent = parent_arr / s
                best_score = compute_obj(parent)
                best_seq = parent.copy()
                print(f"Parent (n={parent.size}): obj={best_score:.10f}")
    except Exception:
        parent = None

    if best_seq is None:
        n0 = 800
        best_seq = np.ones(n0) / n0
        best_score = compute_obj(best_seq)
        print(f"Default init (n={n0}): obj={best_score:.10f}")

    n_current = len(best_seq)

    # Phase 1: Multi-start with quick coordinate descent
    print("\n=== Phase 1: Multi-Start Coord Descent ===")
    remaining = deadline - time.monotonic()
    if remaining > 120:
        modes = [0, 1, 2, 4, 5, 6, 7, 9]
        for mode in modes:
            remaining = deadline - time.monotonic()
            if remaining < 25:
                break
            a_init = make_init(n_current, mode, rng)
            alloc = min(remaining * 0.07, 25.0)
            if alloc < 8:
                break
            a_cd = coord_descent_fast(a_init, time_budget=alloc, verbose=False, seed=mode * 137)
            obj = compute_obj(a_cd)
            if obj < best_score:
                best_score = obj
                best_seq = a_cd.copy()
                print(f"  Mode {mode}: obj={best_score:.10f} **")
            else:
                print(f"  Mode {mode}: obj={obj:.10f}")

    # Phase 2: Intensive coordinate descent on best
    print("\n=== Phase 2: Intensive Coord Descent ===")
    remaining = deadline - time.monotonic()
    if remaining > 150:
        alloc = min(remaining * 0.28, 350.0)
        a_cd = coord_descent_fast(best_seq, time_budget=alloc, verbose=True, seed=42, max_passes=500)
        obj = compute_obj(a_cd)
        if obj < best_score:
            best_score = obj
            best_seq = a_cd.copy()
            print(f"  CoordDec: obj={best_score:.10f} **")
        else:
            print(f"  CoordDec: obj={obj:.10f}")

    # Phase 3: Multiplicative weights (mirror descent)
    print("\n=== Phase 3: Multiplicative Weights ===")
    remaining = deadline - time.monotonic()
    if remaining > 100:
        alloc = min(remaining * 0.18, 250.0)
        a_mw = multiplicative_weights_opt(best_seq, time_budget=alloc, verbose=True, seed=77)
        obj = compute_obj(a_mw)
        if obj < best_score:
            best_score = obj
            best_seq = a_mw.copy()
            print(f"  MW: obj={best_score:.10f} **")
        else:
            print(f"  MW: obj={obj:.10f}")

    # Phase 4: Another coordinate descent round (after MW reshaped the landscape)
    print("\n=== Phase 4: Second Coord Descent ===")
    remaining = deadline - time.monotonic()
    if remaining > 100:
        alloc = min(remaining * 0.22, 250.0)
        a_cd2 = coord_descent_fast(best_seq, time_budget=alloc, verbose=True, seed=555, max_passes=400)
        obj = compute_obj(a_cd2)
        if obj < best_score:
            best_score = obj
            best_seq = a_cd2.copy()
            print(f"  CoordDec2: obj={best_score:.10f} **")
        else:
            print(f"  CoordDec2: obj={obj:.10f}")

    # Phase 5: Lag targeting
    print("\n=== Phase 5: Lag Targeting ===")
    remaining = deadline - time.monotonic()
    if remaining > 80:
        alloc = min(remaining * 0.15, 180.0)
        a_lt = lag_targeting(best_seq, time_budget=alloc, verbose=True, seed=111)
        obj = compute_obj(a_lt)
        if obj < best_score:
            best_score = obj
            best_seq = a_lt.copy()
            print(f"  LagTarget: obj={best_score:.10f} **")
        else:
            print(f"  LagTarget: obj={obj:.10f}")

    # Phase 6: Diversification - try perturbed restarts
    print("\n=== Phase 6: Diversification ===")
    remaining = deadline - time.monotonic()
    if remaining > 80:
        for restart_idx in range(3):
            remaining = deadline - time.monotonic()
            if remaining < 30:
                break
            a_pert = best_seq + 0.05 * np.random.default_rng(900 + restart_idx).standard_normal(n_current)
            a_pert = np.maximum(a_pert, 0)
            a_pert = a_pert / a_pert.sum()
            alloc = min(remaining * 0.15, 40.0)
            if alloc < 10:
                break
            a_r = coord_descent_fast(a_pert, time_budget=alloc, verbose=False, seed=2000 + restart_idx, max_passes=50)
            obj_r = compute_obj(a_r)
            if obj_r < best_score:
                best_score = obj_r
                best_seq = a_r.copy()
                print(f"  Restart {restart_idx}: obj={best_score:.10f} **")
            else:
                print(f"  Restart {restart_idx}: obj={obj_r:.10f}")

    # Phase 7: Multi-n exploration
    print("\n=== Phase 7: Multi-n Exploration ===")
    remaining = deadline - time.monotonic()
    if remaining > 80:
        n_options = sorted(set([
            n_current - 100, n_current - 50,
            n_current + 50, n_current + 100, n_current + 200,
            700, 900, 1000, 1200
        ]))
        n_options = [nn for nn in n_options if 400 <= nn <= 2000 and nn != n_current]
        n_options.sort(key=lambda x: abs(x - n_current))
        n_options = n_options[:4]
        print(f"  Candidates: {n_options}")

        for n_try in n_options:
            remaining = deadline - time.monotonic()
            if remaining < 40:
                break
            x_old = np.linspace(0, 1, len(best_seq))
            x_new = np.linspace(0, 1, n_try)
            a_try = np.interp(x_new, x_old, best_seq)
            a_try = np.maximum(a_try, 0)
            a_try = a_try / a_try.sum()
            alloc1 = min(remaining * 0.15, 30.0)
            if alloc1 > 8:
                a_try = coord_descent_fast(a_try, time_budget=alloc1, verbose=False, seed=n_try, max_passes=30)
            obj_try = compute_obj(a_try)
            if obj_try < best_score:
                best_score = obj_try
                best_seq = a_try.copy()
                n_current = n_try
                print(f"  ** n={n_try}: obj={best_score:.10f} **")
            else:
                print(f"  n={n_try}: obj={obj_try:.10f}")

    # Phase 8: Final intensive polish
    print("\n=== Phase 8: Final Polish ===")
    remaining = deadline - time.monotonic()
    if remaining > 30:
        alloc = min(remaining * 0.3, 80.0)
        a_f1 = coord_descent_fast(best_seq, time_budget=alloc, verbose=False, seed=31415, max_passes=100)
        obj_f1 = compute_obj(a_f1)
        if obj_f1 < best_score:
            best_score = obj_f1
            best_seq = a_f1.copy()
            print(f"  Final CD: obj={best_score:.10f} **")

    remaining = deadline - time.monotonic()
    if remaining > 25:
        alloc = min(remaining * 0.3, 60.0)
        a_f2 = high_tau_polish(best_seq, time_budget=alloc, verbose=False, seed=27182)
        obj_f2 = compute_obj(a_f2)
        if obj_f2 < best_score:
            best_score = obj_f2
            best_seq = a_f2.copy()
            print(f"  Final HT: obj={best_score:.10f} **")

    remaining = deadline - time.monotonic()
    if remaining > 20:
        alloc = min(remaining * 0.35, 50.0)
        a_f3 = lag_targeting(best_seq, time_budget=alloc, verbose=False, seed=16180)
        obj_f3 = compute_obj(a_f3)
        if obj_f3 < best_score:
            best_score = obj_f3
            best_seq = a_f3.copy()
            print(f"  Final LT: obj={best_score:.10f} **")

    remaining = deadline - time.monotonic()
    if remaining > 15:
        alloc = min(remaining * 0.5, 30.0)
        a_f4 = coord_descent_fast(best_seq, time_budget=alloc, verbose=False, seed=99999, max_passes=50)
        obj_f4 = compute_obj(a_f4)
        if obj_f4 < best_score:
            best_score = obj_f4
            best_seq = a_f4.copy()
            print(f"  Final CD2: obj={best_score:.10f} **")

    # Final validation
    if best_seq is None:
        best_seq = np.ones(200)

    result = [float(max(0.0, min(1000.0, x))) for x in best_seq]
    val = evaluate_sequence(result)
    if val < np.inf and val < best_score:
        best_score = val

    elapsed = time.monotonic() - start_time
    print(f"\n=== FINAL: n={len(result)}, score={best_score:.10f}, time={elapsed:.1f}s ===")
    return result
```
