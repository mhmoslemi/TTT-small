This is the (i+n-1)-th element of conv(a_rev, c) = conv(a_rev, c).

So grad[i] = 2 * conv(a_rev, c)[i+n-1] for i = 0, ..., n-1.

where a_rev is the time-reversal of a, and c = conv(a, a).

This can be computed in O(n log n) using FFT!

Great, so the algorithm is:
1. Given a (normalized, sum=1), compute c = conv(a, a) via FFT
2. Compute grad = 2 * conv(rev(a), c)[n-1 : 2n-1] (the relevant slice)
3. Take a step: a_new = a - alpha * grad
4. Project to non-negative simplex (a_new = max(0, a_new), then normalize)
5. Repeat

For the step size, we can use a backtracking line search or a fixed schedule.

But wait, minimizing sum(c[k]^2) is a proxy for minimizing max(c[k]). The proxy might lead to a different (and potentially worse) optimum than directly minimizing the max. However, it's much faster to compute the gradient, so we can take many more iterations.

**Alternative: Direct subgradient of the max**

The subgradient of max(c[k]) with respect to a[i] is a[k*-i] where k* is the argmax. This is simpler but only uses one active constraint. We could use the "top-K" active constraints for a better subgradient.

Actually, let me think about a hybrid approach:
1. Use the smooth proxy (sum of squares) gradient for fast descent
2. Periodically switch to the exact max-based objective for local refinement
3. Use the LP approach sparingly for final polish

**Another idea: Projection onto the set where all c[k] <= T**

At each iteration, given the current a, we know c = a*a. We want to find T such that there exists a' with a'*a' having all components <= T. This is exactly what the LP does, but we can approximate it with a simpler method.

**Let me now design the actual algorithm:**

Phase 1: FFT-based gradient descent on sum(c[k]^2) for fast convergence
Phase 2: Switch to subgradient descent on max(c[k]) for fine-tuning
Phase 3: LP polish for the final squeeze

The key advantage over the previous program is that Phase 1 is very fast (O(n log n) per iteration), allowing thousands of iterations in the time budget.

Let me also consider the **Nesterov acceleration** for the smooth phase:
- Use momentum: v = beta*v + grad
- a_new = a - alpha * v
- This can converge much faster than plain gradient descent.

For the step size, since the objective F(a) = sum(c[k]^2) is not convex in a (it's a quartic form), we need to be careful. But the Lipschitz constant of the gradient can be bounded, and we can use a backtracking line search.

Actually, for simplicity and robustness, let me use:
- Fixed step size with decay: alpha_t = alpha_0 / (1 + gamma * t)
- Or adaptive: alpha_t = alpha_0 * exp(-decay * t)
- With occasional restarts if stuck

Let me also think about the **normalization constraint**. The objective is scale-invariant (if we scale a by c, the objective doesn't change). So we can normalize at each step. The constraint is a[i] >= 0 and sum(a) = 1 (or equivalently, sum(a) > 0).

After the gradient step, we:
1. Clamp to non-negativity: a = max(0, a)
2. Normalize: a = a / sum(a)

This projection might introduce bias, but it should work in practice.

Given that the optimum likely has a "bump" shape (high in the middle, low at the ends), good initializations would be:

- The previous U-shape (inverted: high in middle, low at ends)

OK so the bump shape (high center, low edges) makes sense. The convolution of a bump with itself is also a bump (wider), and we want it to be as flat as possible. A bump shape for a means the convolution is a wider bump, which has a peak in the center. To flatten it, we might want a shape that when self-convolved gives a flat result.

For example, if a is a "top-hat" (rectangle), the convolution is a triangle. To get a flat convolution, a should be something like the inverse of a flat spectrum, which in the time domain is a sinc-like function. But sinc has negative lobes, which we can't use (non-negativity constraint).

So the non-negativity constraint is the main limitation. The best we can do is approximate a flat convolution with a non-negative sequence.

```python
"""
FFT-based gradient optimization for minimizing the max autocorrelation of
a non-negative step function. Uses smooth proxy (sum of squares of
convolution) for fast gradient descent, then switches to exact max-based
subgradient, and finishes with LP polish.
"""

import numpy as np
from scipy.fft import rfft, irfft
import time
import cvxpy as cp


def get_fft_size(n):
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    return size


def compute_conv(a):
    n = len(a)
    size = get_fft_size(n)
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    n = len(a)
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))


def compute_conv_sum_sq(a):
    """Compute sum of squares of convolution (smooth proxy objective)."""
    conv = compute_conv(a)
    return float(np.sum(conv ** 2))


def compute_grad_sum_sq(a):
    """
    Compute gradient of sum(c[k]^2) where c = conv(a, a).
    grad[i] = 2 * sum_j a[j] * c[i+j] for valid indices.
    Computed via: grad = 2 * conv(rev(a), c)[n-1 : 2n-1]
    """
    n = len(a)
    c = compute_conv(a)
    a_rev = a[::-1]
    # conv(a_rev, c) has length n + (2n-1) - 1 = 3n - 2
    size = get_fft_size(3 * n)
    fa_rev = rfft(a_rev, size)
    fc = rfft(c, size)
    conv_ac = irfft(fa_rev * fc, size)[:3 * n - 2]
    # grad[i] = 2 * conv_ac[i + n - 1] for i = 0, ..., n-1
    grad = 2.0 * conv_ac[n - 1:2 * n - 1]
    return grad


def compute_subgrad_max(a):
    """
    Compute subgradient of max(c[k]) where c = conv(a, a).
    Returns subgradient vector of length n.
    """
    n = len(a)
    c = compute_conv(a)
    k_max = int(np.argmax(c))
    grad = np.zeros(n)
    for i in range(n):
        j = k_max - i
        if 0 <= j < n:
            grad[i] = a[j]
    return grad


def project_nonnegative_simplex(a):
    """Project to {a >= 0, sum(a) = 1}."""
    a = np.maximum(a, 0)
    s = float(np.sum(a))
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s


def fft_gradient_descent(a, time_budget=200.0, alpha_init=0.01, decay=0.999, 
                          momentum_init=0.8, momentum_decay=0.9999, verbose=False):
    """
    Nesterov-momentum gradient descent on sum(conv(a,a)^2).
    """
    n = len(a)
    a = project_nonnegative_simplex(a.copy())
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    alpha = alpha_init
    momentum = momentum_init
    v = np.zeros(n)
    it = 0
    best_it = 0
    
    while time.monotonic() - start < time_budget:
        # Compute gradient
        grad = compute_grad_sum_sq(a)
        
        # Momentum update
        v = momentum * v - alpha * grad
        a_new = a + v
        a_new = project_nonnegative_simplex(a_new)
        
        # Check objective (exact)
        obj = compute_obj(a_new)
        if obj < best_obj:
            best_obj = obj
            best_a = a_new.copy()
            best_it = it
        
        a = a_new
        alpha *= decay
        momentum = min(0.9999, momentum * momentum_decay + 1e-6)
        it += 1
        
        # Restart if stuck
        if it - best_it > 2000:
            a = best_a.copy()
            v = np.zeros(n)
            alpha = alpha_init * 0.5
            it = best_it
            if verbose:
                print(f"      GDE restart at it={it}, obj={best_obj:.8f}")
        
        if verbose and it % 500 == 0:
            elapsed = time.monotonic() - start
            print(f"      GDE it={it}: obj={best_obj:.8f}, alpha={alpha:.6f}, elapsed={elapsed:.1f}s")
    
    return best_a, best_obj


def subgradient_refine(a, time_budget=50.0, verbose=False):
    """
    Subgradient descent on the exact max objective.
    Uses Nesterov acceleration and adaptive step size.
    """
    n = len(a)
    a = project_nonnegative_simplex(a.copy())
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    x_avg = a.copy()
    y = a.copy()
    t = 1.0
    it = 0
    best_it = 0
    
    while time.monotonic() - start < time_budget:
        # Compute subgradient at y
        c_y = compute_conv(y)
        k_max = int(np.argmax(c_y))
        # Subgradient: for the active lag k_max
        # subgrad[i] = y[k_max - i] if 0 <= k_max - i < n, else 0
        subgrad = np.zeros(n)
        for i in range(n):
            j = k_max - i
            if 0 <= j < n:
                subgrad[i] = y[j]
        
        # Nesterov step
        t_new = (1 + np.sqrt(1 + 4 * t * t)) / 2
        gamma_t = 2.0 / (t_new + 1)
        
        y_new = y - gamma_t * subgrad
        y_new = project_nonnegative_simplex(y_new)
        
        x_avg = ((t - 1) / t_new) * x_avg + (1 / t_new) * y_new
        x_avg = project_nonnegative_simplex(x_avg)
        
        obj = compute_obj(x_avg)
        if obj < best_obj:
            best_obj = obj
            best_a = x_avg.copy()
            best_it = it
        
        y = y_new
        t = t_new
        it += 1
        
        if it - best_it > 1000:
            x_avg = best_a.copy()
            y = best_a.copy()
            t = 1.0
            if verbose:
                print(f"      SG restart at it={it}, obj={best_obj:.8f}")
        
        if verbose and it % 200 == 0:
            elapsed = time.monotonic() - start
            print(f"      SG it={it}: obj={best_obj:.8f}, t={t:.1f}, elapsed={elapsed:.1f}s")
    
    return best_a, best_obj


def multi_lag_subgradient(a, time_budget=60.0, K=5, verbose=False):
    """
    Subgradient using top-K active lags for a better direction.
    """
    n = len(a)
    a = project_nonnegative_simplex(a.copy())
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    alpha = 0.005
    v = np.zeros(n)
    momentum = 0.7
    
    while time.monotonic() - start < time_budget:
        c = compute_conv(a)
        # Find top-K lags
        top_k = np.argsort(c)[::-1][:K]
        
        # Average subgradient over top-K lags
        grad = np.zeros(n)
        for k in top_k:
            k = int(k)
            for i in range(n):
                j = k - i
                if 0 <= j < n:
                    grad[i] += a[j]
        grad /= K
        
        # Momentum step
        v = momentum * v - alpha * grad
        a_new = a + v
        a_new = project_nonnegative_simplex(a_new)
        
        obj = compute_obj(a_new)
        if obj < best_obj:
            best_obj = obj
            best_a = a_new.copy()
        
        a = a_new
        alpha *= 0.9999
        
        if verbose:
            elapsed = time.monotonic() - start
            if int((time.monotonic() - start) * 4) != int(elapsed * 4):
                print(f"      MultiSG: obj={best_obj:.8f}, elapsed={elapsed:.1f}s")
    
    return best_a, best_obj


def build_conv_matrix(a):
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        A[j:j + n, j] = a[:min(n, 2*n-1-j)]
    return A


def solve_lp(a):
    n = len(a)
    a_norm = a / float(np.sum(a))
    A = build_conv_matrix(a_norm)
    g = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [A @ g <= M, cp.sum(g) == 1]
    prob = cp.Problem(cp.Minimize(M), constraints)
    for solver in [cp.CLARABEL, cp.ECOS, cp.SCS]:
        try:
            prob.solve(solver=solver)
            if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g.value, 0)
                s = float(np.sum(g_val))
                if s > 1e-10:
                    return g_val / s, float(M.value)
        except Exception:
            continue
    return None, None


def lp_polish(a, time_budget=60.0, max_iters=50):
    n = len(a)
    a = project_nonnegative_simplex(a.copy())
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    
    while time.monotonic() - start < time_budget:
        remaining = time_budget - (time.monotonic() - start)
        if remaining < 10:
            break
        
        g_lp, M_lp = solve_lp(a)
        if g_lp is None:
            break
        
        # Line search
        best_t = 0.0
        best_obj_ls = best_obj
        for t in np.linspace(0, 1.2, 20):
            a_try = (1 - t) * a + t * g_lp
            a_try = project_nonnegative_simplex(a_try)
            obj = compute_obj(a_try)
            if obj < best_obj_ls:
                best_obj_ls = obj
                best_t = t
        
        if best_t > 1e-6 and best_obj_ls < best_obj - 1e-12:
            a_new = (1 - best_t) * a + best_t * g_lp
            a_new = project_nonnegative_simplex(a_new)
            best_obj = compute_obj(a_new)
            best_a = a_new.copy()
            a = a_new
        else:
            break
    
    return best_a


def diverse_init(n, rng, mode=0):
    x = np.linspace(0, 1, n)
    idx = np.arange(n, dtype=np.float64)
    if mode == 0:
        # Gaussian bump
        sigma = n / 6.0
        a = np.exp(-((idx - n / 2) ** 2) / (2 * sigma ** 2))
    elif mode == 1:
        # Wide Gaussian
        sigma = n / 4.0
        a = np.exp(-((idx - n / 2) ** 2) / (2 * sigma ** 2))
    elif mode == 2:
        # Raised cosine
        a = 0.5 * (1 + np.cos(2 * np.pi * (x - 0.5)))
    elif mode == 3:
        # Power bump
        a = (1 - (2 * x - 1) ** 4)
    elif mode == 4:
        # Inverted U with flat top
        t = np.abs(2 * x - 1)
        a = np.where(t < 0.3, 1.0, np.exp(-5 * (t - 0.3)))
    elif mode == 5:
        # Two bumps
        a = np.exp(-((idx - n * 0.3) ** 2) / (2 * (n / 8) ** 2)) + \
            np.exp(-((idx - n * 0.7) ** 2) / (2 * (n / 8) ** 2))
    elif mode == 6:
        # Previous U-shape (high center)
        a = 1.0 / (0.05 + 3.0 * (2 * x - 1) ** 2)
    elif mode == 7:
        # Sharp center
        a = 1.0 / (0.01 + 10.0 * (2 * x - 1) ** 2)
    else:
        a = np.ones(n)
    a = np.maximum(a, 0.01)
    return a / a.sum()


def interpolate_sequence(a_src, n_dst):
    n_src = len(a_src)
    x_src = np.linspace(0, 1, n_src)
    x_dst = np.linspace(0, 1, n_dst)
    a_dst = np.interp(x_dst, x_src, a_src)
    a_dst = np.maximum(a_dst, 0)
    s = float(np.sum(a_dst))
    if s < 0.01:
        return None
    return a_dst / s
```

```python
"""
FFT-based Adam gradient descent on smooth proxy (sum of conv^2), combined with
multi-lag subgradient refinement and LP polish for minimizing max autocorrelation
of non-negative step functions. Key innovation: fast per-iteration cost via FFT
enables thousands of optimization steps, far exceeding the LP-only approach.
"""

import numpy as np
from scipy.fft import rfft, irfft
import time
import cvxpy as cp


def get_fft_size(n):
    size = 1
    while size < n:
        size <<= 1
    return size


def compute_conv(a):
    n = len(a)
    if n == 0:
        return np.array([])
    size = get_fft_size(2 * n - 1)
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj(a):
    n = len(a)
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))


def project_simplex(a, floor=1e-10):
    a = np.maximum(a, floor)
    s = float(np.sum(a))
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s


def fft_adam_descent(a, time_budget=300.0, lr=0.002, beta1=0.9, beta2=0.999,
                     verbose=True, restart_interval=2000):
    n = len(a)
    a = project_simplex(a.copy())
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()

    m = np.zeros(n)
    v = np.zeros(n)
    t = 0
    it = 0
    best_it = 0
    size_grad = get_fft_size(3 * n)
    size_conv = get_fft_size(2 * n - 1)

    while time.monotonic() - start < time_budget:
        # Compute convolution of current a
        fa = rfft(a, size_conv)
        c = irfft(fa * fa, size_conv)[:2 * n - 1]

        # Compute gradient: 4 * conv(rev(a), c)[n-1 : 2n-1]
        a_rev = a[::-1]
        fa_rev = rfft(a_rev, size_grad)
        fc = rfft(c, size_grad)
        conv_ac = irfft(fa_rev * fc, size_grad)[:3 * n - 2]
        grad = 4.0 * conv_ac[n - 1:2 * n - 1]

        # Adam update
        t += 1
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)

        a_new = a - lr * m_hat / (np.sqrt(v_hat) + 1e-8)
        a_new = project_simplex(a_new)

        # Check exact objective
        fa_new = rfft(a_new, size_conv)
        c_new = irfft(fa_new * fa_new, size_conv)[:2 * n - 1]
        obj = 2.0 * n * float(np.max(c_new))

        if obj < best_obj:
            best_obj = obj
            best_a = a_new.copy()
            best_it = it

        a = a_new
        it += 1

        if it - best_it > restart_interval:
            a = best_a.copy()
            m = np.zeros(n)
            v = np.zeros(n)
            t = 0
            if verbose:
                print(f"      Adam restart it={it}, obj={best_obj:.8f}")

        if verbose and it % 5000 == 0:
            elapsed = time.monotonic() - start
            print(f"      Adam it={it}: obj={best_obj:.8f}, elapsed={elapsed:.1f}s")

    return best_a, best_obj


def multi_lag_subgradient(a, time_budget=60.0, K=5, verbose=True):
    n = len(a)
    a = project_simplex(a.copy())
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()

    alpha = 0.003
    v = np.zeros(n)
    momentum = 0.7
    it = 0
    best_it = 0

    while time.monotonic() - start < time_budget:
        c = compute_conv(a)
        top_k = np.argsort(c)[::-1][:K]

        grad = np.zeros(n)
        for k in top_k:
            k = int(k)
            for i in range(n):
                j = k - i
                if 0 <= j < n:
                    grad[i] += a[j]
        grad /= K

        v = momentum * v - alpha * grad
        a_new = a + v
        a_new = project_simplex(a_new)

        obj = compute_obj(a_new)
        if obj < best_obj:
            best_obj = obj
            best_a = a_new.copy()
            best_it = it

        a = a_new
        alpha *= 0.9999
        it += 1

        if it - best_it > 1500:
            a = best_a.copy()
            v = np.zeros(n)
            alpha = 0.001

        if verbose and it % 500 == 0:
            elapsed = time.monotonic() - start
            print(f"      MultiSG it={it}: obj={best_obj:.8f}, elapsed={elapsed:.1f}s")

    return best_a, best_obj


def build_conv_matrix(a):
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        r = min(n, 2 * n - 1 - j)
        A[j:j + r, j] = a[:r]
    return A


def solve_lp(a):
    n = len(a)
    a_norm = a / float(np.sum(a))
    A = build_conv_matrix(a_norm)
    g = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [A @ g <= M, cp.sum(g) == 1]
    prob = cp.Problem(cp.Minimize(M), constraints)
    for solver in [cp.CLARABEL, cp.ECOS, cp.SCS]:
        try:
            prob.solve(solver=solver)
            if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g.value, 0)
                s = float(np.sum(g_val))
                if s > 1e-10:
                    return g_val / s, float(M.value)
        except Exception:
            continue
    return None, None


def lp_polish(a, time_budget=80.0, max_iters=40, verbose=False):
    n = len(a)
    a = project_simplex(a.copy())
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()

    while time.monotonic() - start < time_budget:
        remaining = time_budget - (time.monotonic() - start)
        if remaining < 12:
            break

        T0 = time.monotonic()
        g_lp, M_lp = solve_lp(a)
        lp_time = time.monotonic() - T0
        if g_lp is None:
            break

        best_t = 0.0
        best_obj_ls = best_obj
        for t in np.linspace(0, 1.2, 25):
            a_try = (1.0 - t) * a + t * g_lp
            a_try = project_simplex(a_try)
            obj = compute_obj(a_try)
            if obj < best_obj_ls:
                best_obj_ls = obj
                best_t = t

        if best_t > 1e-6 and best_obj_ls < best_obj - 1e-14:
            a_new = (1.0 - best_t) * a + best_t * g_lp
            a_new = project_simplex(a_new)
            best_obj = compute_obj(a_new)
            best_a = a_new.copy()
            a = a_new
            if verbose:
                print(f"      LP: obj={best_obj:.8f}, t={best_t:.4f}, "
                      f"lp_time={lp_time:.1f}s")
        else:
            obj_direct = compute_obj(g_lp)
            if obj_direct < best_obj:
                best_obj = obj_direct
                best_a = g_lp.copy()
                a = g_lp.copy()
                if verbose:
                    print(f"      LP direct: obj={best_obj:.8f}")
            else:
                break

    return best_a, best_obj


def diverse_init(n, rng, mode=0):

    if mode == 0:
        sigma = n / 6.0
        a = np.exp(-((idx - n / 2) ** 2) / (2 * sigma ** 2))
    elif mode == 1:
        sigma = n / 4.0
        a = np.exp(-((idx - n / 2) ** 2) / (2 * sigma ** 2))
    elif mode == 2:
        a = 0.5 * (1.0 + np.cos(2.0 * np.pi * (x - 0.5)))
    elif mode == 3:
        a = np.maximum(1.0 - (2.0 * x - 1.0) ** 4, 0.01)
    elif mode == 4:
        t = np.abs(2.0 * x - 1.0)
        a = np.where(t < 0.3, 1.0, np.exp(-5.0 * (t - 0.3)))
    elif mode == 5:
        a = np.exp(-((idx - n * 0.3) ** 2) / (2 * (n / 8) ** 2)) + \
            np.exp(-((idx - n * 0.7) ** 2) / (2 * (n / 8) ** 2))
    elif mode == 6:
        a = 1.0 / (0.05 + 3.0 * (2.0 * x - 1.0) ** 2)
    elif mode == 7:
        a = 1.0 / (0.01 + 8.0 * (2.0 * x - 1.0) ** 2)
    elif mode == 8:
        a = np.exp(-3.0 * (2.0 * x - 1.0) ** 4)
    else:
        a = np.ones(n)
    a = np.maximum(a, 0.01)
    return a / a.sum()


def interpolate_sequence(a_src, n_dst):
    n_src = len(a_src)
    x_src = np.linspace(0, 1, n_src)
    x_dst = np.linspace(0, 1, n_dst)
    a_dst = np.interp(x_dst, x_src, a_src)
    a_dst = np.maximum(a_dst, 0.01)
    return a_dst / a_dst.sum()


def propose_candidate(seed=42, budget_s=1500):
    start_time = time.monotonic()
    deadline = start_time + float(budget_s) - 25.0
    rng = np.random.default_rng(seed)

    # Load parent or default init
    try:
        parent_arr = np.asarray(height_sequence_1, dtype=np.float64)
        parent_arr = np.clip(parent_arr, 0, None)
        s = float(np.sum(parent_arr))
        if s > 0.01:
            best_seq = parent_arr / s
            best_score = compute_obj(best_seq)
            print(f"Parent loaded: n={parent_arr.size}, obj={best_score:.8f}")
        else:
            raise ValueError("Sum too small")
    except Exception:
        best_seq = diverse_init(800, rng, mode=6)
        best_score = compute_obj(best_seq)
        print(f"Default init: n={len(best_seq)}, obj={best_score:.8f}")

    n_best = len(best_seq)

    # Try alternative initializations
    for mode in range(9):
        a_alt = diverse_init(n_best, rng, mode=mode)
        obj_alt = compute_obj(a_alt)
        if obj_alt < best_score:
            best_score = obj_alt
            best_seq = a_alt.copy()
            print(f"  Alt init mode={mode}: obj={best_score:.8f} **")

    # === Phase 1: FFT Adam Gradient Descent ===
    remaining = deadline - time.monotonic()
    if remaining > 100:
        alloc = min(remaining * 0.35, 450.0)
        print(f"\n=== Phase 1: FFT Adam GD (n={n_best}, budget={alloc:.0f}s) ===")
        a_gd, obj_gd = fft_adam_descent(best_seq, time_budget=alloc,
                                         lr=0.002, beta1=0.9, beta2=0.999,
                                         verbose=True, restart_interval=3000)
        if obj_gd < best_score:
            best_score = obj_gd
            best_seq = a_gd.copy()
            print(f"  Phase 1 done: obj={best_score:.8f} **")
        else:
            print(f"  Phase 1 done: obj={obj_gd:.8f} (no improvement)")

    # === Phase 2: Multi-lag subgradient ===
    remaining = deadline - time.monotonic()
    if remaining > 50:
        alloc = min(remaining * 0.1, 80.0)
        print(f"\n=== Phase 2: Multi-lag Subgradient (budget={alloc:.0f}s) ===")
        a_ml, obj_ml = multi_lag_subgradient(best_seq, time_budget=alloc, K=5, verbose=True)
        if obj_ml < best_score:
            best_score = obj_ml
            best_seq = a_ml.copy()
            print(f"  Phase 2 done: obj={best_score:.8f} **")
        else:
            print(f"  Phase 2 done: obj={obj_ml:.8f} (no improvement)")

    # === Phase 3: LP Polish ===
    remaining = deadline - time.monotonic()
    if remaining > 80:
        alloc = min(remaining * 0.2, 160.0)
        print(f"\n=== Phase 3: LP Polish (budget={alloc:.0f}s) ===")
        a_lp = lp_polish(best_seq, time_budget=alloc, max_iters=50, verbose=True)
        obj_lp = compute_obj(a_lp)
        if obj_lp < best_score:
            best_score = obj_lp
            best_seq = a_lp.copy()
            print(f"  Phase 3 done: obj={best_score:.8f} **")
        else:
            print(f"  Phase 3 done: obj={obj_lp:.8f} (no improvement)")

    # === Phase 4: FFT Adam GD Round 2 (finer lr) ===
    remaining = deadline - time.monotonic()
    if remaining > 60:
        alloc = min(remaining * 0.15, 100.0)
        print(f"\n=== Phase 4: FFT Adam GD Round 2 (budget={alloc:.0f}s) ===")
        a_gd2, obj_gd2 = fft_adam_descent(best_seq, time_budget=alloc,
                                           lr=0.0005, beta1=0.95, beta2=0.999,
                                           verbose=True, restart_interval=5000)
        if obj_gd2 < best_score:
            best_score = obj_gd2
            best_seq = a_gd2.copy()
            print(f"  Phase 4 done: obj={best_score:.8f} **")
        else:
            print(f"  Phase 4 done: obj={obj_gd2:.8f} (no improvement)")

    # === Phase 5: n Exploration ===
    remaining = deadline - time.monotonic()
    if remaining > 120:
        print(f"\n=== Phase 5: n Exploration ===")
        n_best = len(best_seq)
        n_options = sorted(set([
            max(300, n_best - 200), max(300, n_best - 100),
            n_best + 100, n_best + 200, n_best + 400,
            500, 700, 900, 1000, 1200, 1400
        ]))
        n_options = [n for n in n_options if 400 <= n <= 2000 and abs(n - n_best) >= 50]
        n_options.sort(key=lambda x: abs(x - n_best))
        n_options = n_options[:5]
        print(f"  Trying n values: {n_options}")

        for n_try in n_options:
            remaining = deadline - time.monotonic()
            if remaining < 80:
                break
            a_try = interpolate_sequence(best_seq, n_try)
            # Quick Adam GD
            a_try2, obj_try2 = fft_adam_descent(a_try, time_budget=min(remaining * 0.35, 50.0),
                                                 lr=0.002, verbose=False, restart_interval=2000)
            remaining2 = deadline - time.monotonic()
            if remaining2 > 25:
                a_try3, _ = lp_polish(a_try2, time_budget=min(remaining2 * 0.4, 30.0),
                                       max_iters=15, verbose=False)
                obj_try = compute_obj(a_try3)
                if obj_try < obj_try2:
                    a_try2 = a_try3
            else:
                obj_try = obj_try2

            if obj_try < best_score:
                best_score = obj_try
                best_seq = a_try2.copy()
                print(f"  ** n={n_try}: obj={best_score:.8f} **")
            else:
                print(f"  n={n_try}: obj={obj_try:.8f}")

    # === Phase 6: Final LP Polish ===
    remaining = deadline - time.monotonic()
    if remaining > 40:
        alloc = min(remaining - 15, 100.0)
        print(f"\n=== Phase 6: Final LP Polish (budget={alloc:.0f}s) ===")
        a_final = lp_polish(best_seq, time_budget=alloc, max_iters=40, verbose=True)
        obj_final = compute_obj(a_final)
        if obj_final < best_score:
            best_score = obj_final
            best_seq = a_final.copy()
            print(f"  Final LP: obj={best_score:.8f} **")
        else:
            print(f"  Final LP: obj={obj_final:.8f}")

    # === Phase 7: Final Adam Squeeze ===
    remaining = deadline - time.monotonic()
    if remaining > 30:
        alloc = min(remaining - 10, 50.0)
        print(f"\n=== Phase 7: Final Adam Squeeze (budget={alloc:.0f}s) ===")
        a_sq, obj_sq = fft_adam_descent(best_seq, time_budget=alloc,
                                         lr=0.0003, beta1=0.95, beta2=0.9999,
                                         verbose=False, restart_interval=5000)
        if obj_sq < best_score:
            best_score = obj_sq
            best_seq = a_sq.copy()
            print(f"  Squeeze: obj={best_score:.8f} **")

    # Final validation
    if best_seq is None or len(best_seq) == 0:
        best_seq = np.ones(200)

    result = [float(max(0.0, min(1000.0, x))) for x in best_seq]
    val = evaluate_sequence(result)
    if val < np.inf:
        best_score = val
    else:
        result = [1.0] * 100
        best_score = evaluate_sequence(result)

    elapsed = time.monotonic() - start_time
    print(f"\n=== FINAL: n={len(result)}, score={best_score:.8f}, time={elapsed:.1f}s ===")
    return result
```
