`conv(p, a_flipped)[i + n - 1] = sum_j p[i+n-1-j] * a_flipped[j] = sum_j p[i+n-1-j] * a[n-1-j]`

Let `l = n-1-j`, so `j = n-1-l`:
`= sum_l p[i+n-1-(n-1-l)] * a[l] = sum_l p[i+l] * a[l]`

Yes! So `g_non_diag[i] = conv(p, a_flipped)[i + n - 1]`

Where `a_flipped = a[::-1]` and `conv` is the full linear convolution.

Let me verify: `conv(p, a_flipped)[i+n-1] = sum_j p[j] * a_flipped[i+n-1-j]`
`= sum_j p[j] * a[n-1-(i+n-1-j)] = sum_j p[j] * a[j-i]`

Hmm, that gives `sum_j p[j] * a[j-i]` not `sum_j p[j+i] * a[j]`.

Let me try the other way: `conv(a_flipped, p)[i+n-1] = sum_j a_flipped[j] * p[i+n-1-j]`
`= sum_j a[n-1-j] * p[i+n-1-j]`
Let `l = n-1-j`: `= sum_l a[l] * p[i+l]`

Yes! That's what we want: `g_non_diag[i] = conv(a_flipped, p)[i+n-1]`

Or equivalently, since convolution is commutative: `g_non_diag[i] = conv(p, a_flipped)[i+n-1]`

So I can compute the full gradient using FFT:
1. Compute `conv_a = conv(a, a_flipped)` via FFT → gives `g_non_diag`
2. Add diagonal correction: `g[i] += p[2*i] * a[i]` (if `2*i < 2n-1`)

This is O(n log n) per iteration, which is great.

Now let me think about the step size. For mirror descent on the simplex, the standard result gives convergence rate O(1/sqrt(T)) for convex objectives. But our objective is not convex, so we can't guarantee convergence. However, in practice, the method should still work well.

For the step size, I'll use an adaptive approach:

"""
Optimizes step function coefficients to minimize 2*n*max(conv(a,a))/(sum(a))^2.
Uses softmax-smoothed mirror descent (multiplicative weights) as the primary
method, combined with LP alternating for polishing and multi-length exploration.
The mirror descent approach exploits the correlation structure of the gradient
(gradient of max convolution entry is a shifted copy of the sequence itself),
enabling O(n log n) iterations via FFT.

import numpy as np
import cvxpy as cp
import time
from scipy.fft import rfft, irfft


def compute_conv(a):
    """Full linear convolution a*a via FFT. Returns array of length 2n-1."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj_norm(a):
    """Compute objective assuming sum(a)=1: 2*n*max(conv(a,a))."""
    n = len(a)
    conv = compute_conv(a)
    return 2.0 * n * float(np.max(conv))


def softmax_mirror_descent(a, time_budget, T_init=100.0, T_growth=1.005,

    """

        return a

    a_flip = a[::-1]

        t += 1
        conv = compute_conv(a)
        k_star = int(np.argmax(conv))

        size = 1

            size <<= 1

        fp = rfft(p, size)
        corr = irfft(fa * fp, size)

def build_conv_matrix(a):
    """Build matrix A (2n-1 x n) such that A @ g = conv(a, g)."""
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        A[j:j + n, j] = a
    return A


def solve_lp(a, warm_start=None):
    """
    Solve LP: min M s.t. (a*g)[k] <= M for all k, sum(g)=1, g>=0.
    Returns (g_opt, M_opt) or (None, None).
    """
    n = len(a)
    a_norm = a / float(np.sum(a))
    A = build_conv_matrix(a_norm)
    
    g = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [A @ g <= M, cp.sum(g) == 1]
    prob = cp.Problem(cp.Minimize(M), constraints)
    
    if warm_start is not None:
        try:
            g.value = warm_start.copy()
        except Exception:
            pass
    
    for solver in ['CLARABEL', 'SCS', 'ECOS', 'PDLP']:
        try:
            prob.solve(solver=getattr(cp, solver))
            if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(np.asarray(g.value), 0)
                s = float(np.sum(g_val))
                if s > 1e-10:
                    return g_val / s, float(M.value)
        except Exception:
            continue
    return None, None

def fourier_perturb(a, rng, strength=0.02):
    """Add structured Fourier perturbation to escape local minima."""
    n = len(a)
    pert = np.zeros(n)
    for k in range(1, 10):
        freq = k * 2.0 * np.pi / n
        amp = strength * rng.uniform(0.5, 1.5) / k
        phase = rng.uniform(0, 2.0 * np.pi)
        pert += amp * np.cos(freq * np.arange(n) + phase)
    a_new = a * np.exp(pert)
    a_new = np.maximum(a_new, 0)
    s = float(np.sum(a_new))
    if s < 1e-10:
        return a.copy()
    return a_new / s


def random_structured_init(n, rng):
    """Create a random but structured initial sequence."""
    # Mix of smooth and oscillatory components
    a = np.ones(n) / n
    for k in range(1, 5):
        freq = rng.integers(1, max(2, n // (2 * k)))
        amp = rng.uniform(0.1, 0.5) / k
        phase = rng.uniform(0, 2 * np.pi)
        a += amp * np.cos(2 * np.pi * freq * np.arange(n) / n + phase)
    a = np.maximum(a, 0)
    s = float(np.sum(a))
    if s < 1e-10:
        return np.ones(n) / n
    return a / s

We want: `g[i] = sum_{k=i}^{min(i+n-1, 2n-2)} p[k] * a[k-i]`

Let me write this as: `g[i] = sum_{j=0}^{n-1} p[i+j] * a[j]` (where p[k]=0 for k >= 2n-1)

Now, the convolution `conv(X, Y)[m] = sum_j X[j] * Y[m-j]`

If I set `X = a` (length n) and `Y = p` (length 2n-1), then:
`conv(a, p)[m] = sum_j a[j] * p[m-j]`

I want `g[i] = sum_j a[j] * p[i+j]`.

If I set `m = -i` in the convolution... that's negative, so it's in the "cross-correlation" regime.

The cross-correlation is: `corr(i) = sum_j a[j] * p[j+i]`

This is `corr = conv(a, p_flipped)` where `p_flipped[k] = p[2n-2-k]` (reversed p).

`conv(a, p_flipped)[m] = sum_j a[j] * p_flipped[m-j] = sum_j a[j] * p[2n-2-(m-j)] = sum_j a[j] * p[2n-2-m+j]`

Set `2n-2-m = i`: `m = 2n-2-i`
`conv(a, p_flipped)[2n-2-i] = sum_j a[j] * p[i+j]`

So `g[i] = conv(a, p_flipped)[2n-2-i]` for i = 0, ..., n-1.

This means I compute the full convolution of `a` and `p_flipped` (both zero-padded to appropriate length), then take indices `2n-2-n+1 = n-1` through `2n-2-0 = 2n-2`.

Wait, for i=0: index = 2n-2
For i=n-1: index = 2n-2-(n-1) = n-1

So `g = conv_full(a, p_flipped)[n-1 : 2n-1][::-1]`

Or equivalently, `g[i] = conv_full(a, p_flipped)[2n-2-i]`

Let me verify with a tiny example. n=2, a=[a0, a1], p=[p0, p1, p2] (2n-1=3 entries).

g[0] = p[0]*a[0] + p[1]*a[1]
g[1] = p[1]*a[0] + p[2]*a[1]

p_flipped = [p2, p1, p0]

conv_full(a, p_flipped) has length 2+3-1=4:
index 0: a0*p2
index 1: a0*p1 + a1*p2
index 2: a0*p0 + a1*p1
index 3: a1*p0

g[0] = conv[2n-2-0] = conv[2] = a0*p0 + a1*p1 ✓
g[1] = conv[2n-2-1] = conv[1] = a0*p1 + a1*p2 ✓

So `g[i] = conv_full(a, p_flipped)[2*n-2-i]`

In code:
```python
p_flip = p[::-1]  # length 2n-1
size = 1
while size < n + 2*n - 1:  # = 3n-1
    size <<= 1
conv_full = irfft(rfft(a, size) * rfft(p_flip, size), size)[:n + 2*n - 2]

# g[i] = conv_full[2*n-2-i] for i=0..n-1
g = conv_full[2*n-2 : n-2 : -1]  # from index 2n-2 down to n-1
# Or: g[i] = conv_full[2*n-2-i]
g = np.array([conv_full[2*n-2-i] for i in range(n)])
# Or vectorized:
indices = 2*n-2 - np.arange(n)  # [2n-2, 2n-3, ..., n-1]
g = conv_full[indices]
```
