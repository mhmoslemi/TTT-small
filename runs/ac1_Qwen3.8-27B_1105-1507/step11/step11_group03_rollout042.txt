    """Find optimal t in [0,1] minimizing f((1-t)*a + t*g) using golden section."""
    # f is convex in t, so golden section works
    gr = (np.sqrt(5) - 1) / 2  # golden ratio ~ 0.618
    
    lo, hi = 0.0, 1.0
    c = lo + (1 - gr) * (hi - lo)
    d = lo + gr * (hi - lo)
    
    fc = compute_obj((1-c)*a + c*g)
    fd = compute_obj((1-d)*a + d*g)
    
    for _ in range(n_evals - 2):
        if fc < fd:
            hi = d
            d = c
            fd = fc
            c = lo + (1 - gr) * (hi - lo)
            fc = compute_obj((1-c)*a + c*g)
        else:
            lo = c
            c = d
            fc = fd
            d = lo + gr * (hi - lo)

    t = (lo + hi) / 2

The key insight: `max_k (a*a)_k` is related to the `L_infinity` norm of the DTFT of a (squared, specifically). If I define the DTFT as `A(omega) = sum_k a_k * e^{-i*omega*k}`, then `|A(omega)|^2` has its peak at some frequency. Minimizing this peak (given A(0) = 1) is a classical problem.

4. Renormalize
5. Update A to reduce the peak

    a = a.copy() / a.sum()
    best_obj = compute_obj(a)

    # Zero-pad to length N (power of 2) for FFT
    N = 1
    while N < 2 * n:
        N <<= 1
    
    # Define target spectrum: we want |A(omega)|^2 to be as flat as possible
    # Subject to A(0) = 1 (DC component)
    
    for it in range(10000):
        if time.monotonic() - start > time_budget:
            break
        
        a_padded = np.zeros(N, dtype=complex)
        a_padded[:n] = a
        A = np.fft.fft(a_padded)
        
        # |A|^2 is the power spectrum
        # The peak of linear convolution is related to the peak of |A|^2
        # (not exactly, due to the linear vs circular convolution difference)
        
        # Strategy: where |A|^2 is above the mean, reduce it; where below, increase it
        mag = np.abs(A)
        target = np.ones(N)  # flat target
        target[0] = a.sum()  # keep DC
        
        # Smoothly modify the spectrum
        blend = 0.3
        for k in range(N):

                continue
            if mag[k] > target[k]:
                # Reduce: set to geometric mean
                A[k] = A[k] * np.sqrt(target[k] / mag[k])
            # Don't boost (to maintain non-negativity)
        
        # Back to time domain
        a_new = np.fft.ifft(A).real[:n]
        a_new = np.maximum(a_new, 0)
        sn = a_new.sum()
        if sn < 1e-10:
            a_new = a.copy()
            continue
        a_new = a_new / sn
        
        obj_new = compute_obj(a_new)
        if obj_new < best_obj:
            best_obj = obj_new
            a = a_new
        else:
            # Blend
            a_blend = 0.7 * a + 0.3 * a_new
            a_blend = np.maximum(a_blend, 0)
            a_blend = a_blend / a_blend.sum()
            obj_blend = compute_obj(a_blend)
            if obj_blend < best_obj:
                best_obj = obj_blend
                a = a_blend
    
    return a

This is a reasonable spectral approach. But the connection between `max_k (a*a)_k` and `max_k |A_k|^2` is not exact for linear convolution with zero-padding.

For a sequence of length n, zero-padded to length N >= 2n-1, the linear convolution equals the circular convolution (no aliasing). So `max_k (a*a)_k = max of first (2n-1) entries of IFFT(|FFT(a_padded)|^2)`.

And `IFFT(|FFT(a_padded)|^2)` gives the circular convolution of the zero-padded sequence with itself, which for the first 2n-1 entries equals the linear convolution.

So `max_k (a*a)_k = max_{k=0}^{2n-2} IFFT(|FFT(a_padded)|^2)[k]`.

This is the maximum of the circular autocorrelation (for the first 2n-1 lags). The full circular autocorrelation has N entries, but we only care about the first 2n-1 (the rest are "aliased" parts that don't correspond to linear convolution).

So the spectral approach is: minimize the peak of the circular autocorrelation over the first 2n-1 lags, which is equivalent to minimizing the peak of `|A(omega)|^2` in a certain range... actually it's not exactly the same, because the peak of the time-domain autocorrelation is not the same as the peak of the frequency-domain power.

The peak of the time-domain autocorrelation is `max_k r(k)` where `r(k) = sum_j a_j * a_{j+k}`. This is the `L_infinity` norm of the autocorrelation sequence.

In the frequency domain, `r(k) = IFFT(|A|^2)[k]`. So `max_k r(k) = max_k IFFT(|A|^2)[k]`. This is the peak of the inverse DFT of the power spectrum.

To minimize this peak, we want `|A|^2` to be "spread out" in such a way that its inverse DFT has minimal peak. This is a non-trivial optimization in the frequency domain.

The approach of setting `|A|` to be flat (equal magnitude at all frequencies) would give a delta-like autocorrelation (peak at lag 0 only), but this requires the time-domain signal to be a complex exponential (or Kronecker delta), which can't be non-negative (except for the delta itself, which has infinite peak).

For non-negative sequences, the best we can do is approach a "smooth" spectrum. The optimal spectrum for minimizing peak sidelobes of the autocorrelation is known in the radar literature.

Alternative: **Mirror descent with entropy regularization.**
- Minimize `max_k (a*a)_k + (1/eta) * KL(a || uniform)`
- The KL-regularized problem has a closed-form solution: `a_i = exp(-eta * grad_i) / sum(exp(-eta * grad_j))`
- This is a "softmax" of the negative gradient
- Iterate: compute gradient, update a via softmax, decrease eta

This is equivalent to the **multiplicative weights** algorithm or **exponentiated gradient**. It has the advantage of staying in the interior of the simplex (a_i > 0 always) and being very fast (no LP needed).

The gradient of `max_k (a*a)_k` is: for the active set S, it's `sum_{k in S} lambda_k * grad_k`. If we use the uniform lambda (1/|S| for each active k), we get the average gradient over active lags.

The update: `a_i <- a_i * exp(-eta * g_i) / Z` where Z is the normalization constant.

This is fast: O(n) per step (plus O(n log n) for the gradient computation via FFT).

Actually, for the mirror descent on the simplex with entropy regularization:
- The problem is: min_f max_k (a*a)_k s.t. a in simplex
- The mirror is: D_KL(a || b) = sum a_i log(a_i / b_i)
- The update is: a_new = argmin { <g, a> + (1/eta) D_KL(a || a_old) }
- Solution: a_new_i = a_old_i * exp(-eta * g_i) / Z

Where g is the gradient of the objective with respect to a (in the "Euclidean" sense, i.e., the unconstrained gradient projected appropriately).

For a scale-invariant objective f(a) = f(a/c for any c > 0), the gradient on the simplex is:
g_i = df/da_i - (sum_j a_j * df/da_j) (to ensure sum_i a_i * g_i = 0)

But since f is scale-invariant, sum_j a_j * df/da_j = 0 (Euler's theorem for homogeneous functions of degree 0). So the gradient is just df/da_i.

def compute_conv(a):

    n = len(a)

    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]

        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))

def lp_solve_fast(a, solver_list=None):
    """Solve min M s.t. conv(a,g) <= M, g >= 0, sum(g) = 1. Returns (g, M)."""
    n = len(a)
    num_constraints = 2 * n - 1
    
    # Build constraint matrix: A[k, j] = a[k-j] if 0 <= k-j < n, else 0
    A = np.zeros((num_constraints, n))
    for j in range(n):
        A[j:j+n, j] = a
    
    g_var = cp.Variable(n, nonneg=True)
    M_var = cp.Variable()
    constraints = [A @ g_var <= M_var, cp.sum(g_var) == 1]
    prob = cp.Problem(cp.Minimize(M_var), constraints)
    
    if solver_list is None:
        solver_list = [cp.MOSEK, cp.CLARABEL, cp.PDLP, cp.SCS]
    
    for solver in solver_list:
        try:
            prob.solve(solver=solver, verbose=False)
            if g_var.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g_var.value, 0)
                sg = float(np.sum(g_val))
                if sg > 1e-10:
                    return g_val / sg, float(M_var.value)
        except Exception:
            continue
    return None, None


def exact_line_search(a, g, n_points=20):
    """Find optimal t in [0,1] minimizing f((1-t)*a + t*g).
    Uses coarse grid + golden section refinement."""
    # Coarse grid
    best_t = 0.0
    best_obj = compute_obj(a)
    
    ts = np.linspace(0, 1, n_points)
    objs = []
    for t in ts:
        if t == 0:
            objs.append(best_obj)
        else:
            v = (1 - t) * a + t * g
            v = np.maximum(v, 0)
            sv = float(np.sum(v))
            if sv < 1e-15:
                objs.append(np.inf)
            else:
                objs.append(compute_obj_fast(v))
    objs = np.array(objs)
    
    # Find best on grid
    best_idx = int(np.argmin(objs))
    best_t = ts[best_idx]
    best_obj = objs[best_idx]
    
    # Golden section refinement in the neighborhood
    lo = ts[max(0, best_idx - 1)]
    hi = ts[min(len(ts) - 1, best_idx + 1)]
    
    if hi - lo < 1e-6:
        return best_t, best_obj
    
    gr = (np.sqrt(5) - 1) / 2
    c = lo + (1 - gr) * (hi - lo)
    d = lo + gr * (hi - lo)
    
    def eval_t(t):
        v = (1 - t) * a + t * g
        v = np.maximum(v, 0)
        sv = float(np.sum(v))
        if sv < 1e-15:
            return np.inf
        return compute_obj_fast(v)
    
    fc = eval_t(c)
    fd = eval_t(d)
    
    for _ in range(30):
        if hi - lo < 1e-7:
            break
        if fc < fd:
            hi = d
            d = c
            fd = fc
            c = lo + (1 - gr) * (hi - lo)
            fc = eval_t(c)
        else:
            lo = c
            c = d
            fc = fd
            d = lo + gr * (hi - lo)
            fd = eval_t(d)
    
    t_star = (lo + hi) / 2
    obj_star = eval_t(t_star)
    
    if obj_star < best_obj:
        return t_star, obj_star
    return best_t, best_obj

            obj_try = compute_obj(a_try)
            if obj_try < best_obj - 1e-14:
                best_obj = obj_try
                best_a = a_try.copy()
                a = a_try
                improved = True
                break
        
        if not improved:
            # Try LP step
            if it % 5 == 0:
                g_lp, _ = lp_solve_fast(a)
                if g_lp is not None:
                    for t in [0.05, 0.1, 0.2, 0.3, 0.5]:
                        a_try = (1 - t) * a + t * g_lp
                        a_try = np.maximum(a_try, 0)
                        a_try = a_try / a_try.sum()
                        obj_try = compute_obj(a_try)
                        if obj_try < best_obj - 1e-14:
                            best_obj = obj_try
                            best_a = a_try.copy()
                            a = a_try
                            improved = True
                            break
            
            if not improved:
                # Perturb
                a = a + 0.008 * rng.standard_normal(n)
                a = np.maximum(a, 0)
                a = a / a.sum()
        
        if verbose and it % 20 == 0:
            print(f"    ActiveSet it{it:3d}: obj={best_obj:.10f}, n_active={len(active_lags)}")
    
    return best_a


def resample_seq(a, new_n):
    """Resample sequence to new length via linear interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, a[0])
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    a_new = np.maximum(a_new, 0)
    s = float(np.sum(a_new))
    if s < 1e-10:
        return np.ones(new_n) / new_n
    return a_new / s


def make_structured_init(n, rng, mode=0):
    """Create structured initializations."""
    if mode == 0:
        return np.ones(n) / n
    elif mode == 1:
        x = np.linspace(-1, 1, n)
        a = np.maximum(np.sinc(x), 0.001)
        return a / a.sum()
    elif mode == 2:
        a = 0.54 - 0.46 * np.cos(2 * np.pi * np.arange(n) / (n - 1))
        return a / a.sum()
    elif mode == 3:
        x = np.arange(n) / (n - 1)
        a = 0.42 - 0.5 * np.cos(2 * np.pi * x) + 0.08 * np.cos(4 * np.pi * x)
        return a / a.sum()
    elif mode == 4:
        x = np.linspace(-3, 3, n)
        a = np.exp(-x ** 2)
        return a / a.sum()
    elif mode == 5:
        x = np.linspace(0, 1, n)
        a = 0.5 * (1 + np.cos(2 * np.pi * (x - 0.5)))
        return a / a.sum()
    elif mode == 6:
        # Optimal-ish: raised cosine squared
        x = np.linspace(0, 1, n)
        a = (0.5 * (1 + np.cos(2 * np.pi * (x - 0.5)))) ** 2
        return a / a.sum()
    elif mode == 7:
        # Flat with exponential taper
        taper = 0.15
        a = np.ones(n)
        for i in range(n):
            d = min(i, n - 1 - i)
            if d < taper * n:
                a[i] = np.exp(-((taper * n - d) / (taper * n)) ** 2)
        return a / a.sum()
    elif mode == 8:
        # Multi-lobe
        x = np.arange(n) / n
        a = 1.0 + 0.3 * np.cos(2 * np.pi * 2 * x) + 0.1 * np.cos(2 * np.pi * 4 * x)
        a = np.maximum(a, 0.01)
        return a / a.sum()
    elif mode == 9:
        # Bernoulli factory: optimal for flat convolution (theoretical)
        # Use a sequence that approximates a fractional Brownian motion
        x = np.arange(n) / n
        a = 1.0 + 0.5 * np.cos(2 * np.pi * 3 * x) - 0.3 * np.cos(2 * np.pi * 7 * x)
        a = np.maximum(a, 0.005)
        return a / a.sum()
    else:
        a = rng.uniform(0.1, 1.0, n)
        return a / a.sum()


def propose_candidate(seed=42, budget_s=1500):

    Main search combining FW with exact line search, mirror descent,
    coordinate descent, spectral shaping, and multi-start.
    """

    deadline = start_time + float(budget_s) - 15.0  # Leave 15s buffer
    
    best_seq = None
    best_score = np.inf
    rng = np.random.default_rng(seed)
    
    # --- Load parent ---
    try:
        parent_arr = np.asarray(height_sequence_1, dtype=np.float64)
        parent_arr = np.clip(parent_arr, 0, None)
        if parent_arr.size > 0 and np.isfinite(parent_arr).all():
            s = float(np.sum(parent_arr))
            if s > 0.01:
                parent = parent_arr / s
                best_score = compute_obj(parent)
                best_seq = parent.copy()
                print(f"Parent (n={parent.size}): obj={best_score:.10f}")
    except Exception:
        parent = None
    
    if best_seq is None:
        n0 = 800
        best_seq = np.ones(n0) / n0
        best_score = compute_obj(best_seq)
        print(f"Default init (n={n0}): obj={best_score:.10f}")

            remaining = deadline - time.monotonic()
            if remaining < 15:
                break

                print(f"  Init mode {mode}: obj={obj_screen:.10f}")

    print(f"\n=== Phase 2: FW Exact Line Search ===")
