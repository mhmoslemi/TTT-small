2. Line search along the direction `f -> (1-t)f + t*g`
3. Subgradient polishing

The key insight of the LP is: given current `f`, find `g` that minimizes `max_k (f*g)[k]`. This is like finding the "most compatible" direction.

To improve, I could:
- Use a **second-order** method: not just look at `f*g` but also consider `g*g` (since the final direction matters for the self-convolution of the new point)
- Use **multiple LP directions** and combine them
- Use a **trust region** approach

Let me try a **trust region** method:
1. Current point: `a`
2. Find direction `d` (from LP)
3. Find optimal step `t` by minimizing `max_k ((a + t*d) * (a + t*d))[k]` over `t`
   - This is `max_k (conv_a[k] + 2t*(a*d)[k] + t^2*(d*d)[k])`
   - For each k, this is a quadratic in t: `f_k(t) = (d*d)[k] * t^2 + 2*(a*d)[k] * t + conv_a[k]`
   - We want to minimize `max_k f_k(t)`
   - This is a 1D convex problem (max of convex quadratics is convex)
   - Can be solved by bisection or golden section search!

This is a significant improvement over the previous linear line search! The trust region quadratic line search will find a better step.

Let me implement this:

```python
def trust_region_line_search(a, d, n_evals=50):
    """Find optimal t > 0 minimizing max_k ((a+t*d)*(a+t*d))[k]"""
    n = len(a)
    conv_a = np.convolve(a, a)  # length 2n-1
    conv_ad = np.convolve(a, d)  # length 2n-1
    conv_dd = np.convolve(d, d)  # length 2n-1
    
    # f_k(t) = conv_dd[k]*t^2 + 2*conv_ad[k]*t + conv_a[k]
    # We want min_t max_k f_k(t)
    
    # The feasible t range: t in [0, t_max] where a + t*d >= 0
    # If d[i] < 0, then t_max <= -a[i]/d[i]
    neg_mask = d < 0
    if np.any(neg_mask):
        t_max = np.min(-a[neg_mask] / d[neg_mask]) - 1e-10
    else:
        t_max = 1.0  # cap it
    
    t_max = max(t_max, 0.0)
    
    # Use golden section search on [0, t_max]
    if t_max <= 1e-10:
        return 0.0, compute_obj(a)
    
    inv_phi = (np.sqrt(5) - 1) / 2
    lo, hi = 0.0, t_max
    for _ in range(n_evals):
        t1 = hi - inv_phi * (hi - lo)
        t2 = lo + inv_phi * (hi - lo)
        obj1 = max_obj_quad(t1, conv_dd, conv_ad, conv_a)
        obj2 = max_obj_quad(t2, conv_dd, conv_ad, conv_a)
        if obj1 < obj2:
            hi = t2
        else:
            lo = t1
    t_opt = (lo + hi) / 2
    obj_opt = compute_obj(np.maximum(a + t_opt * d, 0))
    return t_opt, obj_opt

def max_obj_quad(t, conv_dd, conv_ad, conv_a):
    """Compute max_k (conv_dd[k]*t^2 + 2*conv_ad[k]*t + conv_a[k])"""
    vals = conv_dd * t*t + 2 * conv_ad * t + conv_a
    return float(np.max(vals))
```

This is much more efficient than the previous exhaustive line search because:
1. We only need to evaluate the max of a quadratic (O(n) per evaluation)
2. Golden section search converges in ~20-30 evaluations
3. We don't need to recompute the full convolution

Actually, I realize the quadratic formula gives us the exact value of `max_k f_k(t)` for any `t`, so the golden section search is very fast.

Now, for the direction `d`, I'll use the LP approach but also try a **steepest descent** direction.

The steepest descent direction for minimizing `max_k conv[k]` at the current point is:
- `k* = argmax conv[k]`
- `d[i] = -2 * a[k*-i]` (if valid), else 0
- Then project: `d[i] = max(0, d[i] + c)` for appropriate `c` to maintain sum, or use the null space of the sum constraint.

Actually, for the constrained problem (sum a = 1, a >= 0), the steepest descent direction is:
- Compute gradient `g[i] = 2*a[k*-i]` (subgradient of max conv)
- Project onto the constraint set: the direction is `-g + mean(g)` (the projection of -g onto the tangent space of {sum a = 1}), then clip to non-negative.

```python
"""
Trust-region LP optimization with quadratic line search,
Nesterov subgradient polishing, and adaptive n exploration.
"""

import numpy as np
from scipy.fft import rfft, irfft
import time
import cvxpy as cp

def get_fft_size(n):
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    return size

def compute_conv(a):
    n = len(a)
    if n == 0:
        return np.array([])
    size = get_fft_size(n)
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]

def compute_conv_pair(a, b):
    """Compute linear convolution of a and b (same length)."""
    n = len(a)
    size = get_fft_size(n)
    fa = rfft(a, size)
    fb = rfft(b, size)
    return irfft(fa * fb, size)[:2 * n - 1]

def compute_obj(a):
    n = len(a)
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_norm = a / s
    conv = compute_conv(a_norm)
    return 2.0 * n * float(np.max(conv))

def build_conv_matrix(a):
    """Build matrix A such that (A @ g)[k] = sum_i a[i]*g[k-i] (cross-conv)."""
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        r = min(n, 2 * n - 1 - j)
        A[j:j + r, j] = a[:r]
    return A

def solve_lp(a, time_limit=None):
    """Solve: minimize M s.t. conv(a, g) <= M, g >= 0, sum(g) = 1."""
    n = len(a)
    a_norm = a / float(np.sum(a))
    A = build_conv_matrix(a_norm)
    g = cp.Variable(n, nonneg=True)
    M = cp.Variable()
    constraints = [A @ g <= M, cp.sum(g) == 1]
    prob = cp.Problem(cp.Minimize(M), constraints)
    for solver in [cp.CLARABEL, cp.ECOS, cp.SCS]:
        try:
            prob.solve(solver=solver)
            if g.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g.value, 0)
                s = float(np.sum(g_val))
                if s > 1e-10:
                    return g_val / s
        except Exception:
            continue
    return None

def quadratic_line_search(a, d, t_max=1.0):
    """
    Find t in [0, t_max] minimizing max_k ((a+t*d)*(a+t*d))[k].
    Uses golden section search on the exact quadratic expression.
    """
    n = len(a)
    conv_a = compute_conv(a)
    conv_ad = compute_conv_pair(a, d)
    conv_dd = compute_conv(d)
    
    # f_k(t) = conv_dd[k]*t^2 + 2*conv_ad[k]*t + conv_a[k]
    # max_k f_k(t) is convex in t (max of convex quadratics)
    
    # Determine valid t range: a + t*d >= 0
    neg_mask = d < -1e-15
    if np.any(neg_mask):
        t_max = min(t_max, np.min(-a[neg_mask] / d[neg_mask]) * 0.999)
    t_max = max(t_max, 0.0)
    
    if t_max <= 1e-12:
        return 0.0, float(np.max(conv_a))
    
    # Golden section search
    inv_phi = (np.sqrt(5) - 1) / 2
    lo, hi = 0.0, t_max
    for _ in range(60):
        t1 = hi - inv_phi * (hi - lo)
        t2 = lo + inv_phi * (hi - lo)
        vals1 = conv_dd * t1*t1 + 2 * conv_ad * t1 + conv_a
        vals2 = conv_dd * t2*t2 + 2 * conv_ad * t2 + conv_a
        if np.max(vals1) < np.max(vals2):
            hi = t2
        else:
            lo = t1
    t_opt = (lo + hi) / 2
    a_new = np.maximum(a + t_opt * d, 0)
    s = float(np.sum(a_new))
    if s < 1e-10:
        return 0.0, float(np.max(conv_a))
    a_new = a_new / s
    obj = compute_obj(a_new)
    return t_opt, obj

def steepest_descent_step(a, n=50):
    """Nesterov-accelerated subgradient descent for max(conv)."""
    n = len(a)
    a_curr = a.copy()
    a_prev = a.copy()
    best_a = a.copy()
    best_obj = compute_obj(a)
    
    for it in range(n):
        y = a_curr + (it / (it + 2)) * (a_curr - a_prev)
        conv = compute_conv(y)
        k_star = int(np.argmax(conv))
        # Subgradient of max conv at k_star
        grad = np.zeros(n)
        for i in range(n):
            j = k_star - i
            if 0 <= j < n:
                grad[i] = 2 * y[j]
        # Project gradient onto {sum = 0} (tangent to simplex)
        grad = grad - np.mean(grad)
        # Step
        lr = 1.0 / (np.sqrt(it + 1) * np.linalg.norm(grad) + 1e-10)
        a_new = np.maximum(y - lr * grad, 0)
        s = float(np.sum(a_new))
        if s < 1e-10:
            a_new = a_curr.copy()
        else:
            a_new = a_new / s
        a_prev = a_curr
        a_curr = a_new
        obj = compute_obj(a_curr)
        if obj < best_obj:
            best_obj = obj
            best_a = a_curr.copy()
    return best_a

def u_shaped_init(n, sharpness=3.0):
    x = np.linspace(0, 1, n)
    a = 1.0 / (0.05 + sharpness * (2 * x - 1) ** 2)
    a = np.maximum(a, 0)
    s = float(np.sum(a))
    if s < 1e-10:
        return np.ones(n) / n
    return a / s

def diverse_init(n, rng, mode=0):
    x = np.linspace(0, 1, n)
    idx = np.arange(n)
    if mode == 0:
        a = (2 * x - 1) ** 4 + 0.05
    elif mode == 1:
        a = np.exp(-((idx - n // 4) ** 2) / (2 * (n // 6) ** 2)) + \
            np.exp(-((idx - 3 * n // 4) ** 2) / (2 * (n // 6) ** 2)) + 0.01
    elif mode == 2:
        a = 4 * np.abs(x - 0.5) + 0.05
    elif mode == 3:
        a = rng.uniform(0.1, 1.0, n)
        kernel = np.ones(5) / 5
        a = np.convolve(a, kernel, mode='same')
    elif mode == 4:
        a = np.exp(5 * (2 * x - 1) ** 2)
    elif mode == 5:
        a = 1.0 / (0.02 + 5.0 * (2 * x - 1) ** 4)
    else:
        a = 1.0 / (0.1 + 2.0 * np.abs(2 * x - 1))
    a = np.maximum(a, 0)
    s = float(np.sum(a))
    if s < 1e-10:
        return np.ones(n) / n
    return a / s

def interpolate_sequence(a_src, n_dst):
    n_src = len(a_src)
    x_src = np.linspace(0, 1, n_src)
    x_dst = np.linspace(0, 1, n_dst)
    a_dst = np.interp(x_dst, x_src, a_src)
    a_dst = np.maximum(a_dst, 0)
    s = float(np.sum(a_dst))
    if s < 0.01:
        return None
    return a_dst / s

def lp_iterate(a, time_budget, max_iters):
    """Main optimization loop: LP direction + quadratic line search."""
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64)
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s
    best_a = a.copy()
    best_obj = compute_obj(a)
    start = time.monotonic()
    it = 0
    stall = 0
    rng = np.random.default_rng(12345 + it)
    
    while time.monotonic() - start < time_budget and it < max_iters:
        remaining = time_budget - (time.monotonic() - start)
        if remaining < 5:
            break
        
        T0 = time.monotonic()
        g_lp = solve_lp(a)
        T1 = time.monotonic()
        lp_time = T1 - T0
        
        if g_lp is None:
            # Fallback: steepest descent
            a_new = steepest_descent_step(a, n=30)
            obj_new = compute_obj(a_new)
            if obj_new < best_obj:
                best_obj = obj_new
                best_a = a_new.copy()
                a = a_new
            it += 1
            continue
        
        # Quadratic line search
        d = g_lp - a  # direction from a to g
        t_opt, obj_opt = quadratic_line_search(a, d, t_max=1.0)
        
        if t_opt > 1e-8 and obj_opt < best_obj - 1e-12:
            a_new = np.maximum(a + t_opt * d, 0)
            s_new = float(np.sum(a_new))
            if s_new > 0.01:
                a_new = a_new / s_new
                obj_new = compute_obj(a_new)
                best_obj = obj_new
                best_a = a_new.copy()
                a = a_new
                stall = 0
            else:
                stall += 1
        else:
            stall += 1
            # Try full step to g
            obj_g = compute_obj(g_lp)
            if obj_g < best_obj:
                best_obj = obj_g
                best_a = g_lp.copy()
                a = g_lp.copy()
                stall = 0
        
        it += 1
        if it % 10 == 0:
            elapsed = time.monotonic() - start
            print(f"    LP it{it}: obj={best_obj:.10f}, t={t_opt:.4f}, "
                  f"lp_time={lp_time:.2f}s, elapsed={elapsed:.1f}s")
        
        if stall >= 3:
            if stall <= 5:
                # Small perturbation
                freq = rng.integers(1, max(2, n // 100))
                phase = rng.uniform(0, 2 * np.pi)
                idx = np.arange(n, dtype=np.float64)
                pert = 0.02 * stall * np.cos(2 * np.pi * freq * idx / n + phase)
                a_pert = best_a * np.exp(pert)
                a_pert = np.maximum(a_pert, 0)
                s_p = float(np.sum(a_pert))
                if s_p > 0.01:
                    a = a_pert / s_p
                else:
                    a = best_a.copy()
            else:
                # Larger restart
                mode = it % 6
                a_div = diverse_init(n, rng, mode=mode)
                a = 0.3 * a_div + 0.7 * best_a
                a = np.maximum(a, 0)
                a = a / a.sum()
            stall = 0
    
    return best_a
