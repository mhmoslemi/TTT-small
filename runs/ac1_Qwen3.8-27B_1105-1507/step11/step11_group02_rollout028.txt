Actually, let me reconsider the problem from scratch. The objective is:

f(a) = 2*n*max_k C[k] / (sum a)^2

where C[k] = sum_j a[j]*a[k-j].

Since f is scale-invariant, we can fix sum(a) = 1 and minimize 2*n*max C[k].

The gradient of max C[k] (at a smooth point where a unique k* achieves the max) is:
grad = 2 * (C gradient at k*) = 2 * vec(a shifted by k*)

Specifically, grad[i] = 2*a[k*-i] if 0 <= k*-i < n, else 0.

This is just 2*a reversed and shifted! So the gradient is very simple.

The issue is that max is not differentiable at points where multiple k achieve the maximum. The smoothed version (log-sum-exp) handles this by taking a weighted average of the active gradients.

Near the optimum, if there are m active positions, the gradient is:
grad[i] = 2 * sum_{k in active} w_k * a[k-i]

where w_k are the subgradient weights (sum to 1, supported on active set).

At the true optimum, there exist weights w_k such that grad[i] is constant (equal to the Lagrange multiplier) for all i with a[i] > 0.

So the "residual" grad[i] - mean(grad on support) should be zero at the optimum. We can use this as a convergence criterion.

**New idea: "Subgradient balancing"**

At each iteration:
1. Compute C = conv(a,a)
2. Identify active set A = {k : C[k] > M - epsilon} (near-max positions)
3. Find weights w_k (k in A) such that sum_k w_k * a[k-i] is as constant as possible for i in support(a)
   - This is a least-squares problem: minimize ||(W * a)[support] - mean||^2
   - Where W[i,k] = a[k-i] for k in A
4. Compute the residual: r[i] = sum_k w_k * a[k-i] - mean
5. Update: a[i] <- a[i] * (1 - lr * r[i]) for i in support
   (or a[i] <- a[i] - lr * r[i] with projection)

This is a "balancing" approach: we're trying to find a combination of peak gradients that's as "flat" as possible, and then moving in the direction that reduces the imbalance.

The least-squares step (3) can be solved efficiently:
- Let B be the matrix with B[i,k] = a[k-i] for i=0..n-1, k in A (|A| columns)
- We want to find w (|A| x 1) minimizing ||B*w - 1||^2 (where 1 is the all-ones vector on support)
- This is a simple linear least squares: w = (B^T B)^{-1} B^T 1
- Since |A| is small (say 20-100), this is very fast!

Then the update direction is d = B * w (the "balanced" gradient), and we move:
a <- a - lr * (d - mean(d on support))

Wait, I need to be more careful. The KKT condition says that at optimum, there exist w_k >= 0 such that:
sum_{k in A} w_k * dC[k]/da[i] = mu for all i with a[i] > 0
and sum_k w_k = 1 (normalization of subgradient).

dC[k]/da[i] = 2*a[k-i] (if valid).

So: 2 * sum_{k in A} w_k * a[k-i] = mu for all i in support.

This means sum_{k in A} w_k * a[k-i] = mu/2 (constant) for all i in support.

So we want to find w such that (B*w)[support] is as constant as possible. The best constant is the mean of (B*w)[support].

Let 1_s be the indicator of support. We want:
minimize_w ||1_s^T B w - |support| * c||^2 + penalty for w not being on the simplex

Actually, simpler: minimize ||(B w - c * 1_s)||^2 over w >= 0, sum w = 1, c.
This is equivalent to: minimize ||B w||^2 - 2c * 1_s^T B w + ... 
For fixed w, optimal c = 1_s^T (Bw) / |support|.
So: minimize_w |support| * mean((Bw)_s)^2 ... no wait.

Let me just do: minimize ||B w - mean(Bw)_s * 1_s||^2 subject to w >= 0, sum w = 1.
This is a QP. Since |A| is small, we can solve it with cvxpy or even a simple projection method.

```python
def active_set_balance(a, K=30):
    """Find balanced subgradient using active set."""
    n = len(a)
    C = compute_conv(a)
    M = float(np.max(C))
    
    # Find active set: positions where C is within epsilon of max
    # Use top K positions
    top_idx = np.argsort(C)[-K:]
    top_idx = np.sort(top_idx)
    
    # Build matrix B[i, m] = a[top_idx[m] - i] if 0 <= top_idx[m]-i < n
    support = np.where(a > 1e-10)[0]
    if len(support) == 0:
        return None, None
    
    B = np.zeros((len(support), K))
    for m, k in enumerate(top_idx):
        for s_idx, i in enumerate(support):
            if 0 <= k - i < n:
                B[s_idx, m] = a[k - i]
    
    # Solve: min ||B w - c*1||^2 s.t. w >= 0, sum w = 1
    # For simplicity, solve the unconstrained LS first:
    # min_w ||B w||^2 - 2 * (B^T 1)^T w + const
    # => B^T B w = B^T 1
    # But we want B w to be as constant as possible, not as close to 1 as possible.
    # Actually, min ||B w - c*1||^2 over c gives:
    # min_w 1_s^T B w B^T 1_s - (1_s^T B w)^2 / |s|
    # = ||B^T 1_s||^2 ... this is getting complicated.
    
    # Simpler approach: minimize ||B w - mean(Bw)||^2 = ||(I - (1/|s|) 1 1^T) B w||^2
    # Let P = I - (1/|s|) 1 1^T (projection onto sum-zero subspace)
    # Then min_w ||P B w||^2 s.t. w >= 0, sum w = 1
    # = min_w w^T B^T P B w s.t. w >= 0, sum w = 1
    # This is a QP!
    
    P = np.eye(len(support)) - np.ones((len(support), len(support))) / len(support)
    H = B.T @ P @ B  # K x K
    
    # Solve: min w^T H w s.t. w >= 0, sum w = 1
    # Use cvxpy for this small QP
    w_var = cp.Variable(K)
    constraints = [w_var >= 0, cp.sum(w_var) == 1]
    obj = cp.quad_form(w_var, cp.psd_wrap(H))
    prob = cp.Problem(cp.Minimize(obj), constraints)
    prob.solve()
    
    if w_var.value is None:
        return None, None
    
    w = np.maximum(w_var.value, 0)
    w = w / float(np.sum(w))
    
    # Compute the balanced gradient
    grad = B @ w  # This is (Bw)[support]
    # The actual gradient in full space:
    full_grad = np.zeros(n)
    full_grad[support] = 2.0 * grad
    
    return full_grad, w
```

One more thought on the "deflation" method. Let me formalize it:

Given current a (sum=1), compute C = conv(a,a). Let k_1, ..., k_m be the positions where C is at or near the maximum.

Define the "load" on coordinate i as:
L[i] = sum_{m=1}^{m} w_m * a[k_m - i] (if 0 <= k_m - i < n)

where w_m are weights (e.g., w_m = (C[k_m] - M + epsilon) / sum(C[k_l] - M + epsilon) for C[k_l] > M - epsilon).

The deflation step is:
a[i] <- a[i] * (1 - lr * L[i])
a = max(a, 0); a = a / sum(a)

This is equivalent to a multiplicative gradient step where the "gradient" is L (which is a weighted average of the peak gradients).

The key advantage over the standard gradient method is that the multiplicative update naturally maintains non-negativity and the step size can be larger (since we're scaling, not shifting).

```python
"""
Optimizes step function coefficients using a multi-phase strategy combining:
1. Adaptive smoothed gradient descent with backtracking line search
2. Active-set QP subgradient balancing (targets KKT conditions directly)
3. Multi-peak multiplicative deflation
4. Exact coordinate descent with active-set prioritization
5. LP polishing with warm starts
6. Multi-length exploration and diverse restarts
Key innovation: QP-based active set balancing that solves for optimal
subgradient weights to produce the flattest possible descent direction.
"""

import numpy as np
from scipy.fft import rfft, irfft, fft, ifft
import cvxpy as cp
import time


def compute_conv(a):
    """Full linear convolution a*a via FFT. Returns array of length 2n-1."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    fa = rfft(a, size)
    return irfft(fa * fa, size)[:2 * n - 1]


def compute_obj_norm(a):
    """Compute objective assuming sum(a)=1: 2*n*max(conv(a,a))."""
    n = len(a)
    if n == 0:
        return np.inf
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    a_n = a / s
    conv = compute_conv(a_n)
    return 2.0 * n * float(np.max(conv))


def compute_obj(a):
    """Compute the full objective: 2*n*max(conv)/sum^2."""
    n = len(a)
    s = float(np.sum(a))
    if s < 0.01:
        return np.inf
    return 2.0 * n * float(np.max(compute_conv(a))) / (s * s)


def softmax_grad(a, beta):
    """
    Compute gradient of smoothed max of conv(a,a) using softmax.
    Returns (gradient, conv, softmax weights, max_conv).
    """
    n = len(a)
    conv = compute_conv(a)
    max_c = float(np.max(conv))
    exp_vals = np.exp(beta * (conv - max_c))
    sum_exp = float(np.sum(exp_vals))
    if sum_exp < 1e-300:
        p = np.zeros(len(conv))
        p[np.argmax(conv)] = 1.0
    else:
        p = exp_vals / sum_exp

    N = 1
    while N < 3 * n:
        N <<= 1
    P = fft(p, N)
    A = fft(a, N)
    cross = ifft(P * np.conj(A), N).real[:n]
    grad = 2.0 * cross
    return grad, conv, p, max_c


def topk_grad(a, K):
    """
    Compute gradient using top-K uniform weights (sharper than softmax).
    Returns (gradient, conv, max_conv).
    """
    n = len(a)
    conv = compute_conv(a)
    max_c = float(np.max(conv))
    top_idx = np.argsort(conv)[-K:]
    p = np.zeros(len(conv))
    p[top_idx] = 1.0 / K

    N = 1
    while N < 3 * n:
        N <<= 1
    P = fft(p, N)
    A = fft(a, N)
    cross = ifft(P * np.conj(A), N).real[:n]
    grad = 2.0 * cross
    return grad, conv, max_c


def active_set_qp_balance(a, K, time_budget=5.0):
    """
    Solve QP to find optimal subgradient weights w that make
    the combined gradient as flat as possible on the support of a.
    Returns (direction, w, active_indices) or (None, None, None).
    """
    n = len(a)
    conv = compute_conv(a)
    max_c = float(np.max(conv))

    top_idx = np.argsort(conv)[-K:]
    top_idx = np.sort(top_idx).astype(int)

    support = np.where(a > 1e-12)[0]
    ns = len(support)
    if ns == 0 or ns > 5000:
        support = np.where(a > 1e-8)[0]
        ns = len(support)
        if ns == 0:
            return None, None, None

    B = np.zeros((ns, K))
    for m in range(K):
        k = top_idx[m]
        diffs = k - support
        valid = (diffs >= 0) & (diffs < n)
        B[valid, m] = a[diffs[valid]]

    P_mat = np.eye(ns) - np.ones((ns, ns)) / ns
    H = B.T @ (P_mat @ B)
    H = (H + H.T) / 2.0
    H += 1e-10 * np.eye(K)

    try:
        w_var = cp.Variable(K)
        constraints = [w_var >= 0, cp.sum(w_var) == 1]
        obj = cp.quad_form(w_var, cp.psd_wrap(H))
        prob = cp.Problem(cp.Minimize(obj), constraints)
        prob.solve(solver=cp.CLARABEL)
        if prob.status not in ('optimal', 'optimal_inaccurate'):
            prob.solve(solver=cp.SCS)
        if w_var.value is None:
            return None, None, None
        w = np.maximum(w_var.value, 0)
        ws = float(np.sum(w))
        if ws < 1e-15:
            return None, None, None
        w = w / ws
    except Exception:
        w = np.ones(K) / K

    balanced = B @ w
    full_grad = np.zeros(n)
    full_grad[support] = 2.0 * balanced
    mean_bal = float(np.mean(balanced))
    direction = full_grad.copy()
    direction[support] -= 2.0 * mean_bal
    return direction, w, top_idx


def balanced_gradient_step(a, K, lr, time_budget=5.0):

    One step of active-set balanced gradient descent.
    Returns (new_a, new_obj, improved).
    """
    n = len(a)
    direction, w, active = active_set_qp_balance(a, K, time_budget)
    if direction is None:
        return a, compute_obj_norm(a), False

    a_try = a - lr * direction
    a_try = np.maximum(a_try, 0)
    s = float(np.sum(a_try))
    if s < 1e-10:
        return a, compute_obj_norm(a), False
    a_try = a_try / s
    obj_try = compute_obj_norm(a_try)
    obj_cur = compute_obj_norm(a)
    if obj_try < obj_cur:
        return a_try, obj_try, True
    return a, obj_cur, False


def multiplicative_deflation(a, K, lr, n_iters=10):
    """
    Multi-peak multiplicative deflation: scale down coordinates
    proportional to their load from active peaks.
    """
    n = len(a)
    conv = compute_conv(a)
    max_c = float(np.max(conv))
    top_idx = np.argsort(conv)[-K:]

    for it in range(n_iters):
        load = np.zeros(n)
        for k in top_idx:
            diffs = k - np.arange(n)
            valid = (diffs >= 0) & (diffs < n)
            load[valid] += a[diffs[valid]]
        load /= K

        a = a * (1.0 - lr * load)
        a = np.maximum(a, 0)
        s = float(np.sum(a))
        if s < 1e-10:
            break
        a = a / s

    return a


def smoothed_gradient_descent(a, time_budget=300.0, beta_start=5.0, beta_end=300.0,
                               lr_start=0.5, lr_end=0.05, seed=42, verbose=False):
    """
    Adaptive smoothed gradient descent with multiplicative updates.
    Beta increases over time for sharper gradient.
    """
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64).copy()
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s

    best_a = a.copy()
    best_obj = compute_obj_norm(a)
    start = time.monotonic()
    rng = np.random.default_rng(seed)
    it = 0
    stall_count = 0
    max_stall = 200

    while time.monotonic() - start < time_budget:
        elapsed = time.monotonic() - start
        progress = min(1.0, elapsed / max(time_budget, 1e-10))
        beta = beta_start + (beta_end - beta_start) * (progress ** 0.7)
        lr = lr_start + (lr_end - lr_start) * progress

        if it % 100 == 0 and beta > 50:
            grad, conv, p, max_c = topk_grad(a, min(20, int(5 + 50 * progress)))
        else:
            grad, conv, p, max_c = softmax_grad(a, beta)

        g_norm = float(np.linalg.norm(grad))
        if g_norm < 1e-14:
            break

        grad = grad / g_norm

        # Backtracking line search with multiplicative update
        best_f = best_obj
        best_try = best_a.copy()
        for trial_lr in [lr, lr * 0.5, lr * 0.25, lr * 0.1, lr * 0.05]:
            # Multiplicative update
            update = np.exp(-trial_lr * grad)
            a_try = a * update
            a_try = np.maximum(a_try, 1e-15)
            s_try = float(np.sum(a_try))
            if s_try < 1e-10:
                continue
            a_try = a_try / s_try
            obj_try = compute_obj_norm(a_try)
            if obj_try < best_f:
                best_f = obj_try
                best_try = a_try.copy()

        if best_f < best_obj - 1e-12:
            a = best_try
            best_obj = best_f
            best_a = a.copy()
            stall_count = 0
        else:
            stall_count += 1
            if stall_count > max_stall:
                # Perturb to escape
                pert = rng.normal(0, 0.02 * (1.0 - progress), n)
                a = a * np.exp(pert)
                a = np.maximum(a, 0)
                a = a / float(a.sum())
                stall_count = 0

        it += 1
        if verbose and it % 5000 == 0:
            print(f"    SGD it{it}: obj={best_obj:.8f}, beta={beta:.1f}, lr={lr:.4f}")

    return best_a

    it = 0
    stall = 0

    while time.monotonic() - start < time_budget:
        elapsed = time.monotonic() - start
        progress = min(1.0, elapsed / max(time_budget, 1e-10))
        K = int(K_start + (K_end - K_start) * progress)
        K = max(K, 5)

        lr = 0.3 * (1.0 - 0.7 * progress) / np.sqrt(n)

        new_a, new_obj, improved = balanced_gradient_step(a, K, lr,
                                                           time_budget=min(3.0, (time_budget - elapsed) * 0.1))
        if improved:
            a = new_a
            if new_obj < best_obj:
                best_obj = new_obj
                best_a = a.copy()
            stall = 0
        else:
            # Try smaller step
            new_a2, new_obj2, improved2 = balanced_gradient_step(a, K, lr * 0.3,
                                                                  time_budget=min(2.0, (time_budget - elapsed) * 0.05))
            if improved2:
                a = new_a2
                if new_obj2 < best_obj:
                    best_obj = new_obj2
                    best_a = a.copy()
                stall = 0
            else:
                stall += 1
                if stall > 30:
                    pert = rng.normal(0, 0.01, n)
                    a = a * np.exp(pert)
                    a = np.maximum(a, 0)
                    a = a / float(a.sum())
                    stall = 0

        # Periodic deflation
        if it % 20 == 0:
            a_def = multiplicative_deflation(a, K,.lr=0.1 / np.sqrt(n), n_iters=3)
            obj_def = compute_obj_norm(a_def)
            if obj_def < best_obj:
                best_obj = obj_def
                best_a = a_def.copy()
                a = a_def

        it += 1
        if verbose and it % 50 == 0:
            print(f"    ASQ it{it}: obj={best_obj:.8f}, K={K}")

    return best_a


def coordinate_descent(a, time_budget=300.0, verbose=False, seed=42, priority_mode=True):
    """
    Exact coordinate descent with optional active-set priority ordering.
    """
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64).copy()
    S = float(np.sum(a))
    if S < 1e-10:
        return a
    a = a / S

    conv = compute_conv(a)
    best_obj = 2.0 * n * float(np.max(conv))
    best_a = a.copy()
    start = time.monotonic()
    rng = np.random.default_rng(seed)
    sweep = 0
    gr = (np.sqrt(5.0) - 1.0) / 2.0

    while time.monotonic() - start < time_budget:
        sweep += 1

        if sweep % 4 == 1:
            S_check = float(np.sum(a))
            if S_check > 1e-10:
                obj = 2.0 * n * float(np.max(conv)) / (S_check * S_check)
                if obj < best_obj:
                    best_obj = obj
                    best_a = a.copy()

        # Priority ordering: start with high-value coordinates
        if priority_mode and sweep % 3 == 1:
            order = np.argsort(-a)
        else:
            order = rng.permutation(n)

        S = float(np.sum(a))

        for i in order:
            if time.monotonic() - start >= time_budget:
                break

            v = a[i]
            S_other = S - v
            if S_other < 1e-12 and v < 1e-12:
                continue

            k_min = max(0, i)
            k_max = min(2 * n - 2, i + n - 1)
            ks = np.arange(k_min, k_max + 1)
            a_ki = a[ks - i]
            c_k = conv[ks].copy()

            mask = (ks != 2 * i)
            ks_lin = ks[mask]
            a_ki_lin = a_ki[mask]
            c_k_lin = c_k[mask]

            k_quad = 2 * i
            c_2i = float(conv[k_quad]) if 0 <= k_quad <= 2 * n - 2 else 0.0

            best_x = v
            best_f = _cd_eval(v, v, S_other, n, c_k_lin, a_ki_lin, c_2i)

            # Candidate points
            scale = max(v, 1.0 / n, 1e-6)
            candidates = [0.0, v * 0.5, v * 0.8, v * 1.2, v * 1.5, v * 2.0, 1.0 / n, 2.0 / n]
            for x in sorted(set(max(0.0, float(c)) for c in candidates)):
                fx = _cd_eval(x, v, S_other, n, c_k_lin, a_ki_lin, c_2i)
                if fx < best_f:
                    best_f = fx
                    best_x = x

            # Golden section
            x_lo = max(0.0, best_x - scale)
            x_hi = best_x + scale * 3.0
            if x_hi - x_lo < 1e-12:
                x_hi = x_lo + 1e-8

            c_pt = x_hi - gr * (x_hi - x_lo)
            d_pt = x_lo + gr * (x_hi - x_lo)
            fc = _cd_eval(c_pt, v, S_other, n, c_k_lin, a_ki_lin, c_2i)
            fd = _cd_eval(d_pt, v, S_other, n, c_k_lin, a_ki_lin, c_2i)

            for _ in range(50):
                if x_hi - x_lo < 1e-14 * max(1.0, x_hi):
                    break
                if fc < fd:
                    x_hi = d_pt
                    d_pt = c_pt
                    fd = fc
                    c_pt = x_hi - gr * (x_hi - x_lo)
                    fc = _cd_eval(c_pt, v, S_other, n, c_k_lin, a_ki_lin, c_2i)
                else:
                    x_lo = c_pt
                    c_pt = d_pt
                    fc = fd
                    d_pt = x_lo + gr * (x_hi - x_lo)
                    fd = _cd_eval(d_pt, v, S_other, n, c_k_lin, a_ki_lin, c_2i)

            x_opt = max(0.0, (x_lo + x_hi) / 2.0)
            if abs(x_opt - v) < 1e-14:
                continue

            delta = x_opt - v
            a[i] = x_opt
            if 0 <= k_quad <= 2 * n - 2:
                conv[k_quad] += x_opt * x_opt - v * v
            if len(ks_lin) > 0:
                conv[ks_lin] += 2.0 * delta * a_ki_lin
            S += delta

            if S > 1e-10:
                obj = 2.0 * n * float(np.max(conv)) / (S * S)
                if obj < best_obj:
                    best_obj = obj
                    best_a = a.copy()

        if verbose and sweep % 5 == 0:
            elapsed = time.monotonic() - start
            print(f"    CD sweep {sweep}: obj={best_obj:.8f}, t={elapsed:.1f}s")

    return best_a


def _cd_eval(x, v, S_other, n, c_k_lin, a_ki_lin, c_2i):
    """Evaluate 1D objective for coordinate descent."""
    if len(a_ki_lin) > 0:
        lin_vals = c_k_lin + 2.0 * a_ki_lin * (x - v)
        max_lin = float(np.max(lin_vals))
    else:
        max_lin = 0.0
    quad_val = c_2i + x * x - v * v
    max_val = max(max_lin, quad_val)
    denom = (S_other + x) * (S_other + x)
    if denom < 1e-30:
        return 1e30
    return 2.0 * n * max_val / denom


def lp_minpeak_polish(a, time_budget=30.0, K=None):
    """
    LP: min M s.t. conv(a_norm, g)[k] <= M for k in active set,
    sum(g)=1, g>=0. Then blend.
    """
    n = len(a)
    a_norm = a / float(np.sum(a))
    conv = compute_conv(a_norm)
    max_c = float(np.max(conv))

    if K is None:
        K = min(50, n)

    top_idx = np.argsort(conv)[-K:]
    top_idx = np.sort(top_idx)

    # Build constraint matrix: A[g] = conv(a_norm, g) at top_idx
    # conv(a_norm, g)[k] = sum_j a_norm[j] * g[k-j]
    # For fixed k: sum_j a_norm[j] * g[k-j] where 0<=k-j<n
    # = sum_i a_norm[k-i] * g[i] (where i = k-j, 0<=i<n, 0<=k-i<n)

    A_rows = []
    for k in top_idx:
        row = np.zeros(n)
        for i in range(n):
            j = k - i
            if 0 <= j < n:
                row[i] = a_norm[j]
        A_rows.append(row)
    A_mat = np.array(A_rows)

    g_var = cp.Variable(n, nonneg=True)
    M_var = cp.Variable()
    constraints = [A_mat @ g_var <= M_var, cp.sum(g_var) == 1]
    prob = cp.Problem(cp.Minimize(M_var), constraints)

    solvers = [cp.CLARABEL, cp.SCS, cp.MOSEK]
    for solver in solvers:
        try:
            prob.solve(solver=solver)
            if g_var.value is not None and prob.status in ('optimal', 'optimal_inaccurate'):
                g_val = np.maximum(g_var.value, 0)
                s_g = float(np.sum(g_val))
                if s_g > 1e-10:
                    g_val = g_val / s_g
                    return g_val, float(M_var.value)
        except Exception:
            continue
    return None, None


def lp_polish_phase(a, time_budget=100.0, seed=42, verbose=False):
    """Multiple rounds of LP polishing with blending."""
    n = len(a)
    a = np.maximum(a, 0).astype(np.float64).copy()
    s = float(np.sum(a))
    if s < 1e-10:
        return a
    a = a / s

    best_a = a.copy()
    best_obj = compute_obj_norm(a)
    start = time.monotonic()
    rng = np.random.default_rng(seed)

    while time.monotonic() - start < time_budget:
        remaining = time_budget - (time.monotonic() - start)
        if remaining < 5:
            break

        K = min(40, max(15, int(15 + 30 * (1 - remaining / time_budget))))
        g_lp, M_lp = lp_minpeak_polish(a, time_budget=min(remaining * 0.4, 15.0), K=K)
        if g_lp is None:
            break

        best_t_obj = best_obj
        best_a_local = best_a.copy()
        for t in [0.05, 0.1, 0.2, 0.3, 0.5, 0.7, 1.0]:
            a_try = (1.0 - t) * a + t * g_lp
            a_try = np.maximum(a_try, 0)
            s_try = float(np.sum(a_try))
            if s_try < 1e-10:
                continue
            a_try = a_try / s_try
            obj_try = compute_obj_norm(a_try)
            if obj_try < best_t_obj:
                best_t_obj = obj_try
                best_a_local = a_try.copy()

        if best_t_obj < best_obj - 1e-13:
            best_obj = best_t_obj
            best_a = best_a_local.copy()
            a = best_a
            if verbose:
                print(f"    LP: obj={best_obj:.8f} **")
        else:
            # Perturb and try again
            pert = rng.normal(0, 0.01, n)
            a = a * np.exp(pert)
            a = np.maximum(a, 0)
            a = a / float(a.sum())

    return best_a


def diverse_init(n, rng, mode=0):
    """Generate diverse initializations."""
    if mode == 0:
        a = np.ones(n) / n
    elif mode == 1:
        a = rng.uniform(0, 1, n)
        a = a / a.sum()
    elif mode == 2:
        centers = [n // 4, 3 * n // 4]
        widths = [n // 6, n // 6]
        a = np.zeros(n)
        for c, w in zip(centers, widths):
            a += np.exp(-((np.arange(n) - c) ** 2) / (2 * w ** 2))
        a = a / a.sum()
    elif mode == 3:
        x = np.linspace(-1, 1, n)
        a = 1.0 / np.sqrt(1 - x ** 2 + 1e-6)
        a = a / a.sum()
    elif mode == 4:
        freqs = rng.integers(1, 8, size=3)
        phases = rng.uniform(0, 2 * np.pi, size=3)
        x = np.linspace(0, 1, n)
        a = np.ones(n)
        for f, p in zip(freqs, phases):
            a += 0.2 * np.sin(2 * np.pi * f * x + p)
        a = np.maximum(a, 0.01)
        a = a / a.sum()
    elif mode == 5:
        x = np.linspace(0.01, 1, n)
        a = x ** rng.uniform(-3, 3)
        a = a / a.sum()
    elif mode == 6:
        a = 1.0 - np.abs(2 * np.linspace(0, 1, n) - 1)
        a += 0.15 * rng.uniform(0, 1, n)
        a = a / a.sum()
    else:
        a = np.ones(n) / n
    return a


def resample_sequence(a, new_n):
    """Resample sequence to new length via interpolation."""
    n = len(a)
    if n == new_n:
        return a.copy()
    if n == 1:
        return np.full(new_n, a[0])
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    return np.maximum(a_new, 0)


def propose_candidate(seed=42, budget_s=1500):
    """
    Main search: multi-phase optimization combining smoothed gradient descent,
    active-set QP balancing, multiplicative deflation, coordinate descent,
    and LP polishing.
    """
    start_time = time.monotonic()
    deadline = start_time + float(budget_s) - 15.0

    best_seq = None
    best_score = np.inf
    rng = np.random.default_rng(seed)

    # Load parent sequence
    try:
        parent_arr = np.asarray(height_sequence_1, dtype=np.float64)
        parent_arr = np.clip(parent_arr, 0, None)
        if parent_arr.size > 0 and np.isfinite(parent_arr).all():
            s_p = float(np.sum(parent_arr))
            if s_p > 0.01:
                parent = parent_arr / s_p
                best_score = compute_obj_norm(parent)
                best_seq = parent.copy()
                print(f"Parent (n={parent.size}): obj={best_score:.8f}")
    except Exception:
        n_default = 800
        best_seq = np.ones(n_default) / n_default
        best_score = compute_obj_norm(best_seq)
        print(f"Default init (n={n_default}): obj={best_score:.8f}")

    n = len(best_seq)

    # === Phase 1: Smoothed Gradient Descent (35% time) ===
    print(f"\n=== Phase 1: Smoothed Gradient Descent (n={n}) ===")
    remaining = deadline - time.monotonic()
    p1_budget = min(remaining * 0.35, 450.0)
    if p1_budget > 30:
        a_sgd = smoothed_gradient_descent(best_seq, time_budget=p1_budget,
                                          beta_start=5.0, beta_end=200.0,
                                          lr_start=0.8, lr_end=0.05,
                                          seed=seed, verbose=True)
        obj_sgd = compute_obj_norm(a_sgd)
        if obj_sgd < best_score:
            best_score = obj_sgd
            best_seq = a_sgd.copy()
            print(f"  SGD: obj={best_score:.8f} **")
        else:
            print(f"  SGD: obj={obj_sgd:.8f} (no improvement)")

    # === Phase 2: Active Set QP Balancing (25% time) ===
    print(f"\n=== Phase 2: Active Set QP (n={n}) ===")
    remaining = deadline - time.monotonic()
    p2_budget = min(remaining * 0.25, 300.0)
    if p2_budget > 20:
        a_asq = active_set_optimization(best_seq, time_budget=p2_budget,
                                        K_start=10, K_end=60,
                                        seed=seed + 100, verbose=True)
        obj_asq = compute_obj_norm(a_asq)
        if obj_asq < best_score:
            best_score = obj_asq
            best_seq = a_asq.copy()
            print(f"  ASQ: obj={best_score:.8f} **")
        else:
            print(f"  ASQ: obj={obj_asq:.8f}")

    # === Phase 3: Multiplicative Deflation + Gradient Combo (15% time) ===
    print(f"\n=== Phase 3: Deflation + Gradient ===")
    remaining = deadline - time.monotonic()
    p3_budget = min(remaining * 0.15, 180.0)
    if p3_budget > 15:
        a_def = best_seq.copy()
        obj_def = best_score
        start_def = time.monotonic()
        it = 0
        while time.monotonic() - start_def < p3_budget:
            progress = (time.monotonic() - start_def) / p3_budget
            K = int(10 + 40 * progress)
            lr_def = 0.2 / np.sqrt(n) * (1.0 - 0.5 * progress)

            # Deflation step
            a_def = multiplicative_deflation(a_def, K, lr_def, n_iters=5)
            obj_def_new = compute_obj_norm(a_def)

            # Follow with a few gradient steps
            if obj_def_new < obj_def - 1e-10:
                obj_def = obj_def_new
                beta = 20 + 100 * progress
                grad, conv, p, max_c = softmax_grad(a_def, beta)
                g_norm = float(np.linalg.norm(grad))
                if g_norm > 1e-14:
                    grad = grad / g_norm
                    lr_g = 0.3 / np.sqrt(n)
                    update = np.exp(-lr_g * grad)
                    a_def = a_def * update
                    a_def = np.maximum(a_def, 1e-15)
                    a_def = a_def / float(a_def.sum())
                    obj_def = compute_obj_norm(a_def)

            if obj_def < best_score:
                best_score = obj_def
                best_seq = a_def.copy()

            it += 1
            if it % 50 == 0:
                print(f"    Def it{it}: obj={best_score:.8f}")

        print(f"  Deflation: obj={best_score:.8f}")

    # === Phase 4: Coordinate Descent (15% time) ===
    print(f"\n=== Phase 4: Coordinate Descent ===")
    remaining = deadline - time.monotonic()
    p4_budget = min(remaining * 0.15, 200.0)
    if p4_budget > 20:
        a_cd = coordinate_descent(best_seq, time_budget=p4_budget,
                                  verbose=True, seed=seed + 200,
                                  priority_mode=True)
        obj_cd = compute_obj_norm(a_cd)
        if obj_cd < best_score:
            best_score = obj_cd
            best_seq = a_cd.copy()
            print(f"  CD: obj={best_score:.8f} **")
        else:
            print(f"  CD: obj={obj_cd:.8f}")

    # === Phase 5: Second round of Active Set + CD (10% time) ===
    print(f"\n=== Phase 5: ASQ + CD Refinement ===")
    remaining = deadline - time.monotonic()
    if remaining > 40:
        alloc_asq = min(remaining * 0.05, 80.0)
        alloc_cd = min(remaining * 0.05, 80.0)

        if alloc_asq > 10:
            a_asq2 = active_set_optimization(best_seq, time_budget=alloc_asq,
                                             K_start=20, K_end=80,
                                             seed=seed + 300, verbose=False)
            obj_asq2 = compute_obj_norm(a_asq2)
            if obj_asq2 < best_score:
                best_score = obj_asq2
                best_seq = a_asq2.copy()
                print(f"  ASQ2: obj={best_score:.8f} **")

        remaining = deadline - time.monotonic()
        if remaining > 20:
            a_cd2 = coordinate_descent(best_seq, time_budget=min(remaining * 0.4, 60.0),
                                       verbose=False, seed=seed + 400,
                                       priority_mode=True)
            obj_cd2 = compute_obj_norm(a_cd2)
            if obj_cd2 < best_score:
                best_score = obj_cd2
                best_seq = a_cd2.copy()
                print(f"  CD2: obj={best_score:.8f} **")

    # === Phase 6: LP Polishing (8% time) ===
    print(f"\n=== Phase 6: LP Polishing ===")
    remaining = deadline - time.monotonic()
    p6_budget = min(remaining * 0.08, 100.0)
    if p6_budget > 15:
        a_lp = lp_polish_phase(best_seq, time_budget=p6_budget,
                               seed=seed + 500, verbose=True)
        obj_lp = compute_obj_norm(a_lp)
        if obj_lp < best_score:
            best_score = obj_lp
            best_seq = a_lp.copy()
            print(f"  LP: obj={best_score:.8f} **")
        else:
            print(f"  LP: obj={obj_lp:.8f}")

    # === Phase 7: Multi-length exploration ===
    print(f"\n=== Phase 7: Multi-length Exploration ===")
    remaining = deadline - time.monotonic()
    n_best = len(best_seq)

    n_options = sorted(set([
        n_best - 50, n_best + 50, n_best + 100,
        n_best + 150, n_best + 200,
        700, 900, 1000, 1100, 1200
    ]))
    n_options = [x for x in n_options if 500 <= x <= 1500 and abs(x - n_best) > 30]
    n_options = n_options[:4]

    for n_try in n_options:
        remaining = deadline - time.monotonic()
        if remaining < 50:
            break

        a_try = resample_sequence(best_seq, n_try)
        s_try = float(np.sum(a_try))
        if s_try < 1e-10:
            continue
        a_try = a_try / s_try

        # Quick CD
        alloc = min(remaining * 0.15, 40.0)
        if alloc > 10:
            a_try = coordinate_descent(a_try, time_budget=alloc,
                                       verbose=False, seed=n_try)

        obj_try = compute_obj_norm(a_try)
        if obj_try < best_score:
            best_score = obj_try
            best_seq = a_try.copy()
            print(f"  ** n={n_try}: obj={best_score:.8f} **")
        else:
            print(f"  n={n_try}: obj={obj_try:.8f}")

    # === Phase 8: Diverse Restarts ===
    print(f"\n=== Phase 8: Diverse Restarts ===")
    remaining = deadline - time.monotonic()
    n_current = len(best_seq)

    for r in range(3):
        remaining = deadline - time.monotonic()
        if remaining < 40:
            break

        mode = 1 + r
        a_r = diverse_init(n_current, rng, mode=mode)
        blend = 0.3 + 0.1 * r
        a_r = (1 - blend) * a_r + blend * best_seq
        a_r = np.maximum(a_r, 0)
        a_r = a_r / float(a_r.sum())

        alloc = min(remaining * 0.15, 50.0)
        if alloc > 15:
            a_r = coordinate_descent(a_r, time_budget=alloc, verbose=False,
                                     seed=7000 + r * 111)
            obj_r = compute_obj_norm(a_r)
            if obj_r < best_score:

                print(f"  Restart {r}: obj={best_score:.8f} **")
            else:
                print(f"  Restart {r}: obj={obj_r:.8f}")

    print(f"\n=== Phase 9: Final Polish ===")

    if remaining > 20:

                best_score = obj_final

                print(f"  Final CD: obj={best_score:.8f} **")

                print(f"  Final CD: obj={obj_final:.8f}")

                                              K_start=30, K_end=80,
                                              seed=seed + 8888, verbose=False)
            obj_fasq = compute_obj_norm(a_fasq)
            if obj_fasq < best_score:
                best_score = obj_fasq
                best_seq = a_fasq.copy()

            a_fcd = coordinate_descent(best_seq, time_budget=min(remaining * 0.5, 30.0),
                                       verbose=False, seed=seed + 7777,
                                       priority_mode=True)
            obj_fcd = compute_obj_norm(a_fcd)
            if obj_fcd < best_score:
                best_score = obj_fcd
                best_seq = a_fcd.copy()
                print(f"  Final CD2: obj={best_score:.8f} **")

    # Final validation
    if best_seq is None:
        best_seq = np.ones(200)
        best_score = compute_obj_norm(best_seq)
    else:
        best_seq = np.maximum(best_seq, 0)
        s_final = float(np.sum(best_seq))
        if s_final > 0.01:
            best_seq = best_seq / s_final

    result = [float(max(0.0, min(1000.0, x))) for x in best_seq]
    val = evaluate_sequence(result)
    if val < np.inf:
        best_score = val
    else:
        result = [1.0] * 100
        best_score = 2.0

    elapsed = time.monotonic() - start_time
    print(f"\n=== FINAL: n={len(result)}, score={best_score:.8f}, time={elapsed:.1f}s ===")

    return result
```
