2. Constraint: sum_{i} h[i] = sum_target (equivalent to integral constraint)

4. Global Search: Dual-Annealing with logarithmic tempering
5. Smoothness: l2-regularization applied during function calls

Implementation outline:
1. create_candidates(n, sum_target):
   - build structured patterns (cosine, sawtooth) scaled to sum_target
   - optimize uniform random samples through local adjustments
   - include parent if available

2. COBYLA_bounds(x):
   - objective: np.max(np.correlate(x, 1-x, full)) * dx
   - bounds: [0,1]^n
   - equality: sum(x)=sum_target

3. minimize_slsqp(x):
   - objective: as above
   - constraints: box and equality
   - method: 'SLSQP'

4. repair_candidate(x):
   - clip to [0,1], sum-based scaling

5. select_candidate(res):
   - discard candidates with >10% variance from target

6. smooth_transition(x, smoothness):
   - apply Savitzky-Golay filter with polynomial order=min(3,smoothness)
