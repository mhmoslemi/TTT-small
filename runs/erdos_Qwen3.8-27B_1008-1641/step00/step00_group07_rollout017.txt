**Better approach: Use the fact that C5 is determined by a few "active" lags.**

At any point, C5 = max_k g_k(h). The active set is usually small (2-5 lags). If I can identify the active lags and minimize the max of just those, I make progress.

This is like a "bundle method" for max-of-functions minimization.

Algorithm:
1. Evaluate C5, identify active lags (say up to 5)
2. Solve: min max_{k in active} g_k(h) subject to constraints
3. This is a small nonlinear program (or we can just do gradient descent on max of active g_k)
4. Repeat

For step 2, the subgradient of max g_k is a convex combination of the active gradients. We can use:
- h_new = h - α * (average of active gradients)
- Or: h_new = h - α * (gradient of the single worst g_k)

Let me implement this:

```python
def subgradient_step(h, tsum, dx, alpha):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    # Find active lags (top 5)
    top_k = np.argsort(corr)[-5:][::-1]  # indices of top 5
    # Compute subgradient: average of gradients of top 5
    grad = np.zeros(n)
    for k in top_k:
        lag = k - (n - 1)
        n_lo = max(0, lag)
        n_hi = min(n - 1, n - 1 + lag)
        for nn in range(n_lo, n_hi + 1):
            m = nn - lag
            grad[nn] += (1.0 - h[m])
            grad[m] += -h[nn]
    grad /= len(top_k)
    # Projected step
    h_new = h - alpha * grad
    h_new = project_feasible(h_new, tsum)
    return h_new
```

```python
    h_try[j] -= delta
    h_try = np.clip(h_try, 0, 1)
    # Now sum might not be exactly tsum due to clipping
    h_try = project_feasible(h_try, tsum)
    return h_try
```
