Actually, let me reconsider. For a {0,1} sequence h:
h(x) * (1-h(x+k)) = h(x) - h(x)*h(x+k)

So the sum over x is: sum(h) - autocorrelation(h, k) = n/2 - R(k)

where R(k) is the autocorrelation at lag k.

So C₅ = max_k dx * (n/2 - R(k)) = dx * (n/2 - min_k R(k))

We want to minimize C₅, which means maximizing min_k R(k).

So this IS the minimum autocorrelation problem! We want the binary sequence with the highest minimum autocorrelation.
