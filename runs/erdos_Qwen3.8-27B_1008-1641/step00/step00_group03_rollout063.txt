Actually, I want to also consider: is there a way to vectorize the gradient computation? For n=70, it's not necessary, but let me think for completeness.

The gradient is:
G = sum_{ℓ=0}^{n-1} w_{n-1+ℓ} * (A_ℓ - B_ℓ) + sum_{ℓ=1}^{n-1} w_{n-1-ℓ} * (C_ℓ - D_ℓ)

where:
A_ℓ[j] = (1-h[j+ℓ]) for j ≤ n-1-ℓ, 0 otherwise → this is a "shifted" (1-h)
B_ℓ[j] = h[j-ℓ] for j ≥ ℓ, 0 otherwise → shifted h
C_ℓ[j] = (1-h[j-ℓ]) for j ≥ ℓ, 0 otherwise
D_ℓ[j] = h[j+ℓ] for j ≤ n-1-ℓ, 0 otherwise

Each of these is a vector that can be computed as a slice of h or (1-h). The sum over ℓ is a weighted sum of shifted vectors, which is a convolution.

Specifically:
sum_ℓ w'[ℓ] * (1-h)[j+ℓ] where w'[ℓ] = w_{n-1+ℓ} + w_{n-1-ℓ} (for ℓ>0) and w_{n-1} for ℓ=0
