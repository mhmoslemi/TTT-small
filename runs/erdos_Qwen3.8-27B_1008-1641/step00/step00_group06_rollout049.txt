Let me also add a "coordinate descent" approach where I optimize one variable at a time:

For variable i, given all other h[j] fixed, the objective is:
max_k sum_j h[j+k]*(1-h[j]) * dx

When we change h[i], it affects the correlation terms where index i appears. Specifically, for correlation at lag k:
corr[k] = sum_j h[j+k] * (1-h[j])

h[i] appears in corr[k] when:
- i = j+k (as h[i] = h[j+k]): contributes (1-h[j]) = (1-h[i-k])
- i = j (as (1-h[i])): contributes h[i+k]

So changing h[i] affects corr[k] for all k where the indices are valid.

This is complex to optimize exactly for one variable, but I can do:
- For each i, find the optimal h[i] given all others fixed
- The optimal h[i] minimizes max_k (a_k + b_k * h[i]) where a_k, b_k depend on other variables

Since each corr[k] is linear in h[i] (because it's bilinear overall, but fixing all other variables makes it linear in h[i]), the max of linear functions is convex in h[i], so the optimal h[i] is at a breakpoint or at a boundary (0 or 1).

This gives a coordinate descent method! Let me implement it.

For correlation at lag k (where corr[k] = sum_j h[j+k]*(1-h[j]), with appropriate index ranges):
- h[i] appears as h[j+k] when j = i-k: term is h[i]*(1-h[i-k])
- h[i] appears as (1-h[j]) when j = i: term is (1-h[i])*h[i+k]

So: corr[k] = (terms not involving h[i]) + h[i]*(1-h[i-k]) + (1-h[i])*h[i+k]
            = (terms not involving h[i]) - h[i]*h[i-k] + h[i] - h[i]*h[i+k] + h[i+k]

Wait, let me be more careful. Let's say the full correlation is:
corr[k] = sum_{j: 0<=j<n, 0<=j+k<n} h[j+k] * (1-h[j])

For a fixed i, h[i] appears in this sum when:
1. j+k = i, i.e., j = i-k (if 0 <= i-k < n): contributes h[i]*(1-h[i-k])
2. j = i (of): contributes h[i+k]*(1-h[i]) (if 0 <= i+k < n)

So: corr[k] = C_k + h[i]*(1-h[i-k]) + h[i+k]*(1-h[i]) [for valid indices]
            = C_k + h[i] - h[i]*h[i-k] + h[i+k] - h[i+k]*h[i]

where C_k is the sum of all terms not involving h[i].

The terms involving h[i] are:
h[i]*(1-h[i-k]) + (1-h[i])*h[i+k]
= h[i] - h[i]*h[i-k] + h[i+k] - h[i]*h[i+k]
= h[i+k] + h[i]*(1 - h[i-k] - h[i+k])

So as a function of h[i]:
corr[k] = C_k + h[i+k] + h[i]*(1 - h[i-k] - h[i+k])

This is linear in h[i]! Good.

So the objective max_k corr[k] as a function of h[i] is the max of linear functions, which is convex. The minimum is at the point where the active constraints' lines cross, or at a boundary.

This gives a very efficient coordinate descent:
For each i, compute the slope of each corr[k] with respect to h[i], find the optimal h[i] that minimizes the max.
