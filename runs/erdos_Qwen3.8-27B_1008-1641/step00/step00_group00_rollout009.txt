```python
    # Bisection: find c such that sum(clip(h+c, 0, 1)) = target
    lo, hi = -1.0, 1.0
    for _ in range(60):
        mid = (lo + hi) / 2
        s = np.sum(np.clip(h + mid, 0.0, 1.0))
        if s < target:
            lo = mid
        else:
            hi = mid
    h_out = np.clip(h + (lo+hi)/2, 0.0, 1.0)
    # Fine-tune: distribute residual to non-saturated
    residual = target - np.sum(h_out)
    if abs(residual) > 1e-12:
        mask = (h_out > 0) & (h_out < 1)
        if np.sum(mask) > 0:
            h_out[mask] += residual / np.sum(mask)
            h_out = np.clip(h_out, 0, 1)
    return h_out, target - np.sum(h_out)
```

This is cleaner. The bisection finds the right shift, then we fine-tune.

Now for the gradient computation, let me write it more efficiently using numpy operations:

```python
def compute_gradient(h, n, lag):
    """Gradient of c[lag] = sum_i h[i+lag]*(1-h[i]) w.r.t. h"""
    grad = np.zeros(n)
    if lag >= 0:
        # h[i+lag]*(1-h[i]) for i=0 to n-1-lag
        # d/dh[j]: (1-h[j-lag]) for j>=lag, minus h[j+lag] for j<n-lag
        if n - lag > 0:
            grad[lag:] += (1.0 - h[:n-lag])  # j goes from lag to n-1, j-lag from 0 to n-1-lag
            grad[:n-lag] -= h[lag:]  # j goes from 0 to n-1-lag, j+lag from lag to n-1
    else:
        # h[i+lag]*(1-h[i]) for i=-lag to n-1
        nl = -lag
        # d/dh[j]: (1-h[j+nl]) for j < n-nl, minus h[j-nl] for j>=nl
        if n - nl > 0:
            grad[:n-nl] += (1.0 - h[nl:])  # j goes from 0 to n-1-nl
            grad[nl:] -= h[:n-nl]  # j goes from nl to n-1
    return grad
```

Now the main optimization loop. I want to use a flexible step-size strategy and also consider the "soft-max" trick for better convergence.

Let me also think about whether to use the soft-max. The soft-max approximation of max is:
soft_max(c, t) = (1/t) * log(sum(exp(t*c_k)))
Its gradient is: sum_k softmax_k * grad_k where softmax_k = exp(t*c_k) / sum(exp(t*c_j))

This gives a weighted average of gradients, which can be more stable than just the argmax.

Let me implement both and use the soft-max for better convergence.

Actually, for the problem at hand (n up to maybe 500, so 2n-1 up to 1000 correlations), computing the full correlation each time is fine. Let me just use the argmax for simplicity and add some noise for exploration.

            h_out = np.clip(h_out, 0.0, 1.0)

def corr_gradient(h, n, lag):
    grad = np.zeros(n)
    if lag >= 0:
        m = n - lag
        if m > 0:
            grad[lag:] += (1.0 - h[:m])
            grad[:m] -= h[lag:]
    else:
        nl = -lag
        m = n - nl
        if m > 0:
            grad[:m] += (1.0 - h[nl:])
            grad[nl:] -= h[:m]
    return grad
