For two arrays a and v of length n:
full correlation has length 2n-1
full[k] = sum_i a[i+k-n+1] * v[i] for valid i

Actually, the numpy documentation says:
(c_k = \sum_n a_{n+k} \overline{v_n})

where the product is taken only for valid indices. So:
full[k] = sum_{n: 0≤n<n, 0≤n+k<n} a[n+k] * v[n] = sum_{n: max(0,-k)≤n<min(n, n-k)} a[n+k] * v[n]

For v = 1-h:
full[k] = sum_{valid n} h[n+k] * (1-h[n])

For k=0: sum h[n]*(1-h[n]) = 0 for binary
For k>0: n goes from 0 to n-1-k, so full[k] = sum_{n=0}^{n-1-k} h[n+k]*(1-h[n])
For k<0: n goes from -k to n-1, so full[k] = sum_{n=-k}^{n-1} h[n+k]*(1-h[n])

The full array index range is from -(n-1) to (n-1), stored at positions 0 to 2n-2.
Position p in the array corresponds to k = p - (n-1).

So:
- Position n-1: k=0
- Position n-1+k: k>0 (for k=1,...,n-1)
- Position n-1-k: k<0 (for k=-1,...,-(n-1))
