Let c = np.correlate(h, 1-h, mode="full") * dx (shape: 2n-1)
Let weights = exp(alpha * (c - c.max())) / sum(exp(alpha * (c - c.max())))

= (1-h[j+lag]) * I[0≤j≤n-1-lag for lag>0 or 0≤j≤n-1 for lag=0 or lag+1≤j≤n-1 for lag<0]
  - h[j-lag] * I[0≤j-lag≤n-1 and 0≤j≤n-1]

This is: (1-h)[j+lag] (with 0 padding) - h[j-lag] (with 0 padding), where we zero out-of-bounds indices.

For all j simultaneously, this is:
grad = (1-h) shifted by -lag (i.e., grad[j] = (1-h)[j+lag] if valid) 
     - h shifted by lag (i.e., grad[j] = h[j-lag] if valid)

Which is: np.roll(1-h, -lag) with boundary zeroing - np.roll(h, lag) with boundary zeroing.

More precisely:
For lag > 0:
  (1-h)[j+lag] is valid for j = 0, ..., n-1-lag
  h[j-lag] is valid for j = lag, ..., n-1

For lag < 0:
  Let L = |lag|
  (1-h)[j-L] is valid for j = L, ..., n-1
  h[j+L] is valid for j = 0, ..., n-1-L

For lag = 0:
  (1-h)[j] - h[j] = 1 - 2h[j] for all j

So the gradient contribution from lag k is:
If lag > 0:
  g[0:n-lag] += (1-h)[lag:n]
  g[lag:n] -= h[0:n-lag]

If lag < 0 (L = -lag):
  g[L:n] += (1-h)[0:n-L]
  g[0:n-L] -= h[L:n]

If lag = 0:
  g += 1 - 2*h

This is O(n) per lag, O(n²) total for all lags. Very fast!

from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(corr.max() * dx)

def soft_c5_and_grad(h, alpha):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    c = corr * dx
    m = c.max()
    exp_c = np.exp(alpha * (c - m))
    s = exp_c.sum()
    val = m + np.log(s) / alpha

        w = wts[k]
        if w < 1e-15:
            continue
        L = abs(lag)
        if L == 0:
            grad += w * (1.0 - 2.0 * h)
        elif lag > 0:
            grad[L:] += w * (1.0 - h[:n-L])
            grad[:n-L] -= w * h[L:]
        else:
            grad[:n-L] += w * (1.0 - h[L:])
            grad[L:] -= w * h[:n-L]

    diff = target - h.sum()

        else:
            hi = mid
