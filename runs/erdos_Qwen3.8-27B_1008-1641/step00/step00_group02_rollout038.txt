So c[p] = B_p + h[j] * (1 - h[j-p+n-1]) - h[j]*h[j+p-n+1] (when i=j is valid)

Let me just be more careful. Let me denote the correlation at lag k (where k = p - (n-1), ranging from -(n-1) to (n-1)):

R[k] = ∑_{i} h[i+k] * (1-h[i]) where i ranges over valid indices (0 ≤ i ≤ n-1, 0 ≤ i+k ≤ n-1)

Terms involving h[j]:
1. When i+k = j, i.e., i = j-k: term is h[j] * (1-h[j-k])
   Valid when 0 ≤ j-k ≤ n-1 and 0 ≤ j ≤ n-1 (j is valid since it's our index)
   So valid when 0 ≤ j-k ≤ n-1

2. When i = j: term is h[j+k] * (1-h[j])
   Valid when 0 ≤ j ≤ n-1 (yes) and 0 ≤ j+k ≤ n-1
   So valid when 0 ≤ j+k ≤ n-1

So R[k] = (terms not involving j) + [h[j]*(1-h[j-k]) if 0≤j-k≤n-1] + [h[j+k]*(1-h[j]) if 0≤j+k≤n-1]

= B_k + h[j] - h[j]*h[j-k] (if valid) + h[j+k] - h[j]*h[j+k] (if valid)

= B_k + (h[j+k] if 0≤j+k≤n-1 else 0) + h[j]*(1 - (h[j-k] if 0≤j-k≤n-1 else 0) - (h[j+k] if 0≤j+k≤n-1 else 0))

So R[k] = B_k + D_k + A_k * h[j]

where:
B_k = sum of terms not involving j
D_k = h[j+k] if 0≤j+k≤n-1 else 0
A_k = 1 - (h[j-k] if 0≤j-k≤n-1 else 0) - (h[j+k] if 0≤j+k≤n-1 else 0)

So R[k] is linear in h[j]! And C₅ = max_k R[k] * dx is the max of linear functions of h[j], which is convex in h[j].

So for fixed other coordinates, minimizing C₅ with respect to h[j] (ignoring the sum constraint) is a 1D convex problem that can be solved by finding where the maximum of the piecewise-linear function is minimized.

With the sum constraint, it's trickier. But we can use a Lagrange multiplier λ:
minimize max_k R[k]*dx + λ*(sum(h) - n/2)
= max_k (R[k]*dx + λ/n) ... no, that's not right.

Actually: max_k R[k]*dx + λ*(∑h[j] - n/2) = max_k R[k]*dx + λ*(h[j] + ∑_{i≠j}h[i] - n/2)

The λ*h[j] term is added to the objective. Since R[k] = B_k + D_k + A_k*h[j], the objective becomes:
max_k (B_k + D_k + A_k*h[j])*dx + λ*h[j] + const
= max_k ((B_k + D_k)*dx + A_k*dx*h[j]) + λ*h[j] + const
= max_k (C_k + (A_k*dx + λ)*h[j]) + const

where C_k = (B_k + D_k)*dx is constant w.r.t. h[j].

This is still the max of linear functions of h[j] (with modified coefficients), which is convex. So we can find the optimal h[j] for any λ.

Then we could use bisection on λ to enforce the sum constraint. But this would be slow.

    dx = 2.0 / n

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def soft_max(vals, beta):
    m = np.max(vals)
    return m + np.log(np.sum(np.exp(beta * (vals - m)))) / beta

def soft_obj(x, beta):
    n = len(x)
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode='full') * dx
    return soft_max(corr, beta)

def fix_sum(h, n):
    target = n / 2.0
    h = np.clip(h, 0, 1)
    s = h.sum()
    if s < 1e-12:
        h[:] = 0.5
        return h
    h = h / s * target
    h = np.clip(h, 0, 1)
    diff = target - h.sum()
    if abs(diff) > 1e-14:
        if diff > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        if mask.any():
            h[mask] += diff / mask.sum()
            h = np.clip(h, 0, 1)
    return h

def make_sum_constraint(n):
    def f(x):
        return x.sum() - n / 2.0
    return f

def coord_descent(h, n, n_sweeps=50, time_budget=60):
    t_start = time.time()
    h = h.copy()
    dx = 2.0 / n
    n_corr = 2 * n - 1
    
    for sweep in range(n_sweeps):
        if time.time() - t_start > time_budget:
            break
        for j in range(n):
            old_val = h[j]
            # Compute A_k and C_k by evaluating at 0 and 1
            h[j] = 0.0
            R0 = np.correlate(h, 1.0 - h, mode='full') * dx
            h[j] = 1.0
            R1 = np.correlate(h, 1.0 - h, mode='full') * dx
            h[j] = old_val
            
            A = R1 - R0
            C = R0
            
            # Minimize max_k (C[k] + A[k]*t) over t in [0,1]
            # Use fine grid
            ts = np.linspace(0, 1, 201)
            # R_new[k] = C[k] + A[k]*ts  -> shape (n_corr, 201)
            R_new = C[:, None] + A[:, None] * ts[None, :]
            vals = np.max(R_new, axis=0)
            idx = np.argmin(vals)
            new_val = ts[idx]
            
            if abs(new_val - old_val) > 1e-10:
                h[j] = new_val
                h = fix_sum(h, n)
