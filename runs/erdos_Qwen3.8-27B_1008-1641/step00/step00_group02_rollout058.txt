```python
def project_sum_box(h, target_sum):
    """Project h onto {x: sum(x) = target_sum, 0 <= x <= 1}"""
    # Binary search on lambda for the box constraint
    # x_i = clip(a_i + lambda, 0, 1) where a_i is some offset
    # We need sum(clip(h_i - mu, 0, 1)) = target_sum
    # Actually, the projection onto sum constraint with box is:
    # x_i = clip(h_i - mu, 0, 1) where mu is chosen so sum(x) = target_sum
    
    lo, hi = h.min() - 1, h.max() + 1
    for _ in range(60):
        mu = (lo + hi) / 2
        x = np.clip(h - mu, 0, 1)
        s = x.sum()
        if s > target_sum:
            lo = mu
        else:
            hi = mu
    return np.clip(h - (lo + hi) / 2, 0, 1)
```

This is the exact Euclidean projection onto the intersection of the sum hyperplane and the box. Then I can do:

1. Compute gradient of C5 w.r.t. h
2. Take a step: h_new = h - lr * grad
3. Project onto the constraint set: h_new = project_sum_box(h_new, target_sum)

This avoids needing SLSQP and its lambda constraints.

But the gradient of C5 is only a subgradient (gradient of the maximizing component). For better convergence, I could use a smooth max (softmax):

C5_smooth = (1/T) * log(sum_k exp(T * c_k * dx))

Where c_k = np.correlate(h, 1-h, 'full')[k]

The gradient of this is a weighted average of the individual c_k gradients, weighted by exp(T*c_k*dx)/sum exp(T*c_j*dx).

Actually, for a min-max problem, the standard approach is:
- Track the maximum and its gradient
- When the maximum is unique, use its gradient
- When multiple are close to the max, use a weighted average

Let me implement a practical version:

```python
def c5_smooth_objective(h, dx, T=50):
    c = compute_c5_raw(h) * dx
    c_max = np.max(c)
    c_shifted = c - c_max
    log_sum = np.log(np.sum(np.exp(T * c_shifted))) / T + c_max
    return log_sum

def c5_smooth_gradient(h, dx, T=50):
    n = len(h)
    c = compute_c5_raw(h)
    c_scaled = c * dx
    c_max = np.max(c_scaled)
    weights = np.exp(T * (c_scaled - c_max))
    weights /= weights.sum()
    
    # Sum of weighted gradients
    grad = np.zeros(n)
    for k in range(len(c)):
        w = weights[k]
        if w < 1e-10:
            continue
        lag = k - (n - 1)
        i_start = max(0, -lag)
        i_end = min(n, n - lag)
        for i in range(i_start, i_end):
            j = i + lag
            grad[i] += w * (1 - h[j]) * dx
            grad[j] -= w * h[i] * dx
    return grad
```
