This integral is over what domain? If h is defined on [0,2], then h(x) is defined for x ∈ [0,2] and h(x+k) is defined for x+k ∈ [0,2], i.e., x ∈ [-k, 2-k]. For the product to be defined, x must be in [0,2] ∩ [-k, 2-k] = [max(0,-k), min(2, 2-k)].

For k > 0: ∫_0^{2-k} h(x)(1-h(x+k)) dx
For k < 0: ∫_{-k}^{2} h(x)(1-h(x+k)) dx = ∫_0^{2+k} h(x-k)(1-h(x)) dx (substituting)
For k = 0: ∫_0^2 h(x)(1-h(x)) dx

In the discrete case:
dx = 2/n
For shift s (in units of dx), the integral is:
dx * sum_{i: 0≤i<n, 0≤i+s<n} h[i]*(1-h[i+s])

This is exactly what np.correlate(h, 1-h, "full") gives (at the appropriate index).

    dx = 2.0 / n

def project(h, target):
    h = np.asarray(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    for _ in range(100):
        d = target - h.sum()
        if abs(d) < 1e-12:
            break
        if d > 0:
            m = h < 1.0
        else:
            m = h > 0.0
        cnt = int(m.sum())
        if cnt == 0:
            break
        h[m] += d / cnt
    return np.clip(h, 0.0, 1.0)

def compute_subgrad(h, corr, eps):
    n = len(h)
    cm = np.max(corr)
    w = np.exp((corr - cm) / eps)
    w /= w.sum()

            grad[:L] += wk * (1.0 - h[s:s + L])
