This is valid for indices where both h[n+k] and h[n] exist, i.e., 0 <= n < n_points and 0 <= n+k < n_points.

So for k >= 0: n ranges from 0 to n_points-1-k
For k < 0: n ranges from -k to n_points-1

The result has indices from -(n-1) to n-1 (offset by n-1 in the output array).

This represents: for shift k, the overlap integral is dx * sum_n h[n+k] * (1-h[n]).

This is exactly what we want: for each shift k, compute ∫ h(x+k)(1-h(x)) dx.
