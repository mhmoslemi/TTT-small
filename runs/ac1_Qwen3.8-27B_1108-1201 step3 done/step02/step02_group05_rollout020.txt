```python
def simplex_project(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    # Algorithm from Duchi et al. 2008
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)
```

`B[j] = sum_k weights[k]*p[j-k]`. Let `m = j-k`: `B[j] = sum_m weights[j-m]*p[m]` (m from 0 to n-1, j-m from -(n-1) to j).

This is `(p * weights)[j]` (standard convolution at index j), BUT only the part where `j-m >= 0` contributes (since weights[k] = 0 for k < 0). Actually, `weights` is defined for k = 0,...,2n-2. So `j-m` must be in [0, 2n-2]. For `j < n` and `m >= 0`, `j-m` can be negative, in which case `weights[j-m] = 0`.

So `B[j] = sum_{m=0}^{j} weights[j-m]*p[m] + sum_{m=j+1}^{n-1} 0 = sum_{m=0}^{min(j, n-1)} weights[j-m]*p[m]`.

This IS `(p * weights)[j]` (the j-th element of the linear convolution of p and weights), because in the linear convolution, `(p * weights)[j] = sum_m p[m]*weights[j-m]` where the sum is over m such that both indices are valid. Since weights has length 2n-1 and p has length n, for j < n, the valid range is m = 0 to j (since j-m must be in [0, 2n-2], which is always true for m >= 0 and j < n since j-m <= j < n < 2n-1).

So `B[j] = (p * weights)[j]` for `j = 0, ..., n-1`. ✓
