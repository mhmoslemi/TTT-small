Actually, since the objective is scale-invariant (if we scale a by c, both num and den scale by c²), we can fix sum(a) = S (some constant) and just minimize g(a) = smooth_max(conv(a,a)) subject to sum(a) = S and a ≥ 0.

This simplifies the gradient to just ∂g/∂a[j], projected onto the constraint set {a ≥ 0, sum(a) = S}.

The projection onto {a ≥ 0, sum(a) = S} is:
1. Compute a' = a - lr * grad
2. Project: this is the Euclidean projection onto the intersection of the non-negative orthant and the hyperplane sum = S.

The projection onto sum(a) = S is: a -> a + (S - sum(a))/n (add uniform offset)
The projection onto a ≥ 0 is: a -> max(a, 0)

These don't commute, so we need to use the witness point algorithm or just do:
- a_new = a - lr * grad
- a_new = a_new - mean(a_new) + S/n (project onto hyperplane)
- a_new = max(a_new, 0) (project onto non-negative)
- a_new = a_new * S / sum(a_new) (renormalize to sum = S)

This isn't the exact Euclidean projection onto the intersection, but it's a good approximation.

Let me go with a simpler approach:

- Optimize theta using Adam
- The gradient with respect to theta is: ∂f/∂theta = J^T * ∂f/∂a where J is the Jacobian of softmax

This is the standard "centering" of the gradient.
