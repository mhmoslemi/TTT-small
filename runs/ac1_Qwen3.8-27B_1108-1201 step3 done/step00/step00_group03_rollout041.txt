For the maximization over p (probability simplex), we want to find the p that maximizes the minimum of a^T Q a.

Key insight: The optimal p is the "worst-case" distribution over lags, and the optimal a is the response to that worst case. At the optimum, the max conv is "flat" in the sense that all the "active" lags (where p[k] > 0) have conv[k] = min (the same value).

This is similar to the "max-min" or "Chebyshev" approach in approximation theory.

For practical purposes, we can use an iterative algorithm:
1. Start with some a (e.g., uniform).
2. Compute conv = convolve(a, a).
3. Set p[k] proportional to exp(β * conv[k]) (softmax, approximating the "worst-case" distribution).
4. Solve the QP: min a^T Q a subject to sum a = S, a ≥ 0, where Q[i,j] = p[i+j].
5. Update a.
6. Iterate.

Step 4 is a quadratic programming problem, which can be solved efficiently.

Actually, since we're minimizing a quadratic form subject to linear constraints, and the quadratic form might not be convex (Q might not be PSD), this is non-convex in general. But if Q is PSD (which it will be for "reasonable" p), then it's a convex QP.

When is Q PSD? Q[i,j] = p[i+j] is a Hankel matrix. A Hankel matrix is PSD if and only if the generating sequence is the moment sequence of a positive measure. For p being a probability distribution on {0, ..., 2n-2}, the Hankel matrix Q[i,j] = p[i+j] for 0 ≤ i,j < n is PSD if and only if... hmm, this is not always the case.

Actually, let's think about it differently. a^T Q a = sum_{i,j} a[i]*a[j]*p[i+j] = sum_k p[k] * (sum_{i+j=k} a[i]*a[j]) = sum_k p[k] * conv[k].

Since p is a probability distribution and conv[k] ≥ 0 (because a ≥ 0), we have a^T Q a ≥ 0. But that doesn't mean Q is PSD.

For Q to be PSD, we need a^T Q a ≥ 0 for ALL a (not just non-negative). Since we're restricting to a ≥ 0, we only need a^T Q a ≥ 0 for a ≥ 0, which is always true (as shown above).

For practical purposes, if Q is "close to" PSD (which it likely is for smooth p), then gradient methods on the QP will work well.

Let me simplify: instead of solving the full QP, I can use gradient descent on the objective sum_k p[k]*conv[k] with the constraint sum a = S, a ≥ 0.

The gradient of sum_k p[k]*conv[k] with respect to a[j] is:
∂/∂a[j] sum_k p[k]*conv[k] = sum_k p[k]*∂conv[k]/∂a[j] = 2*sum_k p[k]*a[k-j]*[j∈I(k)]
= 2*c[j] (where c[j] = sum_{m} p[j+m]*a[m] as before)

So the gradient is 2*c[j] for all j. To minimize, we move in the direction -2*c[j].

With the constraint sum a = S: we subtract the mean of the gradient (to maintain the sum).
With the constraint a ≥ 0: we clip.

Algorithm:
1. a = uniform (sum = S, say S = 1 for normalization).
2. Repeat:
   a. conv = np.convolve(a, a)
   b. p = softmax(β * conv)
   c. c = np.correlate(p, a, 'valid')  # c[j] = sum_m p[j+m]*a[m]
   d. a = a - lr * (c - mean(c))
   e. a = max(a, 0)
   f. a = a / sum(a)  # renormalize
3. Return a.

This is essentially a projected gradient method on the simplex.
