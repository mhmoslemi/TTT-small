And alternate between:
1. Update a: minimize L with respect to a (this is a quadratic minimization with constraints)
2. Update t: minimize L with respect to t (1D problem)
3. Update λ: dual ascent

The "update a" step is:
minimize sum_k λ_k * b[k] + μ/2 * sum_k b[k]^2 + ρ/2 * (sum(a) - 1)^2
subject to a >= 0

where b[k] = a^T Q_k a (quadratic in a).

This is a non-convex quadratic program (since Q_k is not PSD). But we can solve it approximately using multiplicative updates or gradient descent.

Actually, for the specific structure of Q_k (anti-diagonal), the objective becomes:
sum_k λ_k * sum_i a[i]*a[k-i] + μ/2 * sum_k (sum_i a[i]*a[k-i])^2 + ρ/2 * (sum(a) - 1)^2

The first term is: sum_i sum_k λ_k * a[i]*a[k-i] = sum_i a[i] * (sum_k λ_k * a[k-i]) = <a, (λ * a)> (convolution)

So the first term is a "convolution-based" quadratic form, which is PSD (it's a Toeplitz form with PSD symbol if λ >= 0).

The second term is more complex (sum of squares of convolutions).

This is getting too complicated for an efficient implementation. Let me just go with a simpler heuristic.

**Practical algorithm:**

1. Start from a uniform sequence (or the parent sequence)
2. Compute b = convolve(a, a)
3. Find the peak positions: K_peak = {k : b[k] >= (1-eps) * max(b)}
4. For each peak position k, compute the "contribution" of each i to b[k]: contrib[i] = a[i] * a[k-i]
5. Identify the "hottest" positions (large contributions) and "coldest" positions (small contributions)
6. Move mass from hot to cold positions
7. Repeat with decreasing step size (annealing)

Additional techniques:
- Use FFT for fast convolution (O(n log n) instead of O(n^2))
- Keep multiple candidates and do a "best of" selection
- Periodically restart with a different initialization

Let me also consider: can we use the FFT to compute the gradient more efficiently?

The gradient of b[k] with respect to a[i] is: a[k-i] + a[i-k] (with 0 for out-of-range).

If we have m peak positions k_1, ..., k_m, the subgradient is:
g[i] = (1/m) * sum_{j=1}^{m} (a[k_j - i] + a[i - k_j])

This can be computed as:
g[i] = (1/m) * sum_{j=1}^{m} a[k_j - i] + (1/m) * sum_{j=1}^{m} a[i - k_j]

The first sum is (1/m) * (a correlated with the indicator of {k_j}), which can be computed via FFT:
Let v be the vector with v[k_j] = 1/m for j=1,...,m and 0 otherwise.
Then sum_j a[k_j - i] / m = (a * v)[i] (correlation, which is convolution with rev(v))

So we can compute the subgradient in O(n log n) using FFT!
