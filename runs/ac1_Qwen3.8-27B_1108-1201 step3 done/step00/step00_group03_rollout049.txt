The idea is:
1. Fix f (the current sequence).
2. Find g that maximizes sum(g) subject to g ≥ 0 and (f*g)_k ≤ M for all k.
3. The constraint (f*g)_k = sum_i f_i * g_{k-i} ≤ M is LINEAR in g!
4. Rescale g to match the normalization.
5. Update f ← (1-t)f + t*g.

This is brilliant! Each iteration solves a linear program (LP), which is very fast even for n=256.

Let me implement this:

```python
import cvxpy as cp
import numpy as np

def solve_lp_for_g(f, M, n):
    """Find g that maximizes sum(g) subject to g >= 0 and (f*g)_k <= M for all k."""
    g = cp.Variable(n, nonneg=True)
    
    constraints = []
    # (f * g)_k = sum_i f_i * g_{k-i} <= M for k = 0, ..., 2n-2
    # This is linear in g.
    for k in range(2*n - 1):
        # (f*g)_k = sum_{i} f[i] * g[k-i] where 0 <= k-i <= n-1
        # = sum_{i=max(0,k-n+1)}^{min(k,n-1)} f[i] * g[k-i]
        expr = 0
        for i in range(max(0, k-n+1), min(k, n-1) + 1):
            expr += f[i] * g[k-i]
        constraints.append(expr <= M)
    
    prob = cp.Problem(cp.Maximize(cp.sum(g)), constraints)
    prob.solve(solver=cp.SCS)
    
    return g.value
```
