To minimize this peak, we want |fft(a, 2n-1)|^2 to be as flat as possible (in the sense that its inverse transform has low peak).

Algorithm (iterative):
1. Initialize a (non-negative, sum = 1)
2. Repeat:
   a. A = fft(a, L) where L >= 2n-1
   b. p = |A|^2
   c. Compute target: we want ifft(p) to have low peak. 
   d. One approach: modify p to reduce its peak in time domain while keeping sum(p) constant.
      - Compute s = ifft(p) (real)
      - Find peak positions
      - Reduce p at frequencies that contribute most to the peak

   g. Project: a_new = max(a_new, 0), normalize to sum = 1

This is essentially the "error reduction" or "Gerchberg-Saxton" type algorithm, where we alternate between:
- Time domain constraint: a >= 0, sum(a) = 1
- Frequency domain "constraint": |A| should be flat

Let me think about the spectral method more carefully.

The idea: We want to minimize max_k c[k] where c = conv(a, a) and a >= 0, sum(a) = S.

Step 1: Compute c = conv(a, a) (or equivalently, c = ifft(|fft(a, 2n-1)|^2)).
Step 2: Identify the "peak" regions of c.
Step 3: Modify a to reduce the peaks.

One approach: "peak shaving" in the frequency domain.
- Let A = fft(a, L) where L = 2n-1 (or next power of 2).
- Let P = |A|^2.
- If we could make P flat, then c would be flat (approximately, for circular convolution).
- The target P would be constant: P_target = sum(P) / L.
- But we can't just set P = P_target because we need to maintain the phase of A (which determines a).

So the iterative step is:
1. A = fft(a_zero_padded, L)
2. P = |A|^2
3. Compute c = real(ifft(P)) [this is the circular conv, which equals linear conv for our zero-padded case]
4. Find peak locations in c.
5. Reduce P at frequencies that contribute most to the peaks.
   - One way: P_new = P * (1 - alpha * softplus(c - threshold)) for some threshold.
   - Or: P_new = P - beta * (c_convolved_with_something)... this gets complicated.

Alternative approach: Direct time-domain "peak shaving".
1. Compute c = conv(a, a).
2. Find the peak value M = max(c).
3. For each a[i], compute its "contribution" to the peak: how much does a[i] contribute to c at the peak locations?
4. Reduce a[i] proportionally to its contribution to the peak.

The contribution of a[i] to c[k] is a[i]*a[k-i] (for the peak k* where c is maximized). So the gradient of c[k*] w.r.t. a[i] is:
d(c[k*])/d(a[i]) = a[k*-i] + a[k*-i] = 2*a[k*-i] (approximately)

So the gradient-based update would be:
a_new[i] = a[i] - lr * 2 * a[(k*-i) mod n] (approximately)

But this is a bit crude. Let me think of a better approach.

Actually, here's a cleaner formulation. Let's use the "proportional reduction" method:

1. Compute c = conv(a, a).
2. Let M = max(c).
3. We want all c[k] <= M * (1 - epsilon) for some small epsilon.
4. For the peak position m, the constraint c[m] <= M(1-eps) means:
   sum_j a[j]*a[m-j] <= M(1-eps)
5. To reduce c[m], we can reduce some a[j] values.
6. The most effective reduction (per unit decrease in a[j]) is for j where a[j]*a[m-j] is largest AND where a[j] also contributes to other c[k] values that are already near the peak.

This is getting complex. Let me just go with a practical iterative algorithm:

Algorithm:
1. Initialize a (e.g., from parent, or random non-negative).
2. Normalize: a = a / sum(a) * S (where S is target sum, say 1).
3. Repeat:
   a. Compute c = conv(a, a) (using FFT for speed).
   b. M = max(c).
   c. Compute gradient: g[i] = 2 * a[m-i] (where m is argmax of c, clipped to valid range).

import numpy as np
import time


def compute_conv_fft(a):
    """Compute linear convolution of a with a using FFT."""
    n = len(a)
    L_conv = 2 * n - 1
    # Next power of 2
    L_fft = 1 << (L_conv - 1).bit_length()
    A = np.fft.rfft(a, L_fft)

    # No wait. ifft(|A|^2) = circular_conv(a, a) for the zero-padded version.
    # But we want linear_conv(a, a) which equals circular_conv with sufficient zero-padding.
    # So: c = ifft(|fft(a, L_fft)|^2)[:L_conv]
    P = A * np.conj(A)
    c = np.fft.irfft(P, L_fft)[:L_conv]
    return c

def spectral_peak_reduce(a, max_iters, beta_start, beta_end, lr_start, lr_end, rng):
    """
    Iteratively reduce the peak of conv(a,a) using gradient descent
    on the smoothed max objective.
    """
    n = len(a)
    a = a.copy().astype(np.float64)
    
    for it in range(max_iters):
        # Anneal parameters
        frac = it / max(max_iters - 1, 1)
        beta = beta_start + (beta_end - beta_start) * frac
        lr = lr_start * (lr_end / lr_start) ** frac
        
        # Compute gradient
        grad = gradient_smoothed_max(a, beta)
        
        # Gradient descent step
        a = a - lr * grad
        a = normalize_nonneg(a)
        
        # Occasionally add noise to escape local minima
        if rng.random() < 0.05:
            a += rng.normal(0, lr * 0.5, n)
            a = normalize_nonneg(a)
    
    return a

For our case, w is defined for k=0,...,2n-2 and a for k=0,...,n-1.
So (w \star a)[i] = sum_{k: 0<=k<=2n-2, 0<=k-i<=n-1} w[k] * a[k-i]

For i in [0, n-1]: k ranges from i to min(i+n-1, 2n-2), and k-i ranges from 0 to min(n-1, 2n-2-i).
Since i <= n-1, we have 2n-2-i >= n-1, so k-i ranges from 0 to n-1.
And k ranges from i to i+n-1, which is within [0, 2n-2] for i in [0, n-1].

For the linear correlation to match, we need (k-i) mod M = k-i (i.e., no wrap-around) for all k in [0, L-1] where w[k] != 0.

This requires k-i >= 0 for all k in [0, L-1] where the term is non-zero, OR if k-i < 0, then a_pad[(k-i) mod M] should be 0.

For i in [0, n-1] and k in [0, 2n-2]:
- k-i ranges from -(n-1) to 2n-2.

So the gradient is: grad[i] = 2 * beta * circular_corr[i] for i = 0, ..., n-1.

Actually, let me try a different approach entirely: **multiplicative update / iterative water-filling**.

The idea: we want to make c[k] = conv(a,a)[k] as uniform as possible. If c[k] > target for some k, we should reduce the "contribution" to c[k], which means reducing a[i] * a[k-i] for various i. The most effective way is to reduce the larger of a[i] and a[k-i].

Algorithm:
1. Initialize a (non-negative, sum = 1).
2. Repeat:
   a. Compute c = conv(a, a).
   b. target = mean(c) + lambda * (max(c) - mean(c)) for some lambda in [0, 1].
   c. For each k where c[k] > target:
      - For each i that contributes to c[k]:
        - Reduce a[i] proportionally to its contribution.
   d. Normalize a.
3. Adjust lambda over time (start with lambda=1, decrease toward 0).

This is a "proportional fairness" approach. But it's O(n^2) per iteration (for each peak k, we iterate over n contributions).

For n = 7000, that's 49 million operations per iteration, which is ~50ms in numpy. We can do ~20 iterations per second, so ~30,000 iterations in 1800 seconds. That should be enough.

"""
Algorithm: Iterative spectral peak reduction for minimizing 2n*max(conv(a,a))/sum(a)^2.
Uses gradient-based peak shaving with FFT-accelerated convolution, multiple
initializations (ramps, exponential, random), and local search refinement.
"""

import numpy as np
import time


def compute_conv_fft(a):
    """Compute linear convolution of a with a using FFT."""
    n = len(a)
    L = 2 * n - 1
    M = 1 << (L - 1).bit_length()
    A = np.fft.rfft(a, M)
    c = np.fft.irfft(A * np.conj(A), M)[:L]
    return c


def compute_objective(a):
    """Compute J(a) = 2n * max(conv(a,a)) / sum(a)^2."""
    n = len(a)
    s = a.sum()
    if s < 1e-10:
        return np.inf
    c = compute_conv_fft(a)
    return float(2.0 * n * c.max() / (s * s))


def grad_smoothed_max(a, beta):
    """
    Compute gradient of sum_k exp(beta * c[k]) w.r.t. a,
    where c = conv(a, a). Uses FFT for efficiency.
    """
    n = len(a)
    c = compute_conv_fft(a)
    L = len(c)  # 2n-1
    max_c = c.max()
    w = np.exp(beta * (c - max_c))
    # Cross-correlation of w (len L) and a (len n) via FFT
    M = 1 << (L + n - 2).bit_length()
    W = np.fft.rfft(w, M)
    A = np.fft.rfft(a, M)
    corr = np.fft.irfft(W * np.conj(A), M)
    # grad[i] = 2*beta * corr[i] for i=0..n-1
    return 2.0 * beta * corr[:n]


def normalize_nonneg(a):
    """Project to non-negative and normalize to sum=1."""
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-12:
        return np.ones(len(a), dtype=np.float64) / len(a)
    return a / s


def peak_reduce(a, time_budget, rng):
    """
    Iterative gradient-based peak reduction with annealing.
    Returns (best_a, best_obj).
    """
    n = len(a)
    a = a.astype(np.float64).copy()
    start_time = time.monotonic()
    best_a = a.copy()
    best_obj = compute_objective(a)
    stall_count = 0
    iterations_since_improve = 0

    beta = 1.0
    lr = 0.02
    noise_scale = 0.002

    iter_count = 0
    while time.monotonic() - start_time < time_budget:
        # Occasionally re-evaluate and adapt
        if iter_count % 100 == 0 and iter_count > 0:
            obj = compute_objective(a)
            if obj < best_obj - 1e-8:
                best_a = a.copy()
                best_obj = obj
                stall_count = 0
                iterations_since_improve = 0
                # Cool down
                noise_scale *= 0.9
                beta *= 1.08
                lr *= 0.97
            else:
                iterations_since_improve += 1
                if iterations_since_improve > 3:
                    # Reheat: go back to best, increase noise
                    a = best_a.copy()
                    noise_scale = min(noise_scale * 4.0, 0.05)
                    lr = min(lr * 2.5, 0.05)
                    beta = max(beta * 0.5, 0.5)
                    iterations_since_improve = 0
                    stall_count += 1
                    if stall_count > 15:
                        break

        # Gradient step
        grad = grad_smoothed_max(a, beta)
        a = a - lr * grad
        # Add noise for exploration
        if noise_scale > 1e-6:
            a += noise_scale * rng.standard_normal(n)
        a = normalize_nonneg(a)
        iter_count += 1

    return best_a, best_obj


def local_search(a, time_budget, rng):
    """Block perturbation local search."""
    n = len(a)
    best = a.astype(np.float64).copy()
    best_obj = compute_objective(best)
    start_time = time.monotonic()
    no_improve = 0

    while time.monotonic() - start_time < time_budget:
        # Perturbation width: mix of small and large
        r = rng.random()
        if r < 0.5:
            width = int(rng.integers(1, max(2, n // 50)))
        elif r < 0.8:
            width = int(rng.integers(n // 50, max(n // 50 + 1, n // 10)))
        else:
            width = int(rng.integers(n // 10, max(n // 10 + 1, n // 2)))
        start_idx = int(rng.integers(0, n - width + 1))

        candidate = best.copy()
        pert_type = rng.random()
        if pert_type < 0.6:
            # Multiplicative
            candidate[start_idx:start_idx + width] *= np.exp(
                rng.normal(0, 0.1, width))
        elif pert_type < 0.8:
            # Additive
            candidate[start_idx:start_idx + width] += rng.normal(
                0, 0.02, width)
        else:
            # Set to new random values
            candidate[start_idx:start_idx + width] = rng.random(width) * 0.1

        candidate = normalize_nonneg(candidate)
        obj = compute_objective(candidate)

        if obj < best_obj:
            best = candidate
            best_obj = obj
            no_improve = 0
        else:
            no_improve += 1
            if no_improve > 5000:
                break

    return best, best_obj


def init_ramp(n, t, rng):
    """Linear ramp initialization."""
    a = 1.0 + t * np.arange(n, dtype=np.float64) / max(n - 1, 1)
    if rng.random() < 0.5:
        a = a[::-1].copy()
    a += 0.005 * rng.standard_normal(n)
    return normalize_nonneg(a)


def init_exponential(n, alpha, rng):
    """Exponential ramp initialization."""
    a = np.exp(alpha * np.arange(n, dtype=np.float64) / max(n - 1, 1))
    if rng.random() < 0.5:
        a = a[::-1].copy()
    a += 0.005 * rng.standard_normal(n)
    return normalize_nonneg(a)


def init_cosine_mod(n, rng):
    """Cosine-modulated initialization (inspired by flat-spectrum design)."""
    a = 1.0 + 0.5 * np.cos(2.0 * np.pi * rng.integers(1, n // 2) *
                            np.arange(n, dtype=np.float64) / n)
    a += 0.1 * rng.standard_normal(n)
    return normalize_nonneg(a)
