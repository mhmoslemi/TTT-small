Actually, for the function f(x) = x^d on [0, n], the convolution (f*f)(k) = integral_0^k x^d (k-x)^d dx for k <= n (in the continuous approximation). This is maximized at... let's see:
d/dk [k^{2d+1} * B(d+1,d+1)] = (2d+1)k^{2d} * B(d+1,d+1) > 0

So it's increasing in k for k <= n! The max in the range k <= n is at k = n.

For k > n, the convolution is (f*f)(k) = integral_{k-n}^{n} x^d (k-x)^d dx, which is decreasing in k.

So the max is at k = n (or k = n-1 in discrete terms), and the value is n^{2d+1} * B(d+1,d+1) = n^{2d+1} * (d!)^2/(2d+1)!.

And sum(f) ≈ n^{d+1}/(d+1).

Score ≈ 2n * n^{2d+1} * (d!)^2/(2d+1)! / (n^{d+1}/(d+1))^2
= 2n^{2d+2} * (d!)^2/(2d+1)! * (d+1)^2/n^{2d+2}
= 2(d+1)^2 * (d!)^2 / (2d+1)!
= 2(d+1)^2 / ((2d+1) * C(2d, d))
