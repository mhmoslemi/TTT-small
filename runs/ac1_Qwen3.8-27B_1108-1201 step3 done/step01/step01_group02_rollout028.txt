Let me also think about the problem from a different angle. The score is:
score = 2n * max_k c_k / S^2

where c = a * a.

This is equivalent to: min max_k c_k subject to sum(a) = 1, a ≥ 0. (Since the 2n factor is constant for fixed n.)

This is a minimax problem. The LP dual would be:
max Σ_k y_k
subject to: Σ_k y_k * (a * a)_k ≥ 1 for all i (this doesn't quite work because of the nonlinearity)

Actually, the problem min max_k c_k subject to sum(a) = 1, a ≥ 0 is NOT linear because c = a * a is quadratic in a.

But the LP approach in the previous code works by fixing a and finding g that satisfies a * g ≤ M. This is a "direction finding" approach, not directly solving the original problem.

A more direct approach would be:
- Alternate between: (1) given g, find a that minimizes max_k (a*g)_k subject to sum(a) = 1, a ≥ 0. (2) Given a, find g that minimizes max_k (a*g)_k subject to sum(g) = 1, g ≥ 0.

Step (2) is exactly the LP in the previous code.
Step (1) is also an LP! For fixed g, minimize max_k (a*g)_k subject to sum(a) = 1, a ≥ 0.
This is: min t subject to (a*g)_k ≤ t for all k, sum(a) = 1, a ≥ 0.
This is a feasible LP!

So we can alternate between:
- Fix g, solve: min t s.t. (a*g)_k ≤ t ∀k, sum(a) = 1, a ≥ 0. → optimal a
- Fix a, solve: min t s.t. (a*g)_k ≤ t ∀k, sum(g) = 1, g ≥ 0. → optimal g

This is a "block coordinate descent" on the bilinear problem min max_k (a*g)_k subject to sum(a)=1, a≥0, sum(g)=1, g≥0.

Wait, but our original problem is min max_k (a*a)_k, not min max_k (a*g)_k with a ≠ g. The alternating approach works on a related but different problem.

However, if the alternating converges to a fixed point where a = g, then we've solved the original problem! And even if it doesn't converge to a fixed point, the sequence of a's generated might be good.

Actually, I recall that this is similar to the "von Neumann minimax" or "zero-sum game" approach. The problem min_a max_k (a*a)_k can be written as:
min_a max_{p in simplex} Σ_k p_k * (a*a)_k

By minimax (Sion's theorem), this equals:
max_{p in simplex} min_a Σ_k p_k * (a*a)_k

The inner minimization is: min_a Σ_k p_k * (sum_i a_i * a_{k-i}) subject to sum(a) = 1, a ≥ 0.
= min_a sum_i sum_j a_i * a_j * p_{i+j}
= min_a a^T P a
where P is a symmetric matrix with P_{ij} = p_{i+j} (with appropriate bounds).

This is a quadratic program! Not linear. So the alternating LP approach is an approximation.

But the alternating LP approach (block coordinate descent on the bilinear relaxation) is still a valid heuristic and might work well in practice.

Actually, for the bilinear problem min_a,g max_k (a*g)_k s.t. a,g ≥ 0, sum=1, the alternating method (also known as the "row-column" method in game theory) is known to converge, though possibly slowly.

Let me code this up:

```python
import numpy as np
from scipy.sparse import csr_matrix
from scipy.optimize import linprog
import time

def score_sequence(a):
    n = len(a)
    conv = np.convolve(a, a)
    max_b = conv.max()
    sum_a = a.sum()
    if sum_a < 0.01:
        return float('inf')
    return 2.0 * n * max_b / (sum_a ** 2)

def build_convolve_rows(a, n):
    """Build the matrix A such that (A @ g)_k = (a * g)_k for k = 0, ..., 2n-2."""
    n_rows = 2 * n - 1
    # For each k, (a*g)_k = sum_{i: max(0,k-n+1) <= i <= min(n-1,k)} a[i] * g[k-i]
    # So the k-th row of A has A[k, i] = a[i] for valid i.
    row_idx = []
    col_idx = []
    data = []
    for k in range(2 * n - 1):
        i_min = max(0, k - n + 1)
        i_max = min(n - 1, k)
        for i in range(i_min, i_max + 1):
            row_idx.append(k)
            col_idx.append(i)
            data.append(a[i])
    return csr_matrix((data, (row_idx, col_idx)), shape=(n_rows, n))

def solve_lp_min_peak(fixed, n):
    """
    Solve: min t s.t. (fixed * x)_k <= t for all k, sum(x) = 1, x >= 0, t >= 0.
    Returns optimal x and t.
    """
    A_conv = build_convolve_rows(fixed, n)
    n_rows = 2 * n - 1
    
    # Variables: x_0, ..., x_{n-1}, t (total n+1 variables)
    # Objective: minimize t → c = [0, ..., 0, 1]
    c = np.zeros(n + 1)
    c[-1] = 1.0
    
    # Inequality constraints: (fixed * x)_k - t <= 0 for k = 0, ..., 2n-2
    # This is: A_conv @ x - t <= 0
    # In standard form: [A_conv | -I] @ [x; t] <= 0
    A_ineq = np.hstack([A_conv.toarray(), -np.eye(n_rows)])
    b_ineq = np.zeros(n_rows)
    
    # Equality constraint: sum(x) = 1
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([1.0])
    
    # Bounds: x_i >= 0, t >= 0
    bounds = [(0, None)] * (n + 1)
    
    res = linprog(c, A_ub=A_ineq, b_ub=b_ineq, A_eq=A_eq, b_eq=b_eq, 
                  bounds=bounds, method='highs', options={'presolve': True})
    
    if res.success and res.x is not None:
        x = np.maximum(0, res.x[:n])
        t = res.x[n]
        return x, t
    return None, None
```

```python
from scipy.sparse import csr_matrix, eye as speye, hstack as sshstack

def solve_lp_min_peak(fixed, n):
    A_conv = build_convolve_rows(fixed, n)
    n_rows = 2 * n - 1
    
    c = np.zeros(n + 1)
    c[n] = 1.0  # minimize t
    
    # [A_conv | -I_{n_rows}] @ [x; t] <= 0
    neg_I = -speye(n_rows, format='csr')
    A_ineq = sshstack([A_conv, neg_I], format='csr')
    b_ineq = np.zeros(n_rows)
    
    # Equality: sum(x) = 1
    ones_row = csr_matrix(np.ones((1, n)))
    A_eq = sshstack([ones_row, csr_matrix(np.zeros((1,1)))], format='csr')
    b_eq = np.array([1.0])
    
    bounds = [(0, None)] * (n + 1)
    
    res = linprog(c, A_ub=A_ineq, b_ub=b_ineq, A_eq=A_eq, b_eq=b_eq,
                  bounds=bounds, method='highs', options={'presolve': True})
    
    if res.success and res.x is not None:
        x = np.maximum(0, res.x[:n])
        t = float(res.x[n])
        return x, t
    return None, None
```
