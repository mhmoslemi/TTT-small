The idea is:
1. Compute b = conv(a, a)
2. Find the peak: k* = argmax b
3. Compute the "peak-reducing" update: a_new[i] = a[i] - α * a[k*-i] (for valid i)

5. Repeat

This is a simple but effective "peak shaving" algorithm. The key is the step size α.

A better version: use all peaks, not just the maximum:
1. Compute b = conv(a, a)
2. For each k with b[k] > threshold, add a "pressure" proportional to b[k] - threshold
3. Update: a_new[i] = a[i] - α * sum_k pressure[k] * a[k-i]
4. Project

This is similar to what the previous code does with top-k, but with a continuous threshold instead of a hard top-k selection.

where p_k = exp(β*b_k) / sum_j exp(β*b_j).

This is a smooth, well-defined gradient that automatically weights the peaks by their "importance." As β increases, it focuses more on the maximum.

**Another important idea: the "Desired Convolution" approach.**

Specifically:
1. Compute b = conv(a, a)
2. Compute error: E[k] = b[k] - C (where C = S^2/(2n-1))
3. The gradient of sum_k (E[k])^2 with respect to a[i] is:

4. Update: a[i] -= lr * gradient[i]
5. Project

This is a least-squares approach to flattening the convolution. It might converge faster than just reducing the max because it uses information from ALL lags, not just the peaks.

"""
Minimize 2*n*max(conv(a,a))/sum(a)^2 over non-negative sequences.

Strategy:
  - Exploit the fact that asymmetric sequences can beat the symmetric bound of 2.
  - Use log-sum-exp smooth approximation for the max in the gradient.
  - Use multiplicative (exponential) updates to preserve non-negativity.
  - Combine peak-reduction with convolution-flattening objectives.
  - Adaptive temperature for the log-sum-exp.
  - Multi-start from diverse initializations including the given sequence.
  - Polish the best with a fine-tuned optimizer in the remaining budget.
"""
import numpy as np
import time
from scipy.fft import fft, ifft


def fft_convolve_self(a):
    """Full self-convolution of sequence a via FFT."""
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    c = np.real(ifft(A * A))
    return c[:size]


def logsumexp_gradient(a, n, beta):
    """Compute the gradient of log-sum-exp(beta * conv(a,a)) with respect to a.
    
    Returns (gradient, log_sum_exp_value, max_conv)
    """
    c = fft_convolve_self(a)
    # Numerically stable log-sum-exp
    c_max = c.max()
    shifted = beta * c - beta * c_max
    exp_shifted = np.exp(shifted)
    sum_exp = exp_shifted.sum()
    # p_k = exp(beta * c_k) / sum exp(beta * c_j) = exp_shifted_k / sum_exp
    p = exp_shifted / sum_exp
    # Gradient: grad[i] = sum_k p_k * a[k-i] (for valid indices)
    # This is a weighted "smeared" version of a
    # Use FFT: grad = conv(a, p) ... wait, not exactly.
    # grad[i] = sum_k p[k] * a[k-i] where k-i must be in [0, n-1]
    # This is a circular correlation-like operation.
    # For each i, grad[i] = sum_{k} p[k] * a[k-i] where 0 <= k-i < n
    # = sum_{j} p[i+j] * a[j] where j = k-i, 0 <= j < n, 0 <= i+j < 2n-1
    # This is a cross-correlation of p and a.
    
    # Actually, let's think again:
    # b[k] = sum_i a[i] * a[k-i] (valid i, k-i)
    # db[k]/da[i] = a[k-i] (if 0 <= k-i < n)
    # So grad[i] = sum_k p[k] * db[k]/da[i] = sum_k p[k] * a[k-i] * 1[0 <= k-i < n]
    
    # Let j = k-i, so k = i+j. Then:
    # grad[i] = sum_j p[i+j] * a[j] * 1[0 <= j < n, 0 <= i+j < 2n-1]
    # = sum_j p[i+j] * a[j] for j in [max(0, 0-i), min(n-1, 2n-1-i)]
    # = sum_j p[i+j] * a[j] for j in [0, n-1] (since i >= 0 and i+j <= i+n-1 <= 2n-2 for i <= n-1)
    
    # So grad[i] = sum_{j=0}^{n-1} a[j] * p[i+j]
    # This is the cross-correlation of a and p (specifically, it's conv-like).
    
    # We can compute this with FFT: 
    # If we define q = reverse(p) (length 2n-1), then grad = conv(a, q) evaluated at specific positions.
    # Actually, let's use: grad[i] = sum_j a[j] * p[i+j]
    # This is (a ⋆ p)[i] where ⋆ is cross-correlation... 
    # Actually in numpy terms: if we compute np.convolve(a, p), we get:
    # (conv_a_p)[k] = sum_i a[i] * p[k-i]
    # We want grad[i] = sum_j a[j] * p[i+j] = (conv_a_p)[i] if p is long enough? No...
    
    # Let me just use FFT directly:
    # grad[i] = sum_j a[j] * p[i+j]
    # Define r[m] = p[m] for m = 0, ..., 2n-2
    # Then grad[i] = sum_j a[j] * r[i+j]
    # This is the "anti-convolution" or cross-correlation.
    # In FFT terms: if A = FFT(a, fsize) and R = FFT(r, fsize), 
    # then cross-correlation = IFFT(A * conj(R)) ... 
    # Actually, cross-correlation of a and r at lag i is:
    #   cc[i] = sum_j a[j] * conj(r[j-i]) (circular)
    # That's not quite what we want.
    
    # Let me just do it with a direct FFT approach:
    # grad[i] = sum_{j=0}^{n-1} a[j] * p[i+j]
    # = sum_{j=0}^{n-1} a[j] * p[i+j]
    # Let's define s = p reversed: s[m] = p[2n-2-m] for m = 0, ..., 2n-2
    # Then p[i+j] = s[2n-2-i-j]
    # grad[i] = sum_j a[j] * s[2n-2-i-j]
    # = (conv(a, s))[2n-2-i]
    
    # So: compute conv(a, s) via FFT, then reverse and take appropriate slice.
    
    fsize = 1 << (3 * n - 1).bit_length()  # enough for conv of length n and 2n-1
    A = fft(a, fsize)
    S = fft(p[::-1], fsize)  # s = p reversed, but p has length 2n-1
    conv_result = np.real(ifft(A * S))
    # conv_result[k] = sum_i a[i] * s[k-i] = sum_i a[i] * p[2n-2-k+i]
    # We want grad[i] = sum_j a[j] * p[i+j]
    # = conv_result[2n-2-i] ... let me verify:
    # conv_result[2n-2-i] = sum_j a[j] * s[2n-2-i-j] = sum_j a[j] * p[2n-2-(2n-2-i-j)] = sum_j a[j] * p[i+j] ✓
    
    grad = conv_result[2*n-2 : n-1 : -1]  # indices 2n-2, 2n-3, ..., n-1 -> grad[0], grad[1], ..., grad[n-1]
    # Wait: conv_result[2n-2-i] for i=0 gives conv_result[2n-2], for i=n-1 gives conv_result[n-1]
    # So grad = conv_result[n-1 : 2n-1][::-1]
    grad = conv_result[n-1:2*n-1][::-1]
    
    lse_val = c_max + np.log(sum_exp) / beta
    return grad, c.max(), lse_val


def run_logsumexp_opt(a_init, n, S, max_time, rng, beta_init, beta_final, lr_init):
    """Optimize using log-sum-exp gradient with multiplicative updates."""
    a = np.clip(a_init.copy(), 0, 1000).astype(np.float64)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n * S
    else:
        a = a * (S / s)
    
    best_score = np.inf
    best_local = a.copy()
    start = time.monotonic()
    t = 0
    
    while time.monotonic() - start < max_time:
        t += 1
        # Adaptive beta: increase over time
        progress = min(1.0, t / 2000.0)
        beta = beta_init + (beta_final - beta_init) * progress
        
        grad, cur_max, lse_val = logsumexp_gradient(a, n, beta)
        
        # The objective (when sum = S) is max_conv, so we track cur_max
        if cur_max < best_score:
            best_score = cur_max
            best_local = a.copy()
            
        # Learning rate decay
        lr = lr_init * (0.5 ** (t / 500.0))
        
        # Multiplicative update: a_new = a * exp(-lr * grad / (S/n))
        # Normalize gradient by typical scale
        grad_scale = np.abs(grad).max()
        if grad_scale < 1e-15:
            break
        grad_norm = grad / grad_scale
        
        a_new = a * np.exp(-lr * grad_norm)
        a_new = np.maximum(a_new, 1e-15)  # avoid zeros
        
        # Renormalize
        s_new = a_new.sum()
        if s_new < 1e-15:
            a = np.full(n, S / n)
        else:
            a = a_new * (S / s_new)
        
        # Periodic noise injection
        if t % 1000 == 0:
            noise = rng.normal(0, 0.02 * S / n, n)
            a = np.maximum(a + noise, 0)
            s = a.sum()
            if s > 1e-15:
                a = a * (S / s)
    
    return best_local, best_score


def run_ls_flatten(a_init, n, S, max_time, rng, lr_init):
    """Optimize by flattening the convolution (reduce variance)."""
    a = np.clip(a_init.copy(), 0, 1000).astype(np.float64)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n * S
    else:
        a = a * (S / s)
    
    best_score = np.inf
    best_local = a.copy()
    start = time.monotonic()
    t = 0
    
    while time.monotonic() - start < max_time:
        t += 1
        c = fft_convolve_self(a)
        cur_max = c.max()
        
        if cur_max < best_score:
            best_score = cur_max
            best_local = a.copy()
        
        # Target: flat convolution at level S^2 / (2n-1)
        target = S * S / (2 * n - 1)
        error = c - target  # shape (2n-1,)
        
        # Gradient of sum(error^2) / 2 w.r.t. a[i]:
        # d/d a[i] sum_k (c[k] - target)^2 = 2 * sum_k error[k] * a[k-i]
        # (same structure as logsumexp_gradient but with error instead of p)
        # Use FFT: grad[i] = sum_j a[j] * error[i+j]
        # Same computation as before
        
        fsize = 1 << (3 * n - 1).bit_length()
        A = fft(a, fsize)
        E = fft(error[::-1], fsize)
        conv_result = np.real(ifft(A * E))
        grad = conv_result[n-1:2*n-1][::-1]
        
        lr = lr_init * (0.5 ** (t / 300.0))
        grad_scale = np.abs(grad).max()
        if grad_scale < 1e-15:
            break
        grad_norm = grad / grad_scale
        
        # Use a combination: reduce peaks (from logsumexp) + flatten (from LS)
        a_new = a - lr * grad_norm
        a_new = np.maximum(a_new, 0)
        
        # Renormalize to sum = S
        s_new = a_new.sum()
        if s_new < 1e-15:
            a = np.full(n, S / n)
        else:
            a = a_new * (S / s_new)
        
        if t % 2000 == 0:
            noise = rng.normal(0, 0.01 * S / n, n)
            a = np.maximum(a + noise, 0)
            s = a.sum()
            if s > 1e-15:
                a = a * (S / s)
    
    return best_local, best_score

    beta1 = 0.9
    
    while time.monotonic() - start < max_time:
        t += 1
        progress = min(1.0, t / 3000.0)
        beta = beta_init + (beta_final - beta_init) * progress
        
        c = fft_convolve_self(a)
        cur_max = c.max()
        
        if cur_max < best_score:
            best_score = cur_max
            best_local = a.copy()
        
        # Compute log-sum-exp gradient
        c_max = c.max()
        shifted = beta * c - beta * c_max
        exp_shifted = np.exp(shifted)
        sum_exp = exp_shifted.sum()
        p = exp_shifted / sum_exp
        
        # LSE gradient
        fsize = 1 << (3 * n - 1).bit_length()
        A = fft(a, fsize)
        P = fft(p[::-1], fsize)
        conv_p = np.real(ifft(A * P))
        grad_lse = conv_p[n-1:2*n-1][::-1]
        
        # LS gradient
        target = S * S / (2 * n - 1)
        error = c - target
        E = fft(error[::-1], fsize)
        conv_e = np.real(ifft(A * E))
        grad_ls = conv_e[n-1:2*n-1][::-1]
        
        # Combined gradient
        grad = alpha * grad_lse + (1 - alpha) * grad_ls
        
        # Momentum
        mom = beta1 * mom + (1 - beta1) * grad
        grad_eff = mom / (1 - beta1 ** t)
        
        lr = lr_init * (0.5 ** (t / 800.0))
        grad_scale = np.abs(grad_eff).max()
        if grad_scale < 1e-15:
            break
        grad_norm = grad_eff / grad_scale
        
        # Multiplicative update
        a_new = a * np.exp(-lr * grad_norm)
        a_new = np.maximum(a_new, 1e-15)
        s_new = a_new.sum()
        if s_new < 1e-15:
            a = np.full(n, S / n)
        else:
            a = a_new * (S / s_new)
        
        if t % 1500 == 0 and rng.random() < 0.3:
            noise = rng.normal(0, 0.01 * S / n, n)
            a = np.maximum(a + noise, 0)
            s = a.sum()
            if s > 1e-15:
                a = a * (S / s)
    
    return best_local, best_score


def generate_initializations(rng, n):
    """Generate diverse initializations of length n."""
    inits = {}
    S = np.sqrt(2.0 * n)
    
    # Uniform
    inits['uniform'] = np.full(n, S / n)
    
    # Linear ramp (more mass at one end)
    tt = np.linspace(0, 1, n)
    inits['ramp_up'] = (1.0 + 2.0 * tt) * (S / n)  # will be renormalized
    inits['ramp_down'] = (3.0 - 2.0 * tt) * (S / n)
    
    # Quadratic (U-shaped)
    inits['u_shape'] = (1.0 + 3.0 * (2 * tt - 1) ** 2) * (S / n)
    
    # Exponential decay
    inits['exp_decay'] = np.exp(-3.0 * tt) * (S / np.exp(-3.0 * tt).sum() * n)
    
    # Cosine
    inits['cosine'] = (1.0 + 0.5 * np.cos(2 * np.pi * tt)) * (S / n)
    
    # Two peaks
    inits['two_peaks'] = (np.exp(-20 * (tt - 0.2) ** 2) + np.exp(-20 * (tt - 0.8) ** 2) + 0.1) * (S / n)
    
    # Random
    inits['random'] = rng.random(n)
    
    # Given sequence (if available)
    try:
        given = np.asarray(height_sequence_1, dtype=np.float64).reshape(-1)
        if given.size == n:
            inits['given'] = np.clip(given, 0, 1000)
        elif given.size > 0:
            # Resample to length n
            from scipy.interpolate import interp1d
            x_old = np.linspace(0, 1, len(given))
            x_new = np.linspace(0, 1, n)
            f = interp1d(x_old, given, kind='cubic', bounds_error=False, fill_value=0)
            inits['given_resampled'] = np.maximum(f(x_new), 0)
    except Exception:
        pass
    
    # Normalize all
    for name in inits:
        arr = inits[name]
        arr = np.clip(arr, 0, 1000)
        s = arr.sum()
        if s > 1e-15:
            inits[name] = arr * (S / s)
        else:
            inits[name] = np.full(n, S / n)
    
    return inits
