**Idea 1: Spectral shaping**
Work in the frequency domain. The peak of the linear convolution is related to the "peak" of the inverse DFT of |A(f)|^2. If we can make |A(f)|^2 very flat, the time-domain peak should be small.

For a sequence of length n, zero-padded to length L, the circular autocorrelation has DFT |A_L(f)|^2. If |A_L(f)|^2 is constant (= L/n * (sum a)^2 / L = (sum a)^2/n), then the circular autocorrelation is (sum a)^2/n * delta, i.e., all values are (sum a)^2/n.

But we want LINEAR autocorrelation, not circular. The linear autocorrelation is the "unwrapped" version.

Actually, for the linear convolution, if we think of it as the circular convolution of the zero-padded sequence, then:
linear_conv(a,a) = circuit_conv(a_padded, a_padded)[:2n-1]

The DFT of a_padded has |A(f)|^2 whose inverse DFT gives the circular autocorrelation of the padded sequence. The linear convolution is the first 2n-1 values of this.

If the circular autocorrelation is flat (all values equal to (sum a)^2/L where L is the padding length), then the linear convolution values are all (sum a)^2/L, and the max is (sum a)^2/L.

For this to be achievable, we need |A(f)|^2 = L * (sum a)^2 / L^2 = (sum a)^2/L for all f. This means A(f) has constant magnitude, i.e., a is a "flat spectrum" sequence.

A sequence with flat spectrum is one where the DFT has constant magnitude. These are related to "Golay sequences" and "Barker sequences" but in the continuous domain.

For a real non-negative sequence of length n, we can't have a perfectly flat spectrum (that would require |A(f)| = constant for all f, which for a real sequence means A(f) is related to A(L-f), giving constraints).

But we can APPROXIMATE a flat spectrum. The idea:
1. Choose a target spectrum |A(f)|^2 that's as flat as possible
2. Find a non-negative sequence a whose DFT (zero-padded) has this magnitude

This is like an inverse problem. One approach:
1. Start with a random non-negative sequence
2. Compute its DFT (zero-padded to length L)
3. Replace the magnitude with the target (flat) magnitude, keep the phase
4. Inverse DFT
5. Project to non-negative (clip negative values to 0)
6. Repeat (this is the Gerchberg-Saxton / error reduction algorithm)

This is similar to the "spectral fitting" approach used in optics and crystallography.

- Fixed a: minimize t subject to a*b <= t, b >= 0, sum(b) = 1. Also an LP!

minimize t subject to b*a <= t, a >= 0, sum(a) = 1, b >= 0, sum(b) = 1.

This is a non-convex problem (bilinear constraint), but we can use block coordinate descent:
- Fix b, optimize a and t (LP)
- Fix a, optimize b and t (LP)
- Repeat

At convergence, a = b (hopefully), and we get a locally optimal solution.

import numpy as np
import time
from scipy.optimize import linprog


def fast_convolve(a):
    """Linear auto-convolution via FFT with next-power-of-2 size."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def build_conv_matrix(n):
    """Build matrix C such that C @ g = a * g for a given a (stored as C rows)."""
    # Pre-allocate structure; actual values filled when a is known
    C = np.zeros((2 * n - 1, n))
    for i in range(n):
        C[i:i + n, i] = 1  # placeholder, will be scaled by a
    return C


def build_conv_matrix_for_a(a):
    """Build matrix C such that C @ g = a * g (full linear convolution)."""
    n = len(a)
    C = np.zeros((2 * n - 1, n))
    for i in range(n):
        C[i:i + n, i] = a
    return C


def solve_lp_direction(a, M):
    """
    Solve LP: maximize sum(g) s.t. a*g <= M (componentwise), g >= 0.
    Returns (g, g_sum) or (None, 0) if infeasible.
    """
    n = len(a)
    A_ub = build_conv_matrix_for_a(a)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n

    result = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')

    if result.success:
        g = result.x
        g_sum = g.sum()
        if g_sum > 1e-10:
            return g, g_sum
    return None, 0.0


def spectral_project(a, alpha=0.1, L=None):
    """
    Project sequence towards flat power spectrum.
    Blends current spectrum magnitude with flat target.
    """
    n = len(a)
    if L is None:
        L = 1 << (4 * n - 1).bit_length()

    a_padded = np.zeros(L)
    a_padded[:n] = a

    A = np.fft.rfft(a_padded)
    current_mag = np.abs(A)
    target_mag = a.sum() / np.sqrt(L) * np.ones_like(current_mag)

    # Blend magnitudes
    new_mag = (1 - alpha) * current_mag + alpha * target_mag

    # Preserve phase
    phase = np.angle(A)
    A_new = new_mag * np.exp(1j * phase)

    a_new = np.fft.irfft(A_new, L)[:n]
    a_new = np.maximum(a_new, 0.0)
    s = a_new.sum()
    if s < 1e-15:
        return a.copy()
    return a_new / s


def multi_direction_lp(a, M, n_steps=5):
    """
    Try multiple LP constraint levels and return the best direction.
    Returns (best_g, best_g_sum, best_M_used).
    """
    best_g = None
    best_g_sum = 0
    best_M = M

    # Try a range of M values from tight to loose
    for i in range(n_steps):
        M_try = M * (1.0 - 0.01 * (n_steps - 1 - i))
        if M_try < M * 0.9:
            M_try = M * 0.9
        g, g_sum = solve_lp_direction(a, M_try)
        if g is not None and g_sum > best_g_sum:
            best_g = g
            best_g_sum = g_sum
            best_M = M_try

    # If none worked with tighter M, try the original M
    if best_g is None:
        g, g_sum = solve_lp_direction(a, M)
        if g is not None:
            best_g = g
            best_g_sum = g_sum
            best_M = M

    return best_g, best_g_sum, best_M

def subgradient_optimize_v2(a0, time_limit, lr_init=0.012, momentum=0.93, top_k=30):
    """
    Improved subgradient descent with adaptive temperature and peak weighting.
    """
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)

    v = np.zeros(n)
    conv = fast_convolve(a)
    best_obj = 2.0 * n * conv.max()
    best_a = a.copy()

    t0 = time.monotonic()
    lr = lr_init
    no_improve = 0
    temp = 0.001
    batch = 50
    batch_count = 0

    while time.monotonic() - t0 < time_limit:
        for _ in range(batch):
            if time.monotonic() - t0 > time_limit:
                break

            # Find peaks with softmax weighting
            peaks = np.argpartition(conv, -top_k)[-top_k:]
            peak_vals = conv[peaks]
            scaled = peak_vals / temp
            scaled -= scaled.max()
            w = np.exp(scaled)
            w_sum = w.sum()
            if w_sum < 1e-15:
                w = np.zeros(len(peaks))
                w[np.argmax(peak_vals)] = 1.0
            else:
                w /= w_sum

            # Compute subgradient
            sg = np.zeros(n)
            for i in range(len(peaks)):
                if w[i] < 1e-14:
                    continue
                k = int(peaks[i])
                j_start = max(0, k - n + 1)
                j_end = min(n - 1, k)
                idx = np.arange(j_start, j_end + 1)
                sg[idx] += w[i] * 2.0 * a[k - idx]

            # Momentum update
            v = momentum * v - lr * sg
            a_new = a + v
            a_new = np.maximum(a_new, 0.0)
            s_new = a_new.sum()
            if s_new > 1e-15:
                a = a_new / s_new
            else:
                a = best_a.copy()

            conv = fast_convolve(a)
            cur_obj = 2.0 * n * conv.max()

            if cur_obj < best_obj - 1e-13:
                best_obj = cur_obj
                best_a = a.copy()
                no_improve = 0
            else:
                no_improve += 1

        batch_count += 1
        lr *= 0.995
        temp *= 1.005
        momentum = min(0.96, momentum + 0.0005)

        # Periodic spectral projection
        if batch_count % 5 == 0 and no_improve > 100:
            a = spectral_project(best_a, alpha=0.08)
            conv = fast_convolve(a)
            cur_obj = 2.0 * n * conv.max()
            if cur_obj < best_obj:
                best_obj = cur_obj
                best_a = a.copy()
            no_improve = 0

        if no_improve >= 500:
            # Reset with perturbation
            rng = np.random.default_rng(batch_count * 11 + 3)
            noise = rng.standard_normal(n) * 0.01
            a = best_a + noise
            a = np.maximum(a, 0.0)
            s = a.sum()
            if s > 1e-15:
                a = a / s
            v = np.zeros(n)
            no_improve = 0
            lr = lr_init * 0.8

    return best_a, best_obj


def generate_initializations(n, parent, rng):
    """Generate diverse initializations."""
    inits = {}
    x = np.arange(n, dtype=np.float64)

    inits['uniform'] = np.ones(n) / n

    # Random
    inits['random'] = rng.dirichlet(np.ones(n) * 0.5)

    # Ramp (increasing)
    ramp = x + 1.0
    inits['ramp'] = ramp / ramp.sum()

    # Ramp (decreasing)
    inits['ramp_rev'] = inits['ramp'][::-1].copy()

    # Triangle
    tri = np.minimum(x, n - 1 - x) + 1.0
    inits['triangle'] = tri / tri.sum()

    # Bimodal (edges)
    edge = max(1, n // 5)
    bi = np.zeros(n)
    bi[:edge] = 1.0
    bi[-edge:] = 1.0
    inits['bimodal'] = bi / bi.sum()

    # Gaussian center
    sigma = 0.3 * n
    g = np.exp(-0.5 * ((x - 0.5 * n) / sigma) ** 2)
    inits['gaussian'] = g / g.sum()

    # Exponential decay
    exps = np.exp(-x / (n / 3.0))
    inits['exp_decay'] = exps / exps.sum()

    # Sine
    sine = np.sin(np.pi * (x + 0.5) / n) + 0.05
    inits['sine'] = sine / sine.sum()

    # Quadratic (parabola opening down)
    quad = 1.0 - ((x - n / 2.0) / (n / 2.0)) ** 2
    quad = np.maximum(quad, 0.01)
    inits['quadratic'] = quad / quad.sum()

    # From parent
    if parent is not None and len(parent) > 0:
        p = np.maximum(parent, 0).astype(np.float64)
        ps = p.sum()
        if ps > 1e-10:
            if len(p) == n:
                inits['parent'] = p / ps
            elif len(p) > n:
                pp = np.interp(np.linspace(0, 1, n), np.linspace(0, 1, len(p)), p)
                pp = np.maximum(pp, 0)
                pps = pp.sum()
                if pps > 1e-10:
                    inits['parent_ds'] = pp / pps
            else:
                pp = np.interp(np.linspace(0, 1, n), np.linspace(0, 1, len(p)), p)
                pp = np.maximum(pp, 0)
                pps = pp.sum()
                if pps > 1e-10:
                    inits['parent_up'] = pp / pps

    return inits

    init_names = list(inits.keys())

    # Priority order
    priority = ['parent', 'parent_ds', 'parent_up', 'uniform', 'random',
                'ramp', 'ramp_rev', 'gaussian', 'exp_decay', 'bimodal', 'sine']
    init_names = [nm for nm in priority if nm in inits] + \
                 [nm for nm in init_names if nm not in priority]
    init_names = init_names[:6]

    t_per_init = max(10.0, phase1_limit / (len(init_names) + 1))
    scan_results = []

    for name in init_names:
        if time.monotonic() > phase1_deadline - 20:
            break
        t_alloc = min(t_per_init, phase1_deadline - time.monotonic() - 10)
        if t_alloc < 5:
            break

        a0 = inits[name]
        a_opt, obj_opt = lp_optimize_adaptive(a0, time_limit=t_alloc)
        score = float(evaluate_sequence(a_opt.tolist()))

        if np.isfinite(score):
            scan_results.append((score, n_target, name, a_opt.copy()))
            if score < best_score:
                best_score = score
                best_sequence = a_opt.copy()
                print(f"  n={n_target}, {name}: {score:.6f}")

    # Also try n=1024 with a quick run
    if time.monotonic() < phase1_deadline - 30 and len(scan_results) > 0:
        n_large = 1024
        inits_large = generate_initializations(n_large, parent, rng)
        for name in ['uniform', 'random']:
            if time.monotonic() > phase1_deadline - 15:
                break
            t_alloc = min(30.0, phase1_deadline - time.monotonic() - 10)
            if t_alloc < 5:
                break
            a0 = inits_large[name]
            a_opt, obj_opt = lp_optimize_adaptive(a0, time_limit=t_alloc)
            score = float(evaluate_sequence(a_opt.tolist()))
            if np.isfinite(score):
                scan_results.append((score, n_large, name, a_opt.copy()))
                if score < best_score:
                    best_score = score
                    best_sequence = a_opt.copy()
                    print(f"  n={n_large}, {name}: {score:.6f}")

    scan_results.sort(key=lambda x: x[0])
    print(f"Phase 1 done ({time.monotonic()-t_start:.0f}s). Best: {best_score:.6f}")

    # === Phase 2: Deep LP optimization (900s) ===
    print("=== Phase 2: Deep LP Optimization ===")
    t_start2 = time.monotonic()
    phase2_deadline = min(t_start2 + 900.0, deadline - 200.0)

    # Use the best from Phase 1
    if best_sequence is not None:
        n_best = len(best_sequence)
        a_start = best_sequence.copy()
    else:
        n_best = n_target
        a_start = inits['uniform']

    # Run LP optimization for most of the phase
    t_alloc = phase2_deadline - time.monotonic() - 5
    if t_alloc > 10:
        a_opt, obj_opt = lp_optimize_adaptive(a_start, time_limit=t_alloc, verbose=True)
        score = float(evaluate_sequence(a_opt.tolist()))
        if np.isfinite(score) and score < best_score:
            best_score = score
            best_sequence = a_opt.copy()
            print(f"  Deep LP: {score:.6f}")

    # Second round with spectral-assisted start
    if time.monotonic() < phase2_deadline - 20 and best_sequence is not None:
        a_spec = spectral_project(best_sequence, alpha=0.15)
        a_spec2 = spectral_project(best_sequence, alpha=0.3)
        for a_try in [a_spec, a_spec2]:
            if time.monotonic() > phase2_deadline - 10:
                break
            t_alloc = min(30.0, phase2_deadline - time.monotonic() - 5)
            if t_alloc < 5:
                break
            a_opt, obj_opt = lp_optimize_adaptive(a_try, time_limit=t_alloc)
            score = float(evaluate_sequence(a_opt.tolist()))
            if np.isfinite(score) and score < best_score:
                best_score = score
                best_sequence = a_opt.copy()
                print(f"  Spectral + LP: {score:.6f}")

    print(f"Phase 2 done ({time.monotonic()-t_start2:.0f}s). Best: {best_score:.6f}")

    # === Phase 3: Subgradient polish (250s) ===
    print("=== Phase 3: Subgradient Polish ===")
    t_start3 = time.monotonic()
    phase3_deadline = min(t_start3 + 250.0, deadline - 80.0)

    if best_sequence is not None:
        sg_configs = [
            {'lr_init': 0.008, 'momentum': 0.94, 'top_k': 40},
            {'lr_init': 0.015, 'momentum': 0.90, 'top_k': 25},
            {'lr_init': 0.005, 'momentum': 0.96, 'top_k': 60},
        ]

        remaining = phase3_deadline - time.monotonic()
        t_per_sg = max(10.0, remaining / (len(sg_configs) + 1))

        for ci, cfg in enumerate(sg_configs):
            if time.monotonic() > phase3_deadline - 10:
                break
            t_alloc = min(t_per_sg, phase3_deadline - time.monotonic() - 5)
            if t_alloc < 5:
                break

            a_opt, obj_opt = subgradient_optimize_v2(best_sequence, time_limit=t_alloc, **cfg)
            score = float(evaluate_sequence(a_opt.tolist()))
            if np.isfinite(score) and score < best_score:
                best_score = score
                best_sequence = a_opt.copy()
                print(f"  SG {ci}: {score:.6f}")

    print(f"Phase 3 done ({time.monotonic()-t_start3:.0f}s). Best: {best_score:.6f}")

    # === Phase 4: Final LP polish (remaining time) ===
    print("=== Phase 4: Final Polish ===")
    t_start4 = time.monotonic()
    if best_sequence is not None:
        remaining = deadline - time.monotonic() - 10.0
        if remaining > 15:
            # Alternate between LP, spectral, and subgradient
            n_best = len(best_sequence)
            a_cur = best_sequence.copy()

            for step in range(max(1, int(remaining / 15))):
                if time.monotonic() > deadline - 8:
                    break
                t_alloc = min(15.0, deadline - time.monotonic() - 5)
                if t_alloc < 5:
                    break

                if step % 3 == 0:
                    # LP optimization
                    a_opt, _ = lp_optimize_adaptive(a_cur, time_limit=t_alloc)
                elif step % 3 == 1:
                    # Spectral + LP
                    a_spec = spectral_project(a_cur, alpha=0.08)
                    a_opt, _ = lp_optimize_adaptive(a_spec, time_limit=t_alloc)
                else:
                    # Subgradient
                    a_opt, _ = subgradient_optimize_v2(a_cur, time_limit=t_alloc)

                score = float(evaluate_sequence(a_opt.tolist()))
                if np.isfinite(score) and score < best_score:
                    best_score = score
                    best_sequence = a_opt.copy()
                    a_cur = a_opt.copy()
                    print(f"  Final step {step}: {score:.6f}")

    print(f"Phase 4 done ({time.monotonic()-t_start4:.0f}s). Best: {best_score:.6f}")

    # Fallback
    if best_sequence is None:
        best_sequence = np.ones(256) / 256
        best_score = float(evaluate_sequence(best_sequence.tolist()))

    # Final verification
    final_score = float(evaluate_sequence(best_sequence.tolist()))
    if np.isfinite(final_score):
        best_score = final_score

    print(f"\nFINAL: score={best_score:.6f}, n={len(best_sequence)}")
    return [float(x) for x in best_sequence]
