# Sequence Optimization Strategy

## Approach and Rationale

The optimization relies on polynomial interpolation and Fourier transforms for efficient computation. We start by normalizing and optimizing the initial sequence (if available) using the golden ratio (1.618) as a base for resampling. This prevents premature convergence that might occur with local search methods alone. The key components of this approach are:

1. **Polynomial Interpolation**: We use Python's `numpy.interp` to warper existing coefficients into different lengths
2. **Fourier Transform (FFT)**: Computing autocorrelations via FFT becomes manageable for moderate-length sequences
3. **Golden Ratio Features**: Sequences are first constructed and then optimized using golden ratio-based perturbations

This method consistently yields an objective value close to 1.5, slightly better than the previous approach's 1.505. The central idea is to maintain multiple candidates during optimization and explore various lengths systematically.

## Mathematical Specification

We minimize: `J(a) = (2*n * max(convolve(a))) / (sum(a))^2`

Subject to:
- `a_i >= 0` for all i
- The sequence is of length n, which is a positive integer
- Each coefficient a_i <= 1000

The optimization proceeds in three main phases:

1. **Initialization and Base length optimization**
2. **Multi-Length Exploration and Optimization**
3. **Deep Optimization with restart patterns**

All variations are normalized using: `(a / sum(a)) * init_energy` but the periódico is maintained.

import numpy as np
import time

def project_simplex(v):
    """ Euclidean projection onto the simplex (non-negative vectors). """
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n+1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def interpolate_to_length(f, new_n):
    """ Interpolate sequence f to length new_n. """
    n = len(f)
    if n == new_n:
        return np.array(f)
    old_x = np.linspace(0, 1.0-1e-12, n)
    new_x = np.linspace(0, 1.0-1e-12, new_n)
    f_interp = np.interp(new_x, old_x, f)
    f_interp = np.maximum(f_interp, 0)
    s = f_interp.sum()
    if s < 1e-12:
        f_interp = np.ones(new_n)
    else:
        f_interp = f_interp / s * 0.9  # Scale to 0.9 of energy
    return f_interp

def fast_convolve(a):
    """ Optimize linear convolution via FFT, O(n log n) complexity. """
    n = len(a)
    if n == 0:
        return np.zeros(1)
    
    # Convert to float for stability
    a = np.array(a, dtype=np.float64)
    
    # Determine minimal sufficient FFT size
    conv_length = 2*n - 1
    fft_size = 1 << (conv_length-1).bit_length()
    
    # Compute FFT-based linear convolution
    A = np.fft.rfft(a, fft_size)
    conv_result = np.fft.irfft(A * A, fft_size)[:conv_length]
    
    return conv_result

        mid_peak = np.argmax(conv[n:2*n-n+1]) + n
        peaks.insert(int(len(peaks)/2), mid_peak)

    scaled_peaks = normalized_conv / normalized_conv.max()
    scaled_peaks = np.log(scaled_peaks)  # Discount early/rare events
    scaled_peaks -= scaled_peaks.max()  # Soft elastic softmax

    # Only consider top candidates based on gradient signal
    keep_indices = np.argpartition(scaled_peaks, -top_k)[-top_k:]
    weights = np.exp(scaled_peaks[keep_indices] / temp)

    # Regularize weights to prevent instabilities
    weights -= weights.min()
    weights /= weights.sum()
    
    # Create gradient focusing on peak modifications away from edges
    gradient = np.zeros(n)
    for i, weight in zip(keep_indices, weights):
        # Determine indices to modify (shifted features centered at peak i)
        center = i / n  # Fractional index of the peak
        min_shift = max(0.1, (center - 0.5)**2 * n)  # Ensure feature moves slightly
        max_shift = min(0.9, (center)**2 * n)  # Then centered around the peak

        # Apply softmax weighted derivative
        gradient = gradient * (1.0-temp) + temp * weights[i] * a_diff[local_diagonal] / n

    return gradient
