- subgrad[j] = p[j] for j = k/2 (if k is even)

`grad_k = shift(reversed(p), k) + shift(p, k)` (with appropriate boundary handling)

More precisely, `grad_k[j] = 2*p[k-j]` for valid k-j (and j) (except when j = k/2).

`conv[k] = sum_j p[j]*p[k-j]`

This is the k-th element of the linear convolution of p with p. The gradient of this with respect to p is:
`grad = [convolve(p, reversed(p)) at position k]`... 

Actually, the gradient of the k-th autocorrelation value is simply:
`grad_k = p shifted by k, reversed + p shifted by k`

def conv_gradient(p, k):
    """Compute gradient of conv(p,p)[k] with respect to p."""
    n = len(p)
    grad = np.zeros(n)
    # conv[k] = sum_j p[j]*p[k-j]
    # d/dp[j0] conv[k] = p[k-j0] + (p[j0] if j0 != k-j0 else 0)
    # Actually: = p[k-j0] + p[k-j0] if k-j0 != j0, else p[j0]
    # Simplified: = 2*p[k-j0] if k-j0 valid and k-j0 != j0
    #              = p[j0] if 2*j0 == k
    #              = 0 if k-j0 not valid
    lo = max(0, k - (n-1))
    hi = min(n-1, k)
    for j in range(lo, hi+1):
        if 2*j == k:
            grad[j] = p[j]
        else:
            grad[j] = 2*p[k-j]
    return grad
```

Let me also think about a completely different approach: **Solving the non-convex problem using alternating minimization or fixed-point iteration.**

**Fixed-point iteration idea:**
At the optimum, we have `conv[k] = t` for all active k. If we fix all but one variable, we can solve for that variable to make the active constraints tight. This gives a coordinate descent / Gauss-Seidel type method.

For variable p[j], the constraints are:
`sum_m p[m]*p[k-m] <= t` for all k.

If we fix all p[m] for m ≠ j, then:
`p[j]*p[k-j] + p[j]*p[k-j] + (constant) <= t` (roughly)
`2*p[j]*p[k-j] + C_k <= t`
`p[j] <= (t - C_k) / (2*p[k-j])` for all k where p[k-j] > 0.

So `p[j] <= min_k (t - C_k) / (2*p[k-j])`.

This gives an upper bound on p[j]. We can iteratively update each p[j] to this bound (or a fraction of it).

This is similar to the "water-filling" approach used in signal processing.

Let me code this up:

```python
def fixed_point_iteration(p_init, t_target, max_iter=1000):

            # => p[j] <= (t - C_k) / (2*p[k-j]) for all k where p[k-j] > 0
            
            p_old_j = p[j]

By the rearrangement inequality, this is minimized when p is "oppositely sorted" to its reverse, i.e., when p is monotone. But as we saw, a monotone sequence gives a terrible score because the edge peaks become large.

Let me try yet another approach: **formulate as a min-max problem and solve using bisection on t.**

For a given t, check if there exists p >= 0, sum(p) = 1, such that conv[k] <= t for all k.

This is equivalent to checking if the feasible set is non-empty. The constraints are:
- p >= 0
- sum(p) = 1
- p^T Q_k p <= t for all k

The quadratic constraints make this non-convex. But we can use a relaxation:
- Replace p^T Q_k p <= t with a linear constraint using the tangent at a feasible point.

This gives an SDP or LP relaxation that we can solve iteratively (cutting plane method).

Actually, here's a cleaner approach:

**Benders decomposition / cutting plane:**

1. Start with an initial p (e.g., uniform).
2. Compute conv(p) and find the max.
3. Add a cutting plane constraint: for the active lag k*, add the linear approximation of conv[k*] at the current p.
4. Solve the resulting LP.
5. Iterate.

The linear approximation of conv[k*] at p is:
`conv[k*] ≈ p^T Q_k* p + (p' - p)^T Q_k* p + ... ≈ p^T Q_k* p + 2*(p' - p)^T Q_k* p` (first order)

So the cutting plane is:
`2*p^T Q_k* (p' - p) + p^T Q_k* p <= t`

i.e., `2*(Q_k* p)^T p' <= t + p^T Q_k* p`

Where `Q_k* p` is the gradient of conv[k*] at p (which is `2*p reversed and shifted`, as computed earlier).

This is a valid cutting plane for the non-convex function (it's a tangent plane, and since we're minimizing the max, the tangent gives a valid under-estimate... wait, for a non-convex function, the tangent is NOT a valid under-estimate).

Hmm, this won't work directly for non-convex functions.

Let me try a different approach: **use the KKT conditions.**

At the optimum, there exist Lagrange multipliers λ_k >= 0 for each conv[k] <= t constraint, and μ for the sum constraint, such that:

`2 * sum_k λ_k * (Q_k p) + μ * 1 = ν * max(p, 0)` (roughly, for the p >= 0 constraint)

Where Q_k p is the gradient of conv[k] at p.

This is a system of equations that can be solved iteratively.

```python
"""
Multi-phase optimization for minimizing peak autocorrelation of non-negative sequences.
Combines subgradient descent, LP direction finding, coordinate descent, and 
simulated annealing across multiple sequence lengths and initializations.
"""

import numpy as np
import time
from scipy.optimize import linprog
from scipy.fft import rfft, irfft


def fft_convolve(a, b):
    n, m = len(a), len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = rfft(a, size)
    fb = rfft(b, size)
    return irfft(fa * fb, size)[:n + m - 1]


def score_fast(a):
    a = np.asarray(a, dtype=np.float64)
    a = np.clip(a, 0.0, 1000.0)
    n = len(a)
    S = float(np.sum(a))
    if S < 0.01:
        return np.inf
    c = fft_convolve(a, a)
    return float(2.0 * n * np.max(c) / (S * S))


def conv_gradient(p, k, n):
    """Gradient of conv(p,p)[k] w.r.t. p."""
    grad = np.zeros(n)
    lo = max(0, k - (n - 1))
    hi = min(n - 1, k)
    for j in range(lo, hi + 1):
        idx = k - j
        if idx < 0 or idx >= n:
            continue
        if 2 * j == k:
            grad[j] = p[j]
        else:
            grad[j] = 2.0 * p[idx]
    return grad


def conv_gradient_fast(p, k, n):
    """Faster gradient using vectorized operations."""
    lo = max(0, k - (n - 1))
    hi = min(n - 1, k)
    js = np.arange(lo, hi + 1)
    idxs = k - js
    grad = np.zeros(n)
    mask = (idxs >= 0) & (idxs < n)
    valid_js = js[mask]
    valid_idxs = idxs[mask]
    values = 2.0 * p[valid_idxs]
    # Handle the case where 2*j == k
    center_mask = (2 * valid_js == k)
    values[center_mask] = p[valid_js[center_mask]]
    grad[valid_js] = values
    return grad


def subgradient_optimize(p_init, time_limit, K=10, lr_init=0.05, verbose=False):
    """Subgradient descent on the simplex for minimizing max(conv)."""
    n = len(p_init)
    p = p_init.astype(np.float64).copy()
    p = np.clip(p, 0.0, None)
    S = p.sum()
    if S < 1e-10:
        p = np.ones(n) / n
    else:
        p = p / S
    
    best_p = p.copy()
    best_conv_max = np.max(fft_convolve(p, p))
    t0 = time.monotonic()
    lr = lr_init
    momentum = np.zeros(n)
    beta = 0.9
    stall = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        if time.monotonic() - t0 >= time_limit - 1.0:
            break
        
        conv = fft_convolve(p, p)
        conv_max = np.max(conv)
        
        # Find top-K active constraints
        K_actual = min(K, len(conv))
        top_indices = np.argsort(conv)[-K_actual:]
        
        # Compute subgradient
        subgrad = np.zeros(n)
        for k in top_indices:
            k = int(k)
            subgrad += conv_gradient_fast(p, k, n)
        subgrad /= K_actual
        
        # Remove mean (since we're on the simplex)
        subgrad -= np.mean(subgrad)
        
        # Update with momentum
        momentum = beta * momentum + (1.0 - beta) * subgrad
        p_new = p - lr * momentum
        p_new = np.clip(p_new, 0.0, None)
        S_new = p_new.sum()
        if S_new < 1e-10:
            p_new = np.ones(n) / n
        else:
            p_new = p_new / S_new
        
        # Evaluate
        conv_new = fft_convolve(p_new, p_new)
        conv_max_new = np.max(conv_new)
        
        if conv_max_new < best_conv_max:
            best_conv_max = conv_max_new
            best_p = p_new.copy()
            stall = 0
        else:
            stall += 1
        
        # Adaptive learning rate
        if stall > 20:
            lr *= 0.9
            stall = 0
            # Occasionally perturb
            if lr < 0.001:
                p_new += 0.01 * np.random.standard_normal(n)
                p_new = np.clip(p_new, 0.0, None)
                p_new = p_new / p_new.sum()
                lr = lr_init * 5
        
        p = p_new
        it += 1
        
        if verbose and it % 100 == 0:
            elapsed = time.monotonic() - t0
            print(f"    [subgrad {elapsed:6.1f}s] it={it} conv_max={conv_max_new:.6f} best={best_conv_max:.6f} lr={lr:.5f}")
    
    return best_p, best_conv_max


def build_conv_matrix(f, n):
    """Build matrix A where A @ b = conv(f, b) (full length 2n-1)."""
    A = np.zeros((2 * n - 1, n), dtype=np.float64)
    for j in range(n):
        A[j:j + n, j] = f
    return A


def solve_lp_direction(f, M, n, timeout=3.0):
    """Solve LP: max sum(b) s.t. conv(f,b) <= M, b >= 0."""
    A = build_conv_matrix(f, n)
    c_obj = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    try:
        res = linprog(c_obj, A_ub=A, b_ub=b_ub,
                      bounds=[(0, None)] * n,
                      method='highs',
                      options={'time_limit': timeout, 'presolve': True})
        if res.success:
            return res.x
    except Exception:
        pass
    return None


def lp_optimize(f_init, time_limit, verbose=False):
    """LP-based direction finding optimization."""
    n = len(f_init)
    f = f_init.astype(np.float64).copy()
    f = np.clip(f, 0.01, None)
    best_f = f.copy()
    best_score = score_fast(f)
    t0 = time.monotonic()
    it = 0
    stall = 0
    
    while time.monotonic() - t0 < time_limit:
        if time.monotonic() - t0 >= time_limit - 3.0:
            break
        
        conv = fft_convolve(f, f)
        M = float(np.max(conv))
        
        b = solve_lp_direction(f, M, n, timeout=2.0)
        if b is None:
            stall += 5
            if stall > 30:
                break
            continue
        
        S = float(np.sum(f))
        Sb = float(np.sum(b))
        if Sb < 1e-12:
            break
        b = b * (S / Sb)
        
        # Line search
        best_t = 0.05
        best_s = np.inf
        for t_try in [0.1, 0.05, 0.02, 0.01]:
            f_cand = (1.0 - t_try) * f + t_try * b
            f_cand = np.clip(f_cand, 0.01, None)
            s_cand = score_fast(f_cand)
            if s_cand < best_s:
                best_s = s_cand
                best_t = t_try
        
        f = (1.0 - best_t) * f + best_t * b
        f = np.clip(f, 0.01, None)
        it += 1
        
        if best_s < best_score - 1e-12:
            best_score = best_s
            best_f = f.copy()
            stall = 0
        else:
            stall += 1
        
        if verbose and it % 50 == 0:
            elapsed = time.monotonic() - t0
            print(f"    [LP {elapsed:6.1f}s] it={it} score={best_s:.6f} best={best_score:.6f}")
        
        if stall >= 50:
            # Perturb to escape local minimum
            rng = np.random.default_rng(it * 7919 + 42)
            f += 0.02 * rng.standard_normal(n)
            f = np.clip(f, 0.01, None)
            stall = 0
    
    return best_f, best_score


def coordinate_descent(f_init, time_limit, verbose=False):
    """Coordinate descent: optimize one element at a time."""
    n = len(f_init)
    f = f_init.astype(np.float64).copy()
    best_f = f.copy()
    best_score = score_fast(f)
    t0 = time.monotonic()
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        if time.monotonic() - t0 >= time_limit - 2.0:
            break
        
        improved = False
        for j in range(n):
            if time.monotonic() - t0 >= time_limit - 2.0:
                break
            
            old_val = f[j]
            # Try a range of values
            for scale in [0.8, 0.9, 1.1, 1.2, 0.7, 1.3, 0.5, 1.5]:
                f[j] = old_val * scale
                f[j] = max(0.01, f[j])
                s = score_fast(f)
                if s < best_score:
                    best_score = s
                    best_f = f.copy()
                    improved = True
                    break
            f[j] = old_val
        
        it += 1
        if not improved and it > 3:
            break
        
        if verbose and it % 10 == 0:
            print(f"    [CD {time.monotonic()-t0:6.1f}s] it={it} best={best_score:.6f}")
    
    return best_f, best_score


def make_initializations(n, rng):
    """Generate diverse initializations."""
    inits = []
    t = np.arange(n, dtype=np.float64)
    tx = t / max(1, n - 1)
    
    # Hann window
    inits.append(0.5 * (1.0 + np.cos(2.0 * np.pi * tx)))
    # U-shaped (inverted Hann)
    inits.append(0.5 * (1.0 - np.cos(2.0 * np.pi * tx)))
    # Uniform
    inits.append(np.ones(n))
    # Triangular
    inits.append(1.0 - np.abs(2.0 * tx - 1.0))
    # Cosine modulation (various frequencies)
    for freq in [1, 2, 3, 5]:
        inits.append(1.0 + 0.5 * np.cos(2.0 * np.pi * freq * tx))
    # Chirp
    inits.append(1.0 + 0.3 * np.cos(2.0 * np.pi * (tx + 2.0 * tx**2)))
    # Random smoothed
    for _ in range(3):
        raw = rng.standard_normal(n)
        # Simple smoothing
        kernel = np.ones(5) / 5
        smoothed = np.convolve(raw, kernel, mode='same')
        inits.append(1.0 + 0.3 * smoothed)
    # Power law
    inits.append(tx ** 0.5 + 0.1)
    inits.append((1 - tx) ** 0.5 + 0.1)
    
    # Add small noise to each
    result = []
    for a in inits:
        a = a + 0.02 * rng.standard_normal(n)
        a = np.clip(a, 0.01, None)
        result.append(a)
    
    return result
