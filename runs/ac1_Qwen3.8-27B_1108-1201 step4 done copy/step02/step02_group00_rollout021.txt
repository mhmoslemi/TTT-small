- Let a[i] = x (variable)
- Let S = sum_{j≠i} a[j] (fixed)
- conv_k = base_k + x * m_k where m_k = a[k-i] if 0<=k-i<n, else 0
- Objective: g(x) = 2n * max_k (base_k + x*m_k) / (S+x)^2

To find the optimal x:
- g(x) is the ratio of a convex piecewise-linear function to (S+x)^2
- The maximum of (base_k + x*m_k) over k is the upper envelope of lines
- Each line has slope m_k = a[k-i] >= 0 (since a >= 0)
- So all slopes are non-negative
- The upper envelope is a convex, non-decreasing piecewise-linear function
- g(x) = C(x) / (S+x)^2 where C(x) is convex and non-decreasing
- g'(x) = [C'(x)(S+x)^2 - C(x)*2(S+x)] / (S+x)^4 = [C'(x)(S+x) - 2C(x)] / (S+x)^3
- g'(x) = 0 when C'(x)(S+x) = 2C(x)

Since C(x) is piecewise linear, C'(x) is piecewise constant. So g'(x) is piecewise of the form (c*(S+x) - 2*(b + c*x)) / (S+x)^3 = (cS + cx - 2b - 2cx) / (S+x)^3 = (cS - cx - 2b) / (S+x)^3

This is linear in x (for each piece), so g'(x) is a rational function that changes sign at most once per piece. Overall, g(x) is likely unimodal.

So we can use ternary search or golden section to find the optimal x in [0, x_max].

What should x_max be? If we normalize to sum=1 after each sweep, then x should be in [0, 1]. But during the sweep, we might want x to be larger. Let's use [0, 2*S/(n-1)] as a reasonable upper bound (this ensures the new element isn't more than twice the average of the others).

Actually, for simplicity, let's just use [0, 2] as the range (since we normalize to sum=1, no element should need to exceed 2 in practice).

For the 1D optimization, golden section search with 40 iterations gives relative precision of about (0.618)^40 ≈ 1e-9, which is more than enough.

Each evaluation of g(x) requires computing max_k (base_k + x*m_k). If we precompute base and m, this is O(n) per evaluation (just a dot product + max).

Total cost per coordinate: 40 * n operations.
Total cost per sweep: n * 40 * n = 40 * n^2 operations.
For n=256: 40 * 65536 = 2.6M operations per sweep.
At ~10^8 ops/sec in Python/NumPy: ~0.03 seconds per sweep.

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def compute_obj(a, conv):
    n = len(a)
    s = a.sum()
    if s < 1e-15:
        return float('inf')
    return 2.0 * n * conv.max() / (s * s)

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using coordinate descent with golden-section
inner optimization, combined with subgradient exploration and multi-length search.
Key innovation: exact 1D coordinate updates via golden section on the piecewise-
linear max-convolution objective, giving near-exact per-coordinate optimization
and much faster convergence than subgradient methods alone.
"""

import numpy as np
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def compute_obj_normalized(a, conv):
    """Compute 2n*max(conv) for sum-normalized sequence."""
    n = len(a)
    return 2.0 * n * conv.max()


def coordinate_descent(a_init, time_limit, start_time, rng, max_sweeps=None,
                       perturb_interval=25, perturb_scale=0.02):
    """
    Coordinate descent with golden-section 1D optimization per coordinate.
    Maintains conv incrementally for O(n) per-coordinate cost.
    """
    a = np.maximum(a_init.astype(np.float64), 0.0).copy()
    n = len(a)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    conv = fast_convolve(a).copy()
    best_obj = 2.0 * n * conv.max()
    best_a = a.copy()

    no_improve = 0
    sweep = 0
    gr = (np.sqrt(5.0) - 1.0) / 2.0

    while (max_sweeps is None or sweep < max_sweeps) and time.monotonic() - start_time < time_limit:
        sweep += 1
        order = rng.permutation(n)
        improved = False

        for i in order:
            if time.monotonic() - start_time > time_limit:
                break

            x_old = a[i]
            k_lo = i
            k_hi = min(2 * n - 2, i + n - 1)
            m_len = k_hi - k_lo + 1
            m = a[:m_len]  # a[0], a[1], ..., a[m_len-1] = a[k_hi - i]

            # Precompute unaffected max
            unaff_max = 0.0
            if k_lo > 0:
                v = conv[:k_lo].max()
                if v > unaff_max:
                    unaff_max = v
            if k_hi < 2 * n - 2:
                v = conv[k_hi + 1:].max()
                if v > unaff_max:
                    unaff_max = v

            conv_aff = conv[k_lo:k_lo + m_len]

            # Golden section search on [0, 1]
            x_lo = 0.0
            x_hi = 1.0
            c = x_hi - gr * (x_hi - x_lo)
            d = x_lo + gr * (x_hi - x_lo)

            def f_at(x):
                dx = x - x_old
                if abs(dx) < 1e-15:
                    aff_max = conv_aff.max()
                else:
                    aff_max = np.max(conv_aff + dx * m)
                tot_max = aff_max if aff_max > unaff_max else unaff_max
                s_new = 1.0 - x_old + x
                return 2.0 * n * tot_max / (s_new * s_new)

            fc = f_at(c)
            fd = f_at(d)
            for _ in range(42):
                if fc < fd:
                    x_hi = d
                    d = c
                    fd = fc
                    c = x_hi - gr * (x_hi - x_lo)
                    fc = f_at(c)
                else:
                    x_lo = c
                    c = d
                    fc = fd
                    d = x_lo + gr * (x_hi - x_lo)
                    fd = f_at(d)

            x_opt = 0.5 * (x_lo + x_hi)
            f_opt = f_at(x_opt)
            f_cur = 2.0 * n * max(conv_aff.max(), unaff_max)

            if f_opt < f_cur - 1e-13:
                dx = x_opt - x_old
                conv[k_lo:k_lo + m_len] += dx * m
                a[i] = x_opt
                improved = True

        # Renormalize
        s = a.sum()
        if s < 1e-15:
            a = np.ones(n) / n
            conv = fast_convolve(a)
        else:
            a /= s
            conv /= (s * s)

        cur_obj = 2.0 * n * conv.max()
        if cur_obj < best_obj - 1e-12:
            best_obj = cur_obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1

        if no_improve >= perturb_interval:
            scale = min(0.05, perturb_scale * (1 + 0.5 * (no_improve // perturb_interval)))
            noise = rng.standard_normal(n) * scale
            a = np.maximum(a + noise, 0.0)
            s = a.sum()
            a /= s
            conv = fast_convolve(a)
            no_improve = 0
            perturb_interval = min(50, perturb_interval + 3)

    return best_a, best_obj


def subgradient_optimize(a_init, time_limit, start_time, lr=0.02, momentum=0.9,
                         top_k=20, temp=0.001):
    """Projected subgradient with momentum as exploration aid."""
    a = np.maximum(a_init.astype(np.float64), 0.0).copy()
    n = len(a)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    conv = fast_convolve(a)
    best_obj = 2.0 * n * conv.max()
    best_a = a.copy()
    v = np.zeros(n)
    lr_cur = lr
    moment_cur = momentum

    while time.monotonic() - start_time < time_limit:
        # Compute subgradient from top-k peaks
        if top_k >= len(conv):
            peaks = np.arange(len(conv))
            peak_vals = conv
        else:
            peaks = np.argpartition(conv, -top_k)[-top_k:]
            peak_vals = conv[peaks]

        scaled = peak_vals / temp
        scaled -= scaled.max()
        w = np.exp(scaled)
        w_sum = w.sum()
        if w_sum < 1e-15:
            w = np.zeros(len(peaks))
            w[np.argmax(peak_vals)] = 1.0
        else:
            w /= w_sum

        sg = np.zeros(n)
        for idx in range(len(peaks)):
            if w[idx] < 1e-12:
                continue
            k = int(peaks[idx])
            wi = w[idx] * 2.0
            j_start = max(0, k - n + 1)
            j_end = min(n - 1, k)
            for j in range(j_start, j_end + 1):
                sg[j] += wi * a[k - j]

        v = moment_cur * v - lr_cur * sg
        a_new = np.maximum(a + v, 0.0)
        s_new = a_new.sum()
        if s_new > 1e-15:
            a_new /= s_new
        a = a_new
        conv = fast_convolve(a)
        cur_obj = 2.0 * n * conv.max()

        if cur_obj < best_obj - 1e-12:
            best_obj = cur_obj
            best_a = a.copy()

        lr_cur *= 0.9998
        moment_cur = min(0.97, moment_cur + 0.0003)

    return best_a, best_obj


def generate_initializations(n, parent, rng):
    """Generate diverse initializations of length n, normalized to sum=1."""
    inits = {}
    x = np.arange(n, dtype=np.float64)

    inits['uniform'] = np.ones(n) / n

    # Ramp
    ramp = np.arange(1, n + 1, dtype=np.float64)
    inits['ramp'] = ramp / ramp.sum()

    # Gaussian center
    g = np.exp(-0.5 * ((x - 0.5 * (n - 1)) / (0.25 * n)) ** 2)
    inits['gauss'] = g / g.sum()

    # Cosine modulation
    for freq in [1, 2, 3, 5]:
        c = 1.0 + 0.4 * np.cos(2.0 * np.pi * freq * x / n)
        c = np.maximum(c, 0.01)
        inits[f'cos_{freq}'] = c / c.sum()

    # Sine modulation
    for freq in [1, 2]:
        c = 1.0 + 0.3 * np.sin(2.0 * np.pi * freq * x / n + 0.5)
        c = np.maximum(c, 0.01)
        inits[f'sin_{freq}'] = c / c.sum()

    # Bimodal (edges)
    bi = np.zeros(n)
    edge = max(1, n // 5)
    bi[:edge] = 1.0
    bi[-edge:] = 1.0
    inits['bimodal'] = bi / bi.sum()

    # Random
    inits['random'] = rng.dirichlet(np.ones(n) * 0.5) / 1.0
    s = inits['random'].sum()
    inits['random'] /= s

    # Random frequency mix (abs of random DFT)
    for trial in range(3):
        coeffs = rng.standard_normal(n) + 1j * rng.standard_normal(n)
        coeffs[0] = np.abs(coeffs[0]) + 1.0  # positive DC
        sig = np.fft.irfft(coeffs, n)
        sig = np.abs(sig) + 0.01
        inits[f'randfreq_{trial}'] = sig / sig.sum()

    # From parent
    if parent is not None and len(parent) > 0:
        p = np.maximum(parent, 0.0)
        ps = p.sum()
        if ps > 1e-10:
            if len(p) == n:
                inits['parent'] = p / ps
            else:
                # Resample to length n
                pp = np.interp(np.linspace(0, 1, n),
                               np.linspace(0, 1, len(p)), p)
                pp = np.maximum(pp, 0.0)
                pps = pp.sum()
                if pps > 1e-10:
                    inits['parent_rs'] = pp / pps

    return inits
