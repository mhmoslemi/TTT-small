Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using FFT-accelerated smooth subgradient
descent with momentum, annealed smoothness, multiple restarts, and local polish.

Key technique: The subgradient of the smooth max of the linear autocorrelation
is computed in the frequency domain via g_hat[m] = 2*A[-m]*FFT(w)[m],

def _norm_nonneg(a):

def _obj_fast(a, L):
    """Fast objective evaluation using FFT. Assumes a is normalized to sum 1."""
    A = fft(a, L)

    return float(2.0 * len(a) * C.max())


def _subgrad_freq(A, L, C, ktop, eps, neg_idx, n):
    """
    Compute subgradient of eps*log(sum exp(C_k/eps)) w.r.t. a,

    Returns gradient of length n.
