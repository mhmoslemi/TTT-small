For large n, if we can get max(convolve) ≈ (sum)^2 / (2n), then the objective approaches 1. The question is how close to this lower bound we can get.

The sum of all elements of the convolution is (sum a)^2, and there are 2n-1 elements. So the average is (sum a)^2 / (2n-1). The max must be at least this average. So the objective is at least 2n/(2n-1), which approaches 1.

But for non-negative sequences, the convolution has additional structure that prevents it from being perfectly flat.

Key observation: convolve[0] = a[0]^2 and convolve[2n-2] = a[n-1]^2. These are the "edges" of the convolution. If the sequence is non-uniform, these edge values will differ from the interior values.

For the convolution to be as flat as possible, we'd want a[0]^2 ≈ a[n-1]^2 ≈ interior values. This suggests a[0] ≈ a[n-1] ≈ constant, which pushes toward uniformity.
