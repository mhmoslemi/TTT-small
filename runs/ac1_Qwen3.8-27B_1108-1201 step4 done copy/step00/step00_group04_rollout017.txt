For the target of 1.5027, we need `max_c / (sum_a)^2 ≈ 1.5027 / (2n)`. With sum_a = 1, this is `max_c ≈ 0.7514/n`. The average is `1/(2n-1) ≈ 1/(2n)`. So the peak is about 1.5x the average. This is quite flat!

def fft_convolve(a, b):
    L = len(a) + len(b) - 1
    n_fft = 1 << (L - 1).bit_length()
    fa = np.fft.rfft(a, n=n_fft)
    fb = np.fft.rfft(b, n=n_fft)
    return np.fft.irfft(fa * fb, n=n_fft)[:L]

def objective_smooth(a, tau):
    """Smooth approximation of max(convolve(a,a))."""
    c = fft_convolve(a, a)
    c_shifted = c - c.max()
    return tau * np.log(np.sum(np.exp(c_shifted / tau)))

def gradient_smooth(a, tau):
    """Gradient of the smooth objective."""
    c = fft_convolve(a, a)
    c_shifted = c - c.max()
    w = np.exp(c_shifted / tau)
    w /= w.sum()
    
    g = np.zeros(len(a))
    n = len(a)
    # For numerical efficiency, only process non-negligible weights
    threshold = 1e-10
    active = np.where(w > threshold)[0]
    for k in active:
        j_min = max(0, k - n + 1)
        j_max = min(n - 1, k)
        lo = k - j_max
        hi = k - j_min + 1
        g[j_min:j_max+1] += w[k] * 2.0 * a[lo:hi][::-1]
    return g

Let me reconsider. Using `a = softmax(z)` parameterization:
- `a` is always in the interior of the simplex (positive, sums to 1).
- We minimize `f(z) = soft_max(conv(softmax(z), softmax(z)), tau)` with respect to `z`.
- This is a smooth function (for tau > 0), so L-BFGS should work.

The gradient `df/dz = df/da * da/dz`. And `da/dz[j] = a[j] * (delta_{jk} - a[k])` (the Jacobian of softmax).

But computing `df/da` requires the convolution gradient, which is O(n * num_active_peaks). And `da/dz` is a full n×n matrix, so `df/dz = J^T * (df/da)` where `J` is the Jacobian of softmax.

`J[j,k] = a[j] * (delta_{jk} - a[k])`.

So `df/dz[j] = sum_k J[k,j] * df/da[k] = sum_k a[k]*(delta_{kj} - a[j]) * df/da[k]`
`= a[j] * df/da[j] - a[j] * sum_k a[k] * df/da[k]`
`= a[j] * (df/da[j] - dot(a, df/da))`

So the gradient w.r.t. z is: `grad_z[j] = a[j] * (grad_a[j] - dot(a, grad_a))`.

This is a scaled and centered version of `grad_a`. Nice!

    from scipy.optimize import minimize
    import numpy as np
    
    n = len(a_init)
    log_a = np.log(np.maximum(a_init, 1e-30))
    # Center it (softmax is invariant to adding a constant)
    log_a -= log_a.mean()
    
    tau = tau_init
    
    def objective(z):
        a = np.exp(z - z.max())  # numerically stable softmax
        a /= a.sum()
        c = fft_convolve(a, a)
        c_shifted = c - c.max()
        return tau * np.log(np.sum(np.exp(c_shifted / tau)))
    
    def gradient(z):
        a = np.exp(z - z.max())
        a /= a.sum()
        c = fft_convolve(a, a)
        c_shifted = c - c.max()
        w = np.exp(c_shifted / tau)
        w /= w.sum()
        
        # grad_a
        grad_a = np.zeros(n)
        active = np.where(w > 1e-8)[0]
        for k in active:
