- Define `a_i = target_sum * exp(x_i) / sum_j exp(x_j)`
- This guarantees `a_i > 0` and `sum(a) = target_sum`

With this parameterization, the gradient w.r.t. `x` is:
`∂F/∂x_i = sum_j (∂F/∂a_j) * (∂a_j/∂x_i)`

where `∂a_j/∂x_i = a_j * (delta_{ij} - a_j/target_sum)` (softmax Jacobian).

So `∂F/∂x = (∂F/∂a) ⊙ a - a * sum((∂F/∂a) ⊙ a) / target_sum`

where `⊙` is element-wise multiplication.

This is O(n) to compute given `∂F/∂a`.

    """Compute objective and gradient w.r.t. x for softmax parameterization."""
    # Softmax parameterization
    x_shifted = x - np.max(x)
    exp_x = np.exp(x_shifted)
    a = target_sum * exp_x / np.sum(exp_x)
    
    # Compute convolution
    size = 1 << (2*n - 2).bit_length()
    fa = np.fft.rfft(a, size)
    c = np.fft.irfft(fa * fa, size)[:2*n-1]
    
    # Log-sum-exp
    tau = 0.1  # fixed smoothing
    c_s = c / tau
    c_max = np.max(c_s)
    log_sum_exp = c_max + np.log(np.sum(np.exp(c_s - c_max)))
    
    # Gradient of log-sum-exp w.r.t. a
    w = np.exp(c_s - c_max) / np.sum(np.exp(c_s - c_max))
    grad_a = 2.0 * np.correlate(w, a, mode='valid')
    
    # Gradient w.r.t. x (chain rule through softmax)
    # ∂a_j/∂x_i = a_j * (δ_{ij} - a_j/S)
    # ∂F/∂x_i = sum_j grad_a[j] * a_j * (δ_{ij} - a_j/S)
    #          = a_i * grad_a[i] - a_i/S * sum_j a_j * grad_a[j]
    S = target_sum
    ax = a * grad_a  # element-wise
    grad_x = a * grad_a - a * np.sum(ax) / S
    
    # The objective we minimize is log_sum_exp (which approximates log(max(c)))
    # Actually, for the true objective, we want 2n*max(c)/S^2 = max(c) when S=sqrt(2n)
    # But log_sum_exp ≈ log(max(c)) for small tau, so minimizing log_sum_exp ≈ minimizing max(c)
    # (since log is monotone)
    
    return log_sum_exp, grad_x
