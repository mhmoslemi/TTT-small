This connects to the theory of "low autocorrelation sequences" (LACS) and "frequency-hopping sequences" (FHS). In the continuous setting, we want a function whose autocorrelation is as flat as possible.

One approach: **Iterative "water-filling" on the spectrum**. 
1. Compute the FFT of `a`
2. Flatten the magnitude of the spectrum (keeping the phase)
3. Inverse FFT
4. Project back to non-negative, sum=1
5. Repeat

This is similar to the Gerchberg-Saxton algorithm used in phase retrieval. Let me explore this!

```python
def spectral_flattening(a, time_limit, target_flatness=None):
    """Iteratively flatten the power spectrum to reduce auto-correlation peaks."""
    n = len(a)
    a = a / a.sum()

    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    
    t0 = time.monotonic()

        A = np.fft.rfft(a, fft_size)
        mag = np.abs(A)
        phase = np.angle(A)
        
        # Flatten the magnitude: replace with a smoother version
        # Option 1: Use a target spectrum (e.g., constant)
        # Option 2: Blend current magnitude with a flat one
        target_mag = np.ones_like(mag) * mag.mean()
        # Blend
        new_mag = 0.9 * mag + 0.1 * target_mag
        # Or use a power compression
        new_mag = mag ** 0.9  # Compress dynamic range
        
        A_new = new_mag * np.exp(1j * phase)
        a_new = np.fft.irfft(A_new, fft_size)[:n]
        
        # Project to simplex
        a_new = np.maximum(a_new, 0)
        s = a_new.sum()
        if s < 1e-15:
            break
        a_new = a_new / s
        
        obj = fast_convolve(a_new).max()
        if obj < best_obj:
            best_obj = obj
            best_a = a_new.copy()
        else:
            # Revert and try different flattening
            pass
        a = a_new
    
    return best_a, best_obj
```

1. The phase information is crucial for the time-domain signal to be non-negative
2. Flattening the spectrum tends to make the time-domain signal oscillatory (negative values)
3. The projection back to simplex destroys the spectral information

Let me think of a better spectral approach...

Actually, the connection is:
- `conv(a,a)` linear convolution → its DFT is `|A(f)|^2` (for circular convolution with appropriate zero-padding)
- We want `conv(a,a)` to be flat → we want `|A(f)|^2` to be flat → we want `|A(f)|` to be constant

But `a` must be non-negative and sum to 1. This is a constraint that's hard to express in the frequency domain.

The Gerchberg-Saxton / error reduction approach would be:
1. In time domain: enforce non-negativity and sum=1 (project to simplex)
2. In frequency domain: enforce flat magnitude
3. Alternate

This is exactly the magnitudes-to-signal problem in phase retrieval with an additional non-negativity constraint. It might work!

Let me also think about **another angle**: the problem is equivalent to finding a probability distribution on {0,...,n-1} that minimizes the maximum of the "convolution" (which is the distribution of the sum of two independent random variables with that distribution).

So we want: `max_k P(X+Y=k)` to be minimized, where X and Y are i.i.d. with distribution `a`.

This is the "anti-concentration" problem! We want the sum of two i.i.d. discrete random variables to be as spread out as possible.

Known results:
- For uniform distribution on {0,...,n-1}, the sum has a triangular distribution with max at the center: `P(X+Y = (n-1)) ≈ 1/n` (more precisely, the triangular distribution has peak `n/(2n-1)^2 * 2`... let me compute).

For uniform `a[i] = 1/n`:
`conv(a,a)[k] = (k+1)/n^2` for `0 <= k <= n-1`
`conv(a,a)[k] = (2n-1-k)/n^2` for `n <= k <= 2n-2`
Max is at `k = n-1`: `n/n^2 = 1/n`

So objective = `2*n*(1/n) = 2`. That's our baseline.

We want to get below 2. The target is 1.5027, which means `max(conv) ≈ 1.5027/(2*368) ≈ 0.00204`.

For a "flat" convolution, the average value is `sum(k) conv[k] = sum(a)^2 = 1` over `2n-1` values, so the average is `1/(2n-1)`. The max must be at least the average, so `max(conv) >= 1/(2n-1)`, giving objective >= `2n/(2n-1) ≈ 1`. So the theoretical lower bound is 1, and we're at 1.5057, which is above the bound.

The question is: how much can we improve?

Let me think about what kind of distributions give flat sums. If `a` is uniform on a "well-distributed" subset, the sum distribution might be flatter.

Actually, there's a beautiful connection to **Benford's law** and **log-uniform distributions**. If `a[i]` is log-uniform (i.e., `a[i] ∝ 1/(i+1)`), the sum distribution might be flatter than triangular.

Let me also think about **Fourier analysis** of the problem. The auto-convolution being flat means the Fourier transform has flat magnitude. By the uncertainty principle, a signal can't have both flat time-domain and flat frequency-domain. But we have the constraint that the signal is non-negative, which is a strong constraint.

```python
"""
Multi-strategy optimizer combining:
1. Softmax-parameterized Adam with log-sum-exp smoothing (fast global optimization)
2. Active-set subgradient with line search (fast local refinement)
3. Spectral error-reduction (episodic global moves)
4. Multi-length exploration

import numpy as np
import time

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def softmax(theta):
    theta = theta - theta.max()
    e = np.exp(theta)
    return e / e.sum()

def compute_smoothed_grad(a, conv, T):
    """Compute gradient of T*log(sum(exp(conv/T))) w.r.t. a using FFT."""
    n = len(a)
    scaled = conv / T
    scaled -= scaled.max()
    w = np.exp(scaled)
    ws = w.sum()
    if ws < 1e-300:
        p = np.zeros(len(conv))
        p[np.argmax(conv)] = 1.0
    else:
        p = w / ws
    fft_size = 1 << (3 * n).bit_length()
    A = np.fft.rfft(a, fft_size)
    P = np.fft.rfft(p, fft_size)
    cross = np.fft.irfft(np.conj(A) * P, fft_size)
    return 2.0 * cross[:n], p

def softmax_adam(f0, time_limit, T_init=0.003, lr_init=0.005, verbose=False):
    """
    Adam optimizer on softmax parameterization with log-sum-exp smoothed max.
    """
    n = len(f0)
    a_init = np.maximum(f0, 1e-30)
    a_init = a_init / a_init.sum()
    theta = np.log(a_init).copy()
    
    m = np.zeros(n)
    v = np.zeros(n)
    beta1, beta2, eps = 0.85, 0.999, 1e-8
    t = 0
    lr = lr_init
    
    best_a = a_init.copy()
    best_obj = fast_convolve(a_init).max()
    
    T = T_init
    t0 = time.monotonic()
    no_improve = 0
    lr_schedule = [0.005, 0.003, 0.001, 0.0005, 0.0002]
    stage = 0
    
    while time.monotonic() - t0 < time_limit:
        t += 1
        a = softmax(theta)
        conv = fast_convolve(a)
        grad_a, p = compute_smoothed_grad(a, conv, T)
        
        # Gradient w.r.t. theta
        mean_grad = np.dot(grad_a, a)
        grad_theta = a * (grad_a - mean_grad)
        
        # Adam update
        m = beta1 * m + (1 - beta1) * grad_theta
        v = beta2 * v + (1 - beta2) * (grad_theta ** 2)
        m_hat = m / (1 - beta1 ** t)
        v_hat = v / (1 - beta2 ** t)
        theta -= lr * m_hat / (np.sqrt(v_hat) + eps)
        
        # Check improvement
        a_new = softmax(theta)
        conv_new = fast_convolve(a_new)
        obj_new = conv_new.max()
        
        if obj_new < best_obj - 1e-13:
            best_obj = obj_new
            best_a = a_new.copy()
            no_improve = 0
            if verbose and t % 5000 == 0:
                print(f"    SoftmaxAdam t={t}: obj={best_obj:.10f}, T={T:.6f}")
        else:
            no_improve += 1
        
        # Schedule
        if t % 200 == 0:
            T = max(T * 0.998, 0.0003)
        
        if no_improve > 1000:
            # Restart from best with perturbation
            theta = np.log(np.maximum(best_a, 1e-30)) + np.random.default_rng(t).standard_normal(n) * 0.01
            m = np.zeros(n)
            v = np.zeros(n)
            t = 0
            no_improve = 0
            stage = min(stage + 1, len(lr_schedule) - 1)
            lr = lr_schedule[stage]
            T = max(T * 2, 0.001)
        
        if no_improve > 5000:
            break
    
    return best_a, best_obj

def active_set_polish(f0, time_limit, top_k=3, verbose=False):
    """
    Focused subgradient on top-k peaks with backtracking line search.
    """
    n = len(f0)
    a = np.maximum(f0, 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    
    t0 = time.monotonic()
    it = 0
    no_improve = 0
    lr = 0.002
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        conv = fast_convolve(a)
        
        # Get top-k peaks
        peak_idx = np.argpartition(conv, -top_k)[-top_k:]
        peak_vals = conv[peak_idx]
        # Soft weights
        scaled = peak_vals / 0.00002
        scaled -= scaled.max()
        w = np.exp(scaled)
        w /= w.sum()
        
        # Subgradient: sum of weighted peak gradients
        sg = np.zeros(n)
        for i in range(top_k):
            if w[i] < 1e-6:
                continue
            k = peak_idx[i]
            # grad[m] = 2 * a[k-m] for valid m
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            sg[idx] += 2.0 * w[i] * a[k - idx]
        
        # Project onto tangent space of simplex
        sg = sg - np.mean(sg * a)  # Hmm, not quite right
        
        # Better: project gradient onto tangent space
        sg_tangent = sg - a * np.dot(sg, a)  # This projects onto the tangent space of the log-barrier
        
        # Actually, for simplex projection, we just subtract the mean
        sg = sg - np.mean(sg)
        
        # Backtracking line search
        alpha = lr
        improved = False
        for _ in range(20):
            a_try = project_simplex(a - alpha * sg)
            conv_try = fast_convolve(a_try)
            obj_try = conv_try.max()
            if obj_try < best_obj - 1e-14:
                a = a_try
                best_obj = obj_try
                best_a = a_try.copy()
                no_improve = 0
                improved = True
                break
            alpha *= 0.7
        
        if not improved:
            no_improve += 1
            lr = max(lr * 0.95, 0.0001)
            if no_improve > 200:
                # Perturb
                rng = np.random.default_rng(it)
                a = project_simplex(best_a + rng.standard_normal(n) * 0.001)
                lr = 0.001
                no_improve = 0
        
        if verbose and it % 500 == 0:
            print(f"    ActiveSet it={it}: obj={best_obj:.10f}")
    
    return best_a, best_obj

def spectral_error_reduction(f0, time_limit, n_iter_per_check=10, verbose=False):
    """
    Gerchberg-Saxton style: alternate between time-domain (simplex projection)
    and frequency-domain (magnitude flattening) steps.
    """
    n = len(f0)
    a = np.maximum(f0, 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    
    fft_size = 1 << (2 * n).bit_length()
    t0 = time.monotonic()
    it = 0
    blend = 0.3  # How much to flatten per step
    
    while time.monotonic() - t0 < time_limit:
        # Get current spectrum
        A = np.fft.rfft(a, fft_size)
        mag = np.abs(A)
        phase = np.angle(A)
        
        # Target: flat magnitude (but keep DC component)
        mag_smooth = mag.copy()
        # Blend towards flat
        target_mag = np.full_like(mag, mag[1:].mean())  # Exclude DC
        target_mag[0] = mag[0]  # Keep DC (ensures sum is preserved)
        new_mag = (1 - blend) * mag + blend * target_mag
        
        # Reconstruct
        A_new = new_mag * np.exp(1j * phase)
        a_new = np.fft.irfft(A_new, fft_size)[:n]
        
        # Project to simplex
        a_new = np.maximum(a_new, 0)
        s_new = a_new.sum()
        if s_new < 1e-15:
            blend *= 0.5
            continue
        a_new = a_new / s_new
        
        it += 1
        conv = fast_convolve(a_new)
        obj = conv.max()
        
        if obj < best_obj - 1e-13:
            best_obj = obj
            best_a = a_new.copy()
            a = a_new
        else:
            # Try reducing blend
            if it % 50 == 0:
                blend = max(blend * 0.8, 0.05)
        
        if verbose and it % 1000 == 0:
            print(f"    Spectral it={it}: obj={best_obj:.10f}, blend={blend:.3f}")
    
    return best_a, best_obj
```

```python
"""
Multi-strategy optimizer combining:
1. Softmax-parameterized Adam with log-sum-exp smoothing (fast global optimization)
2. Active-set subgradient with line search (fast local refinement)
3. Spectral error-reduction (episodic global moves via Gerchberg-Saxton)
4. Multi-length exploration and adaptive T-scheduling

Key insight: By using softmax parameterization, we avoid costly simplex projections
and use Adam's adaptive per-coordinate step sizes for faster convergence.
The log-sum-exp smoothing of the max function provides a smooth objective that
becomes exact as T -> 0, giving a continuation method.
"""

import numpy as np
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex {x>=0, sum(x)=1}."""
    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def softmax_fn(theta):
    """Numerically stable softmax."""
    theta = theta - theta.max()
    e = np.exp(theta)
    return e / e.sum()


def compute_smoothed_grad(a, conv, T):
    """Compute gradient of T*log(sum(exp(conv/T))) w.r.t. a using FFT."""
    n = len(a)
    scaled = conv / T
    scaled -= scaled.max()
    w = np.exp(scaled)
    ws = w.sum()
    if ws < 1e-300:
        p = np.zeros(len(conv))
        p[np.argmax(conv)] = 1.0
    else:
        p = w / ws
    fft_size = 1 << (3 * n).bit_length()
    A = np.fft.rfft(a, fft_size)
    P = np.fft.rfft(p, fft_size)
    cross = np.fft.irfft(np.conj(A) * P, fft_size)
    return 2.0 * cross[:n], p


def softmax_adam_optimize(f0, time_limit, T_init=0.004, lr_init=0.004, verbose=False):
    """
    Adam optimizer on softmax parameterization with log-sum-exp smoothed max.
    Fast per-iteration (O(n log n)), no projection needed.
    """
    n = len(f0)
    a_init = np.maximum(f0, 1e-30)
    a_init = a_init / a_init.sum()
    theta = np.log(a_init).copy()

    m = np.zeros(n)
    v = np.zeros(n)
    beta1, beta2, eps_adam = 0.85, 0.999, 1e-8
    t = 0
    lr = lr_init

    best_a = a_init.copy()
    best_obj = fast_convolve(a_init).max()

    T = T_init
    t0 = time.monotonic()
    no_improve = 0

    lr_schedule = [lr_init, lr_init * 0.6, lr_init * 0.35, lr_init * 0.2, lr_init * 0.1]
    stage = 0

    while time.monotonic() - t0 < time_limit:
        t += 1
        a = softmax_fn(theta)
        conv = fast_convolve(a)
        grad_a, p = compute_smoothed_grad(a, conv, T)

        # Gradient w.r.t. theta via chain rule
        mean_grad = np.dot(grad_a, a)
        grad_theta = a * (grad_a - mean_grad)

        # Adam update
        m = beta1 * m + (1.0 - beta1) * grad_theta
        v = beta2 * v + (1.0 - beta2) * (grad_theta ** 2)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)
        theta -= lr * m_hat / (np.sqrt(v_hat) + eps_adam)

        # Check improvement
        a_new = softmax_fn(theta)
        conv_new = fast_convolve(a_new)
        obj_new = conv_new.max()

        if obj_new < best_obj - 1e-13:
            best_obj = obj_new
            best_a = a_new.copy()
            no_improve = 0
            if verbose and t % 10000 == 0:
                print(f"    SoftmaxAdam t={t}: obj={best_obj:.10f}, T={T:.6f}")
        else:
            no_improve += 1

        # Anneal T slowly
        if t % 500 == 0:
            T = max(T * 0.997, 0.0002)

        # Adaptive restart
        if no_improve > 2000:
            stage = min(stage + 1, len(lr_schedule) - 1)
            lr = lr_schedule[stage]
            # Perturb from best
            rng = np.random.default_rng(t * 31 + 7)
            theta = np.log(np.maximum(best_a, 1e-30))
            theta += rng.standard_normal(n) * 0.005 * (stage + 1)
            m = np.zeros(n)
            v = np.zeros(n)
            t = 0
            no_improve = 0
            T = max(T * 3.0, 0.001)

        if no_improve > 15000:
            break

    return best_a, best_obj


def active_set_optimize(f0, time_limit, top_k=3, verbose=False):
    """
    Focused subgradient on top-k peaks with backtracking line search.
    Very effective for final polishing.
    """
    n = len(f0)
    a = np.maximum(f0, 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    best_a = a.copy()
    best_obj = fast_convolve(a).max()

    t0 = time.monotonic()
    it = 0
    no_improve = 0
    lr = 0.003
    min_lr = 0.00005

    while time.monotonic() - t0 < time_limit:
        it += 1
        conv = fast_convolve(a)

        # Get top-k peaks with soft weighting
        if top_k >= len(conv):
            peak_idx = np.arange(len(conv))
        else:
            peak_idx = np.argpartition(conv, -top_k)[-top_k:]
        peak_vals = conv[peak_idx]

        # Soft weights over peaks
        temp = max(0.00001, (peak_vals[-1] - peak_vals[0]) * 0.5) if len(peak_vals) > 1 else 0.00001
        scaled = peak_vals / temp
        scaled -= scaled.max()
        w = np.exp(scaled)
        w /= w.sum()

        # Compute subgradient
        sg = np.zeros(n)
        for i in range(len(peak_idx)):
            if w[i] < 1e-8:
                continue
            k = int(peak_idx[i])
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            if js > je:
                continue
            idx = np.arange(js, je + 1)
            sg[idx] += 2.0 * w[i] * a[k - idx]

        # Project onto tangent space of simplex (subtract mean)
        sg = sg - np.mean(sg)

        # Backtracking line search
        alpha = lr
        improved = False
        for _ in range(25):
            a_try = project_simplex(a - alpha * sg)
            conv_try = fast_convolve(a_try)
            obj_try = conv_try.max()
            if obj_try < best_obj - 1e-14:
                a = a_try
                best_obj = obj_try
                best_a = a_try.copy()
                no_improve = 0
                improved = True
                break
            alpha *= 0.7

        if not improved:
            no_improve += 1
            lr = max(lr * 0.97, min_lr)
            if no_improve > 300:
                # Perturb and reset
                rng = np.random.default_rng(it * 17 + 3)
                a = project_simplex(best_a + rng.standard_normal(n) * 0.0008)
                lr = max(lr * 2.0, 0.001)
                no_improve = 0

        if verbose and it % 200 == 0:
            print(f"    ActiveSet it={it}: obj={best_obj:.10f}, lr={lr:.6f}")

    return best_a, best_obj


def spectral_error_reduction(f0, time_limit, blend=0.15, verbose=False):
    """
    Gerchberg-Saxton style: alternate between time-domain (simplex projection)
    and frequency-domain (magnitude flattening) steps.
    Provides large-scale "kicks" out of local minima.
    """
    n = len(f0)
    a = np.maximum(f0, 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    best_a = a.copy()
    best_obj = fast_convolve(a).max()

    fft_size = 1 << (2 * n).bit_length()
    t0 = time.monotonic()
    it = 0
    current_blend = blend

    while time.monotonic() - t0 < time_limit:
        # Get current spectrum
        A = np.fft.rfft(a, fft_size)
        mag = np.abs(A)
        phase = np.angle(A)

        # Target: flatten magnitude (keep DC for sum preservation)
        target_mag = np.full_like(mag, mag[1:].mean())
        target_mag[0] = mag[0]

        # Blend towards flat
        new_mag = (1.0 - current_blend) * mag + current_blend * target_mag

        # Reconstruct
        A_new = new_mag * np.exp(1j * phase)
        a_new = np.fft.irfft(A_new, fft_size)[:n]

        # Project to simplex
        a_new = np.maximum(a_new, 0.0)
        s_new = a_new.sum()
        if s_new < 1e-15:
            current_blend = max(current_blend * 0.5, 0.01)
            continue
        a_new = a_new / s_new

        it += 1
        conv = fast_convolve(a_new)
        obj = conv.max()

        if obj < best_obj - 1e-12:
            best_obj = obj
            best_a = a_new.copy()
            a = a_new
        else:
            if it % 100 == 0:
                current_blend = max(current_blend * 0.85, 0.02)
            if it % 500 == 0:
                # Random phase perturbation to escape
                rng = np.random.default_rng(it)
                phase += rng.standard_normal(len(phase)) * 0.01
                A_new = new_mag * np.exp(1j * phase)
                a_new = np.fft.irfft(A_new, fft_size)[:n]
                a_new = np.maximum(a_new, 0.0)
                s_new = a_new.sum()
                if s_new > 1e-10:
                    a = a_new / s_new

        if verbose and it % 2000 == 0:
            print(f"    Spectral it={it}: obj={best_obj:.10f}, blend={current_blend:.4f}")

    return best_a, best_obj


def projected_adam_optimize(f0, time_limit, T_init=0.003, lr_init=0.008, verbose=False):
    """
    Projected gradient with Adam on the simplex.
    Combines the simplicity of projection with Adam's adaptive rates.
    """
    n = len(f0)
    a = np.maximum(f0, 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s

    m = np.zeros(n)
    v = np.zeros(n)
    beta1, beta2, eps_adam = 0.85, 0.999, 1e-8
    t = 0
    lr = lr_init

    best_a = a.copy()
    best_obj = fast_convolve(a).max()

    T = T_init
    t0 = time.monotonic()
    no_improve = 0

    while time.monotonic() - t0 < time_limit:
        t += 1
        conv = fast_convolve(a)
        grad_a, p = compute_smoothed_grad(a, conv, T)

        # Project gradient onto tangent space
        grad_proj = grad_a - np.mean(grad_a)

        # Adam
        m = beta1 * m + (1.0 - beta1) * grad_proj
        v = beta2 * v + (1.0 - beta2) * (grad_proj ** 2)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)
        step = lr * m_hat / (np.sqrt(v_hat) + eps_adam)

        a_new = project_simplex(a - step)

        conv_new = fast_convolve(a_new)
        obj_new = conv_new.max()

        if obj_new < best_obj - 1e-13:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new
            no_improve = 0
            if verbose and t % 10000 == 0:
                print(f"    ProjAdam t={t}: obj={best_obj:.10f}, T={T:.6f}")
        else:
            no_improve += 1

        if t % 300 == 0:
            T = max(T * 0.995, 0.0003)

        if no_improve > 1500:
            rng = np.random.default_rng(t * 13 + 5)
            a = project_simplex(best_a + rng.standard_normal(n) * 0.003)
            m = np.zeros(n)
            v = np.zeros(n)
            t = 0
            no_improve = 0
            lr = max(lr * 0.7, 0.0005)
            T = max(T * 2.0, 0.001)

        if no_improve > 10000:
            break

    return best_a, best_obj

            _try_cv(a_opt, "parent_pa")

    # Try different lengths
    for delta in [8, -8, 16, -16, 4, -4, 32, -32, 64]:
        new_n = base_n + delta
        if new_n < 192 or new_n > 640:
            continue
        rem = p1_budget - (time.monotonic() - t_p1)
        if rem < 30:
            break

        # Resample parent to new length
        if parent is not None:
            x_old = np.linspace(0, 1, len(parent))
            x_new = np.linspace(0, 1, new_n)
            a_init = np.interp(x_new, x_old, parent)
            a_init = np.maximum(a_init, 0)
            a_init = project_simplex(a_init)
        else:
            a_init = np.ones(new_n) / new_n

        t_alloc = min(30.0, rem - 15)
        if t_alloc < 10:
            break
        print(f"  SoftmaxAdam n={new_n}, t={t_alloc:.0f}s")
        a_opt, _ = softmax_adam_optimize(a_init, time_limit=t_alloc, T_init=0.004, lr_init=0.003)
        _try_cv(a_opt, f"n{new_n}")

    print(f"  Phase 1 best: {best_score:.6f}")

    # === Phase 2: Active-Set Polish (500s) ===
    print(f"\n=== Phase 2: Active-Set Polish ===")
    t_p2 = time.monotonic()
    p2_budget = 500.0

    if best_seq is not None:
        f_work = best_seq / best_seq.sum()

        # Progressive tightening of top_k
        active_configs = [
            (5, 100),
            (3, 100),
            (2, 100),
            (1, 80),
            (2, 60),
            (1, 60),
        ]

        for i, (tk, tt) in enumerate(active_configs):
            rem = p2_budget - (time.monotonic() - t_p2)
            if rem < 25:
                break
            t_alloc = min(tt, rem - 10)
            print(f"  ActiveSet k={tk}, t={t_alloc:.0f}s")
            a_opt, _ = active_set_optimize(f_work, time_limit=t_alloc, top_k=tk)
            _try_cv(a_opt, f"as_k{tk}_{i}")
            if best_seq is not None:
                f_work = best_seq / best_seq.sum()

    print(f"  Phase 2 best: {best_score:.6f}")

    # === Phase 3: Spectral + Adam Interleaving (400s) ===
    print(f"\n=== Phase 3: Spectral + Adam ===")
    t_p3 = time.monotonic()
    p3_budget = 400.0

    if best_seq is not None:
        f_work = best_seq / best_seq.sum()

        n_cycles = 5
        for cycle in range(n_cycles):
            rem = p3_budget - (time.monotonic() - t_p3)
            if rem < 30:
                break

            t_each = min(50.0, rem / 3.0)

            # Spectral kick
            print(f"  Cycle {cycle}: Spectral t={t_each:.0f}s")
            a_opt, _ = spectral_error_reduction(f_work, time_limit=t_each, blend=0.12)
            _try_cv(a_opt, f"spec_{cycle}")
            if best_seq is not None:
                f_work = best_seq / best_seq.sum()

            # Adam refinement
            rem = p3_budget - (time.monotonic() - t_p3)
            if rem > 25:
                t_each2 = min(50.0, rem / 3.0)
                print(f"  Cycle {cycle}: ProjAdam t={t_each2:.0f}s")
                a_opt, _ = projected_adam_optimize(f_work, time_limit=t_each2,
                                                   T_init=0.002, lr_init=0.004)
                _try_cv(a_opt, f"pa_{cycle}")
                if best_seq is not None:
                    f_work = best_seq / best_seq.sum()

            # Quick active-set
            rem = p3_budget - (time.monotonic() - t_p3)
            if rem > 20:
                t_each3 = min(30.0, rem / 3.0)
                a_opt, _ = active_set_optimize(f_work, time_limit=t_each3, top_k=2)
                _try_cv(a_opt, f"as3_{cycle}")
                if best_seq is not None:
                    f_work = best_seq / best_seq.sum()

    print(f"  Phase 3 best: {best_score:.6f}")

    # === Phase 4: Final Refinement (350s) ===
    print(f"\n=== Phase 4: Final Refinement ===")
    t_p4 = time.monotonic()
    p4_budget = 350.0

    if best_seq is not None:
        f_work = best_seq / best_seq.sum()
        n_best = len(f_work)

        # Alternating active-set with very small steps
        for i in range(6):
            rem = p4_budget - (time.monotonic() - t_p4)
            if rem < 30:
                break
            tk = 1 if i >= 3 else 2
            t_alloc = min(50.0, rem / 3.0)
            print(f"  Final AS k={tk}, t={t_alloc:.0f}s")
            a_opt, _ = active_set_optimize(f_work, time_limit=t_alloc, top_k=tk)
            _try_cv(a_opt, f"fin_as_{i}")
            if best_seq is not None:
                f_work = best_seq / best_seq.sum()

            # Occasional spectral micro-kick
            rem = p4_budget - (time.monotonic() - t_p4)
            if rem > 25 and i % 2 == 1:
                t_kick = min(20.0, rem / 3.0)
                a_opt, _ = spectral_error_reduction(f_work, time_limit=t_kick, blend=0.05)
                _try_cv(a_opt, f"fin_spec_{i}")
                if best_seq is not None:
                    f_work = best_seq / best_seq.sum()

        # Very slow softmax for final polish
        rem = p4_budget - (time.monotonic() - t_p4)
        if rem > 40:
            t_alloc = min(80.0, rem - 10)
            print(f"  Final SoftmaxAdam t={t_alloc:.0f}s")
            a_opt, _ = softmax_adam_optimize(f_work, time_limit=t_alloc,
                                             T_init=0.001, lr_init=0.001)
            _try_cv(a_opt, "fin_sma")
            if best_seq is not None:
                f_work = best_seq / best_seq.sum()

    print(f"  Phase 4 best: {best_score:.6f}")

    # === Phase 5: Final Tricks (remaining time) ===
    print(f"\n=== Phase 5: Final Tricks ===")

    if best_seq is not None:
        f_work = best_seq / best_seq.sum()
        n_best = len(f_work)

        # Tiny perturbations + polish
        n_perturb = 5
        while time.monotonic() < deadline - 20:
            for i in range(n_perturb):
                if time.monotonic() > deadline - 15:
                    break
                scale = 0.0002 + 0.0001 * i
                noise = rng.standard_normal(n_best) * scale
                f_pert = project_simplex(f_work + noise)
                t_alloc = min(25.0, deadline - 15 - time.monotonic())
                if t_alloc < 5:
                    break
                a_opt, _ = active_set_optimize(f_pert, time_limit=t_alloc, top_k=1)
                _try_cv(a_opt, f"pert_{i}")
                if best_seq is not None:
                    f_work = best_seq / best_seq.sum()

        # Try one more length near the best
        rem = deadline - 15 - time.monotonic()
        if rem > 30:
            for delta in [2, -2, 1, -1, 4, -4]:
                new_n = n_best + delta
                if new_n < 200 or new_n > 500:
                    continue
                if time.monotonic() > deadline - 10:
                    break
                x_old = np.linspace(0, 1, n_best)
                x_new = np.linspace(0, 1, new_n)
                a_init = np.interp(x_new, x_old, f_work)
                a_init = project_simplex(np.maximum(a_init, 0))
                t_alloc = min(20.0, deadline - 10 - time.monotonic())
                if t_alloc < 5:
                    break
                a_opt, _ = active_set_optimize(a_init, time_limit=t_alloc, top_k=1)
                _try_cv(a_opt, f"newlen_{new_n}")

    # Fallback
    if best_seq is None:
        best_seq = np.ones(368) / 368
        best_score = float(evaluate_sequence(best_seq.tolist()))
        print(f"  Using fallback: {best_score:.6f}")

    # Final verification
    fs = float(evaluate_sequence(best_seq.tolist()))
    if np.isfinite(fs):
        best_score = fs
    else:
        best_seq = np.ones(368) / 368
        best_score = float(evaluate_sequence(best_seq.tolist()))

    print(f"\nFINAL SCORE: {best_score:.6f} (n={len(best_seq)})")
    print(f"Elapsed: {time.monotonic() - (deadline - budget_s + 10):.1f}s")
    return [float(x) for x in best_seq]
```
