For coordinate descent: fix all variables except `a[i]`. The objective is `max_k (C_k + a[i]*D_k)` where:
- `C_k` = convolution value at lag k with `a[i]` set to 0
- `D_k` = the coefficient of `a[i]` in `conv(a,a)[k]`

`D_k = a[k-i] + a[k-i] = 2*a[k-i]` (for valid k-i, and counting both terms)
Actually: `conv(a,a)[k] = sum_j a[j]*a[k-j]`. The terms involving `a[i]` are:
- j=i: `a[i]*a[k-i]`
- j=k-i: `a[k-i]*a[i]` (same as above if i=k-i)

So `conv(a,a)[k] = C_k + a[i]*(a[k-i] + a[k-i]) = C_k + 2*a[i]*a[k-i]` (when i ≠ k-i)
Or `conv(a,a)[k] = C_k + a[i]^2` (when i = k-i, i.e., k = 2i)

So the objective as a function of `a[i] = x` is:
`max_k (C_k + 2x*a[k-i])` for k ≠ 2i
`max_k (C_k + x^2)` for k = 2i

This is the max of linear functions (and one quadratic). The minimum of this maximum subject to `x >= 0` and `x = 1 - sum_{j≠i} a[j]` (sum constraint) can be found.

Wait, if we fix all other variables, then `sum(a) = sum_{j≠i} a[j] + x = 1`, so `x = 1 - sum_{j≠i} a[j]` is fixed! We can't freely choose x.

So coordinate descent doesn't work directly with the sum constraint. We'd need to either:
a. Drop the sum constraint and use a penalty
b. Use a different parameterization (e.g., optimize in the projective space)
c. Update two coordinates at a time (move mass from one to another)

Option (c) is the most natural: choose coordinates i and j, and redistribute mass between them. Fix `a[i] + a[j] = c` (constant), and find the optimal split.

For a fixed pair (i,j) with `a[i] + a[j] = c`, let `a[i] = x, a[j] = c-x`. The change in the convolution at lag k is:
`delta_k = (2x*a[k-i] - 2a[i]*a[k-i]) + (2(c-x)*a[k-j] - 2a[j]*a[k-j])`

Actually, for the "two-coordinate" update, the change in `conv(a,a)[k]` when we change `a[i]` to `a[i]+d` and `a[j]` to `a[j]-d` (preserving sum) is:
`delta_k = 2d*(a[k-i] - a[k-j])` (for the cross terms)
Plus the self-terms: `2id` if k=2i, `-2jd` if k=2j.

So `delta_k ≈ 2d*(a[k-i] - a[k-j])` for most k.

We want to choose d to minimize `max_k (b[k] + delta_k)`. This is a 1D optimization problem that can be solved by bisection or by finding the intersection points.

This is essentially a "steepest descent" direction in the (i,j) coordinate pair.

"""
Optimized step function search using mirror descent with soft-max objective,
combined with projected gradient descent and coordinate descent for refinement.
Uses FFT-based convolution for efficiency.
"""

import numpy as np
import time


def compute_b(a):
    """Compute the full self-convolution of a."""
    return np.convolve(a, a)


def compute_score(a):
    """Compute the objective: 2*n*max_b/(sum_a)^2. Assumes sum_a=1."""
    n = len(a)
    b = compute_b(a)
    return 2.0 * n * np.max(b)


def project_simplex(v, target=1.0):
    """Project vector v onto {x >= 0, sum(x) = target}."""
    v = np.asarray(v, dtype=np.float64)
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.max(np.nonzero(u * np.arange(1, n + 1) > (cssv - target))[0])
    theta = (cssv[rho] - target) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def soft_max_weights(b, tau):
    """Compute softmax weights for the convolution peaks."""
    b_max = np.max(b)
    exp_b = np.exp(tau * (b - b_max))
    return exp_b / np.sum(exp_b)


def compute_gradient(p, a):
    """
    Compute the gradient of the soft-max objective w.r.t. a.
    grad[i] = 2 * sum_k p[k] * a[k-i]
    """
    n = len(a)
    grad_full = np.convolve(p, a[::-1])
    return 2.0 * grad_full[n-1:2*n-1]


def mirror_descent_step(a, grad, eta, momentum_vec, momentum):
    """Perform a mirror descent step."""
    # Scale gradient for numerical stability
    grad_scale = np.max(np.abs(grad))
    if grad_scale < 1e-15:
        return a, momentum_vec
    log_ratio = -eta * grad / grad_scale
    log_ratio = np.clip(log_ratio, -10, 10)
    momentum_vec = momentum * momentum_vec + (1 - momentum) * log_ratio
    a_new = a * np.exp(momentum_vec)
    a_new = np.maximum(a_new, 1e-15)
    a_new = a_new / np.sum(a_new)
    return a_new, momentum_vec


def subgradient_step(a, grad, eta):
    """Perform a projected subgradient step."""
    a_new = a - eta * grad
    a_new = project_simplex(a_new, 1.0)
    return a_new


def make_ramp(n, direction=1):
    """Create a linear ramp sequence, normalized to sum 1."""
    if direction == 1:
        a = np.linspace(1, 2, n)
    else:
        a = np.linspace(2, 1, n)
    a = a / np.sum(a)
    return a


def make_two_level(n, t):
    """Two-level anti-symmetric sequence."""
    a = np.ones(n)
    a[:n//2] = 1 + t
    a[n//2:] = 1 - t
    a = np.maximum(a, 0)
    a = a / np.sum(a)
    return a


def make_smooth_ramp(n, sharpness=2.0):
    """Smooth ramp using a sigmoid-like function."""
    x = np.arange(n, dtype=np.float64) / (n - 1)
    a = 1.0 + sharpness * (2.0 * x - 1.0)
    a = np.maximum(a, 0.01)
    a = a / np.sum(a)
    return a


def make_quadratic_ramp(n, coeff=1.0):
    """Quadratic ramp: a[i] = 1 + coeff*(2i/(n-1) - 1)^2"""
    x = np.arange(n, dtype=np.float64) / (n - 1)
    a = 1.0 + coeff * (2*x - 1)
    a = np.maximum(a, 0.01)
    a = a / np.sum(a)
    return a
