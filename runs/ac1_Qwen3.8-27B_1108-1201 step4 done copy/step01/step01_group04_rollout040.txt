  So:
  - Q[m] = c[m] - (contribution from a_i at the current value)
  - P[m] = coefficient of a_i (linear term)
  - F[m] = coefficient of a_i^2 (quadratic term)
  
  For m = 2i: contribution = a_i^2, so Q[2i] = c[2i] - a_i^2, P[2i] = 0, F[2i] = 1
  For m ≠ 2i and 0 <= m-i < n: contribution = 2 * a_i * a[m-i], so Q[m] = c[m] - 2*a_i*a[m-i], P[m] = 2*a[m-i], F[m] = 0
  Otherwise: Q[m] = c[m], P[m] = 0, F[m] = 0

minimize 2n * max_m (Q[m] + P[m]*a_i + F[m]*a_i^2) / (S + a_i)^2
subject to a_i >= 0

where S = sum of all a_j (j ≠ i).

If m ≠ 2i and 0 <= m-i < n: Δc[m] = 2*Δ*a[m-i]
Otherwise: Δc[m] = 0

This is much faster to update! I can maintain the convolution array and update it in O(n) per coordinate change (only the entries where m-i is in [0, n-1] change, which is n entries).

def _coord_update_incr(a, c, i):
    """Optimize coordinate i, updating convolution c in-place. Returns new a[i]."""
    n = len(a)
    S = float(a.sum()) - a[i]
    if S < 1e-12:
        return a[i], c
    
    old = a[i]
    
    # P[m] = 2*a[m-i] if 0 <= m-i < n, else 0 (for m != 2i)
    # For m = 2i: the quadratic term is handled separately
    m_idx = np.arange(2*n-1)
    offset = m_idx - i
    valid = (offset >= 0) & (offset < n)
    
    P = np.zeros(2*n-1)
    P[valid] = 2.0 * a[offset[valid].astype(int)]
    P[2*i] = 0.0  # handled by quadratic
    
    # Q[m] = c[m] - old * P[m] - (old^2 if m==2i else 0)
    Q = c - old * P
    Q[2*i] -= old*old
    
    # Find best t
    candidates = np.array([0.0, old])
    if Q[2*i] > 0 and S > 0:
        candidates = np.append(candidates, Q[2*i] / S)
    
    pos_P = P > 1e-15
    if np.any(pos_P):
        t_lines = S - 2.0 * Q[pos_P] / P[pos_P]
        t_lines = t_lines[t_lines > 0]
        if len(t_lines) > 0:
            if len(t_lines) > 20:
                dist = np.abs(t_lines - old)
                idx = np.argpartition(dist, 20)[:20]
                t_lines = t_lines[idx]
            candidates = np.append(candidates, t_lines)

        candidates = np.append(candidates, [old*0.5, old*2.0])
    candidates = candidates[candidates >= 0]
    
    best_t = old
    best_val = float('inf')
    for t in candidates:
        vals = Q + P * t
        vals[2*i] = Q[2*i] + t*t
        obj = 2.0 * n * vals.max() / ((S + t)**2)
        if obj < best_val:
            best_val = obj
            best_t = t

Wait, I need to be careful with the c update. Let me re-derive:

c_new[m] = c_old[m] + Δc[m]

For m where 0 <= m-i < n and m ≠ 2i:
Δc[m] = 2 * Δ * a[m-i]

For m = 2i:
Δc[m] = 2*old*Δ + Δ^2

For other m:
Δc[m] = 0

In the code:
- P[valid] = 2*a[m-i] for m in valid set
- c[valid] += delta * P[valid] = c[valid] += 2*delta*a[m-i] ✓
- But wait, valid includes m=2i! So c[2i] gets updated by delta * P[2i] = delta * 0 = 0. Then I separately add 2*old*delta + delta^2. But P[2i] was set to 0, so c[2i] += delta * 0 = 0. Then c[2i] += 2*old*delta + delta^2. That's correct!

Actually wait, I set P[2*i] = 0, but the valid mask includes m=2i (since 0 <= 2i-i = i < n, assuming i < n which it always is). So c[valid] includes c[2i], and P[2i] = 0, so c[2i] += delta * 0 = 0. Then I do c[2i] += 2*old*delta + delta^2. Total change to c[2i] = 2*old*delta + delta^2. ✓

Great, the incremental update is correct.

Now, with this approach, each coordinate update is O(n) (to compute P, Q, and the candidates) + O(n) (to update c) = O(n). A full pass is O(n^2) = 262K for n=512. That's very fast! We can do many thousands of passes.

But wait, I'm still computing P and Q from scratch each time, which involves numpy operations on arrays of size 2n-1. That's fine, it's O(n) with good constants.

Let me also think about whether I need to recompute the sum S each time. I can maintain it incrementally:
- When a[i] changes by delta, S_total changes by delta.
- But S (sum excluding a[i]) doesn't change when I update a[i] (since S excludes a[i]).
- However, when I update a different coordinate j, S (which excludes a[i]) changes by the delta for j.

So I should maintain the total sum and compute S = total_sum - a[i] each time. That's O(1).
