A multiplicative update would be: `a_i <- a_i * exp(-η * sum_k w_k * a[k-i])`.

But we need to be careful: this might drive some `a_i` to zero, which could be good (reducing the support) or bad (losing information).

Let me think about this more carefully and design a complete algorithm.

**Complete Algorithm:**

```
1. Initialize a (anti-symmetric two-level or smooth profile).
2. Normalize: a = a / sum(a).
3. For each iteration until deadline:
   a. Compute b = convolve(a, a).
   b. Find the top M peaks: k_1, ..., k_M with weights w_1, ..., w_M.
   c. Compute gradient: g_i = sum_j w_j * a[k_j - i] (for valid indices).
   d. Normalize gradient: g = g - mean(g) (to preserve sum approximately).
   e. Update: a_i = a_i * exp(-eta * g_i) (or a_i = a_i - eta * g_i for additive).
   f. Project: a = max(a, 0), then a = a / sum(a).
   g. Track best.
4. Return best.
```

Let me also think about **FISTA (Fast Iterative Shrinkage-Thresholding Algorithm)**:

FISTA is an acceleration of proximal gradient that gives O(1/k^2) convergence for convex problems. While our problem is non-convex, FISTA can still be effective in practice.

```
y_0 = x_0, t_0 = 1
For k = 0, 1, 2, ...:
  Compute gradient at y_k: g = grad F(y_k)
  x_{k+1} = prox_{η*g}(y_k - η*g)
  t_{k+1} = (1 + sqrt(1 + 4*t_k^2)) / 2
  y_{k+1} = x_{k+1} + (t_k - 1)/t_{k+1} * (x_{k+1} - x_k)
```

Where `prox` is the projection onto the feasible set `{a >= 0, sum a = S}`.

The gradient of `F(a) = max_k b[k]` at point `a` is a subgradient: `g = sum_{k in active} λ_k * grad b[k]` where `active` is the set of `k` achieving the max.

For FISTA, we can use a "smoothed" version: `F_smooth(a) = (1/M) * sum_{k in top_M} log-sum-exp(β * b[k]) / β` which is a smooth approximation of the max.

import numpy as np
import time

def _softmax_weights(b, M, temperature):
    """Get softmax weights for the top M elements of b."""
    n = len(b)
    if M >= n:
        idx = np.arange(n)
        vals = b
    else:
        idx = np.argpartition(b, -M)[-M:]
        vals = b[idx]
    
    # Softmax with temperature
    max_val = np.max(vals)
    weights = np.exp((vals - max_val) / temperature)
    weights /= np.sum(weights)
    return idx, weights

def _compute_gradient(a, k_idx, weights):
    """Compute weighted sum of gradients of b[k] for k in k_idx."""
    n = len(a)
    grad = np.zeros(n)
    for i, k in enumerate(k_idx):
        w = weights[i]
        if w < 1e-10:
            continue
        # grad b[k]_i = a[k-i] for valid i (0 <= i < n, 0 <= k-i < n)
        lo = max(0, k - n + 1)
        hi = min(n - 1, k)
        if lo <= hi:
            grad[lo:hi+1] += w * 2.0 * a[k - np.arange(lo, hi+1)]
    return grad

def _project_simplex(v, target=1.0):
    """Project v onto {x >= 0, sum(x) = target}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - target)
    rho = np.nonzero(cond)[0][-1] if np.any(cond) else n - 1
    theta = (cssv[rho] - target) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def _score(a):
    """Compute the score 2*n*max(b)/sum(a)^2."""
    n = len(a)
    S = np.sum(a)
    if S < 1e-10:
        return np.inf
    b = np.convolve(a, a)
    return 2.0 * n * np.max(b) / (S * S)

def _optimize(a, deadline, rng, use_fista=True, M=20, eta_init=None, rho=0.95):
    """Optimize using smoothed subgradient with optional FISTA acceleration."""
    n = len(a)
    a = np.asarray(a, dtype=np.float64).copy()
    S = np.sum(a)
    if S < 1e-10:
        a = np.ones(n) / n
        S = 1.0
    a = a / S
    
    if eta_init is None:
        eta_init = 0.5 / np.sqrt(n)
    
    best = a.copy()
    best_score = _score(best)
    
    if use_fista:
        y = a.copy()
        t = 1.0
    else:
        y = a.copy()
    
    eta = eta_init
    patience = 0
    best_patience = 500
    
    while time.monotonic() < deadline:
        b = np.convolve(y, y)
        b_max = np.max(b)
        
        # Temperature for softmax weighting
        temp = 0.1 * b_max  # adjust this
        
        k_idx, weights = _softmax_weights(b, M, temp)
        
        # Compute gradient
        grad = _compute_gradient(y, k_idx, weights)
        
        # Center gradient (for the sum constraint)
        grad = grad - np.mean(grad)
        
        # Step size
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-15:
            break
        step = eta / grad_norm
        
        if use_fista:
            x_new = y - step * grad
            x_new = _project_simplex(x_new, 1.0)
            t_new = (1.0 + np.sqrt(1.0 + 4.0 * t * t)) / 2.0
            y = x_new + ((t - 1.0) / t_new) * (x_new - a)
            y = _project_simplex(y, 1.0)
            a = x_new
            t = t_new
        else:
            a = a - step * grad
            a = _project_simplex(a, 1.0)
            y = a.copy()
        
        # Evaluate
        cur_score = _score(a)
        if cur_score < best_score - 1e-12:
            best_score = cur_score
            best = a.copy()
            patience = 0
        else:
            patience += 1
        
        # Adaptive step size
        if patience > best_patience:
            eta *= rho
            patience = 0
            if use_fista:
                t = 1.0  # reset momentum
                y = a.copy()
            if eta < 1e-12:
                break
        
        # Reset momentum periodically to avoid diverging
        if use_fista and patience % 200 == 0 and patience > 0:
            t = 1.0
            y = a.copy()
    
    return best, best_score

```python
"""
FFT-accelerated smoothed subgradient descent with Nesterov momentum
for minimizing the normalized autocorrelation peak of a non-negative sequence.
"""

import numpy as np
import time


def _fft_convolve_square(a):
    """Compute convolve(a, a) using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    result = np.fft.irfft(A * A, fft_size)[:size]
    return result


def _gradient_at_peaks(a, k_idx, weights):
    """Compute sum_j weights[j] * 2*a[k_j - i] for all i."""
    n = len(a)
    grad = np.zeros(n)
    for j in range(len(k_idx)):
        w = weights[j]
        if w < 1e-12:
            continue
        k = k_idx[j]
        lo = max(0, k - n + 1)
        hi = min(n - 1, k)
        if lo <= hi:
            indices = np.arange(lo, hi + 1)
            grad[indices] += 2.0 * w * a[k - indices]
    return grad


def _project_simplex(v, target=1.0):
    """Project v onto {x >= 0, sum(x) = target}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - target)
    if not np.any(cond):
        return np.full(n, target / n)
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - target) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def _compute_score(a):
    """Compute 2*n*max(b)/sum(a)^2."""
    n = len(a)
    S = np.sum(a)
    if S < 1e-10:
        return np.inf
    b = _fft_convolve_square(a)
    return 2.0 * n * np.max(b) / (S * S)


def _logsumexp_smooth_max(b, beta):
    """Compute smooth approximation of max(b) using log-sum-exp."""
    m = np.max(b)
    return m + np.log(np.sum(np.exp(beta * (b - m)))) / beta


def _optimize(a_init, deadline, rng, M=30, beta_init=50.0, eta_init=None,
              use_momentum=True, cool_rate=0.9, patience_max=500):
    """
    Smoothed subgradient descent with optional Nesterov momentum.
    Minimizes log-sum-exp approximation of max(b) subject to sum(a)=1, a>=0.
    """
    n = len(a_init)
    a = np.asarray(a_init, dtype=np.float64).copy()
    S = np.sum(a)
    if S < 1e-10:
        a = np.ones(n) / n
    else:
        a = a / S

    if eta_init is None:
        eta_init = 1.0 / np.sqrt(n)

    best = a.copy()
    best_score = _compute_score(best)
    eta = eta_init
    beta = beta_init
    patience = 0
    total_iters = 0

    if use_momentum:
        y = a.copy()
        t = 1.0
    else:
        y = a.copy()

    while time.monotonic() < deadline:
        total_iters += 1
        b = _fft_convolve_square(y)
        b_max = np.max(b)

        # Select top M peaks with softmax weights
        if M >= len(b):
            k_idx = np.arange(len(b))
            wts = np.full(len(b), 1.0 / len(b))
        else:
            k_idx = np.argpartition(b, -M)[-M:]
            b_sel = b[k_idx]
            # Softmax weights with temperature
            temp = b_max / beta
            wts = np.exp((b_sel - b_max) / temp)
            wts_sum = np.sum(wts)
            if wts_sum > 1e-30:
                wts /= wts_sum
            else:
                wts = np.full(M, 1.0 / M)
                k_idx = k_idx[np.argsort(b_sel)[::-1][:M]]

        # Compute gradient
        grad = _gradient_at_peaks(y, k_idx, wts)
        # Center for sum constraint
        grad = grad - np.mean(grad)

        # Step size
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-15:
            break
        step = eta / (grad_norm + 1e-15)

        if use_momentum:
            x_new = y - step * grad
            x_new = _project_simplex(x_new, 1.0)
            t_new = (1.0 + np.sqrt(1.0 + 4.0 * t * t)) / 2.0
            y = x_new + ((t - 1.0) / t_new) * (x_new - a)
            # Ensure y stays in feasible set (approximately)
            y = np.maximum(y, 0.0)
            y_sum = np.sum(y)
            if y_sum > 1e-10:
                y = y / y_sum
            else:
                y = x_new.copy()
            a = x_new
            t = t_new
        else:
            a = a - step * grad
            a = _project_simplex(a, 1.0)
            y = a.copy()

        # Evaluate
        cur_score = _compute_score(a)
        if cur_score < best_score - 1e-10:
            best_score = cur_score
            best = a.copy()
            patience = 0
        else:
            patience += 1

        # Adaptive stepping
        if patience >= patience_max:
            eta *= cool_rate
            patience = 0
            if use_momentum:
                t = 1.0
                y = a.copy()
            if eta < 1e-12:
                break
        
        # Also slowly increase beta (make smoothing sharper)
        if total_iters % 100 == 0:
            beta = min(beta * 1.05, 500.0)

    return best, best_score


def _make_two_level(n, eps):
    """Anti-symmetric two-level: first half high, second half low."""
    a = np.ones(n)
    a[:n // 2] = 1.0 + eps
    a[n // 2:] = 1.0 - eps
    a = np.maximum(a, 0.0)
    S = np.sum(a)
    return a / S


def _make_cosine_anti(n, eps):
    """Smooth anti-symmetric: 1 + eps*cos(pi*i/(n-1))."""
    i = np.arange(n, dtype=np.float64)
    a = 1.0 + eps * np.cos(np.pi * i / (n - 1))
    a = np.maximum(a, 0.01)
    S = np.sum(a)
    return a / S


def _make_four_segment(n, eps):
    """Four segments with decreasing amplitude."""
    q = n // 4
    a = np.ones(n)
    a[:q] = 1.0 + eps
    a[q:2*q] = 1.0 + eps/3
    a[2*q:3*q] = 1.0 - eps/3
    a[3*q:] = 1.0 - eps
    a = np.maximum(a, 0.01)

def _make_oscillatory(n, freq, eps):
    """Anti-symmetric oscillatory: 1 + eps*cos(2*pi*freq*i/n)."""
    i = np.arange(n, dtype=np.float64)

    a = np.maximum(a, 0.01)
    S = np.sum(a)
    return a / S


def _perturb(a, rng, scale=0.1):
    """Add smooth random perturbation."""
    n = len(a)
    # Low-frequency noise
    n_modes = min(10, n // 4)
    noise = np.zeros(n)
    i = np.arange(n, dtype=np.float64)
    for _ in range(n_modes):
        f = rng.uniform(1, n // 2)
        phi = rng.uniform(0, 2 * np.pi)
        amp = rng.uniform(-1, 1)
        noise += amp * np.cos(2 * np.pi * f * i / n + phi)
    noise /= (np.max(np.abs(noise)) + 1e-15)
    a_new = a + scale * noise
    return _project_simplex(a_new, 1.0)

    """Compute p[j] = sum_k w[k]*a[k-j] for j=0,...,n-1 using FFT."""
    n = len(a)
    m = len(w)
    size = m + n - 1
    fft_size = 1 << (size - 1).bit_length()
    W = np.fft.rfft(w, fft_size)
    A = np.fft.rfft(a, fft_size)
    # Correlation via FFT: ifft(conj(W) * A) gives the correlation
    # But we need to be careful about the indexing.
    corr = np.fft.irfft(np.conj(W) * A, fft_size)
    # The result corr[k] = sum_i w[i] * a[i-k] (mod fft_size)
    # We want p[j] = sum_k w[k] * a[k-j] = sum_i w[i+j] * a[i]
    # This is the cross-correlation at lag j.
    # From FFT: ifft(conj(W)*A)[k] = sum_n w[n] * a[n-k] (circular)
    # So ifft(conj(W)*A)[k] ≈ sum_n w[n] * a[n-k] (linear, if no aliasing)
    # We want p[j] = sum_n w[n] * a[n-j] = ifft(conj(W)*A)[j]

    # p[j] = sum_k w[k] * a[k-j]
    # Let rev_a[t] = a[n-1-t]. Then a[k-j] = rev_a[n-1-(k-j)] = rev_a[n-1-k+j].
    # p[j] = sum_k w[k] * rev_a[n-1-k+j]
    # Let m' = n-1+j. p[j] = sum_k w[k] * rev_a[m'-k] = (w * rev_a)[m']
    # So p[j] = convolve(w, rev_a)[n-1+j]
    
    rev_a = a[::-1]
    W = np.fft.rfft(w, fft_size)
    RA = np.fft.rfft(rev_a, fft_size)
    conv = np.fft.irfft(W * RA, fft_size)[:m + n - 1]
    return conv[n-1:n-1+n]  # p[0], ..., p[n-1]
```

`H_F[i,j] = sum_k λ_k * 2 * δ_{j, k-i} = 2 * sum_{k: k-i=j} λ_k = 2 * λ_{i+j}` (if `0 <= i+j < 2n-1`).

Hankel matrices have special properties: they can be diagonalized using the discrete sine/cosine transform (DST/DCT) in certain cases.

If `λ_k` is non-negative (which it is at the KKT optimum), then `H_F` is a positive semidefinite Hankel matrix (by a theorem of Schoenberg). So the weighted sum of active `b[k]` terms is a convex function!

However, the wavelength of the Hankel matrix might not be diagonal, so we can't easily compute Newton steps. But we can use conjugate gradient or other first-order methods that work well on smooth convex functions.

In practice, the smoothed objective `sum_k λ_k * b[k]` (with approximately correct `λ`) is a good surrogate for the original non-convex objective. Optimizing this surrogate might lead to better solutions.

def _fft_conv_square(a):
    """Compute np.convolve(a, a) using FFT."""
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fsize)
    return np.fft.irfft(A * A, fsize)[:size]


def _pressure_fft(a, w):
    """
    Compute p[i] = sum_k w[k] * a[k-i] for i=0,...,n-1 using FFT.
    w has length 2n-1, a has length n.
    """
    n = len(a)
    m = len(w)
    size = m + n - 1
    fsize = 1 << (size - 1).bit_length()
    W = np.fft.rfft(w, fsize)
    RA = np.fft.rfft(a[::-1], fsize)
    conv = np.fft.irfft(W * RA, fsize)[:size]
    return conv[n - 1:n - 1 + n]


def _project_simplex(v, target=1.0):
    """Project v onto {x >= 0, sum(x) = target}."""
    n = len(v)
    if n == 0:
        return v
    if np.all(v <= 0):
        return np.full(n, target / n)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - target)
    if not np.any(cond):
        return np.full(n, target / n)
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - target) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)
