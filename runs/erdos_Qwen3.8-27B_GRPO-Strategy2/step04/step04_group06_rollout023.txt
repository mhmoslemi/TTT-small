If lag ≥ 0: corr[j] = sum_{i=lag}^{n-1} h[i] * (1-h[i-lag])
If lag < 0: corr[j] = sum_{i=0}^{n-1+lag} h[i] * (1-h[i-lag]) where -lag > 0

Let d = |lag|.
If lag = d > 0: corr = sum_{i=d}^{n-1} h[i]*(1-h[i-d])
  d/dh[m]: 
  - m as first factor: (1-h[m-d]) for m ≥ d
  - m as second factor (in 1-h[m]): -h[m+d] for m+d ≤ n-1, i.e., m ≤ n-1-d
  So: grad[m] = (1-h[m-d])*(m≥d) - h[m+d]*(m≤n-1-d)

If lag = -d (d > 0): corr = sum_{i=0}^{n-1-d} h[i]*(1-h[i+d])
  d/dh[m]:
  - m as first factor: (1-h[m+d]) for m ≤ n-1-d
  - m as second factor: -h[m-d] for m-d ≥ 0, i.e., m ≥ d
  So: grad[m] = (1-h[m+d])*(m≤n-1-d) - h[m-d]*(m≥d)

For lag = 0: corr = sum h[i]*(1-h[i])
  grad[m] = 1 - 2h[m]

f(x) = max(c[top_k]) + (1/alpha) * log(sum(exp(alpha*(c[top_k] - max(c[top_k])))))
