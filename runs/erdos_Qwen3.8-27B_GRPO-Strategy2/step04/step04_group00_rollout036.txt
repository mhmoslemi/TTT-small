This is LINEAR in h[i]: coefficient is (1 - h[i-L] - h[i+L]), no quadratic term.

For L < 0: similar by symmetry.

So for each k, c_k is either:
- Linear in h[i] (for k ≠ 0, i.e., L ≠ 0)
- Linear + quadratic in h[i] (for k = 0, i.e., L = 0): specifically h[i] - h[i]^2 + const

The max of (2n-2) linear functions and 1 concave quadratic, evaluated at h[i] = t ∈ [0,1].

To minimize this max over t, I can:
1. Compute the value at t=0 and t=1
2. For the interior: the max of linear functions is convex (piecewise linear), and the quadratic is concave. The max of a convex and concave function is convex. So the minimum is either at a boundary or at a point where two linear functions cross (or where a linear function is tangent to the quadratic).

Actually, the max of linear functions is convex and piecewise linear. The max of this and a concave quadratic is... not necessarily convex. Hmm.

Let me simplify: for the coordinate descent, I'll just do a fine grid search over t ∈ [0,1] (say, 100 points) and pick the best. This is O(100 * n) per coordinate, and O(100 * n * n) total for one sweep. For n=140, that's about 200,000 operations per sweep, which is very fast.

Even better: I can precompute the "slope" of each c_k with respect to h[i], and then the problem reduces to minimizing max_k (a_k + b_k * t) over t, where (a_k, b_k) are the intercept and slope of c_k w.r.t. h[i].

For k=0: a_0 = c_0_base + 1, b_0 = ... wait, c_0 = (sum_j≠i h[j](1-h[j])) + h[i](1-h[i]) = base + h[i] - h[i]^2.
So as a function of t: c_0(t) = base + t - t^2.

For k≠0: c_k(t) = base_k + slope_k * t.

The max of these is:
f(t) = max(base_0 + t - t^2, max_k≠0 (base_k + slope_k * t))

To minimize f(t) over t ∈ [0,1]:
- f is the max of a concave parabola and several lines
- The maximum of lines is a convex piecewise-linear function
- f(t) = max(concave, convex) is not necessarily convex

The minimum of f can be found by:
1. Checking t = 0 and t = 1
2. Finding where the parabola equals each line (quadratic equation)
3. Finding where each pair of lines cross
4. Evaluating f at all these points and picking the minimum

This is doable in O(n^2) per coordinate, but for n=140, a grid search with 200 points is sufficient and much simpler.

Let me implement the simple grid-search coordinate descent:

Wait, this has an issue: when I set h[i] = t and then repair, the repair might change h[i] again (if it clips or redistributes). This makes the coordinate descent not exactly coordinate-wise. But it should still work as a heuristic.

Actually, let me think more carefully. If I fix all h[j] for j≠i, and I want to choose h[i]=t, then:
- The constraint sum(h) = target becomes: h[i] = target - sum_{j≠i} h[j]
- So t is NOT free! It's determined by the sum constraint.

Unless... I redistribute the sum constraint. But that's what repair does.

Alternative: optimize h[i] and h[j] simultaneously for a pair, keeping the sum constraint satisfied. This is the pairwise swap approach.

Or: for single-coordinate optimization, fix the sum by adjusting h[i] AND redistributing the excess to all other coordinates proportionally. But this is getting complicated.

Let me just stick with the pairwise approach (which the previous code already does) but make it more efficient and targeted.

import numpy as np
from scipy.optimize import minimize
import time

def _corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def _c5(h, dx):
    return float(np.max(_corr(h))) * dx

def _repair(h, target):
    n = len(h)
    h = np.clip(h.copy(), 0.0, 1.0)
    diff = target - float(h.sum())
    if abs(diff) > 1e-13:
        h += diff / n
        h = np.clip(h, 0.0, 1.0)
        diff = target - float(h.sum())
        if abs(diff) > 1e-13:
            order = np.argsort(1.0 - h) if diff > 0 else np.argsort(h)
            for idx in order:
                if diff > 0:
                    a = min(diff, 1.0 - h[idx])
                    h[idx] += a; diff -= a
                else:
                    a = min(-diff, h[idx])
                    h[idx] -= a; diff += a
                if abs(diff) < 1e-14:
                    break
    return h

def _soft_obj(x, alpha):
    c = _corr(x)
    m = float(np.max(c))
    s = np.clip(alpha * (c - m), -500, 500)
    s -= float(np.max(s))
    n = len(x)
    return m + float(np.log(np.sum(np.exp(s)))) / alpha + 500.0*(float(np.sum(x))-n/2.0)**2

def _soft_grad(x, alpha):
    c = _corr(x)
    m = float(np.max(c))
    s = np.clip(alpha*(c-m), -500, 500)
    s -= float(np.max(s))
    ew = np.exp(s)
    pw = ew / float(ew.sum())
    n = len(x)
    g = np.zeros(n)
    for k in range(2*n-1):
        pk = pw[k]
        if pk < 1e-15: continue
        L = k - (n-1)
        if L == 0:
            g += pk*(1.0-2.0*x)
        elif L > 0:
            g[L:] += pk*(1.0-x[:n-L])
            g[:n-L] -= pk*x[L:]
        else:
            M=-L
            g[:n-M] += pk*(1.0-x[M:])
            g[M:] -= pk*x[:n-M]
    g /= alpha
    g += 1000.0*(float(np.sum(x))-n/2.0)
    return g

def _act_grad(h, frac):
    c = _corr(h); n = len(h)
    cm = float(np.max(c)); mn = float(np.min(c))
    spread = cm-mn if cm-mn>1e-12 else 1.0
    thr = cm - frac*spread
    act = np.where(c>=thr)[0]
    g = np.zeros(n)
    for k in act:
        L = k-(n-1)
        if L==0: g += 1.0-2.0*h
        elif L>0:
            g[L:] += 1.0-h[:n-L]; g[:n-L] -= h[L:]
        else:
            M=-L; g[:n-M] += 1.0-h[M:]; g[M:] -= h[:n-M]
    g /= float(len(act))
    return g, act

def _lbfgs(h, n, dx, bounds, alphas, tl):
    bh, bc = h.copy(), _c5(h, dx)
    for a in alphas:
        if tl() < 12: break
        try:
            r = minimize(_soft_obj, bh.copy(), jac=_soft_grad, args=(a,),
                         method='L-BFGS-B', bounds=bounds,
                         options={'maxiter':500,'ftol':1e-19,'gtol':1e-15})
            hc = _repair(r.x, n/2.0); cv = _c5(hc, dx)
            if cv < bc: bc=cv; bh=hc
        except: pass
    return bh, bc

def _proj_grad(h, n, dx, tl, mxit=4000):
    bh, bc = h.copy(), _c5(h, dx)
    tgt = n/2.0; step = 0.012
    for _ in range(mxit):
        if tl() < 8: break
        g,_ = _act_grad(h, 0.06)
        gc = g - g.mean(); ng = np.linalg.norm(gc)
        if ng < 1e-12: break
        gc /= ng
        ok = False
        for s in [step, step*.5, step*.25, step*.1]:
            hn = _repair(h - s*gc, tgt)
            cn = _c5(hn, dx)
            if cn < _c5(h,dx)-1e-15:
                h = hn; ok = True
                if cn < bc: bc=cn; bh=h.copy()
                break
        if ok: step = min(step*1.08, 0.045)
        else:
            step *= 0.5
            if step < 1e-8: break
    return bh, bc

def _pairwise(h, n, dx, tl):
    bh, bc = h.copy(), _c5(h, dx)
    tgt = n/2.0
    dl = np.array([.001,.003,.008,.015,-.001,-.003,-.008,-.015])
    for sw in range(300):
        if tl() < 8: break
        g,_ = _act_grad(h, 0.04)
        ord_ = np.argsort(-np.abs(g))[:45]
        imp = False
        for ii in range(len(ord_)):
            i = ord_[ii]
            for jj in range(ii+1, min(ii+18, len(ord_))):
                j = ord_[jj]
                for d in dl:
                    ni,nj = h[i]+d, h[j]-d
                    if 0<=ni<=1 and 0<=nj<=1:
                        h[i],h[j] = ni,nj
                        hn = _repair(h, tgt)
                        c = _c5(hn, dx)
                        if c < bc:
                            bc=c; bh=hn.copy(); h=hn; imp=True
                        else:
                            h[i],h[j] = ni-d, nj+d
                if imp: break
            if imp: break
        if not imp: break
    return bh, bc

def _anneal(h, n, dx, tl, rng, n_iter=30000):
    bh, bc = h.copy(), _c5(h, dx)
    tgt = n/2.0; T = 0.0003
    for _ in range(n_iter):
        if tl() < 5: break
        T *= 0.9997
        i,j = rng.randint(n), rng.randint(n)
        if i==j: continue
        d = rng.uniform(-0.004, 0.004)
        ni,nj = h[i]+d, h[j]-d
        if 0<=ni<=1 and 0<=nj<=1:
            h[i],h[j] = ni,nj
            hn = _repair(h, tgt)
            c = _c5(hn, dx)
            if c < bc or (T>1e-8 and np.log(rng.uniform()) < (bc-c)/T):
                h = hn
                if c < bc: bc=c; bh=hn.copy()
            else:
                h[i],h[j] = ni-d, nj+d
    return bh, bc

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    rng = np.random.RandomState(seed)
    def tl(): return budget_s - (time.time()-t0)
    
    n0 = len(initial_h_values)

    h0 = _repair(np.array(initial_h_values, dtype=float), n0/2.0)

        h1, c1 = _proj_grad(h1, n1, dx1, lambda: tl()-20)
