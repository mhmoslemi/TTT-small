```python
def _project(g, S):
    """Project g onto {0<=x<=1, sum(x)=S}"""
    n = len(g)
    # Bisection on shift
    lo, hi = -max(g) - 1, max(1 - g.max(), 0) + 1
    # Actually: clip(g - tau, 0, 1), find tau s.t. sum = S
    # f(tau) = sum(clip(g - tau, 0, 1)) is decreasing in tau
    # f(-inf) = n, f(inf) = 0
    for _ in range(60):
        tau = (lo + hi) / 2
        s = np.clip(g - tau, 0, 1).sum()
        if s > S:
            # need to decrease values, increase tau
            lo = tau
        else:
            hi = tau
    tau = (lo + hi) / 2
    return np.clip(g - tau, 0, 1)
```

**Idea: Use the structure of the problem more directly**

The key observation is that c_k + c_{2(n-1)-k} has a special relationship (they involve the same pairs but in reverse).
