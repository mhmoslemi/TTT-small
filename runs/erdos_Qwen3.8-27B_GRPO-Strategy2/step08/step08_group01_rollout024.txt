import numpy as np
from scipy.optimize import minimize
import time

def _repair(h, n):
    """Projection onto {0<=h<=1, sum(h)=n/2}"""
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    if abs(s - target) < 1e-12:
        return h
    # Bisection for proper projection
    lo, hi = -2.0, 2.0
    for _ in range(60):
        mid = (lo + hi) * 0.5
        h_p = np.clip(h - mid, 0, 1)
        if h_p.sum() > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) * 0.5, 0, 1)

def _eval(h):
    n = len(h)
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * 2.0 / n)

def _eval_vec(h):
    n = len(h)
    return np.correlate(h, 1.0 - h, mode='full') * 2.0 / n

def _grad_topk(h, k_list):
    """Exact gradient of sum of overlaps at specific shifts"""
    n = len(h)
    dx = 2.0 / n
    g = np.zeros(n)
    for m in k_list:
        lag = m - (n - 1)
        # c[m] = sum_i h[i]*(1-h[i+lag]) for valid i
        i_lo = max(0, -lag)
        i_hi = min(n, n - lag)
        for i in range(i_lo, i_hi):
            # h[i] as first factor: d(c)/d(h[i]) = (1-h[i+lag])*dx
            g[i] += dx * (1.0 - h[i + lag])
            # h[i+lag] as second factor: d(c)/d(h[i+lag]) = -h[i]*dx
            g[i + lag] -= dx * h[i]
    return g

    n = len(h)
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full') * dx
    idx = np.argsort(c)[-top_k:]
    c_top = c[idx]
    m = c_top.max()
    s = np.clip(alpha * (c_top - m), -400, 400)
    s -= s.max()
    w = np.exp(s)

    g = np.zeros(n)

        lag = k - (n - 1)

    target = n * 0.5
    h = h0.copy()
    y = h.copy()
    t = 1.0

        else:
            step *= 0.7

            c_new = cur_c

For a 2-point move h[i]+=d, h[j]-=d:
- The objective is max_m c[m] where c[m] depends linearly on d (for fixed i,j)
- Actually c[m] is LINEAR in d for a 2-point move! Because h[i]*(1-h[i+lag]) is linear in h[i] (when h[i+lag] is fixed).

Wait, no. If I change h[i] by d, then terms where h[i] appears as the first factor change linearly, but terms where h[i] appears as the second factor (h[i+lag] where i+lag = some index) also change.

Actually, for a 2-point move h[i]→h[i]+d, h[j]→h[j]-d:
c[m] = sum_k h[k]*(1-h[k+lag_m])

The change is:
dc[m] = d*(1-h[i+lag_m]) - d*h[i-lag_m] - (-d)*(1-h[j+lag_m]) + (-d)*h[j-lag_m]
      = d*(1-h[i+lag_m]) - d*h[i-lag_m] + d*(1-h[j+lag_m]) - d*h[j-lag_m]
      = d * [(1-h[i+lag_m]) - h[i-lag_m] + (1-h[j+lag_m]) - h[j-lag_m]]

(validity: each term present only if the index is in [0,n))

So dc[m] = d * A[m] where A[m] is a constant (for fixed i,j).

This means c[m] is LINEAR in d! So max_m (c[m] + d*A[m]) is a piecewise linear function of d, and we can find the optimal d (that minimizes the max) by checking the breakpoints!

The optimal d minimizes max_m (c[m] + d*A[m]). This is a 1D convex piecewise linear optimization. The minimum is where the "upper envelope" has a vertex, or at a boundary (d=0, or the constraint 0<=h[i]+d<=1 and 0<=h[j]-d<=1).

The breakpoints occur where c[m1] + d*A[m1] = c[m2] + d*A[m2], i.e., d = (c[m2]-c[m1])/(A[m1]-A[m2]).

So the algorithm for a given pair (i,j):
1. Compute A[m] for all m (or at least for the top m's)
2. Find the d that minimizes max_m (c[m] + d*A[m]) subject to 0<=h[i]+d<=1, 0<=h[j]-d<=1
3. Apply the move

This is exact and much more powerful than random step sizes!

But computing A[m] for all 2n-1 values of m for each pair (i,j) is expensive. However, we only need it for the top ~20 shifts.

Let me define:
A[m] = [(1-h[i+lag]) if valid else 0] - [h[i-lag] if valid else 0] + [(1-h[j+lag]) if valid else 0] - [h[j-lag] if valid else 0]

where lag = m - (n-1).

For a fixed i, the values A_i[lag] = (1-h[i+lag])*(valid) - h[i-lag]*(valid) is a vector of length 2n-1.
Similarly for j.

So A[m] = A_i[lag_m] + A_j[lag_m].

We can precompute A_i and A_j for the current i and j in O(n) time.

Then the 1D optimization: minimize max_{m in top_K} (c[m] + d * A[m]) subject to d in [lo, hi].

For K active shifts, this is: minimize max of K linear functions of d, subject to d in [lo, hi].

The minimum of the max of linear functions is at a point where two of them are equal (or at a boundary). So we can:
1. Sort the K lines by their slope A[m]
2. Find the upper envelope
3. The minimum of the upper envelope is at a vertex or boundary

For small K (say 10-20), this is very fast.

Actually, even simpler: we can just do golden section search on d in [lo, hi], evaluating the max of K linear functions. Each evaluation is O(K). A few dozen evaluations gives us the answer to high precision.

Let me code this up:

```python
def _exact_2point(h, c, i, j, top_k, dx):
    """Find optimal d for h[i]+=d, h[j]-=d that minimizes max of top_k overlaps"""
    n = len(h)
    # Compute A[m] for top_k shifts
    idx = np.argsort(c)[-top_k:]
    c_top = c[idx]
    
    # A_i[lag] = (1-h[i+lag]) - h[i-lag] (with validity)
    # A_j[lag] = (1-h[j+lag]) - h[j-lag] (with validity)
    # A[m] = A_i[lag_m] + A_j[lag_m]
    
    A = np.zeros(top_k)
    for t, m in enumerate(idx):
        lag = m - (n - 1)
        ai = 0.0
        aj = 0.0
        # (1-h[i+lag]) if 0<=i+lag<n
        if 0 <= i + lag < n:
            ai += (1.0 - h[i + lag])
        # -h[i-lag] if 0<=i-lag<n
        if 0 <= i - lag < n:
            ai -= h[i - lag]
        # (1-h[j+lag]) if 0<=j+lag<n
        if 0 <= j + lag < n:
            aj += (1.0 - h[j + lag])
        # -h[j-lag] if 0<=j-lag<n
        if 0 <= j - lag < n:
            aj -= h[j - lag]
        A[t] = ai + aj
    
    # d bounds
    lo = max(0.0 - h[i], 0.0 - (1.0 - h[j]))  # h[i]+d>=0, h[j]-d>=0 → d<=h[j]
    hi = min(1.0 - h[i], h[j])  # h[i]+d<=1 → d<=1-h[i], h[j]-d>=0 → d<=h[j]
    # Wait: h[i]+d <= 1 → d <= 1-h[i]; h[i]+d >= 0 → d >= -h[i]
    # h[j]-d <= 1 → d >= h[j]-1; h[j]-d >= 0 → d <= h[j]
    lo = max(-h[i], h[j] - 1.0)
    hi = min(1.0 - h[i], h[j])
    
    if lo >= hi:
        return 0.0
    
    # Golden section search
    gr = (np.sqrt(5) - 1) / 2  # golden ratio ~0.618
    a, b = lo, hi
    c_pt = b - gr * (b - a)
    d_pt = a + gr * (b - a)
    f_c = np.max(c_top + c_pt * A)
    f_d = np.max(c_top + d_pt * A)
    
    for _ in range(50):
        if f_c < f_d:
            b = d_pt
            d_pt = c_pt
            f_d = f_c
            c_pt = b - gr * (b - a)
            f_c = np.max(c_top + c_pt * A)
        else:
            a = c_pt
            c_pt = d_pt
            f_c = f_d
            d_pt = a + gr * (b - a)
            f_d = np.max(c_top + d_pt * A)
    
    return (a + b) * 0.5
```
