Actually, wait. Let me reconsider the problem structure. The key insight I want to exploit:

For h with values in [0,1] and sum = n/2:
- The overlap at lag 0 is sum h[i](1-h[i]) = n/2 - sum h[i]^2
- To minimize this, maximize sum h[i]^2, which means making h as binary as possible
- So the optimal h is indeed close to binary

For a binary h (0 or 1), the overlap at lag k is:
ov_k = |{i: h[i+k]=1 and h[i]=0}| (for the "full" correlation)

This is the number of 1s in h that are shifted by k and land on 0s. Equivalently:
ov_k = (# positions where h has 1 and h shifted by k has 0)
= #1s in h - #1s in h ∩ (h shifted by k)
= n/2 - |A ∩ (A-k)|

where A is the set of positions with h=1.

So minimizing max_k ov_k is equivalent to minimizing max_k (n/2 - |A ∩ (A-k)|) = n/2 - min_k |A ∩ (A-k)|.

This is the classic problem of finding a subset A of size n/2 that maximizes the minimum autocorrelation. This is related to Sidon sets, difference sets, and other combinatorial designs!

def _c5(h):
    n = len(h)
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * (2.0 / n))

def _repair(h):
    n = len(h)
    target = n * 0.5
    h = np.clip(h, 0.0, 1.0).copy()
    for _ in range(100):
        d = target - h.sum()
        if abs(d) < 1e-13:
            break
        mask = (h < 1.0) if d > 0 else (h > 0.0)
        c = mask.sum()
        if c == 0:
            break
        h[mask] += d / c
        np.clip(h, 0.0, 1.0, out=h)
    d = target - h.sum()
    if abs(d) > 1e-12:
        order = np.argsort(1.0 - h) if d > 0 else np.argsort(h)
        for i in order:
            step = min(abs(d), (1.0 - h[i]) if d > 0 else h[i])
            h[i] += np.sign(d) * step
            d -= np.sign(d) * step
            if abs(d) < 1e-13:

    return h

            grad[:n - lag] -= h[lag:]
        elif lag < 0 and -lag < n:
            k = -lag
            grad[:n - k] += (1.0 - h[k:])
            grad[k:] -= h[:n - k]
    return dx * grad / max(1, len(lags))
