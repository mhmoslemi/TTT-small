subject to: -h[i] ≤ s ≤ 1-h[i] and h[j]-1 ≤ -s ≤ -h[j], i.e., h[j]-1 ≤ s...

h'[j] = h[j] - s ∈ [0,1] → h[j]-1 ≤ s ≤ h[j]

So: s ∈ [max(-h[i], h[j]-1), min(1-h[i], h[j])]

The objective max_k (c[k] + s * dx * d[k]) is a convex piecewise-linear function of s.
Its minimum is at a "kink" point where two (or more) lines achieve the maximum simultaneously.

To find the minimum:
- Evaluate at s = 0, s = s_min, s = s_max
- The convex function decreases then increases (or is constant)

The minimum is where 0 is in the subgradient, i.e., min_k(d[k] for k in argmax) ≤ 0 ≤ max_k(d[k] for k in argmax).

Binary search: 
- If all d[k] for k in argmax are > 0, increase s (the max is increasing)
  Wait, if 0 is not in the subgradient and the subgradient is all positive, the function is increasing, so we should decrease s.

But wait, I need to double-check: the pair search changes h[i] and h[j] temporarily for each grid point, then calls _eval which recomputes the full correlate. That's wasteful. A smarter approach would be to compute the correlation once and update it incrementally.

When h changes by Δh[i] = s and Δh[j] = -s, the change in the correlation is:
Δfull[k] = s * (∂full[k]/∂h[i] - ∂full[k]/∂h[j])

This is linear in s! So I can compute the gradient vector once and then evaluate c[k] + s * grad_diff[k] for different s values without recomputing the full correlate.

Let me implement this:

```python
def _pair_search_fast(h, n_trials, n_grid, rng):
    n = len(h)
    dx = 2.0 / n
    cur_c = _eval(h)
    c_vec = _corr(h)
    best_c, best_h = cur_c, h.copy()
    for _ in range(n_trials):
        i = rng.randint(n)
        j = (i + 1 + rng.randint(0, 30)) % n
        # Compute grad diff: d[k] = dx * (∂full[k]/∂h[i] - ∂full[k]/∂h[j])
        d = np.zeros(2 * n - 1)
        for k in range(2 * n - 1):
            lag = k - (n - 1)
            # ∂full[k]/∂h[i]:
            lo_i = max(0, lag)
            hi_i = min(n - 1, n - 1 + lag)
            vi = 0.0
            if lo_i <= i <= hi_i:
                vi += (1.0 - h[i - lag])
            j2_lo = max(0, lo_i - lag)
            j2_hi = min(n - 1, hi_i - lag)
            if j2_lo <= i + lag <= j2_hi:
                vi -= h[i + lag]
            
            vj = 0.0
            if lo_i <= j <= hi_i:
                vj += (1.0 - h[j - lag])
            if j2_lo <= j + lag <= j2_hi:
                vj -= h[j + lag]
            
            d[k] = (vi - vj) * dx
        
        # Now c_new[k] = c_vec[k] + s * d[k]
        # Find s that minimizes max(c_vec + s * d)
        lo_s = max(-h[i], h[j] - 1.0)
        hi_s = min(1.0 - h[i], h[j])
        if hi_s <= lo_s + 1e-14:
            continue
        
        best_s = 0.0
        best_c_t = cur_c
        for s in np.linspace(lo_s, hi_s, n_grid):
            c_t = np.max(c_vec + s * d)
            if c_t < best_c_t:
                best_c_t = c_t
                best_s = s
        
        if abs(best_s) > 1e-14 and best_c_t < cur_c:
            h[i] += best_s
            h[j] -= best_s
            c_vec = _corr(h)  # Recompute (or update incrementally)
            cur_c = _eval(h)
            if cur_c < best_c:
                best_c, best_h = cur_c, h.copy()
    return best_h, best_c
```

def _pair_grad_diff(h, i, j):
    n = len(h)
    d = np.zeros(2 * n - 1)
    # For each lag, compute ∂full/∂h[i] - ∂full/∂h[j]
    # ∂full[k]/∂h[p] = (1-h[p-lag]) if p in V_k - h[p+lag] if p+lag in V_k
    # where V_k = [max(0,lag), min(n-1, n-1+lag)]
    
    for lag in range(-(n-1), n):
        lo_v = max(0, lag)
        hi_v = min(n-1, n-1 + lag)
        
        vi = 0.0
        if lo_v <= i <= hi_v:
            vi += (1.0 - h[i - lag])
        if lo_v <= i + lag <= hi_v:
            vi -= h[i + lag]
        
        vj = 0.0
        if lo_v <= j <= hi_v:
            vj += (1.0 - h[j - lag])
        if lo_v <= j + lag <= hi_v:
            vj -= h[j + lag]
        
        d[lag + n - 1] = vi - vj
    return d * (2.0 / n)
