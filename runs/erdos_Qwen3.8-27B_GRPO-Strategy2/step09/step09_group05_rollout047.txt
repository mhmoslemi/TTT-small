For a specific lag L (where L is the full-correlation index, 0 to 2n-2, corresponding to shift l = L - (n-1)):
- The gradient of f_L(h) = dx * sum_{valid i} h[i](1-h[i+l]) wrt h is:

```python
def _lag_grad(h, L):
    """Gradient of overlap at correlation index L (shift = L - (n-1))"""
    n = len(h)
    dx = 2.0 / n
    shift = L - (n - 1)
    g = np.zeros(n)
    if shift >= 0:
        # h[i] appears as first factor for i < n-shift
        g[:n-shift] += (1.0 - h[shift:])
        # h[i] appears as second factor (in 1-h) for i >= shift
        g[shift:] -= h[:n-shift]
    else:
        M = -shift
        g[M:] += (1.0 - h[:n-M])
        g[:n-M] -= h[M:]
    return dx * g
```

This is O(n) per lag. For stochastic subgradient, I can pick a random lag each iteration and do one gradient step.

But actually, the full correlation at each lag is also O(n), and I need to know which lag to pick. Let me compute the full correlation once (O(n²) for all lags, or O(n·m) for m sampled lags), then pick the most active ones.

For n=560, computing the full correlation is O(n²) = ~313k operations, which is fast.

Let me design the stochastic subgradient:
1. Compute full correlation C
2. Weight each lag by exp(alpha * (C[L] - C.max())) (softmax over lags)
3. Sample a lag L from this distribution
4. Compute gradient g = _lag_grad(h, L)
5. Projected step: h ← proj(h - step * g / ||g||)
6. Use decreasing/increasing step with backtracking

This is different from the previous approach because:
- It's stochastic (explores more lags)
- It's cheaper per iteration (O(n) gradient vs O(n·m) for smoothed max)
- The step size is adaptively adjusted

- Find top k active lags
- Average their gradients
- Take a step

def _repair(h, n):
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    if s < 1e-12:
        return np.full(n, 0.5)
    for _ in range(120):
        h *= target / s
        h = np.clip(h, 0.0, 1.0)
        s = h.sum()
        if abs(s - target) < 1e-12:
            break
    diff = target - h.sum()
    if abs(diff) > 1e-12:
        order = np.argsort(1.0 - h) if diff > 0 else np.argsort(h)
        for idx in order:
            if diff > 0:
                a = min(diff, 1.0 - h[idx])
                h[idx] += a
