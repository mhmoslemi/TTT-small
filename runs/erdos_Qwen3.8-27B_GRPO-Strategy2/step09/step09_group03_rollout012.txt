Let me also try a different optimization: **Frank-Wolfe (conditional gradient)** method.

The problem: min max_k f_k(h) s.t. h ∈ [0,1], ∑h = n/2.

Frank-Wolfe: at each step, solve the linearized subproblem:
min_v <∇f_{k*}(h), v> s.t. v ∈ [0,1], ∑v = n/2

The optimal v is: v[i] = 0 if ∂f/∂h[i] > λ, v[i] = 1 if ∂f/∂h[i] < λ, else in between. Then v is a thresholded version of the negative gradient.

Then: h ← (1-γ)h + γv, where γ is the step size.

This is attractive because the subproblem has a closed-form solution!

Let me implement this.

For f_k(h) = ∑_{i} h[i](1-h[i+k]) (for lag k ≥ 0):
∂f_k/∂h[i] = (1-h[i+k]) [if i+k < n] - h[i-k] [if i-k ≥ 0 and i-k ≤ n-1-k]

For the max (or top-M average), the gradient is the weighted sum of individual gradients.

Let me code this up:

```python
def _fw_step(h, g, target_sum):
    """Frank-Wolfe step: find v that minimizes <g, v> subject to v in [0,1], sum(v) = target_sum"""
    n = len(h)
    sorted_g = np.sort(g)
    # Find threshold
    # v[i] = 1 if g[i] < theta, 0 if g[i] > theta, fraction if g[i] == theta
    # Need sum(v) = target_sum
    # If we set v[i] = 1 for all i where g[i] < theta: count = number of g < theta
    # We need exactly target_sum ones (or fractional last one)
    k = int(target_sum)
    # The v that minimizes <g,v> with exactly k ones is: v[i]=1 for the k smallest g[i]
    # But we also need v in [0,1], and sum = target_sum (which may not be integer)
    idx = np.argsort(g)
    v = np.zeros(n)
    full = int(np.floor(target_sum))
    frac = target_sum - full
    v[idx[:full]] = 1.0
    if frac > 1e-12 and full < n:
        v[idx[full]] = frac
    return v
```

    for _ in range(100):
        s = h.sum()
        if abs(s - target) < 1e-14:
            break
        # Binary search on shift
        lo, hi = -1, 1
        for _ in range(60):
            mid = (lo + hi) / 2
            if np.clip(h - mid, 0, 1).sum() > target:
                lo = mid
            else:
                hi = mid
        h = np.clip(h - (lo+hi)/2, 0, 1)
    # Fix residual
    diff = target - h.sum()
    if abs(diff) > 1e-12:
        if diff > 0:
            order = np.argsort(1 - h)
        else:
            order = np.argsort(h)
        for idx in order:
            if diff > 0:
                a = min(diff, 1 - h[idx])
                h[idx] += a
                diff -= a
            else:
                a = min(-diff, h[idx])
                h[idx] -= a
                diff += a
            if abs(diff) < 1e-13:
                break
    return h

def _eval(h):
    n = len(h)
    return float(np.max(np.correlate(h, 1-h, mode='full')) * 2.0 / n)

def _grad_one(h, s):
    """Gradient of f_s(h) = sum h[i]*(1-h[i+s]) for lag s (can be negative)"""
    n = len(h)
    g = np.zeros(n)
    if s == 0:
        g = 1.0 - 2.0 * h
    elif s > 0:
        g[:n-s] += (1.0 - h[s:])
        g[s:n] -= h[:n-s]
    else:
        m = -s
        g[:n-m] += (1.0 - h[m:])
        g[m:n] -= h[:n-m]
    return g

def _fw_point(g, n, target):
    """Find v in [0,1]^n, sum(v)=target, minimizing <g, v>"""
    idx = np.argsort(g)
    v = np.zeros(n)
    full = int(np.floor(target + 1e-12))
    frac = target - full
    if full > 0:
        v[idx[:full]] = 1.0
    if frac > 1e-12 and full < n:
        v[idx[full]] = frac
    return v
