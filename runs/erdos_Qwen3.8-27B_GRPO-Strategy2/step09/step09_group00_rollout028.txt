For the full correlate output[n-1+k] (k≥0):

If I only change h[j], the new value is:
old_val + (change)

- If j appears as the first factor h[i+k]: i+k=j, so i=j-k. Valid if 0≤j-k≤n-1-k, i.e., k≤j≤n-1. Coefficient: (1-h[j-k])

def _repair(h, n):
    t = n * 0.5
    h = np.clip(h, 0.0, 1.0).copy()
    s = h.sum()
    if s < 1e-15:
        return np.full(n, 0.5)
    for _ in range(100):
        h *= t / s
        np.clip(h, 0.0, 1.0, out=h)
        s = h.sum()
        if abs(s - t) < 1e-14:
            break
    d = t - h.sum()
    if abs(d) > 1e-12:
        order = np.argsort(1.0 - h) if d > 0 else np.argsort(h)
        for i in order:
            if d > 0:
                a = min(d, 1.0 - h[i]); h[i] += a; d -= a
            else:
                a = min(-d, h[i]); h[i] -= a; d += a
            if abs(d) < 1e-13:
                break
    return h

def _proj(v, S):
    x = np.array(v, dtype=float, copy=True)
    x += (S - x.sum()) / x.size
    for _ in range(30):
        np.clip(x, 0.0, 1.0, out=x)
        d = S - x.sum()
        if abs(d) < 1e-13:
            break
        m = (x < 1.0) if d > 0 else (x > 0.0)
        c = m.sum()
        if c == 0:
            break
        x[m] += d / c
    return x

def _fft_size(n):
    m = 2 * n - 1
    N = 1
    while N < m:
        N <<= 1
    return N

def _pn(h):

    N = _fft_size(n)
    H = np.fft.rfft(h, N)
    ac = np.fft.irfft(H * np.conj(H), N).real[:n]
    pref = np.empty(n + 1)
    pref[0] = 0.0
    np.cumsum(h, out=pref[1:])
    total = pref[n]
    P = np.empty(n)
    P[0] = total - ac[0]
    Nv = np.zeros(n)
    if n > 1:
        idx = np.arange(1, n)
        P[idx] = pref[n - idx] - ac[idx]
        Nv[idx] = total - pref[idx] - ac[idx]
        mx = max(float(np.max(P)), float(np.max(Nv)))
    else:
        mx = float(P[0])
    return P, Nv, mx

        e += np.exp(np.clip(a * (Nv[1:] - mx), -400, 0)).sum()
    return dx * (mx + np.log(e) / a)

def _grad_weights(h, wP, wN):
    n = len(h)
    dx = 2.0 / n
    u = np.zeros(n)
    if n > 1:
        u[1:] = wP[1:] + wN[1:]
    cp = np.zeros(n)
    cn = np.zeros(n)
    if n > 1:
        cp[1:] = np.cumsum(wP[1:])
        cn[1:] = np.cumsum(wN[1:])
    linP = cp[n - 1::-1]
    linN = cn
    q = np.zeros(n)
    if n > 1 and np.any(u[1:]):

        H = np.fft.rfft(h, Nf)
        R = np.fft.irfft(H * np.fft.rfft(u[::-1], Nf), Nf)
        L = np.fft.irfft(H * np.fft.rfft(u, Nf), Nf)
        q = -(R[n - 1:2*n - 1].real + L[:n].real)
    return dx * (wP[0] * (1.0 - 2.0 * h) + linP + linN + q)

def _soft_grad(h, a):
    P, Nv, mx = _pn(h)
    n = len(h)
    wP = np.zeros(n)
    wN = np.zeros(n)
    e0 = np.exp(np.clip(a * (P[0] - mx), -400, 0))
    tot = e0

        en = np.exp(np.clip(a * (Nv[1:] - mx), -400, 0))
        tot += ep.sum() + en.sum()
        if tot <= 0:
            tot = 1.0; e0 = 1.0
        wP[0] = e0 / tot
        wP[1:] = ep / tot
        wN[1:] = en / tot
    else:
        wP[0] = 1.0
    return _grad_weights(h, wP, wN)

corr[l] = sum_{i: 0≤i<n, 0≤l-i<n} h[i] * (1-h[l-i])

For a given l and coordinate j:
- h[j] appears as h[i] when i=j: valid if 0≤j<n (always) and 0≤l-j<n
  Contribution: h[j] * (1-h[l-j])
  Derivative w.r.t. h[j]: if l-j ≠ j, then (1-h[l-j]); if l-j=j, then (1-h[j]) - h[j] = 1-2h[j]
  
- h[j] appears as h[l-i] when l-i=j, i.e., i=l-j: valid if 0≤l-j<n and 0≤j<n
  Contribution: h[l-j] * (1-h[j])
  Derivative w.r.t. h[j]: if l-j ≠ j, then -h[l-j]; if l-j=j, this is the same term as above

So if l-j = j (i.e., l=2j):
  Only one term: h[j]*(1-h[j]), derivative = 1-2h[j]

If l-j ≠ j (and 0≤l-j<n):
  Two terms: h[j]*(1-h[l-j]) + h[l-j]*(1-h[j])
  Derivative: (1-h[l-j]) + (-h[l-j]) = 1 - 2*h[l-j]

Wait, that's interesting. The derivative doesn't depend on h[j] at all (in the linear case)!

So the coefficient for h[j] in corr[l] is:
- If l-j >= 0 and l-j < n and l-j ≠ j: coefficient = 1 - 2*h[l-j]
- If l-j = j (l=2j): coefficient = 1 - 2*h[j] (but this depends on h[j]! It's the quadratic case)
- Otherwise: coefficient = 0

Wait, but when l-j = j, the term is h[j]*(1-h[j]) which is quadratic. The "coefficient" is actually 1-2h[j] which changes as we change h[j]. So for the quadratic case, we need to handle it separately.

For the linear case (l-j ≠ j):
  corr[l] = ... + h[j]*(1-h[l-j]) + h[l-j]*(1-h[j]) + ...
  = ... + (1-h[l-j])*h[j] + (1-h[j])*h[l-j] + ...
  = ... + (1-h[l-j])*h[j] + h[l-j] - h[l-j]*h[j] + ...
  = ... + (1 - 2*h[l-j])*h[j] + h[l-j] + ...

So the change in corr[l] when h[j] changes by δ (keeping others fixed):
  δ_corr[l] = (1 - 2*h[l-j]) * δ  (for l-j ≠ j, 0≤l-j<n)
  δ_corr[l] = (1-2*h[j])*δ - δ²  (for l-j = j, the quadratic case)

This is a linear function of δ in the non-symmetric case! Great, so the 1D minimax is well-defined.

But wait, I also need to handle the constraint. If I change h[j] by δ, the sum changes by δ. To maintain the constraint, I need to compensate. 

One approach: don't enforce the sum constraint during coordinate descent, but add a large penalty term. Or: after each coordinate change, repair.

Let me use a simpler approach: after each coordinate change, do a quick repair (distribute the sum error to the coordinate with most slack). This maintains feasibility.

Actually, let me think about this differently. What if I do "paired" coordinate descent?

Pick (i, j), change h[i] += δ, h[j] -= δ. This maintains the sum constraint exactly!

For this pair, the change in corr[l]:

where coeff_i(l) is the coefficient of h[i] in corr[l] as derived above.

The new max of active constraints:

This is a 1D minimax of affine functions! The optimal δ is at a breakpoint or boundary.

The boundary for δ:

    h = h.copy()
    best_c = _c5(h)
    best_h = h.copy()
    rng = np.random.RandomState(123)
    
    while time.time() < deadline:
        corr = np.correlate(h, 1.0 - h, mode='full')
        mx = float(corr.max())
        c = mx * (2.0 / n)
        if c < best_c:
            best_c = c
            best_h = h.copy()
        
        order = np.argsort(corr)[::-1]
        active = order[:T_act]
        active_vals = corr[active].copy()
        
        # Try random pairs
        n_pairs = 200
        for _ in range(n_pairs):
            i = rng.randint(n)
            j = rng.randint(n)
            if i == j:
                continue
            
            # Compute coefficients for active lags
            ci = np.zeros(T_act)
            cj = np.zeros(T_act)
            for idx, l in enumerate(active):
                # coeff of h[i] in corr[l]
                lj_i = l - i
                if 0 <= lj_i < n:
                    if lj_i != i:
                        ci[idx] = 1.0 - 2.0 * h[lj_i]
                    else:
                        ci[idx] = 1.0 - 2.0 * h[i]  # approximately linear
                # coeff of h[j] in corr[l]
                lj_j = l - j
                if 0 <= lj_j < n:

                        cj[idx] = 1.0 - 2.0 * h[lj_j]
                    else:
                        cj[idx] = 1.0 - 2.0 * h[j]

            if np.all(np.abs(b) < 1e-15):
                continue

            d_lo = max(-h[i], h[j] - 1.0)
            d_hi = min(1.0 - h[i], h[j])

            # Breakpoints: (active_vals[j] - active_vals[i]) / (b[i] - b[j])
            candidates = [d_lo, d_hi, 0.0]

                for jj in range(ii + 1, T_act):

                        if d_lo <= tp <= d_hi:
                            candidates.append(tp)
            
            best_d = 0.0
            best_mx = float(corr[active].max())
            for d in candidates:
                vals = active_vals + b * d
                mx_d = np.max(vals)
                if mx_d < best_mx - 1e-12:  # require improvement
                    best_mx = mx_d
                    best_d = d
            
            if abs(best_d) > 1e-10:
                # Also check global max (not just active set)
                h[i] += best_d
                h[j] -= best_d
                new_corr = np.correlate(h, 1.0 - h, mode='full')
                new_mx = float(new_corr.max())
                if new_mx < mx - 1e-12:
                    corr = new_corr
                    mx = new_mx
                    c = mx * (2.0 / n)
                    if c < best_c:
                        best_c = c
                        best_h = h.copy()
                else:
                    h[i] -= best_d
                    h[j] += best_d
        
        # Periodic repair
        if h.sum() != n * 0.5:
            h = _repair(h, n)
    
    return best_h, best_c

import numpy as np
import time

def _repair(h, n):
    t = n * 0.5
    h = np.clip(h, 0.0, 1.0).copy()
    s = h.sum()
    if s < 1e-15:
        return np.full(n, 0.5)
    for _ in range(100):
        h *= t / s
        np.clip(h, 0.0, 1.0, out=h)
        s = h.sum()
        if abs(s - t) < 1e-14:
            break
    d = t - h.sum()
    if abs(d) > 1e-12:
        order = np.argsort(1.0 - h) if d > 0 else np.argsort(h)
        for i in order:
            if d > 0:
                a = min(d, 1.0 - h[i]); h[i] += a; d -= a
            else:
                a = min(-d, h[i]); h[i] -= a; d += a
            if abs(d) < 1e-13:
                break
    return h

def _proj(v, S):
    x = np.array(v, dtype=float, copy=True)
    x += (S - x.sum()) / x.size
    for _ in range(30):
        np.clip(x, 0.0, 1.0, out=x)
        d = S - x.sum()
        if abs(d) < 1e-13:
            break
        m = (x < 1.0) if d > 0 else (x > 0.0)
        c = m.sum()
        if c == 0:
            break
        x[m] += d / c
    return x

def _c5(h):
    n = len(h)
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * (2.0 / n))

def _fft_size(n):
    m = 2 * n - 1
    N = 1
    while N < m:
        N <<= 1
    return N

def _pn(h):
    n = len(h)
    N = _fft_size(n)
    H = np.fft.rfft(h, N)
    ac = np.fft.irfft(H * np.conj(H), N).real[:n]
    pref = np.zeros(n + 1)
    np.cumsum(h, out=pref[1:])
    total = pref[n]
    P = np.empty(n)
    P[0] = total - ac[0]
    Nv = np.zeros(n)
    if n > 1:
        idx = np.arange(1, n)
        P[idx] = pref[n - idx] - ac[idx]
        Nv[idx] = total - pref[idx] - ac[idx]
        mx = max(float(np.max(P)), float(np.max(Nv)))
    else:
        mx = float(P[0])
    return P, Nv, mx

def _soft_val(h, a):
    P, Nv, mx = _pn(h)
    n = len(h)
    dx = 2.0 / n
    e = np.exp(np.clip(a * (P[0] - mx), -400, 0))
    if n > 1:
        e += np.exp(np.clip(a * (P[1:] - mx), -400, 0)).sum()
        e += np.exp(np.clip(a * (Nv[1:] - mx), -400, 0)).sum()
    return dx * (mx + np.log(e) / a)

def _grad_weights(h, wP, wN):
    n = len(h)
    dx = 2.0 / n
    u = np.zeros(n)
    if n > 1:
        u[1:] = wP[1:] + wN[1:]
    cp = np.zeros(n)
    cn = np.zeros(n)
    if n > 1:
        cp[1:] = np.cumsum(wP[1:])
        cn[1:] = np.cumsum(wN[1:])
    linP = cp[n - 1::-1]
    linN = cn
    q = np.zeros(n)
    if n > 1 and np.any(u[1:]):
        Nf = _fft_size(n)
        H = np.fft.rfft(h, Nf)
        R = np.fft.irfft(H * np.fft.rfft(u[::-1], Nf), Nf)
        L = np.fft.irfft(H * np.fft.rfft(u, Nf), Nf)
        q = -(R[n - 1:2*n - 1].real + L[:n].real)
    return dx * (wP[0] * (1.0 - 2.0 * h) + linP + linN + q)

def _soft_grad(h, a):
    P, Nv, mx = _pn(h)
    n = len(h)
    wP = np.zeros(n)
    wN = np.zeros(n)
    e0 = np.exp(np.clip(a * (P[0] - mx), -400, 0))
    tot = e0
    if n > 1:
        ep = np.exp(np.clip(a * (P[1:] - mx), -400, 0))
        en = np.exp(np.clip(a * (Nv[1:] - mx), -400, 0))
        tot += ep.sum() + en.sum()
        if tot <= 0:
            tot = 1.0; e0 = 1.0
        wP[0] = e0 / tot
        wP[1:] = ep / tot
        wN[1:] = en / tot
    else:
        wP[0] = 1.0
    return _grad_weights(h, wP, wN)

def _fista(h0, alpha, max_t, L0=10.0):
    if max_t <= 0:
        h = h0.copy()
        return h, h.copy(), _c5(h)
    n = len(h0)
    S = n * 0.5
    t0 = time.time()
    h = _repair(h0, n)
    hp = h.copy(); y = h.copy(); t = 1.0
    fy = _soft_val(h, alpha); fh = fy
    best_h = h.copy(); best_c = _c5(h)
    stale = 0; Lc = L0
    for it in range(500000):
        if time.time() - t0 > max_t:
            break
        if it:
            tn = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t * t))
            y = h + ((t - 1.0) / tn) * (h - hp)
            t = tn
            if y.min() < -1e-5 or y.max() > 1.0 + 1e-5 or abs(y.sum() - S) > 1e-8:
                y = _proj(y, S)
            fy = _soft_val(y, alpha)
        else:
            y = h; fy = fh
        g = _soft_grad(y, alpha)
        step = 1.0 / max(Lc, 1e-12)
        accepted = False
        for _ in range(14):
            xn = _proj(y - step * g, S)
            fx = _soft_val(xn, alpha)
            dv = xn - y
            rhs = fy + float(np.dot(g, dv)) + 0.5 * (1.0 / step) * float(np.dot(dv, dv))
            if fx <= rhs + 1e-11:
                accepted = True
                break
            step *= 0.5
        Lc = 1.0 / max(step, 1e-12)
        if accepted:
            hp = h; h = xn; fh = fx; stale = 0
            Lc = max(Lc * 0.85, 1.0)
            if it % 10 == 0:
                c = _c5(h)
                if c < best_c:
                    best_c = c; best_h = h.copy()
        else:
            stale += 1; hp = h; y = h; t = 1.0; fy = fh
            Lc = max(Lc * 0.5, 1.0)
            if stale > 12:
                break
    c = _c5(h)
    if c < best_c:
        best_c = c; best_h = h.copy()
    return h, best_h, best_c

def _coeff(h, j, l, n):
    lj = l - j
    if 0 <= lj < n:
        return 1.0 - 2.0 * h[lj]
    return 0.0

def _paired_cd(h, deadline, rng, T_act=10, n_pairs=300):
    n = len(h)
    h = h.copy()
    best_c = _c5(h)
    best_h = h.copy()
    full = 2 * n - 1
    while time.time() < deadline:
        corr = np.correlate(h, 1.0 - h, mode='full')
        mx = float(corr.max())
        c = mx * (2.0 / n)
        if c < best_c:
            best_c = c
            best_h = h.copy()
        order = np.argsort(corr)[::-1]
        active = order[:T_act]
        av = corr[active].copy()
        improving = False
        for _ in range(n_pairs):
            i = rng.randint(n)
            j = rng.randint(n)
            if i == j:
                continue
            ci = np.array([_coeff(h, i, l, n) for l in active])
            cj = np.array([_coeff(h, j, l, n) for l in active])
            b = ci - cj
            if np.all(np.abs(b) < 1e-15):
                continue
            d_lo = max(-h[i], h[j] - 1.0)
            d_hi = min(1.0 - h[i], h[j])
            if d_hi - d_lo < 1e-12:
                continue
            cands = [d_lo, d_hi, 0.0]
            for ii in range(T_act):
                for jj in range(ii + 1, T_act):
                    bb = b[ii] - b[jj]
                    if abs(bb) > 1e-15:
                        tp = (av[jj] - av[ii]) / bb
                        if d_lo - 1e-9 <= tp <= d_hi + 1e-9:
                            cands.append(max(d_lo, min(d_hi, tp)))
            best_d = 0.0
            best_mx = float(np.max(av))
            for d in cands:
                vals = av + b * d
                m2 = float(np.max(vals))
                if m2 < best_mx - 1e-13:
                    best_mx = m2
                    best_d = d
            if abs(best_d) > 1e-11:
                h[i] += best_d
                h[j] -= best_d
                nc = np.max(np.correlate(h, 1.0 - h, mode='full'))
                if nc < mx - 1e-13:
                    corr = np.correlate(h, 1.0 - h, mode='full')
                    mx = float(np.max(corr))
                    improving = True
                    if not (0 <= h[i] <= 1 and 0 <= h[j] <= 1):
                        h[i] -= best_d; h[j] += best_d
                        mx = -mx  # revert flag
                else:
                    h[i] -= best_d
                    h[j] += best_d
        if not improving:
            # try larger steps
            for _ in range(50):
                i = rng.randint(n)
                j = rng.randint(n)
                if i == j:
                    continue
                d = (rng.random() - 0.5) * 0.1
                if h[i] + d < 0 or h[i] + d > 1 or h[j] - d < 0 or h[j] - d > 1:
                    continue
                h[i] += d; h[j] -= d
                nc = float(np.max(np.correlate(h, 1.0 - h, mode='full')))
                if nc < mx - 1e-13:
                    mx = nc
                else:
                    h[i] -= d; h[j] += d
        h = _repair(h, n)
    return best_h, best_c

def _sa_search(h0, rng, deadline, T_act=6):

    while time.time() < deadline:
        frac = min(1.0, (time.time() - t_start) / total_t)

        k_act = int(np.argmax(corr)) - (n - 1)
        if rng.random() < 0.8:

def _resample(h, m):
    n = len(h)
    if n == m:
        return _repair(h, n)
    x0 = (np.arange(n) + 0.5) * (2.0 / n)
    x1 = (np.arange(m) + 0.5) * (2.0 / m)
    out = np.interp(x1, x0, h)
    return _proj(out, m * 0.5)

    end5 = t0 + budget_s - 30.0
    if end5 > time.time():
        best, best_c = _sa_search(best, rng, end5, 8)
    # Phase 6: Final paired CD
    end6 = t0 + budget_s - 2.0
    if end6 > time.time():
        best, best_c = _paired_cd(best, end6, rng, 15, 200)
    # Final variants
    for hh in (1.0 - best, best[::-1], 0.5 + 0.5*(best - best[::-1]), 0.5 + 0.5*(best + best[::-1] - 1.0)):
        h2 = _proj(hh, len(hh) * 0.5)
        c = _c5(h2)
        if c < best_c:
            best = h2; best_c = c
    best = _repair(best, len(best))
    best_c = _c5(best)
    return best, best_c, len(best)
