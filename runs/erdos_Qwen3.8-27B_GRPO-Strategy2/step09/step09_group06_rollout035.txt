For the 1D coordinate optimization, here's the key: if I change h[i] by δ, the correlation vector changes linearly:
c_new[p] = c_old[p] + δ * g_i[p]

where g_i[p] = dc_p/dh[i] (computed in O(n) time).

The new C₅ = max_p (c_old[p] + δ * g_i[p]) * dx

To minimize this over δ (with 0 ≤ h[i]+δ ≤ 1), I need to find the δ that minimizes the max of linear functions. This can be done by:
1. Compute all values c_old[p] + δ * g_i[p] at δ=0
2. The lags with values near the max are the "active" ones
3. As δ changes, the active set changes
4. The minimum of the max is at a "breakpoint" where two active lags have equal value

Simple approach: ternary search or golden section on the 1D convex function.

Even simpler: since the function is piecewise linear with at most 2n-1 breakpoints, I can:
1. Compute f(δ) = max_p (c_old[p] + δ*g_i[p]) for δ in [max(-h[i], -1+h[i]), min(1-h[i], -h[i])]
   Wait: 0 ≤ h[i]+δ ≤ 1, so δ ∈ [-h[i], 1-h[i]]
2. The breakpoints occur where c_old[p1] + δ*g_i[p1] = c_old[p2] + δ*g_i[p2], i.e., δ = (c_old[p2]-c_old[p1])/(g_i[p1]-g_i[p2])
3. Evaluate f at all breakpoints (plus endpoints), take the minimum

This is O(n²) per coordinate in the worst case (n breakpoints, evaluate max at each), but typically much less. For n=560, that's 560 breakpoints × 1120 lags = 627,200 operations per coordinate. For all 560 coordinates: 351M operations. That might be too slow.

- δ = 0 (current)
- δ = -h[i] (set h[i]=0)
- δ = 1-h[i] (set h[i]=1)
- A few values in between
- The "bisection" point where the two most active lags cross

Actually, the fastest approach for this 1D problem: 
- The objective is convex piecewise-linear in δ
- Use subgradient method: at the current δ, compute subgradient (set of slopes of active lags)
- If 0 is in the subgradient, we're at the optimum
- Otherwise, move in the direction opposite to the subgradient

        s = alpha * (c[top] - cm)
        s = np.clip(s, -500, 0)
        w = np.exp(s)
        w /= w.sum()
        g = np.zeros(n_l)
        dx_val = 2.0 / n_l
        for ii, p in enumerate(top):
            L = p - (n_l - 1)
            wk = w[ii] * dx_val
            if L >= 0:
                g[:n_l - L] += wk * (1.0 - x[L:])
                g[L:] -= wk * x[:n_l - L]
            else:
                M = -L
                g[M:] += wk * (1.0 - x[:n_l - M])
                g[:n_l - M] -= wk * x[M:]
        return g
    
    for alpha, topk, maxit in alpha_seq:
        if _el() > budget_s * 0.4:
            break
        bnds = [(0.0, 1.0)] * n
        cons = [{'type': 'eq', 'fun': lambda x: x.sum() - n * 0.5,
                 'jac': lambda x: np.ones(n)}]
        try:
            res = minimize(_slsqp_obj, best_h, jac=_slsqp_grad,
                         args=(alpha, topk), method='SLSQP',
                         bounds=bnds, constraints=cons,
                         options={'maxiter': maxit, 'ftol': 1e-20, 'maxls': 20})
            h_new = _proj(res.x, n * 0.5)
            c5n = _eval(h_new)
            if c5n < best_c5:
                best_c5 = c5n
                best_h = h_new.copy()
        except Exception:
            pass
    
    # Phase 3: Nesterov gradient (multiple configs)
    nesterov_configs = [
        (10000, 20, 2000, 0.005),
        (100000, 30, 1500, 0.003),
        (1000000, 40, 1000, 0.001),
        (10000000, 50, 800, 0.0005),
    ]
    for alpha, topk, steps, lr in nesterov_configs:
        if _el() > budget_s * 0.7:
            break
        h_new, c5n = _nesterov_grad(best_h, alpha, topk, steps, lr, rng)
        if c5n < best_c5:
            best_c5 = c5n
            best_h = h_new.copy()

    if _el() < budget_s - 60:
        h_cd = best_h.copy()

            if c5_cd < best_c5:
                best_c5 = c5_cd
