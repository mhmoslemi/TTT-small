Phase 2 (300s): Projected gradient with momentum, increasing alpha

Phase 4 (200s): Random restart + short re-optimization

For Phase 2, I'll use a "restart" strategy: if progress stalls, increase momentum and decrease step size.

For Phase 3, I'll use a "cyclic" approach: sweep through coordinates one by one, computing the optimal value for each.

For the coordinate optimal: given all other coordinates fixed, the objective as a function of h[j] is:
f(t) = max_k ∑_i h[i](1-h[i+k]) * dx where h[j] = t

This is the max of linear functions of t (for fixed other h values), so it's a piecewise-linear convex function in t. The optimal t is at a "kink" point, which is where two of the linear functions cross.

But computing this exactly for all 560 coordinates × 560 lags is O(n²) per coordinate, O(n³) total. Too slow.

Instead, I'll use a gradient-based 1D optimization: for coordinate j, take a few gradient steps in the 1D direction.

Actually, for a single coordinate h[j], the change in C(L) is:
ΔC(L) = dx * [(1-h[j+L]) - h[j-L]] * (h_new[j] - h[j])  (for appropriate L)

Wait, this isn't quite right because changing h[j] affects C(L) for all L. But for a small change δ in h[j]:
ΔC(L) ≈ dx * δ * [∂C(L)/∂h[j]]

And the max increases by at most the max over active L of the positive part of ΔC(L).

So a good 1D step for coordinate j is:
- Compute ∂C(L)/∂h[j] for all active L
- Find the direction (increase or decrease h[j]) that reduces the max most
- Take a small step

This is essentially what the gradient method does, but applied one coordinate at a time.

import numpy as np

import time

def _eval(h):
    n = len(h)
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * 2.0 / n)

def _eval_vec(h):
    n = len(h)
    return np.correlate(h, 1.0 - h, mode='full') * (2.0 / n)

def _repair(h, n):
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    if s < 1e-12:
        return np.full(n, 0.5)
    for _ in range(300):
        h *= target / s
        h = np.clip(h, 0.0, 1.0)
        s = h.sum()
        if abs(s - target) < 1e-14:
            break
    diff = target - h.sum()
    if abs(diff) > 1e-14:
        order = np.argsort(1.0 - h) if diff > 0 else np.argsort(h)
        for idx in order:
            if diff > 0:
                a = min(diff, 1.0 - h[idx])
                h[idx] += a
                diff -= a
            else:
                a = min(-diff, h[idx])
                h[idx] -= a
                diff += a
            if abs(diff) < 1e-14:
                break
    return h

def _proj(h, target):

        if np.clip(h - mid, 0, 1).sum() > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) * 0.5, 0, 1)

def _smooth_obj(x, alpha, ml):
    n = len(x)

    m = c.max()
    idx = np.argpartition(-c, ml - 1)[:ml]
    s = np.clip(alpha * (c[idx] - m), -400, 400)
    s -= s.max()
    return m + np.log(np.exp(s).sum()) / alpha

def _smooth_grad(x, alpha, ml):
    n = len(x)

    c = np.correlate(x, 1.0 - x, mode='full') * dx
    m = c.max()

def _slsqp(h_init, n, alpha, ml, maxiter, ftol):
    bnds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x: x.sum() - n * 0.5,
             'jac': lambda x: np.ones(n)}]
    try:
        res = minimize(_smooth_obj, h_init, jac=_smooth_grad,
                       args=(alpha, ml), method='SLSQP',
                       bounds=bnds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': ftol, 'maxls': 40})
        return _repair(res.x, n)
    except Exception:
        return h_init

def _momentum_pg(h, n, alpha_start, alpha_end, ml, total_steps, lr0, mom):
    v = np.zeros(n)
    best_c = _eval(h)
    best_h = h.copy()

    stall = 0
    for it in range(total_steps):
        alpha = alpha_start * (alpha_end / alpha_start) ** (it / max(1, total_steps - 1))
        ml_cur = min(ml, max(10, int(ml * (0.3 + 0.7 * it / total_steps))))
        g = _smooth_grad(h, alpha, ml_cur)
        v = mom * v - lr * g
        h_new = _proj(h + v, n * 0.5)
        c_new = _eval(h_new)

            best_c = c_new

            stall = 0
        else:

                v *= 0.5

                lr = min(step * 1.05, lr0 * 10.0)
                taken = True
                break
