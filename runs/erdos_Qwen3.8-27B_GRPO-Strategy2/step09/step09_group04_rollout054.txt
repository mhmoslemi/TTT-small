**Coordinate descent idea**:
For a fixed i, the objective as a function of h[i] (with all other h[j] fixed) is:
f(h[i]) = max_k [c[k] - h[i]*h[i... ] + h[i]*(1-h[i-k]) - ...]

This is complicated because h[i] appears in c[k] for multiple k values (as both h[i] and h[i-k] and h[i+k]).

Actually, for a fixed i, h[i] appears in c[k] for:
- k = j-i (where h[i] is the first factor: h[j] with i=j... no)
- Let me think again. h[i] appears in c[k] = sum_m h[m]*(1-h[m-k]) when:
  - m = i (first factor): contributes h[i]*(1-h[i-k])
  - m-k = i, i.e., m = i+k (second factor): contributes h[i+k]*(1-h[i]) 

So c[k] depends on h[i] through: h[i]*(1-h[i-k]) + h[i+k]*(1-h[i]) (for valid indices)
= h[i] - h[i]*h[i-k] + h[i+k] - h[i+k]*h[i]
= h[i] + h[i+k] - h[i]*(h[i-k] + h[i+k])

So ∂c[k]/∂h[i] = 1 - h[i-k] - h[i+k] (for valid indices)
And c[k] is quadratic in h[i]: c[k] = h[i] + h[i+k] - h[i]*(h[i-k] + h[i+k])
= h[i] * (1 - h[i-k] - h[i+k]) + h[i+k]

This is LINEAR in h[i]! (The coefficient is 1 - h[i-k] - h[i+k], which doesn't depend on h[i].)

Wait, that's great! For a fixed k, c[k] is linear in each individual h[i]. This means:
f(h) = max_k c[k] is the max of functions that are each linear in each h[i] separately.

So coordinate descent works! For a fixed h[0], h[1], ..., h[i-1], h[i+1], ..., h[n-1], the function f as a function of h[i] alone is:
f(h[i]) = max_k [a_k * h[i] + b_k]

where a_k = ∂c[k]/∂h[i] (a constant for fixed other h values) and b_k = c[k] - h[i]*a_k.

This is the max of linear functions of h[i], which is a convex piecewise-linear function! We can minimize it in O(M) where M is the number of relevant k values.

The minimum of max_k (a_k * x + b_k) over x ∈ [0,1] occurs at:
- x = 0 if all a_k > 0
- x = 1 if all a_k < 0
- Otherwise, at a point where two lines cross: a_k * x + b_k = a_l * x + b_l

This is like finding the lower envelope of lines... actually the upper envelope (max) and finding its minimum.

For a max of lines, the minimum is at a "breaking point" where the active set changes. We can find it by:
1. Computing all (a_k, b_k) pairs
2. Finding the x ∈ [0,1] that minimizes max_k (a_k*x + b_k)

This is a 1D linear programming problem! We can solve it in O(M log M) or just O(M) by finding the minimum of the piecewise-linear function.
