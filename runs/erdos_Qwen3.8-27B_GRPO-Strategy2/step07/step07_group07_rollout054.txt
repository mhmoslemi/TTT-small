Let me think about a fundamentally different approach:

**Coordinate descent on lags**: 
- For each lag k, the correlation c_k is a function of h.
- If we fix all lags except k, the problem of minimizing c_k alone is:
  min_h c_k s.t. h in [0,1]^n, sum(h) = n/2, and c_j = fixed for j ≠ k
  
  This is a convex problem (c_k is bilinear in h, but fixing other constraints makes it... actually not obviously convex).

Actually, c_k = sum_i h[i+sh]*(1-h[i]) is a quadratic function of h (it has h*h terms). So minimizing it with the box and sum constraints is a QP! We could solve it exactly for each lag.

But the constraint that other c_j are fixed is not simple. However, we could just minimize c_k while keeping the sum constraint, and hope that other lags don't increase too much.

This is like a "greedy" approach: at each step, pick the lag with the highest correlation and minimize it.

Actually, this is similar to what the top-k Nesterov does, but instead of a gradient step, we could do an exact minimization of the top lag.

Let me think about minimizing c_k = sum_i h[i+sh]*(1-h[i]) subject to 0≤h≤1, sum(h)=n/2.

This is: c_k = sum_i h[i+sh] - sum_i h[i+sh]*h[i]

= (sum of h over the shifted range) - (sum of products)

The first term is linear in h, the second is a sum of products of pairs. This is a quadratic optimization problem.

For the "forward" case (sh ≥ 0):
c_k = sum_{i=0}^{n-1-sh} h[i+sh] - sum_{i=0}^{n-1-sh} h[i+sh]*h[i]
    = sum_{j=sh}^{n-1} h[j] - sum_{j=sh}^{n-1} h[j]*h[j-sh]

This is a QP: minimize -sum_j (1 - 0.5*h[j-sh]) * h[j] + const... 

Actually, it's: min_h sum_j h[j]*(1-h[j-sh]) subject to box and sum constraints.

This is a non-convex QP (the h*h terms make it indefinite). So we can't just use a QP solver directly.

However, if sh is large enough, the pairs (j, j-sh) don't overlap much, and the problem is approximately separable.

I think a practical approach is:
1. For the top lag k, compute the gradient
2. Take a large gradient step in the direction that reduces c_k
3. Project to [0,1] and sum constraint
4. Check if c_k decreased; if not, halve the step

This is essentially what the Nesterov top-k does, but let me make it more aggressive.

    if abs(h.sum() - t) > 1e-8:
        h = _proj_sum(h, t)

def _eval(h):

    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * 2.0 / n)

def _corrs(h):
