**Key insight for improvement**: The previous code's `_pair_cd` uses random pairs. But the gradient information tells us which directions are most promising. Let me use a **gradient-informed pair selection**:

1. Compute the subgradient of C₅ (average over top-m lags)

def _subgrad_top_lags(h, c, top_m=5):
    n = len(h)
    top_lags = np.argpartition(c, -top_m)[-top_m:]
    g = np.zeros(n)
    for lag in top_lags:
        shift = lag - (n - 1)
        dx = 2.0 / n
        gl = np.zeros(n)
        if shift >= 0:
            m = n - shift
            gl[:m] += (1.0 - h[shift:shift+m])
            gl[shift:] -= h[:m]
        else:
            s = -shift
            m = n - s
            gl[:m] += (1.0 - h[:m])
            gl[s:] -= h[s:s+m]
        g += gl
    return g * dx / top_m, top_lags
