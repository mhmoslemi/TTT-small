C'[m] = C[m] + d*g[m] + d²*s[m]

where g[m] and s[m] are computed from the OLD values of h. This is exact (not an approximation) because C is quadratic in h! So the bisection on C + d*g + d²*s is finding the exact minimizer for this pair.

The issue is that g[m] depends on h, which is the old h. Since we're doing coordinate descent (one pair at a time), this is correct.
