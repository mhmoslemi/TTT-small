def _grad_w(h, w):

    dx = 2.0 / n
    g = np.zeros(n)

            m = n - sp
            g[sp:] += wk * (1.0 - h[:m])

    return g

   - ∂c_k/∂h[i] can be computed from the current h values

Let me define: for a given shift sh = n-1-k:
If sh ≥ 0:
  c_k = Σ_{j=0}^{n-1-sh} h[j](1-h[j+sh]) * dx
  ∂c_k/∂h[i] = dx * [(1-h[i+sh]) if i ≤ n-1-sh, else 0] + dx * [-h[i-sh] if i ≥ sh, else 0]

If sh < 0, sp = -sh:
  c_k = Σ_{j=sp}^{n-1} h[j](1-h[j-sp]) * dx
  ∂c_k/∂h[i] = dx * [(1-h[i-sp]) if i ≥ sp, else 0] + dx * [-h[i+sp] if i ≤ n-1-sp, else 0]

So for each i, I can compute the vector A = ∂c/∂h[i] in O(n) time.

Then c_new = c + δ * A where δ = new_h[i] - old_h[i].

The objective is max(c_new) = max(c + δ*A). This is a convex piecewise linear function of δ.

I can find the minimum by:
- The function f(δ) = max_k (c_k + δ*A_k) is convex in δ
- f'(δ) = A_{k*(δ)} where k*(δ) = argmax_k (c_k + δ*A_k)
- Minimum is where f'(δ) = 0 or at boundary

For a quick solution: evaluate f at δ = 0, and at the δ where the top 1 or 2 c_k values cross.

            for idx in range(2*n-1):

                if sh >= 0:
                    m = n - sh
                    a = 0.0
                    if i < m: a += (1.0 - h[i+sh])
                    if i >= sh: a -= h[i-sh]

                else:

                    m = n - sp
                    a = 0.0
                    if i >= sp: a += (1.0 - h[i-sp])
                    if i <= m-1: a -= h[i+sp]
                    A[idx] = a * dx

            lo_d = -h[i]
            hi_d = 1.0 - h[i]

            # At the optimum, 0 is in the subgradient

            # Simple approach: bisection on f'
            # f'(d) = A[k*(d)] where k*(d) = argmax(c + d*A)
            # This is non-decreasing (since as d increases, modes with larger A become dominant)
            
            # Actually this isn't quite right. Let me just do a grid search.

                if f_val < best_f:

                h[i] = np.clip(h[i], 0, 1)
