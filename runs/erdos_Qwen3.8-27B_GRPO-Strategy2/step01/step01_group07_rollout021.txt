Actually, let me reconsider the approach. The key question is: what's the theoretical minimum C₅?

For a continuous h: [0,2] → [0,1] with ∫h = 1:
C₅ = max_k ∫₀² h(x)(1-h(x+k)) dx (with appropriate boundary handling)

If h is periodic with period 1 (i.e., h(x+1) = h(x)), then for k=1:
∫₀² h(x)(1-h(x+1)) dx = ∫₀² h(x)(1-h(x)) dx = ∫₀² h(x) - h(x)² dx

By Cauchy-Schwarz: ∫h² ≥ (∫h)²/2 = 1/2
So ∫h - ∫h² ≤ 1 - 1/2 = 1/2.
And ∫h(1-h) = 1 - ∫h².

To minimize ∫h(1-h) over k, we'd want ∫h² to be as large as possible while keeping ∫h = 1. Max of ∫h² for h ∈ [0,1] is 1 (when h is 0/1). So min of ∫h(1-h) over k is... well, it depends on the structure.

For a step function that's 1 on a set A and 0 elsewhere, with |A| = 1:
∫ h(x)(1-h(x+k)) dx = |A ∩ (A+k)^c| = |A| - |A ∩ (A+k)| = 1 - |A ∩ (A+k)|
So C₅ = max_k (1 - |A ∩ (A+k)|) = 1 - min_k |A ∩ (A+k)|

For a "good" set A of measure 1 in [0,2], we want min_k |A ∩ (A+k)| to be as large as possible.

If A = [0,1], then |(0,1) ∩ (k,k+1)| varies from 1 (at k=0) to 0 (at k=1 or k=2). So C₅ = 1 - 0 = 1. Bad.

If A is "spread out", like every other bit (n-thing in the harmonic analysis world), we can do better.

For a binary sequence of length n with n/2 ones: C₅ ≈ (n/2) * max_k (1 - density_k) / n where density_k is the autocorrelation at shift k.
