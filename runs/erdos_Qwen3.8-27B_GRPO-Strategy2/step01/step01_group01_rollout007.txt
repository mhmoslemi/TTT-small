**Algorithm: Averaged subgradient method**

1. Initialize h from initial_h_values
2. For iter in 1..T:
   a. Compute c = np.correlate(h, 1-h, mode='full')
   b. Find top K lags
   c. With probability proportional to c[j]^2 (or just pick the max), select lag j
   d. Compute subgradient g for that lag
   e. Update: h ← h - alpha * g (projected to constraint set)
   f. Store iterate
3. Return averaged iterate (or best iterate)

The step size alpha can be adaptive.

1. Clip to [0,1]
2. Adjust sum by adding a constant to all elements, then clip again (iterate)

Actually, the projection onto {0≤h≤1, sum(h)=S} is:

We can find λ by bisection.

    starts.append(0.5 + 0.3 * np.cos(2.0 * np.pi * x_grid / 1.3))
    starts.append(0.5 + 0.25 * np.sin(4.0 * np.pi * x_grid))
    starts.append(np.where(x_grid < 1.0, 1.0, 0.0).astype(float))
    starts.append(1.0 - np.abs(x_grid - 1.0))
    rq = np.random.dirichlet(np.ones(n) * 0.5)
    starts.append(rq * n)

    per_start_budget = (dl4 - time.time()) / max(len(starts), 1)
    for s in starts:
        if time.time() > dl4 or per_start_budget < 8:
            break
        s = project_constraint(s, target)
        dl_s = time.time() + per_start_budget * 0.6
        hs, vs = nesterov_subgrad(s, n, target, 80000, dl_s, width=5, step_scale=2.0)
        if vs < best_c5:
            best_c5, best_h = vs, hs
        if time.time() < dl4 - 5:
            hs2 = lbfgs_polish(hs, n, target, dl4, t_smooth=400.0)
            val = compute_c5(hs2)
            if val < best_c5:
                best_c5, best_h = val, hs2

    # Phase 5: Final refinement (15% budget)
    dl5 = t0 + budget_s * 0.97
    if time.time() < dl5:
        h5, v5 = nesterov_subgrad(best_h, n, target, 100000, min(dl5 - 10, time.time() + (dl5 - time.time()) * 0.5), width=3, step_scale=1.0)
        if v5 < best_c5:
            best_c5, best_h = v5, h5
    if time.time() < dl5 - 3:
        h5b = lbfgs_polish(best_h, n, target, dl5, t_smooth=1500.0)
        val = compute_c5(h5b)
        if val < best_c5:
            best_c5, best_h = val, h5b

    # Final constraint enforcement
    best_h = project_constraint(best_h, target)
    best_c5 = compute_c5(best_h)
    return (best_h, best_c5, n)
