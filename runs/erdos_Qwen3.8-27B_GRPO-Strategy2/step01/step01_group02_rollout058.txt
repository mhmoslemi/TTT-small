- If j-d is in [0, n-1-d] (i.e., j in [d, n-1]): contributes -h[j-d] [from -(1-h[i+d]) = h[i+d]... wait]

∂c(d)/∂h[j] = sum over all terms where j appears:
- j appears as h[i] when i = j (if j ≤ n-1-d): contributes (1-h[j+d])
- j appears as h[i+d] when i+d = j, i.e., i = j-d (if j-d ≥ 0 and j-d ≤ n-1-d, i.e., 0 ≤ j-d ≤ n-1-d, i.e., d ≤ j ≤ n-1): contributes -h[j-d]
