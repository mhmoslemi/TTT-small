def _repair(h, target):

        for i in idx:

                h[i] += a; diff -= a
            else:
                a = min(-diff, h[i])
                h[i] -= a; diff += a
            if abs(diff) < 1e-12:
                break
    return h

Let me think about a different strategy entirely. What if I use **Cvxpy** to solve a related convex problem?

The problem min max_m C[m] is non-convex (bilinear). But I can use a **successive convex approximation**:
1. Linearize C[m] at the current point h*: C[m] ≈ C_h*(m) + (h-h*)^T grad_C[m](h*)
2. Solve: min t s.t. linearized C[m] ≤ t for all m, 0≤h≤1, sum(h)=target
3. This is a LP! Solve with CVXPY.
4. Iterate.

The linearized problem is:
min t
s.t. C_h*(m) + grad_C[m](h*)^T (h - h*) ≤ t  for all m
     0 ≤ h ≤ 1
     sum(h) = target

This is a linear program with 2n-1 + 1 constraints, n+1 variables. Very fast!

And the gradient of C[m] w.r.t. h at h* is:
dC[m]/dh[i] = (1-h*[i-m+n-1]) * I(valid) + (-h*[i+m-n+1]) * I(valid)

Wait, let me be more careful. C[m] = sum_j h[j] * (1-h[j-m+n-1]) for valid j.
dC[m]/dh[i] = sum_j [δ(j,i)*(1-h[j-m+n-1]) + h[j]*(-δ(j-m+n-1, i))]
= (1-h[i-m+n-1]) * I(0≤i-m+n-1<n) + (-h[i+m-n+1]) * I(0≤i+m-n+1<n)

Hmm wait, the second term: j-m+n-1 = i → j = i+m-n+1. So the contribution is -h[i+m-n+1] if 0≤i+m-n+1<n.

Let me define: for each m, the gradient vector g_m has:
g_m[i] = (1-h[i-m+n-1]) * I(0≤i-m+n-1<n) + (-h[i+m-n+1]) * I(0≤i+m-n+1<n)

This is O(n) per m, O(n²) for all m. Very fast.

**Algorithm: Successive Linear Programming (SLP)**

1. Start with h0
2. For iteration = 1, 2, ...:
   a. Compute C[m] and grad_m for all m
   b. Solve LP: min t s.t. C_h*(m) + g_m^T(h-h*) ≤ t, 0≤h≤1, sum(h)=target
   c. If ||h_new - h*|| < tol: converged
   d. h* = h_new (or damped: h* = (1-λ)h* + λ h_new)
3. After convergence, do local polish

This should be much faster than SLSQP and find a better solution because it handles all 2n-1 constraints simultaneously in each step.

Let me implement this with CVXPY:

```python
import cvxpy as cp

def _solve_lp(h_star, dx, n, target):
    h = cp.Variable(n)
    t = cp.Variable()
    c_star = _corr(h_star)
    
    # Compute gradients
    grads = np.zeros((2*n-1, n))
    for m in range(2*n-1):
        for i in range(n):
            j1 = i - m + n - 1
            j2 = i + m - n + 1
            g = 0.0
            if 0 <= j1 < n:
                g += (1.0 - h_star[j1])
            if 0 <= j2 < n:
                g += (-h_star[j2])
            grads[m, i] = g
    
    constraints = [h >= 0, h <= 1, cp.sum(h) == target]
    for m in range(2*n-1):
        constraints.append(c_star[m] + grads[m, :].T @ (h - h_star) <= t)
    
    problem = cp.Problem(cp.Minimize(t), constraints)
    problem.solve(solver=cp.GLPK)
    return h.value, t.value
```

Wait, this LP has 2n+1 variables (h + t) and (2n-1) + 3 = 2n+2 constraints. For n=70, that's 141 variables and 142 constraints. Very small LP, solvable in milliseconds.

The issue is that the linearization may not be tight enough, requiring many iterations. But with damping, it should converge.
