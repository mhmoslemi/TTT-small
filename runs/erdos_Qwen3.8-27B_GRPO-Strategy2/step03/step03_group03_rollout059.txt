For a single coordinate h[p], the objective F(h) = max_k f_k(h) is the max of several bilinear functions. If I fix all other coordinates and vary h[p], each f_k becomes linear in h[p] (since h[p] appears at most linearly in each f_k). For a specific k, f_k as a function of h[p] (with other h fixed):
- If p is in the "valid range" for k: f_k = a * h[p] + b, linear
- The max over k gives a piecewise linear convex function
- Its minimum is at a breakpoint (where two f_k's cross) or at a boundary (0 or 1)

1. Compute the slope and intercept of f_k for all k
2. Find the minimum of max_k (slope_k * t + intercept_k) over t ∈ [0,1]
3. Set h[p] to the minimizer

So for each k, f_k as a function of t = h[p] is:

And we want to minimize max_k (C_k + slope_k * t) over t ∈ [0, 1].

This is a 1D piecewise linear minimization! The minimum of a max of linear functions occurs at a breakpoint (intersection of two lines) or at a boundary (0 or 1).

Algorithm for coordinate p:
1. For each lag m (0 to 2n-2), compute k = m-(n-1), slope_k, and C_k
2. Find t ∈ [0,1] that minimizes max_k (C_k + slope_k * t)
3. Set h[p] = t

Step 2 can be done by:
- Evaluating at t=0 and t=1
- Finding all intersection points t_ij where C_i + s_i*t = C_j + s_j*t, i.e., t = (C_j - C_i)/(s_i - s_j)
- Among all intersections in [0,1], evaluate the max and find the minimum
- Also check t=0 and t=1

This is O(n²) per coordinate (n lags, O(n²) pairs of lags for intersections). Total per pass: O(n³) = 70³ = 343000. Very fast!

def _coord_descent(h, n, k_max_active=20):
    """One pass of coordinate descent for the Erdos problem."""
    c = _corr(h)
    # Focus on top lags
    top_lags = np.argsort(c)[-k_max_active:]
    
    for p in range(n):
        old = h[p]
        # Compute for each active lag k: slope and intercept
        slopes = []
        intercepts = []
        for m in top_lags:
            k = m - (n - 1)
            # slope = 1 - h[p+k]*[valid] - h[p-k]*[valid]
            s = 1.0
            iv = p + k
            if 0 <= iv < n:
                s -= h[iv]
            iv = p - k
            if 0 <= iv < n:
                s -= h[iv]
            # intercept = f_k - h[p]*s
            # f_k = c[m] (current value)
            # But c[m] was computed with old h[p]. We need to adjust.
            # Actually, f_k = C_k + h[p]*slope_k, so C_k = f_k - h[p]*slope_k
            # But f_k = c[m] only if h[p] is the current value.
            # Since we're about to change h[p], let's compute C_k directly.
            # C_k = f_k(h with h[p]=0) ... this is hard to compute directly.
            # Instead: C_k = c[m] - old * s (since c[m] = C_k + old * s)
            C_k = c[m] - old * s
            slopes.append(s)
            intercepts.append(C_k)
        
        if not slopes:
            continue
        
        slopes = np.array(slopes)
        intercepts = np.array(intercepts)
        
        # Find t in [0,1] minimizing max_k (intercept_k + slope_k * t)
        # Candidate points: 0, 1, and intersection points
        candidates = [0.0, 1.0]
        for i in range(len(slopes)):
            for j in range(i+1, len(slopes)):
                ds = slopes[i] - slopes[j]
                if abs(ds) > 1e-12:
                    t = (intercepts[j] - intercepts[i]) / ds
                    if 0.0 <= t <= 1.0:
                        candidates.append(t)
        
        best_t = old
        best_val = np.max(intercepts + slopes * old)
        for t in candidates:
            val = np.max(intercepts + slopes * t)
            if val < best_val:
                best_val = val
                best_t = t
        
        if abs(best_t - old) > 1e-12:
            h[p] = best_t
    
    return h

Optimization: We can use a convex hull trick or binary search. The function g(t) = max_k (C_k + s_k * t) is convex in t. We can find its minimum in [0,1] by binary search (or ternary search) if we can evaluate g(t) and its subgradient quickly.

g(t) = max_k (C_k + s_k * t)
g'(t) = s_k* where k* is the argmax (or subgradient = convex hull of active s's)

Binary search: find t* where 0 ∈ ∂g(t*), i.e., min active slope ≤ 0 ≤ max active slope.

This is O(n) per evaluation (to find the max and its subgradient), and O(log(precision)) iterations. So O(n * log(1/eps)) per coordinate. Much faster!

```python
def _find_1d_min(slopes, intercepts, lo=0.0, hi=1.0, tol=1e-10):
    """Find t in [lo, hi] minimizing max_k (intercept_k + slope_k * t)."""
    # g(t) = max_k (intercept_k + slope_k * t) is convex in t
    # Binary search on the subgradient
    for _ in range(60):
        t = 0.5 * (lo + hi)
        vals = intercepts + slopes * t
        idx = np.argmax(vals)
        # Subgradient at t: the set of slopes achieving the max
        active_mask = np.abs(vals - vals[idx]) < 1e-9
        s_min = slopes[active_mask].min()
        s_max = slopes[active_mask].max()
        if s_min <= 0 <= s_max:
            break
        elif s_min > 0:
            hi = t  # g is increasing, go left
        else:
            lo = t  # g is decreasing, go right
    t_opt = 0.5 * (lo + hi)
    # Also check boundaries
    t_opt = max(lo, min(hi, t_opt))
    # Final check at t_opt and boundaries
    best_t = lo
    best_val = np.max(intercepts + slopes * lo)
    for t in (lo, hi, t_opt):
        v = np.max(intercepts + slopes * t)
        if v < best_val:
            best_val = v
            best_t = t
    return best_t
```

def _repair(h, n):
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    if s < 1e-12:
        return np.full(n, 0.5)
    h *= target / s
    h = np.clip(h, 0.0, 1.0)
    diff = target - h.sum()
    if abs(diff) > 1e-12:
        order = np.argsort(1.0 - h) if diff > 0 else np.argsort(h)
        for idx in order:
            if diff > 0:
                add = min(diff, 1.0 - h[idx])
            else:
                add = max(diff, h[idx] - 1.0)
            h[idx] += add
            diff -= add
            if abs(diff) < 1e-12:
                break
    return h
