    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    if s < 1e-12:
        return np.full(n, 0.5)
    if abs(s - target) > 1e-9:
        h *= target / s
        h = np.clip(h, 0.0, 1.0)
        diff = target - h.sum()
        if abs(diff) > 1e-12:
            order = np.argsort(1.0 - h) if diff > 0 else np.argsort(h)
            for idx in order:
                if diff > 0:
                    a = min(diff, 1.0 - h[idx])
                    h[idx] += a
                    diff -= a
                else:
                    a = min(-diff, h[idx])
                    h[idx] -= a
                    diff += a
                if abs(diff) < 1e-12:

def _grad_lag(h, k):

    n = len(h)
    dx = 2.0 / n
    g = np.zeros(n)
    sh = (n - 1) - k
    if sh >= 0:
        i1 = np.arange(n - sh)
        g[i1] += (1.0 - h[i1 + sh])
        if sh > 0:
            i2 = np.arange(sh, n)
            g[i2] -= h[i2 - sh]
    else:
        sp = -sh
        i1 = np.arange(sp, n)
        g[i1] += (1.0 - h[i1 - sp])
        i2 = np.arange(n - sp)
        g[i2] -= h[i2 + sp]

                        i2 = np.arange(n - sp)
                        gk[i2] -= h_try[i2 + sp]
                    g += gk[start:end]
                return g / len(idx)
            
            # Sum constraint for this block
            target_block = h[start:end].sum()
            
            res = minimize(obj, h_block, jac=jac, method='SLSQP',
                          bounds=bnds,
                          constraints=[{'type': 'eq', 'fun': lambda x: x.sum() - target_block,
                                       'jac': lambda x: np.ones(bs)}],
                          options={'maxiter': 50, 'ftol': 1e-10})
            
            if res.success and obj(res.x) < f:
                h[start:end] = res.x
                f = obj(res.x)
    return h, f

Wait, is minimizing the sum of top-k lags convex? Each lag is a bilinear form in h (since it's h * (1-h) = h - h²). So each lag is concave in h (since -h² is concave). Wait no:
h_i * (1 - h_j) = h_i - h_i * h_j

The derivative w.r.t. h_i is 1 - h_j, and the second derivative involves the product term. Actually, the Hessian of h_i * (1 - h_j) w.r.t. (h_i, h_j) is:
∂²/∂h_i² = 0
∂²/∂h_j² = 0
∂²/∂h_i∂h_j = -1

So the Hessian has a -1 in the (i,j) position and 0 elsewhere. This is indefinite, so the problem is not convex.

But if we only vary one variable at a time (coordinate descent), each coordinate step is linear (for h_i, the lag is h_i * (1-h_j) which is linear in h_i). So coordinate descent is well-defined!

**Coordinate descent with active set**:
- For each i, minimize the sum of top-k lags w.r.t. h[i], with h[i] ∈ [0,1]
- This is a piecewise linear minimization (since for fixed other h's, each lag is linear in h[i])
- The minimum of a sum of piecewise linear functions is... at a kink point or at 0 or 1

Actually, for fixed h[-i] and a given lag k, the contribution of h[i] to lag k is:
- If i is the first element: h[i] * (1 - h[i+sh])
- If i is the second element: h[i-sh] * (1 - h[i])
- Both: h[i]*(1-h[i+sh]) + h[i-sh]*(1-h[i]) = h[i] - h[i+sh] + h[i-sh] - 2*h[i]*h[i-sh]... 

No wait, the correlation at lag k is:
c[k] = sum_i h[i] * (1 - h[i + k - (n-1)])

For a fixed i, h[i] appears in c[k] as:
- First factor at position i: h[i] * (1 - h[i + k - (n-1)]) if i + k - (n-1) is valid
- Second factor at position i: h[i - k + (n-1)] * (1 - h[i]) if i - k + (n-1) is valid

So c[k] as a function of h[i] is:
A_k * h[i] + B_k * (1 - h[i]) = A_k * h[i] + B_k - B_k * h[i] = (A_k - B_k) * h[i] + B_k

where A_k = 1 - h[i + k - (n-1)] (if valid, else 0) and B_k = h[i - k + (n-1)] (if valid, else 0).

This is LINEAR in h[i]! So the sum of top-k lags is a piecewise linear function of h[i] (it changes slope when the active set changes).

The minimum of a linear function on [0,1] is at an endpoint (0 or 1), unless the slope is 0 (any value works).
