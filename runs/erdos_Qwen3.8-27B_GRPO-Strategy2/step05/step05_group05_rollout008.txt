- i appears in c[k] if 0<=i<n and 0<=i+sh_k<n (for the h[i+sh] term) or 0<=i<n (for the (1-h[i]) term, which is always true).
- Actually, i appears in c[k] if 0<=i+sh_k<n (contributing through h[i+sh_k]) OR 0<=i+sh_k<n is not needed for the (1-h[i]) part... 

Let me re-derive. c[k] = sum_{i': 0<=i'<n, 0<=i'+sh<n} h[i'+sh] * (1-h[i'])

h[m] appears in this sum if:
- m = i' + sh for some valid i': i.e., m - sh >= 0 and m - sh < n, and m < n (always) and m >= 0 (always). So 0 <= m-sh < n.
- m = i' for some valid i': i.e., m >= 0 (always) and m < n (always) and m+sh >= 0 and m+sh < n. So -m <= sh < n-m.

So for a given m (like i or j), the set of k values (or equivalently sh values) for which c[k] is affected is:
- sh in [m-n+1, n-1-m] (from the second condition, m+sh in [0,n-1], so sh in [-m, n-1-m])
  Wait: sh >= -m and sh <= n-1-m
- sh in [m-(n-1), m] (from the first condition, m-sh in [0,n-1], so m-(n-1) <= sh <= m)

Combined: sh in [max(m-n+1, -m), min(m, n-1-m)]

For m near the center (m ≈ n/2), this is roughly sh in [-(n/2-1), n/2-1], so about n values of sh, hence about n values of k.

So changing h[i] affects about n of the 2n-1 correlation values. For n=280, that's about 280 out of 559 values.

- Through h[i] as the "(1-h[i])" term: contributes -h[i+sh] if 0<=i+sh<n

import numpy as np
import time

def _repair(h, n):
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    if s < 1e-12:
        return np.full(n, 0.5)
    if abs(s - target) > 1e-9:
        h *= target / s
        h = np.clip(h, 0.0, 1.0)
        diff = target - h.sum()
        if abs(diff) > 1e-12:
            order = np.argsort(1.0 - h) if diff > 0 else np.argsort(h)
            for idx in order:
                if diff > 0:
                    a = min(diff, 1.0 - h[idx])
                    h[idx] += a
                    diff -= a
                else:
                    a = min(-diff, h[idx])
                    h[idx] -= a
                    diff += a
                if abs(diff) < 1e-12:
                    break
    return h

def _eval(h):
    n = len(h)
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * 2.0 / n)

def _tc_step(h, i, j, n_iter=25):
    n = len(h)
    s = h[i] + h[j]
    lo = max(0.0, s - 1.0)
    hi = min(1.0, s)
    if hi - lo < 1e-14:
        return
    a, b = lo, hi
    for _ in range(n_iter):
        m1 = a + (b - a) / 3.0
        m2 = b - (b - a) / 3.0
        h[i], h[j] = m1, s - m1
        f1 = np.max(np.correlate(h, 1.0 - h, mode='full'))
        h[i], h[j] = m2, s - m2
        f2 = np.max(np.correlate(h, 1.0 - h, mode='full'))
        if f1 < f2:
            b = m2
        else:
            a = m1
    x_opt = (a + b) / 2.0
    h[i] = min(1.0, max(0.0, x_opt))
    h[j] = min(1.0, max(0.0, s - h[i]))

def _cyclic_pass(h, n_iter, i_order=None):

    if i_order is None:
        i_order = list(range(n))
    for i in i_order:
        for j in range(i + 1, n):
