Now let me think about the gradient-informed incremental search:

At each step:
1. Compute the gradient of the current smoothed objective (or just the subgradient of the max)
2. Use |gradient| to weight the probability of selecting positions i and j
3. Try the move, accept if it improves

For the subgradient of max(c), it's just the dc/dh for the argmax lag. This is simpler than the full smoothed gradient.

Actually, for the incremental search, we don't need the full gradient. We just need to try moves and see if they work. The gradient helps us select which (i,j) pairs to try.

Let me use a simpler heuristic:
- Compute c = corr(h)
- Find the worst lag k*
- For the worst lag, compute the "impulse response": for each i, how much does c[k*] change if h[i] increases by 1?
- This is just dc[k*]/dh[i] for the single lag k*
- Positions where dc[k*]/dh[i] > 0 should have h[i] decreased
- Positions where dc[k*]/dh[i] < 0 should have h[i] increased
- Pair a "should decrease" position with a "should increase" position

This is O(n) to compute the impulse response for one lag, and O(n) to select pairs.

But we need to maintain the sum constraint, so we always do paired moves (increase one, decrease another by the same amount).

Let me implement this:

```python
def _grad_incr(h, c, c5c, rng, n_iter, n, start_step):
    dx = 2.0 / n
    step = start_step
    stall = 0
    for it in range(n_iter):
        # Select pairs based on gradient of worst lag
        k_star = c.argmax()
        sh = (n - 1) - k_star
        # Compute impulse response for worst lag
        if sh >= 0:
            imp = np.zeros(n)
            imp[:n-sh] += (1.0 - h[sh:n])
            imp[sh:] -= h[:n-sh]
        else:
            sp = -sh
            imp = np.zeros(n)
            imp[sp:] += (1.0 - h[:n-sp])
            imp[:n-sp] -= h[sp:]
        
        # Select i from "decrease" positions (imp > 0), j from "increase" (imp < 0)
        dec_mask = imp > 0
        inc_mask = imp < 0
        if dec_mask.sum() < 2 or inc_mask.sum() < 2:
            # Fallback to random
            i = rng.randint(n)
            j = rng.randint(n)
            if i == j:
                continue
            d = step * rng.randn()
        else:
            # Weighted random selection
            dec_idx = np.where(dec_mask)[0]
            inc_idx = np.where(inc_mask)[0]
            i = dec_idx[rng.randint(len(dec_idx))]
            j = inc_idx[rng.randint(len(inc_idx))]
            d = -step * abs(rng.randn())  # Decrease i, increase j
            # Sometimes also try the opposite
            if rng.rand() < 0.3:
                d = -d
        
        ni = h[i] + d
        nj = h[j] - d
        if ni < -1e-10 or ni > 1.0 + 1e-10 or nj < -1e-10 or nj > 1.0 + 1e-10:
            # Clip
            if ni < 0: d += ni  # adjust
            elif ni > 1: d -= ni - 1
            if nj < 0: d -= nj  # adjust back
            elif nj > 1: d += nj - 1
            ni = h[i] + d
            nj = h[j] - d
            if ni < 0 or ni > 1 or nj < 0 or nj > 1:
                continue
        
        dc = _pos_change(h, i, d, n) + _pos_change(h, j, -d, n)
        new_c = c + dc
        new_c5 = new_c.max() * dx
        if new_c5 < c5c - 1e-15:
            h[i] = ni
            h[j] = nj
            c = new_c
            c5c = new_c5
            stall = 0
        else:
            stall += 1
            if stall > 5000:
                step *= 0.7
                stall = 0
                if step < 1e-7:
                    break
    return h, c, c5c
```

```python
    m = c.max()

    return m + float(np.log(np.sum(np.exp(s))) / alpha)

    n = len(h)
    c = _corr(h)
    m = c.max()
    s = np.clip(alpha * (c - m), -500, 0)
    w = np.exp(s - s.max())
    w /= w.sum()

        else:
            sp = -sh
            g[sp:] += w[kk] * (1.0 - h[:n - sp])
            g[:n - sp] -= w[kk] * h[sp:]

    return x.sum() - len(x) * 0.5

    return np.ones(len(x))
```
