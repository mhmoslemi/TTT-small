Now, the coordinate descent algorithm:
1. Compute current correlations c
2. For each pair (i,j) in some order:
   a. Compute d = g_i - g_j for all lags
   b. Ternary search for optimal δ
   c. Update h[i] += δ, h[j] -= δ
   d. Update c (or recompute)
3. Repeat until convergence

The key question is: what order to update pairs?

Options:
- Random pairs
- Pairs involving the most "active" coordinates (those in the argmax lags)
- Cyclic: (0,1), (0,2), ..., (0,n-1), (1,2), ...

For efficiency, I'll use random pairs with a bias toward active coordinates.

```python
            if lo_d >= hi_d:
                continue
            delta = _optimal_delta(c, d, lo_d, hi_d)
            if abs(delta) < 1e-15:
                continue
            # Apply update
            h[i] += delta
            h[j] -= delta
            # Check if it improved
            c_new = _corrs(h)
            f_new = c_new.max()
            if f_new < f - 1e-15:
                f = f_new
                c = c_new
                improved += 1
            else:
                # Revert
                h[i] -= delta
                h[j] += delta
        if improved == 0:
            break
    return h, f
```
