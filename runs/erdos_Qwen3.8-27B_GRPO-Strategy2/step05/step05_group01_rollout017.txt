For a fixed (i,j), as a function of d, the objective is:

where g[k] is the change per unit d for shift k.

f(d) is a convex piecewise-linear function of d (max of linear functions). The minimum is at the point where the two "active" constraints cross, or at a boundary d∈[0, 1-h[i]], [h[j]-1, 0], etc.

We can find the optimal d by:
1. Computing g[k] for all k
2. Finding d that minimizes max_k (c[k] + d*g[k])

This is equivalent to finding d such that the upper envelope of {c[k] + d*g[k]} is minimized.

For small |d|, the active constraint is the current max. We want to reduce the max, so we want d*sign(g[argmax]) < 0.

If g[k*] > 0, decreasing d reduces the max.

The optimal d (for this pair) is where the current max constraint stops being active, i.e.:

Actually, I just realized I should think about what makes this problem hard and what would actually help.

The Erdős minimum overlap problem is about finding a set of measure 1 in [0,2] that minimizes the maximum measure of A ∩ (A+k) over all k. The continuous version would have h(x) ∈ {0,1} almost everywhere.

For the discrete version with h[i] ∈ [0,1], the binary solutions (h[i] ∈ {0,1}) have:
- c[0] = Σ h[i] * (1-h[i]) = 0 (since h[i](1-h[i]) = 0 for binary h)
- c[k] for k≠0: Σ h[i] * (1-h[i+k]) = |A ∩ (A+k)^c| = |A| - |A ∩ (A+k)|

So for binary h, c[0] = 0 and c[k] = |A| - |A ∩ (A+k)| for k ≠ 0.

The max is then max_{k≠0} (|A| - |A ∩ (A+k)|) * 2/n.

Since |A| = n/2, we want to maximize min_{k≠0} |A ∩ (A+k)|.

This is a classic additive combinatorics problem! We want a set A of size n/2 in Z_n (or in a linear array) that maximizes the minimum additive energy.

For the discretized problem on [0,2] with n points, the "shift" k goes from -(n-1) to (n-1), and the overlap at shift s = k-(n-1) is the number of pairs (i, i+s) both in A (for positive s) or (i-s, i) both in A (for negative s).

This is very different from the general [0,1] problem because we're working on a linear array, not cyclic.

For binary h, the problem reduces to: choose n/2 positions out of n to minimize the maximum "disagreement" over all shifts.

This is reminiscent of designing a binary sequence with low autocorrelation.

def _repair(h, n):
    h = np.clip(h, 0.0, 1.0).copy()
    tgt = n * 0.5
    if abs(h.sum() - tgt) < 1e-12: return h
    lo, hi = -1.5, 1.5
    for _ in range(80):
        mid = (lo + hi) * 0.5
        if np.clip(h + mid, 0, 1).sum() > tgt: lo = mid
        else: hi = mid
    h = np.clip(h + (lo + hi) * 0.5, 0, 1)
    d = tgt - h.sum()

        idx = np.argsort(1.0 - h) if d > 0 else np.argsort(h)
        for ii in idx:
            if d > 0:

            else:
                a = min(-d, h[ii]); h[ii] -= a; d += a

def _og(h, alpha):
    c = _corr(h)
    m = c.max()
    s = np.clip(alpha * (c - m), -600, 600)
    e = np.exp(s - s.max())
    w = e / e.sum()
    n = len(h)
    g = np.zeros(n)
    for k in range(2 * n - 1):

        sh = (n - 1) - k

            g[sh:] -= w[k] * h[:n - sh]

            g[sp_:] += w[k] * (1.0 - h[:n - sp_])

    return x.sum() - 0.5 * len(x)

def _cj(x):
    return np.ones(len(x))

                     method='SLSQP', bounds=[(0.0, 1.0)] * n,
                     constraints=[{'type': 'eq', 'fun': _cf, 'jac': _cj}],
                     options={'maxiter': mi, 'ftol': ft})
        return _repair(r.x, n)
    except Exception:

def _pch(h, i, di, n):
    dc = np.zeros(2 * n - 1)
    if di == 0.0: return dc
    ns = n - i
    s1 = np.arange(ns)
    dc[(n - 1) - s1] += di * (1.0 - h[i:i + ns])
    s2 = np.arange(i + 1)
    dc[(n - 1) - s2] -= di * h[i::-1][:i + 1]
    sp = np.arange(1, n)
    k3 = (n - 1) + sp
    m1 = sp <= i
    if m1.any(): dc[k3[m1]] += di * (1.0 - h[i - sp[m1]])
    m2 = sp < ns
    if m2.any(): dc[k3[m2]] -= di * h[i + sp[m2]]
    return dc

def _pair(h, c, rng, nit, scl, n):
    dx = 2.0 / n
    c5 = c.max() * dx
    for _ in range(nit):
        i = rng.randint(n); j = rng.randint(n)
        if i == j: continue
        d = scl * rng.randn()
        a = h[i] + d; b = h[j] - d
        if a < -1e-10 or a > 1 + 1e-10 or b < -1e-10 or b > 1 + 1e-10: continue
        dc = _pch(h, i, d, n) + _pch(h, j, -d, n)
        nc = c + dc
        v = nc.max() * dx
        if v < c5 - 1e-15:
            h[i] = a; h[j] = b; c = nc; c5 = v
    return h, c, c5

    c = _corr(h)
    top = np.argsort(c)[-nt:]
    g = np.zeros(n)
    for k in top:

        else:
            sp_ = -sh; g[sp_:] += (1.0 - h[:n - sp_]); g[:n - sp_] -= h[sp_:]
    g /= nt
    return _pts(h - stp * g, n * 0.5)
