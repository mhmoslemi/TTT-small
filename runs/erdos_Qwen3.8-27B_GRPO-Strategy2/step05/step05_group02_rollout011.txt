The Erdős problem: C₅ is the minimum over all h of max_k ∫h(x)(1-h(x+k))dx.

For the 0/1 case (h is a characteristic function), this becomes:
min_A max_k |A ∩ (A+k)|' where |A∩(A+k)'| = |A| - |A∩(A+k)|

Wait, that's the overlap of A with the complement of A shifted by k. For |A| = 1 (measure), on [0,2]:
- |A ∩ (A+k)^c| in the overlap domain [0, 2-|k|]

This is related to the "auto-correlation" of the set A. For a random set of measure 1 in [0,2], the expected overlap at shift k is:
(1/2) * (2-|k|) * (1/2) = (2-|k|)/4

The maximum is at k=0: 2/4 = 0.5. But we can do better with structured sets.

For a periodic set with period p: if 2/p is integer, the auto-correlation has peaks at multiples of p. To minimize the max, we want to spread out these peaks.

This is analogous to the "Golay ruler" or "Barker sequence" problem in discrete signal processing.
