Also, I want to add a **top-k equalization** step. Here's the idea:
- After Adam converges, identify the top m lags (say m=3-10)
- For these lags, compute the gradient directions g_i
- Find the direction d that most evenly reduces all top lags
- Take a line search step in that direction

The "most even reduction" direction is the solution of:
min_d max_i (c_i + d^T g_i)
s.t. ||d|| ≤ step_size

By LP duality, this is:
max_{λ ≥ 0, sum λ = 1} min_{||d||≤ε} (sum λ_i c_i + d^T (sum λ_i g_i))
= max_λ (sum λ_i c_i - ε * ||sum λ_i g_i||)

So we want to find λ that maximizes sum λ_i c_i - ε * ||Σ λ_i g_i||.

Since c_i are all close to each other (near the max), sum λ_i c_i ≈ c_max regardless of λ. So we mainly want to minimize ||Σ λ_i g_i||, i.e., find the convex combination of gradients with the smallest norm.

This is a QP: min ||G^T λ||^2 s.t. λ ≥ 0, sum λ = 1
where G is the n×m matrix whose columns are g_i.

This can be solved with a few iterations of projected gradient or a direct QP solver.

    deadline = t0 + budget_s - 3
    rng = np.random.RandomState(seed)
    n0 = len(initial_h_values)
    h = _repair(np.array(initial_h_values, dtype=float).copy(), n0)
    best_h = h.copy()
    best_c5 = _eval(h)
    best_n = n0

    # Phase 1: Adam with broad alpha sweep
    seq1 = [(100, 0.004, 200), (300, 0.003, 300), (1000, 0.002, 400),
            (3000, 0.0015, 500), (10000, 0.001, 500), (30000, 0.0008, 500),
            (100000, 0.0006, 500), (300000, 0.0004, 400), (1000000, 0.0003, 400)]
    h, c5 = _adam(best_h, seq1, deadline)
    if c5 < best_c5:
        best_h = h.copy(); best_c5 = c5

    # Phase 2: Active descent
    if time.time() < deadline - 200:
        h, c5 = _active_descent(best_h.copy(), 8000, 5, deadline)
        if c5 < best_c5:
            best_h = h.copy(); best_c5 = c5

    # Phase 3: High-alpha polish
    if time.time() < deadline - 200:
        h, c5 = _multi_alpha_polish(best_h, deadline, base_alpha=30000)
        if c5 < best_c5:
            best_h = h.copy(); best_c5 = c5

    # Phase 4: Active descent with fewer lags
    if time.time() < deadline - 120:
        h, c5 = _active_descent(best_h.copy(), 8000, 3, deadline)
        if c5 < best_c5:
            best_h = h.copy(); best_c5 = c5

    # Phase 5: Multi-start exploration
    if time.time() < deadline - 250:
        for _ in range(12):
            if time.time() > deadline - 180:
                break
            strat = rng.randint(4)
            if strat == 0:
                hp = _repair(best_h + 0.008 * rng.randn(n0), n0)
            elif strat == 1:
                hp = _repair(1.0 - best_h + 0.005 * rng.randn(n0), n0)
            elif strat == 2:
                hp = best_h.copy()
                for _ in range(3):
                    bs = rng.randint(5, max(6, n0 // 8))
                    st = rng.randint(0, n0 - bs)
                    hp[st:st + bs] += 0.02 * rng.randn(bs)
                hp = _repair(hp, n0)
            else:
                hp = best_h.copy()
                t_arr = np.arange(n0)
                for f in range(4):
                    freq = rng.randint(1, n0 // 3 + 1)
                    hp += 0.004 * rng.randn() * np.sin(2 * np.pi * freq * t_arr / n0)
                hp = _repair(hp, n0)
            small_seq = [(5000, 0.001, 300), (30000, 0.0008, 400),
                         (100000, 0.0005, 400), (500000, 0.0003, 300)]
            h, c5 = _adam(hp, small_seq, deadline)
            h, c5 = _active_descent(h, 3000, 3, deadline)
            if c5 < best_c5:
                best_h = h.copy(); best_c5 = c5

    # Phase 6: Final high-alpha Adam
    if time.time() < deadline - 100:
        seq2 = [(200000, 0.0002, 800), (1000000, 0.00015, 1000),
                (5000000, 0.0001, 1000), (20000000, 0.00008, 800)]
        h, c5 = _adam(best_h, seq2, deadline)
        if c5 < best_c5:
            best_h = h.copy(); best_c5 = c5

    # Phase 7: Ultra-fine active descent
    if time.time() < deadline - 50:
        h, c5 = _active_descent(best_h.copy(), 15000, 2, deadline)
        if c5 < best_c5:
            best_h = h.copy(); best_c5 = c5

    # Phase 8: Pairwise refinement
    if time.time() < deadline - 20:
        for scale in [0.002, 0.0005, 0.0001, 5e-5, 2e-5]:
            if time.time() > deadline - 10:
                break
            h, c5 = _pairwise(best_h.copy(), 8000, scale, rng, deadline)
            if c5 < best_c5:
                best_h = h.copy(); best_c5 = c5

    # Phase 9: Final tiny Adam
    if time.time() < deadline - 5:
        h, c5 = _adam(best_h, [(50000000, 0.00005, 2000)], deadline)
        if c5 < best_c5:
            best_h = h.copy(); best_c5 = c5

    best_h = _repair(best_h, best_n)
    best_c5 = _eval(best_h)
    return (best_h, best_c5, best_n)
