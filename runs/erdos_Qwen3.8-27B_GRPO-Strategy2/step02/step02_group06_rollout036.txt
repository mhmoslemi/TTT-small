def _subgradient_step(h, n, dx, lr, n_iters):

    for _ in range(n_iters):
        c = _corr(h)
        cmax = np.max(c)
        # Active lags (within tolerance)
        active = c > cmax - 1e-6
        # Subgradient
        grad = np.zeros(n)
        for k in range(2 * n - 1):
            if not active[k]:
                continue
            # d c[k] / d h[i] for each i
            m_idx = np.array([k])
            for i in range(n):
                # d/dh[i] of c[k] = (1 - h[i + k - (n-1)]) (if valid) - h[i + (n-1) - k] (if valid)
                idx_a = i + k - (n - 1)
                if 0 <= idx_a < n:
                    grad[i] += (1.0 - h[idx_a])
                idx_b = i + (n - 1) - k
                if 0 <= idx_b < n:
                    grad[i] -= h[idx_b]
        # Step
        h -= lr * grad
        h = _repair(h, n)
    return h

def _pnorm_obj(x, p):
    c = _corr(x)
    return float(np.sum(c ** p) ** (1.0 / p))

    try:
        res = minimize(_pnorm_obj, h.copy(), args=(p,), method='SLSQP',
                      bounds=bounds, constraints=cons,
                      options={'maxiter': maxiter, 'ftol': 1e-15})
        return _repair(res.x, n)
    except Exception:
        return h.copy()

Actually, here's a cleaner idea for a new element: **coordinate-wise exact optimization**. For each coordinate i (holding all others fixed), the optimal h[i] can be found by solving a 1D problem. But the sum constraint couples all coordinates, so I can't optimize one coordinate in isolation.

However, I can use the following trick: optimize h[i] and h[j] simultaneously (which is what pair sweep does), but use the EXACT solution of the 1D problem (not a grid). The 1D problem is:
minimize max_m (a[m] + b[m] * d) subject to d_min ≤ d ≤ d_max

where a = corr, b = g, and d = change in h[i] (with h[j] changing by -d).

The function f(d) = max_m (a[m] + b[m] * d) is convex and piecewise linear. Its minimum is at a vertex of the upper envelope. I can find this exactly:
1. Compute all breakpoints: for pairs (m1, m2) where b[m1] ≠ b[m2], the breakpoint is d = (a[m2] - a[m1]) / (b[m1] - b[m2])
2. Filter to [d_min, d_max]
3. Evaluate f at all breakpoints + boundaries
4. Take the minimum

With 139 "lines", there are C(139,2) ≈ 9600 breakpoints. Computing them all is O(139²) ≈ 19000 ops. Evaluating f at each is O(139). Total: O(139³) ≈ 2.7 million per pair. With 2415 pairs: 6.5 billion ops. Way too slow.

def _min_convex_1d(a, b, dmin, dmax):
    """Find d in [dmin, dmax] minimizing f(d) = max_m (a[m] + b[m]*d)."""
    # f is convex, piecewise linear
    # Use golden section search (works for unimodal functions)
    phi = (1.0 - np.sqrt(5.0)) / 2.0  # golden ratio conjugate ≈ -0.618
    # Actually for minimization: c = dmax - (dmax-dmin)*phi, d = dmin + (dmax-dmin)*phi
    # Hmm, let me just use bisection on the derivative (subgradient)
    
    # Simpler: ternary search
    for _ in range(60):  # 60 iterations of ternary search → factor of (2/3)^60 ≈ 2.4e-11
        d1 = dmin + (dmax - dmin) / 3.0
        d2 = dmax - (dmax - dmin) / 3.0
        f1 = np.max(a + b * d1)
        f2 = np.max(a + b * d2)
        if f1 < f2:
            dmax = d2
        else:
            dmin = d1
    return (dmin + dmax) / 2.0
