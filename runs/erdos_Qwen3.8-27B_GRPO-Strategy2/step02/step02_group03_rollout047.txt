For the local phase, I'll use a key insight: the objective is the max of linear functions (each c_k is linear in h... wait, no, c_k = sum h[i]*(1-h[i+k]) is NOT linear in h, it's bilinear).

Actually c_k = sum h[i] - sum h[i]*h[i+k]. The first term is constant (= 35). So c_k = 35 - sum h[i]*h[i+k].

Minimizing max_k c_k = minimizing max_k (35 - sum h[i]*h[i+k]) = maximizing min_k sum h[i]*h[i+k].

So we want to MAXIMIZE the minimum of the autocorrelation-like quantities sum_i h[i]*h[i+k]!

This is a maxValue minimax problem. The function g_k(h) = sum_i h[i]*h[i+k] is a quadratic form in h. We want to maximize min_k g_k(h).

This is related to "Golay sequences" and " Barker sequences" in signal processing! The goal is to make the autocorrelation as flat as possible (minimize peak sidelobe).

For a binary sequence of length n with sum n/2, this is exactly the problem of designing a "low peak-to-average sidelobe ratio" sequence.

Known constructions:
- **m-sequences** (from finite geometry)
- **Costas arrays**
- **Golay complementary sequences**

But these are typically for circular correlation. For linear correlation, the problem is different.

However, the insight is useful: we want the quadratic form h^T Q_k h to be as large and equal as possible for all k, where Q_k is the shift-k adjacency matrix.

  And for the first term, j-shift must be in [0, n-1-shift], i.e., j in [shift, n-1].

def _grad_c(h):
    """Compute gradient of all c[m] w.r.t. h. Returns (2n-1, n) array."""
    n = len(h)
    G = np.zeros((2*n-1, n))
    for m in range(2*n-1):
        shift = m - (n-1)
        if shift >= 0:
            # c[m] = sum_{i=0}^{n-1-shift} h[i+shift]*(1-h[i])
            for i in range(n - shift):
                # h[i+shift] term: derivative w.r.t. h[i+shift] is (1-h[i])
                G[m, i+shift] += (1.0 - h[i])
                # (1-h[i]) term: derivative w.r.t. h[i] is -h[i+shift]
                G[m, i] += -h[i+shift]
        else:
            s = -shift
            for i in range(s, n):
                # h[i-s] term: derivative w.r.t. h[i-s] is (1-h[i])
                G[m, i-s] += (1.0 - h[i])
                # (1-h[i]) term: derivative w.r.t. h[i] is -h[i-s]
                G[m, i] += -h[i-s]

And d/dh [max_c] = sum_m [exp(alpha*(c_m - max_c)) / sum_n exp(alpha*(c_n - max_c))] * dc_m/dh (by the softmax gradient trick, since max_c + log(sum exp(...))/alpha has the same gradient as the logsumexp)

Actually, the function f(h) = max_c + log(sum exp(alpha*(c_m - max_c)))/alpha
has the same gradient as the logsumexp of (alpha*c_m - alpha*max_c) divided by alpha, which is:
∇f = (1/alpha) * sum_m softmax_m(alpha*(c-max_c)) * alpha * ∇c_m = sum_m w_m * ∇c_m

where w_m = exp(alpha*(c_m - max_c)) / sum_n exp(alpha*(c_n - max_c))

So the gradient is a weighted sum of ∇c_m!
