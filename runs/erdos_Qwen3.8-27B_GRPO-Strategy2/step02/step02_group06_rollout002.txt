But wait: the objective is smooth_max(corr) * dx. The dx factor is constant, so it doesn't affect the gradient direction. I'll just optimize smooth_max(corr) and the constraint is on sum(h).

- Try lr
- If f(h_new) > f(h) + 1e-4 * lr * grad . (h_new - h), halve lr
- Repeat

This ensures monotone decrease (approximately).

    val = m + np.log(e.sum()) / alpha

        return np.full(n, 0.5)

                diff -= add

                diff += sub

    idx2 = p + k

            h_new = h_curr
        else:

            h_curr = h_new

                continue

                h[j] = hj - d_best
