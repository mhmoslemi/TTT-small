The terms involving h[i]:
- When n = i: h[i] * (1-h[i+s]) (if i+s is in [0,n-1])

= (rest') + h[i]*(1 - h[i+s] - h[i-s])

where (rest') = (rest) + h[i-s].

So c[k] is linear in h[i]! The coefficient is (1 - h[i+s] - h[i-s]).

To minimize max_k c[k] with respect to h[i] (with 0 ≤ h[i] ≤ 1), we need to find the h[i] that minimizes the maximum of a set of linear functions in h[i]. This is a 1D convex optimization that can be solved by finding where the maximum of the lines changes.

This is a great insight! Let me implement coordinate descent:

For each i:
1. Compute the coefficient a_k = 1 - h[i+s_k] - h[i-s_k] for each k (where s_k = k-(n-1))
2. Compute the intercept b_k = c[k] - h[i]*a_k (the value of c[k] when h[i]=0, adjusted)
3. Find h[i] ∈ [0,1] that minimizes max_k (b_k + a_k * h[i])

This is a 1D problem: minimize max_k (a_k * t + b_k) over t ∈ [0,1].
The optimal t is where the two "tightest" lines cross (or at 0 or 1 if the crossing is outside [0,1]).

This can be solved efficiently! Let me implement this.

Actually, for 2n-1 lines in 1D, finding the min of the max is equivalent to:
- Compute the "upper envelope" of the lines
- Find the minimum of this envelope

For a set of lines y = a_k * t + b_k, the upper envelope is a convex piecewise-linear function. Its minimum occurs either at a vertex (intersection of two lines) or at a boundary (t=0 or t=1).

An efficient algorithm:
1. Sort lines by slope a_k
2. Use a convex hull trick to find the minimum of the upper envelope
3. Or just: evaluate at t=0, t=1, and at all pairwise intersections that fall in [0,1]

For n=560, there are 2n-1 = 1119 lines. Pairwise intersections would be ~600K, which is a lot. But with the convex hull trick, we can do it in O(n log n).

Actually, for this specific problem, let me just use a simpler approach: since we only need the min of the max, we can binary search on the value. For a given value V, check if max_k (a_k * t + b_k) ≤ V for all k. This is a feasibility check: t must satisfy a_k * t + b_k ≤ V for all k, i.e.:
- If a_k > 0: t ≤ (V - b_k) / a_k
- If a_k < 0: t ≥ (V - b_k) / a_k
- If a_k = 0: need b_k ≤ V

So the feasible set for t is an interval [L, U], and we need L ≤ U and the interval intersects [0,1].

We can binary search on V to find the minimum V such that a feasible t exists in [0,1].

This gives us the optimal h[i] in O(n log precision) per coordinate.

With n=560 coordinates, this is 560 * 1119 * log(precision) ≈ 560 * 1119 * 20 ≈ 12.6M operations per sweep. That's fast!

Let me implement this coordinate descent approach. It should converge quickly and give a very precise solution.

import numpy as np
from scipy.optimize import minimize
import time

def _repair(h, n):
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    if s < 1e-12:
        return np.full(n, 0.5)
    if abs(s - target) > 1e-9:
        h *= target / s
        h = np.clip(h, 0.0, 1.0)
        diff = target - h.sum()
        if abs(diff) > 1e-12:
            order = np.argsort(1.0 - h) if diff > 0 else np.argsort(h)
            for idx in order:
                if diff > 0:
                    a = min(diff, 1.0 - h[idx])
                    h[idx] += a
                    diff -= a
                else:
                    a = min(-diff, h[idx])
                    h[idx] -= a
                    diff += a
                if abs(diff) < 1e-12:
                    break
    return h

def _eval(h):
    n = len(h)
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * 2.0 / n)

def _coord_step(h, i):
    """Find optimal h[i] given all other h[j] fixed.
    Minimize max_k c[k] over h[i] ∈ [0,1].
    c[k] = b_k + a_k * h[i] where b_k, a_k computed from other h values.
    """
    n = len(h)
    dx = 2.0 / n
    # Compute a_k and b_k for each lag k
    # c[k] at index k in np.correlate(h, 1-h, 'full') corresponds to shift s = k - (n-1)
    # c[k] = sum_{valid n} h[n] * (1-h[n+s])
    # Terms involving h[i]:
    #   n=i: h[i]*(1-h[i+s]) -> coeff of h[i] = (1-h[i+s]), intercept = 0
    #   n=i-s: h[i-s]*(1-h[i]) -> coeff of h[i] = -h[i-s], intercept = h[i-s]
    # So c[k] = (rest_k) + h[i] * (1-h[i+s]) + h[i-s] * (1-h[i])
    #          = (rest_k + h[i-s]) + h[i] * (1-h[i+s]-h[i-s])
    
    a = np.zeros(2*n-1)  # coefficient of h[i]
    b = np.zeros(2*n-1)  # intercept (c[k] with h[i] removed)
    
    current = h[i]
    for k in range(2*n-1):
        s = k - (n-1)
        # n=i term: h[i] * (1-h[i+s])
        a1 = 0.0
        if 0 <= i+s < n:
            a1 = 1.0 - h[i+s]
        # n=i-s term: h[i-s] * (1-h[i])
        a2 = 0.0
        b2 = 0.0
        if 0 <= i-s < n and (i-s) != i:  # (i-s) != i means s != 0
            a2 = -h[i-s]
            b2 = h[i-s]
        
        a[k] = a1 + a2
        # b[k] = c[k] - h[i]*a[k] but computed directly
        # c[k] = (rest) + h[i]*a1 + h[i-s]*(1-h[i]) where rest doesn't involve h[i]
        # = (rest) + h[i]*a1 + h[i-s] - h[i]*h[i-s]
        # b[k] = c[k] - h[i]*a[k] = (rest) + h[i-s] (the h[i] terms cancel)
        # Actually: c[k] = rest + h[i]*a1 + (1-h[i])*h[i-s] (if i-s valid)
        #          = rest + h[i]*a1 + h[i-s] - h[i]*h[i-s]
        #          = (rest + h[i-s]) + h[i]*(a1 - h[i-s])
        # So b[k] = rest + h[i-s], a[k] = a1 - h[i-s]
        
        # But I need to compute rest + h[i-s] = c[k] - h[i]*(a1-h[i-s])
        # This is circular... Let me just compute c[k] directly for current h[i],
        # then derive b[k] = c[k] - h[i]*a[k]
        
    # Simpler approach: compute c = correlate(h, 1-h, 'full') * dx
    # then b[k] = c[k] - h[i]*a[k]
    # and a[k] as derived above
    
    c = np.correlate(h, 1.0 - h, mode='full') * dx
    
    for k in range(2*n-1):
        s = k - (n-1)
        a1 = 0.0
        if 0 <= i+s < n:
            a1 = 1.0 - h[i+s]
        a2 = 0.0
        if 0 <= i-s < n and s != 0:
            a2 = -h[i-s]
        a[k] = a1 + a2
        b[k] = c[k] - current * a[k]
    
    # Now minimize max_k (b[k] + a[k]*t) over t ∈ [0,1]
    # Binary search on V: find min V such that ∃ t∈[0,1] with b[k]+a[k]*t ≤ V ∀k
    lo_v = 0.0
    hi_v = 1.0  # max possible value
    
    for _ in range(60):
        mid_v = (lo_v + hi_v) * 0.5
        # Check feasibility: ∃ t ∈ [0,1] with a[k]*t + b[k] ≤ mid_v ∀k
        L = 0.0
        U = 1.0
        feasible = True
        for k in range(2*n-1):
            if a[k] > 1e-15:
                t_max = (mid_v - b[k]) / a[k]
                U = min(U, t_max)
            elif a[k] < -1e-15:
                t_min = (mid_v - b[k]) / a[k]
                L = max(L, t_min)
            else:
                if b[k] > mid_v:
                    feasible = False
                    break
        if not feasible or L > U:
            hi_v = mid_v
        else:
            lo_v = mid_v
            # Remember feasible t
            t_opt = max(0.0, min(1.0, (L + U) * 0.5))
    
    # Now find the actual optimal t at V = lo_v
    # t must be in [L, U] ∩ [0,1]
    L = 0.0
    U = 1.0
    for k in range(2*n-1):
        if a[k] > 1e-15:
            t_max = (lo_v - b[k]) / a[k]
            U = min(U, t_max)
        elif a[k] < -1e-15:
            t_min = (lo_v - b[k]) / a[k]
            L = max(L, t_min)
    
    t_opt = max(0.0, min(1.0, (L + U) * 0.5))
    if L > U:
        # Infeasible at lo_v, stay at current
        t_opt = current
    return t_opt

def _coord_descent(h, n_sweeps=10, t0=0, budget_frac=0.3):
    """Multiple sweeps of coordinate descent."""
    n = len(h)
    best = h.copy()
    best_c = _eval(h)
    elapsed = time.time() - t0
    deadline = t0 + budget_frac * (time.time() - t0 + 1100)  # rough
    
    for sw in range(n_sweeps):
        for i in range(n):
            if time.time() > deadline:
                return best, best_c
            t_new = _coord_step(h, i)
            h[i] = t_new
        c = _eval(h)
        if c < best_c:
            best_c = c
            best = h.copy()
    
    return best, best_c

def _proj_to_sum(h, target):
    lo, hi = -2.0, 2.0
    for _ in range(60):

        if s > target:

def _slsqp_smooth(h, alpha, maxiter, ftol):
    n = len(h)
    bnds = [(0.0, 1.0)] * n
    
    def _cf(x):
        return x.sum() - n * 0.5
    
    def _cj(x):
        return np.ones(n)
    
    cons = [{'type': 'eq', 'fun': _cf, 'jac': _cj}]
    
    def _obj(x):
        dx = 2.0 / n
        c = np.correlate(x, 1.0 - x, mode='full') * dx
        m = c.max()
        s = np.clip(alpha * (c - m), -500, 500)
        s -= s.max()
        return m + np.log(np.sum(np.exp(s))) / alpha
    
    def _obj_grad(x):
        dx = 2.0 / n
        c = np.correlate(x, 1.0 - x, mode='full') * dx
        m = c.max()
        s = np.clip(alpha * (c - m), -500, 500)
        s -= s.max()
        w = np.exp(s)
        w /= w.sum()
        g = np.zeros(n)
        for k in range(2 * n - 1):
            if w[k] < 1e-14:
                continue
            sh = (n - 1) - k
            wk = w[k] * dx
            if sh >= 0:
                i1 = np.arange(n - sh)
                g[i1] += wk * (1.0 - x[i1 + sh])
                if sh > 0:
                    i2 = np.arange(sh, n)
                    g[i2] -= wk * x[i2 - sh]
            else:
                sp = -sh
                i1 = np.arange(sp, n)
                g[i1] += wk * (1.0 - x[i1 - sp])
                i2 = np.arange(n - sp)
                g[i2] -= wk * x[i2 + sp]
        return g
    
    try:
        res = minimize(_obj, h, jac=_obj_grad,
                       method='SLSQP', bounds=bnds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': ftol})
        return _repair(res.x, n)
    except Exception:
        return _repair(h, n)
