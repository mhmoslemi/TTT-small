Let me also think about a completely different approach: **iterative reweighting**.

The problem is: min_h max_k c_k(h) where c_k = Σ_i h[i](1-h[i+k])*dx.

Think of it as: we have 2n-1 "lag variables" c_k, and we want to minimize the maximum. This is like a "water-filling" problem in the lag domain.

Algorithm:
1. Start with h
2. Compute all c_k
3. Identify the "bottleneck" lags (those with c_k close to max)
4. Adjust h to reduce the bottleneck lags while not increasing others
5. Repeat

The adjustment in step 4: for a bottleneck lag k, we want to increase Σ h[i]h[i+k] (to reduce c_k = n/2*dx - Σ h[i]h[i+k]*dx). This means we want h[i] and h[i+k] to both be high (or both be low, but since we're looking at h[i]*(1-h[i+k]), we specifically want to reduce the count where h[i]=1 and h[i+k]=0).

So the operation is: find pairs (i, i+k) where h[i]≈1 and h[i+k]≈0, and move mass from i to i+k (or vice versa).

This is essentially what the subgradient does, but let me make it more explicit:

For the top lag k*:
- Find all i where h[i] is high and h[i+k*] is low
- Move a small amount of mass from h[i] to h[i+k*]
- This reduces c_{k*} but might increase c_{k*'} for other lags

The subgradient captures this automatically. Let me just make the implementation efficient and run it for many iterations.

    for nr in [80, 120]:
        if el() > 100:
            break
        h_r = _interp_dn(h0, nr)
        h_r = _repair(h_r, nr)
        for nl in [3, 5, 7]:
            if el() > 120:
                break
            h_r, f = _subgrad_mom(h_r, nl, 12000, 0.015, 0.7, el, bc)
            h_hi = _repair(_interp_up(h_r, n0), n0)
            c5h = _eval_c5(h_hi)[0]
            if c5h < best_c5:
                best_c5, best_h, best_n = c5h, h_hi, n0

    # Phase 2: Mid-res (n=n0//2) subgradient
    n_mid = max(100, n0 // 2)
    if el() < budget_s - 450:
        h_mid = _repair(_interp_dn(best_h, n_mid), n_mid)
        for nl in [5, 7, 10]:
            if el() > budget_s - 350:
                break
            h_mid, f = _subgrad_mom(h_mid, nl, 15000, 0.008, 0.75, el, bc)
            h_hi = _repair(_interp_up(h_mid, n0), n0)
            c5h = _eval_c5(h_hi)[0]
            if c5h < best_c5:
                best_c5, best_h, best_n = c5h, h_hi, n0

    # Phase 3: Full-res subgradient (n=n0)
    if el() < budget_s - 250:
        for nl in [5, 8, 4, 12]:
            if el() > budget_s - 200:
                break
            h_nf, f = _subgrad_mom(best_h, nl, 15000, 0.002, 0.8, el, bc)
            if f < best_c5:
                best_c5, best_h = f, h_nf.copy()
                best_n = len(h_nf)

    # Phase 4: SLSQP polish at full res (short)
    if el() < budget_s - 120:
        for alpha in [5000, 50000]:
            if el() > budget_s - 100:
                break
            h_sp = _slsqp_fast(best_h, alpha, 400)
            c5s = _eval_c5(h_sp)[0]
            if c5s < best_c5:
                best_c5, best_h, best_n = c5s, h_sp, len(h_sp)

    # Phase 5: Additional subgradient at higher res (n0*2) if time
    if el() < budget_s - 100:
        n2 = min(n0 * 2, 1200)
        if n2 != best_n:
            h2 = _repair(_interp_up(best_h, n2), n2)
            h2, f2 = _subgrad_mom(h2, 5, 8000, 0.001, 0.8, el, bc)
            c5v = _eval_c5(h2)[0]
            if c5v < best_c5:
                best_c5, best_h, best_n = c5v, h2, n2

    # Phase 6: Local 2-point pair search (final polish)
    if el() < budget_s - 10:
        n_tries = min(int((budget_s - 10 - el()) * 400), 200000)
        best_h, best_c5 = _local_pairs(best_h, n_tries, rng, el, bc)
        best_n = len(best_h)

    best_h = _repair(best_h, best_n)
    best_c5 = _eval_c5(best_h)[0]
    return (best_h, best_c5, best_n)
