```python
def _pm_grads(x, alpha, n):
    c = np.correlate(x, 1.0 - x, mode='full')
    c = np.clip(c, 1e-12, None)
    m = 2 * n - 1
    sa = np.sum(c ** alpha)
    pref = (sa / m) ** (1.0 / alpha - 1.0) / m
    w = pref * c ** (alpha - 1) * 2.0 / n
    g = _grad_w(w, x, n)
    g += 2e4 * (x.sum() - n * 0.5)
    return g
```

Hmm, the Nesterov scheme is getting complicated. Let me simplify:

Standard Nesterov:
- x_0 = initial, y_0 = x_0
- For t = 0, 1, 2, ...:
  - g = ∇f(y_t)
  - x_{t+1} = proj(y_t - η_t * g)
  - β_t = (1 + sqrt(1 + 4t²)) / 2
  - y_{t+1} = x_{t+1} + (β_t - 1) / β_{t+1} * (x_{t+1} - x_t)

The learning rate η_t for the projected subgradient in Nesterov is typically:
η_t = c / sqrt(t + 1)

where c depends on the Lipschitz constant and the domain diameter.

For our problem, the Lipschitz constant of the gradient (for the max of correlations) is bounded by... it's a bit hard to know exactly. Let me just use a decreasing learning rate.

Let me simplify the Nesterov to:
- Momentum-based gradient descent with decreasing step size
- Step size: η_t = η_0 / sqrt(t + 1)
- Momentum: β = 0.9

This is simpler and works well in practice.

```python
def _nesterov(h0, n_iter, t_end, top_k=3):
    n = len(h0)
    x = h0.copy()
    v = np.zeros(n)
    best_h = h0.copy()
    best_c = _eval(h0)[0]
    beta = 0.9
    eta0 = 0.5
    for t in range(n_iter):
        if time.time() > t_end:
            break
        eta = eta0 / np.sqrt(t + 1.0)
        _, cc = _eval(x)
        idx = np.argsort(cc)[::-1][:top_k]
        w = np.zeros(2 * n - 1)
        w[idx] = 1.0 / top_k
        g = _grad_w(w, x, n)
        v = beta * v - eta * g
        x = _proj(x + v, n)
        c_new = _eval(x)[0]
        if c_new < best_c:
            best_c = c_new
            best_h = x.copy()
    return best_h, best_c
```
