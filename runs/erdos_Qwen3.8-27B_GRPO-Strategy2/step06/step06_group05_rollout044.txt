def _project(h, n):
    """Project h onto {0 <= h_i <= 1, sum(h) = n/2}"""
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0).copy()
    s = h.sum()
    if abs(s - target) < 1e-12:
        return h
    # Water filling: find lambda such that sum(clip(h - lambda, 0, 1)) = target
    # If s > target: need to decrease sum by (s - target)
    # If s < target: need to increase sum by (target - s)
    lo, hi = -1.0, 1.0
    for _ in range(100):
        mid = (lo + hi) / 2
        s_mid = np.clip(h - mid, 0.0, 1.0).sum()
        if s_mid > target:
            lo = mid
        else:
            hi = mid
    h = np.clip(h - (lo + hi) / 2, 0.0, 1.0)
    # Fine adjustment
    diff = target - h.sum()
    if abs(diff) > 1e-12:
        order = np.argsort(1.0 - h) if diff > 0 else np.argsort(h)
        for idx in order:
            if diff > 0:
                a = min(diff, 1.0 - h[idx]); h[idx] += a; diff -= a
            else:
                a = min(-diff, h[idx]); h[idx] -= a; diff += a
            if abs(diff) < 1e-12: break
    return h

Let me try a different approach: **Frank-Wolfe (conditional gradient) method** for the non-smooth max problem.

Frank-Wolfe for min max_k c_k(h) s.t. h ∈ P (polytope):
- At each step, compute subgradient g = ∇c_k*(h) where k* is the argmax
- Find s = argmin_{s ∈ P} <g, s> (the linear oracle)
- Update: h ← (1-t)h + t*s

The linear oracle for P = {0 ≤ h ≤ 1, sum(h) = n/2}:
min <g, s> s.t. 0 ≤ s ≤ 1, sum(s) = n/2
This is solved by: sort g, set s[i] = 1 for the n/2 smallest g[i], s[i] = 0 for the rest.
(If n/2 is not integer, one variable is fractional.)

This is very efficient! The Frank-Wolfe method converges at rate O(1/T) for non-smooth functions, which is slow, but combined with the "away steps" variant or "conditional gradient with strong step", it can be much faster.

Actually, for the max of smooth functions, we can use the smooth approximation and then gradient descent + projection, which should converge faster.

    # g = gradient of c_k*(h) where k* = argmax
    k_star = np.argmax(c)

    half = n//2
    idx = np.argsort(g)[:half]
    s = np.zeros(n)
    s[idx] = 1.0
    # Now s is binary with sum = n/2 (if n is even)
    # Update
    h_new = (1-t)*h + t*s
    return h_new

Actually, one more idea: **What if the optimal solution has a specific structure?**

For the Erdős problem, the optimal function might be close to a "sparse" pattern. Think about it: if h is 0 or 1 (binary), then h(x)(1-h(x+k)) is 1 only where h(x)=1 and h(x+k)=0. The integral counts the "boundary" between 1s and 0s at shift k.

For a binary function with n/2 ones and n/2 zeros, the overlap at shift k is the number of positions where h=1 and h shifted by k gives 0 (or vice versa), times dx.

The maximum over k of this overlap is what we want to minimize. This is related to the "autocorrelation discrepancy" of a binary sequence.

In binary sequence design, the goal of minimizing the maximum autocorrelation is related to "low autocorrelation sequences" or "Barker sequences". This is a well-studied problem in signal processing!

Known results:
- For a binary sequence of length n with n/2 ones, the sum of squared autocorrelation values is bounded below by n (by Parseval).
- The maximum autocorrelation is at least sqrt(n) - 1 or so.
- Optimal sequences (like Barker sequences) achieve the maximum possible flatness.

If we think of h values as ±1 (mapping 0→-1, 1→+1), then the autocorrelation structure is related. Let me explore this connection.

Let h ∈ {0,1}^{n} with sum = n/2. Define a[i] = 2h[i] - 1 ∈ {-1, 1}^{n} with sum(a) = 0.

Then h[i](1-h[j]) = (a[i]+1)/2 * (1-(a[j]+1)/2) = (a[i]+1)(1-a[j])/4 = (1 - a[j] + a[i] - a[i]a[j])/4

The correlation at lag k:
c_k = (1/n) * sum_i h[i](1-h[i+k]) * dx  (roughly)
= dx/4 * sum_i (1 - a[i+k] + a[i] - a[i]a[i+k])
= dx/4 * (N_k - sum a[i+k] + sum a[i] - sum a[i]a[i+k])

where N_k is the number of overlapping terms.

For k = 0: c_0 = dx/4 * (n - 0 + 0 - n) = 0 (since sum a = 0 and a[i]^2 = 1)

Wait, c_0 = sum h[i](1-h[i]) = sum h[i] - h[i]^2. For binary h, this is 0.

For k ≠ 0:
c_k = dx/4 * (N_k - sum_{overlap} a[i+k] + sum_{overlap} a[i] - sum_{overlap} a[i]a[i+k])

The key term is the autocorrelation R(k) = sum a[i]a[i+k].

If n is large and we're away from boundaries, N_k ≈ n-k, sums of a[i] ≈ 0 (since mean is 0), so:
c_k ≈ dx/4 * (n-k - R(k))

We want to maximize this over k, so we want to minimize (n-k - R(k)) / 4, i.e., minimize (n-k - R(k)) for all k.

This means we want R(k) to be as close to n-k as possible for all k. But R(k) is an autocorrelation of a ±1 sequence, so R(0) = n, and |R(k)| ≤ n for all k.

def _repair(h, n):
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    if s < 1e-12:
        return np.full(n, 0.5)
    if abs(s - target) > 1e-9:
        h *= target / s
        h = np.clip(h, 0.0, 1.0)
        diff = target - h.sum()
        if abs(diff) > 1e-12:
            order = np.argsort(1.0 - h) if diff > 0 else np.argsort(h)
            for idx in order:
                if diff > 0:
                    a = min(diff, 1.0 - h[idx]); h[idx] += a; diff -= a
                else:
                    a = min(-diff, h[idx]); h[idx] -= a; diff += a
                if abs(diff) < 1e-12: break
    return h

def _eval(h):
    n = len(h)
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * 2.0 / n)

def _lssm(x, alpha):
    n = len(x)
    dx = 2.0 / n
    c = np.correlate(x, 1.0 - x, mode='full') * dx
    m = c.max()
    s = np.clip(alpha * (c - m), -500, 500)
    sm = s - s.max()
    return m + float(np.sum(np.exp(sm))) / alpha

def _lssm_grad(x, alpha):
    n = len(x)
    dx = 2.0 / n

    m = c.max()
