```python
def _repair(h, n):
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    if s < 1e-12:
        return np.full(n, 0.5)
    if abs(s - target) > 1e-9:
        h *= target / s
        h = np.clip(h, 0.0, 1.0)
        diff = target - h.sum()
        if abs(diff) > 1e-12:
            order = np.argsort(1.0 - h) if diff > 0 else np.argsort(h)
            for idx in order:
                if diff > 0:
                    a = min(diff, 1.0 - h[idx]); h[idx] += a; diff -= a
                else:
                    a = min(-diff, h[idx]); h[idx] -= a; diff += a
                if abs(diff) < 1e-12:
                    break
    return h
```

```python
import numpy as np
from scipy.optimize import minimize
import time

def _repair(h, n):
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    if s < 1e-12:
        return np.full(n, 0.5)
    if abs(s - target) > 1e-9:
        h *= target / s
        h = np.clip(h, 0.0, 1.0)
        diff = target - h.sum()
        if abs(diff) > 1e-12:
            order = np.argsort(1.0 - h) if diff > 0 else np.argsort(h)
            for idx in order:
                if diff > 0:
                    a = min(diff, 1.0 - h[idx]); h[idx] += a; diff -= a
                else:
                    a = min(-diff, h[idx]); h[idx] -= a; diff += a
                if abs(diff) < 1e-12:
                    break
    return h

def _eval(h):
    n = len(h)
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * 2.0 / n)

def _overlaps(h):
    return np.correlate(h, 1.0 - h, mode='full')

def _subgrad_max(h):
    """Subgradient of max_k overlap_k."""
    n = len(h)
    c = _overlaps(h)
    m = c.max()
    k_star = np.argmax(c)
    lag = k_star - (n - 1)
    g = np.zeros(n)
    for k in range(n):
        # h[k-lag] contributes (1-h[k]) if k-lag valid
        if 0 <= k - lag <= n - 1:
            g[k] += (1.0 - h[k])
        # h[k+lag] contributes -h[k] if k+lag valid
        if 0 <= k + lag <= n - 1:
            g[k] -= h[k]
    return g, c, m

def _subgrad_topk(h, topk=5):
    """Weighted subgradient of top-k overlaps."""
    n = len(h)
    c = _overlaps(h)
    m = c.max()
    idx = np.argsort(c)[::-1][:topk]
    g = np.zeros(n)
    w = np.zeros(2*n-1)
    for i in idx:
        w[i] = 1.0
    # Normalize
    w = w / w.sum()
    for k_idx in idx:
        lag = k_idx - (n - 1)
        for k in range(n):
            if 0 <= k - lag <= n - 1:
                g[k] += (1.0 - h[k])
            if 0 <= k + lag <= n - 1:
                g[k] -= h[k]
    g /= topk
    return g
```

```python
def _sg_method(h, n, n_iters, deadline, seed):
    rng = np.random.RandomState(seed)
    x = h.copy()
    best_x = x.copy()
    best_c = _eval(x)
    alpha = 0.1  # step size
    for i in range(n_iters):
        if time.time() > deadline:
            break
        c = _overlaps(x)
        m = c.max()
        # Find active set (top few)
        topk = 5
        idx = np.argsort(c)[-topk:]
        # Compute weighted subgradient
        g = np.zeros(n)
        for k_idx in idx:
            lag = k_idx - (n - 1)
            g += _subgrad_for_lag(x, lag)
        g /= topk
        # Normalize
        gn = np.linalg.norm(g)
        if gn > 1e-12:
            g /= gn
        # Step
        x -= alpha * g
        x = _repair(x, n)
        c_val = _eval(x)
        if c_val < best_c:
            best_c = c_val
            best_x = x.copy()
        # Adaptive step
        alpha *= 0.9999
        # Occasionally add noise
        if i % 100 == 0:
            x += 0.01 * rng.randn(n)
            x = _repair(x, n)
    return best_x, best_c
```

Actually, I just realized: I can precompute the correlation and then for each swap, compute the change in O(1) per lag (or O(n) total for all lags).

For swap: h[i]: 0→1, h[j]: 1→0 (i≠j)

c_L = Σ_k h[k+L]*(1-h[k]) for valid k

Change due to h[i]: 0→1:
- For term where k+L = i (k = i-L): contribution changes from h[i]*(1-h[i-L]) to 1*(1-h[i-L]) → change = (1-1)*(1-h[i-L]) - 0*(1-h[i-L])... wait.
  Old: h[i]*(1-h[i-L]) = 0*(1-h[i-L]) = 0
  New: 1*(1-h[i-L]) = 1-h[i-L]
  Change: (1-h[i-L]) (if i-L is valid, i.e., 0≤i-L≤n-1)
  
  Also for term where k = i: contribution changes from h[i+L]*(1-h[i]) to h[i+L]*(1-1) = 0
  Old: h[i+L]*(1-0) = h[i+L]
  New: h[i+L]*0 = 0
  Change: -h[i+L] (if i+L is valid)

Change due to h[j]: 1→0:
- For term where k+L = j (k = j-L): 
  Old: 1*(1-h[j-L]) = 1-h[j-L]
  New: 0
  Change: -(1-h[j-L]) = h[j-L]-1 (if j-L valid)
  
- For term where k = j:
  Old: h[j+L]*(1-1) = 0
  New: h[j+L]*(1-0) = h[j+L]
  Change: h[j+L] (if j+L valid)

So total change at lag L:
Δc_L = (1-h[i-L])*I(0≤i-L≤n-1) - h[i+L]*I(0≤i+L≤n-1) + (h[j-L]-1)*I(0≤j-L≤n-1) + h[j+L]*I(0≤j+L≤n-1)

Special case: if i-L = j (i.e., L = i-j):
  The first term has 1-h[j] = 0 (h[j]=1), and the third term has h[j-j]-1 = h[0]-1... wait, that's not right.
  If L = i-j, then i-L = i-(i-j) = j. So the first term is (1-h[j]) = 0. ✓
  And j-L = j-(i-j) = 2j-i. That's a different index, so no interference.
  
  Also, if i+L = j (L = j-i): second term is -h[j] = -1. ✓
  And j+L = 2j-i, different index.

Special case: if i-L = j AND i+L = j simultaneously → i-j = j-i → i=j, impossible since i≠j.

What if i+L = j AND j-L = i? i+L=j and j-L=i → L=j-i and L=j-i. Same condition!
So if L = j-i: second term is -h[j] = -1, fourth term is h[j+(j-i)] = h[2j-i]
  And first term: i-L = i-(j-i) = 2i-j, so (1-h[2i-j]) if valid
  Third term: j-L = j-(j-i) = i, so h[i]-1 = 0-1 = -1

So Δc_L for L=j-i: (1-h[2i-j])*I(2i-j valid) - 1 + (-1) + h[2j-i]*I(2j-i valid)

This is all O(1) per lag! So I can compute the change for ALL lags in O(n) per swap.

Total for one sweep: O(n * n²/4) = O(n³/4) for all swaps. For n=310: 310³/4 ≈ 7.5M. Fast.

Actually, for a given (i,j) swap, the delta for all L can be computed as:
delta[L] = (1-x[i-L])*I(0≤i-L≤n-1) - x[i+L]*I(0≤i+L≤n-1) + (x[j-L]-1)*I(0≤j-L≤n-1) + x[j+L]*I(0≤j+L≤n-1)

For all L from -(n-1) to (n-1), this is:
- (1-x[i-L]): non-zero for L in [i-(n-1), i] → L in [i-n+1, i], intersect [-(n-1), n-1]
- -x[i+L]: non-zero for L in [-i, n-1-i]
- (x[j-L]-1): non-zero for L in [j-n+1, j]
- x[j+L]: non-zero for L in [-j, n-1-j]

So the delta is non-zero for L in the union of these 4 intervals, which spans at most 2n-1 values (all of them). But each individual term is non-zero for at most n values.
