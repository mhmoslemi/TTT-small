def _grad_period(h_p, alpha):
    T = len(h_p)
    c = np.zeros(T)
    for r in range(T):
        c[r] = np.sum(h_p * (1.0 - np.roll(h_p, -r)))
    m = c.max()
    s = np.clip(alpha * (c - m), -500, 500)
    w = np.exp(s - s.max())

        if w[r] < 1e-14:

        wr = w[r]
        g += wr * ((1.0 - np.roll(h_p, -r)) - np.roll(h_p, r))

c[r] = Σ_i h[i] * (1 - h[(i+r) mod T])
     = Σ_i h[i] - Σ_i h[i]*h[(i+r) mod T]

∂c[r]/∂h[j] = 1 - h[(j+r) mod T] - h[(j-r) mod T]

So: g = Σ_r w[r] * [1 - h[(j+r) mod T] - h[(j-r) mod T]]

= 1 * Σ_r w[r] - Σ_r w[r]*h[(j+r) mod T] - Σ_r w[r]*h[(j-r) mod T]
= 1 - Σ_r w[r]*h[(j+r) mod T] - Σ_r w[r]*h[(j-r) mod T]
  (since Σ_r w[r] = 1)

In numpy:
g[j] = 1 - sum_r w[r] * h[(j+r) mod T] - sum_r w[r] * h[(j-r) mod T]
     = 1 - sum_r w[r] * h[(j+r) mod T] - sum_r w[-r] * h[(j+r) mod T]
     = 1 - sum_r (w[r] + w[-r]) * h[(j+r) mod T]

**Key speedup: Use the periodic structure to compute the gradient in O(T²) instead of O(n²).**

For a T-periodic function repeated m times:
The gradient of the full correlation with respect to the T-variable pattern is:
g_p[r] = sum over all m blocks and all relevant lags

But since the function is periodic, the gradient for each block is the same (up to boundary effects). So:
g_p ≈ m * g_circ (where g_circ is the circular gradient) 

The boundary corrections are small. So computing g_circ in O(T²) and multiplying by m is much faster than computing g_full in O(n²).

Let me implement this:

```python
def _grad_period_approx(h_p, alpha):
    """Gradient of soft-max of full correlation, approximated via circular corr."""
    T = len(h_p)
    m_ratio = 1.0  # Will be adjusted
    c = np.zeros(T)
    for r in range(T):
        c[r] = np.dot(h_p, 1.0 - np.roll(h_p, -r))
    mm = c.max()
    s = np.clip(alpha * (c - mm), -500, 500)
    w = np.exp(s - s.max())
    w /= w.sum()
    g = np.ones(T)  # The '1' from the linear part, times sum(w)=1
    for r in range(T):
        if w[r] > 1e-14:
            g -= w[r] * np.roll(h_p, -r) + w[r] * np.roll(h_p, r)
    return g
```
