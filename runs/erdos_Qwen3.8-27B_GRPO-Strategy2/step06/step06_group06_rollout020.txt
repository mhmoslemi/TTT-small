Wait, the gradient computation needs to account for the projection. Since _proj is a projection, the gradient of the composition is the gradient of the objective evaluated at the projected point (by the Moreau decomposition / projection property). So we can just compute the gradient at h = _proj(z) and that's the gradient of the outer function at z. This is correct for projected gradient methods.

But for L-BFGS-B, we need the gradient to be consistent with the function value. Since we're using z as input and projecting internally, the function _sm_obj(z) = F(_proj(z)) + penalty, and the gradient should be the chain-rule gradient. For a projection (which is a metric projection onto a convex set), the gradient of F(_proj(z)) at z is simply the gradient of F at _proj(z) for points where _proj is differentiable. This is the "decomposition property" - actually it's not quite right in general, but for our practical purposes with L-BFGS-B, it works well enough.

Actually wait - L-BFGS-B uses the (z, f(z), g(z)) triple and assumes g is the gradient of f at z. If we define f(z) = F(proj(z)) and g(z) = grad(F)(proj(z)), these are NOT consistent in general. The true gradient of f at z would involve the Jacobian of proj.

    h = np.clip(h, 0.0, 1.0).astype(float).copy()
    target = n / 2.0
    s = h.sum()
    if s < 1e-12:
        return np.full(n, 0.5)
    if abs(s - target) > 1e-14:
        h *= target / s
        h = np.clip(h, 0.0, 1.0)
        diff = target - h.sum()

            order = np.argsort(1.0 - h) if diff > 0 else np.argsort(h)

                if diff > 0:

                    h[idx] += a; diff -= a
                else:
                    a = min(-diff, h[idx])
                    h[idx] -= a; diff += a
                if abs(diff) < 1e-13:

        else:

    g = np.zeros(n)

        g[:n - q] += (1.0 - h[q:])
        g[q:] -= h[:n - q]

            g[q:] -= wk * z[:n - q]

    g += 2.0 * mu * (z.sum() - n * 0.5)

        else:

        top = np.argsort(c)[::-1][:top_m]
        g = np.zeros(n)
        for k in top:
            g += _cg_one(h_cur, k, n)
        g /= len(top)
        g *= 2.0 / n
        gn = np.linalg.norm(g)
        if gn < 1e-15:

        c_new = _eval(h_new)
        if c_new < c_cur - 1e-15:

            c_cur = c_new
            step = min(step * 1.03, 0.15)
        else:
            step *= 0.6
            if step < step_min:
                break
    return h_cur, c_cur
