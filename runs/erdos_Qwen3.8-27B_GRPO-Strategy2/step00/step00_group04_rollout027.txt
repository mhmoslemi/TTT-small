The overlap at shift k measures: "How much of h's mass is in places where h shifted by k has no mass?"

Ideally, we want h to be "autocorrelation-flat" - its autocorrelation should be as uniform as possible across all shifts. For a function with integral 1 over [0,2], the autocorrelation at lag 0 is ∫h² ≤ 1 (by Cauchy-Schwarz, with equality when h is an indicator). At lag 0, the overlap is ∫h(1-h) = 1 - ∫h² which is minimized when ∫h² is maximized, i.e., h is an indicator function.

So binary (indicator) solutions are favored! In fact, for binary h, the overlap at lag 0 is 0.

For lag k ≠ 0, the overlap is the measure of {x : h(x)=1 and h(x+k)=0} ∩ [0,2-k] (for k>0, approximately).

So for binary h, we want the indicator set to have the property that for every shift k, the overlap between the set and its shifted complement is minimized in its maximum.

This is exactly the "minimum covering" or "autocorrelation minimization" problem for binary sequences/sets.

For a continuous indicator set S ⊂ [0,2] with measure 1, we want:
min_S max_k |S ∩ (S+k)ᶜ| (intersected with [0,2])

            x0 = best_h if r == 0 else proj(best_h + 0.02 * np.random.randn(n_best), tgt_best)
            hn = lbgbs(x0, n_best, tgt_best, maxit=500)
            cn = c5_val(hn, n_best)
            if cn < best_c5:
                best_h, best_c5 = hn.copy(), cn

    best_h = proj(best_h, len(best_h) / 2.0)
    best_c5 = c5_val(best_h, len(best_h))
    return (best_h.tolist(), float(best_c5), int(len(best_h)))
