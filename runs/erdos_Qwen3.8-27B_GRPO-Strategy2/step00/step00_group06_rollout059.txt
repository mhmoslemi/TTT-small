For the 1D coordinate optimization:
Fix all h[i] for i ≠ j. Then:
- c_k is linear in h[j] (as I showed earlier)
- We want to minimize max_k c_k over h[j] ∈ [0,1]
- This is the minimum of a convex piecewise-linear function on [0,1]
- The minimum is at a breakpoint (where two c_k's cross) or at the boundary

To find it:
1. For each k, compute c_k(h[j]=0) and c_k(h[j]=1)
2. The function at h[j]=t is: c_k(t) = c_k(0) + t * (c_k(1) - c_k(0))
3. We want min_t max_k [a_k + b_k * t] where a_k = c_k(0), b_k = c_k(1) - c_k(0)
4. This is a 1D convex optimization: the minimum is where the two largest lines cross

To find the crossing point:
- Sort by value at t=0: a_(1) ≥ a_(2) ≥ ...
- The maximum at t=0 is a_(1)
- As t increases, lines with large b_k increase
- The minimum of the max is where the first two "active" lines cross

This can be done in O(K log K) where K = 2n-1 is the number of lags.

        # For h[j]=1: c_k(1) = sum_{i} h[i+k]*(1-h[i]) with h[j]=1

        h[j] = 0.0

        # Setting h[j] = 1:
        h[j] = 1.0
        c1 = np.correlate(h, 1.0 - h, mode='full')
        
        a = c0  # c_k at h[j]=0
        b = c1 - c0  # slope

        # This is the minimum of a convex piecewise-linear function
        f0 = np.max(a)  # value at t=0
        f1 = np.max(a + b)  # value at t=1

        # Simple approach: ternary search on [0,1] (since it's convex)
        lo, hi = 0.0, 1.0
        for _ in range(50):

            m2 = hi - (hi - lo) / 3.0
            fm1 = np.max(a + b * m1)
            fm2 = np.max(a + b * m2)
            if fm1 < fm2:
                hi = m2

        h[j] = t_opt
    
    # Repair sum
    h = repair(h, n)
    return h
