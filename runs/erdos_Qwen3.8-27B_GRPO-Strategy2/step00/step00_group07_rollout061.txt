When we flip h[i] from 1 to 0 and h[j] from 0 to 1:
- For corr[k] = sum_m h[m+k] * (1-h[m]):
  - The term m=i: was h[i+k]*0, becomes h[i+k]*1. Delta: +h[i+k]
  - The term m+k=i (i.e., m=i-k): was h[i]*(1-h[i-k])=(1-h[i-k]), becomes 0. Delta: -(1-h[i-k])
  - The term m=j: was h[j+k]*1, becomes h[j+k]*0. Delta: -h[j+k]
  - The term m+k=j (i.e., m=j-k): was 0*(1-h[j-k])=0, becomes 1*(1-h[j-k]). Delta: +(1-h[j-k])

But these only apply when the indices are valid (0 ≤ m < n and 0 ≤ m+k < n in the correlation sense).

Actually, the full correlation np.correlate(h, 1-h, mode='full') at index p (0 to 2n-2) corresponds to:
sum over m of h[m + (p - (n-1))] * (1-h[m])

where both indices must be in [0, n-1].

So for a given p, the valid m range is:
0 ≤ m < n and 0 ≤ m + p - (n-1) < n
→ 0 ≤ m < n and (n-1-p) ≤ m < (n-1-p) + n
→ max(0, n-1-p) ≤ m < min(n, 2n-1-p)

Let me denote shift s = p - (n-1), so s ranges from -(n-1) to (n-1).
Valid m: 0 ≤ m < n and 0 ≤ m+s < n → max(0, -s) ≤ m < min(n, n-s).

So corr[p] = sum_{m=max(0,-s)}^{min(n,n-s)-1} h[m+s] * (1-h[m])

When we change h[i] (i goes from 1 to 0):
- Terms where m+s = i, i.e., m = i-s: corr[p] changes by -(1-h[i-s]) [was h[i]*(1-h[i-s]), now 0]
  Valid when max(0,-s) ≤ i-s < min(n, n-s), i.e., 0 ≤ i < n and 0 ≤ i-s < n
- Terms where m = i: corr[p] changes from h[i+s]*(1-h[i]) = 0 to h[i+s]*1 = h[i+s]. Changes by +h[i+s]
  Valid when 0 ≤ i < n and 0 ≤ i+s < n

When we change h[j] (j goes from 0 to 1):
- Terms where m+s = j: corr[p] changes from 0 to (1-h[j-s]). Changes by +(1-h[j-s])
- Terms where m = j: corr[p] changes from h[j+s] to 0. Changes by -h[j+s]

So the total change for swap (i: 1→0, j: 0→1) at correlation index p (shift s = p-(n-1)):
delta[p] = -h[i+s] + (1-h[i-s]) + (1-h[j-s]) - h[j+s]
(where each term is included only if the corresponding index is valid)

This is O(1) per p, so O(n) per swap evaluation. Total for all swaps: O(n³) = 80³ = 512K per step. Much better!
