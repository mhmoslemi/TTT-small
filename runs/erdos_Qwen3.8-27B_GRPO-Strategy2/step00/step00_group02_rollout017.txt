Actually, I want to make sure I'm not missing a key insight. Let me re-read the problem.

"Find a step function h: [0, 2] → [0, 1] that minimizes the overlap integral: C₅ = max_k ∫ h(x)(1 - h(x+k)) dx"

The integral is over the domain where both h(x) and h(x+k) are defined. For h defined on [0,2], h(x+k) is defined when x+k ∈ [0,2], i.e., x ∈ [-k, 2-k]. So the integral is over max(0, -k) to min(2, 2-k) for k ≥ 0, and similarly for k < 0.

But the discretization just uses np.correlate(h, 1-h, mode='full') which gives correlations for all valid index pairs. The "full" mode gives 2n-1 values, corresponding to shifts from -(n-1) to (n-1) in index space, or from -(n-1)*dx to (n-1)*dx in physical space.

So the max is over all these shifts. This is correct.

One thing I notice: for shift 0, the correlation is ∑ h[i]*(1-h[i]) = ∑ h[i] - ∑ h[i]². For h ∈ [0,1], this is ≤ ∑ h[i] = n/2. So the shift-0 overlap is at most n/2 * dx = 1. But we can make it smaller by making h more binary (h[i]² ≈ h[i]).

For the optimal solution, the shift-0 overlap should be small (since we want h to be as binary as possible), and the non-zero shift overlaps should be the binding constraints.

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * dx

def project_feasible(h, n):
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    s = np.sum(h)
    if s > 1e-12:
        h *= target / s
    h = np.clip(h, 0.0, 1.0)
    resid = target - np.sum(h)
    if abs(resid) > 1e-9:
        free = np.where((h > 1e-12) & (h < 1.0 - 1e-12))[0]
        if len(free) > 0:
            h[free] += resid / len(free)
            h = np.clip(h, 0.0, 1.0)
