- **Discrete Dependence**: The algorithm relies heavily on the initial solution (n=70); extending to larger grids (e.g., higher resolution) must restore feasibility and may require re-initialization if the parent becomes invalid.

### 2. Mathematical Specification
**Dimension and Variables**:  
- Let \(N = n\_points\) be the number of grid points, with \(dx = 2.0 / N\). The function \(h\) is represented as an array \(h \in [0,1]^N\) with \(\sum_{i=1}^N h_i = N/2\).
- The overlap integral is evaluated on a fixed grid, and the goal is to minimize \(\max_k \left| \int_0^2 h(x)(1-h(x+k)) \, dx \right|\), approximated discretely using correlation in the code: compute correlation via `np.correlate(h, 1-h, mode='full')`, scale by \(dx = 2.0 / N\), and take the max (including both positive and negative lags) for the degree of freedom.
- Since the discretization preserves the physics, all derivations from the continuous case hold by Riemann sum approximation, with the max defined over \(k = -(N-1)\) to \(N-1\).

**Objective and Constraints**:
- **Objective**: Minimize \(C_5(h) = \max_{k} \left| \text{corr}[k] \cdot \delta_k \right|\), but in the code, \(C_5 = \max_k (\text{np.correlate}(h, 1-h, \text{mode}='full') \cdot dx\). The correlation is computed via: \(\text{corr}[m] = \sum_{i} h[i] \cdot (1-h[i + m])\), but with index out-of-bounds handled by mode='full' (implicitly padding with 0 or averaging only shared points), and the max is taken over all possible lags \(m \in [- (N-1), N-1]\).
- **Constraints**:
  1. \(0 \leq h[i] \leq 1\) for all \(i\) (all components non-negative and bounded).
  2. \(\sum_{i=1}^N h_i = N/2\) (integral of h is exactly 1).
- **Allowable h Values**: Continuous \(h\) can be used in optimization (0 < h[i] < 1) and clipped to [0,1] or rounded to binary for final comparison, but original constraints must be satisfied for score calculation.
- **Derived Formulas**:
  - The overlap integral discretization: \(\int_0^2 h(x)(1-h(x+k)) \, dx \approx \frac{2}{N} \sum_{i} h[i] (1-h[i+k])\), but this is essentially the correlation result scaled by dx. Back-of-envelope calculation: At lag 0, \(\int_0^2 h(x)(1-h(x)) \, dx \leq \frac{N/2}{2} = 0.25\) if h is binary; extending to continuous h improves by reducing variance.

**Optimization Formulation**:
- The problem is non-convex due to the \(\max\) function and the step functions' interactions (no closed-form solution exists).
- Target error: For example, a C_5 value of 0.38 implies that for all shifts, the overlap is at most 0.38, which is near the total integral (average max 0.5 for unoptimized h, so improvement is critical).
- No solver is claimed (as per rules). Within the code, we use numerical optimization with LBFGS-B, COBYLA, or similar built-in solvers with constraints, but none are guaranteed to handle the discrete output.

Try without abs if correlation is symmetric in definition? In this case, correlation can be negative, so abs is used.

2. **Feasibility Check and Repair**:
   - Define a helper function `validate_h(h, n_points)`:
     - If `not all(0 <= x <= 1 for x in h)`: Clip to [0,1] using `np.clip`.
     - Scale: Compute `current_sum = np.sum(h) * dx`; target integral condition corresponds to `sum(h) * dx ≈ 1`, so adjust: new_sum = N/2, new_h = (h / (current_sum / N)) * (N/2 / dx/current_sum) calculate: dx value depends on N.
