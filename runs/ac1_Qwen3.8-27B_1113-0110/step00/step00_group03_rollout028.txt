Let me also consider using scipy.optimize.minimize with a smooth surrogate.

The smooth surrogate: instead of max(c), use the log-sum-exp:
soft_max(c) = t * log(sum exp(c[k]/t))

for a temperature t. As t -> 0, this approaches max(c). For t > 0, it's smooth and differentiable.

The gradient of soft_max(c) w.r.t. a[i] is:
sum_k (exp(c[k]/t) / sum_j exp(c[j]/t)) * dc[k]/da[i]

This is a weighted average of the subgradients of c[k], weighted by the softmax weights.

This is computable in O(n^2) time (or O(n log n) with FFT for the c values, plus O(n) for each dc[k]/da[i]).

Actually, computing all dc[k]/da[i] for all k and i is O(n^2) in the worst case. But we can be smarter: the "gradient of the soft max" is:
g[i] = sum_k w_k * 2*a[k-i] (for valid k-i)
= 2 * sum_k w_k * a[k-i]

This is a correlation of the weight vector w with a! So it can be computed in O(n log n) using FFT.

Specifically, if w is a vector of length 2n-1 (the softmax weights), then:
g = 2 * correlate(w, a) (with appropriate alignment)

This is the key insight that makes the gradient computation efficient!

Let me formalize:
- w[k] = exp(c[k]/t) / sum_j exp(c[j]/t), for k = 0, ..., 2n-2
- g[i] = 2 * sum_{k: 0<=k-i<=n-1} w[k] * a[k-i]
  = 2 * (w * a)[i] where (w * a) is the cross-correlation

Actually, let me define it more carefully:
g[i] = sum_k w[k] * dc[k]/da[i] = sum_k w[k] * 2*a[k-i] * [0 <= k-i <= n-1]
= 2 * sum_{k=i}^{i+n-1} w[k] * a[k-i]
= 2 * sum_{j=0}^{n-1} w[i+j] * a[j]

This is the cross-correlation of w (shifted) with a at lag i. If we pad w to length 3n-2 (to handle all shifts), this can be computed as a convolution/correlation.

Actually, it's simpler: g[i] = 2 * (a * w_padded)[i + n - 1] or something like that. Let me just compute it directly for now since n is only ~2500.

For n = 2500, computing g directly takes O(n^2) = 6.25 million operations, which is fast enough.

Actually, let me reconsider the gradient computation. We have:
g[i] = 2 * sum_{j=0}^{n-1} a[j] * w[i+j]

This is the cross-correlation of a and w, evaluated at specific lags. Let me use FFT:

If we define:
A = fft(a, 2*(2n-1))  (padded)
W = fft(w, 2*(2n-1))  (padded)

Then the cross-correlation R = ifft(conj(A) * W) gives:
R[k] = sum_j a[j] w[j+k] (for k >= 0) ... or is it w[j-k]?

"""
Minimize 2n*max(conv(a,a))/sum(a)^2 using FFT-accelerated mirror descent
with soft-max reweighting. Tries multiple initializations (chirps, cosines,
random) and sequence lengths. Uses multiplicative updates that naturally
preserve non-negativity, with adaptive temperature for peak focusing.
"""
import numpy as np
import time


def fft_convolve(a, b):
    """Compute full linear convolution using FFT."""
    n = len(a) + len(b) - 1
    N = 1
    while N < n:
        N *= 2
    A = np.fft.rfft(a, N)
    B = np.fft.rfft(b, N)
    result = np.fft.irfft(A * B, N)
    return result[:n]


def fft_autocorr(a):
    """Compute full autocorrelation (convolution of a with itself) using FFT."""
    n = len(a)
    N = 1
    while N < 2 * n - 1:
        N *= 2
    A = np.fft.rfft(a, N)
    result = np.fft.irfft(A * A, N)
    return result[:2 * n - 1]


def compute_gradient_fft(a, w):
    """Compute g[i] = 2*sum_j a[j]*w[i+j] for i=0..n-1 using FFT.
    This is the gradient of the soft-max of the autocorrelation."""
    n = len(a)
    total_len = n + len(w) - 1
    N = 1
    while N < total_len:
        N *= 2
    A = np.fft.rfft(a, N)
    W = np.fft.rfft(w, N)
    # Cross-correlation: R[k] = sum_j a[j] * w[j+k]
    R = np.fft.irfft(np.conj(A) * W, N)
    return 2.0 * R[:n]


def soft_max_weights(c, temperature):
    """Compute softmax weights over the autocorrelation values."""
    c_scaled = c / temperature
    c_max = c_scaled.max()
    exp_vals = np.exp(c_scaled - c_max)
    w_sum = exp_vals.sum()
    if w_sum == 0 or not np.isfinite(w_sum):
        n_c = len(c)
        w = np.zeros(n_c)
        w[np.argmax(c)] = 1.0
        return w
    return exp_vals / w_sum


def optimize_sequence(a_init, n_max_iters, deadline, base_sum, rng):
    """Run mirror descent on a single initialization. Returns best (a, score)."""
    a = a_init.copy().astype(np.float64)
    if a.sum() <= 0:
        a = np.ones_like(a)
    a = a / a.sum()  # normalize to sum=1
    
    n = len(a)
    best_a = a.copy()
    best_local_score = np.inf
    
    # Parameters
    eta = 1.0  # step size
    temperature = max(1.0, n / 20.0)  # start with smooth weights
    eta_decay = 0.9995
    temp_decay = 0.998
    
    for it in range(n_max_iters):
        if time.monotonic() > deadline:
            break
        
        # Compute autocorrelation
        c = fft_autocorr(a)
        peak = c.max()
        
        # Evaluate (approximate score with sum=1)
        approx_score = 2.0 * n * peak
        if approx_score < best_local_score:
            best_local_score = approx_score
            best_a = a.copy()
        
        # Compute soft-max weights
        w = soft_max_weights(c, temperature)
        
        # Compute gradient using FFT
        g = compute_gradient_fft(a, w)
        
        # Multiplicative (mirror) update
        g_max = np.max(np.abs(g))
        if g_max > 1e-15:
            g_norm = g / g_max
        else:
            g_norm = g
        
        # a_new[j] = a[j] * exp(-eta * g_norm[j])
        log_update = -eta * g_norm
        # Clip to avoid overflow
        log_update = np.clip(log_update, -10, 10)
        a = a * np.exp(log_update)
        
        # Project: non-negativity and normalization
        a = np.maximum(a, 0.0)
        s = a.sum()
        if s > 1e-15:
            a = a / s
        else:
            a = np.ones(n) / n
        
        # Adapt parameters
        eta *= eta_decay
        temperature *= temp_decay
        temperature = max(temperature, 0.5)
    
    # Final evaluation
    candidate = best_a * base_sum
    score = float(evaluate_sequence(candidate.tolist()))
    if not np.isfinite(score):
        candidate = best_a * base_sum
        score = float(evaluate_sequence(candidate.tolist()))
    
    return candidate, score, best_a


def optimize_sequence_subgradient(a_init, n_max_iters, deadline, base_sum, rng):
    """Run subgradient descent as an alternative to mirror descent."""
    a = a_init.copy().astype(np.float64)
    if a.sum() <= 0:
        a = np.ones_like(a)
    a = a / a.sum()
    
    n = len(a)
    best_a = a.copy()
    best_local_score = np.inf
    
    eta = 0.5
    temperature = max(1.0, n / 30.0)
    
    for it in range(n_max_iters):
        if time.monotonic() > deadline:
            break
        
        c = fft_autocorr(a)
        peak = c.max()
        approx_score = 2.0 * n * peak
        if approx_score < best_local_score:
            best_local_score = approx_score
            best_a = a.copy()
        
        w = soft_max_weights(c, temperature)
        g = compute_gradient_fft(a, w)
        
        g_max = np.max(np.abs(g))
        if g_max > 1e-15:
            g_norm = g / g_max
        else:
            g_norm = g
        
        a = a - eta * g_norm
        a = np.maximum(a, 0.0)
        s = a.sum()
        if s > 1e-15:
            a = a / s
        else:
            a = np.ones(n) / n
        
        eta *= 0.999
        temperature *= 0.998
        temperature = max(temperature, 0.5)
    
    candidate = best_a * base_sum
    score = float(evaluate_sequence(candidate.tolist()))
    
    return candidate, score, best_a


def generate_initializations(n, base_sum, rng):
    """Generate diverse initializations for optimization."""
    inits = []
    
    # 1. Chirp-like sequences
    x = np.arange(n, dtype=np.float64)
    for freq_mult in [1, 2, 3, 5]:
        a = 0.5 + 0.5 * np.cos(2 * np.pi * freq_mult * x * x / (2.0 * n))
        a = np.clip(a, 0.01, None)
        a = a / a.sum() * base_sum
        inits.append(a)
    
    # 2. Cosine sequences
    for freq in [1, 2, 3]:
        a = 1.0 + 0.9 * np.cos(2 * np.pi * freq * x / n)
        a = np.clip(a, 0.01, None)
        a = a / a.sum() * base_sum
        inits.append(a)
    
    # 3. Tapered sequences
    for p in [0.5, 1.0, 2.0, 4.0]:
        t = x / max(1, n - 1)
        a = np.sin(np.pi * t) ** p
        a = np.clip(a, 0.001, None)
        a = a / a.sum() * base_sum
        inits.append(a)
    
    # 4. Random sequences
    for _ in range(3):
        a = np.abs(rng.standard_normal(n)) + 0.1
        a = a / a.sum() * base_sum
        inits.append(a)
    
    # 5. Two-scale structure
    for alpha in [0.3, 0.5, 0.7]:
        a = 1.0 + alpha * np.sin(np.pi * x / n)
        a = np.clip(a, 0.01, None)
        a = a / a.sum() * base_sum
        inits.append(a)
    
    # 6. Quadratic chirp (Frank-like)
    for m in [2, 4, 8]:
        a = np.abs(np.exp(2j * np.pi * x * x / (2.0 * m * n))) + 0.5
        a = np.real(a)
        a = np.clip(a, 0.01, None)
        a = a / a.sum() * base_sum
        inits.append(a)
    
    return inits
