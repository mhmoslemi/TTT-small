2. Find the "active" lag k* where c[k*] = max
3. Try to reduce c[k*] while not increasing other c[k] too much
4. Iterate

Step 3 is like: minimize c[k*] = sum_i a[i]*a[k*-i] subject to a >= 0, sum(a) = 1.

This is like a "water-filling" or "load balancing" problem.

Algorithm:
1. Start with a (e.g., uniform)
2. Compute c = a*a
3. Find the lag k* with maximum c[k*]
4. Try to reduce c[k*] by adjusting a
   - c[k*] = sum_i a[i]*a[k*-i]
   - To reduce this, we can decrease some a[i] where a[i]*a[k*-i] is large
   - But this also affects other c[k]
5. Use a small step size and reoptimize

This is essentially what the LP approach does, but in a more heuristic way.
