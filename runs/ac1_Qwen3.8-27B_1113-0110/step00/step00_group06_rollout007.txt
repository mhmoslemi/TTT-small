So:
∂b_k/∂x_j = x_{k-j} * (1 if 0<=k-j<n else 0) + x_{k-j} * (1 if 0<=k-j<n and k≠2j else 0)

Simplifying:
- If 0 <= k-j < n and k ≠ 2j: ∂b_k/∂x_j = 2*x_{k-j}
- If 0 <= k-j < n and k = 2j: ∂b_k/∂x_j = 2*x_j (since k-j=j, so x_{k-j}=x_j)
- If not (0 <= k-j < n): ∂b_k/∂x_j = 0

Wait, if k=2j, then k-j=j, and the only valid i that gives x_j in one of the factors is i=j (which gives x_j*x_j). The term i=k-j=i=j is the same term. So it's just x_j², and ∂/∂x_j = 2*x_j.

If k≠2j and 0<=k-j<n: both i=j and i=k-j are valid and distinct. We get x_j*x_{k-j} + x_{k-j}*x_j = 2*x_j*x_{k-j}. ∂/∂x_j = 2*x_{k-j}.

If k-j < 0 or k-j >= n: x_j doesn't appear in b_k at all. ∂/∂x_j = 0.

So the gradient of the "active" objective (sum of active b_k's) w.r.t. x_j is:
∇_j = sum_{k in active} ∂b_k/∂x_j = sum_{k in active} 2*x_{k-j} * [0<=k-j<n]

where the active set is the set of k where b_k is near the maximum.

This is essentially a correlation of the active indicators with x!

For the constraint sum x = 1, we project: after the gradient step, normalize to sum=1.
For x >= 0, we clip to 0.

The active set approach:
1. Initialize x (normalized to sum=1)
2. Compute b = conv(x,x), find active set A = {k: b_k >= max_b - eps}
3. Compute gradient: for each j, grad_j = sum_{k in A} 2*x_{k-j} * [0<=k-j<n]
4. Take step: x_new = x - lr * grad
5. Project: x_new = max(0, x_new), then normalize to sum=1
6. Repeat until convergence or time's up

The "flatness" approach (smooth approximation):
Instead of the hard max, use a soft-max: f_β(x) = (1/β) * log(sum exp(β*b_k)). This is smooth and we can use gradient descent.
