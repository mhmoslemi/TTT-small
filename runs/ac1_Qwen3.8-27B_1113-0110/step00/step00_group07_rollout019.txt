**Algorithm: Iterative Peak Reduction**

1. Start with a (random or uniform) non-negative sequence.
2. Compute c = a * a.
3. Find the peak location k*.
4. Compute the gradient of c[k*] with respect to a: ∂c[k*]/∂a[i] = a[k*-i] (with appropriate bounds).
5. Update a[i] -= η * ∂c[k*]/∂a[i] for all i, then project to non-negative orthant.
6. Repeat.

But this only reduces one peak at a time. A better approach:

**Algorithm: Minimax Subgradient Method**

1. Start with non-negative a.

def autoconv_fft(a):
    """Fast auto-convolution using FFT."""
    n = len(a)
    size = 2 * n - 1
    N = 1 << (size - 1).bit_length()  # Next power of 2
    A = np.fft.rfft(a, N)
    C = np.fft.irfft(A * A, N)
    return C[:size]

def score_from_conv(a, C):
    """Compute score from sequence and its auto-convolution."""
    n = len(a)
    s = a.sum()
    if s < 0.01:
        return np.inf
    return 2.0 * n * C.max() / (s * s)

def subgrad_max_conv(C, a, n, frac=0.05):
    """Compute subgradient of max(C) w.r.t. a."""
    M = C.max()
    threshold = M * (1.0 - frac)
    peaks = np.where(C >= threshold)[0]
    grad = np.zeros(n)
    for k in peaks:
        lo = max(0, k - (n - 1))
        hi = min(n - 1, k)

        # So we need a[k-hi : k-lo+1] in reverse
        grad[lo:hi+1] += 2.0 * a[k-hi:k-lo+1][::-1]
    return grad
