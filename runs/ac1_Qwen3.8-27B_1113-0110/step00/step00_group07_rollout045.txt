**Log-sum-exp smoothing:**
Instead of max_k C[k], use (1/β) * log(Σ_k exp(β*C[k])) for large β. This is a smooth approximation to the max, and its gradient is:
∇ = (1/β) * Σ_k exp(β*C[k]) * ∇C[k] / Σ_k exp(β*C[k])
= Σ_k p_k * ∇C[k]
where p_k = exp(β*C[k]) / Σ_j exp(β*C[j]) is a "soft" probability over the peaks.

This gives a smooth optimization problem that we can solve with gradient descent.

Let me think about the complexity of evaluating the gradient:
- Compute C = conv(a, a): O(n log n) using FFT, or O(n²) directly.
- Compute p_k (softmax of C): O(n).
- Compute the subgradient: for each k, ∇C[k] = 2 * (a cross-correlated with delta_k) = 2 * flip(a) shifted by k. The sum Σ_k p_k * ∇C[k] = 2 * (a cross-correlated with p) = 2 * conv(a, p_reversed). This is O(n log n) using FFT.

So each gradient step is O(n log n). For n=2000, that's about 2000 * 11 ≈ 22000 operations per step. Very fast!
