Actually, let me think about this from a different angle. What if we use a sequence based on a Barker-like code but made non-negative?

A Barker code of length N has values in {+1, -1} and its aperiodic autocorrelation has sidelobes bounded by some small value. If we map +1 -> 1 and -1 -> 0, we get a binary sequence. The autocorrelation of this binary sequence would be related to the Barker code's autocorrelation.
