```python
Multi-restart L-BFGS-B optimizer with FFT-based soft-max gradient.
Uses diverse perturbations and adaptive temperature to minimize
2*n*max(convolve(a,a))/sum(a)^2 for non-negative sequences.

_T_global = 0.01

def fft_self_conv(a):
    """Compute full self-convolution of a using FFT."""
    n = len(a)
    if n <= 1:
        return a * a
    size = 1
    while size < 2 * n - 1:
        size *= 2
    fa = np.fft.rfft(a, size)
    c = np.fft.irfft(fa * fa, size)
    return c[:2 * n - 1]

def _obj(x):
    """Objective (uses global _T_global)."""
    n = len(x)
    S = x.sum()
    if S < 0.01:
        return 1e10
    c = fft_self_conv(x)
    c_max = c.max()
    exp_arg = np.clip(_T_global * (c - c_max), -50, 50)
    exp_c = np.exp(exp_arg)
    exp_sum = exp_c.sum()
    M = c_max + np.log(exp_sum) / _T_global
    return 2.0 * n * M / (S * S)

def _grad(x):
    """Gradient (uses global _T_global)."""
    n = len(x)
    S = x.sum()
    if S < 0.01:
        return np.zeros(n)
    c = fft_self_conv(x)
    c_max = c.max()
    exp_arg = np.clip(_T_global * (c - c_max), -50, 50)
    exp_c = np.exp(exp_arg)
    exp_sum = exp_c.sum()
    M = c_max + np.log(exp_sum) / _T_global
    score = 2.0 * n * M / (S * S)
    
    weights = exp_c / exp_sum  # length 2n-1
    
    # Cross-correlation via FFT
    L = 1
    while L < 3 * n - 2:
        L *= 2
    fa = np.fft.rfft(x, L)
    wpad = np.zeros(L)
    wpad[:2*n-1] = weights
    fw = np.fft.rfft(wpad, L)
    R = np.fft.irfft(np.conj(fw) * fa, L)
    grad_M = R[:n]
    
    return (2.0 * n / (S * S)) * grad_M - (4.0 * n * M) / (S * S * S)

    M = c.max()
    return 2.0 * n * M / (S * S)
```

One option: compute the gradient analytically without a separate FFT. Since I already have c = a*a (convolution), and I need the cross-correlation of weights and a, I can use the fact that:

cross_corr(weights, a)[j] = sum_k weights[k] * a[k-j]

And weights is derived from c, which is derived from a. So there's no way to avoid computing a new FFT for the cross-correlation.

Unless... I use a different approach. What if I compute the gradient differently?

Alternative: Instead of the soft-max, use the "top-k" peaks. If I know the top-k peaks, the gradient is:
grad_M[j] = (1/k) * sum_{l=1}^{k} a[k_l - j] (for valid k_l - j)

This is O(k*n) which is much faster than FFT-based correlation for small k (like k=1 or k=2).

For k=1: grad_M[j] = a[k_star - j] (for valid k_star - j). This is just a shifted copy of a.
For k=2: grad_M[j] = 0.5 * (a[k1-j] + a[k2-j]).

Let me use this approach for the L-BFGS-B phase. It's much faster and avoids the FFT overhead for the gradient.

But the issue is: the "active set" (which peaks are in the top-k) can change during optimization, making the objective non-smooth. This can cause L-BFGS-B to have trouble.

A compromise: use the "active set" gradient (fast) but verify with the soft-max gradient (accurate) every few iterations. Or just use the active set gradient and accept the occasional non-smoothness.

Actually, for L-BFGS-B, the non-smoothness is not a huge problem in practice because:
1. The changes between iterations are small, so the active set rarely changes.
2. Even when it does, the gradient is still a valid subgradient in some sense.

```python
def _active_set_grad(x, k_star):
    """Gradient using a single active peak at lag k_star."""
    n = len(x)
    S = x.sum()
    c = fft_self_conv(x)
    M = c[k_star]
    score = 2.0 * n * M / (S * S)
    
    # dM/da[j] = a[k_star - j] for 0 <= k_star - j <= n-1
    grad_M = np.zeros(n)
    j_min = max(0, k_star - (n - 1))
    j_max = min(n - 1, k_star)
    for j in range(j_min, j_max + 1):
        grad_M[j] = x[k_star - j]
    
    grad = (2.0 * n / (S * S)) * grad_M - (4.0 * n * M) / (S * S * S)
    return score, grad
```

```python
Multi-restart L-BFGS-B optimizer with FFT-based soft-max gradient.
Uses diverse perturbations, adaptive temperature, and optional length extension
to minimize 2*n*max(convolve(a,a))/sum(a)^2 for non-negative sequences.

import numpy as np

_T_global = 0.01
_L_global = 0  # cached FFT size
_n_global = 0  # cached n


def _get_fft_size(n):
    """Get power-of-2 FFT size for cross-correlation of (2n-1) and (n)."""
    need = 3 * n - 2
    s = 1
    while s < need:
        s *= 2
    return s


def _compute_score_grad(x, T):
    """Compute soft-max score and its gradient w.r.t. x. Assumes x >= 0, sum >= 0.01."""
    n = len(x)
    S = x.sum()
    if S < 0.01:
        return 1e10, np.zeros(n)

    # FFT size
    L = _get_fft_size(n)

    # Forward FFT of x
    fa = np.fft.rfft(x, L)

    # Self-convolution
    c = np.fft.irfft(fa * fa, L)[:2 * n - 1]

    # Soft-max
    c_max = c.max()
    exp_arg = np.clip(T * (c - c_max), -60, 60)
    exp_c = np.exp(exp_arg)
    exp_sum = exp_c.sum()
    M_soft = c_max + np.log(exp_sum) / T

    score = 2.0 * n * M_soft / (S * S)

    # Weights for the soft-max (length 2n-1)
    weights = exp_c / exp_sum

    # Cross-correlation: grad_M[j] = sum_i weights[j+i] * x[i]
    # R = ifft(conj(FFT(weights)) * FFT(x)), take first n elements
    wpad = np.zeros(L // 2 + 1)
    wpad[:2 * n - 1] = weights
    fw = np.fft.rfft(wpad, L)
    R = np.fft.irfft(np.conj(fw) * fa, L)
    grad_M = R[:n]

    # Full gradient of score
    grad = (2.0 * n / (S * S)) * grad_M - (4.0 * n * M_soft) / (S * S * S)

    return score, grad
```
