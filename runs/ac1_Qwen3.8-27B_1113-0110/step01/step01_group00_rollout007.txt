def _fft_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    c = np.fft.irfft(A * A, fft_size)
    return c[:size]

    max_c = float(np.max(c))
    s = float(np.sum(a))
    if s < 0.01:

One more idea: **Use the LOQO / Osada method for optimal pulse design.**

The idea (from radar pulse compression literature):
1. Define a target autocorrelation R_target (e.g., a flat-top or raised-cosine).
2. Iteratively:
   a. Compute current autocorrelation R = conv(a, a).
   b. In frequency domain: A_new = A * sqrt(R_target / R) (spectral shaping).
   c. Time domain: a_new = IFFT(A_new).
   d. Project: a_new = max(0, a_new).
   e. Renormalize.
3. Repeat.

This is the "transformation algorithm" or "Osada's algorithm" for matched filter design. It's proven to converge for certain target shapes.

    a = a_init.copy()
    S = np.sum(a)
    a = a / S
    n = len(a)
    best = a.copy()
    best_score = _score(a)
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        # Current spectrum
        N = 1 << (3*n).bit_length()  # enough for full conv
        A = np.fft.rfft(a, N)
        C = np.fft.irfft(A * np.conj(A), N)[:2*n-1]  # current autocorrelation
        
        # Spectral shaping
        # |A_new|^2 = |A|^2 * R_target / C
        ratio = R_target / (C + 1e-15)
        ratio = np.clip(ratio, 0, 100)  # prevent blowup
        A_new_mag = np.abs(A) * np.sqrt(ratio[:N//2+1])
        A_new = A_new_mag * np.exp(1j * np.angle(A))
        
        # Time domain
        a_new = np.fft.irfft(A_new, N)[:n]
        a_new = np.maximum(a_new, 0)
        S_new = np.sum(a_new)
        if S_new > 1e-10:
            a_new = a_new / S_new
            a = a_new
        
        score = _score(a)
        if score < best_score:
            best_score = score
            best = a.copy()
    
    return best, best_score
