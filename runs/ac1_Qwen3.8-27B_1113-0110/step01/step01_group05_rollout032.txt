Actually, let me reconsider the problem. The key insight is:

We want to minimize `max_k (a*a)(k)` subject to `sum(a) = S` and `a_i >= 0`.

This is equivalent to: minimize `max_k sum_j a_j * a_{k-j}` subject to `sum a_i = 1` (WLOG) and `a_i >= 0`.

The LP perspective: we want to find the minimum value M such that there exists `a >= 0` with `sum a = 1` and `sum_j a_j * a_{k-j} <= M` for all k.

This is a nonlinear constraint (products of a's), so it's not a linear program directly. But we can use the approach from the state-of-the-art: fix the "other" sequence and solve an LP for the "current" one.

Actually, the approach in the state-of-the-art is:
1. Start with some `f`.
2. Solve LP: maximize `sum b_j` subject to `b >= 0` and `convolve(f, b)(k) <= M` for all k, where M = max(convolve(f,f)).
3. Rescale and update.

This is a multiplicative weight / empirical risk minimization approach.
