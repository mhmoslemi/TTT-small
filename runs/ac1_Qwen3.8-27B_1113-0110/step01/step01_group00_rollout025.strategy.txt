Approach and rationale
The primary goal is to minimize the evaluation function J(a) = (2 * n * max(convolve(a, a))) / (sum(a))^2 for a non-negative sequence a. This function measures the autocorrelation strength, where low values indicate a flatter autocorrelation. Previous implementations used linear programming and subgradient methods, but these showed diminishing returns by the time budget expired. Therefore, this strategy uses a Bayesian optimization approach that creates surrogate models to predict objectives and constraints, then searches within those regions.

The key idea is to use different initial sequences (including the supplied parent) for different lengths n and run gradient-free optimization with a parameter budget. We leverage the FFT-based convolution for faster evaluation. Bayesian optimization with Tree of Parzen Estimators (TPE) is selected because it balances exploration and exploitation well and can handle the large unbounded search space effectively.

To prevent missing the global optimum, we set up to two initial runs with distinct n values. These initial candidates form the starting points for the Bayesian optimization. We also use random weight adjustments (mutations) to help escape local optima.

Mathematical specification
