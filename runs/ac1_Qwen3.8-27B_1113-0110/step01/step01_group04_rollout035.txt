In the center-dominated regime, the score is 2*B(q,q)*q^2 which decreases as q decreases (i.e., as p increases). So the best in this regime is at the boundary p ≈ 0.58.

At p = 0.58 (q = 0.42): score ≈ 2*4.166*0.1764 = 1.469.

In the edge-dominated regime (p > 0.58), the score is 2n/S^2 where S = n^(1-p)/(1-p) = n^q/q.
Score = 2n * q^2 / n^(2q) = 2*q^2 * n^(1-2q).

This increases as q decreases (p increases), since n^(1-2q) increases as q decreases (for q < 0.5, which is always true here). Wait, 1-2q > 0 when q < 0.5, so n^(1-2q) > 1 and increases as q decreases. But q^2 decreases. So the product q^2 * n^(1-2q) has a minimum at some q.

d/dq [q^2 * n^(1-2q)] = 2q*n^(1-2q) + q^2*n^(1-2q)*(-2*ln(n))
= n^(1-2q) * q * (2 - 2q*ln(n))
= 2q*n^(1-2q) * (1 - q*ln(n))

This is zero when q = 1/ln(n). For n = 3809, ln(n) = 8.245, so q* = 0.1213.

At q* = 0.1213: score = 2 * (0.1213)^2 * 3809^(1-0.2426) = 2 * 0.01471 * 3809^0.7574.
3809^0.7574 = e^(0.7574*8.245) = e^(6.246) = 515.6.
Score = 2 * 0.01471 * 515.6 = 15.16.

That's terrible! So in the edge-dominated regime, the score is always large (the minimum is 15.16 at the optimal q, and it's even larger at the boundary q=0.42).
