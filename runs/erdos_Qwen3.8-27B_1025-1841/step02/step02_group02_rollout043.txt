```python
def binary_hill_climb(h, n, time_limit, start_time):
    dx = 2.0 / n
    h = binary_project(h, n)
    corr = np.correlate(h, 1.0 - h, mode='full')
    best_c5 = corr.max() * dx
    best_h = h.copy()
    
    ones = list(np.where(h == 1)[0])
    zeros = list(np.where(h == 0)[0])
    
    no_improve_count = 0
    max_no_improve = 200
    
    while time.time() - start_time < time_limit:
        if no_improve_count > max_no_improve:
            break
        
        found = False
        # Try random swaps
        n_trials = 200
        for _ in range(n_trials):
            i = ones[np.random.randint(len(ones))]
            j = zeros[np.random.randint(len(zeros))]
            
            # Compute delta
            delta = swap_delta(h, i, j, n)
            new_max = (corr + delta).max()
            
            if new_max < corr.max() - 1e-12:
                # Accept
                h[i] = 0
                h[j] = 1
                corr += delta
                ones.remove(i)
                zeros.remove(j)
                ones.append(j)
                zeros.append(i)
                best_c5 = corr.max() * dx
                best_h = h.copy()
                no_improve_count = 0
                found = True
                break
        
        if not found:
            no_improve_count += 1
    
    return best_h, best_c5
```

```python
def swap_delta(h, i, j, n):
    """Compute change in corr when h[i]:1->0 and h[j]:0->1"""
    delta = np.zeros(2*n-1)
    
    # Effect of h[i] going 1->0 (diff = -1)
    # Term 1: -(1-h[i-L]) for valid L
    ks1 = np.arange(max(0,i), min(2*n-2, i+n-1)+1)
    idxs1 = i - ks1 + n - 1
    delta[ks1] += -(1 - h[idxs1])
    
    # Term 2: +h[i+L] for valid L
    ks2 = np.arange(max(0, n-1-i), min(2*n-2, 2*n-2-i)+1)
    idxs2 = i + ks2 - n + 1
    delta[ks2] += h[idxs2]
    
    # Effect of h[j] going 0->1 (diff = +1)
    # Term 1: +(1-h[j-L]) for valid L
    ks1j = np.arange(max(0,j), min(2*n-2, j+n-1)+1)
    idxs1j = j - ks1j + n - 1
    delta[ks1j] += (1 - h[idxs1j])
    
    # Term 2: -h[j+L] for valid L
    ks2j = np.arange(max(0, n-1-j), min(2*n-2, 2*n-2-j)+1)
    idxs2j = j + ks2j - n + 1
    delta[ks2j] += -h[idxs2j]
    
    return delta
```

Wait, I need to be careful. When I compute the effect of h[i] going 1→0, I use the CURRENT h (before the swap). Similarly for h[j] going 0→1. Since i and j are different positions and we're computing the linear change, this should be correct (the change is linear in each individual flip, and the total change is the sum of individual changes, as long as i≠j).

Actually wait, there's a subtlety. When computing the effect of h[i] going 1→0, the "Term 2" involves h[i+L]. If i+L happens to equal j, then h[j] is about to change too. But since we're computing the linear approximation (each flip independently), and the total change is the sum of individual changes (because corr is bilinear in h, not linear), we need to be careful.

Let me verify: corr[k] = Σ_n h[n]*(1-h[n-L]) = Σ_n h[n] - Σ_n h[n]*h[n-L]

So corr is NOT linear in h! It's quadratic (bilinear). So the change from two flips is NOT the sum of individual changes.

The cross term: when both h[i] and h[j] change, there's an additional term if i and j are "connected" through the correlation.

Specifically, corr[k] = Σ_n h[n] - Σ_n h[n]*h[n-L]

Change in corr[k] from h[i]: 1→0 and h[j]: 0→1:
= -1 (from the linear term) + 1 (from the linear term) - [change in quadratic term]
= 0 - [change in Σ_n h[n]*h[n-L]]

The quadratic term Σ_n h[n]*h[n-L] changes when:
- n=i: h[i]*h[i-L] changes from h[i-L] to 0. Delta = -h[i-L]
- n-L=i, i.e., n=i+L: h[i+L]*h[i] changes from h[i+L] to 0. Delta = -h[i+L]
- n=j: h[j]*h[j-L] changes from 0 to h[j-L]. Delta = +h[j-L]
- n-L=j, i.e., n=j+L: h[j+L]*h[j] changes from 0 to h[j+L]. Delta = +h[j+L]

But we also need to check cross terms: if i-L = j (i.e., the "removed" term h[i]*h[j] becomes 0*1=0, was 1*1=1, delta=-1) or if i+L = j (removed term h[j]*h[i] was h[j]*h[i]=0*1=0, becomes 1*0=0, no change) or if j-L = i (added term h[j]*h[i] was 0*1=0, becomes 1*1=1, delta=+1) or if j+L = i (added term h[i]*h[j] was h[i]*h[j]=1*0=0, becomes 0*1=0, no change).

So the cross terms matter when i-L=j or j-L=i (i.e., |i-j| = |L| for the relevant L).

This means my simple "sum of individual effects" approach is NOT exactly correct. There's a cross term.

However, the cross term only affects a SINGLE value of k (the one where L = |i-j| or L = -(i-j)), and its magnitude is at most 1. For the purpose of finding improving moves, this approximation is probably good enough (the cross term is a small correction).

Alternatively, I can just compute the exact change for the critical k values:

For the k values where corr is near the maximum, compute the exact new value after the swap. This is O(|K_max|) per swap, which is fast.

```python
def exact_swap_effect(corr, h, i, j, n, critical_ks):
    """Compute exact new corr values at critical_ks after swapping h[i]:1->0, h[j]:0->1"""
    results = {}
    for k in critical_ks:
        L = k - (n - 1)
        # corr[k] = sum_n h[n]*(1-h[n-L])
        # After swap: h[i]=0, h[j]=1
        # Change in sum:
        # -n=i term: was h[i]*(1-h[i-L]) = 1*(1-h[i-L]), now 0. Delta = -(1-h[i-L])
        # -n=i+L term (if valid): was h[i+L]*(1-h[i]) = h[i+L]*0 = 0, now h[i+L]*1 = h[i+L]. Delta = +h[i+L]
        # -n=j term: was h[j]*(1-h[j-L]) = 0, now 1*(1-h[j-L]). Delta = +(1-h[j-L])
        # -n=j+L term (if valid): was h[j+L]*(1-h[j]) = h[j+L]*1 = h[j+L], now h[j+L]*0 = 0. Delta = -h[j+L]
        # Cross terms: if i-L==j: the n=i term was 1*(1-1)=0, now 0*(1-1)=0. No change.
        #              if i+L==j: the n=i+L term was h[j]*0=0, now h[j]*1=h[j]. But wait, this is already counted above.
        #              Actually the cross term issue is: when computing the n=i term, h[i-L] might be h[j] which is changing.
        #              Let me be more careful.
        
        # Actually, for the EXACT new value, I should just compute:
        # new_corr[k] = sum_n h'[n]*(1-h'[n-L]) where h' is h with i->0, j->1
        # The difference from old_corr[k]:
        # Let's identify all n where h[n] or h[n-L] is changed (i.e., n=i, n=j, n=i+L, n=j+L)
        
        affected_ns = set()
        for candidate in [i, j]:
            if 0 <= candidate < n:
                affected_ns.add(candidate)
            if 0 <= candidate + L < n:
                affected_ns.add(candidate + L)
        
        delta = 0
        for nn in affected_ns:
            old_val = h[nn] * (1 - h[nn - L]) if 0 <= nn - L < n else 0
            # new h:
            new_h_nn = 0 if nn == i else (1 if nn == j else h[nn])
            new_h_nnL = 0 if (nn-L) == i else (1 if (nn-L) == j else (h[nn-L] if 0 <= nn-L < n else 0))
            new_val = new_h_nn * (1 - new_h_nnL) if 0 <= nn - L < n else 0
            delta += new_val - old_val
        
        results[k] = corr[k] + delta
    return results
```

```python
def smooth_obj_grad(h, tau):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    max_c = corr.max()
    shifted = np.clip(tau * (corr - max_c), -400, 400)
    exp_c = np.exp(shifted)
    s = exp_c.sum()
    p = exp_c / s
    obj = dx * (max_c + np.log(s) / tau)
    
    grad = np.zeros(n)
    for k in range(2 * n - 1):
        pk = p[k]
        if pk < 1e-15:
            continue
        sh = k - n + 1
        # First term: (1-h[i+sh]) for valid i
        if sh >= 0:
            grad[:n-sh] += pk * (1.0 - h[sh:])
        else:
            grad[-sh:] += pk * (1.0 - h[:n+sh])
        # Second term: -h[i-sh] for valid i
        if sh >= 0:
            grad[sh:] += -pk * h[:n-sh]
        else:
            grad[:n+sh] += -pk * h[-sh:]
    
    grad *= dx
    return obj, grad
```

```python
def adam_optimize(h, n, tau, time_limit, start_time, lr=0.1, max_iters=50000):
    h = h.astype(float).copy()
    m = np.zeros(n)
    v = np.zeros(n)
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    t = 0
    
    best_c5 = compute_c5(h)
    best_h = h.copy()
    best_obj = None
    stall = 0
    
    for it in range(max_iters):
        if time.time() - start_time > time_limit:
            break
        t += 1
        obj, grad = smooth_obj_grad(h, tau)
        
        if best_obj is None or obj < best_obj - 1e-12:
            best_obj = obj
            # Don't update best_h here (it's approximate)
            stall = 0
        else:
            stall += 1
        
        if stall > 100:
            break
        
        m = beta1 * m + (1-beta1) * grad
        v = beta2 * v + (1-beta2) * grad**2
        m_hat = m / (1 - beta1**t)
        v_hat = v / (1 - beta2**t)
        
        h = h - lr * m_hat / (np.sqrt(v_hat) + eps)
        h = project_to_feasible(h, n)
        
        # Check actual c5 periodically
        if it % 100 == 0:
            c5 = compute_c5(h)
            if c5 < best_c5:
                best_c5 = c5
                best_h = h.copy()
    
    # Final check
    c5 = compute_c5(h)
    if c5 < best_c5:
        best_c5 = c5
        best_h = h.copy()
    
    best_h = project_to_feasible(best_h, n)
    best_c5 = compute_c5(best_h)
    return best_h, best_c5
```

```python
    target = n // 2
    idx = np.argsort(-g, kind='stable')
    b = np.zeros(n)
    b[idx[:target]] = 1.0
    return b

def interp_periodic(h, target_n):
    n = len(h)
    if n == target_n:
        return h.copy()
    x_new = np.arange(target_n) * (2.0 / target_n)
    pos = (x_new / (2.0 / n)) % n
    i0 = pos.astype(int) % n
    i1 = (i0 + 1) % n
    frac = pos - pos.astype(int)
    return h[i0] * (1.0 - frac) + h[i1] * frac

def binary_hill_climb(h_input, n, time_limit, start_time, max_stall=300, use_anneal=True):
    dx = 2.0 / n
    h = binary_project(h_input, n).copy()
    corr = np.correlate(h, 1.0 - h, mode='full')
    cur_max = float(corr.max())
    best_c5 = cur_max * dx
    best_h = h.copy()
    ones = list(np.where(h == 1)[0])
    zeros = list(np.where(h == 0)[0])
    stall = 0
    restart_count = 0
    max_restarts = 25
    trials = 80
    total_iters = 0
    temp = 2.0 / n
    while time.time() - start_time < time_limit:
        if stall > max_stall:
            if restart_count >= max_restarts:
                break
            restart_count += 1
            n_flip = min(5, max(2, len(ones) // 20))
            for _ in range(n_flip):
                i = ones[np.random.randint(len(ones))]
                j = zeros[np.random.randint(len(zeros))]
                h[i] = 0
                h[j] = 1
                ones.remove(i)
                zeros.remove(j)
                ones.append(j)
                zeros.append(i)
            corr = np.correlate(h, 1.0 - h, mode='full')
            cur_max = float(corr.max())
            stall = 0
            temp = max(0.5 / n, temp * 0.5)
            continue
        improved = False
        for _ in range(trials):
            i = ones[np.random.randint(len(ones))]
            j = zeros[np.random.randint(len(zeros))]
            h[i] = 0
            h[j] = 1
            new_corr = np.correlate(h, 1.0 - h, mode='full')
            new_max = float(new_corr.max())
            accept = False
            if new_max < cur_max - 1e-15:
                accept = True
            elif use_anneal and new_max < cur_max + temp:
                if np.random.random() < 0.3:
                    accept = True
            if accept:
                corr = new_corr
                cur_max = new_max
                ones.remove(i)
                zeros.remove(j)
                ones.append(j)
                zeros.append(i)
                if cur_max * dx < best_c5:
                    best_c5 = cur_max * dx
                    best_h = h.copy()
                improved = True
                break
            else:
                h[i] = 1
                h[j] = 0
        if not improved:
            stall += 1
        total_iters += 1
        if total_iters % 50 == 0:
            temp *= 0.995
    return best_h, best_c5

def smooth_obj_grad(h, tau):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    max_c = corr.max()
    shifted = np.clip(tau * (corr - max_c), -400, 400)
    exp_c = np.exp(shifted)
    s = exp_c.sum()
    p = exp_c / s
    obj = dx * (max_c + np.log(s) / tau)
    grad = np.zeros(n)
    for k in range(2 * n - 1):
        pk = p[k]
        if pk < 1e-15:
            continue
        sh = k - n + 1
        if sh >= 0:
            grad[:n - sh] += pk * (1.0 - h[sh:])
            grad[sh:] += -pk * h[:n - sh]
        else:
            grad[-sh:] += pk * (1.0 - h[:n + sh])
            grad[:n + sh] += -pk * h[-sh:]
    grad *= dx
    return obj, grad

def adam_optimize(h_init, n, tau, time_limit, start_time, lr=0.05, max_iters=100000):
    h = h_init.astype(float).copy()
    m = np.zeros(n)
    v = np.zeros(n)
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    t = 0
    best_c5 = compute_c5(h)
    best_h = h.copy()
    best_obj = float('inf')
    stall = 0
    for it in range(max_iters):
        if time.time() - start_time > time_limit:
            break
        t += 1
        obj, grad = smooth_obj_grad(h, tau)
        if obj < best_obj - 1e-12:
            best_obj = obj
            stall = 0
        else:
            stall += 1
        if stall > 200:
            break
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * grad * grad
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)
        h = h - lr * m_hat / (np.sqrt(v_hat) + eps)
        h = project_to_feasible(h, n)
        if it % 200 == 0:
            c5 = compute_c5(h)
            if c5 < best_c5:
                best_c5 = c5
                best_h = h.copy()
    c5 = compute_c5(h)
    if c5 < best_c5:
        best_c5 = c5
        best_h = h.copy()
    best_h = project_to_feasible(best_h, n)
    best_c5 = compute_c5(best_h)
    return best_h, best_c5

def run(seed=42, budget_s=1300, **kwargs):
    start_time = time.time()
    np.random.seed(seed)
    h_init = initial_h_values.copy()
    n_init = len(h_init)
    best_c5 = compute_c5(h_init)
    best_h = h_init.copy()

    def elapsed():
        return time.time() - start_time

    def remaining():
        return max(0.0, budget_s - elapsed())

    # Phase 1: Binary hill climb at initial resolution
    if remaining() > 120:
        tl = remaining() * 0.35
        h_b1, c5_b1 = binary_hill_climb(h_init, n_init, tl, start_time)
        if c5_b1 < best_c5:
            best_c5 = c5_b1
            best_h = h_b1
        else:
            best_h = h_init.copy()

    # Phase 2: Interpolate to 2x and binary search
    if remaining() > 100:
        n2 = n_init * 2
        h2 = interp_periodic(best_h, n2)
        h2_bin = binary_project(h2, n2)
        tl = remaining() * 0.20
        h_b2, c5_b2 = binary_hill_climb(h2_bin, n2, tl, start_time)
        if c5_b2 < best_c5:
            best_c5 = c5_b2
            best_h = h_b2
        else:
            best_h = interp_periodic(best_h, n2)
            best_h = project_to_feasible(best_h, n2)

    # Phase 3: Continuous refinement with smooth max
    if remaining() > 80:
        n_c = len(best_h)
        h_c = best_h.astype(float).copy()
        h_c = project_to_feasible(h_c, n_c)
        for tau_val in [20.0, 50.0, 100.0]:
            if remaining() < 40:
                break
            tl = remaining() * 0.18
            h_c, c5_c = adam_optimize(h_c, n_c, tau_val, tl, start_time + elapsed(), lr=0.03)
            if c5_c < best_c5:
                best_c5 = c5_c
                best_h = h_c
            else:
                h_c = best_h.astype(float).copy()

    # Phase 4: Binary round and refine again
    if remaining() > 60:
        n4 = len(best_h)
        h4_bin = binary_project(best_h, n4)
        tl = remaining() * 0.15
        h_b4, c5_b4 = binary_hill_climb(h4_bin, n4, tl, start_time)
        if c5_b4 < best_c5:
            best_c5 = c5_b4
            best_h = h_b4

    # Phase 5: Final continuous polish
    if remaining() > 30:
        n5 = len(best_h)
        h5 = best_h.astype(float).copy()
        h5 = project_to_feasible(h5, n5)
        c5_curr = compute_c5(h5)
        if c5_curr < best_c5:
            best_c5 = c5_curr
            best_h = h5
        tl = remaining() * 0.25
        h5, c5_5 = adam_optimize(h5, n5, 100.0, tl, start_time + elapsed(), lr=0.01)
        if c5_5 < best_c5:
            best_c5 = c5_5
            best_h = h5

    # Phase 6: Try a coarser resolution binary search for diversity
    if remaining() > 60:
        n_coarse = max(225, n_init // 2)
        h_coarse = interp_periodic(best_h, n_coarse)
        h_coarse_bin = binary_project(h_coarse, n_coarse)
        tl = remaining() * 0.20
        h_cb, c5_cb = binary_hill_climb(h_coarse_bin, n_coarse, tl, start_time)
        if c5_cb < best_c5:
            best_c5 = c5_cb
            best_h = interp_periodic(h_cb, len(best_h))
            best_h = project_to_feasible(best_h, len(best_h))
            new_c5 = compute_c5(best_h)
            if new_c5 < best_c5:
                best_c5 = new_c5

    # Final
    best_h = project_to_feasible(best_h, len(best_h))
    final_c5 = compute_c5(best_h)
    if final_c5 < best_c5:
        best_c5 = final_c5

    return best_h, best_c5, len(best_h)
```
