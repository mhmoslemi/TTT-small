```python
def swap_delta(h, a, b, N):
    """Compute ΔO(k) for all k when swapping h[a](1→0) and h[b](0→1)."""
    k = np.arange(-(N-1), N)
    
    # h[a-k] for all k (with boundary: 0 if out of range)
    def safe_index(idx):
        out = np.zeros(len(idx))
        mask = (idx >= 0) & (idx < N)
        out[mask] = h[idx[mask]]
        return out
    
    delta = safe_index(a - k) + safe_index(a + k) - safe_index(b - k) - safe_index(b + k)
    return delta
```

- Changing h[a] from 1 to 0: contributes (h[a-k]) - (1-h[a+k]) = h[a-k] + h[a+k] - 1
- Changing h[b] from 0 to 1: contributes (1-h[b+k]) - h[b-k] = 1 - h[b-k] - h[b+k]
- Total: h[a-k] + h[a+k] - 1 + 1 - h[b-k] - h[b+k] = (h[a-k]+h[a+k]) - (h[b-k]+h[b+k])

But this derivation assumes that h[a+k] is NOT b (i.e., the change in h[a] doesn't affect h[a+k] through the swap). Similarly for the other terms.

The problematic cases:
1. k=0: a+k = a, so h[a+k] = h[a] which IS changing. Also a-k = a.
