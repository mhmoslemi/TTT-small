where k_m = m-(n-1).

Actually:
sum_k w_k * (1-h[i+k]) is the cross-correlation of w with (1-h) at position i.

Actually, you know what, let me just skip the analytical gradient and use SLSQP (which handles constraints natively) or L-BFGS-B with the default numerical gradient. The key is to manage the time budget.

For n=336, L-BFGS-B with numerical gradient:
- Each gradient evaluation: 336 function evaluations
- Each function evaluation: one np.correlate (very fast, maybe 10-50μs in numpy)
- So each gradient: ~3-17ms
- With maxiter=200: ~0.6-3.4 seconds per T value
- With 7 T values: ~4-24 seconds total for L-BFGS-B phase

That's very manageable! Let me go with this.

For SLSQP, it's slower (more iterations for similar accuracy) but handles the equality constraint exactly. I'll use it for a few refinement passes.

Let me also add a key improvement: **iterative reweighting**. After each optimization, identify the top few lags that are near the maximum, and re-optimize with a softmax that's even more peaked (higher T) to focus on those.

And another idea: **try to enforce that the solution is "smooth"** by adding a small Hessian penalty term. This might help avoid oscillatory solutions that are artifacts of the discretization.

import numpy as np
from scipy.optimize import minimize
import time

def evaluate_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def project(h, n):
    target = n / 2.0
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    for _ in range(500):
        s = np.sum(h)
        d = target - s
        if abs(d) < 1e-14:
            break
        if d > 0:
            mask = h < 1.0 - 1e-15
        else:
            mask = h > 1e-15
        cnt = np.sum(mask)
        if cnt == 0:
            break
        h[mask] += d / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

def interp_to(h, n_from, n_to):
    if n_from == n_to:
        return h.copy()
    xf = np.linspace(0, 2, n_from, endpoint=False)
    xt = np.linspace(0, 2, n_to, endpoint=False)
    return np.interp(xt, xf, h)

def obj_lfbs(x, n, T, penalty):
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode='full')
    scaled = corr * T
    m = np.max(scaled)
    sm = (m + np.log(np.sum(np.exp(scaled - m)))) / T
    s = np.sum(x) - n / 2.0
    return sm * dx + penalty * s * s

def obj_slsqp(x, n, T):
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode='full')
    scaled = corr * T
    m = np.max(scaled)
    return (m + np.log(np.sum(np.exp(scaled - m)))) / T * dx
