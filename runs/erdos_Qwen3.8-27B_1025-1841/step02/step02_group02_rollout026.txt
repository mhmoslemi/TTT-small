A better local search: instead of random perturbations, do **coordinate descent**:
- For each coordinate i (or a random subset), try to optimize h[i] while keeping others fixed

- The optimal h[i] can be found by solving a small 1D problem

Actually, coordinate descent on this problem: fix all h[j] for j ≠ i, and optimize h[i]. The objective is max_k corr[k], and corr[k] is a quadratic in h[i] (specifically, a concave quadratic: -h[i]² * (number of terms) + h[i] * (linear terms) + constant).

Wait, corr[k] = sum_j h[j+sh](1-h[j]) for the appropriate shift. If h[i] appears in this sum, it appears as:
- h[i] * (1-h[i-sh]) if i = j+sh (i.e., h[i] is the "first" factor)
- (1-h[i]) * h[i+sh] if i = j (i.e., h[i] is inside the "1-h" factor)

So corr[k] as a function of h[i] (for fixed other h[j]):
= terms not involving h[i] + h[i](1-h[i-sh]) + (1-h[i])h[i+sh]
= const + h[i] - h[i]h[i-sh] + h[i+sh] - h[i]h[i+sh]
= const' + h[i](1 - h[i-sh] - h[i+sh])

This is LINEAR in h[i]! So for a fixed k, the optimal h[i] is either 0 or 1 (whichever minimizes the coefficient).

But we're minimizing the MAX over k, so it's more complex. The max of linear functions is convex, so we're minimizing a convex function of h[i] (for fixed others). The minimum is where the subgradient contains 0, which means we need to balance the top few shifts.

This suggests a **coordinate descent** approach:
- For each i, find h[i] that minimizes max_k corr[k] (1D convex optimization)
- This can be done by bisection on the 1D problem

This is O(n * log(1/ε) * n) per full pass = O(n² log(1/ε)) per pass. For n=900, that's about 810K * 20 = 16M ops per pass. At 100M ops/s, that's 0.16s per pass. In 100 seconds, we can do about 600 passes.

For the 1D subproblem: given h with h[i] = t, compute max_k corr[k](t). This is the max of linear functions of t (each corr[k] is linear in t as shown above). The minimum of this max is where the top two (or more) functions intersect.

To solve: 
1. Find which shifts k have h[i] in their overlap (i.e., where corr[k] depends on t)
2. For each such k, corr[k] = a_k * t + b_k where a_k and b_k can be computed
3. Minimize max_k (a_k * t + b_k) over t ∈ [0,1]
4. This is a 1D linear programming problem: minimize z subject to a_k * t + b_k ≤ z for all relevant k, 0 ≤ t ≤ 1

def smooth_grad_fast(h, p, tau):
    """Compute smooth max gradient using FFT"""
    n = len(h)
    dx = 2.0 / n
    
    # p has length 2n-1
    # A[j] = sum_k p[k] * (1-h[j-k+n-1]) for valid indices
    # This is a correlation
    
    # Use FFT to compute: A = correlate(f, q) where f[m] = 1-h[m], q[k] = p[k]
    # numpy correlate(a, v) = sum_k a[k+m] * v[k]
    # We want: A[j] = sum_k q[k] * f[j - k + n - 1]
    # Let l = j - k + n - 1, so k = j + n - 1 - l
    # A[j] = sum_l q[j+n-1-l] * f[l]
    # This is the convolution of q and f evaluated at j+n-1:
    # (q * f)[j+n-1] = sum_l q[j+n-1-l] * f[l]
    
    # So A[j] = (q * f)[j+n-1] for j = 0, ..., n-1
    
    # Similarly: B[j] = sum_k p[k] * h[j+k-n+1]
    # Let l = j+k-n+1, so k = l-j+n-1
    # B[j] = sum_l p[l-j+n-1] * h[l]
    # = (p * h_flipped)[?]
    # Actually: B[j] = sum_l p[l-j+n-1] * h[l]
    # Let m = l-j+n-1, so l = m+j-n+1
    # B[j] = sum_m p[m] * h[m+j-n+1]
    # This is the cross-correlation of p and h at offset j-n+1... 
    
    # Let me just use direct computation for now since n=900 and the Python loop
    # might be acceptable if I vectorize the inner ops.
    
    # Actually, let me use a different approach:
    # grad[j] = sum_k p[k] * ((1-h[j-sh_k]) - h[j+sh_k])
    # where sh_k = k - n + 1
    
    # Let me precompute the arrays and use slicing
    
    grad = np.zeros(n)
    one_minus_h = 1.0 - h
    
    for k in range(2*n-1):
        if p[k] < 1e-12:
            continue
        sh = k - n + 1
        # Term 1: (1-h[j-sh]) for j where j-sh is in [0,n)
        j0 = max(0, sh)
        j1 = min(n, sh + n)
        if j0 < j1:
            grad[j0:j1] += p[k] * one_minus_h[j0-sh:j1-sh]
        # Term 2: -h[j+sh] for j where j+sh is in [0,n)
        j0b = max(0, -sh)
        j1b = min(n, n - sh)
        if j0b < j1b:
            grad[j0b:j1b] -= p[k] * h[j0b+sh:j1b+sh]
    
    grad *= dx
    return grad
