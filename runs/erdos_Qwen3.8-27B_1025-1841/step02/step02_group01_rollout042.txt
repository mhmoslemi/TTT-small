            # (1-h[j-m]) for j in [m, n-1]
            grad[m:] += w * (1 - h[:-m])
            # -h[j+m] for j in [0, n-1-m]
            grad[:n-m] += w * (-h[m:])
    
    return grad * dx

Let me think of another approach: **alternating minimization over lags**.

The idea: for each lag k, the function f_k(h) = ∑_i h[i](1-h[i+k]) is not convex in h (it's bilinear). But if I fix all variables except those in a specific "diagonal", I get a simpler subproblem.

Actually, for a fixed k, f_k is a sum of terms h[i](1-h[i+k]). Each term involves a pair (h[i], h[i+k]). This is a quadratic assignment problem in disguise, which is NP-hard in general. So exact optimization over a single lag is hard.

Let me stick with the SLSQP + projected subgradient + coordinate descent approach.

2. Use simulated annealing (flip bits) to minimize the max overlap

For binary h, the objective is simply:
C₅ = max_k (number of i where h[i]=1 and h[(i+k) mod n]=0) * 2/n

Wait, but the problem doesn't use circular correlation. It uses linear correlation. So for binary h:

                if rem() < 50:
                    break
                h_new = slsqp_opt(h2, n2, T, maxiter=400)
                h_new = make_feasible(h_new, n2)
                c = compute_c5(h_new)
                if c < best_c5:
                    best_c5 = c
                    best_h = h_new.copy()
                    h2 = h_new.copy()

    # Phase 5: SLSQP polish at best resolution
    if rem() > 80:
        hn = len(best_h)
        for T in [400.0, 800.0]:
            if rem() < 40:
                break
            h_new = slsqp_opt(best_h, hn, T, maxiter=500, ftol=1e-14)
            h_new = make_feasible(h_new, hn)
            c = compute_c5(h_new)
            if c < best_c5:
                best_c5 = c
                best_h = h_new.copy()

    # Phase 6: Projected subgradient at final resolution
    if rem() > 60:
        hn = len(best_h)
        h_pg = proj_subgrad(best_h, steps=5000, lr=0.2, tb=min(80, rem() - 30))
        h_pg = make_feasible(h_pg, hn)
        c = compute_c5(h_pg)
        if c < best_c5:
            best_c5 = c
            best_h = h_pg.copy()

    # Phase 7: Binary-aware polish
    if rem() > 30:
        h_b, c_b = binary_polish(best_h, tb=min(40, rem() - 15))
        if c_b < best_c5:
            best_c5 = c_b
            best_h = h_b

    # Phase 8: Fine coordinate descent
    if rem() > 20:
        h_c, c_c = coord_desc(best_h, tb=max(10, rem() - 10))
        if c_c < best_c5:
            best_c5 = c_c
            best_h = h_c

    best_h = make_feasible(best_h, len(best_h))
    final_c5 = compute_c5(best_h)
    if final_c5 < best_c5:
        best_c5 = final_c5

    return best_h, best_c5, len(best_h)
