Let me redo this. corr[n-1+k] = ∑_i h[i+k]*(1-h[i])

The change when h[j] goes from old to new:
- Terms where h[i+k] = h[j], i.e., i = j-k: change = (new-old)*(1-h[j-k]) [if 0≤j-k<n]
- Terms where h[i] = h[j], i.e., i = j: change = h[j+k]*(1-new) - h[j+k]*(1-old) = h[j+k]*(old-new) [if 0≤j+k<n]

So Δcorr[n-1+k] = (new-old)*(1-h[j-k]) [if valid] + h[j+k]*(old-new) [if valid]
= (new-old) * [(1-h[j-k]) - h[j+k]] [combining, where valid indices]
= (new-old) * [1 - h[j-k] - h[j+k]] [with h out-of-bounds = 0]

Wait, for k=0: i=j-k=j and i=j are the same. The term is h[j]*(1-h[j]). Change: new*(1-new) - old*(1-old) = new - new² - old + old². This is NOT linear in (new-old) unless we're careful.

Actually: new*(1-new) - old*(1-old) = (new-old) - (new²-old²) = (new-old)(1-new-old)

So for k=0: Δcorr[n-1] = (new-old)*(1-new-old)

For k≠0: Δcorr[n-1+k] = (new-old)*(1-h[j-k]-h[j+k]) [with appropriate bounds]

def make_feasible(h, n):
    h = np.clip(h.astype(float).copy(), 0.0, 1.0)
    target = n / 2.0

        else:

def make_feasible(h, n):
    h = np.clip(h.astype(float).copy(), 0.0, 1.0)
