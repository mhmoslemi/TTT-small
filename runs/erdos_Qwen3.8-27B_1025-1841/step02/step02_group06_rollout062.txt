numpy.correlate(a, v, 'full')[k] = sum_n a[n+k] * conj(v[n])

Let i = n+k: sum_i a[i] * conj(v[i-k])

So numpy.correlate(a, v, 'full')[k] = (a ⋆ v)[k] where (a ⋆ v)[k] = sum_i a[i] * conj(v[i-k])

So they're the same! With m = k.

So the FFT cross-correlation gives us (x ⋆ y)[m] for m = 0, 1, ..., N-1.
For m in [0, n-1]: these are the "positive" lags (a ahead of v).
For m in [N-(n-1), N-1]: these correspond to negative lags. Specifically, (x ⋆ y)[N-m] = (x ⋆ y)[-m] for the linear cross-correlation.

Wait, for zero-padded arrays:

For m = n, ..., N-1: this wraps around in circular correlation, but since N >= 2n-1, the wrap-around terms are zero.

Actually, for zero-padded arrays:
(x ⋆ y)[m] = sum_j x[j] * conj(y[(j-m) mod N])

For m = 0: sum_j x[j] * y[j] (both zero-padded, so effectively sum_{j=0}^{n-1} x[j]y[j])
For m = 1: sum_j x[j] * y[j-1] (y[-1] = y[N-1] = 0)
= sum_{j=1}^{n-1} x[j] * y[j-1]

For m = n-1: sum_{j=n-1}^{n-1} x[j] * y[0] = x[n-1] * y[0]

For m = N-1: sum_j x[j] * y[(j-(N-1)) mod N] = sum_j x[j] * y[(j+1) mod N]
= x[0] * y[1] + x[1] * y[2] + ... (only non-zero where y is non-zero)
= sum_{j=0}^{n-2} x[j] * y[j+1]

This is (x ⋆ y)[-1] = sum_j x[j] * y[j+1], which is the cross-correlation at lag -1.

So: (x ⋆ y)[N-1] = (x ⋆ y)[-1]
In general: (x ⋆ y)[N-m] = (x ⋆ y)[-m] for m = 1, ..., n-1.

import numpy as np
import time


def project_to_feasible(g, n):
    target = n / 2.0
    g = np.asarray(g, dtype=np.float64)
    if g.size != n:
        raise ValueError
    lo = g.min() - 2.0
    hi = g.max() + 2.0
    for _ in range(50):
        mid = 0.5 * (lo + hi)
        clipped = np.clip(g - mid, 0.0, 1.0)
        s = clipped.sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(g - 0.5 * (lo + hi), 0.0, 1.0)


def interp_periodic(h, target_n):
    n = len(h)
    if n == target_n:
        return h.copy()
    x_old = np.arange(n, dtype=np.float64) * (2.0 / n)
    x_new = np.arange(target_n, dtype=np.float64) * (2.0 / target_n)
    return np.interp(x_new, x_old, h, period=2.0)


def corr_full(h):
    n = len(h)
    N = 1 << (2 * n - 2).bit_length()
    H = np.fft.rfft(h, N)
    F = np.fft.rfft(1.0 - h, N)
    xc = np.fft.irfft(H * F.conj(), N)
    return np.concatenate([xc[N - n + 1:], xc[:n]]) * (2.0 / n)


def c5_val(h):
    return corr_full(h).max()


def grad_lag(h, d, n, dx):
    g = np.zeros(n)
    a, b = max(0, d), min(n, n + d)
    if a < b:
        g[a:b] += 1.0 - h[a - d:b - d]
    a, b = max(0, -d), min(n, n - d)
    if a < b:
        g[a:b] -= h[a + d:b + d]
    return g * dx


def run_opt(h_init, n, time_limit, tau, K, lr, beta=0.85):
    dx = 2.0 / n
    h = project_to_feasible(h_init, n).copy()
    v = np.zeros(n)
    best = c5_val(h)
    best_h = h.copy()
    t0 = time.time()
    it = 0
    stall = 0
    
    while time.time() - t0 < time_limit:
        it += 1
        c = corr_full(h)
        mx = c.max()
        if mx < best - 1e-13:
            best = mx
            best_h = h.copy()
            stall = 0
        else:
            stall += 1
            if stall > 5000:
                break
        
        # Softmax weights
        max_c = c.max()
        shifted = np.clip(tau * (c - max_c), -500, 500)
        ec = np.exp(shifted)
        p = ec / ec.sum()
        
        # Top-K for gradient
        kM = min(K, 2 * n - 1)
        top = np.argpartition(-c, kM - 1)[:kM]
        pt = p[top].copy()
        pt_sum = pt.sum()
        if pt_sum > 0:
            pt /= pt_sum
        
        g = np.zeros(n)
        for i in range(kM):
            w = pt[i]
            if w < 1e-12:
                continue
            d = top[i] - n + 1
            a, b = max(0, d), min(n, n + d)
            if a < b:
                g[a:b] += w * (1.0 - h[a - d:b - d])
            a, b = max(0, -d), min(n, n - d)
            if a < b:
                g[a:b] -= w * h[a + d:b + d]
        g *= dx
        
        cur_lr = lr / (1.0 + it * 0.0005)
        v = beta * v - cur_lr * g
        h = project_to_feasible(h + v, n)
    
    fc = c5_val(h)
    if fc < best:
        best = fc
        best_h = h.copy()
    return best_h, best

Now, one issue: the `project_to_feasible` function is called every iteration. It does 50 bisection steps, each involving a clip and sum over n elements. For n=7200, that's 50 * 7200 * 2 = 720K operations per call. Over 2000 iterations, that's 1.4B operations. At ~1ns per op, that's 1.4 seconds. Not too bad.

But the gradient computation also loops over kM lags, each doing O(n) work. For kM=30, that's 30 * 7200 = 216K per call. Over 2000 iterations, 432M ops. Also fine.
