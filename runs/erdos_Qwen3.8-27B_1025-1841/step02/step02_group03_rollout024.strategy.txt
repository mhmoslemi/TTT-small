## Mathematical Specification

### Objective Function, Boundaries, and Resolutions
The objective is to **minimize**:

\[
C_5 = \max_k \int_0^2 h(x)(1 - h(x+k)) \, dx
\]

**Constraints:**
- \(\sum_{i=0}^{n-1} h_i = \frac{n}{2}\)  (discrete integral reference dx=2/n)
- \(0 \leq h_i \leq 1\) for all \(i\)

For discretization, select any \(n = 2^k\) for computational speed (\(n\) often 16, 32, 64 initially).

\(\mathbf{Variable Reformulation}\): We model h as a piecewise linear function defined at \(n\) points, but the function can be represented by control points at \(m\) positions where \(m << n\) (degN interpolation). This reduces dimensionality for optimization.

\[
h_i = \sum_{p=0}^m c_p \Phi_p(i/n)
\]

Where \(\Phi_p(x)\) are basis functions (e.g., B-splines, Fourier or wavelets). We choose B-splines for flexibility and ease.

\(\mathbf{Equilibrium Constraints}\): The sum must be exactly \(\frac{n}{2}\). Use projected-gradient style optimization with exact repair procedure.

### Solver and Objective Structure
The objective function in code:

```python
def compute_c5(h):
    dx = 2.0 / len(h)
    n = len(h)
    h_flat = h.reshape(-1, 1)
    lagged = np.zeros((n, n), dtype=np.float64)
    for i in range(-n+1, n):
        lagged[i, :] = h_flat
        lagged[i, :] = np.roll(h_flat, i, axis=0)
        lagged[i, :] = lagged[i, :] * (1 - h_flat)[:-1]  # Adjust for dx=2/n length
    corr = np.sum(lagged, axis=0)
    return np.max(corr) * dx  # Full correlation model
```

    h_init = make_feasible(h_init, n_points)  # Maintains [0,1] and sum.

            bootstrapped_idx = np.random.randint(0, len(h_curr))
            h_trial[bootstrapped_idx] = h_curr[bootstrapped_idx] + delta_sum / (1 if i==j else 1)   # Simulated Annealing uses trial move, not full plan.
            # However, we must maintain sum and [0,1]—hence clip.
            h_trial = repair_vector(h_trial, n_points)  # Repair after move.
            h_new = h_trial
            score_new = compute_c5(h_new)
            delta_score = score_new - h_curr_score
            if np.random.random() < np.exp(-delta_score / t):
                continue  # Accept anyway → Update
            h_curr = h_new
            h_curr_score = score_new
            if h_curr_score < best_score:
                best_score = h_curr_score
                best_possible_try = h_curr.copy()
        # If better score found, update.
        if h_curr_score < best_score:
            best_score = h_curr_score
            best_h = h_curr.copy()
            history.append(best_score)
            t = T_end  # Early termination if improvement guaranteed? Or use permutation.
    return best_h, best_score, n_points

## Search Choices and Variations

### Selection of Representations

- **B-splines and Fourier**: For coarse optimization, this reduces dimensionality to manageable levels (not used here).
- **Piecewise Linear (PLI)**: Implemented for interpolation and repair. Controls overlapping via knots.
- **Global to Local Fix** 
-  ** adaptive cooling** based on improvements—when plateau, turn down by a factor (all the SA above).
- **Probabilistic selection** of whether to adjust one or multiple knots—increasing exploration vs. exploitation.

### Dynamic Objective Functioning

-  **Objective** is `max_{k} ∫h(x)(1-h(x+k))dx`.
-  **Normalize objective by current function 'scale'** (not performed, but could be done).

### Computational Budget

**Dominant Cost:** SA step—O(10000) steps, each step O(n) for compute correlation. (Hence, n should be small—≤256). 

**Time Estimation**:
- At n=256, time ∼5 seconds for SA (worst-case), plus local optimization ∼15s.
- Budget allows one-run with 1000-2000 steps.

**Fallback**: If time for initial SA expires, return `initial_h_values` (or repair of that).
