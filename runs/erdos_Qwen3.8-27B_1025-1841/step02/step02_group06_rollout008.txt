```python
def compute_c5_fft(h):
    n = len(h)
    dx = 2.0 / n
    # Compute autocorrelation via FFT
    n_fft = 1
    while n_fft < 2 * n - 1:
        n_fft *= 2
    H = np.fft.fft(h, n_fft)
    acf = np.fft.ifft(H * np.conj(H)).real[:n]  # acf[d] = sum_{i=0}^{n-1-d} h[i]*h[i+d]
    
    # Prefix sums
    prefix = np.concatenate([[0], np.cumsum(h)])
    
    # For d = 0:
    corr_0 = h.sum() - np.sum(h*h)
    
    # For d > 0:
    max_corr = corr_0
    for d in range(1, n):
        valid_sum = prefix[n-d] - prefix[0]  # = sum h[0..n-d-1]
        ac = acf[d]
        corr_pos = valid_sum - ac
        # For -d:
        valid_sum_neg = prefix[n] - prefix[d]  # = sum h[d..n-1]
        ac_neg = ac  # autocorrelation is symmetric
        corr_neg = valid_sum_neg - ac_neg
        max_corr = max(max_corr, corr_pos, corr_neg)
    
    return max_corr * dx
```

Note: S_d = prefix[n-d] for d > 0 (sum of first n-d elements)
And S_{-d} = prefix[n] - prefix[d] = n/2 - prefix[d]

So the "sum" part varies with d depending on the distribution of h.

If h is "uniform" (h[i] = 1/2 for all i), then S_d = (n-d)/2 and R_d = (n-d)/4, so C_d = (n-d)/4 * dx for all d. The max is at d=0: C_0 = n/4 * dx = 1/2.

To do better, we need h to be non-uniform. The variation in h should be structured so that R_d is high for all d (making C_d low).

The "best" non-uniform h would have R_d close to (n-d)/4 for all d, but with S_d potentially different from (n-d)/2. The difference S_d - (n-d)/2 is determined by where h is concentrated.

```python
def project_to_feasible(g, n):
    """Project g onto {h: 0<=h<=1, sum(h)=n/2} using binary search on threshold."""
    target = n / 2.0
    lo = g.min() - 2.0
    hi = g.max() + 2.0

        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(g - mid, 0.0, 1.0))

            lo = mid
        else:
            hi = mid

            stall = 0
```

```python
def smooth_and_reproject(h, n, sigma=2):
```

**Alternative: Frank-Wolfe (Conditional Gradient) Method**

The problem: min_h max_k corr[k] s.t. 0≤h≤1, Σh=n/2

Frank-Wolfe for the smoothed version: min_h softmax_τ(max_k corr[k]) s.t. 0≤h≤1, Σh=n/2

The FW method: h_{t+1} = (1-γ_t)h_t + γ_t * FrankWolfeStep(h_t)

where FrankWolfeStep(h_t) = argmin_{z ∈ P} ⟨∇f(h_t), z⟩

P = {z: 0≤z≤1, Σz=n/2}

The FW step: minimize Σ_i grad[i]*z[i] s.t. 0≤z≤1, Σz=n/2

This is solved by: z[i] = 1 if grad[i] < θ, 0 if grad[i] > θ, and some value in (0,1) for the one index where grad[i] ≈ θ. Where θ is chosen so Σz = n/2.

This is essentially the same as project_to_feasible! The FW step gives the vertex (or edge) of the feasible polytope closest to -grad.

So FW iteration: 
1. Compute grad at h
2. z = project_to_feasible(-grad, n)  (this gives the FW step)
3. h_new = (1-γ)*h + γ*z
4. (optionally project h_new back to feasible set)

This is actually very clean! And each iteration is O(n) for the gradient (if using topM) + O(n log n) for the sort in projection.
