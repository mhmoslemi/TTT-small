If h takes values in (0,1) continuously, then h(x)(1-h(x+k)) can be made small by having h(x) and h(x+k) be correlated (both high or both low). This reduces the "crossover" h(1-h).

So the optimal strategy is to make h(x) as correlated with h(x+k) as possible for ALL k simultaneously. This is like making h as "smooth" as possible (highly autocorrelated) while maintaining the constraint ∫h = 1.

A smooth h that's concentrated: e.g., h is high in the middle and low at the edges. Then for small k, h(x) ≈ h(x+k), so h(x)(1-h(x+k)) ≈ 0. For large k, the overlap region is small, so the integral is small.

This suggests the optimal h is a "bump" function: high in the center, low at the edges!

Let me try h(x) = 0.5 + a*f(x) where f has zero mean. The key insight from the sinusoidal analysis is that we want h(x) and h(x+k) to be anti-correlated for the "bad" k values.

Actually wait, we want h(x)(1-h(x+k)) to be small, which means h(x) and h(x+k) should be correlated (both high or both low). So we want h to be highly autocorrelated!

But a highly autocorrelated function with ∫h = 1 over [0,2] would be approximately constant = 0.5, which gives h(1-h) = 0.25 and C₅ = 0.25 * 2 = 0.5.

The tension is: we want h to be smooth (highly autocorrelated) but also to deviate from 0.5 enough to satisfy ∫h = 1 (which requires the mean to be 0.5, so this is automatic).

Wait, ∫h = 1 over [0,2] means the average value is 1/2 = 0.5. So h already has mean 0.5!

So the question is: what's the best "shape" for h given that its mean is 0.5?

If h = 0.5 + ε*f where ∫f = 0:
h(x)(1-h(x+k)) = (0.5+εf(x))(0.5-εf(x+k)) = 0.25 - 0.5ε(f(x)+f(x+k)) + ε²f(x)f(x+k)

∫ = 0.5 - 0.5ε∫(f(x)+f(x+k))dx + ε²∫f(x)f(x+k)dx
= 0.5 - 0.5ε(∫f + ∫f(x+k)dx) + ε² * autocorrelation of f at lag k
= 0.5 + ε² * R_f(k)

(where ∫f = 0 and ∫f(x+k)dx = 0 for small k, approximately)

So to minimize C₅, we want to minimize the autocorrelation R_f(k) for the worst k. If f has negative autocorrelation everywhere, that would be ideal. But a function with zero mean and negative autocorrelation at ALL lags is impossible (the integral of the autocorrelation is ||f||² > 0, so it must be positive somewhere).

The best we can do is make R_f(k) as negative as possible for the "active" lags, while keeping it small (near zero) for others.

This is getting into the territory of optimal spectral design. The problem is equivalent to finding a function f with zero mean that minimizes max_k R_f(k) subject to some normalization.

This is related to the theory of "Golay sequences" or "complementary sequences" in signal processing, where one designs sequences with specific autocorrelation properties.
