The smooth max approach minimizes: (1/tau) * log(sum(exp(tau * O(k)))) which approximates max_k O(k). The gradient involves ALL shifts (weighted by softmax).

The LP approach: at each step, we identify the top M shifts and solve an LP to minimize the maximum of the linearized objectives for just those M shifts. This is more "direct" in targeting the active constraints.

The advantage of LP: it can make a large correction in one step (solving the exact LP for the top M constraints). The smooth max approach takes small gradient steps.

The disadvantage of LP: the linearization might be poor if the step is too large, and we only consider M shifts (not all).

Now, let me also think about a completely different approach: **direct search on the "active" set**.

The key insight is that at the optimum, only a few shifts k are "active" (i.e., achieve the maximum). If we could identify the active set, we could solve the problem more efficiently.

At the optimum, the KKT conditions say:
- For active k: ∇O(k) is in the span of the active gradients
- The gradient of the objective (max of O(k)) is a convex combination of the active gradients

So at the optimum, there exist weights λ_k ≥ 0 (sum λ_k = 1) such that:
∑_k λ_k ∇O(k) = 0 (stationarity, ignoring constraints)

This is the condition for a weighted sum of the active gradients to vanish. We can use this to design an algorithm:
1. Identify the active set (top shifts)
2. Find weights λ_k such that the weighted gradient is as close to zero as possible
3. If not close to zero, update h in the direction of the negative weighted gradient

This is essentially what the smooth max approach does (the softmax weights are the λ_k). So there's not much new here.

```python
def smooth_obj_grad(h, tau, threshold=1e-6):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    max_c = corr.max()
    shifted = np.clip(tau * (corr - max_c), -500, 500)
    exp_c = np.exp(shifted)
    s = exp_c.sum()
    p = exp_c / s
    grad = np.zeros(n)
    
    # Only process shifts with significant weight
    active = np.where(p > threshold)[0]
    for k in active:
        pk = p[k]
        sh = k - n + 1
        j0 = max(0, -sh)
        j1 = min(n, n - sh)
        if j0 < j1:
            grad[j0:j1] += pk * (1.0 - h[j0+sh:j1+sh])
        b0 = max(0, sh)
        b1 = min(n, n + sh)
        if b0 < b1:
            grad[b0:b1] -= pk * h[b0-sh:b1-sh]
    
    grad *= dx
    obj = dx * (max_c + np.log(s) / tau)
    return obj, grad
```

    target = n / 2.0
    lo = g.min() - 2.0

        s = np.sum(np.clip(g - mid, 0.0, 1.0))
        if s > target:

        else:
