where d_k = k - (n-1), and h[t] = 0 for t < 0 or t ≥ n.

Now, the gradient of the softmax-weighted sum:
G[i] = Σ_k p[k] * ∂c[k]/∂h[i] = Σ_k p[k] * (1 - h[i+d_k] - h[i-d_k])
= (Σ_k p[k]) - Σ_k p[k]*h[i+d_k] - Σ_k p[k]*h[i-d_k]
= 1 - Σ_k p[k]*h[i+d_k] - Σ_k p[k]*h[i-d_k]

(since Σ_k p[k] = 1 for normalized softmax)

Now, let d = d_k = k - (n-1), ranging from -(n-1) to n-1.
Let q[d] = p[d+(n-1)] for d in [-(n-1), n-1].

First sum: Σ_d q[d]*h[i+d]
Second sum: Σ_d q[d]*h[i-d] = Σ_d q[-d]*h[i+d] (substituting d→-d)

So G[i] = 1 - Σ_d (q[d] + q[-d])*h[i+d]

Let r[d] = q[d] + q[-d] (symmetric: r[d] = r[-d])
G[i] = 1 - Σ_d r[d]*h[i+d]

This is a correlation of r with h! Specifically:
Σ_d r[d]*h[i+d] = Σ_d r[d]*h[i+d] = (r ⊛ h)[i + offset]

In terms of standard arrays:
r is defined for d in [-(n-1), n-1], length 2n-1.
Let R[j] = r[j-(n-1)] for j in [0, 2n-2]. (R is symmetric: R[j] = R[2n-2-j])

Σ_d r[d]*h[i+d] = Σ_j R[j]*h[i+j-(n-1)] = Σ_j h[i+j-(n-1)]*R[j]

This is the cross-correlation of h and R evaluated at position i-(n-1):
(h ⊛ R)[i-(n-1)] = Σ_j h[j]*R[i-(n-1)-j]... 

Hmm, let me just use the direct FFT formula.

Σ_d r[d]*h[i+d] for d in [max(-(n-1), -(i)), min(n-1, n-1-i)]
= Σ_{j: 0≤j≤n-1} r[j-i]*h[j] (substituting j = i+d)
= Σ_j h[j]*r[j-i]

This is the cross-correlation of h with r at lag i:
= (h ⊛ r)[i] where (h ⊛ r)[i] = Σ_j h[j]*r[j-i] (with r[t]=0 for t outside [-(n-1), n-1])

Using FFT: (h ⊛ r)[i] = ifft(FFT(h) * conj(FFT(r)))[i]

where r is embedded in an array of appropriate length.

So the algorithm is:
1. Compute r[d] = q[d] + q[-d] for d in [-(n-1), n-1], where q[d] = p[d+n-1]
2. Embed r in an array of length ≥ 2n-1 (centered at index n-1)
3. Compute FFT of h (padded) and FFT of r (padded)
4. G = 1 - ifft(FFT(h) * conj(FFT(r)))[appropriate slice]
5. Multiply by dx

```python
def fft_gradient(h, p, n):
    """Compute gradient of Σ_k p[k]*corr[k]*dx.
    h: length n
    p: length 2n-1 (softmax weights, sum to 1)
    Returns: gradient of length n
    """
    dx = 2.0 / n
    
    # q[d] = p[d + n - 1] for d in [-(n-1), n-1]
    # r[d] = q[d] + q[-d] = p[d+n-1] + p[-d+n-1] = p[d+n-1] + p[n-1-d]
    # R[j] = r[j-(n-1)] = p[j] + p[2*(n-1)-j] for j in [0, 2n-2]
    
    R = p + p[::-1].copy()
    # R[j] = p[j] + p[2n-2-j] for j in [0, 2n-2]
    # This is r[j-(n-1)] = q[j-(n-1)] + q[(n-1)-j] = p[j] + p[2n-2-j] ✓
    
    # We need (h ⊛ r)[i] = Σ_j h[j]*r[j-i] for i in [0, n-1]
    # = Σ_j h[j]*R[j-i+n-1]
    # Let's define: S[i] = Σ_j h[j]*R[j-i+n-1] for i in [0, n-1]
    # = Σ_j h[j]*R[n-1 + (j-i)]
    # Substituting m = j-i: Σ_m h[m+i]*R[n-1+m]
    # This is a cross-correlation of h and R!
    
    # (h ⊛ R)[n-1+i] = Σ_m h[m+i]*R[m]... 
    
    # Actually, the standard cross-correlation:
    # xcorr(a, b)[k] = Σ_n a[n]*b[n+k]
    # In terms of convolution: xcorr(a,b) = conv(a, flip(b))
    
    # We want: S[i] = Σ_j h[j]*R[j-(i-(n-1))]
    # Let k = i - (n-1): S[i] = Σ_j h[j]*R[j-k] = (h ⊛ R)[k] where (h⊛R)[k] = Σ_j h[j]*R[j-k]
    
    # Using FFT: (h ⊛ R)[k] = ifft(FFT(h)*conj(FFT(R)))[k]
    
    size = 1
    while size < n + (2*n - 1):  # need at least n + 2n-2 = 3n-2
        size *= 2
    
    H = np.zeros(size)
    H[:n] = h
    Rr = np.zeros(size)
    Rr[:2*n-1] = R
    
    Hf = np.fft.rfft(H)
    Rf = np.fft.rfft(Rr)
    
    xcorr = np.fft.irfft(Hf * np.conj(Rf), size)
    
    # xcorr[k] = Σ_j h[j]*R[j-k] (for the non-wrapping part)
    # We need xcorr[k] for k = i-(n-1), i.e., k from -(n-1) to 0
    # xcorr[k] for negative k: xcorr[k] = xcorr[k] (it's defined for all k)
    # Actually, the linear cross-correlation has length n + (2n-1) - 1 = 3n-2
    # xcorr[0] to xcorr[3n-3]
    # k = i-(n-1) ranges from -(n-1) to 0
    # Negative k in circular corr of length `size`: xcorr[k mod size] = xcorr[k + size]
    # But since size > 3n-2, there's no wrapping for the valid range.
    # xcorr[k] for k in [-(n-1), 0] corresponds to xcorr[size + k] in the circular result? No.
    
    # Let me think again. The linear cross-correlation (h ⊛ R)[k] = Σ_j h[j]*R[j-k]
    # is defined for k from -(len(R)-1) to len(h)-1, i.e., k from -(2n-2) to n-1.
    # In the FFT computation with zero-padding to `size`:
    # xcorr_circ[k] = Σ_j h[j]*R[(j-k) mod size]
    # For k in [0, size-1], this equals the linear cross-correlation at lag k
    # only if there's no wrap-around.
    
    # The linear xcorr has support k ∈ [-(2n-2), n-1].
    # In the circular result (length `size`):
    # xcorr_circ[k] = linear_xcorr[k] for k ∈ [0, n-1]
    # xcorr_circ[k] = linear_xcorr[k - size] for k ∈ [size-(2n-2), size-1]
    
    # We need linear_xcorr[k] for k ∈ [-(n-1), 0].
    # For k=0: xcorr_circ[0]
    # For k=-d (d>0): xcorr_circ[size-d]
    
    # So S[i] = xcorr[i-(n-1)]:
    # For i < n-1: k = i-(n-1) < 0, use xcorr_circ[size + i - (n-1)]
    # For i = n-1: k = 0, use xcorr_circ[0]
    # For i > n-1: not needed (i only goes to n-1)
    
    # So S[i] = xcorr_circ[(i - (n-1)) % size]
    
    S = xcorr[(np.arange(n) - (n-1)) % size]
    
    grad = (1.0 - S) * dx
    return grad
```

**Algorithm: Adaptive Softmax Projected Gradient with FISTA**

```
Initialize h, compute corr, c5
For each iteration:
  1. Compute softmax weights p (with temperature τ)
  2. Compute gradient G via FFT
  3. FISTA update: y = h + (t-1)/(t+2) * (h - h_prev)
     h_new = project(y - lr * G)
  4. Update τ (increase to focus on max lags)
  5. Adaptive lr (backtracking or fixed decay)
```

The FISTA (accelerated projected gradient) should converge faster for the smooth part.

However, the objective max_k f_k(h) is not smooth (it's the max of smooth functions). The softmax smoothing makes it smooth, and the gradient of the smoothed objective is what we compute. As τ → ∞, we recover the subgradient of the max.

For FISTA to work well, we need a Lipschitz constant for the gradient. The smoothed objective has gradient Lipschitz constant roughly proportional to τ * (max eigenvalue of Hessian). This is tricky to bound, so I'll use a practical approach: start with a small lr and adapt.

Let me also consider: **What about using scipy's `minimize` with L-BFGS-B on the smoothed objective?**

The smoothed objective F_τ(h) = (1/τ) * log(Σ_k exp(τ * f_k(h))) is convex if each f_k is convex (which they're not - they're bilinear). So L-BFGS-B won't guarantee convergence to a global min, but it might find a better local min than projected gradient.

The issue is that the Hessian of f_k is not positive semidefinite (it's bilinear, so the Hessian has both positive and negative eigenvalues). So the smoothed objective is not convex, and L-BFGS-B might not be reliable.

Let me stick with projected gradient + FISTA acceleration.

**Key hyperparameters to tune:**
- τ (softmax temperature): Start low (e.g., 5), increase over time
- Learning rate: Start at 0.5/dx or similar, decay
- FISTA momentum: Standard (t-1)/(t+2)
- Resolution: n = 3600, 7200

```python
import numpy as np
import time

def project_to_feasible(g, n):
    target = n / 2.0
    lo = float(g.min()) - 2.0
    hi = float(g.max()) + 2.0
    for _ in range(50):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(g - mid, 0.0, 1.0))
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(g - (lo + hi) / 2.0, 0.0, 1.0)

def compute_c5(h):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(corr.max() * (2.0 / n))

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def fft_gradient(h, p, n):
    """FFT-based gradient of sum_k p[k]*corr[k]*dx"""
    dx = 2.0 / n
    R = p + p[::-1].copy()
    size = 1
    while size < 3 * n:
        size *= 2
    H = np.zeros(size)
    H[:n] = h
    Rr = np.zeros(size)
    Rr[:2*n-1] = R
    Hf = np.fft.rfft(H)
    Rf = np.fft.rfft(Rr)
    xcorr = np.fft.irfft(Hf * np.conj(Rf), size)
    idx = (np.arange(n) - (n-1)) % size
    S = xcorr[idx]
    return (1.0 - S) * dx

def softmax_weights(corr, tau):
    """Compute softmax weights from correlation values."""
    c = corr * (2.0 / len(corr))  # scale by dx... actually no
    # corr values are sums, we want to weight by the actual integral values
    # f_k = corr[k] * dx
    # softmax on f_k / temperature
    max_c = corr.max()
    shifted = tau * (corr - max_c)
    shifted = np.clip(shifted, -500, 500)
    e = np.exp(shifted)
    s = e.sum()
    if s == 0:
        return np.ones(len(corr)) / len(corr)
    return e / s

def optimize_fft(h, n, time_limit, tau_init=5.0, tau_max=200.0, lr_init=0.3, use_fista=True):
    """Main optimization loop with FFT gradient."""
    dx = 2.0 / n
    h = project_to_feasible(h.copy(), n)
    corr = compute_corr(h)
    best_c5 = float(corr.max() * dx)
    best_h = h.copy()
    start = time.time()
    
    lr = lr_init
    t = 1.0
    h_prev = h.copy()
    tau = tau_init
    stall = 0
    patience = 500
    
    for it in range(100000):
        if time.time() - start > time_limit:
            break
        
        # Compute correlation and objective
        corr = compute_corr(h)
        c5_cur = float(corr.max() * dx)
        if c5_cur < best_c5 - 1e-15:
            best_c5 = c5_cur
            best_h = h.copy()
            stall = 0
        else:
            stall += 1
        
        # Softmax weights
        p = softmax_weights(corr, tau)
        
        # Gradient via FFT
        grad = fft_gradient(h, p, n)
        
        # FISTA update
        if use_fista:
            momentum = (t - 1) / (t + 2)
            y = h + momentum * (h - h_prev)
        else:
            y = h
        
        h_prev = h.copy()
        h_new = project_to_feasible(y - lr * grad, n)
        
        # Adaptive lr
        if stall > patience:
            lr *= 0.7
            tau = min(tau * 1.5, tau_max)
            stall = 0
            t = 1.0  # reset momentum
            if lr < 1e-12:
                break
        
        # Gradually increase tau
        tau = min(tau * 1.001, tau_max)
        
        h = h_new
        t += 1.0
    
    return best_h, best_c5

def subgrad_polish(h, n, time_limit, topK=5, lr_init=0.002):
    """Subgradient polish on top-K lags."""
    dx = 2.0 / n
    h = project_to_feasible(h.copy(), n)
    best_c5 = compute_c5(h)
    best_h = h.copy()
    start = time.time()
    lr = lr_init
    
    for it in range(200000):
        if time.time() - start > time_limit:
            break
        
        corr = compute_corr(h)
        c5_cur = float(corr.max() * dx)
        if c5_cur < best_c5 - 1e-15:
            best_c5 = c5_cur
            best_h = h.copy()
        
        top_idx = np.argsort(corr)[-topK:]
        grad = np.zeros(n)
        for ki in top_idx:
            d = ki - (n - 1)
            for _ in range(2):  # two terms
                pass
            # grad[i] += (1 - h[i+d]) - h[i-d] (with boundary handling)
            # Use vectorized:
            # Term 1: (1 - h[i+d]) for valid i+d
            if d >= 0:
                # h[i+d] valid for i in [0, n-1-d]
                grad[:n-d] += (1.0 - h[d:])
                # h[i-d] valid for i in [d, n-1]
                grad[d:] -= h[:n-d]
            else:
                dd = -d
                # h[i+d] = h[i-dd] valid for i in [dd, n-1]
                grad[dd:] += (1.0 - h[:n-dd])
                # h[i-d] = h[i+dd] valid for i in [0, n-1-dd]
                grad[:n-dd] -= h[dd:]
        
        grad *= dx / topK
        
        cur_lr = lr / (1.0 + it * 0.01)
        h_new = project_to_feasible(h - cur_lr * grad, n)
        h = h_new
    
    return best_h, best_c5

def run(seed=42, budget_s=1300, **kwargs):
    start_time = time.time()
    np.random.seed(seed)
    
    def remaining():
        return max(0.0, budget_s - (time.time() - start_time))
    
    # Start from initial
    h_init = initial_h_values.copy()
    n_init = len(h_init)
    best_h = h_init.copy()
    best_c5 = compute_c5(best_h)
    
    # Phase 1: FFT optimization at initial resolution with various tau
    if remaining() > 200:
        for tau in [5.0, 15.0, 40.0, 100.0]:
            if remaining() < 50:
                break
            tl = min(remaining() * 0.2, 200.0)
            h1, c5_1 = optimize_fft(best_h.copy(), n_init, tl, tau_init=tau,
                                     tau_max=tau*3, lr_init=0.3)
            if c5_1 < best_c5:
                best_c5 = c5_1
                best_h = h1.copy()
    
    # Phase 2: Increase resolution
    n2 = n_init * 2
    if remaining() > 150:
        # Upsample
        x_old = np.arange(n_init) * (2.0 / n_init)
        x_new = np.arange(n2) * (2.0 / n2)
        h2 = np.interp(x_new, x_old, best_h)
        h2 = project_to_feasible(h2, n2)
        
        for tau in [20.0, 60.0]:
            if remaining() < 40:
                break
            tl = min(remaining() * 0.25, 200.0)
            h2, c5_2 = optimize_fft(h2, n2, tl, tau_init=tau,
                                     tau_max=tau*3, lr_init=0.2)
            if c5_2 < best_c5:
                best_c5 = c5_2
                best_h = h2.copy()
    
    # Phase 3: Subgradient polish
    if remaining() > 60:
```

```python
import numpy as np
import time


def project_to_feasible(g, n):
    target = n / 2.0
    lo = float(g.min()) - 2.0
    hi = float(g.max()) + 2.0
    for _ in range(50):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(g - mid, 0.0, 1.0))
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(g - (lo + hi) / 2.0, 0.0, 1.0)


def compute_c5(h):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(corr.max() * (2.0 / n))


def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')


def fft_gradient(h, p, n):
    dx = 2.0 / n
    R = p + p[::-1].copy()
    size = 1
    while size < 3 * n:
        size *= 2
    H = np.zeros(size)
    H[:n] = h
    Rr = np.zeros(size)
    Rr[:2 * n - 1] = R
    Hf = np.fft.rfft(H)
    Rf = np.fft.rfft(Rr)
    xcorr = np.fft.irfft(Hf * np.conj(Rf), size)
    idx = (np.arange(n) - (n - 1)) % size
    S = xcorr[idx]
    return (1.0 - S) * dx


def softmax_weights(corr, tau):
    max_c = float(corr.max())
    shifted = np.clip(tau * (corr - max_c), -500, 500)
    e = np.exp(shifted)
    s = e.sum()
    if s < 1e-300:
        return np.ones(len(corr)) / len(corr)
    return e / s


def optimize_fft(h, n, time_limit, tau_init=10.0, tau_end=100.0, lr_init=0.4):
    dx = 2.0 / n
    h = project_to_feasible(h.copy(), n)
    corr = compute_corr(h)
    best_c5 = float(corr.max() * dx)
    best_h = h.copy()
    start = time.time()
    lr = lr_init
    t = 1.0
    h_prev = h.copy()
    tau = tau_init
    stall = 0
    patience = 800
    num_lags = 2 * n - 1

    for it in range(200000):
        if time.time() - start > time_limit:
            break
        corr = compute_corr(h)
        c5_cur = float(corr.max() * dx)
        if c5_cur < best_c5 - 1e-14:
            best_c5 = c5_cur
            best_h = h.copy()
            stall = 0
        else:
            stall += 1

        progress = min(1.0, it / 5000.0)
        tau_cur = tau_init + (tau_end - tau_init) * progress
        p = softmax_weights(corr, tau_cur)

        topM = max(50, int(0.05 * num_lags))
        if topM < num_lags:
            idx_top = np.argpartition(p, -topM)[-topM:]
            p_trunc = np.zeros(num_lags)
            p_trunc[idx_top] = p[idx_top]
            s = p_trunc.sum()
            if s > 1e-300:
                p = p_trunc / s

        grad = fft_gradient(h, p, n)

        momentum = (t - 1.0) / (t + 2.0)
        y = h + momentum * (h - h_prev)
        h_prev = h.copy()
        h = project_to_feasible(y - lr * grad, n)

        if stall > patience:
            lr *= 0.6
            h_prev = h.copy()
            t = 1.0
            stall = 0
            if lr < 1e-11:
                break
        t += 1.0

    return best_h, best_c5


def subgrad_polish(h, n, time_limit, topK=5):
    dx = 2.0 / n
    h = project_to_feasible(h.copy(), n)
    best_c5 = compute_c5(h)
    best_h = h.copy()
    start = time.time()
    lr = 0.003
    stall = 0

    for it in range(500000):
        if time.time() - start > time_limit:
            break
        corr = compute_corr(h)
        c5_cur = float(corr.max() * dx)
        if c5_cur < best_c5 - 1e-14:
            best_c5 = c5_cur
            best_h = h.copy()
            stall = 0
        else:
            stall += 1

        top_idx = np.argsort(corr)[-topK:]
        grad = np.zeros(n)
        for ki in top_idx:
            d = ki - (n - 1)
            if d >= 0:
                grad[:n - d] += (1.0 - h[d:])
                grad[d:] -= h[:n - d]
            else:
                dd = -d
                grad[dd:] += (1.0 - h[:n - dd])
                grad[:n - dd] -= h[dd:]
        grad *= dx / topK

        cur_lr = lr / (1.0 + it * 0.005)
        h_new = project_to_feasible(h - cur_lr * grad, n)

        if stall > 300:
            lr *= 0.7
            stall = 0
            if lr < 1e-13:
                break
        h = h_new

    return best_h, best_c5


def coordinate_snap(h, n):
    corr = compute_corr(h)
    c5_cur = float(corr.max() * (2.0 / n))
    improved = True
    max_rounds = 3
    for _ in range(max_rounds):
        if not improved:
            break
        improved = False
        for i in range(n):
            old = h[i]
            if old <= 1e-6 or old >= 1.0 - 1e-6:
                continue
            for trial in [0.0, 1.0]:
                h[i] = trial
                proj = project_to_feasible(h, n)
                h[i] = proj[i]
                c = compute_c5(h)
                if c < c5_cur - 1e-8:
                    c5_cur = c
                    improved = True
                    break
            h[i] = project_to_feasible(h, n)
    return h, c5_cur


def upsample(h, target_n):
    n = len(h)
    if n == target_n:
        return h.copy()
    x_old = np.arange(n) * (2.0 / n)
    x_new = np.arange(target_n) * (2.0 / target_n)
    return np.interp(x_new, x_old, h)
```
