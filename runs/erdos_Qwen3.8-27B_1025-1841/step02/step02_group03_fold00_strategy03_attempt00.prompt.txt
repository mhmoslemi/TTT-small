## Mathematical Specification

### Objective Function, Boundaries, and Resolutions
The objective is to **minimize**:

\[
C_5 = \max_k \int_0^2 h(x)(1 - h(x+k)) \, dx
\]

**Constraints:**
- \(\sum_{i=0}^{n-1} h_i = \frac{n}{2}\)  (discrete integral reference dx=2/n)
- \(0 \leq h_i \leq 1\) for all \(i\)

For discretization, select any \(n = 2^k\) for computational speed (\(n\) often 16, 32, 64 initially).

\(\mathbf{Variable Reformulation}\): We model h as a piecewise linear function defined at \(n\) points, but the function can be represented by control points at \(m\) positions where \(m << n\) (degN interpolation). This reduces dimensionality for optimization.

\[
h_i = \sum_{p=0}^m c_p \Phi_p(i/n)
\]

Where \(\Phi_p(x)\) are basis functions (e.g., B-splines, Fourier or wavelets). We choose B-splines for flexibility and ease.

\(\mathbf{Equilibrium Constraints}\): The sum must be exactly \(\frac{n}{2}\). Use projected-gradient style optimization with exact repair procedure.

```python
def compute_c5(h):
    dx = 2.0 / len(h)
    n = len(h)
    h_flat = h.reshape(-1, 1)
    lagged = np.zeros((n, n), dtype=np.float64)
    for i in range(-n+1, n):
        lagged[i, :] = h_flat
        lagged[i, :] = np.roll(h_flat, i, axis=0)
        lagged[i, :] = lagged[i, :] * (1 - h_flat)[:-1]  # Adjust for dx=2/n length
    corr = np.sum(lagged, axis=0)
    return np.max(corr) * dx  # Full correlation model
```
