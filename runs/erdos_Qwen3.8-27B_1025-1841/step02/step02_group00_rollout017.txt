Let me also think about the binary local search more carefully:

For binary h (0/1) with sum = n/2:
- Flipping h[p] from 0 to 1 makes sum = n/2 + 1 (infeasible)
- We need to simultaneously flip some h[q] from 1 to 0
- This is a "swap" operation: 0 at p → 1, 1 at q → 0

The change in correlation for a swap (p, q):
- h[p] += 1, h[q] -= 1
- (1-h)[p] -= 1, (1-h)[q] += 1
- Effect on corr: delta_corr = contribution of +1 at h[p] and +1 at (1-h)[q] minus contribution of -1 at h[q] and -1 at (1-h)[p]

This is O(n) to compute for a given (p,q) pair.

But trying all (p,q) pairs is O(n²) per step, and with n=2048, that's 4M pairs. Each takes O(n) to evaluate naively, so O(n³) total per step. That's too slow.

Better: for each p (the 0→1 position), find the best q (the 1→0 position) to swap with. For a fixed p, the change in corr due to h[p]→1 is a fixed vector (call it Δp). Then for each candidate q, the additional change is Δq (from h[q]→0). So the total change is Δp + Δq, and we want to minimize the max of (corr + Δp + Δq).

If we precompute Δp for each p, then for each (p,q) we just add two O(n) vectors and find the max. That's O(n) per pair, O(n³) total per pass.

For n=2048, that's about 8.6 billion operations per pass. Too slow.

Alternative: use a greedy approach. For each p (0→1), find the q that minimizes the max. Use a priority queue or top-k selection on the resulting max.

Or: just do SLSQP with fractional values and skip the binary local search. The SLSQP already handles the continuous optimization.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_feasible(h, n):
    h = np.clip(np.asarray(h, dtype=float), 0.0, 1.0).copy()
    target = n / 2.0
    for _ in range(200):
        diff = target - np.sum(h)
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-15
        else:
            mask = h > 1e-15
        cnt = np.sum(mask)
        if cnt == 0:
            break
        h[mask] = np.clip(h[mask] + diff / cnt, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-12:
        # Distribute remaining diff
        step_size = 1e-6
        if diff > 0:
            candidates = np.where(h < 1.0)[0]
        else:
            candidates = np.where(h > 0.0)[0]
        for idx in candidates:
            if abs(diff) < step_size:
                h[idx] = np.clip(h[idx] + diff, 0.0, 1.0)
                break
            amt = step_size if diff > 0 else -step_size
            if diff > 0:
                amt = min(amt, 1.0 - h[idx])
            else:
                amt = max(amt, -h[idx])
            h[idx] += amt
            diff -= amt
            if abs(diff) < 1e-12:
                break
    # Final fix
    diff = target - np.sum(h)
    if abs(diff) > 1e-12:
        if diff > 0:
            idx = np.argmin(h)
            h[idx] = np.clip(h[idx] + min(diff, 1.0 - h[idx]), 0.0, 1.0)
        else:
            idx = np.argmax(h)
            h[idx] = np.clip(h[idx] + max(diff, -h[idx]), 0.0, 1.0)
    return h

def upsample_h(h, new_n):
    old_n = len(h)
    if new_n == old_n:
        return make_feasible(h.copy(), new_n)
    old_x = np.linspace(0.0, 2.0, old_n, endpoint=False)
    new_x = np.linspace(0.0, 2.0, new_n, endpoint=False)
    h_new = np.interp(new_x, old_x, h, period=2.0)
    return make_feasible(h_new, new_n)

def slsqp_solve(h0, n, T, max_iter, ftol=1e-14):
    """SLSQP with analytical gradient for the log-sum-exp smoothed max."""
    dx = 2.0 / n
    
    def objective(g):
        corr = np.correlate(g, 1.0 - g, mode='full')
        mc = np.max(corr)
        s = np.sum(np.exp(T * (corr - mc)))
        return (mc + np.log(s) / T) * dx
    
    def gradient(g):
        corr = np.correlate(g, 1.0 - g, mode='full')
        mc = np.max(corr)
        w = np.exp(T * (corr - mc))
        w_sum = np.sum(w)
        w = w / w_sum  # softmax weights
        
        # term1[p] = sum_i (1-g)[i] * w[p+n-1-i]
        # = convolve(1-g, w, 'full')[p+n-1]
        term1 = np.convolve(1.0 - g, w, mode='full')[n-1 : 2*n-1]
        
        # term2[p] = correlate(g, w, 'full')[3n-3-p]
        corr_gw = np.correlate(g, w, mode='full')
        term2 = corr_gw[3*n-3 : 2*n-3 : -1]
        
        return dx * (term1 - term2)
    
    def cons_func(g):
        return np.sum(g) - n / 2.0
    
    def cons_jac(g):
        return np.ones(n)
    
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cons_func, 'jac': cons_jac}]
    
    res = minimize(objective, h0, jac=gradient, method='SLSQP',
                   bounds=bounds, constraints=cons,
                   options={'maxiter': max_iter, 'ftol': ftol})
    return make_feasible(res.x, n)
