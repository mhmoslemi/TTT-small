**Key insight for improvement**: The previous approach used SLSQP with a soft-max approximation. The main limitations are:
1. SLSQP is a local method
2. The soft-max approximation might not be tight enough
3. The resolution might not be high enough

**New approach ideas:**

1. **Binary search on C₅ with non-convex optimization**: For a target C, try to find h such that max_k c_k ≤ C. Use alternating projections or penalty methods.

2. **Subgradient method with projection**: Use the subgradient of the max function (which is the indicator of the maximizing lag) to do projected subgradient descent.

3. **Evolutionary/genetic algorithm on binary sequences**: Start with random binary sequences and use local search (flipping individual bits) to minimize C₅.

4. **Simulated annealing on binary sequences**: Flip bits with a Metropolis-like acceptance criterion.

5. **Combination approach**: 
   - First, find a good binary sequence using local search
   - Then, allow small perturbations around the binary values to further reduce C₅
   - Use the non-binary optimization from the parent as a final polish

I think the most promising approach is:
1. Start with the initial_h_values (which is already a good non-binary solution)
2. Round to binary and optimize the binary arrangement using local search
