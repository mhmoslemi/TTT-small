Let me precompute the current autocorrelation and update it incrementally.

If we swap h[i]=1→0 and h[j]=0→1 (so i has a 1 and j has a 0), the change in overlap(s) for each shift s:
- overlap(s) = Σ_k h[k]·(1-h[k+s])·dx
- The change at position k=i: we remove h[i]·(1-h[i+s]) = 1·(1-h[i+s]) = 1-h[i+s]
- The change at position k=j: we add h[j]·(1-h[j+s]) = 1·(1-h[j+s]) = 1-h[j+s] (but h[j] was 0, now 1)
- Also, for shifts where i or j appears as k+s:
  - If i = k+s, i.e., k = i-s: we change h[k]·(1-h[k+s]) = h[i-s]·(1-h[i]) = h[i-s]·(1-1) = 0 → h[i-s]·(1-0) = h[i-s]
  - If j = k+s, i.e., k = j-s: we change h[k]·(1-h[k+s]) = h[j-s]·(1-h[j]) = h[j-s]·(1-0) = h[j-s] → h[j-s]·(1-1) = 0

So the total change in overlap(s) is:
Δoverlap(s) = dx · [(1-h[j+s]) - (1-h[i+s]) + h[i-s] - h[j-s]]
            = dx · [h[i+s] - h[j+s] + h[i-s] - h[j-s]]

(where h[i+s] is 0 if i+s is out of bounds, similarly for others)
