def project_to_feasible(g, n):
    """Project g onto {h: 0<=h<=1, sum(h)=n/2}"""
    target = n / 2.0
    # Bisection on the threshold
    lo = g.min() - 1.0
    hi = g.max() + 1.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(g - mid, 0.0, 1.0))
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(g - (lo + hi) / 2.0, 0.0, 1.0)

    n = len(h)

    x_new = np.arange(target_n) * (2.0 / target_n)
    return np.interp(x_new, x_old, h, period=2.0)

Let me try a different optimization: **Frank-Wolfe / conditional gradient**.

At each iteration:
1. Compute the gradient g = ∇f(h)
2. Find s ∈ S (feasible set) that minimizes <g, s>
3. Update h ← h + γ(s - h)

The minimum of <g, s> over the hypersimplex is:
- Sort g in decreasing order: g_(1) ≥ g_(2) ≥ ... ≥ g_(n)
- The vertex s* has s*_i = 1 if i is among the first n/2 (by value), 0 otherwise

Actually, to minimize <g, s>, we want s_i = 1 where g_i is most negative and s_i = 0 where g_i is most positive. So sort g in increasing order: g_(1) ≤ g_(2) ≤ ... ≤ g_(n). Set s_i = 1 for the n/2 indices with smallest g.

Then update: h ← (1-γ)h + γs

This is attractive because:
- Each iteration is O(n log n) for the sort
- No projection needed (s is automatically feasible)
- The combination (1-γ)h + γs is also feasible (convex combination of feasible points)

For arrays a of length N and v of length M:
- 'full' output has length N+M-1
- output[k] = Σ_n a[n] * v[n + k - M + 1] for valid n

Actually, from the numpy source, for real inputs:
np.correlate(a, v, 'full')[k] = Σ_n a[n] * v[n + k - M + 1]

where the sum is over all n where both indices are valid (0 ≤ n < N, 0 ≤ n+k-M+1 < M).

In our case, a = h (length n), v = 1-h (length n), so M = N = n.
output[k] = Σ_j h[j] * (1-h)[j + k - n + 1]

For k = 0: sum_j h[j] * (1-h)[j - n + 1]. The valid j are those where 0 ≤ j-n+1 < n, i.e., n-1 ≤ j < 2n-1, but j < n, so j = n-1. So output[0] = h[n-1] * (1-h[0]).

For k = n-1 (middle): sum_j h[j] * (1-h)[j]. This is the "zero-lag" term.

For k = 2n-2: output[2n-2] = h[0] * (1-h[n-1]).

So the maximum is typically near the middle (k ≈ n-1), which corresponds to small shifts.

The C5 = max_k output[k] * dx where dx = 2/n.

Now, for the gradient of output[k] w.r.t. h[i]:
output[k] = Σ_j h[j] * (1-h[j + k - n + 1])

Let shift = k - n + 1 (ranges from -(n-1) to (n-1)).
output[k] = Σ_j h[j] * (1-h[j + shift]) = Σ_j h[j] - Σ_j h[j]h[j+shift]

∂output[k]/∂h[i]:
- h[i] appears in the first sum: contributes 1 (if i is in the valid range for j)
- h[i] appears in h[j] in the second sum: j = i, valid if i+shift is in [0,n-1]
