def evaluate_c5_full(h):

    dx = 2.0 / n

def softmax_obj(h, T):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    vals = corr * T
    m = np.max(vals)
    return float((m + np.log(np.sum(np.exp(vals - m)))) / T * dx)

    n = len(h)

    second = np.convolve(h, p[::-1], mode='full')[n-1:2*n-1]

Now, one issue: when I project onto the symmetric subspace and the box/sum constraints, I might lose some of the gradient information. Let me handle this by:
1. Compute the gradient in the full space
2. Symmetrize the gradient: grad_sym = (grad + grad[::-1]) / 2
3. Take a step: h_new = h - alpha * grad_sym
4. Project to [0,1] and sum constraint
5. Symmetrize again: h_new = (h_new + h_new[::-1]) / 2

Actually, a cleaner approach: work in the 168-dim symmetric space. Define a mapping from the 168-dim space to the 336-dim space, and compute the gradient with respect to the 168 variables.

If h_full[j] = h_half[j] for j < 168, and h_full[j] = h_half[335-j] for j >= 168.
The constraint: sum(h_half) * 2 * dx = 1, i.e., sum(h_half) = 84.

The gradient w.r.t. h_half[i] is:
dF/dh_half[i] = dF/dh_full[i] + dF/dh_full[335-i] = grad_full[i] + grad_full[335-i]

So the reduced gradient is: grad_half[i] = grad_full[i] + grad_full[n-1-i] for i=0..n/2-1.

Let me use this approach. It's cleaner and avoids the double-counting issue.

Let me also think about resolution. With n=336, the half-space has 168 variables. With the FFT-based gradient, each gradient evaluation is O(n log n) ≈ O(336 * 9) ≈ 3000 operations. Each step also requires one correlation (O(n^2) ≈ 112k) for the objective. So each step is dominated by the correlation computation.

For 200 steps per temperature, 5 temperatures: 1000 correlations ≈ 1000 * 112k = 112M operations. In numpy, this should take about 10-20 seconds. Plus the random restarts. Should be well within budget.

Let me also add a "direct max" approach after the softmax optimization: once we've converged with a high-T softmax, we can use a subgradient method for the actual max function (no smoothing).
