2. Use a "softmax max" approximation with adaptive temperature

Let me also think about the mathematical structure. We want to minimize max_k C_k where C_k = sum_i h[i] * (1-h[i+k]) (discretized).

Note that C_k = sum_i h[i] - sum_i h[i]*h[i+k] = (n/2) - sum_i h[i]*h[i+k]

So minimizing max_k C_k is equivalent to minimizing max_k [(n/2) - auto_corr_h(k)] = (n/2) - min_k auto_corr_h(k)

where auto_corr_h(k) = sum_i h[i]*h[i+k] (the autocorrelation of h at lag k).

So we want to MAXIMIZE min_k autocorr_h(k)!

This is a much nicer formulation. We want h to have high minimum autocorrelation. This is related to "good" autocorrelation properties in signal processing.

Actually wait, let me double-check. C_k = ∫ h(x)(1-h(x+k)) dx = ∫h(x)dx - ∫h(x)h(x+k)dx = 1 - ∫h(x)h(x+k)dx (in continuous form, since ∫h=1).

In discrete form: C_k * dx = sum_i h[i]*(1-h[i+d]) * dx = (sum_i h[i] - sum_i h[i]*h[i+d]) * dx = 1 - sum_i h[i]*h[i+d] * dx

So C_k = 1 - R(k) where R(k) = sum_i h[i]*h[i+d_k] * dx is the autocorrelation of h at shift d_k.

To minimize max_k C_k = 1 - min_k R(k), we need to maximize min_k R(k).

So the problem is equivalent to: maximize the minimum autocorrelation of h, subject to 0≤h≤1 and sum(h)*dx=1.

This is a known problem in signal processing - finding signals with good autocorrelation properties. The "Golay complementary sequences" and "m-sequences" are related discrete analogues.

For continuous functions, we want h to be as "autocorrelation-flat" as possible (high everywhere).

This gives us a different perspective for optimization. We could:
1. Focus on the lags where autocorrelation is lowest (equivalently, where C_k is highest)
2. Try to raise the minimum autocorrelation

Hmm, this gradient computation is O(n * (2n-1)) = O(n²) in the worst case, which is the same as computing the correlation. That's not ideal.

But wait - with the FFT approach, computing the correlation is O(n log n). The gradient is inherently O(n²) because each of the 2n-1 lags affects n different elements. However, we can limit to the top-M lags (which is what the previous code does with topM).

Actually, let me think about this differently. If we use the softmax approximation:
f(h) = (1/tau) * log(sum_k exp(tau * C_k))

Then grad f = sum_k p_k * grad C_k where p_k = exp(tau*C_k) / sum exp(tau*C_j)

And if tau is large, p_k is concentrated on the top few lags. So computing the gradient is O(M * n) where M is the effective number of significant lags.

For the FFT-based correlation, each iteration is:
1. Compute correlation: O(n log n) via FFT
2. Compute weights (softmax): O(n)
3. Compute gradient: O(M * n) where M is the number of significant lags
4. Projection: O(n * log(n)) for bisection (50 iterations * O(n))

So per iteration: O(n log n + M*n) ≈ O(n log n) if M is small.

For n=3600, this is very fast. We can do many thousands of iterations.

import time

def project_to_feasible(g, n):
    target = n / 2.0
    lo = g.min() - 2.0
    hi = g.max() + 2.0
    for _ in range(50):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(g - mid, 0.0, 1.0))
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(g - (lo + hi) / 2.0, 0.0, 1.0)

def corr_fft(h):
    n = len(h)
    size = 1 << (2 * n - 1).bit_length()
    H = np.fft.rfft(h, size)
    O = np.fft.rfft(1.0 - h, size)
    r = np.fft.irfft(H * np.conj(O), size)
    idx = (np.arange(2 * n - 1) - n + 1) % size
    return r[idx]

def compute_c5(h):
    n = len(h)
    return corr_fft(h).max() * (2.0 / n)

def gradient_topM(h, top_idx, weights, n):
    """Gradient using only top-M lags with given weights."""
    dx = 2.0 / n
    grad = np.zeros(n)
    for i in range(len(top_idx)):
        w = weights[i]
        if abs(w) < 1e-15:
            continue
        k = top_idx[i]
        d = k - n + 1
        j0 = max(0, -d)
        j1 = min(n, n - d)
        if j0 < j1:
            idx = np.arange(j0, j1)
            grad[idx] += w * (1.0 - h[idx + d])
        j0b = max(0, d)
        j1b = min(n, n + d)
        if j0b < j1b:
            idx = np.arange(j0b, j1b)
            grad[idx] -= w * h[idx - d]
    return grad * dx

def softmax_optimize(h, n, tau, max_iters, time_limit, lr_init=0.2, topM=50):
    """Optimize using softmax-approximated gradient with FFT correlation."""
    dx = 2.0 / n
    h = project_to_feasible(h, n).copy()
    corr = corr_fft(h) * dx
    best_obj = corr.max()
    best_h = h.copy()
    start = time.time()
    lr = lr_init
    v = np.zeros(n)
    beta = 0.9
    stall = 0
    patience = max(50, max_iters // 20)
    
    for it in range(max_iters):
        if time.time() - start > time_limit:
            break
        
        corr = corr_fft(h) * dx
        cur_max = corr.max()
        if cur_max < best_obj - 1e-15:
            best_obj = cur_max
            best_h = h.copy()
            stall = 0
        else:
            stall += 1
        
        # Compute weights
        if topM > 0 and topM < (2 * n - 1):
            top_idx = np.argpartition(corr, -topM)[-topM:]
            c_top = corr[top_idx]
            max_c = c_top.max()
            shifted = np.clip(tau * (c_top - max_c), -500, 500)
            exp_c = np.exp(shifted)
            s = exp_c.sum()
            p_top = exp_c / s
            grad = gradient_topM(h, top_idx, p_top, n)
        else:
            max_c = corr.max()
            shifted = np.clip(tau * (corr - max_c), -500, 500)
            exp_c = np.exp(shifted)
            s = exp_c.sum()
            p = exp_c / s
            # For full gradient, use all lags
            grad = gradient_topM(h, np.arange(2*n-1), p, n)
        
        v = beta * v - lr * grad
        h_new = project_to_feasible(h + v, n)
        
        if stall > patience:
            lr *= 0.7
            v *= 0.5
            stall = 0
            if lr < 1e-10:
                break
        h = h_new
    
    return best_h, best_obj

import numpy as np
import time


def project_to_feasible(g, n):
    target = n / 2.0
    lo = g.min() - 2.0
    hi = g.max() + 2.0
    for _ in range(50):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(g - mid, 0.0, 1.0))
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(g - (lo + hi) / 2.0, 0.0, 1.0)


def corr_fft(h):
    n = len(h)
    size = 1 << (2 * n - 1).bit_length()
    H = np.fft.rfft(h, size)
    O = np.fft.rfft(1.0 - h, size)
    r = np.fft.irfft(H * np.conj(O), size)
    idx = (np.arange(2 * n - 1) - n + 1) % size
    return r[idx]


def compute_c5(h):
    n = len(h)
    return corr_fft(h).max() * (2.0 / n)


def gradient_lags(h, lags, weights, n):
    dx = 2.0 / n
    grad = np.zeros(n)
    for i in range(len(lags)):
        w = weights[i]
        if abs(w) < 1e-14:
            continue
        d = lags[i] - n + 1
        j0 = max(0, -d)
        j1 = min(n, n - d)
        if j0 < j1:
            idx = np.arange(j0, j1)
            grad[idx] += w * (1.0 - h[idx + d])
        j0b = max(0, d)
        j1b = min(n, n + d)
        if j0b < j1b:
            idx = np.arange(j0b, j1b)
            grad[idx] -= w * h[idx - d]
    return grad * dx


def softmax_optimize(h, n, taus, max_iters, time_limit, lr_init, topM):
    dx = 2.0 / n
    h = project_to_feasible(h, n).copy()
    corr = corr_fft(h) * dx
    best_obj = corr.max()
    best_h = h.copy()
    start = time.time()
    lr = lr_init
    v = np.zeros(n)
    beta = 0.9
    stall = 0
    patience = max(80, max_iters // 15)
    total = 0

    for tau in taus:
        it_phase = max(1, max_iters // len(taus))
        for it in range(it_phase):
            if time.time() - start > time_limit:
                break
            total += 1
            corr = corr_fft(h) * dx
            cur_max = corr.max()
            if cur_max < best_obj - 1e-15:
                best_obj = cur_max
                best_h = h.copy()
                stall = 0
            else:
                stall += 1

            if topM > 0 and topM < (2 * n - 1):
                top_idx = np.argpartition(corr, -topM)[-topM:]
                c_top = corr[top_idx]
                max_c = c_top.max()
                shifted = np.clip(tau * (c_top - max_c), -400, 400)
                exp_c = np.exp(shifted)
                s = exp_c.sum()
                if s < 1e-30:
                    p_top = np.ones(len(top_idx)) / len(top_idx)
                else:
                    p_top = exp_c / s
                grad = gradient_lags(h, top_idx, p_top, n)
            else:
                max_c = corr.max()
                shifted = np.clip(tau * (corr - max_c), -400, 400)
                exp_c = np.exp(shifted)
                s = exp_c.sum()
                if s < 1e-30:
                    p = np.ones(len(corr)) / len(corr)
                else:
                    p = exp_c / s
                grad = gradient_lags(h, np.arange(2 * n - 1), p, n)

            v = beta * v - lr * grad
            h_new = project_to_feasible(h + v, n)

            if stall > patience:
                lr *= 0.65
                v *= 0.4
                stall = 0
                if lr < 1e-11:
                    break
            h = h_new

    return best_h, best_obj


def interp_up(h, target_n):
    n = len(h)
    if n == target_n:
        return h.copy()
    x_old = np.arange(n) * (2.0 / n)
    x_new = np.arange(target_n) * (2.0 / target_n)
    return np.interp(x_new, x_old, h, period=2.0)


def sine_start(n, freqs, amps, phase=0.0):
    x = np.arange(n) * (2.0 / n)
    h = np.full(n, 0.5)
    for f, a in zip(freqs, amps):
        h += a * np.sin(2.0 * np.pi * f * x + phase)
    return project_to_feasible(h, n)

        h3 = interp_up(best_h, n3)
        h3 = project_to_feasible(h3, n3)
        taus3 = [15.0, 40.0, 80.0, 150.0]
        tl3 = min(remaining() * 0.25, 300.0)
        h3, c5_3 = softmax_optimize(h3, n3, taus3, max_iters=25000,
                                    time_limit=tl3, lr_init=0.12, topM=80)
        if c5_3 < best_c5:
            best_c5 = c5_3
            best_h = h3.copy()

    # Phase 4: Low-temperature polish (spread gradient across more lags)
    n_f = len(best_h)
    if remaining() > 100:
        h_f = best_h.copy()
        taus4 = [3.0, 5.0, 8.0]
        tl4 = min(remaining() * 0.2, 150.0)
        h_f, c5_f = softmax_optimize(h_f, n_f, taus4, max_iters=30000,
                                     time_limit=tl4, lr_init=0.06, topM=300)
        if c5_f < best_c5:
            best_c5 = c5_f
            best_h = h_f.copy()

    # Phase 5: Random restarts with smaller perturbations
    n_p = len(best_h)
    max_restarts = 10
    if remaining() > 80:
        for attempt in range(max_restarts):
            if remaining() < 25:
                break
            noise = 0.008 * (1 + attempt * 0.5)
            h_p = best_h + noise * np.random.randn(n_p)
            h_p = project_to_feasible(h_p, n_p)
            tl_p = min(remaining() * 0.08, 40.0)
            if tl_p < 8:
                break
            taus_p = [20.0, 50.0]
            h_p, c5_p = softmax_optimize(h_p, n_p, taus_p, max_iters=8000,
                                         time_limit=tl_p, lr_init=0.12, topM=100)
            if c5_p < best_c5:
                best_c5 = c5_p
                best_h = h_p.copy()

    # Phase 6: Try a sine-based alternative starting point
    if remaining() > 60:
        n_s = n_init
        h_s = sine_start(n_s, [2, 4, 6, 8], [0.15, 0.10, 0.06, 0.04], phase=0.3)
        c5_s = compute_c5(h_s)
        if c5_s < best_c5 + 0.05:
            taus_s = [10.0, 30.0, 60.0]
            tl_s = min(remaining() * 0.15, 80.0)
            if tl_s > 10:
                h_s, c5_s = softmax_optimize(h_s, n_s, taus_s, max_iters=20000,
                                             time_limit=tl_s, lr_init=0.15, topM=100)
                if c5_s < best_c5:
                    best_c5 = c5_s
                    best_h = h_s.copy()

    # Phase 7: Final aggressive polish at high tau on top few lags
    n_final = len(best_h)
    if remaining() > 40:
        h_final = best_h.copy()
        taus_final = [50.0, 100.0, 200.0]
        tl_final = min(remaining() * 0.3, 120.0)
        h_final, c5_final = softmax_optimize(h_final, n_final, taus_final,
                                             max_iters=20000, time_limit=tl_final,
                                             lr_init=0.08, topM=40)
        if c5_final < best_c5:
            best_c5 = c5_final
            best_h = h_final.copy()

    # Final feasibility check and evaluation
    best_h = project_to_feasible(best_h, len(best_h))
    final_c5 = compute_c5(best_h)
    if final_c5 < best_c5:
        best_c5 = final_c5

    return best_h, best_c5, len(best_h)
