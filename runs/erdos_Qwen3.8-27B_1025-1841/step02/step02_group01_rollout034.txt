That's a lower bound, not helpful for improving the upper bound.

But it suggests that binary solutions might not be optimal for minimizing the max, because the max is at least the average, and we want to make all f_k as equal as possible.

Actually, for a perfectly "random" binary string, the f_k values would be approximately n/4 each (by concentration), so the max would be close to n/4 + O(√(n log n))/4. With dx = 2/n, this gives C₅ ≈ 1/2 + O(√(log n)/n). That's much worse than 0.38.

So the optimal solution is definitely not random binary. It must have some structure that makes the correlations more uniform.

Let me think about what structure would minimize the max correlation. We want h(x) to be such that for every shift k, the overlap between h and (1-h shifted by k) is small. This is related to "Golay sequences" or "m-sequences" in coding theory!

An optimal binary sequence would be one where the autocorrelation (or more precisely, the cross-correlation with its complement) is as flat as possible. This is exactly the "optimal binary sequence" problem.

For our problem, f_k = Σ h[i](1-h[i+k]) = Σ h[i] - Σ h[i]h[i+k] = n/2 - autocorr(k)

where autocorr(k) = Σ h[i]h[i+k] (with the appropriate normalization).

So minimizing max_k f_k is equivalent to maximizing min_k autocorr(k).

This is the "maximum minimum autocorrelation" problem! The best we can do is related to the "Achlovitz bound" or similar.

For a binary sequence of length n with n/2 ones:
autocorr(k) = Σ_{i=0}^{n-1-|k|} h[i]h[i+|k|]

We want to maximize the minimum of autocorr(k) over k ≠ 0.

This is a well-studied problem. The optimal sequences are related to Barker sequences, Zadoff-Chu sequences, etc.

def compute_c5(h):

    return float(np.max(corr) * dx)

def make_feasible(h, n):
    h = np.clip(np.asarray(h, dtype=float), 0.0, 1.0)
    target = n / 2.0
    diff = target - np.sum(h)
    h = h + diff / n
    h = np.clip(h, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-12:
        if diff > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        cnt = np.sum(mask)
        if cnt > 0:
            h[mask] += diff / cnt
            h = np.clip(h, 0.0, 1.0)
    return h

    old_n = len(h)
    if new_n == old_n:
        return h.copy()
    old_x = np.linspace(0.0, 2.0, old_n)
    new_x = np.linspace(0.0, 2.0, new_n)

    return make_feasible(h_new, new_n)

        max_shifted = np.max(shifted)
        soft = mc + (max_shifted + np.log(np.sum(np.exp(shifted - max_shifted)))) / t
        return soft * dx
    return obj

    dx = 2.0 / n

    max_val = np.max(corr)
    
    # Active set
    threshold = max_val - active_tol_frac * max_val if max_val > 0 else max_val - 0.01
    active = corr >= threshold
    n_active = np.sum(active)
    if n_active == 0:
        active = corr >= max_val
        n_active = 1
    
    # Compute gradient
    grad = np.zeros(n)
    for k in range(2 * n - 1):
        if not active[k]:
            continue
        s = k - (n - 1)

            grad[s:] += (1.0 - h[:n-s])

            grad[sp:] -= h[:n-sp]
    
    grad /= n_active
    
    # Projected step
    h_new = h - step * grad
    h_new = make_feasible(h_new, n)
    return h_new

                patience = 0
                if step < 1e-7:
                    break

from scipy.optimize import minimize

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_feasible(h, n):
    h = np.clip(np.asarray(h, dtype=float), 0.0, 1.0)
    target = n / 2.0
    diff = target - np.sum(h)
    h = h + diff / n
    h = np.clip(h, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-12:
        if diff > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        cnt = np.sum(mask)
        if cnt > 0:
            h[mask] += diff / cnt
            h = np.clip(h, 0.0, 1.0)
    return h

def upsample_h(h, new_n):
    old_n = len(h)
    if new_n == old_n:
        return h.copy()
    old_x = np.linspace(0.0, 2.0, old_n)
    new_x = np.linspace(0.0, 2.0, new_n)
    h_new = np.interp(new_x, old_x, h)
    return make_feasible(h_new, new_n)

def soft_objective(h, n, t):
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    mc = np.max(corr)
    shifted = corr - mc
    max_s = np.max(shifted)
    log_sum = max_s + np.log(np.sum(np.exp(shifted - max_s)))
    return (mc + log_sum / t) * dx

    def fun(h):
        return np.sum(h) - n / 2.0
    return fun
