But for our discretized problem, let me just focus on finding a good binary (or near-binary) pattern.

Let me try a different approach: **genetic algorithm / simulated annealing on the binary space**.

Steps:
1. Start with a random binary vector with n/2 ones
2. Repeat:
   a. Pick a random position to flip
   b. If it improves (or doesn't worsen too much, for SA), accept
   c. Cool down if SA
3. After convergence, try local search: for each position, try flipping and see if it improves the max

The key computation is: after flipping h[j], how does the overlap vector change?
- Only the overlaps for lags m where j±m is a valid index change
- Specifically, overlap[m] changes by: if h[j] was 0 and becomes 1:
  - overlap[m] changes by: (for the h[j+m] term) -1 if j+m was 1 (now it's still 1, wait...)

Actually, let me think about this more carefully. If we flip h[j] from 0 to 1:
- For lag m: overlap[m] = ∑_i h[i+m]*(1-h[i])
  - The term involving h[j] as the first factor (i+m=j, i=j-m): change is (1-h[j-m]) - 0 = (1-h[j-m]) if j-m valid → but wait, if h[j] was 0 and becomes 1:
    - h[j] appears in overlap[m] as h[i+m] when i+m=j (i=j-m): adds (1-h[j-m]) to overlap[m]
    - h[j] appears in overlap[m] as (1-h[i]) when i=j: subtracts h[j+m] from overlap[m] (since (1-0)→(1-1), change is -h[j+m])
  
  Net change: (1-h[j-m])*I(valid) - h[j+m]*I(valid) = same as the gradient formula!

So Δoverlap[m] = (1-h[j-m])*I(0≤j-m<n) - h[j+m]*I(0≤j+m<n) (for 0→1 flip)
For 1→0 flip: Δoverlap[m] = -(1-h[j-m])*I(0≤j-m<n) + h[j+m]*I(0≤j+m<n)

This is the same b_m we computed before! Great.

So for local search on binary vectors:
1. Compute the overlap vector (one correlate call)
2. Compute the current max and which lags achieve it
3. For each position j, compute Δoverlap[m] for all m (O(n) work)
4. For each j, compute the new max (O(n) work if we have the old overlaps + deltas)
5. Pick the j that gives the best improvement

This is O(n²) per step, and we can do many steps.
