Let me also consider using the **projected subgradient method** directly on the max objective:

The subgradient of f(x) = max_k g_k(x) is in the convex hull of {∇g_k(x) : k ∈ argmax}.

For a single argmax k*, the subgradient is ∇g_{k*}(x).
For multiple argmaxes, we can use a random one or the average.

The projected subgradient method:
x_{t+1} = P_C(x_t - α_t * ∇g_{k_t}(x_t))

where P_C is projection onto the constraint set C = {x : sum(x) = n/2, 0 ≤ x ≤ 1}.

The projection onto C can be done efficiently (it's a quadratic problem: minimize ||x - y||² subject to sum(x) = n/2, 0 ≤ x ≤ 1).

This is a "Dykstra" or "Euclidean projection" problem. The solution is x_i = clip(y_i - λ, 0, 1) where λ is chosen so that sum(x) = n/2. We can find λ by bisection.
