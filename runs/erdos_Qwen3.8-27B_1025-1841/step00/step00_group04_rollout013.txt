Actually, let me think about this more carefully. The objective at lag 0 is:
sum_i h[i](1-h[i]) = sum_i h[i] - sum_i h[i]^2 = n/2 - sum_i h[i]^2

To minimize this, we maximize sum h[i]^2, which means making h as binary as possible (0 or 1). With sum = n/2, we set exactly n/2 entries to 1 and n/2 to 0.

But then, at other lags, the overlap depends on the pattern. The question is: what binary pattern minimizes the max overlap at all lags?

For a binary pattern with n/2 ones, the overlap at lag s (shift by s positions) is:
count of i where h[i+s] = 1 and h[i] = 0 (for the forward direction) 

This is the number of "1s followed by 0s" at distance s. Equivalently, it's the number of positions where the pattern at i is 00→10 or 01→10 (transitions from 0 to 1 at offset s).

For a random binary pattern with n/2 ones, the expected count at lag s is approximately (n-s)/4 for s not too large. So C₅ ≈ (n/4) * (2/n) = 1/2 for random, which is bad.

But structured patterns can do better. For example, if the 1s are clustered together: [1,1,...,1,0,0,...,0] with n/2 ones. Then:
- Lag 0: 0
- Lag s (0 < s < n/2): the number of i where h[i+s]=1 and h[i]=0 is 0 (since ones are all before zeros, shifting right by s keeps ones before zeros). Wait no: h[i+s]=1 means i+s < n/2, h[i]=0 means i ≥ n/2. So i ≥ n/2 and i < n/2 - s, which is impossible for s > 0.

            best_c5 = v
            best_h = h_opt
            h_work = h_opt.copy()
        elif v < best_c5 + 0.01:
            h_work = h_opt.copy()

        # Polish
        if remaining() > 60:
            tau_pol = 100.0 if n_new <= 200 else 50.0
            if n_new <= 200:
                h_pol = opt_slsqp(h_work, tau_pol, max_iter=400)
            else:
                h_pol = opt_lbgfs(h_work, tau_pol, pen=200.0, max_iter=1500)
            v_pol = c5_value(h_pol)
            if v_pol < best_c5:
                best_c5 = v_pol
                best_h = h_pol
            h_work = h_pol.copy()

    # Phase 3: random restarts
    n_rand = min(200, max(np_ * 2, len(best_h)))
    ntrials = 12
    for _ in range(ntrials):
        if remaining() < 45:
            break
        h_r = upscale(best_h, n_rand) if len(best_h) != n_rand else best_h.copy()
        h_r = h_r + rng.normal(0, 0.08, n_rand)
        h_r = project_sum(h_r, n_rand / 2.0)

        if n_rand <= 200:
            h_opt = opt_slsqp(h_r, 40.0, max_iter=500)
        else:
            h_opt = opt_lbgfs(h_r, 40.0, pen=100.0, max_iter=2000)

        v = c5_value(h_opt)
        if v < best_c5:
            best_c5 = v
            best_h = h_opt

    # Final projection and rounding
    nf = len(best_h)
    best_h = project_sum(best_h, nf / 2.0)
    best_h = np.round(best_h, 12)
    best_h = project_sum(best_h, nf / 2.0)
    best_c5 = c5_value(best_h)

    return best_h, best_c5, nf
