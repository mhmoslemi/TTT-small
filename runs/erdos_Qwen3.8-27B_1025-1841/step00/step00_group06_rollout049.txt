```python
def binary_round(h, target_sum):
    n = len(h)
    # We need sum = target_sum
    # For even n: target_sum is integer, make exactly target_sum entries = 1
    # For odd n: target_sum = k + 0.5, make k entries = 1, one = 0.5, rest = 0
    
    # Rank entries by h value (higher more likely to be 1)
    order = np.argsort(-h)
    h_bin = np.zeros(n)
    remaining = target_sum
    for i in order:
        if remaining <= 0:
            break
        h_bin[i] = min(remaining, 1.0)
        remaining -= h_bin[i]
    return h_bin
```

This is better. It greedily assigns 1s to the highest h[i] values.
