np.correlate(a, v, mode='full') for a, v of length n:
- Output length: 2n-1
- Output[k] = sum_{t} a[t] * conj(v[t + k - (n-1)])
  where t ranges over valid indices

For a = h, v = (1-h), both real:
Output[k] = sum_t h[t] * (1-h[t+k-(n-1)])

For k = n-1 (center): sum_t h[t]*(1-h[t]) = sum h - sum h² 
For k = n-1+j (j > 0): sum_t h[t]*(1-h[t+j]) (where t+j < n)
For k = n-1-j (j > 0): sum_t h[t]*(1-h[t-j]) (where t-j >= 0)

So the "full" correlation gives us all lag values. The maximum over all these, times dx, is C₅.

This matches the problem statement. Good.

Now, one subtlety: the maximum might be at the center (zero lag) or at some other lag. At zero lag, c_0 = (sum h - sum h²) * dx. Since sum h = n/2, c_0 = (n/2 - sum h²) * dx = (n/2 - sum h²) * 2/n = 1 - 2*sum(h²)/n.

To minimize c_0, we want sum(h²) to be as large as possible, i.e., h should be as "spiky" as possible (close to 0 or 1). But this might increase other lag values.

For a binary h (values 0 or 1 with n/2 of each): sum(h²) = n/2, c_0 = 1 - 2*(n/2)/n = 0. Good, zero lag gives 0.

But for binary h, other lags can be large as we saw earlier.

For h = 0.5 everywhere: sum(h²) = n/4, c_0 = 1 - 2*(n/4)/n = 1/2. And all other lags also give ~1/2 (since h is constant).

So the trade-off is: make h spiky to reduce c_0, but this increases other lags. The optimum balances these.

import numpy as np
from scipy.optimize import minimize
import time

def _smooth_max(v, beta):
    m = np.max(v)
    return m + np.log(np.sum(np.exp(v - m))) / beta

def _get_c5(h, dx):
    c = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(c)) * dx

def _project(h, target_sum):
    h = np.clip(h, 0.0, 1.0)
    s = float(h.sum())
    if s < 1e-12:
        return np.full_like(h, target_sum / len(h))
    h = h / s * target_sum
    return np.clip(h, 0.0, 1.0)

def _interp_parent(parent, n):
    return np.interp(np.linspace(0, len(parent) - 1, n), np.arange(len(parent)), parent)

def _fourier_init(n, rng):
    x = np.linspace(0, 2, n, endpoint=False)
    nc = rng.randint(2, 8)
    h = np.full(n, 0.5)
    for _ in range(nc):
        f = rng.randint(1, 14)
        a = rng.uniform(0.05, 0.35)
        p = rng.uniform(0, 2 * np.pi)
        h += a * np.cos(2 * np.pi * f * x + p)
    return _project(h, n / 2.0)

def _random_init(n, rng):
    return _project(rng.rand(n), n / 2.0)

def _block_init(n, rng):
    h = np.zeros(n)
    i = 0
    while i < n:
        w = min(rng.randint(2, 6), n - i)
        h[i:i + w] = rng.choice([0.0, 1.0])
        i += w
    return _project(h, n / 2.0)

def _obj_func(h, dx, target_sum, beta):
    c = np.correlate(h, 1.0 - h, mode='full') * dx
    return _smooth_max(c, beta) + 500.0 * (h.sum() - target_sum) ** 2

def _do_optimize(h0, n, dx, target_sum, beta, maxiter):
    bounds = [(0.0, 1.0)] * n
    try:
        res = minimize(_obj_func, h0, method='L-BFGS-B', bounds=bounds,
                       args=(dx, target_sum, beta),
                       options={'maxiter': maxiter, 'ftol': 1e-13, 'gtol': 1e-10,
                                'maxls': 50})
        return _project(res.x, target_sum)
    except Exception:
        return _project(h0, target_sum)
