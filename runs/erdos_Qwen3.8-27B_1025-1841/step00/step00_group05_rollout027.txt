out[i] = sum_j h[j] * (1-h[i - j + (n-1)]) ... 

No wait, let me look at the actual definition. From numpy docs:
c_k = sum_n a_{n+k} * conj(v_n)

So for a=h, v=1-h:
c_k = sum_n h_{n+k} * (1-h_n)

where the sum is over n such that both indices are in [0, n-1].

The output array is indexed from k=-(n-1) to k=n-1, with index 0 corresponding to k=-(n-1).

So output[i] corresponds to k = i - (n-1).

For k=0 (i = n-1): c_0 = sum_n h_n * (1-h_n) = sum h_n - sum h_n^2

For binary h: c_0 = 0 (since h_n(1-h_n) = 0 for each n).

For k=1 (i = n): c_1 = sum_{n=0}^{n-2} h_{n+1} * (1-h_n)
This counts the number of adjacent pairs (n, n+1) where h_{n+1}=1 and h_n=0.

OK so my earlier analysis was correct.

Now, for the parent solution with n=70, C₅ ≈ 0.38085, which means max correlation ≈ 0.38085 * 70/2 = 13.33.

Let me think about what kind of structure gives low max correlation. We want to minimize the maximum number of "1 followed by 0" pairs at any given shift.

A random binary string with 35 ones and 35 zeros would have, for each shift k, approximately 35*35/70 = 17.5 such pairs (by linearity of expectation). The maximum over all shifts would be higher than the mean, maybe around 25-30.

So we need a structured solution that does better than random.

import numpy as np
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode="full")
    return np.max(c) * dx

def project_feasible(h, target_sum):
    h = np.clip(h, 0.0, 1.0)
    if abs(np.sum(h) - target_sum) < 1e-12:
        return h
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(h - mid, 0.0, 1.0))
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def get_subgradient(h, lag):
    n = len(h)
    grad = np.zeros(n)
    if lag == 0:
        grad = 1.0 - 2.0 * h
    elif lag > 0 and lag < n:
        grad[lag:] += (1.0 - h[:n - lag])
        grad[:n - lag] -= h[lag:]
    elif lag < 0 and -lag < n:
        L = -lag
        grad[:n - L] += (1.0 - h[L:])
        grad[L:] -= h[:n - L]
    return grad

def binary_local_search(h, rng, max_iters=200000, time_limit=None, t_start=None):
    n = len(h)
    dx = 2.0 / n
    h = h.copy()
    best_h = h.copy()
    best_c5 = compute_c5(h)
    c5 = best_c5
    stall = 0

            break

        zeros = np.where(h == 0)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break
        i = ones[rng.randint(len(ones))]
        j = zeros[rng.randint(len(zeros))]
        h[i] = 0
        h[j] = 1
        c = np.correlate(h, 1.0 - h, mode="full")
        c5_new = np.max(c) * dx
        if c5_new < c5 - 1e-14:
            c5 = c5_new
            if c5 < best_c5:
                best_c5 = c5
                best_h = h.copy()
            stall = 0
        else:
            h[i] = 1
            h[j] = 0
            stall += 1
        if stall > 20000:
            break
    return best_h, best_c5

def round_to_binary(h, target_sum):
    h_bin = (h > 0.5).astype(float)
    num_ones = int(np.sum(h_bin))
    target = int(round(target_sum))
    if num_ones > target:
        ones = np.where(h_bin == 1)[0]
        n_flip = num_ones - target
        h_bin[ones[np.argsort(h[ones])[:n_flip]]] = 0
    elif num_ones < target:
        zeros = np.where(h_bin == 0)[0]
        n_flip = target - num_ones
        h_bin[zeros[np.argsort(h[zeros])[-n_flip:]]] = 1
    return h_bin

def subgradient_optimize(h, n, target_sum, max_iters, time_limit, t_start, alpha_init=0.05, rng=None):
    dx = 2.0 / n
    alpha = alpha_init
    for it in range(max_iters):
        if time.time() - t_start > time_limit:
            break
        c = np.correlate(h, 1.0 - h, mode="full")
        max_val = np.max(c)
        c5 = max_val * dx
        threshold = max_val - 0.3
        max_indices = np.where(c >= threshold)[0]
        avg_grad = np.zeros(n)
        for idx in max_indices:
            lag = idx - (n - 1)
            avg_grad += get_subgradient(h, lag)
        avg_grad /= len(max_indices)
        h_new = project_feasible(h - alpha * avg_grad, target_sum)
        c5_new = compute_c5(h_new)
        if c5_new < c5:
            h = h_new
            alpha = min(alpha * 1.01, 0.3)
        else:
            alpha = max(alpha * 0.96, 0.0005)
        alpha = min(alpha, alpha_init / (1.0 + 0.003 * it))
    return h
