def compute_c5(h, dx):
    corr = np.correlate(h, 1-h, mode="full")
    return np.max(corr) * dx

def project_simplex(h, target_sum):
    """Project h onto {0<=x<=1, sum(x)=target_sum}"""
    h = np.clip(h, 0, 1)
    # Iterative bisection on the Lagrange multiplier
    lo, hi = 0, 1
    for _ in range(50):
        mid = (lo + hi) / 2
        proj = np.clip(h - mid, 0, 1)
        s = np.sum(proj)
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo+hi)/2, 0, 1)

def soft_c5(h, dx, temperature=0.01):
    """Soft version of C5 for differentiable optimization"""
    corr = np.correlate(h, 1-h, mode="full")
    # Use log-sum-exp for smooth max
    max_c = np.max(corr)
    if temperature <= 0:
        return max_c * dx
    shifted = (corr - max_c) / temperature
    result = (max_c + temperature * np.log(np.sum(np.exp(shifted)))) * dx
    return result

For binary h, the correlation at lag k counts positions where h[i+k]=1 and h[i]=0. This is related to the "discrepancy" of the sequence.

For a binary sequence with density 1/2, the autocorrelation at lag k is:
A(k) = ∑_{i=0}^{n-1-|k|} h[i+k]h[i]

And the objective term is:
B(k) = ∑_{i=0}^{n-1-|k|} h[i+k](1-h[i]) = ∑_{i=0}^{n-1-|k|} h[i+k] - A(k)

For a well-distributed binary sequence, ∑ h[i+k] ≈ (n-|k|)/2, so B(k) ≈ (n-|k|)/2 - A(k).

To minimize max B(k), we want A(k) to be as close to (n-|k|)/4 as possible for all k (since if A(k) = (n-|k|)/4, then B(k) = (n-|k|)/4, and the max over k would be at k=0: n/4).

For a truly random binary sequence, B(k) ≈ (n-|k|)/4 ± √((n-|k|)/16), so the max would be around n/4 + a few √n/4.

C₅ ≈ (n/4 + O(√n)) * 2/n ≈ 1/2 + O(1/√n).

    n = len(h)
