1. Approach and rationale:

The core idea is to represent the step function h as a piecewise constant function on a grid and find the optimal configuration that minimizes the maximum overlap integral. We use a greedy improvement strategy that iteratively refines the parent solution (n_points=70). The key components are:

- Adaptive grid refinement: Start with the parent grid and double n_points until the time budget is exhausted
- Random perturbations: Apply small, structured changes to the function values to explore the solution space
- Local optimization: After large-scale changes, perform local hill-climbing to find better solutions
- Early termination: Stop and return the best solution found when the time budget is nearly exhausted

The main bottleneck is the high dimensionality of the optimization problem (n_points variables). By increasing the grid resolution systematically (70, 140, 280,...), we can potentially find better solutions while respecting the time budget. The trade-off is that finer grids require more computational time per evaluation, so we balance grid resolution with runtime.

2. Mathematical specification:

The optimization seeks to minimize:
$$ C_5 = \max_k \int_{0}^{2} h(x) (1-h(x+k)) dx $$

For grid representation:
- domain: [0, 2] divided into n_points intervals
- dx = 2.0 / n_points
- h(x) approximated by constant values h[0..n_points-1] over each interval
- integral constraint: sum(h) * dx = 1 ⇨ sum(h) = n_points / 2
- The convolution is computed as: conv = np.correlate(h, 1-h, mode="full")
- C_5 = max(conv) * dx

Representation: h_values is a numpy array of length n_points with:
- 0 ≤ h[i] ≤ 1 for all i
- sum(h) = n_points / 2

Constraints are enforced by projection after each optimization step. The rare function includes a projection step to adjust to the simplex and the sum constraint.
