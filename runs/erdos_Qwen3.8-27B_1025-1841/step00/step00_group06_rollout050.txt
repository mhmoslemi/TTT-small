The objective is f(h) = max_k g_k(h) where g_k(h) = sum_i h(i) * (1-h(i+k)) * dx (approximately).

The subgradient of g_k with respect to h[j] is:

For the full correlate indexing, this is a bit involved. Let me think...

Actually, for a given active lag, the gradient of that particular correlation with respect to h[i] is:

- h[i] appears in the term h[i+lag] * (1-h[i]) with coefficient -h[i+lag] * dx

```python
def compute_corr_and_grad(h):
    """Compute correlate and its gradient w.r.t. h at the max lag."""
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1-h, mode='full')
    max_idx = np.argmax(corr)
    
    # Gradient of corr[max_idx] w.r.t. h
    # corr[k] = sum_n h[n+k-(n-1)] * (1-h[n]) for valid indices
    # This is the cross-correlation
    
    # For the full correlation of a (len na) and v (len nv):
    # result[m] = sum_n a[n + m - (nv-1)] * v[n] for valid n
    # Here a=h, v=1-h, na=nv=n
    # result[m] = sum_n h[n + m - (n-1)] * (1-h[n])
    # Let lag = m - (n-1)
    # result[m] = sum_n h[n + lag] * (1-h[n]) where 0 ≤ n < n and 0 ≤ n+lag < n
    
    lag = max_idx - (n - 1)
    
    grad = np.zeros(n)
    for i in range(n):
        # h[i] appears in result[max_idx] when:
        # (a) As h[n + lag] where n + lag = i, so n = i - lag:
        #     contribution: (1-h[i-lag]) if 0 ≤ i-lag < n
        # (b) As (1-h[n]) where n = i:
        #     contribution: -h[i+lag] if 0 ≤ i+lag < n (from h[n+lag]*(1-h[n]))
        #     Wait, (1-h[n]) = 1-h[n], derivative w.r.t. h[n] is -1
        #     So term h[n+lag] * (-1) where n = i: -h[i+lag]
        
        if 0 <= (i - lag) < n:
            grad[i] += (1 - h[i - lag]) * dx
        if 0 <= (i + lag) < n:
            grad[i] += -h[i + lag] * dx
    
    return corr[max_idx] * dx, grad, lag
```

```python
    step = 0.01

        max_idx = np.argmax(corr)

        grad = np.zeros(n)

                grad[i] += (1 - h[i - lag]) * dx
            if 0 <= (i + lag) < n:
                grad[i] += -h[i + lag] * dx

        h_new = h - step * grad
        # Project onto [0,1]^n ∩ {sum = target_sum}
        h_new = np.clip(h_new, 0, 1)
        # Adjust sum
        diff = target_sum - h_new.sum()
        h_new += diff / n
        h_new = np.clip(h_new, 0, 1)
        # Re-adjust sum (clip might have broken it)
        diff = target_sum - h_new.sum()
        # Distribute among non-saturated entries
        free = (h_new > 0) & (h_new < 1)
        if free.sum() > 0 and abs(diff) > 1e-10:

            h = h_new

        else:
            step *= 0.9
```
