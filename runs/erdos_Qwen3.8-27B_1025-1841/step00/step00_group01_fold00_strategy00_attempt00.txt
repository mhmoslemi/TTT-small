        Duplicate (N*2) or halve (N/2) as windows for change
   - Candidate generation: After each update, generate 3-5 new candidates:
        ∙ Add Gaussian noise to the current best and adjust
        ∙ Replace any point with a probability distribution:
            Normal near mean intuition or uniform near edges

5. Compute budget and robustness:
   - Dominant cost: The QP updates (cost O(N²) but N≈60-100 limits it)
   - Total evaluations: Keep 10-20 candidates, each with QP and correlation cost, for about 10 generations of refinement.
   - Baseline: Start with 0.38085 value, target improvement to near 0.37-0.36.
   - Time budget: With N=100, each correlation and QP is ~10⁴ operations, totaling ~5×10⁶ operations which is feasible in Python across 20 minutes.

6. Validation and return contract:
   - Check: sum(h)=N/2 and all values between 0-1.
   - Compute: C_5 = (max correlation term)*(2/N)
   - Return best found (h_values, C_5, N)
   - Fallback: If all attempts fail, return the parent construction.
