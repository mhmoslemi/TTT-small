So: ∂c[k]/∂h[j] = (1-h[j-lag]) * 1[0≤j-lag<n] - h[j+lag] * 1[0≤j+lag<n]

(since 0≤j<n is always true for j in [0,n-1])

This is correct. Now, for the subgradient of max_k c[k], we need the gradient of the active term(s).

For simplicity, let's use only the most active term (the one with the maximum value).

The direction of steepest descent for c[k*] is -∇c[k*]. To maintain the sum constraint, we project this onto the hyperplane sum(h) = n/2.

Actually, since we're doing two-point moves (transfer δ from j to i), the effective direction is:
- We want to decrease c[k*]
- Changing h[i] by +δ and h[j] by -δ changes c[k*] by:
  δ * (∂c/∂h[i] - ∂c/∂h[j])
- To decrease c[k*], we want this to be negative
- So we want ∂c/∂h[i] - ∂c/∂h[j] < 0, i.e., ∂c/∂h[i] < ∂c/∂h[j]
- We should transfer from j (high gradient) to i (low gradient)

So the "greedy" move is:
1. Compute g = ∇c[k*] (gradient of the active correlation)
2. Pick i = argmin(g) and j = argmax(g)
3. Transfer a small amount from j to i

This is a form of coordinate descent / steepest descent. Let me implement this as an alternative to random moves.

def compute_gradient(h, k_index):
    """Compute gradient of c[k_index] w.r.t. h.
    k_index is the index into the 'full' correlation array."""
    n = len(h)
    lag = k_index - (n - 1)
    g = np.zeros(n)
    # h[j] as first factor: i = j - lag
    valid_i = (np.arange(n) - lag)
    mask1 = (valid_i >= 0) & (valid_i < n)
    g[mask1] += (1.0 - h[valid_i[mask1]])

    valid_jp = (np.arange(n) + lag)

One more optimization: I can precompute the correlation once and only recompute it when h changes. But since every move changes h, this doesn't help.

Actually, there's a trick: for a two-point move (change h[i] by +δ, h[j] by -δ), the change in the correlation at lag ℓ is:
Δc[ℓ] = δ * [(1-h[i+ℓ]) - h[i-ℓ] - (1-h[j+ℓ]) + h[j-ℓ]]

(with appropriate boundary handling). This is O(n) to compute for all lags. Then we can find the new max in O(n). So the total per-move cost is O(n) instead of O(n log n).

For n=1600, this is 1600 operations vs. ~16000 for FFT. A 10x speedup!

def evaluate_c5_fast(h):

def update_corr(corr, h, i, j, delta):
    """Update correlation after h[i] += delta, h[j] -= delta."""
    n = len(h)
    # For each lag, the change is:
    # Δc[lag_index] = delta * [(1-h[i+lag]) - h[i-lag] - (1-h[j+lag]) + h[j-lag]]
    # where lag_index = lag + (n-1)
    
    # h[i] was changed by +delta
    # h[i] contributes to c at lags where i is the "first" index (i = m + lag, so lag = i - m)
    # or the "second" index (i = m, so lag = i - m = 0... wait no)
    
    # Let me think differently.
    # c[k] = sum_m h[m] * (1-h[m + lag_k]) where lag_k = k - (n-1)
    # 
    # h[i] appears in c[k] when:
    #   a) m = i (h[i] is the first factor): contribution is h[i] * (1-h[i+lag_k])
    #      valid when 0 ≤ i+lag_k < n
    #   b) m + lag_k = i (h[i] is in the (1-h[...]) part): contribution is h[m] * (1-h[i])
    #      valid when 0 ≤ m < n, i.e., m = i - lag_k, valid when 0 ≤ i-lag_k < n
    #
    # After h[i] → h[i] + delta:
    #   a) change: delta * (1-h[i+lag_k]) for valid lag_k
    #   b) change: -h[m] * delta = -h[i-lag_k] * delta for valid lag_k
    #
    # Total change from h[i]: delta * [(1-h[i+lag_k]) - h[i-lag_k]]
    # Similarly for h[j]: -delta * [(1-h[j+lag_k]) - h[j-lag_k]]
    
    lags = np.arange(2*n - 1) - (n - 1)  # range from -(n-1) to n-1

    # 0 ≤ i+lag_k < n → -i ≤ lag_k < n-i
    # 0 ≤ i-lag_k < n → i-n < lag_k ≤ i
    # Combined: max(-i, i-n+1) ≤ lag_k < min(n-i, i+1)
    
    # Actually let me just compute it directly:
    delta_c = np.zeros(2*n - 1)
    
    # Contribution from h[i] change (+delta)
    # Case a: i is first factor, need i+lag valid
    valid_a = (lags + i >= 0) & (lags + i < n)
    delta_c[valid_a] += delta * (1.0 - h[lags[valid_a] + i])
    
    # Case b: i is in (1-h[m+lag]) part, m+lag = i, so m = i-lag
    valid_b = (i - lags >= 0) & (i - lags < n)
    delta_c[valid_b] += -delta * h[i - lags[valid_b]]
    
    # Contribution from h[j] change (-delta)
    # Case a: j is first factor
    valid_a2 = (lags + j >= 0) & (lags + j < n)
    delta_c[valid_a2] += -delta * (1.0 - h[lags[valid_a2] + j])
    
    # Case b: j is in (1-h[m+lag]) part
    valid_b2 = (j - lags >= 0) & (j - lags < n)
    delta_c[valid_b2] += delta * h[j - lags[valid_b2]]
    
    return corr + delta_c

np.correlate(a, v, mode="full") with a of length n and v of length n:
The output has length 2n-1.
Output[k] = sum_m a[m + k - (n-1)] * v[m] for valid m.

So for a = h, v = 1-h:
Output[k] = sum_m h[m + k - (n-1)] * (1-h[m])

Let lag = k - (n-1). Then:
c[lag] = sum_m h[m + lag] * (1-h[m]) for 0 ≤ m < n and 0 ≤ m+lag < n.

If lag ≥ 0: m ranges from 0 to n-1-lag
If lag < 0: m ranges from -lag to n-1

Now, ∂c[lag]/∂h[j]:
- h[j] appears as h[m+lag] when m+lag = j, i.e., m = j-lag.
  Valid when 0 ≤ j-lag < n (and 0 ≤ m+lag = j < n, which is always true).
  So: contributes (1-h[j-lag]) when 0 ≤ j-lag < n.
  
- h[j] appears in (1-h[m]) when m = j.
  Valid when 0 ≤ j < n (always) and 0 ≤ m+lag = j+lag < n.
  So: contributes -h[j+lag] when 0 ≤ j+lag < n.

Therefore: ∂c[lag]/∂h[j] = (1-h[j-lag]) · 1[0≤j-lag<n] - h[j+lag] · 1[0≤j+lag<n]

This matches what I had before. Good.

import numpy as np
import time

def evaluate_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def get_gradient(h):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    k_star = int(np.argmax(corr))
    lag = k_star - (n - 1)
    idx = np.arange(n)
    g = np.zeros(n)
    v1 = (idx - lag) >= 0
    v1 &= (idx - lag) < n
    g[v1] += (1.0 - h[idx[v1] - lag])
    v2 = (idx + lag) >= 0
    v2 &= (idx + lag) < n
    g[v2] -= h[idx[v2] + lag]
    return g, float(corr[k_star] * (2.0 / n))

def upsample_linear(h, new_n):
    old_n = len(h)
    if old_n == new_n:
        return h.copy()
    old_x = np.linspace(0.0, 2.0, old_n, endpoint=False)
    new_x = np.linspace(0.0, 2.0, new_n, endpoint=False)
    return np.interp(new_x, old_x, h)

def fix_sum(h, target):
    h = np.clip(h, 0.0, 1.0)
    diff = target - h.sum()
    if abs(diff) < 1e-12:
        return h
    if diff > 0:
        mask = h < 1.0
    else:
        mask = h > 0.0
    cnt = int(mask.sum())
    if cnt == 0:
        return h
    h[mask] += diff / cnt
    return np.clip(h, 0.0, 1.0)

    n_init = len(h_init)

                        200, 400, 800, 1600]))

        target = n_pts / 2.0
