Actually, for the step function interpretation:

- Fine grid: interval j covers [j*df, (j+1)*df) where df = 2/n_fine
- The coarse value h_c[i] applies to the entire interval [i*dc, (i+1)*dc)
- For the fine grid, interval j might span parts of multiple coarse intervals

h_f[j] = integral over fine interval j of the coarse step function
       = (1/df) * integral_{j*df}^{(j+1)*df} h_c(x) dx

But this is complex. Simpler: just use linear interpolation of the values at the centers. This gives a reasonable smooth approximation.

Or even simpler: use nearest-neighbor (which is exact for step functions):
h_f[j] = h_c[floor(j * n_coarse / n_fine)] when n_fine is a multiple of n_coarse

            mi = 3000 if nf <= 84 else (1500 if nf <= 168 else 800)
            r = minimize(obj_func, h_init, method='SLSQP',
                         bounds=bnds, constraints=cons,
                         options={'maxiter': mi, 'ftol': 1e-13})
            hc = fix_feas(r.x, nf)
            c5 = compute_c5(hc)
            if c5 < best_c5:
                best_c5, best_h, best_n = c5, hc, nf
        except Exception:
            pass

    # Phase 3: perturbation restarts at best resolution
    for _ in range(10):
        if budget_s - (time.time() - t0) < 70:
            break
        scale = 0.06 + 0.04 * rng.rand()
        h_p = best_h + rng.randn(best_n) * scale
        h_p = fix_feas(h_p, best_n)
        _g_n = best_n
        try:
            bnds = [(0.0, 1.0)] * best_n
            cons = {'type': 'eq', 'fun': sum_con}
            r = minimize(obj_func, h_p, method='SLSQP',
                         bounds=bnds, constraints=cons,
                         options={'maxiter': 1500, 'ftol': 1e-13})
            hc = fix_feas(r.x, best_n)
            c5 = compute_c5(hc)
            if c5 < best_c5:
                best_c5, best_h = c5, hc
        except Exception:
            pass

    # Phase 4: try binary projection at best resolution
    if budget_s - (time.time() - t0) > 30:
        n_b = best_n
        target = int(round(n_b / 2.0))
        # Sort by value, set top 'target' to 1, rest to 0
        idx = np.argsort(best_h)
        h_bin = np.zeros(n_b)
        h_bin[idx[n_b - target:]] = 1.0
        c5_bin = compute_c5(h_bin)
        if c5_bin < best_c5:
            best_c5, best_h = c5_bin, h_bin

    return best_h, best_c5, best_n
