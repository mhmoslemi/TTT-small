1. Finding all "breakpoints" where the argmax changes
2. Checking the minimum at each breakpoint and at the interval endpoints

A better approach: **gradient-guided search**. Compute the subgradient of the objective and use it to select promising directions.

The subgradient of f(h) = max_m C[m] at h is ∇C[m*] where m* = argmax C[m]. This tells us which direction to move to reduce the current maximum.

For the move (h[i] += d, h[j] -= d), the directional derivative in this direction is:
d * (∂C[m*]/∂h[i] - ∂C[m*]/∂h[j])

We want this to be negative (to decrease the max). So we want:
sign(d) * (∂C[m*]/∂h[i] - ∂C[m*]/∂h[j]) < 0

This gives us a quick filter: for each pair (i,j), we can check if there exists a sign of d that makes the directional derivative negative. If not, skip that pair.

Let me implement this:

```python
# Precompute gradient of C[m*]
m_star = np.argmax(current_corr)  # index in the full correlation
# Convert to lag
lag = m_star - (n - 1)

# Gradient of C[lag] with respect to h[k]:
# ∂C[lag]/∂h[k] = (1-h[k-lag])*[0≤k-lag≤n-1] - h[k+lag]*[0≤k+lag≤n-1]
grad = np.zeros(n)
for k in range(n):
    g = 0.0
    if 0 <= k - lag <= n - 1:
        g += (1.0 - current[k - lag])
    if 0 <= k + lag <= n - 1:
        g -= current[k + lag]
    grad[k] = g
```

Then for pair (i,j), the directional derivative for d>0 is grad[i] - grad[j]. If grad[i] > grad[j], increasing h[i] and decreasing h[j] (d>0) decreases the max. If grad[i] < grad[j], the opposite sign works.

This gives us a very fast filter: we only need to try pairs where grad[i] ≠ grad[j], and we always know the correct sign. This reduces the search by a lot.

Moreover, we can sort by |grad[i] - grad[j]| and try the most promising pairs first.
