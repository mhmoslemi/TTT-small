The problem: minimize max_k ∫ h(x)(1-h(x+k)) dx subject to ∫h = 1, 0≤h≤1.

For a periodic function with period 2, the integral ∫₀² h(x)(1-h(x+k)) dx is well-defined for all k (with the understanding that h is extended periodically).

Wait, but the problem says h: [0,2] → [0,1], not necessarily periodic. And the correlation is computed on the finite array. So it's not exactly periodic.

For the discrete case:
- h has n elements
- np.correlate(h, 1-h, mode="full") has 2n-1 elements
- The k-th element (0-indexed, from 0 to 2n-2) represents the correlation at shift (k - (n-1))
- At shift 0 (k = n-1): sum h[i]*(1-h[i]) = sum(h) - sum(h²) = n/2 - sum(h²)
- At shift +1 (k = n): sum_{i=0}^{n-2} h[i]*(1-h[i+1])
- At shift -1 (k = n-2): sum_{i=1}^{n-1} h[i]*(1-h[i-1])

So the max is over all these shifts.

For a binary h with exactly n/2 ones:
- At shift 0: n/2 - n/2 = 0 (since h² = h for binary)
- At shift k: number of i where h[i]=1 and h[i+k]=0 (for valid i)

So for binary h, the shift-0 contribution is always 0. The max is over other shifts.

This is essentially a "discrepancy" problem related to the autocorrelation of the binary sequence.

For a random binary sequence with n/2 ones, the expected autocorrelation at shift k is approximately (n-|k|)/4, and the variance is approximately (n-|k|)/16. So the expected max over all shifts would be roughly (n/4) + O(sqrt(n * log n)) for the positive part.
