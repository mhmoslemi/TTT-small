Let me also think about the binary local search. For a binary sequence, flipping h[j] from 1 to 0 (or vice versa) changes the correlations in a predictable way. I can do a best-improvement or first-improvement local search.

For binary h[j]=1 → 0:
- corr_l changes: h[j] goes from 1 to 0, and (1-h)[j] goes from 0 to 1
- First term: -1 * (1-h[j+l]) for valid l → subtracts (1-h[j+l])
- Second term: +1 * h[j-l] for valid l → adds h[j-l]

So delta_corr_l = -(1-h[j+l]) + h[j-l] = h[j-l] - 1 + h[j+l] = h[j-l] + h[j+l] - 1

For binary h, h[j-l] + h[j+l] - 1 ∈ {-1, 0, 1}:
- If h[j-l]=0, h[j+l]=0: delta = -1
- If h[j-l]=0, h[j+l]=1: delta = 0
- If h[j-l]=1, h[j+l]=0: delta = 0
- If h[j-l]=1, h[j+l]=1: delta = +1

Similarly, flipping h[j] from 0 to 1:
delta_corr_l = -(h[j-l] + h[j+l] - 1) = 1 - h[j-l] - h[j+l]

So for binary sequences, the change in each correlation is in {-1, 0, 1}, which makes the local search very efficient!

For a binary local search:
1. Compute all correlations (O(n²) or O(n log n) with FFT)
2. For each j, compute the delta for flipping j (O(n) per j, O(n²) total)
3. Find the flip that most reduces the max correlation
4. Apply it and repeat

This should be very efficient. Let me also think about "swap" moves: flip j from 1 to 0 and k from 0 to 1 simultaneously. This maintains the sum constraint.

For a swap (j: 1→0, k: 0→1):
- Effect on corr_l from j flip: h[j-l] + h[j+l] - 1 (but now h[k] is also changing)
- Effect on corr_l from k flip: 1 - h[k-l] - h[k+l]

If j and k are far apart, these are independent. If they're close, there can be interaction.

Let me also add a "exact" step: after finding the best candidate from the discrete set, do a few iterations of subgradient projection to find the exact optimum in that coordinate.

For the 1D subproblem: minimize f(v) = max_m (corr[m] + (v-old)*coeff[m]) over v ∈ [0,1].
This is equivalent to: find v that minimizes the maximum of lines {corr[m] + (v-old)*coeff[m] : m = 0, ..., 2n-2}.

The optimal v is where the maximum is minimized. Since f is convex piecewise linear:
- f'(v) from the right = max of coeff[m] for m that are "active" (achieve the max)
- At the optimum, 0 ∈ subgradient, meaning there exist active m1, m2 with coeff[m1] ≤ 0 ≤ coeff[m2] (or an active m with coeff[m]=0)

A simple approach: 
1. Find v0 that minimizes f (using the discrete candidates)
2. At v0, find the active set A = {m : corr[m] + (v0-old)*coeff[m] ≈ f(v0)}
3. If all coeff[m] for m in A are positive, decrease v; if all negative, increase v
4. Find the crossing point: for the active m with minimum coeff (most negative) and the active m with maximum coeff (most positive), find where their lines cross
5. That's the new v (clipped to [0,1])
6. Repeat until convergence

This is at most O(n) iterations with O(n) work each, so O(n²) per coordinate, which is too slow for large n.

Simpler: just use the discrete candidates approach. With 5-7 candidates per coordinate, and the function being relatively flat (since the max of many lines is typically flat near its minimum), the discrete approach should be quite accurate.
