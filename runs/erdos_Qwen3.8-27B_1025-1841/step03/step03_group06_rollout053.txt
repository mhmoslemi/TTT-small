The "center" is at k=n-1, where `corr[n-1] = sum_n h[n] * (1-h[n]) = 0` for binary.

For k = n-1 + sh (sh is the "shift"):
`corr[n-1+sh] = sum_n h[n+sh] * (1-h[n])` for n where both indices are valid.

If sh > 0: n ranges from 0 to n-1-sh
If sh < 0: n ranges from -sh to n-1

So for sh > 0: `corr[n-1+sh] = sum_{n=0}^{n-1-sh} h[n+sh] * (1-h[n])`
This counts positions where h[n+sh]=1 and h[n]=0.

To reduce this: find a position n where h[n+sh]=1 and h[n]=0, and either:
- Set h[n+sh]=0 (move that 1 elsewhere)
- Set h[n]=1 (but this increases the count, bad)

So the productive move is: find n where h[n+sh]=1 and h[n]=0, move the 1 from n+sh to some other position j where h[j]=0.

But we need to be careful: moving the 1 to j might increase other correlations. The local search handles this by checking the full C₅.

    corr = np.correlate(x, 1.0 - x, mode='full')
    mc = corr.max()
    shifted = corr - mc
    return (mc + np.log(np.sum(np.exp(_T * shifted))) / _T) * dx

    return np.sum(x) - _N / 2.0

    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_feasible(h, n):
    h = np.clip(h.astype(float).copy(), 0.0, 1.0)

        else:

        cnt = np.sum(mask)
        if cnt == 0:
            break
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h
