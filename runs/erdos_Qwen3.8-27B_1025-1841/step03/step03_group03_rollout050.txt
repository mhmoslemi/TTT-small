This is a combinatorial design problem! We want a subset S of size n/2 in Z_n (or in {0,...,n-1} with boundary effects) that maximizes the minimum autocorrelation.

For the circular case (torus), this would be related to difference sets. But here we have boundary effects (the function is on [0,2], not on a torus).

For the linear (full) correlation, the shifts range from -(n-1) to (n-1), and for large shifts, fewer terms are involved.

```python
def binary_sa(h0, n, max_steps=50000, start_time=None, time_limit=None, seed=42):
    """Simulated annealing on binary swap moves."""
    rng = np.random.RandomState(seed)
    h = (h0 > 0.5).astype(float)
    h = make_feasible(h, n)
    # Ensure exactly n/2 ones
    ones_count = int(np.sum(h))
    if ones_count > n//2:
        # Flip some 1s to 0s
        one_indices = np.where(h == 1)[0]
        flip_indices = one_indices[ones_count - n//2:]
        h[flip_indices] = 0
    elif ones_count < n//2:
        zero_indices = np.where(h == 0)[0]
        flip_indices = zero_indices[:n//2 - ones_count]
        h[flip_indices] = 1
    
    dx = 2.0 / n
    corr = np.correlate(h, 1-h, mode='full')
    current_c = np.max(corr) * dx
    best_c = current_c
    best_h = h.copy()
    
    one_set = set(np.where(h == 1)[0])
    zero_set = set(np.where(h == 0)[0])
    
    T_start = 0.05 * dx * n  # scale with problem
    T_end = 0.001 * dx * n
    T = T_start
    
    for step in range(max_steps):
        if time_limit is not None and start_time is not None:
            if time.time() - start_time > time_limit - 30:
                break
        
        # Choose a random swap
        if len(one_set) == 0 or len(zero_set) == 0:
            break
        i = rng.choice(list(one_set))
        j = rng.choice(list(zero_set))
        
        # Compute delta
        h[j] = 1  # tentatively
        h[i] = 0
        new_corr = np.correlate(h, 1-h, mode='full')
        new_c = np.max(new_corr) * dx
        
        delta = new_c - current_c
        if delta < 0 or rng.rand() < np.exp(-delta / T):
            # Accept
            current_c = new_c
            one_set.remove(i)
            one_set.add(j)
            zero_set.add(i)
            zero_set.remove(j)
            corr = new_corr
            if current_c < best_c:
                best_c = current_c
                best_h = h.copy()
        else:
            # Reject
            h[j] = 0
            h[i] = 1
        
        # Cool
        T = T_start * (T_end / T_start) ** (step / max_steps)
    
    return best_h, best_c
```

```python
    """Compute change in all correlations when h[i]:1->0 and h[j]:0->1. Uses old h."""
    offsets = np.arange(2*n-1) - n + 1  # shape (2n-1,)

    term1 = np.zeros(2*n-1)
```

```python
def compute_swap_delta(h, i, j, n):
    """Compute the change in corr vector when h[i]:1->0, h[j]:0->1. O(n) time."""
    offsets = np.arange(2*n-1) - n + 1
    
    # -vec1[i]: -(1-h[i+offset]) for valid indices
    idx = i + offsets
    d = np.zeros(2*n-1)
    m = (idx >= 0) & (idx < n)
    d[m] = -(1 - h[idx[m]])
    
    # +vec1[j]: +(1-h[j+offset])
    idx = j + offsets
    m = (idx >= 0) & (idx < n)
    d[m] += (1 - h[idx[m]])
    
    # -vec2[i]: -h[i-offset]
    idx = i - offsets
    m = (idx >= 0) & (idx < n)
    d[m] -= h[idx[m]]
    
    # +vec2[j]: +h[j-offset]
    idx = j - offsets
    m = (idx >= 0) & (idx < n)
    d[m] += h[idx[m]]
    
    return d
```

This is O(n) per evaluation. For n=640, that's 1280 array operations of length 1279. In numpy, this should be very fast (~0.1ms per call).

For 100K SA steps: 100K * 0.1ms = 10 seconds. Manageable!

But wait, I also need to track the current corr vector and update it. And I need to find the max each time (O(n)). So total per step is about 4 array ops of size 2n-1 plus one max. In numpy, this is dominated by the array operations: ~5 * 1280 * 8 bytes = 51KB of memory traffic per step. At 10GB/s bandwidth, that's ~5μs per step. 100K steps = 0.5 seconds. Very fast!

Let me also add a "steepest descent" phase after SA: try all n*(n/2) ≈ 200K possible swaps, pick the best one, repeat. Each trial is O(n), so total is O(n^3) = 2.7B for n=640. In numpy with vectorization, maybe 10-20 seconds per full pass. Do 5-10 passes.

Actually, I can vectorize the steepest descent: for a fixed i (from ones), compute delta for all j (from zeros) simultaneously. That's O(n) deltas each of size O(n), so O(n^2) per i. For n/2 values of i: O(n^3) total. For n=640: 268M ops. In numpy, maybe 1-2 seconds per full pass.

Let me write the full solution now. I'll combine:
1. Binary SA (fast exploration)
2. Steepest descent local search (polish)
3. Continuous refinement (SLSQP on the continuous values)
4. Upsampling for higher resolution

Let me also add a key insight: after the binary optimization, try a small continuous perturbation. The optimal might have some non-binary values at the "boundary" positions.

Here's my plan for the code:

```python
def make_feasible(h, n):
    h = np.clip(np.asarray(h, dtype=float), 0.0, 1.0)
    target = n / 2.0
    diff = target - np.sum(h)
    h = h + diff / n
    h = np.clip(h, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-12:
        if diff > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        cnt = np.sum(mask)
        if cnt > 0:
            h[mask] += diff / cnt
            h = np.clip(h, 0.0, 1.0)
    return h

def upsample_h(h, new_n):
    old_n = len(h)
    if new_n == old_n:
        return h.copy()
    old_x = np.linspace(0.0, 2.0, old_n)
    new_x = np.linspace(0.0, 2.0, new_n)
    h_new = np.interp(new_x, old_x, h)
    return make_feasible(h_new, new_n)

def swap_delta(h, i, j, n, offsets):
    d = np.zeros(2*n-1)
    idx = i + offsets
    m = (idx >= 0) & (idx < n)
    d[m] = h[idx[m]] - 1.0  # -(1-h[i+off])
    idx = j + offsets
    m = (idx >= 0) & (idx < n)
    d[m] += 1.0 - h[idx[m]]  # +(1-h[j+off])
    idx = i - offsets
    m = (idx >= 0) & (idx < n)
    d[m] -= h[idx[m]]  # -h[i-off]
    idx = j - offsets
    m = (idx >= 0) & (idx < n)
    d[m] += h[idx[m]]  # +h[j-off]
    return d

        zero_arr = np.where(h==0)[0]
        best_delta = 0
        best_i = -1
        best_j = -1
        best_new_corr = None
        
        for i in one_arr:

            # Just loop
            for j in zero_arr:
                d = swap_delta(h, i, j, n, offsets)
                nc = np.max(corr + d) * dx
                if nc < best_delta:

                    best_i = i
                    best_j = j
        
        if best_i < 0:
            break
        
        h[best_i] = 0
        h[best_j] = 1
        corr = np.correlate(h, 1-h, mode='full').copy()
        current_c = np.max(corr) * dx
        if current_c < best_c:
            best_c = current_c
            best_h = h.copy()
    
    return best_h, best_c
```

Wait, the local search is O(n^2) swaps per round, each O(n) to evaluate. For n=640: 320*320*1280 = 131M per round. In pure Python this is very slow. I need to vectorize.

Let me vectorize the swap delta computation. For a fixed i, the delta for all j can be computed as:
delta[i,j] = -vec1[i] + vec1[j] - vec2[i] + vec2[j]

where vec1[j] = vector of (1-h[j+offset_m]) and vec2[j] = vector of h[j-offset_m].

If I precompute vec1 and vec2 as n × (2n-1) matrices, then:
delta_for_fixed_i = -vec1[i] - vec2[i] + vec1[zero_arr] + vec2[zero_arr]

This is a matrix operation: (len(zero_arr) × (2n-1)) formatted. The max over the last axis gives the max corr for each j. Then I find the best (i,j) pair.

For n=640: vec1 is 640×1279 ≈ 819K elements. The matrix operation for one i is 320×1279 ≈ 410K elements. For all i: 320 × 410K = 131M. In numpy, this is fast (~0.5 sec per round).

Let me implement this:
