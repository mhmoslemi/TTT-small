Actually, the 1D subproblem is: minimize max_k (A_k + B_k * t) over t ∈ [0,1], where A_k and B_k are the correlation values and their derivatives w.r.t. h[j] (the B_k = dc_k/dh[j] computed above).

This is a linear programming problem:
minimize z
subject to A_k + B_k * t ≤ z for all k
0 ≤ t ≤ 1

In 1D, the optimal t is at one of the "breakpoints" where two constraints are tight, or at t=0 or t=1.

For a practical implementation:
- Compute all A_k + B_k * t for k in the affected range
- The function is convex piecewise-linear in t
- Use ternary search or check breakpoints

Since the affected range has O(n) values, finding the minimum by checking all breakpoints is O(n^2) per coordinate. For n=2048 and 2048 coordinates, total is O(n^3) ≈ 8.6B. Too slow in Python.

Better: use the fact that we only care about the top few. If we can identify which 3-5 correlation values are the "worst" at the current t, we only need to check the breakpoints among those. This is O(n) per coordinate.

Even better: for the convex piecewise-linear function, we can do a binary search on the subgradient. The subgradient at t is the set of B_k for k where A_k + B_k*t = max. We want to find t where 0 is in the subgradient (or t hits a boundary).

Practical approach: 
1. Evaluate at t=0 and t=1, get the max and its argmax.
2. Do a few iterations of "move to equalize top-2", like:
   - Find top-2: k1, k2
   - If B_k1 != B_k2, find t where A_k1+B_k1*t = A_k2+B_k2*t
   - Move t to that point (clipped to [0,1])
   - Repeat

This converges in a few iterations for practical purposes.

For n=2048, each SLSQP iteration might take 0.1-1 seconds for the QP solve. 200 iterations would be 20-200 seconds. That's the bottleneck.

At n=960, the QP is 960-dimensional, O(960^{{2.5}}) ≈ 29M per iteration. 200 iterations ≈ 6 seconds. Much more manageable.

So maybe I should stick with n=960 or at most n=1280 for the SLSQP part, and use higher resolution only for the coordinate descent (where I'm not solving a QP, just doing 1D searches).

Alternative: use a different optimizer for high-n. Options:
- L-BFGS-B (unconstrained, with penalty for constraints) - O(n) per iteration
- Projected gradient method - O(n) per iteration
- ADMM - O(n log n) per iteration (with FFT)

For the projected gradient method:
- Compute gradient of smooth_max_obj: O(n log n) (FFT-based)
- Take a step: h_new = h - step_size * grad
- Project to feasible set: clip to [0,1] and adjust sum to n/2
- Backtracking line search

The projection to {h: 0≤h≤1, sum(h)=n/2} can be done by:
1. Clip to [0,1]
2. If sum > n/2, reduce values (prioritizing those closest to 1)
3. If sum < n/2, increase values (prioritizing those closest to 0)
This is an O(n log n) operation (sorting).

Projected gradient could be much faster at high n. Let me use it.

```
def project_feasible(h, n):
    h = np.clip(h, 0, 1)
    target = n / 2.0
    diff = target - np.sum(h)
    if abs(diff) < 1e-15:
        return h
    # Binary search for threshold
    if diff > 0:
        # Need to add 'diff' to h, spreading to values below 1
        # Find threshold tau such that sum(min(1, h+max(0, tau))) = target
        # Sort h, find where to add
        idx = np.argsort(h)  # ascending
        h_sorted = h[idx]
        cumsum = np.cumsum(h_sorted)
        # Add evenly to the smallest values first
        # If I add x to the first k values, sum increases by k*x
        # I want k*x = diff, and h_sorted[k-1] + x ≤ 1
        # So x = diff/k, need h_sorted[k-1] + diff/k ≤ 1
        # Binary search for k
        lo, hi = 1, n
        while lo < hi:
            mid = (lo + hi) // 2
            if h_sorted[mid-1] + diff/mid <= 1.0:
                lo = mid + 1
            else:
                hi = mid
        k = lo
        x = diff / k
        h[idx[:k]] += x
        h = np.clip(h, 0, 1)
        # Fix any rounding
        residual = target - np.sum(h)
        if abs(residual) > 1e-15:
            mask = h < 1.0
            h[mask] += residual / np.sum(mask)
            h = np.clip(h, 0, 1)
    else:
        # Similar for diff < 0 (subtract)
        idx = np.argsort(h)[::-1]  # descending
        h_sorted = h[idx]
        if diff < 0:
            adiff = -diff
            lo, hi = 1, n
            while lo < hi:
                mid = (lo + hi) // 2
                if h_sorted[mid-1] - adiff/mid >= 0.0:
                    lo = mid + 1
                else:
                    hi = mid
            k = lo
            x = -adiff / k
            h[idx[:k]] += x
            h = np.clip(h, 0, 1)
            residual = target - np.sum(h)
            if abs(residual) > 1e-15:
                mask = h > 0.0
                h[mask] += residual / np.sum(mask)
                h = np.clip(h, 0, 1)
    return h
```

Actually, the simplest correct projection onto {h: 0≤h_i≤1, sum h_i = S} is:
1. Start with h
2. Clip to [0,1]
3. If sum > S: find the "water level" tau such that sum(max(0, min(1, h_i - (h_i - tau)))) = S... 

Actually, the Euclidean projection onto the set {h: 0≤h_i≤1, sum h_i = S} is:
h_proj[i] = clip(h[i] - tau, 0, 1) where tau is chosen so sum(clip(h[i]-tau, 0, 1)) = S.

tau can be found by bisection (since sum(clip(h[i]-tau, 0, 1)) is a decreasing function of tau).
