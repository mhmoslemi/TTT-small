```python
def obj_grad(h, n, T):
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    mc = np.max(corr)
    shifted = corr - mc
    exp_s = np.exp(T * shifted)
    s = np.sum(exp_s)
    weights = exp_s / s  # shape: (2n-1,)
    
    # weights[idx] corresponds to lag k = idx - (n-1)
    # Create a lag-indexed weight array
    # lags range from -(n-1) to (n-1)
    lags = np.arange(-(n-1), n)  # shape: (2n-1,)
    
    # For the gradient:
    # grad[j] = dx * sum over lags k of weights[k] * [(1-h[j+k]) if j+k valid - h[j-k] if j-k valid]
    # 
    # Term 1: sum_k weights[k] * (1-h[j+k]) for j+k in [0,n-1]
    #   = sum_k weights[k] - sum_k weights[k] * h[j+k] for j+k in [0,n-1]
    #   = sum(weights) - sum_k weights[k] * h[j+k]
    #   = 1 - (weights ⊛ h)[j]  (cross-correlation)
    #
    # Term 2: sum_k weights[k] * h[j-k] for j-k in [0,n-1]
    #   = (weights_flipped ⊛ h)[j]
    
    # np.correlate(a, b, mode='full')[i] = sum_j a[j] * b[j - (i - (len(b)-1))]
    # This is confusing. Let me use fft-based convolution instead.
    
    # Actually, let me think about it more carefully.
    # 
    # Define w as a function of lag: w[k] for k = -(n-1), ..., (n-1)
    # w[idx] where idx = 0..2n-2, k = idx - (n-1)
    # 
    # Term 1 at position j: T1[j] = sum_{k: 0 ≤ j+k ≤ n-1} w[k] * (1 - h[j+k])
    #                        = sum_{k: 0 ≤ j+k ≤ n-1} w[k] - sum_{k: 0 ≤ j+k ≤ n-1} w[k] * h[j+k]
    # 
    # Let i = j+k, so k = i-j. Range of i: max(0,j) to min(n-1, n-1+j)
    # T1[j] = sum_{i: max(0,j) ≤ i ≤ n-1} w[i-j] - sum_{i: max(0,j) ≤ i ≤ n-1} w[i-j] * h[i]
    # 
    # The second part is a cross-correlation of w and h.
    # If I define w_ext of length 2n-1 with w_ext[i-j] = w[i-j] (0-indexed),
    # then (w_ext * h)[j] in the convolution sense...
    
    # This is getting too complicated to vectorize cleanly. Let me just use the loop
    # but only over significant weights.
    
    grad = np.zeros(n)
    # Only process weights above threshold
    thresh = 1e-8
    significant = np.where(weights > thresh)[0]
    for idx in significant:
        w_val = weights[idx]
        k = idx - (n - 1)
        if k >= 0:
            length = n - k
            if length > 0:
                grad[:length] += w_val * (1.0 - h[k:])
                grad[k:] += -w_val * h[:length]
        else:
            ka = -k
            length = n - ka
            if length > 0:
                grad[ka:] += w_val * (1.0 - h[:length])
                grad[:length] += -w_val * h[ka:]
    
    grad *= dx
    return grad
```

The number of significant weights depends on T. For large T, only a few weights are significant (close to 1 for the max lag, close to 0 for others). For small T, many weights are significant.

At T=200 (a typical value), the weights decay as exp(-200 * (mc - c_k)). If the gap between the max and second-max is, say, 0.01 * sum(h) ≈ 0.01 * n/2 = 10 (in correlation units), then the second weight is exp(-2000) ≈ 0. So only 1-2 significant weights.

If the gap is smaller, say 0.1 correlation units, then exp(-20) ≈ 2e-9, still small. So for T=200, typically 1-5 significant weights.

This means the gradient computation is fast (O(n) per significant weight, and only a few are significant).
