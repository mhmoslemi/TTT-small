Actually, let me reconsider the coordinate descent efficiency. The bottleneck is calling np.correlate for each trial value. Can I speed this up?

For a single coordinate change (h[i]: old → new), the change in corr is:
Δcorr[k] = (new - old) * (1 - h[i-s_k]) - (new - old) * h[i+s_k] (approximately, for the shifts where i participates)

where s_k = k - (n-1) is the shift for correlation index k.

More precisely, h[i] participates in corr[k] when:
- i is in the valid range for shift s_k: max(0, s_k) ≤ i ≤ min(n-1, n-1+s_k)
- In that case, the contribution is h[i]*(1-h[i-s_k])
- Also h[i] appears as the "shifted" value: h[i+s_k]*(1-h[i]) when i+s_k is valid

So Δcorr[k] = (new-old)*(1-h[i-s_k]) - h[i+s_k]*(new-old) (when both valid)
            = (new-old)*(1-h[i-s_k]-h[i+s_k])

For the shift where s_k = 0 (k = n-1): h[i]*(1-h[i]) is quadratic, not linear.
Δcorr[n-1] = new*(1-new) - old*(1-old) = (new-old)*(1-new-old)

So I can precompute for each coordinate i the vector of coefficients a[i,k] = 1-h[i-s_k]-h[i+s_k] (with appropriate boundary handling), and then:
new_corr[k] = old_corr[k] + (new-old)*a[i,k]

This makes each evaluation O(1) per shift (just a scalar addition), or O(n) total for all shifts. But I still need to recompute a[i,k] after each accepted change (since h changes). 

Actually, after changing h[i], only the a[j,k] values that involve h[i] change. Specifically, a[j,k] involves h[i] when i = j-s_k or i = j+s_k, i.e., when k is related to j and i. This is a small subset.

For a full pass of coordinate descent, after each coordinate update, I'd need to update O(n) coefficients. Total: O(n^2) per pass. For n=960: ~1M ops. Very fast!

```python
def compute_coefficients(h, i, n):
    """Compute a[k] for coordinate i: corr[k] = base[k] + h[i]*a[k]"""
    # a[k] = d(corr[k])/d(h[i])
    # Using the formula: a[k] = (1-h[i-s]) - h[i+s] for shift s = k-(n-1)
    # with boundary handling
    a = np.zeros(2*n-1)
    for k in range(2*n-1):
        s = k - (n-1)
        coeff = 0.0
        # h[i] as first factor: need i-s in [0, n-1]
        if 0 <= i-s < n:
            coeff += (1.0 - h[i-s])
        # h[i] as second factor: need i+s in [0, n-1]  
        if 0 <= i+s < n and s != 0:
            coeff -= h[i+s]
        a[k] = coeff
    return a
```

Wait, but this only works for s ≠ 0. For s = 0 (k = n-1):
corr[n-1] = sum_j h[j]*(1-h[j])
d(corr[n-1])/d(h[i]) = 1 - 2*h[i] (this depends on h[i]!)

So for k = n-1, the relationship is quadratic: corr[n-1] = const + h[i] - h[i]^2.

I'll handle this separately:
- For k ≠ n-1: corr[k] = base[k] + x * a[k] (linear)
- For k = n-1: corr[n-1] = base_0 + x - x^2 (quadratic)

where base[k] = corr[k] - h[i]*a[k] for k≠n-1, and base_0 = corr[n-1] - h[i] + h[i]^2.

Then the 1D optimization is:
min_{x∈[0,1]} max( max_{k≠n-1}(base[k] + x*a[k]), base_0 + x - x^2 )

I can evaluate this efficiently using numpy:
```python
def eval_1d(x, base, a, base_0):
    # base, a: arrays of length 2n-2 (excluding k=n-1)
    # base_0: scalar
    linear = (base + x * a).max()
    quad = base_0 + x - x*x
    return max(linear, quad)
```

```python
    top = np.where(corr >= thr)[0]
    if len(top) > max_top:
        ord_ = np.argsort(-corr[top])
        top = top[ord_[:max_top]]
    elif len(top) == 0:
        top = np.array([int(np.argmax(corr))])
    return do_slsqp(h, T, maxiter, top_idx=top)

def run(seed=42, budget_s=1300, **kwargs):
    t0 = time.time()
    rng = np.random.RandomState(seed)

    def elapsed():
        return time.time() - t0

    try:
        h0 = np.array(initial_h_values, dtype=float).copy()
    except Exception:
        h0 = np.full(960, 0.5)
    n0 = len(h0)
    h = make_feasible(h0, n0)
    best_c5 = compute_c5(h)
    best_h = h.copy()

    # Phase 1: SLSQP warmup at n=960
    for T in [150, 400, 1000]:
        if elapsed() > budget_s - 120:
            break
        h_t = do_slsqp(best_h, T, 600)
        c5_t = compute_c5(h_t)
        if c5_t < best_c5:
            best_c5 = c5_t
            best_h = h_t

    # Phase 2: Fine coordinate descent at n=960
    n = len(best_h)
    best_h, best_c5 = fine_cd(best_h, n, 12, elapsed, budget_s)

    # Phase 3: Shift-targeted SLSQP rounds
    for rnd in range(4):
        if elapsed() > budget_s - 100:
            break
        h_t = shift_targeted_slsqp(best_h, 500, 400)
        c5_t = compute_c5(h_t)
        if c5_t < best_c5:
            best_c5 = c5_t
            best_h = h_t
        best_h, best_c5 = fine_cd(best_h, len(best_h), 4, elapsed, budget_s)

    # Phase 4: Upsample to 2x and optimize
    if elapsed() > budget_s - 400:
        pass
    else:
        n_up = len(best_h) * 2
        if n_up <= 3840:
            h_up = upsample(best_h, n_up)
            c5_up = compute_c5(h_up)
            for T in [300, 800]:
                if elapsed() > budget_s - 200:
                    break
                h_up = do_slsqp(h_up, T, 400)
            h_up = shift_targeted_slsqp(h_up, 600, 300)
            h_up, c5_up = fine_cd(h_up, n_up, 5, elapsed, budget_s)
            if c5_up < best_c5:
                best_c5 = c5_up
                best_h = h_up

    # Phase 5: Random restarts
    for rs in range(5):
        if elapsed() > budget_s - 80:
            break
        n_r = len(best_h)
        sigma = 0.008 + 0.006 * rs
        h_r = make_feasible(best_h + rng.randn(n_r) * sigma, n_r)
        h_r = do_slsqp(h_r, 400, 300)
        h_r, c5_r = fine_cd(h_r, n_r, 3, elapsed, budget_s)
        if c5_r < best_c5:
            best_c5 = c5_r
            best_h = h_r

    # Phase 6: Final polish - high T SLSQP + fine CD
    if elapsed() > budget_s - 40:
        pass
    else:
        best_h = do_slsqp(best_h, 2000, 400)
        best_h, best_c5 = fine_cd(best_h, len(best_h), 5, elapsed, budget_s)
        # Binary snap attempt
        n_s = len(best_h)
        for i in range(n_s):
            if elapsed() > budget_s - 5:
                break
            for val in [0.0, 1.0]:
                if abs(best_h[i] - val) < 2e-4:
                    continue
                trial = best_h.copy()
                trial[i] = val
                trial = make_feasible(trial, n_s)
                c = compute_c5(trial)
                if c < best_c5 - 1e-14:
                    best_c5 = c
                    best_h = trial

    best_h = make_feasible(best_h, len(best_h))
    best_c5 = compute_c5(best_h)
    return best_h, best_c5, len(best_h)
```
