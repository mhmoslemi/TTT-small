```python
def corr_update_swap(corr, h, i, j, n):
    """Update full correlation after swapping h[i] (1→0) and h[j] (0→1).
    corr is indexed 0 to 2n-2, corresponding to shifts -(n-1) to n-1."""
    # shift s = m - (n-1) where m is the index in corr
    # So s ranges from -(n-1) to n-1
    
    # Create shift array
    s = np.arange(2*n-1) - (n-1)  # shape (2n-1,)
    
    # Validity masks for h[i-s], h[i+s], h[j-s], h[j+s]
    # h[i-s] valid: 0 <= i-s < n
    valid_is = (i - s >= 0) & (i - s < n)
    valid_ias = (i + s >= 0) & (i + s < n)
    valid_js = (j - s >= 0) & (j - s < n)
    valid_jas = (j + s >= 0) & (j + s < n)
    
    # Delta
    delta = np.zeros(2*n-1)
    # From h[i]: 1->0
    # -(1-h[i-s]) for valid i-s
    delta[valid_is] -= (1 - h[i - s[valid_is]])
    # +h[i+s] for valid i+s
    delta[valid_ias] += h[i + s[valid_ias]]
    # From h[j]: 0->1
    # +(1-h[j-s]) for valid j-s
    delta[valid_js] += (1 - h[j - s[valid_js]])
    # -h[j+s] for valid j+s
    delta[valid_jas] -= h[j + s[valid_jas]]
    
    corr += delta
    return corr, delta
```

This is O(n) per swap with numpy vectorization. For n=4000, the array s has length 7999, and each operation is a vectorized update. Should be very fast.
