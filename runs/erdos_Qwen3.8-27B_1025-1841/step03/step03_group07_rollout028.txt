```python
    """Compute np.correlate(a, b, mode='full') using FFT."""
    n = len(a)
    m = len(b)
    N = 1
    while N < n + m - 1:
        N *= 2
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    corr = np.fft.irfft(fa * np.conj(fb), N)
    # Rearrange to match np.correlate output
    # np.correlate(a, b, 'full')[k] = sum_i a[i] * b[i - (k - (m-1))]
    # The FFT gives circular correlation, which for zero-padded signals equals linear correlation
    # corr[j] = sum_i a[i] * b[(i-j) mod N]
    # For linear: corr_linear[k] = sum_i a[i] * b[i-k] for k = -(m-1), ..., n-1
    # In the zero-padded case: corr[j] for j=0..N-1
    # We want: result[k] for k = 0..n+m-2
    # result[k] = sum_i a[i] * b[i - (k - (m-1))]
    # Let j = k - (m-1), then result[k] = sum_i a[i] * b[i-j]
    # In circular correlation: corr[j mod N] = sum_i a[i] * b[(i-j) mod N]
    # With zero-padding, for |j| <= max(n,m)-1, this equals the linear correlation
    result = np.concatenate([corr[N-(m-1):], corr[:n-1]])
```

**Greedy local search with efficient evaluation:**

For a given pair (i, j), the change in c_l for each lag l is:

This is O(n) to compute for all lags (vectorized). Then the new max is:

which is also O(n). So each candidate evaluation is O(n).

If I try 1000 candidates per iteration, that's 1000 * n = 1000 * 4000 = 4M operations. Very fast!

The question is: which 1000 candidates to try? Strategy:
1. For the worst lag l*, find the i's with smallest h[i-l*] + h[i+l*] (least "loss" from removing i)
2. For those i's, find the j's with largest h[j-l*] + h[j+l*] (most "gain" from adding j)
3. Try the top combinations

```python
def efficient_flip_eval(h, i, j, c_old, n):
    """Evaluate the change in correlation for flipping i(1→0) and j(0→1)."""
    lags = np.arange(-(n-1), n, dtype=np.int64)
    
    # i-l and i+l validity
    i_m = i - lags
    i_p = i + lags
    j_m = j - lags
    j_p = j + lags
    
    # Compute h[i-l] with bounds (0 if out of range)
    hm_i_m = np.zeros(n*2-1)
    valid = (i_m >= 0) & (i_m < n)
    hm_i_m[valid] = h[i_m[valid]]
    
    hm_i_p = np.zeros(n*2-1)
    valid = (i_p >= 0) & (i_p < n)
    hm_i_p[valid] = h[i_p[valid]]
    
    hm_j_m = np.zeros(n*2-1)
    valid = (j_m >= 0) & (j_m < n)
    hm_j_m[valid] = h[j_m[valid]]
    
    hm_j_p = np.zeros(n*2-1)
    valid = (j_p >= 0) & (j_p < n)
    hm_j_p[valid] = h[j_p[valid]]
    
    delta = hm_i_m - hm_j_m + hm_i_p - hm_j_p
    return c_old + delta
```
