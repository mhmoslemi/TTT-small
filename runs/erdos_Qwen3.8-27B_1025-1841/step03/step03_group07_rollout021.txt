For the local search (Phase 3), here's the key insight: given all h[j] for j ≠ i fixed, the objective as a function of h[i] = t is:

C(t) = max_k (a_k * t + b_k)

where a_k and b_k are constants (depending on the other h values).

Specifically, for shift s ≥ 0:
The k-th correlation value (let's call it R_s) as a function of h[i]=t:
- If i is in the "overlap" region for shift s (i.e., both h[i-s] and h[i+s] are in range):
  R_s = ... + t*(1-h[i-s]) + h[i+s]*(1-t) + ... = ... + t - t*h[i-s] + h[i+s] - t*h[i+s] + ...
  = ... + h[i+s] + t*(1 - h[i-s] - h[i+s]) + ...
  
  So the coefficient of t is (1 - h[i-s] - h[i+s]).

- If only h[i-s] is in range (i < s or i > N-1-s... need to be more careful):
  Only one term involves t.

So R_s = A_s * t + B_s for all s, where A_s and B_s are constants given the other h values.

Therefore C(t) = max_s (A_s * t + B_s) is the maximum of affine functions of t, which is a convex piecewise-linear function. The minimum over t ∈ [0,1] can be found by:
1. Computing all the breakpoints where the active constraint changes
2. Or more simply, since it's convex, we can use the fact that the minimum is at a point where two constraints are tight, or at a boundary.

An efficient approach: 
- Evaluate C(0) and C(1)
- If C(0) ≤ C(1), the minimum is at t=0 or where the slope becomes positive
- The slope changes at specific points

Actually, the simplest approach for the 1D subproblem: since C(t) is convex piecewise linear on [0,1], the minimum is at:
- t = 0
- t = 1  
- Or at a breakpoint (where two lines cross)

The breakpoints are at t = (B_j - B_i) / (A_i - A_j) for pairs (i,j) where A_i ≠ A_j.

But there could be O(N) breakpoints, making this O(N²) per coordinate, which is O(N³) total. Too expensive.

Alternative: Since C(t) is convex, we can do ternary search or binary search on the derivative. The derivative of C(t) at t is A_k* where k* is the active constraint (the one achieving the max). Since C is piecewise linear, the subdifferential at t is [min active A, max active A].

We want to find t where 0 is in the subdifferential, i.e., where the active constraints have both positive and negative slopes (or the active slope is 0).

A practical approach: 
1. Compute the max of R_s at t=0.5 (or current t)
2. Get the active set (top few constraints)
3. Compute the slope for each active constraint
4. If all slopes > 0, decrease t; if all < 0, increase t
5. Binary search for the crossing point

- Compute the full correlation for the current h (O(N²))
- For coordinate i, compute a_s for all s (O(N))
- Find t* = argmin_{t∈[0,1]} max_s (a_s * t + b_s)
  - This is equivalent to: find t* such that the max of {a_s * t* + b_s} is minimized
  - By strong duality of LP: this equals the max of {b_s} + t* * min of {a_s | active at t*}... 
  
  Actually, the minimum of max_s (a_s * t + b_s) over t ∈ [0,1] can be found by:
  1. If max_s a_s ≤ 0, the function is non-increasing, min at t=1
  2. If min_s a_s ≥ 0, the function is non-decreasing, min at t=0
  3. Otherwise, the minimum is at a breakpoint where two lines cross

  A simpler approach: since we only need to do this for O(N) coordinates, and each evaluation is O(N), total is O(N²). We can just evaluate C(t) at a few candidate values of t (e.g., t=0, 0.25, 0.5, 0.75, 1) and pick the best.

Wait, but evaluating C(t) requires computing the full correlation, which is O(N²). If I do this for 5 values of t and N coordinates, that's 5*N*O(N²) = O(5N³) which is way too expensive for N=8000.

I need to be smarter. Let me use the incremental update:
- Keep the full correlation vector `corr` (length 2N-1)
- When I change h[i] from old to new, the change in corr[p] for each p is:
  Δcorr[p] = (new - old) * grad_s[p-(N-1)][i]
  where grad_s is the gradient of corr at shift s with respect to h[i]

So the update is O(N) (one per correlation value). Then I need to find the max of the updated corr, which is O(N).

Total per coordinate: O(N). Total per sweep: O(N²). For N=8000, that's 64M per sweep, which is fast.

But I also need to update the sum constraint. If I change h[i] by Δ, the sum changes by Δ. I need to compensate by changing another coordinate. This makes it more complex.

Alternative: Don't enforce the sum constraint during coordinate descent. Just do the optimization and project at the end of each sweep. The objective might temporarily increase during the sweep but should converge.

Let me just implement a simple version:

```python
def coord_descent(h, n, time_limit=100, n_candidates=5):
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full').astype(float)
    best_c5 = corr.max() * dx
    best_h = h.copy()
    start = time.time()
    
    candidates = np.array([0.0, 0.25, 0.5, 0.75, 1.0])
    
    for sweep in range(10000):
        if time.time() - start > time_limit:
            break
        improved = False
        for i in range(n):
            old = h[i]
            old_corr_max = corr.max()
            
            best_t = old
            best_max = old_corr_max
            
            for t in candidates:
                if abs(t - old) < 1e-10:
                    continue
                delta = t - old
                # Update corr incrementally
                new_corr = corr + delta * corr_grad_sum(h, n, i, old, t)
                new_max = new_corr.max()
                if new_max < best_max:
                    best_max = new_max
                    best_t = t
                    best_new_corr = new_corr
            
            if best_t != old:
                h[i] = best_t
                corr = best_new_corr
                improved = True
        
        # Project to feasible set
        h = project_to_feasible(h, n)
        corr = np.correlate(h, 1.0 - h, mode='full').astype(float)
        c5_now = corr.max() * dx
        
        if c5_now < best_c5:
            best_c5 = c5_now
            best_h = h.copy()
        
        if not improved:
            break
    
    return best_h, best_c5
```

But the `corr_grad_sum` function needs to compute, for a given i and delta, the change in all correlation values. Let me precompute this.

For coordinate i, the change in corr[p] when h[i] changes by delta is:
Δcorr[p] = delta * g_s[i] where s = p - (N-1) and g_s is the gradient of corr at shift s wrt all h.

From my earlier derivation:
g_s[i] = (1-h[i-s]) * [s≤i, 0≤i-s≤N-1] + (-h[i+s]) * [0≤i≤N-1-s, 0≤i+s≤N-1]

For s ≥ 0:
  g_s[i] = (1-h[i-s]) if s ≤ i ≤ N-1, else 0
           + (-h[i+s]) if 0 ≤ i ≤ N-1-s, else 0

For s < 0 (s = -m):
  g_s[i] = (1-h[i+m]) if 0 ≤ i ≤ N-1-m, else 0
           + (-h[i-m]) if m ≤ i ≤ N-1, else 0

So for a fixed i, g_s[i] is non-zero only for s in a specific range:
- For s ≥ 0: s can range from 0 to min(N-1-i, i) for the first term, and from 0 to min(N-1-i, i) for the second term. Actually:
  - First term (1-h[i-s]): valid when s ≤ i and i-s ≤ N-1, i.e., 0 ≤ s ≤ min(i, N-1) → 0 ≤ s ≤ min(i, N-1)
  - Second term (-h[i+s]): valid when i+s ≤ N-1, i.e., 0 ≤ s ≤ N-1-i

  So g_s[i] ≠ 0 for s = 0, 1, ..., min(i, N-1-i) (both terms) and possibly s = min(i, N-1-i)+1, ..., max(i, N-1-i) (one term only).

This means for each i, there are O(N) non-zero gradient components, and computing them is O(N).

For the coordinate descent, per coordinate: O(N) to compute the gradient contributions, O(N) to update corr and find max. Total O(N) per coordinate, O(N²) per sweep.

For N=8000: 64M per sweep. Each "operation" is simple (add, compare), so maybe 1-2 seconds per sweep in numpy. That's fine.

But wait, I'm also trying 5 candidate values of t for each coordinate. So it's 5 * O(N) per coordinate = O(5N) per coordinate, O(5N²) per sweep = 320M operations. Maybe 3-5 seconds per sweep. We can do ~20 sweeps in 100 seconds.

Actually, I realize there's an issue: when I try a candidate t for coordinate i, I compute new_corr = corr + delta * grad_vec. But grad_vec depends on the current h (not on t). So I can precompute grad_vec once per coordinate and then just do corr + delta * grad_vec for each candidate t. That's O(N) to precompute and O(5*N) to evaluate all candidates = O(N) per coordinate.

Let me also think about whether I should try intermediate values or just 0 and 1. Since the objective is bilinear in h, the minimum over the hypercube [0,1]^N (with the linear constraint) is achieved at a vertex, which means h ∈ {0,1}^N. So binary solutions are optimal!

Wait, is that true? The objective C(h) = max_k f_k(h) where each f_k(h) = ∫h(x)(1-h(x+k))dx is bilinear (quadratic but with no h² terms). The maximum of bilinear functions is not necessarily convex, so the minimum might not be at a vertex.

Actually, f_k(h) = sum_i h_i * (1 - h_{i+k}) is bilinear in h (linear in each argument separately). The maximum of bilinear functions is generally not convex or concave, so the minimum is not necessarily at a vertex.

However, in practice, good solutions tend to be close to binary. Let me try both binary and continuous approaches.

OK, I think I've thought about this enough. Let me write a practical solution that:

1. Uses the initial h, upsamples to n=8000
2. Does Nesterov optimization with adaptive tau (similar to before but tuned)
3. Does coordinate descent with binary candidates (0 and 1) and projection
4. Does a final Nesterov polish
5. Uses remaining time for multi-start

Let me also add a key improvement: **adaptive tau schedule**. The tau parameter controls the smoothness of the log-sum-exp approximation to max. Starting with high tau (smooth, easy to optimize) and gradually decreasing to low tau (sharp, close to true max) is a standard technique.

```python
import numpy as np
import time


def project_to_feasible(g, n):
    target = n / 2.0
    lo = g.min() - 2.0
    hi = g.max() + 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(g - mid, 0.0, 1.0))
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(g - (lo + hi) / 2.0, 0.0, 1.0)


def interp_periodic(h, target_n):
    n = len(h)
    if n == target_n:
        return h.copy()
    x_old = np.arange(n) * (2.0 / n)
    x_new = np.arange(target_n) * (2.0 / target_n)
    return np.interp(x_new, x_old, h, period=2.0)


def compute_c5(h):
    n = len(h)
    return np.correlate(h, 1.0 - h, mode='full').max() * (2.0 / n)


def corr_grad_vec(h, n, i):
    """Compute the gradient of all correlation values wrt h[i]. Returns vector of length 2n-1."""
    grad = np.zeros(2 * n - 1)
    # For shift s >= 0: g_s[i] = (1-h[i-s]) if s<=i else 0, plus -h[i+s] if i+s<=n-1 else 0
    # For shift s < 0 (s=-m): g_s[i] = (1-h[i+m]) if i<=n-1-m else 0, plus -h[i-m] if m<=i else 0
    # In full correlation indexing: position p = s + (n-1)
    # s ranges from -(n-1) to (n-1)
    
    # First term contribution: (1-h[i-s]) for s in [0, min(i, n-1)]
    s_max1 = min(i, n - 1)
    if s_max1 >= 0:
        s_range = np.arange(0, s_max1 + 1)
        positions = s_range + (n - 1)
        if i >= s_max1:
            # h[i-s] for s=0..s_max1
            vals = 1.0 - h[i - s_range]
            grad[positions] += vals
    
    # Second term contribution: -h[i+s] for s in [0, min(n-1-i, n-1)]
    s_max2 = n - 1 - i
    if s_max2 >= 0:
        s_range = np.arange(0, s_max2 + 1)
        positions = s_range + (n - 1)
        grad[positions] -= h[i + s_range]
    
    # Now negative shifts: s = -m, m in [1, n-1]
    # First term: (1-h[i+m]) for m in [1, min(n-1-i, n-1)]
    m_max1 = n - 1 - i
    if m_max1 >= 1:
        m_range = np.arange(1, m_max1 + 1)
        positions = -m_range + (n - 1)
        grad[positions] += 1.0 - h[i + m_range]
    
    # Second term: -h[i-m] for m in [1, min(i, n-1)]
    m_max2 = min(i, n - 1)
    if m_max2 >= 1:
        m_range = np.arange(1, m_max2 + 1)
        positions = -m_range + (n - 1)
        grad[positions] -= h[i - m_range]
    
    return grad


def nesterov_optimize(h, n, tau_start, tau_end, time_limit, top_k=15, lr_init=None):
    dx = 2.0 / n
    h = project_to_feasible(h, n).copy()
    best_c5 = compute_c5(h)
    best_h = h.copy()
    start = time.time()
    
    if lr_init is None:
        lr_init = 0.5 / tau_start
    
    h_prev = h.copy()
    t = 1.0
    lr = lr_init
    stall = 0
    n_iters = 0
    tau = tau_start
    
    for it in range(5000000):
        if time.time() - start > time_limit:
            break
        
        # Adaptive tau: decrease geometrically
        progress = min(1.0, (time.time() - start) / time_limit)
        tau = tau_start * (tau_end / tau_start) ** progress
        
        mu = (t - 1.0) / (t + 2.0)
        mu = min(mu, 0.9)
        y = h + mu * (h - h_prev)
        y = np.clip(y, 0.0, 1.0)
        
        # Compute soft objective gradient
        corr = np.correlate(y, 1.0 - y, mode='full')
        if top_k < len(corr):
            top_idx = np.argpartition(corr, -top_k)[-top_k:]
        else:
            top_idx = np.arange(len(corr))
        top_vals = corr[top_idx]
        m = top_vals.max()
        shifted = tau * (top_vals - m)
        shifted = np.clip(shifted, -60.0, 0.0)
        exp_c = np.exp(shifted)
        s = exp_c.sum()
        p = exp_c / s
        
        grad = np.zeros(n)
        for kk in range(len(top_idx)):
            pk = p[kk] * dx
            k = top_idx[kk]
            sh = k - n + 1
            if sh >= 0:
                # (1-h[i-sh]) for i=sh..n-1
                if sh < n:
                    grad[sh:] += pk * (1.0 - y[:n - sh])
                # -h[i+sh] for i=0..n-1-sh
                if sh < n:
                    grad[:n - sh] -= pk * y[sh:]
            else:
                mval = -sh
                # (1-h[i+mval]) for i=0..n-1-mval
                if mval < n:
                    grad[:n - mval] += pk * (1.0 - y[mval:])
                # -h[i-mval] for i=mval..n-1
                if mval < n:
                    grad[mval:] -= pk * y[:n - mval]
        
        h_new = y - lr * grad
        h_new = project_to_feasible(h_new, n)
        
        if it % 50 == 0:
            c5_now = compute_c5(h_new)
            if c5_now < best_c5 - 1e-15:
                best_c5 = c5_now
                best_h = h_new.copy()
                stall = 0
            else:
                stall += 50
            if stall > 3000:
                lr *= 0.5
                stall = 0
                if lr < 1e-14:
                    break
        
        t = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t * t))
        h_prev = h
        h = h_new
        n_iters += 1
    
    c5_final = compute_c5(h)
    if c5_final < best_c5:
        best_c5 = c5_final
        best_h = h.copy()
    return best_h, best_c5


def coord_descent_binary(h, n, time_limit=200):
    """Coordinate descent trying binary values, with projection after each sweep."""
    dx = 2.0 / n
    h = project_to_feasible(h, n).copy()
    corr = np.correlate(h, 1.0 - h, mode='full').astype(np.float64)
    best_c5 = corr.max() * dx
    best_h = h.copy()
    start = time.time()
    
    stall = 0
    
    for sweep in range(1000):
        if time.time() - start > time_limit:
            break
        if time.time() - start > time_limit - 5:
            break
        
        n_improved = 0
        for i in range(n):
            if time.time() - start > time_limit - 2:
                break
            old = h[i]
            # Try setting to 0 or 1
            candidates = []
            if old < 0.999:
                candidates.append(1.0)
            if old > 0.001:
                candidates.append(0.0)
            
            if len(candidates) == 0:
                continue
            
            grad_vec = corr_grad_vec(h, n, i)
            
            best_t = old
            best_max = corr.max()
            best_new_corr = None
            
            for t in candidates:
                delta = t - old
                new_corr = corr + delta * grad_vec
                new_max = new_corr.max()
                if new_max < best_max - 1e-14:
                    best_max = new_max
                    best_t = t
                    best_new_corr = new_corr
            
            if best_t != old:
                h[i] = best_t
                corr = best_new_corr
                n_improved += 1
        
        # Project
        h = project_to_feasible(h, n)
        corr = np.correlate(h, 1.0 - h, mode='full').astype(np.float64)
        c5_now = corr.max() * dx
        
        if c5_now < best_c5:
            best_c5 = c5_now
            best_h = h.copy()
            stall = 0
        else:
            stall += 1
        
        if stall > 8:
            break
    
    return best_h, best_c5


def subgrad_finetune(h, n, time_limit=100, lr_init=0.001, top_k=8):
    """Subgradient method with Nesterov smoothing for fine-tuning."""
    dx = 2.0 / n
    h = project_to_feasible(h, n).copy()
    best_c5 = compute_c5(h)
    best_h = h.copy()
    start = time.time()
    lr = lr_init
    v = np.zeros(n)
    beta = 0.75
    stall = 0
    
    for it in range(2000000):
        if time.time() - start > time_limit:
            break
        
        corr = np.correlate(h, 1.0 - h, mode='full')
        c5_now = corr.max() * dx
        if c5_now < best_c5 - 1e-15:
            best_c5 = c5_now
            best_h = h.copy()
            stall = 0
        else:
            stall += 1
        
        if stall > 3000:
            lr *= 0.6
            v *= 0.3
            stall = 0
            if lr < 1e-15:
                break
        
        if top_k < len(corr):
            top_idx = np.argpartition(corr, -top_k)[-top_k:]
        else:
            top_idx = np.arange(len(corr))
        top_vals = corr[top_idx]
        w = np.exp(top_vals - top_vals[0])
        w /= w.sum()
        
        grad = np.zeros(n)
        for kk in range(len(top_idx)):
            pk = w[kk] * dx
            k = top_idx[kk]
            sh = k - n + 1
            if sh >= 0:
                if sh < n:
                    grad[sh:] += pk * (1.0 - h[:n - sh])
                if sh < n:
                    grad[:n - sh] -= pk * h[sh:]
            else:
                mval = -sh
                if mval < n:
                    grad[:n - mval] += pk * (1.0 - h[mval:])
                if mval < n:
                    grad[mval:] -= pk * h[:n - mval]
        
        v = beta * v - lr * grad
        h = project_to_feasible(h + v, n)
    
    c5_final = compute_c5(h)
    if c5_final < best_c5:
        best_c5 = c5_final
        best_h = h.copy()
    return best_h, best_c5


def get_remaining(start_time, budget_s):
    return max(0.0, budget_s - (time.time() - start_time))
```
