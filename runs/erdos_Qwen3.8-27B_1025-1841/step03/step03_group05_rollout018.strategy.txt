   We propose to solve the Erdős minimum overlap problem using a hierarchical Bayesian optimization framework that incorporates spectral analysis and adaptive subsampling. By modeling the correlation structure in the frequency domain and linking it to the time-domain optimization, we can efficiently search for solutions that reduce the maximum overlap while respecting the constraints.

   Key Contributions:
   - Formulate the problem as minimizing a max-correlation criterion using Bayesian optimization
   - Introduce a frequency-domain smoothing regularizer to escape local optima
   - Develop an adaptive subsampling strategy that balances resolution and computational cost

   Theoretical Foundation:
   We observe that the overlap integral exhibits periodicity and correlation structure that can be characterized in the frequency domain. By incorporating a low-frequency bias into our search, we can find solutions that achieve lower overlap by effectively "smoothing" the correlation peaks.

2. Mathematical Specification

   Representation:
   - h(x) defined at n_point grid points x_i = i * dx, dx = 2/n_points
   - Continuous-valued variables h_i ∈ [0, 1] for i = 0, 1, ..., n_points-1

   Objective Function:
   - C5 = max_k (dx * ∫h(x)(1-h(x+k))dx)
   - Discrete equivalent: dx * max_l (np.correlate(h, 1-h, mode='full')[l])

   Constraints:
   - Integral constraint: Σh_i * dx = 1 → Σh_i = n_points/2
   - Box constraints: 0 ≤ h_i ≤ 1 for all i

   Optimization:
   - We minimize C5 using a constrained Bayesian optimization approach
   - The objective function is non-convex and requires careful handling of integer lags

   Implementation Details:
   - We use a probabilistic surrogate model to approximate the objective function
   - Incorporate a smoothing regularizer in the form of a low-pass filter on the Fourier coefficients
   - Automatically handle the integral constraint via projection in the sampler

   Helper Functions:
   def evaluate_overlap(h, n):
       dx = 2.0 / n
       corr = np.correlate(h, 1-h, mode='full')
       return np.max(corr) * dx

   def project_to_integral(h, n):
       clip = np.clip(h, 0, 1)
       total = np.sum(clip)
       if abs(total-n/2) < 1e-5: return clip
       factor = (n/2) / total
       return clip * factor

   3. Project to feasible set (intensity and integral constraints)
