Actually, the max of linear functions is convex, so the minimum of the max is well-defined. But finding it requires knowing which linear functions are active at the minimum.

A simpler approach: for coordinate i, compute the objective for v = 0, 1, and the current value, plus a few interpolated values. Or better: compute the gradient of the max w.r.t. v at the current point, and do a Newton/bisection step.

Wait, the objective (max of correlations) as a function of a single coordinate v is:
f(v) = max_k (c_k + a_k * v)

where c_k is the correlation k with h[i]=0 contribution removed, and a_k is the coefficient of v in correlation k.

This is the max of linear functions, hence convex. The minimum can be found by:
- Computing the slopes a_k for all k
- The minimum is where the subgradient contains 0, i.e., max(a_k for k where c_k+a_k*v = max) crosses 0.

But this is complex to implement. A simpler approach that works well in practice:
- Evaluate f at v=0, v=1, v=current, v=0.5
- Take the best and do a few bisection steps around it

Actually, since f is convex in v, we can use:
- f(0), f(1) to bracket
- If f is decreasing at 0 and increasing at 1, the minimum is in between
- Do bisection: evaluate f(mid), check if we can go left or right

But evaluating f requires computing the full correlation (O(n²) with np.correlate, or O(n) if we know which correlations are affected).

```python
    # Then for each trial v, add back h[i]'s contribution
    # corr[k] = sum_j h[j]*(1-h[j+n-1-k])
    # h[i] contributes: (1-h[i+n-1-k])*v (as first factor) + h[i+k-(n-1)]*(-v) (as part of 1-h)
    # Wait, (1-h[i]) = 1-v, so the term where i is the second index:
    # h[j]*(1-h[i]) where j+n-1-k=i => j=i-(n-1-k)=i+k-(n-1)

    h[i] = 0.0
    base_corr = np.correlate(h, 1.0 - h, mode='full')

    # As first factor h[i]=v: v*(1-h[i+n-1-k]) for k where 0<=i+n-1-k<=n-1 => k in [i, i+n-1]
    # As part of (1-h[i])=1-v: h[i+k-(n-1)]*(1-v) for k where 0<=i+k-(n-1)<=n-1 => k in [n-1-i, n-1-i+n-1] = [n-1-i, 2n-2-i]

    # Change: h[i+k-(n-1)]*(1-v) - h[i+k-(n-1)]*1 = -v*h[i+k-(n-1)]

    k2 = np.arange(max(0, n-1-i), min(2*n-2, 2*n-2-i)+1)

    valid2 = (idx2 >= 0) & (idx2 <= n-1)
    coeff[k2[valid2]] -= h[idx2[valid2]]
    
    # Now corr(k)(v) = base_corr[k] + v * coeff[k]
    # We want to minimize max_k (base_corr[k] + v * coeff[k]) over v in [0,1]

    # The subgradient at v is the set {coeff[k] : base_corr[k] + v*coeff[k] = max}
    # Minimum is where 0 is in the subgradient.

    # Since it's convex, ternary/bisection works

    for _ in range(20):

        v_right = min(1, best_v + 0.01)
        f_left = np.max(base_corr + v_left * coeff) if v_left >= 0 else float('inf')
        f_right = np.max(base_corr + v_right * coeff) if v_right <= 1 else float('inf')
        if f_left < best_f:
            best_v = v_left
            best_f = f_left
        elif f_right < best_f:
            best_v = v_right
            best_f = f_right
        else:
            # Binary search for the minimum
            lo = max(0, best_v - 0.01)
            hi = min(1, best_v + 0.01)
            for _ in range(30):
                mid = (lo + hi) / 2
                f_mid = np.max(base_corr + mid * coeff)
                # Check subgradient: if all active coeff > 0, go left; if all < 0, go right
                active = np.where(np.abs(base_corr + mid * coeff - f_mid) < 1e-10)[0]
                if len(active) == 0:
                    active = np.where(base_corr + mid * coeff >= f_mid - 1e-8)[0]
                if len(active) > 0 and np.max(coeff[active]) < 0:
                    hi = mid
                elif len(active) > 0 and np.min(coeff[active]) > 0:
                    lo = mid
                else:
                    break
            best_v = (lo + hi) / 2
            best_f = np.max(base_corr + best_v * coeff)
            break
    
    h[i] = best_v
    new_c5 = best_f * 2.0 / n
    return best_v, new_c5
```

Since f(v) = max_k (base_corr[k] + v * coeff[k]) is convex in v, I can use scipy's minimize_scalar bounded method on [0,1]. But that requires many function evaluations.

Alternatively, since f is piecewise linear with at most O(n) pieces (breakpoints where the argmax changes), I can find the minimum by:
1. Evaluating f at v=0 and v=1
2. If f'(0) >= 0 (all active coeff at v=0 are >= 0), minimum is at v=0
3. If f'(1) <= 0 (all active coeff at v=1 are <= 0), minimum is at v=1
4. Otherwise, the minimum is at a breakpoint in (0,1)
5. Find the breakpoint by: at the minimum, there exist k1, k2 with coeff[k1] < 0 < coeff[k2] and base_corr[k1]+v*coeff[k1] = base_corr[k2]+v*coeff[k2]

This is getting complicated. Let me just use a practical approach:
- Evaluate f at 20 evenly-spaced points in [0,1]
- Find the best one
- Do 30 bisection steps around it (using the subgradient)

Actually, the simplest effective approach: since f is convex, use the fact that the minimum of a convex function can be found by checking where the slope changes sign. The "slope" of f at v is the range of active coefficients [min(coeff[active]), max(coeff[active])]. If max < 0, we're to the right of the minimum. If min > 0, we're to the left.

Let me implement this cleanly:

```python
def opt_1d(base_corr, coeff):
    """Find v in [0,1] minimizing max_k(base_corr[k] + v*coeff[k])"""
    # Convex piecewise linear
    def f(v):
        return np.max(base_corr + v * coeff)
    
    def subgrad(v):
        fv = f(v)
        active = base_corr + v * coeff >= fv - 1e-12
        return np.min(coeff[active]), np.max(coeff[active])
    
    # Check endpoints
    f0 = f(0)
    f1 = f(1)
    
    mn0, mx0 = subgrad(0)
    if mn0 >= 0:
        return 0.0, f0
    mn1, mx1 = subgrad(1)
    if mx1 <= 0:
        return 1.0, f1
    
    # Bisection on the subgradient
    lo, hi = 0.0, 1.0
    for _ in range(60):
        mid = (lo + hi) / 2
        mn, mx = subgrad(mid)
        if mn >= 0:
            hi = mid
        elif mx <= 0:
            lo = mid
        else:
            return mid, f(mid)
    return (lo+hi)/2, f((lo+hi)/2)
```

```python
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_feasible(h, n):
    h = np.clip(h.astype(float).copy(), 0.0, 1.0)
    target = n / 2.0
    for _ in range(200):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0
            if not np.any(mask):
                break
            h[mask] += diff / np.sum(mask)
        else:
            mask = h > 0.0
            if not np.any(mask):
                break
            h[mask] += diff / np.sum(mask)
        h = np.clip(h, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-14:
        if diff > 0:
            idx = int(np.argmin(h))
        else:
            idx = int(np.argmax(h))
        h[idx] = float(np.clip(h[idx] + diff, 0.0, 1.0))
    return h

def build_coeff(h, n, i):
    """Build the coefficient array for h[i]'s contribution to correlations."""
    # h[i] = v: corr[k] = base[k] + v * coeff[k]
    # coeff[k] = (1-h[i+n-1-k]) [if valid] - h[i+k-(n-1)] [if valid]
    coeff = np.zeros(2 * n - 1)
    
    # First term: h[i] as first factor, (1-h[j]) where j = i+n-1-k
    # Valid: 0 <= i+n-1-k <= n-1 => i <= k <= i+n-1 (clipped to [0, 2n-2])
    k_lo = max(0, i)
    k_hi = min(2 * n - 2, i + n - 1)
    if k_lo <= k_hi:
        ks = np.arange(k_lo, k_hi + 1)
        js = i + n - 1 - ks
        coeff[ks] += (1.0 - h[js])
    
    # Second term: h[i] in (1-h[i]) = 1-v, affecting h[j]*(1-v) where j+k-(n-1)=i
    # j = i - k + (n-1) = i + n - 1 - k... wait
    # The second index in corr[k] = sum_i h[i]*(1-h[i+n-1-k]) is i+n-1-k.
    # If i+n-1-k = i (the coordinate we're varying), then k = n-1.
    # Wait no. The coordinate we're varying is h[i] (the i-th element of h).
    # It appears as the FIRST factor h[i] when the sum index is i.
    # It appears in the SECOND factor (1-h[...]) when the second index equals i.
    # Second index = sum_index + n - 1 - k. Set equal to i: sum_index = i - n + 1 + k.
    # Valid: 0 <= i-n+1+k <= n-1 => n-1-i <= k <= 2n-2-i (clipped to [0, 2n-2])
    k_lo2 = max(0, n - 1 - i)

    h_saved = h[i].copy()
    h[i] = 0.0
    base = np.correlate(h, 1.0 - h, mode='full')
    h[i] = h_saved
    
    coeff = build_coeff(h, n, i)

    # Convex piecewise linear
    def f_of_v(v):
        return np.max(base + v * coeff)

    # Subgradient at v: {coeff[k] : base[k] + v*coeff[k] = f(v)}
    def check_optimal(v):
        fv = f_of_v(v)
        active = (base + v * coeff) >= fv - 1e-12
        if not np.any(active):
            active = (base + v * coeff) >= fv - 1e-8
        return np.min(coeff[active]), np.max(coeff[active])

    v0 = h_saved
    mn0, mx0 = check_optimal(v0)
    if mn0 >= -1e-12 and mx0 <= 1e-12:
        return v0, f_of_v(v0)  # already optimal
    
    # Bisection
    lo, hi = 0.0, 1.0
    if mn0 >= 0:
        # f is non-decreasing at v0, so minimum is to the left
        hi = v0
    if mx0 <= 0:
        lo = v0
    
    for _ in range(50):
        mid = (lo + hi) / 2
        mn, mx = check_optimal(mid)
        if mn >= 0:
            hi = mid
        elif mx <= 0:
            lo = mid
        else:
            break
    
    best_v = (lo + hi) / 2
    best_f = f_of_v(best_v)
    
    # Also check endpoints
    f_left = f_of_v(lo)
    f_right = f_of_v(hi)
    if f_left < best_f:
        best_v, best_f = lo, f_left
    if f_right < best_f:
        best_v, best_f = hi, f_right
    
    h[i] = best_v
    return best_v, best_f
```

```python
def _compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def _make_feasible(h, n):
    h = np.clip(h.astype(float).copy(), 0.0, 1.0)
    target = n / 2.0
    for _ in range(200):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0
            if not np.any(mask):
                break
            h[mask] += diff / np.sum(mask)
        else:
            mask = h > 0.0
            if not np.any(mask):
                break
            h[mask] += diff / np.sum(mask)
        h = np.clip(h, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-14:
        if diff > 0:
            idx = int(np.argmin(h))
        else:
            idx = int(np.argmax(h))
        h[idx] = float(np.clip(h[idx] + diff, 0.0, 1.0))
    return h

def _build_coeff(h, n, i):
    coeff = np.zeros(2 * n - 1)
    k_lo = max(0, i)
    k_hi = min(2 * n - 2, i + n - 1)
    if k_lo <= k_hi:
        ks = np.arange(k_lo, k_hi + 1)
        js = i + n - 1 - ks
        coeff[ks] += (1.0 - h[js])
    k_lo2 = max(0, n - 1 - i)
    k_hi2 = min(2 * n - 2, 2 * n - 2 - i)
    if k_lo2 <= k_hi2:
        ks2 = np.arange(k_lo2, k_hi2 + 1)
        js2 = i - n + 1 + ks2
        coeff[ks2] -= h[js2]
    return coeff

    if fl < best_f:

    if fr < best_f:

        for s in range(max_swaps):
            if _time_left() < 5:
                break
            i = int(ones_list[rng.randint(len(ones_list))])
            j = int(zeros_list[rng.randint(len(zeros_list))])
            if i == j:
                continue
            h_cur[i], h_cur[j] = h_cur[j], h_cur[i]
            c5_try = _compute_c5(h_cur)
            if c5_try < c5_cur - 1e-14:
                c5_cur = c5_try
                if c5_cur < best_c5:
                    best_c5 = c5_cur
                    best_h = h_cur.copy()
            else:
                h_cur[i], h_cur[j] = h_cur[j], h_cur[i]

    # Phase 6: Final coordinate polish
    if _time_left() > 15:
        h_work = best_h.copy()
        for i in range(n):
            if _time_left() < 3:
                break
            new_v, new_max_corr = _opt_coord(h_work, n, i)
            new_c5 = new_max_corr * 2.0 / n
            if new_c5 < best_c5 - 1e-15:
                best_c5 = new_c5
                best_h = h_work.copy()
        h_work = _make_feasible(h_work, n)
        c5_f = _compute_c5(h_work)
        if c5_f < best_c5:
            best_c5 = c5_f
            best_h = h_work.copy()

    best_h = _make_feasible(best_h, n)
    best_c5 = _compute_c5(best_h)
    return best_h, best_c5, n
```
