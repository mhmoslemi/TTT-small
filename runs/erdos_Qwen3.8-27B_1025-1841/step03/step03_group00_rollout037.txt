For the binary local search, I want to be smarter than the previous approach. Instead of random swaps, I can:

- Identify the lag k* that achieves the maximum
- Find pairs (i,j) where flipping h[i] from 1 to 0 and h[j] from 0 to 1 would most reduce c_{k*}
- The change in c_k from flipping h[i]:1→0 and h[j]:0→1 is:
  For the term h[i](1-h[i+k]): we remove it, so delta = -(1-h[i+k])
  For the term h[i+k](1-h[i]): we add h[i+k], so delta = +h[i+k]
  For the term h[j](1-h[j+k]): we add it, so delta = +(1-h[j+k])
  For the term h[j+k](1-h[j]): we remove h[j+k], so delta = -h[j+k]
  
  Wait, this isn't quite right because we're changing both h[i] and h[j], and they might interact.

  Actually, for a unit flip (change h[i] by -1 and h[j] by +1), the change in c_k is:
  delta_c_k = -∂c_k/∂h[i] * (-1) + ∂c_k/∂h[j] * (+1)
  Wait, that's the linear approximation. For binary, the exact change is:
  
  c_k = sum_m h[m+k]*(1-h[m])
  
  If we change h[i] from 1 to 0 and h[j] from 0 to 1:
  - Term m=i in (1-h[m]): changes from 0 to 1, so h[i+k]*(1-h[i]) changes from h[i+k]*0 to h[i+k]*1, delta = +h[i+k]
  - Term m+k=i, i.e., m=i-k in h[m+k]: changes from h[i] to 0, so h[i]*(1-h[i-k]) changes from 1*(1-h[i-k]) to 0, delta = -(1-h[i-k])

  - Term m+k=j, i.e., m=j-k in h[m+k]: changes from h[j] to 1, so h[j]*(1-h[j-k]) changes from 0*(1-h[j-k]) to 1*(1-h[j-k]), delta = +(1-h[j-k])

  Net change in c_k: delta_c_k = h[i+k] - (1-h[i-k]) - h[j+k] + (1-h[j-k])
  = (h[i+k] + h[j-k]) - (h[i-k] + h[j+k])
  (with the convention that out-of-range terms are 0)

  Note: this is the same as the negative of the subgradient difference:
  -∂c_k/∂h[i] + ∂c_k/∂h[j] = -[(1-h[i-k]) - h[i+k]] + [(1-h[j-k]) - h[j+k]]
  = -(1-h[i-k]) + h[i+k] + (1-h[j-k]) - h[j+k]
  = h[i+k] - (1-h[i-k]) + (1-h[j-k]) - h[j+k]

So for the binary local search, I can:
1. Compute the correlation array c
2. Find the argmax lag k*
3. For each possible swap (i in ones, j in zeros), compute the effect on c_{k*}
4. Make the swap that most reduces c_{k*} (or the max correlation)

But this is O(n^2) per step, which for n=2048 is about 4M operations. That's fine for a few hundred steps.

Actually, I can be smarter. For a fixed lag k, the effect of swapping (i,j) on c_k is:
delta = h[i+k] + h[j-k] - h[i-k] - h[j+k] (with boundary handling)

To minimize c_k, we want to maximize -delta = h[i-k] + h[j+k] - h[i+k] - h[j-k]

For a fixed i (removing a 1), we want to choose j (adding a 1) to maximize h[j+k] - h[j-k].
For a fixed j (adding a 1), we want to choose i (removing a 1) to maximize h[i-k] - h[i+k].

So the best swap for lag k is:
best_i = argmax_{i in ones} (h[i-k] - h[i+k])
best_j = argmax_{j in zeros} (h[j+k] - h[j-k])

And the total delta is -((h[best_i-k] - h[best_i+k]) + (h[best_j+k] - h[best_j-k]))

This can be computed in O(n) time! Then we just need to check that the swap actually reduces the MAX correlation (not just c_{k*}), and possibly try a few candidate swaps.

    new_x = np.linspace(0.0, 2.0, new_n, endpoint=False)
    h_new = np.interp(new_x, old_x, h, period=2.0)

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_feasible(h, n):
    h = np.clip(np.asarray(h, dtype=float), 0.0, 1.0).copy()
    target = n / 2.0
    for _ in range(100):
        diff = target - np.sum(h)
        if abs(diff) < 1e-12:
            break
        mask = h < 1.0 - 1e-12 if diff > 0 else h > 1e-12
        cnt = np.sum(mask)
        if cnt == 0:
            break
        step = diff / cnt
        h[mask] = np.clip(h[mask] + step, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-12:
        idx = np.argmin(h) if diff > 0 else np.argmax(h)
        h[idx] = np.clip(h[idx] + diff, 0.0, 1.0)
    return h

def upsample_h(h, new_n):
    old_n = len(h)
    if new_n == old_n:
        return make_feasible(h.copy(), new_n)
    old_x = np.linspace(0.0, 2.0, old_n, endpoint=False)
    new_x = np.linspace(0.0, 2.0, new_n, endpoint=False)
    h_new = np.interp(new_x, old_x, h, period=2.0)
    return make_feasible(h_new, new_n)

def f_and_grad(h, n, T, mu):
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    mc = np.max(corr)
    shifted = T * (corr - mc)
    shifted = np.clip(shifted, -80.0, 80.0)
    exp_shifted = np.exp(shifted)
    log_sum = mc + np.log(np.sum(exp_shifted)) / T
    obj = log_sum * dx
    viol = np.sum(h) - n / 2.0
    obj += mu * viol * viol

    w = exp_shifted / np.sum(exp_shifted)
    L = 1
    while L < 3 * n - 1:
        L <<= 1
    a = 1.0 - h
    w_rev = w[::-1]
    conv1 = np.fft.ifft(np.fft.fft(a, L) * np.fft.fft(w, L)).real
    conv2 = np.fft.ifft(np.fft.fft(h, L) * np.fft.fft(w_rev, L)).real
    grad = dx * (conv1[n - 1:2 * n - 1] - conv2[n - 1:2 * n - 1])
    grad += 2.0 * mu * viol
    return obj, grad

                   bounds=bounds, options={'maxiter': max_iter, 'ftol': 1e-15, 'gtol': 1e-10, 'maxls': 50})
