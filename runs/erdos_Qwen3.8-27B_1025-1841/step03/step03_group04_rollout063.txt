```python
def compute_delta(h, n):
    """delta[p][k] = change in corr[k] when h[p] flips 0->1 (h is BEFORE flip)."""
    m = 2 * n - 1  # number of correlation lags
    delta = np.zeros((n, m))
    center = n - 1  # k = n-1 is the self-correlation
    
    for p in range(n):
        # Self-correlation: no change
        # delta[p, center] = 0 (already 0)
        
        # First factor: h[p] * (1 - h[p+k-center])
        # p+k-center in [0, n): k in [center-p, center-p+n)
        k1_start = max(0, center - p)
        k1_end = min(m-1, center - p + n - 1)
        if k1_start <= k1_end:
            other_idx = np.arange(k1_start, k1_end+1) + p - center  # = p+k-center
            delta[p, k1_start:k1_end+1] += (1.0 - h[other_idx])
        
        # Second factor: h[p-k+center] * (1 - h[p])
        # p-k+center in [0, n): k in [p-center, p+center]  wait...
        # 0 <= p-k+center < n => center-p < k <= center+p  wait
        # 0 <= p-k+center => k <= p+center
        # p-k+center < n => k > p+center-n => k >= p+center-n+1
        k2_start = max(0, p + center - n + 1)
        k2_end = min(m-1, p + center)
        if k2_start <= k2_end:
            other_idx = p - np.arange(k2_start, k2_end+1) + center  # = p-k+center
            delta[p, k2_start:k2_end+1] += (-h[other_idx])
        
        # Remove the double-counting at k=center (self-interaction)
        # At k=center: first factor gives (1-h[p]), second gives -h[p]. Sum = 1-2h[p].
        # But actual change is 0. So subtract (1-2h[p]) at k=center.
        if 0 <= center < m:
            delta[p, center] -= (1.0 - 2.0 * h[p])
    
    return delta
```

Now I can code the 2-swap optimization. The key insight is:
- For a swap (j: 1→0, i: 0→1), the change in corr is: -delta[j] + delta[i]
  (since flipping 1→0 is the negative of 0→1)
- New corr = corr - delta[j] + delta[i]
- We want to minimize max(new_corr)

```python
def greedy_2swap(h, n, n_active=30, n_sweeps=50):
    """Greedy 2-swap local search for binary h."""
    best_h = h.copy()
    best_c5 = compute_c5(best_h)
    
    for sweep in range(n_sweeps):
        corr = get_corr(best_h)
        delta = compute_delta(best_h, n)
        
        # Find active shifts
        top_k_idx = np.argsort(-corr)[:n_active]
        
        # Get indices of 1s and 0s
        ones = np.where(best_h == 1)[0]
        zeros = np.where(best_h == 0)[0]
        
        improved = False
        # For each pair, compute the max over active shifts
        # Vectorized: for each j in ones, i in zeros:
        # new_corr_active = corr_active - delta[j, active] + delta[i, active]
        # new_max = max(new_corr_active)
        
        corr_act = corr[top_k_idx]  # shape: (K,)
        delta_ones = delta[ones]  # shape: (n_ones, 2n-1)
        delta_zeros = delta[zeros]  # shape: (n_zeros, 2n-1)
        delta_ones_act = delta_ones[:, top_k_idx]  # (n_ones, K)
        delta_zeros_act = delta_zeros[:, top_k_idx]  # (n_zeros, K)
        
        # For each j, i: new_max = max(corr_act - delta_ones_act[j] + delta_zeros_act[i])
        # = max over k in active of (corr_act[k] - delta_ones_act[j,k] + delta_zeros_act[i,k])
        
        # This is an (n_ones × n_zeros × K) computation. For n_ones=n_zeros=480, K=30:
        # 480 * 480 * 30 = 6.9M float ops. Should be fast with numpy.
        
        # For a given j: best i minimizes max_k (corr_act - delta_ones_act[j] + delta_zeros_act[i])
        # Let base_j = corr_act - delta_ones_act[j]  (shape K)
        # Then for each i: value_i = max_k (base_j[k] + delta_zeros_act[i,k])
        # We want argmin_i value_i
        
        best_overall_c5 = best_c5
        for j_idx in range(len(ones)):
            base_j = corr_act - delta_ones_act[j_idx]  # shape: (K,)
            # For each zero i: max_k (base_j[k] + delta_zeros_act[i, k])
            # = for each i: max of (K,) vectors
            # delta_zeros_act has shape (n_zeros, K)
            # base_j[None, :] + delta_zeros_act → (n_zeros, K)
            # max over axis=1 → (n_zeros,)
            candidate_maxes = np.max(base_j[None, :] + delta_zeros_act, axis=1)
            best_i_idx = np.argmin(candidate_maxes)
            new_max_active = candidate_maxes[best_i_idx]
            
            # Also check the full max (not just active)
            # For speed, only compute full if active max is promising
            if new_max_active < np.max(corr_act) - 1e-10:
                trial = best_h.copy()
                trial[ones[j_idx]] = 0
                trial[zeros[best_i_idx]] = 1
                new_c5 = compute_c5(trial)
                if new_c5 < best_overall_c5 - 1e-12:
                    best_h = trial
                    best_c5 = new_c5
                    best_overall_c5 = new_c5
                    improved = True
                    # Recompute everything
                    corr = get_corr(best_h)
                    delta = compute_delta(best_h, n)
                    top_k_idx = np.argsort(-corr)[:n_active]
                    ones = np.where(best_h == 1)[0]
                    zeros = np.where(best_h == 0)[0]
                    corr_act = corr[top_k_idx]
                    delta_ones = delta[ones][:, top_k_idx]
                    delta_zeros = delta[zeros][:, top_k_idx]
                    break  # restart the j loop
        
        if not improved:
            break
    
    return best_h, best_c5
```

This is O(n_ones * n_zeros * K) per sweep with early break. Should be manageable.

Now for the continuous coordinate descent, exploiting the linearity:

For coordinate j, the optimal h[j] minimizes max_k (a_k * h[j] + b_k) * dx over h[j] ∈ [0,1], where:
- a_k = delta[j][k] (the change per unit change in h[j])
  Wait, delta[j][k] is the change when h[j] goes from 0 to 1. So for a general change δh:
  corr[k] → corr[k] + δh * delta[j][k] (for small δh, linear)
  
  Actually, for h[j] going from current value v to v+δ:
  The change is NOT simply δ * delta[j][k] unless h[j] was 0 or 1 (binary).
  
  For general v ∈ (0,1):
  corr[k] = ... + h[j]*(1-h[p1]) + h[p2]*(1-h[j]) + ... where p1 = j+k-center, p2 = j-k+center
  (with appropriate validity checks)
  
  = ... + h[j] - h[j]*h[p1] + h[p2] - h[p2]*h[j]
  = ... + h[j]*(1 - h[p1] - h[p2]) + h[p2]
  
  So the coefficient of h[j] in corr[k] is: (1 - h[p1] - h[p2]) where p1, p2 are the "partner" positions.
  And the constant (from the other terms) makes b_k = corr[k] - a_k * h[j].

For k = center: the term is h[j]*(1-h[j]) = h[j] - h[j]^2. This is NONLINEAR.
So for k=center, corr[center] as a function of h[j] is: (constant) + h[j] - h[j]^2.

For k ≠ center (and where p1 ≠ p2, which is guaranteed since k≠center):
corr[k] = (constant) + a_k * h[j] where a_k = 1 - h[p1] - h[p2] (with validity: if p1 invalid, just 1-h[p2]; if p2 invalid, just 1-h[p1]; if both invalid: 1).

So the function to minimize is:
max( max_{k≠center} (a_k * h + b_k), b_center + h - h^2 ) * dx

The first part is convex (max of linear functions), the second part is concave (h - h^2).
The max of a convex and concave function is not necessarily convex.

However, since h - h^2 ≤ 1/4 (max at h=0.5), and the convex part is ≥ 0, in practice the max will often be determined by the convex part. And the overall function is still unimodal in [0,1] (I think? Not necessarily, but likely in practice).

For a safe approach: I'll evaluate the function at a grid of points (say 100 points in [0,1]) and pick the best. Or use a more refined method.
