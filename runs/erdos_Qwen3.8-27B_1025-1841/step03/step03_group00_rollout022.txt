**Subgradient descent algorithm:**
1. Compute c_k for all k, find k* = argmax
2. Compute gradient of c_{k*} w.r.t. h
3. Take a step: h_new = h - alpha * grad(c_{k*})
4. Project to feasible set (clip to [0,1], adjust sum)
5. Repeat

This is like a cutting-plane method applied to the max.

The gradient of c_{k*} = sum_i h[i+k*]*(1-h[i]) w.r.t. h[j]:
- If j is in the range where it appears as h[i+k*]: ∂/∂h[j] = 1 - h[j-k*] (for valid j-k*)
- If j is in the range where it appears as h[i]: ∂/∂h[j] = -h[j+k*] (for valid j+k*)
- If j appears in both: combined

Let me code this up properly.

For the linear correlation c_k = sum_{i=max(0,-k)}^{min(n-1, n-1-k)} h[i+k] * (1-h[i]):
- For k >= 0: i ranges from 0 to n-1-k
- For k < 0: i ranges from -k to n-1

Let me use the numpy convention: corr[m] = sum_i h[i] * (1-h[i-(m-(n-1))])
where m = 0, ..., 2n-2 and the shift is s = m - (n-1).

Actually, let me just use the formula:
corr = np.correlate(h, 1-h, mode='full')
This gives corr[m] for m = 0, ..., 2n-2.

The gradient of corr[m] w.r.t. h[j]:
corr[m] = sum_i a[i] * v[i - (m - (n-1))] where a = h, v = 1-h

Hmm, let me just use the definition directly.

np.correlate(a, v, 'full')[m] = sum_n a[n] * v[n + (n_a - 1 - m)]

where n_a = len(a) = n. So:
corr[m] = sum_{n=0}^{n-1} h[n] * (1-h[n + n - 1 - m])

For this to be valid, we need 0 ≤ n + n - 1 - m ≤ n-1, i.e., m-n+1 ≤ n ≤ m.

So the valid range of n is from max(0, m-n+1) to min(n-1, m).

∂corr[m]/∂h[j]:
- From the h[n] term: if n = j is in range, contribution is (1-h[j + n - 1 - m]) = (1-h[2n-1-j-m])... wait this is getting confusing.

Let me just use a different convention. Let s = m - (n-1) be the "shift" (ranging from -(n-1) to n-1).

corr[m] = sum_i h[i] * (1-h[i-s]) for valid i (where both i and i-s are in [0, n-1]).

∂corr[m]/∂h[j]:
- Term where h[j] appears as h[i] (i=j): (1-h[j-s]) if j-s is valid
- Term where h[j] appears as h[i-s] (i-s=j, i=j+s): -(h[j+s]) if j+s is valid

So: ∂corr[m]/∂h[j] = (1-h[j-s])*I[j-s valid] - h[j+s]*I[j+s valid]

Where s = m - (n-1).

This gives us the subgradient of the objective at the point where corr[m] is the maximum.

        else:

def subgradient_step(h, alpha):
    """Take a subgradient descent step on the max correlation."""
    n = len(h)
    corr = compute_corr(h)
    m_star = np.argmax(corr)
    s = m_star - (n - 1)  # shift
    
    # Gradient of corr[m_star] w.r.t. h[j]
    grad = np.zeros(n)
    for j in range(n):
        # Contribution from h[j] as h[i] (i=j): (1-h[j-s]) if j-s in [0,n-1]
        if 0 <= j - s <= n - 1:
            grad[j] += (1.0 - h[j - s])
        # Contribution from h[j] as h[i-s] (i=j+s): -h[j+s] if j+s in [0,n-1]
        if 0 <= j + s <= n - 1:
            grad[j] -= h[j + s]
    
    h_new = h - alpha * grad
    h_new = make_feasible(h_new, n)
    return h_new, m_star, grad

Actually, for a given shift s, the gradient is:
grad[j] = (1-h[j-s]) * I[0≤j-s≤n-1] - h[j+s] * I[0≤j+s≤n-1]

This can be computed with array operations:
```python
def compute_subgradient(h, s):
    n = len(h)
    grad = np.zeros(n)
    # (1-h[j-s]) for valid j-s
    if s >= 0:
        # j-s >= 0 means j >= s; j-s <= n-1 means j <= n-1+s (always true for j < n)
        valid_start = max(0, s)
        valid_end = n
        grad[valid_start:valid_end] += (1.0 - h[valid_start-s:valid_end-s])
    else:
        # j-s >= 0 means j >= s (but s < 0, so always true for j >= 0)
        # j-s <= n-1 means j <= n-1+s
        valid_start = 0
        valid_end = min(n, n + s)  # n-1+s+1 = n+s
        grad[valid_start:valid_end] += (1.0 - h[valid_start-s:valid_end-s])
    
    # -h[j+s] for valid j+s
    if s >= 0:
        valid_start = 0
        valid_end = n - s
        grad[valid_start:valid_end] -= h[valid_start+s:valid_end+s]
    else:
        valid_start = -s
        valid_end = n
        grad[valid_start:valid_end] -= h[valid_start+s:valid_end+s]
    
    return grad
```

Now, the subgradient descent algorithm:
1. Start with h (feasible)
2. Compute corr, find m* = argmax
3. Compute s* = m* - (n-1)
4. Compute grad = subgradient at s*
5. h_new = h - alpha * grad
6. Project h_new to feasible set
7. If C5(h_new) < C5(h), accept; otherwise reduce alpha
8. Repeat

This is a standard subgradient method for minimizing a max function. It's not the fastest, but it's reliable.

However, since our objective is not just max but max of quadratic functions, the subgradient method might be slow. Let me also include the soft-max L-BFGS-B approach.

Let me now write the complete algorithm:

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def make_feasible(h, n):
    h = np.clip(np.asarray(h, dtype=float), 0.0, 1.0).copy()
    target = n / 2.0
    for _ in range(500):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-14
        else:
            mask = h > 1e-14
        cnt = np.sum(mask)
        if cnt == 0:
            break
        step = diff / cnt
        h[mask] = np.clip(h[mask] + step, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-14:
        if diff > 0:
            idx = int(np.argmax(h))
        else:
            idx = int(np.argmin(h))
        h[idx] = float(np.clip(h[idx] + diff, 0.0, 1.0))
    return h

def upsample_h(h, new_n):
    old_n = len(h)
    if new_n == old_n:
        return make_feasible(h.copy(), new_n)
    old_x = np.linspace(0.0, 2.0, old_n, endpoint=False)
    new_x = np.linspace(0.0, 2.0, new_n, endpoint=False)
    h_new = np.interp(new_x, old_x, h, period=2.0)
    return make_feasible(h_new, new_n)

def softmax_objective(h, T, mu):
    n = len(h)
    dx = 2.0 / n
    corr = compute_corr(h)
    mc = np.max(corr)
    shifted = T * (corr - mc)
    shifted = np.clip(shifted, -100, 100)
    soft = (mc + np.log(np.sum(np.exp(shifted))) / T) * dx
    viol = np.sum(h) - n / 2.0
    return soft + mu * viol * viol

def lbgfb_optimize(h_start, n, T, mu, max_iter=300, gtol=1e-12):
    dx = 2.0 / n
    def f(h):
        return softmax_objective(h, T, mu)
    bounds = [(0.0, 1.0)] * n
    res = minimize(f, h_start, method='L-BFGS-B', bounds=bounds,
                   options={'maxiter': max_iter, 'ftol': 1e-18, 'gtol': gtol})
    return make_feasible(res.x, n)

def compute_subgrad(h, s):
    n = len(h)
    grad = np.zeros(n)
    # First term: (1-h[j-s]) for valid j-s in [0, n-1]
    if s >= 0:
        # j-s >= 0 => j >= s; j-s <= n-1 => j <= n-1+s (always true for j < n when s >= 0)
        lo = s
        hi = n
        grad[lo:hi] += (1.0 - h[lo-s:hi-s])
    else:
        # j-s >= 0 => j >= -s (always true); j-s <= n-1 => j <= n-1+s
        lo = 0
        hi = n + s  # = n-|s|
        grad[lo:hi] += (1.0 - h[lo-s:hi-s])
    
    # Second term: -h[j+s] for valid j+s in [0, n-1]
    if s >= 0:
        # j+s <= n-1 => j <= n-1-s
        lo = 0
        hi = n - s
        grad[lo:hi] -= h[lo+s:hi+s]
    else:
        # j+s >= 0 => j >= -s
        lo = -s
        hi = n
        grad[lo:hi] -= h[lo+s:hi+s]
    
    return grad

def subgradient_method(h, n, max_iter=5000, alpha_init=0.01, alpha_decay=0.999):
    alpha = alpha_init
    best_c5 = compute_c5(h)
    best_h = h.copy()
    for it in range(max_iter):
        corr = compute_corr(h)
        m_star = int(np.argmax(corr))
        s = m_star - (n - 1)
        grad = compute_subgrad(h, s)
        h_new = h - alpha * grad
        h_new = make_feasible(h_new, n)
        c5_new = compute_c5(h_new)
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new.copy()
            h = h_new
        else:
            alpha *= alpha_decay
            if alpha < 1e-10:
                break
    return best_h, best_c5

def coordinate_descent(h, n, max_rounds=100, step_sizes=None):
    if step_sizes is None:
        step_sizes = [0.01, -0.01, 0.005, -0.005, 0.002, -0.002, 0.001, -0.001]
    best_c5 = compute_c5(h)
    best_h = h.copy()
    for rnd in range(max_rounds):
        improved = False
        for j in range(n):
            ov = best_h[j]
            for d in step_sizes:
                nv = ov + d
                if nv < 0 or nv > 1:
                    continue
                trial = best_h.copy()
                trial[j] = nv
                trial = make_feasible(trial, n)
                c = compute_c5(trial)
                if c < best_c5 - 1e-15:
                    best_c5 = c
                    best_h = trial
                    ov = nv
                    improved = True
            # Also try binary
            for bv in (0.0, 1.0):
                if abs(bv - best_h[j]) < 1e-9:
                    continue
                trial = best_h.copy()
                trial[j] = bv
                trial = make_feasible(trial, n)
                c = compute_c5(trial)
                if c < best_c5 - 1e-15:
                    best_c5 = c
                    best_h = trial
                    improved = True
        if not improved:
            break
    return best_h, best_c5

def binary_local_search(h_bin, n, rng, max_rounds=200):
    h = h_bin.copy()
    current = compute_c5(h)
    ones = np.where(h > 0.5)[0].copy()
    zeros = np.where(h <= 0.5)[0].copy()
    for rnd in range(max_rounds):
        improved = False
        n_tries = min(5000, max(100, len(ones) * len(zeros) // 10))
        for _ in range(n_tries):
            ii = int(rng.randint(len(ones)))
            jj = int(rng.randint(len(zeros)))
            oi, oj = int(ones[ii]), int(zeros[jj])
            h[oi] = 0.0
            h[oj] = 1.0
            c = compute_c5(h)
            if c < current:
                current = c
                # Update lists
                ones = np.delete(ones, ii)
                zeros = np.delete(zeros, jj)
                ones = np.append(ones, oj)
                zeros = np.append(zeros, oi)
                improved = True
            else:
                h[oi] = 1.0
                h[oj] = 0.0
        if not improved:
            break
    return h, current
