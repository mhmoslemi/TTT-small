np.correlate(a, v, mode='full') for same-length arrays a, v of length n:

Wait, I need to be more careful. From numpy docs:
"correlate(a, v, mode='full'): ... The (1-D) cross-correlation c(k) = sum_n a(n+k) * conj(v(n))"

For mode='full', the output is:
c[k] for k = -(n-1), ..., 0, ..., n-1
stored at indices 0, 1, ..., 2n-2

So output[i] = c[i-(n-1)] where c(k) = sum_n a[n+k] * v[n] (valid n).

For k >= 0: c(k) = sum_{n=0}^{n-1-k} a[n+k] * v[n]
For k < 0: c(k) = sum_{n=-k}^{n-1} a[n+k] * v[n]

Now, convolve(a, b, mode='full')[k] = sum_i a[i] * b[k-i]

If I set b = v[::-1], then b[j] = v[n-1-j].
convolve(a, v[::-1])[k] = sum_i a[i] * v[n-1-(k-i)] = sum_i a[i] * v[n-1-k+i]

Let m = n-1-k+i, so i = m - n + 1 + k.
= sum_m a[m-n+1+k] * v[m]

This matches c(k-(n-1)) = sum_m a[m+k-(n-1)] * v[m].

So: correlate(a, v, 'full') = convolve(a, v[::-1], 'full')

And convolve via FFT:
conv(a, b) = ifft(fft(a, N) * fft(b, N)) (with proper zero-padding)

So: correlate(h, g, 'full') = ifft(rfft(h, Np) * rfft(g[::-1], Np))[:2n-1]

```python
def fast_c5(h):
    n = len(h)
    dx = 2.0 / n
    g = 1.0 - h
    N = 2 * n - 1
    Np = 1 << (N - 1).bit_length()
    H = np.fft.rfft(h, Np)
    G = np.fft.rfft(g[::-1], Np)
```

For the SLSQP part, I'll use a global variable for n and T (temperature of soft-max):

```python
_sl_n = 0
_sl_T = 0.0

def _slsqp_obj(x):
    n = _sl_n
    T = _sl_T
    dx = 2.0 / n
    g = 1.0 - x
    N = 2 * n - 1
    Np = 1 << (N - 1).bit_length()
    H = np.fft.rfft(x, Np)
    G = np.fft.rfft(g[::-1], Np)
    corr = np.fft.irfft(H * G, Np)[:N]
    mc = np.max(corr)
    shifted = corr - mc
    return (mc + np.log(np.sum(np.exp(T * shifted))) / T) * dx

def _slsqp_con(x):
    return np.sum(x) - len(x) / 2.0

def _slsqp_con_jac(x):
    return np.ones(len(x))

def slsqp_polish(h, n, T, maxiter, ftol, deadline):
    global _sl_n, _sl_T
    _sl_n = n
    _sl_T = T
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _slsqp_con, 'jac': _slsqp_con_jac}]
    res = minimize(_slsqp_obj, h.copy(), method='SLSQP',
                   bounds=bounds, constraints=cons,
                   options={'maxiter': maxiter, 'ftol': ftol})
    if time.time() > deadline:
        return h
    return make_feasible(res.x, n)
```

```python
    best_c5 = fast_c5(h)
    for rnd in range(max_rounds):
        if time.time() > deadline:
            break
        improved = False
```

```python
            if time.time() > deadline:
                break
            i = j
            k = j + 1 if j + 1 < n else j - 1
            old_i, old_k = h[i], h[k]
            # Try transferring different amounts
            for delta in [0.1, 0.05, 0.02, -0.02, -0.05, -0.1]:

                new_k = old_k - delta

                        improved = True

                        h[k] = old_k
                else:
                    h[i] = old_i
                    h[k] = old_k
        if not improved:
            break
```
