Actually, you know what, let me just use a simpler approach for the SLSQP: compute the gradient using the "top-k" approximation. Instead of the full soft-max gradient, just use the gradient of the single worst correlation. This is much simpler and still effective for SLSQP.

```python
def _worst_corr_grad(h, n):
    corr = np.correlate(h, 1.0 - h, mode='full')
    k_top = np.argmax(corr)
    off = k_top - (n - 1)
    m = 2 * n - 1
    g = np.zeros(n)
    # ∂c[k_top]/∂h[j] = (1 - h[j+off])*1[valid] - h[j-off]*1[valid]
    idx_p = np.arange(n) + off
    valid_p = (idx_p >= 0) & (idx_p < n)
    g[valid_p] += (1.0 - h[idx_p[valid_p]])
    idx_m = np.arange(n) - off
    valid_m = (idx_m >= 0) & (idx_m < n)
    g[valid_m] -= h[idx_m[valid_m]]
    obj = np.max(corr) * 2.0 / n
    return obj, g * (2.0 / n)
```

This gives the gradient of the single worst correlation, which is a valid subgradient of the max function. SLSQP can handle subgradients (it might be slow to converge but should work).
