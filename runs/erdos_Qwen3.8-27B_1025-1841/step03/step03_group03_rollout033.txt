def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_feasible(h, n):
    h = np.clip(np.asarray(h, dtype=float), 0.0, 1.0)
    target = n / 2.0
    diff = target - np.sum(h)
    if abs(diff) > 1e-10:
        if diff > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        cnt = np.sum(mask)
        if cnt > 0:
            h[mask] += diff / cnt
            h = np.clip(h, 0.0, 1.0)
    return h

def binarize_with_constraint(h, n, rng):
    """Convert to binary with exactly n/2 ones"""
    h_bin = (h > 0.5).astype(float)
    s = int(np.sum(h_bin))
    target = n // 2
    if s > target:
        idx = np.where(h_bin == 1)[0]
        to_remove = rng.choice(idx, s - target, replace=False)
        h_bin[to_remove] = 0
    elif s < target:
        idx = np.where(h_bin == 0)[0]
        to_add = rng.choice(idx, target - s, replace=False)
        h_bin[to_add] = 1
    return h_bin

1. i=p: old = 1*(1-h[p+k]), new = 0*(1-h[p+k]=new h) 
   If q ≠ p+k: change = -(1-h_old[p+k])
   If q = p+k: change = -(1-1) = 0 (since h[p+k] is now 1)
   
   Wait, this is getting complicated because the flip at q also affects the value at position p+k if q = p+k.

Let me handle this more carefully.

After the swap, the new values are:
- h_new[p] = 0 (was 1)
- h_new[q] = 1 (was 0)
- All other h_new[i] = h[i]

The change in cross_corr[k] = sum_i (h_new[i]*(1-h_new[i+k])) - sum_i (h[i]*(1-h[i+k]))

The terms that change are those where i ∈ {p, p-k} or i+k ∈ {p, p-k} (terms involving h[p]) OR i ∈ {q, q-k} or i+k ∈ {q, q-k} (terms involving h[q]).

Terms involving h[p]:
- i=p: h[p]*(1-h[p+k]) → 0. Change: -(1-h_new[p+k])
  - h_new[p+k] = h[p+k] if p+k ≠ q, else 1
- i=p-k: h[p-k]*(1-h[p]) → h[p-k]*(1-0) = h[p-k]. Change: h[p-k] - h[p-k]*(1-1) = h[p-k] - 0 = h[p-k]
  - Wait, old value of this term: h[p-k]*(1-h[p]) = h[p-k]*(1-1) = 0
  - New value: h_new[p-k]*(1-h_new[p]) = h[p-k]*(1-0) = h[p-k] (assuming p-k ≠ q)
  - Change: h[p-k]
  - But if p-k = q: h_new[p-k] = h_new[q] = 1, so new value = 1*(1-0) = 1, change = 1

Terms involving h[q]:
- i=q: h[q]*(1-h[q+k]) → 1*(1-h_new[q+k]). Change: (1-h_new[q+k]) - 0 = 1-h_new[q+k]
  - h_new[q+k] = h[q+k] if q+k ≠ p, else 0
- i=q-k: h[q-k]*(1-h[q]) → h_new[q-k]*(1-1) = 0. Change: 0 - h_old[q-k]*(1-0) = -h[q-k]
  - Old value: h[q-k]*(1-h[q]) = h[q-k]*(1-0) = h[q-k]
  - New value: h_new[q-k]*(1-h_new[q]) = h[q-k]*(1-1) = 0 (assuming q-k ≠ p)
  - Change: -h[q-k]
  - But if q-k = p: h_new[q-k] = h_new[p] = 0, so new value = 0*(0) = 0, change = 0 - 0 = 0. 
    Wait, old value when q-k=p: h[p]*(1-h[q]) = 1*1 = 1. New value: h_new[p]*(1-h_new[q]) = 0*0 = 0. Change: -1.

**Final algorithm plan:**

1. Start from parent, binarize
2. Run simulated annealing with:
   - Swap moves (random 1↔0 swap)
   - "Guided" swaps: preferentially swap 1s that are in "dense" regions with 0s in "sparse" regions (to equalize the correlation)
   - Block moves: swap a contiguous block of 1s with a contiguous block of 0s
   - Adaptive temperature with periodic reheating
3. After SA, do a continuous refinement (allow values in [0,1])
4. Return best solution

Let me also add a "diversity" mechanism: periodically perturb the solution significantly to explore different regions of the search space.

For the continuous refinement, I'll use a simple approach:
- For each coordinate, try values in {0, 0.1, 0.2, ..., 0.9, 1} and pick the best
- Repeat until no improvement

This is faster than SLSQP for this problem.

                h = make_feasible(h, n)

                    h = make_feasible(h, n)
                    h[j] = best_val
                    h = make_feasible(h, n)
                    best_c5 = best_obj
                    improved = True
            if not improved:
                break
    return h, best_c5
