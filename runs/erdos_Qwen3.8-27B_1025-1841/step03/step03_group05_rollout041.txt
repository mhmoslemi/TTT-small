This is like a "swap" operation. The change in corr_k is:

We want to choose δ and (i,j) to minimize this.

For fixed (i,j), the optimal δ minimizes max_k (corr_k + δ * d_k) where d_k = g_k[i] - g_k[j].

This is a 1D problem! We can solve it with a ternary search or by finding the breakpoints.

This is a nice approach. Let me formalize:

Given current h, compute all corr_k and all d_k = g_k[i] - g_k[j].
We want to find δ ∈ [min(0, h[i]), min(1-h[j], -min(0, h[j]-1))] (the feasible range) that minimizes max_k (corr_k + δ * d_k).

This is a piecewise linear function of δ, so the minimum is at a breakpoint (where two corr values are equal).

So: ∂corr_s/∂h[i] = (1-h[i+s])*1[s ≤ n-1-i] - h[i-s]*1[s ≤ i]

For s = 0,...,n-1:
- First term nonzero when s ≤ n-1-i, i.e., i+s ≤ n-1: gives (1-h[i+s])
- Second term nonzero when s ≤ i: gives -h[i-s]

So for the positive shift part (indices n-1 to 2n-2):
result[n-1+s] = (1-h[i+s]) * 1[s ≤ n-1-i] - h[i-s] * 1[s ≤ i] for s=0,...,n-1

That is:
- result[n-1 : n-1+(n-i)] += (1 - h[i : n])  [s goes from 0 to n-1-i, giving h[i], h[i+1], ..., h[n-1]]
  Wait: s goes from 0 to n-1-i, that's n-i values. h[i+s] for s=0,...,n-1-i is h[i], h[i+1], ..., h[n-1].
  
- result[n-1 : n-1+(i+1)] -= h[i], h[i-1], ..., h[0]  [s goes from 0 to i, giving h[i-s] = h[i], h[i-1], ..., h[0]]
  That's h[0:i+1][::-1]

For shift s < 0 (let t = -s, t = 1,...,n-1; idx = n-1-t):
corr_{-t} = sum_{p=t}^{n-1} h[p] * (1-h[p-t])

∂corr_{-t}/∂h[i]:
- h[i] appears in h[p] when p = i: need t ≤ i ≤ n-1, contribution: (1-h[i-t])
- h[i] appears in h[p-t] when p-t = i, p = i+t: need t ≤ i+t ≤ n-1, i.e., 0 ≤ i ≤ n-1-t, contribution: -h[i+t]

So: ∂corr_{-t}/∂h[i] = (1-h[i-t])*1[t ≤ i] - h[i+t]*1[n-1-t ≥ i]

For t = 1,...,n-1:
- First term nonzero when t ≤ i: (1-h[i-t])
- Second term nonzero when i ≤ n-1-t: -h[i+t]

So for the negative shift part (indices 0 to n-2):
result[n-1-t] = (1-h[i-t])*1[t ≤ i] - h[i+t]*1[i ≤ n-1-t] for t=1,...,n-1

- For t = 1 to min(i, n-1): result[n-1-t] += (1-h[i-t])
  t goes from i down to 1: result[n-1-i], result[n-1-(i-1)], ..., result[n-1-1]
  = result[n-1-i : n-1] in reverse order of t
  (1-h[i-t]) for t=i, i-1, ..., 1: (1-h[0]), (1-h[1]), ..., (1-h[i-1])
  = (1 - h[0:i])
  
  Wait: t goes from 1 to i (ascending). n-1-t goes from n-2 down to n-1-i.
  So result[n-1-i : n-1] = (1-h[i-1]), (1-h[i-2]), ..., (1-h[0])? No...
  
  Let me be more careful:
  t=1: result[n-2] gets (1-h[i-1])
  t=2: result[n-3] gets (1-h[i-2])
  ...
  t=i: result[n-1-i] gets (1-h[0])
  
  So result[n-1-i : n-1] = [(1-h[0]), (1-h[1]), ..., (1-h[i-1])]
  = (1 - h[0:i])
  
  Wait no: result[n-1-i] = (1-h[0]), result[n-1-(i-1)] = result[n-i] = (1-h[1]), ..., result[n-2] = (1-h[i-1])
  
  So result[n-1-i : n-1] = [ (1-h[0]), (1-h[1]), ..., (1-h[i-1]) ] = 1 - h[0:i]

- For t = 1 to min(n-1-i, n-1): result[n-1-t] -= h[i+t]
  t=1: result[n-2] gets -h[i+1]
  t=2: result[n-3] gets -h[i+2]
  ...
  t=n-1-i: result[i] gets -h[n-1]
  
  So result[i : n-1] (reversed) = [-h[i+1], -h[i+2], ..., -h[n-1]]
  Which means: result[i : n-1] = [-h[n-1], -h[n-2], ..., -h[i+1]]
  = -h[i+1:n][::-1]

  Actually let me re-index:
  result[n-1-t] -= h[i+t] for t = 1, 2, ..., min(n-1-i, n-1)
  
  Let m = min(n-1-i, n-1) = n-1-i (since i ≥ 0, n-1-i ≤ n-1)
  
  t=1: result[n-2] -= h[i+1]
  t=2: result[n-3] -= h[i+2]
  ...
  t=m: result[n-1-m] = result[i] -= h[i+m] = h[n-1]
  
  So we're subtracting h[i+1], h[i+2], ..., h[n-1] from result[n-2], result[n-3], ..., result[i]
  
  In numpy: result[i:n-1] has entries result[i], result[i+1], ..., result[n-2]
  We want: result[n-2] -= h[i+1], result[n-3] -= h[i+2], ..., result[i] -= h[n-1]
  
  That's result[i:n-1][::-1] -= h[i+1:n]
  Or equivalently: result[i:n-1] -= h[i+1:n][::-1]

Let me rewrite the vectorized _sens:

```python
def _sens(h, i):
    n = len(h)
    result = np.zeros(2*n-1)
    
    # Positive shifts (indices n-1 to 2n-2), s = 0, ..., n-1
    # result[n-1+s] += (1-h[i+s]) for s = 0,..., n-1-i
    nf = n - i  # number of forward terms (s from 0 to n-1-i)
    if nf > 0:
        result[n-1:n-1+nf] += (1.0 - h[i:n])  # h[i], h[i+1], ..., h[n-1]
    
    # result[n-1+s] -= h[i-s] for s = 0,..., i
    nb = i + 1  # number of backward terms
    if nb > 0:
        result[n-1:n-1+nb] -= h[0:i+1][::-1]  # h[i], h[i-1], ..., h[0]
    
    # Negative shifts (indices 0 to n-2), t = 1, ..., n-1
    # result[n-1-t] += (1-h[i-t]) for t = 1,..., min(i, n-1)
    nt = min(i, n-1)
    if nt > 0:
        result[n-1-nt:n-1] += (1.0 - h[0:i])  # (1-h[0]), (1-h[1]), ..., (1-h[i-1])
        # Wait, let me recheck: 
        # t=1: result[n-2] += (1-h[i-1])
        # t=2: result[n-3] += (1-h[i-2])
        # ...
        # t=i: result[n-1-i] += (1-h[0])
        # So result[n-1-i : n-1] = [(1-h[0]), (1-h[1]), ..., (1-h[i-1])]
        # h[0:i] = [h[0], h[1], ..., h[i-1]]
        # 1 - h[0:i] = [(1-h[0]), (1-h[1]), ..., (1-h[i-1])]
        # Yes! result[n-1-nt : n-1] = result[n-1-i : n-1] = 1 - h[0:i] ✓
    
    # result[n-1-t] -= h[i+t] for t = 1,..., min(n-1-i, n-1)
    nt2 = min(n-1-i, n-1)
    if nt2 > 0:
        # t=1: result[n-2] -= h[i+1]
        # t=2: result[n-3] -= h[i+2]
        # ...
        # t=nt2: result[n-1-nt2] = result[i] -= h[i+nt2] = h[n-1]
        # result[i : n-1] should get: -h[n-1], -h[n-2], ..., -h[i+1]
        # That's -h[i+1:n][::-1]
        result[i:n-1] -= h[i+1:i+1+nt2][::-1]
    
    return result
```

Now, the two-coordinate descent:

```python
def two_coord_cd(h0, n_iters, seed=42, check_every=2000):
    n = len(h0)
    dx = 2.0 / n
    h = h0.astype(float).copy()
    rng = np.random.RandomState(seed)
    best_c = compute_c5(h)
    best_h = h.copy()
    
    for it in range(n_iters):
        i, j = rng.randint(n, 2)
        if i == j:
            continue
        
        si = _sens(h, i)
        sj = _sens(h, j)
        d = si - sj
        
        corr = np.correlate(h, 1.0 - h, mode='full')
        
        # Feasible delta range
        d_lo = max(-h[i], h[j] - 1)
        d_hi = min(1 - h[i], h[j])
        if d_lo >= d_hi:
            continue
        
        # Minimize max(corr + delta*d) over delta in [d_lo, d_hi]
        # Ternary search (convex function)
        a, b = d_lo, d_hi
        for _ in range(30):
            m1 = a + (b - a) / 3.0
            m2 = b - (b - a) / 3.0
            f1 = np.max(corr + m1 * d)
            f2 = np.max(corr + m2 * d)
            if f1 > f2:
                a = m1
            else:
                b = m2
        delta = (a + b) / 2.0
        
        if abs(delta) < 1e-10:
            continue
        
        h[i] = np.clip(h[i] + delta, 0, 1)
        h[j] = np.clip(h[j] - delta, 0, 1)
        
        if (it + 1) % check_every == 0:
            c = compute_c5(h)
            if c < best_c:
                best_c = c
                best_h = h.copy()
    
    c = compute_c5(h)
    if c < best_c:
        best_c = c
        best_h = h.copy()
    return best_h, best_c
```

The issue is that `np.correlate(h, 1-h, 'full')` is O(n²) and we call it every iteration. For n=960, that's about 960² = 921600 operations per call, times n_iters. For 50000 iterations: 50000 * 921600 ≈ 4.6 × 10^10. That's too slow!

I need to avoid recomputing the full correlation every iteration. Instead, I should maintain the correlation vector and update it incrementally.

When h[i] changes by δ and h[j] changes by -δ:
Δcorr_k = δ * si[k] - δ * sj[k] = δ * (si[k] - sj[k]) = δ * d[k]

where si, sj are the sensitivity vectors (which we already compute).

So I can maintain corr incrementally:
corr_new = corr + delta * d

But I also need to update d for future iterations (since si and sj depend on h). However, I only compute si and sj for the current (i,j) pair, so I just need to update corr.

Wait, but si and sj are computed FROM h, so after I update h, the next iteration will recompute si and sj from the new h. The issue is just maintaining corr efficiently.

Let me restructure:

```python
def two_coord_cd(h0, n_iters, seed=42, check_every=2000):
    n = len(h0)
    dx = 2.0 / n
    h = h0.astype(float).copy()
    rng = np.random.RandomState(seed)
    corr = np.correlate(h, 1.0 - h, mode='full')  # O(n²) once
    best_c = float(np.max(corr) * dx)
    best_h = h.copy()
    
    for it in range(n_iters):
        i, j = rng.randint(n, 2)
        if i == j:
            continue
        
        si = _sens(h, i)  # O(n)
        sj = _sens(h, j)  # O(n)
        d = si - sj  # O(n)
        
        # Feasible delta range
        d_lo = max(-h[i], h[j] - 1)
        d_hi = min(1 - h[i], h[j])
        if d_lo >= d_hi:
            continue
        
        # Minimize max(corr + delta*d) over delta in [d_lo, d_hi]
        a, b = d_lo, d_hi
        for _ in range(30):
            m1 = a + (b - a) / 3.0
            m2 = b - (b - a) / 3.0
            if np.max(corr + m1 * d) > np.max(corr + m2 * d):
                a = m1
            else:
                b = m2
        delta = (a + b) / 2.0
        
        if abs(delta) < 1e-12:
            continue
        
        h[i] = np.clip(h[i] + delta, 0, 1)
        h[j] = np.clip(h[j] - delta, 0, 1)
        corr += delta * d  # O(n) update
        
        if (it + 1) % check_every == 0:
            # Verify (to catch numerical drift)
            corr_true = np.correlate(h, 1.0 - h, mode='full')
            corr = corr_true  # Reset to true value
            c = float(np.max(corr) * dx)
            if c < best_c:
                best_c = c
                best_h = h.copy()
    
    # Final check
    corr = np.correlate(h, 1.0 - h, mode='full')
    c = float(np.max(corr) * dx)
    if c < best_c:
        best_c = c
        best_h = h.copy()
    return best_h, best_c
```

Now each iteration is O(n) (for _sens and the ternary search), and we do n_iters of them. Total: O(n * n_iters). For n=960 and n_iters=200000: 960 * 200000 = 192M operations. With numpy vectorization, this should take maybe 10-30 seconds. Good.

But wait, the ternary search does 30 iterations of O(n) work (max of a vector of length 2n-1), so it's O(30*n) per coordinate swap. Total: O(n_iters * 30 * n) = 200000 * 30 * 960 ≈ 5.8 × 10^9. That might be too slow in Python.

Let me reduce: n_iters=50000, ternary iterations=20.
50000 * 20 * 1919 (length of corr) ≈ 1.9 × 10^9. Still might be slow.

Actually, `np.max(corr + delta * d)` where corr and d are arrays of length 2n-1=1919. This is a single numpy operation on 1919 elements. In numpy, this takes about 1-2 microseconds. So 30 such operations per iteration = 30-60 microseconds. Times 50000 iterations = 1.5-3 seconds. That's fine!

The _sens function: involves a few numpy operations on subarrays of h (length ≤ n). Each is O(n) but with very small constants. Maybe 5-10 microseconds each. Two calls = 10-20 microseconds per iteration.

Total per iteration: ~50-80 microseconds. Times 50000 = 2.5-4 seconds. 

Let me be a bit more generous: n_iters = 100000 should take about 5-8 seconds. Good.

Now, one concern: the ternary search might not be precise enough. With 20 iterations of ternary search on an interval of length at most 1, we get precision 1/3^20 ≈ 3 × 10^-10. That's more than enough.

Actually, I realize there might be an issue: the function max(corr + delta*d) is convex but piecewise linear. The minimum might be at a "kink" point. Ternary search should still work for convex functions, but it converges by reducing the bracket, not by finding the kink exactly. With 20 iterations, the bracket is very small, so we're fine.

Now let me think about the FISTA part. The previous code's FISTA was:
- Phase A: 5000 iters, T: 50→1, lr=0.14
- Phase B: 5000 iters, T: 2→0.02, lr=0.03
- Final: 2000 iters, T: 2→0.01, lr=0.008

I'll keep similar structure but add:
1. A "very low T" phase: T: 0.1→0.001, lr=0.005, 5000 iters
2. Two-coordinate descent between phases
3. Try at both n=960 and n=1920

Let me also add a "peeling" phase:
- After FISTA, identify the top 5 lags
- For each, do a mini-optimization focused on that lag
- Use a weighted sum: minimize sum_{k in top5} weight_k * corr_k

Actually, the two-coordinate descent should handle this implicitly since it minimizes the max directly.

Let me now write the final code:

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def project_c(h, n):
    target = n / 2.0
    lo, hi = -2.0, 2.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        if np.sum(np.clip(h - mid, 0.0, 1.0)) > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def _grad_shift(h, shift):
    n = len(h)
    s = abs(shift)
    if s >= n:
        return np.zeros(n)
    g = np.zeros(n)
    if shift >= 0:
        g[:n-s] += (1.0 - h[s:])
        g[s:] -= h[:n-s]
    else:
        g[s:] += (1.0 - h[:n-s])
        g[:n-s] -= h[s:]
    return g

def _sens(h, i):
    n = len(h)
    result = np.zeros(2 * n - 1)
    nf = n - i
    if nf > 0:
        result[n-1:n-1+nf] += (1.0 - h[i:n])
    nb = i + 1
    if nb > 0:
        result[n-1:n-1+nb] -= h[0:i+1][::-1]
    nt = min(i, n-1)
    if nt > 0:
        result[n-1-nt:n-1] += (1.0 - h[0:i])
    nt2 = min(n-1-i, n-1)
    if nt2 > 0:
        result[i:n-1] -= h[i+1:i+1+nt2][::-1]
    return result

def fista(h0, n_iter, T_start, T_end, lr0, check_interval=50):
    n = len(h0)
    dx = 2.0 / n
    x = h0.astype(float).copy()
    z = x.copy()
    tk = 1.0
    corr_z = np.correlate(z, 1.0 - z, mode='full')
    best_c = float(np.max(corr_z) * dx)
    best_h = x.copy()
    
    for it in range(n_iter):
        f = it / max(n_iter - 1, 1)
        T = T_start * (T_end / T_start) ** f
        lr = lr0 * (1.0 - 0.5 * f)
        
        mc = np.max(corr_z)
        exps = np.exp(T * (corr_z - mc))
        tot = np.sum(exps)
        if tot < 1e-300:
            top_idx = int(np.argmax(corr_z))
            g = _grad_shift(z, top_idx - (n-1)) * dx
        else:
            w = exps / tot
            k_top = min(20, len(w))
            idx = np.argsort(w)[::-1][:k_top]
            g = np.zeros(n)
            for ii in idx:
                wi = w[ii]
                if wi < 1e-12:
                    break
                g += wi * _grad_shift(z, ii - (n-1))
            g *= dx
        
        x_new = project_c(z - lr * g, n)
        tn = (1.0 + np.sqrt(1.0 + 4.0 * tk * tk)) / 2.0
        z = x_new + (tk - 1.0) / tn * (x_new - x)
        np.clip(z, -0.5, 1.5, out=z)
        x = x_new
        tk = tn
        corr_z = np.correlate(z, 1.0 - z, mode='full')
        
        if (it + 1) % check_interval == 0:
            c = float(np.max(np.correlate(x, 1.0 - x, mode='full')) * dx)
            if c < best_c:
                best_c = c
                best_h = x.copy()
    
    c = float(np.max(np.correlate(x, 1.0 - x, mode='full')) * dx)
    if c < best_c:
        best_c = c
        best_h = x.copy()
    return best_h, best_c

def two_coord_cd(h0, n_iters, seed=42, check_every=5000):
    n = len(h0)
    dx = 2.0 / n
    h = h0.astype(float).copy()
    rng = np.random.RandomState(seed)
    corr = np.correlate(h, 1.0 - h, mode='full')
    best_c = float(np.max(corr) * dx)
    best_h = h.copy()
    
    for it in range(n_iters):
        i, j = rng.randint(n, 2)
        if i == j:
            continue
        
        d = _sens(h, i) - _sens(h, j)
        
        d_lo = max(-h[i], h[j] - 1.0)
        d_hi = min(1.0 - h[i], h[j])
        if d_lo >= d_hi - 1e-12:
            continue
        
        a, b = d_lo, d_hi
        for _ in range(25):
            m1 = a + (b - a) * 0.3333
            m2 = b - (b - a) * 0.3333
            if np.max(corr + m1 * d) > np.max(corr + m2 * d):
                a = m1
            else:
                b = m2
        delta = 0.5 * (a + b)
        
        if abs(delta) < 1e-10:
            continue
        
        h[i] = np.clip(h[i] + delta, 0.0, 1.0)
        h[j] = np.clip(h[j] - delta, 0.0, 1.0)
        corr += delta * d
        
        if (it + 1) % check_every == 0:
            corr = np.correlate(h, 1.0 - h, mode='full')
            c = float(np.max(corr) * dx)
            if c < best_c:
                best_c = c
                best_h = h.copy()
    
    corr = np.correlate(h, 1.0 - h, mode='full')
    c = float(np.max(corr) * dx)
    if c < best_c:
        best_
