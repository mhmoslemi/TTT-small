Actually, I realize I need to be more careful. Let me think about what optimization method to use.

The objective is f(h) = max_k c_k(h) * dx, where c_k(h) is a quadratic function of h. This is a non-convex problem.

For a practical approach:
1. Use the "max trick": minimize t subject to c_k(h)*dx ≤ t for all k, 0≤h≤1, sum h = N/2.
   - This is a QP (quadratically constrained program) - not directly solvable by standard solvers.
   - But we can iterate: for a given t, check feasibility; or for a given h, compute the active constraints.

2. Alternatively, use gradient methods on the smoothed objective.

Let me go with approach 2: projected gradient with softmax smoothing.

The key is to make the gradient computation efficient. For N=42, even computing all gradients with a loop is fine.

Let me also think about what random starting points to try. The problem has symmetries:

Wait, if h has integral 1, then 1-h(2-x) also has integral 2-1=1. And the correlation of (1-h(2-x)) with h(2-x) is the same as correlation of h with 1-h (just at negated lags). So C₅ is invariant under h → 1-h(2-x).

This means we can WLOG assume h(0) ≥ 0.5 or something.

For the gradient, let me use the finite difference approach for simplicity (N=42 is small):
- Compute f(h)
- For each i, compute f(h + ε*e_i) - f(h) / ε
- This gives the gradient

But this is O(N) function evaluations per gradient step, and each function evaluation is O(N²) for the correlation. So O(N³) per step. For N=42, that's about 74,000 operations per step, which is nothing.

Actually, let me use the analytical gradient. It's not that hard:

For the k-th lag correlation:
c_k = sum_{j ∈ J_k} h[j] * (1 - h[j+k])

where J_k = {j : 0 ≤ j < N, 0 ≤ j+k < N}

dc_k/dh[i] = sum_{j ∈ J_k} [δ(j,i) * (1-h[j+k]) - h[j] * δ(j+k, i)]
= (1-h[i+k]) * [i ∈ J_k] - h[i-k] * [i-k ∈ J_k]

So for the smoothed objective f_ε = ε * ln(sum exp(c_k/ε)):
df_ε/dh[i] = sum_k p_k * (dc_k/dh[i]) / 1  (where p_k = exp(c_k/ε)/sum_j exp(c_j/ε))
= sum_k p_k * [(1-h[i+k])*[i∈J_k] - h[i-k]*[i-k∈J_k]]

This is O(N * N) = O(N²) to compute, which is fine.

Let me code this up properly:

```python
def compute_corr_array(h, N):
```

For the gradient, I'll compute it for each active lag:

```python
def compute_gradient(h, N, eps=0.01):
    dx = 2.0 / N
    correlation = np.correlate(h, 1-h, mode='full') * dx
    # Softmax weights
    max_c = np.max(correlation)
    exp_c = np.exp((correlation - max_c) / eps)
    weights = exp_c / np.sum(exp_c)  # length 2N-1
    
    grad = np.zeros(N)
    for idx in range(2*N-1):
        w = weights[idx]
        if w < 1e-10:
            continue
        lag = idx - (N-1)
        # J = {j : max(0,-lag) <= j < min(N, N-lag)}
        j_min = max(0, -lag)
        j_max = min(N, N - lag)
        for j in range(j_min, j_max):
            # dc/dh[j] += w * (1 - h[j+lag])
            # dc/dh[j+lag] -= w * h[j]
            grad[j] += w * (1 - h[j+lag])
            if lag != 0:
                grad[j+lag] -= w * h[j]
            else:
                # For lag=0: dc/dh[j] = 1 - 2h[j]
                # Already added (1-h[j]) to grad[j], need to subtract another h[j]
                grad[j] -= w * h[j]
    
    return grad  # already includes dx factor from correlation
```

df/dh[i] = sum_k p_k * dx * (dc_k/dh[i])

Now let me think about the optimization algorithm:
1. Start with h (feasible)
2. Compute gradient
3. Update: h_new = h - alpha * grad
4. Project to feasible set: clip to [0,1], adjust sum to N/2
5. Adaptive step size (backtracking)
6. Repeat

The projection is the tricky part. After clipping and scaling, we need to ensure both 0≤h≤1 AND sum(h)=N/2.

A simple projection:
1. h = h - alpha * grad
2. h = clip(h, 0, 1)
3. If sum(h) != N/2, scale: h = h * (N/2) / sum(h), then clip again
4. If still not exact, do a water-filling adjustment

Actually, for exact constraint satisfaction, I'll use a bisection approach:
- Find λ such that sum(clip(h - alpha*grad + λ, 0, 1)) = N/2
- This is a 1D problem in λ, solvable by bisection

Let me implement this properly.

```python
def project_feasible(x, N):
    """Project x onto {h : 0<=h<=1, sum(h)=N/2} using bisection on shift."""
    target = N / 2.0
    # Find shift s such that sum(clip(x + s, 0, 1)) = target
    # sum(clip(x+s, 0, 1)) is monotonically increasing in s
    
    lo = -1.0 - np.max(x)
    hi = 1.0 - np.min(x)
    
    for _ in range(100):
        mid = (lo + hi) / 2
        s = np.sum(np.clip(x + mid, 0, 1))
        if s < target:
            lo = mid
        else:
            hi = mid
    
    h = np.clip(x + (lo + hi) / 2, 0, 1)
    # Verify
    # sum(h) should be very close to target
    return h
```

This should work well. The bisection converges in about 60 iterations for machine precision.

For the step size, I'll use a simple backtracking line search:
- Start with alpha = 0.01
- If f decreases, increase alpha
- If f increases, decrease alpha

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, dx):
    v = 1.0 - h
    corr = np.correlate(h, v, mode='full') * dx
    return np.max(corr)

def project_feasible(x, N):
    target = N / 2.0
    lo = -1.0 - np.max(x)
    hi = 1.0 - np.min(x)
    for _ in range(80):
        mid = (lo + hi) / 2
        s = np.sum(np.clip(x + mid, 0, 1))
        if s < target:
            lo = mid
        else:
            hi = mid
    h = np.clip(x + (lo + hi) / 2, 0, 1)
    return h

def smoothed_objective(h, N, eps=0.005):
    dx = 2.0 / N
    v = 1.0 - h
    corr = np.correlate(h, v, mode='full') * dx
    return eps * np.log(np.sum(np.exp((corr - np.max(corr)) / eps)))

def smoothed_gradient(h, N, eps=0.005):
    dx = 2.0 / N
    v = 1.0 - h
    corr = np.correlate(h, v, mode='full') * dx
    max_c = np.max(corr)
    exp_c = np.exp((corr - max_c) / eps)
    weights = exp_c / np.sum(exp_c)
    
    grad = np.zeros(N)
    for idx in range(2 * N - 1):
        w = weights[idx]
        if w < 1e-10:
            continue
        lag = idx - (N - 1)
        j_min = max(0, -lag)
        j_max = min(N, N - lag)
        for j in range(j_min, j_max):
            if lag == 0:
                grad[j] += w * dx * (1.0 - 2.0 * h[j])
            else:
                grad[j] += w * dx * (1.0 - h[j + lag])
                grad[j + lag] -= w * dx * h[j]
    return grad

def projected_gradient_descent(h, N, rng, max_iter=5000, eps_start=0.01, eps_min=0.001, time_limit=200):
    """PJGD with adaptive eps and step size."""
    start = time.time()
    h = h.copy()
    best_h = h.copy()
    best_f = smoothed_objective(h, N, eps_start)
    alpha = 0.05
    eps = eps_start
    
    for it in range(max_iter):
        if time.time() - start > time_limit:
            break
        
        # Anualge eps
        eps = max(eps_min, eps_start * (0.995 ** it))
        
        g = smoothed_gradient(h, N, eps)
        
        # Gradient step
        h_new = project_feasible(h - alpha * g, N)
        
        f_new = smoothed_objective(h_new, N, eps)
        
        if f_new < best_f:
            best_f = f_new
            best_h = h_new.copy()
        
        # Adaptive step size
        if f_new < smoothed_objective(h, N, eps) + 1e-10:
            h = h_new
            alpha = min(alpha * 1.1, 0.5)
        else:
            alpha *= 0.7
            # Try again with smaller alpha
            h_new = project_feasible(h - alpha * g, N)
            f_new = smoothed_objective(h_new, N, eps)
            if f_new < smoothed_objective(h, N, eps) + 1e-10:
                h = h_new
            else:
                h = h_new  # accept anyway to make progress
                alpha *= 0.8
        
        # Periodically check actual objective
        if it % 100 == 0:
            actual_f = compute_c5(h, 2.0/N)
            if actual_f < compute_c5(best_h, 2.0/N):
                best_h = h.copy()
    
    return best_h, compute_c5(best_h, 2.0/N)

def upsample(h, new_N):
    """Upsample h from len(h) to new_N using linear interpolation."""
    old_N = len(h)
    if new_N <= old_N:
        return h[:new_N].copy()
    x_old = np.linspace(0, 2, old_N, endpoint=False)
    x_new = np.linspace(0, 2, new_N, endpoint=False)
    return np.interp(x_new, x_old, h)

def run(seed=42, budget_s=1300, **kwargs):
    start_time = time.time()
    rng = np.random.RandomState(seed)
    
    # Get initial values
    global initial_h_values
    if 'initial_h_values' in globals() and initial_h_values is not None:
        h_init = np.array(initial_h_values, dtype=float)
    else:
        N_init = 42
        h_init = np.full(N_init, 0.5)
    
    N_init = len(h_init)
    h_init = project_feasible(h_init, N_init)
    
    best_h = h_init.copy()
    best_c5 = compute_c5(h_init, 2.0 / N_init)
    
    # Phase 1: Optimize at initial resolution
    time_left = budget_s - (time.time() - start_time)
    h_opt, c5_opt = projected_gradient_descent(
        h_init, N_init, rng, 
        max_iter=10000, time_limit=max(50, int(time_left * 0.25))
    )
    if c5_opt < best_c5:
        best_h = h_opt
        best_c5 = c5_opt
    
    # Phase 2: Try multiple random restarts at same N
    elapsed = time.time() - start_time
    time_left = budget_s - elapsed
    for restart in range(5):
        if time_left < 30:
            break
        # Generate diverse starting points
        h_rand = generate_random_h(N_init, rng)
        h_rand = project_feasible(h_rand, N_init)
        
        t_alloc = int(time_left * 0.15)
        h_opt, c5_opt = projected_gradient_descent(
            h_rand, N_init, rng,
            max_iter=5000, time_limit=t_alloc
        )
        if c5_opt < best_c5:
            best_h = h_opt
            best_c5 = c5_opt
        
        elapsed = time.time() - start_time
        time_left = budget_s - elapsed
    
    # Phase 3: Try higher resolutions
    elapsed = time.time() - start_time
    time_left = budget_s - elapsed
    for N_new in [84, 126, 168, 210]:
        if time_left < 60:
            break
        h_up = project_feasible(upsample(best_h, N_new), N_new)
        t_alloc = int(time_left * 0.4)
        h_opt, c5_opt = projected_gradient_descent(
            h_up, N_new, rng,

        )
        if c5_opt < best_c5:
            best_h = h_opt
            best_c5 = c5_opt

        time_left = budget_s - elapsed
    
    # Final verification
    best_h = project_feasible(best_h, len(best_h))
    best_c5 = compute_c5(best_h, 2.0 / len(best_h))
    
    return best_h, best_c5, len(best_h)

def generate_random_h(N, rng):
    """Generate a random feasible h."""
    # Random: a mix of block-like and smooth patterns
    strategy = rng.randint(4)
    if strategy == 0:
        # Smooth: h = sigmoid of random polynomial
        x = np.linspace(0, 2, N)
        a = rng.uniform(-2, 2)
        b = rng.uniform(-2, 2)
        c = rng.uniform(-2, 2)
        h = 1.0 / (1.0 + np.exp(-(a * x + b * x**2 + c)))
    elif strategy == 1:
        # Block: 1 in a random interval
        a = rng.uniform(0, 1)
        h = (x_ := np.linspace(0, 2, N) >= a) & (np.linspace(0, 2, N) <= a + 1)
        h = h.astype(float)
    elif strategy == 2:
        # Two blocks
        h = np.zeros(N)
        for _ in range(2):
            a = rng.uniform(0, 1.5)
            b = rng.uniform(a, min(a+0.5, 2))
            for i, x in enumerate(np.linspace(0, 2, N)):
                if a <= x <= b:
                    h[i] = 1.0
    else:
        # Random with smoothing
        h = rng.uniform(0, 1, N)
        # Smooth
        kernel = np.ones(5) / 5
        h = np.convolve(h, kernel, mode='same')
        h = np.clip(h, 0, 1)
```

```python
    return eps * np.log(np.sum(np.exp((corr - np.max(corr)) / eps))) + np.max(corr)

def _smoothed_grad(h, N, eps):
    dx = 2.0 / N
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    max_c = np.max(corr)
    exp_c = np.exp((corr - max_c) / eps)
    w = exp_c / np.sum(exp_c)
    
    grad = np.zeros(N)
    for idx in range(2 * N - 1):
        wi = w[idx]
        if wi < 1e-12:
            continue
        lag = idx - (N - 1)
        jlo = max(0, -lag)
        jhi = min(N, N - lag)
        if lag == 0:
            for j in range(jlo, jhi):
                grad[j] += wi * dx * (1.0 - 2.0 * h[j])
        else:

                grad[j] += wi * dx * (1.0 - h[j + lag])
```
