Wait, one more thought: the `evaluate_c5` function uses `np.correlate(h, 1-h, mode='full')`. The maximum of this (times dx) is C₅. But I should make sure that the correlation convention matches what we want.

np.correlate(a, v, mode='full') computes c[k] = Σ_n a[n+k] * conj(v[n])
For a = h, v = 1-h: c[k] = Σ_n h[n+k] * (1-h[n])

The "shift" k corresponds to: h is shifted by k positions to the left relative to (1-h).
In the continuous limit, this is ∫ h(x+k) * (1-h(x)) dx, which is the overlap of h shifted by k with (1-h).

    """Compute subgradient of correlation at lag k (numpy convention: k in [-(n-1), n-1])"""
    n = len(h)
    grad = np.zeros(n)
    if k >= 0:
        # First term: (1-h[j-k]) for j=k..n-1
        grad[k:] += (1.0 - h[:n-k])

        # Second term: -h[j-k_neg] for j=k_neg..n-1
        grad[k_neg:] -= h[:n-k_neg]
    return grad

        if c5 < best_c5:
            best_c5 = c5
            best_h = h_polish.copy()

    # Final subgradient refinement
    if time.time() < deadline - 5:
        h_final = subgradient_method(best_h, 50, deadline, n_worst=2, base_lr=0.2)
        c5 = evaluate_c5(h_final)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h_final.copy()

    best_c5 = evaluate_c5(best_h)
    best_h = project_feasible(best_h, len(best_h))
    best_c5 = evaluate_c5(best_h)
    return (best_h, best_c5, len(best_h))
