Total change for 2-flip (i: 1→0, j: 0→1):
Δc[k] = Δc_flip1to0[i,k] + Δc_flip0to1[j,k]

This is O(n) per move (iterate over all k).

def slsqp_optimize(h0, n, dx, maxiter=300):
    target = n / 2.0
    def obj(x):
        return np.max(np.correlate(x, 1 - x, mode='full')) * dx
