Actually, for the greedy phase, I can compute the change in correlation more efficiently. When I swap position a (1→0) with b (0→1), the new h differs from old h only at positions a and b. The correlation changes only at lags involving a or b.

correlate(h, 1-h) at lag k = sum_i h[i] * (1-h[i+k])

After swap:
- h[a] goes from 1 to 0
- h[b] goes from 0 to 1
- (1-h)[a] goes from 0 to 1
- (1-h)[b] goes from 1 to 0

The change in correlation at lag k:
- Terms involving h[a]: was h[a]*(1-h[a+k]) = 1*(1-h[a+k]), now 0. Change: -(1-h[a+k])
- Terms involving (1-h) at position a as the "shifted" value: this is when i+k = a, i.e., i = a-k. Term was h[a-k]*(1-h[a]) = h[a-k]*0 = 0, now h[a-k]*1. Change: +h[a-k]
- Terms involving h[b]: was 0, now 1*(1-h[b+k]). Change: +(1-h[b+k])
- Terms involving (1-h) at position b: i+k = b, i = b-k. Was h[b-k]*1, now h[b-k]*0. Change: -h[b-k]

So the change at lag k:
Δ(k) = -(1-h[a+k]) + h[a-k] + (1-h[b+k]) - h[b-k]
(with terms only present if the indices are valid, i.e., 0 ≤ index < n)

This is O(1) per lag! And we only need to check if the max changes.
