    # Second term: sum_i h[i+s]*h[i]
    #   Let j = i: term is h[j+s]*h[j] for j in valid range
    #   Gradient w.r.t. h[j]: h[j+s] + h[j-s] (from the two positions where h[j] appears)
    #   Wait: sum_i h[i+s]*h[i]. If we differentiate w.r.t. h[j]:
    #   - h[j] appears as h[i] when i=j: contributes h[j+s] (if j+s < n and j is valid i)
    #   - h[j] appears as h[i+s] when i+s=j, i=j-s: contributes h[j-s] (if j-s >= 0 and j-s is valid i)

    # Cleanest approach: for each shift s, compute the gradient as:
    # grad_s = zeros(n)
    # valid_i = range from max(0,-s) to min(n-1, n-1-s)

    #   grad_s[i]   -= h[i+s]    # from d/dh[i] of h[i+s]*(1-h[i])

    # grad = sum_k p_k * grad_k * dx

    # valid i: i_lo = max(0, -s), i_hi = min(n-1, n-1-s)
    # grad_s[i+s] += (1-h[i]) for i in [i_lo, i_hi]

    #   indices_b = i_lo to i_hi (these get -= h[i_lo+s:i_hi+s+1])

    #   Combined: 0 <= j <= n-1+s (which is < n+s since n-1 < n-1)
    #   Wait: n-1+s < n+s always. And we need j <= n-1+s AND j < n+s. Since n-1+s < n-s (for s<0, -1 < -s so n-1+s < n+s), the binding constraint is j <= n-1+s.

    #     Wait: for s = j-(n-1), j-s = n-1 ✓. For s = -1, j-s = j+1. Need j+1 <= n-1, i.e., j <= n-2.
    #     So the upper limit should be min(-1, -(n-1-j)) = min(-1, j-(n-1)+... hmm
    #     Let me just say: for s < 0, valid range is s from max(-(n-1), j-(n-1)) to min(-1, -(n-1-j)) = min(-1, j-(n-1))... 
    #     This is getting too complicated for a hand derivation. Let me just do it numerically.

    # I'll compute the gradient by iterating over shifts.
    
    grad = np.zeros(n)
    for s in range(-(n-1), n):
        k = s + n - 1
        pk = p[k]
        if pk < 1e-15:
            continue
        i_lo = max(0, -s)
        i_hi = min(n-1, n-1-s)
        if i_lo > i_hi:
            continue
        i_range = np.arange(i_lo, i_hi+1)
        # grad[i+s] += (1-h[i]) * pk
        idx_a = i_range + s
        grad[idx_a] += (1.0 - h[i_range]) * pk
        # grad[i] -= h[i+s] * pk
        idx_b = i_range
        grad[idx_b] -= h[i_range + s] * pk
    
    grad *= dx
    return smooth_val, grad
