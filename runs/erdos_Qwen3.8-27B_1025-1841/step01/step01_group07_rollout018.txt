    diff = target - np.sum(h)

                h += diff * room / total_room
            else:
                h += diff / n
        else:
            h += diff / n
        h = np.clip(h, 0.0, 1.0)
    return h

Alternative: use a direct "subgradient" approach.

The objective is max_k f_k(h) where f_k(h) = sum_i h[i]*(1-h[i+k]) (times dx).

The subdifferential of max is the convex hull of the gradients of the active functions. So the subgradient is a convex combination of the gradients of the active (near-max) lags.

For each active lag k, the gradient of f_k with respect to h[j] is:
∂f_k/∂h[j] = (1-h[j+k]) * I(j+k valid) - h[j-k] * I(j-k valid)

where I(·) is an indicator.

Actually, let me be more careful. For lag k (positive, meaning we compute sum_{i=0}^{n-1-k} h[i]*(1-h[i+k])):

∂/∂h[j] of sum_{i=0}^{n-1-k} h[i]*(1-h[i+k]):
- Term where j=i: (1-h[j+k]) if j+k ≤ n-1, i.e., j ≤ n-1-k
- Term where j=i+k: -h[j-k] if j-k ≥ 0 and j-k ≤ n-1-k, i.e., 0 ≤ j-k ≤ n-1-k, i.e., k ≤ j ≤ n-1

So: ∂f_k/∂h[j] = (1-h[j+k]) * I(j ≤ n-1-k) - h[j-k] * I(k ≤ j ≤ n-1)

(For positive k. For negative k, similar with signs flipped.)

Let me verify: for k=1, j=0:
∂f_1/∂h[0] = (1-h[1]) - 0 (since j=0 < k=1, the second term doesn't apply)
This makes sense: h[0] appears only as the first factor in h[0]*(1-h[1]).

For k=1, j=1:
∂f_1/∂h[1] = (1-h[2]) - h[0]
h[1] appears as first factor in h[1]*(1-h[2]) and as second factor in h[0]*(1-h[1]).

For k=1, j=n-1:
∂f_1/∂h[n-1] = 0 - h[n-2]
h[n-1] only appears as the second factor in h[n-2]*(1-h[n-1]).

This looks right.
