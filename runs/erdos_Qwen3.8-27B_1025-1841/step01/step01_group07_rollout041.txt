Actually, I think the key insight is: for the Hadamard sequence, the circular cross-correlation with (1-h) at non-zero lags is:
sum_{i=0}^{N-1} h[(i+k) mod N] * (1-h[i])

For a Hadamard row (mapped to 0-1), this equals:
(N/2) - sum_{i=0}^{N-1} h[(i+k) mod N] * h[i]

The circular autocorrelation sum = 0 for non-zero k (by orthogonality of Hadamard rows to the all-ones row... wait, no. The autocorrelation of a single row is not necessarily 0.

Actually, for a Hadamard matrix H, the rows are orthogonal: H H^T = N I. So row_i · row_j = 0 for i ≠ j, and row_i · row_i = N.

The autocorrelation of row r at lag k (circular) is:
sum_i r[i] * r[(i+k) mod N]

This is NOT the same as r · (shifted r), which would be 0 only if shifted r is a different row. In general, the circular autocorrelation of a Hadamard row is NOT zero at all non-zero lags.

For example, the 4-point Hadamard row [1,-1,1,-1]:
At lag 1: 1*(-1) + (-1)*1 + 1*(-1) + (-1)*1 = -4
At lag 2: 1*1 + (-1)*(-1) + 1*1 + (-1)*(-1) = 4
At lag 3: 1*(-1) + (-1)*1 + 1*(-1) + (-1)*1 = -4

So the circular autocorrelation is -4, 4, -4 at lags 1, 2, 3. Not zero!

I was confusing this with the cross-correlation between DIFFERENT rows (which IS zero).

So Hadamard rows don't have zero autocorrelation. They have zero CROSS-correlation between different rows.
