Now, to find the optimal v ∈ [0,1] that minimizes max_d (A_d * v + B_d):
This is a 1D convex optimization. The function f(v) = max_d (A_d * v + B_d) is convex and piecewise linear.

The minimum of a convex piecewise-linear function on [0,1] is at a point where:
- The left slope ≤ 0 and the right slope ≥ 0 (i.e., 0 is in the subgradient)
- Or at a boundary (v=0 or v=1)

The slopes of the active pieces are A_d. So we need:
- min_{d: active} A_d ≤ 0 and max_{d: active} A_d ≥ 0

A practical approach:
1. Evaluate f(0) and f(1)
2. Find the d that maximizes A_d * 0 + B_d = B_d → d* for v=0
3. Find the d that maximizes A_d * 1 + B_d → d* for v=1
4. The breakpoints are where A_d1 * v + B_d1 = A_d2 * v + B_d2 → v = (B_d2 - B_d1)/(A_d1 - A_d2)
5. Find the minimum over all breakpoints in [0,1] and the boundaries.

But step 4 could involve O(n^2) pairs. However, since we only need the MAX (upper envelope), we can use a more efficient method.

Actually, the upper envelope of n lines in 1D can be computed in O(n log n) time (using the fact that the upper envelope of lines is a convex piecewise-linear function, and its breakpoints can be found via a convex hull trick or by sorting).

But for n=80, even O(n^2) = 6400 operations per coordinate is fine. Total: 80 * 6400 = 512K per pass, which is very fast.

```python
def find_optimal_v(A, B, n):
    """Find v in [0,1] that minimizes max_i (A[i]*v + B[i])"""
    # Evaluate at boundaries
    f0 = np.max(B)  # v=0
    f1 = np.max(A + B)  # v=1
    
    # Find breakpoints: for each pair (i,j), v = (B[j]-B[i])/(A[i]-A[j])
    # But we only need breakpoints that are on the upper envelope
    # Simpler: just check all O(n^2) breakpoints
    
    best_f = min(f0, f1)
    best_v = 0.0 if f0 < f1 else 1.0
    
    # For each pair with A[i] != A[j], compute intersection
    for i in range(n):
        for j in range(i+1, n):
            if abs(A[i] - A[j]) < 1e-15:
                continue
            v = (B[j] - B[i]) / (A[i] - A[j])
            if 0.0 < v < 1.0:
                # Check if this is actually on the upper envelope
                # (i.e., both lines i and j are maximal at this v)
                f_i = A[i] * v + B[i]
                f_j = A[j] * v + B[j]
                if abs(f_i - f_j) < 1e-10:
                    # Verify it's on the upper envelope
                    f_all = np.max(A * v + B)
                    if abs(f_i - f_all) < 1e-10:
                        if f_i < best_f:
                            best_f = f_i
                            best_v = v
    
    return best_v, best_f
```

Actually, I just realized something important. Let me re-examine the objective.

The problem states: C₅ = max_k ∫ h(x)(1 - h(x+k)) dx

And the evaluation is: max(np.correlate(h, 1-h, mode="full") * dx)

But wait, ∫₀² h(x)(1-h(x+k)) dx is NOT the same as the correlation in general! The correlation np.correlate(h, 1-h, 'full') gives the sum of products over the overlapping region, which when multiplied by dx gives an approximation to the integral.

For a shift of k*dx:
∫₀² h(x)(1-h(x+k*dx)) dx

This integral is over [0,2] but h(x+k*dx) is only defined for x+k*dx ∈ [0,2], i.e., x ∈ [-k*dx, 2-k*dx]. So the effective integral is over [max(0, -k*dx), min(2, 2-k*dx)].

The correlation np.correlate(h, 1-h, 'full')[k'] where k' = k + (n-1) gives:
sum_{i: valid} h[i] * (1-h[i-k]) * dx

which approximates the integral over the valid range. So yes, the evaluation is correct.

Now, an important observation: for the "central" lags (small |k|), the valid range is almost all of [0,2], so the integral is close to ∫₀² h(x)(1-h(x+k*dx)) dx. For edge lags (large |k|), the valid range is small, so the contribution is small.

The maximum will typically be at a central lag (small |k|), since the valid range is largest there.

def compute_c5(h, dx):
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    return np.max(corr)

def project_sum(h, target):
    """Project h onto {x: sum(x)=target, 0<=x<=1}"""
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.clip(h - mid, 0.0, 1.0).sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def binarize(h, n):
    """Round h to binary while maintaining sum = n/2"""
    target = n // 2
    h_bin = (h >= 0.5).astype(float)
    n_ones = int(h_bin.sum())
    if n_ones > target:
        # Flip the smallest h values that are 1
        ones = np.where(h_bin == 1)[0]
        h_ones = h[ones]
        order = np.argsort(h_ones)
        for i in range(n_ones - target):
            h_bin[ones[order[i]]] = 0
    elif n_ones < target:
        zeros = np.where(h_bin == 0)[0]
        h_zeros = h[zeros]
        order = np.argsort(-h_zeros)
        for i in range(target - n_ones):
            h_bin[zeros[order[i]]] = 1
    return h_bin
