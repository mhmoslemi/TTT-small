∂corr[k]/∂x[j]:

Contribution: -x[j+k-(n-1)]

These are exactly what I computed before. 

Now, the key insight: I can compute the gradient in O(n) using 3 np.correlate calls (each O(n) for these sizes). Then I can use SLSQP or L-BFGS-B with analytical gradients.

But SLSQP also needs to handle the equality constraint Σx = n/2. With analytical gradient, SLSQP should be faster.

Let me also consider: instead of SLSQP, I can use a **projected gradient method**:
1. Compute gradient g
2. h_new = h - α * g
3. Project h_new onto {0≤x≤1, Σx=n/2} (water-filling)
4. Adjust α by backtracking

The projection onto the simplex-with-boxes (0≤x≤1, Σx=n/2) can be done efficiently.

Actually, for the equality constraint Σx = n/2 with box [0,1], the projection is:
- Start with y = h - α*g
- Find λ such that Σ clip(y_i - λ, 0, 1) = n/2
- This is a 1D problem solvable by bisection

This is clean and fast. Let me implement this.

3. Periodically (every 50 iterations), do a coordinate descent pass with golden section search
4. Final polish: SLSQP with analytical gradient and T=5000

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_feasible(h, n):
    h = np.clip(h.astype(float).copy(), 0.0, 1.0)
    target = n / 2.0
    for _ in range(50):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0
            if not np.any(mask):
                break
            h[mask] += diff / np.sum(mask)
        else:
            mask = h > 0.0
            if not np.any(mask):
                break
            h[mask] += diff / np.sum(mask)
        h = np.clip(h, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-13:
        if diff > 0:
            idx = int(np.argmin(h))
        else:
            idx = int(np.argmax(h))
        h[idx] = np.clip(h[idx] + diff, 0, 1)
    return h

def project_simplex_box(y, n):
    """Project y onto {0<=x<=1, sum(x)=n/2}"""
    target = n / 2.0
    # Water-filling: find lambda such that sum(clip(y_i - lambda, 0, 1)) = target
    # clip(y_i - lambda, 0, 1) is:
    #   0 if y_i - lambda < 0, i.e., lambda > y_i
    #   1 if y_i - lambda > 1, i.e., lambda < y_i - 1
    #   y_i - lambda otherwise
    # Sort y
    y_sorted = np.sort(y)[::-1]  # descending
    # Binary search on lambda
    lo = y_sorted[-1] - 1.0 - 1e-10
    hi = y_sorted[0] + 1e-10
    
    def sum_clipped(lam):
        return np.sum(np.clip(y - lam, 0.0, 1.0))
    
    # Bisection
    for _ in range(60):
        mid = (lo + hi) / 2.0
        s = sum_clipped(mid)
        if s > target:
            lo = mid  # need larger lambda to reduce sum
        else:
            hi = mid
    lam = (lo + hi) / 2.0
    return np.clip(y - lam, 0.0, 1.0)

def softmax_obj_grad(h, T):
    """Compute softmax-approximated objective and analytical gradient."""
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    mc = np.max(corr)
    shifted = corr - mc
    exp_shifted = np.exp(T * shifted)
    exp_sum = np.sum(exp_shifted)
    obj = (mc + np.log(exp_sum) / T) * dx
    
    # Softmax weights
    p = exp_shifted / exp_sum  # length 2n-1
    
    # Gradient computation using correlations
    p_rev = p[::-1]
    ones = np.ones(n)
    
    # grad[j] = dx * (corr1[2n-2-j] - corr2[2n-2-j] - corr3[2n-2-j])
    # where:
    # corr1 = np.correlate(p_rev, 1-h, mode='full')  -> gives sum_t p[j-t+n-1]*(1-h[t])
    # corr2 = np.correlate(p_rev, h, mode='full')    -> gives sum_t p[j-t+n-1]*h[t]
    # corr3 = np.correlate(p, h, mode='full')        -> gives sum_t p[t-j+n-1]*h[t]
    
    c1 = np.correlate(p_rev, 1.0 - h, mode='full')
    c2 = np.correlate(p_rev, h, mode='full')
    c3 = np.correlate(p, h, mode='full')
    
    idx = 2 * n - 2  # we need c[2n-2-j] for j=0,...,n-1
    
    # We need indices [2n-2, 2n-3, ..., 2n-2-(n-1)] = [2n-2, 2n-3, ..., n-1]
    idx_range = np.arange(2 * n - 2, n - 2, -1)  # 2n-2, 2n-3, ..., n-1
    
    grad = dx * (c1[idx_range] - c2[idx_range] - c3[idx_range])
    
    return obj, grad
