**New idea: Dual approach (Lagrangian relaxation)**

Consider the problem:
minimize max_k c[k]
subject to sum(h) = n/2, 0 ≤ h ≤ 1

The Lagrangian dual (for the max) introduces variables λ_k ≥ 0 with sum(λ) = 1:
minimize sum_k λ_k * c[k]
subject to sum(h) = n/2, 0 ≤ h ≤ 1

For a fixed λ, this is a quadratic program (since c[k] is quadratic in h):
minimize sum_k λ_k * [sum_j h[j+k] - h[j+k]*h[j]]
= sum_k λ_k * sum_j h[j+k] - sum_k λ_k * sum_j h[j+k]*h[j]
= sum_i h[i] * (sum_k λ_k * [0≤i-k<n]) - sum_k λ_k * sum_j h[j+k]*h[j]

The first term is linear in h. The second term is a quadratic form h^T B h where B is a symmetric matrix.

If B is positive semidefinite, this is a convex QP! Let me check:
B[i,j] = sum_k λ_k * [j = i+k or j = i-k] (from the cross terms)

Actually, sum_k λ_k * sum_j h[j+k]*h[j] = sum_j sum_k λ_k * h[j+k]*h[j] = sum_j h[j] * sum_k λ_k * h[j+k]

This is h^T (A†) h where A is the cross-correlation matrix weighted by λ. Specifically:
(A_λ h)[j] = sum_k λ_k * h[j+k] (with zero padding)

So the quadratic form is h^T A_λ h where A_λ is a symmetric (circulant-like) matrix.

A_λ is positive semidefinite if and only if its Fourier eigenvalues are non-negative. The eigenvalues are:
μ_m = sum_k λ_k * exp(2πimk/n) (for the circulant approximation)

Since λ_k ≥ 0, μ_m is the Fourier transform of a non-negative sequence, which is always... wait, no. The Fourier transform of a non-negative sequence can have negative values.

Actually, for a circulant matrix with first row [λ_0, λ_1, ..., λ_{n-1}], the eigenvalues are:
μ_m = sum_k λ_k * exp(-2πimk/n)

This is the DFT of λ, which is not necessarily non-negative.

So the QP might be non-convex. This makes the dual approach harder.

However, if we restrict λ to be concentrated on a few shifts (active set), then A_λ is a sum of a few permutation matrices, and its eigenvalues are:
μ_m = sum_{k in active} λ_k * exp(-2πimk/n)

For this to be PSD, we need the active set to form a "positive definite" configuration, which is generally not guaranteed.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def get_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def make_feasible(h, n):
    h = np.clip(h.astype(float).copy(), 0.0, 1.0)
    target = n / 2.0
    for _ in range(200):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        cnt = np.sum(mask)
        if cnt == 0:
            break
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    # Exact fix
    diff = target - np.sum(h)
    if abs(diff) > 1e-15:
        if diff > 0:
            idx = int(np.argmin(h))
        else:
            idx = int(np.argmax(h))
        h[idx] += diff
    return h

def soft_max_obj(x, T, top_idx):
    n = x.shape[0]
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode='full')
    if top_idx is not None:
        corr_sub = corr[top_idx]
    else:
        corr_sub = corr
    mc = np.max(corr_sub)
    shifted = T * (corr_sub - mc)
    return (mc + np.log(np.sum(np.exp(shifted))) / T) * dx

def soft_max_grad(x, T, top_idx):
    n = x.shape[0]
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode='full')
    if top_idx is not None:
        corr_sub = corr[top_idx]
    else:
        corr_sub = corr
    
    mc = np.max(corr_sub)
    shifted = T * (corr_sub - mc)
    exp_shifted = np.exp(shifted)
    sum_exp = np.sum(exp_shifted)
    
    if top_idx is not None:
        p_full = np.zeros(2 * n - 1)
        p_full[top_idx] = exp_shifted / sum_exp
    else:
        p_full = exp_shifted / sum_exp
    
    C = np.cumsum(p_full)[:n]
    D = np.convolve(p_full, x, mode='full')[:n]
    h_r = x[::-1]
    conv2 = np.convolve(p_full, h_r, mode='full')
    E = conv2[n-1::-1][:n]
    
    return dx * T * (C - D - E)

def soft_max_obj_grad(x, T, top_idx):
    return soft_max_obj(x, T, top_idx), soft_max_grad(x, T, top_idx)
