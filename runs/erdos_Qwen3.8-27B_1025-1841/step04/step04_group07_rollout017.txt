For lag l < 0: corr_l = sum_{i=-l}^{n-1} h[i]*(1-h[i+l]) = sum_{i=0}^{n-1+l} h[i+l]*(1-h[i]) (by reindexing)
For lag l = 0: corr_0 = sum_i h[i]*(1-h[i])

These can be computed with numpy:
```python
def single_corr(h, l):
    n = len(h)
    if l >= 0:
        return np.sum(h[:n-l] * (1-h[l:]))
    else:
        return np.sum(h[-l:] * (1-h[:n+l]))
```

And the gradient wrt h[j] for a single lag l:
For l > 0:
- j in [0, n-1-l]: d = (1-h[j+l])
- j in [l, n-1]: d = -h[j-l]
- (overlap region [l, n-1-l] has d = (1-h[j+l]) - h[j-l])

For l < 0, let m = -l:
- j in [0, n-1-m]: d = -h[j+m]
- j in [m, n-1]: d = (1-h[j-m])

Let me try a different approach: **simulated annealing / tabu search on the binary case at moderate n**.

For the binary case (h[i] ∈ {0,1}), the problem becomes:
- Choose exactly n/2 positions to be 1
- Minimize max_l |overlap of h and (1-h) shifted by l|
- For binary h, h[i]*(1-h[i+l]) = 1 iff h[i]=1 and h[i+l]=0

So corr_l = number of positions i where h[i]=1 and h[i+l]=0 (for valid i)
= (number of 1s in h) - (number of positions where h[i]=1 AND h[i+l]=1)
= n/2 - autocorrelation_h(l)

So minimizing max_l corr_l is equivalent to maximizing min_l autocorrelation_h(l)!

Where autocorrelation_h(l) = number of positions i where h[i]=1 AND h[i+l]=1 (for valid i)

This is a combinatorial problem: find a subset S ⊂ {0,...,n-1} of size n/2 that maximizes the minimum autocorrelation.

This is related to difference sets and combinatorial designs!

For the binary case at n=640 (320 ones), we want to place 320 ones in a circle of 640 positions such that for every shift l, the number of overlapping pairs (i, i+l both in S) is maximized.

The average autocorrelation over all l is: sum_l autocorr(l) = C(n/2, 2) * 2 (each pair contributes to exactly 2 lags in a circular arrangement)... actually in a linear arrangement it's different.

def make_feasible(h, n):

    for _ in range(300):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
