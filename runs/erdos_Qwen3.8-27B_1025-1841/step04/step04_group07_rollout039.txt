from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_feasible(h, n):
    h = np.clip(np.asarray(h, dtype=float), 0.0, 1.0).copy()
    target = n / 2.0
    for _ in range(300):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
        else:
            room = h
        mask = room > 1e-13
        if not mask.any():
            break
        step = diff / mask.sum()
        h[mask] = np.clip(h[mask] + step, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-14:
        idx = np.argmax(1.0 - h) if diff > 0 else np.argmin(h)
        h[idx] = np.clip(h[idx] + diff, 0.0, 1.0)
    return h

def upsample_h(h, new_n):
    old_n = len(h)
    if new_n == old_n:

    old_x = np.linspace(0.0, 2.0, old_n, endpoint=False)
    new_x = np.linspace(0.0, 2.0, new_n, endpoint=False)
    h_new = np.interp(new_x, old_x, h, period=2.0)
    return make_feasible(h_new, new_n)

def topk_mean(corr, k):
    """Mean of top k values in corr"""
    if k >= len(corr):
        return np.mean(corr)
    idx = np.argpartition(corr, -k)[-k:]
    return np.mean(corr[idx])

    return topk_mean(corr, k) * dx + mu * (h.sum() - len(h)/2.0)**2

**Let me try yet another approach: use CVXPY to solve a sequence of convex relaxations.**

The problem:
minimize t
subject to: sum_i h[i+k]*(1-h[i]) ≤ t for all k
            0 ≤ h[i] ≤ 1
            sum(h) = n/2

The constraint sum_i h[i+k]*(1-h[i]) ≤ t is non-convex (bilinear). But we can relax it:

Replace h[i+k]*(1-h[i]) with a linear upper bound. For fixed h̄ (current iterate):
h[i+k]*(1-h[i]) ≤ h̄[i+k]*(1-h[i]) + h[i+k]*(1-h̄[i]) - h̄[i+k]*(1-h̄[i])

This is the "linearization" (first-order upper bound) of the bilinear term. This gives a convex (actually linear) constraint!

So the DCA (Difference of Convex functions) approach:
- At each iteration: linearize the bilinear terms around the current point
- Solve the resulting LP (or QP)
- Update and repeat

This is essentially the "method of convex extraposition" or "penalty convex-concave procedure" (PCCP).

Let me implement this:

At iterate h⁽ᵗ⁾:
minimize t
subject to: sum_i [h̄[i+k]*(1-h[i]) + h[i+k]*(1-h̄[i]) - h̄[i+k]*(1-h̄[i])] ≤ t for all k
            0 ≤ h ≤ 1
            sum(h) = n/2

The constraint becomes:
sum_i h̄[i+k]*(1-h[i]) + h[i+k]*(1-h̄[i]) - h̄[i+k]*(1-h̄[i]) ≤ t
= sum_i h̄[i+k] - sum_i h̄[i+k]*h[i] + sum_i h[i+k] - sum_i h[i+k]*h̄[i] - sum_i h̄[i+k]*(1-h̄[i]) ≤ t
= (linear in h) - (bilinear h[i+k]*h[i] + h[i+k]*h̄[i]) ... 

Hmm, this still has bilinear terms. Let me redo.

The bilinear term is f(h) = h[i+k] * (1-h[i]) = h[i+k] - h[i+k]*h[i].

The concave part is -h[i+k]*h[i] (since the Hessian of h[i+k]*h[i] is indefinite, but on [0,1]², it's... let me think).

Actually, for DCA, we write f = g - h where g is convex and h is convex.
f(h,a) = ha = (h+a)²/4 - (h-a)²/4 = g(h,a) - h'(h,a) where g = (h+a)²/4 and h' = (h-a)²/4.
Both g and h' are convex in (h,a).

So f = h[i+k](1-h[i]) = h[i+k] - h[i+k]h[i].

Let a = h[i+k], b = h[i]. Then ab = (a+b)²/4 - (a-b)²/4.

So the constraint sum_i [h[i+k] - h[i+k]h[i]] ≤ t becomes:
sum_i h[i+k] - sum_i [(h[i+k]+h[i])²/4 - (h[i+k]-h[i])²/4] ≤ t

The first part (sum_i h[i+k]) is linear. The second part involves squared terms, which are convex. But we have a minus sign: -sum_i [(h[i+k]+h[i])²/4] + sum_i [(h[i+k]-h[i])²/4].

So the constraint is: (linear) - (convex) + (convex) ≤ t, which is not a standard convex constraint.

For the CCCP/DCA approach, at each iteration we linearize the "h" part (the subtracted convex function):
At iterate h⁽ᵗ⁾:
-h[i+k]h[i] ≈ -h⁽ᵗ⁾[i+k]h[i] - h⁽ᵗ⁾[i]h[i+k] + h⁽ᵗ⁾[i+k]h⁽ᵗ⁾[i]

This is the tangent plane to the function -ab at the point (a⁽ᵗ⁾, b⁽ᵗ⁾).

So the linearized constraint is:
sum_i [h[i+k] - h⁽ᵗ⁾[i+k]h[i] - h⁽ᵗ⁾[i]h[i+k] + h⁽ᵗ⁾[i+k]h⁽ᵗ⁾[i]] ≤ t

This IS linear in h! Great. So at each iteration, we solve an LP:
minimize t
subject to: sum_i [h[i+k] - h⁽ᵗ⁾[i+k]h[i] - h⁽ᵗ⁾[i]h[i+k] + const_k] ≤ t for all k
            0 ≤ h ≤ 1
            sum(h) = n/2

This is a linear program with O(n) variables and O(n) constraints. We can solve it with scipy's linprog or cvxpy.

This is the **CCCP (Concave-Convex Procedure)** or **DCA (Difference of Convex Algorithms)** approach!

This is fundamentally different from the parent's approach and should converge to a local minimum of the original non-convex problem.
