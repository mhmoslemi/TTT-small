The problem is: minimize max_k ∫ h(x)(1-h(x+k)) dx subject to ∫h = 1, 0≤h≤1.

Note that ∫ h(x)(1-h(x+k)) dx = ∫ h(x) dx - ∫ h(x)h(x+k) dx = 1 - R(k)

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)
