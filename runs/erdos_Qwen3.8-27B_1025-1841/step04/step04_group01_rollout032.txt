Now, for the coordinate descent, I'll use the 1D analytical optimization:
Given all h except h[j], find the optimal h[j] ∈ [0,1] that minimizes max(corr).

The affected correlations are those m where j is involved:

- m such that 0 <= j-m+n-1 < n: m in [j-1, j+n-1]
Union: m in [max(0, j-1, n-1-j), min(2n-2, j+n-1, n-1+j)]

For each affected m, corr[m] = base[m] + (new-old) * coeff[m]
where coeff[m] = d(corr[m])/dh[j] (computed with old value, but since it's linear in new, the coefficient doesn't change)

Wait, is corr[m] linear in h[j]? Let's check:
corr[m] = sum_i h[i]*(1-h[i+m-n+1])
The terms involving h[j]:
- i=j: h[j]*(1-h[j+m-n+1]) - this is linear in h[j] (since h[j+m-n+1] is fixed when we vary h[j], unless m=n-1)
- i=j-m+n-1: h[j-m+n-1]*(1-h[j]) - linear in h[j]

When m=n-1: h[j]*(1-h[j]) = h[j] - h[j]^2 - this is NOT linear! It's quadratic.

So for m=n-1, the contribution is h[j] - h[j]^2, which is a concave quadratic.

For m≠n-1: the contribution is linear in h[j].

So the objective (max of correlations) is:
- For m=n-1: contains the term h[j] - h[j]^2 (plus other fixed terms)
- For m≠n-1: contains a linear term in h[j]

The maximum of these is a function that's:
- Piecewise linear (from the m≠n-1 terms) but with one concave quadratic (from m=n-1)
