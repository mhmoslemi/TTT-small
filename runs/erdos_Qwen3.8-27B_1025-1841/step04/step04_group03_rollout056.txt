    shifted = corr - mc

    return val

But we can optimize: if we precompute the correlation, we can compute the delta for a 2-flip in O(1) per lag, or O(1) total using the right formula.

For a 2-flip (i: 1→0, j: 0→1), the change in corr at lag k (full correlation, positive lag):
- Positive lag k (result index n-1+k, where n-1+k < 2n-1):
  - h[i+k]*(1-h[i]) was 0, now h[i+k]*1 = h[i+k]: change +h[i+k] (if i+k < n)
  - h[i]*(1-h[i-k]) was (1-h[i-k]), now 0: change -(1-h[i-k]) (if i-k >= 0)
  - h[j+k]*(1-h[j]) was h[j+k]*1 = h[j+k], now h[j+k]*0 = 0: change -h[j+k] (if j+k < n)
  - h[j]*(1-h[j-k]) was 0, now 1*(1-h[j-k]) = (1-h[j-k]): change +(1-h[j-k]) (if j-k >= 0)

So Δ(k) = h[i+k] - (1-h[i-k]) - h[j+k] + (1-h[j-k]) (with appropriate boundary checks)

Similarly for negative lags.

This means I can compute the new max in O(n) by updating the correlation array in O(1) per lag. But the max over all lags still requires O(n) to check.

Actually, for the purpose of finding if the new max is lower than the current max, I just need to check if any lag increases above the current max. I can maintain the correlation array and update it incrementally.

import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_feasible(h, n):
    h = np.clip(h.astype(float), 0.0, 1.0)
    target = n / 2.0
    for _ in range(500):
        diff = target - np.sum(h)
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        cnt = np.sum(mask)
        if cnt == 0:
            break
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

def slsqp_obj(x, n, T):
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode='full')
    mc = np.max(corr)
    shifted = corr - mc
    return (mc + np.log(np.sum(np.exp(T * shifted))) / T) * dx

    return np.sum(x) - len(x) / 2.0

    return np.ones(len(x))

        return slsqp_obj(x, n, T)

            if time.time() - start_time > time_limit:
                return best_b, best_c5
            best_new = curr_c5
            best_j = -1
            for j in zeros:
                b[i] = 0
                b[j] = 1
                c = compute_c5(b)
                b[i] = 1
                b[j] = 0
                if c < best_new - 1e-16:
                    best_new = c
                    best_j = j
            if best_j >= 0:
                b[i] = 0
                b[best_j] = 1
                curr_c5 = best_new
                if curr_c5 < best_c5:
                    best_c5 = curr_c5
                    best_b = b.copy()
                improved = True
                ones = np.where(b == 1)[0]
                zeros = np.where(b == 0)[0]
        if not improved:
            break
    return best_b, best_c5
