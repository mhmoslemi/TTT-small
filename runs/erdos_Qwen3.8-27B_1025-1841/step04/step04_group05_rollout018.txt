For a "true" step function that takes values 0 and 1 on unit intervals, the C5 in the continuous sense is:
C5_cont = max_k ∫₀² h(x)(1-h(x+k)) dx

C5_disc = (2/n) * max_k sum_i h[i](1-h[i+k])

As n→∞, C5_disc → C5_cont (for a piecewise constant h).

So higher n gives a better approximation. But the optimization is harder at higher n.

                    tv = hcd[j] + dv
                    if tv < 0 or tv > 1:
                        continue
                    trial = hcd.copy()
                    trial[j] = tv
                    trial = project_feasible(trial, ncd)
                    c = compute_c5(trial)
                    if c < best_c5 - 1e-13:
                        best_c5 = c
                        hcd = trial
                        best_h = hcd.copy()
                        any_imp = True
                        break
            if not any_imp:
                break
        update(hcd)

    # Try binary local search at the best resolution
    if tl() > 50:
        nb = len(best_h)
        h_bb = (best_h > 0.5).astype(float)
        h_bb = project_feasible(h_bb, nb)
        h_bs2, _ = binary_local_search(h_bb, nb, 3000, min(80, tl() * 0.15), seed + 1)
        update(h_bs2)

    # Final SLSQP from best
    if tl() > 30:
        nfin = len(best_h)
        if nfin <= 1280:
            hf = slsqp_optimize(best_h, nfin, 3000, 80)
        else:
            hf = upsample(best_h, 1280)
            hf = slsqp_optimize(hf, 1280, 3000, 80)
        update(hf)

    best_h = project_feasible(best_h, len(best_h))
    final_c5 = compute_c5(best_h)
    return best_h, final_c5, len(best_h)
