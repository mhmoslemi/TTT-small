For binary h (values 0 or 1), the correlation at lag k is:
corr[k] = number of i such that h[i+k] = 1 and h[i] = 0 (with appropriate range)

When we swap h[a] from 1 to 0 and h[b] from 0 to 1:
- corr decreases by: number of i where the swap removes a (1,0) pair at lag k
- corr increases by: number of i where the swap adds a (1,0) pair at lag k

The change in corr[k] for the swap (a: 1→0, b: 0→1):
- At position a: was contributing (1, 1-h[a-k]) to corr[k] for various k, now contributes (0, ...)
  Actually it's: corr[k] = sum_i h[i+k]*(1-h[i])
  - When a is the "i" in (1-h[i]): corr[k] had term h[k+a]*(1-h[a]) = h[k+a]*0 = 0, now becomes h[k+a]*1
    So corr[k] increases by h[k+a] for the relevant k (where k+a is in [0,n-1])
  - When a is the "i+k" in h[i+k]: corr[k] had term h[a]*(1-h[a-k]) = 1*(1-h[a-k]) = 1-h[a-k], now becomes 0
    So corr[k] decreases by (1-h[a-k]) for relevant k (where a-k is in [0,n-1])
  
- At position b: was contributing (0, ...) to h and (1-h[b]=1, ...) to (1-h)
  - When b is the "i" in (1-h[i]): corr[k] had term h[k+b]*(1-h[b]) = h[k+b]*1, now becomes h[k+b]*0 = 0
    So corr[k] decreases by h[k+b] for relevant k
  - When b is the "i+k" in h[i+k]: corr[k] had term h[b]*(1-h[b-k]) = 0, now becomes 1*(1-h[b-k])
    So corr[k] increases by (1-h[b-k]) for relevant k

So the net change in corr[k] for swap (a→0, b→1):
delta[k] = h[k+a] - (1-h[a-k]) - h[k+b] + (1-h[b-k])  (with appropriate range checks)

For the full correlation of length 2n-1, the indexing is:
corr[t] for t = 0, ..., 2n-2 corresponds to lag k = t - (n-1) ranging from -(n-1) to (n-1).

        b_res, c5_bin = binary_swap_opt(b_init.copy(), n0, t0, tl_bin, rng)
        if c5_bin < best_c5:
            best_c5 = c5_bin
            best_h = b_res.copy()

    # SLSQP refinement after binary
    if time.time() - t0 < budget_s - 120:
        for T in [500.0, 2000.0, 8000.0, 30000.0]:
            if time.time() - t0 > budget_s - 120:
                break
            try:
                x_res = slsqp_opt(best_h, T, 150)
                c5_r = compute_c5(x_res)
                if c5_r < best_c5:
                    best_c5 = c5_r
                    best_h = make_feasible(x_res, n0)
            except Exception:
                pass

    # Phase 3: Coordinate descent
    remaining = budget_s - (time.time() - t0)
    if remaining > 100:
        tl_cd = min(250, remaining - 60)
        best_h, best_c5 = coord_descent(best_h, n0, 80, t0, tl_cd, rng)

    # Phase 4: Perturb + re-optimize
    if time.time() - t0 < budget_s - 150:
        perts = [shift_swap_perturb, fourier_perturb]
        for pf in perts:
            if time.time() - t0 > budget_s - 100:
                break
            for _ in range(2):
                if time.time() - t0 > budget_s - 80:
                    break
                try:
                    hp = pf(best_h, n0, rng)
                    # Quick binary + refine
                    bp = (hp >= 0.5).astype(float)
                    tl_sub = min(80, budget_s - (time.time() - t0) - 60)
                    if tl_sub > 30:
                        b_sub, c5_sub = binary_swap_opt(bp, n0, t0, tl_sub, rng)
                        if c5_sub < best_c5:
                            best_c5 = c5_sub
                            best_h = b_sub.copy()
                    if time.time() - t0 < budget_s - 40:
                        try:
                            x_res = slsqp_opt(best_h, 5000.0, 100)
                            c5_r = compute_c5(x_res)
                            if c5_r < best_c5:
                                best_c5 = c5_r
                                best_h = make_feasible(x_res, n0)
                        except Exception:
                            pass
                except Exception:
                    pass

    # Phase 5: Higher resolution
    remaining = budget_s - (time.time() - t0)
    if remaining > 300:
        n1 = n0 + 400
        old_x = np.linspace(0.0, 2.0, n0)
        new_x = np.linspace(0.0, 2.0, n1)
        h_up = np.interp(new_x, old_x, best_h)
        h_up = make_feasible(h_up, n1)
        # Binary at higher res
        tl_hires = min(150, remaining - 80)
        if tl_hires > 40:
            b_up = (h_up >= 0.5).astype(float)
            b_res2, c5_up = binary_swap_opt(b_up, n1, t0, tl_hires, rng)
            if c5_up < best_c5:
                best_c5 = c5_up
                best_h = b_res2.copy()
        # SLSQP at higher res
        if time.time() - t0 < budget_s - 50:
            try:
                x_res = slsqp_opt(best_h, 3000.0, 100)
                c5_r = compute_c5(x_res)
                if c5_r < best_c5:
                    best_c5 = c5_r
                    best_h = make_feasible(x_res, n1)
            except Exception:
                pass
        # Coord descent at higher res
        remaining2 = budget_s - (time.time() - t0)
        if remaining2 > 50:
            best_h, best_c5 = coord_descent(best_h, n1, 30, t0, min(100, remaining2 - 20), rng)

    # Phase 6: Final refinement
    remaining = budget_s - (time.time() - t0)
    n_pts = len(best_h)
    if remaining > 30:
        best_h, best_c5 = coord_descent(best_h, n_pts, 30, t0, min(60, remaining - 10), rng)
    if remaining > 20 and time.time() - t0 < budget_s - 15:
        try:
            x_res = slsqp_opt(best_h, 50000.0, 100)
            c5_r = compute_c5(x_res)
            if c5_r < best_c5:
                best_c5 = c5_r
                best_h = make_feasible(x_res, n_pts)
        except Exception:
            pass

    best_h = make_feasible(best_h, len(best_h))
    best_c5 = compute_c5(best_h)
    return best_h, best_c5, len(best_h)
