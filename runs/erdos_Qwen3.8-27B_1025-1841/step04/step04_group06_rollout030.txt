Wait, I realize there might be an issue with the targeted swap in SA. When j > 0, the correlation at index (n-1+j) is:
corr[n-1+j] = sum_{i=0}^{n-1-j} h[i] * (1-h[i+j])

This counts the number of positions where h[i]=1 AND h[i+j]=0, for i from 0 to n-1-j.

To reduce this, we want to either:
- Set h[i]=0 for some i where h[i]=1 and h[i+j]=0 (and correspondingly set h[i+j]=1 to maintain the count)
- Set h[i+j]=1 for some i where h[i]=1 and h[i+j]=0

Both approaches involve a swap (set one position to 0 and another to 1).

So my targeted swap logic is correct: find i where h[i]=1 and h[i+j]=0, then swap (set h[i]=0, h[i+j]=1).

But wait, for j < 0 (negative lag), the correlation is:
corr[n-1+j] = corr[n-1-|j|] = sum_{i=|j|}^{n-1} h[i] * (1-h[i-|j|])

This counts positions where h[i]=1 and h[i-|j|]=0.

To reduce this, swap: set h[i]=0, h[i-|j|]=1 for some valid i.

Actually, let me also consider a different approach for the targeted search: instead of SA, use a deterministic "steepest descent" on the binary space. At each step:
1. Find the worst lag
2. For all possible swaps that reduce the worst lag, evaluate which one gives the best overall C5
3. Make that swap

This is more expensive per step (O(n) evaluations) but each step is guaranteed to improve (or we're at a local optimum).

For n=640, there are about 320*320 = 102,400 possible swaps. Evaluating each takes O(n) = O(640) for the correlation. Total per step: O(n * n * n/4) = O(n³/4) ≈ 640³/4 ≈ 67 million operations. That's too slow.

But we can be smarter: only consider swaps that affect the worst lag. For a given lag j, there are at most (n-|j|)/4 such swaps (roughly). So maybe 100-200 candidates. Evaluating each in O(n) gives O(200 * 640) = 128K operations per step. That's very fast!

Let me implement this "greedy binary local search":

```python
def greedy_binary_search(h, n, max_rounds=1000):
    h = (h > 0.5).astype(float)
    current = compute_c5(h)
    
    for rnd in range(max_rounds):
        corr = np.correlate(h, 1.0 - h, mode='full')
        worst = int(np.argmax(corr))
        j = worst - (n - 1)
        
        best_improve = current
        best_swap = None
        
        if 0 < j < n:
            ones = np.where(h > 0.5)[0]
            for i in ones:
                if i + j >= n:
                    continue
                if h[i+j] > 0.5:
                    continue
                # Swap h[i] and h[i+j]
                h[i] = 0.0
                h[i+j] = 1.0
                c = compute_c5(h)
                if c < best_improve:
                    best_improve = c
                    best_swap = (i, i+j)
                h[i] = 1.0
                h[i+j] = 0.0
        elif -n < j < 0:
            j2 = -j
            zeros = np.where(h <= 0.5)[0]
            for i in zeros:
                if i + j2 >= n:
                    continue
                if h[i+j2] <= 0.5:
                    continue
                h[i+j2] = 0.0
                h[i] = 1.0
                c = compute_c5(h)
                if c < best_improve:
                    best_improve = c
                    best_swap = (i+j2, i)
                h[i+j2] = 1.0
                h[i] = 0.0
        else:
            break
        
        if best_swap is None:
            # Try all random swaps (limited)
            improved = False
            ones = np.where(h > 0.5)[0]
            zeros = np.where(h <= 0.5)[0]
            # Try a few random swaps
            for _ in range(200):
                oi = ones[np.random.randint(len(ones))]
                oj = zeros[np.random.randint(len(zeros))]
                h[oi] = 0.0
                h[oj] = 1.0
                c = compute_c5(h)
                if c < best_improve:
                    best_improve = c
                    best_swap = (oi, oj)
                    improved = True
                h[oi] = 1.0
                h[oj] = 0.0
            if not improved:
                break
        
        oi, oj = best_swap
        h[oi] = 0.0
        h[oj] = 1.0
        current = best_improve
    
    return h, current
```

This is O(n) per round (since we iterate over all ones at the worst lag), and each evaluation is O(n) for the correlation. So each round is O(n²). For n=640, that's about 400K operations per round. In 1000 rounds, that's 400M operations, which takes about 40 seconds. That's reasonable.

But wait, the number of ones at the worst lag is at most n/2 = 320. So each round is 320 * O(n) = 320 * 640 = 200K operations. In 1000 rounds: 200M operations. About 20 seconds. Good.

This greedy approach is deterministic and should find a local optimum. Combined with SA (which can escape local optima), this should give good results.

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_feasible(h, n):
    h = np.clip(np.asarray(h, dtype=float), 0.0, 1.0).copy()
    target = n / 2.0
    for _ in range(200):
        diff = target - np.sum(h)
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-15
        else:
            mask = h > 1e-15
        cnt = np.sum(mask)
        if cnt == 0:
            break
        step = diff / cnt
        h[mask] = np.clip(h[mask] + step, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-15:
        idx = np.argmin(h) if diff > 0 else np.argmax(h)
        h[idx] = np.clip(h[idx] + diff, 0.0, 1.0)
    return h

def upsample_h(h, new_n):
    old_n = len(h)
    if new_n == old_n:

    new_x = np.linspace(0.0, 2.0, new_n, endpoint=False)
    h_new = np.interp(new_x, old_x, h, period=2.0)
    return make_feasible(h_new, new_n)
