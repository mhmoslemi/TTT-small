  - Also, for the term where the second index is i: h[i-s]*(1-h[i]) changes from h[i-s]*0 to h[i-s]*1: change = +h[i-s]
  
  Net change at shift s: -(1-h[i+s])*[i+s valid] + h[i-s]*[i-s valid]

  If h[j] changes from 0 to 1:
  - The term h[j]*(1-h[j+s]) changes from 0 to (1-h[j+s]): change = +(1-h[j+s])
  - The term h[j-s]*(1-h[j]) changes from h[j-s]*1 to h[j-s]*0: change = -h[j-s]
  
  Net change at shift s: +(1-h[j+s])*[j+s valid] - h[j-s]*[j-s valid]

  Total change at shift s from swapping i(1→0) and j(0→1):
  Δ_s = -(1-h[i+s])*[i+s∈[0,n-1]] + h[i-s]*[i-s∈[0,n-1]] + (1-h[j+s])*[j+s∈[0,n-1]] - h[j-s]*[j-s∈[0,n-1]]

This can be computed in O(1) per shift, so evaluating the effect of a swap on ALL shifts is O(n). And checking if max changes is O(n) as well.

But we have O(n²) possible swaps. To do local search efficiently, I should:
1. Precompute the current correlation values
2. For each candidate swap, compute Δ_s for all s in O(n)
3. Check if the max of (corr + Δ) is less than the current max

This gives O(n) per swap trial, and with O(n²) swaps, the total is O(n³). For n=960, that's about 9*10^8 operations, which might be too slow.

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_feasible(h, n):
    h = np.clip(h.astype(float).copy(), 0.0, 1.0)
    target = n / 2.0
    for _ in range(200):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        mask = (h < 1.0 - 1e-12) if diff > 0 else (h > 1e-12)
        cnt = np.sum(mask)
        if cnt == 0:
            break
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    # Final exact adjustment
    diff = target - np.sum(h)
    if abs(diff) > 1e-10:
        # Adjust spread across a few points for exactness
        idx = int(np.argmin(np.abs(h - 0.5)))
        h[idx] += diff
        h = np.clip(h, 0.0, 1.0)
    return h

def softmax_obj(x, n, T, top_m):
    corr = np.correlate(x, 1.0 - x, mode='full')
    if top_m and top_m < len(corr):
        idx = np.argpartition(corr, -top_m)[-top_m:]
        vals = corr[idx]
    else:
        vals = corr
    mc = np.max(vals)
    return (mc + np.log(np.sum(np.exp(T * (vals - mc)))) / T) * (2.0 / n)

def optimize_continuous(h, n, budget_s, start_time, T=2000, top_m=15, max_iter=5000):
    def obj(x):
        base = softmax_obj(x, n, T, top_m)

        return base + 1e6 * constraint_viol ** 2
    
    bounds = [(0.0, 1.0)] * n

    best_c5 = compute_c5(h)
