   However, if we linearize: c_m(h + Δ) ≈ c_m(h) + ∇c_m(h)·Δ (first-order approximation), then the problem becomes:
   Minimize max_{m ∈ A} (c_m(h) + ∇c_m(h)·Δ)
   Subject to: 0 ≤ h + Δ ≤ 1, sum(h + Δ) = n/2

   This is a linear program in Δ! We can solve it with any LP solver.

   **Active set linearization approach:**
   1. Start with h₀, compute c_m(h₀) for all m
   2. Active set A = {m : c_m(h₀) > max(c(h₀)) - ε}
   3. Solve LP: min t s.t. c_m(h) + ∇_h c_m(h)·Δ ≤ t, 0 ≤ h+Δ ≤ 1, sum(h+Δ) = n/2
   4. Update h ← h + Δ
   5. Recompute c_m, update active set
   6. Repeat until convergence

   This is essentially a cutting-plane / linearization method for the non-smooth max. It should converge to a local minimum.

   Actually, this is very similar to what SLSQP does internally, but with a more explicit active set management.

   - Computing all c_m: O(n²) ≈ 1M ops (fast, ~1ms)
   - Computing gradient of c_m for all m: O(n²) (fast)
   - Solving LP with O(n) variables and O(|A| + n) constraints: depends on solver, but should be fast for moderate |A|

        # Actually l <= n-1 means j-k <= n-1, i.e., k >= j-(n-1)
        # And l >= -(n-1) means j-k >= -(n-1), i.e., k <= j+(n-1)
        # So k in [max(0, j-n+1), min(n-1, j+n-1)] = [0, n-1] always (since j in [0,n-1])
        # Wait: k >= j-(n-1) and k >= 0, so k_lo = max(0, j-n+1)
        # k <= j+(n-1) and k <= n-1, so k_hi = min(n-1, j+n-1) = n-1
        
        # So k ranges from max(0, j-n+1) to n-1
        k_arr = np.arange(max(0, j - (n-1)), n)
        l_arr = j - k_arr  # l = j - k

What about a **non-periodic** pattern? For example, based on the Thue-Morse sequence or a Sturmian word?

**Sturmian words** are aperiodic sequences with low complexity that have good distribution properties. A Sturmian word of slope α (irrational) on {0,1} has the property that the number of 1s in any interval of length L is either floor(αL) or ceil(αL).

For our problem, if we use a Sturmian word of slope 1/2 (which gives a balanced sequence), the autocorrelation might be more uniform.

Actually, the balanced property is exactly what we want! A balanced binary sequence of length n with n/2 ones has the property that for any two substrings of the same length, the difference in the number of 1s is at most 1.

This would give a very uniform autocorrelation, which is exactly what we want to minimize the max.

Let me think about how to construct a Sturmian-like sequence for our problem:
- Use a mechanical word with slope 1/2: s[n] = floor((n+1)/2) - floor(n/2) = 1 if n is even, 0 if n is odd
  This gives 1,0,1,0,1,0,... which is periodic with period 2. Not good.

- Use an irrational slope, say α = (√5-1)/2 ≈ 0.618 (golden ratio conjugate)
  s[n] = floor((n+1)α) - floor(nα)
  This gives a Sturmian word that is aperiodic and balanced.

But wait, we need exactly n/2 ones. For a Sturmian word of irrational slope, the number of 1s in length n is either floor(nα) or ceil(nα). We need this to be n/2, so α = 1/2. But α = 1/2 is rational, giving a periodic sequence.

So we can't directly use a Sturmian word with exactly n/2 ones and irrational slope. We'd need to modify it.

from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_feasible(x, target_sum):
    lo = x.min() - target_sum - 2
    hi = x.max() + target_sum + 2
    lam = (lo + hi) / 2.0
    for _ in range(80):
        proj = np.clip(x - lam, 0.0, 1.0)
        s = proj.sum()
        if abs(s - target_sum) < 1e-13:
            break
        if s > target_sum:
            lo = lam
        else:
            hi = lam
        lam = (lo + hi) / 2.0
    result = np.clip(x - lam, 0.0, 1.0)
    # Fix any tiny numerical issues
    diff = target_sum - result.sum()
    if abs(diff) > 1e-14:
        idx = int(np.argmin(result) if diff > 0 else np.argmax(result))
        result[idx] += diff
    return result

def smooth_max(h, T):
    dx = 2.0 / len(h)
    corr = compute_corr(h) * dx
    cmax = np.max(corr)
    return cmax + np.log(np.sum(np.exp(T * (corr - cmax)))) / T

def smooth_max_grad(h, T):
    n = len(h)
    dx = 2.0 / n
    corr = compute_corr(h) * dx
    cmax = np.max(corr)
    w = np.exp(T * (corr - cmax))
    w /= w.sum()
    
    grad = np.zeros(n)
    for j in range(n):
        # First term: sum_l w[l+(n-1)] * (1-h[j-l]) for valid (j-l)
        # k = j-l, valid k in [0,n-1], l = j-k in [-(n-1), n-1]
        k_lo = max(0, j - (n-1))
        k_hi = n - 1
        if k_lo <= k_hi:
            k_arr = np.arange(k_lo, k_hi + 1)
            l_arr = j - k_arr
            w_idx = l_arr + (n-1)
            term1 = np.sum(w[w_idx] * (1.0 - h[k_arr]))
        else:
            term1 = 0.0
        
        # Second term: sum_l w[l+(n-1)] * h[j+l] for valid (j+l)
        # k = j+l, valid k in [0,n-1], l = k-j in [-(n-1), n-1]
        k_lo2 = max(0, j - (n-1))
        k_hi2 = min(n-1, j + (n-1))
        if k_lo2 <= k_hi2:
            k_arr2 = np.arange(k_lo2, k_hi2 + 1)
            l_arr2 = k_arr2 - j
            w_idx2 = l_arr2 + (n-1)
            term2 = np.sum(w[w_idx2] * h[k_arr2])
        else:
            term2 = 0.0
        
        grad[j] = dx * (term1 - term2)
    
    return grad

def binary_sa(h_binary, n_swaps, T_start, T_end, rng, target_sum):
    """Simulated annealing on binary sequences using pair swaps"""
    n = len(h_binary)
    h = h_binary.copy()
    best_h = h.copy()
    best_c5 = compute_c5(h)
    cur_c5 = best_c5
    
    ones = np.where(h == 1)[0]
    
    for swap_i in range(n_swaps):
        T = T_start * (T_end / T_start) ** (swap_i / max(1, n_swaps - 1))
        
        # Pick a random pair (i, j) where h[i]=1, h[j]=0
        i = ones[rng.randint(len(ones))]
        zeros = np.where(h == 0)[0]
        j = zeros[rng.randint(len(zeros))]
        
        # Swap
        h[i] = 0
        h[j] = 1
        
        new_c5 = compute_c5(h)
        
        if new_c5 <= cur_c5 or rng.random() < np.exp(-(new_c5 - cur_c5) / max(T, 1e-10)):
            cur_c5 = new_c5
            # Update ones list
            ones = np.where(h == 1)[0]
            if new_c5 < best_c5:
                best_c5 = new_c5
                best_h = h.copy()
        else:
            # Revert
            h[i] = 1
            h[j] = 0
    
    return best_h, best_c5
