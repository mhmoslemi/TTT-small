- Evaluate the max at each candidate point
- Pick the best

But this is O(K²) where K = 2n-1, which is O(n²) per coordinate, making the full CD O(n³). Too slow for n=960.

However, we can do better: since the objective is convex in x[j] (max of linear functions), we can use bisection or ternary search. But the function is piecewise linear with O(n) breakpoints, so we can find the minimum in O(n log n) by finding the vertex.

Actually, for a max of linear functions, the minimum is at a point where the "slope" changes from negative to positive. The slope at x[j] is B_k* where k* is the argmax. So:
- At x[j]=0: slope = B_{argmax at 0}
- If slope < 0 at 0: minimum is at 0
- If slope > 0 at 1: minimum is at 1
- Otherwise: minimum is where the active set changes

For practical purposes, I can just evaluate at a few key points: 0, 1, and the intersection of the top 2-3 lag lines. This gives a good approximation.

Actually, let me simplify: for each coordinate j, evaluate the objective at x[j] = 0, 1, and the current value, and maybe a couple of intermediate values. This is what the previous code does, but I can be smarter about the intermediate values.

The key intermediate value is where the two most "active" lags cross. If lag k1 and k2 are both near the maximum:
A_k1 + B_k1 * x = A_k2 + B_k2 * x

_G_T = 100.0

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_feasible(h, n):

    target = n / 2.0
    for _ in range(200):

        if abs(diff) < 1e-13:

        if diff > 0:

        else:
            mask = h > 0.0
        cnt = np.sum(mask)
        if cnt == 0:
            break
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

def _obj_fs(x):

    T = _G_T
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode='full')
    mc = np.max(corr)
    shifted = T * (corr - mc)
    s = np.sum(np.exp(shifted))
    return (mc + np.log(s) / T) * dx

def _con_fun(x):
    return np.sum(x) - _G_N / 2.0

def _con_jac(x):

                       bounds=bounds, constraints=cons,

    for rnd in range(max_rounds):
        rem = budget_s - (time.time() - start_time)

            cands = [0.0, 1.0, max(0.0, old - 0.02), max(0.0, old - 0.005),
