        if c5_1 < best_c5:

            best_h = b2.copy()
            best_n = n2

Now let me think about the continuous_polish function. The key issue is that SLSQP with numerical gradients is slow for large n. Let me use a different approach:

**Coordinate descent with focus on the worst lags:**
1. Compute the correlate and find the top-k lags
2. For each coordinate i, find the value that minimizes the max (or sum of top-k) correlation
3. This is a 1D optimization for each coordinate

For a single coordinate i, the correlation at lag L is:
r[L] = ... + h[i]*(1-h[i+L]) + (1-h[i])*h[i-L] + ... (terms involving h[i])

Actually, let me think about this more carefully. The full correlation r[L] = sum_j h[j]*(1-h[j+L]).

The terms involving h[i] are:
- h[i]*(1-h[i+L]) when j = i (if i+L is valid)
- h[j]*(1-h[i]) when j+L = i, i.e., j = i-L (if i-L is valid and h[i] appears in the (1-h[...]) factor)

Wait, (1-h[i]) appears when j+L = i, i.e., j = i-L. In that case, the term is h[i-L]*(1-h[i]).

So r[L] as a function of h[i] (treating all other h values as fixed):
r[L] = A[L] + h[i]*(1-h[i+L])*valid(i+L) + h[i-L]*(1-h[i])*valid(i-L)

where A[L] is the sum of all terms not involving h[i].

Expanding:
r[L] = A[L] + h[i]*(1-h[i+L])*v1 + h[i-L]*(1-h[i])*v2

where v1 = 1 if 0 ≤ i+L < n, else 0, and v2 = 1 if 0 ≤ i-L < n, else 0.

If h is binary (0 or 1), then:
- If v1=1 and v2=1: r[L] = A[L] + h[i]*(1-h[i+L]) + h[i-L]*(1-h[i])
  If h[i]=0: r[L] = A[L] + h[i-L]
  If h[i]=1: r[L] = A[L] + (1-h[i+L])
  
- If v1=1 and v2=0: r[L] = A[L] + h[i]*(1-h[i+L])
  If h[i]=0: r[L] = A[L]
  If h[i]=1: r[L] = A[L] + (1-h[i+L])

- If v1=0 and v2=1: r[L] = A[L] + h[i-L]*(1-h[i])
  If h[i]=0: r[L] = A[L] + h[i-L]
  If h[i]=1: r[L] = A[L]

This is getting complex. For the continuous case, the function is linear in h[i] (since h[i] appears at most once in each product term when we fix the other variable).

Wait: r[L] as a function of h[i]:
- Term h[i]*(1-h[i+L]): linear in h[i] (coefficient = 1-h[i+L])
- Term h[i-L]*(1-h[i]): linear in h[i] (coefficient = -h[i-L])

So r[L] = A[L] + h[i] * ((1-h[i+L])*v1 - h[i-L]*v2)

This is LINEAR in h[i]! So for a fixed set of other variables, each r[L] is linear in h[i].

The objective max_L r[L] is the max of linear functions of h[i], which is convex in h[i]. So for each coordinate, the 1D optimization is:
minimize max_L (A[L] + h[i] * B[L]) over h[i] ∈ [0,1]

where B[L] = (1-h[i+L])*v1 - h[i-L]*v2.

This is a 1D convex optimization! We can solve it analytically:
- The function f(t) = max_L (A[L] + t*B[L]) is piecewise linear and convex in t
- The minimum over t ∈ [0,1] is at a "kink point" or at a boundary

For a practical implementation:
1. Compute A[L] and B[L] for the current h[i]
2. Find the t that minimizes max_L (A[L] + t*B[L])
   - This is equivalent to: find t that minimizes the maximum of lines with intercepts A[L] and slopes B[L]
   - The optimal t is where two (or more) lines intersect at the maximum

This is a small-scale linear programming problem:
minimize z
subject to: A[L] + t*B[L] ≤ z for all L
            0 ≤ t ≤ 1

This has 2n-1 constraints and 2 variables (t, z). We can solve it with a simple approach:
- Evaluate f(t) at t=0, t=1, and all intersection points
- Return the t with minimum f(t)

But computing all intersection points is O(n²), which is too slow if we do this for every coordinate.

A simpler approach: use ternary search or golden section search on t ∈ [0,1] to minimize f(t) = max_L (A[L] + t*B[L]). Since f is convex, this is guaranteed to find the global minimum in O(n) evaluations, each O(n).

Total cost per coordinate: O(n²)
Total cost per full pass: O(n³)
For n=960: O(960³) ≈ 885 million operations. Too slow!

Let me use a simpler approach: just try t = h[i] (current), t = 0, t = 1, and a few intermediate values. This is the coordinate descent approach from the parent.

Actually, for the continuous case, the most effective approach is probably:
1. Use the binary solution as a starting point
2. For each "boundary" coordinate (where neighboring values are 0 and 1), try shifting the value
3. This is essentially the same as what the parent does in its coordinate descent phase

Let me simplify and focus on what will work:

**Final algorithm:**
1. Start from parent (n=960)
2. Binary SA at n=960 (aggressive, with restarts)
3. Binary SA at n=480 (from downsampled parent + random init)
4. Binary SA at n=1920 (from upsampled best)
5. Simple continuous polish (coordinate descent)
6. Return best

Let me also add a key trick: **when evaluating the SA move, only check the affected lags**. For a point swap (flip i: 0→1, flip j: 1→0), the correlation changes at all lags L where i±L or j±L is in range. But the CHANGE is:
Δr[L] = (1-h[i+L])*v(i+L) - h[i-L]*v(i-L) - (1-h[j+L])*v(j+L) + h[j-L]*v(j-L)

For binary h, each term is 0 or 1. So Δr[L] ∈ {-2, -1, 0, 1, 2}.

The new max is: max(old_max, max of r[L] + Δr[L] for affected L).
But we also need to check if any previously-max lags decreased below the new max.

This is complex to implement correctly. Let me just use the full correlate computation, which is fast enough in numpy.

Let me measure: np.correlate on two arrays of length 960. In numpy, this is a C implementation using FFT or direct computation. For length 960, the direct computation is 960² ≈ 921,600 multiplications. In C, this takes maybe 50-100μs. The FFT-based approach would be O(n log n) ≈ 9600 operations, which is faster.

Actually, numpy's correlate uses direct computation for small arrays and FFT for larger ones. For n=960, it might use direct. Let's assume ~100μs per call.

In 100 seconds, we can do ~1 million SA iterations. That should be enough.

Let me write the final code now. I'll keep it focused and practical:

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_feasible(h, n):
    h = np.clip(h.astype(float), 0.0, 1.0)
    target = n / 2.0
    for _ in range(200):
        diff = target - np.sum(h)
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-12
        else:
            mask = h > 1e-12
        cnt = np.sum(mask)
        if cnt == 0:
            break
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

def to_binary(h, n, rng):
    b = (h >= 0.5).astype(float)
    target = n // 2
    cur = int(np.sum(b))
    if cur > target:
        ones = np.where(b == 1)[0]
        idx = rng.choice(ones, size=cur - target, replace=False)
        b[idx] = 0
    elif cur < target:
        zeros = np.where(b == 0)[0]
        idx = rng.choice(zeros, size=target - cur, replace=False)
        b[idx] = 1
    return b

def sa_binary(b, n, iters, T0, T1, rng, block_max=3, start_time=None, budget_s=None, restart_patience=30000):

    curr_c5 = compute_c5(b)
    best_c5 = curr_c5
    best_b = b.copy()
    stale = 0
    it = 0
    
    while it < iters:
        if start_time is not None and budget_s - (time.time() - start_time) < 5:
            break
        
        frac = min(1.0, float(it) / max(1, iters))
        T = max(1e-15, T0 * (T1 / T0) ** frac)
        
        # Adaptive block size
        bm = max(1, int(block_max * (1.0 - 0.5 * frac))) if block_max > 1 else 1
        
        if bm > 1:
            bs = rng.randint(1, bm + 1)
            s = rng.randint(0, max(1, n - bs))
            e = s + bs
            seg_ones = np.where(b[s:e] == 1)[0]
            seg_zeros = np.where(b[s:e] == 0)[0]
            if len(seg_ones) == 0 or len(seg_zeros) == 0:
                it += 1
                continue
            k = min(len(seg_ones), len(seg_zeros))
            ci = seg_ones[rng.choice(len(seg_ones), k, replace=False)]
            cj = seg_zeros[rng.choice(len(seg_zeros), k, replace=False)]
            b[s + ci] = 0
            b[s + cj] = 1
        else:
            ones = np.where(b == 1)[0]
            zeros = np.where(b == 0)[0]
            i = ones[rng.randint(len(ones))]
            j = zeros[rng.randint(len(zeros))]
            b[i] = 0
            b[j] = 1
        
        new_c5 = compute_c5(b)
        
        accept = (new_c5 <= curr_c5) or (rng.random() < np.exp(-max(0, new_c5 - curr_c5) / T))
        
        if accept:
            curr_c5 = new_c5
            if new_c5 < best_c5 - 1e-15:
                best_c5 = new_c5
                best_b = b.copy()
            stale += 1 if new_c5 >= best_c5 - 1e-15 else 0
        else:
            if bm > 1 and k > 0:
                b[s + ci] = 1
                b[s + cj] = 0
            else:
                b[i] = 1
                b[j] = 0
            stale += 1
        
        it += 1
        
        if stale >= restart_patience and it < iters * 0.95:
            b = best_b.copy()
            nf = max(3, n // 15)
            ones = np.where(b == 1)[0]
            zeros = np.where(b == 0)[0]
            fo = rng.choice(ones, size=min(nf, len(ones)), replace=False)
            fz = rng.choice(zeros, size=min(nf, len(zeros)), replace=False)
            b[fo] = 0
            b[fz] = 1
            curr_c5 = compute_c5(b)
            stale = 0
    
    return best_b, best_c5

def coord_descent(h, n, max_rounds, start_time, budget_s):
    best_c5 = compute_c5(h)
    for rnd in range(max_rounds):
        if budget_s - (time.time() - start_time) < 5:
            break
        improved = False
        for j in range(n):
            if budget_s - (time.time() - start_time) < 3:
                break
            old = h[j]
            best_c = best_c5
            best_v = old
            for cand in [0.0, 1.0, max(0.0, old - 0.1), min(1.0, old + 0.1),
                         max(0.0, old - 0.05), min(1.0, old + 0.05)]:
                if abs(cand - old) < 1e-10:
                    continue
                trial = h.copy()
                trial[j] = cand
                trial = make_feasible(trial, n)
                c = compute_c5(trial)
                if c < best_c - 1e-14:
                    best_c = c
                    best_v = cand
            if best_v != old:
                h[j] = best_v
                h = make_feasible(h, n)
                best_c5 = best_c
                improved = True
        if not improved:
            break
    return h, best_c5

def slsqp_polish(h, n, T, maxiter, ftol):
    def obj(x):
        corr = np.correlate(x, 1.0 - x, mode='full')
        mc = np.max(corr)
        shifted = corr - mc
        return (mc + np.log(np.sum(np.exp(T * shifted))) / T) * (2.0 / n)
    
    def con_fun(x):
        return np.sum(x) - n / 2.0
    
    def con_jac(x):
        return np.ones(n)
    
    cons = [{'type': 'eq', 'fun': con_fun, 'jac': con_jac}]
    bounds = [(0.0, 1.0)] * n
    
    res = minimize(obj, h.copy(), method='SLSQP', bounds=bounds,
                   constraints=cons, options={'maxiter': maxiter, 'ftol': ftol,
                                              'iprint': 0})
    if res.fun < compute_c5(h):
        return make_feasible(res.x, n)
    return h
