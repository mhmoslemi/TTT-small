- First term contributes to k in [0, n-1-t] = [0, n+s-1]: grad[k] += (1-h[k-t]) = (1-h[k+s+... wait
  k-s = k-t = k+|s|, so (1-h[k+|s|]) for k in [0, n-1-|s|]
  In terms of s (negative): k in [0, n-1+s] (since s=-|s|, n-1-|s| = n-1+s)
  grad[k] += (1-h[k-s]) where k-s = k+|s|

- Second term contributes to k in [t, n-1] = [|s|, n-1] = [-s, n-1]:
  grad[k] += -h[k+s] where k+s = k-|s|

Let me code this up properly:

```python
def smooth_max_gradient_vec(h, n, corr_vals, T, top_k=10):
    """Compute gradient of smooth max of correlation values w.r.t. h."""
    top_idx = np.argsort(corr_vals)[-top_k:]
    c = corr_vals[top_idx]
    mc = np.max(c)
    weights = np.exp(T * (c - mc))
    weights /= np.sum(weights)
    
    grad = np.zeros(n)
    for i, idx in enumerate(top_idx):
        s = idx - (n - 1)
        w = weights[i]
        if s >= 0:
            # First term: k in [s, n-1], grad[k] += (1-h[k-s])
            grad[s:] += w * (1.0 - h[:n-s])
            # Second term: k in [0, n-1-s], grad[k] += -h[k+s]
            grad[:n-s] -= w * h[s:]
        else:
            t = -s  # t > 0
            # First term: k in [0, n-1-t], grad[k] += (1-h[k+t])
            grad[:n-t] += w * (1.0 - h[t:])
            # Second term: k in [t, n-1], grad[k] += -h[k-t]
            grad[t:] -= w * h[:n-t]
    
    return grad
```

This is O(n * top_k) which is very fast.

def smooth_max_optimize(h, n, budget_s, start_time, T_start=50, T_end=5000, top_k=10):
    """Optimize using smooth max with subgradient descent + backtracking."""
    best_h = h.copy()
    best_c5 = compute_c5(h)[0]
    step_size = 0.5 / n  # Initial step size
    momentum = 0.8
    velocity = np.zeros(n)
    
    n_iter = 0
    total_iters = 5000
    no_improve = 0
    
    while time.time() - start_time < budget_s - 5:
        n_iter += 1
        # Adaptive T
        frac = min(1.0, n_iter / total_iters)
        T = T_start * (T_end / T_start) ** frac
        
        _, curr_vals = compute_c5(h)
        curr_c5 = np.max(curr_vals)
        
        if curr_c5 < best_c5 - 1e-14:
            best_c5 = curr_c5
            best_h = h.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        if no_improve > 200:
            step_size *= 0.5
            if step_size < 1e-8:
                break
            no_improve = 0
        
        # Compute gradient
        grad = smooth_max_gradient_vec(h, n, curr_vals, T, top_k)
        
        # Nesterov momentum
        y = h - momentum * velocity
        y = np.clip(y, 0, 1)
        _, y_vals = compute_c5(y)
        y_grad = smooth_max_gradient_vec(y, n, y_vals, T, top_k)
        velocity = momentum * velocity - step_size * y_grad
        new_h = h + velocity
        new_h = make_feasible(new_h, n)
        
        new_c5 = compute_c5(new_h)[0]
        if new_c5 <= curr_c5 + 1e-14:
            h = new_h
        else:
            # Backtracking
            new_h2 = make_feasible(h - step_size * grad, n)
            new_c52 = compute_c5(new_h2)[0]
            if new_c52 <= curr_c5 + 1e-14:
                h = new_h2
                velocity *= 0.5
            else:
                step_size *= 0.5
                velocity = np.zeros(n)
            if step_size < 1e-9:
                break
    
    final_h = make_feasible(h, n)
    final_c5 = compute_c5(final_h)[0]
    if final_c5 < best_c5:
        best_h, best_c5 = final_h, final_c5
    return best_h, best_c5

Now, let me also think about the binary approach more carefully. For the Erdős problem, it's known that the optimal solution is a step function (or can be approximated by one). The question is whether a binary solution (0/1 valued) can achieve the same bound as a non-binary one.

Actually, by a rearrangement argument, for the specific structure of this problem, the optimal solution should be binary (or very close to binary). This is because the objective is linear in each h[i] for fixed other variables (it's a product h[i](1-h[j]) which is bilinear). The max of linear functions is convex, and we're minimizing a convex function over a hypercube with a linear constraint. The minimum of a convex function over a polytope occurs at a vertex, which for our case means h is binary.

Wait, that's not right. The objective is max_k sum_i h[i](1-h[i+k]), which is the max of linear functions in h (for fixed shift structure). Actually no, h[i](1-h[i+k]) is NOT linear in h. It's quadratic.

Let me reconsider. For a fixed shift s:
g_s(h) = sum_i h[i](1-h[i-s]) = sum_i h[i] - sum_i h[i]h[i-s]

This is quadratic in h. The max of quadratic functions is not necessarily convex.

So the optimal solution might not be binary. However, in practice, solutions that are close to binary tend to work well.

2. Round to binary and do binary local search
3. Use the best of both

For the binary local search, I'll use a more efficient approach:
- Precompute the correlation
- When we flip h[i] from 1 to 0 and h[j] from 0 to 1, we can update the correlation incrementally

Actually, let me think about this incrementally. If we flip h[a] from 1 to 0:
- For each shift s, the correlation changes by:
  - If a is a valid "first" index for shift s: we lose h[a]*(1-h[a-s]) = (1-h[a-s])
  - If a is a valid "second" index (i.e., a+s is valid): we lose h[a+s]*(1-h[a]) = h[a+s] * 1 = h[a+s]... wait

g_s(h) = sum_{i valid for s} h[i] * (1-h[i-s])

If we change h[a] from 1 to 0:
- Term i=a: was h[a]*(1-h[a-s]) = 1*(1-h[a-s]) = (1-h[a-s]), now 0. Change: -(1-h[a-s])
- Term i=a+s (if valid): was h[a+s]*(1-h[a]) = h[a+s]*1 = h[a+s], now h[a+s]*1 = h[a+s]. No change! Because h[a] only appears in the (1-h[i-s]) part when i-s = a, i.e., i = a+s. And (1-h[a]) changes from 0 to 1, so the term h[a+s]*(1-h[a]) changes from h[a+s]*0 to h[a+s]*1. Wait that's an increase!

Let me redo. g_s(h) = sum_{i in S_s} h[i] * (1-h[i-s]) where S_s = {i : 0<=i<n, 0<=i-s<n}

Change h[a] from 1 to 0:
1. For i=a (if a in S_s): term changes from 1*(1-h[a-s]) to 0*(1-h[a-s]). Delta = -(1-h[a-s])
2. For i=a+s (if a+s in S_s): term changes from h[a+s]*(1-1) to h[a+s]*(1-0) = h[a+s]. Delta = +h[a+s]
   Wait: before: h[a+s]*(1-h[a]) = h[a+s]*(1-1) = 0
   After: h[a+s]*(1-0) = h[a+s]
   So delta = +h[a+s]

So total change in g_s when h[a] goes 1→0:
delta_s = -(1-h[a-s]) * I[a in S_s] + h[a+s] * I[a+s in S_s]

And when h[a] goes 0→1:
delta_s = +(1-h[a-s]) * I[a in S_s] - h[a+s] * I[a+s in S_s]

These are the same with opposite sign, which makes sense.

This gives us an O(1) update per shift per flip! So a pair flip (a: 1→0, b: 0→1) changes g_s by:
delta_s = [-(1-h[a-s]) + h[a+s]] * I[a in S_s] + h[a+s] * I[a+s in S_s] ... 

Wait, I need to be more careful. When we do a pair flip (a:1→0, b:0→1):
- Effect of a:1→0 on g_s: delta_a_s = -(1-h'[a-s])*I[a in S_s] + h'[a+s]*I[a+s in S_s]
  where h' is after the flip. But since we're evaluating the change, we should use the "before" values for the other positions.
  
  Actually, the change in g_s due to flipping h[a] from 1 to 0 (with all other h fixed) is:
  - From the h[a] term: -(1-h[a-s]) if a in S_s
  - From the (1-h[a]) factor in term i=a+s: +h[a+s] if a+s in S_s
  
  But wait, if b = a+s or b = a-s, there's interaction. Let me ignore that for now (it's a small edge case).

Similarly for b: 0→1:
- From the h[b] term: +(1-h[b-s]) if b in S_s
- From the (1-h[b]) factor in term i=b+s: -h[b+s] if b+s in S_s

So total change in g_s for pair flip (a:1→0, b:0→1):
delta_s = -(1-h[a-s])*I[a in S_s] + h[a+s]*I[a+s in S_s]
          + (1-h[b-s])*I[b in S_s] - h[b+s]*I[b+s in S_s]

This is O(1) per shift! So we can evaluate the change in the max correlation in O(n) time (checking all shifts), or O(top_k) if we only check the top shifts.

This makes binary local search very efficient!

def binary_local_search_fast(h, n, budget_s, start_time, top_k=10):
    """Fast binary local search with O(1) per-shift evaluation."""
    h = np.where(h > 0.5, 1.0, 0.0)
    target = n // 2
    num_ones = int(np.sum(h))
    if num_ones > target:
        # Need to flip (num_ones - target) ones to zeros
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        for i in range(num_ones - target):
            h[ones[i]] = 0.0
            h[zeros[i]] = 1.0
    elif num_ones < target:
        zeros = np.where(h == 0)[0]
        ones = np.where(h == 1)[0]
        for i in range(target - num_ones):
            h[zeros[i]] = 1.0
            h[ones[i]] = 0.0
    
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    best_c5 = np.max(corr)
    best_h = h.copy()
    
    ones_set = set(np.where(h == 1)[0].tolist())
    zeros_set = set(np.where(h == 0)[0].tolist())
    
    rng = np.random.RandomState(42)
    no_improve = 0
    max_no_improve = 2000
    
    while time.time() - start_time < budget_s - 5:
        if no_improve > max_no_improve:
            break
        
        # Get top shifts
        top_idx = np.argsort(corr)[-top_k:]
        
        # Try to find an improving flip
        found = False
        # Strategy: pick a random one from hot positions, try to flip with random zero
        # Hot positions: ones that contribute to top shifts
        hot_ones = []
        for idx in top_idx:
            s = idx - (n - 1)
            if s >= 0:
                valid_range = range(s, n)
            else:
                valid_range = range(0, n + s)
            for j in valid_range:
                if h[j] == 1 and h[(j - s) % n if 0 <= j-s < n else -1] != 1:
                    hot_ones.append(j)
                    if len(hot_ones) > 20:
                        break
            if len(hot_ones) > 20:
                break
        
        # Try flips
        candidates = hot_ones if hot_ones else list(ones_set)
        zeros_list = list(zeros_set)
        
        n_trials = min(20, len(candidates) * max(1, len(zeros_list)))
        
        for _ in range(n_trials):
            a = candidates[rng.randint(len(candidates))]
            b = zeros_list[rng.randint(len(zeros_list))]
            if a == b:
                continue
            
            # Evaluate change in all top shifts
            new_corr_top = np.zeros(top_k)
            for i, idx in enumerate(top_idx):
                s = idx - (n - 1)
                # Compute delta for pair flip (a:1->0, b:0->1)
                delta = 0.0
                # Effect of a: 1->0
                if s >= 0:
                    if s <= a < n and 0 <= a-s < n:
                        delta += -(1.0 - h[a-s])
                    if 0 <= a+s < n:
                        delta += h[a+s]
                else:
                    t = -s
                    if 0 <= a < n - t:  # a in S_s means 0<=a<n and 0<=a-s<n = 0<=a+t<n
                        delta += -(1.0 - h[a+t])
                    if a - t >= 0 and a - t < n:  # a+s in [0,n-1] means a-t in [0,n-1]
                        delta += h[a-t]
                # Effect of b: 0->1
                if s >= 0:
                    if s <= b < n and 0 <= b-s < n:
                        delta += (1.0 - h[b-s])
                    if 0 <= b+s < n:
                        delta += -h[b+s]
                else:
                    t = -s
                    if 0 <= b < n - t:
                        delta += (1.0 - h[b+t])
                    if b - t >= 0 and b - t < n:
                        delta += -h[b-t]
                new_corr_top[i] = corr[idx] + delta * dx
            
            new_max = np.max(new_corr_top)
            # Also need to check non-top shifts... but for simplicity, accept if top improves
            if new_max < best_c5 - 1e-12:
                # Apply flip
                h[a] = 0.0
                h[b] = 1.0
                # Update correlation
                # Recompute full correlation (expensive but correct)
                corr = np.correlate(h, 1.0 - h, mode='full') * dx
                actual_max = np.max(corr)
                if actual_max < best_c5 - 1e-14:
                    best_c5 = actual_max
                    best_h = h.copy()
                    ones_set.discard(a)
                    ones_set.add(b)
                    zeros_set.discard(b)
                    zeros_set.add(a)
                    found = True
                    no_improve = 0
                    break
                else:
                    # Revert
                    h[a] = 1.0
                    h[b] = 0.0
            
        if not found:
            no_improve += 1
            # Occasionally do a random neutral move (simulated annealing)
            if no_improve % 100 == 0 and rng.rand() < 0.5:
                a = list(ones_set)[rng.randint(len(ones_set))]
                b = list(zeros_set)[rng.randint(len(zeros_set))]
                h[a] = 0.0
                h[b] = 1.0
                ones_set.discard(a)
                ones_set.add(b)
                zeros_set.discard(b)
                zeros_set.add(a)
                corr = np.correlate(h, 1.0 - h, mode='full') * dx
    
    return best_h, best_c5

def compute_c5_full(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx, corr * dx

def make_feasible(h, n):
    h = np.clip(h.astype(float).copy(), 0.0, 1.0)
    target = n / 2.0
    for _ in range(500):
        diff = target - np.sum(h)
        if abs(diff) < 1e-15:
            break
        mask = (h < 1.0 - 1e-10) if diff > 0 else (h > 1e-10)
        cnt = float(np.sum(mask))
        if cnt == 0:
            break
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-14:
        # Distribute among closest to boundary
        if diff > 0:
            idx = np.argsort(h)[-int(abs(diff)):] if abs(diff) < n else np.argsort(h)[-1:]
        else:
            idx = np.argsort(h)[:int(abs(diff))] if abs(diff) < n else np.argsort(h)[:1]
        h[idx] += diff / len(idx) if len(idx) > 1 else diff
        h = np.clip(h, 0.0, 1.0)
        # Final fix
        diff = target - np.sum(h)
        if abs(diff) > 1e-15:
            j = int(np.argmin(h)) if diff > 0 else int(np.argmax(h))
            h[j] += diff
            h = np.clip(h, 0.0, 1.0)
    return h

def smooth_max_gradient(h, n, corr_vals, T, top_k=10):
    top_idx = np.argsort(corr_vals)[-top_k:]
    c = corr_vals[top_idx]
    mc = np.max(c)
    weights = np.exp(T * (c - mc))
    sum_w = np.sum(weights)
    if sum_w == 0:
        return np.zeros(n)
    weights /= sum_w
    
    grad = np.zeros(n)
    for i, idx in enumerate(top_idx):
        s = int(idx - (n - 1))
        w = weights[i]
        if s >= 0:
            if s < n:
                grad[s:] += w * (1.0 - h[:n-s])
            if n - s > 0:
                grad[:n-s] -= w * h[s:]
        else:
            t = -s
            if t < n:
                grad[:n-t] += w * (1.0 - h[t:])
            if n - t > 0:
                grad[t:] -= w * h[:n-t]
    return grad

def subgradient_opt(h, n, time_limit, start_time, T_start=100, T_end=10000, top_k=10, max_iter=20000):
    best_h = h.copy()
    best_c5, _ = compute_c5_full(h)
    step = 0.1 / n
    mom = 0.85
    vel = np.zeros(n)
    no_imp = 0
    
    for it in range(max_iter):
        if time.time() - start_time > time_limit:
            break
        frac = min(1.0, it / max_iter)
        T = T_start * (T_end / T_start) ** frac
        
        c5_cur, corr_vals = compute_c5_full(h)
        if c5_cur < best_c5 - 1e-14:
            best_c5 = c5_cur
            best_h = h.copy()
            no_imp = 0
        else:
            no_imp += 1
        
        if no_imp > 500:
            step *= 0.5
            if step < 1e-10:

            no_imp = 0
            vel = np.zeros(n)
        
        grad = smooth_max_gradient(h, n, corr_vals, T, top_k)
        
        # Nesterov
        y = np.clip(h - mom * vel, 0, 1)
        _, y_corr = compute_c5_full(y)
        y_grad = smooth_max_gradient(y, n, y_corr, T, top_k)
        vel = mom * vel - step * y_grad
        nh = h + vel
        nh = make_feasible(nh, n)
        
        nc5, _ = compute_c5_full(nh)

                vel *= 0.3

    fh = make_feasible(h, n)
    fc5, _ = compute_c5_full(fh)
    if fc5 < best_c5:
        best_h, best_c5 = fh, fc5
    return best_h, best_c5

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5_full(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx, corr * dx

def make_feasible(h, n):
    h = np.clip(h.astype(float).copy(), 0.0, 1.0)
    target = n / 2.0
    for _ in range(300):
        diff = target - np.sum(h)
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            mask = (h < 1.0 - 1e-12)
        else:
            mask = (h > 1e-12)
        cnt = float(np.sum(mask))
        if cnt == 0:
            break
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-14:
        if diff > 0:
            idx = int(np.argmin(h))
        else:
            idx = int(np.argmax(h))
        h[idx] += diff
        h = np.clip(h, 0.0, 1.0)
    return h

def smooth_max_grad(h, n, corr_vals, T, top_k=10):
    top_idx = np.argsort(corr_vals)[-top_k:]
    c = corr_vals[top_idx]
    mc = float(np.max(c))
    exps = np.exp(T * (c - mc))
    sw = np.sum(exps)
    if sw == 0:
        return np.zeros(n)
    w = exps / sw
    grad = np.zeros(n)
    for i in range(len(top_idx)):
        s = int(top_idx[i] - (n - 1))
        wi = w[i]
        if s >= 0:
            if s < n:
                grad[s:] += wi * (1.0 - h[:n-s])
            if n - s > 0:
                grad[:n-s] -= wi * h[s:]
        else:
            t = -s
            if t < n:
                grad[:n-t] += wi * (1.0 - h[t:])
            if n - t > 0:
                grad[t:] -= wi * h[:n-t]
    return grad

def subgrad_opt(h, n, time_limit, start_time, T0=50, T1=8000, top_k=10, max_it=50000):

    for it in range(max_it):

        T = T0 * (T1 / T0) ** frac
        c5_cur, cv = compute_c5_full(h)
        if c5_cur < best_c5 - 1e-14:
            best_c5 = c5_cur
            best_h = h.copy()
            no_imp = 0
        else:
            no_imp += 1
        if no_imp > 800:
            step *= 0.5
            vel *= 0.1
            if step < 1e-11:
                break
            no_imp = 0
        g = smooth_max_grad(h, n, cv, T, top_k)
        y = np.clip(h - mom * vel, 0.0, 1.0)
        _, yv = compute_c5_full(y)
        yg = smooth_max_grad(y, n, yv, T, top_k)
        vel = mom * vel - step * yg
        nh = make_feasible(h + vel, n)
        nc5, _ = compute_c5_full(nh)
        if nc5 <= c5_cur + 1e-12:

        else:

def coord_refine(h, n, time_limit, start_time):
    best_h = h.copy()
    best_c5 = compute_c5_full(h)[0]
    steps = [0.01, 0.005, 0.002, 0.001, 0.0005]
    improved = True
    while improved and time.time() - start_time < time_limit:
        improved = False
        for j in range(n):
            if time.time() - start_time > time_limit:
                break
            ov = best_h[j]
            bc = best_c5
            bv = ov
            for s in steps:
                for sg in [-1.0, 1.0]:
                    v = ov + sg * s
                    if 0.0 <= v <= 1.0 and abs(v - ov) > 1e-10:
                        tr = best_h.copy()
                        tr[j] = v
                        tr = make_feasible(tr, n)
                        c = compute_c5_full(tr)[0]
                        if c < bc - 1e-14:
                            bc = c
                            bv = v
            for v in [0.0, 1.0]:
                if abs(v - ov) > 1e-6:
                    tr = best_h.copy()
                    tr[j] = v
                    tr = make_feasible(tr, n)
                    c = compute_c5_full(tr)[0]
                    if c < bc - 1e-14:
                        bc = c
                        bv = v
            if bv != ov:
                best_h[j] = bv
                best_h = make_feasible(best_h, n)
                best_c5 = bc
                improved = True
    return best_h, best_c5

def slsqp_polish(h, n, time_limit, start_time, T=2000.0, top_m=None):
    dx = 2.0 / n
    def obj(x):
        corr = np.correlate(x, 1.0 - x, mode='full') * dx
        if top_m is not None and top_m < len(corr):
            ti = np.argsort(corr)[-top_m:]
            mc = np.max(corr[ti])
            sh = corr[ti] - mc
            return mc + np.log(np.sum(np.exp(T * sh))) / T
        mc = np.max(corr)
        sh = corr - mc
        return mc + np.log(np.sum(np.exp(T * sh))) / T
    def conf(x):
        return np.sum(x) - n / 2.0
    def conj(x):
        return np.ones(n)
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': conf, 'jac': conj}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': 300, 'ftol': 1e-18})
        c5r = compute_c5_full(res.x)[0]
        if c5r < compute_c5_full(h)[0]:
            return make_feasible(res.x, n), c5r
    except Exception:
        pass
    return h, compute_c5_full(h)[0]
