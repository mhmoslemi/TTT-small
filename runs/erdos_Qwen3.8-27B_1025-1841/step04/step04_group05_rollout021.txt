Let me think about the projected gradient descent more carefully.

The smoothed objective:
F_T(h) = (max(corr) + (1/T) * log(sum(exp(T*(corr - max(corr)))))) * dx

Gradient:
∇F_T(h)[i] = dx * sum_m p[m] * ∂corr[m]/∂h[i]
where p[m] = exp(T*(corr[m]-max(corr))) / sum(exp(T*(corr-max(corr))))

And ∂corr[m]/∂h[i] = (1-h[i+k_m]) - h[i-k_m] (with out-of-range = 0)

So ∇F_T(h)[i] = dx * [sum_m p[m]*(1-h[i+k_m]) - sum_m p[m]*h[i-k_m]]

Let me define:
A[i] = sum_m p[m]*h[i+k_m]  (correlation-like quantity)
B[i] = sum_m p[m]*h[i-k_m]  (another correlation-like quantity)

Then ∇F_T(h)[i] = dx * [(sum_m p[m] - A[i]) - B[i]] = dx * [1 - A[i] - B[i]]

(I'm using sum_m p[m] = 1 since p is a probability distribution)

Now, A and B can be computed as:
A[i] = sum_m p[m]*h[i+(m-(N-1))]
B[i] = sum_m p[m]*h[i-(m-(N-1))]

These are cross-correlations of p (length 2N-1) with h (length N), but with non-standard indexing.

Let me use the following approach: 
- Create a "centered" version of p: p_c has length 2N-1, with p_c[N-1] = p[N-1] (the zero-lag weight)
- A[i] = sum_{k=-(N-1)}^{N-1} p_c[N-1+k] * h[i+k] (where h out of range = 0)
- B[i] = sum_{k=-(N-1)}^{N-1} p_c[N-1+k] * h[i-k] (where h out of range = 0)

For computation, I'll use the following trick:
- Pad h to length 3N-2 (with zeros)
- A[i] is a "sliding dot product" of p_c with the window of h centered at position i+N-1 in the padded array
- This is a cross-correlation, computable with `np.correlate` or FFT

Specifically:
- h_pad = [0, 0, ..., 0, h[0], h[1], ..., h[N-1], 0, 0, ..., 0] (length 3N-2)
- A[i] = sum_k p_c[k]*h_pad[N-1+i+k-N+1] = sum_k p_c[k]*h_pad[i+k+N-1]

```python
def compute_AB(h, p, N):
    """Compute A[i] = sum_m p[m]*h[i+m-(N-1)] and B[i] = sum_m p[m]*h[i-m+(N-1)]"""
    # A[i]: for each i, weighted sum of h at positions i+m-(N-1) for m=0..2N-2
    # This is a convolution of p (reversed) with h, evaluated at specific positions
    
    # Using FFT:
    fsize = 1
    while fsize < 2*N:
        fsize *= 2
    
    # A[i] = sum_m p[m]*h[i+m-(N-1)]
    # Let's define q[m] = p[2N-2-m] (reverse of p)
    # Then A[i] = sum_m q[2N-2-m]*h[i+m-(N-1)]
    # = sum_m q[m]*h[i+(2N-2-m)-(N-1)]
    # = sum_m q[m]*h[i+N-1-m]
    # = (q * h)[i+N-1] (linear convolution of q and h)
    
    q = p[::-1]
    Q = np.fft.rfft(q, fsize)
    H = np.fft.rfft(h, fsize)
    conv_qh = np.fft.irfft(Q * H, fsize)
    A = conv_qh[N-1:N-1+N]
    
    # B[i] = sum_m p[m]*h[i-m+(N-1)]
    # = sum_m p[m]*h[(i+(N-1))-m]
    # = (p * h)[i+N-1] (linear convolution of p and h)
    
    P = np.fft.rfft(p, fsize)
    conv_ph = np.fft.irfft(P * H, fsize)
    B = conv_ph[N-1:N-1+N]
    
    return A, B
```

One more consideration: the projection step. After taking a gradient step z = h - lr * grad, I need to project z onto the set {h : 0 ≤ h[i] ≤ 1, sum(h) = N/2}.

The projection is: h_proj = clip(z - tau, 0, 1) where tau is chosen so that sum(h_proj) = N/2.

Finding tau: this is a 1D root-finding problem. Since sum(clip(z-tau, 0, 1)) is a monotone decreasing function of tau, I can use bisection.

```python
def project_to_simplex_with_bounds(z, target_sum):
    """Project z onto {h: 0<=h[i]<=1, sum(h)=target_sum}"""
    lo, hi = z.min() - 1, z.max() + 1
    for _ in range(60):
        mid = (lo + hi) / 2
        s = np.sum(np.clip(z - mid, 0, 1))
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(z - (lo+hi)/2, 0, 1)
```

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_feasible(h, n):
    h = np.clip(np.asarray(h, dtype=float), 0.0, 1.0).copy()
    target = n / 2.0
    diff = target - np.sum(h)
    if abs(diff) < 1e-12:
        return h
    # Distribute the difference
    if diff > 0:
        mask = h < 1.0 - 1e-10
    else:
        mask = h > 1e-10
    cnt = np.sum(mask)
    if cnt == 0:
        return h
    step = diff / cnt
    h[mask] = np.clip(h[mask] + step, 0.0, 1.0)
    # Fix any remaining error
    remaining = target - np.sum(h)
    if abs(remaining) > 1e-10:
        idx = np.argmin(h) if remaining > 0 else np.argmax(h)
        h[idx] = np.clip(h[idx] + remaining, 0.0, 1.0)
    return h

def upsample_h(h, new_n):
    old_n = len(h)
    if new_n == old_n:
        return make_feasible(h.copy(), new_n)
    old_x = np.linspace(0.0, 2.0, old_n, endpoint=False)
    new_x = np.linspace(0.0, 2.0, new_n, endpoint=False)
    h_new = np.interp(new_x, old_x, h, period=2.0)
    return make_feasible(h_new, new_n)
