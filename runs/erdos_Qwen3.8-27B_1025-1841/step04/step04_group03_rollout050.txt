Wait for binary h: 1-h[i+k] is either 0 or 1.
- h[i] was 1, now 0: 
  - In count_k, the term h[i]*(1-h[i+k]) was (1-h[i+k]), now 0. Change: -(1-h[i+k])
  - The term h[i-k]*(1-h[i]) was h[i-k]*0=0, now h[i-k]*1=h[i-k]. Change: +h[i-k]
- h[j] was 0, now 1:

  - The term h[j-k]*(1-h[j]) was h[j-k]*1=h[j-k], now h[j-k]*0=0. Change: -h[j-k]

Total Δcount_k = -(1-h[i+k]) + h[i-k] + (1-h[j+k]) - h[j-k]

For this to be useful, we want the max count to decrease. If count_{k*} is currently the maximum, we want Δcount_{k*} < 0.

A **greedy approach**: For each 1→0 flip position i, find the j (0→1) that minimizes the resulting max. This is O(n²) per i, or O(n³) total. Too slow for n=4000.

For each j (0→1), compute the "benefit vector" b_j[k] = (1-h[j+k]) - h[j-k].
The new max is max_k (count_k + d_i[k] + b_j[k]).

We want to find (i,j) that minimizes this max. This is still O(n³) in the worst case.

Compromise: For the worst lag k*, find the best (i,j) swap that minimizes count_{k*} + d_i[k*] + b_j[k*]. This is O(n²) total (for each i, find best j). Then check if the overall max doesn't increase.

+h[i-k*] is +1 when h[i-k*]=1, and 0 when h[i-k*]=0.

-h[j-k*] is -1 when h[j-k*]=1, and 0 when h[j-k*]=0.

Worst case (most positive): h[i+k*]=1, h[i-k*]=1, h[j+k*]=0, h[j-k*]=0 → Δ = 0+1+1-0 = +2

So the swap can change count_{k*} by at most ±2.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx), corr

def make_feasible(h, n):
    h = np.clip(h.astype(float).copy(), 0.0, 1.0)
    target = n / 2.0
    for _ in range(500):
        diff = target - np.sum(h)
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        cnt = np.sum(mask)
        if cnt == 0:
            break
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

# SLSQP objective with log-sum-exp smooth max
def make_slsqp_obj(n, T):
    def obj(x):
        corr = np.correlate(x, 1.0 - x, mode='full')
        mc = np.max(corr)
        # Stable log-sum-exp
        shifted = corr - mc
        logsum = mc + np.log(np.sum(np.exp(T * shifted))) / T
        return logsum * (2.0 / n)
    return obj

def slsqp_step(h, n, T, maxiter, ftol, time_limit, start_time):
    remaining = time_limit - (time.time() - start_time)
    if remaining < 10:
        return h
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x: np.sum(x) - n/2.0,
             'jac': lambda x: np.ones(n)}]
    obj_fn = make_slsqp_obj(n, T)
    try:
        res = minimize(obj_fn, h.copy(), method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': ftol})
        if res.success or res.fun < obj_fn(h):
            return make_feasible(res.x, n)
    except Exception:
        pass
    return h

def greedy_binary_swap(h, n, start_time, time_limit, max_sweeps=100):
    """Greedy swap for binary (or near-binary) h."""
    b = (h >= 0.5).astype(float)
    # Ensure exactly n//2 ones
    n_ones = int(np.sum(b))
    target = n // 2
    if n_ones > target:
        idx = np.where(b == 1)[0]
        for k in range(n_ones - target):
            b[idx[k]] = 0
    elif n_ones < target:
        idx = np.where(b == 0)[0]
        for k in range(target - n_ones):
            b[idx[k]] = 1
    
    curr_c5 = compute_c5(b)[0]
    best_c5 = curr_c5
    best_b = b.copy()
    
    for sweep in range(max_sweeps):
        if time.time() - start_time > time_limit:
            break
        corr = np.correlate(b, 1.0 - b, mode='full')
        max_idx = np.argmax(corr)
        k_max = max_idx - (len(b) - 1)  # actual lag
        curr_max_val = corr[max_idx]
        
        ones = np.where(b == 1)[0]
        zeros = np.where(b == 0)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        best_delta = 0
        best_i, best_j = -1, -1
        
        # For the worst lag, find best swap
        # Δcount at lag k_max for swap (i: 1→0, j: 0→1):
        # = -(1-b[i+k]) + b[i-k] + (1-b[j+k]) - b[j-k]
        # where k = k_max (the actual shift)
        k = k_max
        for i in ones:
            ipk = i + k
            imk = i - k
            term_i = 0.0
            if 0 <= ipk < n:
                term_i -= (1.0 - b[ipk])
            if 0 <= imk < n:
                term_i += b[imk]
            
            # Vectorized over j:
            jpk = zeros + k
            jmk = zeros - k
            term_j = np.zeros(len(zeros))
            valid_p = (jpk >= 0) & (jpk < n)
            valid_m = (jmk >= 0) & (jmk < n)
            term_j[valid_p] += (1.0 - b[jpk[valid_p]])
            term_j[valid_m] -= b[jmk[valid_m]]
            
            deltas = term_i + term_j
            idx = np.argmin(deltas)
            if deltas[idx] < best_delta:
                best_delta = deltas[idx]
                best_i = i
                best_j = zeros[idx]
        
        if best_i < 0 or best_delta >= 0:
            break
        
        # Apply swap
        b[best_i] = 0
        b[best_j] = 1
        
        new_c5 = compute_c5(b)[0]
        if new_c5 < curr_c5:
            curr_c5 = new_c5
            if new_c5 < best_c5:
                best_c5 = new_c5
                best_b = b.copy()
        else:
            # Revert
            b[best_i] = 1
            b[best_j] = 0
            break
    
    return best_b, best_c5
