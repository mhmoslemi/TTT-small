Actually, for coordinate descent, the standard approach is:

- This is a 1D optimization problem

The 1D function is:
f_j(v) = soft_max(corr with h[j]=v)

Since corr changes linearly with h[j] (each corr_k changes by ∂corr_k/∂h[j] * (v - h[j])), we can compute f_j(v) efficiently.

For the soft-max objective, f_j(v) is a smooth function of v, and I can use scipy.optimize.minimize_scalar to find the minimum.

Actually, I can be smarter. Since corr_k changes linearly with v:
corr_k(v) = corr_k_current + (v - old) * d_k

where d_k = ∂corr_k/∂h[j] (computed once per coordinate).

Then f_j(v) = soft_max(corr_k_current + (v-old)*d_k) * dx

This is a function of one variable v, and I can evaluate it in O(K) time (over selected lags) or O(n) time (over all lags).

            for val in (0.0, 1.0):
                if abs(best_h[j] - val) < 1e-8:
                    continue
                trial = best_h.copy()
                trial[j] = val
                trial = _fix(trial, n_f)
                c = _c5(trial)
                if c < best_c - 1e-14:
                    best_c, best_h = c, trial

    best_h = _fix(best_h, len(best_h))
    best_c = _c5(best_h)
    return best_h, best_c, len(best_h)
