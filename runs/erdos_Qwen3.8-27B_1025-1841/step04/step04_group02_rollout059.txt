    best_c5 = curr_c5
    best_h = h.copy()
    dx = 2.0 / n

        if time.time() - start_time > budget_s - 30:
            break
        
        c = corr_arr(h)
        peak_idx = int(np.argmax(c))
        d = peak_idx - (n - 1)
        peak_val = c[peak_idx]
        
        # Compute subgradient: dc/dh at peak lag
        # c[peak] = sum_i h[i] * (1-h[i+d]) (for d >= 0)
        # dc/dh[i] = (1-h[i+d]) for the h[i] term, and -h[i-d] for the h[i+d] term
        # (when i+d is in range)
        
        grad = np.zeros(n)
        if d >= 0:
            for i in range(n - d):
                grad[i] += (1 - h[i + d])  # derivative w.r.t. h[i]
                grad[i + d] += -h[i]       # derivative w.r.t. h[i+d]
        else:

                grad[i + da] += (1 - h[i])  # derivative w.r.t. h[i+da]
                grad[i] += -h[i + da]       # derivative w.r.t. h[i]

        h_new = h - step_size * grad
        h_new = np.clip(h_new, 0, 1)

            curr_c5 = new_c5

                best_c5 = new_c5
                best_h = h.copy()
            # Decrease step size
            step_size *= 0.98
        else:
            step_size *= 0.95
            if step_size < 1e-8:
                break
    
    return best_h, best_c5

Actually, I can make it faster by exploiting the structure. When I flip positions i (1→0) and j (0→1), the correlation only changes at specific lags. The change in the full correlation vector is:

Old: b[i]=1, b[j]=0
New: b[i]=0, b[j]=1

Change in corr at lag d (where corr[d] = ∑ b[k]*(1-b[k+d])):
- For the pair (i, i+d): old contribution was 1*(1-b[i+d]), new is 0*(1-b[i+d]) = 0. Change: -(1-b[i+d])
- For the pair (j, j+d): old was 0*(1-b[j+d]) = 0, new is 1*(1-b[j+d]). Change: +(1-b[j+d])
- For the pair (i-d, i): old was b[i-d]*(1-1) = 0, new is b[i-d]*(1-0) = b[i-d]. Change: +b[i-d]
- For the pair (j-d, j): old was b[j-d]*(1-0) = b[j-d], new is b[j-d]*(1-1) = 0. Change: -b[j-d]

So the total change in corr at lag d is:
Δcorr[d] = -(1-b[i+d]) + (1-b[j+d]) + b[i-d] - b[j-d]

This is O(1) per lag! But there are O(n) lags total. So computing the full new correlation is O(n), which is the same as before.

But I can compute just the new max in O(n) by updating: new_corr = old_corr + Δcorr, where Δcorr is O(n) to compute.
