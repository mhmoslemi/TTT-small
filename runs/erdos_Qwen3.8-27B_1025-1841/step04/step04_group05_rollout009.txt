Let me think about this differently. For the 'full' correlation:
- Element m (0-indexed, m in [0, 2n-2])
- tau = m - (n-1) in [-(n-1), n-1]
- The overlap has (n - |tau|) elements

The gradient ∂c[m]/∂h[j] is non-zero only for j in the overlap region (and adjacent elements). Specifically, for tau > 0:
- j ranges from 0 to n-1-tau for the h[i] part
- j ranges from tau to n-1 for the h[i+tau] part
- Union: 0 to n-1 (all j), but with different formulas in different regions

Actually, for any j in [0, n-1], the derivative is:
- (1-h[j-tau]) if tau ≤ j ≤ n-1 (from the h[i+tau] term)
- -h[j+tau] if 0 ≤ j ≤ n-1-tau (from the (1-h[i]) term)
- 0 otherwise

These two conditions overlap for tau ≤ j ≤ n-1-tau (when tau ≤ (n-1)/2).

So the derivative is:
For j in [0, tau-1]: -h[j+tau]
For j in [tau, n-1-tau]: (1-h[j-tau]) - h[j+tau]
For j in [n-tau, n-1]: (1-h[j-tau])
For tau = 0: 1 - 2h[j]

For tau < 0 (tp = -tau):
For j in [0, tp-1]: -h[j+tp]
For j in [tp, n-1-tp]: (1-h[j-tp]) - h[j+tp]
For j in [n-tp, n-1]: (1-h[j-tp])

This is a banded structure! For each tau, the derivative vector is:
- -h shifted by tau (with truncation) + (1-h) shifted by -tau (with truncation)

So the full gradient g[j] = sum_tau w[tau] * (the above) can be computed as:
g[j] = sum_{tau>0} w[tau] * ((1-h[j-tau])*1[tau≤j≤n-1] - h[j+tau]*1[0≤j≤n-1-tau])
     + sum_{tau<0} w[tau] * ((1-h[j+|tau|])*1[|tau|≤j≤n-1] - h[j-|tau|]*1[0≤j≤n-1-|tau|])
     + w[0] * (1 - 2h[j])

This is EXACTLY (no approximation!) a weighted sum of shifted copies of h and 1-h, with truncation.

The truncation is the issue. For the non-truncated (circular) version, it's just a convolution. The truncation affects O(tau) elements at each boundary, totaling O(n^2) affected elements across all taus. But for the weighted sum, only the weights w[tau] matter, and for high T, only a few taus have significant weight.

For high T (say T=1000), the softmax weights are concentrated within O(1/√T) of the max. If the max is at tau* = 0 (or some central value), then only O(√n/T) taus have significant weight, and the boundary effects are negligible (since those small taus don't reach the boundary).

So for high T, the circular approximation is essentially exact!

- For T < 100, either skip or use direct computation

def compute_c5(h):

    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_feasible(h, n):
    h = np.clip(np.asarray(h, dtype=float), 0.0, 1.0).copy()
    target = n / 2.0
    for _ in range(100):
        diff = target - np.sum(h)
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-14
        else:
            mask = h > 1e-14
        cnt = np.sum(mask)
        if cnt == 0:
            break
        step = diff / cnt
        h[mask] = np.clip(h[mask] + step, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-13:
        idx = np.argmin(h) if diff > 0 else np.argmax(h)
        h[idx] = np.clip(h[idx] + diff, 0.0, 1.0)
    return h

def upsample_h(h, new_n):
    old_n = len(h)
    if new_n == old_n:
        return make_feasible(h.copy(), new_n)
    old_x = np.linspace(0.0, 2.0, old_n, endpoint=False)
    new_x = np.linspace(0.0, 2.0, new_n, endpoint=False)
    h_new = np.interp(new_x, old_x, h, period=2.0)
    return make_feasible(h_new, new_n)

def exact_grad(h, T, n, k=30):
    """Exact gradient of smoothed max using top-k weighting."""
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    mc = np.max(corr)
    shifted = corr - mc
    exps = np.exp(T * shifted)
    s = np.sum(exps)
    soft_val = (mc + np.log(s) / T) * dx
    weights = exps / s
    
    g = np.zeros(n)
    # Use top-k indices
    top_idx = np.argsort(weights)[-k:]
    for m in top_idx:
        w_m = weights[m]
        if w_m < 1e-12:
            continue
        tau = m - (n - 1)
        if tau >= 0:
            # g[0:n-tau] += -w_m * h[tau:n]
            if n - tau > 0:
                g[:n-tau] -= w_m * h[tau:]
            # g[tau:n] += w_m * (1-h[0:n-tau])
            if tau < n:
                g[tau:] += w_m * (1.0 - h[:n-tau])
        else:
            tp = -tau
            # g[0:n-tp] += -w_m * h[tp:n]
            if n - tp > 0:

            # g[tp:n] += w_m * (1-h[0:n-tp])
            if tp < n:
                g[tp:] += w_m * (1.0 - h[:n-tp])
    
    g *= dx
    return soft_val, g

        h = h_new
    
    # Return the best found
    c_final = compute_c5(h)
    if c_final < best_c:
        best_c = c_final
    return h, best_c
