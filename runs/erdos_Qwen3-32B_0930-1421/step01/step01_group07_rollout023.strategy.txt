      if i + lag < n_points: grad[i] += (1 - h[i + lag])
      if i - lag >= 0: grad[i] -= h[i - lag]
   v. Normalize gradient: grad = grad / np.linalg.norm(grad)
   vi. Line search step size α using backtracking
   vii. Update h: h = h - α * grad
   viii. Project h into feasible region:
      1. Clip h to [0,1]
      2. Rescale to meet sum constraint:
         if sum_h != n/2, h *= (n/2) / sum_h
         repeat clipping and scaling until convergence
   ix. Track best_h and best_c5

4. Search choices and useful variations
   - Initial step size α=1e-3, decrease by 0.5 on overflow, increase by 1.1 on success.
   - Backtracking: reduce α by 0.5 until improvement or min α=1e-6
   - Perturb h with noise every 500 iterations to escape local minima
   - Track move history to avoid repeating states

Dominant cost: O(n²) per iteration for n=80 => ~6.4e6 operations. With 1e5 iterations, ~6.4e11 operations; infeasible. Thus, limit to n=80 with 10k iterations (~1000s) using efficient numpy.
