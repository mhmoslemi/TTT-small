So C₅ = max_k (1 - |S ∩ (S-k)|) = 1 - min_k |S ∩ (S-k)|.

To minimize C₅, we want to maximize min_k |S ∩ (S-k)|.

For a binary solution, the answer is 1 - max_k |S \ (S-k)|.

The question becomes: what set S ⊂ [0,2] of measure 1 maximizes the minimum autocorrelation?

This is a classic problem in additive combinatorics / harmonic analysis.

For the continuous case, I believe the optimal set is related to a "thin" set or a set with some self-similar structure.

Actually, for the discrete case (which is what we're solving), let me think about it differently.

With n=80 grid points, h is a vector of 80 values in [0,1] with sum 40. The correlation at lag k (for k ≥ 1) is:
sum_{i=0}^{n-1-k} h[i] * (1 - h[i+k])

We want to minimize the maximum of these (over all non-zero lags).

For a binary solution (h[i] ∈ {0,1}, exactly 40 ones), this becomes:
count of i where h[i]=1 and h[i+k]=0

For a random binary sequence with 40 ones and 40 zeros, the expected count at any lag is approximately 40*40/80 = 20 (for small lags where the overlap is approximately 80 positions). So the expected C₅ ≈ 20 * (2/80) = 0.5.

To do better, we need structure. The Sierpinski-like or "Thue-Morse" sequences have good equidistribution properties.

Actually, the Thue-Morse sequence! It's a 2-adic sequence where t(n) = parity of number of 1s in binary expansion of n. It has the property that for any k, the autocorrelation is bounded.

But we need exactly 40 ones in 80 positions. The first 80 Thue-Morse bits have exactly 40 ones (by self-similarity). Let me check: the Thue-Morse sequence has 2^{m-1} ones in the first 2^m positions. For 80 positions... 80 is not a power of 2. The first 64 positions have 32 ones, and positions 64-79: t(64)=0, t(65)=1, t(66)=1, t(67)=0, t(68)=1, t(69)=0, t(70)=0, t(71)=1, t(72)=1, t(73)=0, t(74)=0, t(75)=1. That's 6 ones in positions 64-79. Total: 32+6=38. Not 40.

So a pure Thue-Morse prefix doesn't give exactly 40 ones. We'd need to modify it.

Let me think of another approach. What about a "balanced" sequence where ones and zeros alternate as much as possible?

The simplest: h = [1,0,1,0,...,1,0] (alternating). This has 40 ones and 40 zeros.
For lag k=1: count of i where h[i]=1 and h[i+1]=0 = 40 (every 1 is followed by 0)
For lag k=2: h[i]=1 and h[i+2]=0: h[i+2]=h[i] (period 2), so count = 0
For lag k=3: same as lag 1, count = 40
So max count = 40, C₅ = 40 * 2/80 = 1.0. Terrible!

What about blocks of 2: [1,1,0,0,1,1,0,0,...]?
For lag 1: h[i]=1, h[i+1]=0: positions 1,3,5,...(0-indexed: 1,5,9,...) → 20 ones followed by 0
Actually let me count: pattern is (1,1,0,0) repeated 20 times.
- Lag 1: h[i]=1, h[i+1]=0. In each block of 4: position 1 (1→0). So 20 times.
- Lag 2: h[i]=1, h[i+2]=0. In each block: position 0 (1→0 at pos 2). So 20 times.
- Lag 3: h[i]=1, h[i+3]=0. In each block: position 0 (1→0 at pos 3), position 1 (1→? at pos 0 of next block = 1). So 20 times.
- Lag 4: h[i]=1, h[i+4]=1 (same pattern). Count = 0.
- Lag 5: same as lag 1. Count = 20.

Max = 20, C₅ = 20*2/80 = 0.5. Still the same as random.

import time

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(h, target_sum):
    h = np.clip(h, 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        if not np.any(mask):
            break
        step = diff / np.sum(mask)
        h[mask] += step
        h = np.clip(h, 0.0, 1.0)
    return h

def smooth_max(vals, beta):
    m = np.max(vals)
    return float(m + beta * np.log(np.sum(np.exp((vals - m) / beta))))

def objective_smooth(h, beta):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode="full")
    vals = corr * dx
    return smooth_max(vals, beta)

def try_slsqp(h0, target_sum, beta, maxiter, t0, budget_s):
    n = len(h0)
    cons = [{'type': 'eq',
             'fun': lambda x, ts=target_sum: np.sum(x) - ts,
             'jac': lambda x: np.ones(n)}]
    bounds = [(0.0, 1.0)] * n
    res = minimize(lambda x: objective_smooth(x, beta), h0,
                   method='SLSQP', bounds=bounds, constraints=cons,
                   options={'maxiter': maxiter, 'ftol': 1e-14})
    h_new = project_feasible(res.x, target_sum)
    return h_new

def local_search(h0, target_sum, rng, max_iters, t0, budget_s):

    h = h0.copy()
    c5 = compute_c5(h)
    step = 0.05
    for it in range(max_iters):
        if time.time() - t0 > budget_s - 10:

        i = rng.integers(0, n)
        j = rng.integers(0, n)
        if i == j:

        h_trial = h.copy()
        h_trial[i] = np.clip(h_trial[i] + delta, 0.0, 1.0)
        h_trial[j] = np.clip(h_trial[j] - delta, 0.0, 1.0)
        h_trial = project_feasible(h_trial, target_sum)
        c5_trial = compute_c5(h_trial)
        if c5_trial < c5 - 1e-12:
            h = h_trial
            c5 = c5_trial
            step = min(step * 1.05, 0.2)
        else:
            step *= 0.95
    return h, c5
