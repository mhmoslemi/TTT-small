The Erdős minimum overlap problem: we want a function h on [0,2] with integral 1, such that for all k, the integral of h(x)(1-h(x+k)) is minimized in the max sense.

This is related to the problem of finding a set of measure 1 in [0,2] that has minimum "self-overlap" with its complement at any shift.

One classical construction is based on the "Fibonacci" or "Beatty sequence" type constructions, but for continuous case, the optimal solution might have a specific structure.

For the discrete case, the optimal h might be a sequence of 0s and 1s (a step function taking only values 0 and 1). If h only takes values 0 and 1, then h(x)(1-h(x+k)) is 1 when h(x)=1 and h(x+k)=0, and 0 otherwise. So the overlap integral becomes the measure of the set {x : h(x)=1, h(x+k)=0}.

For a binary h with sum = n/2 (so half the points are 1), the overlap at lag k is the number of positions where h has a 1 followed by a 0 at distance k (times dx).

This is exactly the "cross-correlation" between h and its complement at lag k.

For a binary sequence, minimizing the maximum cross-correlation with the complement is related to "Golay sequences" or "low autocorrelation sequences" but with the complement.

Actually, this is related to the concept of "bent functions" in coding theory, or more precisely, "dual-bent" or "planar functions".

But for the continuous/relaxed case (h can take values in [0,1]), the solution might be smoother.

k=3: i=0: a*s, i=1: b*r, i=2: c*q → a*s+b*r+c*q
k=4: i=0: a*t, i=1: b*s, i=2: c*r → a*t+b*s+c*r
k=5: i=1: b*t, i=2: c*s → b*t+c*s
k=6: i=2: c*t → c*t

B[0] = p*c + q*b + r*a = c*p + b*q + a*r = conv[2] ✓ (m+(n-1) = 0+2 = 2)
B[1] = q*c + r*b + s*a = c*q + b*r + a*s = conv[3] ✓ (m+(n-1) = 1+2 = 3)
B[2] = r*c + s*b + t*a = c*r + b*s + a*t = conv[4] ✓ (m+(n-1) = 2+2 = 4)

So: **B[m] = np.convolve(h, w, mode='full')[m + (n-1)]**

And: **A[m] = np.correlate(h, w, mode='full')[m + (n-1)]**

Therefore:
**∇L[m] = 1 - np.correlate(h, w, 'full')[m+(n-1)] - np.convolve(h, w, 'full')[m+(n-1)]**

This is great! I can compute the gradient efficiently using one correlation and one convolution.

Now, for the penalty term: P(h) = λ * (sum(h) - n/2)²
∇P[h] = 2λ * (sum(h) - n/2) * ones(n)

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    dx = 2.0 / len(h)
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    return float(np.max(corr))

def project_h(h, target_sum):
    h = np.clip(h, 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-10:
        return h
    # Water-filling projection
    if diff > 0:
        # Need to increase sum: add to elements not at 1
        order = np.argsort(h)  # ascending, so end elements are closest to 1
        for idx in reversed(order):
            room = 1.0 - h[idx]
            add = min(room, diff)
            h[idx] += add
            diff -= add
            if diff <= 0:
                break
    else:
        # Need to decrease sum: subtract from elements not at 0
        order = np.argsort(h)  # ascending, so start elements are closest to 0
        for idx in order:
            room = h[idx]
            sub = min(room, -diff)
            h[idx] -= sub
            diff += sub
            if diff >= 0:
                break
    return np.clip(h, 0.0, 1.0)

def lse_and_weights(c, T):
    """Compute log-sum-exp value and softmax weights."""
    max_c = np.max(c)
    shifted = (c - max_c) / T
    log_sum = np.log(np.sum(np.exp(-shifted)))
    L = max_c - T * log_sum  # = -T * log(sum(exp(-c/T)))... wait
    # Actually: -T * log(sum(exp(-c/T)))
    # = -T * log(sum(exp(-(c-max_c)/T) * exp(-max_c/T)))
    # = -T * (-max_c/T + log(sum(exp(-(c-max_c)/T))))
    # = max_c - T * log(sum(exp(-(c-max_c)/T)))
    L = max_c - T * np.log(np.sum(np.exp(-(c - max_c) / T)))
    w = np.exp(-(c - max_c) / T)
    w /= np.sum(w)
    return L, w

def smooth_obj_grad(h, T, mu):
    """Objective and gradient for L-BFGS-B."""
    n = len(h)
    c = np.correlate(h, 1.0 - h, mode='full')
    L, w = lse_and_weights(c, T)
    
    # Gradient of LSE
    corr_part = np.correlate(h, w, 'full')[n-1:2*n-1]
    conv_part = np.convolve(h, w, 'full')[n-1:2*n-1]
    grad_L = 1.0 - corr_part - conv_part
    
    # Penalty gradient
    s = np.sum(h) - n * 0.5
    grad_P = 2.0 * mu * s * np.ones(n)
    
    val = L + mu * s * s
    grad = grad_L + grad_P
    return val, grad

def optimize_lbfgsb(h0, T, mu, max_iter=500, gtol=1e-8):
    n = len(h0)
    bounds = [(0.0, 1.0)] * n
    
    def obj(h):
        val, _ = smooth_obj_grad(h, T, mu)
        return val
    
    def grad(h):
        _, g = smooth_obj_grad(h, T, mu)
        return g
    
    res = minimize(obj, h0, jac=grad, method='L-BFGS-B',
                   bounds=bounds, options={'maxiter': max_iter, 'gtol': gtol})
    h_new = project_h(res.x, n * 0.5)
    return h_new, compute_c5(h_new)
