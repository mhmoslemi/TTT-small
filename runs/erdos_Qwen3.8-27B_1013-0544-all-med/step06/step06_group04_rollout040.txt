The subgradient of f(δ) at a point δ is the set {s_k : f(δ) = c_k + δ*s_k} (the active s_k's).
f is minimized where 0 is in the subgradient, i.e., where there exist active k's with both positive and negative s_k (or an active k with s_k = 0).

1. Start at δ = 0
2. Compute the active set: k_0 = argmax_k (c_k + 0*s_k) = argmax_k c_k

3. If max(active s_k) ≥ 0 and min(active s_k) ≤ 0, we're at the minimum
4. Otherwise, move in the direction of the subgradient:
   - If all active s_k > 0, move left (decrease δ)
   - If all active s_k < 0, move right (increase δ)
5. Find the next breakpoint (where the active set changes)

        i_lo = max(0, -lag)
