def project_feasible(h, target_sum):

        d = target_sum - h.sum()

def project_feasible(h, target_sum):

Since f(x) = max_k (a_k * x + b_k) is convex on [0,1], I can find its minimum efficiently:
1. Evaluate f(0) and f(1)
2. If f is decreasing at 0 (i.e., the active k at x=0 has a_k < 0), the minimum is to the right of 0
3. Binary search for the point where the active k changes

Actually, the simplest efficient approach:
1. At x=0, find k0 = argmax b_k (this is the active constraint at x=0)
2. At x=1, find k1 = argmax (a_k + b_k) (active at x=1)
3. If k0 == k1: the same constraint is active throughout, so f is linear, min is at 0 or 1
4. Otherwise: the minimum is at the intersection of the two lines, or at one of the endpoints

Wait, that's not quite right either. The minimum of a convex piecewise-linear function is at a "valley" point, which is either an endpoint or a kink (where the active constraint changes).

A better approach for the 1D minimization:
1. Start at x=0
2. Find the active k: k* = argmax (a_k * x + b_k)
3. If a_{k*} ≥ 0: f is non-decreasing at x, so minimum is at x (or to the left)
4. If a_{k*} < 0: f is decreasing at x, move right
   - Find the next x' > x where the active k changes: x' = min over k≠k* of (b_k - b_{k*}) / (a_{k*} - a_k) (where denominator > 0)
   - Set x = x' and repeat

This is O(n) per step and at most O(n) steps, so O(n²) total for the 1D problem. Combined with n coordinates, it's O(n³) per sweep. For n=384: about 56M per sweep. That's feasible for a few sweeps.
