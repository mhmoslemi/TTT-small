### Erdős Minimum Overlap Problem Optimization Strategy

#### 1. Approach and Rationale
The objective is to improve the upper bound for the Erdős minimum overlap problem constant C by finding a step function h(x) on [0, 2] that minimizes the maximum correlation integral C5. The previous record is 0.3808. Our approach combines multi-resolution optimization, gradient-based refinement, and global search with interpolation to find better solutions:

- **Multi-resolution optimization**: Evaluate the problem at different numbers of grid points (n) to identify the optimal resolution
- **Gradient-based refinement**: Use soft gradient descent with adaptive parameters to escape local optima
- **Global search**: Combine interpolation-based restarts from high-quality solutions with random binary restarts
- **Adaptive hyperparameter tuning**: Dynamically adjust learning rate, softness parameter, and restart thresholds to optimize convergence

This strategy addresses the non-convex optimization problem by combining local search (gradient projection) with exploration (restarts at different resolutions). The key bottleneck is the high-dimensional search space (hundreds of dimensions), which requires efficient exploration and exploitation.

#### 2. Mathematical Specification
**Variables and Representation**:
- h: Step function with n samples over [0, 2], satisfying 0 ≤ h[i] ≤ 1 and ∑h[i] = n/2 (integral=1)
- dx = 2/n: Grid spacing
- Objective: minimizes C5 = max_k (1/n) ∑_{i,j} h[i](1-h[j]) for |i-j| ≤ k (mode="full")

**Gradient Calculation**:
∂C5/∂h[i] ≈ (1/(k*dx)) * [∑_{j} (1-h[j]) * 1_{|i-j|≤k} - h[i] * ∑_{j} 1_{|i-j|≤k}]

**Constraints**:
- Bounds: 0 ≤ h[i] ≤ 1 for all i
- Integral: ∑h[i] = n/2

**Objective Transformation**:
C5 = (2/n) * max_{k} (∑h[i](1-h[i+k])) for i in [0,2n-1-k]

**Feasibility Projection**:
Project any array to [0,1] with integral n/2 while maintaining function shape.

def project_feasible(h, n):
    target = n/2.0  # Required sum
    lo, hi = -1.5, 1.5
    for _ in range(80):  # Iterative clipping
        mid = (lo+hi)/2.0
        clipped = np.clip(h - mid, 0, 1)
        total = np.sum(clipped)
        if abs(total - target) < 1e-12:
            break
        elif total < target:
            lo = mid
        else:
            hi = mid
    lam = (lo+hi)/2.0
    h_centered = h - lam
    h_projected = np.clip(h_centered, 0, 1)
    # Adjust sum by scaling non-extreme points
    mask = (h_centered > 1e-10) & (h_centered < 1-1e-10)
    if mask.any():
        delta = (target - np.sum(h_projected)) / np.sum(mask)
        h_projected[mask] += delta * mask / mask.sum()
    return np.clip(h_projected, 0, 1)
