If h(x+1) = 1 - h(x), then:

And the correlation:
c[k] = ∫ h(x)(1-h(x+k)) dx (approximately, for the continuous case)

For k=1: c[1] = ∫₀¹ h(x)(1-h(x+1)) dx = ∫₀¹ h(x)*h(x) dx = ∫₀¹ h²(x) dx
For k=1: c[-1] = ∫₁² h(x)(1-h(x-1)) dx = ∫₀¹ h(x+1)*(1-h(x)) dx = ∫₀¹ (1-h(x))*h(x) dx

So c[1] + c[-1] = ∫₀¹ h²(x) dx + ∫₀¹ h(x)(1-h(x)) dx = ∫₀¹ h(x) dx = 1/2.

This is interesting! If h has the anti-symmetry h(x+1) = 1-h(x), then c[1] + c[-1] = 1/2 (in the continuous case).

More generally, for shift k:

= ∫ [h(x) + h(x+k) - 2h(x)h(x+k)] dx (over the overlap region)

For the anti-symmetric case, this simplifies nicely.

from scipy.optimize import minimize

def compute_c5_fft(h):
    n = len(h)
    dx = 2.0 / n
    N = 1 << (2 * n - 2).bit_length()
    H = fft(h, N)
    G = fft(1.0 - h, N)
    R = ifft(H * np.conj(G)).real
    full_corr = np.concatenate([R[N - n + 1:], R[:n]])
    return float(np.max(full_corr) * dx)

def compute_c5_direct(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(h, target_sum):
    h = np.asarray(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        d = target_sum - h.sum()
        if abs(d) < 1e-13:
            break
        interior = (h > 1e-12) & (h < 1.0 - 1e-12)
        if interior.sum() == 0:
            if d > 0:
                k = int(np.ceil(d))
                idx = np.argsort(h)[-k:]
                h[idx] = np.minimum(1.0, h[idx] + d / k)
            else:
                k = int(np.ceil(-d))
                idx = np.argsort(h)[:k]
                h[idx] = np.maximum(0.0, h[idx] + d / k)
        else:
            h[interior] += d / interior.sum()
            h = np.clip(h, 0.0, 1.0)
    return h

    result[idx[:target]] = 1.0

        for _ in range(n_trials):

                zeros = np.where(h == 0)[0]
                improved = True

                    best_c5 = new_c5
                    best_h = h.copy()
            else:
                h[i] = 1
                h[j] = 0
        if not improved:
            break
    return best_h, best_c5

def smooth_obj(h, temp):
    n = len(h)
    dx = 2.0 / n
    N = 1 << (2 * n - 2).bit_length()
    H = fft(h, N)
    G = fft(1.0 - h, N)
    R = ifft(H * np.conj(G)).real
    corr = np.concatenate([R[N - n + 1:], R[:n]])
    m = np.max(corr)
    shifted = temp * (corr - m)
    shifted -= np.max(shifted)
    lse = m + np.log(np.exp(shifted).sum()) / temp
    return lse * dx

def optimize_slsqp(h_start, n, temp, maxiter=200):
    target = n / 2.0
    bnds = [(0.0, 1.0)] * n
    def obj(x):
        return smooth_obj(x, temp)
    def cfun(x):
        return x.sum() - target
    def cjac(x):
        return np.ones(n)
    cons = [{'type': 'eq', 'fun': cfun, 'jac': cjac}]
    res = minimize(obj, h_start, method='SLSQP', bounds=bnds,
                   constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-14})
    return project_feasible(res.x, target)

**Alternative: Greedy coordinate descent on the smooth problem**
Instead of SLSQP (which is slow for large n), I can implement my own projected gradient descent:
1. Compute the gradient of the smooth objective
2. Take a step in the negative gradient direction
3. Project back to the feasible set

The gradient of the smooth objective requires computing the gradient of each correlation coefficient with respect to h. Let me derive this.

For the correlation at lag k: c_k(h) = Σ_i h[i+k]*(1-h[i]) (for positive lags, with bounds)

dc_k/dh[j] = Σ_i [δ_{i+k=j}*(1-h[i]) + h[i+k]*(-δ_{i=j])]
= (1-h[j-k]) - h[j-k] (if j-k is in range and j is in range for the first sum)
  - h[j-k] for the second term... 

Wait, let me be more careful:
c_k = Σ_{i: i valid, i+k valid} h[i+k]*(1-h[i])

dc_k/dh[j]:
- j appears as h[j] in the (1-h[i]) factor when i=j: contributes -h[j+k] (if j+k is valid)
- j appears as h[j] in the h[i+k] factor when i+k=j, i.e., i=j-k: contributes (1-h[j-k]) (if j-k is valid)

So dc_k/dh[j] = (1-h[j-k])*[j-k valid] - h[j+k]*[j+k valid]

For the smooth objective F(h) = (1/ε) * log(Σ_k exp(ε*c_k*dx)):
dF/dh[j] = (dx/ε) * Σ_k exp(ε*c_k*dx) * ε * dc_k/dh[j]
= dx * Σ_k p_k * dc_k/dh[j]
where p_k = exp(ε*c_k*dx) / Σ_m exp(ε*c_m*dx) (softmax weights)

This can be computed efficiently:
- For each j, dc_k/dh[j] = (1-h[j-k])*[valid] - h[j+k]*[valid]
- This is a convolution-like operation!
- Σ_k p_k * (1-h[j-k]) = (p * (1-h))[j] (convolution with appropriate alignment)
- Σ_k p_k * h[j+k] = (p_reversed * h)[j] (cross-correlation)

So the gradient can be computed with two FFTs! That makes the projected gradient descent very fast.

def smooth_grad(h, temp):

    n = len(h)
    dx = 2.0 / n
    N = 1 << (2 * n - 2).bit_length()
    
    # Compute correlation
    H = fft(h, N)

    # Softmax weights
    ec = temp * corr * dx
    ec -= np.max(ec)

    n = len(h)
    dx = 2.0 / n
    N = 1 << (2 * n - 2).bit_length()
    H = fft(h, N)
    G = fft(1.0 - h, N)
