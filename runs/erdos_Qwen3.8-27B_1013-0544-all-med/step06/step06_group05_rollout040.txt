Let me define the lag as L = k - (n-1), so L ranges from -(n-1) to (n-1).
r[k] = sum_{i: 0≤i<n, 0≤i+L<n} h[i+L] * (1-h[i])

For L ≥ 0: r[k] = sum_{i=0}^{n-1-L} h[i+L] * (1-h[i])
For L < 0: r[k] = sum_{i=-L}^{n-1} h[i+L] * (1-h[i]) = sum_{i=0}^{n-1+L} h[i+L] * (1-h[i+L-L]) ... 

Let me just use L ≥ 0 case for now (the negative case is symmetric in a sense).

For L ≥ 0: r_L = sum_{i=0}^{n-1-L} h[i+L] * (1-h[i])

If h[a] changes from 1 to 0 (a is a "1" position):
- In r_L, the term h[a+L]*(1-h[a]) was 0 (since h[a]=1), now becomes h[a+L]*1 = h[a+L] (if a+L < n)
  - So r_L increases by h[a+L] for each L where a+L < n (i.e., L < n-a)
- Also, for each L where a-L ≥ 0 (i.e., L ≤ a): the term h[a]*(1-h[a-L]) was h[a]*(1-h[a-L]) = 1*(1-h[a-L]) = 1-h[a-L], now becomes 0*(1-h[a-L]) = 0
  - So r_L decreases by (1-h[a-L]) for each L where 0 ≤ L ≤ a

If h[b] changes from 0 to 1 (b is a "0" position):
- In r_L, the term h[b+L]*(1-h[b]) was h[b+L]*1 = h[b+L] (if b+L < n), now becomes h[b+L]*0 = 0
  - So r_L decreases by h[b+L] for each L where b+L < n
- Also, for each L where b-L ≥ 0: the term h[b]*(1-h[b-L]) was 0*(1-h[b-L]) = 0, now becomes 1*(1-h[b-L]) = 1-h[b-L]
  - So r_L increases by (1-h[b-L]) for each L where 0 ≤ L ≤ b

So the total change in r_L from swapping h[a]:1→0 and h[b]:0→1:
Δr_L = [h[a+L] if a+L<n else 0] - [(1-h[a-L]) if 0≤L≤a else 0]

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')

def continuous_minmax(h_init, max_time, lr=0.01):
    n = len(h_init)
    dx = 2.0 / n
    h = h_init.astype(float).copy()
    target = n / 2.0
    h = np.clip(h, 0, 1)
    h = h / h.sum() * target
    c5 = compute_c5(h)
    best_c5 = c5
    best_h = h.copy()
    t0 = time.time()
    
    while time.time() - t0 < max_time:
        # Compute correlation
        corr = np.correlate(h, 1-h, mode='full')
        k_star = np.argmax(corr)
        # Compute subgradient at k_star
        L = k_star - (n-1)
        grad = np.zeros(n)
        if L >= 0:
            for j in range(n):
                if 0 <= j-L < n-L:
                    grad[j] += (1 - h[j-L])
                if 0 <= j < n-L:
                    grad[j] -= h[j+L]
        else:
            Lp = -L
            for j in range(n):
                if 0 <= j+Lp < n:
                    grad[j] += (1 - h[j+Lp])
                if Lp <= j < n:
                    grad[j] -= h[j-Lp]
        
        # Projected gradient step
        h_new = h - lr * grad
        # Project onto {0<=x<=1, sum(x)=target}
        h_new = np.clip(h_new, 0, 1)
        diff = target - h_new.sum()
        if abs(diff) > 1e-10:
            # Distribute the difference
            if diff > 0:
                room = 1 - h_new
                total_room = room.sum()
                if total_room > 1e-10:
                    h_new += room * (diff / total_room)
            else:
                total = h_new.sum()
                if total > 1e-10:
                    h_new *= (1 + diff/total)
            h_new = np.clip(h_new, 0, 1)
        
        c5_new = compute_c5(h_new)
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new.copy()
        
        # Adaptive step size
        if c5_new <= c5:
            lr = min(lr * 1.5, 0.1)
        else:
            lr = lr * 0.5
            h_new = h  # undo
        
        h = h_new
        c5 = compute_c5(h)
    
    return best_h, best_c5

np.correlate(h, 1-h, mode='full') computes:
c[k] = sum_n h[n+k] * (1-h[n]) for valid n

Where k ranges from -(len(h2)-1) to (len(h1)-1) in the 'full' mode. Since both have length n:
k ranges from -(n-1) to (n-1), giving 2n-1 values.

The index in the output array: output[k + (n-1)] corresponds to lag k.
So output[0] is lag -(n-1), output[n-1] is lag 0, output[2n-2] is lag (n-1).

For lag 0: c[0] = sum_n h[n] * (1-h[n]) = sum h[n] - sum h[n]²
For binary h: c[0] = 0 (since h[n](1-h[n]) = 0 always for binary)

For lag 1 (output[n]): c[1] = sum_{n=0}^{n-2} h[n+1] * (1-h[n])
For binary: this counts the number of positions where h[n]=0 and h[n+1]=1, i.e., 0→1 transitions.

For lag -1 (output[n-2]): c[-1] = sum_{n=1}^{n-1} h[n-1] * (1-h[n])
For binary: this counts 1→0 transitions.

So the max of the full correlation includes both 0→1 and 1→0 transition counts (and all other lags).

For a binary sequence, the key lags to worry about are:
- Lag 0: always 0 for binary
- Small lags (1, 2, 3, ...): count nearby 0→1 or 1→0 transitions
- Large lags: count "far" disagreements

The max is likely at a small positive or negative lag (1 or 2 usually).

This means: to minimize C₅, we want to minimize the number of "far" disagreements at the worst lag. This is related to the sequence having low "out-of-phase" correlation.

This is analogous to the "minimum peak sidelobe level" problem in radar/communications, where we design a sequence with low peak sidelobes in its autocorrelation.

- Zadoff-Cu sequences (but these are complex-valued)

import numpy as np
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_binary(h, n):
    h = np.asarray(h, dtype=float)
    idx = np.argsort(-h)
    h_bin = np.zeros(n)
    h_bin[idx[:n // 2]] = 1.0
    return h_bin

def random_binary(n, seed):
    rng = np.random.RandomState(seed)
    h = np.zeros(n)
    h[rng.choice(n, n // 2, replace=False)] = 1.0
    return h

def structured_binary(n, seed):
    rng = np.random.RandomState(seed)
    h = np.zeros(n)
    n_blocks = rng.randint(3, n // 4 + 1)
    block_sizes = np.zeros(n_blocks, dtype=int)
    block_sizes[:] = n // n_blocks
    rem = n - block_sizes.sum()
    for i in range(rem):
        block_sizes[i] += 1
    pos = 0
    for bs in block_sizes:
        if rng.random() < 0.5:
            h[pos:pos+bs] = 1.0
        pos += bs
    return make_binary(h, n)

def local_search(h, max_time, seed=42):
    n = len(h)
    h = h.astype(float).copy()
    c5 = compute_c5(h)
    t0 = time.time()
    stagnant = 0
    rng = np.random.RandomState(seed)
    
    while time.time() - t0 < max_time:
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break
        best_gain = 0
        best_i, best_j = -1, -1
        for i in ones:
            for j in zeros:
                h[i] = 0; h[j] = 1
                nc = compute_c5(h)
                g = c5 - nc
                if g > best_gain:
                    best_gain = g; best_i, best_j = i, j
                h[i] = 1; h[j] = 0
        if best_i >= 0:
            h[best_i] = 0; h[best_j] = 1
            c5 -= best_gain
            stagnant = 0
        else:
            stagnant += 1
            if stagnant > 3:

            improved = False

                if len(ones) < 2 or len(zeros) < 2:

                a, b = rng.choice(ones, 2, replace=False)

                    grad[j] -= h[j-Lp]
        if cooldown > 0:
            cooldown -= 1
            continue
        h_new = h - lr * grad

        if abs(diff) > 1e-10:
            if diff > 0:
                room = 1.0 - h_new
                tr = room.sum()
                if tr > 1e-10: h_new += room*(diff/tr)

                if tot > 1e-10: h_new *= (1.0+diff/tot)
            h_new = np.clip(h_new, 0, 1)
        c5_new = compute_c5(h_new)
        if c5_new < best_c5:
            best_c5 = c5_new; best_h = h_new.copy()
        if c5_new <= compute_c5(h):
            lr = min(lr*1.1, 0.08)
            h = h_new

    return best_h, best_c5
