The bottleneck in the previous code was the DOUBLE move search which was O(n⁴) and in pure Python (nested for loops). My approach will use vectorized numpy to evaluate all swaps at once.

Here's my key insight: I can evaluate ALL single swaps (i, j) where i is a 1-position and j is a 0-position simultaneously using matrix operations.

For a fixed swap (i→0, j→1), the new correlation at lag k is:
new_corr[k] = old_corr[k] + delta[k]

where delta[k] = -(1-h[i+k]) * [i+k < n] + h[i-k] * [i-k ≥ 0] + (1-h[j+k]) * [j+k < n] - h[j-k] * [j-k ≥ 0]

Let me define:
A[i, k] = -(1-h[i+k]) if i+k < n, else 0; + h[i-k] if i-k ≥ 0, else 0  [for all k]
B[j, k] = (1-h[j+k]) if j+k < n, else 0; - h[j-k] if j-k ≥ 0, else 0  [for all k]

Then delta[k] = A[i,k] + B[j,k]

And new_max(i,j) = max_k (old_corr[k] + A[i,k] + B[j,k])

I can precompute A (matrix of size n_ones × (2n-1)) and B (matrix of size n_zeros × (2n-1)).

Then for each pair (i, j), new_max = max(old_corr + A[i,:] + B[j,:]).

If I stack all A[i,:] for all i and all B[j,:] for all j, I get a tensor of size n_ones × n_zeros × (2n-1). The max over the last axis gives n_ones × n_zeros values. I can then find the minimum.

For n=112: n_ones = n_zeros = 56, so the tensor is 56 × 56 × 223 ≈ 700,000 elements. That's small!

So the algorithm per iteration:
1. Compute old_corr (O(n²) or O(n log n))
2. Compute A matrix (O(n²) with numpy)
3. Compute B matrix (O(n²) with numpy)
4. Compute new_max for all pairs: max over last axis of (old_corr + A[:,None,:] + B[None,:,:]) → O(n³) but vectorized
5. Find the best (i,j) pair
6. Apply the swap
7. Repeat

Each iteration is O(n³) but heavily vectorized. For n=112, this should take maybe 1-5 ms per iteration. Over 1000 seconds, we can do ~200,000-1,000,000 iterations. That's more than enough for convergence.

import numpy as np
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_binary(h, n):
    h = np.asarray(h, dtype=float).copy()
    h = np.round(h)
    n_ones = int(np.sum(h))
    target = n // 2
    if n_ones > target:
        ones = np.where(h == 1)[0]
        rng = np.random.RandomState(0)
        rng.shuffle(ones)
        for idx in ones[:n_ones - target]:
            h[idx] = 0
    elif n_ones < target:
        zeros = np.where(h == 0)[0]
        rng = np.random.RandomState(1)
        rng.shuffle(zeros)
        for idx in zeros[:target - n_ones]:
            h[idx] = 1
    return h

def safe_idx(arr, max_idx):
    mask = (arr >= 0) & (arr < max_idx)
    safe = np.clip(arr, 0, max_idx - 1)
    return safe, mask

def fast_binary_ls(h, max_time=30.0, kick_size=3, max_kicks=20):
    n = len(h)
    h = h.astype(float).copy()
    dx = 2.0 / n
    n_full = 2 * n - 1
    lags = np.arange(-(n-1), n)
    
    curr_corr = np.correlate(h, 1.0 - h, mode='full').astype(float)
    curr_max = float(np.max(curr_corr))
    best_h = h.copy()
    best_max = curr_max
    kicks_used = 0
    
    start = time.time()
    while (time.time() - start) < max_time:
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        n_o = len(ones)
        n_z = len(zeros)
        if n_o == 0 or n_z == 0:
            break
        
        # Compute effects
        p_plus = ones[:, None] + lags[None, :]
        p_minus = ones[:, None] - lags[None, :]
        pp_s, pp_m = safe_idx(p_plus, n)
        pm_s, pm_m = safe_idx(p_minus, n)
        remove_eff = -(1.0 - h[pp_s]) * pp_m + h[pm_s] * pm_m
        
        q_plus = zeros[:, None] + lags[None, :]
        q_minus = zeros[:, None] - lags[None, :]
        qp_s, qp_m = safe_idx(q_plus, n)
        qm_s, qm_m = safe_idx(q_minus, n)
        add_eff = (1.0 - h[qp_s]) * qp_m - h[qm_s] * qm_m
        
        base = curr_corr[None, :] + remove_eff
        combined = base[:, None, :] + add_eff[None, :, :]
        new_max = combined.max(axis=2)
        
        min_val = float(new_max.min())
        if min_val >= curr_max - 1e-12:
            # Stuck, try a kick
            if kicks_used >= max_kicks:
                break
            kicks_used += 1
            # Random kick: flip kick_size pairs
            for _ in range(kick_size):
                i = np.random.randint(n_o)
                j = np.random.randint(n_z)
                h[ones[i]] = 0.0
                h[zeros[j]] = 1.0
            ones = np.where(h == 1)[0]
            zeros = np.where(h == 0)[0]
            curr_corr = np.correlate(h, 1.0 - h, mode='full').astype(float)
            curr_max = float(np.max(curr_corr))
            continue
        
        # Apply best move
        i, j = np.unravel_index(new_max.argmin(), new_max.shape)
        h[ones[i]] = 0.0
        h[zeros[j]] = 1.0
        curr_corr = curr_corr + remove_eff[i, :] + add_eff[j, :]
        curr_max = min_val
        
        if curr_max * dx < best_max * dx:
            best_max = curr_max
            best_h = h.copy()
    
    return best_h, float(best_max * dx)

def random_binary(n, seed=42):
    rng = np.random.RandomState(seed)
    h = np.zeros(n)
    ones = rng.choice(n, n//2, replace=False)
    h[ones] = 1.0
