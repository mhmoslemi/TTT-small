If g has period 1 (on the [0,2] circle), then G(1) = G(0) = ||g||², so c_1 = 0.
But for other k values, G(k) might be small or negative.

For a square wave with period 1: h = 1 on [0,0.5]∪[1,1.5], h = 0 on [0.5,1]∪[1.5,2].
Then g = 0.5 on the "high" parts, -0.5 on the "low" parts.
g is a square wave with period 1 and amplitude 0.5.
G(k) = 0.25 * (overlap of two unit-square waves shifted by k)
For k=0: G(0) = 0.25*1 = 0.25 (since the "duty cycle" is 0.5, ∫g² = 0.5*0.25*2 = 0.25... wait let me recalculate)

Actually with h being 1 on half the domain and 0 on the other half:
∫h = 1 ✓ (since domain length is 2 and h=1 on length 1)
g = h - 0.5, so g = 0.5 on length 1 and g = -0.5 on length 1.
G(0) = ∫g² = 0.25*1 + 0.25*1 = 0.5
c_0 = 0.5 - 0.5 = 0 ✓

G(1) = ∫g(x)g(x+1)dx. Since g has period 1, g(x+1) = g(x), so G(1) = G(0) = 0.5.
c_1 = 0.5 - 0.5 = 0 ✓

G(0.5) = ∫g(x)g(x+0.5)dx. Since g is a square wave with period 1, shifting by 0.5 flips it.
So g(x+0.5) = -g(x), and G(0.5) = -G(0) = -0.5.
c_0.5 = 0.5 - (-0.5) = 1.0. Terrible!

So a square wave with period 1 gives c_0.5 = 1, which is the worst possible case.

What about a sine wave? g(x) = A*sin(2πx). Then:
G(k) = A² * ∫sin(2πx)sin(2π(x+k))dx = A² * ∫sin(2πx)[sin(2πx)cos(2πk) + cos(2πx)sin(2πk)]dx
     = A² * cos(2πk) * ∫sin²(2πx)dx + A² * sin(2πk) * ∫sin(2πx)cos(2πx)dx
     = A² * cos(2πk) * 1 + 0 = A²*cos(2πk)

And G(0) = A². So c_k = 0.5 - A²*cos(2πk).
For this to be well-behaved, we need A²*cos(2πk) ≥ 0 for all k, which means cos(2πk) ≥ 0, which is false for k ∈ (0.25, 0.75).

At k=0.5: c_0.5 = 0.5 - A²*cos(π) = 0.5 + A². Even worse!

So a single frequency is bad. We need multiple frequencies.

What about g(x) = A*(sin(2πx) + sin(4πx))/2? This is getting complicated.

Let me think about this differently. The problem is essentially: find a bandlimited (or not) function g with ∫g=0, |g|≤0.5, that maximizes min_{k≠0} G(k).

This is a classical problem in signal processing related to "low autoperiodic" or "low autocorrelation" waveforms. The optimal solutions are related to Golay complementary sequences or Zadoff-Chu sequences in the discrete case.

In the continuous case, the optimal g is related to the prolate spheroidal wave functions or their generalizations.

For our practical purposes, the best approach is probably:

2. Optimize with good local methods
3. Try to escape local optima with structured perturbations

Let me also consider: what if I try a "two-level" solution where h takes only values in {0, 0.5, 1}? This might be easier to optimize.

Or what about trying h(x) = 0.5 + A*sum_j a_j * sin(2π*f_j*x + φ_j) for a small number of frequencies? This parameterizes the problem with a small number of parameters (2*number_of_frequencies) and makes the optimization much easier.

For example, with 5 frequencies, we have 10 parameters + 1 amplitude = 11 parameters to optimize, which is very tractable.

Let me try this "Fourier parametrization" approach:

- We can normalize so that sum a_j² = 1, and A is the overall amplitude

The frequencies f_j should be integers (for period 2) or half-integers.

import numpy as np
import time
import scipy.optimize as so
import warnings
warnings.simplefilter("ignore")

_P = {"tau": 0.02}

def _time_left(dl):
    return max(0.0, dl - time.time())

def repair(h):
    x = np.array(h, dtype=float, copy=True)
    n = x.size
    target = 0.5 * n
    np.clip(x, 0.0, 1.0, out=x)
    for _ in range(60):
        diff = target - x.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            slack = 1.0 - x; m = slack > 1e-14
            if not m.any(): break
            x[m] += diff * slack[m] / slack[m].sum()
        else:
            m = x > 1e-14
            if not m.any(): break
            x[m] += diff * x[m] / x[m].sum()
        np.clip(x, 0.0, 1.0, out=x)
    diff = target - x.sum()
    if abs(diff) > 1e-11:
        order = np.argsort(1.0 - x)[::-1] if diff > 0 else np.argsort(x)
        for i in order:
            if abs(diff) < 1e-15: break
            if diff > 0:
                a = min(diff, 1.0 - x[i]); x[i] += a; diff -= a
            else:
                a = max(diff, -x[i]); x[i] += a; diff -= a
    return x

def c_vals(h):
    n = h.size
    return np.correlate(h, 1.0 - h, mode="full") * (2.0 / n)

def exact_c(h):
    return float(np.max(c_vals(h)))

def _grad_x(x, w):
    n = x.size
    dx = 2.0 / n
    grad = np.zeros(n)
    m = 2 * n - 1
    for ki in range(m):
        wk = w[ki]
        if wk < 1e-14: continue
        k = ki - (n - 1)
        if k >= 0:
            hi = n - 1 - k
            if hi >= 0:
                grad[0:hi+1] += wk * dx * (1.0 - x[k:hi+1+k])
            if k <= n-1:
                grad[k:n] -= wk * dx * x[0:n-k]
        else:
            kk = -k
            if kk <= n-1:
                grad[kk:n] += wk * dx * (1.0 - x[0:n-kk])
            hi = n - 1 - kk
            if hi >= 0:
                grad[0:hi+1] -= wk * dx * x[kk:hi+1+kk]
    return grad

def _weights(c):
    tau = _P["tau"]
    cm = c.max()
    if tau < 1e-10:
        w = np.zeros(c.size); w[int(c.argmax())] = 1.0
        return cm, w
    z = (c - cm) / tau; z -= z.max()
    e = np.exp(z); s = e.sum()
    if not np.isfinite(s) or s <= 0:
        w = np.zeros(c.size); w[int(c.argmax())] = 1.0
        return cm, w
    w = e / s
    return cm + tau * np.log(s), w

def s_obj(x):
    c = c_vals(x)
    v, _ = _weights(c)
    return v

def s_grad(x):
    c = c_vals(x)
    _, w = _weights(c)
    return _grad_x(x, w)

def _slsqp(x0, n_iter):
    n = x0.size
    bnds = [(0.0, 1.0)] * n
    def cfun(x): return np.array([x.sum() - 0.5 * n])
    def cjac(x): return np.ones((1, n))
    try:
        r = so.minimize(s_obj, x0, method="SLSQP", jac=s_grad,
                        bounds=bnds, constraints=[{"type":"eq","fun":cfun,"jac":cjac}],
                        options={"maxiter": n_iter, "ftol": 1e-13})
        return r.x if r is not None else x0
    except:
        return x0

def _resample(h0, n_new):
    n0 = h0.size
    if n0 == n_new: return repair(h0)
    x0 = (np.arange(n0) + 0.5) * (2.0/n0)
    x1 = (np.arange(n_new) + 0.5) * (2.0/n_new)
    return repair(np.interp(x1, x0, h0))

def _fourier_eval(params, n_eval=400):
    m = len(params) // 2
    t = np.linspace(0, 2.0, n_eval, endpoint=False) + 1.0/n_eval
    h = np.full(n_eval, 0.5)
    for j in range(m):
        a = params[2*j]; ph = params[2*j+1]
        h += a * np.cos(np.pi * (j+1) * t + ph)
    h = np.clip(h, 0.0, 1.0)
    s = h.sum() * (2.0/n_eval)
    if s > 0:
        h /= s
    h = np.clip(h, 0.0, 1.0)
    return exact_c(h)

def _fourier_opt(n_harm, seed, time_lim):
    rng = np.random.RandomState(seed)
    best_params = np.zeros(2*n_harm)
    best_params[0] = 0.3
    best_c = 1e9
    deadline = time.time() + time_lim
    x0 = np.zeros(2*n_harm)
    x0[0] = 0.25
    x0[1] = 0.0
    for trial in range(3):
        if time.time() > deadline: break
        x0[0] = 0.15 + 0.25 * rng.rand()
        for j in range(n_harm):
            x0[2*j] = (0.02 + 0.15*rng.rand()) * (1.0/(1+j))
            x0[2*j+1] = rng.uniform(0, 2*np.pi)
        r = so.minimize(_fourier_eval, x0, method="Nelder-Mead",
                        options={"maxiter": 2000, "xatol": 1e-8, "fatol": 1e-10})
        c = _fourier_eval(r.x)
        if c < best_c:
            best_c = c; best_params = r.x.copy()
    return best_params, best_c

def _polish(x, time_lim, seed):
    x = repair(x)
    best = x.copy(); bc = exact_c(x)
    dl = time.time() + time_lim
    rng = np.random.RandomState(seed)
    step = 0.5; noimp = 0
    while time.time() < dl:
        cv = c_vals(x); C = cv.max()
        if C < bc - 1e-14:
            bc = C; best = x.copy(); noimp = 0
        else:
            noimp += 1
        if noimp > 20:
            broke = False
            for sg in (0.01, 0.005, 0.002, 0.001):
                y = repair(x + rng.normal(0, sg, x.size))
                cy = exact_c(y)
                if cy < bc:
                    bc = cy; best = y.copy(); x = y; noimp = 0; broke = True; break
            if not broke: break
            continue
        tol = max(1e-9, 1e-5*C)
        act = np.where(cv >= C - tol)[0]
        if act.size > 8: act = np.argsort(cv)[::-1][:8]
        w = np.zeros(cv.size); w[act] = 1.0/act.size
        g = _grad_x(x, w)
        gn = np.linalg.norm(g)
        if gn < 1e-15: break
        acc = False
        for _ in range(20):
            y = repair(x - step*g/gn)
            cy = exact_c(y)
            if cy < C - 1e-13:
                x = y; acc = True; break
            step *= 0.5
            if step < 1e-12: break
        if acc: noimp = 0
        else: noimp += 1
    return best, bc

def run(seed=42, budget_s=1100, **kwargs):
    dl = time.time() + budget_s
    sv = int(seed)

    raw = globals().get("initial_h_values", None)
    init = None if raw is None else np.asarray(raw, dtype=float)
    if init is not None and init.size < 10:
        init = None

    best_x = None; best_c = 999.0

    if init is not None:
        base = repair(init.copy())
        bc = exact_c(base)
        best_x = base.copy(); best_c = bc

        # Phase 1: Polish parent with SLSQP at decreasing tau
        for tau in [0.05, 0.02, 0.01, 0.005, 0.002, 0.001]:
            if _time_left(dl) < 60: break
            _P["tau"] = tau
            t0 = time.time()
            mi = max(30, int(min(300, (120/tau**0.5))))
            xr = _slsqp(base, mi)
            xr = repair(xr)
            cx = exact_c(xr)
            if cx < best_c:
                best_c = cx; best_x = xr.copy()
            if cx <= best_c + 1e-4:
                base = xr
            else:
                base = best_x

        # Phase 2: Subgradient polish
        if _time_left(dl) > 30:
            xp, cp = _polish(best_x, min(120, _time_left(dl)*0.3), sv)
            if cp < best_c:
                best_c = cp; best_x = xp

    # Phase 3: Try different resolutions
    if _time_left(dl) > 100:
        for n_try in [80, 100, 120]:
            if _time_left(dl) < 50: break
            if best_x is not None:
                start = _resample(best_x, n_try)
            else:
                start = np.full(n_try, 0.5)
            start = repair(start)
            for tau in [0.03, 0.01, 0.005, 0.002]:
                if _time_left(dl) < 20: break
                _P["tau"] = tau
                xr = _slsqp(start, 200)
                xr = repair(xr)
                cx = exact_c(xr)
                if cx < best_c:
                    best_c = cx; best_x = xr.copy()
                    start = xr
                elif cx <= best_c + 2e-4:
                    start = xr
            if _time_left(dl) > 20:
                xp, cp = _polish(start, 30, sv+n_try)
                if cp < best_c:
                    best_c = cp; best_x = xp

    # Phase 4: Fourier parametrization
    if _time_left(dl) > 80:
        for nh in [3, 4, 5]:
            if _time_left(dl) < 30: break
            fp, fc = _fourier_opt(nh, sv+nh*999, min(40, _time_left(dl)*0.4))
            if fc < best_c:
                # Convert Fourier to step function
                t = np.linspace(0, 2.0, 200, endpoint=False) + 1.0/200
                hf = np.full(200, 0.5)
                for j in range(nh):
                    hf += fp[2*j]*np.cos(np.pi*(j+1)*t + fp[2*j+1])
                hf = np.clip(hf, 0, 1)
                hf /= hf.sum() * (2.0/200)
                hf = repair(hf)
                cx = exact_c(hf)
                if cx < best_c:
                    best_c = cx; best_x = hf.copy()

    # Phase 5: Structured restarts from best
    if _time_left(dl) > 60 and best_x is not None:
        n = best_x.size
        rng = np.random.RandomState(sv+7777)
        t = (np.arange(n)+0.5)*(2.0/n)
        for freq in [2, 3, 5, 7]:
            if _time_left(dl) < 20: break
            amp = 0.05 + 0.05*rng.rand()
            pert = best_x + amp*np.cos(2*np.pi*freq*t/2.0 + rng.uniform(0, 6.28))
            pert = repair(pert)
            _P["tau"] = 0.01
            xr = _slsqp(pert, 150)
            xr = repair(xr)
            cx = exact_c(xr)
            if cx < best_c:
                best_c = cx; best_x = xr
            if _time_left(dl) > 15:
                xp, cp = _polish(xr, 20, sv+freq*31)
                if cp < best_c:
                    best_c = cp; best_x = xp

    # Phase 6: Multi-jitter from best
    if _time_left(dl) > 40 and best_x is not None:
        rng = np.random.RandomState(sv+55555)
        for trial in range(5):
            if _time_left(dl) < 15: break
            sc = 0.03 + 0.02*trial
            y = repair(best_x + rng.normal(0, sc, best_x.size))
            _P["tau"] = 0.005
            xr = _slsqp(y, 100)
            xr = repair(xr)
            cx = exact_c(xr)
            if cx < best_c:
                best_c = cx; best_x = xr
            xp, cp = _polish(xr, min(15, _time_left(dl)*0.3), sv+trial*13)
            if cp < best_c:
                best_c = cp; best_x = xp

    # Final
    if best_x is None:
        best_x = repair(np.full(70, 0.5))
        best_c = exact_c(best_x)
    else:
        best_x = repair(best_x)
        best_c = exact_c(best_x)

    return best_x, best_c, int(best_x.size)
