For a random binary function with 50% ones, the expected overlap at any lag is about 0.25 (since E[h(x)(1-h(x+k))] = E[h(x)]*E[1-h(x+k)] = 0.5*0.5 = 0.25 for independent values). But we want to minimize the MAX overlap, so we want all overlaps to be as small as possible.

The theoretical lower bound: if h is perfectly periodic with period p, then at lag p, the overlap is 0 (if h and h(x+p) are complementary). But at other lags, it might be larger.

Actually, for the continuous case, if h is the indicator of a set A with measure 1 in [0,2], then the overlap at lag k is the measure of A ∩ (A+k)^c = measure(A) - measure(A ∩ (A+k)) = 1 - measure(A ∩ (A+k)).

    dx = 2.0 / n
    overlaps = np.correlate(x, 1.0 - x, mode='full') * dx
    m = np.max(overlaps)
    if m <= 1e-12:

    return float(m + np.log(np.sum(np.exp(shifted))) / alpha)

    lo, hi = -2.0, 2.0

        proj = np.clip(h - mid, 0, 1)
        s = np.sum(proj)
        if s > S:

        else:

For k=0: ∫ h(x)(1-h(x)) dx = ∫ h(x) dx - ∫ h(x)² dx = 1 - ∫h² dx.

To minimize the k=0 overlap, we want to maximize ∫h², which means making h as close to binary as possible (0 or 1). This is consistent with the intuition that the optimal solution is close to binary.

For other k values, the situation is more complex. The key insight is that we want h(x) and h(x+k) to be "anti-correlated" for all k, which is impossible for all k simultaneously.
