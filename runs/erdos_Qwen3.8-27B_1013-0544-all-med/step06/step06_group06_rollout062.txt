- j=i+k: h[i+k]*(1-(h[i]+δ)) = h[i+k]*(1-h[i]) - δ*h[i+k]

So the change from h[i] → h[i]+δ is: δ*(1-h[i-k]) - δ*h[i+k] = δ*(1 - h[i-k] - h[i+k])

Similarly for h[j] → h[j]-δ: change is -δ*(1 - h[j-k] - h[j+k])

Total change in c[k]: δ*(1 - h[i-k] - h[i+k] - 1 + h[j-k] + h[j+k])
= δ*(h[j-k] + h[j+k] - h[i-k] - h[i+k])

Let me define: d_k = h[j-k] + h[j+k] - h[i-k] - h[i+k] (with 0 for out-of-range)

Then c'[k] = c[k] + δ * d_k

And we want to minimize: max_k (c[k] + δ * d_k) subject to 0 ≤ h[i]+δ ≤ 1, 0 ≤ h[j]-δ ≤ 1
i.e., -h[i] ≤ δ ≤ 1-h[i] and -(1-h[j]) ≤ δ ≤ h[j]
So: max(-h[i], h[j]-1) ≤ δ ≤ min(1-h[i], h[j])

This is a 1D convex piecewise-linear minimization! The function is:
f(δ) = max_k (c[k] + d_k * δ)

To find the minimum:
- The subgradient at δ is {d_k : k ∈ argmax f(δ)}
- At optimum, 0 ∈ subgradient
- So we need: min_{k∈argmax} d_k ≤ 0 ≤ max_{k∈argmax} d_k

Algorithm to find optimal δ:
1. Evaluate f at δ_low = max(-h[i], h[j]-1) and δ_high = min(1-h[i], h[j])
2. If f is decreasing throughout (all d_k < 0 at argmax for all δ), optimum is at δ_high
3. If f is increasing throughout, optimum is at δ_low
4. Otherwise, use bisection:
   - At current δ, find argmax k*, check sign of d_{k*}
   - If d_{k*} < 0: function is decreasing, increase δ
   - If d_{k*} > 0: function is increasing, decrease δ
   - If d_{k*} = 0 (or 0 is in subgradient): we're at optimum

Actually, for a cleaner approach: the minimum of max_k (a_k + b_k * δ) occurs at a breakpoint where two lines cross. The breakpoints are at δ = (a_i - a_j) / (b_j - b_i) for all pairs i,j with b_i ≠ b_j.

```python
def golden_section_min(f, a, b, tol=1e-10, max_iter=50):
    gr = (np.sqrt(5) - 1) / 2  # 0.618...
    c = b - gr * (b - a)
    d = a + gr * (b - a)
    fc = f(c)
    fd = f(d)
    for _ in range(max_iter):
        if b - a < tol:
            break
        if fc < fd:
            b = d
            d = c
            fd = fc
            c = b - gr * (b - a)
            fc = f(c)
        else:
            a = c
            c = d
            fc = fd
            d = a + gr * (b - a)
            fd = f(d)
    return 0.5 * (a + b)
```

```python
def solve_1d_numeric(h, i, j, n, c_current):
    """Find optimal delta for pair swap h[i]+=delta, h[j]-=delta"""
    dlo = max(-h[i], h[j] - 1.0)
    dhi = min(1.0 - h[i], h[j])
    if dlo >= dhi - 1e-14:
        return 0.0, c_current
    
    def f(delta):
        h[i] += delta
        h[j] -= delta
        c_new = np.correlate(h, 1-h, mode='full')
        result = float(np.max(c_new))
        h[i] -= delta
        h[j] += delta
        return result, c_new
    
    # Coarse grid
    n_grid = 20
    deltas = np.linspace(dlo, dhi, n_grid)
    best_f = float('inf')
    best_delta = 0
    for d in deltas:
        val, _ = f(d)
        if val < best_f:
            best_f = val
            best_delta = d
    
    # Local refinement
    if best_delta > dlo and best_delta < dhi:
        lo = best_delta - (dhi-dlo)/n_grid
        hi = best_delta + (dhi-dlo)/n_grid
        lo = max(lo, dlo)
        hi = min(hi, dhi)
        # Golden section
        gr = (np.sqrt(5)-1)/2
        a, b = lo, hi
        c = b - gr*(b-a)
        d = a + gr*(b-a)
        fc, _ = f(c)
        fd, _ = f(d)
        for _ in range(20):
            if abs(b-a) < 1e-12:
                break
            if fc < fd:
                b = d; d = c; fd = fc
                c = b - gr*(b-a); fc, _ = f(c)
            else:
                a = c; c = d; fc = fd
                d = a + gr*(b-a); fd, _ = f(d)
        mid = 0.5*(a+b)
        val, _ = f(mid)
        if val < best_f:
            best_f = val
            best_delta = mid
    
    return best_delta, None
```
