For each coordinate p:

- Fix all other coordinates

f_m(h) = ∑_{i} h[i] * (1-h[i+m])

If I fix all h except h[p] = t:
f_m(t) = [terms not involving h[p]] + [terms involving h[p]]

Terms where h[p] is the first factor (i=p): h[p]*(1-h[p+m]) = t*(1-h[p+m]) if p+m < n
Terms where h[p] is the second factor (i+m=p, so i=p-m): h[p-m]*(1-h[p]) = h[p-m]*(1-t) if p-m ≥ 0

So: f_m(t) = f_m(0) + t*((1-h[p+m]) - h[p-m]) (where valid terms are 0)

Let a_m = (1-h[p+m]) * [0≤p+m<n] - h[p-m] * [0≤p-m<n]

Then f_m(t) = f_m(0) + t * a_m

The objective is max_m f_m(t) = max_m (f_m(0) + t*a_m)

This is the max of linear functions of t, so it's convex in t! We want to minimize it over t ∈ [0,1].

The minimum of a convex piecewise-linear function on [0,1] occurs at a breakpoint or at the boundary. The breakpoints are where two of the linear functions cross, i.e., f_m(0) + t*a_m = f_{m'}(0) + t*a_{m'}, giving t = (f_{m'}(0) - f_m(0))/(a_m - a_{m'}).

But there are O(n) linear functions, so O(n²) breakpoints. We can find the minimum more efficiently.

Actually, since we want to minimize the max, and the max of linear functions is the upper envelope, the minimum occurs at:
- t=0, t=1, or at a point where the slope changes from negative to positive.

The slope of the upper envelope at point t is max over active m of a_m (where active means f_m(t) = max).

So we can binary search for the optimal t:
- If at some t, the slope is negative (all active a_m < 0), we should increase t
- If positive, decrease t
- If there's a mix or zero, we're at the optimum

    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    vals = corr * dx
    max_val = np.max(vals)
    tol = 1e-7
    active = np.where(vals >= max_val - tol)[0]
    
    grad = np.zeros(n)
    for m in active:
        L = m - (n - 1)
        # Term 1: (1-h[p-L]) for p such that 0<=p-L<n, i.e., L<=p<L+n
        p_lo = max(0, L)

        # Term 2: -h[p+L] for p such that 0<=p+L<n, i.e., -L<=p<n-L

            p_idx2 = np.arange(p_lo2, p_hi2)
            grad[p_idx2] -= h[p_idx2 + L] / len(active)
    
    return grad, max_val

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_binary(h, n):
    h = np.asarray(h, dtype=float).copy()
    h = np.round(h)
    n_ones = int(np.sum(h))
    target = n // 2
    if n_ones > target:
        ones = np.where(h == 1)[0]
        for idx in ones[target:]:
            h[idx] = 0
    elif n_ones < target:
        zeros = np.where(h == 0)[0]
        for idx in zeros[:target - n_ones]:
            h[idx] = 1
    return h

def normalize_continuous(h, n):
    h = np.asarray(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(30):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tr = np.sum(room)
            if tr > 1e-14:
                h += room * (diff / tr)
            else:
                h += diff / n
        else:
            tot = np.sum(h)
            if tot > 1e-14:
                h += h * (diff / tot)
            else:
                h += diff / n
        h = np.clip(h, 0.0, 1.0)
    return h
