    target = n // 2
    h = h.copy()

        j = zeros[j_idx]

        vec[j] = 1

                best_vec = vec.copy()
        else:
            vec[i] = 1
            vec[j] = 0
            ones[i_idx] = i
            zeros[j_idx] = j

Let me also think about the problem from a different angle. The overlap at lag k is:
c[k] = ∑_i h[i+k](1-h[i])

This counts the number of "0→1" transitions at shift k (for binary h). We want to minimize the maximum over all k.

A key observation: for a binary sequence with exactly n/2 ones, the total number of 0→1 transitions over all lags is:
∑_k c[k] = ∑_k ∑_i h[i+k](1-h[i]) = ∑_i ∑_k h[i+k](1-h[i])

For a fixed i with h[i]=0: ∑_k h[i+k] = (number of ones) = n/2
For a fixed i with h[i]=1: contribution is 0

So ∑_k c[k] = (number of zeros) * (n/2) = (n/2)^2 = n²/4

And there are 2n-1 possible lags, so the average overlap is n²/4 / (2n-1) ≈ n/8.
C₅ ≥ n/8 * dx = n/8 * 2/n = 1/4 = 0.25

So the theoretical lower bound is 0.25, and we're currently at 0.38. There's room for improvement!

    inv = 1.0 - h
    cur = bin_c5(h, n)
    best = h.copy()
    best_c = cur
    
    ones_p = list(np.where(h > 0.5)[0])
    zeros_p = list(np.where(h < 0.5)[0])
    
    for step in range(n_steps):
        T = T0 * (T1 / T0) ** (step / max(n_steps - 1, 1))
        if T < 1e-12:
            T = 1e-12
        
        ii = rng.randint(len(ones_p))
        jj = rng.randint(len(zeros_p))
        i = ones_p[ii]
        j = zeros_p[jj]
        
        h[i] = 0.0; inv[i] = 1.0
        h[j] = 1.0; inv[j] = 0.0
        ones_p[ii] = j; zeros_p[jj] = i

        new_c = float(np.max(c) * dx)
        d = new_c - cur
        
        if d < 0 or rng.random() < np.exp(-d / T):
            cur = new_c
            if new_c < best_c:
                best_c = new_c
                best = h.copy()
        else:
            h[i] = 1.0; inv[i] = 0.0
            h[j] = 0.0; inv[j] = 1.0
            ones_p[ii] = i; zeros_p[jj] = j

    best = h.astype(float).copy()
    best_c = bin_c5(best, n)
    no_improve = 0

        ones_p = np.where(best > 0.5)[0]
        zeros_p = np.where(best < 0.5)[0]

        rng.shuffle(zeros_p)

                best[j] = 1.0

                    improved = True
                else:
                    best[i] = 1.0
                    best[j] = 0.0
        
        if improved:
            no_improve = 0
        else:
            no_improve += 1
