### Phase 5: Refinement with Optimization

We use **CVXPY** to fit a **Conic Quadratic Optimization (CQO)** model that:
- Maximizes the sum of radii.
- Enforces non-overlap between circles.
- Enforces boundaries.

The optimization model will look something like this:
```python
import cvxpy as cp

n = 26
centers = cp.Variable((n, 2)) # initial seed positions
radii = cp.Variable(n)

# Objective: max sum of radii
objective = cp.Maximize(cp.sum(radii))

# Constraints:
# 1. Each circle fits within the unit square
for i in range(n):
    x, y = centers[i]
    r = radii[i]
    cons = [
        x - r >= 0,
        x + r <= 1,
        y - r >= 0,
        y + r <= 1
    ]

# 2. Non-overlap between circles
for i in range(n):
    for j in range(i+1, n):
        dist = cp.sqrt((centers[i, 0] - centers[j, 0])**2 + (centers[i, 1] - centers[j, 1])**2)
        cons.append(dist >= radii[i] + radii[j])

problem = cp.Problem(objective, cons)
problem.solve()
```

We can use this to find the best configuration of radii and positions, stopping once the objective has converged or we reach a maximum number of iterations.
