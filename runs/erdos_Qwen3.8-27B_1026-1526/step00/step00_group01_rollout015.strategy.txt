We use a mixed-integer programming (MIP) approach on a reduced problem representation, leveraging the parent solution as a validator and search direction. The non-convex nature requires iterative refinement with re-linearization: we alternate between pruning dominated solutions and projecting back to the feasible region while respecting both box and integral constraints. The key insight is that the optimal h(x) likely has a sparse active set (few intervals away from 0 and 1), so we project the parent solution into a lower-dimensional "active set" space and optimize over these salient points.

The method directly addresses the approximation problem by discretizing into a reduced optimization space with:
