**Heuristic: Focus on worst lags**
1. Find the lag j* with maximum overlap
2. Try to reduce overlap at j* by finding a good pair (a,b)
3. For the lag j* (corresponding to d* = j*-(n-1)):
   - We want to decrease overlap(d*) = sum_m h[m+d*]*(1-h[m])
   - Flipping h[a]:1→0 removes (1-h[a-d*]) from overlap(d*) [if valid]
   - Flipping h[b]:0→1 adds (1-h[b-d*]) to overlap(d*) [if valid]
   - Also affects the "1-h[m]" parts:
     - h[a]:1→0 changes 1-h[a] from 0 to 1, so adds h[a+d*] to overlap(d*)
     - h[b]:0→1 changes 1-h[b] from 1 to 0, so removes h[b+d*] from overlap(d*)

4. We want Δ(d*) < 0. The best a is one that maximizes (1-h[a-d*]) - h[a+d*] (the reduction).
   The best b is one that minimizes (1-h[b-d*]) - h[b+d*] (the addition, which we want to be small or negative).

This gives an O(n) heuristic per step (scan all a's and b's for the best pair), instead of O(n³).

```python
def compute_delta_vectorized(h, a, b, n):
    """Compute Δ for all lags when flipping h[a]:1→0 and h[b]:0→1."""
    # Delta at lag j (where d = j - (n-1)):
    # Δ(j) = -(1-h[a-d])*1[0<=a-d<n] + h[a+d]*1[0<=a+d<n]
    #        + (1-h[b-d])*1[0<=b-d<n] - h[b+d]*1[0<=b+d<n]
    
    # Precompute the four contributions as vectors over j
    j_vals = np.arange(2*n - 1)
    d_vals = j_vals - (n-1)  # d ranges from -(n-1) to n-1
    
    delta = np.zeros(2*n - 1)
    
    # Term 1: -(1-h[a-d]) where 0 <= a-d < n
    # a-d in [0, n-1] => d in [a-(n-1), a]
    # j in [a-(n-1)+(n-1), a+(n-1)] = [a, a+n-1]
    idx = a - d_vals  # this is m = a-d
    valid1 = (idx >= 0) & (idx < n)
    delta[valid1] -= (1.0 - h[idx[valid1]])
    
    # Term 2: +h[a+d] where 0 <= a+d < n
    # a+d in [0, n-1] => d in [-a, n-1-a]
    idx2 = a + d_vals
    valid2 = (idx2 >= 0) & (idx2 < n)
    delta[valid2] += h[idx2[valid2]]
    
    # Term 3: +(1-h[b-d]) where 0 <= b-d < n
    idx3 = b - d_vals
    valid3 = (idx3 >= 0) & (idx3 < n)
    delta[valid3] += (1.0 - h[idx3[valid3]])
    
    # Term 4: -h[b+d] where 0 <= b+d < n
    idx4 = b + d_vals
    valid4 = (idx4 >= 0) & (idx4 < n)
    delta[valid4] -= h[idx4[valid4]]
    
    return delta
```

Actually, I realize there might be an even better approach. Let me think about what structure the optimal solution has.

For a binary sequence of length n with n/2 ones, the overlap at lag d is:
overlap(d) = #{m: h[m+d]=1, h[m]=0}

This is the number of "inversions" at shift d. If the sequence were perfectly "balanced" (ones and zeros alternating), then for any shift d, roughly half the overlapping positions would have h[m+d]=1 and h[m]=0, giving overlap ≈ N/4.

But we can do better by clustering. For example, if all ones are on the left and all zeros on the right:
- For positive d: overlap(d) = min(n/2, n-d) approximately (lots of 1→0 transitions)
- For negative d: overlap(d) ≈ 0 (mostly 0→1, not 1→0)

So the max would be about n/2, giving C5 ≈ (n/2) * (2/n) = 1. That's terrible.

A more balanced distribution is needed. The key is to make the sequence "spread out" so that for every shift, the overlap is about the same.

This is related to "difference sets" in combinatorics! A (v, k, λ) difference set is a subset D of a group G of size v such that every nonzero group element can be expressed as d1-d2 (d1,d2 ∈ D) in exactly λ ways.

For our problem, we want a subset of {0, ..., n-1} of size n/2 such that the "cross-correlation" is as uniform as possible.

This is related to "Sidon sequences", "Golomb rulers", and "tactical configurations".

For our specific problem (binary sequence with balanced density), the optimal solution is related to "binary sequences with low autocorrelation" - like Barker sequences or m-sequences.

However, these are typically defined for the periodic case (circular correlation). Our problem uses aperiodic correlation, which is slightly different.

```python
import numpy as np
import time

def evaluate_c5(h):
    n = len(h)
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(c) * dx)

def project_box_sum(h, target_sum):
    n = len(h)
    lo, hi = -2.0, 3.0
    for _ in range(70):
        mid = (lo + hi) * 0.5
        p = np.clip(h - mid, 0.0, 1.0)
        if p.sum() > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) * 0.5, 0.0, 1.0)

def compute_delta(h, a, b, n, d_vals):
    j_len = 2 * n - 1
    delta = np.zeros(j_len)
    idx1 = a - d_vals
    m1 = (idx1 >= 0) & (idx1 < n)
    delta[m1] -= (1.0 - h[idx1[m1]])
    idx2 = a + d_vals
    m2 = (idx2 >= 0) & (idx2 < n)
    delta[m2] += h[idx2[m2]]
    idx3 = b - d_vals
    m3 = (idx3 >= 0) & (idx3 < n)
    delta[m3] += (1.0 - h[idx3[m3]])
    idx4 = b + d_vals
    m4 = (idx4 >= 0) & (idx4 < n)
    delta[m4] -= h[idx4[m4]]
    return delta

def local_search(h, time_limit, rng):
    n = len(h)
    dx = 2.0 / n
    d_vals = np.arange(2 * n - 1) - (n - 1)
    over = np.correlate(h, 1.0 - h, mode="full").astype(float).copy()
    cur_max = float(np.max(over))
    best_h = h.copy()
    best_max = cur_max
    start = time.time()
    fail_count = 0

    while time.time() - start < time_limit:
        if fail_count > 800:
            break
        ones = np.where(h == 1.0)[0]
        zeros = np.where(h == 0.0)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break

        best_new_max = cur_max + 1e-9
        best_move = None

        for a in ones:
            for b in zeros:
                delta = compute_delta(h, a, b, n, d_vals)
                new_max = np.max(over + delta)
                if new_max < best_new_max:
                    best_new_max = new_max
                    best_move = (a, b, delta)

        if best_move is not None and best_new_max < cur_max - 1e-12:
            a, b, delta = best_move
            h[a] = 0.0
            h[b] = 1.0
            over = over + delta
            cur_max = best_new_max
            fail_count = 0
            if cur_max < best_max:
                best_max = cur_max
                best_h = h.copy()
        else:
            fail_count += 1
            a = ones[rng.integers(len(ones))]
            b = zeros[rng.integers(len(zeros))]
            delta = compute_delta(h, a, b, n, d_vals)
            h[a] = 0.0
            h[b] = 1.0
            over = over + delta
            cur_max = float(np.max(over))

    return best_h, best_max * dx

def subgradient_descent(h, time_limit):
    n = len(h)
    dx = 2.0 / n
    target = n / 2.0
    h = project_box_sum(h.copy(), target)
    best_h = h.copy()
    best_c5 = evaluate_c5(h)
    start = time.time()
    alpha = 1.0 / np.sqrt(n)
    n_iter = 100000
    fail_count = 0
    it = 0

    while time.time() - start < time_limit and it < n_iter:
        it += 1
        T = 5.0 + 40.0 * it / n_iter
        c = np.correlate(h, 1.0 - h, mode="full")
        Tc = T * c
        Tc = Tc - np.max(Tc)
        w = np.exp(Tc)
        w_sum = w.sum()
        if w_sum < 1e-300:
            break
        w /= w_sum

        grad = np.zeros(n)
        for j in range(2 * n - 1):
            if w[j] < 1e-8:
                continue
            d = j - (n - 1)
            wi = w[j] * dx
            lo1 = max(0, d)
            hi1 = min(n - 1, n - 1 + d)
            if lo1 <= hi1:
                grad[lo1:hi1 + 1] += wi * (1.0 - h[lo1 - d:hi1 - d + 1])
            lo2 = max(0, -d)
            hi2 = min(n - 1, n - 1 - d)
            if lo2 <= hi2:
                grad[lo2:hi2 + 1] -= wi * h[lo2 + d:hi2 + d + 1]

        h_new = h - alpha * grad
        h_new = project_box_sum(h_new, target)
        c5 = evaluate_c5(h_new)

        if c5 < best_c5:
            best_c5 = c5
            best_h = h_new.copy()
            fail_count = 0
        else:
            fail_count += 1

        h = h_new
        if it % 100 == 0:
            alpha *= 0.98
        if fail_count > 3000:
            alpha = 0.5 / np.sqrt(n)
            fail_count = 0

    return best_h, best_c5

def random_binary(n, n_ones, rng):
    idx = rng.permutation(n)
    result = np.zeros(n)
    result[idx[:n_ones]] = 1.0
    return result

    t0 = time.time()

    best_c5 = 1.0
    best_h = None

        return budget_s - (time.time() - t0)

        else:

        time_per = max(5.0, min(40.0, time_left() * 0.7 / n_restarts))

                n_flips = rng.integers(2, max(3, n // 10) + 1)

                for _ in range(n_flips):
                    if len(ones) > 0 and len(zeros) > 0:
                        a = ones[rng.integers(len(ones))]
                        b = zeros[rng.integers(len(zeros))]
                        h_pert[a], h_pert[b] = h_pert[b], h_pert[a]
                        ones = np.where(h_pert == 1.0)[0]
                        zeros = np.where(h_pert == 0.0)[0]
                h_ls2, c5_ls2 = local_search(h_pert, min(20, time_left() * 0.3), rng)
                if c5_ls2 < best_c5:
                    best_c5 = c5_ls2

            idx = np.argsort(-h_sg)
            h_round = np.zeros(n_sg)
            h_round[idx[:n_ones2]] = 1.0
            c5_round = evaluate_c5(h_round)
            if c5_round < best_c5:
                best_c5 = c5_round
                best_h = h_round.copy()

                if c5_ls3 < best_c5:
                    best_c5 = c5_ls3
                    best_h = h_ls3.copy()

    # Phase 4: Final refinement on best solution found
    if best_h is not None and time_left() > 20:
        n_best = len(best_h)
        if n_best % 2 == 0:
            h_ref, c5_ref = local_search(best_h, min(60, time_left() * 0.5), rng)

            best_h = random_binary(n_fallback, n_fallback // 2, rng)
            best_c5 = evaluate_c5(best_h)

    return best_h, best_c5, len(best_h)
```
