Actually wait, I want to think more about the coordinate descent approach.

For a given h and the current maximum lag ℓ, the contribution at lag ℓ is:
S(ℓ) = Σ_i h[i]·(1 - h[i+ℓ]) for valid i

To reduce S(ℓ), we can:
- For each valid i, if h[i] > h[i+ℓ], decreasing h[i] or increasing h[i+ℓ] helps
- The most efficient pair to adjust is the one with the largest h[i]·(1-h[i+ℓ])

But adjusting h[i] also affects other lags. So we need to be careful.

A simple approach: for the maximum lag, find the pair (i, j=i+ℓ) with the largest contribution, and move h[i] slightly toward h[j] (and vice versa), while maintaining the sum constraint.

Let me implement this:

```python
def coordinate_descent(h, n, max_iters, time_limit, t_start):

            break

        max_idx = np.argmax(corr)

        if lag >= 0:
            ia = np.arange(0, n - lag)
            ib = ia + lag
        else:

        contribs = h[ia] * (1 - h[ib])

        worst = np.argmax(contribs)
        i, j = ia[worst], ib[worst]

        if h[i] > h[j]:
```

This is getting messy. Let me use finite differences for the subgradient.

Actually, let me simplify. The gradient of f_ℓ(h) = Σ_{valid i} h[i](1-h[i+ℓ]) with respect to h[m] is:
- For the first factor: if m is a valid first index (m < n and m+ℓ < n for ℓ≥0, etc.), contributes (1-h[m+ℓ])
- For the second factor: if m-ℓ is a valid first index, contributes -h[m-ℓ]

So ∂f_ℓ/∂h[m] = (1-h[m+ℓ])·1_{valid1} - h[m-ℓ]·1_{valid2}

where valid1 and valid2 are indicator conditions.

For the max over lags, the subgradient is the average of gradients at all maximizing lags (or just one).

```python
def projected_subgradient(h, n, lr, max_iters, t_start, time_limit):
    target_sum = n / 2.0
    dx = 2.0 / n
    h = h.copy()
    
    for it in range(max_iters):
        if time.time() - t_start > time_limit:
            break
        
        corr = compute_corr(h)
        max_val = np.max(corr)
        # Find all maximizing lags (within tolerance)
        max_lags = np.where(corr >= max_val - 1e-6)[0]
        
        # Compute subgradient: average gradient over max lags
        grad = np.zeros(n)
        for k_idx in max_lags:
            lag = k_idx - (n - 1)
            for i in valid_range(n, lag):
                j = i + lag
                grad[i] += (1 - h[j])
                grad[j] += -h[i]
        grad /= len(max_lags)
        
        # Gradient step
        h -= lr * grad
        
        # Project: clip to [0,1] and fix sum
        h = np.clip(h, 0.0, 1.0)
        diff = target_sum - np.sum(h)
        h += diff / n
        h = np.clip(h, 0.0, 1.0)
        
        # Adaptive step size
        lr *= 0.999
        lr = max(lr, 0.0001)
    
    return h
```
