def fourier_perturb(h, rng, n_modes=10, amplitude=0.1):
    """Perturb h by adding random low-frequency Fourier modes."""
    n = len(h)
    perturbation = np.zeros(n)
    for k in range(1, n_modes + 1):
        phase = rng.uniform(0, 2 * np.pi)
        amp = amplitude / k
        if k < n:
            perturbation += amp * np.cos(2 * np.pi * k * np.arange(n) / n + phase)
    return h + perturbation

def block_swap_perturb(h, rng, n_blocks=8):
    """Perturb h by swapping random blocks."""
    n = len(h)
    h = h.copy()
    block_size = n // n_blocks
    for _ in range(3):
        i = rng.randint(0, n_blocks - 1)
        j = rng.randint(0, n_blocks - 1)
        if i == j:
            continue
        si, sj = i * block_size, j * block_size
        ei = si + block_size
        ej = sj + block_size
        # Handle last block
        if i == n_blocks - 1:
            ei = n
        if j == n_blocks - 1:
            ej = n
        h[si:ei], h[sj:ej] = h[sj:ej].copy(), h[si:ei].copy()
    return h

The problem is equivalent to: find a function h: [0,2] → [0,1] with ∫h=1 that minimizes the "maximum mismatch" with its shifts.

One key observation: the maximum is likely achieved at a small lag (like lag 0 or lag 1 or 2 in the discrete case). This is because for small lags, the overlap region is large, so the integral is large.

If the maximum is at lag 0, then we're minimizing ∫h(1-h)dx = ∫h dx - ∫h² dx = 1 - ∫h² dx. So we want to maximize ∫h² dx, which means making h as "peaky" as possible (close to 0 or 1).

But if h is too peaky, then other lags might have large overlaps. So there's a trade-off.

The optimal solution balances: making h as binary as possible (to minimize lag-0 overlap) while ensuring that no other lag has a larger overlap.

This suggests that the optimal h is a step function with a few steps, taking values close to 0 and 1, with the step positions chosen to minimize the worst-case overlap.

Let me try a different approach: **parametric optimization of step positions**.

If h is a step function with M steps, there are M-1 step positions and M step heights. The constraint is that the integral equals 1. We can optimize the step positions and heights.

For M = 10-20 steps, this is a low-dimensional optimization problem that can be solved with standard methods.
