1. Clip to [0,1]
2. Find a threshold θ such that ∑ clip(x_i - θ, 0, 1) = n/2
3. The projection is clip(x - θ, 0, 1)

This is a 1D root-finding problem (bisection on θ).

```python
def proj_box_sum(x, target_sum):
    """Project x onto {y : 0 <= y <= 1, sum(y) = target_sum}."""
    n = len(x)
    # First, find theta such that sum(clip(x - theta, 0, 1)) = target_sum
    lo, hi = x.min() - 1, x.max() + 1
    for _ in range(100):
        mid = (lo + hi) / 2
        s = np.clip(x - mid, 0, 1).sum()
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(x - (lo + hi) / 2, 0, 1)
```
