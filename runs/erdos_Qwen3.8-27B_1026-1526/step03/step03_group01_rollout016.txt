def compute_corr_fft(h):
    n = len(h)
    N = 2 * n - 1
    H = np.fft.rfft(h, N)
    O = np.fft.rfft(1.0 - h, N)
    corr = np.fft.irfft(H * np.conj(O), N)
    return corr[:N]

    grad = np.sum(vf * (1.0 - h[fc]) * w[None, :] - vs * h[sc] * w[None, :], axis=1)

    return obj, grad

    w[active] = 1.0 / len(active)
    
    nj = np.arange(n)[:, None]
    nm = np.arange(2 * n - 1)[None, :]
    fi = nj - nm + n - 1
    si = nj + nm - n + 1

    sc = np.clip(si, 0, n - 1)

            # i or j index is involved
            # This is complex, so let's just evaluate C5 before and after

            # Try a small transfer

                    continue

                h[j] += delta
                h = np.clip(h, 0, 1)

    return h

For k=0: ∫ h(x)(1-h(x)) dx = ∫ h(x) dx - ∫ h(x)² dx = 1 - ∫ h² dx
To minimize this, we want to maximize ∫ h² dx, which means making h as "peaked" as possible (closer to 0 or 1).

For small k: similar, we want h(x) and h(x+k) to be "aligned" (both high or both low).

For k near 1: h(x) and h(x+1) should be "anti-aligned" (one high, other low) to minimize h(x)(1-h(x+1)).

So the optimal h should:
- Be close to 0 or 1 (bimodal)
- Have h(x) ≈ h(x+k) for small k
- Have h(x) ≈ 1-h(x+1) for k near 1
