For Phase 4 (Pair exchange):
The key idea: for each pair (i,j), the change in overlap for shift d is:
ΔO_d = δ * [(1-h[i+d])*I(0≤i+d<n) - h[i-d)*I(0≤i-d<n)] - δ * [(1-h[j+d])*I(0≤j+d<n) - h[j-d]*I(0≤j-d<n)

For the maximum to decrease, we need:
max_d (O_d + ΔO_d) < C5

This is equivalent to: for all d, O_d + δ*(g_i[d] - g_j[d]) < C5
where g_i[d] = (1-h[i+d])*I(0≤i+d<n) - h[i-d]*I(0≤i-d<n)

The maximum feasible δ is:
δ_max = min_{d: g_i[d] > g_j[d]} (C5 - O_d) / (g_i[d] - g_j[d])

If δ_max > 0, we can make progress.

To vectorize: for a fixed i, compute g_i[d] for all d. Then for all j, compute g_j[d] - g_i[d] and find which d's are problematic.

This is O(n²) per sweep (n choices of i, n choices of j, and for each we need O(n) work to check all d). Total: O(n³) per sweep = 512³ ≈ 134M. That's too slow in Python.

Better approach: for a fixed i, precompute g_i. Then for all j simultaneously:
diff_ij = g_i - G[:, j] for all d (where G is an (n, n) matrix with G[j, d] = g_j[d])

Wait, that's still O(n²) per i, so O(n³) total.

Alternative: Instead of checking all pairs, use a greedy approach:
- For each i, find the best j to swap with (the one that most reduces C5)
- Make that swap
- Repeat

For a fixed i, the "best j" is the one that minimizes max_d (O_d + δ*(g_i[d] - g_j[d])).

For small δ, this is approximately minimizing max_d (O_d + δ*(g_i[d] - g_j[d])) ≈ C5 + δ * max_d (g_i[d] - g_j[d]) (for active d).

So we want j such that max_active_d (g_i[d] - g_j[d]) is most negative, i.e., min over j of max_active_d (g_i[d] - g_j[d]).

This is still O(n²) per i but only over the active set (say |S| active shifts), so O(n * |S|) per i. If |S| is small (say 10-50), this is O(n * 50) = O(50n) per sweep, which is fine.

Actually, even simpler: for the active shifts S, compute the "descent direction" for each active shift. The subgradient for shift d is:
gs_d[i] = (1-h[i+d])*I(0≤i+d<n) - h[i-d]*I(0≤i-d<n)

The average subgradient over active shifts gives the descent direction.

Let me simplify and just use the subgradient approach (Phase 3) with careful step size control, and add a "pair swap" as a final polish (Phase 4) using a simpler heuristic.

    corr = np.correlate(h, 1.0 - h, mode="full")

    corr = np.correlate(h, 1.0 - h, mode="full")

def project_to_sum(h, target_sum):
    h = np.clip(h.astype(float).copy(), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        mask = (h > 1e-12) & (h < 1.0 - 1e-12)
        cnt = np.sum(mask)
        if cnt > 0:
            h[mask] += diff / cnt
        else:
            h += diff / len(h)
        h = np.clip(h, 0.0, 1.0)
    return h

def smooth_max_obj(h, alpha):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    m = np.max(corr)
    sh = alpha * (corr - m)
    ms = np.max(sh)
    ev = np.exp(sh - ms)
    return m + (ms + np.log(np.sum(ev))) / alpha

def smooth_max_grad(h, alpha):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    m = np.max(corr)
    sh = alpha * (corr - m)
    ms = np.max(sh)
    ev = np.exp(sh - ms)
    w = ev / np.sum(ev)

    # Vectorized O(n²):

    # T1[i] = sum_j (1-h[j]) * w[n-1+j-i]

    def f(x):
        return smooth_max_obj(x, alpha)
    def g(x):
        return smooth_max_grad(x, alpha)
    cons = [{'type': 'eq', 'fun': lambda x: np.sum(x) - ts, 'jac': lambda x: np.ones(n)}]
    bnds = [(0.0, 1.0)] * n
    try:
        r = minimize(f, h0.copy(), method='SLSQP', jac=g, bounds=bnds,
                     constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-15, 'gtol': 1e-14})
        return project_to_sum(r.x, ts)
    except Exception:
        return project_to_sum(h0, ts)

def active_subgradient(h, n, ts, n_iter=5000, tol=1e-4):
    h = h.copy()
    lr = 0.01
    best_c5 = compute_c5(h)
    for it in range(n_iter):
        overlaps = compute_overlaps(h)
        c5_cur = np.max(overlaps)
        if c5_cur < best_c5 - 1e-10:
            best_c5 = c5_cur
        
        # Active set
        active_mask = overlaps > c5_cur - tol
        n_active = np.sum(active_mask)
        if n_active == 0:
            active_mask = overlaps > c5_cur - 1e-3
            n_active = np.sum(active_mask)
        
        if n_active == 0:
            break
        
        # Subgradient: average of gradients over active shifts
        # For shift d (correlate index m = n-1+d), gradient at position i is:
        # (1-h[i+d])*I(0≤i+d<n) - h[i-d]*I(0≤i-d<n)
        # We need sum over active d of this, averaged.
        
        # For each active shift d, compute the gradient vector and sum.
        # d ranges from -(n-1) to (n-1), but only those where the overlap is active.
        # Active correlate indices: where active_mask is True
        active_indices = np.where(active_mask)[0]
        active_ds = active_indices - (n-1)  # shifts
        
        # For efficiency, only process shifts where |d| < n (all of them) and the overlap region is non-trivial
        # Practically, for small |d| the overlap region is large, for large |d| it shrinks.
        # The active shifts are likely to be small |d| since those have the largest overlaps.
        
        grad = np.zeros(n)
        for d in active_ds:
            d = int(d)
            if d >= 0:
                # (1-h[i+d]) for i where i+d < n
                valid_i = np.arange(n - d)
                grad[valid_i] += (1 - h[valid_i + d])
                # -h[i-d] - but i-d < 0 for i < d, so no valid i
                # Actually for d≥0: i-d is valid when i≥d
                if d > 0:
                    valid_i2 = np.arange(d, n)
                    grad[valid_i2] -= h[valid_i2 - d]
            else:
                dd = -d
                # (1-h[i-dd]) for i where i-dd < n, i.e., i < n+dd (always) and i-dd ≥ 0, i.e., i ≥ dd
                valid_i = np.arange(dd, n)
                grad[valid_i] += (1 - h[valid_i - dd])
                # -h[i+dd] for i where i+dd < n
                valid_i2 = np.arange(n - dd)
                grad[valid_i2] -= h[valid_i2 + dd]
        
        grad /= n_active
        
        # Projected gradient step
        h_new = project_to_sum(h - lr * grad, ts)
        c5_new = compute_c5(h_new)
        
        if c5_new < c5_cur:
            h = h_new
            lr = min(lr * 1.02, 0.1)
        else:
            lr *= 0.7
            if lr < 1e-10:
                break
    
    return h, best_c5

def pair_swap_search(h, n, ts, n_sweeps=50, max_delta=0.1):
    h = h.copy()
    c5_cur = compute_c5(h)
    
    for sweep in range(n_sweeps):
        overlaps = compute_overlaps(h)
        c5_max = np.max(overlaps)
        
        best_improvement = 0
        best_move = None

        # Try random pairs
        rng = np.random.RandomState(sweep * 1000 + 42)

        for _ in range(n_trials):
            i = rng.randint(n)
            j = rng.randint(n)
            if i == j:
                continue
            if h[i] <= 0.01 or h[j] >= 0.99:
                continue
            
            # Try moving delta from i to j
            delta = min(h[i] * 0.5, (1-h[j]) * 0.5, max_delta)
            if delta < 0.005:
                continue
            
            h[i] -= delta
            h[j] += delta
            h = np.clip(h, 0, 1)
            h = project_to_sum(h, ts)
            
            c5_new = compute_c5(h)
            if c5_new < c5_cur:
                c5_cur = c5_new
                h[i] -= 0  # already applied
                best_move = (i, j, delta)
            else:
                h[i] += delta
                h[j] -= delta
                h = np.clip(h, 0, 1)
                h = project_to_sum(h, ts)
        
        if best_move is None:
            # Try smaller deltas
            for _ in range(2000):
                i = rng.randint(n)
                j = rng.randint(n)
                if i == j or h[i] <= 0.005 or h[j] >= 0.995:

                if delta < 0.002:

                h[j] += delta

                else:

                    h[j] -= delta
                    h = np.clip(h, 0, 1)
                    h = project_to_sum(h, ts)
            
            # Check if we made progress
            if compute_c5(h) >= c5_cur:
                break
    
    return h, c5_cur

Hmm, the pair swap with random pairs is going to be slow because each evaluation is O(n) (for np.correlate). With 5000 trials per sweep and 50 sweeps, that's 250k evaluations, each O(n log n) or O(n²) for np.correlate. For n=512, np.correlate is O(n²) = 262k ops, so total is 250k * 262k = 65 billion ops. Way too slow!

I need a faster way to evaluate the effect of a single swap.

**Key optimization**: When we change h[i] by -δ and h[j] by +δ, how does the overlap change?

For shift d, the overlap is:
O_d = sum_k h[k](1-h[k+d]) (for valid k, k+d)

After swap:
ΔO_d = -δ*(1-h[i+d])*I(i+d valid) + δ*h[i-d]*I(i-d valid)  [from changing h[i]]
     + δ*(1-h[j+d])*I(j+d valid) - δ*h[j-d]*I(j-d valid)  [from changing h[j]]

Wait, let me redo this. O_d = sum_k h[k](1-h[k+d])

The terms involving h[i]:
- k=i: h[i](1-h[i+d])
- k+d=i, i.e., k=i-d: h[i-d](1-h[i])

So ∂O_d/∂h[i] = (1-h[i+d])*I(valid) - h[i-d]*I(valid)

After h[i] → h[i]-δ:
ΔO_d (from i) = -δ * [(1-h[i+d])*I(i+d valid) - h[i-d]*I(i-d valid)]

After h[j] → h[j]+δ:
ΔO_d (from j) = +δ * [(1-h[j+d])*I(j+d valid) - h[j-d]*I(j-d valid)]

Total: ΔO_d = δ * [g_j[d] - g_i[d]]
where g_p[d] = (1-h[p+d])*I(0≤p+d<n) - h[p-d]*I(0≤p-d<n)

So the new max is: max_d (O_d + δ*(g_j[d] - g_i[d]))

For this to be < C₅, we need:
For all d: O_d + δ*(g_j[d] - g_i[d]) < C₅

The binding constraint is: δ < (C₅ - O_d) / (g_j[d] - g_i[d]) for all d where g_j[d] > g_i[d].

And we need g_j[d] < g_i[d] for at least the active d's (otherwise the overlap increases).

So the algorithm for a pair swap:
1. Precompute g_i for all i (this is O(n²) total)
2. For a given pair (i,j), compute diff = g_j - g_i (O(n))
3. Find the maximum feasible δ: δ_max = min_{d: diff[d]>0} (C₅ - O_d) / diff[d]
4. If δ_max > threshold, apply the swap with δ = min(δ_max * 0.9, h[i], 1-h[j])

Precomputing g_i for all i:
g_i[d] = (1-h[i+d])*I(0≤i+d<n) - h[i-d]*I(0≤i-d<n)

For each i and d: this is O(1) to compute, and there are n values of d and n values of i, so O(n²) total.

Then for each pair (i,j): O(n) to evaluate. With random sampling of pairs, this is manageable.

But we can do better: instead of random pairs, we can find the best pair more systematically.

For a given i, we want to find j such that:
max_d (O_d + δ*(g_j[d] - g_i[d])) is minimized

For small δ, this is approximately: minimize max_d (O_d + δ*(g_j[d] - g_i[d]))
≈ minimize max_active_d (g_j[d] - g_i[d])  [for the active d's]

So for a given i, the best j is the one that minimizes the maximum of (g_j[d] - g_i[d]) over active d's.

If we precompute g_j for all j and all active d's, this is an O(n * |S|) comparison for each i, where |S| is the number of active shifts.

Total: O(n² * |S|) per sweep. For n=512, |S|≈20: 512² * 20 ≈ 5.2M per sweep. With 100 sweeps: 520M. That's borderline but might work in optimized numpy.

Actually, I can vectorize this:
- G_active: (n, |S|) matrix where G_active[j, s] = g_j[d_s] for active shift d_s
- For a given i, diff = G_active - G_active[i]  (shape (n, |S|))
- worst[j] = max_s diff[j, s]  (shape (n,))
- best_j = argmin(worst)

This is O(n * |S|) per i, vectorized. Total per sweep: O(n² * |S|) but with good constant factor due to vectorization.

Let me implement this approach. It should be much faster than the random pair search.

    cons = [{'type': 'eq', 'fun': lambda x: np.sum(x) - ts, 'jac': lambda x: np.ones(n)}]
    bnds = [(0.0, 1.0)] * n
    try:
        r = minimize(f, h0.copy(), method='SLSQP', jac=g, bounds=bnds,
                     constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-15, 'gtol': 1e-14})
        return project_to_sum(r.x, ts)
    except Exception:
        return project_to_sum(h0, ts)

def compute_g_matrix(h, active_ds):
    """Compute g_i[d] for all i and given list of shifts d.
    Returns (n, len(active_ds)) matrix."""
    n = len(h)
    result = np.zeros((n, len(active_ds)))
    for k, d in enumerate(active_ds):
        d = int(d)
        if d >= 0:
            # g_i[d] = (1-h[i+d]) for i < n-d, minus h[i-d] for i >= d
            result[:n-d, k] = (1 - h[d:])  # (1-h[i+d]) for i=0..n-d-1
            if d > 0:
                result[d:, k] -= h[:n-d]  # -h[i-d] for i=d..n-1
        else:
            dd = -d
            # g_i[d] = (1-h[i-dd]) for i >= dd, minus h[i+dd] for i < n-dd
            result[dd:, k] = (1 - h[:-dd])  # (1-h[i+dd])... wait
            # For d = -dd: g_i[-dd] = (1-h[i-dd])*I(0≤i-dd<n) - h[i+dd]*I(0≤i+dd<n)
            # (1-h[i-dd]) valid for i≥dd: gives (1-h[0]), (1-h[1]), ..., (1-h[n-1-dd])
            # i.e., result[dd:, k] += (1 - h[:n-dd])
            result[dd:, k] += (1 - h[:n-dd])
            # -h[i+dd] valid for i < n-dd: gives -h[dd], -h[dd+1], ..., -h[n-1]
            # i.e., result[:n-dd, k] -= h[dd:]
            result[:n-dd, k] -= h[dd:]
    return result

def active_set_opt(h, n, ts, n_iter=3000, tol=1e-4):
    """Optimize using active-set subgradient with exact C5 evaluation."""
    h = h.copy()
    lr = 0.005
    stall = 0
    
    for it in range(n_iter):
        overlaps = compute_overlaps(h)
        c5_cur = float(np.max(overlaps))
        
        # Active set
        active_mask = overlaps > c5_cur - tol
        n_active = int(np.sum(active_mask))
        if n_active == 0:
            active_mask = overlaps > c5_cur - 1e-3
            n_active = int(np.sum(active_mask))
        if n_active == 0 or n_active > 100:
            # Fall back to top-50
            top_idx = np.argsort(overlaps)[-50:]
            active_mask = np.zeros(len(overlaps), dtype=bool)
            active_mask[top_idx] = True
            n_active = 50
        
        active_indices = np.where(active_mask)[0]
        active_ds = active_indices - (n-1)
        
        # Compute subgradient
        g_mat = compute_g_matrix(h, active_ds)  # (n, n_active)
        grad = g_mat.mean(axis=1)  # Average subgradient
        
        # Projected gradient step
        h_new = project_to_sum(h - lr * grad, ts)
        c5_new = compute_c5(h_new)
        
        if c5_new < c5_cur - 1e-12:
            h = h_new
            stall = 0
            lr = min(lr * 1.01, 0.05)
        else:
            stall += 1
            lr *= 0.85
            if stall > 200 or lr < 1e-10:
                break
    
    return h, compute_c5(h)

def directed_pair_swap(h, n, ts, n_sweeps=100):
    """Directed pair swap: for each i, find best j to swap with."""
    h = h.copy()
    c5_cur = compute_c5(h)
    
    for sweep in range(n_sweeps):
        overlaps = compute_overlaps(h)
        c5_max = float(np.max(overlaps))
        
        # Top active shifts
        top_k = min(30, len(overlaps))
        top_idx = np.argsort(overlaps)[-top_k:]
        active_ds = top_idx - (n-1)
        active_overlaps = overlaps[top_idx]
        
        # Precompute g matrix for active shifts
        g_mat = compute_g_matrix(h, active_ds)  # (n, top_k)
        
        # For each i, find best j:
        # We want to minimize max_s (O_s + δ*(g_j[s] - g_i[s]))
        # For small δ: minimize max_s (g_j[s] - g_i[s]) subject to g_j[s] < g_i[s] for binding s
        
        # More precisely: the max overlap after swap is:
        # max_s (O_s + δ * diff_s) where diff_s = g_j[s] - g_i[s]
        # We need this < c5_max for all s
        # δ_max = min_{s: diff_s > 0} (c5_max - O_s) / diff_s
        
        best_total_improvement = 0
        any_improved = False
        
        # Try each i (or a subset for speed)
        for i in range(n):
            if h[i] < 0.02:
                continue
            diff = g_mat - g_mat[i]  # (n, top_k): diff[j, s] = g_j[s] - g_i[s]
            
            # For each j, find if there's a feasible δ
            # δ_max(j) = min_{s: diff[j,s] > 0} (c5_max - O_s) / diff[j,s]
            # Also bounded by h[i] (can't move more than h[i]) and 1-h[j]
            
            # Vectorized: for each j, compute the minimum over s where diff[j,s]>0
            pos_diff = np.maximum(diff, 0)  # (n, top_k)
            # constraint_s = (c5_max - active_overlaps[s]) / pos_diff[j,s] for pos_diff > 0
            # If pos_diff[j,s] = 0 for all s, then no constraint from active set
            # δ_feas = min_s constraint_s (over s where pos_diff > 0)
            
            with np.errstate(divide='ignore', invalid='ignore'):
                constraints = np.where(pos_diff > 0, (c5_max - active_overlaps[None, :]) / pos_diff, np.inf)
            delta_feas = np.min(constraints, axis=1)  # (n,)
            
            # Also bounded by available mass
            delta_feas = np.minimum(delta_feas, h[i])
            delta_feas = np.minimum(delta_feas, 1.0 - h)  # Can't push j above 1
            delta_feas = np.maximum(delta_feas, 0)
            
            # Find best j
            best_j = int(np.argmax(delta_feas))
            best_delta = float(delta_feas[best_j])
            
            if best_delta > 0.001 and best_j != i:
                # Verify
                h[best_j] += best_delta
                h[i] -= best_delta
                h = np.clip(h, 0, 1)
                h = project_to_sum(h, ts)
                c5_new = compute_c5(h)
                if c5_new < c5_cur:
                    c5_cur = c5_new
                    any_improved = True
                else:
                    # Revert
                    h = project_to_sum(h + (best_delta * (-np.ones(n))) + best_delta * np.zeros(n) + best_delta * (np.ones(n) * np.arange(n) != i).astype(float) * 0 + ... , ts)
                    # Actually let me just redo: h[best_j] -= best_delta; h[i] += best_delta
                    h[i] += best_delta
                    h[best_j] -= best_delta
                    h = np.clip(h, 0, 1)
                    h = project_to_sum(h, ts)
        
        if not any_improved:
            break
    
    return h, c5_cur
