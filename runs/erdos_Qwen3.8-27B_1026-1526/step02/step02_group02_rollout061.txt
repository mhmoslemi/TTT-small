Wait, for the quadratic term h^T W h, the gradient is (W + W^T)h = 2W*h (if W is symmetric).

Is W symmetric? W[m,j] = w_{m-j}. W[j,m] = w_{j-m} = w_{-(m-j)}.
So W is symmetric iff w_k = w_{-k} for all k.

In our problem, the weights w_k are softmax(β * g_k(h)) where g_k(h) is the lag value. In general, g_k ≠ g_{-k}, so w_k ≠ w_{-k}, and W is NOT symmetric.

This complicates the power iteration. The Hessian is W + W^T (not 2W), and the power iteration converges to the top eigenvector of (W+W^T)/2, not W.

For a non-symmetric quadratic h^T W h, the stationary points satisfy (W+W^T)h = 2μ*1 (for the constrained problem). The relevant matrix is the symmetric part (W+W^T)/2.

For the projected gradient method, I should use:
h ← project(h - α * ∇G(h)) = project(h - α * dx * (a - (W+W^T)h))

where (W+W^T)h = W*h + W^T*h.

W*h[m] = sum_j W[m,j] h[j] = sum_j w_{m-j} h[j] = (w * h)[m] (cross-correlation).
W^T*h[m] = sum_j W[j,m] h[j] = sum_j w_{j-m} h[j] = sum_j w_{-(m-j)} h[j].

If I define w_rev[k] = w_{-k}, then W^T*h = (w_rev * h) (cross-correlation with the reversed weights).

So the gradient step is:
h ← project(h + α * dx * ((W+W^T)h - a))
= project(h + α * dx * ((w*h) + (w_rev*h) - a))

This can be computed via two cross-correlations (or one convolution with the symmetric part of w).

For the power iteration (maximizing h^T W h), the update is:
h ← project(h + α * (W+W^T)h) = project(h + α * ((w*h) + (w_rev*h)))

And we subtract the linear term if we're minimizing G.

Actually, for the weighted ascent method, the inner problem is:
min_h G(h) = min_h [dx * a^T h - dx * h^T W h]
= min_h [-dx * h^T W h + dx * a^T h]

Since we want to minimize, and the quadratic term is -h^T W h (which we want to make as negative as possible, i.e., maximize h^T W h), the problem is:
max_h h^T W h - a^T h (ignoring the dx constant)

This is a non-convex maximization. The projected gradient step:
h ← project(h + α * (2*W_sym*h - a)) where W_sym = (W+W^T)/2.

Or equivalently:
h ← project(h + α * ((w*h) + (w_rev*h) - a))

Let me implement this. For n=270, I'll use the direct O(n²) computation.

Actually, you know what, let me simplify. For the weighted ascent method, I'll just use the subgradient of the max:

At the current h, the subgradient of max_k g_k(h) is any convex combination of the gradients of the active g_k. The "steepest descent" direction is the negative of this.

But computing the gradient of g_k with respect to h is:
∂g_k/∂h[m] = dx * (1-h[m-k]) - dx * h[m+k] (for the valid range)

Wait, let me be more careful. g_k(h) = dx * sum_n h[n+k](1-h[n]) for valid n.

∂g_k/∂h[m]: h[m] appears in g_k in two ways:
1. As h[n+k] when n+k = m, i.e., n = m-k: contributes dx*(1-h[m-k]) if m-k is valid.
2. As (1-h[n]) when n = m: contributes -dx*h[m+k] if m+k is valid.

So ∂g_k/∂h[m] = dx * [(1-h[m-k]) * 1_{0≤m-k≤n-1} - h[m+k] * 1_{0≤m+k≤n-1}]

For the max function, the subgradient is:
∂(max_k g_k)/∂h[m] = sum_k p_k * ∂g_k/∂h[m]

where p_k is a probability distribution over the active k's (the "weights" in the softmax).

For the projected subgradient descent:
h ← project(h - η * ∂(max)/∂h)

Let me implement this:

```python
def subgradient_step(h, p_lags, n, eta):
    """One step of projected subgradient descent on max_k g_k."""
    dx = 2.0 / n
    grad = np.zeros(n)
    for k_idx, p_k in enumerate(p_lags):
        if p_k < 1e-15:
            continue
        k = k_idx - (n - 1)  # convert to lag
        # ∂g_k/∂h[m] = dx * [(1-h[m-k]) * 1_{0≤m-k≤n-1} - h[m+k] * 1_{0≤m+k≤n-1}]
        for m in range(n):
            val = 0.0
            mk = m - k
            if 0 <= mk < n:
                val += (1.0 - h[mk])
            mk2 = m + k
            if 0 <= mk2 < n:
                val -= h[mk2]
            grad[m] += p_k * dx * val
    h_new = h - eta * grad
    h_new = project_feasible(h_new, n)
    return h_new
```

But this inner loop over m is O(n) per k, and we have O(n) k values (even if sparse), so it's O(n²) per step. For n=270, that's about 72900 operations per step, which is fine.

But in Python, the inner loop is slow. Let me vectorize:

```python
def subgradient_step_vec(h, w_lags, n, eta):
    """Vectorized subgradient step.
    w_lags: array of length 2n-1, w_lags[k+n-1] = weight for lag k."""
    dx = 2.0 / n
    grad = np.zeros(n)
    for idx in range(2 * n - 1):
        w = w_lags[idx]
        if w < 1e-15:
            continue
        k = idx - (n - 1)  # lag
        # Term 1: sum_m (1-h[m-k]) * 1_{0≤m-k≤n-1}
        # This is: for m from max(0,k) to n-1 (k≥0) or m from 0 to n-1+... 
        # Actually: m-k in [0,n-1] means m in [k, k+n-1], intersected with [0,n-1]
        if k >= 0:
            m_range = slice(k, n)
            mk_range = slice(0, n - k)
            term1 = (1.0 - h[mk_range])  # 1-h[m-k] for m=k,...,n-1
            # This contributes to grad[m] for m = k, k+1, ..., n-1
            grad[m_range] += w * dx * term1
        else:
            m_range = slice(0, n + k)  # 0 to n-1+k
            mk_range = slice(-k, n)  # -k to n-1
            term1 = (1.0 - h[mk_range])
            grad[m_range] += w * dx * term1
