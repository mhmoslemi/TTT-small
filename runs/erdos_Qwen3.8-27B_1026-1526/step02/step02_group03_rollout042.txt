OK this is getting too complex to implement efficiently in the "compute the exact optimal delta" way. Let me simplify to a more straightforward approach:

**Simplified coordinate descent:**
For each coordinate i:
1. Try h[i] + delta for delta in a set of values
2. For each, adjust the sum by adding the residual to the coordinate closest to 0.5
3. Project to [0,1]
4. Evaluate C5
5. Keep the best

This is O(n * num_deltas * n²) per sweep = O(n³ * num_deltas). For n=77 and num_deltas=10, that's about 4.6M * 10 = 46M operations per sweep. In numpy, each "evaluate C5" is fast (one correlate call), so this should be manageable.

Actually, let me benchmark: np.correlate for n=77 with mode="full" produces an array of length 153. This is very fast, probably ~10 microseconds. So 770 evaluations per sweep (77 coords * 10 deltas) would take about 8ms. That means we can do ~1000 sweeps in 8 seconds. 

Let me go with this simpler approach but make it more effective:
- Use adaptive step sizes (start large, decrease over time)
- Use the exact max (no smoothing)
- Try both positive and negative deltas
- Use multiple "anchor" coordinates for the sum adjustment

```python
        progress = (time.time() - start) / max_time
        d_idx = min(int(progress * len(base_deltas)), len(base_deltas) - 1)
        deltas = [d * sign for d in base_deltas[d_idx:] for sign in [1, -1]]

                break

            for d in deltas:

                if new_val < 0 or new_val > 1:
                    continue
                h_new = best.copy()
                h_new[i] = new_val
                # Adjust sum
                target = n / 2.0
                diff = target - np.sum(h_new)
                if abs(diff) < 1e-15:
                    pass
                else:

                    others = np.delete(np.arange(n), i)
```

```python
def smooth_max(values, tau):
    v = values / tau
    vmax = np.max(v)
    return tau * (vmax + np.log(np.sum(np.exp(v - vmax))))

def objective_slqp(x, n, tau):
    dx = 2.0 / n
    g = 1.0 - x
    corr = np.correlate(x, g, mode="full")
    return smooth_max(corr, tau) * dx

def constraint_slqp(x, n):
    return np.sum(x) - n / 2.0

def project_feasible(h, n):
    target = n / 2.0
    h = np.array(h, dtype=float)
    h = np.clip(h, 0.0, 1.0)
    s = np.sum(h)
    if abs(s - target) < 1e-10:
        return h
    lo, hi = -2.0, 2.0
    for _ in range(100):
        mid = 0.5 * (lo + hi)
        proj = np.clip(h + mid, 0.0, 1.0)
        if np.sum(proj) > target:
            hi = mid
        else:
            lo = mid
    result = np.clip(h + 0.5 * (lo + hi), 0.0, 1.0)
    diff = target - np.sum(result)
    if abs(diff) > 1e-14:
        idx = int(np.argmin(np.abs(result - 0.5)))
        result[idx] = np.clip(result[idx] + diff, 0.0, 1.0)
    return result

def pair_descent(h, n, max_time, seed):
    best = h.copy()
    best_c5 = evaluate_c5(best)
    start = time.time()
    rng = np.random.RandomState(seed)
    
    # Precompute all pairs
    pairs = [(i, j) for i in range(n) for j in range(i + 1, n)]
    
    no_improve = 0
    sweep = 0
    
    while time.time() - start < max_time:
        sweep += 1
        if no_improve >= 5:
            break
        
        progress = min(1.0, (time.time() - start) / max_time)
        
        # Adaptive max delta
        max_d = 0.05 * max(0.01, (1.0 - progress) ** 0.7)
        
        # Number of delta levels
        n_levels = 8 if progress < 0.3 else (5 if progress < 0.7 else 3)
        
        improved = False
        rng.shuffle(pairs)
        
        for i, j in pairs:
            if time.time() - start > max_time:
                break
            
            for level in range(1, n_levels + 1):
                d = max_d / level
                
                # Direction 1: h[i] += d, h[j] -= d
                if best[i] + d <= 1.0 + 1e-12 and best[j] - d >= -1e-12:
                    bi, bj = best[i], best[j]
                    best[i] = min(1.0, bi + d)
                    best[j] = max(0.0, bj - d)
                    c5_new = evaluate_c5(best)
                    if c5_new < best_c5 - 1e-13:
                        best_c5 = c5_new
                        improved = True
                    else:
                        best[i] = bi
                        best[j] = bj
                
                # Direction 2: h[i] -= d, h[j] += d
                if best[i] - d >= -1e-12 and best[j] + d <= 1.0 + 1e-12:
                    bi, bj = best[i], best[j]
                    best[i] = max(0.0, bi - d)
                    best[j] = min(1.0, bj + d)
                    c5_new = evaluate_c5(best)
                    if c5_new < best_c5 - 1e-13:
                        best_c5 = c5_new
                        improved = True
                    else:
                        best[i] = bi
                        best[j] = bj
        
        if improved:
            no_improve = 0
        else:
            no_improve += 1
    
    return best, best_c5

def slqp_polish(h, n, max_time):
    best = h.copy()
    best_c5 = evaluate_c5(best)
    start = time.time()
    
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': constraint_slqp, 'args': (n,)}]
    
    tau_list = [0.01, 0.005, 0.002, 0.001, 0.0005]
    current = best.copy()
    
    for tau in tau_list:
        if time.time() - start > max_time:
            break
        try:
            res = minimize(
                objective_slqp, current,
                method='SLSQP',
                args=(n, tau),
                bounds=bounds,
                constraints=cons,
                options={'maxiter': 200, 'ftol': 1e-15}
            )
            current = project_feasible(res.x, n)
            c5 = evaluate_c5(current)
            if c5 < best_c5:
                best_c5 = c5
                best = current.copy()
        except Exception:
            pass
    
    return best, best_c5
```

Let me also add one more trick: **line search along the pair direction**. Instead of trying fixed deltas, do a binary search for the optimal delta along each pair direction.

For a pair (i, j) with direction (h[i] += t, h[j] -= t):
- The objective as a function of t is: F(t) = max_m (corr[m] + t * effect_m) * dx
- This is a piecewise linear function of t (convex in t, since it's the max of linear functions)
- We can find the minimum by ternary search or by checking breakpoints

But the piecewise linear function has up to O(n) breakpoints, so finding the minimum exactly requires O(n) evaluations per pair. That's the same as trying n different deltas.

Actually, for a piecewise linear convex function, the minimum is at a breakpoint or at the boundary. The breakpoints are where two of the "lines" cross. There are at most O(n) breakpoints, but finding them all is expensive.

A simpler approach: **ternary search** on t ∈ [t_min, t_max]. Since F(t) is convex (max of linear functions), ternary search works. It takes O(log(1/epsilon)) evaluations to find the minimum to precision epsilon.

Let me implement this:

```python
def line_search_pair(best, i, j, n, dx):
    """Find optimal t for h[i]+t, h[j]-t using ternary search."""
    # Feasible range for t
    t_lo = max(-best[i], best[j] - 1)
    t_hi = min(1 - best[i], best[j])
    
    if t_lo >= t_hi:
        return 0.0
    
    # Ternary search
    a, b = t_lo, t_hi
    for _ in range(40):  # enough for double precision
        m1 = a + (b - a) / 3
        m2 = b - (b - a) / 3
        
        best[i] += m1
        best[j] -= m1
        f1 = evaluate_c5(best)
        best[i] -= m1
        best[j] += m1
        
        best[i] += m2
        best[j] -= m2
        f2 = evaluate_c5(best)
        best[i] -= m2
        best[j] += m2
        
        if f1 < f2:
            b = m2
        else:
            a = m1
    
    return 0.5 * (a + b)
```
