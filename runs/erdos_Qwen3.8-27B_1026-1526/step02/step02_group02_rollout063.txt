**Alternative: Use the structure of the problem more directly**

The objective is max_k c(k) where c(k) = sum_i h[i](1-h[i+k]).

This is a min-max problem. A dual approach:
min_h max_k c(k) = min_h { t : c(k) ≤ t ∀k }

For a fixed t, the feasibility problem is:
find h such that 0≤h≤1, sum(h)=n/2, and c(k) ≤ t ∀k.

The constraints c(k) ≤ t are BILINEAR (quadratic) in h. This is a non-convex feasibility problem in general.

However, we can use the method of alternating projections or the Dykstra-Motzkin algorithm:
1. Project onto {0≤h≤1, sum(n/2)} → easy (clipping + scaling)
2. Project onto {c(k) ≤ t ∀k} → hard (bilinear constraints)

The projection onto the bilinear constraint set is non-trivial. But we can use a penalty approach:
min_h (1/2)||h - h_old||² + μ * sum_k max(0, c(k) - t)²

This is a non-convex quadratic problem, but can be solved approximately by fixing one side of the bilinear term.
