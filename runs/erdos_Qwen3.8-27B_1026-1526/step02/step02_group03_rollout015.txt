c[n-1-k] = ∑_{i=k}^{n-1} h[i-k](1-h[i]) = ∑_{j=0}^{n-1-k} h[j](1-h[j+k]) (substituting j=i-k)

So c[n-1+k] = ∑ h[j+k](1-h[j]) and c[n-1-k] = ∑ h[j](1-h[j+k]).

These are related: c[n-1-k] = ∑ h[j] - ∑ h[j]h[j+k] = (sum of h over valid range) - ∑ h[j]h[j+k]
And c[n-1+k] = ∑ h[j+k](1-h[j]) = ∑_{valid} h[j+k] - ∑ h[j]h[j+k]

So c[n-1+k] - c[n-1-k] = ∑_{valid} h[j+k] - ∑_{valid} h[j] = (partial sum of h) - (partial sum of h)

For the gradient of c_{k*} (where k* is the shift, and the correlation index is m* = n-1+k*):

c_{k*} = ∑_{i valid} h[i+k*](1-h[i])

∂c_{k*}/∂h[j] = (1-h[j-k*]) * [j-k* valid] + (-h[j+k*]) * [j valid in the "1-h[i]" part]

More precisely:
- h[j] appears in the "h[i+k*]" term when i+k*=j, i=j-k*, valid if the sum includes i=j-k*
- h[j] appears in the "(1-h[i])" term when i=j, valid if the sum includes i=j

For the full correlation index m (corresponding to shift k = m-(n-1)):
The sum is over i such that 0≤i<n and 0≤i+k<n.

So:
∂c/∂h[j] = (1-h[j-k]) * [0≤j-k<n AND 0≤(j-k)+k<n AND (j-k) is in the valid i range]
          + (-h[j+k]) * [0≤j<n AND 0≤j+k<n AND j is in the valid i range]

The valid i range is: max(0, -k) ≤ i ≤ min(n-1, n-1-k)

So:
∂c/∂h[j]:
- First term: valid if max(0,-k) ≤ j-k ≤ min(n-1, n-1-k)
  → max(k, 0) ≤ j ≤ min(n-1, n-1-k) + k = min(n-1+k, n-1)
  For k≥0: k ≤ j ≤ n-1-k+k = n-1... wait that's k ≤ j ≤ n-1. But also j-k ≤ n-1-k means j ≤ n-1. And j-k ≥ 0 means j ≥ k. So k ≤ j ≤ n-1.
  Hmm, but also j-k ≤ min(n-1, n-1-k). For k≥0: min(n-1, n-1-k) = n-1-k (since k≥0). So j-k ≤ n-1-k, i.e., j ≤ n-1. And j-k ≥ max(0,-k) = 0, i.e., j ≥ k.
  So for k≥0: k ≤ j ≤ n-1.
  For k<0 (let q=-k>0): max(0,q) ≤ j+q ≤ min(n-1, n-1+q) = n-1. So q ≤ j+q ≤ n-1, i.e., 0 ≤ j ≤ n-1-q = n-1+k.
  So for k<0: 0 ≤ j ≤ n-1+k.

- Second term: valid if max(0,-k) ≤ j ≤ min(n-1, n-1-k)
  For k≥0: 0 ≤ j ≤ n-1-k.
  For k<0: max(0,q) = q ≤ j ≤ min(n-1, n-1+q) = n-1. So q ≤ j ≤ n-1, i.e., -k ≤ j ≤ n-1.

So:
For k ≥ 0:
  ∂c/∂h[j] = (1-h[j-k]) * [k ≤ j ≤ n-1] - h[j+k] * [0 ≤ j ≤ n-1-k]
  Note: for j in [k, n-1-k], both terms are active.
  For j in [n-1-k+1, n-1] (i.e., j > n-1-k), only the first term.
  For j in [0, k-1], only the second term.
  For j in [k, n-1-k], both terms.

For k < 0 (q = -k):

For k = 0:

def compute_subgradient(h, n, top_k=1):
    """Compute subgradient of C5 at h (average over top_k active lags)."""
    dx = 2.0 / n
    corr = np.correlate(h, 1-h, mode="full")
    max_val = np.max(corr)
    # Get indices of top_k lags
    indices = np.argsort(corr)[::-1][:top_k]
    
    grad = np.zeros(n)
    for m in indices:
        k = m - (n - 1)  # shift
        g = np.zeros(n)
        if k == 0:
            g[:] = 1.0 - 2.0 * h
        elif k > 0:
            # First term: (1-h[j-k]) for j in [k, n-1]
            for j in range(k, n):
                g[j] += (1.0 - h[j-k])
            # Second term: -h[j+k] for j in [0, n-1-k]
            for j in range(0, n-k):
                g[j] -= h[j+k]
        else:
            q = -k
            # First term: (1-h[j+q]) for j in [0, n-1-q]
            for j in range(0, n-q):
                g[j] += (1.0 - h[j+q])
            # Second term: -h[j-q] for j in [q, n-1]
            for j in range(q, n):
                g[j] -= h[j-q]
        grad += g
    
    grad /= len(indices)
    return dx * grad

Actually, here's another idea that might be more effective: **Alternating between SLSQP and "active set" optimization**

1. Run SLSQP to get close to the optimum
2. Identify the top lag k* (or top few lags)
3. Optimize specifically to reduce c_{k*} (using SLSQP with objective = c_{k*} * dx, not the max)
4. Check if other lags have now become the max
5. Repeat

This is like a "coordinate descent in the space of lags" - we alternate which lag we're optimizing for.

def active_set_opt(h, n, num_rounds=20):

    best_c5 = evaluate_c5(h)

    for round_num in range(num_rounds):
        # Find the max lag
        corr = np.correlate(h, 1-h, mode="full")
        max_idx = np.argmax(corr)
        k_star = max_idx - (n-1)
        
        # Optimize to minimize c_{k_star}
        def obj_active(x, n, k_target):
            corr = np.correlate(x, 1-x, mode="full")
            return corr[n-1+k_target] * (2.0/n)
        
        try:
            res = minimize(obj_active, h, method='SLSQP',
                          args=(n, k_star), bounds=bounds,
                          constraints=cons,
                          options={'maxiter': 100, 'ftol': 1e-14})
            h_new = project_feasible(res.x, n)
            c5_new = evaluate_c5(h_new)
            if c5_new < best_c5:
                best_c5 = c5_new
                h = h_new.copy()
        except Exception:
            pass
    
    return h, best_c5

import numpy as np
from scipy.optimize import minimize
from scipy.interpolate import interp1d
import time

def evaluate_c5(h):
    n = len(h)
    dx = 2.0 / n
    g = 1.0 - h
    corr = np.correlate(h, g, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.array(h, dtype=float)
    h = np.clip(h, 0.0, 1.0)
    s = np.sum(h)
    if abs(s - target) < 1e-12:
        return h
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = 0.5 * (lo + hi)
        proj = np.clip(h + mid, 0.0, 1.0)
        if np.sum(proj) > target:
            hi = mid
        else:
            lo = mid
    result = np.clip(h + 0.5 * (lo + hi), 0.0, 1.0)
    diff = target - np.sum(result)
    if abs(diff) > 1e-14:
        idx = int(np.argmin(np.abs(result - 0.5)))
        result[idx] = np.clip(result[idx] + diff, 0.0, 1.0)
    return result

def smooth_max(values, tau):
    v = values / tau
    vmax = np.max(v)
    v_shifted = np.clip(v - vmax, -400, 400)
    return tau * (vmax + np.log(np.sum(np.exp(v_shifted))))

def objective_fn(x, n, tau):
    dx = 2.0 / n
    g = 1.0 - x
    corr = np.correlate(x, g, mode="full")
    return smooth_max(corr, tau) * dx

def objective_single_lag(x, n, lag_idx):
    dx = 2.0 / n
    g = 1.0 - x
    corr = np.correlate(x, g, mode="full")
    return corr[lag_idx] * dx

def constraint_fn(x, n):
    return np.sum(x) - n / 2.0

def slsqp_run(h0, n, tau_list, maxiter):
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': constraint_fn, 'args': (n,)}]
    h = project_feasible(h0.copy(), n)
    for tau in tau_list:
        try:
            res = minimize(objective_fn, h, method='SLSQP',
                          args=(n, tau), bounds=bounds,
                          constraints=cons,
                          options={'maxiter': maxiter, 'ftol': 1e-15})
            h = project_feasible(res.x, n)
        except Exception:
            pass
    return h, evaluate_c5(h)

def slsqp_single_lag(h, n, lag_idx, maxiter=100):
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': constraint_fn, 'args': (n,)}]
    try:
        res = minimize(objective_single_lag, h, method='SLSQP',
                      args=(n, lag_idx), bounds=bounds,
                      constraints=cons,
                      options={'maxiter': maxiter, 'ftol': 1e-14})
        return project_feasible(res.x, n)
    except Exception:
        return h

def compute_subgrad(h, n, top_k=3):
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode="full")
    indices = np.argsort(corr)[::-1][:top_k]
    grad = np.zeros(n)
    for m in indices:
        k = int(m - (n - 1))
        g = np.zeros(n)
        if k == 0:
            g[:] = 1.0 - 2.0 * h
        elif k > 0:
            g[k:] += (1.0 - h[:n - k])
            g[:n - k] -= h[k:]
        else:
            q = -k
            g[:n - q] += (1.0 - h[q:])
            g[q:] -= h[:n - q]
        grad += g
    grad /= len(indices)
    return dx * grad

def subgrad_descent(h, n, num_steps, alpha_init, alpha_decay, top_k=3):
    h = h.copy()
    best = h.copy()
    best_c5 = evaluate_c5(h)
    alpha = alpha_init
    stuck = 0
    for step in range(num_steps):
        grad = compute_subgrad(h, n, top_k)
        grad = grad - np.mean(grad)
        h_new = h - alpha * grad
        h_new = project_feasible(h_new, n)
        c5_new = evaluate_c5(h_new)
        if c5_new < best_c5 - 1e-15:
            best_c5 = c5_new
            best = h_new.copy()
            stuck = 0
        else:
            stuck += 1
        h = h_new
        alpha *= alpha_decay
        if stuck > 200:
            alpha = alpha_init * 0.5
            h = best.copy()
            stuck = 0
    return best, best_c5

def pair_descent(h, n, rng, num_sweeps=5, pairs_per_sweep=150):
    h = h.copy()
    best_c5 = evaluate_c5(h)
    for sweep in range(num_sweeps):
        improved = False
        for _ in range(pairs_per_sweep):
            i = rng.randint(n)
            j = rng.randint(n)
            if i == j:
                continue
            lo = max(-h[i], h[j] - 1.0)
            hi = min(1.0 - h[i], h[j])
            if hi - lo < 1e-7:
                continue
            save_i, save_j = h[i], h[j]
            a, b = lo, hi
            for _ in range(25):
                m1 = a + (b - a) / 3.0
                m2 = b - (b - a) / 3.0
                h[i], h[j] = save_i + m1, save_j - m1
                c1 = evaluate_c5(h)
                h[i], h[j] = save_i + m2, save_j - m2
                c2 = evaluate_c5(h)
                if c1 < c2:
                    b = m2
                else:
                    a = m1
            best_delta = 0.5 * (a + b)
            if abs(best_delta) < 1e-9:
                h[i], h[j] = save_i, save_j
                continue
            h[i], h[j] = save_i + best_delta, save_j - best_delta
            c5_new = evaluate_c5(h)
            if c5_new < best_c5 - 1e-14:
                best_c5 = c5_new
                improved = True
        if not improved:
            break
    return h, best_c5

def active_set_cycle(h, n, num_rounds=15):
    h = h.copy()
    best_c5 = evaluate_c5(h)
    for _ in range(num_rounds):
        corr = np.correlate(h, 1 - h, mode="full")
        max_idx = int(np.argmax(corr))
        h_old = h.copy()
        h = slsqp_single_lag(h, n, max_idx, maxiter=80)

        else:
            h = h_old
            break
    return h, best_c5

def interpolate_to_n(parent, new_n):
    if len(parent) == new_n:
        return parent.copy()
    x_old = np.linspace(0, 2, len(parent), endpoint=False)
    x_new = np.linspace(0, 2, new_n, endpoint=False)
    f = interp1d(x_old, parent, kind='cubic', fill_value='extrapolate', bounds_error=False)
    h_new = np.clip(f(x_new), 0, 1)
    return project_feasible(h_new, new_n)
