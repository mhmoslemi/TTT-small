min_h max_k f_k(h) where f_k(h) = corr[k] * dx

This is a convex-in-the-max but non-convex-in-h problem (because f_k is quadratic in h). However, we can use the following approach:

**Alternating Minimization**:
1. Fix the current h, find the worst lag k*
2. Minimize f_{k*}(h) = corr[k*] * dx subject to constraints (this is a QP!)
3. Repeat

Step 2 is a QP: minimize sum_i h[i] * (1-h[i+k*]) (with appropriate indexing) subject to 0≤h[i]≤1 and sum(h)=n/2. This is a quadratic program that can be solved exactly!

Wait, actually corr[k] = sum_m h[m+k]*(1-h[m]) is NOT convex in h (it has -h[m]*h[m+k] terms which are indefinite). So it's not a QP.

But we can linearize: at the current h, the first-order approximation of corr[k] is:
corr[k] ≈ corr[k]|_{h0} + sum_j grad_j * (h[j] - h0[j])

And minimize this linear function subject to constraints. This gives a linear program (LP)!

**LP-based alternating approach**:
1. Find worst lag k* at current h
2. Linearize corr[k*] at current h
3. Solve LP: min sum_j grad_j * h[j] subject to 0≤h≤1, sum(h)=n/2
4. Update h, repeat

This is essentially a cutting-plane or SLP (Sequential Linear Programming) approach. It should converge well for this type of problem.

Actually, even better: I can implement a "conditional gradient" (Frank-Wolfe) style approach:
1. At current h, compute gradient of the objective
2. Find the point in the feasible set that minimizes the linear approximation
3. Move towards that point

The "linearization oracle" step (finding min of linear function over the polytope {0≤h≤1, sum(h)=n/2}) is easy: sort the gradient components, and the solution is to set the n/2 smallest gradient components to 1 and the rest to 0 (well, not exactly, because we need sum = n/2).

Wait, the feasible set is {h : 0≤h≤1, sum(h)=n/2}. The linear minimization over this set:
- If the gradient is sorted as g[σ(1)] ≤ g[σ(2)] ≤ ... ≤ g[σ(n)]
- The optimal solution sets h[σ(1)] = ... = h[σ(n/2)] = 1 and h[σ(n/2+1)] = ... = h[σ(n)] = 0
- (Assuming n is even; for odd n, one variable is at 0.5)

Wait, n/2 might not be an integer. For n odd, n/2 is not integer. E.g., n=59, n/2=29.5. So we need sum(h) = 29.5, which means 29 variables at 1, 1 variable at 0.5, and 29 variables at 0. Or 28 at 1, 3 at 0.5, 28 at 0, etc.

The exact solution to min c^T h subject to 0≤h≤1, sum(h)=n/2:
- Sort indices by c[i]
- Set the smallest n/2 (in the continuous sense) to 1
- Since n/2 might be fractional, the last one is fractional

For n=59, n/2 = 29.5:
- Sort c: c[σ(1)] ≤ ... ≤ c[σ(59)]
- h[σ(1)] = h[σ(2)] = ... = h[σ(29)] = 1
- h[σ(30)] = 0.5
- h[σ(31)] = ... = h[σ(59)] = 0
- Sum = 29 + 0.5 = 29.5 ✓

For n=60, n/2 = 30:
- h[σ(1)] = ... = h[σ(30)] = 1
- h[σ(31)] = ... = h[σ(60)] = 0
- Sum = 30 ✓

This is the Frank-Wolfe conditional gradient step! Let me implement this.

**Frank-Wolfe (Conditional Gradient) for our problem:**

```
h = initial feasible point
for t = 1, 2, ...:
    compute gradient g = ∇f(h) (for smooth_max objective)
    find s = argmin_{v in P} g^T v (where P is our polytope)
    step_size = 2/(t+2) (or use line search)
    h = (1 - step_size) * h + step_size * s
```

This is simple, fast, and doesn't require any optimization solver! The "linear minimization oracle" is just sorting.

import numpy as np
from scipy.optimize import minimize, linprog
from scipy.interpolate import interp1d
import time

def evaluate_c5(h):
    n = len(h)
    dx = 2.0 / n
    g = 1.0 - h
    corr = np.correlate(h, g, mode="full")
    return float(np.max(corr) * dx)

def smooth_max(values, tau):
    v = values / tau
    vmax = np.max(v)
    return tau * (vmax + np.log(np.sum(np.exp(v - vmax))))

def compute_corr_full(h):
    g = 1.0 - h
    return np.correlate(h, g, mode="full")

def smooth_max_and_grad(h, n, tau):
    dx = 2.0 / n
    corr = compute_corr_full(h)
    v = corr / tau
    vmax = np.max(v)
    exp_v = np.exp(v - vmax)
    sum_exp = np.sum(exp_v)
    sm_val = tau * (vmax + np.log(sum_exp)) * dx
    weights = exp_v / sum_exp
    grad = np.zeros(n)
    n_corr = len(corr)
    for ki in range(n_corr):
        lag = ki - (n - 1)
        w = weights[ki] * dx
        if w < 1e-12:
            continue
        if lag == 0:
            grad += w * (1.0 - h)
            grad += w * (-h)
        elif lag > 0:
            j1 = np.arange(lag, n)
            grad[j1] += w * (1.0 - h[j1 - lag])
            j2 = np.arange(0, n - lag)
            grad[j2] += w * (-h[j2 + lag])
        else:
            L = -lag
            j1 = np.arange(0, n - L)
            grad[j1] += w * (1.0 - h[j1 + L])
            j2 = np.arange(L, n)
            grad[j2] += w * (-h[j2 - L])
    return sm_val, grad

def obj_func(h, n, tau):
    dx = 2.0 / n
    corr = compute_corr_full(h)
    return smooth_max(corr, tau) * dx

def constraint_func(h, n):
    return np.sum(h) - n / 2.0

def project_feasible(h, n):
    target = n / 2.0
    lo = -3.0
    hi = 3.0
    for _ in range(200):
        mid = 0.5 * (lo + hi)
        proj = np.clip(h + mid, 0.0, 1.0)
        s = np.sum(proj)
        if s > target:
            hi = mid
        else:
            lo = mid
    result = np.clip(h + 0.5 * (lo + hi), 0.0, 1.0)
    diff = target - np.sum(result)
    if abs(diff) > 1e-10:
        idx = int(np.argmin(np.abs(result - 0.5)))
        result[idx] = np.clip(result[idx] + diff, 0.0, 1.0)
    return result

def fw_oracle(grad, n):
    target = n / 2.0
    order = np.argsort(grad)
    s = np.zeros(n)
    k = int(np.floor(target))
    s[order[:k]] = 1.0
    frac = target - k
    if frac > 1e-12:
        s[order[k]] = frac
    return s

def frank_wolfe(h, n, tau, max_iter=5000, momentum=0.0):
    h = h.copy()
    best_c5 = evaluate_c5(h)
    best_h = h.copy()
    beta = 0.0
    for t in range(max_iter):
        val, grad = smooth_max_and_grad(h, n, tau)
        s = fw_oracle(grad, n)
        step = 2.0 / (t + 2.0)
        w = (1.0 - step) * h + step * s
        if momentum > 0:
            beta = 0.9 * beta
            w = w + momentum * beta * (h - h)
        h = project_feasible(w, n)
        c5 = evaluate_c5(h)
        if c5 < best_c5 - 1e-10:
            best_c5 = c5
            best_h = h.copy()
    return best_h, best_c5

def slsqp_optimize(h0, n, tau, maxiter=100, ftol=1e-12):
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': constraint_func, 'args': (n,)}]
    res = minimize(
        obj_func, h0,
        method='SLSQP',
        args=(n, tau),
        bounds=bounds,
        constraints=cons,
        options={'maxiter': maxiter, 'ftol': ftol}
    )
    return project_feasible(res.x, n)

def localized_descent(h, n, max_iter=3000, tau=0.001):
    h = h.copy()
    best_c5 = evaluate_c5(h)
    best_h = h.copy()
    scale = 0.02
    for it in range(max_iter):
        val, grad = smooth_max_and_grad(h, n, tau)
        grad_proj = grad - np.mean(grad)
        norm_g = np.linalg.norm(grad_proj)
        if norm_g < 1e-10:
            break
        direction = -grad_proj / norm_g
        h_new = h + scale * direction
        h_new = project_feasible(h_new, n)
        c5 = evaluate_c5(h_new)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h_new.copy()
            h = h_new
            scale = min(scale * 1.1, 0.05)
        else:
            scale *= 0.7
            if scale < 1e-6:
                break
    return best_h, best_c5

def slp_step(h, n, max_iter=2000, tau=0.005):
    h = h.copy()
    best_c5 = evaluate_c5(h)
    best_h = h.copy()
    for it in range(max_iter):
        val, grad = smooth_max_and_grad(h, n, tau)
        grad_proj = grad - np.mean(grad)
        c = grad_proj
        target = n / 2.0
        order = np.argsort(c)
        s = np.zeros(n)
        k = int(np.floor(target))
        s[order[:k]] = 1.0
        frac = target - k
        if frac > 1e-12:
            s[order[k]] = frac
        step = 2.0 / (it + 2.0)
        h_new = (1.0 - step) * h + step * s
        h_new = project_feasible(h_new, n)
        c5 = evaluate_c5(h_new)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h_new.copy()
        h = h_new
    return best_h, best_c5
