    f0 = np.max(b)
    f1 = np.max(a + b)

    # For lines i and j: a_i*t + b_i = a_j*t + b_j => t = (b_j - b_i)/(a_i - a_j)

- Otherwise (some active d_m > 0 and some < 0, or some = 0): 0 is in the subgradient → return t_mid

This is correct because:
- The subgradient of a convex PBLS function at t is the convex hull of the slopes of active lines
- If all active slopes are positive, the function is locally increasing → minimum is to the left
- If all active slopes are negative, the function is locally decreasing → minimum is to the right
- If the active slopes straddle 0, t is a minimizer

One edge case: what if only one line is active and its slope is exactly 0? Then the function is locally flat, and any nearby point is also optimal. We can just return t_mid.

Another edge case: numerical issues. If d_m is very close to 0 for an active line, we might have issues. The tolerance of 1e-14 should handle this.
