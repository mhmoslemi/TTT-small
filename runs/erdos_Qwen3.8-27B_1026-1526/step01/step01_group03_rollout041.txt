```python
def smooth_max_grad(h, tau):
    n = len(h)
    dx = 2.0 / n
    g = 1.0 - h
    corr = np.correlate(h, g, mode="full")
    overlaps = corr * dx
    
    v = overlaps / tau
    vmax = np.max(v)
    w = np.exp(v - vmax)
    w /= np.sum(w)
    
    # grad[j] = dx * sum_{l=0}^{n-1} w[j+l] * g[l]
    grad = np.zeros(n)
    for j in range(n):
        grad[j] = dx * np.dot(w[j:j+n], g)
    
    return grad
```

This is O(n²) per gradient evaluation. For n=159, each gradient costs about 159*159 = 25281 multiply-adds, which is fast.

For n=500, it would be 250000, still manageable.
