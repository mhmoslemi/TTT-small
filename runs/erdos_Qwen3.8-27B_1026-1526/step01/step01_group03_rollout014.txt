One more idea: **coordinate descent**. For each coordinate j, fix all others and optimize h[j] in [0,1] subject to the sum constraint becoming an inequality. The 1D subproblem is: minimize max_k [A_k + B_k * h[j] + C_k * h[j]²] where A_k, B_k, C_k depend on the other coordinates. Since C_k ≤ 0 (the coefficient of h[j]² in h[j]*(1-h[j+k]) is... wait, h[j]*(1-h[j+k]) is linear in h[j] when h[j+k] is fixed. And h[j-k]*(1-h[j]) is also linear in h[j]. Wait: c[r] = sum_{valid i} h[i]*(1-h[i+r])
If I fix all h except h[j]:
- Terms where i=j: h[j]*(1-h[j+r]) - linear in h[j]
- Terms where i+r=j (i=j-r): h[j-r]*(1-h[j]) - linear in h[j]
- All other terms: constant

So c[r] = A_r + B_r * h[j] where:
- A_r = sum of all terms not involving h[j]
- B_r = (1-h[j+r]) * I(j valid in first role) + (-h[j-r]) * I(j valid in second role)

So the objective max_r (A_r + B_r * h[j]) * dx is a max of linear functions of h[j], which is convex in h[j]! I can minimize it exactly by finding the point where the "active" linear functions intersect.

This means coordinate descent will converge (for convex subproblems) and each coordinate update is a 1D convex optimization (minimize max of linears = find the point where the upper envelope has its minimum).

def pgd_optimize(h, n, taus, lr, iters_per_tau, t0, budget_frac):

    best_local = h.copy()
    best_local_c5 = evaluate_c5(h)
    for tau in taus:
        if time.time() - t0 > budget_frac:
            break
        for it in range(iters_per_tau):
            if time.time() - t0 > budget_frac:
                break
            obj_new, grad = grad_smooth_max(h, n, tau)
            grad = grad - np.mean(grad)
            h = h - lr * grad
            h = np.clip(h, 0.0, 1.0)

        c5 = evaluate_c5(h)
        if c5 < best_local_c5:

            best_local = h.copy()
