We are to implement the outgoing version of the TriMul operator from AlphaFold3. The operator works on a 4D tensor of shape [B, N, N, C]. The core operation is a reduction that for each (b, i, j, d) sums over k: 
  out[b, i, j, d] = sum_{k=0}^{N-1} left[b, i, k, d] * right[b, j, k, d]

This is a computationally intensive operation with complexity O(N^3) due to the reduction over k. To optimize this, we can use the provided matrix multiplication kernel example as inspiration for a batched reduction.

The mathematical specification is clear: we have two tensors left and right of shape [B, N, N, hidden_dim], and we wish to compute a new tensor of the same shape where each element is the dot product of two vectors from left and right along the k index.

Given the allocation of hidden_dim = 128, we can design the Triton kernel to handle these dimensions with a blocking strategy. Here's the detailed plan:

### 1. Approach and Rationale

The main bottleneck is the O(N^3) reduction. We want to parallelize this reduction using Triton's program grid and block-based scheduling. The reduction along k can be treated similarly to a matrix multiplication operation, where we load elements in the kernel's program dimensions and then perform a dot product.

The outgoing version means we only consider pairs (i, j) such that the mask is active. This allows us to skip masked elements. However, since the mask is applied to left and right, we can rely on that to set some values to zero, making the reduction effectively only over the allowed k indices.

### 2. Mathematical Specification

We have:
- `left` and `right`: input tensors of shape [B, N, N, hidden_dim]
- `mask`: binary tensor of shape [B, N, N]

The operation is:
- For each (b, i, j, d), compute:
  out[b, i, j, d] = \(\sum_{k=0}^{N-1} \mask[b, i, k] \times \mask[b, j, k] \times \left(\text{left}[b, i, k, d] \times \text{right}[b, j, k, d]\right)\)
  However, note the original PyTorch code applied the mask only once on the normalized input and then again on the projections. Since the mask is same for all (b, i, j), we can write the reduction conditionally.

Actually, the reduction conditions are set by the mask: only active elements (mask[b, i, k] and mask[b, j, k] being one) contribute to the sum. We can use the mask to avoid communicating zero values.

But for simplicity and safety, we will use the mask to conditionally reduce. The reduction is an element-wise multiplication and then a sum over k.
