- The update `a - alpha * (g - g_mean)` reduces a where the reversed a is high, and increases a where the reversed a is low.

For a symmetric sequence (a[i] = a[n-1-i]), the reversed a is the same as a, so the perturbation is proportional to a - mean(a). This reduces large elements and boosts small ones - a "flattening" operation. But for a nearly uniform sequence, this does almost nothing!

For an ASYMMETRIC sequence, the reversed a is different from a, and the perturbation is more interesting. The update tries to make a more like the reverse of itself at the peak lag, which... hmm, that would make it MORE symmetric, not less.

At peak lag k*, the convolution value is `(a*a)[k*] = sum_i a[i] * a[k*-i]`. To REDUCE this, we want to decrease the products a[i] * a[k*-i]. The simplest way is to decrease whichever of a[i] or a[k*-i] is larger.

The gradient g[j] = 2*a[k*-j] tells us: to reduce the peak, decrease a[j] by an amount proportional to a[k*-j]. 

If k* = n-1 (center), then g[j] = 2*a[n-1-j]. So we decrease a[j] by an amount proportional to a[n-1-j]. This means:
- If a[n-1-j] is large (i.e., a is large at the mirrored position), we decrease a[j] more.
- If a[n-1-j] is small, we decrease a[j] less (or increase it).

This is like "balancing" the sequence with its mirror. For a symmetric sequence, this does nothing (g is proportional to a itself). For an asymmetric sequence, it pushes toward symmetry.
