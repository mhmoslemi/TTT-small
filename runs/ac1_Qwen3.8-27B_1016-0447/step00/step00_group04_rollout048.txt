What about a "random" perturbation? a[i] = 1 + B*ξ_i where ξ_i are i.i.d. with mean 0, variance 1.
E[c[n-1]] = sum_i E[(1+Bξ_i)(1+Bξ_{n-1-i})] = n (since cross terms have mean 0).
Var(c[n-1]) = B^4 * sum_i Var(ξ_i * ξ_{n-1-i}) = B^4 * n (for i.i.d. ξ).
So c[n-1] ≈ n ± B^2*sqrt(n). The mean is unchanged, but there's variance.

The peak of the OVERALL convolution (not just at n-1) might be different. For random ξ, c[k] ≈ n + B*sqrt(n) for all k (with different random fluctuations). The max over k would be approximately n + B*sqrt(n)*sqrt(2*log(2n)) (Gaussian tail).

So obj ≈ 2n*(n + B*sqrt(n)*sqrt(2*log(2n))) / (n + B*E[sum ξ])^2 ≈ 2n*n/n^2 = 2 (for small B).

This doesn't help either! Random perturbations don't reduce the peak below the uniform level on average.

OK so the key question is: what structure CAN reduce the peak below the uniform level?

Going back to basics: c[k] = sum_i a[i]*a[k-i]. The sum over all k is (sum a)^2. The average is (sum a)^2/(2n-1). For the peak to be below the uniform value of n (with sum = n), we need the convolution to be more "spread out" than the triangular profile of the uniform sequence.

The uniform sequence has c[k] = k+1 for k < n, then decreasing. This is a "triangular" shape. The peak is n, the average is n(n+1)/(2n-1) ≈ n/2. So the peak is 2x the average.

To reduce the peak while keeping the sum constant, we need to "flatten" the convolution profile. This means making c[k] more uniform across k.

For a sequence that's 1 at positions {p_0, p_1, ..., p_{m-1}} (0/1 sequence with m ones), the convolution c[k] = |{j: p_j + p_{j'} = k}| (counting ordered pairs). The average is m^2/(2n-1). The peak is at most m (at k=0, c[0]=1 if p_0=0)... 

Wait, for a 0/1 sequence, c[0] = a[0]^2 = 1 (if a[0]=1). c[k] for small k is the number of adjacent pairs. The maximum c[k] is roughly m/n * n = m (for the "most populated" lag). Actually for a random 0/1 sequence with m ones, c[k] ≈ m^2/n for most k, and c[k] can be as high as m for some k.

For m = n/2 (50% density), the peak is about n/2 and the average is n^2/4 / 2n = n/8. So the peak is 4x the average.

```
1. Initialize a as a random nonnegative sequence (or structured).
2. Normalize so sum(a) = S = sqrt(2n).
3. For each iteration:

   b. Find all positions k where C[k] is in the top few percent (not just the global max, to get a smoother gradient).
   c. For each such k, compute the shadow h_k[i] = a[k-i] (valid).
   d. Compute the average shadow H[i] = (1/|K|) * sum_{k in K} h_k[i].
   e. Update: a[i] ← max(ε, a[i] * exp(-step * (H[i] - mean(H)) / std(H))).
   f. Renormalize: a ← a * S / sum(a).
4. Every T iterations, check the exact score.
5. Keep the best.
```

This is essentially a "mirror descent" with the geometric mean penalty (since we're using multiplicative updates, which is the natural update for the simplex with the entropy barrier).

The key parameter is the step size. Too large and we oscillate; too small and we converge slowly.
