def simplex_project(v):

Wait, DFT of convolution: DFT(f*g) = DFT(f) * DFT(g). So DFT(f*f) = DFT(f)^2.

For real f, DFT(f) has the conjugate symmetry: DFT(f)[-k] = conj(DFT(f)[k]). So DFT(f*f)[-k] = DFT(f)[-k]^2 = conj(DFT(f)[k])^2 = conj(DFT(f)[k]^2) = conj(DFT(f*f)[k]). Good, C is real and symmetric.

But DFT(f*f)[k] = DFT(f)[k]^2, which can be negative! (Since DFT(f)[k] is complex, its square can have negative real part.)

Wait, that can't be right. C[k] ≥ 0 for all k (since f ≥ 0), so the DFT of C should satisfy... well, the DFT of a nonnegative sequence doesn't have to be nonnegative. Only the DFT of a positive definite sequence (like |DFT(f)|^2) is nonnegative.

So C = f*f is nonnegative (as a sequence) but its DFT = DFT(f)^2 can take negative values. This is a crucial difference from the power spectrum |DFT(f)|^2.

This means C = f*f is MORE constrained than just "nonnegative + symmetric + positive definite DFT". It must have a DFT that is a perfect square.

This extra constraint is what prevents us from achieving a uniform C (whose DFT would be a single delta, which is a perfect square only if DFT(f) is a delta, i.e., f is a constant).

So the uniform f (constant) is actually the ONLY way to get a "flat-ish" C, and any deviation from uniformity increases the peak of C.
