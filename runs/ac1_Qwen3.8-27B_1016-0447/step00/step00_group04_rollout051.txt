Actually more carefully: ∂b[k]/∂f[j] = Σ_i δ(i,j)f[k-i] + f[i]δ(k-i,j) = f[k-j] + f[k-(k-j)] = f[k-j] + f[j].

Wait: b[k] = Σ_i f[i]*f[k-i]. ∂/∂f[j]: the first term contributes f[k-j] (when i=j), the second contributes f[j] (when k-i=j, i.e., i=k-j). So ∂b[k]/∂f[j] = f[k-j] + f[j] (if j ≠ k-j) or 2f[j] (if j = k/2).

So the gradient of ||b||²:
∂(||b||²)/∂f[j] = 2 Σ_k b[k] (f[k-j] + f[j]) (with the caveat for j=k/2)
≈ 2 (b*f)[j] + 2 f[j] Σ_k b[k] (approximately, dropping the diagonal correction)

Where (b*f)[j] = Σ_k b[k] f[k-j] (with proper bounds).

And Σ_k b[k] = (Σf)².

So the gradient ≈ 2(b*f)[j] + 2f[j](Σf)².

The second term is proportional to f[j] itself, which just scales f. Since we're normalizing Σf=1, this term doesn't change the direction (it's absorbed in the normalization). So the effective gradient direction is (b*f)[j] (centered).

This can be computed as a convolution of b and f, which is O(n log n) with FFT.

Let me implement this:

```python
def power2_step(f, eta):
    """One gradient step to minimize ||f*f||^2."""
    n = len(f)
    b = fft_convolve(f)  # length 2n-1
    # Gradient direction: (b * f) - mean
    # (b * f)[j] = sum_k b[k] f[k-j] (with bounds)
    # This is a convolution of b (length 2n-1) with f (length n)
    # Result has length 3n-2, but we only need the first n components
    # Actually, we need (b * f)[j] for j = 0, ..., n-1
    # = sum_k b[k] * f[k-j] where 0 ≤ k < 2n-1 and 0 ≤ k-j < n
    # = sum_{k=max(0,j)}^{min(2n-2, j+n-1)} b[k] * f[k-j]
    
    # Use FFT for efficiency
    fft_size = 1
    target_len = (2*n-1) + n - 1  # = 3n-2
    while fft_size < target_len:
        fft_size *= 2
    B = np.fft.rfft(b, fft_size)
    F = np.fft.rfft(f, fft_size)
    conv_bf = np.fft.irfft(B * F, fft_size)[:target_len]
    
    # The gradient for f[j] is: 2 * conv_bf[j] + 2*f[j]*sum(b)
    # The second term is proportional to f, absorbed by normalization
    grad = conv_bf[:n].copy()
    grad -= grad.mean()  # center to preserve sum
    
    norm = np.linalg.norm(grad)
    if norm < 1e-15:
        return f.copy()
    
    f_new = f - eta * grad / norm
    f_new = np.clip(f_new, 0.0, 1000.0)
    if f_new.sum() > 0:
        f_new = f_new / f_new.sum() * f.sum()
    return f_new
```
