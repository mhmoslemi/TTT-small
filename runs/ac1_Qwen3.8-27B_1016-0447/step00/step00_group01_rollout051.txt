Let me focus on making the main loop effective. The key insight is:

**The max of the convolution is what we're minimizing. To reduce it, we need to "spread out" the weight of a so that no particular lag has too much mass.**

A good heuristic: for each peak at position k, the value b[k] = sum_i a[i]*a[k-i]. The "partners" of position j in this sum are a[k-j]. If a[k-j] is large, then a[j] contributes a lot to b[k]. So we should reduce a[j] where a[j]*a[k-j] is large for some peak k.

But we also want to maintain the sum. So we should increase a[j] where a[j]*a[k-j] is small (for all peaks k).

This is essentially a gradient step on max(b) with a constraint on sum(a).

Let me implement this:

```python
def pressure_update(a, b, top_k_indices, eta, time_budget):
    n = len(a)
    M = b.max()
    pressure = np.zeros(n)
    # Weight peaks by their relative height
    for k in top_k_indices:
        w = (b[k] / M) ** 4  # emphasize the tallest peaks
        # partner[j] = a[k-j] for valid j
        lo = max(0, k - n + 1)
        hi = min(n - 1, k)
        # a[k-j] for j in [lo, hi] is a[k-hi : k-lo+1] reversed
        # = a[lo:k+1] reversed... wait
        # j=lo -> a[k-lo], j=hi -> a[k-hi]
        # So it's a[k-hi : k-lo+1] but in reverse: a[k-lo], a[k-lo-1], ..., a[k-hi]
        # Which is a[k-lo : k-hi-1 : -1] or a[k-hi : k-lo+1][::-1]
        seg = a[k-hi : k-lo+1][::-1]  # length hi-lo+1
        pressure[lo:hi+1] += w * seg
    # Update: reduce where pressure is high
    # a[j] *= exp(-eta * pressure[j] / max_pressure)
    max_p = pressure.max()
    if max_p > 0:
        scale = np.exp(-eta * pressure / max_p)
        a = a * scale
    # Renormalize
    s = a.sum()
    if s > 0:
        a = a * (s / a.sum())  # no-op, just for safety
    return np.clip(a, 0, 1000)
```
