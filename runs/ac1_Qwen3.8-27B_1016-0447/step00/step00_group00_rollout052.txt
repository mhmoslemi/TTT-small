The key insight is that the uniform sequence is a local minimum, so we need a GLOBAL optimization approach. The LP-based approach from the problem description is designed for this: it finds the best "direction" to move that reduces the peak.

Let me implement a simplified version of the LP approach:

1. Start with a (the current sequence), normalize so sum = √(2n) (or any normalization).
2. Compute M = max(a*a).
3. Solve: max sum(b) s.t. (a*b)[k] <= M for all k, b >= 0.
   - This LP has n variables and (2n-1) + n constraints.
   - The constraint matrix is a Toeplitz matrix (size (2n-1) × n).
   - For n=4806, this is about 4806 × 9611 ≈ 46 million entries. Too dense.

Alternative: Use a cutting-plane approach. Start with a small set of active constraints and add violated constraints iteratively.

Or: Use a simpler iterative approach based on the observation that:
- The constraint (a*b)[k] <= M means sum_j a[j]*b[k-j] <= M.
- For the current a, the "tightest" constraint is at the lag where a*b is maximum.
- We can update b by: b_new[k] = min(b[k], M / max_j(a[j]*b[k-j])... no, this doesn't quite work.

Actually, a simpler approach: after computing the LP solution direction, we can approximate it with a few iterations of a "projected power method" style algorithm:

1. Start with b = a (or b = 1).
2. Compute c = a * b (full convolution).
3. Where c[k] > M, scale down b at the indices that contributed to c[k].
4. Repeat.

This is like a multiplicative updates / mirror descent on the LP.

Actually, let me think of an even simpler approach that might work well:

**Approach: Iterative Peak Reduction**

1. Start with a (normalized, sum > 0).
2. Compute conv = a * a. Find the peak lag k*.
3. The peak is contributed by pairs (j, k*-j) where a[j]*a[k*-j] is large.
4. Reduce the larger of the two elements in each contributing pair.
5. Re-normalize.
6. Repeat.

This is essentially a specialized form of the subgradient method, but targeting the actual peak contributors.

For step 4, a practical implementation:
- Identify the top-m contributing pairs at lag k*.
- Reduce the elements in those pairs by a small factor.
- Increase the elements at the edges (which contribute less to the peak) to maintain the sum.

Let me think about this more concretely. If the peak is at lag k*, then:
conv[k*] = sum_j a[j]*a[k*-j]

The contribution of a[i] to this sum is: a[i]*a[k*-i] (if k*-i is valid) + (a[k*-i]*a[i] if 2i != k*) = (1 or 2) * a[i] * a[k*-i].

To reduce the peak, we want to decrease a[i] * a[k*-i] for the pairs with large contributions. The cheapest way is to decrease the larger of the two.

But we also want to maintain the sum (or increase it). So we can:
- Decrease a[i] by δ at positions where a[i]*a[k*-i] is large.
- Increase a[j] by δ at positions where a[j]*a[k*-j] is small.

This is like a "water filling" approach.

Let me code this up. For n=4806, each iteration involves:
- One convolution: O(n log n) ≈ fast.
- Finding the peak: O(n).
- Updating a few elements: O(n).

So each iteration is O(n log n) ≈ O(n) effectively. In 1100 seconds, we can do many iterations.

import numpy as np
import time

def compute_conv(a):
    """Full convolution of a with itself."""
    return np.convolve(a, a)

def peak_reduction_step(a, max_iter=100):
    """One step of peak reduction."""
    n = len(a)
    conv = np.convolve(a, a)
    k_star = np.argmax(conv)
    M = conv[k_star]
    
    # Compute the contribution of each a[i] to the peak
    # conv[k_star] = sum_j a[j]*a[k_star-j]
    # Contribution of a[i]: a[i]*a[k_star-i] (with multiplicity 2 if i != k_star-i)
    valid_j = np.arange(max(0, k_star-n+1), min(n, k_star+1))
    valid_kmi = k_star - valid_j
    
    # Contribution vector
    contrib = np.zeros(n)
    for j in valid_j:
        kmi = k_star - j
        if 0 <= kmi < n:
            if j == kmi:
                contrib[j] += a[j]  # self-term, contributes a[j]^2, derivative is 2*a[j] but only one term
            else:
                contrib[j] += a[kmi]
                contrib[kmi] += a[j]
    
    # Actually, it's simpler to just compute the gradient directly
    # d(conv[k_star])/d(a[i]) = a[k_star-i] if valid, times 2 if i != k_star-i, times 1 if i == k_star-i
    grad = np.zeros(n)
    for i in range(n):
        kmi = k_star - i
        if 0 <= kmi < n:
            if i == kmi:
                grad[i] = a[i]
            else:
                grad[i] = 2 * a[kmi]
    
    return grad, k_star, M
