```python
    hi = min(n, k + 1)
    idx = np.arange(lo, hi)
    mir = k - idx
    sg[idx] += 2.0 * n / (S * S) * 2.0 * a[mir] / 3.0
```

Actually this is:
sg[i] = -4n*cmax/S³ + (2n/S²) * sum_{k in top3} (2*a[k-i]/3) [if valid]
= -4n*cmax/S³ + (4n/(3S²)) * sum_{k in top3} a[k-i] [if valid]

This is O(3n) to compute. Good.

But wait, for the "not in range" indices, the -4n*cmax/S³ term is constant. This means the gradient always has a constant offset. The interesting part is the variable part.

For the step, I'll normalize by the gradient norm anyway, so the constant offset just shifts the direction slightly.

Let me simplify: since the constant term is the same for all indices, and I'm normalizing the step, I can just use the variable part:
direction[i] = sum_{k in top3} a[k-i] (for valid i) - 3*cmax/S (threshold)

Then step = lr * direction / ||direction|| (normalized).

This is cleaner. Let me implement this.

Actually, you know what, let me just go with the straightforward implementation. The gradient computation is O(n) and the convolution is O(n²). The whole per-iteration cost is dominated by the convolution. Let me not over-optimize and just write clean code.

Let me also think about potential issues:
1. The max might not be unique → using top-3 handles this
2. The gradient step might overshoot → I'll use a simple acceptance test
3. Getting stuck in a local minimum → random perturbations
4. The sequence might become all zeros → clip to [0, 1000] and check sum > 0.01

I think the key insight for beating the uniform (score 2) is that the gradient descent on the subgradient will naturally find a structure where the convolution is flatter. For nonnegative sequences, this means a structure where no particular "mirror pair" is too prominent.

Let me also add: after the gradient descent converges (gradient norm is small), I can try a different strategy: directly optimize for a specific convolution shape.

But for now, let me go with the gradient approach and see.

One more thought: the problem is scale-invariant (multiplying a by a constant doesn't change the score). So I should normalize after each step to keep things in a reasonable range. Let me normalize to sum = n after each accepted step.

import numpy as np
import time

def _eval_and_grad(a):
    """Evaluate score and compute subgradient direction."""
    n = a.size
    S = float(a.sum())
    if S < 1e-10:
        return None, np.inf
    c = np.convolve(a, a)
    cmax = float(c.max())
    score = 2.0 * n * cmax / (S * S)
    
    # Top-3 peaks for subgradient
    if c.size >= 3:
        top3 = np.argpartition(c, -3)[-3:].astype(int)
    else:
        top3 = np.argsort(c)[-3:]
    
    # Variable part of gradient: for each i, sum of a[k-i] over peak positions
    var = np.zeros(n)
    counts = np.zeros(n)
    for k in top3:
        lo = max(0, k - n + 1)
        hi = min(n, k + 1)
        idx = np.arange(lo, hi)
        mir = k - idx
        var[idx] += a[mir]
        counts[idx] += 1.0
    
    # Average
    mask = counts > 0
    var[mask] /= counts[mask]
    
    # Direction: var[i] - cmax/S (push high values down, low values up)
    direction = np.zeros(n)
    direction[mask] = var[mask] - cmax / S
    # For unmasked indices, the direction is -cmax/S (push up)
    ~mask_direction = ~mask
    direction[~mask_direction] = -cmax / S
    
    return direction, score
