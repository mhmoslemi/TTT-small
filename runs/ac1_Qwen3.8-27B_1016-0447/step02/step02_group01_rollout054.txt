def sparse_grad(p_lags, p_weights, x, n):
    """Compute gradient without FFT, using sparse lags."""
    grad = np.zeros(n)
    x_rev = x[::-1]  # x_rev[i] = x[n-1-i]
    for k, w in zip(p_lags, p_weights):
        # grad[m] += 2*w * x[k-m] for valid m
        # x[k-m] is valid when 0 <= k-m < n, i.e., k-n+1 <= m <= k
        lo = max(0, k - n + 1)
        hi = min(k, n - 1)
        if lo <= hi:
            indices = np.arange(hi, lo - 1, -1)  # m goes from hi down to lo
            # x[k-m] for m in [lo, hi]: x[k-hi], x[k-hi+1], ..., x[k-lo]

            # k-lo <= k - (k-n+1) = n-1, so k-lo < n. Good.
            grad[lo:hi+1] += 2 * w * x[k - np.arange(lo, hi + 1)]
    return grad

Actually, let me try a different approach for the polish: **coordinate descent on the max lag**. 

The idea: fix all but two coordinates, and optimize those two to reduce the max autocorrelation. This is a 2D optimization that can be done quickly.

Or even simpler: **single-coordinate adjustment**. For each coordinate i, try changing it slightly (up or down) and see if it reduces the max autocorrelation. This is O(n) per pass, and each evaluation is O(n) (just recompute the affected autocorrelation values). Total: O(n²) per pass. For n=4498, that's 20M operations per pass, which is fast.

Actually, changing x[i] by delta changes conv[k] by:
delta_conv[k] = 2*delta*x[k-i] + delta² (for the k=i+i=2i term... no)

Hmm, let me just say:
conv_new[k] = conv_old[k] + delta*(x[k-i] + x[i-k]) + delta²*i(k-i==i) ... I'm overcomplicating.

Actually: (x+delta*e_i)(x+delta*e_i) convolved:
= x*x + delta*(e_i*x + x*e_i) + delta²*(e_i*e_i)

conv(x*x)[k] + delta*(conv(e_i,x)[k] + conv(x,e_i)[k]) + delta²*conv(e_i,e_i)[k]

conv(e_i, x)[k] = x[k-i] (if valid)
conv(x, e_i)[k] = x[i-k] (if valid)
conv(e_i, e_i)[k] = 1 if k=2i else 0

So delta_conv[k] = delta*(x[k-i] + x[i-k]) + delta²*I(k=2i)

This means changing one coordinate only affects O(n) autocorrelation values (those where k-i or i-k is in [0,n-1]).

For coordinate descent:
- For each i from 0 to n-1:
  - Compute current max of conv
  - Find the best delta for coordinate i that reduces the max
  - Apply the delta

The "best delta" can be found analytically: we want to minimize max_k (conv[k] + delta * g_k) where g_k = x[k-i] + x[i-k] (+ delta*I(k=2i) which is small).

This is a 1D problem: find delta >= 0 (or delta can be negative, making x[i]+delta > 0) that minimizes max_k (conv[k] + delta*g_k).

The optimal delta is where the constraint is "tightest". This can be found by:
- If max is at lag k* where g_{k*} > 0: reduce x[i] (negative delta) to reduce conv[k*]
- The maximum reduction before another lag becomes the max: delta_max = (conv[k*] - conv[k**]) / (g_{k*} - g_{k**}) where k** is the second-highest affecting lag

This gives an efficient coordinate descent step.

import time
from scipy import fft as sfft

def npow2(m):
    p = 1
    while p < m:
        p <<= 1
    return p

def sc(x):
    return float(evaluate_sequence(x.tolist()))

    deadline = time.monotonic() + max(0.0, float(budget_s) - 5.0)
    
    # Load and initialize
    try:
        par = np.clip(np.asarray(height_sequence_1, dtype=np.float64), 0.0, 1000.0)
    except Exception:
        par = np.ones(512)
    if par.ndim != 1 or par.size < 2 or not np.all(np.isfinite(par)):
        par = np.ones(512)
    
    n = par.size
    ts = np.sqrt(2.0 * n)
    fs = npow2(2 * n - 1)
    
    x = par * (ts / max(par.sum(), 0.01))
    x = np.clip(x, 0.0, 1000.0)
    best = x.copy()
    best_score = sc(best)
    if not np.isfinite(best_score):
        x = np.ones(n) * (ts / n)
        best = x.copy()
        best_score = sc(best)
    
    # Main optimization loop
    K = 16
    T = 0.05
    lr = 0.25
    v = np.zeros(n)
    mu = 0.7  # momentum
    stuck = 0
    it = 0
    
    while time.monotonic() < deadline - 60.0:
        # Autocorrelation via FFT
        X = sfft.rfft(x, fs)
        c = np.real(sfft.irfft(X * X, fs))[:2 * n - 1]
        np.maximum(c, 0.0, out=c)

        if K < c.size:
            k_idx = np.argpartition(c, c.size - K)[-K:]
        else:
            k_idx = np.arange(c.size)
        k_vals = c[k_idx]
        T_eff = max(T, 1e-8)
        wts = np.exp((k_vals - k_vals[-1]) / T_eff)  # k_vals[-1] approx max after partition
        # Actually argpartition doesn't sort, so let me use the actual max
        kmax = k_vals.max()
        wts = np.exp((k_vals - kmax) / T_eff)
        ws = wts.sum()
        if ws < 1e-300:
            wts = np.zeros_like(k_vals)
            wts[k_vals.argmax()] = 1.0
        else:
            wts /= ws

        grad = np.zeros(n)
        for ki, w in zip(k_idx, wts):

            lo = max(0, ki - n + 1)
            hi = min(ki, n - 1)
            if lo <= hi:
                grad[lo:hi+1] += 2.0 * w * x[ki - np.arange(lo, hi + 1)]
