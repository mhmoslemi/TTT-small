- When `m-j = i`, i.e., `j = m-i`: derivative is `a_i` (if `0 <= m-i < n`)
- If `i = m-i` (i.e., `m = 2i`), both contributions are the same and we get `2*a_i`.

So: `df/dx_i = a_{m-i} * I(0 <= m-i < n) + a_i * I(0 <= m-i < n)`
            `= (a_{m-i} + a_i) * I(max(0, m-n+1) <= i <= min(n-1, m))`

OK so the gradient at position i is `(a[m-i] + a[i])` if `0 <= m-i < n`, else 0.

I can compute this efficiently: for the range of valid i, the gradient is `a[m-i] + a[i]`.

Let me code this:
```python
def grad_conv_at(a, m, n):
    # Gradient of conv(a,a)[m] w.r.t. a
    g = np.zeros(n)
    # Valid i: max(0, m-n+1) <= i <= min(n-1, m)
    lo = max(0, m - n + 1)
    hi = min(n - 1, m)
    if lo <= hi:
        idx = np.arange(lo, hi + 1)
        g[lo:hi+1] = a[m - idx] + a[idx]
    return g
```

This is O(n) per evaluation, which is fine.

For the softmax-weighted version (to handle numerical issues when max is at multiple points), I can use a weighted average of gradients at the top few peak positions.

- Since it's scale-invariant, fix `sum a = sqrt(2n)` and minimize `max(conv(a,a))`.
- Use projected gradient: `a -= lr * grad`, then project to `a >= 0` and rescale to `sum a = sqrt(2n)`.

from scipy import fft as sfft

def npow2(m):
    p = 1
    while p < m:
        p <<= 1
    return p

def autocorr_fft(x, fs, n):

    c = np.real(sfft.irfft(X * X, fs))[:2 * n - 1]
    np.maximum(c, 0.0, out=c)
    return c
