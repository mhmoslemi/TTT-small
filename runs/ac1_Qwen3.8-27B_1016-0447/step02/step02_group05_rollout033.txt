```python
def _next_pow2(m):
```
```python
    p = 1
```

```python
        p[:] = 0.0; p[n-1] = 1.0
    else:
        p /= ps
    P = sfft.rfft(p, N2)
    Xc = sfft.rfft(x, N2)
    cr = np.real(sfft.irfft(P * np.conj(Xc), N2))[:n]
    g = cr - cr.mean()
    return g, score
```

This way I get both the gradient and the score in one pass (one convolution + one cross-correlation). The score from FFT should match `evaluate_sequence` exactly (up to floating point).
