Let me also think about whether there's a structural insight I'm missing. The problem is:

minimize 2n * max_k (sum_j a_j * a_{k-j}) / (sum a)^2

over a >= 0.

This is equivalent to (with S = sum a, normalizing S = 1):
minimize 2n * max_k conv_k

where conv_k = sum_j a_j * a_{k-j}.

The constraint conv_k <= c for all k is a set of quadratic constraints. The feasible region is: find the smallest c such that there exists a >= 0 with sum a = 1 and all conv_k <= c.

This is a QCQP (quadratic constraint, quadratic objective) which is non-convex in general. But the structure (convolution) might help.

For the "state of the art" LP approach: they fix M = max conv_k for the current a, then solve:
maximize sum(b) subject to b >= 0, and for all k: sum_j b_j * conv_f_j[k] <= M

Wait, that's: ||f * g||_inf <= M, which means for all x: sum_i f[i] * g[x-i] <= M. This is a system of linear inequalities in g (the variables are g_j). The convex set is defined by 2n-1 linear constraints.

The objective is max sum(g), subject to:
- g_j >= 0 for all j
- sum_i f[i]*g[k-i] <= M for all k = 0, 2n-2

This is a linear program! And the constraint matrix has a convolution structure (each row has the coefficients of f shifted).

For n=2535, this is 2535 variables and 5069+2535 = 7604 constraints. The constraint matrix is banded (each row has at most n nonzeros, but structured as a shifted version of f).

Using CVXPY with this would create a problem of about that size. With a sparse solver, this might work, but it could be slow.

Actually, the "state of the art" approach iterates:
1. Compute M = max conv(a,a)
2. Solve LP to get g
3. Update a = (1-t)*a + t*g (normalized)
4. Repeat

This is a subgradient-like method where the LP gives the optimal search direction. But each LP solve might take seconds for n=2535.

def _norm(a):
    a = np.maximum(a, 0.0)
    s = a.sum()
    return a / s if s > 1e-15 else np.ones(len(a)) / len(a)

def _fft_pow2(target):
    sz = 1
    while sz < target:
        sz <<= 1
    return sz


def _opt(a, dl, rng):
    n = len(a)

    best = a.copy()
    best_s = _sc(a)

        it += 1
        fa = np.fft.rfft(a, f1)

            if ss < 1e-300:
