Actually, let me think about the LP approach more carefully. The LP is:
- Given current a and M = max(a*a):
- max sum b s.t. b >= 0, (a*b)[k] <= M for all k

This finds the "best" direction to move (the direction that maximizes the sum while keeping the autocorrelation bounded by M).

The dual of this LP is:
- min M * sum y_k s.t. sum_k y_k * a[k-j] >= 1 for all j, y >= 0

The dual has 2n-1 variables (y) and n constraints. The constraint matrix is the same Toeplitz/Hankel matrix.

For a matrix-free approach, I can use:
- Projected gradient on the dual: minimize M * sum y s.t. (A^T y - 1) <= 0, y >= 0
- The projection is just clipping to y >= 0 and the PEP constraint

Actually, for the primal LP, I can use a simple active-set method:
1. Start with y = 0 (all dual variables 0)
2. The primal solution is b = argmax sum b s.t. A@b <= M, b >= 0
3. With y = 0, the active constraints are just b >= 0, so b is unbounded → we need active constraints

Let me use a simpler approach: **multiplicative update**.

For minimizing max(a*a) with sum(a) = 1, a >= 0:
- Multiplicative update: a[j] *= exp(-eta * g[j]) where g is the subgradient
- This automatically maintains nonnegativity

Or better: use the "mirror descent" approach with entropy regularization:
- a_new[j] = a[j] * exp(-eta * g[j]) / normalization

This is like the "exponential weights" method. It has the advantage of automatically staying in the nonnegative orthant.
