**Approach: Alternating minimization on (a, M) where M = max(b)**

Fix M, find the a that minimizes ||a|| subject to b_k <= M for all k, a >= 0.
Then update M.

The inner problem is a convex optimization (minimize quadratic ||a||^2 subject to linear constraints a >= 0 and b_k <= M). This can be solved by projected gradient or active set methods.

But the constraints b_k <= M are linear in a only if we fix the "other" elements. Actually, b_k = sum_i a_i * a_{k-i} is quadratic in a. So the constraint is quadratic, making the problem non-convex.

So this doesn't simplify things.

**Approach: Subgradient method with step size 1/t**

The objective f(a) = 2n * max(b) / (sum a)^2 is the maximum of a family of functions (one for each k). The subgradient at the argmax k* is the gradient of b_{k*} w.r.t. a, scaled appropriately.

Using step size 1/t (or 1/sqrt(t)) in the subgradient method would give O(1/sqrt(t)) convergence. But this is slow and the non-smoothness of max makes it tricky.

**Approach: Smoothed approximation + Newton's method**

Use the softmax approximation with very small temperature to approximate max, then use Newton's method (or BFGS) to minimize the smooth approximation.

Newton's method requires the Hessian, which is O(n^2) to compute. For n=2535, that's 6.4M entries, which is feasible but expensive. And we'd need to invert the Hessian each step, which is O(n^3) = 16B operations. Too expensive.

**Approach: Use the structure of the autocorrelation**

The autocorrelation b = a * a has the property that its Fourier transform is |A|^2, where A = DFT(a). So b_k are the Fourier coefficients of |A|^2.

We want to minimize max_k b_k. In the Fourier domain, this is minimizing the peak of the inverse Fourier transform of |A|^2.

This is related to the "minimum peak" problem in signal processing. There are known results: for a random sequence with sum 1, the expected max b is about (log(2n))/(2n) * sum(a)^2 or something like that.

For our problem, the target max b is about 1.5/(2n) ≈ 3e-4. The "random" max would be about (log(5070))/5070 ≈ 8.5/5070 ≈ 1.7e-3. So we need to do significantly better than random.

This suggests that structured sequences (not random) are needed. The gradient-based approach should naturally discover such structure.

**Approach: Preconditioning**

Apply a preconditioner to the gradient to speed up convergence. For example, if we know the approximate shape of the optimal sequence, we can precondition by that shape.

But this is speculative without knowing the optimal shape.
