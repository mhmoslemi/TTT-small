This sorts by the tuple `(score, array)`. The first element is a float, so it sorts by score. If two scores are exactly equal (unlikely for floats), it would try to compare the arrays, which would fail. To be safe:

```python
for i in range(len(scored)):
    for j in range(i + 1, len(scored)):
        if scored[j][0] < scored[i][0]:
            scored[i], scored[j] = scored[j], scored[i]
```
