Let me also think about the LP-based approach from the "state of the art" description. The idea is:
1. Given current a, compute M = max(convolve(a,a))
2. Solve: maximize sum(b) subject to b >= 0, convolve(a, b) <= M (element-wise)
3. Rescale b to match normalization
4. Blend: a_new = (1-t)*a + t*b

The LP is: maximize sum(b_j) subject to:
- b_j >= 0
- (convolve(a,b))[k] <= M for k = 0, ..., 2n-2

The constraint matrix is a (2n-1) x n "convolution" matrix, which is banded (each column has at most n nonzero entries, specifically the column for b_j has a[k] at row k+j for k=0,...,n-1). This is a banded matrix with bandwidth n, which is actually the same as a Toeplitz-like matrix.

For n ~ 6000, the constraint matrix is 12000 x 6000 with ~6000 nonzeros per column, so ~36M nonzeros total. This is too large for a standard LP solver.

However, we can use a matrix-free approach or a simpler heuristic. The LP's optimal solution has at most n active constraints (by complementary slackness). In practice, the active set might be much smaller.

A simpler approach: instead of solving the full LP, we can use a "water-filling" or "dual" heuristic:
- Start with b = a (normalized)
- Iteratively: compute convolve(a, b), find violations (> M), reduce b at positions that cause the most constraint violations
- This is like a projected subgradient method for the LP dual

Or even simpler: use the KKT conditions heuristically. The dual of the LP is:
minimize M * sum(y_k) subject to sum_k y_k * A_{k,j} >= 1, y_k >= 0

Where A_{k,j} = a[k-j] (for valid k-j). This is a (2n-1)-variable LP with n constraints.

Let me think about what shape a should have. If a is a "broad" window (like a raised cosine or a flat-top), the autocorrelation will be broad and relatively flat. The peak will be at the center and only slightly above the mean.

import numpy as np

def _convolve(a):
    """Compute full convolution a*a using FFT (O(n log n))."""
    n = len(a)
    L = 1
    while L < 2*n - 1:
        L <<= 1
    fa = np.fft.rfft(a, L)
    return np.fft.irfft(fa * fa, L)[:2*n - 1]

def _soft_grad(a, b, tau):
    """Compute gradient of soft-max of b w.r.t. a, where b = convolve(a, a)."""
    n = len(a)
    # Soft-max weights
    bmax = b.max()
    w = np.exp((b - bmax) / tau)
    Z = w.sum()
    if Z < 1e-300:
        return np.zeros(n)
    w /= Z  # now w[k] = exp(b[k]/tau) / Z (shifted by bmax, doesn't matter for gradient direction)
    
    # Compute c[j] = sum_i a[i]*w[i+j] for j=0,...,n-1

    return g
