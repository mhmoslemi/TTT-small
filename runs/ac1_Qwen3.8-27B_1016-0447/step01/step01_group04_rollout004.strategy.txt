  Approach and rationale

The strategy involves using a projected gradient descent algorithm to optimize a nonnegative sequence of real numbers. The goal is to minimize the AC1 upper bound (lower is better), which is defined as 2*n*max(convolve(a,a,mode="full"))/sum(a)^2. 

The key idea is to approximate the gradient of this objective function using a dual norm method, which allows us to:
1. Handle the nonlinear max operation in the convolution by using a temperature parameter
2. Project updates onto the feasible space (nonnegative and bounded coefficients)
3. Maintain the constraint that the sum of coefficients is sqrt(2*n)

Compared to the previous state-of-the-art approach (which solved an LP at each iteration), this method:
- Has simpler mathematical formulation
- Uses one-dimensional FFT-based operations
- Is computationally cheaper per iteration
- Specializes gradient approximation to the convolution constraint
- Should converge faster due to direct gradient descent

However, we must be cautious:
- The approximation uses 1D FFTs with carefully chosen temperatures
- Requires explicit restarting to escape local minima
- Normalization must be strictly maintained

The method is initialized with the parent sequence (if available) and uses aggressive gradient steps that are adaptively clipped. This should yield sequences with AC1 bounds below 1.50 while maintaining implementation simplicity.

Mathematical specification

We work on normalized sequences \(a \in \mathbb{R}^n\) with:
\[s(a) = \frac{\sum a_i}{\|a\|_1} = \sqrt{2n}\]
and nonnegative coefficients \(0 \leq a_i \leq 1000\)

The objective to minimize is:
\(f(a) = \frac{2n\cdot \max(convolve(a,a))}{(\text{sum}(a))^2}\)

But note with normalization, this simplifies to just \(\max(convolve(a,a))\).

To handle the max operation, we approximate the gradient using:
1. A temperature parameter \(\tau\) scaled by \(\approx 0.05\) of the current maximum
2. The softmax weighting function:
   \(w_k = \frac{\exp((M_k - M_{\text{max}})/\tau}{\sum_j \exp((M_j - M_{\text{max}})/\tau\)
   where \(M_k\) are the coefficients of the full convolution (2n-1 long) and \(M_{\text{max}}\) is its maximum value

The gradient estimator is:
\(g = \tau^{-1}\cdot\text{weighted\_convolve}(w, a)\)

where weighted_convolve computes the convolution between the weights and the input vector, using FFT-based operations.

The update rule is:
\(a \leftarrow \max(0, \min(1000, a + \eta g))\), then project to sum \(\sqrt{2n}\)
