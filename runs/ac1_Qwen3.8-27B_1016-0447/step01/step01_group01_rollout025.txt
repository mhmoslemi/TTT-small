Wait, I need to double-check a few things:

1. The `_norm` function: I'm normalizing sum to $S = n$. This is because the score is scale-invariant, so any normalization works. Using $S = n$ means the mean is 1.

2. The gradient: I'm using the gradient of $\max(b)$ (which is a function of $a$). Since we're keeping $S$ constant (by normalizing after each step), the effective gradient should be projected orthogonal to $\mathbf{1}$. I do this with `g -= g.mean()`.

3. The step: $a \leftarrow a \cdot \exp(-\eta g)$. This is a multiplicative update that keeps $a \geq 0$ (before clipping). The exponential ensures positivity.

4. The K peaks: I use $K = 48$ peaks in the main loop and $K = 24$ in the polish. This gives a reasonable trade-off between accuracy and speed.

5. Time management: I check `time.monotonic() < t_end` in the loops, with `t_end` set to 25 seconds before the hard deadline.

**Idea: Use the "LP direction" approximately**

The LP approach finds a direction $g_0$ that maximizes $\sum b_j$ subject to $\|f * g_0\|_\infty \leq M$. This is equivalent to finding the "fairness" direction - the one that equalizes all autocorrelation values.

A simple approximation: at each step, compute the "desired" autocorrelation: $b_{\text{target}}[k] = S^2 / (2n-1)$ for all $k$ (the flat target). The "excess" is $e[k] = b[k] - b_{\text{target}}[k]$. We want to reduce the positive excess.

The gradient of $\max_k e[k]$ gives the direction to reduce the largest excess. But we could also use $\sum_k \max(0, e[k])$ which gives a smoother objective.
