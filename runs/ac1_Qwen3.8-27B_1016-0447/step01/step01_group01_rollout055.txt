Actually, let me try a completely different approach for variety: **FISTA (Fast Iterative Shrinkage-Thresholding Algorithm)** or **Proximal Gradient Descent**.

The problem: minimize $f(a) = \max_k b_k$ subject to $a \geq 0, \sum a = S$.

The constraint set $a \geq 0, \sum a = S$ is a simplex. The projection onto this simplex can be computed in $O(n \log n)$.

FISTA for the constrained problem:
1. $g_t = \nabla f(a_t)$ (subgradient)
2. $z_{t+1} = \text{proj}_C(a_t - \eta_t g_t)$ where $C = \{a \geq 0, \sum a = S\}$
3. $a_{t+1} = z_{t+1} + \frac{t}{t+3}(z_{t+1} - a_t)$ (momentum)

The projection onto $C$: $a_t - \eta g_t = v$. Find $\tau$ such that $\sum_j \max(0, v_j - \tau) = S$. This is a 1D root-finding problem that can be solved in $O(n \log n)$ by sorting.

This might be more stable than the renormalization approach.

Let me implement this:

```python
def _proj_simplex(v, S):
    """Project v onto {a >= 0, sum a = S}."""
    n = len(v)
    sorted_v = np.sort(v)[::-1]
    cssv = np.cumsum(sorted_v)
    cond = sorted_v > (cssv - S) / np.arange(1, n+1)
    idx = cond.sum() - 1
    if idx < 0:
        idx = 0
    tau = (cssv[idx] - S) / (idx + 1)
    return np.maximum(v - tau, 0.0)
```

Wait, the standard simplex projection: project $v$ onto $\{x \geq 0, \sum x = S\}$.

The solution is $x_j = \max(0, v_j - \tau)$ where $\tau$ is chosen so that $\sum x_j = S$.

$\tau$ can be found by: sort $v$ in decreasing order $v_{\pi(1)} \geq v_{\pi(2)} \geq \ldots$. Let $\hat{k}$ be the largest $k$ such that $v_{\pi(k)} - \frac{1}{k}(\sum_{j=1}^k v_{\pi(j)} - S) > 0$. Then $\tau = \frac{1}{\hat{k}}(\sum_{j=1}^{\hat{k}} v_{\pi(j)} - S)$.

This is $O(n \log n)$ due to sorting.

For FISTA, the momentum step can help with convergence.
