Hmm, but I realize there's a subtlety. The objective we want to minimize is `2n * max(conv(f,f))` (assuming sum(f)=1). The logsumexp is a smooth approximation of the max, but the relationship between the logsumexp objective and the actual max objective isn't perfect.

When beta is large, logsumexp(beta * conv) ≈ max(conv) + log(k_max)/beta where k_max is the number of near-max elements. So minimizing logsumexp with large beta is approximately minimizing the max.

But there's a catch: the gradient of logsumexp is a weighted average of the individual gradients, weighted by the softmax weights. When beta is large, the weights concentrate on the max elements, so the gradient points in the direction that reduces the max most. This is exactly what we want.

However, when beta is too large, the gradient becomes noisy (concentrated on a few elements). So we should start with moderate beta and increase it.

Let me also add a "plateau detection" mechanism: if the objective stops improving, try a different approach (LP, mirror descent, or restart).

Let me also think about the **mirror descent** approach more carefully.

Mirror descent on the simplex uses the KL divergence as the Bregman divergence. The update is:
`f_new[j] = f[j] * exp(-eta * grad[j]) / Z`

where Z is a normalizing constant. This is also known as the "multiplicative weights" update or "exponential descent".

The gradient for the max objective (subgradient) is:
`grad[j] = sum_{k in argmax(conv)} (f[k-j] + f[j])` (averaged over the argmax set)

Or more smoothly, with softmax weights:
`grad[j] = sum_k p[k] * (f[k-j] + f[j])`

For mirror descent, the step size eta is crucial. Too large and we oscillate; too small and we're slow.

I'll use an adaptive step size: start with eta=0.5, reduce by 0.9 when we don't improve, and occasionally reset.

Now let me think about the **LP approach** more carefully.

The LP solves: max sum(g) s.t. g >= 0, (f*g)[k] <= M for all k.

The idea is that if we can find a g with large sum that satisfies the constraint, then blending f with g (while maintaining sum=1) should reduce the max of the convolution.

Why? Because g is "spread out" in a way that's compatible with f's convolution being bounded by M. By moving f toward g, we make f more "spread out" in a compatible way.

One improvement: instead of maximizing sum(g), we could maximize a regularized objective like `sum(g) - lambda * sum(g^2)` to encourage g to be more uniform.

Another improvement: use a smaller M (like 0.95 * current_M) to force the LP to find a more "spread out" g.

Let me also consider: what if we solve the LP in the **dual**? The dual of our LP is:

min M * sum_k y[k]
s.t. sum_k y[k] * f[k-j] >= 1 for all j
     y[k] >= 0

where y[k] are the dual variables. This has 2n-1 variables and n constraints. For n=512, that's 1023 variables and 512 constraints. This might be faster to solve.

Actually, HiGHS is quite efficient for both primal and dual, so it probably doesn't matter much.

"""
Multi-phase optimizer for minimizing 2*n*max(conv(a,a))/(sum(a))^2.
Combines Adam with log-sum-exp, LP-guided alternating optimization,
and mirror descent polishing with random restarts.
"""

import numpy as np
import scipy.optimize as optimize
import scipy.sparse as sparse
import time


def fast_convolve(a):
    """Linear auto-convolution using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    result = np.fft.irfft(A * A, fft_size)
    return result[:size]


def project_simplex(v, target_sum=1.0):
    """Project v onto {x >= 0, sum(x) = target_sum}."""
    v = np.maximum(v, 0.0)
    s = v.sum()
    if s < 1e-15:
        return np.ones(len(v)) * target_sum / len(v)
    return v * (target_sum / s)


def compute_grad_LSE(f, conv, beta):
    """Compute gradient of logsumexp(beta * conv(f,f)) w.r.t. f."""
    n = len(f)
    mx = conv.max()
    if mx < 1e-15:
        return np.zeros(n)
    w = np.exp(beta * (conv - mx))
    w_sum = w.sum()
    if w_sum < 1e-30:
        w = np.zeros(len(conv))
        w[int(np.argmax(conv))] = 1.0
    else:
        w /= w_sum
    corr = np.correlate(w, f, mode='full')
    return f + corr[:n]


def adam_phase(f0, time_limit, beta_start=5.0, beta_end=200.0, lr=0.02):
    """Adam optimization with log-sum-exp on the probability simplex."""
    f = project_simplex(f0.astype(np.float64), 1.0)
    n = len(f)
    
    conv = fast_convolve(f)
    best_obj = 2.0 * n * conv.max()
    best_f = f.copy()
    
    m = np.zeros(n)
    v = np.zeros(n)
    t = 0
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    
    t0 = time.monotonic()
    patience = 0
    
    while time.monotonic() - t0 < time_limit:
        t += 1
        progress = min(1.0, (time.monotonic() - t0) / max(1.0, time_limit))
        beta = beta_start + (beta_end - beta_start) * (progress ** 0.3)
        
        conv = fast_convolve(f)
        grad = compute_grad_LSE(f, conv, beta)
        
        m = beta1 * m + (1 - beta1) * grad
        v = beta2 * v + (1 - beta2) * grad ** 2
        m_hat = m / (1 - beta1 ** t)
        v_hat = v / (1 - beta2 ** t)
        
        f_new = f - lr * m_hat / (np.sqrt(v_hat) + eps)
        f_new = project_simplex(f_new, 1.0)
        
        conv_new = fast_convolve(f_new)
        obj_new = 2.0 * n * conv_new.max()
        
        if obj_new < best_obj - 1e-13:
            best_obj = obj_new
            best_f = f_new.copy()
            patience = 0
        else:
            patience += 1
            if patience % 50 == 0:
                lr *= 0.9
            if patience > 300:
                break
        
        f = f_new
    
    return best_f, best_obj


def make_lp_indices(n):
    """Precompute indices for cross-convolution constraint matrix."""
    rows_list = []
    cols_list = []
    for i in range(n):
        for j in range(n):
            rows_list.append(i + j)
            cols_list.append(i)
    return np.array(rows_list, dtype=np.int32), np.array(cols_list, dtype=np.int32)


def solve_lp(f, M, rows, cols, n):
    """Solve max sum(g) s.t. g>=0, (f*g)[k]<=M for all k."""
    vals = np.tile(f, n)
    A = sparse.csc_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
    c = -np.ones(n)
    b = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    res = optimize.linprog(c, A_ub=A, b_ub=b, bounds=bounds, method='highs',
                           options={'disp': False, 'time_limit': 10})
    if res.success:
        return np.maximum(res.x, 0.0)
    return None


def lp_phase(f0, time_limit, lp_target_ratio=1.0):
    """LP-guided alternating optimization."""
    f = project_simplex(f0.astype(np.float64), 1.0)
    n = len(f)
    
    conv = fast_convolve(f)
    M = conv.max()
    best_obj = 2.0 * n * M
    best_f = f.copy()
    
    rows, cols = make_lp_indices(n)
    
    t0 = time.monotonic()
    step = 0.5
    patience = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        target_M = M * lp_target_ratio
        g = solve_lp(f, target_M, rows, cols, n)
        if g is None:
            break
        g_sum = g.sum()
        if g_sum < 1e-12:
            break
        g = project_simplex(g, 1.0)
        
        if np.max(np.abs(g - f)) < 1e-14:
            break
        
        improved = False
        for t_try in [step, 0.7 * step, 0.5 * step, 0.3 * step, 0.1 * step]:
            f_new = (1.0 - t_try) * f + t_try * g
            f_new = project_simplex(f_new, 1.0)
            conv_new = fast_convolve(f_new)
            obj_new = 2.0 * n * conv_new.max()
            if obj_new < best_obj - 1e-13:
                f = f_new
                M = conv_new.max()
                best_obj = obj_new
                best_f = f.copy()
                patience = 0
                step = min(1.0, step * 1.05)
                improved = True
                break
        
        if not improved:
            patience += 1
            step *= 0.85
            if patience > 40:
                break
        
        if it % 30 == 0:
            elapsed = time.monotonic() - t0
            print(f"    LP it={it}, obj={best_obj:.8f}, step={step:.3f}, elapsed={elapsed:.1f}s")
    
    return best_f, best_obj


def mirror_phase(f0, time_limit, t_param=50.0, eta0=0.3):
    """Mirror descent (multiplicative weights) on the simplex."""
    f = project_simplex(f0.astype(np.float64), 1.0)
    n = len(f)
    
    conv = fast_convolve(f)
    best_obj = 2.0 * n * conv.max()
    best_f = f.copy()
    
    eta = eta0
    patience = 0
    t0 = time.monotonic()
    
    while time.monotonic() - t0 < time_limit:
        conv = fast_convolve(f)
        max_c = conv.max()
        if max_c < 1e-15:
            break
        
        # Softmax weights on convolution
        scaled = t_param * conv / max_c
        scaled -= scaled.max()
        w = np.exp(scaled)
        w_sum = w.sum()
        if w_sum < 1e-30:
            w = np.zeros(len(conv))
            w[int(np.argmax(conv))] = 1.0
        else:
            w /= w_sum
        
        # Gradient
        corr = np.correlate(w, f, mode='full')
        grad = f + corr[:n]
        
        # Center the gradient (so sum of updates is ~0, preserving sum)
        grad_c = grad - grad.mean()
        
        # Multiplicative update
        lf = -eta * grad_c
        lf -= lf.max()
        f = f * np.exp(lf)
        f = project_simplex(f, 1.0)
        
        conv = fast_convolve(f)
        obj = 2.0 * n * conv.max()
        
        if obj < best_obj - 1e-12:
            best_obj = obj
            best_f = f.copy()
            patience = 0
        else:
            patience += 1
            if patience % 20 == 0:
                eta *= 0.8
                if eta < 0.01:
                    t_param = min(t_param * 1.5, 500.0)
                    eta = 0.2
            if patience > 200:
                break
    
    return best_f, best_obj


def gen_inits(n, rng):
    """Generate diverse initializations."""
    inits = {}
    x = np.arange(n, dtype=np.float64)
    
    inits['uni'] = np.ones(n) / n
    
    for sf in [0.1, 0.15, 0.2, 0.3, 0.4]:
        g = np.exp(-0.5 * ((x - 0.5 * n) / (sf * n)) ** 2)
        g /= g.sum()
        inits[f'g{int(sf * 100)}'] = g
    
    r = np.arange(1, n + 1, dtype=np.float64)
    inits['ramp'] = r / r.sum()
    
    w = max(1, n // 4)
    bi = np.zeros(n)
    bi[:w] = 1.0
    bi[-w:] = 1.0
    inits['bi'] = bi / bi.sum()
    
    cb = 0.5 * (1 + np.cos(2 * np.pi * x / n))
    inits['cos'] = cb / cb.sum()
    
    tri = np.maximum(1.0 - np.abs(x - 0.5 * n) / (0.5 * n), 0.05)
    inits['tri'] = tri / tri.sum()
    
    # Arithmetic progression based (related to the "flat convolution" solution)
    ap = np.ones(n)
    for i in range(1, n):
        ap[i] = ap[i-1] * (1 - 1.0 / (n + i))
    # Actually let's use the theoretical flat-convolution approximation
    # P(X=k) proportional to 1/sqrt(k*(2n-1-k)) for k in 1..n-1, with edge terms
    # This is the arcsine-like distribution
    k = np.arange(n, dtype=np.float64)
    k_safe = np.maximum(k, 0.5)
    k_end = np.maximum(n - 1 - k, 0.5)
    asym = 1.0 / np.sqrt(k_safe * k_end + 1.0)
    inits['asym'] = asym / asym.sum()
    
    # Power-law
    for p in [0.5, 1.0, 2.0]:
        pw = (x + 1) ** (-p)
        inits[f'pw{int(p * 10)}'] = pw / pw.sum()
    
    return inits

"""
Multi-phase optimizer for minimizing 2*n*max(conv(a,a))/(sum(a))^2.
Uses Adam with log-sum-exp smoothing, LP-guided alternating optimization,
mirror descent polishing, and diverse initializations including the
theoretical "ideal" flat-convolution distribution.

import numpy as np
import scipy.optimize as optimize
import scipy.sparse as sparse
import time


def fast_convolve(a):
    """Linear auto-convolution using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    result = np.fft.irfft(A * A, fft_size)
    return result[:size]


def project_simplex(v, target_sum=1.0):
    """Project v onto {x >= 0, sum(x) = target_sum}."""
    v = np.maximum(v, 0.0)
    s = v.sum()
    if s < 1e-15:
        return np.ones(len(v)) * target_sum / len(v)
    return v * (target_sum / s)


def compute_grad_LSE(f, conv, beta):
    """Gradient of logsumexp(beta * conv(f,f)) w.r.t. f."""
    n = len(f)
    mx = conv.max()
    if mx < 1e-15:
        return np.zeros(n)
    w = np.exp(beta * (conv - mx))
    w_sum = w.sum()
    if w_sum < 1e-30:
        w = np.zeros(len(conv))
        w[int(np.argmax(conv))] = 1.0
    else:
        w /= w_sum
    corr = np.correlate(w, f, mode='full')
    return f + corr[:n]


def ideal_distribution(n):
    """Compute the ideal flat-convolution distribution (truncated)."""
    c = np.ones(n)
    for k in range(1, n):
        c[k] = c[k - 1] * (2 * k - 1) / (2 * k)
    return c / c.sum()


def adam_phase(f0, time_limit, beta_start=5.0, beta_end=300.0, lr=0.015):
    """Adam optimization with log-sum-exp on the probability simplex."""
    f = project_simplex(f0.astype(np.float64), 1.0)
    n = len(f)

    conv = fast_convolve(f)
    best_obj = 2.0 * n * conv.max()
    best_f = f.copy()

    m = np.zeros(n)
    v = np.zeros(n)
    t = 0
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8

    t0 = time.monotonic()
    patience = 0

    while time.monotonic() - t0 < time_limit:
        t += 1
        progress = min(1.0, (time.monotonic() - t0) / max(1.0, time_limit))
        beta = beta_start + (beta_end - beta_start) * (progress ** 0.4)

        conv = fast_convolve(f)
        grad = compute_grad_LSE(f, conv, beta)

        m = beta1 * m + (1 - beta1) * grad
        v = beta2 * v + (1 - beta2) * grad ** 2
        m_hat = m / (1 - beta1 ** t)
        v_hat = v / (1 - beta2 ** t)

        f_new = f - lr * m_hat / (np.sqrt(v_hat) + eps)
        f_new = project_simplex(f_new, 1.0)

        conv_new = fast_convolve(f_new)
        obj_new = 2.0 * n * conv_new.max()

        if obj_new < best_obj - 1e-13:
            best_obj = obj_new
            best_f = f_new.copy()
            patience = 0
        else:
            patience += 1
            if patience % 80 == 0:
                lr *= 0.92
            if patience > 400:
                break

        f = f_new

    return best_f, best_obj


def make_lp_indices(n):
    """Precompute indices for cross-convolution constraint matrix."""
    rows_list = []
    cols_list = []
    for i in range(n):
        for j in range(n):
            rows_list.append(i + j)
            cols_list.append(i)
    return np.array(rows_list, dtype=np.int32), np.array(cols_list, dtype=np.int32)


def solve_lp(f, M, rows, cols, n):
    """Solve max sum(g) s.t. g>=0, (f*g)[k]<=M for all k."""
    vals = np.tile(f, n)
    A = sparse.csc_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
    c = -np.ones(n)
    b = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    res = optimize.linprog(c, A_ub=A, b_ub=b, bounds=bounds, method='highs',
                           options={'disp': False, 'time_limit': 12})
    if res.success:
        return np.maximum(res.x, 0.0)
    return None


def lp_phase(f0, time_limit, lp_target_ratio=1.0):
    """LP-guided alternating optimization with backtracking line search."""
    f = project_simplex(f0.astype(np.float64), 1.0)
    n = len(f)

    conv = fast_convolve(f)
    M = conv.max()
    best_obj = 2.0 * n * M
    best_f = f.copy()

    rows, cols = make_lp_indices(n)

    t0 = time.monotonic()
    step = 0.5
    patience = 0
    it = 0

    while time.monotonic() - t0 < time_limit:
        it += 1
        target_M = M * lp_target_ratio
        g = solve_lp(f, target_M, rows, cols, n)
        if g is None:
            break
        g_sum = g.sum()
        if g_sum < 1e-12:
            break
        g = project_simplex(g, 1.0)

        if np.max(np.abs(g - f)) < 1e-14:
            break

        improved = False
        for t_try in [step, 0.7 * step, 0.5 * step, 0.3 * step, 0.1 * step]:
            f_new = (1.0 - t_try) * f + t_try * g
            f_new = project_simplex(f_new, 1.0)
            conv_new = fast_convolve(f_new)
            obj_new = 2.0 * n * conv_new.max()
            if obj_new < best_obj - 1e-13:
                f = f_new
                M = conv_new.max()
                best_obj = obj_new
                best_f = f.new = f copy()  # BUG - fix below
                patience = 0
                step = min(1.0, step * 1.05)
                improved = True
                break

        if not improved:
            patience += 1
            step *= 0.85
            if patience > 50:
                break

        if it % 40 == 0:
            elapsed = time.monotonic() - t0
            print(f"    LP it={it}, obj={best_obj:.8f}, step={step:.3f}, elapsed={elapsed:.1f}s")

def mirror_phase(f0, time_limit, t_param=50.0, eta0=0.3):
    """Mirror descent (multiplicative weights) on the simplex."""
    f = project_simplex(f0.astype(np.float64), 1.0)
    n = len(f)

    conv = fast_convolve(f)
    best_obj = 2.0 * n * conv.max()
    best_f = f.copy()

    eta = eta0
    patience = 0
    t0 = time.monotonic()

    while time.monotonic() - t0 < time_limit:
        conv = fast_convolve(f)
        max_c = conv.max()
        if max_c < 1e-15:
            break

        scaled = t_param * conv / max_c
        scaled -= scaled.max()
        w = np.exp(scaled)
        w_sum = w.sum()
        if w_sum < 1e-30:
            w = np.zeros(len(conv))
            w[int(np.argmax(conv))] = 1.0
        else:
            w /= w_sum

        corr = np.correlate(w, f, mode='full')
        grad = f + corr[:n]
        grad_c = grad - grad.mean()

        lf = -eta * grad_c
        lf -= lf.max()
        f = f * np.exp(lf)
        f = project_simplex(f, 1.0)

        conv = fast_convolve(f)
        obj = 2.0 * n * conv.max()

        if obj < best_obj - 1e-12:
            best_obj = obj
            best_f = f.copy()
            patience = 0
        else:
            patience += 1
            if patience % 25 == 0:
                eta *= 0.8
                if eta < 0.01:
                    t_param = min(t_param * 1.5, 500.0)
                    eta = 0.2
            if patience > 250:
                break

    return best_f, best_obj


def gen_inits(n, rng):
    """Generate diverse initializations including the ideal distribution."""
    inits = {}
    x = np.arange(n, dtype=np.float64)

    inits['uni'] = np.ones(n) / n
    inits['ideal'] = ideal_distribution(n)

    for sf in [0.1, 0.15, 0.25, 0.35, 0.5]:
        g = np.exp(-0.5 * ((x - 0.5 * n) / (sf * n)) ** 2)
        g /= g.sum()
        inits[f'g{int(sf * 100)}'] = g

    r = np.arange(1, n + 1, dtype=np.float64)
    inits['ramp'] = r / r.sum()

    w = max(1, n // 4)
    bi = np.zeros(n)
    bi[:w] = 1.0
    bi[-w:] = 1.0
    inits['bi'] = bi / bi.sum()

    cb = 0.5 * (1 + np.cos(2 * np.pi * x / n))
    inits['cos'] = cb / cb.sum()

    tri = np.maximum(1.0 - np.abs(x - 0.5 * n) / (0.5 * n), 0.05)
    inits['tri'] = tri / tri.sum()

    k_safe = np.maximum(x, 0.5)
    asym = 1.0 / np.sqrt(k_safe)
    inits['inv_sqrt'] = asym / asym.sum()

    for p in [0.5, 1.5]:
        pw = (x + 1) ** (-p)
        inits[f'pw{int(p * 10)}'] = pw / pw.sum()

    return inits

    results.sort(key=lambda x: x[0])
    print(f"  Phase 2 done. Best: {best_score:.6f}")

    # Phase 3: Mirror descent polishing
    print("Phase 3: Mirror polish")
    phase3_deadline = phase2_deadline + 0.20 * (float(budget_s) - 15.0)

    if best_seq is not None:
        configs = [(30.0, 0.4), (80.0, 0.2), (200.0, 0.1), (500.0, 0.05)]
        n_configs = len(configs)
        t_each = (phase3_deadline - time.monotonic()) / max(1, n_configs)

        for tp, eta in configs:
            if time.monotonic() > phase3_deadline - 3:
                break
            ta = min(t_each, phase3_deadline - time.monotonic() - 3)
            if ta < 3:
                break
            f_m, _ = mirror_phase(best_seq, time_limit=ta, t_param=tp, eta0=eta)
            sc_m = float(evaluate_sequence(f_m.tolist()))
            if np.isfinite(sc_m) and sc_m < best_score:
                best_score = sc_m
                best_seq = f_m.copy()
                print(f"  Mirror tp={tp:.0f} eta={eta}: score={sc_m:.6f}")

    print(f"  Phase 3 done. Best: {best_score:.6f}")

    # Phase 4: Final deep optimization
    print("Phase 4: Final optimization")
    phase4_deadline = deadline

    if best_seq is not None and time.monotonic() < phase4_deadline - 5:
        # High-beta Adam for sharp optimization
        ta = min(60.0, (phase4_deadline - time.monotonic()) * 0.3)
        if ta > 5:
            f_a, _ = adam_phase(best_seq, time_limit=ta, beta_start=200.0, beta_end=2000.0, lr=0.003)
            sc_a = float(evaluate_sequence(f_a.tolist()))
            if np.isfinite(sc_a) and sc_a < best_score:
                best_score = sc_a
                best_seq = f_a.copy()
                print(f"  Final Adam: score={sc_a:.6f}")

        # Tight LP
        if time.monotonic() < phase4_deadline - 10:
            ta = min(60.0, (phase4_deadline - time.monotonic()) * 0.35)
            if ta > 10:
                f_lp, _ = lp_phase(best_seq, time_limit=ta, lp_target_ratio=0.97)
                sc_lp = float(evaluate_sequence(f_lp.tolist()))
                if np.isfinite(sc_lp) and sc_lp < best_score:
                    best_score = sc_lp
                    best_seq = f_lp.copy()
                    print(f"  Final LP: score={sc_lp:.6f}")

        # Mirror with high temperature
        if time.monotonic() < phase4_deadline - 5:
            ta = min(40.0, (phase4_deadline - time.monotonic()) * 0.4)
            if ta > 3:
                f_m, _ = mirror_phase(best_seq, time_limit=ta, t_param=800.0, eta0=0.03)
                sc_m = float(evaluate_sequence(f_m.toList() if hasattr(f_m, 'toList') else f_m.tolist()))
                if np.isfinite(sc_m) and sc_m < best_score:
                    best_score = sc_m
                    best_seq = f_m.copy()
                    print(f"  Final Mirror: score={sc_m:.6f}")

        # One more Adam pass
        if time.monotonic() < phase4_deadline - 3:
            ta = max(3.0, (phase4_deadline - time.monotonic()) - 3.0)
            f_a2, _ = adam_phase(best_seq, time_limit=ta, beta_start=500.0, beta_end=5000.0, lr=0.001)
            sc_a2 = float(evaluate_sequence(f_a2.tolist()))
            if np.isfinite(sc_a2) and sc_a2 < best_score:
                best_score = sc_a2
                best_seq = f_a2.copy()
                print(f"  Final Adam2: score={sc_a2:.6f}")

    # Fallback
    if best_seq is None:
        best_seq = np.ones(128)
        best_score = float(evaluate_sequence(best_seq.tolist()))

    print(f"\nFINAL: n={len(best_seq)}, score={best_score:.6f}")
    return [float(x) for x in best_seq]
