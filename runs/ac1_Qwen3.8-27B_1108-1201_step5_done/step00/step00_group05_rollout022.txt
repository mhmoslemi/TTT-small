**Improvement 4: Use multiple k* points**

At the optimum, multiple k's achieve the max. So instead of using just one k*, I can use the top m k's (or all k's above some threshold) and average their gradients. This gives a better descent direction.

    """Compute subgradient of max(b) using top m indices."""
    n = len(a)
    # Find top m indices
    top_indices = np.argsort(b)[::-1][:m]
    # Average the subgradients
    grad = np.zeros(n)
    for k in top_indices:
        # db_k/da_j = 2 * a[k-j] (when 0 <= k-j <= n-1)
        k_int = int(k)
        j_start = max(0, k_int - n + 1)
        j_end = min(n - 1, k_int)
        if j_start <= j_end:
            indices_in_a = range(j_start, j_end + 1)
            a_indices = np.arange(k_int - j_start, k_int - j_end)  # k - j for j in range
            # Wait: db_k/da_j = 2*a[k-j], so for j in [j_start, j_end], k-j is in [k-j_end, k-j_start]
            # a[k-j] for j from j_start to j_end: a[k-j_start], a[k-j_start-1], ..., a[k-j_end]
            # = a[k-j_end : k-j_start+1][::-1]

            hi = k_int - j_start
            grad[j_start:j_end+1] += 2.0 * a[lo:hi+1][::-1]
    return grad / m

For example, instead of minimizing max(b), I could minimize `sum(b²) = ||b||²`. This is a smooth objective (quadratic in a) and can be optimized more efficiently.

`sum(b²)` = `sum_k (sum_i a_i * a[k-i])²` = a more complex expression.

Actually, `sum(b²) = sum_k (b_k)² = (a * a) ⊛ (a * a) * 1`... this is getting complicated.

In the frequency domain: `sum(b²) = (1/N) * sum_k |B(ω_k)|²` where B is the DFT of b (with zero-padding). And `B(ω) = |A(ω)|²`. So `sum(b²) = (1/N) * sum_k |A(ω_k)|⁴`.

Minimizing `sum |A(ω_k)|⁴` subject to `sum(a) = 1`, `a ≥ 0` is a well-defined optimization problem. It's related to making the power spectrum "flat" (which corresponds to a flat autocorrelation in time, by Parseval).

This is actually a **convex** problem! Because `sum |A(ω_k)|⁴ = sum (|A(ω_k)|²)²` and `|A(ω_k)|²` is a quadratic form in a (it's `a^T Q_k a` for a positive semidefinite matrix Q_k), and the sum of squares of quadratic forms... hmm, actually it's not convex in a because it's quartic.

Wait: `|A(ω_k)|² = (sum_i a_i cos(2πki/N) + sum_j a_j sin(2πkj/N))² + ...` — this is a quadratic in a. And squaring it gives a quartic. The minimum of a quartic is not necessarily convex.

So this is not a convex problem either. But it's smoother than the max, which might help with optimization.
