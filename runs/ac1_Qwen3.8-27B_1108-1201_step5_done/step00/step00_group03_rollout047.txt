= (2n/S) * (∂M/∂a[m] - 2M/S)

For m where k*-m is in [0, n-1]:
∂M/∂a[m] = 2*a[k*-m] (if k* ≠ 2m) or a[k*-m] (if k* = 2m)

For m where k*-m is NOT in [0, n-1]:
∂M/∂a[m] = 0

So:
grad[m] = (2n/S) * (dM[m] - 2M/S)

where dM[m] is as above.

For non-contributing elements: grad[m] = (2n/S) * (0 - 2M/S) = -4nM/S² < 0

If a[k*-m] < M/S: grad < 0, a[m] increases. (increase elements that make the product small)

This makes sense! The gradient wants to equalize a[k*-m] to M/S for all contributing m.

But wait, there's a problem. The "contributing" elements are those m where k*-m is in [0, n-1]. The value a[k*-m] is the MIRROR of a[m] (with respect to position k*/2). Actually, I realize there's a symmetry issue. If m contributes (k*-m in range), then k*-m also potentially "contributes" to the same max. The gradient for a[k*-m] would involve a[m].     n = len(a)

    M = conv.max()
    k = int(np.argmax(conv))
    
    grad = np.full(n, -4.0 * n * M / (S * S))
