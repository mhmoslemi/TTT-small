The key insight is that we want to make the sequence "asymmetric" - shifted toward one end - to reduce the peak of the convolution. The optimal sequence probably has a specific shape.

For large `n`, the problem becomes: find a non-negative function `w(x)` on `[0,1]` with `integral = 1` that minimizes `max_x (w*w)(x)` where `(w*w)(x) = integral w(t)w(x-t) dt`.

This is related to the problem of finding a function whose autocorrelation is as flat as possible. In the continuous setting, this is related to "flat频谱" (flat spectrum) sequences.

Actually, for the continuous case, I recall that the optimal solution involves a "rectangular" or "top-hat" shape that's shifted. Let me think...

If `w(x) = c` on `[a, b]` (a rectangle of width `L = b-a`), then `(w*w)(x)` is a triangle function: it's `c^2 * L` at the center and tapers linearly to 0 at the edges. The max is `c^2 * L`.

With `integral = c*L = 1`, we get `max = 1/L`. To minimize this, we want `L` as large as possible, i.e., `L = 1` (the entire interval). This gives `max = 1`, which corresponds to the constant sequence with `f = 2n * 1/n^2 = 2` (in the discrete case).

So a rectangle is not optimal. We need something else.

What about a "bump" that's shifted to one side? In the continuous case, if `w` is supported on `[0, L]` with `L < 1`, then `(w*w)(x)` is supported on `[0, 2L]` and has max `max(w) * integral(w)` roughly... no, that's not right either.

Actually, I think the optimal strategy for large `n` is to use a sequence that's approximately a "cosine bump" or "raised cosine" that's shifted to one edge.
