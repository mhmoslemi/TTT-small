Actually, for the subgradient method, we don't need to verify improvement at every step. We can just take the step and check periodically. The subgradient method with a diminishing step size converges regardless.

Actually, I just realized something. The subgradient I computed is for the function f(a) = c[k*](a) = sum_i a[i]*a[k*-i]. But k* depends on a (it's the argmax). So this is a "conditional" subgradient.

For the function F(a) = max_k c[k](a), the subdifferential at a is:
∂F(a) = conv{∇c[k](a) : k in argmax(c[k](a))}

So any convex combination of {∇c[k](a) : k in argmax} is a valid subgradient. I can use just one (the argmax) or average over all tied argmaxes.

Let me also think about whether the problem has any special structure I can exploit.

The objective is F(a) = max_k sum_i a[i]*a[k-i]. Each c[k] is a quadratic form: c[k] = a^T A_k a where (A_k)_{ij} = 1 if i+j=k, else 0 (with appropriate symmetry).

Actually, c[k] = sum_i a[i]*a[k-i]. This is NOT a standard quadratic form a^T A a = sum_{i,j} a[i]*A[i,j]*a[j] unless we define A_k[i,j] = (1/2)(δ_{i+j,k} + δ_{j+i,k}) = δ_{i+j,k} (since it's symmetric).

Wait: a^T A_k a = sum_{i,j} a[i] * A_k[i,j] * a[j] = sum_{i,j: i+j=k} a[i]*a[j].
But c[k] = sum_i a[i]*a[k-i] = sum_{i: i+(k-i)=k} a[i]*a[k-i] = sum_{i+j=k} a[i]*a[j].

So c[k] = a^T A_k a where A_k[i,j] = 1 if i+j=k, else 0. But A_k should be symmetric: A_k[i,j] = A_k[j,i]. Since i+j=k iff j+i=k, A_k IS symmetric.

So c[k] = a^T A_k a. The eigenvalues of A_k determine whether c[k] is convex or concave.

For k = n-1 (center): A_k has 1s on the anti-diagonal. This is a permutation matrix (reversal), which has eigenvalues +1 and -1. So c[n-1] is indefinite (neither convex nor concave).

For k = 0: A_0 = [[1,0,...],[0,0,...],...], which is a single 1 in the (0,0) position. This is PSD, so c[0] = a[0]^2 is convex.

In general, A_k is a "thick" permutation matrix with 1s on the anti-diagonal i+j=k. It has at most min(k+1, 2n-1-k, n) non-zero rows. The eigenvalues of such a matrix are ±1 (it's a partial permutation matrix, and the non-zero part is a permutation matrix which has eigenvalues that are roots of unity).

Actually, the anti-diagonal submatrix (where i+j=k) is a reversal matrix of size m = min(k+1, 2n-1-k). The reversal matrix J_m has eigenvalues that come in pairs ±1 (and a +1 if m is odd). So A_k has eigenvalues in {+1, -1, 0}, and c[k] is indefinite for any k where m >= 2.

This confirms the problem is non-convex. But the subgradient method should still work well in practice.
