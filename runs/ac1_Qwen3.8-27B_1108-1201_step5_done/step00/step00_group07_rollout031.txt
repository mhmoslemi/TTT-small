```python
def gradient_step(f, step_size):
    n = len(f)
    b = np.convolve(f, f)
    max_val = b.max()
    
    # Use all lags where b is close to max (within 1%)
    threshold = max_val * 0.95
    active = np.where(b >= threshold)[0]
    
    # Compute subgradient
    sg = np.zeros(n)
    for m in active:
        # sg[j] += 2*f[m-j] for j where 0 <= m-j < n
        lo = max(0, m - n + 1)
        hi = min(m, n - 1)
        if lo <= hi:
            sg[lo:hi+1] += 2 * f[m - hi : m - lo + 1]
    
    sg /= len(active)
    
    # Take step
    f_new = f - step_size * sg
    
    # Project: clip to non-negative and renormalize
    f_new = np.clip(f_new, 0, None)
    if f_new.sum() > 0:
        f_new = f_new / f_new.sum()
    else:
        f_new = f.copy()
    
    return f_new
```

Fuchs algorithm:
1. Start with a (e.g., rectangular window)
2. Compute A = DFT(a)
3. For each frequency bin k, if |A[k]|^2 > T (threshold), set |A[k]| = sqrt(T) (keep phase)

5. Apply mask: a_new = max(a_new, 0) (or project onto non-negative)
6. Repeat

The advantage of Fuchs is that each iteration is O(n log n) (FFT), making many iterations feasible.

import numpy as np
import time

def compute_objective(f):
    """Compute the objective value (same as evaluate_sequence but without the safety checks)."""
    n = len(f)
    b = np.convolve(f, f)
    max_b = np.max(b)
    sum_a = np.sum(f)

        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)

def fuchs_iteration(f, num_thresholds=8):
    """Fuchs-like algorithm for reducing peak autocorrelation."""
    n = len(f)
    f_work = f.copy().astype(np.float64)
    
    for _ in range(num_thresholds):
        # Compute autocorrelation via FFT
        size = 2 * n
        F = np.fft.rfft(f_work, size)
        power = np.abs(F) ** 2
        
        # Find current peak in time domain
        b = np.fft.irfft(power, size)
        # Actually, for linear autocorrelation:
        # b = np.fft.irfft(np.abs(F)**2, size) gives circular autocorrelation
        # For linear, we need to be more careful.
        
        # Let's just use direct computation for the peak:
        b_full = np.convolve(f_work, f_work)

        # Set threshold at current peak
        # In frequency domain: reduce bins where power > peak
        # Actually, for autocorrelation, power[k] = |F[k]|^2
        # The peak of the autocorrelation corresponds to the maximum of the inverse DFT of power
        # To reduce the peak, we can cap the power spectrum
        
        # Better approach: compute the peak, then in the frequency domain,
        # replace any |F[k]|^2 that would contribute to peaks with a capped value
        # This is the "peak shaving" in frequency domain
        
        # Simpler: just cap the power at the peak value
        # This makes the autocorrelation have a flat top at the peak level
        power_capped = np.minimum(power, peak)
        
        # Reconstruct
        F_capped = np.sqrt(power_capped) * np.exp(1j * np.angle(F))
        f_new = np.fft.irfft(F_capped, size)[:n]
        
        # Project to non-negative
        f_new = np.clip(f_new, 0, None)
        
        if f_new.sum() > 0:
            f_new = f_new / f_new.sum()
        
        f_work = f_new
    
    return f_work

This is the "full" cross-correlation: sg[j] = (w ⋆ f)[j] where (w ⋆ f)[j] = sum_d w[j+d] f[d].

Using the FFT trick: (w ⋆ f) = ifft(fft(w) * conj(fft(f))) (circular correlation), but we need to handle the linear case.

For linear cross-correlation of w (length L1=2n-1) and f (length L2=n):
- Pad both to length L = L1 + L2 - 1 = 3n-2
- Compute W = fft(w_padded), F = fft(f_padded)
- result = ifft(W * conj(F))
- The linear cross-correlation is result[0:L2] (or a slice thereof)

Actually, I think it's simpler to just note that:
sg[j] = sum_{d=0}^{n-1-min(0, j+d-(2n-2))} w[j+d] * f[d]

For j = 0: sg[0] = sum_{d=0}^{n-1} w[d] * f[d] (all valid since j+d = d <= n-1 < 2n-1)
For j = n-1: sg[n-1] = sum_{d=0}^{n-1} w[n-1+d] * f[d] (valid since n-1+d <= 2n-2)

So all terms are valid for all j. We can compute:
sg = [sum_{d=0}^{n-1} w[j+d] * f[d] for j in 0..n-1]

This is a "sliding dot product" which can be computed with a Toeplitz matrix multiplication, or with FFT.

Using FFT:
- Create a matrix W_mat where W_mat[j, d] = w[j+d]. This is (2n-1-j) x n for row j. It's a Hankel-like matrix.
- sg = W_mat @ f

But constructing W_mat is O(n^2) memory. For n=6733, that's 45M * 8 = 360 MB. Too much.

Alternative: Use the fact that sg = ifft(fft(w, size) * conj(fft(f, size)))[:n] with appropriate zero-padding.
