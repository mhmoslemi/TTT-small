Key insight: The objective is scale-invariant (scaling `a` by a constant doesn't change the ratio), so we can normalize to `sum(a) = 1` (or any fixed value). Then we're minimizing `2*n*max(conv(a,a))` subject to `sum(a) = 1, a >= 0`.

- We want to minimize the peak of the auto-convolution
- The auto-convolution at lag 0 is `sum(a_i^2)`, which is minimized when `a` is uniform (giving `1/n` for each element, so `max_conv = 1/n`, objective = `2*n*(1/n)/1 = 2`)

So we want to make the peaks of the convolution as flat as possible. The best case would be if all convolution values are equal, which would give `max_conv = sum(a_i^2) * n / (2n-1)`... no wait.

Actually, `sum_k conv(a,a)[k] = sum_i sum_j a_i * a_j = (sum a_i)^2 = 1` (if normalized to sum=1). The convolution has `2n-1` terms. If all were equal, each would be `1/(2n-1)`, and max would be `1/(2n-1)`, giving objective `2n/(2n-1) ≈ 1` for large n.

But this is impossible to achieve exactly because the convolution structure couples the values.

The gradient of `q_k(a)` with respect to `a_j` is: `sum_i [a_{k-i} * delta(i,j) + a_i * delta(k-i,j)]` = `a_{k-j} + a_j` (with appropriate boundary handling). Wait let me be more careful.

`q_k(a) = sum_i a[i] * a[k-i]` where `a[i] = 0` for `i < 0` or `i >= n`.

`dq_k/d(a[j]) = sum_i [delta(i,j) * a[k-i] + a[i] * delta(k-i,j)]`
`= a[k-j] + sum_i a[i] * delta(k-i,j)`
`= a[k-j] + a[k-j]` (when `0 <= k-j < n`)
`= 2*a[k-j]` if `0 <= k-j < n`
`= a[k-j]` if only one term contributes (boundary case)

Wait, let me redo this. `q_k = sum_{i=0}^{n-1} a[i] * a[k-i]` where `a[m] = 0` if `m < 0` or `m >= n`.

`dq_k/da[j] = sum_{i=0}^{n-1} [delta(i,j) * a[k-i] + a[i] * delta(k-i, j)]`
`= a[k-j] + sum_{i=0}^{n-1} a[i] * delta(k-i, j)`
`= a[k-j] + a[k-j]` (since `k-i = j` means `i = k-j`, and if `0 <= k-j < n` then this term exists)

So `dq_k/da[j] = 2*a[(k-j) mod ...]` - wait, it's `a[k-j]` if `0 <= k-j < n`, else 0. Plus `a[k-j]` from the first term if `0 <= k-j < n`, else 0.

Actually: first term: `delta(i,j) * a[k-i]` evaluated at `i=j` gives `a[k-j]` (if `0 <= k-j < n`, else 0).
Second term: `a[i] * delta(k-i,j)` - this is nonzero when `i = k-j`, giving `a[k-j]` (if `0 <= k-j < n`, else 0).

So `dq_k/da[j] = 2 * a[k-j]` if `0 <= k-j < n`, else 0.

Wait, but there's a subtlety: when `k-j = j` (i.e., `k = 2j`), both terms give the same `a[j]`, so it's `2*a[j]`. That's consistent.

So the subgradient of `f(a) = max_k q_k(a)` at a point where the max is achieved at set `S` is:
`g = sum_{k in S} w_k * grad(q_k)` where `w_k >= 0, sum w_k = 1`.

For the active set (where max is achieved), we can use uniform weights or softmax weights.

One approach that might work better: **Proximal Gradient with Entropic Regularization (Mirror Descent)**

Instead of projecting onto the simplex (Euclidean projection), use the KL projection (entropic mirror). This gives a different geometry that might work better for this problem.

The update would be:
`a_new[j] = a[j] * exp(-eta * g[j]) / sum_i a[i] * exp(-eta * g[i])`

This is multiplicative weights / exponential tilting.

Another idea: **Alternating minimization on the active set**. 

1. Identify the top `K` peak positions in the convolution.
2. For a fixed set of active peaks, the problem becomes: minimize the sum of the top K quadratic forms, subject to `a >= 0, sum(a) = 1`.
3. This is a trust region subproblem on the simplex.

Actually, let me think about a completely different approach: **Iterative reweighting / cycle cancelling**.

The idea is:
1. Start with some `a`.
2. Compute `conv(a,a)`.
3. The peak positions are where we need to reduce correlation.
4. For each peak at position `k`, the contribution is `sum_i a[i]*a[k-i]`. To reduce this, we can try to make the sequence more "uncorrelated" at that lag.
5. A simple approach: for the peak at lag `k`, try to reduce `a[i]` for pairs `(i, k-i)` that have large products.

Let me think about another angle: **spectral design / Golay-like sequences**.

If we think in the frequency domain: `DFT(conv(a,a)) = |DFT(a)|^2`. We want `|DFT(a)(k)|^2` to be as flat as possible. This is related to "flat-top" spectral design. For a sequence of length `n`, `|DFT(a)(k)|^2` has `n` values (for cyclic convolution). For linear convolution, it's more complex.

The constraint is `a >= 0` and `sum(a) = 1`. In the frequency domain, `a >= 0` becomes a complex constraint (all the inverse DFT elements must be non-negative).

This is essentially the problem of finding a non-negative sequence with flat spectrum - related to PSD (positive definite) sequence design.

1. **Softmax-smoothed max**: Instead of using the hard max, use `logsumexp` of the convolution values, which gives a smooth approximation.

2. **Mirror descent with KL geometry**: Use multiplicative updates.

3. **Adaptive peak targeting with quadratic approximation**: For each peak, compute a local quadratic model and solve the resulting subproblem.

import numpy as np
import time
from scipy.optimize import linprog, minimize
import scipy.fft

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def clip_nonneg_normalize(a):
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s

def compute_subgradient(a, top_k=50, temperature=0.01):
    """Compute a weighted subgradient of max(conv(a,a))."""
    n = len(a)
    conv = fast_convolve(a)
    # Use softmax weighting on the top peaks
    k_actual = min(top_k, len(conv))
    peaks = np.argpartition(conv, -k_actual)[-k_actual:]
    pv = conv[peaks]
    scaled = pv / temperature
    scaled -= scaled.max()
    w = np.exp(scaled)
    ws = w.sum()
    w = w / ws
    
    # Compute gradient of each q_k with respect to a
    # dq_k/da[j] = 2*a[k-j] if 0 <= k-j < n, else 0
    sg = np.zeros(n)
    for i in range(len(peaks)):
        if w[i] < 1e-12:
            continue
        k = int(peaks[i])
        # a[k-j] is nonzero when 0 <= k-j < n, i.e., k-n+1 <= j <= k
        js = max(0, k - n + 1)
        je = min(n - 1, k)
        # a[k-j] for j in [js, je]
        idx = np.arange(js, je + 1)
        a_vals = a[k - idx]  # a[k-js], ..., a[k-je]
        # Wait: for j in [js, je], a[k-j] ranges from a[k-js] to a[k-je]
        # k-js = k - max(0, k-n+1)
        # k-je = k - min(n-1, k)
        
        # Handle the case where k-j = j (i.e., j = k/2) - the derivative is a[k-j] not 2*a[k-j]
        # Actually no: dq_k/da[j] = a[k-j] (first term, from i=j) + a[k-j] (second term, from i=k-j)
        # But when i=j and i=k-j, i.e., j = k-j, i.e., 2j = k, then both terms are the same a[j]
        # So the derivative is still 2*a[j] in that case too? Wait...
        
        # Let me re-derive: q_k = sum_{i=0}^{n-1} a[i] * a[k-i]
        # d/d(a[j]) = sum_{i} [delta(i,j)*a[k-i] + a[i]*delta(k-i,j)]
        # = a[k-j] + a[k-j] = 2*a[k-j] (when 0 <= k-j < n)
        # The first term: setting i=j gives a[k-j] (if 0<=k-j<n)
        # The second term: setting k-i=j gives i=k-j, value is a[k-j] (if 0<=k-j<n)
        # These are the same value! So the total is 2*a[k-j].
        # But wait - when j = k-j (i.e., 2j=k), the "first term" and "second term" 
        # both come from the same product a[j]*a[j] = a[j]^2, and d/d(a[j]) a[j]^2 = 2*a[j].
        # So yes, it's always 2*a[k-j] when 0 <= k-j < n.
        
        sg[js:je+1] += 2.0 * w[i] * a_vals
    
    return sg

def mirror_descent_optimize(a0, time_limit, lr=0.01, top_k=50, temp=0.01, verbose=False):
    """Mirror descent (exponential tilting) on the simplex."""
    a = clip_nonneg_normalize(a0.astype(np.float64))
    n = len(a)
    
    conv = fast_convolve(a)
    best_obj = conv.max()
    best_a = a.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    cur_lr = lr
    cur_temp = temp
    
    while time.monotonic() - t0 < time_limit:
        sg = compute_subgradient(a, top_k=top_k, temperature=cur_temp)
        # Mirror descent step: a_new[j] = a[j] * exp(-lr * sg[j])
        # Normalize to simplex
        log_a = np.log(a + 1e-300)
        log_a_new = log_a - cur_lr * sg
        # For numerical stability, subtract max
        log_a_new -= log_a_new.max()
        a_new = np.exp(log_a_new)
        a_new = a_new / a_new.sum()
        
        conv = fast_convolve(a_new)
        obj = conv.max()
        
        if obj < best_obj - 1e-14:
            best_obj = obj
            best_a = a_new.copy()
            no_improve = 0
            a = a_new
            if verbose and (int(time.monotonic() - t0)) % 10 == 0:
                print(f"    MD: obj={best_obj:.10f}, t={time.monotonic()-t0:.0f}s")
        else:
            no_improve += 1
            a = a_new  # still move
        
        cur_lr *= 0.9995
        cur_temp *= 1.003
        
        if no_improve > 300:
            # Restart with perturbation
            rng = np.random.default_rng(int(time.monotonic() * 10000) % 999983)
            a = clip_nonneg_normalize(best_a + rng.standard_normal(n) * 0.002)
            cur_lr = max(lr * 0.5, 0.003)
            no_improve = 0
    
    return best_a, best_obj

    best_obj = conv.max()
    best_a = a.copy()

    smooth_param = 0.01  # temperature for logsumexp
    
    while time.monotonic() - t0 < time_limit:
        # Compute smooth gradient: softmax-weighted gradient
        conv = fast_convolve(a)
        scaled = conv / smooth_param
        scaled -= scaled.max()
        w = np.exp(scaled)
        w = w / w.sum()
        
        # Gradient of sum_k w_k * q_k(a)
        sg = np.zeros(n)
        # Only need to consider peaks with significant weight
        significant = w > 1e-10
        for k in np.where(significant)[0]:
            if w[k] < 1e-12:

            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            sg[js:je+1] += 2.0 * w[k] * a[k - idx]

        # This is just s = e_argmin(sg)
        s = np.zeros(n)

                best_alpha = alpha

            a_new = (1 - best_alpha) * a + best_alpha * s
            a_new = clip_nonneg_normalize(a_new)
            val = fast_convolve(a_new).max()
            
            if val < best_obj - 1e-14:

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp /= ss
    return f_interp

import numpy as np

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def clip_normalize(a):
    """Clip to non-negative and normalize to sum=1."""
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s


def compute_gradient(a, top_k=80, temp=0.005):
    """Compute softmax-weighted subgradient of max(conv(a,a))."""
    n = len(a)
    conv = fast_convolve(a)

    peaks = np.argpartition(conv, -k_actual)[-k_actual:]
    pv = conv[peaks]
    scaled = pv / temp
    scaled -= scaled.max()
    w = np.exp(scaled)
    ws = w.sum()
    if ws < 1e-15:
        w = np.zeros(len(peaks))
        w[np.argmax(pv)] = 1.0

        je = min(n - 1, k)
        idx = np.arange(js, je + 1)

            grad[js:je + 1] += 2.0 * p[k] * y[k - idx]

        # Step size based on Lipschitz estimate
        step = cur_tau / (2.0 * (y.max() + 1e-8))
        step = min(step, 0.5)

        z = project_simplex(y - step * grad)

        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t * t)) / 2.0
        y = z + (t - 1.0) / t_new * (z - a_prev)
        y = np.maximum(y, 0)
        ys = y.sum()
        if ys < 1e-15:
            y = a.copy()
        else:
            y = y / ys
        t = t_new
        a_prev = a
        a = z

        conv = fast_convolve(a)
        obj = conv.max()

        if obj < best_obj - 1e-15:
            best_obj = obj
            best_a = a.copy()
            no_improve = 0
            if verbose and it % 100 == 0:
                print(f"    FISTA iter {it}: obj={best_obj:.10f}, t={time.monotonic()-t0:.0f}s")
        else:
            no_improve += 1

        if no_improve > 80:
            no_improve = 0
            if cur_tau < 0.05:
                cur_tau *= 1.3
            else:
                rng = np.random.default_rng(int(time.monotonic() * 100000) % 999983)
                a_prev = clip_normalize(best_a + rng.standard_normal(n) * 0.002)
                t = 1.0
                cur_tau = max(cur_tau * 0.7, 0.005)

    return best_a, best_obj


def mirror_descent_optimize(a0, time_limit, lr=0.02, top_k=40, temp=0.005, verbose=False):
    """Mirror descent (exponential tilting) on the simplex."""
    a = clip_normalize(a0.astype(np.float64))
    n = len(a)

    conv = fast_convolve(a)
    best_obj = conv.max()
    best_a = a.copy()

    t0 = time.monotonic()
    no_improve = 0
    cur_lr = lr
    cur_temp = temp
    it = 0

    while time.monotonic() - t0 < time_limit:
        it += 1
        sg, conv = compute_gradient(a, top_k=top_k, temp=cur_temp)

        # Multiplicative update
        log_update = -cur_lr * sg
        log_update -= log_update.max()
        mult = np.exp(log_update)
        a_new = a * mult
        a_new = a_new / a_new.sum()

        conv_new = fast_convolve(a_new)
        obj_new = conv_new.max()

        if obj_new < best_obj - 1e-15:
            best_obj = obj_new
            best_a = a_new.copy()
            no_improve = 0
            a = a_new
            if verbose and it % 200 == 0:
                print(f"    MD iter {it}: obj={best_obj:.10f}, t={time.monotonic()-t0:.0f}s")
        else:
            no_improve += 1
            a = a_new

        cur_lr *= 0.9993
        cur_temp *= 1.003

        if no_improve > 400:
            rng = np.random.default_rng(int(time.monotonic() * 100000) % 999983)
            a = clip_normalize(best_a + rng.standard_normal(n) * 0.002)
            cur_lr = max(lr * 0.4, 0.005)
            no_improve = 0

    return best_a, best_obj


def pairwise_swap_cd(a0, time_limit, verbose=False):
    """Coordinate descent using pairwise mass transfers (maintains sum=1 automatically)."""
    a = clip_normalize(a0.astype(np.float64))
    n = len(a)

    conv = fast_convolve(a)
    best_obj = conv.max()
    best_a = a.copy()

    t0 = time.monotonic()
    no_improve = 0
    it = 0

    while time.monotonic() - t0 < time_limit:
        it += 1
        improved = False

        # Find peak positions
        top_k = min(5, len(conv))
        peak_positions = np.argpartition(conv, -top_k)[-top_k:]

        # For each peak, try to reduce it by transferring mass
        for pk in peak_positions:
            peak_k = int(pk)
            # Coordinates contributing to this peak: j where 0 <= peak_k - j < n
            js = max(0, peak_k - n + 1)
            je = min(n - 1, peak_k)

            # Find the coordinate with largest contribution to the peak
            contribs = np.array([a[j] * a[peak_k - j] for j in range(js, je + 1)])
            if contribs.max() < 1e-15:
                continue

            # Try reducing the largest contributor
            j_star = js + int(np.argmax(contribs))
            partner = peak_k - j_star

            if partner < 0 or partner >= n or partner == j_star:
                continue

            # Transfer mass from j_star to a random other coordinate (to spread out)
            rng = np.random.default_rng(it * 104729 + pk)
            for _ in range(5):
                target = int(rng.integers(0, n))
                if target == j_star or target == partner:
                    continue

                for frac in [0.1, 0.2, 0.3, 0.5]:
                    delta = a[j_star] * frac
                    if delta < 1e-12:
                        continue
                    a_trial = a.copy()
                    a_trial[j_star] -= delta
                    a_trial[target] += delta
                    if a_trial[j_star] < -1e-10:
                        continue
                    a_trial = clip_normalize(a_trial)

                    val = fast_convolve(a_trial).max()
                    if val < best_obj - 1e-14:
                        a = a_trial
                        best_obj = val
                        best_a = a.copy()
                        conv = fast_convolve(a)
                        improved = True
                        break

            if improved:
                break

        if not improved:
            no_improve += 1
            # Try random pairwise swaps
            rng = np.random.default_rng(it * 7919 + 13)
            for _ in range(20):
                i = int(rng.integers(0, n))
                j = int(rng.integers(0, n))
                if i == j or a[i] < 1e-10:
                    continue
                delta = a[i] * 0.2
                a_trial = a.copy()
                a_trial[i] -= delta
                a_trial[j] += delta
                a_trial = clip_normalize(a_trial)
                val = fast_convolve(a_trial).max()
                if val < best_obj - 1e-14:
                    a = a_trial
                    best_obj = val
                    best_a = a.copy()
                    improved = True
                    break

            if no_improve > 30:
                break
        else:
            no_improve = 0

        if verbose and it % 50 == 0:
            print(f"    Swap iter {it}: obj={best_obj:.10f}, t={time.monotonic()-t0:.0f}s")

    return best_a, best_obj


def single_coord_cd(a0, time_limit, verbose=False):
    """Single coordinate descent with golden section search."""
    a = clip_normalize(a0.astype(np.float64))
    n = len(a)

    conv = fast_convolve(a)
    best_obj = conv.max()
    best_a = a.copy()

    t0 = time.monotonic()
    no_improve = 0
    it = 0

    while time.monotonic() - t0 < time_limit:
        it += 1
        improved = False

        rng = np.random.default_rng(it * 6151)
        order = rng.permutation(n)

        for j in order:
            if time.monotonic() - t0 > time_limit:
                break
            if a[j] < 1e-12:
                continue

            old_val = a[j]
            best_j_val = old_val
            best_j_obj = best_obj

            # Try several multipliers
            for mult in [0.4, 0.6, 0.8, 1.2, 1.5, 2.0]:
                new_val = old_val * mult
                if new_val < 0 or new_val > 0.8:
                    continue
                denom = 1.0 - old_val
                if denom < 1e-10:
                    continue
                scale = (1.0 - new_val) / denom
                a_trial = a.copy()
                a_trial[j] = new_val
                mask = np.ones(n, dtype=bool)
                mask[j] = False
                a_trial[mask] *= scale
                a_trial = a_trial / a_trial.sum()

                val = fast_convolve(a_trial).max()
                if val < best_j_obj - 1e-14:
                    best_j_obj = val
                    best_j_val = new_val

            if best_j_val != old_val:
                denom = 1.0 - old_val
                if denom > 1e-10:
                    scale = (1.0 - best_j_val) / denom
                    a[j] = best_j_val
                    mask = np.ones(n, dtype=bool)
                    mask[j] = False
                    a[mask] *= scale
                    a = a / a.sum()
                    conv = fast_convolve(a)
                    if best_j_obj < best_obj - 1e-14:
                        best_obj = best_j_obj
                        best_a = a.copy()
                        improved = True

        if not improved:
            no_improve += 1
            if no_improve > 5:
                break
        else:
            no_improve = 0

        if verbose and it % 10 == 0:
            print(f"    CD iter {it}: obj={best_obj:.10f}, t={time.monotonic()-t0:.0f}s")

    return best_a, best_obj


def interpolate_sequence(f, new_n):
    """Interpolate a sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp /= ss
    return f_interp


def propose_candidate(seed=42, budget_s=1800, **kwargs):
    """
    Multi-strategy optimization: subgradient with momentum, FISTA,
    mirror descent, coordinate descent, and dimension exploration.
    """
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + max(1.0, float(budget_s) - 25.0)

    best_seq = None
    best_score = float('inf')

    def try_seq(a, label=""):
        nonlocal best_seq, best_score
        a = np.maximum(a, 0.0)
        if a.sum() < 1e-10:
            return float('inf')
        a_norm = a / a.sum()
        score = float(evaluate_sequence(a_norm.tolist()))
        if np.isfinite(score) and score < best_score:
            best_score = score
            best_seq = a_norm.copy()
            print(f"  NEW BEST [{label}]: {score:.10f} (n={len(a_norm)})")
        return score

    # Get parent
    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            parent = p / p.sum()
            p_score = float(evaluate_sequence(parent.tolist()))
            print(f"Parent: n={len(parent)}, score={p_score:.10f}")
            best_seq = parent.copy()
            best_score = p_score
    except Exception:
        pass

    if parent is None:
        parent = np.ones(832) / 832
        best_seq = parent.copy()
        best_score = float(evaluate_sequence(parent.tolist()))
        print(f"Default: n={len(parent)}, score={best_score:.10f}")

    base_n = len(parent)

    # === Phase 1: Fast subgradient with momentum ===
    print(f"\n=== Phase 1: Subgradient (n={base_n}) ===")
    rem = deadline - time.monotonic()
    t1 = min(250, rem * 0.2)
    if t1 > 30:
        print(f"  n={base_n}, t={t1:.0f}s")
        a_opt, _ = subgradient_optimize(parent, time_limit=t1, lr=0.004,
                                        momentum=0.92, top_k=40, temp=0.004)
        try_seq(a_opt, "sg_momentum")

        # Second run with different params
        rem = deadline - time.monotonic()
        t1b = min(150, rem * 0.15)
        if t1b > 20 and best_seq is not None:
            a_opt, _ = subgradient_optimize(best_seq, time_limit=t1b, lr=0.002,
                                            momentum=0.94, top_k=80, temp=0.01)
            try_seq(a_opt, "sg_fine")

    # === Phase 2: FISTA ===
    print(f"\n=== Phase 2: FISTA (best={best_score:.10f}) ===")
    if best_seq is not None:
        rem = deadline - time.monotonic()
        t2 = min(250, rem * 0.2)
        if t2 > 30:
            print(f"  n={len(best_seq)}, t={t2:.0f}s")
            a_opt, _ = fista_optimize(best_seq, time_limit=t2, tau=0.008)
            try_seq(a_opt, "fista_1")

            rem = deadline - time.monotonic()
            t2b = min(150, rem * 0.1)
            if t2b > 20:
                a_opt, _ = fista_optimize(best_seq, time_limit=t2b, tau=0.02)
                try_seq(a_opt, "fista_2")

    # === Phase 3: Mirror Descent ===
    print(f"\n=== Phase 3: Mirror Descent (best={best_score:.10f}) ===")
    if best_seq is not None:
        rem = deadline - time.monotonic()
        t3 = min(200, rem * 0.15)
        if t3 > 25:
            print(f"  n={len(best_seq)}, t={t3:.0f}s")
            a_opt, _ = mirror_descent_optimize(best_seq, time_limit=t3, lr=0.03,
                                               top_k=30, temp=0.003)
            try_seq(a_opt, "mirror_descent")

    # === Phase 4: Coordinate Descent ===
    print(f"\n=== Phase 4: Single-Coord CD (best={best_score:.10f}) ===")
    if best_seq is not None:
        rem = deadline - time.monotonic()
        t4 = min(250, rem * 0.2)
        if t4 > 30:
            print(f"  n={len(best_seq)}, t={t4:.0f}s")
            a_opt, _ = single_coord_cd(best_seq, time_limit=t4)
            try_seq(a_opt, "single_cd")

    # === Phase 5: Pairwise Swaps ===
    print(f"\n=== Phase 5: Pairwise Swaps (best={best_score:.10f}) ===")
    if best_seq is not None:
        rem = deadline - time.monotonic()
        t5 = min(200, rem * 0.15)
        if t5 > 25:
            print(f"  n={len(best_seq)}, t={t5:.0f}s")
            a_opt, _ = pairwise_swap_cd(best_seq, time_limit=t5)
            try_seq(a_opt, "pairwise_swaps")

    # === Phase 6: Dimension exploration ===
    print(f"\n=== Phase 6: Dimension Exploration ===")
    if best_seq is not None:
        candidate_lengths = []
        base = len(best_seq)
        for delta in [-64, -32, 32, 64, 96, 128]:
            ln = base + delta
            if 300 <= ln <= 2048:
                candidate_lengths.append(ln)
        # Also try some round numbers
        for ln in [640, 768, 1000, 1024, 1280]:
            if ln not in candidate_lengths and 300 <= ln <= 2048:
                candidate_lengths.append(ln)
        candidate_lengths = sorted(set(candidate_lengths))

        for target_n in candidate_lengths[:4]:
            rem = deadline - time.monotonic()
            if rem < 60:
                break
            t_alloc = min(rem * 0.25, 150)
            if t_alloc < 20:
                break
            f_interp = interpolate_sequence(best_seq, target_n)
            print(f"  SG n={target_n}, t={t_alloc:.0f}s")
            a_opt, _ = subgradient_optimize(f_interp, time_limit=t_alloc, lr=0.004,
                                            momentum=0.9, top_k=30, temp=0.005)
            try_seq(a_opt, f"dim_{target_n}")

    # === Phase 7: Final Polish ===
    print(f"\n=== Phase 7: Final Polish (best={best_score:.10f}) ===")
    if best_seq is not None:
        n_best = len(best_seq)

        # Quick multi-method polish
        rem = deadline - time.monotonic() - 30
        if rem > 20:
            t = min(rem, 80)
            a_opt, _ = subgradient_optimize(best_seq, time_limit=t, lr=0.002,
                                            momentum=0.95, top_k=20, temp=0.002)
            try_seq(a_opt, "polish_sg")

        rem = deadline - time.monotonic() - 20
        if rem > 15:
            t = min(rem, 60)
            a_opt, _ = single_coord_cd(best_seq, time_limit=t)
            try_seq(a_opt, "polish_cd")

        rem = deadline - time.monotonic() - 15
        if rem > 15:
            t = min(rem, 60)
            a_opt, _ = mirror_descent_optimize(best_seq, time_limit=t, lr=0.01,
                                               top_k=20, temp=0.002)
            try_seq(a_opt, "polish_md")

        # Perturbations from best
        for p in range(8):
            rem = deadline - time.monotonic() - 10
            if rem < 12:
                break
            noise_scale = 0.001 + 0.0005 * p
            f_pert = clip_normalize(best_seq + rng.standard_normal(n_best) * noise_scale)
            a_opt, _ = subgradient_optimize(f_pert, time_limit=min(rem, 25),
                                            lr=0.002, momentum=0.93,
                                            top_k=20, temp=0.003)
            try_seq(a_opt, f"perturb_{p}")

    # Fallback
    if best_seq is None:
        best_seq = np.ones(832) / 832
        best_score = float(evaluate_sequence(best_seq.tolist()))

    # Final verification
    fs = float(evaluate_sequence(best_seq.tolist()))
    if np.isfinite(fs):
        best_score = fs
    else:
        best_seq = np.ones(832) / 832
        best_score = float(evaluate_sequence(best_seq.tolist()))

    print(f"\nFINAL SCORE: {best_score:.10f} (n={len(best_seq)})")
    return [float(x) for x in best_seq]
