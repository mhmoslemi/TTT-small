Now let me think about what the optimal structure looks like. The key insight is:
- `conv[k] = sum_j a[j] * a[k-j]` (with out-of-bounds = 0)
- We want to minimize `max_k conv[k]` relative to `(sum a)^2 / n`

The "spread" of mass matters. If we put mass at positions that are "far apart" in the convolution sense, the products don't overlap much, reducing the peak.

This is related to "difference sets" and "Golomb rulers" in combinatorics! A set S of integers is a "perfect difference set" if all pairwise differences are distinct (or nearly so). This minimizes the number of collisions in the difference table, which is exactly what we want to minimize the auto-convolution.

More precisely: if `a` is the indicator of a set S ⊂ {0,...,n-1}, then `conv[k] = |{(x,y) ∈ S×S : x-y = -k}|` (roughly). We want to minimize the maximum number of representations of any difference.

This is the "additive energy" problem! The additive energy of a set S is `E(S) = |{(a,b,c,d) ∈ S^4 : a+b=c+d}| = sum_k conv_S[k]^2`. The "collision energy" or "difference energy" is `sum_k |{(a,b) : a-b=k}|^2`.

For our problem, we want to minimize `max_k |{(x,y) ∈ S×S : x-y = k}|` (for indicator sequences) or the weighted version for general sequences.

This connects to the theory of "Bhattacharya" sequences and "Sidon sets."

For general (non-indicator) sequences, the problem is to find a non-negative vector that minimizes the peak of its auto-convolution, which is related to the "minimum peak auto-correlation" problem in radar/communications (though here it's convolution, not correlation).

Now, for the optimization approach, I think the key new ideas are:

1. **Combinatorial initialization**: Start from structured sequences based on difference sets, Golomb rulers, or other combinatorial designs.

2. **Subgradient with Nesterov acceleration**: The previous code uses Adam, but Nesterov's accelerated gradient might converge faster for this type of non-smooth convex-like problem.

3. **Exact coordinate descent**: For each pair (i,j), exactly solve the optimal redistribution. Since the objective is `max_k conv[k]` and conv is bilinear, fixing all coordinates except i and j makes the objective a function of one variable (the fraction of mass at position i vs j). This function is piecewise linear (since conv values are linear in each variable, and max of linear functions is piecewise linear). So we can find the exact optimum by checking breakpoints.

4. **Mirror descent with KL divergence**: Instead of Euclidean projection, use the KL projection (which gives multiplicative updates). This might work better for non-negative variables.

Let me focus on implementing these ideas:

**Key algorithm: Accelerated subgradient + exact coordinate descent**

For the subgradient:
- Compute `c = conv(f, f)`
- Find active set: `A = {k : c[k] >= M - epsilon}` where `M = max(c)`
- Subgradient: `sg[i] = sum_{k in A} c_k'(i) / |A|` where `c_k'(i) = a[k-i]` (if valid)
- Nesterov momentum: maintain `z = x + beta*(x - x_prev)`, compute subgradient at `z`, update `x_new = x - step * sg(z)`

For exact coordinate descent:
- For pair (i,j), let `s = f[i] + f[j]`. Let `f[i] = t*s, f[j] = (1-t)*s`.
- The convolution values that change are those involving i or j.
- For each affected position k, `conv[k]` becomes `base_k + t*s*a[k-i] + (1-t)*s*a[k-j]` (approximately, ignoring the i-j cross term).
- Actually it's more complex because conv involves products.
- `conv[k]` changes as: terms involving a[i] and a[j].
- Specifically, `conv[k] = old_conv[k] - a[i]*a[k-i] - a[j]*a[k-j] + t*s*a[k-i] + (1-t)*s*a[k-j]` (for k where only one of i,j contributes)
- Plus the cross term: when k-i = j or k-j = i, there's a `t*(1-t)*s^2` term.

This is getting complex. Let me just implement a numerical approach for the coordinate descent (ternary search or golden section on t).

Let me now write the actual code:

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Nesterov-accelerated subgradient with adaptive step size
2. Exact 2-coordinate descent (golden section search)
3. Combinatorial initializations (Golomb ruler based)
4. Multi-scale exploration with diverse restarts
5. Mirror descent (multiplicative updates) for non-negativity
"""

import numpy as np
from scipy.optimize import linprog
import time

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    """Euclidean projection onto the probability simplex {x>=0, sum(x)=1}."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1.0)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def nesterov_subgrad(f0, time_limit, verbose=False):
    """Nesterov-accelerated subgradient method for minimizing max(conv(f,f)) on the simplex."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f0)) / len(f0)
    else:
        f = f / s
    n = len(f)
    
    best_obj = fast_convolve(f).max()
    best_f = f.copy()
    
    # Nesterov momentum
    x = f.copy()
    y = f.copy()  # Nesterov lookahead point
    beta = 1.0  # Will be updated
    
    # Polyak step size parameters
    # Lower bound for max(conv(f,f)) on simplex is at least 1/n (at center for uniform)
    # Actually the true lower bound is problem-dependent
    LB = 0.0  # Conservative lower bound
    
    t0 = time.monotonic()
    it = 0
    no_improve = 0
    
    # Adaptive temperature for subgradient
    T_start = 2.0 / n
    T_end = 0.1 / n
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        progress = min(1.0, time.monotonic() - t0) / time_limit
        T = T_start * (T_end / T_start) ** progress
        beta = 2.0 / (it + 3)  # Nesterov momentum parameter
        
        # Nesterov step: y = x + (beta_prev - 1) * (x - x_prev)
        # Simplified: y = x + (1 - beta) * (x - y_prev)
        # Standard: y = ((t-1)*(t+1)/((t+2)*(t-1))) * x + ((t+2)-(t-1))/(t+2) * ... 
        # Let's use the simple form: y = x + (t_k - 1) / (t_{k+1}) * (x - x_prev)
        # Where t_k = (1 + sqrt(1 + 4*k^2)) / 2
        t_k = (1 + np.sqrt(1 + 4.0 * (it - 1) ** 2)) / 2.0 if it > 1 else 1.0
        t_k1 = (1 + np.sqrt(1 + 4.0 * it ** 2)) / 2.0
        if it > 1:
            y = x + ((t_k - 1.0) / t_k1) * (x - y)
        else:
            y = x.copy()
        
        # Project y to simplex (must stay feasible)
        y = project_simplex(y)
        
        # Compute subgradient at y
        conv_y = fast_convolve(y)
        M_y = conv_y.max()
        
        # Soft subgradient using temperature
        k_actual = min(2 * n - 1, max(10, int(0.1 * (2 * n - 1))))
        peaks = np.argpartition(conv_y, -k_actual)[-k_actual:]
        pv = conv_y[peaks]
        scaled = T * (pv - pv.max())
        w = np.exp(scaled)
        ws = w.sum()
        if ws < 1e-15:
            w = np.zeros(len(peaks))
            w[np.argmax(pv)] = 1.0
        else:
            w = w / ws
        
        sg = np.zeros(n)
        for i in range(len(peaks)):
            if w[i] < 1e-14:
                continue
            k = int(peaks[i])
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            sg[idx] += 2.0 * w[i] * y[k - idx]
        
        # Polyak step size: step = (f(y) - LB) / ||sg||^2
        sg_norm_sq = np.sum(sg ** 2)
        if sg_norm_sq < 1e-20:
            no_improve += 5
            continue
        step = (M_y - LB) / (sg_norm_sq + 1e-20)
        step = min(step, 1.0 / (np.sqrt(it) + 1))  # Cap step size
        
        # Update
        x_new = project_simplex(y - step * sg)
        
        if np.max(np.abs(x_new - x)) < 1e-14:
            no_improve += 1
            if no_improve > 100:
                rng = np.random.default_rng(it * 17 + 5)
                x = project_simplex(best_f + rng.standard_normal(n) * 0.003)
                y = x.copy()
                no_improve = 0
            continue
        
        x = x_new
        new_M = fast_convolve(x).max()
        
        if new_M < best_obj - 1e-13:
            best_obj = new_M
            best_f = x.copy()
            no_improve = 0
            if verbose and it % 50 == 0:
                print(f"  Nesterov iter {it}: obj={best_obj:.10f}, T={T:.6f}, step={step:.6f}")
        else:
            no_improve += 1
    
    return best_f, best_obj


def coordinate_descent(f0, time_limit, verbose=False):
    """
    Exact 2-coordinate descent: for each pair (i,j), find optimal mass split
    using the structure of the max-conv objective.
    """
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f0)) / len(f0)
    else:
        f = f / s
    n = len(f)
    
    best_f = f.copy()
    best_obj = fast_convolve(f).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(12345)
    
    # Precompute offsets for diverse pair selection
    offsets = list(range(1, min(n, 100)))
    
    passes = 0
    no_improve_passes = 0
    
    while time.monotonic() - t0 < time_limit:
        passes += 1
        if time.monotonic() - t0 > time_limit - 5:
            break
        
        pass_improved = False
        improved_this_pass = 0
        
        # Select pairs to optimize
        # Strategy: random pairs + structured pairs
        num_pairs = min(n * 3, 5000)
        if passes % 4 == 0:
            # Structured: focus on pairs that contribute to peaks
            conv = fast_convolve(f)
            peak_positions = np.argsort(conv)[-10:]
            pairs = []
            for k in peak_positions:
                js = max(0, k - n + 1)
                je = min(n - 1, k)
                for j in range(js, je + 1):
                    i = k - j
                    if i != j and i < n:
                        pairs.append((i, j))
            # Add random pairs
            while len(pairs) < num_pairs:
                i = rng.integers(n)
                j = rng.integers(n)
                if i != j:
                    pairs.append((i, j))
        else:
            pairs = []
            while len(pairs) < num_pairs:
                i = rng.integers(n)
                offset = offsets[rng.integers(len(offsets))]
                j = (i + offset) % n
                if i != j:
                    pairs.append((i, j))
        
        for (i, j) in pairs:
            if time.monotonic() - t0 > time_limit - 2:
                break
            
            c = f[i] + f[j]
            if c < 1e-12:
                continue
            
            # Golden section search on t in [0, 1] where f[i] = t*c, f[j] = (1-t)*c
            # Objective: max_k conv_k(t)
            # conv_k(t) is quadratic in t (at most)
            
            # Quick evaluation at a few points
            def obj_at_t(t):
                f_trial = f.copy()
                f_trial[i] = t * c
                f_trial[j] = (1 - t) * c
                f_trial = f_trial / f_trial.sum()
                return fast_convolve(f_trial).max()
            
            # Coarse scan
            best_t = f[i] / c
            best_val = obj_at_t(best_t)
            
            candidates = np.linspace(0, 1, 11)
            for t in candidates:
                val = obj_at_t(t)
                if val < best_val - 1e-14:
                    best_val = val
                    best_t = t
            
            # Fine search around best_t
            if 0.02 < best_t < 0.98:
                lo = max(0.0, best_t - 0.1)
                hi = min(1.0, best_t + 0.1)
                gr = (np.sqrt(5) - 1) / 2
                c1 = hi - gr * (hi - lo)
                c2 = lo + gr * (hi - lo)
                v1 = obj_at_t(c1)
                v2 = obj_at_t(c2)
                
                for _ in range(12):
                    if hi - lo < 1e-7:
                        break
                    if v1 < v2:
                        hi = c2
                        c2 = c1
                        v2 = v1
                        c1 = hi - gr * (hi - lo)
                        v1 = obj_at_t(c1)
                    else:
                        lo = c1
                        c1 = c2
                        v1 = v2
                        c2 = lo + gr * (hi - lo)
                        v2 = obj_at_t(c2)
                
                mid = (lo + hi) / 2
                v_mid = obj_at_t(mid)
                if v_mid < best_val:
                    best_val = v_mid
                    best_t = mid
            
            if best_val < best_obj - 1e-13:
                f[i] = best_t * c
                f[j] = (1 - best_t) * c
                f = f / f.sum()
                best_obj = best_val
                best_f = f.copy()
                pass_improved = True
                improved_this_pass += 1
        
        if pass_improved:
            no_improve_passes = 0
            if verbose and passes % 5 == 0:
                print(f"  CoordDesc pass {passes}: obj={best_obj:.10f}, improved={improved_this_pass}")
        else:
            no_improve_passes += 1
            if no_improve_passes >= 5:
                break
        
        # Occasionally add noise to escape local minima
        if passes % 10 == 0 and no_improve_passes >= 2:
            rng2 = np.random.default_rng(passes * 31)
            f = project_simplex(best_f + rng2.standard_normal(n) * 0.002)
            best_obj = fast_convolve(f).max()
            no_improve_passes = 0
    
    return best_f, best_obj


def multiplicative_update(f0, time_limit, verbose=False):
    """
    Mirror descent with KL divergence (multiplicative updates).
    a_i <- a_i * exp(-eta * sg_i) / normalizer
    """
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f0)) / len(f0)
    else:
        f = f / f * 1  # already normalized
    n = len(f)
    
    best_obj = fast_convolve(f).max()
    best_f = f.copy()
    t0 = time.monotonic()
    
    eta = 1.0 / n  # Step size
    it = 0
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        progress = min(1.0, time.monotonic() - t0) / time_limit
        eta = (1.0 / n) * (1.0 - 0.5 * progress)
        
        conv = fast_convolve(f)
        M = conv.max()
        
        # Subgradient (exact max subgradient, averaged over argmax)
        argmax = np.where(conv >= M - 1e-10)[0]
        sg = np.zeros(n)
        for k in argmax:
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            sg[idx] += 2.0 * f[k - idx]
        sg /= len(argmax)
        
        # Multiplicative update
        f_new = f * np.exp(-eta * sg)
        f_new_sum = f_new.sum()
        if f_new_sum < 1e-15:
            break
        f_new /= f_new_sum
        
        if np.max(np.abs(f_new - f)) < 1e-14:
            no_improve += 1
            if no_improve > 50:
                rng = np.random.default_rng(it * 23 + 11)
                f = project_simplex(best_f + rng.standard_normal(n) * 0.005)
                no_improve = 0
            continue
        
        f = f_new
        new_M = fast_convolve(f).max()
        
        if new_M < best_obj - 1e-12:
            best_obj = new_M
            best_f = f.copy()
            no_improve = 0
            if verbose and it % 100 == 0:
                print(f"  Multiplicative iter {it}: obj={best_obj:.10f}, eta={eta:.6f}")
        else:
            no_improve += 1
    
    return best_f, best_obj


def golomb_ruler_init(n, num_markers):
    """Create an initial sequence based on Golomb ruler-like spacing."""
    a = np.zeros(n)
    # Place markers at positions that minimize difference collisions
    # Use a greedy construction
    positions = [0]
    for _ in range(num_markers - 1):
        best_pos = -1
        best_score = float('inf')
        for pos in range(1, n):
            if pos in positions:
                continue
            # Check differences with existing positions
            diffs = []
            for p in positions:
                d = abs(pos - p)
                if d != 0:
                    diffs.append(d)
            # Score: number of repeated differences
            from collections import Counter
            counts = Counter(diffs)
            max_count = max(counts.values()) if counts else 0
            # Also check against existing differences
            existing_diffs = []
            for i in range(len(positions)):
                for j in range(i + 1, len(positions)):
                    existing_diffs.append(abs(positions[i] - positions[j]))
            all_diffs = existing_diffs + diffs
            counts_all = Counter(all_diffs)
            max_count_all = max(counts_all.values()) if counts_all else 0
            if max_count_all < best_score:
                best_score = max_count_all
                best_pos = pos
                if best_score == 1:
                    break
        if best_pos >= 0:
            positions.append(best_pos)
    
    for p in positions:
        a[p] = 1.0
    
    return a / a.sum()


def diverse_random_init(n, seed):
    """Generate diverse random initializations."""
    rng = np.random.default_rng(seed)
    method = seed % 5
    
    if method == 0:
        # Sparse random
        a = np.zeros(n)
        k = max(2, n // 4)
        positions = rng.choice(n, size=k, replace=False)
        a[positions] = rng.dirichlet(np.ones(k))
    elif method == 1:
        # Symmetric random
        half = rng.dirichlet(np.ones(n // 2 + 1))
        a = np.zeros(n)
        a[:n // 2 + 1] = half
        a[n // 2:] = half[:n - n // 2][::-1]
    elif method == 2:
        # Exponential decay
        a = np.exp(-np.linspace(0, 3, n))
        a = a + rng.standard_normal(n) * 0.1
        a = np.maximum(a, 0)
    elif method == 3:
        # Fourier-domain random
        L = 1 << (2 * n - 2).bit_length()
        phase = rng.standard_normal(L // 2 + 1)
        mag = rng.chisquare(1, size=L // 2 + 1) + 1
        A = mag * np.exp(1j * phase)
        a = np.fft.irfft(A, L)[:n]
        a = np.maximum(a, 0)
    else:
        # Power law
        a = 1.0 / (np.arange(1, n + 1) ** 0.5)
        a += rng.standard_normal(n) * 0.05
        a = np.maximum(a, 0)
    
    a_sum = a.sum()
    if a_sum < 1e-10:
        a = np.ones(n)
        a_sum = n
    return a / a_sum


def lp_direction(f, M, n):
    """Solve LP: max sum(g) s.t. (f*g)[k] <= M for all k, g >= 0."""
    c = -np.ones(n)
    A_ub = np.zeros((2 * n - 1, n))
    for j in range(n):
        rows = np.arange(j, j + n)
        A_ub[rows, j] = f
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success:
        return np.maximum(res.x, 0)
    return None


def lp_fw_optimize(f0, time_limit, verbose=False):
    """LP-based Frank-Wolfe with line search."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f0)) / len(f0)
    else:
        f = f / s
    n = len(f)
    
    conv = fast_convolve(f)
    M = conv.max()
    best_obj = M
    best_f = f.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 3:
            break
        
        g = lp_direction(f, M, n)
        if g is None:
            g = lp_direction(f, M * 1.01, n)
            if g is None:
                no_improve += 1
                if no_improve > 50:
                    rng = np.random.default_rng(it * 13 + 42)
                    f = project_simplex(best_f + rng.standard_normal(n) * 0.003)
                    conv = fast_convolve(f)
                    M = conv.max()
                    no_improve = 0
                continue
        
        g_sum = g.sum()
        if g_sum < 1e-15:
            break
        g = g / g_sum
        
        if np.max(np.abs(g - f)) < 1e-11:
            no_improve += 1
            if no_improve > 50:
                rng = np.random.default_rng(it * 137 + 42)
                f = project_simplex(best_f + rng.standard_normal(n) * 0.003)
                conv = fast_convolve(f)
                M = conv.max()
                no_improve = 0
            continue
        
        # Step size: try several and pick best
        best_alpha = 0.0
        best_val = M
        for alpha in [0.1, 0.2, 0.3, 0.5, 0.7, 1.0]:
            ft = np.maximum(f + alpha * (g - f), 0.0)
            st = ft.sum()
            if st < 1e-15:
                continue
            ft = ft / st
            val = fast_convolve(ft).max()
            if val < best_val:
                best_val = val
                best_alpha = alpha
        
        if best_alpha > 1e-10:
            f_new = f + best_alpha * (g - f)
            f_new = np.maximum(f_new, 0.0)
            f_new = f_new / f_new.sum()
            conv = fast_convolve(f_new)
            M = conv.max()
            f = f_new
            
            if M < best_obj - 1e-14:
                best_obj = M
                best_f = f.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1
        
        if no_improve > 80:
            rng = np.random.default_rng(it * 31 + 7)
            f = project_simplex(best_f + rng.standard_normal(n) * 0.002)
            conv = fast_convolve(f)
            M = conv.max()
            no_improve = 0
    
    return best_f, best_obj


def interpolate_sequence(f, new_n):
    """Interpolate a sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp /= ss
    return f_interp
