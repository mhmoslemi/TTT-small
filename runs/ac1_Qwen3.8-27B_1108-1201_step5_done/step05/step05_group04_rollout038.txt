```python
            grad[ms2] += wk * f[k - ms2]
    return grad
```

This computes `grad[m] = sum_k w[k] * (contribution from k to m)`.

From I1: for m in [lo, hi], `grad[m] += w[k] * f[k-m]`. Since lo = max(0,k-n+1) and hi = min(n-1,k), this means 0 ≤ k-m ≤ n-1 for m in [lo,hi]. So this gives `w[k] * f[k-m]` for valid k-m.

From I2: for m in [k-hi, k-lo], `grad[m] += w[k] * f[k-m]`. Now k-hi = k - min(n-1,k) and k-lo = k - max(0,k-n+1).

If k < n: hi = k, lo = 0. So k-hi = 0, k-lo = k. So m in [0, k], and grad[m] += w[k] * f[k-m].
If k >= n: hi = n-1, lo = k-n+1. So k-hi = k-(n-1), k-lo = k-(k-n+1) = n-1. So m in [k-n+1, n-1], and grad[m] += w[k] * f[k-m].

So in both cases, the total contribution to grad[m] from lag k is:
- I1: w[k]*f[k-m] for m in [lo, hi] (i.e., 0 ≤ k-m ≤ n-1)
- I2: w[k]*f[k-m] for m in [k-hi, k-lo]

But wait, [k-hi, k-lo] = [k - min(n-1,k), k - max(0,k-n+1)].

If k < n: [0, k] (same as [lo, hi] = [0, k])
If k ≥ n: [k-n+1, n-1] (same as [lo, hi] = [k-n+1, n-1])

So I1 and I2 give the SAME range of m! The code is double-counting!

That's the "double-counting" bug mentioned in the docstring! The gradient should be `2 * sum_k w[k] * f[k-m] * [valid]`, but the code computes `sum_k w[k] * f[k-m] * [valid] + sum_k w[k] * f[k-m] * [valid]` = `2 * sum_k ...` which is actually correct!

Wait no. The correct gradient is `∂(a*a)[k]/∂a[m] = 2*f[k-m]*[valid]`. So the gradient of `sum_k w[k]*(a*a)[k]` is `sum_k w[k] * 2*f[k-m]*[valid]`.

The code computes:
- I1 adds `w[k]*f[k-m]` for valid m
- I2 adds `w[k]*f[k-m]` for valid m (same range)
- Total: `2*w[k]*f[k-m]` for valid m ✓

So it IS correct! The "double-counting" that was "fixed" was actually the correct computation. Or maybe the original had a bug where I2 didn't match I1's range.

**Approach: Iterative peak reduction via equality constraints**

The max autocorrelation problem can be attacked by:

The gradient of C[k*] w.r.t. a is `2*a[::-1] shifted`, which is a simple shift of a.

So the natural descent direction is to move a in the direction that reduces C[k*]. Since `∂C[k*]/∂a[m] = 2*a[k*-m]`, the descent direction for a is `-a[flipped and shifted]`.

But we need to stay on the simplex (a >= 0, sum = 1). So we project.

This is essentially what the directed peak gradient does, but maybe we can do it more aggressively.

**A new idea: Use the fact that the gradient is a shifted copy of a**

The gradient of `C[k]` w.r.t. `a` is `2 * reverse_shift(a, k)`. So if the peaks are at lags k1, k2, ..., the gradient is a sum of shifted/reversed copies of a.

This means the "eigen-directions" of the problem are related to the shift operators. In the Fourier domain, shifting corresponds to phase rotation. So the problem has a natural spectral structure.

**Spectral approach:**
Let's work in the DFT domain. Let `A[j] = DFT(a)[j]` for j = 0, ..., N-1 where N >= 2n-1.

Then `C[k] = IDFT(|A|^2)[k]` (for the linear convolution, with appropriate zero-padding).

We want to minimize `max_k C[k]` subject to `a >= 0`, `sum(a) = 1`.

In the spectral domain:
- `sum(a) = 1` means `A[0] = 1` (DC component)
- `a >= 0` is a constraint that's hard to express spectrally
- `max_k C[k]` is the max of the IDFT of `|A|^2`

The IDFT of `|A|^2` has mean `sum_k C[k]/N = (1/N) sum_j |A[j]|^2 = ||a||^2/N`.

For the linear convolution (zero-padded), the mean is `||a||^2 / N` where N is the FFT size. But the actual sum of C[k] for k=0 to 2n-2 is `||a||^4` ... wait no.

`sum_k C[k] = (a*a)[0] + (a*a)[1] + ... + (a*a)[2n-2]`.

Actually, `sum_k (a*a)[k] = (sum_i a[i])^2 = (sum a)^2 = 1` (for normalized a).

So the mean of C is `1/(2n-1)` and we want to minimize the max. The theoretical minimum is `1/(2n-1)` (perfectly flat), giving objective `2n/(2n-1) ≈ 1`.

For the objective `2n * max(C) / (sum a)^2`, with sum a = 1:
- We want max(C) as small as possible
- C has 2n-1 entries summing to 1
- So the mean is 1/(2n-1)
- We want C to be as flat as possible

The "flattest" C would be the one where C[k] = 1/(2n-1) for all k. This requires `|A[j]|^2 = 1/((2n-1)) * N` for all j (where N is FFT size), i.e., |A[j]| is constant. This is the CAZAC condition, which for real sequences means a is uniform (all equal). But uniform gives C with a triangular shape (peak at center), not flat!

The issue is that for LINEAR convolution (not circular), the relationship between the spectrum and the autocorrelation is different. The linear autocorrelation is the IFFT of |A|^2 only when we use circular convolution in the padded space.

Actually, let me reconsider. If we zero-pad a to length N >= 2n-1, then the linear convolution equals the circular convolution in the padded space. So:
- Let a_pad be a zero-padded to length N
- C_circ[k] = IFFT(|FFT(a_pad)|^2)[k] for k = 0, ..., N-1
- C_linear[k] = C_circ[k] for k = 0, ..., 2n-2
- C_circ[k] = C_circ[N-k] for the wrappedaround part (due to conjugate symmetry of real signals)

So we want to minimize `max_{k=0}^{2n-2} C_circ[k]` where C_circ = IFFT(|FFT(a_pad)|^2).

This is exactly the "peak-to-average power ratio" (PAPR) problem in the autocorrelation domain! Or equivalently, we want the autocorrelation to be as flat as possible.

The PAPR problem in communications is usually about the time-domain signal, but here it's about the autocorrelation domain. It's a dual problem.

**Key insight for algorithm**: The subgradient of `max C[k]` is a sum of shifted copies of `a`. In the frequency domain, shifting corresponds to multiplication by a phase factor. So the "descent direction" in the frequency domain is a sum of phase-rotated copies of `A`.

This suggests an iterative algorithm:
1. Compute C = autoconv(a)
2. Find peak lag k*
3. Descent direction in time domain: d = -a[reversed, shifted by k*] (normalized)
4. In frequency domain: D = FFT(d) = -conj(A) * exp(2πi*k*/N) (approximately)
5. Update: A_new = A + step * D (or some variant)
6. Project back to time domain: a_new = Re(IFFT(A_new)), clip to non-negative, re-normalize

This is essentially a projected subgradient method, but with spectral structure exploited.

```python
import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def autoconv_gradient(a, k):
    """Compute gradient of (a*a)[k] w.r.t. a.
    Returns a vector of length len(a).
    grad[m] = 2*a[k-m] if 0 <= k-m < n, else 0.
    """
    n = len(a)
    grad = np.zeros(n)
    # m ranges over [max(0, k-n+1), min(k, n-1)]
    lo = max(0, k - n + 1)
    hi = min(k, n - 1)
    if lo <= hi:
        ms = np.arange(lo, hi + 1)
        grad[ms] = 2.0 * a[k - ms]
    return grad

def subgradient_max_conv(a, n_peaks=1):
    """Compute subgradient of max_k C[k] w.r.t. a.
    If n_peaks=1, uses only the argmax.
    If n_peaks>1, averages over top peaks with exponential weighting.
    """
    n = len(a)
    C = fast_convolve(a)
    conv_len = len(C)
    
    if n_peaks == 1:
        k_star = np.argmax(C)
        return autoconv_gradient(a, k_star), C
    
    # Use exponential weighting over top peaks
    top_k = min(n_peaks, conv_len)
    peak_idx = np.argpartition(C, -top_k)[-top_k:]
    peak_vals = C[peak_idx]
    # Soft max weighting
    scaled = peak_vals - peak_vals.max()
    w = np.exp(scaled * 10)  # sharp weighting towards highest
    w /= w.sum()
    
    grad = np.zeros(n)
    for idx, wk in zip(peak_idx, w):
        grad += wk * autoconv_gradient(a, idx)
    return grad, C

def spectral_perturb(a, rng, scale=0.1):
    """Perturb a in the frequency domain and project back."""
    n = len(a)
    fft_size = 1 << (2*n - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    # Random phase perturbation
    phases = 2 * np.pi * rng.random(fft_size // 2 + 1) * scale
    phases[0] = 0  # keep DC
    A_pert = A * np.exp(1j * phases)
    a_pert = np.fft.irfft(A_pert, fft_size)[:n]
    a_pert = np.maximum(a_pert, 0)
    s = a_pert.sum()
    if s < 1e-15:
        return a.copy()
    return a_pert / s

def coordinate_descent_step(a, C, n_coords=None, max_iter=100):
    """For each coordinate, find the best value that reduces max C."""
    n = len(a)
    a_new = a.copy()
    best_max = C.max()
    
    if n_coords is None:
        indices = np.random.permutation(n)
    else:
        # Focus on coordinates with high leverage
        # A coordinate a[m] affects C[k] for k in [0, 2n-2] where a[k-m] is nonzero
        # High leverage = coordinates that appear in the peak autocorrelation terms
        peak_k = np.argmax(C)
        lo = max(0, peak_k - n + 1)
        hi = min(peak_k, n - 1)
        indices = np.concatenate([np.arange(lo, hi+1), np.random.permutation(n)[:n//4]])
        indices = indices[:min(n, len(indices))]
    
    for m in indices:
        # Try different values of a[m]
        # The effect on C: C[k] changes by a_new[m] * a[k-m] - a_old[m] * a[k-m]
        # = (a_new[m] - a_old[m]) * a[k-m]
        # So increasing a[m] increases C[k] by (delta) * a[k-m] for valid k
        # We want to choose a[m] to minimize max C
        
        old_val = a_new[m]
        if old_val < 1e-10:
            continue
        
        # Try reducing a[m] and redistributing
        # Simple approach: try a[m] * factor for various factors
        for factor in [0.5, 0.7, 0.85, 1.15, 1.3, 1.5]:
            new_val = old_val * factor
            a_new[m] = new_val
            # Renormalize (approximately - just recompute the affected C values)
            # For speed, just check if max C decreased
            # Quick check: the peak C[peak_k] changes by (new_val - old_val) * a[peak_k - m]
            delta = (new_val - old_val) * a[peak_k - m] if 0 <= peak_k - m < n else 0
            if delta < -1e-10:
                break  # keep this value
        
        # Renormalize
        a_new = np.maximum(a_new, 0)
        s = a_new.sum()
        if s > 1e-15:
            a_new = a_new / s
        else:
            a_new = a.copy()
            break
    
    return a_new

def lse_descent(a0, time_limit, beta_start=50.0, beta_end=20000.0):
    """LSE-based gradient descent with adaptive beta."""
    a = np.maximum(a0.astype(np.float64), 0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    C = fast_convolve(a)
    best_obj = C.max()
    best_a = a.copy()
    
    beta = beta_start
    lr = 2.0 / n
    momentum = 0.92
    v = np.zeros(n)
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        C = fast_convolve(a)
        bc = beta * C
        bc_max = bc.max()
        exp_bc = np.exp(bc - bc_max)
        w = exp_bc / exp_bc.sum()
        
        # Compute weighted gradient
        grad = np.zeros(n)
        # Use only significant weights for efficiency
        sig_threshold = w.max() * 0.01
        sig_idx = np.where(w > sig_threshold)[0]
        
        for k in sig_idx:
            wk = w[k]
            if wk < 1e-12:
                continue
            lo = max(0, k - n + 1)
            hi = min(k, n - 1)
            if lo <= hi:
                ms = np.arange(lo, hi + 1)
                grad[ms] += 2.0 * wk * a[k - ms]
        
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-15:
            break
        grad /= grad_norm
        
        v = momentum * v - lr * grad
        a_new = project_simplex(a + v)
        C_new = fast_convolve(a_new)
        obj_new = C_new.max()
        
        if obj_new < best_obj - 1e-12:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new
            no_improve = 0
        else:
            no_improve += 1
            if no_improve >= 15:
                lr *= 0.94
            if no_improve > 80:
                beta = min(beta * 2.0, beta_end)
                a = best_a.copy()
                v = np.zeros(n)
                lr = 2.0 / n
                no_improve = 0
        
        beta = min(beta * 1.003, beta_end)
    
    return best_a, best_obj

def interpolate_to_length(f, new_n):
    x_old = np.linspace(0, 1, len(f))
    x_new = np.linspace(0, 1, new_n)
    f_new = np.interp(x_new, x_old, f)
    f_new = np.maximum(f_new, 0)
    s = f_new.sum()
    if s > 1e-15:
        f_new /= s
    else:
        f_new = np.ones(new_n) / new_n
```

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1

    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    """Euclidean projection onto {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = (u * np.arange(1, n + 1)) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = int(np.nonzero(cond)[0][-1])
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def grad_at_peak(a, k):

    lo = max(0, k - n + 1)
    hi = min(k, n - 1)
    if lo <= hi:
        ms = np.arange(lo, hi + 1)
        grad[ms] = 2.0 * a[k - ms]
    return grad

    a_new = np.maximum(a_new, 0)
    s = a_new.sum()
    if s < 1e-15:

    return a_new / s
