   So I1 and I2 are computing the same thing! The total gradient contribution from peak k is:
   `2 * wk * f[k-m]` for valid m.
   
   This matches our derivation. So the gradient is correct, just computed in a loop over peaks.
   
   The FFT-based approach would be much faster for large n and many peaks. Let me use that.

Let me think about what the optimal structure looks like. For a "flat" autocorrelation, we want the sequence to be like a "perfect" sequence. In radar/communications, these are related to Zadoff-Chu sequences, Barker codes, etc.

For continuous sequences, a Gaussian has a Gaussian autocorrelation. To make it flat, we want something more like a rectangular function... but a rectangular function has a sinc^2 autocorrelation which has sidelobes.

Actually, for the discrete case with the constraint that all values are non-negative, the optimal solution is likely to be some kind of smooth "bell-shaped" curve or a flat top with smooth edges.

1. **Faster gradient computation via FFT**: This would allow more iterations in the same time.
2. **Better step size selection**: Adaptive learning rates, maybe using a backtracking line search.

**Phase 1**: Quick exploration of different n values using a fast gradient method.
**Phase 2**: Focus on the best n and use the FFT-accelerated gradient with Nesterov momentum.
**Phase 3**: Fine-tuning with coordinate descent and local search.

The key improvement over the previous code:
- FFT-based gradient (much faster, allows working with more peaks or even all peaks)
- Nesterov-accelerated gradient descent
- Better time management
- Try to use all peaks in the LSE weight (not just top K)

Actually, with FFT-based gradient, we can compute the exact gradient of the LSE objective in O(N log N) time, which is much faster than the O(n*K) loop over peaks. This means we can do many more iterations.

Let me also think about the LSE objective more carefully:
`LSE(f) = (1/beta) * log(sum_k exp(beta * (f*f)[k]))`

This approximates `max_k (f*f)[k]` as beta → ∞. The gradient is:
`grad_i = (1/beta) * sum_k exp(beta*g[k]) / sum_j exp(beta*g[j]) * 2*f[k-i]`
      = 2 * sum_k w[k] * f[k-i] where w[k] = exp(beta*g[k]) / sum_j exp(beta*g[j])

With FFT, this is O(N log N) per step.

For n=768, N would be about 2048 (next power of 2 >= 2*768-1=1535). So each FFT step is very fast.

Let me also consider: what if we use the exact max instead of LSE? The subgradient of max is just the indicator of argmax, so the subgradient is `2 * f[peak_index - i]` for i in range. This is even simpler but might be too noisy.

A hybrid approach: use LSE with high beta for stability, but also try the exact peak subgradient.

"""

import numpy as np
import time
from scipy.optimize import linprog
from scipy.sparse import csr_matrix


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def lse_gradient(f, beta, fft_size=None):
    """Compute gradient of LSE objective using FFT.
    LSE = (1/beta) * log(sum_k exp(beta * (f*f)[k]))
    grad = 2 * correlation(w, f) where w = softmax(beta * (f*f))
    """
    n = len(f)
    conv_len = 2 * n - 1
    if fft_size is None:
        fft_size = 1 << (conv_len + n - 2).bit_length()
    
    conv = fast_convolve(f)
    # Compute softmax weights
    bc = beta * conv
    bc_max = bc.max()
    exp_bc = np.exp(bc - bc_max)
    w = exp_bc / exp_bc.sum()
    
    # Gradient = 2 * cross_correlation(w, f)
    # cross_corr[i] = sum_j w[j+i] * f[j] for j=0..n-1
    # = ifft(fft(f, N) * conj(fft(w, N)))
    W = np.fft.rfft(w, fft_size)
    F = np.fft.rfft(f, fft_size)
    corr = np.fft.irfft(F * np.conj(W), fft_size)[:n]
    
    return 2.0 * corr


def exact_peak_gradient(f, fft_size=None):
    """Compute subgradient at the peak: 2 * correlation(onehot_peak, f)."""
    n = len(f)
    conv = fast_convolve(f)
    peak_idx = int(np.argmax(conv))
    
    # Subgradient is 2 * f[peak_idx - i] for valid i
    lo = max(0, peak_idx - n + 1)
    hi = min(n - 1, peak_idx)
    grad = np.zeros(n)
    if lo <= hi:
        grad[lo:hi+1] = 2.0 * f[peak_idx - hi : peak_idx - lo + 1][::-1]
    
    return grad, conv


def nesterov_lse(f0, time_limit, beta_start=50.0, beta_end=20000.0, 
                  lr_init=None, momentum_init=0.9, seed=0):
    """LSE gradient descent with Nesterov momentum and FFT-accelerated gradient."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    
    if lr_init is None:
        lr_init = 2.0 / n
    
    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()
    
    fft_size = 1 << (2 * n - 1 + n - 2).bit_length()
    
    beta = beta_start
    lr = lr_init
    momentum = momentum_init
    v = np.zeros(n)
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        
        # Nesterov lookahead
        y = f + momentum * v
        
        # Compute gradient at y
        y_pos = np.maximum(y, 0.0)
        y_sum = y_pos.sum()
        if y_sum < 1e-15:
            y_pos = f
        else:
            y_pos = y_pos / y_sum
        
        grad = lse_gradient(y_pos, beta, fft_size)
        
        # Project gradient onto tangent space of simplex (remove mean)
        # Actually, we project the step, not the gradient
        v = momentum * v - lr * grad
        f_new = project_simplex(f + v)
        
        conv_new = fast_convolve(f_new)
        obj_new = conv_new.max()
        
        if obj_new < best_obj - 1e-15:
            best_obj = obj_new
            best_f = f_new.copy()
            no_improve = 0
            # Slightly increase lr on improvement
            lr = min(lr * 1.002, 5.0 / n)
        else:
            no_improve += 1
            if no_improve >= 5:
                lr *= 0.95
            if no_improve > 50:
                f = best_f.copy()
                v = np.zeros(n)
                lr = max(lr_init * 0.5, 0.001 / n)
                beta = min(beta * 1.5, beta_end)
                no_improve = 0
        
        f = f_new
        
        # Gradually increase beta
        if beta < beta_end:
            beta *= 1.003
    
    return best_f, best_obj


def peak_subgradient_method(f0, time_limit, lr_init=None, momentum=0.85, seed=0):
    """Subgradient method targeting the exact peak."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:

    best_f = f.copy()
    
    lr = lr_init
    v = np.zeros(n)
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        
        grad, conv = exact_peak_gradient(f)
        v = momentum * v - lr * grad
        f_new = project_simplex(f + v)

        obj_new = conv_new.max()
        
        if obj_new < best_obj - 1e-15:

    return best_f, best_obj

            # Simple approach: try perturbing f[i] and check if max(conv) decreases
            # This is O(n) per evaluation (recompute affected conv entries)
            
            # Actually for simplicity and speed, let's skip full coordinate descent

def build_lp_and_fw(f0, time_limit):
    """Frank-Wolfe with LP oracle for the normalized problem."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    conv_len = 2 * n - 1
    
    conv = fast_convolve(f)
    M = conv.max()
    best_obj = M
    best_f = f.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        
        # Build LP: max sum(g) s.t. A@g <= M, g >= 0
        # A is the convolution matrix
        rows = []
        cols = []
        vals = []
        for k in range(conv_len):
            j_start = max(0, k - n + 1)
            j_end = min(n - 1, k)
            if j_start <= j_end:
                js = np.arange(j_start, j_end + 1)
                rows.extend([k] * len(js))
                cols.extend(js.tolist())
                vals.extend((f[k - js]).tolist())
        
        A = csr_matrix((vals, (rows, cols)), shape=(conv_len, n))
        c = -np.ones(n)
        b_ub = np.full(conv_len, M)
        bounds = [(0.0, None)] * n
        
        try:
            res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds,
                          method='highs', options={'presolve': True, 'time_limit': 10})
            if res.success and res.x is not None:
                g = res.x
            else:
                no_improve += 1
                if no_improve > 20:
                    break
                M *= 1.1
                continue
        except Exception:
            no_improve += 1
            if no_improve > 20:
                break
            M *= 1.1
            continue
        
        g = np.maximum(g, 0.0)
        gs = g.sum()
        if gs < 1e-15:
            break
        g /= gs
        
        if np.max(np.abs(g - f)) < 1e-12:
            no_improve += 1
            if no_improve > 30:
                break
            M *= 1.05
            continue
        
        # Line search
        best_alpha = 0.0
        best_val = M
        for alpha in [0.1, 0.2, 0.3, 0.5, 0.7, 1.0]:
            ft = np.maximum((1.0 - alpha) * f + alpha * g, 0.0)
            st = ft.sum()
            if st < 1e-15:
                continue
            ft /= st
            val = fast_convolve(ft).max()
            if val < best_val:
                best_val = val
                best_alpha = alpha
        
        if best_alpha > 1e-10:
            f = np.maximum((1.0 - best_alpha) * f + best_alpha * g, 0.0)
            f /= f.sum()
            conv = fast_convolve(f)
            M = conv.max()
            if M < best_obj - 1e-14:
                best_obj = M
                best_f = f.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1
            M *= 1.05
        
        if no_improve > 40:
            rng = np.random.default_rng(it * 31 + 7)
            f = project_simplex(best_f + rng.standard_normal(n) * 0.003)
            conv = fast_convolve(f)
            M = conv.max()
            no_improve = 0
    
    return best_f, best_obj


def polynomial_init(n, order=4):
    """Create a polynomial-shaped initialization (bell curve)."""
    x = np.linspace(-1, 1, n)
    # Raised cosine / Hamming-like window
    f = 0.5 * (1 + np.cos(np.pi * x))
    f = np.maximum(f, 0)
    s = f.sum()
    if s > 1e-15:
        f /= s
    return f


def gaussian_init(n, sigma_ratio=0.3):
    """Create a Gaussian-shaped initialization."""
    x = np.linspace(-1, 1, n)
    sigma = sigma_ratio * 2  # so that ~80% of the signal is within [-1,1]
    f = np.exp(-x**2 / (2 * sigma**2))
    s = f.sum()
    if s > 1e-15:
        f /= s
    return f


def flat_top_init(n, edge_width=0.2):
    """Flat top with smooth edges."""
    x = np.linspace(0, 1, n)
    f = np.ones(n)
    # Smooth edges
    for i in range(n):
        if x[i] < edge_width:
            t = x[i] / edge_width
            f[i] = 0.5 * (1 + np.cos(np.pi * (1 - t)))
        elif x[i] > 1 - edge_width:
            t = (1 - x[i]) / edge_width
            f[i] = 0.5 * (1 + np.cos(np.pi * (1 - t)))
    f = np.maximum(f, 0)
    s = f.sum()
    if s > 1e-15:
        f /= s
    return f
