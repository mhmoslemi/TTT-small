The subgradient at point a is:

For a single active peak k, the gradient is `2*a[k-j]` (for valid j). This is just a reversed and shifted copy of a! So the gradient computation is O(n) per peak, and if we have K active peaks, it's O(K*n).

This means each iteration of FISTA or mirror descent costs O(n log n) (for the convolution) + O(n) (for the gradient) + O(n log n) (for the projection, if needed).

For FISTA, the projection onto the simplex is O(n log n) (sorting). So each iteration is O(n log n).

    n = len(a_init)
    a = a_init.copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    else:
        a = a / s
    
    y = a.copy()  # Nesterov momentum variable
    t = 1.0
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    
    # Lipschitz constant estimate
    # The Hessian of (a*a)[k] has norm bounded by 2*max(a)
    # So L ~ 2*max(a) for a single peak
    L = 2.0 * a.max() * 2  # conservative
    
    t0 = time.monotonic()
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        
        # Compute subgradient at y
        conv_y = fast_convolve(y)
        k_actual = min(n_peaks, len(conv_y))
        peaks = np.argpartition(conv_y, -k_actual)[-k_actual:]
        pv = conv_y[peaks]
        
        # Softmax weights
        scaled = pv / (1e-6 * max(1, pv.max()))
        scaled -= scaled.max()
        w = np.exp(scaled)
        w /= w.sum()
        
        # Compute weighted subgradient
        g = np.zeros(n)
        for i in range(len(peaks)):
            if w[i] < 1e-12:
                continue
            k = int(peaks[i])
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            for j in range(js, je + 1):
                kg = k - j
                if 0 <= kg < n:
                    if 2 * j == k:
                        g[j] += w[i] * 2.0 * y[j]
                    else:
                        g[j] += w[i] * 2.0 * y[kg]
        
        # Gradient step
        step = 1.0 / L
        z = y - step * g
        
        # Project onto simplex
        z_new = project_simplex(z)
        
        # Update Nesterov momentum
        t_new = (1 + np.sqrt(1 + 4 * t * t)) / 2
        y = z_new + (t / t_new - 1) * (z_new - a)
        a = z_new
        t = t_new
        
        # Update L (backtracking)
        # Check if the Lipschitz condition holds
        # (simplified: just increase L if the objective increases)
        obj_a = fast_convolve(a).max()
        if obj_a < best_obj - 1e-15:

            best_a = a.copy()
        
        # Adaptive L
        if it % 100 == 0:
            L = max(2.0 * a.max() * 2, L * 0.99)  # slowly decrease
            # Or increase if needed
            # for backtracking, we'd need to check the descent condition
    
    return best_a, best_obj

`(a*a)[k] = sum_j a[j] * a[k-j]` (sum over valid j)

`∂(a*a)[k]/∂a[j]`:
- The term a[j]*a[k-j] appears when j is in the sum. Its derivative w.r.t. a[j] is a[k-j].
- If k-j ≠ j (i.e., 2j ≠ k), the term a[k-j]*a[j] also appears in the sum (when the index is k-j). Its derivative w.r.t. a[j] is a[k-j].
- If 2j = k, the term is a[j]^2, and the derivative is 2*a[j].

So:
- If 2j ≠ k and 0 ≤ k-j < n: ∂/∂a[j] = 2*a[k-j]
- If 2j = k: ∂/∂a[j] = 2*a[j] (which equals 2*a[k-j] since k-j=j)
- Otherwise: 0

Now let me think about the LP-based approach for the final polish.

**Cutting-plane LP approach:**

We maintain a set of "cuts" (linear approximations of the objective at various points). The subproblem is:

```
minimize t
subject to: t >= f(a_i) + g_i^T (x - a_i) for all cuts i
            sum(x) = 1
            x >= 0
            ||x - center||^2 <= delta^2  (proximity term, optional)
```

The proximity term makes it a QP. Without it, it's an LP.

For the LP version (no proximity):
```
minimize t
subject to: g_i^T x <= t - f(a_i) + g_i^T a_i for all i
            sum(x) = 1
            x >= 0
```

This LP has n+1 variables and (num_cuts + n + 1) constraints. It can be solved with scipy's linprog or a more efficient solver.

The issue is that without the proximity term, the LP solution might be unbounded or jump far away. In practice, we can add a small L2 regularizer or limit the number of variables.

Actually, for the Frank-Wolfe method, the subproblem IS the LP:
```
minimize g^T x
subject to: x in simplex
```

And the solution is `x = e_{argmin g}`. This is the standard FW step.

For the **away-steps FW (FW+)**, the subproblem is:
```
minimize g^T x
subject to: x in conv({e_j : j in support(a)} ∪ {e_{argmin g}})
```

The solution is a convex combination of at most two points in the support.
