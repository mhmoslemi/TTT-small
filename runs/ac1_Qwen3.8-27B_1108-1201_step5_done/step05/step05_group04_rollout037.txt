Let me also think about the **theoretical lower bound** more carefully.

For a non-negative sequence a with sum(a) = 1 and length n:
- (a*a)[n-1] = sum_j a[j] * a[n-1-j]
- By AM-GM or other inequalities, (a*a)[n-1] >= (sum_j sqrt(a[j]*a[n-1-j]))^2 / n... 

Actually, let's think about it differently. By Cauchy-Schwarz:
sum_j a[j]*a[n-1-j] <= sqrt(sum_j a[j]^2 * sum_j a[n-1-j]^2) = sum_j a[j]^2

So (a*a)[n-1] <= sum_j a[j]^2 = ||a||^2.

And by the constraint sum(a) = 1, we have ||a||^2 >= 1/n (by Cauchy-Schwarz again: (sum a)^2 <= n * sum a^2).

So (a*a)[n-1] >= 1/n (achieved when a is uniform).

But the maximum of (a*a) might be at a different position. For a uniform sequence, the max is at the center and equals 1/n.

For the objective: 2n * max / 1 = 2n * max. So uniform gives 2n * (1/n) = 2.

To beat 2, we need max < 1/n. But can we?

For (a*a)[k] < 1/n for all k, we need the autocorrelation to be "flatter" than the triangular shape of the uniform sequence.

Actually, I realize I made an error. For the uniform sequence a = [1/n, ..., 1/n]:
(a*a)[k] = (number of valid j) / n^2

The number of valid j for (a*a)[k] is:
- For 0 <= k <= n-1: k+1
- For n-1 <= k <= 2n-2: 2n-1-k

So (a*a)[k] = (k+1)/n^2 for 0 <= k <= n-1, and (2n-1-k)/n^2 for n-1 <= k <= 2n-2.

The maximum is at k = n-1: n/n^2 = 1/n.

So the objective for uniform is 2n * (1/n) = 2. ✓

Now, can we do better? We need max_k (a*a)[k] < 1/n.

Consider (a*a)[0] = a[0]^2. For this to be < 1/n, we need a[0] < 1/sqrt(n).
Similarly, (a*a)[2n-2] = a[n-1]^2 < 1/n requires a[n-1] < 1/sqrt(n).

The center value (a*a)[n-1] = sum a[j]*a[n-1-j]. If a is "anti-symmetric" (a[j] is large when a[n-1-j] is small), this could be small. But since a >= 0, the minimum of sum a[j]*a[n-1-j] given sum a = 1 is... 

By the rearrangement inequality, the minimum of sum a[j]*b[j] over permutations of b is achieved when a and b are oppositely sorted. But here b = a reversed, so we're computing sum a[j]*a[n-1-j].

The minimum of sum a[j]*a[n-1-j] subject to a >= 0, sum a = 1 is achieved when a is "concentrated" on one side. For example, a = [1, 0, ..., 0] gives sum a[j]*a[n-1-j] = a[0]*a[n-1] = 0.

But then (a*a)[0] = a[0]^2 = 1, which is much larger than 1/n.

So there's a trade-off: making the center small makes the edges large, and vice versa.

The optimal balance gives the minimum of max_k (a*a)[k].

- sum a[j]*a[n-1-j] <= M

The second constraint is a bilinear constraint. If we set a[0] = sqrt(M), then a[0]*a[n-1] <= M means a[n-1] <= sqrt(M). Similarly for other edge elements.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using fast FFT-based gradients.
Key improvements over previous approach:
1. O(n log n) gradient via cross-correlation FFT (vs O(M*n) loop)
2. Nesterov momentum with backtracking line search

4. Spectral initialization for better starting points
5. Strategic multi-length exploration with interpolation

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def fast_gradient(f, w):
    """Compute gradient of sum_k w[k] * (f*f)[k] w.r.t. f using FFT cross-correlation.
    
    grad[i] = 2 * sum_k w[k] * f[k-i] for valid k,i
    This equals 2 * ifft(FFT(w_pad) * conj(FFT(f_pad)))[:n]
    """
    n = len(f)
    conv_len = 2 * n - 1
    fft_size = 1 << (conv_len - 1).bit_length()
    W = np.fft.rfft(w, fft_size)
    F = np.fft.rfft(f, fft_size)
    # Cross-correlation: ifft(FFT(w) * conj(FFT(f)))
    xcorr = np.fft.irfft(W * np.conj(F), fft_size)
    return 2.0 * xcorr[:n]

def project_simplex(v):
    """Euclidean projection onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def build_lp_matrix(f):
    """Build sparse constraint matrix for the LP."""
    n = len(f)
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        if j_start <= j_end:
            js = np.arange(j_start, j_end + 1)
            rows.extend([k] * len(js))
            cols.extend(js.tolist())
            vals.extend((f[k - js]).tolist())
    return csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))

def solve_lp_direction(f, M, A_cache=None):
    """Solve LP: max sum(g) s.t. A@g <= M, g >= 0."""
    n = len(f)
    if A_cache is None:
        A_cache = build_lp_matrix(f)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c, A_ub=A_cache, b_ub=b_ub, bounds=bounds,
                      method='highs', options={'presolve': True, 'time_limit': 20})
        if res.success and res.x is not None:
            return np.maximum(res.x, 0.0)
    except Exception:
        pass
    return None

def lse_fast(f0, time_limit, beta_start=30.0, beta_end=10000.0, lr_init=None, momentum_init=0.9):
    """Fast LSE gradient descent with FFT-based gradient and Nesterov momentum."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    
    if lr_init is None:
        lr_init = 3.0 / n
    
    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()
    
    beta = beta_start
    lr = lr_init
    momentum = momentum_init
    v = np.zeros(n)
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        conv = fast_convolve(f)
        bc = beta * conv
        bc_max = bc.max()
        exp_bc = np.exp(bc - bc_max)
        w = exp_bc / exp_bc.sum()
        
        grad = fast_gradient(f, w)
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-15:
            no_improve += 100
            break
        grad /= grad_norm
        
        # Nesterov momentum
        f_nest = f + momentum * v
        v = project_simplex(f_nest) - f
        # Actually, let's use standard momentum with projection
        v = momentum * v - lr * grad
        f_new = project_simplex(f + v)
        
        # Backtracking line search
        obj_new = fast_convolve(f_new).max()
        alpha = 1.0
        for _ in range(10):
            if obj_new < best_obj or obj_new < conv.max() * (1 - 1e-4 * alpha):
                break
            alpha *= 0.5
            v_scaled = momentum * (v / alpha if alpha > 0 else v) - lr * alpha * grad
            # Actually simpler: just reduce the step
            f_new = project_simplex(f - lr * alpha * grad / grad_norm)
            obj_new = fast_convolve(f_new).max()
        
        if obj_new < best_obj - 1e-14:
            best_obj = obj_new
            best_f = f_new.copy()
            f = f_new
            no_improve = 0
            lr = min(lr * 1.002, 8.0 / n)
        else:
            no_improve += 1
            if no_improve >= 10:
                lr *= 0.92
                momentum = max(0.80, momentum - 0.005)
            if no_improve > 80:
                f = best_f.copy()
                v = np.zeros(n)
                lr = max(2.0 / n, 0.0005)
                beta = min(beta * 1.5, beta_end)
                momentum = 0.88
                no_improve = 0
        
        if beta < beta_end:
            beta *= 1.003
    
    return best_f, best_obj

def directed_fast(f0, time_limit, n_peaks=20, lr_init=None, momentum_init=0.92):
    """Directed peak reduction with FFT gradient."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    conv_len = 2 * n - 1
    
    if lr_init is None:
        lr_init = 0.005
    
    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    cur_lr = lr_init
    v = np.zeros(n)
    cur_mom = momentum_init
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        conv = fast_convolve(f)
        
        # Select top peaks
        k_top = min(n_peaks, conv_len)
        peaks = np.argpartition(conv, -k_top)[-k_top:]
        pv = conv[peaks]
        
        # Exponential weighting
        scaled = pv - pv.min()
        w = np.exp(scaled - scaled.max())
        w_sum = w.sum()
        if w_sum < 1e-15:
            w = np.zeros(k_top)
            w[np.argmax(pv)] = 1.0
        else:
            w /= w_sum
        
        w_full = np.zeros(conv_len)
        w_full[peaks] = w
        
        grad = fast_gradient(f, w_full)
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-15:
            no_improve += 100
            break
        grad /= grad_norm
        
        v = cur_mom * v - cur_lr * grad
        f_new = project_simplex(f + v)
        obj_new = fast_convolve(f_new).max()
        
        if obj_new < best_obj - 1e-14:
            best_obj = obj_new
            best_f = f_new.copy()
            f = f_new
            no_improve = 0
        else:
            no_improve += 1
            if no_improve % 30 == 0:
                cur_lr *= 0.95
            if no_improve > 200:
                rng = np.random.default_rng((it * 7919 + 13) % 999983)
                f = project_simplex(best_f + rng.standard_normal(n) * 0.001)
                v = np.zeros(n)
                cur_lr = max(lr_init * 0.3, 0.0001)
                no_improve = 0
    
    return best_f, best_obj

def fw_lp(f0, time_limit, verbose=False):
    """Frank-Wolfe with LP oracle."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    conv = fast_convolve(f)
    M = conv.max()
    best_obj = M
    best_f = f.copy()
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    m_exp = 1.0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        A_cache = build_lp_matrix(f)
        g = solve_lp_direction(f, M * m_exp, A_cache)
        if g is None:
            m_exp *= 1.15
            if m_exp > 10.0:
                m_exp = 1.0
            continue
        
        g = np.maximum(g, 0.0)
        gs = g.sum()
        if gs < 1e-15:
            break
        g = g / gs
        
        if np.max(np.abs(g - f)) < 1e-12:
            no_improve += 1
            if no_improve > 30:
                break
            m_exp = min(m_exp * 1.05, 5.0)
            continue
        
        # Line search
        best_alpha = 0.0
        best_val = M
        for alpha in [0.05, 0.1, 0.15, 0.2, 0.3, 0.4, 0.5, 0.7, 1.0]:
            ft = np.maximum((1.0 - alpha) * f + alpha * g, 0.0)
            st = ft.sum()
            if st < 1e-15:
                continue
            ft /= st
            val = fast_convolve(ft).max()
            if val < best_val:
                best_val = val
                best_alpha = alpha
        
        if best_alpha > 1e-10:
            f = np.maximum((1.0 - best_alpha) * f + best_alpha * g, 0.0)
            f /= f.sum()
            conv = fast_convolve(f)
            M = conv.max()
            m_exp = 1.0
            if M < best_obj - 1e-14:
                best_obj = M
                best_f = f.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1
            m_exp = min(m_exp * 1.08, 8.0)
        
        if no_improve > 40:
            rng = np.random.default_rng(it * 31 + 7)
            scale = 0.002 + 0.003 * min(1.0, (no_improve - 40) / 50.0)
            f = project_simplex(best_f + rng.standard_normal(n) * scale)
            conv = fast_convolve(f)
            M = conv.max()
            m_exp = 1.0
            no_improve = 0
    
    return best_f, best_obj

def interpolate_to_length(f, new_n):
    """Interpolate a normalized sequence to a new length."""
    x_old = np.linspace(0, 1, len(f))
    x_new = np.linspace(0, 1, new_n)
    f_new = np.interp(x_new, x_old, f)
    f_new = np.maximum(f_new, 0)
    s = f_new.sum()
    if s > 1e-15:
        f_new /= s
    else:
        f_new = np.ones(new_n) / new_n
    return f_new

def spectral_init(n):
    """Initialize using a flat-spectrum approach.
    Generate a random phase, take IFFT, project to non-negative simplex.
    """
    rng = np.random.default_rng(12345)
    fft_size = 1 << (2 * n - 2).bit_length()
    # Random flat power spectrum
    phases = rng.uniform(0, 2 * np.pi, fft_size // 2 + 1)
    mag = np.ones(fft_size // 2 + 1)
    spectrum = mag * np.exp(1j * phases)
    # Make it conjugate symmetric for real signal
    full_spectrum = np.zeros(fft_size, dtype=complex)
    full_spectrum[:fft_size // 2 + 1] = spectrum
    for k in range(1, fft_size // 2):
        full_spectrum[fft_size - k] = np.conj(full_spectrum[k])
    signal = np.fft.ifft(full_spectrum).real
    signal = signal[:n]
    signal = np.maximum(signal, 0.0)
    s = signal.sum()
    if s > 1e-15:
        signal /= s
    else:
        signal = np.ones(n) / n
    return signal

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using FFT-accelerated gradients.
Key innovations:
1. O(n log n) gradient via FFT cross-correlation (vs O(M*n) loop in previous)
2. FISTA-style accelerated gradient with adaptive step
3. Adaptive multi-scale LSE with peak-aware weighting
4. Directed peak reduction with exponential weighting schedules
5. Strategic multi-length exploration with spectral initialization

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def fast_gradient(f, w):
    """Compute gradient of sum_k w[k] * (f*f)[k] w.r.t. f using FFT.
    
    grad[i] = 2 * sum_j w[i+j] * f[j]  (cross-correlation)
    Computed as 2 * ifft(FFT(w_pad) * conj(FFT(f_pad)))[:n]
    """
    n = len(f)
    conv_len = 2 * n - 1
    fft_size = 1 << (conv_len - 1).bit_length()
    W = np.fft.rfft(w, fft_size)
    F = np.fft.rfft(f, fft_size)
    xcorr = np.fft.irfft(W * np.conj(F), fft_size)
    return 2.0 * xcorr[:n]


def project_simplex(v):
    """Euclidean projection onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def build_lp_matrix(f):
    """Build sparse constraint matrix for the LP. Shape: (2n-1, n)."""
    n = len(f)
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        if j_start <= j_end:
            js = np.arange(j_start, j_end + 1)
            rows.extend([k] * len(js))
            cols.extend(js.tolist())
            vals.extend((f[k - js]).tolist())
    return csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))


def solve_lp_direction(f, M, A_cache=None):
    """Solve LP: max sum(g) s.t. A@g <= M, g >= 0."""
    n = len(f)
    if A_cache is None:
        A_cache = build_lp_matrix(f)
    c = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c, A_ub=A_cache, b_ub=b_ub, bounds=bounds,
                      method='highs', options={'presolve': True, 'time_limit': 20})
        if res.success and res.x is not None:
            return np.maximum(res.x, 0.0)
    except Exception:
        pass
    return None


def lse_accelerated(f0, time_limit, beta_start=30.0, beta_end=10000.0,
                    lr_init=None, momentum_init=0.9):
    """LSE gradient descent with FFT gradient and FISTA-style acceleration."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)

    if lr_init is None:
        lr_init = 4.0 / n

    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()

    beta = beta_start
    lr = lr_init
    momentum = momentum_init
    v = np.zeros(n)
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    f_prev = f.copy()
    t_fista = 1.0

    while time.monotonic() - t0 < time_limit:
        it += 1
        conv = fast_convolve(f)
        bc = beta * conv
        bc_max = bc.max()
        exp_bc = np.exp(bc - bc_max)
        w = exp_bc / exp_bc.sum()

        grad = fast_gradient(f, w)
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-15:
            no_improve += 100
            break
        grad /= grad_norm

        # FISTA-style: compute y, then gradient at y
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t_fista * t_fista)) / 2.0
        y = f + (t_fista - 1.0) / t_new * (f - f_prev)

        if y_sum < 1e-15:

            if no_improve >= 10:
                lr *= 0.93
                momentum = max(0.70, momentum - 0.005)
            if no_improve > 70:
                f = best_f.copy()
                f_prev = f.copy()
                v = np.zeros(n)
                t_fista = 1.0
                lr = max(3.0 / n, 0.001)
                beta = min(beta * 2.0, 50000.0)
                momentum = 0.88
                no_improve = 0

    return best_f, best_obj


def fw_lp(f0, time_limit, verbose=False):
    """Frank-Wolfe with LP oracle."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    conv = fast_convolve(f)
    M = conv.max()
    best_obj = M
    best_f = f.copy()
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    m_exp = 1.0

    while time.monotonic() - t0 < time_limit:
        it += 1
        A_cache = build_lp_matrix(f)
        g = solve_lp_direction(f, M * m_exp, A_cache)
        if g is None:
            m_exp *= 1.15
            if m_exp > 10.0:
                m_exp = 1.0
            continue

        g = np.maximum(g, 0.0)
        gs = g.sum()
        if gs < 1e-15:
            break
        g = g / gs

        if np.max(np.abs(g - f)) < 1e-12:
            no_improve += 1
            if no_improve > 30:
                break
            m_exp = min(m_exp * 1.05, 5.0)
            continue

        best_alpha = 0.0
        best_val = M
        for alpha in [0.05, 0.1, 0.15, 0.2, 0.3, 0.4, 0.5, 0.7, 1.0]:
            ft = np.maximum((1.0 - alpha) * f + alpha * g, 0.0)
            st = ft.sum()
            if st < 1e-15:
                continue
            ft /= st
            val = fast_convolve(ft).max()
            if val < best_val:
                best_val = val
                best_alpha = alpha

        if best_alpha > 1e-10:
            f = np.maximum((1.0 - best_alpha) * f + best_alpha * g, 0.0)
            f /= f.sum()
            conv = fast_convolve(f)
            M = conv.max()
            m_exp = 1.0
            if M < best_obj - 1e-14:
                best_obj = M
                best_f = f.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1
            m_exp = min(m_exp * 1.08, 8.0)

        if no_improve > 40:
            rng = np.random.default_rng(it * 31 + 7)
            scale = 0.002 + 0.003 * min(1.0, (no_improve - 40) / 50.0)
            f = project_simplex(best_f + rng.standard_normal(n) * scale)
            conv = fast_convolve(f)
            M = conv.max()
            m_exp = 1.0
            no_improve = 0

    return best_f, best_obj


def try_sequence(a, best_tracker):
    """Evaluate a sequence and update best tracker."""
    a = np.maximum(a, 0.0)
    try:
        score = float(evaluate_sequence(a.tolist()))
    except Exception:
        return float('inf')
    if np.isfinite(score) and score < best_tracker[0]:
        best_tracker[0] = score
        best_tracker[1] = a.copy()
        print(f"  NEW BEST: {score:.8f} (n={len(a)})")
    return score


def interpolate_to_length(f, new_n):
    """Interpolate a normalized sequence to a new length."""
    x_old = np.linspace(0, 1, len(f))
    x_new = np.linspace(0, 1, new_n)
    f_new = np.interp(x_new, x_old, f)
    f_new = np.maximum(f_new, 0)
    s = f_new.sum()
    if s > 1e-15:
        f_new /= s
    else:
        f_new = np.ones(new_n) / new_n
    return f_new


def spectral_init(n, seed=12345):
    """Initialize using a flat-spectrum approach with random phases."""
    rng = np.random.default_rng(seed)
    fft_size = 1 << (2 * n - 2).bit_length()
    phases = rng.uniform(0, 2 * np.pi, fft_size // 2 + 1)
    mag = np.ones(fft_size // 2 + 1)
    # Slightly tilt the magnitude to help with non-negativity
    tilt = np.linspace(1.0, 0.8, fft_size // 2 + 1)
    spectrum = (mag * tilt) * np.exp(1j * phases)
    full_spectrum = np.zeros(fft_size, dtype=complex)
    full_spectrum[:fft_size // 2 + 1] = spectrum
    for k in range(1, fft_size // 2):
        full_spectrum[fft_size - k] = np.conj(full_spectrum[k])
    signal = np.fft.ifft(full_spectrum).real
    signal = signal[:n]
    signal = np.maximum(signal, 0.0)
    s = signal.sum()
    if s > 1e-15:
        signal /= s
    else:
        signal = np.ones(n) / n
    return signal


def power_sum_optimize(f0, time_limit, p_start=20, p_end=500, lr_init=None):
    """Optimize the p-th power sum as a surrogate for the max.
    min (sum_k (a*a)[k]^p)^(1/p) with increasing p.
    """
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    if lr_init is None:
        lr_init = 3.0 / n

    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()

    p = p_start
    lr = lr_init
    momentum = 0.90
    v = np.zeros(n)
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    f_prev = f.copy()
    t_fista = 1.0

    while time.monotonic() - t0 < time_limit:
        it += 1
        conv = fast_convolve(f)
        # Power-sum weights: w[k] = p * (conv[k])^(p-1) / sum_k (conv[k])^p
        conv_pos = np.maximum(conv, 1e-30)
        conv_p = conv_pos ** (p - 1)
        w_sum = conv_p.sum()
        if w_sum < 1e-30:
            w = np.ones(len(conv)) / len(conv)
        else:
            w = conv_p / w_sum

        grad = fast_gradient(f, w)
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-15:
            no_improve += 100
            break
        grad /= grad_norm

        # FISTA
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t_fista * t_fista)) / 2.0
        y = f + (t_fista - 1.0) / t_new * (f - f_prev)
        y = np.maximum(y, 0.0)
        y_s = y.sum()
        if y_s < 1e-15:
            y = f.copy()
        else:
            y = y / y_s

        grad_y = fast_gradient(y, w)
        gy_n = np.linalg.norm(grad_y)
        if gy_n > 1e-15:
            grad_y /= gy_n
            v = momentum * v - lr * grad_y
        else:
            v = momentum * v - lr * grad

        f_prev = f.copy()
        f_new = project_simplex(y + v)
        t_fista = t_new

        obj_new = fast_convolve(f_new).max()
        if obj_new < best_obj - 1e-14:
            best_obj = obj_new
            best_f = f_new.copy()
            f = f_new
            no_improve = 0
            lr = min(lr * 1.001, 10.0 / n)
        else:
            no_improve += 1
            if no_improve >= 10:
                lr *= 0.93
                momentum = max(0.75, momentum - 0.004)
            if no_improve > 60:
                f = best_f.copy()
                f_prev = f.copy()
                v = np.zeros(n)
                t_fista = 1.0
                lr = max(2.0 / n, 0.001)
                momentum = 0.88
                no_improve = 0

        p = min(p * 1.005, p_end)

    return best_f, best_obj


def propose_candidate(seed=42, budget_s=1800):
    """
    Multi-phase optimization with FFT-accelerated gradients:
    Phase 1: Multi-length exploration with LSE + directed
    Phase 2: Power-sum optimization (smooth surrogate)
    Phase 3: Intensive LSE with adaptive beta + FISTA
    Phase 4: Alternating FW/directed/power-sum
    Phase 5: Final micro-polish with extreme settings
    Phase 6: Length perturbation
    """
    deadline = time.monotonic() + max(1.0, float(budget_s) - 20.0)
    best_tracker = [float('inf'), None]

    # Load parent
    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            parent = p / p.sum()
            print(f"Parent: n={len(parent)}, score={evaluate_sequence(parent.tolist()):.8f}")
            try_sequence(parent, best_tracker)
    except Exception:
        pass

    if parent is None:
        parent = np.ones(640) / 640
        try_sequence(parent, best_tracker)

    n_parent = len(parent)

    # === Phase 1: Multi-length exploration ===
    print("\n=== Phase 1: Multi-length exploration ===")
    t1_end = deadline - 1000
    n_candidates = sorted(set([n_parent, 576, 640, 768, 896, 1024]), reverse=True)
    n_candidates = [nc for nc in n_candidates if 256 <= nc <= 1100]

    for nc in n_candidates[:4]:
        t_remaining = t1_end - time.monotonic()
        if t_remaining < 30:
            break
        t_alloc = min(100, t_remaining * 0.3)
        if t_alloc < 20:
            break

        f_init = parent.copy() if nc == n_parent else interpolate_to_length(parent, nc)

        print(f"  LSE n={nc}, t={t_alloc:.0f}s")
        f_opt, _ = lse_accelerated(f_init, time_limit=t_alloc,
                                    beta_start=20.0, beta_end=3000.0)
        try_sequence(f_opt, best_tracker)

        # Quick directed follow-up
        t_dir = min(50, t1_end - time.monotonic() - 20)
        if t_dir > 15:
            f_opt2, _ = directed_fast(f_opt, time_limit=t_dir, n_peaks=20)
            try_sequence(f_opt2, best_tracker)

    # Spectral init at a good length
    if time.monotonic() < t1_end - 50:
        n_spec = max(n_parent, 768)
        f_spec = spectral_init(n_spec, seed=seed)
        t_alloc = min(70, t1_end - time.monotonic() - 25)
        if t_alloc > 20:
            print(f"  Spectral+LSE n={n_spec}, t={t_alloc:.0f}s")
            f_opt, _ = lse_accelerated(f_spec, time_limit=t_alloc,
                                        beta_start=20.0, beta_end=2000.0)
            try_sequence(f_opt, best_tracker)

    # === Phase 2: Power-sum optimization ===
    print(f"\n=== Phase 2: Power-sum optimization ===")
    t2_end = deadline - 600
    current = best_tracker[1].copy() if best_tracker[1] is not None else parent
    n_cur = len(current)

    t_alloc = min(200, t2_end - time.monotonic())
    if t_alloc > 30:
        print(f"  PowerSum n={n_cur}, t={t_alloc:.0f}s, p: 10->300")
        f_opt, _ = power_sum_optimize(current, time_limit=t_alloc,
                                       p_start=10, p_end=300)
        try_sequence(f_opt, best_tracker)

    current = best_tracker[1].copy() if best_tracker[1] is not None else current

    # === Phase 3: Intensive LSE with adaptive beta ===
    print(f"\n=== Phase 3: Intensive adaptive LSE ===")
    t3_end = deadline - 400
    t_alloc = min(200, t3_end - time.monotonic())
    if t_alloc > 30:
        print(f"  Adaptive LSE n={len(current)}, t={t_alloc:.0f}s")
        f_opt, _ = lse_scheduler(current, time_limit=t_alloc)
        try_sequence(f_opt, best_tracker)

    current = best_tracker[1].copy() if best_tracker[1] is not None else current
    t_alloc = min(120, t3_end - time.monotonic())
    if t_alloc > 20:
        print(f"  Directed (n_peaks=30) n={len(current)}, t={t_alloc:.0f}s")
        f_opt, _ = directed_fast(current, time_limit=t_alloc, n_peaks=30,
                                 lr_init=0.004, momentum_init=0.93)
        try_sequence(f_opt, best_tracker)

    # === Phase 4: Alternating refinement ===
    print(f"\n=== Phase 4: Alternating refinement ===")
    t4_end = deadline - 250
    cycles = 0
    while time.monotonic() < t4_end and cycles < 12:
        cycles += 1
        current = best_tracker[1].copy() if best_tracker[1] is not None else parent
        n_cur = len(current)
        remaining = t4_end - time.monotonic()
        if remaining < 50:
            break

        phase = cycles % 4
        if phase == 0:
            t_alloc = min(80, remaining * 0.35)
            if t_alloc > 15:
                print(f"  C{cycles}: FW n={n_cur}, t={t_alloc:.0f}s")
                f_opt, _ = fw_lp(current, time_limit=t_alloc)
                try_sequence(f_opt, best_tracker)
        elif phase == 1:
            t_alloc = min(80, remaining * 0.35)
            if t_alloc > 15:
                print(f"  C{cycles}: LSE high-beta n={n_cur}, t={t_alloc:.0f}s")
                f_opt, _ = lse_accelerated(current, time_limit=t_alloc,
                                            beta_start=200.0, beta_end=30000.0)
                try_sequence(f_opt, best_tracker)
        elif phase == 2:
            t_alloc = min(70, remaining * 0.3)
            if t_alloc > 15:
                print(f"  C{cycles}: Directed (n_peaks=10) n={n_cur}, t={t_alloc:.0f}s")
                f_opt, _ = directed_fast(current, time_limit=t_alloc, n_peaks=10,
                                         lr_init=0.003, momentum_init=0.94)
                try_sequence(f_opt, best_tracker)
        else:
            t_alloc = min(70, remaining * 0.3)
            if t_alloc > 15:
                print(f"  C{cycles}: PowerSum high-p n={n_cur}, t={t_alloc:.0f}s")
                f_opt, _ = power_sum_optimize(current, time_limit=t_alloc,
                                               p_start=50, p_end=1000)
                try_sequence(f_opt, best_tracker)

    # === Phase 5: Final micro-polish ===
    print(f"\n=== Phase 5: Final micro-polish ===")
    current = best_tracker[1].copy() if best_tracker[1] is not None else parent
    n_cur = len(current)

    # Extreme LSE (very high beta = nearly exact max targeting)
    t_alloc = min(120, deadline - time.monotonic() - 40)
    if t_alloc > 15:
        print(f"  Extreme LSE n={n_cur}, t={t_alloc:.0f}s, beta_end=50000")
        f_opt, _ = lse_accelerated(current, time_limit=t_alloc,
                                    beta_start=500.0, beta_end=50000.0,
                                    lr_init=2.0 / n_cur)
        try_sequence(f_opt, best_tracker)

    # Directed with minimal peaks
    current = best_tracker[1].copy() if best_tracker[1] is not None else current
    t_alloc = min(80, deadline - time.monotonic() - 20)
    if t_alloc > 12:
        print(f"  Directed (n_peaks=3) t={t_alloc:.0f}s")
        f_opt, _ = directed_fast(current, time_limit=t_alloc, n_peaks=3,
                                 lr_init=0.001, momentum_init=0.96,
                                 weight_mode='exp')
        try_sequence(f_opt, best_tracker)

    # One more power-sum pass with very high p
    current = best_tracker[1].copy() if best_tracker[1] is not None else current
    t_alloc = min(60, deadline - time.monotonic() - 10)
    if t_alloc > 12:
        print(f"  PowerSum p=100->2000 t={t_alloc:.0f}s")
        f_opt, _ = power_sum_optimize(current, time_limit=t_alloc,
                                       p_start=100, p_end=2000,
                                       lr_init=2.0 / len(current))
        try_sequence(f_opt, best_tracker)

    # === Phase 6: Length perturbation ===
    print(f"\n=== Phase 6: Length perturbation ===")
    if best_tracker[1] is not None:
        n_best = len(best_tracker[1])
        for off in [32, -32, 64, -64, 96, -96]:
            n_try = n_best + off
            if n_try < 256 or n_try > 1200:
                continue
            t_remaining = deadline - time.monotonic() - 8
            if t_remaining < 20:
                break
            t_alloc = min(35, t_remaining * 0.4)
            if t_alloc < 10:
                break
            f_init = interpolate_to_length(best_tracker[1], n_try)
            print(f"  n={n_try}, t={t_alloc:.0f}s")
            f_opt, _ = lse_accelerated(f_init, time_limit=t_alloc,
                                        beta_start=50.0, beta_end=5000.0)
            try_sequence(f_opt, best_tracker)

    # === Final ===
    if best_tracker[1] is not None:
        final_seq = best_tracker[1]
        final_score = float(evaluate_sequence(final_seq.tolist()))
        if np.isfinite(final_score):
            print(f"\nFINAL: score={final_score:.10f}, n={len(final_seq)}")
            return [float(x) for x in final_seq]

    print("WARNING: Using uniform fallback")
    fallback = np.ones(512) / 512
    return [float(x) for x in fallback]
