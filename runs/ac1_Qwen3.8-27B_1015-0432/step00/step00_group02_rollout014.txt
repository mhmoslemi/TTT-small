Actually, for the LINEAR autocorrelation, "flat" means (a*a)[k] is constant for all k. The generating function: if A(z) = Σ a_i z^i, then (a*a)[k] is the coefficient of z^k in A(z)A(z^{-1}). For this to be constant, A(z)A(z^{-1}) = C (constant). This means |A(e^{iω})|² = C for all ω, i.e., A is an all-pass filter. For nonnegative a, the only all-pass is a single impulse. So a flat linear autocorrelation is impossible for nonnegative a with n>1.

So the optimum is NOT flat. The best we can do is to make the autocorrelation as flat as possible given the nonnegativity constraint.
