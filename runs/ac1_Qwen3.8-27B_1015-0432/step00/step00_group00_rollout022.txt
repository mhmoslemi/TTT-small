**Approach 8: Iterative refinement using FFT**

Instead of solving an LP at each step, use a simpler iterative method:

1. Start with a = uniform (or the parent sequence).
2. Compute c = convolve(a, a) using FFT.
3. Find k* = argmax c.
4. The "pressure" is at k*. To reduce c[k*], we want to reduce the contribution of a[j] * a[k*-j] for all j.
5. A simple heuristic: reduce a at positions where it contributes most to c[k*].
6. Redistribute the reduced mass to positions where the convolution is low.

This is similar to the "power iteration" for finding the dominant eigenvalue, but for the convolution operator.

More concretely:
- c[k*] = sum_j a[j] * a[k*-j]
- The "gradient" of c[k*] with respect to a is: g[j] = a[k*-j] (the flipped a, shifted)
- To reduce c[k*], decrease a in the direction of g.
- But we need to maintain sum(a) = 1 and a >= 0.

Algorithm:
1. a = initial (e.g., uniform).
2. Repeat:
   a. c = ifft(fft(a, 2n)^2).real
   b. k* = argmax(c)
   c. g = 2 * np.roll(a[::-1], k*)  # gradient of c[k*] (approximately)
      # More precisely: g[j] = 2 * a[k*-j] if 0 <= k*-j < n, else 0
   d. a = a - eta * g
   e. Project a onto simplex {a >= 0, sum(a) = 1}
   f. If time up, stop.

```python
def proj_simplex(v, s=1.0):
    n = len(v)
    if v.sum() <= s and (v >= 0).all():
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - s))[0][-1]
    theta = (cssv[rho] - s) / (rho + 1.0)
    return np.maximum(v - theta, 0)
```

The key insight is that the LP finds the "best" direction b to move in, subject to the constraint that the convolution with f doesn't exceed M. This is like finding the most "spread out" sequence b that's compatible with f.

But there's a subtlety: the LP solution b might have many zeros (b_basic solution). The blending f ← (1-t)f + t*b might not improve much if b is very sparse.

Also, I need to be careful with the rescaling. The SOTA says:
- Normalize f so that sum(f) = sqrt(2n). (Or any fixed normalization.)
- M = ||f*f||_inf
- Solve LP for b
- Rescale b: b = sqrt(2n)/sum(b) * b
- Blend: f ← (1-t)f + t*b

The objective is 2n * ||f*f||_inf / (sum(f))^2. With the normalization sum(f) = sqrt(2n), the objective is ||f*f||_inf / n.

Wait, let me recompute. If sum(f) = S, then objective = 2n * max(conv(f,f)) / S^2.
If S = sqrt(2n): objective = 2n * max(conv(f,f)) / (2n) = max(conv(f,f)).

So with S = sqrt(2n), the objective equals max(conv(f,f)). Minimizing the objective is equivalent to minimizing max(conv(f,f)).

For the LP: max sum(b) s.t. conv(f, b)[k] <= M for all k, b >= 0.
Here M = max(conv(f, f)).

The LP finds the largest b (in sum) that's "compatible" with f in the sense that conv(f, b) <= M.

After rescaling b to have sum = S, we blend. The idea is that b is "anti-concentrated" relative to f, so blending spreads out the convolution.

```python
import numpy as np
import scipy.sparse as sp
from scipy.optimize import linprog
import time

def compute_conv(f):
    """Compute full linear convolution using FFT."""
    n = len(f)
    N = 2 * n  # padding for FFT
    F = np.fft.rfft(f, N)
    C = np.fft.irfft(F * F, N)
    return C[:2*n-1]

def simplex_project(v):
    """Project v onto the simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1.0))[0]
    if len(rho) == 0:
        return np.full(n, 1.0/n)
    rho = rho[-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

        M = convf.max()
        if M < 1e-15:

        # A[k, m] = f[k-m] if 0 <= k-m < n
```
