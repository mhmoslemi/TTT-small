Let me verify: for m=0, grad[0] = 2*conv(a, w[::-1])[2n-2]. And 2n-2 is the last valid index in conv(a, w[::-1]) (which has indices 0 to 3n-3).
conv(a, w[::-1])[2n-2] = sum_j a[j]*w[::-1][2n-2-j] = sum_j a[j]*w[j] (since w[::-1][2n-2-j] = w[2n-2-(2n-2-j)] = w[j]).
So grad[0] = 2*sum_j a[j]*w[j]. And from the definition: grad[0] = 2*sum_j a[j]*w[j+0] = 2*sum_j a[j]*w[j]. ✓

For m=n-1: grad[n-1] = 2*conv(a, w[::-1])[n-1]. 
conv(a, w[::-1])[n-1] = sum_j a[j]*w[::-1][n-1-j] = sum_j a[j]*w[2n-2-(n-1-j)] = sum_j a[j]*w[n-1+j].
And from definition: grad[n-1] = 2*sum_j a[j]*w[j+n-1]. ✓

So the formula is:
```
conv_result = np.convolve(a, w[::-1])  # length 3n-2
grad = 2.0 * conv_result[n-1 : 2*n-1][::-1]
```

This is a single O(n log n) convolution! 

So the algorithm step becomes:
1. Compute c = conv(a, a) (length 2n-1)
2. Compute w = softmax(c / s) where s is a temperature parameter
3. Compute grad = 2 * conv(a, w[::-1])[n-1:2n-1][::-1]
4. Update: a_new = a - eta * grad (or a_new = a * (1 - eta * grad/max_grad))
5. Clip, normalize, evaluate

The temperature s controls how "peaky" the softmax is. Small s → focus on the max lag. Large s → uniform weighting.

This is O(n log n) per step (for the two convolutions). For n=5582, each convolution takes about 1-5 ms. So each step is about 10 ms. In 1100 seconds, we can do about 100,000 steps.
