**Structured initialization:**
For length n, use a "binomial" or "Pascal" sequence: a_k = C(n-1, k) / 2^(n-1).
This gives a "triangular" autocorrelation (actually, the autocorrelation of a binomial sequence is related to a higher-order binomial).

Actually, the convolution of two binomial(n-1) sequences gives binomial(2n-2) scaled. The peak of binomial(2n-2) is at the center: C(2n-2, n-1) / 4^(n-1) ≈ 1/sqrt(π(n-1)/2).

Score for binomial init: 2n * max_b / S^2 where S = 1 (normalized).
max_b = C(2n-2, n-1) / 4^(n-1) ≈ 1/sqrt(πn/2).
Score ≈ 2n / sqrt(πn/2) = 2*sqrt(2n/π) ≈ 1.13*sqrt(n).

For n=6121: score ≈ 1.13 * 78.2 ≈ 88. Terrible! Much worse than uniform.

What about a "box" sequence: a_k = 1/m for k in [0, m-1], 0 otherwise, with m < n.
S = 1.
conv: b_k = (k+1)/m^2 for 0<=k<m, (2m-1-k)/m^2 for m<=k<=2m-2.
max_b = m/m^2 = 1/m.
Score = 2n/m.

To minimize: maximize m. But m <= n, so min score = 2n/n = 2 (same as uniform).
For m = n/2: score = 2n/(n/2) = 4. Worse.

So the box sequence is worse than uniform unless it's full-length.

What about a "ramp" sequence: a_k = (k+1)/S for k=0,...,n-1 (increasing).
S = n(n+1)/2.
a_k = 2(k+1)/(n(n+1)).

conv: b_k = sum_{i=max(0,k-n+1)}^{min(k,n-1)} a_i * a_{k-i}
This is a quadratic in k. The peak is at k = n-1:
b_{n-1} = sum_{i=0}^{n-1} a_i * a_{n-1-i} = sum 2(i+1)/(n(n+1)) * 2(n-i)/(n(n+1))
= 4/(n^2(n+1)^2) * sum (i+1)(n-i) for i=0 to n-1
= 4/(n^2(n+1)^2) * n * sum (i+1)(n-i) / n

Let me compute sum_{i=0}^{n-1} (i+1)(n-i) = sum (n(i+1) - i(i+1))
= n * sum(i+1) - sum(i^2 + i)
= n * n(n+1)/2 - (n(n-1)(2n-1)/6 + n(n-1)/2)
= n^2(n+1)/2 - n(n-1)(2n-1)/6 - n(n-1)/2
= n[n(n+1)/2 - (n-1)(2n-1)/6 - (n-1)/2]
= n[(3n(n+1) - (n-1)(2n-1) - 3(n-1)) / 6]
= n[(3n^2+3n - (2n^2-3n+1) - 3n+3) / 6]
= n[(3n^2+3n - 2n^2+3n-1 - 3n+3) / 6]
= n[(n^2+3n+2) / 6]
= n(n+1)(n+2)/6

So b_{n-1} = 4/(n^2(n+1)^2) * n(n+1)(n+2)/6 = 4(n+2)/(6n(n+1)) = 2(n+2)/(3n(n+1)).

For large n: b_{n-1} ≈ 2/(3n).
Score = 2n * 2/(3n) / 1 = 4/3 ≈ 1.33!
