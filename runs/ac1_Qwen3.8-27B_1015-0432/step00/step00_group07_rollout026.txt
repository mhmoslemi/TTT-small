For the gradient step, I'll use a more sophisticated approach:
- Compute the top K peaks of the convolution
- For each peak at lag k, compute the "coupling vector" v_k where v_k[j] = a[k-j]
- The goal is to make a orthogonal to all v_k (in a weighted sense)
- Use gradient descent: a ← a - lr * sum_k w_k * v_k
- Project onto simplex

The learning rate should be adaptive:

- Increase on improvement, decrease on failure

def fft_conv(a):
    n = len(a)
    size = 2 * n
    A = np.fft.rfft(a, size)
    return np.fft.irfft(A * A, size)[:2*n-1]

    n = len(a)
    js = max(0, k - n + 1)
    je = min(n - 1, k)
    g = np.zeros(n)
    if js <= je:
        idx = k - np.arange(js, je + 1)
        g[js:je+1] = 2.0 * a[idx]
    return g

    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-30:

    return a / s
