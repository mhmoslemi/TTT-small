The constraint is conv(a, b)_k <= M for all k. We want to find b >= 0, sum(b) = 1, that satisfies this and is as "spread out" as possible (maximizes sum of b_j... well, sum is already 1, so we want it to be as uniform as possible subject to the constraint).

The iterative method: b_new_j = b_j * (1 / max_k' {conv(a, b)_k' / M}) ... hmm, this isn't quite right.

Actually, the standard approach for "projection" onto {b: Ab <= M, b >= 0, sum b = 1} is:
- Start with b >= 0, sum b = 1.
- While not converged:
  - c = A @ b
  - If c <= M (all constraints satisfied), stop.
  - Find the most violated constraint k*.
  - Adjust b to reduce (Ab)_{k*}.
  
A simple adjustment: b_new = b / (1 + lambda * (Ab - M)^+) where lambda is a step size. This is like exponentiated gradient / multiplicative weights.

```python

for _ in range(50):  # fixed number of inner iterations
    c = fft_conv(a, b)

    if viol.max() < 1e-10:
        break

    # b_j *= product over k of (if c_k > M, reduce b_j proportionally to a[k-j])
    # This is complex. Simpler: b *= (1 - eta * A^T * max(c-M, 0))
    # where A^T has (A^T y)_j = sum_k y_k * a[k-j]
    y = np.maximum(c - M, 0)  # length 2n-1
    # A^T y has length n: (A^T y)_j = sum_k y_k * a[k-j] (if valid)
    # This is a cross-correlation: (A^T y)[j] = sum_k y_k * a[k-j]
    # = sum_k y_k * a[j' - j] where j' = k-j... 
    
    # (A^T y)_j = sum_{k: 0<=k-j<n} y_k * a[k-j] = sum_{m: 0<=m<n} y_{j+m} * a[m]
    # (where j+m < 2n-1)
    # This is again a cross-correlation.
    a_rev = a[::-1]
    Ay = fft_conv(y, a_rev)
    At_y = Ay[n-1:2*n-1]  # length n
    
    eta = 0.5 / (np.abs(At_y).max() + 1e-10)
    b = b * (1.0 - eta * At_y)
    b = np.clip(b, 0, None)
    sb = b.sum()
    if sb < 1e-10:
        break
    b /= sb
```
