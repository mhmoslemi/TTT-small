- Project onto f >= 0: f_new = max(f_new, 0)
- Renormalize: f_new = f_new * S / sum(f_new)

This is the projected gradient method for minimizing a linear function (conv_{k*}) on the probability simplex. But we're minimizing the MAX of multiple linear functions, so it's more complex.

For the max, we can use:
- Find the top M lags (not just the single peak)
- Average their gradients: h_avg = (1/M) * sum of h_k for top M lags

def _score(f):
    """Fast score computation matching the evaluator semantics."""
    f = np.clip(f, 0.0, 1000.0)
    n = f.size
    conv = np.convolve(f, f)
    max_b = float(np.max(conv))
    sum_a = float(np.sum(f))
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a * sum_a)

def _partner(f, k, n):

    i_hi = min(n - 1, k)
    if i_hi >= i_lo:

    return h
