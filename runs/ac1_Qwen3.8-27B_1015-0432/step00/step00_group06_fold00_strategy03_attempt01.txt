2. Mathematical specification
- Objective: min AC1(a) = 2 * n * max(convolve(a, a)) / (sum(a))^2 
- Constraints: a_i ∈ [0, 1000] ∀i, sum(a) ≥ 0.01
- Representation: a of length 5582
- Perturbation types:
  - Random coefficient flip (with Gaussian noise)
  - Block reversal and scaling
  - Segmentination (partitioning into 2-3 segments)
- Evaluation: Uses full linear convolution from np.convolve with mode='full'

4. Search choices and variations
The algorithm uses three distinct perturbation kernels with adaptive weighting:
◯ Physics-inspired kernel (60%) - mimics fluid dynamics
◯ Structural transformation (30%) - segments and reorganizes coefficients
◯ Preservation kernel (10%) - maintains original parent sequence structure
The volatility increases as the algorithm approaches the target value from above

5. Compute budget and robustness
- Dominant cost: Each evaluation computes ~11k-point convolution (O(n log n))
- Evaluation frequency: Adaptively limited to ~3 eval/sec in rough phases
- Fallback: Uses uniform coefficients if all attempts fail ($\geq 2$ convolutions)
- Stagnation detection: Maximum of 3 identical results penalizes premature convergence
