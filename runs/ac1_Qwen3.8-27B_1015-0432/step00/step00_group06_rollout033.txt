- a(j) = (1 - alpha * j/(n-1))^beta for various alpha in [0, 2], beta in [0.5, 4]
- a(j) = 1 + alpha * sin(2*pi*j/g) for various g
- a(j) = exp(-((j-mu)/sigma)^2) for various mu, sigma (Gaussian bump)
- Two-Gaussian: sum of two Gaussians

For local refinement:
- Pick a random block of size w
- Perturb the block (scale, shift)
- Accept if improved

Let me also try the "LP-free" version of the suggested approach: instead of solving the LP, use the "dual" information (which constraint is active) to guide the update.

If k* = argmax (a*a)(k), then the "direction" that most reduces (a*a)(k*) while keeping sum(a) fixed is:
d_j = -2*a[k*-j] + lambda (where lambda is chosen so sum(d) = 0)
= -2*a[k*-j] + (2/n) * sum_i a[k*-i]
= -2*a[k*-j] + (2/n)*(a*a)(k*)

Then a_new = a + t*d, projected to a >= 0.

But this might make some a_j negative, and the step size needs to be small.

Actually, I think the most effective approach for this problem size is:

1. Try a variety of parametric shapes (fast, O(n log n) each)
2. For the best one, do iterative local search with:
   a. Subgradient step
   b. Random block perturbations
   c. "Flattening" step: reduce the peak by lowering the values that contribute most to it

Let me implement this. For n=5582, each convolution via FFT takes about 50 microseconds. So in 1100 seconds, I can do about 20 million evaluations. That's more than enough.
