def project_simplex(v):
    """Project v onto the probability simplex (x >= 0, sum(x) = 1)."""
    n = len(v)
    # Sort in descending order
    u = np.sort(v)[::-1]
    # Find the threshold
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1)
    return np.maximum(v - theta, 0)

- For n=6121, A has about n*(n) = 37M nonzeros (since each row has about n/2 nonzeros on average). That's a lot but maybe manageable for HiGHS.

Wait, actually the convolution matrix A[k, j] = a[j] for 0 <= k-j < n means:
- Row k has nonzeros in columns j = max(0, k-n+1) to min(n-1, k)
- So row k has min(k+1, n, 2n-1-k) nonzeros

Alternative: Use the dual of the LP. The dual is:
min M * sum_k y_k  s.t. sum_k y_k * A[k,j] >= 1 for all j, y_k >= 0

Where y_k >= 0 are the dual variables. The constraint sum_k y_k * a[j] * 1_{0<=k-j<n} >= 1 becomes:
For each j: sum_{k: 0<=k-j<n} y_k * a[j] >= 1
i.e., a[j] * (sum_{k=j}^{j+n-1} y_k) >= 1 for all j
i.e., S[j] >= 1/a[j] where S[j] = sum_{k=j}^{j+n-1} y_k

And the objective is M * sum_k y_k.

This is a simpler structure! The constraints are on "sliding window sums" of y. This is a covering LP with interval structure.

For the optimal solution, the convolution b = a*a should be as "flat" as possible (minimize the max). The optimal b is the minimum possible peak value C, achieved when the convolution is as flat as possible subject to a >= 0 and sum(a) = 1.

This is equivalent to: find the smallest C such that there exists a >= 0, sum(a) = 1, and a*a <= C (elementwise).

This is a feasibility problem, and we can binary search on C! For a given C, check if there exists a >= 0, sum(a) = 1, a*a[k] <= C for all k.

The check is: does there exist a >= 0, sum(a) = 1, such that a*a <= C? This is a set of quadratic constraints, which is not convex (in general). Wait, actually a*a[k] = a^T T_k a <= C IS a convex constraint (since T_k is PSD... is it?).

Only if it's the identity. So T_k is NOT PSD in general, meaning the constraint a^T T_k a <= C is NOT convex.

So the feasibility check is NOT a convex problem. This rules out simple binary search + SOCP/QP.

OK so I need to stick with the non-convex approach (the original problem IS convex in the sense that we're minimizing the max of convex functions, but each individual function a^T T_k a is not convex).

Wait, I need to recheck. Is a^T T_k a convex in a?

a^T T_k a = sum_i a_i * a_{k-i} (for valid indices). This is NOT a standard quadratic form a^T M a with M symmetric PSD. It's a "cross term" quadratic.

For n=2, k=0: a^T T_0 a = a_0^2 (convex)
For n=2, k=1: a^T T_1 a = 2*a_0*a_1 (NOT convex - it's indefinite)
For n=2, k=2: a^T T_2 a = a_1^2 (convex)

So the max of {a_0^2, 2a_0a_1, a_1^2} on the simplex a_0+a_1=1, a_0,a_1>=0 is:
= max(a_0^2, 2a_0(1-a_0), (1-a_0)^2)
= max(a_0^2, 2a_0-2a_0^2, 1-2a_0+a_0^2)

This is the max of convex functions, hence convex. ✓

So the problem IS convex (minimizing max of convex functions over a convex set). Good.

But the individual functions are NOT all convex in the standard quadratic form sense. The subgradient approach still works though.

Let me go back to the projected subgradient but with better convergence:

**Nesterov's accelerated subgradient method:**
- Maintain two sequences: a_k (current) and v_k (average)
- v_k = (1/k) * sum_{i=1}^{k} a_i (or weighted average)
- a_{k+1} = project_simplex(v_k - beta_k * g_k)
- beta_k = (v_k - a_k) / ||g_k||^2 (optimal step for this iteration)
- Return v_T after T iterations

This gives O(1/T) convergence rate. For T = 100K, gap ≈ initial_gap/T ≈ 1.25/100K ≈ 1.25e-5. That's excellent!

                best_score = score

import numpy as np
import time


def project_simplex(v):
    n = v.size
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    idx = np.arange(1, n + 1)
    cond = u * idx > (cssv - 1)
    if not np.any(cond):
        return np.full(n, 1.0 / n, dtype=np.float64)
    rho = int(np.nonzero(cond)[0][-1])
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def fft_convolve_self(a, fft_size):
    A = np.fft.rfft(a, n=fft_size)
    return np.fft.irfft(A * A, n=fft_size)
