**Simplified approach: Top-K gradient**

Instead of the full softmax (which requires a length-2n-1 kernel), just use the top-K positions:

```python
K = 20
top_idx = np.argpartition(c, -K)[-K:]
# Gradient for the max at top_idx positions (equal weight for simplicity)
g = np.zeros(n)
for k in top_idx:
    i_lo = max(0, k - n + 1)
    i_hi = min(n - 1, k)
    if i_hi >= i_lo:
        idx = np.arange(i_lo, i_hi + 1)
        g[idx] += a[k - idx]
g /= K
```

This is O(K*n) per iteration, very fast. And it directly targets the peak.

The update: to minimize max(c)/S^2, we want to reduce the top positions while maintaining S.

A natural update: reduce a[i] where the top positions have large contributions, and increase where they have small contributions.

Let me define: for the active set (top K positions), the "pressure" on a[i] is:
p[i] = sum_{k in top_K} a[k-i] (how much a[i] contributes to the peak)

Then: descent direction for max(c) is +p (increasing a[i] increases c at peak positions).
Descent for S^2 is +2a (increasing a[i] increases S^2).

For the ratio r = max_c/S^2:
gradient ≈ (p*S - 2*max_c*a) / S^3

Descent: a[i] -= eta * (p[i]*S - 2*max_c*a
