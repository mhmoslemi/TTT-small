More precisely, H = P_k + P_k^T where (P_k)[j, k-j] = 1/2.

P_k is a partial permutation matrix (shifting by k). Its eigenvalues are roots of unity, so the Hessian P_k + P_k^T has eigenvalues 2*cos(theta) which can be negative. So (f*f)[k] is NOT convex in general.

This means the subgradient method doesn't apply directly. The objective max_k (f*f)[k] is not a convex function of f.

def solve_lp_for_g(f, M, k_active, n):
    """Solve max sum(g) s.t. (f*g)[k] <= M for k in k_active, g >= 0."""
    from scipy.optimize import linprog
    from scipy.sparse import csr_matrix
    
    m = len(k_active)
    
    # Build constraint matrix A: m x n
    # A[i, j] = f[k_active[i] - j] if 0 <= k_active[i] - j <= n-1
    A = np.zeros((m, n))
    for i, k in enumerate(k_active):
        for j in range(max(0, k - n + 1), min(n, k + 1)):
            A[i, j] = f[k - j]
    
    # Objective: maximize sum(g) => minimize -sum(g)
    c = -np.ones(n)
    
    # Solve
    res = linprog(c, A_ub=A, b_ub=np.full(m, M), bounds=(0, None), method='highs')
    
    if res.success:
        return res.x
    return None
