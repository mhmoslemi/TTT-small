The LP approach from the "previous state of the art" is:
1. Start with some f (e.g., uniform)
2. M = max(f*f)
3. Solve LP: max sum(g) s.t. g >= 0, (f*g)[k] <= M for all k
4. Rescale g: g = g * sqrt(2n) / sum(g) (or appropriate normalization)
5. f <- (1-t)*f + t*g
6. Repeat

The LP in step 3: we want to maximize sum(g_j) subject to:
- g_j >= 0 for all j
- sum_j f(j) * g(k-j) <= M for all k (where the sum is over valid j)

The constraint matrix is a Toeplitz matrix T where T[k,j] = f(clip(k-j, 0, n-1)) or something like that. Actually, (f*g)[k] = sum_j f(j)*g(k-j) where k-j is in [0,n-1] and j is in [0,n-1].

So T[k,j] = f(k-j) if 0 <= k-j <= n-1, else 0. This is a (2n-1) x n Toeplitz matrix. It's banded with at most n nonzeros per row, so it has about n^2 nonzeros total. For n=6733, that's about 45 million nonzeros. That's feasible for a sparse LP.

Actually, the dual of this LP might be more tractable. The primal is:

The dual is:

Where y has length 2n-1.

The dual has 2n-1 variables and n constraints. The constraint T^T @ y >= 1 means for each j: sum_k T[k,j] * y[k] >= 1.

T[k,j] = f(k-j) if valid. So T^T[j,k] = f(k-j) = f(|k-j|) (by symmetry of convolution... wait, no, f is not necessarily symmetric).

The dual constraint for variable j: sum_{k=j}^{j+n-1} f(k-j) * y[k] >= 1.
