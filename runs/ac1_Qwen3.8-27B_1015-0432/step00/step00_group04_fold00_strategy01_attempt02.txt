The solution involves a multi-stage optimization strategy to minimize the AC1 score (autocorrelation inequality) by iteratively improving the input sequence through perturbations and gradient/linear programming methods. The core innovation is the adaptive use of gradient-based refinement based on the sequence's score distribution.

1. **Approach and Rationale:**  
   The central idea is to minimize the AC1 score (lower is better) by combining gradient-based refinement and linear programming projections. Unlike naive perturbations, this method focuses on directions reducing the maximum autocorrelation. The bottleneck is computational expense for dense convolutions, addressed by sparse representations. The strategy is justified by leveraging local gradient information while using exact evaluations to validate candidates.

2. **Mathematical Specification:**  
   - **Variables:** Let \( a_i \) be sequence coefficients, \( S = \sum a_i \), and \( M = \max_{k} ( \sum_{i+j=i+k} a_{i} a_{j} ) \).
   - **Objective:** Minimize \( \text{AC1} = \frac{2n \cdot M}{S^2} \).
   - **Gradient Refinement:** For each position, compute \( \frac{\partial \text{AC1}}{\partial a_i} \) by analyzing shift contributions to max autocorrelation.
   - **LP Projection:** When block-level gradients are large, solve a sparse LP to redistribute mass while maintaining non-negativity.

3. **Implementation Procedure:**  
   - **Phase 0 (400s):** Exact gradient evaluation on inputs.
   - **Phase 1 (800s):** Apply block-wise Lipschitz-preserving perturbations and exact evaluations for AC1 reduction.
   - **Phase 2 (900s):** Gradient-based refinement weighted by score distribution. Uses sparse voting mechanisms.
   - **Fallback:** Uses target-aligned sparse perturbations if extensive methods fail.

4. **Search Choices:**  
   - **Block Radius Adjustment:** Dynamically chosen as fraction of sequence length (1% to 10%).
   - **Resolution Strategy:** Three passes (gross, medium, fine) increasing in convolution detail.
   - **Validation:** Requires AC1 improvement for LP solutions; fallback uses exact evaluations.

5. **Compute Budget and Robustness:**  
   - **Time Allocations:** 400s for initialization, 150s for exact gradient, 650s for adaptive search.
   - **Resource Usage:** Sparse matrices limited to current block (O(n) memory vs. O(n²) dense).
   - **Fallback Construction:** 15-step targeting sequence from worst regions.

6. **Validation and Return Contract:**  
   - **Feasibility Checks:** Sum ≥0.01, finite values, nonnegative coefficients.
   - **Sanity Checks:** Minimum sum ≥0.01, basic AC1 validation on fallback.
   - **Output Format:** Nonnegative sequence of length 3809 in standard list format.
