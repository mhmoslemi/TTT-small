This IS a linear programming problem (linear constraints, linear objective) with variables a'[j] >= 0.

The constraint c'[k] = sum_i a'[i]*a'[k-i] <= M is quadratic, not linear! So it's NOT an LP.

Wait, the problem statement says:
"maximizing sum_j b_j subject to b_j>=0 and ||f*g_0||_∞ <= M"

Here f is the current sequence (fixed) and g_0 is the variable. So the constraint is (f*g_0)[k] <= M for all k, where f is FIXED. Since f is fixed, (f*g_0)[k] is LINEAR in g_0! So it IS an LP.

This is the key: we're not minimizing max(a*a), we're finding a direction g that, when mixed with the current a, reduces the peak while maintaining the constraint that the cross-correlation f*g is bounded.
