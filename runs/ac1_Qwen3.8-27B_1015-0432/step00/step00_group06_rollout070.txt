The key mathematical insight from my reasoning:
- The problem is to minimize `2n * max(conv(a,a)) / (sum(a))^2`
- For uniform sequences, this is always 2
- To beat 2, we need non-uniform sequences
- The "peak-shaving" approach: iteratively reduce the maximum of the convolution

The practical algorithm:
1. Start with parent sequence (or uniform)
2. Iteratively:
   a. Compute full convolution via FFT
   b. Find pressure on each coefficient based on where peaks are
   c. Update coefficients to reduce peak pressure
   d. Enforce nonnegativity
   e. Track best candidate

The pressure computation: if `b = conv(a, a)` has peak at lag k, then the gradient of b[k] w.r.t. a[j] is `a[k-j]` (shifted/reversed a). So to reduce the peak, we want to reduce a[j] where a[k-j] is large.

More generally, using a weighted sum of all lags (weighted by how much they exceed a threshold), we get:
`pressure[j] = sum_k w[k] * a[k-j]`

This is a cross-correlation between the weight vector w and a, which can be computed via FFT.
