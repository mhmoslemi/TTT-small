- `conv(a,a) = [1, 0, ..., 0, 2, 0, ..., 0, 1]` (peak 2 at center)
- Score = `2n * 2 / 4 = n`. Terrible.

What about a sequence with values spread over a small subset? Say `a[j] = 1` for j in S and 0 otherwise, where S has k elements.
- `sum = k`
- The conv at lag n-1 is the number of pairs (i, n-1-i) both in S. If S is symmetric about the center, this is k.
- Peak of conv is at most k (at the center) or less.
- Actually, the conv at arbitrary lag l is the number of pairs (i, i+l) both in S (with appropriate boundary handling for linear conv).
- The max over all lags is at most k.
- Score = `2n * k / k^2 = 2n/k`.
- To get score < 2, we need `k > n`. But k ≤ n! So binary sequences can't beat 2.

What about a sequence with three values? This is getting complicated.

Let me think about it from a different angle. The problem is:
Minimize `max_k [sum_i a_i a_{k-i}] / (sum_i a_i)^2`

Let `p_i = a_i / S` (probability distribution). Then we're minimizing `max_k sum_i p_i p_{k-i} * S`.

Wait no: `sum_i a_i a_{k-i} / S^2 = sum_i (a_i/S) * (a_{k-i}/S) * S = S * sum_i p_i p_{k-i}`.

So the score is `2n * S * max_k (p*p)[k]` where p is a probability vector.

To minimize this, we want to minimize `S * max_k (p*p)[k]`.

If we fix the shape of p (normalize to sum 1), then the score is `2n * max_k (p*p)[k]`. And S = sum(a) is free to scale. Wait, no - the score is `2n * max(conv(a,a)) / S^2`, and `max(conv(a,a)) = S^2 * max(conv(p,p))`. So the score is `2n * max(conv(p,p))` where p sums to 1. The scale cancels out!

So we just need to find a probability distribution p on {0,...,n-1} that minimizes `max_k (p*p)[k]`, and the score is `2n * max_k (p*p)[k]`.

For the uniform distribution: `max_k (p*p)[k] = 1/n` (at the center). Score = 2. ✓

To get score 1.5: `max_k (p*p)[k] = 1.5/(2n) = 0.75/n`.

So we need the convolution to have max value 0.75/n instead of 1/n. The "mean" of the conv is `1/(2n-1)` (total mass is 1, spread over 2n-1 values). So 0.75/n is about 1.5 times the mean. We need the conv to be within a factor of 1.5 of its mean.

This is the "minimum peak-to-mean ratio" problem for linear self-convolution of a probability vector.

I recall that for the CIRCULAR autocorrelation, the minimum peak-to-mean ratio for a probability vector is achieved by certain "flat" spectra. For LINEAR convolution, the boundary effects help.

One construction: a "truncated exponential" or geometric distribution. `p_j = (1-r)*r^j` for j=0,...,n-1. The self-convolution of a geometric is also geometric-like, with peak at 0 (value ≈ (1-r)^2) and decaying. The peak is at the edge, not the center. For r close to 1, the distribution is nearly uniform and the peak approaches 1/n. For r much less than 1, the distribution is concentrated and the peak is large.

Actually for a geometric, the peak of the conv is at k=0 (the beginning), and its value is `p_0^2 = (1-r)^2`. As r→1, this → 0, but the distribution becomes uniform. As r→0, p_0→1 and the peak → 1.

Hmm, this doesn't seem to give a better ratio than uniform.
