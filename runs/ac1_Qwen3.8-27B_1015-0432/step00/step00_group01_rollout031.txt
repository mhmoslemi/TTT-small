11. **Key realization**: To get score < 2, we need:
    max(conv(a,a)) < S^2/n
    
    This means the convolution must be "flatter" than S^2/n at its peak. Since the sum of all conv values is S^2, and there are 2n-1 values, the average is S^2/(2n-1). For the max to be < S^2/n, we need the values to be spread more evenly than the triangular distribution of the all-ones sequence.

    For a random sequence with independent entries, the convolution values are roughly S^2/(2n) at each position (by concentration), so max ≈ S^2/n (for large n, the max of 2n-1 values of a random variable with mean S^2/(2n) and the peak at center being S^2/n). Actually for random sequences, the center lag is sum(a_i^2) ≈ S^2/n (by law of large numbers for the empirical second moment), so the peak is still S^2/n.

    Hmm, so random sequences also give score ≈ 2.

    What structure could give max(conv) < S^2/n?

    We need the convolution to be "anti-peaked" - the values should be more uniform than the triangular function. This means we need the sequence to have structure that causes destructive "interference" in the convolution at the peak lag.

    For a periodic-like sequence: a[i] = 1 + eps*( -1)^i (alternating 1+eps and 1-eps):
    conv[k] at even k: contributions from same-parity pairs
    conv[k] at odd k: contributions from cross-parity pairs
    
    Let's compute for a = [1+e, 1-e, 1+e, 1-e, ...] (n even):
    Let h = 1+e, l = 1-e. n/2 of each.
    S = n/2*(h+l) = n/2*2 = n.
    
    conv[0] = h^2
    conv[1] = 2*h*l
    conv[2] = h^2 + l^2 (wait, need to be more careful)
    
    Actually for the linear convolution of length-n sequence with itself:
    conv[k] = sum_{i=max(0,k-n+1)}^{min(k,n-1)} a[i]*a[k-i]
    
    For the alternating sequence, a[i]*a[j] = (1+e)(1-e) = 1-e^2 if i≡j mod 2, and (1+e)(1-e) or (1-e)(1+e) = 1-e^2 if i≠j mod 2. Wait, that's the same!
    
    a[i]*a[j] = (1+(-1)^i * e) * (1+(-1)^j * e) = 1 + (-1)^i * e + (-1)^j * e + (-1)^{i+j} * e^2
    
    Sum over valid i,j with i+j=k:
    conv[k] = count + e*(-1)^i summed + e*(-1)^j summed + e^2*(-1)^{i+j} summed
    
    For i+j=k: (-1)^{i+j} = (-1)^k (constant!), so the e^2 term contributes e^2 * (-1)^k * count.
    The (-1)^i term: for i+j=k, j=k-i, so (-1)^i + (-1)^{k-i}. If k is even: (-1)^i + (-1)^i = 2(-1)^i, which sums to 0 over symmetric range. If k is odd: (-1)^i + (-1)^{k-i} = (-1)^i - (-1)^i = 0.
    
    So the cross terms (linear in e) vanish! (For large n, the boundary effects are small.)
    
    conv[k] ≈ count * (1 + (-1)^k * e^2) where count is the number of valid pairs.
    
    For the all-ones sequence, count = min(k+1, n, 2n-1-k).
    
    So conv[k] ≈ min(k+1, n, 2n-1-k) * (1 + (-1)^k * e^2)
    
    At k = n-1 (center, n even so k odd): conv[n-1] ≈ n * (1 - e^2)
    At k = n-2 (even): conv[n-2] ≈ (n-1) * (1 + e^2)
    
    max(conv) = max(n*(1-e^2), (n-1)*(1+e^2))
    
    For small e: n*(1-e^2) ≈ n - ne^2, (n-1)*(1+e^2) ≈ n-1 + (n-1)e^2
    
    The center is n - ne^2, the next is n-1+(n-1)e^2.
    Center < next when n - ne^2 < n-1+(n-1)e^2, i.e., 1 < (2n-1)e^2, i.e., e^2 > 1/(2n-1).
    
    So for e^2 > 1/(2n-1), the peak shifts from center to the adjacent even lags!
    
    The max is then (n-1)*(1+e^2) (approximately).
    S = n (the alternating doesn't change the sum for even n).
    Score = 2n * (n-1)*(1+e^2) / n^2 = 2(n-1)(1+e^2)/n
    
    For e^2 = 1/(2n-1) ≈ 1/(2n):
    Score ≈ 2(n-1)(1+1/(2n))/n ≈ 2(1-1/n)(1+1/(2n)) ≈ 2 - 2/n + 1/n ≈ 2 - 1/n
    
    That's barely below 2! Not enough.
    
    For larger e: e^2 up to 1 (making l=0):
    Score ≈ 2(n-1)*2/n = 4(n-1)/n ≈ 4. Worse!
    
    So the alternating approach barely helps.
