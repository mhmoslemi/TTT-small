Actually, let me just go with a practical iterative approach. Here's my refined plan:

1. Initialize with a few candidate shapes:
   - Uniform (parent)
   - Raised cosine: a[j] = max(0, 1 + cos(2πj/n))
   - Triangular: a[j] = 1 - |2j/n - 1|
   - Gaussian-like: a[j] = exp(-(2j/n - 1)^2 / σ^2) for various σ

2. Evaluate each, pick the best

3. Refine with gradient-based local search:
   - For each iteration:
     a. Compute conv = np.convolve(a, a)
     b. Find k* = argmax(conv)
     c. Compute gradient of conv[k*] w.r.t. a (O(n))
     d. Take a step in the negative gradient direction (with projection)
     e. Accept if score improves
   - Adapt step size

4. Also try random restarts with structured perturbations

import numpy as np
import time

def compute_conv_max_and_grad(a):
    """Compute convolution, find max index, and gradient at max."""
    conv = np.convolve(a, a)
    k = int(np.argmax(conv))
    n = len(a)
    # Gradient of conv[k] w.r.t. a
    # conv[k] = sum_{i: 0<=i<n, 0<=k-i<n} a[i]*a[k-i]
    # d/d a[j] = 2*a[k-j] for 0<=k-j<n
    j_lo = max(0, k - n + 1)
    j_hi = min(n - 1, k)
    grad = np.zeros(n)
    grad[j_lo:j_hi+1] = 2.0 * a[k - j_hi:k - j_lo:-1]  # a[k-j] for j from j_lo to j_hi
    # Fix the diagonal: where 2j=k
    mid = k // 2
    if 2 * mid == k and 0 <= mid < n:
        grad[mid] = a[mid]  # not 2*a[mid]
    return conv, k, grad
