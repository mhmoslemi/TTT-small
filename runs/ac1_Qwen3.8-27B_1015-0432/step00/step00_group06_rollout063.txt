```python
import numpy as np
import time

def convolve_full(a):
    """Full convolution of a with itself."""
    return np.convolve(a, a)

def ac1_score(a):
    """Compute the AC1 score without calling evaluate_sequence (for speed during search)."""
    n = len(a)
    c = np.convolve(a, a)
    max_b = np.max(c)
    sum_a = np.sum(a)
    if sum_a < 0.01:
        return float('inf')
    return 2.0 * n * max_b / (sum_a * sum_a)

def project_simplex(v, target=1.0):
    """Project v onto {x >= 0, sum(x) = target} in O(n log n)."""
    n = len(v)
    # Scale to target sum
    s = v.sum()
    if s <= 0:
        return np.full(n, target / n)
    v = v * (target / s)
    # Now project onto {x >= 0, sum(x) = target}
    # Standard algorithm: find threshold
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.where(u * np.arange(1, n+1) > (cssv - target))[0][-1]
    theta = (cssv[rho] - target) / (rho + 1)
    result = np.maximum(v - theta, 0)
    # Ensure sum is exactly target
    result[result > 0] += (target - result.sum()) / np.count_nonzero(result > 0)
    return result
```

```python
        idx = j_star - np.arange(n)
        valid = (idx >= 0) & (idx < n)
        g = np.zeros(n)
        g[valid] = 2.0 * a[idx[valid]]
        
        # Multiplicative weights update
        # a_new = a * exp(-eta * g)
        # To avoid underflow, shift g by its max
        gm = g.max()
        log_ratio = -eta * (g - gm)
        ratio = np.exp(log_ratio)
        a_new = a * ratio
        a_new = np.maximum(a_new, 1e-30)
        a_new = a_new / a_new.sum()
        
        s_new = score(a_new)
        if s_new < best_score and np.isfinite(s_new):
            best_a = a_new.copy()
            best_score = s_new
            a = a_new
            no_improve = 0
            # Occasionally increase eta
            if no_improve == 0 and rng.random() < 0.05:
                eta = min(eta * 1.1, 2.0)
        else:
            no_improve += 1
            if no_improve > 20:
                eta *= 0.8
                # Mix with uniform to escape local opt
                a = 0.9 * a + 0.1 * (1.0/n)
                a = a / a.sum()
        
        # Periodically try random restarts or perturbations
        if no_improve > 100 and rng.random() < 0.01:
            # Add random perturbation
            pert = rng.exponential(0.01, size=n)
            a = a + pert
            a = a / a.sum()
    
    return [float(x) for x in best_a]
```

Alternative approach: directly minimize the peak using a different method.

Let me think about the problem differently. We want to minimize max_j (a*a)[j] subject to a >= 0, sum a = 1.

This is equivalent to: find the smallest t such that there exists a >= 0, sum a = 1 with (a*a)[j] <= t for all j.

For a given t, the feasibility problem is:
a >= 0, sum a = 1, (a*a)[j] <= t for all j.

Each (a*a)[j] <= t is a quadratic constraint (not linear in a). So this is a quadratic programming problem (ball problem).

Actually, (a*a)[j] = a^T H_j a where H_j is a symmetric (Hankel) matrix. The constraint a^T H_j a <= t is a quadratic constraint. The problem is:
min t
s.t. a^T H_j a <= t for all j
a >= 0, sum a = 1

This is a convex QP if H_j is PSD for all j. But as we noted, H_j is not necessarily PSD (for odd j, the anti-diagonal entries make it indefinite).

Wait, let me recheck. H_j[m, k] = 1 if m + k = j, else 0? No, that's not right.

(a*a)[j] = sum_k a[k] * a[j-k] = sum_{k} a[k] * a[j-k].

Writing as a quadratic form: a^T H_j a = sum_{m,k} a[m] H_j[m,k] a[k].

We need a^T H_j a = sum_k a[k] a[j-k].

As a quadratic form: sum_m a[m] a[j-m] = sum_{m,k} a[m] a[k] * 1_{m+k=j}? No, that's not right either.

a^T H_j a = sum_{m,k} a[m] H_j[m,k] a[k].

We want this to equal sum_m a[m] a[j-m].

So we need: sum_k H_j[m,k] a[k] = a[j-m] for all m. This means H_j[m,k] = 1 if k = j-m, else 0.

So H_j is the matrix with H_j[m, j-m] = 1 (anti-diagonal). This is the "reversal" matrix shifted.

H_j is a permutation matrix (specifically, H_j = P_j where P_j[m,k] = 1 if k = j-m mod... no, it's not a permutation for all j because j-m might be out of range).

Actually, for 0 <= m < n and 0 <= j-m < n, H_j[m, j-m] = 1. This is a sub-identity (anti-identity) matrix.

H_j^2 = ? Let's check: (H_j^2)[m,k] = sum_l H_j[m,l] H_j[l,k] = H_j[m, j-m] * H_j[j-m, k].
H_j[j-m, k] = 1 if k = j-(j-m) = m. So H_j^2[m,k] = H_j[m,j-m] * 1_{k=m}.
= 1_{0<=j-m<n} * 1_{k=m}.

So H_j^2 = P_{j} where P_j is a diagonal matrix with P_j[m,m] = 1_{0<=j-m<n}. This is PSD (diagonal with 0s and 1s).

But H_j itself is not symmetric (in general), so it's not a valid quadratic form matrix. We need the symmetric part: (H_j + H_j^T)/2.

(H_j + H_j^T)/2 [m,k] = (1_{k=j-m} + 1_{m=j-k})/2 = (1_{m+k=j} + 1_{k+m=j})/2 = 1_{m+k=j}.

So the symmetric part is the matrix with 1s on the anti-diagonal (where m+k=j) and 0s elsewhere. This is symmetric! And its eigenvalues: for the full n×n anti-identity matrix, eigenvalues are ±1. For a sub-anti-identity (only some anti-diagonal entries are 1), the eigenvalues are still ±1 and 0.

So the symmetric part is NOT PSD. The quadratic form a^T S_j a where S_j has S_j[m,k] = 1_{m+k=j} can be negative!

Let me verify: n=3, j=1. S_1 = [[0,1,0],[1,0,0],[0,0,0]]. Eigenvalues: 1, -1, 0. So a^T S_1 a = 2*a[0]*a[1]. For a = [1, -1, 0], this is -2. Negative!

But we have the constraint a >= 0, so a^T S_j a = 2*sum_{m+k=j} a[m]*a[k] (with the factor of 2 adjusted for m=k case) >= 0 for a >= 0. So on the domain a >= 0, the quadratic forms ARE nonnegative, even if the matrices are not PSD.

This means the problem is not convex in the full space, but is "convex" on the nonnegative orthant. Standard convex optimization tools might not directly apply.

However, the problem is still well-defined and we can use numerical methods.

Let me go back to the practical approach. Given that:
1. The problem is scale-invariant (fix sum = 1)
