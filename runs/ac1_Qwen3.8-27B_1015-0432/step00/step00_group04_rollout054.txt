(conv(a,a))[k] = Σ_i a[i] * a[k-i] for k=0,...,2n-2

For k=0: a[0]*a[0] = a[0]² (only one term)
For k=1: a[0]*a[1] + a[1]*a[0] = 2*a[0]*a[1]
For k=2: a[0]*a[2] + a[1]*a[1] + a[2]*a[0]

So conv[0] = a[0]², NOT sum(a_i²)!

I was confusing linear convolution with autocorrelation! The autocorrelation would be conv with one flipped:
autocorr[k] = Σ_i a[i] * a[i+k]

But np.convolve(a, a) is just the polynomial product! It's NOT the autocorrelation.

Actually wait, let me reconsider. The key question is: for a non-negative sequence, can max(conv(a,a)) < s²/n?

conv(a,a)[k] for k in [0, 2n-2]. The sum of all conv values is (sum a)² = s². There are 2n-1 values. So the average is s²/(2n-1) < s²/n for n > 1.

So the AVERAGE is less than s²/n. But the MAX could still be ≥ s²/(2n-1).

For the max to be < s²/n, we need the peak to be less than about half the average (since (2n-1)/1 ≈ 2n, and we need max < s²/n while avg = s²/(2n-1), so max < 2 * avg approximately).

This IS possible! For a sequence with very low autocorrelation peaks relative to its mean energy.

score ≈ 2n * p²*n / p²*n² = 2
