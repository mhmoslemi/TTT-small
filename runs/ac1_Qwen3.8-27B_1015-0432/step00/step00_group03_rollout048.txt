- To reduce the center, decrease p[n/2] and increase p[0] and p[n-1].
- Each adjustment reduces the center peak but might increase edge peaks.
- Continue until all peaks are equalized.

This is essentially what the LP does, but in one shot.

import time
from scipy.optimize import linprog
from scipy.sparse import csr_matrix

def build_conv_matrix(p, n):
    """Build sparse (2n-1) x n convolution matrix."""
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        j_lo = max(0, k - n + 1)

        rows.append(np.full(len(j_range), k, dtype=np.int32))
        cols.append(j_range.astype(np.int32))

    cols = np.concatenate(cols)

        M = conv_p.max()

                             bounds=[(0.0, None)] * n,

Actually, I just realized: for the LP, the constraint matrix A has entries A[k,j] = p[k-j] which are all non-negative (since p >= 0). This means the LP is:

Let me also think about the convergence of the LP-based iteration. The key question: does the iteration p_{t+1} = solve_LP(p_t) converge?

The LP finds q = argmax {sum(q) : q >= 0, (p_t * q)[k] <= M_t for all k}.

At the fixed point, p = q, so (p*p)[k] <= M for all k, and sum(p) is maximized subject to this. Since we normalize to sum=1, at the fixed point, p is the (normalized) maximizer of... hmm, this isn't quite a standard fixed-point iteration.

Let me think differently. The LP is: max sum(q) s.t. (p*q)[k] <= M for all k, q >= 0.
The dual is: min M * sum(λ_k) s.t. (λ*p)[i] >= 1 for all i, λ_k >= 0.

(Here (λ*p)[i] = sum_k λ_k * p[k-i], the cross-correlation of λ and p.)

At the optimum, by complementary slackness:
- If q_i > 0, then (λ*p)[i] = 1.
- If λ_k > 0, then (p*q)[k] = M.

So
