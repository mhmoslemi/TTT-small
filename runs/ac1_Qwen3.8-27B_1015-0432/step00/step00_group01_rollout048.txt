Let me think about the LP approach more carefully. The SOTA says:
- Maximize sum(g) subject to g >= 0 and (f * g)[k] <= M for all k.

This is a linear program with:
- n variables (g_0, ..., g_{n-1})
- 2n-1 inequality constraints (convolution values <= M)
- n nonnegativity constraints
- Objective: maximize sum(g)

The constraint matrix is (2n-1) x n, where row k has nonzeros at positions i where 0 <= k-i < n, with value f[i]. This is a "convolution matrix" - it's banded in a sense, but each row has up to n nonzeros.

Total nonzeros: sum over k of (number of valid i) = sum_k min(k+1, n, 2n-1-k) ≈ n^2/2.

For n=6121: about 18.7M nonzeros. With CVXPY and a sparse solver, this might be feasible but tight on time.

Alternative: Use the constraint in a projected subgradient setting. At each iteration:
1. Compute c = conv(a, a), M = max(c).
2. Try to find g that maximizes sum(g) s.t. conv(a, g) <= M. Use a few iterations of a simple method (e.g., projected gradient or iterative water-filling).
3. Blend a toward g.

Actually, for step 2, a simpler approach: we want g >= 0 such that a[i]*g[k-i] summed over i <= M for all k. This is like: for each k, sum_i a[i]*g[k-i] <= M. If a is roughly uniform (a[i] ≈ S/n), this becomes approximately (S/n) * sum_i g[k-i] <= M, i.e., the "smoothing" of g is bounded.
