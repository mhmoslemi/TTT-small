    # v_i - tau > 0 when v_i > tau
    # So we need: sum_{i: v_i > tau} (v_i - tau) = 1
    # Let S(tau) = sum_{i: v_i > tau} (v_i - tau)
    # S is continuous, decreasing in tau, S(-inf) = inf, S(inf) = 0

            lo = mid
        else:
            hi = mid
    tau = (lo + hi) / 2
    return np.maximum(v - tau, 0)

For a sequence a of length n, the score is 2*n*max(b)/S^2 where S = sum(a) and b = convolve(a,a).

The sum of all b values is S^2 (as I showed earlier). There are 2n-1 values. So the average of b is S^2/(2n-1).

The max is at least the average: max(b) >= S^2/(2n-1).
Score >= 2n/(2n-1) ≈ 1 for large n.

But can we get close to this? We need b to be as flat as possible.

For the uniform sequence, b is triangular: b[k] = (k+1)*c for k < n-1, (2n-1-k)*c for k >= n-1, where c = 1/n^2. The max is n*c = 1/n, and the average is S^2/(2n-1) = n^2/n^2/(2n-1) = 1/(2n-1). The ratio max/avg = (1/n)/(1/(2n-1)) = (2n-1)/n ≈ 2.

For a "flatter" sequence, this ratio would be closer to 1.
