Actually, for the LP:
max sum(g) s.t. A*g <= M*1, g >= 0

where A is the (2n-1) x n convolution matrix.

The dual is:
min M * sum(y) s.t. A^T * y >= 1, y >= 0

where y has 2n-1 components.

A^T * y >= 1 means: for each i, sum_k A[k,i] * y[k] >= 1.
A[k,i] = 1 if... no, A[k,i] is the coefficient of g[i] in the k-th constraint.
(f*g)[k] = sum_j f[j]*g[k-j], so the coefficient of g[i] in constraint k is f[k-i] (if valid).
So A[k,i] = f[k-i] if 0 <= k-i < n, else 0.

A^T * y >= 1 means: for each i, sum_k f[k-i]*y[k] >= 1 (over valid k).
Let m = k-i: sum_m f[m]*y[m+i] >= 1.
This is (f * y)[i] >= 1 where * is convolution (with appropriate bounds).

So the dual is: min M * sum(y) s.t. (f*y)[i] >= 1 for all i, y >= 0.

Actually, for the LP max sum(g) s.t. (f*g)[k] <= M for all k, g >= 0:
A simple approach: start with g = uniform, then for each constraint k that's violated, reduce the g[i] that contribute most to (f*g)[k].

This is like the "water-pouring" algorithm. Each iteration:
1. Compute (f*g) for current g
2. Find violated constraints (where (f*g)[k] > M)
3. For each violated k, reduce g[i] for the i that contribute most (largest f[k-i]*g[i])

Let me implement this:

```python
def lp_direction(f, M, n, rng, max_iters=100):
    """Approximate LP solution: max sum(g) s.t. f*g <= M, g >= 0"""
    g = np.full(n, 1.0/n)
    for _ in range(max_iters):
        fg = np.convolve(f, g)
        violations = np.where(fg > M + 1e-12)[0]
        if len(violations) == 0:
            break
        # For each violation, reduce contributing g
        for k in violations[:10]:  # limit to 10 per iteration
            # fg[k] = sum_{j} f[j]*g[k-j] (valid j)
            # Reduce proportional to f[j]*g[k-j]
            lo = max(0, k-n+1)
            hi = min(n-1, k)
            if hi < lo:
                continue
            js = np.arange(lo, hi+1)
            ks = k - js
            contrib = f[js] * g[ks]
            total = contrib.sum()
            if total > 0:
                # Reduce so that sum becomes M
                scale = M / fg[k]
                g[ks] *= scale
    return g
```
