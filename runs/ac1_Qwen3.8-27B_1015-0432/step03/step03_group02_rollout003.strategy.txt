1. Approach and rationale
The central idea is to minimize the AC1 upper bound score by iteratively refining candidate sequences based on a projected gradient approach. Unlike the previous program's exponential update, this approach uses a coordinate-wise descent combined with an active set strategy to target high-convolution indices. We compute the gradient direction using the constraint `convolve(f, g_0) <= M` and update the sequence while maintaining non-negativity. This differs from the previous work by directly leveraging gradient information and adaptive active set selection. The main limitation is ensuring convergence in high dimensions (n=4806), but we mitigate this with early termination and restart heuristics.

2. Mathematical specification
- **Variables**: Represent candidate sequences as vectors `f ∈ ℝⁿ⁺⁺` with `0 ≤ f_i ≤ 1000`.
- **Objective**: Minimize `score(f) = 2n·max(convolve(f, f)[0:2n-1]) / (∑fᵢ)²`.
- **Active Set**: Identify indices `k` where `(convolve(f, f))[k]` exceeds a threshold `θ·max_conv` (θ starts at 0.99, decreasing).
- **Gradient Direction**: For active set `A`, compute `g = convolve(f, h)` where `h` is 1 in active set and 0 elsewhere. Then `g_dir` is the normalized gradient vector.
- **Update Rule**: `f ← clip(f·exp(η·(-g_dir/max_g)), min=1e-30)`, with `η` adapted from 0.1-0.3.
- **Score Calculation**: Use `evaluate_sequence` for all candidate checks; compute convolution via FFT.

3. Implementation procedure
- **Initialization**: Generate 5 initial candidates (uniform, Gaussian, `height_sequence_1`, and two patterns). Score them and select best.
- **Core Loop**:
  1. Compute convolution `c = full_conv(f) -> (2n-1)`
  2. Identify active set `A` indices for `c[k] ≥ θ·max(c)`
  3. Compute `h = rect(A, n)` and then `g = convolve(f, h[::-1])`
  4. Extract `g_dir = g[n-1:2n-1][::-1]`
  5. Update `f` with projection: `f ← f·exp(-η·g_dir/max(g_dir) + κ) → max(1e-30, clip)`
  6. Renormalize `f ← f/sum(f)` to maintain sum scaling.
  7. Check score improvement; revert if worse.
- **Restart Heuristics**: If 100 iterations without improvement, restart from best_so_far with additive noise.
- **Budget Management**: Check time every 5 iterations; exit if remaining time < 30s.

4. Search choices and variations
- **Active Set Threshold**: Starts at θ=0.99, decreases by 0.01 if plateau detected.
- **Learning Rate η**: Adapts from 0.1 to 0.3; halves if 50 iterations without improvement.
- **Initialization**: 4 methods: uniform, `height_sequence_1`, Gaussian burst, and sinusoidal.
- **Dimension**: Fixed at n=4806; if modified, use cubic interpolation for padding.

5. Compute budget and robustness
- **Time Estimation**: 80% core loop, 10% auxiliary operations. Core convolution costs ~0.5s (n=4806).
- **Deadline Check**: Inside core loop every 5 iterations.
- **Fallback**: Keep `best_f` and `best_score`; if valid candidate not found, return uniform `1/n`.
- **Instability**: Clip `η` to [0.05, 0.35]; use soft clipping in updates.

6. Validation and return contract
- **Final Check**: Call `evaluate_sequence(best_f)` and ensure it's finite and minimized.
- **Post-Processing**: Round values to float precision; ensure no negative/overflow candidates.
- **Sanity Checks**: Verify maximum convolution index exceeds active threshold during updates.
