The problem min max_k b[k] subject to f >= 0, sum(f) = 1 can be written as:
min t subject to b[k] <= t for all k, f >= 0, sum(f) = 1

Using log-sum-exp approximation: t ≈ (1/K) * log(sum exp(K*b[k]))
This is smooth and we can use gradient descent.

But the computation of the gradient of log-sum-exp(K*b) is:
grad = (1/K) * sum_k exp(K*b[k]) * grad(b[k]) / sum_k exp(K*b[k])

Which is a weighted average of the gradients, with weights proportional to exp(K*b[k]). For large K, this is essentially the gradient of the max (active set). For small K, it's a smoother approximation.

This is essentially the same as the previous approach but with a smoother transition. The "K" parameter plays the role of the threshold.
