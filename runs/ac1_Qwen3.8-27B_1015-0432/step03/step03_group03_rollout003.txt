The key question: what is the minimum of max_k (f*f)[k] over f >= 0, sum(f) = 1?

For large n, the answer should be close to 1/n (the uniform case gives exactly 1/n for the center lag, but the max is also 1/n for uniform). The subgradient ∇(f*f)[k]_j = f[k-j] + (if j != k-j) f[k-j]... actually it's the "shifted and reversed" f.

So the condition is: sum_k λ_k * (S_k f) = μ + ν, where S_k is the shift-reverse operator.

This means that a convex combination of the "shifted-reversed" versions of f should equal a constant (on the support of f). This is a strong condition.

For the uniform f, all shifted-reversed versions are the same, so the condition is trivially satisfied. For a non-uniform f, the condition requires a specific balance.

This is similar to the "flattening" problem in spectral design. The optimal f should have its "circular autocorrelation" as flat as possible (subject to nonnegativity).

Let me implement the soft-max approach:

Instead of max_k (f*f)[k], use (1/T) * log(sum exp(T * (f*f)[k])). As T -> inf, this approaches the max. The gradient is:
∇_f (1/T) log(sum exp(T b_k)) = (1/T) * sum_k exp(T b_k) / sum_l exp(T b_l) * ∇_f b_k
= sum_k softmax(T*b)_k * ∇_f b_k

This is a weighted average of the individual gradients, with weights proportional to exp(T b_k). For large T, the weights concentrate on the max.

The advantage: smooth gradient, always defined, and we can adapt T during optimization.
