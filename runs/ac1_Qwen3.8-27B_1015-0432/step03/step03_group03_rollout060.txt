def lp_step(f, M, deadline):
    n = f.shape[0]
    L = 2 * n - 1
    # Build sparse constraint matrix
    rows = []
    cols = []
    vals = []
    for k in range(L):
        i_start = max(0, k - n + 1)
        i_end = min(n - 1, k)
        if i_end >= i_start:
            cols.extend(range(i_start, i_end + 1))
            vals.extend(f[i_start:i_end + 1])
            rows.extend([k] * (i_end - i_start + 1))
    
    A = sparse.csr_matrix((vals, (rows, cols)), shape=(L, n))
    # Maximize sum(b) s.t. A @ b <= M, b >= 0
    from scipy.optimize import linprog
    c = -np.ones(n)
    res = linprog(c, A_ub=A, b_ub=np.full(L, M), bounds=[(0, None)]*n, method='highs',
                  options={'time_limit': max(1, deadline - time.monotonic() - 30)})
    if res.status == 0:
        b = res.x
        s = b.sum()
        if s > 1e-10:
            return b / s
    return None

Let me instead use a simpler approach: the dual of this LP. The primal is:
max 1^T b
s.t. A b <= M * 1
b >= 0

The dual is:
min M * 1^T y
s.t. A^T y >= 1
y >= 0

Where y has length 2n-1 = 9611. A^T y >= 1 means for each i: sum_k A[k,i] * y[k] >= 1, i.e., sum_k f[i] * y[k] (for valid k) >= 1.

Actually, A[k,i] = f[i] if max(0,k-n+1) <= i <= min(n-1,k). So A^T y >= 1 means:
sum_{k: max(0,k-n+1)<=i<=min(n-1,k)} f[i] * y[k] >= 1
f[i] * sum_{k=max(0,i)}^{min(2n-2, i+n-1)} y[k] >= 1
sum_{k=i}^{i+n-1} y[k] >= 1/f[i]  (with y[k]=0 for k outside [0,2n-2])

So the dual is:
min M * sum(y)
s.t. sum_{k=i}^{i+n-1} y[k] >= 1/f[i] for each i
y >= 0

This is a covering LP with a "sliding window" constraint structure! The constraint matrix is a (n x (2n-1)) banded matrix where each row is a window of n consecutive 1s. This is much more structured.
