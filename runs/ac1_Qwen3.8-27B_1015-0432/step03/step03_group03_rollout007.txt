subject to c_k(f) <= t for all k
sum f = 1
f >= 0

This is a semi-definite program (SDP) if we use the lift F = f f^T! But the lift is rank 1, which makes it non-convex.

However, we can relax: minimize t
subject to tr(A_k F) <= t for all k (where A_k encodes the k-th convolution)
F = f f^T (rank 1 constraint - drop for relaxation)
F >= 0 (PSD)
sum f = 1 (linear in f, but in F it becomes more complex)

This relaxation might give a lower bound but not necessarily a feasible solution.

def fft_conv(a, b):
    n, m = len(a), len(b)
    size = 1 << (n + m - 2).bit_length()
    return np.fft.irfft(np.fft.rfft(a, size) * np.fft.rfft(b, size))[:n + m - 1]

def norm_pos(f):
    f = np.maximum(f, 0.0)
    s = f.sum()
    if s < 1e-15:
        return np.ones_like(f) / f.shape[0]
    return f / s

def obj_val(f):
    b = fft_conv(f, f)
    s = f.sum()
    if s < 1e-15:
        return np.inf
    return 2.0 * f.size * b.max() / (s * s)

def peak_grad(f, peaks, weights):
    n = f.shape[0]
    L = 2 * n - 1
    h = np.zeros(L)
    h[peaks] = weights
    c = fft_conv(f, h[::-1])
    g = 2.0 * c[n - 1:2 * n - 1][::-1]
    return g
