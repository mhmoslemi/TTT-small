The gradient of log-sum-exp of the autocorrelation values would be:
g_j = 2 * sum_k softmax_k * f(k-j)

where softmax_k = exp(b_k / T) / sum_m exp(b_m / T)

This is a smooth approximation to the max, and its gradient is dense (involves all k, not just peaks). But we can compute it efficiently:

g_j = 2 * sum_k softmax_k * f(clip(k-j, 0, n-1))

This is a weighted sum of shifted copies of f, which can be computed as a convolution of f with the softmax weights (reversed).

def fft_conv(a, b):
    n, m = len(a), len(b)
    size = 1 << (n + m - 2).bit_length()
    return np.fft.irfft(np.fft.rfft(a, size) * np.fft.rfft(b, size))[:n + m - 1]

    f = np.maximum(f, 0.0)
    s = f.sum()
    if s < 1e-15:
        return np.ones_like(f) / f.shape[0]

        return np.inf
