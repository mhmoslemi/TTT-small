We want: grad[m] = sum_{j=0}^{n-1} f[j] * w[m+j] for m = 0, ..., n-1

where w has length 2n-1 (the convolution length).

Using fft_conv(f, w[::-1]):
- f has length n, w[::-1] has length 2n-1
- Result has length n + (2n-1) - 1 = 3n-2
- c[k] = sum_i f[i] * w_rev[k-i] where w_rev = w[::-1]
- w_rev[t] = w[2n-2-t]
- c[k] = sum_i f[i] * w[2n-2-(k-i)] = sum_i f[i] * w[i + 2n - 2 - k]

We want: g[m] = sum_j f[j] * w[m+j]

Setting k = 2n - 2 - m + j... this isn't a simple index.

Let me re-derive. c[k] = sum_i f[i] * w[i + 2n - 2 - k]

For the term f[j] * w[m+j]: we need i=j and i + 2n - 2 - k = m+j, so 2n-2-k = m, k = 2n-2-m.

So c[2n-2-m] = sum_j f[j] * w[m+j]. 

So g[m] = c[2n-2-m] for m=0,...,n-1.

In array notation: c[2n-2-m] for m=0 gives c[2n-2], m=1 gives c[2n-3], ..., m=n-1 gives c[n-1].

So g = c[n-1 : 2n-1][::-1]
