def fft_conv(a, b):

    if s < 1e-15:

    b = fft_conv(f, f)

In the cross-correlation g[j] = sum_i f[i] * h[j+i], if we let p = j+i, then i = p-j, and g[j] = sum_p f[p-j] * h[p]. Yes! That's exactly the gradient I want.

So the update f *= exp(-eta * g / gmax) reduces elements that contribute more to active peaks. Good.

Now, one issue: the gradient of b[p] = sum_i f[i]*f[p-i] with respect to f[j] is f[p-j] (from first factor) + f[p-j] (from second factor, when p-i=j, i=p-j) = 2*f[p-j]. But we only need the direction, so the factor of 2 doesn't matter.

But wait, there's a subtlety. The element f[j] contributes to peak b[p] through TWO paths: as the "left" element (i=j, contributing f[j]*f[p-j]) and as the "right" element (p-i=j, contributing f[p-j]*f[j]). Both give f[p-j] as the derivative. So the total gradient at j from peak p is 2*f[p-j]. My cross-correlation g[j] = sum_p h[p]*f[p-j] captures this (up to the factor of 2 which doesn't matter for the direction).
