For k = n-1: (a*a)[n-1] = sum_i a[i]*a[n-1-i] = a^T J a where J is the exchange matrix (flip). J is symmetric, and a^T J a = sum a[i]*a[n-1-i]. The eigenvalues of J are ±1, so it's not PSD. So the constraint is NOT convex.

For k = 0: (a*a)[0] = a[0]^2, which IS convex.

So the problem is non-convex. The multiplicative gradient approach is appropriate.
