Where y has length 2n-1 and A(f)^T y at position j = sum_k A(k,j) * y[k] = sum_k f_j * y[k] (for valid k) = f_j * sum_{k in valid range} y[k].

And: sum_{k=max(0,j)}^{min(2n-2, j+n-1)} y[k] ≥ 0 (for f_j = 0, which is automatically satisfied since y ≥ 0)

This is a system of constraints on partial sums of y! Let's define Y[k] = sum_{i=0}^{k} y[i]. Then the constraint becomes:
Y[min(2n-2, j+n-1)] - Y[max(0, j)-1] ≥ 1/f_j

This is a set of difference constraints! We can solve it efficiently.
