Actually, I should not use a dense LP. The problem says "Any LP realization must use a genuinely sparse or matrix-free formulation with bounded working memory."

Let me use a first-order approach for the LP subproblem:
- The LP is: max c'g subject to A g <= b, g >= 0 where A is the (2n-1) x n convolution matrix.
- Use projected subgradient or ADMM.

ADMM formulation:
Minimize: sum_k max(0, (Ag)_k - M) + rho/2 * ||g - z||^2 + sum_j max(0, -z_j)
... this is getting complicated.

Let me stick with improving the multiplicative weight method, which already works:

**Improved algorithm:**

```
1. Start with multiple diverse initializations
2. For each initialization, run mirror descent (multiplicative weights) with:
   - Adaptive peak selection (all peaks above threshold, weighted by excess)
   - Two-timescale eta (fast + slow)
   - Periodic symmetrization
   - Adaptive restart with structured perturbations
3. After optimization, do local refinement:
   - For the top few peaks, do a small coordinate descent
   - Try anti-symmetric perturbations (f[i] += eps, f[n-1-i] -= eps)
4. Return the best solution found
```

Let me also think about what the optimal structure looks like. For large n, the optimal f should have a "Wigner distribution" that's as flat as possible. In the time domain, this looks like a combination of:
- A broad base (to keep sum(f) large)
- Modulations that push the autocorrelation energy away from the peak

For a "flat" Wigner distribution, f should look like |sinc| in some sense, but made nonnegative. A good approximation is a "raised cosine" or "Hamming" window, possibly with additional structure.

Actually, for the specific problem of minimizing the L-infinity norm of the autocorrelation subject to L1 norm constraint, the optimal solution for continuous functions is related to the "ideal" Wigner distribution (flat), which in turn corresponds to a function whose Fourier transform has a specific structure.

For discrete nonnegative sequences, the best we can do is approximate this. The raised-cosine (Hamming) window is a good starting point because its autocorrelation is more concentrated than a rectangle's.

import numpy as np
import time

def fft_conv(a, b):
    n, m = len(a), len(b)
    size = 1 << (n + m - 2).bit_length()
    return np.fft.irfft(np.fft.rfft(a, size) * np.fft.rfft(b, size))[:n + m - 1]

def obj_val(f):
    b = fft_conv(f, f)
    s = f.sum()
    if s < 1e-15:
        return np.inf
    return 2.0 * f.size * b.max() / (s * s)

def peak_subgrad_w(f, peaks, weights):
    n = f.shape[0]
    L = 2 * n - 1
    h = np.zeros(L)
    h[peaks] = weights
    c = fft_conv(f, h[::-1])
    g = c[n-1:2*n-1][::-1]
    return np.maximum(g, 0.0)

    f = f / s  # normalize to sum 1
    best_f = f.copy()
    best_sc = obj_val(f)
    eta = eta0
    no_improv = 0
    momentum = np.zeros(n)
    iter_count = 0
    
    for it in range(max_iter):
        if time.monotonic() > deadline:
            break
        iter_count += 1
        b = fft_conv(f, f)
        M = b.max()
        # Weight peaks by their excess above the mean
        mean_b = b.mean()
        excess = b - mean_b
        # Select peaks with significant excess
        thresh = mean_b + 0.3 * (M - mean_b)
        peaks = np.where(b >= thresh)[0]
        if len(peaks) == 0:
            peaks = np.array([np.argmax(b)])
        if len(peaks) > 400:
            # Keep top 400 by value
            idx = np.argsort(b)[::-1][:400]
            peaks = idx
        w = b[peaks] / b[peaks].max()
        
        g = peak_subgrad_w(f, peaks, w)
        gmax = g.max()
        if gmax < 1e-25:

        momentum = 0.7 * momentum + 0.3 * g
        mmax = momentum.max()
        if mmax < 1e-25:
            break
        
        # Multiplicative update with barrier
        f = f * np.exp(-eta * momentum / mmax)
        f = np.maximum(f, 1e-18)
        f = f / f.sum()
        
        # Periodic symmetrization
        if it % 100 == 0:
            f = 0.5 * (f + f[::-1])
            f = f / f.sum()

        if it % 50 == 0:
            sc = obj_val(f)
            if sc < best_sc - 1e-13:
                best_sc = sc
                best_f = f.copy()
                no_improv = 0
            else:
                no_improv += 1
            
            if no_improv > 400:
