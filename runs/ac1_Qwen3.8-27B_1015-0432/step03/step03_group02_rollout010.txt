Actually, let me use scipy.optimize.minimize with the smooth approximation. The gradient would be:
∂/∂f_i [2n * logsumexp(b/τ) / τ] = 2n/τ * Σ_k (exp(b[k]/τ) / Σ_m exp(b[m]/τ)) * ∂b[k]/∂f_i

And ∂b[k]/∂f_i = 2*f[k-i] (for valid k-i).

This is an O(n * 2n) = O(n^2) computation per gradient eval, which for n=4806 is about 46 million operations. That's maybe 1-2 seconds for a full precision float array. Too slow for many iterations.

Alternative: use the FFT trick. The gradient is proportional to the weighted sum of shifted f's, where the weights are the softmax of b/τ. I can compute this with FFT:
1. Compute w = softmax(b/τ), length 2n-1
2. gradient[i] = Σ_k w[k] * 2*f[k-i] = 2 * (f ⋆ w)[i] (cross-correlation)
3. This is an FFT computation!

import numpy as np

def fft_conv(a, b):
    n, m = len(a), len(b)
    size = 1 << (n + m - 2).bit_length()
    return np.fft.irfft(np.fft.rfft(a, size) * np.fft.rfft(b, size))[:n + m - 1]

def score(f):
    s = f.sum()
    if s < 1e-15:
        return np.inf
    b = fft_conv(f, f)
    return 2.0 * len(f) * b.max() / (s * s)

def smooth_grad(f):
    n = len(f)
    b = fft_conv(f, f)
    tau = max(1e-4, b.max() * 0.002)
    bs = b / tau
    bm = bs.max()
    e = np.exp(bs - bm)
    w = e / e.sum()
    size2 = 1 << (3 * n - 2).bit_length()
    F2 = np.fft.rfft(f, size2)
    Wr = np.fft.rfft(w[::-1], size2)
    cw = np.fft.irfft(F2 * Wr)[:3 * n - 1]
    g = 2.0 * cw[n - 1:2 * n - 1][::-1]
    return g, bm * tau

        M = b.max()

        prog = min(1.0, it / 6000.0)

                patience = 0

def grad_descent(f, deadline, rng, steps=80):

    best_f = f.copy()
    best_sc = score(f)
    step = 0.002
    for i in range(steps):

            break
        g, _ = smooth_grad(f)
        g_mean = g[f > 1e-10].mean() if (f > 1e-10).any() else 0.0
        g_dir = g - g_mean
        for _ in range(4):

            np.maximum(trial, 1e-30, out=trial)
            trial /= trial.sum()
            sc = score(trial)
            if sc < best_sc - 1e-14:
                best_sc = sc
                best_f = trial.copy()
                break
            step *= 0.5
        step = min(step * 1.2, 0.005)
    return best_f, best_sc
