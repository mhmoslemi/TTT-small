The multiplicative update `f_i *= exp(-eta * g_i)` reduces f_i proportionally to its gradient. The gradient g_i is the amount by which f_i contributes to the peak. So this update reduces the values that contribute most to the peak.

4. The "gradient" at position i is `f_{k*-i}` (the partner value). So we reduce f_i by f_{k*-i}.

This is exactly what the multiplicative update does (with the factor of 2). So the approach is correct.

We have `b = fft_conv(f, f)`, which gives the full convolution of f with itself, length 2n-1.

The objective is `max_k b_k` (scale-invariant, so we can ignore the `2n/S^2` factor).

The subgradient of `max_k b_k` at f is: for the set P of indices where `b_k = max`, a subgradient is `sum_{k in P} alpha_k * (db_k/df)` where `alpha_k >= 0`, `sum alpha_k = 1`.

We use a soft version: `alpha_k = w_k` where `w_k = (b_k / M)^p` normalized.

The gradient `db_k/df_i = 2 * f_{k-i}` if `0 <= k-i < n`, else 0. (As derived earlier.)

So the full gradient at f is: `g_i = sum_k w_k * 2 * f_{k-i} * [0 <= k-i < n]`

This is `2 * sum_k w_k * f_{k-i}` (with f=0 outside [0,n-1]).

Let `f_ext[j] = f[j]` for `0 <= j < n`, else 0.

`g_i = 2 * sum_{k=0}^{2n-2} w_k * f_ext[k-i]`

Let `j = k - i`, so `k = j + i`:
`g_i = 2 * sum_{j} w_{j+i} * f_ext[j]`

This is the cross-correlation of `w` and `f` at lag `i`.

Using FFT: `cross_corr(i) = sum_j f[j] * w[j+i]`

This can be computed as: `convolve(f, reverse(w))[len(w)-1-i]`

Since `w` has length 2n-1, `len(w)-1 = 2n-2`.

`convolve(f, reverse(w))` has length `n + (2n-1) - 1 = 3n-2`.

`g_i = 2 * convolve(f, reverse(w))[2n-2-i]` for `i = 0, ..., n-1`.

import numpy as np
import time

def fft_conv(a, b):
    n, m = len(a), len(b)
    s = 1 << (n + m - 2).bit_length()
    return np.fft.irfft(np.fft.rfft(a, s) * np.fft.rfft(b, s))[:n + m - 1]

def get_score(f):
    b = fft_conv(f, f)
    s = f.sum()
    if s < 1e-10:
        return 1e30
    return float(2.0 * f.size * b.max() / (s * s))

def _grad(f, w):
    n = f.shape[0]
    c = fft_conv(f, w[::-1])
    return np.maximum(2.0 * c[n - 1:2 * n - 1][::-1], 0.0)

def cgrad(f, b, pp, mk):
    n = f.shape[0]
    M = b.max()
    if M <= 0:
        return np.zeros(n)
    w = np.power(np.maximum(b, 0.0) / M, pp)
    ws = w.sum()
    if ws < 1e-30:
        w = np.zeros_like(b)
        w[int(np.argmax(b))] = 1.0
        return _grad(f, w)
    w /= ws
    if mk < len(w):
        ix = np.argpartition(w, -mk)[-mk:]
        msk = np.zeros_like(w)
        msk[ix] = 1.0
        w *= msk
        w /= w.sum()
    return _grad(f, w)

def opt_run(f, dl, rng, pp, eta0):
    n = f.shape[0]
    f = np.maximum(np.abs(f), 1e-20)
    f /= f.sum()
    best, bs = f.copy(), get_score(f)
    eta, stale, rst, it = eta0, 0, 0, 0
    while time.monotonic() < dl:
        b = fft_conv(f, f)
        g = cgrad(f, b, pp, 200)
        gm = g.max()
        if gm < 1e-28:
            break
        f = np.maximum(f * np.exp(-eta * g / gm), 1e-20)
        f /= f.sum()
        it += 1
        if it % 5 == 0:
            sc = get_score(f)
            if sc < bs - 1e-14:
                bs, best, stale = sc, f.copy(), 0
            else:
                stale += 1
        if stale > 60:
            s = 0.05 + 0.1 * min(1.0, rst / 6.0)
            f = np.maximum(best * np.exp(s * rng.standard_normal(n)), 1e-20)
            f /= f.sum()
            stale, rst = 0, rst + 1
            eta = min(0.35, eta * 1.4)
        eta *= 0.9995
    sc = get_score(f)
    if sc < bs:
        bs, best = sc, f.copy()
    return best, bs

def propose_candidate(seed=42, budget_s=1100, **kwargs):
    rng = np.random.default_rng(seed)
    t0 = time.monotonic()
    dl = t0 + budget_s - 20.0
    n = len(height_sequence_1)
    x = np.arange(n, dtype=np.float64)
    inits = []
    p = np.clip(np.asarray(height_sequence_1, dtype=np.float64), 0.0, 1000.0)
    if p.sum() > 1e-10:
        inits.append(p / p.sum())
    inits.append(np.ones(n) / n)
    h = 0.5 * (1.0 - np.cos(2.0 * np.pi * x / (n + 1)))
    inits.append(h / h.sum())
    d = np.minimum(x, n - 1.0 - x) + 1.0
    for pw in (0.3, 0.8, 1.5):
        inits.append(d ** pw / (d ** pw).sum())
    for bw in (0.3, 0.45):
        w = max(2, int(n * bw / 2))
        c = np.zeros(n)
        c[:w] = 1.0
        c[n - w:] = 1.0
        inits.append(c / c.sum())
    for _ in range(3):
        r = np.abs(rng.standard_normal(n)) + 0.01
        r = 0.5 * (r + r[::-1])
        inits.append(r / r.sum())
    bf, bs = inits[0], 1e30
    for ini in inits:
        sc = get_score(ini)
        if sc < bs:
            bs, bf = sc, ini.copy()
    rem = dl - t0
    pd = rem * 0.60 / 4.0
    for i, (pp, e0) in enumerate([(80, 0.12), (30, 0.08), (10, 0.05), (30, 0.04)]):
        ph_dl = min(dl, t0 + (i + 1) * pd)
        if time.monotonic() >= ph_dl - 5:
            break
        fo, so = opt_run(bf.copy(), ph_dl, rng, pp, e0)
        if so < bs:
            bs, bf = so, fo.copy()
    if time.monotonic() < dl - 50:
        fs = 0.5 * (bf + bf[::-1])
        fs /= fs.sum()
        fo, so = opt_run(fs, dl - 30, rng, 30, 0.04)
        if so < bs:
            bs, bf = so, fo.copy()
    if time.monotonic() < dl - 3:
        for _ in range(300):
            if time.monotonic() > dl - 1:
                break
            tr = bf * np.exp(0.003 * rng.standard_normal(n))
            tr = np.maximum(tr, 1e-15)
            tr /= tr.sum()
            sc = get_score(tr)
            if sc < bs:
                bs, bf = sc, tr.copy()
    res = bf.copy()
    if res.sum() < 0.01:
        res *= 0.02 / res.sum()
    rl = [float(v) for v in res]
    if not np.isfinite(evaluate_sequence(rl)):
        rl = [1.0 / n] * n
    return rl
