```python
def evaluate_sequence(sequence: list) -> float:
    if not isinstance(sequence, list):
        return np.inf
    if not sequence:
        return np.inf
    for x in sequence:
        if isinstance(x, bool) or not isinstance(x, (int, float)):
            return np.inf
        if np.isnan(x) or np.isinf(x):
            return np.inf
    sequence = [float(x) for x in sequence]
    sequence = [max(0, x) for x in sequence]
    sequence = [min(1000.0, x) for x in sequence]
    n = len(sequence)
    b_sequence = np.convolve(sequence, sequence)
    max_b = max(b_sequence)
    sum_a = np.sum(sequence)
    if sum_a < 0.01:
        return np.inf
    return float(2 * n * max_b / (sum_a**2))
```

```python
def fft_conv(a, b):
    n, m = len(a), len(b)
    sz = 1 << (n + m - 2).bit_length()

    s = f.sum()
    return 2.0 * f.size * b.max() / (s * s)

def subgrad(f, w):

    n = f.shape[0]
    L = 2 * n - 1
    h = np.zeros(L)
    pk = np.where(w > 0)[0]
    h[pk] = w[pk]
```

**Idea: Coordinate descent on peaks**

After the main optimization, identify the top K peaks in the autocorrelation. For each peak, try to reduce it by adjusting the corresponding elements of f. This is like a coordinate descent on the peak values.

For peak at position k: (f*f)[k] = sum_i f[i] f[k-i]. To reduce this, we want to decrease f[i] for i where f[k-i] is large, i.e., i near k/2.

But this is essentially what the subgradient already does. So it's redundant.

**Idea: Coarse-to-fine**

1. Downsample f to length n/4 by averaging groups of 4.
2. Optimize the coarse sequence (much faster, n/4 iterations).
3. Upsample back to length n.
4. Optimize the full sequence starting from the upsampled initialization.
