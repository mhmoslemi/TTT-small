def logsumexp_gradient(f, tau, peaks=None):
    """Smooth gradient using log-sum-exp."""
    n = f.size
    b = fft_conv(f, f)
    # softmax weights
    b_max = b.max()
    w = np.exp((b - b_max) / tau)
    w /= w.sum()
    # Gradient: d/d f_j sum_k w_k * b_k ≈ 2 * sum_k w_k * f[k-j]

    L = 2*n-1
    h = w
    c = fft_conv(f, h[::-1])
    g = 2.0 * c[n-1:2*n-1]
    return g

def fft_conv(a, b):
    n, m = len(a), len(b)

    return np.fft.irfft(np.fft.rfft(a, size) * np.fft.rfft(b, size))[:n + m - 1]

    b = fft_conv(f, f)
    s = f.sum()
    return 2.0 * f.size * b.max() / (s * s)

    s = f.sum()
    if s < 1e-15:

Actually, let me think about it differently. If f[j] = g(j) for j < n/2 and f[j] = g(n-1-j) for j >= n/2 (i.e., f is symmetric), then b[n-1] = sum f[j]^2. But if f[j] = g(j) for j < n/2 and f[j] = h(n-1-j) for j >= n/2 with g != h, then b[n-1] = sum_{j=0}^{n-1} f[j]*f[n-1-j] = sum_{j} g_or_h(j)*g_or_h(n-1-j). This is more like a cross-correlation.

The key is to make the "overlap" at lag n-1 small while keeping other lags also small.

Let me think about a specific construction. Suppose f[j] = exp(-alpha*j) * exp(-beta*(n-1-j)) for some alpha, beta > 0. This is a "skewed Gaussian" peaking at (n-1)*beta/(alpha+beta) from the left. If alpha != beta, it's asymmetric.

For alpha = beta, it's a centered Gaussian (symmetric), giving score near 2.
For alpha >> beta, it peaks near the right end.
For alpha << beta, it peaks near the left end.

The optimal might be somewhere in between.

def fft_conv(a, b):
    n, m = len(a), len(b)
    size = 1 << (n + m - 2).bit_length()
