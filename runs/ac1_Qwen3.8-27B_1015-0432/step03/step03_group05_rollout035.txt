import numpy as np

def fft_conv(a, b):
    n, m = len(a), len(b)
    sz = 1 << (n + m - 2).bit_length()
    return np.fft.irfft(np.fft.rfft(a, sz) * np.fft.rfft(b, sz))[:n + m - 1]

def compute_score(f):
    b = fft_conv(f, f)
    s = f.sum()
    if s < 0.01:
        return np.inf
    return float(2.0 * f.size * b.max() / (s * s))

Let me trace through the gradient computation one more time to be sure:

f has length n. w has length L = 2n-1.
w[::-1] has length L.
F = rfft(f, sz) where sz >= 2n-1.
Wr = rfft(w[::-1], sz).
c = irfft(F * Wr, sz) gives the full convolution of f and w[::-1], length n + L - 1 = n + 2n - 2 = 3n - 2.

We want g[i] = 2 * sum_{j=0}^{n-1} f[j] * w[i+j] for i = 0, ..., n-1.

c[k] = sum_{j=0}^{n-1} f[j] * w_rev[k-j] where w_rev = w[::-1], so w_rev[m] = w[L-1-m].

c[k] = sum_{j=0}^{n-1} f[j] * w[L-1-k+j]

We want g[i] = 2 * sum_j f[j] * w[i+j].

Setting L-1-k+j = i+j: L-1-k = i, so k = L-1-i = 2n-2-i.

g[i] = 2 * c[2n-2-i].

For i=0: g[0] = 2*c[2n-2].
For i=n-1: g[n-1] = 2*c[n-1].

So g = 2 * c[n-1 : 2n-1][::-1] (indices n-1, n, ..., 2n-2, reversed).

In code: `g = 2.0 * c[n-1:L][::-1]` where L = 2n-1.

c[n-1:L] = c[n-1:2n-1] which is c[n-1], c[n], ..., c[2n-2]. That's n elements.
Reversed: c[2n-2], c[2n-3], ..., c[n-1].

So g[0] = 2*c[2n-2], g[1] = 2*c[2n-3], ..., g[n-1] = 2*c[n-1]. ✓
