Wait, if tk >= 2n-1, we're computing the sum over ALL lags, which is `sum_k a[k-i] * a[i]` for each i... that's just `a_i * sum_j a_j = a_i * sum_a`. So the gradient would be proportional to `a` itself, which would just shrink `a` uniformly. That's not useful.

Actually wait, let me re-derive. The convolution at lag k is `cv_k = sum_j a_j * a_{k-j}` (with valid indices). The derivative of `cv_k` with respect to `a_i` is `a_{k-i}` (when valid). So the gradient of `max(cv)` (at the argmax lag k*) with respect to `a_i` is `a_{k*-i}`.

For the average over all lags: `sum_k cv_k = (sum a)^2`, so `d(sum_k cv_k)/da_i = 2 * a_i * sum_a`. The gradient of the average is `2*a_i`. So averaging the gradient over all lags gives a multiple of `a` itself. That's just scaling, not useful for shaping.

So for the fine-tuning, using all lags is not helpful. We should use the top-k that are *above average*, or use a weighted scheme.
