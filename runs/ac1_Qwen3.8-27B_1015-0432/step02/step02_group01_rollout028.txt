g[j] = sum_{k: b[k]=M} 2*f[k-j] (where f[k-j]=0 if out of bounds)

With top-k weighting: g[j] = sum_k w[k]*2*f[k-j]

Now, how to compute this efficiently?
g[j] = 2 * sum_k w[k]*f[k-j]

This is 2 * (cross-correlation of w and f at lag j), but with the specific indexing.

Let me define: g[j] = 2 * sum_k w[k] * f[k-j] for j = 0..n-1.

Using FFT:
Let w have length 2n-1 (same as b), f has length n.
f_flip[i] = f[n-1-i] (reverse f)

conv(w, f_flip)[m] = sum_k w[k] * f_flip[m-k] = sum_k w[k] * f[n-1-(m-k)] = sum_k w[k] * f[n-1-m+k]

We want sum_k w[k] * f[k-j]. Set n-1-m+k = k-j → n-1-m = -j → m = n+1-j.

Wait: n-1-m+k = k-j → n-1-m = -j → m = n-1+j.

So sum_k w[k]*f[k-j] = conv(w, f_flip)[n-1+j]

Let me verify: m = n-1+j
conv(w, f_flip)[n-1+j] = sum_k w[k]*f_flip[n-1+j-k] = sum_k w[k]*f[n-1-(n-1+j-k)] = sum_k w[k]*f[k-j] ✓

So: g[j] = 2 * conv(w, f_flip)[n-1+j] for j = 0..n-1.

The array conv(w, f_flip) has length (2n-1) + n - 1 = 3n-2.
We need indices n-1 to n-1+(n-1) = 2n-2, which is within [0, 3n-3]. ✓

So the gradient is simply:
g = 2.0 * c1[n-1:2n-1] where c1 = fft_conv(w, f_flip)

And we take the positive part since we want to decrease f where gradient is positive.

gc = fft_conv(w, f_r) where f_r = f[::-1]
grad = gc[f.size - 1:2 * f.size - 1]
