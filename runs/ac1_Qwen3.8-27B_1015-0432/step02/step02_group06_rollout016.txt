Objective: `L = sum_{k=0}^{2n-2} w[k] * b[k] = sum_k w[k] * sum_i f[i] f[k-i]`

`∂L/∂f[j] = sum_k w[k] * ∂b[k]/∂f[j]`

Now, `∂b[k]/∂f[j]`: `b[k]` involves `f[j]` when `j` appears in the sum, i.e., when `i=j` (giving `f[j]*f[k-j]`) or when `k-i=j` i.e., `i=k-j` (giving `f[k-j]*f[j]`).

So `∂b[k]/∂f[j] = f[k-j] + f[j-k]` (with the convention that `f[m]=0` for `m<0` or `m>=n`).

Note: if `k=j` then `f[k-j] = f[0]` and `f[j-k] = f[0]`, so `∂b[j]/∂f[j] = 2*f[0]`.
If `k=j+n` then... wait, `k` only goes up to `2n-2` and `j` is in `[0,n-1]`.

So `∂L/∂f[j] = sum_k w[k] (f[k-j] + f[j-k])`

First term: `sum_k w[k] f[k-j]` where `f[k-j]` is nonzero only when `0 <= k-j < n`, i.e., `j <= k < j+n`.
= `sum_{k=j}^{j+n-1} w[k] f[k-j]`
= `sum_{m=0}^{n-1} w[m+j] f[m]` (letting `m = k-j`)

This is exactly `conv(w, f_rev)[n-1+j]` where `f_rev = f[::-1]`:
`conv(w, f_rev)[n-1+j] = sum_i w[i] f_rev[n-1+j-i] = sum_i w[i] f[n-1-(n-1+j-i)] = sum_i w[i] f[i-j]`

Hmm wait, that gives `f[i-j]` not `f[k-j]`. Let me redo.

`f_rev[m] = f[n-1-m]`
`conv(w, f_rev)[p] = sum_i w[i] * f_rev[p-i]` (sum over valid i)
`= sum_i w[i] * f[n-1-(p-i)]`
`= sum_i w[i] * f[n-1-p+i]`

For `p = n-1+j`:
`= sum_i w[i] * f[n-1-(n-1+j)+i]`
`= sum_i w[i] * f[i-j]`

`f[i-j]` is nonzero when `0 <= i-j < n`, i.e., `j <= i < j+n`.
`= sum_{i=j}^{j+n-1} w[i] * f[i-j]`
`= sum_{m=0}^{n-1} w[j+m] * f[m]` (letting `m = i-j`)

This matches the first term! ✓

Second term: `sum_k w[k] f[j-k]` where `f[j-k]` is nonzero when `0 <= j-k < n`, i.e., `j-n+1 <= k <= j`.
Since `k >= 0` and `j < n`: `0 <= k <= j`.
= `sum_{k=0}^{j} w[k] f[j-k]`

This is `conv(w, f)[j]` (the j-th entry of the full convolution of w and f):
`conv(w, f)[j] = sum_k w[k] f[j-k]` (sum over valid k where both are in range)
For `j < n < 2n-1 = len(w)`: `= sum_{k=0}^{j} w[k] f[j-k]` ✓

So the total gradient is:
`grad[j] = conv(w, f_rev)[n-1+j] + conv(w, f)[j]`

The key insight is that we're minimizing `max(b)/(sum(a))^2` where `b = conv(a,a)`. Since the score is scale-invariant, we fix `sum(a) = 1` and minimize `max(b)`.

The optimal solution for nonnegative `a` with `sum(a) = 1` to minimize `max(conv(a,a))` is related to the "minimum autocorrelation" problem.
