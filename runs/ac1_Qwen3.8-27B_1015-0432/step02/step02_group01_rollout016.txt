For large β, this approaches max(c[k]). The gradient is:
∂G_β/∂f[i] = (1/β) * sum_k (β * exp(β*c[k]) / sum_j exp(β*c[j])) * ∂c[k]/∂f[i]
= sum_k p_k * ∂c[k]/∂f[i]
where p_k = exp(β*c[k]) / sum_j exp(β*c[j])

This is exactly what the temperature-weighted gradient computes (with p_k = w_k / sum(w)).

So the approach is already computing the gradient of the log-sum-exp smoothed objective. Good.
