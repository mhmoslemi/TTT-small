The key issue: the subgradient method converges slowly near the optimum because the active set changes. Near the optimum, many lags are at approximately the same height, and we need to balance them all.

A better approach for the final phase: **Alternating direction method**

Actually, even simpler: **Iterative clipping / projection**

1. Start with a (normalized)
2. Compute conv = a*a
3. For each lag k where conv[k] > L:
   - Compute the gradient of conv[k] w.r.t. a
   - Reduce a along this gradient direction
4. Renormalize
5. Repeat, decreasing L

This is essentially what the subgradient does, but with a more structured approach.

Let me think about another angle: **The structure of the optimal solution**

At the optimum of min max_j (a*a)[j] s.t. sum a = 1, a >= 0:
- By KKT, there exist multipliers y[k] >= 0 for constraints (a*a)[k] <= L
- For active constraints (where (a*a)[k] = L): y[k] > 0
- Stationarity: for j with a[j] > 0: sum_k y[k] * 2*a[k-j] = lambda (for valid k-j)
- This means: for all active j: sum_k y[k] * a[k-j] = const

So the "dual" sequence y acts as a weight, and the condition is that the convolution y*a is constant on the support of a.

This suggests an iterative algorithm:
1. Guess active lags A (where (a*a)[k] ≈ L)
2. Solve for y: minimize subject to A^T y = 1 (some normalization), y >= 0
   Actually, we want y such that (y*a)(j) is constant on supp(a)
3. Update a to satisfy this

Instead of additive subgradient, use multiplicative updates:

This naturally maintains non-negativity and can be more effective for "spreading" the mass.

Algorithm:
1. Compute conv, find top-K lags with values v_1 >= v_2 >= ... >= v_K
2. Compute the "excess" at each: e_i = v_i - mean(v_1,...,v_K)
3. For each peak lag k_i with excess e_i, reduce a along the gradient of conv[k_i]
4. This pushes down the peaks and (hopefully) leaves the others unchanged

    parent = np.clip(np.asarray(height_sequence_1, dtype=np.float64), 0.0, 1000.0)
    n = parent.size
    s0 = float(parent.sum())

    if n < 2 or s0 < 0.01 or not np.all(np.isfinite(parent)):
        n = 2048
        t = np.arange(n, dtype=np.float64)
        parent = 1.0 + 0.4 * np.cos(2.0 * np.pi * t / n)
        s0 = float(parent.sum())

    best = parent.copy()
    best_score = float(evaluate_sequence(best.tolist()))

    # Phase 1: Main subgradient descent (50% budget)
    frac = deadline - t_start
    t1 = t_start + 0.50 * frac
    a = parent / s0
    a, lb, ls = opt_pass(a, n, s0, best, best_score, t1, max_iter=300000, lr0=0.35, beta0=0.82)
    if ls < best_score:
        best_score, best = ls, lb

    # Phase 2: Refined pass with lower initial lr (25% budget)
    remaining = deadline - time.monotonic()
    if remaining > 80:
        t2 = time.monotonic() + 0.90 * remaining
        a2 = best / float(best.sum())
        a2, lb2, ls2 = opt_pass(a2, n, s0, best, best_score, t2, max_iter=400000, lr0=0.18, beta0=0.88)
        if ls2 < best_score:
            best_score, best = ls2, lb2

    # Phase 3: Multiplicative polishing (15% budget)
    remaining = deadline - time.monotonic()
    if remaining > 40:
        t3 = time.monotonic() + 0.90 * remaining
        a3 = best / float(best.sum())
        a3, lb3, ls3 = multiplicative_pass(a3, n, s0, best, best_score, t3, max_iter=100000)
        if ls3 < best_score:
            best_score, best = ls3, lb3

    # Phase 4: Local perturbations (remaining)
    base = best.copy()
    while time.monotonic() < deadline - 8.0:
        cand = base.copy()
        nperts = int(rng.integers(1, 4))
        for _ in range(nperts):
            w = int(rng.integers(max(4, n // 80), max(5, n // 15)))
            st = int(rng.integers(0, max(1, n - w)))
            scale = np.exp(float(rng.normal(0.0, 0.012)))
            cand[st:st + w] *= scale
        cand = np.clip(cand, 0.0, 1000.0)
        if cand.sum() < 0.01:
            continue
        sc = float(evaluate_sequence(cand.tolist()))
        if np.isfinite(sc) and sc < best_score:
            best_score, best, base = sc, cand, cand

    out = np.clip(best, 0.0, 1000.0)
    if out.size < 1 or not np.all(np.isfinite(out)) or out.sum() < 0.01:
        out = parent
    return [float(x) for x in out]
