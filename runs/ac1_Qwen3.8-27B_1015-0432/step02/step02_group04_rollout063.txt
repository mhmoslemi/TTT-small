One idea: **use the structure of the problem more directly**. The objective is `2n * max_k (f*f)_k / (sum f)^2`. With sum f = 1, it's `2n * max_k (f*f)_k`.

The key constraint is that `(f*f)_k <= M` for all k, where M = max_k (f*f)_k. This is a system of quadratic constraints. We want to minimize M subject to sum f = 1, f >= 0.

This is a QCQP (quadratically constrained quadratic program), which is NP-hard in general. But for our specific structure (autocorrelation), there might be efficient approaches.

One approach: **alternating minimization**. Fix the peak position k*, minimize the convolution at k* by adjusting f. Then move to the next peak position. Repeat.

For a fixed peak position k*, the constraint is `sum_i f_i * f_{k*-i} <= M`. The gradient is `2 * f_{k*-i}` (reversed). The mirror descent approach is already doing this.

For the specific case of a nonnegative sequence with fixed sum, the optimal `|F|^2` should be as flat as possible (white noise spectrum), which corresponds to a sequence with random-looking coefficients. But the nonnegativity constraint makes this non-trivial.
