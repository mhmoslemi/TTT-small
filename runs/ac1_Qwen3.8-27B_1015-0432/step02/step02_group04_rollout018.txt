Actually, let me think about this differently. The LP has a very special structure: A is upper triangular with constant diagonals. This means the problem is:

Maximize sum_{j=0}^{n-1} g_j
s.t. sum_{j=0}^{min(m,n-1)} a[m-j] g_j ≤ M for m = 0, ..., 2n-2
     g_j ≥ 0

The constraints are:
- m=0: a[0] g_0 ≤ M
- m=1: a[1] g_0 + a[0] g_1 ≤ M
- m=2: a[2] g_0 + a[1] g_1 + a[0] g_2 ≤ M
- ...
- m=n-1: a[n-1] g_0 + ... + a[0] g_{n-1} ≤ M
- m=n: a[n-1] g_1 + ... + a[0] g_{n-1} ≤ M
- ...
- m=2n-2: a[n-1] g_{n-1} ≤ M

This is a "banded" LP. I could potentially exploit the structure, but for now let me just use the sparse matrix formulation.

Given the time constraints, let me design the program:

1. **Initialization**: Use parent, flat-top, Hann, various asymmetric shapes.
2. **Phase 1**: Mirror descent with log-sum-exp smoothing (fast, many iterations).
3. **Phase 2**: LP-based direction finding with the sparse constraint matrix (fewer iterations but bigger steps).
4. **Phase 3**: Final mirror descent polishing.
5. **Polishing**: Coordinate-wise or small perturbation search.

def grad_smooth(f, C, T):
    """Gradient of log-sum-exp smoothed max of C, backpropagated through convolution."""
    n = f.size
    cs = C - C.max()
    p = np.exp(cs / T)
    p /= p.sum()
    N = 1 << (C.size + n - 1).bit_length()
    P = np.fft.rfft(p, N)
    F = np.fft.rfft(f, N)
    return 2.0 * np.fft.irfft(P * np.conj(F), N)[:n]

def grad_argmax(f, k_star):
    n = f.size
    lo = max(0, k_star - n + 1)
    hi = min(k_star, n - 1)
    grad = np.zeros(n)
    if lo <= hi:
        grad[lo:hi+1] = 2.0 * f[k_star-hi:k_star-lo+1][::-1]
    return grad
