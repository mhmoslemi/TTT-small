Let me think about what structure actually minimizes the peak autocorrelation for nonnegative sequences.

Key insight: We want b_k to be as flat as possible. For nonnegative a, this means we want the "mass" to be distributed so that all autocorrelation lags are approximately equal.

A sequence with "bursty" structure (high at two separated points) would give a peaked autocorrelation. A smooth spread-out sequence gives a more gradual autocorrelation.

The uniform sequence gives b_k that goes from a_0^2 (small) up to 1/n (at center) and back down. The peak is 1/n, score = 2.

To beat 2, we need to reduce the peak below 1/n. The peak is at the center lag. We can reduce it by making the sequence "anti-correlated with itself at the center lag", but since all values are nonnegative, we can't do true anti-correlation.

However, we CAN reduce the center lag by making the sequence "light" in the middle and "heavy" at the edges. For example:
- a_j = 1 for j near 0 and j near n-1, 0 in the middle.
- This reduces the cross-terms at the center lag.

But it increases the autocorrelation at lags near 0 and n (where the two "bumps" overlap with themselves).

The optimal trade-off is somewhere in between. This is essentially a "water-filling" problem on the autocorrelation.

For the optimization, the multiplicative gradient descent approach should work. The key is to start from a good initial point and have an effective gradient.

- The parent `height_sequence_1` (already optimized to 1.5156)
- A "two-bump" structure: high at both ends, low in middle
- The parent, modified by pushing mass to the edges

For the gradient, the subgradient of max(b) at the maximizing lag k* is:
∇b_k* = (a_{k*-j})_j for j=0..n-1 (with a_i=0 outside [0,n-1])

a_j <- a_j * exp(-eta * grad_j) / normalization

This decreases a_j where the gradient is large, which makes sense: if a_j contributes a lot to the peak autocorrelation, we decrease it.

import numpy as np
import time

def fft_conv(a, b):
    n, m = len(a), len(b)
    size = 1 << (n + m - 2).bit_length()
    return np.fft.irfft(np.fft.rfft(a, size) * np.fft.rfft(b, size))[:n + m - 1]

def score_norm(f):
    b = fft_conv(f, f)
    return 2.0 * f.size * b.max()

def subgrad(f, b, top_k):
    """Hard subgradient: average of shifted f over top-k lags."""
    n = f.size
    if top_k <= 0:
        top_k = 1
    top_lags = np.argpartition(b, -top_k)[-top_k:]
    # grad[j] = (1/top_k) * sum_{lag in top_lags} f[lag-j] (clipped)
    grad = np.zeros(n)
    for lag in top_lags:
        lo = max(0, lag - n + 1)
        hi = min(n, lag + 1)
        # grad[lag-hi+1 : lag-lo+1] += f[lo:hi][::-1]
        if hi > lo:
            grad[lag - hi + 1: lag - lo + 1] += f[lo:hi][::-1]
    grad /= top_k
    return grad

def optimize(f, deadline, rng, max_iters=5000):
    """Multiplicative subgradient descent with adaptive step."""
    n = f.size
    f = f.astype(np.float64).copy()
    S = f.sum()
    if S < 1e-15:
        return f.copy(), np.inf
    f /= S
    best_f = f.copy()
    best_sc = score_norm(f)
    eta = 0.02
    top_k = max(1, n // 50)
    stagnant = 0
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        b = fft_conv(f, f)
        M = b.max()
        sc = 2.0 * n * M
        
        if sc < best_sc - 1e-10:
            best_sc = sc
            best_f = f.copy()
            stagnant = 0
        else:
            stagnant += 1
        
        if stagnant > 200:
            # Restart with perturbation
            f = best_f * np.exp(0.05 * rng.standard_normal(n))
            f = np.maximum(f, 1e-15)
            f /= f.sum()
            stagnant = 0
            top_k = max(1, n // 50)
            eta = 0.02
            continue
        
        # Anneal top_k
        progress = min(1.0, it / max_iters)
        top_k = max(1, int(n // (50 + 100 * progress)))
        
        g = subgrad(f, b, top_k)
        gmax = g.max()
        if gmax < 1e-30:
            break
        g /= gmax
        
        # Line search: try decreasing eta until we improve
        best_trial = None
        best_trial_sc = sc
        for factor in [1.0, 0.7, 0.5, 0.3, 0.2]:
            t = eta * factor
