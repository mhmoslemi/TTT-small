Let me think about this more carefully. We want to minimize max(conv(f,f)) / (sum f)^2.

By the properties of convolution:
- (sum f)^2 = sum_k conv(f,f)[k] (total mass of the conv)
- The conv has 2n-1 nonnegative terms
- max conv >= (sum of conv) / (2n-1) = (sum f)^2 / (2n-1)

So score >= 2n * (sum f)^2 / (2n-1) / (sum f)^2 = 2n/(2n-1) ≈ 1 for large n.

So the theoretical lower bound is about 1, achieved when the conv is perfectly flat (all 2n-1 terms equal). But can we achieve a flat conv with a nonnegative f?

A flat conv of height h means conv(f,f)[k] = h for all k = 0, ..., 2n-2. This is a "root" or "factor" problem: find f such that f*f = h * [1,1,...,1]. In the z-transform domain: F(z)^2 = h * (1 + z + ... + z^{2n-2}) = h * (1-z^{2n-1})/(1-z).

F(z) = sqrt(h * (1-z^{2n-1})/(1-z)). For this to be a polynomial with nonnegative coefficients, we need (1-z^{2n-1})/(1-z) = 1 + z + ... + z^{2n-2} to be a perfect square, which it's not in general.

So a perfectly flat conv is impossible. The question is how close we can get.

For the "fourier domain" perspective: if F is the DFT of f, then the DFT of conv(f,f) is |F|^2 (with appropriate scaling). So we want |F[k]|^2 to be as flat as possible (equal for all k). This means |F[k]| = constant, i.e., f has a "flat spectrum" in magnitude. But f must be nonnegative!

For a nonnegative f, F[0] = sum f > 0 and F[k] for k≠0 can be positive or negative. |F[k]| being constant means f is approximately complex-exponential-like, which contradicts nonnegativity (a nonnegative function has a peaked spectrum at k=0).

So there's a fundamental tension: nonnegativity forces a peaked spectrum, while flatness of the conv requires a flat spectrum.
