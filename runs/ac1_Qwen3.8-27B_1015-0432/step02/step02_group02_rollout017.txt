The minimum for n=2: we want to minimize max(x^2, 2xy, y^2) subject to x+y=1, x,y>=0.
By symmetry, assume x >= y. Then x >= 0.5, and x^2 >= y^2.
We need x^2 <= 2xy (otherwise x^2 is the max). x^2 <= 2x(1-x) → x <= 2(1-x) → 3x <= 2 → x <= 2/3.
Also need 2xy <= x^2, i.e., 2y <= x, i.e., 2(1-x) <= x, i.e., x >= 2/3.
So at x = 2/3, y = 1/3: max = 2*(2/3)*(1/3) = 4/9. And x^2 = 4/9. All equal!
Score = 4 * 4/9 = 16/9 ≈ 1.778.

So for n=2, the optimal is [2/3, 1/3] (or [1/3, 2/3]) giving score 16/9 ≈ 1.778.
