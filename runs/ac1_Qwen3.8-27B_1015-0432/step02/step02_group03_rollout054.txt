Let me use the log-sum-exp (or a soft-max) as a smooth approximation to the max:
- soft_max_k = T * log(sum_k exp(conv_k / T))
- As T → 0, this approaches max_k conv_k
- The gradient is: d/d(a[i]) soft_max = sum_k (exp(conv_k/T) / sum_j exp(conv_j/T)) * 2*a[k-i]
- This is a weighted average of the per-lag gradients, with weights proportional to exp(conv_k/T)

This is smooth and always well-defined. We can start with a moderate T and decrease it.
