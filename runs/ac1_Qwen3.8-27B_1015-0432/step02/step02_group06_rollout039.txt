Let me also think about the LP-inspired update. The idea is:
- Given f, find g that maximizes sum(g) subject to (f*g)[k] <= M for all k, g >= 0
- Then set f_new = (1-t)*f + t*g (normalized)

The constraint (f*g)[k] = sum_j f[j]*g[k-j] <= M.
This is a linear constraint on g. The matrix is a Toeplitz matrix T where T[k,j] = f[k-j] (for valid indices).

A simple iterative approach: 
- Start with g = ones/n
- Iterate: for each k, g must satisfy sum_j T[k,j]*g[j] <= M
- This is like a "water filling" / "projection onto intersection of half-spaces"

Actually, a simpler approach: the dual problem.
Primal: max 1^T g s.t. T g <= M*1, g >= 0
Dual: min M * 1^T y s.t. T^T y >= 1, y >= 0

The dual has 2n-1 variables (y) and n constraints (T^T y >= 1). The primal has n variables and 2n-1 constraints.

For the primal, a simple projected gradient / subgradient method:
- g_new = max(0, g - alpha * (T^T_y * ... ))... this gets complicated.

Alternative: Since we just need a direction, we can use a simple heuristic:
- Compute b = conv(f, f), M = max(b)
- The "tightest" constraints are where b[k] is close to M
- Set g = 1 / (something related to f) to spread out the convolution

Actually, the LP update is:
- Given f (fixed), the best g satisfies: for each lag k, (f*g)[k] = sum_j f[j]*g[k-j] <= M
- If f is relatively flat, then g should also be relatively flat
- If f has peaks, g should be "anti-peaked" (put more mass where f has less)

A simple heuristic: g[j] proportional to 1/sqrt(f[j]) or 1/f[j] (to equalize the contributions).

import numpy as np
import time

def fft_conv(a, b):
    n, m = len(a), len(b)
    size = 1 << (n + m - 2).bit_length()
    return np.fft.irfft(np.fft.rfft(a, size) * np.fft.rfft(b, size))[:n + m - 1]

def fast_score(f):
    s = f.sum()
    if s < 1e-15:
        return np.inf
    b = fft_conv(f, f)
    return float(2 * len(f) * b.max() / (s * s))

def full_grad(f, beta):
    n = f.size
    b = fft_conv(f, f)
    M = max(b.max(), 1e-30)
    w = np.exp(beta * (b / M - 1.0))
    f_rev = f[::-1]
    L = len(w) + n - 1
    size = 1 << (L - 1).bit_length()
    w_hat = np.fft.rfft(w, size)
    t1 = np.fft.irfft(w_hat * np.fft.rfft(f_rev, size))[:L]
    t2 = np.fft.irfft(w_hat * np.fft.rfft(f, size))[:L]
    grad = t1[n - 1:2 * n - 1] + t2[:n]
    return grad, b, M

def gd_step(f, grad, eta):
    gmax = grad.max()
    if gmax < 1e-30:
        return f
    f_new = f * np.exp(-eta * grad / gmax)
    f_new = np.maximum(f_new, 1e-25)
    f_new /= f_new.sum()
    return f_new

import numpy as np
import time


def fft_conv(a, b):
    n, m = len(a), len(b)
    size = 1 << (n + m - 2).bit_length()
    return np.fft.irfft(np.fft.rfft(a, size) * np.fft.rfft(b, size))[:n + m - 1]


def fast_score(f):
    s = f.sum()
    if s < 1e-15:
        return np.inf
    b = fft_conv(f, f)
    return float(2 * len(f) * b.max() / (s * s))


def full_grad(f, beta):
    n = f.size
    b = fft_conv(f, f)
    M = max(b.max(), 1e-30)
    w = np.exp(beta * (b / M - 1.0))
    f_rev = f[::-1]
    L = len(w) + n - 1
    size = 1 << (L - 1).bit_length()
    w_hat = np.fft.rfft(w, size)
    t1 = np.fft.irfft(w_hat * np.fft.rfft(f_rev, size))[:L]
    t2 = np.fft.irfft(w_hat * np.fft.rfft(f, size))[:L]
    grad = t1[n - 1:2 * n - 1] + t2[:n]
    return grad, b, M


def init_hann(n):
    x = np.arange(n, dtype=np.float64)
    h = 0.5 * (1.0 - np.cos(2.0 * np.pi * x / (n + 1)))
    h = np.maximum(h, 1e-15)
    return h / h.sum()


def init_tri(n):
    x = np.arange(n, dtype=np.float64)
    t = 1.0 - np.abs(2.0 * x / (n - 1) - 1.0)
    t = np.maximum(t, 1e-15)
    return t / t.sum()

    x = np.arange(n, dtype=np.float64)
    c = (n - 1) / 2.0
    a = np.exp(-0.5 * ((x - c) / (sf * n)) ** 2)
    return a / a.sum()
