The constraints are: for each k in [0, 2n-2], sum_j a[j]*a[k-j] <= t. But these are quadratic (bilinear) constraints, so it's not a standard QP. However, for fixed a, the constraint "conv(a,a)[k] <= t" is linear in the "other" variable if we split... no, it's quadratic.

Actually, we can reformulate: minimize t subject to a >= 0, sum(a) = 1, and a^T T_k a <= t for all k, where T_k is a symmetric permutation matrix (or sub-permutation). This is a SOCP-like problem but with quadratic constraints, making it a QCQP. CVXPY might handle it with DCP if we use the right formulation... but quadratic forms with variable coefficients are generally non-convex (a^T P a is convex only if P is PSD).

The permutation matrices T_k: (T_k a)_i = a[k-i]. So a^T T_k a = sum_i a_i * a[k-i] = conv(a,a)[k]. The matrix T_k is a permutation matrix (or sub-permutation for boundary k). Permutation matrices are symmetric and have eigenvalues on the unit circle, so they're not PSD in general. This means the problem is NOT convex in the a variables.

So we can't use standard convex optimization. The mirror descent / subgradient approach is the way to go.

Let me also consider: since the objective is scale-invariant, and we're working on the simplex, the problem is to find a point on the simplex that minimizes the max autocorrelation. This is a min-max problem on a compact set, so a minimum exists.
