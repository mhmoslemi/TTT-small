For the uniform vector, b[n-1] = 1/n and sum f[j]^2 = 1/n. So max(b) = 1/n and score = 2.

So the tradeoff is: reducing b[n-1] increases some other b[k]. The minimum of max(b) is achieved when all b[k] at the "active" k's are equal.

This is like a magic rectangle / Sidon sequence problem in continuous form.

For the optimization, the key is to have the subgradient push down all active peaks simultaneously. The multiplicative update does this naturally.
