```python
    n = a.size

    thresh = m * (1 - frac)
    idx = np.where(cv >= thresh)[0]
    T = len(idx)
    if T == 0:
        T = 8
        idx = np.argpartition(cv, -T)[-T:]
    g = np.zeros(n)
    for kk in idx:
        kk = int(kk)
        lo = max(0, kk - n + 1)
        hi = min(n - 1, kk)
        if lo <= hi:
            g[lo:hi+1] += a[kk-hi:kk-lo+1][::-1]
    g /= float(len(idx))
    return g
```

This could be more effective because as the autocorrelation flattens, more elements are included, giving a smoother gradient. But if the threshold fraction is too large, it approaches the full gradient (averaging over all 2n-1 elements), which might be less effective.
