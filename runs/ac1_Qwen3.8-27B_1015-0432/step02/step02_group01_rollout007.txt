def fft_conv(a, b):
    n, m = len(a), len(b)
    size = 1 << (n + m - 2).bit_length()
    return np.fft.irfft(np.fft.rfft(a, size) * np.fft.rfft(b, size))[:n + m - 1]

def score_of(f):
    b = fft_conv(f, f)
    return 2.0 * f.size * b.max()

    ws = w.sum()
    if ws < 1e-30:

The problem is: minimize max_m (f⊛f)[m] subject to f >= 0, sum(f) = 1.

This is a non-convex problem (max of quadratic forms). But it has some structure:

- The objective is the max of 2n-1 quadratic forms

The previous approach (multiplicative gradient descent) is essentially a projected gradient method on the simplex, using the multiplicative update to stay positive.

- f >= 0
- sum(f) = 1

- For inactive f[i] = 0: the gradient of (f⊛f)[m*] w.r.t. f[i] should be >= 0 (KKT)

This means: at the optimal f, the "directional derivative" of the max autocorrelation should be zero in all feasible directions.

The multiplicative gradient descent is already converging to such a point (approximately). The question is whether it converges fast enough.
