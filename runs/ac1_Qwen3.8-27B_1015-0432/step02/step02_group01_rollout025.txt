For the uniform sequence, c[k] = (n - |k - (n-1)|) * A^2, so the max is at k = n-1 and equals n*A^2.

For a non-uniform sequence, the convolution shape changes. If the sequence is "peaked" at one end, the convolution will be peaked at the corresponding end. If it's "peaked" in the middle, the convolution will be peaked in the middle.

The key insight is: the maximum of the convolution is at least the average value of the convolution. The sum of all convolution values is:
sum_k c[k] = (sum_i a[i]) * (sum_j a[j]) = (sum a)^2

There are 2n-1 values of c[k]. So the average is (sum a)^2 / (2n-1).

Therefore, max c[k] >= (sum a)^2 / (2n-1).

Score >= 2n * (sum a)^2 / ((2n-1) * (sum a)^2) = 2n / (2n-1).

For n = 4806: 2*4806/(2*4806-1) = 9612/9611 ≈ 1.000104.

So the theoretical lower bound is approximately 1.0001, not 2! The uniform sequence achieves 2, but it's not optimal!
