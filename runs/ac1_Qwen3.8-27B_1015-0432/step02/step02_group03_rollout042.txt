import numpy as np
import time

def _convolve_fft(a, fs):
    fa = np.fft.rfft(a, n=fs)
    return np.fft.irfft(fa * fa, n=fs)

def _subgrad(a, active_lags):
    n = a.size
    g = np.zeros(n)
    for k in active_lags:
        k = int(k)
        lo = max(0, k - n + 1)
        hi = min(n - 1, k)
        if lo <= hi:
            g[lo:hi+1] += a[k-hi:k-lo+1][::-1]
    return g / max(1, len(active_lags))

def _descent(a0, fs, target_sum, deadline, eta0, decay, frac, cap, max_iter, rng, multi=False):
    n = a0.size
    a = a0.copy()
    best = a.copy()
    best_sc = 2.0 * n * float(_convolve_fft(a, fs).max()) / (a.sum()**2)
    eta = eta0
    mom = np.zeros(n)
    stall = 0
    for it in range(max_iter):
        if time.monotonic() > deadline:
            break
        c = _convolve_fft(a, fs)
        mx = float(c.max())
        sc = 2.0 * n * mx / (a.sum()**2)
        if sc < best_sc - 1e-13:
            best_sc = sc
            best = a.copy()
            stall = 0
        else:
            stall += 1
        if stall > 2000:
            break
        # Active set
        thresh = mx * (1.0 - frac)
        act = np.where(c >= thresh)[0]
        act = act[(act >= 0) & (act < 2*n-1)]
        if len(act) > cap:
            idx = np.argpartition(c[act], -cap)[-cap:]
            act = act[idx]
        g = _subgrad(a, act)
        g -= g.mean()  # maintain sum constraint
        # Update
        if multi:
            gm = np.abs(g).max()
            if gm > 1e-14:
                a = a * np.exp(-eta * g / gm)
        else:
            mom = 0.85 * mom + 0.15 * g
            a = np.maximum(a - eta * mom, 0.0)
        s = a.sum()
        if s < 1e-10:
            break
        a *= target_sum / s
        eta *= decay
    return best, best_sc

For convex problems, we can use:
- Subgradient method (what the previous code does)
- Cutting plane method
- ellipsoid method
- Mirror descent
- FISTA (if we smooth the objective)

But for a 4498-dimensional problem, most of these are impractical. The subgradient method is probably the way to go, but we can improve it.

One key improvement: **use the "subgradient of the smoothed objective"** where we smooth the max with a kernel. Specifically, use:
`f_τ(a) = τ * log(sum_k exp(c[k]/τ))`

This is a smooth approximation to `max_k c[k]` that converges as τ→0. Its gradient is:
`∇f_τ(a) = sum_k p_k * ∇c[k]` where `p_k = exp(c[k]/τ) / sum_j exp(c[j]/τ)`

This is a probabilistically-weighted average of the subgradients, which is much smoother than the raw subgradient.

The cost: we need to compute `exp(c[k]/τ)` for all 2n-1 lags, which is O(n) per iteration (the FFT is already O(n log n)). This should be fine.

Let me implement this approach:

```python
def _smooth_grad(a, c, tau):
    n = a.size
    c = c[:2*n-1]
    # Numerical stability
    cm = c - c.max()
    exp_c = np.exp(cm / tau)
    p = exp_c / exp_c.sum()
    # Gradient: sum_k p_k * ∇c[k]
    g = np.zeros(n)
    for k in range(2*n-1):
        if p[k] < 1e-10:
            continue
        lo = max(0, k - n + 1)
        hi = min(n - 1, k)
        if lo <= hi:
            g[lo:hi+1] += p[k] * a[k-hi:k-lo+1][::-1]
    return g
```

But this loop over k is O(n^2) in the worst case (each k contributes to O(n) entries). For n=4498, that's about 20 million operations per gradient evaluation. With FFT, we can do better...

Actually, the loop is: for each k, add `p[k] * a[k-hi:k-lo+1][::-1]` to `g[lo:hi+1]`. The total work is `sum_k (hi-lo+1) * p[k]`. In the worst case (uniform p), this is `sum_k (hi-lo+1) = sum_k min(k+1, n, 2n-1-k) ≈ n^2/2`. For n=4498, that's about 10 million operations. In numpy, this would be fast (vectorizable per k, but the loop over k is 9000 iterations).

Actually, we can vectorize this! The gradient is:
`g[j] = sum_k p[k] * a[k-j]` (where 0<=k-j<n, i.e., j<=k<j+n)
`= sum_k p[k] * a[k-j]` for k in [j, j+n-1]

This is a weighted cross-correlation of `p` and `a`! We can compute it with FFT:
`g = cross_correlation(p, a)` where `p` has length 2n-1 and `a` has length n.

Using FFT: `g = ifft(fft(p) * conj(fft(a)))` (padded to appropriate length).

    n = a.size

    fp = np.fft.rfft(p, n=fs)

    # = ifft(fft(p) * conj(fft(a)))[j] (circular, with padding)
    xc = np.fft.irfft(fp * np.conj(fa), n=fs)

    # For p of length 2n-1 and a of length n:
    # corr[j] = sum_{k=j}^{j+2n-2} p[k] * a[(k-j) mod n]... 
    # Actually, with zero-padding to fs, the linear cross-correlation is directly available.
    # corr[j] = sum_{m} p[j+m] * a[m] for m=0..n-1, j=0..(2n-2)-(n-1)=n-1
    # So g[j] for j=0..n-1 is at xc[j] (if the padding is correct)
    # Wait, I need to be more careful.
    # If p has "length" 2n-1 (padded to fs) and a has length n (padded to fs):
    # Circular cross-correlation: xc[j] = sum_{m=0}^{fs-1} p[m] * a[(j+m) mod fs]

    # xc[j] = sum_{m=0}^{n-1} p[j+m] * a[m] (assuming j+m < 2n-1, i.e., j < n)
    # YES! So g[j] = xc[j] for j=0..n-1.
    return xc[:n]
