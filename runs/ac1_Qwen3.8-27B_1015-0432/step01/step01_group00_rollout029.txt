The problem: min max_k (a*a)[k] s.t. sum(a) = 1, a >= 0.

By duality: min t s.t. (a*a)[k] <= t for all k, sum(a) = 1, a >= 0.

The Lagrangian: L = t + sum_k lambda_k * ((a*a)[k] - t) - mu * (sum(a) - 1) - sum_j nu_j * (-a[j])

This is a saddle-point problem. At the optimum, the KKT conditions give:
- The lambda_k > 0 only for k where (a*a)[k] = t (active constraints)
- grad_a L = 0: 2 * sum_k lambda_k * a[k*-j] = mu for all j (with nu_j handling the a_j >= 0 constraint)
- If a[j] > 0: 2 * sum_k lambda_k * a[k*-j] = mu
- If a[j] = 0: 2 * sum_k lambda_k * a[k*-j] <= mu

This is a system of equations that's hard to solve directly for n=4806.

In the symmetric case (a[j] = a[n-1-j]), the active constraints would be symmetric too. And the gradient condition becomes:
2 * sum_k lambda_k * a[k*-j] = mu for j = 0, ..., n-1

This is a linear equation in the lambda_k (for fixed a) or in a (for fixed lambda). It's a coupled system.

import numpy as np
import time


def fft_conv(a, b):
    n, m = len(a), len(b)
    size = 1 << (n + m - 2).bit_length()
    return np.fft.irfft(np.fft.rfft(a, size) * np.fft.rfft(b, size))[:n + m - 1]


def fast_score(f):
    s = f.sum()
    if s < 1e-15:
        return np.inf
    b = fft_conv(f, f)
    return float(2 * len(f) * b.max() / (s * s))


def init_hann(n):
    x = np.arange(n, dtype=np.float64)
    h = 0.5 * (1.0 - np.cos(2.0 * np.pi * x / (n + 1)))
    h = np.maximum(h, 1e-15)
    return h / h.sum()


def init_exp_pair(n, r1, r2):
    x = np.arange(n, dtype=np.float64)
    a = np.exp(-r1 * x / n) + 0.3 * np.exp(-r2 * (n - 1 - x) / n)
    return a / a.sum()


def init_cos_shift(n, shift):
    x = np.arange(n, dtype=np.float64)
    a = np.cos(np.pi * (x / n + shift)) ** 2
    a = np.maximum(a, 1e-15)
    return a / a.sum()
