gc[m] = c[m] = sum_i a[i]*a[m-i]
dc[m]/da[j] = a[m-j] (if 0 <= m-j < n) + a[m-j] (if 0 <= m-j < n)

Wait, I need to be more careful:
c[m] = sum_i a[i] * a[m-i] where a[k] = 0 for k < 0 or k >= n.

dc[m]/da[j]: 
- From the "a[i]" factor: i = j, contributes a[m-j] if 0 <= m-j < n
- From the "a[m-i]" factor: m-i = j, i = m-j, contributes a[m-j] if 0 <= m-j < n AND 0 <= m-j < n (i is valid)

Wait, i = m-j must satisfy 0 <= i < n, i.e., 0 <= m-j < n. Same condition.

So dc[m]/da[j] = a[m-j] + a[m-j] = 2*a[m-j] if 0 <= m-j < n, else 0.

Wait no. When i = j: the term is a[j]*a[m-j], and d/d a[j] gives a[m-j].
When i = m-j: the term is a[m-j]*a[j], and d/d a[j] gives a[m-j].

These are the same term when j = m-j (i.e., m = 2j). In that case, the term is a[j]^2 and the derivative is 2*a[j].

When j ≠ m-j: two separate terms in the sum, each contributes a[m-j]. Total: 2*a[m-j].

So in all cases: dc[m]/da[j] = 2*a[m-j] if 0 <= m-j < n, else 0.

Wait, that's not right either. When j ≠ m-j, the two terms are:
- Term 1 (i=j): a[j]*a[m-j], derivative w.r.t. a[j] is a[m-j]
- Term 2 (i=m-j): a[m-j]*a[j], derivative w.r.t. a[j] is a[m-j]
Total: 2*a[m-j] ✓

When j = m-j (m=2j): single term a[j]^2, derivative is 2*a[j] = 2*a[m-j] ✓

Great, so dc[m]/da[j] = 2*a[max(0, m-j)] if 0 <= m-j < n, else 0.

For the smoothed objective: F(a) = sum_m z[m] * c[m] where z is the softmax weight.
dF/da[j] = sum_m z[m] * 2*a[m-j] * [0<=m-j<n]
= 2 * sum_{m: 0<=m-j<n} z[m] * a[m-j]
= 2 * sum_{k=0}^{n-1} z[j+k] * a[k]  (substituting m = j+k)

This is the cross-correlation! Let G[j] = 2 * sum_{k=0}^{n-1} z[j+k] * a[k] = 2 * (a ⋆ z)[j]

where (a ⋆ z)[j] = sum_k a[k] * z[k+j].

And the full score gradient (with sum constraint S = sum(a) fixed):
d(score)/da[j] = d(2n*max_c/S^2)/da[j]

If we fix S (Lagrange multiplier lambda for sum constraint = 1):
d/d a[j] (2n * F(a)/S^2 - lambda * (sum(a) - S))
= 2n/S^2 * dF/da[j] - lambda
= 2n/S^2 * G[j] - lambda

At the optimum, this should be 0 for interior points: G[j] = (lambda * S^2)/(2n) = const.
So at the optimum, G[j] is constant for all j in the interior!

This is the key equation: G[j] = const for all j where a[j] > 0.

G[j] = 2 * sum_{k=0}^{n-1} z[j+k] * a[k] = 2 * (a ⋆ z)[j]

This is a convolution equation! If z is known, we can solve for a.

For the "flat" target (z uniform over all lags): z[m] = 1/(2n-1) for m = 0..2n-2.
G[j] = 2/(2n-1) * sum_{k=0}^{n-1} a[k] = 2*S/(2n-1) = const. ✓ (any a works)

This makes sense - if all lags are equally weighted, the gradient is the same for all j.

For non-uniform z (focused on the max lags), the equation G[j] = const becomes nontrivial and gives a specific structure for a.

OK so the optimization is: find a >= 0, sum(a) = S, such that G[j] = const for all j (with G depending on z which depends on a). This is a fixed-point problem.

Practical algorithm:
1. Initialize a (e.g., parent sequence, normalized)
2. Compute c = conv(a, a)
3. Compute z = softmax(alpha * (c - max(c)))
4. Compute G = 2 * cross_corr(a, z)
5. Update a to make G more uniform:
   - a_new[j] = a[j] * exp(-lr * (G[j] - mean(G)))
   - Or: a_new[j] = max(0, a[j] - lr * (G[j] - mean(G)))
   - Normalize: a_new /= sum(a_new)
6. Iterate

The step 5 is: decrease a[j] where G[j] is above average (this reduces the convolution at the hot spots) and increase where below.

This is essentially what the Adam optimizer in the previous code does, but without the Adam momentum (which can help or hurt).

Let me also add a "spectral" step: after computing z, form the target convolution T = z (or alpha * z), and set a_new = ifft(sqrt(fft(T)))[:n]. This gives a sequence whose convolution is approximately T.

Actually, the spectral step is: if we want a*a ≈ T in convolution, then |fft(a)|^2 ≈ fft(T), so a ≈ ifft(sqrt(fft(T))). This is the "square root" step.

Let me now write the final code. I'll focus on:
1. Using N = 16384 (not 32768)
2. Adam optimizer on log-space with adaptive alpha
3. Periodic spectral "jump" to escape local minima
4. Final polish with direct gradient steps
5. Good fallback handling

Let me also think about the "active set" approach for the final polish:
- Identify the top K lags (K ≈ 10-50)
- Project to the subspace where these lags are equal
- This is a linear constraint: c[m_1] = c[m_2] = ... = c[m_K]
- Solve the projected QP: min ||c_top - max||^2 subject to a >= 0, sum(a) = 1

But this requires solving a K x K system (or using the fact that c is quadratic in a). It might be too complex for the time budget.

Simpler: just iterate the gradient method with a very high alpha (focus on the top few lags) and a small step size.

Let me write the code now. I'll aim for clarity and correctness, keeping it under 300 lines.

```python
import numpy as np
import time

def next_pow2(x):
    m = 1
    x = max(1, int(x))
    while m < x:
        m <<= 1
    return m

def proj(a, ref):
    a = np.asarray(a, dtype=np.float64).copy()
    a = np.where(np.isfinite(a), a, 0.0)
    a = np.clip(a, 0, 1000.0)
    s = float(a.sum())
    if not np.isfinite(s) or s < 1e-12:
        a = np.asarray(ref, dtype=np.float64).copy()
        a = np.clip(a, 0, 1000.0)
        s = float(a.sum())
    if s < 1e-12:
        a = np.ones(a.size)
        s = float(a.size)
    return a / s

def score_fft(a, N):
    n = a.size
    if n < 1:
        return np.inf
    s = float(a.sum())
    if s < 0.01 or not np.isfinite(s):
        return np.inf
    A = np.fft.rfft(a, N)
    c = np.fft.irfft(A * A, N)
    L = 2 * n - 1
    c = c[:L].copy()
    c = np.maximum(c, 0.0)
    mc = float(c.max())
    return float(2.0 * n * mc / (s * s))

def adam_logspace(a, n, N, deadline, seed):
    rng = np.random.default_rng(seed)
    L = 2 * n - 1
    a = np.clip(a, 1e-300, 1000.0)
    a = a / a.sum()
    best = a.copy()
    best_sc = score_fft(a, N)
    y = np.log(a)
    y = y - y.mean()
    m_v = np.zeros(n)
    v_v = np.zeros(n)
    b1, b2 = 0.85, 0.999
    b1c = 1.0
    b2c = 1.0
    t = 0
    lr = 0.3
    no_improve = 0
    alpha = 5.0
    while time.monotonic() < deadline:
        t += 1
        ym = float(y.max())
        e = np.exp(y - ym)
        es = float(e.sum())
        if not np.isfinite(es) or es < 1e-300:
            y = np.log(np.maximum(best, 1e-300))
            y = y - y.mean()
            e = np.exp(y - y.max())
            es = float(e.sum())
        a = e / es
        A = np.fft.rfft(a, N)
        c = np.fft.irfft(A * A, N)[:L]
        c = np.maximum(c, 0.0)
        mc = float(c.max())
        sc = 2.0 * n * mc  # sum(a)=1 so score = 2n*max_c
        if sc < best_sc - 1e-15:
            best = a.copy()
            best_sc = sc
            no_improve = 0
        else:
            no_improve += 1
        if no_improve > 300:
            y = np.log(np.maximum(best, 1e-300)) - np.log(best).mean()
            y += rng.normal(0, 0.03 + 0.02 * min(5, no_improve / 200), n)
            y = np.clip(y, -25, 25)
            y = y - y.mean()
            m_v.fill(0)
            v_v.fill(0)
            b1c = 1.0
            b2c = 1.0
            t = 0
            lr = max(0.02, lr * 0.6)
            no_improve = 0
            alpha = max(3.0, alpha * 0.5)
            continue
        # Adaptive alpha
        alpha = 5.0 + 200.0 * min(1.0, t / 10000.0)
        if no_improve > 50:
            alpha += 100.0 * min(3.0, (no_improve - 50) / 200.0)
        alpha = min(alpha, 500.0)
        # Softmax weights
        z = np.exp(alpha * (c - mc))
        zs = float(z.sum())
        if not np.isfinite(zs) or zs < 1e-300:
            z = np.zeros(L)
            z[int(np.argmax(c))] = 1.0
        else:
            z = z / zs
        # Gradient in a-space: G[j] = 2 * sum_k z[j+k] * a[k]
        Wr = np.fft.rfft(z[::-1], N)
        conv = np.fft.irfft(A * Wr, N)
        G = 2.0 * conv[n-1:L][::-1].copy()
        G = np.where(np.isfinite(G), G, 0.0)
        # Log-space gradient (softmax param): grad_y = a * (G - dot(a,G))
        gdot = float(np.dot(a, G))
        gy = a * (G - gdot)
        gy = np.where(np.isfinite(gy), gy, 0.0)
        # Normalize gradient magnitude
        gm = float(np.sqrt(np.dot(gy, gy)))
        if gm > 1e-30:
            gy = gy / gm
        # Adam update
        b1c *= b1
        b2c *= b2
        m_v = b1 * m_v + (1 - b1) * gy
        v_v = b2 * v_v + (1 - b2) * gy * gy
        mb = m_v / (1.0 - b1c)
        vb = v_v / (1.0 - b2c)
        step = lr * mb / (np.sqrt(vb) + 1e-8)
        step = np.clip(step, -0.5, 0.5)
        y = y - step
        y = y - float(y.mean())
        y = np.clip(y, -25, 25)
    return best, best_sc

def spectral_refine(a, n, N, deadline, seed):

    rng = np.random.default_rng(seed)
    L = 2 * n - 1
    a = a.copy()
    a = np.maximum(a, 0)
    a = a / a.sum()
    best = a.copy()
    best_sc = score_fft(a, N)
    it = 0
    while time.monotonic() < deadline:
        A = np.fft.rfft(a, N)
        c = np.fft.irfft(A * A, N)[:L]
        c = np.maximum(c, 0.0)
        cs = float(c.sum())
        if cs < 1e-30:
            break
        cn = c / cs
        alpha = max(0.5, 1.0 - 0.005 * it)
        ct = np.power(cn + 1e-15, alpha)
        ct = ct / ct.sum()
        T = np.fft.rfft(ct, N)
        T = np.maximum(T, 0.0)  # for sqrt
        a2 = np.fft.irfft(np.sqrt(T), N)[:n]
        a2 = np.where(np.isfinite(a2), a2, 0.0)
        # Blend
        mix = max(0.1, 0.5 - 0.3 * min(1.0, it / 50.0))
        cand = (1.0 - mix) * a + mix * a2 / (a2.sum() + 1e-30)
        cand = np.maximum(cand, 0)
        cs2 = cand.sum()
        if cs2 < 1e-12:
            it += 1

        cand = cand
