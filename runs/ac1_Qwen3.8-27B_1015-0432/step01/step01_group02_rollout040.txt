b[m] = sum_{k=0}^{n-1} a[k] * a[m-k] (where both indices are valid, i.e., 0 <= m-k < n)

∂b[m]/∂a[i] = sum over k where a[i] appears:
- When k = i: a[i] * a[m-i], derivative wrt a[i] is a[m-i] (if 0 <= m-i < n)
- When m-k = i, i.e., k = m-i: a[m-i] * a[i], derivative wrt a[i] is a[m-i] (if 0 <= m-i < n)

But if k = i and k = m-i simultaneously (i.e., i = m-i, m = 2i), then it's the same term a[i]^2, derivative is 2a[i] = 2a[m-i].

So the total derivative is:
- If 0 <= m-i < n and i != m-i: a[m-i] + a[m-i] = 2*a[m-i]
- If 0 <= m-i < n and i == m-i: 2*a[i] = 2*a[m-i]
- If not 0 <= m-i < n: 0

So ∂b[m]/∂a[i] = 2*a[m-i] if 0 <= m-i < n, else 0.

The pressure from peak m with weight w is: w * 2*a[m-i] for each i where 0 <= m-i < n.
So i ranges from max(0, m-n+1) to min(n-1, m).
