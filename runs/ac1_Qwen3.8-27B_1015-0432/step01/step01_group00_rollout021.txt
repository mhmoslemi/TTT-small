The gradient of M with respect to f[i] (using soft-max subgradient) is:
g[i] = (1/Z) * sum_m (f[m-i] + f[i]) * exp(beta*c[m]/M)
= f[i]/Z * sum_m exp(beta*c[m]/M) + (1/Z) * sum_m f[m-i] * exp(beta*c[m]/M)
= f[i] + (1/Z) * (w * f_rev)[i]

where w[m] = exp(beta*c[m]/M) and (w * f_rev) is the convolution.

The parent computes `gc = fft_conv(w, f_r)` where f_r = f[::-1]. Then `grad = gc[n-1:2*n-1]`.

The convolution of w (length 2n-1) with f_r (length n) has length 3n-2. The slice [n-1:2n-1] gives n values.

(w * f_r)[k] = sum_i w[i] * f_r[k-i] = sum_i w[i] * f[n-1-(k-i)] = sum_i w[i] * f[n-1-k+i]

For k = n-1+i0 (where i0 is the output index 0 to n-1):
(w * f_r)[n-1+i0] = sum_i w[i] * f[n-1-(n-1+i0)+i] = sum_i w[i] * f[i-i0]

This is sum_i w[i] * f[i-i0] which is a cross-correlation. This should give the "second term" of the gradient for each f[i0].
