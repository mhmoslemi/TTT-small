Actually, let me reconsider. The score is `2n * max(c) / S^2`. Since it's scale-invariant, let's work with S=1. Then we minimize `2n * max(c)` where c = convolve(a,a), sum(a)=1, a>=0.

The constraint sum(a)=1 is an equality constraint. The parent uses L-BFGS-B with only box constraints [0, 1000]. It doesn't enforce sum(a)=1. But since the objective is scale-invariant, the optimizer will naturally find a direction that doesn't change the scale (or the scale will settle at some value). Actually, L-BFGS-B might struggle with the scale invariance.

Better approach: parameterize a as exp(x)/sum(exp(x)) (softmax) to automatically satisfy a>=0 and sum(a)=1. But this changes the optimization problem and might be harder for L-BFGS-B.

Alternative: just normalize after each iteration. In the _obj function, the scale invariance means the gradient points are well-defined in the scale-free direction but have a zero component in the scale direction. L-BFGS-B should handle this OK.
