Let me also think about the spectral step more carefully. The idea is:
1. Compute c = conv(a,a) (via FFT)
2. Shape c toward a "flat peak": compute c^alpha for alpha < 1
3. The new "target" autocorrelation shape is c_t = c^alpha / sum(c^alpha)
4. Find a new a whose autocorrelation has this shape
5. This means: if A = fft(a), then |A|² should have IFFT = c_t
6. So A_new = sqrt(fft(c_t)), and a_new = ifft(A_new)
7. Project a_new to be nonnegative

The issue: sqrt(fft(c_t)) might not give a valid A (the fft of c_t might have negative values due to numerical errors). Also, a_new = ifft(sqrt(fft(c_t))) might have negative values.

The nonnegativity of a is the tricky part. The spectral step will naturally produce sequences with some negative lobes (like sinc-like functions). We project to nonnegative, which changes the autocorrelation shape. The iteration between spectral shaping and nonnegativity projection is what drives convergence.

Let me also consider a "two-spectrum" approach: instead of directly computing sqrt(fft(c_t)), we can blend:
`A_new = (1-t) * A_old + t * sqrt(fft(c_t))`
where t is a step size. This gives smoother transitions.

Or in the time domain:
`a_new = (1-t) * a_old + t * max(0, ifft(sqrt(fft(c_t))))`

def spec(a, Ng, n, alpha, beta):
    A = np.fft.rfft(a, Ng)
    c = np.fft.irfft(A * A, Ng)[:2 * n - 1]
    c = np.maximum(c, 0.0)

    dl = t0 + budget - max(10.0, 0.05 * budget)
    try:
        par = np.asarray(height_sequence_1, dtype=np.float64).ravel()
    except Exception:
        par = np.ones(5582)
    if par.size == 0 or not np.all(np.isfinite(par)):
        par = np.ones(5582)
    par = np.clip(par, 0.0, 1000.0)
    if par.sum() < 0.01:
        par = np.ones(max(1, par.size))
    n = par.size
    ones = np.ones(n) / n
    Ng = nxt2(2 * n - 1)
    pn = npos(par, ones)
    pool = [ones.copy(), pn]
    if n > 2:
        j = np.arange(n, dtype=np.float64)
        mid = (n - 1) / 2.0
        w = np.exp(-(((j - mid) / max(1.0, n * 0.25)) ** 4))
        pool.append(npos(w, ones))
    for al in (0.8, 0.6, 0.4):
        try:
            pool.append(spec(ones, Ng, n, al, 0.0))
            pool.append(spec(pn, Ng, n, al, 0.0))
        except Exception:
            pass
    scored = []
    for p in pool:
        s = sc(p, Ng)
        if np.isfinite(s):
            scored.append((s, p))
    scored.sort()
    if not scored:
        return [1.0 / float(n)] * n
    best_a, best_sc = scored[0][1].copy(), scored[0][0]
    if time.monotonic() < dl - 5:
        rem = dl - time.monotonic()
        d1 = time.monotonic() + min(150.0, 0.2 * rem)
        try:
            a1, s1 = run_spec(best_a, Ng, n, d1, seed + 1)
            if s1 < best_sc:
                best_a, best_sc = a1, s1
        except Exception:
            pass
    if time.monotonic() < dl - 5:
        rem = dl - time.monotonic()
        d2 = time.monotonic() + max(30.0, 0.55 * rem)
        try:
            a2, s2 = run_adam(best_a, Ng, n, d2, seed + 2)
            if s2 < best_sc:
                best_a, best_sc = a2, s2
        except Exception:
            pass
    if time.monotonic() < dl - 3:
        rem = dl - time.monotonic()
        d3 = time.monotonic() + max(5.0, 0.15 * rem)
        try:
            a3, s3 = rls(best_a, Ng, n, d3, seed + 3)
            if s3 < best_sc:
                best_a, best_sc = a3, s3
        except Exception:
            pass
    if time.monotonic() < dl - 30:
        rem = dl - time.monotonic()
        if rem > 120:
            rng2 = np.random.default_rng(seed + 10)
            p2 = npos(best_a * (1.0 + 0.04 * rng2.normal(size=n)), best_a)
            d4 = time.monotonic() + min(80.0, 0.3 * rem)
            try:
                a4, s4 = run_spec(p2, Ng, n, d4, seed + 4)
                if s4 < best_sc:
                    best_a, best_sc = a4, s4
            except Exception:
                pass
            if time.monotonic() < dl - 10:
                d5 = time.monotonic() + max(20.0, 0.5 * (dl - time.monotonic()))
                try:
                    a5, s5 = run_adam(best_a, Ng, n, d5, seed + 5)
                    if s5 < best_sc:
                        best_a, best_sc = a5, s5
                except Exception:
                    pass
    out = [float(x) for x in best_a.tolist()]
    try:
        if not np.isfinite(evaluate_sequence(out)):
            out = [float(x) for x in ones.tolist()]
    except Exception:
        out = [float(x) for x in ones.tolist()]
    return out
