Let me also think about the spectral projection more carefully. The idea is:
- Given current a, compute c = a*a
- c has peaks we want to reduce
- Define a target c_target that's flatter
- Find a_new such that a_new * a_new ≈ c_target
- a_new = ifft(sqrt(fft(c_target)))

The power method: c_new = c^alpha (alpha < 1 flattens). Then a_new = ifft(sqrt(fft(c_new))).

This is a fixed-point iteration: a_{t+1} = f(a_t) where f(a) = ifft(sqrt(fft(norm(c(a)^alpha)))).

The previous code does this in `spectral_raw`. Let me keep it but make it more effective.

Actually, I realize there's a subtlety: the spectral projection changes the length/scale of a, so we need to normalize after each step. Also, the projection might introduce negative values, which we need to clip (and this changes the shape).

def next_pow2(x):
    m = 1
    x = max(1, int(x))
    while m < x:
        m <<= 1
    return m

def softmax_vec(y):
    y = np.where(np.isfinite(y), y, 0.0)
    ym = y - y.max()
    e = np.exp(np.clip(ym, -700, 700))
    s = e.sum()
    if s <= 0 or not np.isfinite(s):
        return np.ones(y.size) / y.size
    return e / s

def score_fft(a, N):
    n = a.size
    s = a.sum()
    if s <= 0 or not np.isfinite(s):
        return np.inf, None
    A = np.fft.rfft(a, N)
    c = np.fft.irfft(A * A, N)
    L = 2 * n - 1
    c = np.maximum(c[:L], 0)
    mc = c.max()
    if not np.isfinite(mc):
        return np.inf, c
    return 2.0 * n * mc / (s * s), c
