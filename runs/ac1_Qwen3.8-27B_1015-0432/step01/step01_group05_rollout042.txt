For the peak to be low, we want the autocorrelation to be spread out. This is related to "flat" autocorrelation sequences (like Barker sequences, Zadoff-Chu, etc.), but those are for complex/unit-modulus sequences.

For non-negative sequences, the constraint is much tighter. Let me think about it differently.

Score = 2n * max(conv) / sum^2.

Let S = sum. We want to minimize max(conv) / S^2.

Note that sum(conv) = sum over all k of conv[k] = (sum a)^2 = S^2.
The convolution has 2n-1 entries.
So the AVERAGE of conv is S^2 / (2n-1).
And max(conv) >= S^2 / (2n-1).
So score >= 2n * S^2/(2n-1) / S^2 = 2n/(2n-1) ≈ 1 for large n.

So the theoretical lower bound is 2n/(2n-1) which approaches 1 as n grows! The target of 1.5027 is above this bound, so it's achievable in principle.

The question is: can we actually achieve close to 1? That would require the convolution to be as flat as possible, i.e., all entries approximately equal to S^2/(2n-1).

For a "white noise" sequence (iid random), the convolution would be approximately flat, with max being the mean plus a few standard deviations. The mean is S^2/(2n-1) and the std is roughly S^2/sqrt(2n). So max ≈ S^2/(2n-1) + c*S^2/sqrt(2n) for some small c.

score ≈ 2n * [S^2/(2n-1) + c*S^2/sqrt(2n)] / S^2
= 2n/(2n-1) + 2n*c/sqrt(2n)
≈ 1 + c*sqrt(2n)

For n=3809, sqrt(2n) ≈ 87. So even small c would dominate. This suggests random sequences won't be great.

But structured sequences (like FKM, GMF sequences, etc.) can have much flatter autocorrelation. However, those are typically for ±1 or complex sequences, not non-negative.

For non-negative sequences, the constraint is much harder. The sequence values are all ≥ 0, which makes it hard to cancel out peaks.

def _fft_conv(a, b):
    n = len(a) + len(b) - 1
    size = 1 << (n - 1).bit_length()
    return np.fft.irfft(np.fft.rfft(a, size) * np.fft.rfft(b, size), size)[:n]

def _smooth_grad(a, c, w, size2, n):
    flip_a = a[::-1]
    W = np.fft.rfft(w, size2)
    FA = np.fft.rfft(flip_a, size2)
    conv = np.fft.irfft(W * FA, size2)
    g = 2.0 * conv[n - 1:n - 1 + n]
    g -= g.mean()
    return g
