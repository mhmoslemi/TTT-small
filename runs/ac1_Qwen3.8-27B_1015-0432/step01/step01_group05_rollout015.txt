One powerful technique: iteratively modify the spectrum. In the frequency domain, the convolution is |A(f)|^2 (for autocorrelation) or A(f)*A(f) for convolution (which is the same for real signals if we're careful).

Wait, for the linear convolution: F_conv(c) = F_a * F_a (product in frequency domain). To minimize max(c), we want F_a * F_a to be as flat as possible (in the sense that its inverse FFT has small max). This is a different problem from making F_a flat.

Actually, making |F_a| flat would make F_a * F_a = |F_a|^2 flat (if F_a is real and positive, which it is for nonnegative a). So the goal in frequency domain is to make |F_a(f)| as flat as possible, subject to F_a(0) = sum(a) = sqrt(2n) and the time-domain constraint a >= 0.

The "flattening" algorithm: 
1. Take FFT of a: A = FFT(a)
2. Replace |A| with a smoothed version (e.g., geometric mean of |A| and target)
3. Inverse FFT, clip to nonnegative
4. Repeat

This is similar to the "Gerchberg-Saxton" or "error diffusion" algorithms used in holography.

Let me add this as an alternative optimization pass:

```python
def _flatten_pass(a, n, iters):
    for _ in range(iters):
        A = np.fft.rfft(a, 2*n)
        mag = np.abs(A)
        # Target: constant magnitude
        target = mag.mean()
        # Blend
        new_mag = np.sqrt(mag * target)  # Geometric mean with constant
        # Actually, to preserve DC: A[0] should stay = sum(a)
        new_A = new_mag * np.exp(1j * np.angle(A))
        new_A[0] = A[0]
        a_new = np.fft.irfft(new_A, 2*n)[:n]
        a_new = np.maximum(a_new, 0)
        a = a_new / a_new.sum() * np.sqrt(2*n)
    return a
```

    sz = 1 << (n - 1).bit_length()
    return np.fft.irfft(np.fft.rfft(a, sz) * np.fft.rfft(b, sz), sz)[:n]
