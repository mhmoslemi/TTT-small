# Optimization of Sparse Signal Representations with Bounded Autocorrelation

## 1. Approach and rationale

The evaluation metric targets the minimization of the AC1 bound (|\H(f)|), a key performance indicator for autocorrelation estimation accuracy. Our research focuses on a **sparse representation approach** leveraging structured convex optimization. The central idea is that optimal sequences typically possess sparse autocorrelation structures, which can be enforced through optimization constraints.

We address the convexification challenge by viewing the AC1 bound minimization through a dualframe approach:
- Solve a related BIEP (Bandlimited Infinite-Energy Positive) problem via time-encoding machines
- Use an accelerated proximal framework to enforce sparsity constraints
- Implement a regularization scheme combining L0-"sparsification" with L1-constraint

The primary algorithm employs an **adaptive weighted L2-proximal gradient method** combined with a **fast composite gradient descent** procedure. Each iteration includes:
1. A stochastic proximal step to handle non-smooth regularization
2. Convex combination of the latest model and its neighbors to maintain mass balance
3. Real-time update of weights based on local gradient magnitudes
4. Adaptive noise injection to escape local minima

This strategy addresses three key challenges:
1. **Full solution space capture** - handles both sparse and dense representations dynamically
2. **Early termination** - configurable based on convergence metrics
3. **Adaptive regularization** - smoothly transitions between L0/L1 regimes

There's no requirement to use fourier-based representations ortraditional optimization frameworks, and we ensure unconditional positive definiteness through the optimization formulation.

## 2. Mathematical specification

### Variables and constraints

Let **a** ∈ ℝⁿ denote the sequence coefficients to be optimized. The combinatorial AC1 optimization is transformed into a hierarchy of problems:

**Primary optimization problem**:
min_{a} \quad 2n · max{full_convolution} / (1 + ‖a‖₁)

s.t. \quad a ≥ 0 (after normalization)
\quad \quad ‖a‖_∞ ≤ 1000
\quad \quad full_convolution(a, a)[k] ≤ M, ∀k (implicitly)

**Equivalent CVQP formulation** (with 0<R<1 being the complexity-accuracy trade-off parameter):

minimizeₐ \quad  f(a) + λ·g(a) + R· LogisticReg(a)

subject to:
\quad 0 ≤ a_i ≤ 1000, ∀i
\quad ∑_i a_i ≥ 1 (to avoid trivial zero sequences)

Where:
- f(a) = 2n·max{full_convolution} - This is non-convex but conditionally Lipschitz
- g(a) = ∑|a_i| - With appropriate scaling preserves the gradient contributions
- LogisticReg(a) = (1/n²)∑log(1 + |a_i|²) - Ensures positive definiteness

### Convex relaxation

For numerical stability, we use an exponential penalty formulation:

 minimizeₐ \quad max_k { |full_convolution[k]| } + μ· ( ∑|a_i| - 1 )

This is minimized iteratively with:
\begin{pmatrix}
\hat{a}_{k+1} = \text{Proj}_box( \hat{a}_k - 
\frac{1}{L} J_{f}( \hat{a}_k )
\end{pmatrix}

where J_{f} is the subgradient of the non-smooth part.

### Solution feasibility check

A candidate solution {a} is valid if:
1. All a_i ≥ 0
2. ∑|a_i| ≥ 0.01
3. All values are finite and non-infinite
4. Convolution does not contain impossibly large values (filtered by box-bound compliance)
