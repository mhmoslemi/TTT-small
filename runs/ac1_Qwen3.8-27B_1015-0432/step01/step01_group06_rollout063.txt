subject to sum(a) = n, a >= 0

where b[k] = sum_i a[i] a[k-i].

This can be rewritten as:
minimize T
subject to b[k] <= T for all k
sum(a) = n
a >= 0
T >= 0

The Lagrangian (ignoring the max) would involve KKT conditions. At the optimum, the active constraints (where b[k] = T) determine the solution.

For a practical approach, let me use an iterative method:
1. Start with an initial `a`.
2. Compute `b = convolve(a, a)`.
3. Identify the "hot" positions where `b[k]` is close to `max(b)`.
4. Update `a` to reduce the contributions at those positions.
5. Renormalize.

A specific algorithm:
- `a_new[j] = a[j] / (1 + sum_{k in hot} w_k * a[k-j])`
  where `w_k` are weights based on how close `b[k]` is to the max.
- Then renormalize: `a_new = a_new * n / sum(a_new)`.

This is like a coordinate descent or minimax approach.

Let me also consider: what if we use a smooth approximation of the max? `max(b) ≈ sum(b[k]^p)^{1/p}` for large `p`. Then we can use gradient descent on this smooth objective.

For `p=4` or `p=8`, the approximation is decent and the gradient is computable.

`f_p(a) = (sum_k b[k]^p)^{1/p}`

`df_p/da[j] = (p/(p)) * (sum_k b[k]^p)^{1/p - 1} * sum_k p * b[k]^{p-1} * db[k]/da[j]`
= `(sum_k b[k]^p)^{1/p - 1} * p * sum_k b[k]^{p-1} * 2*a[k-j]` (where valid)

This can be computed via convolution: the inner sum `sum_k b[k]^{p-1} * a[k-j]` is a convolution of `b^{p-1}` with `a` (reversed).

So the gradient is: `2 * (sum b^p)^{1/p - 1} * convolve(b^{p-1}, a_reversed)_j` (appropriately truncated).

This is computable in O(n log n) via FFT!

To make it smoother, I can use a weighted average of top-k positions:
`g[j] = (1/|S|) * sum_{k in S} 2*a[k-j]` where S is the set of top-k positions.

This gives a smoother gradient that still targets the peak region.

Let me also consider: the convolution `b = conv(a,a)` has length `2n-1`. For a bump-shaped `a`, the peak is around `k = n-1`. For a ramp, it shifts to one side. The optimization should handle both.

```python
import numpy as np
import time

def _fft_conv(u, v):
    L = u.size + v.size - 1
    sz = 1 << (L - 1).bit_length()
    return np.fft.irfft(np.fft.rfft(u, sz) * np.fft.rfft(v, sz), sz)[:L]

def _proj_nn_sum(a, target_sum):
    """Project a onto {x >= 0, sum(x) = target_sum} via bisection."""
    lo = a.min() - 1.0
    hi = a.max() + 1.0
    for _ in range(40):
        mid = 0.5 * (lo + hi)
        s = np.maximum(a - mid, 0.0).sum()
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    t = 0.5 * (lo + hi)
    return np.maximum(a - t, 0.0)

def _subgrad_peak(b, a, ntop=16):
    """Subgradient of max(b) w.r.t. a, using top ntop positions."""
    n = a.size
    if ntop >= b.size:
        idx = np.arange(b.size)
    else:
        idx = np.argpartition(b, -ntop)[-ntop:]
    # Weight by proximity to max
    bm = b[idx]
    w = bm ** 4  # emphasize the peak
    w /= w.sum()
    g = np.zeros(n)
    for k in idx:
        lo = max(0, k - n + 1)
        hi = min(n - 1, k)
        if lo <= hi:
            g[lo:hi+1] += 2.0 * w[
                np.where(idx == k)[0][0]
            ] * a[k - np.arange(lo, hi + 1)]
    return g
```

Hmm, this loop over idx is O(ntop * n) which is fine for ntop=16 and n=3809.

But wait, I can vectorize this. For each k in idx, the contribution to g is `2 * w_k * shift(a, k)`. The shift operation:
- For k >= n-1: `g[max(0,k-n+1):n] += 2*w_k * a[0:k-(max(0,k-n+1))+1]`... this is getting messy.

Actually, for k in [0, 2n-2]:
- Valid j range: j in [max(0, k-n+1), min(n-1, k)]
- g[j] += 2 * w_k * a[k-j]

For k >= n-1: j in [k-n+1, n-1], and a[k-j] where k-j goes from n-1 down to k-(n-1) = k-n+1
So g[k-n+1:n] += 2*w_k * a[k-n+1:k+1][::-1]

For k < n-1: j in [0, k], and a[k-j] where k-j goes from k down to 0
So g[0:k+1] += 2*w_k * a[k::-1]

Let me just do it in a loop for simplicity (ntop is small):

```python
def _subgrad_peak(b, a, ntop=16):

    kb = b.size
    idx = np.argpartition(b, -min(ntop, kb))[-min(ntop, kb):]
```

```python
def _proj(a, ts):
    if a.max() <= 0:
        return np.full_like(a, ts / a.size)
    lo, hi = a.min(), a.max()
    for _ in range(30):
        mid = 0.5 * (lo + hi)
        if np.maximum(a - mid, 0.0).sum() > ts:
            lo = mid
        else:
            hi = mid
    return np.maximum(a - 0.5 * (lo + hi), 0.0)
```
