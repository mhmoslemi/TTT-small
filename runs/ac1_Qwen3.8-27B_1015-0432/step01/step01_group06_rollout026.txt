    h = np.fft.irfft(Fc * np.conj(Fa), L)[:n]

  First: k-n+1 <= k-j <= k and max(0,...) <= k-j <= min(k,n-1).
  k-j >= max(0,k-n+1) means j <= k - max(0,k-n+1) = min(k, n-1).
  k-j <= min(k,n-1) means j >= k - min(k,n-1) = max(0, k-n+1).
  So: max(0,k-n+1) <= j <= min(k,n-1). Same range! ✓

So indeed d(conv[k])/da_j = 2*a[k-j] for j in [max(0,k-n+1), min(k,n-1)], and 0 otherwise.

df/da_j = 2 * sum_k conv[k] * 2*a[k-j] * [j in valid range for k]
= 4 * sum_{k: j in [max(0,k-n+1), min(k,n-1)]} conv[k] * a[k-j]

The condition j in [max(0,k-n+1), min(k,n-1)] is equivalent to:
- j >= max(0, k-n+1) → k <= j+n-1 (and k >= 0 always)
- j <= min(k, n-1) → k >= j (and j <= n-1 always)

So k in [j, j+n-1] (intersected with [0, 2n-2], but j+n-1 <= 2n-2 since j <= n-1).

df/da_j = 4 * sum_{k=j}^{j+n-1} conv[k] * a[k-j]
= 4 * sum_{l=0}^{n-1} conv[j+l] * a[l]  (letting l = k-j)

This is 4 times the cross-correlation of conv with a at lag j:
h[j] = sum_{l=0}^{n-1} conv[j+l] * a[l]

And we take the first n elements: h[0..n-1].

Let me verify: ifft(FFT(x) * conj(FFT(y))) gives the cross-correlation r[m] = sum_n x[n+m] * conj(y[n]).
For real signals: r[m] = sum_n x[n+m] * y[n].
With x = conv (length 2n-1), y = a (length n):
r[m] = sum_{n=0}^{n-1} conv[m+n] * a[n] (for valid indices).

So r[j] = sum_{n=0}^{n-1} conv[j+n] * a[n] = h[j]. ✓

def _fft_conv(a):
    n = a.size
    sz = 1
    while sz < 2*n - 1:
        sz <<= 1
    fa = np.fft.rfft(a, sz)
    return np.fft.irfft(fa * fa, sz)[:2*n-1]

def _grad_l2(corr, a, n):

    Fa = np.fft.rfft(a, L)

def _grad_topk(corr, a, n, K):
