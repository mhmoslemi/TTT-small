Actually, I want to be more strategic about the CD. Let me think about what the CD is really doing.

The CD optimizes the max correlation by cycling through coordinates. At each step, it finds the best value for one coordinate (keeping all others fixed) that minimizes the max correlation. This is a classic approach for non-convex optimization.

The key advantage over gradient methods: the CD finds the exact 1D optimum for each coordinate, including handling the kinks in the max function. Gradient methods (even L-BFGS-B) approximate this.

The disadvantage: the CD is sensitive to the coordinate ordering and can get stuck in local minima where no single coordinate move improves the objective. This is exactly the weakness that the diverse restarts address.

For the final polish, the CD should be very effective because the solution is already close to a local optimum and the CD can fine-tune each coordinate.
