Let me formalize: at the current h, let c_k = corr_k(h). For a perturbation δ (with sum(δ) = 0):

We want to minimize max_k (c_k + ∇corr_k · δ) subject to:
- sum(δ) = 0
- h_i + δ_i ∈ [0, 1] for all i

This is a linear program! We can introduce a variable t:
minimize t
subject to:
  c_k + ∇corr_k · δ ≤ t for all k in active set
  sum(δ) = 0
  -h_i ≤ δ_i ≤ 1 - h_i for all i

This LP has 2n+1 variables (t, δ_0, ..., δ_{n-1}) and about (K + n + 1) constraints.

For n=280, K=10: about 281 variables and 291 constraints. This is very fast to solve!

    j = np.arange(n); g = np.zeros(n)
    if s >= 0:
        m1 = j >= s; m2 = (j+s) < n
        g[m1] += 1-h[j[m1]-s]; g[m2] -= h[j[m2]+s]
    else:
        s2 = -s; m1 = (j+s2) < n; m2 = j >= s2
        g[m1] += 1-h[j[m1]+s2]; g[m2] -= h[j[m2]-s2]

    n = len(h); dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode="full")) * dx)

def proj(y, n):
    t = n / 2.0
    lo, hi = -2.0, 3.0
    for _ in range(80):
        m = (lo + hi) / 2.0
        if np.clip(y - m, 0.0, 1.0).sum() > t:

        else:

def sgrad(h, n, s):
    j = np.arange(n)
    g = np.zeros(n)
    if s >= 0:
        m1 = j >= s
        m2 = (j + s) < n
        g[m1] += 1.0 - h[j[m1] - s]
        g[m2] -= h[j[m2] + s]
    else:

        m2 = j >= s2
        g[m1] += 1.0 - h[j[m1] + s2]
        g[m2] -= h[j[m2] - s2]
    return g
