One idea: **Use scipy.optimize.linprog or milp** for a linearized version.

If I linearize around the current point h₀:
f_k(h) ≈ f_k(h₀) + ∇f_k(h₀) · (h - h₀)

Then the problem becomes:
min C
s.t. f_k(h₀) + ∇f_k(h₀) · (h - h₀) ≤ C for all k
     0 ≤ h ≤ 1
     sum(h) = n/2

This IS a linear program! I can solve it with scipy or cvxpy.

The idea:
1. Start with current h₀
2. Linearize all f_k at h₀
3. Solve LP: min C s.t. linearized constraints
4. Update h₀ = solution
5. Repeat (this is basically the cutting plane method / outer approximation)

This could be much more effective than SLSQP because:
- It considers ALL lags simultaneously (not just one or a soft approximation)
- LP solvers are very efficient
- The solution of the LP gives a direction that reduces the max overlap

```python
from scipy.optimize import linprog

def lp_step(h, c5_current, n):
    """Take one LP step: linearize and minimize max overlap."""
    target = n / 2.0
    m = len(h)
    corr = get_corr(h)
    dx = 2.0 / m
    center = m - 1
    
    # Decision variables: h_new (m vars) + C (1 var) = m+1 vars
    # Minimize C
    # s.t.: for each lag k: corr_k + grad_k . (h_new - h) * dx <= C
    #       0 <= h_new <= 1
    #       sum(h_new) = target
    
    c = np.zeros(m + 1)
    c[-1] = 1.0  # minimize C
    
    A_ub = []
    b_ub = []
    
    for k in range(2*m - 1):
        # grad of corr_k with respect to h
        o = k - center
        g = np.zeros(m)
        if o == 0:
            g[:] = 1.0 - 2.0*h
        elif o > 0:
            g[o:] += 1.0 - h[:m-o]
            g[:m-o] -= h[o:]
        else:
            p = -o
            g[:m-p] += 1.0 - h[p:]
            g[p:] -= h[:m-p]
        g *= dx
        
        # Linearized: corr_k * dx + g . (h_new - h) <= C
        # => g . h_new - C <= corr_k * dx - g . h
        g_ext = np.zeros(m+1)
        g_ext[:m] = g
        g_ext[-1] = -1.0
        A_ub.append(g_ext)
        b_ub.append(corr[k] * dx - g @ h)
    
    A_ub = np.array(A_ub)
    b_ub = np.array(b_ub)
    
    # Equality: sum(h_new) = target
    A_eq = np.zeros((1, m+1))
    A_eq[0, :m] = 1.0
    b_eq = [target]
    
    bounds = [(0,1)]*m + [(0, None)]
    
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                  bounds=bounds, method='highs')
    
    if res.success:
        h_new = res.x[:m]
        C_new = res.x[-1]
        return h_new, C_new
    return h, c5_current
```
