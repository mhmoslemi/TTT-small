Let me optimize shift_grad to be more vectorized. Actually, for a given shift s, shift_grad is:
- For j >= s: grad[j] += (1-h[j-s])
- For j < n-s: grad[j] -= h[j+s]

This can be done with two slice operations:
grad[s:] += (1 - h[:n-s])
grad[:n-s] -= h[s:]

That's O(n) with numpy vectorization, very fast.

import numpy as np
from scipy.optimize import minimize
import time

    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")

def project_feasible(y, n):
    target = n / 2.0
    # Bisection for the threshold
    lo = y.min() - 1.0
    hi = y.max() + 1.0
    for _ in range(40):

        s = np.clip(y - mid, 0.0, 1.0).sum()
        if abs(s - target) < 1e-12:
            break
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(y - mid, 0.0, 1.0)

def shift_grad_fast(h, n, s):
    """Gradient of c[k] w.r.t. h, where k is the shift (s = k - (n-1))"""
    grad = np.zeros(n)
    if s >= 0:
        # c = sum_{j=0}^{n-1-s} h[j+s]*(1-h[j])
        # dc/dh[j] for j in [s, n-1]: += (1-h[j-s])
        # dc/dh[j] for j in [0, n-1-s]: -= h[j+s]
        grad[s:] += (1.0 - h[:n-s])
        grad[:n-s] -= h[s:]
    else:
        ss = -s
        # c = sum_{j=0}^{n-1-ss} h[j]*(1-h[j+ss])
        # dc/dh[j] for j in [0, n-1-ss]: += (1-h[j+ss])
        # dc/dh[j] for j in [ss, n-1]: -= h[j-ss]
        grad[:n-ss] += (1.0 - h[ss:])
        grad[ss:] -= h[:n-ss]
    return grad

The correlation output of np.correlate(h, 1-h, mode="full") has 2n-1 elements. Let me denote the input to correlate as a=h (length n) and v=1-h (length n).

From numpy docs: correlate(a, v)[k] = sum_j a[j+k] * v[j] for the valid range of j.

For s >= 0: j ranges from 0 to n-1-s
For s < 0: j ranges from -s to n-1 (let ss = -s, then j from ss to n-1, and h[j-ss]*(1-h[j]))

Gradient w.r.t. h[p] (for a single h element at position p):

dc[s]/dh[p]:
- First term: sum_{j=0}^{n-1-s} h[j+s] contributes 1 if p = j+s for some valid j, i.e., j = p-s is valid (0 <= p-s <= n-1-s), i.e., s <= p <= n-1.
- Second term: -sum h[j+s]*h[j]. By product rule:
  - If p = j+s (= h[j+s] changes): contribution = -h[j] for j = p-s (valid if s <= p <= n-1)
  - If p = j (= h[j] changes): contribution = -h[j+s] for j = p (valid if 0 <= p <= n-1-s)

So dc[s]/dh[p] = (1 - h[p-s]) * [s<=p<=n-1] - h[p+s] * [0<=p<=n-1-s]

In array form for s >= 0:
grad[p] = (1 - h[p-s]) for p in [s, n-1]  (first term)
        - h[p+s] for p in [0, n-1-s]  (second term)

So:

grad[:n-s] -= h[s:]            # for p in [0, n-1-s], h[p+s] for p+s in [s, n-1]

For s < 0 (let ss = -s > 0):

dc[s]/dh[p]:
- First term: 1 if p in [0, n-1-ss]
- Second term: 
  - p = i: -h[i+ss] for i in [0, n-1-ss], i.e., p in [0, n-1-ss], contribution -h[p+ss]
  - p = i+ss: -h[i] for i in [0, n-1-ss], i.e., p in [ss, n-1], contribution -h[p-ss]

So dc[s]/dh[p] = [p in [0, n-1-ss]] - h[p+ss]*[p in [0, n-1-ss]] - h[p-ss]*[p in [ss, n-1]]
= (1-h[p+ss]) for p in [0, n-1-ss]
- h[p-ss] for p in [ss, n-1]

In array form:
grad[:n-ss] += (1 - h[ss:])     # for p in [0, n-1-ss]
grad[ss:] -= h[:n-ss]           # for p in [ss, n-1]

        h_new = project_feasible(h_new, n)
        
        # Nesterov restart check
        h_prev = h
        h = h_new
        
        it += 1

            c5_now = compute_c5(h)
            if c5_now < c5_best:

                h_best = h.copy()

The problem is: min_{h ∈ P} max_k (h^T A_k h + b_k^T h) where P is the clipped simplex.

The max can be handled with the log-sum-exp trick or by alternating.

Actually, let me try a **penalty method** approach:
min_t t
s.t. h^T A_k h + b_k^T h ≤ t for all k
     h ∈ P

The Lagrangian: L(h, t, λ) = t + sum_k λ_k (h^T A_k h + b_k^T h - t)
= t(1 - sum_k λ_k) + sum_k λ_k (h^T A_k h + b_k^T h)

Setting ∂L/∂t = 0: sum_k λ_k = 1 (probability distribution over lags).

So the dual is: max_{λ ≥ 0, sum λ = 1} min_{h ∈ P} [sum_k λ_k (h^T A_k h + b_k^T h)]

This is a convex problem in h for fixed λ! (Quadratic with linear term, box constraints, sum constraint.)

Wait, is h^T A_k h convex? A_k has the structure of the bilinear form h[j+k]*h[j]. Let me think...

c[k] = sum_j h[j+k](1-h[j]) = sum_j h[j+k] - sum_j h[j+k]h[j]

The term sum_j h[j+k]h[j] is a quadratic form. Is it positive or negative semi-definite?

(Q_k)[i,j] = 0.5*(δ_{i,j+k} + δ_{i+k,j}) for i,j in the valid range.

This is the adjacency matrix of a "shift graph" - it has eigenvalues on the unit circle (for the periodic case), so it's NOT positive semi-definite in general.

So the quadratic form is NOT convex. The problem is genuinely non-convex.

However, we can still use the Lagrangian dual as a heuristic: fix λ (a distribution over lags), minimize the weighted quadratic, project to feasible set. Iterate.

This is essentially what the top-K weighted gradient is doing! The weights w in the Nesterov loop are essentially the λ_k.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(y, n):
    target = n * 0.5
    lo = y.min() - 1.0
    hi = y.max() + 1.0
    mid = 0.0
    for _ in range(35):
        mid = (lo + hi) * 0.5
        s = np.clip(y - mid, 0.0, 1.0).sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(y - mid, 0.0, 1.0)

def interp_to_n(h, n_old, n_new):
    if n_old == n_new:
        return h.copy()
    x_old = np.arange(n_old) * (2.0 / n_old)
    x_new = np.linspace(0, 2.0, n_new, endpoint=False)
    h_new = np.interp(x_new, x_old, h)
    return project_feasible(h_new, n_new)

def nesterov_opt(h0, n, t_deadline):
    dx = 2.0 / n
    center = n - 1
    h = h0.copy()
    h_prev = h0.copy()
    c5_best = compute_c5(h)
    h_best = h.copy()
    it = 0
    no_improve = 0
    
    while time.time() < t_deadline:
        # Adaptive K
        frac = min(it / 200000.0, 1.0)
        K = max(1, int(1 + 39 * frac * frac))
        
        # Momentum
        beta = float(it) / (it + 1.5) if it else 0.0
        h_y = h + beta * (h - h_prev)
        
        # Correlation
        c_corr = np.correlate(h_y, 1.0 - h_y, mode="full")
        cmax = c_corr.max()
        
        # Gradient from top-K
        if K == 1:
            idx = int(np.argmax(c_corr))
            s = idx - center
            g = np.zeros(n)
            if s >= 0:
                g[s:] += (1.0 - h_y[:n-s])
                g[:n-s] -= h_y[s:]
            else:
                ss = -s
                g[:n-ss] += (1.0 - h_y[ss:])
                g[ss:] -= h_y[:n-ss]
        else:
            top_idx = np.argpartition(c_corr, -K)[-K:]
            tv = c_corr[top_idx]
            w = (tv / max(cmax, 1e-10)) ** 12
            ws = w.sum()
            if ws < 1e-15:
                w = np.ones(K) / K
            else:
                w /= ws
            g = np.zeros(n)
            for i in range(K):
                if w[i] < 1e-8:
                    continue
                s = top_idx[i] - center
                if s >= 0:
                    g[s:] += w[i] * (1.0 - h_y[:n-s])
                    g[:n-s] -= w[i] * h_y[s:]
                else:
                    ss = -s
                    g[:n-ss] += w[i] * (1.0 - h_y[ss:])
                    g[ss:] -= w[i] * h_y[:n-ss]
        
        # Step
        alpha = 0.7 / (1.0 + 0.005 * it)
        h_new = h_y - alpha * g * dx
        h_new = project_feasible(h_new, n)
        
        h_prev = h
        h = h_new
        it += 1
        
        # Check improvement
        if (it + 1) % 30000 == 0:
            c5_now = compute_c5(h)
            if c5_now < c5_best - 1e-6:
                c5_best = c5_now
                h_best = h.copy()
                no_improve = 0
            else:
                no_improve += 1
                if no_improve > 8:
                    # Restart momentum
                    h_prev = h.copy()
                    no_improve = 0
    
    return h_best, c5_best

def slsqp_refine(h0, n, t_deadline, T=4, maxiter=3000):
    target = n * 0.5
    dx = 2.0 / n
    center = n - 1
    n_corr = 2 * n - 1
    
    def obj(x):
        corr = np.correlate(x, 1.0 - x, mode="full")
        mc = corr.max()
        sh = T * (corr - mc)
        e = np.exp(sh)
        return (mc + np.log(e.sum()) / T) * dx
    
    def jac(x):
        corr = np.correlate(x, 1.0 - x, mode="full")
        mc = corr.max()
        sh = T * (corr - mc)
        e = np.exp(sh)
        sw = e / e.sum()
        g = np.zeros(n)
        for oi in range(n_corr):
            w = sw[oi]
            if w < 1e-10:
                continue
            s = oi - center
            if s >= 0:
                g[s:] += w * (1.0 - x[:n-s])
                g[:n-s] -= w * x[s:]
            else:
                ss = -s
                g[:n-ss] += w * (1.0 - x[ss:])
                g[ss:] -= x[:n-ss]
        return g * dx
    
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x: x.sum() - target,
             'jac': lambda x: np.ones(n)}]
    try:
        res = minimize(obj, h0, method='SLSQP', jac=jac,
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-16})
        return project_feasible(res.x, n)
    except Exception:
        return h0.copy()

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(y, n):
    target = n * 0.5
    lo = y.min() - 1.0
    hi = y.max() + 1.0
    mid = 0.0
    for _ in range(35):
        mid = (lo + hi) * 0.5
        s = np.clip(y - mid, 0.0, 1.0).sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(y - mid, 0.0, 1.0)

def interp_to_n(h, n_old, n_new):
    if n_old == n_new:
        return h.copy()
    x_old = np.arange(n_old) * (2.0 / n_old)
    x_new = np.linspace(0.0, 2.0, n_new, endpoint=False)
    h_new = np.interp(x_new, x_old, h)
    return project_feasible(h_new, n_new)

def _grad_one(h_y, n, s):
    g = np.zeros(n)
    if s >= 0:
        g[s:] += (1.0 - h_y[:n - s])
        g[:n - s] -= h_y[s:]
    else:
        ss = -s
        g[:n - ss] += (1.0 - h_y[ss:])
        g[ss:] -= h_y[:n - ss]
    return g

def nesterov_opt(h0, n, t_deadline):
    dx = 2.0 / n
    center = n - 1
    h = h0.copy()
    h_prev = h0.copy()
    c5_best = compute_c5(h)
    h_best = h.copy()
    it = 0
    no_improve = 0

    while time.time() < t_deadline:
        frac = min(it / 150000.0, 1.0)
        K = max(1, int(1 + 49 * frac * frac))

        beta = float(it) / (it + 1.5) if it else 0.0
        h_y = h + beta * (h - h_prev)

        c_corr = np.correlate(h_y, 1.0 - h_y, mode="full")
        cmax = c_corr.max()

        if K == 1:
            idx = int(np.argmax(c_corr))
            g = _grad_one(h_y, n, idx - center)
        else:
            top_idx = np.argpartition(c_corr, -K)[-K:]
            tv = c_corr[top_idx]
            w = (tv / max(cmax, 1e-10)) ** 12
            ws = w.sum()
            if ws < 1e-15:
                w = np.ones(K) / K
            else:
                w /= ws
            g = np.zeros(n)
            for i in range(K):
                if w[i] < 1e-8:
                    continue
                s = top_idx[i] - center
                gg = _grad_one(h_y, n, s)
                g += w[i] * gg

        alpha = 0.7 / (1.0 + 0.004 * it)
        h_new = h_y - alpha * g * dx
        h_new = project_feasible(h_new, n)

        h_prev = h
        h = h_new
        it += 1

        if (it + 1) % 25000 == 0:
            c5_now = compute_c5(h)
            if c5_now < c5_best - 5e-7:
                c5_best = c5_now
                h_best = h.copy()
                no_improve = 0
            else:
                no_improve += 1
                if no_improve > 10:
                    h_prev = h.copy()
                    no_improve = 0

    return h_best, c5_best

def _slsqp_obj(x, n, T):
    corr = np.correlate(x, 1.0 - x, mode="full")
    mc = corr.max()
    sh = T * (corr - mc)
    e = np.exp(sh)
    return (mc + np.log(e.sum()) / T) * (2.0 / n)

def _slsqp_jac(x, n, T):
    corr = np.correlate(x, 1.0 - x, mode="full")
    mc = corr.max()
    sh = T * (corr - mc)
    e = np.exp(sh)
    sw = e / e.sum()
    dx = 2.0 / n
    center = n - 1
    g = np.zeros(n)
    for oi in range(len(corr)):
        w = sw[oi]
        if w < 1e-10:
            continue
        s = oi - center
        g += w * _grad_one(x, n, s)
    return g * dx

def _cons_fun(x, n):
    return x.sum() - n * 0.5

def _cons_jac(x, n):
    return np.ones(len(x))

def slsqp_refine(h0, n, T, maxiter):
    target = n * 0.5
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x: x.sum() - target,
             'jac': lambda x: np.ones(len(x))}]
    try:
        res = minimize(_slsqp_obj, h0, args=(n, T), method='SLSQP',
                       jac=lambda x: _slsqp_jac(x, n, T),
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-16})
        return project_feasible(res.x, n)
    except Exception:
        return h0.copy()
