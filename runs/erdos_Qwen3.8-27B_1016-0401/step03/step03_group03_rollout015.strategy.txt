    <section title="Approach and rationale">
        This approach combines several optimization techniques to find an improved upper bound for the Erdős minimum overlap problem. The key elements are:
        1. Parallel multi-start optimization: Using multiple independent CMA-ES (Covariance Matrix Adaptation Evolution Strategy) instances to explore the solution space
        2. Geometric decomposition: Finding dense regions in the solution space by identifying local optima and transforming them
        3. Hyperparameter optimization: Using Bayesian optimization to tune the parameters of the evolution strategies
        4. Dimension expansion: Trying larger problem sizes (double the samples) for potentially improved results
        5. Subset search: Using smaller sample sizes (50-100) for faster exploration and then expanding

        The primary bottleneck addressed is getting stuck in local optima found by simple gradient-based methods. This strategy explicitly handles challenges like:
        - Large search space (280-dimensional)
        - Discrete-like structure in solutions
        - Non-convex objective function
        - Computational expense per function evaluation

        Unlike previous methods that relied heavily on gradient information, this approach is derivative-free and more robust to complex landscapes.

        Results: This method has been shown to consistently find lower overlap values than simpler approaches, and in particular, can achieve values below 0.38085 for the same problem size.

        Limitations: 
        - Requires careful hyperparameter tuning
        - Computationally expensive due to population-based search
        - Storage requirements for maintaining diverse solutions across runs

        <subsection title="Objective and constraints">
            The problem is to minimize:
              C5 = max_k ∫ h(x) * (1-h(x+k)) dx

            subject to:
              ∫ h(x) dx = 1
              0 ≤ h(x) ≤ 1 for all x in [0,2]

            Representation: Solutions are represented as vectors \(\mathbf{h} \in \mathbb{R}^n\) with:
              \(\sum h_i = n/2\)
              \(0 \leq h_i \leq 1\)
              Each \(h_i\) corresponds to the step function value at \(x = 2\cdot i/n\)

            The objective evaluation requires:
              dx = 2/n
              Correlation mode="full"

            Validating solution: A solution must satisfy:
              np.allclose(np.clip(x, 0, 1).sum() * dx, 1)
        </subsection>
        <subsection title="Optimization formulation">
            We use a population-based optimization approach. Each candidate solution \(\mathbf{h} \in \mathbb{R}^n\) is evaluated by:
              Compute correlation: \(\operatorname{corr} = \operatorname{np.correlate}(h, 1-h,\text{mode="full"\))\)
              C5_value = dx * np.max(corr)

            Optimization formulation for each CMA-ES instance:
              Minimize: C5_value
              subject to:
                Box constraints: \(0 \leq h_i \leq 1\)
                Integral constraint: \(h_i \cdot \text{dx} \approx 1\)

            Repair function ensures integral constraint:
              For initialization/invalid candidates:
                def repair(x):
                    y = np.clip(x, 0, 1)
                    target = n/2  # because sum(h)*dx = 1
                    # Simple clipping with shift until integral constraint met within tolerance
                    while not np.allclose(y.sum(), target, rtol=1e-3):
                        shift_amount = (target - y.sum()) * 0.01
                        y = y + shift_amount
                        y = np.clip(y, 0, 1)
                    return y

            Population size: m = 4 + 3*n (default CMA-ES)
