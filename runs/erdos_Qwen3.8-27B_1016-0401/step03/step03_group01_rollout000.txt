2. Find the argmax at 0 and at 1
3. If they're the same, check if the minimum is at a boundary
4. If different, find the crossing point

```python
        h[i] = best_t
    
    return h
```

Let me also think about a completely different approach: **formulate as a nonlinear program and use a different solver**.

The problem:
min C
s.t. for all k: sum_i h[i]*(1-h[i+k])*dx ≤ C
     sum(h) = n/2
     0 ≤ h ≤ 1

This is a non-convex problem (bilinear constraints), but for a fixed C, the feasibility check is: does there exist h satisfying all the bilinear constraints? This is still non-convex.

However, we can linearize: for a given h, the active constraints are those k where the correlation is near the max. We can then solve a linear program:
min C
s.t. for k in active_set: sum_i h[i]*(1-h[i+k]) ≤ C/dx
     sum(h) = n/2
     0 ≤ h ≤ 1

Wait, but h[i]*(1-h[i+k]) is still bilinear! Unless we fix one of them.

If we fix h[i+k] for all k and i (i.e., the "shifted" values are given), then the constraint becomes linear in h[i]:
sum_i h[i] * (1 - h_shifted[i+k]) ≤ C/dx

This is linear! So we can do alternating linearization:
1. Fix h_shifted = current h
2. Solve LP: min C subject to linearized constraints
3. Update h_shifted
4. Repeat

This is essentially the **Alternating Direction Method of Multipliers (ADMM)** or **Successive Linear Programming (SLP)** approach.

Let me implement this with scipy's linprog or cvxpy:

```python
def slp_step(h, n, n_lags=50):
    """One SLP iteration: linearize around current h and solve LP."""
    dx = 2.0 / n
    # Find top lags
    corr = np.correlate(h, 1.0 - h, mode="full")
    n_corr = len(corr)
    n_active = min(n_lags, n_corr)
    idx = np.argpartition(corr, -n_active)[-n_active:]
    center = n - 1
    
    # Linearize: for each active lag k, constraint is sum_i h[i] * (1-h[i+k-center]) ≤ C
    # where h[i+k-center] is treated as a constant (from current h)
    
    # Build LP: min C
    # s.t. for each active lag a: sum_i A[a,i] * h[i] ≤ C
    #      sum_i h[i] = n/2
    #      0 ≤ h[i] ≤ 1
    #      C ≥ 0
    
    # A[a,i] = (1-h[i+shift]) if i+shift valid, else 0; plus contribution from shifted h[i]*(-1)
    
    # Actually, corr[a] = sum_i h[i] * (1-h[i+a-center])
    # Linearizing around current h: corr[a] ≈ sum_i h_new[i] * (1-h_old[i+a-center])
    # (treating the shifted value as fixed)
    
    # So A[a,i] = (1 - h_old[i+a-center]) for valid indices
    
    import scipy.optimize as opt
    # Variables: [h[0], ..., h[n-1], C]
    # Objective: minimize C → c = [0,...,0,1]
    
    A_ub_rows = []
    b_ub_rows = []
    
    for a in idx:
        shift = a - center
        row = np.zeros(n + 1)
        if shift >= 0:
            for i in range(n - shift):
                row[i] = -(1.0 - h[i + shift])  # negative because we want ≤ C
            # -sum_i h[i]*(1-h[i+shift]) ≤ -C → sum_i h[i]*(1-h[i+shift]) ≥ -??
            # Actually: sum_i h[i]*(1-h[i+shift]) ≤ C
            # → sum_i (1-h[i+shift])*h[i] - C ≤ 0
            row[:n-shift] = (1.0 - h[shift:n])
            row[n] = -1.0
        else:
            s2 = -shift
            for i in range(s2, n):
                row[i] = (1.0 - h[i - s2])
            row[n] = -1.0
        A_ub_rows.append(row)
        b_ub_rows.append(0.0)
    
    # Equality: sum(h) = n/2
    A_eq = np.zeros((1, n+1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([n/2.0])
    
    c_obj = np.zeros(n+1)
    c_obj[n] = 1.0
    
    bounds = [(0,1)]*n + [(0,1)]
    
    res = opt.linprog(c_obj, A_ub=np.array(A_ub_rows), b_ub=np.array(b_ub_rows),
                      A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')
    
    if res.success:
        return res.x[:n]
    return h.copy()
```

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(y, n):
    target = n / 2.0
    lo, hi = y.min() - 2.0, y.max() + 2.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        s = np.clip(y - mid, 0.0, 1.0).sum()
        if abs(s - target) < 1e-13:
            break
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(y - mid, 0.0, 1.0)

def coord_pass(h, n, iters_per_coord=10):
    """Coordinate descent with exact 1D minimization of max correlation."""
    center = n - 1
    n_corr = 2 * n - 1
    s_range = np.arange(n_corr)
    
    for i in range(n):
        idx1 = i + s_range - center
        idx2 = i - s_range + center
        v1 = (idx1 >= 0) & (idx1 < n)
        v2 = (idx2 >= 0) & (idx2 < n)
        
        a = np.zeros(n_corr)
        if v1.any():
            a[v1] = 1.0 - h[idx1[v1]]
        if v2.any():
            a[v2] -= h[idx2[v2]]
        
        corr = np.correlate(h, 1.0 - h, mode="full")
        b = corr - h[i] * a
        
        lo, hi = 0.0, 1.0
        best_t = h[i]
        best_v = np.max(b + h[i] * a)
        for _ in range(iters_per_coord):
            m1 = lo + (hi - lo) / 3.0
            m2 = hi - (hi - lo) / 3.0
            v1t = np.max(b + m1 * a)
            v2t = np.max(b + m2 * a)

def subgrad_step(h, n, top_k=5, lr=0.05):
    """Subgradient step on the max of bilinear forms."""
    dx = 2.0 / n

    center = n - 1
    mk = min(top_k, len(corr))

            grad[m2] -= h[j[m2] - s2]
    grad *= dx / mk
    h_new = h - lr * grad
