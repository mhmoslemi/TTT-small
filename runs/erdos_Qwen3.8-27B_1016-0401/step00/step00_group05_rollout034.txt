Now the gradient computation. For f_k(h) = sum_i h[i](1-h[i+k]) (non-circular):

For k = 0: f_0 = sum h[i]²... wait, f_0 = sum h[i](1-h[i]) = sum h[i] - sum h[i]².

For k > 0: f_k = sum_{i=0}^{n-1-k} h[i](1-h[i+k])
df_k/dh[j] = sum over terms where j appears.
- If j is in [0, n-1-k] (as i=j): contributes (1-h[j+k])
- If j-k is in [0, n-1-k] (as i+k=j, i=j-k): contributes -h[j-k]
So df_k/dh[j] = (1-h[j+k]) * [j ≤ n-1-k] - h[j-k] * [j-k ≥ 0 and j-k ≤ n-1-k]

For k < 0 (let k = -m, m > 0): f_{-m} = sum_{i=m}^{n-1} h[i](1-h[i-m])

= (1-h[j-m]) - h[j+m] * [j ≤ n-1-m]

So the gradient is:
grad[j] = (1 - h[j+k]) * valid1 - h[j-k] * valid2 (for k > 0)
where valid1 = (0 ≤ j ≤ n-1-k) and valid2 = (0 ≤ j-k ≤ n-1-k)

Let me simplify for k > 0:

- valid2: j-k ∈ [0, n-1-k] → j ∈ [k, n-1] → contributes -h[j-k]
