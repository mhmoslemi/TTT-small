c[m] = sum_ν h[ν] * (1-h[ν+m-(n-1)])

For a fixed m, the terms involving h[i] are:
- When ν = i: h[i] * (1-h[i+m-(n-1)])
- When ν+m-(n-1) = i, i.e., ν = i-m+(n-1): h[i-m+(n-1)] * (1-h[i])

where R_m doesn't depend on h[i].

= h[i] - h[i]*h[i+m-n+1] + h[i-m+n-1] - h[i-m+n-1]*h[i] + R_m

Let a = h[i+m-n+1] (if valid) and b = h[i-m+n-1] (if valid)

c[m] = h[i](1-a) + b(1-h[i]) + R_m
= h[i] - a*h[i] + b - b*h[i] + R_m
= h[i](1-a-b) + (b + R_m)

So c[m] is linear in h[i]! The slope is (1-a-b) and the intercept is (b+R_m).

Therefore, the objective max_m c[m] is the max of linear functions of h[i], which is convex. We can minimize it by finding the point where the max is minimized.

For a single variable optimization with convex objective (max of linear functions), the optimal value is where the two "active" constraints are equal, or at a boundary.

This is great! It means for coordinate descent, we can compute the exact optimal h[i] in O(n) time (just evaluate all the slopes and intercepts).

```python
def optimal_coord(h, n, i):
    """Find optimal h[i] given all other h fixed. Returns optimal value."""
    # For each m (0 to 2n-2), compute slope and intercept of c[m] as function of h[i]
    # c[m] = sum_v h[v] * (1-h[v + m - (n-1)])
    # Terms with h[i]:
    #   v = i: contributes h[i] * (1 - h[i + m - n + 1]) if 0 <= i+m-n+1 < n
    #   v + m - n + 1 = i, i.e., v = i - m + n - 1: contributes h[i-m+n-1] * (1-h[i]) if 0 <= i-m+n-1 < n
    
    n2 = 2*n - 1
    slopes = np.zeros(n2)
    intercepts = np.zeros(n2)
    
    # Compute base correlation without h[i] contribution
    # Actually, let's just compute slope and intercept directly
    
    for m in range(n2):
        shift = m - (n-1)
        # v = i: valid if 0 <= i + shift < n
        # contributes h[i] * (1 - h[i+shift])
        # This gives: slope contribution = (1 - h[i+shift]), intercept = 0
        valid1 = 0 <= i + shift < n
        # v = i - shift: valid if 0 <= i - shift < n
        # contributes h[i-shift] * (1 - h[i])
        # This gives: slope contribution = -h[i-shift], intercept = h[i-shift]
        valid2 = 0 <= i - shift < n
        
        if valid1:
            slopes[m] = (1.0 - h[i + shift])
        # else slopes[m] stays 0 from this term
        
        if valid2:
            slopes[m] -= h[i - shift]
            intercepts[m] += h[i - shift]
    
    # Now c[m] = slopes[m] * h[i] + intercepts[m]
    # We want to minimize max_m (slopes[m]*x + intercepts[m]) for x in [0,1]
    
    # This is a 1D LP / minimax problem
    # The objective is convex in x (max of linear functions)
    # Find x that minimizes it
    
    # Simple: ternary search or bisection on the subgradient
    # Or: find the x where the max is minimized
    # For a convex piecewise-linear function, the minimum is where the subgradient contains 0
    
    # Let's just do a fine grid search
    xs = np.linspace(0, 1, 101)
    vals = slopes[:, None] * xs[None, :] + intercepts[:, None]
    obj = vals.max(axis=0)
    best_idx = obj.argmin()
    
    return xs[best_idx]
```

```python
def optimize_coord(h, n, i):
    """Minimize C5 by optimizing h[i] (keeping others fixed). Returns new h[i]."""
    n2 = 2 * n - 1
    shift = np.arange(n2) - (n - 1)  # -[n-1] to n-1
    
    # For each m, the contribution to c[m] from h[i]:
    # If 0 <= i+shift[m] < n: h[i] * (1 - h[i+shift[m]])
    # If 0 <= i-shift[m] < n: h[i-shift[m]] * (1 - h[i])
    
    # c[m] = base[m] + h[i] * slope[m]
    base = np.zeros(n2)
    slope = np.zeros(n2)
    
    # h[i] * (1 - h[i+shift]) for valid i+shift
    valid1 = (i + shift >= 0) & (i + shift < n)
    slope[valid1] += (1.0 - h[i + shift[valid1]])
    
    # h[i-shift] * (1 - h[i]) for valid i-shift
    valid2 = (i - shift >= 0) & (i - shift < n)
    slope[valid2] -= h[i - shift[valid2]]
    base[valid2] += h[i - shift[valid2]]
    
    # Now minimize max_m (base[m] + x * slope[m]) for x in [0,1]
    # Convex piecewise linear in x
    
    # Evaluate at endpoints and find minimum
    x = np.linspace(0.0, 1.0, 201)
    obj = (base[None, :] + x[:, None] * slope[None, :]).max(axis=1)
    best_x = x[obj.argmin()]
```

```python
def opt_coord(h, n, i):
    """Find best h[i] minimizing max correlation, with others fixed."""
    n2 = 2 * n - 1
    sh = np.arange(n2) - (n - 1)
    
    # c[m] = base[m] + x * slope[m] where x = h[i]
    base = np.zeros(n2)
    slope = np.zeros(n2)
    
    # Term: h[i] * (1 - h[i+sh[m]]) for valid i+sh[m]
    v1 = (i + sh >= 0) & (i + sh < n)
    # When h[i] = x: contribution is x * (1 - h[i+sh[m]])
    # slope contribution: (1 - h[i+sh[m]])
    # base contribution: 0
    slope[v1] += (1.0 - h[i + sh[v1]])
    
    # Term: h[i-sh[m]] * (1 - h[i]) for valid i-sh[m]
    v2 = (i - sh >= 0) & (i - sh < n)
    # When h[i] = x: contribution is h[i-sh[m]] * (1-x)
    # = h[i-sh[m]] - h[i]*h[i-sh[m]]
    # slope: -h[i-sh[m]]
    # base: h[i-sh[m]]
    slope[v2] -= h[i - sh[v2]]
    base[v2] += h[i - sh[v2]]
    
    # Minimize max_m(base[m] + x*slope[m]) for x in [0,1]
    # Use fine grid
    x = np.linspace(0.0, 1.0, 401)
    obj = np.max(base[None, :] + x[:, None] * slope[None, :], axis=1)
    return x[obj.argmin()]
```
