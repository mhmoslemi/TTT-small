```python
    dx = 2.0 / n
    omh = 1.0 - h
    cr = np.correlate(h, omh, mode="full")

        if 0 <= a < n: v += omh[a]

        if 0 <= b < n: v -= h[b]

    idx = np.argsort(h)[::-1]

    b[idx[:target]] = 1.0

    """Compute C5 after swapping b[i] and b[j] (b[i]=1→0, b[j]=0→1) without modifying b."""
    # Actually just modify, compute, revert
    b[i], b[j] = b[j], b[i]
```

Actually, let me try a different approach: for the binary local search, I can make it much more efficient by computing the change in C5 analytically for each swap.

For a binary vector b, the correlation at lag p is:
c_p = Σ_n b[n+p] * (1-b[n])

For a swap b[i]: 1→0, b[j]: 0→1:
Δc_p = [change from b[i] going 1→0] + [change from b[j] going 0→1]

Change from b[i]: 1→0:
- In the first factor b[n+p]: when n+p=i → n=i-p. Term was 1*(1-b[i-p]) → 0. Change: -(1-b[i-p]) if 0≤i-p<n
- In the second factor (1-b[n]): when n=i. Term was b[i+p]*1 → b[i+p]*0. Change: -b[i+p] if 0≤i+p<n

Change from b[j]: 0→1:
- In the first factor: n+p=j → n=j-p. Term was 0 → 1*(1-b[j-p]). Change: (1-b[j-p]) if 0≤j-p<n
- In the second factor: n=j. Term was b[j+p]*0 → b[j+p]*1. Change: +b[j+p] if 0≤j+p<n

So: Δc_p = -(1-b[i-p])*1[0≤i-p<n] - b[i+p]*1[0≤i+p<n] + (1-b[j-p])*1[0≤j-p<n] + b[j+p]*1[0≤j+p<n]

This is O(1) per lag p, and there are 2n-1 lags. So computing all Δc_p is O(n).

Then new_C5 = max_p (c_p + Δc_p) * dx.

So for each swap, we can compute the new C5 in O(n) by updating all correlation values. Total per swap: O(n). Total per pick of best swap: O(n^2). Total per full pass: O(n^3).

This is much more efficient than recomputing the full correlation each time (O(n^2) per swap × n^2 swaps = O(n^4)).

For n=70: O(n^3) = 343k per pass vs O(n^4) = 24M per pass. Big improvement.

```python
    cr = np.correlate(b, omh, mode="full").astype(float)
    curr_max = float(np.max(cr))
    curr_c5 = curr_max * dx
    lags = np.arange(-(n-1), n)  # all lag values
    
    for _ in range(passes):
        ones = list(np.where(b == 1)[0])
        zeros = list(np.where(b == 0)[0])
        rs.shuffle(ones)
        rs.shuffle(zeros)
        improved = False
        for i in ones:
            # Δ from b[i]: 1→0: -(omh[i-p])*1[0≤i-p<n] - b[i+p]*1[0≤i+p<n]
            # Vectorized over lags
            delta_i = np.zeros(2*n-1)
            idx = i - lags  # position in omh for each lag
            valid = (idx >= 0) & (idx < n)
            delta_i[valid] -= omh[idx[valid]]
            idx2 = i + lags
            valid2 = (idx2 >= 0) & (idx2 < n)
            delta_i[valid2] -= b[idx2[valid2]]
            
            for j in zeros:
                delta_j = np.zeros(2*n-1)
                jIdx = j - lags
                jv = (jIdx >= 0) & (jIdx < n)
                delta_j[jv] += omh[jIdx[jv]]
                jIdx2 = j + lags
                jv2 = (jIdx2 >= 0) & (jIdx2 < n)
                delta_j[jv2] += b[jIdx2[jv2]]
                
                new_cr = cr + delta_i + delta_j
                new_max = float(np.max(new_cr))
                if new_max < curr_max - 1e-14:
                    b[i] = 0.0; b[j] = 1.0
                    omh[i] = 1.0; omh[j] = 0.0
                    cr = new_cr
                    curr_max = new_max
                    curr_c5 = new_max * dx
                    improved = True
                    break
            if improved:
                break
        if not improved:
            break
    return b, curr_c5
```

This is O(n) per swap (vectorized), and O(n^2) per full pass over all swaps. Much faster than before.
