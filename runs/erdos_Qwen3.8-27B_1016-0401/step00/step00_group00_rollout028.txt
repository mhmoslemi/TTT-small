Wait, I want to double-check: `np.correlate(h, 1-h, mode="full")` - what does this compute exactly?

For arrays a and v of length n, np.correlate(a, v, mode="full") returns an array of length 2n-1.
The k-th element (0-indexed) is: sum_i a[i+k] * conj(v[i]) for valid i.

So for a=h, v=(1-h):
correlate[k] = sum_i h[i+k] * (1-h[i]) for valid i

For k=0: sum_i h[i]*(1-h[i]) = sum_i h[i] - sum_i h[i]^2
For k>0: sum_{i=0}^{n-1-k} h[i+k]*(1-h[i])
For k<0 (represented as 2n-2-k in the full array): sum_{i=0}^{n-1-k} h[i]*(1-h[i-k])

Actually, the "full" mode means:
- For lag τ from -(n-1) to (n-1):
  corr[τ + n - 1] = sum_i a[i+τ] * conj(v[i]) for valid i

So the maximum over all lags of the correlate values, times dx, gives C5.

This is what we want: max over all shifts of ∫h(x+τ)(1-h(x))dx ≈ sum_i h[i+τ]*(1-h[i])*dx

    t1 = t0 + budget_s * 0.22
    t2 = t0 + budget_s * 0.50
    t3 = t0 + budget_s * 0.85
    t4 = t0 + budget_s * 0.95

    # Phase 1: Projected gradient descent with increasing smoothness
    for alpha in [5, 20, 50, 100, 300]:
        if time.time() > t1:
            break
        h_c = pd_refine(best_h, alpha, n, 300, t1, 0.05)
        c = c5_of(h_c)
        if c < best_c5:
            best_c5 = c
            best_h = h_c.copy()

    # Phase 2: Coordinate descent for local refinement
    if time.time() < t2:
        h_c = coord_descent(best_h, n, 4000, t2)
        c = c5_of(h_c)
        if c < best_c5:
            best_c5 = c
            best_h = h_c.copy()

    # Phase 3: Evolutionary search with adaptive sigma
    if time.time() < t3:
        sigma = 0.12
        for gen in range(500):
            if time.time() > t3:
                break
            best_g = best_c5
            best_gx = best_h.copy()
            for j in range(12):
                scale = sigma * (0.5 + j * 0.4)
                x = best_h + rng.randn(n) * scale
                x = project_feasible(x, n)
                c = c5_of(x)
                if c < best_g:
                    best_g = c
                    best_gx = x.copy()
            if best_g < best_c5:
                best_c5 = best_g
                best_h = best_gx
                sigma = min(sigma * 1.04, 0.5)
            else:
                sigma *= 0.94
            hr = pd_refine(best_h, 50, n, 40, t3, 0.03)
            cr = c5_of(hr)
            if cr < best_c5:
                best_c5 = cr
                best_h = hr.copy()

    # Phase 4: Random restarts to escape local optima
    if time.time() < t3 + budget_s * 0.06:
        t_rr = t3 + budget_s * 0.06
        for r in range(30):
            if time.time() > t_rr:
                break
            hr = project_feasible(rng.rand(n), n)
            hr = pd_refine(hr, 20, n, 80, t_rr, 0.08)
            c = c5_of(hr)
            if c < best_c5:
                best_c5 = c
                best_h = hr.copy()

    # Phase 5: Final fine-tune with high alpha
    if time.time() < t4:
        hf = pd_refine(best_h, 500, n, 200, t4, 0.02)
        c = c5_of(hf)
        if c < best_c5:
            best_c5 = c
            best_h = hf.copy()
        # Extra coordinate polish
        hf2 = coord_descent(best_h, n, 1000, t4)
        c = c5_of(hf2)
        if c < best_c5:
            best_c5 = c
            best_h = hf2.copy()

    best_h = project_feasible(best_h, n)
    best_c5 = c5_of(best_h)
    if not np.isfinite(best_c5):
        best_h = np.full(n, 0.5)
        best_c5 = c5_of(best_h)
    return (best_h, best_c5, n)
