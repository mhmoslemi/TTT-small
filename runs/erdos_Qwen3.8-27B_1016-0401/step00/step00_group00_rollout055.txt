1. Generate candidate in unconstrained space
2. Apply projection: clip to [0,1], then adjust to meet sum constraint
3. For the sum adjustment, use a bisection on a threshold:

    corr = np.correlate(h, 1.0 - h, mode="full")

    max_idx = np.where(np.isclose(corr, max_val, atol=1e-12))[0]
    lags = max_idx - (n - 1)
    
    j = np.arange(n)
    grad = np.zeros(n)
    for lag in lags:
        # (1-h_{j-lag}) where 0<=j-lag<n
        jl = j - lag
        m1 = (jl >= 0) & (jl < n)
        if m1.any():
            grad[m1] += (1.0 - h[jl[m1]])
        # -h_{j+lag} where 0<=j+lag<n
        jp = j + lag
        m2 = (jp >= 0) & (jp < n)
        if m2.any():
            grad[m2] -= h[jp[m2]]
    
    grad *= dx / len(lags)
    return C5, grad

But the chain rule through the projection is complex. The projection is:
project_feasible(v, n) = clip(v - t*, 0, 1) where t* is found by bisection.

The Jacobian of the projection is:
∂h_i/∂v_j = δ_{ij} - ∂t*/∂v_j

And ∂t*/∂v_j is found from the constraint sum(h) = n/2:
∂/∂v_j [sum_i clip(v_i - t*, 0, 1)] = 0
This gives: I(0 < v_j - t* < 1) - sum_i I(0 < v_i - t* < 1) * ∂t*/∂v_j = 0
So ∂t*/∂v_j = I(0 < v_j - t* < 1) / |{i: 0 < v_i - t* < 1}|

Let S = {i: 0 < v_i - t* < 1} (the set of non-saturated coordinates).
Then ∂h_i/∂v_j = δ_{ij} - I(j∈S) / |S| for i∈S, and 0 otherwise.

So J = P_S (I - (1/|S|) 11^T) where P_S is the projection onto coordinates in S.

The composite gradient is: J^T * ∇C5(h) = P_S (I - (1/|S|) 11^T) ∇C5(h)

Since P_S just zeros out coordinates not in S, and (I - (1/|S|) 11^T) reduces the gradient by its mean over S:

composite_grad[i] = grad_C5[i] - mean_S(grad_C5) if i ∈ S, else 0

This is the projected gradient! It's the component of the gradient that's tangent to the constraint surface.

So I can compute the composite gradient in O(n) after computing ∇C5(h):

```python
def composite_grad(v, n):
    h = project_feasible(v, n)
    C5, g = c5_and_grad(h)
    # Find non-saturated coordinates
    # From the projection, h = clip(v - t, 0, 1)
    # S = {i: 0 < h_i < 1} (approximately, but need to be careful at the threshold)
    S = (h > 1e-10) & (h < 1.0 - 1e-10)
    if S.sum() == 0:
        return C5, np.zeros(n)
    # Projected gradient
    g_proj = np.zeros(n)
    g_proj[S] = g[S] - g[S].mean()
    return C5, g_proj
```
