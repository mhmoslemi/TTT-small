We have corr = np.correlate(h, 1-h, mode="full").

NumPy docs: for 1-D, c_k = ∑_n a_{n+k} · conj(v_n)

So for a=h (length N) and v=1-h (length N):
c_k = ∑_n h_{n+k} · (1-h)_n

The "full" mode gives k ranging from -(N-1) to N-1, stored in an array of length 2N-1.
The index in the output array is k + (N-1).

So output[j] = c_{j-(N-1)} = ∑_n h_{n + j - (N-1)} · (1-h)_n

where the sum is over all n such that 0 ≤ n < N and 0 ≤ n + j - (N-1) < N.

Let s = j - (N-1) (the shift). Then:
output[j] = ∑_n h_{n+s} · (1-h)_n

valid when 0 ≤ n < N and 0 ≤ n+s < N.

Now, the gradient of output[j*] with respect to h[m]:

output[j*] = ∑_n h_{n+s} · (1-h)_n

Term where h[m] appears:
1. As h_{n+s} when n+s = m, i.e., n = m-s. Need 0 ≤ m-s < N and 0 ≤ (m-s)+s < N → 0 ≤ m < N.
   Contribution: (1-h)_{m-s} = 1 - h[m-s]

2. As (1-h)_n when n = m. Need 0 ≤ m < N and 0 ≤ m+s < N.
   Contribution: -h_{m+s} = -h[m+s] (derivative of (1-h_m) w.r.t. h_m is -1)

So: ∂output[j*]/∂h[m] = (1-h[m-s])·[0≤m-s<N] - h[m+s]·[0≤m+s<N]

And C5 = dx · max_j output[j], so:
∂C5/∂h[m] = dx · [(1-h[m-s])·[0≤m-s<N] - h[m+s]·[0≤m+s<N]]
