For k=1: sum_i h[i]*(1-h[i+1]) = sum_{i even, i+1 < n} 1*(1-0) + sum_{i odd, i+1 < n} 0*(...) = (n/2 - 1) if n even
  Wait: i even and i+1 odd: h[i]=1, h[i+1]=0, so 1*(1-0)=1. There are n/2-1 such pairs (i=0,2,...,n-4)
  i odd: h[i]=0, contribution is 0.
  Also need i+1 < n: i < n-1, so i up to n-4 (even). Count: (n-2)/2 - 1 + 1 = (n-4)/2 + 1 = n/2 - 1.
  So corr[1] ≈ n/2 - 1.
  C₅ contribution: (n/2-1)*2/n ≈ 1. That's bad!

So the alternating pattern is bad because it maximizes the correlation at odd lags.

What about a block pattern? h = [1,1,...,1, 0,0,...,0] with n/2 ones then n/2 zeros.
corr[0] = 0 (binary)
corr[k] for k > 0: sum_{i=0}^{n/2-1} 1*(1-h[i+k]) + sum_{i=n/2}^{n-1} 0*(...) 
= sum_{i=0}^{n/2-1} (1-h[i+k])
For k < n/2: h[i+k] = 1 for i < n/2-k, h[i+k] = 0 for i ≥ n/2-k
So corr[k] = (n/2-k)*0 + k*1 = k for k < n/2
For k ≥ n/2: h[i+k] = 0 for all i < n/2, so corr[k] = n/2

Max corr = n/2, C₅ = n/2 * 2/n = 1. Also bad!

What about a more complex pattern? The key insight is we want the autocorrelation R_h(k) = sum_i h[i]*h[i+k] to be as large as possible for all k. Since C₅ = max_k (n/2 - R_h(k)) * 2/n = 1 - 2*R_h(k)/n (for the max over k).

Wait: C₅ = max_k corr[k] * 2/n = max_k (n/2 - R_h(k)) * 2/n = 1 - 2*min_k R_h(k)/n

So minimizing C₅ = maximizing min_k R_h(k)/n.

For the binary pattern with n/2 ones: R_h(k) is between 0 and n/4 (since at most n/4 pairs of both-1s can overlap for any shift... actually for k=0, R_h(0) = n/2 * 1 = n/2 since h[i]² = h[i] for binary).

Wait, R_h(0) = sum h[i]² = n/2 for binary. So C₅ at k=0: (n/2 - n/2)*2/n = 0. Good.

For other k: R_h(k) = number of i where both h[i]=1 and h[i+k]=1.

We want to maximize the minimum of R_h(k) over all k. This is a combinatorial design problem! We want a binary sequence of length n with n/2 ones that maximizes the minimum autocorrelation.

This is related to "difference sets" and "Golomb rulers" in combinatorial design theory!

A (v, k, λ) difference set has the property that every nonzero difference appears exactly λ times. If we take the indicator of a difference set as h, then R_h(k) = λ for all nonzero k, and R_h(0) = k (the size of the set).

For our problem: v = n, k = n/2 (number of ones), and we want R_h(k) ≈ λ for all k ≠ 0.

But a (v, k, λ) difference set requires v = k(k-1)/λ + 1 and specific conditions. The most famous is the (7, 3, 1) difference set (Fano plane), giving n=7, k=3, λ=1. But we need k = n/2, so n=6, k=3... that doesn't match the difference set parameters.

Actually, for our problem, we don't need a perfect difference set. We just want the autocorrelation to be as flat as possible. This is the "Golomb ruler" / "optimal binary sequence" problem.

For even n with n/2 ones, the minimum possible max autocorrelation is approximately n/4 (by averaging: sum_k R_h(k) = (sum h[i])² = n²/4, so average R_h(k) ≈ n/4 over n lags). So the best we can do is min_k R_h(k) ≈ n/4, giving C₅ ≈ 1 - 2*(n/4)/n = 1 - 1/2 = 1/2.

import numpy as np
from scipy.optimize import minimize
import time

def _c5(h):
    n = len(h)
    return float(np.correlate(h, 1.0 - h, mode="full").max() * (2.0 / n))

def _proj(h, n):
    tgt = 0.5 * n
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        d = h.sum() - tgt
        if abs(d) < 1e-15:
            break
        h -= d / n
        np.clip(h, 0.0, 1.0, out=h)
    r = tgt - h.sum()
    if abs(r) > 1e-14:
        if r > 0:
            msk = h < 1.0
        else:
            msk = h > 0.0
        if msk.any():
            h[msk] += r / msk.sum()
            np.clip(h, 0.0, 1.0, out=h)
    return h

def _smooth_max(corr, s):
    m = corr.max()
    return (m + np.log(np.exp(s*(corr - m)).sum()) / s)

def _slsqp_smooth(h, n, dx, scale, maxiter):
    # SLSQP with smooth max objective
    def obj(x):
        x = np.clip(x, 0, 1)
        corr = np.correlate(x, 1.0 - x, mode="full")
        return _smooth_max(corr, scale) * dx
    
    def cons_eq(x):
        return x.sum() - 0.5 * n
    
    bds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cons_eq, 'jac': lambda x: np.ones(n)}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-16})
        return _proj(res.x, n)
    except:
        return _proj(h, n)

def _coord_descent(h, n, time_limit, rng):
    t0 = time.time()
    tgt = 0.5 * n
    best_h = h.copy()
    best_c = _c5(best_h)
    
    while time.time() - t0 < time_limit:
        # One pass of coordinate descent
        order = rng.permutation(n)
        for i in order:
            # Choose partner
            j = rng.randint(n)
            if j == i:
                j = (i + 1) % n

            t_lo = max(0.0, s - 1.0)
            t_hi = min(1.0, s)
            if t_hi - t_lo < 1e-12:
                continue
            
            # Golden section search for optimal t
            gr = (np.sqrt(5.0) - 1.0) / 2.0  # golden ratio conjugate
            a, b = t_lo, t_hi
            c_ = b - gr * (b - a)
            d_ = a + gr * (b - a)
            
            def f1d(t):
                h[i] = t
                h[j] = s - t
                corr = np.correlate(h, 1.0 - h, mode="full")
                return corr.max()
            
            fc = f1d(c_)
            fd = f1d(d_)
            for _ in range(30):  # 30 iterations of golden section
                if fc < fd:
                    b = d_
                    d_ = c_
                    fd = fc
                    c_ = b - gr * (b - a)
                    fc = f1d(c_)
                else:
                    a = c_
                    c_ = d_
                    fc = fd
                    d_ = a + gr * (b - a)
                    fd = f1d(d_)
            t_best = (a + b) / 2.0
            
            h[i] = t_best
            h[j] = s - t_best
            # Re-project
            np.clip(h, 0.0, 1.0, out=h)
            r = tgt - h.sum()
            if abs(r) > 1e-14:
                h += r / n
                np.clip(h, 0.0, 1.0, out=h)
        
        # Evaluate
        c = _c5(h)
        if c < best_c:
            best_h = h.copy()
            best_c = c
    
    return best_h, best_c

import time

def _c5(h):
    n = len(h)
    return float(np.correlate(h, 1.0 - h, mode="full").max() * (2.0 / n))

def _proj(h, n):
    tgt = 0.5 * n
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        d = h.sum() - tgt
        if abs(d) < 1e-15:
            break
        h -= d / n
        np.clip(h, 0.0, 1.0, out=h)
    r = tgt - h.sum()
    if abs(r) > 1e-14:
        if r > 0:
            msk = h < 1.0
        else:
            msk = h > 0.0
        if msk.any():
            h[msk] += r / msk.sum()
            np.clip(h, 0.0, 1.0, out=h)
    return h

def _smooth_max_val(corr, s):
    m = corr.max()
    return float(m + np.log(np.exp(s * (corr - m)).sum()) / s)

def _slsqp(h, n, scale, maxiter):
    dx = 2.0 / n
    tgt = 0.5 * n
    def obj(x):
        x = np.clip(x, 0.0, 1.0)
        corr = np.correlate(x, 1.0 - x, mode="full")
        return _smooth_max_val(corr, scale) * dx
    def eq_fun(x):
        return x.sum() - tgt
    def eq_jac(x):
        return np.ones(n)
    bds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': eq_fun, 'jac': eq_jac}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-18})
        return _proj(res.x, n)
    except Exception:
        return _proj(h, n)

def _golden_1d(h, i, j, n, iters=40):

    d_ = a + gr * (b - a)

_G_DX = 0.0
_G_SCALE = 1.0

def _c5(h):
    n = len(h)
    return float(np.correlate(h, 1.0 - h, mode="full").max() * (2.0 / n))

def _proj(h, n):
    tgt = 0.5 * n
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        d = h.sum() - tgt
        if abs(d) < 1e-15:
            break
        h -= d / n
        np.clip(h, 0.0, 1.0, out=h)
    r = tgt - h.sum()
    if abs(r) > 1e-14:
        if r > 0:
            msk = h < 1.0
        else:
            msk = h > 0.0
        if msk.any():
            h[msk] += r / msk.sum()
            np.clip(h, 0.0, 1.0, out=h)
    return h

    x = np.clip(x, 0.0, 1.0)
    corr = np.correlate(x, 1.0 - x, mode="full")
    m = corr.max()
