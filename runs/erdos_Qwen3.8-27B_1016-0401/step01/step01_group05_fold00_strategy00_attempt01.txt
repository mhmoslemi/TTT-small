2. **Improved transition between scales** - By explicitly validating transformations between grid resolutions, we ensure consistent solutions across scales.
3. **Higher-quality initializations** - A novel binary transformation combined with Gaussian smoothing creates more promising starting points.

- `h`: Continuous values in `[0, 1]` of length `N_points`
- `dx = 2.0 / N_points`: Spatial discretization

**Objective:** Minimize

`C = (max(np.correlate(h, 1-h, mode='full')) * dx`

**Transition between grids:** Exploiting mathematical consistency under resampling to transfer valid solutions between scales.

**Feasibility:** Ensured through:
1. Clipping values into `[0, 1]`
2. Adjusting the global sum by redistributing errors
3. Strict validation before grid expansion

### Key mathematical innovations:
1. **Cross-scale constraint satisfaction:** We ensure solutions transform consistently between grid sizes (e.g., downsampleable candidate states)
2. **Probabilistic binary initialization:** Using randomized convex combinations of binary vectors with exact sum constraints
3. **Efficient local search:** Using a two-step local perturbation method that avoids costly function evaluations

                adjust = ones[np.random.choice(np.arange(len(ones)))]
                h[adjust] -= delta
            elif np.count_nonzero(ones) > np.count_nonzero(zeros) and delta > 0:
                adjust = zeros[np.random.choice(np.arange(len(zeros)))]
                h[adjust] += delta
            break
        
        if np.random.random() < 0.5 and zeros.any():
            mask = zeros
            prob = mask.astype(float) / np.count_nonzero(mask)
            if diff > 0:
                # Too few, add
                inc = np.random.choice(np.arange(len(h)), size=min(np.count_nonzero(zeros), 7), replace=False)
                h[inc] += 0.005
            else:
                # Too many, remove
                to_remove = zeros[prob > (diff / len(h))]
                h[to_remove] -= 0.005
        else:
            mask = ones
            prob = mask.astype(float) / np.count_nonzero(mask)
            if diff > 0:
                inc = np.random.choice(np.arange(len(h)), size=min(np.count_nonzero(ones), 7), replace=False)
                h[inc] -= 0.005
        
        h = np.clip(h, 0, 1)
        target_new = np.sum(h)
        if abs(target_new - len(h)/2) < 1e-6:
            break
    
    return h

def make_feasible_alt(h):
    # Another feasibility approach
    h = np.clip(h.astype(float), 0.0, 1.0)
    
    # Enforce sum constraint
    if abs(sum(h) - len(h)/2) > 1e-6:
        max_iter = 100
        period = 1
        alpha = 0.05
        
        for _ in range(max_iter):
            deficit = (len(h)/2 - sum(h)) * alpha
            
            # Group indices for parallel adjustment
            indices = np.arange(len(h))
            np.random.shuffle(indices)
            groups = np.array_split(indices, period)
            
            for group in groups:
                h_this = h[group]
                
                # Clip extreme values
                too_low = h_this < 0.2
                too_high = h_this > 0.8
                
                # Adjust distribution within group
                too_low_sum = sum(h_this[too_low])
                too_high_sum = sum(h_this[too_high])
                
                if deficit * np.log(1 + too_low_sum) < 0:
                    # Move probability from high to low
                    to_adjust = np.random.choice(too_high)
                    min_val = np.min(h_this)
                    if min_val < 0.001:
                        h_this[to_adjust] = min_val * 0.5
                    else:
                        h_this[to_adjust] *= 0.5
            
            h += deficit
            sum_new = sum(h)
            if abs(sum_new - len(h)/2) < 1e-6:
                break
        
        h = np.clip(h, 0, 1)
    
    return h

def compute_c5(h):
    dx = 2.0 / len(h)
    # Ensure proper length for correlation
    # Construct auto-normalized 1-h array for correlation
    corr = np.correlate(h, 1-h, mode='full')
    max_corr_val = np.max(corr)
    
    # Special handling for very small candidates
    if max_corr_val == 0.0:
        return 0.0
    
    # Check if correlation might be miscomputed due to normalization
    return float(max_corr_val) * dx

def construct_cand_level1(n=14):
    # Level 1 candidate construction
    target_sum = n/2
    binary = np.random.rand(n) > 0.3
    binary = binary.astype(int)
    
    # Repair binary to meet sum constraint
    current_sum = n - np.sum(binary)
    needed = abs(current_sum - target_sum)
    if needed > 0:
        # Add if too few ones
        if current_sum > target_sum:
            ones_to_flip = np.where(~binary)[0]
            np.random.shuffle(ones_to_flip)
            flip_count = int(needed) + 1
            binary[ones_to_flip[:flip_count]] = 1
        elif current_sum < target_sum:
            zeros_to_flip = np.where(binary)[0]
            np.random.shuffle(zeros_to_flip)
            flip_count = int(needed) + 1
            binary[zeros_to_flip[:flip_count]] = 0
        
        binary = binary.astype(int)
    return binary + np.random.normal(0, 0.05, n)

def slsqp_optimize(h_initial, n, target_sum_initial):
    def objective(x):
        return compute_c5(x)

    def constraint(x):
        return np.abs(sum(x) - target_sum_initial) - 1e-3
    
    # SLSQP parameters fine-tuned for performance
    bounds = [(0.0, 1.0) for _ in range(n)]
    options = {'maxiter': min(200, 10*len(h_initial)), 'ftol': 1e-6, 'disp': False}
    
    try:
        res = minimize(objective, h_initial, method='SLSQP', bounds=bounds, constraints={'type': 'eq', 'fun': constraint},
                        options=options)
        if res.success:
            return make_feasible(res.x)
        return make_feasible(h_initial)
    except:
        return make_feasible(h_initial)

## Search choices and variations
The algorithm uses four probabilistic strategies controlled by hyperparameter weights:

1. **Binary Transformations (30%)**: 
   - Combines binary vectors with Gaussian perturbations
   - Used in `construct_cand_level1`
   - Allows escape from dense basins

2. **Gaussian Perturbations (50%)**:
   - Maintains continuity between transformations
   - Implemented in `local_search` method 1

3. **Hybrid Binary-Optimal Initialization (20%)**:
   - Creates candidates that satisfy constraints more rigorously
   - Implemented in `try_binary_base_optimal`

4. **Adaptive Sum Constraints (Not directly controllable)**:
   - The algorithm uses dynamic sum adjustments that scale with grid size
