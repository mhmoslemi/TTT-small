```python
    return corr * dx, dx

    h = np.clip(h, 0.0, 1.0).copy()
    for _ in range(50):
        diff = target - h.sum()
        if abs(diff) < 1e-12:

            if mask.sum() == 0:

            add = diff / mask.sum()
            h[mask] = np.minimum(h[mask] + add, 1.0)

            mask = h > 0.0
            if mask.sum() == 0:
                break
            sub = (-diff) / mask.sum()
            h[mask] = np.maximum(h[mask] - sub, 0.0)
    return h

    dx = 2.0 / n

    # corr[o] for shift (o - (n-1))
    corr = np.correlate(h, 1 - h, mode="full")
    # Find worst shifts (highest corr values = highest overlap = worst)
    n_corr = len(corr)
    # Get top n_worst indices
    top_idx = np.argsort(corr)[-n_worst:]

    # ∂/∂h_i = (1 - h_{i+l}) for the first term + (-h_{i-l}) for the second term

        # f_l = sum_i h[i] * (1 - h[i+l]) * dx

            # i ranges p to n-1
```

```python
        l = k - (n-1)  # actual shift
        f_k = cp.Constant(compute O_k at h0)
        grad_k = compute gradient of O_k at h0
        terms.append(cp.Max(f_k + grad_k @ (h - h0)))

    obj = cp.Minimize(cp.Max(terms))
    prob = cp.Problem(obj, constraints)
    prob.solve()
    return h.value
```

```python
    dx_val = 2.0 / n
    mc = np.max(corr)
    return (mc + np.log(np.sum(np.exp(T * (corr - mc)))) / T) * dx_val

    dx_val = 2.0 / n
    mc = np.max(corr)

    shifted -= np.max(shifted)
    e = np.exp(shifted)

        else:

            grad[:n-p] += w * (1.0 - x[p:])
```

For two arrays a (length n) and b (length n), np.correlate(a, b, mode="full") gives an array of length 2n-1 where:
result[k] = Σ_{j} a[j] * b[j + k - (n-1)]  (for valid j)

So result[k] corresponds to the "cross-correlation" at lag (k - (n-1)).

For our case: a = h, b = 1-h.
result[k] = Σ_{j: 0≤j<n, 0≤j+k-(n-1)<n} h[j] * (1-h[j+k-(n-1)])

This is the overlap integral at shift (k-(n-1)) * dx.

So C₅ = max_k result[k] * dx = max(result) * (2/n).

Yes, this matches the problem statement.

Now, for the gradient: the overlap at shift l (where l = k-(n-1)) is:
O(l) = Σ_{j: 0≤j, 0≤j+l, both <n} h[j] * (1-h[j+l]) * dx

For l > 0: O(l) = Σ_{j=0}^{n-1-l} h[j]*(1-h[j+l]) * dx
For l = 0: O(0) = Σ_{j=0}^{n-1} h[j]*(1-h[j]) * dx
For l < 0: O(l) = Σ_{j=-l}^{n-1} h[j]*(1-h[j+l]) * dx = Σ_{j=0}^{n-1+l} h[j+l]*(1-h[j]) * dx

∂O(l)/∂h[i]:
For l > 0:
- If 0 ≤ i ≤ n-1-l: contributes (1-h[i+l])*dx from first term of position i
- If l ≤ i ≤ n-1: contributes -h[i-l]*dx from second term (when j = i-l, h[i-l]*(1-h[i]), ∂/∂h[i] gives -h[i-l]*dx)

So ∂O(l)/∂h[i] = dx * [(1-h[i+l]) * 1_{0≤i≤n-1-l} - h[i-l] * 1_{l≤i≤n-1}]

For l < 0, let p = -l > 0:
O(-p) = Σ_{j=0}^{n-1-p} h[j+p]*(1-h[j]) * dx
∂O(-p)/∂h[i] = dx * [(1-h[i-p]) * 1_{p≤i≤n-1} - h[i+p] * 1_{0≤i≤n-1-p}]

For l = 0:
O(0) = Σ h[j]*(1-h[j]) * dx
∂O(0)/∂h[i] = dx * (1-2h[i])
