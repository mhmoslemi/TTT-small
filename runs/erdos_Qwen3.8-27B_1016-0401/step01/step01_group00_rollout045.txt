Each cor[k] is linear in h[j] (since we're only varying h[j] and h[0]):
cor[k] = A_k + B_k * h[j]

where A_k and B_k are constants (determined by the other coordinates).

So we need: min_{h[j] ∈ [lo, hi]} max_k (A_k + B_k * h[j])

This is a 1D minimax of linear functions! The optimal solution is at a point where two (or more) of the lines intersect, or at a boundary.

To compute A_k and B_k:

For o=0: cor[0] = sum_i h[i] - sum_i h[i]².

Total = h[j] - h[j]² + S - h[j] - (S² - 2S*h[j] + h[j]²)

The main issue with coordinate descent here is that changing one coordinate requires re-fixing the sum, which changes another coordinate, which then requires re-computing correlations. This is slow.

Let me instead use a paired swap: change h[j] by δ and h[k] by -δ simultaneously (maintaining the sum). Then the change in each correlation is straightforward.

For a pair swap (j, k) with change δ:
Δcor[o] = δ * [(1-h[j+o])*[valid(j+o)] - h[j-o]*[valid(j-o)] - (1-h[k+o])*[valid(k+o)] + h[k-o]*[valid(k-o)]]

For o=0: this includes h[j]*(-δ) and h[k]*(+δ) from the (1-h) terms, plus δ*(1-h[j]) and -δ*(1-h[k]) from the h terms.
Actually for o=0: cor[0] = sum h[i](1-h[i]), ∂/∂h[j] = 1-2h[j], ∂/∂h[k] = 1-2h[k].
Δcor[0] = δ(1-2h[j]) - δ(1-2h[k]) = δ(2h[k]-2h[j])

For o≠0: ∂cor[o]/∂h[j] = (1-h[j+o])*[valid] - h[j-o]*[valid] (as derived before)
Δcor[o] = δ * (∂cor[o]/∂h[j] - ∂cor[o]/∂h[k])

This is all linear in δ for o≠0, and linear for o=0 too (since we're doing a swap, not changing a single h[j]).

So the 1D subproblem for a pair swap is: min_{δ ∈ [δ_lo, δ_hi]} max_o (C_o + D_o * δ)

where C_o is the current correlation and D_o is the coefficient. This is a standard 1D minimax of lines, solvable in O(n) time.

The optimal δ is:
- If all D_o = 0: any δ works, stay put
- Otherwise: the optimal δ is where the maximum of the (C_o + D_o*δ) lines is minimized. This occurs at an intersection of two lines with opposite slopes, or at a boundary.

Algorithm:
1. Compute D_o for all o (O(n) work)
2. Determine valid δ range: δ_lo and δ_hi such that h[j]+δ ∈ [0,1] and h[k]-δ ∈ [0,1]
3. Find optimal δ:
   - Compute the value C_o + D_o*δ at δ_lo and δ_hi
   - Find all intersection points δ* where C_i + D_i*δ = C_j + D_j*δ → δ = (C_j - C_i)/(D_i - D_j)
   - Keep only those in [δ_lo, δ_hi]
   - At each candidate δ*, compute the max of all C_o + D_o*δ*
   - Pick the δ* with minimum max value

This is O(n²) in the worst case (for finding intersections), but in practice with n=280 it's fine. Or I can simplify: just try a few candidate δ values.

import numpy as np
import time

def compute_c5(h):
    n = len(h)
    return float(np.max(np.correlate(h, 1.0 - h, mode="full")) * 2.0 / n)

def fix_sum(h, target):
    h = np.clip(h, 0.0, 1.0).copy()
    for _ in range(300):
        diff = h.sum() - target
        if abs(diff) < 1e-14:
            break
        frac = min(0.95, abs(diff) / max(h.sum() if diff > 0 else (len(h) - h.sum()), 1e-30))
        if diff > 0:
            scale = h / max(h.sum(), 1e-30)
            h -= frac * diff * scale
        else:
            avail = 1.0 - h
            s = max(avail.sum(), 1e-30)
            h += frac * (-diff) * avail / s
        np.clip(h, 0.0, 1.0, out=h)
    return h

def corr_gradient_one(h, o):
    n = len(h)
    g = np.zeros(n)
    if o >= 0:
        g[:n - o] += (1.0 - h[o:])
        if o > 0:
            g[o:] -= h[:n - o]
        else:
            g -= h
    else:
        p = -o
        g[p:] += (1.0 - h[:n - p])
        if p > 0:
            g[:n - p] -= h[p:]
        else:
            g -= h
    return g

def subgrad_step(h, corr, k_top, alpha, target):
    n = len(h)
    top_idx = np.argsort(corr)[::-1][:k_top]
    grad = np.zeros(n)
    for idx in top_idx:
        o = idx - (n - 1)
        grad += corr_gradient_one(h, o)
    grad /= k_top
    h_new = h - alpha * grad
    h_new = np.clip(h_new, 0.0, 1.0)
    h_new = fix_sum(h_new, target)
    return h_new

def pair_swap_cd(h, target, rng, max_iters, time_limit_fn):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    best_c5 = float(np.max(corr) * 2.0 / n)
    for it in range(max_iters):
        if time_limit_fn():
            break
        o_star = int(np.argmax(corr))
        o = o_star - (n - 1)
        coeffs = corr_gradient_one(h, o)
        j = int(np.argmin(coeffs))
        k = int(np.argmax(coeffs))
        D = coeffs[j] - coeffs[k]
        if D >= 0:
            j, k = tuple(rng.choice(n, 2, replace=False))
            D = coeffs[j] - coeffs[k]
            if D >= 0:
                break
        d_lo = max(-h[j], h[k] - 1.0) + 1e-8
        d_hi = min(1.0 - h[j], h[k]) - 1e-8
        if d_hi <= d_lo:
            continue
        candidates = [0.0, np.clip(0.05 / abs(D), d_lo, d_hi),
                      np.clip(0.1 / abs(D), d_lo, d_hi),
                      np.clip(0.3 / abs(D), d_lo, d_hi),
                      np.clip(0.8 / abs(D), d_lo, d_hi)]
        best_d = 0.0
        best_c5_trial = float(np.max(corr) * 2.0 / n)
        for d in candidates:
            d = float(np.clip(d, d_lo, d_hi))
            h_tmp = h.copy()
            h_tmp[j] += d
            h_tmp[k] -= d
            h_tmp = fix_sum(h_tmp, target)
            c_trial = float(np.max(np.correlate(h_tmp, 1.0 - h_tmp, mode="full")) * 2.0 / n)
            if c_trial < best_c5_trial - 1e-14:
                best_c5_trial = c_trial
                best_d = d
                best_h = h_tmp
        if best_d != 0.0:
            h = best_h
            corr = np.correlate(h, 1.0 - h, mode="full")
            if best_c5_trial < best_c5:
                best_c5 = best_c5_trial
    return h, best_c5

def try_n_resolution(h_best, c5_best, n_try, target_old, rng, time_limit_fn, budget_left):
    if budget_left < 60:
        return h_best, c5_best
    n_old = len(h_best)
    target_try = n_try / 2.0

    x_new = np.arange(n_try) / n_try * 2.0
    h_try = np.interp(x_new, x_old, h_best)
    h_try = fix_sum(h_try, target_try)
    c5_try = compute_c5(h_try)
    target_arr = target_try
    n_arr = n_try
    h_cur = h_try.copy()
    corr = np.correlate(h_cur, 1.0 - h_cur, mode="full")
    for it in range(3000):
        if time_limit_fn() or budget_left - (time.time() - t0_global) < 60:
            break
        k_top = min(5 + it // 100, 25)
        alpha = 0.08 / (1.0 + 0.0005 * it) ** 0.7

        c = compute_c5(h_cur)

            c5_try = c
        corr = np.correlate(h_cur, 1.0 - h_cur, mode="full")

        c5_best = c5_try

    # Phase 1: Subgradient optimization on current grid
    h_cur = h_best.copy()
    corr = np.correlate(h_cur, 1.0 - h_cur, mode="full")
    stall = 0

    c5_final = compute_c5(h_best)
    c5_final = min(c5_final, c5_best)
    return (h_best, c5_final, n_f)
