Wait, but the subgradient method with a smoothed objective is actually a gradient descent method (the LSE is smooth). So I can use a better step size rule.

For a L-smooth function, the optimal step size is 1/L. What is L here?

The function f_T(h) = dx * (mc + log(Σ exp(T*(corr-mc)))/T) is a composition of:
- corr (bilinear in h)
- LSE (smooth)
- scaling by dx

The Hessian of corr w.r.t. h is bounded (each entry is 0 or ±1). The LSE has a bounded Hessian (≤ T). So L ≈ T * (something related to n).

Actually, for the correlation corr_k = Σ_i h[i](1-h[i+k]), the Hessian has entries:
∂²corr_k/∂h[i]∂h[j] = -δ_{i+k,j} - δ_{i,j+k} (from the -h[i]h[i+k] term)

So the spectral norm of the Hessian of corr_k is at most 2 (for a given k). With the LSE combination, the Hessian of f_T has spectral norm at most 2*T*max(w) ≈ 2T (when the weights are concentrated).

With dx = 2/n, the total Lipschitz constant is L ≈ 2T*(2/n) = 4T/n.

For n=280, T=4: L ≈ 16/280 ≈ 0.057. Step size 1/L ≈ 17.5. That seems very large.
For n=280, T=64: L ≈ 256/280 ≈ 0.91. Step size 1/L ≈ 1.1.

Hmm, these step sizes seem too large for a subgradient method on [0,1] variables. Let me just use a practical step size schedule.

Actually, I realize the gradient I'm computing includes the dx factor, so the gradient magnitude is already scaled by dx = 2/n = 2/280 ≈ 0.007. So the gradient is small.

Let me estimate: corr values are O(n) (sum of ~n/2 terms each ≤ 1), so mc ≈ n/4 ≈ 70. dx * mc ≈ 0.5. The gradient components are dx * (sum of ~n/2 terms) ≈ 0.007 * 70 ≈ 0.5.

import numpy as np
from scipy.optimize import minimize
import time

_SL_T = 1.0
_SL_N = 0
_SL_DX = 0.0
_SL_TARGET = 0.0

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(y, n):
    target = n / 2.0
    lo, hi = y.min() - 2.0, y.max() + 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.clip(y - mid, 0.0, 1.0).sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(y - mid, 0.0, 1.0)

def shift_grad(h, n, shift):
    j = np.arange(n)
    grad = np.zeros(n)
    if shift >= 0:
        m1 = j >= shift
        ii = j[m1]
        grad[m1] += (1.0 - h[ii - shift])
        m2 = (j + shift) < n
        ii = j[m2]
        grad[m2] -= h[ii + shift]
    else:
        s = -shift
        m1 = (j + s) < n
        ii = j[m1]
        grad[m1] += (1.0 - h[ii + s])
        m2 = j >= s
        ii = j[m2]
        grad[m2] -= h[ii - s]
    return grad

def lse_obj_grad(h, T):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    mc = corr.max()
    center = n - 1
    if T < 0.5:
        idx = int(np.argmax(corr))
        return mc * dx, shift_grad(h, n, idx - center) * dx
    sh = T * (corr - mc)
    e = np.exp(sh)
    sw = e / e.sum()
    obj = (mc + np.log(e.sum()) / T) * dx
    grad = np.zeros(n)
    for oi in range(len(sw)):
        if sw[oi] < 1e-10:
            continue
        grad += sw[oi] * shift_grad(h, n, oi - center)
    return obj, grad * dx

def _sl_obj(x):
    return lse_obj_grad(x, _SL_T)[0]

def _sl_jac(x):
    return lse_obj_grad(x, _SL_T)[1]

def _sl_con_fun(x):
    return x.sum() - _SL_TARGET

def _sl_con_jac(x):
    return np.ones(_SL_N)

def slsqp_polish(h, n, T, maxiter):
    global _SL_T, _SL_N, _SL_DX, _SL_TARGET
    _SL_T = float(T)
    _SL_N = n
    _SL_DX = 2.0 / n
    _SL_TARGET = n / 2.0
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _sl_con_fun, 'jac': _sl_con_jac}]
    try:
        res = minimize(_sl_obj, h, method='SLSQP', jac=_sl_jac,
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-16})
        return project_feasible(res.x, n)
    except Exception:
        return h

    h_prev = h_init.copy()
    c5_best = compute_c5(h)
    h_best = h.copy()
    T_sched = [128, 64, 32, 16, 8, 4, 2, 1, 1]
    iters = [5000, 8000, 10000, 12000, 15000, 18000, 20000, 25000, 25000]

            t_new = (1.0 + np.sqrt(1.0 + 4.0 * t * t)) / 2.0

            h_y = project_feasible(h_y, n)

            alpha = a0[Ti] / t_new

            h_p = project_feasible(h_p, n)
        h_new, c5_p = nesterov_optimize(h_p, n, t0, d4)
        if c5_p < c5_best:
            c5_best = c5_p
            h_best = h_new

    # Phase 5: Final SLSQP + local search
    d5 = t0 + budget_s - 35
    for T in [2, 1]:
        if time.time() > d5:
            break
        h_new = slsqp_polish(h_best, n, T, 5000)
        c5 = compute_c5(h_new)
        if c5 < c5_best:
            c5_best = c5
            h_best = h_new
    h_new, c5_ls = local_search(h_best, n, t0, t0 + budget_s - 10, rng, 3000)
    if c5_ls < c5_best:
        c5_best = c5_ls
        h_best = h_new

    # Phase 6: Try double resolution if time permits
    if time.time() < t0 + budget_s - 90:
        n2 = n * 2
        x_old = np.arange(n) * (2.0 / n)
        x_new = np.linspace(0.0, 2.0, n2, endpoint=False)
        h_hi = np.interp(x_new, x_old, h_best)
        h_hi = project_feasible(h_hi, n2)
        c5_hi = compute_c5(h_hi)
        if c5_hi < c5_best:
            c5_best = c5_hi
            h_best = h_hi
            n = n2
        if time.time() < t0 + budget_s - 40:
            h_new, c5_new = nesterov_optimize(h_best, n, t0, t0 + budget_s - 15)
            if c5_new < c5_best:
                c5_best = c5_new
                h_best = h_new

    h_best = project_feasible(h_best, n)
    c5_final = min(compute_c5(h_best), c5_best)
    return (h_best, c5_final, n)
