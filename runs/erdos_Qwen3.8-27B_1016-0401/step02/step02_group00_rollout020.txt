Let me also think about a completely different approach: **use the Fourier structure of the problem**.

The correlation at lag k is:
c_k = sum_i h[i]*(1-h[i+k]) = sum_i h[i] - sum_i h[i]*h[i+k]

With the constraint sum_i h[i] = n/2, we have:
c_k = n/2 - sum_i h[i]*h[i+k]

So minimizing max_k c_k is equivalent to minimizing max_k (n/2 - sum_i h[i]*h[i+k]) = n/2 - min_k sum_i h[i]*h[i+k]

Wait, that's not right. Minimizing max_k c_k means we want all c_k to be small. Since c_k = n/2 - R(h,h,k) where R is the autocorrelation at lag k, we want R(h,h,k) to be maximized uniformly over k.

Actually: c_k = sum h[i]*(1-h[i+k]) = sum h[i] - sum h[i]*h[i+k]

For lag 0: c_0 = sum h[i] - sum h[i]^2 = n/2 - sum h[i]^2
For lag k≠0: c_k = n/2 - sum h[i]*h[i+k] (with appropriate bounds)

So C5 = max_k (n/2 - sum h[i]*h[i+k+center]) * (2/n)

To minimize C5, we want to maximize the minimum of sum h[i]*h[i+k] over all k. This is like a "maximum minimum autocorrelation" problem!

This is an interesting reformulation. We want:
min_C5 h = (2/n) * max_k (n/2 - R_k) where R_k = sum_i h[i]*h[i+k]
         = (2/n) * (n/2 - min_k R_k)
         = 1 - (2/n) * min_k R_k

So maximizing min_k R_k minimizes C5! This is a max-min problem.

For binary h (0/1 values), R_k counts the number of 1s that are also 1s at position k away. We want to maximize the minimum count over all shifts. This is related to the "maximum minimum overlap" of a binary string with its shifts.

This reformulation suggests that the optimal h might be close to a binary (or near-binary) function, since the autocorrelation is maximized when the values are as "spread out" as possible while maintaining high overlap at all shifts.
