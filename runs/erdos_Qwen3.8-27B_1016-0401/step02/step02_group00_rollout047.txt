  - If j >= 0 and j+o < n: term is h[j+o]*(1-h[j]), derivative w.r.t. h[j] is -h[j+o]
  
So for o > 0:
  d(corr)/d(h[j]) = (1-h[j-o]) if j >= o, else 0
                    - h[j+o] if j < n-o, else 0

Combining: d(corr)/d(h[j]) = [j>=o]*(1-h[j-o]) - [j<n-o]*h[j+o]

This can be computed as:
  g[j] = (1-h[j-o]) * (j>=o) - h[j+o] * (j<n-o)

In numpy:
  g = np.zeros(n)
  g[o:] += (1.0 - h[:n-o])   # (1-h[j-o]) for j = o,...,n-1, which is (1-h[0:n-o])
  g[:n-o] -= h[o:]            # -h[j+o] for j = 0,...,n-o-1, which is -h[o:n]

This is exactly what the previous code does! And it's O(n) per lag.

            target = tgt_alt
            _TARGET = target
            bounds = b_alt

    # Phase 5: Final tight SLSQP polish
    p5_end = t0 + budget_s - 15.0
    n_f = len(h_best)
    target_f = n_f / 2.0
    _TARGET = target_f
    bounds_f = [(0.0, 1.0)] * n_f
    cons_f = [{'type': 'eq', 'fun': eqfun, 'jac': eqjac}]
    for _ in range(30):
        if time.time() > p5_end:
            break
        corr_f = np.correlate(h_best, 1.0 - h_best, mode="full")
        # Optimize top 5 lags
        top5 = np.argsort(corr_f)[-5:]
        top5 = top5[np.argsort(-corr_f[top5])]
        for li in top5:
            if time.time() > p5_end:
                break
            try:
                res = minimize(lagfun, h_best, args=(li,), method='SLSQP',
                               jac=lagjac, bounds=bounds_f, constraints=cons_f,
                               options={'maxiter': 3000, 'ftol': 1e-19})
                h_new = project(np.clip(res.x, 0, 1), target_f)
                c5n = compute_c5(h_new)
                if c5n < c5_best - 1e-17:
                    c5_best = c5n
                    h_best = h_new
            except Exception:
                pass

    c5_final = min(compute_c5(h_best), c5_best)
    return (h_best, c5_final, len(h_best))
