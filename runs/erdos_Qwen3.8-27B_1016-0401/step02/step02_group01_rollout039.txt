**Idea: Work directly with the step function structure**

A step function on [0,2] with the constraint ∫h = 1 can be parameterized by its transition points. If h has s transitions, it has s+1 constant segments. The total length of segments where h=1 must be 1.

For a binary step function with s transitions (s even for ∫h=1 on [0,2]), we can parameterize by the s transition points 0 ≤ t_1 ≤ t_2 ≤ ... ≤ t_s ≤ 2.

The overlap at lag k is then a function of these transition points. We could optimize over the transition points directly.

But this is a different parameterization and might not be easier to optimize.

**Alternative idea: Use the dual problem**

The overlap at lag k is:
∫_0^{2-k} h(x)·(1-h(x+k)) dx (for k > 0)

For binary h, this counts the measure of x where h(x)=1 and h(x+k)=0.

The constraint ∫h = 1 means the measure of {x: h(x)=1} is 1.

By inclusion-exclusion and the subadditivity of measure:
m({h=1 at x} ∩ {h=0 at x+k}) ≤ min(m({h=1}), m({h=0})) = min(1, 1) = 1

So C₅ ≤ 1 trivially. We're doing much better than that.

The question is: what's the optimal arrangement of a set of measure 1 in [0,2] to minimize max_k m(A ∩ (A+k)^c)?

This is related to the "packing" problem. If A is a single interval of length 1, say [0,1], then:
m(A ∩ (A+k)^c) = m([0,1] \ [k,1+k]) for k > 0
= m([0, 1-k]) for 0 < k < 1 = 1-k
= 1 for k ≥ 1

So max_k = 1 (at k=1). That's bad.

If A is split into two intervals: [0, a] ∪ [b, b+(1-a)], then the overlap structure is more complex.

If A is uniformly distributed (h=1/2 everywhere), then:
∫h(1-h) = 2 * (1/2)(1/2) = 1/2. But this is at k=0.
At k≠0: ∫h(x)(1-h(x+k))dx = ∫(1/2)(1/2)dx = 1/2 for all k.
So C₅ = 1/2 = 0.5. Better than 1 but not great.

Our current C₅ ≈ 0.38 is much better than 0.5, so the optimal structure is quite different from uniform.

        c5 = np.max(corr) * (2.0 / n)
        grad = _act_grad(h, corr, top_m)
        if np.linalg.norm(grad) < 1e-14:
            break
        ok = False
        for _ in range(30):
            hn = project_constraint(h - lr * grad, target)
            c5n = compute_c5(hn)
            if c5n < c5 - 1e-14:
                ok = True
                break
            lr *= 0.5
        if not ok:
            if it > 200:
                break
            continue
        h = hn
        lr = min(lr * 1.06, lr0)
        if c5n < bc5:
            bc5 = c5n
            bh = h.copy()
    return bh, bc5

def bin_snap(h, ti):
    hb = (h >= 0.5).astype(float)
    ones = int(hb.sum())
    if ones > ti:
        i1 = np.where(hb == 1)[0][np.argsort(h[np.where(hb == 1)[0]])]
        for i in range(ones - ti):
            hb[i1[i]] = 0.0
    elif ones < ti:
        i0 = np.where(hb == 0)[0][np.argsort(-h[np.where(hb == 0)[0]])]
        for i in range(ti - ones):
            hb[i0[i]] = 1.0
    return hb

_G_T, _G_TGT, _G_N = 0.0, 0.0, 0

def _sf(x):
    return x.sum() - _G_TGT

def _sj(x):
    return np.ones(_G_N)

def _so(x):
    return _smooth_data(x, _G_T)[0]

def _sg(x):
    _, sw, _ = _smooth_data(x, _G_T)
    return _smooth_grad(x, sw)

def run(seed=42, budget_s=1100, **kwargs):
    global _G_T, _G_TGT, _G_N
    B = budget_s
    rng = np.random.default_rng(seed)

    if 'initial_h_values' in globals() and initial_h_values is not None:
        h_best = np.array(initial_h_values, dtype=float)
    else:
        h_best = np.tile([1.0, 0.0], 280)
    n0 = len(h_best)
    t0 = n0 / 2.0
    h_best = project_constraint(h_best, t0)
    c5_best = compute_c5(h_best)

    # Phase 1: Smooth PG with fine-grained temperature schedule
    hw = h_best.copy()
    schedule = [(10, 6000, 0.04), (20, 5000, 0.04), (40, 4500, 0.035),
                (80, 4000, 0.03), (160, 3500, 0.025), (350, 3500, 0.02),
                (700, 3000, 0.015), (1500, 2500, 0.012), (3000, 2000, 0.008)]
    for Ti, ni, lr in schedule:
        if time.time() > B - 350:
            break
        hw, c5 = pg_smooth(hw, t0, Ti, ni, lr, B - 300)
        if c5 < c5_best:
            c5_best = c5
            h_best = hw.copy()

    # Phase 2: Active-set polishing at multiple active-set sizes
    for tm in [1, 2, 3, 5, 8, 15]:
        if time.time() > B - 220:
            break
        hw, c5 = pg_active(h_best, t0, tm, 3500, 0.012, B - 180)
        if c5 < c5_best:
            c5_best = c5
            h_best = hw.copy()

    # Phase 3: Binary snap check
    hb = bin_snap(h_best, int(t0))
    cb = compute_c5(hb)
    if cb < c5_best:
        c5_best = cb
        h_best = hb

    # Phase 4: SLSQP refinement
    if time.time() < B - 150:
        _G_T, _G_TGT, _G_N = 800.0, t0, n0
        try:
            res = minimize(_so, h_best, method='SLSQP', jac=_sg,
                           bounds=[(0.0, 1.0)] * n0,
                           constraints=[{'type': 'eq', 'fun': _sf, 'jac': _sj}],
                           options={'maxiter': 300, 'ftol': 1e-15})
            if res.fun < 100:
                hs = project_constraint(res.x, t0)
                cs = compute_c5(hs)
                if cs < c5_best:
                    c5_best = cs
                    h_best = hs
        except Exception:
            pass

    # Phase 5: Diverse restarts with re-optimization
    for r in range(25):
        if time.time() > B - 70:
            break
        hp = h_best.copy()
        m = r % 5
        if m == 0:
            idx = rng.integers(0, n0)
            sz = rng.integers(3, 12)
            for i in range(sz):
                hp[(idx + i) % n0] = 1.0 - hp[(idx + i) % n0]
        elif m == 1:
            hp = np.clip(h_best + rng.normal(0, 0.015, n0), 0, 1)
        elif m == 2:
            hp = (h_best > rng.uniform(0.35, 0.65)).astype(float)
        elif m == 3:
            hp = np.roll(h_best, rng.integers(1, 8))
        else:
            ii = rng.choice(n0, size=rng.integers(10, 30), replace=False)
            hp[ii] = 1.0 - hp[ii]
        hp = project_constraint(hp, t0)
        hp, cp = pg_smooth(hp, t0, 200, 2000, 0.02, B - 55)
        hp, cp = pg_active(hp, t0, 2, 1500, 0.01, B - 45)
        if cp < c5_best:
            c5_best = cp
            h_best = hp

    # Phase 6: Higher resolution n=700
    if time.time() < B - 55:
        n2 = 700
        t2 = n2 / 2.0
        xo = np.arange(n0) * (2.0 / n0)
        x2 = np.linspace(0.0, 2.0, n2, endpoint=False)
        h2 = project_constraint(np.interp(x2, xo, h_best), t2)
        for Ti, ni in [(50, 2500), (200, 2500), (600, 2500), (1500, 2000)]:
            if time.time() > B - 18:
                break
            h2, _ = pg_smooth(h2, t2, Ti, ni, 0.02, B - 12)
        if time.time() < B - 10:
            h2, _ = pg_active(h2, t2, 2, 1500, 0.01, B - 5)
        c2 = compute_c5(h2)
        if c2 < c5_best:
            c5_best = c2
            h_best = h2

    # Phase 7: Final micro-polish at best resolution
    if time.time() < B - 5:
        nf = len(h_best)
        tf = nf / 2.0
        hf, cf = pg_active(h_best, tf, 1, 1000, 0.008, B - 2)
        if cf < c5_best:
            c5_best = cf
            h_best = hf

    c5f = min(compute_c5(h_best), c5_best)
    return (h_best, c5f, len(h_best))
