Actually, a better approach: instead of random swaps, use a **simulated annealing** style where we accept worse moves with some probability. This helps escape local minima.

Or better yet: use a **targeted** approach. Identify the worst lag, and specifically try to reduce correlation at that lag.

For lag k (k > 0), corr[k] = sum_{i=0}^{n-1-k} h[i]*(1-h[i+k])
For binary h, this counts pairs (i, i+k) where h[i]=1 and h[i+k]=0.

To reduce corr[k], I want to either:
- Change some h[i] from 1 to 0 where h[i+k]=0 (and change some other h[b] from 0 to 1)
- Change some h[i+k] from 0 to 1 where h[i]=1 (and change some other h[a] from 1 to 0)

The most "efficient" swap would fix as many bad pairs as possible.

Let me try a different approach: **column/row-based swaps**. 

For the worst lag k:
- Bad positions: i where h[i]=1 and h[i+k]=0
- Good positions: i where h[i]=1 and h[i+k]=1, or h[i]=0 and h[i+k]=0, or h[i]=0 and h[i+k]=1

If I pick a bad position i, and I flip h[i] to 0, I fix this bad pair. But I need to flip some h[b] to 0→1. If b is chosen such that b doesn't create new bad pairs at the same lag k, then we're better off.

This is getting too complex for a quick implementation. Let me just go with a practical approach:
1. Smooth-max optimization (which the previous solution already does well)
2. Binary snap + limited random swap search
3. Multi-start with different initializations
4. More aggressive T schedule

The key improvement I think will work is:
- **Better T schedule**: The previous solution uses [15, 40, 80, 160, 320, 600]. I'll use a wider range: [10, 20, 50, 100, 200, 400, 800, 1500] with more iterations at high T.
- **Binary local search with simulated annealing**: After continuous optimization, snap to binary and do SA.
- **Better multi-start**: Try more diverse initializations.

Let me also consider: maybe the issue is that the smooth-max approximation at high T doesn't perfectly capture the max, leading to a slight error. The actual C5 might be slightly different from what the smooth-max objective reports.

One more idea: **post-processing**. After optimization, identify the points where 0 < h[i] < 1 (the "fuzzy" points) and try to snap them to 0 or 1 in a way that minimizes C5. This is a small combinatorial problem (typically only a handful of fuzzy points).

import numpy as np
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_constraint(h, target):
    lo, hi = h.min() - 1.0, h.max() + 1.0
    for _ in range(64):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(h - mid, 0.0, 1.0))
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def sm_values(h, T):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    mc = np.max(corr)
    sh = T * (corr - mc)
    sh -= sh.max()
    e = np.exp(sh)
    se = e.sum()
    obj = (mc + np.log(se) / T) * (2.0 / n)
    sw = e / se
    return obj, sw

def sm_grad(h, sw):
    n = len(h)
    grad = np.zeros(n)
    c = n - 1
    for j in range(2 * n - 1):
        w = sw[j]
        if w < 1e-15:
            continue
        k = j - c
        if k == 0:
            grad += w * (1.0 - 2.0 * h)
        elif k > 0:
            grad[k:] += w * (1.0 - h[:n - k])
            grad[:n - k] -= w * h[k:]
        else:
            p = -k
            grad[:n - p] += w * (1.0 - h[p:])
            grad[p:] -= w * h[:n - p]
    return grad * (2.0 / n)

def pg_optimize(h0, target, T, n_iter, lr0, t0, deadline):
    h = h0.copy()
    n = len(h)
    best_c5 = compute_c5(h)
    best_h = h.copy()
    lr = lr0
    for it in range(n_iter):
        if time.time() > deadline:
            break
        obj, sw = sm_values(h, T)
        grad = sm_grad(h, sw)
        gn = np.linalg.norm(grad)
        if gn < 1e-14:
            break
        accepted = False
        for _ in range(30):
            h_new = project_constraint(h - lr * grad, target)
            obj_new, _ = sm_values(h_new, T)
            if obj_new < obj - 1e-16:
                accepted = True
                break
            lr *= 0.5
        if not accepted:
            break
        h = h_new
        lr = min(lr * 1.06, lr0)
        if it % 200 == 199:
            c5 = compute_c5(h)
            if c5 < best_c5:
                best_c5 = c5
                best_h = h.copy()
    c5 = compute_c5(h)
    if c5 < best_c5:
        best_c5 = c5
        best_h = h.copy()
    return best_h, best_c5

def snap_binary(h, target):
    n = len(h)
    h_bin = (h >= 0.5).copy()
    excess = h_bin.sum() - target
    if excess > 0:
        # Need to flip 'excess' ones to zeros: pick the ones with lowest h value
        one_idx = np.where(h_bin == 1)[0]
        order = np.argsort(h[one_idx])
        for i in range(int(excess)):
            h_bin[one_idx[order[i]]] = 0
    elif excess < 0:
        zero_idx = np.where(h_bin == 0)[0]
        order = np.argsort(-h[zero_idx])
        for i in range(int(-excess)):
            h_bin[zero_idx[order[i]]] = 1
    return h_bin.astype(float)

def local_search_binary(h_bin, t0, deadline):
    n = len(h_bin)
    h = h_bin.copy().astype(float)
    dx = 2.0 / n
    best_c5 = compute_c5(h)
    corr = np.correlate(h.astype(int), 1 - h.astype(int), mode="full")
    rng = np.random.default_rng(777)
    
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    
    for step in range(200000):
        if time.time() > deadline:
            break
        a = ones[rng.integers(len(ones))]
        b = zeros[rng.integers(len(zeros))]
        h[a] = 0.0
        h[b] = 1.0
        nc = np.correlate(h.astype(int), 1 - h.astype(int), mode="full")
        if nc.max() < corr.max() - 1e-10:
            corr = nc
            best_c5 = float(corr.max()) * dx
            ones = np.where(h == 1)[0]
            zeros = np.where(h == 0)[0]
        else:
            h[a] = 1.0
            h[b] = 0.0
    return h, best_c5

    for T in T2_schedule:
        if time.time() > deadline_p3:

        if c5 < c5_best:

        h_p = h_best.copy()
        if r % 5 == 0:

        h_p = project_constraint(h_p, target)

        c5_best = c5_bin2
        h_best = h_bin2
    
    c5_final = min(compute_c5(h_best), c5_best)
    return (h_best, c5_final, len(h_best))

import numpy as np
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_constraint(h, target):
    lo, hi = h.min() - 1.0, h.max() + 1.0
    for _ in range(64):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(h - mid, 0.0, 1.0))
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def sm_values(h, T):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    mc = np.max(corr)
    sh = T * (corr - mc)
    sh -= sh.max()
    e = np.exp(sh)
    se = e.sum()
    obj = (mc + np.log(se) / T) * (2.0 / n)
    sw = e / se
    return obj, sw, corr

def sm_grad(h, sw):
    n = len(h)
    grad = np.zeros(n)
    c = n - 1
    for j in range(2 * n - 1):
        w = sw[j]
        if w < 1e-15:
            continue
        k = j - c
        if k == 0:
            grad += w * (1.0 - 2.0 * h)
        elif k > 0:
            grad[k:] += w * (1.0 - h[:n - k])
            grad[:n - k] -= w * h[k:]
        else:
            p = -k
            grad[:n - p] += w * (1.0 - h[p:])
            grad[p:] -= w * h[:n - p]
    return grad * (2.0 / n)

def pg_optimize(h0, target, T, n_iter, lr0, t0, deadline):
    h = h0.copy()
    best_c5 = compute_c5(h)
    best_h = h.copy()
    lr = lr0
    for it in range(n_iter):
        if time.time() > deadline:
            break
        obj, sw, _ = sm_values(h, T)
        grad = sm_grad(h, sw)
        gn = np.linalg.norm(grad)
        if gn < 1e-14:
            break
        accepted = False
        for _ in range(35):
            h_new = project_constraint(h - lr * grad, target)
            obj_new, _, _ = sm_values(h_new, T)
            if obj_new < obj - 1e-16:
                accepted = True
                break
            lr *= 0.5
        if not accepted:
            break
        h = h_new
        lr = min(lr * 1.06, lr0)
        if it % 300 == 299:
            c5 = compute_c5(h)
            if c5 < best_c5:
                best_c5 = c5
                best_h = h.copy()
    c5 = compute_c5(h)
    if c5 < best_c5:
        best_c5 = c5
        best_h = h.copy()
    return best_h, best_c5

def targeted_grad(h, top_idx, top_w):
    n = len(h)
    sw = np.zeros(2 * n - 1)
    for i, w in zip(top_idx, top_w):
        sw[i] = w
    return sm_grad(h, sw)

def pg_targeted(h0, target, n_iter, lr0, t0, deadline, n_top=5):
    h = h0.copy()
    n = len(h)
    best_c5 = compute_c5(h)
    best_h = h.copy()
    lr = lr0
    for it in range(n_iter):
        if time.time() > deadline:
            break
        corr = np.correlate(h, 1.0 - h, mode="full")
        mc = np.max(corr)
        thr = mc - 2.0 / np.sqrt(n)
        bad = np.where(corr >= thr)[0]
        if len(bad) > n_top:
            bad = np.argsort(corr[bad])[-n_top:] + np.where(corr >= thr)[0]
            bad = np.where(corr >= thr)[0]
        top_idx = np.argsort(corr)[-min(n_top, len(bad)):]
        top_w = np.full(len(top_idx), 1.0)
        grad = targeted_grad(h, top_idx, top_w)
        gn = np.linalg.norm(grad)
        if gn < 1e-14:
            break
        obj = mc * (2.0 / n)
        accepted = False
        for _ in range(30):
            h_new = project_constraint(h - lr * grad, target)
            nc5 = compute_c5(h_new)
            if nc5 < obj - 1e-16:
                accepted = True
                break
            lr *= 0.5
        if not accepted:
            break
        h = h_new
        lr = min(lr * 1.05, lr0)
        c5 = compute_c5(h)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h.copy()
    return best_h, best_c5

def snap_binary(h, target):
    n = len(h)
    h_bin = (h >= 0.5).astype(float)
    excess = int(h_bin.sum()) - int(target)
    if excess > 0:
        one_idx = np.where(h_bin == 1)[0]
        order = np.argsort(h[one_idx])
        for i in range(excess):
            h_bin[one_idx[order[i]]] = 0
    elif excess < 0:
        zero_idx = np.where(h_bin == 0)[0]
        order = np.argsort(-h[zero_idx])
        for i in range(-excess):
            h_bin[zero_idx[order[i]]] = 1
    return h_bin

def local_search_binary(h_bin, t0, deadline):
    n = len(h_bin)
    h = h_bin.copy()
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    best_c5 = float(corr.max()) * dx
    rng = np.random.default_rng(31415)
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    for step in range(200000):
        if time.time() > deadline:
            break
        a = ones[rng.integers(len(ones))]
        b = zeros[rng.integers(len(zeros))]
        h[a] = 0.0
        h[b] = 1.0
        nc = np.correlate(h, 1.0 - h, mode="full")
        if nc.max() < corr.max() - 1e-12:
            corr = nc
            best_c5 = float(corr.max()) * dx
            ones = np.where(h == 1)[0]
            zeros = np.where(h == 0)[0]
        else:
            h[a] = 1.0
            h[b] = 0.0
    return h, best_c5

def gen_thue_morse(n):
    tm = [0]
    while len(tm) < n:
        tm.extend(1 - x for x in tm)
    return np.array(tm[:n], dtype=float)

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    budget = budget_s
    rng = np.random.default_rng(seed)

    if 'initial_h_values' in globals() and initial_h_values is not None:
        h_best = np.array(initial_h_values, dtype=float)
    else:
        h_best = np.zeros(560)
        h_best[::2] = 1.0

    n = len(h_best)
    target = n / 2.0
    h_best = project_constraint(h_best, target)
    c5_best = compute_c5(h_best)

    # Phase 1: Smooth-max with geometric T
    d1 = t0 + budget * 0.30
    for T in [12, 30, 80, 200, 500, 1000, 2000, 4000]:
        if time.time() > d1:
            break
        h_best, c5 = pg_optimize(h_best, target, T, 1200, 0.045, t0, d1)
        if c5 < c5_best:
            c5_best = c5

    # Phase 2: Targeted lag optimization
    d2 = t0 + budget * 0.42
    h_best, c5 = pg_targeted(h_best, target, 2000, 0.03, t0, d2, n_top=5)
    if c5 < c5_best:
        c5_best = c5
    h_best, c5 = pg_targeted(h_best, target, 2000, 0.02, t0, d2, n_top=3)
    if c5 < c5_best:
        c5_best = c5
    h_best, c5 = pg_targeted(h_best, target, 1500, 0.015, t0, d2, n_top=2)
    if c5 < c5_best:
        c5_best = c5

    # Phase 3: Binary snap + local search
    d3 = t0 + budget * 0.58
    h_bin = snap_binary(h_best, target)
    h_bin, c5_bin = local_search_binary(h_bin, t0, d3)
    if c5_bin < c5_best:
        c5_best = c5_bin
        h_best = h_bin.copy()

    # Phase 4: Re-optimize from binary with smooth-max
    d4 = t0 + budget * 0.72
    for T in [100, 400, 1000]:
        if time.time() > d4:
            break
        h_try, c5 = pg_optimize(h_best, target, T, 800, 0.03, t0, d4)
        if c5 < c5_best:
            c5_best = c5
            h_best = h_try
        h_try2, c5_2 = pg_targeted(h_best, target, 600, 0.02, t0, d4, n_top=3)
        if c5_2 < c5_best:
            c5_best = c5_2
            h_best = h_try2

    # Phase 5: Multi-start perturbations
    d5 = t0 + budget * 0.90
    tm = gen_thue_morse(n)
    for r in range(35):
        if time.time() > d5:
            break
        h_p = h_best.copy()
        if r % 7 == 0:
            idx = rng.integers(0, n - 20)
            sz = rng.integers(4, 22)
            h_p[idx:idx + sz] = 1.0 - h_p[idx:idx + sz]
        elif r % 7 == 1:
            h_p = np.clip(h_best + rng.normal(0, 0.025, n), 0, 1)
        elif r % 7 == 2:
            h_p = np.roll(h_best, rng.integers(1, 12))
        elif r % 7 == 3:
            h_p = 0.6 * h_best + 0.4 * tm
        elif r % 7 == 4:
            h_p = (h_best > rng.uniform(0.3, 0.7)).astype(float)
        elif r % 7 == 5:
            bs = 7
            nb = n // bs
            blk = h_best[:nb * bs].reshape(nb, bs)
            perm = rng.permutation(nb)
            h_p[:nb * bs] = blk[perm].reshape(-1)
        else:
            h_p = 0.5 * h_best + 0.5 * np.roll(h_best, rng.integers(3, 30))
        h_p = project_constraint(h_p, target)
        T_p = 200 + (r % 5) * 100
        h_p, c5_p = pg_optimize(h_p, target, T_p, 500, 0.035, t0, d5)
        if c5_p < c5_best:
            c5_best = c5_p
            h_best = h_p.copy()
        h_p2, c5_p2 = pg_targeted(h_p, target, 300, 0.02, t0, d5, n_top=3)
        if c5_p2 < c5_best:
            c5_best = c5_p2
            h_best = h_p2.copy()

    # Phase 6: Final binary polish
    d6 = t0 + budget - 15
    h_bin2 = snap_binary(h_best, target)
    h_bin2, c5_bin2 = local_search_binary(h_bin2, t0, d6)
    if c5_bin2 < c5_best:
        c5_best = c5_bin2
        h_best = h_bin2.copy()

    # Phase 7: Ultimate targeted polish
    if time.time() < t0 + budget - 5:
        h_best, c5 = pg_targeted(h_best, target, 800, 0.008, t0, t0 + budget - 2, n_top=2)
        if c5 < c5_best:
            c5_best = c5

    c5_final = min(compute_c5(h_best), c5_best)
    return (h_best, c5_final, len(h_best))
