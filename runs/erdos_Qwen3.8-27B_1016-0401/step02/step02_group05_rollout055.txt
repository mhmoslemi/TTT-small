**Barzilai-Borwein step size + projected gradient:**
1. Compute subgradient (or soft-max gradient) g
2. Project gradient: g_proj = g - mean(g) (to maintain sum constraint)
3. Step: h_new = h - alpha * g_proj
4. Project h_new onto [0,1]^n with sum = n/2
5. Update alpha using BB rule

This might be faster and more reliable than SLSQP for the fine-tuning phase.

Let me also think about **coordinate descent**:
- For each coordinate i, given all other coordinates fixed, find the optimal h[i] that minimizes C5.
- This is a 1D optimization problem (piecewise cubic, since the correlations are linear in h[i]).
- We can find the optimal h[i] by checking the critical points.

Actually, the correlation at lag k involves h[i] in at most 2 terms:
- h[i] appears as h[i] in the term h[i]*(1-h[i+k])
- h[i] appears as (1-h[i]) in the term h[i-k]*(1-h[i])

So f_k(h) as a function of h[i] is: h[i]*(1-h[i+k]) + h[i-k]*(1-h[i]) + const
= h[i] - h[i]h[i+k] + h[i-k] - h[i-k]h[i] + const
= h[i](1 - h[i+k] - h[i-k]) + h[i-k] + const

This is linear in h[i]! So the max of linear functions in h[i] is convex in h[i], and we can find the minimizer by checking where the "active" piece changes.

This means **coordinate descent** is very efficient here! For each coordinate:
1. Compute the current value of each correlation as a function of h[i]
2. Find the h[i] that minimizes the maximum
3. Update

The minimizer of max_k (a_k * h[i] + b_k) over h[i] ∈ [0,1] is found by:
- The upper envelope of lines a_k * t + b_k for t ∈ [0,1]
- The minimum of this upper envelope is at a "valley" of the upper envelope
- This occurs where two lines cross (or at a boundary)

We can find this in O(n * |K|) time where |K| is the number of lags that could be active.
