  For binary with n/2 ones: (n/2) * 2/n = 1. Wait that's 1.0? No...
  h[i](1-h[i]) for binary: if h[i]=1, term is 0; if h[i]=0, term is 0. So lag 0 is 0 for binary!
  
  Oh right! For binary h, h(x)(1-h(x)) = 0 everywhere. So the lag 0 contribution is 0.
  
  The non-zero contributions come from lags k ≠ 0 where h[i] and h[i+k] can be different.

For binary h, corr at lag k (k>0): sum_{i=0}^{n-1-k} h[i] * (1-h[i+k]) * 2/n
This is the number of (1,0) adjacent pairs at distance k, times 2/n.

Similarly for negative lags.

So for binary h, C5 = (max number of (1,0) pairs at any lag) * 2/n.

For n=560, if the max number of (1,0) pairs is M, then C5 = M * 2/560 = M/280.
For C5 = 0.38085, M ≈ 0.38085 * 280 ≈ 106.6.

So we need the maximum number of (1,0) transitions at any lag to be at most about 106.

For a random binary sequence with 280 ones and 280 zeros, the expected number of (1,0) pairs at lag k is (n-k) * 0.25 ≈ 140 for small k. So we need to be significantly better than random.

    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode="full")
    return float(np.max(corr) * dx)

def project_constraint(h, target):
    lo, hi = h.min() - 1.0, h.max() + 1.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        if np.sum(np.clip(h - mid, 0.0, 1.0)) > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def sm_obj_grad(h, T):
    n = len(h)
    corr = np.correlate(h, 1 - h, mode="full")
    mc = np.max(corr)
    sh = T * (corr - mc) - (T * (corr - mc)).max()
    e = np.exp(sh)
    se = e.sum()
    obj = (mc + np.log(se) / T) * (2.0 / n)
    sw = e / se
    grad = np.zeros(n)
    c = n - 1
    for j in range(2 * n - 1):
        w = sw[j]
        if w < 1e-15:
            continue
        k = j - c
        if k == 0:
            grad += w * (1.0 - 2.0 * h)
        elif k > 0:
            grad[k:] += w * (1.0 - h[:n - k])
            grad[:n - k] -= w * h[k:]
        else:
            p = -k
            grad[:n - p] += w * (1.0 - h[p:])
            grad[p:] -= w * h[:n - p]
    return obj, grad * (2.0 / n)

    best_h = h.copy()

    c5_final = min(compute_c5(h_best), c5_best)
    h_best = project_constraint(h_best, target)
    c5_final = min(compute_c5(h_best), c5_final)
    return (h_best, c5_final, n)
