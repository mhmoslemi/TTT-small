def _weighted_gradient(a, weights, fft_size, n):

    h = np.where(h > 0.0, h, 0.0)

def _block_perturb(a, rng, strength=0.22):
    n = a.size
    c = a.copy()

    start = int(rng.integers(0, max(1, n - width + 1)))
    stop = min(n, start + width)

    if rng.random() < 0.25:

## Approach and Rationale

We'll use a multi-start optimization with gradient descent focusing on two complementary sequence families:
1. Dense compact sequences with high-mass concentrations at specific centers

- Equi-p spaced extrema improve potential to avoid local minima

- The optimization must balance the number of points in the sequence against the flatness of the autocorrelation
