So (B_k)_{i,j} should be 1 when j = k-i (and 0 <= j < n), and 0 otherwise.
a^T B_k a = sum_i a_i * a_{k-i} = c_k. ✓

But B_k is generally not symmetric (B_k)_{i,j} = 1 if j = k-i, which means B_k = B_k^T only if the set {(i,j): j=k-i} is symmetric, i.e., if k-i = k-j implies i=j, which is true. Wait, (B_k)_{i,j} = δ_{j,k-i} and (B_k)_{j,i} = δ_{i,k-j}. These are equal when j=k-i and i=k-j, which is the same condition. So B_k IS symmetric!

So c_k = a^T B_k a where B_k is symmetric. Good.

Now the problem is: minimize max_k a^T B_k a subject to a >= 0, sum(a) = sqrt(2n).

This is a non-convex problem (minimizing the max of convex quadratic forms). But we can use:
- Bisection on M: check if min a^T B_k a <= M for all k, subject to a >= 0, sum(a) = S.
- Or: iteratively reduce the max.

For the bisection approach, the feasibility check is:
Does there exist a >= 0, sum(a) = S, such that a^T B_k a <= M for all k = 0, ..., 2n-2?

This is a system of quadratic inequalities. It's not convex (the feasible set {a: a^T B_k a <= M} is not convex in general since B_k is not PSD).

However, B_k for small k (like k=0,1,2,...) has a special structure. B_0 has only (0,0) = 1, so a_0² <= M. B_1 has (0,1) = (1,0) = 1, so 2*a_0*a_1 <= M. Etc.
