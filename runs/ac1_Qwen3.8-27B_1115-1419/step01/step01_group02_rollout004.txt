import time

from scipy.sparse import coo_matrix
from scipy.optimize import linprog

    """Compute score using FFT convolution."""

    a = np.maximum(a, 0.0)

    return a * (target_sum / s)

    """Build sparse matrix A such that A @ b = convolve(a, b)."""
    n = len(a)
    m = 2 * n - 1
    rows = []
    cols = []
    vals = []
    for k in range(m):
        for j in range(n):
            i = k - j
            if 0 <= i < n:
                v = a[i]
                if v > 1e-15:
                    rows.append(k)
                    cols.append(j)
                    vals.append(v)
    return coo_matrix((vals, (rows, cols)), shape=(m, n))

Actually, I think the key insight is: for non-negative sequences, the center of the convolution `conv[n-1] = sum_i a[i]*a[n-1-i]` is maximized when `a` is constant (by rearrangement inequality, since both sequences have the same multiset of values). So to minimize the center peak, we want `a` to be "anti-sorted" relative to its reverse: large values on one side, small on the other.

But the max of the convolution might be elsewhere (at the edges for very asymmetric sequences). So the tradeoff is:
- Symmetric sequence: center peak is large, edge peaks are small → max at center
- Asymmetric sequence: center peak is smaller, but edge peaks might be larger → max might be at edge

The optimal is somewhere in between: enough asymmetry to reduce the center peak, but not so much that edge peaks become dominant.
