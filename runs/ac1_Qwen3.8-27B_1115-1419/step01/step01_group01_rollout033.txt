def _normalize(a):
    """Project to non-negative and normalize sum to 1."""
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s <= 0:

def _softmax(v, tau=1.0):

def _spectral_flatten(a, n_iterations=20, m=None):
    """Iterative spectral flattening with non-negativity projection."""
    a = np.asarray(a, dtype=np.float64).copy()
    n = a.size
    if m is None:
        m = _next_pow2(2*n-1)
    
    for _ in range(n_iterations):
        F = np.fft.fft(a, m)
        power = np.abs(F)**2
        power = np.maximum(power, 1e-30)
        target = np.ones(m) / m  # flat target
        
        # Wiener-like update
        F_new = F * np.sqrt(target / power)
        a_new = np.fft.ifft(F_new).real[:n]
        a_new = np.maximum(a_new, 0.0)
        s = a_new.sum()
        if s <= 0:
            break
        a_new = a_new / s
        a = a_new
    
    return a

def _interpolate(a, new_n):
    """Interpolate sequence to new length."""
    a = np.asarray(a, dtype=np.float64)
    a = np.maximum(a, 0)
    s = a.sum()
    if s <= 0:
        return np.ones(new_n) / new_n
    a = a / s
    x_old = np.linspace(0, 1, a.size)
    x_new = np.linspace(0, 1, new_n)
    out = np.interp(x_new, x_old, a)
    out = np.maximum(out, 0)
    ss = out.sum()
    if ss <= 0:
        out.fill(1.0/new_n)
    else:
        out /= ss
    return out

The objective is: `score = 2*n*max(b) / S^2` where `b = conv(a,a)` and `S = sum(a)`.

Actually, in the code above, I'm using `a = exp(v) / sum(exp(v))` which automatically normalizes. So `S = 1` always, and the score is `2*n*max(b)`.

The gradient of `score = 2*n*max(b)` with respect to `v`:
- `b = conv(a, a)` where `a = softmax(v)`

- `da_k/dv_j = a_j * (delta(k,j) - a_k)` (standard softmax derivative)
- `db/dv_j = sum_k db/da_k * a_j * (delta(k,j) - a_k) = a_j * (db/da_j - sum_k db/da_k * a_k)`

For the smooth max: `smooth_max(b) = tau * log(sum(exp(b_k/tau)))`
`d(smooth_max)/da_j = sum_k w_k * db_k/da_j` where `w_k = exp(b_k/tau) / sum(exp(b_k/tau))`

And `db_k/da_j = sum_i [delta(i,j)*a_{k-i} + a_i*delta(k-i,j)]` = `a_{k-j} + a_{j-k}` (with bounds)

In the FFT/circular formulation:
`b = IFFT(|F|^2)` where `F = FFT(a)`

If `b = IFFT(|F|^2)` (linear convolution computed via FFT with zero-padding), then:
`d(b_k)/d(a_j)` can be computed as follows.

Note that `|F|^2 = F ⊙ conj(F)` (Hadamard product).
`d|F|^2[k] / da_j = dF[k]/da_j * conj(F[k]) + F[k] * d(conj(F[k]))/da_j`
