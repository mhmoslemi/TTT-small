For n elements: sum_{i=0}^{n-1} (i+1)(n-i) = sum_{i=1}^{n} i(n+1-i) = (n+1)sum(i) - sum(i^2) = (n+1)*n(n+1)/2 - n(n+1)(2n+1)/6
= n(n+1)[(n+1)/2 - (2n+1)/6] = n(n+1)(3(n+1)-(2n+1))/6 = n(n+1)(n+2)/6

(sum(i+1))^2 = (n(n+1)/2)^2 = n^2(n+1)^2/4

So c[n-1] = [n(n+1)(n+2)/6] / [n^2(n+1)^2/4] = [n(n+1)(n+2)/6] * [4/(n^2(n+1)^2)] = 4(n+2)/(6n(n+1)) = 2(n+2)/(3n(n+1))

For large n: ≈ 2/(3n)

Compare to 1/n for uniform. So c[n-1] ≈ 2/(3n) < 1/n. Good!
