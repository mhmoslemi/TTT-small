Let me also think about the "flat-top for autocorrelation" more carefully. We want (w*w)(k) to be as flat as possible. For a discrete sequence, this is related to " Barker codes" and "low autocorrelation sequences", but those are for complex/signed sequences. For non-negative real sequences, the options are more limited.

One key insight: if w is a "box" (uniform), then w*w is a triangle. If w is a "triangle", then w*w is a "quadratic" shape. If w is a "Gaussian", w*w is a wider Gaussian. 

The ideal would be w such that w*w is a "box" (or as close to a box as possible). But this is impossible for non-negative w on a finite interval (by convolution properties).

The best we can do is make w*w as flat as possible in the middle while tapers smoothly to zero at the edges. This suggests w should be designed so that w*w has a flat top.

For continuous functions: if w(x) = 1 for |x| < a/2 and 0 otherwise (a box of width a), then (w*w)(x) is a triangle of width 2a. Not flat.

If w(x) = (1 - |2x/a|) for |x| < a/2 (a triangle), then (w*w)(x) is a quadratic "parabola" of width a. Still peaked.

Actually, for continuous functions, the only way to get a flat autocorrelation is to use an "ideal" sinc-like function, which is not non-negative.

So for non-negative sequences, the best we can do is approximate a flat autocorrelation. The flat-top window is designed for this purpose (in the frequency domain, making |W(f)|² flat).
