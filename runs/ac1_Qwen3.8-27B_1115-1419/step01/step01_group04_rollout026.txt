Actually, the key insight is: d(a*a)[k]/d(a) is just a shifted version of a (reversed). Specifically, it's the cross-correlation of a with a delta at position k. So d(a*a)[k]/d(a) = a[max(0,k-n+1):min(n,k+1)] (reversed appropriately) zero-padded.

More precisely, d(a*a)[k]/d(a) is a vector of length n where:
- Position j gets a[k-j] if 0 <= k-j <= n-1
- Position j gets a[j-k] if 0 <= j-k <= n-1

This is equivalent to: take the vector a, reverse it, and cross-correlate with a delta at position k. Or: it's the convolution of a with a delta at position k, plus the convolution of reverse(a) with a delta at position 2n-2-k.

For the top-K subgradient, I need to sum K such shifted/reversed copies of a. This can be done efficiently using FFT: instead of doing K separate shifts, I can compute the "weight" function w[j] = sum_{k in topK} (number of ways j contributes to lag k), and then grad = w * a + w * reverse(a) (with appropriate shifts).

Actually, the weight function w[j] for the top-K subgradient is:
w[j] = (1/K) * |{k in topK : 0 <= k-j <= n-1}| + (1/K) * |{k in topK : 0 <= j-k <= n-1}|

The first term counts the number of top-K lags k such that k is in [j, j+n-1].
The second term counts the number of top-K lags k such that k is in [j-n+1, j].

So w[j] = (1/K) * (count of topK in [j, j+n-1] + count of topK in [j-n+1, j])

This can be computed in O(n + K) using a prefix sum of the indicator of topK!
