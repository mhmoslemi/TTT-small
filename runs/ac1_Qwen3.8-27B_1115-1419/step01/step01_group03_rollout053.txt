```python
def spectral_iteration(a, N, target_flat, n_iter, alpha=0.7):
    """
    a: input sequence (non-negative, sum=1)
    N: FFT length (>= 2n-1)
    target_flat: target amplitude for non-DC bins
    alpha: compression exponent (0 < alpha < 1)
    """
    n = len(a)
    A = np.fft.rfft(a, N)  # Use real FFT for efficiency
    for it in range(n_iter):
        # Frequency domain: modify amplitude
        mag = np.abs(A)
        phase = A / np.maximum(mag, 1e-30)
        
        # Compress the amplitude toward the target
        # For DC: keep as is (or set to sqrt(N) since sum=1)
        # For others: move toward target_flat
        new_mag = mag.copy()
        new_mag[1:] = mag[1:] ** alpha * target_flat ** (1 - alpha)
        # Or: new_mag[1:] = np.minimum(mag[1:], target_flat * (1 + eps))
        
        A = new_mag * phase
        a_new = np.fft.irfft(A, N)[:n]
        
        # Time domain: project to non-negative
        a_new = np.maximum(a_new, 0)
        s = a_new.sum()
        if s > 1e-15:
            a_new /= s
        else:
            a_new = a.copy()
            break
        a = a_new
    return a
```

Actually, let me think about it from the energy perspective:
- Total energy in A: `sum_k |A[k]|^2 = N * sum_k a[k]^2` (Parseval with numpy convention: `sum|A|^2 = N * sum|a|^2`).
- `|A[0]|^2 = 1` (since A[0] = sum(a) = 1).
- Remaining energy: `N * sum(a^2) - 1` distributed among N-1 bins.
- "Flat" would be: `|A[k]|^2 = (N * sum(a^2) - 1) / (N-1)` for k != 0.
- So `T = sqrt((N * sum(a^2) - 1) / (N-1))`.

But as we iterate, sum(a^2) changes. Initially, for a uniform a, sum(a^2) = 1/n, so T = sqrt((N/n - 1)/(N-1)) ≈ sqrt(1/n) for N >> n.

Let me just use a simpler approach: at each iteration, compute the "excess" of the current spectrum over the flat level, and reduce it.

**Revised algorithm:**

```
For each iteration:
    A = fft(a, N)
    mag = |A|
    # Compute the "flat" level for non-DC bins
    flat_level = sqrt((N * sum(a^2) - |A[0]|^2) / (N-1))
    # Or more simply: flat_level = mean(mag[1:])
    
    # Compress: move mag[1:] toward flat_level
    # New mag: for k != 0, new_mag[k] = mag[k] + alpha * (flat_level - mag[k])
    # = (1-alpha)*mag[k] + alpha*flat_level
    # But this changes the total energy... 
    
    # Alternative: scale down peaks, scale up valleys
    # new_mag[1:] = mag[1:] ^ alpha * flat_level^(1-alpha)
    # This is a geometric mean approach
    
    phase = A / max(mag, eps)
    new_mag = copy(mag)
    new_mag[1:] = mag[1:] ** alpha * flat_level ** (1-alpha)
    A_new = new_mag * phase
    a_new = ifft(A_new).real
    a_new = max(a_new, 0) / sum(max(a_new, 0))
    a = a_new
```
