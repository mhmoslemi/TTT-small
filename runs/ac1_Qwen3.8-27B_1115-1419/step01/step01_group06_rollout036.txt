Alternatively, we can use a first-order method (like the previous code) but with better tuning.

**Let me try a different approach: use the structure of the problem more directly.**

The objective is `2n * max_k (a*a)[k] / (sum a)^2`. Let's normalize `sum(a) = 1` and minimize `2n * max_k (a*a)[k]`.

Let `T = max_k (a*a)[k]`. We want to minimize T.

Consider the following bisection approach:
- For a given T, check if there exists `a >= 0, sum(a)=1` with `(a*a)[k] <= T` for all k.
- This is a feasibility problem. We can approach it with:
  - Start with `a = uniform`
  - Find the most violated constraint: `k* = argmax_k (a*a)[k]`
  - Update a in a direction that reduces `(a*a)[k*]` while maintaining feasibility of other constraints
  - This is like the Kelley cutting plane method or the ellipsoid method for non-convex constraints

Actually, since the constraints are not convex (as we showed), this won't work directly.

**Let me try yet another angle: spectral methods.**

The DFT of `a` is `A_k = sum_j a_j * exp(-2*pi*i*j*k/N)`. The (circular) autocorrelation is `r[m] = sum_j a_j * a_{j+m} = IDFT(|A|^2)[m]`.

For linear convolution, it's slightly different, but for large N relative to n, the circular and linear convolutions agree on the relevant range.

If we want the autocorrelation to be flat, we want `|A_k|^2` to be flat. This means `|A_k| ≈ constant`.

For a non-negative sequence with constant magnitude DFT, we need the sequence to be "close to" a Barker sequence or a Zadoff-Chu sequence (but those are complex/signed, not non-negative).

For non-negative sequences, the "flat spectrum" condition is harder to achieve. The best we can do is make the spectrum as flat as possible.

I'll write a program that:
1. Starts from `height_sequence_1` if available, else from a random or structured initialization.
2. Uses a combination of:
   a. Smoothed-max gradient descent (Adam in log-space) with adaptive beta
   b. Periodic "annealing" (temporarily reduce beta to explore)
   c. Multiple restarts with different seeds
   d. A "polish" phase at the end with very high beta
3. Tries a few different sequence lengths (e.g., 2048, 4096, 8192)
4. Uses exact numpy.convolve for final validation

def _softmax(w):
    w = np.asarray(w, dtype=np.float64)
    w = w - np.max(w)
    w = np.clip(w, -700.0, 700.0)
    e = np.exp(w)
    s = float(e.sum())
    if not np.isfinite(s) or s <= 0.0:
        return np.ones(w.size, dtype=np.float64) / w.size
    return e / s


def _conv_fft(a, N):
    n = a.size
    A = np.fft.rfft(a, N)
    c = np.fft.irfft(A * A, N)
    c = c[: 2 * n - 1].copy()
    if float(np.min(c)) < 0.0:
        np.maximum(c, 0.0, out=c)
    return c


def _smax_p(c, beta):
    cmax = float(np.max(c))
    shifted = beta * (c - cmax)
    shifted = np.clip(shifted, -700.0, 0.0)
    e = np.exp(shifted)
    s = float(e.sum())
    if not np.isfinite(s) or s <= 0.0:
        p = np.zeros(c.size, dtype=np.float64)
        p[int(np.argmax(c))] = 1.0
    else:
        p = e / s
    smax = cmax + float(np.log(s)) / beta
    return smax, p


def _score_grad_w(w, beta, N):
    """Returns (score, grad_w, a, c)."""
    a = _softmax(w)
    n = a.size
    c = _conv_fft(a, N)
    smax, p = _smax_p(c, beta)
    # Gradient of smax w.r.t. a
    P = np.fft.rfft(p, N)
    A = np.fft.rfft(a, N)
    xcorr = np.fft.irfft(np.conj(P) * A, N)
    g = 2.0 * xcorr[:n]  # d(smax)/d(a_j) = 2 * xcorr(p,a)[j]

    grad_w = np.where(np.isfinite(grad_w), grad_w, 0.0)
    score = 2.0 * n * smax
    return score, grad_w, a, c


def _adam_step(w, g, m, v, t, lr, b1=0.9, b2=0.999, eps=1e-8):

    w_new = np.where(np.isfinite(w_new), w_new, 0.0)
    w_new = w_new - float(np.max(w_new))
    return w_new, m, v, t

    mx = float(np.max(b))

    return 2.0 * n * mx / (s * s)
