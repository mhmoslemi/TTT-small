- b[n-1] = sum_i a[i]*a[n-1-i] (the "reversed" correlation at lag 0)

The average value of b is (sum_a)²/(2n-1).

For a "flat" b, we want b[k] ≈ (sum_a)²/(2n-1) for all k.

This means:
- a[0]² ≈ (sum_a)²/(2n) → a[0] ≈ sum_a/sqrt(2n)
- a[n-1]² ≈ (sum_a)²/(2n) → a[n-1] ≈ sum_a/sqrt(2n)
- sum_i a[i]*a[n-1-i] ≈ (sum_a)²/(2n)

The last condition (for the center) is the tricky one. For the all-equal sequence, a[i]*a[n-1-i] = (sum_a/n)² for all i, so the sum is n*(sum_a/n)² = (sum_a)²/n ≈ 2*(sum_a)²/(2n). So the center is about 2x the average, giving a triangular shape.

To make the center ≈ average, we need sum_i a[i]*a[n-1-i] ≈ (sum_a)²/(2n). This means the "reversed correlation" should be about half of what it is for the all-equal case.

One way: Make a[i]*a[n-1-i] small for most i. For example, if a is "anti-symmetric" in the sense that a[i] is large when a[n-1-i] is small, then the products are small.

Example: a = [high, high, ..., high, low, low, ..., low] (first half high, second half low).
Then a[i]*a[n-1-i] = high*low for most i (when i is in the first half, n-1-i is in the second half).
sum_i a[i]*a[n-1-i] ≈ n * high * low.
sum_a = (n/2)*high + (n/2)*low = (n/2)(high+low).
(sum_a)²/(2n) = n(high+low)²/8.
Center = n*high*low.
Ratio = n*high*low / (n(high+low)²/8) = 8*high*low/(high+low)².

For high = 2*low: ratio = 16/(9) ≈ 1.78.
For high = 3*low: ratio = 24/(16) = 1.5.
For high = 10*low: ratio = 200/(121) ≈ 1.65.
For high → ∞, low → 0: ratio → 0.
