    # d||b||_p/db_k = p * b_k^(p-1) / ||b||_p^p = p * b_k^(p-1) / sum_l b_l^p
    
    norm_p = float(np.sum(b**p))
    if norm_p <= 0:
        return np.zeros(n)
    w = p * np.maximum(b, 1e-300)**(p-1) / norm_p

    return grad

Wait, I need to double-check the cross-correlation formula. Let me verify:

I want `c_j = sum_k w_k * a_{k-j}` (where a_out = 0).

In the DFT framework (length m >= 2n-1):
`ifft(FFT(w) * FFT(a))[j] = sum_k w_k * a_{(j-k) mod m}` (circular convolution)

This is NOT what I want. I want `sum_k w_k * a_{k-j}`, not `sum_k w_k * a_{j-k}`.

`sum_k w_k * a_{k-j} = sum_k w_k * a_{-(j-k)} = (w * a_flip)[j]` where `a_flip[i] = a[-i mod m]`.

In DFT: `FFT(w * a_flip) = FFT(w) * FFT(a_flip)`.
`a_flip[i] = a[(-i) mod m]`. For real a, `FFT(a_flip)[l] = conj(FFT(a)[l])` (for the right length).

So: `ifft(FFT(w) * conj(FFT(a)))[:n]` gives `sum_k w_k * a_{k-j}` (with the circular wrap-around, which is harmless if m >= 2n-1).

Let me verify with a small example:

m = 8 (next pow2 of 5).

c_0 = w_0*a_0 + w_1*a_1 + w_2*a_2 = 0.1*1 + 0.2*2 + 0.3*3 = 0.1+0.4+0.9 = 1.4
c_1 = w_1*a_0 + w_2*a_1 + w_3*a_2 = 0.2*1 + 0.3*2 + 0.4*3 = 0.2+0.6+1.2 = 2.0
c_2 = w_2*a_0 + w_3*a_1 + w_4*a_2 = 0.3*1 + 0.4*2 + 0.5*3 = 0.3+0.8+1.5 = 2.6

        return np.inf

    if S <= 1e-300:
        return np.inf
    m = _next_pow2(2 * n - 1)
    F = np.fft.fft(a, m)
    b = np.fft.ifft(F * F).real[:2 * n - 1]
    b = np.maximum(b, 0.0)
