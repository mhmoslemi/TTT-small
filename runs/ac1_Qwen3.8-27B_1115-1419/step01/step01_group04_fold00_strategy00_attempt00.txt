For the challenge of minimizing the evaluation function for step-function sequences, a multi-stage global vs local optimization strategy was chosen. The key idea involves combining a broad multilevel search with a structured piecewise-distribution optimization to balance exploratory searches across different sequence lengths with fine-grained optimization. The algorithm starts by generating a coarse grid of points with block structures at various scales, then refines promising candidates in trackable computations.

The evaluation function is `score = 2 * n * max(convolve(a, a)) / (sum(a))^2`. The solution involves:
1. **Coarse-Grained Search**: Explore sequences of lengths 256, 512, 1024, and 2048 using initial narrow-pulse families to find competitive `sum(a)` and `convolve(a)` combinations.
2. **Piecewise Structure Optimization**: Treat sequences as having variable numbers of blocks, allowing each segment's height to be optimized independently while maintaining distinct break points.
3. **Greedy Refinement**: Once a strong candidate is found, locally search its symmetric components to confirm the minimum score without excessive iterations.
4. **Fallback Strategy**: If no improvement is found, fall back to a simple uniform sequence through explicit construction.

The implementation uses gradient top-K approximation to maintain pruned explorers and ensures finite, nonnegative sequences that meet the evaluation criteria.

def normalize_sequence(a, target_sum, max_value=1000.0):
    """Clip and normalize to fixed target_sum, default to ones if target_sum is low or empty."""
    a = np.array(a, dtype=np.float64, copy=True)
    if len(a) == 0:
        return np.ones(1)
    a = np.where(np.isfinite(a), a, 0.0)
    a = np.clip(a, 0.0, max_value)
    s_old = a.sum()
    if s_old >= 0.01:
        # Scale to target_sum=1.0
        a = a / s_old * target_sum
        # Enforce we are in the domain [0, 1000] again
        a = np.clip(a, 0.0, max_value)

        if np.isfinite(s_new) and s_new > 0.001:

            a = a / s_new

        target = max(0.01, target_sum)
        a_new = np.ones_like(a) / len(a) * target
        return a_new
