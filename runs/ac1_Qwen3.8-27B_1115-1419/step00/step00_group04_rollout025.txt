Wait, there's a problem with the multiplicative update. If g[j] is large (positive), then a[j] gets decreased a lot. But g[j] = 2 * sum_k p[k] * a[k-j], which is always non-negative (since p >= 0 and a >= 0). So the update always decreases all elements of a!

That's not right. I need to center the gradient: subtract the mean (or use the dual ascent variable).

In mirror descent on the simplex, the update is:
`a_new[j] ∝ a[j] * exp(-eta * (g[j] - <g, a>))`

where `<g, a> = sum_j g[j] * a[j]` is the "dual variable" that ensures the constraint sum a_new = 1 is satisfied.

Actually, for the simplex constraint, the Bregman projection of the gradient step already handles this. The update for mirror descent with KL divergence on the simplex is:
`a_new[j] = a[j] * exp(-eta * g[j]) / sum_k a[k] * exp(-eta * g[k])`

The normalization ensures sum a_new = 1. But the issue is that if g[j] > 0 for all j (which it is here), all elements decrease proportionally to their current value, and the relative changes are determined by the relative gradient values.

Actually, this is fine! The normalization takes care of the scale. The effective update is:
`a_new[j] / a_new_sum ∝ a[j] * exp(-eta * g[j])`

Elements with high gradient (high "pressure") get decreased relative to elements with low gradient. This is exactly what we want.

Let me verify: if g[j] = g for all j (uniform gradient), then a_new[j] ∝ a[j] * exp(-eta*g) = exp(-eta*g) * a[j], so a_new = a (no change). Good.

If g[j] is high for some j and low for others, the high-g elements get decreased relative to the low-g elements. This is the correct behavior.

"""
Optimization of non-negative sequences to minimize the peak of self-convolution.
Uses multiplicative weights (mirror descent) with adaptive softmax temperature.
"""

import numpy as np
import time


def self_conv(a):
    """Compute full self-convolution of a with itself using FFT."""
    n = len(a)
    L = 1
    while L < 2 * n - 1:
        L <<= 1
    fa = np.fft.rfft(a, L)
    return np.fft.irfft(fa * fa, L)[:2 * n - 1]


def compute_soft_gradient(a, t):
    """
    Compute the gradient of the soft-max approximation of max(self_conv(a)).
    Returns (gradient, max_value).
    """
    n = len(a)
    c = self_conv(a)
    mx = c.max()
    # Softmax weights
    p = np.exp(t * (c - mx))
    p /= p.sum()
    # Gradient: 2 * correlate(p, a, 'valid')
    # correlate(p, a, 'valid')[j] = sum_{m=0}^{n-1} p[j+m] * a[m]
    g = np.correlate(p, a, mode='valid')
    return 2.0 * g, mx


def mirror_descent_step(a, g, eta):
    """
    Multiplicative weights update on the simplex.
    a_new[j] ∝ a[j] * exp(-eta * g[j])
    """
    # Center the gradient for numerical stability
    g_centered = g - g.mean()
    # Compute log update
    log_ratio = -eta * g_centered
    # Subtract max for numerical stability
    log_ratio -= log_ratio.max()
    a_new = a * np.exp(log_ratio)
    s = a_new.sum()
    if s < 1e-300:
        return a  # Fallback
    a_new /= s
    # Ensure non-negativity (should already be positive, but clip for safety)
    a_new = np.maximum(a_new, 0)
    a_new /= a_new.sum()
    return a_new
