**Approach: Iterative peak reduction via "anti-correlation" weighting**

The idea:
1. Start with a sequence `f`
2. Compute `conv = convolve(f, f)` and find the peak position `k*`
3. Create a "correction" sequence `c` that is concentrated at positions that would REDUCE the peak at `k*`
4. Update `f = f - alpha * c` (with projection to non-negative and sum=1)

The "correction" sequence: to reduce `conv[f+c, f+c][k*]`, we want to reduce `2*f*c[k*] + c*c[k*]`. Since `f*c[k*] = sum_j f[j]*c[k*-j]`, we want `c` to be such that `c[k*-j]` is small where `f[j]` is large. So `c` should be "anti-correlated" with the reversed `f`.

A simple choice: `c[j] = f[k*-j]` (the reversed version of `f` around position `k*`). Then `f*c[k*] = sum_j f[j]*f[k*-j-k*+k*]`... this is getting confusing.

Let me think differently. The gradient approach is actually the simplest:
1. Compute `conv = convolve(f, f)`
2. Find all positions where `conv[k]` is close to the max (within some tolerance)
3. The subgradient at those positions points in the direction of increasing the convolution
4. Move AGAINST the subgradient (to decrease the peak)
5. Project: clip to non-negative, normalize sum to 1

This is essentially a projected subgradient method. Let me implement it:

```python
def subgradient_step(f, learning_rate, top_fraction=0.1):
    """One step of projected subgradient descent on max(conv(f,f))."""
    n = len(f)
    conv = np.convolve(f, f)
    peak = conv.max()
    
    # Find positions where conv is close to peak
    threshold = peak * (1 - top_fraction)
    peak_positions = np.where(conv >= threshold)[0]
    
    # Compute sum of subgradients at peak positions
    g = np.zeros(n)
    for k in peak_positions:
        # subgradient of conv[k] w.r.t. f[i] = 2*f[k-i] if 0 <= k-i < n
        i_start = max(0, k - n + 1)
        i_end = min(n - 1, k)
        idx = np.arange(i_start, i_end + 1)
        g[idx] += 2 * f[k - idx]
    
    # Normalize gradient
    g_norm = np.linalg.norm(g)
    if g_norm > 0:
        g = g / g_norm
    
    # Gradient step
    f_new = f - learning_rate * g
    
    # Project: non-negative
    f_new = np.maximum(f_new, 0)
    
    # Normalize sum to 1
    s = f_new.sum()
    if s > 0:
        f_new = f_new / s
    else:
        f_new = f
    
    return f_new
```
