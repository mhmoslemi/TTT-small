The key insight: we want to reduce the peak of the autocorrelation. The peak is at some lag k*. To reduce it, we want to "spread out" the mass that contributes to (a*a)[k*].

The contribution to (a*a)[k*] from position i is a[i]*a[k*-i]. To reduce this, we can:
- Decrease a[i] for i that has a large a[k*-i]
- Or increase a[j] for j not involved in the peak

This suggests a gradient-based approach: compute the gradient of the objective and take a step in the negative gradient direction (projected to maintain non-negativity and fixed sum).

**Gradient-based approach:**
- Objective: F(a) = 2n * max_k (a*a)[k] / (sum a)^2
- Let S = sum(a), M = max_k (a*a)[k]
- F = 2nM / S^2
- dF/da = (2n/S^2) * dM/da - (4nM/S^3) * dS/da = (2n/S^2) * dM/da - (4nM/S^3) * 1

Where dM/da is the subgradient of max_k (a*a)[k], which is the gradient of (a*a)[k*] at the peak.

As computed earlier: d(a*a)[k*]/da[m] = 2*a[k*-m] (if 0 <= k*-m < n).

So dF/da[m] = (2n/S^2) * 2*a[k*-m] - 4nM/S^3 (for valid m).

Simplified: dF/da[m] = (4n/S^2) * a[k*-m] - 4nM/S^3

To minimize F, we decrease a[m] where dF/da[m] > 0 and increase where < 0. But we must maintain a >= 0 and S = constant.

This is a projected gradient step:
a_new[m] = max(0, a[m] - eta * (dF/da[m] - mean(dF/da)))
Then normalize to have sum = S.

The subtraction of the mean ensures the sum is preserved (approximately).

This is essentially a natural gradient flow on the simplex. Let me implement this.

Actually, since F is scale-invariant, let me fix S = 1 and just minimize 2n * M.

d(2nM)/da[m] = 2n * 2*a[k*-m] = 4n * a[k*-m] (for 0 <= k*-m < n, else 0).

So the gradient is just a shifted version of a, scaled by 4n. The direction to decrease F is to decrease a where the shifted a is large.

Natural gradient / multiplicative update:
a_new[m] = a[m] * exp(-eta * 4n * a[k*-m]) / normalization

Or additively:
a_new[m] = max(0, a[m] - eta * 4n * a[k*-m])

Then renormalize.

Let me think about the stability of this. If a is uniform (a[m] = 1/n), then the gradient is 4n * (1/n) = 4 everywhere (for the valid range), so the update is a_new[m] = 1/n - eta*4, which is uniform again. So uniform is a fixed point, as expected.

For a non-uniform a, the gradient will push mass from peak-contributing positions to other positions.
