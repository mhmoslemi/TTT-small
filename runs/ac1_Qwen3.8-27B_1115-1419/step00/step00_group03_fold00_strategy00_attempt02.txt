- **Approach and Rationale**: 
  Target the minimal value of the evaluation function by combining global and local search steps. Start from a random sequence or the provided parent, then use a linear transformation (reflection) to explore the space. After each reflection, we perform a local optimization (gradient clip) to improve the score. This approach balances exploration and exploitation while sharing the same sequence length (300) for reduced computational cost. The reflection step (`r`) and gradient clip step (`t`) create structured neighborhoods around local optima.

- **Mathematical Specification**: 
  1. **Objective**: Minimize \( f(x) = 2n \max(\text{convolve}(x_i)) / (\sum x_i)^2 \) where \( x \) is a non-negative sequence of length 300.
  2. **Constraints**: Ensure all elements are non-negative and do not exceed 1000.
  3. **Optimization Steps**:
     - **Reflection**: For a current sequence `x`, find a `r` and `t` such that \( x'[i] = (x[i] \text{ reflected w.r.t. } r) \cap [0, 1000] \).
     - **Gradient Clipping**: After reflection, solve a small linear program to maximize \( \sum x'[i] \) under \( \|x'[i]\| \leq t \max(\text{convolve}(x[i,j])) \).

- **Implementation Procedure**:
  1. Initialize sequence length to 300.
  2. Generate two initial sequences: one random and one based on the parent if available.
  3. Evaluate both using `evaluate_sequence` and keep the best.
  4. Iterate until time runs out:
     - **Perturbation**: For each point, generate random candidate reflections around a central point `r`.
     - **Local Optimization**: Clip the gradient while maintaining non-negativity bounds.
  5. Update the best sequence whenever a lower score is found.
