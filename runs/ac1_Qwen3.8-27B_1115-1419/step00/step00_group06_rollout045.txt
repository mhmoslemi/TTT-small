For the gradient, we need d/dy_j [max_k conv(y)_k]. This is the subgradient, which is the partial derivative with respect to y_j of the convolution value at the maximizing lag.

conv(y)_k = sum_i y_i * y_{k-i} (with appropriate index bounds)
d conv(y)_k / d y_j = y_{k-j} + y_{j-k} (if the indices are valid)

So the subgradient of max_k conv(y)_k with respect to y_j is y_{k*-j} + y_{j-k*} where k* is the maximizing lag.

This is easy to compute! So we can use subgradient descent.

But subgradient descent is slow. Instead, let's use a smooth approximation:
soft_max(conv(y), T) = T * log(sum_k exp(conv(y)_k / T))

The gradient of this is:
d/dy_j [soft_max] = (1/sum_k exp(conv_k/T)) * sum_k exp(conv_k/T) * d(conv_k)/dy_j
= sum_k p_k * (y_{k-j} + y_{j-k}) where p_k = exp(conv_k/T) / sum exp(conv_m/T)

This is a weighted sum of the "cross-correlation" vectors, which is still O(n) to compute (or O(n log n) with FFT).
