**Strategy and Approach**

We are to search for a sequence of coefficients (for a step function) that minimizes the given evaluation function: `2*n*max(convolve(a, a, mode='full'))/sum(a)^2`. 

**Problem Analysis**
- The previous program achieved an upper bound of 2.000000.
- The goal is to achieve an upper bound below 1.5027.
- The evaluation function's purpose is to measure the "compactness" or "smoothness" of the sequence through the autocorrelation (via convolution) and the total sum.

**Key Insight**
- Many step function algorithms rely on the iteration of optimizing a single sequence. However, this may only lead us to a local minimum.
- Insight from the initial state of the art: use another extremal sequence (a normalized sequence to maximize the sum while staying within the convolution bound) and then update.
- However, the original LP approach had some issues regarding the constraints and the objective function.

1. **Initialization from Provided Parent (if exists):**

   - Each candidate is evaluated by the provided function, and the best is carried forward.

**Search Process**
- The algorithm will use the provided parent (if available) and then perform a local search (number of iterations determined by the time budget) by perturbing blocks of coefficients and solving the LP to find a better direction.
- The objective to be minimized is the resulting value from the `evaluate_sequence` function (which returns the maximum convolution normalized by the square of the sum).

**Optimization Setup**
- We have an initial sequence `base` (length `n` = 256 if no parent provided) with sum `sqrt(2*n)`.
- We need to compute the maximum autocorrelation (convolution) point (`M_prev`) from `base`.
- Then, using `base` and its `M_prev`, we solve the linear program to find a candidate `g0` (same length `n`) that maximizes the sum (normalized to `sqrt(2*n)`), subject to:
  - All elements are nonnegative.
  - The maximum convolution between `base` and `g0` (full mode convolution) is ≤ `M_prev`.

**C++-like Algorithm Steps**
1. Read the user's provided sequence or use a default sequence of length 256 with normalized sum.
2. While remaining time > 0:
   - If less than two thirds of the remaining time is left, reduce the block size.
   - Evaluate the current candidate's `M`.
   - Use a linear program to find a new candidate in the direction of increasing the sum, subject to staying within `M`.
   - Update the candidate sequence using a convex combination to avoid invalid values.
   - Retain the best candidate so far.

**Implementation Details**
- We use GUROBI to solve the LP.
- The linear program is formulated as follows:
  ```cpp
  /*
  Objective: Maximize sum_{j=0}^{n-1} g0_j
  Constraints:
    1. For each convolution point p from 0 to 2*n-2:
  ```
