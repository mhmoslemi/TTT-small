    s = x.sum()
    if s < 1e-15:
        x = np.ones(n) / n
        return 2.0, x
    
    x /= s  # normalize to sum = 1
    
    # FFT size: need L >= 3n-2 for cross-correlation of w (len 2n-1) and x (len n)
    L = 1
    while L < 3 * n - 1:
        L *= 2
    
    best_score = np.inf
    best_x = x.copy()
    
    lr = 0.5
    T = 0.05
    
    for it in range(500000):
        if time.monotonic() > deadline:
            break
        
        # Compute convolution c = convolve(x, x), length 2n-1
        F = np.fft.rfft(x, L)
        C = np.fft.irfft(F * F, L)
        c = C[:2*n-1]
        
        M = c.max()
        current_score = 2.0 * n * M  # sum(x) = 1
        if current_score < best_score:
            best_score = current_score
            best_x = x.copy()
        
        # Soft subgradient
        c_shifted = c - c.max()
        w = np.exp(c_shifted / T)
        w /= w.sum()

        W = np.fft.rfft(w, L)
        X = np.fft.rfft(x, L)
        # ifft(FFT(w) * conj(FFT(x)))[i] = sum_j w[j] * x[j-i] (circular)
        # With sufficient padding, for i in [0, L-1]:
        # = sum_j w[j] * x[j-i] where j-i >= 0, which is sum_k w[k+i] * x[k]
        # That's what we want!
        sg_full = np.fft.irfft(W * np.conj(X), L)
        sg = sg_full[:n] * 2.0
        
        # Multiplicative update
        sg_norm = sg / sg.mean()  # normalize gradient
        update = lr * sg_norm
        update = np.clip(update, -100, 100)
        x = x * np.exp(-update)
        x = np.maximum(x, 1e-15)
        x /= x.sum()
        
        # Anneal
        if it % 500 == 499:
            T *= 0.97
            lr = max(0.01, lr * 0.995)
        
        if verbose and it % 10000 == 0:
            print(f"  iter {it}: score={current_score:.6f}, best={best_score:.6f}, T={T:.4f}, lr={lr:.4f}")
    
    return best_score, best_x

For two sequences a (length Na) and b (length Nb), zero-padded to length L:
ifft(FFT(a) * conj(FFT(b)))[k] = sum_j a[j] * b[j-k] (circular, mod L)

For linear cross-correlation (no wrap-around), we need L >= Na + Nb - 1.

With a = w (length 2n-1), b = x (length n):
ifft(FFT(w) * conj(FFT(x)))[k] = sum_j w[j] * x[j-k] (for k in [0, L-1])

For k in [0, n-1] (the range we need):
= sum_j w[j] * x[j-k] where j-k >= 0 and j < 2n-1 and j-k < n
= sum_j w[j] * x[j-k] where j in [k, k+n-1] and j in [0, 2n-2]

Let m = j-k:
= sum_m w[m+k] * x[m] where m in [0, n-1] and m+k in [0, 2n-2]
= sum_m w[m+k] * x[m] where m in [max(0, -k), min(n-1, 2n-2-k)]

For k in [0, n-1]: m+k ranges from k to k+n-1, and we need m+k <= 2n-2, i.e., m <= 2n-2-k. Since m <= n-1 and 2n-2-k >= n-1 (for k <= n-1), the constraint is just m in [0, n-1].

So for k in [0, n-1]:
ifft(FFT(w) * conj(FFT(x)))[k] = sum_{m=0}^{n-1} w[m+k] * x[m]

This is exactly what we want! sg[k] = 2 * sum_m x[m] * w[m+k] = 2 * ifft(FFT(w) * conj(FFT(x)))[k].

So my formula is correct.
