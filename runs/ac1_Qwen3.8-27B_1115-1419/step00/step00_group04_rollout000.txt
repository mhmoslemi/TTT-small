def fast_conv(a):

The objective is: minimize 2n * max_k C_k / (sum a)².

The uniform sequence gives max_k C_k = n (at the center). Any perturbation from uniform will increase some C_k and decrease others. The question is whether we can make ALL C_k ≤ n.

For the perturbation δ (with sum δ = 0):
C_k = C_k^unif + δ * (contribution from δ)

The uniform C_k^unif = (k+1) for 0 ≤ k ≤ n-1, and (2n-1-k) for n ≤ k ≤ 2n-2.

So the "deficit" from the uniform at lag k is: n - C_k^unif = n - (k+1) for k < n, or n - (2n-1-k) for k ≥ n.

The maximum deficit is at k=0 (and k=2n-2): n - 1 ≈ n.
The minimum deficit is at k=n-1: n - n = 0.

So at the center, the perturbation must be ≤ 0 (to not increase C_{n-1} above n). At the edges, the perturbation can be much more positive.

This means: we need a perturbation δ such that:
- sum_i δ_i * δ_{n-1-i} ≤ 0 (center doesn't increase)
- sum_i δ_i * δ_{k-i} ≤ (n - C_k^unif) for all k (other lags don't exceed n)

The second condition is very loose for edge lags (lots of room) but tight for lags near the center.

2. Make sure the perturbation is small enough that it doesn't increase other peaks.

def fast_conv(a):
    """Linear self-convolution via FFT."""
    n = len(a)
    N = 1 << (2 * n - 1).bit_length()
    f = np.fft.rfft(a, N)
    return np.fft.irfft(f * f, N)[:2*n-1]

def fast_obj(a):
    """2*n*max(conv)/sum(a)^2"""
    n = len(a)
    conv = fast_conv(a)
    s = a.sum()
    if s < 1e-6:
        return np.inf
    return 2.0 * n * conv.max() / (s * s)

        g[idx] = a[k_star - idx]
