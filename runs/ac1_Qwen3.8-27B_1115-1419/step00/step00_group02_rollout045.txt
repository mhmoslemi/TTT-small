    n = len(f)

    # C_f[k, m] = f[k-m] if 0 <= k-m < n
    k_idx = np.arange(2*n-1)[:, None]

= sum_{j=1}^{n-1} (j+1)(n+1-j)
Let i = j+1: = sum_{i=2}^{n} i*(n+2-i)
= sum_{i=1}^{n} i*(n+2-i) - 1*(n+1)
= (n+2)*n(n+1)/2 - n(n+1)(2n+1)/6 - (n+1)
= n(n+1)[(n+2)/2 - (2n+1)/6] - (n+1)
= n(n+1)(3n+6-2n-1)/6 - (n+1)
= n(n+1)(n+5)/6 - (n+1)
= (n+1)[n(n+5)/6 - 1]
= (n+1)(n^2+5n-6)/6

So (f*f)[n] = 4/(n^2(n+1)^2) * (n+1)(n^2+5n-6)/6 = 4(n^2+5n-6)/(6n^2(n+1))

For large n: ≈ 4/n^2 * n^2/(6n) = 4/(6n) = 2/(3n). Same leading order.
