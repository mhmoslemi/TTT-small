OK so the plan for computing the gradient:
1. Compute conv = np.convolve(a, a) [length 2n-1]
2. Compute weights = softmax(conv / tau) [length 2n-1]
3. w_rev = weights[::-1] [length 2n-1]
4. C = IFFT(FFT(a, L) * FFT(w_rev, L)) where L >= n + 2n-2 = 3n-2
5. C[j] = C[2n-2-j] for j=0..n-1
6. W_sum[j] = sum of weights[j:j+n] (sliding sum via cumsum)
7. grad_sm[j] = C[2n-2-j] + a[j] * W_sum[j]
8. grad_f = (2n/S^2) * (grad_sm - 2*M/S)
9. Update: a = max(0, a - lr * grad_f); a /= sum(a)

This should be O(n log n) per iteration.
