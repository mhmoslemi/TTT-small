If `f` is symmetric about its center (`f_i = f_{n-1-i}`), then `g_{n-1} = sum_i f_i^2`. By Cauchy-Schwarz, `sum f_i^2 ≥ (sum f)^2 / n`. So `g_{n-1} ≥ (sum f)^2 / n`. And we want `g_{n-1} ≤ 1.5 * (sum f)^2 / (2n-1)`. This requires `(sum f)^2 / n ≤ 1.5 * (sum f)^2 / (2n-1)`, i.e., `1/n ≤ 1.5/(2n-1)`, i.e., `2n-1 ≤ 1.5n`, i.e., `0.5n ≤ 1`, i.e., `n ≤ 2`. So for n > 2, a symmetric sequence cannot achieve score < 2!

This is a key insight: **the sequence must be asymmetric** to achieve score < 2.

If `f` is asymmetric, then `g_{n-1} = sum_i f_i * f_{n-1-i}` can be less than `sum f_i^2` (by the rearrangement inequality, the minimum of `sum f_i * f_{n-1-i}` over permutations is achieved when the sequences are sorted in opposite orders).

So the strategy should be: **make the sequence asymmetric in a way that minimizes the center autocorrelation while keeping the edge autocorrelations low.**

One approach: make `f` monotonically decreasing. Then `f_i` is large for small `i` and small for large `i`. The center autocorrelation `g_{n-1} = sum_i f_i * f_{n-1-i}` pairs large `f_i` with small `f_{n-1-i}`, reducing the sum.

Let's check: if `f_i = a * (1 - i/n)` (linearly decreasing from `a` to 0), then:
- `sum f ≈ a * n/2`
- `g_{n-1} = sum_i f_i * f_{n-1-i} = sum_i a(1-i/n) * a(1-(n-1-i)/n) = a^2 * sum_i (1-i/n)(i/n + 1/n)`
  `= a^2/n * sum_i (n-i)(i+1) = a^2/n * sum_i (ni + n - i^2 - i) = a^2/n * (n * n(n-1)/2 + n^2 - n(n-1)(2n-1)/6 - n(n-1)/2)`
