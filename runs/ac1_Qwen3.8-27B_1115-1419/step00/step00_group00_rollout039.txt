**Alternative: Direct optimization of the "flatness" of the autocorrelation.**

Since we want b to be as flat as possible, we can minimize the variance of b (or the max minus the mean). This is a differentiable objective (if we smooth the max).

Let me use the approach: minimize sum_k (b[k] - mean(b))^2 subject to sum(a) = 1, a_i >= 0.

This is a quartic optimization (b is quadratic in a, so b^2 is quartic). But we can use gradient descent.

Actually, let me use a simpler approach: minimize max(b) using a log-sum-exp approximation:
max(b) ≈ (1/beta) * log(sum(exp(beta * b)))

Then minimize log(sum(exp(beta * b))) subject to sum(a) = 1, a_i >= 0.

The gradient with respect to a[i]:
d/da[i] log(sum_k exp(beta * b[k])) = sum_k (beta * b[k] / sum_l exp(beta * b[l])) * db[k]/da[i]
= beta * sum_k (w[k] * 2 * a[k-i]) where w[k] = exp(beta*b[k]) / sum(exp(beta*b[l]))

This is a weighted "autocorrelation" of a with weights w. We can compute it efficiently using FFT.

The constraint sum(a) = 1 can be handled by Lagrange multipliers or by projecting onto the simplex after each step.

def compute_objective_normalized(a):

    n = len(a)

def gradient_logsumexp(a, beta):
    """Compute gradient of (1/beta)*log(sum(exp(beta*b))) w.r.t. a."""
    n = len(a)
