Also, I should add diversity: instead of always following the subgradient, sometimes try random directions.

Let me also think about convergence. The subgradient method on a piecewise-linear function (max of linear functions) converges, but slowly. For this problem, the objective is piecewise-quadratic (max of quadratics), so subgradient methods are even less straightforward.

A better approach might be to use the "moreau-yosida" smoothing: instead of max(c), use the soft-max:
SM(c, tau) = tau * log(sum(exp(c/tau)))
This is smooth and converges to max as tau → 0. The gradient is:
grad_j(SM) = (1/sum(exp(c/tau))) * sum_k exp(c_k/tau) * dc_k/df_j

But computing all dc_k/df_j is O(n) per k, and there are 2n-1 k's, so O(n^2) total. That's too slow.

Alternative: use a fixed number of "active" constraints (the top few c_k values) and average their gradients.

Let me refine the approach:

```python
# Use top-K active constraints
active = np.argsort(c)[::-1][:K]
grad = np.zeros(n)
for k in active:
    idx = k - np.arange(n)
    valid = (idx >= 0) & (idx < n)
    grad[valid] += 2.0 * f[idx[valid]]
grad /= K
```

With K=5 or 10, this is still O(K*n) = O(n) per iteration.

Actually, I realize there's an even better formulation. Let me think about this as a bilevel/outer-approximation problem:

minimize t
subject to: (f*f)_k <= t for all k = 0,...,2n-2
            sum(f) = 1
            f >= 0

For a given t, the feasible set is {f: (f*f)_k <= t for all k, sum(f)=1, f>=0}. We want the smallest t such that this is non-empty.

We can use bisection on t: for a candidate t, check if there exists f with (f*f)_k <= t for all k, sum(f)=1, f>=0. The check is a feasibility problem (QP).

But solving a QP with 5582 variables and 11163 quadratic constraints is expensive per iteration.

Alternatively, use the "cutting plane" / "outer approximation" method:
- Start with a subset of constraints (the "active" ones).
- Solve the LP/QP with active constraints.
- Check if the solution violates any inactive constraint.
- If yes, add that constraint and repeat.

For the inner problem (QCP with a few constraints), we can use projected gradient or a QP solver.
