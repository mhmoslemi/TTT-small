Actually, I think the LP-based approach from the SOTA description is more elegant and likely more effective. Let me implement that properly.

The key insight of the SOTA approach:
1. Current sequence f (sum=1), current max M = max(f*f).
2. Find g >= 0 that maximizes sum(g) subject to (f*g)[k] <= M for all k.
   - This is a LP in g!
   - (f*g)[k] = sum_i f_i * g_{k-i} (with appropriate bounds)
   - For fixed f, this is linear in g.
3. Normalize g to sum=1.
4. Move towards g: f = (1-t)*f + t*g.
5. Repeat.

The LP for step 2:
- Variables: g_0, ..., g_{n-1} >= 0
- Objective: maximize sum(g_i) (or minimize -sum(g_i))
- Constraints: for each k = 0, ..., 2n-2: sum_i f_{k-i} * g_i <= M
  where f_{k-i} = 0 if k-i is outside [0, n-1].
  So the constraint for lag k is: sum_{i: 0<=k-i<n} f_{k-i} * g_i <= M
  = sum_{i: max(0, k-n+1) <= i <= min(n-1, k)} f_{k-i} * g_i <= M

The constraint matrix A has A[k, i] = f[k-i] if 0 <= k-i < n, else 0.
This is a Toeplitz matrix (each row is a shifted version of f).

For n=1000: A is 1999 × 1000, with about n^2/2 = 500K nonzeros (actually more like n*(2n-1) - (n-1)*n ≈ n^2 total nonzeros).

Using scipy.optimize.linprog with method='highs' should handle this efficiently.
