import numpy as np
import time

def fast_convolve(a):
    """Compute linear convolution using FFT."""
    n = len(a)
    size = 1
    while size < 2*n - 1:
        size *= 2
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2*n-1]

def smooth_max(b, tau):
    """Compute the smooth maximum (log-sum-exp) of b / tau."""
    b_max = np.max(b)
    if np.isinf(b_max):
        return b_max
    shifted = tau * b - b_max * tau
    log_sum = np.log(np.sum(np.exp(shifted))) + b_max * tau
    return log_sum / tau

def grad_smooth_max(b, a, tau):
    """Compute the gradient of the smooth max of b=a*a w.r.t. a."""
    n = len(a)
    # Softmax weights
    b_max = np.max(b)
    p = np.exp(tau * b - tau * b_max)
    p /= np.sum(p)
    # Gradient: 2 * corr(p, a) at appropriate indices
    # (p has length 2n-1, a has length n)
    # We need c_j = sum_{m=0}^{n-1} p_{j+m} * a_m for j=0,...,n-1
    # This is the cross-correlation of p and a
    size = 1
    while size < len(p) + n - 1:
        size *= 2
    fp = np.fft.rfft(p, size)
    fa = np.fft.rfft(a, size)
    corr = np.fft.irfft(fp * np.conj(fa), size)
    # The cross-correlation corr[k] = sum_m p[m+k] * a[m]
    # We want corr[j] for j = 0, ..., n-1
    grad = 2.0 * corr[:n]
    return grad

One more thought: the problem is equivalent to finding a non-negative sequence with minimum "peak-to-mean ratio" of its self-convolution. This is related to the "minimum peak-to-average power ratio" (PAPR) problem in signal processing.

In the PAPR literature, the "successive interference cancellation" (SICS) algorithm and the "Adam's algorithm" are commonly used. Let me adapt the Adam's algorithm:

**Adam's Algorithm (for PAPR reduction):**
1. Start with a sequence $a$.
2. Compute the "interference" at each position: $I_k = b_k - b_k^{target}$ where $b_k = (a*a)_k$ and $b_k^{target}$ is the desired level.
3. "Cancel" the interference by adjusting $a$.

The key idea is: if $b_k$ is too large, we want to reduce the "contribution" of $a$ to $b_k$. Since $b_k = \sum_i a_i a_{k-i}$, reducing $a_i$ (for $i$ that contribute to $b_k$) will reduce $b_k$.

A simple version:
1. Compute $b = a*a$.
2. Find the positions where $b_k$ exceeds the target.
3. For each such position $k$, reduce $a_i$ for $i$ in the "support" of $b_k$ (i.e., $i$ such that both $i$ and $k-i$ are valid).
4. Redistribute the reduced mass to positions where $b$ is below the target.
5. Repeat.

This is essentially the LP approach in a simplified form.

Let me combine all these ideas into a practical algorithm:

**Final Algorithm:**
1. Start from multiple initializations.
2. For each initialization, run an iterative optimization:
   a. Compute the convolution $b = a*a$ (using FFT).
