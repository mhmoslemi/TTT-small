def lp_direction(a, M=None):
    """Find LP direction: max sum(g) s.t. conv(a,g) <= M, g >= 0"""
    n = len(a)
    if M is None:
        conv_aa = np.convolve(a, a)
        M = np.max(conv_aa)
    
    # Build constraint matrix: A @ g <= M (scalar, same for all k)
    # Constraint k: sum_i a[i] * g[k-i] <= M for k = 0, ..., 2n-2
    # g has n components (g[0], ..., g[n-1])
    
    rows = []
    cols = []
    vals = []
    
    for k in range(2*n - 1):
        for i in range(n):
            j = k - i  # g[j] coefficient
            if 0 <= j < n:
                rows.append(k)
                cols.append(j)
                vals.append(a[i])
    
    A = csr_matrix((vals, (rows, cols)), shape=(2*n-1, n))
    
    # Maximize sum(g) = -minimize -sum(g)
    c = -np.ones(n)
    b = np.full(2*n-1, M)
    
    try:
        result = linprog(c, A_ub=A, b_ub=b, bounds=[(0, None)]*n, method='highs')
        if result.success:
            return result.x
    except Exception:
        pass
    return None

def local_search(a, deadline, rng, max_iter=10000):

- The convolution of the full sequence is the same as the convolution of the m-element part (padded with zeros)
- max(conv) = m/m^2 = 1/m
- score = 2*n*(1/m)/1 = 2n/m

For this to be < 2, we need n/m < 1, i.e., m > n. Which is impossible since m <= n.

So a sequence with zeros at the ends can NEVER beat 2! The zeros just increase n without contributing to the convolution.

What about zeros in the middle? Let's think about it differently.

OK so I was wrong earlier. Let me think about when the score CAN be less than 2.

The score is 2*n*max(conv)/sum^2. For score < 2, we need max(conv) < sum^2/n.

For a probability vector (sum=1), we need max(conv) < 1/n.

But conv[n-1] = sum a[i]*a[n-1-i]. By Cauchy-Schwarz, this is at most sum a[i]^2. And sum a[i]^2 >= 1/n. So conv[n-1] can be as low as... well, it depends on the sequence.

Wait, Cauchy-Schwarz says (sum a[i]*b[i])^2 <= (sum a[i]^2)(sum b[i]^2). Here b[i] = a[n-1-i], so sum b[i]^2 = sum a[i]^2. Thus conv[n-1]^2 <= (sum a[i]^2)^2, so conv[n-1] <= sum a[i]^2. This gives an upper bound, not a lower bound.

For a lower bound: conv[n-1] = sum a[i]*a[n-1-i] >= 0 (since a >= 0). So the center value can be 0!

Example: a = [1, 0, 0] (n=3): conv[2] = a[0]*a[2]+a[1]*a[1]+a[2]*a[0] = 0+0+0 = 0.
But conv = [1, 0, 0, 0, 0], max = 1. Score = 2*3*1/1 = 6.

The issue is that even if the center is 0, other conv values might be large.

For the score to be < 2, ALL conv values must be < 1/n (for sum=1). In particular, conv[0] = a[0]^2 < 1/n, so a[0] < 1/sqrt(n). Similarly for all elements.

But we also need the "off-diagonal" terms to be small. For example, conv[1] = a[0]*a[1] + a[1]*a[0] = 2*a[0]*a[1] < 1/n.

This is a very restrictive constraint. Let me think about whether it's achievable.

If a[i] = 1/sqrt(n) for all i (sum = sqrt(n), not 1), then:

max = 1/n

So for uniform, the max is exactly 1/n and score = 2. To get score < 2, we need max(conv) < 1/n for a probability vector. But conv[n-1] = sum a[i]*a[n-1-i]. If a is the uniform probability (1/n each), then conv[n-1] = n*(1/n)^2 = 1/n.

Can we make conv[n-1] < 1/n? We need sum a[i]*a[n-1-i] < 1/n subject to sum a[i] = 1, a[i] >= 0.

If a is symmetric, conv[n-1] = sum a[i]^2. By power mean, sum a[i]^2 >= 1/n. So for symmetric sequences, conv[n-1] >= 1/n, and score >= 2.

Actually, I think the optimal shape might be something like a "staircase" or a function that decreases from left to right. Let me think about what continuous analog would work.

In the continuous case, if f is a non-negative function on [0,1] with integral 1, we want to minimize the peak of f*f (the convolution). The peak of f*f is at the point where f has the most "self-similarity."

For f(x) = 1 (uniform), f*f is triangular with peak 1. Score analog = 2.
For f(x) = 2x (linearly increasing), integral = 1.
f*f(x) = integral_0^1 f(t)f(x-t) dt = integral_0^{min(x,1)} 2t*2(x-t) dt (for 0<=x<=1)
= 4 * integral_0^x t(x-t) dt = 4 * [x*t^2/2 - t^3/3]_0^x = 4 * (x^3/2 - x^3/3) = 4 * x^3/6 = 2x^3/3

For x in [1,2]: f*f(x) = integral_{x-1}^1 2t*2(x-t) dt
= 4 * integral_{x-1}^1 t(x-t) dt
= 4 * [x*t^2/2 - t^3/3]_{x-1}^1
= 4 * [(x/2 - 1/3) - (x(x-1)^2/2 - (x-1)^3/3)]
This is getting complicated. Let me just evaluate at x=1:
f*f(1) = 4 * integral_0^1 t(1-t) dt = 4 * [t^2/2 - t^3/3]_0^1 = 4*(1/2-1/3) = 4/6 = 2/3

And f*f(0) = 0, f*f(2) = 0.
The peak of f*f is at x=1 (or near it) with value 2/3.

Compare to uniform: peak = 1. So the linear function has a lower peak!

Score analog for continuous: the "score" would be (max of f*f) / (integral f)^2 * (some factor). If we use the same formula: 2 * (max f*f) / (integral f)^2. For f(x)=2x: 2*(2/3)/1 = 4/3. Better than uniform's 2!
