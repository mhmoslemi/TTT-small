    """Compute full convolution using FFT."""

    while size < n:
        size *= 2
    fa = rfft(a, size)
    fb = rfft(b, size)
    return irfft(fa * fb, size)[:n]

def compute_gradient(a, w):
    """Compute soft-max weighted gradient of max(convolve(a,a))."""
    n = len(a)
    # w has length 2n-1
    v_rev = w[::-1]  # reversed w, length 2n-1
    conv_full = fast_full_convolve(a, v_rev)  # length n + 2n-1 - 1 = 3n-2
    # grad[i] = conv_full[2n-2-i] for i=0,...,n-1
    # So grad = conv_full[n-1:2n-1][::-1]
    grad = conv_full[n-1:2*n-1][::-1]
    return grad

def softmax(x, T):
    """Numerically stable softmax."""
    x_shifted = x - np.max(x)
    ex = np.exp(x_shifted / T)
    return ex / np.sum(ex)

Let me think about this from a different angle. The convolution of a with itself is c[k] = sum_i a[i]*a[k-i]. If a is a smooth function (like a Gaussian), then c is the convolution of two smooth functions, which is also smooth. The key is the ratio max(c) / mean(c) = max(c) / (sum(c)/(2n-1)) = (2n-1)*max(c) / sum(c) = (2n-1)*max(c) / sum(a)^2.

For a Gaussian a[i] = exp(-i^2/(2*sigma^2)) / Z (normalized), the convolution is a wider Gaussian with std sigma*sqrt(2). The max of the convolution is proportional to 1/(sigma*sqrt(2)), and the "effective width" is sigma*sqrt(2). The peak-to-mean ratio for a Gaussian is proportional to the width in units of the effective support.

For a truncated Gaussian (effectively supported on n positions), the peak-to-mean ratio is roughly:
- If sigma << n: the Gaussian is much narrower than the support, and the convolution is also narrow. Peak/mean ≈ (2n-1)/effective_width ≈ 2n/(sigma*sqrt(2)*const). This can be >> 2.
- If sigma ≈ n: the Gaussian is about the same width as the support. The convolution is slightly wider. Peak/mean ≈ 2 * (some factor close to 1). This is close to the uniform case.
- If sigma >> n: the Gaussian is wider than the support, so it's truncated and looks like a smooth function on the support. The convolution is also truncated. Peak/mean depends on the truncation.

I think for our purposes, the optimal sequence is one that's "slightly wider than uniform" in some sense - i.e., a smooth function on the support that's close to uniform but slightly concave (higher in the center, lower at the edges).
