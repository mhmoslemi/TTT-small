More generally: DFT(a)^2 = [C_0, 0, ..., C_{p/2}, 0, ..., 0] where C_0 and C_{p/2} satisfy:
C_0 + (-1)^k * C_{p/2} = C*p for all k.
This gives C_0 = C_{p/2} = C*p/2 (for even p).

So the condition is:
- A_0^2 = C*p/2
- A_{p/2}^2 = C*p/2
- A_k^2 = 0 for k not in {0, p/2}

This means A_k = 0 for k not in {0, p/2}. So a is of the form:
a[j] = (A_0 + A_{p/2} * exp(2pi*i*p/2*j/p))/p = (A_0 + A_{p/2}*(-1)^j)/p
