**Another idea: "Project onto the set where conv == T"**

This is like a constraint satisfaction approach. Given a target $T$, I want to find $a \geq 0, \sum a = 1$ such that $(a*a)[k] \leq T$ for all $k$. If I can find the minimum such $T$, I'm done.

For a given $T$, the feasibility problem is:
$a \geq 0, \sum a = 1, (a*a)[k] \leq T \forall k$.

This is non-convex. But I can use an iterative approach:
1. Start with $a_0$ and $T_0 = \max(a_0 * a_0)$.
2. Find the most violated constraint: $k^*$ such that $(a*a)[k^*] = T_0$.
3. Adjust $a$ to reduce $(a*a)[k^*]$ while keeping other constraints satisfied.
4. Try to decrease $T$.

This is essentially what the subgradient method does. So I'm already on the right track.
