So the peak increases for $k > n-1$ and decreases for $k < n-1$. The maximum is at $k$ as large as possible (for $\epsilon > 0$), which is near $k = 2n-2$.

At $k = 2n-2$: $(a*a)_{2n-2} = a_{n-1}^2 = (1 + \epsilon(n-1)/2)^2 \approx 1 + \epsilon(n-1)$.

So the peak is at the far end, and its value is approximately $1 + \epsilon(n-1)$. For the constant sequence, this value was 1 (well, $c^2$ where $c = S/n$).

Hmm, so a linear perturbation of the constant makes the far-end peak grow. This is bad.

What if we use a non-linear perturbation? Like $a_i = 1 + \epsilon \sin(2\pi i/n)$?

For a sinusoidal perturbation, the effect on the convolution is more complex. The first-order effect is:
$(a*a)_k \approx m_k + \epsilon \sum_i \sin(2\pi i/n) \cos(2\pi(k-i)/n)$ (using the product-to-sum formula).

This might have zero first-order effect at the peak... Let me not go down this path analytically and instead just try numerical optimization.

Actually, let me reconsider the LP approach more carefully.

Given $a$ (current sequence), $M = \max(a*a)$, and we want to find $b \geq 0$ maximizing $\sum b$ subject to $(a*b)_k \leq M$ for all $k = 0, \ldots, 2n-2$.

The constraint $(a*b)_k \leq M$ is: $\sum_i a_i b_{k-i} \leq M$ (with appropriate bounds).

This is a system of linear inequalities in $b$. The LP is:
$\max \mathbf{1}^T b$
s.t. $A b \leq M \mathbf{1}$
$b \geq 0$

where $A$ is a $(2n-1) \times n$ matrix with $A_{k,i} = a_i$ if $0 \leq k-i \leq n-1$, else 0. (This is a "toeplitz-like" matrix.)

After solving, we get $b^*$. Then we blend:
$a_{new} = (1-t) a + t \cdot c \cdot b^*$ where $c$ is chosen so that $\sum a_{new} = \sum a$.

The blending parameter $t$ controls the step size. We can use a line search: try several $t$ values and pick the one that minimizes the objective.

This approach should work well because:
- The LP finds the "best" direction to move.
- The line search ensures we don't overshoot.
- Repeating this should converge to a local (or even global) minimum.

Let me implement this. I'll use scipy's linear programming solver (or cvxpy if available).

Actually, for efficiency, I can use `scipy.optimize.linprog` with the HiGHS method, which is fast for problems of this size.

import numpy as np
import time
from scipy.optimize import linprog

def compute_convolution(a):
    """Compute full convolution of a with itself."""
    return np.convolve(a, a)

def objective_value(a):
    """Compute the objective J(a) = 2n * max(a*a) / (sum(a))^2."""
    n = len(a)
    conv = compute_convolution(a)
    S = np.sum(a)
    if S < 0.01:
        return np.inf
    return 2.0 * n * np.max(conv) / (S * S)

def solve_lp(a, M):
    """Solve the LP to find best direction b."""
    n = len(a)
    # Maximize sum(b) subject to (a*b)_k <= M for all k, b >= 0
    # In linprog form: minimize -sum(b) subject to (a*b)_k <= M, b >= 0
    
    c = -np.ones(n)  # minimize -sum(b)
    
    # Constraints: (a*b)_k <= M for k = 0, ..., 2n-2
    # (a*b)_k = sum_i a_{k-i} * b_i (where a_j = 0 if j < 0 or j >= n)
    # So the constraint matrix A has A[k, i] = a[k-i] if 0 <= k-i <= n-1
    
    A_ub = np.zeros((2*n-1, n))
    for k in range(2*n-1):
        for i in range(n):
            j = k - i
            if 0 <= j < n:
                A_ub[k, i] = a[j]
    
    b_ub = np.full(2*n-1, M)
    
    # b >= 0 is handled by bounds
    bounds = [(0, None)] * n
    
    result = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    return result.x if result.success else None

    init_seqs.append(np.ones(256))
    
    # Linear ramp
    init_seqs.append(np.arange(1, 257, dtype=np.float64))
    
    # Exponential
    init_seqs.append(np.exp(np.linspace(0, 2, 256)))
    
    # Various n values
    for n in [100, 500, 1000, 2000, 5000]:
        init_seqs.append(np.ones(n))
        init_seqs.append(np.exp(np.linspace(0, 1, n)))
    
    best_seq = None
    best_score = np.inf
    
    for seq in init_seqs:
        score = objective_value(seq)
        if score < best_score:
            best_score = score
            best_seq = seq.copy()
    
    # Now optimize the best initial sequence
    a = best_seq.copy()
    n = len(a)
    
    while time.monotonic() < deadline:

        M = np.max(conv)
        S = np.sum(a)
        current_score = 2.0 * n * M / (S * S)

        b = solve_lp(a, M)
        if b is None:

            a_t = np.clip(a_t, 0, 1000)
            if np.sum(a_t) < 0.01:

            score_t = objective_value(a_t)
            if score_t < best_t_score:

                best_t = t

            k_star = np.argmax(conv)
            # Gradient of (a*a)_{k_star}
            g = np.zeros(n)

        if score < best_score:

            best_seq = a.copy()
