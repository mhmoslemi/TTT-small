```python
from scipy.optimize import linprog

def solve_lp(f, M):
    """Solve max sum(g) subject to g >= 0 and f*g <= M."""
    n = len(f)
    # Variables: g_0, ..., g_{n-1}
    # Objective: minimize -sum(g)
    c = -np.ones(n)
    
    # Constraints: (f*g)_k <= M for k = 0, ..., 2n-2
    # (f*g)_k = sum_i f_i * g_{k-i} where g_j = 0 for j < 0 or j >= n
    # For a given k, the valid i range is max(0, k-(n-1)) <= i <= min(n-1, k)
    # And g_{k-i} must have index k-i in [0, n-1], so i in [k-(n-1), k]
    
    A_ub = np.zeros((2*n-1, n))
    b_ub = np.full(2*n-1, M)
    
    for k in range(2*n-1):
        for i in range(max(0, k-n+1), min(n, k+1)):
            j = k - i  # index of g
            A_ub[k, j] = f[i]
    
    bounds = [(0, None)] * n
    result = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    return result.x
```

But for `n = 6733`, the matrix `A_ub` is `(2n-1) x n ≈ 13465 x 6733`, which is about 90 million entries. That's a lot of memory (about 720 MB as float64). It might be too large.

def solve_lp_sparse(f, M):
    n = len(f)
    c = -np.ones(n)
    
    # Build sparse constraint matrix
    rows = []
    cols = []
    data = []
    
    for k in range(2*n-1):
        for i in range(max(0, k-n+1), min(n, k+1)):
            j = k - i
            rows.append(k)
            cols.append(j)
            data.append(f[i])
    
    A_ub = csr_matrix((data, (rows, cols)), shape=(2*n-1, n))
    b_ub = np.full(2*n-1, M)
    
    bounds = [(0, None)] * n
    result = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    return result.x

def project_simplex(v):
    """Project v onto the probability simplex {x: x >= 0, sum(x) = 1}."""
    n = len(v)
    if np.sum(v) <= 0:
        return np.ones(n) / n
    # Euclidean projection onto simplex
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)


def compute_score(a):
    """Compute the objective value directly."""
    n = len(a)
    b = np.convolve(a, a, mode='full')
    max_b = np.max(b)
    sum_a = np.sum(a)
    if sum_a < 0.01:
        return np.inf
    return 2.0 * n * max_b / (sum_a ** 2)


def lp_iteration(f, M, rng):
    """One LP iteration: find g maximizing sum(g) + small random perturbation
    subject to g >= 0 and f*g <= M."""
    n = len(f)
    # Build sparse constraint matrix A_ub where (A_ub @ g)_k = (f*g)_k
    rows = []
    cols = []
    data = []
    for k in range(2 * n - 1):
        i_lo = max(0, k - n + 1)
        i_hi = min(n - 1, k)
        for i in range(i_lo, i_hi + 1):
            j = k - i  # index into g
            rows.append(k)
            cols.append(j)
            data.append(f[i])
    
    A_ub = csr_matrix((data, (rows, cols)), shape=(2 * n - 1, n))
    b_ub = np.full(2 * n - 1, M)
    
    # Objective: minimize -(sum g + epsilon * r . g)
    epsilon = 0.01
    r = rng.standard_normal(n)
    c = -(1.0 + epsilon * r)
    
    bounds = [(0, None)] * n
    
    result = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if result.success:
        return result.x
    return None

def block_perturbation(f, rng, n_blocks=10):
    """Apply random block perturbations."""
    n = len(f)
    candidate = f.copy()
    block_size = max(1, n // n_blocks)
    for _ in range(rng.integers(1, 5)):
        start = rng.integers(0, n - block_size)
        end = start + block_size
        candidate[start:end] *= np.exp(rng.normal(0, 0.1))
    candidate = np.maximum(candidate, 0)
    sum_c = np.sum(candidate)
    if sum_c > 0:
        candidate = candidate / sum_c
    return candidate

The key formula is:
`grad[i] = (1/tau) * sum_k p_k * (2*a_{k-i} - a_i * [k=2i])`

Let me define `q_k = 2*p_k` for all `k`, and subtract `p_{2i}*a_i` for the diagonal.

The main term is `(1/tau) * sum_k (2*p_k) * a_{k-i}` = `(2/tau) * (p *_ a)[i]` where `*_` is the appropriate correlation.

Let me define: `s[i] = sum_{k=0}^{2n-2} p_k * a_{k-i}` where `a_j = 0` for `j < 0` or `j >= n`.

This is: `s[i] = sum_{j=0}^{n-1} p_{i+j} * a_j` (where `p_{i+j}` is 0 if `i+j >= 2n-1`).

This is the "valid" cross-correlation of `p` and `a`:
`s = np.correlate(p, a[:], mode='valid')` ... hmm, let me check.

`np.correlate(p, a, mode='full')[k] = sum_j p[j] * a[j + k - (len(a)-1)]`

Actually, I think the clearest way is:
`s[i] = sum_{j=0}^{n-1} p_{i+j} * a_j`

This is: take the segment `p[i:i+n]` and dot it with `a`. This is a "sliding dot product" or "valid cross-correlation."

In numpy: `scipy.signal.correlate(p, a, mode='valid')` gives:
`c[i] = sum_j p[i+j] * conj(a[j])` for real `a`, this is `sum_j p[i+j] * a[j]`.

Yes! `scipy.signal.correlate(p, a, mode='valid')` gives exactly `s[i]` for `i = 0, ..., len(p)-len(a) = (2n-1)-n = n-1`.

So `s = scipy.signal.correlate(p, a, mode='valid')` has length `n`, and `s[i] = sum_j p_{i+j} * a_j`.

Then `grad[i] = (2/tau) * s[i] - (1/tau) * p_{2i} * a[i]` (if `2i < 2n-1`, else just `(2/tau) * s[i]`).

This is O(n) after computing `s` via FFT (which is O(n log n)).
