**Clean algorithm design:**

The objective is `score = 2*n*max(b) / S²` where `b = convolve(a, a)`, `S = sum(a)`.

Key observations:
1. `sum(b) = S²` (total energy of convolution equals square of sum)
2. `max(b) >= S²/(2n-1)` (peak >= average)
3. Lower bound on score: `2n/(2n-1) ≈ 1` for large n
4. Constant sequence gives score = 2
5. We want to flatten b to reduce max(b)

**Strategy**: Use an iterative multiplicative update that flattens b:
1. Compute b = convolve(a, a)
2. Compute "pressure" on each a[j]: how much a[j] contributes to the peaks of b
3. Reduce high-pressure elements, increase low-pressure elements
4. Repeat

For step 2, the pressure on a[j] is:
`p[j] = sum_k b[k] * ∂b[k]/∂a[j] / max(b)`

This is like a "sensitivity" measure.

import numpy as np
import time


def _fft_autoconv(a):
    """Compute auto-convolution a*a via FFT, return array of length 2n-1."""
    n = len(a)
    size = 2 ** int(np.ceil(np.log2(2 * n - 1)))
    A = np.fft.rfft(a, n=size)
    b = np.fft.irfft(A * A, n=size)
    return b[:2 * n - 1]


def _subgradient_peaks(a, peaks):
    """Subgradient of max(b) w.r.t. a, averaged over peak indices."""
    n = len(a)
    grad = np.zeros(n)
    for k in peaks:
        j1_lo = max(0, k - n + 1)
        j1_hi = min(n - 1, k)
        if j1_lo <= j1_hi:
            grad[j1_lo:j1_hi + 1] += a[k - j1_hi:k - j1_lo + 1][::-1]
        j2_lo = max(0, k)
        j2_hi = min(n - 1, k + n - 1)
        if j2_lo <= j2_hi:
            grad[j2_lo:j2_hi + 1] += a[j2_lo - k:j2_hi - k + 1]
    return grad / max(1, len(peaks))


def _score_from_conv(a, b):
    P = float(np.max(b))
    S = float(np.sum(a))
    if S < 0.01:
        return np.inf
    return 2.0 * len(a) * P / (S * S)

    eta = 0.8
