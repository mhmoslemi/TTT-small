However, the strategy claims that the iteration produces non-increasing ||f*f||_inf. Let me think about why.

The blending a_new = (1-t)*a + t*b gives:
(a_new * a_new)_k = (1-t)^2 (a*a)_k + 2t(1-t) (a*b)_k + t^2 (b*b)_k

We know (a*a)_k <= M and (a*b)_k <= M. If we also had (b*b)_k <= M, then (a_new*a_new)_k <= M for all k, and the peak doesn't increase.

But we don't know (b*b)_k <= M. However, if t is small enough, the t^2 term is negligible and the (1-t)^2 and 2t(1-t) terms dominate, both of which are <= M. So for small t, the peak doesn't increase.

Specifically: (a_new*a_new)_k <= (1-t)^2 M + 2t(1-t) M + t^2 * max(b*b)
= M[(1-t)^2 + 2t(1-t)] + t^2 * max(b*b)
= M(1-t)(1-t+2t) + t^2 * max(b*b)
= M(1-t)(1+t) + t^2 * max(b*b)
= M(1-t^2) + t^2 * max(b*b)

For this to be <= M, we need t^2 * max(b*b) <= t^2 * M, i.e., max(b*b) <= M, which we don't know.

Alternatively, if max(b*b) = C*M for some C, then:
(a_new*a_new)_k <= M(1-t^2) + t^2*C*M = M(1 + t^2(C-1))

For C > 1, this increases with t. So we need t to be small enough: t^2(C-1) < epsilon.

In practice, we can just try t=1, 0.5, 0.25, ... and check if J actually decreases. If it does, accept; if not, try smaller t or reject.

Actually, for the fine optimization, I can use a much simpler approach: **gradient-like descent**.

The gradient of R_a(k) = sum_i a_i * a_{i+k} with respect to a_j is:
dR_a(k)/da_j = a_{j-k} + a_{j+k} (for valid indices)

So the gradient of max_k R_a(k) is the gradient of the active R_a(k) (the one achieving the max).

We can use subgradient descent:
1. Find k* = argmax R_a(k)
2. Compute the subgradient g_j = a_{j-k*} + a_{j+k*} (for valid indices)
3. Update: a_j -= eta * g_j for all j
4. Project: a_j = max(0, a_j), then renormalize to sum = 1

This is very cheap (O(n) per step) and can be run millions of times.

But subgradient descent is slow to converge. Let me use a momentum-based variant or Nesterov acceleration.

Actually, let me think about this more carefully. The subgradient of max_k R_a(k) at point a is:
∇(max_k R_a(k))(a) = sum_{k in S} lambda_k * ∇R_a(k) where S = {k: R_a(k) = max} and lambda_k >= 0, sum lambda_k = 1.

The simplest choice is lambda_{k*} = 1 for k* = argmax. But a better choice is to use all active k's.

In practice, only a few k's are active (usually k=0 is the max for most sequences). So the subgradient is approximately:
g_j = a_{j-k*} + a_{j+k*} (with 0 for out-of-bounds)

```python
def subgradient_step(a, eta, num_active=5):
    n = len(a)
    conv = np.convolve(a, a)
    # Find top num_active lags
    top_k = np.argsort(conv)[::-1][:num_active]
    
    # Subgradient
    g = np.zeros(n)
    for k in top_k:
        k = int(k)
        if k == 0:
            g += 2 * a
        else:
            # conv[k] = sum_{i=0}^{n-1-k} a[i] * a[i+k]
            # d(conv[k])/da[j] = a[j-k] + a[j+k] (for valid j)
            for j in range(n):
                dj = 0
                if j - k >= 0:
                    dj += a[j-k]
                if j + k < n:
                    dj += a[j+k]
                g[j] += dj
    
    # Update
    a_new = a - eta * g
    a_new = np.clip(a_new, 0, None)
    if a_new.sum() > 0:
        a_new = a_new / a_new.sum()
    return a_new
```
