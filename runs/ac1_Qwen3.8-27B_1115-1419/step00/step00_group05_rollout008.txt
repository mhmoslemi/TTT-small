**Iterative approach (simplified LP-inspired):**

1. Start with initial a
2. Compute M = max(conv(a,a))
3. Find the constraint that's most "binding" - the index k* where conv(a,a) is maximum
4. Compute the "direction" that would reduce conv(a,.)[k*] while keeping a >= 0
5. Take a step in that direction
6. Repeat

The "direction" in step 4: we want to find b >= 0 such that conv(a,b)[k*] is minimized (ideally negative, but since a,b >= 0, it can't be negative). So we want conv(a,b)[k*] = sum_i a[i]*b[k*-i] to be small. This means b should be small at indices k*-i where a[i] is large.

Equivalently, b[j] should be small where a[k*-j] is large (i.e., b[j] should be inversely proportional to a[k*-j]).

A simple choice: b[j] = 1 / (a[k*-j] + epsilon) (for valid k*-j), and b[j] = 1 for invalid k*-j.

Then conv(a,b)[k*] = sum_i a[i] / (a[i] + epsilon) ≈ sum_i 1 = n (for small epsilon).
And conv(a,a)[k*] = sum_i a[i]² which is typically >> n.

So this direction does reduce the peak!

But we also need to consider the other convolution values. A more principled approach:

**Better iterative approach:**

1. Start with initial a
2. At each iteration:
   a. Compute c = conv(a,a), M = max(c)
   b. Compute weights w[k] = c[k]^p for some p (emphasizing the peaks)
   c. Compute the "gradient" g[j] = 2 * sum_m w[j+m] * a[m] (as derived above)
   d. The direction to reduce the weighted peak is -g
   e. But we also want to maintain the sum. So use: a_new = a - eta * g + eta * (sum(a)/(n*sum(g))) * sum(g)/n
      (This projects the gradient to have zero mean, preserving the sum approximately)
   f. Actually simpler: a_new = a - eta * (g - mean(g)), then clip to [0, 1000]
   g. Normalize: a_new = a_new * (sum(a) / sum(a_new))
3. Use adaptive step size (line search or backtracking)

This is essentially a projected gradient descent with a "peak-emphasizing" weighting.

"""
Minimizes 2n*max(conv(a,a))/sum(a)^2 for non-negative sequences a.
Uses FFT-based convolution, gradient descent with peak-emphasizing weights,
multiple initializations, and adaptive step sizes.
"""
import numpy as np
import time

def _fft_convolve(a, b=None):
    """Full linear convolution using FFT."""
    if b is None:
        b = a
    n = len(a) + len(b) - 1
    size = 1
    while size < n:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:n]

def _compute_grad(weights, a):
    """Compute g[j] = 2 * sum_{m=0}^{n-1} weights[j+m] * a[m]."""
    n = len(a)
    # Direct computation: O(n^2)
    # For n up to ~10000, this is 100M ops which is ~100ms in numpy
    # Use matrix multiplication for speed
    # g[j] = 2 * a @ weights[j:j+n]^T ... no
    # g[j] = 2 * sum_m a[m] * weights[j+m]
    # This is a correlation. Use scipy or direct.
    # For speed, use the fact that it's a Toeplitz matrix-vector product
    # But for simplicity, just do it directly with broadcasting for moderate n
    
    if n <= 5000:
        # Create index array
        idx = np.arange(n)
        # weights[j+m] for j=0..n-1, m=0..n-1
        # This is a (n, n) matrix where row j is weights[j:j+n]
        # g = 2 * (weights_matrix @ a)
        # But creating the full matrix is O(n^2) memory
        # Instead, use a loop or strided tricks
        g = np.empty(n)
        for j in range(n):
            g[j] = 2.0 * np.dot(a, weights[j:j+n])
        return g
    else:
        # Use FFT-based approach
        # g[j] = 2 * sum_m a[m] * weights[j+m]
        # = 2 * cross_correlation(a, weights)[n-1-j] ... need to get indices right
        # Actually: define w_padded = weights (length 2n-1)
        # g[j]/2 = sum_{m=0}^{n-1} a[m] * w_padded[j+m]
        # This is the "valid" cross-correlation of a and w_padded
        # np.correlate(w_padded, a, mode='valid')[j] = sum_m w_padded[j+m] * a[m]
        # Wait: np.correlate(v, w)[k] = sum_n v[n+k] * conj(w[n])
        # So np.correlate(weights, a, mode='valid') = sum_n weights[n+k] * a[n] for k=0..(len(weights)-len(a))
        # = sum_n weights[n+k] * a[n] for k=0..n-1 (since len(weights)=2n-1, len(a)=n)
        # That's exactly what we want! g/2 = np.correlate(weights, a, mode='valid')
        g = 2.0 * np.correlate(weights, a, mode='valid')
        return g

def _initialize(n, init_type, rng):
    """Create initial sequence."""
    t = np.linspace(0, 1, n)
    if init_type == 'ramp':
        a = (t + 0.1) / 1.1
    elif init_type == 'sigmoid':
        a = 1.0 / (1.0 + np.exp(-10.0 * (t - 0.3)))
    elif init_type == 'power':
        a = (t + 0.1) ** 2.0
    elif init_type == 'exp':
        a = np.exp(2.0 * (t - 1.0)) + 0.05
    elif init_type == 'tri':
        a = np.abs(t - 0.7)  # asymmetric triangle
    elif init_type == 'neg_tri':
        a = 1.0 - np.abs(t - 0.3) / (1.0 - 0.3)
    elif init_type == 'random':
        a = np.abs(rng.normal(0.5, 0.3, n)) + 0.05
    else:
        a = np.ones(n) * 0.5
    
    a = np.clip(a, 0.0, 1000.0)
    return a

def _gradient_step(a, weights_power, eta, rng, smooth_sigma=0):
    """One gradient descent step with peak-emphasizing weights."""
    n = len(a)
    S = np.sum(a)
    if S < 1e-10:
        return a, 0
    
    # Compute convolution
    conv = _fft_convolve(a)
    M = np.max(conv)
    if M < 1e-30:
        return a, 0
    
    # Peak-emphasizing weights
    normalized = conv / M
    weights = normalized ** weights_power
    
    # Compute gradient
    g = _compute_grad(weights, a)
    
    # Remove mean to preserve sum
    g = g - np.mean(g)
    
    # Normalize gradient
    max_g = np.max(np.abs(g))
    if max_g < 1e-30:
        return a, M
    
    # Step size
    scale = eta * S / (n * max_g)  # scale so that total change is ~ eta * S
    a_new = a - scale * g
    a_new = np.clip(a_new, 0.0, 1000.0)
    
    # Optional smoothing
    if smooth_sigma > 0 and n > 10:
        # Simple moving average
        kernel_size = max(3, int(2 * smooth_sigma * 3) | 1)
        kernel = np.ones(kernel_size) / kernel_size
        a_new = np.convolve(a_new, kernel, mode='same')
    
    # Rescale to preserve sum
    S_new = np.sum(a_new)
    if S_new < 1e-10:
        a_new = a.copy()
    else:
        a_new = a_new * (S / S_new)
    
    return a_new, M

    n = len(a_init)

    score = float(evaluate_sequence(a.tolist()))

    best_score = score
