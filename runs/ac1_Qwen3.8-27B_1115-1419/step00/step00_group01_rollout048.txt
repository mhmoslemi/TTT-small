```python
    n = len(v)
```

```python
    # Let j = n-1-m: = sum_i p[i] * a[i-j] ... hmm this is getting confusing.
    
    # Let me just use the direct approach for now and optimize later if needed.
    g = np.zeros(n)
    for j in range(n):
        # g[j] = 2 * sum_{k=j}^{min(j+n-1, 2n-2)} p[k] * a[k-j]
        lo = j
        hi = min(j + n - 1, 2*n - 2)
        if lo > hi:
            continue
        g[j] = 2.0 * np.dot(p[lo:hi+1], a[hi-lo+1])
    return g
```

Hmm, the direct approach in a loop is O(n^2) and not vectorized well. Let me think of a better way.

Actually, the cross-correlation can be computed as:
g[j]/2 = sum_{j'=0}^{n-1} p[j+j'] * a[j']

This is the "sliding window dot product" of p (shifted by j) with a. I can compute all of these at once using:
- Create a matrix M where M[j, j'] = p[j+j'] for valid indices
- Then g[j]/2 = M[j,:] @ a

But M is a Toeplitz matrix (each row is a shifted version of p), so I can use FFT.

Actually, the simplest FFT approach:
- Let P = p (length 2n-1), A = a (length n)
- We want g[j] = 2 * sum_{j'=0}^{n-1} P[j+j'] * A[j'] for j = 0, ..., n-1

This is the cross-correlation of P and A, evaluated at lags 0, 1, ..., n-1.

In numpy/scipy, this can be done with:
from scipy.signal import correlate
g_corr = correlate(P, A, mode='valid')  # gives sum_{j'} P[j+j'] * A[j'] for valid j

Wait, scipy.signal.correlate(in1, in2, mode='valid') computes:
c[k] = sum_n in1[n+k] * in2[n] for k = 0, ..., len(in1)-len(in2) (when len(in1) >= len(in2))

So correlate(P, A, mode='valid') gives:
c[j] = sum_n P[n+j] * A[n] for j = 0, ..., (2n-1)-n = n-1

That's exactly what I want! g[j] = 2 * c[j].

Let me use this:

```python
def compute_gradient_fast(p, a):
    from scipy.signal import correlate
    n = len(a)
    c = correlate(p, a, mode='valid')  # length n
    return 2.0 * c
```

This is O(n log n) using FFT internally. 

Now let me put it all together. I'll also handle the case where p has very small values (numerical underflow in the softmax).

def project_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n <= 1:
        return np.ones(n) / max(n, 1)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n+1) > (cssv - 1)
    idx = np.nonzero(cond)[0]
    if len(idx) == 0:
        return np.ones(n) / n
    rho = idx[-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)
