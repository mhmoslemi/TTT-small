The gradient of the smooth max has magnitude roughly proportional to 2*max(a) (since the gradient is a weighted sum of 2*a[k-j]). For a uniform sequence, max(a) = 1/n. So the gradient magnitude is about 2/n.

The multiplicative update: a[j] *= exp(-eta * grad[j]). For small eta*grad, this is approximately a[j] * (1 - eta*grad[j]). The change in a[j] is about a[j] * eta * grad[j] ≈ (1/n) * eta * (2/n) = 2*eta/n^2.

We want this to be a reasonable step. The convolution values are O(1/n). A 1% change in the max convolution corresponds to a change of 0.01/n in the objective. The gradient step changes the convolution by roughly grad * step ≈ (2/n) * (2*eta/n^2) = 4*eta/n^3 per component. With n components, total change is O(4*eta/n^2).

Actually, let me reconsider. The problem with the smooth max approach is that for large beta, it's close to the hard max, and the gradient is only nonzero (in a meaningful way) at the peak. The update would only modify elements that contribute to the peak.

For the uniform sequence, the peak is at the center (k=n-1), and all elements contribute equally. The gradient would be uniform (at the peak), and the multiplicative update would be uniform, not changing anything.

We need the gradient to have variation. This happens when the smooth max assigns slightly different weights to different entries near the peak. For the uniform sequence, the convolution is a triangle, so the entries near the peak are: ..., c[k-1]=1/n - 1/n^2, c[k]=1/n, c[k+1]=1/n - 1/n^2, ...

With beta large, w concentrates on the peak. The gradient at the peak is 2*sum(a) = 2 (times 1/n for uniform). This is uniform, so no useful direction.

The issue is that the smooth max with large beta doesn't capture the "shape" of the convolution well. We need a moderate beta so that entries slightly below the peak also contribute.

Let me try a different approach: instead of the smooth max, use the p-norm:
F(a) = (Sum_k c_k^p)^(1/p) for large p.
dF/da_j = (1/p) * (Sum c_k^p)^(1/p - 1) * p * Sum c_k^(p-1) * dc_k/da_j
= (Sum c_k^p)^(1/p - 1) * Sum c_k^(p-1) * 2*a[k-j]

For large p, this is dominated by the peak, similar to the smooth max.

I think the key issue is that for the uniform sequence, by symmetry, the gradient is "flat" and we can't make progress with a simple gradient step. We need to break the symmetry.

One approach: add a small random perturbation to break the symmetry, then use gradient descent.

Another approach: use a structured perturbation. For example, perturb with a sinusoid of a specific frequency.

Let me think about what perturbation would help. We want to reduce the center of the convolution. The center value is c[n-1] = sum a[i]*a[n-1-i]. To reduce this, we want a[i] and a[n-1-i] to be "anti-correlated" - where one is large, the other is small.

For the symmetric case (a[i] = a[n-1-i]), c[n-1] = sum a[i]^2, which is minimized (subject to sum a = 1) when a is uniform. So for symmetric sequences, we can't do better than 1/n.

For asymmetric sequences, c[n-1] = sum a[i]*a[n-1-i] can be less than 1/n. For example, if a[0]=0.5, a[n-1]=0.5, and the rest is 0, then c[n-1] = 0.25 (less than 1/n for large n). But then c[0] = 0.25 and c[2n-2] = 0.25, and the max is 0.25, giving J = 2n*0.25 = n/2. Very bad.

The insight: we need to reduce c[n-1] WITHOUT increasing the other entries too much. The other entries are "protected" by the triangle shape of the uniform convolution.

For the uniform sequence:
c[k] = min(k+1, n, 2n-1-k) / n^2

The ratio c[k]/c[n-1] at the edges is 1/n. So there's a lot of "slack" at the edges. We can increase the edge values by up to a factor of n before they become the new max.

Strategy: redistribute mass from the center to the edges of the sequence. This will:
- Decrease c[n-1] (since a[i]*a[n-1-i] gets smaller for center elements)
- Increase edge c[k] values (like c[0] = a[0]^2)

The trade-off: we can increase a[0] from 1/n to some value t, as long as c[0] = t^2 <= c[n-1]_new.
