For a sequence with flat power spectrum (like a Zadoff-Chu sequence or m-sequence), the autocorrelation is approximately flat (with a peak at zero lag). But those are typically complex or binary.

def fast_convolve(a, b, n=None):

    if n is None:
        n = len(a)
    m = len(b)
    n_fft = 1
    while n_fft < n + m - 1:
        n_fft <<= 1
    fa = np.fft.rfft(a, n_fft)
    fb = np.fft.rfft(b, n_fft)
    result = np.fft.irfft(fa * fb, n_fft)
    return result[:n + m - 1]

Actually, let me reconsider the problem. The key question is: what is the theoretical minimum of 2n * max(conv(a,a)) / S^2 over non-negative a?

Let me define: minimize max_j c_j where c_j = sum_i a[i]a[j-i], subject to sum(a) = 1, a >= 0.

The "dual" of this problem (in a informal sense) is: maximize sum(a) subject to c_j <= 1 for all j, a >= 0. (Scaling back.)

If the max achievable sum with c_j <= 1 is S_max, then the min of max(c_j) with sum(a)=1 is 1/S_max^2.

So score = 2n / S_max^2.

What is S_max? It's the maximum L1 norm of a non-negative sequence whose autocorrelation (in the convolution sense) is bounded by 1.

This is related to the "Beurling-Lax" problem or "Saffari" type problems in harmonic analysis.

For a sequence of length n with conv(a,a) <= 1 (element-wise) and a >= 0:
The sum of all c_j values is (sum a)^2 = S^2. Since there are 2n-1 values, each <= 1:
S^2 <= 2n-1, so S <= sqrt(2n-1).

Thus: score >= 2n / (2n-1) ≈ 1.
