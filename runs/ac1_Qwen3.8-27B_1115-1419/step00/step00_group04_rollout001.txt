By scale invariance, let's fix sum(a) = 1 and minimize max_k c[k].

This is a convex optimization problem! We want to minimize t subject to:
- a[i] >= 0 for all i
- sum a[i] = 1
- c[k] <= t for all k = 0, 2n-2

where c[k] = sum_{valid i} a[i]*a[k-i].

The constraints c[k] <= t are quadratic (bilinear) in a. So this is NOT a convex problem (the feasible set is not convex).

However, we can reformulate: fix t and ask if there exists a with sum=1, a>=0, and c[k] <= t for all k. This is still non-convex.
