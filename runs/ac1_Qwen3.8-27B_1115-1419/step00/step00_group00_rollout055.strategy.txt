# Harmony Search Algorithm for Step Function Sequence Optimization

## Approach and rationale
The Harmony Search (HS) algorithm is employed to find an optimal sequence for minimizing the objective function. This approach is chosen because it mimics musical improvisation and population-based optimization, allowing for flexible exploration of the solution space without strict coordination between elements. The HS algorithm can escape local optima by maintaining a diverse population and uses stochastic methods that account for the constraints in our problem. Its population-based nature and ability to handle high-dimensional spaces make it suitable for sequences up to 100,000 elements, though we'll limit to 256 based on our working memory and previous results.

This approach shows several advantages:
1. It avoids local minima by maintaining a population of candidate sequences
2. It offers more natural handling of constraints compared to previous coordinate-based methods
3. It incorporates physics-inspired metaphors, aligning with the assessment task's theme
4. It can potentially find better sequences by allowing arbitrary combinations, unlike previous methods that often used structured updates

The main limitation is the algorithm's quality of lower bound estimation, but this is acceptable given the problem's requirements.

## Mathematical specification
The sequences are represented as arrays `a` of length `n` with `a_i >= 0` and `a_i <= 1000` for each `i`, where `n` is fixed at 256.

The objective is defined as:
$$O(a) = \frac{2 \cdot n \cdot \max_{k=0}^{2n-2} (\mathcal{C}_k)}{(\sum_{i=0}^{n-1} a_i)^2}$$
Where $\mathcal{C}_k$ is the k-th term of the full linear self-convolution.

The optimization process uses:

1. **Memory Set (HMS)**: Store top performing sequences of length `n`
2. **Harmony Memory Consideration (HMC)**: Probability of using a value from current sequence
3. **Harmony Memory Constriction (HMC)**: 
   - Control the diversity of the search space
   - Ensure sequences maintain convexity properties
   - Manage the trade-off between exploration and exploitation

## Implementation procedure
We'll use the following specifications:

1. Initialize with the最好的 sequence found by previous methods, but allow fallback if necessary.
2. Maintain a memory set of top performing sequences, initially size 50 but adjustable
3. In each iteration, create new sequences by:
   - Selecting a random memory vector if HMC > threshold
   - Otherwise, generating a new random sequence
4. Adjust selected values stochastically to maintain diversity
5. Evaluate each sequence candidate using the evaluator
6. Update the memory set if new sequence improves the best score
7. Continue for up to 2400 seconds

The computational score is calculated as `score = 2 * n * max(convolve(a)) / (sum(a)) ** 2`.
