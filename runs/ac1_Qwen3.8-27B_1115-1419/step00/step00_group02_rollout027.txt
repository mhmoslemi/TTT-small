The key gradient step:
- Find k* = argmax(conv)
- For each j, dM/da[j] = 2*a[k*-j] if 0 ≤ k*-j ≤ n-1, else 0
  (If multiple indices achieve the max, sum over them)
- d(score)/da[j] = (2n/S^3) * (S * dM/da[j] - 2*M)
  = (4n/(S^3)) * (S/2 * dM/da[j] - M)
  Let me recompute: score = 2nM/S^2
  d(score)/da[j] = 2n * (dM/da[j] * S^2 - M * 2S) / S^4
                 = 2n * (S * dM/da[j] - 2M) / S^3

To minimize score, we want to decrease a[j] when d(score)/da[j] > 0 and increase when < 0.
Let's define the "descent direction" as d = -d(score)/da[j], then we update a += lr * d.

d[j] = -(2n/S^3) * (S * dM/da[j] - 2M)
     = (2n/S^3) * (2M - S * dM/da[j])

So d[j] = (2n/S^3) * (2M - S * 2*a[k*-j]) (when valid)
         = (4n/S^3) * (M - S*a[k*-j]) (when k*-j is valid)

For j where k*-j is not valid: dM/da[j] = 0, so d[j] = (2n/S^3) * 2M > 0.
This means we always want to increase a[j] for indices j that don't contribute to the maximum. This makes sense - their increase doesn't affect the peak but increases S, which helps.

For j where k*-j is valid: d[j] = (4n/S^3) * (M - S*a[k*-j])
- If a[k*-j] > M/S, we want to decrease a[j] (d[j] < 0)
- If a[k*-j] < M/S, we want to increase a[j] (d[j] > 0)

def compute_grad_at_max(a, k):
    """Compute d(conv[k])/da[j] for all j. = 2*a[k-j] if 0<=k-j<n, else 0."""
    n = len(a)
    grad = np.zeros(n)
    # k-j in [0, n-1] means j in [k-(n-1), k]
    j_start = max(0, k - n + 1)
    j_end = min(n - 1, k)

        # For j in [j_start, j_end], k-j is in [k-j_end, k-j_start] = [max(0,k-n+1)... ]
