```python
def build_conv_matrix(n, f):
    """Build the (2n-1) x n convolution matrix A where (A @ g)[k] = (f*g)[k]."""
    A = np.zeros((2*n - 1, n))

        j_min = max(0, k - n + 1)
        j_max = min(k, n - 1)
```

```python
    # But we need to clip to [0, 2n-2]
    
    # Rows: for column j, valid rows are j to j+n-1, but clipped to 0..2n-2
    # which is always valid since j >= 0 and j+n-1 <= 2n-2 (since j <= n-1)
    # So column j has entries at rows j, j+1, ..., j+n-1 with values f[0], f[1], ..., f[n-1]
    # Total non-zeros: n * n (every column has n entries)
    
    # Actually wait: column j has entries at rows j, j+1, ..., j+n-1
    # j ranges from 0 to n-1
    # j+n-1 ranges from n-1 to 2n-2
    # All rows are in [0, 2n-2]. ✓
    
    cols = np.repeat(np.arange(n), n)
    rows = np.concatenate([np.arange(j, j+n) for j in range(n)])
    vals = np.tile(f, n)
    
    A = csr_matrix((vals, (rows, cols)), shape=(2*n-1, n))
    return A
```

This is O(n^2) in memory and time, but vectorized. For n=2000, that's 4M entries. Should be fine.

Actually, for the Barankin method, the standard approach is to just interpolate with a fixed t (like 0.1-0.5) and let it converge. The LP step already ensures that the new g doesn't increase the peak, so the interpolation should monotonically decrease the peak.

Wait, does it? Let me verify:
- f has max(f*f) = M
- g satisfies f*g <= M (element-wise)
- f_new = (1-t)*f + t*g
- What is max(f_new * f_new)?

f_new * f_new = (1-t)^2 (f*f) + t^2 (g*g) + 2t(1-t) (f*g)

We know f*f <= M and f*g <= M, but we don't know about g*g. So the peak of f_new*f_new could exceed M.

Hmm, so the Barankin iteration doesn't guarantee monotonic decrease of the peak. But it should converge to a fixed point where f = g (satisfying f*f <= M and sum(f) = S).

At the fixed point: f*f <= M and the LP says that f maximizes sum(f') subject to f*f' <= M, f' >= 0. Since f itself is feasible, the LP with f as the variable would give sum(f) as the maximum, meaning any other feasible g' has sum(g') <= sum(f).

This is a KKT-type condition that characterizes the optimum.

    """Build (2n-1) x n convolution matrix A where (A @ g)[k] = sum_j A[k,j]*g[j] = (f*g)[k]."""
    cols = np.repeat(np.arange(n), n)
