                # Update with relaxation

                a = (1 - t) * a + t * x

Also, for numerical stability, I'll work in log-space: let $a_i = e^{x_i}$, and optimize over $x$.

$\frac{\partial f}{\partial x_i} = \frac{\partial f}{\partial a_i} \cdot a_i$

$= \frac{2n}{s^2} g_i a_i - \frac{4n \cdot \text{LSE}}{s^3} a_i^2$

This is simpler! Let me use this.

For the update in $x$-space: $x_i \leftarrow x_i - \eta \frac{\partial f}{\partial x_i}$

This naturally maintains $a_i > 0$ (since $a_i = e^{x_i}$).

Let me also use Adam for the $x$-space optimization.

Now, one concern: the gradient computation involves FFT of length $p$ (which has length $2n-1$) and $q$ (which has length $n$). The convolution $p * q$ has length $3n-2$. I need FFT size at least $3n-1$. For $n = 6962$, that's about $20885$, which is fine.

Let me code this up properly:

```python
import numpy as np
import time

def autocorr(a):
    """Compute full autocorrelation of a."""
    n = len(a)
    size = 2 * (2*n - 1)
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:2*n-1]

def smooth_obj_grad(a, eps):
    """Compute objective value and gradient in x-space (a = exp(x))."""
    n = len(a)
    s = a.sum()
    c = autocorr(a)
    max_c = c.max()
    e = np.exp(eps * (c - max_c))
    p = e / e.sum()
    lse_val = max_c + np.log(e.sum()) / eps
    obj = 2.0 * n * lse_val / (s * s)
    
    # Gradient in x-space: df/dx_i = a_i * (2n/s^2 * g_i - 4n*lse/s^3 * a_i)
    # where g_i = (p * a[::-1])[i+n-1]
    q = a[::-1]
    conv_size = len(p) + len(q) - 1
    fft_size = 1
    while fft_size < conv_size:
        fft_size *= 2
    temp = np.fft.irfft(np.fft.rfft(p, fft_size) * np.fft.rfft(q, fft_size), fft_size)
    g = temp[n-1:n-1+n]
    
    df_dx = a * (2.0*n/(s*s) * g - 4.0*n*lse_val/(s**3) * a)
    
    return obj, df_dx, c, max_c
```
