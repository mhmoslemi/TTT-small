The full problem: minimize `max_k (a*a)[k]` subject to `a >= 0`, `sum(a) = 1`.

Or using the **smooth max approximation**: replace `max_k (a*a)[k]` with `(1/τ) * log(sum_k exp(τ * (a*a)[k]))` (the log-sum-exp, which is a smooth upper bound on the max). Then use gradient descent on this smooth function.

The gradient of the log-sum-exp:
`d/d a[i] log(sum_k exp(τ * (a*a)[k])) = (1/sum_k exp(τ*(a*a)[k])) * sum_k τ * exp(τ*(a*a)[k]) * d(a*a)[k]/d(a[i])`
`= sum_k softmax(τ * (a*a))[k] * τ * 2 * a[k-i]`

This is a weighted average of the gradients, weighted by the softmax of the convolution values. For large `τ`, this concentrates on the active set (recovering the subgradient). For small `τ`, it's more "smooth" and might help escape local minima.

This is a nice approach! Let me implement it:

```python
def smooth_max_gradient(a, tau):
    """Compute gradient of log-sum-exp of convolution values."""
    n = len(a)
    c = np.convolve(a, a)  # length 2n-1
    # Softmax weights
    c_shifted = c - c.max()  # for numerical stability
    weights = np.exp(tau * c_shifted)
    weights /= weights.sum()
    # Gradient: sum_k weights[k] * 2 * a[k-i]
    h = weights  # this is the "effective" active set (soft)
    a_ext = np.concatenate([a, np.zeros(n-1)])
    g = 2.0 * np.convolve(h, a_ext[::-1], mode='full')
    offset = 2*(n-1)
    return g[offset:offset+n], c.max()
```

```python
def compute_smooth_grad_fft(a, tau):
    n = len(a)
    c = np.convolve(a, a)  # O(n^2) or use FFT
    c_max = c.max()
    weights = np.exp(tau * (c - c_max))
    weights /= weights.sum()
    
    # g[i] = 2 * sum_k weights[k] * a[k-i]
    # Use FFT: g/2 = cross-correlation of weights and a
    L = 1
    while L < len(weights) + n - 1:
        L *= 2
    W = np.fft.rfft(weights, L)
    A = np.fft.rfft(a, L)
    # cross-correlation: IFFT(conj(W) * A) or IFFT(W * conj(A)) depending on convention
    # We want: sum_k weights[k] * a[k-i]
    # = cross_corr[weights, a][i]
    # Using FFT: IFFT(conj(FFT(weights)) * FFT(a))[i] ... need to verify
    # Let me use the convolution formula:
    # sum_k weights[k] * a[k-i] = (weights * a_flipped)[(n-1) + something]
    # Actually, let me just use the formula I derived earlier:
    # g/2[i] = (weights * a_ext_flipped)[offset + i]
    # where a_ext = [a, 0, ..., 0] (length 2n-1)
    # a_ext_flipped = [0, ..., 0, a[n-1], ..., a[0]] (length 2n-1)
    # offset = 2*(n-1)
    
    # Using FFT for the convolution:
    a_ext = np.zeros(2*n - 1)
    a_ext[:n] = a
    a_ext_flipped = a_ext[::-1]
    
    W_full = np.fft.rfft(weights, L)  # weights has length 2n-1
    A_flipped = np.fft.rfft(a_ext_flipped, L)
    g_half = np.fft.irfft(W_full * A_flipped, L)
    
    offset = 2*(n-1)
    g = 2.0 * g_half[offset:offset+n]
    return g, c_max
```
