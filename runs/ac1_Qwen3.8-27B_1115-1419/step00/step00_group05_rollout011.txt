    """Compute a * a (linear convolution) using FFT."""

    fa = fft(a, n=size)
    c = ifft(fa * fa, n=size).real

    if s < 0.01:

3. c[k_max] = sum_i a[i]*a[k_max-i]. To reduce this, we want to reduce the products a[i]*a[k_max-i].
4. For the pair (i, k_max-i) with the largest product, reduce a[i] (or a[k_max-i]) and redistribute the mass to positions that don't contribute to k_max.
5. Repeat.

Alternative: Use the Fourier transform. c = a * a has Fourier transform C = A² (in the frequency domain, with appropriate zero-padding for linear convolution).

If A(ω) = |A(ω)|e^{iθ(ω)}, then C(ω) = |A(ω)|² e^{2iθ(ω)}.

c[k] = (1/N) Σ_ω C(ω) e^{2πikω/N}

To minimize max_k c[k], we want C(ω) to be as "flat" as possible in the time domain, which means A(ω)² should be flat. But A(ω)² = |A(ω)|² e^{2iθ(ω)}, and the flatness in time domain is about |C(ω)| = |A(ω)|².

So we want |A(ω)|² to be flat, i.e., |A(ω)| constant. This means a should have a flat power spectrum, which is the definition of a "Maximum Entropy" or "Maximum Flatness" signal.
