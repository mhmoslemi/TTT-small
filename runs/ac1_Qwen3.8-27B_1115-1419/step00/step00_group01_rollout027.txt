Let me think about what approach is most likely to work:

The key insight is that the problem is equivalent to finding a non-negative sequence that minimizes the peak of its self-convolution relative to its sum. This is a non-convex optimization problem.

One promising approach: use the fact that the convolution can be computed via FFT. Then we can:
1. Represent the sequence in the frequency domain.
2. The peak of the convolution is related to the time-domain representation.
3. Use projected gradient descent: minimize the peak projection of the convolution, subject to non-negativity.

But the peak function is not differentiable. We can use a smooth approximation (e.g., log-sum-exp) to make it differentiable.

Here's my plan:
1. Start with the given sequence or a uniform sequence.
2. Use log-sum-exp as a smooth approximation to the max.
3. Perform gradient descent with projection onto the non-negative orthant.
4. Normalize to keep the sum constant (since the objective is scale-invariant).

The smooth objective: f(a) = 2*n*logsumexp(conv(a,a)/T) / (sum(a))^2 for some temperature T.
As T → 0, this approaches 2*n*max(conv(a,a))/(sum(a))^2.

The gradient of logsumexp(conv/T) with respect to a[i] can be computed using the chain rule and FFT.

Let me think about the gradient:
conv = a * a (convolution)
L = log(sum exp(conv[k]/T))
dL/da[i] = sum_k (exp(conv[k]/T) / sum_j exp(conv[j]/T)) * d(conv[k])/da[i]
= sum_k softmax(conv[k]/T) * (a[k-i] if 0 ≤ k-i ≤ n-1)
= (softmax(conv/T) * a)[i] (convolution with the softmax weights)

And d(1/S^2)/da[i] = -2/(S^3) where S = sum(a).

So the gradient of the full objective is:
∇f = 2n * (L' / S^2 - 2*L / S^3)
where L' = (softmax(conv/T) * a)[i] (the convolution of softmax weights with a)

This gives a feasible gradient-based approach.

However, for large n (e.g., n = 6121), each gradient computation requires an FFT of size ~12000, which is fast. The main question is how many iterations we can do in 2400 seconds.

Let me estimate: each iteration requires:
- Computing conv via FFT: O(M log M) where M = 2n
- Computing the softmax: O(M)
- Computing the gradient via another FFT: O(M log M)
- Update and projection: O(n)

For n = 6121, M ≈ 12242. FFT of size 16384 (next power of 2) takes about 16384 * 14 ≈ 230K operations. So each iteration is maybe 1000-2000 operations * a few FFTs = a few million operations. In Python with numpy, this should take a few milliseconds. So we can do maybe 10,000-100,000 iterations in 2400 seconds.
