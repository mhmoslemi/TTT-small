where (A_cur @ a)[k] = sum_{j in S_k} a_cur[k-j] * a[j].

So the LP at each step is:
min t
s.t. 2 * (A_cur @ a)[k] <= t + conv_cur[k] for all k
     a >= 0
     sum(a) = 1

This is a linear program! The matrix A_cur depends on the current iterate, so this is a "successive linear programming" (SLP) method.

The constraint 2*(A_cur @ a)[k] - t <= conv_cur[k] can be written as:
[2*A_cur[k,:] | -1] @ [a; t] <= conv_cur[k]

Plus the equality constraint sum(a) = 1 and a >= 0, t free (or t >= 0).

This is a standard LP. Let me implement this.

Actually, I realize this SLP approach is essentially the same as the "state of the art" approach, just formulated differently. The LP in the state of the art is:
max sum(g) s.t. (f*g)[k] <= M, g >= 0

where M = max(f*f). This is equivalent to the SLP I described (with a slight difference in formulation).

    conv_cur = np.convolve(a_cur, a_cur)
    S = a_cur.sum()
    
    # Build A_cur matrix (same as before)
    A = build_conv_matrix(a_cur, n)
    
    # LP: min t
    # s.t. 2*(A @ a)[k] - t <= conv_cur[k] for all k
    #      sum(a) = 1
    #      a >= 0
    #      t >= 0
    #
    # Variables: a[0]...a[n-1], t (total n+1 variables)
    # Constraints: (2n-1) inequalities + 1 equality
    #
    # Inequality: 2*A @ a - t <= conv_cur
    # Matrix: [2*A | -ones(2n-1,1)] @ [a;t] <= conv_cur
    
    m = 2 * n - 1
    # Build the combined matrix
    # A is (m, n) sparse
    # We need [2*A | -1] which is (m, n+1) sparse
    
    # For linprog, we need:
    # c = [0, 0, ..., 0, 1] (minimize t)
    # A_ub = [2*A | -ones(m,1)]
    # b_ub = conv_cur
    # A_eq = [ones(1,n) | 0]
    # b_eq = [1]
    # bounds: a[i] >= 0, t >= 0
    
    # Build sparse matrix for A_ub
    # [2*A | -1] has shape (m, n+1)
    # The last column is all -1
    
    A_2 = 2 * A  # (m, n) sparse
    # Add a column of -1's
    from scipy.sparse import eye as sp_eye
    neg_one_col = csr_matrix(-np.ones((m, 1)))
    A_ub_sparse = csr_matrix.hstack([A_2, neg_one_col])
    
    c = np.zeros(n + 1)
    c[-1] = 1.0  # minimize t
    
    A_eq = np.zeros((1, n+1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([1.0])
    
    bounds = [(0, None)] * (n+1)
    
    result = linprog(c, A_ub=A_ub_sparse, b_ub=conv_cur,
                    A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')
    
    if not result.success:
        return None
    
    a_new = result.x[:n]
    t_new = result.x[n]
    return a_new, t_new

def build_conv_matrix(a, n):
    """Build sparse convolution matrix A where (A@x)[k] = sum_j a[k-j]*x[j]."""
    m = 2 * n - 1
    rows = np.empty(n * n, dtype=np.int32)
    cols = np.empty(n * n, dtype=np.int32)
    vals = np.empty(n * n, dtype=np.float64)
    idx = 0
    for j in range(n):
        k_start = j
        k_end = min(j + n, m)
        count = k_end - k_start
        if count > 0:
            d = np.arange(count, dtype=np.int32)
            rows[idx:idx+count] = k_start + d
            cols[idx:idx+count] = j
            vals[idx:idx+count] = a[:count]
            idx += count
    if idx < n*n:
        rows, cols, vals = rows[:idx], cols[:idx], vals[:idx]
    return csr_matrix((vals, (rows, cols)), shape=(m, n))
