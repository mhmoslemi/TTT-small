For the autocorrelation `conv(a, flip(a))`, the DFT is `A(ω) * A(-ω) = |A(ω)|^2` (for real a).

Since our problem uses `conv(a, a)` (not autocorrelation), the frequency domain picture is different.

If a is symmetric (palindromic), then `A(ω)` is real (actually, it's `sum a_i (cos(ωi) + i*sin(ωi))` but for symmetric a, the imaginary part cancels... hmm, not exactly).

For a palindromic sequence `a_i = a_{n-1-i}`, the DFT is:
`A(ω) = sum_i a_i e^{-iωi} = sum_i a_i cos(ωi) - i * sum_i a_i sin(ωi)`

For palindromic a, `sum_i a_i sin(ωi) = 0` (by antisymmetry of sin around the center). So `A(ω) = sum_i a_i cos(ωi)`, which is real.

Then `A(ω)^2` is real and non-negative (since A is real, A^2 >= 0).

The convolution `c = conv(a, a)` has DFT `A(ω)^2`. We want `c` to be as flat as possible, which means `A(ω)^2` should be as flat as possible, i.e., `|A(ω)|` should be as flat as possible.

For a palindromic sequence, this is the same as the "flat spectrum" design problem, which is well-studied in signal processing. The goal is to design a filter with a flat amplitude response.

But we also have the constraint `a >= 0`, which is a significant restriction.

OK, I think the most practical approach is:

1. **Start with a palindromic sequence** (to simplify the problem)
2. **Use gradient-based optimization** on the smoothed max (soft-max)
3. **Use simulated annealing** to escape local minima
4. **Periodically try different structures** (periodic, random, etc.)

import time

def propose_candidate(seed=42, budget_s=2400, **kwargs):
    """
    Multi-phase optimization for minimizing 2*n*max(conv(a,a))/(sum(a))^2.
    Phase 1: Random structured initialization
    Phase 2: Gradient-based descent with soft-max smoothing
    Phase 3: Simulated annealing local search
    Phase 4: Final refinement
    """
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + float(budget_s) - 5.0
    
    # --- Initialization ---
    if 'height_sequence_1' in globals() and height_sequence_1 is not None:
        base = np.array(height_sequence_1, dtype=np.float64)
    else:
        base = np.ones(2000)
    base = np.clip(base, 0, 1000)
    n = len(base)
    s = base.sum()
    if s < 1e-6:
        base = np.ones(n)
        s = n
    a = base / s
    
    best = a.copy()
    best_score = evaluate_sequence(best.tolist())
    print(f"Init: n={n}, score={best_score:.6f}")
    
    # --- Phase 2: Gradient-based optimization ---
    # Use soft-max to smooth the max
    params = {
        'T_soft': 5.0,      # Softmax temperature
        'lr': 0.001,        # Learning rate
        'momentum': 0.9,    # Momentum
        'sa_T': 0.01,       # SA temperature
        'sa_decay': 0.99995,
        'perturb_scale': 0.05
    }
    
    v = np.zeros(n)  # Momentum
    iters = 0
    stall = 0
    
    while time.monotonic() < deadline:
        a = best.copy()
        r = rng.random()
        
        if r < 0.6:
            # Gradient step with soft-max
            c = np.convolve(a, a)
            c_max = c.max()
            # Soft-max weights
            w = np.exp((c - c_max) / params['T_soft'])
            w /= w.sum()
            
            # Gradient of weighted sum of c_k
            # g_m = sum_k w_k * dc_k/da[m]
            # dc_k/da[m] = 2*a[k-m] (valid, k!=2m) or a[k-m] (k==2m)
            # Efficient: g = 2 * conv(w, a) (approximately)
            # More precisely: g[m] = sum_k w_k * 2 * a[k-m]
            # This is 2 * (w flipped) * a convolved... 
            # Actually, let me just compute it directly for the top few k
            
            # For efficiency, use the fact that g[m] = 2 * sum_k w_k * a[k-m]
            # = 2 * (w * a)[m] (if we define the convolution appropriately)
            # Let's use: g = 2 * np.convolve(w, a, mode='same') approximately
            # But w has length 2n-1, so this needs care.
            
            # Direct computation for top-k peaks
            top_k_idx = np.argsort(c)[-min(50, len(c)):]
            top_w = w[top_k_idx]
            top_w /= top_w.sum()
            
            g = np.zeros(n)
            for k_i in top_k_idx:
                wi = top_w[np.argmax(top_k_idx == k_i)]
                i_lo = max(0, k_i - n + 1)
                i_hi = min(n - 1, k_i)
                for m in range(i_lo, i_hi + 1):
                    j = k_i - m
                    g[m] += wi * a[j]
                    if j != m:
                        g[j] += wi * a[m]
            
            # Project out mean
            g -= g.mean()
            
            # Momentum step
            v = params['momentum'] * v + params['lr'] * g
            a -= v
            a = np.clip(a, 0, 1000)
            sa = a.sum()
            if sa < 1e-6:
                continue
            a /= sa
            
        elif r < 0.75:
            # Block perturbation
            w_size = int(rng.integers(3, max(5, n // 100)))
            s0 = int(rng.integers(0, n - w_size))
            a[s0:s0+w_size] += rng.normal(0, params['perturb_scale'], w_size)
            a = np.clip(a, 0, 1000)
            a /= a.sum()
            
        elif r < 0.85:
            # Multiplicative perturbation
            w_size = int(rng.integers(5, max(10, n // 50)))
            s0 = int(rng.integers(0, n - w_size))
            a[s0:s0+w_size] *= np.exp(rng.normal(0, 0.1, w_size))
            a = np.clip(a, 0, 1000)
            a /= a.sum()
            
        elif r < 0.92:
            # Swap-based perturbation
            n_swaps = int(rng.integers(5, 20))
            for _ in range(n_swaps):
                i, j = rng.integers(0, n, 2)
                if i != j:
                    d = 0.02 * (a[i] - a[j]) * rng.random()
                    a[i] -= d
                    a[j] += d
            a = np.clip(a, 0, 1000)
            a /= a.sum()
            
        else:
            # Large restart: keep 50% and re-randomize 50%
            mask = rng.random(n) < 0.5
            old_s = a[~mask].sum()
            new_s = a[mask].sum()
            a[mask] = rng.dirichlet(np.ones(mask.sum())) * (old_s + new_s) * 0.5
            a[~mask] *= (old_s + new_s) * 0.5 / max(old_s, 1e-10)
            a = np.clip(a, 0, 1000)
            a /= a.sum()
        
        score = evaluate_sequence(a.tolist())
        iters += 1
        
        if np.isfinite(score):
            if score < best_score:
                best = a.copy()
                best_score = score
                stall = 0
                v *= 0.5  # Reset momentum on improvement
            else:
                stall += 1
                # SA acceptance
                diff = score - best_score
                if diff < params['sa_T']:
                    if rng.random() < np.exp(-diff / params['sa_T']):
                        best = a.copy()
            
            params['sa_T'] = max(1e-6, params['sa_T'] * params['sa_decay'])
            
            # Adaptive learning rate
            if stall > 5000:
                params['lr'] *= 1.05
                params['perturb_scale'] *= 1.05
            elif stall < 100:
                params['lr'] = max(1e-6, params['lr'] * 0.98)
            
            if iters % 5000 == 0:
                print(f"it={iters} best={best_score:.6f} lr={params['lr']:.6f} "
                      f"T_sa={params['sa_T']:.6f} stall={stall} "
                      f"time={time.monotonic() - (deadline - float(budget_s) + 5):.0f}s")
    
    print(f"Final: {best_score:.6f} after {iters} iters")
    return best.tolist()

For real values, this is `result[k] = sum_n w[n+k] * a[n]`.

With `mode='valid'`, k ranges so that the product is fully within both arrays. For `w` of length `L1=2n-1` and `a` of length `L2=n`:

`= sum_k w[k] * 2 * a[k-m]` (for valid k, m where 0 <= k-m < n)
`= 2 * sum_k w[k] * a[k-m]`

`= 2 * sum_j w[j+m] * a[j]` (for valid j, m)

Actually, let me try a different approach entirely. Instead of gradient descent, let me use the LP-based approach from the paper. The idea is:

1. Given current `a`, compute `M = max(conv(a, a))`
2. Solve: max `sum(b)` subject to `conv(a, b) <= M` (element-wise) and `b >= 0`
3. This gives a direction `b` that, when mixed with `a`, should reduce the peak
4. Update: `a_new = (1-t)*a + t*b` for small `t`

The LP in step 2 has `n` variables and `2n-1` inequality constraints. For n=3809, this is a 3809-variable LP with ~7617 constraints. Using CVXPY with a fast solver, this should take a few seconds.

But wait, the LP is:
max `sum_j b_j`
s.t. `conv(a, b)[k] <= M` for all k (2n-1 constraints)
     `b_j >= 0` for all j (n constraints)

The conv constraint `conv(a, b)[k] <= M` is linear in b! Because `conv(a, b)[k] = sum_i a[i] * b[k-i]` is linear in b.

So this is a standard LP. With CVXPY and a solver like CLARABEL or SCIP, it should be solvable in a few seconds for n=3809.

But can I afford to solve this LP every iteration? If each LP takes ~2 seconds, I can do ~1200 LP iterations in 2400 seconds. That should be enough.

        b = cp.Variable(n, nonneg=True)

The smooth surrogate: `f_T(a) = 2n * (1/T) * log(sum_k exp(T * c_k))` where `c = conv(a, a)`

This is smooth and differentiable. The gradient is:
`∇f_T = 2n * sum_k (exp(T*c_k) / sum_l exp(T*c_l)) * ∇c_k`
      = 2n * sum_k softmax(T*c)_k * ∇c_k

And `∇c_k = 2 * correlate(delta_k, a)` where `delta_k` is a delta at position k.

More efficiently: `∇f_T = 2n * correlate(softmax(T*c), a)` (approximately, with the factor of 2 and boundary corrections).
