   For a[i] = 1 + A*cos(2π*F*i/n) where F is an integer:
   
   The aperiodic autocorrelation is:
   R[k] = sum_i a[i]*a[i+k] (for |k| < n)
   
   = sum_i (1 + A*cos(2πF*i/n)) * (1 + A*cos(2πF*(i+k)/n))
   = sum_i [1 + A*(cos(2πF*i/n) + cos(2πF*(i+k)/n)) + A²*cos(2πF*i/n)*cos(2πF*(i+k)/n)]
   = (n-|k|) + A*sum_i [cos(2πF*i/n) + cos(2πF*(i+k)/n)] + A²*sum_i cos(2πF*i/n)*cos(2πF*(i+k)/n)

   For F to be an integer and n to be such that F and n are coprime (or F divides n appropriately), the sums of cosines will be approximately 0 for the linear term (they're like sampling a sinusoid over complete periods).

   The quadratic term: cos(2πF*i/n)*cos(2πF*(i+k)/n) = (1/2)[cos(4πF*i/n - 2πF*k/n) + cos(2πF*k/n)]
   
   Sum over i: (1/2)[sum_i cos(4πF*i/n - 2πF*k/n) + (n-|k|)*cos(2πF*k/n)]
   ≈ (1/2)[0 + (n-|k|)*cos(2πF*k/n)] (if 4F is not a multiple of n)

   So R[k] ≈ (n-|k|) + A²/2 * (n-|k|) * cos(2πF*k/n)
   = (n-|k|) * (1 + A²/2 * cos(2πF*k/n))

   At k=0 (the peak): R[0] = n * (1 + A²/2)
   At k=n/2 (if n is even): R[n/2] = (n/2) * (1 + A²/2 * cos(πF))
   
   If F is odd: cos(πF) = -1, so R[n/2] = (n/2) * (1 - A²/2)
   If F is even: cos(πF) = 1, so R[n/2] = (n/2) * (1 + A²/2)

   For F odd, the value at k=n/2 is (n/2)*(1-A²/2), which can be negative if A > sqrt(2)! But we need non-negative sequence values.

   The constraint for non-negativity: a[i] = 1 + A*cos(2πF*i/n) >= 0 for all i.
   The minimum of cos is -1, so we need 1 - A >= 0, i.e., A <= 1.

   With A = 1: a[i] = 1 + cos(2πF*i/n) = 2*cos(πF*i/n)². This is always non-negative.

   R[k] ≈ (n-|k|) * (1 + cos(2πF*k/n)) = 2*(n-|k|)*cos(πF*k/n)²

   At k=0: R[0] = 2n
   At k where cos(πF*k/n) = 0 (i.e., F*k/n = (2m+1)/2, k = (2m+1)*n/(2F)): R[k] = 0!

   So the autocorrelation has deep nulls! This is very promising.

   But wait, this is the aperiodic autocorrelation R[k] = sum_{i=max(0,-k)}^{min(n-1, n-1-k)} a[i]*a[i+k]. The full convolution conv(a,a) is related to this: conv(a,a)[j] = R[j-n+1] (with appropriate indexing).

   Actually, the full linear convolution of a with a (length 2n-1) is:
   conv(a,a)[k] = sum_{i=max(0,k-n+1)}^{min(k,n-1)} a[i]*a[k-i]

   This is different from the autocorrelation R[k] = sum_i a[i]*a[i+k]. They're related but not the same.
