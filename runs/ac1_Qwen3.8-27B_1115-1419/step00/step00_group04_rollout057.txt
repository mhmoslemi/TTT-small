This is the "cross-correlation at zero lag" of a with its reverse. For a decreasing sequence, a[i] > a[n-1-i] for i < n/2, so the products a[i]*a[n-1-i] are "balanced" (large times small).

The key is: for a decreasing sequence, the convolution at the edges (k=0: a[0]^2, k=2n-2: a[n-1]^2) can be controlled by choosing the ratio a[0]/a[n-1].

If a[0] is too large, b[0] = a[0]^2 dominates. If a[n-1] is too small, the "tail" of the convolution is small but the "head" is large.

Optimal balance: we want b[0] ≈ b[n-1] ≈ ... ≈ b[2n-2] (all equal) for the flattest convolution.

**Key Insight for Perturbations:**
The gradient of the objective w.r.t. a[i] (at the current max position k*) is:
- d(max_b)/da[i] ≈ a[k*-i] (the "partner" value)
- d(score)/da[i] ≈ 2n/(sum^2) * a[k*-i] - 4n*max_b/(sum^3)

So we should DECREASE a[i] where a[k*-i] is large (i.e., where a[i] contributes most to the peak) and INCREASE a[i] where it contributes less.

But we also need to keep sum(a) roughly constant (score is scale-invariant, but the evaluator uses the actual sum).

Actually, the score IS scale-invariant:
score(a) = 2n * max(conv(c*a, c*a)) / (sum(c*a))^2 = 2n * c^2 * max(conv(a,a)) / c^2 * (sum a)^2 = score(a)

So we can normalize after each step.

    import numpy as np
    import time
    
    deadline = time.time() + budget_s - 5
    
    # Get initial sequences
    candidates = []
    
    # Try height_sequence_1 if available
    if 'height_sequence_1' in globals() and height_sequence_1 is not None:
        h = np.array(height_sequence_1, dtype=np.float64)
        candidates.append(np.clip(h, 0, 1000))
    
    # Generate various initial shapes
    n = 3809  # Match the length
    if candidates:
        n = len(candidates[0])
    
    # Geometric sequences
    for r in [0.999, 0.998, 0.995, 0.99, 0.98, 0.95]:
        a = r ** np.arange(n)
        candidates.append(a)
    
    # Power law
    for p in [0.5, 1.0, 2.0, 3.0]:
        a = 1.0 / (1.0 + np.arange(n) / (n * 0.1)) ** p
        candidates.append(a)
    
    # Linear decreasing
    a = np.linspace(2.0, 0.1, n)
    candidates.append(a)
    
    # Sinusoidal modulation
    for freq in [1, 2, 3]:
        a = 1.0 + 0.5 * np.cos(2 * np.pi * freq * np.arange(n) / n)
        a = np.clip(a, 0, None)
        candidates.append(a)
    
    # Evaluate all and pick best
    best = None
    best_score = np.inf
    for c in candidates:
        s = evaluate_sequence(c.tolist())
        if s < best_score:
            best_score = s
            best = c.copy()
    
    print(f"Best initial: {best_score}")
    
    # Local search
    rng = np.random.default_rng(seed)
    
    while time.time() < deadline:
        # Compute convolution
        b = np.convolve(best, best)
        k_star = np.argmax(b)
        max_b = b[k_star]
        sum_a = np.sum(best)
        
        # Gradient direction (subgradient of max)
        # d b[k_star] / d a[i] = a[k_star - i] (for valid i)
        grad = np.zeros(n)
        for i in range(n):
            j = k_star - i
            if 0 <= j < n:
                grad[i] = best[j]
        
        # We want to DECREASE a where grad is large (contributes to peak)
        # and INCREASE where grad is small
        # But we want to keep sum roughly constant
        # So: direction = -grad + mean(grad) (centered)
        direction = -grad + np.mean(grad)
        
        # Add some randomness
        noise = rng.normal(0, 0.1, n)
        step = direction + noise
        
        # Apply step
        alpha = 0.01  # Step size
        candidate = best + alpha * step
        candidate = np.clip(candidate, 0, 1000)
        
        # Normalize (scale-invariant, but keep sum in reasonable range)
        if np.sum(candidate) > 0.01:
            candidate = candidate / np.sum(candidate) * sum_a
        
        score = evaluate_sequence(candidate.tolist())
        if score < best_score:
            best_score = score
            best = candidate.copy()
            print(f"Improved: {best_score} at t={time.time()-start_time:.1f}s")
    
    return best.tolist()
