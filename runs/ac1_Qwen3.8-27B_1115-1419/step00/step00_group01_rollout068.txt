"""
Return a globally optimal sequence for the provided evaluate_sequence.

For any valid input sequence a of length n with S = sum(a) > 0, the evaluator
computes:

    score = 2 * n * max_k (a * a)[k] / S^2

where (a * a) is the full linear convolution.  The zero-lag term is

    (a * a)[0] = sum_i a_i^2.

By Cauchy-Schwarz,

    (sum_i a_i)^2 <= n * sum_i a_i^2,

so

    (a * a)[0] >= S^2 / n.

Because max_k (a * a)[k] >= (a * a)[0], we always have

    score >= 2 * n * S^2 / n / S^2 = 2.

Equality holds exactly when all entries are equal positive constants.
Therefore the mathematical minimum is 2, attained by any positive constant
sequence.  This program simply returns such a sequence, choosing a modest
length that is fast to evaluate and consistent with the previously supplied
construction when available.
"""

    Build a positive constant sequence with a safe, finite length.

    evaluator's cap of 1000, and makes the final score numerically clean.
    """
    try:
