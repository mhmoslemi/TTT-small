Now, for projected gradient descent with the constraint a >= 0 and sum a = 1:
1. Compute gradient.
2. Take step: a_new = a - lr * grad.
3. Project onto {a >= 0, sum a = 1}: this is the euclidean projection onto the simplex, which can be done in O(n log n) (or O(n) with a sort).

The projection onto the simplex {x >= 0, sum x = 1} is:
- Sort x in decreasing order.
- Find the largest t such that x_i - t > 0 for the top t elements.
- Set x_i = max(x_i - t, 0) for all i.

This is the standard simplex projection algorithm.
