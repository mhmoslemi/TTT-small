Wait, I need to verify the cross-correlation formula. 

Cross-correlation: (w ⋆ a)[i] = sum_k w[k+i] * a[k] (for all k where both are defined)

Using FFT: 
W = fft(w, L) where L >= len(w) + len(a) - 1
A = fft(a, L)
xcorr = ifft(W * conj(A, L))

Then xcorr[i] = sum_{k=0}^{L-1} w[(k+i) mod L] * a[k] (circular)
= sum_{k: 0<=k<len(a), 0<=k+i<len(w)} w[k+i] * a[k] (linear, if L is large enough to avoid wrap-around)

For i >= 0: (k+i) mod L = k+i if k+i < L. Since k < len(a) = n and i < n, k+i < 2n. If L >= 3n, no wrap-around for the positive lags.

So g[i] = xcorr[i] for i = 0, ..., n-1 gives sum_k w[k+i] * a[k] = sum_j w[j] * a[j-i] (substituting j=k+i).

Yes! That's exactly what we want: g[i] = sum_k w[k] * a[k-i].

So the algorithm is:
1. Compute c = full_conv(a)
2. w = max(0, c - t)
3. g = cross_corr(w, a)[:n] (using FFT)
4. Update: a <- a - alpha * (2*g - mean(2*g)) (subtract mean to preserve sum)
5. Clip: a = max(0, a)
6. Renormalize: a = a / sum(a)
