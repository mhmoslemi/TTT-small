**Now, the simplex projection:**

Project x onto {z >= 0, sum(z) = 1}:
1. Compute mu such that sum(max(x - mu, 0)) = 1. This can be done via bisection or sorting.
2. Return max(x - mu, 0).

- Sort x in decreasing order: x_(1) >= x_(2) >= ... >= x_(n)
- Find the largest k such that x_(k) - (1 - sum_{j=1}^k x_(j))/k > 0
- mu = (1 - sum_{j=1}^k x_(j))/k
- Return max(x - mu, 0)

This is O(n log n) per projection.

import time

def project_simplex(v):
    """Project v onto {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    # Use the sorting-based method
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.where(u * (np.arange(1, n+1)) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1)
    return np.maximum(v - theta, 0)

    """Compute 2n * max(conv(p,p)) for p with sum=1."""
    b = np.convolve(p, p, mode='full')
    return 2 * len(p) * b.max()
