def deflate(a, lr=0.01):
    n = len(a)
    S = np.sum(a)
    conv = np.convolve(a, a)
    k_star = np.argmax(conv)
    
    # Partner array
    partner = np.zeros(n)
    for i in range(n):
        j = k_star - i
        if 0 <= j < n:
            partner[i] = a[j]
    
    # We want to reduce a_i where partner[i] is large
    # and increase a_i where partner[i] is small
    # while keeping sum constant
    
    # Normalized partner
    p = partner / S  # So sum(p) = (sum of valid partners) / S <= 1
    
    # Direction: decrease where p is large, increase where p is small
    # d_i = p_i - mean(p) (projected to sum-zero)
    d = partner - np.mean(partner)
    
    a_new = a - lr * d
    a_new = np.clip(a_new, 0, 1000)
    
    # Renormalize to keep sum constant
    if np.sum(a_new) > 0:
        a_new = a_new * (S / np.sum(a_new))
    
    return a_new

A better approach: use the gradient, but project out the radial component.

The gradient is $g_i = \frac{2n}{S^2}(a_{k^*-i} - 2M/S)$.
The radial component is $\bar{g} = \frac{1}{n}\sum_i g_i$.
The tangential gradient is $g_i - \bar{g}$.

If the tangential gradient is non-zero, we can use it for optimization.

For the uniform sequence, the tangential gradient is zero (as shown). But for any non-uniform sequence, it should be non-zero (generic case).

So the algorithm is:
1. Start from a non-uniform sequence (to have a non-zero tangential gradient).
2. At each step:
   a. Compute the convolution, find the peak $k^*$.
   b. Compute the gradient $g$.
   c. Project out the radial component: $g \leftarrow g - \bar{g}$.
   d. Take a step: $a \leftarrow a - \alpha g$ (with $\alpha$ small).
   e. Clip to [0, 1000].
   f. Optionally, renormalize to keep the sum constant.
