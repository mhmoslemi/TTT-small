def solve_lp_for_g(f, M):
    """Solve: max sum(g) s.t. (f*g)[k] <= M for all k, g >= 0."""
    n = len(f)

    # c[k] = sum_j f[k-j] * g[j] for valid j
    # Row k, col j: value f[k-j] if 0<=k-j<n else 0
    
    # For efficiency, build the sparse matrix

        j_max = min(n - 1, k)
        if j_min <= j_max:

            rows.extend([k] * len(js))
            cols.extend(js.tolist())

**Approach: Iterative Proportional Fitting (IPF) variant**

1. Start with a (normalized, sum=1).
2. Compute c = convolve(a, a).
3. Compute target: t[k] = 1/(2n-1) for all k (flat target).
4. Compute ratio: r[k] = t[k] / c[k] (where c[k] > 0).
5. Update: a[i]_new = a[i] * (average of r[k] over k where a[i] contributes to c[k])^alpha.

This is similar to the "sinkhorn" or "iterative proportional fitting" approach for contingency tables, adapted for convolution.

More precisely:
- c[k] = sum_i a[i] * a[k-i]
- We want c[k] ≈ 1/(2n-1) for all k.
- The "deficit" at position k is c[k] - 1/(2n-1).
- To reduce c[k] for large c[k], we should reduce the a[i]'s that contribute to it.
- a[i] contributes to c[k] for k = i + j where j is a valid index, with contribution a[i]*a[j].
- So the "pressure" on a[i] from position k is proportional to a[k-i] (if valid).

Let me define:
pressure[i] = sum_{k: c[k] > threshold} a[k-i] * (c[k] - threshold) / sum_k (c[k] - threshold)_+

Then update: a[i] *= (1 - eta * pressure[i]) for some step size eta.

This is a heuristic but might work well.

def pressure_update(a, alpha=0.1, beta=2.0):
    """One step of pressure-based update to flatten convolution."""
    n = len(a)
    c = np.convolve(a, a)
    
    # Weight: emphasize peaks
    c_max = np.max(c)
    w = (c / c_max) ** beta
    
    # Pressure: p[i] = sum_k w[k] * a[k-i] (cross-correlation of w and a)
    N = int(2 ** np.ceil(np.log2(3 * n)))

    """Solve LP: max sum(g) s.t. (f*g)[k] <= M for all k, g >= 0."""

    cols = []
    vals = []

            rows.extend(range(d, d + count))
            cols.extend(range(count))

                  bounds=[(0, None)]*n, method='highs')
    if res.status == 0:
        return res.x
    return None
