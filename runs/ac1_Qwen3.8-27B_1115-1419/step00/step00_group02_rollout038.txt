**Algorithm: Spectral flattening**

1. Initialize a random 0-1 sequence a of length n.
2. Compute the DFT F = DFT(a).
3. For each frequency ξ, compute |F(ξ)|^2.
4. The linear convolution coefficients are (up to scaling) the inverse DFT of |F|^2 (padded appropriately).
5. Identify the "hot spots" (frequencies where |F(ξ)|^2 is too large).
6. Adjust the sequence: try flipping bits to reduce the hot spots.

5. Choose the flip that most reduces max(c) (or the score).
6. Repeat.

The key challenge is step 4: for each of the n possible flips, we need to evaluate the new max(c). This is O(n * k) per iteration (where k = |S|).

For efficiency, we can precompute the "contribution vector" for each position p:

- contrib_1(p) = vector that gets subtracted from c when a_p changes from 1 to 0.

contrib(p)[s] = 1 if s = 2p (the diagonal term)
contrib(p)[s] = 0 otherwise.

So contrib(p) is essentially 2*a (shifted by p) plus a delta at 2p.

To find the best flip, we need:
- For each p with a_p = 0: compute max(c + contrib(p)) and pick the p that minimizes it.
- For each p with a_p = 1: compute max(c - contrib(p)) and pick the p that minimizes it.

This is O(n * (2n-1)) in the worst case, which is O(n^2). For n=1000, that's 10^6 per iteration. In Python with numpy, that's probably 0.01-0.1 seconds per iteration. So we can do about 10^4-10^5 iterations in 2400 seconds.

**Optimization: Focus on the peak**

- Or, increasing other c_s values to "shift" the peak (but this is less direct).
