For a perfectly flat convolution, we'd need `conv(p,p)[k] = 1/(2n-1)` for all k. This means `|FFT(p)|^2` is constant (by the convolution theorem, in the circular case). A sequence with constant-magnitude FFT is a "chirp" or "Zadoff-Chu" sequence, but those are complex. For real non-negative sequences, we can't achieve this exactly.

However, we can approximate it. One approach: use `p[j] = |F^{-1}(e^{i*phi})|^2` where `|F^{-1}(e^{i*phi})|` is constant. But this gives a complex sequence in general.

For real sequences, the best we can do is minimize the variance of conv(p,p) subject to non-negativity. This is a non-convex problem, but we can use iterative methods.

**Practical algorithm:**

Let me use an iterative water-filling approach:

1. Start with p (normalized, non-negative, sum=1).
2. Compute c = conv(p,p).
3. Find the "excess" at each position: `excess[k] = max(0, c[k] - target)` where target is the current max or a threshold.
4. Adjust p to reduce the excess: decrease p at positions that contribute to the excess, increase at positions that don't.
5. Normalize and repeat.

The adjustment in step 4 can be done using the gradient: `dp = -alpha * subgradient`. This is essentially projected gradient descent.

Let me also consider using **accelerated methods** like FISTA (Fast Iterative Shrinkage-Thresholding Algorithm) or Nesterov's accelerated gradient method, which can help with convergence.

But since the problem is non-convex, acceleration might not help as much. Let me stick with basic projected subgradient descent with good step sizes, combined with the LP-based refinement.

1. Efficiency (use FFT for convolution)
2. Multiple starting points
3. Adaptive step sizes
4. LP-based refinement (using scipy or a simple projected approach)
5. Time management (2400s budget)

import numpy as np
import time
import sys

def _normalize(a):
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / a.size
    return a / s

def _conv_self(a):
    n = a.size
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    C = np.fft.irfft(A * A, fft_size)[:size]
    return np.maximum(C, 0.0)

def _subgrad(a, active):
    """Subgradient of max(conv(a,a)) given active set."""
    n = a.size
    a_pad = np.zeros(2 * n - 1)
    a_pad[:n] = a
    g = np.zeros(n)
    g += len(active) * a
    for k in active:
        jlo = max(0, k - (2*n - 2))
        jhi = min(n - 1, k)
        if jlo <= jhi:
            js = np.arange(jlo, jhi + 1)
            g[js] += a_pad[k - js]
    return g

def _project_sum1(a):
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones_like(a) / a.size
    return a / s

def _sgd_step(a_init, max_iter, time_limit, verbose=False):
    """Projected subgradient descent with BB step sizes."""
    a = _normalize(a_init.copy())
    n = a.size
    c = _conv_self(a)
    best_val = c.max()
    best_a = a.copy()
    
    a_prev = a.copy()
    g_prev = None
    step_count = 0
    
    deadline = time.monotonic() + time_limit
    it = 0
    while it < max_iter and time.monotonic() < deadline:
        c = _conv_self(a)
        M = c.max()
        if M < best_val - 1e-15:
            best_val = M
            best_a = a.copy()
        
        # Active set: positions where c is within 1% of max (or exact max)
        threshold = M * 0.999
        active = np.where(c >= threshold)[0]
        
        g = _subgrad(a, active)
        g_norm = np.linalg.norm(g)
        if g_norm < 1e-15:
            break
        
        # BB step size
        if g_prev is not None:
            y = g - g_prev
            s_vec = a - a_prev
            sy = s_vec @ y
            yy = y @ y
            ss = s_vec @ s_vec
            if yy > 1e-15 and abs(sy) > 1e-15:
                if sy > 0:
                    alpha = ss / sy
                else:
                    alpha = ss / yy
                alpha = np.clip(alpha, 1e-4, 1.0)
            else:
                alpha = 0.5 / g_norm
        else:
            alpha = 1.0 / max(g_norm, 1e-10)
            alpha = np.clip(alpha, 0.01, 1.0)
        
        # Backtracking line search (simplified)
        a_new = _project_sum1(a - alpha * g)
        
        a_prev = a
        g_prev = g
        a = a_new
        it += 1
        
        if verbose and it % 500 == 0:
            print(f"    SGD iter {it}: val={best_val:.8f}, M={_conv_self(a).max():.8f}")
    
    return best_a, best_val

Wait, I realize there's an issue with the subgradient approach. The function `max(conv(a,a))` is not smooth, and the subgradient can be expensive to compute and unreliable in direction.

Let me think of a smoother alternative. Instead of minimizing `max(c)` directly, I can minimize a smooth approximation like:
- `log-sum-exp(c / tau) * tau` (for small tau)
- Or minimize `sum(c^p)` for large p (approximates max)

The gradient of `sum(c^p)` is `p * sum_k c[k]^{p-1} * dc[k]/da`, which uses all points (not just the argmax) and is smoother.

For p = 4 or p = 6, this should be a good approximation to max while being smoother.
