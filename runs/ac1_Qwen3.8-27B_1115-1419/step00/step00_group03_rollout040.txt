Hmm, this is getting complicated. Let me just note that the Hessian is the sum of a permutation matrix and its reverse, which is a symmetric matrix. It's not necessarily positive semi-definite, so the quadratic form is not necessarily convex.

```python
def build_conv_structure(n):
    """Precompute the sparse structure of the convolution constraint matrix.
    
    Returns (rows, cols, indices) where:
    - A[k, j] = f[k-j] if 0 <= k-j <= n-1, else 0
    - indices = rows - cols = k - j for each non-zero entry
    """
    rows_list = []
    cols_list = []
    for k in range(2 * n - 1):
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        if j_start <= j_end:
            count = j_end - j_start + 1
            rows_list.extend([k] * count)
            cols_list.extend(range(j_start, j_end + 1))
    rows = np.array(rows_list, dtype=np.int32)
    cols = np.array(cols_list, dtype=np.int32)
    indices = (rows - cols).astype(np.int32)
    return rows, cols, indices

def fast_convolve(a, b):
    """Fast convolution using FFT for large sequences."""
    n = len(a) + len(b) - 1
    size = 1
    while size < n:
        size *= 2
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:n]
```

**Approach: Gradient-based with exact line search**

Since the objective is f(a) = max_k (a*a)[k] (after normalization), and it's a max of smooth functions, we can use:
1. Subgradient descent with projection onto {a >= 0, sum(a) = sqrt(2n)}
2. Or, use the "smooth max" approximation and do gradient descent

The smooth max: h_β(a) = (1/β) log(sum_k exp(β * (a*a)[k]))

For large β, this is close to max_k (a*a)[k]. We can use β-annealing: start with small β and gradually increase.

The gradient of h_β(a) w.r.t. a[j]:
= sum_k p_k * (a[k-j] + a[j-k])

where p_k = exp(β*(a*a)[k]) / sum_m exp(β*(a*a)[m]) (softmax weights).

This is a weighted average of the gradients of each (a*a)[k], weighted by the softmax. For large β, the weight concentrates on the argmax.

The algorithm:
1. Start with a random a (normalized).
2. For β in [1, 10, 100, 1000, ...]:
   a. Do gradient descent on h_β(a) + λ(sum(a) - norm)^2 with projection onto a >= 0.
   b. Or, do projected gradient descent on h_β(a) subject to sum(a) = norm and a >= 0.

The projection onto {a >= 0, sum(a) = norm} is the "Euclidean projection onto the simplex" (scaled). This can be done in O(n log n) time.

```python
def project_onto_simplex(v, target_sum):
    """Project v onto {x >= 0, sum(x) = target_sum}."""
    n = len(v)
    # Standard simplex projection
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.max(np.where(u * np.arange(1, n+1) > (cssv - target_sum), np.arange(1, n+1)))
    theta = (cssv[rho-1] - target_sum) / rho
    return np.maximum(v - theta, 0)
```
