Actually, I think the key question is: can the peak of the auto-convolution of a non-negative sequence be less than s^2/n?

Let's think: C[n-1] = sum_{j=0}^{n-1} a[j]*a[n-1-j]. This is the "anti-diagonal" product.
By rearrangement inequality, for a fixed multiset of {a[j]}, the sum sum a[j]*a[n-1-j} is:
- Maximized when both sequences are sorted in the same order (i.e., a[j] = a[n-1-j], palindrome).
- Minimized when they're sorted in opposite orders.

But a[j]*a[n-1-j} uses the SAME sequence, just reversed. So it's the dot product of a and its reverse.

For non-negative a with fixed sum s:
- max of dot(a, reverse(a)) = sum a[j]^2 (when a is a palindrome, achieved by uniform or by concentrating mass).
  Actually, by Cauchy-Schwarz: dot(a, reverse(a)) <= ||a||^2 = sum a[j]^2.
  And sum a[j]^2 >= s^2/n (by QM-AM or C-S).
  Equality when all a[j] = s/n (uniform).

- min of dot(a, reverse(a)): By rearrangement, to minimize sum a[j]*a[n-1-j}, we should pair large a[j] with small a[n-1-j}. Since a[j] and a[n-1-j} are the same multiset, the minimum is achieved when one is ascending and the other is descending, i.e., a is increasing (or decreasing).

For a = (0, 0, ..., 0, s) (all mass at one end):
dot(a, reverse(a)) = s*0 + 0*0 + ... + 0*s + 0*s = 0 (if n > 1).
But then C[0] = s^2, so peak = s^2. Score = 2n. Terrible.
