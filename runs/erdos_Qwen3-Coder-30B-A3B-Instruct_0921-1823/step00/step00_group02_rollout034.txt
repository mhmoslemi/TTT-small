    # Correlation result has length 2*n-1
    # The maximum overlap occurs when k is from -1 to 1
    # But due to symmetry and periodicity, we want max of middle values

    # But since it's convolution, we take the result from indices 0 to 2*n-2
    # and shift it to get the correct k values

    # k = 2 -> conv[n+1] 
    # we care about k between 0 and 2, so indices are from n-1 - (n-1) = 0 to n-1 + (n-1) = 2*(n-1) 
    # No, let's rederive carefully.
    # Convolution result corresponds to k from - (n-1) to n-1, or equivalently
    # convolution_i corresponds to k = i - (n-1)  
    # so for k in [0,2] we need from index = k + (n-1) which goes from (n-1) to (n+1)
    # Actually, this problem has periodic boundary conditions assumed.
    # Let's assume h is periodic on [0,2]
    # Then for given k, we evaluate int h(x) (1 - h(x+k)) dx
    # The full convolution is correct for evaluating it in continuous time
    # Take maximum of all the relevant k values from the convolution result
    # The proper way:
    # If we interpret it as the full 2n-1 elements of convolution, the k values are:
    # k = indices - (n - 1), so k=0 corresponds to index n-1
    # We want the values for k in [0,2] i.e. indices in [n-1, n+1] states
    # But also we should consider periodicity, that is, overall the
    # actual support is [0,2] so there are finite values of k.
    # Also note h is 0-1 valued over [0,2], with integral=1
    # So the max correlation is:
    # max_{k in [0,2]} of \int h(x) (1 - h(x+k)) dx
    # Evaluate convolution, and the correct indices for k between 0 and 2 are
    # from index (n-1) to (n+1) since k = index - (n-1) so 
    # k in [0,2] means index in [n-1, n+1]
    return np.max(conv[n-1:n+2]) * dx
