Putting this into code:

For each shift k, the approximated overlap_k_linear is:

where:

linear_part = dx * ( sum_i [ h_t[ (i -k) mod n ] + h_t[ (i +k) mod n ] ] * h[i] )

and const_k is dx * sum_i [ h_t[i] * h_t[ (i +k) mod n ] ]

Wait, sum h_t[i] h_t[j] is for the same indices as in the sum over i and j.

So in code, for each k, we need to compute the coefficients for the linear part and the constant term.

Now, with this, we can model each overlap_k_linear as a linear expression in h, plus a constant. In CVXPY, this can be represented as:

for each k, overlap_k = dx * sum(h) - dx * dot(coeffs, h) + const_k

Where coeffs is a vector of the coefficients for h.

Once we have all these overlaps for all k, we can compute the log_sum_exp of them as before.

3. Minimize log_sum_exp - gamma * entropy, with the constraints on h.

4. Solve this convex problem.

5. Update h_t to the new solution.
