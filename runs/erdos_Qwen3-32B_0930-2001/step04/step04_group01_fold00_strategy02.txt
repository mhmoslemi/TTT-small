- **Bottleneck addressed**: The non-convex nature of C₅ makes gradient-based methods prone to local optima. Nelder-Mead's global exploration capabilities can better navigate this landscape.
- **Strengths of Nelder-Mead**: It is simple to implement, robust, and effective for non-linear, non-differentiable problems like ours.
- **Constraints handling**: Unlike pure Nelder-Mead, this implementation includes projection operations to enforce the 0 ≤ h[i] ≤ 1 and sum(h) = n_points/2 constraints after every simplex operation.

### 2. Mathematical specification

- **Objective function**:  
  $$C_5 = \max_{k}\left( \text{correlate}(h, 1 - h, \text{mode="full"}) \cdot dx \right)$$  
  where $dx = \frac{2}{n\_points}$ and $k$ ranges over all lags.

- **Constraints**:  
  1. $0 \leq h[i] \leq 1 \quad \forall i$  
  2. $\sum_{i=1}^{n\_points} h[i] = \frac{n\_points}{2}$  

- **Feasible region**: The intersection of the simplex $\sum h[i] = n\_points/2$ and the hypercube $[0,1]^{n\_points}$.

- **Optimization direction**: Minimize C₅.

- **Key operations**:
  1. Reflection: $r = x + \alpha(x - x_{worse})$
  2. Expansion: $e = x + \gamma(r - x)$
  3. Contraction: $c = x + \delta(x - x_{best})$
  4. Reduction: Shrinking all points toward the best point.

    best_idx = simplex_order[0]

    # Update best found
    if evals[best_idx] < best_c5:

    if max_c5 - min_c5 < tolerance:

    # Get centroid of all points except worst
    centroid = np.mean([ simplex[i] for i in simplex_order[:-1] ], axis=0)
