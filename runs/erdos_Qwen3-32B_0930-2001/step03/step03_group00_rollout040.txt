The cutting plane approach would:

- Start with a small set of constraints (e.g., k=0).
- Solve for h and C.
- Compute the overlaps for all k and find the maximum one.
- If this maximum is greater than the current C, add the corresponding constraint.
- Repeat until the maximum overlap is <= C.

This way, we add only a few constraints instead of all possible ones.
