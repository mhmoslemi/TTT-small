But wait, no. Earlier, I thought that the objective for the convex subproblem is to maximize the linear approximation of sum h[i] * h[j], but here the overlap is sum h[i] * (1 - h[j]). The sum for the overlap is sum [h[i] * (1 - h[j])], which is sum h[i] - sum h[i]h[j]. So to minimize the overlap, we need to maximize sum h[i]h[j].

Ah, right. So for the current subproblem, the objective is to maximize sum h[i]h[j], for the pairs (i,j) derived from the current k.

So for each pair (i,j), we have a term h[i]h[j], which is approximated as h_t[i]h[j] + h_t[j]h[i] - h_t[i]h_t[j]. This is the linear expansion around the current h_t. 

Then, the convex subproblem is:

Maximize sum_{(i,j)} [h_t[i]h[j] + h_t[j]h[i] - h_t[i]h_t[j]]

Subject to:

- 0 ≤ h[i] ≤ 1 for all i
- sum h[i] = n_points / 2

This is a linear program (since the objective is linear in h) with linear constraints.

Therefore, the code can now:

- For each iteration, solve this LP to get a new h.
