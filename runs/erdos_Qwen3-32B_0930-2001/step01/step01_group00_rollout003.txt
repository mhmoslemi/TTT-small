        c5_scores = [compute_c5(ind) for ind in population]
        min_idx = np.argmin(c5_scores)
        if c5_scores[min_idx] < best_c5:
            best_c5 = c5_scores[min_idx]
            best_h = population[min_idx].copy()
        
        # Select top half
        sorted_indices = np.argsort(c5_scores)
        top_half = sorted_indices[:population_size//2]
        top_parents = [population[i] for i in top_half]
        
        # Generate new population
        new_population = top_parents.copy()
        while len(new_population) < population_size:
            parent1, parent2 = np.random.choice(top_parents, 2, replace=False)
            child = crossover(parent1, parent2)
            # Apply mutation with some probability
            if np.random.rand() < 0.3:
                child = mutate(child)
            new_population.append(child)
        
        population = new_population
    
    return best_h, best_c5, n_points

Now, some notes about this code:

1. The initial population is created by applying 3 mutations to the initial_h. This increases diversity.

2. In the while loop, for each generation, evaluate all population members, track the best solution.

3. Selection is the top 50%, then new offspring are generated until population is filled.

4. Each child is a crossover of two selected parents, possibly mutated.

5. The mutate function adds small perturbations and adjusts sum by changing one element.

6. In crossover, after averaging, adjust the sum similarly.

7. The code checks the time budget and stops when it's exceeded.

Potential improvements:

- The mutation's adjustment could be more robust, but for the sake of time, it's a heuristic.
