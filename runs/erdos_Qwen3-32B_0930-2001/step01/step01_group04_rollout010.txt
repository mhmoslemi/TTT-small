For sequences of length n, the output length is 2n -1, and the shifts range from -(n-1) to +(n-1). The index in the output array for a positive shift k is (n -1) + k. So, for a given k_max (an index in the corr array), we can compute the real shift value as shift = k_max - (n-1). 

Once we have the real shift value, we can determine the valid (i, j) pairs as follows:

For a shift δ, the overlap sum is computed over i where i + δ is within [0, n-1]. Given that δ can be positive or negative, this defines the valid indices.

For example, if δ is positive, then i ranges from 0 to n-1 - δ, so that i + δ = j ranges from δ to n-1.

If δ is negative, then i ranges from -δ to n-1, so that j = i + δ ranges from 0 to n-1 + δ.

This is manageable in code. So, for the current worst k_max index in the corr array, we can compute the actual shift δ = k_max - n_point + 1. Then generate all valid i and j pairs.

Once we have that, the linear approximation can be calculated.

So, putting it all together:

In each iteration of the CCCP approach:

1. Compute the corr using np.correlate(h_prev, 1 - h_prev, 'full').

2. Find the k_max index with the maximum corr value.

3. Convert k_max to the real shift δ.

4. Generate all valid (i, i+δ) pairs for i in 0..n_point-1.

5. For each such pair, add h_prev[j] to the coefficient of h[i], and h_prev[i] to the coefficient of h[j].

6. The LP objective is to maximize the sum of these coefficients * h[i] * dx, minus the constants (which are ignored as they are constant in h).

- 0 ≤ h[i] ≤ 1 for all i.
