Key improvement idea: **Adaptive proposal distribution**. Instead of always proposing uniform random swaps, propose swaps that are more likely to be improving. Specifically:
- Identify the current worst shift k*
- Propose swaps where the 1→0 position i satisfies h[i-k*]=1 (so the swap doesn't increase overlap at k*)

Actually, let me think about this more carefully. The overlap at shift k is:
O_k = Σ_i h[i] * (1-h[i-k])

If I change h[i] from 0 to 1:
- O_k changes by: (1-h[i-k]) - 0 = 1-h[i-k] (adds the contribution of position i)
  So if h[i-k]=1, no change to O_k. If h[i-k]=0, O_k increases by 1.

If I change h[j] from 1 to 0:
- O_k changes by: 0 - (1-h[j-k]) = -(1-h[j-k]) = h[j-k]-1 (removes the contribution of position j)
  So if h[j-k]=0, O_k decreases by 1. If h[j-k]=1, no change.

So a swap (i: 0→1, j: 1→0) changes O_k by:
ΔO_k = (1-h[i-k]) + (h[j-k]-1) = h[j-k] - h[i-k]

For the swap to decrease O_k (the worst shift), we need h[j-k] < h[i-k].
Since both are 0 or 1, this means h[j-k]=0 and h[i-k]=1.

So focused swaps for reducing O_{k*}: prefer i such that h[i-k*]=1 and j such that h[j-k*]=0.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(2000):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)

def round_to_binary(h, n):
    target = n // 2
    idx = np.argsort(h)[::-1]
    out = np.zeros(n)
    out[idx[:target]] = 1.0
    return out

def slsqp_smooth(h, n, alpha, maxiter=500):
    dx = 2.0 / n
    def obj(x):
        g = np.correlate(x, 1 - x, mode='full') * dx
        m = g.max()
        sh = alpha * (g - m)
        sm = sh.max()
        return m + (sm + np.log(np.exp(sh - sm).sum())) / alpha
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x: x.sum() - n / 2.0}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-14})
        return project_feasible(res.x, n)
    except Exception:
        return h

def swap_delta(h, n, i, j, m_range):
    delta = np.zeros(2 * n - 1)
    im = i + m_range
    msk = (im >= 0) & (im < n)
    delta[msk] += 1.0 - h[im[msk]]
    imn = i - m_range
    msk = (imn >= 0) & (imn < n)
    delta[msk] -= h[imn[msk]]
    jm = j + m_range
    msk = (jm >= 0) & (jm < n)
    delta[msk] -= 1.0 - h[jm[msk]]
    jmn = j - m_range
    msk = (jmn >= 0) & (jmn < n)
    delta[msk] += h[jmn[msk]]
    delta[n - 1] -= 2.0
    k1 = n - 1 + (j - i)
    delta[k1] += 1.0
    k2 = n - 1 + (i - j)
    delta[k2] += 1.0
    return delta
