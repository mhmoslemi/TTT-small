    d = np.arange(-(n-1), n)
    k = n - 1 + d  # correlation indices, 0 to 2n-2

    mask4 = (idx4 >= 0) & (idx4 < n)
    t4 = np.zeros(2*n-1)

Alternative: maintain a "threshold" that's slightly above the current max. A move is accepted if max(corr+delta) < threshold. This is the same as checking if (corr+delta).max() < threshold, which still requires the full max.

OK, let me just go with the full max computation. It's O(n) = O(499) which is fine.

Let me also think about the **multi-swap** idea. Instead of swapping one 1 with one 0, swap two 1s with two 0s. This gives more freedom in the search.

For a 2-swap (i1, i2 are ones to become zeros; j1, j2 are zeros to become ones):
The delta is the sum of the deltas for each individual swap, MINUS the cross terms (because the h values changed for the second swap).

Actually, it's easier to just compute the delta directly:
- h changes at 4 positions: i1, i2 (1→0), j1, j2 (0→1)
- The delta in c[k] involves contributions from all 4 positions

This is still O(n) but with 4x the work per trial. Not worth it unless single swaps are stuck.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(100):
        diff = target - h.sum()
        if abs(diff) < 1e-10: break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14: break
            h = np.clip(h + diff/s * room, 0.0, 1.0)
        else:
            s = h.sum()
            if s < 1e-14: break
            h = np.clip(h + diff/s * h, 0.0, 1.0)
