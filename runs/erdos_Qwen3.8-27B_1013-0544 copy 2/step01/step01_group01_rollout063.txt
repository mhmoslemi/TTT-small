def lag_correlation(h, lag, n):
    """Compute correlation at a specific lag for h against 1-h."""
    # lag can be negative or positive
    if lag >= 0:
        # sum h[i] * (1-h[i+lag]) for i=0 to n-1-lag
        if lag == 0:
            return 0.0
        valid = slice(0, n - lag)
        return np.sum(h[valid] * (1.0 - h[lag:]))
    else:
        lag = -lag
        # sum h[i+lag] * (1-h[i]) for i=0 to n-1-lag
        # = sum h[j] * (1-h[j-lag]) for j=lag to n-1
        valid = slice(lag, n)
        return np.sum(h[valid] * (1.0 - h[0:n-lag]))

Now the full algorithm:
1. Precompute correlations
2. For each pair (j,k):
   a. Compute gj = grad(h, j), gk = grad(h, k)
   b. dg = gj - gk
   c. 1D optimization: minimize max(corr + delta*dg) over valid delta
   d. Update h
3. Repeat

The 1D optimization: minimize max over 2n-1 values of (corr[m] + delta * dg[m]).
This is the minimum of the max of linear functions, which is a convex LP in 1D.

For a 1D convex piecewise linear function, the minimum is at a "kink" point, which is where two lines cross. We can find it by:
- For each pair of lines (m1, m2), find the intersection point
- Check if it's in the valid range
- Evaluate the objective at all such points + boundaries
- Return the minimum

But that's O(n^2) intersections to check. For n=70, that's ~2400, which is fine.

Actually, a simpler approach for 1D: use the fact that the subgradient is the convex hull of {dg[m] : m is active}. The minimum is where 0 is in the subgradient, i.e., where there exist active m+ with dg[m+] >= 0 and active m- with dg[m-] <= 0.

But wait, for the final answer, we want to be as precise as possible. Let me add a refinement step: after finding the approximate optimal delta with the grid, do a few bisection iterations to nail it down.

For the bisection: the function f(delta) = max_m (corr[m] + delta * dg[m]) is convex and piecewise linear. Its subgradient at delta is the set {dg[m] : m is active}. We want to find where 0 is in the subgradient.

Bisection on the subgradient:
- If all active m have dg[m] > 0, the minimum is to the left (decrease delta)
- If all active m have dg[m] < 0, the minimum is to the right (increase delta)
- If there are active m with dg[m] > 0 and active m with dg[m] < 0, we're at the minimum

But "active" means achieving the max, which is a condition on delta. So:
1. Compute f(delta) and the set of active m
2. Check if 0 is in the convex hull of {dg[m] : m active}
3. If yes, we're done
4. If all dg[m] > 0 for active m, move left
5. If all dg[m] < 0 for active m, move right

This is a bisection-like method. Let me implement it:

```python
def _bisection_1d(corr, dg, lo, hi, tol=1e-10, max_iter=50):
    for _ in range(max_iter):
        mid = (lo + hi) / 2
        vals = corr + mid * dg
        active = np.abs(vals - vals.max()) < 1e-12
        g_active = dg[active]
        if g_active.min() <= 0 <= g_active.max():
            break  # 0 is in subgradient, optimal
        elif g_active.min() > 0:
            hi = mid  # all gradients positive, move left
        else:
            lo = mid  # all gradients negative, move right
    return (lo + hi) / 2
```

def smooth_max(x, beta):
    m = x.max()
    return m + np.log(np.sum(np.exp(beta * (x - m)))) / beta

    h = h.copy()
