        return float(np.max(x))
    m = np.max(x)

Let me write the final clean version. I'll also add a "coordinate descent" phase that's fast and can polish the SLSQP result.

For coordinate descent:
- Fix all coordinates except h[i]
- The objective becomes max_k (corr_k(h)) where corr_k depends on h[i] linearly
- So for fixed i, the problem is: minimize max_k (a_k + b_k * h[i]) over h[i] ∈ [0,1]
- where a_k = corr_k with h[i]=0 and b_k = d corr_k / d h[i]
- The optimal h[i] is found by checking where the max changes

This is a 1D problem that can be solved exactly!

For a fixed i:
corr_k(h[i]) = corr_k_base + h[i] * infl_i[k]

where corr_k_base is the correlation with h[i] set to 0, and infl_i[k] is the influence of h[i] on lag k.

We want to find h[i] ∈ [0,1] that minimizes max_k (corr_k_base + h[i] * infl_i[k]).

This is a 1D convex optimization problem (max of linear functions). The optimum is at:
- h[i] = 0, or
- h[i] = 1, or
- A point where two lines are tied for the maximum

The number of candidate points is O(n). So for each i, finding the optimal h[i] is O(n^2) (compute corr_k_base in O(n), then check O(n) candidate points, each O(n) to evaluate the max).

Total for one full coordinate descent sweep: O(n^3). For n=70, that's 343,000. In numpy, this should be fast.

But wait, I also need to maintain the sum constraint. If I change h[i], the sum changes. I need to either:
a) Fix the sum by adjusting another coordinate (pair move)
b) Use a Lagrange multiplier

For simplicity, let me use the "include the constraint in the objective" approach:
minimize max_k (corr_k_base + h[i] * infl_i[k]) + λ * (sum - target)

where λ is chosen to enforce the constraint. This is a 1D problem in (h[i], λ), which is 2D. I can solve it by:
1. For a given λ, find optimal h[i] (1D problem)
