And there are 2n-1 values of d. So the average g(d) = dx * n²/4 / (2n-1) ≈ dx * n/8 = (2/n) * n/8 = 1/4 = 0.25.

So the average is 0.25, and we're trying to make the max as close to 0.25 as possible. Currently we're at 0.38, which is significantly above the average. So there's room for improvement!

This suggests that the optimal solution has g(d) very close to 0.25 for all d, and the theoretical lower bound is 0.25 (achieved only if g(d) = 0.25 for all d, which may not be achievable with the constraints).

This is a great insight! It means we should be looking for solutions where g(d) is as flat as possible.

Now, how to achieve this? The key is to make the autocorrelation of h as "flat" as possible. This is related to the theory of "low autocorrelation sequences" in signal processing.

For binary sequences, the problem of minimizing the maximum autocorrelation is well-studied. The "Legendre sequences" and "m-sequences" (from finite field theory) have good autocorrelation properties.

Let me think about what binary sequence of length n with n/2 ones minimizes the maximum autocorrelation.

For a binary sequence b[0], ..., b[n-1] with n/2 ones:
g(d) = (number of i such that b[i]=1 and b[i+d]=0) for valid i.

Note that g(d) + g(-d) = (number of i where b[i]≠b[i+d]) for valid i (counting both directions).
And g(d) = (number of i where b[i]=1, b[i+d]=0) = (total transitions at offset d) - (number where b[i]=0, b[i+d]=1).

If the sequence is "balanced" in a certain sense, g(d) ≈ g(-d), so g(d) ≈ (transitions at offset d) / 2.

For a random sequence, the expected transitions at offset d is (n-|d|) * 2 * (1/2) * (1/2) = (n-|d|)/2.
So expected g(d) ≈ (n-|d|)/4, and with dx = 2/n: g(d) * dx ≈ (n-|d|)/(2n) ≈ 1/2 for small d.

This matches our earlier calculation that random gives about 0.5, and we need to do much better.

For a "perfect" sequence with g(d) = constant for all d, we'd need g(d) = 0.25/dx = 0.25 * n/2 = n/8 (in unweighted terms). For n=250, that's 31.25, which isn't an integer. So we can't achieve perfect flatness with binary sequences.

But with non-binary (continuous) h values, we might be able to get closer.

OK so my plan is:

1. Use the subgradient/gradient method with the smooth max, but with better optimization (Adam-like).
2. Use gradient-guided pair moves.
3. Try to make g(d) as flat as possible (add a variance penalty).
4. Multiple restarts with different initializations.

Let me also consider: what if I add a secondary objective that penalizes the variance of g(d)? This would push the solution toward flat g(d), which is what we want.

f(h) = max_d g(d) + λ * Var(g)

This is a convex combination of the max and the variance, both of which we want to minimize. The variance term helps guide the optimization toward flat solutions.

Actually, since we've established that the average is 0.25, minimizing the variance is equivalent to minimizing the max (when the mean is fixed). But in practice, the variance penalty provides a smoother landscape for optimization.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)

def compute_g(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)

def gradient_smooth_max(h, n, alpha):
    """Compute gradient of smooth max approximation."""
    dx = 2.0 / n
    g = np.correlate(h, 1 - h, mode='full') * dx
    shifted = alpha * (g - g.max())
    p = np.exp(shifted)
    p /= p.sum()
    
    grad = np.zeros(n)
    dm = np.arange(2 * n - 1) - (n - 1)
    
    for m_idx in range(2 * n - 1):
        if p[m_idx] < 1e-14:
            continue
        d = dm[m_idx]
        i_lo = max(0, -d)
        i_hi = min(n - 1, n - 1 - d)
        if i_lo > i_hi:
            continue
        js = np.arange(i_lo, i_hi + 1)
        jd = js + d
        mask1 = (jd >= 0) & (jd < n)
        grad[js[mask1]] += p[m_idx] * (1.0 - h[jd[mask1]])
        jd2 = js - d
        mask2 = (jd2 >= 0) & (jd2 < n)
        grad[js[mask2]] -= p[m_idx] * h[jd2[mask2]]
    
    return grad * dx

def gradient_variance(h, n):
    """Gradient of sum of squared deviations of g from its mean."""
    dx = 2.0 / n
    g = np.correlate(h, 1 - h, mode='full') * dx
    mean_g = g.mean()
    # d(g(d))/dh[j] * 2 * (g(d) - mean_g) summed over d
    # Plus the mean derivative term... but if we fix the sum, the mean is constant.
    # Actually, let's just use: f = sum_d (g(d) - mean)^2
    # df/dh[j] = 2 * sum_d (g(d) - mean) * dg(d)/dh[j] - 2*mean * sum_d dg(d)/dh[j]
    # The second term is 2*mean * d(sum_d g(d))/dh[j]
    # We showed sum_d g(d) = dx * n^2/4 (constant!), so this term is 0.
    # So df/dh[j] = 2 * sum_d (g(d) - mean) * dg(d)/dh[j]
    
    # Compute dg(d)/dh[j] for all d, j - this is O(n^2)
    # Same structure as before
    dev = g - mean_g  # length 2n-1
    dm = np.arange(2 * n - 1) - (n - 1)
    grad = np.zeros(n)
    
    for m_idx in range(2 * n - 1):
        w = dev[m_idx]
        if abs(w) < 1e-14:
            continue
        d = dm[m_idx]
        i_lo = max(0, -d)
        i_hi = min(n - 1, n - 1 - d)
        if i_lo > i_hi:
            continue
        js = np.arange(i_lo, i_hi + 1)
        jd = js + d
        mask1 = (jd >= 0) & (jd < n)
        grad[js[mask1]] += w * (1.0 - h[jd[mask1]])
        jd2 = js - d
        mask2 = (jd2 >= 0) & (jd2 < n)
        grad[js[mask2]] -= w * h[jd2[mask2]]
    
    return 2.0 * grad * dx

def adam_optimize(h, n, deadline, lr=0.01, alpha_start=100, alpha_end=10000, n_steps=None):
    """Adam optimizer for the smooth max + variance objective."""
    m = np.zeros(n)
    v = np.zeros(n)
    t = 0
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    
    best_h = h.copy()
    best_c = compute_c5(h, n)
    
    if n_steps is None:
        n_steps = 10000
    
    for step in range(n_steps):
        if time.time() > deadline:
            break
        t += 1
        # Interpolate alpha
        frac = step / n_steps
        alpha = alpha_start * (alpha_end / alpha_start) ** frac
        
        # Compute gradient
        g_sm = gradient_smooth_max(h, n, alpha)
        g_var = gradient_variance(h, n)
        grad = g_sm + 0.1 * g_var  # weighted combination
        
        # Update Adam moments
        m = beta1 * m + (1 - beta1) * grad
        v = beta2 * v + (1 - beta2) * grad ** 2
        m_hat = m / (1 - beta1 ** t)
        v_hat = v / (1 - beta2 ** t)
        
        # Update
        h_new = h - lr * m_hat / (np.sqrt(v_hat) + eps)
        h_new = project_feasible(h_new, n)
        
        c = compute_c5(h_new, n)
        if c < best_c:
            best_c = c
            best_h = h_new.copy()
        
        h = h_new
    
    return best_h, best_c

    h = np.clip(h, 0.0, 1.0)

        if abs(diff) < 1e-13:
            break

            if s < 1e-14:

            if s < 1e-14:
                break

        g = np.correlate(x, 1 - x, mode='full') * dx

        return m + (sm + np.log(np.exp(shifted - sm).sum())) / alpha
    def cons_fun(x):
        return x.sum() - n / 2.0
    bounds = [(0.0, 1.0)] * n

                       constraints=cons,

    # F[k, m] involves h[k+d_m] and h[k-d_m]

    #   k = j - d_m or k = j + d_m
    # If h[i] changed: F[k, m] changes when k+d_m = i or k-d_m = i
    #   k = i - d_m or k = i + d_m

        if 0 <= j + d < n:

        # k = i - d (for k+d = i): F[i-d, m] += -delta
        if 0 <= i - d < n:
            F[i - d, m] -= delta
        
        # k = i + d (for k-d = i): F[i+d, m] += -delta

def binary_polish(h, n, deadline):
    target = n // 2
    idx = np.argsort(h)[::-1]
    h_bin = np.zeros(n)
    h_bin[idx[:target]] = 1.0
    best_c = compute_c5(h_bin, n)
    ones = list(np.where(h_bin == 1)[0])
    zeros = list(np.where(h_bin == 0)[0])
    for _ in range(40):
        if time.time() > deadline:
            break
        improved = False
        for z in zeros[:]:
            if time.time() > deadline:
                break
            for o in ones[:]:
                h_bin[z] = 1.0
                h_bin[o] = 0.0
                c = compute_c5(h_bin, n)
                if c < best_c - 1e-14:
                    best_c = c
                    ones[ones.index(o)] = z
                    zeros[zeros.index(z)] = o
                    improved = True
                else:
                    h_bin[z] = 0.0
                    h_bin[o] = 1.0
                if improved:
                    break
            if improved:
                break
        if not improved:
            break
    return h_bin, best_c

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    dl = t0 + budget_s - 5
    rng = np.random.RandomState(seed)
    try:
        h0 = np.array(initial_h_values, dtype=float).copy()
        n = len(h0)
    except Exception:
        n = 250
        h0 = np.full(n, 0.5)
    best_h = project_feasible(h0.copy(), n)
    best_c = compute_c5(best_h, n)
    # Phase 1: SLSQP with increasing alpha (15%)
    p1 = t0 + 0.15 * (budget_s - 5)
    h = best_h.copy()
    for alpha in [500, 2000, 10000, 50000, 500000, 5000000]:
        if time.time() > p1:
            break
        h = slsqp_optimize(h, n, alpha, maxiter=200)
        c = compute_c5(h, n)
        if c < best_c:
            best_c = c
            best_h = h.copy()
    # Phase 2: Adam gradient (15%)
    p2 = t0 + 0.30 * (budget_s - 5)
    if time.time() < p2:
        h, c = gradient_adam(best_h.copy(), n, p2, lr=0.003)
        if c < best_c:
            best_c = c
            best_h = h.copy()
    # Phase 3: SLSQP polish (10%)
    p3 = t0 + 0.40 * (budget_s - 5)
    if time.time() < p3:
        for alpha in [2000000, 20000000]:
            if time.time() > p3:
                break
            h = slsqp_optimize(best_h.copy(), n, alpha, maxiter=200)
            c = compute_c5(h, n)
            if c < best_c:
                best_c = c
                best_h = h.copy()
    # Phase 4: Pair descent with gradient ordering (30%)
    p4 = t0 + 0.70 * (budget_s - 5)
    if time.time() < p4:
        h, c = pair_descent(best_h.copy(), n, p4, max_sweeps=400, K=12, use_gradient=True)
        if c < best_c:
            best_c = c
            best_h = h.copy()
    # Phase 5: Restart loop (20%)
    p5 = t0 + 0.90 * (budget_s - 5)
    if time.time() < p5:
        for r in range(10):
            if time.time() > p5:
                break
            pert = rng.randn(n) * 0.03
            h_r = project_feasible(best_h + pert, n)
            h_r = slsqp_optimize(h_r, n, 500000, maxiter=100)
            h_r, c_r = pair_descent(h_r, n, min(time.time() + 40, p5), max_sweeps=80, K=10, use_gradient=True)
            c_r = compute_c5(h_r, n)
            if c_r < best_c:
                best_c = c_r
                best_h = h_r.copy()
    # Phase 6: Final polish (remaining)
    if time.time() < dl - 10:
        h, c = pair_descent(best_h.copy(), n, dl - 8, max_sweeps=100, K=14, use_gradient=False)
        if c < best_c:
            best_c = c
            best_h = h.copy()
    if time.time() < dl - 5:
        h = slsqp_optimize(best_h.copy(), n, 50000000, maxiter=200)
        c = compute_c5(h, n)
        if c < best_c:
            best_c = c
            best_h = h.copy()
    best_h = project_feasible(best_h, n)
    best_c = compute_c5(best_h, n)
    return best_h, best_c, n
