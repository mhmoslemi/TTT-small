  - As source: if i=j and j+k < n and h[j+k]=0: previously not counted (h[j]=0), now counted (h[j]=1, h[j+k]=0). L(k) increases by 1.
  - As target: if i=j-k ≥ 0 and h[j-k]=1: previously (j-k, j) had h[j-k]=1, h[j]=0 (counted in L). Now h[j]=1, not counted. L(k) decreases by 1.
  
  ΔL(k) = [j+k < n and h[j+k]=0] - [j-k ≥ 0 and h[j-k]=1]  (for 0→1 flip)

This gives O(n) update per flip (iterate over all k). For trying all n positions, that's O(n²) = 62500 total, which is the same as one full recomputation. So for local search (trying all single flips), incremental is the same cost as full recomputation. But for SA where we do one flip per iteration, incremental saves a factor of n.

Actually wait, for a single flip, the incremental update is O(n) while full recomputation is O(n²). So for SA (one flip per iteration), incremental is n× faster. That's 250× faster. So instead of 100,000 iterations/sec, we'd get 25,000,000 iterations/sec. That's way more than enough.

But implementing the incremental update correctly requires care. Let me just use full recomputation for simplicity and rely on the fact that n=250 is small enough.

Actually, let me benchmark mentally: np.correlate for n=250 in 'full' mode. The output is 499 elements. The computation is essentially a convolution-like operation. In practice, this is probably around 2-5 μs for numpy. So we can do about 200,000-500,000 iterations per second. In 1000 seconds, that's 200M-500M iterations. More than enough for SA.

from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14: break
            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-14: break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)

def make_binary(h, n, rng):
    """Convert continuous h to binary with exactly n/2 ones"""
    h = h.copy()
    # Sort by value descending, take top n/2
    target = n // 2
    # Add small random tie-breaking
    h_tiebreak = h + 0.001 * rng.randn(n)
    idx = np.argsort(h_tiebreak)[::-1]
    h_bin = np.zeros(n)
    h_bin[idx[:target]] = 1.0
    return h_bin

def sa_binary(h_bin, n, deadline, rng, T_init=0.02):
    """Simulated annealing on binary sequences with unit moves"""
    dx = 2.0 / n
    h = h_bin.astype(float).copy()
    cur_c = float(np.max(np.correlate(h, 1-h, mode='full')) * dx)
    best_c = cur_c
    best_h = h.copy()
    T = T_init
    T_min = 1e-4
    cool = 0.99999
    no_improve = 0
    max_no_improve = 50000
    
    while time.time() < deadline:
        j = rng.randint(n)
        h[j] = 1 - h[j]
        new_c = float(np.max(np.correlate(h, 1-h, mode='full')) * dx)
        delta = new_c - cur_c
        if delta < 0 or rng.random() < np.exp(-delta / T):
            cur_c = new_c
            if new_c < best_c:
                best_c = new_c
                best_h = h.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            h[j] = 1 - h[j]
            no_improve += 1
        
        T = max(T * cool, T_min)
        if no_improve > max_no_improve:
            T = T_init * 0.5  # reheat
            no_improve = 0
        
        if T < T_min * 1.01:
            break
    
    return best_h, best_c

def local_search_binary(h_bin, n, rng, max_rounds=20):
    """Hill climbing: flip bits that reduce C5"""
    dx = 2.0 / n
    h = h_bin.astype(float).copy()
    cur_c = float(np.max(np.correlate(h, 1-h, mode='full')) * dx)
    
    for _ in range(max_rounds):
        improved = False
        order = rng.permutation(n)
        for j in order:
            h[j] = 1 - h[j]
            new_c = float(np.max(np.correlate(h, 1-h, mode='full')) * dx)
            if new_c < cur_c:
                cur_c = new_c
                improved = True
            else:
                h[j] = 1 - h[j]
        if not improved:
            break
    return h, cur_c

def lbfgs_smooth(h, n, alpha, maxiter, deadline):
    dx = 2.0 / n
    def obj(x):
        c = np.correlate(x, 1 - x, mode='full') * dx
        m = c.max()
        shifted = alpha * (c - m)
        sm = shifted.max()
        val = m + (sm + np.log(np.exp(shifted - sm).sum())) / alpha
        val += 1e6 * (x.sum() - n / 2.0) ** 2
        return val
    def grad(x):
        c = np.correlate(x, 1 - x, mode='full')
        m_star = int(np.argmax(c))
        k = m_star - (n - 1)
        g = np.zeros(n)
        if k >= 0:
            g[k:] += (1.0 - x[:n-k])
            g[:n-k] += -x[k:]
        else:
            g[:n+k] += (1.0 - x[-k:])
            g[-k:] += -x[:n+k]
        g *= dx
        g += 2e6 * (x.sum() - n / 2.0)
        return g
    try:
        res = minimize(obj, h, method='L-BFGS-B', jac=grad,
                       bounds=[(0.0, 1.0)] * n,
                       options={'maxiter': maxiter, 'ftol': 1e-16, 'gtol': 1e-10})
        return project_feasible(res.x, n)
    except:
        return h
