- As first factor (h[i+d]): contributes (1-h[i-d]) if i-d >= 0, i.e., the term h[i]*(1-h[i-d])
- As second factor (1-h[i]): contributes -h[i+d] if i+d < n, i.e., the term -h[i+d]*h[i] = -h[i]*(h[i+d])

So ∂c/∂h[i] = dx * [(1-h[i-d])*1_{d≤i} - h[i+d]*1_{i≤n-1-d}] for d ≥ 0.

For d < 0: c = sum_{l=0}^{n-1+d} h[l]*(1-h[l-d]) * dx (where -d > 0)
Let d' = -d > 0. c = sum_{l=0}^{n-1-d'} h[l]*(1-h[l+d']) * dx
∂c/∂h[i]:
- h[i] appears as h[l] when l = i, contributing (1-h[i+d'])*dx if 0 ≤ i ≤ n-1-d'
- h[i] appears as (1-h[l+d']) when l+d' = i, i.e., l = i-d', contributing -h[i-d']*dx if 0 ≤ i-d' ≤ n-1-d', i.e., d' ≤ i ≤ n-1

So ∂c/∂h[i] = dx * [(1-h[i+d'])*1_{i≤n-1-d'} - h[i-d']]*1_{d'≤i}] for d < 0 (where d' = -d).

This is O(1) per (i, k) pair, so O(n²) to compute the full gradient. For n=250, that's 62500 operations, which is very fast.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full') * dx
    return float(np.max(c))

def proj(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(100):
        d = target - h.sum()
        if abs(d) < 1e-14:
            break
        if d > 0:
            r = 1.0 - h
            s = r.sum()
            if s < 1e-14:
                break
            h = h + (d / s) * r
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + (d / s) * h
    return np.clip(h, 0.0, 1.0)

def obj_fn(x, n, alpha):
    dx = 2.0 / n
    c = np.correlate(x, 1.0 - x, mode='full') * dx
    m = c.max()
    a = alpha * (c - m)
    am = a.max()
    return m + (am + np.log(np.sum(np.exp(a - am)))) / alpha

def sf(x, n):
    return x.sum() - n / 2.0

def sj(x, n):
    return np.ones(n)

def slsqp_run(h, n, alpha, maxiter=2000):
    bnd = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': sf, 'jac': sj, 'args': (n,)}]
    try:
        r = minimize(obj_fn, h, args=(n, alpha), method='SLSQP',
                     bounds=bnd, constraints=cons,
                     options={'maxiter': maxiter, 'ftol': 1e-18})
        return proj(r.x, n)
    except Exception:
        return h.copy()
