Also, I realize I should double-check my understanding of the problem. Let me re-read:

"Find a step function h: [0, 2] → [0, 1] that minimizes the overlap integral: C₅ = max_k ∫ h(x)(1 - h(x+k)) dx"

And the discretized evaluation: C₅ = max(np.correlate(h, 1-h, mode="full") * dx)

So the objective is indeed max of the full correlation between h and (1-h), scaled by dx.

Let me verify: np.correlate(h, 1-h, mode="full") has length 2n-1. The values range from shift -(n-1) to +(n-1). The max over all these shifts is what we minimize.

For a "good" solution, we want all the correlation values to be as small as possible (ideally all equal, by some averaging argument).

Now, there's a constraint: sum(h) = n/2. This means the "average value" of h is 1/2.

For the uniform solution h = 1/2 everywhere:
corr[k] = sum_i (1/2)(1-1/2) = n * 1/4 for k = n-1 (shift 0)
For other shifts, the number of valid terms is less.
Actually, for shift s=0: corr[n-1] = sum_i h[i](1-h[i]) = n * (1/2)(1/2) = n/4
For shift s≠0: corr[n-1+s] = sum_{valid i} h[i+s](1-h[i]) = (n-|s|) * (1/2)(1/2) = (n-|s|)/4

So max is n/4, and C5 = (n/4) * (2/n) = 1/2. As I computed before.

For a 0/1 solution with h being a "block" of n/2 ones followed by n/2 zeros:
The auto-correlation at shift s is n/2 - |s| for |s| < n/2, and 0 otherwise.
The overlap at shift s is n/2 - (n/2 - |s|) = |s| for |s| < n/2.
Max overlap is n/2 (at s = n/2 - 1, approximately).
C5 = (n/2) * (2/n) = 1. Much worse.

So we need a more spread-out solution. The initial solution (n=47, C5≈0.38) is already much better than both the uniform (0.5) and block (1.0) solutions.

    return np.clip(a + find_lambda(a, n), 0.0, 1.0)

    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    max_val = float(np.max(corr))
    active = np.where(corr >= max_val - 1e-10)[0]

        if lo2 < hi2:
            grad[lo2:hi2] -= h[lo2+s:hi2+s]
    grad *= dx / len(active)
    return grad

    best_c5 = evaluate_c5(h0)
    lam = find_lambda(h0, n)
    a = h0 - lam
    
    gamma = 0.03
    momentum = 0.9

    stuck = 0

        t += 1
        h = h_from_a(a, n)

        if c5 < best_c5 - 1e-12:
            best_c5 = c5
            best_h = h.copy()

            t = 0
