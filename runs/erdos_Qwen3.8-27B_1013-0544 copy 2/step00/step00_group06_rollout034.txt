OK wait, I think there's an issue with my delta computation. Let me re-derive it carefully.

The correlation at lag k (correlate index m = k + n - 1) is:
C_k = sum_{i: 0≤i<n, 0≤i+k<n} h[i+k] * (1-h[i])

Note: I'm using the convention that correlate(a, v, k) = sum a[i+k] * v[i], which means:
C_k = sum_i h[i+k] * (1-h[i]) where both i and i+k are in [0, n-1].

When we change h[i] from 1 to 0 and h[j] from 0 to 1:

Effect on C_k:
- h[i] appears as h[i+k] when the "first" index in the sum is i-k: term is h[i] * (1-h[i-k]), contributes (1-h[i-k]) before, 0 after. Change: -(1-h[i-k]) if 0≤i-k<n.
- h[i] appears as (1-h[i]) when the "second" index (i in the sum) is i: term is h[i+k'] * (1-h[i]) where i+k' = some valid index. Wait, I'm getting confused.

Let me use different variable names. Let me write:
C_k = sum_{s} h[s] * (1-h[s-k])  ... NO, that's not right either.

OK let me be very precise. np.correlate(a, v, 'full') gives:
out[m] = sum_n a[n] * v[n + m - (len(v)-1)]  ... no, let me just look it up.

From numpy docs: 
c_{ij} = \sum_k a_{k+i} \overline{b_{k+j}}

For the 'full' mode with same-length arrays a and v (both length n):
The result has length 2n-1.
result[i] = \sum_k a[k] * v[k + i - (n-1)]  ... 

Actually, I think the cleanest way is:
result[m] = \sum_k a[k] * v[k + m - n + 1]  for m = 0, ..., 2n-2
This means the "lag" is (m - n + 1).

So result[m] = \sum_k a[k] * v[k + (m-n+1)]

With a = h, v = 1-h:
result[m] = \sum_k h[k] * (1-h[k + m - n + 1])

where the sum is over all k such that 0 ≤ k < n and 0 ≤ k + m - n + 1 < n.

Let lag = m - (n-1). Then:
result[m] = \sum_k h[k] * (1-h[k + lag])
where 0 ≤ k < n and 0 ≤ k + lag < n.

So for a given lag L:
C_L = \sum_k h[k] * (1-h[k+L])  for k in [max(0, -L), min(n, n-L))

Now, the change when h[i]: 1→0, h[j]: 0→1:

C_L = \sum_k h[k] - \sum_k h[k] * h[k+L]

Change in \sum_k h[k] over valid range:
- Position i: if i is in valid range for first factor, loses 1. Valid range for k: max(0,-L) ≤ k < min(n, n-L). So i is valid if max(0,-L) ≤ i < min(n, n-L).
