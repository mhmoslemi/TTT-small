For k > 0: sum_i s[i+k] = sum_{j=k}^{n-1} s[j], sum_i s[i] = sum_{j=0}^{n-1-k} s[j].
So sum_i s[i+k] - sum_i s[i] = sum_{j=n-k}^{n-1} s[j] - sum_{j=0}^{k-1} s[j].

And sum_i s[i+k]s[i] is the autocorrelation of s at lag k.

So corr[k] = (1/4)[(n-k) + (tail_sum - head_sum) - autocorr_s[k]]

The top-lag equalization idea:
Suppose the top K lags are k_1, ..., k_K with corr values c_1 ≥ c_2 ≥ ... ≥ c_K.
I want to find h' such that corr[k_j](h') = t for all j, where t is as small as possible.

This is an underdetermined system (K equations, n unknowns). I can add the constraint sum(h') = n/2 and 0 ≤ h' ≤ 1.

If K < n, I can solve this exactly (or approximately) using optimization.

But the equations are quadratic (corr is quadratic in h), so it's a system of quadratic equations. This is hard in general.

However, if h is close to binary, I can linearize:
corr[k](h + δ) ≈ corr[k](h) + J_k · δ
where J_k is the Jacobian of corr[k] at h.

Then I have K linear equations in n unknowns, plus the constraint sum(δ) = 0 and |δ| small.
I can solve this as a least-squares problem: minimize ||J δ - (t - c)||² subject to sum(δ) = 0.

This gives a direction to move. Then I do a line search.

This is essentially the subgradient method but using ALL top lags simultaneously (weighted equally) rather than just the argmax.

def project_feasible(x, target):
    """Project x onto {h: 0<=h<=1, sum(h)=target}"""
    n = len(x)
