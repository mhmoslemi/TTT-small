```python
    # Compute smooth max value and weights
    m = np.max(corr)
    shifted = np.clip(beta * (corr - m), -500, 500)
    exp_s = np.exp(shifted)
    w = exp_s / exp_s.sum()
    val = (m + np.log(exp_s.sum()) / beta) * dx
    
    # Compute gradient
    grad = np.zeros(n)
    n_corr = len(corr)  # 2n-1
    offset = n - 1
    
    for k_idx in range(n_corr):
        wk = w[k_idx]
        if wk < 1e-12:
            continue
        lag = k_idx - offset
        if lag == 0:
            # corr = sum h[i]*(1-h[i]) = sum h - sum h^2
            # d/dh[i] = 1 - 2*h[i]
            grad += wk * (1.0 - 2.0 * h)
        elif lag > 0:
            # corr = sum_{i=0}^{n-1-lag} h[i+lag]*(1-h[i])
            # d/dh[j] = (1-h[j-lag]) for j in [lag, n-1]
            #          - h[j+lag] for j in [0, n-1-lag]
            grad[lag:] += wk * (1.0 - h[:-lag])
            grad[:-lag] -= wk * h[lag:]
        else:
            la = -lag
            # corr = sum_{m=0}^{n-1-la} h[m]*(1-h[m+la])
            # d/dh[j] = (1-h[j+la]) for j in [0, n-1-la]
            #          - h[j-la] for j in [la, n-1]
            grad[:-la] += wk * (1.0 - h[la:])
            grad[la:] -= wk * h[:-la]
    
    return val, grad * dx
```

This is O(n * (2n-1)) = O(n^2) per gradient evaluation, which for n=70 is about 10,000 operations - very fast.

Now let me design the full algorithm:

1. Start from initial_h_values
2. Phase 1: SLSQP with analytical gradient, continuation on beta
3. Phase 2: Corrected subgradient with top-K lags, momentum
4. Phase 3: SLSQP polish
5. Phase 4: Try different resolutions
6. Phase 5: Final subgradient polish

Let me also add some diverse restarts to avoid local optima.

One more thought: the problem is symmetric in the sense that if h is a solution, then 1-h is also a solution (since ∫(1-h) = 2-1 = 1, and the overlap (1-h)(x)*h(x+k) is the same as h(x+k)*(1-h)(x) which is just a different lag). Actually that's not quite right because the integral domain changes.

Let me also think about special structures. If h is periodic with period p (in the discrete sense, h[i+p] = h[i] for i < n-p), then the overlap at lag p would be the same as at lag 0. This might not be helpful.

What about h being a "sawtooth" or "triangle wave"? These have known autocorrelation properties.
