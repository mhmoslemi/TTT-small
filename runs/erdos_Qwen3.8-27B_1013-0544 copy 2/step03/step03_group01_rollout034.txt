  Total: d*(1-2h[i]+d) + d*(2h[j]+d-1) = d*(1-2h[i]+d+2h[j]+d-1) = d*(2h[j]-2h[i]+2d) = 2d*(h[j]-h[i]+d)

- For m in 1..n-1:
  corr[n-1±m] += d*(1-h[i+m]-h[i-m]) + (-d)*(1-h[j+m]-h[j-m])
  = d*(1-h[i+m]-h[i-m]-1+h[j+m]+h[j-m])
  = d*(h[j+m]+h[j-m]-h[i+m]-h[i-m])

This is very clean! The update for a pair move is:
- corr[n-1] += 2d*(h[j]-h[i]+d)
- corr[n-1±m] += d*(h[j+m]+h[j-m]-h[i+m]-h[i-m]) for m=1..n-1 (with h[out-of-range]=0)

And we can compute C₅ = max(corr) after the update.

This makes each pair move evaluation O(n) instead of O(n²)! That's a huge speedup.

                update_best(h_ils, n_b)

    # Phase 3: Try different n and structures
    n_tries = [50, 60, 80, 120, 160]
    for n in n_tries:
        if time.time() > deadline - 25:
            break
        starts = []
        starts.append(make_binary(n, rng))
        starts.append(make_tm(n))
        starts.append(make_tm(n, amp=0.35))
        starts.append(project_feasible(make_sine(n, 3, 0.4), n))
        starts.append(project_feasible(make_sine(n, 7, 0.3), n))
        for s in starts:
            if time.time() > deadline - 15:
                break
            s = project_feasible(s, n)
            c0 = compute_c5(s, n)
            if c0 < 0.44:
                dl = min(deadline - 12, time.time() + 20)
                s, c = greedy_ls(s, n, dl, rng)
                c = compute_c5(s, n)
                if c < best_c:
                    best_c = c
                    best_h = s.copy()

    # Phase 4: Final polish on overall best
    if best_h is not None:
        n = len(best_h)
        if time.time() < deadline - 8:
            best_h, _ = greedy_ls(best_h, n, deadline - 3, rng,
                                  deltas=[0.02, 0.01, 0.005, 0.002, 0.001, 0.0005])
        best_h = project_feasible(best_h, n)
        best_c = compute_c5(best_h, n)

    if best_h is None:
        best_h = project_feasible(np.full(n_init, 0.5), n_init)
        best_c = compute_c5(best_h, n_init)

    return best_h, best_c, len(best_h)
