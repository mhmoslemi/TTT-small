### 1. Approach and Rationale  
The central idea is to minimize the AC1 upper bound using a geometric gradient descent approach that leverages the discreteness of the convolution maximum. Unlike the root-constant sequence or genetic algorithm, this method focuses on systematically reducing the score by iteratively adjusting the sequence coefficients based on the gradient of the objective function. The AC1 score is defined as `2 * n * max_b / (sum_a^2)`, where `max_b` is the maximum of the full self-convolution (`np.convolve(a, a, mode="full")`) and `sum_a` is the sum of the coefficients. The gradient estimation is approximated using finite differences at the Lag where the convolution achieves its maximum, ensuring compactness and efficiency.  

The initial solution is based on the provided parent sequence `height_sequence_1` (length 4806), which yields a score of 1.570878. The target is 1.50274349, so an improvement is required. This method improves by directly targeting the score reduction through coordinated gradient updates. The key bottleneck is the high cost of full convolution evaluations, so the algorithm limits gradient estimation to only the Lag that defines `max_b`, reducing computational overhead. Non-negative coefficients are enforced, and values are clipped to [0, 1000], consistent with the evaluator's bounds.  

Limitations include the approximate gradient due to the nondifferentiability at the convolution maximum, potential sensitivity to initial conditions, and O(n) convolution evaluations per gradient step. Convexity is not claimed, so local minima may exist, but the update rule aims to exploit global features.

### 2. Mathematical Specification  
The objective minimization is: min s = 2 * n * max_k c_k / (sum_{i=1}^n a_i)^2, where \( \mathbf{a} = (a_1, \ldots, a_n) \) is the sequence vector, c_k is the convolution coefficient at lag k (resulting from `np.convolve(a, a, mode="full")` with full indices from 0 to 2n-2), n is the sequence length (default 4806, from `height_sequence_1`).  

The sequence is parameterized as a vector **a** ∈ ℝ^n, with constraints:  
- Non-negativity: a_i ≥ 0 for all i  
- Upper bound: a_i ≤ 1000 for all i (evaluated in the fallback)  
- Sum constraint: After evaluator clipping, sum_a ≥ 0.01  

The score s is evaluated exactly via the provided `evaluate_sequence`. The gradient approximation is chosen because the max operator at k = k_max breaks differentiability. Instead, use finite differences to estimate partial derivatives of s with respect to a_i at k_max. This avoids full Jacobian computation, abating quadratic costs.  

Solver: Gradient descent with backtracking line search. Initialize with `height_sequence_1` if available. Determine k_max (argmax of indices 0 to 2n-2 where c_k = eval_sequence(candidate)[0]).  

Decision variables: a vector of coefficients.  
Objective function: Minimize s.  
Constraints: Non-negativity and upper bound enforced by the gradient update and fallback.  
Updates: Perform gradient steps with step size determined by a line search (Armijo) to ensure sufficient decrease.  
Exact evaluation: `evaluate_sequence` is called once per candidate in the optimizer for feasibility checks and full score computation.  
For gradient estimation: At each iteration, determine if k_max changes; only then compute finite differences at k_max, affecting the numerator via partial derivatives of c_k_max and sum across all coefficients.

**Compute Gradient Approximation**:
- For each i from 0 to n-1:
  - First perturbation: Set a_i' = a_i + delta, recompute all convolve, evaluate score s_+ = 2*n* new_max / (sum_a(new))^2

- Clip delta based on current gradient norm.

- If s(new) ≤ s_old + c * alpha * ||grad||^2 (c=1e-4), reduce alpha until met.
