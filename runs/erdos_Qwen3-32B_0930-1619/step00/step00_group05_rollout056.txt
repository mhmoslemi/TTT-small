ADAM requires the following steps:

Initialize first and second moment vectors m and v, with zero initialization. The hyperparameters are learning rate α, beta_1, beta_2, and epsilon. The default values could be α=0.001, beta_1=0.9, beta_2=0.999, eps=1e-8. Or any other values as decided.

In each iteration:

1. Compute gradient g_t.

2. Update m = beta_1*m + (1 - beta_1)*g_t.

3. Update v = beta_2*v + (1 - beta_2)*g_t^2.

4. Compute m_hat = m/(1 - beta_1^t), v_hat = v/(1 - beta_2^t).

5. Compute delta = -alpha * m_hat / (sqrt(v_hat) + eps).

6. Update h = h + delta.

Then clip and project.

But since the gradient is computed only for the maximum term, which changes as h changes, this approach is used.

So the code outline would be:

Initialize h as initial_h_values.

Compute dx = 2.0 / n.

Initialize ADAM parameters: m = 0, v = 0, t =0.

Record the best h and best C_5.

Within the time budget:

for each iteration:

    t +=1

    compute c = np.correlate(...)

    m0 = np.argmax(c)

    k0 = m0 - (n -1)

    perform adam step:

    v = beta_2 * v + (1 - beta_2) * (gradient **2)

    m_hat = m / (1 - beta_1**t)

    compute current C_5 as max(c) * dx

    update best_h and best_c5 if needed.

    check for early stopping (e.g., no improvement for 100 steps, then reduce alpha)

    check time budget and break if exceeded.
