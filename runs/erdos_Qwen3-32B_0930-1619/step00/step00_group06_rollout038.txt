We need to minimize C such that for all k, the integral for that k <= C.

The integral for each k is:

Thus, for each k, the constraint is:

1 - ∫ h(x) h(x +k) dx <= C.

Rearranged:

∫ h(x) h(x +k) dx >= 1 - C.

The problem is to minimize C.

The term integral h(x) h(x +k) dx can be expressed in terms of the outer product H of h with itself. For the discrete case, this would be the sum over i of h[i] * h[j], where j = i +k, multiplied by dx^2.

But this is a quadratic form in h, making the constraints quadratic. Thus, the problem is a quadratically constrained quadratic program (QCQP), which is non-convex due to the product terms.

X is positive semidefinite.

X_diagonal = h.

X_ii = h_i for all i.

import numpy as np
from scipy.optimize import minimize
import time

def run(seed=42, budget_s=1100, **kwargs):
    h = initial_h_values.copy()
    n_points = len(h)
    dx = 2.0 / n_points
    start_time = time.time()
    
    def objective(h_vec):
        corr = np.correlate(h_vec, 1.0 - h_vec, mode='full') * dx
        return np.max(corr)
    
    def constraint_sum(h_vec):
        return np.sum(h_vec) - n_points / 2

    bounds = [(0.0, 1.0) for _ in range(n_points)]
    constraints = [{'type': 'eq', 'fun': constraint_sum}]

    best_h = h.copy()
    best_c5 = objective(h)

    def store_best(result):
        nonlocal best_h, best_c5
        if result.success:
            corr = objective(result.x)
            if corr < best_c5:
                best_h = result.x.copy()
                best_c5 = corr

    # First optimization pass with L-BFGS-B
    result = minimize(objective, h, method='L-BFGS-B', bounds=bounds, constraints=constraints)
    store_best(result)
    elapsed = time.time() - start_time
    if elapsed >= budget_s:
        return best_h, best_c5, n_points

    # Second pass with SLSQP
    result = minimize(objective, best_h, method='SLSQP', bounds=bounds, constraints=constraints)
    store_best(result)
    elapsed = time.time() - start_time
    if elapsed >= budget_s:

    # Final check and return
    return best_h, best_c5, n_points
