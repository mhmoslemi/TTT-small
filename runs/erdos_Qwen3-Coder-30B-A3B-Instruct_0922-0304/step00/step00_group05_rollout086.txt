            # THAT works: for all lags that create max overlap, sum contribution to gradient:  
            # Lag k contributes: d/dh[i] = (1 - h[i+k]) when i can be used in marginal overlap
            # Assume we extract overlap over [k] now, take for k=0 to n-1  
            # indices overlap_values = corr[n-1:2*(n-1)+1]  
            # These in reality come from:
            # for k = 0 to n-1, term overlap_k = corr[n-1+k]  
            # =>
            # Partial derivative of overlap_k w.r.t h[i] is 1-h[i+k] IFF i+k < n  
            # Try direct strategy that restrict gradient to current overlaps
            # => Loop for valid i (i from 0 to n_points-1) and traverse lag k which contributes: 
            # Gradient[i] += delta_lag_k 
            # For sum_k: lag_k = overlap_k = sum_{i=0}^{n_points-1-k} h[i] (1-h[i+k])
            # so d/h[i] of this sum has terms (1-h[i+k]) with i+k<n points where i is really at place
            # for each index each within bounds 0 <= i <= n-1 and 0 <= i+k <= n-1 
            # => 0 <= k <= n-1-i. This holds i = 0 to n-1-k (so    k   <= n-1-i)  
            # entropy of gradient for h[i] =  sum_{k=0}^{n-1-i} (1-h[i+k]) for valid k such that i+k < n  
            # 
            # But let’s go faster by making one pass per block:
            # This way, we know corr[(n-1+k)] exists for each of these k .  
            # But need to extract proper gradient.  
            # => i from 0 to n_points-1 :   grad[i] += weight*1-h[i]  
            # But instance is involves current lags aligning  
            # We compute split from the existing correlations trick. 
            # For k, shift value index for overlapping with input k => [n_points-1+k]  
            # For all lags k = 0 to n_points-1 where overlap_k is maximum
            # For each such lag k:  
            # in lag k: h[i] (1 - h[i+k]) appears in sum., so for all 0 <= i <= n-1-k.  
            # Check that also p[i+k] exists (alt: i from 0 to n-1-k) 
            #   So add term: 1 - h[i+k] to grad[i] for i=0 to n-1-k 
            # For i from 0 to n-1, we calculate how many lags can insert this term. 
            # That is, for i from 0 to n-1, check which overlapping lags k=0 to n-1  
            # satisfy i+k < n and index (i+k) = i + k in [0, n-1] → i+k < n  
            # And also k must match max lag indices. 
            # So for each i from 0 to n-1:
            #   k from 0 to n-1:
            #     if i + k < n and lag_k in max_lags:
            #         grad[i] += (1 - h[i + k]) 
            # But this is rather slow and iterates over arrays and redundantly checks many overlapping terms.
            # For a faster way, compute: 
            # For overlapping with lag k match:
            # For valid k, set overlaps_k for 0 <= k <= n-1  
            # km = n-1 + k 
            # => derivative d_overlap_k / d h[i] = 1 - h[i+k] when i+k < n  
            # For such k we add grad[i] += 1-h[i+k] for i from 0 to n-1-k ... 
            # Well   
            # But to pick those max overlapping lags from    
            # Continue working direct. 
            lag = lag_idx - (n_points - 1)  # Convert to actual lag  
            # lag ranges from -n+1 to n-1. 
            # mapping: lag_idx = k + n - 1 -> lag = k - (n-1)  
            # For lag k from 0 to n-1, then lag_idx = n-1 + k
            # But what is correct way: we know actual indices that the maximum are in
            # start fixed.  
            # We expect the update:
            # For valid indices, set the i such that terms like (1-h[i+k]) are used.
            # These are where i is changed, and k = selected lag. 
            # For overlaps_k = sum_{i=0}^{n-lag-1} h[i] (1-h[i+k])
            # instance of classic transpose-juggling:
            #
            # t = (i+k)  
            # balance: i+k <= n-1 ⇒ k >= 0 = t - i  
            # i not selected independently, instead: for each i in [0, n-1],  
            #   we track where k and i are valid ( i+k in [0, n-1] ):
            #   So for each i: i+k ≤ n-1 
            #   For k = 0 to n-1: k = 0 to n-1 and i+k ≤ n-1 ⇒ i = 0 to n-1-k,  
            #   and add contribution 1-h[i+k] to gradient[i]  
            # For all valid k from 0 to n-1:  
            #   for i=0 to n-1-k: gradient[i] += 1-h[i+k]  
            # Let’s do this part one by one for lags corresponding to argmax overlap.  
            # Because we want gradients to apply to terms that ARE explictly maximum-dependent  
            # small steps for one final effect.
            # Avoid vectorization due to extra if but use the accumulation: 
            
            if lag < 0:
                # Possible to be redundant. This path is ignored
                continue  
            # For specific overlap_lag where overlap_lag_max
            # considering overlap of lag k = 0 to n-1, iteration over k:
            # Map to position first over k=0 to n-1 then i=0 to n-1-k 
            # gradient update for i = 0 to n-1-k, add term:  
            # grad[i] += (1-h[i+lag]) mostly but not all!  
            # We are explicit about that i, and i+lag indices is within bounds
            # For i = 0 to n_points - lag - 1, grad[i] += (1 - h[i + lag])  
            # Effect: Jacobian matrix of overlap w.r.t h    
            # But we can integrate gradient reduction if we are on the right track.
            # Minimum code reduced-form:
            start_idx = 0
            end_idx = n_points - lag  # i < end_idx  under 0-indexed [0, end_idx) 
            if end_idx <= 0:
                continue
            # relax not checking that started computations  
            # That's just differences in [start_idx, end_idx) so  
            # This handles directly getting: add gradient per presence  
            # Simple mean  for off-diagonal..  
            grad[start_idx:end_idx] += 1 - h[start_idx + lag:end_idx + lag] 
        # normalize gradient by number of terms that contributed  
        grad /= len(max_indices)  
        # update h   
        h -= lr * grad  
        # projection step: boundary and normalization  
        h = np.clip(h, 0, 1)
        # rescale  
        h *= (n_points / 2) / np.sum(h)
        
        # check for better solution
        current_c5 = evaluate_erdos_solution(h, dx)
        if current_c5 < best_c5:
            best_c5 = current_c5
            best_h = h.copy()
        else:
            patience += 1
            if patience > gamma_patience:
                patience = 0
                lr *= 0.1

    return best_h, best_c5, n_points
