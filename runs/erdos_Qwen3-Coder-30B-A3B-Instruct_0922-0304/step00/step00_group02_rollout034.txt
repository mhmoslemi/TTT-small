        # We will compute this as a full convolution:
        # h * (1 - h) over all lags
        # This gives:
        # O_k = sum_{i=0}^{n-1} h[i] * (1 - h[(i+k)%n])

        # The overlap function O_k is cor(h, 1-h, mode='full')
        # We need to multiply by dx = 2.0 / n_points
        overlaps = correlate(h_vec, comp_h, mode='full')  # length 2*n-1
        # Now we have overlaps at indices from -(n-1) to (n-1)
        # Center around zero lag
        # Extract the center n overlaps (shifts 0 to n-1)
        # we want:
        # O_k = sum h[i] * (1 - h[(i+k)%n]) for k=0 to n-1
        # Only need the positive and zero lags, because of symmetry in correlation
        
        # Actually compute the real support of lags: k = 0 to n-1.
        # The left half: negative lags are equivalent to positive lag (due to periodicity)
        # Here we use correlate with mode='full' and take the necessary slices

        # It's like the auto-correlation, but we're looking at h * (1-h)
        # So with mode='full', index from 0 to 2*n-2
        # From index (n-1) to (2*n-2), we have lags 0 to n-1 (positive lag)
        # From index 0 to n-2, we have lags -(n-1) to -1 (negative lag)

        # Let's simply take the maximum of all actual shift values

        # But we take overlapping lags for a single shift h against shifted 1-h

        return np.max(overlaps) * dx
