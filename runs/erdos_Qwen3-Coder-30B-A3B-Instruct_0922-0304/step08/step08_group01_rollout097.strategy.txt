### 2. Mathematical Specification

**Variables**:
- $h \in [0, 1]^{n_{\text{points}}}$: Step function to be optimized.
- $dx = \frac{2.0}{n_{\text{points}}}$.
- $C_5 = \max_k \left( \text{np.correlate}(h, 1 - h, \text{mode="full"}) \times dx \right)$.

**Objective**:
Minimize $C_5$ subject to:
1. $h[i] \in [0, 1]$ for all $i$.
2. $\sum_{i=0}^{n_{\text{points}}-1} h[i] = \frac{n_{\text{points}}}{2}$.

**Operations**:
1. **Bit Flip**: Set $h[i] \leftarrow 1 - h[i]$ for a randomly selected index.
2. **Gray Adjustment**: For a random index, adjust $h[i]$ by $\Delta$ with $\Delta \sim \text{Uniform}(-0.1, 0.1)$.
3. **Segment Shuffle**: Randomly select a segment of length $L$ and permute it.

**Acceptance Probability**:
$p(\Delta E, T) = \exp(-\Delta E / T)$, where $\Delta E = \text{new}_C5 - \text{old}_C5$.

def perturb(h):
    # Randomly select operation
    op = np.random.choice(['flip', 'adjust', 'shuffle'])
    
    if op == 'flip':
        i = np.random.randint(len(h))
        h[i] = 1 - h[i]
    elif op == 'adjust':
        i = np.random.randint(len(h))
        delta = np.random.uniform(-0.1, 0.1)
        h[i] += delta
    elif op == 'shuffle':
        length = np.random.randint(1, 5)
        i = np.random.randint(len(h) - length + 1)
        segment = h[i:i+length]
        np.random.shuffle(segment)
        h[i:i+length] = segment
