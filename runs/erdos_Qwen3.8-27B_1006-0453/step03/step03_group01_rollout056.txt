∂/∂h[i] sum_j h[j](1-h[j+k]) = (1-h[i+k]) - h[i-k] (with appropriate bounds)

More carefully, for the full correlation:
corr[m] = sum_j h[j] * (1-h[j + (m - (N-1))])

Let L = m - (N-1) be the lag.
corr[m] = sum_j h[j] * (1 - h[j+L]) where the sum is over valid j.

∂corr[m]/∂h[i] = (1 - h[i+L]) * [i+L valid] - h[i-L] * [i-L valid]

So the gradient contribution from lag L to position i is:
(1 - h[i+L]) if 0 <= i+L < N, minus h[i-L] if 0 <= i-L < N.

This is what the previous code does. Good.

Now, for the "max" objective, at the optimum, typically 1-3 lags are at the maximum. The gradient of max is just the gradient of the argmax component (or a convex combination if there's a tie).

So the most effective gradient is to just use the top-1 or top-2 lags. The previous code's softmax approach is actually suboptimal because it adds noise from non-max lags.

import time

def compute_c5_val(h, dx):
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_sum(h, target):
    h = h.copy()
    np.clip(h, 0.0, 1.0, out=h)
    s = float(h.sum())
    if abs(s - target) < 1e-12:
        return h
    if s > target:
        lo, hi = 0.0, 2.0
    else:
        lo, hi = -2.0, 0.0
    for _ in range(60):
        mid = 0.5 * (lo + hi)
        if float(np.clip(h - mid, 0.0, 1.0).sum()) > target:
            lo = mid
        else:
            hi = mid
    c = 0.5 * (lo + hi)
    h2 = h - c
    np.clip(h2, 0.0, 1.0, out=h2)
    return h2

def topK_grad(h, N, topK):
    dx = 2.0 / N
    corr = np.correlate(h, 1.0 - h, mode='full')
    center = N - 1
    # Get top K lags
    top_idx = np.argpartition(corr, -topK)[-topK:]
    v = np.zeros(N)
    for i in top_idx:
        L = i - center
        if L == 0:
            v += (1.0 - 2.0 * h)
        elif L > 0:
            v[L:] += (1.0 - h[:N-L])
            v[:N-L] -= h[L:]
        else:
            M = -L
            v[:N-M] += (1.0 - h[M:])
            v[M:] -= h[:N-M]
    c5 = float(corr.max()) * dx
    return v * dx, c5, top_idx

def optimize_one(h, N, target, deadline, rng):
    """Single optimization run with hard gradient and restarts."""
    dx = 2.0 / N
    best_h = h.copy()
    best_c5 = compute_c5_val(h, dx)
    v = np.zeros(N)
    lr = 0.05
    mom = 0.8
    it = 0
    stall = 0
    while time.time() < deadline:
        it += 1
        # Adaptive topK: start with 3, reduce to 1
        topK = 3 if it < 500 else (2 if it < 1500 else 1)
        g, c5v, _ = topK_grad(h, N, topK)

            best_c5 = c5v
            best_h = h.copy()
            stall = 0
        else:
            stall += 1
        
        # Momentum update
        v = mom * v + (1.0 - mom) * g

        h = project_sum(h_new, target)
        
        # Schedule

            lr *= 0.93
        if stall > 300:
            # Random restart perturbation

            v *= 0.1
            lr = 0.03
            stall = 0
        if lr < 1e-8:
            break
    return best_h, best_c5

    h = h.copy()

            v *= 0.2
            lr = max(lr * 0.7, 0.01)
