Let P_k = Σ_{i=0}^{n-1-k} h[i]*h[i+k] (autocorrelation)

corr_k = S_k - P_k

Note: S_0 = Σ h[i] = n/2 (by constraint)
S_k = S_{k-1} - h[n-k] (telescoping)

And P_k = Σ h[i]*h[i+k] is the autocorrelation.

So C₅ = max_k (S_k - P_k) * dx

At the optimum, we want all (S_k - P_k) to be as equal as possible (by the max-min principle).

For a "good" solution, the active set should include k=0 (since S_0 = n/2 and P_0 = Σ h[i]², so corr_0 = n/2 - Σ h[i]²).

If h takes values 0 and 1 (a step function), then Σ h[i]² = Σ h[i] = n/2, so corr_0 = 0. But the other k values will have corr_k > 0.

For a smoother h, corr_0 > 0 but the other corr_k might be more balanced.

        if tot < 1e-14:
            return h
        h = h + room * (diff / tot)
    else:

        elif k == 0:

    n = len(h)
    dx = 2.0 / n
    corr = get_corr(h)
    m = np.max(corr)
    val = m + np.log(np.sum(np.exp(T * (corr - m)))) / T
    return val * dx

def slsqp_step(h, T, n, maxiter=500, ftol=1e-14):
    def obj(x):
        return smooth_c5(x, T)
    def con_fun(x):
        return x.sum() - n / 2.0
    cons = [{'type': 'eq', 'fun': con_fun}]
    bnds = [(0.0, 1.0)] * n
    res = minimize(obj, h, method='SLSQP', bounds=bnds, constraints=cons,
                   options={'maxiter': maxiter, 'ftol': ftol})
    return project(np.clip(res.x, 0, 1), n)

            if abs(h.sum() - proj_before) > 1e-12:
