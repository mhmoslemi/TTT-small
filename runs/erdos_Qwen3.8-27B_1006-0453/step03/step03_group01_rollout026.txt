One idea: use the structure of the problem. The overlap at lag k is:
∫ h(x)(1-h(x+k)) dx = ∫h(x)dx - ∫h(x)h(x+k)dx = 1 - ∫h(x)h(x+k)dx

So minimizing max_k overlap is equivalent to maximizing min_k ∫h(x)h(x+k)dx.

This is a different way to look at it: we want the autocorrelation of h to be high at ALL lags. A function with high autocorrelation at all lags is close to a constant. But the constraint ∫h = 1 (average 0.5) with h ∈ [0,1] limits how "constant" it can be.

The optimal would be h ≡ 0.5 everywhere, giving overlap = ∫0.5*0.5 dx = 0.5 * 2 = 1... wait that's not right.

h ≡ 0.5: overlap at any k = ∫₀² 0.5*(1-0.5) dx = 0.25 * 2 = 0.5.

But we can do better by making h oscillate. If h alternates between 0 and 1 with period 1 (one full cycle per unit), then at k=1, h(x+k) = 1-h(x), so overlap = ∫h(1-h)dx = 0 (if h is exactly 0/1). But at k=0.5, overlap = ∫h(1-h)dx = 0 again (if h is exactly 0/1 with period 1). Wait, if h is 1 on [0,0.5) and 0 on [0.5,1) repeating, then:
- At k=0.5: h(x+0.5) = 1-h(x), so h(x)(1-h(x+0.5)) = h(x)*h(x) = h(x)². Overlap = ∫h²dx = 0.5 (half the area)
- At k=1: h(x+1) = h(x), so h(x)(1-h(x+1)) = 0. Overlap = 0.
- At k=0.25: partial overlap.

So the max overlap would be at k=0 and k close to period/2.

At k=0: ∫h(1-h)dx = ∫h - ∫h² = 1 - ∫h². For h ∈ {0,1}, ∫h² = ∫h = 1, so overlap at k=0 is 0.

Actually wait, for h ∈ {0,1}, h(1-h) = 0 everywhere! So the overlap at k=0 is 0. And for any k where h(x+k) = 1-h(x) almost everywhere, the overlap is also 0.

So for a {0,1}-valued function, the overlap is ∫h(x)(1-h(x+k))dx which is the measure of the set where h(x)=1 and h(x+k)=0.

This is the standard overlap problem! And the answer for {0,1}-valued functions on [0,2] with ∫h = 1 is known to be related to the Erdős problem.

For [0,2] with measure 1 (half the interval), it's similar.

    # Phase 4: Coordinate descent (200s)
    d4 = min(t0 + 750, deadline - 150)
    h, c5 = coord_descent(best_h.copy(), N, target, dx, d4, rng)
    if c5 < best_c5:
        best_c5 = c5
        best_h = h.copy()

    # Phase 5: Another perturb + top-1 subgrad (100s)
    d5 = min(t0 + 850, deadline - 100)
    h5 = best_h + rng.randn(N) * 0.015
    h5 = project_sum(h5, target)
    h5, c5 = subgrad_loop(h5, N, target, d5, 1, 0.03, 0.997, 30, rng)
    if c5 < best_c5:
        best_c5 = c5
        best_h = h5.copy()

    # Phase 6: Final coordinate descent (remaining - 80s)
    d6 = max(deadline - 80, d5 + 10)
    h, c5 = coord_descent(best_h.copy(), N, target, dx, d6, rng)
    if c5 < best_c5:
        best_c5 = c5
        best_h = h.copy()

    # Phase 7: Boundary sweep (last 80s)
    if time.time() < deadline - 5:
        best_h, best_c5 = boundary_sweep(best_h, N, target, dx, deadline - 3, rng)

    final_c5 = compute_c5(best_h, dx)
    return best_h, final_c5, N
