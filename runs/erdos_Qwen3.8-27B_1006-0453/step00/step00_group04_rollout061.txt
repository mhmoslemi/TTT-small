```python
            extra = int(n/2 - tm.sum())
            zeros = np.where(tm == 0)[0]
            tm[rng.choice(zeros, min(extra, len(zeros)), replace=False)] = 1
        elif tm.sum() > n/2:
            excess = int(tm.sum() - n/2)
            ones = np.where(tm == 1)[0]
            tm[rng.choice(ones, min(excess, len(ones)), replace=False)] = 0
        inits.append(tm.astype(float))
        
        for h0 in inits:
            if time.time() - t0 > budget_s * 0.85:
                break
            c5_0 = eval_c5(h0)
            if c5_0 < best_c5:
                best_c5 = c5_0
                best_h = h0.copy()
                best_n = n
            
            # Local search
            h_ls = local_search(h0, n, n_time * 0.5, rng)
            c5_ls = eval_c5(h_ls)
            if c5_ls < best_c5:
                best_c5 = c5_ls
                best_h = h_ls.copy()
                best_n = n
            
            # SLSQP refinement (for continuous)
            if n <= 200:
                h_sl = slsqp_refine(h_ls, n, time.time() - t0, budget_s)
                if h_sl is not None:
                    c5_sl = eval_c5(h_sl)
                    if c5_sl < best_c5:
                        best_c5 = c5_sl
                        best_h = h_sl.copy()
                        best_n = n
    
    return best_h, best_c5, best_n
```

Now let me implement the local search and SLSQP:

For local search, I'll use a "steepest descent" approach on the binary sequence:
- Compute c10 for all lags
- Try all single-bit swaps (i→0, j→1 where h[i]=1, h[j]=0)
- Pick the one that most reduces max(c10)
- Repeat until no improvement or time runs out

For efficiency, I'll compute the effect of each swap in O(1) amortized time using precomputed arrays.

Actually, for n up to ~120, the O(n²) per iteration (trying all swaps) with ~100 iterations should be fine.

Let me think about the effect of a swap (i: 1→0, j: 0→1) on c10:

c10[s] = sum_{m=0}^{n-s-1} h[m]*(1-h[m+s])

Effect on c10[s]:
- h[i] changes from 1 to 0:
  - If i ≤ n-s-1 (i appears as h[m] term): contribution changes from 1*(1-h[i+s]) to 0. Delta: -(1-h[i+s]) = -1 if h[i+s]=0, 0 if h[i+s]=1.
  - If i-s ≥ 0 and i ≤ n-1 (i appears as h[m+s] where m=i-s): 1-h[i] changes from 0 to 1. The term h[i-s]*(1-h[i]) changes from h[i-s]*0 to h[i-s]*1. Delta: +h[i-s].
  
- h[j] changes from 0 to 1:
  - If j ≤ n-s-1: contribution changes from 0*(1-h[j+s]) to 1*(1-h[j+s]). Delta: +(1-h[j+s]).
  - If j-s ≥ 0: 1-h[j] changes from 1 to 0. The term h[j-s]*(1-h[j]) changes from h[j-s]*1 to 0. Delta: -h[j-s].

So Δc10[s] = [-(1-h[i+s]) * 1{i < n-s}] + [h[i-s] * 1{i-s ≥ 0, i-s ≤ n-s-1}]
            + [(1-h[j+s]) * 1{j < n-s}] + [-h[j-s] * 1{j-s ≥ 0, j-s ≤ n-s-1}]

This can be computed for all s at once:
- First term: -(1-h[i+s]) for s = 1 to min(n-1-i, n-1), 0 otherwise
- Second term: h[i-s] for s = 1 to min(i, n-1), 0 otherwise
- Third term: (1-h[j+s]) for s = 1 to min(n-1-j, n-1), 0 otherwise
- Fourth term: -h[j-s] for s = 1 to min(j, n-1), 0 otherwise

So for a given swap (i,j), I can compute Δc10 in O(n) time, then check if max(c10 + Δc10) < max(c10).

For all possible swaps, this is O(n² * n) = O(n³) per iteration. For n=100, that's 10⁶ per iteration. With 100 iterations, 10⁸. Should be OK in a few seconds.

Actually, let me vectorize: for a fixed i (the 1 being flipped), the changes for all possible j (zeros) can be computed simultaneously.

Let me think of a cleaner implementation:
