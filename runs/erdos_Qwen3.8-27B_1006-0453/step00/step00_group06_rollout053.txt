    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    c5_vals = corr * dx

    scale = c5_vals / temperature
    scale -= np.max(scale)
    w = np.exp(scale)
    w /= w.sum()

    # d(corr[m])/dh[i] = [0<=i-a<n]*(1-h[i-a]) - [0<=i+a<n]*h[i+a] where a = m-(n-1)
    grad = np.zeros(n)

        lo = max(0, a)
        hi = min(n, n + a)
        if lo < hi:

                grad[i] += wm * (1.0 - h[ja])
            ja2 = i + a
            if 0 <= ja2 < n:

- Actually, i-a ∈ [0,n-1] means i ∈ [a, a+n-1]. Intersected with [0,n-1].
- Similarly, i+a ∈ [0,n-1] means i ∈ [-a, n-1-a]. Intersected with [0,n-1].

For a >= 0:
- (1-h[i-a]) contributes to i ∈ [a, n-1], value is (1-h[i-a]) for i from a to n-1
- -h[i+a] contributes to i ∈ [0, n-1-a], value is -h[i+a] for i from 0 to n-1-a

For a < 0:
- (1-h[i-a]) = (1-h[i+|a|]) contributes to i ∈ [0, n-1-|a|], value is (1-h[i+|a|])
- -h[i+a] = -h[i-|a|] contributes to i ∈ [|a|, n-1], value is -h[i-|a|]

So for a >= 0:
grad[a:n] += (1-h[0:n-a])
grad[0:n-a] += -h[a:n]

For a < 0 (let b = -a > 0):
grad[0:n-b] += (1-h[b:n])
grad[b:n] += -h[0:n-b]

This is O(n) per lag, but we have O(n) lags total, so O(n^2) total. For n=95, that's ~9000 operations per gradient computation, which is very fast.
