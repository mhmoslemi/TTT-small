So we want to place m = n/2 positions in {0, ..., n-1} such that for every d, the number of p ∈ P with p+d ∉ P is as small as possible (uniformly over d).

This is equivalent to: for every d, #{p ∈ P : p+d ∈ P} is as large as possible (uniformly over d).

This is the "maximum minimum autocorrelation" problem for binary sequences!

The autocorrelation of h at lag d is:
autocor[d] = #{i : h[i]=h[i+d]} = #{i: h[i]=1, h[i+d]=1} + #{i: h[i]=0, h[i+d]=0}

And cor[d] = #{i: h[i]=1, h[i+d]=0} = m - #{i: h[i]=1, h[i+d]=1}

So minimizing max cor[d] is equivalent to minimizing max (m - autocor_ones[d]) = maximizing min autocor_ones[d].

Where autocor_ones[d] = #{i : h[i]=1, h[i+d]=1}.

This is a well-studied problem! It's related to "difference sets" in combinatorial design theory.

A (v, k, λ) difference set has the property that every nonzero difference appears exactly λ times. If we can find such a set, then autocor_ones[d] = λ for all nonzero d, giving perfect balance.

For v = n, k = n/2: we'd need a (n, n/2, λ) difference set where (k-1) = (v-1)*λ /... 

The parameters satisfy: k(k-1) = λ(v-1), so λ = k(k-1)/(v-1) = (n/2)(n/2-1)/(n-1).

import time
from scipy.optimize import minimize

def eval_c5(h):

    dx = 2.0 / n
    cor = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(cor) * dx)

def repair(h, n):
    h = np.array(h, dtype=float)
    h = np.clip(h, 0.0, 1.0)
    target = n * 0.5
    diff = target - h.sum()
    if abs(diff) > 1e-14:
        if diff > 0:
            free = np.where(h < 1.0)[0]
        else:
            free = np.where(h > 0.0)[0]
        if len(free) > 0:
            h[free] += diff / len(free)
            h = np.clip(h, 0.0, 1.0)
    return h

def local_search_swap(h, n, rng, t_deadline, max_iter=1000000):
    c = eval_c5(h)
    no_improve = 0
    stall_limit = 8000
    it = 0
    while it < max_iter and time.time() < t_deadline and no_improve < stall_limit:
        it += 1
        ones = np.where(h > 0.5)[0]

        j = zeros[rng.randint(len(zeros))]

        h[i], h[j] = old_j, old_i
        c_new = eval_c5(h)
        if c_new < c - 1e-14:
            c = c_new
            no_improve = 0
        else:
            h[i], h[j] = old_i, old_j
            no_improve += 1
    return h, c

def local_search_continuous(h, n, rng, t_deadline, max_iter=100):

        half_pos = rng.choice(

    except:
