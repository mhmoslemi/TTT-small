Wait, I realize there might be an issue with the "full" mode correlation. Let me double-check.

For arrays a and b of length n, np.correlate(a, b, mode="full") has length 2n-1.
result[k] = sum_{i} a[i] * b[i + k - (n-1)]

where the sum is over all i such that both i and i+k-(n-1) are valid indices.

So for k = n-1 (the middle): result[n-1] = sum_i a[i] * b[i] (standard dot product)
For k = n: result[n] = sum_i a[i] * b[i+1] for i = 0 to n-2
For k = n-2: result[n-2] = sum_i a[i] * b[i-1] for i = 1 to n-1

So the "lag" interpretation:
- result[n-1+m] = sum_{i=0}^{n-1-m} a[i] * b[i+m] for m ≥ 0
- result[n-1-m] = sum_{i=m}^{n-1} a[i] * b[i-m] for m ≥ 0

With a = h, b = 1-h:
- result[n-1] = sum h[i]*(1-h[i]) = 0 for binary
- result[n-1+m] = sum_{i=0}^{n-1-m} h[i]*(1-h[i+m]) for m ≥ 1
- result[n-1-m] = sum_{i=m}^{n-1} h[i]*(1-h[i-m]) for m ≥ 1

These are the "forward" and "backward" correlations. Both can be non-zero.

C₅ = max(result) * dx = max over all lags of these sums * dx.

For binary h, all values are non-negative (since h[i] ∈ {0,1} and (1-h[i+m]) ∈ {0,1}).

import numpy as np
import time

def corr_max(h):
    return float(np.max(np.correlate(h, 1 - h, mode="full")))

def make_binary(h, n, rng):
    h = (np.asarray(h, dtype=float) >= 0.5).astype(float)
    target = n // 2
    s = int(h.sum())
    if s > target:
        idx = np.where(h == 1)[0]
        perm = rng.permutation(s)[:s - target]
        h[idx[perm]] = 0.0
    elif s < target:
        idx = np.where(h == 0)[0]
        perm = rng.permutation(len(idx))[:target - s]
        h[idx[perm]] = 1.0
    return h

def greedy_search(h, n, deadline=None):
    dx = 2.0 / n
    c5 = corr_max(h) * dx
    changed = True
    while changed:
        if deadline is not None and time.time() > deadline:
            break
        changed = False
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        best_val = c5 + 1e-14
        best_pair = None
        for i in ones:
            for j in zeros:
                h[i], h[j] = h[j], h[i]
                v = corr_max(h) * dx
                h[i], h[j] = h[j], h[i]
                if v < best_val:
                    best_val = v
                    best_pair = (int(i), int(j))
        if best_pair is not None:
            a, b = best_pair
            h[a], h[b] = h[b], h[a]
            c5 = best_val
            changed = True
    return h, c5

def sa_pass(h, n, rng, T0, iters, deadline):
    dx = 2.0 / n
    c5 = corr_max(h) * dx
    T = T0

        if time.time() > deadline:
            break

        zeros = np.where(h == 0)[0]
        i = int(ones[rng.integers(len(ones))])
        j = int(zeros[rng.integers(len(zeros))])
        h[i], h[j] = h[j], h[i]

        else:

        T *= 0.99992
