result[n-1+k] = sum_j h[j] * (1-h)[j-k]

For k ≥ 0: j ranges from k to n-1, so:
result[n-1+k] = sum_{j=k}^{n-1} h[j] * (1-h)[j-k]

For k < 0: j ranges from 0 to n-1+k, so:
result[n-1+k] = sum_{j=0}^{n-1+k} h[j] * (1-h)[j-k]

In both cases, this is the sum of h[j]*(1-h[j-k]) over valid j, which is the number (weighted) of positions where h is 1 and h shifted by k is 0.

The maximum of this over all k (from -(n-1) to n-1) is what we're minimizing.

For a binary sequence, at shift k=0: sum h[j](1-h[j]) = 0 (since h is 0 or 1).
At shift k=1: count of j where h[j]=1 and h[j-1]=0.
At shift k=n-1: just h[n-1](1-h[0]) or h[0](1-h[n-1]).

The key shifts to worry about are small k (like 1, 2, 3) because they have the most terms.

For shift k=1: sum_{j=1}^{n-1} h[j]*(1-h[j-1])
This counts the number of "01" patterns in the sequence (a 0 followed by a 1).

For shift k=-1: sum_{j=0}^{n-2} h[j]*(1-h[j+1])
This counts the number of "10" patterns (a 1 followed by a 0).

So we need to minimize the maximum of:
- Number of "01" patterns at distance k
- Number of "10" patterns at distance k
- For all k

This is a combinatorial optimization problem. For a binary sequence, the total number of "01" patterns at distance 1 plus "10" patterns at distance 1 equals the number of transitions in the sequence.

To minimize the max, we want the transitions to be spread out over all distances.

This is reminiscent of "low-discrepancy" sequences or "m-sequences" (Maximal length LFSR sequences) which have the property that their autocorrelation is as flat as possible.

For a sequence of length n with n/2 ones, the ideal property would be that for every non-zero shift k, the number of matching positions is as close to n/4 as possible (since we have n/2 ones and n/2 zeros, the expected overlap is n/4).

For an m-sequence of period 2^m - 1, the autocorrelation is 1 for the trivial shift and -(2^m-1)/2 for all others. But our sequences aren't periodic in this way.

def compute_c5(h):
    dx = 2.0 / len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def raw_corr_max(h):
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr))

def project_feasible(h, n):
    h = np.clip(h, 0.0, 1.0)
    target = n * 0.5
    s = h.sum()
    diff = target - s
    if abs(diff) < 1e-12:
        return h
    if diff > 0:
        order = np.argsort(h)
        for idx in order:
            if diff <= 1e-12:
                break
            add = min(1.0 - h[idx], diff)
            h[idx] += add
            diff -= add
    else:
        order = np.argsort(-h)
        for idx in order:
            if diff >= -1e-12:
                break
            sub = min(h[idx], -diff)
            h[idx] -= sub
            diff += sub
    return h

def make_binary(n, rng):
    h = np.zeros(n)
    if n % 2 == 0:
        n_ones = n // 2
        idx = rng.choice(n, n_ones, replace=False)
        h[idx] = 1.0
    else:

        idx = rng.choice(n, n_ones, replace=False)
        h[idx] = 1.0
        zeros = np.setdiff1d(np.arange(n), idx)
        h[zeros[rng.randint(len(zeros))]] = 0.5
    return h

    bh, bn = None, 45

    # Phase 1: Use initial_h_values
    n = 45
    h0 = None
    try:
        if initial_h_values is not None:
            h0 = np.array(initial_h_values, dtype=float).copy()
            n = len(h0)
            h0 = project(h0, n)
    except NameError:
        pass

    if h0 is not None:
        sub_dl = min(t0 + 40, dl)
        h1, v1 = local_search(h0, n, sub_dl, rng)
        if v1 < bval:
            bval, bh, bn = v1, h1, n
        print(f"P1: n={n}, C5={v1*2.0/n:.6f}")

    # Phase 2: Structured starts
    for kind in range(4):
        if time.time() > dl - 30:
            break
        nt = 45 if kind < 2 else 44
        hi = struct_seq(nt, rng, kind)
        sub_dl = min(time.time() + 20, dl - 25)
        hr, vr = local_search(hi, nt, sub_dl, rng)
        if vr < bval:
            bval, bh, bn = vr, hr, nt
            print(f"S{kind}: n={nt}, C5={vr*2.0/nt:.6f}")

    # Phase 3: Random binary restarts
    n_opts = [44, 45, 46, 48, 50, 52, 56, 60, 64, 72]
    while time.time() < dl - 10:
        nt = int(rng.choice(n_opts))
        hi = bin_seq(nt, rng)
        remaining = dl - 10 - time.time()
        dur = min(15.0, remaining * 0.4)
        if dur < 2:
            break
        sub_dl = time.time() + dur
        hr, vr = local_search(hi, nt, sub_dl, rng)
        if vr < bval:
            bval, bh, bn = vr, hr, nt
            print(f"R: n={nt}, C5={vr*2.0/nt:.6f}")

    # Phase 4: Polish best solution
    if time.time() < dl - 2:
        bh, bv = polish(bh, bn, dl - 1, rng)
        bval = bv

    c5 = compute_c5(bh)
    print(f"FINAL: n={bn}, C5={c5:.6f}")
    return bh, c5, bn
