  C ≥ dx * Σ_j h[j] * (1-h[j+s_k]) for all k
  0 ≤ h[j] ≤ 1
  Σ h[j] = N/2

But wait, the constraint involves h[j] * (1-h[j+s_k]) which is NOT linear in h! It's bilinear. So it's not an LP.

However, if we fix one set of variables, it becomes linear. This suggests a block coordinate / alternating approach might work.

Alternatively, we can use the fact that h*(1-h) is concave in h on [0,1], so h*(1-h) ≤ h - h^2... but that doesn't directly help.

Actually, h*(1-h) = h - h^2 is concave (maximum at h=0.5). So Σ h[j]*(1-h[j+s]) is a sum of concave functions, which is concave. We want to minimize the max of concave functions, which is a non-convex problem.

For the specific structure, I think the basin hopping approach is the way to go.

import numpy as np
import time

def project_onto_constraint(h, target_sum):
    lo = h.min() - 1.5
    hi = h.max() + 1.5
    for _ in range(100):
        mid = 0.5 * (lo + hi)
        s = np.clip(h - mid, 0.0, 1.0).sum()
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - 0.5*(lo+hi), 0.0, 1.0)

def compute_c(h, dx):
    return np.correlate(h, 1.0-h, mode="full") * dx

def compute_subgrad(h, dx, n, c, tol_frac=0.05):
    C = c.max()
    active = np.where(c >= C - tol_frac * C)[0]
    if len(active) == 0:
        active = np.array([np.argmax(c)])
    grad = np.zeros(n)
    for k in active:
        s = n - 1 - k
        if s >= 0:
            g = np.zeros(n)
            g[:n-s] += (1.0 - h[s:])
            g[s:] -= h[:n-s]
        else:
            ss = -s
            g = np.zeros(n)
            g[ss:] += (1.0 - h[:n-ss])
            g[:n-ss] -= h[ss:]
        grad += g
    grad *= dx / len(active)
    return grad

def local_opt(h, dx, n, max_it=2000, lr=0.05):
    best = h.copy()
    best_C = compute_c(h, dx).max()
    target = n * 0.5
    mom = np.zeros(n)
    h = h.copy()
    for it in range(max_it):
        c = compute_c(h, dx)
        C = c.max()
        if C < best_C:
            best_C = C
            best = h.copy()
        g = compute_subgrad(h, dx, n, c)
        mom = 0.8 * mom - lr * g
        h = h + mom
        h = project_onto_constraint(h, target)
        lr *= 0.997
        if lr < 1e-7:
            break
    return best, best_C

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    end_t = t0 + budget_s

        if C_try < best_C:

    # Phase 2: basin hopping
    while time.time() < end_t - 30:

        hp = best_h + rng.normal(0, noise, n)
