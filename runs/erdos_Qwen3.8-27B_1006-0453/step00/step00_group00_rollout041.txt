The objective C₅ = max_k correlate(h, 1-h, k) * dx. The "full" mode gives 2n-1 values. The key insight is that we want to minimize the maximum of all these correlation values.

Actually, a better approach might be to use a smooth approximation of the max:
f_smooth(h) = (1/T) * log(sum_k exp(T * c_k))

For large T, this approximates the max. The gradient is:
grad f_smooth = sum_k (exp(T*c_k) / sum_k exp(T*c_k)) * grad c_k

This gives a convex combination of the gradients of all lags, weighted by their proximity to the maximum. This is more stable than just using the single active lag.

```python
def smooth_max_obj(h, T=50):
    n = len(h)
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode="full") * dx
    # Smooth max
    c_max = np.max(c)
    c_shifted = T * (c - c_max)
    c_exp = np.exp(c_shifted)
    c_sum = np.sum(c_exp)
    val = c_max + np.log(c_sum) / T
    return val

    c_max = np.max(c)
    c_shifted = T * (c - c_max)
    c_exp = np.exp(c_shifted)
    w = c_exp / np.sum(c_exp)  # weights
    
    # Gradient is weighted sum of gradients at each lag
    grad = np.zeros(n)
    for k in range(2*n-1):
        d = k - (n-1)
        if w[k] < 1e-10:
            continue
        for j in range(n):
            if 0 <= j+d and j+d < n:
                grad[j+d] += w[k] * (1.0 - h[j]) * dx
                grad[j] -= w[k] * h[j+d] * dx
    return grad
```

This is O(n^2) per gradient evaluation, which for n=45 is about 2000 operations. Should be fast enough.

Actually, I can vectorize the gradient computation:

For lag d, the gradient is:
grad_d[m] = (1-h[m-d]) * [0<=m-d<n] - h[m+d] * [0<=m+d<n]

This can be computed with shifts:
- term1[m] = (1-h[m-d]) if 0<=m-d<n, else 0
- term2[m] = h[m+d] if 0<=m+d<n, else 0

```python
def grad_all_lags(h):
    """Returns gradient for each lag, shape (2n-1, n)"""
    n = len(h)
    dx = 2.0 / n
    one_minus_h = 1.0 - h
    grads = np.zeros((2*n-1, n))
    for k in range(2*n-1):
        d = k - (n - 1)
        # term1: (1-h[m-d]) for valid m-d
        if d >= 0:
            # m >= d, so term1[m] = 1-h[m-d] for m in [d, n-1]
            grads[k, d:] = one_minus_h[:n-d]
            # m <= n-1-d, so term2[m] = h[m+d] for m in [0, n-1-d]
            if n-1-d >= 0:
                grads[k, :n-d] -= h[d:]
        else:
            dd = -d
            # m >= 0, m-d = m+dd < n, so m < n-dd
            # term1[m] = 1-h[m+dd] for m in [0, n-1-dd]
            grads[k, :n-dd] = one_minus_h[dd:]
            # m+d >= 0, m >= -d = dd, so m in [dd, n-1]
            # term2[m] = h[m-dd] for m in [dd, n-1]
            grads[k, dd:] -= h[:n-dd]
    return grads * dx
```

Then the smooth max gradient is:
grad = w @ grad_all_lags(h) where w has shape (2n-1,)

This is clean and vectorizable.

```python
    target = n / 2.0
    # Find t such that sum(clip(h+t, 0, 1)) = target
    # sum(clip(h+t, 0, 1)) is a piecewise linear function of t, increasing
    # Range: t from -max(h) to 1-min(h)
    
    lo = -np.max(h) - 1
    hi = 1.0 - np.min(h) + 1
    
    for _ in range(100):
        mid = (lo + hi) / 2
        s = np.sum(np.clip(h + mid, 0, 1))
        if s < target:
            lo = mid
        else:
            hi = mid
    t = (lo + hi) / 2
    return np.clip(h + t, 0, 1)
```

This bisection finds the right shift. The function sum(clip(h+t, 0, 1)) is monotonically increasing in t, so bisection works.
