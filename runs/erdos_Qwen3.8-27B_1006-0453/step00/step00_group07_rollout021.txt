Instead of just using the top lag, I can use a softmax smoothing:
f_smooth = (1/T) * log(sum(exp(T * corr_k)))

As T → ∞, this approaches the max. For finite T, it's smooth and has a well-defined gradient.

The gradient is:
∂f_smooth/∂h[m] = (1/T) * sum_k exp(T*corr_k) * ∂corr_k/∂h[m] / sum_k exp(T*corr_k)
= sum_k p_k * ∂corr_k/∂h[m]
where p_k = exp(T*corr_k) / sum_j exp(T*corr_j) (softmax weights)

This is better than just using the top lag because it gives a smoother gradient.

Let me implement this:

def optimize_smooth(h, S, max_iter=5000, T0=50, T_final=500):

    dx = 2.0 / n
    h = project_box_sum(h.copy(), S, n)
    best_t = np.inf
    best_h = h.copy()
    step = 0.01
    eps = 1e-8
    
    for it in range(max_iter):
        T = T0 + (T_final - T0) * it / max_iter
        corr = compute_corr(h) * dx
        t = np.max(corr)
        
        if t < best_t:
            best_t = t
            best_h = h.copy()
        
        # Softmax weights
        scaled = T * corr
        scaled -= np.max(scaled)
        p = np.exp(scaled)
        p /= np.sum(p)
        
        # Weighted gradient
        grad = np.zeros(n)
        # Only use lags with significant weight
        mask = p > 1e-6
        for idx in np.where(mask)[0]:
            d = idx - (n - 1)
            grad += p[idx] * vectorized_lag_gradient(h, d, n)
        
        # Projected gradient step
        for _ in range(10):  # backtracking line search
            h_trial = project_box_sum(h - step * grad, S, n)
            t_trial = np.max(compute_corr(h_trial)) * dx
            if t_trial < t - eps * np.linalg.norm(grad):
                break
            step *= 0.5
        else:
            break
        
        h = h_trial
        step = min(step * 1.05, 0.1)
    
    return best_h, best_t

    hi = 2.0 + float(np.max(x))
