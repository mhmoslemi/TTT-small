```python
def fast_coord_descent(h, t_end, max_sweeps=200):
    n = len(h)
    dx = 2.0 / n
    best_h = h.copy()
    best_c5 = compute_c5(best_h)
    m_full = 2 * n - 1
    
    for sweep in range(max_sweeps):
        if time.time() > t_end:
            break
        improved = False
        order = np.random.permutation(n)
        for m in order:
            v = best_h[m]
            # Compute delta for this coordinate
            # d[k] = (1-h[m+s])*I(0<=m+s<n) - h[m-s]*I(0<=m-s<n) where s = k-(n-1)
            delta = np.zeros(m_full)
            for k in range(m_full):
                s = k - (n - 1)
                d = 0.0
                if 0 <= m + s < n:
                    d += (1.0 - best_h[m + s])
                if 0 <= m - s < n:
                    d -= best_h[m - s]
                delta[k] = d
            
            # Current correlations
            corr = np.correlate(best_h, 1.0 - best_h, mode='full')
            
            # Minimize max_k (corr[k] + (x-v)*delta[k]) over x in [0,1]
            # This is convex in x, use binary search on subgradient
            def g(x):
                return np.max(corr + (x - v) * delta)
            
            # Ternary search (convex function)
            lo, hi = 0.0, 1.0
            for _ in range(40):
                m1 = lo + (hi - lo) / 3
                m2 = hi - (hi - lo) / 3
                if g(m1) < g(m2):
                    hi = m2
                else:
                    lo = m1
            
            x_new = (lo + hi) / 2
            if abs(x_new - v) < 1e-12:
                continue
            
            h_trial = best_h.copy()
            h_trial[m] = x_new

            if c5_trial < best_c5 - 1e-15:
```

```python
import numpy as np
from scipy.optimize import minimize, minimize_scalar
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def project_h(h):
    n = len(h)
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    s = h.sum()
    diff = target - s
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        room = 1.0 - h
        tot = room.sum()
        if tot < 1e-14:
            return h
        h = h + room * (diff / tot)
    else:
        if s < 1e-14:
            return h
        h = h * (1.0 + diff / s)
    return np.clip(h, 0.0, 1.0)
```

For the coordinate descent, the key optimization: instead of recomputing the full correlation each time, I can:
1. Maintain corr as a state
2. For each coordinate update, compute the delta vector (how corr changes)
3. After the update, project (which changes all coords) and recompute corr

Actually, projection changes all coords, so I have to recompute corr. But for n=160, np.correlate is very fast (maybe 10μs). The bottleneck is the 1D optimization.

For the 1D problem: minimize max_k (a_k + b_k * x) over x in [0,1]
where a_k = corr[k] - v*delta[k] and b_k = delta[k]

This is a max of lines. The minimum of a max of lines over an interval can be found by:
- If all b_k = 0: answer is x=v (no change)
- Otherwise: the optimal x is where the "upper envelope" has minimum value
- This occurs at a breakpoint (intersection of two lines) or at a boundary

Efficient algorithm:
1. Compute the value at x=0 and x=1
2. Use binary search: at each x, the subgradient is the sum of b_k for all k achieving the max
3. If subgradient > 0, move left; if < 0, move right; if 0 is in subgradient, we're at optimum

But for a max of lines, the subgradient at x is {sum of b_k for k in argmax(a_k + b_k*x)}.

Actually, for a strict max (unique argmax), the derivative is b_argmax. For the optimum:
- If b_argmax > 0 at current x, decreasing x helps → move left
- If b_argmax < 0, increasing x helps → move right
- If b_argmax = 0 or multiple argmax with mixed signs, we're at a breakpoint

The simplest robust approach: ternary search (since the function is convex). 40 iterations gives precision ~1/3^40 which is more than enough.

Each evaluation of the max is O(m_full) = O(319) for n=160.
40 evaluations per coordinate, 160 coordinates per sweep = 40*319*160 = 2M ops per sweep.
100 sweeps = 200M ops. In numpy, each "op" is vectorized, so it's really 40*160*100 = 640K vector evaluates of length 319. That's about 200M scalar ops, should take a few seconds.

Actually, the simplest correct approach: since the 1D problem is convex (max of affine functions), I can solve it exactly. The optimal x* is:
- If the slope of the max at x=v is 0 (or v is a breakpoint with subgradient containing 0), then x* = v
- Otherwise, x* is at a breakpoint or at a boundary (0 or 1)

The breakpoints of the max of lines {a_k + b_k * x} occur where two lines intersect:
a_i + b_i * x = a_j + b_j * x → x = (a_j - a_i)/(b_i - b_j)

I can find all breakpoints in [0,1], sort them, and evaluate the max at each. But there are O(n^2) breakpoints which is 25K for n=160. That's more than the 35 evaluations of ternary search.

Alternatively, I can use the "megiddo algorithm" or just do a binary search on the value level:
- Binary search on value v*: is there an x in [0,1] such that max_k(a_k + b_k*x) <= v*?
- This is equivalent to: does the intersection of halfspaces {x: a_k + b_k*x <= v* for all k} intersect [0,1]?
- Each halfspace gives: if b_k > 0: x <= (v* - a_k)/b_k; if b_k < 0: x >= (v* - a_k)/b_k; if b_k = 0: need a_k <= v*
- So the feasible x range is [max_{k:b_k<0} (v*-a_k)/b_k, min_{k:b_k>0} (v*-a_k)/b_k] intersected with [0,1]
- Feasible if: max of lower bounds <= min of upper bounds

This gives an exact solution in O(n) per binary search step, and ~50 binary search steps for machine precision. Total: O(n) per coordinate!

```python
def solve_1d_max_affine(a, b, x_lo=0.0, x_hi=1.0):
    """Minimize max_k(a[k] + b[k]*x) over x in [x_lo, x_hi]"""
    n = len(a)
    # Binary search on the optimal value v*
    # Lower bound: min of max(a + b*x_lo, max of a) ... 
    val_lo = np.max(a + b * x_lo)  # value at x_lo
    val_hi = np.max(a + b * x_hi)  # value at x_hi
    # Actually, the min value is between min(val_lo, val_hi) and max over k of a[k] (if x=0 is in range)
    # Let's just binary search
    lo_val = min(val_lo, val_hi)
    hi_val = max(val_lo, val_hi)
    
    for _ in range(60):
        mid = (lo_val + hi_val) / 2
        # Check feasibility: is there x in [x_lo, x_hi] with a[k] + b[k]*x <= mid for all k?
        lb = x_lo  # lower bound on x
        ub = x_hi  # upper bound on x
        feasible = True
        for k in range(n):
            if b[k] > 1e-15:
                # a[k] + b[k]*x <= mid → x <= (mid - a[k])/b[k]
                ub = min(ub, (mid - a[k]) / b[k])
            elif b[k] < -1e-15:
                # a[k] + b[k]*x <= mid → x >= (mid - a[k])/b[k] (b[k]<0 so inequality flips)
                lb = max(lb, (mid - a[k]) / b[k])
            else:
                if a[k] > mid + 1e-15:
                    feasible = False
                    break
        if lb <= ub:
            hi_val = mid
        else:
            lo_val = mid
    
    optimal_val = hi_val
    # Find x* at the optimal value
    mid = optimal_val
    lb = x_lo
    ub = x_hi
    for k in range(n):
        if b[k] > 1e-15:
            ub = min(ub, (mid - a[k]) / b[k])
        elif b[k] < -1e-15:
            lb = max(lb, (mid - a[k]) / b[k])
    x_star = (lb + ub) / 2
    x_star = np.clip(x_star, x_lo, x_hi)
    return x_star, optimal_val
```

```python
def solve_1d_max_affine(a, b, x_lo=0.0, x_hi=1.0):
    """Minimize max_k(a[k] + b[k]*x) over x in [x_lo, x_hi]"""
    # Binary search on value
    val_at_lo = np.max(a + b * x_lo)
    val_at_hi = np.max(a + b * x_hi)
    lo_val = min(val_at_lo, val_at_hi)
    hi_val = max(a + b * (x_lo + x_hi) / 2)  # rough upper bound
    hi_val = max(hi_val, val_at_lo, val_at_hi)
    
    # Actually, a better upper bound: max_k a[k] + max_k |b[k]| (over [0,1])
    hi_val = np.max(a) + np.max(np.abs(b))
    
    pos_mask = b > 1e-15
    neg_mask = b < -1e-15
    
    for _ in range(50):
        mid = (lo_val + hi_val) / 2
        # Upper bound on x from positive b: x <= (mid - a[k])/b[k]
        ub_pos = (mid - a[pos_mask]) / b[pos_mask]
        # Lower bound on x from negative b: x >= (mid - a[k])/b[k]
        lb_neg = (mid - a[neg_mask]) / b[neg_mask]
        
        ub = min(x_hi, np.min(ub_pos)) if np.any(pos_mask) else x_hi
        lb = max(x_lo, np.max(lb_neg)) if np.any(neg_mask) else x_lo
        
        # Check zero-b entries
        zero_mask = ~(pos_mask | neg_mask)
        if np.any(zero_mask) and np.max(a[zero_mask]) > mid:
            lb = x_hi + 1  # infeasible
        
        if lb <= ub:
            hi_val = mid
        else:
            lo_val = mid
    
    optimal_val = hi_val
    # Find x*
    mid = optimal_val
    ub_pos = (mid - a[pos_mask]) / b[pos_mask]
    lb_neg = (mid - a[neg_mask]) / b[neg_mask]
    ub = min(x_hi, np.min(ub_pos)) if np.any(pos_mask) else x_hi
    lb = max(x_lo, np.max(lb_neg)) if np.any(neg_mask) else x_lo
    x_star = np.clip((lb + ub) / 2, x_lo, x_hi)
```

```python
            contrib_f = np.where(valid_f, 1.0 - best_h[ms[valid_f]], 0.0)

            contrib_s = np.where(valid_s2, -best_h[mss[valid_s2]], 0.0)
            
            delta = contrib_f + contrib_s
            
            # 1D problem: minimize max_k (corr[k] + (x-v)*delta[k]) over x in [0,1]
            # = minimize max_k ((corr[k] - v*delta[k]) + x*delta[k])
            a = corr - v * delta
            b = delta
            
            x_new, _ = solve_1d_max_affine(a, b)
            
            change = x_new - v

            corr = np.correlate(best_h, 1.0 - best_h, mode='full')

            improved = True
```

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def project_h(h):
    n = len(h)
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    diff = target - s
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        room = 1.0 - h
        tot = room.sum()
        if tot < 1e-14:
            return h
        h = h + room * (diff / tot)
    else:
        if s < 1e-14:
            return h
        h = h * (1.0 + diff / s)
    return np.clip(h, 0.0, 1.0)

def solve_1d_max_affine(a, b):
    """Minimize max_k(a[k] + b[k]*x) over x in [0,1]. Returns (x*, val*)."""
    n = len(a)
    pos_mask = b > 1e-15
    neg_mask = b < -1e-15
    
    # Quick check: if all b are ~0, no improvement
    if not (np.any(pos_mask) or np.any(neg_mask)):
        return 0.5, np.max(a)  # x doesn't matter
    
    val_lo = np.max(a)  # at x=0
    val_hi = np.max(a + b)  # at x=1
    lo_val = min(val_lo, val_hi) - np.max(np.abs(b))  # safety
    hi_val = max(val_lo, val_hi)
    
    for _ in range(50):
        mid = (lo_val + hi_val) / 2.0
        # Feasibility: exists x in [0,1] s.t. a[k]+b[k]*x <= mid for all k
        ub = 1.0
        lb = 0.0
        if np.any(pos_mask):
            ub = min(ub, np.min((mid - a[pos_mask]) / b[pos_mask]))
        if np.any(neg_mask):
            lb = max(lb, np.max((mid - a[neg_mask]) / b[neg_mask]))
        if lb <= ub + 1e-15:
            hi_val = mid
        else:
            lo_val = mid
    
    # Find x*
    mid = hi_val
    ub = 1.0
    lb = 0.0
    if np.any(pos_mask):
        ub = min(ub, np.min((mid - a[pos_mask]) / b[pos_mask]))
    if np.any(neg_mask):
        lb = max(lb, np.max((mid - a[neg_mask]) / b[neg_mask]))
    x_star = np.clip((lb + ub) / 2.0, 0.0, 1.0)
    return x_star, mid

def smooth_obj_grad(h, T, lam):

    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    mc = np.max(corr)
    Tc = T * (corr - mc)
    Tc -= np.max(Tc)

    w = exps / exps.sum()
    sm = mc + np.log(exps.sum()) / T
    val = dx * sm + lam * (h.sum() - n / 2.0) ** 2
    
    grad = np.zeros(n)
    m_full = 2 * n - 1
    lag_arr = np.arange(m_full) - n + 1

        lg = lag_arr[idx]
        wi = w[idx]
        if wi < 1e-15:
            continue
        if lg >= 0:
            if lg < n:
                grad[lg:] += wi * (1.0 - h[:n-lg])
            grad[:n-lg] += -wi * h[lg:]
        else:
            p = -lg
            grad[:n-p] += wi * (1.0 - h[p:])
            grad[p:] += -wi * h[:n-p]
    grad = dx * grad + 2.0 * lam * (h.sum() - n / 2.0)
    return val, grad
```

```python
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def project_h(h):
    n = len(h)
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    diff = target - s
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        room = 1.0 - h
        tot = room.sum()
        if tot < 1e-14:
            return h
        h = h + room * (diff / tot)
    else:
        if s < 1e-14:
            return h
        h = h * (1.0 + diff / s)
    return np.clip(h, 0.0, 1.0)

            grad[p:] += -wi * h[:n - p]

    """Minimize max(a + b*x) for x in [0,1]. Returns x*."""
    pos = b > 1e-14
    neg = b < -1e-14
    if not (np.any(pos) or np.any(neg)):
        return 0.5
    v0 = np.max(a)
    v1 = np.max(a + b)
    lo_val = min(v0, v1) - np.max(np.abs(b))
    hi_val = min(v0, v1)
    for _ in range(55):

        lb = 0.0
```

```python
import numpy as np
from scipy.optimize import minimize
import time

_OPT_T = 100.0
_OPT_LAM = 300.0


def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)


def project_h(h):
    n = len(h)
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    diff = target - s
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        room = 1.0 - h
        tot = room.sum()
        if tot < 1e-14:
            return h
        h = h + room * (diff / tot)
    else:
        if s < 1e-14:
            return h
        h = h * (1.0 + diff / s)
    return np.clip(h, 0.0, 1.0)


def smooth_obj_grad(h, T, lam):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    mc = np.max(corr)
    Tc = T * (corr - mc)
    Tc -= np.max(Tc)
    exps = np.exp(Tc)
    w = exps / exps.sum()
    sm = mc + np.log(exps.sum()) / T
    val = dx * sm + lam * (h.sum() - n / 2.0) ** 2
    grad = np.zeros(n)
    m_full = 2 * n - 1
    lag_arr = np.arange(m_full) - n + 1
    for idx in range(m_full):
        lg = lag_arr[idx]
        wi = w[idx]
        if wi < 1e-15:
            continue
        if lg >= 0:
            if lg < n:
                grad[lg:] += wi * (1.0 - h[:n - lg])
            grad[:n - lg] += -wi * h[lg:]
        else:
            p = -lg
            grad[:n - p] += wi * (1.0 - h[p:])
            grad[p:] += -wi * h[:n - p]
    grad = dx * grad + 2.0 * lam * (h.sum() - n / 2.0)
    return val, grad


def _lbfgs_obj(x):
    return smooth_obj_grad(x, _OPT_T, _OPT_LAM)[0]


def _lbfgs_grad(x):
    return smooth_obj_grad(x, _OPT_T, _OPT_LAM)[1]


def lbfgs_opt(h0, T, lam, maxiter, ftol):
    global _OPT_T, _OPT_LAM
    _OPT_T = T
    _OPT_LAM = lam
    n = len(h0)
    x0 = project_h(h0)
    try:
        res = minimize(_lbfgs_obj, x0, jac=_lbfgs_grad, method='L-BFGS-B',
                       bounds=[(0.0, 1.0)] * n,
                       options={'maxiter': maxiter, 'ftol': ftol, 'gtol': 1e-10})
        return project_h(res.x)
    except Exception:
        return x0


def solve_1d(a, b):
    """Minimize max_k(a[k]+b[k]*x) for x in [0,1]. Returns x*."""
    pos = b > 1e-14
    neg = b < -1e-14
    if not (np.any(pos) or np.any(neg)):
        return 0.5
    v0 = np.max(a)
    v1 = np.max(a + b)
    lo_val = min(v0, v1) - np.max(np.abs(b))
    hi_val = min(v0, v1)
    for _ in range(55):
        mid = (lo_val + hi_val) / 2.0
        ub = 1.0
        lb = 0.0
        if np.any(pos):
            ub = min(ub, np.min((mid - a[pos]) / b[pos]))
        if np.any(neg):
            lb = max(lb, np.max((mid - a[neg]) / b[neg]))
        if lb <= ub + 1e-14:
            hi_val = mid
        else:
            lo_val = mid
    mid = hi_val
    ub = 1.0
    lb = 0.0
    if np.any(pos):
        ub = min(ub, np.min((mid - a[pos]) / b[pos]))
    if np.any(neg):
        lb = max(lb, np.max((mid - a[neg]) / b[neg]))
    return float(np.clip((lb + ub) / 2.0, 0.0, 1.0))


def coord_desc(h, t_end, max_sweeps=500):
    n = len(h)
    best_h = h.copy()
    corr = np.correlate(best_h, 1.0 - best_h, mode='full')
    best_c5 = np.max(corr) * (2.0 / n)
    m_full = 2 * n - 1
    shifts = np.arange(m_full) - (n - 1)
    for sweep in range(max_sweeps):
        if time.time() > t_end:
            break
        improved = False
        for m in np.random.permutation(n):
            v = best_h[m]
            ms = m + shifts
            mss = m - shifts
            vf = (ms >= 0) & (ms < n)
            vs = (mss >= 0) & (mss < n)
            delta = np.zeros(m_full)
            if np.any(vf):
                delta[vf] += 1.0 - best_h[ms[vf]]
            if np.any(vs):
                delta[vs] -= best_h[mss[vs]]
            x_new = solve_1d(corr - v * delta, delta)
            ch = x_new - v
            if abs(ch) < 1e-13:
                continue
            best_h[m] = x_new
            best_h = project_h(best_h)
            corr = np.correlate(best_h, 1.0 - best_h, mode='full')
            best_c5 = np.max(corr) * (2.0 / n)
            improved = True
        if not improved:
            break
    best_h = project_h(best_h)
    best_c5 = compute_c5(best_h)
    return best_h, best_c5


def run(seed=42, budget_s=1100, **kwargs):
    np.random.seed(seed)
    t0 = time.time()
    if 'initial_h_values' in globals() and initial_h_values is not None:
        best_h = np.array(initial_h_values, dtype=float).copy()
    else:

        best_h[:80] = 1.0
    n = len(best_h)
    best_h = project_h(best_h)
    best_c5 = compute_c5(best_h)

    # Phase 1: L-BFGS-B warmup
    p1 = t0 + budget_s * 0.07
    for T in [50, 300, 1500]:

        hc = lbfgs_opt(best_h, T, 200.0, 1500, 1e-17)

        if c5v < best_c5:
            best_c5, best_h = c5v, hc
    best_h, best_c5 = coord_desc(best_h, p1, 50)

    # Phase 2: Main coordinate descent (long)
    p2 = t0 + budget_s * 0.35
    best_h, best_c5 = coord_desc(best_h, p2, 5000)

    # Phase 3: L-BFGS-B refinement + coord
    p3 = t0 + budget_s * 0.50

        if time.time() > p3:
            break
        hc = lbfgs_opt(best_h, T, 200.0, 3000, 1e-17)
        c5v = compute_c5(hc)
        if c5v < best_c5:
            best_c5, best_h = c5v, hc
    best_h, best_c5 = coord_desc(best_h, p3, 300)

    # Phase 4: Basin hopping with coord descent refinement
    p4 = t0 + budget_s * 0.75
    wh, wc = best_h.copy(), best_c5
    for it in range(80):
        if time.time() > p4:
            break
        cool = max(0.0, 1.0 - it / 80.0)
        sc = 0.002 + 0.012 * cool
        hp = project_h(wh + sc * np.random.randn(n))
        T_bh = max(500, int(5000 * cool))
        hc = lbfgs_opt(hp, T_bh, 200.0, 800, 1e-16)
        hc, cv = coord_desc(hc, min(time.time() + 1.0, p4), 25)
        temp = 0.00015 * cool + 0.00003
        accept = cv < wc or (cv < wc + 0.003 and np.random.rand() < np.exp(-(cv - wc) / temp))
        if accept:
            wh, wc = hc, cv
            if cv < best_c5:
                best_h, best_c5 = hc, cv

    # Phase 5: Extended coordinate descent
    p5 = t0 + budget_s * 0.93
    best_h, best_c5 = coord_desc(best_h, p5, 5000)

    # Phase 6: Final high-T L-BFGS-B + tiny coord polish

        hc = lbfgs_opt(best_h, 200000, 500.0, 2000, 1e-17)
        c5v = compute_c5(hc)
        if c5v < best_c5:
            best_h, best_c5 = hc, c5v
    if time.time() < t0 + budget_s * 0.995:
        best_h, best_c5 = coord_desc(best_h, t0 + budget_s * 0.995, 200)

    best_h = project_h(best_h)
    best_c5 = compute_c5(best_h)
    return best_h, best_c5, n
```
