       = const + x*(1-h[i-L])

If only condition 2 holds (i < L, meaning i-L < 0):
corr_L = const + h[i+L] - h[i+L]*x
       = const + h[i+L]*(1-x)

So in all cases, corr_L is LINEAR in x = h[i]! There's no x^2 term!

Wait, that's because we're changing only ONE variable. The product h[j+L]*h[j] only involves h[i] at most once (as either h[j+L] or h[j], but not both unless j = i-L = i which means L=0).

Oh wait! When L = 0: corr_0 = sum_j h[j]*(1-h[j]) = sum_j h[j] - sum_j h[j]^2. Here h[i]^2 appears! So for L=0, it IS quadratic: corr_0 = const + x - x^2 (approximately, with other terms).

Let me redo for L=0: corr_0 = sum_j h[j] - h[j]^2. Changing h[i] to x:
corr_0 = (sum_{j≠i} h[j] - h[j]^2) + x - x^2
This IS quadratic in x.

For L ≠ 0: corr_L is linear in x (as I showed above).

Great, so for each coordinate i and each lag L≠0, corr_L is linear in h[i]. For L=0, it's quadratic.

This means for coordinate descent:
- For a given i, each corr_L (L≠0) is linear in h[i]
- corr_0 is quadratic in h[i]
- We want to minimize max_L corr_L * dx over h[i] ∈ [0,1]

This is a 1D problem: minimize max of (linear functions and one quadratic function) over [0,1].

We can solve this efficiently:
- The maximum of linear functions is a convex piecewise-linear function
- Adding a concave function (x-x^2 is concave for x in [0,1]) makes it nonconvex
- But in 1D, we can find the minimum by checking critical points

Actually, the max of lines is convex, and adding a concave function... the result is neither convex nor concave in general. But in 1D, we can solve it by:
1. Computing all the values and slopes of corr_L at x=0 and x=1
2. The max function changes slopes at breakpoints
3. The quadratic term has a well-known shape

This is doable but complex. Let me just use a simple approach: evaluate at a few points and use golden section or ternary search.

Actually, for speed, let me just precompute the linear coefficients for each (i, L) pair, then the 1D optimization is fast.

Let me restructure:

For coordinate i, define:
- a[k] = coefficient of x in corr_{lag[k]} (for the linear part, L≠0 it's the full coefficient; for L=0 it's the linear coefficient)
- b[k] = coefficient of x^2 in corr_{lag[k]} (only nonzero for k corresponding to L=0, where b = -1)
- c[k] = constant term (corr_L with h[i]=0)

Then corr_L(x) = c[k] + a[k]*x + b[k]*x^2

And we want to minimize max_k (c[k] + a[k]*x + b[k]*x^2) * dx over x ∈ [0,1].

Since only one b[k] is nonzero (for L=0), this is:
minimize max(max_{k≠k0}(c[k]+a[k]*x), c[k0]+a[k0]*x - x^2) over x∈[0,1]

This can be solved by considering the envelope of the lines and the single parabola.

import numpy as np
from scipy.optimize import minimize, minimize_scalar
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def project_h(h):
    n = len(h)
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(30):
        s = h.sum()
        diff = target - s
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-15
            cnt = mask.sum()
            if cnt == 0:
                break
            h[mask] += diff / cnt
        else:
            mask = h > 1e-15
            cnt = mask.sum()
            if cnt == 0:
                break
            h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

def smax_gradient(h, T, lam):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    mx = np.max(corr)
    z = T * (corr - mx)
    z -= z.max()
    e = np.exp(z)
    w = e / e.sum()
    val = dx * (mx + np.log(e.sum()) / T) + lam * (h.sum() - n/2.0)**2
    m = 2*n - 1
    lags = np.arange(m) - (n-1)
    grad = np.zeros(n)
    for k in range(m):
        lg = lags[k]
        wk = dx * w[k]
        if wk < 1e-14:
            continue
        if lg >= 0:
            grad[lg:] += wk * (1.0 - h[:n-lg])
            grad[:n-lg] -= wk * h[lg:]
        else:
            p = -lg
            grad[:n-p] += wk * (1.0 - h[p:])
            grad[p:] -= wk * h[:n-p]
    grad += 2.0 * lam * (h.sum() - n/2.0)
    return val, grad

def lbfgs_opt(h0, T, lam, maxit, ftol=1e-17):
    n = len(h0)
    x0 = project_h(h0)
    def F(x): return smax_gradient(x, T, lam)[0]
    def G(x): return smax_gradient(x, T, lam)[1]
    try:
        r = minimize(F, x0, jac=G, method='L-BFGS-B',
                     bounds=[(0.0,1.0)]*n,
                     options={'maxiter':maxit,'ftol':ftol,'gtol':1e-11})
        return project_h(r.x)
    except:
        return x0

def coord_descent(h, t_end, max_sweeps=500):
    n = len(h)
    best = h.copy()
    best_c5 = compute_c5(best)
    m = 2*n - 1
    lags = np.arange(m) - (n-1)
    for sw in range(max_sweeps):
        if time.time() > t_end:
            break
        improved = False
        order = np.random.permutation(n) if sw % 3 == 2 else np.arange(n)
        for i in order:
            hv = best[i]
            # Precompute linear/quadratic coefficients for corr_L as function of x=h[i]
            a = np.zeros(m)  # linear coeff
            b = np.zeros(m)  # quadratic coeff (only for lag=0)
            c = np.zeros(m)  # constant
            for k in range(m):
                lg = lags[k]
                # corr_lg = sum_{j=0}^{n-1-|lg|} h[j+|lg|]*(1-h[j]) for proper indexing
                # Compute contribution of h[i] to corr_lg
                # For lag L>=0: h[i] appears as h[j+L] if j=i-L (needs L<=i<n), and as h[j] if j=i (needs i<n-L)
                # For lag L<0 (P=-L): h[i] appears as h[j] if j=i (needs i<n-P), and as h[j-P]... 
                # Simplify: just compute corr with h[i]=0, h[i]=1, h[i]=0.5
                pass
            # Direct method: evaluate at 3 points and fit quadratic/linear
            best[i] = 0.0
            c0 = np.correlate(best, 1.0-best, mode='full')
            best[i] = 1.0
            c1 = np.correlate(best, 1.0-best, mode='full')
            best[i] = 0.5
            c05 = np.correlate(best, 1.0-best, mode='full')
            best[i] = hv
            # For L!=0: linear, so a_k = 2*(c1_k - c0_k), and c_k = c0_k
            # For L=0: quadratic, check if c05_k = 0.5*a_k + c0_k (linear) or different
            a = 2.0 * (c1 - c0)
            c = c0.copy()
            # Check which lags are quadratic (lag=0 only)
            b[k0] = 0.0  # will be -1 for lag 0
            # Actually just use: f(x) = c + a*x for all, except lag 0 where f(x)=c+a*x-x^2
            # Find the lag-0 index
            k0 = n - 1  # index where lag=0 in 'full' output
            b[k0] = -1.0
            # 1D minimization: minimize max_k f_k(x) over x in [0,1]
            def f1d(x):
                vals = c + a * x
                vals[k0] -= x*x
                return np.max(vals)
            # Use scalar minimization
            res = minimize_scalar(f1d, bounds=(0.0,1.0), method='bounded', options={'xatol':1e-12})
            x_new = res.x
            if abs(x_new - hv) > 1e-11:
                best[i] = x_new
                best = project_h(best)
                c5n = compute_c5(best)
                if c5n < best_c5 - 1e-15:
                    best_c5 = c5n
                    improved = True
        if not improved:
            break
    return best, best_c5

def resample_h(h, n_new):
    n_old = len(h)
    x_old = np.linspace(0, 2, n_old, endpoint=False) + 1.0/n_old
    x_new = np.linspace(0, 2, n_new, endpoint=False) + 1.0/n_new
    # Step function: value at x_new[i] is h at the old index
    idx = np.searchsorted(x_old, x_new, side='right') - 1
    idx = np.clip(idx, 0, n_old-1)
    h_new = h[idx].astype(float)
    return project_h(h_new)

def run(seed=42, budget_s=1100, **kwargs):
    np.random.seed(seed)
    t0 = time.time()
    
    # Get starting point
    if 'initial_h_values' in globals() and initial_h_values is not None:
        base_h = np.array(initial_h_values, dtype=float).copy()
    else:
        base_h = np.zeros(160)
        base_h[:80] = 1.0
        base_h = project_h(base_h)
    
    best_h = base_h.copy()
    best_c5 = compute_c5(base_h)
    best_n = len(base_h)
    
    # Try multiple resolutions
    n_options = [len(base_h)]
    for nn in [100, 128, 144, 176, 200, 240]:
        if nn != best_n:
            n_options.append(nn)
        if len(n_options) >= 5:
            break
    
    # Phase 1: Optimize at parent resolution with L-BFGS-B warm-up
    p1_end = t0 + budget_s * 0.12
    n_cur = best_n
    h_cur = best_h.copy()
    for T in [50, 200, 800, 3000]:
        if time.time() > p1_end:
            break
        h_cur = lbfgs_opt(h_cur, T, 200.0, 2000)
        c5v = compute_c5(h_cur)
        if c5v < best_c5:
            best_c5 = c5v
            best_h = h_cur.copy()
    
    # Phase 2: Coordinate descent at parent resolution
    p2_end = t0 + budget_s * 0.28
    h_cur, c5v = coord_descent(h_cur, p2_end, 400)
    if c5v < best_c5:
        best_c5 = c5v
        best_h = h_cur.copy()
    
    # Phase 3: Try other resolutions
    p3_end = t0 + budget_s * 0.50
    for nn in n_options:
        if time.time() > p3_end:
            break
        if nn == best_n and nn != len(base_h):
            continue
        if abs(nn - best_n) < 1 and nn != len(base_h):
            continue
        h_try = resample_h(best_h, nn)
        # Quick L-BFGS-B
        if time.time() < p3_end:
            h_try = lbfgs_opt(h_try, 1000, 100.0, 1500)
        if time.time() < p3_end:
            h_try, c5v = coord_descent(h_try, min(p3_end, time.time()+120), 200)
        if c5v < best_c5:
            best_c5 = c5v
            best_h = h_try.copy()
            best_n = nn
    
    # Phase 4: High-T L-BFGS-B refinement at best resolution
    p4_end = t0 + budget_s * 0.70
    h_cur = best_h.copy()
    for T in [3000, 10000, 40000, 120000]:
        if time.time() > p4_end:
            break
        h_cur = lbfgs_opt(h_cur, T, 300.0, 4000)
        c5v = compute_c5(h_cur)
        if c5v < best_c5:
            best_c5 = c5v
            best_h = h_cur.copy()
    
    # Phase 5: Basin hopping with L-BFGS-B
    p5_end = t0 + budget_s * 0.85
    n_h = len(best_h)
    work_h = best_h.copy()
    work_c5 = best_c5
    for it in range(40):
        if time.time() > p5_end:
            break
        cool = 1.0 - 0.92*(it/40.0)
        sc = 0.008 + 0.05*cool
        h_p = project_h(work_h + sc*np.random.randn(n_h))
        T_bh = int(2000*cool + 300)
        h_new = lbfgs_opt(h_p, T_bh, 200.0, 1200)
        c5v = compute_c5(h_new)
        temp = 0.0004*cool + 0.00005
        if c5v < work_c5 or np.random.rand() < np.exp(-max(0,c5v-work_c5)/max(temp,1e-10)):
            work_h = h_new
            work_c5 = c5v
            if c5v < best_c5:
                best_c5 = c5v
                best_h = h_new.copy()
    
    # Phase 6: Final coordinate descent polish
    p6_end = t0 + budget_s * 0.95
    best_h, best_c5 = coord_descent(best_h, p6_end, 400)
    
    # Final L-BFGS-B polish
    if time.time() < t0 + budget_s * 0.98:
        h_fin = lbfgs_opt(best_h, 50000, 500.0, 3000)
        c5v = compute_c5(h_fin)
        if c5v < best_c5:
            best_c5 = c5v
            best_h = h_fin
    
    best_h = project_h(best_h)
    best_c5 = compute_c5(best_h)
    return best_h, best_c5, len(best_h)
