- For each p in ones (190), we compute D[zeros,:] - a where a = c - D[p,:]

  - a is 759, broadcast to 190 × 759
  - (D[zeros,:] - a).max(axis=1) gives 190 values
  - Total per p: 190 × 759 = 144k ops
  - Total per sweep: 190 × 144k = 27.5M ops

In practice, numpy vectorizes this well. Let me estimate: 27.5M float ops in a vectorized numpy operation takes about 50-100ms. So ~20-40 sweeps per second. In 200s, we get 4000-8000 sweeps. That's good.

But we can do even better: vectorize over p too.
- D[ones,:] is 190 × 759
- c is 759
- base = c[None,:] - D[ones,:] → 190 × 759
- D[zeros,:] is 190 × 759
- cand = base[:,None,:] - D[zeros][None,:,:] → 190 × 190 × 759 = 27.5M floats = 220 MB

That's too much memory. So we need to loop over p (or a subset).

Alternative: for each p, the computation is O(n_zeros * (2N-1)) which is fast. Looping over 190 p's gives 190 * (190 * 759) = 27.5M total.

            h_p, _ = binary_search_full(h_pert, len(h_pert), d_p, max_sweeps=800, stall_limit=60)
        else:
            h_p, _ = binary_search_sampled(h_pert, len(h_pert), d_p, max_sweeps=400, sample_n=60, stall_limit=50)
        c5_p = compute_c5(h_p, len(h_p))
        if c5_p < best_c5:
            best_c5, best_h = c5_p, h_p.copy()

    # Phase 6: Final Nesterov + binary cleanup
    if time.time() < deadline - 8:
        dF = min(deadline - 4, time.time() + 40)
        hF = best_h.astype(float) + np.random.randn(len(best_h)) * 0.03
        hF = project_sum(hF, len(best_h) / 2.0)
        hF, c5F = nesterov_opt(hF, len(best_h), dF, k=60, lr0=0.008)
        if c5F < best_c5:
            best_c5, best_h = c5F, hF.copy()

    if time.time() < deadline - 2:
        hF2 = (best_h > 0.5).astype(float)
        hF2 = fix_sum_binary(hF2, len(hF2))
        hF2, _ = binary_search_full(hF2, len(hF2), deadline - 0.5, max_sweeps=200, stall_limit=40)
        c5F2 = compute_c5(hF2, len(hF2))
        if c5F2 < best_c5:
            best_c5, best_h = c5F2, hF2.copy()

    final_c5 = compute_c5(best_h, len(best_h))
    return best_h, final_c5, len(best_h)
