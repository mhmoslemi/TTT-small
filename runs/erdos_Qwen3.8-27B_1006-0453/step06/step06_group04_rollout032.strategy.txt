 Approach and rationale:

 Central idea: The problem is highly non-convex and prone to local optima. We need a method that can 
                explore a large part of the solution space without being trapped. 

 Instead of refining a single resolution, we can use a multi-resolution coordinate descent. The idea is to 
 represent the step function on multiple grid resolutions, and iteratively project the current solution to a 
 coarser grid, optimize on that grid, and then project back to the finer grid. This is inspired by the concept 
 of multi-scale optimization.

 Steps:

 1. Start with the provided initial_h_values (n=380).
 2. Coarsen the grid to, say, 190 points by averaging (ensuring integral is preserved) and optimize on this grid.
 3. Then, use the solution from the coarser grid to refine the original grid by interpolation and then optimizing locally.
 4. Repeat the process with different coarse grid sizes (e.g., 380 -> 190 -> 95) to try to escape local optima.

 Why multi-resolution coordinate descent?
 - It leverages the fact that global optima often have a simpler structure on coarser grids (sparsity, fewer fluctuations).
 - By optimizing on coarse grids and then refining, we can find solutions that are not found by single-resolution optimization.
