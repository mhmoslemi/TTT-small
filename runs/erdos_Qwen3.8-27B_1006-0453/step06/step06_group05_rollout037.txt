    h = h.astype(float).copy()
    target = N / 2.0
    best_h = h.copy()

    lr = lr0

    v = np.zeros(N)

        val = float(c.max())

        c_shifted = c - c.max()
        w = np.exp(beta * c_shifted)
        w /= w.sum()

        grad = (D @ w) / beta

        # Adam update

            beta *= beta_rate

Actually, I'll just use the Python definition. From numpy docs:
"Cross-correlation of 1-D sequences. Given a, v, it computes: c_k = sum_n a_{n+k} conj(v_n)"

So c_k = Σ_n a[n+k] * conj(v[n])

For a=[1,0], v=[0,1]:
k=-1: a[n-1]*v[n] for n where 0≤n<2 and 0≤n-1<2 → n=1: a[0]*v[1] = 1*1 = 1
k=0: a[n]*v[n] for n=0,1: a[0]*v[0]+a[1]*v[1] = 1*0+0*1 = 0
k=1: a[n+1]*v[n] for n where 0≤n<2 and 0≤n+1<2 → n=0: a[1]*v[0] = 0*0 = 0

So c = [1, 0, 0], mapped to indices 0,1,2 (lags -1, 0, 1).

The "full" correlation c[k] for k=0..2N-2 corresponds to lag = k-(N-1).
For N=2: lags are -1, 0, 1 for indices 0, 1, 2.

Using the convolution approach: correlate(a, b) = convolve(a, flip(b))
flip(b) = flip([0,1]) = [1, 0]
convolve([1,0], [1,0], 'full') = [1*1, 1*0+0*1, 0*0] = [1, 0, 0]
