  - p = q-m: so p+m = q → q is m ahead of p
  - p-m = q: so p is m ahead of q (q = p-m)
  - p-m = q-m: so p=q: impossible

So the overlap happens when q = p+m OR q = p-m, i.e., |p-q| = |m|.

Hmm, but if p+m is out of range, then h[p+m] doesn't exist, and the term in f(m) at index p doesn't contribute. Similarly for the overlap term.

Actually, if p+m ≥ N or p-m < 0, then the "p terms" in f(m) only include one of the two (or neither). The overlap condition requires BOTH the p-term and q-term to exist at the same index. If that index is out of range, there's no overlap.

The overlap index is q (=p-m) when p-m=q, or p (=q+m) when q-m=p.
- If q=p-m and 0≤q<N (which is true since q is a valid position), then the overlap is at index q, which is in range.
- If p=q+m and 0≤p<N (true), overlap at index p, in range.

So the overlap index is always in range (it's either p or q, both valid). But we also need the "m-shifted" index to be in range for the term to exist in f(m):
- Term at index i in f(m) exists if 0≤i<N and 0≤i+m<N.
- For the overlap at index q=p-m: we need 0≤q+m<N, i.e., 0≤p<N. True.
- For the overlap at index p=q+m: we need 0≤p-m<N, i.e., 0≤q<N. True.

So the correction applies whenever |p-q|=|m| (for m≠0). My simple mask is correct.

One more optimization: instead of computing the full correlation with FFT every iteration (O(N log N)), I can update it incrementally. After a swap (p: 1→0, q: 0→1), the correlation changes at lags... actually, ALL lags change (each lag m is affected if p or q is in the valid range for that lag). So the update is O(N) per swap, vs O(N log N) for full FFT. For N=380, O(N)=380 vs O(N log N)≈3420. So incremental is ~9x faster.

The incremental update: for each lag m, delta(m) = h[p+m]+h[p-m]-h[q+m]-h[q-m] + correction.
This is O(1) per lag, O(N) total.

Let me implement this:
```python
# c is the current correlation array (length 2N-1)
# After swap (p: 1→0, q: 0→1):
center = N - 1
for m in range(-(N-1), N):
    if m == 0:
        continue
    delta = 0.0
    if 0 <= p+m < N:
        delta += h_old[p+m]  # h before swap
    if 0 <= p-m < N:
        delta += h_old[p-m]
    if 0 <= q+m < N:
        delta -= h_old[q+m]
    if 0 <= q-m < N:
        delta -= h_old[q-m]
    if abs(p-q) == abs(m) and m != 0:
        delta += 1.0
    c[center+m] += delta
```
