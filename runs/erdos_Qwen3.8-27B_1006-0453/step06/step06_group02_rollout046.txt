- D[i, j] changes if i + s_j = p, i.e., j = p - i + N - 1
- For a fixed i, there's at most one j where this happens
- So for each row i, at most one element changes

Similarly for h[q] changing from 0 to 1.

So I can maintain D incrementally. But the computation of the candidate scores still requires the full (n_zeros, L) matrix per p.

Let me think of a faster approach:

For a given p (moving from 1 to 0):
- new_corr_if_move_to_q = c - D[p, :] + D_new[q, :]
- where D_new[q, :] is D[q, :] after the change

The key insight: D[q, j] = 1 - h[q + s_j] (if valid). After moving p from 1→0 and q from 0→1:
- D_new[q, j] differs from D_old[q, j] only where q+s_j = p (i.e., one element)

So: new_corr[j] = c[j] - D_old[p, j] + D_old[q, j] - delta[j]
where delta[j] = 1 if q+s_j = p (i.e., j = p-q+N-1), else 0.
And the delta is: D_new[q, p-q+N-1] = 1 - h_new[p] = 1 - 0 = 1, while D_old[q, p-q+N-1] = 1 - h_old[p] = 1 - 1 = 0.
So delta = +1 at that one position.

Similarly, D_new[p, j] differs from D_old[p, j] where p+s_j = q, i.e., j = q-p+N-1.
D_new[p, q-p+N-1] = 1 - h_new[q] = 1 - 1 = 0, while D_old[p, q-p+N-1] = 1 - h_old[q] = 1 - 0 = 1.
But we're removing p entirely, so this doesn't matter.

So: new_corr[j] = c[j] - D[p,j] + D[q,j] + (1 if j == p-q+N-1 else 0)

This means for each p, I can compute base = c - D[p,:] once, then for all q simultaneously:
cand[q, :] = base + D[q, :] + correction[q, :]

Where correction[q, :] is a 1 at position p-q+N-1 (if valid) and 0 elsewhere.

This is much more efficient! The (n_zeros, L) addition is the main cost.

The overlap integral C5 = max_k ∫ h(x)(1-h(x+k)) dx.

For a "good" solution, we want h(x) and h(x+k) to be complementary for all k. This is related to the concept of a "basis" or "tiling" of the interval.

- ∫ h(x)(1-h(x+k)) dx = μ(A \ (A-k)) = measure of points in A that, when shifted by k, are NOT in A
- We want to minimize the maximum over k of this quantity.

For a set A of measure 1 in [0,2] (so complement has measure 1):
- μ(A \ (A-k)) ≤ μ(A) = 1
- μ(A ∩ (A-k)) + μ(A \ (A-k)) = μ(A) = 1
- So μ(A \ (A-k)) = 1 - μ(A ∩ (A-k))

We want to minimize max_k (1 - μ(A ∩ (A-k))), i.e., maximize min_k μ(A ∩ (A-k)).

This is related to the "autocorrelation" of the set A. We want the autocorrelation to be as flat as possible (or at least have a high minimum).

import numpy as np
import time

def fft_corr(h):
    N = len(h)
    L = 2 * N - 1
    H = np.fft.fft(h, L)
    G = np.fft.fft(np.flip(1.0 - h), L)
    return np.real(np.fft.ifft(H * G))

def compute_c5(h, N):
    return float(np.max(fft_corr(h))) * (2.0 / N)

def project_sum(h, target):
    h = np.clip(h, 0.0, 1.0)
    s = float(h.sum())
    if abs(s - target) < 1e-12:
        return h
    lo, hi = -0.5, 0.5
    for _ in range(80):
        mid = (lo + hi) * 0.5
        if float(np.clip(h - mid, 0.0, 1.0).sum()) > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) * 0.5, 0.0, 1.0)

def subgrad_smooth(y, N, top_k, temp):
    """Soft subgradient using exp weighting over top-k peaks."""
    corr = fft_corr(y)
    top_idx = np.argpartition(corr, -top_k)[-top_k:]
    vals = corr[top_idx]
    v_max = vals.max()
    w = np.exp((vals - v_max) * temp)
    w /= w.sum()
    center = N - 1
    grad = np.zeros(N)
    for wi, ai in zip(w, top_idx):
        L = int(ai - center)
        if L == 0:
            grad += wi * (1.0 - 2.0 * y)
        elif 0 < L < N:
            grad[L:] += wi * (1.0 - y[:N-L])
            grad[:N-L] -= wi * y[L:]
        elif -N < L < 0:
            M = -L
            grad[:N-M] += wi * (1.0 - y[M:])
            grad[M:] -= wi * y[:N-M]
    return grad, float(corr.max())

def nesterov_opt(h, N, deadline, top_k=50, lr0=0.015, temp0=10.0):
    h = project_sum(h.astype(float).copy(), N/2.0)
    target = N / 2.0
    dx = 2.0 / N
    best_h = h.copy()
    best_pk = float(np.max(fft_corr(h)))
    m = np.zeros(N)
    lr = lr0
    beta = 0.85
    temp = temp0
    it = 0
    while time.time() < deadline:
        y = h + m
        grad, pk = subgrad_smooth(y, N, top_k, temp)
        if pk < best_pk:
            best_pk = pk
            best_h = h.copy()
        h_new = project_sum(y - lr * grad, target)
        m = beta * (h_new - h)
        h = h_new
        it += 1
        if it % 200 == 0:
            lr *= 0.995
            beta = min(0.97, beta + 0.002)
            temp *= 1.08
    return best_h, best_pk * dx
