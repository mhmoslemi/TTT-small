One more idea: **Lag-aware optimization**. Instead of treating all lags symmetrically, I can note that the overlap integral at lag L and at lag -L are related:
overlap(L) = ∫ h(x)(1-h(x+L)) dx
overlap(-L) = ∫ h(x)(1-h(x-L)) dx = ∫ h(x+L)(1-h(x)) dx = ∫ (1-h(y))h(y-L) dy (sub y=x+L)

Actually overlap(L) + overlap(-L) = ∫ h(x)(1-h(x+L)) dx + ∫ h(x+L)(1-h(x)) dx
= ∫ [h(x) - h(x)h(x+L) + h(x+L) - h(x)h(x+L)] dx
= ∫ [h(x) + h(x+L) - 2h(x)h(x+L)] dx
= ∫ h(x) dx + ∫ h(x+L) dx - 2∫ h(x)h(x+L) dx

For small L, ∫ h(x+L) dx ≈ ∫ h(x) dx = 1 (by periodicity or boundary effects).
So overlap(L) + overlap(-L) ≈ 2 - 2∫ h(x)h(x+L) dx

To minimize the max, we want both overlap(L) and overlap(-L) to be small, which means we want ∫ h(x)h(x+L) dx to be close to 1 for all L. This means h should be "autocorrelation-minimizing" at all shifts... which is like a Barker sequence or Zadoff-Chu sequence!

One more thought: the previous code's binary optimization was quite basic (random single swaps). A better approach might be:
- Compute the "benefit" of flipping each position (change in max overlap)
- Try the most beneficial flips first
- This is a greedy local search

- The change in max is approximately the change at the current worst lag

This can be computed in O(N) per position if done naively, or O(N log N) for all positions simultaneously using the gradient.

Actually, for binary optimization, the simplest effective approach is:
1. Compute current corr
2. Find worst lag L*
3. For each position i, compute how much flipping it would reduce corr[L*]
4. Try the flip with the largest benefit
5. If it also doesn't increase other corr values too much, accept

This is a "directed" local search that's much more efficient than random swaps.

import numpy as np

def fft_corr(h):
    N = len(h)
    L = 2 * N - 1
    Lf = 1 << (L - 1).bit_length()
    H = np.fft.rfft(h, Lf)
    G = np.fft.rfft((1.0 - h)[::-1], Lf)
    return np.fft.irfft(H * G, Lf)[:L]

def compute_c5(h):
    N = len(h)
    return float(np.max(fft_corr(h))) * (2.0 / N)

def project_sum(h, target):
    s = float(h.sum())
    if abs(s - target) < 1e-9:
        return np.clip(h, 0.0, 1.0)
    lo, hi = -2.0, 2.0
    for _ in range(50):
        mid = 0.5 * (lo + hi)
        if float(np.clip(h - mid, 0.0, 1.0).sum()) > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - 0.5 * (lo + hi), 0.0, 1.0)

def compute_grad(h, w):
    N = len(h)
    Lf = 1 << (3 * N - 1).bit_length()
    fr = 1.0 - h
    wr = w[::-1]
    H = np.fft.rfft(h, Lf)
    FR = np.fft.rfft(fr, Lf)
    W = np.fft.rfft(w, Lf)
    WR = np.fft.rfft(wr, Lf)
    c1 = np.fft.irfft(FR * W, Lf)
    c2 = np.fft.irfft(H * WR, Lf)
    return c1[N-1:2*N-1] - c2[N-1:2*N-1]

    h_prev = h.copy()
    lr = lr0
    beta = 0.9
    k = k_init
    stall = 0
    it = 0
    while time.time() < deadline:
        y = h + beta * (h - h_prev)
        h_prev = h.clone() if hasattr(h, 'clone') else h.copy()
        corr = fft_corr(y)
        pk = float(np.max(corr))
        if pk < best_pk - 1e-14:
            best_pk = pk
            best_h = y.copy()
            stall = 0
        else:
            stall += 1
        
        # Adaptive k
        k = min(k_max, k_init + it // 50)
        # Softmax weights on top-k lags
        idx = np.argpartition(corr, -k)[-k:]
        w = np.exp((corr[idx] - corr[idx].max()) / max(temp, 1e-8))
        w /= w.sum()
        
        # Build full weight vector
        W = np.zeros(2 * N - 1)
        W[idx] += w
        
        # Compute gradient
        g = compute_grad(y, W)
        
        # Nesterov step + projection
        h_new = project_sum(y - lr * g, target)
        h = h_new
        it += 1

            temp = max(0.002, temp * 0.997)

            h_prev = h.copy()
            lr = max(lr, lr0 * 0.7)
            stall = 0
    
    return best_h, best_pk * (2.0 / N)
