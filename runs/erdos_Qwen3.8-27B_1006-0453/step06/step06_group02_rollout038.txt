def fft_corr(h):
    N = len(h)
    L = 2 * N - 1
    H = np.fft.fft(h, L)
    G = np.fft.fft(np.flip(1.0 - h), L)
    return np.real(np.fft.ifft(H * G))

def c5_val(h):
    N = len(h)
    return float(np.max(fft_corr(h))) * (2.0 / N)

def project_to_sum(h, target):
    """Project h to [0,1]^N with sum = target using bisection."""
    h = np.clip(h, 0.0, 1.0)
    s = h.sum()
    if abs(s - target) < 1e-10:
        return h
    lo, hi = -2.0, 2.0
    for _ in range(60):
        mid = (lo + hi) * 0.5
        if np.clip(h - mid, 0.0, 1.0).sum() > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) * 0.5, 0.0, 1.0)

Let me think about a faster approach. Instead of full FFT for each candidate, I can compute the delta incrementally.

If I precompute the current correlation c, and I know the delta for flipping position p, then:
- Flip p (1→0): c_new = c + delta_p (where delta_p[k] is the change at shift k)
- Flip q (0→1): c_new = c + delta_p + delta_q

I can precompute delta for all positions, then for a swap (p, q), the new correlation is c + delta_p + delta_q.

The delta for position p (changing h[p] by δ, where δ = -1 for 1→0, +1 for 0→1):
For shift k (actual shift, can be negative):
- If p+k is valid: contribution δ*(1-h[p+k]) 
- If p-k is valid: contribution -δ*h[p-k]

Let me precompute this as a matrix D of shape (N, 2N-1) where D[p, s] is the change in correlation at index s when h[p] increases by 1 (goes from 0 to 1).

For h[p] going 0→1 (δ=+1):
- Shift k (s = center + k):
  - If 0 ≤ p+k < N: D[p, s] += (1 - h[p+k])
  - If 0 ≤ p-k < N: D[p, s] += -(h[p-k])

For h[p] going 1→0 (δ=-1): just negate D[p,s].

So for a swap (p: 1→0, q: 0→1):
new_c = c - D[p] + D[q]

And I need max(new_c) < current max for improvement.

This way, computing new_c for a candidate swap is just: c - D[p] + D[q], which is O(N) (vector addition). And finding its max is O(N).

With the D matrix precomputed (O(N²) = O(380²) ≈ 144K, trivial), I can evaluate each swap in O(N) = O(380).

def compute_D(h, N):

    L = 2*N - 1
    D = np.zeros((N, L))
