Wait, there's an issue with the Δcorr formula. Let me rederive it.

Let corr[k] = Σ_{i valid} h[i]·g[i+k] where g = 1-h and "valid" means both i and i+k are in [0, N-1].

After swapping h[p]=1→0 and h[q]=0→1:
- h'[p] = 0, h'[q] = 1, rest same
- g'[p] = 1, g'[q] = 0, rest same

Δcorr[k] = corr'[k] - corr[k]

The terms that change are those involving index p or q (in h or g):

Terms involving h[p]:
- In the "h[i]" part: i=p contributes h[p]·g[p+k] = 1·g[p+k]. After: 0·g[p+k] = 0. Change: -g[p+k] = -(1-h[p+k])
- In the "g[i+k]" part: i+k=p, i=p-k contributes h[p-k]·g[p] = h[p-k]·0. After: h[p-k]·1. Change: +h[p-k]

Terms involving h[q] (was 0, now 1):
- In the "h[i]" part: i=q contributes h[q]·g[q+k] = 0·g[q+k] = 0. After: 1·g[q+k] = g[q+k]. Change: +g[q+k] = +(1-h[q+k])
- In the "g[i+k]" part: i+k=q, i=q-k contributes h[q-k]·g[q] = h[q-k]·1. After: h[q-k]·0. Change: -h[q-k]

Total: Δcorr[k] = -(1-h[p+k]) + h[p-k] + (1-h[q+k]) - h[q-k]

with all terms being 0 if the index is out of [0, N-1].

This is correct! And for a fixed p, it decomposes as:
Δcorr[k] = [-(1-h[p+k]) + h[p-k]] + [(1-h[q+k]) - h[q-k]]
= A_p(k) + B_q(k)

So for a fixed p, we can precompute A_p(k) for all top shifts, then for each q, the score is max_k(corr[k_top] + A_p(k_top) + B_q(k_top)).

The B_q(k) computation for all q and all top shifts is O(len(zeros) * top_k). With 190 zeros and 50 top shifts, that's 9500 operations. Very fast.

The A_p(k) computation is O(top_k) per p. With 190 p's, that's 9500 operations.

Total per sweep: 190 * (50 + 190*50) ≈ 190 * 9550 ≈ 1.8M. Very fast!

            k = ki - (N - 1)
            wk = w[ki]
            if abs(k) < N:
                if k >= 0:
                    # (1-y[j+k]) for j in [0, N-1-k]
                    grad[:N-k] += wk * (1.0 - y[k:])
                    # -y[j-k] for j in [k, N-1]
                    grad[k:] -= wk * y[:N-k]
                else:
                    m = -k
                    # (1-y[j-m]) for j in [m, N-1]
                    grad[m:] += wk * (1.0 - y[:N-m])
                    # -y[j+m] for j in [0, N-1-m]
                    grad[:N-m] -= wk * y[m:]
            # Note: for k=0: (1-y[j]) - y[j] = 1-2y[j], handled by k>=0 branch
        
        # Project: h_new = project(y - lr * grad)
        h_new = project_sum(y - lr * grad, target)
        m = beta * (h_new - h)
        h = h_new
        
        # Anneal learning rate
        if it % 200 == 0:
            lr *= 0.98
            beta = min(0.95, 0.85 + it * 0.0002)
    
    return best_h, best_c5

def project_sum(h, target):
    """Project h to {0<=h<=1, sum(h)=target}."""
    h = np.clip(h, 0.0, 1.0)
    s = h.sum()
    if abs(s - target) < 1e-10:
        return h
    lo, hi = -2.0, 2.0
    for _ in range(60):
        mid = 0.5 * (lo + hi)
        s_mid = np.clip(h - mid, 0.0, 1.0).sum()
        if s_mid > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - 0.5 * (lo + hi), 0.0, 1.0)
