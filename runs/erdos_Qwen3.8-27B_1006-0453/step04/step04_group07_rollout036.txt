Actually, after a swap (i: 1→0, j: 0→1):

- For position p, flip_eff[p, m] depends on h[p±lag] for various lags
- After changing h[i] and h[j], flip_eff changes for all p where p±lag ∈ {i, j}
- That's at most 4 positions (i-lag, i+lag, j-lag, j+lag for all lag) = all positions

So actually flip_eff changes everywhere. Not worth maintaining incrementally.

def compute_flip_eff(h, n):
    M = 2 * n - 1
    lags = np.arange(-(n-1), n)
    # For each p, flip_eff[p, m] = (1-h[p-lag]) * I(0<=p-lag<n) - h[p+lag] * I(0<=p+lag<n)
    # Vectorize:
    flip_eff = np.zeros((n, M))
    for p in range(n):
        a = p - lags  # p - (-(n-1))..p-(n-1) = p+(n-1)..p-(n-1)
        b = p + lags
        va = (a >= 0) & (a < n)
        vb = (b >= 0) & (b < n)
        flip_eff[p, va] += (1.0 - h[a[va]])
        flip_eff[p, vb] -= h[b[vb]]
    return flip_eff
```

def flip_eff(h, n):
    M = 2 * n - 1
    lags = np.arange(-(n-1), n)  # L = k - (n-1), so k = L + (n-1)
    # p+k-n+1 = p + L
    # p-k+n-1 = p - L
    out = np.zeros((n, M))
    for p in range(n):
        b = p + lags  # p + L = p + k - (n-1) = p + k - n + 1 ✓
        a = p - lags  # p - L = p - k + (n-1) = p - k + n - 1 ✓
        vb = (b >= 0) & (b < n)
        va = (a >= 0) & (a < n)
        out[p, vb] += (1.0 - h[b[vb]])
        out[p, va] -= h[a[va]]
        # Correction for k = n-1 (L = 0)
        out[p, n-1] -= (1.0 - 2.0 * h[p])
    return out
```

- After: 0*(1-1) = 0
- Change: -1

- Flip j: delta_j=+1, term h[i]*(1-h[j]) changes by -1*h[i] = -1*1 = -1
- Sum: -2

- i = j+k-n+1 AND j+k-n+1 = j: k = n-1. Same thing.
- i appears as the h[j] and j appears as h[j+k-n+1]: j=i and j+k-n+1=j means k=n-1.
- j appears as the h[j'] and i appears as h[j'+k-n+1]: j'=j and j'+k-n+1=i means j+k-n+1=i.
