where d_k = (1-h[i+s_k]) - h[i-s_k] (with 0 for out of bounds).

And c_k^0 = c_k (at current h) - h[i]*d_k (undo the current h[i]'s contribution).

So c_k(t) = c_k_current - h[i]*d_k + t*d_k = c_k_current + (t - h[i])*d_k

The objective is J(t) = max_k (c_k_current + (t-h[i])*d_k) * dx

This is a convex function of t (max of linear functions). To minimize it:
- Compute the slope at each t
- The minimum is where the slope crosses 0 (or at boundaries 0 or 1)

For a max of linear functions, the subgradient at t is the max of the active (tied) slopes... actually it's the convex hull of the active slopes.

Simplest approach: evaluate J(t) at t=0, t=1, and find all "knee points" (where the argmax changes). The minimum is at a knee point or at a boundary.

The knee points occur at t values where two c_k's are tied: c_k1 + (t-h[i])*d_k1 = c_k2 + (t-h[i])*d_k2
→ (t-h[i])*(d_k1 - d_k2) = c_k2 - c_k1
→ t = h[i] + (c_k2 - c_k1)/(d_k1 - d_k2)

For n=160, there are 319 correlations, so at most C(319,2) ≈ 50K pairwise intersections. That's a lot to check.

Simpler: just sample J(t) at a few points and do a ternary/golden search. Since J(t) is convex, golden section search works.

Actually, since J(t) is convex and piecewise linear, we can use a subgradient method:
- Evaluate J and its subgradient at t
- If subgradient > 0, go left; if < 0, go right; if 0, we're at minimum
- The subgradient of max of lines is the convex hull of active line slopes

For practical purposes, let me just use golden section search for the 1D problem. It converges in about 50-100 evaluations.

Each evaluation of J(t) requires computing the full correlation: O(n²) = O(25600). With 100 evaluations per coordinate, and 160 coordinates, that's 160*100*25600 = 400M per sweep. That's too slow.

```python
def coord_opt_fast(h, i, n):
    """Optimize h[i] assuming other coordinates fixed. O(n) per evaluation."""
    v = 1.0 - h
    corr = np.correlate(h, v, mode='full')  # O(n²), but we do this once
    # d_k for coordinate i
    # d_k = (1-h[i+s_k]) - h[i-s_k] where s_k = k-(n-1)
    d = np.zeros(2*n-1)
    for k in range(2*n-1):
        s = k - (n-1)
        val = 0.0
        if 0 <= i+s < n:
            val += 1.0 - h[i+s]
        if 0 <= i-s < n:
            val -= h[i-s]
        d[k] = val
    
    # J(t) = max_k (corr[k] + (t - h[i]) * d[k]) * dx
    # = max_k (corr[k] - h[i]*d[k] + t*d[k]) * dx
    base = corr - h[i]*d  # c_k^0
    # J(t) = max_k (base[k] + t*d[k]) * dx
    
    dx = 2.0/n
    # Golden section search on [0, 1]
    gr = (np.sqrt(5) - 1) / 2
    a, b = 0.0, 1.0
    c = b - gr*(b-a)
    d_pt = a + gr*(b-a)
    fc = np.max(base + c*d) 
    fd = np.max(base + d_pt*d)
    for _ in range(50):
        if fc < fd:
            b = d_pt; d_pt = c; fd = fc; c = b - gr*(b-a); fc = np.max(base + c*d)
        else:
            a = c; c = d_pt; fc = fd; d_pt = a + gr*(b-a); fd = np.max(base + d_pt*d)
    t_opt = (a + b) / 2
    return t_opt
```

Actually, I realize there might be an issue with my coordinate descent. When I change h[i], the constraint sum(h) = n/2 is violated. I need to either:
1. Redistribute the sum change across all coordinates (project)
2. Or fix one other coordinate to maintain the sum

The projection approach (bisection to find the right shift) is clean but changes all coordinates. For the 1D optimization, I could:
- Optimize h[i] freely in [0,1]
- After finding the optimal h[i], project the whole vector

But the projection changes all coordinates, so the "optimal" h[i] might not be optimal after projection. However, for small changes, the perturbation from projection is small.

Alternatively, I can incorporate the sum constraint into the 1D optimization: if I change h[i] by δ, I need to change the sum by -δ. The simplest is to spread -δ/n to all other coordinates (or use the projection).

For simplicity, let me just project after each coordinate update. The projection is a bisection, which is fast.

```python
import numpy as np
from scipy.optimize import minimize, minimize_scalar
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * dx

def project(h, n):
    target = n / 2.0
    vec = np.clip(np.array(h, dtype=float), 0.0, 1.0)
    s = vec.sum()
    if abs(s - target) < 1e-12:
        return vec
    lo = -vec.max() - 1.0
    hi = 1.0 - vec.min() + 1.0
    for _ in range(100):
        mid = (lo + hi) * 0.5
        if np.clip(vec + mid, 0.0, 1.0).sum() > target:
            hi = mid
        else:
            lo = mid
    return np.clip(vec + (lo + hi) * 0.5, 0.0, 1.0)

def smooth_c5(h, T):
    corr = np.correlate(h, 1.0 - h, mode='full')
    n = len(h)
    dx = 2.0 / n
    m = np.max(corr)
    return (m + np.log(np.sum(np.exp(T * (corr - m)))) / T) * dx

def compute_gradient(h, T):
    n = len(h)
    dx = 2.0 / n
    v = 1.0 - h
    corr = np.correlate(h, v, mode='full')
    m = np.max(corr)
    w = np.exp(T * (corr - m))
    ws = w.sum()
    if ws < 1e-300:
        idx = np.argmax(corr)
        w = np.zeros(2*n-1)
        w[idx] = 1.0
    else:
        w /= ws
    grad = np.zeros(n)
    for k in range(2*n-1):
        wk = w[k]
        if wk < 1e-15:
            continue
        s = k - (n - 1)
        # v[j+s] valid for j in [max(0,-s), min(n-1, n-1-s)]
        jv0 = max(0, -s)
        jv1 = min(n-1, n-1-s)
        if jv0 <= jv1:
            grad[jv0:jv1+1] += wk * v[jv0+s:jv1+s+1]
        # -h[j-s] valid for j in [max(0,s), min(n-1, n-1+s)]
        jh0 = max(0, s)
        jh1 = min(n-1, n-1+s)
        if jh0 <= jh1:
            grad[jh0:jh1+1] -= wk * h[jh0-s:jh1-s+1]
    grad *= dx
    return grad, np.max(corr) * dx

def slsqp_opt(h, T, n, maxiter=500):
    def obj(x):
        return smooth_c5(x, T)
    def con(x):
        return x.sum() - n / 2.0
    res = minimize(obj, h, method='SLSQP',
                   bounds=[(0.0, 1.0)]*n,
                   constraints=[{'type': 'eq', 'fun': con}],
                   options={'maxiter': maxiter, 'ftol': 1e-14})
    return project(res.x, n)

def coord_opt_fast(h, i, n):
    """Optimize h[i] with O(n) per 1D eval using precomputed correlation."""
    v = 1.0 - h
    corr = np.correlate(h, v, mode='full')
    # d_k = (1-h[i+s_k]) - h[i-s_k]
    d = np.zeros(2*n-1)
    s = np.arange(2*n-1) - (n-1)
    # v part: 1-h[i+s] valid when 0<=i+s<n
    mask_v = (i+s >= 0) & (i+s < n)
    d[mask_v] += 1.0 - h[i+s[mask_v]]
    # h part: -h[i-s] valid when 0<=i-s<n
    mask_h = (i-s >= 0) & (i-s < n)
    d[mask_h] -= h[i-s[mask_h]]
    
    base = corr - h[i] * d
    # Maximize -J(t) = -max_k(base[k] + t*d[k])
    # J(t) is convex in t, minimize over [0,1]
    gr = (np.sqrt(5) - 1) / 2
    lo, hi = 0.0, 1.0
    c = hi - gr * (hi - lo)
    dpt = lo + gr * (hi - lo)
    fc = np.max(base + c * d)
    fd = np.max(base + dpt * d)
    for _ in range(40):
        if fc < fd:
            hi = dpt; dpt, fd = c, fc
            c = hi - gr * (hi - lo)
            fc = np.max(base + c * d)
        else:
            lo = c; c, fc = dpt, fd
            dpt = lo + gr * (hi - lo)
            fd = np.max(base + dpt * d)
    return (lo + hi) / 2

def coord_descent(h, n, t_end, max_sweeps=1000):
    best_h = h.copy()
    best_c5 = compute_c5(best_h)
    no_improve = 0
    for sweep in range(max_sweeps):
        if time.time() > t_end:
            break
        improved = False
        order = np.random.permutation(n)
        for i in order:
            if time.time() > t_end:
                return best_h, best_c5
            hi_new = coord_opt_fast(best_h, i, n)
            if abs(hi_new - best_h[i]) < 1e-10:
                continue
            h_try = best_h.copy()
            h_try[i] = hi_new
            h_try = project(h_try, n)
            c5_try = compute_c5(h_try)
            if c5_try < best_c5 - 1e-14:
                best_c5 = c5_try
                best_h = h_try
                improved = True
        no_improve = 0 if improved else no_improve + 1
        if no_improve >= 5:
            break
    return best_h, best_c5

def grad_descent(h, n, t_end, T_start=5, T_end=100000, max_iter=2000):
    best_h = h.copy()
    best_c5 = compute_c5(best_h)
    h_work = h.copy()
    for it in range(max_iter):
        if time.time() > t_end:
            break
        frac = it / max_iter
        T = T_start * (T_end / T_start) ** frac
        grad, c5_curr = compute_gradient(h_work, T)
        # Project gradient (remove component along constraint normal)
        grad_proj = grad - np.mean(grad)
        gnorm = np.linalg.norm(grad_proj)
        if gnorm < 1e-14:
            break
        # Line search
        alpha = 1.0 / (T * gnorm + 1)
        improved = False
        for _ in range(30):
            h_new = project(h_work + alpha * grad_proj, n)
            c5_new = compute_c5(h_new)
            if c5_new < c5_curr - 1e-15 * max(1, c5_curr):
                h_work = h_new
                c5_curr = c5_new
                improved = True
                if c5_new < best_c5:
                    best_c5 = c5_new
                    best_h = h_work.copy()
                break
            alpha *= 0.5
        if not improved:
            # Try smaller step
            alpha = 1e-4 / (T + 1)
            h_new = project(h_work + alpha * grad_proj, n)
            c5_new = compute_c5(h_new)
            if c5_new < best_c5:
                best_c5 = c5_new
                best_h = h_work.copy()
    return best_h, best_c5

def run(seed=42, budget_s=1100, **kwargs):
    np.random.seed(seed)
    t0 = time.time()
    t_end = t0 + budget_s
    
    if 'initial_h_values' in globals() and initial_h_values is not None:
```

```python
    corr = np.correlate(h, v, mode='full')
    s = np.arange(2*n-1) - (n-1)
    # d_k = (1-h[i-s_k]) - h[i+s_k]

    d[mask1] += 1.0 - h[i-s[mask1]]
    mask2 = (i+s >= 0) & (i+s < n)  # i+s_k valid
    d[mask2] -= h[i+s[mask2]]

    # J(t) = max_k (base[k] + t*d[k]) * dx
    # Minimize over t in [0,1]
    gr = (np.sqrt(5) - 1) / 2
    lo, hi = 0.0, 1.0
    c1 = hi - gr * (hi - lo)
    c2 = lo + gr * (hi - lo)
    f1 = np.max(base + c1 * d)
    f2 = np.max(base + c2 * d)
    for _ in range(40):
        if f1 < f2:
            hi = c2; c2 = c1; f2 = f1
            c1 = hi - gr * (hi - lo)
            f1 = np.max(base + c1 * d)
        else:
            lo = c1; c1 = c2; f1 = f2
            c2 = lo + gr * (hi - lo)
            f2 = np.max(base + c2 * d)
    return (lo + hi) / 2
```

```python
import numpy as np
from scipy.optimize import minimize

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * dx

def project(h, n):
    target = n / 2.0
    vec = np.clip(np.asarray(h, dtype=float), 0.0, 1.0)
    s = vec.sum()
    if abs(s - target) < 1e-13:
        return vec
    lo = -vec.max() - 1.0
    hi = 1.0 - vec.min() + 1.0
    for _ in range(100):
        mid = (lo + hi) * 0.5
        if np.clip(vec + mid, 0.0, 1.0).sum() > target:
            hi = mid
        else:
            lo = mid
    return np.clip(vec + (lo + hi) * 0.5, 0.0, 1.0)

def smooth_c5(h, T):
    corr = np.correlate(h, 1.0 - h, mode='full')
    n = len(h)
    dx = 2.0 / n
    m = np.max(corr)
    return (m + np.log(np.sum(np.exp(T * (corr - m)))) / T) * dx

    m = np.max(corr)

    if ws < 1e-300:
        idx = np.argmax(corr)
        w = np.zeros(2 * n - 1)
        w[idx] = 1.0

    no_improve = 0
    for sweep in range(max_sweeps):
        if time.time() > t_end:
            break
        improved = False
        order = np.random.permutation(n)
        for i in order:
            if time.time() > t_end:
                return best_h, best_c5
            hi_new = coord_opt_fast(best_h, i, n)
            if abs(hi_new - best_h[i]) < 1e-11:
                continue
            ht = best_h.copy()
            ht[i] = hi_new
            ht = project(ht, n)
            c5v = compute_c5(ht)
            if c5v < best_c5 - 1e-14:
                best_c5 = c5v
                best_h = ht
                improved = True
        no_improve = 0 if improved else no_improve + 1
        if no_improve >= 4:
            break
    return best_h, best_c5

def grad_descent(h, n, t_end, T_start=5.0, T_end=80000.0, max_iter=5000):
    best_h = h.copy()
    best_c5 = compute_c5(best_h)
    hw = h.copy()
    stuck = 0
    for it in range(max_iter):
        if time.time() > t_end:
            break
        frac = min(it / max_iter, 0.999)
        T = T_start * (T_end / T_start) ** frac
        grad, c5c = compute_gradient(hw, T)
        gp = grad - np.mean(grad)
        gn = np.linalg.norm(gp)
        if gn < 1e-14:
            stuck += 1
            if stuck > 50:
                hw = project(best_h + 0.05 * np.random.randn(n), n)
                stuck = 0
            continue
        alpha = min(1.0, 0.5 / (T * gn + 1.0))
        improved = False
        for _ in range(40):
            hn = project(hw + alpha * gp, n)
            c5n = compute_c5(hn)
            if c5n < c5c - 1e-15 * max(1.0, c5c):
                hw = hn
                c5c = c5n
                improved = True
                if c5n < best_c5:
                    best_c5 = c5n
                    best_h = hw.copy()
                break
            alpha *= 0.5
        if not improved:
            stuck += 1
            if stuck > 100:
                hw = project(best_h + 0.03 * np.random.randn(n), n)
                stuck = 0
        else:
            stuck = 0
    return best_h, best_c5

def run(seed=42, budget_s=1100, **kwargs):
    np.random.seed(seed)
    t0 = time.time()
    t_end = t0 + budget_s

    if 'initial_h_values' in globals() and initial_h_values is not None:
        best_h = np.array(initial_h_values, dtype=float)
    else:
        best_h = np.zeros(160)
        best_h[:80] = 1.0
    n = len(best_h)
    best_h = project(best_h, n)
    best_c5 = compute_c5(best_h)

    # Phase 1: SLSQP with increasing T (12%)
    for T in [5, 20, 100, 500, 2000, 8000]:
        if time.time() > t0 + budget_s * 0.12:
            break
        try:
            hc = slsqp_opt(best_h.copy(), T, n, maxiter=300)
            c5v = compute_c5(hc)
            if c5v < best_c5:
                best_c5 = c5v
                best_h = hc
        except Exception:
            pass

    # Phase 2: Gradient descent (22%)
    best_h, best_c5 = grad_descent(best_h, n, t0 + budget_s * 0.34,
                                   T_start=5.0, T_end=50000.0, max_iter=5000)

    # Phase 3: Intensive coordinate descent (48%)
    best_h, best_c5 = coord_descent(best_h, n, t0 + budget_s * 0.82, max_sweeps=10000)

    # Phase 4: Diversification + re-optimize (12%)
    work_h = best_h.copy()
    work_c5 = best_c5
    t_div = t0 + budget_s * 0.82
    t_div_end = t0 + budget_s * 0.94
    for attempt in range(20):
        if time.time() > t_div_end:
            break
        pert = 0.02 + 0.06 * np.random.rand()
        hp = project(work_h + pert * np.random.randn(n), n)
        try:
            hp = slsqp_opt(hp, 2000.0, n, maxiter=200)
        except Exception:
            pass
        hp, c5p = coord_descent(hp, n, min(t_div_end, time.time() + budget_s * 0.01), max_sweeps=100)
        if c5p < work_c5:
            work_h = hp
            work_c5 = c5p
        if work_c5 < best_c5:
            best_c5 = work_c5
            best_h = work_h.copy()

    # Phase 5: Final polish (6%)
    for T in [30000, 100000]:
        if time.time() > t0 + budget_s * 0.97:
            break
        try:
            hc = slsqp_opt(best_h.copy(), T, n, maxiter=500)
            c5v = compute_c5(hc)
            if c5v < best_c5:
                best_c5 = c5v
                best_h = hc
        except Exception:
            pass
    if time.time() < t0 + budget_s * 0.995:
        best_h, best_c5 = coord_descent(best_h, n, t0 + budget_s * 0.998, max_sweeps=500)

    best_h = project(best_h, n)
    best_c5 = compute_c5(best_h)
    return best_h, best_c5, n
```
