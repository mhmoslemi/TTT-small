2. Or where the quadratic is the active constraint

This is getting complex. For practical purposes, since n=160 and there are 319 correlation values, I can just evaluate C5(t) at a few key points (the breakpoints of the piecewise linear part, plus the critical point of the quadratic) and pick the minimum.

The breakpoints of max of lines occur where pairs of lines intersect: C_k + D_k*t = C_l + D_l*t → t = (C_l - C_k)/(D_k - D_l)

There are O(n²) breakpoints, but most will be outside [0,1]. I can be smarter:
- First, find which lines are active at t=0 and t=1
- The optimal t is somewhere in between
- Use a ternary search or bisection on the convex function

Actually, since max of affine functions is convex, and we're adding a concave term (the k=0 case), the overall function is NOT necessarily convex. But in practice, the k=0 term is usually not the binding constraint.

For simplicity, let me just use minimize_scalar with a high precision, as the previous code does. The key improvement would be to make each evaluation faster.

Actually, for the 1D optimization, instead of doing a full np.correlate (which is O(n²)), I can compute C5(t) in O(n) time since I only need to evaluate the max of 319 values, each of which I can compute in O(1) once I've precomputed the C_k and D_k.

Let me precompute for coordinate i:
- For each p (0 to 2n-2), compute C_p and D_p as above
- Then C5(t) = max_p (C_p + D_p*t) * dx (ignoring the k=0 quadratic for now)
- Or C5(t) = max(max_{p≠n-1}(C_p + D_p*t), C_0 + D_0*t - t²) * dx

This makes each evaluation O(n) instead of O(n²), a speedup of O(n).

Let me implement this:

```python
def coord_opt_fast(h, i, n):
    # Precompute C_p and D_p for coordinate i
    dx = 2.0 / n
    corr_full = np.correlate(h, 1.0 - h, mode='full')  # Current values
    # When h[i] changes from h[i] to t:
    # For p corresponding to shift k = p - (n-1):
    #   if k != 0: corr[p] changes by (t - h[i]) * (1 - h[(i+k) % ...]) ... 
    #   Actually, let's compute D_p directly
    
    # D_p = coefficient of t in corr_p
    # For shift k = p - (n-1):
    #   D_p = (1-h[i+k]) * [0<=i+k<n] + (1-h[i-k]) * [0<=i-k<n, k!=0] - (for k=0: t term)
    
    # Actually let me just compute it directly
    D = np.zeros(2*n-1)
    h_i = h[i]
    for p in range(2*n-1):
        k = p - (n-1)
        d = 0.0
        if 0 <= i+k < n:
            d += (1.0 - h[i+k])
        if k != 0 and 0 <= i-k < n:
            d += (1.0 - h[i-k])
        # For k=0, there's also the -t*h[i] term from h[i]*(1-h[i])
        # Actually for k=0: corr = ... + h[i]*(1-h[i]) = ... + t*(1-t)
        # Linear part: t, quadratic part: -t²
        # So D_0 gets +1 from the t*(1-h[i]) = t - t² part
        # But we also have the (1-h[i])*h[i] = (1-t)*t part... wait
        # For k=0: j=i gives h[i]*(1-h[i]) = t*(1-t)
        # There's no separate j=i-k term since k=0
        # So for k=0: D_0 = 1 (from t*(1-t) = t - t²)
        # And there's a -t² term
        if k == 0:
            d = 1.0  # from t*(1-t)
        D[p] = d
    
    # Now C_p = corr_full[p] - h[i] * D[p] (for k≠0)
    # For k=0: corr = C_0 + t*D_0 - t², so C_0 = corr_0 - h[i]*D_0 + h[i]²
    C = np.zeros(2*n-1)
    for p in range(2*n-1):
        k = p - (n-1)
        if k == 0:
            C[p] = corr_full[p] - h[i] * D[p] + h[i]*h[i]
        else:
            C[p] = corr_full[p] - h[i] * D[p]
    
    # Minimize max(C + D*t)*dx over t in [0,1]
    # (plus the -t² term for p=n-1 if k=0)
    # Use minimize_scalar
    def f1d(t):
        vals = C + D * t
        if n > 0:
            # The k=0 term (p=n-1) has an extra -t²
            vals[n-1] -= t * t
        return np.max(vals) * dx
    
    res = minimize_scalar(f1d, bounds=(0.0, 1.0), method='bounded',
                          options={'xatol': 1e-12})
    return res.x
```

For the max of affine functions: the minimum is at a breakpoint (where two lines intersect) or at the boundary. We can find it by:
1. Evaluating at t=0 and t=1
2. Finding all breakpoints in [0,1]
3. Evaluating at each breakpoint
4. Taking the minimum

But there are O(n²) breakpoints. A faster approach: use the fact that the max of lines is a convex function, so we can use ternary search or subgradient methods.

```python
import numpy as np
from scipy.optimize import minimize_scalar, minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * dx

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project(h, target):
    vc = np.clip(h, 0.0, 1.0)
    if abs(vc.sum() - target) < 1e-12:
        return vc
    lo, hi = -2.0, 2.0
    for _ in range(60):
        mid = (lo + hi) * 0.5
        if np.clip(h + mid, 0, 1).sum() > target:
            hi = mid
        else:
            lo = mid
    return np.clip(h + (lo + hi) * 0.5, 0, 1)

def coord_opt_fast(h, i, n):
    """Fast 1D coordinate optimization using O(n) per evaluation."""
    dx = 2.0 / n
    h_i = h[i]
    if h_i <= 1e-15 or h_i >= 1.0 - 1e-15:
        # At boundary, just check if moving inward helps
        pass
    
    corr = np.correlate(h, 1.0 - h, mode='full')
    
    # Compute D for each correlation index
    D = np.zeros(2 * n - 1)
    for p in range(2 * n - 1):
        k = p - (n - 1)
        d = 0.0
        if 0 <= i + k < n:
            d += 1.0 - h[i + k]
        if k != 0 and 0 <= i - k < n:
            d += 1.0 - h[i - k]
        if k == 0:
            d = 1.0
        D[p] = d
    
    # C[p] = corr[p] - h_i * D[p] (for k != 0)
    # C[n-1] = corr[n-1] - h_i * 1 + h_i^2 (for k = 0)
    C = corr - h_i * D
    C[n-1] += h_i * h_i  # fix the k=0 case
    
    def f1d(t):
        vals = C + D * t
        vals[n-1] -= t * t
        return vals.max() * dx
    
    res = minimize_scalar(f1d, bounds=(0.0, 1.0), method='bounded',
                          options={'xatol': 1e-12})
    return res.x

def coord_descent(h, n, t_end, max_sweeps=5000):
    best_h = h.copy()
    best_c5 = compute_c5(best_h)
    target = n / 2.0
    no_improve = 0
    for sweep in range(max_sweeps):
        if time.time() > t_end:
            break
        improved = False
        order = np.random.permutation(n)
        for i in order:
            if time.time() > t_end:
                return best_h, best_c5
            new_val = coord_opt_fast(best_h, i, n)
            if abs(new_val - best_h[i]) < 1e-10:
                continue
            h_try = best_h.copy()
            h_try[i] = new_val
            h_try = project(h_try, target)
            c5_try = compute_c5(h_try)
            if c5_try < best_c5 - 1e-14:
                best_h = h_try
                best_c5 = c5_try
                improved = True
        if improved:
            no_improve = 0
        else:
            no_improve += 1
            if no_improve >= 3:
                break
    return best_h, best_c5
```

```python
import numpy as np
from scipy.optimize import minimize_scalar, minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * dx

def project(h, target):
    vc = np.clip(h, 0.0, 1.0)
    if abs(vc.sum() - target) < 1e-12:
        return vc
    lo, hi = -2.0, 2.0
    for _ in range(60):
        mid = (lo + hi) * 0.5
        if np.clip(h + mid, 0, 1).sum() > target:
            hi = mid
        else:
            lo = mid
    return np.clip(h + (lo + hi) * 0.5, 0, 1)

def coord_opt_fast(h, i, n):
    dx = 2.0 / n
    h_i = h[i]
    corr = np.correlate(h, 1.0 - h, mode='full')
    k_vals = np.arange(-(n-1), n)
    fwd_valid = (i + k_vals >= 0) & (i + k_vals < n)
    bwd_valid = (k_vals != 0) & (i - k_vals >= 0) & (i - k_vals < n)
    D = np.zeros(2 * n - 1)
    D[fwd_valid] += 1.0 - h[i + k_vals[fwd_valid]]
    D[bwd_valid] += 1.0 - h[i - k_vals[bwd_valid]]
    D[n-1] = 1.0
    C = corr - h_i * D
    C[n-1] += h_i * h_i
    k0_mask = np.zeros(2 * n - 1)
    k0_mask[n-1] = 1.0
    def f1d(t):
        return np.max(C + D * t - t * t * k0_mask) * dx
    res = minimize_scalar(f1d, bounds=(0.0, 1.0), method='bounded',
                          options={'xatol': 1e-13})
    return res.x

def coord_descent(h, n, t_end, max_sweeps=10000, seed=None):
    if seed is not None:
        rng = np.random.RandomState(seed)
    else:
        rng = np.random
    best_h = h.copy()
    best_c5 = compute_c5(best_h)
    target = n / 2.0
    no_improve = 0
    for sweep in range(max_sweeps):
        if time.time() > t_end:
            break
        improved = False
        order = rng.permutation(n)
        for i in order:
            if time.time() > t_end:
                return best_h, best_c5
            new_val = coord_opt_fast(best_h, i, n)
            if abs(new_val - best_h[i]) < 1e-10:
                continue
            h_try = best_h.copy()
            h_try[i] = new_val
            h_try = project(h_try, target)
            c5_try = compute_c5(h_try)
            if c5_try < best_c5 - 1e-14:
                best_h = h_try
                best_c5 = c5_try
                improved = True
        if improved:
            no_improve = 0
        else:
            no_improve += 1
            if no_improve >= 3:
                break
    return best_h, best_c5

def slsqp_opt(h, T, n, maxiter=1000):
    corr = np.correlate(h, 1.0 - h, mode='full')
    m = corr.max()
    w = np.exp(T * (corr - m))
    w /= w.sum()
    n_full = 2 * n - 1
    k_vals = np.arange(-(n-1), n)
    dx = 2.0 / n
    
    def obj(x):
        c = np.correlate(x, 1.0 - x, mode='full')
        mm = c.max()
        return (mm + np.log(np.sum(np.exp(T * (c - mm)))) / T) * dx
    
    def con(x):
        return x.sum() - n / 2.0
    
    res = minimize(obj, h, method='SLSQP',
                   bounds=[(0.0, 1.0)] * n,
                   constraints=[{'type': 'eq', 'fun': con}],
                   options={'maxiter': maxiter, 'ftol': 1e-14})
    return project(res.x, n / 2.0)

def run(seed=42, budget_s=1100, **kwargs):
    np.random.seed(seed)
    t0 = time.time()
    
    if 'initial_h_values' in globals() and initial_h_values is not None:
        best_h = np.array(initial_h_values, dtype=float)
    else:
        n_init = 160
        best_h = np.zeros(n_init)
        best_h[:n_init//2] = 1.0
    
    n = len(best_h)
    best_h = project(best_h, n / 2.0)
    best_c5 = compute_c5(best_h)
    
    def elapsed():
        return time.time() - t0
    
    # Phase 1: SLSQP (8% budget)
    t_phase1 = t0 + budget_s * 0.08
    for T in [50, 500, 5000]:
        if time.time() > t_phase1:
            break
        try:
            hc = slsqp_opt(best_h.copy(), T, n, maxiter=500)
            c5v = compute_c5(hc)
            if c5v < best_c5:
                best_c5 = c5v
                best_h = hc
        except Exception:
            pass
    
    # Phase 2: Intensive coordinate descent (60% budget)
    t_phase2 = t0 + budget_s * 0.68
    best_h, best_c5 = coord_descent(best_h, n, t_phase2, max_sweeps=20000, seed=seed)
    
    # Phase 3: Diversification (20% budget)
    t_phase3 = t0 + budget_s * 0.88
    work_h = best_h.copy()
    work_c5 = best_c5
    n_div = 20
    for it in range(n_div):
        if time.time() > t_phase3:
            break
        cool = 1.0 - it / float(n_div)
        if it % 2 == 0:
            h_pert = work_h + 0.05 * cool * np.random.randn(n)
        else:
            h_pert = work_h + 0.1 * cool * np.random.randn(n)
        h_pert = project(h_pert, n / 2.0)
        # Quick CD
        hc, c5v = coord_descent(h_pert, n, min(t_phase3, time.time() + budget_s * 0.01), max_sweeps=200, seed=seed+it)
        temp = 0.002 * cool + 0.0002
        if c5v < work_c5 or np.random.rand() < np.exp(-(c5v - work_c5) / max(temp, 1e-9)):
            work_h = hc
            work_c5 = c5v
        if c5v < best_c5:
            best_c5 = c5v
            best_h = hc
    if work_c5 < best_c5:
        best_c5 = work_c5
        best_h = work_h
    
    # Phase 4: Final CD (10% budget)
    t_phase4 = t0 + budget_s * 0.98
    best_h, best_c5 = coord_descent(best_h, n, t_phase4, max_sweeps=10000, seed=seed+999)
    
    # Final polish with SLSQP
    if elapsed() < budget_s * 0.99:
        try:
            hc = slsqp_opt(best_h.copy(), 10000, n, maxiter=500)
            c5v = compute_c5(hc)
            if c5v < best_c5:
                best_c5 = c5v
                best_h = hc
        except Exception:
            pass
    
    best_h = project(best_h, n / 2.0)
    best_c5 = compute_c5(best_h)
    return best_h, best_c5, n
```

Wait, I need to think about whether this will actually be faster. The key question is: how fast is coord_opt_fast?

For n=160:
- np.correlate(h, 1-h): O(n²) ≈ 25600 ops, maybe 50μs
- Computing D: O(n) vectorized, maybe 5μs
- minimize_scalar: ~50 evaluations of f1d, each O(n) ≈ 319 ops, total ~16000 ops ≈ 20μs
- Total per coordinate: ~75μs

For a sweep of 160 coordinates: 160 * 75μs ≈ 12ms
In 600 seconds (55% of budget): 600/0.012 = 50,000 sweeps!

That's a LOT of sweeps. The previous code probably did maybe 2000-5000 sweeps total. So this is 10-25x more coordination passes.

But wait, I'm also doing a full np.correlate inside coord_opt_fast, which is O(n²). Can I avoid that?

The purpose of the initial np.correlate is to get the current corr values, from which I compute C = corr - h_i * D. 

Alternative: maintain the correlation incrementally. When h[i] changes from old_val to new_val, update corr[p] by:
Δcorr[p] = (new_val - old_val) * D[p] - (new_val² - old_val²) * [p==n-1]

This avoids the O(n²) correlate call! The update is O(n).

Let me restructure:

```python
def coord_descent_v2(h, n, t_end, max_sweeps=50000):

    corr = np.correlate(best_h, 1.0 - best_h, mode='full')
    best_c5 = corr.max() * (2.0/n)
```
