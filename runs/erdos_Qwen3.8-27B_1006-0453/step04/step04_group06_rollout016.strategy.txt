We use a combination of coordinate descent, stochastic local search, and multi-resolution refinement to improve the current solution. The key bottleneck is the difficulty of escaping local optima in the non-convex overlap minimization problem. To address this:  
1. **Diversified Initialization**: Start with multiple random phases of coordinate descent to avoid premature convergence.  
2. **Annealing Schedule**: Use high temperatures in surrogate optimization to explore the solution space more thoroughly.  
3. **Perturbation Strategies**: Apply random noise and coordinate-wise optimization to escape shallow optima.  
4. **Resolution Transfer**: Gradually refine the grid resolution to balance between exploration and exploitation.

**Bottleneck Addressed**:  
The reference implementation struggles to consistently improve the initial state from 0.380911 by relying on local searches (coordinate descent and SLSQP) without sufficient global exploration.

### Mathematical Specification
**Objective**: Minimize \( C_5 = \max_k \int_0^2 h(x) (1 - h(x+k))  dx \) subject to \( \sum h_i = N/2 \) and \( 0 \leq h_i \leq 1 \), where \( N \) is the number of grid points.  
**Discretization**: Use \( dx = 2/N \) and compute \( C_5 \) via full correlation:  
\[
C_5 = \frac{\max(\text{correlation})}{\text{length}} \cdot dx
\]
**Constraints**:  
- \( h_i \in [0, 1] \) for all \( i \)  
- \( \sum h_i = N/2 \)  

### Implementation Procedure
**1. Initialization**:  
- Use initial guess from `initial_h_values` (if available) or sinusoidal function.  
- Project initial guess to feasible set: clip values and scale to satisfy sum constraint.  

**2. Validation Function**:  
```python
def validate(h, n):
    # Clip to [0,1] and re-scale to meet sum constraint.
    h = np.clip(h, 0, 1)
    total = np.sum(h)
    if abs(total - n/2.0) > 1e-6:
        h_scaled = h * (n/2.0) / total if total > 0 else np.ones_like(h) * 0.5
        return np.clip(h_scaled, 0, 1)
    return h
```  

**3. Coordinate Descent Sweep**:  
```python
def coordinate_descent(h, n, steps=300):
    best_h = h.copy()
    t0 = time.time()
    progress = 300 - steps  # Target progress (90% of sweeps)
    for i in range(steps):
        if i % 10 == 0 and time.time() - t0 > progress:
            return best_h
        # Set h[i] to 0 temporarily
        h_base = h.copy()
        h_base[i] = 0.0
        corr_prev = compute_c5(h_base)
        best_val = corr_prev
        best_x = 0.0
        # Binary search for optimal h[i]
        low, high = 0.0, 1.0
        while high - low > 1e-4:
            mid = (low + high) / 2.0
            h_try = h_base.copy()
            h_try[i] = mid
            corr_try = compute_c5(h_try)
            if corr_try < best_val - 1e-6:
                best_val = corr_try
                best_x = mid
                low = mid
            elif mid > best_x:
                high = mid
        # Update h[i] and record if improved
        if best_x > 1e-6:
            h_base[i] = best_x
            corr_base = compute_c5(h_base)
            if corr_base < compute_c5(best_h):
                best_h = h_base.copy()
    return best_h
```

**4. Stochastic Local Search**:  
- **Phase 1**: Apply random phase perturbations:  
  ```python
  def random_phase_perturbation(h, n, seed=None):
      if seed is not None:
          np.random.seed(seed)
      perturb = 0.05 * np.random.rand(n)   # Small random noise
      h_try = h + perturb
      h_clean = validate(h_try, n)
      return h_clean
  ```
- **Frequency**: Every 50 sweeps (at phase boundaries).

**5. Annealing with SLSQP**:  
- Use \( T \) to smooth the objective:  
  \[
  f_T(h) = \max_k \left( I_k + \frac{1}{T} \log \left( \sum_{m} e^{T(I_m - I_k)} \right) \right)
  \]
- Optimize with SLSQP, providing gradients via finite differences.

**6. Refinement Phases**:  
- **Phase 5**: Transfer to 500 points via interpolation and repeat coordinate descent.  
- **Phase 6**: Use high \( T \) annealing for wider exploration.

### Resolving Parent Constraints

- If `initial_h_values` is provided, use it as starting point for coordinate descent sweeps.  
- Do not attempt to down-sample unless explicitly targeted by grid refinement.

**2. Grid Refinement**:  
- For new grid size \( n_{\text{new}} \):  
  ```python
  def interpolate_solution(h_old, n_old, n_new):
      x_old = np.linspace(0, 2, n_old, endpoint=False)
      x_new = np.linspace(0, 2, n_new, endpoint=False)
      h_new = np.interp(x_new, x_old, h_old, bounds=[0,2], method='linear')
      return validate(h_new, n_new)
  ```

**3. Budget Management**:  
- **Time-based Checkpoints**: Monitor elapsed time and terminate if risk of exceeding budget.  
- **Early Termination**: Stop when objective plateau occurs or 25% improvement threshold is reached.

**Post-check**: Recompute objective to ensure score is not stale.  
**Output Format**:  
- `(h_values, c5_bound, n_points)`  
- `n_points = max(original N, grid refinement N)`
