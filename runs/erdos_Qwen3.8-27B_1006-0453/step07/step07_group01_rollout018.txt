import numpy as np

def fft_corr(h):
    N = len(h)
    L = 2 * N - 1
    H = np.fft.rfft(h, L)
    G = np.fft.rfft(np.flip(1.0 - h), L)
    return np.fft.irfft(H * G, L)

def compute_c5(h, N):
    return float(np.max(fft_corr(h))) * (2.0 / N)

def project_sum(h, target):
    h = np.clip(h, 0.0, 1.0)
    s = float(h.sum())
    if abs(s - target) < 1e-10:
        return h
    lo, hi = -1.0, 1.0
    for _ in range(40):
        mid = 0.5 * (lo + hi)
        if float(np.clip(h - mid, 0.0, 1.0).sum()) > target:
            lo = mid
        else:
            hi = mid

                grad[M:] -= wi * h[:N-M]

        m = beta * (h_new - h)
        h = h_new
        it += 1

- For position i, the contribution to corr at shift k (index N-1+k) is:
  - If i is the "first" index: h[i] * (1-h[i+k]), valid when 0<=i+k<N
  - If i is the "second" index: h[i-k] * (1-h[i]), valid when 0<=i-k<N

So corr[N-1+k] = sum_{i: 0<=i+k<N} h[i]*(1-h[i+k])
And also = sum_{j: 0<=j<N} h[j-k]*(1-h[j]) where j=i+k (reindexing)

These are the same sum, just written differently.

Now, if I change h[i] from v to v':
- corr[N-1+k] changes by:
  - From "first index" at i: v'*(1-h[i+k]) - v*(1-h[i+k]) = (v'-v)*(1-h[i+k]) for 0<=i+k<N
  - From "second index" at i: h[i-k]*(1-v') - h[i-k]*(1-v) = h[i-k]*(v-v') for 0<=i-k<N

So for i: 1→0 (v=1, v'=0):
  - First index: -(1-h[i+k]) for 0<=i+k<N
  - Second index: h[i-k] for 0<=i-k<N

For i: 0→1 (v=0, v'=1):
  - First index: +(1-h[i+k]) for 0<=i+k<N
  - Second index: -h[i-k] for 0<=i-k<N

So the effect of changing h[i] is a fixed vector (depending on current h at other positions) plus/minus.

The key: for a swap (p:1→0, q:0→1), the total delta on corr is:
delta = effect(p, 1→0) + effect(q, 0→1)

Where:
effect(p, 1→0) at index m=N-1+k:
  = -(1-h[p+k]) * [0<=p+k<N] + h[p-k] * [0<=p-k<N]

effect(q, 0→1) at index m=N-1+k:
  = (1-h[q+k]) * [0<=q+k<N] - h[q-k] * [0<=q-k<N]

So if I precompute these effect vectors, I can evaluate any swap in O(2N) (just add two vectors and take max).

But the effect vectors change as h changes. However, for a swap (p,q), only the effects at p and q change (since h only changes at those two positions). So I can:
1. Maintain the corr array
2. Maintain effect vectors for all positions
3. For a swap: delta = effect[p] (for 1→0) + effect_neg[q] (for 0→1)

4. new_corr = corr + delta
5. new_P = max(new_corr)
6. If accepted, update corr, and update effect vectors at all positions affected by the h change at p and q.

- effect[i, 1→0] changes at shifts where i+k=p or i-k=p
