def fft_corr(h):
    N = len(h)
    L = 2 * N - 1
    H = np.fft.fft(h, L)
    G = np.fft.fft(np.flip(1.0 - h), L)
    return np.real(np.fft.ifft(H * G))[:L]

def compute_c5(h):
    N = len(h)
    return float(np.max(fft_corr(h))) * (2.0 / N)

So new_c = c - D[p] - D[q]. Here D[p] is the row for position p (which is a one) and D[q] is the row for position q (which is a zero).

But actual is [0,0,1]. So the formula is wrong for this case. But as I discussed, for large N the error is small.

For the 2-swap, I'll use: new_c ≈ c - D[p1] - D[p2] - D[q1] - D[q2]

This is consistent with the single-swap approximation extended to 2 pairs.

Now let me think about the soft-max gradient approach:

The objective is f(h) = max_k c[k] where c = corr(h, 1-h).

A smooth approximation: f_β(h) = (1/β) * log(Σ_k exp(β*c[k]/max(c))) 

Or better: f_β(h) = (1/β) * log(Σ_k exp(β*c[k]))

The gradient: ∂f_β/∂h[i] = Σ_k (exp(β*c[k])/Σ_j exp(β*c[j])) * ∂c[k]/∂h[i]

And ∂c[k]/∂h[i] can be computed from the D matrix (with appropriate signs).

Actually, ∂c[k]/∂h[i] = ∂/∂h[i] Σ_m h[m+δ]*(1-h[m])
= (1-h[i-δ]) if i-δ is valid (h[i] appears as m+δ=m where m=i-δ, contributing h[i]*(1-h[i-δ]))
  Wait: c[k] = Σ_m h[m+δ]*(1-h[m])
  ∂c[k]/∂h[i]: h[i] appears when m+δ=i (m=i-δ) as a factor h[i], and when m=i as (1-h[i]).
  = (1-h[i-δ])*valid(i-δ) - h[i+δ]*valid(i+δ)

Hmm wait, that's: ∂c/∂h[i] = (1-h[i-δ]) - h[i+δ] (for valid indices)

This is exactly -D[i,k]! Since D[i,k] = -(1-h[i-δ]) + h[i+δ].

So ∂c[k]/∂h[i] = -D[i,k].

Therefore: ∂f_β/∂h[i] = -Σ_k w_k * D[i,k] where w_k = exp(β*c[k])/Σ_j exp(β*c[j])

This is a weighted sum of rows of D, with weights concentrated on the shifts where c is largest.

For the gradient descent: h_new = project(h - lr * grad, sum=N/2)

This is clean and efficient! The key advantage over the previous Nesterov approach (which uses argpartition to approximate the max gradient) is that the soft-max gives a TRUE gradient of a smooth surrogate, allowing more principled optimization.

def fft_corr(h):
    N = len(h)
    L = 2 * N - 1
    H = np.fft.fft(h, L)
    G = np.fft.fft(np.flip(1.0 - h), L)
    return np.real(np.fft.ifft(H * G))[:L]

def project_sum(h, target):

            lo = mid

def compute_D(h, N):
    shifts = np.arange(2 * N - 1) - (N - 1)

    pp_c = np.clip(pp, 0, N - 1)
    hm = np.where(vm, h[pm_c], 0.0)

def softmax_gradient_descent(h, N, deadline, beta0=50.0, beta_max=500.0, lr0=0.03, decay=0.999):
    h = h.astype(float).copy()
    target = N / 2.0
    dx = 2.0 / N
    best_h = h.copy()
    best_pk = float(np.max(fft_corr(h)))
    beta = beta0
    lr = lr0
    momentum = np.zeros(N)
    mu = 0.9
    it = 0
    while time.time() < deadline:
        c = fft_corr(h)
        pk = float(np.max(c))
        if pk < best_pk - 1e-14:
            best_pk = pk
            best_h = h.copy()
        # Soft-max weights
        c_shifted = c - c.max()  # numerical stability
        w = np.exp(beta * c_shifted)
        w_sum = w.sum()
        if w_sum > 0:
            w = w / w_sum
        else:
            w = np.ones_like(c) / len(c)
        # Compute D
        D = compute_D(h, N)
        # Gradient: ∂f/∂h[i] = -Σ_k w_k * D[i,k]
        grad = -(D @ w)
        # Gradient step with momentum
        momentum = mu * momentum - lr * grad
        h_new = h + momentum
        h_new = project_sum(h_new, target)
        h = h_new
        it += 1
        if it % 50 == 0:
            beta = min(beta_max, beta * 1.02)
            lr = lr * decay
            mu = min(0.98, mu + 0.001)
    return best_h, best_pk * dx
