```python
def swap_delta(h, p, q, N):
    """Compute ΔC[k] for all k when h[p]:1→0 and h[q]:0→1"""
    # ΔC[k] = -(1-h[p+k]) + h[p-k] + (1-h[q+k]) - h[q-k]
    # with boundary: if index out of [0,N), term is 0
    center = N - 1
    delta = np.zeros(2*N - 1)
    for shift in range(2*N - 1):
        k = shift - center
        val = 0.0
        # -(1-h[p+k]) if p+k in [0,N)
        pk = p + k
        if 0 <= pk < N:
            val -= (1.0 - h[pk])
        # +h[p-k] if p-k in [0,N)
        pk2 = p - k
        if 0 <= pk2 < N:
            val += h[pk2]
        # +(1-h[q+k]) if q+k in [0,N)
        qk = q + k
        if 0 <= qk < N:
            val += (1.0 - h[qk])
        # -h[q-k] if q-k in [0,N)
        qk2 = q - k
        if 0 <= qk2 < N:
            val -= h[qk2]
        delta[shift] = val
    return delta
```

The key insight is that the continuous problem (h ∈ [0,1]^N, sum = N/2) might be easier to optimize, and then we binarize at the end.

Objective: f(h) = max_k C[k] where C = fft_corr(h)

This is a max of linear functions (for fixed h, C[k] is... wait, C[k] = ∑ h[i](1-h[i+k]) is QUADRATIC in h, not linear.

Hmm, so it's not a convex problem. But maybe we can use a subgradient approach.

Actually, for the continuous case:
C[k] = ∑_i h[i] - ∑_i h[i]h[i+k]

The gradient w.r.t. h[j]:
∂C[k]/∂h[j] = 1 - h[j+k] - h[j-k] (for valid indices)
= 1 - h[j+k] - h[j-k]

So the gradient of f(h) = max_k C[k] is:
∂f/∂h[j] = max over active k of (1 - h[j+k] - h[j-k])

where "active" k are those achieving the maximum.

This is a subgradient (since max of differentiable functions is subdifferentiable).

We can use:
∂f/∂h[j] ≈ (1/T) ∑_k (C[k]/T)^m × (1 - h[j+k] - h[j-k]) / (∑_l (C[l]/T)^m)

This is the softmax-approximated gradient.

Let me try Nesterov with this gradient:

def nesterov_smooth(h, N, deadline, T=5.0, k_active=20, lr=0.01):
    h = h.astype(float).copy()
    target = N / 2.0
    best = h.copy()
    best_pk = np.inf
    m = np.zeros(N)
    
    while time.time() < deadline:
        y = h + m
        C = fft_corr(y)
        pk = float(C.max())
        
        if pk < best_pk:
            best_pk = pk
            best = h.copy()
        
        # Softmax weights
        Cm = C / T
        exp_Cm = np.exp(Cm - Cm.max())
        w = exp_Cm / exp_Cm.sum()
        
        # Gradient: ∂C[k]/∂h[j] = 1 - h[j+k] - h[j-k] (valid)
        # ∂f/∂h[j] = ∑_k w[k] * (1 - h[j+k] - h[j-k])
        
        # Vectorized computation
        center = N - 1
        grad = np.zeros(N)
        for k_shift in range(2*N-1):
            k = k_shift - center
            if abs(w[k_shift]) < 1e-10:
                continue
            # ∂C[k]/∂h[j] for all j:
            # = 1(for j+k valid) - h[j+k](if valid) - h[j-k](if valid)
            # Term 1: j+k valid iff 0<=j+k<N iff -k<=j<N-k
            # Term 2: h[j+k] for 0<=j+k<N
            # Term 3: h[j-k] for 0<=j-k<N
            lo = max(0, -k)
            hi = min(N, N-k)
            if hi > lo:
                grad[lo:hi] += w[k_shift] * 1.0
                jk = np.arange(lo, hi) + k
                grad[lo:hi] -= w[k_shift] * h[jk]
            lo2 = max(0, k)
            hi2 = min(N, N+k)
            if hi2 > lo2:
                jn = np.arange(lo2, hi2) - k
                grad[lo2:hi2] -= w[k_shift] * h[jn]
        
        # Project gradient descent step
        h_new = np.clip(h - lr * grad, 0, 1)
        # Fix sum
        s = h_new.sum()
        if s != target:
            h_new = project_sum(h_new, target)
        
        m = 0.9 * (h_new - h)
        h = h_new
    return best, best_pk

Actually, the gradient computation can be done as:
∂f/∂h[j] = ∑_k w[k] * (1_{j+k valid} - h[j+k] * 1_{j+k valid} - h[j-k] * 1_{j-k valid})

The first term: ∑_k w[k] * 1_{j+k valid} = number of valid k for position j, weighted
Actually, for the "full" correlation with shifts -(N-1) to (N-1):
- j+k is valid (in [0,N)) iff k ∈ [-j, N-1-j]
- The number of such k is N (for any j)
- So the first term is ∑_{k valid for j} w[k]

The second term: ∑_k w[k] * h[j+k] * 1_{j+k valid}
This is a weighted sum of h at positions shifted by k from j, weighted by w[k].
This is a convolution! (j+k ranges over valid positions, weighted by w[k])

Specifically: second term at position j = ∑_k w[k] * h[j+k] = (w_reversed * h)[j] (circular conv)
But it's not circular, it's with boundary (only valid indices count).

Actually, for the linear convolution: if we define W[k] = w[k+(N-1)] for k = -(N-1)..(N-1), then:
∑_k W[k] * h[j+k] is the linear cross-correlation of W and h evaluated at j.

This can be computed via FFT!

So:
grad[j] = S[j] - (W * h)[j] - (W * flip(h))[j] (approximately)

Where S[j] = ∑_k w[k] for valid k (which is just the sum of w over the valid range for j).

**Simpler approach: Direct gradient via FFT**

The key observation: ∂C[k]/∂h[j] has a simple structure. Let me define:
- A_k[j] = 1 if j+k ∈ [0,N) else 0
- B_k[j] = h[j+k] if j+k ∈ [0,N) else 0  
- C_k[j] = h[j-k] if j-k ∈ [0,N) else 0

Then ∂C[k]/∂h[j] = A_k[j] - B_k[j] - C_k[j]

And the smooth gradient is:
g[j] = ∑_k w_k * (A_k[j] - B_k[j] - C_k[j])

Where:
- ∑_k w_k * A_k[j] = sum of w_k for k where j+k ∈ [0,N) = sliding window sum (O(N))
- ∑_k w_k * B_k[j] = ∑_k w_k * h[j+k] * A_k[j] = this is a correlation
- ∑_k w_k * C_k[j] = ∑_k w_k * h[j-k] * (j-k ∈ [0,N)) = this is also a correlation

The correlation computations can be done via FFT in O(N log N).

Let me just use a direct FFT approach:

For B: ∑_k w_k * h[j+k] where j+k ∈ [0,N)
Define array W of length L=2N-1: W[k] = w[k] for k=0..L-1 (shift = k-(N-1))
Define array H of length L: H[j] = h[j] for j=0..N-1, H[j]=0 for j≥N

The circular correlation (W ⊛ H)[j] = ∑_k W[k] * H[(j+k) mod L]
This is NOT what we want because we need the "linear" version.

But if we zero-pad to length L (which is 2N-1 ≥ N + (N-1) - 1... actually 2N-1 = (N-1) + N, so it's exactly the right length for linear convolution/correlation):

If we compute the circular correlation with zero-padded arrays of length L=2N-1:
corr[j] = ∑_{k=0}^{L-1} W[k] * H[(j+k) mod L]

Since H is zero for indices ≥ N, and W has length 2N-1:
corr[j] = ∑_{k: (j+k) mod (2N-1) < N} W[k] * h[(j+k) mod (2N-1)]

For j < N: (j+k) mod (2N-1) = j+k if j+k < 2N-1, else j+k-(2N-1)
Since j < N and k < 2N-1: j+k < 3N-2. For j+k ≥ 2N-1: (j+k)-(2N-1) < j+k-2N+1 < N+N-2N+1 = -1 < 0. So actually j+k < 2N-1 always (since j≤N-1, k≤2N-2, j+k≤3N-3, and 3N-3 could be ≥ 2N-1 for N≥2).

    w: array of length 2N-1, weights for each shift (index 0 = shift -(N-1), index 2N-2 = shift N-1)
