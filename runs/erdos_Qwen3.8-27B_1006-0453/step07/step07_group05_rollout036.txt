import time

def fft_corr(h):
    N = len(h)
    L = 2 * N - 1
    H = np.fft.rfft(h, L)
    G = np.fft.rfft((1.0 - h)[::-1], L)
    return np.real(np.fft.irfft(H * G, L))

def compute_c5(h):
    N = len(h)
    corr = fft_corr(h)
    return float(np.max(corr)) * (2.0 / N)

def steepest_descent(h, N, deadline, max_no_improve=50):
    nh = N // 2
    h = h.copy()
    corr = fft_corr(h)
    cur_max = float(np.max(corr))
    best_h = h.copy()
    best_c = cur_max * 2.0 / N
    no_improve = 0
    
    while time.time() < deadline:
        if no_improve > max_no_improve:
            break
        
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        
        best_delta = cur_max  # we want to minimize, so best is < cur_max
        best_oi, best_zi = -1, -1
        
        # Evaluate all single swaps
        for oi in ones:
            for zi in zeros:
                if oi == zi:
                    continue
                h[oi] = 0
                h[zi] = 1
                c = float(np.max(fft_corr(h)))
                h[oi] = 1
                h[zi] = 0
                if c < best_delta:
                    best_delta = c
                    best_oi, best_zi = oi, zi
        
        if best_oi >= 0 and best_delta < cur_max - 1e-12:
            h[best_oi] = 0
            h[best_zi] = 1
            corr = fft_corr(h)
            cur_max = best_delta
            best_h = h.copy()
            best_c = cur_max * 2.0 / N
            no_improve = 0
        else:
            no_improve += 1
    
    return best_h, best_c

  If h[b]: 0→1, then (1-h)[b]: 1→0, so (1-h)_new = (1-h) - e_b
  
  (1-h)_new[::-1] = (1-h)[::-1] + e_{N-1-a} - e_{N-1-b}
  
- G_new = G + rfft(e_{N-1-a}) - rfft(e_{N-1-b})

Now, rfft(e_j) for a unit vector at position j:
rfft(e_j, L)[k] = exp(-2πi*j*k/L) for k = 0, ..., L//2

So ΔH = -rfft(e_a) + rfft(e_b) = [exp(-2πi*b*k/L) - exp(-2πi*a*k/L)] for k=0,...,L//2
ΔG = rfft(e_{N-1-a}) - rfft(e_{N-1-b}) = [exp(-2πi*(N-1-a)*k/L) - exp(-2πi*(N-1-b)*k/L)]

Then:
corr_new = irfft(H_new * G_new) = irfft((H+ΔH)(G+ΔG)) = irfft(HG + HΔG + ΔH G + ΔH ΔG)

Since corr = irfft(HG), we have:
Δcorr = irfft(H*ΔG + ΔH*G + ΔH*ΔG)

This requires:
- H*ΔG: element-wise multiply of two complex arrays of length L//2+1 = 380
- ΔH*G: same
- ΔH*ΔG: same
- Sum: element-wise
- IFFT: one inverse FFT of length 759

The element-wise multiplies are fast (380 complex mults each). The IFFT is the bottleneck: ~759*log2(759) ≈ 759*10 = 7590 complex ops.

Compared to the full correlation: 2 FFTs + 1 IFFT ≈ 3 * 7590 = 22770 ops.

So the incremental approach is about 3x faster per evaluation. Not a huge improvement, but it adds up.

Actually, I realize there's a much better approach for the inner loop. Instead of computing the full FFT for each swap, I can compute the change in correlation analytically:

When I flip h[a] from 1 to 0 and h[b] from 0 to 1, the change in corr at lag k is:

Let me define corr[k] = Σ_n h[n+k] * (1-h[n]) for the "full" mode (with appropriate bounds).

Actually, let me use the circular version for simplicity first (it's an approximation but might be good enough for the heuristic):

If I flip h[a]: 1→0, h[b]: 0→1:
- At lag k, the terms involving a:
  - h[(a+k) mod N] * (1-h[a]): was h[(a+k))*(1), now h[(a+k)]*(0) = 0. Change: -h[(a+k)]
  - h[(a-k) mod N] * (1-h[a+k]): no wait...
  
  Let me be more careful. c_k = Σ_n h[(n+k) mod N] * (1-h[n])
  
  Terms where a appears:
  1. n = a: h[(a+k)%N] * (1-h[a]) = h[(a+k)] * 1 → h[(a+k)] * 0. Change: -h[(a+k)]
  2. n+k = a mod N, i.e., n = (a-k)%N: h[a] * (1-h[(a-k)%N]) = 1 * (1-h[(a-k)]) → 0 * (...). Change: -(1-h[(a-k)])
  
  Terms where b appears:
  1. n = b: h[(b+k)%N] * (1-h[b]) = h[(b+k)] * 0 → h[(b+k)] * 1. Change: +h[(b+k)]
  2. n+k = b mod N, i.e., n = (b-k)%N: h[b] * (1-h[(b-k)%N]) = 0 * (...) → 1 * (1-h[(b-k)]). Change: +(1-h[(b-k)])
  
  Cross terms (when a+k = b or b+k = a mod N): need to be careful, but for N=380 and random positions, this is rare.

So Δc_k = -h[(a+k)%N] - (1-h[(a-k)%N]) + h[(b+k)%N] + (1-h[(b-k)%N])

This is O(1) per lag k! So for a given swap (a,b), I can compute Δc_k for all k in O(N).

Then the new max = max(c_k + Δc_k) for all k.

But I still need to find the max over all k, which is O(N). So total per swap: O(N).

But I need to be careful: the circular correlation is NOT the same as the linear correlation. The linear correlation (mode="full") has 2N-1 lags and different bounds.

For the linear case: corr[k] = Σ_{n: 0≤n<N, 0≤n+k<N} h[n+k] * (1-h[n])

The change when flipping a (1→0) and b (0→1):
- At lag k, term a contributes if 0≤a<N (always) and 0≤a+k<N
  - n=a: h[a+k]*(1-h[a]) = h[a+k]*1 → 0. Change: -h[a+k] (if 0≤a+k<N)
  - n=a-k: h[a]*(1-h[a-k]) = 1*(1-h[a-k]) → 0. Change: -(1-h[a-k]) (if 0≤a-k<N)
- At lag k, term b contributes:
  - n=b: h[b+k]*(1-h[b]) = h[b+k]*0 → h[b+k]*1. Change: +h[b+k] (if 0≤b+k<N)
  - n=b-k: h[b]*(1-h[b-k]) = 0*(...) → 1*(1-h[b-k]). Change: +(1-h[b-k]) (if 0≤b-k<N)

So Δc_k (linear) = -h[a+k]*[0≤a+k<N] - (1-h[a-k])*[0≤a-k<N] + h[b+k]*[0≤b+k<N] + (1-h[b-k])*[0≤b-k<N]

where [condition] is 1 if true, 0 otherwise.

This is still O(1) per lag! Great.

1. Precompute corr (full linear) via FFT: O(N log N)
2. For each swap (a, b):

   b. Compute new_max = max(corr + Δc) in O(N)
   c. Track the best swap
3. Apply the best swap, recompute corr via FFT: O(N log N)
4. Repeat

Step 2 is O(N²/4 * N) = O(N³/4) per outer iteration ≈ 13.7M for N=380.
Step 3 is O(N log N) ≈ 3800.

import time

def fft_corr(h):
    N = len(h)
    L = 2 * N - 1
    H = np.fft.rfft(h, L)
    G = np.fft.rfft((1.0 - h)[::-1], L)
    return np.real(np.fft.irfft(H * G, L))

def compute_c5(h):
    N = len(h)
    return float(np.max(fft_corr(h))) * (2.0 / N)

def fix_sum(h, target):
    h = h.copy()
    s = int(h.sum())
    if s > target:
        excess = s - target
        ones = np.where(h == 1)[0]
        to_flip = np.random.choice(ones, excess, replace=False)
        h[to_flip] = 0
    elif s < target:
        deficit = target - s
        zeros = np.where(h == 0)[0]
        to_flip = np.random.choice(zeros, deficit, replace=False)
        h[to_flip] = 1
    return h

import numpy as np
import time

def fft_corr(h):
    N = len(h)
    L = 2 * N - 1
    H = np.fft.rfft(h, L)
    G = np.fft.rfft((1.0 - h)[::-1], L)
    return np.real(np.fft.irfft(H * G, L))

def compute_c5(h):
    N = len(h)
    return float(np.max(fft_corr(h))) * (2.0 / N)

def fix_sum(h, target):
    h = h.copy()
    s = int(h.sum())
    if s > target:
        ones = np.where(h == 1)[0]
        to_flip = np.random.choice(ones, s - target, replace=False)
        h[to_flip] = 0
    elif s < target:
        zeros = np.where(h == 0)[0]
        to_flip = np.random.choice(zeros, target - s, replace=False)
        h[to_flip] = 1
    return h

def best_single_swap(h, N, corr):
    """Find the best single swap (oi:1->0, zi:0->1) that minimizes max(corr)."""
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    cur_max = float(np.max(corr))
    
    best_val = cur_max
    best_oi, best_zi = -1, -1
    
    L = 2 * N - 1
    for oi in ones:
        for zi in zeros:
            if oi == zi:
                continue
            h[oi] = 0
            h[zi] = 1
            new_corr = fft_corr(h)
            new_max = float(np.max(new_corr))
            h[oi] = 1
            h[zi] = 0
            if new_max < best_val:
                best_val = new_max
                best_oi, best_zi = oi, zi
    
    return best_oi, best_zi, best_val

def ilds_search(h, N, deadline, seed):
    """Iterated Local Search with steepest descent on single swaps."""
    np.random.seed(seed)
    nh = N // 2
    h = h.copy().astype(float)
    corr = fft_corr(h)
    cur_max = float(np.max(corr))
    best_h = h.copy()
    best_c = cur_max * 2.0 / N
    
    stall = 0
    max_stall = 3
    
    while time.time() < deadline:
        # Steepest descent phase
        oi, zi, new_max = best_single_swap(h, N, corr)
        if oi >= 0 and new_max < cur_max - 1e-10:
            h[oi] = 0
            h[zi] = 1
            corr = fft_corr(h)
            cur_max = new_max
            stall = 0
            if cur_max * 2.0 / N < best_c:
                best_c = cur_max * 2.0 / N
                best_h = h.copy()
        else:
            stall += 1
            if stall > max_stall:
                # Kick: random perturbation
                kick_size = np.random.randint(3, 8)
                for _ in range(kick_size):
                    ones = np.where(h == 1)[0]
                    zeros = np.where(h == 0)[0]
                    if len(ones) == 0 or len(zeros) == 0:
                        break
                    oi = int(np.random.choice(ones))
                    zi = int(np.random.choice(zeros))
                    h[oi], h[zi] = h[zi], h[oi]
                corr = fft_corr(h)
                cur_max = float(np.max(corr))
                stall = 0
    
    return best_h, best_c

def fft_corr(h):
    N = len(h)
    L = 2 * N - 1
    H = np.fft.rfft(h, L)
    G = np.fft.rfft((1.0 - h)[::-1], L)
    return np.real(np.fft.irfft(H * G, L))

def compute_c5(h):
    N = len(h)
    return float(np.max(fft_corr(h))) * (2.0 / N)

def fix_sum(h, target):
    h = h.copy()
    s = int(h.sum())
    if s > target:
        ones = np.where(h == 1)[0]
        h[np.random.choice(ones, s - target, replace=False)] = 0
    elif s < target:
        zeros = np.where(h == 0)[0]
        h[np.random.choice(zeros, target - s, replace=False)] = 1
    return h

def eval_swap(h, oi, zi):
