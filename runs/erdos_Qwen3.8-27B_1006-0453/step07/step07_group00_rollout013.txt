For the gradient, let me derive it properly.

Given h of length N, define:
b = 1 - h
corr = np.correlate(h, b, "full")  # length 2N-1

For the "full" correlation: corr[k] = sum_{i} h[i + k - (N-1)] * b[i] for valid indices.

Let me define the shift: for output index k (0 to 2N-2), the effective lag is d = k - (N-1), ranging from -(N-1) to N-1.

For lag d ≥ 0: corr = sum_{i=0}^{N-1-d} h[i+d] * b[i]
For lag d < 0: corr = sum_{i=-d}^{N-1} h[i] * b[i+d]

The gradient of corr[k] w.r.t. h[j]:
For lag d ≥ 0:
- h[j] appears in the sum as h[i+d] when i = j-d (contributing b[j-d] if valid)
- h[j] appears in b[i] = 1-h[i] when i = j (contributing -h[j+d] if valid)

So: d corr[k] / d h[j] for lag d:
= b[j-d] * 1[j≥d] + (-h[j+d]) * 1[j < N-d]
= (1-h[j-d]) * 1[j≥d] - h[j+d] * 1[j<N-d]

For lag d < 0 (let m = -d > 0):
corr = sum_{i=m}^{N-1} h[i] * b[i-m]
- h[j] appears as h[i] when i = j (contributing b[j-m] = 1-h[j-m] if j≥m)
- h[j] appears in b[i-m] when i-m = j, i.e., i = j+m (contributing -h[j+m] if j+m < N)

So: d corr[k] / d h[j] for lag d = -m:
= (1-h[j-m]) * 1[j≥m] - h[j+m] * 1[j+m<N]

This is the same form! Let me denote the absolute lag |d| = m:
d corr / d h[j] = (1-h[j-m]) * 1[j≥m] - h[j+m] * 1[j+m<N]

So for the gradient of the max (or log-sum-exp), I need to sum over the top lags with appropriate weights.

For a given set of top lags with weights w_k:
grad[j] = sum_k w_k * [(1-h[j-m_k]) * 1[j≥m_k] - h[j+m_k] * 1[j+m_k<N]]

where m_k = |k - (N-1)|.

This can be computed in O(N * k_top) per iteration. For N=380, k_top=30, that's 11400 operations per gradient eval, which is very fast.

```python
def compute_grad(h, corr, k_top=30, lam=30.0):
    N = len(h)
    c_max = corr.max()
    weights = np.exp((corr - c_max) / lam)
    weights /= weights.sum()
    
    top = np.argpartition(corr, -k_top)[-k_top:]
    grad = np.zeros(N)
    
    for idx in range(k_top):
        w = weights[idx]
        k = int(top[idx])
        m = abs(k - (N - 1))  # absolute lag
        if m == 0:
            grad += w * (1.0 - 2.0 * h)
        else:
            # (1-h[j-m]) for j >= m
            grad[m:] += w * (1.0 - h[:N-m])
            # -h[j+m] for j < N-m
            grad[:N-m] -= w * h[m:]
    
    return grad, c_max + np.log(weights.sum() * lam) / lam  # lse value (not exactly, but ok)
```

```python
def fft_corr(h):

    L = 2 * N - 1
    H = np.fft.rfft(h, L)

def make_binary(h, N):

    target = N // 2
    n1 = int(np.round(h.sum()))
    if n1 > target:
        idx = np.where(h > 0.5)[0]
        h[np.random.choice(idx, n1 - target, replace=False)] = 0

        h[np.random.choice(idx, target - n1, replace=False)] = 1
    h[h > 0.5] = 1.0
    h[h <= 0.5] = 0.0
    diff = target - int(h.sum())
    if diff > 0:
        z = np.where(h == 0)[0]
        h[np.random.choice(z, min(diff, len(z)), replace=False)] = 1
    elif diff < 0:
        o = np.where(h == 1)[0]
        h[np.random.choice(o, min(-diff, len(o)), replace=False)] = 0
    return h

def build_deltas(h):
    N = len(h)
    s = 2.0 * h - 1.0
    deltas = np.zeros((N, 2 * N - 1))
    for i in range(N):
        deltas[i, i:i + N] = s
    return s, deltas

    m = np.zeros(N)
    beta = 0.85
    best_pk = compute_c5(h, N)
    best_h = h.copy()

        it += 1
        y = h + m
        corr = fft_corr(y)
        pk = float(corr.max())
        if pk * (2.0 / N) < best_pk:
            best_pk = pk * (2.0 / N)
            best_h = h.copy()
        c_max = corr.max()

        grad = np.zeros(N)
        for idx in range(k_top):

            k = int(top[idx])
            mlag = abs(k - (N - 1))
            if mlag == 0:
                grad += wi * (1.0 - 2.0 * y)
            else:
```
