delta_corr = (delta for p1→∅) + (delta for p2→∅) + (delta for ∅→q1) + (delta for ∅→q2) + interaction terms

The individual deltas are the same as single swaps. The key question is: can I efficiently find good 2-swaps?

One approach: 
1. Find the best single swap (p→q)
2. From the new state, find another good swap
3. If the combined move improves, take both

This is a "compound move" approach. It's simpler than full 2-swap optimization.

Another approach for 2-swaps:
- Precompute the effect of removing each 1 (call it R[p] = -contribution of h[p] to corr)
- Precompute the effect of adding each 1 at a 0-position (call it A[q] = +contribution)
- For a 2-swap (p1,p2→q1,q2): new_corr ≈ corr + R[p1] + R[p2] + A[q1] + A[q2] + interaction
- The interaction term is small (only affects a few points), so we can ignore it for candidate selection
- Then verify the top candidates exactly

For efficiency:
- R[p] for all p: O(N^2) to compute (each R[p] is a vector of length 2N-1)
- A[q] for all q: O(N^2) to compute
- For each pair (p1,p2): base = corr + R[p1] + R[p2], then find best (q1,q2)

The "find best (q1,q2)" step is O(N^2 * (2N)) which is O(N^3) per (p1,p2) pair, too slow.

import numpy as np
import time

def fft_corr(h):
    N = len(h)
    L = 2 * N - 1
    H = np.fft.fft(h, L)
    G = np.fft.fft(np.flip(1.0 - h), L)
    return np.real(np.fft.ifft(H * G))[:L]

def c5_val(h):
    return float(np.max(fft_corr(h))) * 2.0 / len(h)

def to_binary(h, N, seed=0):
    hb = (np.asarray(h, dtype=float) > 0.5).copy()
    n1, tgt = int(hb.sum()), N // 2
    if n1 != tgt:
        rng = np.random.RandomState(seed + N)
        if n1 > tgt:
            hb[rng.choice(np.where(hb)[0], n1 - tgt, replace=False)] = 0
        else:
            hb[rng.choice(np.where(~hb)[0], tgt - n1, replace=False)] = 1
    return hb.astype(float)

def greedy_fh(h, N, deadline, max_it=2000):
    h = h.copy()
    for _ in range(max_it):
        if time.time() > deadline:
            break
        corr = fft_corr(h)
        P = float(corr.max())
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break
        SH = np.zeros((N, 2 * N - 1))
        for i in range(N):
            SH[i, i:i + N] = h
        found = False
        for p in ones:
            base = corr + 2.0 * SH[p]
            base[p] -= 1.0
            diffs = base[None, :] - 2.0 * SH[zeros]
            diffs[np.arange(len(zeros)), zeros] -= 1.0
            mxs = diffs.max(axis=1)
            if mxs.min() < P - 1e-13:
                mi = int(np.argmin(mxs))
                h[p] = 0.0
                h[int(zeros[mi])] = 1.0
                found = True
                break
        if not found:
            break
    P = float(np.max(fft_corr(h)))
    return h, P * (2.0 / N)

def sa_run(h, N, deadline, T0=3.0, Tcl=0.996, Tm=0.03, nswap=1, kick_int=400, kick_n=4):
    h = h.copy()
    corr = fft_corr(h)
    P = float(corr.max())
    best_P = P
    best_h = h.copy()
    T = T0
    stall = 0
    while time.time() < deadline:
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        if len(ones) < nswap or len(zeros) < nswap:
            break
        ps = np.random.choice(ones, nswap, replace=False)
        qs = np.random.choice(zeros, nswap, replace=False)
        h[ps] = 0.0
        h[qs] = 1.0
        nc = fft_corr(h)
        nP = float(nc.max())
        d = nP - P
        if d < -1e-13 or np.random.random() < np.exp(-max(d, 0.0) / max(T, 1e-12)):
            P, corr = nP, nc
            if P < best_P - 1e-14:
                best_P = P
                best_h = h.copy()
                stall = 0
        else:
            h[ps] = 1.0
            h[qs] = 0.0
        stall += 1
        if stall >= kick_int:
            for _ in range(kick_n):
                o2 = np.where(h == 1)[0]
                z2 = np.where(h == 0)[0]
                if len(o2) < 2 or len(z2) < 2:
                    break
                h[o2[np.random.randint(len(o2))]] = 0.0
                h[z2[np.random.randint(len(z2))]] = 1.0
            P = float(fft_corr(h).max())
            corr = fft_corr(h)
            T = T0 * 0.6
            stall = 0
        T = max(Tm, T * Tcl)
    return best_h, best_P * (2.0 / N)
