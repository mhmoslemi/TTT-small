def continuous_optimize(h, N, deadline, lr0=0.005, push_binary=0.05):
    h = h.astype(float).copy()
    target = N / 2.0
    best_h = h.copy()
    best_c = compute_c5(h, N)
    lr = lr0
    alpha = push_binary
    it = 0
    
    while time.time() < deadline - 1:
        it += 1
        corr = fft_corr(h)
        peak = float(np.max(corr))
        # Get top few peaks for robust subgradient
        top_k = np.argsort(corr)[-3:]
        g = np.zeros(N)
        for k_idx in top_k:
            k = int(k_idx)
            # d(corr[k])/d(h[j]) for linear correlation
            # corr[k] = sum_i h[i+k] * (1-h[i]) for i=0..N-1-k
            # d/d(h[j]): if j < N-k: (1-h[j]) (from h[j] term) ... 
            # Actually: corr[k] = sum_{i=0}^{N-1-k} h[i+k]*(1-h[i])
            # d(corr[k])/d(h[j]):
            #   if j >= k and j < N: contributes as h[j] with (1-h[j-k])
            #   if j < N-k: contributes as (1-h[j]) with h[j+k], derivative = -h[j+k]
            # So: d(corr[k])/d(h[j]) = (1-h[j-k])*[j>=k] - h[j+k]*[j<N-k]
            
            if 0 <= k < N:
                # h[j] appears as first factor for j in [k, N-1]: contrib (1-h[j-k])
                # h[j] appears as second factor (1-h[j]) for j in [0, N-k-1]: contrib -h[j+k]
                j_range_1 = range(k, N)
                j_range_2 = range(0, N - k)
                for j in j_range_1:
                    g[j] += (1.0 - h[j - k])
                for j in j_range_2:
                    g[j] -= h[j + k]
            elif -N < k < 0:
                # Negative shift: corr[k] = sum_{i=-k}^{N-1} h[i+k]*(1-h[i])
                # = sum_{i=0}^{N+k-1} h[i]*(1-h[i-k])  ... hmm this gets complicated
                # For the FFT output, negative shifts are in the latter part
                # Let me just handle k >= 0 for now and use symmetry
                pass
        
        # Center gradient
        g = g - np.mean(g)
        
        # Push toward binary
        g -= 2.0 * alpha * (1.0 - 2.0 * h)
        
        h_new = h - lr * g
        h_new = np.clip(h_new, 0, 1)
        
        # Project to sum = N/2
        lo, hi = -1.0, 1.0
        for _ in range(25):
            mid = (lo + hi) / 2
            if np.clip(h_new - mid, 0, 1).sum() > target:
                lo = mid
            else:
                hi = mid
        h_new = np.clip(h_new - (lo + hi) / 2, 0, 1)
        
        c_new = compute_c5(h_new, N)
        if c_new < best_c:
            best_c = c_new
            best_h = h_new.copy()
        
        h = h_new
        if it % 50 == 0:
            lr *= 0.995
            alpha *= 0.98
    
    return best_h, best_c

Hmm, the gradient computation in the continuous optimizer is getting complicated and slow (O(N^2) per step). For N=380, that's about 144,000 operations per step. With the FFT evaluation being O(N log N) ≈ 3000 ops, the gradient would dominate.

Let me think of a faster gradient computation. Actually, the gradient of corr[k] w.r.t. h can be expressed as a convolution-like operation:
- g1[j] = 1 - h[j-k] (for j >= k, the "h[j]" part)
- g2[j] = -h[j+k] (for j < N-k, the "(1-h[j])" part)

g[j] = (1-h[j-k]) * (j>=k) - h[j+k] * (j < N-k)

This can be computed in O(N) for a given k. If we use only the top 1-2 k values, it's still O(N) per step.

Actually, for the single peak case, the gradient is:
g[j] = (1-h[j-k*]) * (j >= k*) - h[j+k*] * (j < N-k*)

This is O(N) to compute.

Let me simplify and use only the argmax shift for the subgradient.

Also, I realize I should think about whether continuous values actually help. The problem says h: [0,2] → [0,1], so it allows continuous values. But the evaluation uses np.correlate(h, 1-h, mode="full") * dx, which works for any h in [0,1].

For a continuous h, the max correlation might be lower than for any binary h, because we can "spread out" the mass more smoothly.

def fft_corr(h):
    N = len(h)
    L = 2 * N - 1
    H = np.fft.rfft(h, L)
    G = np.fft.rfft((1.0 - h)[::-1], L)
    return np.real(np.fft.irfft(H * G, L))
