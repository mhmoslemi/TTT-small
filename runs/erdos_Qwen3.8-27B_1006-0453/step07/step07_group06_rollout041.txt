Let me compute the gradient of the L2 objective:

L2 = sum_k corr(k)²

where corr(k) = cross_correlate(h, 1-h) at lag k.

In the frequency domain:
- Let H = FFT(h, L) and G = FFT(1-h, L) where L = 2N-1
- corr = IFFT(H * conj(G)) ... wait, let me be careful.

For numpy's correlate: np.correlate(a, v, 'full')[n] = sum_i a[i] * conj(v[i - n + (len(v)-1)])

For real signals, this is the cross-correlation. In FFT terms:
cross_corr = IFFT(FFT(a, L) * conj(FFT(v, L)))

where L >= len(a) + len(v) - 1.

So with a = h and v = 1-h:
cross_corr = IFFT(H * conj(G)) where H = FFT(h, L), G = FFT(1-h, L)

L2 = sum_k |cross_corr[k]|² = (1/L) * sum_freq |H[f] * conj(G[f])|² (by Parseval)
= (1/L) * sum_f |H[f]|² * |G[f]|²

Since G = FFT(1-h) = FFT(1) - FFT(h) = C - H where C = FFT(1-vector of length L)... actually it's more complex because of the zero-padding.

Let me define: h_padded = [h, 0, 0, ..., 0] (length L), v_padded = [1-h, 0, 0, ..., 0] (length L)
H = FFT(h_padded), G = FFT(v_padded)

Then |H[f]|² * |G[f]|² where G = FFT(v_padded).

Since v_padded[i] = 1 - h[i] for i < N and 0 for i >= N:
G[f] = sum_{i=0}^{N-1} (1-h[i]) * exp(-2πif/L) = sum_{i=0}^{N-1} exp(-2πif/L) - H[f] = B[f] - H[f]

where B[f] = sum_{i=0}^{N-1} exp(-2πif/L) = exp(-πi(N-1)f/L) * sin(πNf/L) / sin(πf/L) (geometric series)

So |G[f]|² = |B[f] - H[f]|²

L2 = (1/L) * sum_f |H[f]|² * |B[f] - H[f]|²

This is a function of H (the FFT of h), and by linearity of FFT, it's a function of h.

The gradient: dL2/dh[m] is complex to compute analytically in the time domain.

**Simpler approach**: Use the fact that L2 = sum_k corr(k)² and compute the gradient numerically or use the chain rule.

Actually, let me just use L-BFGS with a numerical gradient (or use scipy's minimize with method='L-BFGS-B' and let it compute numerical gradients). For N=380, a numerical gradient requires N function evaluations per gradient step, each O(N log N). That's manageable but slow.

Alternatively, I can compute the gradient analytically:
dL2/dh[m] = 2 * sum_k corr(k) * dcorr(k)/dh[m]

dcorr(k)/dh[m]: for the cross correlation sum_i h[i]*(1-h[i+k]):
- If m appears as h[i] (i=m, valid): d/dh[m] = (1-h[m+k])
- If m appears as h[i+k] (i=m-k, valid): d/dh[m] = -h[m-k]

So dcorr(k)/dh[m] = (1-h[m+k]) * I[valid] - h[m-k] * I[valid]

And dL2/dh[m] = 2 * sum_k corr(k) * [(1-h[m+k]) * I[k valid for i=m] - h[m-k] * I[k valid for i=m-k]]

This can be written as a convolution!

Let's define: A[k] = corr(k) (the full correlation, length 2N-1)
Then dL2/dh[m] = 2 * sum_k A[k] * (1-h[m+k]) * I[0<=m<N, 0<=m+k<N] - 2 * sum_k A[k] * h[m-k] * I[0<=m-k<N, 0<=m-k+k<N]

The first sum: for k such that 0<=m+k<N, i.e., -m <= k <= N-1-m:
sum_{k=max(-m, -(N-1))}^{min(N-1-m, N-1)} A[k] * (1-h[m+k])

Let j = m+k, so k = j-m:
= sum_{j=m}^{min(2m, N-1)} A[j-m] * (1-h[j])  (with appropriate bounds)

Hmm, this is essentially a cross-correlation of A with (1-h), evaluated at specific positions.

This is getting complex. Let me just use a simpler numerical approach: compute the L2 objective, use scipy's minimize with numerical gradients, and see if it works within the time budget.

Actually, for N=380, each L2 evaluation is O(N log N) ≈ 380 * 9 ≈ 3420 ops. With numerical gradient needing N evaluations, that's ~1.3M ops per gradient. L-BFGS needs maybe 50-100 iterations, each needing 1-2 gradients. So ~260M ops total. Should be under a second.

Wait, but the function is bounded (h in [0,1]) and we need to maintain the constraint sum(h) = N/2. This makes the numerical gradient tricky.

Let me just try a different approach: use the L2 objective as a "guide" but optimize with the binary local search, using the L2 to score moves.

**Revised plan:**
- Score each candidate swap by the reduction in L2 (sum of squares of overlap)
- This is different from scoring by the reduction in max
- The L2 reduction might guide the search differently, potentially escaping local optima of the max

And let me also add a "rebuild" step: after getting stuck, take the best solution, flip 30% of the positions (maintaining the constraint), and re-optimize.

Let me also add a key insight: **the optimal binary solution likely has a specific structure**. For the Erdős problem, the optimal set A should have roughly uniform "difference distribution" - i.e., for each k, the number of pairs {a, a+k} in A should be roughly constant. This is the "difference set" property.

A good heuristic: after each swap, check if the autocorrelation is becoming more "flat" (lower variance). If it is, the max is also likely decreasing.

import numpy as np
import time

def fft_corr(h):
    N = len(h)
    L = 2 * N - 1
    H = np.fft.rfft(h, L)
    G = np.fft.rfft(1.0 - h, L)
    return np.real(np.fft.irfft(H * G, L))

def compute_c5(h, N):
    return float(np.max(fft_corr(h))) * (2.0 / N)

def make_binary(h, nh):
    h = (h > 0.5).astype(float)
    n1 = int(h.sum())
    if n1 > nh:
        ones = np.where(h == 1)[0]
        h[np.random.choice(ones, n1 - nh, replace=False)] = 0
    elif n1 < nh:
        zeros = np.where(h == 0)[0]
        h[np.random.choice(zeros, nh - n1, replace=False)] = 1
    return h

def local_search(h, N, deadline, n_cands=50, stall_limit=200, two_swap=False, anneal_temp=0.0):
    h = h.copy()
    nh = N // 2
    h = make_binary(h, nh)
    corr = fft_corr(h)
    best_c = float(np.max(corr))
    best_h = h.copy()
    stall = 0
    it = 0
    while time.time() < deadline and stall < stall_limit and it < 8000:
        it += 1
        pk = float(np.max(corr))
        if pk < best_c - 1e-14:
            best_c = pk
            best_h = h.copy()
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        if len(ones) < (2 if two_swap else 1) or len(zeros) < (2 if two_swap else 1):
            break
        best_d = -1e6
        best_move = None
        for _ in range(n_cands):
            if two_swap:
                io = np.random.choice(len(ones), 2, replace=False)
                iz = np.random.choice(len(zeros), 2, replace=False)
                i1, i2 = int(ones[io[0]]), int(ones[io[1]])
                j1, j2 = int(zeros[iz[0]]), int(zeros[iz[1]])
                h[i1], h[i2], h[j1], h[j2] = 0, 0, 1, 1
                nd = pk - float(np.max(fft_corr(h)))
                h[i1], h[i2], h[j1], h[j2] = 1, 1, 0, 0
                if nd > best_d:
                    best_d = nd
                    best_move = (i1, i2, j1, j2)
            else:
                i = int(ones[np.random.randint(len(ones))])
                j = int(zeros[np.random.randint(len(zeros))])
                h[i], h[j] = 0, 1
                nd = pk - float(np.max(fft_corr(h)))
                h[i], h[j] = 1, 0
                if nd > best_d:
                    best_d = nd
                    best_move = (i, j)
        if best_move is not None:
            accept = best_d > 1e-14
            if not accept and anneal_temp > 0 and np.random.random() < np.exp(best_d / anneal_temp):
                accept = True
            if accept:
                if len(best_move) == 4:
                    a, b, c, d = best_move
                    h[a], h[b], h[c], h[d] = 0, 0, 1, 1
                else:
                    a, b = best_move
                    h[a], h[b] = 0, 1
                stall = 0
            else:
                stall += 1
                if anneal_temp > 0:
                    anneal_temp *= 0.999
        else:
            stall += 1
        corr = fft_corr(h)
    return best_h, best_c

def l2_continuous_min(h, N, deadline, T=40.0, lam=3.0):
    """Minimize soft-max (approximation of max) via L-BFGS on continuous h in [0,1]"""
    from scipy.optimize import minimize as sp_min
    h = h.astype(float).copy()
    target = N / 2.0
    best_h = h.copy()
    best_v = softmax_obj(h, T, target, lam)[0]

    def obj(x):
        return softmax_obj(x, T, target, lam)[0]

    def objg(x):
        return softmax_obj(x, T, target, lam)

    hlb = np.clip(h, 0, 1)
    for outer in range(3):
        if time.time() > deadline:
            break
        res = sp_min(objg, hlb, jac=True, method='L-BFGS-B',
                     bounds=[(0,1)]*N, options={'maxiter':100,'maxfun':300,'ftol':1e-14})
        hlb = np.clip(res.x, 0, 1)
        hlb = proj01(hlb, target)
        v = softmax_obj(hlb, T, target, lam)[0]
        if v < best_v:
            best_v = v
            best_h = hlb.copy()
    return best_h

def proj01(h, target):
    h = np.clip(h, 0.0, 1.0)
    lo, hi = -1.5, 1.5
    for _ in range(50):
        mid = (lo + hi) / 2.0
        if np.clip(h - mid, 0, 1).sum() > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def softmax_obj(h, T, target, lam):
    N = len(h)
    L = 2 * N - 1
    H = np.fft.rfft(h, L)
    G = np.fft.rfft(1.0 - h, L)
    corr = np.real(np.fft.irfft(H * G, L))
    mx = corr.max()
    e = np.exp(T * (corr - mx))
    es = e.sum()
    val = mx + np.log(es) / T
    s = h.sum() - target
    val += 0.5 * lam * s * s
    # Gradient via FFT shift
    g = np.zeros(N)
    w = e / es
    ctr = N - 1
    # Only do a subset for speed
    idx = np.where(w > 0.01)[0]
    for ii in idx[:30]:
        k = int(ii - ctr)
        if k == 0:
            g += w[ii] * (1.0 - 2.0 * h)
        elif k > 0:
            g[k:] += w[ii] * (1.0 - h[:N-k])
            g[:N-k] -= w[ii] * h[k:N]
        else:
            M = -k
            g[:N-M] += w[ii] * (1.0 - h[M:])
            g[M:] -= w[ii] * h[:N-M]
    g += lam * s * np.ones(N)
    return val, g

def structured_start(N, seed_val):
    """Generate diverse structured binary starts"""
    rng = np.random.RandomState(seed_val)
    nh = N // 2
    h = np.zeros(N)
    method = seed_val % 4
    if method == 0:
        phi = (1 + np.sqrt(5)) / 2
        pos = sorted(set(int((i * phi) % 1.0 * N) for i in range(nh)))
        while len(pos) < nh:
            pos.append(int(rng.randint(N)))
        for p in pos[:nh]:
            h[p] = 1
    elif method == 1:
        pos = rng.choice(N, nh, replace=False)
        h[pos] = 1
    elif method == 2:
        period = max(2, N // nh + 1)
        pos = list(range(0, N, period))
        while len(pos) < nh:
            pos.append(int(rng.randint(N)))
        for p in pos[:nh]:
            h[p] = 1
    else:
        half = N // 2
        pos = list(range(0, N, 2))[:nh]
        while len(pos) < nh:
            pos.append(int(rng.randint(N)))
        for p in pos[:nh]:
            h[p] = 1
    return h
