import time

def compute_corr(h):
    N = len(h)
    L = 2 * N - 1
    H = np.fft.fft(h, L)
    G = np.fft.fft(np.flip(1.0 - h), L)
    return np.real(np.fft.ifft(H * G))

def compute_c5(h):
    N = len(h)
    return float(np.max(compute_corr(h))) * (2.0 / N)

def project(h, target_sum):
    h = np.clip(h, 0.0, 1.0)
    s = h.sum()
    if abs(s - target_sum) < 1e-12:
        return h.copy()
    lo, hi = -1.5, 1.5
    for _ in range(60):
        mid = (lo + hi) / 2.0
        if np.clip(h - mid, 0, 1).sum() > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0, 1)

def grad_top(h, corr, k=60):

    center = N - 1
    top_idx = np.argsort(corr)[-k:]
    grad = np.zeros(N)
    for m in top_idx:

        if M == 0:
            grad += (1.0 - 2.0 * h)

            lo_idx = np.arange(0, N - M)
            grad[hi_idx] += (1.0 - h[hi_idx - M])
            grad[lo_idx] -= h[lo_idx + M]

    v = np.zeros(N)

    best_h = h.copy()

        lr = lr0 / np.sqrt(1 + 0.001 * t)

For d < 0, by symmetry of the correlation... actually, let me check.

For d < 0, let d' = -d > 0. The correlation at index N-1+d = N-1-d' is:
corr(N-1-d') = Σ_n h[n]·(1-h[n-d'])

Valid n: 0 ≤ n < N and 0 ≤ n-d' < N → d' ≤ n ≤ N-1.
So corr(N-1-d') = Σ_{n=d'}^{N-1} h[n]·(1-h[n-d'])

This is NOT the same as corr(d'). Let me see:
corr(d') = Σ_{n=0}^{N-1-d'} h[n]·(1-h[n+d'])

These are different! The first is h[n](1-h[n-d']), the second is h[n](1-h[n+d']).

By substitution m = n+d' in the first: Σ_{m=0}^{N-1-d'} h[m+d']·(1-h[m]) = Σ_m h[m+d'](1-h[m])

And the second: Σ_m h[m](1-h[m+d'])

These are NOT the same in general (unless h is symmetric).

So I need to handle d < 0 separately. For d < 0 (let d' = -d > 0):
