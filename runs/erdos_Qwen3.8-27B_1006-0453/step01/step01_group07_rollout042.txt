dci[k] = (1-h[i-lag_k])·[0≤i-lag_k<n] - h[i+lag_k]·[0≤i+lag_k<n]

where lag_k = k - (n-1) for k=0,...,2n-2.

i - lag_k = i - k + (n-1) = (i+n-1) - k
i + lag_k = i + k - (n-1)

So:
dci[k] = (1-h[(i+n-1)-k])·[0≤(i+n-1)-k<n] - h[i+k-(n-1)]·[0≤i+k-(n-1)<n]

For the first term: 0≤(i+n-1)-k<n → i ≥ k-(n-1) and (i+n-1)-k ≤ n-1 → k ≥ i
So valid k: i ≤ k ≤ i+n-1 (and k ≥ 0, k ≤ 2n-2)
The valid range is k ∈ [max(0,i), min(2n-2, i+n-1)]

For the second term: 0≤i+k-(n-1)<n → n-1-i ≤ k ≤ n-1+n-1-i = 2n-2-i
So valid k: max(0, n-1-i) ≤ k ≤ min(2n-2, 2n-2-i)

```python
def delta_cor_i(i, h, n):
    """Compute delta_corr vector for changing h[i]."""
    nc = 2 * n - 1
    dc = np.zeros(nc)
    # First term: (1-h[i-lag_k]) for valid k
    # i - lag_k = i - (k-(n-1)) = i+n-1-k
    # Valid when 0 ≤ i+n-1-k < n, i.e., i ≤ k ≤ i+n-1
    k_lo = max(0, i)
    k_hi = min(nc, i + n)  # exclusive
    if k_lo < k_hi:
        idx = i + n - 1 - np.arange(k_lo, k_hi)
        dc[k_lo:k_hi] += (1.0 - h[idx])
    # Second term: -h[i+lag_k]
    # i + lag_k = i + k - (n-1)
    # Valid when 0 ≤ i+k-(n-1) < n, i.e., n-1-i ≤ k ≤ 2n-2-i
    k_lo2 = max(0, n - 1 - i)
    k_hi2 = min(nc, 2 * n - 1 - i)  # exclusive
    if k_lo2 < k_hi2:
        idx2 = i + np.arange(k_lo2, k_hi2) - (n - 1)
        dc[k_lo2:k_hi2] -= h[idx2]
    return dc
```

This is O(n) with numpy vectorized operations.
