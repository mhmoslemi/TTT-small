\begin{align*}
\text{Minimize} \quad & \max_k \left(\int_0^2 h(x)(1-h(x+k))  dx\right) \\
\text{Subject to} \quad & \int_0^2 h(x)  dx = 1 \\
& 0 \leq h(x) \leq 1
\end{align*}
\]

The objective is evaluated approximately via:
\[
\frac{1}{dx} \cdot \max_k \left(\sum_{i=0}^{n-1} h[i](1-h[i+k]) \cdot dx\right)
\]
where \(dx = 2.0/45\).

**Constraints Implementation**:
- Integral constraint handled exactly via projected parameter updates.
- Bound constraints enforced via truncation and sliding technique.

**Notable Formulas**:
- Projection matrix: \(P = (X^\top X)^{-1} X^\top\) (least-squares solution)
- Solution: \(\theta = P \cdot b\) where \(b\) ensures integral constraint via \(\theta\)

def is_feasible(theta):
    # Theta: vector of parameters
    
    # Check bounds
    if not (np.min(theta) >= 0 - 1e-5 and np.max(theta) <= 1 + 1e-5):
        return False
    
    # Check integral
    if abs(sum(transform(theta) * dx - 1.0) > 1e-4:

    return True

def compute_c5(h):
    if not is_feasible(h):
