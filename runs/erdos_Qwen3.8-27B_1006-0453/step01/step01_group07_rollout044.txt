For h of length n, corr = np.correlate(h, 1-h, mode="full") has length 2n-1.

The numpy definition: for a of length N and v of length M:
c[k] = sum_{t} a[t+k] * conj(v[t]) for k = -(M-1), ..., N-1

In our case, a = h (length n), v = 1-h (length n):
c[k] = sum_{t: 0<=t<n, 0<=t+k<n} h[t+k] * (1-h[t])

where k ranges from -(n-1) to (n-1).

The output of mode="full" has indices 0 to 2n-2, where output[i] = c[i-(n-1)].

So output[i] = c[i-n+1] = sum_t h[t+i-n+1] * (1-h[t]) for valid t.

Let me denote k = i - (n-1), so:
output[n-1+k] = sum_t h[t+k] * (1-h[t]) for t in [max(0,-k), min(n, n-k)-1]

For the objective f(h) = max_k output[n-1+k]:
Let's use the soft-max: g(h) = beta * log(sum_k exp(output[n-1+k]/beta))

dg/dh[j] = (1/beta) * sum_k exp(output[n-1+k]/beta) * d(output[n-1+k])/dh[j]

d(output[n-1+k])/dh[j]:
output[n-1+k] = sum_t h[t+k] * (1-h[t]) for valid t

∂/∂h[j]:
- If j = t+k for some valid t (i.e., t = j-k is valid): contributes (1-h[t]) = (1-h[j-k])
- If j = t for some valid t (i.e., j is valid): contributes -h[j+k] (if j+k is valid)

So: d(output[n-1+k])/dh[j] = [1-h[j-k]]_{valid} - [h[j+k]]_{valid}

where [X]_{valid} means X if the index is in [0,n-1], else 0.
