Now for the subgradient:
∇f(h) at h where the max is achieved at shifts S = {k : c_k ≈ max(c)}:
∇f(h) = (1/|S|) * sum_{k in S} ∇c_k(h) * dx

Where ∇c_k(h)[j]:
- For shift s = k - (n-1):
  - If s = 0: 1 - 2*h[j]
  - If s > 0: (1-h[j+s]) for j < n-s, plus (-h[j-s]) for j ≥ s
  - If s < 0 (t=-s): (1-h[j-t]) for j ≥ t, plus (-h[j+t]) for j < n-t

Let me code the subgradient step:

def subgrad_step(h, n, alpha):
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    max_val = np.max(corr)
    # Active set: shifts within some tolerance of max
    active = corr >= max_val - 0.01 * max_val - 1e-10
    center = n - 1
    grad = np.zeros(n)
    for s in range(-(n-1), n):
        k = center + s
        if not active[k]:
            continue
        w = 1.0 / np.sum(active)
        if s == 0:
            grad += w * (1.0 - 2.0 * h)
        elif s > 0:
            grad[:n-s] += w * (1.0 - h[s:])
            grad[s:] += w * (-h[:n-s])
        else:
            t = -s
            grad[t:] += w * (1.0 - h[:n-t])
            grad[:n-t] += w * (-h[t:])
    grad *= dx
    h_new = h - alpha * grad
    h_new = project_onto_box_hyperplane(h_new, n)
    return h_new, compute_c5(h_new, n)
