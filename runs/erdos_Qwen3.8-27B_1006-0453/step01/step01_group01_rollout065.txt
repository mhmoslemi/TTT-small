Hmm wait, let me double-check. corr_k = Σ_{i=0}^{n-1-k} h[i](1-h[i+k]).

∂/∂h[2] = (1-h[3]) + (-h[1]) = 1 + 0 = 1

```python
def full_grad(h, n):
    """Gradient of the full correlation vector w.r.t. h, shape (2n-1, n)"""
    # This would be a (2n-1) x n matrix. For n=280, that's 559 x 280 = 156520 floats. Fine.
    grad = np.zeros((2*n-1, n))
    center = n - 1
    for offset in range(-(n-1), n):
        j = center + offset  # index in full correlation
        if offset > 0:
            # corr[j] = sum_{i=0}^{n-1-offset} h[i]*(1-h[i+offset])
            # ∂/∂h[p] = (1-h[p+offset]) for p in [0, n-1-offset]
            #              + (-h[p-offset]) for p in [offset, n-1]
            p1 = np.arange(0, n-offset)
            grad[j, p1] += (1.0 - h[offset:n])
            p2 = np.arange(offset, n)
            grad[j, p2] += (-h[0:n-offset])
        elif offset < 0:
            m = -offset
            # corr[j] = sum_{i=m}^{n-1} h[i]*(1-h[i-m])
            # ∂/∂h[p] = (1-h[p-m]) for p in [m, n-1]
            #              + (-h[p+m]) for p in [0, n-1-m]
            p1 = np.arange(m, n)
            grad[j, p1] += (1.0 - h[0:n-m])
            p2 = np.arange(0, n-m)
            grad[j, p2] += (-h[m:n])
        else:
            # corr[j] = sum h[i]*(1-h[i])
            grad[j, :] = 1.0 - 2.0*h
    return grad
```

But computing this full (2n-1, n) matrix is O(n²) which for n=280 is 280*559 = 156520 operations. That's fine.

Then the smooth max gradient is:
g = Σ_j w_j * grad[j] where w_j = softmax(t * (corr - mx))

This is a matrix-vector product: g = w @ grad, which is O(n²).

Then: h_new = proj(h - lr * g * dx, n) (the dx factor because C₅ = max(corr)*dx)

Actually, the gradient of C₅ = max(corr)*dx w.r.t. h is just dx * gradient of max(corr). So we multiply by dx.

This gives us a clean projected subgradient method! And it's fundamentally different from SLSQP.

Let me also implement a more advanced version: **proximal gradient / FISTA** style with acceleration, or at least a Polyak step size.

For the step size: since our objective is not strongly convex, we'll use a diminishing step: lr_t = c / sqrt(t) or lr_t = c / t.

But C₅ is not smooth (it's a max of bilinear functions), so the smooth max approximation is key. With the smooth max, the gradient is Lipschitz with constant dependent on t. For the smooth max with parameter t, the Lipschitz constant is approximately t * dx (roughly).

So lr ≈ 1 / (t * dx) might be a good starting step size.

Let me implement this:

```python
def projected_smooth_gradient(h, n, t, lr):
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    mx = np.max(corr)
    s = t * (corr - mx)
    s = np.clip(s, -50, 50)
    w = np.exp(s)
    w /= w.sum()
    
    # Compute weighted gradient
    grad = np.zeros(n)
    center = n - 1
    for offset in range(-(n-1), n):
        j = center + offset
        wj = w[j]
        if wj < 1e-10:
            continue
        if offset > 0:
            p1 = np.arange(0, n - offset)
            grad[p1] += wj * (1.0 - h[offset:n])
            p2 = np.arange(offset, n)
            grad[p2] += wj * (-h[0:n-offset])
        elif offset < 0:
            m = -offset
            p1 = np.arange(m, n)
            grad[p1] += wj * (1.0 - h[0:n-m])
            p2 = np.arange(0, n - m)
            grad[p2] += wj * (-h[m:n])
        else:
            grad += wj * (1.0 - 2.0 * h)
    
    return grad * dx
```

Alternative: use the fact that the gradient can be computed via convolution.

For the full correlation: corr[j] = (h * (1-h))[j] where * is the full cross-correlation.

The gradient ∂corr[j]/∂h[p] can be written as:
- It's a block matrix where the (j,p) entry is as derived above.

Actually, there's a cleaner way. Note that corr = np.correlate(h, 1-h, mode='full'). We can write:
corr = h ⊛ (1-h) (cross-correlation)

The Jacobian J[j,p] = ∂corr[j]/∂h[p] is a Toeplitz-like matrix.

For our purposes, the weighted gradient is: g = J^T @ w (where w is the softmax weight vector of length 2n-1).

J^T @ w means: for each p, g[p] = Σ_j J[j,p] * w[j].

From our derivation:
- For offset > 0, j = center + offset: J[j, p] has contributions from p in [0, n-1-offset] (value 1-h[p+offset]) and p in [offset, n-1] (value -h[p-offset]).
- For offset < 0, j = center + offset (offset = -m): J[j, p] has contributions from p in [m, n-1] (value 1-h[p-m]) and p in [0, n-1-m] (value -h[p+m]).

So g[p] = Σ_{offset>0: p≤n-1-offset} w[center+offset]*(1-h[p+offset]) + Σ_{offset>0: offset≤p<n} w[center+offset]*(-h[p-offset]) + Σ_{offset<0: p≥-offset} w[center+offset]*(1-h[p+offset]) + Σ_{offset<0: p<n-(-offset)} w[center+offset]*(-h[p+offset]) + w[center]*(1-2h[p])

    grad = np.zeros(n)
    
    # offset = 0
    grad += w[center] * (1.0 - 2.0 * h)
    
    # offset > 0: k = 1, ..., n-1
    for k in range(1, n):
        wj = w[center + k]
        if wj < 1e-12:
            continue
        # First part: p in [0, n-1-k], contribution (1-h[p+k])
        grad[:n-k] += wj * (1.0 - h[k:n])
        # Second part: p in [k, n-1], contribution (-h[p-k])
        grad[k:] += wj * (-h[:n-k])
        
        # offset < 0: -k
        wj2 = w[center - k]
        if wj2 < 1e-12:
            continue
        # First part: p in [k, n-1], contribution (1-h[p-k])
        grad[k:] += wj2 * (1.0 - h[:n-k])
        # Second part: p in [0, n-1-k], contribution (-h[p+k])
        grad[:n-k] += wj2 * (-h[k:n])
    
    return grad * dx
```

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def obj_smooth(h, t):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    mx = np.max(corr)
    s = t * (corr - mx)
    s = np.clip(s, -60, 60)
    return (mx + np.log(np.sum(np.exp(s))) / t) * dx

def proj(h, n):
    h = np.clip(h, 0.0, 1.0)
    tgt = n / 2.0
    for _ in range(1000):
        d = tgt - np.sum(h)
        if abs(d) < 1e-14:
            break
        m = h < 1.0 if d > 0 else h > 0.0
        cnt = np.count_nonzero(m)
        if cnt == 0:
            break
        h[m] += d / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

def ceq(x):
    return np.array([np.sum(x) - len(x) / 2.0])

def ceqj(x):
    return np.ones((1, len(x)))

def smooth_gradient(h, n, t):
    """Gradient of smooth max approximation of C5"""
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    mx = np.max(corr)
    s = t * (corr - mx)
    s = np.clip(s, -60, 60)
    w = np.exp(s)
    w /= w.sum()
    
    center = n - 1
    grad = np.zeros(n)
    grad += w[center] * (1.0 - 2.0 * h)
    
    for k in range(1, n):
        wk = w[center + k]
        wb = w[center - k]
        # For offset +k:
        if wk > 1e-14:
            grad[:n-k] += wk * (1.0 - h[k:n])
            grad[k:] += wk * (-h[:n-k])
        # For offset -k:
        if wb > 1e-14:
            grad[k:] += wb * (1.0 - h[:n-k])
            grad[:n-k] += wb * (-h[k:n])
    
    return grad * dx

def projected_gradient_descent(h, n, t, steps, lr0, rng):
    """PGD with backtracking line search"""
    h = h.copy()
    best_h = h.copy()
    best_c = compute_c5(h)
    lr = lr0
    
    for s in range(steps):
        g = smooth_gradient(h, n, t)
        # Backtracking line search
        for bt in range(10):
            h_trial = proj(h - lr * g, n)
            f_trial = obj_smooth(h_trial, t)
            f_curr = obj_smooth(h, t)
            if f_trial <= f_curr - 1e-8 * np.linalg.norm(g) * lr:
                h = h_trial
                break
            lr *= 0.5
        else:
            h = h - lr * g
            h = proj(h, n)
        
        c = compute_c5(h)
        if c < best_c:
            best_c = c
            best_h = h.copy()
        
        # Slowly decrease step size
        lr = lr0 / (1 + 0.001 * s)
    
    return best_h, best_c

def binary_swap_search(h, n, max_iters, rng):
    h = h.copy()
    best_c = compute_c5(h)
    ones = list(np.where(h >= 0.999)[0])
    zeros = list(np.where(h <= 0.001)[0])
    
    for it in range(max_iters):
        if not ones or not zeros:
            break
        i = ones[rng.randint(len(ones))]
        j = zeros[rng.randint(len(zeros))]
        h[i], h[j] = h[j], h[i]
        c = compute_c5(h)
        if c < best_c - 1e-16:
            best_c = c
            ones[ones.index(i)] = j
            zeros[zeros.index(j)] = i
        else:
            h[i], h[j] = h[j], h[i]
    
    return h, best_c

    except Exception:
