```python
        g[n] = 1.0
```

```python
        if w[idx_pos] > 1e-15:
            grad[lag:] += w[idx_pos] * (1.0 - h[:n-lag])
            grad[:n-lag] -= w[idx_pos] * h[lag:]
        
        # Negative lag (-lag): corr = sum_{i=0}^{n-1-lag} h[i]*(1-h[i+lag])
        # d/dh_j: (1-h_{j+lag}) for j in [0, n-1-lag]
        #         -h_{j-lag} for j in [lag, n-1]
        if w[idx_neg] > 1e-15:
            grad[:n-lag] += w[idx_neg] * (1.0 - h[lag:])
            grad[lag:] -= w[idx_neg] * h[:n-lag]
    
    return grad * dx
```

This is O(n^2) but vectorized, so it's fast.

Let me also add a "coordinate descent" step: for each coordinate, find the optimal value given all others fixed. This is a 1D optimization that's exact.

For coordinate j:
corr_k = ... + h[j]·(1-h[j-lag]) + (1-h[j])·h[j+lag] + ...
The contribution to corr_k from h[j] is:
- If j appears as h[i+k] in corr_k: contributes (1-h[i])
- If j appears as h[i] in corr_k (1-h[i+k]): contributes -h[i+k]

So the total contribution of h[j] to the objective is linear in h[j] (since it appears as a product h[j]·constant). The max of a set of affine functions of h[j] is convex in h[j]. So we're minimizing a convex function of h[j] over [0,1] (or [0,1] intersected with the sum constraint).

This is great! We can do exact coordinate minimization.

Wait, but the sum constraint couples all coordinates. If we change h[j], we need to adjust some other coordinate to maintain the sum. Unless we work in the space where the sum is already fixed.

Alternative: Do coordinate descent in the "free" space. Fix all coordinates except h[j] and h[m] for some "compensating" coordinate m. Then adjust both to maintain the sum.

Actually, the simplest approach: after changing h[j] by delta, change all other non-bound coordinates by -delta/(n-1) to maintain the sum. This is what project_sr does, but it's not optimal.

For exact coordinate descent:
- Fix all h[i] for i ≠ j
- The sum constraint gives: h[j] is free, but sum constraint means we need to adjust another coordinate
- This is a 2-variable problem (h[j] and h[m] for the compensating coordinate)

        if tok(30):
            h1 = slsqp_active(h0, dx, ts, 20, 400)
            c1 = compute_c5(h1, dx)
            if c1 < c5_0: h0, c5_0 = h1, c1

            if c2 < c5_0: h0, c5_0 = h2, c2
