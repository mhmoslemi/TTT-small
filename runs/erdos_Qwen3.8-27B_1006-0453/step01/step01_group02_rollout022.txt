But the issue is: random pair selection is very inefficient. Most swaps won't improve the solution. A better approach is to try all pairs at the "critical" lags (the ones that achieve the max) and see which swap reduces the max.

Let me think about this differently. The max is achieved at some lag k*. To reduce corr[k*], I need to find a pair (a,b) with h[a]=1, h[b]=0 such that the swap reduces corr[k*].

For lag k* (with m = k*-(N-1)):
corr[k*] = sum_j h[j]*(1-h[j+m]) (for valid j)

A swap (a:1→0, b:0→1) changes corr[k*] by:
- Remove contribution of j=a: -(1-h[a+m]) [if a+m valid]
- Remove contribution of j=a-m: was h[a-m]*(1-h[a])=h[a-m], now h[a-m]*(1-0)=h[a-m]. Change: 0.

Wait, I need to be more careful. The term at j=a in the sum is h[a]*(1-h[a+m]) = 1*(1-h[a+m]) = 1-h[a+m]. After swapping h[a] to 0, this becomes 0. Change: -(1-h[a+m]).

The term at j=a-m (if valid) involves h[a] as (1-h[j+m]) = (1-h[a]). Before: h[a-m]*(1-h[a]) = h[a-m]*0 = 0. After: h[a-m]*(1-0) = h[a-m]. Change: +h[a-m].

Similarly for b (0→1):
The term at j=b: was h[b]*(1-h[b+m]) = 0. Now: 1*(1-h[b+m]). Change: +(1-h[b+m]).
The term at j=b-m: was h[b-m]*(1-h[b]) = h[b-m]*1 = h[b-m]. Now: h[b-m]*(1-1) = 0. Change: -h[b-m].

But also, if a+m = b (i.e., b = a+m), then the "remove a" and "add b" effects interact. Let me handle this case separately.

For the general case (a+m ≠ b and b+m ≠ a):
Δcorr[k*] = -(1-h[a+m]) + h[a-m] + (1-h[b+m]) - h[b-m]

All with appropriate validity checks.

To reduce corr[k*], I want Δcorr[k*] < 0.

But I also need to not increase other lags beyond the current max. This is the hard part.

In practice, for local search, I'll just try random pairs and accept improvements. The key is to try enough pairs and use the incremental update.

But wait, I can precompute the a matrix (N × (2N-1)) and then the gradient is just A @ w, which is O(N * 2N) = O(N²). Let me vectorize this.

Actually, for each coordinate i, a_i is a vector of length 2N-1. The full gradient is:
grad[i] = sum_k w[k] * a_i[k] = (A @ w)[i]

where A is an N × (2N-1) matrix with A[i,k] = a_i[k].

Let me construct A:
A[i, k] = (1-h[i+m]) * [0≤i+m<N] - h[i-m] * [0≤i-m<N]

where m = k-(N-1).

This can be vectorized:
For each i, the valid m range for "i+m" is [max(-i, -(N-1)), min(N-1-i, N-1)]
And for "i-m" is [max(i-N+1, -(N-1)), min(i, N-1)]

Let me just construct it with broadcasting:

```python
def compute_A(h):
    N = len(h)
    m_range = np.arange(-(N-1), N)  # shape (2N-1,)
    I = np.arange(N)  # shape (N,)
    # i + m: shape (N, 2N-1)
    ipm = I[:, None] + m_range[None, :]  # (N, 2N-1)
    imn = I[:, None] - m_range[None, :]  # (N, 2N-1)
    vp = (ipm >= 0) & (ipm < N)
    vn = (imn >= 0) & (imn < N)
    # (1-h[i+m]) * vp - h[i-m] * vn
    h_im = np.where(vp, h[ipm[vp]], 0.0)  # this won't work with 2D indexing easily
    # Better:
    h_ipm = np.zeros_like(ipm, dtype=float)
    h_imn = np.zeros_like(imn, dtype=float)
    h_ipm[vp] = h[ipm[vp]]
    h_imn[vn] = h[imn[vn]]
    A = (1.0 - h_ipm) * vp.astype(float) - h_imn * vn.astype(float)
    return A
```

import numpy as np
import time

def compute_c5(h, dx):
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def project_sum(h, target):
    h = np.clip(h, 0.0, 1.0)
    s = float(h.sum())
    if abs(s - target) < 1e-13:
        return h.copy()
    lo, hi = -0.5, 0.5
    for _ in range(80):
        mid = (lo + hi) * 0.5
        if float(np.clip(h - mid, 0.0, 1.0).sum()) > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) * 0.5, 0.0, 1.0)

def build_A(h):
    N = len(h)
    m_range = np.arange(-(N - 1), N)
    I = np.arange(N)
    ipm = I[:, None] + m_range[None, :]
    imn = I[:, None] - m_range[None, :]
    vp = (ipm >= 0) & (ipm < N)
    vn = (imn >= 0) & (imn < N)
    h_ipm = np.where(vp, h[np.clip(ipm, 0, N - 1)], 0.0)
    h_imn = np.where(vn, h[np.clip(imn, 0, N - 1)], 0.0)
    return (1.0 - h_ipm) * vp.astype(np.float64) - h_imn * vn.astype(np.float64)

def adam_smooth(h, N, target, dx, t0, budget_s, n_iters, lr, tau0):
    best_c5 = compute_c5(h, dx)
    best_h = h.copy()
    m_buf = np.zeros(N)
    v_buf = np.zeros(N)
    b1, b2, eps = 0.9, 0.999, 1e-8
    tau = tau0
    for it in range(n_iters):
        if time.time() - t0 > budget_s - 10:
            break
        corr = np.correlate(h, 1.0 - h, mode='full')
        c5 = float(corr.max() * dx)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h.copy()
        sc = tau * corr
        sc -= sc.max()
        w = np.exp(sc)
        w /= w.sum()
        A = build_A(h)
        grad = A @ w
        m_buf = b1 * m_buf + (1 - b1) * grad
        v_buf = b2 * v_buf + (1 - b2) * grad * grad
        m_hat = m_buf / (1 - b1 ** (it + 1))
        v_hat = v_buf / (1 - b2 ** (it + 1))
        h = h - lr * m_hat / (np.sqrt(v_hat) + eps)
        h = project_sum(h, target)
        if (it + 1) % 400 == 0:
            lr *= 0.75
            tau *= 2.5
            if lr < 1e-7:
                break
    return best_h, best_c5
