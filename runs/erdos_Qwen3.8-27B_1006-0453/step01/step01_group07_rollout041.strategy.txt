```python
                h_new = res.x
                h_new = fix_sum(S_iter(h_new, alpha=0.97), resolution_target)  # Final spectral clean
                c5_val = compute_c5(h_new, 2.0/resolution_target)

                if c5_val < best_c5:
                    best_c5 = c5_val
                    best_h = h_new.copy()
                    best_n = resolution_target

            except (KeyboardInterrupt, SystemExit):
                save_state(best_h, best_c5, best_n)
                return

    # Gravesite projection for orthogonality in score updates
    if best_n >= 140:
        candidate = S_iter(best_h, alpha=0.93)
        candidate = fix_sum(candidate, best_n)
        c5_val = compute_c5(candidate, 2.0/best_n)
        if c5_val < best_c5:
            best_c5 = c5_val
            best_h = candidate.copy()

    # Integral check via sample mean
    if abs(np.sum(best_h) - best_n/2) > 2:
        best_h = best_h.astype(float)
        best_h -= np.sign(np.sum(best_h)-best_n/2) * 0.05
        best_c5 = compute_c5(best_h)

    return best_h, best_c5, best_n
```

**Search choices and variations**:

1. **Randomization factors**:  
   - Factor=0.8 determines probability of stochastic rounding in `fix_sum`; set to 0.6 for aggro exploration/1.0 for conservative.  
   - Frequency of spectral projection: every 3 SLSQP steps in large runs.  

2. **Hardware-aware budget**:
   - \( \alpha = 0.95 \) in `S_iter` ensures Nyquist frequency stable methods.  
   - `beta` in `obj_func`: Current 0.01 is balanced; higher values (≤0.1) penalize spectral mismatch better.  

3. **Fallback validation**:
   - Penalties via `if abs(np.sum(h_final)-n/2)>2`: Only apply if mean is off by >±2 optimization steps.  
   - `best_c5` vs `compute_c5`: Cross verifies with analytical dx.

**Budget and robustness**:

- **Time profiling**:  
  - `compute_c5` costs negligible time for n=400 (~0.02s).  
  - SLSQP calls ~1-2s per candidate at n=400.  
  - Target: Spend 3x more time at higher resolutions (n=400) than at lower ones.  

- **State saving**:
  ```python
  def save_state(candidate, score, n_pts):
      # Save best candidate to free memory if needed
      if hasattr(save_state, "last_time"):
          if (time.time() - save_state.last_time) > 60:  # Save every minute
              np.savez("optimization_checkpoint", cand=candidate, score=score, n=n_pts)
  ```

- **Special cases**:
  1. **Large deviations**: When n>2048, fall back to the parent solution (discovered to delay exponential growth incorrectly).
  2. **Hook frustration**: If multiple local minima per resolution, use spectral forcing with penalty \( ||\cdot||_2^2 \) embedded.

Before returning:

3. **Fallback**: Maintain parent solution if no candidate is accepted.  

Return structure:
