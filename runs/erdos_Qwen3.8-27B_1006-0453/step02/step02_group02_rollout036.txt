```python
def compute_grad_direct(h, w, n):
    # w has length 2n-1
    # k_m = m - (n-1) for m = 0..2n-2
    k = np.arange(2*n-1) - (n-1)  # lags from -(n-1) to n-1
    
    # Part A[j] = sum_m w[m] * (1-h[j-k[m]]) where 0 <= j-k[m] < n
    # Part B[j] = sum_m w[m] * h[j+k[m]] where 0 <= j+k[m] < n
    
    # For Part A: j-k[m] in [0, n-1] → k[m] in [j-(n-1), j]
    # For Part B: j+k[m] in [0, n-1] → k[m] in [-(n-1-j), n-1-j]
    
    # Vectorized: create index arrays
    # For each j, the valid m for Part A: 0 <= j-k[m] < n
    # k[m] = m-(n-1), so 0 <= j-(m-(n-1)) < n → j-n+1 <= m-n+1+j... 
    
    # Let me just do it with a loop over j, vectorized over m:
    grad = np.zeros(n)
    one_minus_h = 1.0 - h
    for j in range(n):
        # Part A: valid m where 0 <= j - k[m] < n
        idx_a = np.where((j - k >= 0) & (j - k < n))[0]
        if len(idx_a) > 0:
            grad[j] += np.sum(w[idx_a] * one_minus_h[j - k[idx_a]])
        
        # Part B: valid m where 0 <= j + k[m] < n
        idx_b = np.where((j + k >= 0) & (j + k < n))[0]
        if len(idx_b) > 0:
            grad[j] -= np.sum(w[idx_b] * h[j + k[idx_b]])
    
    return grad
```

This is O(n * (2n-1)) but vectorized over m for each j. For n=280, the inner operations are on arrays of size up to 559, and we loop 280 times. That's about 280 * 559 ≈ 156K operations, which should be fast in numpy.
