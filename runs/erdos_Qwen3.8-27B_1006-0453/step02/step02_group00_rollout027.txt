For the smooth problem: minimize f(h) = smooth_C5(h, T) subject to h ∈ [0,1]^n, sum(h) = n/2.

The projection onto {h ∈ [0,1]^n : sum(h) = n/2} is:
1. Project onto [0,1]^n: clip
2. Adjust sum: if sum > n/2, reduce; if sum < n/2, increase
   This is done by finding a threshold θ such that sum(clip(h - θ, 0, 1)) = n/2
   This requires a 1D bisection!

This is a proper polyhedral projection. Let me implement it:

```python
def project_polytope(h, n):
    """Project h onto {x : 0<=x_i<=1, sum(x)=n/2}"""
    target = n / 2.0
    h = h.copy()
    for _ in range(100):  # bisection on threshold
        h_clipped = np.clip(h, 0.0, 1.0)
        s = h_clipped.sum()
        if abs(s - target) < 1e-12:
            break
        # Adjust: find θ such that sum(clip(h - θ, 0, 1)) = target
        # Actually, the projection onto the intersection of [0,1]^n and hyperplane sum=n/2
        # is not simply clip + adjust. It's:
        # min ||h - x||² s.t. 0<=x_i<=1, sum(x)=n/2
        # KKT: x_i = clip(h_i - θ, 0, 1) where θ is chosen so sum(clip(h_i - θ, 0,1)) = n/2
        # Find θ by bisection
        lo, hi = -1.0, 1.0
        for _ in range(60):
            mid = (lo + hi) / 2.0
            x = np.clip(h - mid, 0.0, 1.0)
            if x.sum() > target:
                lo = mid  # need to decrease x, so increase θ
            else:
                hi = mid
        x = np.clip(h - (lo+hi)/2.0, 0.0, 1.0)
        # Fix any tiny numerical issues
        x = np.clip(x, 0.0, 1.0)
        diff = target - x.sum()
        if abs(diff) > 1e-10:
            # Distribute remaining
            free = (x > 1e-8) & (x < 1.0 - 1e-8)
            if free.sum() > 0:
                x[free] += diff / free.sum()
                x = np.clip(x, 0.0, 1.0)
        return x
    return h_clipped
```

Wait, the bisection logic: if x.sum() > target, I need to decrease x, which means increasing θ (since x = clip(h - θ, 0, 1), larger θ → smaller x). So if x.sum() > target, set lo = mid (search higher θ). If x.sum() < target, set hi = mid (search lower θ). Yes, that's correct.
