```python
    corr = np.correlate(h, 1.0 - h, mode='full')
```

Total gradient: O(n) perturbations × O(n) update = O(n^2) = 280^2 ≈ 78K ops. Very fast!

Then the soft-max gradient: O(2n) to compute weights + O(n * 2n) for the matrix-vector product = O(n^2).

So the full gradient is O(n^2) which is fine.

Let me just implement it cleanly:

```python
def soft_max_grad(h, t, M):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    cmax = np.max(corr)
    s = t * (corr - cmax)
    s -= np.max(s)  # for numerical stability
    w = np.exp(s)
    w /= np.sum(w)
    # w has length 2n-1
    # grad[j] = dx * sum_k w[k] * J[k,j] + 2*M*(sum(h)-n/2)*dx... wait, the penalty gradient
    # Actually the penalty is M*(sum(h)-n/2)^2, gradient is 2*M*(sum(h)-n/2) for each component
    
    # Compute J @ w: (J @ w)[j] = sum_k J[k,j] * w[k]
    # J[k,j] = (1-h[j-s*k])*I(0<=j-s*k<n) - h[j+s*k]*I(0<=j+s*k<n) where s*k = k-(n-1)
    
    # S1[j] = sum_k w[k] * (1-h[j-(k-n+1)]) * I(0<=j-(k-n+1)<n)
    # S2[j] = sum_k w[k] * h[j+(k-n+1)] * I(0<=j+(k-n+1)<n)
    
    Jw = np.zeros(n)
    for k in range(2*n-1):
        s = k - (n-1)
        wk = w[k]
        if wk < 1e-15:
            continue
        # (1-h[j-s]) for valid j: j-s in [0,n-1] → j in [s, s+n-1] intersected with [0,n-1]
        lo = max(0, s)
        hi = min(n-1, s+n-1)
        if lo <= hi:
            Jw[lo:hi+1] += wk * (1.0 - h[lo-s:hi-s+1])
        # -h[j+s] for valid j: j+s in [0,n-1] → j in [-s, n-1-s] intersected with [0,n-1]
        lo2 = max(0, -s)
        hi2 = min(n-1, n-1-s)
        if lo2 <= hi2:
            Jw[lo2:hi2+1] -= wk * h[lo2+s:hi2+s+1]
    
    grad = dx * Jw + 2.0 * M * (np.sum(h) - n/2.0)
    return grad
```

This loop over k (2n-1 iterations) with O(n) work each gives O(n^2) total. For n=280, that's about 157K operations per gradient. Very fast.

Now, for L-BFGS-B, I'll use:
- Objective: soft_max_obj(h, t, M)
- Gradient: soft_max_grad(h, t, M)
- Bounds: [(0,1)] * n
- No linear constraints (handled by penalty M)

The penalty M needs to be large enough to enforce sum(h) ≈ n/2. Let's use M = 1e4 or 1e5.

Actually, a better approach: after each L-BFGS-B optimization, project onto the constraint exactly. And during optimization, use a moderate M (like 100) to guide the optimizer, then project at the end.

Let me now think about the overall algorithm:

```
1. Start from initial_h_values (n=280), project to feasible
2. For several temperatures t (increasing):
   a. Run L-BFGS-B with soft_max objective
   b. Project result
   c. Track best
3. Binary push
4. Local search on binary (swap-based)
5. If time allows, go back to continuous refinement
```

For the local search, the key operation is: given binary h with sum = n/2, try swapping h[a]=1 with h[b]=0. The change in corr can be computed in O(n) time (checking all 2n-1 lags affected).

Actually, for binary h, the change in corr[k] from swapping positions a (1→0) and b (0→1) is:
Δcorr[k] = [change from a going 1→0] + [change from b going 0→1]

For position a going 1→0:
- In corr[k] = sum_i h[i]*I(i+k in range)*(1-h[i+k]): h[a] was 1, now 0
  - Contribution from a as h-term: was (1-h[a+k]), now 0. Change: -(1-h[a+k])
  - Contribution from a as (1-h) term: h[a-k] was multiplied by (1-h[a])=0, now (1-h[a])=1. Change: +h[a-k]
  
For position b going 0→1:
- h[b] was 0, now 1
  - Contribution from b as h-term: was 0, now (1-h[b+k]). Change: +(1-h[b+k])
  - Contribution from b as (1-h) term: h[b-k] was multiplied by (1-h[b])=1, now (1-h[b])=0. Change: -h[b-k]

Total: Δcorr[k] = -(1-h[a+k]) + h[a-k] + (1-h[b+k]) - h[b-k]
              = h[a-k] - h[a+k] + h[b+k] - h[b-k]

(where terms with out-of-range indices are 0)

This is O(1) per lag! So checking all 2n-1 lags is O(n) per swap.

For the local search, I want to minimize max(corr). So I need:
- Current max = C
- After swap, new corr[k] = old_corr[k] + Δcorr[k]
- New max = max_k (old_corr[k] + Δcorr[k])
- Accept if new max < C

I can speed this up by only checking lags where old_corr[k] is near the maximum (within Δmax of C) plus lags where Δcorr[k] is large.

For now, let me just check all lags (O(n) per swap, n=280, so ~560 ops per swap). With, say, 10000 swaps to try, that's 5.6M ops. Very fast.

```python
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def proj(h, n):
    h = np.clip(h, 0.0, 1.0)
    tgt = n / 2.0
    for _ in range(200):
        d = tgt - np.sum(h)
        if abs(d) < 1e-14:
            break
        if d > 0:
            m = h < 1.0
        else:
            m = h > 0.0
        cnt = np.count_nonzero(m)
        if cnt == 0:
            break
        h[m] += d / cnt
        h = np.clip(h, 0.0, 1.0)

    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    cmax = np.max(corr)

    s -= np.max(s)

def soft_max_grad(h, t, M):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    cmax = np.max(corr)
    s = t * (corr - cmax)
    s -= np.max(s)
    w = np.exp(s)
    w /= np.sum(w)
    
    Jw = np.zeros(n)
    for k in range(2 * n - 1):
        s_val = k - (n - 1)
        wk = w[k]
        if wk < 1e-15:
            continue
        # (1-h[j-s_val]) for j in [max(0,s_val), min(n-1, s_val+n-1)]
        lo = max(0, s_val)
        hi = min(n - 1, s_val + n - 1)
        if lo <= hi:
            Jw[lo:hi + 1] += wk * (1.0 - h[lo - s_val:hi - s_val + 1])
        # -h[j+s_val] for j in [max(0,-s_val), min(n-1, n-1-s_val)]
        lo2 = max(0, -s_val)
        hi2 = min(n - 1, n - 1 - s_val)
        if lo2 <= hi2:
            Jw[lo2:hi2 + 1] -= wk * h[lo2 + s_val:hi2 + s_val + 1]
    
    return dx * Jw + 2.0 * M * (np.sum(h) - n / 2.0)

def local_search_binary(h, n, max_swaps=50000, rng=None):
    dx = 2.0 / n
    h = h.copy()
    if rng is None:
        rng = np.random.RandomState(0)
    corr = np.correlate(h, 1.0 - h, mode='full').copy()
    best_c5 = float(np.max(corr) * dx)
    
    ones = np.where(h > 0.5)[0]
    zeros = np.where(h < 0.5)[0]
    
    n_stagnant = 0
    for it in range(max_swaps):
        if n_stagnant > 5000:
            break
        # Try a random swap
        a = ones[rng.randint(len(ones))]
        b = zeros[rng.randint(len(zeros))]
        if a == b:
            continue
        
        # Compute delta for all lags
        # delta[k] = h[a-(k-(n-1))] - h[a+(k-(n-1))] + h[b+(k-(n-1))] - h[b-(k-(n-1))]
        # Simplified: for shift s = k-(n-1), delta = h[a-s]-h[a+s]+h[b+s]-h[b-s]
        
        # Vectorized computation
        shifts = np.arange(-(n-1), n)  # 2n-1 values
        # For a: h[a-s] valid when 0<=a-s<n, h[a+s] valid when 0<=a+s<n
        idx_a_s = a - shifts  # a[s] - s
        idx_a_p = a + shifts
        idx_b_p = b + shifts
        idx_b_s = b - shifts
        
        da_s = np.where((idx_a_s >= 0) & (idx_a_s < n), h[idx_a_s], 0.0)
        da_p = np.where((idx_a_p >= 0) & (idx_a_p < n), h[idx_a_p], 0.0)
        db_p = np.where((idx_b_p >= 0) & (idx_b_p < n), h[idx_b_p], 0.0)
        db_s = np.where((idx_b_s >= 0) & (idx_b_s < n), h[idx_b_s], 0.0)
        
        delta = da_s - da_p + db_p - db_s
        new_corr = corr + delta
        new_max = float(np.max(new_corr))
        
        if new_max < best_c5 - 1e-12:
            corr = new_corr
            best_c5 = new_max
            h[a] = 0.0
            h[b] = 1.0
            # Update ones and zeros
            ones = np.where(h > 0.5)[0]
            zeros = np.where(h < 0.5)[0]
            n_stagnant = 0
        else:
            n_stagnant += 1
    
    return h, best_c5
```

Actually, here's another idea: **mirror descent / projected subgradient**. Since the objective is f(h) = max_k corr[k] * dx, and for binary h each corr[k] is linear in h, I can use a subgradient method:
- Pick the k* that achieves the maximum
- Subgradient of corr[k*] with respect to h is just the Jacobian row J[k*,:]
- Update: h_new = h - step * J[k*,:]
- Project h_new onto {h ∈ [0,1]^n : sum(h) = n/2}

This is O(n^2) per iteration (for the correlation + projection) and is very simple. The convergence might be slow, but it's guaranteed to find a local minimum.

Actually, the projection onto {h ∈ [0,1]^n : sum(h) = n/2} is the "isotonic regression" type problem, solvable in O(n log n) by sorting.

Let me implement this as an alternative/complement to L-BFGS-B:

```python
def project_polytope(h, n):
    """Project h onto {x in [0,1]^n : sum(x) = n/2} using water-filling"""
    h = h.copy()
    tgt = n / 2.0
    # Bisection on the Lagrange multiplier
    lo, hi = -1.0, 1.0
    for _ in range(100):
        mid = (lo + hi) / 2
        x = np.clip(h - mid, 0.0, 1.0)
        s = np.sum(x)
        if s > tgt:
            lo = mid
        else:
            hi = mid
    x = np.clip(h - (lo + hi) / 2, 0.0, 1.0)
    # Fix up any small errors
    d = tgt - np.sum(x)
    if abs(d) > 1e-12:
        if d > 0:
            m = (x < 1.0) & (x > 0.0)
            if np.any(m):
                x[m] += d / np.count_nonzero(m)
                x = np.clip(x, 0.0, 1.0)
        else:
            m = (x > 0.0) & (x < 1.0)
            if np.any(m):
                x[m] += d / np.count_nonzero(m)
                x = np.clip(x, 0.0, 1.0)
    return x
```

```python

from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def proj(h, n):
    h = np.clip(h, 0.0, 1.0)
    tgt = n / 2.0
    for _ in range(500):
        d = tgt - np.sum(h)
        if abs(d) < 1e-14:
            break
        if d > 0:
            m = h < 1.0
        else:
            m = h > 0.0
        cnt = np.count_nonzero(m)
        if cnt == 0:
            break
        h[m] += d / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

def sm_val(h, t, M):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    cmax = np.max(corr)
    s = t * (corr - cmax)
    s -= s.max()
    return (cmax + np.log(np.sum(np.exp(s))) / t) * dx + M * (np.sum(h) - n / 2.0) ** 2

def sm_grad(h, t, M):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    cmax = np.max(corr)
    s = t * (corr - cmax)
    s -= s.max()
    w = np.exp(s)
    w /= w.sum()
    Jw = np.zeros(n)
    for k in range(2 * n - 1):
        sv = k - (n - 1)
        wk = w[k]
        if wk < 1e-15:
            continue
        lo = max(0, sv)
        hi = min(n - 1, sv + n - 1)
        if lo <= hi:
            Jw[lo:hi+1] += wk * (1.0 - h[lo-sv:hi-sv+1])
        lo2 = max(0, -sv)
        hi2 = min(n - 1, n - 1 - sv)
        if lo2 <= hi2:
            Jw[lo2:hi2+1] -= wk * h[lo2+sv:hi2+sv+1]
    return dx * Jw + 2.0 * M * (np.sum(h) - n / 2.0)

def local_search(h, n, max_passes=5, rng=None):
    dx = 2.0 / n
    h = h.copy()
    if rng is None:
        rng = np.random.RandomState(0)
    corr = np.correlate(h, 1.0 - h, mode='full').astype(float).copy()
    best = float(np.max(corr))
    shifts = np.arange(-(n - 1), n)
    
    for _ in range(max_passes):
        improved = False
        ones = np.where(h > 0.5)[0].tolist()
        zeros = np.where(h < 0.5)[0].tolist()
        # Shuffle for variety
        rng.shuffle(ones)
        rng.shuffle(zeros)
        for a in ones:
            for b in zeros:
                idx_as = a - shifts
                idx_ap = a + shifts
                idx_bp = b + shifts
                idx_bs = b - shifts
                da_s = np.where((idx_as >= 0) & (idx_as < n), h[idx_as], 0.0)
                da_p = np.where((idx_ap >= 0) & (idx_ap < n), h[idx_ap], 0.0)
                db_p = np.where((idx_bp >= 0) & (idx_bp < n), h[idx_bp], 0.0)
                db_s = np.where((idx_bs >= 0) & (idx_bs < n), h[idx_bs], 0.0)
                delta = da_s - da_p + db_p - db_s
                nm = np.max(corr + delta)
                if nm < best - 1e-12:
                    corr += delta
                    best = nm
                    h[a] = 0.0
                    h[b] = 1.0
                    improved = True
        if not improved:
            break
    return h, best * dx
```

```python
def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    rng = np.random.RandomState(seed)
    
    n = 280
    # Initialize
    try:
        h = proj(np.array(initial_h_values, dtype=float).copy(), n)
    except Exception:
        h = proj(np.full(n, 0.5) + rng.randn(n) * 0.05, n)
    
    best_h = h.copy()
    best_c5 = compute_c5(h)
    
    bnds = [(0.0, 1.0)] * n
    
    def tleft():
        return budget_s - (time.time() - t0)
    
    # Phase 1: L-BFGS-B continuous optimization at n=280
    for t_val in [50, 150, 400, 1000, 3000, 10000]:
        if tleft() < 30:
            break
        M = 100.0
        r = minimize(sm_val, h, jac=sm_grad, args=(t_val, M),
                    method='L-BFGS-B', bounds=bnds,
                    options={'maxiter': 300, 'ftol': 1e-14, 'gtol': 1e-10})
        h = proj(np.clip(r.x, 0, 1), n)
        c5 = compute_c5(h)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h.copy()
    
    # Phase 2: Binary push + local search
    h_bin = (h > 0.5).astype(float)
    h_bin = proj(h_bin, n)
    h_bin, c5_bin = local_search(h_bin, n, max_passes=10, rng=rng)
    if c5_bin < best_c5:
        best_c5 = c5_bin
        best_h = h_bin.copy()
    
    # Phase 3: More L-BFGS-B from different starts
    if tleft() > 60:
        # Try from binary
        h2 = h_bin.copy()
        for t_val in [200, 500, 1500]:
```

**Key insight**: For binary h, corr[k] = sum_i h[i] * (1-h[i+k]) (with appropriate bounds). When I swap positions a (1→0) and b (0→1), the change in corr[k] for all k can be precomputed as a function of a and b.

The change formula: Δcorr for shift s (where s = k - (n-1)) is:
Δ(s) = h[a-s] - h[a+s] + h[b+s] - h[b-s]

This is O(1) per s, so O(n) for all s. But can I precompute something?

For a fixed a: h[a-s] - h[a+s] as a function of s is just two "reflected" copies of h. I can precompute this for all a in O(n^2) total.

Similarly for b. Then Δ(a,b,s) = f_a(s) + g_b(s) where f_a(s) = h[a-s]-h[a+s] and g_b(s) = h[b+s]-h[b-s].

So I can precompute F[a,s] and G[b,s] for all a,b in O(n^2) time and O(n^2) space.

Then for each pair (a,b), the new corr is corr + F[a,:] + G[b,:], and I need max(corr + F[a,:] + G[b,:]).

This is still O(n) per pair. But the numpy overhead might be less since I'm just doing array additions.

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def proj(h, n):
    h = np.clip(h, 0.0, 1.0)
    tgt = n / 2.0
    for _ in range(500):
        d = tgt - np.sum(h)
        if abs(d) < 1e-14:
            break
        if d > 0:
            m = h < 1.0
        else:
            m = h > 0.0
        cnt = np.count_nonzero(m)
        if cnt == 0:
            break
        h[m] += d / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

def sm_val(h, t, M):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    cmax = np.max(corr)
    s = t * (corr - cmax)
    s -= s.max()
    return (cmax + np.log(np.sum(np.exp(s))) / t) * dx + M * (np.sum(h) - n / 2.0) ** 2

def sm_grad(h, t, M):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    cmax = np.max(corr)
    s = t * (corr - cmax)
    s -= s.max()
    w = np.exp(s)
    w /= w.sum()
    Jw = np.zeros(n)
    for k in range(2 * n - 1):
        sv = k - (n - 1)
        wk = w[k]
        if wk < 1e-15:
            continue
        lo = max(0, sv)
        hi = min(n - 1, sv + n - 1)
        if lo <= hi:
            Jw[lo:hi + 1] += wk * (1.0 - h[lo - sv:hi - sv + 1])
        lo2 = max(0, -sv)
        hi2 = min(n - 1, n - 1 - sv)
        if lo2 <= hi2:
            Jw[lo2:hi2 + 1] -= wk * h[lo2 + sv:hi2 + sv + 1]
    return dx * Jw + 2.0 * M * (np.sum(h) - n / 2.0)

    dx = 2.0 / n
    h = h.copy()
    if rng is None:
        rng = np.random.RandomState(0)
    corr = np.correlate(h, 1.0 - h, mode='full').astype(float).copy()
    best = float(np.max(corr))
    shifts = np.arange(-(n - 1), n)
    for _ in range(max_passes):
        improved = False
        ones = np.where(h > 0.5)[0].tolist()
        zeros = np.where(h < 0.5)[0].tolist()
        rng.shuffle(ones)
        rng.shuffle(zeros)
        for a in ones:
            for b in zeros:
                idx_as = a - shifts
                idx_ap = a + shifts
                idx_bp = b + shifts
                idx_bs = b - shifts
                da_s = np.zeros(2 * n - 1)
                da_p = np.zeros(2 * n - 1)
                db_p = np.zeros(2 * n - 1)
                db_s = np.zeros(2 * n - 1)
                m1 = (idx_as >= 0) & (idx_as < n)
                m2 = (idx_ap >= 0) & (idx_ap < n)
                m3 = (idx_bp >= 0) & (idx_bp < n)
                m4 = (idx_bs >= 0) & (idx_bs < n)
                da_s[m1] = h[idx_as[m1]]
                da_p[m2] = h[idx_ap[m2]]
                db_p[m3] = h[idx_bp[m3]]
                db_s[m4] = h[idx_bs[m4]]
                nm = np.max(corr + da_s - da_p + db_p - db_s)

                    h[b] = 1.0
                    corr += da_s - da_p + db_p - db_s

        if not improved:
