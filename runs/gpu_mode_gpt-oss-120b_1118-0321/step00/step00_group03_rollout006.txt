custom_kernel: Triton‑accelerated forward of the TriMul (outgoing) block.

Algorithm
---------
1. Layer‑norm the input tensor (shape [B,N,N,D]).
2. Linear projections → left / right, plus three sigmoid gates.
3. Apply the pairwise mask (if any) and the gates.
4. Compute the core tensor contraction:
       out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]
   This is a batched mat‑mul L @ Rᵀ for every hidden channel h.
   It is implemented in Triton as a tiled GEMM where each kernel program
   processes a (BLOCK_M × BLOCK_N) tile for a specific (batch, hidden) pair.
5. Apply a second LayerNorm, the output‑gate, and the final linear projection
   back to the original dimension.

Only the cubic reduction (step 4) runs on Triton; all other ops use
ordinary PyTorch primitives.
"""

import torch.nn.functional as F
import triton
import triton.language as tl

    # unpack inputs
    # ------------------------------------------------------------------ #

        stride_o_j,
        stride_o_h,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # ------------------------------------------------------------------ #
    # 5. Post‑processing (norm, output gate, final linear)
    # ------------------------------------------------------------------ #
    out = F.layer_norm(
        out,
        (hidden_dim,),
        weight=to_out_norm_weight,
        bias=to_out_norm_bias,
        eps=1e-5,
    )
    out = out * out_gate
    out = F.linear(out, to_out_weight)  # back to [B,N,N,dim]

    return out
```
