 Steps:
 1. Apply LayerNorm to the input tensor (host code, but we'll convert to float16 for device code).
 2. Project the LayerNormed tensor using two linear projections (left_proj and right_proj) to a hidden dimension (host code, to float16).
 3. Compute the gates (left_gate, right_gate, out_gate) by applying linear layers and then sigmoid (host code, still float16).
 4. Apply the mask (if present) to the left and right projections: element-wise multiplication with the mask and the gates (host code for the mask case, but we can try to fuse some operations in Triton).
 5.
