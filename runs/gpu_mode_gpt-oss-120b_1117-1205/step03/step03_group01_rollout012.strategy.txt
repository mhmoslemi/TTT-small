**1. Approach and rationale**  
The "outgoing" TriMul operator from AlphaFold3 requires tracking input vectors and their projected interactions to update output vectors. For input tensor shape `[B, N, N, C]`, we compute interactions between vectors at positions `(B, i, k)` and `(B, j, k)` for all `k`, then update original vectors only via outgoing links.  

Key points:  
- Avoid redesigning mathematical operations based on memory layout; structure the code around tensor dimensions  
- Compute and cache masking results as float buffers to enable safe contiguous tensor creation during kernel data movement  
- Use small static block sizes for all dimensions except the sequence dimension `N` (ideally 16, though 32 or 64 might be tested on real hardware)  
- Launch kernel only once per input/output dimension combination `[B, N, N, C]`
