```python
import torch
from torch import nn, einsum
import math

# Reference code in PyTorch
class TriMul(nn.Module):
    def __init__(
        self,
        dim: int,
        hidden_dim: int,
    ):
        super().__init__()

        self.norm = nn.LayerNorm(dim)

        self.left_proj = nn.Linear(dim, hidden_dim, bias=False)
        self.right_proj = nn.Linear(dim, hidden_dim, bias=False)

        self.left_gate = nn.Linear(dim, hidden_dim, bias=False)
        self.right_gate = nn.Linear(dim, hidden_dim, bias=False)
        self.out_gate = nn.Linear(dim, hidden_dim, bias=False)

        self.to_out_norm = nn.LayerNorm(hidden_dim)
        self.to_out = nn.Linear(hidden_dim, dim, bias=False)

    def forward(self, x: torch.Tensor, mask: torch.Tensor) -> torch.Tensor:
        """
        x: [bs, seq_len, seq_len, dim]
        mask: [bs, seq_len, seq_len]

        Returns:
            output: [bs, seq_len, seq_len, dim]
        """
        batch_size, seq_len, _, dim = x.shape

        x = self.norm(x)

        left = self.left_proj(x)
        right = self.right_proj(x)

        mask = mask.unsqueeze(-1)
        left = left * mask
        right = right * mask

        left_gate = self.left_gate(x).sigmoid()
        right_gate = self.right_gate(x).sigmoid()
        out_gate = self.out_gate(x).sigmoid()

        left = left * left_gate
        right = right * right_gate

        out = einsum('... i k d, ... j k d -> ... i j d', left, right)
        # This einsum is the same as the following:
        # out = torch.zeros(batch_size, seq_len, seq_len, dim, device=x.device)
        
        # # Compute using nested loops
        # for b in range(batch_size):
        #     for i in range(seq_len):
        #         for j in range(seq_len):
        #             # Compute each output element
        #             for k in range(seq_len):
        #                 out[b, i, j] += left[b, i, k, :] * right[b, j, k, :]

        out = self.to_out_norm(out)
        out = out * out_gate
        return self.to_out(out)
```

## Triton launch convention

Every failure mode below has appeared in this search. Read this before writing.

A `@triton.jit` function is NOT a Python function. It is launched with a grid
subscript, and its `tl.constexpr` parameters exist only inside it:

```python
@triton.jit
def my_kernel(x_ptr, y_ptr, n, BLOCK: tl.constexpr):
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    m = offs < n
    tl.store(y_ptr + offs, tl.load(x_ptr + offs, mask=m, other=0.0), mask=m)

def custom_kernel(data):
    ...
    BLOCK = 128                                   # a host variable YOU define
    grid = (triton.cdiv(n, BLOCK),)               # host-side, use triton.cdiv
    my_kernel[grid](x, y, n, BLOCK=BLOCK)         # note the [grid] subscript
```

- `my_kernel(...)` without `[grid]` raises "Cannot call @triton.jit'd outside
  the scope of a kernel".
- `BLOCK`, `BLOCK_M`, `BLOCK_N` are not defined on the host unless you define
  them there. Referencing one you only declared as a `tl.constexpr` parameter
  raises NameError.
- `tl.cdiv` is device-side. On the host use `triton.cdiv`.
- Define the kernel at module top level, never nested inside `custom_kernel`.

You do not have to move everything into Triton. A correct submission that keeps
most of the computation in PyTorch and moves one hot region into a kernel scores;

```python
TriMul (outgoing) forward pass with a Triton‑accelerated elementwise
mask‑and‑gate fusion.  All heavy linear / projection / layer‑norm work is
performed in PyTorch (FP16 where possible).  The only Triton kernel fuses
the three elementwise multiplications

    out = tensor * gate * mask

for the left and right branches, avoiding separate Python launches.
The cubic contraction

    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]

is then computed as a batched matrix‑multiply (torch.bmm) which uses
cuBLAS and is far faster than a naïve Triton implementation.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


@triton.jit
def mul_gate_mask_kernel(
    out_ptr,                # pointer to output (flattened)
    a_ptr,                  # pointer to tensor (flattened)
    gate_ptr,               # pointer to gate (flattened)
    mask_ptr,               # pointer to mask (flattened, broadcast over H)
    total,                  # total number of elements
    BLOCK_SIZE: tl.constexpr,
    H: tl.constexpr,        # hidden dimension (size of the innermost axis)
):
    pid = tl.program_id(0)
    offs = pid * BLOCK_SIZE + tl.arange(0, BLOCK_SIZE)
    mask = offs < total

    a = tl.load(a_ptr + offs, mask=mask)
    g = tl.load(gate_ptr + offs, mask=mask)

    # broadcast mask over the hidden dimension
    mask_idx = offs // H
    m = tl.load(mask_ptr + mask_idx, mask=mask)

    tl.store(out_ptr + offs, a * g * m, mask=mask)

    # --------------------------------------------------------------------

    right_gate = torch.sigmoid(F.linear(x_fp16, right_gate_w)) # [B,N,N,hidden_dim]
    out_gate = torch.sigmoid(F.linear(x_fp16, out_gate_w))    # [B,N,N,hidden_dim]

    # Prepare mask: if None or nomask, use a tensor of ones
    if mask_tensor is None:

    else:

    # Flatten tensors for the kernel
    left_flat = left.contiguous().view(-1)
    left_gate_flat = left_gate.contiguous().view(-1)
    right_flat = right.contiguous().view(-1)
    right_gate_flat = right_gate.contiguous().view(-1)

    right_mat = right_perm.view(LH, N, N)  # (B*H, N, N)

    out_norm = out_norm * out_gate.to(torch.float32)

    output = F.linear(out_norm, to_out_w)  # [B, N, N, dim], float32
```

# Approach and Rationale

The TriMul operator from AlphaFold3 performs a computationally expensive cubic contraction (N^3) over the sequence dimensions for each feature channel. Unlike standard linear and matrix operations, this contraction requires dot product calculations between elements at different sequence positions. Directly implementing this contraction requires:

1. Careful tiling strategies to minimize register spills and optimize reuse patterns
2. Handling the transform from (B, N, N, dim) to (B, N, N, hidden_dim)
3. Performing element-wise gating and masking operations
4. Exploiting optimal arithmetic intensity throughout the computation

The key challenge is to design a single efficient Triton kernel that handles:
- The initial linear projection and normalization
- The three gating operations (left_gate, right_gate, out_gate)
- The three-way cubic contraction of dimensions [B, N, N] × [B, N, N] 
- The final projection and normalization

The solution can be achieved by restructuring the computation as matrix operations and combining all five steps into a single unified kernel launch. This approach leverages:
- Shared memory extent optimizations
- Natural alignment for memory access patterns
- Intrinsic support for masking operations
- Compiler optimizations for fused operations

# Mathematical Specification

Let:
- `x`: Input tensor of shape `B,N,N,dim`
- `weights`: Dictionary containing weights for all linear transformations
- `mask`: Optional mask tensor of shape `B,N,N`

The forward pass involves:

1. Initial normalization:
   `x_norm = F.layer_norm(x, (dim,), weight=norm_w, bias=norm_b)`

2. Three linear transformations in sequence:
   - `left_proj`: dim → hidden_dim
   - `right_proj`: dim → hidden_dim
   - `gate_proj`: dim → hidden_dim

3. The cubic contraction operation:
   `out[b,i,j,d] = sum_{k} left_proj[b,i,k,d] * right_proj[b,j,k,d]`

But note the full process includes:
   - Element-wise application of mask
   - Gating on the projections and initial tensor
   - Intermediate layernorm (optional)
   - Final projection/out/gating

```python
def optional_layernorm(input: torch.Tensor,
                      ln_weight: torch.Tensor,
                      ln_bias: torch.Tensor,
                      epsilon: float=1e-5) -> torch.Tensor:
    # Skip normalization if both ln-weight and ln-bias are None
    if ln_weight is None:
        return input
    
    # Compute mean and variance - done offload because it uses separate ops
    mean = input.mean(dim=-1, keepdim=True)
    var = input.var(dim=-1, keepdim=True, unbiased=False)
    inv_stddev = torch.rsqrt(var + epsilon)
    scale = ln_weight * inv_stddev
    shift = ln_bias - mean * inv_stddev
    return input * scale + shift
```
