**Approach and rationale**

The outgoing TriMul operator is defined by the computation:
flatten_output[batch_index, sequence_index1, sequence_index2, hidden_index] = \sum_{k} \text{left}[batch_index, sequence_index1, k, hidden_index] \times \text{right}[batch_index, sequence_index2, k, hidden_index]

This requires an element-wise multiplication over the sequence dimension (N) for each of the B batches and hidden_dim hidden dimensions, and then summing over k (N terms). However, this is expensive and scales as O(N^3) due to the triple nested loops.

Instead, we view this as a batched matrix multiplication of two matrices formed by selecting a fixed hidden dimension and a fixed batch, but then transposing one. Specifically, for each fixed (b, d) (batch and hidden dimension), we have two matrices of shape (N, hidden_dim):
A = left[b][:, :, d]   (N x hidden_dim)
B = right[b][:, :, d]   (N x hidden_dim, but then we need B^T for multiplication)

Then, the output for (b, d) is the matrix product (N x N) which is the result of A @ B^T. This product is then stored at the corresponding (b, i, j, d) position.

This insight allows us to use the standard triton gemm kernel by reorganizing the dimensions. We note that the operation is separable by (batch, hidden_dim), so we can launch a kernel once for each unique combination of batch and hidden dimension. This reduces the exploitation effort by decoupling the outer dimension from the inner matrix multiplication, but the total work is still bandwidth-bound or latency-bound.

We will implement a persistent kernel that can handle the inner (N x hidden_dim) matrix multiplication with transposition. The key advantage is that the gemm kernel is natively supported and optimized.

**Mathematical specification**

Let the input tensor have shape $(B, N, N, \text{dim})$.

Steps:
1. Apply LayerNorm to the input tensor along its channel dimension.
   shape: $(B, N, N, \text{dim})$ -> same
   equation: output = LayerNorm_{\text{dim}}(normalized_input)

2. Project the tensor via left_proj and right_proj, and convert to fp16.
   left_proj(x) = x @ left_proj_weight   (dim -> hidden_dim)
   right_proj(x) = x @ right_proj_weight   (dim -> hidden_dim)

   For the second part (gating), similarly we project along the dim dimension to hidden_dim:
   left_gate = x @ left_gate_weight
   right_gate = x @ right_gate_weight
   out_gate = x @ out_gate_weight

3. Apply optional mask (broadcasted across hidden_dim dimension).

4. Compute the element-wise multiplication for gating.

5. For the core operation, we wish to compute:
   out_{b,i,j,d} = \sum_{k} \left( \text{left}[b,i,k,d] \times \text{right}[b,j,k,d] \right)

   Alternatively, form two matrices for each (b, d):
   A_{b,d} = \left( \text{left}[b, :, :, d] \right)_{i,k} \in \mathbb{R}^{N \times \text{hidden_dim}}
   B_{b,d} = \left( \text{right}[b, :, :, d] \right)_{j,k} \in \bb码N \times \text{hidden_dim}}}

   Then, out_{b,i,j,d} = (A_{b,d}^{i} \cdot B_{b,d}^{j}) = \text{ the dot product of row i of } A_{b,d} \text{ and column } j \text{ of } B_{b,d} (which is the transpose of } B_{b,d}^{j} \text{ )}

   In matrix terms: out_{b, :, :, d} = A_{b,d} @ B_{b,d}^T  [where the multiplication is matrix multiplication]

   The result for each (b, d) is an $(N \times N)$ matrix.

6. Combine the outputs for all (b, d) appropriately.
