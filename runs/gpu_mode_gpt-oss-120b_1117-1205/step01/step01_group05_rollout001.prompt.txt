```python
import torch
from torch import nn, einsum
import math

# Reference code in PyTorch
class TriMul(nn.Module):
    def __init__(
        self,
        dim: int,
        hidden_dim: int,
    ):
        super().__init__()

        self.norm = nn.LayerNorm(dim)

        self.left_proj = nn.Linear(dim, hidden_dim, bias=False)
        self.right_proj = nn.Linear(dim, hidden_dim, bias=False)

        self.left_gate = nn.Linear(dim, hidden_dim, bias=False)
        self.right_gate = nn.Linear(dim, hidden_dim, bias=False)
        self.out_gate = nn.Linear(dim, hidden_dim, bias=False)

        self.to_out_norm = nn.LayerNorm(hidden_dim)
        self.to_out = nn.Linear(hidden_dim, dim, bias=False)

    def forward(self, x: torch.Tensor, mask: torch.Tensor) -> torch.Tensor:
        """
        x: [bs, seq_len, seq_len, dim]
        mask: [bs, seq_len, seq_len]

        Returns:
            output: [bs, seq_len, seq_len, dim]
        """
        batch_size, seq_len, _, dim = x.shape

        x = self.norm(x)

        left = self.left_proj(x)
        right = self.right_proj(x)

        mask = mask.unsqueeze(-1)
        left = left * mask
        right = right * mask

        left_gate = self.left_gate(x).sigmoid()
        right_gate = self.right_gate(x).sigmoid()
        out_gate = self.out_gate(x).sigmoid()

        left = left * left_gate
        right = right * right_gate

        out = einsum('... i k d, ... j k d -> ... i j d', left, right)
        # This einsum is the same as the following:
        # out = torch.zeros(batch_size, seq_len, seq_len, dim, device=x.device)
        
        # # Compute using nested loops
        # for b in range(batch_size):
        #     for i in range(seq_len):
        #         for j in range(seq_len):
        #             # Compute each output element
        #             for k in range(seq_len):
        #                 out[b, i, j] += left[b, i, k, :] * right[b, j, k, :]

        out = self.to_out_norm(out)
        out = out * out_gate
        return self.to_out(out)
```

## Triton launch convention

Every failure mode below has appeared in this search. Read this before writing.

A `@triton.jit` function is NOT a Python function. It is launched with a grid
subscript, and its `tl.constexpr` parameters exist only inside it:

```python
@triton.jit
def my_kernel(x_ptr, y_ptr, n, BLOCK: tl.constexpr):
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    m = offs < n
    tl.store(y_ptr + offs, tl.load(x_ptr + offs, mask=m, other=0.0), mask=m)

def custom_kernel(data):
    ...
    BLOCK = 128                                   # a host variable YOU define
    grid = (triton.cdiv(n, BLOCK),)               # host-side, use triton.cdiv
    my_kernel[grid](x, y, n, BLOCK=BLOCK)         # note the [grid] subscript
```

- `my_kernel(...)` without `[grid]` raises "Cannot call @triton.jit'd outside
  the scope of a kernel".
- `BLOCK`, `BLOCK_M`, `BLOCK_N` are not defined on the host unless you define
  them there. Referencing one you only declared as a `tl.constexpr` parameter
  raises NameError.
- `tl.cdiv` is device-side. On the host use `triton.cdiv`.
- Define the kernel at module top level, never nested inside `custom_kernel`.

You do not have to move everything into Triton. A correct submission that keeps

```python
"""
TriMul forward (outgoing) kernel implementation.

The heavy part of the computation is the tensor contraction:
    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
which is equivalent to a batched matrix multiplication:
    out = (left reshaped) @ (right reshaped).T

We implement this contraction with a custom Triton kernel that performs
a batched GEMM over (batch*hidden_dim) independent matrices of size
(N, N). All other linear operations and layer‑norms are done in PyTorch.
The final result is returned as float32.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


@triton.jit
def _batched_matmul_kernel(
    A_ptr, B_ptr, C_ptr,
    stride_az, stride_am, stride_ak,
    stride_bz, stride_bk, stride_bn,
    stride_cz, stride_cm, stride_cn,
    M, N, K,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr,
):
    """Batched GEMM: C = A @ B, where
    A: (batch, M, K), B: (batch, K, N), C: (batch, M, N)
    All tensors are stored in row‑major layout.
    """
    batch_id = tl.program_id(0)
    pid_m = tl.program_id(1)   # block row
    pid_n = tl.program_id(2)   # block col

    # tile offsets
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # pointer to output tile
    c_ptrs = (
        C_ptr
        + batch_id * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn
    )
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # loop over K dimension
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # A tile (M x K)
        a_ptrs = (
            A_ptr
            + batch_id * stride_az
            + offs_m[:, None] * stride_am
            + offs_k[None, :] * stride_ak
        )
        a = tl.load(
            a_ptrs,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
        ).to(tl.float32)

        # B tile (K x N)
        b_ptrs = (
            B_ptr
            + batch_id * stride_bz
            + offs_k[:, None] * stride_bk
            + offs_n[None, :] * stride_bn
        )
        b = tl.load(
            b_ptrs,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0,
        ).to(tl.float32)

        acc += tl.dot(a, b)

    # store result as fp16 (matches the dtype of C)
    c = acc.to(tl.float16)
    tl.store(c_ptrs, c, mask=mask_m[:, None] & mask_n[None, :])


def custom_kernel(data):
    """
    Args:
        data: Tuple (input, mask, weights, config)
            input  : torch.Tensor of shape [B, N, N, dim] (float32)
            mask   : torch.Tensor of shape [B, N, N]   (float32 or bool)
            weights: dict of torch.Tensors for all linear / norm parameters
            config : dict with keys "dim" and "hidden_dim"
    Returns:
        torch.Tensor of shape [B, N, N, dim] (float32)
    """
    # Unpack
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    eps = 1e-5

    # ------------------------------------------------------------------
    # LayerNorm on the input (over last dimension)
    # ------------------------------------------------------------------
    gamma = weights["norm.weight"].to(torch.float32)
    beta = weights["norm.bias"].to(torch.float32)

    x = input_tensor.to(torch.float32)
    mean = x.mean(dim=-1, keepdim=True)
    var = x.var(dim=-1, unbiased=False, keepdim=True)
    x_norm = (x - mean) / torch.sqrt(var + eps)
    x_norm = x_norm * gamma + beta          # shape [B, N, N, dim]

    # ------------------------------------------------------------------
    # Projections and gates (computed in fp16 for speed)
    # ------------------------------------------------------------------
    x_h = x_norm.to(torch.float16)

    # Linear weights (fp16)
    w_left = weights["left_proj.weight"].to(torch.float16)      # (hidden_dim, dim)
    w_right = weights["right_proj.weight"].to(torch.float16)

    w_left_gate = weights["left_gate.weight"].to(torch.float16)
    w_right_gate = weights["right_gate.weight"].to(torch.float16)
    w_out_gate = weights["out_gate.weight"].to(torch.float16)

    # Project
    left = F.linear(x_h, w_left)          # [B, N, N, hidden_dim]
    right = F.linear(x_h, w_right)

    # Apply mask (if any)
    if mask is not None:
        mask_exp = mask.unsqueeze(-1).to(x_h.dtype)   # [B, N, N, 1]
        left = left * mask_exp
        right = right * mask_exp

    # Gates
    left_gate = F.linear(x_h, w_left_gate).sigmoid()
    right_gate = F.linear(x_h, w_right_gate).sigmoid()
    out_gate = F.linear(x_h, w_out_gate).sigmoid()

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # Triton batched matmul: out = left @ right^T (over k dimension)
    # ------------------------------------------------------------------
    B, N, _, H = left.shape  # H == hidden_dim

    # reshape to (B*H, N, N) and transpose right for the k dimension
    left_mat = left.permute(0, 3, 1, 2).contiguous().view(B * H, N, N)       # (batch, M, K)
    right_mat = right.permute(0, 3, 1, 2).contiguous()                      # (B, H, N, N)
    right_mat = right_mat.permute(0, 1, 3, 2).contiguous().view(B * H, N, N)  # (batch, K, N)

    out_mat = torch.empty((B * H, N, N), dtype=torch.float16, device=device)

    # Strides
    stride_az, stride_am, stride_ak = left_mat.stride()
    stride_bz, stride_bk, stride_bn = right_mat.stride()
    stride_cz, stride_cm, stride_cn = out_mat.stride()

    # Tiling parameters – chosen to fit typical B200 SM capacity
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 64

    grid = (
        B * H,
        triton.cdiv(N, BLOCK_M),
        triton.cdiv(N, BLOCK_N),
    )
    _batched_matmul_kernel[grid](
        left_mat,
        right_mat,
        out_mat,
        stride_az,
        stride_am,
        stride_ak,
        stride_bz,
        stride_bk,
        stride_bn,
        stride_cz,
        stride_cm,
        stride_cn,
        N,
        N,
        N,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,
    )

    # reshape back to [B, N, N, hidden_dim]
    out = out_mat.view(B, H, N, N).permute(0, 2, 3, 1).contiguous()  # fp16
    out_f32 = out.to(torch.float32)

    # ------------------------------------------------------------------
    # Output LayerNorm (over hidden_dim)
    # ------------------------------------------------------------------
    gamma_out = weights["to_out_norm.weight"].to(torch.float32)
    beta_out = weights["to_out_norm.bias"].to(torch.float32)

    mean_o = out_f32.mean(dim=-1, keepdim=True)
    var_o = out_f32.var(dim=-1, unbiased=False, keepdim=True)
    out_norm = (out_f32 - mean_o) / torch.sqrt(var_o + eps)
    out_norm = out_norm * gamma_out + beta_out

    # Apply out gate
    out_norm = out_norm * out_gate.to(torch.float32)

    # ------------------------------------------------------------------
    # Final linear projection back to input dim
    # ------------------------------------------------------------------
    w_to_out = weights["to_out.weight"].to(torch.float32)
    output = F.linear(out_norm, w_to_out)   # shape [B, N, N, dim], float32

    return output
```

## Strategy from the reasoning-model planning stage

<strategy>
1. **Approach and Rationale**:
   - The TriMul operator requires computing pairwise interactions over a large sequence dimension (N) using a small hidden dimension (hidden_dim). 
   - The key challenge is its O(N² * hidden_dim * B) complexity (up to 266 million operations for B=2, N=1024, hidden_dim=128), which must be optimized for the B200 accelerator.
   - We will implement a multi-kernel strategy:
     - Offload LayerNorm, projection, gating, and any applicable mask operations to PyTorch.
     - Use a dedicated Triton kernel for the most computationally intensive part: the tensor contraction `out[b,i,j,d] = sum_{k} left[b,i,k,d] * right[b,j,k,d]`.
     - This contraction is transformed into a batched matrix multiplication between matrices of shape `[N, hidden_dim]` and `[hidden_dim, N]` for each `(b,d)` pair.
   - The thrillerationale centers on leveraging spawn-pending calls and keeping most calculations on the CPU for memory management.

2. **Mathematical Specification**:
   - **Operations**:
     - LayerNorm on input: Normalizes `[B, N, N, C]` over the feature dimension C.
     - Linear projections: Maps to hidden_dim via `[B, N, N] * [C -> hidden_dim]`.
     - Element-wise multiplications: left/right gates applied as sigmoid activations.
     - Mask multiplication: Applies `[B, N, N]` mask if provided.
     - Contraction: `out[b,i,j,d] = sum_{k} left[b,i,k,d] * right[b,j,k,d]`.
     - Final LayerNorm and projection: Converts back to output dimension C.
   - **Variables**:
     - `batch_size`: Input B dimension.
     - `seqlen`: Input N dimension.
     - `dim`, `hidden_dim`: Feature dimensions.
     - `x_norm`, `left`, `right`, `mask_exp`, `left_gate`, `right_gate`, `out_gate`, `out`, `out_norm`: Intermediate tensors.
     - The tensor contraction size is `seqlen x seqlen x hidden_dim`, which overflows standard GEMM when using Tensor Cores.

3. **Implementation Procedure**:
   1. Perform LayerNorm in PyTorch.
   2. Project input using `left_proj` and `right_proj`, apply gates/sigmoid to multiplied features.
   3. Apply mask if present.
   4. Spawn-pending calls for the tensor contraction kernel to handle each `(b,d)` pair:
        - For each batch index `b` and each hidden_dim index `d` (parallel launch).
        - In kernel, reshape the `[N, N]` feature matrices for `[b,d]`.
        - Compute `C` via `A = left[b,:,d]` and `B = right[b,:,d]`, then `out[b,i,j,d] = dot(A[i], B[j])`.
   5. Convert summed results to float32 via this-proposed PyTorch path.
   6. Apply final LayerNorm and projection.

4. **Search Choices**:
   - **Kernel Launching**: `spawn` pending calls for scalability, keeping all memory-bound operations on CPU.
   - **Contraction Size**: `[seqlen, seqlen]` dimensions are large (e.g., 1024x1024), while `[seqlen, hidden_dim]` dimensions require careful tiling (possibly blocking `[seqlen, seqlen]` into 64x64 tiles).
   - **Mixed Precision**: Use fp16 intermediates (via PyTorch) during contraction, then convert to fp32 final output.
   - **Structure**: Conttraction broken into separate kernels per `(b, d)` pair, with `spawn` allowing multiple GPU offload targets.

5. **Compute Budget**:
   - **Memory**: Use pinned shared memory to store buffers for each `(b,d)` pair.
   - **Time**: Projections and gates done of batch tensor are ahead lowered via user’s Async API in if a faster overall path is possible.
   - **Fallback**: If aKernel fails to compile or launch, issue explicit warnings and use a synchronous CPU path (very slow).

6. **Validation**：
   - **Output Shape**: Consistent with input shape [B, N, N, dim].
   - **Values**: Proper thresholds applied for attention weights.
   - **Integration**: Kept with other operations using spawnpending calls.

7. **Reference Calls**: Use spawnpending calls for Tuple list operations, only transfer necessary intermediates to GPU.
   - `spawnpending` olive feature dimension, etc to avoid prolonged device hangs.
   - Note: Computation is split across computers, with each handling their own cache policies.
