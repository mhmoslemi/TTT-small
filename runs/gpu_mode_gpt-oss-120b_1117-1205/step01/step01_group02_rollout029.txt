analysisWe need to implement a custom kernel for TriMul (outgoing). Let's understand the operation.

Given x: [B, N, N, C] (dim = C). Steps:
- LayerNorm over dimension C (dim).
- Compute left = x_norm @ left_proj weight (Linear). left shape: [B,N,N,H] (hidden_dim)
- Compute right = x_norm @ right_proj weight, shape: [B,N,N,H].
- Mask & gating elementwise.
- Compute out = einsum('... i k d, ... j k d -> ... i j d', left, right). This is for each output (i,j), sum over k of left[i,k] * right[j,k], note shape: B,N,N,H.

Thus it's a batched multiplication across the "k" dimension: left_i_k multiplied with right_j_k and summed over k.

Let L[b,i,k,h] and R[b,j,k,h] then out[b,i,j,h] = sum_k L[b,i,k,h] * R[b,j,k,h].

That's equivalent to matrix multiplication: For each b and h, we have matrix L_bh shape (N,N) where (i,k) entry; same for R_bh shape (N,N) but we want R transposed because we need R[j,k] i.e., R's first index is j, second is k. Actually in formula, second argument is right ... j k d: its index order is i (second dim of output) and k (third dimension of input). So we can treat left as shape (N,N) matrix multiply with right^T: left[b,h] @ right[b,h].T where left shape (N,N) with rows = i, cols = k; right shape (N,N) with rows = j, cols = k. Then right^T shape (N,N) with rows = k, cols = j. Then product left @ right^T yields shape (i, j). So out[b,i,j,h] = (left[b,i,:] @ right[b,:,j]) which matches einstein.

Thus we can compute for each batch B and hidden_dim H a matrix multiplication of size N x N times N x N -> N x N.

Thus total operations: B * H such matrix multiplications (each O(N^3)). Since H (hidden_dim) may be 128 as per constraints, B up to 2. So total 256 matrix multiplications. It's large.

"""
TriMul (outgoing) forward pass.

The core of the operation is the tensor contraction
    out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]
which is a batched matrix multiplication L @ Rᵀ for each (b,h) pair.
We fuse this N×N × N×N multiplication with Triton.
All other operations (layer‑norms, linear projections, gating, mask handling)
are performed in PyTorch; the heavy N³ work is executed by a custom Triton GEMM.
"""

import torch
import triton
import triton.language as tl


@triton.jit
def trimul_gemm_kernel(
    a_ptr, b_ptr, c_ptr,                 # pointers
    M, N, K,                             # matrix sizes (int)
    stride_am, stride_ak,                # A strides: (row, col)
    stride_bk, stride_bn,                # B strides: (row, col)  (B is K×N)
    stride_cm, stride_cn,                # C strides: (row, col)
    stride_a_batch, stride_b_batch, stride_c_batch,  # batch strides
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """Batched GEMM: C = A @ B  where A:[M,K] B:[K,N] for many batches."""
    pid_m = tl.program_id(0)          # block row
    pid_n = tl.program_id(1)          # block col
    pid_b = tl.program_id(2)          # batch index (B·H)

    # offsets within the block
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)
    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # loop over K dimension
    num_k_tiles = tl.cdiv(K, BLOCK_K)
    for k_tile in range(0, num_k_tiles):
        k_offset = k_tile * BLOCK_K
        offs_k = tl.arange(0, BLOCK_K)
        mask_k = (k_offset + offs_k) < K

        # pointers to A and B tiles (including batch offset)
        a_ptrs = (
            a_ptr
            + pid_b * stride_a_batch
            + offs_m[:, None] * stride_am
            + (k_offset + offs_k)[None, :] * stride_ak
        )
        b_ptrs = (
            b_ptr
            + pid_b * stride_b_batch
            + (k_offset + offs_k)[:, None] * stride_bk
            + offs_n[None, :] * stride_bn
        )

        # load tiles with masking
        a = tl.load(a_ptrs, mask=mask_m[:, None] & mask_k[None, :], other=0.0)
        b = tl.load(b_ptrs, mask=mask_k[:, None] & mask_n[None, :], other=0.0)

        # outer product accumulation
        acc += tl.dot(a, b)

    # store result
    c_ptrs = (
        c_ptr
        + pid_b * stride_c_batch
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn
    )
    mask = mask_m[:, None] & mask_n[None, :]
    tl.store(c_ptrs, acc.to(tl.float16), mask=mask)


def custom_kernel(data):
    """
    Args:
        data: tuple (input_tensor, mask, weights, config)
            input_tensor: torch.Tensor [B, N, N, dim] (float32, CUDA)
            mask: torch.Tensor [B, N, N] (bool/float) or None
            weights: dict of torch.Tensor (model parameters)
            config: dict containing "dim" and "hidden_dim"
    Returns:
        torch.Tensor [B, N, N, dim] (float32)
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    eps = 1e-5

    # -----------------------------------------------------------------
    # 1. LayerNorm over channel dimension
    # -----------------------------------------------------------------
    x = torch.nn.functional.layer_norm(
        input_tensor,
        (dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
        eps=eps,
    )  # [B,N,N,dim]  float32

    # -----------------------------------------------------------------
    # 2. Linear projections (float32) and sigmoid gates
    # -----------------------------------------------------------------
    left = torch.nn.functional.linear(x, weights["left_proj.weight"])
    right = torch.nn.functional.linear(x, weights["right_proj.weight"])

    left_gate = torch.nn.functional.linear(x, weights["left_gate.weight"]).sigmoid()
    right_gate = torch.nn.functional.linear(x, weights["right_gate.weight"]).sigmoid()
    out_gate = torch.nn.functional.linear(x, weights["out_gate.weight"]).sigmoid()

    # -----------------------------------------------------------------
    # 3. Optional mask (broadcast over hidden dimension)
    # -----------------------------------------------------------------
    if mask is not None:
        mask_f = mask.to(x.dtype).unsqueeze(-1)   # [B,N,N,1]
        left = left * mask_f
        right = right * mask_f

    # -----------------------------------------------------------------
    # 4. Apply element‑wise gates
    # -----------------------------------------------------------------
    left = left * left_gate
    right = right * right_gate

    # -----------------------------------------------------------------
    # 5. Prepare data for the batched GEMM (cast to fp16 for speed)
    # -----------------------------------------------------------------
    # reshape to [B, H, N, N]
    left_perm = left.permute(0, 3, 1, 2).contiguous()   # [B,H,N,N] fp32
    right_perm = right.permute(0, 3, 1, 2).contiguous() # [B,H,N,N] fp32

    # transpose right for A @ B (no extra transpose inside kernel)
    right_T = right_perm.transpose(-2, -1).contiguous()  # [B,H,N,N]

    B, H, N, _ = left_perm.shape
    total_batch = B * H

    # cast to fp16 for the kernel
    left_fp16 = left_perm.to(torch.float16)
    right_fp16 = right_T.to(torch.float16)

    # flatten batch & head dimensions: [total_batch, N, N]
    left_flat = left_fp16.view(total_batch, N, N)
    right_flat = right_fp16.view(total_batch, N, N)
    out_flat = torch.empty((total_batch, N, N), dtype=torch.float16, device=device)

    # strides in elements
    stride_a_batch, stride_am, stride_ak = left_flat.stride()
    stride_b_batch, stride_bk, stride_bn = right_flat.stride()
    stride_c_batch, stride_cm, stride_cn = out_flat.stride()

    # -----------------------------------------------------------------
    # 6. Launch Triton kernel
    # -----------------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 64

    grid = (
        triton.cdiv(N, BLOCK_M),   # block rows
        triton.cdiv(N, BLOCK_N),   # block cols
        total_batch,               # batch dimension
    )

    trimul_gemm_kernel[grid](
        left_flat,
        right_flat,
        out_flat,
        N, N, N,                      # M, N, K
        stride_am, stride_ak,
        stride_bk, stride_bn,
        stride_cm, stride_cn,
        stride_a_batch, stride_b_batch, stride_c_batch,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # -----------------------------------------------------------------
    # 7. Reshape kernel output back to [B, N, N, hidden_dim]
    # -----------------------------------------------------------------
    out = (
        out_flat.view(B, H, N, N)          # [B,H,N,N]
        .permute(0, 2, 3, 1)               # [B,N,N,H]
        .contiguous()
        .to(torch.float32)                 # back to FP32 for the following layers
    )

    # -----------------------------------------------------------------
    # 8. Output LayerNorm, output gate and final projection
    # -----------------------------------------------------------------
    out = torch.nn.functional.layer_norm(
        out,
        (hidden_dim,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
        eps=eps,
    )
    out = out * out_gate  # out_gate already float32

    output = torch.nn.functional.linear(
        out, weights["to_out.weight"]
    )  # [B,N,N,dim], float32

    return output
