`out[b,i,j,h] = sum_{k} (left[b,i,k,h] * right[b,j,k,h])`

1. Normalize input tensor using LayerNorm weights/bias (host-side in PyTorch).
2. Project input to hidden_dim using two linear layers (host-side in PyTorch).
