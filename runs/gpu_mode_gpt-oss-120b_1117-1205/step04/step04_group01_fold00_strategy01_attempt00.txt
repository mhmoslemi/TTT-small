 The key steps are:
  1. Input LayerNorm (convert to float16 if beneficial, but note: we are only implementing forward and not gradients, so we can do this in place)
  2. Linear projections for left and right (left_proj and right_proj)
  3. Compute the gate values (left_gate and right_gate) with sigmoid
  4. Optionally fuse a mask (if provided) by multiplying with mask and gates
  5. Core contraction: for each (b, i, j, d), sum over k: left[b,i,k,d] * right[b,j,k,d]
  6. Apply output gate (out_gate) and final linear projection
  7. Output LayerNorm (final output in float32)
