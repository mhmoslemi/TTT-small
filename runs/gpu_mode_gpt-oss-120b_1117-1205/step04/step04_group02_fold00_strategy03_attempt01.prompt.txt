import torch
from torch import nn, einsum
import math

# Reference code in PyTorch
class TriMul(nn.Module):
    def __init__(
        self,
        dim: int,
        hidden_dim: int,
    ):
        super().__init__()

        self.norm = nn.LayerNorm(dim)

        self.left_proj = nn.Linear(dim, hidden_dim, bias=False)
        self.right_proj = nn.Linear(dim, hidden_dim, bias=False)

        self.left_gate = nn.Linear(dim, hidden_dim, bias=False)
        self.right_gate = nn.Linear(dim, hidden_dim, bias=False)
        self.out_gate = nn.Linear(dim, hidden_dim, bias=False)

        self.to_out_norm = nn.LayerNorm(hidden_dim)
        self.to_out = nn.Linear(hidden_dim, dim, bias=False)

    def forward(self, x: torch.Tensor, mask: torch.Tensor) -> torch.Tensor:
        """
        x: [bs, seq_len, seq_len, dim]
        mask: [bs, seq_len, seq_len]

        Returns:
            output: [bs, seq_len, seq_len, dim]
        """
        batch_size, seq_len, _, dim = x.shape

        x = self.norm(x)

        left = self.left_proj(x)
        right = self.right_proj(x)

        mask = mask.unsqueeze(-1)
        left = left * mask
        right = right * mask

        left_gate = self.left_gate(x).sigmoid()
        right_gate = self.right_gate(x).sigmoid()
        out_gate = self.out_gate(x).sigmoid()

        left = left * left_gate
        right = right * right_gate

        out = einsum('... i k d, ... j k d -> ... i j d', left, right)
        # This einsum is the same as the following:
        # out = torch.zeros(batch_size, seq_len, seq_len, dim, device=x.device)
        
        # # Compute using nested loops
        # for b in range(batch_size):
        #     for i in range(seq_len):
        #         for j in range(seq_len):
        #             # Compute each output element
        #             for k in range(seq_len):
        #                 out[b, i, j] += left[b, i, k, :] * right[b, j, k, :]

        out = self.to_out_norm(out)
        out = out * out_gate
        return self.to_out(out)

## Triton launch convention

Every failure mode below has appeared in this search. Read this before writing.

A `@triton.jit` function is NOT a Python function. It is launched with a grid
subscript, and its `tl.constexpr` parameters exist only inside it:

```python
@triton.jit
def my_kernel(x_ptr, y_ptr, n, BLOCK: tl.constexpr):
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    m = offs < n
    tl.store(y_ptr + offs, tl.load(x_ptr + offs, mask=m, other=0.0), mask=m)

def custom_kernel(data):
    ...
    BLOCK = 128                                   # a host variable YOU define
    grid = (triton.cdiv(n, BLOCK),)               # host-side, use triton.cdiv
    my_kernel[grid](x, y, n, BLOCK=BLOCK)         # note the [grid] subscript
```

- `my_kernel(...)` without `[grid]` raises "Cannot call @triton.jit'd outside
  the scope of a kernel".
- `BLOCK`, `BLOCK_M`, `BLOCK_N` are not defined on the host unless you define
  them there. Referencing one you only declared as a `tl.constexpr` parameter
  raises NameError.
- `tl.cdiv` is device-side. On the host use `triton.cdiv`.
- Define the kernel at module top level, never nested inside `custom_kernel`.

You do not have to move everything into Triton. A correct submission that keeps
most of the computation in PyTorch and moves one hot region into a kernel scores;

"""
Outgoing TriMul operator (AlphaFold3) forward pass.

Algorithm
---------
1. Layer‑norm the input tensor (float32 → float16).
2. Linear projections → left/right (half‑precision).
3. Compute three sigmoid gates (half‑precision).
4. Fuse mask (if present) and the left/right gates in a Triton kernel
   (in‑place element‑wise multiplication, broadcast mask over hidden dim).
5. Core O(N³) contraction:
   out_{b,i,j,d} = Σ_k left_{b,i,k,d} * right_{b,j,k,d}
   Implemented as a batched GEMM (torch.bmm) on half tensors:
   for each hidden channel d we perform a matmul left_d @ right_dᵀ.
6. Output layer‑norm, multiply by out‑gate and final linear projection.
   The result is returned as float32.

Only the mask‑gate fusion is performed in Triton; the heavy matrix
multiplication uses highly tuned cuBLAS via torch.bmm.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


@triton.jit
def gate_mask_fuse_kernel(
    left_ptr,          # * half
    right_ptr,         # * half
    left_gate_ptr,     # * half
    right_gate_ptr,    # * half
    mask_ptr,          # * half (broadcasted)
    total_elements,    # int32
    BLOCK: tl.constexpr,
    HAS_MASK: tl.constexpr,
    HIDDEN_DIM: tl.constexpr,
):
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    valid = offs < total_elements

    # Load tensors
    left = tl.load(left_ptr + offs, mask=valid, other=tl.float16(0.0))
    right = tl.load(right_ptr + offs, mask=valid, other=tl.float16(0.0))
    left_gate = tl.load(left_gate_ptr + offs, mask=valid, other=tl.float16(0.0))
    right_gate = tl.load(right_gate_ptr + offs, mask=valid, other=tl.float16(0.0))

    if HAS_MASK:
        mask_idx = offs // HIDDEN_DIM          # broadcast mask over hidden dim
        mask_val = tl.load(mask_ptr + mask_idx, mask=valid, other=tl.float16(1.0))
        left = left * left_gate * mask_val
        right = right * right_gate * mask_val
    else:
        left = left * left_gate
        right = right * right_gate

    # Store results back in‑place
    tl.store(left_ptr + offs, left, mask=valid)
    tl.store(right_ptr + offs, right, mask=valid)

        right_gate,
        mask_ptr,

    Parameters

    # Unpack inputs

    input_tensor, mask, weights, config = data

    dim = config["dim"]
    hidden_dim = config["hidden_dim"]

    # 1. Input LayerNorm (float32) → half precision
    # ------------------------------------------------------------------

        bias=weights["norm.bias"],

    # 2. Linear projections (half)
    # ------------------------------------------------------------------
    left = F.linear(
        x_h,
        weights["left_proj.weight"].to(torch.float16),
        bias=None,
    )
    right = F.linear(
        x_h,
        weights["right_proj.weight"].to(torch.float16),
        bias=None,
    )

    # ------------------------------------------------------------------
    # 3. Compute gates (half)
    # ------------------------------------------------------------------
    left_gate = F.linear(
        x_h,
        weights["left_gate.weight"].to(torch.float16),
        bias=None,

    right_gate = F.linear(
        x_h,
        weights["right_gate.weight"].to(torch.float16),
        bias=None,
    ).sigmoid()
    out_gate = F.linear(
        x_h,
        weights["out_gate.weight"].to(torch.float16),
        bias=None,
    ).sigmoid()

    # ------------------------------------------------------------------
    # 4. Fuse mask (if present) with gates via Triton
    # ------------------------------------------------------------------
    if not nomask and mask is not None:
        # Prepare mask
        mask_h = mask.to(torch.float16).contiguous().view(-1)   # [B*N*N]

        # Ensure contiguous tensors before flattening
        left_f = left.contiguous().view(-1)
        right_f = right.contiguous().view(-1)
        left_gate_f = left_gate.contiguous().view(-1)
        right_gate_f = right_gate.contiguous().view(-1)

            right_f,
            left_gate_f,
            right_gate_f,
            mask_h,
            hidden_dim,

        left = left_f.view_as(left)
        right = right_f.view_as(right)

        left = left * left_gate
        right = right * right_gate

    del left_gate, right_gate, x_h

    # 5. Core contraction via batched GEMM (half precision)
    #    out_{b,i,j,d} = Σ_k left_{b,i,k,d} * right_{b,j,k,d}
    # ------------------------------------------------------------------
    # Rearrange to (B, hidden_dim, N, N) for batched matmul
    left_perm = left.permute(0, 3, 1, 2).contiguous()   # (B, H, N, N)
    right_perm = right.permute(0, 3, 1, 2).contiguous() # (B, H, N, N)

    B, H, N, _ = left_perm.shape
    left_mat = left_perm.view(B * H, N, N)               # (B*H, N, N)
    right_mat = right_perm.view(B * H, N, N)             # (B*H, N, N)

    # Batched GEMM: left @ rightᵀ  (each hidden channel independent)
    out_mat = torch.bmm(left_mat, right_mat.transpose(1, 2))  # (B*H, N, N)

    # Restore (B, N, N, H) layout
    out = out_mat.view(B, H, N, N).permute(0, 2, 3, 1).contiguous()

    # 6. Output LayerNorm, out‑gate scaling and final linear projection

        bias=weights["to_out_norm.bias"].to(torch.float16),

        out,
        weights["to_out.weight"].to(torch.float16),
        bias=None,
    )

    return out.to(torch.float32)

The core challenge is the computation of the output tensor, which involves O(N^3) operations when dealing with large sequence lengths, making it crucial to implement this section efficiently. 

We break down the problem into several key steps:
1. **LayerNorm**: Normalize the input tensor in float32.
2. **Linear Projections**: Transform the normalized input into hidden_dim space using linear projections.
3. **Gate Computation**: Calculate three sigmoid gates using linear projections.
4. **Mask Fusion**: Apply mask and gates element-wise using a Triton kernel to avoid Python loops.
5. **Core Contraction**: Perform the heavy computation of the matrix multiplication via a batched operation within the Triton kernel.
6. **Output Processing**: Normalize the output and apply scaling before final projection.

**Mathematical Specification**:

We have an input tensor `x` with shape [B, N, N, C] and a mask tensor with shape [B, N, N]. The goal is to compute:

output[b, i, j, d] = left_proj[gated_data][b, i, :, d] @ right_proj[gated_data][b, j, :, d]

Where the projection and gating steps are defined by linear transformations, and the mask conditionally masks out positions to zero.

**Implementation Procedure**:

1. **LayerNorm**:
   - Input: `x` (float32)
   - Apply `nn.LayerNorm` to each 3D slice [N, N, C] in float32.
   - `x_layernorm = F.layer_norm(x.float(), (C,), weight, bias)`

2. **Take Gated Data (if using previous approach)**:
   - Optional but for sequential execution, use the output of the LayerNorm as the base tensor.

3. **Linear Projections**:
   - Apply `left_proj` (torch.nn.Linear) and `right_proj` (torch.nn.Linear) in float16 to reduce memory usage and optimize speed.
   - `left = left_proj(x_layernorm)` and `right = right_proj(x_layernormalized)`

4. **Gate Computation**:
   - Compute three separate sigmoid activations using the `left_gate`, `right_gate`, and `out_gate` linear projections, all in float16.
   - `left_gate = left_gate( activations ).sigmoid()`
   - `right_gate = right_gate( activations ).sigmoid()`

5. **Mask Fusion**:
