# 1. Approach and Rationale
This implementation adopts a hierarchical kernel fusion strategy using Triton:

- **Key Insight**: The TriMul operation is essentially a batched matrix multiplication with extra dimensions. We must compute `output[b,i,j] = (left[b,i] @ right[b,j]).t()` but with careful memory access patterns.
- **Manual Blocking**: We implement dynamic tiling of the sequences with explicit reduction over the masked sequence dimensions. This avoids excessive grid sizes while maximizing Tensor Core utilization.
- **Optimization Focus**: Main gains come from:
  - In-place fused operations ($*$ gate $*$ mask) to reduce memory overhead
  - Tensor Core-ready tiling in the `@` operation (contraction stage)
  - Minimal use of explicit loops at element-wise level

The primary benefit is reducing the O(N^3) complexity to a Tensor Core fast path, but noting that the entire implementation requires manual blocking.
