We have:

- Input x: shape [B, N, N, dim]
- mask: shape [B, N, N] (optional)
- Model weights:

Operation steps:
1. Apply norm on x (full tensor). (LayerNorm per element across last dim.)
2. left = left_proj(x)  shape [B,N,N,hidden_dim]
   right = right_proj(x) shape [B,N,N,hidden_dim]
   (Both per element linear transform)
3. mask: unsqueeze(-1) to broadcast over hidden_dim, then multiply:
   left = left * mask; right = right * mask.
   If nomask true (no mask), we can skip.
4. left_gate = left_gate(x).sigmoid()
   right_gate = right_gate(x).sigmoid()
   out_gate = out_gate(x).sigmoid()
5. left = left * left_gate
   right = right * right_gate
   (So gating and mask fused.)
6. out = einsum('... i k d, ... j k d -> ... i j d', left, right)
   Equivalent to: for each batch b, for each i,j, sum over k: left[b,i,k,d] * right[b,j,k,d]
   So shape [B,N,N,hidden_dim]. This is a contraction over axis k (the second dimension of left and third dimension of right? Actually left dims: (b, i, k, d); right dims: (b, j, k, d). Not symmetrical; they share k and d but right has j in position second. So performing per hidden dimension:
   Out_{b,i,j,d} = sum_{k} left_{b,i,k,d} * right_{b,j,k,d}.
   So we can treat each hidden dimension d separately as batched matrix multiplication between left[..., :, :, d] (shape B x N x N) and right[..., :, :, d] (B x N x N) with second operand transposed on the second axis? Actually left: (B,N,N) where left dimension order is (i,k). right: (B,N,N) where (j,k). So we need to compute left_{b, i, k} dot right_{b, j, k} across k. That is like a matrix multiplication where left has rows i and columns k, and right has rows j and columns k (i.e., right's columns are also k). If we transpose right on the second dimension (k) to create shape (B,N,N) with rows k and columns j? Wait:

Let left_{b}[i,k] = left[b,i,k,d]; right_{b}[j,k] = right[b,j,k,d]; out_{b}[i,j] = sum_k left_{b}[i,k] * right_{b}[j,k]. This is like left @ right.T under usual matrix multiplication where left shape (i,k) and right shape (j,k). But right.T shape (k,j). So out = left @ right.T. So out = left_mat @ right_mat^T.

Hence we can compute for each hidden dimension d and each batch b: out_{b,:,:,d} = left_{b,:,:,d} @ right_{b,:,:,d}^T.

def fuse_left_right_gate_mask_kernel(
    left_ptr, right_ptr,
    left_gate_ptr, right_gate_ptr,
    mask_ptr,   # mask broadcasted (maybe same pointer if no mask)
    total_elems: tl.int32,
    H: tl.constexpr,
    HAS_MASK: tl.constexpr,
    BLOCK: tl.constexpr
):
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    mask = offs < total_elems
    left = tl.load(left_ptr + offs, mask=mask, other=0.0)
    right = tl.load(right_ptr + offs, mask=mask, other=0.0)
    left_gate = tl.load(left_gate_ptr + offs, mask=mask, other=0.0)
    right_gate = tl.load(right_gate_ptr + offs, mask=mask, other=0.0)
    if HAS_MASK:
        # mask index = (offs // H)
        mask_idx = offs // H
        m = tl.load(mask_ptr + mask_idx, mask=mask, other=1.0)  # mask is 0 or 1.
        left = left * left_gate * m
        right = right * right_gate * m
    else:
        left = left * left_gate
        right = right * right_gate
    tl.store(left_ptr + offs, left, mask=mask)
    tl.store(right_ptr + offs, right, mask=mask)

"""
TriMul (outgoing) forward implementation with Triton‐fused mask & gating.

Algorithm
---------
1. Layer‑norm the input (float32) → half precision.
2. Linear projections to hidden_dim: left_proj, right_proj (half).
3. Compute gating tensors (left_gate, right_gate, out_gate) via linear + sigmoid (half).
4. Fuse mask (if any) and gating in‑place with a small Triton kernel:
       left  = left  * left_gate  * mask
       right = right * right_gate * mask
5. Perform the O(N³) contraction as a batch of GEMMs:
       out_{b,i,j,d} = Σ_k left_{b,i,k,d} * right_{b,j,k,d}
   which is equivalent to batched matrix multiplication
       left @ rightᵀ   (per hidden dimension).
6. Apply output LayerNorm, multiply by out_gate, and a final linear projection
   back to the original dimension.
7. Return the result in float32.

Only the mask‑gate fusion is performed in Triton; the rest uses
high‑performance torch operations (batched GEMM, layer‑norm, etc.).
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


@triton.jit
def _gate_mask_fuse_kernel(
    left_ptr,                 # float16 *
    right_ptr,                # float16 *
    left_gate_ptr,            # float16 *
    right_gate_ptr,           # float16 *
    mask_ptr,                 # float16 * (broadcasted)
    total_elems: tl.int32,    # total number of elements in left/right tensors
    H: tl.constexpr,          # hidden_dim (size of innermost channel)
    HAS_MASK: tl.constexpr,   # 1 if mask is present, else 0
    BLOCK: tl.constexpr,      # block size
):
    """
    In‑place fusion kernel:
        left  = left  * left_gate  * mask
        right = right * right_gate * mask
    When HAS_MASK == 0 the mask term is omitted.
    The mask is broadcast over the hidden dimension, i.e. each (b,i,j)
    entry shares a single mask value.
    """
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    active = offs < total_elems

    # Load tensors
    left = tl.load(left_ptr + offs, mask=active, other=0.0)
    right = tl.load(right_ptr + offs, mask=active, other=0.0)
    left_gate = tl.load(left_gate_ptr + offs, mask=active, other=0.0)
    right_gate = tl.load(right_gate_ptr + offs, mask=active, other=0.0)

    if HAS_MASK:
        # Compute index into the mask (broadcast over H)
        mask_idx = offs // H
        mask_val = tl.load(mask_ptr + mask_idx, mask=active, other=1.0)
        left = left * left_gate * mask_val
        right = right * right_gate * mask_val
    else:
        left = left * left_gate
        right = right * right_gate

    # Store results back in‑place
    tl.store(left_ptr + offs, left, mask=active)
    tl.store(right_ptr + offs, right, mask=active)


def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Args:
        data: tuple (input_tensor, mask, weights, config)
            - input_tensor: torch.Tensor [B, N, N, dim] (float32)
            - mask: torch.Tensor [B, N, N] (bool or float) – may be ignored if nomask=True
            - weights: dict of model parameters (float32)
            - config: dict containing "dim", "hidden_dim", optional "nomask"

    Returns:
        torch.Tensor [B, N, N, dim] (float32)
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device

    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    nomask = config.get("nomask", True)

    # ------------------------------------------------------------------
    # 1. Input LayerNorm (float32) → half precision
    # ------------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        (dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
    )
    x_h = x.to(torch.float16)

    # ------------------------------------------------------------------
    # 2. Linear projections to hidden_dim (half)
    # ------------------------------------------------------------------
    left = F.linear(
        x_h,
        weights["left_proj.weight"].to(torch.float16),
        bias=None,
    )
    right = F.linear(
        x_h,
        weights["right_proj.weight"].to(torch.float16),
        bias=None,
    )

    # ------------------------------------------------------------------
    # 3. Gates (half) with sigmoid
    # ------------------------------------------------------------------
    left_gate = F.linear(
        x_h,
        weights["left_gate.weight"].to(torch.float16),
        bias=None,
    ).sigmoid()
    right_gate = F.linear(
        x_h,
        weights["right_gate.weight"].to(torch.float16),
        bias=None,
    ).sigmoid()
    out_gate = F.linear(
        x_h,
        weights["out_gate.weight"].to(torch.float16),
        bias=None,
    ).sigmoid()

    # ------------------------------------------------------------------
    # 4. Fuse mask (if any) with gates via Triton kernel
    # ------------------------------------------------------------------
    # Ensure contiguous layout for 1‑D view
    left_f = left.contiguous().view(-1)
    right_f = right.contiguous().view(-1)
    left_gate_f = left_gate.contiguous().view(-1)
    right_gate_f = right_gate.contiguous().view(-1)

    if not nomask:
        mask_h = mask.to(torch.float16).contiguous().view(-1)  # [B*N*N]
    else:
        mask_h = None

    total = left_f.numel()
    BLOCK = 1024
    grid = (triton.cdiv(total, BLOCK),)

    _gate_mask_fuse_kernel[grid](
        left_f,
        right_f,
        left_gate_f,
        right_gate_f,
        mask_h if mask_h is not None else left_f,  # dummy pointer when no mask
        total,
        H=hidden_dim,
        HAS_MASK=0 if mask_h is None else 1,
        BLOCK=BLOCK,
    )

    # Restore original shapes (views share storage)
    left = left_f.view_as(left)
    right = right_f.view_as(right)

    # Free gate tensors no longer needed
    del left_gate, right_gate, left_gate_f, right_gate_f, x_h, mask_h

    # ------------------------------------------------------------------
    # 5. Core contraction via batched GEMM:
    #    out_{b,i,j,d} = Σ_k left_{b,i,k,d} * right_{b,j,k,d}
    # ------------------------------------------------------------------
    # Move hidden dimension to second axis for efficient matmul
    left_perm = left.permute(0, 3, 1, 2).contiguous()   # (B, H, N, N)
    right_perm = right.permute(0, 3, 1, 2).contiguous() # (B, H, N, N)

    B, H, N, _ = left_perm.shape
    left_mat = left_perm.view(B * H, N, N)    # (B*H, N, N)
    right_mat = right_perm.view(B * H, N, N)  # (B*H, N, N)

    # Batched matrix multiplication with transpose on the second operand
    out_mat = torch.bmm(left_mat, right_mat.transpose(1, 2))  # (B*H, N, N)

    # Reshape back to (B, N, N, H)
    out = out_mat.view(B, H, N, N).permute(0, 2, 3, 1).contiguous()

    # ------------------------------------------------------------------
    # 6. Output LayerNorm, out‑gate scaling, final linear projection
    # ------------------------------------------------------------------
    out = F.layer_norm(
        out,
        (hidden_dim,),
        weight=weights["to_out_norm.weight"].to(torch.float16),
        bias=weights["to_out_norm.bias"].to(torch.float16),
    )
    out = out * out_gate  # element‑wise gating (half)

    out = F.linear(
        out,
        weights["to_out.weight"].to(torch.float16),
        bias=None,
    )

    # Return in float32 as required by the interface
    return out.to(torch.float32)
