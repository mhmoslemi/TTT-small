analysisWe need to implement custom_kernel which receives a tuple of input_tensor, mask, weights, config. We must implement the TriMul operator in forward pass, but we need to implement part of the operations in a Triton kernel for better performance. The final output must be a torch Tensor.

The reference implementation uses LayerNorm, Linear (project weights), gating, and a contraction using einsum (which is the main computationally heavy part). The main heavy part is:

- left = left_proj(x) → shape [B, N, N, hidden_dim]
- left = left * mask (broadcast mask shape [B, N, N, 1])
- left_gate = sigmoid(left_gate_proj(x)) → shape [B,N,N,hidden_dim], left = left * left_gate
Similarly right = right_proj(x) * mask * right_gate (right_gate sigma)
- out = einsum('... i k d, ... j k d -> ... i j d', left, right)

Let's decode: left shape: [B, N, N, H], right shape: [B, N, N, H]; note we treat dims as index i: first pairwise dimension, second pairwise dimension, and k is the third dimension (the shared dimension being summed over). In einsum: left dims: ... i k d, right dims: ... j k d. So we sum over k and d contracts at the same "d"? Wait the d corresponds to hidden_dim (d=H). But the contraction sums over index k (the second index of left and right) while leaving i and j, and keeping d (hidden_dim) same. So out shape: ... i j d, same dims but without k. So we are performing, for each batch b, hidden dim d, and i,j: out[b,i,j,d] = sum_{k=0}^{N-1} left[b,i,k,d] * right[b,j,k,d].

Thus it's equivalent to a batched matrix multiplication with per-d dimension: For each d, left[b,:, :, d] is a matrix shape [N,N]; right[b,:, :, d] is also [N,N] but we multiply left[b,i,k,d] with right[b,j,k,d] meaning we need left[b,:, :, d] (N x N) multiplied by right[b,:, :, d] transposed on the second dimension (?), but note we sum over k: left[b,i,k,d] * right[b,j,k,d] = (left[b,:, :, d]) dot (right[b,:, :, d]^\top) -> but careful: right's second index is j, third is k. So right[b,j,k,d] but we view as matrix with rows j and columns k. So we are summation over k of left[i,k] * right[j,k] = left[i,:] dot right[j,:] = (left) @ (right).T? Actually (right[j,k]) is row j, column k. left[i,k] is row i, column k. Then out[i,j] = sum_k left[i,k] * right[j,k] = left @ right^T (since (right^T) has shape [N,N] with indices (k,j)). Indeed left (i,k) times right^T (k,j) gives i,j entry. So out = left @ right^T for each d and batch.

Thus the heavy operation reduces to: For each batch b and each hidden dimension d, compute matrix multiplication between left[b,:,:,d] and right[b,:,:,d]^T. So we have shape B x H x N x N * B x H x N x N -> out shape B x H x N x N.

We can restructure this as we fuse d dimension (hidden) with batch: treat (B*H) as batch dimension for matmul. That is, we can flatten left and right as [B*H, N, N] and compute matmul producing [B*H, N, N].

We can use Triton to perform this batched matrix multiplication with no bias, but we also have later a to_out_norm and to_out linear weight.

Potential approach: Use PyTorch for LayerNorm, gates, projection, mask, etc., and then use a triton kernel for the batched matmul (left @ right^T). Then perhaps also do to_out_norm and to_out in PyTorch.

But we need to load the weights manually and implement Linear layers ourselves because weight matrices are provided. Could implement linear transformation via torch.nn.functional.linear using weight and no bias. That can be done in PyTorch efficiently enough.

But must implement the heavy part (the batched matmul) in Triton. We need to decide BLOCK sizes for N and H.

Given constraints: N can be up to 1024, hidden_dim is up to 128 (and maybe also 128? In tests hidden_dim always 128). B is 1 or 2. So B*H is up to 2*128=256. That's moderate. So we need to compute for each (batch*hidden) a matmul of size N x N @ N x N not transposed, but we need right^T. Or we can compute left @ right_T = left @ right_permuted.

But better to directly compute using a Triton kernel that loads from left and right and does dot product over k.

We need to handle different data types for computing: we can cast to float16 (or bfloat16) for speed then convert to float32 final. The reference uses left in bfloat16 before einsum. The weights are float32? Usually we can cast to FP16. But we can keep everything in float16 for matmul, convert to float32 for output.

@triton.jit
def batched_matmul_kernel(
    A_ptr, B_ptr, C_ptr,
    M, N, K,
    stride_am, stride_ai, stride_ak,
    stride_bm, stride_bn, stride_bk,
    stride_cm, stride_ci, stride_cj,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr
):
    pid = tl.program_id(0)
    # Compute grid dimensions
    num_blocks_i = tl.cdiv(N, BLOCK_M)
    num_blocks_j = tl.cdiv(N, BLOCK_N)
    # Determine batch index, block_i, block_j
    batch = pid // (num_blocks_i * num_blocks_j)
    tmp = pid % (num_blocks_i * num_blocks_j)
    block_i = tmp // num_blocks_j
    block_j = tmp % num_blocks_j

    # Compute offsets if out of bounds
    offs_i = block_i * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_j = block_j * BLOCK_N + tl.arange(0, BLOCK_N)
    # Masks for global boundaries
    mask_i = offs_i < N
    mask_j = offs_j < N

    # Initialize accumulator
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # Loop over K dimension
    for kk in range(0, tl.cdiv(K, BLOCK_K)):
        k_off = kk * BLOCK_K
        offs_k = k_off + tl.arange(0, BLOCK_K)
        # mask for K
        mask_k = offs_k < K

        # Load A block: shape [BLOCK_M, BLOCK_K]
        a_ptrs = A_ptr + batch * stride_am + offs_i[:, None] * stride_ai + offs_k[None, :] * stride_ak
        a = tl.load(a_ptrs, mask=mask_i[:, None] & mask_k[None, :], other=0.0)
        # Load B_T block: shape [BLOCK_K, BLOCK_N]
        # B originally [M,N,K], we need B_T: row=j (original col) and col=k (original row)
        b_ptrs = B_ptr + batch * stride_bm + offs_k[:, None] * stride_bn + offs_j[None, :] * stride_bk
        b = tl.load(b_ptrs, mask=mask_k[:, None] & mask_j[None, :], other=0.0)

        # Convert to float32
        a = a.to(tl.float32)
        b = b.to(tl.float32)

        # Dot product accumulation
        acc += tl.dot(a, b)

    # Store result
    c_ptrs = C_ptr + batch * stride_cm + offs_i[:, None] * stride_ci + offs_j[None, :] * stride_cj
    c_mask = mask_i[:, None] & mask_j[None, :]
    tl.store(c_ptrs, acc.to(tl.float16), mask=c_mask)

"""
TriMul forward (outgoing) implementation with a custom Triton kernel.

Algorithm
---------
1. Layer‑norm the input `x` using the provided LN parameters.
2. Linear projections (`left_proj`, `right_proj`) and three gates
   (`left_gate`, `right_gate`, `out_gate`) are computed with the supplied
   weights.  The projected values are multiplied with their gates and an
   (optional) mask.
3. For each hidden channel the contraction
        out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
   is a batched matrix multiplication `left @ rightᵀ`.  This O(N³) step is
   performed by a Triton kernel that computes, for every (batch,
   hidden_dim) pair, C = A @ Bᵀ where A and B are N×N matrices stored as
   half‑precision tensors.
4. The result is cast back to float32, reshaped to `[B, N, N, hidden_dim]`,
   passed through a second layer‑norm, multiplied by `out_gate`, and finally
   projected back to the original dimension `dim` with a linear layer.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl

# -----------------------------------------------------------------------------#
# Triton kernel: batched matmul C = A @ Bᵀ
# A, B, C have shape (M, N, N) where M = batch * hidden_dim.
# -----------------------------------------------------------------------------#
@triton.jit
def batched_matmul_kernel(
    A_ptr,                     # *ptr, half
    B_ptr,                     # *ptr, half
    C_ptr,                     # *ptr, half (output)
    M, N, K,                   # int32 scalars
    stride_am, stride_ai, stride_ak,   # strides for A  (batch, row, col)
    stride_bm, stride_bn, stride_bk,   # strides for B  (batch, row, col) – will be accessed as Bᵀ
    stride_cm, stride_ci, stride_cj,   # strides for C  (batch, row, col)
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr
):
    pid = tl.program_id(0)

    # Number of tiles along the two output dimensions
    num_blocks_i = tl.cdiv(N, BLOCK_M)
    num_blocks_j = tl.cdiv(N, BLOCK_N)

    # Decompose pid → (batch, tile_i, tile_j)
    batch = pid // (num_blocks_i * num_blocks_j)
    tmp = pid % (num_blocks_i * num_blocks_j)
    tile_i = tmp // num_blocks_j
    tile_j = tmp % num_blocks_j

    # Offsets for the output tile
    offs_i = tile_i * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_j = tile_j * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_i = offs_i < N
    mask_j = offs_j < N

    # Accumulator in FP32 for better precision
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # Loop over the reduction dimension K (which equals N)
    for kk in range(0, tl.cdiv(K, BLOCK_K)):
        k_off = kk * BLOCK_K
        offs_k = k_off + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # -------- load A block (M tile_i × K) --------
        a_ptrs = (A_ptr
                  + batch * stride_am
                  + offs_i[:, None] * stride_ai
                  + offs_k[None, :] * stride_ak)
        a = tl.load(a_ptrs,
                    mask=mask_i[:, None] & mask_k[None, :],
                    other=0.0)
        a = a.to(tl.float32)

        # -------- load Bᵀ block (K × N tile_j) --------
        # B is stored as (batch, row, col).  To access Bᵀ we treat the row
        # index as the original column and the column index as the original row.
        b_ptrs = (B_ptr
                  + batch * stride_bm
                  + offs_k[:, None] * stride_bn   # original row index (k)
                  + offs_j[None, :] * stride_bk)   # original column index (j)
        b = tl.load(b_ptrs,
                    mask=mask_k[:, None] & mask_j[None, :],
                    other=0.0)
        b = b.to(tl.float32)

        # -------- accumulate --------
        acc += tl.dot(a, b)   # (BLOCK_M, BLOCK_K) @ (BLOCK_K, BLOCK_N)

    # Store the result back in FP16
    c_ptrs = (C_ptr
              + batch * stride_cm
              + offs_i[:, None] * stride_ci
              + offs_j[None, :] * stride_cj)
    mask_store = mask_i[:, None] & mask_j[None, :]
    tl.store(c_ptrs, acc.to(tl.float16), mask=mask_store)


# -----------------------------------------------------------------------------#
# Host‑side entry point
# -----------------------------------------------------------------------------#
def custom_kernel(data):
    """
    Triton‑accelerated forward pass for the outgoing TriMul operator.

    Args:
        data: Tuple (input, mask, weights, config)
            - input: Tensor[B, N, N, dim]   (float32)
            - mask : Tensor[B, N, N]        (bool / 0‑1)
            - weights: dict of tensors required by the module
            - config : dict containing 'dim' and 'hidden_dim'

    Returns:
        Tensor[B, N, N, dim] (float32)
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    eps = 1e-5

    B, N, _, D = input_tensor.shape
    hidden_dim = config["hidden_dim"]
    dim = config["dim"]

    # --------------------------------------------------------------------- #
    # 1. Input layer norm
    # --------------------------------------------------------------------- #
    norm_weight = weights["norm.weight"]
    norm_bias = weights["norm.bias"]
    x = F.layer_norm(
        input_tensor,
        (D,),
        weight=norm_weight,
        bias=norm_bias,
        eps=eps,
    )  # [B, N, N, D], float32

    # --------------------------------------------------------------------- #
    # 2. Projections and gates (float32)
    # --------------------------------------------------------------------- #
    left_proj = F.linear(x, weights["left_proj.weight"])
    right_proj = F.linear(x, weights["right_proj.weight"])

    left_gate = F.linear(x, weights["left_gate.weight"]).sigmoid()
    right_gate = F.linear(x, weights["right_gate.weight"]).sigmoid()
    out_gate = F.linear(x, weights["out_gate.weight"]).sigmoid()   # [B,N,N,hidden_dim]

    # --------------------------------------------------------------------- #
    # 3. Apply mask and gates, then cast to half (FP16) for the matmul
    # --------------------------------------------------------------------- #
    mask_exp = mask.unsqueeze(-1).to(x.dtype)               # [B,N,N,1]
    left = (left_proj * left_gate * mask_exp).to(torch.float16)
    right = (right_proj * right_gate * mask_exp).to(torch.float16)

    # --------------------------------------------------------------------- #
    # 4. Prepare tensors for the batched matmul kernel
    #    Layout: (B * hidden_dim, N, N)
    # --------------------------------------------------------------------- #
    # Move hidden_dim to the second axis and flatten batch*hidden_dim
    left = left.permute(0, 3, 1, 2).contiguous()   # [B, H, N, N]
    right = right.permute(0, 3, 1, 2).contiguous() # [B, H, N, N]
    M = B * hidden_dim
    left_flat = left.view(M, N, N)
    right_flat = right.view(M, N, N)

    # Output buffer (FP16)
    out_flat = torch.empty((M, N, N), dtype=torch.float16, device=device)

    # Strides for the kernel
    stride_am, stride_ai, stride_ak = left_flat.stride()
    stride_bm, stride_bn, stride_bk = right_flat.stride()
    stride_cm, stride_ci, stride_cj = out_flat.stride()

    # --------------------------------------------------------------------- #
    # 5. Launch Triton kernel
    # --------------------------------------------------------------------- #
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 64

    num_blocks_i = triton.cdiv(N, BLOCK_M)
    num_blocks_j = triton.cdiv(N, BLOCK_N)
    total_programs = M * num_blocks_i * num_blocks_j
    grid = (total_programs,)

    batched_matmul_kernel[grid](
        left_flat,
        right_flat,
        out_flat,
        M, N, N,
        stride_am, stride_ai, stride_ak,
        stride_bm, stride_bn, stride_bk,
        stride_cm, stride_ci, stride_cj,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )
    # Ensure kernel completion before next ops
    torch.cuda.synchronize()

    # --------------------------------------------------------------------- #
    # 6. Post‑processing in FP32
    # --------------------------------------------------------------------- #
    # Reshape back to [B, N, N, hidden_dim]
    out = out_flat.view(B, hidden_dim, N, N).permute(0, 2, 3, 1).to(torch.float32)

    # Second layer norm over hidden_dim
    out = F.layer_norm(
        out,
        (hidden_dim,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
        eps=eps,
    )

    # Multiply by out_gate (float32)
    out = out * out_gate

    # Final linear projection to original `dim`
    out = F.linear(out, weights["to_out.weight"])

    return out
