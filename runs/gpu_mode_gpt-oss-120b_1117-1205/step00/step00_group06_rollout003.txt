- Input: x shape [B, N, N, C]; mask shape [B, N, N] (maybe None or all ones).
- model weights: weight dict for all linear layers (no bias). plus LayerNorm weights/bias.

Process:

1. x_norm = LayerNorm over last dim (C). Equivalent to (x - mean)/sqrt(var + eps) * weight + bias. Usually, weight shape [C], bias shape [C], epsilon = 1e-5 (PyTorch's default). We'll need to compute mean/var per last dimension across channel dimension? Actually, LayerNorm applied over last dim = C per each element [..., C] individually across C. So for each (b,i,k) we have a row of length C. Compute mean, var across C. Then produce x_norm = (x - mean)/sqrt(var+eps) * weight + bias. Note that input may be (float32). The reference code uses nn.LayerNorm(dim) default eps=1e-5. We'll replicate.

2. left_proj = Linear(x_norm, weight = left_proj_weight shape [hidden_dim, dim] or [dim, hidden_dim]? In PyTorch nn.Linear(in_features, out_features, bias=False) weight shape [out_features, in_features]. So left_proj (x @ weight.T) basically. Input shape [B,N,N,dim] => output shape [B,N,N,hidden_dim]. Right similarly.

3. mask: unsqueeze(-1) to shape [B,N,N,1]; left = left * mask; right = right * mask. This zeros out mask false positions (mask likely 0/1). We'll treat mask as float (0/1). In outgoing version: they apply mask after proj.

4. left_gate = sigmoid(left_gate_linear(x_norm)): shape [B,N,N,hidden_dim]; right_gate similarly; out_gate similarly (for final output). Apply gate: left = left * sigmoid_gate_left; right = right * sigmoid_gate_right.

5. out = einsum('... i k d, ... j k d -> ... i j d', left, right). Explanation: left dims: (b,i,k,d) where k iterates seq indices. Right dims: (b,j,k,d). We sum over k, resulting shape (b,i,j,d). This is essentially for each output pair (i,j) for each batch b and channel d: sum over k of left[b,i,k,d] * right[b,j,k,d].

This is a large compute: O(N^3 * hidden_dim). There's potential to use GEMM-like approach: treat left as shape [B,N,hidden_dim,N]? Actually left shape [B,N,N,hidden_dim] with axes i (first seq), k (second seq), d (channel). Similarly right shape [B,N,N,hidden_dim] with axes j (first seq), k (second seq), d (channel). The operation can be computed by for each b,d we compute matrix M_left = left[..., :, :, d] shape [N,N] (i,k). M_right = right[..., :, :, d] shape [N,N] (j,k). Then result_{i,j,d} = sum_k M_left[i,k] * M_right[j,k] = (M_left @ M_right.T)[i,j]. Actually M_right[j,k] uses j row but k column, same shape as left but swapped first dimension. So basically for each d, compute left_slice @ right_slice^T. So each d independent. That suggests we can compute a batched matrix multiplication.

Thus out = torch.einsum('bikd,bjkd->bijd') = For each batch b and channel d compute (left[b,:, :, d] @ right[b,:, :, d].T). So we need to compute that efficiently.

We can implement this with a Triton kernel that computes matrix multiplication per channel per batch: basically compute (B * hidden_dim) batched GEMMs each of size (N x N) * (N x N). The result also shape [B,N,N,hidden_dim].

We can implement a fused GEMM: use block matrix multiplication: blockM = BLOCK_M, blockN = BLOCK_N, blockK = BLOCK_K. Use typical triton matmul kernel.

But need also incorporate pre-processing steps: LayerNorm, projection linear, gating, masking. Some may be done in PyTorch to simplify; but must implement at least part in Triton. The heavy part is the triple reduction (matmul). So it is acceptable to keep earlier steps in PyTorch, and only implement the core einsum using Triton.

Pseudo-code for custom_kernel:

```python
def custom_kernel(data):
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    eps = 1e-5

    dim = config["dim"]; hidden_dim = config["hidden_dim"]
    # Extract weights
    norm_weight = weights["norm.weight"]
    norm_bias = weights["norm.bias"]
    left_proj_weight = weights["left_proj.weight"]
    right_proj_weight = weights["right_proj.weight"]
    left_gate_weight = weights["left_gate.weight"]
    right_gate_weight = weights["right_gate.weight"]
    out_gate_weight = weights["out_gate.weight"]
    to_out_norm_weight = weights["to_out_norm.weight"]
    to_out_norm_bias = weights["to_out_norm.bias"]
    to_out_weight = weights["to_out.weight"]

    # LayerNorm on input
    # compute mean and var
    x = input_tensor
    mean = x.mean(dim=-1, keepdim=True)
    var = x.var(dim=-1, unbiased=False, keepdim=True)
    x_norm = (x - mean) / torch.sqrt(var + eps)
    x_norm = x_norm * norm_weight + norm_bias

    # Projections
    left = torch.nn.functional.linear(x_norm, left_proj_weight)  # shape [B,N,N,hidden_dim]
    right = torch.nn.functional.linear(x_norm, right_proj_weight)

    if mask is not None:
        mask_unsq = mask.unsqueeze(-1).type_as(left)
        left = left * mask_unsq
        right = right * mask_unsq

    # Gates
    left_gate = torch.nn.functional.linear(x_norm, left_gate_weight).sigmoid()
    right_gate = torch.nn.functional.linear(x_norm, right_gate_weight).sigmoid()
    out_gate = torch.nn.functional.linear(x_norm, out_gate_weight).sigmoid()

    left = left * left_gate
    right = right * right_gate

    # Compute output using triton matmul kernel
    B, N, _, _ = left.shape # third dim N as second N

    # Prepare output tensor
    out = torch.empty((B, N, N, hidden_dim), device=device, dtype=torch.float32)
    # call kernel
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 64

    # compute strides for left/right/out:
    # For left shape [B,N,N,hidden_dim]
    s_l_b, s_l_i, s_l_k, s_l_h = left.stride()
    s_r_b, s_r_j, s_r_k, s_r_h = right.stride()  # same as left but names changed
    s_o_b, s_o_i, s_o_j, s_o_h = out.stride()
    # Use kernel
    grid = (triton.cdiv(N, BLOCK_M), triton.cdiv(N, BLOCK_N), B * hidden_dim)
    tri_mul_gemm_kernel[grid](
        left, right, out,
        N,
        hidden_dim,
        B,
        s_l_b, s_l_i, s_l_k, s_l_h,
        s_r_b, s_r_j, s_r_k, s_r_h,
        s_o_b, s_o_i, s_o_j, s_o_h,
        BLOCK_M=BLOCK_M, BLOCK_N=BLOCK_N, BLOCK_K=BLOCK_K
    )
    # After kernel out now shape [B,N,N,hidden_dim]

    # to_out_norm (LayerNorm over hidden_dim)
    # compute mean and var over last dim
    out_mean = out.mean(dim=-1, keepdim=True)
    out_var = out.var(dim=-1, unbiased=False, keepdim=True)
    out_norm = (out - out_mean) / torch.sqrt(out_var + eps)
    out_norm = out_norm * to_out_norm_weight + to_out_norm_bias

    # Multiply by out_gate
    out_norm = out_norm * out_gate

    # Final linear
    out_final = torch.nn.functional.linear(out_norm, to_out_weight)

    return out_final
```

def tri_mul_gemm_kernel(
    left_ptr, right_ptr, out_ptr,
    N, H, B,
    stride_l_b, stride_l_i, stride_l_k, stride_l_h,
    stride_r_b, stride_r_i, stride_r_k, stride_r_h,
    stride_o_b, stride_o_i, stride_o_j, stride_o_h,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr
):
    pid_m = tl.program_id(0) # i block
    pid_n = tl.program_id(1) # j block
    pid_z = tl.program_id(2) # batch*head index

    b = pid_z // H
    h = pid_z % H

    # Determine offsets
    offs_i = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_j = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)
    offs_k = tl.arange(0, BLOCK_K)

    mask_i = offs_i < N
    mask_j = offs_j < N

    # compute base offsets for left and right:
    # left offset factor base: b*stride_lb + h*stride_lh
    # left_i offset: offs_i[:, None] * stride_l_i
    # left_k offset: (k_base + offs_k)[None, :] * stride_l_k
    # left_ptr base = left_ptr + b*slb + h*slh

    # Initialize acc
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    for kk in range(0, tl.cdiv(N, BLOCK_K)):
        k_base = kk * BLOCK_K

        # compute ptrs
        left_ptrs = left_ptr + b*stride_l_b + h*stride_l_h + \
                    offs_i[:, None] * stride_l_i + (k_base + offs_k)[None, :] * stride_l_k

        # right block with shape (BLOCK_K, BLOCK_N)
        # pointer: b*stride_r_b + h*stride_r_h + (k_base+offs_k) * stride_r_k + offs_j[None,:] * stride_r_i?
        # Wait stride_r_i corresponds to second dim (j). In right shape: (B,N,N,H), so second dim = j, third dim = k.

        # For right we want j index as second dimension (like i) and k as third dimension (like k). So right stride_i = stride_r_i (for dim1), right stride_k = stride_r_k (for dim2).         right_ptrs = right_ptr + b*stride_r_b + h*stride_r_h + \
                    (k_base + offs_k)[:, None] * stride_r_k + offs_j[None, :] * stride_r_i

        # Load left & right with mask
        left = tl.load(left_ptrs, mask=mask_i[:, None] & (k_base + offs_k < N), other=0.0)

"""
TriMul (outgoing) forward pass with Triton acceleration.

The heavy part of TriMul is the einsum:
    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]

For each batch and hidden dimension `d` this is a matrix multiplication:
    left_slice  = left[b,:, :, d]   shape (N, N)
    right_slice = right[b,:, :, d]  shape (N, N)
    out_slice   = left_slice @ right_slice.T  shape (N, N)

We compute all these batched GEMMs in a single Triton kernel.
All other operations (LayerNorm, Linear projections, gating, final
normalization and linear) are performed with PyTorch for simplicity.
The kernel works on contiguous tensors of shape [B, N, N, H] and
processes each (batch, hidden) pair as an independent program.
"""
import torch
import triton
import triton.language as tl

@triton.jit
def tri_mul_gemm_kernel(
    left_ptr, right_ptr, out_ptr,
    N, H, B,
    stride_l_b, stride_l_i, stride_l_k, stride_l_h,
    stride_r_b, stride_r_i, stride_r_k, stride_r_h,
    stride_o_b, stride_o_i, stride_o_j, stride_o_h,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr
):
    pid_m = tl.program_id(0)          # row block of output (i)
    pid_n = tl.program_id(1)          # col block of output (j)
    pid_z = tl.program_id(2)          # combined batch*head index

    # decode batch and hidden dimension from pid_z
    b = pid_z // H
    h = pid_z % H

    # offsets inside the output tile
    offs_i = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_j = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)
    mask_i = offs_i < N
    mask_j = offs_j < N

    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # loop over K dimension in blocks
    for kk in range(0, tl.cdiv(N, BLOCK_K)):
        k_base = kk * BLOCK_K
        k_offset = k_base + tl.arange(0, BLOCK_K)
        mask_k = k_offset < N

        # ----- left block (M x K) -----
        left_ptrs = left_ptr \
            + b * stride_l_b + h * stride_l_h \
            + offs_i[:, None] * stride_l_i \
            + k_offset[None, :] * stride_l_k
        left = tl.load(left_ptrs,
                       mask=mask_i[:, None] & mask_k[None, :],
                       other=0.0)

        # ----- right block (K x N) -----
        # we load it transposed so that we can use tl.dot directly
        right_ptrs = right_ptr \
            + b * stride_r_b + h * stride_r_h \
            + k_offset[:, None] * stride_r_k \
            + offs_j[None, :] * stride_r_i
        right = tl.load(right_ptrs,
                        mask=mask_k[:, None] & mask_j[None, :],
                        other=0.0)

        # accumulate product
        acc += tl.dot(left, right)   # (M,K) @ (K,N) -> (M,N)

    # store the result
    out_ptrs = out_ptr \
        + b * stride_o_b + h * stride_o_h \
        + offs_i[:, None] * stride_o_i \
        + offs_j[None, :] * stride_o_j
    tl.store(out_ptrs, acc, mask=mask_i[:, None] & mask_j[None, :])


def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Args:
        data: Tuple (input_tensor, mask, weights, config)
            input_tensor : torch.Tensor [B, N, N, C] (float32)
            mask         : torch.Tensor [B, N, N] (float32, 0/1)
            weights      : dict of torch.Tensor containing all linear/ln weights and biases
            config       : dict with keys "dim", "hidden_dim", "nomask" (bool)

    Returns:
        torch.Tensor of shape [B, N, N, C] (float32)
    """
    # unpack
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    eps = 1e-5

    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    nomask = config.get("nomask", False)

    # ---------- LayerNorm on input ----------
    norm_weight = weights["norm.weight"]
    norm_bias = weights["norm.bias"]
    x = torch.nn.functional.layer_norm(
        input_tensor, (dim,), weight=norm_weight, bias=norm_bias, eps=eps
    )   # [B, N, N, C]

    # ---------- Linear projections ----------
    left_proj_weight = weights["left_proj.weight"]
    right_proj_weight = weights["right_proj.weight"]
    left = torch.nn.functional.linear(x, left_proj_weight)   # [B, N, N, H]
    right = torch.nn.functional.linear(x, right_proj_weight)

    # ---------- Mask ----------
    if not nomask:
        # mask assumed to be broadcastable 0/1
        mask = mask.to(x.dtype).unsqueeze(-1)  # [B, N, N, 1]
        left = left * mask
        right = right * mask

    # ---------- Gating ----------
    left_gate_weight = weights["left_gate.weight"]
    right_gate_weight = weights["right_gate.weight"]
    out_gate_weight = weights["out_gate.weight"]
    left_gate = torch.nn.functional.linear(x, left_gate_weight).sigmoid()
    right_gate = torch.nn.functional.linear(x, right_gate_weight).sigmoid()
    out_gate = torch.nn.functional.linear(x, out_gate_weight).sigmoid()
    left = left * left_gate
    right = right * right_gate

    # ---------- Core tri-mul (batch * hidden) GEMMs ----------
    B, N, _, _ = left.shape
    out = torch.empty((B, N, N, hidden_dim), dtype=left.dtype, device=device)

    # strides (in elements) for the contiguous layout [B,N,N,H]
    s_l_b, s_l_i, s_l_k, s_l_h = left.stride()
    s_r_b, s_r_i, s_r_k, s_r_h = right.stride()
    s_o_b, s_o_i, s_o_j, s_o_h = out.stride()

    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 64

    grid = (
        triton.cdiv(N, BLOCK_M),
        triton.cdiv(N, BLOCK_N),
        B * hidden_dim,
    )
    tri_mul_gemm_kernel[grid](
        left, right, out,
        N, hidden_dim, B,
        s_l_b, s_l_i, s_l_k, s_l_h,
        s_r_b, s_r_i, s_r_k, s_r_h,
        s_o_b, s_o_i, s_o_j, s_o_h,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # ---------- Output LayerNorm ----------
    to_out_norm_weight = weights["to_out_norm.weight"]
    to_out_norm_bias = weights["to_out_norm.bias"]
    out = torch.nn.functional.layer_norm(
        out, (hidden_dim,), weight=to_out_norm_weight,
        bias=to_out_norm_bias, eps=eps
    )

    # ---------- Apply out gate ----------
    out = out * out_gate

    # ---------- Final linear ----------
    to_out_weight = weights["to_out.weight"]
    out = torch.nn.functional.linear(out, to_out_weight)   # [B, N, N, C]

    return out
