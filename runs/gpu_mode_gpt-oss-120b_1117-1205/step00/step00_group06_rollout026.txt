The original reference works with float32. We can use float16 for intermediate to improve performance; the final output conversion to float32.

The key operation: out = einsum('... i k d, ... j k d -> ... i j d', left, right). left shape: [B, N, N, H], right shape same. This results in shape [B, N, N, H] where H = hidden_dim. Actually after linear projections we have shape [B,N,N,hidden_dim]. The einsum sums over k (the third dimension). Equivalent to performing matrix multiplication over N dimension: for each batch b and hidden d, multiply Left_{i,k} (size N x N) and Right_{j,k} (size N x N) but the sum is over k. Wait dimension of left: [B,N,N,H] => left[b,i,k,d]; right[b,j,k,d]. Compute out[b,i,j,d] = sum_k left[b,i,k,d] * right[b,j,k,d].

If we fix b and d, we have left matrix L_d = left[b,:, :, d] of shape (N,N) but where the second axis is k, but the shape is (i,k). Similarly, right matrix R_d = right[b,:, :, d] shape (j,k). Sum over k via dot product of row i of left and row j of right: out[i,j] = L_d[i,:] dot R_d[j,:] (dot product across k). That's exactly the matrix multiplication of L_d (N x N) and R_d^T? Actually, if we think of R_d as shape (N,N) with rows indexed by j and columns by k, the dot product sum over k is:

L_d (i, k) * R_d (j, k) summed over k.

If we treat L_d as (N x N) and R_d as (N x N) but using the same axis k to contract, this is not a standard matrix multiplication (which would contract L's columns with R's rows: L[i,k] * R[k,j]). Here R's second dimension is also k, but its first dimension is j. So we can think of R_d as a matrix where entries are accessed by (j,k). The contraction sum over k is like (L_d) * (R_d)^T if we do L * R^T? Actually R^T would have shape (N,N) with R_T[k,j] = R[j,k]; then sum over k: L[i,k] * R_T[k,j] = sum_k L[i,k] * R[j,k]; which matches our out[i,j] definition. So out = L * R^T. So the operation can be implemented as a batch matrix multiplication on the hidden dimension.

Thus we can compute out[b,:, :, d] = left_d @ right_d.transpose(-2, -1). That's an inner product across the k dimension, but we need to compute this for each hidden dimension channel. So for each hidden dimension channel d, we have a matrix multiply of shape (N,N) x (N,N). Since hidden_dim may be up to 384, but typical hidden_dim is 128. So we have to compute many matrix multiplications.

Hence we can restructure as: left (shape B,N,N,H) -> we permute to (B,H,N,N) and right similarly -> (B,H,N,N). Then out = batched_matmul(left, right_transpose). A batch matmul with shape (B*H, N, N) * (B*H, N, N) -> (B*H, N, N). For each group, we multiply left[b,d] (N,N) with right[b,d].transpose(-2,-1) i.e., right_T: shape (B*H,N,N). So we only need to compute N N matrix multiplication for each (b,d). This is the usual GEMM: (N x N) * (N x N) -> (N x N). So per (b,d) we have O(N^3) compute; overall O(B*H*N^3). That is exactly the operation.

Thus we can implement this via a tiled GEMM using Triton which will be able to compute each per-channel multiplication quickly. This seems like the correct efficient approach: Perform batched GEMM on per-channel slices.

def triton_matmul_kernel(
    A_ptr, B_ptr, C_ptr,
    M, N, K,
    stride_am, stride_ak, stride_bk, stride_bn, stride_cm, stride_cn,

import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict

def custom_kernel(data):
    input_tensor, mask, weights, config = data
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    nomask = config.get("nomask", False)
    device = input_tensor.device
    dtype = input_tensor.dtype  # likely float32

    # LayerNorm: using weight and bias
    norm_weight = weights["norm.weight"]
    norm_bias = weights["norm.bias"]
    x = F.layer_norm(input_tensor, (dim,), weight=norm_weight, bias=norm_bias)

    # linear projections
    left_proj_weight = weights["left_proj.weight"]
    right_proj_weight = weights["right_proj.weight"]
    left = F.linear(x, left_proj_weight)   # shape B,N,N,hidden
    right = F.linear(x, right_proj_weight)

    # mask
    if mask is not None:
        mask_ = mask.unsqueeze(-1).to(x.dtype)  # broadcast
        left = left * mask_
        right = right * mask_
    # else no mask

    # gates
    left_gate_weight = weights["left_gate.weight"]
    right_gate_weight = weights["right_gate.weight"]
    out_gate_weight = weights["out_gate.weight"]
    left_gate = torch.sigmoid(F.linear(x, left_gate_weight))
    right_gate = torch.sigmoid(F.linear(x, right_gate_weight))
    out_gate = torch.sigmoid(F.linear(x, out_gate_weight))

    left = left * left_gate
    right = right * right_gate

    # TriMul via Triton gemm
    # Convert left and right to fp16 for speed.
    left_fp16 = left.to(torch.float16)
    right_fp16 = right.to(torch.float16)

    B, N, _, H = left_fp16.shape
    # Permute for batch GEMM
    left_perm = left_fp16.permute(0, 3, 1, 2).contiguous()   # (B, H, N, N)
    right_perm = right_fp16.permute(0, 3, 1, 2).contiguous()
    # Transpose right on last two dims
    right_t = right_perm.transpose(-2, -1).contiguous()    # (B, H, N, N)

    # Flatten batch*hidden
    BH = B * H

        B_ptr=B_.data_ptr(),
        C_ptr=out_fp16.data_ptr(),
        M=N,
        N=N,
        K=N,
        stride_Ab=stride_A_batch,
        stride_A_M=stride_A_m,
        stride_A_K=stride_A_k,
        stride_Bb=stride_B_batch,
        stride_B_K=stride_B_k,
        stride_B_N=stride_B_n,
        stride_Cb=stride_C_batch,
        stride_C_M=stride_C_m,
        stride_C_N=stride_C_n,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # reshape back
    out_perm = out_fp16.view(B, H, N, N).permute(0, 2, 3, 1).contiguous()
    out = out_perm.to(torch.float32)  # convert to fp32 for following ops

    # output layernorm
    to_out_norm_weight = weights["to_out_norm.weight"]
    to_out_norm_bias = weights["to_out_norm.bias"]
    out = F.layer_norm(out, (hidden_dim,), weight=to_out_norm_weight, bias=to_out_norm_bias)

    # multiply by out_gate
    out = out * out_gate

    # final linear
    to_out_weight = weights["to_out.weight"]
    output = F.linear(out, to_out_weight)  # shape [B,N,N,dim]

    return output

"""TriMul (outgoing) implementation with Triton acceleration.

The core operation computes for each batch b, head d:
    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
which is equivalent to a batch of matrix multiplications:
    left_perm[b,d]  @  right_perm[b,d].T
We perform those GEMMs with a tiled Triton kernel for speed,
while the rest of the pipeline (LayerNorms, projections, gates) stays in PyTorch.
"""
import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict

@triton.jit
def triton_matmul_kernel(
    A_ptr, B_ptr, C_ptr,
    M, N, K,
    stride_Ab, stride_A_M, stride_A_K,
    stride_Bb, stride_B_K, stride_B_N,
    stride_Cb, stride_C_M, stride_C_N,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr
):
    # program ids
    pid_b = tl.program_id(2)          # batch*head index
    pid_m = tl.program_id(0)          # block row (i)
    pid_n = tl.program_id(1)          # block col (j)

    # offsets within the block
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # base pointers for this matrix
    a_batch = A_ptr + pid_b * stride_Ab
    b_batch = B_ptr + pid_b * stride_Bb
    c_batch = C_ptr + pid_b * stride_Cb

    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # iterate over k dimension
    for kk in range(0, tl.cdiv(K, BLOCK_K)):
        k_offset = kk * BLOCK_K
        offs_k = k_offset + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        # load blocks of A and B
        a = tl.load(
            a_batch + offs_m[:, None] * stride_A_M + offs_k[None, :] * stride_A_K,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0
        )
        b = tl.load(
            b_batch + offs_k[:, None] * stride_B_K + offs_n[None, :] * stride_B_N,
            mask=mask_k[:, None] & mask_n[None, :],
            other=0.0
        )
        # accumulate
        acc += tl.dot(a, b)

    # write result
    c_ptrs = c_batch + offs_m[:, None] * stride_C_M + offs_n[None, :] * stride_C_N
    tl.store(c_ptrs, acc.to(tl.float16), mask=mask_m[:, None] & mask_n[None, :])

def custom_kernel(data: Tuple[torch.Tensor, torch.Tensor, Dict[str, torch.Tensor], Dict]) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul operator.
    Arguments:
        data: (input, mask, weights, config)
    Returns:
        Tensor of shape [bs, seq_len, seq_len, dim] (float32)
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dtype = input_tensor.dtype

    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    # -----------------------------------------------------------------
    # LayerNorm on input
    norm_weight = weights["norm.weight"]
    norm_bias = weights["norm.bias"]
    x = F.layer_norm(input_tensor, (dim,), weight=norm_weight, bias=norm_bias)

    # Linear projections
    left = F.linear(x, weights["left_proj.weight"])   # [B,N,N,hidden_dim]
    right = F.linear(x, weights["right_proj.weight"])

    # Apply mask if present
    if mask is not None:
        m = mask.unsqueeze(-1).to(x.dtype)          # [B,N,N,1]
        left = left * m
        right = right * m

    # Gating
    left_gate = torch.sigmoid(F.linear(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"]))
    out_gate = torch.sigmoid(F.linear(x, weights["out_gate.weight"]))

    left = left * left_gate
    right = right * right_gate

    # -----------------------------------------------------------------
    # Convert to fp16 for the heavy O(N^3) contraction
    left = left.to(torch.float16)
    right = right.to(torch.float16)

    B, N, _, H = left.shape  # H == hidden_dim
    # Rearrange to (B, H, N, N) and make contiguous
    left_perm = left.permute(0, 3, 1, 2).contiguous()   # [B, H, N, N]
    right_perm = right.permute(0, 3, 1, 2).contiguous()
    # Transpose right on the last two axes (i.e., take the K dimension as rows)
    right_t = right_perm.transpose(-2, -1).contiguous()  # [B, H, N, N]

    # Flatten batch*head dimension
    BH = B * H
    A = left_perm.view(BH, N, N)          # [BH, N, N]
    B_ = right_t.view(BH, N, N)           # [BH, N, N]

    # Output placeholder
    C = torch.empty_like(A, dtype=torch.float16, device=device)

    # Strides (in elements)
    stride_Ab = A.stride(0)
    stride_A_M = A.stride(1)
    stride_A_K = A.stride(2)

    stride_Bb = B_.stride(0)
    stride_B_K = B_.stride(1)
    stride_B_N = B_.stride(2)

    stride_Cb = C.stride(0)
    stride_C_M = C.stride(1)
    stride_C_N = C.stride(2)

    # Blocking parameters (tuned for typical sizes)
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 64

    grid = (
        triton.cdiv(N, BLOCK_M),   # rows
        triton.cdiv(N, BLOCK_N),   # cols
        BH                         # one program per matrix
    )
    triton_matmul_kernel[grid](
        A_ptr=A.data_ptr(),
        B_ptr=B_.data_ptr(),
        C_ptr=C.data_ptr(),
        M=N,
        N=N,
        K=N,
        stride_Ab=stride_Ab,
        stride_A_M=stride_A_M,
        stride_A_K=stride_A_K,
        stride_Bb=stride_Bb,
        stride_B_K=stride_B_K,
        stride_B_N=stride_B_N,
        stride_Cb=stride_Cb,
        stride_C_M=stride_C_M,
        stride_C_N=stride_C_N,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # Reshape back to [B, N, N, hidden_dim]
    out = C.view(B, H, N, N).permute(0, 2, 3, 1).contiguous().to(torch.float32)

    # -----------------------------------------------------------------
    # Output LayerNorm, gating and final linear
    out = F.layer_norm(
        out,
        (hidden_dim,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"]
    )
    out = out * out_gate
    output = F.linear(out, weights["to_out.weight"])

    return output
