# Approach and Rationale

The TriangleMultiplicativeUpdate (TriMul) operator, used in protein structure prediction models like AlphaFold, performs a constrained pairwise multiplicative update. Its complexity (O(N^3)) arises from the nested loops iterating over potentially all indices. We tackle this by:

- Using `tlcsrnf` to manage state without gradients, enabling optimizations like kernel fusion.
- Mapping parameters to tensors using `torch.compile.setup`.
- Applying a cache-oblivious tiled k loop to automatically block access patterns.
- Optimizing dot product via parallel casting to avoid prolonged L2 access.

This scalable approach adapts to various tensor feature dimensions (dim) and hidden dimensions (hidden_dim), crucial for handling large protein sequences effectively.

# Mathematical Specification

## Variables and Dimensions
- **`x`**: Input tensor of shape [B, N, N, C]
- **`mask`**: Mask tensor of shape [B, N, N]
- **`left_proj`**: Projection linear map in `weight['left_proj.weight']`
- **`right_proj`**: Projection linear map in `weight['right_proj.weight']`
- **`left_gate`**: Gate linear map in `weight['left_gate.weight']`
- **`right_gate`**: Gate linear map in `weight['right_gate.weight']`
- **`out_gate`**: Output gate linear map in `weight['out_gate.weight']`
- **`to_out_norm`**: LayerNorm parameters in `weight['to_out_norm.weight']` and bias
- **`to_out`**: Final projection in `weight['to_out.weight']`

All operations are defined on the same device.

## Operations Sequence

1. **`norm`**: Apply LayerNorm along feature dimension `C`.
2. **`left_proj`**: Project input via linear transformation, shape changes from `[B,N,N,C]` to `[B,N,N,H]`.
3. **`right_proj`**: As above.
4. **`left_gate`**: Apply sigmoid to projection output and element-wise multiply.
5. **`right_gate`**: Same as above.
6. **`to_out`**: Final projection back to original dimension.
7. **`mask`**: Element-wise multiplication with mask, preprocessed by unsqueezing.
8. **`out`**: Compute contracted representation via einsum.

- vectorized loads versus scalars
