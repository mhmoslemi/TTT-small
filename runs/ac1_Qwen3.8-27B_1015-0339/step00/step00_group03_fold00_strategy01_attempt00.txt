The solution uses iterating blocks and edges perturbation to minimize the AC1 upper bound. The central idea is to represent sequences as linear combinations of sines and cosines (Fourier series) whose coefficients are optimized via dynamic programming. This converts the discrete non-convex optimization into a continuous convex problem in the Fourier domain. The algorithm keeps track of both forward and inverse Fourier transformations to guide the search efficiently.

#### 1. Approach and Rationale
The AC1 objective is defined as `2*n*max(convolve(a, a)) / sum(a)^2`. We find that for any sequence, the autocorrelation power can be bounded by its Fourier transform. The optimization problem is mapped to Fourier domain coefficients (known as basis functions), making the problem separable. By expressing coefficients as products of sine and cosine components, we can use stability properties from Parseval's theorem to derive a convex relaxation.

#### 2. Mathematical Specification
- **Variables**: Fourier coefficients `c_k` determine the sequence `a` through inverse Fourier transform: `a_i = ∑_{k} c_k * sin(2π k i / n)`, `a_i = ∑_{k} c_k * cos(2π k i / n)`.  
- **Objective**: Minimize AC1 via Fourier analysis, transformed into `(max_c_k^2) / sum(a)^2`.  
- **Constraints**: Ensured `a_i ≥ 0` via gradient projection and use `sum(a) = 1` for normalization by Parseval's theorem.  
- **Optimization**: Gradient descent using first derivatives and a momentum factor for smoother convergence.  
- **Output**: Best found sequence is returned via inverse Fourier transform with clipping.
