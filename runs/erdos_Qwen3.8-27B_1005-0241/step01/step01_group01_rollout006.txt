```python
    # Simple projection: adjust elements

            diff -= adj
```

```python
            grad[lo1:hi1] += ws * (1.0 - h[lo1+s:hi1+s])

        lo2 = max(0, s)
        hi2 = min(n, n + s)
        if lo2 < hi2:
            grad[lo2:hi2] -= ws * h[lo2-s:hi2-s]
    
    return grad
```

Actually, let me think about this more carefully. The move "change h[j] by δ and h[m] by -δ" changes the correlation by:
Δ corr = δ * (coefs[j] - coefs[m])

The new C₅ = max(corr + δ * (coefs[j] - coefs[m])) * dx

To find the best δ for a given (j, m) pair, I can solve:
minimize max_k [corr[k] + δ * (coefs[j,k] - coefs[m,k])]

subject to 0 ≤ h[j]+δ ≤ 1 and 0 ≤ h[m]-δ ≤ 1

This is a 1D problem! The objective is a convex piecewise-linear function of δ. I can find the minimum by checking the breakpoints (where two components of the max are equal).

For a given (j, m), let d = coefs[j] - coefs[m] (a vector of length 2n-1).
f(δ) = max_k [corr[k] + δ * d[k]]

The breakpoints occur where corr[k1] + δ*d[k1] = corr[k2] + δ*d[k2], i.e., δ = (corr[k2] - corr[k1]) / (d[k1] - d[k2]).

There are O((2n-1)²) breakpoints, but in practice the maximum is only active at a few components. I can use a simpler approach: binary search or ternary search on δ.

Actually, since f is convex in δ (max of linear functions), I can use:

- Try δ in a set of candidates: {-0.5, -0.3, -0.2, -0.1, 0.1, 0.2, 0.3, 0.5} clipped to feasible range
- Pick the best
