OK so the problem is non-trivial. The block pattern is bad. We need a more distributed pattern.

What about an alternating pattern? h = [1,0,1,0,...] (n/2 ones and n/2 zeros alternating).
For s=1: c = sum h[i]*(1-h[i+1]). Since h alternates, h[i+1] = 1-h[i]. So h[i]*(1-h[i+1]) = h[i]*h[i] = h[i]² = h[i] (binary). Sum = n/2.
C₅ ≥ (n/2)*(2/n) = 1. Bad.

For s=2: c = sum h[i]*(1-h[i+2]) = sum h[i]*h[i] = n/2. Same.

So alternating is also bad.

The optimal solution needs to be more nuanced. Maybe a "distributed" pattern where no shift gives lots of overlap.

This is related to the concept of "balanced sequences" or "zero-auto-correlation sequences" in coding theory, but with the specific structure of h*(1-h) rather than h*h.

I think the key is: we want to minimize max_s [sum_i h[i]*(1-h[i+s])]. This is the maximum cross-correlation between h and (1-h).

One approach: if h[i] + h[i+s] ≈ 1 for all i and all s (that's impossible for all s), but we can try to make the cross-correlation uniform.

Actually, if h[i] = 1/2 for all i, then h*(1-h) = 1/4 for all i, and the correlation at shift s is (n-|s|)/4. The max is at s=0: n/4. C₅ = (n/4)*(2/n) = 1/2.

We can do better than 1/2 by making h non-uniform. The question is how.

Let me think about it differently. Let's define f = h - 1/2. Then h = 1/2 + f, 1-h = 1/2 - f.
h*(1-h) = (1/2+f)(1/2-f) = 1/4 - f².

So c_s = sum_{valid i} (1/4 - f[i]²) = (n-|s|)/4 - sum_{valid i} f[i]².

And C₅ = max_s [(n-|s|)/4 - sum_{valid i} f[i]²] * dx.

For s=0: (n/4 - sum f[i]²) * dx = (n/4 - ||f||²) * 2/n = 1/2 - 2||f||²/n.

To minimize the s=0 term, we want to maximize ||f||², i.e., make f as large as possible (h as close to 0 or 1 as possible).

But we also need sum f[i] = 0 (since sum h = n/2).

For s≠0: (n-|s|)/4 - sum_{valid i} f[i]².

The term (n-|s|)/4 decreases with |s|, but the subtracted term also changes.

This is a tradeoff: make f large in magnitude (binary h) to reduce the s=0 term, but arrange f so that the s≠0 terms are also small.

For a "random" f with mean 0 and f[i] ∈ [-1/2, 1/2], the cross-correlation terms have mean (n-|s|)/4 and variance that decreases with n. For large n, the max over s of the random fluctuations might be small.

But we can do better with structured f.

I think a good strategy is:
1. Start with the initial_h_values
2. Use gradient-based optimization (ADAM)
3. Add local search / coordinate descent
4. Try multiple restarts with different random perturbations
