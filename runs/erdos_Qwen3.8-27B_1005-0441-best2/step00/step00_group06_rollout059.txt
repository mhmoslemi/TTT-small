- C₅ = max_k (np.correlate(h, 1-h, mode="full") * dx)

The evaluation uses np.correlate(h, 1-h, mode="full") * dx and takes the max.

Key observations:

- We want to minimize max_k overlap_k

- Or use a smooth approximation: log-sum-exp of overlaps
- Or iterate: at each step, identify the worst overlap and try to reduce it

Let me think about the gradient of overlap_k with respect to h:
overlap_k = sum_i h[i] * (1 - h[i+k])
= sum_i h[i] - sum_i h[i] * h[i+k]

For a fixed shift k, the derivative w.r.t. h[j] is:
∂overlap_k/∂h[j] = 1 - h[j+k] - h[j-k] (where j+k and j-k are within bounds)

Wait, let me be more careful. The correlation:
np.correlate(h, 1-h, mode="full") computes:
c[m] = sum_i h[i] * (1-h)[i + m - (n-1)] depending on convention.

Actually, np.correlate(a, v, mode="full") computes:
c[k] = sum_i a[i+k] * v[i] for k = -(len(v)-1), ..., len(a)-1

So for a = h, v = 1-h:
c[k] = sum_i h[i+k] * (1-h[i])

where the sum is over valid i, i.e., 0 ≤ i < n and 0 ≤ i+k < n.

So c[k] = sum_{i=max(0,-k)}^{min(n-1, n-1-k)} h[i+k] * (1-h[i])

The gradient of c[k] w.r.t. h[j]:
- h[j] appears in c[k] when j = i+k (i.e., i = j-k) and when j = i (i.e., i = j)
- From the first term (h[i+k]): contributes (1-h[i]) = (1-h[j-k]) when i+k=j
- From the second term (1-h[i]): contributes -h[i+k] = -h[j+k] when i=j

So ∂c[k]/∂h[j] = (1-h[j-k]) - h[j+k] (with appropriate boundary handling, terms that go out of range are 0)

For the smooth approximation:
f(h) = (1/s) * log(sum_k exp(s * c[k] * dx))

This approximates max_k c[k] * dx as s → ∞.

The gradient of f w.r.t. h[j] is:
∂f/∂h[j] = (1/s) * (sum_k s * dx * exp(s * c[k] * dx) * ∂c[k]/∂h[j]) / sum_k exp(s*c[k]*dx)
= dx * sum_k w_k * ∂c[k]/∂h[j]

where w_k = exp(s*c[k]*dx) / sum_j exp(s*c[j]*dx)

This is a weighted average of the individual gradients, weighted by how "close to the max" each overlap is.

For projected gradient descent:
1. Compute gradient of smooth max approximation
2. Take a step: h_new = h - lr * grad
3. Project onto constraints: 0 ≤ h ≤ 1, sum(h) = n/2

The projection onto {h : 0 ≤ h ≤ 1, sum(h) = n/2} can be done via:
- This is a projection onto the intersection of a box and a hyperplane
- Can be solved by finding λ such that sum(clamp(h - lr*grad - λ, 0, 1)) = n/2

```python
import numpy as np

def project_to_box_sum(y, target_sum):
    """Project y onto {x: 0<=x<=1, sum(x)=target_sum}."""
    n = len(y)
    # Bisection on lambda
    lo = y.min() - 1
    hi = y.max()
    for _ in range(100):
        mid = (lo + hi) / 2
        x = np.clip(y - mid, 0, 1)
        s = x.sum()
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(y - (lo + hi) / 2, 0, 1)

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    overlaps = np.correlate(h, 1 - h, mode="full")
    return np.max(overlaps) * dx

def run(seed=42, budget_s=1100, **kwargs):
    import time
    start_time = time.time()
    
    np.random.seed(seed)
    
    # Get initial values
    if 'initial_h_values' in globals() and initial_h_values is not None:
        n = len(initial_h_values)
        h = np.array(initial_h_values, dtype=float)
    else:
        n = 95
        # Create a symmetric initial guess
        h = np.zeros(n)
        center = n // 2
        width = n // 2  # need sum = n/2
        h[center - width//2:center + width//2] = 1
        h = h / h.sum() * n / 2
    
    dx = 2.0 / n
    best_h = h.copy()
    best_c5 = compute_c5(h)
    
    # Smooth max parameter
    s = 50  # temperature
    lr = 0.01
    patience = 0
    max_patience = 200
    
    for iteration in range(10000):
        if time.time() - start_time > budget_s - 30:
            break
        
        # Compute overlaps
        overlaps = np.correlate(h, 1 - h, mode="full")
        current_c5 = np.max(overlaps) * dx
        
        if current_c5 < best_c5:
            best_c5 = current_c5
            best_h = h.copy()
            patience = 0
        else:
            patience += 1
        
        if patience > max_patience:
            # Reduce learning rate or break
            lr *= 0.5
            patience = 0
            if lr < 1e-6:
                break
        
        # Compute weights for smooth max
        svals = s * overlaps * dx
        svals -= np.max(svals)  # for numerical stability
        weights = np.exp(svals)
        weights /= np.sum(weights)
        
        # Compute gradient
        grad = np.zeros(n)
        for m in range(len(overlaps)):
            k = m - (n - 1)
            w = weights[m]
            if w < 1e-12:
                continue
            i_lo = max(0, -k)
            i_hi = min(n, n - k)
            for i in range(i_lo, i_hi):
                j1 = i + k
                j2 = i
                grad[j1] += w * (1 - h[i])
                grad[j2] -= w * h[i + k]
        grad *= dx
        
        # Gradient descent step
        h_new = h - lr * grad
        
        # Project onto constraints
        h_new = project_to_box_sum(h_new, n / 2)
        
        h = h_new
        
        # Adaptively adjust s
        if iteration % 100 == 0 and iteration > 0:
            s = min(s * 1.5, 500)
        
        # Adaptively adjust lr
        if iteration % 50 == 0:
            # Simple backtracking: if c5 didn't improve in last 50 iters, reduce lr
            pass
    
    return best_h, best_c5, n
```

```python
import numpy as np
import time

def project_box_sum(y, target_sum):
    """Project y onto {x: 0<=x_i<=1, sum(x)=target_sum}."""
    f = y.min() - 1.5
    t = y.max() + 1.5
    for _ in range(80):
        m = (f + t) * 0.5
        if np.clip(y - m, 0.0, 1.0).sum() > target_sum:
            f = m
        else:
            t = m
    return np.clip(y - (f + t) * 0.5, 0.0, 1.0)

def get_overlaps(h):
    return np.correlate(h, 1.0 - h, mode="full")

def get_c5(h):
    return float(np.max(get_overlaps(h)) * (2.0 / len(h)))

def get_grad(h, s):
    """Gradient of smooth-max of (overlaps*dx) w.r.t. h."""
    n = len(h)
    dx = 2.0 / n
    ov = get_overlaps(h)
    v = s * ov * dx
    v = v - v.max()
    e = np.exp(v)
    w = e / e.sum()
    jj = np.arange(n)[:, None]
    uu = np.arange(n)[None, :]
    A = w[jj - uu + n - 1]
    return dx * (A @ (1.0 - h) - A.T @ h)

    s = s0
    lr = lr0
    mom = mom0
    h_prev = h.copy()
    best_local = h.copy()
    best_c5 = get_c5(h)
    h_cur = h.copy()
    staggered = 0

        h_c = project_box_sum(h_cur + mom * (h_cur - h_prev), target)
        g = get_grad(h_c, s)

        h_cur = h_new

                staggered = 0

            lr *= 0.75

        res, c5 = optimize_phase(best_h, target, s0=200.0, lr0=0.03, mom0=0.2,
                                  max_iters=30000, time_limit=lim3,
                                  s_max=600.0, lr_min=0.0005, check_every=100)
        if c5 < best_c5:
            best_c5 = c5
            best_h = res

    # Phase 4: small random perturbations
    if time.time() < t0 + budget_s - 30:
        for _ in range(30):
            if time.time() > t0 + budget_s - 30:
                break
            scale = 0.005
            pert = np.random.randn(n) * scale
            hp = project_box_sum(best_h + pert, target)
            c5p = get_c5(hp)
            if c5p < best_c5:
                best_c5 = c5p
                best_h = hp

    # Final verify
    best_c5 = get_c5(best_h)
    return best_h, best_c5, n
```
