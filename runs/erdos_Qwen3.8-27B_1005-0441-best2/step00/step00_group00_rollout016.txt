    # For each shift s = -(n-1), ..., n-1:
    # ∂f_k/∂h[j] = (1-h[j-s])*1{0≤j-s≤n-1} - h[j+s]*1{0≤j+s≤n-1}

        idx = s + (n-1)
        w = weights[idx]
        if w < 1e-14:
            continue
        if s >= 0:
            # grad[s:] += w*(1-h[:n-s])
            # grad[:n-s] -= w*h[s:]
            grad[s:] += w * (1.0 - h[:n-s])
            grad[:n-s] -= w * h[s:]
        else:
            p = -s
            # grad[:n-p] += w*(1-h[p:])
            # grad[p:] -= w*h[:n-p]
            grad[:n-p] += w * (1.0 - h[p:])
            grad[p:] -= w * h[:n-p]
    grad *= dx
    # Penalty gradient
    grad += 2 * penalty_weight * (np.sum(h) - n / 2.0) * np.ones(n)
    return grad

For shift 0: corr_0 = Σ_i h[i](1-h[i]) which for binary is 0. So shift 0 never contributes to the max for binary solutions. Good.

For shift k (1≤k≤n-1): corr_k = Σ_{i=0}^{n-1-k} h[i+k]*(1-h[i]) (one direction)
And for shift -k: corr_{-k} = Σ_{i=0}^{n-1-k} h[i]*
