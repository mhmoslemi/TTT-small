C[k] = sum_{i} h[i+k] * (1-h[i]) where the sum is over valid i.

The shift for index k is s = k - (n-1), ranging from -(n-1) to (n-1).

dC[k]/dh[m] = (1-h[m-s]) * [0≤m-s<n] - h[m+s] * [0≤m+s<n]

where s = k-(n-1).

So dC[k]/dh[m]:
- First term: 1-h[m-k+n-1], valid when 0 ≤ m-k+n-1 < n, i.e., k-n+1 ≤ m ≤ k

def compute_c5(h, dx):
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr)) * dx


def smooth_obj_and_grad(h, dx, tau):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full") * dx
    m = np.max(corr)
    e = np.exp((corr - m) * tau)
    se = np.sum(e)
    obj = m + np.log(se) / tau
    w = e / se
    shifts = np.arange(2 * n - 1) - (n - 1)
    grad = np.zeros(n)
    for mi in range(n):
        g = 0.0
        for ki in range(len(shifts)):
            s = shifts[ki]
            t1 = 0.0
            if 0 <= mi - s < n:
                t1 = 1.0 - h[mi - s]
            t2 = 0.0
            if 0 <= mi + s < n:
                t2 = -h[mi + s]
            g += w[ki] * (t1 + t2)
        grad[mi] = g * dx
    return obj, grad
