Wait, that's not standard correlation. Let me look at the numpy docs more carefully.

From numpy docs: 
correlate([a0, a1, a2], [v0, v1, v2]) = 
v0*a0, v0*a1 + v1*a0, v0*a2 + v1*a1 + v2*a0, v1*a2 + v2*a1, v2*a2

So:
c[0] = v0*a0
c[1] = v0*a1 + v1*a0
c[2] = v0*a2 + v1*a1 + v2*a0
c[3] = v1*a2 + v2*a1
c[4] = v2*a2

So c[k] = sum_j v[j] * a[j + k - (n_v - 1)]

For our case: c[k] = sum_j (1-h)[j] * h[j + k - (n-1)]

Let lag = k - (n-1):
c[k] = sum_j (1-h)[j] * h[j + lag]

for j where both j and j+lag are in [0, n).

This is the cross-correlation of (1-h) and h at lag. The integral we want is:
∫ h(x)(1-h(x+k)) dx ≈ sum_j h[j] * (1-h[j+k]) * dx

This is the correlation of h and (1-h) at lag k. But what numpy gives us is the correlation of (1-h) and h at lag, which is:
sum_j (1-h)[j] * h[j+lag] = sum_j h[j+lag] * (1-h)[j]

Let i = j+lag: sum_i h[i] * (1-h)[i-lag] = sum_i h[i] * (1-h[i-lag])

This is the overlap at shift -lag, not +lag! But since we take the MAX over all lags, and the lag range is symmetric (from -(n-1) to n-1), the max is the same whether we use +lag or -lag. So it doesn't matter.

def compute_c5(h, n):
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(h, n):
    h = np.clip(h.copy(), 0.0, 1.0)
    target = n / 2.0
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        m = h < 1.0 - 1e-12 if diff > 0 else h > 1e-12
        c = m.sum()
        if c == 0:
            break
        h[m] = np.clip(h[m] + diff / c, 0.0, 1.0)
    return h

def grad_lag(h, n, lag):
    g = np.zeros(n)
    if lag >= 0:
        g[:n - lag] += 1.0 - h[lag:]
        g[lag:] -= h[:n - lag]
    else:
        L = -lag
        g[L:] += 1.0 - h[:n - L]
        g[:n - L] -= h[L:]
    return g

def phase_subgrad(h, n, t_end):
    c5 = compute_c5(h, n)
    bh, bc = h.copy(), c5
    step, stall = 0.1, 0
    while time.time() < t_end and stall < 400:

        tc = min(5, 2 * n - 1)
        ti = np.argpartition(corr, -tc)[-tc:]
        w = np.exp((corr[ti] - corr.max()) / 0.005)
        w /= w.sum()
