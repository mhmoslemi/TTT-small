The projection onto the intersection of a box [0,1]^n and a hyperplane {x: sum(x) = c} can be done by:
1. Start with the unconstrained projection onto the hyperplane: h_proj = h - ((sum(h)-c)/n) * 1
2. Then clip to [0,1], but this breaks the sum constraint
3. Use bisection: find t such that sum(clip(h - t, 0, 1)) = c

This is the standard approach. The function sum(clip(h-t, 0, 1)) is monotonically decreasing in t, so bisection works.
