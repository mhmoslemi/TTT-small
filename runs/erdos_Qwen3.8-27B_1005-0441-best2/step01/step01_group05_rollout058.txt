Let me also think about whether the problem has any special structure I'm missing.

The correlation np.correlate(h, 1-h, mode='full') for h defined on [0,2]:
- At lag 0: ∑h[i](1-h[i]) = n/2 - ∑h[i]² (by the constraint ∑h = n/2)
- At lag k>0: ∑_{i=0}^{n-1-k} h[i+k](1-h[i])
- At lag k<0: ∑_{i=0}^{n-1+k} h[i](1-h[i+k])

The lag 0 term is n/2 - ∑h². To minimize this, we want to maximize ∑h², which means making h as "peaky" as possible (close to binary). But the other lags want h to be "spread out" to reduce cross-correlation.

So there's a fundamental tension: lag 0 wants binary, other lags want spread-out.

This suggests that the optimal solution is "almost binary" but with small intermediate values to reduce the other lags.

This aligns with the strategy of starting from a good binary arrangement and relaxing.

Let me implement this:
1. Find a good binary arrangement (via local search on the discrete space)
2. Relax to continuous (small perturbations from binary)
3. Optimize the continuous solution

For step 1, the key metric for binary h is:
C₅_binary = dx * max_{k≠0} |∑ h[i+k](1-h[i])| (lag 0 is 0 for binary)

Wait, for binary h, corr[0] = ∑h[i](1-h[i]) = 0. So the max is over k≠0.

For a binary sequence with n/2 ones, the "autocorrelation" at lag k is:
A(k) = ∑ h[i]h[i+k] (number of 1-1 pairs at distance k)
And corr at lag k (one-sided): ∑ h[i+k](1-h[i]) = ∑ h[i+k] - ∑ h[i]h[i+k] = (number of 1s in the overlapping region) - A(k)

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def _corr_full(h):
    return np.correlate(h, 1.0 - h, mode="full")

def _lsse_obj(h, temp, n):
    dx = 2.0 / n
    corr = _corr_full(h)
    m = np.max(corr)
    if temp < 1e-12:
        return m * dx
    e = np.exp((corr - m) / temp)
    return (m + temp * np.log(np.sum(e))) * dx

def _lsse_grad(h, temp, n):
    dx = 2.0 / n
    corr = _corr_full(h)
    m = np.max(corr)
    if temp < 1e-12:
        idx = np.argmax(corr)
        p = np.zeros(2*n-1)
        p[idx] = 1.0
    else:
        e = np.exp((corr - m) / temp)
        p = e / np.sum(e)
    
    omh = 1.0 - h
    grad = np.zeros(n)
    
    for j in range(n):
        # First term: sum_d p[d+n-1] * omh[j-d] for valid d
        d_lo = max(0, j-n+1)
        d_hi = min(n-1, j)
        if d_lo <= d_hi:
            d = np.arange(d_lo, d_hi+1)
            grad[j] += np.dot(p[d+n-1], omh[j-d])
        # Second term: -sum_d p[d+n-1] * h[j+d] for valid d
        d_lo2 = max(-(n-1), -j)
        d_hi2 = min(n-1, n-1-j)
        if d_lo2 <= d_hi2:
            d2 = np.arange(d_lo2, d_hi2+1)
            grad[j] -= np.dot(p[d2+n-1], h[j+d2])
    
    return grad * dx

def _optimize_lbfgs(h_init, n, seed, elapsed, budget_remaining):
    """Optimize h using L-BFGS-B with LSE approximation"""
    np.random.seed(seed)
    h = h_init.copy()
    h = _project(h, n)
    best_h = h.copy()
    best_c5 = compute_c5(best_h)
    t0 = time.time()
    max_time = max(5, budget_remaining - 10)
    
    temps = [0.05, 0.02, 0.01, 0.005, 0.001, 0.0003, 0.0001]
    bounds = [(0.0, 1.0)] * n
    
    for temp in temps:
        if time.time() - t0 > max_time:
            break
        lam = 1e4  # penalty weight for sum constraint
        
        def obj(h_x):
            val = _lsse_obj(h_x, temp, n)
            s = np.sum(h_x) - n/2.0
            return val + lam * s * s
        
        def grad(h_x):
            g = _lsse_grad(h_x, temp, n)
            s = np.sum(h_x) - n/2.0
            return g + 2*lam*s*np.ones(n)
        
        try:
            res = minimize(obj, h, method='L-BFGS-B', jac=grad,
                          bounds=bounds,
                          options={'maxiter': 200, 'ftol': 1e-14, 'gtol': 1e-8})
            h_new = _project(res.x, n)
            c5_new = compute_c5(h_new)
            if c5_new < best_c5 - 1e-12:
                best_h = h_new.copy()
                best_c5 = c5_new
            h = h_new.copy()
        except Exception:
            break
    
    return best_h, best_c5

- We need x_i = clip(z_i + alpha, 0, 1) for some alpha, such that sum(x_i) = n/2
- Bisect on alpha

This is clean and efficient! Let me implement this.

The step size eta can be:
- eta_t = c / sqrt(t) (standard subgradient)
- Or adaptive: eta = 0.1 * (target_c5 - current_c5) / ||g||²

```python
def _project_sum_box(h, n):
    """Project h onto {x: sum(x)=n/2, 0<=x<=1}"""
    # Use bisection on the water level
    target = n / 2.0
    lo, hi = -1.0, 1.0
    for _ in range(60):
        mid = (lo + hi) / 2
        x = np.clip(h + mid, 0.0, 1.0)
        s = np.sum(x)
        if s > target:
            hi = mid
        else:
            lo = mid
    x = np.clip(h + (lo+hi)/2, 0.0, 1.0)
    return x
```

This is O(n) per projection (plus the 60 bisection iterations). For n=160, each projection is very fast.
