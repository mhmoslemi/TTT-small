For the projected gradient on the unsmoothed max:
- At each step, compute which k* achieves the max
- Compute gradient of C[k*] (or average over ties)
- Take gradient step, project to [0,1]^n ∩ {sum = n/2}
- Use backtracking line search

This avoids the smoothing parameter entirely.

```python
def _proj_grad_step(h, step, k_star):
    # Gradient of C[k_star]
    n = len(h)
    k = k_star
    grad = np.zeros(n)
    for m in range(n):
        jm = k - m
        if 0 <= jm < n:
            grad[m] = 1.0 - 2.0 * h[jm]
    return h - step * grad
```
