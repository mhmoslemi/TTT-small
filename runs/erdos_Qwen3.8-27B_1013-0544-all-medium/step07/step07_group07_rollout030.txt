**Vectorized binary local search:**

For the current binary h with correlation c (length 2n-1):
- Let Z = set of zero positions, O = set of one positions
- For each i in Z, compute for all j in O simultaneously:
  - The delta in correlation
  - The new max
  - Find the best j

The delta for swapping i (0→1) and j (1→0) at correlation index p (with m = p-(n-1)):
delta[p] = (1-h[i-m])*[0≤i-m<n] - h[i+m]*[0≤i+m<n] 
         - (1-h[j-m])*[0≤j-m<n] + h[j+m]*[0≤i+m<n]
         + interaction

The interaction terms are at specific indices:
- At p = (n-1)+(j-i): delta -= 1
- At p = (n-1)+(i-j): delta += 1

For the vectorized version:
- Fix i. Compute delta_i[p] for all p (this is O(n) and can be done with numpy).
- For each j in O, delta_j[p] = -(1-h[j-m])[0≤j-m<n] + h[j+m][0≤j+m<n] + interaction
  The interaction depends on j, so we can't fully vectorize over j for the delta.
  
  But we can separate: delta[p] = delta_i[p] + delta_j_base[p] + interaction_j[p]
  where delta_j_base doesn't depend on j (it's just a function of the position), and interaction_j is at 2 specific positions.

- remove_one[p] = the change in c[p] when we set a 1 at position q to 0

For adding 1 at position q:
