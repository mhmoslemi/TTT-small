Actually, I realize the thresholding approach might be too aggressive - it forces binary solutions. The optimal solution for the continuous problem might not be binary. Let me instead use a **soft thresholding** or **proportional** approach.

Alternative: Use the gradient to do a **projected gradient step** with the weighted objective, which is essentially what the subgradient method does but with better weights.

Let me go with a cleaner implementation:

**Algorithm:**
1. Start with initial h (from `initial_h_values`)
2. Iterate:
   a. Compute C = correlate(h, 1-h, 'full')
   b. Compute softmax weights: w[k] = exp(β*C[k]) / Σ exp(β*C[k])
   c. Compute weighted gradient: grad = Σ_k w[k] * ∂C_k/∂h
   d. Take projected gradient step: h_new = project(h - α*grad)
   e. Optionally: binary thresholding step (set h to 0/1 based on gradient sign, adjusted to satisfy sum constraint)
   f. Line search or accept/reject
3. Periodically run LP steps for polishing

The key improvement over the previous code:
- **Softmax weights** give much better direction than uniform active set averaging
- **Binary thresholding** explores the vertex structure of the problem
- **Faster per iteration** (no LP solve)

Let me also add a **simulated annealing** flavor: sometimes accept worse solutions to escape local optima.

    """Compute weighted gradient: sum_k w[k] * dC_k/dh"""
    grad = np.zeros(n)
    for m in range(2 * n - 1):
        wm = w[m]

        i2s = max(0, k)
        i2e = min(n, n + k)
        if i2e > i2s:
            grad[i2s:i2e] -= wm * h[i2s - k:i2e - k]
    return grad

        delta >= -h,
        delta <= 1.0 - h,

            best_h = h_try
    return best_h, best_mc

                beta = 15.0 + 40.0 * rng.rand()
                alpha = 0.02 + 0.06 * rng.rand()
                no_impr = 0
            else:
                no_impr = 150
            continue

        # Softmax weights on correlation
        c_shift = c - c.max()
        w = np.exp(beta * c_shift)
        ws = w.sum()
        if ws < 1e-30:
            w = np.ones(2 * n - 1) / (2 * n - 1)
        else:
            w /= ws

        grad = weighted_gradient(h, n, w)
        h_new = h - alpha * grad
        h_new = project_feasible(h_new, n)
        c_new = float(np.correlate(h_new, 1 - h_new, mode='full').max())
        if c_new > c_max + 0.005:
            h_new2 = h - 0.3 * alpha * grad
            h_new2 = project_feasible(h_new2, n)
            c_new2 = float(np.correlate(h_new2, 1 - h_new2, mode='full').max())
            if c_new2 <= c_max + 0.005:
                h_new = h_new2
            else:
                h_new = h
        h = h_new

    # Phase 2: LP refinement
    phase2_dl = t0 + 0.78 * total
    h = best_h.copy()
    eps = 0.03
    no_improve = 0
    while time.time() < phase2_dl:
        h_new, mc_new = lp_step(h, n, eps)
        c5_new = mc_new * 2.0 / n
        if c5_new < best_c5 - 1e-12:
            best_mc = mc_new
            best_h = h_new.copy()
            best_c5 = c5_new
            no_improve = 0
        else:
            no_improve += 1
            if no_improve > 12:
                eps *= 0.7
                if eps < 0.0015:
                    break
                no_improve = 0
        h = h_new

    # Phase 3: Try lower resolution (faster LP, different landscape)
    phase3_dl = t0 + 0.88 * total
    for nh in [200, 300, 500, 600]:
        if time.time() > phase3_dl - 20:
            break
        xo = np.linspace(0, 2, n)
        xn = np.linspace(0, 2, nh)
        hh = np.interp(xn, xo, best_h)
        hh = project_feasible(hh, nh)
        mc_h = float(np.correlate(hh, 1 - hh, mode='full').max())
        c5_h = mc_h * 2.0 / nh
        if c5_h >= best_c5:
            continue
        best_mc = mc_h
        best_h = hh.copy()
        best_c5 = c5_h
        n = nh
        eps_r = 0.03
        for _ in range(150):
            if time.time() > phase3_dl - 10:
                break
            hh, mc_new = lp_step(hh, nh, eps_r)
            c5_new = mc_new * 2.0 / nh
            if c5_new < best_c5:
                best_mc = mc_new
                best_h = hh.copy()
                best_c5 = c5_new
            hh = project_feasible(hh, nh)
            eps_r = max(eps_r * 0.996, 0.001)

    # Phase 4: Final LP polish with very small eps
    if time.time() < dl - 2:
        h = best_h.copy()
        eps_f = 0.004
        for _ in range(5000):
            if time.time() > dl - 2:
                break
            h_new, mc_new = lp_step(h, n, eps_f)
            c5_new = mc_new * 2.0 / n
            if c5_new < best_c5 - 1e-13:
                best_mc = mc_new
                best_h = h_new.copy()
                best_c5 = c5_new
            h = h_new
            eps_f = max(eps_f * 0.999, 0.0001)

    best_h = project_feasible(best_h, n)
    best_c5 = compute_c5(best_h, n)
    return best_h, best_c5, n
