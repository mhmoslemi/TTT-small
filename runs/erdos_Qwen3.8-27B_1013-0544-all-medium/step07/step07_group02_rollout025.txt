Key idea: **Use the subgradient of the max function more carefully.**

At a point h, the subdifferential of f(h) = max_k c_k is the convex hull of {∇c_k : c_k = f(h)}. The "best" descent direction is the one closest to the origin in the negative subdifferential. This is the "minimum norm subgradient" which gives the steepest descent for the max function.

The minimum norm subgradient can be computed as:
- Find all active indices A = {k : c_k = f(h)}
- Project the origin onto conv({∇c_k : k ∈ A})
- The negative of this projection is the steepest descent direction

This is a QP with |A| variables. For |A| up to n, this is fast.

```python
def steepest_descent_direction(h, n, tol=1e-8):
    """Compute the steepest descent direction for max_k c_k."""
    dx = 2.0 / n
    c = np.correlate(h, 1-h, mode='full')
    f = c.max()
    # Active set: all k where c_k ≈ f
    active = np.where(c >= f - tol)[0]
    
    # Compute gradients for active k
    # ∇c_k has components:
    # (∇c_k)[j] = dx * [(1-h[j+k_rel])*1(0<=j+k_rel<n) - h[j-k_rel]*1(0<=j-k_rel<n)]
    # where k_rel = k - (n-1) for k in [0, 2n-2]
    
    grads = np.zeros((len(active), n))
    for idx, m in enumerate(active):
        k = m - (n - 1)
        g = np.zeros(n)
        # First part: (1-h[j+k]) for valid j
        m1s = max(0, n-1-k)  # j+k >= 0 => j >= -k
        # Actually: for g[j] += (1-h[j+k])*dx, need 0 <= j+k < n, so -k <= j < n-k
        js = max(0, -k)
        je = min(n, n - k)
        if je > js:
            g[js:je] = (1.0 - h[js+k:je+k]) * dx
        # Second part: -h[j-k]*dx, need 0 <= j-k < n, so k <= j < n+k
        js2 = max(0, k)
        je2 = min(n, n + k)
        if je2 > js2:
            g[js2:je2] -= h[js2-k:je2-k] * dx
        grads[idx] = g
    
    # Project origin onto conv({grads[i] : i in active})
    # This is: minimize ||Σ λ_i * g_i||² subject to Σλ = 1, λ >= 0
    # Which is: minimize ||Wλ||² s.t. 1'λ = 1, λ >= 0 (where W = [g_0; g_1; ...; g_{m-1}])
    
    m_a = len(active)
    if m_a == 1:
        return -grads[0], f
    
    try:
```

OK, let me also think about the SLSQP approach more carefully. The log-sum-exp smoothing:

g_α(h) = max_k c_k(h) + (1/α) * log(∑ exp(α*c_k(h) - α*max_k c_k(h)))
≈ max_k c_k(h) + (1/α) * log(|A|) + small terms

where A is the active set. As α → ∞, g_α → max. For finite α, g_α is smooth and we can use gradient methods.

The gradient of g_α:
∇g_α = ∇(max c_k) + (1/α) * ∇log(∑ exp(α(c_k - max)))
= ∇(max c_k) + (1/α) * (∑ exp(α(c_k - max)) * α * ∇c_k) / (∑ exp(α(c_k - max)))
= ∇(max c_k) + ∑ w_k * ∇c_k
where w_k = exp(α(c_k - max)) / ∑ exp(α(c_j - max))

Actually, this simplifies. Let p_k = exp(α(c_k - max)) / ∑ exp(α(c_j - max)). Then:
∇g_α = ∑ p_k * ∇c_k (approximately, for large α)

This is exactly the "softmax-weighted average of active gradients"! This is a well-known technique (entropic regularization of the max).

So the SLSQP with log-sum-exp is essentially doing gradient descent with a "soft" active set. The parameter α controls how "hard" the max is.
