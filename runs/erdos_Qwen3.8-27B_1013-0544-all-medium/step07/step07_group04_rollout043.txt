The key new element is the **coordinate descent with exact 1D minimax**. Let me implement this.

For coordinate i, I need:
- Which lags are affected: those k where h[i] appears in c[k]
- For each such lag, the linear coefficient of h[i] in c[k]
- Then solve: minimize max_k (a_k * t + b_k) for t ∈ [0,1]

where a_k = ∂c[k]/∂h[i] (which doesn't depend on t since c is linear in each h[j])
and b_k = c[k] - a_k * h[i] (the current value minus the contribution of h[i])

Wait, c[k] is bilinear, not linear in h[i]. Let me reconsider.

c[k] = dx * Σ f_{k,i,j}(h) where each term is either h[p]*h[q] or h[p]*(1-h[q]) etc.

When we vary only h[i], c[k] becomes:
c[k] = dx * (A_k * h[i] + B_k) for some A_k and B_k that don't depend on h[i].

This is because c[k] is a sum of products, and each product either:
- Involves h[i] and another h[j] (j≠i): linear in h[i]
- Involves h[i] and (1-h[i]): quadratic in h[i]!

Wait, the k=0 case: c[0] = dx * Σ h[i]*(1-h[i]) = dx * Σ (h[i] - h[i]²)

This is quadratic in h[i]! So for k=0, the dependence on h[i] is:
c[0] = dx * (h[i] - h[i]²) + (contribution from other j)
= -dx * h[i]² + dx * h[i] + const

This is a concave quadratic, not linear. So the 1D problem for k=0 involves a quadratic.

For k≠0: c[k] = dx * Σ h[i+k]*(1-h[i]) or similar. Each term h[i+k]*(1-h[i]) is linear in h[i] (when i+k ≠ i, which is true for k≠0). So for k≠0, c[k] is linear in h[i].

For k=0: c[0] = dx * Σ_j h[j]*(1-h[j]). The term involving h[i] is dx*h[i]*(1-h[i]) = dx*(h[i]-h[i]²). This is quadratic.

So the 1D problem is:
minimize max(k≠0: a_k*t + b_k, a_0*t² + b_0*t + c_0) subject to 0 ≤ t ≤ 1

where the max is over all lags. This is still a convex minimization problem (max of convex functions is convex, and a concave quadratic is... wait, -t²+t is concave, so a_0*t²+b_0*t+c_0 with a_0<0 is concave).

Actually, c[0] as a function of t = h[i]:
c[0] = dx*(t - t²) + dx*Σ_{j≠i} h[j]*(1-h[j])
= -dx*t² + dx*t + const

This is a concave parabola. The max of a concave function and linear functions... that's not necessarily convex!

Hmm, this makes the 1D problem non-convex. But it's still a 1D problem, so we can solve it by:
1. Finding all critical points (where the max changes identity, or where the derivative is 0)
2. Evaluating at all critical points and endpoints
3. Taking the minimum

The critical points of max(f_1, f_2, ..., f_m) where each f is either linear or quadratic are:
- Intersections of pairs of the functions
- Stationary points of individual functions (for the quadratic)
- Endpoints

With 2n-1 functions, there are O(n²) intersection points, but we can be smarter. Since we only need the minimum, and the function is continuous, we can use a golden section or ternary search if the function is unimodal... but it's not guaranteed to be.

Actually, for practical purposes, I can just evaluate the 1D objective at many points (say 200 points in [0,1]) and take the best. This is cheap and works well.

```python
    h_orig = h[i]
    dx = 2.0 / n
    off = n - 1

    # c[idx] = dx * sum of terms. When h[i] changes, which terms change?

    #   Term with h[i]: dx*h[i]*(1-h[i]) = dx*(h[i] - h[i]^2)
    #   So c[off] = -dx*h[i]^2 + dx*h[i] + (dx * sum_{j≠i} h[j]*(1-h[j]))
    #   As function of t: -dx*t^2 + dx*t + C0
    
    # For idx = off + k (k>0): c = dx * sum_{j=0}^{n-1-k} h[j+k]*(1-h[j])
    #   h[i] appears if:
```

Then for a given t:

The max is max(max_{idx≠off}(A_idx*t + B_idx), -dx*t² + dx*t + C_0)

This is the max of (2n-2) linear functions and one concave quadratic. The minimum of this over t∈[0,1] can be found by:
1. Noting that the concave quadratic is ≤ max(0, 1/4)*dx (its max is at t=0.5 with value dx/4)

3. Otherwise, we need to consider it

- B is a vector of length 2n-1
- For a vector of t values, I compute C = outer product: T[:,None] * A[None,:] + B[None,:] giving shape (n_eval, 2n-1)
- Then add the quadratic term for the k=0 row
- Take max over axis=1

```python
def coord_descent_pass(h, n, n_sweeps=1, n_eval=500):
    """One pass of coordinate descent with exact 1D optimization."""
    h = h.copy()
    dx = 2.0 / n
    off = n - 1
    L = 2 * n - 1  # number of lags
    ts = np.linspace(0.0, 1.0, n_eval)
    
    for sweep in range(n_sweeps):
        for i in range(n):
            # Compute coefficients A_k and B_k for each lag
            # c_k = A_k * h[i] + B_k (for k≠0)
            # c_0 = -dx*h[i]^2 + dx*h[i] + B_0 (for k=0)
            
            # Current c values
            c = compute_c(h, n)
            
            # For each lag, compute A_k = ∂c_k/∂h[i] (constant since c_k is linear in h[i] for k≠0)
            # And B_k = c_k - A_k * h[i]
            
            # Let me compute this from scratch for each i
            # c_k = dx * sum of products
            # For k>0: c[off+k] = dx * Σ_{j=0}^{n-1-k} h[j+k]*(1-h[j])
            #   ∂/∂h[i] = dx * [(1-h[i-k]) * I(k≤i≤n-1) - h[i+k] * I(0≤i≤n-1-k)]
            #   (the first term is from h[j+k] where j=i-k, second from (1-h[j]) where j=i)
            #   Wait: h[j+k]*(1-h[j]), ∂/∂h[i]:
            #   = (1-h[j]) * δ(j+k,i) + h[j+k] * (-δ(j,i))
            #   = (1-h[i-k]) * I(0≤i-k≤n-1-k) - h[i+k] * I(0≤i≤n-1-k)
            #   = (1-h[i-k]) * I(k≤i≤n-1) - h[i+k] * I(0≤i≤n-1-k)
            
            A = np.zeros(L)
            for k in range(1, n):
                # Lag +k: idx = off + k
                # A[off+k] = dx * [(1-h[i-k]) if k<=i<=n-1 else 0] - dx * [h[i+k] if 0<=i<=n-1-k else 0]
                a = 0.0
                if k <= i <= n - 1:
                    a += (1.0 - h[i - k])
                if 0 <= i <= n - 1 - k:
                    a -= h[i + k]
                A[off + k] = dx * a
                
                # Lag -k: idx = off - k
                # c[off-k] = dx * Σ_{j=k}^{n-1} h[j]*(1-h[j-k])
                # ∂/∂h[i] = dx * [(1-h[i-k]) * I(k≤i≤n-1) - h[i+k] * I(0≤i≤n-1-k)]
                # Wait, let me recompute:
                # c[off-k] = dx * Σ_{j=k}^{n-1} h[j]*(1-h[j-k])
                # ∂/∂h[i] = dx * [δ(j,i)*(1-h[j-k]) + h[j]*(-δ(j-k,i))]
                # = dx * [(1-h[i-k]) * I(i≥k) - h[i+k] * I(i+k≥k, i+k≤n-1)]
                # = dx * [(1-h[i-k]) * I(i≥k) - h[i+k] * I(i≤n-1-k)]
                a = 0.0
                if i >= k:
                    a += (1.0 - h[i - k])
                if i <= n - 1 - k:
                    a -= h[i + k]
                A[off - k] = dx * a
            
            # Lag 0: idx = off
            # c[off] = dx * Σ_j h[j]*(1-h[j])
            # ∂/∂h[i] = dx * (1 - 2*h[i])  [but this is the derivative, not the coefficient in the linear form]
            # c[off] as function of t: -dx*t² + dx*t + C
            # So it's quadratic. Let me handle it separately.
            
            B = c - A * h[i]  # B_k = c_k - A_k * h[i]
            # For k=0: c[off] = -dx*t^2 + dx*t + B[off] where B[off] = c[off] + dx*h[i]^2 - dx*h[i]
            # Let me verify: c[off] = dx*Σh[j]*(1-h[j]) = dx*h[i]*(1-h[i]) + dx*Σ_{j≠i}h[j]*(1-h[j])
            # = dx*(h[i]-h[i]^2) + const
            # As function of t: dx*(t-t^2) + const = -dx*t^2 + dx*t + dx*h[i] - dx*h[i]^2 + const... 
            # Actually: B[off] should satisfy: c[off](t) = -dx*t^2 + dx*t + B[off]
            # c[off](h[i]) = -dx*h[i]^2 + dx*h[i] + B[off]
            # But also c[off](h[i]) = dx*h[i]*(1-h[i]) + dx*Σ_{j≠i}h[j]*(1-h[j])
            # So B[off] = dx*Σ_{j≠i}h[j]*(1-h[j])
            # And A[off] should be 0 (since it's handled by the quadratic)
            A[off] = 0.0
            B[off] = c[off] + dx * h[i] * h[i] - dx * h[i]
            # Verify: -dx*t^2 + dx*t + B[off] at t=h[i]:
            # = -dx*h[i]^2 + dx*h[i] + c[off] + dx*h[i]^2 - dx*h[i] = c[off] ✓
            
            # Now evaluate max over lags for each t in ts
            # For k≠0: value = A[k]*t + B[k]
            # For k=0: value = -dx*t^2 + dx*t + B[off]
            vals = ts[:, None] * A[None, :] + B[None, :]  # shape (n_eval, L)
            vals[:, off] = -dx * ts**2 + dx * ts + B[off]
            cmax = vals.max(axis=1)
            
            best_j = np.argmin(cmax)
            h[i] = ts[best_j]
    
    return project_box_sum(h, n)
```

Actually, I can precompute A more efficiently. Let me think...

For a given i, A[off+k] for all k can be computed as:
A[off+k] = dx * [(1-h[i-k]) * I(k≤i≤n-1) - h[i+k] * I(0≤i≤n-1-k)]

The condition k≤i≤n-1 means k≤i (since i≤n-1 always).
The condition 0≤i≤n-1-k means k≤n-1-i.

So for k=1,...,min(i, n-1-i):
A[off+k] = dx * [(1-h[i-k]) - h[i+k]]
For k=i+1,...,n-1-i (if i < n-1-i):
A[off+k] = dx * [-h[i+k]]
For k=n-1-i+1,...,i (if n-1-i < i):
A[off+k] = dx * [(1-h[i-k])]

Similarly for A[off-k] (negative lags).

This can be computed in O(n) per i using vectorized numpy.

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c(h, n):
    return np.correlate(h, 1.0 - h, mode="full") * (2.0 / n)

def project_box_sum(v, n):
    v = np.nan_to_num(np.asarray(v, dtype=float).reshape(-1))
    tgt = 0.5 * n
    lo, hi = -1.0, 2.0
    for _ in range(60):
        mid = 0.5 * (lo + hi)
        s = np.clip(v - mid, 0.0, 1.0).sum()
        if s > tgt:
            lo = mid
        else:
            hi = mid
    v = np.clip(v - 0.5 * (lo + hi), 0.0, 1.0)
    for _ in range(30):
        d = tgt - v.sum()
        if abs(d) < 1e-14:
            break
        m = (v > 1e-12) & (v < 1.0 - 1e-12)
        if m.any():
            v[m] += d / m.sum()
        else:
            v += d / n
        v = np.clip(v, 0.0, 1.0)
    return v

def lse_obj(x, n, alpha, mu):
    c = compute_c(x, n)
    m = float(c.max())
    sh = alpha * (c - m)
    s = float(np.exp(sh).sum())
    val = m + np.log(s) / alpha
    d = float(x.sum() - 0.5 * n)
    return val + 0.5 * mu * d * d

def lse_grad(x, n, alpha, mu):
    c = compute_c(x, n)
    m = float(c.max())
    sh = alpha * (c - m)
    e = np.exp(sh)
    q = e / e.sum()
    g = np.zeros(n)
    dx = 2.0 / n
    off = n - 1
    for idx in np.where(q > 1e-8)[0]:
        k = idx - off
        w = q[idx]
        if k > 0:
            m2 = n - k
            g[k:] += w * (1.0 - x[:m2])
            g[:m2] -= w * x[k:]
        elif k < 0:
            k2 = -k
            m2 = n - k2
            g[:m2] += w * (1.0 - x[k2:])
            g[k2:] -= w * x[:m2]
        else:
            g += (1.0 - 2.0 * x)
    d = float(x.sum() - 0.5 * n)
    return dx * g + mu * d

def lbfgs_opt(h, n, alpha, mu, maxiter):
    h = project_box_sum(h, n)
    bounds = [(0.0, 1.0)] * n
    try:
        res = minimize(lse_obj, h, args=(n, alpha, mu), method='L-BFGS-B',
                       jac=lse_grad, bounds=bounds,
                       options={'maxiter': maxiter, 'maxfun': 5*maxiter,
                                'ftol': 1e-15, 'gtol': 1e-9})
        return res.x if res.x is not None else h
    except:
        return h

def coord_descent(h, n, n_sweeps=1, n_eval=300, deadline=None):
    h = h.copy()
    dx = 2.0 / n
    off = n - 1
    L = 2 * n - 1
    ts = np.linspace(0.0, 1.0, n_eval)
    ts2 = ts * ts
    
    for sweep in range(n_sweeps):
        for i in range(n):
            if deadline and time.time() > deadline:
                return project_box_sum(h, n)
            
            c = compute_c(h, n)
            hi = h[i]
            
            # Compute A_k and B_k
            # For k > 0: A[off+k] = dx * [(1-h[i-k])*I(k<=i) - h[i+k]*I(k<=n-1-i)]
            A = np.zeros(L)
            B = c - A * hi  # will fix B[off] later
            
            # Positive lags
            ks = np.arange(1, n)
            # cond_pos: k <= i (always true for k <= i)
            # cond_neg: k <= n-1-i
            valid_pos = ks <= i  # k <= i means i-k >= 0
            valid_neg = ks <= n - 1 - i  # k <= n-1-i means i+k <= n-1
            
            a_pos = np.zeros(n-1)
            a_pos[valid_pos] = (1.0 - h[i - ks[valid_pos]])
            a_pos[valid_neg] -= h[i + ks[valid_neg]]
            A[off + 1:] = dx * a_pos
            
            # Negative lags
            a_neg = np.zeros(n-1)
            a_neg[valid_pos] = (1.0 - h[i - ks[valid_pos]])
            a_neg[valid_neg] -= h[i + ks[valid_neg]]
            A[off-1:0:-1] = dx * a_neg  # A[off-k] for k=1,...,n-1
            
            # Lag 0: quadratic
            A[off] = 0.0
            B = c - A * hi
            B[off] = c[off] + dx * hi * hi - dx * hi
            
            # Evaluate
            vals = ts[:, None] * A[None, :] + B[None, :]
            vals[:, off] = -dx * ts2 + dx * ts + B[off]
            cmax = vals.max(axis=1)
            best_j = np.argmin(cmax)
            h[i] = ts[best_j]
    
    return project_box_sum(h, n)

def interpolate_h(h, nold, nnew):
    if nold == nnew:
        return h.copy()
    xo = (np.arange(nold) + 0.5) * (2.0 / nold)
    xn = (np.arange(nnew) + 0.5) * (2.0 / nnew)
    return np.interp(xn, xo, h)

def pair_search_single(h, c, i, j, n):
    """Try to improve by adjusting h[i] and h[j] (keeping sum constant)."""
    x0, y0 = h[i], h[j]
    S = x0 + y0
    lo = max(0.0, S - 1.0)
    hi = min(1.0, S)
    if hi - lo < 1e-12:
        return None
    
    dx = 2.0 / n
    off = n - 1
    L = 2 * n - 1
    omh = 1.0 - h
    
    # For a trial x, y = S - x
    # Change in each c_k:
    # The terms affected are those involving h[i] or h[j]
    # Let me compute the change directly
    
    # c_k = dx * sum of terms. When h[i] changes by Δx = x - x0 and h[j] by Δy = y - y0 = -(x-x0):
    # 
    # For each c_k, the change is: dx * (Δx * coeff_i_k + Δy * coeff_j_k + cross terms if i,j both in same c_k)
    # Since Δy = -Δx: change = dx * Δx * (coeff_i_k - coeff_j_k) + cross terms
    
    # This is getting complex. Let me just do a grid search over x.
    xs = np.linspace(lo, hi, 64)
    best_x = x0
    best_c = c.max()
    
    for x in xs:
        y = S - x
        if y < 0 or y > 1:
            continue
        h[i], h[j] = x, y
        c_new = compute_c(h, n)
        v = c_new.max()
```

```python
def coord_descent(h, n, n_sweeps=1, deadline=None):
    h = h.copy()
    dx = 2.0 / n
    off = n - 1
    L = 2 * n - 1
    
    for sweep in range(n_sweeps):
        for i in range(n):
            if deadline and time.time() > deadline:
                return project_box_sum(h, n)
            
            c = compute_c(h, n)
            hi = h[i]
            
            # Compute A for all lags
            A = np.zeros(L)
            ks = np.arange(1, n)
            valid_pos = ks <= i
            valid_neg = ks <= n - 1 - i
            a_k = np.zeros(n-1)
            a_k[valid_pos] = (1.0 - h[i - ks[valid_pos]])
            a_k[valid_neg] -= h[i + ks[valid_neg]]
            A[off+1:] = dx * a_k
            A[1:off] = dx * a_k[::-1]  # A[off-k] = A[off+k]
            # Wait, A[off-k] should equal A[off+k] based on our symmetry result
            # A[off-1] = A[off+1], A[off-2] = A[off+2], etc.
            # In array: A[off-k] for k=1,...,n-1 means A[off-1], A[off-2], ..., A[0]
            # And A[off+k] for k=1,...,n-1 means A[off+1], A[off+2], ..., A[2n-2]
            # So A[0] = A[2n-2], A[1] = A[2n-3], ..., A[n-2] = A[n]

            vals[:, off] = -dx * ts_coarse**2 + dx * ts_coarse + B[off]
```

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c(h, n):
    return np.correlate(h, 1.0 - h, mode="full") * (2.0 / n)

def project_box_sum(v, n):
    v = np.asarray(v, dtype=float).reshape(-1)
    v = np.nan_to_num(v)
    tgt = 0.5 * n
    lo, hi = -1.0, 2.0
    for _ in range(60):
        mid = 0.5 * (lo + hi)
        s = np.clip(v - mid, 0.0, 1.0).sum()
        if s > tgt:
            lo = mid
        else:
            hi = mid
    v = np.clip(v - 0.5 * (lo + hi), 0.0, 1.0)
    for _ in range(30):
        d = tgt - v.sum()
        if abs(d) < 1e-14:
            break
        m = (v > 1e-12) & (v < 1.0 - 1e-12)
        if m.any():
            v[m] += d / m.sum()
        else:
            v += d / n
        v = np.clip(v, 0.0, 1.0)
    return v

def lse_obj_pen(x, n, alpha, mu):
    c = compute_c(x, n)
    m = float(c.max())
    sh = alpha * (c - m)
    s = float(np.exp(sh).sum())
    val = m + np.log(s) / alpha
    d = float(x.sum() - 0.5 * n)
    return val + 0.5 * mu * d * d

def lse_grad_pen(x, n, alpha, mu):
    c = compute_c(x, n)
    m = float(c.max())
    sh = alpha * (c - m)
    e = np.exp(sh)
    q = e / e.sum()
    g = np.zeros(n)
    dx = 2.0 / n
    off = n - 1
    nz = np.where(q > 1e-8)[0]
    for idx in nz:
        k = idx - off
        w = q[idx]
        if k > 0:
            g[k:] += w * (1.0 - x[:n-k])
            g[:n-k] -= w * x[k:]
        elif k < 0:
            k2 = -k
            g[:n-k2] += w * (1.0 - x[k2:])
            g[k2:] -= w * x[:n-k2]
        else:
            g += (1.0 - 2.0 * x)
    d = float(x.sum() - 0.5 * n)
    return dx * g + mu * d

def lbfgs_opt(h, n, alpha, mu, maxiter):
    h = project_box_sum(h, n)
    bounds = [(0.0, 1.0)] * n
    try:
        res = minimize(lse_obj_pen, h, args=(n, alpha, mu), method='L-BFGS-B',
                       jac=lse_grad_pen, bounds=bounds,
                       options={'maxiter': maxiter, 'maxfun': 5*maxiter,
                                'ftol': 1e-15, 'gtol': 1e-9})
        return res.x if res.x is not None else h
    except:
        return h

def coord_descent(h, n, n_sweeps=1, deadline=None):
    h = h.copy()
    dx = 2.0 / n
    off = n - 1
    L = 2 * n - 1
    ts_c = np.linspace(0.0, 1.0, 100)
    
    order = np.arange(n)
    for sweep in range(n_sweeps):
        np.random.shuffle(order)  # randomized order
        for i in order:
            if deadline and time.time() > deadline:
                return project_box_sum(h, n)

            hi = h[i]
            ks = np.arange(1, n)
            vp = ks <= i
            vn = ks <= n - 1 - i
            a_k = np.zeros(n-1)
            a_k[vp] = 1.0 - h[i - ks[vp]]
            a_k[vn] -= h[i + ks[vn]]
            A = np.zeros(L)

            A[:off] = dx * a_k[::-1]
            B = c - A * hi
            B[off] = c[off] + dx * hi * hi - dx * hi

            vals[:, off] = -dx * ts_c**2 + dx * ts_c + B[off]
            cm = vals.max(axis=1)
            jc = np.argmin(cm)
            # Fine

            vals[:, off] = -dx * ts_f**2 + dx * ts_f + B[off]
            cm = vals.max(axis=1)
            jf = np.argmin(cm)
            h[i] = ts_f[jf]
    
    return project_box_sum(h, n)
```

```python
def compute_c(h, n):
    return np.correlate(h, 1.0 - h, mode="full") * (2.0 / n)

def project_box_sum(v, n):
    v = np.asarray(v, dtype=float).reshape(-1)
    v = np.where(np.isfinite(v), v, 0.5)
    tgt = 0.5 * n
    lo, hi = -1.0, 2.0
    for _ in range(60):
        mid = 0.5 * (lo + hi)
        s = np.clip(v - mid, 0.0, 1.0).sum()
        if s > tgt:
            lo = mid
        else:
            hi = mid
    v = np.clip(v - 0.5 * (lo + hi), 0.0, 1.0)
    for _ in range(30):
        d = tgt - v.sum()
        if abs(d) < 1e-14:
            break
        m = (v > 1e-12) & (v < 1.0 - 1e-12)
        if m.any():
            v[m] += d / m.sum()
        else:
            v += d / n
        v = np.clip(v, 0.0, 1.0)
    return v

def _lse_obj(x, n, alpha, mu):
    c = compute_c(x, n)
    m = float(c.max())
    sh = alpha * (c - m)
    s = float(np.exp(sh).sum())
    return m + np.log(s) / alpha + 0.5 * mu * (x.sum() - 0.5 * n) ** 2

    c = compute_c(x, n)
    m = float(c.max())
    e = np.exp(alpha * (c - m))
    q = e / e.sum()
    g = np.zeros(n)
    dx = 2.0 / n

            g[k2:] -= w * x[:n-k2]
```
