The function f(x) = max_k (base_k + A_k*x + B_k + Q_k*x²) is convex on [0,1].

For a convex function, the minimum can be found by:
1. Checking if f'(0+) ≥ 0 (then min is at x=0)
2. Checking if f'(-) ≤ 0 (then min is at x=1)
3. Otherwise, the minimum is where f' changes sign

The subgradient of f at x is the convex hull of {A_k + 2*Q_k*x : c_k(x) = f(x)}.

So I can use bisection on the subgradient:
- At x, find all "active" k (where c_k(x) = f(x))
- Compute the subgradient interval: [min(A_k + 2*Q_k*x for active k), max(A_k + 2*Q_k*x for active k)]
- If min > 0: move left
- If max < 0: move right
- Otherwise: x is the minimum

This converges in O(log(1/ε)) iterations, each O(n). Much faster than grid!
