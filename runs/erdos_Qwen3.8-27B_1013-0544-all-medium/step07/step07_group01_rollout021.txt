The advantage is that the optimization over t is unconstrained (except for the sum constraint), which L-BFGS-B handles well.

def optimize_t(h_init, n, alpha, deadline, mu=1000):

3. **Exploiting the problem structure**: The correlation c(L) is a quadratic form in h. The gradient and Hessian of c(L) with respect to h have a specific structure (related to the shift operators).

Let me think about the Hessian. For a fixed lag L:
c(L) = Σ_i h[i](1-h[i+L])
∂c(L)/∂h[j] = (1-h[j+L]) - h[j-L] (with appropriate boundary handling)
∂²c(L)/∂h[j]∂h[k] = -δ_{j,k+L} - δ_{j+L,k} (essentially)

So the Hessian of c(L) is sparse! It only has non-zero entries at positions (j, j+L) and (j+L, j). This means the Hessian of the max (over a few active lags) is also sparse.

This suggests that a **sparse Newton method** or a **Gauss-Newton method** could be very effective. But implementing this from scratch is complex.

Alternatively, I could use **truncated Newton** with the sparse Hessian structure. But scipy doesn't directly support this for SLSQP.

Let me just go with the practical approach and hope that the active-set SLSQP with careful parameter tuning is enough.

One more idea: **successive linear programming (SLP)**. At each iteration:
1. Linearize the objective (max of active lags) at the current point
2. Solve the resulting linear problem (which is a LINPROG)
3. Take a step toward the solution
4. Repeat

The linearization of c(L) at h₀ is:
c(L; h) ≈ c(L; h₀) + ∇c(L; h₀)ᵀ (h - h₀)

And the max of linear functions is a linear program:
min t
s.t. c(L*_j; h₀) + ∇c(L*_j; h₀)ᵀ (h - h₀) ≤ t for j = 1, ..., K
     0 ≤ h ≤ 1
     Σ h = n/2

This is a linear program! I can solve it with scipy.optimize.linprog or cvxpy.

Then I take a damped step: h_new = (1-α) h + α * h_LP where h_LP is the LP solution.

This is essentially the **extral-gradient** or **KARUS** method for min-max problems.

Let me implement this:

```python
def slp_step(h, n, K=10, damping=0.5):
    """Successive Linear Programming step."""
    from scipy.optimize import linprog
    dx = 2.0 / n
    c = compute_corr(h, n)
    active = np.argsort(c)[::-1][:K]
    
    # Linearize: c(L_j; h) ≈ c(L_j; h) + grad_j · (h - h)
    # We want: min t s.t. c_j + grad_j · (h_new - h) <= t
    # i.e., grad_j · h_new <= t - c_j + grad_j · h
    
    # Variables: [h_new (n vars), t (1 var)]
    # Minimize: t
    # Subject to:
    #   For each active lag j: grad_j · h_new - t <= -c_j + grad_j · h
    #   0 <= h_new <= 1
    #   sum(h_new) = n/2
    #   t >= 0 (can add this)
    
    A_ub = []
    b_ub = []
    c_j = c[active]
    
    for j, li in enumerate(active):
        lag = li - (n - 1)
        grad = np.zeros(n)
        if lag >= 0:
            grad[:n-lag] += (1 - h[lag:])
            grad[lag:] -= h[:n-lag]
        else:
            ll = -lag
            grad[ll:] += (1 - h[:n-ll])
            grad[:n-ll] -= h[ll:]
        grad *= dx
        
        # grad · h_new - t <= -c_j + grad · h
        # grad · h_new - t <= grad · h - c_j
        row = np.zeros(n + 1)
        row[:n] = grad
        row[n] = -1
        A_ub.append(row)
        b_ub.append(dot(grad, h) - c_j)
    
    # Equality: sum(h_new) = n/2
    A_eq = np.zeros((1, n+1))
    A_eq[0, :n] = 1.0
    b_eq = [n / 2.0]
    
    # Bounds: 0 <= h_new <= 1, t >= 0
    bounds = [(0, 1)] * n + [(0, None)]
    
    # Objective: minimize t
    c_obj = np.zeros(n + 1)
    c_obj[n] = 1.0
    
    res = linprog(c_obj, A_ub=np.array(A_ub), b_ub=np.array(b_ub),
                  A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')
    
    if not res.success:
        return h
    
    h_lp = res.x[:n]
    h_new = (1 - damping) * h + damping * h_lp
    return project_feasible(h_new, n)
```

This is a very different approach from SLSQP! The SLP method:
- Solves a linear program at each step (very fast with modern solvers)
- Takes damped steps toward the LP solution
- Can be iterated many times

The key advantage is that the LP can be solved very precisely, and the method doesn't suffer from the non-smoothness issues of the max function.

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def compute_corr(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)
