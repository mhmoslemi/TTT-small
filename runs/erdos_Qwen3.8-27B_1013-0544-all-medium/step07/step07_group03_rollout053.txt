def binary_sa(h_b, n, deadline, rng, max_iters=1000000):
    """Simulated annealing on binary solution"""
    dx = 2.0 / n
    corr = np.correlate(h_b, 1 - h_b, mode='full').astype(float)
    cur_max = corr.max() * dx
    best_h = h_b.copy()
    best_max = cur_max
    m_range = np.arange(-(n-1), n)
    
    ones = set(np.where(h_b == 1)[0])
    zeros = set(np.where(h_b == 0)[0])
    
    T = cur_max * 0.1  # initial temperature
    cooling = 0.99999
    
    for it in range(max_iters):
        if time.time() > deadline:
            break
        # Pick random swap
        i = rng.choice(list(ones))  # position to flip 1->0
        j = rng.choice(list(zeros))  # position to flip 0->1
        
        # Compute delta
        delta = np.zeros(2*n-1)
        # i: 1->0
        im = i + m_range
        msk = (im >= 0) & (im < n)
        delta[msk] -= (1.0 - h_b[im[msk]])
        imn = i - m_range
        msk = (imn >= 0) & (imn < n)
        delta[msk] += h_b[imn[msk]]
        # j: 0->1
        jm = j + m_range
        msk = (jm >= 0) & (jm < n)
        delta[msk] += (1.0 - h_b[jm[msk]])
        jmn = j - m_range
        msk = (jmn >= 0) & (jmn < n)
        delta[msk] -= h_b[jmn[msk]]
        # Corrections
        delta[n-1] -= 2.0
        dj = n-1 + (j-i)
        if 0 <= dj < 2*n-1:
            delta[dj] += 2.0
        di = n-1 + (i-j)
        if 0 <= di < 2*n-1:
            delta[di] += 2.0
        
        new_corr = corr + delta
        new_max = new_corr.max() * dx
        
        # Accept?
        if new_max < cur_max or rng.random() < np.exp((cur_max - new_max) / T):
            # Apply swap
            h_b[i], h_b[j] = 0.0, 1.0
            corr = new_corr
            cur_max = new_max
            ones.remove(i)
            ones.add(j)
            zeros.add(i)
            zeros.remove(j)
            if cur_max < best_max:
                best_max = cur_max
                best_h = h_b.copy()
        
        T *= cooling
    
    return best_h, best_max

Now, let me also think about the continuous optimization. The log-sum-exp trick with high alpha approximates the max. The gradient of the log-sum-exp is:
∂/∂h_i [log sum_k exp(alpha * C_k)] = alpha * sum_k exp(alpha*C_k) * (∂C_k/∂h_i) / sum_k exp(alpha*C_k)
= alpha * sum_k w_k * (∂C_k/∂h_i) where w_k = exp(alpha*C_k) / sum exp(alpha*C_j)

This gives a weighted average of the gradients of the individual C_k, weighted by their "importance" (how close they are to the max).

For the binary case, we can't use gradients directly, but we can use the subgradient: the gradient of C_k with respect to h is:
∂C_k/∂h_i = (1-h[i+k]) - h[i-k] (for valid indices)

This is what the `compute_subgrad` function in the previous code does.

For the binary local search, the "subgradient" approach would be:
1. Find the active set (shifts k where C_k is close to the max)
2. Compute the sum of subgradients over the active set
3. Use this to guide which positions to flip

Specifically, if the subgradient at position i is positive, flipping h[i] from 1 to 0 would decrease the objective. If negative, flipping h[i] from 0 to 1 would help.

Let me combine this with the random candidate approach:
- Bias the random selection towards positions with large |subgradient|
- Or: directly propose flips based on the subgradient sign

Actually, here's a cleaner idea: **gradient-guided swap search**.

1. Compute the subgradient g = sum of ∂C_k/∂h over active k's
2. For 1-positions: the best one to flip to 0 is the one with the largest positive g[i] (since decreasing h[i] decreases C_k by g[i]*dh)
   Wait, the subgradient tells us the direction of steepest increase. So to decrease C_k, we should decrease h[i] where g[i] > 0 and increase h[i] where g[i] < 0.
3. For 0-positions: the best one to flip to 1 is the one with the most negative g[i]
4. Try the top M candidates for each type and pick the best swap

This is much more directed than pure random.

    h = np.clip(h, 0.0, 1.0)

def compute_swap_delta(i, j, h, n, m_range):
    delta = np.zeros(2 * n - 1)
    im = i + m_range

    delta[msk] -= h[jmn[msk]]
    delta[n - 1] -= 2.0
    dj = n - 1 + (j - i)
    if 0 <= dj < 2 * n - 1:
        delta[dj] += 2.0
    di = n - 1 + (i - j)
    if 0 <= di < 2 * n - 1:
        delta[di] += 2.0
    return delta

    active = np.argsort(corr)[::-1][:top_k]
    grad = np.zeros(n)
