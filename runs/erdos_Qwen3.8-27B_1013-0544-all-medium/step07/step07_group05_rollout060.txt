The bisection approach is interesting:
- For a given target C, check if there exists h with max_k corr_k ≤ C
- This is a semi-infinite constraint (infinitely many k), but we can discretize
- The feasibility check is: min_h max_k corr_k(h) ≤ C, which is equivalent to min_h [max_k corr_k - C] ≤ 0
- Or: exists h such that corr_k(h) ≤ C for all k
- This is a convex feasibility problem if we use the L1 norm of h... but h is not convex in this problem.

Actually, the problem is non-convex because corr_k = ∑ h[i]·(1-h[i+k]) is bilinear in h. So bisection on C doesn't directly give a convex problem.
