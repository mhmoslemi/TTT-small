For the exact coordinate update:
Given current c[m] for all m, and B[m] = ∂c[m]/∂h[i]:
new_c[m] = c[m] + B[m] * (h_new - h[i]) = c[m] + B[m] * h_new - B[m] * h[i]
= (c[m] - B[m] * h[i]) + B[m] * h_new
= A[m] + B[m] * h_new

where A[m] = c[m] + B[m] * (h[i] - h[i]) = c[m] - B[m]*h[i]... 

Wait, c[m] is the current value. If we change h[i] from its current value to h_new:
new_c[m] = c[m] + B[m] * (h_new - h[i])

We want to find h_new ∈ [0,1] that minimizes max_m new_c[m] = max_m (c[m] + B[m]*(h_new - h[i]))

Let A[m] = c[m] - B[m]*h[i] (the "intercept" when h_new=0)
Then new_c[m] = A[m] + B[m]*h_new

We want to minimize max_m (A[m] + B[m]*h) over h ∈ [0,1].

This is a 1D convex piecewise-linear minimization. The optimal h is where the two "tightest" lines cross at the maximum.

Algorithm:
1. Compute T[m] = A[m] + B[m]*h for h=0: T0[m] = A[m]
2. Compute T[m] at h=1: T1[m] = A[m] + B[m]
3. If max(T0) ≤ max(T1): the function is increasing on [0,1] (or flat), so h*=0
4. If max(T0) > max(T1): might be optimum in interior
5. More generally: the function f(h) = max_m (A[m] + B[m]*h) is convex piecewise linear
   - Its minimum is at h* where the subgradient contains 0
   - In 1D: f is decreasing for h < h* and increasing for h > h*
   - At h*, the max is achieved by at least two lines (or one line with B=0)

Efficient algorithm:
- Sort lines by slope B[m]
- The upper envelope (max) changes at intersection points
- Find the point where the slope of the upper envelope changes from negative to positive

Simpler approach for small n: just evaluate f(h) at a few points and use ternary search or bisection.

Even simpler: since f(h) is convex, use the fact that the minimum is at:
h* = (A[m2] - A[m1]) / (B[m1] - B[m2])

Actually, for a convex piecewise-linear function in 1D, the minimum can be found exactly:
- The function is the max of linear functions
- The minimum is at a "vertex" of the upper envelope, which is an intersection of two lines
- Or at a boundary (h=0 or h=1)

Algorithm:
1. Compute h_left = 0, h_right = 1
2. At h_left, find the line m_l achieving the max
3. At h_right, find the line m_r achieving the max
4. If m_l == m_r: the function is linear on [h_left, h_right], min at endpoint with smaller value
5. If m_l != m_r:
   a. If B[m_l] == B[m_r]: can't intersect (parallel), min at endpoint
   b. Intersection h* = (A[m_r] - A[m_l]) / (B[m_l] - B[m_r])
   c. If h* < h_left: min is at h_left
   d. If h* > h_right: min is at h_right
   e. If h_left ≤ h* ≤ h_right: check if at h*, the max is indeed achieved by m_l and m_r
      (i.e., A[m] + B[m]*h* ≤ A[m_l] + B[m_l]*h* for all m)
      If yes, h* is the optimum
      If no, recursion: the new max line at h* gives a tighter bound

        # where the subgradient contains 0

    # Better: just do a few bisection steps

        # Subgradient: the slope of the upper envelope at mid
        # = B[m] for m achieving the max at mid
        vals = A + B * mid
        m_max = vals.argmax()
        # If B[m_max] < 0, the function is decreasing at mid, so optimum is to the right
        if B[m_max] < -1e-15:

        elif B[m_max] > 1e-15:
            hi = mid
        else:
            break  # B[m_max] ≈ 0, we're at the minimum
        # If B[m_max] == 0, the function is flat at this point (local min)
        # But there might be multiple lines achieving the max with different slopes
        # Check all lines achieving the max
        max_val = vals[m_max]
        active = np.where(np.abs(vals - max_val) < 1e-12)[0]
        slopes = B[active]
        if slopes.min() <= 0 <= slopes.max():
            break  # 0 is in the subgradient, this is the minimum
        if slopes.max() < 0:
            lo = mid
        else:
            hi = mid
    
    h_new = 0.5 * (lo + hi)
    return h_new

def binary_local_search(h, n, max_rounds=500, time_limit=30):
    t0 = time.time()
    best_h = np.where(h > 0.5, 1.0, 0.0).astype(float)
    best_h = project_feasible(best_h, n)
    best_c = np.correlate(best_h, 1 - best_h, mode='full').astype(float)
    best_mc = best_c.max()
    
    for _ in range(max_rounds):
        if time.time() - t0 > time_limit:
            break
        
        # Precompute profiles
        # P[p, m] = 1 if the contribution of position p to c[m], else 0
        # Actually P[p, m] = (1 - 0) * 1[0<=p+m-(n-1)<n] - 1 * 0 * 1[0<=p-m+(n-1)<n]
        # For binary h, the profile of flipping position p from 0 to 1:
        # Δc[m] = (1-h[p+m-(n-1)]) * 1[valid] - h[p-m+(n-1)] * 1[valid]
        # For binary h with h[p]=0:
        # Term 1: (1-h[p+m-(n-1)]) for valid indices
        # Term 2: -h[p-m+(n-1)] for valid indices
        # But this is the same as coord_gradient_vec!
        
        # For a swap (i: 0->1, j: 1->0):
        # Δc = B_i - B_j (where B_i is the gradient for position i, B_j for position j)
        # Wait no. If h[i] goes from 0 to 1, Δc = B_i * 1 = B_i
        # If h[j] goes from 1 to 0, Δc = B_j * (-1) = -B_j
        # Total: Δc = B_i - B_j
        
        # But B depends on h! When we flip, the B values change.
        # However, for a SINGLE flip, the linearization is exact (c is linear in each h[i]).
        # So: new_c = c + B_i(h) * 1 - B_j(h) * 1 = c + B_i - B_j
        # Where B_i and B_j are computed at the CURRENT h (before the flip).
        
        # Precompute all B vectors
        B_all = np.zeros((n, 2*n-1))
        for p in range(n):
            B_all[p] = coord_gradient_vec(best_h, n, p)
        
        ones = np.where(best_h > 0.5)[0]
        zeros = np.where(best_h <= 0.5)[0]
        
        # For each (i, j) pair: new_c = c + B_all[i] - B_all[j]
        # We want max(new_c) < best_mc
        
        # Vectorized: for each i in zeros, new_c[j_idx, m] = c[m] + B_all[i, m] - B_all[j_idx, m]
        # max over m: new_max[j_idx] = max_m (c[m] + B_all[i, m] - B_all[j_idx, m])
        
        best_gain = 0
        best_i, best_j = -1, -1
        
        B_zeros = B_all[zeros]  # (n_zeros, 2n-1)
        B_ones = B_all[ones]    # (n_ones, 2n-1)
        
        for i_idx in range(len(zeros)):
            # diff[j_idx, m] = B_zeros[i_idx, m] - B_ones[j_idx, m]
            # new_max[j_idx] = max_m (c[m] + diff[j_idx, m])
            new_vals = best_c[None, :] + B_zeros[i_idx][None, :] - B_ones
            new_max = new_vals.max(axis=1)
            j_best = new_max.argmin()
            gain = best_mc - new_max[j_best]
            if gain > best_gain:
                best_gain = gain
                best_i = zeros[i_idx]
                best_j = ones[j_best]
        
        if best_gain > 1e-10:
            best_h[best_i] = 1.0
            best_h[best_j] = 0.0
            best_c = np.correlate(best_h, 1 - best_h, mode='full').astype(float)
            best_mc = best_c.max()
        else:
            break
    
    return best_h, best_mc
