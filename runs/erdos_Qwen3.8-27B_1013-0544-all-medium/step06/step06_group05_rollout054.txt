But computing c_{worst_k} for all swaps is O(n²) which is fine for n=250 (62500 operations).

Actually, let me think about this differently. For a given worst lag k*, the overlap c_{k*} = sum_i h[i]*(1-h[i+k*]). 

To reduce c_{k*}, we need to either:
- Set h[i] = 0 where h[i+k*] = 0 (removes a 1 from the "bad" set)
- Set h[j+k*] = 1 where h[j] = 1 (removes a 0 from the "bad" set)

In terms of a swap (i goes 1→0, j goes 0→1):
c_{k*} changes by: -(1-h[i+k*]) + h[i-k*] + (1-h[j+k*]) - h[j-k*]

For this to be negative (reduce c_{k*}):
(1-h[i+k*]) - h[i-k*] > (1-h[j+k*]) - h[j-k*]

Let me define:
A(i) = (1-h[i+k*]) - h[i-k*]  (contribution of turning h[i] from 1 to 0)
B(j) = (1-h[j+k*]) - h[j-k*]  (contribution of turning h[j] from 0 to 1)

We want A(i) > B(j).

So: pick i from {ones} with large A(i), and j from {zeros} with small B(j).

This gives us an O(n) algorithm per step!

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(c) * dx)

def get_corr(h, n):
    return np.correlate(h, 1.0 - h, mode='full').astype(np.float64)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-10:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = np.clip(h + diff / s * room, 0.0, 1.0)
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = np.clip(h + diff / s * h, 0.0, 1.0)
    return np.clip(h, 0.0, 1.0)

def swap_delta(h, n, i, j):
    k = np.arange(-(n - 1), n)
    delta = np.zeros(2 * n - 1)
    ipk = i + k
    m = (ipk >= 0) & (ipk < n)
    delta[m] -= (1.0 - h[ipk[m]])
    ik = i - k
    m = (ik >= 0) & (ik < n)
    delta[m] += h[ik[m]]
    jpk = j + k
    m = (jpk >= 0) & (jpk < n)
    delta[m] += (1.0 - h[jpk[m]])
    jk = j - k
    m = (jk >= 0) & (jk < n)
    delta[m] -= h[jk[m]]
    return delta
