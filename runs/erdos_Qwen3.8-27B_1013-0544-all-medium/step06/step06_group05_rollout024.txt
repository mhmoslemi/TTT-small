For n=250 with 125 ones, a simple pattern would be: 125 ones followed by 125 zeros. But this has O(l) = 125 for l=1 (all the ones at the boundary transition to zeros).

A better pattern: alternating blocks. E.g., blocks of size b: 11...1 00...0 11...1 00...0 ...

With block size b, the number of transitions at distance l:
- For l < b: transitions occur at block boundaries. Number of boundaries ≈ n/(2b). At each boundary, exactly 1 transition. So O(l) ≈ n/(2b) for l < b.
- But also, within a block, if you shift by l < b, you still have the same pattern (all 1s or all 0s), so no additional transitions.

Wait, that's not right. For a block pattern with block size b:
h = [1]*b + [0]*b + [1]*b + [0]*b + ...

For lag l (0 < l < b):
O(l) = number of i where h[i]=1 and h[i+l]=0
This happens at the right edge of each 1-block: i is in the last l positions of a 1-block, and i+l is in the first l positions of the adjacent 0-block.
Number of such i per block boundary: l (the last l positions of the 1-block)
Number of boundaries: n/(2b)
So O(l) = l * n/(2b)

This is maximized at l = b-1: O(b-1) ≈ b * n/(2b) = n/2.

That's bad! The maximum overlap is n/2 * dx = n/2 * 2/n = 1. Way too high.

So block patterns are bad. What about a more "random" arrangement?

For a random 0/1 signal with n/2 ones, the expected O(l) ≈ n/4 for each l (by symmetry, about half the 1s will be followed by a 0 at distance l). The maximum over all l would be around n/4 + some fluctuation.

n/4 * dx = n/4 * 2/n = 1/2 = 0.5. Still too high.

def smooth_max_obj_and_grad(h, n, alpha):
    """Compute smooth max of O_k and its gradient."""
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full') * dx  # shape (2n-1,)
    m = corr.max()
    # Softmax weights
    shifted = alpha * (corr - m)
    max_shifted = shifted.max()
    weights = np.exp(shifted - max_shifted)
    weights /= weights.sum()
    
    # Objective value
    obj = m + np.log(weights.sum()) / alpha  # = m + (max_shifted + log(sum(exp(shifted-max_shifted))))/alpha

    # = m + (1/alpha) * (max_shifted + log(sum exp(shifted - max_shifted)))
    # = m + (1/alpha) * (max_shifted + log(weights.sum() * exp(0)))  # since weights = exp(shifted-max)/sum(exp(shifted-max))

    obj = m + (max_shifted + np.log(np.exp(shifted - max_shifted).sum())) / alpha
    
    # Gradient: sum_k weights_k * dO_k/dh
    # dO_k/dh[j] = dx * [(1-h[j+l_k]) if valid] - dx * [h[j-l_k] if valid]
    # where l_k = k - (n-1)
    
    grad = np.zeros(n)
    # Only use top weights for efficiency
    top_idx = np.argsort(weights)[-20:]  # top 20 lags
    for k in top_idx:

        if weights[k] < 1e-10:
            continue

        # Term 1: (1-h[j+l]) for j+l in [0,n)
        if l >= 0:
            j_range = np.arange(n - l)
            grad[j_range] += weights[k] * dx * (1.0 - h[j_range + l])
        else:
            j_range = np.arange(-l, n)
            grad[j_range] += weights[k] * dx * (1.0 - h[j_range + l])
        # Term 2: -h[j-l] for j-l in [0,n)
        if l >= 0:
            j_range = np.arange(l, n)
            grad[j_range] -= weights[k] * dx * h[j_range - l]
        else:
            j_range = np.arange(n + l)
            grad[j_range] -= weights[k] * dx * h[j_range - l]
    
    return obj, grad

For each lag l, the gradient of O_l with respect to h is:
g_l[j] = dx * (1-h[j+l]) * 1[0≤j+l<n] - dx * h[j-l] * 1[0≤j-l<n]

This can be written as:
g_l = dx * ((1-h) shifted by -l) - dx * (h shifted by l)

where "shifted by -l" means the i-th element is (1-h)[i-l] if valid, 0 otherwise.

So: g_l = dx * (corr(1-h, delta_{-l}) - corr(h, delta_{l}))

where delta_l is a spike at position l.

Actually, let me think of it differently. Define:
- A_l[j] = (1-h)[j+l] if 0≤j+l<n, else 0  (this is (1-h) shifted left by l, zero-padded)
- B_l[j] = h[j-l] if 0≤j-l<n, else 0  (this is h shifted right by l, zero-padded)

Then g_l[j] = dx * (A_l[j] - B_l[j])

And the total gradient is: grad[j] = sum_k w_k * dx * (A_{l_k}[j] - B_{l_k}[j])

For the top few lags, this is efficient. Let me just loop over the top lags.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = np.clip(h + diff / s * room, 0.0, 1.0)
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = np.clip(h + diff / s * h, 0.0, 1.0)
    return np.clip(h, 0.0, 1.0)

def obj_and_grad(x, n, alpha, top_k=10):
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode='full') * dx
    m = corr.max()
    shifted = alpha * (corr - m)
    max_s = shifted.max()
    exp_s = np.exp(shifted - max_s)
    w = exp_s / exp_s.sum()
    obj = m + (max_s + np.log(exp_s.sum())) / alpha
    
    grad = np.zeros(n)
    # Use only top-k lags by weight
    top_idx = np.argsort(w)[-top_k:]
    for k in top_idx:
        if w[k] < 1e-8:
            continue
        l = k - (n - 1)
        if l >= 0:
            # (1-x)[j+l] valid for j in [0, n-1-l]
            j1 = np.arange(n - l)
            grad[j1] += w[k] * dx * (1.0 - x[j1 + l])
            # x[j-l] valid for j in [l, n-1]
            j2 = np.arange(l, n)
            grad[j2] -= w[k] * dx * x[j2 - l]
        else:
            # (1-x)[j+l] valid for j in [-l, n-1]
            j1 = np.arange(-l, n)
            grad[j1] += w[k] * dx * (1.0 - x[j1 + l])
            # x[j-l] valid for j in [0, n-1+l]
            j2 = np.arange(n + l)
            grad[j2] -= w[k] * dx * x[j2 - l]
    return obj, grad

def slsqp_optimize(h, n, alpha, maxiter=2000, deadline=None, top_k=10):
    dx = 2.0 / n
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x: x.sum() - n/2.0, 'jac': lambda x: np.ones(n)}]
    
    def fun(x):
        if deadline is not None and time.time() > deadline:
            raise Exception("timeout")
        return obj_and_grad(x, n, alpha, top_k)[0]
    
    def fprime(x):
        if deadline is not None and time.time() > deadline:
            raise Exception("timeout")
        return obj_and_grad(x, n, alpha, top_k)[1]
    
    try:
        res = minimize(fun, h, jac=fprime, method='SLSQP', bounds=bounds,
                      constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-14})
        return project_feasible(res.x, n)
    except Exception:
        return h
