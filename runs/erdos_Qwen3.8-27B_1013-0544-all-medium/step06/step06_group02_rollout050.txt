```python
                    return best_h, best_c
```

- The optimal t* minimizes max_k (C_k + t * d_k) over t ∈ [t_min, t_max]
- Since this is a 1D convex piecewise linear minimization, I can solve it efficiently

The key observation: the minimum of max_k (C_k + t*d_k) is the smallest value V such that C_k + t*d_k ≤ V for all k and t ∈ [t_min, t_max]. This is equivalent to: for all k, t ∈ [t_min, t_max], C_k + t*d_k ≤ V.

The optimal (t*, V*) can be found by:
V* = max_k min_{t ∈ [t_min, t_max]} (C_k + t*d_k) ... no that's not right either.

Actually, V* = min_{t ∈ [t_min, t_max]} max_k (C_k + t*d_k)

This is a min-max problem. By minimax theorem (since it's linear in both t and the "max" selection), V* = max_k (C_k + t*_k * d_k) where t*_k is the optimal t for line k.

```python
def find_optimal_t(C0, d, t_min, t_max, n_iter=60):
    """Find t in [t_min, t_max] that minimizes max_k (C0[k] + t*d[k])."""
    lo, hi = t_min, t_max
    for _ in range(n_iter):
        mid = (lo + hi) / 2
        # Compute f(mid) = max_k (C0[k] + mid * d[k])
        vals = C0 + mid * d
        f_mid = vals.max()
        active = vals >= f_mid - 1e-15
        # Subgradient at mid: [min d[active], max d[active]]
        sgmin = d[active].min()
        sgmax = d[active].max()
        if sgmin <= 0 <= sgmax:
            break
        elif sgmax < 0:
            lo = mid
        else:  # sgmin > 0
            hi = mid
    return (lo + hi) / 2
```
