from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)

    target = n // 2
    idx = np.argsort(h)[::-1]
    b = np.zeros(n)
    b[idx[:target]] = 1.0

def binary_sa(h_init, n, deadline, seed=42, t0=0.5, t1=0.001):
    """Simulated annealing on binary sequences using full correlation recomputation."""
    dx = 2.0 / n
    h = h_init.copy()
    corr = np.correlate(h, 1 - h, mode='full')
    cur_c = float(corr.max())
    best_c = cur_c

    rng = np.random.RandomState(seed)

            break

        j = int(rng.choice(ones))

            ones = np.where(h == 1)[0]

def smooth_continuous(h_bin, n, deadline, seed=42):
    """Continuous optimization using gradient-based method on smoothed objective."""
    dx = 2.0 / n
    h = h_bin.astype(float).copy()
    rng = np.random.RandomState(seed)
    
    best_h = h.copy()
    best_c = compute_c5(h, n)
    
    alphas = [100, 500, 2000, 10000, 50000, 200000]
    for alpha in alphas:
        if time.time() > deadline - 5:
            break
        # Gradient descent with projection
        lr = 0.01 / alpha
        for it in range(200):

                break
            corr = np.correlate(h, 1 - h, mode='full') * dx
            c_max = corr.max()
            # Softmax weights

            p = np.exp(shifted)
            p /= p.sum()

            h_new = project_feasible(h_new, n)
            
            c_new = compute_c5(h_new, n)
            if c_new < best_c:
                best_c = c_new
                best_h = h_new.copy()
            h = h_new

Actually, let me use a different approach for the continuous phase: **alternating optimization**.

**Key insight**: The objective f(h) = max_k c_k(h) where c_k = sum_i h[i]*(1-h[i+k]) is bilinear in h. If we fix h at all positions except one, c_k becomes linear in that position. So we can use coordinate descent!

For coordinate descent on position m:
c_k = A_k * h[m] + B_k * h[m]² + C_k (for k where m appears)
where the specific form depends on whether m appears as the first or second index.

Actually, since c_k is bilinear (degree 2 in h), fixing all other positions makes c_k quadratic in h[m]. So we can minimize the max of quadratics, which is a 1D problem per coordinate.

Let me think about this more carefully:
c_k = sum_i h[i]*(1-h[i+k-(n-1)])

For a fixed k, the terms involving h[m] are:
- h[m]*(1-h[m+k-(n-1)]) if m ∈ S_k (m is first index)
- h[m-k+(n-1)]*(1-h[m]) if m-k+(n-1) ∈ S_k (m is second index)

If both conditions hold (which happens when m+k-(n-1) = m-k+(n-1), i.e., k = n-1):
Term = h[m]*(1-h[m])

Otherwise, if m is first index (k ∈ [n-1-m, 2n-2-m]):
Term = h[m]*(1-h[m+k-(n-1)]) = h[m] * (1 - h[r]) where r = m+k-(n-1) is fixed

If m is second index (k ∈ [m, m+n-1]):
Term = h[m-k+(n-1)]*(1-h[m]) = h[s]*(1-h[m]) where s = m-k+(n-1) is fixed

So c_k as a function of h[m]:
- If k = n-1 and m is both: h[m] - h[m]²
- If m is first index only: h[m] * (1-h[r]) (linear in h[m])
- If m is second index only: h[s] - h[s]*h[m] (linear in h[m])
- If m is both first and second (different k values): could have quadratic term

Wait, for a given k, m can be first index AND second index simultaneously?
First: m ∈ S_k means m+k-(n-1) ∈ [0,n-1]
Second: m is second index means m-k+(n-1) ∈ [0,n-1] (and 0 ≤ m-k+(n-1) < n)

For m to be both: m+k-(n-1) ∈ [0,n-1] AND m-k+(n-1) ∈ [0,n-1]
The first gives: n-1-m ≤ k ≤ 2n-2-m
The second gives: m-(n-1) ≤ k ≤ m+n-1... wait, m-k+n-1 ∈ [0,n-1] → m+n-1-(n-1) ≤ k ≤ m+n-1-0 → m ≤ k ≤ m+n-1

So m is both when k ∈ [max(n-1-m, m), min(2n-2-m, m+n-1)]

For n=250, m=0: first gives k ∈ [249, 498], second gives k ∈ [0, 249]. Intersection: k=249=n-1. ✓
For n=250, m=100: first gives k ∈ [149, 348], second gives k ∈ [100, 349]. Intersection: k ∈ [149, 348].

So for k in the intersection, h[m] appears in both factors of the product:
h[m] * (1-h[m+k-(n-1)]) + h[m-k+(n-1)] * (1-h[m])

If m+k-(n-1) ≠ m-k+(n-1) (i.e., k ≠ n-1), these are two separate terms and c_k is still linear in h[m].

If k = n-1: h[m]*(1-h[m]) which is quadratic.

So for each k ≠ n-1, c_k is linear in h[m]. For k = n-1, c_k has a quadratic term h[m]-h[m]².

Therefore, f(h) = max_k c_k is the max of (at most one) quadratic and many linear functions of h[m]. This can be minimized in 1D!

This gives us a **coordinate descent** approach:
1. For each m, minimize f as a function of h[m] (with all other h fixed)
2. The 1D problem is: minimize max of {a linear function, one quadratic} over [0,1]
3. The quadratic is h[m]-h[m]² (concave), and the constraint is the max of linear functions (convex)
4. So we're minimizing a convex function on [0,1] → can use ternary search or bisection on the derivative

Actually, the max of a concave quadratic and linear functions is not necessarily convex. Let me think again...

c_{n-1} = h[m]*(1-h[m]) + (other terms not involving m) = -h[m]² + h[m] + const

This is concave in h[m]. The other c_k are linear in h[m]. The max of a concave function and linear functions is... not necessarily convex or concave.

So coordinate descent might not converge. But it might still work in practice.

        i = rng.randint(n)
        j = rng.randint(n)
        if h[i] == h[j]:  # Same value, skip

        # Ensure i is 0 and j is 1
        if h[i] == 0:
            pass
        else:
            i, j = j, i
        
        # Do swap
        h[i], h[j] = 1.0, 0.0
        new_c = float(np.correlate(h, 1-h, mode='full').max())

                best_c = cur_c
                best_h = h.copy()
        else:
            h[i], h[j] = 0.0, 1.0

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:

            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + diff / s * h
