Let me also reconsider the learning rate. The issue is that for large α, the gradient becomes very large (proportional to α in the log-sum-exp), but the effective "direction" is toward reducing the maximum. The step size should be small enough to not overshoot.

For the log-sum-exp approximation:
L(α) = m + (1/α) log(∑ exp(α(c_k - m)))

As α → ∞, L(α) → m = max(c_k).
The gradient ∇L(α) → subgradient of max (the average of active subgradients).

For finite α, the gradient magnitude scales as O(1) (not O(α)), because the 1/α factor cancels the α in the exponent difference. Let me verify:

∇L = ∑_k w_k * ∇c_k * dx

where w_k = exp(α(c_k - m)) / ∑ exp(α(c_l - m)). As α → ∞, w_k → 1/|A| for k in A (active set), 0 otherwise. So ∇L → (1/|A|) ∑_{k∈A} ∇c_k * dx, which is O(1) (bounded by dx * max |∇c_k| ≈ dx * n * 1 = 2 * 1 = 2... wait, |∇c_k| ≤ 2 for binary h (since each term is at most 1 in absolute value and there are at most 2 contributions per h[i])).

Actually, for general h ∈ [0,1]: |∂c_k/∂h[i]| ≤ |(1-h[i+k])| + |h[i-k]| ≤ 2. So |∇L| ≤ 2*dx per component, and the norm is ≤ 2*dx*√n ≈ 2*(2/400)*20 ≈ 0.2.

So the gradient is bounded! This means a fixed learning rate should work. The issue is more about the curvature (Hessian) which determines the step size for convergence.
