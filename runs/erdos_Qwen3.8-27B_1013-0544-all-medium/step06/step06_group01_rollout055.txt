```python
                if abs(d) < 1e-14:
                    continue
                new_c = c_aff + d * s
                if has_center and len(ci) > 0:
                    new_c[ci] -= d * d
                val = max(um, float(new_c.max()))
                if val < best_val:
                    best_val, best_d = val, d
            
            if abs(best_d) > 1e-10 and best_val < cur_max - 1e-12:
                c[ks] = c_aff + best_d * s
                if has_center and len(ci) > 0:
                    c[n-1] -= best_d * best_d
                h[p] += best_d
                cur_max = max(um, float(c[ks].max()))
                improved = True
        if not improved:
            break
    return h, cur_max * (2.0 / n)
```

This is O(n² × grid) per pass. For n=300: 300 × 300 × 40 = 3.6M per pass. With 100 passes: 360M. In Python with numpy, this should be manageable in ~30-60s.
