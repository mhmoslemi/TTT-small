```python
def compute_grad_smoothed(h, n, alpha):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full') * dx
    m = c.max()
    shifted = alpha * (c - m)
    max_s = shifted.max()
    exp_s = np.exp(shifted - max_s)
    w = exp_s / exp_s.sum()
    
    # Vectorized gradient computation
    # For each j, grad[j] = dx * sum_k w[k] * [(1-h[j+k]) - h[j-k]] (with bounds)
    # Create index matrices
    j_idx = np.arange(n)[:, None]  # n x 1
    k_idx = np.arange(-(n-1), n)[None, :]  # 1 x (2n-1)
    
    # j+k: shape n x (2n-1)
    jk = j_idx + k_idx
    jmk = j_idx - k_idx
    
    valid_jk = (jk >= 0) & (jk < n)
    valid_jmk = (jmk >= 0) & (jmk < n)
    
    # (1-h[jk]) where valid, 0 otherwise
    one_minus_h = np.zeros((n, 2*n-1))
    one_minus_h[valid_jk] = 1.0 - h[jk[valid_jk]]
    
    h_vals = np.zeros((n, 2*n-1))
    h_vals[valid_jmk] = h[jmk[valid_jmk]]
    
    w_row = w[None, :]  # 1 x (2n-1)
    grad = dx * (w_row * one_minus_h - w_row * h_vals).sum(axis=1)
    
    obj = m + (max_s + np.log(exp_s.sum())) / alpha
    return grad, obj
```

∂²g_k/∂h[j]∂h[l] = -dx * I(l = j+k) - dx * I(l = j-k)

So the spectral norm of ∇²g_k is at most 2*dx = 4/n = 0.01.

For the smoothed max, the Hessian involves:
∇²f = sum_k w_k * ∇²g_k + alpha * sum_k l_k * (∇g_k * ∇g_k^T - ... )

The second term (from the log-sum-exp) has norm at most alpha * max_k ||∇g_k||² ≤ alpha * 0.04.

So L (Lipschitz constant of gradient) ≤ 2*4/n + alpha*0.04 ≈ 0.02 + 0.04*alpha

For alpha = 100000: L ≈ 4000. So the optimal step size is 1/L = 0.00025.

This means for large alpha, we need small steps. With backtracking, this should be handled automatically.

            h_try, c = pgd(h_try, n, alpha, p5, max_it=8000)
            if c < best_c:
                best_c, best_h = c, h_try.copy()

    # Final project and verify
    best_h = project_feasible(best_h, n)
    best_c = compute_c5(best_h, n)
    return best_h, best_c, n
