def sa_binary(h, n, deadline, seed=42):
    """Simulated annealing for binary h."""
    rng = np.random.RandomState(seed)
    h = h.copy().astype(float)
    corr = np.correlate(h, 1-h, mode='full').astype(np.float64)
    curr_cost = corr.max()
    best_h = h.copy()
    best_cost = curr_cost
    
    n_ones = n // 2
    T = 3.0  # Initial temperature (in units of correlation)
    T_min = 0.01
    cool_rate = 0.9995
    k = 0
    
    while time.time() < deadline:
        ones_idx = np.where(h == 1)[0]
        zeros_idx = np.where(h == 0)[0]
        i = rng.choice(ones_idx)
        j = rng.choice(zeros_idx)
        if i == j:
            continue
        
        # Compute delta
        k_vals = np.arange(-(n-1), n)
        m_vals = k_vals + (n-1)
        delta = np.zeros(2*n-1)
        
        mask = (i + k_vals >= 0) & (i + k_vals < n)
        delta[m_vals[mask]] += h[i + k_vals[mask]]

        new_cost = new_corr.max()

                best_h = h.copy()
        
        k += 1
        if k % 100 == 0:
            T = max(T_min, T * cool_rate)
    
    return best_h, best_cost

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-12:
            break
        if diff > 0:

            s = room.sum()
            if s < 1e-14:

        else:
            s = h.sum()
            if s < 1e-14:

    """Compute delta in correlation when h[i] goes 1→0 and h[j] goes 0→1."""
    delta = np.zeros(2*n - 1)
    p_vals = np.arange(-(n-1), n)
    m_vals = p_vals + (n - 1)
    
    # For each lag p, the affected n indices are:
    # n1 = i - p (i as first)
    # n2 = j - p (j as first)  
    # n3 = i (i as second)
    # n4 = j (j as second)
    
    # Build a map: for each n that's affected, compute old and new term value
    # But this is expensive. Instead, let's handle the 4 contributions and subtract overlaps.
    
    # Contribution 1: i as first (n = i-p)
    mask1 = (i - p_vals >= 0) & (i - p_vals < n)
    # Contribution 2: j as first (n = j-p)
    mask2 = (j - p_vals >= 0) & (j - p_vals < n)
    # Contribution 3: i as second (n = i)
    # This affects only one p: p such that i+p is valid, i.e., p in [-(i), n-1-i]
    # Actually n=i is always valid as an index, but we need i+p to be valid: 0 ≤ i+p ≤ n-1
    mask3 = (i + p_vals >= 0) & (i + p_vals < n)
    # Contribution 4: j as second (n = j)
    mask4 = (j + p_vals >= 0) & (j + p_vals < n)

    # 1: -(1-h[i-p]) for valid
    if mask1.any():
        delta[m_vals[mask1]] -= (1.0 - h[i - p_vals[mask1]])

    if mask2.any():

**Clean approach**: For each affected (n, p) pair, compute the old and new term value directly.

The affected terms are at positions:
- (n=i-p, p) for valid i-p: term involves h[i] and h[i-p]
- (n=j-p, p) for valid j-p: term involves h[j] and h[j-p]
- (n=i, p) for valid i+p: term involves h[i+p] and h[i]
- (n=j, p) for valid j+p: term involves h[j+p] and h[j]

For each unique (n, p) pair that appears, compute:
old_term = h[n+p]*(1-h[n])
new_term = h'[n+p]*(1-h'[n])  where h' is h with i and j swapped
delta = new_term - old_term

This is O(1) per affected position. There are at most 4n affected positions (but many overlap), so at most 4n unique (n,p) pairs. For n=250, that's at most 1000 positions to check.

But actually, for a given (i,j), the affected (n,p) pairs are:
- (i-p, p) for all p where 0 ≤ i-p ≤ n-1: these are p in [i-(n-1), i], giving n values
- (j-p, p) for all p where 0 ≤ j-p ≤ n-1: p in [j-(n-1), j], giving n values
- (i, p) for all p where 0 ≤ i+p ≤ n-1: p in [-i, n-1-i], giving n values
- (j, p) for all p where 0 ≤ j+p ≤ n-1: p in [-j, n-1-j], giving n values

The total number of unique p values is at most 4n, but since p ranges over [-(n-1), n-1] (2n-1 values), it's at most 2n-1.

For each p, the affected n values are: {i-p, j-p, i, j} (deduplicated). So for each p, at most 4 n values are affected.

Total work: O(n) for iterating over p, and O(1) for each p. So O(n) total, which is the same as before.

Let me just implement it directly:

```python
def compute_delta(h, i, j, n):
    delta = np.zeros(2*n - 1)
    p_min = max(-(n-1), i-(n-1), j-(n-1), -i, -j)
    p_max = min(n-1, i, j, n-1-i, n-1-j)
    # Actually, let's just iterate over all p in [-(n-1), n-1]
    for p in range(-(n-1), n):
        affected_ns = set()
        if 0 <= i - p < n:
            affected_ns.add(i - p)
        if 0 <= j - p < n:
            affected_ns.add(j - p)
        if 0 <= i + p < n:
            affected_ns.add(i)
        if 0 <= j + p < n:
            affected_ns.add(j)
        
        for nn in affected_ns:
            if not (0 <= nn < n and 0 <= nn + p < n):
                continue
            # Old term
            old_val = h[nn + p] * (1.0 - h[nn])
            # New term (with i and j swapped)
            np_val = h[nn + p]
            nn_val = h[nn]
            # Apply swap: if nn+p == i, np_val becomes 0; if nn+p == j, np_val becomes 1
            # if nn == i, nn_val becomes 0; if nn == j, nn_val becomes 1
            new_np = np_val
            new_nn = nn_val
            if nn + p == i:
                new_np = 0.0
            elif nn + p == j:
                new_np = 1.0
            if nn == i:
                new_nn = 0.0
            elif nn == j:
                new_nn = 1.0
            new_val = new_np * (1.0 - new_nn)
            delta[p + (n-1)] += new_val - old_val
    
    return delta
```

This is O(n) per swap (iterating over at most 2n-1 values of p, with at most 4 affected n per p). For n=250, that's ~500 iterations per swap. In pure Python, this might be slow (~100μs per swap), giving ~10K swaps/sec. Over 600 seconds, that's 6M swaps. Should be enough.

But actually, I realize I can be even more efficient. Instead of computing the full delta array, I only need to check if max(corr + delta) < curr_max (for local search) or compute new_max for SA. 

For local search: I need max(corr + delta) < curr_max. This is equivalent to: for all k, corr[k] + delta[k] < curr_max. Since corr[k] ≤ curr_max for all k, the only k that could violate are those where corr[k] is close to curr_max AND delta[k] > 0.

So I can precompute the set of "critical" k values (those where corr[k] ≥ curr_max - threshold), and only check those. If none of the critical k values have delta[k] > 0, the swap is definitely accepted. If some do, I need to check the full max.

For SA: I need the exact new_max. But I can compute it as max(max(corr + delta at critical positions), max(corr at non-critical positions)). The second term is at most curr_max (and equals curr_max if there's a critical position not in the support of delta).
