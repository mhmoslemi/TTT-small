**Alternative: Use the structure of the problem**

For a binary sequence, C₅ = max_s T(s) * dx where T(s) = #{i: h[i]=1, h[i+s]=0} (for s>0) and similarly for s<0.

Note that T(s) + T(-s) ≤ n - |s| (the number of valid pairs at shift s).
Also, T(s) + #{i: h[i]=1, h[i+s]=1} = #{i: h[i]=1, i+s < n} (for s > 0).

The key insight: if we define A = #{ones} = n/2, then for shift s > 0:
T(s) + O(s) = min(A, n-s) where O(s) = #{i in [0, n-1-s]: h[i]=1, h[i+s]=1}

So T(s) = min(A, n-s) - O(s).

To minimize max_s T(s), we want to maximize min_s O(s) (approximately).

This is related to the concept of a "Golomb ruler" or "B-sequence" but that's for distinct differences.

```python
def binary_sa_fast(h0, n, deadline, t_start=0.05, t_end=1e-5, max_iters=2000000, seed=42):
    hb = to_binary(h0, n)
    one_minus_h = 1.0 - hb
    cur_c = compute_c5(hb, n)
    best_h = hb.copy()
    best_c = cur_c
    rng = np.random.RandomState(seed)
    T = t_start
    cool = (t_end / t_start) ** (1.0 / max(max_iters, 1))
    
    for it in range(max_iters):
        if time.time() > deadline:
            break
        ones = np.where(hb == 1)[0]
        zeros = np.where(hb == 0)[0]
        i = zeros[rng.randint(len(zeros))]
        j = ones[rng.randint(len(ones))]
        
        # Flip: h[i] 0→1, h[j] 1→0
        hb[i] = 1.0; one_minus_h[i] = 0.0
        hb[j] = 0.0; one_minus_h[j] = 1.0
        new_c = float(np.max(np.correlate(hb, one_minus_h, mode='full')) * (2.0/n))
        
        if new_c <= cur_c or rng.random() < np.exp(-(new_c - cur_c) / max(T, 1e-15)):
            cur_c = new_c
            if new_c < best_c:
                best_c = new_c
                best_h = hb.copy()
        else:
            hb[i] = 0.0; one_minus_h[i] = 1.0
            hb[j] = 1.0; one_minus_h[j] = 0.0
        
        T *= cool
    
    return best_h, best_c
```

def project_feasible(h, n):
