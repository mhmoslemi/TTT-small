Actually, I realize I can be smarter about the correlation update. When I swap positions i and j:
- h[i] changes from 1 to 0 (Δh_i = -1)
- h[j] changes from 0 to 1 (Δh_j = +1)

The correlation C[m] = Σ_k h[k] * (1 - h[k+m-n+1])

Change in C[m]:
- From h[i]: -1 * (1-h[i+m-n+1]) [if i+m-n+1 in range]
- From h[j]: +1 * (1-h[j+m-n+1]) [if j+m-n+1 in range]
- From (1-h[i]) terms: -1 * h[i+m-n+1] [if i+m-n+1 in range, this is the term where i is in the (1-h) position]
  Wait, I need to be more careful.

C[m] = Σ_k h[k] * (1-h[k+m-n+1])

The term involving h[i]:
- k=i: h[i] * (1-h[i+m-n+1]) → changes by Δh[i] * (1-h[i+m-n+1]) = -1*(1-h[i+m-n+1])
- k+m-n+1=i, i.e., k=i-m+n-1: h[k]*(1-h[i]) → changes by h[k]*(-Δh[i]) = h[i-m+n-1]*1 = h[i-m+n-1]

Similarly for h[j]:
- k=j: Δh[j] * (1-h[j+m-n+1]) = 1*(1-h[j+m-n+1])
- k=j-m+n-1: h[k]*(-Δh[j]) = -h[j-m+n-1]

So ΔC[m] = -(1-h[i+m-n+1]) + h[i-m+n-1] + (1-h[j+m-n+1]) - h[j-m+n-1]
(for valid indices, 0 otherwise)

This is O(1) per m, so O(n) total to update the correlation. Much faster than O(n²) for full recompute!

        p = i - m + n - 1
        if 0 <= p < n:

        if 0 <= p < n:

            j = zeros[rng.randint(len(zeros))]

                corr = new_corr
                best_c5 = min(best_c5, new_c5)  # Track global best
                ones.remove(i)
                zeros.remove(j)
                ones.append(j)
                zeros.append(i)

        # Cool
        T = max(T * 0.7, T_min)
        if T == T_min:

    n = len(h)
    dx = 2.0 / n
    corr = compute_corr(h)
    best_c5 = float(np.max(corr) * dx)
    
    for _ in range(200):  # max outer iterations
        if time.time() > deadline:
            break
        for i in range(n):

            G = np.zeros(2*n-1)
            # h[i] as first factor: C[m] includes h[i]*(1-h[i+m-n+1])

                p2 = i - m + n - 1
                if 0 <= p2 < n:
                    G[m] -= h[p2]

            # Binary search for optimal h[i]
            lo_d, hi_d = -old, 1.0 - old

Wait, the coordinate descent without sum constraint will move h towards 0 (since decreasing all h decreases all correlations). I need to handle the sum constraint.

The issue is: the coordinate descent as I've formulated it minimizes max_k corr(k) subject to 0 ≤ h[i] ≤ 1, WITHOUT the sum constraint. This will drive all h[i] → 0.

To handle the sum constraint, I have a few options:
1. Add a Lagrange multiplier: minimize max_k corr(k) + λ * (sum(h) - n/2)
   This is equivalent to minimizing max_k (corr(k) + λ) subject to 0 ≤ h ≤ 1, for the right λ.
   But this doesn't directly help.

2. After coordinate descent, project back to the constraint set. But this might undo the improvements.

3. Do coordinate descent where at each step, I change h[i] and h[j] simultaneously (one up, one down) to maintain the sum.

Option 3 is clean: "2-coordinate" descent where I swap mass between two positions.

Let me implement option 3:

For a pair (i, j), I move δ from position j to position i:
h[i] += δ, h[j] -= δ
Constraint: 0 ≤ h[i]+δ ≤ 1, 0 ≤ h[j]-δ ≤ 1
So δ ∈ [max(0, h[i]-1+0)... wait:
- h[i]+δ ≤ 1 → δ ≤ 1-h[i]
- h[j]-δ ≥ 0 → δ ≤ h[j]
- h[i]+δ ≥ 0 → δ ≥ -h[i]
- h[j]-δ ≤ 1 → δ ≥ h[j]-1

So δ ∈ [max(-h[i], h[j]-1), min(1-h[i], h[j])]

The change in correlation:
ΔC[m] = δ * G_i[m] - δ * G_j[m] = δ * (G_i[m] - G_j[m])

where G_i[m] = dC[m]/dh[i] and G_j[m] = dC[m]/dh[j].

We want to find δ that minimizes max_m (C[m] + δ*(G_i[m] - G_j[m])).

This is the same 1D convex piecewise-linear optimization as before, just with a different range for δ.

This approach maintains the sum constraint automatically!

But the computational cost per step is O(n) to compute G_i and G_j, plus O(n) for the bisection. Per pair, that's O(n). If I check all pairs, that's O(n³) per full pass, which for n=200 is 8M operations. That's fine.

But checking all pairs is expensive. Let me do random pairs instead.

Actually, let me reconsider. The simplest approach that maintains the sum constraint:

**Greedy 2-swap for continuous case:**
1. Maintain h with sum = n/2
2. At each step, pick a random pair (i, j)
3. Find the optimal δ (mass transfer from j to i) that minimizes max corr
4. If it improves, accept
5. Repeat

This is like a continuous version of the binary 2-swap.

Let me implement this. The key subproblem is: given current corr C, and directions G_i - G_j, find δ in [δ_min, δ_max] that minimizes max_m (C[m] + δ * D[m]) where D = G_i - G_j.

This is the same bisection approach.

2. Continuous 2-swap coordinate descent (for fine-tuning)

            lo = mid

            hi = mid
    return np.clip(h-(lo+hi)/2.0, 0, 1)

    b = np.zeros(len(h))
    b[idx[:n_ones]] = 1.0
    return b

def compute_G(h, i, n):
    """Compute dC/dh[i] as a vector of length 2n-1."""
    G = np.zeros(2*n-1)
    # h[i] appears as first factor: C[m] has term h[i]*(1-h[i+m-n+1])
    # valid when 0 <= i+m-n+1 < n, i.e., n-1-i <= m <= 2n-2-i
    lo1 = max(0, n-1-i)
    hi1 = min(2*n-2, 2*n-2-i)
    for m in range(lo1, hi1+1):
        G[m] += (1.0 - h[i+m-n+1])
    # h[i] appears in (1-h) factor: C[m] has term h[i-m+n-1]*(1-h[i])
    # valid when 0 <= i-m+n-1 < n, i.e., i <= m <= i+n-1
    lo2 = max(0, i)
    hi2 = min(2*n-2, i+n-1)
    for m in range(lo2, hi2+1):
        G[m] -= h[i-m+n+1-1]  # h[i-m+n-1]
    return G

    lo, hi = delta_lo, delta_hi
    for _ in range(50):

        c = corr + mid * D
        k = int(np.argmax(c))
        if D[k] > 1e-14:
            hi = mid
        elif D[k] < -1e-14:
            lo = mid
        else:
            return mid
    return (lo+hi)/2.0

    best_c5 = float(np.max(corr) * dx)

        for _ in range(n_samples_per_iter):

                continue

            d_hi = min(1.0-h[i], h[j])
            if d_hi - d_lo < 1e-12:

            delta = solve_1d_corr(corr, D, d_lo, d_hi)

                h[i] += delta
                h[j] -= delta

                improved_this_iter = True
                no_improve = 0

            else:

    h_bin, c5_bin = binary_sa(h0, d1, rng)
    if c5_bin < best_c5:
        best_h, best_c5 = h_bin, c5_bin

    # Phase 2: Continuous 2-swap polish (20% of budget)

    h_cont, c5_cont = continuous_2swap(best_h, d2, rng)
    if c5_cont < best_c5:
        best_h, best_c5 = h_cont, c5_cont

    # Phase 3: Binary SA from structured start (15% of budget)
    d3 = t0 + budget_s * 0.70
    n_s = n0

    k = n_s // 2

    # Phase 4: Try n=100 (10% of budget)
    d4 = t0 + budget_s * 0.80
    n_small = 100
    h_small = np.array([(best_h[2*i] + best_h[2*(i+1)]) / 2.0 for i in range(n_small)])
    h_small = project_box_sum(h_small, n_small / 2.0)

    best_h = project_box_sum(best_h, len(best_h) / 2.0)
    final_c5 = compute_c5(best_h)
    return best_h, final_c5, len(best_h)

import numpy as np
import time

def compute_corr(h):
    return np.correlate(h, 1 - h, mode='full')

def compute_c5(h):
    n = len(h)
    return float(np.max(compute_corr(h)) * (2.0 / n))

def project_box_sum(h, target_sum):
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        if np.sum(np.clip(h - mid, 0, 1)) > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0, 1)

def make_binary(h, n_ones):
    idx = np.argsort(h)[::-1]
    b = np.zeros(len(h))
    b[idx[:n_ones]] = 1.0
    return b

def compute_G(h, i, n):
    G = np.zeros(2 * n - 1)
    lo1 = max(0, n - 1 - i)
    hi1 = min(2 * n - 2, 2 * n - 2 - i)
    for m in range(lo1, hi1 + 1):
        G[m] += (1.0 - h[i + m - n + 1])
    lo2 = max(0, i)
    hi2 = min(2 * n - 2, i + n - 1)
    for m in range(lo2, hi2 + 1):
        G[m] -= h[i - m + n - 1]
    return G

def bisect_1d(corr, D, d_lo, d_hi):
    lo, hi = d_lo, d_hi
    for _ in range(45):
        mid = (lo + hi) * 0.5
        k = int(np.argmax(corr + mid * D))
        if D[k] > 1e-14:
            hi = mid
        elif D[k] < -1e-14:
            lo = mid
        else:
            return mid
    return (lo + hi) * 0.5

def binary_sa(h_init, deadline, rng):
    n = len(h_init)
    n_ones = int(round(np.sum(h_init)))
    n_ones = max(1, min(n - 1, n_ones))
    h = make_binary(h_init, n_ones)
    corr = compute_corr(h)
    current_c5 = float(np.max(corr) * (2.0 / n))
    best_c5 = current_c5
    best_h = h.copy()
    T = 0.012
    T_min = 1e-7
    restarts = 0
    dx = 2.0 / n
    while time.time() < deadline:
        for _ in range(5000):
            if time.time() > deadline:
                return best_h, best_c5
            om = np.where(h == 1)[0]
            zm = np.where(h == 0)[0]
            i = int(om[rng.randint(om.size)])
            j = int(zm[rng.randint(zm.size)])
            h[i], h[j] = 0, 1
            nc = compute_corr(h)
            new_c5 = float(np.max(nc)) * dx
            d = new_c5 - current_c5
            if d < 0 or (T > T_min and rng.rand() < np.exp(-max(d, -100) / T)):
                corr = nc
                current_c5 = new_c5
                if new_c5 < best_c5:
                    best_c5 = new_c5
                    best_h = h.copy()
            else:
                h[i], h[j] = 1, 0
        T = max(T * 0.78, T_min)
        if T <= T_min * 1.001:
            restarts += 1
            if restarts > 6:
                break
            for _ in range(300):
                om = np.where(h == 1)[0]
                zm = np.where(h == 0)[0]
                i = int(om[rng.randint(om.size)])
                j = int(zm[rng.randint(zm.size)])
                h[i], h[j] = 0, 1
                nc = compute_corr(h)
                if float(np.max(nc)) * dx < current_c5:
                    corr = nc
                    current_c5 = float(np.max(nc)) * dx
                    break
                h[i], h[j] = 1, 0
            T = 0.006
    return best_h, best_c5

def continuous_2swap(h_init, deadline, rng):
    n = len(h_init)
    h = project_box_sum(h_init.copy(), n / 2.0)
    corr = compute_corr(h)
    current_c5 = float(np.max(corr))
    best_c5 = current_c5
    best_h = h.copy()
    dx = 2.0 / n
    while time.time() < deadline:
        for _ in range(3000):
            if time.time() > deadline:
                break
            i = rng.randint(n)
            j = rng.randint(n)
            if i == j:
                continue
            d_lo = max(-h[i], h[j] - 1.0)
            d_hi = min(1.0 - h[i], h[j])
            if d_hi - d_lo < 1e-12:
                continue
            D = compute_G(h, i, n) - compute_G(h, j, n)
            delta = bisect_1d(corr, D, d_lo, d_hi)
            c_new = corr + delta * D
            new_max = float(np.max(c_new))
            if new_max < current_c5 - 1e-14:
                corr = c_new
                h[i] += delta
                h[j] -= delta
                current_c5 = new_max
                if new_max < best_c5:
                    best_c5 = new_max
                    best_h = h.copy()
    return best_h, best_c5 * dx

def interpolate_to_n(h_old, n_new):
    n_old = len(h_old)
    x_old = np.linspace(0, 2, n_old, endpoint=False) + 1.0 / n_old
    x_new = np.linspace(0, 2, n_new, endpoint=False) + 1.0 / n_new
    h_ext = np.append(h_old, h_old[0])
    x_ext = np.append(x_old, 2.0 + 1.0 / n_old)
    return np.interp(x_new, x_ext, h_ext)

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    rng = np.random.RandomState(seed)
    if 'initial_h_values' in globals() and initial_h_values is not None:
        h0 = np.array(initial_h_values, dtype=float)
    else:
        h0 = np.full(200, 0.5)
    n0 = len(h0)
    best_h = h0.copy()
    best_c5 = compute_c5(h0)

    # Phase 1: Binary SA from initial (30% budget)
    d1 = t0 + budget_s * 0.30
    h_bin, c5_bin = binary_sa(h0, d1, rng)
    if c5_bin < best_c5:
        best_h, best_c5 = h_bin, c5_bin

    # Phase 2: Continuous 2-swap polish (20% budget)
    d2 = t0 + budget_s * 0.50
    h_cont, c5_cont = continuous_2swap(best_h, d2, rng)
    if c5_cont < best_c5:
        best_h, best_c5 = h_cont, c5_cont

    # Phase 3: Binary SA from random structured start (15% budget)
    d3 = t0 + budget_s * 0.65
    h_struct = np.zeros(n0)
    k = n0 // 2
    perm = rng.permutation(n0)
    h_struct[perm[:k]] = 1.0
    h_s2, c5_s2 = binary_sa(h_struct, d3, rng)
    if c5_s2 < best_c5:
        best_h, best_c5 = h_s2, c5_s2

    # Phase 4: Try n=100 (10% budget)
    d4 = t0 + budget_s * 0.75
    n_small = 100
    h_small = interpolate_to_n(best_h, n_small)
    h_small = project_box_sum(h_small, n_small / 2.0)
    h_sm, c5_sm = binary_sa(h_small, d4, rng)
    if c5_sm < best_c5:
        best_h, best_c5 = h_sm, c5_sm

    # Phase 5: Final continuous polish (remaining)
    d5 = t0 + budget_s - 5
    h_final, c5_final = continuous_2swap(best_h, d5, rng)
    if c5_final < best_c5:
        best_h, best_c5 = h_final, c5_final

    best_h = project_box_sum(best_h, len(best_h) / 2.0)
    final_c5 = compute_c5(best_h)
    return best_h, final_c5, len(best_h)
