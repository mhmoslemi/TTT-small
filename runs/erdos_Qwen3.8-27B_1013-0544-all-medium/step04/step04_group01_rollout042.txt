**Incremental correlation update:**

When we change h[i] by δ and h[j] by -δ (preserving the sum):
- The correlation c[s] changes for each shift s
- For shift s (corresponding to actual lag k = s - (n-1)):
  c[s] = sum_p h[p+k] * (1-h[p]) (where valid indices are used)
  
  The change in c[s] due to changing h[i] by δ:
  - If i is used as "p+k" in some term: c[s] += (1-h[p]) * δ where p = i-k
  - If i is used as "p" in some term: c[s] -= h[p+k] * δ where p = i, so p+k = i+k
  
  Similarly for h[j] by -δ.

So: Δc[s] = δ * [(1-h[i-k]) * I(valid(i-k)) - h[i+k] * I(valid(i+k))] 
           - δ * [(1-h[j-k]) * I(valid(j-k)) - h[j+k] * I(valid(j+k))]

Where valid(x) means 0 ≤ x < n.

And k = s - (n-1).

This gives O(n) per move (to update all c[s] values), and then we need O(n) to find the max.

But wait, we also need to check if the new max is smaller. If we maintain c as an array and update it incrementally, we can recompute the max in O(n).

This makes each move O(n) instead of O(n²). For n=200, that's 200 operations per move. With 20000 pairs per pass, that's 4M operations per pass. At 100M ops/sec, that's 0.04 seconds per pass. Much better!

def _delta_c(h, i, j, d, n):
    """Compute change in correlation when h[i] += d and h[j] -= d."""
    # c[s] = sum_p h[p+k]*(1-h[p]) where k = s-(n-1)
    # Change in c[s] when h[i] += d and h[j] -= d:
    # Δc[s] = d * grad_i[s] - d * grad_j[s]
    # where grad_i[s] = ∂c[s]/∂h[i]
    
    # For shift k = s - (n-1):
    # ∂c/s]/∂h[i] = (1-h[i-k]) * I(0<=i-k<n) - h[i+k] * I(0<=i+k<n)
    # (when k >= 0: first term valid if i >= k, second term valid if i <= n-1-k)
    # (when k < 0: k' = -k, c[s] = sum_p h[p-k']*(1-h[p+k']), 
    #  ∂c[s]/∂h[i] = (1-h[i+k']) * I(0<=i+k'<n) - h[i-k'] * I(0<=i-k'<n))
    
    # Actually let me just compute it directly for all s at once.
    # k ranges from -(n-1) to n-1, corresponding to s = k + (n-1)
    
    dc = np.zeros(2 * n - 1)
    
    # For h[i] += d:
    for k in range(-(n-1), n):
        s = k + (n - 1)
        grad = 0.0
        # Term where i = p + k (i.e., p = i - k)
        p = i - k
        if 0 <= p < n:
            grad += (1 - h[p])
        # Term where i = p (i.e., p = i)
        p2 = i + k
        if 0 <= p2 < n:
            grad -= h[p2]
        dc[s] += d * grad
    
    # For h[j] -= d:
    for k in range(-(n-1), n):
        s = k + (n - 1)
        grad = 0.0
        p = j - k
        if 0 <= p < n:
            grad += (1 - h[p])
        p2 = j + k
        if 0 <= p2 < n:
            grad -= h[p2]
        dc[s] -= d * grad
    
    dc *= dx
    return dc

def _delta_c_vec(h, i, j, d, n):

    grad_i = np.where(valid1, 1 - h[np.where(valid1, p1, 0)], 0.0) - np.where(p2_valid, h[np.where(p2_valid, i+k, 0)], 0.0)

    return dc

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target_sum = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(2000):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def obj_smooth(x, n, alpha):
    dx = 2.0 / n
    c = np.correlate(x, 1 - x, mode='full') * dx
    m = c.max()
    shifted = alpha * (c - m)
    mx = shifted.max()
    if mx > 500:
        return float(m + (mx + np.log(np.sum(np.exp(shifted - mx)))) / alpha)
    return float(m + np.log(np.sum(np.exp(shifted))) / alpha)

import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)

        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            t = room.sum()
            if t < 1e-14:
                break
            h += (diff / t) * room
        else:
            t = h.sum()
            if t < 1e-14:
                break
            h += (diff / t) * h
    return np.clip(h, 0.0, 1.0)
