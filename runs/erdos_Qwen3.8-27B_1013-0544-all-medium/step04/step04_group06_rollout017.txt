2. Check if entry_0 at that x is larger than the max of linears. If so, we need to push x toward 0 or 1.

For step 1, the convex function g(x) = max_{L≠0} (a_L + b_L * x) has subgradient = {b_L : L is active (achieves max)}. We want to find x* where 0 ∈ subgradient(g)(x*), i.e., there's an active line with b_L < 0 and an active line with b_L > 0 (or a single line with b_L = 0).

Bisection: 
- At x=0, subgradient is the set of b_L for L achieving max at x=0. If all are ≥ 0, the minimum is at x=0. If all are ≤ 0, try larger x.
- Actually, g is convex, so its derivative is non-decreasing. At x=0, if the right-derivative ≥ 0 (min of active b_L's ≥ 0), we're at the minimum. Otherwise, increase x. Use bisection.

Wait, for a piecewise-linear convex function, the subgradient at x is [min_active_slope, max_active_slope]. The function is minimized where 0 is in the subgradient, i.e., min_active_slope ≤ 0 ≤ max_active_slope.

Algorithm:
1. At x=0: find active set (entries achieving max). If min slope of active set ≥ 0, return x=0.
2. At x=1: find active set. If max slope of active set ≤ 0, return x=1.
3. Otherwise, bisect: find x where the max switches from a line with positive slope to one with negative slope.

Actually, a simpler approach: since g is piecewise linear and convex, its minimum is at a "kink" where the slope changes from negative to positive. We can find all kinks (intersections of pairs of lines) in [0,1], but that's O(n²). 

Better: use the fact that g(x) = max_L (a_L + b_L * x). Define h(x) = g(x). 
- h(0) = max_L a_L
- h(1) = max_L (a_L + b_L)
- h is convex, so minimum is where h transitions from decreasing to increasing.

I'll use ternary search (which works for convex functions) with enough iterations for the desired precision. Each evaluation is O(n) (computing max of n linear functions). With ~50 iterations of ternary search, that's 100 evaluations per coordinate, each O(n) = O(480). Total per sweep: 480 * 100 * 480 = 23M operations. That's fine!

def compute_c5(h):

    return float(np.max(np.correlate(h, 1.0 - h, mode="full")) * dx)

def project_sum(h, target):
    h = np.clip(h, 0.0, 1.0)
    lo, hi = -2.0, 2.0
    for _ in range(60):
        mid = (lo + hi) * 0.5
        if np.clip(h - mid, 0.0, 1.0).sum() > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) * 0.5, 0.0, 1.0)

def obj_grad(h, beta):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    m = np.max(corr)
    bc = np.clip(beta * (corr - m), -500, 500)
    e = np.exp(bc)
    se = e.sum()
    val = (m + np.log(se / len(corr)) / beta) * dx
    w = e / se
    g = np.zeros(n)
    nc = len(corr)
    for j in range(nc):
        if w[j] < 1e-12:
            continue
        lag = j - (n - 1)
        if lag == 0:
            g += w[j] * (1.0 - 2.0 * h)
        elif lag > 0:
            g[lag:] += w[j] * (1.0 - h[:-lag])
            g[:n - lag] -= w[j] * h[lag:]
        else:
            m2 = -lag
            g[:n - m2] += w[j] * (1.0 - h[m2:])
            g[m2:] -= w[j] * h[:n - m2]
    return val, g * dx

        return obj_grad(np.clip(x, 0, 1), beta)[1]

        return np.sum(x) - target

        return np.ones(n)

                   constraints=cons, options={'maxiter': maxiter, 'ftol': ftol})

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    dx = 2.0 / len(h)
    return float(np.max(np.correlate(h, 1.0 - h, mode="full")) * dx)

def project_sum(h, target):
    h = np.clip(h, 0.0, 1.0)
    lo, hi = -2.0, 2.0
    for _ in range(60):
        mid = (lo + hi) * 0.5
        if np.clip(h - mid, 0.0, 1.0).sum() > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) * 0.5, 0.0, 1.0)

def obj_grad(h, beta):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    m = np.max(corr)
    bc = np.clip(beta * (corr - m), -500, 500)
    e = np.exp(bc)
    se = e.sum()
    val = (m + np.log(se / len(corr)) / beta) * dx
    w = e / se
    g = np.zeros(n)
    nc = len(corr)
    for j in range(nc):
        if w[j] < 1e-12:
            continue
        lag = j - (n - 1)
        if lag == 0:
            g += w[j] * (1.0 - 2.0 * h)
        elif lag > 0:
            g[lag:] += w[j] * (1.0 - h[:-lag])
            g[:n - lag] -= w[j] * h[lag:]
        else:
            m2 = -lag
            g[:n - m2] += w[j] * (1.0 - h[m2:])
            g[m2:] -= w[j] * h[:n - m2]
    return val, g * dx

def slsqp_optimize(h_init, beta, maxiter=2000, ftol=1e-16):
    n = len(h_init)
    target = n / 2.0
    bounds = [(0, 1)] * n
    def obj(x):
        return obj_grad(np.clip(x, 0, 1), beta)[0]
    def grad(x):
        return obj_grad(np.clip(x, 0, 1), beta)[1]
    cons = [{'type': 'eq', 'fun': lambda x: np.sum(x) - target,
             'jac': lambda x: np.ones(n)}]
    res = minimize(obj, h_init, jac=grad, method='SLSQP', bounds=bounds,
                   constraints=cons, options={'maxiter': maxiter, 'ftol': ftol})
    return project_sum(res.x, target)

def coord_descent(h, t0, budget, max_sweeps=500):
    """Exact coordinate descent with vectorized grid search per coordinate."""
    n = len(h)
    dx = 2.0 / n
    ncorr = 2 * n - 1
    center = n - 1
    target = n / 2.0
    best_c5 = compute_c5(h)
    
    # Precompute
    L = np.arange(1, n)  # lag values 1..n-1
    
    # Grid for initial search
    x_grid = np.linspace(0.0, 1.0, 100)
    
    for sweep in range(max_sweeps):
        if budget - (time.time() - t0) < 20:
            break
        
        h = project_sum(h, target)
        corr = np.correlate(h, 1.0 - h, mode="full")
        sum_sq = np.dot(h, h)
        
        for i in range(n):
            cur = h[i]
            
            # Compute slopes for all lags
            # Positive lag +L at index center+L
            m1 = L < (n - i)
            m2 = L <= i
            slope_pos = np.zeros(n - 1)
            if np.any(m1):
                slope_pos[m1] += (1.0 - h[i + L[m1]])
            if np.any(m2):
                slope_pos[m2] -= h[i - L[m2]]
            
            # Negative lag -L at index center-L
            m3 = L <= i
            m4 = L < (n - i)
            slope_neg = np.zeros(n - 1)
            if np.any(m3):
                slope_neg[m3] += (1.0 - h[i - L[m3]])
            if np.any(m4):
                slope_neg[m4] -= h[i + L[m4]]
            
            # Assemble slopes
            slopes = np.zeros(ncorr)
            slopes[center + 1:] = slope_pos
            slopes[:center] = slope_neg[::-1]
            
            # Intercepts (entry value with h[i] = 0)
            intercepts = corr - slopes * cur
            # Center: entry_0(x) = sum(h) - (sum_sq - cur^2) - x^2
            intercepts[center] = np.sum(h) - (sum_sq - cur * cur)
            # So entry_0(x) = intercepts[center] - x^2
            # For non-center: entry_j(x) = intercepts[j] + slopes[j] * x
            
            # Remove center for the linear part
            idx_nc = np.ones(ncorr, dtype=bool)
            idx_nc[center] = False
            slopes_nc = slopes[idx_nc]
            intercepts_nc = intercepts[idx_nc]
            
            # Evaluate on grid
            # g(x) = max(intercepts_nc + x * slopes_nc) over non-center entries
            g_vals = np.max(intercepts_nc[None, :] + x_grid[:, None] * slopes_nc[None, :], axis=1)
            e0_vals = intercepts[center] - x_grid**2
            f_vals = np.maximum(g_vals, e0_vals)
            
            # Coarse best
            x_best = x_grid[np.argmin(f_vals)]
            
            # Fine search around x_best
            delta = 0.01
            xf_lo = max(0.0, x_best - delta)
            xf_hi = min(1.0, x_best + delta)
            x_fine = np.linspace(xf_lo, xf_hi, 100)
            g_fine = np.max(intercepts_nc[None, :] + x_fine[:, None] * slopes_nc[None, :], axis=1)
            e0_fine = intercepts[center] - x_fine**2
            f_fine = np.maximum(g_fine, e0_fine)
            x_opt = x_fine[np.argmin(f_fine)]
            
            # Only update if it improves (and is different)
            if abs(x_opt - cur) > 1e-10:
                h[i] = x_opt
        # end for i
        
        # Project after sweep
        h = project_sum(h, target)
        c5 = compute_c5(h)
        if c5 < best_c5:
            best_c5 = c5
            # Track best
            h_best = h.copy()
        else:
            # No improvement this sweep, use h_best
            h = h_best
    
    return h_best, best_c5

Wait, there's a problem. After I update h[i], the precomputed `corr` is no longer valid for subsequent coordinates. I'm using the old corr to compute intercepts, but h has changed.

This is a common issue in coordinate descent. The standard approach is:
1. Update h[i] using the current corr (which is slightly stale for later coordinates)
2. Recompute corr after the full sweep

This is called "Gauss-Seidel" style (using updated values) vs "Jacobi" style (using values from start of sweep). The Gauss-Seidel approach is generally better for convergence.

To do Gauss-Seidel properly, I'd need to update corr after each coordinate change. The change to corr when h[i] changes from old to new:
- For each lag L ≠ 0: the change is (new - old) * slope_L (where slope_L is the coefficient we computed)
- For L = 0: the change is (new - old) - (new² - old²) = (new-old)(1 - new - old)

So I can update corr in O(n) after each coordinate change! This makes it feasible.

def subgrad_polish(h, t0, budget, max_iter=5000, n_active=6):
    n = len(h)
    dx = 2.0 / n
    ncorr = 2 * n - 1
    target = n / 2.0
    best = h.copy()
    best_c5 = compute_c5(best)
    no_imp = 0
    for it in range(max_iter):
        if budget - (time.time() - t0) < 5:
            break
        corr = np.correlate(best, 1.0 - best, mode="full")
        top = np.argsort(corr)[::-1][:n_active]
        g = np.zeros(n)
        for idx in top:
            lag = int(idx) - (n - 1)
            if lag == 0:
                g += (1.0 - 2.0 * best)
            elif lag > 0:
                g[lag:] += (1.0 - best[:-lag])
                g[:n - lag] -= best[lag:]
            else:

                g[m2:] -= best[:n - m2]
