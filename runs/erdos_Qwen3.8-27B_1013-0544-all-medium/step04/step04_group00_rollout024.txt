Let me now think about the gradient computation more carefully.

For the smooth max:
F(h) = T * log(sum_k exp(c[k]/T))

where c = np.correlate(h, 1-h, mode='full') * dx

The gradient:
dF/dh[j] = sum_k p[k] * dc[k]/dh[j]

where p[k] = exp(c[k]/T) / sum_m exp(c[m]/T)

And dc[k]/dh[j] = (1-h[j-k']) * dx - h[j+k''] * dx (with appropriate boundary conditions)

where k' and k'' depend on the correlation indexing.

Let me be very precise. Let n = len(h), and the full correlation has 2n-1 entries indexed 0 to 2n-2.

np.correlate(h, v, mode='full')[m] = sum_{i} h[i + m - (n-1)] * v[i] (this is one common convention)

Actually, let me just use numpy's convention directly. From the docs:
c_k = \sum_n a_{n+k} \overline{v_n}

For 'full' mode, k ranges from -(N-1) to (N-1) where N is the length.
But the output is indexed 0 to 2N-2, where output index m corresponds to k = m - (N-1).

So c[m] = c_{k=m-(n-1)} = sum_n h[n + m - (n-1)] * v[n]

where n ranges over valid indices: 0 <= n < n AND 0 <= n + m - (n-1) < n

Let me substitute: let k = m - (n-1). Then:
c[k] = sum_n h[n+k] * v[n] where 0 <= n < n and 0 <= n+k < n

dc[k]/dh[j]:
h[j] appears in h[n+k] when n+k = j, i.e., n = j-k.
So the contribution is v[j-k] * dx if 0 <= j-k < n.

h[j] also appears in v[n] = 1-h[n] when n = j, contributing -h[j+k] * dx if 0 <= j+k < n.

So: dc[k]/dh[j] = v[j-k]*dx * [0<=j-k<n] - h[j+k]*dx * [0<=j+k<n]
= (1-h[j-k])*dx * [0<=j-k<n] - h[j+k]*dx * [0<=j+k<n]

Now the full gradient:
dF/dh[j] = sum_k p[k] * ((1-h[j-k])*dx * [0<=j-k<n] - h[j+k]*dx * [0<=j+k<n])

Let me define P[k] = p[k]*dx for k in [-(n-1), n-1].

dF/dh[j] = sum_{k: 0<=j-k<n} P[k] * (1-h[j-k]) - sum_{k: 0<=j+k<n} P[k] * h[j+k]

First sum: let t = j-k, so k = j-t. Range: 0<=t<n and -(n-1) <= j-t <= n-1.
= sum_t P[j-t] * (1-h[t]) [for valid t and j-t]
= (P * (1-h))[j] (convolution, with P defined on [-(n-1), n-1])

Second sum: let t = j+k, so k = t-j. Range: 0<=t<n and -(n-1) <= t-j <= n-1.
= sum_t P[t-j] * h[t] [for valid t and t-j]
= (P_rev * h)[j] where P_rev[k] = P[-k]

So: grad[j] = (P * (1-h))[j] - (P_rev * h)[j]

This can be computed with FFT! Let me implement it.

For the FFT approach:
- P is defined on indices [-(n-1), n-1], which is 2n-1 values
- (1-h) and h are defined on [0, n-1], which is n values
- The convolution (P * (1-h)) is defined on [-(n-1), 2n-2], but we only need [0, n-1]

Using np.fft:
- Zero-pad P to length 2n (or next power of 2)
- Zero-pad (1-h) to same length
- Compute FFT, multiply, inverse FFT
- Extract the relevant portion

Similarly for (P_rev * h).

```python
def compute_correlation(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    # Bisection for theta such that sum(clip(h - theta, 0, 1)) = target
    if h.sum() == target:
        return h
    lo, hi = -1.0, 1.0
    for _ in range(200):
        mid = (lo + hi) / 2.0
        s = np.clip(h - mid, 0.0, 1.0).sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2.0
    return np.clip(h - theta, 0.0, 1.0)

def smooth_max_obj_and_grad(h, n, T):
    """ Compute T*log(sum exp(c/T)) and gradient. """
    c = compute_correlation(h, n)
    # Numerical stability
    c_max = c.max()
    exp_c = np.exp((c - c_max) / T)
```

```python
def compute_gradient(h, n, T):
    c = compute_correlation(h, n)
    c_max = c.max()
    exp_c = np.exp((c - c_max) / T)
    p = exp_c / exp_c.sum()
    dx = 2.0 / n
    
    # grad[j] = dx * (sum_{m: valid} p[m] * (1-h[j - (m-(n-1))]) - sum_{m: valid} p[m] * h[j + (m-(n-1))])
    # Let s = m - (n-1), so m = s + (n-1)
    # grad[j] = dx * (sum_{s: 0<=j-s<n} p[s+(n-1)] * (1-h[j-s]) - sum_{s: 0<=j+s<n} p[s+(n-1)] * h[j+s])
    
    # For the first term, for each j, valid s: max(-(n-1), j-(n-1)) <= s <= min(n-1, j)
    # j-s >= 0 => s <= j
    # j-s <= n-1 => s >= j-(n-1)
    # And s in [-(n-1), n-1]
    # So s in [max(-(n-1), j-(n-1)), min(n-1, j)]
    
    # For the second term, for each j, valid s: max(-(n-1), -j) <= s <= min(n-1, n-1-j)
    # j+s >= 0 => s >= -j
    # j+s <= n-1 => s <= n-1-j
    # So s in [max(-(n-1), -j), min(n-1, n-1-j)]
    
    grad = np.zeros(n)
    for j in range(n):
        # First term
        s_lo = max(-(n-1), j - (n-1))
        s_hi = min(n-1, j)
        if s_lo <= s_hi:
            indices = np.arange(s_lo, s_hi + 1)
            p_idx = indices + (n - 1)  # index into p array
            h_idx = j - indices  # index into h for (1-h[j-s])
            grad[j] += dx * np.dot(p[p_idx], 1 - h[h_idx])
        
        # Second term
        s_lo2 = max(-(n-1), -j)
        s_hi2 = min(n-1, n-1-j)
        if s_lo2 <= s_hi2:
            indices = np.arange(s_lo2, s_hi2 + 1)
            p_idx = indices + (n - 1)
            h_idx = j + indices  # index into h for h[j+s]
            grad[j] -= dx * np.dot(p[p_idx], h[h_idx])
    
    return c_max, grad
```

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def compute_correlation(h, n):
    return np.correlate(h, 1 - h, mode='full') * (2.0 / n)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    if abs(h.sum() - target) < 1e-12:
        return h
    lo, hi = -2.0, 2.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        s = np.clip(h - mid, 0.0, 1.0).sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def smooth_max_obj_grad(h, n, T, mu):
    c = compute_correlation(h, n)
    cmax = c.max()
    exp_c = np.exp((c - cmax) / T)
    s = exp_c.sum()
    p = exp_c / s
    obj = cmax + T * np.log(s) + mu * (h.sum() - n/2.0)**2
    
    dx = 2.0 / n
    grad = np.zeros(n)
    for j in range(n):
        s_lo = max(-(n-1), j-(n-1))
        s_hi = min(n-1, j)
        if s_lo <= s_hi:
            idx = np.arange(s_lo, s_hi+1)
            grad[j] += dx * np.dot(p[idx+(n-1)], 1-h[j-idx])
        s_lo2 = max(-(n-1), -j)
        s_hi2 = min(n-1, n-1-j)
        if s_lo2 <= s_hi2:
            idx = np.arange(s_lo2, s_hi2+1)
            grad[j] -= dx * np.dot(p[idx+(n-1)], h[j+idx])
    grad += 2 * mu * (h.sum() - n/2.0)
    return obj, grad

def lbfgsb_smooth(h0, n, T, mu, maxiter=5000):
    def fun(x):
        return smooth_max_obj_grad(x, n, T, mu)[0]
    def jac(x):
        return smooth_max_obj_grad(x, n, T, mu)[1]
    bounds = [(0.0, 1.0)] * n
    res = minimize(fun, h0, jac=jac, method='L-BFGS-B', bounds=bounds,
                   options={'maxiter': maxiter, 'ftol': 1e-15, 'gtol': 1e-12})
    return project_feasible(res.x, n)
```
