### 2. Analytic sub‑gradient of the objective  

For any fixed shift `s` the contribution  

```
g_s(h) = dx·∑_i h_i·(1‑h_{i+s}) = dx·(∑_i h_i – ∑_i h_i·h_{i+s})
```

is differentiable w.r.t. each `h_j`:

```
∂g_s/∂h_j = dx·[ (1‑h_{j+s})  –  (if j‑s in range)  h_{j‑s} ] .
```

(The second term appears because `h_j` also participates as the *right* factor in `g_s` when `j = i+s`.)

The overall objective is `F(h)=max_s g_s(h)`.  
At a point where the maximum is attained at a unique shift `s*`, a sub‑gradient of `F` is simply `∇g_{s*}`.  
If several shifts share the same maximal value, any convex combination of their gradients is a valid sub‑gradient; we use an equal weighting.

Thus we can compute a (sub‑)gradient **exactly** from the correlation array:

1. Compute the full correlation `c = np.correlate(h, 1‑h, 'full')` (length `2N‑1`).  
2. Identify the set `S = {s | c[s] == max(c)}`.  
3. For each `s∈S` build the per‑shift gradient `∂g_s/∂h` using the formula above (vectorised).  
4. Average the gradients over `S` to obtain the sub‑gradient `∂F/∂h`.  
5. Chain‑rule back to `z` through `u_i = 0.5+0.5·tanh(z_i)` (`∂u_i/∂z_i = 0.5·sech²(z_i)`).

All operations are O(N), far cheaper than O(N²) correlation (the correlation itself dominates but still cheap for `N≈200`).
