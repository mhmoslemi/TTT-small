### 1. Reformulation as a periodic autocorrelation problem

If we view the domain as a circle of length 2 (i.e. impose periodic boundary conditions), the tail terms disappear and the overlap simplifies to  

```
Uₖ^per = w – Σ_i h[i]·h[i+k]      (k ≠ 0, indices taken modulo n)
```

Thus minimising `maxₖ Uₖ` ⇔ maximising the **minimum periodic autocorrelation**  

```
aₖ = Σ_i h[i]·h[i+k] ,   k=1,…,n‑1 .
```

The periodic problem is a relaxation of the original one: any feasible `h` for the original problem is also feasible for the periodic version, but the converse need not hold.  Consequently, a vector that performs well in the periodic sense will also have a low value of the original (non‑periodic) `C₅`.

### 2. SDP relaxation

Introduce an `n×n` symmetric matrix variable  

```
X = hhᵀ   (relaxed: X ⪰ 0, X_ii = h_i)
```

The periodic autocorrelation at shift `k` is a *linear* functional of `X`:

```
aₖ = trace(T_k X)   ,   where (T_k)_{ij} = 1  iff  j-i ≡ k (mod n), else 0.
```

We now maximise the smallest autocorrelation value `t` subject to the natural constraints on `X`.

**SDP formulation**

```
maximise   t
subject to
    trace(T_k X)  ≥  t           for all k = 1,…,n‑1        (uniform overlap)
    X_ii          ≤  1        ,   X_ii ≥ 0    for i=1,…,n   (0‑1 box)
    trace(X)      =  w                                   (total mass)
    X ⪰ 0                                               (psd)
```

All constraints are linear in `X` except the PSD cone; the problem is a standard semidefinite program.

*Why this works.*  
For any binary `h`, `X = hhᵀ` satisfies the constraints and `t = minₖ aₖ`.  The SDP therefore yields an upper bound on the attainable `t`.  Its optimal value `t*` gives a concrete bound on the periodic overlap:


Because the periodic overlap never exceeds the original (zero‑padded) overlap, any `h` generated from the SDP will also give a valid upper bound for the original `C₅`.
