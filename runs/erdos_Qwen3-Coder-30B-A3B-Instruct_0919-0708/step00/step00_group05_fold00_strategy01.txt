**1.  Problem reformulation**

*   The step function is discretised as a vector `h = (h₀,…,h_{n‑1})` on a uniform grid of `n` points over `[0,2]`.
*   The constraints become  
    `0 ≤ h_i ≤ 1` and `∑ h_i = n/2`   (because `dx = 2/n` and the integral must equal 1).
*   For a given `h` the evaluator computes  

    `C₅(h) = max_k ∫ h(x)(1‑h(x+k))dx = max_{lag L}  (∑_i h_i·(1‑h_{i+L}))·dx`.

    Since `∑ h_i·dx = 1`,  

    `C₅(h) = 1 – min_{lag L} (∑_i h_i·h_{i+L})·dx`.

    Thus **minimising** `C₅` is equivalent to **maximising** the smallest auto‑correlation  

    `corr(L) = (h * h)[L]·dx`.

**2.  Why binary search is sensible**

The known best constructions are essentially indicator functions (values 0 or 1).  
Restricting the search to binary vectors preserves the sum constraint (`n/2` ones) and turns the problem into a combinatorial optimisation that can be explored efficiently with heuristics. After a good binary pattern is found we can relax it to a continuous one for a final fine‑tuning.

**3.  Core heuristic – Simulated Annealing on binary vectors**

*   **Choose a grid size `n`**

*   **Representation**

    ```
    Δcorr(L) = (h_{j+L}+h_{j‑L}) – (h_{i+L}+h_{i‑L})   (for L ≠ 0)

    ```
