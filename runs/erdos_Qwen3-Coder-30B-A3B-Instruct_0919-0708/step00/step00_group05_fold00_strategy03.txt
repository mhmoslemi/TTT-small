**1.  Problem discretisation**  
* Choose an even number of sample points `n` (the length of the step function).  
* The mesh size is `dx = 2 / n`.  
* The decision vector is `h = (h₀,…,h_{n‑1})` with `0 ≤ h_i ≤ 1`.  
* The integral constraint becomes a linear equality  

\[
\sum_{i=0}^{n-1} h_i \;dx = 1\qquad\Longleftrightarrow\qquad 
\sum_{i=0}^{n-1} h_i = n/2 .
\]

* For a discrete shift `ℓ ∈ {-(n‑1),…,n‑1}` the overlap integral is  

\[
F(ℓ) = \int_0^2 h(x)\bigl(1-h(x+ℓdx)\bigr)dx
     = 1 - C(ℓ),\qquad 
C(ℓ)=\sum_{i}h_i\,h_{i+ℓ}\;dx ,
\]

where `h_{i+ℓ}` is taken as 0 outside the interval.  
The quantity to be minimised is  

\[
C_5 = \max_{ℓ}F(ℓ) = 1 - \min_{ℓ} C(ℓ).
\]

Thus the optimisation is a **min‑max** problem: maximise the smallest auto‑correlation `C(ℓ)`.

**2.  Exact binary formulation as a Mixed‑Integer Linear Programme (MILP)**  

The known extremal constructions are indicator functions (i.e. binary values);
therefore we first search over the binary space `h_i∈{0,1}`.  
Introduce auxiliary continuous variables  

\[
y_{i,ℓ} \;=\; h_i\,h_{i+ℓ}\qquad
\text{ for every }ℓ\text{ and every }i\text{ with }0\le i,i+ℓ<n .
\]

For binary `h` the product can be linearised with the standard McCormick
constraints:

```
y[i,ℓ] ≤ h[i]
y[i,ℓ] ≤ h[i+ℓ]
y[i,ℓ] ≥ h[i] + h[i+ℓ] – 1
y[i,ℓ] ≥ 0
```

All `y[i,ℓ]` are bounded by `0 ≤ y[i,ℓ] ≤ 1`.

Define a continuous variable `C` that will become the bound we are looking for.
For each shift `ℓ` the auto‑correlation is  

\[
Cℓ = dx·\sum_i y_{i,ℓ}.
\]

Because `∑_i h_i·dx = 1`, the overlap for shift `ℓ` is `1 – Cℓ`.  
The max‑over‑ℓ constraint is linearised by a set of inequalities

\[
C \;≥\; 1 - Cℓ\qquad\Longleftrightarrow\qquad
C + Cℓ \;≥\; 1\;\;\; \forall ℓ .
\]

The complete MILP is therefore

```
variables:   h[i] ∈ {0,1}      (n variables)
             y[i,ℓ] ≥ 0        (≈ n² variables)
             C  ≥ 0             (scalar)

constraints:
    Σ_i h[i] = n/2
    for every (i,ℓ) with i+ℓ in range:
          y[i,ℓ] ≤ h[i]
          y[i,ℓ] ≤ h[i+ℓ]
          y[i,ℓ] ≥ h[i] + h[i+ℓ] – 1
    for every ℓ:
          C + dx·Σ_i y[i,ℓ] ≥ 1

objective:  minimise C
```

All constraints are linear; only the `h[i]` variables are integer.
The model size is `O(n²)`.  For `n = 70` (the size of the supplied
`initial_h_values`) we have roughly 4 900 `y` variables and about 15 000 linear
constraints – comfortably solvable with an off‑the‑shelf MILP solver such as
CBC, GLPK‑MI, or ECOS MI from the `cvxpy` interface.

**4.  Continuous refinement (projected sub‑gradient ascent on the worst lag)**  

The binary optimum may still be improvable by allowing fractional values.
From the binary `h*` we perform a short projected gradient descent on the
function  

\[
\Phi(h) = \max_{ℓ}F(ℓ) = 1-\min_{ℓ}C(ℓ).
\]

Because `Φ` is the pointwise maximum of a family of smooth functions, a
sub‑gradient at `h` is obtained by averaging the gradients of the *active*
lags – those `ℓ` for which `C(ℓ)` attains the global minimum.

* **Gradient of a single lag**  
  For a fixed lag `ℓ≠0`

\[
\frac{∂C(ℓ)}{∂h_j}=dx\bigl( h_{j+ℓ}+h_{j-ℓ}\bigr),
\]

with the convention that out‑of‑range indices contribute zero.  
For `ℓ = 0` we have `C(0)=∑_i h_i·dx = 1`, whose gradient is simply the
vector of ones (scaled by `dx`).

* **Sub‑gradient for the min‑correlation**  
  Let `ℓ₁,…,ℓ_k` be the lags attaining `min_ℓ C(ℓ)`.  
  The sub‑gradient of `min_ℓ C(ℓ)` is the **average** of the individual
  gradients:

  \[
  g = \frac{1}{k}\sum_{p=1}^{k}\bigl(h_{j+ℓ_p}+h_{j-ℓ_p}\bigr)_{j=0}^{n-1}.
  \]

  To *decrease* `Φ` we move **against** the gradient of `C` (i.e. in the
  direction of `+g`) because `Φ = 1 – min C`.

* **Projected update**  
  With a step size `α_t` (decreasing, e.g. `α_t = α₀ /√t`), propose  

  \[
  \tilde h = h + α_t\,g .
  \]

  The vector `\tilde h` may violate the box constraints and the sum
  constraint.  Project it onto the intersection of the box `[0,1]^n` and the
  affine hyperplane `Σ h_i = n/2`:

  * For a given shift λ compute `z_i(λ)=\operatorname{clip}( \tilde h_i-λ,0,1 )`.  
  * The function `S(λ)=Σ_i z_i(λ)` is monotone decreasing in λ; find λ by a
    short bisection (≈30 iterations) so that `S(λ)=n/2`.  
  * The resulting `z` satisfies all constraints and is the Euclidean projection
    onto the feasible set.

* **Acceptance**  
  Evaluate `Φ(z)` (use a single correlation `np.correlate(z,z,mode='full')*dx`,
  compute the smallest entry, and set `Φ=1-min`).  
  If `Φ(z) < Φ(h)` accept the move; otherwise keep `h`.  Because the update
  strictly follows the sub‑gradient direction, a simple greedy acceptance
  already yields monotonic improvement.

* **Stopping**  
  Run this refinement until the remaining time budget expires (or until no
  improvement for a few hundred iterations).  Keep the best vector seen.
