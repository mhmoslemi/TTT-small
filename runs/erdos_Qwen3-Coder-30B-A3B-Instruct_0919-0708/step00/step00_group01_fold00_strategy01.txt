### 1. Discretisation choice
* Choose a moderate resolution `n = 400` (≈ 0.005 Δx).  
  This size balances expressive power with the O(n²) cost of a full
  correlation (≈ 1.6 × 10⁵ operations per iteration, comfortably fast in C).
* The decision variable is a real vector `h ∈ ℝⁿ`.

### 2. Feasible set – projection onto the capped simplex
We must enforce simultaneously:
* box constraints `0 ≤ h[i] ≤ 1`;
* the linear equality `∑ h = n/2` (because `dx·∑ h = 1`).

After each gradient step we **project** the trial vector onto this set:
1. Clip every component to `[0,1]`.
2. If the sum is already `n/2` we are done.
3. Otherwise perform a *water‑filling* projection onto the capped simplex:
   solve for a scalar `λ` such that  
   `∑_i min(1, max(0, h[i]‑λ)) = n/2`.  
   This can be done by sorting the clipped values once (O(n log n)) and
   applying the standard algorithm for the capped simplex.

The projector is exact, so the constraint is always satisfied (up to floating‑point tolerance).

### 3. Smooth approximation of the max
Define the vector of overlap values for all shifts:

```
g(s) = dx * ( Σ_i h[i] – Σ_i h[i]·h[i+s] )      for s = -(n‑1)…(n‑1)
```

(The convolution `np.correlate` gives exactly `g`).  

Instead of `max_s g(s)` we minimise the **softmax (log‑sum‑exp)**:

```
L_τ(h) = τ * log( Σ_s exp( g(s) / τ ) )
```

* For large `τ` the function is smooth and its gradient is well‑behaved.
* As `τ → 0` we obtain the true max.  
  We start with `τ₀ = 0.05` (empirically large enough) and **geometrically
  decay** it after each outer epoch (`τ ← τ·γ`, γ≈0.9) until a final value
  `τ_min = 1e‑4`.

The loss provides a differentiable surrogate that yields a useful descent
direction while still guiding the optimiser towards reducing the actual
maximum.

### 4. Analytic gradient of the soft‑max loss
For a fixed `τ` let  

```
w_s = exp( g(s) / τ ) / Σ_t exp( g(t) / τ )      (softmax weights)
```

The derivative of `g(s)` with respect to a component `h[i]` is

```
∂g(s)/∂h[i] = dx * ( 1 – h[i+s] – h[i–s] ),   (out‑of‑range indices → 0)
```

Hence the gradient of the loss is

```
∇L_τ = Σ_s w_s * ∂g(s)/∂h
```

Computationally this can be obtained without explicit loops:

1. Compute the weight vector `w` (size `2n‑1`).  
2. Form the 1‑D convolution `c₁ = conv(w, h)` and `c₂ = conv(w, h[::-1])`
   (both via FFT for speed).  
   The two convolutions give the sums `Σ_s w_s·h[i+s]` and `Σ_s w_s·h[i‑s]`
   for every index `i`.
3. Let `W = Σ_s w_s`. Then  

```
∇L_τ[i] = dx * ( W – c₁[i] – c₂[n‑1‑i] )
```

All operations are O(n log n).  The gradient is exact (up to round‑off).
