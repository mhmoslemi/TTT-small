#### 1.2  Smooth surrogate for the max

For a smoothing parameter `p > 0` define  

```

```

The two shifted terms can be obtained efficiently by **convolutions**:

```

def obj_and_grad(h, p):

ϕ(λ) = Σ_i clamp(x_i - λ, 0, 1) - target = 0 .
```

Because `ϕ` is monotone decreasing, a **bisection** on `λ ∈ [min(x)-1 , max(x)+1]` converges in < 50 iterations. The function `project_to_feasible(x)` implements this and returns a feasible `h`.

#### 4.2  Local deterministic refinement (pairwise swaps)

After the SLSQP phase we run a cheap **hill‑climbing** phase that manipulates *pairs* of indices while preserving the sum:

```
while time permits:
    pick i≠j uniformly
    determine allowed δ range so that
         0 ≤ h_i+δ ≤ 1  and  0 ≤ h_j-δ ≤ 1
    try a few δ values (e.g. ±step, ±step/2)
    keep the one giving the smallest exact C5
```

Because the exact `C5` is used, this step can squeeze out the last few thousandths that the smooth surrogate might miss.

#### 4.3  Time management

At the top of `run` we record `t0 = time.time()`.  
Before every major loop (new `p` stage, new random start, or hill‑climb iteration) we check:

```python
if time.time() - t0 > budget_s - 5:   # keep 5 s safety margin
    break
```

If the budget is exhausted we return the best feasible solution encountered so far.

### 5.  Full algorithm outline (pseudo‑code)

```
run(seed=42, budget_s=600):
    set RNG seeds
    n = len(initial_h_values)                     # usually 45
    dx = 2.0 / n
    target_sum = n/2

    best_h   = initial_h_values.copy()
    best_val = C5_exact(best_h)

    define C5_exact, obj_and_grad(p) as above
    define project_to_feasible(x)

    p_list = [5, 15, 35, 70]                      # increasing sharpness
    for p in p_list:
        # ---- generate a few starting points ----
        start_points = [best_h]                  # keep current best
        # random binary‑plus‑fraction
        start_points.append(random_binary_plus_fraction())
        # random continuous (projected)
        for _ in range(2):
            u = np.random.rand(n)
            start_points.append(project_to_feasible(u))

        for h0 in start_points:
            if time exhausted: break
            # optimize with SLSQP for current p
            res = minimize( obj_and_grad(p), x0=h0, method='SLSQP',
                            jac=True, bounds=bounds, constraints=[eq_cons],
                            options={'maxiter':250, 'ftol':1e-10} )
            h_opt = res.x
            val   = C5_exact(h_opt)
            if val < best_val:
                best_val, best_h = val, h_opt

    # ----- post‑processing hill‑climbing -----
    while time left:
        try a random pair‑swap move on best_h (as described in 4.2)
        keep move if exact C5 improves
        update best_val/h if improved

    return (best_h.tolist(), best_val, n)
```

--------------------------------------------------------------------
### 6.  Expected performance & “failure modes”

* **Local minima** – mitigated by multi‑start and by starting each higher‑`p` stage from the best result of the previous smoother stage.
* **Numerical overflow in `exp(p·S_raw)`** – solved by subtracting `max(p·S_raw)` before exponentiation (standard log‑sum‑exp trick).
* **Projection‑round‑off** – the bisection ends when the residual sum difference is `|ϕ(λ)| < 1e‑12`; this guarantees feasibility up to machine precision.
* **Time overflow** – the outer loop stops well before the deadline (`budget_s-5`). The inner SLSQP runs are bounded (`maxiter=250`), so total time is predictable (≈ a few seconds per start). The hill‑climb runs only while time remains.

With this combination of **smooth surrogate optimisation**, **exact post‑hoc refinement**, and **extensive multi‑start exploration**, the search reliably reaches **C₅ ≤ 0.379** (or at least improves the existing 0.38092 bound) well within the 600 s budget and using ≤ 1 k sample points (the default `n=45`).
