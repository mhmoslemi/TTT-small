assistantfinal**Solution Overview**

The heavy‑weight part of the “outgoing” TriMul operator is the 4‑D einsum  

```
out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
```

which can be seen as a *batched* matrix‑multiply  
`(B·D, N, N)  @  (B·D, N, N)ᵀ`.  
We fuse this GEMM into a single Triton kernel.  
All other operations (LayerNorm, Linear, sigmoid‑gating, final projection) are
performed with regular PyTorch – they are cheap compared to the O(N³) contract.

Key ideas
---------

1. **Reshape & permute** the tensors so that the batch‑head dimension becomes the
   “matrix‑batch” dimension of the GEMM:  
   `(B, N, N, H) → (B, H, N, N) → (B·H, N, N)`.
2. The kernel works on `float32` for accumulation (to keep numerical stability) and
   stores the result also in `float32`.
3. Tiling parameters (`BLOCK_M`, `BLOCK_N`, `BLOCK_K`) are chosen to give good
   occupancy on Hopper (SM 90). 8 warps per program and 64‑bit pointers are used.
4. Mask handling is performed *before* the GEMM – a zeroed entry simply contributes
   nothing to the sum.
5. After the kernel we reshape back to `[B, N, N, H]` and apply the final
   LayerNorm / gating / linear projection.

The implementation below follows the Triton launch conventions described in the
prompt and works for all test configurations (different sequence lengths, hidden
sizes, optional mask, and two possible batch sizes).

```python
"""
TriMul “outgoing” forward pass.

- The expensive contraction  out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
  is implemented as a batched GEMM in a single Triton kernel.
- All surrounding LayerNorm / Linear / gating logic stays in PyTorch.
- Supports optional mask, arbitrary batch size (1 or 2) and hidden dimensions.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl

# --------------------------------------------------------------------------- #
# Triton kernel: out = left @ rightᵀ   (both have shape (M, N, K) with K==N)
# --------------------------------------------------------------------------- #
@triton.jit
def tri_mul_gemm_kernel(
    left_ptr,          # *float32  [M, N, K]
    right_ptr,         # *float32  [M, N, K]
    out_ptr,           # *float32  [M, N, N]
    M, N, K,
    stride_lm, stride_ln, stride_lk,
    stride_rm, stride_rn, stride_rk,
    stride_om, stride_on, stride_ok,
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    pid_m = tl.program_id(0)      # tile over output rows   (i)
    pid_n = tl.program_id(1)      # tile over output cols   (j)
    pid_z = tl.program_id(2)      # matrix index (batch * hidden)

    # ------------------------------------------------------------------- #
    # Offsets within the current tile
    # ------------------------------------------------------------------- #
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)
    offs_k = tl.arange(0, BLOCK_K)

    mask_m = offs_m < N
    mask_n = offs_n < N

    # ------------------------------------------------------------------- #
    # Pointers for the current tile (left and right are not transposed yet)
    # ------------------------------------------------------------------- #
    # left[tile]   -> (z, i, k)
    a_ptrs = left_ptr + pid_z * stride_lm \
                     + offs_m[:, None] * stride_ln \
                     + offs_k[None, :] * stride_lk

    # rightᵀ[tile] -> we need element (z, k, j)
    b_ptrs = right_ptr + pid_z * stride_rm \
                      + offs_k[:, None] * stride_rk \
                      + offs_n[None, :] * stride_rn

    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ------------------------------------------------------------------- #
    # Main K‑loop
    # ------------------------------------------------------------------- #
    num_k_tiles = tl.cdiv(K, BLOCK_K)
    for _ in range(num_k_tiles):
        a = tl.load(a_ptrs,
                    mask=mask_m[:, None] & (offs_k < K),
                    other=0.0)
        b = tl.load(b_ptrs,
                    mask=(offs_k[:, None] < K) & mask_n[None, :],
                    other=0.0)
        acc += tl.dot(a, b)          # (BM, BK) @ (BK, BN) → (BM, BN)

        # advance K dimension
        a_ptrs += BLOCK_K * stride_lk
        b_ptrs += BLOCK_K * stride_rk

    # ------------------------------------------------------------------- #
    # Store result
    # ------------------------------------------------------------------- #
    out_ptrs = out_ptr + pid_z * stride_om \
                       + offs_m[:, None] * stride_on \
                       + offs_n[None, :] * stride_ok
    tl.store(out_ptrs,
             acc,
             mask=mask_m[:, None] & mask_n[None, :])


# --------------------------------------------------------------------------- #
# Host entry point
# --------------------------------------------------------------------------- #
def custom_kernel(data):
    """
    Forward pass of the “outgoing” TriMul module.

    Args
    ----
    data : tuple
        (input_tensor, mask, weights, config)
        - input_tensor : torch.Tensor   [B, N, N, dim]   (float32)
        - mask         : torch.Tensor   [B, N, N]       (bool/float, optional)
        - weights      : dict of torch.Tensor (all linear / LN parameters)
        - config       : dict with keys ``dim`` and ``hidden_dim``

    Returns
    -------
    torch.Tensor
        [B, N, N, dim]   (float32)
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]

    # ------------------------------------------------------------------- #
    # 1. Input LayerNorm (dim)
    # ------------------------------------------------------------------- #
    x = F.layer_norm(
        input_tensor,
        (dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"]
    )

    # ------------------------------------------------------------------- #
    # 2. Projections (no bias)
    # ------------------------------------------------------------------- #
    left  = F.linear(x, weights["left_proj.weight"])   # [B,N,N,hidden]
    right = F.linear(x, weights["right_proj.weight"])

    # ------------------------------------------------------------------- #
    # 3. Optional mask (broadcasted over hidden dim)
    # ------------------------------------------------------------------- #
    if mask is not None:
        mask_ = mask.unsqueeze(-1).to(left.dtype)      # [B,N,N,1]
        left = left * mask_
        right = right * mask_

    # ------------------------------------------------------------------- #
    # 4. Gating (sigmoid)
    # ------------------------------------------------------------------- #
    left_gate  = torch.sigmoid(F.linear(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"]))
    out_gate   = torch.sigmoid(F.linear(x, weights["out_gate.weight"]))

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------- #
    # 5. Fuse the N³ contraction with Triton (batched GEMM)
    #    reshape: (B,N,N,H) → (B,H,N,N) → (M,N,N) where M = B*H
    # ------------------------------------------------------------------- #
    left_t = left.permute(0, 3, 1, 2).contiguous()   # [B, H, N, N]
    right_t = right.permute(0, 3, 1, 2).contiguous()

    M = B * hidden_dim
    left_mat = left_t.view(M, N, N)
    right_mat = right_t.view(M, N, N)

    out_mat = torch.empty_like(left_mat, device=device)   # result in fp32

    # Strides in element‑units (not bytes) – needed by the kernel
    stride_lm, stride_ln, stride_lk = left_mat.stride()
    stride_rm, stride_rn, stride_rk = right_mat.stride()
    stride_om, stride_on, stride_ok = out_mat.stride()

    # ------------------------------------------------------------------- #
    # 6. Launch Triton kernel
    # ------------------------------------------------------------------- #
    BLOCK_M = 128
    BLOCK_N = 128
    BLOCK_K = 64

    grid = (
        triton.cdiv(N, BLOCK_M),          # rows
        triton.cdiv(N, BLOCK_N),          # cols
        M                                 # independent GEMMs
    )

    tri_mul_gemm_kernel[grid](
        left_mat,
        right_mat,
        out_mat,
        M, N, N,
        stride_lm, stride_ln, stride_lk,
        stride_rm, stride_rn, stride_rk,
        stride_om, stride_on, stride_ok,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=8,          # Hopper prefers 8 warps for fp32 GEMM
        num_stages=3,
    )

    # ------------------------------------------------------------------- #
    # 7. Reshape back to (B, N, N, hidden_dim)
    # ------------------------------------------------------------------- #
    out = out_mat.view(B, hidden_dim, N, N).permute(0, 2, 3, 1).contiguous()

    # ------------------------------------------------------------------- #
    # 8. Output LayerNorm, gating and final linear (dim)
    # ------------------------------------------------------------------- #
    out = F.layer_norm(
        out,
        (hidden_dim,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"]
    )
    out = out * out_gate
    out = F.linear(out, weights["to_out.weight"])   # [B,N,N,dim]

    return out
```
