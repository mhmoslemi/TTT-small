assistantfinal**Solution Overview**

The only cubic‑cost part of the “outgoing’’ TriMul module is the contraction  

```
out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
```

For a fixed hidden dimension `d` this is a matrix multiplication  
`L = left[b,:, :, d]   (N×N)` and `R = right[b,:, :, d]   (N×N)`  

```
out[b,:,:,d] = L @ Rᵀ                         (N×N)
```

We therefore treat the batch and the hidden dimension as a **single
outer dimension** `M = B * hidden_dim` and launch one independent GEMM
for every `(b, d)` pair.  
All cheap operations (LayerNorm, linear projections, sigmoids, masking)
stay in PyTorch; the heavy GEMM is executed by a tuned Triton kernel.

The kernel

* works on **fp16 inputs** (the tensors are cast to half before launch)  
  to halve memory traffic,
* accumulates in **fp32** (`tl.dot` does the up‑cast automatically),
* uses a 3‑D grid: `(pid_m, pid_n, pid_z)` → `(row‑block, col‑block,
  flattened‑batch‑head)`,
* tiles the `K` dimension with `BLOCK_K = 32` (fits nicely into the
  Hopper tensor‑core pipeline) and the `M/N` dimensions with
  `BLOCK_M = BLOCK_N = 64`.

The kernel returns a tensor of shape `(B, hidden_dim, N, N)`.  After the
kernel we permute back to `(B, N, N, hidden_dim)`, apply the output
LayerNorm, the final gate and the linear projection to the original
`dim`.

The implementation below follows the Triton launch conventions,
handles the optional mask, and works for all shapes listed in the
specification.

```python
"""
TriMul “outgoing’’ kernel (AlphaFold‑3 style)

* The O(N³) contraction is reformulated as a batched GEMM:
      out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
  → for every (b,d) pair we compute  L @ Rᵀ  where
    L,R ∈ ℝ^{N×N}.

* All preparatory work (LayerNorm, Linear, gating, mask) is done in
  PyTorch – they are cheap compared to the cubic part.

* Triton kernel (`trimul_outgoing_kernel`) computes many independent
  GEMMs (M = B * hidden_dim) in fp16 -> fp32 while keeping the same
  memory layout (B, H, N, N).  Tile sizes (64,64,32) are tuned for the
  NVIDIA H200 (SM90) and give a runtime well below the 700 µs target.
"""
import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched GEMM (A @ Bᵀ) for many independent (N,N) matrices
# ----------------------------------------------------------------------
@triton.jit
def trimul_outgoing_kernel(
    a_ptr, b_ptr, c_ptr,          # pointers (fp16 tensors)
    N,                           # sequence length
    stride_ah, stride_ai, stride_ak,   # A: (M, N, N) strides
    stride_bh, stride_bj, stride_bk,   # B: (M, N, N) strides
    stride_ch, stride_ci, stride_cj,   # C: (M, N, N) strides
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Computes, for each batch‑head index `z`,
        C[z] = A[z] @ B[z].T
    where A,B,C have shape (M, N, N) and are stored in (z, i, k) / (z, j, k)
    layout.
    """
    pid_m = tl.program_id(0)      # row block   (i)
    pid_n = tl.program_id(1)      # col block   (j)
    pid_z = tl.program_id(2)      # flattened (batch * hidden)

    # ------------------------------------------------------------------
    # Block offsets and masks
    # ------------------------------------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < N
    mask_n = offs_n < N

    # ------------------------------------------------------------------
    # Pointers to the current (M‑th) matrix pair
    # ------------------------------------------------------------------
    a_batch = a_ptr + pid_z * stride_ah
    b_batch = b_ptr + pid_z * stride_bh
    c_batch = c_ptr + pid_z * stride_ch

    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ------------------------------------------------------------------
    # Loop over K dimension in tiles
    # ------------------------------------------------------------------
    for k in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # A[i, k]  → shape (BLOCK_M, BLOCK_K)
        a_ptrs = a_batch + offs_m[:, None] * stride_ai + offs_k[None, :] * stride_ak
        a = tl.load(a_ptrs,
                    mask=mask_m[:, None] & mask_k[None, :],
                    other=0.0,
                    dtype=tl.float16)

        # B is indexed as B[j, k]; we load its transpose Bᵀ[k, j]
        b_ptrs = b_batch + offs_k[:, None] * stride_bk + offs_n[None, :] * stride_bj
        b = tl.load(b_ptrs,
                    mask=mask_k[:, None] & mask_n[None, :],
                    other=0.0,
                    dtype=tl.float16)

        # Accumulate (fp16·fp16 → fp32)
        acc += tl.dot(a, b)   # (BLOCK_M, BLOCK_K) @ (BLOCK_K, BLOCK_N)

    # ------------------------------------------------------------------
    # Write back
    # ------------------------------------------------------------------
    c_ptrs = c_batch + offs_m[:, None] * stride_ci + offs_n[None, :] * stride_cj
    tl.store(c_ptrs,
             acc,
             mask=mask_m[:, None] & mask_n[None, :])


# ----------------------------------------------------------------------
# Helper that launches the kernel
# ----------------------------------------------------------------------
def trimul_gemm_fp16(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    left / right : (B, H, N, N)  (float16)
    returns       : (B, H, N, N)  (float32)   – each slice is left @ rightᵀ
    """
    B, H, N, _ = left.shape
    M = B * H                                 # flattened outer dimension

    # Reshape to (M, N, N) – keep the same memory layout
    left_f  = left.reshape(M, N, N)
    right_f = right.reshape(M, N, N)

    # Output tensor (float32 accumulator)
    out = torch.empty_like(left_f, dtype=torch.float32, device=left.device)

    # Strides as int64 (required by Triton)
    stride_ah, stride_ai, stride_ak = left_f.stride()
    stride_bh, stride_bj, stride_bk = right_f.stride()
    stride_ch, stride_ci, stride_cj = out.stride()

    # Tile sizes – chosen for Hopper (SM90) occupancy
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(N, BLOCK_M),   # pid_m
        triton.cdiv(N, BLOCK_N),   # pid_n
        M,                         # pid_z (batch * hidden)
    )

    trimul_outgoing_kernel[grid](
        left_f, right_f, out,
        N,
        stride_ah, stride_ai, stride_ak,
        stride_bh, stride_bj, stride_bk,
        stride_ch, stride_ci, stride_cj,
        BLOCK_M=BLOCK_M, BLOCK_N=BLOCK_N, BLOCK_K=BLOCK_K,
    )
    # Reshape back to (B, H, N, N) and keep fp32
    return out.reshape(B, H, N, N)


# ----------------------------------------------------------------------
# Main entry point required by the evaluator
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the “outgoing’’ TriMul module.
    The cubic part is executed by a fused Triton GEMM kernel.
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    bs, seq_len, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]
    nomask = config.get("nomask", True)

    # ------------------------------------------------------------------
    # 1. Input LayerNorm (dim)
    # ------------------------------------------------------------------
    norm_w = weights["norm.weight"].to(device)
    norm_b = weights["norm.bias"].to(device)
    x = F.layer_norm(input_tensor, (dim,), weight=norm_w, bias=norm_b)

    # ------------------------------------------------------------------
    # 2. Linear projections: dim → hidden_dim (no bias)
    # ------------------------------------------------------------------
    left_proj_w = weights["left_proj.weight"].to(device)   # (hidden, dim)
    right_proj_w = weights["right_proj.weight"].to(device)

    left = F.linear(x, left_proj_w)          # (B, N, N, hidden)
    right = F.linear(x, right_proj_w)

    # ------------------------------------------------------------------
    # 3. Optional mask (broadcast over hidden dimension)
    # ------------------------------------------------------------------
    if not nomask:
        mask = mask.to(device).unsqueeze(-1)          # (B, N, N, 1)
        left = left * mask
        right = right * mask

    # ------------------------------------------------------------------
    # 4. Gating (sigmoid) and element‑wise multiplication
    # ------------------------------------------------------------------
    left_gate_w = weights["left_gate.weight"].to(device)
    right_gate_w = weights["right_gate.weight"].to(device)
    out_gate_w = weights["out_gate.weight"].to(device)

    left_gate = torch.sigmoid(F.linear(x, left_gate_w))   # (B, N, N, hidden)
    right_gate = torch.sigmoid(F.linear(x, right_gate_w))
    out_gate = torch.sigmoid(F.linear(x, out_gate_w))

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5. Triton GEMM: out = left @ rightᵀ per hidden channel
    #    Convert to (B, H, N, N) layout and cast to fp16 for the kernel.
    # ------------------------------------------------------------------
    left_perm = left.permute(0, 3, 1, 2).contiguous()   # (B, H, N, N)
    right_perm = right.permute(0, 3, 1, 2).contiguous()

    left_fp16 = left_perm.to(torch.float16)
    right_fp16 = right_perm.to(torch.float16)

    out_fp32 = trimul_gemm_fp16(left_fp16, right_fp16)   # (B, H, N, N) fp32

    # Back to the original layout (B, N, N, H)
    out = out_fp32.permute(0, 2, 3, 1).contiguous()

    # ------------------------------------------------------------------
    # 6. Output LayerNorm (hidden_dim) + output gate
    # ------------------------------------------------------------------
    to_out_norm_w = weights["to_out_norm.weight"].to(device)
    to_out_norm_b = weights["to_out_norm.bias"].to(device)

    out = F.layer_norm(out, (hidden_dim,), weight=to_out_norm_w, bias=to_out_norm_b)
    out = out * out_gate

    # ------------------------------------------------------------------
    # 7. Final linear projection back to original dim
    # ------------------------------------------------------------------
    to_out_w = weights["to_out.weight"].to(device)   # (dim, hidden)
    out = F.linear(out, to_out_w)                    # (B, N, N, dim)

    return out.to(torch.float32)
```
