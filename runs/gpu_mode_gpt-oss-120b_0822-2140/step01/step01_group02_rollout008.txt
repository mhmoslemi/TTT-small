## Triton‑accelerated “outgoing” TriMul (forward only)

```python
"""
TriMul “outgoing” forward pass (AlphaFold‑3 style) with a fused Triton GEMM.

Algorithm
---------
1. Layer‑norm over the input channel dimension (dim).
2. Linear projections → left, right   (shape B×N×N×H, dtype float32).
3. Optional mask multiplication (broadcast over the hidden dim).
4. Compute three sigmoid‑gates from the original norm‑ed tensor.
5. Apply gates to left/right.
6. Permute to (B, H, N, N) and view as (B*H, N, N) → fp16.
7. Batched GEMM C = A @ Bᵀ   (A,B∈(B*H, N, N), fp16, FP32 accumulation).
8. Reshape back to (B, N, N, H), layer‑norm + out‑gate, final linear → dim.
9. Return float‑32 output.

Only step 7 (the N³·H contraction) is executed in Triton.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel : C = A @ Bᵀ   (batched GEMM, FP16 inputs, FP32 accumulation)
# ----------------------------------------------------------------------
@triton.jit
def batched_gemm_tiled_kernel(
    a_ptr,                # const FP16*   (B*H, M, K)
    b_ptr,                # const FP16*   (B*H, N, K)   (will be read transposed)
    c_ptr,                #       FP16*   (B*H, M, N)
    M, N, K,              # matrix sizes (int)
    stride_az, stride_am, stride_ak,   # strides for A (batch, row, col)
    stride_bz, stride_bn, stride_bk,   # strides for B (batch, row, col)
    stride_cz, stride_cm, stride_cn,   # strides for C (batch, row, col)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
    num_warps: tl.constexpr,
):
    """
    Each program instance computes a BLOCK_M×BLOCK_N tile of C for a
    particular (batch, head) pair.  B is accessed as its transpose, i.e.
    element (k, n) of the original tensor.
    """
    pid_batch = tl.program_id(2)                 # index in B*H dimension
    pid_m = tl.program_id(0)                     # tile row
    pid_n = tl.program_id(1)                     # tile col

    # ------------------------------------------------------------------
    # Offsets for this tile
    # ------------------------------------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # Pointers to the start of the A‑tile (row‑major) and B‑tile (will be read transposed)
    a_ptrs = a_ptr + pid_batch * stride_az \
                  + offs_m[:, None] * stride_am \
                  + tl.arange(0, BLOCK_K)[None, :] * stride_ak

    # For Bᵀ we need element (k, n) → row‑k, col‑n in the original layout.
    b_ptrs = b_ptr + pid_batch * stride_bz \
                  + tl.arange(0, BLOCK_K)[:, None] * stride_bk \
                  + offs_n[None, :] * stride_bn

    # Accumulator in FP32 (higher precision)
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ------------------------------------------------------------------
    # Loop over K dimension in tiles
    # ------------------------------------------------------------------
    for k_tile in range(0, tl.cdiv(K, BLOCK_K)):
        # Load A and B tiles (apply bounds masks)
        a = tl.load(
            a_ptrs,
            mask=mask_m[:, None] & (tl.arange(0, BLOCK_K)[None, :] < K),
            other=0.0,
        )
        b = tl.load(
            b_ptrs,
            mask=(tl.arange(0, BLOCK_K)[:, None] < K) & mask_n[None, :],
            other=0.0,
        )
        # FP16 × FP16 → FP32 dot product
        acc += tl.dot(a, b)

        # Advance tiles
        a_ptrs += BLOCK_K * stride_ak
        b_ptrs += BLOCK_K * stride_bk

    # ------------------------------------------------------------------
    # Write‑back (store as FP16 to keep bandwidth low)
    # ------------------------------------------------------------------
    c = acc.to(tl.float16)
    c_ptrs = c_ptr + pid_batch * stride_cz \
                     + offs_m[:, None] * stride_cm \
                     + offs_n[None, :] * stride_cn

    tl.store(c_ptrs, c, mask=mask_m[:, None] & mask_n[None, :])


def batched_gemm_fp16(a: torch.Tensor, b: torch.Tensor) -> torch.Tensor:
    """
    Batched GEMM wrapper.
    a,b : (B*H, N, N), dtype=torch.float16, contiguous.
    Returns c of same shape/dtype.
    """
    assert a.is_contiguous() and b.is_contiguous()
    B_H, M, K = a.shape
    assert K == M and b.shape == (B_H, M, K)

    c = torch.empty_like(a)

    # Strides in *elements* (not bytes)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bn, stride_bk = b.stride()   # original layout (batch, row, col)
    stride_cz, stride_cm, stride_cn = c.stride()

    # Tile sizes – good defaults for Hopper/SM90
    BLOCK_M = 128
    BLOCK_N = 128
    BLOCK_K = 32          # fits well into registers

    grid = (
        triton.cdiv(M, BLOCK_M),          # blocks along M
        triton.cdiv(N, BLOCK_N),          # blocks along N
        B_H,                               # batch*head dimension
    )
    # 8 warps is a sweet spot for 128×128 tiles on sm90
    batched_gemm_tiled_kernel[grid](
        a,
        b,
        c,
        M,
        N,
        K,
        stride_az,
        stride_am,
        stride_ak,
        stride_bz,
        stride_bn,
        stride_bk,
        stride_cz,
        stride_cm,
        stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=8,
        # num_stages can be left at default (2)
    )
    return c


# ----------------------------------------------------------------------
# Host‑side entry point required by the evaluation harness
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward‑only outgoing TriMul with a fused Triton GEMM.

    Args
    ----
    data : tuple
        (input_tensor, mask, weights, config)
        - input_tensor : torch.Tensor, shape (B, N, N, dim), dtype float32
        - mask         : torch.Tensor, shape (B, N, N)    (bool or float)
        - weights      : dict of torch.Tensors (all float32)
        - config       : dict with keys
            * "dim"          – input channel dimension
            * "hidden_dim"   – projection dimension (H)
            * "nomask" (bool, optional, default True)

    Returns
    -------
    torch.Tensor : shape (B, N, N, dim), dtype float32
    """
    # --------------------------------------------------------------
    # 0. unpack
    # --------------------------------------------------------------
    input_tensor, mask, weights, config = data
    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]
    nomask = config.get("nomask", True)

    # --------------------------------------------------------------
    # 1. Input LayerNorm over the last dim
    # --------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        (dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
    )   # (B, N, N, dim), float32

    # --------------------------------------------------------------
    # 2. Linear projections (no bias)
    # --------------------------------------------------------------
    left = F.linear(x, weights["left_proj.weight"])   # (B,N,N,hidden_dim)
    right = F.linear(x, weights["right_proj.weight"])

    # --------------------------------------------------------------
    # 3. Optional mask (broadcast on hidden dim)
    # --------------------------------------------------------------
    if not nomask:
        # mask can be bool or float; convert to same dtype as left/right
        mask_f = mask.to(left.dtype).unsqueeze(-1)    # (B,N,N,1)
        left = left * mask_f
        right = right * mask_f

    # --------------------------------------------------------------
    # 4. Gates (sigmoid of linear projections)
    # --------------------------------------------------------------
    left_gate = torch.sigmoid(F.linear(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"]))
    out_gate = torch.sigmoid(F.linear(x, weights["out_gate.weight"]))

    # Apply gates (element‑wise)
    left = left * left_gate
    right = right * right_gate

    # --------------------------------------------------------------
    # 5. Prepare tensors for the batched GEMM
    #    (B, N, N, H) -> (B, H, N, N) -> (B*H, N, N)  (fp16)
    # --------------------------------------------------------------
    left = left.permute(0, 3, 1, 2).contiguous()   # (B, H, N, N)
    right = right.permute(0, 3, 1, 2).contiguous()

    left = left.view(B * hidden_dim, N, N).to(torch.float16)
    right = right.view(B * hidden_dim, N, N).to(torch.float16)

    # --------------------------------------------------------------
    # 6. Batched GEMM: C = left @ rightᵀ   (still fp16)
    # --------------------------------------------------------------
    out_fp16 = batched_gemm_fp16(left, right)     # (B*H, N, N), fp16

    # --------------------------------------------------------------
    # 7. Reshape back to (B, N, N, H) and cast to fp32
    # --------------------------------------------------------------
    out = out_fp16.view(B, hidden_dim, N, N).permute(0, 2, 3, 1).to(torch.float32)

    # --------------------------------------------------------------
    # 8. Post‑projection LayerNorm + out‑gate
    # --------------------------------------------------------------
    out = F.layer_norm(
        out,
        (hidden_dim,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
    )
    out = out * out_gate          # out_gate shape (B,N,N,hidden_dim)

    # --------------------------------------------------------------
    # 9. Final linear projection back to `dim`
    # --------------------------------------------------------------
    out = F.linear(out, weights["to_out.weight"])

    return out
```

**Key points**

* The heavy `N³·hidden_dim` contraction is the only part executed in Triton (`batched_gemm_tiled_kernel`).  
* All other operations (LayerNorm, Linear, sigmoid gates, reshapes) stay in PyTorch – they are cheap relative to the GEMM and already highly optimized.  
* The kernel works with **FP16** inputs, accumulates in **FP32**, and writes back **FP16** to keep memory traffic low.  
* Masks and gates are applied **before** the permutation so the kernel never needs to read the mask or gate tensors.  
* Block sizes (`128×128×32`) and `num_warps=8` are chosen for the Hopper‑class H200 GPU; they give a solid performance‑/memory‑balance for all tested sequence lengths (256 → 1024).  

With this implementation the forward pass should comfortably beat the reference runtime (~700 µs target) while remaining numerically correct for all configurations listed in the problem statement.
