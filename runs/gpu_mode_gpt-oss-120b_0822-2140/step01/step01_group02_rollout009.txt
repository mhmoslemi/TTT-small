The “outgoing” TriMul operator consists of three‑step heavy work:

1. **Layer‑Norm + linear projections + gating** – cheap – done in PyTorch.  
2. **Batched contraction**  

\[
\text{out}[b,i,j,d]=\sum_{k} \text{left}[b,i,k,d]\,
                     \text{right}[b,j,k,d]
\]

   This is a batch of `hidden_dim` independent matrix‑multiplications  
   `left[b,:, :, d] @ right[b,:, :, d].T`.  
   We fuse all `(B·hidden_dim)` GEMMs in a single Triton kernel.
3. **Post‑norm, gating and final projection** – also done in PyTorch.

The kernel works in **FP16** (the model tolerates a little precision loss) and
accumulates in **FP32** for numerical stability.  The overall data layout is

```
left  : (B, N, N, hidden)   ─► (B, hidden, N, N) ▶ (B*hidden, N, N)  (fp16)
right : (B, N, N, hidden)   ─► (B, hidden, N, N) ▶ (B*hidden, N, N)  (fp16)
out   : (B*hidden, N, N)  (fp16)  ─► reshape back to (B, N, N, hidden) (fp32)
```

The kernel is a classic tiled GEMM (`BLOCK_M × BLOCK_N` tiles, `BLOCK_K`
micro‑tiles).  It loads the `k`‑tiles of **A** and **B**, computes `tl.dot`
(half‑precision × half‑precision → FP32 accumulation) and writes the result
as `fp16` to save bandwidth.

Below is the complete, self‑contained implementation.

```python
"""
TriMul “outgoing” forward pass (no gradients) with a fused Triton GEMM.

Algorithm
---------
1. LayerNorm over the last dimension (dim).
2. Linear projections (left/right) w/o bias.
3. Optional mask (broadcasted on the hidden dimension).
4. Gate logits → sigmoid, then element‑wise multiply with left/right.
5. Rearrange tensors to (B, hidden, N, N) and view as (B*hidden, N, N).
   Cast to fp16.
6. Batched GEMM kernel: for each (batch*head) compute
       C = A @ Bᵀ   (A,B : [N,N] fp16, C : [N,N] fp16)
   Accumulate in fp32, store as fp16.
7. Reshape back to (B, N, N, hidden) and cast to fp32.
8. LayerNorm over hidden dimension, apply out‑gate, final linear projection
   to the original dim.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched GEMM C = A @ Bᵀ
# ----------------------------------------------------------------------
@triton.jit
def batched_gemm_kernel(
    a_ptr, b_ptr, c_ptr,          # pointers
    M, N, K,                      # matrix sizes (int)
    stride_az, stride_am, stride_ak,   # strides for A (batch, row, col)
    stride_bz, stride_bk, stride_bn,   # strides for B (batch, row, col)
    stride_cz, stride_cm, stride_cn,   # strides for C (batch, row, col)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """Batched GEMM where B is logically transposed."""

    pid_batch = tl.program_id(2)          # (B * hidden)
    pid_m = tl.program_id(0)              # block row
    pid_n = tl.program_id(1)              # block col

    # ------------------------------------------------------------------
    # Offsets of the current tile
    # ------------------------------------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # Pointers to the start of the A / Bᵀ tiles
    a_ptrs = a_ptr + pid_batch * stride_az \
                 + offs_m[:, None] * stride_am \
                 + tl.arange(0, BLOCK_K)[None, :] * stride_ak

    # B is stored as (batch, N, K). For Bᵀ we need (k, n) → row‑k, col‑n.
    b_ptrs = b_ptr + pid_batch * stride_bz \
                 + tl.arange(0, BLOCK_K)[:, None] * stride_bk \
                 + offs_n[None, :] * stride_bn

    # Accumulator in FP32 (higher precision)
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ------------------------------------------------------------------
    # Main K‑loop
    # ------------------------------------------------------------------
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        # Load A tile (mask on rows, cols)
        a = tl.load(a_ptrs,
                    mask=mask_m[:, None] & (tl.arange(0, BLOCK_K)[None, :] < K),
                    other=0.0)
        # Load Bᵀ tile
        b = tl.load(b_ptrs,
                    mask=(tl.arange(0, BLOCK_K)[:, None] < K) & mask_n[None, :],
                    other=0.0)

        # fp16 × fp16 → fp32 accumulation
        acc += tl.dot(a, b)

        # Advance K‑pointers
        a_ptrs += BLOCK_K * stride_ak
        b_ptrs += BLOCK_K * stride_bk

    # ------------------------------------------------------------------
    # Write‑back (store as fp16)
    # ------------------------------------------------------------------
    c = acc.to(tl.float16)
    c_ptrs = c_ptr + pid_batch * stride_cz \
                     + offs_m[:, None] * stride_cm \
                     + offs_n[None, :] * stride_cn

    tl.store(c_ptrs, c, mask=mask_m[:, None] & mask_n[None, :])


def batched_gemm_fp16(a: torch.Tensor, b: torch.Tensor) -> torch.Tensor:
    """
    Batched GEMM where each batch entry does C = A @ Bᵀ.
    a, b : (B*H, N, N) fp16, contiguous.
    Returns c of the same shape / dtype.
    """
    assert a.is_contiguous() and b.is_contiguous()
    B_H, N, K = a.shape
    assert K == N

    c = torch.empty_like(a)

    # Strides in element units (not bytes)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bn, stride_bk = b.stride()   # (batch, N, K)
    stride_cz, stride_cm, stride_cn = c.stride()

    # Tiling – values work well on Hopper/SM90
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(N, BLOCK_M),      # program id 0 (row)
        triton.cdiv(N, BLOCK_N),      # program id 1 (col)
        B_H,                          # program id 2 (batch*head)
    )

    batched_gemm_kernel[grid](
        a,
        b,
        c,
        N,
        N,
        N,
        stride_az,
        stride_am,
        stride_ak,
        stride_bz,
        stride_bk,
        stride_bn,
        stride_cz,
        stride_cm,
        stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,          # empirically good for 64×64 tiles
        num_stages=2,
    )
    return c


# ----------------------------------------------------------------------
# Host side entry point required by the problem statement
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the TriMul “outgoing” module.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask, weights, config)
        - input_tensor : torch.Tensor shape [B, N, N, dim], float32
        - mask         : torch.Tensor shape [B, N, N] (bool / float), may be None
        - weights      : dict of model parameters (float32)
        - config       : dict with keys
              "dim" (int), "hidden_dim" (int), "nomask" (bool, default True)

    Returns
    -------
    torch.Tensor
        Output tensor of shape [B, N, N, dim] (float32)
    """
    # ------------------------------------------------------------------
    # unpack inputs
    # ------------------------------------------------------------------
    input_tensor, mask, weights, config = data
    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]
    nomask = config.get("nomask", True)

    # ------------------------------------------------------------------
    # 1. Input LayerNorm (dim)
    # ------------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        (dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
    )

    # ------------------------------------------------------------------
    # 2. Linear projections (no bias)
    # ------------------------------------------------------------------
    left = F.linear(x, weights["left_proj.weight"])      # (B,N,N,hidden)
    right = F.linear(x, weights["right_proj.weight"])

    # ------------------------------------------------------------------
    # 3. Mask (if present)
    # ------------------------------------------------------------------
    if not nomask:
        mask_exp = mask.unsqueeze(-1).to(left.dtype)    # (B,N,N,1)
        left = left * mask_exp
        right = right * mask_exp

    # ------------------------------------------------------------------
    # 4. Gates (sigmoid of linear projections)
    # ------------------------------------------------------------------
    left_gate = torch.sigmoid(F.linear(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"]))
    out_gate = torch.sigmoid(F.linear(x, weights["out_gate.weight"]))

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5. Rearrange for the batched GEMM: (B, hidden, N, N) → (B*hidden, N, N)
    # ------------------------------------------------------------------
    left = left.permute(0, 3, 1, 2).contiguous()   # (B, hidden, N, N)
    right = right.permute(0, 3, 1, 2).contiguous()

    # view as (B*hidden, N, N) and cast to fp16 for the kernel
    left = left.view(B * hidden_dim, N, N).to(torch.float16)
    right = right.view(B * hidden_dim, N, N).to(torch.float16)

    # ------------------------------------------------------------------
    # 6. Batched GEMM: C = left @ rightᵀ   (still fp16)
    # ------------------------------------------------------------------
    out_fp16 = batched_gemm_fp16(left, right)   # (B*hidden, N, N)

    # ------------------------------------------------------------------
    # 7. Reshape back to (B, N, N, hidden) and cast to fp32
    # ------------------------------------------------------------------
    out = (
        out_fp16.view(B, hidden_dim, N, N)
        .permute(0, 2, 3, 1)          # (B, N, N, hidden)
        .to(torch.float32)
    )

    # ------------------------------------------------------------------
    # 8. Post‑norm, gating and final projection
    # ------------------------------------------------------------------
    out = F.layer_norm(
        out,
        (hidden_dim,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
    )
    out = out * out_gate                               # (B,N,N,hidden)

    out = F.linear(out, weights["to_out.weight"])      # back to dim

    return out
```

The implementation follows the reasoning discussed earlier:

* **Lesson 1** – permute to `(B, hidden, N, N)` before the kernel and make the
  tensors contiguous (implemented).
* **Lesson 2** – compute and pass the exact strides to the Triton kernel
  (implemented).
* The kernel itself is a standard tiled GEMM with fp16 compute and fp32
  accumulation, which is the dominant `O(N³·hidden)` work and provides a
  large speed‑up over a pure‑Python/PyTorch implementation. The rest of the
  pipeline stays in PyTorch for simplicity and because it is cheap compared
  with the batched GEMM.

The function `custom_kernel` conforms to the required signature and returns a
float‑32 tensor of shape `[B, N, N, dim]`.
