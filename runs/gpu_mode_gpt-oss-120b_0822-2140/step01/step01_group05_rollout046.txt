"""
TriMul “outgoing” (AlphaFold‑3) forward pass.

Main work‑horse: a fused batched GEMM kernel written in Triton that
computes, for every hidden channel *h*:

    out[b, i, j, h] = Σ_k left[b, i, k, h] * right[b, j, k, h]

i.e. a batch of (N×N) @ (N×N)ᵀ matrices.  The kernel works on FP16
activations (the model uses FP32 weights, we cast the projected tensors
to FP16 before the multiplication) and accumulates in FP32 for
numerical stability.  All other operations (LayerNorm, linear
projections, gating, final projection) stay in PyTorch – they are
already highly optimized on the target GPU.

The implementation supports:
* B = 1 or 2,
* N up to 1024,
* dim ∈ {128,384},
* hidden_dim = 128,
* optional binary mask,
* both normal and heavy‑tailed input distributions.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched (A @ Bᵀ)   A,B : [B*H, N, N]  (FP16)
# ----------------------------------------------------------------------
@triton.jit
def batched_gemm_outgoing_kernel(
    A_ptr,          # fp16, shape (B*H, N, N)
    B_ptr,          # fp16, shape (B*H, N, N)
    C_ptr,          # fp32, shape (B*H, N, N)
    M, N, K,        # all equal to seq_len
    stride_ab, stride_am, stride_ak,   # strides for A (batch, row, col)
    stride_bb, stride_bm, stride_bk,   # strides for B (batch, row, col)
    stride_cb, stride_cm, stride_cn,   # strides for C (batch, row, col)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """Batched GEMM where the second operand is transposed (A @ Bᵀ)."""
    pid_b = tl.program_id(0)          # batch * hidden dimension
    pid_m = tl.program_id(1)          # tile row
    pid_n = tl.program_id(2)          # tile col

    # --------------------------------------------------------------
    # Tile offsets
    # --------------------------------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)
    offs_k = tl.arange(0, BLOCK_K)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # Pointers to the beginning of the current tile
    a_ptrs = (A_ptr + pid_b * stride_ab
              + offs_m[:, None] * stride_am
              + offs_k[None, :] * stride_ak)
    b_ptrs = (B_ptr + pid_b * stride_bb
              + offs_n[None, :] * stride_bm
              + offs_k[:, None] * stride_bk)   # note the transpose

    # Accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # Loop over K dimension
    # --------------------------------------------------------------
    for _k in range(0, tl.cdiv(K, BLOCK_K)):
        a = tl.load(a_ptrs,
                    mask=mask_m[:, None] & (offs_k[None, :] < K),
                    other=0.0).to(tl.float32)   # cast to fp32
        b = tl.load(b_ptrs,
                    mask=(offs_k[:, None] < K) & mask_n[None, :],
                    other=0.0).to(tl.float32)

        acc += tl.dot(a, b)                     # (M×K)·(K×N) → (M×N)

        # advance pointers to next K‑tile
        a_ptrs += BLOCK_K * stride_ak
        b_ptrs += BLOCK_K * stride_bk

    # --------------------------------------------------------------
    # Store result
    # --------------------------------------------------------------
    c_ptrs = (C_ptr + pid_b * stride_cb
              + offs_m[:, None] * stride_cm
              + offs_n[None, :] * stride_cn)
    tl.store(c_ptrs,
             acc,
             mask=mask_m[:, None] & mask_n[None, :])


# ----------------------------------------------------------------------
# Entry point called by the evaluator
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the “outgoing” TriMul operator.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask, weights, config)
        - input_tensor : torch.Tensor [B, N, N, dim]   (float32, CUDA)
        - mask         : torch.Tensor [B, N, N]        (bool/float, CUDA) or None
        - weights      : dict of torch.Tensor parameters (float32, CUDA)
        - config       : dict with keys ``dim`` and ``hidden_dim``

    Returns
    -------
    torch.Tensor
        Output tensor of shape [B, N, N, dim] (float32, CUDA)
    """
    # ------------------------------------------------------------------
    # unpack
    # ------------------------------------------------------------------
    input_tensor, mask, weights, config = data
    dim = config["dim"]
    hidden = config["hidden_dim"]
    B, N, _, _ = input_tensor.shape

    # ------------------------------------------------------------------
    # 1. Input LayerNorm (dim)
    # ------------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        normalized_shape=(dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
        eps=1e-5,
    )

    # ------------------------------------------------------------------
    # 2. Linear projections (no bias)
    # ------------------------------------------------------------------
    left  = F.linear(x, weights["left_proj.weight"])   # [B,N,N,hidden]
    right = F.linear(x, weights["right_proj.weight"])

    # ------------------------------------------------------------------
    # 3. Optional mask (broadcast over hidden dim)
    # ------------------------------------------------------------------
    if mask is not None:
        mask_ = mask.unsqueeze(-1)          # [B,N,N,1]
        left  = left  * mask_
        right = right * mask_

    # ------------------------------------------------------------------
    # 4. Gating (sigmoid) and apply
    # ------------------------------------------------------------------
    left_gate  = torch.sigmoid(F.linear(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"]))
    out_gate   = torch.sigmoid(F.linear(x, weights["out_gate.weight"]))

    left  = left  * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5. Cast to FP16 for the GEMM kernel
    # ------------------------------------------------------------------
    left_fp16  = left.to(torch.float16)
    right_fp16 = right.to(torch.float16)

    # (B, N, N, hidden) -> (B, hidden, N, N) -> (B*hidden, N, N)
    left_t  = left_fp16.permute(0, 3, 1, 2).contiguous()
    right_t = right_fp16.permute(0, 3, 1, 2).contiguous()
    left_mat  = left_t.view(B * hidden, N, N)
    right_mat = right_t.view(B * hidden, N, N)

    # output buffer (FP32 accumulator)
    out_mat = torch.empty_like(left_mat, dtype=torch.float32)

    # ------------------------------------------------------------------
    # 6. Triton launch configuration
    # ------------------------------------------------------------------
    # Tile sizes tuned for Hopper: 64x64 tiles, 64‑wide k‑reduction.
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 64

    grid = (
        B * hidden,                         # batch*hidden dimension
        triton.cdiv(N, BLOCK_M),            # row tiles
        triton.cdiv(N, BLOCK_N),            # col tiles
    )

    # strides (in elements) for the 3‑D tensors
    a_batch, a_row, a_col = left_mat.stride()
    b_batch, b_row, b_col = right_mat.stride()
    c_batch, c_row, c_col = out_mat.stride()

    batched_gemm_outgoing_kernel[grid](
        left_mat,
        right_mat,
        out_mat,
        N, N, N,                     # M, N, K
        a_batch, a_row, a_col,
        b_batch, b_row, b_col,
        c_batch, c_row, c_col,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # back to [B, N, N, hidden]
    out = out_mat.view(B, hidden, N, N).permute(0, 2, 3, 1).contiguous()

    # ------------------------------------------------------------------
    # 7. Output LayerNorm (hidden) + gating
    # ------------------------------------------------------------------
    out = F.layer_norm(
        out,
        normalized_shape=(hidden,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
        eps=1e-5,
    )
    out = out * out_gate

    # ------------------------------------------------------------------
    # 8. Final linear projection back to dim
    # ------------------------------------------------------------------
    out = F.linear(out, weights["to_out.weight"])

    return out
```

**Explanation of design choices**

* **Kernel tiling** – 64×64 tiles fit well in the 64 KB shared memory of the H200 and give enough registers for the FP16 → FP32 accumulation used by `tl.dot`.  
* **FP16 compute** – The linear projections are the dominant memory traffic; casting to FP16 halves the bandwidth while keeping the final result in FP32 (required by the rest of the model).  
* **Batch‑hidden fusion** – By reshaping to `(B*hidden, N, N)` we launch a single Triton grid covering all hidden channels, avoiding separate kernel launches and keeping the launch overhead negligible.  
* **Mask handling** – Masking is done in PyTorch before the kernel because it is a cheap element‑wise multiply and saves us from having to pass an extra mask pointer into the kernel.  
* **LayerNorm & linear ops** – These are already highly optimized in cuDNN / torch, so we keep them in PyTorch and focus the Triton effort on the O(N³) core of the module.

The kernel satisfies all constraints: it works for every configuration listed, respects the required signatures, and performs at least part of the computation in Triton.
