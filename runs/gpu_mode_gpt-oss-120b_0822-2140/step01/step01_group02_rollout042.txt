## Final implementation

```python
"""
TriMul “outgoing” forward pass (no backward).

The expensive contraction

    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]

is a batched matrix multiplication over the hidden dimension d:

    left  : (B, H, N, N)   →  (B*H, N, N)   (A)
    right : (B, H, N, N)   →  (B*H, N, N)   (B)
    out   = A @ Bᵀ        (one GEMM per head)

We fuse *all* GEMMs in a single Triton kernel.  All other ops
(LayerNorm, Linear, gates, final projection) stay in PyTorch – they are
tiny compared to the O(N³·H) work.

The kernel works in float16 and accumulates in float32 (`tl.dot` does
exactly that).  The final result is cast back to float32 for the rest of
the network.
"""
import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel : batched GEMM C = A @ Bᵀ
#   A,B shape = (batch, M, K)  where K == N
#   C shape = (batch, M, N)
# ----------------------------------------------------------------------
@triton.jit
def _batched_gemm_kernel(
    a_ptr, b_ptr, c_ptr,               # pointers (float16)
    M, N, K,                           # matrix sizes (int)
    stride_az, stride_am, stride_ak,   # A strides (batch, row, col)
    stride_bz, stride_bk, stride_bn,   # B strides (batch, row, col) – original layout
    stride_cz, stride_cm, stride_cn,   # C strides (batch, row, col)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """Batched GEMM where the second operand is logically transposed."""
    pid_z = tl.program_id(2)          # batch * hidden_dim
    pid_m = tl.program_id(0)          # tile-row
    pid_n = tl.program_id(1)          # tile-col

    # ------------------------------------------------------------------
    # 1) Compute tile offsets
    # ------------------------------------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # ------------------------------------------------------------------
    # 2) Pointers to the start of the tiles
    # ------------------------------------------------------------------
    a_tile_ptr = (
        a_ptr
        + pid_z * stride_az
        + offs_m[:, None] * stride_am
        + tl.arange(0, BLOCK_K)[None, :] * stride_ak
    )
    # B is stored as (batch, N, K).  For Bᵀ we need element (k, n) → row‑k,
    # col‑n in the original layout.
    b_tile_ptr = (
        b_ptr
        + pid_z * stride_bz
        + tl.arange(0, BLOCK_K)[:, None] * stride_bk
        + offs_n[None, :] * stride_bn
    )

    # ------------------------------------------------------------------
    # 3) Accumulator (FP32)
    # ------------------------------------------------------------------
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # Pre‑compute masks that are independent of the K‑loop
    k_full = tl.arange(0, BLOCK_K) < K

    # ------------------------------------------------------------------
    # 4) Main K‑loop
    # ------------------------------------------------------------------
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        # Load a (M×K) tile
        a = tl.load(
            a_tile_ptr,
            mask=mask_m[:, None] & k_full[None, :],
            other=0.0,
        )
        # Load b (K×N) tile (remember we are using Bᵀ)
        b = tl.load(
            b_tile_ptr,
            mask=k_full[:, None] & mask_n[None, :],
            other=0.0,
        )
        # FP16×FP16 → FP32 accumulation
        acc += tl.dot(a, b)

        # Advance pointers to the next K‑tile
        a_tile_ptr += BLOCK_K * stride_ak
        b_tile_ptr += BLOCK_K * stride_bk

    # ------------------------------------------------------------------
    # 5) Write result back (store as FP16 to save bandwidth)
    # ------------------------------------------------------------------
    c = acc.to(tl.float16)
    c_tile_ptr = (
        c_ptr
        + pid_z * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn
    )
    tl.store(c_tile_ptr, c, mask=mask_m[:, None] & mask_n[None, :])


# ----------------------------------------------------------------------
# Host helper
# ----------------------------------------------------------------------
def _batched_gemm_fp16(a: torch.Tensor, b: torch.Tensor) -> torch.Tensor:
    """
    Batched GEMM C = A @ Bᵀ   (A,B shape == (B*H, N, N), dtype==float16)
    Returns C of the same shape/dtype.
    """
    assert a.is_contiguous() and b.is_contiguous()
    B_H, N, K = a.shape
    assert K == N  # square pairwise matrices

    c = torch.empty_like(a)

    # Element‑wise strides (not bytes!)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bn, stride_bk = b.stride()   # (batch, N, K) layout
    stride_cz, stride_cm, stride_cn = c.stride()

    # Tile sizes – 128×128 works well on Hopper/SM90; K‑tile 32 fits registers.
    BLOCK_M = 128
    BLOCK_N = 128
    BLOCK_K = 32

    grid = (
        triton.cdiv(N, BLOCK_M),   # pid_m
        triton.cdiv(N, BLOCK_N),   # pid_n
        B_H,                       # pid_z  (batch * hidden_dim)
    )

    _batched_gemm_kernel[grid](
        a,
        b,
        c,
        N,
        N,
        N,
        stride_az,
        stride_am,
        stride_ak,
        stride_bz,
        stride_bk,
        stride_bn,
        stride_cz,
        stride_cm,
        stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=4,               # empirically good for 128×128 tiles
    )
    return c


# ----------------------------------------------------------------------
# Entry point required by the evaluator
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the TriMul “outgoing” module with a fused Triton GEMM.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask, weights, config)
        * input_tensor : torch.Tensor [B, N, N, dim]      (float32)
        * mask          : torch.Tensor [B, N, N]          (bool or float)
        * weights       : dict of torch.Tensors (all float32)
        * config        : dict with keys
              - "dim"          : input channel dimension
              - "hidden_dim"   : projection dimension H
              - "nomask" (bool, optional) : True ⇒ ignore mask

    Returns
    -------
    torch.Tensor
        Output tensor [B, N, N, dim] (float32)
    """
    # ------------------------------------------------------------------
    # Unpack arguments
    # ------------------------------------------------------------------
    input_tensor, mask, weights, config = data
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    nomask = config.get("nomask", True)

    B, N, _, _ = input_tensor.shape

    # ------------------------------------------------------------------
    # 1) LayerNorm over the last dimension (dim)
    # ------------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        (dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
    )

    # ------------------------------------------------------------------
    # 2) Linear projections (no bias)
    # ------------------------------------------------------------------
    left = F.linear(x, weights["left_proj.weight"])   # (B,N,N,hidden_dim)
    right = F.linear(x, weights["right_proj.weight"])

    # ------------------------------------------------------------------
    # 3) Optional mask (broadcasted on hidden dimension)
    # ------------------------------------------------------------------
    if not nomask:
        mask_exp = mask.unsqueeze(-1).to(left.dtype)          # (B,N,N,1)
        left = left * mask_exp
        right = right * mask_exp

    # ------------------------------------------------------------------
    # 4) Gating (sigmoid of linear projections)
    # ------------------------------------------------------------------
    left_gate = torch.sigmoid(F.linear(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"]))
    out_gate = torch.sigmoid(F.linear(x, weights["out_gate.weight"]))

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5) Prepare tensors for the batched GEMM
    #    (B, N, N, H) --> (B, H, N, N) --> (B*H, N, N)
    # ------------------------------------------------------------------
    left = left.permute(0, 3, 1, 2).contiguous()   # (B, H, N, N)
    right = right.permute(0, 3, 1, 2).contiguous()

    left = left.view(B * hidden_dim, N, N).to(torch.float16)
    right = right.view(B * hidden_dim, N, N).to(torch.float16)

    # ------------------------------------------------------------------
    # 6) Batched GEMM: out_fp16 = left @ rightᵀ   (still fp16)
    # ------------------------------------------------------------------
    out_fp16 = _batched_gemm_fp16(left, right)   # (B*H, N, N)

    # ------------------------------------------------------------------
    # 7) Reshape back to (B, N, N, H) and cast to fp32
    # ------------------------------------------------------------------
    out = (
        out_fp16.view(B, hidden_dim, N, N)
        .permute(0, 2, 3, 1)
        .to(torch.float32)
    )

    # ------------------------------------------------------------------
    # 8) Post‑projection LayerNorm (hidden_dim) + output gate
    # ------------------------------------------------------------------
    out = F.layer_norm(
        out,
        (hidden_dim,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
    )
    out = out * out_gate      # out_gate shape matches (B,N,N,hidden_dim)

    # ------------------------------------------------------------------
    # 9) Final linear projection back to `dim`
    # ------------------------------------------------------------------
    out = F.linear(out, weights["to_out.weight"])

    return out
```

**What the code does**

1. **LayerNorm + linear projections** – done in PyTorch (they are cheap).  
2. **Mask & gating** – also in PyTorch; the mask is applied before the contraction.  
3. **Permutation & view** – brings the hidden dimension into the batch axis, yielding a tensor `(B·H, N, N)` that can be treated as a batch of independent GEMMs.  
4. **Batched GEMM kernel** – computes `C = A @ Bᵀ` for every head in a single launch.  The kernel tiles the `M` and `N` dimensions (128 × 128) and iterates over `K` in 32‑element chunks, using `tl.dot` for FP16×FP16 → FP32 accumulation.  
5. **Reshape / post‑norm / gating / final linear** – finish the forward path in PyTorch.

The implementation respects all constraints:

* Works for any `B ∈ {1,2}`, `N ∈ {128,256,512,1024}`, `dim ∈ {128,384}`, `hidden_dim ∈ {128,384,768}`.  
* Handles both masked and un‑masked inputs.  
* No gradients are computed (forward‑only).  
* Only the expensive `einsum`‑equivalent contraction is in Triton; everything else stays in PyTorch.  

This should meet the required correctness and achieve runtimes well below the 700 µs target on an NVIDIA H200.
