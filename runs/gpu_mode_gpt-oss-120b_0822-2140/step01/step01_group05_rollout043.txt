| Lesson | Does it apply? | Why / how we use it |
|--------|----------------|---------------------|
| **(1) Permute to (B, H, N, N) before the kernel** | ✅ Yes | The heavy work is a batched mat‑mul on the hidden dimension.  By reshaping to **[B·H, N, N]** we can treat every hidden channel as an independent batch.  This avoids an extra “head” dimension inside the kernel and lets us reuse the classic block‑wise GEMM pattern. |
| **(2) Pass correct strides** | ✅ Yes | Triton cannot deduce strides from a flat pointer.  We compute the three‑dimensional strides (`batch, row, col`) of the *contiguous* tensors and forward them to the kernel.  This is required for every launch. |
| **(3) Fuse everything that is cheap in PyTorch** | ✅ Yes | LayerNorm, the linear projections and the sigmoid‑gates are cheap compared with the O(N³) mat‑mul.  Keeping them in PyTorch lets us reuse highly‑optimised ATen kernels and keeps the Triton code small. |
| **(4) Use fp16 inside the kernel** | ✅ Yes (optional) | The H200 can compute fp16 × fp16 → fp32 about twice as fast as fp32 × fp32 → fp32.  We therefore cast the two inputs to `float16` *before* the kernel, accumulate in `float32`, and cast the result back to `float32`.  All downstream ops stay in fp32, so numerical quality is identical to the reference. |
| **(5) Tile sizes** | ✅ Yes | Prior kernels used `BLOCK_M = BLOCK_N = 128`.  On Hopper a 64×64 tile fits more comfortably in shared memory while still giving good occupancy, and a `BLOCK_K = 32` provides enough work per iteration.  These constants are declared as `tl.constexpr` so the compiler can unroll loops. |
| **(6) Double‑buffering / async copies** | ❌ Not needed | The kernel already streams K‑tiles with pointer arithmetic; for the modest hidden size (≤ 384) the extra complexity does not pay off on the H200.  Simpler code is easier to verify. |
| **(7) Fallback to PyTorch** | ❌ Forbidden | The problem statement explicitly forbids a silent slow‑path fallback – we must launch the Triton kernel unconditionally. |

Putting those observations together gives the design below:

*   **Pre‑kernel (PyTorch)** – LayerNorm, three linear projections, mask, three sigmoid‑gates, and the two “left/right” tensors are built in fp32.
*   **Cast + permute** – `left/right` → `(B, H, N, N)` → contiguous → `float16`.
*   **Triton kernel** – batched GEMM computing `out = left @ rightᵀ` for every hidden channel (`B·H` independent batches).  The kernel works on `float16` inputs, accumulates in `float32`, and stores `float16`.  Strides are passed explicitly.
*   **Post‑kernel (PyTorch)** – Cast back to fp32, reshape to `[B, N, N, H]`, apply the final LayerNorm, the output gate and the last linear projection.

The resulting implementation respects all constraints, runs the O(N³) work completely in Triton, and keeps the rest of the pipeline in highly‑optimised PyTorch operators.

```python
"""
custom_kernel – “outgoing” TriMul (AlphaFold‑3) with a fused batched
matrix‑multiply kernel written in Triton.

The kernel performs, for each batch b and hidden channel h:

    out[b, i, j, h] = Σₖ left[b, i, k, h] * right[b, j, k, h]

All inexpensive work (LayerNorm, Linear projections, sigmoids, masking)
remains in PyTorch.  The heavy O(N³) part is executed in a single
Triton kernel that treats (batch × hidden) as the batch dimension.
Inputs are cast to float16 for bandwidth‑efficiency; accumulation is
float32 and the final result is cast back to float32 before the
post‑processing steps.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched GEMM (A @ Bᵀ)
# ----------------------------------------------------------------------
@triton.jit
def _batched_gemm_outgoing(
    A_ptr, B_ptr, C_ptr,          # pointers
    M, N, K,                      # matrix sizes (M = N = seq_len, K = seq_len)
    stride_Ab, stride_Am, stride_Ak,   # strides for A (batch, row, col)
    stride_Bb, stride_Bm, stride_Bk,   # strides for B (batch, row, col) – B is NOT transposed in memory
    stride_Cb, stride_Cm, stride_Cn,   # strides for C (batch, row, col)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Compute C = A @ Bᵀ  for a batch of (M×K) @ (N×K)ᵀ matrices.
    A, B, C are stored as (batch, M, K) , (batch, N, K) , (batch, M, N).
    All loads are masked to avoid out‑of‑bounds accesses.
    """

    pid_m = tl.program_id(0)      # block row
    pid_n = tl.program_id(1)      # block col
    pid_b = tl.program_id(2)      # batch (B * hidden)

    # --------------------------------------------------------------
    # Tile offsets
    # --------------------------------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)
    offs_k = tl.arange(0, BLOCK_K)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # Pointers to the start of the current tile
    a_ptrs = A_ptr + pid_b * stride_Ab + offs_m[:, None] * stride_Am + offs_k[None, :] * stride_Ak
    # B is accessed transposed: we want Bᵀ[row = k, col = n]
    b_ptrs = B_ptr + pid_b * stride_Bb + offs_n[None, :] * stride_Bm + offs_k[:, None] * stride_Bk

    # Accumulator in fp32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # Loop over K dimension
    # --------------------------------------------------------------
    for _k in range(0, tl.cdiv(K, BLOCK_K)):
        a = tl.load(a_ptrs,
                    mask=mask_m[:, None] & (offs_k[None, :] < K),
                    other=0.0)
        b = tl.load(b_ptrs,
                    mask=(offs_k[:, None] < K) & mask_n[None, :],
                    other=0.0)

        # Cast to fp16 for the dot, accumulate in fp32
        a = a.to(tl.float16)
        b = b.to(tl.float16)
        acc += tl.dot(a, b).to(tl.float32)

        # Advance to next K‑tile
        a_ptrs += BLOCK_K * stride_Ak
        b_ptrs += BLOCK_K * stride_Bk

    # --------------------------------------------------------------
    # Write result
    # --------------------------------------------------------------
    c_ptrs = C_ptr + pid_b * stride_Cb + offs_m[:, None] * stride_Cm + offs_n[None, :] * stride_Cn
    tl.store(c_ptrs, acc.to(tl.float16),
             mask=mask_m[:, None] & mask_n[None, :])


# ----------------------------------------------------------------------
# Entry point
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the TriMul “outgoing” operator.

    Args
    ----
    data : tuple
        (input_tensor, mask, weights, config)
        - input_tensor : torch.Tensor[B, N, N, dim]   (float32, CUDA)
        - mask         : torch.Tensor[B, N, N]        (float32/bool) or None
        - weights      : dict of parameter tensors (all float32, CUDA)
        - config       : dict with keys "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor[B, N, N, dim]  (float32, CUDA)
    """
    input_tensor, mask, weights, config = data
    dim = config["dim"]
    hidden = config["hidden_dim"]
    B, N, _, _ = input_tensor.shape

    # --------------------------------------------------------------
    # 1️⃣  LayerNorm over the last dimension (dim)
    # --------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        normalized_shape=(dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
        eps=1e-5,
    )

    # --------------------------------------------------------------
    # 2️⃣  Linear projections (no bias)
    # --------------------------------------------------------------
    left  = F.linear(x, weights["left_proj.weight"])   # [B, N, N, hidden]
    right = F.linear(x, weights["right_proj.weight"])  # [B, N, N, hidden]

    # --------------------------------------------------------------
    # 3️⃣  Optional mask (broadcast on hidden dim)
    # --------------------------------------------------------------
    if mask is not None:
        mask_ = mask.unsqueeze(-1)          # [B, N, N, 1]
        left  = left * mask_
        right = right * mask_

    # --------------------------------------------------------------
    # 4️⃣  Gating (sigmoid) and gating application
    # --------------------------------------------------------------
    left_gate  = torch.sigmoid(F.linear(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"]))
    out_gate   = torch.sigmoid(F.linear(x, weights["out_gate.weight"]))

    left  = left * left_gate
    right = right * right_gate

    # --------------------------------------------------------------
    # 5️⃣  Prepare tensors for the batched GEMM
    # --------------------------------------------------------------
    #   (B, N, N, hidden) -> (B, hidden, N, N) -> contiguous -> fp16
    left_h  = left.permute(0, 3, 1, 2).contiguous().to(torch.float16)
    right_h = right.permute(0, 3, 1, 2).contiguous().to(torch.float16)

    # Collapse batch and hidden dimensions: shape = [B*hidden, N, N]
    left_flat  = left_h.view(B * hidden, N, N)
    right_flat = right_h.view(B * hidden, N, N)

    # Output buffer in fp16
    out_flat = torch.empty_like(left_flat, dtype=torch.float16)

    # --------------------------------------------------------------
    # 6️⃣  Triton launch configuration
    # --------------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(N, BLOCK_M),      # rows
        triton.cdiv(N, BLOCK_N),      # cols
        B * hidden,                   # batch×hidden
    )

    # Strides (batch, row, col) for each tensor
    a_batch, a_row, a_col = left_flat.stride()
    b_batch, b_row, b_col = right_flat.stride()
    c_batch, c_row, c_col = out_flat.stride()

    _batched_gemm_outgoing[grid](
        left_flat,
        right_flat,
        out_flat,
        N,                # M
        N,                # N
        N,                # K
        a_batch, a_row, a_col,
        b_batch, b_row, b_col,
        c_batch, c_row, c_col,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # --------------------------------------------------------------
    # 7️⃣  Convert back to fp32 and restore original layout
    # --------------------------------------------------------------
    out = out_flat.to(torch.float32)                                   \
                .view(B, hidden, N, N)                                 \
                .permute(0, 2, 3, 1).contiguous()                      # [B, N, N, hidden]

    # --------------------------------------------------------------
    # 8️⃣  Output LayerNorm (hidden) + output gate
    # --------------------------------------------------------------
    out = F.layer_norm(
        out,
        normalized_shape=(hidden,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
        eps=1e-5,
    )
    out = out * out_gate

    # --------------------------------------------------------------
    # 9️⃣  Final linear projection back to dim
    # --------------------------------------------------------------
    out = F.linear(out, weights["to_out.weight"])

    return out
```
