| Lesson | Relevance for this kernel |
|-------|---------------------------|
| 1️⃣ *Permute to (B, H, N, N) before kernel* | **Useful** – the contraction is a batched GEMM where each head (`hidden_dim`) can be treated as an independent batch.  Permuting to `(B, H, N, N)` lets us reshape to `(B·H, N, N)` and launch a single Triton kernel that works on a 3‑D tensor. |
| 2️⃣ *Pass correct strides* | **Essential** – Triton loads/stores need exact element‑wise strides.  The host helper computes the strides of the reshaped, contiguous tensors and passes them to the kernel. |
| 3️⃣ *Keep everything in Triton* | **Not required** – the surrounding LayerNorms, Linear projections, and sigmoids are cheap compared to the `O(N³·H)` contraction, so we keep them in PyTorch for clarity.  Only the heavy GEMM is fused. |
| 4️⃣ *Mean/var for LayerNorm* | **Irrelevant** – we perform LayerNorm with `torch.nn.functional.layer_norm`, avoiding any synchronisation inside Triton. |
| 5️⃣ *Mixed‑precision* | **Beneficial** – we compute the GEMM in `float16` (the model tolerates it) and accumulate in `float32` for accuracy, then cast back to `float32` for the final layers. |

With those observations the implementation below:

*   performs the cheap linear/gate/LayerNorm work in PyTorch;
*   reshapes the tensors so that each `(head)` becomes a separate batch;
*   launches a single Triton kernel that computes `C = A @ Bᵀ` for all batches in parallel;
*   restores the original shape, applies the post‑norm, gating and final linear projection;
*   returns a `float32` tensor of shape `[B, N, N, dim]`.

"""
TriMul “outgoing” forward pass (AlphaFold3) with a fused Triton GEMM.

The costly contraction
    out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]
is a batched matrix multiplication per head:
    C = A @ Bᵀ   with A,B ∈ (B·H, N, N).

All inexpensive ops (LayerNorm, Linear, sigmoid gating) are kept in
PyTorch.  The GEMM is performed in float16 with FP32 accumulation
inside a Triton kernel, then cast back to float32.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched GEMM C = A @ Bᵀ  (A,B shape [B·H, N, K]), K == N
# ----------------------------------------------------------------------
@triton.jit
def batched_gemm_outgoing_kernel(
    a_ptr, b_ptr, c_ptr,               # pointers
    M, N, K,                           # matrix dimensions (int)
    stride_az, stride_am, stride_ak,   # strides for A (batch, row, col)
    stride_bz, stride_bk, stride_bn,   # strides for B (batch, row, col)
    stride_cz, stride_cm, stride_cn,   # strides for C (batch, row, col)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """Batched GEMM where the second operand is logically transposed."""
    pid_batch = tl.program_id(2)   # index over (B·H)
    pid_m = tl.program_id(0)       # block‑row
    pid_n = tl.program_id(1)       # block‑col

    # ------------------------------------------------------------------
    # Offsets for this block
    # ------------------------------------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # Pointers to the current tile of A (row‑major)
    a_ptrs = (
        a_ptr
        + pid_batch * stride_az
        + offs_m[:, None] * stride_am
        + tl.arange(0, BLOCK_K)[None, :] * stride_ak
    )

    # For Bᵀ we need elements (k, n) from the original B layout
    b_ptrs = (
        b_ptr
        + pid_batch * stride_bz
        + tl.arange(0, BLOCK_K)[:, None] * stride_bk
        + offs_n[None, :] * stride_bn
    )

    # Accumulator in FP32 (higher precision than FP16)
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ------------------------------------------------------------------
    # Main K‑loop
    # ------------------------------------------------------------------
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        a = tl.load(
            a_ptrs,
            mask=mask_m[:, None] & (tl.arange(0, BLOCK_K)[None, :] < K),
            other=0.0,
        )
        b = tl.load(
            b_ptrs,
            mask=(tl.arange(0, BLOCK_K)[:, None] < K) & mask_n[None, :],
            other=0.0,
        )
        acc += tl.dot(a, b)          # FP16 × FP16 → FP32
        a_ptrs += BLOCK_K * stride_ak
        b_ptrs += BLOCK_K * stride_bk

    # ------------------------------------------------------------------
    # Write‑back (store as FP16 to reduce memory traffic)
    # ------------------------------------------------------------------
    c = acc.to(tl.float16)
    c_ptrs = (
        c_ptr
        + pid_batch * stride_cz
        + offs_m[:, None] * stride_cm
        + offs_n[None, :] * stride_cn
    )
    tl.store(c_ptrs, c, mask=mask_m[:, None] & mask_n[None, :])


# ----------------------------------------------------------------------
# Helper that launches the kernel
# ----------------------------------------------------------------------
def batched_gemm_outgoing_fp16(a: torch.Tensor, b: torch.Tensor) -> torch.Tensor:
    """
    a, b : tensors of shape (B·H, N, N), dtype float16, contiguous.
    Returns c of the same shape and dtype.
    """
    assert a.is_contiguous() and b.is_contiguous()
    B_H, N, K = a.shape
    assert K == N, "Square matrices expected for TriMul."

    c = torch.empty_like(a)

    # Strides in elements (not bytes)
    stride_az, stride_am, stride_ak = a.stride()
    stride_bz, stride_bn, stride_bk = b.stride()   # original layout (batch, N, K)
    stride_cz, stride_cm, stride_cn = c.stride()

    # Tile sizes – 128×128 tiles work well on Hopper; K‑tile 32 fits registers.
    BLOCK_M = 128
    BLOCK_N = 128
    BLOCK_K = 32

    grid = (
        triton.cdiv(N, BLOCK_M),   # rows
        triton.cdiv(N, BLOCK_N),   # cols
        B_H,                       # batch * heads
    )
    batched_gemm_outgoing_kernel[grid](
        a,
        b,
        c,
        N,
        N,
        N,
        stride_az,
        stride_am,
        stride_ak,
        stride_bz,
        stride_bk,
        stride_bn,
        stride_cz,
        stride_cm,
        stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=8,               # empirically good on sm90
    )
    return c


# ----------------------------------------------------------------------
# Entry‑point required by the test harness
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    TriMul “outgoing” forward pass.

    Args:
        data: tuple (input_tensor, mask, weights, config)
            - input_tensor : torch.Tensor [B, N, N, dim]      (float32)
            - mask         : torch.Tensor [B, N, N]          (bool or float)
            - weights      : dict of torch.Tensor (float32)
            - config       : dict with keys
                  "dim" (int), "hidden_dim" (int), "nomask" (bool, optional)

    Returns:
        torch.Tensor of shape [B, N, N, dim] (float32)
    """
    input_tensor, mask, weights, config = data

    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]
    nomask = config.get("nomask", True)

    # ------------------------------------------------------------------
    # 1. Input LayerNorm over the last dim
    # ------------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        (dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
    )

    # ------------------------------------------------------------------
    # 2. Linear projections (no bias in the original model)
    # ------------------------------------------------------------------
    left = F.linear(x, weights["left_proj.weight"])   # (B,N,N,hidden_dim)
    right = F.linear(x, weights["right_proj.weight"])

    # ------------------------------------------------------------------
    # 3. Optional mask (broadcast on the hidden dimension)
    # ------------------------------------------------------------------
    if not nomask:
        mask_exp = mask.unsqueeze(-1).to(left.dtype)   # (B,N,N,1)
        left = left * mask_exp
        right = right * mask_exp

    # ------------------------------------------------------------------
    # 4. Gates (sigmoid of a linear projection)
    # ------------------------------------------------------------------
    left_gate = torch.sigmoid(F.linear(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"]))
    out_gate = torch.sigmoid(F.linear(x, weights["out_gate.weight"]))

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5. Rearrange for the batched GEMM:
    #   (B, N, N, H) -> (B, H, N, N) -> (B*H, N, N)
    #   Cast to float16 for the kernel.
    # ------------------------------------------------------------------
    left = left.permute(0, 3, 1, 2).contiguous()   # (B, H, N, N)
    right = right.permute(0, 3, 1, 2).contiguous()

    left = left.view(B * hidden_dim, N, N).to(torch.float16)
    right = right.view(B * hidden_dim, N, N).to(torch.float16)

    # ------------------------------------------------------------------
    # 6. Batched GEMM: C = left @ rightᵀ   (still float16)
    # ------------------------------------------------------------------
    out_fp16 = batched_gemm_outgoing_fp16(left, right)   # (B*H, N, N)

    # ------------------------------------------------------------------
    # 7. Reshape back to (B, N, N, H) and cast to float32
    # ------------------------------------------------------------------
    out = (
        out_fp16.view(B, hidden_dim, N, N)
        .permute(0, 2, 3, 1)
        .to(torch.float32)
    )

    # ------------------------------------------------------------------
    # 8. Post‑projection LayerNorm + gating
    # ------------------------------------------------------------------
    out = F.layer_norm(
        out,
        (hidden_dim,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
    )
    out = out * out_gate          # (B,N,N,H) broadcast works

    # ------------------------------------------------------------------
    # 9. Final linear projection back to `dim`
    # ------------------------------------------------------------------
    out = F.linear(out, weights["to_out.weight"])

    return out
