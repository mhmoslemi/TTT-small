The outgoing TriMul operator consists of three parts that dominate the runtime  

1. **Layer‑norm + linear / gating** – cheap, kept in PyTorch.  
2. **Batched matrix‑multiply**  

```
out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]          (h = hidden_dim)
```

   For each head **h** this is a matrix product  
   ` (N×N)  @  (N×N)ᵀ `.  
   We fuse **all** heads and the batch dimension (`B·hidden_dim`) into a single
   Triton kernel.  
3. **Output‑norm + final linear** – also in PyTorch.

The heavy part is implemented as a *blocked* GEMM that works on the
tensor shape `(B·H, N, N)`.  The kernel

* loads a `BLOCK_M × BLOCK_K` tile of **A** (`left`) and a `BLOCK_K × BLOCK_N`
  tile of **Bᵀ** (`right`)  
* accumulates the product in FP32 (`acc`)  
* stores the `BLOCK_M × BLOCK_N` result tile.

The implementation respects the lessons learned in the previous attempts:

| Lesson | Action taken |
|--------|--------------|
| **Permute to (B, H, N, N) before kernel** | Done (`left.permute(0,3,1,2)`). |
| **Pass correct strides** | Strides are read from the *contiguous* tensors and passed
  verbatim to the kernel. |
| **Do not rely on `tl.mean`** | Not needed – we use the PyTorch `nn.LayerNorm`. |
| **Avoid excessive tiling** | Tile sizes (`64×64×64`) match the H200 SM‑90 cache line
  size and give a good trade‑off between shared‑memory pressure and occupancy. |
| **Mixed‑precision is optional** | The kernel stays in FP32 (the reference
  implementation uses FP32).  Changing to FP16 would require extra casts and
  does not improve the already‑fast baseline for the target shapes. |

The rest of the forward pass stays in PyTorch, which keeps the code short,
readable and numerically identical to the reference implementation.

```python
"""
custom_kernel – outgoing TriMul (AlphaFold‑3) with a fused batched GEMM.

The kernel computes, for every batch element and hidden head,
   out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]

where
    left  = (x @ left_proj)   * sigmoid(x @ left_gate)
    right = (x @ right_proj)  * sigmoid(x @ right_gate)

All LayerNorm, linear layers and gating are performed in PyTorch.
The heavy GEMM (`left @ rightᵀ`) is executed by a single Triton kernel that
processes the whole `(B·hidden, N, N)` tensor in blocks of 64×64×64.
The kernel works for any batch size (1 or 2), sequence length up to 1024 and
hidden dimension up to 384 while keeping the final tensor in float32.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched (A @ Bᵀ) for many “heads” at once
# ----------------------------------------------------------------------
@triton.jit
def _batched_gemm_kernel(
    A_ptr, B_ptr, C_ptr,          # pointers to the three tensors
    M, N, K,                      # matrix dimensions (M = N = seq_len, K = seq_len)
    stride_Ab, stride_Am, stride_Ak,   # strides for A (batch, row, col)
    stride_Bb, stride_Bm, stride_Bk,   # strides for B (batch, row, col)
    stride_Cb, stride_Cm, stride_Cn,   # strides for C (batch, row, col)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    A : (batch, M, K)
    B : (batch, N, K)   – we use it as Bᵀ inside the kernel
    C : (batch, M, N)   = A @ Bᵀ
    """
    pid_b = tl.program_id(0)          # batch * hidden index
    pid_m = tl.program_id(1)          # tile row
    pid_n = tl.program_id(2)          # tile column

    # ------------------------------------------------------------------
    # Compute the absolute offsets of the current tile
    # ------------------------------------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)
    offs_k = tl.arange(0, BLOCK_K)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # Pointers to the beginning of the tile
    a_ptrs = (
        A_ptr
        + pid_b * stride_Ab
        + offs_m[:, None] * stride_Am
        + offs_k[None, :] * stride_Ak
    )
    b_ptrs = (
        B_ptr
        + pid_b * stride_Bb
        + offs_n[None, :] * stride_Bm      # note the swapped order – treats B as transposed
        + offs_k[:, None] * stride_Bk
    )

    # Accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ------------------------------------------------------------------
    # Loop over K dimension (tiling)
    # ------------------------------------------------------------------
    num_k_tiles = tl.cdiv(K, BLOCK_K)
    for k_idx in range(num_k_tiles):
        # Load tiles – masks guard out‑of‑bounds elements
        a = tl.load(a_ptrs, mask=mask_m[:, None] & (offs_k[None, :] < K), other=0.0)
        b = tl.load(b_ptrs, mask=(offs_k[:, None] < K) & mask_n[None, :], other=0.0)

        # Rank‑K dot product
        acc += tl.dot(a, b)      # (BLOCK_M, BLOCK_K) @ (BLOCK_K, BLOCK_N)

        # Advance to the next K‑tile
        a_ptrs += BLOCK_K * stride_Ak
        b_ptrs += BLOCK_K * stride_Bk

    # ------------------------------------------------------------------
    # Write result
    # ------------------------------------------------------------------
    c_ptrs = (
        C_ptr
        + pid_b * stride_Cb
        + offs_m[:, None] * stride_Cm
        + offs_n[None, :] * stride_Cn
    )
    tl.store(c_ptrs, acc, mask=mask_m[:, None] & mask_n[None, :])


# ----------------------------------------------------------------------
# Entry‑point called by the evaluator
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Args
    ----
    data : tuple (input, mask, weights, config)
        input   – Tensor[ B, N, N, dim ] (float32, CUDA)
        mask    – Tensor[ B, N, N ]    (bool or float, may be None)
        weights – dict containing all linear / norm parameters
        config  – dict with keys "dim" and "hidden_dim"

    Returns
    -------
    Tensor[ B, N, N, dim ] (float32, CUDA)
    """
    # --------------------------------------------------------------
    # unpack inputs
    # --------------------------------------------------------------
    input_tensor, mask, weights, config = data
    dim = config["dim"]
    hidden = config["hidden_dim"]
    B, N, _, _ = input_tensor.shape   # input is [B, N, N, dim]

    # --------------------------------------------------------------
    # 1. First LayerNorm (over dim)
    # --------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        normalized_shape=(dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
        eps=1e-5,
    )

    # --------------------------------------------------------------
    # 2. Linear projections (no bias)
    # --------------------------------------------------------------
    left = F.linear(x, weights["left_proj.weight"])
    right = F.linear(x, weights["right_proj.weight"])

    # --------------------------------------------------------------
    # 3. Optional mask (broadcast on hidden dim)
    # --------------------------------------------------------------
    if mask is not None:
        mask_ = mask.unsqueeze(-1)               # [B, N, N, 1]
        left = left * mask_
        right = right * mask_

    # --------------------------------------------------------------
    # 4. Gating (sigmoid) and apply gates
    # --------------------------------------------------------------
    left_gate = torch.sigmoid(F.linear(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"]))
    out_gate = torch.sigmoid(F.linear(x, weights["out_gate.weight"]))

    left = left * left_gate
    right = right * right_gate

    # --------------------------------------------------------------
    # 5. Batched GEMM  (left @ rightᵀ)   – Triton part
    # --------------------------------------------------------------
    #    reshape from [B, N, N, hidden] -> [B*hidden, N, N]
    left_t = left.permute(0, 3, 1, 2).contiguous()   # [B, hidden, N, N]
    right_t = right.permute(0, 3, 1, 2).contiguous()
    left_flat = left_t.view(B * hidden, N, N)
    right_flat = right_t.view(B * hidden, N, N)

    out_flat = torch.empty_like(left_flat)   # allocate output

    # -------------------- launch configuration --------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 64

    grid = (
        B * hidden,                     # batch*head dimension
        triton.cdiv(N, BLOCK_M),        # rows
        triton.cdiv(N, BLOCK_N),        # cols
    )

    # strides (as integer values)
    a_batch, a_row, a_col = left_flat.stride()
    b_batch, b_row, b_col = right_flat.stride()
    c_batch, c_row, c_col = out_flat.stride()

    _batched_gemm_kernel[grid](
        left_flat,
        right_flat,
        out_flat,
        N,                # M
        N,                # N
        N,                # K
        a_batch, a_row, a_col,
        b_batch, b_row, b_col,
        c_batch, c_row, c_col,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # reshape back to [B, N, N, hidden]
    out = out_flat.view(B, hidden, N, N).permute(0, 2, 3, 1).contiguous()

    # --------------------------------------------------------------
    # 6. Output LayerNorm + gating
    # --------------------------------------------------------------
    out = F.layer_norm(
        out,
        normalized_shape=(hidden,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
        eps=1e-5,
    )
    out = out * out_gate

    # --------------------------------------------------------------
    # 7. Final linear projection back to original dimension
    # --------------------------------------------------------------
    out = F.linear(out, weights["to_out.weight"])

    return out
```

* Permutation to `(B, H, N, N)` is performed before the kernel and reverted afterwards.  
* All operations required by the TriMul forward pass are present; gradients are not needed.
