The TriMul “outgoing’’ operator consists of three phases  

1. **Pre‑processing** – layer‑norm, two linear projections, optional masking and
   three sigmoid gates.  
2. **Core contraction** – for each batch `b` and hidden head `h`

   \[
   \text{out}[b,i,j,h]=\sum_{k=0}^{N-1}
        \text{left}[b,i,k,h]\;\times\;
        \text{right}[b,j,k,h]
   \]

   This is exactly a batched matrix‑multiply `A @ Bᵀ` where each
   `(b,h)` slice has shape `N×N`.  The contraction dominates the runtime
   (`O(B·H·N³)`) and is the only part we accelerate with Triton.
3. **Post‑processing** – a second layer‑norm, element‑wise out‑gate and a final
   linear projection back to the original channel dimension `dim`.

Only the contraction needs a custom kernel; everything else can be expressed
with regular PyTorch kernels (they already run efficiently on the GPU and keep
the code simple).

--------------------------------------------------------------------
### Triton kernel

* **Data layout** – before launching the kernel we reshape the tensors to
  `(B·H, N, N)` and store them in **contiguous** memory with layout
  `(batch, row, col)`.  This lets the kernel use a single program id for the
  batch dimension (`pid_b = tl.program_id(2)`).

* **Mixed‑precision** – inputs are cast to `float16` (half‑precision) to
  minimise memory traffic, while the accumulator uses `float32` to keep
  numerical stability.

* **Tiling** – the kernel tiles the output matrix with
  `BLOCK_M × BLOCK_N` tiles (default `128×128`) and iterates over the `K`
  dimension in chunks of `BLOCK_K` (`64`).  These values are chosen for the
  Hopper SM90 architecture (large shared memory, 256‑bit load/store).  The
  tile size can be overridden from the host if needed.

* **Compute** – each iteration loads a `BLOCK_M×BLOCK_K` tile from `A` and a
  `BLOCK_K×BLOCK_N` tile from the **transposed** view of `B`.  The transpose is
  realised by swapping the stride arguments (`stride_Bk` and `stride_Bn`) – no
  data movement is required.  The multiplication is performed with `tl.dot`,
  which internally uses Tensor‑Core instructions on Hopper.

* **Boundary handling** – masks protect against out‑of‑bounds accesses on the
  last partial tiles.

### How the lessons are applied

| Lesson | Action taken |
|--------|--------------|
| *Permute to (B, H, N, N) before kernel* | `left` and `right` are permuted to `(B,H,N,N)` and flattened to `(B·H,N,N)`. |
| *Reformulate as batched GEMM* | The kernel implements exactly `A @ Bᵀ` for each `(b,h)` pair. |

| *Use fp16 loads / fp32 accum* | Implemented directly (`tl.load(...).to(tl.float32)`). |
| *Tune tile sizes for Hopper* | Default `BLOCK_M = BLOCK_N = 128`, `BLOCK_K = 64`.  These give high occupancy on SM90. |

"""
custom_kernel: Triton‑accelerated forward pass of the TriMul “outgoing’’
operator (AlphaFold3).  The heavy N³ contraction is performed by a batched
matrix‑multiply kernel (A @ Bᵀ) where each slice has shape N×N and the hidden
dimension H (= hidden_dim) acts as independent heads.  All other operations
(layer‑norm, linear projections, gating) are carried out with regular PyTorch
ops.  Mixed‑precision (fp16 loads, fp32 accumulation) and a 128×128×64
tiling strategy are used for the Hopper (SM90) architecture.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict

# ----------------------------------------------------------------------
# Triton kernel: batched GEMM C = A @ Bᵀ
#   A : (B·H, M, K)   fp16
#   B : (B·H, N, K)   fp16      (we read it as K×N by swapping strides)
#   C : (B·H, M, N)   fp32
# ----------------------------------------------------------------------
@triton.jit
def _batched_gemm_T_kernel(
    A_ptr,                     # *fp16   (batch, M, K)
    B_ptr,                     # *fp16   (batch, N, K)   (read as K×N)
    C_ptr,                     # *fp32   (batch, M, N)
    M, N, K,                   # matrix dimensions
    stride_Ab, stride_Am, stride_Ak,   # strides of A
    stride_Bb, stride_Bk, stride_Bn,   # strides of B (Bk = stride on K, Bn = stride on N)
    stride_Cb, stride_Cm, stride_Cn,   # strides of C
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    pid_b = tl.program_id(2)      # batch*head index
    pid_m = tl.program_id(0)      # block row
    pid_n = tl.program_id(1)      # block col

    # ------------------------------------------------------------------
    # 1. compute offsets for the current tile
    # ------------------------------------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)
    offs_k = tl.arange(0, BLOCK_K)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # Pointers for the start of the tile
    a_ptrs = (A_ptr
              + pid_b * stride_Ab
              + offs_m[:, None] * stride_Am
              + offs_k[None, :] * stride_Ak)

    b_ptrs = (B_ptr
              + pid_b * stride_Bb
              + offs_k[:, None] * stride_Bk       # K dimension
              + offs_n[None, :] * stride_Bn)      # N dimension (transposed view)

    # ------------------------------------------------------------------
    # 2. accumulate over K
    # ------------------------------------------------------------------
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    num_k_iter = tl.cdiv(K, BLOCK_K)
    for _ in range(num_k_iter):
        # load tiles, apply masks, cast to fp32
        a = tl.load(a_ptrs,
                    mask=mask_m[:, None] & (offs_k < K),
                    other=0.0).to(tl.float32)
        b = tl.load(b_ptrs,
                    mask=(offs_k[:, None] < K) & mask_n[None, :],
                    other=0.0).to(tl.float32)

        acc += tl.dot(a, b)        # (M×K)·(K×N) → (M×N)

        # advance K‑dimension pointers
        a_ptrs += BLOCK_K * stride_Ak
        b_ptrs += BLOCK_K * stride_Bk

    # ------------------------------------------------------------------
    # 3. write result
    # ------------------------------------------------------------------
    c_ptrs = (C_ptr
              + pid_b * stride_Cb
              + offs_m[:, None] * stride_Cm
              + offs_n[None, :] * stride_Cn)

    tl.store(c_ptrs, acc,
             mask=mask_m[:, None] & mask_n[None, :])


# ----------------------------------------------------------------------
def custom_kernel(data: Tuple[torch.Tensor,
                              torch.Tensor,
                              Dict[str, torch.Tensor],
                              Dict]) -> torch.Tensor:
    """
    Forward pass of the TriMul “outgoing’’ operator.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask, weights, config)
        - input_tensor : torch.Tensor, shape [B, N, N, dim] (float32)
        - mask         : torch.Tensor, shape [B, N, N] (bool/float) – may be None
        - weights      : dict of all param tensors (float32)
        - config       : dict with keys ``dim``, ``hidden_dim``, ``nomask``

    Returns
    -------
    torch.Tensor
        Output tensor of shape [B, N, N, dim] (float32)
    """
    # ------------------------------------------------------------------
    # Unpack inputs
    # ------------------------------------------------------------------
    x, mask, weights, config = data
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    nomask = config.get("nomask", True)

    # ------------------------------------------------------------------
    # Weight shortcuts
    # ------------------------------------------------------------------
    norm_w, norm_b = weights["norm.weight"], weights["norm.bias"]
    left_proj_w = weights["left_proj.weight"]
    right_proj_w = weights["right_proj.weight"]
    left_gate_w = weights["left_gate.weight"]
    right_gate_w = weights["right_gate.weight"]
    out_gate_w = weights["out_gate.weight"]
    to_out_norm_w, to_out_norm_b = weights["to_out_norm.weight"], weights["to_out_norm.bias"]
    to_out_w = weights["to_out.weight"]

    # ------------------------------------------------------------------
    # 1️⃣ Layer‑norm on the input (last dim = dim)
    # ------------------------------------------------------------------
    x = F.layer_norm(x, (dim,), weight=norm_w, bias=norm_b)

    # ------------------------------------------------------------------
    # 2️⃣ Linear projections (bias‑free)
    # ------------------------------------------------------------------
    # shape after projection → [B, N, N, hidden_dim]
    left = F.linear(x, left_proj_w)      # (B,N,N,H)
    right = F.linear(x, right_proj_w)

    # ------------------------------------------------------------------
    # 3️⃣ Optional mask (broadcast over hidden dim)
    # ------------------------------------------------------------------
    if not nomask:
        # mask shape (B,N,N) -> (B,N,N,1)
        mask_ = mask.unsqueeze(-1).to(x.dtype)
        left = left * mask_
        right = right * mask_

    # ------------------------------------------------------------------
    # 4️⃣ Gating (sigmoid)
    # ------------------------------------------------------------------
    left_gate = torch.sigmoid(F.linear(x, left_gate_w))
    right_gate = torch.sigmoid(F.linear(x, right_gate_w))
    out_gate = torch.sigmoid(F.linear(x, out_gate_w))

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5️⃣ Core contraction – batched GEMM (A @ Bᵀ)
    # ------------------------------------------------------------------
    B, N, _, H = left.shape            # H == hidden_dim

    # (B, N, N, H) -> (B, H, N, N) -> (B*H, N, N)   keep contiguous layout
    left_t = left.permute(0, 3, 1, 2).contiguous()
    right_t = right.permute(0, 3, 1, 2).contiguous()

    left_flat = left_t.view(B * H, N, N)      # fp32
    right_flat = right_t.view(B * H, N, N)    # fp32

    # Cast to fp16 for the kernel (memory‑bandwidth friendly)
    left_fp16 = left_flat.to(torch.float16)
    right_fp16 = right_flat.to(torch.float16)

    # Output buffer (fp32 accumulator)
    out_buf = torch.empty_like(left_fp16, dtype=torch.float32)

    # ------------------------------------------------------------------
    # Stride extraction (in elements, not bytes)
    # ------------------------------------------------------------------
    stride_Ab, stride_Am, stride_Ak = left_fp16.stride()   # (batch, row, col)
    stride_Bb, stride_Br, stride_Bc = right_fp16.stride()
    # For Bᵀ we need:
    stride_Bk = stride_Bc          # step along K (original column)
    stride_Bn = stride_Br          # step along N (original row)

    stride_Cb, stride_Cm, stride_Cn = out_buf.stride()

    # ------------------------------------------------------------------
    # Tile configuration – can be tweaked for other GPUs
    # ------------------------------------------------------------------
    BLOCK_M = 128
    BLOCK_N = 128
    BLOCK_K = 64

    grid = (
        triton.cdiv(N, BLOCK_M),   # rows
        triton.cdiv(N, BLOCK_N),   # cols
        B * H                      # batch * head dimension
    )

    _batched_gemm_T_kernel[grid](
        left_fp16,
        right_fp16,
        out_buf,
        N, N, N,
        stride_Ab, stride_Am, stride_Ak,
        stride_Bb, stride_Bk, stride_Bn,
        stride_Cb, stride_Cm, stride_Cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # ------------------------------------------------------------------
    # Reshape back to original layout [B, N, N, H]
    # ------------------------------------------------------------------
    out = out_buf.view(B, H, N, N).permute(0, 2, 3, 1).contiguous()

    # ------------------------------------------------------------------
    # 6️⃣ Post‑processing
    # ------------------------------------------------------------------
    out = F.layer_norm(out, (hidden_dim,), weight=to_out_norm_w, bias=to_out_norm_b)
    out = out * out_gate
    out = F.linear(out, to_out_w)          # back to dim

    return out
