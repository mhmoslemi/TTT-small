assistantfinal**Solution Overview**

We implement the *outgoing* TriMul operator exactly as described in the AlphaFold‑3 paper, but we move the **core tensor contraction**  

\[
\text{out}_{b,i,j,h}= \sum_{k=1}^{N}\; \text{left}_{b,i,k,h}\,
                       \text{right}_{b,j,k,h}
\]

into a hand‑written Triton kernel.  The surrounding operations (layer‑norms,
linear projections, gating, the final layer‑norm and linear projection) are
performed with regular PyTorch ‑ they are cheap compared with the \(N^{3}\)
contraction and keep the implementation simple and robust.

The kernel works on a *batch‑head* view of the data:

* shape before the kernel: **[B, N, N, H]** (`H = hidden_dim`)
* permute → **[B, H, N, N]**, then flatten the first two dimensions →  
  **[B·H, N, N]**  

For each “matrix” in this batch we compute a GEMM with the **right** operand
transposed, i.e. `A @ Bᵀ`.  The kernel loads tiles of `A` and `B` in **fp16**,
accumulates in **fp32**, and writes the result back in **fp32**.

The implementation follows the proven pattern from the “lessons” section:

* **Lesson 1** – permute to `(B, H, N, N)` and make the tensors contiguous.  
* **Lesson 2** – treat the contraction as a batched GEMM (`A @ Bᵀ`).  
* **Lesson 3** – compute and pass the *exact* strides of the three tensors;
  the kernel never assumes a contiguous layout.

The block sizes (`BLOCK_M = 128`, `BLOCK_N = 128`, `BLOCK_K = 32`) were chosen
empirically for Hopper SM90 and work well for all benchmark shapes
(‑‑ up to `N = 1024`).  They keep each program‑instance’s shared‑memory usage
well below the hardware limit while providing high arithmetic intensity.

The full pipeline is:

1. **Layer‑norm** on the input (`dim = C`).
2. **Linear projections** → `left`, `right` (shape `[B,N,N,H]`).
3. **Optional mask** (broadcast on the hidden dimension).
4. **Gating** (`sigmoid` on three separate linear layers) and element‑wise
   multiplication.
5. **Triton‑accelerated contraction** (`left @ rightᵀ` per head).
6. **Layer‑norm**, **out‑gate** and final linear projection back to `dim`.

The function `custom_kernel` expects a tuple  
`(input_tensor, mask, weights, config)` exactly as described in the prompt
and returns the final tensor of shape `[B, N, N, C]` (float‑32).

```python
"""
custom_kernel – Triton‑accelerated forward pass of the TriMul “outgoing”
operator (AlphaFold‑3).

The heavy part (pairwise contraction) is implemented as a batched GEMM
(left @ right.T) using a tiled Triton kernel.  All surrounding linear /
normalisation / gating steps are performed in PyTorch for simplicity.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict

# ----------------------------------------------------------------------
# Triton kernel: C = A @ Bᵀ   (A,B : [batch, N, N])
# ----------------------------------------------------------------------
@triton.jit
def _tri_mul_gemm_T_kernel(
    A_ptr,                     # *float16  (batch, M, K)   – left
    B_ptr,                     # *float16  (batch, N, K)   – right, will be read as K×N
    C_ptr,                     # *float32  (batch, M, N)   – output
    M, N, K,                   # matrix dimensions (all int)
    stride_Ab, stride_Am, stride_Ak,   # strides of A
    stride_Bb, stride_Bk, stride_Bn,   # strides of B (B_k = stride along K, B_n = stride along N)
    stride_Cb, stride_Cm, stride_Cn,   # strides of C
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Compute C = A @ Bᵀ for a batch of matrices.
    Each program instance works on a tile (BLOCK_M × BLOCK_N) of the output.
    """
    pid_b = tl.program_id(2)            # batch index  (0 … batch‑1)
    pid_m = tl.program_id(0)            # tile row
    pid_n = tl.program_id(1)            # tile column

    # ----------- tile offsets -----------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)
    offs_k = tl.arange(0, BLOCK_K)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # ----------- pointers ---------------------------------------------
    a_ptrs = A_ptr + pid_b * stride_Ab + offs_m[:, None] * stride_Am + offs_k[None, :] * stride_Ak
    b_ptrs = B_ptr + pid_b * stride_Bb + offs_k[:, None] * stride_Bk + offs_n[None, :] * stride_Bn

    # ----------- accumulator (fp32) -----------------------------------
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ----------- main K‑loop -----------------------------------------
    num_k_tiles = tl.cdiv(K, BLOCK_K)
    for k_tile in range(num_k_tiles):
        # Load A tile
        a = tl.load(a_ptrs,
                    mask=mask_m[:, None] & (offs_k < K),
                    other=0.0).to(tl.float32)

        # Load B tile (transposed view)
        b = tl.load(b_ptrs,
                    mask=(offs_k[:, None] < K) & mask_n[None, :],
                    other=0.0).to(tl.float32)

        acc += tl.dot(a, b)        # (M×K)·(K×N) → (M×N)

        # Advance K‑pointers
        a_ptrs += BLOCK_K * stride_Ak
        b_ptrs += BLOCK_K * stride_Bk

    # ----------- write back -------------------------------------------
    c_ptrs = C_ptr + pid_b * stride_Cb + offs_m[:, None] * stride_Cm + offs_n[None, :] * stride_Cn
    tl.store(c_ptrs,
             acc,
             mask=mask_m[:, None] & mask_n[None, :])

# ----------------------------------------------------------------------
def custom_kernel(data: Tuple[torch.Tensor,
                              torch.Tensor,
                              Dict[str, torch.Tensor],
                              Dict]) -> torch.Tensor:
    """
    Triton‑accelerated forward pass of the TriMul “outgoing” operator.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask, weights, config)
        - input_tensor : torch.Tensor, shape [B, N, N, C] (float32)
        - mask         : torch.Tensor, shape [B, N, N] (bool / float)
        - weights      : dict of model parameters (float32)
        - config       : dict containing
                         {"dim": C, "hidden_dim": H, "nomask": bool}

    Returns
    -------
    torch.Tensor
        Output of shape [B, N, N, C] (float32)
    """
    # ------------------------------------------------------------------
    # unpack inputs
    # ------------------------------------------------------------------
    x, mask, weights, config = data
    C = config["dim"]
    H = config["hidden_dim"]
    nomask = config.get("nomask", True)

    # ------------------------------------------------------------------
    # weight shortcuts
    # ------------------------------------------------------------------
    w_norm,   b_norm   = weights["norm.weight"],   weights["norm.bias"]
    w_left,   w_right  = weights["left_proj.weight"], weights["right_proj.weight"]
    w_left_g, w_right_g = weights["left_gate.weight"], weights["right_gate.weight"]
    w_out_g   = weights["out_gate.weight"]
    w_out_ln, b_out_ln = weights["to_out_norm.weight"], weights["to_out_norm.bias"]
    w_out    = weights["to_out.weight"]

    # ------------------------------------------------------------------
    # 1️⃣ Layer‑norm on the input (last dim = C)
    # ------------------------------------------------------------------
    x = F.layer_norm(x, (C,), weight=w_norm, bias=b_norm)

    # ------------------------------------------------------------------
    # 2️⃣ Linear projections (no bias) → shape [B,N,N,H]
    # ------------------------------------------------------------------
    left  = F.linear(x, w_left)      # (B,N,N,H)
    right = F.linear(x, w_right)     # (B,N,N,H)

    # ------------------------------------------------------------------
    # 3️⃣ Optional mask (broadcast on hidden dim)
    # ------------------------------------------------------------------
    if not nomask:
        # mask: [B,N,N] → [B,N,N,1] and cast to same dtype as left/right
        mask_ = mask.unsqueeze(-1).to(x.dtype)
        left  = left * mask_
        right = right * mask_

    # ------------------------------------------------------------------
    # 4️⃣ Gating (sigmoid) → element‑wise multiplication
    # ------------------------------------------------------------------
    left_gate  = torch.sigmoid(F.linear(x, w_left_g))   # (B,N,N,H)
    right_gate = torch.sigmoid(F.linear(x, w_right_g))
    out_gate   = torch.sigmoid(F.linear(x, w_out_g))

    left  = left  * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5️⃣ Core contraction (batched GEMM) using Triton
    # ------------------------------------------------------------------
    B, N, _, _ = left.shape   # B, N, N, H
    # reshape to (B, H, N, N) → contiguous → flatten first two dims
    left_view  = left.permute(0, 3, 1, 2).contiguous().view(B * H, N, N)
    right_view = right.permute(0, 3, 1, 2).contiguous().view(B * H, N, N)

    # fp16 inside the kernel, fp32 accumulator / output
    left_fp16  = left_view.to(torch.float16)
    right_fp16 = right_view.to(torch.float16)

    # output buffer (fp32)
    out_fp32 = torch.empty_like(left_view, dtype=torch.float32)

    # stride information (in elements, not bytes)
    stride_Ab, stride_Am, stride_Ak = left_fp16.stride()   # (batch, M, K)
    stride_Bb, stride_Br, stride_Bc = right_fp16.stride()  # (batch, N, K)

    # For the transposed view we need:
    #   B_k : step along K (original column dimension) = stride_Bc
    #   B_n : step along N (original row    dimension) = stride_Br
    stride_Bk = stride_Bc
    stride_Bn = stride_Br

    stride_Cb, stride_Cm, stride_Cn = out_fp32.stride()

    # ------------------------------------------------------------------
    # Launch parameters (tuned for Hopper)
    # ------------------------------------------------------------------
    BLOCK_M = 128
    BLOCK_N = 128
    BLOCK_K = 32

    grid = (
        triton.cdiv(N, BLOCK_M),   # rows of output
        triton.cdiv(N, BLOCK_N),   # cols of output
        B * H                      # batch*head dimension
    )

    _tri_mul_gemm_T_kernel[grid](
        left_fp16,
        right_fp16,
        out_fp32,
        N, N, N,
        stride_Ab, stride_Am, stride_Ak,
        stride_Bb, stride_Bk, stride_Bn,
        stride_Cb, stride_Cm, stride_Cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # reshape back to [B, N, N, H]
    out = out_fp32.view(B, H, N, N).permute(0, 2, 3, 1).contiguous()

    # ------------------------------------------------------------------
    # 6️⃣ Post‑processing
    #     – layer‑norm over hidden dim,
    #     – multiplication by out‑gate,
    #     – final linear projection back to C
    # ------------------------------------------------------------------
    out = F.layer_norm(out, (H,), weight=w_out_ln, bias=b_out_ln)
    out = out * out_gate
    out = F.linear(out, w_out)          # (B,N,N,C)

    return out
```

* **Flexibility** – works for any `B ∈ {1,2}`, `N ∈ {128,256,512,1024}`,

  with or without a mask, and for both normal and Cauchy‑distributed data.
* **No gradients** – the kernel uses only forward‑only operations; the
