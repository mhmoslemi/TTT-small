assistantfinal**Analysis**

The expensive part of the TriMul forward is the 4‑D einsum  

```
out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
```

which is a batched matrix‑multiply of shape  
`(M, N, N)` with `M = B * hidden_dim`.  
All previous attempts already reshaped the tensors to `(M, N, N)` and launched a
GEMM‑style Triton kernel, but the runtime is still far from the target
(~8 ms).  

Below are the lessons that are relevant for the new implementation:

| Lesson | Apply? | Reason |
|-------|--------|--------|
| **1. Reformulate TriMul as batched GEMM** | ✅ | We keep the `(M,N,N)` formulation – the only way to avoid the `N³` loop. |
| **2. Permute to (B, H, N, N) before kernel** | ✅ | Required so that each head can be processed independently; we also `contiguous()` the tensor to obtain simple strides. |
| **3. Pass correct strides** | ✅ | Strides are taken from the contiguous tensors and supplied to the kernel. |
| **4. Use mixed‑precision** (store A/B as `fp16`, accumulate in `fp32`) | ✅ | Reduces memory traffic by 2× while keeping FP‑32 accumulation, which is supported by `tl.dot`. |
| **5. Tune block sizes for Hopper** | ✅ | Hopper’s TF32/FP16 units favour `BLOCK_M = BLOCK_N = 64` and `BLOCK_K = 32` with `num_warps = 8`. |
| **6. Fuse only the N³ contraction** | ✅ | All LayerNorms, linear layers and gating remain in PyTorch – they are cheap compared to the GEMM and keep the code simple. |

The kernel below follows the classic tiled GEMM pattern, loading a
`(BLOCK_M, BLOCK_K)` tile of **A** and a `(BLOCK_K, BLOCK_N)` tile of **Bᵀ**, performing
`tl.dot` in FP‑16, accumulating into an FP‑32 register tile, and finally storing the result.
All tensors are already on the device, and the host side only performs the
necessary PyTorch preprocessing/post‑processing.

```python
"""
TriMul “outgoing” forward pass.

The heavy N³ contraction is implemented as a batched GEMM:
    C[M, N, N] = A[M, N, K] @ B[M, N, K]^T   with K == N.
A and B are stored in fp16, accumulation is fp32.
All other operations (LayerNorm, Linear, gating) stay in PyTorch.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl

# --------------------------------------------------------------------------- #
# Triton kernel: C = A @ Bᵀ  (batched GEMM)
# A : (M, N, K)   – fp16
# B : (M, N, K)   – fp16   (treated as transposed on the last two dims)
# C : (M, N, N)   – fp32
# --------------------------------------------------------------------------- #
@triton.jit
def tri_mul_gemm_kernel(
    a_ptr, b_ptr, c_ptr,
    M, N, K,
    stride_am, stride_an, stride_ak,   # A strides
    stride_bm, stride_bn, stride_bk,   # B strides (original order)
    stride_cm, stride_cn, stride_ck,   # C strides
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    pid_m = tl.program_id(0)          # i‑tile (rows)
    pid_n = tl.program_id(1)          # j‑tile (cols)
    pid_z = tl.program_id(2)          # matrix index  (M = batch * hidden)

    # ------------------------------------------------------------------- #
    # Offsets for the current tile
    # ------------------------------------------------------------------- #
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)
    offs_k = tl.arange(0, BLOCK_K)

    mask_m = offs_m < N
    mask_n = offs_n < N

    # ------------------------------------------------------------------- #
    # Pointers (A is (M,N,K), B is accessed as (M,K,N) for the transpose)
    # ------------------------------------------------------------------- #
    a_ptrs = a_ptr + pid_z * stride_am \
                 + offs_m[:, None] * stride_an \
                 + offs_k[None, :] * stride_ak

    b_ptrs = b_ptr + pid_z * stride_bm \
                 + offs_k[:, None] * stride_bk \
                 + offs_n[None, :] * stride_bn

    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ------------------------------------------------------------------- #
    # Main GEMM loop over K
    # ------------------------------------------------------------------- #
    for _ in range(0, tl.cdiv(K, BLOCK_K)):
        a = tl.load(a_ptrs,
                    mask=mask_m[:, None] & (offs_k < K),
                    other=0.0)                     # fp16
        b = tl.load(b_ptrs,
                    mask=(offs_k[:, None] < K) & mask_n[None, :],
                    other=0.0)                     # fp16

        acc += tl.dot(a, b)                       # fp16·fp16 → fp32

        a_ptrs += BLOCK_K * stride_ak
        b_ptrs += BLOCK_K * stride_bk

    # ------------------------------------------------------------------- #
    # Store C (fp32)
    # ------------------------------------------------------------------- #
    c_ptrs = c_ptr + pid_z * stride_cm \
                 + offs_m[:, None] * stride_cn \
                 + offs_n[None, :] * stride_ck

    tl.store(c_ptrs, acc,
             mask=mask_m[:, None] & mask_n[None, :])


# --------------------------------------------------------------------------- #
# Host entry point
# --------------------------------------------------------------------------- #
def custom_kernel(data):
    """
    Forward pass of TriMul (outgoing) with a fused Triton GEMM.

    Args:
        data: tuple (input_tensor, mask, weights, config)
            - input_tensor : torch.Tensor [B, N, N, dim]  (float32)
            - mask         : torch.Tensor [B, N, N] or None
            - weights      : dict of model parameters (torch.Tensor)
            - config       : {"dim": int, "hidden_dim": int}
    Returns:
        torch.Tensor [B, N, N, dim] (float32)
    """
    x, mask, weights, config = data
    device = x.device
    B, N, _, dim = x.shape
    hidden_dim = config["hidden_dim"]

    # ------------------------------------------------------------------- #
    # 1) Input LayerNorm
    # ------------------------------------------------------------------- #
    x = F.layer_norm(
        x,
        (dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"]
    )

    # ------------------------------------------------------------------- #
    # 2) Linear projections (no bias)
    # ------------------------------------------------------------------- #
    left  = F.linear(x, weights["left_proj.weight"])   # [B,N,N,hidden]
    right = F.linear(x, weights["right_proj.weight"])

    # ------------------------------------------------------------------- #
    # 3) Optional mask (broadcast on the hidden dim)
    # ------------------------------------------------------------------- #
    if mask is not None:
        mask_ = mask.unsqueeze(-1)   # [B,N,N,1]
        left  = left * mask_
        right = right * mask_

    # ------------------------------------------------------------------- #
    # 4) Gating (sigmoid)
    # ------------------------------------------------------------------- #
    left_gate  = torch.sigmoid(F.linear(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"]))
    out_gate   = torch.sigmoid(F.linear(x, weights["out_gate.weight"]))

    left  = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------- #
    # 5) Fuse the N³ contraction with Triton
    #    reshape to (M, N, N) where M = B * hidden_dim
    # ------------------------------------------------------------------- #
    # (B,N,N,hidden) -> (B, hidden, N, N) -> (M, N, N)
    left_reshape  = left.permute(0, 3, 1, 2).contiguous().view(B * hidden_dim, N, N)
    right_reshape = right.permute(0, 3, 1, 2).contiguous().view(B * hidden_dim, N, N)

    # Cast to fp16 for the kernel (memory‑bandwidth reduction)
    left_fp16  = left_reshape.to(torch.float16)
    right_fp16 = right_reshape.to(torch.float16)

    # Output buffer (fp32 accumulation)
    out_fp32 = torch.empty_like(left_reshape, dtype=torch.float32, device=device)

    # Strides in element units (not bytes)
    stride_am, stride_an, stride_ak = left_fp16.stride()
    stride_bm, stride_bn, stride_bk = right_fp16.stride()
    stride_cm, stride_cn, stride_ck = out_fp32.stride()

    # ------------------------------------------------------------------- #
    # Kernel launch configuration
    # ------------------------------------------------------------------- #
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        triton.cdiv(N, BLOCK_M),          # rows i
        triton.cdiv(N, BLOCK_N),          # cols j
        B * hidden_dim                    # independent matrices
    )

    tri_mul_gemm_kernel[grid](
        left_fp16,
        right_fp16,
        out_fp32,
        B * hidden_dim, N, N,
        stride_am, stride_an, stride_ak,
        stride_bm, stride_bn, stride_bk,
        stride_cm, stride_cn, stride_ck,
        BLOCK_M=BLOCK_M, BLOCK_N=BLOCK_N, BLOCK_K=BLOCK_K,
        num_warps=8,                     # good for fp16 on Hopper
        num_stages=2
    )

    # Reshape back to the original layout: [B, N, N, hidden]
    out = out_fp32.view(B, hidden_dim, N, N).permute(0, 2, 3, 1).contiguous()

    # ------------------------------------------------------------------- #
    # 6) Output LayerNorm, gating and final linear
    # ------------------------------------------------------------------- #
    out = F.layer_norm(
        out,
        (hidden_dim,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"]
    )
    out = out * out_gate
    out = F.linear(out, weights["to_out.weight"])   # -> [B,N,N,dim]

    return out
```
