assistantfinal**Solution Overview**

The “outgoing’’ TriMul operator can be expressed as a **batched GEMM**:

\[
\text{out}_{b,i,j,h}= \sum_{k=0}^{N-1}
      \underbrace{\text{left}_{b,i,k,h}}_{\displaystyle A_{b,h}[i,k]}
      \;\underbrace{\text{right}_{b,j,k,h}}_{\displaystyle B_{b,h}[j,k]}
      \;=\;
      \bigl(A_{b,h}\;B_{b,h}^{\top}\bigr)_{i,j}
\]

For every batch `b` and hidden head `h` we need a matrix‑matrix multiplication
`N×N  @  N×Nᵀ`.  
All other operations (layer‑norm, linear projections, gating, final
projection) are cheap compared with the `N³` contraction and are kept in PyTorch
for simplicity.

The kernel works on **fp16** inputs (`left`, `right`) to reduce bandwidth,
accumulates in **fp32**, and writes the result as fp32.  
It processes the whole batch×head dimension (`B*hidden_dim`) in parallel by
using the third program‑id dimension (`tl.program_id(2)`).

The implementation follows the proven “lessons’’ from the previous search:

| Lesson | What we keep / adapt |
|--------|----------------------|
| **permute to (B,H,N,N)** | Done before the kernel – contiguous layout gives simple strides |
| **batched GEMM** | Exactly the kernel above, with `A @ Bᵀ` |
| **correct stride handling** | Strides are extracted from the tensors and passed explicitly |
| **tiling** | `BLOCK_M = BLOCK_N = 128`, `BLOCK_K = 32` – a good fit for Hopper SM90 |

The only part that remains in native PyTorch is the surrounding
normalisation / gating logic, which is negligible for the target shapes.

```python
"""
custom_kernel
==============

Forward pass of the “outgoing’’ TriMul operator (AlphaFold‑3) with a
Triton‑accelerated batched GEMM.

Algorithm
---------
1️⃣ Layer‑norm the input (last dim = dim).  
2️⃣ Linear projections → left / right (shape B×N×N×H).  
3️⃣ (Optional) mask the projected tensors.  
4️⃣ Compute three sigmoid gates and apply them element‑wise.  
5️⃣ Core contraction:
       out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]
   realised as a batched GEMM `A @ Bᵀ` for every (batch, head) pair,
   executed in a single Triton kernel (fp16 → fp32 accumulation).  
6️⃣ Post‑processing: layer‑norm, out‑gate, final linear projection back to
   the original channel dimension.

The kernel processes `B*H` independent GEMMs in parallel, using
tiled loads, fp16 arithmetic and fp32 accumulation.  The final tensor is
returned as float‑32.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl
from typing import Tuple, Dict


# ----------------------------------------------------------------------
# Triton kernel: C = A @ Bᵀ   (A,B : [batch*H, N, N])
# ----------------------------------------------------------------------
@triton.jit
def _trigemm_outgoing_kernel(
    A_ptr,                      # *float16   (batch*H, M, K)
    B_ptr,                      # *float16   (batch*H, N, K)   (read as K×N)
    C_ptr,                      # *float32   (batch*H, M, N)
    M, N, K,                    # matrix dimensions (all int32)
    stride_Ab, stride_Am, stride_Ak,      # strides of A
    stride_Bb, stride_Bk, stride_Bn,      # strides of B (B_k is col‑stride, B_n is row‑stride)
    stride_Cb, stride_Cm, stride_Cn,      # strides of C
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Batched GEMM kernel: for each batch*head (pid_b) compute a tile of
    C = A @ Bᵀ .  A and B are stored as (M,K) and (N,K) respectively.
    """
    pid_b = tl.program_id(2)            # batch*head index
    pid_m = tl.program_id(0)            # tile‑row index
    pid_n = tl.program_id(1)            # tile‑col index

    # ------------------------------------------------------------------
    # Tile offsets
    # ------------------------------------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)
    offs_k = tl.arange(0, BLOCK_K)

    mask_m = offs_m < M
    mask_n = offs_n < N

    # Pointers for the current tile
    a_ptrs = A_ptr + pid_b * stride_Ab \
                     + offs_m[:, None] * stride_Am \
                     + offs_k[None, :] * stride_Ak
    b_ptrs = B_ptr + pid_b * stride_Bb \
                     + offs_k[:, None] * stride_Bk \
                     + offs_n[None, :] * stride_Bn

    # ------------------------------------------------------------------
    # Accumulator (fp32)
    # ------------------------------------------------------------------
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ------------------------------------------------------------------
    # Main k‑loop
    # ------------------------------------------------------------------
    num_k = tl.cdiv(K, BLOCK_K)
    for k in range(num_k):
        # Load A and B tiles (mask out‑of‑bounds)
        a = tl.load(a_ptrs,
                    mask=mask_m[:, None] & (offs_k < K),
                    other=0.0).to(tl.float32)        # (BM, BK)
        b = tl.load(b_ptrs,
                    mask=(offs_k[:, None] < K) & mask_n[None, :],
                    other=0.0).to(tl.float32)        # (BK, BN)

        acc += tl.dot(a, b)                               # (BM, BN)

        # Advance K‑dimension pointers
        a_ptrs += BLOCK_K * stride_Ak
        b_ptrs += BLOCK_K * stride_Bk

    # ------------------------------------------------------------------
    # Write out the result
    # ------------------------------------------------------------------
    c_ptrs = C_ptr + pid_b * stride_Cb \
                     + offs_m[:, None] * stride_Cm \
                     + offs_n[None, :] * stride_Cn
    tl.store(c_ptrs,
             acc,
             mask=mask_m[:, None] & mask_n[None, :])


# ----------------------------------------------------------------------
def custom_kernel(data: Tuple[torch.Tensor,
                              torch.Tensor,
                              Dict[str, torch.Tensor],
                              Dict]) -> torch.Tensor:
    """
    Triton‑accelerated forward pass of the TriMul “outgoing’’ operator.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask, weights, config)
        - input_tensor : torch.Tensor, shape [B, N, N, C] (float32)
        - mask         : torch.Tensor, shape [B, N, N]   (bool/float)
        - weights      : dict of model parameters (float32)
        - config       : dict with keys ``dim``, ``hidden_dim`` and optional
                         ``nomask`` (bool).

    Returns
    -------
    torch.Tensor
        Tensor of shape [B, N, N, C] (float32).
    """
    # ------------------------------------------------------------------
    # 0️⃣ unpack & conveniences
    # ------------------------------------------------------------------
    input_tensor, mask, weights, config = data
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    nomask = config.get("nomask", True)

    # ------------------------------------------------------------------
    # 1️⃣ Layer‑norm the input (last dimension = dim)
    # ------------------------------------------------------------------
    norm_w, norm_b = weights["norm.weight"], weights["norm.bias"]
    x = F.layer_norm(input_tensor, (dim,), weight=norm_w, bias=norm_b)

    # ------------------------------------------------------------------
    # 2️⃣ Linear projections (bias‑free)
    # ------------------------------------------------------------------
    left_proj_w  = weights["left_proj.weight"]   # (hidden_dim, dim)
    right_proj_w = weights["right_proj.weight"]
    left  = F.linear(x, left_proj_w)    # [B,N,N,hidden_dim]
    right = F.linear(x, right_proj_w)   # [B,N,N,hidden_dim]

    # ------------------------------------------------------------------
    # 3️⃣ Optional mask (broadcast on hidden dim)
    # ------------------------------------------------------------------
    if not nomask:
        mask_ = mask.unsqueeze(-1).to(x.dtype)          # (B,N,N,1)
        left  = left * mask_
        right = right * mask_

    # ------------------------------------------------------------------
    # 4️⃣ Gating – sigmoid on linear transforms of the *original* x
    # ------------------------------------------------------------------
    left_gate_w  = weights["left_gate.weight"]
    right_gate_w = weights["right_gate.weight"]
    out_gate_w   = weights["out_gate.weight"]
    left_gate  = torch.sigmoid(F.linear(x, left_gate_w))
    right_gate = torch.sigmoid(F.linear(x, right_gate_w))
    out_gate   = torch.sigmoid(F.linear(x, out_gate_w))

    left  = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5️⃣ Core contraction: batched GEMM with Triton
    # ------------------------------------------------------------------
    B, N, _, H = left.shape                # H == hidden_dim

    # Rearrange to (B, H, N, N) → contiguous → view as (B*H, N, N)
    left_  = left.permute(0, 3, 1, 2).contiguous().view(B * H, N, N)
    right_ = right.permute(0, 3, 1, 2).contiguous().view(B * H, N, N)

    # fp16 inside the kernel (bandwidth), fp32 accumulator
    left_fp16  = left_.to(torch.float16)
    right_fp16 = right_.to(torch.float16)

    # Output buffer (fp32)
    out_buf = torch.empty_like(left_, dtype=torch.float32)

    # ------------------------------------------------------------------
    # Strides (in element counts, not bytes)
    # ------------------------------------------------------------------
    stride_Ab, stride_Am, stride_Ak = left_fp16.stride()   # (batch*H, M, K)
    stride_Bb, stride_Br, stride_Bc = right_fp16.stride() # (batch*H, N, K)

    # When we read B as transposed we need
    #   stride_Bk = stride along K   (original column stride)
    #   stride_Bn = stride along N   (original row stride)
    stride_Bk = stride_Bc
    stride_Bn = stride_Br

    stride_Cb, stride_Cm, stride_Cn = out_buf.stride()

    # ------------------------------------------------------------------
    # Tiling – values tuned for Hopper (SM90)
    # ------------------------------------------------------------------
    BLOCK_M = 128
    BLOCK_N = 128
    BLOCK_K = 32

    grid = (
        triton.cdiv(N, BLOCK_M),          # rows
        triton.cdiv(N, BLOCK_N),          # cols
        B * H                             # batch * head
    )

    _trigemm_outgoing_kernel[grid](
        left_fp16,
        right_fp16,
        out_buf,
        N, N, N,                         # M, N, K
        stride_Ab, stride_Am, stride_Ak,
        stride_Bb, stride_Bk, stride_Bn,
        stride_Cb, stride_Cm, stride_Cn,
        BLOCK_M=BLOCK_M, BLOCK_N=BLOCK_N, BLOCK_K=BLOCK_K,
    )

    # Reshape back to [B, N, N, hidden_dim]
    out = out_buf.view(B, H, N, N).permute(0, 2, 3, 1).contiguous()

    # ------------------------------------------------------------------
    # 6️⃣ Post‑processing
    # ------------------------------------------------------------------
    to_out_norm_w, to_out_norm_b = weights["to_out_norm.weight"], weights["to_out_norm.bias"]
    to_out_w = weights["to_out.weight"]

    out = F.layer_norm(out, (hidden_dim,), weight=to_out_norm_w, bias=to_out_norm_b)
    out = out * out_gate
    out = F.linear(out, to_out_w)          # back to original dim (C)

    return out
```

**Key Points**

* The heavy `N³` tensor contraction is the only part executed in Triton.
* By converting `left`/`right` to **fp16** inside the kernel we cut memory traffic
  roughly in half while still accruing the numerical precision of **fp32**
  accumulation.
* The kernel works for any `B ∈ {1,2}`, `N ≤ 1024`, `hidden_dim = 128`
  (the benchmark’s only hidden dimension) and respects the optional mask.
* All stride calculations are performed on the host (`torch.Tensor.stride()`);
  the kernel receives them as integer arguments, guaranteeing correct memory
  addressing.
* The rest of the pipeline (layer‑norm, linear layers, sigmoid gates) remains
  in PyTorch – they are lightweight compared with the GEMM and keep the
  implementation easy to audit.
