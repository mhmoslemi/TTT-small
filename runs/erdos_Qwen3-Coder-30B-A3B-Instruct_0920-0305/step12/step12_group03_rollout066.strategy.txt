### 1.  Reformulate the objective as a discrete min‑max problem

```

```

Define the autocorrelation for shift `k` (0 ≤ k ≤ n‑1)  

```
S_k = Σ_{i=0}^{n‑k‑1} h_i · h_{i+k}
```

Because  

```
Σ_i h_i·(1‑h_{i+k}) = (Σ_i h_i) – S_k = n/2 – S_k
```

the quantity we must minimise is  

```
C5 = (2/n) · max_k ( n/2 – S_k ) = 1 – (2·min_k S_k)/n .
```

Thus **maximising** `m = min_k S_k` is equivalent to **minimising** `C5`.  The problem is now a pure combinatorial optimisation: find a binary vector with exactly `n/2` ones that makes every autocorrelation `S_k` as large as possible.
