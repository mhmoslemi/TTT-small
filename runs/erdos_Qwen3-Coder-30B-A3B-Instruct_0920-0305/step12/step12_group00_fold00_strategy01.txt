### 1.  Core mathematical reformulation  

For a discretisation with `n` points (`dx = 2/n`) and a binary step‑function  
`h_i ∈ {0,1}` (`i = 0,…,n‑1`) the overlap integral evaluated by the supplied
routine is  

\[
C_5(h)=dx\;\max_{\,\ell\in\{-n+1,\dots ,n-1\}} 
\Bigl[\;\sum_{i}h_i\;(1-h_{i+\ell})\Bigr] .
\]

Because the total mass is fixed,
\(\displaystyle N:=\sum_i h_i = n/2\), we have  

\[
\sum_i h_i\;(1-h_{i+\ell}) = N-\underbrace{\sum_i h_i h_{i+\ell}}_{S_\ell}.
\]

Hence  

\[
C_5(h)=dx\;\bigl(N-\min_{\ell\neq0} S_\ell\bigr) .
\]

*Goal*: maximise the **minimum** a‑periodic autocorrelation  

\[
\min_{\ell\neq0} S_\ell ,\qquad 
S_\ell =\sum_{i=0}^{n-\ell-1} h_i\,h_{i+\ell}.
\]

If we can find a binary vector with a large value of   
\(m:=\min_{\ell\neq0} S_\ell\) then the corresponding bound is  

\[
C_5 = dx\,(N-m).
\]

Thus the optimisation becomes a **max‑min quadratic integer programme**.

### 2.  Exact integer linear programming model  

Introduce  

* binary decision variables `x[i] ∈ {0,1}` for the values of `h`.  
* auxiliary binary variables `y[i,ℓ]` that encode the product  
  `x[i]·x[i+ℓ]` for every admissible lag `ℓ = 1,…,n‑1` and index  
  `i = 0,…,n‑ℓ‑1`.  

Linearisation (McCormick / “AND” constraints)  

```
y[i,ℓ] ≤ x[i]
y[i,ℓ] ≤ x[i+ℓ]
y[i,ℓ] ≥ x[i] + x[i+ℓ] – 1
y[i,ℓ] ∈ {0,1}
```

Define for each lag  

\[
S_\ell = \sum_{i} y[i,\ell].
\]

Introduce a continuous epigraph variable `m` that lower‑bounds all
autocorrelations:

```
S_ℓ ≥ m    for all ℓ = 1,…,n‑1 .
```

The complete ILP is

```
max   m
s.t.  Σ_i x[i]                = N          (mass constraint)
      y[i,ℓ] linearised as above
      S_ℓ = Σ_i y[i,ℓ]       ≥ m
      x[i] ∈ {0,1},  y[i,ℓ] ∈ {0,1}
```

The objective `m` is exactly the quantity we need; the resulting bound is  

`C5 = dx * (N - m)`.

### 3.  Reducing symmetry – a few extra constraints  

The problem is invariant under cyclic shifts and under reversal of the
interval.  To break these symmetries (and dramatically shrink the branch‑and‑bound
tree) we add cheap linear constraints:

* **Fix the first point** – set `x[0] = 1`.  
  (Any optimal solution can be shifted so that the leftmost point is occupied.)
* **Lexicographic ordering of the first half** – for the first `N` indices enforce  

```
x[0] ≥ x[1] ≥ … ≥ x[N-1] .
```

  This forbids permutations that are pure rotations while keeping the feasible set
  non‑empty (a balanced Sturmian sequence satisfies it).

These constraints do not change the optimum value but cut the search space
roughly by a factor of `n`.

### 5.  Local combinatorial refinement – greedy swap hill‑climb  

Even when the ILP returns a feasible binary vector, it may be
sub‑optimal because CBC stops at a time limit.  A cheap dedicated
post‑processor can push the minimum autocorrelation `m` upwards.

**Data structures**  

* `x` – current binary vector.
* `S[ℓ] = Σ_i x_i·x_{i+ℓ}` for all lags (computed once with a single FFT, O(n log n)).
* Two index lists: `ones = { i | x_i = 1 }`, `zeros = { i | x_i = 0 }`.

**Swap move**  

Pick uniformly a pair `(i ∈ ones, j ∈ zeros)` and propose swapping the
bits.  The effect on every lag `ℓ` is

```
ΔS_ℓ = - (x[i+ℓ] + x[i-ℓ]) + (x[j+ℓ] + x[j-ℓ]) .
```

All out‑of‑range accesses are ignored (treated as zero).  
We update a temporary `S' = S + ΔS` and compute `m' = min_{ℓ≠0} S'`.  
If `m' > m` we *accept* the swap, set `x←x'`, `S←S'`, `m←m'`
and record a new best bound.  Otherwise the swap is rejected.

Because the update of `S` is `O(n)` we can examine a few thousand swaps per
second.  The hill‑climb stops when a full pass over `5·n` random pairs
produces no improvement or when the allocated time expires.

**Escaping plateaus** – when the greedy phase stalls we switch to a
*simulated‑annealing* mode: accept a non‑improving swap with probability
\(\exp((m'‑m)/T)\) where the temperature `T` decays geometrically
(`T ← 0.99·T` each iteration).  The initial temperature is set to a small
fraction (≈ 0.01) of the current `C5` value; this keeps the search local
yet able to cross shallow barriers.
