Re‑formulate the Erdős minimum‑overlap problem as an *exact* mixed‑integer linear program (MILP) and solve it with a generic MILP solver (CBC, GLPK, SCIP, …).  
The MILP works on a *binary* step‑function (each sample is either 0 or 1) with the exact area constraint ‑‑ this matches the known extremal solutions of the problem and avoids the need for continuous projections or heuristic gradients used in the previous attempts. ### 1. Decision variables

* `n` – number of discretisation points (choose an even value, e.g. **n = 120**; a smaller even `n` such as 80 can be used if the MILP is too large).
* `h_i ∈ {0,1}` for `i = 0,…,n‑1` – the step‑function values (0 = “outside A”, 1 = “inside A”).
* For every admissible pair `(i,k)` with `i + k < n` define a binary auxiliary variable  
  `w_{i,k} ∈ {0,1}` that will encode the product `h_i * h_{i+k}`.
* A scalar continuous variable `t ≥ 0` that will represent the *worst* raw overlap  
  `t = max_k Σ_i h_i·(1‑h_{i+k})`.

### 2. Linearisation of the product  

For each pair `(i,k)` (including `k = 0`) impose the classic “AND’’ constraints:

```
w_{i,k} ≤ h_i
w_{i,k} ≤ h_{i+k}
w_{i,k} ≥ h_i + h_{i+k} – 1
```

These three linear inequalities force `w_{i,k}` to be exactly the logical AND of `h_i` and `h_{i+k}`.

*When k = 0 the constraints collapse to `w_{i,0} = h_i`, so we do not need a separate definition.*

The total number of `w`‑variables is  

```
∑_{k=0}^{n‑1} (n‑k) = n·(n+1)/2 .
```

For `n = 120` this is 7 260 auxiliary binaries – well within the capability of modern open‑source MILP solvers.

### 3. Objective and constraints that encode the overlap

Define the fixed total “mass’’ of the set:

```
F = ∑_i h_i = n/2                (exactly half of the interval)
```

The raw overlap for a given shift `k` is  

```
C_k = ∑_i h_i – ∑_i h_i·h_{i+k}
    = F – Σ_i w_{i,k} .
```

Introduce the variable `t` and enforce, for every shift `k = 0,…,n‑1`,

```
t ≥ F – Σ_i w_{i,k} .
```

Because `F` is constant, each inequality simply bounds `t` from below by the
raw overlap of that shift.  Minimising `t` therefore minimises the worst overlap.

**MILP model**

```
minimise   t
subject to
   Σ_i h_i               = n/2               (area constraint)
   w_{i,k} ≤ h_i
   w_{i,k} ≤ h_{i+k}
   w_{i,k} ≥ h_i + h_{i+k} – 1                (product linearisation)
   t      ≥ F – Σ_i w_{i,k}   for all k
   h_i ∈ {0,1},  w_{i,k} ∈ {0,1},  t ≥ 0 .
```

The model is completely linear; the only non‑linearity (the product) has been removed by the auxiliary `w`‑variables.

The *continuous* value of interest is  

```
C5 = (2/n) * t .
```

After solving the MILP we obtain an integer vector `h` and a tight upper bound on `C5`.
