**Mathematical reformulation**

The objective is  

\[
C_5=\max_{k\in\{-N+1,\dots ,N-1\}} O(k),\qquad 
O(k)=\int_0^2 h(x)\bigl(1-h(x+k)\bigr)\,dx .
\]

If we discretise the interval with \(N\) points (step \(\Delta x =2/N\)) and write the
vector \(h=(h_0,\dots ,h_{N-1})\), the integral becomes  

\[
O(k)=\Delta x\sum_{i:\,0\le i,i+k<N} h_i\bigl(1-h_{i+k}\bigr)
      =\Delta x\Bigl(\sum_i h_i-\sum_i h_i h_{i+k}\Bigr) .
\]

Because \(\sum_i h_i=N/2\) the constant term is always \(1\), so  

\[
O(k)=1-\Delta x\sum_i h_i h_{i+k}.
\]

Hence minimising the maximum overlap is equivalent to **maximising the smallest
auto‑correlation** \(\sum_i h_i h_{i+k}\).  The problem can be written as a
constrained min‑max problem

\[
\min_{h\in[0,1]^N,\; \sum h_i=N/2}\;\max_k O(k).
\]

The max‑operator is non‑smooth, but it can be approximated by a smooth
log‑sum‑exp (LSE) function:

\[
F_\alpha (h)=\frac{1}{\alpha}\log\!\Bigl(\sum_k e^{\alpha\,O(k)}\Bigr) ,
\qquad \alpha>0 .
\]

For increasing \(\alpha\) we have \(F_\alpha(h)\uparrow \max_k O(k)\).
Thus we can solve a sequence of smooth optimisation problems, starting with a
small \(\alpha\) (heavy smoothing) and gradually increasing it (homotopy
strategy).

--------------------------------------------------------------------
### 1.  Discretisation choice
* Use a modest number of points (e.g. \(N=200\) or \(N=240\)).  
  This keeps the correlation matrix small (full convolution costs
  \(O(N^2)\) which is negligible in compiled NumPy code) while providing
  enough resolution to improve on the current record.

--------------------------------------------------------------------
### 2.  Feasible set projection
The constraints are a box \([0,1]^N\) together with a single linear equality
\(\sum_i h_i = N/2\).  
A fast projection onto this convex set is obtained by the classic “water‑filling”
procedure:

```
Given a vector x, find λ such that   sum( clip(x+λ,0,1) ) = N/2.
```

Because the left‑hand side is monotone in λ, λ is found by a short binary
search (≈30–40 iterations) and the projected vector is
`clip(x+λ,0,1)`.  This routine is used after every gradient step.

--------------------------------------------------------------------
### 3.  Gradient of the smoothed objective

For a fixed lag \(k\) the derivative of \(O(k)\) w.r.t. a component \(h_i\) is

\[
\frac{\partial O(k)}{\partial h_i}
   =\Delta x\Bigl(1 - h_{i+k} - h_{i-k}\Bigr) ,
\]

where out‑of‑range indices are treated as zero.  

Define the softmax weights (the LSE gradient coefficients)

\[
w_k = \frac{e^{\alpha O(k)}}{\sum_{j} e^{\alpha O(j)}} .
\]

The gradient of the smoothed objective is the weighted sum

\[
\nabla F_\alpha (h)=\sum_k w_k \,\nabla O(k)
                 =\Delta x\Bigl(
                    \underbrace{\sum_k w_k}_{=1}
                    \mathbf{1}
                    \;-\;
                    \sum_k w_k\,\text{shift}_k^+h
                    \;-\;
                    \sum_k w_k\,\text{shift}_k^-h\Bigr).
\]

All three vector terms can be obtained by a **single convolution**:

* Form the weight vector `W` of length `2N‑1` (corresponding to lags `‑N+1…N‑1`).
* The forward‑shift term equals the **valid convolution** of `W` (reversed)
  with `h`.  
* The backward‑shift term is the same convolution because `h` appears symmetrically.
* Adding the two convolutions gives the full subtraction term.

Thus the gradient is computed in \(O(N\log N)\) (FFT) or \(O(N^2)\) (direct)
time, both cheap for our chosen N.

### 4.  Optimisation algorithm (per restart)

```
Input: initial feasible h0 , target sum = N/2 , total budget T.
Parameters: α schedule (α0=5, multiply by 2 each stage up to αmax≈200),
            initial step size η0 (≈0.5), backtracking factor β=0.5,
            tolerance ε (10⁻⁸) for inner line‑search.

h ← h0
For α in [α0, 2·α0, 4·α0, … , αmax]:
    repeat
        – Compute O(k) = Δx * correlate(h, 1‑h, mode='full')
        – Compute weights w_k = softmax(α·O(k))
        – Compute gradient g = Δx*(1 – (W ⋆ h)_forward – (W ⋆ h)_backward)
        – Line search:
            η ← η0
            while True:
                h₁ ← project( h – η·g )
                F₁ ← (1/α)·log( Σ exp(α·O₁(k)) )   (O₁ from h₁)
                if F₁ ≤ F_current – ε·η·‖g‖²  or η < 1e‑6: break
                η ← β·η
        – If F₁ improves, accept h ← h₁, else keep old h.
    until change in Fα below tolerance or max inner iterations reached.
```

The backtracking line‑search guarantees descent of the smoothed objective
while keeping the iterates feasible (projection after each trial step).
