### 1.  Reformulation of the objective  

For a discretisation with `n` points (`dx = 2/n`) and a binary step‑function  
`h_i ∈ {0,1}` (`i = 0,…,n‑1`) the overlap integral computed by the
provided evaluator is  

\[
C_5(h)=dx\;\max_{\,\ell\in\{-n+1,\dots ,n-1\}} 
\Bigl[\sum_{i} h_i\bigl(1-h_{i+\ell}\bigr)\Bigr].
\]

Because the total mass is fixed,  

\[
\sum_i h_i = N = \frac{n}{2},
\qquad 
\sum_i h_i\bigl(1-h_{i+\ell}\bigr)=N-S_\ell,
\]

where  

\[
S_\ell = \sum_{i=0}^{n-\ell-1} h_i\,h_{i+\ell}
\]

is the (non‑circular) a‑periodic autocorrelation of shift `ℓ`.  

Hence

\[
C_5(h)=dx\;(N-\min_{\ell\neq0}S_\ell).
\]

**Goal:** maximise the *minimum* autocorrelation  
\(m:=\min_{\ell\neq0}S_\ell\); the bound is then  

\[
C_5 = dx\,(N-m).
\]

Thus the problem is a **max‑min quadratic binary optimisation**.

### 2.  Convex SDP relaxation (lifting)

Introduce a real vector variable `x∈ℝⁿ` (intended to be the binary vector) and a
symmetric matrix variable `X∈ℝ^{n×n}` that will play the role of the rank‑one
matrix `x xᵀ`.  The lifting yields a convex (semidefinite) feasible region.

Constraints

| Symbol | Meaning |
|--------|----------|
| `0 ≤ x_i ≤ 1` | box constraints |
| `∑_i x_i = N` | prescribed sum |
| `X ⪰ 0` | positive semidefinite |
| `X_{ii} = x_i` for all `i` | diagonal of `X` equals `x` |
| `X_{ij} ≤ x_i` and `X_{ij} ≤ x_j` | McCormick upper envelope |
| `X_{ij} ≥ x_i + x_j - 1` | McCormick lower envelope |

For each lag `ℓ = 1,…,n‑1` define the autocorrelation term as a linear functional  

\[
S_\ell(x,X)\;=\;\sum_{i=0}^{n-\ell-1} X_{i,i+\ell}.
\]

Introduce a scalar epigraph variable `m`.  Enforce  

\[
S_\ell(x,X) \;\ge\; m \qquad \forall\; \ell=1,\dots,n-1.
\]

The **SDP** is then  

\[
\max\; m\quad\text{s.t. all constraints above.}
\]

If the solution satisfied `rank(X)=1` and `x∈{0,1}` it would be optimal.
Dropping the rank condition gives a tractable convex relaxation that
provides a *upper bound* on the attainable minimum autocorrelation and hence a
*lower bound* on `C_5`.

### 5.  Extracting a binary candidate – Random hyperplane rounding  

The SDP yields a feasible pair `(x̂ , X̂ )`.  To obtain a binary vector
preserving the correlation structure:

1. **Factorise** `X̂`.  Because `X̂ ⪰ 0`, compute a (possibly low‑rank) Cholesky
   or eigen‑decomposition: `X̂ = V Vᵀ`, where rows `v_i` of `V` are vectors in
   ℝʳ (r = rank of `X̂`, typically much smaller than `n`).

2. **Sample a random Gaussian direction** `g ∈ ℝʳ` (each component `~ N(0,1)`).

3. **Hyperplane cut**: set  

   \[
   z_i = \begin{cases}
   1 & \text{if } v_i\cdot g \ge 0,\\
   0 & \text{otherwise}.
   \end{cases}
   \]

   The resulting `z ∈ {0,1}ⁿ` respects the orientation of the embedding; in
   expectation its autocorrelations are close to those of the SDP solution.

4. **Weight correction** – `∑z_i` may differ from `N`.  
   Let `Δ = ∑z_i - N`.  

   *If Δ>0* (too many ones): compute the absolute margins
   `|v_i·g|` for all indices with `z_i=1`; flip the Δ smallest‑margin ones to
   zero.  

   *If Δ<0* (too few ones): compute the same margin for all zeros and flip
   the `|Δ|` largest‑margin zeros to one.  

   This “swap‑rounding” step changes the weight while disturbing the correlation
   as little as possible.

The output of this stage is a **binary vector `h⁰`** that satisfies the sum
constraint exactly.

### 6.  Local combinatorial polishing – greedy swap hill‑climb  

Starting from `h⁰` we improve the worst lag by deterministic swaps.  The
procedure is identical to the fast swap‑move described in the earlier
solution, but we embed it here as an independent refinement:

* Pre‑compute the full autocorrelation array `S_ℓ = Σ_i h_i h_{i+ℓ}` using a
  single FFT (`O(n log n)`).
* Maintain two index lists `ones = {i | h_i=1}` and `zeros = {j | h_j=0}`.
* Repeatedly pick a random pair `(i∈ones, j∈zeros)` and compute the per‑lag
  delta  

  \[
  ΔS_ℓ = -\bigl(h_{i+ℓ}+h_{i-ℓ}\bigr) + \bigl(h_{j+ℓ}+h_{j-ℓ}\bigr)
  \quad(\text{out‑of‑range indices are ignored}).
  \]

* Let `m' = min_{ℓ≠0}(S_ℓ + ΔS_ℓ)`.  If `m' > m` (i.e. the minimum autocorrelation
  improves) **accept** the swap, update `h`, `S_ℓ`, `ones`, `zeros`, and `m`.  
  Otherwise reject.

* If after `5·n` random attempts no improvement occurs, optionally switch to a
  *simulated‑annealing* acceptance rule with temperature `T` decreasing
  geometrically (`T ← 0.99·T`) to escape shallow plateaus.

Run this hill‑climb until the allocated time slice (`≈0.30·budget_s`) expires
or until no improving swap is found for a full pass.  Keep the best `h` and the
corresponding exact `C_5` (computed with `np.correlate` as in the evaluator).

### 7.  Outer binary‑search on the target autocorrelation (optional)

one can instead perform a *feasibility* binary search:

* Choose lower and upper bounds `m_low = 0`, `m_high = N`.
* Repeat:
  * Set `m_candidate = (m_low + m_high)/2`.
  * Add constraints `S_ℓ ≥ m_candidate` (linear in `X`) and **do not**
    maximise `m`.
  * Solve the feasibility SDP (often faster than a maximise problem).
  * If feasible, set `m_low = m_candidate`; else `m_high = m_candidate`.
* Stop after a fixed number of iterations (e.g. 8) or when the time budget for
  the SDP stage is exhausted.
* Use `m_low` as the SDP objective value for rounding.

This binary‑search variant is useful when the optimizer stalls on the
objective gradient.

   * improve `h⁰` with greedy (or annealed) swap hill‑climb,
   * compute exact `C_5`; keep the best vector.
4. **If time remains** – run the deterministic Sturmian construction,
   refine with hill‑climb, update best if better.
5. **Return** `(best_h.tolist(), float(best_C5), n)`.

All helper routines (`build_sdp_model`, `solve_sdp`, `round_solution`,
`adjust_weight`, `hill_climb`, `evaluate_c5`) are defined at top level,
use only `numpy`, `scipy`, and `cvxpy`, and respect the single‑CPU, 600 s
budget.

### 13.  Failure‑mode handling  

| Failure | Mitigation |
|---------|------------|
| SDP does not finish in allocated time | Abort SDP early; move to deterministic fallback. |
| Factorisation of `X̂` is numerically unstable | Add a tiny regularisation term `ε I` (ε≈1e‑8) before Cholesky. |
| Rounding produces a weight far from `N` | Use swap‑rounding; if `|Δ|` exceeds `0.1 N` repeat with a fresh hyperplane. |
| Hill‑climb stalls in a local optimum | Switch to simulated‑annealing acceptance for a few hundred swaps. |
| Memory overflow for PSD matrix (if `n` is too large) | Reduce `n` to 112 or 96 and restart the SDP stage. |
