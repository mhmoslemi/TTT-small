* 0 ≤ h[i] ≤ 1,

### 1.  Reformulation

Because  

\[
O(k)=dx\Bigl(\sum_i h_i-\sum_i h_i h_{i+k}\Bigr)
      =1-dx\sum_i h_i h_{i+k},
\]

minimising the maximum overlap is equivalent to **maximising the minimal auto‑correlation**
\[
Q(k)=\sum_i h_i h_{i+k}.
\]
Thus the problem is a classic “min‑max” optimisation:  

\[
\min_{h\in[0,1]^n,\;\sum h=n/2}\;\;F(h),\qquad
F(h)=\max_{k} O(k).
\]

All constraints are convex; the only non‑convex part is the max of a family of (piece‑wise) linear‑quadratic functions.

### 2.  Sub‑gradient of the max‑overlap

For a *fixed* shift k the overlap is  

\[
O_k(h)=dx\sum_i h_i(1-h_{i+k})
      =dx\Bigl(\sum_i h_i -\sum_i h_i h_{i+k}\Bigr).
\]

The (un‑scaled) gradient of the inner sum is  

\[
\frac{\partial O_k}{\partial h_i}=dx\Bigl(1 - h_{i+k} - h_{i-k}\Bigr),
\qquad
\bigl(h_{j}=0\text{ if }j\notin[0,n-1]\bigr).
\]

If *k\** is a lag attaining the current maximum, any sub‑gradient of F at h is exactly this gradient for k\*.  
Hence a descent direction is  

\[
g_i = 1 - h_{i+k^\*} - h_{i-k^\*}\, .
\]

(We omit the factor dx; it can be absorbed into the step size.)

---

### 3.  Projection onto the feasible set

After a gradient step the iterate may leave the box [0,1] or violate the sum constraint.  
Projection is performed in two stages:

1. **Shift** every component by a scalar λ, then clamp to [0,1]:  

   \[
   \tilde h_i=\operatorname{clip}(h_i+\lambda,\,0,1).
   \]

2. Choose λ so that Σ \tilde h_i = n/2.  
   This is a one‑dimensional monotone equation; a fast binary search on λ (as in the reference code) converges in ~30–40 iterations to machine precision.

The resulting vector is the Euclidean projection onto the intersection of the hyper‑cube and the affine hyperplane.

### 4.  Core optimisation loop (Projected Sub‑gradient Descent)

For a given starting vector **h₀**:

```

best_h ← h₀
best_val ← F(h₀)

```

* **Gradient computation** is O(n) (just two shifted copies of h).  
* **Correlation** for the max value is O(n²) via `np.correlate`, cheap for n ≤ 300.  
* **Momentum** can be added: keep a velocity `v ← β·v + (1‑β)·g` and update `h ← h - step·v`. β≈0.9 works well.  

The diminishing step size guarantees convergence of the sub‑gradient method; the momentum accelerates early progress.

### 5.  Smoothing the max (optional refinement)

Pure max‑sub‑gradient can be noisy because the active lag jumps abruptly.  
A smoother surrogate is the *log‑sum‑exp*:

\[
\tilde F_\tau (h)=\frac{1}{\tau}\log\Bigl(\sum_k e^{\tau O(k)}\Bigr),
\]

with temperature τ ≫ 0. Its gradient is a weighted average of the gradients of all lags:

\[
\frac{\partial\tilde F_\tau}{\partial h_i}
   =\sum_k w_k\;(1-h_{i+k}-h_{i-k}),\qquad
   w_k=\frac{e^{\tau O(k)}}{\sum_j e^{\tau O(j)}} .
\]

In practice we start with a modest τ (e.g. 1) and increase it geometrically (τ←τ·1.5 every few hundred iterations).  
During the low‑τ phase the descent is smoother, helping to escape local plateaus; the high‑τ phase mimics the true max.

Implementation is cheap because the weight vector w is obtained from the O‑array; the weighted sum of shifted h can be formed with a single convolution (`np.convolve`) rather than a loop.
