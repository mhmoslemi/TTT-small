**Goal** – Obtain a step‑function  h  on [0,2]  (discretised with n points) that satisfies  

```
0 ≤ h[i] ≤ 1 ,      Σ h[i] · dx = 1    (dx = 2/n)
```

and minimises  

```
C5(h) = maxk   dx·∑i h[i]·(1−h[i+k])        (full correlation)
```

The current best bound (~0.380975) was found with simulated annealing / DE / SLSQP.  
The new approach replaces the noisy heuristics by **smooth projected gradient optimisation** on a differentiable surrogate of the max‑operator, combined with systematic re‑starts, adaptive resolution and a final small‑scale quadratic refinement.

---

### 1.  Smooth surrogate of the max‑operator

For a vector of overlaps  

```
O = [ O(k) ]k = dx·correlate(h, 1–h, mode='full')
```

define  

```
Fα(h) = (1/α)·log( Σk exp( α·O(k) ) )            (α > 0)
```

*   As α → ∞,  Fα  →  max O(k).  
*   For moderate α the function is smooth, its gradient exists, and the landscape is easier to traverse.

The gradient of a single overlap is elementary:

```
∂O(k)/∂h[i] = dx·( 1 – h[i+k] – h[i−k] )      (zero if index out of range)
```

Hence  

```
∂Fα/∂h[i] = Σk wk · ∂O(k)/∂h[i] ,
wk = exp(α·O(k)) / Σj exp(α·O(j))      (softmax weights)
```

All wk sum to 1, so the gradient is a convex combination of the individual overlap gradients.

---

### 2.  Projection onto the feasible set

The feasible set is a **box** (0 ≤ h ≤ 1) intersected with the **affine** equality Σh = n/2.  
Projection can be performed by a 1‑D **water‑filling** (or the binary‑search lambda) method:

```
Given x, find λ such that  Σ clip(x+λ,0,1) = n/2 .
```

A few bisection steps (≈30) converge to machine precision; the operation is O(n).

---

### 3.  Projected gradient descent with momentum

Maintain a velocity vector **v** (initially 0).  For iteration t:

```
• Compute O(k) and the softmax weights wk with the current α.
• Compute the gradient g = ∂Fα/∂h as described above.
• Update velocity:       v ← β·v + (1−β)·g            (β ≈ 0.9)
• Take a step:          h ← h – η·v
• Project h onto the feasible box‑sum set.
```

**Parameter schedule**

| Phase | α (smoothness) | η (step size) | Iterations |
|------|----------------|---------------|------------|
| Warm‑up   | 1.0 → 4.0 (multiply by 1.5 every 200 it.) | η₀ = 0.5 → 0.05 (divide by √t) | 2000 |
| Fine‑tune| 8.0 → 32.0 (same multiplier)                | η₀ = 0.05 → 0.005               | 3000 |

The gradual increase of α sharpens the approximation to the true max, while the decreasing η prevents overshooting near the optimum. Momentum smooths the trajectory and helps escape shallow plateaus.

All heavy linear algebra uses **NumPy**; the correlation needed for O(k) is obtained either by `np.correlate` (O(n²) but fast for n≤300) or by FFT (`np.fft`) for larger n (O(n log n)).

### 4.  Multi‑resolution and systematic restarts

1. **Base resolution** – start with n = 120 (the size of the supplied `initial_h_values`).  
2. **Upsampling** – after a first successful run, linearly interpolate the best h to a finer grid (n = 180, 240, … up to 400, never exceeding 1000).  The finer grid inherits the structure of the coarse optimum but gains extra degrees of freedom.  
3. **Restart pool** – for each resolution run several initialisations:
   *   The upsampled predecessor.
   *   Random vectors h ∼ U[0,1] projected onto the sum‑box.
   *   Structured patterns (e.g. one block of 1’s, one block of 0’s, a linear ramp, a sine wave clipped to [0,1]) – these are inexpensive to generate and often lie close to good basins.
4. Run the projected gradient descent (Section 3) on each start until either a fixed iteration budget (≈3000) is exhausted or the elapsed wall‑time reaches a pre‑allocated slice of the total 600 s.  
5. Keep the **best** (lowest C5) candidate of the whole pool.

Because the algorithm is deterministic apart from the random starts, the time spent on each resolution can be tuned on‑the‑fly: if a coarse run already reaches C5 < 0.381, the remaining budget is allocated to finer grids; otherwise more restarts at the current resolution are performed.

### 5.  Active‑set quadratic refinement (optional, last 5 % of time)

After the gradient phase we have a candidate h* and a set  

```
Kactive = { k | O(k) ≥ C5(h*) – ε }     (ε ≈ 1e‑4)
```

For these “almost‑tight” lags we solve a small **quadratically‑constrained** problem that directly maximises the minimum overlap product:

```
max   t
s.t.  Σi h[i]·h[i+k] ≥ (1 – t)/dx    ∀ k ∈ Kactive
      Σi h[i] = n/2
      0 ≤ h[i] ≤ 1
```

The constraints are quadratic but involve only the already‑identified active lags; the problem size is modest (|Kactive| ≤ 20).  Using a generic nonlinear optimiser (e.g. `scipy.optimize.minimize` with SLSQP) on this *low‑dimensional* problem converges quickly and often pushes the bound a few 10⁻⁴ further.

If the optimiser fails to improve, we simply keep the gradient‑descent result.
