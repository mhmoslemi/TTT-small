### 1.  Formulate a binary integer program (BIP) that maximises the minimal autocorrelation

#### 1.1 Decision variables  

* `h[i] ∈ {0,1}` for each grid point `i = 0 … n‑1`.  
* `w[i,k] ∈ {0,1}` for each pair `(i,k)` with `0 ≤ k ≤ n‑1` and `i+k < n`.  
  The variable `w[i,k]` will represent the logical **AND** `h[i] ∧ h[i+k]`.  
* A scalar integer variable `m ≥ 0` representing the common lower bound on all autocorrelations.

#### 1.2 Linearisation of the product  

For every feasible `(i,k)` add the classic “AND’’ constraints  

```
w[i,k] ≤ h[i]               (1)
w[i,k] ≤ h[i+k]             (2)
w[i,k] ≥ h[i] + h[i+k] – 1   (3)
```

These three constraints enforce `w[i,k]=1` iff both `h[i]` and `h[i+k]` are 1, otherwise `w[i,k]=0`.

#### 1.3 Sum‑of‑ones (area) constraint  

```
∑_{i=0}^{n-1} h[i] = n/2 .
```

(The right‑hand side is an integer because we will choose `n` even.)

#### 1.4 Autocorrelation lower‑bound constraints  

For every shift `k = 1 … n‑1` (shift `0` is trivial, `S_0 = n/2`)  

```
∑_{i=0}^{n-1‑k} w[i,k] ≥ m .
```

#### 1.5 Objective  

```
maximise  m .
```

Because `C5 = 1 – 2m/n`, maximizing `m` directly minimises the desired overlap bound.

### 4.  Post‑processing of the binary solution

#### 4.1 Compute the exact overlap bound  

From the binary vector `h` returned by the BIP:

```
C5 = (2/n) * ( n/2 – m_obtained ) .
```

(Optionally recompute `C5` via a full correlation to guard against any modelling slip.)

If `C5 < 0.3807` we are already done.  Very often the CP‑SAT solution for `n = 120` reaches `m ≥ 28`, yielding `C5 ≤ 0.375`.

#### 4.2 Deterministic local improvement (swap‑hill‑climb)  

Even when the BIP terminates early, the incumbent may be sub‑optimal by only a few units of `m`.  We therefore perform a **greedy 0↔1 swap search**:

1. Maintain the current autocorrelation array `S_k = Σ_i h[i] h[i+k]`.  
2. For each pair `(i_zero, j_one)` (i.e. `h[i]=0`, `h[j]=1`) compute the *delta* in every `S_k` that would result from swapping these two bits.  This delta can be obtained in `O(n)` by scanning the two rows of the Toeplitz matrix; the cost is negligible for `n = 120`.  
3. The swap is accepted if it **strictly increases** the current lower bound `m` (i.e. the new minimal `S_k` is larger).  Perform the swap, update `S_k`, and repeat until no improving swap exists.

Because each accepted swap raises `m` by at least 1, the loop terminates after at most `n/2` iterations.

#### 4.3 Optional randomized polishing  

If the greedy phase stalls before the target bound, we run a brief **Monte‑Carlo perturbation**:

* Randomly pick a few (e.g. 3) disjoint 0↔1 swaps, accept the batch if the resulting `m` does not decrease, otherwise reject.  
* Repeat for a few thousand trials (still cheap thanks to O(n) updates).  

This can occasionally jump out of a shallow local optimum discovered by the deterministic hill‑climb.

#### 5.1 Encoding  

* Each individual is a binary array of length `n` with exactly `n/2` ones.

#### 5.2 Fitness evaluation  

* Compute `C5` with `np.correlate` (or, for speed, using a pre‑computed FFT of the individual's complement).

* **Selection** – tournament of size 3.  
* **Crossover** – uniform crossover with subsequent repair.  
* **Mutation** – swap mutation: pick a random 0 and a random 1 and exchange them.

* Population size `pop = 200`.
