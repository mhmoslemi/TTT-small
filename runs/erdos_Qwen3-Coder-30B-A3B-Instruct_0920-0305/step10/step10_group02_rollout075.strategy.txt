   * Compute all overlaps `O_k` via FFT (`O_k = S_const – corr_k`).  
   * Form the soft‑max weights  

\[
w_k = \frac{\exp(\alpha O_k)}{\sum_{ℓ}\exp(\alpha O_ℓ)} .
\]

   * Assemble the gradient  

\[
g_j = \sum_{k} w_k\,\bigl(1 - h_{j+k} - h_{j-k}\bigr)
\]

   (vectorised with NumPy, treating out‑of‑range indices as zero).  
   * Take a step `h ← h - η·g` with a diminishing step‑size `η` (e.g. start `η=0.02` and multiply by `0.95` each iteration).  
   * Project back onto the feasible set using the same lambda‑projection of Phase 5.  
   * Evaluate the true `C5` (via `evaluate_c5`) and keep the best `h` seen.

The soft‑max surrogate smooths the landscape enough for gradient descent to make progress, yet the final projection guarantees feasibility.

--------------------------------------------------------------------
### 7. Final polishing with a *exact* optimiser (SLSQP)

Take the best continuous vector from Phase 6 as `h0`.  Run a short **SLSQP** optimisation on the *exact* max‑overlap objective:

* Objective: `C5(h) = dx * max_k np.correlate(h,1-h,mode='full')`.  
  (SLSQP will treat the max as a nondifferentiable piecewise linear function, but it can still handle it via the internal sub‑gradient approximation.)  
* Equality constraint: `∑ h_i = target_sum`.  
* Bounds: `0 ≤ h_i ≤ 1`.  
* Initialise with `h0`, limit `maxiter=400`, tolerance `1e‑9`.  

Even a few SLSQP iterations often shave a few 10⁻⁴ off the value.
