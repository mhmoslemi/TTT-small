def project_to_sum_box(x, target):
    """Project onto [0,1] box and ensure sum = target using bisection on λ."""
    lo = -1.
    hi = 1.
    # Expand bounds until the sum at lo <= target <= sum at hi
    while np.sum(np.clip(x+lo,0,1)) > target:
        lo -= 1
    while np.sum(np.clip(x+hi,0,1)) < target:
        hi += 1
    for _ in range(50):
        mid = (lo + hi) / 2
        s = np.sum(np.clip(x+mid,0,1))
        if s < target:
            lo = mid
        else:
            hi = mid
    return np.clip(x + (lo+hi)/2,0,1)

**Goal** – Find a step‑function `h` on `[0,2]` (sampled on `n_points` grid points) with  
`0 ≤ h[i] ≤ 1`, `∑ h[i]·dx = 1` (`dx = 2/n_points`) that minimises  

```

    = 1 – min_k ∫ h(x)·h(x+k) dx .
```

Thus the problem is equivalent to **maximising the smallest auto‑correlation** of `h`.  
The algorithm below combines a *global* search (Differential Evolution on a low‑dimensional
parameterisation) with a *local* sub‑gradient ascent that directly increases the
minimum correlation, while always enforcing the box‑ and sum‑constraints.
A symmetric shape about the centre of the interval is imposed – the optimal
solution is known to be symmetric, and symmetry halves the effective search space,
making the optimisation more stable.

### 1. Global representation (piecewise constant)

* Choose a modest grid size (`n_points = 200`).  
  `dx = 2.0 / n_points`, target sum `TARGET_SUM = n_points/2` because  
  `∑h·dx = 1  ⇔  ∑h = 1/dx = n_points/2`.

* Parameterise `h` by **`m` intervals** (`m ≈ 30`).  
  Let `v = (v0,…,v_{m‑1})` with each `v_j ∈ [0,1]`.  
  Interval `j` receives a length of either `⌊n/m⌋` or `⌈n/m⌉` points (the first
  `n % m` intervals get one extra point).  
  Expanding `v` yields a length‑`n` vector `h_raw`.

* After expansion we **symmetrise** the vector:

```
h_sym = (h_raw + h_raw[::-1]) / 2          # preserves the total sum
```

* Finally we **project** `h_sym` onto the feasible set
  (box `[0,1]` and exact sum `TARGET_SUM`).  
  Projection is performed by a simple bisection on a scalar shift `λ`:

```
proj(x) = clip(x + λ, 0, 1)   with   Σ proj(x) = TARGET_SUM .
```

The monotone relation `λ ↦ Σ clip(x+λ,0,1)` guarantees convergence in ≤50 bisection steps.

* Compute the full auto‑correlation using NumPy’s C‑implemented routine:
