Given complexity, I propose final algorithm approach:

**Algorithm Overview**:

1. Determine `n_points`. Use 200 for better resolution (makes dx = 0.01). At the end, we may compress to lower number if final solution is just binary (0/1) with length 200, still okay as less than 1000.

2. Create initial h via "interval pattern" with parameters: using m=5 intervals; equally spaced at key positions typical of known constructions: e.g., pattern: [1,0,1,0,1] alternating lengths.

3. Generate multiple random initial binary patterns (mass exactly half). Use each as starting point for local improvement.

4. Local improvement: For each pattern, run a hill climbing search where at each step we consider all possible swaps of a 1 and a 0 (or a limited random subset) and accept if reduces max_overlap. Continue until no improvement for a while.

   - Since evaluating all O(n^2) swaps each iteration expensive, we restrict to candidate swaps that impacted current worst shift(s). To identify candidate swaps: compute gradient - for each index i, compute contribution to the worst shift(s): delta_i = Σ_{s ∈ S_worst} (1 - h_{i+s}) - h_{i-s}. Use that to decide which 1's to lower and 0's to increase. Perform swap of pair with best net improvement.

   - This is effectively evaluating gradient of max (approx) w.r.t binary changes.

5. After hill climbing converges, apply simulated annealing steps to escape local minima: randomly swap pairs; if improvement, accept; else accept with probability decaying temperature. Continue for some time.

6. After many restarts, keep best found pattern.

7. Refine the best pattern using continuous projected gradient descent with log-sum-exp smoothing:

   - Use initial h from best binary vector.

   - Run projected gradient descent with step size schedule; maintain sum and box constraints via projection.
