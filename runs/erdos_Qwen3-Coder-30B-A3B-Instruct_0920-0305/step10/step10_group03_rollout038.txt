# MILP + Local Search Approach for Erdős Constant C₅

## Mathematical Foundation

The key insight is that this is a complex optimization problem with tight constraints that could benefit from structured discrete optimization. Instead of continuous gradient methods alone, we will combine:
1. Mixed Integer Linear Programming (MILP) to handle discrete structure
2. Binary skeleton optimization to represent piecewise constant structures
3. Worst-shift local search with adaptive perturbations
4. Coordinate-wise evolutionary search (DE-style)
5. Simulated Annealing for escape from local optima

## Algorithm Description

Our approach is based on representing the step function h(x) as a binary skeleton of the support set:

*   We discretize the domain [0, 2] into n_points = 120 intervals (so dx = 2/120)
*   We define a binary mask for whether each interval contains support (i.e., h[i] > 0)
*   From this binary skeleton, we use a multistart local search for the optimal piecewise constant piece values

## Key Components

1. **Binary MILP for Skeleton Structure**: Use integer programming to find binary structures that satisfy sum = 1 (via dx = 1/120) and are likely to be good search starting points.
2. **Worst-Shift Local Search**: For a fixed binary skeleton, optimize the values of the intervals involved by focusing on the one that contributes the most to the overlap. This is done iteratively by swapping values of conflicting intervals.
3. **Parametric Shape Search**: Systematically adjust the step function's shape by moving the boundaries or scaling values in a way that maintains the total sum.
4. **Differential Evolution (DE)**: Use a population-based evolutionary method to evolve two key parameters: the binary skeleton and the continuous real values for selected intervals.
5. **Simulated Annealing**: To help escape local minima, we include a probabilistic acceptance step based on energy difference, which guides the search through the discrete space.

## Implementation Plan

1. Start with initial_h_values (n=120) taken from previous solution
2. Generate a binary skeleton that captures local support
3. Use MILP to get a uniform support configuration based on binary structure
4. Perform worst-shift swaps to optimize each group of intervals
5. Optimize continuously within the sets of intervals defined by the skeleton using gradient descent
6. Explore using DE to evolve joint binary structures and values
7. Include at each stage a simulated annealing signal to allow better exploration of discrete space

## Numerical Choices

We choose n_points=120 as the number of samples for efficiency and to stay within the budget.
We use scipy.optimize for minimizing and for gradient-based polishing.
We scale our DE population size to 20 and number of generations to 100.
We define a temperature schedule that exponentially decreases.
We apply gradient descent in local polynomial interpolation.

import numpy as np
from scipy.signal import correlate
from scipy.optimize import minimize
import time
from cvxpy import *
import random

# Global variables
TARGET_SUM = None
n_points = 120
dx = 2.0 / n_points

def compute_corr_fft(h):
    """Compute correlation using FFT"""
    h_rev = h[::-1]
    b = 1 - h
    L = 2 * len(h) - 1
    corr = np.fft.ifft(np.fft.fft(h_rev, L) * np.fft.fft(b, L)).real
    return corr

def c5_from_corr(corr, n):
    """Convert correlation result to C5 value"""
    return dx * np.max(corr)

def evaluate_c5(h):
    """Fast evaluation of C5 using FFT"""
    corr = compute_corr_fft(h)
    return c5_from_corr(corr, n_points)

def project_to_sum_box(x, target_sum):
    """Project vector x onto box constraints [0,1] with sum = target_sum"""
    # Binary search for lambda: find lambda such that sum(clamp(x+lambda, 0, 1)) = target_sum
    def f(lam):
        projected = np.clip(x + lam, 0, 1)
        return np.sum(projected) - target_sum

    a, b = -1.0, 1.0
    while f(a) * f(b) > 0:
        a -= 0.1
        b += 0.1

    # Binary search
    tol = 1e-10
    for _ in range(50):
        m = (a + b) / 2
        fm = f(m)
        if abs(fm) < tol:
            break
        if fm * f(a) < 0:
            b = m
        else:
            a = m

    result = np.clip(x + (a + b)/2, 0, 1)
    return result

def optimize_with_gradient_descent(h0, max_iter=500):
    """Optimize using gradient-based method"""
    def objective(h):
        return evaluate_c5(h)
    
    def constraint_eq(h):
        return np.sum(h) - TARGET_SUM
    
    bounds = [(0, 1) for _ in range(n_points)]
    cons = {'type': 'eq', 'fun': constraint_eq}
    
    try:
        res = minimize(
            objective, 
            h0, 
            method='SLSQP', 
            bounds=bounds, 
            constraints=cons,
            options={'maxiter': max_iter, 'ftol': 1e-12, 'gtol': 1e-12}
        )
        if res.success:
            return project_to_sum_box(res.x, TARGET_SUM)
    except:
        pass
    return h0

def worst_shift_local_search(h_init, max_iter=3000):
    """Perform local search by finding the time-shift that causes worst overlap"""
    current_h = h_init.copy()
    current_c5 = evaluate_c5(current_h)
    best_h = current_h.copy()
    best_c5 = current_c5
    shift_steps = np.arange(1, n_points//2+1)
    for iter_count in range(max_iter):
        # Try shifting different subsegments and compute their new C5
        best_shift_improvement = 0
        best_shift =(None, None)
        best_new_h = None
        for shift in shift_steps:
            # Try shifting the middle section to the left or right side
            # This represents shifting all values in one interval to another
            h_new = current_h.copy()
            h_new[:-shift] = current_h[shift:]
            h_new[-shift:] = current_h[:shift]
            c5_new = evaluate_c5(h_new)
            improvement = current_c5 - c5_new
            if improvement > best_shift_improvement:
                best_shift_improvement = improvement
                best_shift = shift
                best_new_h = h_new
                
        if best_shift_improvement > 0:
            current_h = best_new_h
            current_c5 = evaluate_c5(current_h)
            if current_c5 < best_c5:
                best_h = current_h.copy()
                best_c5 = current_c5
        else:
            break
    return best_h, best_c5

def evolutionary_de(h0):
    """Use a simple evolutionary algorithm (DE) to evolve h values"""
    pop_size = 20
    generations = 100
    bounds = [(0, 1) for _ in range(n_points)]
    
    def fitness(h):
        return evaluate_c5(h)
    
    # Initialize population
    population = [h0.copy()]
    for i in range(1, pop_size):
        h = np.random.rand(n_points)
        h = project_to_sum_box(h, TARGET_SUM)
        population.append(h)
    
    for gen in range(generations):
        new_pop = []
        for i in range(pop_size):
            # DE mutation strategy
            idxs = [idx for idx in range(pop_size) if idx != i]
            a, b, c = [population[j] for j in random.sample(idxs, 3)]
            
            # Crossover
            F = 0.8
            CR = 0.9
            trial = np.where(np.random.rand(n_points) < CR, a + F*(b - c), population[i])
            trial = np.clip(trial, 0, 1)
            trial = project_to_sum_box(trial, TARGET_SUM)
            
            # Selection
            if fitness(trial) < fitness(population[i]):
                new_pop.append(trial)
            else:
                new_pop.append(population[i])
        
        population = new_pop
        
        # Update best so far
        best_idx = np.argmin([fitness(h) for h in population])
        current_best = population[best_idx]
        if fitness(current_best) < best_c5:
            best_h = current_best.copy()
            best_c5 = fitness(current_best)
    
    return best_h, best_c5

        c5_grad = evaluate_c5(h_grad)

            best_c5 = c5_grad
            
    return (best_h.tolist(), float(best_c5), n_points)
