### Mathematical Foundation
The problem seeks to minimize the maximum overlap integral C₅ = max_k ∫ h(x)(1 - h(x+k)) dx under constraints: h(x) ∈ [0,1], ∫₀² h(x) dx = 1. This is a non-convex optimization problem with a combinatorial nature due to the discrete nature of step functions and variable shifts.

### Proposed Algorithm Framework
1. **Binary MILP Skeleton**: Use mixed-integer linear programming to find a discrete skeleton of the optimal step function with a small number of pieces. This reduces the number of continuous variables from 120 to ~20, vastly increasing the tractability of the optimization.

2. **Worst-Shift Local Search**: After identifying a rough skeleton, perform a focused local search that considers only the top-k worst shifts (k typically 5-10), rather than all possible shifts. This significantly reduces the evaluation cost.

3. **Parametric Shape Search**: For each skeleton, use a continuous algorithm to find the optimal step heights that minimize C₅, treating the locations as fixed. This builds upon simple geometric reasoning.

4. **Differential Evolution Wrapper**: Use a global optimization algorithm (Differential Evolution) that iteratively improves skeleton configurations through mutation and recombination.

5. **Simulated Annealing Polish**: Apply simulated annealing to locally refine the final solution, giving fine-grained adjustments.

### Implementation Details
- **Step 1 (MILP)**: Use CBC or GLOP to solve a binary optimization problem that assigns steps to locations, ensuring the total area is 1.
- **Step 2 (Worst-Shift)**: For fixed step locations, compute correlation for top 10 worst shifts and optimize only those.
- **Step 3 (Shape Search)**: Solve for continuous heights using gradient-free optimization or quadratic programming.
- **Step 4 (DE)**: These parameters are represented as binary selections which can be evolved using DE randomization.
- **Step 5 (SA)**: Uses local perturbations with decreasing temperature schedule to escape local minima.

### Key Numerical Choices
- n_points = 100 (smaller grid allows faster running times)
- Binary skeleton = 10-15 steps
- DE population size = 50
- SA iterations = 10000
- Floor of worst shifts = 5-10

### Time Budget Considerations
- Measure time explicitly in each phase
- Early stopping if improvement stalls
- Prioritize phases that provide decrease in C₅

### Failure Modes and Mitigation
- MILP may fail if variables are unbounded or network is complex
- Worst-shift search might miss the true worst case
- DE might converge to same local solution repeatedly
- SA cannot decrease temperature too fast or risk random walk

### Why This Is Different From Previous Work
The logical difference is in combining discrete combinatorial optimization (MILP) with targeted numerical optimization, rather than relying purely on gradient methods or heuristic-based search. It is most different in fractionating the problem into automated discrete-to-continuous transformations. This makes a global structure more likely to be preserved as the numerical part is specifically crafted to optimize around it.

def compute_corr_fft(h):
    """Compute correlation using FFT"""
    h_rev = h[::-1]
    b = 1 - h
    L = 2 * len(h) - 1
    corr = np.fft.ifft(np.fft.fft(h_rev, L) * np.fft.fft(b, L)).real
    return corr

def c5_from_corr(corr, n):
    """Convert correlation result to C5 value"""
    return np.max(corr)

def evaluate_c5(h):
    """Fast evaluation of C5 using FFT"""
    corr = compute_corr_fft(h)
    return c5_from_corr(corr, len(h))

def project_to_sum_box(x, target_sum):
    """Project vector x onto box constraints [0,1] with sum = target_sum"""
    def f(lam):
        projected = np.clip(x + lam, 0, 1)
        return np.sum(projected) - target_sum

    a, b = -1.0, 1.0
    while f(a) * f(b) > 0:
        a -= 0.1
        b += 0.1
    
    # Binary search
    tol = 1e-10
    for _ in range(50):
        m = (a + b) / 2
        fm = f(m)
        if abs(fm) < tol:
            break
        if fm * f(a) < 0:
            b = m
        else:
            a = m
    
    result = np.clip(x + (a + b)/2, 0, 1)
    return result

def fast_worst_shifts(h, k=10):
    """Return indices and values of the k worst shifts (largest correlations)"""
    corr = compute_corr_fft(h)

    return res.x

def iteratively_improve_skeleton(skel_locs_initial, n_points=100, max_iter=10):
    """Improve skeleton by replacing worst shift locations."""
    dx = 2.0 / n_points

    best_c5 = float('inf')
    best_h = None
    
    for iteration in range(max_iter):
        h = np.zeros(n_points)

            if left < n_points - 1:
                right = left + 1
                weight = (loc - left * dx) / dx
                h[left] += 1 * (1 - weight)
                h[right] += 1 * weight
            else:
                h[-1] += 1
        
        # Now optimize shape for skeleton

        h_final = np.zeros(n_points)

                weight = (loc - left * dx) / dx

                h_final[-1] += height

        skel_locs = new_locs
