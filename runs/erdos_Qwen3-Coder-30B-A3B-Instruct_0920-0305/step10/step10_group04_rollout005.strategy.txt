**Goal** – Produce a step‑function `h` on `[0,2]` (discretised with `n` points) that satisfies

### 1.  Problem reformulation

For a **binary** vector `x∈{0,1}ⁿ` with exactly `n/2` ones (so the integral constraint is satisfied automatically) the correlation simplifies to  

```
corr(d) = Σ_{i=0}^{n‑1‑d} x[i]·(1‑x[i+d])      for d≥0
corr(-d)= Σ_{i=0}^{n‑1‑d} x[i+d]·(1‑x[i])      for d>0
```

Since `Σ_i x[i] = n/2` is constant,  

```
corr(d) =  (n/2 – Σ_{i} x[i]·x[i+d])   (for d≥0)
```

Thus **minimising `C5` is equivalent to maximising the *minimal* auto‑correlation**
`S(d) = Σ_i x[i]·x[i+d]` over all non‑zero shifts.  The problem can therefore be tackled as a *max‑min* binary‐sequence optimisation.

A continuous solution can only improve on a binary one, so we first look for a very good binary pattern and then polish it with a smooth optimiser.

### 3.  Fast evaluation of `C5`

```python
def C5_of(h, dx):
    # h is a 1‑D numpy array of floats (or 0/1 ints)
    return np.max(np.correlate(h, 1.0 - h, mode='full')) * dx
```

`np.correlate` is a compiled routine; for `n = 200` a single call costs a few micro‑seconds, allowing **hundreds of thousands** of evaluations inside the time budget.

### 5.  Core optimiser – Simulated‑Annealing on binary vectors

#### 5.1 Move set
* **Basic swap** – Choose two indices `i` and `j` with opposite values (`x[i]=1, x[j]=0`) and exchange them. The sum stays in the feasible set.
* **Targeted swap** – Every few hundred iterations we identify the *worst* shift `d*` (the offset where `corr(d)` is maximal).  
  * `bad_one = { i | i+d* in [0,n) and x[i]=1 and x[i+d*]=0 }` – positions that contribute to the excess.  
  * `bad_zero = { j | j+d* in [0,n) and x[j]=0 and x[j+d*]=1 }`.  
  * Swapping a random element of `bad_one` with a random element of `bad_zero` directly reduces the worst correlation (or leaves it unchanged). If either set is empty we fall back to a random swap.
* **Multi‑swap (optional)** – With a small probability we pick three or four indices and perform a cyclic permutation of their values; this helps the chain jump out of shallow plateaux.

#### 5.2 Acceptance rule
Let `Ccur` be the current `C5` and `Cnew` the value after a proposed swap.

```
Δ = Cnew – Ccur
accept if Δ ≤ 0
else accept with probability exp( –Δ / T )
```

`T` is a temperature that is **decreased linearly** from an initial value `T0` to a final value `T_end` over the allocated number of Monte‑Carlo steps. Empirically good values are

```
T0 = 0.02   (about 2 % of a typical C5)
T_end = 1e‑6
```

The linear schedule gives a high acceptance rate early on (exploration) and becomes greedy later (exploitation).

#### 5.3 Iteration budget & time control
* **Total SA time:** ≈ 0.75 × budget (≈ 450 s).  
* Inside the loop we constantly check `time.time() – start`. As soon as the SA time slice is exhausted we break out of the loop, keeping the *best* binary vector encountered (`best_h_bin`, `best_C5_bin`).

#### 5.4 Book‑keeping
* Keep `cur_h` (current vector) and `cur_C5`.  
* Keep `best_h_bin` and `best_C5_bin`. Whenever `cur_C5 < best_C5_bin` we copy `cur_h`.  
* No explicit feasibility projection is needed – swaps preserve the box constraints and the exact count of ones.

### 6.  Escape from stagnation

If after a large number of iterations (`no_improve > 20000`) the best value has not improved, we **perturb** the current state:

* Randomly select `p %` of the positions (e.g. `p = 5 %`) and re‑assign them to random 0/1 while keeping the global count `n/2`.  
* Reset the temperature to a fraction of `T0` (e.g. `0.5·T0`) and continue.  

This restart strategy prevents the chain from being trapped in a deep local minimum.

### 7.  Projection onto the continuous feasible set

After SA we have a binary vector. To feed a gradient‑based optimiser we must allow fractional values while still obeying:

```
0 ≤ h[i] ≤ 1
∑ h[i] = n/2   (i.e. integral = 1)
```

A fast projection is:

1. **Clip** the vector to `[0,1]`.  
2. Compute the current sum `s`.  
3. Find a scalar `λ` such that `∑ clip(v_i + λ, 0, 1) = n/2`.  
   This is a one‑dimensional root‑finding problem; a binary search on `λ` converges in < 50 iterations.  

The resulting vector is the Euclidean projection onto the box intersected with the affine hyperplane.

### 8.  Continuous polishing – SLSQP

We now treat the problem as a smooth constrained optimisation:

* **Variables:** `h ∈ ℝⁿ`.  
* **Objective:** `C5_of(h) = dx * max( np.correlate( h , 1‑h , mode='full' ) )`.  
  The function is continuous but non‑smooth (max of linear forms). `scipy.optimize.minimize` with method **'SLSQP'** handles such non‑smoothness by using finite‑difference subgradients.
* **Constraints:**  
  * Equality: `∑ h[i] = n/2`.  
  * Bounds: `0 ≤ h[i] ≤ 1` (provided to the optimiser).  
* **Initial point:** the projected version of `best_h_bin`.  
* **Options:**  
  * `maxiter = 2000` (enough for convergence within the remaining time).  
  * Tight tolerances: `ftol = 1e‑12`, `gtol = 1e‑12`.  
  * Use the default line‑search; the cost of each objective evaluation is cheap.

After optimisation we **re‑project** the solution onto the feasible set (step 7) to eliminate any tiny numerical drift and recompute the final `C5`.
