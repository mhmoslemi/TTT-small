<h2>Binary MILP with Skeleton-based Optimization</h2>

<h3>Mathematical Approach</h3>
<ul>
<li>Model the problem as a mixed-integer linear program (MILP) with binary variables.</li>
<li>Use a skeleton of the function to guide the search for optimal shape.</li>
<li>Formulate overlap integral as a linear objective over binary variables.</li>
<li>Employ piecewise linear approximations to handle nonlinearity.</li>
</ul>

<h3>Algorithm Structure</h3>
<ol>
<li>Define binary decision variables to represent function shape at key points.</li>
<li>Model constraints using linear inequalities for box constraints and integral constraint.</li>
<li>Encode overlap integral using mixed-integer constraints to compute maximum correlation.</li>
<li>Solve relaxed linear program (LP) to get continuous solution, then round to binary.</li>
<li>Use 2-opt style worst-shift local search on binary skeleton to improve solution.</li>
<li>Refine solution using gradient-free optimization (Differential Evolution).</li>
</ol>

<h3>Implementation Components</h3>
<ul>
<li>Binary MILP solver with CBC backend (through cvxpy).</li>
<li>Parametric shape sampling (step function with variable positions).</li>
<li>Worst-shift local search to swap in/out binary positions.</li>
<li>Differential Evolution for continuous refinement of shape.</li>
<li>Time-boundened execution with strategy hierarchy.</li>
</ul>

<h3>Numerical Choices</h3>
<ul>
<li>Use n_points = 120 discretization.</li>
<li>Define binary skeleton with ~15-20 key points instead of full 120.</li>
<li>Use Differential Evolution with population size 50, mutation F=0.8.</li>
<li>Apply early stopping when C5 improvement below 1e-5 for 500 iterations.</li>
</ul>

<h3>Potential Failure Modes</h3>
<ul>
<li>Excessive branching in MILP could lead to infeasibility or long solve times.</li>
<li>Binary rounding may not generate feasible continuous solutions.</li>
<li>Worst-shift search might converge to a poor local optimum due to fixed neighborhoods.</li>
<li>DE may struggle with high dimensionality of 120 variables without dimensionality reduction.</li>
</ul>
</strategy>



```python
import numpy as np
from scipy.signal import correlate
from scipy.optimize import differential_evolution
import time
import cvxpy as cp

# Global variables
TARGET_SUM = None
n_points = 120
dx = 2.0 / n_points
MAX_ITER = 1000

def compute_corr_fft(h):
    """Compute correlation using FFT"""
    h_rev = h[::-1]
    b = 1 - h
    L = 2 * len(h) - 1
    corr = np.fft.ifft(np.fft.fft(h_rev, L) * np.fft.fft(b, L)).real
    return corr

def c5_from_corr(corr, n):
    """Convert correlation result to C5 value"""
    return dx * np.max(corr)

def evaluate_c5(h):
    """Fast evaluation of C5 using FFT"""
    corr = compute_corr_fft(h)
    return c5_from_corr(corr, n_points)

def project_to_sum_box(x, target_sum):
    """Project vector x onto box constraints [0,1] with sum = target_sum"""
    # Binary search for lambda: find lambda such that sum(clamp(x+lambda, 0, 1)) = target_sum
    def f(lam):
        projected = np.clip(x + lam, 0, 1)
        return np.sum(projected) - target_sum

    a, b = -1.0, 1.0
    while f(a) * f(b) > 0:
        a -= 0.1
        b += 0.1
    
    # Binary search
    tol = 1e-10
    for _ in range(50):
        m = (a + b) / 2
        fm = f(m)
        if abs(fm) < tol:
            break
        if fm * f(a) < 0:
            b = m
        else:
            a = m
    
    result = np.clip(x + (a + b)/2, 0, 1)
    return result

def binary_milp_initialization():
    """Initialize solution using MILP with binary variables for a skeleton"""
    # We'll use a coarser representation (e.g., 10 points)
    n_skeleton = 12  # reduced skeleton
    # Variables for binary decision
    x = cp.Variable(n_skeleton, boolean=True)
    # Objective to minimize C5 over binary variables (this is simplified)
    # We will instead compute a rough approximation and start from it
    return np.random.rand(n_skeleton) > 0.5

def worst_shift_local_search(h0, max_iter=2000):
    """Worst-shift local search on bitstring"""
    current_h = h0.copy()
    current_c5 = evaluate_c5(current_h)
    best_h = current_h.copy()
    best_c5 = current_c5
    
    for _ in range(max_iter):
        # Find the index k with the worst (highest) correlation value
        corr = compute_corr_fft(current_h)
        k_worst = np.argmax(corr)
        # Try moving the function to reduce worst correlation by one index shift
        # Generate neighbor solutions by flipping one bit
        mask = np.zeros_like(current_h)
        best_flip = None
        best_improvement = 0
        
        for i in range(len(current_h)):
            new_h = current_h.copy()
            new_h[i] = 1 - new_h[i]  # flip bit
            new_h = project_to_sum_box(new_h, TARGET_SUM)
            new_c5 = evaluate_c5(new_h)
            improvement = current_c5 - new_c5
            if improvement > best_improvement:
                best_improvement = improvement
                best_flip = i
                
        if best_flip is not None:
            current_h[best_flip] = 1 - current_h[best_flip]
            current_h = project_to_sum_box(current_h, TARGET_SUM)
            current_c5 = evaluate_c5(current_h)
            if current_c5 < best_c5:
                best_h = current_h.copy()
                best_c5 = current_c5
        else:
            break
            
    return best_h, best_c5

def parametric_step_function_search(x_init):
    """Refine step-function interpolation"""
    # Interpolate between skeleton points
    def interpolate_step(h_skel):
        h_full = np.zeros(n_points)
        # Distribute the skeleton points to full resolution
        step = n_points // len(h_skel)
        for i in range(len(h_skel)):
            start = i * step
            end = start + step if i < len(h_skel) - 1 else n_points
            h_full[start:end] = h_skel[i]
        return h_full
    
    initial_h = project_to_sum_box(interpolate_step(x_init), TARGET_SUM)
    return initial_h

def differential_evolution_refinement(h0):
    """Use DE to polish continuous shape"""
    def objective(x):
        h = project_to_sum_box(x, TARGET_SUM)
        return evaluate_c5(h)
    
    bounds = [(0, 1) for _ in range(n_points)]
    
    # Use differential evolution with higher exploration
    res = differential_evolution(objective, bounds, seed=42, maxiter=500, 
                                 popsize=50, mutation=(0.5, 1.0), recombination=0.7,
                                 disp=False)
    
    h_final = project_to_sum_box(res.x, TARGET_SUM)
    return h_final, evaluate_c5(h_final)

def run(seed=42, budget_s=600, **kwargs):
    global TARGET_SUM, n_points, dx
    np.random.seed(seed)
    start_time = time.time()
    
    TARGET_SUM = n_points / 2
    
    # Strategy 1: Initialize with parametric step function
    x_skel = binary_milp_initialization()
    h0 = parametric_step_function_search(x_skel)
    best_h = h0.copy()
    best_c5 = evaluate_c5(h0)
    
    # Strategy 2: Worst-shift local search
    if time.time() - start_time < budget_s * 0.4:
        h_local, c5_local = worst_shift_local_search(h0, 500)
        if c5_local < best_c5:
            best_h = h_local
            best_c5 = c5_local
    
    # Strategy 3: Differential Evolution refinement
    if time.time() - start_time < budget_s * 0.8:
        h_de, c5_de = differential_evolution_refinement(best_h)
        if c5_de < best_c5:
            best_h = h_de
            best_c5 = c5_de
    
    # Strategy 4: Another local search
    if time.time() - start_time < budget_s * 0.95:
        h_local2, c5_local2 = worst_shift_local_search(best_h, 1000)
        if c5_local2 < best_c5:
            best_h = h_local2
            best_c5 = c5_local2
    
    # Final DE if time remains
    if time.time() - start_time < budget_s:
        h_final, c5_final = differential_evolution_refinement(best_h)
        if c5_final < best_c5:
            best_h = h_final
            best_c5 = c5_final

    return (best_h.tolist(), float(best_c5), n_points)
```
