**Overall idea – a two‑stage construction followed by continuous refinement**  
The new algorithm starts from a *deterministic, number‑theoretic family* of binary step functions that automatically satisfies the integral constraint.  
From this small, well‑structured search space we pick the best candidate and then improve it with a series of discrete hill–climbing moves, a smoothing operation, and a gradient‑descent on a smooth surrogate of the max‑overlap objective.  Finally we polish the result with a small SLSQP solve.  This pipeline is completely different from the previous random‑perturbation / SLSQP loop.

---

### 1. Discretisation and basic notation
* Choose a modest resolution `N` (default `N = 120`; other even values such as 96 or 108 may be tried later).  
* Step size `dx = 2.0 / N`.  
* The vector `h[0 … N‑1]` represents `h(x)` sampled uniformly on `[0,2]`.  
* The sum constraint is `∑_i h[i] = N/2` (because `dx·∑h = 1`).  

All correlation calculations are performed with FFT‑based convolution for speed:  
`O_k = Σ_i h[i]·(1−h[(i+k) mod N])` for each lag `k = 0 … N‑1`.  
The objective is `C5 = dx·max_k O_k`.

---

### 2. Exhaustive search in a *modular Beatty* family  

#### 2.1. Construction of binary candidates  
For any integer multiplier `a` coprime with `N` and any offset `b` in `{0,…,N‑1}` define  

```
h_i(a,b) = 1   if ((a·i + b) mod N) < N/2
          0   otherwise
```

Because multiplication by a unit modulo `N` permutes the residues, exactly `N/2` indices satisfy the inequality, so the sum constraint holds automatically.  

*The family is exhaustive over all linear–congruential permutations, providing `φ(N)·N` distinct binary vectors (≈ 3‑4 k for `N = 120`).*

#### 2.2. Evaluation  
For every pair `(a,b)` compute the correlation via FFT, obtain `C5(a,b)`, and keep the best (smallest) value together with the generating parameters.  
The whole enumeration takes only a few seconds.

#### 2.3. Optional irrational‑slope variants  
To enlarge the candidate pool we also evaluate the “Sturmian” sequences  

```
h_i(α) = 1   if frac(i·α) < 0.5
          0   otherwise
```

where `α` is a rational approximation of an irrational (e.g. the golden ratio) with denominator ≤ N.  
These are generated in the same way (by taking `a = numerator`, `b = 0`) and are already covered by the modular family, but testing them explicitly guarantees we explore the most symmetric cases.

### 3. Discrete local improvement (binary hill‑climbing)

Take the best binary vector `h⁰` from step 2 as the start.

**Loop (until time budget exhausted or no improvement for a while):**

1. Compute the lag `k* = argmax_k O_k`.  
2. Let `I₁ = { i | h[i]=1, h[(i+k*) mod N]=0 }` (positions where a 1 contributes to the worst overlap).  
   Let `J₀ = { j | h[j]=0, h[(j+k*) mod N]=1 }` (complementary zeros).  
3. For each pair `(i,j) ∈ I₁ × J₀` compute the *exact* change ΔO_{k*} when swapping `h[i]↔h[j]`.  
   Because the overlap is linear in each variable, ΔO_{k*} = −(1−h[(i‑k*)])−(1−h[(j‑k*)]) + (1−h[(i+k*)])+(1−h[(j+k*)])` (indices taken modulo N).  
4. Choose the swap with the largest reduction of `O_{k*}` (or overall `max_k O_k`).  
5. Apply the swap, recompute the correlation (FFT) and update `h`.  
6. If no improving swap exists, perform a *random* 1‑0 swap with probability `p = 0.1·exp(−t/τ)` (simulated‑annealing style) to escape plateaus.

Maintain the best ever vector `h_best` and its `C5_best`.  
The hill‑climbing typically reduces `C5` by a few percent over the pure modular solution.

---

### 4. Smoothing of step edges (introducing fractional values)

The binary function is a piecewise‑constant step.  Small linear ramps at each transition often lower the maximal overlap because they reduce the product `h·(1−h_shifted)` where the two steps partially overlap.

**Procedure:**

1. Detect every index `i` where `h[i] ≠ h[i+1]` (mod N).  
2. For a chosen radius `R` (e.g. `R = 2` samples) replace the block `h[i−R … i+R+1]` by a linear interpolation from the left value to the right value (incl. endpoints).  
   After processing all boundaries we obtain a *continuous* vector `h̃` with values in `[0,1]`.  
3. Compute the current sum `S = Σ h̃`.  
4. Enforce the exact sum constraint by adding a uniform offset `δ = (N/2 – S)/N` to all entries, then clip to `[0,1]`.  
   If clipping violates the sum, perform a single projection onto the intersection of the box and the hyperplane (the same "lambda‑projection" used before).  

The smoothed `h̃` serves as a new starting point for a gradient‑based phase.

---

### 5. Gradient descent on a *smooth surrogate* of the max‑overlap

Directly minimizing `max_k O_k` is non‑smooth.  Replace it by the **log‑sum‑exp** approximation  

```
S(h) = (1/α)·log( Σ_k exp( α·O_k(h) ) )
```

where a moderate temperature `α ≈ 10` gives a tight upper bound and a differentiable objective.

**Gradient computation (exact, vectorised):**

* For each lag `k` we already have `O_k`.  
* Compute weights `w_k = exp(α·O_k) / Σ_j exp(α·O_j)`.  
* The derivative of `O_k` w.r.t. `h_j` is  

```
∂O_k/∂h_j = 1 - h_{j+k} - h_{j−k}
```

(indices modulo N, missing terms omitted at boundaries).  
* Hence  

```
∂S/∂h_j = Σ_k w_k·(1 - h_{j+k} - h_{j−k})
```

**Descent loop (≤ 150 iterations or until time runs out):**

1. Compute `O_k`, `S`, and the gradient `g`.  
2. Update `h ← h − η·g` with a stepsize `η` that starts at `0.05` and is multiplied by `0.95` each iteration.  
3. Project onto the feasible set: clip to `[0,1]` then apply the lambda‑projection to enforce `Σ h = N/2`.  
4. Evaluate the *true* `C5` with the original max‑overlap formula; keep the best vector seen.  

Because the surrogate tightly tracks the maximum, the descent quickly reduces `C5`.  The whole phase consumes the bulk of the remaining time budget (≈ 200 s).

### 6. Final polishing with a *linear‑epigraph* SLSQP

To guarantee that the final answer respects the exact objective, solve the following small nonlinear program:

*Variables:* `h[0…N‑1]` (continuous) and scalar `M`.  

*Constraints:*  
  * `0 ≤ h_i ≤ 1` for all `i`.  
  * `Σ_i h_i = N/2`.  
  * For every lag `k`: `O_k(h) ≤ M`, where `O_k(h) = Σ_i h_i·(1−h_{i+k})`.  

*Objective:* minimize `M`.  

All `O_k(h)` are linear in the products `h_i·h_{i+k}`; we linearise them by introducing auxiliary variables `w_{i,k}` with the usual McCormick constraints  

```
w_{i,k} ≤ h_i
w_{i,k} ≤ h_{i+k}
w_{i,k} ≥ h_i + h_{i+k} - 1
w_{i,k} ≥ 0
```

and replace `h_i·h_{i+k}` by `w_{i,k}` inside `O_k`.  
The problem becomes a mixed‑linear program with a modest number of variables (`≈ N·(N−1)/2` ≈ 7 k for `N=120`), which SLSQP can handle because the constraints are linear except for the simple box and equality.  

We start SLSQP from the best continuous vector obtained in step 5, set a modest iteration limit (500), and a tight tolerance (`ftol=1e‑10`).  If the solver fails to converge before the overall time limit, we simply return the best vector found so far.

### 8. Failure‑mode handling

* **Modular enumeration yields no improvement:** fall back to a random balanced binary vector and start hill‑climbing from there.  
* **Hill‑climbing stalls:** after a pre‑defined number of iterations without improvement, perform a *restart* by re‑initialising `h` from a different `(a,b)` pair (next‑best modular candidate).  
* **Projection fails (all entries at bounds):** perform a simple scaling of the free entries before clipping.  
* **Gradient overflow in the exp‑sum:** compute `exp(α·(O_k − max_O))` to keep values in a safe range.  
* **SLSQP does not converge:** keep the last feasible iterate; if any constraint is violated, apply a final projection onto the feasible box + sum hyperplane.
