**1.  Reformulate the objective as a mixed‑integer optimisation**

The integral constraint forces the average value of the step function to be ½, i.e.

\[
\sum_{i=0}^{N-1}h_i = \frac{N}{2},
\qquad N=n_{\text{points}}.
\]

If we restrict the decision variables to the binary set \(\{0,1\}\) the function becomes a characteristic function of a measurable set of measure 1.  
For a binary vector the overlap for a shift \(k\) is

\[
c_k = \sum_{i=0}^{N-1} h_i\bigl(1-h_{i+k}\bigr)
      = \frac{N}{2} - \sum_{i=0}^{N-1} h_i h_{i+k},
\]

where \(h_{i+k}=0\) when the index lies outside \([0,N-1]\).  
Consequently the quantity to be minimised is

\[
\max_{k}c_k
 = \frac{N}{2} - \min_{k}\;\underbrace{\sum_{i}h_i h_{i+k}}_{\displaystyle a_k}.
\]

Thus the problem can be cast as a **mixed‑integer quadratically‑constrained program (MIQCP)**:

*binary variables* \(h_i\in\{0,1\}\) \(i=0,\dots ,N-1\)  
*auxiliary product variables* \(y_{i,k}\in\{0,1\}\) representing \(h_i h_{i+k}\) for every overlap pair \((i,k)\).  
*linear constraints* for each product (McCormick‐exact for binaries)

\[
\begin{aligned}
y_{i,k} &\le h_i,\\
y_{i,k} &\le h_{i+k},\\
y_{i,k} &\ge h_i + h_{i+k} - 1 .
\end{aligned}
\]

Define for every shift \(k\)

\[
a_k = \sum_{i} y_{i,k},
\qquad
c_k = \frac{N}{2} - a_k .
\]

Introduce a scalar variable \(t\) that dominates all overlaps:

\[
t \;\ge\; c_k\quad\forall\,k .
\]

The optimisation model is

\[
\min_{h,y,t}\; t
\;\text{s.t.}\;
\sum_i h_i = \frac{N}{2},\;
0\le h_i\le1,\;
y_{i,k}\in\{0,1\},\;
\text{product constraints above},\;
t\ge \frac{N}{2} - a_k\;\forall k .
\]

All constraints are linear; the only non‑linearities have been eliminated by the auxiliary binaries \(y_{i,k}\).  The model is a pure **MILP**.
