\[
C_5=\max_k\int_0^2h(x)\bigl(1-h(x+k)\bigr)\,dx
    =1-\min_k\int_0^2h(x)h(x+k)\,dx .
\]

Hence the problem is equivalent to **maximising the minimum aperiodic autocorrelation** of h.

* Use an even number of points for symmetry – e.g. `n = 200` (dx = 0.01).

  ```
  h_full = concatenate( h_half , h_half[::-1] )
  ```

  This guarantees a perfectly symmetric candidate and halves the dimensionality of all optimisation steps.

* The sum constraint on the half‑vector is exact:  

  \[
  \sum_{i=0}^{m-1} h_i = \frac{1}{2}\sum_{i=0}^{n-1}h_i = \frac{n}{4}.
  \]

  Let `target_sum = n/4`.

### 2. Fast evaluation of the objective  

* **Autocorrelation** of the full vector gives the quantity we need:  

  \[
  A_k = \sum_{i} h_i\,h_{i+k}\quad (k = -(n-1)\dots n-1).

* Compute `A` with a single FFT per evaluation:  

  1. Reverse `h_full` → `h_rev`.  
  2. Pad both `h_rev` and `h_full` to length `L = 2*n‑1`.  
  3. `A = ifft( fft(h_rev,L) * fft(h_full,L) ).real`.  

* The **minimum autocorrelation** is `amin = min(A)`.  
* The C₅ value is then  

  ```
  C5 = 1 - dx * amin
  ```

### 4. Smooth surrogate for the max‑operator (to obtain a gradient)

The exact objective `C5 = 1 - dx * min(A)` is non‑differentiable at the “worst” shift. Replace the `min` with a **log‑sum‑exp** (LSE) smoothing:

\[
\tilde{C}_5(\beta) = 1 - \frac{dx}{\beta}\,
\log\Bigl(\sum_{k} e^{\beta\,A_k}\Bigr) .
\]

* As `β → +∞`, `\tilde{C}_5 → C5`.  
* Choose a moderate `β` (e.g. 50–100) from a short pilot test – this provides a smooth landscape while still penalising the smallest autocorrelation heavily.

**Gradient** (with respect to the full vector `h`) is:

\[
\frac{\partial \tilde{C}_5}{\partial h_i}
= -dx\,
\frac{\sum_k e^{\beta A_k}\,\partial A_k/\partial h_i}
     {\sum_k e^{\beta A_k}} .
\]

Since  

\[
\frac{\partial A_k}{\partial h_i}
= h_{i+k} + h_{i-k}   \qquad(\text{zero‑padded outside the interval}),
\]

the whole gradient can be obtained **by two convolutions**:

1. Compute the weight vector `w_k = e^{β A_k}`.  
2. Convolve `w` with the reversed `h` to obtain the numerator for each index.  
3. Divide by the sum of `w` and multiply by `-dx`.

All convolutions are performed with FFT, which is cheap for `n ≤ 300`.

Using this gradient we can run **projected L‑BFGS‑B** on the *full* half‑vector (`m` variables) while keeping the box constraints `[0,1]` and the sum constraint (enforced by a simple projection after each L‑BFGS step).
