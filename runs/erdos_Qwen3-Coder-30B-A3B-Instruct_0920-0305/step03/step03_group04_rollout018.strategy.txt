### 2.  Mathematical reformulation  

#### 2.1 Discretisation  
Choose an even grid size `n` (e.g. `n ∈ {36, 42, 48, 54, 60}`).  
`dx = 2 / n`.  
The decision vector `h ∈ [0,1]^n` must satisfy  

```
∑_{i=0}^{n-1} h_i = n/2                     (mass constraint)
```

For a shift `k (0 ≤ k ≤ n‑1)` the discrete overlap is  

```
C(k) = dx * Σ_{i=0}^{n-1‑k} h_i (1 – h_{i+k})
     = dx * ( Σ_{i=0}^{n-1‑k} h_i – Σ_{i=0}^{n-1‑k} h_i h_{i+k} )
```

Define binary variables `x_i ∈ {0,1}` for the *characteristic‑function* case; later we will relax them to `[0,1]`.  
Introduce matrix `X = xxᵀ`.  The quadratic term `h_i h_{i+k}` becomes the linear entry `X_{i,i+k}`.

#### 2.2 SDP (convex) formulation  

Variables  

```
x ∈ ℝ^n          (relaxed indicators)
X ∈ ℝ^{n×n}     (symmetric, PSD)
t ∈ ℝ           (upper bound on all C(k)/dx)
```

Constraints  

1. **Box and mass**  
   `0 ≤ x ≤ 1` , `Σ x = n/2`.

2. **Diagonal consistency**  
   `diag(X) = x`.

3. **McCormick linearisation of products** (for every i<j)  

```
X_{ij} ≥ 0,
X_{ij} ≤ x_i,
X_{ij} ≤ x_j,
X_{ij} ≥ x_i + x_j – 1 .
```

   When `x` is binary these force `X_{ij}=x_i x_j`.

4. **Overlap constraints** (one per shift)  

```
Σ_{i=0}^{n-1‑k} x_i  –  Σ_{i=0}^{n-1‑k} X_{i,i+k}  ≤  t   for every k = 0,…,n‑1 .
```

5. **Positive semidefiniteness**  
   `X ⪰ 0`.

Objective: `minimise t`.  
Because all constraints are linear (except the PSD cone) and the objective is linear, this is a **semidefinite program**.  Its optimal value `t*` is a *lower bound* on the true minimum `C5`.

#### 3.2 Phase B – Random hyperplane rounding  

From `X̂` we extract a low‑rank factorisation:

```

```

*Rounding loop* (repeat `R = 30` times for each `n`)

1. Sample a Gaussian vector `g ∈ ℝ^r`.  
2. Compute scores `s_i = V[i,:]·g`.

5. Evaluate the exact `C5` of the resulting binary vector `h_tmp` using the correlation formula.  
6. Keep the best among the `R` candidates as `h_binary⁰`.
