**1. Re‑interpret the mathematical objective**

The quantity to minimise is  

\[
C_5=\max_{k\in[0,2]}\int_0^2 h(x)\bigl(1-h(x+k)\bigr)\,dx
      =1-\min_{k\in[0,2]}\int_0^2 h(x)h(x+k)\,dx .
\]

Thus the problem is *maximising* the **minimum autocorrelation**
\[
A(k)=\int_0^2 h(x)h(x+k)\,dx
\]
subject to  
\[
0\le h(x)\le 1,\qquad \int_0^2 h(x)\,dx=1 .
\]

Because the integral is periodic (the shift wraps around the interval,
otherwise the bound would be trivially 1), we will work with **circular**
convolution. In the discrete setting with \(n\) points and \(\Delta x=2/n\),

\[
A_s=\Delta x\sum_{i=0}^{n-1} h_i\,h_{(i+s)\bmod n},
\qquad s=0,\dots ,n-1 .
\]

Our goal is to maximise \(\lambda:=\min_s A_s\); the final bound is   
\(C_5=1-\lambda\).

---

**2. Reduce dimensionality by a symmetric‑monotone parametrisation**

All known extremal constructions are symmetric about the centre of the
interval and non‑increasing away from it.  Enforce this structure
explicitly:

* Use only the first half of the domain, indices \(0,\dots,m\) where
  \(m=\lfloor n/2\rfloor\).
* Let the values on the second half be the mirror of the first half
  (i.e. \(h_{n-i}=h_i\)).
* Impose monotonicity: \(h_0\ge h_1\ge\cdots\ge h_m\).

With this parametrisation only \(m+1\) free variables remain (≈30 for
\(n=60\)).  The integral constraint becomes a simple linear equation
in these variables because the mirror halves contribute equally.

Optionally, further reduce the dimension by representing the half‑profile
as a **piecewise linear spline** with a small number \(K\) of knots
(e.g. \(K=6\)–\(10\)).  Heights at the knots become the optimisation
variables; the values at all grid points are obtained by linear
interpolation, guaranteeing monotonicity automatically if the knot
heights are decreasing.

**3. Formulate a *feasibility* problem via bisection on \(\lambda\)**

Instead of handling the max‑min directly, perform a binary search on the
target value \(\lambda\):

*Given a trial \(\lambda\), ask whether there exists a feasible \(h\)
 such that \(A_s\ge\lambda\) for **all** shifts \(s\).*

If feasible, we can raise \(\lambda\); otherwise we must lower it.
After a few bisection steps we obtain a tight lower bound on
\(\lambda\) and consequently an upper bound on \(C_5\).

**4. Encode the feasibility problem as a **Mixed‑Integer Linear Program (MILP)**  
   using McCormick envelopes for the products \(h_i h_j\).**

For each pair \((i,j)\) that appears in a correlation sum we introduce a
new auxiliary variable
\(y_{ij}\approx h_i h_j\).  With binary or bounded continuous \(h_i\)
the product can be linearised by the classic McCormick inequalities:

\[
\begin{aligned}
y_{ij} &\ge 0,\\
y_{ij} &\le h_i,\\
y_{ij} &\le h_j,\\
y_{ij} &\ge h_i+h_j-1 .
\end{aligned}
\]

Because we have already forced the half‑profile to be monotone and
bounded in \([0,1]\), the above linear relaxation is very tight.
For each shift \(s\) we then write the linear constraint

\[
\sum_{i=0}^{n-1} y_{i,(i+s)\bmod n}\;\ge\;\lambda .
\]

All remaining constraints (box bounds, symmetry, monotonicity,
integral‑sum) are linear.  The MILP has:

* \(O(n)\) original variables (the half‑profile),
* \(O(n^2)\) auxiliary product variables (for \(n=60\) about 3 600,
  still tractable for CBC/GLPK),
* \(n\) correlation constraints.

We solve the MILP with a fast open‑source solver (CBC via CVXPY).  
If the solver reports *feasible*, the current \(\lambda\) is attainable;
otherwise it is not.

Because the MILP is still relatively large, we adopt **two‑phase
tightening**:

1. **Coarse phase** – solve the MILP on a reduced grid, e.g. \(n=30\).
   The resulting feasible \(\lambda\) gives a lower bound for the full
   resolution problem.
2. **Refinement phase** – increase \(n\) to the target size (60–80) and
   start the solver from the interpolated solution of the coarse phase.
   The MILP size grows only quadratically, but the warm‑start dramatically
   reduces solving time.

The bisection loop stops when the interval \([\lambda_{\text{low}},
\lambda_{\text{high}}]\) is smaller than the precision needed to push
\(C_5\) below the target 0.3807 (i.e. \(\Delta\lambda < 0.001\)).

**5. Complementary global search with **Differential Evolution** (DE)**

MILP guarantees a binary‑relaxation solution, but the McCormick
envelopes can be loose if many variables take non‑integral values.
To explore the truly continuous feasible region we run a *population‑based*
global optimiser:

* **Population encoding** – each individual stores the half‑profile
  (the monotone decreasing vector).  After mutation/crossover we project
  the vector onto the feasible set:
  * clip to \([0,1]\),
  * enforce monotonicity by sorting in descending order,
  * rescale to satisfy the integral constraint (multiply by a constant so that the sum equals \(n/2\)).

* **Fitness evaluation** – compute the circular autocorrelation via
  FFT (complexity \(O(n\log n)\)), obtain \(\lambda_{\text{min}}=\min_s A_s\),
  and return the corresponding bound \(C_5=1-\lambda_{\text{min}}\).

* **Selection** – keep the individual with the smallest \(C_5\).  
  DE parameters (population size ≈ 15 × dimension, mutation factor ≈ 0.8,
  crossover probability ≈ 0.9) are chosen to give good exploration while
  remaining cheap (each evaluation is a few microseconds).

* **Hybrid refinement** – after a fixed number of generations (or when
  improvement stalls) take the best individual and run a few iterations
  of a gradient‑based optimiser (L‑BFGS‑B) on the full vector (with the
  same projection step after each gradient step).  This fine‑tunes the
  solution and often pushes the bound a few thousandths lower.

Running DE on the reduced grid first (e.g. \(n=40\)) produces a good
starting profile; we then *lift* it to the final resolution, run DE again
and finish with the local L‑BFGS‑B polish.

**6. Smooth approximation of the “minimum” for gradient‑based methods**

When employing L‑BFGS‑B directly (instead of the projection‑only DE) we
replace the nondifferentiable \(\min_s A_s\) with a *soft‑minimum*:

\[
\tilde\lambda(h)= -\tau\;\log\!\Bigl(\sum_{s=0}^{n-1}
      \exp\!\bigl(-A_s/\tau\bigr)\Bigr) ,
\]

where \(\tau>0\) controls the tightness of the approximation.
For \(\tau\) as low as \(10^{-3}\) the soft‑minimum is practically the
true minimum, yet the gradient
\(\partial \tilde\lambda/\partial h_i = 
   \sum_s w_s\,(h_{i+s}+h_{i-s})\) with
\(w_s\propto\exp(-A_s/\tau)\) can be computed efficiently
by first evaluating all \(A_s\) (FFT) and then forming the weighted
sum (also via FFT).  The bound to be minimised is \(C_5=1-\tilde\lambda\).

The optimiser respects the box constraints automatically (L‑BFGS‑B),
while the equality constraint \(\sum h_i = n/2\) is handled by a
simple *affine projection*: after each gradient step subtract the mean
offset so that the sum is restored.

We schedule a decreasing \(\tau\) (e.g. halve every 50 iterations) so
that the algorithm first explores a smooth landscape and then refines
the exact min‑criterion.
