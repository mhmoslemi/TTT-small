**1.  What we are really optimizing**

For a step function \(h\) sampled on a uniform grid \(x_i=i\Delta x\)  (\(\Delta x=2/n\))  

\[
C_5(h)=\max_{k}\;c_k(h),\qquad
c_k(h)=\int_0^2 h(x)\bigl(1-h(x+k)\bigr)\,dx
      =\underbrace{\int_0^2 h(x)\,dx}_{=1}
       -\int_0^2h(x)h(x+k)\,dx .
\]

Because the first term is constant, *minimising* \(C_5\) is equivalent to *maximising the minimal autocorrelation*  

\[
p_k(h)=\int_0^2h(x)h(x+k)\,dx .
\]

The difficulty is that \(p_k\) is a **quadratic** functional of the vector \(h\) and we must minimise the **maximum** over all integer shifts \(k\).  The problem is non‑convex and non‑smooth.

--------------------------------------------------------------------
**2.  Discretisation and basic data structures**

* Choose \(n=200\) (Δx = 0.01).  This gives a good trade‑off: the correlation matrix has size \(200\times200\) (≈ 40 k multiplications) – cheap to evaluate many times – while still providing a fine enough description that the continuous bound improves noticeably.
* Store \(h\) as a 1‑D NumPy array `h[0…n‑1]`.  Correlation for a shift \(s\) (positive integer) is

  \[
  p_s(h)=\sum_{i=0}^{n-1-s}h_i\,h_{i+s}\;\Delta x .
  \]

  The overlap for the same shift is \(c_s=1-p_s\).

--------------------------------------------------------------------
**3.  A *smooth* surrogate for the max‑operator**

Directly minimising \(\max_s c_s\) is hard because the max is non‑differentiable.  
Replace it by the **log‑sum‑exp** (LSE) smoothing:

\[
F_\beta(h)=\frac{1}{\beta}\log\Bigl(\sum_{s=1}^{n-1}
           \exp\bigl(\beta\,c_s(h)\bigr)\Bigr),\qquad \beta>0 .
\]

* For small \(\beta\) the function is very smooth (essentially the average of the \(c_s\)).  
* As \(\beta\to\infty\) the LSE converges to \(\max_s c_s\).

**Gradient of the surrogate**  
Let  

\[
w_s(h)=\frac{\exp(\beta c_s)}{\sum_{t}\exp(\beta c_t)} .
\]

Then  

\[
\nabla F_\beta(h)=\sum_{s} w_s(h)\,\nabla c_s(h) .
\]

For a given shift \(s\) the partial derivative with respect to component \(h_i\) is

\[
\frac{\partial c_s}{\partial h_i}= (1-h_{i+s})\mathbf 1_{i+s<n}
                                   -h_{i-s}\mathbf 1_{i-s\ge0},
\]

where the indicator functions enforce the zero‑padding outside the interval.
All gradients can be assembled in **\(O(n)\) time** for a fixed \(s\) and the full
\(\nabla F_\beta\) is obtained by a weighted sum over the shifts.

--------------------------------------------------------------------
**4.  Enforcing the constraints**

*Box constraints* \(0\le h_i\le 1\) are handled directly by a box‑constrained optimizer (L‑BFGS‑B).  

*Integral constraint* \(\sum_i h_i\Delta x =1\) is linear.  Two simple ways to keep it satisfied:

1. **Variable elimination** – keep the first \(n-1\) components free and define  

   \[
   h_{n-1}= \frac{1}{\Delta x}-\sum_{i=0}^{n-2}h_i .
   \]

   The optimizer works on the reduced vector; after each step we clip the last component to \([0,1]\).  If it hits a bound we discard the step and retry with a smaller line‑search step.

2. **Augmented‑Lagrangian penalty** – add the term  

   \[
   \lambda\bigl(\sum_i h_i\Delta x-1\bigr)^2
   \]

   to the objective, with a modest \(\lambda\) (e.g. \(10^3\)).  The penalty drives the iterates back to the hyperplane while still allowing the L‑BFGS‑B routine to treat the problem as bound‑only.

   In practice the first method is cheaper and fully eliminates drift.

**6.  From a continuous to a binary step function**

The continuous optimum often contains many entries close to 0 or 1; a binary version usually gives a comparable (sometimes better) max‑overlap because it removes “mixed” regions that dilute the autocorrelation.

**6.1  Probabilistic rounding**

* Sort the indices by descending \(h_i\).  
* Set the first \(n/2\) entries to 1, the rest to 0 – this is the deterministic *threshold* rounding.
* To avoid getting stuck in a poor binary configuration, repeat the following 30 times:  
  – Sample a random permutation of the indices.  
  – Walk through the permutation, assigning a 1 with probability proportional to the current \(h_i\) while preserving the total count \(n/2\).  
  – Keep the binary vector with the smallest max‑overlap.

**6.2  Swap‑based local improvement (exact combinatorial hill‑climbing)**

Let \(b\) be a binary vector (weight \(n/2\)) and let  

\[
S_s = \sum_{i=0}^{n-1-s} b_i b_{i+s}
\]

be the overlap counts for each shift \(s\).  
The current objective is  

\[
C(b)=\max_s \bigl(1-S_s\Delta x\bigr).
\]

When swapping a 1 at position \(i\) with a 0 at position \(j\) only the terms involving \(i\) or \(j\) change.  For every shift \(s\) we can update the two contributions in **O(1)**:

```
ΔS_s =   ( b_j * b_{j+s} - b_i * b_{i+s} )
       + ( b_{j-s} * b_j    - b_{i-s} * b_i   )
```

(terms with out‑of‑range indices are omitted).  
Hence the new maximal overlap after a trial swap can be evaluated by scanning all shifts (O(n)) while keeping a running best improvement.

**Swap loop**

```
repeat
    best_gain = 0
    for a random sample of O(0.1% ) of (i,j) pairs:
         compute ΔC (max‑overlap change) using the O(n) update
         if ΔC < best_gain: store (i,j) as best_swap
    if best_gain < 0:
         perform best_swap, update all S_s in O(n)
    else:
         break   # local optimum
```

Because each successful swap strictly reduces the objective, the loop terminates quickly (usually < 30 swaps).  To escape a shallow local optimum we can occasionally *shake* the solution: randomly re‑assign 3–5 pairs and resume the swap loop.

The final binary vector \(b^\*\) is converted back to a float array (0.0/1.0) for output.

**7.  Optional exact MILP refinement (if time remains)**

If after the binary local search there is still a few seconds left, formulate the **binary problem** as an integer linear program and hand it to the open‑source CBC solver via CVXPY.

**Variables**

* \(h_i \in \{0,1\}\) (binary step values).  
* \(w_{i,s}\in\{0,1\}\) for every feasible pair \((i,s)\) with \(0\le i,i+s<n\).  Intended to enforce \(w_{i,s}=h_i h_{i+s}\).  
* A scalar \(C\ge0\) representing the worst overlap *in sample‑units*.

**Constraints**

1. **Weight** \(\sum_i h_i = n/2\).  
2. **AND linearisation** \(w_{i,s}\le h_i,\; w_{i,s}\le h_{i+s},\; w_{i,s}\ge h_i+h_{i+s}-1\).  
3. **Overlap bound** for each shift \(s\ge1\):  

   \[
   \underbrace{\frac{n}{2}}_{\text{constant}} - \sum_i w_{i,s} \le C .
   \]

   (Because \(\int h(1-h(\cdot+s)) = 1 - \sum w_{i,s}\Delta x\) and \(\Delta x = 2/n\).)

**Objective** `minimize C`.

**Warm‑start** Fix the binary vector to the best \(b^\*\) found in Stage 6, initialise all \(w_{i,s}=b_i b_{i+s}\), and give CBC the hint `warm_start=True`.  
Set a **hard time limit** of the remaining budget (e.g. `maximumSeconds = 30`).  CBC returns the best feasible bound it found; multiplying by \(\Delta x\) yields a certified upper bound for the continuous problem at the chosen discretisation.
