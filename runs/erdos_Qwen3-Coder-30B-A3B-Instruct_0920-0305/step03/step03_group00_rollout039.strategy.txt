### 1.  Overview  

The new pipeline treats the **max‑overlap functional** as a **max‑min quadratic problem** and attacks it with a *convex relaxation* (a semidefinite program).  
The SDP supplies a strong lower‑bound on the attainable value of  
\[
t \;=\; \min_{k\in\{1,\dots,n-1\}}\;\sum_{i=0}^{n-1-k}h_i\,h_{i+k},
\qquad 
C_5 \;=\;1-\frac{2}{n}t .
\]  
A feasible (binary or fractional) step‑function is then recovered by **randomised rounding** of the SDP solution, followed by a **short deterministic local refinement** that works directly on the original non‑smooth objective.  
All phases respect the 600 s wall‑clock and use only NumPy, SciPy and CVXPY (with the SCS solver for SDPs).

### 3.  SDP Relaxation  

#### 3.1 Variables  

* **Vector** `h` (continuous, box‑constrained).  
* **Matrix** `X ⪰ 0` (positive semidefinite).  
* **Scalar** `t` (the lower bound on every overlap).

#### 3.2 Linearised product constraints (McCormick envelopes)  

For every pair `(i,j)` (in practice only for the pairs that appear in a shift, i.e. `j = i + s` with `s ≥ 1` and `i+s < n`):

```
X_ij ≤ h_i                (1)
X_ij ≤ h_j                (2)
X_ij ≥ h_i + h_j – 1      (3)
```

When `h` is binary these three inequalities force `X_ij = h_i h_j`.  
With continuous `h` they give the **tightest convex envelope** of the bilinear term on `[0,1]²`.

#### 3.3 Overlap constraints  

For each integer shift `s = 1,…,n‑1` define the *overlap*  

\[
o_s \;=\; \sum_{i=0}^{n-1-s} X_{i,i+s}.
\]

Add the linear constraints  

\[
o_s \;\ge\; t ,\qquad\forall s.
\]

#### 3.4 Additional constraints  

* `diag(X) = h` (the diagonal of `X` must equal `h_i = h_i²` for binary vectors, but in the relaxation we simply enforce equality).  
* Box on `h`:  `0 ≤ h_i ≤ 1`.  
* Weight: `∑ h_i = n/2`.

#### 3.5 Objective  

\[
\max\; t
\qquad\Longleftrightarrow\qquad 
\min\; C_5 = 1-\frac{2}{n}t .
\]

#### 3.6 Solver set‑up  

* Build the model with **CVXPY**.  
* Use the **SCS** solver (first‑order, handles large PSD constraints).  
* Supply a **time limit** (`max_iters` or `maxTime` ≈ 150 s) and a moderate tolerance (`eps = 1e‑5`).  
* Keep the *best incumbent* that SCS reports when the timer expires.

### 5.  Deterministic Local Refinement  

All candidates (the relaxed `ĥ` and the rounded binaries) are fed into a **second‑order constrained optimiser** that works on the *original* non‑smooth functional.

#### 5.1 Smooth‑max surrogate  

Define for a given `α > 0`

\[
\Phi_α(h) = \frac{1}{α}\log\!\Bigl(\sum_{s=1}^{n-1}
      \exp\bigl(α\,f_s(h)\bigr)\Bigr),
\qquad
f_s(h)=dx\sum_{i} h_i\bigl(1-h_{i+s}\bigr).
\]

When `α → ∞`, `Φ_α` → `max_s f_s`.  

The gradient is analytically available:

\[
\frac{\partial\Phi_α}{\partial h_j}

\]
with soft‑max weights  

\[
w_s = \frac{\exp\bigl(α f_s(h)\bigr)}
           {\sum_{r}\exp\bigl(α f_r(h)\bigr)} .
\]

#### 5.2 Optimisation routine  

* **Method**: SciPy’s `trust-constr` (handles bound constraints and a single affine equality).  
* **Constraints**: `0 ≤ h ≤ 1` (bounds) and `∑ h = n/2` (linear equality).  
* **Schedule for `α`**: start with `α₁ = 5`, run to convergence (tolerance `1e‑7`), then increase to `α₂ = 15`, warm‑start, converge again, finally `α₃ = 40`.  
* **Iteration budget**: at most 200 iterations per `α` stage; early‑stop when the improvement in `Φ_α` falls below `1e‑8`.  

Because the gradient is cheap (`O(n²)` for each evaluation) and `n ≤ 100`, each refinement finishes well within a few seconds.

#### 5.3 Post‑processing  

After the last `α` stage compute the *exact* `C_5` (using `np.correlate`).  
If a candidate’s refined `C_5` is lower than the best so far, store it.

### 6.  Time‑Management & Fallback Logic  

| Phase | Intended wall‑time | Remarks |
|------|-------------------|--------|
| **A – SDP** | ≤ 150 s | If termination occurs earlier, keep the solution; if SCS fails to produce any feasible point, reduce `n` (e.g. 80) and retry. |
| **B – Rounding** | ≤ 120 s | Perform a fixed number of trials (≈ 20) or stop when the global timer reaches 400 s. |
| **C – Local refinement** | ≤ 180 s | Run the refinement on each candidate until the overall budget (600 s) is exhausted; keep the best. |
| **D – Final fallback** | remaining time | If the SDP never succeeded, fall back to a pure *random‑restart smooth‑max* optimisation (30 random starts, each ≤ 10 s) to guarantee a solution better than the baseline DE+SLSQP. |

The driver periodically checks `time.time()` and aborts the current phase as soon as the remaining budget would be insufficient for the next phase.

### 9.  Algorithmic pseudocode (high‑level, no code)

```

    set random seed
    start timer

    # ---- Phase A : SDP -------------------------------------------------
    n = 100 (or 80 if time runs out)
    build SDP model (h, X, t) with constraints described in §3
    solve with cvxpy + SCS, time limit 150 s
    if model infeasible:
        reduce n and retry
    obtain (h_sdp, X_sdp, t_opt)

    candidates = [h_sdp]               # relaxed continuous vector

    # ---- Phase B : Randomised rounding --------------------------------
    eigen‑decompose X_sdp → (V, Λ) → Y = V√Λ
    while time_left > 120 s and < max_rounds:
        g ← N(0,I_r)
        y ← Y g
        h_bin ← top‑(n/2) entries of y set to 1, rest 0
        h_bin ← greedy_swap_improve(h_bin)   # ≤200 swaps
        candidates.append(h_bin)

    # ---- Phase C : Local refinement ------------------------------------
    best_h = None ; best_val = +∞
    for h0 in candidates:
        if remaining_time < 5 s: break
        h_refined = trust_constr_optimize(h0,
                                          softmax_alpha_schedule=[5,15,40],
                                          bounds=[0,1], linear_eq=sum(h)=n/2)
        val = exact_C5(h_refined)
        if val < best_val:
            best_val = val ; best_h = h_refined

    # ---- Phase D : Fallback (if nothing good found) -------------------
    if best_h is None:
        best_h, best_val = random_restart_softmax_optimisation(budget_remaining)

    return best_h.tolist(), best_val, n
```

All helper routines (`exact_C5`, `trust_constr_optimize`, `greedy_swap_improve`, `random_restart_softmax_optimisation`) are straightforward NumPy / SciPy implementations that respect the constraints and use the analytical gradient formulas from §5.1.

### 10.  Failure Mitigation  

* **SDP does not finish** – fall back to the smaller grid (`n = 80`) or skip the SDP entirely and rely on the pure smooth‑max random‑restart (still better than the original DE approach).  
* **Rounding yields poor C₅** – increase the number of rounding trials, or use a *deterministic* rounding based on the leading eigenvector (`h_i = 1` for the `n/2` largest components of the first eigenvector).  
* **Local optimiser gets stuck** – restart from a perturbed version of the current best (add Gaussian noise of magnitude 0.02, re‑project) and rerun the refinement.  
* **Memory overflow for large `n`** – the SDP model only stores the upper‑triangular part of `X`; with `n = 120` the matrix has ≈ 7 200 entries, well under typical RAM limits.
