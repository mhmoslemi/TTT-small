**Overall idea – design the sequence in the frequency domain**  
The quantity to be minimised is  

\[
C_5(h)=\max_{k}\int_0^2 h(x)\,\bigl(1-h(x+k)\bigr)\,dx
       =\bigl(m-\min_{k}\!\int_0^2 h(x)h(x+k)\,dx\bigr),
\qquad m=\int_0^2 h(x)dx=1 .
\]

After discretisation (`n` points, `dx=2/n`) the second term is the *autocorrelation* of the vector `h`:

\[
R(k)=\sum_{i=0}^{n-1}h_i\,h_{i+k}, \qquad k\in\{-n+1,\dots ,n-1\}.
\]

Hence **maximising the minimum of the autocorrelation** yields a smaller `C5`.  
The autocorrelation is the inverse discrete Fourier transform of the *power spectrum*:

\[
R = \mathcal F^{-1}\!\bigl(|\widehat h|^2\bigr), \qquad 
\widehat h = \mathcal F(h).
\]

If the magnitudes \(|\widehat h|\) are (almost) constant for all non‑zero frequencies, the inverse transform is *flat* – every shift obtains nearly the same correlation value.  This observation suggests a **alternating‑projection** algorithm that directly manipulates the spectrum and repeatedly enforces the time‑domain constraints \(0\le h_i\le 1\) and \(\sum h_i\,dx=1\).

The method is completely different from the DE/SLSQP pipeline used previously; it works in the spectral domain, uses a simple projection onto a simplex, and exploits the linear relationship between power spectrum and autocorrelation.

### 2. Core algorithm – Alternating projections in the Fourier domain

For a chosen even grid size `n` (we will try several values, starting with 42 and then 48, 56, 64, 72, 80 if time permits) perform the following iterative scheme.

#### 2.1 Parameter set for a given `n`

* `dx = 2.0 / n`, `m = n/2`.  
* Target magnitude for non‑zero frequencies, `M`.  Because of Parseval’s identity  

  \[
  \|h\|_2^2 = \frac1n\|\widehat h\|_2^2,
  \]

  and we know `Σ h_i = m`, we can set  

  \[
  M = \sqrt{\frac{n}{n-1}\Bigl(\|h\|_2^2 - \frac{m^2}{n}\Bigr)}.
  \]

  In practice we start with the value derived from the current `h` and keep it fixed during the inner loop.

* **Maximum inner iterations** – e.g. `it_max = 500`.

#### 2.2 Inner loop (one restart)

1. **Random feasible start** – generate a random vector `h⁰` on the simplex: draw `u_i ~ Exp(1)` (or `Uniform(0,1)`) for all i, set `h⁰ = u / Σu`, then scale by `dx⁻¹` to obtain the required sum `1`.  Clip to `[0,1]` and re‑project with `proj_box_simplex` to guarantee feasibility.

2. **Iterative alternating projection** – for `t = 0 … it_max-1`:

   a. **FFT** – compute the discrete Fourier transform `H = np.fft.fft(hᵗ)`.  
   b. **Magnitude enforcement** – construct a *target* spectrum `\tilde H`:
      * Keep the DC component (`k=0`) unchanged (it encodes the sum of `h`).
