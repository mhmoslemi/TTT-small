**Goal**  
Find a step‑function h on [0,2] (represented by n uniformly spaced samples) that satisfies  

* 0 ≤ h[i] ≤ 1 for every i,  
* Σ h · dx = 1   (i.e. Σ h[i] = n/2),  

and minimises  

 C₅(h) = maxₖ ∫₀² h(x)·(1−h(x+k)) dx  

which, after discretisation, is  

 C₅(h) = dx·maxₖ rₖ(h),  rₖ(h) = Σᵢ hᵢ·(1−h_{i+k})  (0 ≤ k ≤ n−1).

The new approach formulates the problem as a **max‑min** optimisation, replaces the nondifferentiable max by a smooth surrogate, and solves the resulting problem with a **projected accelerated gradient** method combined with aggressive random restarts. ### 1. Reformulation as a Max‑Min Problem  

Define  

 w ≔ Σ hᵢ = n/2 (constant).  

For any shift k  

 rₖ = w − Sₖ,  Sₖ ≔ Σᵢ hᵢ h_{i+k}.  

Thus  

 maxₖ rₖ = w − minₖ Sₖ.  

Minimising C₅ is **equivalent** to **maximising** the smallest auto‑correlation  

 t ≔ minₖ Sₖ.  

The optimisation can be written as  

```
max    t
s.t.   Σ hᵢ = w,
       0 ≤ hᵢ ≤ 1,
       Σᵢ hᵢ·h_{i+k} ≥ t  for every k = 0,…,n‑1 .
```

The constraints are quadratic (bilinear) and non‑convex, but the structure (a common lower bound *t* for all correlations) suggests an iterative **difference‑of‑convex (DC)** or **concave‑convex** procedure.

---

### 2. Smooth Approximation of the Max  

Directly handling `maxₖ rₖ` is difficult because it is nondifferentiable.  
Instead use a **log‑sum‑exp** surrogate:

 fₐ(h) = (dx/α)·log( Σₖ exp(α·rₖ(h)) ),

where α > 0 controls the tightness of the approximation (`α→∞` recovers the exact max).  
For moderate α the surrogate is smooth, its gradient is a weighted sum of the individual gradients

 ∇fₐ(h) = dx· Σₖ wₖ ∇rₖ(h),  wₖ = exp(α·rₖ)/Σ_j exp(α·rⱼ).

When α is gradually increased (continuation), the algorithm first solves an easy smooth problem and then tracks the solution toward the true max.

---

### 3. Closed‑Form Gradient of Each rₖ  

For a given shift k (0 ≤ k < n) the correlation term is  

 rₖ(h) = Σᵢ hᵢ − Σᵢ hᵢ h_{i+k}  (with the obvious boundary truncation).  

Because Σ hᵢ = w is constant,  

 ∂rₖ/∂hⱼ = 1 − [h_{j+k} · 𝟙_{j+k<n}] − [h_{j‑k} · 𝟙_{j‑k≥0}].

For k = 0 the product term collapses to hⱼ², giving  

 ∂r₀/∂hⱼ = 1 − 2 hⱼ.

All gradients are easy to compute with **vectorised convolutions** (or simple slice operations).  The full gradient of the surrogate is then a linear combination of these vectors, weighted by wₖ.

---

### 4. Projection onto the Feasible Set  

The feasible region is the **capped simplex**:

 { h ∈ ℝⁿ | 0 ≤ hᵢ ≤ 1, Σ hᵢ = w }.

After each gradient step we must project back onto this set.  
Projection can be performed in O(n log n) time by the **water‑filling** algorithm:

1. Shift the vector by the lower bound (0) – no change.
2. Sort the entries decreasingly.
3. Find a threshold τ such that  

 xᵢ = min( max(vᵢ − τ, 0), 1 ) and Σ xᵢ = w.  

   τ is obtained by a simple linear scan of the sorted list (or by a short binary search if the sorted scan is inconvenient).  
4. The resulting x is the Euclidean projection onto the capped simplex.

All subsequent arithmetic respects the box constraints automatically.

### 5. Accelerated Projected Gradient Algorithm  

For a fixed α the optimisation problem is smooth and convex **in the surrogate** (the log‑sum‑exp is convex).  The algorithm proceeds as:

```
h⁰ ← random feasible point (projected)
y⁰ ← h⁰,   t⁰ ← 1
for m = 0,1,2,… until convergence:
    # evaluate smooth surrogate and its gradient
    r   ←  compute all rₖ(hᵐ)               # O(n²) or O(n log n) via FFT
    f   ←  dx/α * log( sum_k exp(α·rₖ) )
    w   ←  softmax(α·r)                    # wₖ = exp(α·rₖ)/Σ exp(...)
    g   ←  dx * Σₖ wₖ * grad(rₖ)           # vector of length n
    # Nesterov‑type extrapolation
    h̃  ←  proj( yᵐ − η·g )                # η – step‑size (see line‑search)
    tᵐ⁺¹←  (1+√(1+4·tᵐ²))/2
    yᵐ⁺¹←  h̃ + ((tᵐ−1)/tᵐ⁺¹)·(h̃ − hᵐ)
    # check stop: |fᵐ⁺¹−fᵐ| < ε   or   max iterations reached
```

*Step‑size η* is chosen via a cheap back‑tracking line search that guarantees sufficient decrease of the surrogate (Armijo condition).  Because the gradient is Lipschitz‑continuous with a known bound (each component of ∇rₖ is bounded by 2), the initial η can be set to 0.5 and reduced by a factor 0.5 when the condition fails.

The algorithm is run **until the surrogate stabilises** (e.g. relative change < 10⁻⁶) or a per‑run iteration budget (≈ 5 000 iterations).

### 6. Continuation on the Smoothing Parameter α  

Start with a modest α₀ ≈ 1 (very smooth).  
After each successful run, **increase α** (e.g. multiply by 2) up to a final α_max ≈ 200 – 500.  
At each increase we **warm‑start** the gradient method with the solution obtained for the previous α.  This continuation drives the iterates toward a true minimiser of the original max‑function while keeping the optimisation landscape well‑behaved.

### 7. Random Restarts and Heuristic Initialisations  

The problem is non‑convex; a single run can be trapped in a local basin.  
We therefore employ a **multi‑restart strategy**:

* **Uniform random start** – Generate a vector of i.i.d. Uniform(0,1), project onto the capped simplex.
* **Binary‑biased start** – Create a balanced 0/1 pattern (exactly w ones) and then perturb each entry by a tiny Gaussian (≈ 0.02), finally project.
* **Three‑block start** – Choose two cut‑points a < b and set  

 hᵢ = 1  for xᵢ ∈ [0,a), 
 hᵢ = 0  for xᵢ ∈ (b,2], 
 hᵢ = p  for xᵢ ∈ [a,b)  

with p chosen so that the integral constraint holds (p = (w − a·1/dx)/(b‑a)·dx).  Vary (a,b,p) randomly.

* **Warm‑start from the best solution of the previous run** – after a run finishes, perturb the best vector slightly (swap a small amount of mass between two coordinates) and launch a new gradient run.

The total number of restarts is limited only by the global time budget.  For a 600‑second budget we allocate roughly 0.5 seconds per restart, which comfortably allows many (≈ 200) short runs, each typically converging in < 0.1 seconds.

### 8. Choice of Sample Size *n*  

The discretisation accuracy improves with larger n, but the dimensionality also grows.  
Empirically, values of n that are **multiples of 8** (e.g. 48, 56, 64, 80) give a good trade‑off: the cap‑simplex projection is exact, and the FFT‑based correlation runs in O(n log n) with negligible overhead.

The algorithm proceeds as follows:

1. **Generate a list of candidate n** (e.g. [48, 56, 64, 80]).  
2. For each n, compute `dx = 2.0 / n` and `w = n/2`.  
3. Run the multi‑restart gradient+continuation scheme until the allocated slice of the time budget is exhausted (approximately equal share per n).  
4. Keep the globally best pair (h, C₅) among all n.

Because the surrogate’s value is monotone in α, the final C₅ is evaluated with the original `np.correlate` routine (no smoothing) to guarantee compliance with the evaluation script.

### 10. Failure Modes & Mitigations  

| Potential Issue | Why it Happens | Counter‑measure |
|-----------------|----------------|-----------------|
| **Stagnation at a local minimum** (gradient vanishes) | Non‑convex landscape; log‑sum‑exp may flatten near flat plateaus. | Continuation on α forces the iterates to escape shallow basins; random restarts guarantee diverse basins are explored. |
| **Projection numerical instability** (target sum unreachable) | If the current vector contains many entries at the bound 0 or 1, the water‑filling may fail to meet w because of rounding. | Use double‑precision throughout; after projection, a tiny correction (`+/- 1e‑12`) is applied to the first non‑saturated coordinate to enforce exact equality. |
| **Overflow in exp(α·rₖ)** for large α | rₖ can be up to w ≈ n/2; α·rₖ may exceed floating‑point range. | Subtract the maximum rₖ before exponentiation (standard log‑sum‑exp trick). |
| **Excessive runtime for large n** | O(n²) correlation per iteration may dominate. | Switch to FFT‑based convolution (`np.fft.ifft(np.fft.fft(h)*np.fft.fft(h))`) which reduces per‑iteration cost to O(n log n). |
| **Loss of feasibility due to rounding** | After many projection steps the sum may drift by ≈ 10⁻¹⁴. | After each projection enforce `np.isclose(np.sum(h), w)` and, if necessary, adjust the smallest non‑boundary entry by the residual. |
