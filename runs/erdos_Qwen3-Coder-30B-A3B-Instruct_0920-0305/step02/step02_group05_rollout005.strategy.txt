**1. Problem reformulation**

For a discrete step‑function `h[0…n‑1]` on `[0,2]` with spacing  
`dx = 2/n` we have  

```
A_k = ∫_{overlap(k)} h(x)·(1‑h(x+k)) dx
    = dx * Σ_{i∈I_k} h_i·(1‑h_{i+m})          (m = k/dx, integer)
```

where `I_k = { i | 0 ≤ i ≤ n‑1‑m }` for a non‑negative shift `m` (the case `m<0` is symmetric).  
The objective is  

```
C5(h) = max_k A_k      (to be minimised)
```

subject to  

```
0 ≤ h_i ≤ 1   ∀i ,          Σ_i h_i * dx = 1   ⇔   Σ_i h_i = n/2 .
```

Equivalently  

```
C5(h) = 1 – min_k  dx·Σ_{i∈I_k} h_i·h_{i+m} .
```

Hence we must **maximise the smallest autocorrelation** of `h` while keeping the box and mass constraints.

**2. Core optimisation idea: projected sub‑gradient descent on the max‑over‑k objective**

The function `A_k(h)` is smooth (quadratic) for each fixed shift `k`.  
The max of a finite family of smooth functions is **sub‑differentiable**: a sub‑gradient at `h` can be taken as any convex combination of the gradients of those `A_k` that achieve the current maximum.

Thus we can iteratively:

1. Identify the shift(s) `m*` that realise `C5 = max_k A_k`.
2. Compute the gradient (actually the sub‑gradient) of `A_{m*}` w.r.t. every component `h_i`.
3. Take a step opposite to that sub‑gradient.
4. Project the resulting vector back onto the feasible set  
   `S = { h∈[0,1]^n  |  Σ h_i = n/2 }`.

Repeatedly applying these steps drives the maximum overlap down, provided the step size is controlled.

**3. Exact gradient for a single active shift**

For a non‑negative shift `m ≥ 0` the overlapped index set is `I = {0,…,n‑1‑m}`.  
Define `f_i = h_i·(1‑h_{i+m})`. Then  

```
A_m = dx· Σ_{i∈I} f_i .
```

Derivative w.r.t. a component `h_j`:

- If `j∈I` (i.e. `j ≤ n‑1‑m`):  ∂A_m/∂h_j = dx·(1‑h_{j+m}) .
- If `j ∈ I+m` (i.e. `j ≥ m` and `j ≤ n‑1`):  ∂A_m/∂h_j = –dx·h_{j‑m}`.
- Otherwise the derivative is zero.

Putting both contributions together yields a very compact vectorised formula:

```

if m ≥ 0:
    i = slice(0, n‑m)                # indices i∈I
    j = slice(m, n)                  # corresponding i+m
    g[i] += 1 - h[j]                 # “1‑h_{i+m}” term
    g[j] -= h[i]                     # “‑h_i” term
else:
    m = -m
    i = slice(m, n)                  # indices i∈I for negative shift
    j = slice(0, n‑m)                # i‑m
    g[i] += 1 - h[j]
    g[j] -= h[i]
g *= dx
```

If several shifts share the maximal value, we simply average their `g` vectors (or sum and later normalise the step size).

**4. Projection onto the feasible set**

We need the Euclidean projection onto the intersection of a hyperplane and a box. This can be performed with a **water‑filling** algorithm:

```
project(v, target):
    w = clip(v, 0, 1)
    diff = target – sum(w)
    while |diff| > ε:
        if diff > 0:   free = (w < 1)                 # can increase
        else:          free = (w > 0)                 # can decrease
        n_free = count(free)
        if n_free == 0: break
        delta = diff / n_free
        w[free] += delta
        w = clip(w, 0, 1)
        diff = target – sum(w)
    return w
```

`target = n/2` (because `dx·Σ h_i = 1`). The loop converges in at most `n` iterations because each iteration either fixes at least one variable at a bound.
