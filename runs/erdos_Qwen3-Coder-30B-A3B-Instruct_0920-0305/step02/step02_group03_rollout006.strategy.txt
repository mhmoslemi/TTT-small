### 1. Problem reformulation as a mixed‑integer linear program

1. **Variables**  
   * `h[i] ∈ {0,1}` for `i = 0,…,n‑1`.  
   * For each shift `s = 1,…,n‑1` and each overlapping index `i = 0,…,n‑s‑1` introduce an auxiliary binary variable  

   ```
   y[i,s] = h[i]·h[i+s] .
   ```

   * A scalar integer variable `t` representing the maximal overlap count (the quantity inside `max_s` before multiplication by `dx`).

2. **Linearisation of the product** – enforce the usual “AND’’ constraints  

   ```
   y[i,s] ≤ h[i]                (1)
   y[i,s] ≤ h[i+s]              (2)
   y[i,s] ≥ h[i] + h[i+s] – 1   (3)
   ```

   Together they guarantee `y[i,s] = h[i]·h[i+s]` for binary `h`.

3. **Overlap count for a shift**  

   For a fixed shift `s` the overlap (the expression inside the `max`) equals  

   ```
   m_s = Σ_{i=0}^{n-s-1} h[i] – Σ_{i=0}^{n-s-1} y[i,s] .
   ```

   Both sums are linear in the decision variables.

4. **Constraints**  

   * **Integral constraint** – exactly half of the entries must be 1  

     ```
     Σ_i h[i] = n/2 .
     ```

   * **Maximum‑overlap definition** – enforce  

     ```
     m_s ≤ t    for all s = 1,…,n‑1 .
     ```

5. **Objective** – minimise `t`.  After solving, the continuous bound is  

   ```
   C5 = t · dx   where   dx = 2.0 / n .
   ```
