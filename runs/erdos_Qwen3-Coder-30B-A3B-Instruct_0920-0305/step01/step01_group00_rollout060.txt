## Mathematical Analysis:
The problem is to minimize the maximum overlap integral:
$$C_5 = \max_k \int h(x)(1 - h(x+k)) dx$$
Subject to:
- $h(x) \in [0, 1]$ for all $x \in [0, 2]$
- $\int_0^2 h(x) dx = 1$

This can be interpreted as minimizing the maximum convolution $h * (1-h)$ over all shifts $k$. 

Key insight: Since $\int h = 1$, we have:
$$C_5 = \max_k \left(1 - \int h(x) h(x+k) dx \right) = 1 - \min_k \int h(x) h(x+k) dx$$

Therefore, minimizing $C_5$ is equivalent to maximizing the minimum correlation of $h$ with its shifted versions.

## Computational Strategy:

### Approach 1: Smoothed Gradient Descent
1. Parameterize $h$ as vector of $n$ values in $[0,1]$ constrained by $\sum h = n/2$. 
2. Use smoothed objective: minimize $F(h) = \frac{1}{\alpha} \log \sum \exp(\alpha C_s)$ where $C_s = \int h(x) (1-h(x+s)) dx$.
3. Compute gradient of $F$ as weighted average of gradients $1 - (h_{i+s} + h_{i-s})$.
4. Apply gradient descent with projection onto feasible set (bounded simplex).
5. Anneal $\alpha$ to converge towards true maximum.

### Approach 2: Simulated Annealing (SA)
1. Use SA as global search to jump out of local minima found by gradient methods.
2. Each move modifies two values $h_i, h_j$ by amount $\Delta$ where sum constraint is maintained.
3. Accept new state based on Metropolis criterion with  temperature cooling schedule.
4. Pool of move types: 1-move (two indices), multi-move (using thresholding), combined with randomization.

### Approach 3: Hybrid - Gradient followed by SA
1. Initialize using interpolation of `initial_h_values` to target `n` points.
2. Run gradient descent with projection for ~500 iterations to find local optimum. 
3. Run SA from this point to explore neighbors and possibly improve.
4. Run multiple restarts (5-10) each with different random initializations or with perturbed local optima.

### Key Algorithm Components
- **Correlation computation**: Use `np.correlate(h, 1-h, mode='full')`. Python implementation: Building correlation vector directly from full convolution. Vectorized rolling is inefficient; compute manually via slicing.
- **Projection onto capped simplex**: Algorithm based on binary search for optimal threshold lambda, then thresholding: $x_i = \text{clip}(v_i - \lambda, 0, 1)$ with $\sum x = \text{target}$.
- **Discretization**: $n=100$ to balance resolution and computational cost, keep under ~100k ops per run.
- **Constraint Handling**:
  - Sum constraint enforced by adjusting exactly two indices at a time during SA.
  - Bounds $[0,1]$ via clipping or projection after updates.

### Optimization Parameters
- $\alpha = 1$ initial; increase up to 100 or 1000 for sharp limit.
- Step size adaptively set via $\eta = \eta_0 / \sqrt{iter+1}$; weights from softmax of scaled correlation values.
- SA Temperature schedule: $T = T_0 \cdot \beta^{iter}$ (e.g., $\beta=0.999$, $T_0=0.05$) 
- Simulated annealing iterations or 200k~500k moves.
- Total runs for restarts: 10 with early stopping.

### Final Solution Selection
- Keep best $h$ found over all restarts.
- Ensure $\sum h \cdot \Delta x = 1$, re-project if necessary.
- Evaluate final $C_5 = \max (\text{correlation} \times \Delta x)$.

### Time Budget Management
- Budget: 600s. Sequentially run 10 restarts.
- 500 iterations gradient descent + 200k moves SA = ~400k ops per restart, still possible in 600s.
- Early terminate runs if best result dips below threshold (e.g., target=0.3807) or time goes below threshold for 2 restarts.

import numpy as np
from scipy.signal import correlate
import time

def evaluate_c5(h):
    """Evaluate the C5 constant for a given step function h"""
    n = len(h)
    dx = 2.0 / n
    # Compute the overlap integral for all shifts
    corr = correlate(h, 1 - h, mode="full")
    # The maximum overlap value
    max_corr = np.max(corr)
    return max_corr * dx

def proj_simplex_bounded(v, target_sum, lower=0.0, upper=1.0):
    """
    Project vector v onto the set {x: lower <= x <= upper, sum(x) = target_sum}
    Uses binary search on lambda for thresholding.
    """
    n = len(v)
    # Ensure bounds [lower, upper] are respected
    v_clipped = np.clip(v, lower, upper)
    s = np.sum(v_clipped)
    if abs(s - target_sum) < 1e-12:
        return v_clipped  # Already feasible

    # Binary search over lambda for correct projection
    lambda_low = -1e5
    lambda_high = 1e5
    tol = 1e-8
    for _ in range(100):
        lambda_mid = (lambda_low + lambda_high) / 2.0
        x = np.clip(v - lambda_mid, lower, upper)
        s_new = np.sum(x)
        if s_new > target_sum:
            lambda_low = lambda_mid
        else:
            lambda_high = lambda_mid
    lambda_final = (lambda_low + lambda_high) / 2.0
    x = np.clip(v - lambda_final, lower, upper)
    return x

def propose_move(h, n):
    """Propose a move modifying two indices to maintain sum constraint"""
    i, j = np.random.choice(n, size=2, replace=False)
    max_increase_i = 1.0 - h[i]
    max_decrease_i = h[i]
    max_increase_j = 1.0 - h[j]
    max_decrease_j = h[j]
    delta_min = max(-max_decrease_i, -max_increase_j)
    delta_max = min(max_increase_i, max_decrease_j)
    if delta_min >= delta_max:
        return None
    delta = np.random.uniform(delta_min, delta_max)
    h_new = h.copy()
    h_new[i] += delta
    h_new[j] -= delta
    return h_new, delta, i, j
