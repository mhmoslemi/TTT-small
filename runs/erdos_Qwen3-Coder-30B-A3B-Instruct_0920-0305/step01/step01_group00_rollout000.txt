# Detailed Strategy for Improving C₅ Upper Bound

## Problem Overview
We aim to find a step function h: [0, 2] → [0, 1] minimizing the maximum overlap integral:
$$C_5 = \max_k \int h(x)(1 - h(x+k)) dx$$
Subject to:
- $ h(x) \in [0, 1] $ for all $ x \in [0, 2] $
- $ \int_0^2 h(x) dx = 1 $

## Approaches and Algorithms

### 1. Optimization Algorithm Selection
We propose a hybrid optimization strategy combining two contrasting approaches:
- Gradient-based method with log-sum-exp smoothing for global guidance
- Simulated Annealing for global exploration

This hybrid approach addresses the non-convex nature of the problem and avoids getting stuck in local minima.

### 2. Mathematical Formulation
Rewrite the objective:
$$C_5 = \max_k \left( \int h(x) dx - \int h(x)h(x+k) dx \right) = 1 - \min_k \int h(x)h(x+k) dx$$

We minimize $ \max_k \int h(x)(1 - h(x+k)) dx $, equivalent to minimizing:
$$\max_{k \in \{0, ..., 2n-2\}} \int h(x)(1 - h(x+k)) dx = \max_{k \in \{0, ..., 2n-2\}} C_k$$

where $ C_k = \int h(x)(1 - h(x+k)) dx $

### 3. Details of Gradient Method (Smoothed Minimax)
**Initialization:**
1. Start with discretization using $ n = 100 $ points over [0, 2]
2. Initialize h via a subset of `initial_h_values` with linear interpolation if sample count differs
3. Normalize h to satisfy sum constraint: $ \sum h_i \cdot dx = 1 $, so $ \sum h_i = n/2 $

**Gradient Computation:**
1. For current h, compute correlation vector $ C_k = \text{correlate}(h, 1-h, \text{mode}='full}') \cdot dx $
2. Smooth using log-sum-exp: 
$$
F(h) = \frac{1}{\alpha} \log \sum_k \exp(\alpha C_k)
$$
3. Compute weights: $ w_k = \frac{\exp(\alpha C_k)}{\sum_k \exp(\alpha C_k)} $
4. Compute gradient for each i:
$$
g_i = 1 - \sum_k w_k \left( h_{i+k} + h_{i-k} \right)
$$
5. Use projected gradient descent: $ h^{new} = h - \eta g $, followed by projection onto feasible set

**Projection:**
Project onto constrained set: $ \{h : 0 \leq h_i \leq 1, \sum h_i = n/2\} $
Use iterative projection algorithm based on sorting and thresholding for closed-form projection onto bounded simplex.

### 4. Simulated Annealing (SA) Procedure
Designed to explore different shapes more globally:

**Initialization:**
- Start from the best solution from gradient-based method or random feasible initialization
- Begin with high temperature $ T_0 $

**Main Loop:**
1. Pick two distinct indices $ i, j $
2. Compute feasible movement range: $ \Delta = \min(1 - h_i, h_j) $ (and vice versa)
3. Sample change: $ \delta \sim \text{Uniform}(-\Delta, \Delta) $
4. Update: $ h_i = h_i + \delta, h_j = h_j - \delta $
5. Compute new $ C_5 $
6. Accept if improvement; otherwise accept with probability $ \exp(-\frac{\Delta C_5}{T}) $
7. Reduce temperature $ T = T \cdot \alpha $

### 5. Hybrid Execution Plan
1. **Preprocessing:** Generate initial point from `initial_h_values` (interpolated to n=100)
2. **Hybrid Run:**
   - Run gradient descent for 1000 iterations with smoothing to obtain local optimum $ h_{loc} $
   - Run Simulated Annealing starting from $ h_{loc} $ for up to 100,000 iterations  
   - Keep track of best solution throughout
3. **Validation:** At each iteration, ensure constraint $ \sum h_i \cdot dx = 1 $ (i.e. $ \sum h_i = n/2 $)
4. **Early Termination:** If $ C_5 < 0.3807 $, terminate early

### 6. Implementation Considerations
- **Step Size:** Use fixed step size or adaptive based on gradient norm for gradient descent.
- **Annealing Schedule:** Use exponential cooling: $ T(t) = T_0 \cdot \alpha^t $ where $ \alpha \in (0.99, 0.999) $
- **Performance:** Keep $ n = 100 $ for optimal balance of resolution and numerical cost.
- **Memory:** Efficient numpy operations with precomputed correlation patterns to reduce redundant computation.
- **Exit Strategy:** Preemptively check time budget and return best-known solution before timeout.
