### 1.  Mathematical reformulation

1. **Binary representation** – Because the integrand is linear in each `h_i` and the constraints force the average value to be `1/2`, an optimal solution can be taken to be binary (`h_i∈{0,1}`).  We therefore search for a binary vector  

   \[
   x\in\{0,1\}^N,\qquad \sum_{i=0}^{N-1}x_i = \frac N2 .
   \]

2. **Mismatches for a shift** – For a positive shift `k (1≤k≤N‑1)` define  

   \[
   y_{i,k}=x_i\,x_{i+k}\quad (0≤i≤N-1-k).
   \]

   The number of “overlap‑with‑complement’’ points for that shift is  

   \[
   M_k^{+}= \sum_{i=0}^{N-1-k}\bigl(x_i-y_{i,k}\bigr) .
   \]

   For the symmetric negative shift `‑k` we have  

   \[
   M_k^{-}= \sum_{i=0}^{N-1-k}\bigl(x_{i+k}-y_{i,k}\bigr) .
   \]

   The objective is  

   \[
   \min\;t \quad\text{s.t.}\quad M_k^{+} ≤ t,\; M_k^{-} ≤ t\;\;\forall\,k .
   \]

3. **Linearisation of the products** – Use the standard three‑inequality McCormick (big‑M) linearisation for each binary product `y_{i,k}`:

   ```
   y_{i,k} ≤ x_i
   y_{i,k} ≤ x_{i+k}
   y_{i,k} ≥ x_i + x_{i+k} – 1
   ```

   All `y_{i,k}` are binary, therefore the model is a pure MILP.

4. **Variables and size** –  
   * `x_i` : N binary variables.  
   * `y_{i,k}` : N(N‑1)/2 binary variables (≈ 1 200 for N=48).  
   * `t` : integer (or real) variable representing the worst‑case mismatch count.  

   The total number of linear constraints is roughly `3·N(N‑1)/2 + 2·(N‑1) + 1`, easily solvable for N up to 70 on a single CPU.

5. **Relation to the continuous bound** – After solving, the Erdős constant bound is  

   \[
   C_5 = t_{\text{opt}}\;dx,\qquad dx=\frac{2}{N}.
   \]
