### 1.  Core mathematical reformulation

1. **Binaryisation is optimal.**  
   For any feasible `h` the value at shift 0 is  
   \[
   \int_0^2 h(x)\bigl(1-h(x)\bigr)\,dx = 1-\int_0^2 h(x)^2dx .
   \]  
   Because `0≤h≤1` and the average of `h` is fixed (`∫h=1`), the term `∫h²` is maximised when every sample is either 0 or 1. Hence a binary (0‑1) step function makes the zero‑shift overlap equal to 0 and can only improve the worst‑case value.  
   Consequently we restrict ourselves to vectors `h∈{0,1}ⁿ` (with possibly one extra `0.5` entry when `n` is odd to satisfy the exact integral).

2. **From max‑overlap to max‑‑min autocorrelation.**  
   Define the indicator set `S={i | h_i=1}` (size `k=n/2`).  
   For a shift `d` the overlap count is  
   \[
   m_d = \sum_{i} h_i\bigl(1-h_{i+d}\bigr)
        = k - \underbrace{\sum_i h_i h_{i+d}}_{\text{ordered overlap } \lambda_d } .
   \]  
   Thus  
   \[
   C_5 = \max_d m_d\;dx = \frac{dx}{4}\,\bigl( n-\min_d\rho_d\bigr),
   \]  
   where \(\rho_d=\sum_i s_i s_{i+d}\) and \(s_i=2h_i-1\in\{-1,+1\}\).  
   **Goal:** maximise the **minimum** periodic autocorrelation \(\rho_{\min}=\min_{d\neq0}\rho_d\).  

   The sum of all \(\lambda_d\) (or equivalently all \(\rho_d\)) is fixed:
   \[
   \sum_{d\neq0}\lambda_d = k(k-1),\qquad 
   \sum_{d\neq0}\rho_d = -n + 4k(k-1) .
   \]  
   Hence the problem is a classic *max‑min* constant‑weight binary design: push every shift as close as possible to the average autocorrelation.

3. **Linear (MILP) formulation.**  
   Introduce binary variables \(h_i\) and continuous variables \(y_{i,d}\) that realise the product \(h_i h_{i+d}\) for every admissible shift.  
   For each `(i,d)` (where both indices stay inside `[0,n-1]`) enforce McCormick envelopes

   ```
   y_{i,d} ≤ h_i
   y_{i,d} ≤ h_{i+d}
   y_{i,d} ≥ h_i + h_{i+d} - 1
   y_{i,d} ≥ 0
   ```

   For a given shift `d` let  
   \[
   w_d = \sum_{i\in I(d)} h_i,\qquad
   \lambda_d = \sum_{i\in I(d)} y_{i,d},
   \qquad
   m_d = w_d - \lambda_d ,
   \]  
   where `I(d)={i | 0≤i,i+d<n}`.

   Introduce a scalar variable `t` that bounds all overlaps:
   ```
   t ≥ m_d   for every d ≠ 0
   ```
   The objective is `minimise t`.  

   The global constraints are
   ```
   Σ_i h_i = n/2                (exact integral)
   h_i ∈ {0,1}                (binary)
   0 ≤ y_{i,d} ≤ 1
   t ≥ 0
   ```

#### 3.1  Feasible set projection

The feasible polytope is

\[
\mathcal{P}=\{h\in[0,1]^n\mid \mathbf{1}^\top h=n/2\}.
\]

Projection of an arbitrary vector `y` onto `𝔓` is performed by a *water‑filling* algorithm:

```
1. Clip y to [0,1]  →  ŷ.
2. Compute s = Σ ŷ - n/2.
3. If s ≈ 0, ŷ is already feasible.
4. Otherwise adjust all non‑bound entries by a common offset α:
   - find α such that Σ max(0, min(1, ŷ_i - α)) = n/2.
   - this is a monotone root‑finding problem; solve by bisection
     (the function is piecewise‑linear and decreasing).
5. Return the adjusted vector.
```

This routine runs in `O(n log n)` (due to an initial sort) and is numerically stable.

#### 3.2  Sub‑gradient of the max‑overlap function

This follows from differentiating
\(m_d = Σ h_i - Σ h_i h_{i+d}\).
