### 2. Exact projection onto the feasible set  

The feasible set is the intersection of a hyperplane and a box:

\[
\mathcal{F}=\{x\in[0,1]^N\mid \sum_i x_i = S\},\qquad S=N/2.
\]

The Euclidean projection of any vector `y` onto `𝔽` is given by the solution of  

\[

\sum_i x_i = S .

`λ` is a single scalar; it can be found by a **bisection** because  

\[

is monotone decreasing, with `φ(-∞)=N‑S>0` and `φ(+∞)=-S<0`.  
A binary search over a range `[min(y)‑1, max(y)+1]` for 40–50 iterations yields machine‑precision feasibility.

### 3. Fast evaluation of the overlap vector

### 4. Smooth surrogate of the max‑operator  

The objective `F(h)=max_k O_k` is non‑differentiable.  Replace it by a **log‑sum‑exp** (soft‑max) :

\[
F_{\alpha}(h)=\frac{1}{\alpha}\log\!\Bigl(\sum_{k} e^{\alpha O_k}\Bigr) .
\]

* For a small `α` the landscape is smooth; as `α → ∞`, `F_α → max_k O_k`.  
* Use a **schedule** `α = 2, 5, 10, 20, 50, 100` – increase `α` after the algorithm has roughly converged at the current value.  

The gradient of `F_α` is a convex combination of the gradients of the individual `O_k`:

\[
\nabla F_{\alpha}(h)=\frac{\sum_k w_k \,\nabla O_k}{\sum_k w_k},
\qquad w_k = e^{\alpha O_k}.
\]

Thus we only need the gradient of a single shift; the latter is linear and cheap to compute (see next section).

### 5. Gradient (sub‑gradient) of a single shift  

For a fixed shift `k` (with overlapping region `i=0 … N‑1‑k`)  

\[
O_k = \sum_{i=0}^{N-1‑k} \bigl(h_i - h_i h_{i+k}\bigr) .
\]

Derivative w.r.t. each component:

```
∂O_k/∂h_i =  1 - h_{i+k}      if 0 ≤ i ≤ N-1‑k
∂O_k/∂h_i = -h_{i‑k}          if k ≤ i ≤ N‑1
∂O_k/∂h_i =  0                otherwise
```

These formulas give a **sparse** gradient vector (only two contiguous blocks are non‑zero).  Computing it for all `k` costs `O(N²)` but can be reused when forming the weighted combination for the soft‑max gradient.
