C_5=\max_{k}\int_0^2 h(x)\,\bigl(1-h(x+k)\bigr)\,dx.

### 1.  Reformulation of the objective  

For a discrete vector `h` of length `n` with `dx = 2/n`  

* let `S = np.sum(h)` – this is fixed (`S = n/2` because `S·dx = 1`).  
* the correlation used by the evaluator is  

  \[
  \mathrm{corr}_k = \sum_{i=0}^{n-1} h_i\,(1-h_{i+k}) = S - \sum_{i} h_i\,h_{i+k},
  \]

  where out‑of‑range indices are treated as zero (the “full” mode of `np.correlate`).  

* Hence  

  \[
  C_5 = dx\;\bigl(S - \min_k R_k\bigr),\qquad
  R_k = \sum_i h_i\,h_{i+k}.
  \]

Minimising `C_5` is exactly the same as **maximising the smallest self‑correlation**
`R_k` over all shifts `k`.  The problem is a *max‑min* quadratic program.

---

### 2.  Smooth surrogate for the nonsmooth “minimum”

Define the *soft‑minimum* of the correlation vector `R`:

\[
\widetilde{R}(λ) = -\frac{1}{λ}\log\!\Bigl(\sum_k e^{-λR_k}\Bigr).
\]

As `λ → ∞` this converges to `min_k R_k`.  
Using the constant `S`, a smooth surrogate for `C_5` (ignoring the final `dx`) is

\[
L_λ(h)=S + \frac{1}{λ}\log\!\Bigl(\sum_k e^{-λR_k}\Bigr).
\]

For a given `λ` the function is differentiable; its gradient is cheap to evaluate
(see § 4).

We will **gradually increase λ** (annealing) so that early iterations see a
smooth landscape, while later iterations focus on the true worst shift.

### 4.  Analytic gradient of the smooth objective  

Let  

\[
R_k = \sum_i h_i\,h_{i+k}\quad\text{(zero‑padded convolution)}.
\]

Denote the soft‑weights  

\[
w_k = \frac{e^{-λR_k}}{\sum_j e^{-λR_j}}  \quad\bigl(\sum_k w_k = 1\bigr).
\]

Derivative of `R_k` w.r.t. a component `h_i`:

\[
\frac{\partial R_k}{\partial h_i}
   = h_{i+k} + h_{i-k},
\]

with the convention that out‑of‑range terms are zero.

Hence

\[
\frac{\partial L_λ}{\partial h_i}
   = \frac{1}{λ}\cdot\frac{-λ\,\sum_k e^{-λR_k}\,\frac{\partial R_k}{\partial h_i}}
                 {\sum_j e^{-λR_j}}
   = -\sum_k w_k\,(h_{i+k}+h_{i-k}).
\]

So the **descent direction** for `L_λ` is the **positive** vector

\[
g_i = \sum_k w_k\,(h_{i+k}+h_{i-k}),
\]

and a simple projected gradient step is  

```
h ← project( h + α·g )
```

with step size `α>0`.

The vector `g` can be assembled efficiently:
* Compute the weight vector `w` (length `2n‑1`) from `R`.
* Form the symmetric weight `w_sym = w + w[::-1]`.
* Convolve `w_sym` with `h` (full mode) – the central part of the convolution
  gives exactly `g`.  This uses only a single `np.convolve` per gradient evaluation and
  avoids explicit Python loops.

### 5.  Projection onto the capped simplex  

The Euclidean projection onto  

\[
\{\,0 \le x_i \le 1,\; \sum_i x_i = S\,\}
\]

has a closed‑form “water‑filling” solution:

1. Shift the variables by the lower bound: `y_i = h_i - 0` (trivial here).  
2. Find a scalar `θ` such that  

   \[
   \sum_i \operatorname{clip}(y_i+θ,\;0,\;1) = S.
   \]

Because the left‑hand side is monotone in `θ`, a **binary search** on `θ`
converges rapidly (≈50 iterations give machine precision).  
Implementation steps:
* Initialise `θ_low` and `θ_high` so that the clipped sum is respectively ≤ S
  and ≥ S (e.g. `θ_low = -1`, `θ_high = 1` and expand exponentially if necessary).
* Iterate: `θ = (θ_low+θ_high)/2`, compute clamp‑sum, tighten the interval.
* Return `h_proj = np.clip(h+θ, 0, 1)`.

The projection costs `O(n log n)` if one prefers a sorting‑based version,
but the binary‑search method is perfectly adequate for `n≈200`.
