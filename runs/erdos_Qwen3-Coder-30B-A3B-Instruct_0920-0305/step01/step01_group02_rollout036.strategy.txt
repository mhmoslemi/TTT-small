### 1.  Problem reformulation

For a fixed shift `k (≥ 0)` define  

```
O_k(h) = Σ_{i=0}^{N‑1‑k} h[i]·(1−h[i+k])
```

and for negative `k` the analogous expression.  
The objective is  

```
F(h) = max_{k∈{−(N‑1)…(N‑1)}} O_k(h)·dx .
```

Because `dx` is constant we minimise `max_k O_k(h)` and multiply by `dx` only for reporting.

The ‘max’ is non‑smooth.  To obtain a usable gradient we replace it with a **log‑sum‑exp smooth maximum**:

```
F_α(h) = (1/α)·log( Σ_k exp( α·O_k(h) ) )        (α > 0)
```

* As `α → ∞`, `F_α → max_k O_k`.  
* For moderate `α` the function is smooth, convex‑like in the region of interest and its gradient is a convex combination of the gradients of the active `O_k`.

We will increase `α` gradually (continuation) – start with a small value (e.g. `α = 0.5`) to obtain a broad basin, then raise it step‑by‑step up to a large value (`α ≈ 50‑100`) where the smoothed objective is almost the true max.

### 2.  Analytic gradient of each `O_k`

For a given shift `k ≥ 0` the overlap term is  

```
O_k = Σ_{i=0}^{N‑1‑k}   h[i]      – Σ_{i=0}^{N‑1‑k} h[i]·h[i+k] .
```

Derivative w.r.t. a component `h[j]`:

* If `0 ≤ j ≤ N‑1‑k` (j participates as the *left* index)  

  `∂O_k/∂h[j] = 1 - h[j+k]`.

* If `k ≤ j ≤ N‑1` (j participates as the *right* index)  

  `∂O_k/∂h[j] = -h[j−k]`.

* Otherwise the derivative is zero.

For a negative shift the same formula applies with the sign of `k` changed.  
All gradients are linear in `h` and can be assembled in O(N) time for a given `k`.

The gradient of the smooth objective is then

```
∇F_α(h) = Σ_k w_k(α,h)·∇O_k(h) ,   with
w_k(α,h) = exp(α·O_k(h)) / Σ_j exp(α·O_j(h)) .
```

Thus a single gradient evaluation costs O(N²) (computing all `O_k` and all `∇O_k`).

### 3.  Projection onto the feasible set

The feasible region is the **capped simplex**

```
S = { x ∈ ℝ^N : 0 ≤ x_i ≤ 1 ,   Σ_i x_i = N/2 } .
```

The Euclidean projection onto `S` has a closed‑form “water‑filling” algorithm:

1. For a given vector `y`, look for a scalar λ such that  

   `x_i(λ) = clip( y_i – λ , 0 , 1 )`  

   satisfies `Σ_i x_i(λ) = N/2`.

2. The function `g(λ) = Σ_i clip( y_i – λ , 0 , 1 )` is monotone decreasing, continuous and piecewise linear.  
   Binary‑search λ in the interval `[min(y)‑1 , max(y)+1]` until the sum constraint is met within `1e‑12`.  
   The final `x` is the required projection.

This projection respects both box bounds and the equality constraint exactly, unlike the simple scaling used previously.

We run three successive phases, each respecting the overall time limit with a watchdog.

#### Phase 1 – Smoothed gradient descent (≈60 % of budget)

For each seed:

1. Initialise `α = α_start = 0.5`.  
2. Run a **projected L‑BFGS‑B** loop (or simple projected gradient with back‑tracking line search).

   * Perform a line‑search along `-∇F_α` that respects the box constraints after a tentative step; then **project** the trial point onto `S` using the capped‑simplex routine.  
   * Accept the step if the true (non‑smoothed) max overlap `C₅` decreases or if the Armijo condition on `F_α` holds.
3. After a fixed number of successful iterations (`≈200` or when the improvement stalls), **increase `α`** (multiply by `γ = 2.0`).

#### Phase 2 – Subgradient polishing (≈30 % of budget)

The smoothed objective may leave a small residual gap between the max‐overlap and the true optimum.  In Phase 2 we perform a **projected subgradient method** directly on the true max:

1. Compute the set `K_max = {k : O_k ≈ max_j O_j}` (within a tolerance `1e‑6`).  
2. Form a subgradient as the **average** of the gradients `∇O_k` for `k ∈ K_max`.  
   (any convex combination is a valid subgradient; averaging reduces bias.)  
3. Take a step `h ← h − η·subgrad`, where `η` is a diminishing step size (`η_t = η₀ / √t`).  
4. Project back onto `S` with the capped‑simplex routine.  
5. If the true `C₅` improves, store the vector as the new best.

We run this loop until the time allocated for Phase 2 is exhausted.  Because subgradient steps are cheap, we can afford many thousands of iterations, gradually pushing the worst‐shift value down.

* Pick two indices `i, j` and a feasible transfer `Δ` (respecting bounds).  
* Evaluate the new `C₅`; accept if strictly lower, otherwise accept with a small temperature (`≈1e‑4`).  
* Occasionally (every 1000 trials) perform a *random jitter* on a handful of coordinates to escape flat plateaus.

Because the solution is already near‑optimal, only tiny improvements are possible; this phase serves as a safety net.
