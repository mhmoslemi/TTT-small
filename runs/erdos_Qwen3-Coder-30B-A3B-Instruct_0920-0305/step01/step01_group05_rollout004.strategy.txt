### 1.  Discrete formulation
* Choose an even number of sample points `n` (e.g. 60 → 100 → 150).  
* `dx = 2.0 / n`.  
* Decision vector `h ∈ ℝⁿ` must satisfy  
  - **Box**: `0 ≤ h_i ≤ 1` for all `i`  
  - **Integral**: `∑_{i=0}^{n-1} h_i = n/2` (so that the integral equals 1).  

For a shift `s ∈ {-(n‑1),…, n‑1}` define the **overlap term**

```
f_s(h) = Σ_{i} h_i · (1 – h_{i+s})               (out‑of‑range indices → 0)
```

and the quantity to minimise

```
C₅(h) = dx · max_s f_s(h) .
```

Because `dx` is a constant factor, we can drop it inside the optimisation and re‑apply it only for reporting.

---

### 2.  DC decomposition of each shift term
Rewrite

```
f_s(h) = Σ_i h_i – Σ_i h_i·h_{i+s}
       = Σ_i h_i + ½ Σ_i (h_i² + h_{i+s}²) – ½ Σ_i (h_i + h_{i+s})² .
```

* `g_s^c(h) = Σ_i h_i + ½ Σ_i (h_i² + h_{i+s}²)` – **convex** (linear + convex quadratic).  
* `g_s^d(h) = ½ Σ_i (h_i + h_{i+s})²` – **convex** (quadratic).  

Hence

```
f_s(h) = g_s^c(h) – g_s^d(h)       (difference of two convex functions).
```

### 3.  Convex‑concave (CCP) outer loop
At outer iteration `t` we have a current feasible point `h⁽ᵗ⁾`.  
For each shift `s` linearise the concave part `–g_s^d` at `h⁽ᵗ⁾`:

```
g_s^d(h) ≈ g_s^d(h⁽ᵗ⁾) + ∇g_s^d(h⁽ᵗ⁾)ᵀ·(h – h⁽ᵗ⁾) .
```

Because `g_s^d` is quadratic, its gradient is simple:

```
∂g_s^d/∂h_k = (h_k + h_{k+s}) + (h_{k-s} + h_k)   (zero where index out of range)
```

Define a scalar surrogate `τ` that bounds the worst shift:

```
τ ≥ g_s^c(h) – [ g_s^d(h⁽ᵗ⁾) + ∇g_s^d(h⁽ᵗ⁾)ᵀ·(h – h⁽ᵗ⁾) ]   ∀ s .
```

All constraints are now **convex**: `g_s^c` is a convex quadratic, the bracketed term is affine.  
The CCP sub‑problem is:

```
minimise   τ
subject to τ ≥ convex_quadratic_s(h) – affine_s(h)   ∀ s
           0 ≤ h ≤ 1
           Σ h_i = n/2 .
```

Each “convex_quadratic_s(h) ≤ …” can be expressed as a **second‑order cone (SOC)** constraint because a term of the form `½∥h∥₂²` (or with a shifted version of `h`) is SOC‑representable.  

We solve this sub‑problem with CVXPY using the ECOS (or SCS) solver. The solution yields a new feasible point `h⁽ᵗ⁺¹⁾`.  

Iterate until the change in `τ` (or in `h`) falls below a tolerance (`1e‑6`) or a maximum number of CCP iterations (e.g. 30) is reached.

### 5.  Final polishing – coordinate descent on the original max
CCP solves a convex surrogate; the final `h` may still be improvable for the true non‑convex max.  
Perform a few **coordinate‑descent sweeps**:

* For each coordinate `i` (in random order) fix all other `h_j`.  
* The objective `max_s f_s(h)` as a function of the single variable `h_i` is a piecewise‑quadratic (each `f_s` is quadratic in `h_i`).  
* Compute all breakpoints where a different shift becomes the active maximiser (there are at most `2n‑1` breakpoints).  
* Evaluate the objective at the interval minima (closed‑form for a quadratic) and at the boundaries `0` and `1`.  
* Set `h_i` to the value that yields the smallest maximal overlap, respecting the box and updating the running sum to keep the integral constraint satisfied (the sum can be maintained by adjusting a *compensating* coordinate in the same sweep).  

Do 3–5 full sweeps; each sweep costs `O(n·(2n‑1))` operations, negligible for `n ≤ 150`.

### 6.  Handling the equality constraint
The CCP sub‑problem already enforces `Σ h_i = n/2`.  
During coordinate descent we maintain feasibility by a **pair‑update**: when we change `h_i` by `Δ`, we simultaneously adjust a second coordinate `j` (chosen as a currently non‑saturated variable) by `‑Δ` and clamp both to `[0,1]`. This preserves the sum exactly without a separate projection step.
