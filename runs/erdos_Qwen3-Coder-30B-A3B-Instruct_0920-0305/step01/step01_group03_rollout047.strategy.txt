### Overview
The task is to construct a step‑function `h` on `[0,2]` (discretised on a uniform grid) that satisfies  

* **Box constraints** `0 ≤ h[i] ≤ 1`  
* **Mass constraint** `∑_i h[i]·dx = 1` (equivalently `∑_i h[i] = n/2` for `dx = 2/n`)  

and minimises  

\[
C_{5}(h)=\max_{k}\int_{0}^{2}h(x)\bigl(1-h(x+k)\bigr)dx
        = 1-\min_{k}\int_{0}^{2}h(x)h(x+k)dx .
\]

The integral is evaluated by a full‑mode correlation of the discrete vector `h` with `1‑h`.  

The following plan solves the problem **without using the raw SLSQP/min‑max formulation** that was employed previously.  
It combines three *orthogonal* ideas:

1. **Combinatorial Global Search** – a simulated‑annealing / swap‑based optimisation on *binary* (0/1) vectors, which directly maximises the worst discrete auto‑correlation.  
2. **Continuous Refinement** – a projected‑gradient method on a *smooth soft‑minimum* surrogate, starting from the best binary pattern and allowing fractional heights.  
3. **Majorisation‑Minimisation (MM) polishing** – a sequence of linear programmes that linearise the bilinear terms around the current iterate, guaranteeing a monotone decrease of the true max‑objective.

All three stages respect the box and mass constraints by a *water‑filling projection* onto the capped simplex.  The stages are run sequentially, each receiving a fixed portion of the total time budget, with early‑exit checks that stop as soon as a bound below the target (≈ 0.3807) is obtained.

### 2. Feasibility projection – capped‑simplex water filling
Given a raw vector `z ∈ ℝⁿ`, the projection onto  

\[
\mathcal{F}=\Bigl\{h\;|\;0\le h_i\le1,\;\sum_i h_i=S\Bigr\}
\]

is the unique `h = clip(z+τ,0,1)` where the scalar `τ` is chosen so that the sum equals `S`.  
`τ` is obtained by a monotone binary search:

1. Initialise lower/upper bounds for `τ` (e.g. `-2` and `+2`).  
2. Repeatedly evaluate `f(τ)=∑_i clip(z_i+τ,0,1)`.  
3. Shrink the bracket until `|f(τ)-S|≤10⁻¹²`.  

Because `f` is piecewise linear and strictly increasing, convergence is guaranteed in ≤ 60 iterations.  
All stages invoke this projection after any update of `h`.

### 3. Stage A – Binary simulated‑annealing (global combinatorial search)

#### 3.1 Representation
A binary vector `b ∈ {0,1}ⁿ` with exactly `S` ones (the constraint `∑b=S` is enforced by construction).

#### 3.2 Objective for binaries
For a binary vector the overlap integral simplifies to a **counting problem**:

\[
R(s)=\sum_{i} b_i\,b_{i+s}\;dx ,\qquad 
C_{5}(b)=1-\min_s R(s) .
\]

The correlation `R(s)` is obtained by `np.correlate(b,b,"full")` multiplied by `dx`.  
The worst shift is the one with the smallest count of coincident ones.

#### 3.3 Move set
A move consists of swapping a **1‑position** `i₁` with a **0‑position** `i₀`.  
The swap preserves the cardinality automatically.

#### 3.4 Acceptance rule (simulated annealing)
* Compute `Cold = C5(b)` (full max‑objective).  
* Perform the swap → candidate `b'`.  
* Compute `Cnew = C5(b')`.  
* If `Cnew < Cold` accept unconditionally.  
* Otherwise accept with probability `exp(-(Cnew‑Cold)/T)`, where `T` is the current temperature.

#### 3.5 Temperature schedule
Start with `T₀ = 0.05` (≈ 5 % of the typical C5 magnitude) and multiply by a cooling factor `γ = 0.995` after every 200 accepted/rejected proposals.  
Terminate the annealing when either  
* the temperature falls below `10⁻⁶`, **or**  
* a time limit of `0.35·budget_s` seconds is reached.

#### 3.6 Restarts and seeding
* Perform **10 independent runs** (different random seeds).  
* In addition to a purely random start, include **structured seeds** derived from known combinatorial constructions:  
  * **Cyclic difference‑set approximations** – for `n` that are multiples of a prime power `q`, take the characteristic vector of the Singer set in `ℤ_{q²+q+1}` truncated to length `n`.  
  * **Upsampled initial solution** – linearly interpolate the provided `initial_h_values` (length 42) to `n=200` and then threshold at 0.5 to obtain a binary pattern.  

Each run records the binary vector with the smallest observed `C5`.  The best binary pattern `b*` is kept for the next stage.

### 4. Stage B – Continuous annealed projected‑gradient on a soft‑minimum surrogate

Having a high‑quality binary pattern, we now allow fractional heights to possibly lower the true max‑objective.

#### 4.1 Soft‑minimum formulation
Define the correlation vector (raw, without `dx`)  

\[
R(s)=\sum_i h_i h_{i+s}.
\]

For a temperature parameter `λ>0` introduce  

\[
\Phi_{\lambda}(h)=\frac{1}{\lambda}\log\!\Bigl(\sum_{s}e^{-\lambda R(s)}\Bigr) .
\]

`Φ_λ` is a **smooth convex approximation** of `\min_s R(s)`.  Minimising `Φ_λ` is equivalent to minimising the original `C5` up to the additive constant `∑h_i` (which is fixed).  

#### 4.2 Gradient of the surrogate
Let  

\[
w_s=\frac{e^{-\lambda R(s)}}{\sum_t e^{-\lambda R(t)}} .
\]

Then  

\[
\frac{\partial\Phi_{\lambda}}{\partial h_j}
   =-\sum_{s} w_s\bigl(h_{j+s}+h_{j-s}\bigr).
\]

Thus the **descent direction** is  

\[
g_j=\sum_{s} w_s\bigl(h_{j+s}+h_{j-s}\bigr)\;.
\]

The contributions are computed with zero‑padding; a simple double‑loop using NumPy slices (or a single convolution with `w+w[::-1]`) yields `g` in < 0.5 ms per iteration for `n=200`.

#### 4.3 Step size and line search
* Begin each iteration with a trial step `α = α₀` (e.g. `α₀ = 0.1`).  
* Propose `h' = h + α g`.  
* Project `h'` onto `𝔽` using the water‑filling routine.  
* Evaluate the surrogate `Φ_λ(h')`.  
* If `Φ_λ(h') ≤ Φ_λ(h)` accept, otherwise halve `α` and retry (max 5 halvings).  

If after 5 halvings the surrogate has not decreased, keep `h` unchanged and proceed to the next iteration (this prevents stagnation).

#### 4.4 λ‑annealing schedule
Run the gradient loop in **four phases**, each phase increasing `λ` by a factor ≈ 3:

| Phase | λ | α₀ | Iterations |
|-------|---|-----|------------|
| 1 (smooth) | 0.5 | 0.2 | 150 |
| 2 (medium) | 2   | 0.1 | 200 |
| 3 (focused) | 8   | 0.05 | 250 |
| 4 (sharp)   | 32  | 0.02 | 300 |

After each phase, recompute the exact `C5` (using the true max‑objective) and keep the best vector observed.  The total number of gradient steps ≈ 900, comfortably fitting into the remaining time budget after Stage A.

#### 4.5 Symmetrisation (optional but effective)
After each projection, enforce mirror symmetry:

\[
h_i \leftarrow \frac{h_i+h_{n-1-i}}{2},
\]

then re‑project.  All known near‑optimal constructions are symmetric about `x=1`; imposing symmetry reduces the search space and empirically accelerates convergence.

### 5. Stage C – Majorisation‑Minimisation (MM) polishing on the exact max‑objective

The gradient stage may stop at a point that is only locally optimal for the surrogate.  To guarantee a monotone improvement of the **true** max objective we apply an MM scheme:

1. **Current worst shift** – compute the set `S* = {s | C5 = ∑_i h_i (1‑h_{i+s})}` (normally one or a few shifts).  
2. **Linearisation** – for each `s∈S*` the bilinear term `h_i h_{i+s}` is linearised around the current `h`:

   \[
   h_i h_{i+s} \approx h_i^{\text{old}}h_{i+s} + h_{i+s}^{\text{old}}h_i - h_i^{\text{old}}h_{i+s}^{\text{old}} .
   \]

   Substituting this into the expression for `C5` yields a **linear** objective in the variables `h_i`.  
3. **Linear programme** – minimise the linearised upper bound subject to the box and mass constraints.  Solve with `scipy.optimize.linprog` (highly efficient for `n=200`).  
4. **Update** – set `h ← h_{\text{LP}}`.  
5. **Repeat** – recompute the exact `C5`. If it has decreased, continue; otherwise stop (typically after ≤ 10 cycles).

Because each LP solves a convex relaxation of the true non‑convex problem, this step never increases `C5` and usually provides the final few‑digit improvement needed to cross the target bound.
