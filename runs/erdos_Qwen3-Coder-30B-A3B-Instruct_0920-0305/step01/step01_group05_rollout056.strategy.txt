   ```
       constraints += [t >= n/2 - cp.sum(cp.multiply(shift_mat, X))]
   ```

**Goal** – Produce a step‑function `h` on `[0,2]` (sampled at `n` points, `dx=2/n`) satisfying

```
f_s(h) = Σ_i h_i ( 1 – h_{i+s} )               (out‑of‑range indices are 0)
```

The new method is a **convex semidefinite relaxation + randomized rounding**, a completely different paradigm from the evolutionary / p‑norm / DC‑CCP schemes previously used.

---

### 1. Lifting the bilinear terms

Introduce a symmetric matrix `X ∈ ℝ^{n×n}` meant to capture the pairwise products

```
X_{ij} ≈ h_i * h_j .
```

If `h` were binary, the exact relationship would be `X = h h^T`, which satisfies the *McCormick envelope*:

```
0 ≤ X_{ij} ≤ h_i ,   0 ≤ X_{ij} ≤ h_j ,   X_{ij} ≥ h_i + h_j – 1 .
```

These are linear constraints; together with `X ⪰ 0` (PSD) they form a tight convex relaxation of the binary product.

---

### 2. Expressing the overlap in lifted variables

For a shift `s ≥ 0` the overlap term is

```
f_s(h) = Σ_i h_i – Σ_i h_i h_{i+s}
       = (Σ_i h_i) – Σ_i X_{i,i+s} .
```

Because `Σ_i h_i = n/2` is a constant, each `f_s` becomes an **affine function** of the entries of `X`.  
Define an epigraph variable `t` that bounds the worst shift:

```
t ≥ n/2 – Σ_i X_{i,i+s}      for every shift s ≠ 0 .
```

Minimising `t` therefore minimises the maximal overlap (up to the factor `dx` that will be applied later).

---

### 3. Full SDP formulation

Variables  
* `h ∈ ℝ^n` (continuous, box‑bounded)  
* `X ∈ ℝ^{n×n}` (symmetric PSD)  
* `t ∈ ℝ` (scalar, t ≥ 0)

Constraints  

| Type | Expression |
|------|------------|
| Box | `0 ≤ h_i ≤ 1` for all `i` |
| Integral | `Σ_i h_i = n/2` |
| Diagonal consistency | `diag(X) = h` |
| PSD | `X ⪰ 0` |
| McCormick (for every `i < j`) | `X_{ij} ≥ 0`, `X_{ij} ≤ h_i`, `X_{ij} ≤ h_j`, `X_{ij} ≥ h_i + h_j – 1` |
| Overlap epigraph (for each shift `s ≠ 0`) | `t ≥ n/2 – Σ_i X_{i,i+s}` |

Objective  

```
minimise   t .
```

All constraints are linear except the PSD cone, so the problem is a **semidefinite program (SDP)**.

---

### 4. Solving the SDP

* Choose a modest grid size (e.g. `n = 80` → `dx = 0.025`).  
* Build the shift‑extraction matrices `E_s` with ones on the `(i,i+s)` positions (zero elsewhere).  
* Encode the model in **CVXPY** and solve with a conic solver that handles PSD cones – `SCS` (first‑order, fast) or `ECOS` if higher accuracy is needed.  
* Use a tolerable accuracy (`eps≈1e‑5`, `max_iters≈5000`). The solver typically finishes within ≤ 60 s for `n=80`.  

The optimal value `t*` is a **lower bound** on the true `max f_s`. The corresponding bound on `C5` is

```
C5_lower = dx * t* .
```

---

### 5. Extracting a feasible `h` – Randomised rounding

The SDP solution gives us a feasible pair `(ĥ, X̂)`.  To obtain an actual step‑function we **sample** from the covariance `X̂`.

1. **Eigen‑decompose** `X̂ = V Λ V^T`. Keep only eigenvalues `λ_k > 0`. Form `B = V √Λ`.  
2. Draw a standard normal vector `g ∈ ℝ^r` (where `r` = rank of `X̂`). Set  

```
z = B g    (so  E[zz^T] = X̂ ).
```

3. Clip to the box: `z = clip(z, 0, 1)`.  
4. Enforce the integral constraint by **projection onto the hyperplane** `Σ z_i = n/2` while staying inside `[0,1]`:
   * Find a scalar `α` such that `y = clip(z + α·1, 0, 1)` satisfies the sum exactly.
   * Because the sum after clipping is a monotone decreasing function of `α`, a short bisection (∼30 iterations) yields the required `α`.  
   * The resulting vector `h_candidate` is feasible.

5. **Evaluate** `C5` for this candidate using the provided `evaluate_h`.  
6. **Repeat** the sampling step many times (e.g. 2000 draws) and keep the best candidate.  

Because the relaxed feasible set contains the convex hull of all binary vectors, this rounding strategy often lands very close to the SDP optimum.

---

### 6. Deterministic rounding (binary fallback)

A cheap deterministic alternative: take the diagonal values `ĥ_i = diag(X̂)_i` (which lie in `[0,1]`), set the largest `n/2` of them to `1` and the rest to `0`.  
If the resulting vector violates the exact count (due to ties), swap a few entries to restore `∑h = n/2`.  
Evaluate this binary vector; it provides a baseline that can be further improved by local swaps (see §8).
