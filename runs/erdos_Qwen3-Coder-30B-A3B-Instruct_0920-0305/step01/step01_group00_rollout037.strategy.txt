### 1.  High‑level idea  
Replace the purely local SLSQP search with **a convex relaxation + randomized rounding pipeline**.  
The quadratic term \(\int h(x)h(x+k)\) can be written as a linear functional of the lifted matrix \(X = hh^{\top}\).  
By relaxing the rank‑1 requirement we obtain a **semidefinite program (SDP)** that yields a provable lower bound on the optimum.  
A feasible step‑function is then extracted from the SDP solution by **spectral or Gaussian rounding**, optionally followed by a short local refinement.  
Because the SDP is convex, the search does not get trapped in local minima and the bisection on the target constant provides a systematic way to shrink the bound.

### 2.  Discretisation  
* Choose a modest number of grid points \(n\) (e.g. \(80\le n\le 110\)).  
* Grid spacing \(dx = 2/n\).  
* The integral constraint becomes \(\sum_{i=1}^{n} h_i = n/2\).  

All subsequent matrices are built on this discrete set.

### 3.  Shift‑product matrices  
For each integer shift \(s\in\{-\,n+1,\dots ,n-1\}\) define the **Toeplitz matrix** \(A^{(s)}\in\mathbb{R}^{n\times n}\) by  

\[
A^{(s)}_{i,j}=\begin{cases}
1 & \text{if } j=i+s\text{ and }1\le i,i+s\le n,\\[4pt]
0 & \text{otherwise.}
\end{cases}
\]

Then  

\[
\sum_{i=1}^{n} h_i h_{i+s}= \operatorname{tr}\bigl(A^{(s)}X\bigr),\qquad X = hh^{\top}.
\]

The (unscaled) overlap for shift \(s\) is  

\[
C_s(h)=\sum_i h_i -\sum_i h_i h_{i+s}= \frac{n}{2} - \operatorname{tr}\bigl(A^{(s)}X\bigr).
\]

### 4.  SDP formulation with a target bound  

Introduce a scalar variable \(t\) intended to be an **upper bound on the overlap**.  
For a given candidate \(t\) we ask whether a feasible \(h\) exists such that all overlaps satisfy \(C_s(h)\le t\).  
Using the lifted matrix this becomes the feasibility SDP  

\[
\begin{aligned}
\text{find } & h\in\mathbb{R}^n,\; X\in\mathbb{S}^n\\[2pt]
\text{s.t. } &
\begin{cases}
\displaystyle X \succeq 0,\\[4pt]
X_{ii}=h_i\quad (i=1,\dots,n),\\[4pt]
0\le h_i\le 1,\qquad \sum_i h_i = n/2,\\[4pt]
\displaystyle \operatorname{tr}\bigl(A^{(s)}X\bigr)\;\ge\; \frac{n}{2}-t
\quad\text{for all }s.
\end{cases}
\end{aligned}
\]

The constraints are linear in \((h,X)\) except for the PSD cone, so the problem is an SDP.

### 5.  Bisection on the bound  

* Initialise a bracketing interval \([t_{\text{low}},t_{\text{high}}]\).  
  * \(t_{\text{low}} = 0\).  
  * \(t_{\text{high}} = 1\) (the trivial upper bound).  

* While the interval width exceeds a tolerance (e.g. \(10^{-4}\)) and time budget permits:  

  1. Set \(t = (t_{\text{low}}+t_{\text{high}})/2\).  
  2. Solve the feasibility SDP for this \(t\) using **cvxpy** with an SDP solver (SCS, ECOS, or MOSEK if available).  
  3. If the solver reports *feasible* (allow a small numerical slack \(\varepsilon\approx10^{-6}\) on the shift constraints), set \(t_{\text{high}}\leftarrow t\) and **store** the returned \((h^{\star},X^{\star})\) as the current best feasible pair.  
  4. Otherwise set \(t_{\text{low}}\leftarrow t\).  

The bisection converges to the smallest \(t\) for which the SDP is feasible, yielding a **lower bound** on the true optimum.  The stored pair \((h^{\star},X^{\star})\) produced at the last feasible step is ready for rounding.

### 6.  Extracting a concrete step function  

The SDP solution typically does **not** satisfy the rank‑1 condition \(X = hh^{\top}\).  Two practical rounding schemes are:

#### 6.1 Spectral rounding  
* Compute the eigen‑decomposition of \(X^{\star}\).  
* Let \(v\) be the eigenvector associated with the largest eigenvalue \(\lambda_{\max}\).  
* Form a candidate vector \(\tilde h = \sqrt{\lambda_{\max}}\,v\).  
* Clip \(\tilde h\) to \([0,1]\) and project it onto the capped simplex \(\{h:0\le h_i\le1,\;\sum h_i = n/2\}\) (the same projection used in many other constrained problems).  
* Evaluate the true overlap \(C_5(\tilde h)\); keep the candidate if it improves the current best bound.

#### 6.2 Gaussian (random) rounding  
* Sample a Gaussian vector \(g\sim\mathcal N(0,X^{\star})\); equivalently compute \(g = Lz\) where \(L\) is a Cholesky factor of \(X^{\star}\) and \(z\) is standard normal.  
* Clip and project \(g\) exactly as above.  
* Repeat the sampling many times (e.g. 200–500 draws) and retain the sample with the smallest measured \(C_5\).  

Both methods are inexpensive; the Gaussian approach often finds a better feasible point because it explores the entire feasible ellipsoid rather than a single direction.

### 7.  Local polishing (optional)

Take the best rounded vector \(\hat h\) and run a **few iterations of a deterministic local optimiser** to fine‑tune it:

* Use **SLSQP** (or L‑BFGS‑B) with the original constraints (bounds and equality).  
* Initialise with \(\hat h\).  
* Limit the optimiser to a small budget (e.g. 200 iterations) so that it does not dominate the total runtime.  

Because the rounded point already lies near a low‑overlap region, local polishing typically yields a modest additional improvement without risk of falling back to a worse local minima.

### 10.  Summary of the algorithmic pipeline  

1. **Discretise** the interval with \(n\) points, compute the shift matrices \(A^{(s)}\).  
2. **Bisection** on the overlap bound \(t\); each iteration solves the **feasibility SDP** described in §4.  
3. When the SDP declares *feasible*, **store** the solution \((h^{\star},X^{\star})\) and tighten the upper bound.  
4. After the bisection finishes, **round** the last feasible SDP solution:  
   - Spectral rounding **or** extensive Gaussian rounding (300–500 draws).

   - Keep the sample with the smallest evaluated \(C_5\).  
5. **Polish** that best sample with a few iterations of SLSQP (or L‑BFGS‑B) while preserving bounds.  
6. **Return** the final step‑function values (as a Python list), the measured constant \(C_5\), and the chosen grid size \(n\).
