### 1.  Re‑parameterise the step function  

Instead of optimising a full‑length vector `h[0…n‑1]`, describe the function as a **small collection of weighted intervals** (rectangular pulses):

```
h(x) = Σ_{j=1}^{m} a_j · 1_{[L_j , R_j)}(x) ,
    a_j ∈ [0,1]  (height),
    L_j ≥ 0 , R_j ≤ 2 , L_j < R_j (interval ends),
    ℓ_j = R_j – L_j   (length).
```

The integral constraint becomes  

```
Σ_{j=1}^{m} a_j · ℓ_j = 1 .                         (1)
```

Choosing a modest number of intervals (e.g. `m = 6…8`) reduces the problem to at most `3·m` continuous variables while preserving the ability to form highly non‑trivial shapes (overlaps of intervals give intermediate heights between 0 and 1).

### 2.  Exact evaluation of the worst overlap  

For a given set of intervals the auto‑correlation  

```
S_k = ∫_0^2 h(x)·h(x+k) dx
```

is a **piecewise‑linear function of the shift k**.  
If `I_i = [L_i,R_i)` and `I_j = [L_j,R_j)`, the contribution of the pair `(i,j)` at shift `k` is  

```
a_i·a_j·overlap(I_i , I_j – k) ,
overlap = max(0, min(R_i , R_j−k) – max(L_i , L_j−k)).
```

Consequently the total overlap for a given `k` is a sum of `m²` such terms.  
The function changes its slope only when an endpoint of a shifted interval aligns with an endpoint of another interval. Hence **the set of candidate shifts where a maximum can occur is finite**:

```
K = { L_i – L_j , L_i – R_j , R_i – L_j , R_i – R_j }   for all i,j
    ∪ {0 , 2} .
```

`|K| ≤ 4·m² + 2`.  
Evaluating `S_k` for every `k ∈ K` gives the exact value of  

```
C₅ = max_k ( 1 – S_k ) .
```

The cost of one objective evaluation is only `O(m²)` (a few dozen elementary operations for `m≈6`).

### 3.  Global optimisation on the low‑dimensional space  

Because the search space is tiny, we can afford a **global, population‑based optimiser** that does not rely on gradients:

* **Differential Evolution (DE)** (available in `scipy.optimize`).  
* **Bounds**:  
  - `a_j ∈ [0,1]`  
  - `L_j ∈ [0,2]`  
  - `ℓ_j ∈ [0,2]` with the additional hard constraint `L_j + ℓ_j ≤ 2`.  

DE works only with box constraints; all other constraints are enforced by a **repair step** after each candidate is generated:

1. **Clamp** `a_j` to `[0,1]`, `ℓ_j` to `[0,2]`.  
2. **Clamp** `L_j` to `[0, 2−ℓ_j]`.  
3. **Scale the heights** to satisfy (1): let `s = Σ a_j·ℓ_j`.  
   Replace `a_j ← a_j / s` (preserving the relative heights) and, if any `a_j` exceeds 1 after scaling, clip it and recompute `s` iteratively until the equality holds.  
   This is a tiny version of the binary‑search projection used in the previous code.

The repaired vector is then fed to the **exact overlap evaluator** of §2, which returns the true `C₅`. DE explores the whole feasible region and, because each evaluation is cheap, can perform **tens of thousands of generations** well inside the 600 s budget.

### 4.  Local refinement  

After DE finishes, take its best individual and run a **local optimiser** (`scipy.optimize.minimize` with `method='Nelder‑Mead'` or `trust‑constr`).  
The local optimiser works directly on the raw parameters (`a_j , L_j , ℓ_j`) and, after each trial, applies the same repair routine to stay feasible.  
Finite‑difference gradients are cheap because the objective is `O(m²)`.

### 5.  Rasterisation to a high‑resolution grid  

Once a high‑quality set of intervals is obtained, translate it to a discrete array of length `n` (e.g. `n = 256` or `512`):

```
h_grid[i] = Σ_j a_j  if  x_i ∈ [L_j , R_j)   else 0 .
```

Here `x_i = i·dx` with `dx = 2/n`.  
If multiple intervals overlap, their heights simply add (still ≤ 1 because the optimisation respected (1) and the box constraints).  

After rasterisation:

1. Clip `h_grid` to `[0,1]`.  
2. Apply the **sum‑box projection** (binary search on a scalar λ) to enforce `Σ h_grid = n/2` exactly (this corrects the minute numerical drift caused by discretisation).

### 6.  Grid‑level fine‑tuning (optional but powerful)  

The rasterised vector is now a feasible high‑resolution step function.  
To clean up any artefacts introduced by discretisation, run a **few thousand iterations of the soft‑minimum gradient ascent** described in the earlier “log‑sum‑exp” approach:

* Use the smooth surrogate `G_α(h) = -(1/α) log Σ_k exp(-α·S_k(h))`.  
* Compute its gradient via a single convolution (`O(n log n)`).  
* Take a small step, project back onto the bounded simplex, and gradually increase `α`.  

Because the starting point is already extremely good, only a handful of iterations are needed to push the bound a little further, typically below the target `0.3807`.

### 7.  Final polishing with a constrained local optimiser  

With ≤ 5 % of the time budget remaining, invoke **SLSQP** (or `trust-constr`) on the *grid* vector:

* Variables: the `n` entries of `h_grid`.  
* Objective: exact `C₅` (computed by the FFT‑based correlation routine used by the judge).  
* Bounds: `0 ≤ h_i ≤ 1`.  
* Equality: `Σ h_i = n/2`.  

The optimiser starts from the fine‑tuned vector, respects all constraints, and usually converges in a few hundred iterations, delivering the final very‑low `C₅` value.
