### 1.  Reformulation in the frequency domain  

For a discretised step‑function  
`h = (h₀,…,h_{n‑1})` on `[0,2]` we have  

```
C₅(h) = max_k  ∫₀² h(x)·(1‑h(x+k))dx
       = 1 – min_k  S_k(h) ,      S_k(h)=∫₀² h(x)h(x+k)dx .
```

`S_k` is the (zero‑padded) auto‑correlation of `h`.  
With the discrete Fourier transform (DFT) of the zero‑padded vector  

```
h̃ = [h₀,…,h_{n‑1},0,…,0]   (length L = 2n‑1)
H = FFT(h̃)      (complex, length L)
```

the auto‑correlation is the inverse DFT of the power spectrum  

```
S = IFFT(|H|²) .
```

Thus the shape of `|H|` controls the whole set `{S_k}`.  
If the non‑DC part of `|H|` is made **as flat as possible**, the corresponding
non‑zero lags of `S` become almost equal, i.e. the worst overlap is pushed down.

### 2.  Target spectral shape  

Let  

```
P = |H|²                     # current power spectrum (real, non‑negative)
γ = min_{k ≠ 0} S_k          # current worst auto‑correlation
```

A perfectly flat spectrum for the off‑DC frequencies would give a constant
value  

```
P_target = ( Σ_{ℓ≠0} P_ℓ ) / (L‑1) .
```

Because the total energy Σℓ P_ℓ = Σ_i h_i² is fixed (by the current `h`),
`P_target` is simply the mean of the off‑DC powers.  
If we replace the off‑DC part of `P` by this mean, the new inverse DFT will be
a flat “sidelobe” level.

### 3.  Alternating‑projection (Gerchberg–Saxton‑style) algorithm  

We will iterate between two constraint sets:

* **Spectral flatness set** – the off‑DC magnitude must equal `√P_target`

* **Time‑domain feasibility set** – `0 ≤ h_i ≤ 1` and Σh_i = n/2.

   ```

   ```
