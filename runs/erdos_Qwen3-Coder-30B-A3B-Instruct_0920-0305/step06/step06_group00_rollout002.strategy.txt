**Overall picture**  
We must minimise  

\[
C_5(h)=\frac{2}{n}\max_{\ell\in\{-(n-1),\dots ,n-1\}}
\operatorname{corr}_\ell\bigl(h,\,1-h\bigr),\qquad
\sum_{i=0}^{n-1}h_i=\frac{n}{2},\;\;0\le h_i\le1 .
\]

The difficulty is the *max* over the \(2n-1\) lags, which makes the problem
non‑smooth and non‑convex.  The previous code attacked it by a handcrafted
local search that repeatedly recomputed the full correlation with
`np.correlate`.  The new plan replaces that by a **smooth‑max gradient
descent** backed by fast FFT‑based convolutions, enriches the search with
multiple, qualitatively different initialisations, and finishes with a
binary‑only hill‑climbing/annealing phase.  All steps are lightweight
enough to stay well within the 600 s budget while using modest sample

### 1. Discretisation choice

* **Base resolution** – start with \(n=200\) (grid spacing \(\Delta x=0.01\)).
  At this size the FFT of length \(2n\) is negligible (sub‑millisecond)

### 2. Fast correlation primitive

All objective‑related quantities are expressed through the *zero‑padded*
cross‑correlation  

\[
c = \operatorname{corr}(h,\,1-h)
\]

which can be evaluated in \(O(n\log n)\) by an FFT of length \(2n\):

```
c = ifft( fft(h,2n) * conj(fft(1-h,2n)) ).real[:2n-1]
```

The maximum lag value is `c.max()*Δx`.  This routine will be used everywhere
(evaluation, gradient, binary swaps).

--------------------------------------------------------------------
### 3. Smooth‑max (soft‑max) surrogate

Define the *soft‑max* with temperature parameter \(\alpha>0\):

\[
S_\alpha(h)=\frac{\sum_{\ell} e^{\alpha c_\ell}\,c_\ell}
                {\sum_{\ell} e^{\alpha c_\ell}} .
\]

For \(\alpha\to\infty\) we recover the true max.  For moderate \(\alpha\)
the function is smooth, has a well‑defined gradient and is amenable to
projected gradient descent.

--------------------------------------------------------------------
### 4. Gradient of the surrogate (vectorised)

For a single lag \(\ell\)

\[
\frac{\partial c_\ell}{\partial h_i}
     = (1-h_{i+\ell}) - h_{i-\ell} \quad(\text{out‑of‑range}=0).
\]

Let \(\omega_\ell\) be the soft‑max weights

\[
\omega_\ell =\frac{e^{\alpha c_\ell}}{\sum_m e^{\alpha c_m}} .
\]

Then the gradient of \(S_\alpha\) is

\[
\nabla S_\alpha(i)=\sum_{\ell}\omega_\ell\bigl[(1-h_{i+\ell})-h_{i-\ell}\bigr].
\]

**Vectorised computation** – the two sums are ordinary convolutions:

* forward term   \(F_i=\sum_{\ell}\omega_\ell\,h_{i+\ell}\)  
  = convolution of `h` with the weight vector `ω` (zero‑padded).
* backward term  \(B_i=\sum_{\ell}\omega_\ell\,h_{i-\ell}\)  
  = convolution of `h` with the *reversed* weight vector `ω[::-1]`.

Thus

```
grad = 1.0 - forward_convolution - backward_convolution
```

Both convolutions are performed with the same FFT primitive used for the
correlation, so a full gradient evaluation costs only a few FFTs (≈ 3).

--------------------------------------------------------------------
### 5. Projection onto the feasible set

After every gradient step we must enforce

* box constraints `0 ≤ h_i ≤ 1`,
* the linear equality `∑ h_i = n/2`.

Both are satisfied by the classic *water‑filling* projection:

1. Find a scalar λ such that `clip(h+λ,0,1)` has the required sum.
2. Solve for λ with a binary search (≈ 60 iterations guarantees double‑precision
   accuracy).  The operation is `O(n)`.

The projection is applied after each trial update; it is cheap compared with
the FFT work.
