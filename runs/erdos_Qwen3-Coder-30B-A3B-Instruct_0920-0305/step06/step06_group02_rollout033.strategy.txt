**Goal** – produce a binary (0/1) step function `h` on `[0,2]` (discretised with `n` points, `∑h = n/2`) that maximises the *minimum* self‑overlap  
\[
\min_{k}\;\sum_{i}h_i\,h_{i+k}
\]
and therefore minimises the Erdős overlap constant  
\(C_5 = \max_k\bigl(\frac{n}{2}-\sum_i h_i h_{i+k}\bigr)\,dx\).

The plan consists of three complementary phases that together stay well within the 600 s budget and use ≤ 120 sample points (the current record). All phases share a fast *incremental* update of the correlation array, turning a single 1↔0 swap into an **O(n)** operation rather than an O(n log n) FFT recomputation.

### 1. Mathematical preparation

1. **Binary restriction** – In the continuous Erdős problem the extremal sets are characteristic functions of measurable subsets, i.e. `h∈{0,1}` a.e.  Working with binary vectors therefore does not exclude the optimum and dramatically simplifies the combinatorial structure.

2. **Correlation representation** –  
   *Full* linear correlation of `h` with itself is  
   \[
   \text{corr}[s] = \sum_{i} h_i\,h_{i+s},\qquad s\in\{-(n-1),\dots,n-1\},
   \]
   stored in an array `C` of length `2n‑1`.  The objective value is
   \[
   C_5 = \bigl(\tfrac{n}{2} - \min_s C[s]\bigr)\,dx .
   \]

3. **Swap effect** – Swapping a `1` at index `i` with a `0` at index `j` only changes those entries of `C` that involve `i` or `j`.  
   For every current `1`‑position `p` we have ordered pairs `(p,i)` and `(i,p)`.  Removing `i` subtracts `1` from `C[p-i]` and (if `p≠i`) from `C[i-p]`.  Adding `j` performs the opposite addition.  Because there are exactly `w=n/2` ones, a swap updates at most `2·w≈n` entries – a cheap O(n) operation.

---

### 2. Core optimizer – “worst‑shift targeted swapping”

The optimizer works *directly* on the min‑overlap objective.

1. **Initialisation** – Generate several diverse binary vectors:
   - Uniform random choice of `n/2` ones.
   - Thresholded version of the best continuous solution already known (`h>0.5` → 1).
   - Simple periodic patterns (e.g. blocks `11110000…`) as seeds.

2. **Pre‑compute** – For each seed compute the full correlation `C` (via `np.correlate`) and store the list `ones = {i | h_i=1}`.

3. **Greedy improvement loop** (repeat until stagnation):
   - Find the *worst* shift `s* = argmin C`.  This is the shift with the smallest overlap.
   - Identify **deficient** 1‑positions  
     `A = { i∈ones | i+s* < n and h_{i+s*}=0 }`.  
     (These 1’s do not contribute to the overlap at `s*`.)
   - Identify **beneficial** 0‑positions  
     `B = { j∉ones | j+s* < n and h_{j+s*}=1 }`.  
     (Placing a 1 at `j` would create a new overlapping pair for `s*`.)
   - If both `A` and `B` are non‑empty, pick a random pair `(i,j)∈A×B` and **swap** them.
     * The incremental update described above modifies `C` and `ones` in O(n) time.
     * After the swap `C[s*]` increases by exactly 1, so `min(C)` cannot decrease.
   - If no such pair exists for the current worst shift, move to the *second* worst shift and repeat.  
   - If no improving swap exists for any shift, exit the greedy phase (local optimum reached).

   This greedy rule guarantees that each successful move strictly raises the minimum overlap, i.e. strictly lowers `C_5`.

4. **Escaping plateaux** – When the greedy phase stalls:
   - Perform a **random perturbation**: choose `k∈{2,3,4}` disjoint 1↔0 swaps at random, apply them (updating `C` incrementally), and resume the greedy phase.
   - Keep the perturbation only if it eventually yields a lower `C_5`; otherwise revert.
   - Limit the number of perturbations per restart (e.g. ≤ 30) to bound runtime.

5. **Recording the best** – After each restart (or after a successful perturbation) compute the current bound  
   `c5 = (n/2 - C.min()) * dx`.  
   Keep the globally best `(h, c5)` seen so far.

Because each successful swap improves the bound by at least `dx` (≈ 0.0167), a modest number of swaps (≈ 20–30) can already push the bound from 0.38 toward 0.379. The greedy nature ensures rapid convergence, while random perturbations avoid getting trapped in sub‑optimal basins.

### 3. Global exploration – Simulated‑Annealing layer

Once the greedy search has exhausted all cheap restarts, launch a **simulated‑annealing (SA)** pass seeded with the best binary vector found so far:

1. **State** – current binary vector, correlation array `C`, and `min_overlap = C.min()`.
2. **Temperature schedule** – geometric cooling: `T = T0 * α^t`, with `T0≈1.0` (in units of “overlap count”) and `α≈0.995`.  The schedule runs for a pre‑determined wall‑time slice (≈ 120 s).
3. **Proposal** – random 1↔0 swap (same O(n) update as above).
4. **Acceptance** – compute `Δ = new_min_overlap - min_overlap`.  
   - If `Δ>0` accept (improvement).  
   - Otherwise accept with probability `exp(Δ / T)`.  
   This allows occasional temporary degradations that help escape shallow local minima.
5. **Book‑keeping** – whenever a new state yields a smaller `C_5` than the global best, store it.

The SA phase explores a broader neighbourhood while still using the cheap incremental update, so many thousands of proposals can be examined within the remaining time budget.

### 4. Optional exact refinement – small‑scale MILP

If still time remains (≈ 30 s), solve an **exact mixed‑integer program** on a reduced grid (`n′ = 80`) to obtain a provably optimal binary pattern for that size:

1. Variables `x_i ∈ {0,1}`, `∑ x_i = n′/2`.
2. For each shift `s∈{1,…,n′‑1}` introduce auxiliary binary variables `y_{i,s}` to linearise the product `x_i·x_{i+s}`:
   ```
   y_{i,s} ≤ x_i
   y_{i,s} ≤ x_{i+s}
   y_{i,s} ≥ x_i + x_{i+s} – 1
   ```
3. Let `z_s = Σ_i y_{i,s}` (overlap at shift `s`).  Introduce a scalar integer `t` and enforce `z_s ≥ t` for all `s`.  
4. Maximise `t`.  The optimal value `t*` gives the maximal guaranteed overlap; the resulting bound is
   `C_5 = (n′/2 - t*) * (2/n′)`.

The resulting binary pattern can be **lifted** to the original `n=120` grid by simple periodic repetition or by nearest‑neighbour interpolation while preserving the total integral (the lift may be slightly adjusted by a final greedy pass).
