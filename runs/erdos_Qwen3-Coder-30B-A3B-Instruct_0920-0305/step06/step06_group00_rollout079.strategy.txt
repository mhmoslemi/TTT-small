### Overview  
Instead of optimizing the  `n`  sampled values of `h` directly, we reformulate the problem in a *low‑dimensional interval model*.  
The function `h` is represented as a union of a few disjoint unit‑height intervals (and possibly a second height level).  
The total length of the intervals is forced to be 1 (the integral constraint), and the positions of the intervals are the only free variables.  

Because the overlap integral is a piecewise‑linear function of the interval endpoints, the exact value of  

\[
C_5(h)=\max_{k}\int_0^2 h(x)\bigl(1-h(x+k)\bigr)\,dx
\]

can be computed analytically by checking a **finite set of critical shifts** (differences of interval endpoints).  
Thus we obtain a *fast, exact* evaluator that does not rely on FFT discretisation.  

The optimisation proceeds in three stages:

1. **Global stochastic optimisation** (Differential Evolution) on the interval parameters.  
2. **Deterministic local refinement** using sub‑gradients of the exact max‑overlap.  
3. **Discretisation** of the optimal interval configuration onto a uniform grid, followed by a quick binary‑swap annealing as a safety net.

All stages respect the constraints, run within the 600 s budget, and are mathematically distinct from the previous gradient‑descent‑soft‑max approach.

### 1. Interval representation of `h`

* Choose an integer `p ≥ 2` (the number of unit‑height intervals).  
* Let `ℓ_i > 0` be the length of interval `i`, and `g_i ≥ 0` the gap preceding it.  
* Impose  
  \[
  \sum_{i=1}^{p}\ell_i = 1,\qquad
  \sum_{i=0}^{p} g_i = 1,
  \]
  so the covered length and uncovered length both equal 1 (the domain length is 2).  

**Parameterisation**  
Introduce raw non‑negative variables `u_i` and `v_i`.  
Set  
\[
\ell_i = \frac{u_i}{\sum_{j=1}^{p}u_j},\quad
g_i    = \frac{v_i}{\sum_{j=0}^{p}v_j}.
\]  
This automatically enforces the two sum constraints.  

The left endpoint of interval `i` is  
\[
s_1 = g_0,\qquad
s_i = g_0+\ell_1+g_1+\dots +\ell_{i-1}+g_{i-1}\;(i\ge2).

All intervals lie inside `[0,2]` by construction.  The design vector is  

\[
\mathbf{z} = (u_1,\dots,u_p,\;v_0,\dots,v_p)\in\mathbb R_{\ge0}^{2p+1}.

### 2. Exact evaluation of the max overlap for a given interval set  

For a fixed set of intervals `I = { [s_i, s_i+ℓ_i] }` let  

\[
F(k)=\int_0^2 h(x)(1-h(x+k))dx .
\]

Because `h` is an indicator of the intervals, `F(k)` is the total length of the region that is **inside** an interval and **outside** the shifted interval.  
`F(k)` is a piecewise‑linear function of `k`; its breakpoints occur exactly at the **differences of interval endpoints**:

```
K = {   (s_i      ) - (s_j       ),
        (s_i+ℓ_i) - (s_j+ℓ_j) }   for all i,j.
```

The set `K` contains at most `4p²` values.  
For each `k∈K` we compute `F(k)` analytically by scanning the ordered list of interval
endpoints (a linear sweep yields the total covered length after the shift).  
The maximum of `F(k)` over all real `k` is attained at one of these candidates, so

\[
C_5 = \max_{k\in K} F(k).
\]

Complexity: `O(p²)` to generate `K` and `O(p³)` to evaluate all candidates – trivial for `p≤10`.

### 4. Local refinement – sub‑gradient descent

When DE finishes, we have a design `z*` with intervals `I*`.  
If the max is attained at a *unique* shift `k*`, the objective is locally linear and the gradient w.r.t. each endpoint can be written down explicitly:

* For an endpoint that **moves into** the overlapping region when `k` changes, the gradient contribution is `+1` (increasing overlap).  
* For an endpoint that **moves out**, the contribution is `‑1`.  

If several shifts are tied for the maximum, we take the **average** of the corresponding sub‑gradients (standard convex sub‑gradient rule).  

Using these sub‑gradients we run a few iterations of a **projected sub‑gradient method** on the raw variables `z` (projection simply clips negative values to zero, then re‑normalises the `u` and `v` groups).
