**Goal.**  
Find a discretised step function  
\(h\in[0,1]^{n}\) on the interval \([0,2]\) (with uniform step \(dx=2/n\)) that satisfies  

* \( \sum_{i=0}^{n-1} h_i = n/2\)  (the integral equals 1),  
* \(0\le h_i\le 1\),

and minimises  

\[
C_5(h)=\max_{k\in\{-n+1,\dots ,n-1\}} \int_0^2 h(x)\bigl(1-h(x+k)\bigr)dx.
\]

In the discretised setting this is  

\[
C_5(h)=dx\;\max_{k} \; \sum_{i=0}^{n-1} h_i\bigl(1-h_{i+k}\bigr),
\qquad
h_j=0\ \text{if }j\notin\{0,\dots ,n-1\}.
\]

Because \(\int h=1\),

\[
\sum_i h_i\bigl(1-h_{i+k}\bigr) = \frac{n}{2}-
\sum_{i\;:\;0\le i,i+k<n}h_i\,h_{i+k}.
\]

Hence minimising the maximum overlap is **equivalent to maximising the
minimum number of “1‑1” pairs at each lag**.
The term \(\sum_{i}h_i h_{i+k}\) is a bilinear (quadratic) expression,
non‑convex for continuous \(h\).  However, if we restrict the step function
to be **binary** (\(h_i\in\{0,1\}\)), each product becomes a logical “and’’,
which can be linearised with auxiliary binary variables.
For the Erdős minimum overlap problem it is highly plausible that an optimal
solution is binary (the objective only depends on the products,
and the box constraints already push the solution to the extreme points).

The new method therefore treats the problem as a **pure integer linear
program (ILP)**, solves it to global optimality for a modest grid size,
and finally performs a short continuous local refinement to possibly
improve the bound further.

--------------------------------------------------------------------
### 1. ILP formulation (binary variables)

*Parameters*  

* \(n\) – even number of samples (choose 60 – 80, see below).  
* \(M=n/2\) – required number of ones.  
* \(dx=2/n\).

*Decision variables*  

* \(h_i\in\{0,1\}\) for \(i=0,\dots ,n-1\).  
* For each unordered pair \((i,j)\) with \(0\le i<j<n\) introduce a binary
  auxiliary variable \(y_{ij}\) that represents the logical AND:
  \(y_{ij}=h_i\land h_j\).  
* A continuous scalar \(t\ge0\) that bounds the worst‑lag overlap:
  \(t\ge M-\sum_{i=0}^{n-1-k}y_{i,i+k}\) for every lag \(k=1,\dots ,n-1\).

*Constraints*  

1. **Exact mass** \(\displaystyle\sum_{i=0}^{n-1} h_i = M\).  
2. **Linking AND** for every pair \((i,j)\)

   ```
   y_ij ≤ h_i
   y_ij ≤ h_j
   y_ij ≥ h_i + h_j – 1
   ```

   These three linear inequalities force \(y_{ij}=1\) iff both \(h_i\) and
   \(h_j\) are 1.

3. **Lag constraints** for each positive lag \(k\)

   \[
   t \;\ge\; M \;-\; \sum_{i=0}^{n-1-k} y_{i,i+k}.
   \]

   (The zero lag gives \(t\ge0\) automatically.)

4. **Box** \(0\le h_i\le1\) (redundant because they are binary).

5. **Symmetry breaking** (optional but speeds up the solver):
   fix the first entry, e.g. \(h_0=1\).  This removes the trivial complement
   symmetry (flipping all bits).

*Objective* \(\displaystyle\min\; t\).

Because all constraints are linear and all variables except \(t\) are binary,
the model is an MILP.  The optimal value of \(t\) equals the integer
maximum overlap before scaling; the final bound is \(C_5 = dx\;t\).
