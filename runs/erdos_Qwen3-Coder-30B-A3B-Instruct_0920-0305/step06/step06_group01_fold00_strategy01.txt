**Goal**  
Find a discretised step‑function `h` on `[0,2]` (represented by `n` samples) satisfying  

* `0 ≤ h[i] ≤ 1` for all `i`  
* `∑ h[i] · dx = 1`  (`dx = 2/n`, i.e. `∑ h[i] = n/2`)  

that minimises  

\[
C_5(h)=\max_{k}\;\int_0^2 h(x)\bigl(1-h(x+k)\bigr)\,dx
      \;=\;1-\min_{k}\;\int_0^2 h(x)h(x+k)\,dx .
\]

Thus the problem is equivalent to **maximising the smallest auto‑correlation** of `h`.  
The new method works directly on the autocorrelation and uses a smooth surrogate for the `min` operator, allowing efficient gradient‑based optimisation with exact projection onto the feasibility set.

--------------------------------------------------------------------
### 1. Discretisation & basic utilities
* Choose a modest power‑of‑two size `n` (e.g. `n = 256`).  
  `dx = 2.0 / n`, `target_sum = n/2`.  
* All vectors are NumPy `float64`.  
* **Fast convolution**: use the FFT (`np.fft`) to compute the full autocorrelation  
  `S = corr(h, h) = np.fft.ifft( fft(h, L) * np.conj(fft(h, L)) ).real`  
  where `L = 2*n-1`. This yields `S` of length `2n‑1` (lags `-(n‑1)…+(n‑1)`).  
* **Projection onto the bounded simplex** (box `[0,1]` + sum constraint):  
  solve for a scalar λ such that `∑ clip(h+λ,0,1) = target_sum`.  
  A short binary‑search (≈50 iterations) is sufficient and guarantees feasibility after every update.

--------------------------------------------------------------------
### 2. Smooth surrogate for the `min` of autocorrelations
Define for a positive smoothing parameter `α`  

\[
G_α(h)\;=\;-\frac{1}{α}\log\Bigl(\sum_{ℓ} \exp\!\bigl(-α\,S_ℓ\bigr)\Bigr),
\]

where `S_ℓ` are the autocorrelation values (including the zero lag).  
`G_α` is a **concave** smooth approximation of `\min_ℓ S_ℓ`.  
As `α → ∞`, `G_α → min S_ℓ`.  

The gradient of `G_α` with respect to `h` can be written in closed form:

* Compute the weight vector  
  `w_ℓ = exp(-α S_ℓ) / Σ exp(-α S_ℓ)`.  (`w` is already symmetric.)  
* For each lag `ℓ` the contribution to `∂G/∂h_i` is `w_ℓ·(h_{i+ℓ}+h_{i‑ℓ})` (out‑of‑range terms are zero).  
* This whole sum is exactly the **central part of the convolution** of `h` with the symmetric kernel `w`.  
  Convolution can be performed with a single `np.convolve` call:  

  ```
  conv = np.convolve(h, w, mode='full')
  g   = conv[n-1 : n-1+n]            # central n entries
  g  += w[n-1] * h                    # double‑count zero‑lag term (∂S_0/∂h = 2h)
  ```

  `g` is the gradient ∇ G_α.
