### Overview  
The task is to produce a step‑function `h` on `[0,2]` (discretised into `n` points) with

*   `0 ≤ h[i] ≤ 1`
*   `∑ h[i]·dx = 1`  (`dx = 2/n`, i.e. `∑ h[i] = n/2`)

that minimises  

\[
C_5(h)=\max_{k\in\{-n+1,\dots ,n-1\}}
   \Bigl[\int_0^2 h(x)\bigl(1-h(x+k\,dx)\bigr)\,dx\Bigr]
   =dx\;\max_{l}\operatorname{corr}\bigl(h,\,1-h\bigr)[l].
\]

The previous code attacked the *nondifferentiable* max directly with SLSQP.  
Below is a **different** pipeline that replaces the hard max by a smooth
log‑sum‑exp surrogate, drives the solution with a projected (accelerated)
gradient method, and finally polishes the result with a *cutting‑plane*
min‑max optimisation.  The whole pipeline is inexpensive, works for
moderately large `n` (≤ 400), and fits comfortably into the 600 s budget.

--------------------------------------------------------------------
### 1.  Discretisation choice  

* Start with `n = 240` (dx ≈ 0.00833).  
* If time permits, repeat the whole pipeline for `n = 180` and `n = 120`
  and keep the best final bound.  
* The `initial_h_values` (120‑point construction) are linearly interpolated
  to the chosen `n` and **projected** onto the feasible set – this gives a
  high‑quality deterministic seed.

--------------------------------------------------------------------
### 2.  Feasible‑set projection  

We need a fast routine `proj_sum_box(v, target)` that solves  

\[
\min_{u}\|u-v\|_2\quad\text{s.t.}\quad 0\le u_i\le 1,\;
\sum_i u_i = \text{target}.
\]

The routine uses the classic **water‑filling** / Lagrange‑multiplier
binary‑search on the scalar λ:

```
u = clip(v + λ, 0, 1) ,   choose λ so that Σ u = target.
```

The search interval is widened until the sign of `Σ clip(v+λ,0,1)-target`
changes, then a 40‑iteration bisection yields λ to 1e‑10 precision.
All other parts of the algorithm call this routine after each
gradient step.

--------------------------------------------------------------------
### 3.  Smooth max surrogate  

For a vector of overlaps `o[l]` (length `2n‑1`) define

\[
F_\alpha(h)=\frac{1}{\alpha}\;\log\!\Bigl(\sum_{l}
   \exp\!\bigl(\alpha\,o[l]\bigr)\Bigr),\qquad \alpha>0 .
\]

*When* `α → ∞`, `F_α → max_l o[l]`.  
For moderate `α` the function is **smooth**, its gradient is a weighted
average of the gradients of the individual overlaps:

\[
\frac{\partial F_\alpha}{\partial h_i}
   =\sum_{l} w_l(\alpha)\,
      \frac{\partial o[l]}{\partial h_i},
\qquad
w_l(\alpha)=\frac{\exp(\alpha o[l])}
                {\sum_{j}\exp(\alpha o[j])}.
\]

--------------------------------------------------------------------
### 4.  Gradient of a single overlap  

Let the discrete shift corresponding to index `l` be `s = l-(n-1)`.
The overlap for that shift is  

\[
o_s(h)=\sum_{i=0}^{n-1} h_i\bigl(1-h_{i+s}\bigr) \;dx ,
\]

with the convention `h_{i+s}=0` when the index lies outside `[0,n-1]`.

The (unprojected) gradient w.r.t. `h_i` is

\[
\frac{\partial o_s}{\partial h_i}
   =dx\;\bigl[\,1 - h_{i+s} - h_{i-s}\,\bigr],
\]

where any out‑of‑range term is omitted.
Because the sum‑constraint will later be enforced by projection,
the constant `dx` and the term `1` can be dropped; only the
**negative neighbour sum** matters:

\[
g^{(s)}_i = -\,dx\bigl( h_{i+s}+h_{i-s}\bigr).
\]

Thus the smooth gradient is a convex combination of these neighbour‑sum
vectors, weighted by `w_l(α)`.

--------------------------------------------------------------------
### 5.  Projected (accelerated) gradient descent with **α‑annealing**  

1. **Initial parameters**  
   * `α₀ = 5`, `α_max = 80`.  
   * Learning rate `η₀ = 0.02`.  
   * Momentum coefficient `β = 0.9`.  

2. **Iteration loop** (max ≈ 5000 steps or until time runs out)  

   a. Compute the full overlap vector `o` using one **FFT‑based correlation**
      (complexity `O(n log n)`).  

   b. Build the soft‑max weights `w` with the current `α`.  

   c. Assemble the gradient `g = Σ_l w_l * g^{(s_l)}` (vectorised slices
      for each shift, O(n) total).  

   d. **Momentum update**  
      `v ← β·v  – η·g` ; `h̃ ← h + v`.  

   e. **Projection**  
      `h ← proj_sum_box(clip(h̃,0,1), target = n/2)`.  

   f. **Annealing** – every 500 iterations increase `α` linearly towards
      `α_max` and decrease `η` (e.g. multiply by 0.95).  

   g. Keep the best `(h, max(o))` encountered so far.

The annealing drives the algorithm first to a “soft” optimum where many
shifts influence the search, then gradually concentrates on the true
worst shift, reducing the chance of getting stuck in a local minimum
that is only good for a few lags.

--------------------------------------------------------------------
### 6.  Cutting‑plane refinement (exact min‑max)  

After the gradient phase we have a candidate `ĥ` with a measured
max‑overlap `Ĉ = max(o)`.  The following polishing step enforces the
*exact* max‑overlap constraint only on the **critical** shifts.

1. Compute the overlap vector `ô`.  
2. Initialise the active‑set `S = { l | ô[l] ≥ Ĉ – 1e‑5 }`  
   (all shifts that are essentially tight).  

3. **Iterative optimisation** (solve a small nonlinear program each
   iteration):  

   *Variables*: `x = [h_0,…,h_{n-1}, t]`.  

   *Objective*: minimise `t`.  

   *Constraints*  
   *   `∑ h_i = n/2`   (equality).  
   *   `0 ≤ h_i ≤ 1`   (bounds).  
   *   For every `l ∈ S`:  `dx·corr_l(h) ≥ 1 - t`  ⇔
       `t ≥ dx·corr_l^{complement}(h)` (i.e. `overlap_l(h) ≤ t`).  

   The constraints are *quadratic* but smooth; we use **SLSQP** (or
   `trust‑constr` if available) with analytic Jacobians:
   the derivative of `overlap_l` w.r.t. `h_i` is exactly the neighbour‑sum
   described in section 4.

4. Run the solver with the current `ĥ` as start, obtain a new pair
   `(h*, t*)`.  

5. Re‑evaluate all overlaps for `h*`.  
   If a shift outside `S` violates `overlap ≤ t* + ε`,
   add it to `S` and repeat, otherwise terminate.  

Because `S` grows only while a violation appears, the number of
constraints stays modest (typically ≤ 10) and the final programme is
very fast.  The resulting `t*` is the **exact** `C_5` value for the
discrete model.
