### 2. Reformulating the objective  

Define  

\[
\Phi(h)=\min_{j\neq0} O_j .
\]

Then  

\[
C_5(h)=1-\frac{\Phi(h)}{n/2}.
\]

The gradient of a single autocorrelation term is  

\[
\frac{\partial O_j}{\partial h_i}=h_{i+j}+h_{i-j}
\quad(\text{indices outside }[0,n-1]\text{ treated as }0).
\]

If **J** is the set of shifts attaining the minimum, a sub‑gradient of Φ is  

\[
\nabla\Phi(h)=\frac{1}{|J|}\sum_{j\in J}\bigl( \,h^{(+j)}+h^{(-j)} \,\bigr) ,
\]

where \(h^{(+j)}\) denotes the vector h shifted by +j (zero‑padded) and similarly for \(h^{(-j)}\).

We will **ascend** Φ (i.e. **descend** C₅) using a projected gradient‑ascent step.

### 3. Smooth surrogate (soft‑min)  

Because Φ is a nondifferentiable min, early iterations can be erratic.  
Introduce a smoothed version

\[
\Phi_\gamma(h)= -\frac{1}{\gamma}\,
\log\Bigl(\sum_{j\neq0}\exp\bigl(-\gamma\,O_j\bigr)\Bigr),
\]

with temperature γ>0.  Its gradient is a weighted average of the individual gradients:

\[
\nabla\Phi_\gamma(h)=\sum_{j\neq0}
\underbrace{\frac{\exp(-\gamma O_j)}{\sum_{k\neq0}\exp(-\gamma O_k)}}_{w_j(\gamma)}
\bigl(h^{(+j)}+h^{(-j)}\bigr).
\]

The schedule: start with a modest γ (e.g. 0.5) to obtain a smooth landscape, then **increase γ geometrically** (γ←γ·1.3) after a fixed number of iterations, ending with a large γ (≈20–30) where Φγ≈Φ.  This “continuation” lets the algorithm first make large‑scale moves and finally focus on the true worst shift.

### 4. Feasibility projection  

After a gradient (or soft‑gradient) step we obtain a tentative vector z that may violate the box or sum constraints.  Project it back onto the intersection of  

\[
\mathcal{B}=\{h\mid 0\le h_i\le 1\},\qquad
\mathcal{S}=\{h\mid \sum_i h_i = n/2\}.
\]

The projection can be performed by the classic **water‑filling** (a one‑dimensional Lagrange‑multiplier search): find λ such that  

\[
\hat h_i = \operatorname{clip}(z_i+\lambda,0,1)
\]

satisfies ∑ hat h_i = target.  A simple bisection on λ converges in ≤ 50 iterations because the function is monotone.

### 5. Core optimisation loop (Projected Gradient Ascent)

```
initialize h (see §6)
γ ← γ_start   (≈0.5)
η ← η_0       (initial step size, e.g. 0.1·dx)
```

### 7. Local “pair‑swap” refinement (optional heavy‑tail)

After the gradient phase stabilises, perform a **deterministic swap pass** that directly improves the worst autocorrelation:

```
repeat until no improvement:
    identify J = argmin O_j
    compute contribution vector w_i = h_{i+J} + h_{i-J}
    let p = index with maximal w_i (candidate to increase)
    let q = index with minimal w_i (candidate to decrease)
    δ = min( 0.01, 1-w_p, h_q )      # keep in [0,1]
    h_candidate = h;  h_candidate[p] += δ;  h_candidate[q] -= δ
    project (only sum constraint needed because we kept box)
    if Φ(h_candidate) > Φ(h):
          h ← h_candidate
    else:
          break   # local optimum reached
```

Because only two entries change, the autocorrelation can be **updated in O(n)** using the formula  

\[
\Delta O_j = \delta\bigl( h_{p-j}+h_{p+j} - h_{q-j} - h_{q+j}\bigr)
\]

which is much cheaper than recomputing the whole FFT.  This fine‑tunes the bottleneck shifts.
