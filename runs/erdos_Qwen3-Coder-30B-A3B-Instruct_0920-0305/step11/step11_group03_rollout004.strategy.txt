**Objective reformulation**  
The quantity to minimise is  

\[
C_{5}(h)=\max_{k\in[-2,2]}\;\int_{0}^{2}h(x)\bigl(1-h(x+k)\bigr)\,dx
      =1-\min_{k\in[-2,2]}\;R(k),\qquad 
      R(k)=\int_{0}^{2}h(x)h(x+k)\,dx .
\]

Hence *maximising* the smallest autocorrelation value  

\[
t(h)=\min_{k}R(k)
\]

is exactly the same problem (the smaller \(C_{5}=1-t\) the better).  
The constraints are linear:

* \(0\le h(x)\le 1\) for all \(x\);
* \(\displaystyle\int_{0}^{2}h(x)dx=1\).

After discretising \([0,2]\) into \(n\) uniform points (step \(\Delta =2/n\)) we have a vector  
\(h\in[0,1]^n\) with \(\mathbf{1}^\top h = n/2\).

The key idea is to **optimise the min‑autocorrelation directly** by a projected (sub)‑gradient ascent on the concave‑like function \(t(h)\).  
This differs from the previous approach which minimised the max‑overlap directly with L‑BFGS/D‑E.  

--------------------------------------------------------------------
### 1. Discretisation & basic tools
* Choose a moderate resolution, e.g. **\(n=200\)** (Δ=0.01).  
  This gives enough flexibility whilst keeping each FFT cheap (\(O(n\log n)\)).
* **Fast autocorrelation**: for any \(h\) compute the full correlation  
  \(\rho = \text{ifft}(\text{fft}(h)\,\overline{\text{fft}(h)})\).  
  The positive‑shift autocorrelations are the entries \(\rho[n-1:k]\) (\(k=0,\dots,n-1\)).  
* **Projection onto the feasible set**: after any update
  1. **Clip** to the box \([0,1]\);
  2. **Water‑filling** (binary search on a Lagrange multiplier λ) to enforce the equality \(\mathbf{1}^\top h = n/2\).  
  This is exactly the “project_to_sum_box” routine used before but now applied after every gradient step.

--------------------------------------------------------------------
### 2. Sub‑gradient for the min‑autocorrelation
For a fixed shift \(k\) the autocorrelation is  

\[
R_k(h)=\Delta\sum_{i=0}^{n-1-k}h_i\,h_{i+k}.
\]

Its gradient (w.r.t. the vector \(h\)) is  

\[
(\nabla R_k)_i =
\begin{cases}
\Delta\,h_{i+k} & i\le n-1-k,\\[2pt]
\Delta\,h_{i-k} & i\ge k,\\[2pt]
0               & \text{otherwise}.
\end{cases}
\]

If the minimal autocorrelation is attained at a set of shifts  
\(\mathcal{K}_{\min}=\{k\mid R_k = \min_j R_j\}\) then any **convex combination** of the above gradients is a sub‑gradient of \(t(h)\).  
We use the **uniform average**:

\[
g = \frac{1}{|\mathcal{K}_{\min}|}\sum_{k\in\mathcal{K}_{\min}}\nabla R_k .
\]

### 3. Projected gradient ascent with adaptive step‑size
```
h ← initial feasible vector
best ← h,  bestC5 ← C5(h)
for iteration = 1 … ∞
    compute R = autocorrelation(h)               # via FFT, scale by Δ
    kmin ← argmin_k R
    g    ← average gradient over all k with R_k == R[kmin]   # (see §2)

    # adaptive step‑size (Robbins–Monro style)
    η    ← η0 / sqrt(iteration)   (η0≈0.05 works well)

    h'   ← h + η·g
    h'   ← project_to_sum_box(clamp(h',0,1), target_sum=n/2)

    C5'  ← 1 - min(R')   (R' is autocorrelation of h')
    if C5' < bestC5:
        best ← h',  bestC5 ← C5'

    # termination / restart logic
    if no improvement for 200 iterations:
         # inject noise to escape a plateau
         h ← best + σ·randn(n)  (σ decays with time)
         h ← project_to_sum_box(clamp(h,0,1), target_sum=n/2)
    if time_budget_exhausted: break
    h ← h'
```
* **Momentum** (optional): keep a velocity \(v\) and update \(v←βv+ηg\), \(h←h+v\) to smooth oscillations.

