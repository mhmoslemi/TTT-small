**Goal** – minimise  

\[
C_5(h)=\max_{k\in\mathbb R}\int_{0}^{2}h(x)\,\bigl[1-h(x+k)\bigr]dx
\]

subject to  

* \(0\le h(x)\le1\) for all \(x\)  
* \(\displaystyle\int_{0}^{2}h(x)dx=1\).

The domain is discretised to \(n\) equally‑spaced points  
\(h_i\;(i=0,\dots ,n-1)\) with step size \(dx=2/n\).  
Define  

\[
g_s(h)=dx\sum_{i=0}^{n-1} h_i\bigl[1-h_{i+s}\bigr]
      =dx\Bigl(S-\sum_i h_i h_{i+s}\Bigr),\qquad 
S=\sum_i h_i=\frac n2 .
\]

Thus \(C_5(h)=\max_{s} g_s(h)\) and minimising \(C_5\) is equivalent to
maximising the **minimal autocorrelation**  

\[
t(h)=\min_{s}\sum_i h_i h_{i+s}.
\]

The difficulty is the outer *max* (or inner *min*) which makes the
objective non‑smooth and non‑convex.

### 1.  Smooth surrogate for the max

Replace the hard max by a smooth log‑sum‑exp (soft‑max) with a
temperature parameter \(\tau>0\):

\[
\Phi_\tau(h)=\tau\log\!\Bigl(\sum_{s=-n+1}^{n-1}
        \exp\!\bigl(g_s(h)/\tau\bigr)\Bigr).
\]

* As \(\tau\downarrow0\), \(\Phi_\tau(h)\to\max_s g_s(h)\).  
* For any \(\tau\) the function is **differentiable** and its gradient is
a convex combination of the individual gradients \(\nabla g_s\).

The optimisation problem becomes  

\[
\min_{h\in[0,1]^n,\;\sum h=S}\;\Phi_\tau(h),
\]

which we will solve for a sequence
\(\tau_0>\tau_1>\dots>\tau_{L}\) (continuation).

--------------------------------------------------------------------
### 2.  Gradient of a single shift

For a fixed shift \(s\)

\[
g_s(h)=dx\bigl(S-\sum_i h_i h_{i+s}\bigr),
\]

\[
\frac{\partial g_s}{\partial h_i}
   =dx\Bigl[(1-h_{i+s})-h_{i-s}\Bigr],
\]
where out‑of‑range indices are interpreted as zero.  
Thus the full gradient of \(\Phi_\tau\) is

\[
\nabla\Phi_\tau(h)=\sum_s p_s(\,h\,)\,
     \nabla g_s(h),
\qquad 
p_s(\,h\,)=\frac{\exp(g_s(h)/\tau)}
                {\sum_{r}\exp(g_r(h)/\tau)}.
\]

The weights \(p_s\) are the soft‑max probabilities and can be computed
stably by subtracting \(\max_s g_s\) before exponentiation.

--------------------------------------------------------------------
### 3.  Fast evaluation with FFT

Both the vector of overlaps \(\{g_s\}\) and the weighted sums required for
\(\nabla\Phi_\tau\) are **convolutions**.  Using the discrete Fourier transform:

* Compute \(\widehat h\) and \(\widehat{1-h}\) once per iteration.
* Obtain the full correlation \(c=g_s(dx)=dx\;{\rm ifft}(\widehat h^\*\,\widehat{(1-h)})\).
* The weighted gradient terms are
  * \(A = {\rm ifft}(\widehat p^\*\,\widehat{(1-h)})\)   (the term with \(1-h_{i+s}\))
  * \(B = {\rm ifft}(\widehat p^\*\,\widehat{h})\)     (the term with \(h_{i-s}\))

  and the gradient is \(\nabla\Phi_\tau = dx\,(A-B)\).

Thus a whole iteration costs only two FFTs (O(n log n)).

--------------------------------------------------------------------
### 4.  Projection onto the feasible set

After a gradient step we must enforce  

\[
0\le h_i\le1,\qquad\sum_i h_i=S .
\]

Use the **water‑filling (box‑constrained simplex) projection**:

1. Clip the tentative vector to \([0,1]\).  
2. If the sum equals \(S\) we are done.  
3. Otherwise find a Lagrange multiplier \(\lambda\) such that
   \(\sum_i\operatorname{clip}(v_i-\lambda,0,1)=S\).  
   The monotone relationship permits a binary search on \(\lambda\) in
   \(O(\log(\epsilon^{-1})\cdot n)\) or a linear‑time O(n) algorithm by
   sorting the unclipped values.  The result satisfies the constraints
   exactly.

--------------------------------------------------------------------
### 5.  Accelerated projected gradient (APG) with back‑tracking

For a fixed temperature \(\tau\) run Nesterov’s accelerated method:

```
y_0 = h_0
t_0 = 1
for k = 0,1,2,…:
    compute g_s(y_k), p_s(y_k), gradient G_k = ∇Φτ(y_k)
    choose step α via back‑tracking:
        start α = 1
        while Φτ(project(y_k - α·G_k)) > Φτ(y_k) - η·α·||G_k||^2:
            α ← α/2
    h_{k+1} = project(y_k - α·G_k)
    t_{k+1} = (1+√(1+4·t_k^2))/2
    y_{k+1} = h_{k+1} + ((t_k-1)/t_{k+1})·(h_{k+1}-h_k)
```

Typical parameters: \(\eta=10^{-4}\).  Stop when the relative decrease of
\(\Phi_\tau\) falls below \(10^{-6}\) or when a predefined number of
iterations (e.g. 3000) is reached.

Because each iteration costs only FFTs, the method can perform thousands
of iterations well within the 600 s budget.

### 8.  Final fine‑grained refinement (pairwise exchange)

After the continuation stage we possess a high‑quality vector \(h\).

that respects the sum constraint exactly:

1. Pick two distinct indices \(i,j\).  
2. Compute the admissible move range:
   \(\Delta_{\max}= \min\{h_i,\,1-h_j\}\).  
3. Sample a tiny shift \(\delta\in[-\Delta_{\max},\Delta_{\max}]\).  
4. Form \(h' = h\);  \(h'_i = h_i-\delta\);  \(h'_j = h_j+\delta\).  
5. Evaluate \(C_5(h')\) (single FFT correlation).  
6. Accept if \(C_5(h')<C_5(h)\); otherwise accept with probability
   \(\exp\!\bigl(-(C_5(h')-C_5(h))/T\bigr)\) where the temperature \(T\)
