**Goal** – produce a step function  h  on [0,2]  with  
\[
\int_0^2 h(x)\,dx = 1,\qquad 0\le h(x)\le 1
\]
that minimises  
\[
C_5=\max_{k\in[-2,2]}\int_0^2 h(x)\bigl(1-h(x+k)\bigr)\,dx .
\]

--------------------------------------------------------------------
### 1.  Reformulation

Write the overlap integral as  

\[
g_k(h)=\int_0^2 h(x)\bigl(1-h(x+k)\bigr)dx
         =1-\!\int_0^2 h(x)h(x+k)dx .
\]

Define the **autocorrelation**
\[
R_k(h)=\int_0^2 h(x)h(x+k)dx .
\]
Then  

\[
C_5=\max_k g_k(h)=1-\min_k R_k(h) .
\]

Hence minimising \(C_5\) is **identical** to maximising the smallest autocorrelation value  
\[
t\;=\;\min_{k\in[0,2]} R_k(h) .
\]

--------------------------------------------------------------------
### 2.  Smooth max / min surrogate

The function \(\min_kR_k\) is non‑smooth.  Replace it by a *soft‑minimum* that is differentiable and becomes exact as a temperature parameter β → ∞:

\[
\operatorname{softmin}_\beta(R)= -\frac{1}{\beta}\log\!\Bigl(\sum_{k} e^{-\beta R_k}\Bigr)\; .
\]

The objective to be **minimised** is therefore  

\[
F_\beta(h)=1-\operatorname{softmin}_\beta\!\bigl(R(h)\bigr)
          =\frac{1}{\beta}\log\!\Bigl(\sum_{k} e^{-\beta R_k(h)}\Bigr) .
\]

When β is small the landscape is smooth (good for gradient steps); as β grows the surrogate approaches the true max‑overlap.

--------------------------------------------------------------------
### 3.  Low‑dimensional parameterisation (Fourier basis)

Instead of optimising 120 independent values, represent h as a small cosine series, which automatically satisfies the boundary condition \(h(0)=h(2)\) only in the interior (no periodicity is assumed because the shift is handled explicitly).

For a discretisation of n points (\(n\approx 180\) – still fast for FFT) define  

\[
h_i = \sum_{m=0}^{M-1} a_m \,\phi_m(i),\qquad 
\phi_0(i)=1,\;
\phi_m(i)=\cos\!\Bigl(\frac{\pi m\,i}{n-1}\Bigr),\; m\ge 1 .
\]

Choose a modest number of modes, e.g. \(M=8\).  
The coefficient vector **a**∈ℝ^M is the optimisation variable.

*Advantages*  
* far fewer variables → easier global optimisation,  
* smooth shape → easier to keep values inside [0,1] after projection,  
* the linear map \(a\mapsto h\) allows an explicit Jacobian for the gradient.

### 4.  Efficient evaluation of R_k and its gradient

For a given h (the vector of length n) compute the **full autocorrelation** by FFT:

```
H      = fft(h, 2*n-1)
R_full = ifft( H * conj(H) ).real          # length 2*n-1
```

The entries with non‑negative lag correspond to \(R_k\) for \(k=0,\dots,n-1\).  
Multiplying by the step size dx = 2/n yields the continuous integrals.

**Gradient of each R_k** (with respect to h) is elementary:

\[
\frac{\partial R_k}{\partial h_i}= 
\begin{cases}
h_{i+k} & i+k<n,\\[4pt]
0 & \text{otherwise}
\end{cases}
\;+\;
\begin{cases}
h_{i-k} & i\ge k,\\[4pt]
0 & \text{otherwise}
\end{cases}.
\]

Because the surrogate \(F_\beta\) uses a **soft‑minimum**, the gradient of \(F_\beta\) is a convex combination of those vectors:

1. Compute all \(R_k\) (k ≥ 0).  
2. Form soft‑weights  
   \[
   w_k=\frac{e^{-\beta R_k}}{\sum_j e^{-\beta R_j}} .
   \]  
3. Assemble the gradient  
   \[
   \nabla_h F_\beta = \sum_{k\ge0} w_k\,\bigl(-\nabla_h R_k\bigr) .
   \]

The matrix‑vector product needed for each \(k\) is just a shift of h; it can be assembled in **O(n · |active k|)** time (|active k| is the number of k‑values, which is at most n).  Since the weight vector is dense, we can compute the full gradient in **O(n log n)** by noting that the weighted sum of shifted copies is a convolution:

```
# w (size n) contains the soft‑weights for each shift
grad = - ( conv(w, h, mode='full')[n-1:2*n-1]  # forward shift part
        + conv(w_rev, h, mode='full')[0:n] )   # backward shift part
```

where `w_rev` is `w` reversed.  The convolution can be performed with one FFT.

--------------------------------------------------------------------
### 5.  Projection onto the feasible set

After a gradient step we must enforce  

* box constraints \(0\le h_i\le 1\),  
* the integral constraint \(\sum_i h_i \,dx = 1\)  (equivalently \(\sum_i h_i = n/2\)).

The **water‑filling** (also called “projection onto the simplex with upper bounds”) works as follows:

1. Clip h to the interval [0,1] → \(\tilde h\).  
2. Compute the sum s = ∑ \(\tilde h\).  
3. If s = n/2 we are done.  
4. Otherwise find a scalar λ such that  
   \[
   \sum_i \operatorname{clip}(\tilde h_i + \lambda,\;0,1)=\frac{n}{2}.
   \]  
   Because the left‑hand side is monotone in λ, a short binary search (≈30 iterations) gives λ to machine precision.  
5. Return the final projected vector.

The projection is **exact**, cheap (O(n log n) for the binary search) and works for any dimension.
