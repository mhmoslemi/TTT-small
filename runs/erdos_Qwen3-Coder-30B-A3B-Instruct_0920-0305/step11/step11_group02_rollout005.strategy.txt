**1.  Problem reformulation (discrete version)**  

- Choose a discretisation size `n` (e.g. 300 – 500 points).  
- Let `dx = 2.0 / n`.  The design variable is the vector `h ∈ [0,1]^n` with the linear equality  
  \[
  \sum_{i=0}^{n-1} h_i = \frac{n}{2}\qquad(\text{because }∫_0^2 h =1).
  \]  
- For an integer shift `k` (‑(n‑1) ≤ k ≤ n‑1) define the overlap  
  \[
  g_k(h)=dx\sum_{i=0}^{n-1-k}h_i\bigl(1-h_{i+k}\bigr)
        \qquad(k\ge 0)
  \]
  and analogously for negative `k`.  This is exactly the array returned by  
  `np.correlate(h,1-h,'full')*dx`.  

- The objective is the *max* of these overlaps:  
  \[
  C_5(h)=\max_{k} g_k(h) .
  \]  
  We must **minimise** `C_5`.

**2.  Analytic gradient of a single shift**  

For a fixed shift `k` (the one attaining the current maximum) the term  
\(g_k(h)=dx\sum_i h_i(1-h_{i+k})\) is differentiable w.r.t. each component:

\[
\frac{\partial g_k}{\partial h_i}=dx\bigl[ (1-h_{i+k})\;-\;h_{i-k}\bigr],
\]

where any out‑of‑range index contributes `0`.  Consequently a *sub‑gradient* of the
max‑overlap function is obtained by taking the gradient of the *active* shift
(the index `k* = argmax_k g_k(h)`).

**3.  Projected sub‑gradient descent on the max‑overlap**  

The feasible set is the intersection of the box `[0,1]^n` and the affine hyper‑plane
`\sum h_i = n/2`.  The projection can be performed with a standard “water‑filling’’
procedure:

```
proj(v) = clip(v + λ, 0, 1)   with λ chosen so that sum(proj(v)) = n/2
```

The λ value is found by a short binary search (≈ 30 iterations is enough).

**4.  Smoothing the max – log‑sum‑exp surrogate**  

Direct sub‑gradient on the hard max can stall when several shifts have similar
values.  Replace the objective temporarily by the smooth approximation  

\[
F_γ(h)=\frac{1}{γ}\log\!\Bigl(\sum_{k} e^{γ g_k(h)}\Bigr) .
\]

Its gradient is a convex combination of the individual shift gradients:

\[
∇F_γ(h)=\sum_{k} w_k ∇g_k(h),\quad 
w_k = \frac{e^{γ g_k(h)}}{\sum_j e^{γ g_j(h)}} .
\]

Start with a small `γ` (e.g. 0.1) to obtain a smooth landscape, then **anneal**
`γ` downwards (multiply by 0.5 every few hundred iterations) so that the algorithm
focuses on the true maximum near the end.

  `h_{i‑k}` term.

