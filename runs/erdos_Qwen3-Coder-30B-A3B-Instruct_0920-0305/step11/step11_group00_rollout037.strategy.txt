Let's flesh out the steps:

**Step 1: Formulate the epigraph problem**  

Introduce scalar t to bound the max overlap:  

Minimise t  
subject to for all k:  c_k(h) ≤ t,   (i.e., S - overlap(k) ≤ t).  
h ∈ [0,1]^n,   ∑ h = n/2.

**Step 2: Derive Lagrangian dual**  

Write Lagrangian with multiplier ω_k ≥0 for each inequality, and μ for sum equality, plus ν_i, ξ_i for box constraints. After eliminating t we obtain the dual (as above). The dual variables satisfy ω≥0, ∑ ω_k =1, μ free.  

The dual objective is:  

\[
\max_{\omega\ge0,\;\sum\omega=1,\; \mu} \; \phi(\omega,\mu),
\]  

where  

\[
\phi(\omega,\mu)=\min_{0\le h\le 1} \Bigl\{ \mu(\mathbf{1}^\top h - n/2) + \sum_{k} \omega_k c_k(h) \Bigr\}.
\]  

Given ω, the inner minimization is a separable quadratic problem of the form  

\[
\min_{0\le h\le 1} \Bigl\{ \mu\mathbf{1}^\top h + \mathbf{1}^\top h - h^\top W(\omega) h \Bigr\} - \mu n/2,
\]  

where \(W(\omega)=\sum_{k} \omega_k P^{(k)}\) is the weighted sum of shift matrices \(P^{(k)}\) with entries \([P^{(k)}]_{ij}=1\) iff \(j=i+k\) (zero‑padded).

**Step 3: Solving the inner problem efficiently**  

Because \(W\) is a *convolution* operator, i.e. \( (Wh)_i = \sum_k \omega_k h_{i+k}\) (zero‑padded), we can compute Wh via FFT for any vector h.  

The inner problem is 

\[
\min_{0\le h\le 1} \bigl\{ (\mu+1) \mathbf{1}^\top h - h^\top (W+W^\top) h / 2 \bigr\},
\]  

(note that \(h^\top W h = \sum_i h_i (Wh)_i\) and the matrix is not symmetric, but the term is symmetric anyway).  

We can treat the quadratic term as a **concave** function of h (since the matrix is non‑negative but not PSD). However we can nonetheless solve the inner problem to global optimality using **coordinate‑wise exact line search** because the objective is a *quadratic* over a box with a linear equality. This can be cast as a **quadratic knapsack problem**, for which a simple algorithm exists: sort the entries by the marginal gain of moving a variable from 0 to 1, then fill up to meet the sum constraint. The marginal gain for variable i (starting from 0) is  

\[
\Delta_i = (\mu+1) - (Wh)_i - (W^\top h)_i,
\]  

where initially h=0, the gain reduces as we turn on other variables (due to quadratic coupling). This suggests an iterative greedy algorithm (similar to forward selection) that converges to a local optimum; we can refine with a few passes of swapping to satisfy the equality exactly (swap a 1 with a 0 if it improves objective). Empirically this yields a good (often optimal) solution for the inner problem.

Alternatively, one can run a *projected Newton* method because the Hessian is just \(-(W+W^\top)\) (constant for a given ω). Projected Newton on a box with a linear equality is straightforward: compute Newton direction \(d = -(W+W^\top)^{-1}(\mu+1 - (Wh+W^\top h))\) (solved via Conjugate Gradient exploiting convolution) and then project back onto the feasible set. Since \(W+W^\top\) is circulant‑like, we can invert via FFT as well.

**Step 4: Outer optimisation on ω**  

Given that the inner problem can be solved (approximately) for any ω, we can compute the dual objective value \( \phi(\omega,\mu)\). Its gradient with respect to ω_k is simply the value of the constraint at the optimal h (by envelope theorem). Indeed  

\[
\frac{\partial \phi}{\partial \omega_k} = c_k(h^\star(\omega,\mu)).
\]  

Because in the dual we have fixed t eliminated, the gradient reduces to the actual correlation values at the current primal. Hence we can perform a **simple projected gradient ascent** on ω over the simplex using these gradients:  

* Compute h^\star for current ω (inner solve).  
* Compute c = correlation(h^\star).  
* Gradient g = c - t·1 (where t = max c, but because ω sum =1, the term becomes c - max(c)·1?). Actually the Lagrangian includes -t·∑ ω_k (t eliminated). The derivative w.r.t ω_k of the dual objective is simply c_k(h^\star) (since the term -t vanishes).  

Thus we ascend in the direction of increasing the correlation values. However we must also keep ω in the simplex; we can use standard **Exponentiated Gradient** (mirror descent with KL divergence) or **simplex‑projected gradient** (via Euclidean projection onto simplex, O(n)).  

**Step 5: Updating μ**  

The dual variable μ appears linearly; the inner minimizer with respect to h gives the complementary condition: at optimum, the sum constraint is satisfied (we enforce it), so we can treat μ as a Lagrange multiplier that adjusts the linear term in the inner problem. In the outer loop we can update μ via a subgradient:  

\[
\mu \leftarrow \mu - \eta (\mathbf{1}^\top h^\star - n/2).
\]  

Since the inner problem already enforces the equality (by projecting onto that hyperplane), μ becomes irrelevant; we can fix μ =0 and rely on projection onto the equality, thus eliminating μ entirely.

**Step 6: Whole algorithm**  

```
initialize ω = uniform distribution over all shifts (size 2n-1)
repeat until time runs out or ω converges:
    # inner problem: compute h given ω
    h = solve_inner(ω)   # see step 3
    # evaluate correlation
    c = correlation(h)      # raw values (no dx)
    # compute gradient for ω
    g = c - np.max(c) * np.ones_like(c)   # because sum ω = 1, only direction matters
    # simple gradient ascent on simplex
    ω = simplex_projection( ω + η * g )
    # optionally adapt step size η (e.g., diminishing)
    # keep best h (lowest true C5) seen so far
```

Because each inner solve is cheap (FFT‑based convolution + a few projected gradient steps on h), each outer iteration is O(n log n). With n≈120‑200 and a few thousand outer iterations, total time is well under the 600 s budget.
