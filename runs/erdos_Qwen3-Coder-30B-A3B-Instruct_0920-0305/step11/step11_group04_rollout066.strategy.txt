For a discretised step function  

* `h = (h₀,…,h_{n‑1})`  with 0 ≤ hᵢ ≤ 1,    
* `dx = 2 / n` and the sum constraint  `∑ hᵢ = n/2` (so that ∫₀² h = 1),

the linear autocorrelation vector is  

```
ρ = dx * correlate(h, h, mode='full')          # length 2n‑1
```

and the overlap integral for a shift *k* is  

```
A(k) = 1 – ρ_k .
```

Hence  

```
C₅ = max_k A(k) = 1 – min_k ρ_k .
```

Our optimisation problem is therefore **maximise the smallest entry of ρ**.
