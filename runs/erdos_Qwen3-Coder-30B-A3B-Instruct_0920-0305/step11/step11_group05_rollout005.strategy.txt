**Goal** – Find a step‑function `h` on `[0,2]` (represented by `n` equally spaced samples, `dx=2/n`) that satisfies  

* box constraints `0 ≤ h_i ≤ 1`,  
* integral constraint `∑_i h_i·dx = 1   ⇔   ∑_i h_i = n/2`,  

and minimizes  

\[
C_5(h)=\max_{k\in\{-n+1,\dots ,n-1\}} \;dx\;\sum_{i=0}^{n-1}h_i\bigl(1-h_{i+k}\bigr).
\]

The approach below is fundamentally different from the previous L‑BFGS‑B / simulated‑annealing hybrid: it (a) replaces the hard max by a smooth approximation, (b) uses a deterministic‑annealing style gradient optimisation on the smooth surrogate, (c) supplements the gradient phase with a lightweight global search over a *low‑dimensional parametric family* of shapes, and (d) finishes with a short, highly focused pairwise‑exchange refinement.

### 1.  Mathematical Reformulation

1. **Max–to–softmax.**  
   Define for any vector `h` the array of overlap values  
   \[
   g_s(h)=dx\;\sum_{i} h_i\bigl(1-h_{i+s}\bigr),\qquad s=-n+1,\dots ,n-1 .
   \]
   The original objective is `max_s g_s(h)`.  
   Introduce a *soft‑max* surrogate with temperature parameter `α>0`:
   \[
   \Phi_α(h)=\frac{1}{α}\log\!\Bigl(\sum_{s} \exp\bigl(α\,g_s(h)\bigr)\Bigr).
   \]
   As `α→∞`, `Φ_α(h) → max_s g_s(h)`.  For moderate `α` the function is smooth, everywhere differentiable, and its gradient w.r.t. `h` can be written in closed form using the same correlation that produces `g_s`.

2. **Handling the integral constraint.**  
   Write `h = σ(y)`, where `σ(t)=1/(1+e^{-t})` is the sigmoid.  Then `h∈(0,1)` automatically.  To enforce the exact sum we add a quadratic penalty
   \[
   P_μ(h)=μ\bigl(\sum_i h_i - n/2\bigr)^2,
   \]
   with a penalty coefficient `μ` that is increased during the annealing schedule.  The full smooth objective is
   \[
   F_{α,μ}(y)=\Phi_α\bigl(σ(y)\bigr)+P_μ\bigl(σ(y)\bigr).
   \]

3. **Gradient formula.**  
   Let `w_s = exp(α g_s)/∑_t exp(α g_t)`.  Then
   \[
   \frac{\partial \Phi_α}{\partial h_i}= \sum_s w_s \;dx\;\bigl(1-2h_{i+s}\bigr),
   \]
   where the index `i+s` is interpreted with zero‑padding outside `[0,n-1]`.  Chain rule through `σ` yields the gradient w.r.t. `y_i`.  All terms are computed via the FFT‑based correlation, so a single evaluation of `F_{α,μ}` and its gradient costs `O(n log n)`.

### 2.  Global Search in a Low‑Dimensional Shape Space

Optimising the full `n`‑dimensional vector with a plain gradient method can still get trapped in poor basins.  To supply a *high‑quality initialisation* we restrict attention to a compact family of symmetric, piecewise‑linear shapes that are known to be effective for overlap problems.

1. **Shape parameterisation.**  
   Choose an even number of breakpoints `M` (e.g. `M=8`).  Let `0=x_0 < x_1 < … < x_{M/2}=1` be the abscissae on the half‑interval `[0,1]`.  Define heights `v_0,…,v_{M/2}` with `v_0=0`, `v_{M/2}=1`.  The left half of `h` is obtained by linear interpolation between the `(x_j,v_j)`.  The right half is the mirror image (reflect about the centre `x=1`).  This yields a symmetric `h` on `[0,2]` automatically.

2. **Enforcing the integral constraint analytically.**  
   The integral of a piecewise‑linear function is a simple linear combination of the heights.  Solve the linear equation for a scaling factor `λ` that multiplies all interior heights, guaranteeing that the total area equals 1.  Hence the free optimisation variables are the interior abscissae `{x_1,…,x_{M/2-1}}` and a shape factor controlling curvature (e.g. the slope of the central segment).  The dimensionality is ≤10.

3. **Global optimiser – CMA‑ES.**  
   Run the Covariance‑Matrix‑Adaptation Evolution Strategy (CMA‑ES) on this low‑dimensional space.  CMA‑ES is gradient‑free, works well with moderate budgets, and can explore multi‑modal landscapes.  Each candidate shape is discretised to the chosen `n` (e.g. `n=120`) and evaluated with the *exact* `C_5` (FFT correlation) – no surrogate needed here because the evaluation is cheap.  Use a population size of about `10` and allow ~`2000` function evaluations (well within the time budget).  Keep the best shape found.

4. **Outcome of the global phase.**  
   The best shape from CMA‑ES provides a concrete vector `h⁰` that respects the constraints (by construction) and typically exhibits a low `C_5` (often already below the previous record).

### 3.  Deterministic‑Annealing Gradient Optimisation (Smooth‑max)

Starting from `h⁰` we now perform a fine‑grained optimisation of the smooth surrogate `F_{α,μ}`.

1. **Initialisation of the inner variables.**  
   Convert `h⁰` to logits `y⁰ = logit(h⁰) = log(h⁰/(1-h⁰))`.  Set the temperature `α₀ = 0.5` (soft) and the penalty weight `μ₀ = 0.1`.

2. **Adam optimiser.**  
   Use the Adam adaptive‑learning‑rate scheme (default β₁=0.9, β₂=0.999).  A learning‑rate of `η=0.05` works well for the early soft stages.

3. **Annealing schedule.**  
   - **Outer loop** over temperature levels `α_k = α₀·ρ^k` with `ρ≈1.3`. Stop when `α_k ≥ 30` (the softmax is already a tight approximation of the max).  
   - **Inner loop**: for each `α_k` run `T_k = 400` Adam steps (or fewer if time runs low).  
   - **Penalty increase**: after each temperature level increase `μ ← 10·μ` (or multiply by a factor `γ≈5`). This forces the sum constraint to become exact as the optimisation proceeds.

4. **Gradient computation.**  
   At every Adam step:
   - Compute the full correlation `c = correlate(h, 1‑h, mode='full')·dx` using the FFT routine.
   - Derive the softmax weights `w_s = exp(α·c_s)/∑_t exp(α·c_t)`.
   - Assemble the gradient w.r.t. `h` as `∂Φ/∂h_i = dx·∑_s w_s(1‑2h_{i+s})`.  
   - Transform to gradient w.r.t. logits `y` via the sigmoid derivative `σ'(y_i)=h_i(1‑h_i)`.  
   - Add the gradient of the penalty term `∂P/∂y_i = 2μ(∑h‑n/2)·h_i(1‑h_i)`.  

   All operations are `O(n log n)` thanks to the FFT convolution.

5. **Projection after each outer temperature.**  
   Once a temperature level finishes, project the current `h` onto the exact feasible set (box already satisfied, only the sum may be off).  Use the fast “water‑filling” projection: sort the entries, find the unique Lagrange multiplier that forces the sum to `n/2`, then clamp.  This eliminates drift that can accumulate from the penalty.

6. **Termination.**  
   The loop stops when either the maximum allowed time (≈70 % of the total budget) is reached or the change in `C_5` between successive temperature levels falls below `1e‑4`.  The final vector `ĥ` is then projected once more to guarantee feasibility.

### 4.  Final Local Refinement – Pairwise Exchange (Simulated‑Annealing Light)

The smooth‑max phase yields a near‑optimal `ĥ`, but because of the sigmoid squashing and penalty, a few entries may be stuck near the interior of `[0,1]`.  A concise, targeted local search can polish the solution.

1. **Move primitive.**  
   Pick two distinct indices `i, j`.  Choose a small delta `δ` (initially `δ≈0.02`).  Propose `h_i' = h_i - δ`, `h_j' = h_j + δ`, clipping both to `[0,1]`.  This move preserves the total sum exactly (except when clipping forces a smaller net transfer; in that case adjust `δ` to the maximal feasible amount).  

2. **Fast evaluation of the change in `C_5`.**  
   The correlation contributions of a single index can be updated in `O(1)` per shift using pre‑computed “influence vectors”: for each index `p`, store the vector `u_p` where `u_p[s] = dx·(1‑2h_{p+s})` (with zero padding).  When `h_i` changes by `Δ`, the whole `c` array is shifted by `Δ·u_i`.  Maintaining these vectors allows an `O(1)` update of the maximal overlap after a trial move.

3. **Acceptance rule.**  
   If the trial reduces the true `C_5`, accept it unconditionally.  Otherwise accept with probability `exp(‑(C_5'‑C_5)/τ)`, where the temperature `τ` decays geometrically (`τ←0.95·τ` each 1000 attempts).  Initialise `τ` to `0.005`.

4. **Budget.**  
   Run this exchange loop until the remaining time (≈10 % of the total budget) is exhausted or until `10 000` unsuccessful attempts have occurred in a row.  The loop is extremely cheap because each trial requires only a few arithmetic operations.

5. **Result.**  
   The best vector seen during this refinement is the final answer `h*`.  Perform a final exact `C_5` evaluation with the FFT routine to obtain the bound.

### 6.  Anticipated Failure Modes and Mitigations

| Failure mode | Why it occurs | Counter‑measure |
|--------------|---------------|-----------------|
| **Overflow in `exp(α·g_s)` for large `α`** | `g_s` can be up to ~1, and `α` grows to 30 → `exp(30)` ≈ 10¹³. | Before exponentiation subtract the current maximum `m = max_s g_s`; compute `exp(α·(g_s‑m))` and add back `m` in the log term (standard log‑sum‑exp trick). |
| **Penalty too weak → sum drifts** | Early soft stages use small `μ`; gradient may push mass away from the target sum. | After each temperature level, enforce an exact projection onto the hyperplane `∑h = n/2`. This eliminates accumulated drift. |
| **Adam step size too large → oscillations** | Near the final (hard) max, the landscape becomes steep. | Reduce the learning rate multiplicatively (e.g. `η←0.5·η`) each time `α` is increased. Optionally perform a few extra Adam steps with a halved `η` after the last temperature. |
| **CMA‑ES gets stuck in a plateau** | Low‑dimensional space may contain flat regions. | Run CMA‑ES with a modest restart count (e.g. three independent runs) and keep the best individual across all runs. |
| **Local refinement wastes time** | If the gradient phase already reaches a near‑optimal point, pairwise exchange may not improve further. | Stop the exchange loop early when the acceptance rate falls below 0.1 % over the last 1000 trials. |
| **Numerical inaccuracies in FFT for very small `dx`** | When `n` is large, rounding errors could affect `C_5`. | Stick to `n` in the range 120–168 (dx ≥ 0.012) where double‑precision FFT is accurate; optionally recompute the final correlation with a direct `O(n²)` loop (still cheap for `n≈150`) for the final verification. |
