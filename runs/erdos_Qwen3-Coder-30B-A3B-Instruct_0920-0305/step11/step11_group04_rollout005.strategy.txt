### 1. Variable transformation

Work with binary variables `x_i∈{-1,+1}` and later convert to the required

```

```

In matrix form this is `1ᵀ x = 0` or, equivalently for the lifted matrix

### 2. Autocorrelation in the ±1‑world

For a shift `k` (integer offset, `-(n‑1)…+(n‑1)`) define the *shift mask*
`S_k∈{0,1}^{n×n}`:

```
(S_k)_{i,j} = 1  iff  j = i + k  (and 0≤i,j<n), else 0 .
```

Only the overlapping index pairs contribute.  
Let `n_k` be the number of overlapping positions for shift `k`

Hence the overlap for shift `k` is

```
minimise   t
subject to
```

### 7. Random hyperplane rounding (Gaussian cuts)

Perform **R = 80–120** independent random cuts:

For each trial:
1. Sample a Gaussian vector `g ∈ ℝʳ` (i.i.d. N(0,1)).
2. Compute `x_i = sign(g·ℓ_i)`.  Ties (`=0`) are broken arbitrarily.
3. Transform to the step‑function: `h_i = (x_i + 1)/2` (now 0 or 1).
4. **Balance correction** – the raw cut may not contain exactly `n/2`

5. Evaluate `C₅` for this candidate by the exact correlation:

### 8. Greedy swap‑local‑search (memetic polish)

Take the best rounded vector `ĥ` and improve it with a deterministic
pair‑swap hill‑climb that respects the half‑ones constraint.

**Preparation** – pre‑compute the full correlation `ρ = dx·correlate(ĥ, ĥ)`.
Identify the *worst shift* `k* = argmin ρ` (equivalently the shift that yields
the current maximal `C₅`).

**Swap profit calculation** (for a given worst shift `k*`):
- For any index `i` with `ĥ_i = 0`,
  `gain_i = (ĥ_{i+k*} if i+k* in range else 0) + (ĥ_{i−k*} if i−k* in range else 0)`.
- For any index `j` with `ĥ_j = 1`,
  `loss_j = (ĥ_{j+k*} if j+k* in range else 0) + (ĥ_{j−k*} if j−k* in range else 0)`.

The net improvement of swapping `i↔j` is `Δ = gain_i - loss_j`.  
Search all pairs (`i` zero, `j` one) and perform the swap with the largest
positive `Δ`.  After a successful swap update `ρ` **incrementally**:
only the products involving indices `i` and `j` and their neighbours at
offset `±k*` change, so the update is O(1).  Re‑evaluate the worst shift,
repeat.

Terminate the local search when:
* no improving swap exists, **or**
* a small iteration cap (e.g. 500 swaps) is reached, **or**
* the global time budget is exhausted.

This memetic step can shave a few 1e‑4 off the `C₅` obtained from rounding,

### 9. Robust fallback – lightweight Genetic Algorithm (GA)

If the SDP solver does not return a feasible solution within the allocated
time, a GA runs for the remaining seconds.

**Encoding** – binary vectors of length `n` with exactly `n/2` ones (enforced
by a repair step after crossover).

**Population** – size 80–120, initialised with:
* the Thue‑Morse binary pattern,
* a few random balanced vectors,
* the best solution found by the earlier gradient code (`initial_h_values`).

**Fitness** – `f(h) = max_k np.correlate(h, 1‑h, mode='full') * dx`
(lower fitness is better).

**Selection** – tournament of size 3.

**Crossover** – *uniform balanced crossover*: for each position choose the
bit from one parent; after the child is built, if its number of ones deviates
from `n/2`, fix it by swapping random mismatched bits (preserving feasibility).

**Mutation** – pick two positions of opposite bits and flip them (swap 0↔1);
probability 0.05 per offspring.

**Elitism** – keep the top 5 % unchanged each generation.

Run generations until the time limit (≈ 250 s) is hit.  After the GA finishes,
apply the same greedy swap‑local‑search described in § 8 to the best GA
individual.  This ensures a reasonable solution even when the SDP path is
unavailable.

### 12. Anticipated failure modes & mitigations

| Failure mode                                   | Mitigation |
|------------------------------------------------|------------|
| **SDP does not converge** (timeout, infeasibility) | Switch instantly to GA fallback (§ 9). |
| **Numerical PSD violation** (tiny negative eigenvalues) | Add a small regularisation `X + 1e‑6·I` before eigen‑decomp. |
| **Balance constraint too strict** (trace(J X)=0) | Relax to `|trace(J X)| ≤ 1e‑5`; the rounding step will enforce exact balance anyway. |
| **Rounding produces many unbalanced bits** | The margin‑based repair (flip smallest |g·ℓ_i|) guarantees exact half‑ones while minimally disturbing the cut. |
| **Local swap gets stuck** (no improving pair) | Perform a brief random perturbation (swap a random zero/one pair) and resume; also restart local search after a fixed number of dead‑ends. |
| **Memory for shift masks** (2n‑1 dense matrices) | Store each `S_k` as a sparse CSR matrix; `trace(S_k X)` is then just `cp.sum(cp.multiply(S_k, X))` which cvxpy evaluates efficiently. |

### 13. Why this approach is *materially different*

1. **Convex relaxation** – We formulate the exact binary optimisation as an
   SDP, a globally solvable convex program, rather than applying local
   gradient descent or integer programming directly.
2. **Random hyperplane rounding** – The sign vector is extracted from the
   SDP matrix by a principled probabilistic method (Goemans‑Williamson style),
   not by heuristic mutations.
3. **Balanced SDP constraint** – The condition `trace(J X)=0` embeds the
   half‑area requirement directly into the convex model, a feature absent in
   the previous MILP and gradient schemes.
4. **Two‑stage memetic refinement** – After rounding, a dedicated
   *worst‑shift* greedy swap (instead of generic simulated annealing) exploits
   the problem structure, guaranteeing monotone improvement.
5. **Robust fallback** – A completely different evolutionary strategy (GA)
   is prepared if the convex solver cannot finish, ensuring a solution is
   always delivered.

Together these ingredients create a pipeline that explores the solution space
from a **global convex perspective**, then refines locally, dramatically
different from the earlier local‑gradient and MILP tactics.
