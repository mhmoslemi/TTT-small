### 2. Smoothed objective (log‑sum‑exp)
For a smoothing parameter `γ > 0` define  

```
F_γ(h) = (1/γ)·log( Σ_k exp( γ·g_k(h) ) )
```

`F_γ` is a smooth, convex‑in‑γ approximation of `max_k g_k`.  
When `γ → ∞`, `F_γ → max_k g_k`.  Using a moderate `γ` gives a usable gradient,
while a gradual increase of `γ` drives the solution toward the true max.

--------------------------------------------------------------------
### 3. Gradient of the smoothed objective
For each shift `s = -(n‑1)…(n‑1)` let  

```
g_s = Σ_i h_i·(1‑h_{i+s})·dx                (out‑of‑range indices are ignored)
```

Derivative w.r.t. a component `h_j` (for a *single* shift) is  

```
∂g_s/∂h_j =   (1‑h_{j+s})·dx    if 0 ≤ j ≤ n‑1‑s
            - h_{j‑s}·dx       if s ≤ j ≤ n‑1
            0 otherwise
```

Define the soft‑max weights  

```
w_s = exp(γ·g_s) / Σ_t exp(γ·g_t) .
```

Then the gradient of the smoothed loss is the **weighted sum** of the above
partials:

```
∇F_γ(h)_j = Σ_s w_s · ∂g_s/∂h_j .
```

Because `n` is small we can evaluate this gradient in O(n²) time with
vectorised slices:

```
grad = 0
for each shift s (with weight w = w_s):
    if s ≥ 0:
        grad[:n‑s] += w * (1‑h[s:])
        grad[s:]   -= w * h[:n‑s]
    else:                       # s negative, let t = -s
        grad[t:]   += w * (1‑h[:n‑t])
        grad[:n‑t] -= w * h[t:]
```

All operations are element‑wise, no explicit Python loops over the points,
so a full gradient computation costs ≈ (2n‑1)·n elementary ops – negligible
for `n≈200`.

### 4. Projection onto the feasible set
After each gradient step we must enforce  

```
0 ≤ h_i ≤ 1,    Σ h_i = M .
```

We use the **capped‑simplex projection** (Duchi et al.):

1. Clip `h` to `[0,1]` → `ĥ`.  
2. If `Σ ĥ = M` we are done.  
3. Otherwise find λ such that `Σ clip(ĥ + λ, 0, 1) = M`.  
   This is a water‑filling problem solved by sorting `ĥ` once (`O(n log n)`)
   and performing a linear scan to locate the correct λ.  
   The resulting vector `proj(ĥ)` is the Euclidean projection onto the box‑
   intersected simplex.

The projection is exact, cheap and keeps the iterates feasible for the final
evaluation (which uses the same constraints).
