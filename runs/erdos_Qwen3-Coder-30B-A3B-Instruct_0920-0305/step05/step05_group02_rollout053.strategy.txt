**1. Problem reformulation**

For a discretised step‑function `h` (length `n`, spacing `dx = 2/n`) the objective is  

```
C5(h) = max_k  ∫_0^2 h(x)·(1‑h(x+k)) dx
```

Because `∫_0^2 h = 1`, this can be written as  

```
C5(h) = 1 – min_k R(k) ,   R(k) = ∫_0^2 h(x)·h(x+k) dx .
```

Thus minimising `C5` is equivalent to **maximising the minimum aperiodic autocorrelation** `R(k)`.  
In the discrete setting  

```
R_k = Σ_{i=0}^{n‑k‑1} h[i]·h[i+k]              (k ≥ 0)
R_{‑k}=R_k                                    (symmetry)
C5 = 1 – min_k R_k·dx .
```

The constraints are  

```
0 ≤ h[i] ≤ 1               (box)
Σ h[i]·dx = 1   ⇔   Σ h[i] = n/2   (linear equality)
```

The search space is therefore the unit‑cube intersected with a single hyper‑plane.

--------------------------------------------------------------------
**2. Choice of representation**

*Primary representation* – a **binary vector** (`h[i] ∈ {0,1}`) with exactly `n/2` ones.  
Binary vectors are attractive because the product `h[i]·h[i+k]` is also binary, which makes the autocorrelation integer‑valued and the impact of a move easy to assess.

*Secondary representation* – a **continuous relaxation** (`h[i] ∈ [0,1]`) used only for a final polishing step.  The binary solution is taken as a warm start and then refined with a gradient‑based optimiser while re‑projecting onto the feasible box and the sum hyper‑plane.

--------------------------------------------------------------------
**3. Selecting the problem size `n`**

The bound `C5` improves with finer resolution, but evaluation cost grows roughly as `O(n²)`.  
Empirically a size in the range **60 ≤ n ≤ 80** gives enough degrees of freedom to beat the record while still allowing thousands of cheap moves per second on a single CPU.  
The algorithm will try a small set of even lengths, e.g. `n = 58, 62, 66, 70, 74, 78`.  
For each `n` the best solution found is kept; at the end the overall best across all `n` is returned.

**4. High‑quality initial binary patterns**

Two families of deterministic starts are generated for every `n`:

*4.1. Quadratic‑residue (Legendre) pattern*  
Let `p = n/2` (so `p` is an integer).  If `p` is prime, define  

```
R = { a² mod p : a = 1,…,p‑1 }   (size (p‑1)/2)
```

Create a length‑`p` binary mask `b` with `b[i]=1` iff `i∈R`.  
The full vector is `h = [b, b]` (concatenation of two copies).  
If `p` is not prime, fall back to the next smaller prime or to a random mask.  
If the total number of ones is `p‑1` rather than `p`, flip a single zero to one (anywhere) to satisfy the exact sum constraint.

*4.2. Random balanced mask*  
Generate a random permutation of `n` positions and set the first `n/2` entries to one, the rest to zero.  Several independent draws are kept as additional starting points.

Both families are cheap to create and already exhibit a fairly uniform distribution of pairwise distances, which is desirable for a large minimal autocorrelation.

**5. Core optimisation – “worst‑shift‑aware simulated annealing with swaps”**

The algorithm works exclusively on binary vectors; each elementary move **preserves the sum constraint exactly** by swapping a `1` with a `0`.

*5.1. Data structures*

* `h` – current binary vector (int8)  
* `corr[m]` – current overlap values `c_m = Σ h[i] – Σ h[i]·h[i+m]` for all lags `m = -(n‑1)…(n‑1)` (full correlation).  
  The array is kept up‑to‑date incrementally; its maximum `Cmax = max corr·dx` equals the current `C5`.  
* `worst_shifts` – list of lag indices where `corr[m]` attains `Cmax` (within a tiny tolerance).  

*5.2. Move generation*

For a chosen worst shift `k` (selected uniformly from `worst_shifts`), the set  

```
BadOnes(k) = { i : 0 ≤ i ≤ n‑k‑1,
               h[i]=1,
               h[i+k]=0 } .
```

For each `i∈BadOnes(k)` the contribution to `c_k` is exactly `+1`.  
Swapping this `1` at position `i` with **any** `0` at a position `j` that is *not* in `BadOnes(k)` (i.e. `h[j]=0`) reduces `c_k` by at least `1`, while possibly affecting other lags.

The move generator therefore:

1. Picks a random `k` from `worst_shifts`.  
2. Picks a random `i ∈ BadOnes(k)`.  
3. Picks a random `j` from the set of zero‑positions that are *not* in `BadOnes(k)` (or, if none exist, from the full zero set).  

If no `i` exists for the chosen `k` (highly unlikely when `Cmax` is large) a different `k` is tried.

*5.3. Incremental evaluation of a swap*

For a candidate swap `(i↔j)` the effect on every lag `m` can be computed in `O(n)` time:

```
Δc_m = Δ_i(m) + Δ_j(m) .
```

`Δ_i(m)` is the change in the contribution of index `i` to lag `m`:

```
if i ≤ n‑m‑1                (i participates in the “sum” part)
      old = h[i] - h[i]·h[i+m]
      new = h’[i] - h’[i]·h’[i+m]      (h’[i] is the swapped value)
      Δ_i(m) = new – old
else
      Δ_i(m) = 0

plus the symmetric term where i appears as the second index:
if i ≥ m
      old = -h[i‑m]·h[i]
      new = -h[i‑m]·h’[i]
      Δ_i(m) += new – old
```

All other indices are unchanged, so the total new `corr` after the swap is simply `corr + Δ`.  
The new maximal value `Cmax_new = max(corr+Δ)·dx` is obtained by scanning the updated array once.

Because the swap changes only two positions, the number of affected lags is at most `2·n`; the `O(n)` scan is cheap for the chosen `n`.

*5.4. Acceptance rule (simulated annealing)*  

Let `Ccur` be the current bound.  The swap is **accepted** if

```
Cmax_new < Ccur               (strict improvement)
```

or, with probability  

```
exp( – (Cmax_new – Ccur) / T )
```

if `Cmax_new ≥ Ccur`.  The temperature `T` follows a **geometric cooling schedule**:

```
T0 = 0.05                     (initial temperature)
Tf = 1e‑5                     (final temperature)
N_iter = 2·10⁶ (or less, limited by time budget)
T = T0 * (Tf/T0)^(iter/N_iter)
```

The schedule is recomputed each iteration, guaranteeing a gradual reduction of randomness.

*5.5. Loop structure*

```
start_time = now()
for each chosen n:
    for each deterministic start (Legendre, several random masks):
        initialise h, compute corr, Ccur
        for iter = 1 … N_iter (or until time budget exhausted):
            if elapsed_time > 0.95*budget: break outer loops
            generate a swap as described in 5.2
            evaluate Δc in O(n); obtain Cnew
            apply acceptance test 5.4
            if accepted:
                update h, corr, Ccur
                if Ccur < best_overall:
                    store best vector and its C5
            optionally (every 5000 iterations) recompute corr from scratch
            optionally (every 20000 iterations) perform a *restart*:
                pick a new random balanced mask and continue from there
```

This loop is deterministic apart from the random choices (seeded for reproducibility).  It is **drastically different** from global DE because it focuses every move on the *currently worst* shift and preserves the exact sum constraint through swaps.

--------------------------------------------------------------------
**6. Final polishing – continuous optimisation on the best binary solution**

When the annealing phase terminates (or when the time budget reaches 0.85 · budget), the best binary vector `h_bin` is used as a warm start for a **projected gradient search**:

*6.1. L‑BFGS‑B (or SLSQP) on the continuous problem*  

Variables `x ∈ [0,1]ⁿ` with bounds `(0,1)` and the equality constraint `Σ x = n/2`.  
Objective: `f(x) = max_k Σ x[i]·(1‑x[i+k])`.  
Because `max` is non‑smooth, replace it by a **smooth log‑sum‑exp** surrogate  

```
f̃(x) = (1/α)·log( Σ_k exp( α·c_k(x) ) )
```

with a moderate smoothing constant `α = 30`.  The surrogate is differentiable; its gradient can be obtained automatically (numpy broadcasting).  

The optimiser is called with:

```
bounds = [(0,1)]*n
linear_constraint: Σ x = n/2
initial point = h_bin.astype(float)
```

A small number of iterations (max 300) suffices because the start is already near a local optimum.  The resulting `x*` is projected back onto the feasible hyper‑plane (scale to enforce the sum) and clipped to `[0,1]`.  Its `C5` is computed with the exact correlation; if it improves the best integer bound, it replaces the stored solution.

--------------------------------------------------------------------
**7. Time‑management and early stopping**

* The total wall‑clock time is monitored (`time.time()`).  
* The outer loop over `n` stops as soon as the remaining budget falls below **5 %** of the total budget.  
* Inside the annealing loop, after every **10 000** iterations the current `C5` is compared with a target of **0.3807**.  If it is already below this value, the algorithm terminates immediately and returns the current best – no unnecessary work is performed.  
* A fallback is always available: the best solution found up to the moment of termination (even if it does not reach the target) is returned.

| **Scalability** | Effective up to ~200 points but many evaluations required | Same scalability but far fewer expensive evaluations (millions of cheap swaps) |

**9. Summary of the algorithmic pipeline**

1. **Choose several even lengths** `n` (e.g. 58 … 78).  
2. **Generate deterministic starts**: Legendre‑based binary masks and a few random balanced masks.  
3. **For each start** run the *worst‑shift‑aware simulated annealing*:

   * Maintain the full correlation array and the list of worst shifts.  
   * At each iteration pick a worst shift, swap a contributing `1` with a harmless `0`.  
   * Update the correlation incrementally, accept via an annealing rule.  

4. **Periodically restart** with a fresh random mask to avoid deep local minima.  
5. **When time is low** (≈ 85 % of the budget) **switch to continuous polishing**: minimise a smoothed max‑overlap using L‑BFGS‑B with the equality constraint, starting from the best binary solution.  
6. **Return** the best `h` (as a plain Python list of floats), its exact `C5` (computed with the full correlation), and the `n` used.

The whole procedure respects the 600 s budget by limiting the number of iterations per `n` and by performing cheap `O(n)` updates.  It leverages combinatorial structure (quadratic‑residue seeds) and a targeted annealing scheme, which is fundamentally different from the prior differential‑evolution pipeline and is well‑suited to push the Erdős constant bound beneath the current record.
