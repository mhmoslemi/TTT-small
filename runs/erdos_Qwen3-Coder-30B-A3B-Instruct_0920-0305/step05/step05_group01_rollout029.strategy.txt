**1. Mathematical reformulation**

For a discretised step‑function  
\(h = (h_0,\dots ,h_{n-1})\in[0,1]^n\) with spacing \(\Delta = 2/n\) the overlap for a lag
\(\ell\in\{-(n-1),\dots ,n-1\}\) is  

\[
I_\ell(h)=\Delta\sum_{i=0}^{n-1} h_i\bigl(1-h_{i+\ell}\bigr),
\qquad 
h_{j}=0\;{\rm for}\;j\notin[0,n-1].
\]

The quantity we want to minimise is  

\[
C_5(h)=\max_{\ell} I_\ell(h).
\]

The constraints are  

* box: \(0\le h_i\le 1\) for all \(i\);  
* mass: \(\sum_i h_i = n/2\)  (because \(\int_0^2 h\,dx=1\) and \(\Delta=2/n\)).

**2. Smooth approximation of the max**

The max is non‑differentiable.  Replace it by a *log‑sum‑exp* (soft‑max)  

\[
F_\alpha(h)=\frac{1}{\alpha}\log\Bigl(\sum_{\ell}e^{\alpha I_\ell(h)}\Bigr)
          \;\;\xrightarrow[\alpha\to\infty]{}\;\;C_5(h).
\]

For a fixed \(\alpha>0\) the gradient is a convex combination of the individual
gradients:

\[
\nabla F_\alpha(h)=\sum_{\ell} w_\ell(\alpha,h)\,\nabla I_\ell(h),\qquad
w_\ell(\alpha,h)=\frac{e^{\alpha I_\ell(h)}}{\sum_{k}e^{\alpha I_k(h)} } .
\]

Thus we only need an explicit formula for \(\nabla I_\ell\).

**3. Exact gradient of a single lag**

Let \(\ell\ge 0\).  For an interior index \(i\) with \(i+\ell<n\)

\[
\frac{\partial I_\ell}{\partial h_i}= \Delta\Bigl[\,1-h_{i+\ell} - h_{i-\ell}\Bigr],
\]

where the term \(h_{i-\ell}\) is omitted when \(i-\ell<0\).
If \(i+\ell\ge n\) the product contains the factor \((1-0)=1\) and the derivative
contributes only the constant \(\Delta\).

For a negative lag we use the same formula with \(\ell\) replaced by \(|\ell|\);
the sign of the shift is simply reversed.

Collecting the two cases gives a compact vectorised implementation:

```
grad = 0
for each lag ℓ with weight w:
    if ℓ ≥ 0:
        # (1 - h_{i+ℓ}) part
        grad[:n-ℓ] += w * (1 - h[ℓ:])
        grad[n-ℓ:]   += w               # edge where i+ℓ is outside → contribution 1
        # -h_{i-ℓ} part
        grad[ℓ:]      -= w * h[:n-ℓ]
    else:
        d = -ℓ
        grad[d:]      += w * (1 - h[:n-d])
        grad[:d]      += w               # edge on the left side
        grad[:n-d]    -= w * h[d:]
```

All operations are performed on numpy arrays, therefore the whole gradient is
obtained in \(O(n^2)\) time (for \(n=120\) this is negligible).

**4. Projection onto the feasible set**

After a gradient step the iterate may violate the box and the equality
constraint.  The Euclidean projection onto  
\(\{h\in[0,1]^n\mid \sum h_i = n/2\}\) can be performed by a *water‑filling*
(binary‑search) on a scalar shift \(\lambda\):

```
find λ such that   sum( clip( h + λ , 0 , 1 ) ) = n/2 .
```

The function
\(S(\lambda)=\sum\mathrm{clip}(h_i+\lambda,0,1)\) is monotone increasing,
so a simple bisection (≈30 iterations) yields the exact projection
(up to machine precision).

The increase of α can be linear in the iteration count or exponential:

*Iteration*
