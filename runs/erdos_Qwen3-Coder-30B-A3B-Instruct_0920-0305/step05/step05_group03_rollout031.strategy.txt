**1. Problem restatement**

We must choose a step function  

\[
h:\;[0,2]\rightarrow[0,1],\qquad 
\int_0^{2}h(x)\,dx=1
\]

to minimise  

\[
C_5=\max_{k}\int_0^{2}h(x)(1-h(x+k))\,dx .
\]

After discretisation with `n` equally‑spaced points (`dx=2/n`) the objective becomes  

\[
C_5(\mathbf h)=\max_{r\in\{-n+1,\dots ,n-1\}}
\Bigl(\,\mathbf h\star (1-\mathbf h)\Bigr)_r\,dx,
\]

where `⋆` denotes the (zero‑padded) discrete correlation and `\mathbf h∈[0,1]^n` satisfies  

\[
\sum_{i=0}^{n-1}h_i\;dx=1\;\Longleftrightarrow\;
\sum_{i=0}^{n-1}h_i =\frac{n}{2}.
\]

Hence the problem is a **non‑convex quadratic programme** (a max of quadratic forms).

--------------------------------------------------------------------

**2. Geometry of the objective**

Because  

\[
\int h(x)(1-h(x+k))dx = 1-\int h(x)h(x+k)dx,
\]

minimising the max‑overlap is equivalent to *maximising* the *minimal* self‑correlation  

\[
R_k=\int h(x)h(x+k)dx.
\]

Thus we want a shape whose autocorrelation stays as large as possible for **every** shift.

--------------------------------------------------------------------

**3. Continuous surrogate (log‑sum‑exp) for the max**

The max function is non‑smooth.  A standard smooth upper‑bound is  

\[
F_\alpha(\mathbf h)=\frac{1}{\alpha}
\log\Bigl(\sum_{r}e^{\alpha O_r(\mathbf h)}\Bigr),\qquad 
O_r(\mathbf h)=\bigl(\mathbf h\star(1-\mathbf h)\bigr)_r\,dx .
\]

* As \(\alpha\to\infty\), \(F_\alpha\to\max_r O_r\).
* For moderate \(\alpha\) the function is differentiable and its gradient is a **convex combination** of the gradients of the individual \(O_r\).

We will minimise \(F_\alpha\) while gradually increasing \(\alpha\) (a “continuation” or “annealing” schedule).  At the end we evaluate the true unsmoothed objective `evaluate_c5`.

--------------------------------------------------------------------

**4. Analytic gradient of the smoothed objective**

Let  

* `h`  – current vector (length `n`);
* `dx = 2.0/n`;
* `c1 = correlate(h, np.ones(n), mode='full')` – overlap of `h` with the all‑ones mask (size `2n‑1`);
* `c2 = correlate(h, h, mode='full')` – self‑correlation;
* `O = (c1 – c2) * dx` – the vector of overlaps \(O_r\);
* `w = \exp(\alpha (O - O_{\max}))` – un‑normalised weights;
* `w = w / w.sum()` – normalised weights (they sum to 1).

The derivative of a single overlap \(O_r\) w.r.t. \(h_k\) is

\[
\frac{\partial O_r}{\partial h_k}
= \underbrace{\mathbf 1_{\{k-r\in[0,n-1]\}}}_{\text{contribution from }c_1}
  \;-\;
\bigl(h_{k+r} + h_{k-r}\bigr)\;,
\]

with the convention that out‑of‑range indices give zero contribution.
Consequently the gradient of \(F_\alpha\) is

\[
\frac{\partial F_\alpha}{\partial h_k}
 =dx\Bigl(
      \underbrace{\sum_{r} w_r\,\mathbf 1_{\{k-r\in[0,n-1]\}}}_{\displaystyle
         s_k}
      \;-\;
      \underbrace{\sum_{r} w_r\,h_{k+r}}_{\displaystyle (w\star h)_k}
      \;-\;
      \underbrace{\sum_{r} w_r\,h_{k-r}}_{\displaystyle (w\star \tilde h)_k}
      \Bigr),
\]

where \(\tilde h\) is the reversed vector of `h`.  
All three terms are *convolutions* that can be obtained with a single call to `np.correlate`:

* `s = np.convolve(w, np.ones(n), mode='valid')`              → `[s_0,…,s_{n‑1}]`
* `g2 = np.correlate(w, h, mode='full')[n-1:2*n-1]`        → `[(w⋆h)_0,…,(w⋆h)_{n‑1}]`
* `g3 = np.correlate(w, h[::-1], mode='full')[n-1:2*n-1][::-1]` → `[(w⋆\tilde h)_0,…]`

Finally  

\[
\mathbf g = dx\;(s - g2 - g3).
\]

Because every operation is \(O(n^2)\) (with `n≤~150` this is negligible) we can afford thousands of gradient steps.

--------------------------------------------------------------------

**5. Projection onto the feasible set**

After a gradient step we obtain an unrestricted vector \(\mathbf v\).  We must enforce

```
0 ≤ h_i ≤ 1      (box constraints)
∑ h_i = S = n/2  (equality – total area)
```

The Euclidean projection onto the *capped simplex* is solved by a simple **water‑filling** (binary‑search for a Lagrange multiplier λ):

```
def project(v):
    # find λ so that  p_i = clip(v_i + λ, 0, 1)  satisfies  Σ p_i = S
    lo = -np.max(v) - 1.0      # makes all entries ≤0
    hi =  1.0 - np.min(v) + 1.0# makes all entries ≥1
    for _ in range(60):
        lam = (lo+hi)/2
        p   = np.clip(v + lam, 0.0, 1.0)
        s   = p.sum()
        if s > S:  hi = lam
        else:      lo = lam
    return np.clip(v + (lo+hi)/2, 0.0, 1.0)
```

The projection is \(O(n\log(1/ε))\) and virtually free compared to the correlation work.

**6. Symmetry reduction (optional but powerful)**  

The problem is invariant under the reflection \(x\mapsto 2-x\).  Enforcing `h[i]=h[n-1-i]` halves the dimensionality, reduces the search space and often yields a better bound.  After each gradient step we simply replace  

```
h = (h + h[::-1]) / 2
```

and then re‑project.  The projection still respects the symmetry because the sum constraint is unchanged.

**7. Full optimisation pipeline**

```
run(seed=42, budget_s=600)
    ── set random seed
    ── start timer
    ── choose number of points n
           • n = 84 (2× the original 42) gives finer freedom
           • n may be increased to 126 if time permits
    ── generate an initial feasible h
           • up‑sample the provided `initial_h_values` to length n
           • project onto the capped simplex → h₀
    ── best_h ← h₀ , best_val ← evaluate_c5(h₀)

    ── GLOBAL SEARCH (optional, 5–10 % of budget)
           • run a small Differential‑Evolution (DE) population (pop≈10)
           • each candidate is repaired by the projection routine
           • keep the 5 best distinct candidates for local refinement

    ── LOCAL REFINEMENT (the bulk of the budget)
           • For each starting point (h₀ and the DE elites) do:
                 α ← 5.0                # smoothing strength
                 η ← 0.5 * dx           # initial step size
                 repeat while time left:
                        # 1) evaluate smooth objective & gradient
                        O,w,g ← compute_O_w_grad(h, α)

                        # 2) line‑search step
                        for factor in [1.0, 0.5, 0.25]:
                            h_trial = project( h - factor*η*g )
                            # enforce symmetry if desired
                            if symmetric:
                                h_trial = (h_trial + h_trial[::-1]) / 2
                                h_trial = project(h_trial)   # keep sum exact
                            val = evaluate_c5(h_trial)          # true max
                            if val < best_val:
                                best_h, best_val = h_trial, val
                                h = h_trial
                                break   # accept this factor
                        else:
                            η *= 0.5   # no improvement → shrink step

                        # 3) annealing on α
                        if iteration % 200 == 0:
                            α = min(α*1.5, 50.0)   # slowly sharpen the max

                        # 4) occasional random perturbation
                        if iteration % 500 == 0 and not improved:
                            h = project( h + 0.02*np.random.randn(n) )
                            if symmetric:
                                h = (h + h[::-1])/2
                                h = project(h)

                        # 5) stop criteria
                        if time.time() - start > 0.97*budget_s: break
```

*All arithmetic uses `dx = 2.0/n` for the correct scaling.*  

At any moment we keep the *true* (non‑smoothed) objective value `evaluate_c5` for the best candidate, never the surrogate.  The final return is `best_h.tolist(), best_val, n`.
