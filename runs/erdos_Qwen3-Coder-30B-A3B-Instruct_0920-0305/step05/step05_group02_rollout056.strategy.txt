**Objective** – Find a step‑function `h` on `[0,2]` (represented by `n` equally spaced samples) that satisfies  

* `0 ≤ h[i] ≤ 1` for every index `i`,  
* `∑_{i=0}^{n‑1} h[i]·dx = 1`  with `dx = 2/n`,  

and minimises  

```
C5(h) = max_k  ∫_0^2 h(x)·(1 – h(x+k)) dx .
```

The method below abandons stochastic global optimisation (DE, SLSQP, simulated annealing) and replaces it by an **exact integer‑linear programming (MILP) formulation** that directly maximises the smallest aperiodic autocorrelation.  The MILP delivers a provably optimal *binary* pattern for a chosen resolution `n`; a brief continuous polishing step can then be applied if desired.

### 1.  Reformulate the objective

Because `∫_0^2 h = 1`,  

```
C5(h) = 1 – min_k R(k) ,                (1)
R(k) = ∫_0^2 h(x)·h(x+k) dx .
```

Thus we must *maximise the minimum autocorrelation* `R(k)`.  In the discrete representation let  

```
x_i ∈ {0,1}      (i = 0,…,n‑1)                 # indicator of h = 1
```

The integral constraint becomes the linear equality  

```
∑_{i=0}^{n‑1} x_i = n/2 .                      (2)
```

For a non‑negative shift `k` (negative shifts are symmetric) define the ordered‑pair count  

```
p_k = ∑_{i=0}^{n‑k‑1} x_i·x_{i+k} .            (3)
```

Since `R(k) = p_k·dx`, substitution into (1) yields  

```
C5 = max_k ( n/2 – p_k )·dx .                 (4)
```

Consequently, **maximising the smallest `p_k` is equivalent to minimising `C5`**.  Introduce an integer variable  

```
L = min_{k≥1} p_k                               (5)
```

and note that `p_0 = n/2` automatically, so only `k = 1,…,n‑1` matter.

The discrete optimisation problem becomes  

```
maximise   L
subject to ∑ x_i = n/2
            p_k ≥ L    for every k = 1,…,n‑1
            x_i ∈ {0,1} .
```

All that remains is to express `p_k` linearly.

### 2.  Linearise the product `x_i·x_{i+k}`

Introduce auxiliary binary variables  

```
y_{i,k} ∈ {0,1}      for 0 ≤ i ≤ n‑k‑1 , 1 ≤ k ≤ n‑1 .
```

Enforce the exact AND relationship (McCormick constraints, exact because the `x`‑variables are binary):

```
y_{i,k} ≤ x_i
y_{i,k} ≤ x_{i+k}
y_{i,k} ≥ x_i + x_{i+k} – 1 .
```

Now  

```
p_k = Σ_{i=0}^{n‑k‑1} y_{i,k} .                (6)
```

All constraints are linear; the model is a pure 0‑1 MILP with objective (5).
