### 1.  Problem discretisation  

* Choose a modest number of sampling points `n` (e.g. **64 – 96**).  
  `dx = 2 / n`.  
* The vector `h∈ℝⁿ` must satisfy  

```
0 ≤ h_i ≤ 1            (box constraints)
∑_i h_i = n/2          (integral = 1)
```

* For a shift `k (1 ≤ k ≤ n‑1)` the discrete auto‑correlation is  

```
c_k(h) = Σ_{i=0}^{n-1‑k} h_i · h_{i+k}
```

* The Erdős constant for the discretisation is  

```
C₅(h) = max_{k≠0} ( 1 – c_k(h) ) = 1 – min_{k≠0} c_k(h) .
```

Our goal is to **construct** a feasible `h` with a small `C₅`.

### 2.  Convex SDP relaxation  

The quadratic terms `h_i·h_j` are lifted to a matrix variable  

```
X = h hᵀ   (n × n, symmetric, PSD)
```

If `X = hhᵀ` then each correlation can be written linearly:

```
c_k(h) = Σ_{i=0}^{n-1‑k} X_{i,i+k}.
```

The rank‑one requirement `X = hhᵀ` is non‑convex, so we **relax** it to  

```
X ⪰ 0                (positive semidefinite)
X_{ii} = h_i          for all i            (diagonal matches h)
```

All other constraints stay linear.  Introduce a scalar `t` that lower‑bounds every correlation:

```
t ≤ c_k(h)   for all k = 1 … n‑1 .
```

The relaxed optimisation problem is the following **semidefinite program**:

```
maximise      t
subject to    X ⪰ 0
              X_{ii} = h_i               (i = 0 … n‑1)
              0 ≤ h_i ≤ 1                (i = 0 … n‑1)
              Σ_i h_i = n/2
              Σ_{i=0}^{n‑1‑k} X_{i,i+k} ≥ t    (k = 1 … n‑1)
```

All constraints are affine in the variables `(h, X, t)`, hence the problem is a linear SDP.
