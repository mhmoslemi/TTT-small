**Mathematical reformulation**

For the discrete vector `h∈[0,1]^n` (with `dx = 2/n` and `∑h_i = n/2`) define  

```
Cℓ(h) = ∑_{i} h_i (1 – h_{i+ℓ})                (zero‑padding outside [0,n‑1])
```

and  

```
C5(h) = dx·maxℓ Cℓ(h) .
```

Since `∑h_i` is constant,  

```
Cℓ(h) = dx·( target – Σ_i h_i·h_{i+ℓ} )      with  target = n/2 .
```

Thus minimizing `C5` is equivalent to **maximising the minimal auto‑correlation**
`Σ_i h_i·h_{i+ℓ}` over all integer lags ℓ.  
The term `Σ_i h_i·h_{i+ℓ}` is a quadratic form with a simple shift‑matrix, so its
gradient w.r.t. `h` is known analytically.

**Core idea – smoothed max + projected gradient descent**

Instead of the non‑smooth `maxℓ Cℓ`, we minimise the *log‑sum‑exp* (soft‑max)

```
Sβ(h) = (1/β)·log( Σℓ exp( β·Cℓ(h) ) )      ,  β>0 .
```

For small β the function is smooth and the gradient is a weighted average
of the individual gradients; as β→∞ we recover the true max.  
The gradient of `Sβ` is

```
∇Sβ(h) = Σℓ wℓ( h ) · ∇Cℓ(h) ,  where
wℓ = exp(β·Cℓ) / Σk exp(β·Ck) .
```

For a fixed lag ℓ the gradient is elementary:

```
(∇Cℓ)_i = 1 – h_{i+ℓ} – h_{i-ℓ}    (out‑of‑range indices contribute 0)
```

Hence we can compute the full gradient in O(n log n) time:
* evaluate all Cℓ by a single FFT‑based correlation,
* form the weights wℓ (after subtracting max Cℓ for numerical stability),
* compute the two shifted copies of `h` (vectorised `shift_zero`) and combine them.

The function of λ is monotone, so 40–50 bisection steps give machine‑precision
