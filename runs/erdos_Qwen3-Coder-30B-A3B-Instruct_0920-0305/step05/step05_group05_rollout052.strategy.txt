### 1.  Discretisation & dimensionality
* Choose a moderate size `n = 64` (or 80) – enough freedom for a smooth shape, still cheap (O(n²)≈4 k per iteration).  
* `dx = 2.0 / n`, target sum `T = n/2`.

--------------------------------------------------------------------
### 2.  Analytic gradient of the *smoothed* max‑objective  

The raw objective is the non‑differentiable `max_k O_k` with  

```
O_k(h) = dx·∑_{i=0}^{n‑1} h[i]·(1‑h[i+k])      (out‑of‑range h=0)
```

For a *fixed* shift `k`

```
∂O_k/∂h[i] = dx·( 1‑h[i+k]  –  h[i‑k] )       (terms with out‑of‑range index are 0,
                                                so (1‑0)=1, h[·]=0)
```

Only two slices of `h` appear, therefore the gradient can be built from
simple NumPy slices.

Because `max` is non‑smooth we replace it by the **log‑sum‑exp** (LSE) smooth
approximation

```
F_α(h) = (1/α)·log( Σ_k exp( α·O_k ) )      (α>0)
```

*When α → ∞, `F_α → max_k O_k`.*  
The gradient of `F_α` is a convex combination of the per‑shift gradients:

```
w_k = exp(α·O_k) / Σ_j exp(α·O_j)          (soft‑max weights)

∂F_α/∂h = Σ_k w_k · ∂O_k/∂h
```

All quantities are vector‑valued and can be assembled with O(n²) elementary
operations.

--------------------------------------------------------------------
### 3.  Projection onto the feasible set  

After a gradient step we must enforce  

```
0 ≤ h ≤ 1 ,    ∑ h = T .
```

The Euclidean projection onto the intersection of a box and an affine hyper‑plane
is a **capped simplex projection** and can be solved by a simple binary search
on a Lagrange multiplier `λ`:

```
proj_λ(v) = clip( v – λ , 0 , 1 )
choose λ so that Σ proj_λ(v) = T .
```

The monotonicity of the sum in `λ` guarantees convergence in ~30–40 bisection
iterations, negligible compared with the optimisation cost.

### 4.  Optimisation algorithm (core)

```
Input : n, max_iters, α_start, α_end, lr_0
Output: best_h , best_C5

repeat for many random restarts (until time budget expires):
    1) initialise h:
        – draw uniform random numbers ∈[0,1];
        – project onto the feasible set (section 3).
        – optionally replace by a *structured* seed (triangular, sine,
           Gaussian bump, or a binary “checker‑board” pattern) to diversify.
    2) gradient descent with annealing of α:
        for t = 1 … max_iters:
            α = α_start + (α_end‑α_start)·t/max_iters          # gradual sharpening
            O = dx·np.correlate(h,1‑h,'full')                # vector of O_k
            w = softmax(α·O)   (use stable exp: subtract max(O) first)
            grad = Σ_k w_k * ( (1‑h shifted by –k) – (h shifted by –k) )
            grad *= dx                                      # Jacobian scale
            step = lr_0 / sqrt(t)                           # decay 1/√t (simple schedule)
            h ← h – step·grad
            h ← project_onto_capped_simplex(h)               # section 3
            # optional symmetry enforcement: h ← (h + h[::-1]) / 2
            C5_now = max(O) * dx
            if C5_now < best_C5:
                best_h ← h.copy();  best_C5 ← C5_now
            if time left < ε : break
    3) after the “smooth” phase, run a short *sub‑gradient* refinement:
        – locate the active shift(s) k* with maximal O_k;
        – compute the exact gradient of those O_k (no softmax, w_k = 1);
        – take a few hundred steps with a much smaller step‑size
          (e.g. lr = 0.02 / sqrt(t)) and project after each step.
```

Key features that differentiate this scheme from the previous SLSQP‑based approach:

* **Smoothed max** provides a differentiable objective, enabling efficient
  gradient information instead of repeated black‑box SLSQP calls.
* **Explicit analytic gradient** avoids numerical differentiation and keeps the per‑iteration cost low.
* **Projection onto the capped simplex** guarantees that the equality and box constraints are always satisfied, eliminating the need for penalty terms or ad‑hoc scaling.
* **Annealing of the smoothing parameter α** (starting low, ending high) lets the optimiser first explore a smooth landscape and then focus on the true max.
* **Randomised multi‑start** together with a handful of *structured* seeds (triangular, sine, Gaussian) reduces the chance of being trapped in a poor local minima.
* **Optional symmetry averaging** halves the effective search space and reflects the known symmetry of the optimal function.
* **Sub‑gradient polishing** after the smooth phase directly minimises the true `max_k` for a final tweak.
