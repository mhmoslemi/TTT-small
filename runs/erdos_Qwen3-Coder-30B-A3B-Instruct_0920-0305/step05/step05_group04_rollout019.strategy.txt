### 1.  Core mathematical reformulation  

For a discretised step function `h = (h₀,…,h_{n‑1})` with step size `dx = 2/n`

\[
C_5(h)=\max_{k\neq0}\int_0^2 h(x)\bigl(1-h(x+k)\bigr)\,dx
      = 1-\min_{k\neq0}\;c_k(h),
\qquad       
c_k(h)=\int_0^2 h(x)h(x+k)\,dx .
\]

Thus **minimising** `C₅` ⇔ **maximising** the worst self‑correlation `c_k`.  
Define the linear (zero‑padded) convolution  

\[
c = \operatorname{conv}(h,h),\qquad 
c_k = \sum_{i=0}^{n-1-k}h_i\,h_{i+k}\;\;(k=1,…,n-1).
\]

The vector `c` is a *quadratic* function of `h`.

---

### 2.  Smooth surrogate for the non‑smooth max‑operator  

Introduce a temperature‑parameter `β>0` and the log‑sum‑exp (soft‑minimum)

\[
\Phi_{β}(h)=\frac{1}{β}\log\!\Bigl(\sum_{k=1}^{n-1}\exp\!\bigl(-β\,c_k(h)\bigr)\Bigr)
            \;\approx\; -\min_{k\neq0}c_k(h).
\]

The smooth upper bound for the original constant is  

\[
\widehat C_5(h)=1+\Phi_{β}(h).
\]

When `β→∞`, `Φ_{β}` tends to the exact negative minimum; for small `β` the surface is very smooth and easy to optimise.  
We will **continue** the optimisation by slowly raising `β` (homotopy).

---

### 3.  Analytic gradient of the surrogate  

For a single shift `k` the gradient of `c_k` is

\[
\bigl(\nabla c_k\bigr)_i =
\begin{cases}
h_{i+k} & \text{if }i+k<n \\ 0 & \text{otherwise}
\end{cases}
+
\begin{cases}
h_{i-k} & \text{if }i-k\ge0 \\ 0 & \text{otherwise}
\end{cases}.
\]

Define the soft‑minimum weights  

\[
w_k = \frac{\exp(-βc_k)}{\sum_{t=1}^{n-1}\exp(-βc_t)} ,\qquad k=1,…,n-1 .
\]

Then  

\[
\nabla\Phi_{β}(h)= -\sum_{k=1}^{n-1} w_k\,\nabla c_k .
\]

All `c_k` and the weighted sum can be obtained with **two linear convolutions**:

* `u = conv(h, w)`   (forward shift)  
* `v = conv(h, rev(w))`  (backward shift)  

The gradient is `-(u+v)`.  
Both convolutions are computed efficiently with an FFT of length `2n` (zero‑padded), i.e. in `O(n log n)` time.

---

### 4.  Feasibility projection onto the bounded simplex  

The feasible set is  

\[
\mathcal F=\Bigl\{h\in[0,1]^n\;:\;\sum_{i=0}^{n-1}h_i = \frac{n}{2}\Bigr\}.
\]

After a gradient step we **project** the trial vector onto `𝔽`:

1. **Clip** all components to `[0,1]`.  
2. **Adjust the sum** via a scalar `λ` solving  
   \[
   \sum_i \operatorname{clip}(h_i+λ,0,1)=\frac{n}{2}.
   \]
   The left‑hand side is a monotone piecewise‑linear function of `λ`; a bisection
   (≤30 iterations) yields `λ` to machine precision.  
3. Return `h_i ← \operatorname{clip}(h_i+λ,0,1)`.

This is exactly the “projection onto a simplex with upper bound 1” (Duchi‑Shalev‑Shwartz‑Singer‑Chandra, 2008) and is linear‑time.

### 5.  Projected gradient descent with β‑continuation  

**Initialisation**

* Choose a discretisation size `n`. A good trade‑off is `n = 2·|initial_h|` (≈ 84);
  if time permits a second pass with `n = 3·|initial_h|` (≈ 126) can be tried.
* Build an initial feasible vector:
  * Upsample the provided `initial_h` (repeat each entry) and project onto `𝔽`,
  * or draw `h∼U[0,1]^n` and project.

**Main loop (one restart)**

```
β ← β₀ (e.g. 1.0)      α ← α₀ (initial step length, e.g. 0.5·dx)
repeat while wall‑time < allocated budget:
    # 1. evaluate correlations
    c ← conv(h,h)      # keep shifts 1…n‑1
    # 2. compute smooth surrogate and its gradient
    w ← softmax(-β·c)               # w_k = exp(-βc_k)/∑exp(-βc)
    g ← -(conv(h,w) + conv(h, reverse(w)))   # gradient of Φβ
    # 3. line‑search (Armijo)
    τ ← α
    while True:
        h_candidate ← project_onto_𝔽(h - τ·g)
        if Φβ(h_candidate) ≤ Φβ(h) - 0.1·τ·‖g‖²: break   # sufficient decrease
        τ ← τ/2
        if τ < 1e‑12: break
    h ← h_candidate
    # 4. convergence test
    if ‖τ·g‖ < 1e‑9 or |Φβ(old)-Φβ(new)| < 1e‑12:
        # tighten the surrogate
        β ← min(β·γ, β_max)      # γ≈2, β_max≈200
        α ← α·δ                  # δ≈0.9   (step size slowly shrinks)
```

The loop stops when the wall‑clock reaches ≈ 90 % of the total budget or when
both the gradient norm and the change in `Φβ` fall below tiny tolerances.

**Why this works**

* The soft‑minimum makes the objective differentiable, giving a clear descent direction.
* Raising `β` gradually turns the smooth problem into the original non‑smooth one, allowing the iterates to escape shallow local minima early on.
* The projection guarantees that every iterate satisfies the box and integral constraints exactly, so no penalty terms are needed.
* FFT‑based convolutions keep each iteration cheap (∼ 0.5 ms for `n≈100`).

### 9.  Numerical safeguards and failure‑mode handling  

| Issue | Symptom | Remedy |
|-------|---------|--------|
| **Overflow in `exp(-βc_k)`** | NaNs in the weight vector `w` | Subtract `c_max = max_k c_k` before exponentiation: `exp(-β(c_k - c_max))`. |
| **Gradient vanishes before reaching a good bound** | No improvement despite low `β` | Reset `β` to a smaller value, increase step size `α`, or inject a small random perturbation (swap ε mass between two random indices) and continue. |
| **Projection stalls (sum cannot be satisfied)** | After clipping many entries are at 0 or 1, yet the sum is off | Use the bisection formulation for the λ‑shift; it converges even when many components saturate. |
| **Line‑search fails (τ collapses to 0)** | Too aggressive a step or poor descent direction | Reduce the Armijo constant, fall back to a simple backtracking `τ←τ/2` until a decrease is observed, then continue. |
| **Time budget exhausted early** | Algorithm still improving at termination | Record the best `h` after every iteration; the final return is the best‑so‑far solution. |
| **FFT rounding errors for very small `n`** | Minor violations of the box constraints after projection | Apply a final clipping and re‑project onto `𝔽` before returning the solution. |

All these safeguards are inexpensive compared with the FFT‑based evaluation.
