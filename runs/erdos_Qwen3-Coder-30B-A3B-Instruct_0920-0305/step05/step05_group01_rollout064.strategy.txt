**Stage 3: Gradient of a Single Lag**

- Derive analytic gradient: for a lag ℓ ≥ 0,
  dI_ℓ/dh_j = (1 - h_{j+ℓ}) - (h_{j-ℓ} if j-ℓ ≥ 0 else 0) + (1 if j+ℓ ≥ N else 0).

### 1.  Problem Reformulation  

*For any lag ℓ*  

\[
I_\ell(h)=dx\Bigl(\sum_i h_i-\sum_i h_i h_{i+\ell}\Bigr)
          =dx\Bigl(1-\!\!\sum_i h_i h_{i+\ell}\Bigr) .
\]

Thus reducing the maximum overlap is equivalent to **maximising the minimal autocorrelation**.  
Because each \(I_\ell\) is *linear* in the vector \(h\) once the products \(h_i h_{i+\ell}\) are considered, we can obtain the exact gradient of every lag.

---

### 2.  Smooth Approximation to the Max  

Define the log‑sum‑exp surrogate  

\[
F_\alpha(h)=\frac{1}{\alpha}\log\Bigl(\sum_{\ell}e^{\alpha\,I_\ell(h)}\Bigr),
\qquad\alpha>0 .
\]

*Properties*  

* \(F_\alpha\) is differentiable; \(\displaystyle\lim_{\alpha\to\infty}F_\alpha=\max_\ell I_\ell\).  
* The approximation error is bounded by \(\frac{\log M}{\alpha}\) where \(M=2N-1\) (the number of lags).  
* The gradient is a weighted sum of the individual lag gradients:

\[
\nabla F_\alpha(h)=\sum_{\ell}p_\ell(\alpha,h)\,\nabla I_\ell(h),
\qquad
p_\ell=\frac{e^{\alpha\,I_\ell}}{\sum_j e^{\alpha\,I_j}} .
\]

Choosing a small \(\alpha\) gives a smooth landscape for global exploration; gradually increasing \(\alpha\) focuses the search on the true maximum.

---

### 3.  Analytic Gradient of a Single Lag  

For a given integer lag ℓ (positive or negative) and zero padding outside the domain:

\[
\frac{\partial I_\ell}{\partial h_j}
=\begin{cases}
(1-h_{j+\ell}) - h_{j-\ell} \;+\; 1, &\text{if }j+\ell\ge N,\\[4pt]
(1-h_{j+\ell}) - h_{j-\ell}, &\text{if }0\le j+\ell<N .
\end{cases}
\]

The “+ 1’’ term appears only for the *edge* indices where the shifted partner is outside the interval (because the term becomes simply \(h_j\)).  
The expression can be implemented with vector‑slicing:

*If ℓ ≥ 0*  

```
grad[:N-ℓ]   += p * (1 - h[ℓ:])          # (1‑h_{j+ℓ}) part
grad[N-ℓ:]   += p                        # edge contribution (j+ℓ ≥ N)
grad[ℓ:]     -= p * h[:N-ℓ]             # –h_{j‑ℓ} part
```

*If ℓ < 0* (let d = –ℓ)  

```
grad[d:]     += p * (1 - h[:N-d])        # (1‑h_{j‑d})
grad[:d]     += p                        # edge contribution (j‑d < 0)
grad[:N-d]   -= p * h[d:]                # –h_{j+d}
```

Summing these contributions over all lags with weights \(p_\ell\) yields the full smooth‑max gradient.

### 4.  Projection onto the Feasible Set  

The admissible set is  

\[
\mathcal{F}=\Bigl\{h\in[0,1]^N \;\Big|\; \sum_{i}h_i = N/2\Bigr\}.
\]

Projection onto \(\mathcal{F}\) can be done by the *water‑filling* trick:

1. Add a common scalar \(\lambda\) to every coordinate: \(y_i = \operatorname{clip}(x_i+\lambda,0,1)\).
2. The sum \(S(\lambda)=\sum_i y_i\) is monotone in \(\lambda\).  
3. Binary‑search \(\lambda\) until \(S(\lambda)=N/2\) (tolerance ≈ 1e‑12).  

The result is the Euclidean projection onto the hyperplane‑box intersection, guaranteeing that each update stays feasible.

### 5.  Continuation Projected Gradient Descent  

**Parameter schedules (continuation)**  

| Symbol | Start | End | Schedule |
|--------|-------|-----|----------|
| \(\alpha_t\) (smoothness) | 0.5 | 30–50 | exponential: \(\alpha_t=\alpha_0 (\alpha_f/\alpha_0)^{t/T}\) |
| \(\eta_t\) (step size)    | 0.5 | 1e‑3 | geometric decay: \(\eta_t=\eta_0\rho^{t}\), \(\rho≈0.995\) |

**Iteration** (repeat until a per‑run iteration budget, e.g. 5000, or until the global time budget expires)

1. Compute the full correlation vector `I = correlate(h, 1‑h, mode='full') * dx`.
2. Form the soft‑max weights:  
   `w = exp(alpha * (I - I.max()))` → `p = w / w.sum()`.
3. Assemble the gradient `g` using the slice formulas from **Section 3** (loop over all lags, accumulate `p[ℓ] * contribution`).
4. Tentative update: `h_trial = h - eta * g`.
5. Project `h_trial` onto \(\mathcal{F}\) (Section 4).
6. Evaluate the true objective `C5_trial = max(correlate(h_trial, 1‑h_trial, 'full')) * dx`.  
   *If* `C5_trial ≤ C5_current` *accept* the step; otherwise halve `eta` (up to a few back‑track attempts) and redo step 4–5.
7. Store the best pair `(h_best, C5_best)` seen so far.

The **smooth‑max** surrogate provides a global descent direction that simultaneously reduces all large overlaps, while the continuation on \(\alpha\) moves the algorithm from a smooth basin‑hopping phase to a precise min‑max phase.

### 6.  Multi‑Start Strategy  

Because the problem is non‑convex, launch several independent runs:

* **Seed A** – the supplied `initial_h_values` interpolated to N points.  
* **Seed B** – a *binary* seed: pick exactly N/2 indices uniformly at random and set them to 1, the rest 0.  
* **Seed C** – a *continuous uniform* seed: `h_i ~ U(0,1)` followed by projection.  
* **Seed D+** – perturb the current global best with a small Gaussian jitter (`σ≈0.02`) and re‑run the continuation descent.

Allocate a fixed fraction of the total wall‑clock budget to each seed (e.g., 10 % per seed).  Keep the overall best solution across all seeds.

### 7.  Deterministic Pair‑Exchange Refinement  

After the gradient descent finishes, a **targeted local search** can extract the remaining few‑percent improvement that the smooth‑max gradient may miss.

1. Identify the **worst lag**  
   `ℓ* = argmax I_ℓ`.
2. Compute the *sub‑gradient* of that single lag (`g_i` from Section 3 with `p_ℓ=1` for ℓ*).  
   `g_i > 0` → decreasing `h_i` lowers the worst overlap; `g_i < 0` → increasing `h_i` lowers it.
3. Select a source index `i_src = argmax(g_i)` and a sink index `i_snk = argmin(g_i)`.  
4. Transfer as much mass as allowed: `δ = min( h[i_src], 1‑h[i_snk] )`.  
5. Apply the transfer (`h[i_src]‑=δ; h[i_snk]+=δ`).  Because the transfer respects the box constraints, the sum constraint remains satisfied automatically.
6. Re‑evaluate `C5`.  If it decreased, keep the change; otherwise revert.
7. Repeat until no improving transfer is found or a small iteration cap (≈ 200 moves) is reached.

This step focuses all effort on the most critical lag, often shaving off another 10⁻⁴ – 10⁻³ from the bound.

* Constraints: `0 ≤ h_i ≤ 1` (bounds) and `Σ h_i = N/2` (equality).  
* Use `scipy.optimize.minimize` with `method='SLSQP'` (or `trust-constr`), limit to a few hundred iterations, and initialise with the current best `h`.  
* The optimizer uses finite‑difference gradients of the max‑over‑lags; because we are already in a good basin, only a few iterations are needed.

### 10.  Expected Advantages & Failure Modes  

*Advantages*  

* **Deterministic descent** – no stochastic acceptance, hence fewer wasted evaluations.  
* **Analytic gradient** – exact direction for the smooth surrogate, enabling larger, purposeful steps.  
* **Continuation on α** – starts in a convex‑like regime, avoids being trapped by the rugged landscape of the raw max.  
* **Projection guarantees feasibility** – no need for ad‑hoc repairs.  
* **Pair‑exchange post‑processing** – explicitly targets the worst lag, often yielding the final few‑thousandths improvement that gradient descent alone cannot see.

*Potential pitfalls*  

* If α_f is too small, the surrogate never focuses on the true max and the bound stalls.  
* An excessively large initial step size η₀ can cause divergence; the back‑tracking line‑search mitigates this.  
* Numerical under‑/overflow in the soft‑max exponentials – solved by subtracting the current maximum before `exp`.  
* The pair‑exchange step may become idle when the solution is already saturated; we cap its iterations to avoid wasting time.  
* The total number of lags (2N‑1) leads to O(N²) work per iteration, but with N≈120 this is negligible (< 0.001 s per iteration), leaving ample budget for thousands of iterations.
