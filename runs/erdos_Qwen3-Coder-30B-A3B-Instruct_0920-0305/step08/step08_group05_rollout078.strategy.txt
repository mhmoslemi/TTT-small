### 1. Binary proxy and MILP formulation

#### 1.1 Rationale
If h takes only the values 0 or 1, the integral constraint forces exactly half of the discretisation points to be 1 (because 2·dx·∑hᵢ = 1 ⇒ ∑hᵢ = N/2).  For a binary vector x∈{0,1}ⁿ the overlap for shift ℓ is

\[
f_\ell(x)=\sum_{i=0}^{N-1-\ell} x_i\bigl(1-x_{i+\ell}\bigr)
            =\frac{N}{2}-\sum_{i=0}^{N-1-\ell} x_i x_{i+\ell}.
\]

Thus minimising maxℓ f_ℓ is **equivalent** to maximising the minimum inner product  

\[
g_\ell(x)=\sum_{i=0}^{N-1-\ell} x_i x_{i+\ell}.
\]

The binary formulation is a pure combinatorial optimisation that can be solved to (near‑)optimality by mixed‑integer linear programming (MILP).  Because binary solutions already achieve C₅ ≈ 0.38, a high‑quality binary prototype is an excellent start for the continuous phase.

#### 1.2 MILP model

*Variables*  

- \(x_i\in\{0,1\}\) for \(i=0,\dots,N-1\) (indicator of the step at point i).  
- \(y_{i,\ell}\in\{0,1\}\) for each pair \((i,\ell)\) with \(0\le\ell\le N-1\) and \(i+\ell<N\);   \(y_{i,\ell}=x_i x_{i+\ell}\).  
- \(t\) (real) – lower bound on all inner products \(g_\ell\).

*Constraints*  

1. **Mass constraint** \(\displaystyle \sum_{i=0}^{N-1}x_i = N/2.\)  
2. **Product linearisation** (McCormick for binaries) for every admissible pair \((i,\ell)\):

   \[
   \begin{aligned}
   y_{i,\ell}&\le x_i,\\
   y_{i,\ell}&\le x_{i+\ell},\\
   y_{i,\ell}&\ge x_i + x_{i+\ell} - 1.
   \end{aligned}
   \]

3. **Minimum‑overlap constraints** for each shift \(\ell\)

   \[
   \sum_{i=0}^{N-1-\ell} y_{i,\ell} \;\ge\; t .
   \]

*Objective* maximise \(t\).  

Because \(C_{5}=1 - t\cdot dx\), the optimal MILP value directly yields an upper bound for the continuous problem.

\[

### 5. Expected strengths and possible pitfalls

**Strengths**

* Projected sub‑gradient descent exploits the exact analytical sub‑gradient of the max‑overlap, converging quickly toward a locally optimal continuous shape.

**Pitfalls & Mitigations**
* *MILP size*: If N = 80 still exceeds the solver’s capacity, reduce N to 60 or switch to a pure heuristic binary construction (e.g., greedy placement of 1’s to maximise minimal overlap).  
* *Projection drift*: Re‑project every few hundred iterations to cancel accumulated floating‑point errors.  
* *Flat max‑operator*: When several shifts share the maximal value, the sub‑gradient is a **convex combination** of their individual gradients.  In practice compute the average w‑vector over all active ℓ’s (|c‑max| < 1e‑8) and use it as descent direction.  
* *Annealing stagnation*: If acceptance rate drops below 5 % early, increase temperature slightly or switch to the block‑shift operator, which makes larger structural changes.
