```

4. For a shift `s ∈ {1,…,n‑1}` let  

```

```

   (the term for `s = 0` is always 0).  
   The quantity to be minimised is  

```

```

5. Observe that  

```
C_s(x) = (n/2) – Σ_i x_i·x_{i+s}
```

   Hence minimising the maximum of `C_s` is equivalent to **maximising the minimum overlap**

O_s(x) = Σ_i x_i·x_{i+s}
```

### 2. SDP relaxation of the quadratic problem
Introduce the rank‑1 matrix `X = x xᵀ`.  For any shift `s`

```
O_s(x) = Σ_i X_{i,i+s} = trace(R_s X),
```

where `R_s` is the binary “shift‑matrix’’ that has a 1 at position `(i,i+s)` for all admissible `i` (zeros elsewhere).

We relax the combinatorial constraints:

* `X ⪰ 0` (positive semidefinite).  
* The diagonal of `X` encodes the marginal values: `X_{ii} = μ_i` with `0 ≤ μ_i ≤ 1`.  
* Impose the linear mass constraint on the marginals: `Σ_i μ_i = n/2`.  
* For each shift `s` enforce a lower bound on the overlap:

```
trace(R_s X) ≥ λ          for all s = 1,…,⌊n/2⌋ .
```

(The shifts `s` and `n‑s` give the same overlap, so only half of them are needed.)

The **epigraph variable** `λ` is the (continuous) lower bound on the overlap that we want to make as large as possible.  
The SDP formulation is therefore:

```
maximise   λ
subject to trace(R_s X) ≥ λ    ∀ s = 1,…,⌊n/2⌋
           X ⪰ 0
           X_{ii} = μ_i
           0 ≤ μ_i ≤ 1
           Σ_i μ_i = n/2 .
```

All constraints are linear except the PSD cone, yielding a genuine SDP.

**Why this is different** – The earlier code solved a non‑convex max‑min problem directly with gradient descent.  The SDP provides a *global convex relaxation* that captures the structure of all shift correlations simultaneously.  Its optimum `λ*` is an *upper bound* on the true maximal overlap, and the corresponding relaxed vector `μ = diag(X)` is a high‑quality real‑valued prototype for the optimal step‑function.

### 5. Cardinality‑preserving local refinement (shift‑aware swaps)
The rounded binary vector can be improved further with a *targeted* local search that directly reduces the worst‑case shift count.

**Data needed each iteration**

* The full correlation array `c = correlate(x, 1‑x, mode="full")` (computed once by FFT, O(n log n)).  
* `s* = argmax c` – the shift at which the current `C5` is attained.  
* The set `Bad = { i : x_i = 1  and  x_{i+s*} = 0 }` (positions contributing to the worst shift).  
* The set `Good = { j : x_j = 0  and  x_{j+s*} = 1 }` (positions that would *reduce* the worst‑shift count if swapped).

**Swap move**  
Pick `i ∈ Bad` and `j ∈ Good` (uniformly at random or by greedy scoring) and exchange their values (1↔0).  
*Since the swap reduces the contribution to the worst shift by 1 (and cannot increase it), the move is guaranteed not to worsen the current max.*  
After the swap, recompute the correlation *incrementally*: only the diagonals affected by `i` and `j` need updating, which can be done in O(n) time, but recomputing the whole FFT is still cheap for the modest `n`.  

**Iteration scheme**

* Perform a large number of swaps (e.g. 10 000) or until no improvement is seen for a while.  
* Occasionally (probability 0.1) perform a *neutral* random swap (a 1 with a 0 not in `Bad/Good`) to escape shallow plateaus.  
* Keep the globally best vector seen across the whole refinement phase.

Because each swap strictly improves (or maintains) the maximal overlap, the refinement converges quickly to a **local optimum** that is at least as good as the rounded seed.
