**Overview – Reduce the problem to a low‑dimensional parametric optimisation**

The Erdős C₅ problem asks for a step function  

\[
h:[0,2]\rightarrow[0,1],\qquad 
\int_{0}^{2}h(x)\,dx=1,
\]

that minimises  

\[
C_{5}(h)=\max_{0\le k\le 2}
\int_{0}^{2-k}h(x)\,\bigl(1-h(x+k)\bigr)\,dx .
\]

Instead of treating the discretised vector `h` as a high‑dimensional decision
variable (120 + points) and applying generic black‑box optimisers,
**we encode `h` as a piecewise‑constant function with a small number of
intervals** and solve the resulting *few‑parameter* minimax problem exactly.
All necessary quantities (the integral for any shift, the feasible region,
and the worst‑case shift) can be expressed analytically, so the inner “max over
k’’ reduces to evaluating a handful of candidate shift values.  The outer
optimisation over the interval lengths and heights is then a smooth (or at
worst piecewise‑smooth) low‑dimensional problem that can be solved with a
deterministic global optimiser (branch‑and‑bound, interval arithmetic, or a
dense grid plus local refinement).  After a high‑quality piecewise‑constant
solution is obtained we can optionally up‑sample it and polish it with a
fast correlation‑update routine, but the main improvement comes from the
parametric global search – a completely different methodology from the
previous SLSQP/DE approach.

Below is a step‑by‑step plan that covers the mathematical formulation, the
algorithmic pipeline, implementation details, numerical choices, and the
principal failure modes.

---

### 1. Choose a parametric family for `h`

1. **Number of steps `m`** – start with `m = 5`.  Empirically, optimal solutions
   for the Erdős overlap problem are known to be “almost binary’’: a few
   blocks at height 1, a few at height 0, and at most one fractional block.
   Five intervals are enough to capture this pattern while keeping the
   dimension low (10 variables).

2. **Variables**  

   * Lengths `L = (ℓ₁,…,ℓ_m)`, each `ℓ_j > 0`, with  
     \[
     \sum_{j=1}^{m}\ell_j = 2 .
     \]
   * Heights `A = (a₁,…,a_m)`, each `0 ≤ a_j ≤ 1`.  
   * Mass constraint (integral) becomes  
     \[
     \sum_{j=1}^{m}a_j\ell_j = 1 .
     \]

   The ordered intervals fill `[0,2]` from left to right:
   \[
   I_j=[s_{j-1},s_j),\qquad s_j=\sum_{r=1}^{j}\ell_r .
   \]

3. **Feasibility projection (optional)** – because the constraints are linear,
   any point in the 2m‑dimensional space that satisfies the equality and bound
   constraints can be projected onto the feasible set by a simple linear‑system
   solve followed by clipping.  In practice we will keep the optimisation
   algorithm inside the feasible region, so no explicit projection is needed
   after each step.

### 2. Analytic expression for the overlap integral

For a fixed shift `k` (0 ≤ k ≤ 2) only those interval portions that overlap
contribute to the product term.
Consider any ordered pair of intervals `(I_p, I_q)`.  Their overlap length for a
given shift `k` is  

\[
\omega_{pq}(k)=\max\bigl(0,\;\min(s_p,k+s_q)-\max(s_{p-1},k+s_{q-1})\bigr),
\]

where `s_j` are the cumulative endpoints defined above.
Only when `ω_{pq}(k) > 0` does the pair contribute the amount  

\[
a_p a_q \,\omega_{pq}(k)
\]

to the integral \(\int_{0}^{2-k}h(x)h(x+k)dx\).

The linear part of the objective,
\(\int_{0}^{2-k} h(x)dx\), equals the total mass of the portion of `h`
that lies in the “un‑shifted” interval `[0,2‑k]`.  This can be computed by
traversing the intervals in order and truncating the last intersected interval.
Because `m` is tiny, both the linear and the quadratic contributions can be
evaluated in **O(m²)** operations for any `k`.

Define  

\[
J(k;L,A)=\int_{0}^{2-k}h(x)(1-h(x+k))dx
       =\underbrace{\int_{0}^{2-k}h(x)dx}_{\text{linear term}}
        \;-\;\underbrace{\sum_{p,q}a_pa_q\;\omega_{pq}(k)}_{\text{product term}} .
\]

All quantities are elementary functions of `k`, `ℓ_j` and `a_j`.

---

### 3. Determining the finite set of *critical* shift values

The function `J(k)` is piecewise‑quadratic in `k`.  Its breakpoints occur exactly
when **a boundary of some interval aligns with a (possibly shifted) boundary of
another interval**.  There are only  

\[
K_{\text{crit}} = \{\,|s_p - s_q|,\; |(2-s_p) - (2-s_q)|,\; 
                 s_p,\; 2-s_q\mid 1\le p,q\le m\,\}
\]

distinct shift values in `[0,2]`.  The cardinality is at most `2m²`,
i.e. ≤ 50 for `m=5`.  Between two consecutive critical values `J(k)` is a
smooth quadratic, hence its maximum on that interval is attained at one of the
endpoints.  Consequently, the global maximum `max_{k∈[0,2]} J(k)` can be found by
evaluating `J(k)` **only at the critical shifts** (plus optionally the midpoint
of each interval to be safe against numerical degeneracies).

Thus, for a given `(L,A)` we can compute

```
C(L,A) = max_{k in K_crit} J(k;L,A)
```

exactly (up to floating‑point round‑off) in O(m³) time – negligible.

---

### 4. Formulating the low‑dimensional minimax optimisation

Our objective is  

\[
\min_{L,A} \; C(L,A) .
\]

Subject to:

* `ℓ_j > 0` and `∑ ℓ_j = 2`.
* `0 ≤ a_j ≤ 1`.
* `∑ a_j ℓ_j = 1`.

All constraints are linear, the objective is the **maximum of a finite set of
smooth functions** `J(k;·)`.  This is a classic *convex‑piecewise* minimax problem,
amenable to several deterministic solution strategies:

1. **Epigraph form** – introduce an auxiliary variable `t` and enforce  

   \[
   J(k;L,A) \le t \quad\forall k\in K_{\text{crit}} .
   \]

   This yields a *non‑linear* program with `|K_crit|` inequality constraints.
   Because each `J(k;·)` is a quadratic (bilinear) function of `(L,A)`,
   the constraints are *quadratically‑constrained* and can be handled by a
   *non‑linear programming* (NLP) solver (e.g. IPOPT, SNOPT) with bound
   constraints.  The problem size is < 20 variables and < 60 constraints – easily
   solvable to global optimality by a global branch‑and‑bound wrapper.

2. **Global grid search + local refinement** – generate a dense uniform grid for
   the lengths `(ℓ₁,…,ℓ_{m‑1})` (the last length follows from the sum‑to‑2
   constraint) and for the heights `(a₁,…,a_{m‑1})` (the last height can be
   derived from the mass constraint).  For each grid point evaluate `C(L,A)`,
   keep the best few candidates, and launch a local optimiser (L‑BFGS‑B or
   Nelder–Mead) from each.  Because the dimension is ≤ 10, a fine grid (e.g.
   200 points per variable) is still tractable (≈ 10⁸ evaluations is too much,
   but we can exploit the structure: lengths sum to 2, so we only need to search
   over a simplex; using a barycentric subdivision reduces the number of points
   dramatically).  This approach guarantees that the global optimum will be
   captured if the grid resolution is sufficient.

3. **Interval‑branch‑and‑bound** – treat each variable as an interval, compute
   lower and upper bounds on `C(L,A)` over the interval by convex relaxations
   (replace each quadratic term `a_pa_q` by its McCormick envelope).  Recursively
   split intervals, prune branches whose lower bound exceeds the current best,
   and converge to a provably optimal solution.  Existing open‑source
   interval‑based global optimiser (e.g. `Pyomo` with `glpk` plus custom bounding)
   can be employed.

Any of the three routes is fundamentally different from the high‑dim stochastic
search used previously.  The **key advantage** is that the inner max is reduced
to a handful of explicit evaluations, eliminating the need for expensive FFT
correlations during optimisation.

2. Build the list of critical shift values `K_crit` as described in §3.

#### 5.3 Global optimisation (preferred route: epigraph + NLP)

8. **Optional polishing**:  
   - Upsample the step function to the target `n` (matching the evaluator).  
   - Run a short simulated‑annealing / incremental‑update loop (as described in the previous solution) for a few hundred iterations, always respecting the box and sum constraints.  
   - Keep any improvement; if the bound falls below the target (≈ 0.379) finish early.
9. **Return** the final `h` (as a list), the bound `C₅`, and `n` (the length used for the final evaluation).

### 9. Why this strategy is *materially* different

  becomes a genuine global problem rather than a high‑dimensional heuristic search.
* **Exact inner maximisation** – the troublesome `max_k` is resolved analytically
  by enumerating critical shift values; no FFT or repeated correlation is needed
  during the outer optimisation.
* **Deterministic global optimisation** – the epigraph formulation plus a
  mature NLP/branch‑and‑bound solver yields provable (or at least numerically

  SLSQP/DE combo that only finds local minima.
* **Analytic gradients** – straightforward to derive because each term is a
  product of a height and an overlap length; this eliminates the noisy gradient
  approximations that plagued the previous approach.
* **Flexibility for refinement** – after solving the low‑dim problem we can
  optionally map the solution back to a fine discretisation and apply a few
