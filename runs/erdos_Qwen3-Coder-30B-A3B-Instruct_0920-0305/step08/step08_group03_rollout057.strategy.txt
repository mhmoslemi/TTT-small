`∫₀² h = 1` that minimises  

```
C5(h) = max_{0≤k≤2} ∫₀^{2‑k} h(x)·(1‑h(x+k)) dx .
```

The evaluation used in the benchmark is the discrete version  

`C5 = dx * max( correlate( h , 1‑h , mode='full') )`  

with `dx = 2/n`.  
The new plan abandons the high‑dimensional black‑box optimisation of the previous
solution and **reduces the problem to a low‑dimensional deterministic global
optimisation** by representing `h` as a piecewise‑constant function with a few
intervals.  Because the inner “max over k’’ is a piecewise‑quadratic function of
the interval parameters, its maximum can be evaluated exactly by checking only a
finite set of *critical* shift values.  The whole problem becomes a small
non‑linear (in fact quadratic) minimax programme that can be solved to global
optimality with branch‑and‑bound, interval arithmetic, or a dense grid plus local
refinement.  After a high‑quality piecewise‑constant solution is obtained,
we optionally up‑sample it and perform a brief high‑resolution polishing step.
All steps are described in detail below.

### 1. Parametric representation of `h`

1. **Choose the number of steps `m`.**  
   Empirically the optimal Erdős construction consists of a few blocks at
   height 0, a few at height 1, and at most one block at an intermediate
   height.  `m = 5` (or `m = 6` for a safety check) provides enough flexibility
   while keeping the dimension tiny (≤ 10 free variables).

2. **Variables**  
   *Lengths* `ℓ₁,…,ℓ_m  > 0` with `∑_{j=1}^{m} ℓ_j = 2`.  
   *Heights* `a₁,…,a_m  ∈ [0,1]` with the mass constraint  

   `∑_{j=1}^{m} a_j ℓ_j = 1`.

   The function is defined on the ordered intervals  

   `I_j = [s_{j‑1}, s_j)` where `s_0 = 0`, `s_j = ∑_{r≤j} ℓ_r`.

3. **Eliminate one variable per group** to reduce dimensionality.  
   *Lengths*: keep `ℓ₁,…,ℓ_{m‑1}` as independent; set `ℓ_m = 2 – Σ_{j<m} ℓ_j`.  
   *Heights*: keep `a₁,…,a_{m‑1}` as independent; set

### 2. Exact evaluation of the overlap integral for a given shift `k`

For any shift `k∈[0,2]` only the part of the domain that remains overlapped,
`[0,2‑k]`, contributes to the product term.  The integral splits into a linear
part and a quadratic part:

```
J(k) = ∫₀^{2‑k} h(x) dx               (linear term)
       – ∫₀^{2‑k} h(x)·h(x+k) dx      (product term)
```

Both terms can be expressed analytically using the interval data.

*Linear term* – Walk through the intervals in order, accumulating the length of
the portion of each interval that lies inside `[0,2‑k]`.  For interval `I_j`
the contributed length is  

```
len_j(k) = max( 0 , min(s_j, 2‑k) – max(s_{j‑1}, 0) )
```

The linear term equals `Σ_j a_j · len_j(k)`.

*Quadratic term* – For each ordered pair `(p,q)` compute the overlap of
`I_p` with the shifted interval `I_q + k`.  The overlap length is

```
ω_{pq}(k) = max( 0 , min(s_p, s_q + k) – max(s_{p‑1}, s_{q‑1}+k) )
```

Only pairs with a positive `ω_{pq}` contribute.  The product term is  

```
Σ_{p,q} a_p·a_q·ω_{pq}(k) .
```
