**Objective reformulation**

For a discretisation with `N` points (`dx = 2/N`) let  

```
h = (h₀,…,h_{N‑1}) ,     0 ≤ h_i ≤ 1 ,    Σ h_i = M = N/2 .
```

Define the “overlap” for a shift `k` (index shift, zero‑padding)  

```
F_k(h) = Σ_i h_i·(1 – h_{i+k})  =  M – Σ_i h_i·h_{i+k} .
```

Hence  

```
C5(h) = dx·max_k F_k(h) = dx·( M – min_k Σ_i h_i·h_{i+k} ) .
```

Minimising `C5` is **equivalent** to **maximising** the *minimum* aperiodic autocorrelation  

```
A_k(h) = Σ_i h_i·h_{i+k} .
```

The problem is non‑convex because of the bilinear products `h_i·h_{i+k}`.  
The new plan tackles it in two stages:

1. **Global binary optimisation** – obtain a high‑quality *0/1* pattern that maximises the worst‑case autocorrelation.  
2. **Continuous refinement** – starting from the binary pattern, perform a deterministic sub‑gradient descent that moves the values off the corners while preserving the feasibility constraints, followed by a lightweight stochastic fine‑tuning.

Both stages are explicitly engineered to respect the overall time budget (`budget_s`) and work with modest `N` (≤ 200) so that evaluation is cheap.

### 1. Binary MILP (“max‑min autocorrelation”)

* `w_{k,i}` (continuous, 0 ≤ w_{k,i} ≤ 1) – auxiliary variables that will enforce `w_{k,i}=y_i·y_{i+k}` for every admissible shift `k≥1` and position `i`.  
* `t` (real) – a lower bound on **all** autocorrelations `A_k`.

#### 1.2 Constraints


### 2. Deterministic sub‑gradient descent from a feasible point

After obtaining any feasible `h⁰` (binary or random), we treat the original continuous problem directly.

#### 2.1 Gradient of the worst shift
For a particular shift `k`,  

```
F_k(h) = M – Σ_i h_i·h_{i+k}
```

The derivative w.r.t. component `h_j` (indices outside `[0,N‑1]` are treated as 0) is

```
∂F_k/∂h_j = 1 – h_{j+k} – h_{j‑k} .
```

The *sub‑gradient* of `C5(h) = max_k F_k(h)` is simply the gradient of the **active** shift  

```
k* = argmax_k F_k(h) .
```

So we can compute the sub‑gradient vector `g` with components  

```
g_j = 1 – h_{j+k*} – h_{j‑k*} .
```

(The two shifted terms are omitted when the index falls outside the array.)

#### 2.2 Projection onto the feasible polytope
We must stay inside  

* Box: 0 ≤ h_i ≤ 1.  
* Hyperplane: Σ h_i = M.

A fast two‑step projection suffices:

1. **Box clipping**: `h ← np.clip(h, 0, 1)`.
2. **Affine‑box projection** (water‑filling): find a scalar λ such that  

```
Σ_i clamp(h_i + λ, 0, 1) = M .
```

Because the function `S(λ) = Σ clamp(h_i+λ,0,1)` is monotone, a short bisection on λ∈[‑1, 1] converges in ≤ 30 iterations, O(N) each.

#### 2.3 Iteration rule
With step size schedule `α_t = α₀ / sqrt(t)` (α₀ chosen e.g. `0.5·dx`), perform  

```
h ← project_sum_box( h – α_t·g )
```

After each update evaluate `C5` using the **FFT‑based correlation** (O(N log N)). Keep the best iterate seen so far.

Run this deterministic loop for `τ₂ = 0.35·budget_s` seconds (or a fixed number of iterations that comfortably fits). The method directly attacks the worst shift, converges much faster than generic SLSQP, and usually improves the binary MILP bound by a few 10⁻⁴.
