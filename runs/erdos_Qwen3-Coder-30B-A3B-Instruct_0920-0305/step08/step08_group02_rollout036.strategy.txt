**Overview**  
The new pipeline treats the Erdős overlap problem as a *max‑min* autocorrelation task and decouples it into two fundamentally different phases:

1. **Global combinatorial optimisation** – find the best binary (0/1) step‑function for the chosen discretisation by solving a *mixed‑integer linear programme* (MILP).  
2. **Continuous refinement** – starting from the binary optimum, perform a *deterministic sub‑gradient descent* that directly reduces the worst‑case overlap, followed by a lightweight simulated‑annealing stage to escape possible plateaus.

Both phases respect the box and sum constraints exactly and use fast FFT‑based correlation for evaluation. The approach is mathematically distinct from the earlier SLSQP‑based local search and does not rely on ad‑hoc peak insertion.

### 1.  Discretisation and notation  

* Choose a modest number of points `N` (default **120**; if the MILP proves too heavy we fall back to `N = 100` or `80`).  
* `dx = 2 / N`.  
* Decision variables: a vector `h ∈ [0,1]^N` with `∑ h_i = M = N/2`.  
* For a shift `k (0 ≤ k < N)` the discrete overlap is  
  ```
  F_k(h) = Σ_i h_i (1 – h_{i+k}) = M – Σ_i h_i h_{i+k}.

* Minimising `C5 = dx·max_k F_k(h)` ⇔ **maximising**

### 2.  MILP for the binary sub‑problem  

We first restrict `h_i` to be binary (`0` or `1`).  In this setting the product `h_i h_{i+k}` is also binary and can be *linearised* with auxiliary variables.

#### 2.1 Variables  

| Symbol | Type | Meaning |
|--------|------|---------|
| `y_i`   | binary (`{0,1}`) | indicator of a “high” interval (`h_i = y_i`). |
| `w_{k,i}` | continuous, `0 ≤ w ≤ 1` | intended to equal `y_i·y_{i+k}` for each admissible pair. |
| `t`     | real | lower bound on every autocorrelation value. |

#### 2.2 Linear constraints  

* **Cardinality**: `Σ_i y_i = M`.  
* **Product linearisation** (for every shift `k = 1,…,N‑1` and `i = 0,…,N‑k‑1`):
  ```
  w_{k,i} ≤ y_i
  w_{k,i} ≤ y_{i+k}
  w_{k,i} ≥ y_i + y_{i+k} – 1        (forces w = y_i·y_{i+k})
  w_{k,i} ≥ 0
  ```
* **Minimum autocorrelation**: for each shift `k`
  ```
  Σ_i w_{k,i} ≥ t .
  ```
* **Bounds on t**: `0 ≤ t ≤ M`.  
* (Optional) **Symmetry break**: fix `y_0 = 1` to halve the search space.

All constraints are linear; the only integer variables are the `y_i`.  The MILP therefore contains:
* `N` binary variables,
* `N(N‑1)/2` continuous auxiliary variables,
* ≈ `3·N(N‑1)/2` linear constraints plus `N` autocorrelation constraints.

#### 2.3 Objective  

```
maximise   t .
```

### 3.  Deterministic sub‑gradient descent on the continuous problem  

The binary solution is a good *starting point* but the true optimum may involve fractional values.  We now minimise `C5(h) = dx·max_k F_k(h)` by following the sub‑gradient of the *active* shift.

#### 3.1 Gradient of the worst shift  

For a fixed shift `k`

```
F_k(h) = M – Σ_i h_i h_{i+k}.
```

Derivative w.r.t. component `h_j` (indices outside `[0,N‑1]` are treated as 0) :

```
∂F_k/∂h_j = 1 – h_{j+k} – h_{j‑k}.
```

Let `k* = argmax_k F_k(h)` be the current worst shift (break ties arbitrarily).  
The sub‑gradient of `C5` at `h` is therefore the vector

```
g_j = 1 – h_{j+k*} – h_{j‑k*}.
```

The computation of `g` costs O(N) because only two shifted copies of `h` are needed.

#### 3.2 Exact projection onto the feasible set  

We must maintain both the box `[0,1]` and the affine sum constraint `Σ h_i = M`.  This is done in two steps:

1. **Box clipping**: `h ← clip(h, 0, 1)`.  
2. **Projection onto the simplex with bounds** (water‑filling): find a scalar λ such that  

   ```
   Σ_i clamp(h_i + λ, 0, 1) = M .
   ```

   `clamp(z,0,1) = min(max(z,0),1)`.  
   Because the left‑hand side is monotone in λ, a short bisection on the interval `[-1, 1]` (tight for our variables) converges in ≤ 30 iterations, each O(N).  The result `proj_sum_box(h)` is the unique Euclidean projection onto `{h∈[0,1]^N : Σh = M}`.

#### 3.3 Iteration rule  

Choose an initial step size `α₀` (e.g. `α₀ = 0.5·dx`).  For iteration `t = 1,2,…` :

```
h ← proj_sum_box( h – (α₀/√t) * g )
```

After the update evaluate `C5(h)` via the **FFT‑based correlation** (`O(N log N)`).  
If the new `C5` is lower than the best seen, store the iterate as the current best.  The step‑size schedule `α_t = α₀/√t` guarantees diminishing moves and provable convergence to a stationary point of the non‑smooth objective.

Run this deterministic phase for **τ₂ = 0.35·budget_s** seconds (or a fixed number of iterations that comfortably fits).  Because each iteration is O(N) plus a cheap FFT, tens of thousands of steps fit easily into the allotted time.

### 4.  Stochastic fine‑tuning (final 20 % of the budget)

* **Two‑index swap move** – pick distinct indices `i, j`.  Choose a small `δ` uniformly in `[‑0.02,0.02]`.  
  Update  
  ```
  h_i ← h_i + δ,   h_j ← h_j – δ
