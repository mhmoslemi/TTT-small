### 1‑ Goal and Overview  
We must produce a step‑function `h:[0,2]→[0,1]` (discretised on a uniform grid) with  

* **Mass constraint** ∑ h[i]·dx = 1 ⇔ ∑ h[i] = n/2,  
* **Box constraint** 0 ≤ h[i] ≤ 1,  

that minimises  

\[
C_5(h)=\max_{k\in\mathbb Z}\int_0^2 h(x)\,(1-h(x+k))dx
      =\max_{k} L(k),\qquad 
L(k)=dx\sum_{i} h_i\bigl(1-h_{i+k}\bigr)
\]

(the correlation is computed with zero padding).  
The problem is non‑convex, highly non‑smooth (max‑over‑shifts) and includes a quadratic term `h_i·h_{i+k}`. The previous solution relied on SLSQP on the full‑resolution vector; we will adopt a **different, two‑level scheme**:

1. **Global exploration** on a *low‑dimensional* parametric family (piecewise‑constant blocks).  
2. **Local refinement** by a **projected sub‑gradient descent** that directly attacks the max‑over‑shifts objective, with occasional stochastic “mass‑transfer’’ moves to escape plateaus.

Both phases use the fast FFT‑based correlation for evaluation and a fast **water‑filling projection** to enforce the box‑plus‑sum constraint.

### 3‑ Parametric family for the *global* search  

We represent `h` as **K contiguous blocks** (`K = 8` works well).  

| Block `b` | Width `w_b` (≥0) | Height `a_b` (∈[0,1]) |
|-----------|-----------------|----------------------|
| 1 … K     | Σ_b w_b = 2      | free                 |

The mapping from a vector of free parameters `θ` to a concrete `h` is:

1. **Widths** – sample `u_b = exp(θ_b)` for `b=1…K`; normalise  
   \[
   w_b = 2\frac{u_b}{\sum_{c=1}^K u_c}.
   \]
   This guarantees positivity and the total length `2` automatically.

2. **Heights** – map `θ_{K+b}` through a sigmoid,  
   \[
   a_b = \sigma(θ_{K+b}) = \frac{1}{1+e^{-θ_{K+b}}},
   \]
   guaranteeing `0<a_b<1`. (A tiny epsilon can be added after projection to avoid exact 0/1 if desired.)

3. **Rasterisation** – for each grid point `x_i = (i+½)·dx` we find the block index `b(i)` via `np.searchsorted` on cumulative widths and set  
   `h_i = a_{b(i)}`.

4. **Projection onto the sum‑box** – after rasterisation we *exactly* enforce the mass constraint using a **water‑filling projection**:
   - Compute λ such that `clip(h+λ,0,1)` has sum `S`.  
   - The λ can be obtained in O(n) by sorting `h` once (the standard projection onto a simplex with upper bound 1).  
   This step also guarantees `0≤h≤1`.  

The parametric mapping collapses the original `n≈300` variables to a **12‑dimensional** search space (8 widths + 8 heights → 16 before the sigmoid, but one width degree of freedom is removed by normalisation, leaving 15; we keep 16 and let the projection take care of the sum).

### 5‑ Local Refinement: **Projected Sub‑Gradient Descent (PSGD)**  

#### 5.1 Mathematical sub‑gradient  

For a fixed integer shift `s` (the lag index in the discrete correlation, `s = k - (n-1)`),

\[
L(s) = dx\sum_i h_i\bigl(1-h_{i+s}\bigr).
\]

Its (sub‑)gradient w.r.t. `h_i` (including the dx factor) is  

\[
\nabla_i L(s) = dx\bigl(1 - h_{i+s} - h_{i-s}\bigr),
\]
where out‑of‑range indices are treated as zeros.

The global objective is `C5 = max_s L(s)`.  
If `S = {s*}` is the set of **active shifts** achieving the maximum (often a single shift, possibly a few ties), a sub‑gradient of `C5` is any convex combination of the gradients of the active shifts.  
We use the **uniform average**:

\[
g = \frac{1}{|S|}\sum_{s\in S}\nabla L(s).
\]

#### 5.2 Descent step  

A descent move for a scalar step‑size `η>0` is  

\[
h^{\text{new}} = \operatorname{Proj}_{[0,1],\; \sum = S}\bigl(h - η\,g\bigr),
\]

where `Proj` = *water‑filling projection* defined in §3.4.  
Because each individual gradient term sums to zero (the constant “1’’ part cancels the neighbour contributions), the **raw update `h - η g` already respects the mass constraint up to boundary effects**; the projection only corrects clipping violations.

#### 5.3 Implementation details  

1. **Correlation & active shifts**  
   - Compute the *full* correlation array once per iteration with FFT:  

     ```
     corr = real(ifft(fft(h[::-1]) * fft(1-h))) * dx
     max_val = corr.max()
     active = np.where(corr >= max_val - 1e-12)[0]      # indices of active lags
     shifts = active - (n-1)                           # convert to signed shift
     ```

2. **Gradient assembly (vectorised, O(n·|S|))**  

   Initialise `g = np.zeros(n)`.  
   For each signed shift `s`:
   - Add `-dx` to *all* positions (the constant `1` term).  
   - If `s ≥ 0`:
        ```
        g[:n-s] += -dx * h[s:]          # contribution of -h_{i+s}
        g[s:]   += -dx * h[:n-s]        # contribution of -h_{i-s}
        ```
   - If `s < 0` (let `t = -s`):
        ```
        g[t:]   += -dx * h[:n-t]
        g[:n-t] += -dx * h[t:]
        ```
   - After looping, divide by `|S|` (average).

   Finally reverse sign to obtain the **descent direction** `d = -g`.

3. **Adaptive step‑size**  
   - Start with `η = 0.5` (large because `dx≈0.0067` makes the raw gradient small).  
   - After each successful descent (new C5 < old C5) *increase* `η` by 5 % up to a ceiling (`η_max = 2.0`).  
   - After a failed attempt, *decrease* `η` by 30 % (but keep `η ≥ 1e‑4`).  
   - This simple “gain‑and‑loss” schedule automatically settles to a step that produces progress.

4. **Projection** – the water‑filling routine from §3.4 (O(n log n) due to a sort).  

5. **Acceptance & best‑so‑far tracking**  
   - Keep `h_best` and `c5_best`.  
   - If a trial step improves `c5_best`, store it.  
   - The current iterate `h_cur` is always the last *feasible* vector (whether it improves or not).

#### 5.4 Escaping Plateaus – **Stochastic Mass‑Transfer Moves**  

Every `T_swap = 30` iterations (or when no improvement has occurred for `N_noimp = 200` steps):

1. **Pick two indices** `i⁺, i⁻` uniformly at random such that `h[i⁺] < 1` and `h[i⁻] > 0`.  
2. **Transfer** a random amount `ε = min(0.02, h[i⁻]) * rand()` from `i⁻` to `i⁺`.  
3. **Project** (the transfer already preserves the sum, only clipping may be needed).  
4. **Accept** if the new C5 is ≤ current C5 + δ (δ=1e‑4) – a weak *Metropolis* acceptance that tolerates tiny deteriorations, providing stochastic exploration.

These swaps are cheap and can break symmetry that the pure gradient descent cannot.
