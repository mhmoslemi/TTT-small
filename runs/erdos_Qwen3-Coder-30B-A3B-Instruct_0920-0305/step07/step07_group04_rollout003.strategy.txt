### 1. Reformulation as a Linear‑Programming (LP) relaxation

For any shift `k`

```
Σ_i h[i]·(1 – h[i+k]) = Σ_i h[i] – Σ_i h[i]·h[i+k].
```

The first sum is constant (`S = n/2`).  The difficulty is the bilinear term
`h[i]·h[i+k]`.  Introduce auxiliary variables  

```
p[i,j] ≈ h[i]·h[j]   for all i,j with 0 ≤ i,j < n .
```

Because all `h[i]` lie in `[0,1]`, the convex hull of the product is given by
the McCormick inequalities:

```
p[i,j] ≥ 0
p[i,j] ≤ h[i]
p[i,j] ≤ h[j]
p[i,j] ≥ h[i] + h[j] – 1 .
```

These are linear, so the feasible set {(h,p)} is a polytope.

Define a scalar `t` that bounds every correlation:

```
t ≥ Σ_i h[i] – Σ_{i : i+k < n} p[i,i+k]      for every shift k = 0,…,n‑1 .
```

(The same constraints hold for negative shifts; symmetry lets us keep only
non‑negative `k`.)

**LP model**

```
minimise   t
subject to
    0 ≤ h[i] ≤ 1                     (i = 0..n‑1)
    Σ_i h[i] = n/2
    McCormick constraints for all (i,j)
    t ≥ S – Σ_{i: i+k<n} p[i,i+k]    (k = 0..n‑1)
```

Solving this LP yields a *relaxed* optimal `h`.  Because the relaxation allows
`p[i,j]` to be larger than the true product when both `h[i]` and `h[j]` are
fractional, the LP provides a **lower bound** on the achievable `C5`.  Nevertheless,
the `h` itself respects the original box and sum constraints, and we can evaluate
its *actual* `C5` (using the true product) immediately.  In practice the relaxation
is very tight for the Erdős problem and often produces a usable near‑optimal shape.
