\[
C_5(h)=\max_{k}\int_0^{2}h(x)\bigl(1-h(x+k)\bigr)\,dx .

* 0 ≤ h[i] ≤ 1 for all i,  
* \(\displaystyle\sum_{i=0}^{n-1}h[i]\;dx =1\) with \(dx=2/n\)  ⇔ \(\sum h[i]=n/2\).

The whole pipeline is run from several diverse starts and the best result found before the time budget expires is returned.

### 1.  Reformulation

Write the discrete correlation  

\[
c_k = \sum_{i}h_i\bigl(1-h_{i+k}\bigr) \qquad (k=-(n-1),\dots ,n-1),
\]

where out‑of‑range indices give a contribution 0.  
Then  

\[
C_5(h)=dx\;\max_k c_k .
\]

Instead of the hard max we use the *soft‑max* with temperature ε>0  

\[
F_ε(h)=ε\log\!\Bigl(\sum_{k}e^{c_k/ε}\Bigr)
      =\sum_{k}w_k\,c_k,
\qquad 
w_k=\frac{e^{c_k/ε}}{\sum_j e^{c_j/ε}} .
\]

For any ε,  \(F_ε(h)\)  is a smooth upper‑bound of \(\max_kc_k\) and converges to it as ε→0.  Its gradient is a convex combination of the gradients of the individual correlations:

\[
\frac{\partial c_k}{\partial h_i}= (1-h_{i+k})-h_{i-k},
\]

with the convention \(h_{j}=0\) when j∉[0,n‑1].

### 2.  Projection onto the feasible set

The feasible set is the intersection of the box **[0,1]ⁿ** with the affine hyper‑plane  
\(\sum_i h_i = n/2\).  The projection can be performed with the classic *water‑filling* (binary‑search for a Lagrange multiplier λ):

```
clip(x+λ) = np.clip(x+λ,0,1)
choose λ such that Σ clip(x+λ) = n/2 .
```

The routine is O(n log 1/δ) and extremely cheap compared with the gradient step.

--------------------------------------------------------------------
### 3.  Gradient computation – O(n log n) via FFT

The vector of correlation values \(c\) is obtained efficiently with an FFT‑based convolution:

```
c = real( ifft( fft(h[::-1],L) * fft(1-h, L) ) )   # L = 2*n-1
```

The weight vector **w** is built from the soft‑max (shifted by max(c) to avoid overflow).

The gradient of \(F_ε\) can also be written as a pair of convolutions:

```
total = 1.0                         # Σ w_k = 1 after normalisation
conv1 = convolve(w, h, mode='full')       # Σ w_k * h[i-k]
conv2 = convolve(w[::-1], h, mode='full')# Σ w_k * h[i+k]
offset = n-1
grad_i = total - (conv1[offset:offset+n] + conv2[offset:offset+n])
```

All three FFT‑based convolutions are O(n log n); for n≈150 they take a few microseconds.

### 5.  Sub‑gradient polishing (ε≈0)

When ε reaches 0.01 the soft‑max is already a tight approximation.  The algorithm now switches to a *pure sub‑gradient* step that touches only the most critical shifts:

```
k* = argmax_k c_k                # worst shift(s)
grad_i = (1 - h[i+k*]) - h[i-k*]   (with bounds checking)
h ← h - α_small * grad
project
```

A few hundred such steps (α_small≈0.005) finish the descent, eliminating the remaining “soft‑max bias”.
