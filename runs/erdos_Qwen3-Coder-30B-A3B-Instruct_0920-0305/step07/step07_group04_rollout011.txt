    # due to linear correlation with zero padding, positive shifts map to 
    # negative shifts in the full correlation via symmetric properties
    # For simplicity and to stay within our budget, we'll work with full correlation
    
    # Since we care about C5 = max_k integral h(x)(1-h(x+k)) dx
    # We can instead think of correlations for each shift k from 0 to n-1
    # To do this efficiently, we create a matrix of p variables to store correlations

    P = cp.Variable((n_points, n_points), name="P")
