### 1.  High‑level overview  

The goal is to produce a vector **h** on a uniform grid of the interval [0,2] that satisfies  

* 0 ≤ h[i] ≤ 1 for all i,  
* Σ h[i] · dx = 1   (i.e. Σ h[i] = n/2 for n grid points, because dx = 2/n),

and that minimises  

```
C5(h) = max_k  ∫_0^2 h(x)·(1‑h(x+k)) dx
```

In the discrete setting the integral is evaluated by the linear convolution  

```
C5(h) = dx * max( correlate( h , 1‑h , mode='full' ) )
```

The previous solution used generic pattern‑search and SLSQP.  
The new method builds on **two observations** that lead to a qualitatively different optimiser:

1. **Extremal solutions are binary** – the feasible region is a convex polytope and the objective is a (piecewise) convex function of the quadratic form   h·h.  Empirically the best known constructions are 0/1 step functions, so we search first in the binary sub‑space.
2. **A single shift dominates the max** – for any candidate the worst shift `k*` is the one that attains `C5`.  Swapping a “1‑0” pair that occurs for this shift with a “0‑1” pair eliminates exactly one unit of overlap for that shift without breaking the sum constraint.  Repeating such swaps drives the worst overlap down rapidly.

The algorithm therefore proceeds in three phases:

| Phase | Purpose | Method |
|------|---------|--------|
| **A – Binary greedy optimisation** | Quickly reach a high‑quality local optimum | Repeatedly target the current worst shift and perform beneficial **pairwise swaps** (1↔0) until no such swap exists. |
| **B – Global exploration (simulated annealing)** | Escape local minima and explore the combinatorial landscape | Starting from the best binary solution, repeatedly propose random swaps; accept them with a Metropolis probability that follows a cooling schedule. |
| **C – Continuous refinement** | Exploit any fractional improvement that may exist beyond the binary hull | Run a constrained gradient‑based optimiser (SLSQP) on the continuous variables, initialized from the best binary vector and keeping the sum constraint exactly (projection onto the simplex). |

All three phases are **time‑aware**: the total runtime (≤ budget_s) is split among them, and the loop checks the elapsed time at each iteration, returning the best‑found vector before the deadline.

### 2.  Detailed algorithmic steps  

#### 2.1 Common utilities (used in every phase)

1. **Grid size**  
   *Pick a modest even size that still gives a decent resolution – e.g. `n = 256`.  The sum constraint is then `TARGET_SUM = n/2`.*

2. **Fast C5 evaluation** – a helper `c5(h)`  
   * Compute the linear convolution with FFT  
     ```
     L = 2*n-1
     NFFT = 1 << ((L-1).bit_length())      # next power of two
     H = np.fft.rfft(h, NFFT)
     B = np.fft.rfft(1.-h, NFFT)
     conv = np.fft.irfft(H*B, NFFT)[:L]
     return dx * conv.max()
     ```  
   * Returns a scalar C5 value (the “bound”) and optionally the index of the maximal entry (needed for the greedy phase). The FFT cost is O(n log n) and is negligible for n≈256.*

3. **Projection onto the sum‑and‑box constraints** (used only in the continuous phase)  
   *Given any vector `x`, first clip to `[0,1]`.  Then find a scalar λ such that `clip(x+λ,0,1)` has the required sum `TARGET_SUM`.  This is a standard 1‑dimensional root‑finding (binary search) that converges in < 50 iterations.*

4. **Shift handling** – conversion from the convolution index to an integer shift `k` (grid steps):  
   *`shift = max_index - (n-1)`.  Positive shift means the overlapping region is `h[i] * (1‑h[i+shift])` for `i = 0 … n‑shift‑1`; negative shift is analogous.*

#### 2.2 Phase A – Binary Greedy Optimisation  

```
Input: n (grid size), TARGET_SUM = n/2
Output: binary vector h_best, value C5_best
```

1. **Random binary start** – create a vector with exactly `TARGET_SUM` ones by sampling without replacement.
2. **Loop until dead‑end**  
   a. Compute `conv = correlate(h, 1‑h, mode='full')` via the FFT helper.  
   b. Locate `max_idx`, `shift = max_idx - (n-1)`.  
   c. Determine the overlapping index pairs for this shift:  

      - If `shift ≥ 0` → `i_range = 0 … n‑shift‑1`, `j_range = i_range + shift`.  
      - If `shift < 0`  → `i_range = -shift … n‑1`, `j_range = i_range + shift`.  

      The pair `(i, j)` contributes `h[i] * (1‑h[j])` to the current max C5.
   d. **Find improving candidates**  
      *Let `A = { i ∈ i_range | h[i]==1 and h[j]==0 }`* (a **1‑0** mismatch for the worst shift)

   e. **Swap** – pick a random `i ∈ A` and `j ∈ B` (or choose the pair that gives the largest reduction if a cheap ranking is desired). Perform the swap `(h[i], h[j]) = (0,1)`.  
   f. **Repeat** from step a with the updated vector.

3. **Result** – after the loop exits we have a *greedy‑optimal* binary vector for this start. Record its C5.  

4. **Multiple random restarts** – repeat the whole process a large number of times (e.g. 200–500) while respecting the overall time budget. Keep the best vector across all runs.

#### 2.3 Phase B – Simulated Annealing on the binary space  

The greedy phase typically finds a *plateau*; a global search is needed to jump between plateaus.

1. **Initial state** – the best binary vector from Phase A (call it `h_cur`).  
2. **Temperature schedule** – let `T0` be a fraction (e.g. 0.03) of the initial C5 value.  
   Use a **linear decay**: `T(t) = T0 * (1 – t / τ)`, where `τ` is the allotted annealing duration (≈ 0.5 × budget_s).  
   Optionally switch to a geometric decay `T *= 0.995` each iteration.
3. **Neighbour proposal** – pick uniformly at random a pair `(i,j)` with `h[i]=1, h[j]=0` and swap them (the sum stays constant).  
4. **Evaluation** – compute `C5_new` via the FFT helper (very cheap).  
5. **Acceptance rule** – if `C5_new ≤ C5_cur` accept outright; otherwise accept with probability `exp(-(C5_new‑C5_cur)/T)`.  
6. **Update** – if accepted, set `h_cur = h_new`, `C5_cur = C5_new`.  Keep track of the *best ever* vector (`h_best`, `C5_best`).  
7. **Loop** – continue until the annealing time expires.  
8. **Restart logic** – when improvement stalls for a while, optionally re‑initialise `h_cur` from `h_best` perturbed by a few random swaps (e.g. 5–10) to inject diversity.
