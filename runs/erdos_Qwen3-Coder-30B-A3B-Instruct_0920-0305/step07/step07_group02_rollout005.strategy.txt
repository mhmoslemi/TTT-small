**Overview**  
The goal is to produce a step‑function `h` on `[0,2]` (discretised as a vector) that satisfies  

* `0 ≤ h[i] ≤ 1` for every index,  
* `∑ h[i] · dx = 1`  (i.e. exactly half the entries are equal to 1 when the vector is binary),  

and minimises  

```
C5 = max_k  ∫ h(x)·(1 – h(x+k)) dx
```

Because  

```
∫ h(x)·(1 – h(x+k)) dx = 1 – ∫ h(x)·h(x+k) dx,
```

minimising `C5` is equivalent to **maximising the minimum autocorrelation** of `h`.  
The optimum is expected to lie on an extreme point of the feasible polytope, i.e. on a binary (0/1) function, with possible tiny fractional adjustments that further improve the bound.  

The proposed algorithm therefore consists of three distinct phases, each exploiting a different principle and therefore very different from the previous pattern‑search / SLSQP pipeline:

1. **Binary greedy descent on the worst shift** – a deterministic, combinatorial optimisation that directly attacks the shift where the overlap is maximal.  
2. **Global simulated‑annealing on binary vectors** – a stochastic search that can escape the greedy local minima.  
3. **Fine‑grained continuous refinement** – a short constrained gradient optimisation that allows fractional values to shave off the last decimal places.

All phases share a single fast evaluator based on FFT‑based linear convolution.

### 1. Fast evaluation of `C5`

Define `dx = 2.0 / N` where `N` is the number of discretisation points (chosen later).  

```
def c5_fft(h):
    # linear (non‑circular) convolution of h with (1‑h)
    n = len(h)
    nfft = 1 << ((2*n-1).bit_length())          # next power of two
    H = np.fft.rfft(h, nfft)
    B = np.fft.rfft(1.0 - h, nfft)
    conv = np.fft.irfft(H * B, nfft)[:2*n-1]   # length 2N‑1
    return np.max(conv) * dx
```

All three optimisation phases call this routine; it runs in `O(N log N)` and is fully vectorised.

### 2. Discretisation choice

*Pick a power of two for maximal FFT speed* – `N = 256`.  
`N` is even, so the exact sum constraint is `target_sum = N/2 = 128` (i.e. exactly half the entries must be 1 in a binary representation).  
The grid spacing `dx = 2/N = 0.0078125` is fine enough that the discrete objective is a reliable proxy for the continuous integral, yet still cheap to evaluate.

### 3. Phase‑I – Greedy worst‑shift improvement on binary vectors  

**Rationale** – For a given shift `s`, the term contributing to the overlap is  

```
C5(s) = Σ_i h[i] · (1 – h[i+s])    (indices outside the interval are omitted)
```

Each **pair** `(i, i+s)` that is `(1,0)` adds exactly `dx` to `C5(s)`.  
If we simultaneously change a `(1,0)` pair into a `(0,1)` pair (i.e. swap the `1` at `i` with a `0` at some `j` whose partner at `j+s` is `1`), the contribution of shift `s` drops by `dx` while the total number of ones stays unchanged.

**Algorithm (greedy_descent)**  

1. Start from a binary vector `h` with exactly `target_sum` ones.  
2. Compute the full correlation `corr = np.correlate(h, 1‑h, mode='full')`.  
   *The index of the maximal entry gives the worst shift* `s = argmax(corr) – (N‑1)`.  
3. Determine all indices that belong to a mismatched pair for this shift:  
   * if `s ≥ 0`:  
     - `i` runs over `0 … N‑s‑1`.  
     - `pair = (h[i], h[i+s])`.  
   * if `s < 0`: shift the other way analogously.  
   Build two sets:  

   ```
   A = { i | h[i] = 1  and h[i+s] = 0 }   # (1,0) pairs
   B = { i | h[i] = 0  and h[i+s] = 1 }   # (0,1) pairs
   ```

4. If both `A` and `B` are non‑empty, pick a random `i∈A` and a random `j∈B` (the latter corresponds to an index `j` in the original array; the partner of `j` is `j+s`).  
   Swap the bits: `h[i]=0`, `h[j]=1`.  
   This **strictly reduces** `C5(s)` by `dx`.  
5. Re‑evaluate the correlation (step 2) and repeat from step 2.  
6. Terminate when for the current worst shift either `A` or `B` is empty – no single swap can lower the maximal overlap any more.  

Because each successful swap reduces the worst overlap by at least one discrete unit `dx`, the greedy loop finishes after at most `target_sum` swaps for a given start.  The whole loop is ultra‑fast: one FFT per swap, a few vectorised slice operations, and a handful of `np.where` calls.

**Multiple restarts** – Run the greedy descent from a variety of seeds:

* a uniformly random binary vector,
* the **Thue–Morse** binary sequence (balanced by flipping the last bit if necessary),
* the **Rudin‑Shapiro** binary sequence (balanced similarly),
* the previous best continuous solution interpolated onto the 256‑grid and then rounded to a binary vector (preserving the sum via a simple exchange).

Keep the best (lowest `C5`) result; denote it `h_greedy` and its value `c5_greedy`.  This phase typically yields `C5` already around `0.38` and provides an excellent starting point for the next phase.

### 4. Phase‑II – Simulated annealing on binary vectors  

Greedy descent reaches a **swap‑local** optimum, but the global optimum may require a sequence of swaps that temporarily raise the worst overlap.  Simulated annealing supplies the necessary stochastic “energy‑climbing”.

**State representation** – a binary vector with exactly `target_sum` ones (the swaps preserve the sum).

**Move proposal** – pick a random `i` currently equal to 1 and a random `j` currently equal to 0 and exchange them (the same move as in the greedy phase).  

**Energy** – `E = C5(h)` returned by `c5_fft`.  

**Temperature schedule** –  

```
T0 = 0.02                         # roughly 1 % of the typical C5 range
t = (time_elapsed) / anneal_time
T = T0 * (1 - t)                  # linear cooling to zero
```

We allocate **≈ 50 % of the total budget** to annealing (≈ 300 s).  During this window we repeatedly:

1. Propose a swap, compute `E_new`.  
2. Accept unconditionally if `E_new ≤ E_current`.  
3. Otherwise accept with probability `exp(-(E_new‑E_current)/T)`.  
4. Update the current state and the global best whenever a new record is found.

Every `k = 500` accepted moves we invoke a **mini‑greedy sweep** (exactly the greedy algorithm of Phase I but limited to at most `10` swaps) on the current state.  This injects directed improvements while the annealing continues to explore.

**Stopping condition** – Annealing stops when the allotted time expires or when `T` drops below `1e‑5` and no improvement has been observed for a few thousand proposals.

The output of this phase is a binary vector `h_anneal` with value `c5_anneal ≤ c5_greedy`.  Empirically the annealer can push the bound below the 0.380 threshold, often into the 0.379 range.

Binary vectors are extremal, but the true optimum of the original continuous problem may be slightly better if a few entries are allowed to become fractional.  We therefore perform a short constrained optimisation starting from the best binary result.

**Preparation**  

* Convert `h_anneal` to a float array.  
* Apply a mild low‑pass filter to create a “smoothed” initial guess:

**Optimizer** – SciPy’s `trust-constr` (or `SLSQP` if unavailable) with  

* bounds `(0,1)` for every variable,  
* linear equality constraint `∑ h = target_sum`,
