### Goal
Find a step‑function h on [0,2] (discretised into N samples) that satisfies  

* 0 ≤ h[i] ≤ 1,  
* ∑ h[i] · dx = 1  ⇔ ∑ h[i] = N/2,  

and minimizes  

\[
C_5(h)=\max_{k\in\{-N+1,\dots,N-1\}} \; 
\underbrace{\sum_{i\in S_k} h_i\bigl(1-h_{i+k}\bigr)}_{=:\,c_k}\;dx ,
\]

where \(S_k=\{i\mid 0\le i<N,\;0\le i+k<N\}\).  
The method below builds a *binary* candidate by solving a mixed‑integer linear programme (MILP), then refines this candidate with a deterministic continuous optimiser.  The two phases are mathematically distinct from the gradient‑guided search used previously.

### 1.  Reformulation as a MILP (binary stage)

1. **Decision variables**  
   * \(h_i\in\{0,1\}\) for each grid point \(i=0,\dots,N-1\).  
   * For every admissible pair \((i,k)\) with \(i\in S_k\) introduce a binary auxiliary variable  
     \[
     y_{i,k}=h_i\;h_{i+k}\in\{0,1\}.
     \]  
   * A continuous scalar \(t\ge0\) representing the (unnormalised) worst‑case overlap  
     \[
     t \;=\; \max_k c_k .
     \]

2. **Linearisation of the product** (standard “AND” formulation)  
   For each \((i,k)\):
   \[
   \begin{aligned}
   y_{i,k} &\le h_i,\\
   y_{i,k} &\le h_{i+k},\\
   y_{i,k} &\ge h_i+h_{i+k}-1 .
   \end{aligned}
   \]
   These three inequalities are *exact* because all variables are binary.

3. **Expression of the overlap for a fixed shift**  
   \[
   c_k \;=\; \sum_{i\in S_k} h_i\;-\;\sum_{i\in S_k} y_{i,k}.

   \[
   c_k \le t \quad\Longleftrightarrow\quad

   \[
   \sum_{i\in S_k} y_{i,k}\; \ge\; \frac{N}{2}-t .

### 6.  High‑level algorithmic flow (pseudocode outline)

```
set random seed
choose initial resolution N0 (e.g. 80)
dx = 2 / N0
target = N0 // 2

# ---- Phase I: binary MILP ---------------------------------
build binary variables h_i ∈ {0,1}
for each shift k ∈ {-(N0-1),…,N0-1}:
    for each i ∈ S_k:
        create auxiliary binary y_{i,k}
        add three McCormick constraints linking y to h
    add constraint   Σ_i y_{i,k} ≥ target - t
add sum constraint Σ_i h_i = target
add optional symmetry breaker h_0 = 1
objective: minimise t
solve with cvxpy/CBC, with time limit ≈ 0.4·budget
extract h_bin, compute C5_bin = t·dx
store as best solution so far

# ---- Phase II: continuous refinement -----------------------
h = h_bin cast to float
while time remains:
    compute full correlation ρ = correlate(h,1‑h,'full')*dx
    k_star = argmax(ρ)            # worst lag
    compute exact sub‑gradient g (formula above)
    line‑search: try α = 0.2, 0.1, 0.05,… 
        h_trial = project( h - α·g )
        if C5(h_trial) < C5(h): accept, break
    if line‑search failed:
        perform greedy mass‑transfer based on -g
    occasionally (every K iters) apply annealed random swap
    update best_h, best_val if improvement
    optionally increase β and switch to smooth‑max gradient
    optionally double N (interpolate) when a large time fraction has passed

return best_h as list, best_val, current N
```

### 7.  Why this approach is materially different

* **Exact binary optimisation** – the first phase casts the problem as a *mixed‑integer linear programme* with a provably exact linearisation of the quadratic terms.  This replaces the earlier heuristic “gradient‑guided” search with a rigorous global optimisation on a reduced combinatorial space.
* **Two‑stage hierarchy** – the MILP supplies a provably feasible (binary) upper bound; the second stage refines it continuously.  The previous code blended gradient estimation, SLSQP and ad‑hoc perturbations in a single loop, never using integer programming.
* **Sub‑gradient in closed form** – the descent direction is derived analytically from the worst‑lag term, not via finite differences or noisy approximations.
* **Deterministic projection onto the sum‑hyperplane** – a simple 1‑D bisection replaces the earlier ad‑hoc “project_to_sum_box” that relied on an outer binary search over λ; here the projection is guaranteed to satisfy the equality to machine precision after each step.
* **Explicit mass‑transfer move** – a greedy linear‑programming style redistribution of mass directly minimises the linearised objective, something absent from the prior algorithm.
* **Optional multi‑resolution** – after a combinatorial optimum is found, we embed it into a finer grid and continue optimisation, a strategy not explored before.
