### 1.  Problem Re‑interpretation  

For a discretisation with `n` points (`dx = 2/n`) let  

```
h = (h0,…,h_{n‑1}) ,   0 ≤ h_i ≤ 1 ,   Σ h_i = n/2 .
```

Define the aperiodic correlation  

```
C_k(h) = Σ_{i} h_i ( 1 – h_{i+k} ) ,               k = -(n‑1)…(n‑1)
```

(the summation skips indices outside `[0,n‑1]`).  
The objective is  

```
C5(h) = dx·max_k C_k(h) .
```

Writing `y_i = 2h_i – 1 ∈ [‑1,1]` and using `Σ y_i = 0` gives  

```
C_k = ½ – ½·R_k ,   where   R_k = Σ_i y_i y_{i+k} .
```

Thus **minimising** `C5` is exactly **maximising** the smallest aperiodic autocorrelation
`R_k` (for all non‑zero shifts).  The problem is a **min‑max quadratic program** with linear
box and sum constraints.

### 3.  Phase 1 – Simulated Annealing on Binary Vectors  

1. **Initialisation** – generate a random binary vector `h⁰` with exactly `n/2` ones.
2. **Neighbour generation** – a move consists of **swapping** a randomly chosen `1`‑position with a `0`‑position. This preserves the sum exactly and stays inside the feasible box.
3. **Energy evaluation** – compute `E(h) = C5(h)` using an FFT‑based correlation:
   - FFT length `L = 2n‑1`.

   FFT gives `O(n log n)` (≈ 1 µs for `n=120`).
4. **Acceptance rule** – standard Metropolis:
   ```
   Δ = E_new – E_current
   ```

### 4.  Phase 2 – Exact MILP for Small n (Optional)

For `n ≤ 80` the binary problem can be **linearised**:

*Variables*  
- `h_i ∈ {0,1}` (binary)
- `p_{i,ℓ} ∈ {0,1}` for every pair `i, i+ℓ` (product linearisation).

*Constraints*  

```
p_{i,ℓ} ≤ h_i          (∀ i,ℓ)
p_{i,ℓ} ≤ h_{i+ℓ}
p_{i,ℓ} ≥ h_i + h_{i+ℓ} – 1
```

*Lag‑wise overlap*  

```
C_ℓ = Σ_{i: i+ℓ in range} h_i  –  Σ_{i: i+ℓ in range} p_{i,ℓ}
```

*Objective* – minimise `t` subject to `C_ℓ ≤ t/dx` for all ℓ.  

A single MILP with ≤ 3 500 binary variables (for `n=80`) is comfortably solved by CBC within a few seconds. The optimal binary pattern obtained here can be **embedded** into the larger `n=120` problem (e.g. by repeating or by using it as a template for the SA starting population).

### 5.  Phase 3 – Projected Sub‑gradient Descent on the Continuous Relaxation  

After Phase 1 we have a high‑quality binary vector `h_bin`.  Turning it into a **fractional** step function often reduces the max‑overlap because the objective is the maximum of several linear forms; a small redistribution of mass can lower the dominant form while only slightly raising the others.

#### 5.1  Sub‑gradient of the Max‑Overlap  

Let `c = corr = fft‑based correlation of h with (1‑h)`.  
Let `ℓ* = argmax_k c_k` be the (possibly non‑unique) lag(s) that attain the current maximum.  
For a single lag `ℓ` the correlation (without the `dx` factor) is

```
C_ℓ(h) = Σ_i h_i               (i+ℓ out of range → term = h_i)
        – Σ_{i: i+ℓ∈[0,n‑1]} h_i·h_{i+ℓ}
```

Its gradient w.r.t. `h` is piece‑wise linear:

```
g_i(ℓ) = 1 – h_{i+ℓ}       if i+ℓ < n                     (derivative of the first term)
       – h_{i‑ℓ}          if i‑ℓ ≥ 0                     (derivative of the product term)
       0                   otherwise
```

For `ℓ < 0` the same formula holds after replacing `ℓ` by `‑ℓ` and swapping the roles of the two indices.

When several lags share the maximal value, any convex combination of their gradients is a valid sub‑gradient.  We therefore compute

```
g = (1/|L*|) Σ_{ℓ∈L*} g(ℓ)    where L* = {ℓ : c_ℓ = max c } .
```

#### 5.2  Projection onto the Feasible Set  

After a step `h’ = h – α·g` we must bring `h’` back into the box `[0,1]` **and** enforce the linear equality `Σ h = n/2`.  This is the Euclidean projection onto the intersection of a simplex and a hyper‑cube, which can be performed by the **water‑filling** (dual‑variable bisection) algorithm:

1. Shift all components by a common λ: `z_i = clip( h’_i + λ , 0 , 1 )`.
2. Choose λ such that `Σ z_i = n/2`.  Because the left‑hand side is monotone in λ, a binary search converges in ≤ 50 iterations to machine precision.

The same routine is used throughout the algorithm (it replaces the ad‑hoc `project_to_sum_box` of the reference code).

We employ a **diminishing step‑size** typical for sub‑gradient optimisation:

```
α_t = α0 / sqrt(t) ,   α0 = 0.5·dx·n   (≈1) .
```

If after an iteration the objective does **not** improve, we optionally halve the current α (quick “back‑tracking”).  
We stop this phase after a fixed number of iterations (e.g. 5000) or when the improvement per iteration falls below `1e‑8`.

#### 5.4  Why this works  

The binary SA delivers a pattern where the dominant lag is already relatively low.  The sub‑gradient step specifically attacks the *active* lag(s) while respecting the sum constraint, thus smoothing the peak.  Because the objective is the max of linear forms, any feasible point that reduces the active gradient cannot increase any other lag beyond the current maximum unless the active set changes; consequently the algorithm converges to a **local min‑max** point, which is often strictly better than any binary configuration.
