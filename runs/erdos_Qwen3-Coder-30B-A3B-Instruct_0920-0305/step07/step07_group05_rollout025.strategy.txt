### Overview  
The task is to construct a discretised step‑function `h` on `[0,2]` (sampled at `n` points) that satisfies  

* box constraints `0 ≤ h_i ≤ 1` for all `i`,  
* integral constraint `∑_i h_i = n/2`   (because `Δx·∑h_i = 1`),  

and minimises  

\[
C_5(h)=\max_{k\in[-2,2]}\;\int_0^{2}h(x)\bigl(1-h(x+k)\bigr)\,dx
      =\; \Delta x \;
        \max_{\ell\in\{-n+1,\dots ,n-1\}}\;
        \sum_i h_i\bigl(1-h_{i+\ell}\bigr),
\]

where out‑of‑range indices are interpreted as zero.  
The optimisation is **non‑convex** because the objective contains a “max of quadratic forms”.  
All earlier solutions tackled it with local gradient‑guided heuristics.  
The strategy below is **fundamentally different**: we first solve a **semidefinite programming (SDP) relaxation**, then **randomly round** the SDP solution to obtain a feasible vector, and finally **polish** it with a cheap local search.  
The SDP supplies a strong global lower bound on the true optimum; the rounding–polishing pipeline can convert that bound into an explicit construction that empirically improves the recorded `C5` value.

## 1. Continuous‑to‑discrete reformulation  

Let  

* `n` – number of equally spaced sample points (choose a modest size, e.g. `n = 140` – a power of two is not required, but a multiple of two simplifies the “full” correlation length).  
* `Δx = 2 / n`.  

Define the vector `h = (h_0,…,h_{n‑1})ᵀ`.  

For a shift `ℓ ∈ {-(n‑1),…,n‑1}` the (discrete) autocorrelation is  

\[
s_\ell(h)=\sum_{i=0}^{n-1} h_i\,h_{i+\ell},
\qquad
h_{i+\ell}=0\text{ if }i+\ell\notin[0,n-1].
\]

The overlap integral for that shift equals  

\[
\int h(x)\bigl(1-h(x+ℓΔx)\bigr)dx
   =\Delta x\Bigl(\frac{n}{2}-s_\ell(h)\Bigr).
\]

Thus  

\[
C_5(h)=\Delta x\Bigl(\frac{n}{2}-\min_{\ell}s_\ell(h)\Bigr)
      =1-\Delta x\;\min_{\ell}s_\ell(h).
\]

Consequently **maximising the smallest autocorrelation value** `min_ℓ s_ℓ(h)` is equivalent to **minimising** `C_5`.  

The quantities `s_ℓ` are **quadratic forms** in `h`.  Write  

\[
s_\ell(h)=h^\top A_\ell h,
\]

where `A_ℓ` is the symmetric `n×n` matrix that has a `1` at positions `(i,i+ℓ)` and `(i+ℓ,i)` (if those indices exist) and `0` elsewhere.  
Each `A_ℓ` is extremely sparse – exactly `n-|ℓ|` non‑zero entries.

## 2. SDP relaxation  

Introduce a matrix variable  

\[
X = h\,h^\top \in \mathbb{R}^{n\times n},
\qquad X\succeq 0,\; \operatorname{rank}(X)=1.
\]

If we **drop the rank‑1 requirement** we obtain a convex set:

* `X ≽ 0` (positive semidefinite).  
* Diagonal entries are the original variables: `X_{ii}=h_i`.  

All constraints on `h` translate to linear constraints on the diagonal of `X`:

* `0 ≤ X_{ii} ≤ 1`.  
* `∑_{i=0}^{n-1} X_{ii} = n/2`.  

The autocorrelation values become linear in `X`:

\[
s_\ell(h)=\operatorname{tr}(A_\ell X).
\]

Introduce a scalar variable `t` that will dominate the *overlap* value:

\[
t \ge \Delta x\Bigl(\frac{n}{2}-s_\ell(h)\Bigr)
\quad\Longleftrightarrow\quad
\operatorname{tr}(A_\ell X) \ge \frac{n}{2}-\frac{t}{\Delta x}
\qquad\forall\,\ell .
\]

Because `Δx` is a constant we can absorb it in the right‑hand side.  
The **SDP relaxation** is therefore:

```
minimise   t
subject to X ≽ 0
           0 ≤ diag(X) ≤ 1
           sum(diag(X)) = n/2
           trace(A_ℓ X) ≥ n/2 – t/Δx   for all ℓ
```

All constraints are linear (or affine) in the decision variables `(X,t)`.  
The problem is a standard *semidefinite program*.

### Why this is different  
* The previous approaches directly manipulated the vector `h` with heuristic moves.  
* Here we solve a **global convex relaxation** that gives a *provable lower bound* on the optimum `C_5`.  The solution of the SDP is not a feasible `h`, but a matrix `X` from which we can systematically extract candidates.
