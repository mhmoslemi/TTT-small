\[
C_5=\max_{k}\;O(k),\qquad 
O(k)=\int_{0}^{2} h(x)\bigl(1-h(x+k)\bigr)\,dx .
\]

The evaluation used in the judge is  

```
dx = 2.0 / n_points
C5 = max( correlate(h, 1-h, mode="full") * dx )
```

### 1. Reformulation as a feasibility problem  

Write the integral as a Riemann sum with step dx :

\[
O(d)=\underbrace{\sum_{i=0}^{n-1}h_i}_{=\,n/2}
      -dx\; \sum_{i\in I_d}h_i\,h_{i+d},
\qquad d\in\{-n+1,\dots,n-1\},
\]

where \(I_d=\{i\,|\,0\le i,\;i+d<n\}\) is the set of overlapping indices.
Since the total mass \(\sum h_i=n/2\) is fixed,  

\[
O(d)=1-dx\;\underbrace{\sum_{i\in I_d}h_i h_{i+d}}_{C(d)} .
\]

Thus the constraint “\(O(d)\le t\)” is equivalent to a *lower* bound on the
cross‑correlation:

\[
dx\;\sum_{i\in I_d}h_i h_{i+d}\;\ge\;1-t .
\tag{1}
\]

For a given candidate value \(t\) we ask: *is there a vector \(h\) that
satisfies (1) for *every* shift \(d\) together with the box and sum
constraints?*  This is a **feasibility** problem with bilinear terms
\(h_i h_{i+d}\).

--------------------------------------------------------------------
### 2. Linear relaxation with McCormick envelopes  

Introduce auxiliary variables  

\[
p_{i,d}\;=\;h_i\,h_{i+d},\qquad i\in I_d .
\]

Because each \(h_i\) lies in \([0,1]\) the exact bilinear relation can be
outer‑approximated by the convex McCormick envelope:

```
p_{i,d} ≥ 0
p_{i,d} ≤ h_i
p_{i,d} ≤ h_{i+d}
p_{i,d} ≥ h_i + h_{i+d} – 1
```

These four linear inequalities are *tight* when the variables are binary,
and they are a standard relaxation for continuous variables in [0,1].

Using the auxiliaries, (1) becomes a **linear** inequality:

\[
dx\;\sum_{i\in I_d} p_{i,d}\;\ge\;1-t .
\tag{2}
\]

All constraints of the original problem are now linear:

* box: 0 ≤ h_i ≤ 1  
* mass: ∑ h_i = n/2  
* McCormick: the four inequalities for every (i,d)  
* cross‑correlation: (2) for every shift d.

Consequently, for a fixed \(t\) the problem is a **linear program (LP)**.
If the LP is feasible, there exists a (possibly fractional) vector \(h\)
that attains a maximal overlap **no larger than \(t\)** (the LP may
under‑estimate the true product, but any feasible LP solution provides a
lower bound on the attainable worst‑case overlap).

### 5. Local refinement (optional, cheap)  

A deterministic hill‑climber that preserves the sum exactly:

*Pick two distinct indices i ≠ j*  

```
δ_low  = max( -h[i]               ,  h[j] - 1 )
δ_high = min(  1 - h[i]           ,  h[j]       )

h' = h ; h'[i] += δ ; h'[j] -= δ
```

### 7. Why this approach is different  

* **Global view** – the LP (with McCormick envelopes) enforces *all*
  shift constraints simultaneously, unlike greedy or pure gradient descent
  that only reacts to the current worst shift.
* **Convex outer approximation** – the feasibility test is a linear program,
  guaranteeing fast, reliable solutions and a provable lower bound on the
  attainable max‑overlap.
* **Systematic bisection** – instead of stochastic search, we
  converge on the smallest feasible \(t\) by binary search, guaranteeing
  monotone improvement.
* **Deterministic rounding and refinement** – after the LP we obtain a
  feasible binary step function without resorting to blind random
  mutations; the optional hill‑climber is only a polishing step.

Because the LP relaxation is tight when the optimal solution is close to
binary (which is true for the Erdős problem), the method often reaches
bounds better than the current record and does so with far fewer random
iterations.
