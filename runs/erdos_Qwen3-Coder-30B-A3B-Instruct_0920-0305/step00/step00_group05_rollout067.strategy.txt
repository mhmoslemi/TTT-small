**Step 1 - Exact representation of the overlap functional**.

- For each shift k (0 ≤ k ≤ N-1), the overlap O_k(x) = Σ_{i=0}^{N-1-k} x_i - Σ_{i=0}^{N-1-k} x_i x_{i+k}.

- Write O_k(x) = a_kᵀ x - xᵀ Q_k x, where a_k is a vector of ones in positions 0..N-1-k (zero elsewhere) and Q_k has entries (i,i+k) and (i+k,i) each equal to 1/2 (to keep symmetry) for i in overlapping range. Because the quadratic term is symmetric, the Hessian is negative semidefinite.

- Since -xᵀ Q_k x is concave, O_k(x) is concave.

**Step 2 - Upper linearization (supporting hyperplane)**.

- For a given current point x^t, compute the gradient ∇O_k(x^t) (componentwise formula). The supporting hyperplane is:

    L_k(x) = O_k(x^t) + ∇O_k(x^t)ᵀ (x - x^t)

  This satisfies L_k(x) ≥ O_k(x) for all feasible x.

**Step 3 - Master linear program**.

- Variables: x ∈ ℝ^N, t ∈ ℝ.
- Constraints:
    * Box: 0 ≤ x_i ≤ 1.
    * Sum: Σ_i x_i = N/2.
    * Upper bound constraints: for each k for which we have stored a linearization, enforce: L_k(x) ≤ t.

- Objective: minimize t.

- Initially, we create linearizations for a small set of shifts (e.g., k=0,1,... maybe 5) to give a starting feasible region.

**Step 4 - Cutting‑plane loop**.

- Repeat until a stopping condition (time limit or convergence):
    1. Solve the LP (warm‑starting with previous x, t).
