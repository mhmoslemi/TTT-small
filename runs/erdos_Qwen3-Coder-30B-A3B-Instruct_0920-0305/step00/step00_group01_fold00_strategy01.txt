**Goal** – Find a step‑function `h` on `[0,2]` (discretised with `n` points) with  
`0 ≤ h[i] ≤ 1`, `∑ h[i] = n/2` that minimises  

```
C5(h) = max_k  ∫ h(x)·(1‑h(x+k)) dx .
```

The discrete evaluation used in the checker is  

```
O = np.correlate(h, 1‑h, mode='full') * dx       # O[k] = overlap for shift k
C5 = O.max()
```

The problem is non‑convex (quadratic terms `h[i]·h[i+offset]`).  
The proposed optimisation works in **continuous space** and relies on a
*smooth approximation* of the max‑operator together with a *penalised*
gradient method.  It is fundamentally different from pure hill‑climbing or
simulated‑annealing approaches.

--------------------------------------------------------------------
### 1.  Smooth surrogate for the max

For a vector `v` of overlap values the **log‑sum‑exp** (LSE) gives a smooth
upper bound:

```
smooth_max(v; α) = α * log( Σ_j exp(v_j / α) )
```

`α>0` controls the approximation quality: as `α→0` the surrogate converges
to the true max, for larger `α` it is smoother.  Using the surrogate in the
objective makes the whole loss differentiable.

Define the loss

```
L(h; α, λ) = smooth_max(O(h); α) + λ * ( Σ_i h_i – n/2 )²
```

* The first term drives down the maximum overlap.
* The second term forces the integral constraint; a large `λ` (e.g. 100‑200)
  makes violations expensive.

--------------------------------------------------------------------
### 2.  Parameterisation of the box constraints

Instead of handling the box `[0,1]` by projection after each update we
parameterise each component with a **logistic map**

```
h_i = σ(z_i) = 1 / (1 + exp(‑z_i))   ,   z_i ∈ ℝ .
```

`σ` automatically respects `0≤h_i≤1`.  The equality constraint is still
enforced by the quadratic penalty term.

--------------------------------------------------------------------
### 3.  Gradient of the smooth loss

*Let `dx = 2.0 / n`.*

For a fixed shift `s` (integer offset) the non‑smooth overlap is  

```
O_s(h) = Σ_i h_i – dx * Σ_i h_i * h_{i+s}      (zero‑padding)
```

Derivative w.r.t. a component `h_j` (ignoring boundaries) is

```
∂O_s / ∂h_j = 1 – dx * ( h_{j+s}  +  h_{j‑s} )   (terms missing at the ends are omitted)
```

The surrogate `smooth_max` yields a weighted sum of these gradients:

```
w_s = exp(O_s/α) / Σ_t exp(O_t/α)          # softmax weights
∂smooth_max / ∂h_j = Σ_s w_s * ∂O_s/∂h_j .
```

The penalty gradient is simply

```
∂penalty / ∂h_j = 2 λ ( Σ_i h_i – n/2 ) .
```

By the chain rule `∂L/∂z_j = (∂L/∂h_j) * σ(z_j)*(1‑σ(z_j))`.

All ingredients are explicit, so the gradient can be computed in O(n²)
time (the same double loop used for the correlation).

--------------------------------------------------------------------
### 4.  Optimiser – Adam

Use the **Adam** algorithm (β₁=0.9, β₂=0.999, ε=1e‑8) on the unconstrained
vector `z`.  Adam adapts the learning rate per coordinate and works well on
noisy, non‑convex objectives.

**Annealing schedule for α** – start with a relatively large smoothness
(e.g. `α₀ = 0.05`) and decay it geometrically:

```
α_t = α₀ * decay_factor ^ (t / steps_per_decay)
```

A typical `decay_factor = 0.9` and `steps_per_decay = 2000` give a gradual
tightening of the max‑approximation, allowing the optimiser to move
freely early and focus on the true objective later.

--------------------------------------------------------------------
### 5.  Algorithm outline

```
1. Choose n (e.g. 80 – still cheap for O(n²) work, but gives finer control).
2. Initialise z:
   • start from the supplied initial_h_values (projected back to the
     logistic space:  z = logit(initial_h)).
   • optionally add a small random Gaussian perturbation.
3. Set hyper‑parameters:   α₀, λ, learning_rate, max_iterations, decay_factor.
4. Loop t = 1 … max_iterations   (stop earlier if time budget expires)
     a) Compute h = σ(z).
     b) Compute O = correlation(h, 1‑h) * dx   (full mode).
     c) Compute smooth_max, its softmax weights, and the full gradient
        ∂L/∂z as described above.
     d) Perform one Adam update on z.
     e) Every few hundred steps recompute the *exact* bound
        C5 = O.max() and keep the best pair (h_best, C5_best).
     f) Reduce α according to the schedule.
5. After the loop, project h_best onto the exact feasible set
   (clip to [0,1] and apply the “capped‑simplex” projection that enforces
   Σh = n/2).  This removes any tiny violation caused by the penalty.
6. Return the projected array, its exact C5 value, and n.
```

The projection in step 5 can be performed by a simple bisection on a
Lagrange multiplier `µ`:  

```
h_i_proj = min(1, max(0, h_i – µ))
```

The unique `µ` making the sum equal `n/2` is found in O(n log ε).
