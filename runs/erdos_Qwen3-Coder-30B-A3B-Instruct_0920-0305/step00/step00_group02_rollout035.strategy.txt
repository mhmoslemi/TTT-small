### 2. Exact evaluation of the overlap for a given parameter set

For a shift `t ≥ 0` (the negative shifts are symmetric and need not be examined), the intersection length
\[
I(t)=|S∩(S+t)|
\]
is a **piecewise‑linear** function of `t`.  The breakpoints occur exactly when an endpoint of an interval aligns with an endpoint of another interval, i.e. at values
\[
t = |a_i - (a_j+ℓ_j)|
\quad\text{or}\quad
t = |(a_i+ℓ_i) - a_j|
\]
for any `i,j`.  There are at most `2M²` distinct breakpoints; between any two successive breakpoints the set of overlapping interval pairs is constant, so `I(t)` is linear there.

Therefore the worst‑case shift for the objective
\[
C_5 = 1 - \min_{t\in[0,2]} I(t)
\]
must be attained at one of those breakpoints (including `t=0`).  Computing `I(t)` for all breakpoints yields the exact value of `C_5` for the continuous design in O(`M²`) time.

**Algorithm to compute C₅ from interval data**  
1. Build the list `E = {a_i, a_i+ℓ_i}` of all interval endpoints.  
2. Form the set of candidate shifts `T = {0} ∪ { |e - e'| : e,e'∈E, |e - e'| ≤ 2 }`.  
3. For each `t∈T`, compute `I(t)` by scanning the intervals: for each `i` find the overlap of `[a_i, a_i+ℓ_i]` with `[a_i - t, a_i+ℓ_i - t]` (or with `[a_i+t, a_i+ℓ_i+t]` depending on sign).  Since `M` is tiny this is `O(M²)`.  
4. Set `C₅ = 1 - min_t I(t)`.

All arithmetic is exact up to floating‑point tolerance; the result is a rigorous upper bound for the discretised version once we later sample the intervals.

### 3. Global optimisation in the low‑dimensional space

### 4. Deterministic local refinement (linear programming)

The DE result is already close to optimal, but we can often improve the minimal overlap by *tiny adjustments* of the endpoints while staying within a neighbourhood where the set of active overlapping interval pairs does **not** change.  Within such a region each `I(t)` is a *linear* function of the endpoint positions, so improving the worst case reduces to a **linear program**:

1. Identify the *active* breakpoints – those `t` that realise the current `min I(t)`.  
2. For each active `t`, write `I(t) = c_t + Σ α_{t,k}·x_k` where `x_k` are the free endpoint coordinates (the `a_i` and `a_i+ℓ_i`).  The coefficients `α_{t,k}` are simply `±1` or `0`.  
3. Introduce a small radius `Δ` (e.g. `Δ = 0.001`) and impose `|x_k – x_k^{(old)}| ≤ Δ`.  
4. Maximise the minimum of the linear expressions `I(t)` (equivalently, maximise a new scalar `τ` subject to `c_t + Σ α_{t,k}·x_k ≥ τ` for all active `t`).  
5. Solve this LP (e.g. with `ECOS` or `GLPK`).  
6. Apply the obtained adjustment, recompute the active set, and repeat a few times (typically 3–5 iterations suffice).

Because the LP dimension is at most `2M+1` (≈ 13), each solve is essentially instantaneous.
