**Goal** – Find a step‑function `h:[0,2]→[0,1]` (discretised on `n` equally spaced points) with  
`∑ h[i]·dx = 1` (`dx=2/n`) that minimises  

```
C5(h) = max_k  ∫₀² h(x)·(1‑h(x+k)) dx .
```

In the supplied checker the integral is evaluated as a full linear correlation  

```
c = correlate(h, 1‑h, mode='full') * dx,
C5 = max(c) .
```

The optimisation is non‑convex because each term contains the product `h[i]·h[i+k]`.  
The proposed method solves it by **difference‑of‑convex (DC) programming** (also called the Convex‑Concave Procedure).  
It rewrites every quadratic term as a difference of two convex quadratic forms, linearises the concave part, and solves a **convex quadratic program (QP)** at each iteration.  
Multiple random restarts and a spectral initialisation give global‑search capability, while a damped update prevents divergence.

### 1.  Discrete problem and notation  

* Choose an **even** grid size `n` (e.g. `n = 180`).  
* `dx = 2.0 / n`.  
* Vector `h ∈ ℝⁿ` with `0 ≤ h_i ≤ 1`.  
* Linear constraint: `∑_{i=0}^{n‑1} h_i = n/2` (equivalent to the integral constraint).  

For an integer shift `k ∈ {-(n‑1), …, n‑1}` define the **zero‑padded** shift matrix  

```
(R_k)_{i,j} = 1  if  j = i+k  and 0≤j<n , else 0 .
```

The correlation term is  

```
c_k(h) = dx·∑_i h_i·(1‑h_{i+k})
       = dx·( n/2  –  hᵀ R_k h )                     (1)
```

(The sum `∑ h_i = n/2` is constant.)  
Thus minimising `max_k c_k` ⇔ maximising `min_k q_k` where `q_k(h)=hᵀR_k h`.

The matrix `R_k` is not symmetric, but the scalar product uses a symmetric version:

```
M_k = (R_k + R_{‑k}) / 2   (symmetric)
q_k(h) = hᵀ M_k h .
```

`M_k` has eigenvalues `cos(2πℓk/n)`, some positive and some negative.

### 2.  Convex–concave decomposition of each quadratic form  

Perform an eigen‑decomposition of the symmetric shift matrix  

```
M_k = U_k  Diag(λ_k)  U_kᵀ .
```

Split the eigenvalues into positive and negative parts:

```
λ_k⁺   = max(λ_k, 0)          (componentwise)
λ_k⁻   = -min(λ_k, 0)         (≥0)
```

Define two PSD matrices

```
M_k⁺ = U_k Diag(λ_k⁺) U_kᵀ   (convex part)
M_k⁻ = U_k Diag(λ_k⁻) U_kᵀ   (convex part representing the negative eigenvalues)
```

Hence

```
q_k(h) = hᵀ M_k⁺ h  –  hᵀ M_k⁻ h .               (2)
```

The first term `hᵀ M_k⁺ h` is **convex**, the second term `‑hᵀ M_k⁻ h` is **concave** (negative of a convex quadratic).  
Equation (1) becomes  

```
c_k(h) = dx·( n/2 – hᵀ M_k⁺ h + hᵀ M_k⁻ h ) .
```

Our original **min‑max** problem is therefore a **DC program**:

```
min_{h∈[0,1]^n, Σh=n/2}   t
s.t.    dx·( n/2 – hᵀ M_k⁺ h + hᵀ M_k⁻ h ) ≤ t      for all k .
```

The constraints are the difference of a convex and a concave quadratic expression.

### 3.  DC (Convex‑Concave) iterative scheme  

At iteration `s` we have a feasible point `h^{(s)}` and a current bound `t^{(s)}`.

For each shift `k` **linearise the concave part** `‑hᵀ M_k⁻ h` around `h^{(s)}`:

```
‑hᵀ M_k⁻ h   ≈   –(h^{(s)})ᵀ M_k⁻ h^{(s)}  – 2·(M_k⁻ h^{(s)})ᵀ (h – h^{(s)}).
```

Plugging this affine approximation into the constraint gives a **convex quadratic inequality**:

```
dx·( n/2 – hᵀ M_k⁺ h
      + (h^{(s)})ᵀ M_k⁻ h^{(s)}
      + 2·(M_k⁻ h^{(s)})ᵀ (h – h^{(s)}) )   ≤   t .   (3)
```

All terms are now convex in `h` (a convex quadratic plus an affine part).  

**Sub‑problem (QP)** for the next iterate:

```
minimize      t
variables     h ∈ ℝⁿ , t ∈ ℝ
subject to    0 ≤ h_i ≤ 1                     (box)
              Σ_i h_i = n/2                   (linear equality)
              (3) for every shift k           (convex quadratic)
```

Because every constraint contains at most one quadratic term, the problem is a **convex QP** (or a second‑order‑cone program after a Cholesky factorisation of each `M_k⁺`). The problem size is modest: `n≈180`, number of constraints `2n‑1≈360`.

Solve the QP with a reliable interior‑point QP solver available through **CVXPY** (e.g. ECOS, OSQP, or the open‑source QP solver `PDLP`).  

After solving we obtain `h^{(s+1)}` and `t^{(s+1)}`.

### 4.  Damping / under‑relaxation  

Direct substitution of the QP solution can cause oscillations because the linearisation is only accurate locally. Introduce a **step‑size γ ∈ (0,1]**:

```
h̃ = (1‑γ)·h^{(s)} + γ·h^{(s+1)} .
```

Project `h̃` back onto the feasible box‑hyperplane (the same projection used in the QP) to guarantee exact feasibility, then use the projected point as the next iterate.  
Typical schedule: start with `γ = 0.8` and halve it if the objective `t` does not improve.

### 9.  Why this approach is materially different  

* **Explicit DC decomposition** – Instead of smoothing the max (log‑sum‑exp) or using heuristic swaps alone, the method rewrites each quadratic overlap term as a *difference of two convex quadratics* and solves a sequence of *convex QPs*.
* **Quadratic constraints are handled analytically** – By separating positive/negative eigenvalues we obtain a set of *convex* quadratic inequalities; they are not approximated by linear McCormick envelopes nor tackled by generic black‑box heuristics.
* **Deterministic sub‑problem** – Each DC iteration solves a well‑posed convex optimisation problem with guaranteed convergence properties (monotone decrease of the surrogate objective), rather than relying on stochastic acceptance probabilities only.
* **Spectral initialization** – Uses the leading eigenvector of the summed positive‑part matrices, a principled starting point derived from the problem structure, not a generic random guess.
* **Integrated damping and projection** – Guarantees feasibility after every step, a design not present in simple gradient descent or pure simulated‑annealing pipelines.

All components together constitute a novel, mathematically grounded pipeline that leverages convex‑concave decomposition, convex QP solvers, and systematic restarts to push the Erdős constant `C5` below the current record.
