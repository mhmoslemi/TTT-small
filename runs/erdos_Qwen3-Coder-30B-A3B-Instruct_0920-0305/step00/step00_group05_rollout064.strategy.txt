### 1.  Re‑formulation of the continuous problem

*Domain and discretisation*  
Choose an even integer `N` (the number of sample points, e.g. `N = 100`).  
Let `dx = 2 / N`.  The step‑function `h` is represented by a vector  

```
x = (x0,…,xN‑1) ,      0 ≤ xi ≤ 1 ,      Σi xi = N/2          (1)
```

The evaluator used by the grader computes  

```
C5(x) = maxk  ( Σi xi·(1 – x_{i+k}) ) · dx                (2)
```

where the sum runs over all indices that stay inside `[0,N‑1]` after the shift `k` (the same as `np.correlate(x,1‑x,'full')`).  
For binary vectors (`xi∈{0,1}`) the inner sum is an integer, and the factor `dx` can be applied afterwards.

Thus the optimisation problem is

```
minimise   t·dx
subject to  Σi xi = N/2
            0 ≤ xi ≤ 1
            t ≥ Σi xi·(1 – x_{i+k})   for every shift k∈{-(N‑1)…(N‑1)}    (3)
```

The only non‑linearities are the bilinear products `xi·x_{i+k}` inside the constraints.

### 2.  Exact linearisation via auxiliary binary variables

Introduce a binary auxiliary variable  

```
y_{i,k}  ∈ {0,1}    for all i, k with 0 ≤ i ≤ N‑1‑|k|
```

to represent the product  

```
y_{i,k} = xi · x_{i+|k|} .                              (4)
```

The usual McCormick linearisation for binary variables is exact:

```
y_{i,k} ≤ xi
y_{i,k} ≤ x_{i+|k|}
y_{i,k} ≥ xi + x_{i+|k|} – 1
```

With (4) the overlap for a *positive* shift `k ≥ 0` becomes  

```
O_k = Σ_{i=0}^{N‑1‑k} ( xi – y_{i,k} ) .               (5)
```

For a *negative* shift `k = –ℓ (<0)` we obtain the symmetric expression  

```
O_{–ℓ} = Σ_{i=0}^{N‑1‑ℓ} ( xi – y_{i,ℓ} ) .           (6)
```

(Notice that the same auxiliary variable `y_{i,ℓ}` appears for both `+ℓ` and `–ℓ`; therefore we need only one set of `y`‑variables for each absolute shift.)

Now introduce a scalar variable `t ≥ 0` and enforce  

```
t ≥ O_k   for every shift k = 1,…,N‑1 .                (7)
```

Because `O_0 = 0` for binary vectors (xi·(1‑xi)=0) we may ignore `k=0`.  
The objective is simply `minimise t·dx`.

All constraints are linear; the model is a **mixed‑integer linear program (MILP)** with binary variables `xi` and `y_{i,k}` and a continuous variable `t`.

### 3.  Size of the MILP and practical limits

For a given `N`

* number of decision variables  
  - `N` binary `xi`  
  - `(N‑1)·(N‑|k|)` = `N·(N‑1)/2` binary `y` (because we need one `y` for each unordered pair `{i,i+k}`).  
  - 1 continuous `t`.

  For `N = 100` we have `≈ 5 000` binary `y` variables plus `100` binary `x` – well within the capacity of open‑source MILP solvers (CBC, GLPK, SCIP) in a few seconds.

* number of constraints  
  - 3 linear constraints per `y` (McCormick) → ≈ `15 000`.  
  - `N‑1` constraints for the upper bound on `t`.  
  - 1 equality for the sum of `x`.  
  - Box constraints for `xi`.  

All together < 20 000 rows, a size that modern solvers can explore quickly.

1. **Beatty‑sequence construction**  
   - Choose an irrational `α` (e.g. the golden ratio `φ = (1+√5)/2`).
