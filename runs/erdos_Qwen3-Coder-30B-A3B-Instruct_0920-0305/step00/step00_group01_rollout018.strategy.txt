**Goal** – Produce a step‑function `h` on [0, 2] (discretised with *n* points) satisfying  

* 0 ≤ h[i] ≤ 1, ∑ h[i] · dx = 1 (dx = 2/n)  

and minimise  

```
C5(h) = max_k  ∫ h(x)·(1‑h(x+k)) dx
       = max_k  ( 1 – ∫ h(x)·h(x+k) dx )
```

The problem is a **min‑max quadratic programme**.  The key observation is  

```
C5(h) ≤ t   ⇔   for every integer shift s,
                ∑_{i} h[i]·h[i+s] · dx   ≥   1 – t .
```

Thus the unknown *t* is an upper bound on the constant; the inner products are bilinear.  
We will **linearise the bilinear terms with McCormick envelopes**, obtain a *pure linear feasibility problem* for a fixed *t*, and then **binary‑search on *t***.  After the LP gives a (usually fractional) feasible vector, we **round it to a true step‑function** and perform a short local refinement.  The whole pipeline is fast enough to be run repeatedly with different discretisations inside the 600 s budget.

### 2. Linear programme for a given bound *t*

**Variables**

| Symbol | Meaning |
|--------|----------------------------------------|
| h[i]   | value of the step function at sample i (continuous) |
| p[i,s] | auxiliary variable intended to represent h[i]·h[i+s] (continuous) |

Only pairs *(i, i+s)* that are inside the interval are created; for a negative shift we use the same p‑variable because `h[i]·h[i‑|s|]` appears symmetrically.

**Constraints**

1. **Box and mass**  

   ```
   0 ≤ h[i] ≤ 1               for all i
   Σ_i h[i] = n/2             (∫ h dx = 1, because dx·Σh = 2·Σh/n = 1)
   ```

2. **McCormick envelope for each product** (h[i], h[j]∈[0,1])  

   ```
   p[i,s] ≥ 0
   p[i,s] ≤ h[i]
   p[i,s] ≤ h[i+s]
   p[i,s] ≥ h[i] + h[i+s] – 1
   ```

   These four linear inequalities describe the convex hull of the feasible
   set {(h[i],h[i+s],p) | p = h[i]·h[i+s]}.  They are tight when the solution
   is binary (0/1) and give a good relaxation for fractional values.

3. **Correlation lower bound for each shift**  

   Let `w(t) = (1‑t)/dx`.  The original inequality
   `dx·Σ_i h[i]·h[i+s] ≥ 1‑t` becomes

   ```
   Σ_i p[i,s]  ≥  w(t)       for every integer shift s with |s| < n
   ```

   (the sum runs only over the overlapping indices; for the extreme shifts
   the right‑hand side is small, so the constraint is never active.)

The LP has **no objective** – we only ask the solver whether the feasible
region is non‑empty for the chosen *t*.  In practice we give a dummy
objective (e.g. minimise 0) – any LP solver will then just look for a
feasible point.

### 4. From the fractional LP solution to a true step‑function

The LP solution `h*` is usually fractional but already respects all linear
constraints.  To obtain a permissible step function we **round while preserving
the total mass**:

1. Compute the target sum `S = n/2`.  
2. Sort indices by decreasing `h*[i]`.  
3. Set the first `⌊S⌋` indices to 1, the next one to the fractional remainder
   `r = S – ⌊S⌋` (0 ≤ r < 1), and all remaining indices to 0.  
   This yields a vector `h_round` that satisfies the box constraints and the
   exact mass constraint.

If `r` is non‑zero we keep the corresponding entry fractional; the final
vector still has at most one non‑binary entry, which is harmless for the
evaluation.

### 5. Verify and locally improve the rounded vector

Compute the real objective

```
C5(h) = max_k  dx * correlate( h , 1‑h , mode='full' )
```

If the value is ≤ `high` we already have a certified bound.  
Often the rounding raises the objective a little (because the envelope was
optimistic).  We then launch a **quick hill‑climbing refinement** that works
only on the rounded vector:

*Repeatedly* pick two distinct indices `i, j` and a move `δ` that keeps both
entries inside `[0,1]` while preserving the total sum (`h[i] += δ`, `h[j] –= δ`).
Accept the move **iff** the new `C5` is strictly smaller.  
The move size `δ` is taken uniformly from the feasible interval
`[max(-h[i], h[j]‑1), min(1‑h[i], h[j])]`.  
A few thousand such trials are enough to iron out the small excess created
by rounding.

Because the objective is the max over ≈ 2 n−1 shifts, evaluating it is
O(n²) (≈ 3 600 elementary operations for n = 60) and therefore cheap; we can
perform 10⁴–10⁵ trial moves well within the time limit.

### 7. Why this approach is different and why it should improve the bound

* **Global optimisation via LP relaxation** – instead of a purely local
  random walk, the bisection+LP stage guarantees that *all* shift constraints
  are satisfied simultaneously to the extent the relaxation permits.  This
  moves the search out of the many shallow local minima that trap simple
  hill‑climbers.

* **McCormick linearisation** provides the *tightest* convex hull for each
  product given the box bounds, so the LP bound on *t* is often very close
  to the true (non‑convex) optimum, especially for the modest dimensions we
  use.

* **Controlled rounding** – by keeping the mass exact and rounding the
  highest‑valued coordinates first, we obtain a step‑function that is a
  natural “hardening” of the relaxed solution.  The subsequent targeted
  pair‑wise moves then fine‑tune the exact max‑overlap without destroying the
  global structure found by the LP.

* **Deterministic bisection** gives a provable guarantee: the final `high`
  is a proven feasible upper bound (once the refined `h` passes the exact
  evaluation).  Hence any improvement over the previous record is guaranteed
  to be valid.

* **Scalability** – each LP solve is a few milliseconds; even with 30 – 40
  bisection steps we spend only a few seconds.  The remaining time is
  dedicated to the inexpensive local search, allowing many restarts and
  different n‑values within the 600 s budget.
