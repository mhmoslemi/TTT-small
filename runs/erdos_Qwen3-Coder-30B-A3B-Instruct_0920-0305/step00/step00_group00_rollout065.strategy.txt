### 1.  Problem restatement  

We must produce a step‑function `h` on the interval `[0,2]` (discretised on `n` equally spaced points) such that  

*   `0 ≤ h[i] ≤ 1` for every index `i`,  
*   `∑ h[i] · dx = 1`  (`dx = 2/n`, equivalently `∑ h[i] = n/2`),  

and the *overlap constant*  

```
C5(h) = max_k   ∫_0^2  h(x)·(1‑h(x+k)) dx
```

is as small as possible.  
With the discretisation used in the checker the integral becomes  

```
c[k] = dx·∑_{i} h[i]·(1‑h[i+k])   (zero‑padding outside the interval)
C5(h) = max_k c[k] .
```

Thus the optimisation is **minimise the maximum of a family of quadratic forms**

### 2.  Continuous reformulation  

Define the complementary vector `p = 1‑h`.  
For a fixed shift `k`  

```
c_k(h) = dx·∑_i  h[i]·p[i+k] .

Writing `p = 1‑h` we obtain  

```

```

The dependence on `h` is quadratic (indefinite) – the problem is non‑convex.

### 3.  Smooth approximation of the max  

The max is replaced by the *log‑sum‑exp* (LSE) function

```
L_β(h) = (1/β)·log( ∑_k exp( β·c_k(h) ) )      (β>0)

*   `L_β(h) ≥ max_k c_k(h)`, equality as β→∞.  
*   `L_β` is smooth; its gradient is a convex combination of the
    gradients of the individual `c_k`.

Define the **weights**

```
w_k = exp(β·c_k) / Σ_j exp(β·c_j) ,    Σ w_k = 1 .
```

Then  

```
∇L_β(h) = Σ_k w_k·∇c_k(h) .
```

Thus a single gradient evaluation yields a *sub‑gradient* of the original
max‑objective.

### 4.  Gradient of a single lag  

For a given integer shift `k` (with zero padding)  

```

```

Hence the gradient of `c_k` consists of two *shifted* contributions:
*add* the term `dx·(1‑h_{j+k})` on the interval where `j+k` is defined,
*subtract* the term `dx·h_{j‑k}` where `j‑k` is defined.

These updates can be performed **vector‑wise** for each shift using simple

### 5.  Projection onto the feasible set

```
0 ≤ h_i ≤ 1,      Σ h_i = n/2 .
```

Projection is performed by a **water‑filling / bisection on a Lagrange multiplier**:

1.  Search for λ such that

2.  The mapping `λ ↦ Σ x_i` is monotone, so a binary search on λ

3.  The resulting `x` is the Euclidean projection of `v` onto the feasible

All optimiser steps (gradient descent, line‑search, SLSQP updates) finish
