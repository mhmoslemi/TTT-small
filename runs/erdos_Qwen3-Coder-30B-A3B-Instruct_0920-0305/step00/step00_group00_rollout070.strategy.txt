**1. Problem recap and discretisation**

- The step function `h` is sampled on `n_points` equally spaced points on the interval `[0,2]`.  
  With `dx = 2/n_points` the constraints become  

  1. `0 ≤ h[i] ≤ 1` (box constraints)  
  2. `∑ h[i] = n_points/2`   (since the integral must be 1).

- For any sample vector `h`, the overlap vector for all integer shifts is  

  `O = np.correlate(h, 1‑h, mode='full') * dx`  

  (length `2·n_points‑1`).  
  The quantity to be minimised is `C5 = max(O)`.

**2. Mathematics – turning max‑overlap into a smooth objective**

The overlap for a shift `s` can be written

```
O_s = Σ_i h_i – Σ_i h_i·h_{i+s}   (zero‑padding outside the interval)
```

The first term `Σ_i h_i` is constant (`= n_points/2`) once the sum‑constraint is satisfied.
Thus minimising `max_s O_s` is equivalent to **maximising** the minimum cross‑correlation  
`Q_s = Σ_i h_i·h_{i+s}`.  

Directly handling `max` is non‑smooth.  We replace it by a **soft‑maximum**:

```
SM(h) = (1/α)·log( Σ_s exp(α·O_s) )        (α > 0, large ⇒ tighter approx)
```

`SM` is smooth, its gradient exists and is a weighted sum of the gradients of each `O_s`
with weights `w_s = exp(α·O_s) / Σ_t exp(α·O_t)` (the softmax of the overlaps).

**3. Gradient of the smooth objective**

For any shift `s`

```
∂O_s/∂h_j = 1 – (h_{j+s} + h_{j‑s})      (indices out of range give 0)
```

Hence the gradient of `SM` w.r.t. `h` is

```
g_j = Σ_s w_s·[ 1 – (h_{j+s} + h_{j‑s}) ]
    = 1 – Σ_s w_s·(h_{j+s} + h_{j‑s})          (because Σ_s w_s = 1)
```

The sums over `s` are over `-(n‑1)…+(n‑1)`.  For a moderate `n` (≤ 300) this can be
computed in O(n²) time using simple vectorised slices – far cheaper than a full O(n³)
approach.

**4. Enforcing the linear equality**

The sum constraint `Σ h_i = n_points/2` is added as a **quadratic penalty**

```
P(h) = λ·( Σ h_i – n_points/2 )²
∂P/∂h = 2·λ·( Σ h_i – n_points/2 )·1
```

A sufficiently large `λ` (e.g. 500–2000) keeps the iterate close to the feasible
hyper‑plane while still allowing the optimiser to move.

**5. Overall optimisation objective**

```
F(h) = SM(h) + P(h)
∇F(h) = g (from 3) + ∂P/∂h
```

The box constraints `[0,1]` are supplied directly to the optimiser; the penalty takes
care of the equality.
